## `claude-web`

`claude-web` שולח בקשות צ'אט בפורמט OpenAI דרך סשן דפדפן מאומת של `claude.ai`.
המבצע מנרמל את קובץ ה-Cookie שסופק, מאתר ארגון מאומת אחד, מכין את מצב השיחה, בוחר תעבורה ישירה או תעבורת דפדפן ומתרגם בקפדנות את תגובת ה-SSE ממקור השירות. התזמור נמצא ב-
`open-sse/executors/claude-web.ts:320`.

> **משתמשים חדשים בספקי Web Cookie?**
>
> קראו את **`docs/getting-started/WEB-COOKIE-GUIDE.md`** לקבלת מידע על תהליך ההגדרה הכללי, הנחיות אימות, מגבלות ופתרון בעיות, לפני שתמשיכו למדריך הספציפי לספק זה.

### קטלוג מודלים

מרשם הספקים חושף כעת בדיוק את שבעת מזהי המודלים הסטטיים האלה
(`open-sse/config/providers/registry/claude/web/index.ts:11`):

| מזהה מודל                   | שם תצוגה                    |
| --------------------------- | --------------------------- |
| `claude-fable-5`            | Claude Fable 5 (אינטרנט)    |
| `claude-opus-4-8`           | Claude Opus 4.8 (אינטרנט)   |
| `claude-sonnet-5`           | Claude Sonnet 5 (אינטרנט)   |
| `claude-haiku-4-5-20251001` | Claude Haiku 4.5 (אינטרנט)  |
| `claude-opus-4-7`           | Claude Opus 4.7 (אינטרנט)   |
| `claude-opus-4-6`           | Claude Opus 4.6 (אינטרנט)   |
| `claude-sonnet-4-6`         | Claude Sonnet 4.6 (אינטרנט) |

גילוי דינמי של מודלים אינו ממומש עבור ספק זה. הרשימה לעיל היא הקטלוג בזמן הריצה.

### פרטי התחברות ואיתור ארגון

ספקו את כותרת ה-Cookie המלאה של `claude.ai` או ערך סשן בלבד. ערכים ללא מעטפת
מנורמלים ל-`sessionKey`; קובצי Cookie אחרים נשמרים אם סופקו. המבצע מקבל את קובץ
ה-Cookie דרך `cookie` או `apiKey`, וקורא את הערכים האופציונליים `deviceId` ו-`orgId` מנתוני החיבור
(`open-sse/executors/claude-web.ts:72`).

אם `orgId` אינו קיים, המבצע קורא אל `GET https://claude.ai/api/organizations` ומשתמש בארגון הראשון
שהוחזר על ידי סשן Claude Web המאומת
(`open-sse/executors/claude-web.ts:141`). הוא נכשל באופן סגור כאשר לא מוחזר ארגון תקף,
מדווח על הרשאת סשן שנדחתה כשגיאת 401, ומבחין בין אתגר Cloudflare לבין כשל אימות.

### פעולות שיחה

האובייקט האופציונלי `claude_web` ברמה העליונה הוא קשיח. שדות לא מוכרים נדחים. השדות
המתקבלים שלו מוגדרים ב-`open-sse/executors/claude-web/session.ts:50`:

| שדה                   | משמעות                                                      |
| --------------------- | ----------------------------------------------------------- |
| `operation`           | `completion` כברירת מחדל; השתמשו ב-`retry` לתור ניסיון חוזר |
| `conversation_id`     | UUID מפורש עבור שיחה קיימת                                  |
| `parent_message_uuid` | UUID מפורש עבור הודעת האב של המסייע                         |
| `timezone`            | שם חוקי של אזור זמן לפי IANA                                |
| `locale`              | אזור תקין מבחינה מבנית                                      |
| `tool_states`         | מערך אופציונלי של מצבי כלי החשבון, מוגבל ל-128 רשומות       |

בקשות מוכנות משתמשות באחת משתי נקודות קצה של השירות במעלה הזרם
(`open-sse/executors/claude-web.ts:203`):

- תור חדש או תור המשך שולח בקשת
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/completion`.
- ניסיון חוזר שולח בקשת
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion`.

תור חדש כולל את `create_conversation_params`. המשך שנשמר במטמון או קושר במפורש
כולל את `parent_message_uuid` ומשמיט את `create_conversation_params`. ניסיון חוזר דורש הן
מצב שיחה והן מצב הודעת אב, ואינו שולח הנחיה
(`open-sse/executors/claude-web/session.ts:254`). שיחות חדשות פותחות את ממשק המשתמש המאומת
ב-`/new`; המשכים שנשמרו במטמון או קושרו במפורש פותחים את דף השיחה המדויק
(`open-sse/executors/claude-web/session.ts:324`).

מצב השיחה הוא מטמון בזיכרון, שהמפתח שלו מורכב מטווח חשבון מסוג SHA-256 ומתמליל המתקשר הקנוני.
תוקף הרשומות פג לאחר 30 דקות והמטמון מוגבל ל-5,000 רשומות
(`open-sse/executors/claude-web/session.ts:12`). המצב נשמר רק לאחר שמנתח הזרם הקשיח
מזהה את `message_stop`; הפעלה מחדש של התהליך משליכה אותו. במקרה של החטאה במטמון,
בקשה מרובת הודעות עוברת המרה סדרתית להנחיית שחזור אחת, במקום להשמיט בשקט
הודעות קודמות.

אזור ושעון זמן משתמשים בסדר העדיפות הבא: ערך `claude_web` מהבקשה, ערך החיבור,
ערך זמן הריצה, ולאחר מכן `en-US` עבור אזור או `UTC` עבור אזור זמן
(`open-sse/executors/claude-web/session.ts:218`).

### כלים ומטעני בקשה

בקשות ישירות ממירות רק כלי פונקציה תקינים מבחינה מבנית בפורמט OpenAI, שסופקו על ידי
המתקשר. אין רשימת ברירת מחדל סטטית ומומצאת של כלים
(`open-sse/executors/claude-web/payload.ts:102`).

בקשות דפדפן, לעומת זאת, לוכדות את בקשת ממשק המשתמש המאומת ושומרות את כלי החשבון,
מצבי הכלים והסגנונות המותאמים אישית שלה. שדות השיחה, המודל, ההנמקה, ההנחיה ומזהי ההודעות
שהוכנו עדיין דורסים את הבקשה שנלכדה
(`open-sse/executors/claude-web/browserTransport.ts:175`). תבניות דפדפן מוגבלות לטווח המוגדר
באמצעות גיבוב של החשבון, הארגון, קובץ ה-Cookie, האזור ואזור הזמן, ותוקפן פג לאחר 30 דקות
(`open-sse/executors/claude-web/browserTransport.ts:11`,
`open-sse/executors/claude-web/browserTransport.ts:158`). כאשר לבקשה ישירה אין כלים מטעם
המתקשר, היא יכולה לעשות שימוש חוזר בתבנית זו המוגבלת לטווח; לכלים מפורשים של המתקשר יש קדימות
(`open-sse/executors/claude-web/browserTransport.ts:214`).

### בחירת תעבורה

נתיב ברירת המחדל הוא `sendClaudeWebDirect()`, שקורא ל-`tlsFetchClaude()` באמצעות פרופיל
Chrome 146 שהוגדר וקובץ ה-Cookie שסופק (`open-sse/services/claudeTlsClient.ts:23`). הוא אינו
מפעיל פותר אתגרים ואינו מייצר קובץ Cookie חלופי.

הגדירו את `WEB_COOKIE_USE_BROWSER` לערך `1`,‏ `true` או `on` כדי להפוך את מתאם הדפדפן התחום לחשבון לתעבורה הראשית. הגדירו את `OMNIROUTE_BROWSER_POOL` לאחד מאותם ערכים כדי לאפשר לאתגר Cloudflare 403 מזוהה לעבור מתעבורה ישירה למתאם הדפדפן כחלופה (`open-sse/executors/claude-web.ts:195`). כשלי HTTP אחרים אינם מפעילים מעבר חלופי זה.

מתאם הדפדפן שומר קובצי Cookie בתוך אותו הקשר Playwright מאוגד, משתמש במפתח המגובב והתחום שתואר לעיל ושולח את ההשלמה מתוך הקשר זה (`open-sse/executors/claude-web/browserTransport.ts:444`). הוא לעולם אינו מייצא קובץ Cookie שנפתר בדפדפן אל לקוח ה-TLS הישיר. ניסיונות חוזרים בדפדפן דורשים תבנית ממשק משתמש שטרם פג תוקפה, המקושרת לאותו הקשר Playwright בפועל (`open-sse/executors/claude-web/browserTransport.ts:467`). קריאות תגובה בדפדפן מתבצעות באופן מצטבר בדף המאומת, מכבדות את ביטול הבקשה ומבטלות את גוף התגובה במעלה הזרם ברגע שהוא חורג מ-16 MiB (`open-sse/executors/claude-web/browserTransport.ts:259`).

המבצע מחזיר ללוגר הבקשות המשותף היטל ביקורת מושחר: מזהי UUID של הארגון, השיחה וההודעה, טקסט ההנחיה, הגדרות הכלים, קובצי Cookie ומזהי המכשיר אינם נכללים (`open-sse/executors/claude-web.ts:237`,
`open-sse/executors/claude-web.ts:252`). חריגות תעבורה מחזירות גם הן שגיאת חיבור כללית במקום ההודעה שנזרקה.

### התנהגות SSE

`createClaudeWebResponse()` מטפל במסגור LF או CRLF ובשדות `data:` מרובי שורות. הוא ממפה הפרשי טקסט אל `content`, הפרשי חשיבה אל `reasoning_content` ואירועי מטא-נתונים מוכרים אל הרחבת התגובה `claude_web`. כל אירוע מטא-נתונים מוקרן דרך רשימת השדות המותרים הייחודית לו (`open-sse/executors/claude-web/stream.ts:37`). המטא-נתונים של השיחה, הודעת האב, הודעת העוזר והפעולה מוחזרים גם בכותרות `X-OmniRoute-Claude-Web-*` (`open-sse/executors/claude-web/stream.ts:364`).

המנתח נכשל באופן סגור במקרה של JSON פגום, אירועי `error` במעלה הזרם, סוגי אירועים לא מוכרים, סדר לא תקין, אי-התאמות בבלוקי תוכן או EOF לפני `message_stop`. פלט מוזרם פולט מקטע סיום אחד ו-`[DONE]` אחד; פלט שנאגר משתמש באותו מנתח. המנתח מתייחס אל `message_stop` באופן מיידי כאירוע מסיים, מבטל נתונים עוקבים במעלה הזרם ומעביר ביטול במורד הזרם אל קורא הנתונים במעלה הזרם (`open-sse/executors/claude-web/stream.ts:461`,
`open-sse/executors/claude-web/stream.ts:563`). שורות SSE שלא הסתיימו ואירועים שנצברו מוגבלים ל-1 MiB (`open-sse/executors/claude-web/stream.ts:17`,
`open-sse/executors/claude-web/stream.ts:62`).

### בדיקות

```powershell
node --import tsx/esm --test tests/unit/claude-web-auto-refresh.test.ts tests/unit/claude-web-browser-transport.test.ts tests/unit/claude-web-executor-split.test.ts tests/unit/claude-web-live-alignment.test.ts tests/unit/claude-web-payload-runtime.test.ts tests/unit/claude-web-session.test.ts tests/unit/claude-web-sonnet5-registry-6209.test.ts tests/unit/claude-web-stream.test.ts tests/unit/claude-web-transport.test.ts tests/unit/claude-web.test.ts tests/unit/issue-6662-repro.test.ts
```

המקרים התלויים ב-Playwright בתוך `tests/unit/claude-web-auto-refresh.test.ts` מסומנים במפורש לדילוג. מאגר זה אינו מגדיר כעת סקריפט בדיקה חיה של Claude Web עם פרטי הזדהות, ולכן מקרים אלה, שעליהם מדלגים, אינם מהווים הוכחה להתנהגות בזמן ריצה.

### הגדרה

1. הפעילו את OmniRoute באמצעות `npm run dev` או מהתקנה בנויה.
2. פתחו את Dashboard → Providers → Add Provider.
3. בחרו בקטגוריה Web Cookie וב-Claude Web.
4. הדביקו את כותרת ה-Cookie המלאה שהועתקה מבקשת `claude.ai` מאומתת.
