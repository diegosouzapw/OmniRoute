> **בקצרה**: OmniRoute מדרג את הספקים **החינמיים** שלו לפי איכות המודלים באמצעות **ציוני ELO של
> Arena AI (בסגנון LMArena)**. פתחו את הדף **דירוג ספקים חינמיים** בלוח הבקרה כדי
> לראות אילו ספקים חינמיים מציעים את המודלים החזקים ביותר למשימה שלכם —
> בדירוג הכולל או בסינון לפי קטגוריה (כתיבת קוד, סקירה, תיעוד, ניפוי שגיאות).

---

## מה זה

OmniRoute רושם 329 ספקים, כולל 155 רשומות קטלוג המסומנות כ-**חינמיות/ללא אימות**
(ללא אימות,
OAuth במסלול חינמי או מפתח API במסלול חינמי — ראו
[מדריך המסלולים החינמיים](../getting-started/FREE-TIERS-GUIDE.md) ואת
[ספריית המסלולים החינמיים](../reference/FREE_TIERS.md) המלאה). הבעיה: איכות המודלים
אצל הספקים החינמיים משתנה מאוד. ספק ללא אימות שמציע מודל מתקדם הוא שימושי הרבה יותר
מספק שמציע מודל ישן וקטן.

**דירוג ספקים חינמיים** עונה על השאלה "**איזה ספק חינמי מספק לי את המודל הטוב ביותר?**"
באמצעות הצלבת הקטלוג של כל ספק חינמי עם **ציוני איכות המבוססים על חוכמת ההמונים**
מטבלת המובילים של **Arena AI** (ציוני ELO המבוססים על העדפות אנושיות, אותו רעיון
שמאחורי זירת הצ'אטבוטים של LMArena). לאחר מכן, הספקים מדורגים לפי עוצמתו של
**המודל החינמי הטוב ביותר** שלהם.

הדירוג מחושב משלושה מקורות אמיתיים:

1. רשימות הספקים החינמיים — `NOAUTH_PROVIDERS`, יחד עם רשומות `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` המסומנות ב-`hasFree`
   (`src/shared/constants/providers.ts`).
2. קטלוג המודלים של כל ספק מתוך מרשם הספקים
   (`open-sse/config/providerRegistry.ts`).
3. ציוני התאמה למשימה הנגזרים מ-ELO, הנשמרים בטבלת מסד הנתונים `model_intelligence`
   על ידי מנוע הסנכרון של Arena ELO (`src/lib/arenaEloSync.ts`).

לוגיקת ההצלבה נמצאת בקובץ `src/lib/freeProviderRankings.ts`.

## כיצד לגשת

### דף לוח הבקרה

פתחו את לוח הבקרה ועברו אל **עלויות → דירוג ספקים חינמיים**, או נווטו ישירות אל:

```
/dashboard/free-provider-rankings
```

הדף (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) מציג:

- **דוכן מנצחים לשלושת המקומות הראשונים** (🥇 🥈 🥉) של הספקים החינמיים המדורגים במקומות הגבוהים ביותר.
- **טבלת דירוג** מלאה עם העמודות: **דירוג**, **ספק**, **מודל מוביל**,
  **ציון**, **ציון ממוצע**, **מודלים**, **סוג**.
- **לחצני סינון לפי קטגוריה**: _כל הקטגוריות_, _ברירת מחדל_, _כתיבת קוד_, _סקירה_,
  _תיעוד_, _ניפוי שגיאות_.

תג **הסוג** של כל ספק מציין כיצד הוא ניתן בחינם:

| תג       | משמעות                                  |
| -------- | --------------------------------------- |
| `NOAUTH` | חינמי תמיד, ללא צורך בפרטי גישה         |
| `OAUTH`  | ספק OAuth עם מסלול חינמי (`hasFree`)    |
| `APIKEY` | ספק מפתח API עם מסלול חינמי (`hasFree`) |

הציונים מוצגים כתוויות קריאות לבני אדם (למשל _עילית_, _מצוין_, _טוב מאוד_,
_טוב_, _ממוצע_) במקום כמספרים גולמיים, מכיוון שהערך הבסיסי מייצג איכות דירוג
יחסית ולא אחוזים.

### נקודת קצה של API

הדף נתמך על ידי נקודת קצה ציבורית לקריאה
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

פרמטרים של השאילתה (מאומתים באמצעות Zod):

| פרמטר      | סוג    | ברירת מחדל | הערות                                                                                             |
| ---------- | ------ | ---------- | ------------------------------------------------------------------------------------------------- |
| `category` | מחרוזת | (ללא)      | אחד מבין `default`, `coding`, `review`, `documentation`, `debugging`. השמיטו לקבלת הדירוג המשולב. |
| `limit`    | מספר   | `50`       | מוגבל לטווח `1–100`.                                                                              |

מבנה התגובה:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` הוא ערך Arena ELO המקורי; `score` הוא ערך ההתאמה למשימה לאחר נרמול
(ראו להלן). ספקים שאין להם מודלים עם ציונים אינם נכללים בתגובה.

## כיצד פועלים הציונים

### מקור: טבלת המובילים של Arena AI

מנוע סנכרון ה-ELO של Arena (`src/lib/arenaEloSync.ts`) מושך שתי טבלאות מובילים — `text`
ו-`code` — מה-API של טבלת המובילים של Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). כל רשומה בטבלת המובילים
כוללת שם מודל, ספק, `score` מסוג ELO, רווח סמך ומספר הצבעות.

הקטגוריות בטבלאות המובילים ממופות לקטגוריות המשימות של OmniRoute:

| טבלת המובילים של Arena | קטגוריות המשימות של OmniRoute                     |
| ---------------------- | ------------------------------------------------- |
| `text`                 | `default`, `review`, `documentation`, `debugging` |
| `code`                 | `coding`                                          |

### נרמול (ציון התאמה למשימה)

ציוני ELO גולמיים מנורמלים בכל טבלת מובילים ל**ערך התאמה למשימה בטווח `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

הציון לעולם אינו מגיע ל-`0` או ל-`1`, וכך נותר מרווח לעקיפות שהגדיר המשתמש. זהו השדה
`score` שמופיע בתגובת ה-API והתווית המוצגת בלוח הבקרה.

### רמת ביטחון

לכל רשומה מוקצית רמת ביטחון בהתאם למספר ההצבעות ב-Arena:

| רמת ביטחון | הצבעות  |
| ---------- | ------- |
| `high`     | ≥ 5,000 |
| `medium`   | ≥ 1,000 |
| `low`      | < 1,000 |

### אחסון ועדכניות

הרשומות המנורמלות נכתבות לטבלת מסד הנתונים `model_intelligence` עם
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). תוקף הרשומות **פג לאחר
7 ימים**, כך שספק שמפסיק להסתנכרן מוסר בסופו של דבר במקום להציג
נתונים מיושנים.

הסנכרון פועל **כברירת מחדל**:

- הוא פועל פעם אחת בעת הפעלת השרת ולאחר מכן באמצעות טיימר מחזורי
  (`src/lib/arenaEloSync.ts`, מחובר דרך `src/instrumentation-node.ts`).
- הוא **אינו חוסם ולעולם אינו גורם לכשל קריטי** — אם משיכת הנתונים מהמקור נכשלת, OmniRoute ממשיך
  לפעול והדירוגים פשוט מציגים את הנתונים התקינים האחרונים (או מצב ריק).

שני משתני סביבה שולטים בו (מתועדים ב-
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| משתנה                     | ברירת מחדל        | מטרה                                           |
| ------------------------- | ----------------- | ---------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`            | יש להגדיר ל-`false` כדי לבטל את הסנכרון היוצא. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24 שעות) | מרווח הסנכרון, בשניות.                         |

### סנכרון ידני / סטטוס / ניקוי

עבור מפעילי המערכת, נקודת קצה מאומתת לניהול מאפשרת שליטה ידנית
(`src/app/api/intelligence/sync/route.ts` — דורשת אימות ניהולי):

```
GET    /api/intelligence/sync          # סטטוס הסנכרון הנוכחי (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # הפעלת סנכרון ידני; גוף: { "dryRun": true } לתצוגה מקדימה ללא כתיבה
DELETE /api/intelligence/sync          # ניקוי כל רשומות המודיעין המסונכרנות של arena_elo
```

אם דף הדירוגים ריק, הפעלה ידנית של `POST /api/intelligence/sync` (או פשוט
הפעלה מחדש של השרת) מאכלסת אותו מחדש.

### התאמת מודלים לטבלת המובילים

מזהי המודלים ברישום ושמות המודלים ב-Arena לא תמיד תואמים במדויק. הדירוג משתמש
בהתאמה גמישה (`findMatchingIntelligence` בתוך `src/lib/freeProviderRankings.ts`):

1. התאמה מדויקת למזהה המודל המנורמל.
2. התאמה לאחר הסרת סיומת גרסה בסוף (לדוגמה, `kimi-k2.6` ← `kimi-k2`).
3. התאמת קידומת (שם מודל בטבלת המובילים הוא קידומת של המזהה ברישום).

בצד הסנכרון, קידומות ספקים מוכרות (`anthropic/`, `openai/`, `google/`, …)
מוסרות, ומפת כינויים קטנה מרחיבה שמות קנוניים לגרסאות שבהן OmniRoute משתמש
באופן פנימי, כך שניתן למצוא מודלים תחת כל שם.

### כיצד ספק מדורג

עבור כל ספק חינמי, המנוע מעניק ציון לכל מודל בקטלוג שלו, ולאחר מכן:

- **המודל המוביל** = המודל של הספק שקיבל את הציון הגבוה ביותר.
- **ציון ממוצע** = ממוצע הציונים של כל המודלים של הספק שקיבלו ציון.
- **מודלים** = מספר המודלים של הספק שהיה להם ציון Arena.

הספקים ממוינים תחילה לפי **ציון המודל המוביל**, ולאחר מכן לפי הציון הממוצע. כך מתוגמל
ספק שמציע לפחות מודל חינמי חזק אחד.

## שימוש בדירוג לבחירת ספקים חינמיים

1. **בחרו את הקטגוריה המתאימה.** השתמשו במסנן **תכנות** עבור עומסי עבודה של סוכנים/קוד, או
   השאירו אותו על **כל הקטגוריות** / **ברירת מחדל** עבור צ'אט כללי. אותו ספק עשוי
   להיות מדורג באופן שונה בין קטגוריות, משום שהמודל המוביל שלו שונה בכל טבלת דירוג.
2. **העדיפו את המקומות הראשונים להגדרה חד-פעמית.** אם ברצונכם לחבר רק ספק חינמי אחד או
   שניים, התחילו באלו המדורגים בראש הקטגוריה שלכם.
3. **בדקו את תג הסוג.** ספקי `NOAUTH` הם המהירים ביותר לחיבור (ללא
   פרטי גישה). המסלולים החינמיים מסוג `OAUTH` / `APIKEY` דורשים הרשמה קצרה, אך לעיתים קרובות מציעים
   מודלים חזקים יותר. להוראות חיבור, עיינו ב[מדריך למסלולים חינמיים](../getting-started/FREE-TIERS-GUIDE.md).
4. **חברו כמה ספקים ואפשרו ל-Auto-Combo להחליט.** אותם נתוני Arena ELO שמפעילים
   דף זה משמשים גם את **גורם ההתאמה למשימה** של מנוע הניקוד Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, סדר פתרון
   `user_override → arena_elo → models_dev_tier → static table`). לכן, לאחר חיבור
   הספקים החינמיים המובילים, ניתוב באמצעות `model: "auto"` (למשל `auto/coding`) יעדיף
   אוטומטית את המודלים החינמיים האיכותיים יותר עבור כל בקשה. לפירוט המלא של הניקוד לפי 16 גורמים, עיינו ב-
   [Auto-Combo](../routing/AUTO-COMBO.md).
