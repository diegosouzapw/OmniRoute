**OmniCopilot** מוסיף כל מודל ש-OmniRoute שלכם מספק אל בורר המודלים _המובנה_ של GitHub Copilot Chat.
ללא סרגל צד נוסף וללא ממשק צ'אט נפרד — מצב הסוכן של Copilot, קריאה לכלים,
שרתי MCP והוראות מותאמות אישית ממשיכים כולם לעבוד, רק על המודל שתבחרו.

| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **התקנה (VS Code)**  | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **התקנה (פיצולים)**  | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **קוד מקור / בעיות** | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |

> **אין צורך במינוי Copilot.** מאז VS Code 1.122, ספק מודל שפה פועל
> ללא כניסה ל-GitHub וללא תוכנית Copilot כלשהי. השלמות בתוך השורה ותכונות
> המבוססות על embeddings אינן חלק מ-API הספק ועדיין דורשות Copilot.

## הגדרה

1. **הפעילו את OmniRoute** — `npm install -g omniroute && omniroute` (לוח הבקרה ב-`http://localhost:20128`).
2. **התקינו את ההרחבה** — חפשו "OmniRoute" בתצוגת ההרחבות.
3. **בחרו מודל** — Copilot Chat → בורר המודלים → **ניהול מודלים…** → **OmniRoute**, ואז סמנו
   את המודלים הרצויים.

אין צורך להגדיר דבר כאשר OmniRoute פועל ביציאת ברירת המחדל. עבור מופע מרוחק, פתחו את
**סמל OmniRoute בסרגל הפעילות** (או הפעילו את `OmniRoute: Manage Connection`) והגדירו:

- **כתובת URL של השרת** — שורש השרת, לדוגמה `http://192.168.0.15:20128`. הסיומת `/v1`
  נוספת על ידי ההרחבה; אל תכללו אותה.
- **מפתח API** — רק כאשר השרת מגדיר את `REQUIRE_API_KEY`. נשמר בצרור המפתחות של מערכת ההפעלה באמצעות
  VS Code SecretStorage, ולעולם לא ב-`settings.json`.

## מה יוצג בבורר

ההרחבה אינה מציגה את המטען הגולמי של `GET /v1/models` — היא מעבדת אותו, והמספר
שתראו נמוך מגודל הקטלוג משתי סיבות מכוונות.

### היא מבקשת מזהה אחד לכל מודל

ברירת המחדל של `MODELS_CATALOG_PREFIX_MODE` היא **`dual`**, המפרסמת כל מודל פעמיים — פעם אחת
תחת קידומת הכינוי הקצר ופעם אחת תחת קידומת הספק הקנונית — כך שתצורות לקוח
ישנות ימשיכו לזהות את שתי הצורות:

```
cc/claude-sonnet-4-6        ← קידומת כינוי
claude/claude-sonnet-4-6    ← קידומת קנונית, אותו מודל
```

ההרחבה מבקשת **`GET /v1/models?prefix=alias`** כדי שיגיע מזהה אחד לכל מודל, מבלי
לשנות את ההגדרה הכלל-שרתית עבור הלקוחות האחרים שלכם. במופע ייחוס, פעולה זו צמצמה
**2345 רשומות ל-1396 — 949 כפילויות, ללא אובדן מודלים.**

אם תעדיפו לתקן זאת ברמת השרת עבור _כל_ לקוח, הגדירו בדשבורד את דגל התכונה
`MODELS_CATALOG_PREFIX_MODE` לערך `alias`. ראו
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) לפרטים על
פרמטר השאילתה והטבלה לכל מצב.

### היא מסתירה מודלים שאינם יכולים לנהל צ'אט

הקטלוג מפרט גם מודלים לתמונות, וידאו, שמע, דירוג מחדש, embeddings ומודרציה. אלה
ממילא נדחים בבקשת צ'אט:

```
HTTP 400 — המודל '<id>' הוא מודל ליצירת תמונות ולא ניתן להשתמש בו עם
/v1/chat/completions. השתמשו במקום זאת ב-POST /v1/images/generations.
```

ולכן הם מסוננים לפי שדה ה-`type` שלהם לפני שהם מגיעים לבורר. **מודלים של Responses-API
נשמרים** — כל רשומת Codex / GPT-5.x מפרסמת `supported_endpoints: ["responses"]`,
ו-OmniRoute מתרגם אותם עבור `/v1/chat/completions`, כך שאפשר להשתמש בהם ללא כל בעיה.

### ספקים שמעולם לא הגדרתם

הקטלוג מפרט מודלים מספקים בעלי **חיבור פעיל** _וכן_ כל ספק **noAuth** —
הספקים שאינם דורשים מפתח ומהווים חלק גדול מהשכבה החינמית. זה מכוון. כדי להסתיר
אותם, הוסיפו אותם ל-`blockedProviders` בהגדרות לוח הבקרה; אין צורך לשנות דבר
בהרחבה.

## לוח הבקרה בתוך לשונית של VS Code

`omnicopilot.dashboardOpen: "editor"` מציג את לוח הבקרה של OmniRoute בלשונית עורך באמצעות
Simple Browser במקום בדפדפן חיצוני. ההטמעה היא **בהצטרפות מפורשת בצד השרת** באמצעות
`DASHBOARD_ALLOW_EMBED=vscode`, שמגיש את דפי ה-HTML עם
`frame-ancestors 'self' vscode-webview:` במקום ברירת המחדל `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. ממשק ה-API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) שומר על
הכותרות המחמירות בכל מקרה.

> ⚠️ **זהו דגל של זמן הבנייה, לא של זמן הריצה.** Next.js מקמפל את `headers()` לתוך מניפסט
> הנתיבים, ולכן `next.config.mjs` קורא את המשתנה בזמן בניית החבילה
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> ייצוא שלו לפני שרת שכבר נבנה לא משנה דבר — הכותרות מוטמעות מראש.

```bash
# המשתנה חייב להיות קיים בפקודת הבנייה
DASHBOARD_ALLOW_EMBED=vscode npm run build        # או npm run build:release
npm start
```

| אופן ההתקנה                | האם ניתן להפעיל הטמעה?                                                                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| מקוד המקור                 | ✅ הגדירו את המשתנה בפקודת הבנייה, כפי שמוצג למעלה                                                                                  |
| `npm install -g omniroute` | ❌ החבילה שפורסמה כוללת חבילה שנבנתה מראש — במקום זאת, בנו מקוד המקור                                                               |
| תמונת Docker               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — התמונה שנבנתה מראש ב-Docker Hub אינה תומכת בהטמעה |

ללא גרסה שנבנתה עם תמיכה בהטמעה, הדף מסרב להיטען במסגרת, התוסף מזהה זאת מכותרות
התגובה וחוזר לדפדפן החיצוני — דבר אינו נשבר, ומוצגת על כך הודעה פעם אחת.
ראו [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) ואת הבעיה
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## הגדרת הכלים האחרים שלכם מתוך VS Code

**`OmniRoute: Configure Coding CLI`** מפעיל את ה-CLI של `omniroute` כדי לכתוב פרופילים מוכנים לשימוש
עבור Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo ו-Roo — אותן תצורות שמתוארות ב-
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). מפתח ה-API מועבר ל-CLI דרך משתנה הסביבה
`OMNIROUTE_API_KEY`, ולעולם לא בשורת הפקודה.

## פתרון בעיות

| תסמין                                       | סיבה / פתרון                                                                                                                                                                                                                          |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| אין מודלים של OmniRoute בבורר               | לא ניתן להגיע לשרת. הנקודה בשורת המצב הופכת לאפורה; הפעילו את `OmniRoute: Check Connection`. הגילוי שקט במכוון ואינו מוסיף מודלים במקום להציג בקשה.                                                                                   |
| כל מודל מופיע פעמיים                        | אתם משתמשים בגרסת OmniCopilot ישנה מ-1.0.1 — עדכנו אותה. התוסף מבקש כעת `?prefix=alias`.                                                                                                                                              |
| מודל תמונה/שמע שהיה מופיע בעבר נעלם         | מכוון החל מ-1.0.1 — הוא ממילא לא היה יכול לענות לבקשת צ'אט.                                                                                                                                                                           |
| הלוח חסר מסרגל הפעילות                      | VS Code מעביר מכלי תצוגה נוספים לתפריט הגלישה **"…"** בתחתית סרגל הפעילות, ומכל שהוסתר באמצעות לחיצה ימנית נשאר מוסתר. לחצו לחיצה ימנית על סרגל הפעילות → סמנו את **OmniRoute**, או פתחו אותו באמצעות `OmniRoute: Manage Connection`. |
| לוח הבקרה נפתח בדפדפן למרות מצב `editor`    | השרת לא **נבנה** עם `DASHBOARD_ALLOW_EMBED=vscode` (ראו למעלה) — הגדרתו בזמן ההפעלה בהתקנה שנבנתה מראש לא משנה דבר. המעבר החלופי הוא מכוון.                                                                                           |
| רשימת המודלים אינה מעודכנת לאחר שינוי ספקים | `OmniRoute: Refresh Models`, או הקישור ↻ בלוח.                                                                                                                                                                                        |
