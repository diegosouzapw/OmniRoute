OmniRoute מארגן את 352 הספקים הנתמכים ב-3 רמות כלכליות. כל
בקשה עוברת דרכן לפי הסדר עד שאחת מהן מחזירה תשובה בהצלחה — כך
מתקבלת התשובה הזולה ביותר שזמינה, ללא צורך בכתיבת קוד חלופי.

## רמה 1 — מינוי

**ספקים שכבר שילמתם עליהם.** OmniRoute מנצל כל טיפה מהמכסה לפני
שתוקפה פג.

| ספק                          | מדוע רמה 1                                        |
| ---------------------------- | ------------------------------------------------- |
| Claude Code OAuth            | Anthropic Pro/Team — מחיר קבוע, לעיתים אינו מנוצל |
| OpenAI Codex (מינוי ChatGPT) | Plus/Team כולל מכסת Codex                         |
| GitHub Copilot               | תשלום לפי משתמש — המכסה מתאפסת מדי חודש           |
| Cursor IDE                   | מכסת תוכנית Pro                                   |
| Antigravity / Devin Desktop  | מכסות מובנות                                      |

**אסטרטגיה**: יש לנתב לכאן תחילה כל בקשה שמתאימה לנקודות החוזק של
המודל. עוקב המכסות מנטר מועדי איפוס מתקרבים, ואסטרטגיית השילוב `reset-aware`
מתעדפת בהתאם. כדי לנתב תחילה לרמה 1 ולעבור לרמות בתשלום רק
כאשר המכסה נגמרת, השתמשו במזהה `auto/thrifty` — או ב-`auto/subscription`
כדי להישאר בקיבולת הכלולה בתוכנית ולהיכשל באופן סגור במקום זאת. ראו
[ניתוב עם עדיפות למינוי](../routing/SUBSCRIPTION_LADDER.md).

## רמה 2 — זולה

**ספקים בתשלום לפי אסימון בעלות של פחות מ-$1 למיליון אסימונים.** שמורה לעבודה בנפח גבוה
או לשימוש לאחר שמכסות רמה 1 מגיעות למגבלה.

| ספק                         | מחיר (קלט/פלט)        | נקודות חוזק              |
| --------------------------- | --------------------- | ------------------------ |
| DeepSeek V4 Pro             | $0.27 / $1.10 למיליון | קוד, הסקה                |
| GLM-4.5                     | $0.60 / $2.20 למיליון | הקשר ארוך                |
| MiniMax M1                  | $0.20 / $1.10 למיליון | מהירות                   |
| Qwen Coder                  | $0.30 / $1.20 למיליון | קוד                      |
| OpenRouter (ממוטב לפי מחיר) | משתנה                 | יותר מ-100 מודלים, דינמי |

**אסטרטגיה**: השילוב `cost-optimized` בוחר את המודל בעל העלות הנמוכה ביותר לאסימון שעומד
במסנן היכולות של המשימה (ראייה, מצב JSON, כלים, הקשר מרבי).

## רמה 3 — חינמית

**ספקים ללא עלות** — מסלולים חינמיים, תוכניות זיכוי ומכסות OAuth יומיות.

| ספק              | מכסה חינמית / זיכויים                |
| ---------------- | ------------------------------------ |
| Kiro AI          | מסלול Claude חינמי (שימוש הוגן נדיב) |
| OpenCode Free    | ללא אימות, מגבלות קצב נדיבות         |
| Qoder            | OAuth חינמי                          |
| Google Vertex AI | זיכויים בסך $300 לחשבונות חדשים      |
| Amazon Q         | מסלול חינמי למשתמשי AWS              |
| Pollinations     | API ציבורי פתוח                      |
| Cloudflare AI    | מסלול Workers AI חינמי               |

**אסטרטגיה**: השילוב `auto` עם תקרת תקציב מנתב לכאן כאשר רמות 1+2 נכשלות
או כאשר מוגדר `useFreeOnly=true`. לספקים חינמיים יש לעיתים קרובות
מגבלות קצב מחמירות יותר — מפסק המעגל משחזר אותם לאחר השהיה.

## הגדרת הרמות

לוח הבקרה → **רמות** → הקצו את הספקים שלכם. ברירות המחדל (מתוך `tierDefaults.json`)
הגיוניות; ערכו אותן כאשר יש לכם מינויים מסוימים שברצונכם לתעדף או ספקים שברצונכם להחריג.

הניקוד לפי 16 גורמים של Auto-Combo מתחשב גם ברמה. ראו
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## טלמטריה

לוח הבקרה → **שימוש** מציג את מספר האסימונים שנצרכו בכל רמה בכל יום. השתמשו בכך כדי:

- לוודא שרמה 1 מנוצלת במלואה (אחרת אתם מבזבזים את ערך המינוי)
- לזהות אילו מודלים מרמה 2 נבחרים בתדירות הגבוהה ביותר (צמצמו ל-1–2)
- לוודא שרמה 3 חוסכת כסף בעומסי עבודה של בדיקות וחקירה

## דפוסים נפוצים

### עומס עבודה חינמי בלבד

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

מנתב בעדיפות חזקה לרמה 3; משתמש ברמה 2 רק אם רמה 3 אינה זמינה.

### מינוי תחילה, עם חלופה זולה

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

רשימה מפורשת ומסודרת התואמת לרמה 1 → רמה 2 → רמה 3.
