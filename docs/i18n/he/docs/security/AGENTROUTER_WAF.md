שער ה-upstream של `agentrouter` מפעיל מסנן תוכן מבוסס מילות מפתח על
`messages[].content`. המסנן דטרמיניסטי בחלקו (תמיד חוסם
ביטויים מסוימים) והסתברותי בחלקו (רגיש להתפרצויות — נעשה
אגרסיבי יותר לאחר בקשות מהירות, ומתאושש לאחר תקופת צינון).

כאשר ה-WAF חוסם בקשה, הוא מחזיר:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## היקף המסנן

ה-WAF בודק רק את `messages[].content`. הוא **אינו** בודק:

- את הנחיית ה-`system`
- בלוקי תוכן מובנים (`tool_result`, `tool_use`, `thinking`, `image`)
- את השדות `description` ו-`input_schema` של כלים
- מטא-נתונים של הבקשה, כותרות או מזהה מודל

## דפוסים שנחסמים תמיד (ללא תלות ברישיות)

| דפוס                        | הערות                                                |
| --------------------------- | ---------------------------------------------------- |
| כל גרסה של `Lorem ipsum`    | כל אוצר המילים הלטיני של lorem נחסם                  |
| `language model` (לבדו)     | "the language model" ו-"large language model" עוברים |
| `virtual assistant`         | "AI assistant" עובר                                  |
| `I'm here to help`          | גם "here to help" לבדו נחסם                          |
| `Claude, made by Anthropic` | הביטוי המלא בלבד                                     |

## דפוסים שנחסמים כמעט תמיד

| דפוס                                                    | הערות                                         |
| ------------------------------------------------------- | --------------------------------------------- |
| `placeholder`                                           | כאשר הוא עומד בפני עצמו (לא כשם פרמטר וכדומה) |
| `dummy data`                                            | ביטוי seed נפוץ ל-fixtures                    |
| `foo bar baz`                                           | ביטוי placeholder קנוני                       |
| אסימונים קצרים חוזרים (`AAA BBB CCC`, `test test test`) | גלאי לדחיסת מילות מפתח                        |

## התנהגות תחת עומס

לאחר כ-5 בקשות מהירות בחלון זמן קצר, ה-WAF מתחיל לחסום תוכן
שבדרך כלל היה עובר. הדלי משתחרר לאחר כ-5–10 שניות ללא
פעילות. זהו אותו מגביל קצב הקשור ל-IP ולמפתח, שגורם
לשגיאות `400 content-blocked` לסירוגין כאשר Claude Code או Codex CLI
מבצעים כמה קריאות לשימוש בכלים / שליחת הודעות ברצף מהיר.

## פתרונות שכבר יושמו ב-OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — מנגנון הגנה מפני התפרצויות שאוכף
   מרווח מינימלי של 500 אלפיות השנייה בין בקשות יוצאות לכל כתובת URL מסוג `agentrouter:*`.
   המרווח נמוך בהרבה מסף תפיסת ההשהיה האנושית ומונע
   מה-WAF לפעול בתעבורה רגילה.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — כאשר upstream מחזיר
   `400 content-blocked`, המבצע מנסה שוב את אותה כתובת URL עם
   השהיה מעריכית (1.5 שניות, 3.0 שניות, עד 2 ניסיונות). לאחר ההשהיה
   ה-WAF בדרך כלל משתחרר והניסיון החוזר מצליח.

3. **`tests/unit/compression/harness.test.ts`** — ה-test fixture
   `longInput` שונה מ-`"lorem ipsum dolor sit amet ".repeat(40)`
   ל-`"example content for testing purposes ".repeat(40)`, כך שכאשר
   Claude Code קורא את הקובץ הזה באמצעות הכלי `Read`, תוכן הקובץ
   אינו זורם בחזרה דרך בלוק `tool_result` ומפעיל את ה-WAF.

## הנחיות להנחיות ולפלט כלים

אם הפעלה של Claude Code או Codex CLI נתקלת שוב ושוב ב-
`400 content-blocked`, יש לבדוק את הודעת המשתמש האחרונה ואת תוצאת
הכלי האחרונה לאיתור אחד מהדפוסים שלעיל ולנסח מחדש. דרכי
עקיפה נפוצות:

- החליפו את `Lorem ipsum …` ב-`example text …` או בתוכן בפועל
  שהבדיקה או ה-fixture מנסים לייצג.
- החליפו את `placeholder` (כאשר הוא עומד בפני עצמו) ב-`example value`,
  ב-`sample value` או בערך האמיתי.
- החליפו את `language model` ב-`large language model` או ב-`the model`.
- החליפו את `dummy data` ב-`sample data` או בערכי seed מציאותיים.
- החליפו את `I'm here to help` / `here to help` בפתיח ממוקד יותר
  (למשל "אבדוק את הקובץ שציינת").

## דיווח על זיהויים שגויים ל-upstream

המסנן הנוכחי אגרסיבי מדי — הוא חוסם את "Lorem ipsum" בתוך
בלוקי `tool_result`, אף שברור שהמפעיל לא התכוון
להזריק הנחיה. מפעילים שרוצים שהבעיה תתוקן במקור צריכים
לפנות אל `agentrouter.org` כדי לדווח על הזיהויים השגויים. רשימת החסימה
לעיל היא התוצאה האמפירית של בדיקת ה-upstream נכון ל-2026-08-03.
