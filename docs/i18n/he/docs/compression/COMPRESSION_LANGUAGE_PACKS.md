דחיסת Caveman יכולה לטעון חבילות כללים ייעודיות לשפה בנוסף לכללים המובנים באנגלית.
כך מנוע הליבה נשאר יציב, בעוד שחבילות השפה לפורטוגזית, ספרדית, גרמנית, צרפתית, איטלקית, יפנית ושפות עתידיות יכולות להתפתח באופן עצמאי.

## מיקום

חבילות השפה נמצאות תחת:

```txt
open-sse/services/compression/rules/<language>/
```

החבילות המסופקות כעת (אומתו מול תוכן התיקייה `rules/`):

| שפה               | תיקייה         | קטגוריות כללים קיימות                               |
| ----------------- | -------------- | --------------------------------------------------- |
| אנגלית            | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ספרדית            | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| פורטוגזית (ברזיל) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| אינדונזית         | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| איטלקית           | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| גרמנית            | `rules/de/`    | `context`, `filler`, `structural`                   |
| צרפתית            | `rules/fr/`    | `context`, `filler`, `structural`                   |
| יפנית             | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **הערת תאימות:** החבילות `en`, `es`, `pt-BR`, `id` ו-`it` כוללות את כל 5 הקטגוריות; החבילות `de`, `fr` ו-`ja` מסופקות עם 3 קטגוריות. הקטגוריות החסרות `dedup` ו-`ultra` חוזרות בשקט לכללים המובנים באנגלית. נשמח לקבל תרומות להוספת `dedup.json` ו-`ultra.json` לחבילות הקטנות יותר.
>
> החבילה `pt-BR` מבוססת על **[Troglodita](https://github.com/leninejunior/troglodita)** מאת Lenine Júnior — מערכת דחיסה שתוכננה מאפס עבור הדקדוק של פורטוגזית ברזילאית (צמצום פליאונזם, הסרת מילות מילוי ב-PT-BR וקיצורים טכניים עבור קהילת המפתחים הברזילאית).
>
> רשימת הקטגוריות הקנונית והסכימה לכל קטגוריה נמצאות ב-[`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (טיוטת JSON Schema ‏2020-12).

## זיהוי שפה

`languageDetector.ts` משתמש ביוריסטיקות קלות כדי להסיק את השפה מטקסט ההנחיה. שפת ברירת המחדל שהוגדרה עדיין מכובדת, וניתן להשבית את הזיהוי באמצעות התצורה כאשר נדרשת שליטה מדויקת.

פלט הזיהוי משמש רק לבחירת חבילות כללים. הוא אינו משנה את ניתוב הספקים, בחירת הגדרות האזור או שפת ממשק המשתמש.

## מבנה התצורה

הגדרות הדחיסה יכולות לכלול:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` שולט בברירות המחדל של לוח הבקרה והתצוגה המקדימה. `cavemanConfig` הוא תצורת מנוע זמן הריצה שבה נעשה שימוש כאשר Caveman דוחס טקסט של הודעות.

## הוספת חבילת שפה

1. צרו את `open-sse/services/compression/rules/<language>/<pack>.json`.
2. השתמשו בפורמט הכללים של Caveman מתוך `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. הקפידו על החלפות שמרניות והימנעו משינוי קוד, מזהים, כתובות URL או JSON.
4. הוסיפו או עדכנו בדיקות לבחירת שפה ולהתנהגות ההחלפה.
5. חשפו תוויות חדשות בלוח הבקרה/i18n אם השפה מופיעה בבוררי ממשק המשתמש.

## API

ניתן לשלוח שאילתה לקבלת החבילות הזמינות באמצעות:

```bash
curl http://localhost:20128/api/compression/language-packs
```

נקודת הקצה לתצוגה מקדימה מקבלת דריסות של תצורת השפה:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

כל 6 חבילות השפה קיבלו ב־v3.8.0 סעיף `SHARED_BOUNDARIES`, המוחל בכל רמת עוצמה של
Caveman‏ (LITE, FULL, ULTRA). הוא מנחה את המנוע לשמר את התבניות האלה כלשונן,
ללא קשר להסרת מילות מילוי מסביבן:

| סוג התבנית                     | דוגמה                                  |
| ------------------------------ | -------------------------------------- |
| בלוקי קוד מגודרים              | ` ```python\n...\n``` `                |
| קוד בתוך שורה                  | `` `my_var` ``                         |
| כתובות URL                     | `https://example.com/path`             |
| נתיבי קבצים (מוחלטים + יחסיים) | `/etc/hosts`, `./src/index.ts`         |
| כותרות שגיאה                   | `Error:`, `TypeError:`, `SyntaxError:` |
| שורות מעקב מחסנית              | `  at functionName (file.ts:12:3)`     |

תבניות אלה מאוכלסות ב־`DEFAULT_CAVEMAN_CONFIG.preservePatterns` (בעבר `[]`). הקבוע
נמצא ב־`open-sse/services/compression/types.ts`.

### מדוע זה חשוב

ללא SHARED_BOUNDARIES, מצבי Caveman אגרסיביים עלולים להסיר תוכן שנראה כמו טקסט
חזרתי, אך למעשה היה קטע קוד, נתיב קובץ או מחסנית שגיאות. SHARED_BOUNDARIES משמש כרשת
ביטחון שאינה תלויה בשפה ומוחלת לפני הפעלת כללי מילות המילוי.

### התאמה אישית של preservePatterns

ניתן להוסיף תבניות נוספות בזמן ריצה דרך הגדרות הדחיסה:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

תבניות מותאמות אישית מרחיבות את 6 ברירות המחדל (ואינן מחליפות אותן).

## הערות תפעוליות

- הכללים המובנים באנגלית נשארים ברירת המחדל החלופית כאשר חבילת שפה חסרה.
- חבילות JSON מובנות שאינן תקינות נכשלות באימות, כדי שנכסי הפצה לא ייפגעו ללא התראה.
- חבילות כללים מכילות נתונים בלבד, ואינן אמורות לייבא קוד או להריץ לוגיקה שרירותית.
- שכבת ניתוח נתוני הדחיסה מתעדת את המצב והמנוע שנבחרו, ולא את הטקסט המלא של ההנחיה.
