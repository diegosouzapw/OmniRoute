## ניווט ברמה גבוהה

סרגל הצד של לוח הבקרה (לאחר קבוצה B) כולל את המקטעים הבאים ברמה העליונה, לפי הסדר:

```
בית
ספקים
שילובים
מפתחות API
הגדרות
ניתוח נתונים
עלויות          ← חדש (קבוצה B, תוכנית 16)
ניטור           ← אורגן מחדש (קבוצה B, תוכנית 16)
...
```

## מקטע העלויות (חדש, רמה 1)

קידומת נתיב: `/dashboard/costs/`

| פריט         | URL                                  | תיאור                                  |
| ------------ | ------------------------------------ | -------------------------------------- |
| סקירה כללית  | `/dashboard/costs`                   | לוח עלויות מצטבר (הועבר מניתוח נתונים) |
| תמחור        | `/dashboard/costs/pricing`           | טבלת תמחור לפי מודל                    |
| תקציב        | `/dashboard/costs/budget`            | ספי תקציב + התראות                     |
| שיתוף מכסה   | `/dashboard/costs/quota-share`       | מאגרי שיתוף מכסה + שימוש               |
| הגדרת תוכנית | `/dashboard/costs/quota-share/plans` | דריסות תוכנית לפי ספק                  |

**נימוק**: תמחור, תקציב ושיתוף מכסה היו בעבר תחת
`ניטור > פרמטרי עלויות`. העברתם למקטע ייעודי ברמה העליונה
מאפשרת למצוא אותם מבלי לנווט דרך כלי תצפיתיות.

## מקטע הניטור (אורגן מחדש)

מקטע הניטור כולל כעת את **פעילות בחלק העליון**, ואחריה **3 קבוצות משנה**:

```
ניטור
├── פעילות                 ← ציר זמן של אירועים (פריט ברמה העליונה)
├── קבוצת יומנים
│   ├── יומנים (הכול)
│   ├── יומני פרוקסי
│   └── יומני מסוף
├── קבוצת ביקורת
│   ├── יומן ביקורת
│   ├── ביקורת MCP
│   └── ביקורת A2A
└── קבוצת מערכת
    ├── תקינות
    └── זמן ריצה
```

### מה השתנה לעומת המבנה הישן

| לפני                                                                               | אחרי                                        |
| ---------------------------------------------------------------------------------- | ------------------------------------------- |
| פעילות = לשונית בתוך יומנים שהציגה את יומן הביקורת                                 | פעילות = פיד ייעודי (`/dashboard/activity`) |
| קבוצת פרמטרי עלויות תחת ניטור                                                      | הועברה למקטע העלויות                        |
| רשימה שטוחה: יומנים, פעילות (יומנים), ביקורת, תקינות, זמן ריצה, תמחור, תקציב, מכסה | מבנה של 3 קבוצות + מקטע עלויות ייעודי       |

## פעילות לעומת יומן ביקורת

כעת מדובר בשני פריטים נפרדים:

| ממד                     | פעילות (`/dashboard/activity`)                    | יומן ביקורת (`/dashboard/audit`)          |
| ----------------------- | ------------------------------------------------- | ----------------------------------------- |
| **מטרה**                | פיד אירועים למשתמשים ("מה קרה לאחרונה")           | יומן תאימות / אבטחה                       |
| **מקור נתונים**         | `GET /api/compliance/audit-log?level=high`        | `GET /api/compliance/audit-log?level=all` |
| **תבנית**               | ציר זמן, מקובץ לפי יום, פעלים קריאים לאדם + סמלים | טבלה צפופה עם עימוד, 50/עמוד              |
| **מסננים**              | קטגוריית סוג אירוע                                | פעולה, חומרה, גורם מבצע, טווח תאריכים     |
| **ייצוא**               | לא זמין                                           | ייצוא JSON                                |
| **סינון לפי גורם מבצע** | לא רלוונטי                                        | ניתן לסינון לפי גורם מבצע                 |
| **אירועים מוצגים**      | פעולות ברמה גבוהה בלבד (רשימת היתרים)             | כל אירועי הביקורת                         |

### רשימת ההיתרים לפעולות ברמה גבוהה

מוגדרת ב-`src/lib/audit/highLevelActions.ts`. היא קובעת אילו אירועים יופיעו
בפיד הפעילות. רשימת ההיתרים כוללת:

- אירועי הוספה/הסרה/בדיקה של ספק
- יצירה/עדכון/מחיקה של שילוב
- מחזור החיים של מפתח API (יצירה, ביטול, החלפה)
- הגעה לסף תקציב
- כניסה/יציאה מאימות
- יצירת הפעלת סוכן ענן
- רישום כלי MCP
- יצירה/מחיקה של Webhook
- שינויים במאגר/תוכנית מכסה (פעולות `quota.*`, קבוצה B)
- אירועי פלטפורמה (עדכון, פריסה)
- התקנה/הסרה של מיומנות

אירועים שאינם ברשימה זו מופיעים רק ביומן הביקורת.

### הוספת פעולה חדשה ברמה גבוהה

ערכו את `src/lib/audit/highLevelActions.ts` והוסיפו את מחרוזת הפעולה אל
`HIGH_LEVEL_ACTIONS`. פעולה זו דורשת PR (הרשימה מוגדרת בקוד ואינה ניתנת להגדרה דרך DB).
ניתן להוסיף את הסמל המתאים אל `src/lib/audit/activityIcons.ts`.

## הפניה: `/dashboard/logs/activity`

הנתיב הישן `/dashboard/logs/activity` מופנה לצמיתות (HTTP 308) אל
`/dashboard/activity` באמצעות `permanentRedirect()` בקובץ
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

מזהה סרגל הצד הישן `logs-activity` נשמר ב-`HIDEABLE_SIDEBAR_ITEM_IDS`
(אך הוסר מ-`SIDEBAR_DEFINITIONS`) כדי להימנע משבירת הגדרות משתמש קבועות מראש
שמפנות למזהה הישן.

## i18n

מרחבי שמות שנוספו על ידי קבוצה B:

| מפתח מרחב שמות          | מכסה                                                    |
| ----------------------- | ------------------------------------------------------- |
| `sidebar.costsSection`  | תווית מקטע העלויות                                      |
| `sidebar.activity`      | פריט הפעילות בסרגל הצד                                  |
| `sidebar.logsGroup`     | תווית קבוצת המשנה של היומנים                            |
| `sidebar.systemGroup`   | תווית קבוצת המשנה של המערכת                             |
| `sidebar.costsOverview` | פריט סקירת העלויות                                      |
| `activity.*`            | כל המחרוזות בדף הפעילות (כותרת, פעלים, מסננים, מצב ריק) |

אזורי המקור המוסמכים: `pt-BR` ו-`en`. כל 40 האזורים האחרים חוזרים לאנגלית
באמצעות מנגנון ברירת המחדל של `next-intl` (המוגדר ב-`src/i18n/config.ts`).
