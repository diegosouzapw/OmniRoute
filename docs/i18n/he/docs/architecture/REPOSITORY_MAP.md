## `src/` — אפליקציית Next.js

```
src/
├── app/                 # App Router (דפים + נתיבי API + דפי סטטוס + דף נחיתה)
├── lib/                 # ספריות ליבה / מודולי דומיין (80 תיקיות משנה + כ־70 קבצים ברמה העליונה)
├── domain/              # לוגיקת דומיין טהורה (מנוע מדיניות, מנגנון חלופי, עלות, נעילה, comboResolver, הערכה)
├── server/              # מודולים לצד השרת בלבד (תהליך authz,‏ cors, תווכת אימות) — לא ניתן לייבא בצד הלקוח
├── shared/              # משותף לשרת וללקוח במקומות שבהם הדבר בטוח (קבועים, טיפוסים, אימות, חוזים, כלי עזר)
├── i18n/                # תצורת next-intl + הודעות JSON לכל אזור ושפה (42 אזורים ושפות)
├── middleware/          # תווכת Next.js (העשרת בקשות, זיהוי אזור ושפה)
├── mitm/                # ליבת פרוקסי MITM: יצירה/התקנה של אישורים, מטפלים, יעדים, בודק, מסכות, העברה ישירה
│   ├── handlers/        # 9 מחלקות מטפל לסוכני IDE שמרחיבות את MitmHandlerBase (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # שכבת לכידת תעבורה: מאגר טבעתי (בזיכרון), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # קוד קישור למתאמי מודלים (שכבת תאימות מדור קודם)
├── scripts/             # סקריפטים לתחזוקה בתוך העץ (למשל, backfillAggregation)
├── sse/                 # מטפלים/שירותים מדור קודם של SSE ‏(chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # מאגר בזיכרון מדור קודם (מוצא משימוש בהדרגה לטובת src/lib/db)
├── types/               # קובצי טיפוסים משותפים של TS
├── instrumentation.ts   # נקודת חיבור לטלמטריה של Next.js (דפדפן + edge)
├── instrumentation-node.ts  # תשתית תצפית עבור Node בלבד
└── proxy.ts             # שכבת כניסה ל־HTTP-proxy
```

## `open-sse/` — סביבת עבודה למנוע הזרמה

```
├── handlers/            # 16 קבצים (12 מטפלים + 4 פונקציות עזר): chatCore, responsesHandler, embeddings, audio, image, video, music, rerank, moderations, search וכו׳
├── executors/           # 67 רכיבי הפעלה ייעודיים לספקים (מרחיבים את BaseExecutor)
├── translator/          # ממירי פורמטים (9 לבקשות, 9 לתגובות, 9 פונקציות עזר)
├── transformer/         # Responses API ↔ Chat Completions ‏(TransformStream)
├── services/            # יותר מ־~80 מודולי שירות (combo, accountFallback, autoCombo, reasoningCache, קוד/צ׳אט חשאי של claude, modelDeprecation, taskAwareRouter, workflowFSM וכו׳)
├── mcp-server/          # שרת MCP ‏(110 כלים, 3 תעבורות, 33 תחומים)
├── config/              # מאגרי ספקים/מודלים, תצורת כותרות, כינויים למודלים
├── utils/               # לקוח TLS, אחזור/מנתב פרוקסי, כלי עזר לרשת
├── index.ts             # נקודת הכניסה של סביבת העבודה
├── package.json         # מניפסט סביבת העבודה
├── tsconfig.json        # תצורת TS של סביבת העבודה
└── types.d.ts           # הצהרות הטיפוסים של סביבת העבודה
```
