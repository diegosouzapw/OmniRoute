## שלב 1: התקנת OmniRoute

בחרו את השיטה המועדפת עליכם:

### אפשרות א׳: npm (מומלץ)

```bash
npm install -g omniroute
```

### אפשרות ב׳: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` היא גרסת ה-SemVer היציבה **שפורסמה** והגבוהה ביותר. היא **אינה** עוקבת אחר `main` של git. עבור GitOps, קבעו גרסה באמצעות `diegosouzapw/omniroute:X.Y.Z`. ראו [תגיות Image / ערוצי הפצה](../guides/DOCKER_GUIDE.md#release-channels).

### אפשרות ג׳: מקוד המקור

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## שלב 2: הפעלת OmniRoute

```bash
omniroute
```

OmniRoute מופעל בכתובת `http://localhost:20128`. לוח הבקרה נפתח באופן אוטומטי.

---

## שלב 3: חיבור ספק חינמי

אפשר להשתמש ב-OmniRoute **מבלי לשלם דבר** באמצעות חיבור ספק חינמי.

### אפשרות א׳: Kiro (גישה חינמית ל-Claude — ללא כרטיס אשראי)

1. פתחו את לוח הבקרה בכתובת `http://localhost:20128`
2. עברו אל **ספקים** → **הוספת ספק**
3. בחרו **Kiro AI**
4. לחצו על **התחברות** (אין צורך במפתח API!)
5. זה הכול! כעת יש לכם גישה חינמית למודלים של Claude.

### אפשרות ב׳: OpenCode Free (ללא אימות)

1. פתחו את לוח הבקרה בכתובת `http://localhost:20128`
2. עברו אל **ספקים** → **הוספת ספק**
3. בחרו **OpenCode Free**
4. לחצו על **התחברות** (אין צורך במפתח API!)
5. זה הכול! כעת יש לכם גישה חינמית למספר מודלים.

### אפשרות ג׳: Pollinations (ללא צורך במפתח)

1. פתחו את לוח הבקרה בכתובת `http://localhost:20128`
2. עברו אל **ספקים** → **הוספת ספק**
3. בחרו **Pollinations**
4. לחצו על **התחברות** (אין צורך במפתח API!)
5. זה הכול! כעת יש לכם גישה חינמית ל-GPT-5, ל-Claude, ל-Gemini ולמודלים נוספים.

## שלב 4: וידוא שהמערכת פועלת

במסך [מפתחות API](http://localhost:20128/dashboard/api-manager), צרו מפתח חדש. שמרו את המפתח, משום שהוא לא יוצג שוב. שימו לב שמפתח זה מיועד לאפשר לכלים לגשת ל-OmniRoute, ולא לגשת לספקים במעלה הזרם.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

אתם אמורים לראות רשימה של המודלים המחוברים שלכם.

## שלב 5: הגדרת סביבת הפיתוח או כלי שורת הפקודה לשימוש ב-OmniRoute

בסביבת הפיתוח או בכלי שורת הפקודה שלכם, הגדירו:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

זה הכול! סביבת הפיתוח שלכם משתמשת כעת ב-OmniRoute עם בחירת ספק אוטומטית.

### דוגמה לסביבת פיתוח: VSCode/Continue.dev

1. ב-VSCode, התקינו את ההרחבה [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. עדכנו את `~/.continue/config.yaml` והוסיפו את השורות הבאות:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. בחלונית הצ׳אט של Continue.dev, בחרו `OmniRoute - Auto` וכך תוכלו לשלוח בקשות אל OmniRoute.
4. (אופציונלי) תרגיל לקוראים — בקשו מסביבת הפיתוח שלכם לעדכן את `config.yaml` עם כל שאר התצורות המוכנות מראש 😊

### דוגמה לכלי שורת פקודה: Codex CLI

1. הגדירו במערכת ההפעלה שלכם את משתנה הסביבה באופן קבוע.
   ב-macOS/Linux (הוסיפו אל `~/.bashrc` או `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

ב-Windows (שורת הפקודה):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. כעת נפעיל את Codex כשהוא מוגדר לשימוש ב-OmniRoute. הריצו:

```
omniroute launch-codex --model auto
```

אפשר לעשות זאת ידנית באמצעות `codex` ופרמטרים בשורת הפקודה לציון נקודת הקצה ומפתח ה-API, אך באמצעות הפקודה שלעיל, OmniRoute מטפל עבורכם בהכול.

אותה הפעלה בפקודה אחת פועלת גם עבור כלי CLI אחרים באמצעות המפעיל הכללי — `omniroute run <target>` תומך ב-`claude`, ב-`codex`, ב-`aider`, ב-`goose`, ב-`opencode`, ב-`qwen` וב-`gemini` (ראו [שילובי CLI](../guides/CLI-INTEGRATIONS.md)).

3. כלי ה-CLI אמור כעת לשלוח בקשות אל OmniRoute.

### ודאו שהכלי שלכם מנתב אל OmniRoute

תוכלו לראות את פרטי הבקשה באמצעות לחיצה על [ניטור/יומנים](http://localhost:20128/dashboard/logs) בסרגל הצד השמאלי. לחיצה פנימה תציג פרטים נוספים. כהערת אגב, תוכלו לראות איזה מידע נשלח מסביבת ההרצה המועדפת עליכם. הדבר שימושי לצורכי למידה וניפוי שגיאות.

## שאלות נפוצות

### "האם אני זקוק למפתח API?"

**לא!** אפשר להשתמש בספקים חינמיים (Kiro, OpenCode Free, Pollinations) ללא מפתח API. פשוט חברו אותם בלוח הבקרה.

### "מהו `auto`?"

`auto` מורה ל-OmniRoute לבחור אוטומטית את הספק הטוב ביותר עבור כל בקשה. הוא מביא בחשבון מהירות, עלות, איכות וזמינות. לפרטים, ראו את [מדריך Auto-Combo](./AUTO-COMBO-GUIDE.md).

### "כמה זה עולה?"

OmniRoute עצמו הוא **חינמי ובקוד פתוח**. אתם משלמים רק עבור הספקים שבהם אתם משתמשים. ספקים רבים מציעים מסלולים חינמיים — ראו את [מדריך המסלולים החינמיים](./FREE-TIERS-GUIDE.md).

### "האם אפשר להשתמש בו עם Claude Code / Cursor / Copilot?"

**כן!** OmniRoute פועל עם כל כלי שתומך בפורמט של OpenAI. פשוט הגדירו את כתובת הבסיס כ-`http://localhost:20128/v1`. להוראות הגדרה ספציפיות, ראו את [המדריך לכלי CLI](../reference/CLI-TOOLS.md).

### "מה קורה אם ספק מפסיק לפעול?"

OmniRoute מדלג אוטומטית על ספקים שנכשלו ומנסה את הספק הבא. אינכם צריכים לעשות דבר. לפרטים, ראו את [מדריך Auto-Combo](./AUTO-COMBO-GUIDE.md).
