## מהו ספק?

חשבו על ספק כמו על **מפעיל סלולרי**. בדיוק כפי שנדרש מפעיל סלולרי כדי לבצע שיחות, נדרש ספק AI כדי להשתמש במודלי AI. OmniRoute דומה לטלפון שעובד עם **כל המפעילים** — ניתן לעבור ביניהם באופן אוטומטי.

### סוגי ספקים

| סוג                       | מהו                         | דוגמאות                           | עלות                   |
| ------------------------- | --------------------------- | --------------------------------- | ---------------------- |
| **חינמי**                 | לא נדרש תשלום               | Kiro, OpenCode Free, Pollinations | $0                     |
| **מפתח API**              | נדרש מפתח API               | OpenAI, Anthropic, Google         | תשלום לפי שימוש        |
| **OAuth**                 | התחברות באמצעות החשבון שלכם | Claude Code, GitHub Copilot       | מינוי                  |
| **קובץ Cookie מהאינטרנט** | משתמש בהפעלת הדפדפן שלכם    | ChatGPT Web (Codex), Gemini Web   | $0 (משתמש בחשבון שלכם) |

### ספקים המשתמשים בקובצי Cookie מהאינטרנט

עיינו ב-**[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** לקבלת הוראות הגדרה כלליות, מגבלות, פתרון בעיות והנחיות אימות ספציפיות לספקים.

## התחלה מהירה: חיבור הספק הראשון שלכם

### הגדרה אופציונלית של ספקים חינמיים בהפעלה הראשונה

אשף ההפעלה הראשונה מציע כרטיס מפורש בשם **הגדרת ספקים חינמיים**. הוא מפיק את רשימת
הספקים הזכאים הנוכחית ממרשם הספקים שאינם דורשים אימות של OmniRoute, ולאחר מכן מאפשר לכם לעבור על כל
ספק ולבטל את בחירתו לפני האישור. OmniRoute מציג את הודעת האזהרה של הספק וקישור לאתר שלו,
כדי שתוכלו לעיין תחילה בתנאי הצד השלישי, במדיניות הפרטיות, בזמינות ובמגבלות הקצב.

פעולה זו היא אופציונלית: השלמת האשף לעולם אינה יוצרת חיבורים לספקים חינמיים ללא ידיעתכם.
היא יוצרת רק ספקים שעדיין חסרים, אינה משנה חיבורים קיימים שהותאמו אישית,
ומדווחת בנפרד על ספקים שנוצרו, שכבר הוגדרו ושנכשלו. לאחר תוצאה חלקית, ניתן
לנסות שוב בבטחה רק את הספקים שנכשלו.

### אפשרות א': ספק חינמי (ללא כרטיס אשראי)

1. פתחו את לוח הבקרה בכתובת `http://localhost:20128`
2. עברו אל **ספקים** → **הוספת ספק**
3. בחרו אחד מהספקים החינמיים הבאים:
   - **Kiro AI** — מודלי Claude בחינם (לא נדרש אימות)
   - **OpenCode Free** — מודלי GPT בחינם (לא נדרש אימות)
   - **Pollinations** — GPT-5, Claude, Gemini בחינם (לא נדרש מפתח)
   - **LongCat** — 10 מיליון טוקנים בחינם (הקצאה חד-פעמית, נדרשים חשבון + KYC)
   - **Cloudflare AI** — יותר מ-50 מודלים, 10,000 נוירונים ביום
   - **MLX Gemma 26B** — מודל מקומי עבור Apple Silicon (כ-38.5 טוקנים לשנייה, כ-15.9GB RAM)
   - **MLX Qwen 3.8 27B** — מודל מקומי עבור Apple Silicon (כ-9.1 טוקנים לשנייה, כ-13.1GB RAM)
4. לחצו על **התחברות**
5. זה הכול! כעת יש לכם גישה חינמית ל-AI.

### אפשרות ב': ספק עם מפתח API (בתשלום)

1. השיגו מפתח API מאתר הספק:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. פתחו את לוח הבקרה בכתובת `http://localhost:20128`
3. עברו אל **ספקים** → **הוספת ספק**
4. בחרו את הספק שלכם
5. הדביקו את מפתח ה-API שלכם
6. לחצו על **התחברות**
7. זה הכול! כעת יש לכם גישה למודלים של ספק זה.

### אפשרות ג': ספק OAuth (מינוי)

1. פתחו את לוח הבקרה בכתובת `http://localhost:20128`
2. עברו אל **ספקים** → **הוספת ספק**
3. בחרו את הספק שלכם (לדוגמה, Claude Code, GitHub Copilot)
4. לחצו על **התחברות באמצעות OAuth**
5. התחברו באמצעות החשבון שלכם
6. זה הכול! כעת יש לכם גישה למודלים הכלולים במינוי שלכם.

### אפשרות ד': מודלי MLX מקומיים (Apple Silicon)

עבור מחשבי Mac עם Apple Silicon וזיכרון מאוחד, OmniRoute תומך בחיבור למודלי MLX מקומיים שפועלים באמצעות `mlx-lm.server` כספקים מקומיים רגילים התואמים ל-OpenAI.

#### דרישות מוקדמות

- **Mac עם Apple Silicon** (M1/M2/M3/M4) ומומלץ זיכרון מאוחד של 24GB ומעלה
- מנהל החבילות **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### התחלה מהירה

1. **התקינו את יחסי התלות**:

   ```bash
   # התקינו את uv אם הוא עדיין אינו מותקן
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # התקינו את mlx-lm
   uv pip install mlx-lm
   ```

2. **הפעילו את שרתי MLX באופן ידני** (במסופים נפרדים):

   ```bash
   # מסוף 1: Gemma 4 26B A4B IT-QAT (יציאה 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # מסוף 2: Qwen 3.8 27B MLX Mixed (יציאה 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **התחברו בלוח הבקרה של OmniRoute**:
   - עברו אל **ספקים** → **הוספת ספק**
   - בחרו **MLX Gemma 26B** או **MLX Qwen 3.8 27B**
   - לחצו על **התחברות** (לא נדרש מפתח API)

4. **השתמשו עם OpenCode**:
   ```bash
   # הגדירו את OpenCode לשימוש ב-OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # השתמשו במודלי MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### ניהול זיכרון

**חשוב**: עם זיכרון מאוחד של 24GB, ניתן להפעיל **רק מודל MLX גדול אחד בכל פעם**.

- Gemma 26B: שימוש שיא של כ-15.9GB בזיכרון
- Qwen 3.8 27B: שימוש שיא של כ-13.1GB בזיכרון

עליכם לנהל זאת באופן ידני:

- הפעילו רק שרת MLX אחד בכל פעם, או
- הפעילו את שניהם במחשבים נפרדים, או
- עצרו אחד לפני הפעלת האחר

OmniRoute אינו מנהל אוטומטית את תהליכי שרתי MLX — הוא רק מנתב בקשות לנקודות הקצה התואמות ל-OpenAI שאתם מגדירים.

#### תמיכה בקריאה לכלים

שני המודלים תומכים בקריאה לכלים התואמת ל-OpenAI. בדקו באמצעות:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### פתרון בעיות

| בעיה              | פתרון                                                                     |
| ----------------- | ------------------------------------------------------------------------- |
| השרת לא מופעל     | בדקו את `uv run mlx_lm.server --help` ואמתו את מזהי המודלים               |
| אין מספיק זיכרון  | ודאו שרק מודל אחד פועל; סגרו יישומים אחרים; בדקו את Activity Monitor      |
| החיבור נדחה       | ודאו שהשרת פועל ביציאה הנכונה (11435/11436)                               |
| תגובות איטיות     | הבקשה הראשונה טוענת את המודל לזיכרון (כ־30–60 שניות); הבקשות הבאות מהירות |
| קריאה לכלים נכשלת | ודאו שהמודל תומך בכלים; בדקו אם קיימות שגיאות תרגום ביומני OmniRoute      |

## כיצד לחבר ספק (שלב אחר שלב)

### שלב 1: פתחו את לוח הבקרה

עברו אל `http://localhost:20128` בדפדפן.

### שלב 2: עברו אל ספקים

לחצו על **ספקים** בסרגל הצד.

### שלב 3: לחצו על הוספת ספק

לחצו על הלחצן **+ הוספת ספק**.

### שלב 4: בחרו את הספק שלכם

עיינו ברשימה או חפשו את הספק שלכם. לחצו עליו.

### שלב 5: הזינו פרטי גישה

- **ספקים חינמיים**: אין צורך בפרטי גישה — פשוט לחצו על **התחברות**
- **ספקים עם מפתח API**: הדביקו את מפתח ה-API שלכם
- **ספקי OAuth**: לחצו על **התחברות באמצעות OAuth** והיכנסו לחשבון

### שלב 6: בדקו את החיבור

לחצו על **בדיקת חיבור** כדי לוודא שהוא פועל.

### שלב 7: סיימתם!

הספק שלכם מחובר כעת. תוכלו להשתמש בו באמצעות `model: "auto"` או לציין את הספק ישירות.

## שימוש במספר ספקים

OmniRoute פועל באופן מיטבי עם **מספר ספקים**. כך תקבלו:

- **מעבר אוטומטי לספק חלופי** — אם ספק אחד נכשל, OmniRoute מנסה את הבא
- **אופטימיזציית עלויות** — OmniRoute בוחר את הספק הזול ביותר לכל בקשה
- **אופטימיזציית מהירות** — OmniRoute בוחר את הספק המהיר ביותר לכל בקשה
- **אופטימיזציית איכות** — OmniRoute בוחר את הספק הטוב ביותר לכל משימה

### הגדרה מומלצת

חברו לפחות **3 ספקים** לקבלת החוויה הטובה ביותר:

1. **ספק חינמי אחד** (Kiro, OpenCode Free או Pollinations) — זמין תמיד
2. **ספק מהיר אחד** (Groq, Cerebras) — לקבלת תשובות מהירות
3. **ספק איכותי אחד** (OpenAI, Anthropic, Google) — למשימות מורכבות

לאחר מכן השתמשו ב-`model: "auto"`, ו-OmniRoute יבחר אוטומטית את הספק הטוב ביותר לכל בקשה.

## שאלות נפוצות

### "האם צריך לשלם כדי להשתמש ב-OmniRoute?"

**לא!** OmniRoute הוא חינמי ובקוד פתוח. אפשר להשתמש בספקים חינמיים (Kiro, OpenCode Free, Pollinations) בלי לשלם דבר. משלמים רק אם בוחרים להשתמש בספקים בתשלום.

### "עם איזה ספק כדאי להתחיל?"

התחילו עם **Kiro AI** — הוא חינמי, אינו דורש מפתח API ומעניק גישה למודלים של Claude. לאחר מכן, הוסיפו ספקים נוספים לפי הצורך.

### "האם אפשר להשתמש במספר ספקים בו-זמנית?"

**כן!** זו כל המטרה של OmniRoute. חברו מספר ספקים והשתמשו ב-`model: "auto"` כדי לאפשר ל-OmniRoute לבחור את הספק הטוב ביותר לכל בקשה.

### "מה קורה אם ספק מפסיק לפעול?"

OmniRoute מדלג אוטומטית על ספקים שנכשלו ומנסה את הספק הבא. אין צורך לעשות דבר.

### "איך מנתקים ספק?"

עברו אל ספקים → לחצו על הספק → לחצו על **ניתוק**.

### "האם אפשר להשתמש במפתחות ה-API הקיימים שלי?"

**כן!** אם כבר יש לכם מפתחות API עבור OpenAI, Anthropic, Google וכו', תוכלו להשתמש בהם ב-OmniRoute. פשוט הדביקו אותם בעת חיבור הספק.
