## 1. מקור האמת של השירות (תיעוד רשמי, נבדק בהצלבה)

- כתובת URL בסיסית: `https://api.anysearch.com`‏ (REST) + ‏`POST /mcp`‏ (MCP, JSON-RPC 2.0).
- `POST /v1/search` - פרמטרים: `query` (חובה), `max_results`‏ (1-10, ברירת מחדל 10), `tag`‏ (ניתוב אנכי מסוג `{domain}.{sub_domain}`),‏ `zone`‏ (cn/intl),‏ `language`,‏ `params` (שדות אנכיים מובְנים),‏ `format`‏ (json/markdown).
- `GET /v1/sub-domains?domain=...` - קטלוג יכולות, אינו נחשב במכסה.
- `POST /v1/extract` - אחזור/חילוץ של `{url, title, content}`; גוף JSON קפדני, מגבלה של 16 KiB.
- `POST /v1/auth/email/register` - רישום בקריאה יחידה, מחזיר מפתח חד-פעמי בטקסט גלוי מסוג `as_sk_...`.
- אימות: `Authorization: Bearer <as_sk_...>` אופציונלי; גישה אנונימית יורדת למגבלות לפי כתובת IP וצורכת את המכסה היומית החינמית; מפתח לא תקין מחזיר 401/403 ללא מעבר שקט לגישה אנונימית.
- מסלול חינמי: 1000 בקשות ביום, 20 QPS לכל מפתח. מסלול בתשלום: טרם תומחר (בקרוב).
- מעטפת תגובה: הצלחה `{code: 0, message: "success", request_id, data}`; כשל `{code: -1, message}`. שגיאות אימות/מכסה אינן כוללות `error_code` מובנה (טקסט ההודעה הוא האות); שגיאות ייעודיות לחילוץ כן כוללות `error_code`‏ (`invalid_extract_url`,‏ `extract_failed`). אין כותרת `Retry-After` בתגובת 429.

## 3. החלטות (כולן התקבלו ב-2026-08-26)

1. **מדיניות ניתוב: `fallbackOnly`.** נימוק: ספק חינמי בעל עלות 0 לעולם לא צריך להשתלט על ניתוב אוטומטי לפי עלות; בחירה מפורשת וחזרה בעת כשל אינן מושפעות. תקדים: רשומת xquik שמוזגה.
2. **תחום: webSearch + webFetch באמצעות `POST /v1/extract` ב-v1.** תואם למודל המחשבתי הדו-יכולותי של tavily/exa. ממשקים אנכיים (`tag`, `sub-domains`, `batch_search`) נותרים מחוץ לתחום — כיום אין IR לפרמטרים אנכיים.
3. **הצגת מכסה: `freeMonthlyQuota: 0`** (תצוגה שמרנית בסגנון xquik). ההקצאה בפועל (1000 בקשות ליום, איפוס יומי) מופיעה במקום זאת בטקסט `authHint` שבקטלוג ממשק המשתמש. נימוק: הצגת המכסה חייבת להתאים לסמנטיקת האיפוס; המרת מגבלה יומית לשווי חודשי (30000) היא הבטחת שווא שממשק המשתמש אינו יכול לקיים.
4. **searchTypes: `["web"]` בלבד.** אין ראיות פומביות לקיומו של ממשק אנכי לחדשות/תמונות ב-AnySearch API; שערים שמשלבים ממשקי API ללא ממשק אנכי מתועד (למשל Google Custom Search) חושפים את האינטרנט בלבד, במקום למפות בשקט חדשות -> אינטרנט.
5. **מדיניות מפתח:** עבודה ללא מפתח נתמכת; מפתח לא תקין מחזיר 401/403 ולעולם אינו משונמך בשקט לגישה אנונימית (בהתאם לחוזה של השירות במעלה הזרם).
6. **החרגות מכוונות:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (יירוט צ'אט נשאר עם firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (נקודות קצה מרוחקות אנונימיות חולקות מאגר יחיד המוגבל לפי IP עבור כל כתובת IP ליציאה, ולכן חילוץ ללא מפתח הוא בהצטרפות מפורשת ולא מועמד לניתוב אוטומטי); `QUOTA_STATUS_PROVIDERS` (AnySearch מסמן חריגה מהמכסה באמצעות 429/מעטפת, ולא באמצעות סטטוס 402/403).
