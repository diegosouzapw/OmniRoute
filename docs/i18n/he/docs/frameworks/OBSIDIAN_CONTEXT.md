## מה זה

OmniRoute מתחבר לכספת **Obsidian** בתור **מקור הקשר** — בסיס ידע מקומי בפורמט Markdown
שסוכנים קוראים וכותבים באמצעות שרת ה-MCP המובנה. האינטגרציה מתקשרת עם תוסף הקהילה
**Obsidian Local REST API** שפועל בתוך יישום שולחן העבודה, כך שסוכנים יכולים לחפש
הערות, לקרוא/לכתוב/לעדכן קבצים, להציג את תוכן הכספת, לעבוד עם הערות מחזוריות יומיות
ושבועיות, לנהל תגיות, להריץ פקודות Obsidian, וכן (באופן אופציונלי) לתאם סנכרון כספת
דו-כיווני בין שולחן העבודה למכשיר נייד.

הלקוח (`src/lib/obsidian/api.ts`) עוטף את Local REST API עם:

- **ניסיון חוזר עם השהיה הולכת וגדלה** עבור שגיאות `5xx` זמניות, ו**פסק זמן של 30 שניות** באמצעות `AbortController`.
- **סיווג שגיאות מטיפוס מוגדר** — `ObsidianAuthError`‏ (401/403),
  `ObsidianNotFoundError`‏ (404), `ObsidianServerError`‏ (5xx), `ObsidianTimeoutError`.
- **רמז ידידותי מסוג "לא ניתן להגיע אל Obsidian"** שמדגיש את טעות היציאה הנפוצה
  (HTTP ב-`27123`, **ולא** נקודת הקצה של MCP ב-`27124`) ואת התצורה עבור Tailscale.
- **קידוד נתיבים** יחסיים לכספת, כך שנתיבי הערות הכוללים רווחים ולוכסנים יהיו בטוחים.

## הגדרה

אין **משתנה סביבה** עבור הטוקן או כתובת ה-URL הבסיסית של Obsidian — שניהם נשמרים
בטבלת SQLite בשם `key_value` (מרחב השמות `obsidian`) באמצעות
`src/lib/db/obsidian.ts`. הטוקן **מוצפן במנוחה** (AES-256-GCM, עם אפשרות חלופית של
טקסט גלוי לצורך תאימות לאחור). ניתן להגדיר דרך הלשונית **מקורות הקשר** בלוח הבקרה
של נקודת הקצה (`ObsidianSourceCard`), או באמצעות REST API של ההגדרות.

> [!IMPORTANT]
> התוסף **Obsidian Local REST API** חייב להיות מותקן ופועל. ממשק ה-REST שלו
> מאזין ב-**HTTP `127.0.0.1:27123`** (כתובת ה-URL הבסיסית המוגדרת כברירת מחדל). היציאה `27124`
> היא נקודת קצה _נפרדת_ של MCP/HTTPS, ונתיב ההגדרות דוחה אותה במפורש.
> בעת התחברות ממכשיר אחר, יש להשתמש ב-`http://<tailscale-ip>:27123`.

### מפתחות תצורה (SQLite `key_value`, מרחב השמות `obsidian`)

| מפתח              | מטרה                                                           | מוצפן |
| ----------------- | -------------------------------------------------------------- | ----- |
| `api_key`         | טוקן Bearer של Local REST API                                  | כן    |
| `base_url`        | כתובת URL בסיסית של REST (ברירת מחדל `http://127.0.0.1:27123`) | לא    |
| `vault_path`      | נתיב מוחלט לתיקיית הכספת (לצורך סנכרון)                        | לא    |
| `webdav_username` | שם משתמש WebDAV שנוצר אוטומטית (סנכרון כספת)                   | לא    |
| `webdav_password` | סיסמת WebDAV שנוצרה אוטומטית (סנכרון כספת)                     | כן    |
| `webdav_enabled`  | האם סנכרון הכספת באמצעות WebDAV מופעל                          | לא    |

### הגדרה באמצעות REST

```bash
# שמירה ואימות של טוקן Local REST API‏ (POST מאמת באמצעות בדיקת סטטוס)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# בדיקת סטטוס החיבור (מחזירה connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# ניתוק (מוחק את הטוקן השמור)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

כל המתודות דורשות אימות בלוח הבקרה. `POST` דוחה כל כתובת URL ביציאה `27124`
ומאמת את הטוקן באמצעות קריאה לנקודת הקצה של הסטטוס ב-Local REST API לפני השמירה.

### סנכרון כספת באמצעות WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` מנהל סנכרון כספת אופציונלי המבוסס על
WebDAV (ומופעל באמצעות `src/lib/obsidianSync.ts`). הפעלתו מפנה את OmniRoute אל
תיקיית כספת מקומית ויוצרת צמד אקראי של שם משתמש וסיסמה עבור WebDAV:

```bash
# הפעלת סנכרון WebDAV עבור תיקיית כספת (יוצרת שם משתמש וסיסמה)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# קבלת סטטוס הסנכרון של WebDAV (פרטי ההתחברות מוחזרים רק כשהוא מופעל)
curl http://localhost:20128/api/settings/obsidian/webdav

# השבתת סנכרון WebDAV (מוחקת את פרטי ההתחברות ואת קובץ ה-.stignore המנוהל)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### מקור הקשר לפי מפתח API (אופציונלי)

ניתן לתחום את תצורת Obsidian **לכל מפתח API בנפרד** באמצעות הטבלה
`api_key_context_sources`‏ (`src/lib/db/apiKeyContextSources.ts`). כאשר קריאת MCP
כוללת מזהה של מפתח API מאומת, `getObsidianConfigForApiKey()` מעדיפה את
הטוקן/כתובת ה-URL הבסיסית/נתיב הכספת של אותו מפתח (`source: "api_key"`), ובמקרה
שאין כאלה חוזרת לתצורה הגלובלית (`source: "global"`).

## כלי MCP ‏(22)

מוגדרים ב-`open-sse/mcp-server/tools/obsidianTools.ts`. הטוקן/כתובת ה-URL הבסיסית נפתרים
בכל קריאה (תחילה לפי מפתח API, ולאחר מכן באופן גלובלי). כלים שניגשים אל **שרת הסנכרון**
של OmniRoute (ארבעת כלי `obsidian_sync_*`) דורשים בנוסף את טוקן האימות לסנכרון שהוגדר
בהגדרות OmniRoute.

### כלי קריאה (`read:obsidian`)

| כלי                          | תיאור                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------- |
| `obsidian_check_status`      | בדיקה אם ה-Local REST API נגיש ומאומת.                                          |
| `obsidian_search_simple`     | חיפוש טקסט מלא בתוכן ההערות; מחזיר קטעים עם נתיבי קבצים.                        |
| `obsidian_search_structured` | חיפוש באמצעות ביטוי JSON Logic (מסנני and/or/regex/path).                       |
| `obsidian_read_note`         | קריאת הערה לפי נתיב יחסי לכספת; אופציונלית כותרת, בלוק או frontmatter מסוימים.  |
| `obsidian_list_vault`        | הצגת רשימת הקבצים והתיקיות בכספת (עץ רשומות).                                   |
| `obsidian_get_document_map`  | קבלת מבנה הכותרות של ההערה כמפה של כותרות ← מספרי שורות.                        |
| `obsidian_get_note_metadata` | קבלת frontmatter, תגיות, קישורים וספירת תווים/מילים ללא התוכן המלא.             |
| `obsidian_get_active_file`   | קבלת הנתיב והתוכן של הקובץ הפעיל כעת ב-Obsidian.                                |
| `obsidian_get_periodic_note` | קבלת ההערה התקופתית היומית/שבועית/חודשית עבור תאריך (היום, אם לא צוין).         |
| `obsidian_get_tags`          | הצגת כל תגיות הכספת ותדירויותיהן.                                               |
| `obsidian_list_commands`     | הצגת מזהי הפקודות הזמינות ב-Obsidian (לשימוש עם `obsidian_execute_command`).    |
| `obsidian_sync_status`       | מצב שרת הסנכרון של OmniRoute: פעיל, שם הכספת, פורט, זמן פעילות והסנכרון האחרון. |
| `obsidian_sync_conflicts`    | הצגת התנגשויות סנכרון שלא נפתרו (נתיב, נתיב ההתנגשות וזמן הזיהוי).              |

### כלי כתיבה (`write:obsidian`)

| כלי                              | תיאור                                                                                    |
| -------------------------------- | ---------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | יצירה או דריסה של הערה עם תוכן Markdown נתון.                                            |
| `obsidian_append_note`           | הוספת תוכן לסוף הערה; אופציונלית לכותרת או לבלוק מסוימים.                                |
| `obsidian_patch_note`            | הוספה ממוקדת לסוף/להתחלה או החלפה בכותרת, בבלוק או בשדה frontmatter.                     |
| `obsidian_delete_note`           | מחיקה לצמיתות של הערה מהכספת.                                                            |
| `obsidian_move_note`             | העברה או שינוי שם של הערה בתוך הכספת.                                                    |
| `obsidian_execute_command`       | ביצוע פקודת Obsidian לפי מזהה הפקודה שלה.                                                |
| `obsidian_open_file`             | פתיחת קובץ ב-Obsidian (יוצר אותו אם אינו קיים).                                          |
| `obsidian_sync_trigger`          | הפעלת סנכרון דו-כיווני מיידי של הכספת בין שולחן העבודה↔המכשיר הנייד.                     |
| `obsidian_sync_resolve_conflict` | פתרון התנגשות סנכרון: שמירת `local` (מכשיר נייד), `remote` (שולחן עבודה) או `keep-both`. |

> [!NOTE]
> יעדי `obsidian_patch_note` מקבלים `targetType` מסוג `heading | block | frontmatter`
> ו-`operation` מסוג `append | prepend | replace`, עם
> `createTargetIfMissing` אופציונלי. ארבעת כלי `obsidian_sync_*` מתקשרים עם שרת הסנכרון
> המקומי (`http://127.0.0.1:27781` כברירת מחדל) ודורשים את טוקן הסנכרון.

### היקפים

כלי קריאה דורשים `read:obsidian`; כלי כתיבה דורשים `write:obsidian`. האכיפה
זהה לזו של Notion — מטופלת על ידי `withScopeEnforcement()` בתוך
`open-sse/mcp-server/server.ts`, מותנית בכך ש-`OMNIROUTE_MCP_ENFORCE_SCOPES=true`, כאשר
ההיקפים המותרים נלקחים מ-`OMNIROUTE_MCP_SCOPES` או מהקשר ההיקפים של מפתח ה-API. ראו
[MCP-SERVER.md](./MCP-SERVER.md).

## נקודות קצה

| שיטה     | נתיב                            | מטרה                                                 |
| -------- | ------------------------------- | ---------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | החזרת `{ connected, hasToken, baseUrl, vaultPath }`. |
| `POST`   | `/api/settings/obsidian`        | שמירת האסימון ואימותו (דוחה את הפורט `27124`).       |
| `DELETE` | `/api/settings/obsidian`        | ניתוק (מחיקת האסימון השמור).                         |
| `GET`    | `/api/settings/obsidian/webdav` | סטטוס סנכרון WebDAV ופרטי גישה (כאשר הוא מופעל).     |
| `POST`   | `/api/settings/obsidian/webdav` | הפעלת סנכרון WebDAV עבור ספריית כספת.                |
| `DELETE` | `/api/settings/obsidian/webdav` | השבתת סנכרון WebDAV.                                 |

> אלה נתיבי ההגדרות של לוח הבקרה. הגישה לכספת עצמה מתבצעת דרך ה-Local REST API של Obsidian
> (ה-`base_url` שהוגדר) ודרך כלי ה-MCP שלעיל — אין נקודת קצה ציבורית של שרת מתווך
> עבור Obsidian בנתיב `/v1`.

## מקרי שימוש

- **תשובות המבוססות על הכספת** — `obsidian_search_simple` / `obsidian_search_structured`
  ולאחר מכן `obsidian_read_note`, כדי שסוכן ישיב מתוך ההערות האמיתיות שלכם.
- **יצירת הערות / ניהול יומן** — `obsidian_write_note`, `obsidian_append_note`, או
  `obsidian_patch_note` הממוקד כדי לתעד בכספת פלט של סוכן, סיכומים או הערות יומיות
  (`obsidian_get_periodic_note`).
- **ניווט בכספת** — `obsidian_list_vault`, `obsidian_get_document_map` ו-
  `obsidian_get_tags` כדי לבחון את המבנה לפני קריאה/כתיבה.
- **אוטומציה של Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` כדי
  להפעיל תוספים/פקודות באמצעות סוכן; `obsidian_open_file` כדי להציג הערה בממשק המשתמש.
- **סנכרון בנייד** — הפעילו סנכרון WebDAV, ולאחר מכן השתמשו ב-`obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  כדי לתאם בין מחשב שולחני לנייד ולפתור התנגשויות.
