> **מקור האמת:** `src/lib/agentSkills/` (קטלוג, מחולל, מפענחים) + התיקייה `skills/` (קובצי SKILL.md)
> **עדכון אחרון:** 2026-08-02 — v3.8.50

Agent Skills הם קובצי SKILL.md מובנים, המלמדים סוכנים חיצוניים, לקוחות MCP ומתזמרי A2A כיצד להשתמש ב-REST API וב-CLI של OmniRoute. בשונה מ-[Omni Skills](./SKILLS.md) (שהם הגדרות כלי LLM המופעלות בתוך OmniRoute), Agent Skills הם _קטלוג תיעוד_ — Markdown סטטי שניתן להזין ישירות להקשר של סוכן.

---

## סקירה כללית

הקטלוג מכיל **45 מיומנויות סוכן** (23 עבור REST API +‏ 21 עבור CLI +‏ 1 עבור תהליך עבודה של הגדרות). לכל מיומנות יש:

- **מזהה קנוני** (`omni-auth`, `cli-serve` וכו')
- קובץ **SKILL.md** בנתיב `skills/{id}/SKILL.md`, הכולל YAML frontmatter (`name`, `description`) + גוף Markdown עשיר
- **נקודות קצה של REST** (מיומנויות API) או **פקודות משנה של CLI** (מיומנויות CLI), הנגזרות ממפרט OpenAPI וממרשם ה-CLI
- **כתובת URL גולמית של GitHub** לאחזור בזמן אמת: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

```markdown
name: omni-providers

## סקירה כללית

...

## אימות

...

## נקודות קצה

...

<!-- skill:custom-start -->

## מקטע מותאם אישית (נשמר בין יצירות מחדש)
```

המחולל שומר במהלך יצירה מחדש על התוכן שבין `<!-- skill:custom-start -->` לבין `<!-- skill:custom-end -->`. לעשר מיומנויות יש בלוקים מותאמים אישית שנאצרו:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## גילוי REST API

| נקודת קצה                    | שיטה | תיאור                                                            | אימות |
| :--------------------------- | :--- | :--------------------------------------------------------------- | :---- |
| `/api/agent-skills`          | GET  | הצגת הקטלוג (`?category=api\|cli\|config&area=<area>` אופציונלי) | ללא   |
| `/api/agent-skills/{id}`     | GET  | קבלת מטא-נתונים של מיומנות יחידה                                 | ללא   |
| `/api/agent-skills/{id}/raw` | GET  | אחזור SKILL.md בתור `text/markdown`                              | ללא   |
| `/api/agent-skills/coverage` | GET  | סטטיסטיקות כיסוי (כמה קובצי SKILL.md קיימים)                     | ללא   |
| `/api/agent-skills/generate` | POST | הפעלת המחולל (dryRun/prune/onlyIds)                              | ניהול |

דוגמה — הצגת כל מיומנויות ה-API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

דוגמה — אחזור קובץ SKILL.md יחיד:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

```json

    "messages": [{ "role": "user", "content": "List all capabilities" }]
```

## כיצד סוכנים חיצוניים צורכים מיומנויות

### 1. גילוי באמצעות REST

```bash
# קבלת הקטלוג המלא
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# קבלת SKILL.md להזרקת הקשר
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. גילוי באמצעות MCP

```typescript
// בלקוח MCP של Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → מערך של AgentSkill עם rawUrl עבור כל אחד
```

### 3. גילוי באמצעות A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table היא טבלת markdown הכוללת את כל 45 מזהי המיומנויות + עמודות rawUrl
```

### 4. אחזור ישיר של תוכן גולמי מ-GitHub (ללא צורך בשרת)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## מחולל

המחולל קורא את הקטלוג שנאצר + מפרט OpenAPI + מאגר ה-CLI וכותב את `skills/{id}/SKILL.md` עבור כל רשומה:

```bash
# תצוגה מקדימה (הרצה יבשה, ללא כתיבה)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# יצירה מחדש מלאה
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# יצירה מחדש של מזהים מסוימים
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

תגובת המחולל היא `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
