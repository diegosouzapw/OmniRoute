OmniRoute מספק מאגר נבחר של שרתי proxy חינמיים בטבלה `free_proxies`,
המסונכרן מספקים חיצוניים (1proxy, proxifly, iplocate, webshare). לוח הבקרה
מציג אותם תחת **הגדרות → שרתי Proxy חינמיים**. מסמך זה מתאר את הסינון, המיון,
הספירה ודיווח שגיאות הסנכרון בצד השרת שנחשפים על ידי נתיב הרשימה.

## נתיב הרשימה — `GET /api/settings/free-proxies`

מחזיר מקטע מסונן, ממוין ומחולק לעמודים, יחד עם הספירה הכוללת. הסינון
והספירה מתבצעים ב-SQL, כך שממשק המשתמש יכול להציג את הסכום הכולל האמיתי (למשל `סה״כ: 0`)
מבלי לטעון כל שורה לזיכרון.

### פרמטרים של השאילתה

| פרמטר             | סוג                                | ברירת מחדל | משמעות                                                                                                              |
| ----------------- | ---------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------- |
| `search`          | מחרוזת                             | `""`       | `LIKE` תלוי-רישיות בעמודת המארח (וגם המקור).                                                                        |
| `protocol`        | מחרוזת                             | `""`       | מסנן `type`:‏ `http` / `https` / `socks4` / `socks5`. ערך ריק = הכול.                                               |
| `country`         | מחרוזת                             | `""`       | מסנן `countryCode`‏ (ISO-2). ערך ריק = הכול.                                                                        |
| `minQuality`      | מספר                               | `0`        | רק שורות שבהן `qualityScore >= minQuality`.‏ `0` = ללא סף מינימלי.                                                  |
| `disabledSources` | מחרוזת                             | `""`       | מזהי מקורות מופרדים בפסיקים שיש להחריג (למשל `proxifly,webshare`).                                                  |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`  | `quality` = ציון בסדר יורד; `latency` = זמן השהיה בסדר עולה (ערכי null בסוף); `recent` = `lastValidated` בסדר יורד. |
| `offset`          | מספר                               | `0`        | נקודת ההתחלה של החלוקה לעמודים.                                                                                     |
| `limit`           | מספר                               | `50`       | גודל העמוד (מוגבל בצד השרת).                                                                                        |

### תגובה

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` משקף את הסכום הכולל המסונן **לפני** החלוקה לעמודים, כך שממשק המשתמש יכול להציג
`סה״כ: N` ואת `hasMore` באופן בלתי תלוי. `syncErrors` ממופה לפי מזהה מקור
ומאוכלס רק עבור מקורות שהסנכרון האחרון שלהם נכשל — תוצאה של `סה״כ: 0`
לעולם אינה מוצגת ללא הסבר.

## הוספה למאגר — `POST /api/settings/free-proxies/[id]/add-to-pool`

מקדם שרת proxy חינמי אל המאגר המנוהל `proxy_registry`. תחילה מתבצע אימות מול
המקור; בהצלחה מוחזרים מזהה שרת ה-proxy החדש במאגר וזמן ההשהיה שנמדד.

## סנכרון — `POST /api/settings/free-proxies/sync`

מושך מחדש את כל המקורות המופעלים (או את קבוצת המשנה שב-`{ "sources": [...] }`). כל
מקור מסתנכרן באופן עצמאי; כשל במקור נרשם ב-`syncErrors`, והמקורות
האחרים עדיין משלימים את פעולתם, כך שסנכרונים חלקיים לעולם אינם מוחקים נתונים תקינים קודמים.

## סטטיסטיקות — `GET /api/settings/free-proxies/stats`

מחזיר את הסיכום המצטבר `total / inPool / avgQuality / bySource / lastSyncAt`
ללא מטען השורות — משמש את רכיבי הכותרת של לוח הבקרה.
