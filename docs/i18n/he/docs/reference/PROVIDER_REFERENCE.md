מספר הספקים הכולל: **360**. ראו להלן פירוט לפי קטגוריות.

## קטגוריות

- **חינמי** — מסלול חינמי עם מפתח API (מוגדר דרך לוח הבקרה)
- **ללא אימות** — נקודות קצה ציבוריות שאינן דורשות מפתח או התחברות כלל
- **OAuth** — תהליך התחברות שמטופל על ידי OmniRoute, ללא צורך במפתח API
- **קובץ Cookie מהאינטרנט** — עוטף את יישום האינטרנט של הספק באמצעות אימות Cookie
- **מפתח API** — ספק בתשלום שמוגדר באמצעות מפתח API (ייתכן שיוענקו נקודות זכות בחינם)
- **מקומי** — פועל במחשב המשתמש (Ollama, LM Studio, vLLM וכו')
- **חיפוש** — ספקי חיפוש באינטרנט
- **שמע** — ספקי שמע בלבד (TTS/STT)
- **Proxy במעלה הזרם** — ספקים המשמשים כ-Proxy לספקים אחרים
- **סוכן ענן** — סוכני תכנות הפועלים לאורך זמן (Codex Cloud, Devin, Jules)
- **מערכת** — ספקים פנימיים של OmniRoute (לולאה חוזרת וכו')

תגיות נוספות: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`קריאה לכלים` (כאשר מוצג): `native` — API אמיתי לקריאה לפונקציות; `emulated` — המערך `tools` מדומה באמצעות הנחיות דרך `webTools.ts` (בלוקים מסוג `<tool>{...}</tool>` שמנותחים באמצעות ביטויים רגולריים); `none` — הפרמטר `tools` מושמט כעת ללא הודעה. ראו #7286.

השתמשו בלוח הבקרה בכתובת `/dashboard/providers` כדי להפעיל, להגדיר ולבדוק כל ספק.
