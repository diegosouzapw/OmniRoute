## קטגוריות

- **חינמי** — מסלול חינמי עם מפתח API (מוגדר דרך לוח הבקרה)
- **ללא אימות** — נקודות קצה ציבוריות שאינן דורשות מפתח או התחברות כלל
- **OAuth** — תהליך ההתחברות מטופל על ידי OmniRoute, ללא צורך במפתח API
- **קובץ Cookie מהאינטרנט** — עוטף את יישום האינטרנט של הספק באמצעות אימות מבוסס Cookie
- **מפתח API** — ספק בתשלום המוגדר באמצעות מפתח API (ייתכן שיינתנו נקודות זכות בחינם)
- **מקומי** — פועל במחשב המשתמש (Ollama, LM Studio, vLLM וכו׳)
- **חיפוש** — ספקי חיפוש באינטרנט
- **שמע** — ספקי שמע בלבד (TTS/STT)
- **פרוקסי במעלה הזרם** — ספקים המשמשים כפרוקסי לספקים אחרים
- **סוכן ענן** — סוכני תכנות הפועלים לאורך זמן (Codex Cloud, Devin, Jules)
- **מערכת** — ספקים פנימיים של OmniRoute (לולאה חוזרת וכו׳)

תגיות נוספות: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`קריאה לכלים` (כאשר מוצג): `native` — API אמיתי לקריאה לפונקציות; `emulated` — מערך `tools` מדומה באמצעות הנחיה דרך `webTools.ts` (בלוקי `<tool>{...}</tool>` מנותחים באמצעות ביטוי רגולרי); `none` — `tools` מושמט כעת ללא הודעה. ראו #7286.

השתמשו בלוח הבקרה שבכתובת `/dashboard/providers` כדי להפעיל, להגדיר ולבדוק כל ספק.
