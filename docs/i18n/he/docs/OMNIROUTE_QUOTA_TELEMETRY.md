OmniRoute מפריד בין טלמטריית מכסות של ספקים לבין החשבונאות של Ghostlight.

## מצבים מהימנים

- `healthy` פירושו שמקור דיווח על קיבולת זמינה שנותרה.
- `approaching_limit` פירושו שמקור דיווח על קיבולת שנותרה ברמה השווה לסף שהוגדר או נמוכה ממנו.
- `exhausted` מופק רק כאשר מקור מדווח על קיבולת אפס או על שימוש שהגיע למגבלה.
- `unavailable` פירושו שמקור נתמך לא הצליח להחזיר נתונים.
- `unknown` פירושו שלא קיים מקור נתמך או שלא ידועה מגבלת ספק.

מצב לא ידוע אינו מצב של מיצוי ואינו משבית ספק.

המקורות מקבלים עדיפות בסדר הבא: API רשמי של הספק, API מאומת של נתוני שימוש, כותרות תגובה שמופו במפורש, תצורת מנהל מערכת, אומדנים מקומיים, לא ידוע. אומדנים מקומיים לעולם אינם מוצגים כנתוני חיוב של הספק.

כותרות תגובה מנותחות רק באמצעות מיפוי מפורש של הספק. אין הנחה ששמות כלליים של כותרות תקפים באופן גלובלי.
