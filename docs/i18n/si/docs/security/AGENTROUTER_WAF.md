`agentrouter` උඩුගං ද්වාරය `messages[].content` මත මූලපද-පාදක අන්තර්ගත
පෙරහනක් ක්රියාත්මක කරයි. මෙම පෙරහන අර්ධ වශයෙන් නියතවාදීය (ඇතැම්
වාක්ය ඛණ්ඩ සැමවිටම අවහිර කරයි) සහ අර්ධ වශයෙන් සම්භාවිතාත්මකය (හදිසි ඉල්ලීම්
ගොන්නට සංවේදීය — වේගවත් ඉල්ලීම්වලින් පසු වඩාත් දැඩි වන අතර, සිසිල්වීමේ කාලයකින් පසු
යථා තත්ත්වයට පත් වේ).

WAF මඟින් ඉල්ලීමක් අවහිර කළ විට එය පහත ප්රතිචාරය ලබා දෙයි:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## පෙරහනේ විෂය පථය

WAF පරීක්ෂා කරන්නේ `messages[].content` පමණි. එය පහත දෑ පරීක්ෂා **නොකරයි**:

- `system` ප්රේරකය
- ව්යුහගත අන්තර්ගත බ්ලොක් (`tool_result`, `tool_use`, `thinking`, `image`)
- මෙවලම්වල `description` සහ `input_schema` ක්ෂේත්ර
- ඉල්ලීම් පාරදත්ත, ශීර්ෂක, හෝ model id

## බර යටතේ හැසිරීම

කෙටි කාල පරාසයක් තුළ වේගවත් ඉල්ලීම් ~5කට පසු, සාමාන්යයෙන් සමත් වන අන්තර්ගතද
WAF මඟින් අවහිර කිරීම ආරම්භ කරයි. තත්පර ~5–10ක නිෂ්ක්රීය
කාලයකින් පසු bucket එක ලිහිල් වේ. Claude Code හෝ Codex CLI
විසින් මෙවලම්-භාවිත / පණිවිඩ-යැවීම් ඇමතුම් කිහිපයක් ඉක්මනින් අනුක්රමිකව සිදු කරන විට
අතරින් පතර `400 content-blocked` දෝෂ ඇති කරන්නේද මෙම IP-සහ-key-බැඳුණු rate limiter එකමය.

## OmniRoute තුළ දැනටමත් යොදා ඇති අවම කිරීම්

1. **`open-sse/services/wafRateLimit.ts`** — ඕනෑම `agentrouter:*`
   URL එකකට යවන පිටතට යන ඉල්ලීම් අතර අවම වශයෙන්
   500 ms පරතරයක් බලාත්මක කරන burst guard එකකි. මෙම පරතරය මිනිසුන්ට ප්රමාදයක් ලෙස දැනෙන සීමාවට වඩා බෙහෙවින් අඩු වන අතර,
   සාමාන්ය තදබදය යටතේ WAF සක්රිය වීම වළක්වයි.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — උඩුගං සේවාවක්
   `400 content-blocked` ලබා දුන් විට, executor එක ඝාතීය පසුබැසීමක්
   (1.5 s, 3.0 s, උපරිම උත්සාහ 2ක්) සමඟ එම URL එකම නැවත උත්සාහ කරයි. පසුබැසීමෙන් පසු
   WAF සාමාන්යයෙන් ලිහිල් වන අතර නැවත උත්සාහය සාර්ථක වේ.

3. **`tests/unit/compression/harness.test.ts`** — පරීක්ෂණ fixture එකෙහි
   `longInput`, `"lorem ipsum dolor sit amet ".repeat(40)` වෙතින්
   `"example content for testing purposes ".repeat(40)` වෙත වෙනස් කරන ලදී. එමඟින්
   Claude Code විසින් `Read` මෙවලම හරහා මෙම ගොනුව කියවන විට, ගොනු අන්තර්ගතය
   `tool_result` බ්ලොක් එකක් හරහා ආපසු ගලා ගොස් WAF සක්රිය නොකරයි.

## ප්රේරක සහ මෙවලම් ප්රතිදාන සඳහා මාර්ගෝපදේශ

Claude Code හෝ Codex CLI සැසියකට නැවත නැවතත්
`400 content-blocked` ලැබේ නම්, ඉහත රටාවලින් කිසිවක් සඳහා වඩාත්ම මෑත පරිශීලක පණිවිඩය සහ වඩාත්ම
මෑත මෙවලම් ප්රතිඵලය පරීක්ෂා කර, එය වෙනත් ආකාරයකින් ලියන්න. පොදු
විකල්ප ක්රම:

- `Lorem ipsum …` වෙනුවට `example text …` හෝ පරීක්ෂණය
  හෝ fixture එක ආකෘතිගත කිරීමට උත්සාහ කරන සැබෑ අන්තර්ගතය යොදන්න.
- `placeholder` (තනිවම ඇති විට) වෙනුවට `example value`,
  `sample value`, හෝ සැබෑ අගය යොදන්න.
- `language model` වෙනුවට `large language model` හෝ `the model` යොදන්න.
- `dummy data` වෙනුවට `sample data` හෝ යථාර්ථවාදී seed අගයන් යොදන්න.
