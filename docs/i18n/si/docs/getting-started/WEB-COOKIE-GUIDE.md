Web Cookie සැපයුම්කරුවන් මඟින් OmniRoute හට API යතුරක් වෙනුවට ඔබගේ දැනට පවතින බ්රවුසර සැසිය හරහා AI සේවාවක් භාවිත කිරීමට ඉඩ සලසයි. ඔබට දැනටමත් සේවාවක වෙබ් අඩවිය හරහා එයට ප්රවේශය ඇති විට සහ OmniRoute විසින් එම සත්යාපිත සැසියම භාවිත කිරීමට අවශ්ය විට ඒවා ප්රයෝජනවත් වේ.

API යතුරු සැපයුම්කරුවන් මෙන් නොව, Web Cookie සැපයුම්කරුවන් සත්යාපනය කරන්නේ ඔබගේ බ්රවුසරය වෙබ් අඩවියට යවන අක්තපත්ර භාවිතයෙනි.

# ආරම්භ කිරීමට පෙර

> **වැදගත්:** සැමවිටම අක්තපත්ර පිටපත් කළ යුත්තේ **සජීවී ජාල ඉල්ලීමකින්** මිස ඔබගේ බ්රවුසරයේ cookie ගබඩාවෙන් **නොවේ**.

බොහෝ සත්යාපන ගැටලු ඇති වන්නේ වැරදි ස්ථානයෙන් cookies පිටපත් කිරීම හේතුවෙනි.

## Cookie ගබඩාවෙන් පිටපත් නොකරන්න

බොහෝ බ්රවුසර පහත පරිදි ගබඩා කළ cookies පෙන්වයි:

```
DevTools
→ Application (හෝ Storage)
→ Cookies
```

මෙම cookies නිවැරදි ලෙස පෙනුණත්, ඒවා:

- කල් ඉකුත් වූ
- අසම්පූර්ණ
- සත්යාපිත ඉල්ලීම්වලදී පමණක් යවන cookies නොමැති

ඒවා විය හැකිය.

මෙම අගයන් වලංගු ලෙස පෙනුණත්, ඒවා භාවිත කිරීමෙන් සත්යාපනය අසාර්ථක විය හැකිය.

## සජීවී ඉල්ලීමකින් පිටපත් කරන්න

ඒ වෙනුවට, සාර්ථක ඉල්ලීමක cookies භාවිත කරන්න:

```
DevTools
→ Network
→ පිටුව නැවුම් කරන්න
→ කතාබස් හෝ සංවාද ඉල්ලීමක් විවෘත කරන්න
→ Request Headers
→ Cookie
```

`Cookie` ඉල්ලීම් ශීර්ෂකය තුළ ඔබගේ බ්රවුසරය සාර්ථකව භාවිත කළ නිශ්චිත සත්යාපන තොරතුරු අඩංගු වේ.

බොහෝ Web Cookie සැපයුම්කරුවන් සඳහා, OmniRoute වෙත ඇලවිය යුතු අගය මෙයයි.

# සාමාන්ය පිහිටුවීම

බොහෝ Web Cookie සැපයුම්කරුවන් සඳහා පිහිටුවීමේ ක්රියාවලිය එකම වේ.

1. සැපයුම්කරුගේ වෙබ් අඩවියට පුරන්න.
2. බ්රවුසරයේ Developer Tools විවෘත කරන්න.
3. **Network** පටිත්ත විවෘත කරන්න.
4. පිටුව නැවුම් කරන්න.
5. සත්යාපිත කතාබස් හෝ සංවාද ඉල්ලීමක් විවෘත කරන්න.
6. අවශ්ය සත්යාපන අක්තපත්ර පිටපත් කරන්න.
7. OmniRoute විවෘත කරන්න.
8. **Providers → Add Provider** වෙත යන්න.
9. ඔබගේ Web Cookie සැපයුම්කරු තෝරන්න.
10. අක්තපත්ර අලවන්න.
11. **Test Connection** ක්ලික් කරන්න.
12. සැපයුම්කරු සුරකින්න.

අවශ්ය නිශ්චිත අක්තපත්ර සැපයුම්කරු අනුව වෙනස් වේ.

# Web Cookie සැපයුම්කරුවන්ට කළ හැකි සහ කළ නොහැකි දේ

Web Cookie සැපයුම්කරුවන් වෙබ් අඩවියක කතාබස් අතුරුමුහුණත නැවත භාවිත කරයි. ඔවුන් නිල API මඟින් සපයන හැකියාවලට සමාන හැකියාවන් සපයන්නේ **නැත**.
