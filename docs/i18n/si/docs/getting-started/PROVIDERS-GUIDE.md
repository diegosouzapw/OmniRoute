## ඉක්මන් ආරම්භය: ඔබේ පළමු සපයන්නා සම්බන්ධ කරන්න

### පළමු ධාවනයේදී නොමිලේ සපයන්නන් පිහිටුවීමේ විකල්පය

පළමු ධාවන විශාරදය පැහැදිලි **නොමිලේ සපයන්නන් පිහිටුවන්න** කාඩ්පතක් පිරිනමයි. එය OmniRoute හි සත්යාපනය අවශ්ය නොවන සපයන්නන්ගේ රෙජිස්ට්රියෙන් වත්මන්
සුදුසුකම් ලබන ලැයිස්තුව ලබාගෙන, තහවුරු කිරීමට පෙර එක් එක්
සපයන්නා සමාලෝචනය කර තේරීම ඉවත් කිරීමට ඔබට ඉඩ දෙයි. තෙවන පාර්ශ්ව කොන්දේසි, පෞද්ගලිකත්වය, ලබාගත හැකි බව සහ අනුපාත සීමා පළමුව සමාලෝචනය කළ හැකි වන පරිදි OmniRoute සපයන්නාගේ අවවාදාත්මක දැනුම්දීම සහ එහි අඩවිය වෙත සබැඳියක්
පෙන්වයි.

මෙම ක්රියාව විකල්පයකි: විශාරදය අවසන් කිරීමෙන් කිසිවිටෙක නොමිලේ සපයන්නන්ගේ සම්බන්ධතා රහසිගතව සාදන්නේ නැත.
එය තවමත් නොමැති සපයන්නන් පමණක් සාදයි, පවතින අභිරුචිකරණය කළ සම්බන්ධතා
