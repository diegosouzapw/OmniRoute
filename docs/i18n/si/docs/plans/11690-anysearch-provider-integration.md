## 1. සේවාවේ සත්ය මූලාශ්රය (නිල ලේඛන, හරස්-පරීක්ෂා කර ඇත)

- මූලික URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - පරාමිති: `query` (අවශ්යයි), `max_results` (1-10, පෙරනිමිය 10), `tag` (`{domain}.{sub_domain}` සිරස් මාර්ගගත කිරීම), `zone` (cn/intl), `language`, `params` (ව්යුහගත සිරස් ක්ෂේත්ර), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - හැකියා නාමාවලිය, කෝටාවට එරෙහිව ගණන් නොගනී.
- `POST /v1/extract` - `{url, title, content}` ලබාගෙන/උපුටා ගනී; දැඩි JSON අන්තර්ගතයක්, 16 KiB සීමාවක්.
- `POST /v1/auth/email/register` - තනි-ඇමතුම් ලියාපදිංචිය, එක් වරක් පමණක් භාවිත කළ හැකි සරල පෙළ යතුරක් `as_sk_...` ආපසු ලබා දෙයි.
- සත්යාපනය: විකල්ප `Authorization: Bearer <as_sk_...>`; නිර්නාමික ප්රවේශය දෛනික නොමිලේ කෝටාව පරිභෝජනය කරන එක්-IP සීමාවලට පහත වැටේ; වලංගු නොවන යතුරක් නිහඬ නිර්නාමික පසුබැසීමකින් තොරව 401/403 ආපසු ලබා දෙයි.
- නොමිලේ ස්තරය: දිනකට ඉල්ලීම් 1000ක්, යතුරකට QPS 20ක්. ගෙවුම් ස්තරය: මිල නියම කර නැත (ළඟදීම පැමිණේ).
- ප්රතිචාර ආවරණය: සාර්ථකත්වය `{code: 0, message: "success", request_id, data}`; අසාර්ථකත්වය `{code: -1, message}`. සත්යාපන/කෝටා දෝෂවල ව්යුහගත `error_code` නොමැත (සංඥාව වන්නේ පණිවිඩ පෙළයි); උපුටා ගැනීමට විශේෂිත දෝෂවල `error_code` (`invalid_extract_url`, `extract_failed`) ඇත. 429 මත `Retry-After` ශීර්ෂයක් නොමැත.

## 3. තීරණ (සියල්ල 2026-08-26 දින ගන්නා ලදී)

1. **මාර්ගගත කිරීමේ ස්ථාවරය: `fallbackOnly`.** තාර්කික පදනම: පිරිවැය-0 වන නොමිලේ සැපයුම්කරුවෙකු කිසිවිටෙකත් ස්වයංක්රීය පිරිවැය මාර්ගගත කිරීමේදී ප්රමුඛ නොවිය යුතුය; පැහැදිලි තේරීම සහ අසාර්ථකත්වයකින් පසු ආපසු යොමු කිරීම මෙයින් බලපෑමට ලක් නොවේ. පූර්වාදර්ශය: ඒකාබද්ධ කළ xquik ප්රවේශය.
2. **විෂය පථය: v1 තුළ `POST /v1/extract` හරහා webSearch + webFetch.** tavily/exa ද්විත්ව-හැකියා මානසික ආකෘතිය සමඟ පෙළගස්වා ඇත. සිරස් මතුපිට (`tag`, `sub-domains`, `batch_search`) විෂය පථයෙන් පිටත පවතී — අද සිරස් පරාමිති සඳහා IR එකක් නොමැත.
3. **කෝටා සංදර්ශනය: `freeMonthlyQuota: 0`** (xquik-ශෛලියේ සංරක්ෂණාත්මක සංදර්ශනය). සැබෑ දීමනාව (දිනකට ඉල්ලීම් 1000ක්, දෛනික යළි සැකසීමක් සහිතව) ඒ වෙනුවට UI නාමාවලියේ `authHint` පිටපත තුළ දක්වා ඇත. තාර්කික පදනම: කෝටා සංදර්ශනය යළි සැකසීමේ අර්ථවේදයට ගැළපිය යුතුය; දෛනික සීමාවක් මාසික-සමාන අගයකට (30000) පරිවර්තනය කිරීම UI එකට ඉටු කළ නොහැකි ව්යාජ පොරොන්දුවකි.
4. **searchTypes: `["web"]` පමණි.** AnySearch API තුළ පුවත්/රූප සිරස් සේවාවක් ඇති බවට පොදු සාක්ෂි නොමැත; ලේඛනගත සිරස් සේවාවක් නොමැති API ඒකාබද්ධ කරන ද්වාර (උදා. Google Custom Search), news -> web ලෙස නිහඬව සිතියම්ගත කිරීම වෙනුවට web පමණක් නිරාවරණය කරයි.
5. **යතුරු ස්ථාවරය:** යතුරක් නොමැතිව ක්රියා කරයි; වලංගු නොවන යතුරක් 401/403 ආපසු ලබා දෙන අතර එය කිසිවිටෙකත් නිර්නාමික ප්රවේශයට නිහඬව පහත හෙළනු නොලැබේ (ඉහළ ප්රවාහ ගිවිසුම පිළිබිඹු කරයි).
6. **හිතාමතා කළ බැහැර කිරීම්:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (චැට් අන්තර්ග්රහණය firecrawl/jina/tavily ලෙසම පවතී); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (නිර්නාමික දුරස්ථ අන්ත ලක්ෂ්ය එක් එක් පිටතට යන IP එකකට සීමා කළ තනි IP සංචිතයක් බෙදා ගන්නා බැවින්, යතුරු රහිත extract යනු තෝරා සක්රිය කළ යුතු විකල්පයක් මිස ස්වයංක්රීය මාර්ගගත කිරීමේ අපේක්ෂකයෙක් නොවේ); `QUOTA_STATUS_PROVIDERS` (AnySearch කෝටාව 402/403 තත්ත්ව කේත මඟින් නොව 429/ලියුම් කවරය මඟින් සංඥා කරයි).
