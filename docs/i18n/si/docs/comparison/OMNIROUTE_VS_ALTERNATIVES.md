## OmniRoute තෝරාගත යුත්තේ කවදාද

- ඔබ ස්වයං-සත්කාරක කරන අතර **උපරිම සපයන්නන් ආවරණයක්** අවශ්ය විට (සපයන්නන් 329ක්, නොමිලේ/සත්යාපනය-අවශ්ය-නොවන නාමාවලි ඇතුළත් කිරීම් 155ක්)
- ඔබට **අන්තර්ගත MCP සේවාදායකයක්** අවශ්ය විට (LLM මෙවලම්, මතකය සහ මෙවලම් ලෙස නිරාවරණය කළ කුසලතා)
- නියෝජිතයාගෙන්-නියෝජිතයාට කාර්ය ප්රවාහ සඳහා ඔබට **A2A ප්රොටෝකෝලය** අවශ්ය විට
- ඉහළ මට්ටමේ CAPTCHAs මඟින් හඳුනාගැනීම වැළැක්වීමට ඔබට **ඇඟිලි සලකුණු සැඟවීම** (JA3/JA4) අවශ්ය විට
- SaaS බිල්පතක් නොමැතිව ඔබට **ව්යවසාය විශේෂාංග** (ආරක්ෂණ සීමා, ඇගයීම්, විගණන වාර්තාව) අවශ්ය විට

## LiteLLM තෝරාගත යුත්තේ කවදාද

- ඔබ **Python-ප්රමුඛ** වන අතර `litellm.completion()` සමඟ දැඩි ඒකාබද්ධකරණයක් අවශ්ය විට
- ඔබට **පරිණත නිෂ්පාදන යෙදවුම් ක්රමවේද** (k8s, Helm ප්රස්ථාර) අවශ්ය විට
- ඔබේ කණ්ඩායම දැනටමත් Python ක්ෂුද්ර සේවා ධාවනය කරන විට

## OpenRouter (SaaS) තෝරාගත යුත්තේ කවදාද
