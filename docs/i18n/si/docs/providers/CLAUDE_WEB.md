## `claude-web`

`claude-web` විසින් සත්යාපනය කළ `claude.ai` බ්රවුසර සැසියක් හරහා OpenAI-ආකෘතික කතාබස් ඉල්ලීම් යවයි. ක්රියාත්මකකාරකය සපයා ඇති cookie එක සාමාන්යකරණය කර, සත්යාපනය කළ එක් සංවිධානයක් නිරාකරණය කර, සංවාද තත්ත්වය සූදානම් කර, සෘජු හෝ බ්රවුසර ප්රවාහනයක් තෝරා, upstream SSE ප්රතිචාරය දැඩි ලෙස පරිවර්තනය කරයි. මෙහි මෙහෙයවීම `open-sse/executors/claude-web.ts:320` තුළ ඇත.

සම්පූර්ණ `claude.ai` Cookie ශීර්ෂකය හෝ සැසි අගය පමණක් සපයන්න. සැසි අගය පමණක් දුන් විට එය `sessionKey` ලෙස සාමාන්යකරණය කෙරේ; සපයා ඇත්නම් අනෙකුත් cookies එලෙසම තබාගනී. ක්රියාත්මකකාරකය `cookie` හෝ `apiKey` හරහා cookie එක පිළිගන්නා අතර, සම්බන්ධතා දත්තවලින් විකල්ප `deviceId` සහ `orgId` අගයන් කියවයි (`open-sse/executors/claude-web.ts:72`).

`orgId` නොමැති නම්, ක්රියාත්මකකාරකය `GET https://claude.ai/api/organizations` කැඳවා, සත්යාපනය කළ Claude Web සැසියෙන් ආපසු ලබා දෙන පළමු සංවිධානය භාවිත කරයි (`open-sse/executors/claude-web.ts:141`). වලංගු සංවිධානයක් ආපසු නොලැබෙන විට එය ආරක්ෂිතව අසාර්ථක වේ, ප්රතික්ෂේප කළ සැසි අවසරය 401 ලෙස වාර්තා කරයි, සහ Cloudflare අභියෝගයක් සත්යාපන අසාර්ථකත්වයකින් වෙන්කර හඳුනාගනී.

  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion` වෙත යවයි.

නව වාරයක `create_conversation_params` ඇතුළත් වේ. හැඹිලිගත හෝ පැහැදිලිව සම්බන්ධ කළ පසු විපරමක `parent_message_uuid` ඇතුළත් වන අතර `create_conversation_params` අත්හැරේ. නැවත උත්සාහයක් සඳහා සංවාද සහ මව්-පණිවිඩ තත්ත්ව දෙකම අවශ්ය වන අතර prompt එකක් නොයවයි (`open-sse/executors/claude-web/session.ts:254`). නව සංවාද සත්යාපනය කළ UI එක `/new` හි විවෘත කරයි; හැඹිලිගත හෝ පැහැදිලිව සම්බන්ධ කළ පසු විපරම් නිශ්චිත සංවාද පිටුව විවෘත කරයි (`open-sse/executors/claude-web/session.ts:324`).

සංවාද තත්ත්වය යනු SHA-256 ගිණුම් විෂයපථයක් සහ සම්මත caller පිටපත අනුව යතුරුගත කළ මතකය-තුළ හැඹිලියකි. ඇතුළත් කිරීම් මිනිත්තු 30කට පසු කල් ඉකුත් වන අතර හැඹිලිය ඇතුළත් කිරීම් 5,000කට සීමා කර ඇත (`open-sse/executors/claude-web/session.ts:12`). දැඩි ප්රවාහ විග්රහකය `message_stop` නිරීක්ෂණය කිරීමෙන් පසුව පමණක් තත්ත්වය ස්ථිර කෙරේ; ක්රියාවලි නැවත ආරම්භ කිරීමෙන් එය ඉවත දැමේ. හැඹිලි නොගැළපීමකදී, පෙර පණිවිඩ නිහඬව අත්හැරීම වෙනුවට බහු-පණිවිඩ ඉල්ලීමක් එක් ප්රතිසාධන prompt එකක් බවට අනුක්රමීකරණය කෙරේ.

Locale සහ වේලා කලාපය මෙම ප්රමුඛතා අනුපිළිවෙළ භාවිත කරයි: ඉල්ලීමේ `claude_web` අගය, සම්බන්ධතා අගය, ධාවන-කාල අගය, ඉන්පසු locale සඳහා `en-US` හෝ වේලා කලාපය සඳහා `UTC` (`open-sse/executors/claude-web/session.ts:218`).

### මෙවලම් සහ ඉල්ලීම් payload

සෘජු ඉල්ලීම් පරිවර්තනය කරන්නේ caller විසින් සපයන ව්යුහාත්මකව වලංගු OpenAI ශ්රිත මෙවලම් පමණි. කෘත්රිමව නිර්මාණය කළ ස්ථිතික පෙරනිමි මෙවලම් ලැයිස්තුවක් නොමැත (`open-sse/executors/claude-web/payload.ts:102`).

ඒ වෙනුවට බ්රවුසර ඉල්ලීම් සත්යාපනය කළ UI ඉල්ලීම ග්රහණය කර එහි ගිණුම් මෙවලම්, මෙවලම් තත්ත්ව සහ පුද්ගලීකරණය කළ ශෛලීන් රඳවා ගනී. සූදානම් කළ සංවාද, ආකෘති, තර්කන, prompt සහ පණිවිඩ UUID ක්ෂේත්ර තවමත් ග්රහණය කළ ඉල්ලීම අභිබවා යයි (`open-sse/executors/claude-web/browserTransport.ts:175`). බ්රවුසර සැකිලි ගිණුම, සංවිධානය, cookie, locale සහ වේලා කලාපය යන අගයන්ගේ hash එකක් මඟින් විෂයපථගත වන අතර මිනිත්තු 30කට පසු කල් ඉකුත් වේ (`open-sse/executors/claude-web/browserTransport.ts:11`, `open-sse/executors/claude-web/browserTransport.ts:158`). සෘජු ඉල්ලීමකට caller මෙවලම් නොමැති විට, එයට එම විෂයපථගත සැකිල්ල නැවත භාවිත කළ හැක; caller විසින් පැහැදිලිව සපයන මෙවලම්වලට ප්රමුඛතාව හිමි වේ (`open-sse/executors/claude-web/browserTransport.ts:214`).

### ප්රවාහන තේරීම

පෙරනිමි මාර්ගය `sendClaudeWebDirect()` වන අතර, එය වින්යාස කළ Chrome 146 පැතිකඩ සහ සපයා ඇති cookie එක සමඟ `tlsFetchClaude()` කැඳවයි (`open-sse/services/claudeTlsClient.ts:23`). එය solver එකක් දියත් නොකරන අතර ආදේශක cookie එකක් නිර්මාණය නොකරයි.

ගිණුම්-පරාසගත browser adapter එක ප්රධාන ප්රවාහන ක්රමය බවට පත් කිරීමට `WEB_COOKIE_USE_BROWSER` සඳහා `1`, `true`, හෝ `on` සකසන්න. හඳුනාගත් Cloudflare 403 අභියෝගයකදී සෘජු ප්රවාහනයෙන් browser adapter එක වෙත පසුබැසීමට ඉඩ දීම සඳහා `OMNIROUTE_BROWSER_POOL` සඳහාද එම අගයන්ගෙන් එකක් සකසන්න (`open-sse/executors/claude-web.ts:195`). වෙනත් HTTP අසාර්ථකවීම් එම පසුබැසීම සක්රිය නොකරයි.

Browser adapter එක එකම pooled Playwright context එක තුළ cookies තබාගනී, ඉහත විස්තර කළ පරාසගත hashed key එක භාවිත කරයි, සහ එම context එකෙන් completion එක යවයි (`open-sse/executors/claude-web/browserTransport.ts:444`). එය browser එක මඟින් විසඳූ cookie එකක් කිසිවිටෙකත් සෘජු TLS client එකට export නොකරයි. Browser නැවත උත්සාහ සඳහා, එම සත්ය Playwright context එකට බැඳුණු කල් ඉකුත් නොවූ UI template එකක් අවශ්ය වේ (`open-sse/executors/claude-web/browserTransport.ts:467`). Browser ප්රතිචාර කියවීම් සත්යාපිත පිටුව තුළ වර්ධක ආකාරයෙන් ක්රියාත්මක වන අතර, ඉල්ලීම් අවලංගු කිරීම පිළිපදියි, සහ ප්රමාණය 16 MiB ඉක්මවූ වහාම upstream body එක අවලංගු කරයි (`open-sse/executors/claude-web/browserTransport.ts:259`).

Executor එක හවුල් request logger එක වෙත සංවේදී දත්ත ඉවත් කළ audit projection එකක් ආපසු ලබා දෙයි: organization, conversation සහ message UUIDs, prompt පෙළ, tool අර්ථදැක්වීම්, cookies, සහ device identifiers ඉවත් කර ඇත (`open-sse/executors/claude-web.ts:237`,
`open-sse/executors/claude-web.ts:252`). Transport exceptions මඟින් throw කළ පණිවිඩය වෙනුවට සාමාන්ය connection error එකක්ද ආපසු ලබා දෙයි.

### SSE හැසිරීම

`createClaudeWebResponse()` මඟින් LF හෝ CRLF framing සහ බහු-පේළි `data:` fields හසුරුවයි. එය text deltas `content` වෙතත්, thinking deltas `reasoning_content` වෙතත්, දන්නා metadata events `claude_web` response extension එක වෙතත් සිතියම්ගත කරයි. සෑම metadata event එකක්ම එයටම අදාළ field allowlist එක හරහා project කෙරේ (`open-sse/executors/claude-web/stream.ts:37`). Conversation, parent-message, assistant-message, සහ operation metadata ද `X-OmniRoute-Claude-Web-*` headers තුළ ආපසු ලබා දෙයි (`open-sse/executors/claude-web/stream.ts:364`).

විකෘති JSON, upstream `error` events, නොදන්නා event types, වලංගු නොවන අනුපිළිවෙළ, content-block නොගැළපීම්, හෝ `message_stop` ට පෙර EOF හමු වූ විට parser එක ආරක්ෂිතව අසාර්ථක වේ. Streaming output එක එක් finish chunk එකක් සහ එක් `[DONE]` එකක් නිකුත් කරයි; buffered output එකද එම parser එකම භාවිත කරයි. Parser එක `message_stop` වහාම අවසාන තත්ත්වය ලෙස සලකයි, ඉන් පසුව එන upstream data අවලංගු කරයි, සහ downstream අවලංගු කිරීම upstream reader එක වෙත ප්රචාරණය කරයි (`open-sse/executors/claude-web/stream.ts:461`,
`open-sse/executors/claude-web/stream.ts:563`). අවසන් නොකළ SSE පේළි සහ සමුච්චිත events 1 MiB දක්වා සීමා කර ඇත (`open-sse/executors/claude-web/stream.ts:17`,
`open-sse/executors/claude-web/stream.ts:62`).

### පිහිටුවීම

1. `npm run dev` හෝ build කළ installation එකක් සමඟ OmniRoute ආරම්භ කරන්න.
