වෙන් කිරීම යනු සැපයුම්කරුගේ කෝටාව නොවේ.

කෝටා සංචිත මඟින් සැපයුම්කරුගේ සංචිතයක් භාවිත කළ හැකි API යතුරු සහ දැඩි, මෘදු හෝ තාවකාලික අධිභාර ප්රතිපත්ති යෙදෙන ආකාරය නිර්වචනය කරයි. සැපයුම්කරුගේ කෝටාව යනු සැපයුම්කරුවකු විසින් වාර්තා කරන හෝ පැහැදිලිව වින්යාස කළ මූලාශ්රයකින් ලැබෙන බාහිර ධාරිතාවයි. Ghostlight අභ්යන්තර අයවැය යනු පරිපාලකයා විසින් නිර්වචනය කරන ලද පාලන සීමාවන්ය.

`ensurePool` මෙහෙයුම සමප්රතිඵලදායක වේ: සමාන සංචිතයක් නොවෙනස්ව පවතී, වෙනස් කළ වෙන් කිරීමක් යාවත්කාලීන කෙරේ, සහ නොපවතින සංචිතයක් සාදනු ලැබේ. මෙය ස්වයංක්රීයකරණය සහ සීමාකළ API ඇමතුම්කරුවන් සඳහා අදහස් කර ඇත.

කියවීමට පමණක් ඇති තත්ත්ව අන්ත ලක්ෂ්යය `GET /api/omniroute/status` වේ. සත්යාපන විධානය `npm run omniroute:verify` වේ; එය සජීවී මොඩල් ඉල්ලීමක් සිදු නොකරයි.
