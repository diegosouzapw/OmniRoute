අධීක්ෂණ කොටසේ දැන් ඉහළින් **ක්රියාකාරකම්** ද, ඉන් අනතුරුව **උපකණ්ඩායම් 3ක්** ද ඇත:

│   ├── ප්රොක්සි ලොග්
│   └── කොන්සෝල් ලොග්
├── විගණන කණ්ඩායම
│   ├── විගණන ලොගය
│   ├── MCP විගණනය
│   └── A2A විගණනය
└── පද්ධති කණ්ඩායම
