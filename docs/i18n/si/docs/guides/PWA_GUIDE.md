OmniRoute සම්පූර්ණයෙන්ම ස්ථාපනය කළ හැකි Progressive Web App එකක් ලෙස සපයනු ලැබේ. ඔබ ඕනෑම ජංගම බ්රවුසරයකින් — Android (Chrome) හෝ iOS (Safari) — උපකරණ පුවරුවට පිවිසෙන විට, ඔබට "මුල් තිරයට එක් කරන්න" තෝරා යෙදුම් වෙළඳසැලක් අවශ්ය නොවන ස්වදේශීය යෙදුමකට සමාන අත්දැකීමක් ලබා ගත හැක.

## PWA යනු කුමක්ද?

Progressive Web App එකක් OmniRoute වෙබ් උපකරණ පුවරුව ස්වදේශීය ජංගම යෙදුමක් මෙන් පෙනෙන සහ දැනෙන දෙයක් බවට පත් කරයි. ස්ථාපනය කළ පසු, එය:

- එයටම අයත් නිරූපකයක් සමඟ ඔබේ මුල් තිරයෙන් දියත් වේ
- සම්පූර්ණ තිරයෙන් විවෘත වේ — බ්රවුසර ලිපින තීරුවක් හෝ ටැබ් අතුරුමුහුණතක් නොමැත
- කැපවූ සම්බන්ධතා පිටුවක් සමඟ නොබැඳිව ක්රියා කරයි
- වේගවත් පූරණය සඳහා ස්ථිතික සම්පත් හැඹිලිගත කරයි
- සිරස් සහ තිරස් දිශානති දෙකටම සහාය දක්වයි

## ස්ථාපනය

### Android (Chrome)

1. Chrome තුළ OmniRoute උපකරණ පුවරුව විවෘත කරන්න: `http://YOUR_IP:20128`
2. Chrome ස්වයංක්රීයව **"OmniRoute මුල් තිරයට එක් කරන්න"** බැනරයක් පෙන්වනු ඇත, නැතහොත්:
   - **⋮** මෙනුව (තිත් තුන) තට්ටු කරන්න → **"මුල් තිරයට එක් කරන්න"** හෝ **"යෙදුම ස්ථාපනය කරන්න"**
3. විමසුම තහවුරු කරන්න
4. OmniRoute ස්වාධීන යෙදුමක් ලෙස ඔබේ මුල් තිරය මත දිස් වේ

### iOS (Safari)

1. Safari තුළ OmniRoute උපකරණ පුවරුව විවෘත කරන්න: `http://YOUR_IP:20128`
2. **බෙදාගන්න** බොත්තම (ඊතලයක් සහිත කොටුව) තට්ටු කරන්න
3. පහළට අනුචලනය කර **"මුල් තිරයට එක් කරන්න"** තට්ටු කරන්න
4. එයට නමක් දෙන්න (පෙරනිමිය "OmniRoute" වේ) සහ **එක් කරන්න** තට්ටු කරන්න
5. OmniRoute යෙදුම් නිරූපකය සමඟ ඔබේ මුල් තිරය මත දිස් වේ

### ඩෙස්ක්ටොප් (Chrome / Edge)

1. OmniRoute උපකරණ පුවරුව විවෘත කරන්න
2. ලිපින තීරුවේ ඇති **ස්ථාපන නිරූපකය** ක්ලික් කරන්න (හෝ ⋮ → "OmniRoute ස්ථාපනය කරන්න...")
3. විමසුම තහවුරු කරන්න
4. OmniRoute ස්වාධීන කවුළුවක් ලෙස විවෘත වේ — ටැබ් නැත, ලිපින තීරුවක් නැත

## විශේෂාංග

### සම්පූර්ණ තිර අත්දැකීම

මැනිෆෙස්ටය `display: "fullscreen"` සමඟ වින්යාස කර ඇත, එයින් අදහස් වන්නේ ස්ථාපිත යෙදුම මුළු තිරයම භාවිත කරන බවයි — බ්රවුසර අතුරුමුහුණතක් හෝ තත්ත්ව තීරු අතිච්ඡාදනයක් නොමැත. මෙය උපකරණ පුවරුව සැබැවින්ම ස්වදේශීය යෙදුමක් මෙන් දැනීමට සලස්වයි.

### නොබැඳි පිටුව

ජාලය නොමැති විට සහ පරිශීලකයෙකු නව පිටුවකට සංචාලනය කරන විට, service worker කැපවූ `/offline` පිටුවක් සපයයි, එය:

- පැහැදිලි **"සම්බන්ධතා ගැටලුවක්"** පණිවිඩයක් පෙන්වයි
- තත්ය කාලීනව යාවත්කාලීන වන සජීවී **සබැඳි/නොබැඳි තත්ත්ව දර්ශකයක්** පෙන්වයි
- සම්බන්ධතාව නැවත ලැබුණු විට යළි පූරණය කිරීම සඳහා **"සම්බන්ධතාව නැවත උත්සාහ කරන්න"** බොත්තමක් සපයයි
- රෝග විනිශ්චය සඳහා **තත්ත්ව පිටුවට** සබැඳියක් සපයයි

### වෙබ් යෙදුම් මැනිෆෙස්ටය (`manifest.webmanifest`)

`src/app/manifest.ts` හරහා Next.js මඟින් ජනනය කරනු ලැබේ:

```json
{
  "name": "OmniRoute",
  "short_name": "OmniRoute",
  "description": "OmniRoute is an AI gateway for multi-provider LLMs. One endpoint for all your AI providers.",
  "start_url": "/",
  "scope": "/",
  "display": "fullscreen",
  "orientation": "any",
  "background_color": "#0b0f1a",
  "theme_color": "#0b0f1a",
  "icons": [
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    },
    { "src": "/apple-touch-icon.png", "sizes": "180x180", "type": "image/png" }
  ]
}
```

### සේවා කාර්යකරු (`public/sw.js`)

කිසිදු framework පරායත්තතාවකින් තොර සාමාන්ය සේවා කාර්යකරුවෙකු සතුව ඇත්තේ:

- **ස්ථාපන අදියර**: යෙදුම් කවචය (මූල පිටුව, නොබැඳි පිටුව, මැනිෆෙස්ටය, අයිකන) පූර්වයෙන් cache කරයි
- **සක්රිය කිරීමේ අදියර**: පැරණි cache අනුවාද පිරිසිදු කර සියලු clients තම පාලනයට ගනී
- **Fetch අදියර**: ඉල්ලීම් වර්ගය (සංචාලනය, ස්ථිතික සම්පත, API) මත පදනම් වූ බුද්ධිමත් මාර්ගගත කිරීම
- **Cache අනුවාදකරණය**: `omniroute-pwa-v3` — යාවත්කාලීන කිරීමකදී නව cache එකක් බලහත්කාරයෙන් නිර්මාණය කිරීමට මෙය ඉහළ දමන්න

### පිරිසැලසුම් පාරදත්ත (`src/app/layout.tsx`)

PWA අනුකූලතාව සඳහා අවශ්ය සියලු meta tags මූල පිරිසැලසුම මඟින් සපයයි:

- `/manifest.webmanifest` වෙත යොමු වන `manifest` සබැඳිය
- iOS standalone ආකාරය සඳහා `apple-web-app-capable: true`
- `apple-web-app-status-bar-style: black-translucent`
- Android Chrome සඳහා `mobile-web-app-capable: yes`
- `theme-color: #0b0f1a`
- දාරයෙන් දාරයට rendering කිරීම සඳහා `viewport-fit: cover`

### සංරචකය: `PwaRegister`

`src/shared/components/PwaRegister.tsx` හි පිහිටා ඇති මෙම client සංරචකය:

1. Mount වන විට ක්රියාත්මක වේ (client-side පමණි)
2. Browser එක තුළ `serviceWorker` සහාය තිබේදැයි පරීක්ෂා කරයි
3. `/sw.js` නිහඬව ලියාපදිංචි කරයි (යෙදුම අවහිර වීම වැළැක්වීම සඳහා දෝෂ නොසලකා හරිනු ලැබේ)
4. කිසිවක් render නොකරයි (`return null`) — මෙය අතුරු ප්රතිඵලයක් සඳහා පමණක් භාවිත වන සංරචකයකි

## Termux (Android) සමඟ භාවිතය

Termux හරහා Android මත OmniRoute ධාවනය කරන විට, PWA එක බාධාවකින් තොරව ක්රියා කරයි:

1. Termux තුළ OmniRoute ආරම්භ කරන්න: `npx omniroute`
2. එම දුරකථනයේම Chrome විවෘත කරන්න: `http://localhost:20128`
3. "මුල් තිරයට එක් කරන්න" හරහා PWA එක ස්ථාපනය කරන්න
4. PWA එක දේශීය Termux server එකට සම්බන්ධ වේ — සියල්ල උපාංගය තුළම ක්රියාත්මක වේ

මෙම සංයෝජනයෙන් අදහස් වන්නේ ඔබේ Android දුරකථනය **server එක** (Termux) සහ **client එක** (PWA) යන දෙකම වන බවයි — සම්පූර්ණයෙන්ම ස්වයංපෝෂිත AI gateway එකකි.

## වෙනත් උපාංගවලින් භාවිතය

ඔබේ OmniRoute server එකට browser ප්රවේශය ඇති ඕනෑම උපාංගයක PWA එක ස්ථාපනය කරන්න:

- **වෙනත් දුරකථනයක්/ටැබ්ලටයක්**: `http://PHONE_IP:20128` වෙත ගොස් PWA එක ස්ථාපනය කරන්න
- **ලැප්ටොප් පරිගණකයක්**: Chrome/Edge විවෘත කර එය desktop PWA එකක් ලෙස ස්ථාපනය කරන්න
- **Browser එකක් සහිත Smart TV එකක්**: Dashboard එක පූර්ණ තිරයෙන් ප්රවේශ කරන්න

## අභිරුචිකරණය

### Instance නාමය

PWA මාතෘකාව `Dashboard → Settings` හි ඇති **Instance Name** සැකසුම අනුගමනය කරයි. ඔබ ඔබේ instance එක "My AI Gateway" ලෙස නැවත නම් කළහොත්, ස්ථාපිත PWA එක එම නම පෙන්වනු ඇත.

### අභිරුචි Favicon එක

ඔබ `Dashboard → Settings` හරහා අභිරුචි favicon එකක් උඩුගත කළහොත්, desktop එකේ PWA අයිකනය එම අභිරුචි අයිකනය පිළිබිඹු කරයි. ජංගම මුල් තිර අයිකන සඳහා පෙර සාදන ලද `icon-512.png` සහ `apple-touch-icon.png` ගොනු භාවිත වේ.

## සීමාවන්

- **Push දැනුම්දීම් නොමැත** — සේවා වර්කර් එක Push API ක්රියාත්මක නොකරයි. ඒ වෙනුවට දැනුම්දීම් Electron යෙදුම මඟින් හසුරුවනු ලැබේ.
- **පසුබිම් සමමුහුර්තකරණය නොමැත** — නොබැඳි ක්රියා පසුව නැවත ක්රියාත්මක කිරීම සඳහා පෝලිම්ගත නොකෙරේ. PWA එක මූලික වශයෙන් උපකරණ පුවරු දර්ශකයකි.
- **iOS සීමා කිරීම්** — iOS මත Safari සියලුම PWA විශේෂාංග සඳහා සහය නොදක්වයි (උදා., ස්ථාපන විමසුම් අතින් සිදු කළ යුතු අතර, පසුබිම් සේවා වර්කර් සීමා කර ඇත).
- **කෑෂ් ප්රමාණය** — සේවා වර්කර් එක කෑෂ් කරන්නේ ස්ථිතික සම්පත් පමණි. `/api/` මාර්ගවලින් ලැබෙන විශාල ප්රතිචාර පේලෝඩ් කිසිවිටෙක කෑෂ් නොකෙරේ.
- **ජංගම උපාංගවල අභිරුචි අයිකන** — සැකසුම් තුළ favicon එක වෙනස් කිරීමෙන් ජංගම උපාංගයේ මුල් තිර අයිකනය යාවත්කාලීන නොවේ (මේ සඳහා PWA අයිකන නැවත ජනනය කිරීම අවශ්ය වේ).
