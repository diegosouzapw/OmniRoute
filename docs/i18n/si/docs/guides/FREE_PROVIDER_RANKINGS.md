## එය කුමක්ද

OmniRoute විසින් සපයන්නන් 329ක් ලියාපදිංචි කරන අතර, ඒවා අතර **නොමිලේ/සත්යාපනය අවශ්ය නොවන**
ලෙස සලකුණු කළ නාමාවලි ඇතුළත් කිරීම් 155ක් ඇත (සත්යාපනය අවශ්ය නොවන,
නොමිලේ-ස්ථර OAuth, හෝ නොමිලේ-ස්ථර API යතුර — [නොමිලේ ස්ථර මාර්ගෝපදේශය](../getting-started/FREE-TIERS-GUIDE.md)
සහ සම්පූර්ණ [නොමිලේ ස්ථර නාමාවලිය](../reference/FREE_TIERS.md) බලන්න). නමුත් ගැටලුව වන්නේ:
නොමිලේ සපයන්නන් අතර ආකෘති ගුණාත්මකභාවය බෙහෙවින් වෙනස් වීමයි. අතිනවීන ආකෘතියක් සපයන
සත්යාපනය අවශ්ය නොවන සපයන්නෙකු, කුඩා පැරණි ආකෘතියක් සපයන අයෙකුට වඩා බෙහෙවින් ප්රයෝජනවත් වේ.

**නොමිලේ සපයන්නන්ගේ ශ්රේණිගත කිරීම්** මඟින් "**මට හොඳම ආකෘතිය ලබා දෙන්නේ කුමන නොමිලේ
සපයන්නාද?**" යන ප්රශ්නයට පිළිතුරු සපයන්නේ, සෑම නොමිලේ සපයන්නෙකුගේම නාමාවලිය
**Arena AI ප්රමුඛතා පුවරුවෙන්** ලබාගත් **සමූහ දායකත්වයෙන් සැකසූ ගුණාත්මක ලකුණු** සමඟ
සම්බන්ධ කිරීමෙනි (මානව මනාප මත පදනම් වූ ELO, LMArena chatbot arena පිටුපස ඇති අදහසට සමානයි).
ඉන්පසු සපයන්නන් ඔවුන්ගේ **හොඳම නොමිලේ ආකෘතියේ** ප්රබලත්වය අනුව ශ්රේණිගත කෙරේ.

ශ්රේණිගත කිරීම සැබෑ මූලාශ්ර තුනකින් ගණනය කෙරේ:

1. නොමිලේ සපයන්නන්ගේ ලැයිස්තු — `NOAUTH_PROVIDERS`, සහ `hasFree` ලෙස සලකුණු කළ
   `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` ඇතුළත් කිරීම්
   (`src/shared/constants/providers.ts`).
2. සපයන්නන්ගේ රෙජිස්ට්රියෙන් එක් එක් සපයන්නාගේ ආකෘති නාමාවලිය
   (`open-sse/config/providerRegistry.ts`).
3. Arena ELO සමමුහුර්ත කිරීමේ එන්ජිම (`src/lib/arenaEloSync.ts`) විසින්
   `model_intelligence` DB වගුවේ ගබඩා කරන ලද ELO-ව්යුත්පන්න කාර්ය-ගැළපුම් ලකුණු.

සම්බන්ධ කිරීමේ තර්කනය `src/lib/freeProviderRankings.ts` තුළ පවතී.

(උදා. _අතිවිශිෂ්ට_, _විශිෂ්ට_, _ඉතා හොඳ_, _හොඳ_, _සාමාන්ය_) පෙන්වනු ලැබේ.

### API අන්ත ලක්ෂ්යය

මෙම පිටුවට දත්ත සපයන්නේ පොදු කියවීම් අන්ත ලක්ෂ්යයකි
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

විමසුම් පරාමිති (Zod සමඟ වලංගු කෙරේ):

| පරාමිතිය   | වර්ගය  | පෙරනිමිය      | සටහන්                                                                                                               |
| ---------- | ------ | ------------- | ------------------------------------------------------------------------------------------------------------------- |
| `category` | string | (කිසිවක් නැත) | `default`, `coding`, `review`, `documentation`, `debugging` අතරින් එකක්. ඒකාබද්ධ ශ්රේණිගත කිරීම සඳහා මෙය නොදක්වන්න. |
| `limit`    | number | `50`          | `1–100` පරාසයට සීමා කෙරේ.                                                                                           |

ප්රතිචාරයේ ව්යුහය:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` යනු මුල් Arena ELO අගයයි; `score` යනු සාමාන්යකරණය කළ කාර්ය-ගැළපුම් අගයයි
(පහත බලන්න). ලකුණු ලබා ඇති ආකෘති නොමැති සපයන්නන් ප්රතිචාරයෙන් ඉවත් කෙරේ.

### සාමාන්යකරණය (කාර්ය-ගැළපුම් ලකුණ)

අමු ELO ලකුණු එක් එක් ප්රමුඛතා පුවරුව අනුව **`[0.4, 0.98]` පරාසයේ කාර්ය-ගැළපුම් අගයකට** සාමාන්යකරණය කෙරේ:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

පරිශීලක අභිබවා සැකසීම් සඳහා ඉඩ තබමින්, ලකුණ කිසිවිටෙක `0` හෝ `1` වෙත ළඟා නොවේ. API ප්රතිචාරයේ ඔබ දකින `score` ක්ෂේත්රය සහ උපකරණ පුවරුවේ පෙන්වන ලේබලය මෙයයි.

### ආකෘති ප්රමුඛතා පුවරුවට ගැළපීම

රෙජිස්ට්රි ආකෘති IDs සහ Arena ආකෘති නාම සැමවිටම හරියටම නොගැළපේ. ශ්රේණිගත කිරීම නම්යශීලී ගැළපීම භාවිත කරයි (`src/lib/freeProviderRankings.ts` හි `findMatchingIntelligence`):

1. සාමාන්යකරණය කළ ආකෘති ID එකට නිශ්චිත ගැළපීම.
2. අවසානයේ ඇති අනුවාද ප්රත්යයක් ඉවත් කිරීමෙන් පසු ගැළපීම (උදා. `kimi-k2.6` → `kimi-k2`).
3. උපසර්ග ගැළපීම (ප්රමුඛතා පුවරු ආකෘති නාමයක් රෙජිස්ට්රි ID එකේ උපසර්ගයක් වීම).

සමමුහුර්තකරණ පැත්තේදී, දන්නා සැපයුම්කරු උපසර්ග (`anthropic/`, `openai/`, `google/`, …) ඉවත් කරනු ලබන අතර, කුඩා අන්වර්ථ නාම සිතියමක් සම්මත නාම OmniRoute අභ්යන්තරව භාවිත කරන ප්රභේද වෙත විස්තාරණය කරයි. එම නිසා ආකෘති ඕනෑම නමක් යටතේ සොයාගත හැකිව පවතී.

### සැපයුම්කරුවෙකු ශ්රේණිගත කරන ආකාරය

සෑම නොමිලේ සැපයුම්කරුවෙකු සඳහාම, එන්ජිම එහි නාමාවලියේ සෑම ආකෘතියකටම ලකුණු ලබා දී, ඉන්පසු:

- **ඉහළම ආකෘතිය** = සැපයුම්කරුගේ වැඩිම ලකුණු ලැබූ ආකෘතිය.
- **සාමාන්ය ලකුණ** = එම සැපයුම්කරුගේ ලකුණු ලැබූ සියලු ආකෘතිවල මධ්යන්ය ලකුණ.
- **ආකෘති** = සැපයුම්කරුගේ ආකෘති අතරින් Arena ලකුණක් තිබූ ගණන.

සැපයුම්කරුවන් පළමුව **ඉහළම-ආකෘති ලකුණ** අනුවත්, ඉන්පසු සාමාන්ය ලකුණ අනුවත් අනුපිළිවෙළට සකසනු ලැබේ. මෙය අවම වශයෙන් එක් ප්රබල නොමිලේ ආකෘතියක්වත් සපයන සැපයුම්කරුවෙකුට ප්රතිලාභ ලබා දෙයි.

## නොමිලේ සපයන්නන් තෝරාගැනීමට එය භාවිත කිරීම

1. **නිවැරදි ප්රවර්ගය තෝරන්න.** නියෝජිතමය/කේත වැඩභාර සඳහා **Coding** පෙරහන භාවිත කරන්න, නැතහොත්
   සාමාන්ය කතාබස් සඳහා එය **All Categories** / **Default** ලෙස තබන්න. එක් එක් ප්රමුඛතා ලැයිස්තුවේ එහි ඉහළම මාදිලිය වෙනස් වන බැවින්, එකම සපයන්නා
   ප්රවර්ග අතර වෙනස් ලෙස ශ්රේණිගත විය හැක.
2. **එක්වරක් පමණක් සකසන වින්යාස සඳහා ඉහළම ස්ථාන තුනට ප්රමුඛත්වය දෙන්න.** ඔබට සම්බන්ධ කිරීමට අවශ්ය වන්නේ නොමිලේ
   සපයන්නන් එක් අයෙකු හෝ දෙදෙනෙකු පමණක් නම්, ඔබේ ප්රවර්ගයේ ඉහළම ශ්රේණිගත සපයන්නන්ගෙන් ආරම්භ කරන්න.
3. **Type ලාංඡනය පරීක්ෂා කරන්න.** `NOAUTH` සපයන්නන් සම්බන්ධ කිරීමට වේගවත්ම ඒවාය (අක්තපත්ර
   අවශ්ය නොවේ). `OAUTH` / `APIKEY` නොමිලේ ස්තර සඳහා ඉක්මන් ලියාපදිංචියක් අවශ්ය වුවද, ඒවා බොහෝ විට
   වඩා ප්රබල මාදිලි ලබා දෙයි. සම්බන්ධ කිරීමේ පියවර සඳහා [නොමිලේ ස්තර මාර්ගෝපදේශය](../getting-started/FREE-TIERS-GUIDE.md) බලන්න.
4. **කිහිපයක් සම්බන්ධ කර Auto-Combo හට තීරණය කිරීමට ඉඩ දෙන්න.** මෙම පිටුව බලගන්වන එම Arena ELO දත්තම
   Auto-Combo ලකුණුකරණ එන්ජිමේ **කාර්ය-යෝග්යතා සාධකය** සඳහාද භාවිත වේ
   (`open-sse/services/autoCombo/taskFitness.ts`, නිරාකරණ අනුපිළිවෙළ
   `user_override → arena_elo → models_dev_tier → static table`). එබැවින් ඉහළම නොමිලේ සපයන්නන්
   සම්බන්ධ කළ පසු, `model: "auto"` (උදා. `auto/coding`) සමඟ මාර්ගගත කිරීම මඟින්
   එක් එක් ඉල්ලීම සඳහා උසස් තත්ත්වයේ නොමිලේ මාදිලිවලට ස්වයංක්රීයව ප්රමුඛත්වය දෙනු ඇත. සම්පූර්ණ සාධක 16ක ලකුණුකරණය සඳහා
   [Auto-Combo](../routing/AUTO-COMBO.md) බලන්න.
