OmniRoute මඟින් OpenAI Codex භාවිත කිරීමට ක්රම **දෙකක්** ලබා දෙයි:

| සැපයුම්කරු             | එය OpenAI සමඟ සන්නිවේදනය කරන ආකාරය                                                                                                                                                            | භාවිතය පිළිබඳ අවවාදය                                             |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **`codex`**            | ඔබගේ ChatGPT/OpenAI OAuth ටෝකනය Responses API වෙත සෘජුවම නැවත යොමු කරයි                                                                                                                       | **ඔව්** — නිල සැසිය proxy/router භාවිතය සඳහා අවසර දී නැත         |
| **`codex-app-server`** | JSON-RPC/WebSocket හරහා **Codex CLI සතු `codex app-server`** ධාවනය කරවයි; අන්තර්ක්රියාකාරී `codex` සැසියක් මෙන්ම CLI විසින් එහි OAuth (`~/.codex/auth.json`) පාලනය කර ස්වයංක්රීයව නැවුම් කරයි | **නැත** — OmniRoute කිසිවිටෙකත් ටෝකනයක් API වෙත නැවත යොමු නොකරයි |

`codex-app-server` කිසිවිටෙකත් ටෝකනයක් නැවත යොමු නොකරන බැවින්, එයට
සැසි-නැවත-යොමු කිරීමේ භාවිත අවවාදය අදාළ නොවේ. එහෙත්, **වින්යාස කළ
app-server URL එකෙන් ළඟා විය හැකි Codex CLI එකක්** අවශ්ය වන අතර, එම CLI එකට
**පුරනය වී තිබිය** යුතුය.

## 1. නිර්මාණ ව්යුහය

```
┌─ OmniRoute යෙදුම ────────────────┐        ┌─ codex-app-server sidecar ─────────┐
│  CodexAppServerExecutor          │  WS    │  codex app-server                   │
│  ws://codex-app-server:1456 ─────┼───────▶│  --listen ws://0.0.0.0:1456         │
│  (+ හැකියා ටෝකනය)               │  JSON  │  --ws-auth capability-token         │
│                                  │  RPC   │  OpenAI OAuth ස්වයංව පාලනය කරයි    │
└──────────────────────────────────┘        │  (~/.codex/auth.json, ස්වයං-නැවුම්) │
        │ බෙදාගනී (compose volumes)          └─────────────────────────────────────┘
        ▼
  codex-appserver-token   → WS හැකියා ටෝකනය (දෙකම එය mount කරයි)
  codex-appserver-home    → ~/.codex (dashboard මඟින් auth.json ලියනු ලබන අතර,
                             sidecar හි codex app-server මඟින් කියවනු ලැබේ)
```

- sidecar එක හැකියා ටෝකනයක් පිටුපස ඇති අභ්යන්තර compose ජාලයේ
  (`ws://codex-app-server:1456`) **පමණක්** සවන් දෙයි. එය host වෙත හෝ අන්තර්ජාලයට
  **කිසිවිටෙකත්** publish නොකෙරේ.
- Codex CLI එක `omniroute:base` තුළම අන්තර්ගත කර ඇති බැවින්, sidecar එක
  ධාවනය කරන විට host එකේ හෝ පරිශීලකයාගේ යන්ත්රයේ codex ස්ථාපනය කිරීම අවශ්ය නොවේ.

## 2. එය ආරම්භ කිරීම

```bash
# codex app-server sidecar profile එක සමඟ stack එක ආරම්භ කරන්න:
docker compose --profile base --profile codex-app-server up -d
# (podman: podman compose --profile base --profile codex-app-server up -d)
```

පළමු ආරම්භයේදී sidecar එක එහි WS හැකියා ටෝකනය නිර්මාණය කරයි (හවුල්
`codex-appserver-token` volume එක තුළට), සහ යෙදුම
`OMNIROUTE_CODEX_APPSERVER_WS_TOKEN_FILE` හරහා එම ටෝකනයම කියවයි.
ටෝකනය අතින් සම්බන්ධ කිරීමක් අවශ්ය නොවේ.

## 3. සම්බන්ධ වී පුරනය වීම

1. dashboard එක තුළ **OpenAI Codex (App-Server)** සඳහා සම්බන්ධතාවක් එක් කරන්න.
   API key එකක් හෝ ටෝකනයක් අවශ්ය නොවේ (මෙය සත්යාපනය රහිත සැපයුම්කරුවෙකි —
   සත්යාපනය sidecar එක සතුය).
2. sidecar එකේ Codex CLI වෙත **තවමත් පුරනය වී නොමැති නම්**, සම්බන්ධතා සෞඛ්ය
   පරීක්ෂාව _"ධාවනය වන නමුත් පුරනය වී නැත"_ යනුවෙන් වාර්තා කරයි (රතු සත්යාපන
   දෝෂයක් ලෙස නොවේ). **Sign in with ChatGPT** භාවිත කරන්න: මෙය ඔබගේ browser එකෙහි
   සම්මත Codex device-OAuth ක්රියාවලිය ධාවනය කර, අනතුරුව **Apply auth** හරහා
   හවුල් volume එකට `~/.codex/auth.json` ලියයි (එකම පුරනය වීම `codex` සහ
   `codex-app-server` සැපයුම්කරුවන් දෙකටම සේවය කරයි).
3. පුරනය වූ පසු, සෞඛ්ය පරීක්ෂාව කොළ පැහැයට හැරී ක්රියාත්මක වීම ආරම්භ කරයි
   (එය `/readyz` **සහ** `account/read` යන දෙකම — එනම්, සේවාව ක්රියාත්මකද
   _සහ_ සත්යාපිතද යන්න — තහවුරු කරයි).

dashboard එක සෞඛ්ය සම්පන්න දැනට පවතින `~/.codex/auth.json` ගොනුවක් කිසිවිටෙකත්
මකා නැවත නොලියයි — එය ලියන්නේ ගොනුව නොමැති විට හෝ එහි ටෝකනය කල් ඉකුත් වූ විට
පමණි (සැමවිටම උපස්ථ පිටපතක් ගනු ලැබේ).

## 4. යෙදවීමේ අවස්ථා

- **දැනටමත් සත්යාපිත Codex CLI එකක් ඇති ක්රියාකරු** — ඔබගේ host එකේ
  `~/.codex` sidecar එක (`codex-appserver-home`) තුළට mount කර පුරනය වීමේ පියවර
  මඟ හරින්න.
- **පොදු පරිශීලකයෙක්, codex දේශීයව ස්ථාපනය කර නැත** — එය අදාළ නොවේ:
  sidecar එකේ CLI ඇත. පරිශීලකයා සත්යාපනය කරන්නේ dashboard එක හරහා පමණි.
