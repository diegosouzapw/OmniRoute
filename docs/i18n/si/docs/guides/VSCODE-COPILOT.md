## පිහිටුවීම

1. **OmniRoute ධාවනය කරන්න** — `npm install -g omniroute && omniroute` (`http://localhost:20128` හි dashboard එක).
2. **extension එක ස්ථාපනය කරන්න** — Extensions දසුනේ "OmniRoute" සොයන්න.
3. **මොඩලයක් තෝරන්න** — Copilot Chat → මොඩල් තේරීම්කාරකය → **Manage Models…** → **OmniRoute**, ඉන්පසු
   ඔබට අවශ්ය දෑ සලකුණු කරන්න.

OmniRoute පෙරනිමි port එකේ ධාවනය වන විට වින්යාස කිරීමට කිසිවක් නැත. දුරස්ථ instance එකක් සඳහා,
**Activity Bar හි OmniRoute නිරූපකය** විවෘත කරන්න (හෝ `OmniRoute: Manage Connection` ධාවනය කරන්න) සහ පහත දෑ සකසන්න:

- **Server URL** — server root එක, උදා. `http://192.168.0.15:20128`. `/v1` suffix එක
  extension එක මඟින් එක් කරනු ලැබේ; එය ඇතුළත් නොකරන්න.
- **API key** — server එක `REQUIRE_API_KEY` සකසා ඇති විට පමණි. VS
  Code SecretStorage හරහා OS keychain එකේ ගබඩා කරයි; කිසිවිටෙකත් `settings.json` තුළ නොවේ.

## තේරීම්කාරකයේ පෙන්වන්නේ මොනවාද

extension එක අමු `GET /v1/models` payload එක නොපෙන්වයි — එය එය සකස් කරන අතර, ඔබ දකින
ගණන catalog ප්රමාණයට වඩා අඩු වන්නේ හිතාමතාම ඇති හේතු දෙකක් නිසාය.

### එය එක් මොඩලයකට එක් id එකක් ඉල්ලයි

`MODELS_CATALOG_PREFIX_MODE` හි පෙරනිමිය **`dual`** වේ; එය සෑම මොඩලයක්ම දෙවරක් ප්රචාරය කරයි — එක් වරක්
කෙටි alias prefix එක යටතේ සහ තවත් වරක් canonical provider prefix එක යටතේ — එබැවින් පැරණි client
configs වලට ආකාර දෙකෙන් ඕනෑම එකක් තවදුරටත් resolve කළ හැකිය:

```
cc/claude-sonnet-4-6        ← alias prefix
claude/claude-sonnet-4-6    ← canonical prefix, එකම මොඩලය
```

extension එක **`GET /v1/models?prefix=alias`** ඉල්ලන බැවින්, ඔබේ අනෙකුත් clients සඳහා ඇති
server-wide සැකසුම වෙනස් නොකර එක් මොඩලයකට එක් id එකක් ලැබේ. යොමු instance එකකදී මෙය
**entries 2345 සිට 1396 දක්වා අඩු කළේය — duplicates 949ක්, අහිමි වූ මොඩල ගණන බිංදුවකි.**

ඔබ ඒ වෙනුවට _සෑම_ client එකක් සඳහාම එය server-wide ලෙස නිවැරදි කිරීමට කැමති නම්, dashboard එකේ
`MODELS_CATALOG_PREFIX_MODE` feature flag එක `alias` ලෙස සකසන්න. query parameter එක සහ
එක් එක් mode එක සඳහා වන වගුව සඳහා [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) බලන්න.

### එය chat කළ නොහැකි මොඩල සඟවයි

catalog එකේ image, video, audio, rerank, embedding සහ moderation මොඩල ද ලැයිස්තුගත වේ. ඒවා
chat request එකකදී කෙසේ වෙතත් ප්රතික්ෂේප වේ:

```
HTTP 400 — '<id>' මොඩලය image-generation මොඩලයක් වන අතර එය
/v1/chat/completions සඳහා භාවිත කළ නොහැක. ඒ වෙනුවට POST /v1/images/generations භාවිත කරන්න.
```

එබැවින් ඒවා තේරීම්කාරකයට පැමිණීමට පෙර ඒවායේ `type` field එක අනුව පෙරා ඉවත් කරනු ලැබේ. **Responses-API
මොඩල තබාගනු ලැබේ** — සෑම Codex / GPT-5.x entry එකක්ම `supported_endpoints: ["responses"]`
ප්රචාරය කරන අතර OmniRoute ඒවා `/v1/chat/completions` සඳහා පරිවර්තනය කරයි, එබැවින් ඒවා සම්පූර්ණයෙන්ම භාවිත කළ හැකිය.

### ඔබ කිසිවිටෙක වින්යාස නොකළ providers

catalog එක **active connection** එකක් ඇති providers වෙතින් වන මොඩලවලට අමතරව සෑම **noAuth**
provider එකක්ම — free tier එකේ විශාල කොටසක් සෑදෙන keyless ඒවා — ලැයිස්තුගත කරයි. එය හිතාමතාම සිදු කර ඇත. ඒවා සැඟවීමට,
dashboard settings තුළ `blockedProviders` වෙත ඒවා එක් කරන්න; extension එකේ කිසිවක් වෙනස් නොවේ.

## VS Code ටැබයක් තුළ Dashboard එක

`omnicopilot.dashboardOpen: "editor"` මඟින් OmniRoute dashboard එක බාහිර browser එකක නොව Simple Browser හරහා editor ටැබයක render කරයි. Embed කිරීම **server එකෙහි opt-in කළ යුතුය**. ඒ සඳහා `DASHBOARD_ALLOW_EMBED=vscode` භාවිත කරන අතර, එවිට default `frame-ancestors 'none'` + `X-Frame-Options: DENY` වෙනුවට `frame-ancestors 'self' vscode-webview:` සමඟ HTML පිටු serve කරයි. කෙසේ වෙතත් API පරාසය (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) සෑම අවස්ථාවකම දැඩි headers පවත්වා ගනී.

> ⚠️ **මෙය runtime flag එකක් නොව build-time flag එකකි.** Next.js විසින් `headers()` route manifest එකට compile කරන බැවින්, bundle එක build කරන අතරතුර `next.config.mjs` විසින් variable එක කියවයි
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> දැනටමත් build කර ඇති server එකක් ඉදිරියේ එය export කිරීමෙන් කිසිවක් වෙනස් නොවේ — headers build එකටම ඇතුළත් කර ඇත.

```bash
# variable එක BUILD command එකේ තිබිය යුතුය
DASHBOARD_ALLOW_EMBED=vscode npm run build        # නැතහොත් npm run build:release
npm start
```

| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |

| Docker image               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — Docker Hub හි ඇති prebuilt image එක embed කිරීම සඳහා සක්රීය කර නැත |
