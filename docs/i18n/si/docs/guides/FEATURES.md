## 🎨 සංයෝජන

පොදු ක්රමෝපායන් 19ක් සමඟ ආකෘති මාර්ගගත කිරීමේ සංයෝජන සාදන්න: ප්රමුඛතාව, බරිත, වට-මාරු, සන්දර්භ-ප්රේෂණය, පළමුව-පිරවීම, p2c (විකල්ප දෙකක බලය), අහඹු, අවම-භාවිත, පිරිවැය-ප්රශස්ත, යළි-සැකසීම-සැලකිල්ලට-ගන්නා, යළි-සැකසීමේ-කවුළුව, අතිරික්ත-ධාරිතාව, දැඩි-අහඹු, ස්වයංක්රීය, lkgp (අවසන් වරට හොඳ බව දන්නා සැපයුම්කරු), සන්දර්භ-ප්රශස්ත, හැඹිලි-ප්රශස්ත, **fusion** (ආකෘති සමූහයකට සමාන්තරව ඉල්ලීම් යවා, අනතුරුව විනිශ්චයකරුවෙකු හරහා එක් පිළිතුරක් සංශ්ලේෂණය කිරීම), සහ **pipeline**. සෑම සංයෝජනයක්ම ස්වයංක්රීය පසුබැසීම සමඟ ආකෘති කිහිපයක් දාමගත කරන අතර ඉක්මන් සැකිලි සහ සූදානම්භාව පරීක්ෂණද ඇතුළත් වේ.

මෑතකාලීන සංයෝජන වැඩිදියුණු කිරීම්:

- **ව්යුහගත සංයෝජන සාදනය** — සැපයුම්කරු, ආකෘතිය, සහ නිශ්චිත ගිණුම/සම්බන්ධතාව තේරීමෙන් එක් එක් පියවර සාදන්න
- **නැවත නැවත සැපයුම්කරුවන් භාවිතයට සහාය** — `(provider, model, connection)` ටියුපලය අනන්යව පවතින තාක්, එකම සංයෝජනයක් තුළ එකම සැපයුම්කරු කිහිප වරක් නැවත භාවිත කරන්න
- **සංයෝජන ඉලක්ක සෞඛ්යය** — විශ්ලේෂණ සහ සෞඛ්ය අතුරුමුහුණත් දැන් සියල්ල ආකෘති තන්තු බවට ඒකාබද්ධ කිරීම වෙනුවට, එක් එක් සංයෝජන ඉලක්ක/පියවර වෙන්කර හඳුනා ගනී
- **සංයුක්ත ස්තර අනුපිළිවෙළ** — `defaultTier -> fallbackTier` දැන් ඉහළ මට්ටමේ සංයෝජන පියවර සඳහා ධාවන-කාල ක්රියාත්මක කිරීමේ/පසුබැසීමේ අනුපිළිවෙළට බලපායි

- **අභිරුචි නියෝජිතයන්** — පෝරමයක් හරහා ඕනෑම CLI මෙවලමක් ලියාපදිංචි කරන්න (නම, ද්විමය ගොනුව, අනුවාද විධානය, ආරම්භක තර්ක)
- **CLI ඇඟිලි සලකුණු ගැළපීම** — ප්රොක්සි IP රැක ගනිමින් තහනම් වීමේ අවදානම අඩු කිරීම සඳහා ස්වදේශීය CLI ඉල්ලීම් අත්සන්වලට ගැළපීමට එක් එක් සපයන්නා සඳහා ටොගලයක්
- **දේශීය Devin සත්යාපනය** — Devin CLI විසින් `devin auth login` භාවිත කරයි; බ්රවුසර OAuth ප්රවාහයක් අවශ්ය නොවේ

## 🛡️ ප්රොක්සි ශක්තිමත් කිරීම _(v3.5.5+)_

සමස්ත ඉල්ලීම් නළමාර්ගය පුරා විස්තීර්ණ ප්රොක්සි වින්යාස බලාත්මක කිරීම:

- **ටෝකන සෞඛ්ය පරීක්ෂාව** — පසුබිම් OAuth නැවුම් කිරීම දැන් එක් එක් සම්බන්ධතාව සඳහා ප්රොක්සි වින්යාසය නිරාකරණය කරමින්, ප්රොක්සි අවශ්ය පරිසරවල අසාර්ථකතා වළක්වයි
- **API යතුරු වලංගුකරණය** — සැපයුම්කරු යතුරු වලංගුකරණය (`POST /api/providers/validate`) සැපයුම්කරු-මට්ටමේ සහ ගෝලීය ප්රොක්සි සැකසුම් පිළිපදිමින් `runWithProxyContext` හරහා මාර්ගගත වේ
- **undici Dispatcher නිවැරදි කිරීම** — ප්රොක්සි dispatchers, Node හි ගොඩනඟා ඇති fetch වෙනුවට undici සතු fetch ක්රියාත්මක කිරීම භාවිත කරමින්, Node.js 22 හි `invalid onRequestStart method` දෝෂ නිරාකරණය කරයි
- **Node.js අනුවාද හඳුනාගැනීම** — පිවිසුම් පිටුව නොගැළපෙන Node.js අනුවාද (24+) කල්තියා හඳුනාගෙන Node 22 LTS භාවිත කිරීමේ උපදෙස් සහිත අනතුරු ඇඟවීමේ බැනරයක් පෙන්වයි

වින්යාස බණ්ඩලය `src/lib/sync/bundle.ts` මඟින් ගොඩනඟනු ලැබේ. සම්පූර්ණ දත්ත කොටස නැවත බාගත නොකර වෙනස්කම් හඳුනා ගැනීමට පාරිභෝගිකයෝ `ETag` ප්රතිචාර ශීර්ෂය සසඳති.
