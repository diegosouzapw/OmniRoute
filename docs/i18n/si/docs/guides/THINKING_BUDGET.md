### `auto` ඉවත් කරන දෑ

ප්රකාරය `auto` වන විට, `stripThinkingConfig()` විසින් (අනෙකුත් දෑ අතර) පහත දෑ මකා දමයි:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, සහ පවතින විට `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

සේවාලාභියෙකු (උදා. Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` යවා තිබුණේ නම්, **auto එම වස්තුව ඉවත් කරයි**. ඉහළධාරා සේවාව තවමත් සමහර තර්කන ටෝකන සඳහා ගාස්තු අය කළ හැකි නමුත්, බොහෝ විට **හිස් හෝ සංකේතනය කළ පමණක් වන** තර්කන අයිතම ආපසු එවයි — එබැවින් UI එක ප්රයෝජනවත් සිතීමේ ප්රවාහයක් නොපෙන්වයි.

## දෘශ්යමාන චින්තනය (Codex / Responses සේවාලාභීන්)

සේවාලාභියෙකුට චින්තන පෙළ පෙන්වීමට පහත **සියල්ලම** අවශ්ය වේ:

1. Thinking Budget මාදිලිය = **`passthrough`** (හෝ ඔබ භාවිත කරන මාර්ගයට ප්රමාණවත් ලෙස සාරාංශ ඉල්ලීම් නොවෙනස්ව තබන custom/adaptive මාදිලියක්).
2. සේවාලාභියා සාරාංශයක් ඉල්ලා සිටිය යුතුය, උදා. Codex `model_reasoning_summary = "detailed"` / `auto` (`none` නොවේ).
3. ඉහළ-ධාරා සැපයුම්කරු සැබවින්ම `response.reasoning_summary_text.*` ප්රවාහය කළ යුතුය (හෝ අයිතමයේ හිස් නොවන `reasoning.summary` එකක් තිබිය යුතුය).

ඔබට ලැබෙන්නේ “සංකේතනය කළ පුද්ගලික තර්කනය” පමණක් නම්, එක්කෝ:

- මාදිලිය **`auto`** විය (සේවාලාභී ඉල්ලීම ඉවත් කර ඇත), හෝ
- ඉහළ-ධාරා සැපයුම්කරු සාරාංශ පෙළකින් තොරව `encrypted_content` ලබා දී ඇත (සැපයුම්කරුගේ සීමාවකි; OmniRoute හට පෙන්විය හැක්කේ ස්ථානධාරකයක් පමණි, සරල පෙළ නොවේ).

## API උදාහරණ

```bash
# කියවන්න
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Codex / Desktop හි චින්තනය දෘශ්යමාන කිරීම සඳහා නිර්දේශිතයි
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

යෝජනාක්රමය (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; විකල්ප `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### ස්ථායීතාව / නැවත ආරම්භ කිරීම

අගය `thinkingBudget` සැකසුම් යතුර යටතේ ගබඩා වන අතර ක්රියාවලිය ආරම්භයේදී (`hydrateThinkingBudgetConfig`) පූරණය වේ. DB හෝ API නොවන වෙනත් මාර්ග හරහා වෙනස් කිරීමෙන් පසු, මතකයේ ඇති singleton එක තැටියේ ඇති අගයට ගැළපෙන ලෙස **OmniRoute ක්රියාවලිය නැවත ආරම්භ කරන්න**.
