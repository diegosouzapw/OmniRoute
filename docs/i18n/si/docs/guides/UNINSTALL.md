## ඉක්මන් අස්ථාපනය (v3.6.2+)

OmniRoute පිරිසිදුව ඉවත් කිරීම සඳහා ඇතුළත් කළ ස්ක්රිප්ට් දෙකක් සපයයි:

### ඔබගේ දත්ත තබා ගන්න

```bash
npm run uninstall
```

මෙය OmniRoute යෙදුම ඉවත් කරන නමුත් `~/.omniroute/` තුළ ඇති ඔබගේ දත්ත සමුදාය, වින්යාස, API යතුරු සහ සැපයුම්කරු සැකසුම් **සුරැකේ**. ඔබ පසුව නැවත ස්ථාපනය කිරීමට සැලසුම් කරන්නේ නම් සහ ඔබගේ සැකසුම තබා ගැනීමට අවශ්ය නම් මෙය භාවිත කරන්න.

### සම්පූර්ණයෙන් ඉවත් කිරීම

```bash
npm run uninstall:full
```

මෙය යෙදුම ඉවත් කරන අතර සියලු දත්ත **ස්ථිරවම මකා දමයි**:

- දත්ත සමුදාය (`storage.sqlite`)
- සැපයුම්කරු වින්යාස සහ API යතුරු
- උපස්ථ ගොනු
- ලොග් ගොනු
- `~/.omniroute/` නාමාවලිය තුළ ඇති සියලුම ගොනු

> ⚠️ **අවවාදයයි:** `npm run uninstall:full` ක්රියාව ආපසු හැරවිය නොහැක. ඔබගේ සියලුම සැපයුම්කරු සම්බන්ධතා, සංයෝජන, API යතුරු සහ භාවිත ඉතිහාසය ස්ථිරවම මකා දමනු ඇත.

## අතින් අස්ථාපනය කිරීම

### NPM ගෝලීය ස්ථාපනය

```bash
# ගෝලීය පැකේජය ඉවත් කරන්න
npm uninstall -g omniroute

# (විකල්ප) දත්ත නාමාවලිය ඉවත් කරන්න
rm -rf ~/.omniroute
```

### pnpm ගෝලීය ස්ථාපනය

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# කන්ටේනරය නවත්වා ඉවත් කරන්න
docker stop omniroute
docker rm omniroute

# පරිමාව ඉවත් කරන්න (සියලු දත්ත මකා දමයි)
docker volume rm omniroute-data

# (විකල්ප) ඉමේජය ඉවත් කරන්න
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# කන්ටේනර් නවත්වා ඉවත් කරන්න
docker compose down

# පරිමාවන් ද ඉවත් කරන්න (සියලු දත්ත මකා දමයි)
docker compose down -v
```

### Electron ඩෙස්ක්ටොප් යෙදුම

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` විවෘත කරන්න
- නැතහොත් ස්ථාපන නාමාවලියෙන් NSIS අස්ථාපකය ධාවනය කරන්න

**macOS:**

- `/Applications` වෙතින් `OmniRoute.app` කුණු කූඩයට ඇද දමන්න
- දත්ත ඉවත් කරන්න: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage ගොනුව ඉවත් කරන්න
- දත්ත ඉවත් කරන්න: `rm -rf ~/.omniroute`

### මූලාශ්ර ස්ථාපනය (git clone)

```bash
# ක්ලෝන කළ නාමාවලිය ඉවත් කරන්න
rm -rf /path/to/omniroute

# (විකල්ප) දත්ත නාමාවලිය ඉවත් කරන්න
rm -rf ~/.omniroute
```

## දත්ත නාමාවලි

OmniRoute පෙරනිමියෙන් පහත ස්ථානවල දත්ත ගබඩා කරයි:

| වේදිකාව    | පෙරනිමි මාර්ගය                   | අතික්රමණය                       |
| ---------- | -------------------------------- | ------------------------------- |
| Linux      | `~/.omniroute/`                  | `DATA_DIR` පරිසර විචල්යය        |
| macOS      | `~/.omniroute/`                  | `DATA_DIR` පරිසර විචල්යය        |
| Windows    | `%APPDATA%/omniroute/`           | `DATA_DIR` පරිසර විචල්යය        |
| Docker     | `/app/data/` (මවුන්ට් කළ පරිමාව) | `DATA_DIR` පරිසර විචල්යය        |
| XDG-අනුකූල | `$XDG_CONFIG_HOME/omniroute/`    | `XDG_CONFIG_HOME` පරිසර විචල්යය |

## සම්පූර්ණයෙන් ඉවත් කර ඇති බව තහවුරු කරන්න

අස්ථාපනය කිරීමෙන් පසු, ඉතිරිව ඇති ගොනු කිසිවක් නොමැති බව තහවුරු කරන්න:

```bash
# ගෝලීය npm පැකේජය පරීක්ෂා කරන්න
npm list -g omniroute 2>/dev/null

# දත්ත නාමාවලිය පරීක්ෂා කරන්න
ls -la ~/.omniroute/ 2>/dev/null

# ක්රියාත්මක වන ක්රියාවලි පරීක්ෂා කරන්න
pgrep -f omniroute
```

කිසියම් ක්රියාවලියක් තවමත් ක්රියාත්මක වන්නේ නම්, එය නවත්වන්න:

```bash
pkill -f omniroute
```
