- පරීක්ෂණ/ගවේෂණ කාර්ය භාරවලදී මට්ටම 3 මුදල් ඉතිරි කරන බව සත්යාපනය කරන්න

## පොදු රටා

### සම්පූර්ණයෙන් නොමිලේ කාර්ය භාරයක්

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

මට්ටම 3 වෙත දැඩි ලෙස යොමු කරයි; මට්ටම 3 නොමැති නම් පමණක් මට්ටම 2 භාවිත කරයි.

### අඩු වියදම් fallback එකක් සහිත දායකත්වයට-ප්රමුඛත්වය දීම

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

මට්ටම 1 → මට්ටම 2 → මට්ටම 3 සමඟ ගැළපෙන පැහැදිලි අනුපිළිවෙළක් සහිත ලැයිස්තුවකි.
