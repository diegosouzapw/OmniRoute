සමහර සේවා OmniRoute වෙත ඒකාබද්ධ කර පසුව ඒවා ක්රියාත්මක කරන පුද්ගලයන්ගේ ඉල්ලීම මත ඉවත් කරන ලදී. මෙම පිටුව එම ඉවත් කිරීම් පිළිබඳ ස්ථිර වාර්තාවයි. එහි එකම අරමුණ වන්නේ ඒවා අහම්බෙන් නැවත එක් වීම වැළැක්වීමයි: පැරණි fork එකක්, cache කළ npm
tarball එකක්, සංරක්ෂිත issue එකක් හෝ "provider X ප්රතිසාධනය කරන්න" යන ඉල්ලීමක් සොයාගන්නා දායකයෙකුට **නැවත හඳුන්වා නොදෙන්න** යැයි සඳහන් එක් ස්ථානයක් අවශ්ය වේ.

මෙම පිටුව අක්රිය හෝ නවතා දැමූ සේවා ලැයිස්තුවක් **නොවේ**. ඒවා
[`FREE_TIERS.md`](FREE_TIERS.md) ("ඉවත් කරන ලදී / නොමිලේ ස්තරයක් නැත") තුළ නිරීක්ෂණය කරන අතර සේවාව නැවත පැමිණියහොත් ඒවාද නැවත පැමිණිය හැකිය.
පහත ඇතුළත් කිරීම් නැවත එක් කළ හැක්කේ ඉල්ලීමේ නම් කර ඇති ක්රියාකරුගේ ලිඛිත අවසරය ඇතිව පමණක් වන අතර, එම අවසරයට අදාළ සබැඳිය ඇතුළත් කිරීමෙන් ලබා දිය යුතුය.

## ප්රතිපත්තිය

1. **සේවා ක්රියාකරුවෙකුගෙන් ලැබෙන ඉවත් කිරීමේ ඉල්ලීමකට ගරු කරනු ලැබේ; එය සාකච්ඡා නොකෙරේ.** OmniRoute කිසිදු upstream සේවාවකට අනුබද්ධ නොවේ. සේවාවක ක්රියාකරු එහි ඒකාබද්ධ කිරීම ඉවත් කරන ලෙස ඉල්ලා සිටින විට, එම ඒකාබද්ධ කිරීම නිල API එකක් භාවිත කළේද නැද්ද යන්න නොසලකා එය ඉවත් කෙරේ.
2. **"ඉවත් කරන ලදී" යනු OmniRoute පාලනය කරන සෑම පෘෂ්ඨයක්ම අදහස් කරයි.** Executor, registry ඇතුළත් කිරීම, provider
   id සහ alias, model ලැයිස්තුව, endpoints, environment variables, icon එක, dashboard cards,
   ජනනය කරන ලද provider reference එක, `FREE_TIERS.md`, environment reference එක, README ගණන්,
   `llm.txt` mirrors, කැපවූ tests සහ golden snapshots, code comments, CHANGELOG bullets
   (ලේඛනගත reconciliation එකක් සමඟ, `config/release/changelog-reconciliations.json` බලන්න),
   GitHub Releases notes, wiki එක, සහ එම provider එක විෂය වූ GitHub issues, discussions සහ pull requests
   (issues සහ discussions මකා දමනු ලැබේ; GitHub හට pull requests මකා දැමිය නොහැකි බැවින් pull requests නැවත නම් කර, ඒවායේ විස්තරය ප්රතිස්ථාපනය කර thread එක lock කරනු ලැබේ).
3. **ලිඛිත අවසරයකින් තොරව මෙම පිටුවේ ඇතුළත් කිරීමක් කිසිවිටෙකත් නැවත හඳුන්වා නොදෙන්න.** id හෝ alias එක කිසියම් provider catalog එකකට නැවත එක් කිරීම, domains executor එකකට එක් කිරීම, එය "ප්රතිසාධනය" කරන දායක PR එකක් පිළිගැනීම, free-model catalog එකට එය එක් කිරීම, හෝ OmniRoute හරහා එයට ප්රවේශ වීමට manual ක්රමයක් ලේඛනගත කිරීම මෙයට ඇතුළත් වේ. එවැනි PRs සහ issues මෙම පිටුවට සබැඳියක් සමඟ වසා දමන්න.
4. **ඇතුළත් කිරීම අවම වශයෙන් තබා ගන්න.** නැවත හඳුන්වා දීමක් හඳුනා ගැනීමට සමාලෝචකයෙකුට අවශ්ය දෑ පමණක් වාර්තා කරන්න: identifiers, domains, dates සහ ඉවත් කිරීම සිදු කළ pull request එක.
   ඒකාබද්ධ කිරීම ක්රියා කළ ආකාරය විස්තර නොකරන්න.
5. **Regression guard එක `tests/unit/removed-providers-blocklist.test.ts` වේ.** පහත සඳහන් කිසියම් identifier එකක් හෝ domain එකක් provider catalogs, executor map හෝ provider registry sources තුළ නැවත දිස් වූ විට එය අසමත් වේ. මෙහි row එකක් එක් කරන PR එකේම එම test එකට නව identifiers එක් කරන්න.
