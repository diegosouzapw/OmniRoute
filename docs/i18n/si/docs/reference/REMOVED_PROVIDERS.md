මෙම පිටුව මිය ගිය හෝ අත්හිටවූ සේවාවන් ලැයිස්තුවක් **නොවේ**. ඒවා [`FREE_TIERS.md`](FREE_TIERS.md) ("ඉවත් කරන ලදී / නොමිලේ ස්ථරයක් නොමැත") හි ලුහුබඳින අතර, සේවාව නැවත පැමිණියහොත් ඒවාද නැවත පැමිණිය හැක. පහත ඇති ඇතුළත් කිරීම් නැවත පැමිණිය හැක්කේ ඉල්ලීමේ නම් කර ඇති ක්රියාකරුගේ ලිඛිත අවසරය ඇතිව පමණක් වන අතර, එම අවසරය ඇතුළත් කිරීමෙන් සම්බන්ධ කළ යුතුය.
