## TL;DR — OmniRoute සැබවින්ම කොපමණ නොමිලේ inference ධාරිතාවක් ඒකාබද්ධ කරන්නේද?

මෙම සංඛ්යා මඟින් catalog එක පුරා ඇති වෙන වෙනම තෙවන පාර්ශ්ව ගිණුම් සහ සුදුසුකම් කොන්දේසි විස්තර කෙරේ. OmniRoute මෙම budget එක ප්රදානය නොකරයි: ඔබ අවශ්ය ගිණුම් හෝ credentials ලබාගෙන, සුදුසු providers සම්බන්ධ කර, ඔවුන්ගේ සීමාවලට ගරු කළ යුතුය. සුදුසු route එකක් නොමැති නව installation එකකදී ශුන්ය වීම ඇතුළුව, සැබවින්ම භාවිත කළ හැකි ධාරිතාව මීට අඩු විය හැක. `tos: avoid` ලෙස සලකුණු කර ඇති providers පෙරනිමියෙන් automatic routing වෙතින් බැහැර කර ඇත.

## අපගේ සංඛ්යාව අනෙකුත් සමුච්චයකයන්ගේ සංඛ්යාවලට වඩා කුඩා වන්නේ ඇයි

මෙම ක්ෂේත්රයේ බොහෝ "මසකට නොමිලේ ටෝකන" සංඛ්යා යනු එක් එක් මොඩලයට අදාළ ලේබලවල එකතුවකි. අපගේ සංඛ්යාව එසේ නොවේ, ඒ හිතාමතාමයි:

- **සෑම හවුල් සංචිතයක්ම ගණන් කරන්නේ එක් වරක් පමණි.** Mistral හි නොමිලේ සැලැස්ම යනු එක් සංවිධානයකට මසකට 1Bක එක් දීමනාවකි; එය මොඩල පහක් යටතේ ලැයිස්තුගත කළ පමණින් එය 5Bක් නොවේ. එක් එක් මොඩලය අනුව එකතු කළහොත්, අපගේම නාමාවලිය **~7.4B** ලෙස පෙනෙනු ඇත (2026-09-03 දින නැවත ගණනය කරන ලදී; මෙම සංඛ්යාව CI මඟින් පාලනය නොවේ — නාමාවලිය වෙනස් වන සෑම අවස්ථාවකම එය නැවත මනින්න) — ප්රධාන සංඛ්යාව **~1.47B** ලෙස දක්වන්නේ එක් එක් සැපයුම්කරුගේ එක් ගිණුමකට සැබවින්ම වැය කළ හැක්කේ එපමණක් බැවිනි.
- **දෛනික සීමා පරිවර්තනය කරනු ලැබේ, අනුපාත එසේ නොවේ.** ලේඛනගත tokens/day සීමාවක් `× 30` බවට පත් වේ; ලේඛනගත requests/day සීමාවක් `RPD × ~800 tokens × 30` බවට පත් වේ; මිනිත්තුවකට ඉල්ලීම් ගණන පමණක් ප්රකාශයට පත් කරන සැපයුම්කරුවෙකුට මාසික සංඛ්යාවක් **නොමැති** අතර, එය කිසිවිටෙක එකතුවට ඇතුළත් නොකර _uncapped_ ලෙස ලැයිස්තුගත කෙරේ. අනුපාත සීමාවක් 24/7න් ගුණ කිරීම අප ප්රතික්ෂේප කරන අතිශයෝක්තියයි.
- **කලාපීය අනන්යතා පරීක්ෂාවක් පිටුපස ඇති කෝටා වෙනම පෙන්වනු ලැබේ** (`+~6M behind regional identity verification`), මන්ද බොහෝ පාඨකයන්ට ඒවා භාවිත කළ නොහැකි බැවිනි.
- **ලියාපදිංචි වීමේ ක්රෙඩිට් පළමු මාසයට පමණක් අදාළය** සහ ඒවා ස්ථාවර සංඛ්යාවට කිසිවිටෙක මිශ්ර නොකර, දෙවන සංඛ්යාවක් ලෙස වාර්තා කෙරේ.
- **මෙම සංඛ්යාව CI මඟින් බලාත්මක කෙරේ.** `npm run check:docs-counts` නාමාවලියෙන් එකතු නැවත ගණනය කරන අතර, මෙම ගොනුව, README හෝ අයවැය කාඩ්පත එම අගයන්ගෙන් වෙනස් වූ විට build එක අසාර්ථක කරයි.

## ToS අවධානය යොමු කළ යුතු වගුව
