## ප්රවර්ග

- **නොමිලේ** — API යතුරක් සමඟ නොමිලේ භාවිත මට්ටම (උපකරණ පුවරුව හරහා වින්යාස කෙරේ)
- **සත්යාපනය අවශ්ය නැත** — යතුරක් හෝ පුරනය වීමක් කිසිසේත් අවශ්ය නොවන පොදු අන්ත ලක්ෂ්ය
- **OAuth** — OmniRoute මඟින් හසුරුවන පුරනය වීමේ ප්රවාහය; API යතුරක් අවශ්ය නොවේ
- **වෙබ් කුකිය** — කුකී සත්යාපනය හරහා සැපයුම්කරුගේ වෙබ් යෙදුම ආවරණය කරයි
- **API යතුර** — API යතුරක් හරහා වින්යාස කරන ගෙවුම් සැපයුම්කරු (නොමිලේ ණය අදාළ විය හැක)
- **දේශීය** — පරිශීලකයාගේ පරිගණකයේ ධාවනය වේ (Ollama, LM Studio, vLLM ආදිය)
- **සෙවීම** — වෙබ් සෙවුම් සැපයුම්කරුවන්
- **ශ්රව්ය** — ශ්රව්ය සඳහා පමණක් වූ සැපයුම්කරුවන් (TTS/STT)
- **ඉහළ-ධාරා ප්රොක්සිය** — වෙනත් සැපයුම්කරුවන් වෙත ප්රොක්සි කරන සැපයුම්කරුවන්
- **වලාකුළු නියෝජිතයා** — දිගු කාලයක් ක්රියාත්මක වන කේතකරණ නියෝජිතයන් (Codex Cloud, Devin, Jules)
- **පද්ධතිය** — OmniRoute හි අභ්යන්තර සැපයුම්කරුවන් (loopback ආදිය)

අමතර ටැග: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (පෙන්වා ඇති තැන්වල): `native` — සැබෑ ශ්රිත-ඇමතුම් API එකකි; `emulated` — `tools` අරාව `webTools.ts` හරහා ප්රේරකයක් ලෙස අනුකරණය කෙරේ (regex මඟින් විග්රහ කරන `<tool>{...}</tool>` කොටස්); `none` — දැනට `tools` නිහඬව ඉවත් කරනු ලැබේ. #7286 බලන්න.

එක් එක් සැපයුම්කරු සක්රීය කිරීමට, වින්යාස කිරීමට සහ පරීක්ෂා කිරීමට `/dashboard/providers` හි ඇති උපකරණ පුවරුව භාවිත කරන්න.
