OmniRoute විසින් බාහිර සැපයුම්කරුවන්ගෙන් (1proxy, proxifly, iplocate, webshare) සමමුහුර්ත කරන ලද, තෝරා සකස් කළ නොමිලේ ප්රොක්සි සමූහයක් `free_proxies` වගුව තුළ සපයයි.
උපකරණ පුවරුවේ මේවා **Settings → Free Proxies** යටතේ පෙන්වයි. මෙම ලේඛනය
ලැයිස්තු මාර්ගය මඟින් සපයන සේවාදායක-පාර්ශ්වීය පෙරහන් කිරීම, අනුපිළිවෙළට සැකසීම, ගණනය කිරීම සහ සමමුහුර්ත දෝෂ වාර්තා කිරීම
ආවරණය කරයි.

## ලැයිස්තු මාර්ගය — `GET /api/settings/free-proxies`

පෙරහන් කළ, අනුපිළිවෙළට සැකසූ, පිටුගත කළ කොටසක් සහ මුළු ගණනක් ආපසු ලබා දෙයි. පෙරහන් කිරීම සහ
ගණනය කිරීම SQL තුළ සිදුවන බැවින්, සෑම පේළියක්ම මතකයට පූරණය නොකර UI එකට සැබෑ මුළු ගණන (උදා. `Total: 0`)
පෙන්විය හැකිය.

### විමසුම් පරාමිති

| පරාමිතිය          | වර්ගය                              | පෙරනිමිය  | අර්ථය                                                                                                           |
| ----------------- | ---------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------- |
| `search`          | තන්තුව                             | `""`      | සත්කාරක (සහ මූලාශ්ර) තීරුව මත අක්ෂර විශාලත්වයට සංවේදී `LIKE` සෙවුමක්.                                           |
| `protocol`        | තන්තුව                             | `""`      | `type` පෙරහන: `http` / `https` / `socks4` / `socks5`. හිස් නම් = සියල්ල.                                        |
| `country`         | තන්තුව                             | `""`      | `countryCode` පෙරහන (ISO-2). හිස් නම් = සියල්ල.                                                                 |
| `minQuality`      | සංඛ්යාව                            | `0`       | `qualityScore >= minQuality` වන පේළි පමණි. `0` = අවම සීමාවක් නැත.                                               |
| `disabledSources` | තන්තුව                             | `""`      | බැහැර කළ යුතු කොමාවලින් වෙන් කළ මූලාශ්ර හැඳුනුම් (උදා. `proxifly,webshare`).                                    |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = ලකුණු අවරෝහණව; `latency` = ප්රමාදය ආරෝහණව (null අගයන් අවසානයේ); `recent` = `lastValidated` අවරෝහණව. |
| `offset`          | සංඛ්යාව                            | `0`       | පිටුගත කිරීමේ ආරම්භය.                                                                                           |
| `limit`           | සංඛ්යාව                            | `50`      | පිටුවේ ප්රමාණය (සේවාදායක පාර්ශ්වයෙන් උපරිමයකට සීමා කෙරේ).                                                       |

### ප්රතිචාරය

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` මඟින් පිටුගත කිරීමට **පෙර** පෙරහන් කළ මුළු ගණන නිරූපණය කරන බැවින්, UI එකට
`Total: N` සහ `hasMore` එකිනෙකින් ස්වාධීනව විදැහුම් කළ හැකිය. `syncErrors` මූලාශ්ර හැඳුනුම අනුව යතුරුගත කර ඇති අතර,
අවසන් සමමුහුර්ත කිරීම අසාර්ථක වූ මූලාශ්ර සඳහා පමණක් එය පුරවනු ලැබේ — `Total: 0` ප්රතිඵලයක්
කිසිවිටෙක නිහඬව නොපවතී.

## සමූහයට එක් කිරීම — `POST /api/settings/free-proxies/[id]/add-to-pool`

නොමිලේ ප්රොක්සියක් කළමනාකරණය කරන `proxy_registry` සමූහයට උසස් කරයි. පළමුව
උඩුගං මූලාශ්රය වලංගු කරයි; සාර්ථක වූ විට නව සමූහ ප්රොක්සි හැඳුනුම සහ මනින ලද ප්රමාදය ආපසු ලබා දෙයි.

## සමමුහුර්ත කිරීම — `POST /api/settings/free-proxies/sync`

සක්රීය කර ඇති සියලුම මූලාශ්ර (හෝ `{ "sources": [...] }` තුළ ඇති උපකොටස) නැවත ලබා ගනී. සෑම
මූලාශ්රයක්ම ස්වාධීනව සමමුහුර්ත වේ; අසාර්ථක මූලාශ්රයක් `syncErrors` තුළ සටහන් කරන අතර
අනෙක් ඒවා තවදුරටත් සම්පූර්ණ වේ. එබැවින් අර්ධ සමමුහුර්ත කිරීම් මඟින් පෙර පැවති වලංගු දත්ත කිසිවිටෙක මකා නොදමයි.

## සංඛ්යාලේඛන — `GET /api/settings/free-proxies/stats`

පේළි දත්ත නොමැතිව `total / inPool / avgQuality / bySource / lastSyncAt` සමස්තය
ආපසු ලබා දෙයි — උපකරණ පුවරුවේ ශීර්ෂ විජට් සඳහා මෙය භාවිත කරයි.
