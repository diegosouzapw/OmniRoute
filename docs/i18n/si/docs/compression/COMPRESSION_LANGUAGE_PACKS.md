## පිහිටීම

භාෂා කට්ටල පිහිටා ඇත්තේ:

```txt
open-sse/services/compression/rules/<language>/
```

දැනට සපයා ඇති කට්ටල (`rules/` නාමාවලියේ අන්තර්ගතයට සාපේක්ෂව සත්යාපනය කර ඇත):

| භාෂාව              | නාමාවලිය       | පවතින නීති ප්රවර්ග                                  |
| ------------------ | -------------- | --------------------------------------------------- |
| ඉංග්රීසි           | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ස්පාඤ්ඤ            | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| පෘතුගීසි (බ්රසීලය) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ඉන්දුනීසියානු      | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ඉතාලි              | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ජර්මානු            | `rules/de/`    | `context`, `filler`, `structural`                   |
| ප්රංශ              | `rules/fr/`    | `context`, `filler`, `structural`                   |
| ජපන්               | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **සමානතා සටහන:** `en`, `es`, `pt-BR`, `id`, සහ `it` කට්ටලවල සම්පූර්ණ ප්රවර්ග 5ම ඇත; `de`, `fr`, `ja` කට්ටල ප්රවර්ග 3ක් සමඟ සපයනු ලැබේ. නොමැති `dedup` සහ `ultra` ප්රවර්ග නිහඬව ඇතුළත් ඉංග්රීසි නීති භාවිතයට ආපසු යයි. කුඩා කට්ටල සඳහා `dedup.json` සහ `ultra.json` එක් කිරීමට දායකත්ව සාදරයෙන් පිළිගනිමු.
>
> `pt-BR` කට්ටලය Lenine Júnior විසින් නිර්මාණය කළ **[Troglodita](https://github.com/leninejunior/troglodita)** මත පදනම් වේ — බ්රසීලියානු පෘතුගීසි ව්යාකරණය සඳහා මුල සිටම නිර්මාණය කළ සම්පීඩන පද්ධතියකි (පුනරුක්ති අඩු කිරීම, PT-BR පිරවුම් පද ඉවත් කිරීම, බ්රසීලියානු සංවර්ධක ප්රජාව සඳහා තාක්ෂණික කෙටි යෙදුම්).
>
> සම්මත ප්රවර්ග ලැයිස්තුව සහ එක් එක් ප්රවර්ගයේ යෝජනා ක්රමය [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) තුළ ඇත (JSON Schema කෙටුම්පත 2020-12).

## භාෂාව හඳුනාගැනීම

`languageDetector.ts` ප්රේරක පෙළෙන් භාෂාව අනුමාන කිරීමට සැහැල්ලු හියුරිස්ටික් ක්රම භාවිත කරයි. වින්යාස කර ඇති පෙරනිමි භාෂාවට තවමත් ගරු කරන අතර, නිශ්චිත
පාලනයක් අවශ්ය වූ විට වින්යාසය හරහා හඳුනාගැනීම අක්රිය කළ හැක.

හඳුනාගැනීමේ ප්රතිදානය භාවිත කරන්නේ නීති කට්ටල තේරීමට පමණි. එය සැපයුම්කරු වෙත යොමු කිරීම, දේශීයකරණ
තේරීම හෝ UI භාෂාව වෙනස් නොකරයි.

## වින්යාස ව්යුහය

සම්පීඩන සැකසුම්වල පහත දෑ ඇතුළත් කළ හැක:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` උපකරණ පුවරුවේ/පෙරදසුනේ පෙරනිමි අගයන් පාලනය කරයි. `cavemanConfig` යනු Caveman පණිවිඩ පෙළ සම්පීඩනය කරන
විට භාවිත කරන ධාවනකාල එන්ජින් වින්යාසයයි.

## භාෂා පැකේජයක් එක් කිරීම

1. `open-sse/services/compression/rules/<language>/<pack>.json` සාදන්න.
2. `docs/compression/COMPRESSION_RULES_FORMAT.md` හි ඇති Caveman රීති ආකෘතිය භාවිත කරන්න.
3. ප්රතිස්ථාපන සීමාසහිතව තබා ගනිමින් කේත, හඳුනාගැනීම්, URLs හෝ JSON වෙනස් කිරීමෙන් වළකින්න.
4. භාෂා තේරීම සහ ප්රතිස්ථාපන හැසිරීම සඳහා පරීක්ෂණ එක් කරන්න හෝ යාවත්කාලීන කරන්න.
5. භාෂාව UI තේරීම් තුළ දිස් වන්නේ නම්, නව dashboard/i18n ලේබල නිරාවරණය කරන්න.

## API

ලබා ගත හැකි පැකේජ පහත පරිදි විමසිය හැක:

```bash
curl http://localhost:20128/api/compression/language-packs
```

පෙරදසුන් අන්ත ලක්ෂ්යය භාෂා වින්යාස අතික්රමණ පිළිගනී:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

භාෂා පැකේජ 6ටම v3.8.0 හිදී සෑම Caveman තීව්රතා මට්ටමකදීම (LITE, FULL, ULTRA) යෙදෙන `SHARED_BOUNDARIES` වගන්තියක් ලැබිණි. අවට ඇති පිරවුම් අන්තර්ගතය ඉවත් කළද, මෙම රටා කිසිදු වෙනසකින් තොරව සුරැකීමට එය එන්ජිමට උපදෙස් දෙයි:

### preservePatterns අභිරුචිකරණය කිරීම

සම්පීඩන සැකසුම් හරහා ක්රියාත්මක වන අවස්ථාවේදී අමතර රටා එක් කළ හැක:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",

      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````
