## ටැබ්

### කතාබස් ටැබය

`ChatPlayground.tsx`, බහු-වාර ප්රවාහ වැඩබංකුවක් බවට වැඩිදියුණු කරයි:

- `MarkdownMessage.tsx` හරහා පූර්ණ markdown විදැහුම්කරණය (කේත කුට්ටි, වගු, ලැයිස්තු, සබැඳි).
- හවුල් වින්යාස කවුළුවෙන් ලබාගත් පද්ධති ප්රේරකය.
- එක් එක් පණිවිඩය සඳහා ටෝකන/පිරිවැය (ප්රේරක + සම්පූර්ණ කිරීමේ ටෝකන).
- අවසන් ප්රතිචාරය නැවත ජනනය කිරීම.
- SSE ප්රවාහය සමඟ `POST /v1/chat/completions` වෙත යවයි.

### සැසඳීමේ ටැබය

ප්රොක්සියක ප්රධාන වෙනස: එක් ප්රේරකයක් **මාදිලි 4ක් දක්වා සමාන්තරව** ධාවනය කිරීම.

- තීරු 4ක් දක්වා, සෑම එකක්ම `/v1/chat/completions` වෙතින් ස්වාධීනව ප්රවාහය කරයි.
- තීරු එක් කිරීමට `+ මාදිලියක් එක් කරන්න` බොත්තම (Cmd+K කෙටිමඟ).
- `සියල්ල ධාවනය කරන්න ▶`, `Promise.all` + තීරුවකට `AbortController` එකක් මඟින් සියලු ප්රවාහ එකවර ආරම්භ කරයි.
- ගෝලීය **සියල්ල අවලංගු කරන්න** විකල්පය ක්රියාත්මක වෙමින් පවතින සෑම ප්රවාහයක්ම නවත්වයි.
- සෑම තීරුවකම `ProviderMetrics`, TTFT, TPS, ටෝකන සහ ඇස්තමේන්තුගත පිරිවැය තත්ය කාලීනව පෙන්වයි.
- ප්රමිතික **"සේවාලාභී-පාර්ශ්ව ඇස්තමේන්තුව"** (D12) ලෙස ලේබල් කර ඇත — පළමු SSE කොටසේ සිට මනිනු ලැබේ.

### API ටැබය

ප්රබල පරිශීලකයන් සඳහා මුල් Monaco සංස්කාරකය 100%ක් සුරකියි (D14):

- අන්ත ලක්ෂ්ය 10ක්: කතාබස් සම්පූර්ණ කිරීම්, සම්පූර්ණ කිරීම්, embeddings, රූප, ශ්රව්ය, කථනය, පිටපත් කිරීම්, මධ්යස්ථකරණ, නැවත ශ්රේණිගත කිරීම, සෙවීම.
- බහුමාධ්ය ගොනු උඩුගත කිරීම.
- තත්ය කාලීන ප්රතිදානය සහිත SSE ප්රවාහය.
- `ApiTab.tsx` ලෙස ආවරණය කර ඇත (අවශ්ය විට පූරණය කෙරේ, `ssr: false`).

### ගොඩනැගීමේ ටැබය

මෙවලම්/ශ්රිත ඇමතීම සහ ව්යුහගත ප්රතිදාන UI:
