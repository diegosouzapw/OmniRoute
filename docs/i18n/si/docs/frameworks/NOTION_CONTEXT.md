## මෙය කුමක්ද

OmniRoute හට **Notion** වැඩබිමකට **සන්දර්භ මූලාශ්රයක්** ලෙස සම්බන්ධ විය හැක — එනම්,
ගොඩනඟා ඇති MCP සේවාදායකය හරහා නියෝජිතයන් ප්රවේශ වන කියවිය/ලිවිය හැකි දැනුම් පදනමකි.
Notion ඒකාබද්ධ කිරීමේ ටෝකනයක් වින්යාස කළ පසු, MCP මෙවලම් මඟින් LLM එකකට පිටු සහ
දත්ත සමුදා සෙවීමට, පිටු අන්තර්ගතය සහ බ්ලොක් වෘක්ෂ කියවීමට, පෙරහන්/අනුපිළිවෙළ සැකසීම්
සමඟ දත්ත සමුදා විමසීමට සහ නව බ්ලොක් එක් කිරීමට ඉඩ ලැබේ — මේ සියල්ල OmniRoute හරහා
ප්රොක්සි කරනු ලබන බැවින් (නැවත උත්සාහ කිරීම, කාල සීමාව සහ දෝෂ වර්ගීකරණය සමඟ),
ආකෘතිය කිසිවිටෙකත් Notion API වෙත සෘජුව ප්රවේශ නොවේ.

මෙම ඒකාබද්ධ කිරීම නිල Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) මත ඇති සැහැල්ලු, සවිමත් කළ
ආවරණයකි. සේවාලාභියා (`src/lib/notion/api.ts`) පහත දෑ එක් කරයි:

- `429` සහ `5xx` සඳහා **ඝාතීය ප්රමාදයක් සමඟ නැවත උත්සාහ කිරීම** (උත්සාහ 3ක් දක්වා).
- `AbortController` හරහා **තත්පර 55ක ඉල්ලීම් කාල සීමාවක්**.
- **ටයිප් කළ දෝෂ වර්ගීකරණය** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  ඉඟි පිළිපදියි), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- මතුපිටට පෙන්වීමට පෙර ස්ටැක් ට්රේස් වැනි කොටස් ඉවත් කරන **පණිවිඩ පිරිසිදු කිරීම**.

## පිහිටුවීම

Notion ටෝකනය සඳහා **පරිසර විචල්යයක් නොමැත** — එය
`src/lib/db/notion.ts` හරහා SQLite `key_value` වගුවේ (namespace `notion`, key
`integration_token`) ගබඩා කෙරේ. Endpoint උපකරණ පුවරුවේ **Context Sources** ටැබයෙන්
(`ObsidianSourceCard` හි සහෝදර `NotionSourceCard`), හෝ සැකසුම් REST API හරහා එය
වින්යාස කරන්න.

> [!NOTE]
> මෙම ටෝකනය **Notion අභ්යන්තර ඒකාබද්ධ කිරීමේ ටෝකනයකි**. ඒකාබද්ධ කිරීමක්
> <https://www.notion.com/my-integrations> හි සාදා, අනතුරුව OmniRoute වෙත ප්රවේශ වීමට
> අවශ්ය පිටු/දත්ත සමුදා එම ඒකාබද්ධ කිරීම සමඟ බෙදාගන්න (Notion හි අවසර ආකෘතිය
> වැඩබිම පුරා ක්රියාත්මක වන එකක් නොව, බෙදාගැනීම මත පදනම් වූවකි).

### REST හරහා වින්යාස කිරීම

```bash
# ඒකාබද්ධ කිරීමේ ටෝකනය සුරකින්න + වලංගු කරන්න (POST මඟින් පරීක්ෂණ සෙවුමක් නිකුත් කර වලංගු කරයි)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# සම්බන්ධතා තත්ත්වය පරීක්ෂා කරන්න
curl http://localhost:20128/api/settings/notion

# විසන්ධි කරන්න (ගබඩා කළ ටෝකනය ඉවත් කරයි)
curl -X DELETE http://localhost:20128/api/settings/notion
```

ක්රම තුනටම උපකරණ පුවරු සත්යාපනය (`isAuthenticated`) අවශ්ය වේ. `POST` මත,
OmniRoute ටෝකනය සුරකිමින් වහාම ප්රතිඵල 1ක පරීක්ෂණ සෙවුමක් ධාවනය කරයි; Notion
දෝෂ වස්තුවක් ලබා දුනහොත් ටෝකනය ඉවත් කර ඇමතුම `400` සමඟ අසාර්ථක වේ.

| `notion_append_blocks`       | `write:notion` | පවතින බ්ලොක් එකකට හෝ පිටුවකට අනුබ්ලොක් එක් කරයි (ඉල්ලීමකට උපරිම බ්ලොක් 100ක්).             |

### ආදාන පරාමිති

- `notion_search` — `query` (අක්ෂර 1–500), `pageSize` (1–100, පෙරනිමිය 20),
  `startCursor` (විකල්ප).
- `notion_get_page` — `pageId` (අක්ෂර 32ක hex හෝ UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, පෙරනිමිය 50),
  `startCursor` (විකල්ප).
- `notion_query_database` — `databaseId`, `filter` (විකල්ප, Notion පෙරහන් ආකෘතිය),
  `sorts` (විකල්ප අරාව), `pageSize` (1–100, පෙරනිමිය 50), `startCursor` (විකල්ප).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (බ්ලොක් වස්තු අරාව),
  `after` (විකල්ප පිහිටීම).

### විෂය පථ

කියවීමේ මෙවලම් සඳහා `read:notion` ද, ලිවීමේ මෙවලම සඳහා `write:notion` ද අවශ්ය වේ.
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` වූ විට පමණක්
`open-sse/mcp-server/server.ts` තුළ ඇති `withScopeEnforcement()` මඟින් විෂය පථ
බලාත්මක කරනු ලැබේ; අමතන්නාට අවසර ඇති විෂය පථ `OMNIROUTE_MCP_SCOPES`
(කොමාවෙන් වෙන් කළ) වෙතින් හෝ සත්යාපිත API යතුරේ විෂය පථ සන්දර්භයෙන් පැමිණේ.
සම්පූර්ණ විෂය පථ ආකෘතිය සඳහා [MCP-SERVER.md](./MCP-SERVER.md) බලන්න.

## භාවිත අවස්ථා

- **දැනුම මත පදනම් වූ පිළිතුරු** — පිළිතුරු සැපයීමට පෙර නියෝජිතයෙකුට වැඩබිම තුළ `notion_search` කර
  හොඳම ප්රතිඵලය `notion_get_page` කිරීමට ඉඩ දෙන්න, එවිට ප්රතිචාර සැබෑ අභ්යන්තර ලේඛන උපුටා දක්වයි.
- **දත්ත සමුදාය මත පදනම් වූ කාර්ය ප්රවාහ** — පෙරහන් + අනුපිළිවෙළ සමඟ කාර්ය/CRM දත්ත සමුදායක්
  `notion_query_database` කර, පසුව පේළි සාරාංශ කරන්න හෝ ප්රමුඛතා අනුව වර්ග කරන්න.
- **ආපසු ලිවීම / ලොග් කිරීම** — රැස්වීම් සටහන්, ධාවන
  සාරාංශ, හෝ නියෝජිත ප්රතිදානය පවතින පිටුවකට එක් කිරීමට `notion_append_blocks` භාවිත කරන්න (අගට එක් කිරීම පමණි; විනාශකාරී සංස්කරණ නොමැත).
- **ව්යුහය ගවේෂණය** — පිටුවක බ්ලොක් ගස තුළ ගමන් කිරීමට `notion_list_block_children`,
  හෝ විමසීමට පෙර දත්ත සමුදායක ගුණාංග යෝජනා ක්රමය සොයා ගැනීමට `notion_get_database` භාවිත කරන්න.
