## මෙය කුමක්ද

Local Corpus මඟින් ක්රියාකරුට පැහැදිලිව අනුමත කළ පෙළ ගොනු නාමාවලියක්
OmniRoute හි MCP සේවාදායකයට ප්රවේශ කළ හැක. ගොනු ඒවායේ මුල් නාමාවලියෙහිම පවතී: OmniRoute විසින්
SQLite තුළ ගබඩා කරන්නේ සම්මත මූල මාර්ගය පමණක් වන අතර, මතකය තුළ සෙවුම් දර්ශකයක් පවත්වාගෙන යයි. එය
කෝපස් අන්තර්ගතය කේත ගබඩාවට හෝ දත්ත සමුදායට පිටපත් නොකරයි.

දර්ශක නැවුම් කිරීම වර්ධක ආකාරයෙන් සිදු වේ. වෙනස් නොවූ ගොනු ඒවායේ ප්රමාණය සහ වෙනස් කළ
වේලාව මත පදනම්ව නැවත භාවිත කරයි, වෙනස් වූ ගොනු යළි කියවා SHA-256 මඟින් හැෂ් කරයි, සහ මකා දැමූ ගොනු ඉවත් කරයි.
සෙවීමේදී තත්පර 30කට වඩා පැරණි දර්ශකයක් නැවුම් කරයි; ඇමතුම්කරුවන්ට වහාම
නැවුම් කිරීමක් ද ඉල්ලා සිටිය හැක.

## මූලාශ්රය වින්යාස කරන්න

සැකසුම් මාර්ගයට අනෙකුත් සැකසුම් API සඳහා භාවිත කරන කළමනාකරණ සත්යාපනයම අවශ්ය වේ.
ඉදිරිපත් කරන මාර්ගය දැනටමත් පැවතිය යුතු අතර එය නිරපේක්ෂ නාමාවලි මාර්ගයක් විය යුතුය.

```bash
# අනුමත නාමාවලියක් සම්බන්ධ කරන්න
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# වින්යාසය සහ දර්ශක තත්ත්වය පරීක්ෂා කරන්න
curl http://localhost:20128/api/settings/local-corpus

# මූලාශ්ර ගොනු වෙනස් නොකර විසන්ධි කරන්න
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP මෙවලම්

## මෙහෙයුම් සටහන්

- වින්යාස කළ මූලය වෙනස් කිරීම හෝ මකා දැමීම හවුල් මතකස්ථ දර්ශකය හිස් කරයි.
- ක්රියාවලි නැවත ආරම්භයක් මඟින් දර්ශකය ඉවත දමයි; ඊළඟ සෙවීමේදී එය වින්යාස කළ
  මූලාශ්රයෙන් යළි ගොඩනඟයි.
- `local_corpus_status` ස්කෑන් කිරීමක් බලහත්කාරයෙන් සිදු නොකරයි. වහාම යළි ස්කෑන් කිරීමක් අවශ්ය විට
  `refresh: true` සමඟ `local_corpus_search` භාවිත කරන්න.
- ස්කෑන් සහ කියවීම් අසාර්ථකතා ගණනය කරනු ලැබේ හෝ පිරිසිදු කළ දෝෂ ලෙස ආපසු ලබා දෙයි; මූලාශ්ර ගොනු
  කිසිවිටෙක වෙනස් නොකරයි.
