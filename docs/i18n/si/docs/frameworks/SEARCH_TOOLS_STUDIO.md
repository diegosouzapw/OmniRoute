## ටැබ්

### සෙවුම් ටැබය

පවතින `SearchForm` + `ResultsPanel` + `RerankPanel` ටැබයක් බවට වැඩිදියුණු කරයි:

- විමසුම → ප්රතිඵල (මාතෘකාව, URL, සාරාංශ කොටස, අදාළතා ලකුණ).
- වින්යාස කවුළුවේ සැපයුම්කරුගේ පාරදත්ත (පිරිවැය, කෝටාව, තත්ත්වය).
- නැවත ශ්රේණිගත කිරීමේ කොටස: නැවත ශ්රේණිගත කිරීමේ ආකෘතියක් තෝරා ප්රතිඵල නැවත අනුපිළිවෙළට සකසා `positionDelta` පෙන්වයි.
- සෙවුම් සැපයුම්කරුවන් කිසිවෙකු වින්යාස කර නොමැති විට CTA එකක් සහිත හිස් තත්ත්වයක්.
- `SearchHistory.tsx` හරහා සෙවුම් ඉතිහාසය.
- `POST /v1/search` අමතයි (පවතින අන්ත ලක්ෂ්යය, වෙනස්කම් නොමැත).

### දත්ත උකහා ගැනීමේ ටැබය

`POST /v1/web/fetch` හරහා URL එකකින් අන්තර්ගතය උකහා ගැනීම සඳහා නව ටැබයක් (සැලැස්ම 05 තුළ සාදන ලදී):

- ආදානය: URL + සම්පූර්ණ පිටුව ටොගලය + ආකෘති තේරීම (markdown / පෙළ / HTML).
- ඉදිරිපත් කිරීම → ලබා ගැනීම → `ScrapeResult.tsx` විදැහුම්කරණය.
- `ScrapeResult` මඟින් markdown පෙරදසුනක් + අමු දත්ත ටොගලයක් විදැහුම් කරයි.
- සීමාව: ප්රතිචාර අන්තර්ගතය **256 KB** ඉක්මවන්නේ නම්, UI එක `(කප්පාදු කරන ලදී, අමු දත්ත බලන්න)` පෙන්වා අමු දත්ත Monaco මාදිලි කවුළුවක විවෘත කරයි (D21).
- පාරදත්ත කවුළුව: සැපයුම්කරු (firecrawl/jina-reader/tavily-search/tinyfish/nimble-search/anysearch-search), ප්රමාදය, පිරිවැය, ප්රතිචාර ප්රමාණය, සබැඳි ගණන.
- `useScrapeFetch.ts` හුකය භාවිත කරයි.

### සැසඳීමේ ටැබය

එකම විමසුම/URL එක සැපයුම්කරුවන් **4 දෙනෙකු දක්වා සමාන්තරව** ක්රියාත්මක කරයි (D22):

- එක් එක් සැපයුම්කරු සඳහා පැත්තෙන් පැත්තට තීරු.
- මිනුම්: ප්රමාදය, පිරිවැය, ප්රතිඵල ගණන, ප්රතිචාර ප්රමාණය.
- සෙවීම සඳහා URL අතිච්ඡාදන ගණනය (මුල් ප්රතිඵලයට සාපේක්ෂව හවුල් URL ගණන).
- එක් එක් සැපයුම්කරු සඳහා `POST /v1/search` (සෙවීම) හෝ `POST /v1/web/fetch` (දත්ත උකහා ගැනීම) අමතයි.

## සපයන්නන්ගේ නාමාවලිය

අක්තපත්ර පවතින්නේද සහ සියලු යතුරු දැනට cooldown තත්ත්වයේ පවතින්නේද යන්න පරීක්ෂා කිරීමෙන්,
තත්ත්වය **ඉල්ලීම සිදු කරන අවස්ථාවේදී ව්යුත්පන්න කෙරේ**.

## Backend වෙනස්කම්

මෙම විශේෂාංගය සඳහා අවශ්ය වූයේ එක් backend වෙනසක් පමණි:

### පුළුල් කළ `GET /api/search/providers`

`src/app/api/search/providers/route.ts` පහත පරිදි පුළුල් කරන ලදී:

- fetch සපයන්නන් 6 දෙනාම (`firecrawl`, `jina-reader`, `tavily-search`, `tinyfish`, `nimble-search`, `anysearch-search`) array එකට ඇතුළත් කිරීම.
- සෑම අයිතමයකටම `kind: "search" | "fetch"` එක් කිරීම.
- සජීවී අක්තපත්ර තත්ත්වයෙන් ව්යුත්පන්න කළ `status: "configured" | "missing" | "rate_limited"` එක් කිරීම.
- පසුගාමී අනුකූලතාව පවත්වා ගැනීම — පවතින ක්ෂේත්ර (`id`, `name`, ආදිය) නොවෙනස්ව පවතී.
