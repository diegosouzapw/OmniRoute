## ගෘහනිර්මාණය

```text
Claude Code 2.1.258 (හුදකලා non-root Linux container එක)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-format, no-auth provider)
  -> devin acp --agent-type summarizer (නිල ACP stdio, Devin tools නොමැත)
  -> කැප වූ devin-auth volume එක තුළ Devin account එක
```

## හුදකලාව සහ තර්ජන ආකෘතිය

තහනම් ලෙස සලකනු ලැබේ. Compose services:

- UID/GID `10001:10001` ලෙස, read-only root filesystem එකක්, ඉවත් කළ capabilities, සහ
  `no-new-privileges` සමඟ ධාවනය වේ;
- private `/home/bridge` එකක්, කැප වූ Claude config volume එකක්, හුදකලා OmniRoute data,
  සහ වෙනම `devin-auth` volume එකක් භාවිත කරයි;
- තාවකාලික `.sandbox` workspaces/evidence පමණක් mount කරයි;
- host home, Keychain, SSH, cloud credentials, හෝ Docker socket එක mount නොකරයි;
- පැහැදිලි environments සාදා Anthropic API/OAuth/routing variables ඉවත් කරයි;
- local-only key එකක් සමඟ Claude Code inference එක `http://omniroute:20128` වෙත පමණක් යොමු කරයි.

Offline profile එක internal network එකක් භාවිත කරයි. Live profile එකේදී, OmniRoute නිල
Devin endpoints වෙත ළඟා වන්නේ `network-guard` හරහා පමණි; සම්බන්ධ නොවන destinations ප්රතික්ෂේප කෙරේ.

```bash
./scripts/devin-bridge/launch
```

`launch` විසින් container තුළ ක්රියාත්මක වන Claude Code ආරම්භ කිරීමට පෙර හුදකලා කිරීම, Devin සත්යාපනය සහ model සොයාගැනීම නැවත පරීක්ෂා කරයි. එය කිසිවිටෙක host එකේ Claude executable එක ධාවනය නොකරයි. Model aliases `.env.devin-bridge` තුළ සැකසිය හැක; වින්යාස කළ සෑම අගයකම `devin-cli-agentic/` prefix එක පවත්වාගත යුතුය.

## වලංගුකරණ commands

ප්රතිනිෂ්පාදනය කළ හැකි offline මාර්ගයට Devin account එකක් අවශ්ය නොවන අතර runtime Internet සම්බන්ධතාවක්ද නොමැත:

ACP sessions එකවර විශාල සංඛ්යාවකින් විවෘත කිරීම වළක්වා ගැනීම සඳහා live runner එක scenarios අතර රැඳී සිටින අතර, පෙළමය ප්රකාශ විශ්වාස කිරීම වෙනුවට ව්යුහගත Claude stream events වලංගු කරයි. එහි scenarios තුනෙන් පහත දෑ සනාථ කරයි:

2. සැබෑ `Edit` එකක්, client සතු `Bash` `npm test` එකක් සහ terminal ප්රතිඵලයක්;
3. `/bridge-check` සහ `bridge-proof` සොයාගැනීම, project එක කියවීම, තවත් සාර්ථක client සතු `npm test` එකක් සහ ඉතිරිව ඇති වැඩ නොමැතිව සම්පූර්ණ කිරීම.

අවසාන gate එක Devin network audit එකද පරීක්ෂා කරන අතර Claude egress audit එක හිස්ව පැවතීම අවශ්ය කරයි.
