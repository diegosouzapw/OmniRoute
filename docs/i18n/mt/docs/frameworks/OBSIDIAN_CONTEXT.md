## X’inhu

OmniRoute jikkonnettja ma’ vault ta’ **Obsidian** bħala **sors ta’ kuntest** — bażi lokali
ta’ għarfien f’Markdown li l-aġenti jaqraw u jiktbu fiha permezz tas-server MCP integrat.
L-integrazzjoni tikkomunika mal-plugin tal-komunità **Obsidian Local REST API** li jkun qed
jaħdem fl-applikazzjoni tad-desktop, sabiex l-aġenti jkunu jistgħu jfittxu fin-noti,
jaqraw/jiktbu/japplikaw patches għall-fajls, jelenkaw il-vault, jaħdmu b’noti perjodiċi
ta’ kuljum/kull ġimgħa, jimmaniġġjaw it-tags, iħaddmu kmandi ta’ Obsidian, u
(fakultattivament) jikkoordinaw sinkronizzazzjoni bidirezzjonali tal-vault bejn
id-desktop u l-mobile.

Il-klijent (`src/lib/obsidian/api.ts`) jipprovdi saff fuq il-Local REST API b’dawn
il-karatteristiċi:

- **Tentattivi mill-ġdid b’dewmien progressiv** għal żbalji temporanji `5xx`, u
  **timeout ta’ 30 sekonda** permezz ta’ `AbortController`.
- **Klassifikazzjoni tipizzata tal-iżbalji** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Ħjiel ċar li “Obsidian ma jistax jintlaħaq”** li jiġbed l-attenzjoni għall-iżball
  komuni tal-port (HTTP fuq `27123`, **mhux** l-endpoint MCP fuq `27124`) u għall-format
  ta’ Tailscale.
- **Kodifikazzjoni tal-paths** relattivi għall-vault sabiex il-paths tan-noti bi spazji
  jew slashes ikunu sikuri.

## Konfigurazzjoni

Ma hemm **l-ebda varjabbli tal-ambjent** għat-token jew għall-URL bażi ta’ Obsidian —
it-tnejn jinħażnu fit-tabella SQLite `key_value` (namespace `obsidian`) permezz ta’
`src/lib/db/obsidian.ts`. It-token ikun **ikkriptat waqt il-ħażna** (AES-256-GCM, b’għażla
ta’ kompatibbiltà retroattiva għal plaintext). Ikkonfigura mit-tab **Context Sources**
tad-dashboard tal-Endpoint (`ObsidianSourceCard`), jew permezz tal-API REST tas-settings.

> [!IMPORTANT]
> Il-plugin **Obsidian Local REST API** irid ikun installat u qed jaħdem. L-interfaċċa
> REST tiegħu tisma’ fuq **HTTP `127.0.0.1:27123`** (il-URL bażi predefinit). Il-port
> `27124` huwa endpoint MCP/HTTPS _separat_ u jiġi espliċitament miċħud mir-route
> tas-settings. Jekk qed tikkonnettja minn apparat ieħor, uża
> `http://<tailscale-ip>:27123`.

### Ċwievet tal-konfigurazzjoni (SQLite `key_value`, namespace `obsidian`)

| Ċavetta           | Għan                                                                   | Ikkriptata |
| ----------------- | ---------------------------------------------------------------------- | ---------- |
| `api_key`         | Token bearer tal-Local REST API                                        | iva        |
| `base_url`        | URL bażi REST (predefinit `http://127.0.0.1:27123`)                    | le         |
| `vault_path`      | Path assolut għad-direttorju tal-vault (għas-sinkronizzazzjoni)        | le         |
| `webdav_username` | Username WebDAV iġġenerat (sinkronizzazzjoni tal-vault)                | le         |
| `webdav_password` | Password WebDAV iġġenerata (sinkronizzazzjoni tal-vault)               | iva        |
| `webdav_enabled`  | Jekk is-sinkronizzazzjoni tal-vault permezz ta’ WebDAV hijiex attivata | le         |

### Ikkonfigura permezz ta’ REST

```bash
# Issejvja + ivvalida t-token tal-Local REST API (POST jivvalidah permezz ta’ verifika tal-istatus)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Ivverifika l-istatus tal-konnessjoni (jirritorna connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Skonnettja (ineħħi t-token maħżun)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Il-metodi kollha jeħtieġu awtentikazzjoni tad-dashboard. `POST` jiċħad kwalunkwe URL
fuq il-port `27124` u jivvalida t-token billi jsejjaħ l-endpoint tal-istatus tal-Local
REST API qabel ma jippersistih.

### Sinkronizzazzjoni tal-vault permezz ta’ WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` jimmaniġġja sinkronizzazzjoni
fakultattiva tal-vault appoġġjata minn WebDAV (imħaddma minn
`src/lib/obsidianSync.ts`). Meta tiġi attivata, tidderieġi lil OmniRoute lejn direttorju
lokali tal-vault u tiġġenera par każwali ta’ username/password għal WebDAV:

```bash
# Attiva s-sinkronizzazzjoni WebDAV għal direttorju tal-vault (tiġġenera username/password)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Ikseb l-istatus tas-sinkronizzazzjoni WebDAV (il-kredenzjali jintbagħtu lura biss waqt li tkun attivata)
curl http://localhost:20128/api/settings/obsidian/webdav

# Iddiżattiva s-sinkronizzazzjoni WebDAV (ineħħi l-kredenzjali + il-fajl .stignore ġestit)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Sors ta’ kuntest għal kull API key (fakultattiv)

Il-konfigurazzjoni ta’ Obsidian tista’ tiġi limitata **għal kull API key** permezz
tat-tabella `api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Meta
sejħa MCP tinkludi id awtentikat ta’ API key, `getObsidianConfigForApiKey()` jippreferi
t-token/URL bażi/path tal-vault ta’ dik iċ-ċavetta stess (`source: "api_key"`) u,
jekk ma jkunx hemm, juża l-konfigurazzjoni globali (`source: "global"`).

## Għodod MCP (22)

Definiti f’`open-sse/mcp-server/tools/obsidianTools.ts`. It-token/URL bażi jiġu riżolti
għal kull sejħa (l-ewwel skont iċ-ċavetta API, imbagħad globalment). Għodod li jaċċessaw is-**server tas-sinkronizzazzjoni**
ta’ OmniRoute (l-erba’ għodod `obsidian_sync_*`) jeħtieġu wkoll it-token tal-awtentikazzjoni tas-sinkronizzazzjoni kkonfigurat
fis-settings ta’ OmniRoute.

### Għodod tal-qari (`read:obsidian`)

| Għodda                       | Deskrizzjoni                                                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Iċċekkja jekk il-Local REST API hijiex aċċessibbli u awtentikata.                                                                            |
| `obsidian_search_simple`     | Tiftix fit-test sħiħ tal-kontenut tan-noti; jirritorna siltiet bil-mogħdijiet tal-fajls.                                                     |
| `obsidian_search_structured` | Fittex billi tuża espressjoni JSON Logic (filtri and/or/regex/path).                                                                         |
| `obsidian_read_note`         | Aqra nota permezz ta’ mogħdija relattiva għall-vault; b’mod fakultattiv intestatura/blokka/frontmatter speċifiċi.                            |
| `obsidian_list_vault`        | Elenka l-fajls u d-direttorji fil-vault (siġra ta’ entrati).                                                                                 |
| `obsidian_get_document_map`  | Ikseb l-istruttura tal-intestaturi tan-nota bħala mappa ta’ intestaturi → numri tal-linji.                                                   |
| `obsidian_get_note_metadata` | Ikseb il-frontmatter, it-tags, il-links, u l-għadd ta’ karattri/kliem mingħajr il-kontenut sħiħ.                                             |
| `obsidian_get_active_file`   | Ikseb il-mogħdija + il-kontenut tal-fajl attiv bħalissa f’Obsidian.                                                                          |
| `obsidian_get_periodic_note` | Ikseb in-nota perjodika ta’ kuljum/kull ġimgħa/kull xahar għal data (illum jekk titħalla barra).                                             |
| `obsidian_get_tags`          | Elenka t-tags kollha tal-vault bil-frekwenzi tagħhom.                                                                                        |
| `obsidian_list_commands`     | Elenka l-IDs tal-kmandi disponibbli ta’ Obsidian (uża ma’ `obsidian_execute_command`).                                                       |
| `obsidian_sync_status`       | Status tas-server tas-sinkronizzazzjoni ta’ OmniRoute: jekk hux qed jaħdem, isem il-vault, port, ħin ta’ tħaddim, l-aħħar sinkronizzazzjoni. |
| `obsidian_sync_conflicts`    | Elenka l-kunflitti tas-sinkronizzazzjoni mhux solvuti (mogħdija, mogħdija tal-kunflitt, ħin tal-identifikazzjoni).                           |

### Għodod tal-kitba (`write:obsidian`)

| Għodda                           | Deskrizzjoni                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Oħloq jew issostitwixxi nota b’kontenut Markdown partikolari.                                       |
| `obsidian_append_note`           | Żid kontenut ma’ nota; b’mod fakultattiv ma’ intestatura/blokka speċifika.                          |
| `obsidian_patch_note`            | Żid wara/żid qabel/issostitwixxi b’mod preċiż f’intestatura, blokka, jew kamp tal-frontmatter.      |
| `obsidian_delete_note`           | Ħassar nota b’mod permanenti mill-vault.                                                            |
| `obsidian_move_note`             | Ċaqlaq jew semmi mill-ġdid nota fil-vault.                                                          |
| `obsidian_execute_command`       | Eżegwixxi kmand ta’ Obsidian permezz tal-ID tal-kmand tiegħu.                                       |
| `obsidian_open_file`             | Iftaħ fajl f’Obsidian (joħolqu jekk ma jkunx jeżisti).                                              |
| `obsidian_sync_trigger`          | Attiva sinkronizzazzjoni bidirezzjonali immedjata tal-vault bejn id-desktop↔il-mobile.              |
| `obsidian_sync_resolve_conflict` | Issolvi kunflitt tas-sinkronizzazzjoni: żomm `local` (mobile), `remote` (desktop), jew `keep-both`. |

> [!NOTE]
> Il-miri ta’ `obsidian_patch_note` jaċċettaw `targetType` ta’ `heading | block | frontmatter`
> u `operation` ta’ `append | prepend | replace`, b’`createTargetIfMissing`
> fakultattiv. L-erba’ għodod `obsidian_sync_*` jikkomunikaw mas-server lokali tas-sinkronizzazzjoni
> (`http://127.0.0.1:27781` awtomatikament) u jeħtieġu t-token tas-sinkronizzazzjoni.

### Ambiti

L-għodod tal-qari jeħtieġu `read:obsidian`; l-għodod tal-kitba jeħtieġu `write:obsidian`. L-infurzar
huwa identiku għal dak ta’ Notion — jiġi ġestit minn `withScopeEnforcement()` f’
`open-sse/mcp-server/server.ts`, ikkontrollat minn `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, bl-
ambiti permessi miksuba minn `OMNIROUTE_MCP_SCOPES` jew mill-kuntest tal-ambitu taċ-ċavetta API. Ara
[MCP-SERVER.md](./MCP-SERVER.md).

## Endpoints

| Metodu   | Mogħdija                        | Għan                                                                            |
| -------- | ------------------------------- | ------------------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Jirritorna `{ connected, hasToken, baseUrl, vaultPath }`.                       |
| `POST`   | `/api/settings/obsidian`        | Isalva u jivvalida t-token (jirrifjuta l-port `27124`).                         |
| `DELETE` | `/api/settings/obsidian`        | Jiskonnettja (iħassar it-token maħżun).                                         |
| `GET`    | `/api/settings/obsidian/webdav` | L-istatus tas-sinkronizzazzjoni WebDAV u l-kredenzjali (waqt li tkun attivata). |
| `POST`   | `/api/settings/obsidian/webdav` | Jattiva s-sinkronizzazzjoni WebDAV għal direttorju ta’ vault.                   |
| `DELETE` | `/api/settings/obsidian/webdav` | Jiddiżattiva s-sinkronizzazzjoni WebDAV.                                        |

> Dawn huma rotot tas-settings tad-dashboard. Il-vault innifsu jiġi aċċessat permezz tal-Obsidian
> Local REST API (il-`base_url` ikkonfigurat) u permezz tal-għodod MCP ta’ hawn fuq — ma hemm
> l-ebda endpoint proxy pubbliku `/v1` għal Obsidian.

## Każijiet ta’ użu

- **Tweġibiet ibbażati fuq il-vault** — `obsidian_search_simple` / `obsidian_search_structured`
  imbagħad `obsidian_read_note` sabiex aġent iwieġeb min-noti reali tiegħek.
- **Kitba ta’ noti / ġurnal** — `obsidian_write_note`, `obsidian_append_note`, jew
  `obsidian_patch_note` għal modifiki preċiżi biex tirreġistra l-output tal-aġent, sommarji, jew noti ta’ kuljum
  (`obsidian_get_periodic_note`) fil-vault.
- **Navigazzjoni fil-vault** — `obsidian_list_vault`, `obsidian_get_document_map`, u
  `obsidian_get_tags` biex tesplora l-istruttura qabel taqra/tikteb.
- **Awtomazzjoni ta’ Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` biex
  tħaddem plugins/kmandi minn aġent; `obsidian_open_file` biex turi nota fl-interfaċċa tal-utent.
- **Sinkronizzazzjoni mal-mobile** — attiva s-sinkronizzazzjoni WebDAV, imbagħad `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  biex tikkoordina bejn id-desktop u l-mobile u ssolvi l-kunflitti.
