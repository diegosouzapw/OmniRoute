## Ħarsa ġenerali

Playground Studio jittrasforma `/dashboard/playground` minn editur sempliċi bbażat fuq Monaco għal
spazju tax-xogħol tal-ittestjar b'funzjonalità sħiħa. Jissostitwixxi l-`page.tsx` l-antik b'qafas
`PlaygroundStudio` li jirrendi erba' tabs u pannell tal-konfigurazzjoni kondiviż.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Chat] [⚖ Qabbel] [{} API] [🔧 Ibni]       142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {kontenut tat-tab attiva}               │ ─ Konfigurazzjoni         │
│                                          │ Endpoint  [chat ∨]        │
│                                          │ Mudell    [gpt-5.4 ∨]     │
│                                          │ Sistema   [textarea]      │
│                                          │ Temp      ▕▕▔▔ 0.7        │
│                                          │ Presets [▾ tella'][salva] │
│                                          │ [✨ Tejjeb il-prompt]      │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Tabs

### Tab taċ-Chat

Tevolvi `ChatPlayground.tsx` f'ambjent tax-xogħol bi streaming u b'diversi skambji:

- Rendering sħiħ tal-markdown permezz ta' `MarkdownMessage.tsx` (blokok tal-code, tabelli, listi, links).
- Il-prompt tas-sistema jittieħed mill-pannell tal-Konfigurazzjoni kondiviż.
- Tokens/spiża għal kull messaġġ (tokens tal-prompt + tat-tlestija).
- Iġġenera mill-ġdid l-aħħar tweġiba.
- Tibgħat lil `POST /v1/chat/completions` bi streaming SSE.

### Tab tat-Tqabbil

Il-karatteristika ewlenija li tiddistingwi proxy: ħaddem prompt wieħed fuq sa **4 mudelli b'mod parallel**.

- Sa 4 kolonni, kull waħda tagħmel streaming indipendenti minn `/v1/chat/completions`.
- Buttuna `+ Żid mudell` (shortcut Cmd+K) biex iżżid kolonni.
- `Ħaddem kollox ▶` tiskatta l-streams kollha simultanjament permezz ta' `Promise.all` + `AbortController` għal kull kolonna.
- **Ikkanċella kollox** globali twaqqaf kull stream li jkun għaddej.
- `ProviderMetrics` għal kull kolonna juri t-TTFT, it-TPS, it-tokens u l-ispiża stmata f'ħin reali.
- Il-metriċi huma ttikkettati **"stima min-naħa tal-klijent"** (D12) — imkejla mill-ewwel parti SSE.

### Tab tal-API

Iżżomm 100% tal-editur Monaco oriġinali għall-utenti avvanzati (D14):

- 10 endpoints: tlestijiet taċ-chat, tlestijiet, embeddings, stampi, awdjo, diskors, traskrizzjonijiet, moderazzjonijiet, klassifikazzjoni mill-ġdid, tfittxija.
- Tlugħ ta' fajls multimodali.
- Streaming SSE b'output f'ħin reali.
- Imgeżwer bħala `ApiTab.tsx` (jitgħabba b'mod lazy, `ssr: false`).

### Tab tal-Bini

Interfaċċa għall-għodod/sejħiet ta' funzjonijiet u output strutturat:

- `ToolsBuilder.tsx` — żid/editja/neħħi `tools[]` b'editur tal-iskema JSON għal kull għodda.
  Jivvalida l-parametri permezz ta' `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — ixgħel jew itfi l-modalità JSON + editur tal-iskema JSON.
  Jivvalida t-tweġiba kontra l-iskema permezz ta' `StructuredOutputSchema` (Zod).
- Jibgħat it-talba lil `/v1/chat/completions` b'`tools[]` u/jew `response_format`.

## Panew tal-Konfigurazzjoni (Kondiviż)

`StudioConfigPane.tsx` — dejjem viżibbli, jista' jiġi kollassat.

| Qasam              | Komponent             | Noti                                                                              |
| ------------------ | --------------------- | --------------------------------------------------------------------------------- |
| Endpoint           | `<select>`            | 10 għażliet li jaqblu ma' `PlaygroundEndpoint`                                    |
| Mudell             | `<input>`             | test liberu, eż. `openai/gpt-4o`                                                  |
| Prompt tas-sistema | `<textarea>`          | jintuża fit-tabs kollha                                                           |
| Parametri          | `ParamSliders`        | temperature, max_tokens, top_p, penali ta' presence/frequency, seed, stop         |
| Presets            | `PresetPicker`        | tagħbija/issejvja snapshots tal-konfigurazzjoni bl-isem (ippersistiti fid-DB)     |
| Tejjeb il-prompt   | `ImprovePromptButton` | jiftaħ modal ta' twissija dwar il-kwota, isejjaħ `/api/playground/improve-prompt` |

L-istat jittella' għal `PlaygroundStudio.tsx` u jiġi mgħoddi lit-tabs kollha. Il-bdil bejn it-tabs
jippreserva l-istat tal-konfigurazzjoni.

## Modal għall-Esportazzjoni tal-Code

`ExportCodeModal.tsx` juża `codeExport.ts` biex jiġġenera snippets ta' curl / Python / TypeScript
mill-`PlaygroundState` attwali. Il-placeholder tal-API key dejjem ikun `$OMNIROUTE_API_KEY` (D11).

## Titjib tal-Prompt

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Il-modal iwissi li "se jikkonsma l-kwota".
2. Mal-konferma, jibgħat `{ system, prompt, model, tone }` lir-route.
3. Ir-route jsejjaħ `/v1/chat/completions` internament bi `promptImprover.META_SYSTEM_PROMPT`.
4. Jirritorna `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. L-UI taġġorna l-prompt tas-sistema fil-panew tal-Konfigurazzjoni u l-prompt tal-utent fit-tab Chat.

---

## Presets

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Jinħażnu fit-tabella SQLite `playground_presets` (migrazzjoni `084_playground_presets.sql`).
- Kull preset jaħżen: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: lista permezz ta' `GET`, ħolqien permezz ta' `POST`, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Metriċi tal-Istream

`useStreamMetrics.ts` + `streamMetrics.ts` (funzjoni pura):

- `start()` — jirreġistra l-ħin tal-bidu tat-talba.
- `onFirstChunk()` — jirreġistra t-TTFT.
- `onChunk(n)` — jakkumula l-għadd tat-tokens tal-kompletament.
- `finish(usage?)` — jikkalkula l-metriċi finali: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Il-prezzijiet jittieħdu mit-tabella statika f'`src/lib/playground/types.ts` (immarkati bħala "stmati" — D13).

## Routes tal-Backend

| Metodu   | Path                             | Handler                                                                                      |
| -------- | -------------------------------- | -------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | Jivvalida `ImprovePromptRequestSchema` b'Zod; isejjaħ `/v1/chat/completions` bil-meta-prompt |
| `GET`    | `/api/playground/presets`        | Jirritorna `{ presets: PlaygroundPresetListItem[] }`                                         |
| `POST`   | `/api/playground/presets`        | Joħloq preset; jivvalida `PlaygroundPresetCreateSchema`                                      |
| `GET`    | `/api/playground/presets/:id`    | Jirritorna preset wieħed jew 404                                                             |
| `PUT`    | `/api/playground/presets/:id`    | Aġġornament parzjali                                                                         |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                          |

Awtentikazzjoni: fakultattiva (`REQUIRE_API_KEY`). Żbalji permezz ta' `buildErrorBody()` (Regola Stretta #12).

## Soluzzjoni tal-Problemi

| Sintomu                                          | Kawża                                           | Soluzzjoni                                                                                                  |
| ------------------------------------------------ | ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| L-editur Monaco ma jintweriex fit-tab tal-API    | SSR tella’ lil Monaco                           | Ivverifika li `ApiTab` juża `dynamic(..., { ssr: false })`                                                  |
| Il-flussi tat-tqabbil jibdew wieħed wara l-ieħor | Użu ħażin ta’ `Promise.all`                     | Il-bidu tal-flussi kollha jrid jintbagħat f’sejħa waħda ta’ `Promise.all`                                   |
| Il-metriċi juru TTFT bħala `null`                | Il-handler tal-ewwel parti mhuwiex ikkonnettjat | Iċċekkja li `useStreamMetrics.onFirstChunk()` jissejjaħ fil-loop tal-qarrej SSE                             |
| Il-preset ma jinżammx                            | Il-migrazzjoni tad-DB ma saritx                 | Ħaddem `npm run db:migrate` jew erġa’ ibda s-server (il-migrazzjoni titħaddem awtomatikament mal-istartjar) |
| It-titjib tal-prompt jirritorna 502              | Il-mudell mhuwiex issettjat f’Config            | L-utent irid idaħħal isem ta’ mudell fil-pannell Config qabel it-titjib                                     |
| Il-kodiċi esportat juri `MISSING_API_KEY`        | Il-placeholder ma ddaħħalx                      | `codeExport.ts` dejjem juża `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"`                                    |
