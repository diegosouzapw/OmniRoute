## X'inhu

Local Corpus jippermetti lil operatur jesponi direttorju wieħed ta' fajls tat-test approvat b'mod espliċitu lis-server MCP ta' OmniRoute. Il-fajls jibqgħu fid-direttorju oriġinali tagħhom: OmniRoute jaħżen biss il-mogħdija ewlenija kanonika f'SQLite u jżomm indiċi tat-tiftix fil-memorja. Ma jikkupjax il-kontenut tal-korpus fir-repożitorju jew fil-bażi tad-data.

L-aġġornament tal-indiċi huwa inkrementali. Fajls mhux mibdula jerġgħu jintużaw abbażi tad-daqs u l-ħin tal-modifika, fajls mibdula jerġgħu jinqraw u jiġu soġġetti għal hashing b'SHA-256, u fajls imħassra jitneħħew. It-tiftix jaġġorna indiċi li jkollu aktar minn 30 sekonda; min jagħmel it-talba jista' wkoll jitlob aġġornament immedjat.

## Ikkonfigura s-sors

Ir-rotta tas-settings teħtieġ l-istess awtentikazzjoni tal-ġestjoni bħall-APIs l-oħra tas-settings. Il-mogħdija sottomessa trid tkun diġà teżisti u trid tkun mogħdija assoluta ta' direttorju.

```bash
# Qabbad direttorju approvat
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Iċċekkja l-konfigurazzjoni u l-istatus tal-indiċi
curl http://localhost:20128/api/settings/local-corpus

# Skonnettja mingħajr ma tbiddel il-fajls tas-sors
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Għodod MCP

It-tliet għodod kollha jeħtieġu `read:local-corpus`. It-tweġibiet tal-għodod jesponu mogħdijiet relattivi u l-isem bażi tad-direttorju ewlieni, iżda qatt il-mogħdija assoluta tiegħu.

| Għodda                | Deskrizzjoni                                                                                         |
| :-------------------- | :--------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Jirrapporta l-istat tal-konfigurazzjoni, id-daqs tal-indiċi, il-limiti u l-ħin tal-aħħar aġġornament |
| `local_corpus_search` | Ifittex fit-test indiċjat u jirritorna siltiet limitati u marbuta mal-linji (sa 20 riżultat)         |
| `local_corpus_read`   | Jaqra firxa limitata ta' linji minn fajl wieħed permess b'mogħdija relattiva għall-korpus            |

Eżempji ta' inputs MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Limiti tas-sigurtà

- Il-lista tal-estensjonijiet permessi hija orjentata lejn it-test: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, u `.yml`.
- Il-links simboliċi jinqabżu. Il-mogħdijiet tal-qari jiġu kkanonizzati u jridu jibqgħu ġewwa d-direttorju ewlieni kkonfigurat; mogħdijiet assoluti u tentattivi ta' traversar jiġu miċħuda.
- Ismijiet ta' direttorji sensittivi u ġġenerati huma esklużi: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, u
  `secrets`.
- Il-limiti predefiniti huma 5,000 fajl, 1 MiB għal kull fajl, 64 MiB ta' kontenut indiċjat b'kollox, madwar 4,000 karattru għal kull blokka ta' tiftix, u 400 linja għal kull qari.
- Fajls li fihom NUL jiġu ttrattati bħala mhux testwali u jinqabżu jew jiġu miċħuda.

Dokumenti binarji bħal PDF, DOCX, stampi u arkivji mhumiex appoġġjati intenzjonalment. Ikkonvertihom għal format ta' test approvat fid-direttorju kkonfigurat qabel l-indiċjar.

## Noti operazzjonali

- It-tibdil jew it-tħassir tad-direttorju ewlieni kkonfigurat ineħħi l-indiċi kondiviż mill-memorja.
- Meta proċess jerġa' jinbeda, l-indiċi jintrema; it-tiftixa li jmiss terġa' tibnih mis-sors ikkonfigurat.
- `local_corpus_status` ma jisforzax skennjar. Uża `local_corpus_search` b'
  `refresh: true` meta jkun meħtieġ skennjar mill-ġdid immedjat.
- Ħsarat waqt l-iskennjjar u l-qari jingħaddu jew jiġu rritornati bħala żbalji sanitizzati; il-fajls tas-sors qatt ma jiġu modifikati.
