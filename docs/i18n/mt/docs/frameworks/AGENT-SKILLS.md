> **Sors awtorevoli:** `src/lib/agentSkills/` (katalgu, ġeneratur, parsers) + id-direttorju `skills/` (fajls SKILL.md)
> **Aġġornat l-aħħar:** 2026-08-02 — v3.8.50

L-Agent Skills huma fajls SKILL.md strutturati li jgħallmu lill-aġenti esterni, lill-klijenti MCP, u lill-orkestraturi A2A kif jużaw ir-REST API u s-CLI ta’ OmniRoute. Għall-kuntrarju ta’ [Omni Skills](./SKILLS.md) (li huma definizzjonijiet ta’ għodod LLM eżegwiti ġewwa OmniRoute), l-Agent Skills huma _katalgu ta’ dokumentazzjoni_ — markdown statiku li jista’ jiddaħħal direttament fil-kuntest tal-aġent.

---

## Ħarsa ġenerali

Il-katalgu fih **45 Agent Skill** (23 REST API + 21 CLI + fluss tax-xogħol wieħed għall-konfigurazzjoni). Kull skill għandha:

- **ID kanoniku** (`omni-auth`, `cli-serve`, eċċ.)
- Fajl **SKILL.md** f’`skills/{id}/SKILL.md` b’YAML frontmatter (`name`, `description`) + korp markdown dettaljat
- **Endpoints REST** (skills tal-API) jew **sottokmandi CLI** (skills tas-CLI) derivati mill-ispeċifikazzjoni OpenAPI u mir-reġistru tas-CLI
- **URL raw ta’ GitHub** għall-aċċess dirett: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Skoperta tal-REST API

| Endpoint                     | Metodu | Deskrizzjoni                                                            | Awtentikazzjoni |
| :--------------------------- | :----- | :---------------------------------------------------------------------- | :-------------- |
| `/api/agent-skills`          | GET    | Elenka l-katalgu (`?category=api\|cli\|config&area=<area>` fakultattiv) | ebda waħda      |
| `/api/agent-skills/{id}`     | GET    | Ikseb il-metadejta ta' ħila waħda                                       | ebda waħda      |
| `/api/agent-skills/{id}/raw` | GET    | Ġib SKILL.md bħala `text/markdown`                                      | ebda waħda      |
| `/api/agent-skills/coverage` | GET    | Statistika tal-kopertura (kemm jeżistu fajls SKILL.md)                  | ebda waħda      |
| `/api/agent-skills/generate` | POST   | Attiva l-ġeneratur (dryRun/prune/onlyIds)                               | ġestjoni        |

Eżempju — elenka l-ħiliet kollha tal-API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Eżempju — ġib SKILL.md wieħed:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Kif Aġenti Esterni Jużaw il-Ħiliet

### 1. Skoperta permezz ta’ REST

```bash
# Ikseb il-katalgu sħiħ
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Ikseb SKILL.md għall-injezzjoni tal-kuntest
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Skoperta permezz ta’ MCP

```typescript
// F'klijent MCP ta' Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → array ta' AgentSkill b'rawUrl għal kull wieħed
```

### 3. Skoperta permezz ta’ A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table hija tabella markdown bl-45 ID tal-ħiliet kollha flimkien mal-kolonni rawUrl
```

### 4. Ġbir dirett tad-data mhux ipproċessata minn GitHub (mingħajr il-ħtieġa ta’ server)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Ġeneratur

Il-ġeneratur jaqra l-katalgu kkurat + l-ispeċifikazzjoni OpenAPI + ir-reġistru CLI u jikteb `skills/{id}/SKILL.md` għal kull entrata:

```bash
# Previżjoni (eżekuzzjoni ta' prova, mingħajr kitba)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Riġenerazzjoni sħiħa
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Irriġenera IDs speċifiċi
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Ir-rispons tal-ġeneratur huwa `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
