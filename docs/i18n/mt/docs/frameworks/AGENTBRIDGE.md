AgentBridge huwa l-proxy MITM (Man-in-the-Middle) ta' OmniRoute li jinterċetta t-traffiku HTTPS mill-aġenti tal-IA tal-IDE u jerġa' jidderiġih permezz tal-magna unifikata tar-routing ta' OmniRoute. Jappoġġja **10 aġenti tal-IDE** — Antigravity, Kiro, GitHub Copilot, GHE Copilot, OpenAI Codex, Cursor, Zed, Claude Code, Open Code, u Trae (taħt investigazzjoni) — u b'hekk jagħmel lil OmniRoute l-proxy MITM bl-aktar kopertura wiesgħa fis-suq għall-assistenti tal-ipprogrammar bl-IA.

**Post tad-dashboard:** `/dashboard/tools/agent-bridge`
**Grupp fil-sidebar:** Għodod (wara Cloud Agents)
**Ara wkoll:** [`TRAFFIC_INSPECTOR.md`](./TRAFFIC_INSPECTOR.md) — issorvelja t-traffiku interċettat kollu f'ħin reali; `docs/security/MITM-TPROXY-DECRYPT.md` (git; mhux ikkompilat f'`/docs`) — il-modalità ta' qbid transparent-decrypt TPROXY għal-Linux, ikkontrollata mir-rotta `/api/tools/agent-bridge/tproxy`.

## §1 Ħarsa ġenerali

### X'inhu AgentBridge?

Meta aġent tal-IDE (eż., GitHub Copilot, Cursor, Claude Code) jagħmel sejħa API, huwa jikkonnettja direttament mal-fornitur upstream tal-IA (OpenAI, Anthropic, eċċ.). AgentBridge jinterċetta dik il-konnessjoni b'mod trasparenti fil-livell TLS — mingħajr ma jeħtieġ ebda bidla fil-konfigurazzjoni tal-aġent — u jerġa' jikteb it-talba permezz ta' OmniRoute.

Dan ifisser li tista':

- **Terġa' tidderieġi kwalunkwe aġent lejn kwalunkwe fornitur**: Copilot qed jikkomunika ma' OpenAI? Irridireġih lejn Anthropic Claude, Gemini, jew kwalunkwe wieħed mit-352 fornitur ta' OmniRoute.
- **Tapplika mmappjar tal-mudelli**: `gemini-3-flash` → `claude-sonnet-4.7` b'mod trasparenti fil-livell tal-handler.
- **Tosserva t-traffiku kollu tal-aġenti**: kull talba interċettata tiġi ppubblikata fit-[Traffic Inspector](./TRAFFIC_INSPECTOR.md).
- **Tapplika r-reżiljenza ta' OmniRoute**: ir-routing ikkombinat, is-circuit breakers, il-fallbacks, u t-traċċar tal-ispejjeż jaħdmu wkoll għat-traffiku tal-aġenti tal-IDE.

## §2 Arkitettura

### 2.1 Ħarsa ġenerali lejn il-komponenti

```
Aġent tal-IDE (VS Code / Cursor / eċċ.)
    │  HTTPS (port 443)
    ▼
/etc/hosts — 127.0.0.1 api.githubcopilot.com   ← Direzzjoni mill-ġdid tad-DNS
    │
    ▼
src/mitm/server.cjs  (port 443, proċess sekondarju CJS)
    │  jirriżolvi d-destinazzjoni permezz tal-SNI tal-header Host
    │  jiġġenera ċertifikat TLS għal kull SNI, iffirmat mis-CA ta’ AgentBridge
    ├── Taqbel mal-lista ta’ bypass? → passthrough TCP (mingħajr deċifrar)
    ├── Taqbel ma’ destinazzjoni? → fetch → router OmniRoute (port 20128)
    │       └── handler.intercept() — TypeScript
    │               ├── maskSecrets() fuq il-body/headers tat-talba
    │               ├── TrafficBuffer.push() — jippubblika fit-Traffic Inspector
    │               └── fetchRouter() → /v1/chat/completions
    └── Ma taqbel xejn? → passthrough TCP (mingħajr deċifrar)
```

### 2.2 Server MITM (`src/mitm/server.cjs`)

Is-server MITM ewlieni jaħdem bħala proċess sekondarju CJS ta’ Node.js (biex jiġi evitat li terġa’ tinkiteb il-codebase CJS eżistenti). Dan:

- Jisma’ fuq il-port 443 (jeħtieġ privileġġ jew `authbind`/`setcap`)
- Jirċievi mini CONNECT mill-OS (permezz tad-direzzjoni mill-ġdid tad-DNS f’`/etc/hosts`)
- Jiġġenera ċertifikati TLS għal kull SNI, iffirmati mis-CA ta’ AgentBridge (`DATA_DIR/mitm/ca.crt`)
- Jirriżolvi l-aġent tad-destinazzjoni permezz tal-header Host billi juża r-reġistru `targets/index.ts`
- Jiddelega lis-saff tal-handler TypeScript permezz tal-HTTP lejn `http://127.0.0.1:20128`

`TARGET_HOSTS` jitgħabba minn `DATA_DIR/mitm/targets.json` (miktub minn `targets/index.ts` waqt l-istartjar), u b’hekk jippermetti aġġornamenti dinamiċi mingħajr ma jerġa’ jinbeda s-server CJS.

> **Mudell root-CA (#6684).** Id-deskrizzjoni taċ-ċertifikat għal kull SNI ffirmat minn CA hawn fuq
> hija l-mudell root-CA persistenti miżjud f’#6684 (`src/mitm/cert/rootCa.ts` +
> `src/mitm/_internal/rootCaShim.cjs`, li juża mill-ġdid il-kriptografija tal-CA/leaf diġà
> ppruvata għal TPROXY f’`src/mitm/tproxy/dynamicCert.ts`) — dan jissostitwixxi
> l-leaf awtoffirmat statiku uniku l-antik (`src/mitm/cert/generate.ts`, li għadu
> limitat biss għall-hosts antigravity) indikat minn par sempliċi `server.crt`/`server.key`
> fuq id-diska. **Imġiba tal-migrazzjoni**: installazzjoni ġdida (mingħajr
> `server.crt` preċedenti) tikseb il-mudell root-CA awtomatikament; installazzjoni li diġà
> tafda l-leaf statiku l-antik tibqa’ tużah sakemm l-operatur jistabbilixxi
> `MITM_ROOT_CA_ENABLED=true` u jerġa’ jibda l-bridge (`src/mitm/cert/migration.ts`
> hija l-funzjoni pura tad-deċiżjoni — CA MITM fdata li tista’ tiffirma leaf għal
> **kwalunkwe** host hija sostanzjalment aktar b’saħħitha mil-leaf l-antik b’SAN fiss, għalhekk
> il-bidla qatt ma ssir mingħajr avviż għal installazzjoni li diġà hija fdata). Iċ-ċertifikat CA jiġi installat
> fl-istess slot `omniroute-mitm.crt` tal-maħżen tal-fiduċja li kien juża l-leaf l-antik
> (`cert/install.ts::installCaCert`) — ma hemm bżonn l-ebda tindif ta’ fiduċja doppja.

### 2.3 Bażi tal-handler (`src/mitm/handlers/base.ts`)

Il-handlers kollha tal-aġenti jestendu `MitmHandlerBase`:

Kull handler isejjaħ `hookBufferStart()` qabel jagħmel proxying u `hookBufferUpdate()` meta jitlesta. Dawn idaħħlu entrati `InterceptedRequest` f’`globalTrafficBuffer` (ara [Traffic Inspector](./TRAFFIC_INSPECTOR.md) §4).

### 2.4 Reġistru tad-destinazzjonijiet (`src/mitm/targets/`)

Kull aġent għandu fajl ta’ destinazzjoni dikjarattiv:

```ts
// src/mitm/targets/copilot.ts
export const COPILOT_TARGET: MitmTarget = {
  id: "copilot",
  name: "GitHub Copilot",
  hosts: ["api.githubcopilot.com", "copilot-proxy.githubusercontent.com"],
  port: 443,
  endpointPatterns: ["/chat/completions", "/v1/chat/completions"],
  defaultModels: [{ id: "gpt-4o", name: "GPT-4o", alias: "gpt-4o" }],
  handler: () => import("../handlers/copilot"),
  riskNoticeKey: "providers.riskNotice.oauth",
};
```

Ir-reġistru (`targets/index.ts`) jesporta `ALL_TARGETS` u joħroġ `DATA_DIR/mitm/targets.json` waqt l-istartjar.

### 2.5 Passthrough u lista ta’ bypass (`src/mitm/passthrough.ts`)

**Lista ta’ bypass** (iċċekkjata l-ewwel, bi preċedenza fuq it-tqabbil mad-destinazzjoni):

- Mudelli predefiniti: hosts bankarji, `.gov.`, fornituri OAuth/SSO (Okta, Auth0), eċċ.
- Mudelli tal-utent: maħżuna fit-tabella tad-DB `agent_bridge_bypass`
- Il-hosts li jgħaddu mill-bypass jirċievu mina TCP trasparenti — it-TLS **qatt ma jiġi ddeċifrat**

**Passthrough predefinit** (ebda tqabbil ma’ destinazzjoni u mhux fil-bypass):

- Jirċievi wkoll mina TCP — il-konnessjonijiet qatt ma jinkisru
- Jipprevjeni lil AgentBridge milli jfixkel it-traffiku HTTPS ġenerali tas-sistema

Preċedenza tar-routing:

```
lista ta’ bypass → tqabbil mad-destinazzjoni → passthrough
```

### 2.6 Ċertifikat CA upstream (`src/mitm/upstreamTrust.ts`)

Għal ambjenti ta’ netwerk korporattiv b’CA personalizzata:

```bash
AGENTBRIDGE_UPSTREAM_CA_CERT=/path/to/corporate-ca.pem
```

Meta jkun stabbilit, jikkonfigura d-dispatcher globali ta’ `undici` biċ-ċertifikat CA addizzjonali, u b’hekk jippermetti lil AgentBridge jilħaq il-fornituri upstream permezz ta’ proxies korporattivi tat-terminazzjoni TLS.

### 2.7 Maskra tas-sigrieti (`src/mitm/maskSecrets.ts`)

L-iskaner indipendenti clean-room jiġi applikat għall-bodies tat-talbiet u għall-headers tal-kredenzjali
**qabel** ma jidħlu fil-buffer tat-Traffic Inspector jew fi kwalunkwe log. Dan iwettaq passaġġ lineari wieħed:

- Tokens bil-prefiss `sk-` / `ak-` / `pk-` (stil OpenAI/Anthropic)
- Kredenzjali RFC 6750 `Authorization: Bearer <token>`, bi preċedenza għat-token kollu
- Tokens opaki twal ġeneriċi (≥40 karattru), inklużi forom bit-tikek u bil-padding

`sanitizeHeaders()` jaqleb l-ismijiet miżmuma għal ittri żgħar, jgħaqqad il-valuri tal-arrays b’mod deterministiku, ineħħi l-
lista kondiviża ta’ projbizzjoni hop-by-hop/framing (inkluża l-awtentikazzjoni tal-proxy), jaħbi kompletament `cookie` u
`set-cookie`, u jiddelega l-valuri tal-kredenzjali lill-iskaner.

## §3 Konfigurazzjoni

### 3.1 Ibda/waqqaf is-server MITM

Uża l-Kard tas-Server AgentBridge f’`/dashboard/tools/agent-bridge`:

| Azzjoni                         | Deskrizzjoni                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------------ |
| Ibda s-Server                   | Iniedi `src/mitm/server.cjs` fuq il-port 443                                                     |
| Waqqaf is-Server                | Jagħlaq il-proċess sekondarju b’mod ikkontrollat                                                 |
| Erġa’ Ibda s-Server             | Waqqaf + ibda (japplika l-bidliet fil-miri)                                                      |
| Afda ċ-Ċertifikat               | Jinstalla `DATA_DIR/mitm/ca.crt` fil-maħżen ta’ fiduċja tal-OS                                   |
| Niżżel iċ-Ċertifikat            | Iniżżel `ca.crt` għal installazzjoni manwali                                                     |
| Iġġenera ċ-Ċertifikat Mill-Ġdid | Joħloq par ġdid ta’ ċwievet CA (iċ-ċertifikati eżistenti kollha għal kull aġent jiġu invalidati) |

### 3.2 Afda ċ-ċertifikat

Iċ-ċertifikat CA ta’ AgentBridge jrid ikun fdat mill-OS qabel ma l-IDEs jaċċettaw il-konnessjoni MITM.

**Linux (NSS — Chrome/Firefox):**

```bash
certutil -A -d sql:$HOME/.pki/nssdb -n "OmniRoute AgentBridge" -t CT,, -i ~/.omniroute/mitm/ca.crt
```

**macOS (Keychain):**

```bash
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/.omniroute/mitm/ca.crt
```

**Windows (certmgr):**

```powershell
certutil -addstore -f Root $env:USERPROFILE\.omniroute\mitm\ca.crt
```

Jew uża l-buttuna "Afda ċ-Ċertifikat" fid-dashboard (din tħaddem il-kmand xieraq għall-OS tiegħek, b’talba għal sudo jekk ikun meħtieġ).

#### IDEs ibbażati fuq Electron jinjoraw il-maħżen ta’ fiduċja tal-OS (`NODE_EXTRA_CA_CERTS`)

Xi IDEs — b’mod partikolari **Antigravity IDE**, u applikazzjonijiet oħra derivati minn Electron / VS Code — jinkludu
r-runtime Node.js tagħhom stess li **ma jikkonsultax il-maħżen ta’ fiduċja tal-OS** għal
`fetch`/HTTPS ’il barra. Li tafda s-CA fil-livell tal-OS/NSS huwa biżżejjed għall-**backend** nattiv
tal-IDE (eż. server tal-lingwa Go, li juża l-ġabra tas-CA tal-OS), iżda l-**frontend ta’ Electron**
xorta jfalli fit-TLS — dan jidher bħallikieku l-utent ikun _inqala’ mill-kont_ jew bħala _"żball fil-konnessjoni"_
minkejja li r-reġistru MITM juri li t-talbiet tal-inizjalizzazzjoni tal-backend qed jirritornaw `200`. Huma
meħtieġa żewġ passi, u t-tnejn huma importanti:

1. Indika s-CA espliċitament lir-runtime:
   ```bash
   export NODE_EXTRA_CA_CERTS=/path/to/omniroute-agentbridge-ca.crt
   ```
2. **Ħaddem l-IDE minn dik is-shell.** Jekk tibdieh mill-ikona tad-desktop / Dock / menu Start,
   **ma** jiretx l-esportazzjonijiet tas-shell, u `~/.config/environment.d/*.conf` japplika biss wara
   login grafiku ġdid. Agħlaq l-IDE kompletament l-ewwel — il-lock ta’ istanza waħda ta’ Electron ifisser li tnedija oħra
   sempliċement tiffoka l-proċess eżistenti u l-ambjent il-ġdid jiġi injorat.

Il-pass tal-fiduċja tal-OS + NSS ta’ hawn fuq jibqa’ meħtieġ (l-istack tan-network ta’ Chromium użat minn xi flussi
ta’ awtentikazzjoni jaqra l-maħżen NSS għal kull utent, u għandu l-pins statiċi tiegħu għal `*.googleapis.com` li
jiġu megħluba minn CA fdata lokalment). `NODE_EXTRA_CA_CERTS` ikopri wkoll il-perkors ta’ `fetch` ta’ Node.

### 3.3 Rotot DNS

Għal kull aġent li trid tinterċetta, il-host(s) tal-API tiegħu jridu jirriżolvu għal `127.0.0.1`. AgentBridge jimmaniġġja l-entrati ta’ `/etc/hosts` awtomatikament meta tattiva jew tiddiżattiva d-DNS għal aġent fil-Gwida tal-Konfigurazzjoni.

Eżempju ta’ entrati f’`/etc/hosts` għal GitHub Copilot:

```
127.0.0.1 api.githubcopilot.com
127.0.0.1 copilot-proxy.githubusercontent.com
```

### 3.4 Immappjar tal-mudelli

Uża t-Tabella tal-Immappjar tal-Mudelli f’kull kard ta’ aġent biex tiddefinixxi mmappjar minn sors → għal mira:

| Mudell sors (nattiv tal-aġent) | Mudell mira (OmniRoute) |
| ------------------------------ | ----------------------- |
| `gpt-4o`                       | `claude-sonnet-4.7`     |
| `*` (wildcard)                 | `claude-haiku-4.7`      |

Il-wildcard `*` jimmappja kwalunkwe mudell mhux rikonoxxut għall-mira speċifikata. Jinħażen fit-tabella `agent_bridge_mappings`.

> **Parir — skopri l-IDs reali tal-mudelli tal-aġent.** IDE jista’ jibgħat ismijiet ta’ mudelli li jkunu differenti mit-tikketti
> fl-UI tiegħu u li jinbidlu bejn verżjonijiet ewlenin. Pereżempju, **Antigravity 2** jibgħat
> `gemini-3.1-pro-low`, `gemini-pro-agent`, u `gemini-3.1-flash-lite` fuq il-konnessjoni — mhux
> `gemini-2.5-pro` muri f’dokumentazzjoni eqdem. Ibgħat chat wieħed mingħajr immappjar korrispondenti attiv: l-MITM

### 3.5 Avviż dwar ir-riskju

AgentBridge jinterċetta l-kredenzjali (tokens OAuth, ċwievet API) li l-IDE juża biex jawtentika ruħu mal-fornituri upstream. Dawn jiġu **moħbija qabel ma jiġu rreġistrati** (ara §2.7), iżda jkunu viżibbli għas-saff MITM ta’ OmniRoute. ### 3.7 Importazzjoni/esportazzjoni ta’ konfigurazzjoni portabbli

AgentBridge jista’ jisserjalizza l-istat **aġġustabbli mill-operatur** fi blob JSON b’verżjoni sabiex konfigurazzjoni tkun tista’ tiġi replikata bejn magni differenti. Is-serializzatur huwa `src/lib/inspector/configPortability.ts` (`exportConfig()` / `importConfig()`), ivvalidat minn `AgentBridgeConfigSchema`.

L-esportazzjoni tinkludi eżattament tliet partijiet (il-valuri prestabbiliti integrati intenzjonalment **MHUMIEX** esportati, sabiex l-importazzjoni qatt ma tidduplikahom jew toħloq kunflitt magħhom):

| Kamp             | Sors                                                                  | Noti                                                                     |
| ---------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `bypassPatterns` | mudelli ta’ bypass definiti mill-utent (`agent_bridge_bypass`)        | il-mudelli prestabbiliti bank/gov/okta huma esklużi                      |
| `customHosts`    | hosts personalizzati ta’ Traffic Inspector (`inspector_custom_hosts`) | kull wieħed: `{ host, kind: "llm"\|"app"\|"custom", label? }`            |
| `agentMappings`  | mappings tal-mudelli għal kull aġent (`agent_bridge_mappings`)        | `{ [agentId]: [{ source, target }] }` għal kull aġent li għandu mappings |

```jsonc
// GET /api/tools/agent-bridge/config
{
  "version": 1,
  "bypassPatterns": ["*.internal.example.com"],
  "customHosts": [{ "host": "api.example.com", "kind": "llm", "label": null }],
  "agentMappings": {
    "copilot": [{ "source": "gpt-4o", "target": "claude-sonnet-4.7" }],
  },
}
```

**Imġiba tal-importazzjoni** (`POST /api/tools/agent-bridge/config`): il-mudelli ta’ bypass u l-mappings għal kull aġent **jinbidlu kompletament**; il-hosts personalizzati jiżdiedu **b’mod idempotenti** (`INSERT OR IGNORE`). Ir-risposta tirrapporta kemm minn kull wieħed ġew applikati:

```jsonc
{ "ok": true, "bypassPatterns": 1, "customHosts": 1, "agents": 1 }
```

Dak li **MHUWAX** fil-konfigurazzjoni: l-istat tat-tħaddim tas-server, il-perkorsi taċ-ċertifikati, l-istat tad-DNS għal kull aġent, il-perkors tas-CA upstream, u s-settings tat-TPROXY — dawn huma l-istat tal-host/runtime, mhux preferenzi portabbli.

### Lista ta' bypass għal hosts sensittivi

Il-lista ta' bypass tiżgura li istituzzjonijiet finanzjarji, fornituri OAuth/SSO, u hosts sensittivi oħra **qatt ma jiġu ddeċifrati**. It-traffiku TLS tagħhom jgħaddi bħala mina TCP trasparenti — OmniRoute qatt ma jara t-test mhux iċċifrat.

Il-mudelli ta' bypass predefiniti jinkludu:

- `*.bank.*`, `*.gov.*` (finanzjarji/gvernattivi)
- `*.okta.com`, `*.auth0.com`, `*.microsoft.com` (SSO/identità)
- `*.apple.com`, `*.icloud.com` (servizzi tas-sistema Apple)

Mudelli ta' bypass miżjuda mill-utent jinħażnu fit-tabella `agent_bridge_bypass` u jieħdu preċedenza fuq kollox.

### Maskar tas-sigrieti

Jiġi applikat `maskSecrets()` minn `src/mitm/maskSecrets.ts`:

- Fuq kull body ta' talba qabel `TrafficBuffer.push()`
- Fuq kull header qabel il-logging jew ix-xandir

Mudelli: tokens bil-prefiss `sk-`/`ak-`/`pk-`, tokens `Bearer`, u tokens ġeneriċi ta' ≥40 karattru.

### Ċertifikat CA upstream

Meta `AGENTBRIDGE_UPSTREAM_CA_CERT` ikun issettjat, il-fajl jinqara waqt l-istartjar. Jekk il-mogħdija teżisti iżda l-fajl ma jistax jinqara, AgentBridge jirreġistra żball ċar u jirrifjuta li jibda (dan jipprevjeni fallimenti TLS silenzjużi f’ambjenti korporattivi).

### Limitazzjonijiet magħrufa

- **Il-port 443 jeħtieġ privileġġ**: Fuq Linux, AgentBridge jeħtieġ `setcap 'cap_net_bind_service=+ep'` fuq il-binarju ta' Node, jew irid jitħaddem permezz ta' `authbind`. L-Assistent tal-Konfigurazzjoni juri struzzjonijiet speċifiċi għas-sistema operattiva.
- **Huwa meħtieġ restart tal-IDE**: Wara r-ridirezzjoni tad-DNS, l-IDE jrid jerġa' jinbeda biex ir-riżoluzzjoni l-ġdida tal-host tidħol fis-seħħ.
- **Tokens OAuth hardcoded**: Xi aġenti (Kiro, Antigravity) jaħżnu tokens lokali ta' aġġornament OAuth. Dawn huma trasparenti għal AgentBridge — dan jara t-token Bearer f’kull talba, li jiġi mgħotti qabel il-logging.
- **Frontends Electron jeħtieġu `NODE_EXTRA_CA_CERTS`**: IDEs li l-frontend tagħhom jaħdem fuq runtime Node/Electron inkluż magħhom jinjoraw it-trust store tal-OS/NSS u jridu jiġu varati minn shell b’`NODE_EXTRA_CA_CERTS` issettjat (ara §3.2). Sintomu meta jkun nieqes: il-backend tal-IDE jawtentika (MITM juri `200`s) iżda l-UI tibqa' mhux illoggjata.
- **Installazzjonijiet multipli tal-istess IDE huma indipendenti**: installazzjoni tas-sistema (eż. `/usr/share/antigravity/antigravity`) u installazzjoni "Full" lokali għall-utent (eż. `~/AntigravityIDE_Full/antigravity-ide`) huma proċessi separati bir-runtimes tagħhom stess — kull waħda trid terġa' titvara bil-CA injettata. Identifika liema waħda qed taħdem mill-mogħdija tal-binarju tagħha qabel terġa' tvaraha.
- **L-identità tiġi stabbilita mis-system prompt tal-aġent, mhux mill-mudell irrottat**: meta timmapja mill-ġdid il-mudell ta' aġent għal fornitur differenti, ir-risposta xorta tiddikjara l-identità nattiva tal-aġent (eż. Antigravity iwieġeb "Jiena mħaddem minn Gemini") minħabba li l-IDE jinjetta dan fis-system prompt. Ikkonferma l-backend reali f’`call_logs` / `proxy_logs` (`provider`, `model`, `target_format`), mhux billi tistaqsi lill-mudell min hu.

## §6 Soluzzjoni tal-problemi

### Kunflitt fuq il-port 443

Jekk proċess ieħor diġà qed jisma' fuq il-port 443 (server tal-web, VPN, eċċ.):

```bash
lsof -i :443          # sib il-proċess
sudo fuser -k 443/tcp  # waqqfu bil-forza (uża b'attenzjoni)
```

Inkella, ikkonfigura port mhux privileġġat fis-settings ta' AgentBridge u stabbilixxi regoli ta' ridirezzjoni għal `iptables` / `pf`.

### Iċ-ċertifikat mhuwiex fdat

Jekk l-IDE juri żbalji TLS wara li jinbeda AgentBridge:

1. Ivverifika li ċ-ċertifikat ġie installat: `security find-certificate -c "OmniRoute AgentBridge"` (macOS) jew `certutil -L -d sql:$HOME/.pki/nssdb` (Linux/NSS)
2. Xi apps iżommu l-maħżen tal-fiduċja tagħhom stess (Firefox, Chrome fuq Linux). Erġa' ħaddem "Trust Cert" u ċċekkja l-maħżen taċ-ċertifikati speċifiku għal NSS/Firefox.
3. Erġa' ibda l-IDE wara li tafda ċ-ċertifikat — is-sessjonijiet TLS li jkunu għaddejjin jużaw l-istat ta' fiduċja l-antik.

### L-IDE ħareġ mill-kont / "żball fil-konnessjoni" minkejja CA fdata

Sintomu: wara r-ridirezzjoni tad-DNS u l-għoti ta' fiduċja lis-CA, IDE ibbażat fuq Electron (eż. Antigravity)
jinfetaħ **barra mill-kont** jew juri żball ta' awtentikazzjoni/konnessjoni, iżda l-log tal-MITM juri li
s-sejħiet inizjali (`loadCodeAssist`, `fetchAvailableModels`, …) qed jirritornaw `200`.

Kawża: ir-**runtime Node/Electron inkluż mal-IDE jinjora l-maħżen tal-fiduċja tal-OS**. Il-backend
nattiv (server tal-lingwa Go) jafda lis-CA tal-OS u jawtentika, iżda l-frontend ta' Electron
ma jagħmilx dan — għalhekk l-UI taħseb li mhijiex konnessa.

Soluzzjoni (iż-żewġ passi): esporta `NODE_EXTRA_CA_CERTS=<ca.crt>` **u erġa' niedi l-IDE minn dak
is-shell**, mhux mill-ikona tad-desktop. L-ewwel agħlaq kompletament l-IDE — il-lock tas-singleton ta'
Electron ifisser li tnedija oħra sempliċement tiffoka l-proċess eżistenti u l-ambjent il-ġdid jiġi injorat. Ara §3.2.
Dan jirrifletti rapport upstream miftuħ fejn aġent awtonomu jaħdem permezz ta' MITM iżda l-varjant tal-IDE
ifalli bl-istess konfigurazzjoni.

### Id-DNS ma ġiex propagat

Iċċekkja li `/etc/hosts` ġie aġġornat:

```bash
grep "omniroute\|127.0.0.1.*github\|127.0.0.1.*cursor" /etc/hosts
```

Battal il-cache tad-DNS:

```bash
# macOS
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder
# Linux (systemd-resolved)
sudo systemctl restart systemd-resolved
# Windows
ipconfig /flushdns
```

### L-IDE ma nstabx

L-individwazzjoni awtomatika tuża mogħdijiet komuni ta' installazzjoni. Jekk l-individwazzjoni tfalli iżda l-IDE huwa installat:

- Iċċekkja jekk il-binarju tal-IDE jinsabx f'post mhux standard
- Is-Setup Wizard xorta jaħdem — il-falliment tal-individwazzjoni jfisser biss li l-badge mhux se juri l-mogħdija tal-installazzjoni

### Żbalji fil-handler (it-tniżżil upstream ifalli)

Jekk AgentBridge jinterċetta iżda t-talbiet kollha jfallu:

1. Ivverifika li mill-inqas fornitur wieħed huwa konness f'`/dashboard/providers`
2. Iċċekkja l-logs tas-server OmniRoute: `APP_LOG_LEVEL=debug` f'`.env`
3. Ivverifika li `OMNIROUTE_BASE_URL` jindika l-endpoint korrett tar-router (default: `http://127.0.0.1:20128`)

### Investigazzjoni ta' Trae

Trae huwa assistent tal-kodifikazzjoni bl-IA relattivament ġdid. Qabel ma jiġi implimentat handler:

1. Identifika l-binary/extension fis-swieq ta' VS Code / JetBrains jew bħala app awtonoma

4. Evalwa jekk għandux jitkompla jew le abbażi tat-TOS u kemm l-API tista' tiġi skoperta

Sakemm titlesta l-investigazzjoni, il-kard ta' Trae fid-dashboard turi badge "Taħt investigazzjoni" b'link "Irrapporta l-vijabbiltà". L-istub tal-handler f'`src/mitm/handlers/trae.ts` jitfa' żball strutturat `Għadu mhux implimentat`.
