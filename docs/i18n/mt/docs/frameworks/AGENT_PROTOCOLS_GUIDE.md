OmniRoute jesponi tliet interfaċċi differenti relatati mal-aġenti. Għall-ewwel jidhru simili, iżda jsolvu problemi differenti. Uża din il-paġna biex tagħżel dik it-tajba.

## Fil-Qosor

| Interfaċċa                        | L-aħjar għal                                                                                                                                                | Trasport                             | Standard                           |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ | ---------------------------------- |
| **A2A — Minn Aġent għal Aġent**   | Kollaborazzjoni bejn aġenti ma' aġenti pari li jużaw il-protokoll A2A                                                                                       | JSON-RPC 2.0 fuq HTTP                | A2A v0.3 (speċifikazzjoni miftuħa) |
| **ACP — Reġistru tal-Aġenti CLI** | Sejbien / reġistrazzjoni / tħaddim ta' aġenti CLI għall-ipprogrammar installati fuq il-magna tal-utent (Cursor, Cline, Codex CLI, Claude Code, Aider, eċċ.) | HTTP REST                            | Speċifiku għal OmniRoute           |
| **Aġenti tal-Cloud**              | Sottomissjoni ta' kompiti tal-ipprogrammar fit-tul lil servizzi cloud esterni (Codex Cloud, Devin, Jules, Cursor Cloud)                                     | HTTP REST + kompiti sostnuti minn DB | Speċifiku għal OmniRoute           |

It-tlieta huma indipendenti — agħżel kwalunkwe subsett.

## Siġra tad-Deċiżjonijiet

```
Għandek bżonn servizz cloud biex jagħmel xogħol barra minn din il-magna (Codex Cloud / Cursor Cloud / Devin / Jules)?
├─ IVA → Aġenti tal-Cloud (POST /api/v1/agents/tasks)
└─ LE → Kompli
    │
    Għandek aġent pari li juża A2A u jrid jikkollabora?
    ├─ IVA → A2A (POST /a2a)
    └─ LE → Kompli
        │
        Għandek bżonn telenka / tikkonfigura aġenti CLI għall-ipprogrammar installati lokalment?
        ├─ IVA → ACP (GET /api/acp/agents)
        └─ LE → Uża /v1/chat/completions direttament
```

## 1. A2A — Minn Aġent għal Aġent

**Speċifikazzjoni:** [A2A v0.3](https://a2a-protocol.org)
**Endpoint ta' OmniRoute:** `POST /a2a` (JSON-RPC 2.0)
**Kard tal-Aġent:** `GET /.well-known/agent.json`

### Meta għandek tużah

- Meta tkun qed tibni sistema b'diversi aġenti fejn OmniRoute ikun wieħed mill-pari
- Meta tkun qed tesponi l-intelliġenza tar-routing ta' OmniRoute (routing intelliġenti, ġestjoni tal-kwoti, eċċ.) lil aġenti f'oqfsa bħal Google ADK jew f'networks ġeneriċi ta' aġenti
- Meta tkun qed tqiegħed OmniRoute wara interfaċċa standard ta' skoperta + invokazzjoni

### Metodi

- `message/send` — issottometti messaġġ u rċievi tweġiba sinkronika
- `message/stream` — issottometti u rċievi avvenimenti tal-progress trażmessi permezz ta' SSE
- `tasks/get` — aqra kompitu skont l-ID
- `tasks/cancel` — ikkanċella kompitu li jkun qed jitħaddem

### Ħiliet integrati (6)

- `smart-routing` — għaddi prompt mill-aħjar kombinazzjoni
- `quota-management` — irrapporta l-istat tal-kwota għal kull fornitur
- `provider-discovery` — elenka l-fornituri installati flimkien mal-kapaċitajiet tagħhom
- `cost-analysis` — stima l-ispiża ta' talba/konverżazzjoni
- `health-report` — agħmel aggregazzjoni tal-istat tal-breaker/cooldown/lockout għal kull fornitur
- `list-capabilities` — elenka l-ħiliet disponibbli tal-aġent u l-metadata

### Analiżi fil-fond

Ara [A2A-SERVER.md](./A2A-SERVER.md) għad-dettalji tat-trasport, l-istruttura tal-kard tal-aġent, il-konfigurazzjoni tat-TTL tal-kompiti, u l-mudell biex iżżid ħiliet ġodda.

## 2. ACP — Reġistru tal-Aġenti CLI

**Endpoint ta’ OmniRoute:** `GET /api/acp/agents`
**Sors:** `src/lib/acp/{index,manager,registry}.ts`

### X’inhu

ACP huwa l-**inventarju lokali tal-aġenti CLI** ta’ OmniRoute. Jidentifika liema CLIs tal-ipprogrammar huma installati fuq il-host (Cursor, Cline, Claude Code, Codex CLI, Continue, eċċ.), jiddetermina l-verżjonijiet tagħhom, u jurihom fid-dashboard sabiex l-utent ikun jista’ jikkonfigura kull CLI biex tipponta lejn OmniRoute.

Dan MHUX protokoll estern — huwa reġistru intern li jħaddem l-interfaċċa tal-utent “CLI Tools” u t-traċċar tal-marki tas-swaba’ tas-CLI (ara [CLI-TOOLS.md](../reference/CLI-TOOLS.md)).

### X’jagħmel

- Jiċċekkja l-host għal binarji CLI installati (juża `which` / `where` skont is-sistema operattiva)
- Jaqra l-verżjoni ta’ kull CLI (isejjaħ `<bin> --version`)
- B’mod fakultattiv jaċċetta aġenti personalizzati ddefiniti mill-utent (mogħdija tal-binarju + kontroll tal-verżjoni + argumenti tat-tnedija)
- Jippersisti l-aġenti personalizzati fis-settings
- Jirritorna l-lista unifikata lid-dashboard

### API REST

| Endpoint          | Metodu | Deskrizzjoni                                                               | Awtentikazzjoni |
| ----------------- | ------ | -------------------------------------------------------------------------- | --------------- |
| `/api/acp/agents` | GET    | Elenka l-aġenti identifikati + personalizzati (għadd installat/total)      | Ċavetta API     |
| `/api/acp/agents` | POST   | Żid/aġġorna/neħħi aġent personalizzat (diskriminatur tal-azzjoni fil-body) | Ċavetta API     |

L-istruttura tal-body għal POST (`customAgentBodySchema` f’`src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### Każijiet ta’ użu

- Il-paġna “CLI Tools” tad-dashboard telenka x’inhu installat u tgħinek tipponta kull wieħed lejn OmniRoute
- L-aġenti personalizzati jippermettu lill-utenti avvanzati jirreġistraw CLIs interni/proprjetarji li OmniRoute ma jafx bihom b’mod awtomatiku
- Ir-riżultat tal-identifikazzjoni jalimenta l-matriċi tal-marki tas-swaba’ `cli-tools`

### Meta MA għandekx tuża ACP

- ACP ma _jħaddimx_ kompiti. Huwa jidentifika u jikkonfigura biss is-CLIs. Biex effettivament tinvoka CLI, tniediha int stess bil-varjabbli tal-ambjent ipprovduti minn OmniRoute (`OPENAI_BASE_URL`, `OPENAI_API_KEY`, eċċ.).

## 3. Aġenti tal-Cloud

**Endpoints ta’ OmniRoute:** `/api/v1/agents/tasks/*` (ċiklu tal-ħajja) + `/api/cloud/*` (infrastruttura ta’ konnessjoni)
**Sors:** `src/lib/cloudAgent/`

### X’inhu

Interfaċċa uniformi għall-aġenti tal-ipprogrammar tal-cloud ta’ partijiet terzi. Int tibgħat prompt + URL tar-repożitorju, OmniRoute jgħaddih lill-aġent tal-cloud it-tajjeb, jiċċekkja perjodikament l-istatus, u jirritorna r-riżultati.

### Aġenti appoġġjati (4, kollha kkonfermati f’`src/lib/cloudAgent/agents/`)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### Ċiklu tal-ħajja

```
POST /api/v1/agents/tasks
  → BaseAgent.createTask() għal kull klassi ta’ aġent
  → is-servizz estern jibda x-xogħol
  → tinħoloq ringiela tal-kompitu fid-DB (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → sinkronizzazzjoni għażżiena tal-istatus mill-fornitur
  → jirritorna l-istatus attwali + il-pjan + ir-reġistru tal-attività
  ↓
POST /api/v1/agents/tasks/[id]   (azzjoni: "approve" | "message" | "cancel")
  → jgħaddiha lill-fornitur (jew jimmarkaha bħala kkanċellata lokalment)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → kanċellazzjoni lokali
```

### Awtentikazzjoni

⚠️ **L-endpoints kollha `/api/v1/agents/tasks/*` jeħtieġu awtentikazzjoni tal-ġestjoni** (commit `588a0333`). Min jagħmel sejħiet b’Bearer biss jirċievi 401 minn v3.8.0 ’l quddiem.

### Analiżi dettaljata

Ara [CLOUD_AGENT.md](./CLOUD_AGENT.md) għall-kuntratt `CloudAgentBase`, id-dettalji speċifiċi għal kull aġent, id-dettalji tal-iskema, u l-endpoints tal-infrastruttura tal-kredenzjali.

## Tqabbil: A2A vs Aġenti tal-Cloud

It-tnejn għandhom "kompiti fit-tul", iżda f'livelli differenti:

| Aspett                     | A2A                                                                                                                  | Aġenti tal-Cloud                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Standard                   | Open A2A v0.3                                                                                                        | Speċifiku għal OmniRoute                                   |
| Fejn isir il-komputazzjoni | Ġewwa OmniRoute (juża l-kombinazzjonijiet ikkonfigurati)                                                             | Esternament (servers ta' Codex / Devin / Jules)            |
| Tul tal-kompitu            | TTL predefinit ta' 5 minuti (konfigurabbli f'`TaskManager`)                                                          | Minn minuti sa sigħat                                      |
| Konxju tar-repożitorju     | Le (jgħaddi biss il-prompts)                                                                                         | Iva (URL tar-repożitorju + fergħa)                         |
| Każ ta' użu                | Kollaborazzjoni bejn l-aġenti, routing intelliġenti bħala servizz                                                    | Iddelega "implimenta l-karatteristika X fir-repożitorju Y" |
| Awtentikazzjoni            | `OMNIROUTE_API_KEY` fakultattiva għal `/a2a`; awtentikazzjoni ta' ġestjoni għall-għodod awżiljarji REST `/api/a2a/*` | Dejjem awtentikazzjoni ta' ġestjoni                        |

## Eżempji ta' Integrazzjoni

### Skopri l-kapaċitajiet A2A ta' OmniRoute

```bash
curl http://localhost:20128/.well-known/agent.json
```

Jirritorna l-Kard tal-Aġent bis-6 ħiliet kollha, it-trasporti u l-verżjoni.

### Sejjaħ lil OmniRoute bħala aġent A2A

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### Elenka l-aġenti CLI installati permezz ta' ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### Żid aġent CLI personalizzat

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

### Issottometti kompitu lil Aġent tal-Cloud

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Implement feature X in repo Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### Iċċekkja perjodikament l-istatus tal-kompitu fil-cloud

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```

## Meta Għandek Tuża Xiex

- **Frontend ta' chatbot / copilot** → `/v1/chat/completions` (kompatibbli ma' OpenAI — mhux protokoll tal-aġenti)
- **Kollaborazzjoni bejn diversi aġenti** → A2A
- **Elenkar tas-CLIs lokali fid-dashboard** → ACP
- **Delega ta' kompiti ta' kodifikazzjoni fit-tul lil servizzi tal-cloud** → Aġenti tal-Cloud
