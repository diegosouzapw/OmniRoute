OmniRoute jipprovdi ġabra magħżula ta’ proxies bla ħlas fit-tabella `free_proxies`,
sinkronizzata minn fornituri esterni (1proxy, proxifly, iplocate, webshare). Id-dashboard
juri dawn taħt **Settings → Free Proxies**. Dan id-dokument
ikopri l-iffiltrar, l-issortjar, l-għadd u r-rappurtar tal-iżbalji tas-sinkronizzazzjoni
fuq in-naħa tas-server li tesponi r-rotta tal-lista.

## Rotta tal-lista — `GET /api/settings/free-proxies`

Tirritorna parti ffiltrata, issortjata u paġinata flimkien mal-għadd totali. L-iffiltrar u
l-għadd isiru f’SQL, sabiex l-UI tkun tista’ turi t-total reali (eż. `Total: 0`)
mingħajr ma ttella’ kull ringiela fil-memorja.

### Parametri tal-query

| Param             | Tip                                | Default   | Tifsira                                                                                                                   |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`      | `LIKE` sensittiv għall-każ fuq il-kolonna tal-host (u tas-sors).                                                          |
| `protocol`        | string                             | `""`      | Filtru `type`: `http` / `https` / `socks4` / `socks5`. Vojt = kollha.                                                     |
| `country`         | string                             | `""`      | Filtru `countryCode` (ISO-2). Vojt = kollha.                                                                              |
| `minQuality`      | number                             | `0`       | Ringieli biss fejn `qualityScore >= minQuality`. `0` = l-ebda limitu minimu.                                              |
| `disabledSources` | string                             | `""`      | IDs tas-sorsi separati b’virgola li għandhom jiġu esklużi (eż. `proxifly,webshare`).                                      |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = punteġġ dekrexxenti; `latency` = latenza axxendenti (nulls fl-aħħar); `recent` = `lastValidated` dekrexxenti. |
| `offset`          | number                             | `0`       | Bidu tal-paġinazzjoni.                                                                                                    |
| `limit`           | number                             | `50`      | Daqs tal-paġna (limitat fuq in-naħa tas-server).                                                                          |

### Rispons

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 mis-sors estern"],
    "webshare": ["skadenza tal-ħin tan-network"]
  }
}
```

`total` jirrifletti t-total iffiltrat **qabel** il-paġinazzjoni, sabiex l-UI tkun tista’ turi
`Total: N` u `hasMore` indipendentement. `syncErrors` juża l-ID tas-sors bħala ċavetta u
jimtela biss għas-sorsi li fallew fl-aħħar sinkronizzazzjoni tagħhom — riżultat `Total: 0`
qatt ma jkun mingħajr spjegazzjoni.

## Żieda mal-ġabra — `POST /api/settings/free-proxies/[id]/add-to-pool`

Jippromwovi proxy bla ħlas għall-ġabra amministrata `proxy_registry`. L-ewwel jivvalida
s-sors estern; meta jirnexxi, jirritorna l-ID il-ġdid tal-proxy fil-ġabra u l-latenza mkejla.

## Sinkronizzazzjoni — `POST /api/settings/free-proxies/sync`

Jerġa’ jiġbed is-sorsi attivati kollha (jew is-subsett f’`{ "sources": [...] }`). Kull
sors jissinkronizza indipendentement; sors li jfalli jiġi rreġistrat f’`syncErrors` u
l-oħrajn xorta jitlestew, għalhekk sinkronizzazzjonijiet parzjali qatt ma jħassru data tajba preċedenti.

## Statistika — `GET /api/settings/free-proxies/stats`

Tirritorna l-aggregat `total / inPool / avgQuality / bySource / lastSyncAt`
mingħajr il-payload tar-ringieli — użat mill-widgets tal-header tad-dashboard.
