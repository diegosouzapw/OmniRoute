```
CLI Code's / CLI Agents (fluss tal-konsum):
Claude / Codex / OpenCode / Cline / KiloCode / Continue / Hermes Agent / Goose / ...
           │
           ▼  (kollha jippuntaw lejn OmniRoute)
    http://YOUR_SERVER:20128/v1
           │
           ▼  (OmniRoute jidderieġi lejn il-fornitur it-tajjeb)

    Talba tal-klijent → OmniRoute → iniedi CLI permezz ta’ stdio/ACP → tweġiba
```

**Benefiċċji:**

- Ċavetta API waħda biex timmaniġġja l-għodod kollha

- Qlib tal-mudell mingħajr ma terġa’ tikkonfigura kull għodda
- Jaħdem lokalment u fuq servers remoti (VPS, Docker, Akamai, Cloudflare Tunnel)

## Ikkonfigura awtomatikament b’`setup-*`

M’għandekx għalfejn tikteb il-konfigurazzjoni ta’ kull għodda manwalment. OmniRoute jipprovdi kmand `setup-*`
għal kull CLI appoġġjat li jaqra l-katalgu **attiv** tal-mudelli minn istanza ta’
OmniRoute li tkun qed taħdem (lokali jew remota) u jikteb il-konfigurazzjoni proprja tal-għodda fuq il-magna tiegħek:

```bash
omniroute setup-codex        omniroute setup-claude       omniroute setup-opencode
omniroute setup-cline        omniroute setup-kilo         omniroute setup-continue
omniroute setup-cursor       omniroute setup-roo          omniroute setup-crush
omniroute setup-goose        omniroute setup-qwen         omniroute setup-aider
omniroute setup-5dive
```

Kull wieħed jaċċetta `--remote <url> --api-key <key>` (biex tikkonfigura għodda lokali ma’
OmniRoute remot), `--dry-run` (biex tara minn qabel mingħajr ma tikteb), u `--port`. Għodod
mingħajr skoperta awtomatika tal-mudelli (Cline, Kilo, Roo, Goose, Aider, Qwen, 5dive) jieħdu
`--model <id>` (u `--yes` għal eżekuzzjonijiet mhux interattivi). `setup-5dive` huwa l-unika
riċetta li ma tiktebx taħt `$HOME`: tikkonfigura flotta ta’ aġenti 5dive billi
tikteb profil tal-awtentikazzjoni li jkun proprjetà ta’ root fuq il-host tal-flotta, għalhekk jerġa’ jeżegwixxi permezz ta’ `sudo`
u m’għandux mod remot tiegħu stess. Biex tniedi CLI bl-ambjent
it-tajjeb injettat u mingħajr ma tinkiteb ebda konfigurazzjoni, uża l-lanċjatur ġeneriku
`omniroute run <target>` (claude, codex, aider, goose, opencode, qwen,
gemini — il-miri u l-aliases jiġu minn `bin/cli/cli-manifest.mjs`); il-lanċjaturi antiki
speċifiċi għal kull għodda `omniroute launch` (Claude Code) u `omniroute launch-codex`
(Codex) jibqgħu disponibbli. Gemini CLI jista’ jitnieda biss: huwa mira ta’ `omniroute run`
iżda m’għandux riċetta `setup-*`/`configure`.

> **Referenza sħiħa:** it-tabella ewlenija — x’jikteb kull kmand, kull flag,
> lokali kontra remot, u liema għodod jeħtieġu s-suffiss `/v1` — tinsab fi
> **[Integrazzjonijiet CLI](../guides/CLI-INTEGRATIONS.md)**.

### Eżekuzzjoni ta’ dawn ġewwa container

Kmand `setup-*` eżegwit ġewwa l-container ta’ OmniRoute jikteb fid-direttorju home
tal-container stess, li ebda CLI fuq il-host ma jaqra u li jisparixxi flimkien mal-
container. OmniRoute jinduna b’dan u joħroġ bil-kodiċi `2` bi struzzjonijiet minflok
ma jikteb. Hemm żewġ modi appoġġjati biex tkompli — installa s-CLI fuq il-host u
uża `omniroute connect` biex tikkonnettja mal-container, jew agħmel bind-mount tad-direttorji tal-konfigurazzjoni u ssettja
`CLI_CONFIG_HOME` (il-profil `host` ta’ compose). Kull kmand `setup-*`, flimkien ma’
`omniroute configure` u `omniroute config set`, jaċċetta
`--allow-container-write` meta dak li fil-fatt trid hu li tikkonfigura l-CLIs tal-container
stess; `OMNIROUTE_ALLOW_CONTAINER_CONFIG_WRITE=true` jagħmel l-istess għas-
server. Ara
[Gwida ta’ Docker → Konfigurazzjoni tal-għodod CLI tal-host](../guides/DOCKER_GUIDE.md#configuring-host-cli-tools-when-omniroute-runs-in-docker).

L-**endpoint tal-applikazzjoni** tad-dashboard (`POST /api/cli-tools/apply`) jinforza l-
istess protezzjoni: f’container, operazzjoni ta’ kitba li l-mira tagħha mhijiex bind-mounted mill-
host twieġeb b’**`422`** flimkien ma’ `containerEphemeralTarget: true`, it-test sigur tal-iżball
u — għall-għodod li għandhom riċetta għall-host (claude, codex, opencode, cline,
kilo, continue) — `hostSetupCommand` (eż. `omniroute setup-opencode`) biex jiġi eżegwit
fuq il-host minflok; ma jinkiteb xejn. `dryRun: true` jibqa’ jaħdem fil-modalità container
u jirritorna previżjoni b’informazzjoni sensittiva moħbija flimkien mal-mogħdija tal-mira mingħajr ma jmiss id-disk. Il-kontenut tal-
previżjoni mhuwiex konfigurazzjoni li fiha kredenzjali biex tiġi kkupjata jew importata. Applika bl-
inputs oriġinali tal-għodda/URL bażi/ċavetta API/mudell fuq il-host, jew uża l-kmand ta’
setup fuq il-host indikat. Ara [Sigurtà tal-konfigurazzjoni CLI](../security/CLI-CONFIGURATION.md)
għall-header tal-previżjoni u l-kuntratt tat-talba. Din l-imġiba hija
intenzjonata u protetta kontra rigressjonijiet minn
`tests/unit/api/cli-tools/apply-container-guard.test.ts` — qatt “issewwi” 422
billi tneħħi l-protezzjoni.

## Sors Ewlieni

Il-katalgu unifikat jinsab f'`src/shared/constants/cliTools.ts` bħala `CLI_TOOLS: Record<string, CliCatalogEntry>`.

Kull entrata għandha dawn l-oqsma (iddefiniti f'`src/shared/schemas/cliCatalog.ts`):

| Qasam                                           | Tip                                                          | Deskrizzjoni                                                                       |
| ----------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| `category`                                      | `"code" \| "agent"`                                          | Fuq liema paġna tidher l-għodda                                                    |
| `vendor`                                        | `string`                                                     | Oriġini tal-għodda ("Anthropic", "OSS (P. Gauthier)")                              |
| `acpSpawnable`                                  | `boolean`                                                    | Tista' tintuża wkoll bħala Aġent ACP (tintwera badge)                              |
| `baseUrlSupport`                                | `"full" \| "partial" \| "none"`                              | Livell ta' appoġġ għal endpoint personalizzat. `"none"` = xogħol pendenti tal-MITM |
| `configType`                                    | `"env" \| "custom" \| "guide" \| "custom-builder" \| "mitm"` | Mekkaniżmu ta' konfigurazzjoni                                                     |
| `id`, `name`, `color`, `description`, `docsUrl` | standard                                                     | Oqsma ewlenin tal-wiri                                                             |

L-entrati b'`baseUrlSupport: "none"` **ma jintwerewx** fil-paġni tad-dashboard — huma rreġistrati fix-xogħol pendenti tal-MITM għall-pjan 11 (ara `_tasks/features-v3.8.6/refactorpages/_orchestration/_plan11-mitm-backlog.md`).

### Livelli ta' kapaċità (ikkatalogati × rilevabbli × konfigurabbli × eżegwibbli)

Mhux kull għodda kkatalogata tista' tiġi rilevata, ikkonfigurata jew eżegwita. Kull livell għandu sors wieħed
ta' dikjarazzjoni, u test tad-diskrepanzi jiżgura li jibqgħu allinjati:

| Livell            | Tifsira                                                                                     | Iddikjarat fi                                                         |
| ----------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **Ikkatalogat**   | Jidher fil-katalgu tad-dashboard (isem, fornitur, dokumentazzjoni, tip ta' konfigurazzjoni) | `src/shared/constants/cliTools.ts` (`CLI_TOOLS`)                      |
| **Rilevabbli**    | Rilevament tal-binarju/konfigurazzjoni, kontrolli tas-saħħa, mogħdijiet tal-konfigurazzjoni | `src/shared/services/cliRuntime.ts` (katalgu tar-runtime `CLI_TOOLS`) |
| **Konfigurabbli** | Appoġġjat minn `omniroute configure <cli>` (teżisti riċetta tas-setup)                      | `bin/cli/cli-manifest.mjs` (`configure: true`)                        |
| **Eżegwibbli**    | Appoġġjat minn `omniroute run <target>` (injezzjoni tal-ambjent/argumenti definita)         | `bin/cli/cli-manifest.mjs` (`run: true`)                              |

`bin/cli/cli-manifest.mjs` huwa l-manifest eżegwibbli kanoniku għall-interfaċċi tal-kmandi
CLI: `run`, `configure` u l-ġeneraturi tal-awtokompletament tax-shell kollha jiksbu minnu
l-listi tal-miri tagħhom, ir-riżoluzzjoni tal-aliases (pereżempju `kilocode`/`kilo-code`/`kilo_cli` → `kilo`)
u l-konnessjoni tal-flag `--model`. Il-gwardja kontra d-diskrepanzi
`tests/unit/cli/cli-manifest-drift.test.ts` tivverifika li l-manifest, il-katalgu tar-runtime,
il-katalgu tal-UI u kull interfaċċa tal-konsumatur jibqgħu sinkronizzati — mira miżjuda ma'
interfaċċa waħda mingħajr l-oħrajn twassal biex is-sett tat-testijiet ifalli minflok ma tinħoloq
diskrepanza fis-skiet.

## 5. API tad-Detezzjoni f’Lott

Id-detezzjoni kollha tal-għodod hija aggregata permezz ta’ endpoint wieħed:

**`GET /api/cli-tools/all-statuses`**

- Awtentikazzjoni: `requireCliToolsAuth(request)` (l-istess bħar-rotot l-oħra ta’ `/api/cli-tools/`)
- Jirritorna: `Record<toolId, ToolBatchStatus>` (tip: `src/shared/types/cliBatchStatus.ts`)
- Strateġija: `Promise.all` fuq l-għodod kollha, timeout ta’ 5s għal kull għodda
- Cache: LRU fil-memorja indiċjat skont l-`mtime` tal-fajl tal-konfigurazzjoni. Il-cache jiġi invalidat meta jinbidel l-mtime. Jiġi ssettjat mill-ġdid meta jerġa’ jibda s-server.

Struttura tar-rispons għal kull għodda:

```ts
interface ToolBatchStatus {
  detection: {
    installed: boolean;
    runnable: boolean;
    version?: string;
    command?: string;
    commandPath?: string;
    reason?: string;
  };
  config: {
    status: "configured" | "not_configured" | "not_installed" | "unknown" | "other";
    endpoint?: string | null;
    lastConfiguredAt?: string | null;
  };
  error?: string; // sanitizzat, mingħajr traċċi tal-munzell
}
```

## 10. CLI Interna ta’ OmniRoute

Il-binarju `omniroute` jipprovdi kmandi għaċ-ċiklu tal-ħajja tas-server, il-konfigurazzjoni, id-dijanjostika, u l-ġestjoni tal-fornituri. Punt tad-dħul: `bin/omniroute.mjs`.

```bash

omniroute reset-password               # Irrisettja l-password tal-amministratur
omniroute logs                         # Xandar kontinwament il-logs tat-talbiet

```

### Konfigurazzjoni u Inizjalizzazzjoni

```bash
omniroute setup                        # Assistent interattiv tal-konfigurazzjoni
omniroute setup --non-interactive      # Modalità CI/awtomatizzazzjoni (taqra varjabbli tal-ambjent + flags)
omniroute setup --password '<value>'   # Issettja l-password tal-amministratur direttament
omniroute setup --add-provider \
  --provider openai \
  --api-key '<value>' \
  --test-provider                      # Żid u ttestja fornitur f’pass wieħed
```

Varjabbli tal-ambjent rikonoxxuti għall-konfigurazzjoni mhux interattiva:

| Var                 | Għan                                                                              |
| ------------------- | --------------------------------------------------------------------------------- |
| `OMNIROUTE_API_KEY` | Ċavetta API tal-fornitur (marbuta ma’ `--api-key` permezz ta’ Commander `.env()`) |
| `DATA_DIR`          | Ibdel id-direttorju tad-data ta’ OmniRoute                                        |

L-inputs l-oħra kollha mhux interattivi jiġu mgħoddija bħala flags, mhux bħala varjabbli tal-ambjent:
`--password`, `--provider`, `--provider-name`, `--provider-base-url`, `--default-model`
(ara l-għażliet ta’ `omniroute setup` hawn fuq).

### Dijanjostika

```bash
omniroute doctor                       # Iċċekkja l-konfigurazzjoni, id-DB, il-ports, ir-runtime, il-memorja u l-istat operattiv
omniroute doctor --json                # JSON li jista’ jinqara minn magna
omniroute doctor --no-liveness         # Aqbeż is-sonda tal-istat HTTP
omniroute doctor --host 0.0.0.0        # Ibdel il-host tal-kontroll tal-istat operattiv
omniroute doctor --liveness-url <url>  # Ibdel il-URL sħiħ tal-endpoint tal-istat
```

Il-kmand doctor iwettaq dawn il-kontrolli: `Config`, `Database`, `Storage/encryption`,
`Port availability`, `Node runtime`, `Native binary` (better-sqlite3),
`Memory`, u `Server liveness`. Joħroġ b’kodiċi mhux żero jekk xi kontroll ikun `fail`.

### Ġestjoni tal-Fornituri

```bash
omniroute providers available                       # Katalgu tal-fornituri ta’ OmniRoute
omniroute providers available --search openai       # Iffiltra l-katalgu skont id/isem/alias/kategorija
omniroute providers available --category api-key    # Iffiltra skont il-kategorija (api-key, oauth, free, ...)
omniroute providers available --json                # JSON li jista’ jinqara minn magna

omniroute providers list                            # Konnessjonijiet tal-fornituri kkonfigurati
omniroute providers list --json

omniroute providers test <id|name>                  # Ittestja konnessjoni kkonfigurata waħda
omniroute providers test-all                        # Ittestja kull konnessjoni attiva
omniroute providers validate                        # Validazzjoni strutturali lokali biss

omniroute providers import ./providers.json --dry-run --json

```

`providers add/import/auth/edit/remove` jużaw l-API bħala l-metodu primarju u għalhekk jaħdmu mal-kuntest
lokali jew remot attiv. Għall-input tal-kredenzjali għandhom jintużaw
`--credential-stdin` jew `--credential-env`; `--dry-run --json` jirrapporta biss
il-preżenza/forma b’informazzjoni sensittiva moħbija. `providers available` jaqra l-katalgu ta’ OmniRoute;
`providers list/test/test-all/validate` iżommu l-imġiba lokali tagħhom ta’ SQLite u
ma jeħtiġux li s-server ikun qed jaħdem.

```bash

```

### Esportazzjoni tal-Kredenzjali (⚠ ittrattahom b’attenzjoni)

```bash
omniroute auth export                                 # Uri twissija + pass ta’ konferma — ebda aċċess għad-DB
omniroute auth export --force                          # Esporta l-kredenzjali DEKRIPTATI tal-konnessjonijiet KOLLHA lejn stdout bħala JSON
omniroute auth export --force --id <id>                 # Esporta biss il-konnessjoni li taqbel
omniroute auth export --force --format env               # Oħroġ linji OMNIROUTE_<PROVIDER>_<FIELD>=<value>
omniroute auth export --force --out creds.json           # Ikteb f’fajl (jinħoloq bil-permessi 0600)
```

`auth export` huwa **lokali biss** (qari dirett minn SQLite, ebda rotta HTTP) u intenzjonalment jistampa/jikteb
il-valuri **f’test sempliċi** ta’ `apiKey`/`accessToken`/`refreshToken`/`idToken` — din hija l-funzjonalità, mhux
bug. Ma jinqara xejn mid-database, u ma jiġi ddekriptat xejn, mingħajr `--force`. Banner ta’
twissija dejjem jiġi stampat fuq stderr qabel ma jinħareġ kwalunkwe test sempliċi. Jeħtieġ li `STORAGE_ENCRYPTION_KEY`
tkun issettjata. Field li ma jkunx jista’ jiġi ddekriptat (ċavetta antika, ciphertext korrott) jiġi rrappurtat bħala
`<field>DecryptFailed: true` minflok ma titwaqqaf l-esportazzjoni kollha jew jiġi żvelat l-iżball sottostanti.
