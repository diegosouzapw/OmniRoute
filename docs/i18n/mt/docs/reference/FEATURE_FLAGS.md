> Swiċċijiet waqt l-eżekuzzjoni li jbiddlu l-imġiba ta’ OmniRoute **mingħajr skjerament mill-ġdid**.
> Kull indikatur elenkat hawn huwa definit f’
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — is-sors uniku tal-verità. Kemm id-dashboard kif ukoll l-API REST jaqraw minn
> dak il-fajl, għalhekk it-tabella ta’ hawn taħt hija ġġenerata biex taqbel miegħu 1:1.

---

## X’Inhuma l-Indikaturi tal-Karatteristiċi

Indikatur ta’ karatteristika huwa swiċċ b’isem (boolean jew enum) li l-valur tiegħu jista’ jinbidel waqt
l-eżekuzzjoni u jinħażen b’mod persistenti fid-database, mingħajr il-ħtieġa ta’ skjerament mill-ġdid tal-proċess. Kull
indikatur huwa deskritt minn `FeatureFlagDefinition` bi `key`, `label`,
`description`, `category`, `defaultValue`, `type`, u indikazzjoni `requiresRestart`.

### Ordni tar-Riżoluzzjoni

Il-**valur effettiv** ta’ indikatur jiġi riżolt minn
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) skont din
il-preċedenza (jirbaħ dak bl-ogħla preċedenza):

1. **Sovrastruttura tad-DB** — valur maħżun fit-tabella `key_value` taħt l-ispazju tal-ismijiet
   `feature_flags` (issettjat permezz tad-dashboard jew tal-API REST).
2. **Varjabbli tal-ambjent** — `process.env[<KEY>]`, jekk tkun issettjata u mhix vojta.
3. **Valur predefinit tad-definizzjoni** — id-`defaultValue` minn `featureFlagDefinitions.ts`.

Indikatur boolean jitqies **attivat** meta l-valur effettiv tiegħu jkun `"true"`,
`"1"`, jew `"yes"` (ara `isFeatureFlagEnabled()`).

> [!NOTE]
> Il-biċċa l-kbira tal-indikaturi għandhom ukoll varjabbli tal-ambjent korrispondenti bl-**istess isem**
> iddokumentata f’[`ENVIRONMENT.md`](./ENVIRONMENT.md). Is-sovrastruttura tad-DB tal-indikatur
> tieħu preċedenza fuq dik il-varjabbli tal-ambjent. Indikatur b’
> `requiresRestart: true` jinħażen b’mod persistenti minnufih iżda jerġa’ jinqara biss mal-istartjar
> tal-proċess — il-bidla tiegħu turi banner **"Erġa’ Ibda s-Server"** fid-dashboard.

## Attivazzjoni u Diżattivazzjoni tal-Markaturi

### Dashboard

Mur f’**Dashboard → Settings → Feature Flags**
(`/dashboard/settings/feature-flags`). Il-grilja
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
tappoġġja:

- **Tiftix** skont iċ-ċavetta jew id-deskrizzjoni, u **filtrazzjoni** skont il-kategorija (flimkien ma’ dehra sintetika
  **Requires Restart**).
- **Toggle** għall-markaturi Boolean u **dropdown** għall-markaturi enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Badge tas-sors** għal kull markatur — `DB`, `ENV`, jew `DEF` — li juri minn fejn ġie
  l-valur effettiv.
- Buttuna **Reset** (murija biss għal markaturi li s-sors tagħhom huwa `DB`) biex titneħħa s-sovrastruttura,
  u buttuna **Reset All Overrides** fil-qiegħ.
- Banner **Restart Server** meta jinbidel markatur `requiresRestart`.

### API REST

L-operazzjonijiet kollha jgħaddu minn rotta waħda:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Kull metodu jeħtieġ sessjoni awtentikata tad-dashboard (inkella jingħata `401`).

#### `GET /api/settings/feature-flags`

Jirritorna kull markatur bil-valur effettiv tiegħu, is-sors, u sommarju.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Jeħtieġ API Key",
      "description": "Jeħtieġ API key għat-talbiet kollha li jidħlu",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... it-72 markatur kollha
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Issettja jew neħħi sovrastruttura waħda. Korp: `{ key: string; value?: string }`.
Jekk `value` jitħalla barra, is-sovrastruttura titneħħa (u jerġa’ jiġi stabbilit il-valur tal-env / default).

```bash
# Issettja sovrastruttura fid-DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Neħħi s-sovrastruttura (mingħajr "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Ir-rispons jirrepeti l-`effectiveValue`/`source` il-ġodda, il-`previousValue`/
`previousSource`, u `requiresRestart`. Ċwievet mhux magħrufa u valuri enum
barra mill-firxa jiġu rrifjutati b’`400`.

#### `DELETE /api/settings/feature-flags`

Ineħħi **s-sovrastrutturi kollha** tad-DB f’daqqa, u jerġa’ jistabbilixxi kull markatur għall-valur
tal-env / default tiegħu. Jirritorna `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Markaturi b’`requiresRestart: true` jidħlu fis-seħħ biss wara li l-proċess jerġa’ jitgħabba.
> Il-fluss tar-restart tad-dashboard isejjaħ `POST /api/restart` u mbagħad jiċċekkja ripetutament
> `GET /api/health/ping` sakemm is-server jerġa’ jibda jaħdem.

## Riżerva ta’ Emerġenza għall-Baġit

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, default `true`) jikkontrolla
r-rotta ta’ riżerva bla ħlas ta’ emerġenza f’
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Meta jkun attivat, it-talbiet li jeżawrixxu l-baġit tagħhom jiġu diretti lejn
fornitur/mudell ta’ riżerva bla ħlas minflok ma jfallu għalkollox. Issettjah għal `false` (jew `0`) — permezz tat-
toggle tad-dashboard, sovrastruttura tad-DB, jew il-varjabbli tal-ambjent `OMNIROUTE_EMERGENCY_FALLBACK`
— biex tiddiżattiva din l-imġiba u tħalli t-talbiet li jkunu eżawrew il-baġit
ifallu. (Deher bħala toggle fid-dashboard fil-PRs #3741 / #3752.)
