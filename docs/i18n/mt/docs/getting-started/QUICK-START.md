## Pass 1: Installa OmniRoute

Agħżel il-metodu li tippreferi:

### Għażla A: npm (Rakkomandata)

```bash
npm install -g omniroute
```

### Għażla B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` hija l-ogħla verżjoni SemVer stabbli **ppubblikata**. Din **ma** ssegwix il-fergħa `main` ta' git. Uża `diegosouzapw/omniroute:X.Y.Z` bħala verżjoni fissa għal GitOps. Ara [Tags tal-Immaġni / Kanali tar-Rilaxx](../guides/DOCKER_GUIDE.md#release-channels).

### Għażla C: Mill-Kodiċi Sors

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Pass 2: Ibda OmniRoute

```bash
omniroute
```

OmniRoute jibda fuq `http://localhost:20128`. Id-dashboard jinfetaħ awtomatikament.

---

## Pass 3: Qabbad Fornitur Bla Ħlas

Tista' tuża OmniRoute **mingħajr ma tħallas xejn** billi tqabbad fornitur bla ħlas.

### Għażla A: Kiro (Claude Bla Ħlas — Mingħajr Karta ta' Kreditu)

1. Iftaħ id-dashboard fuq `http://localhost:20128`
2. Mur f'**Fornituri** → **Żid Fornitur**
3. Agħżel **Kiro AI**
4. Ikklikkja **Qabbad** (ma teħtieġ l-ebda ċavetta tal-API!)
5. Lest! Issa għandek aċċess bla ħlas għall-mudelli Claude.

### Għażla B: OpenCode Free (Mingħajr Awtentikazzjoni)

1. Iftaħ id-dashboard fuq `http://localhost:20128`
2. Mur f'**Fornituri** → **Żid Fornitur**
3. Agħżel **OpenCode Free**
4. Ikklikkja **Qabbad** (ma teħtieġ l-ebda ċavetta tal-API!)
5. Lest! Issa għandek aċċess bla ħlas għal diversi mudelli.

### Għażla C: Pollinations (Ma Teħtieġx Ċavetta)

1. Iftaħ id-dashboard fuq `http://localhost:20128`
2. Mur f'**Fornituri** → **Żid Fornitur**
3. Agħżel **Pollinations**
4. Ikklikkja **Qabbad** (ma teħtieġ l-ebda ċavetta tal-API!)
5. Lest! Issa għandek aċċess bla ħlas għal GPT-5, Claude, Gemini, u aktar.

## Pass 4: Ivverifika li Jaħdem

Minn [Ċwievet tal-API](http://localhost:20128/dashboard/api-manager), oħloq ċavetta ġdida. Żomm din iċ-ċavetta peress li mhux se terġa' tidher. Innota li din iċ-ċavetta tintuża biex l-għodod jaċċessaw OmniRoute, mhux biex jaċċessaw lill-fornituri upstream.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Għandek tara lista tal-mudelli mqabbdin tiegħek.

## Pass 5: Orjenta l-IDE jew is-CLI Tiegħek Lejn OmniRoute

Fl-għodda IDE jew CLI tiegħek, issettja:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

Dak kollox! L-IDE tiegħek issa juża OmniRoute b'għażla awtomatika tal-fornitur.

### Eżempju ta' IDE: VSCode/Continue.dev

1. F'VSCode, installa l-estensjoni [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Aġġorna `~/.continue/config.yaml` tiegħek biex iżżid il-linji li ġejjin:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Fil-pannell taċ-chat ta' Continue.dev, agħżel `OmniRoute - Auto` u tibda tagħmel talbiet lil OmniRoute.
4. (Fakultattiv) Eżerċizzju għall-qarrej — itlob lill-IDE tiegħek jaġġorna `config.yaml` bil-konfigurazzjonijiet l-oħra kollha mibnija minn qabel 😊

### Eżempju ta' CLI: Codex CLI

1. Fis-sistema operattiva tiegħek, issettja l-varjabbli tal-ambjent b'mod permanenti.
   Għal macOS/Linux (żidha ma' `~/.bashrc` jew `~/.zshrc` tiegħek):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Għal Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Issa ejja nniedu Codex, iżda kkonfigurat għal OmniRoute. Ħaddem:

```
omniroute launch-codex --model auto
```

Tista' tagħmel dan manwalment permezz ta' `codex` u parametri tal-linja tal-kmand biex tispeċifika l-endpoint u ċ-ċavetta tal-API, iżda bil-kmand ta' hawn fuq, OmniRoute jieħu ħsieb kollox għalik.

L-istess tnedija bi kmand wieħed taħdem għal CLIs oħra permezz tal-launcher ġeneriku — `omniroute run <target>` jappoġġja `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, u `gemini` (ara [Integrazzjonijiet tas-CLI](../guides/CLI-INTEGRATIONS.md)).

3. Is-CLI issa għandu jkun qed jibgħat it-talbiet lil OmniRoute.

### Ikkonferma li l-għodda tiegħek qed tidderieġi t-talbiet lejn OmniRoute

Tista' tara d-dettalji tat-talba billi tikklikkja [Monitoraġġ/Logs](http://localhost:20128/dashboard/logs) mill-sidebar tax-xellug. Meta tikklikkja fuqhom tara aktar dettalji. Barra minn hekk, tista' tara liema informazzjoni tintbagħat mill-harness favorit tiegħek. Dan huwa utli għal skopijiet edukattivi u ta' debugging.

## Mistoqsijiet Komuni

### "Għandi bżonn ċavetta tal-API?"

**Le!** Tista' tuża fornituri bla ħlas (Kiro, OpenCode Free, Pollinations) mingħajr l-ebda ċavetta tal-API. Sempliċement qabbadhom fid-dashboard.

### "X'inhu `auto`?"

`auto` jgħid lil OmniRoute biex jagħżel awtomatikament l-aħjar fornitur għal kull talba. Dan iqis il-veloċità, l-ispiża, il-kwalità u d-disponibbiltà. Ara l-[Gwida għal Auto-Combo](./AUTO-COMBO-GUIDE.md) għad-dettalji.

### "Kemm jiswa?"

OmniRoute innifsu huwa **bla ħlas u open-source**. Tħallas biss għall-fornituri li tuża. Ħafna fornituri għandhom livelli bla ħlas — ara l-[Gwida għall-Livelli Bla Ħlas](./FREE-TIERS-GUIDE.md).

### "Nista' nużah ma' Claude Code / Cursor / Copilot?"

**Iva!** OmniRoute jaħdem ma' kwalunkwe għodda li tappoġġja l-format OpenAI. Sempliċement issettja l-URL bażi għal `http://localhost:20128/v1`. Ara l-[Gwida għall-Għodod tas-CLI](../reference/CLI-TOOLS.md) għal istruzzjonijiet speċifiċi dwar il-konfigurazzjoni.

### "X'jiġri jekk fornitur ma jibqax disponibbli?"

OmniRoute awtomatikament jaqbeż lill-fornituri li fallew u jipprova lil dak li jmiss. M'għandek bżonn tagħmel xejn. Ara l-[Gwida għal Auto-Combo](./AUTO-COMBO-GUIDE.md) għad-dettalji.
