**OmniCopilot** ipoġġi kull mudell li jservi OmniRoute tiegħek fis-selettur _nattiv_ tal-mudelli ta’ GitHub Copilot Chat.
L-ebda sidebar ieħor, l-ebda UI taċ-chat separata — il-modalità tal-aġent ta’ Copilot, is-sejħiet tal-għodod,
is-servers MCP u l-istruzzjonijiet personalizzati kollha jibqgħu jaħdmu, sempliċement fuq il-mudell li tagħżel.

> **M’hemmx bżonn abbonament ta’ Copilot.** Minn VS Code 1.122 ’il quddiem, fornitur ta’ mudelli lingwistiċi jaħdem
> mingħajr ma tidħol f’GitHub u mingħajr ebda pjan ta’ Copilot. It-tlestijiet inline u
> l-karatteristiċi bbażati fuq embeddings jibqgħu barra mill-API tal-fornitur u xorta jeħtieġu Copilot.

## Konfigurazzjoni

1. **Ħaddem OmniRoute** — `npm install -g omniroute && omniroute` (dashboard fuq `http://localhost:20128`).
2. **Installa l-estensjoni** — fittex "OmniRoute" fil-veduta tal-Estensjonijiet.
3. **Agħżel mudell** — Copilot Chat → selettur tal-mudelli → **Immaniġġja l-Mudelli…** → **OmniRoute**, imbagħad immarka
   dak li trid.

M’hemm xejn x’tikkonfigura meta OmniRoute jaħdem fuq il-port predefinit. Għal istanza remota, iftaħ
l-**ikona ta’ OmniRoute fl-Activity Bar** (jew ħaddem `OmniRoute: Manage Connection`) u ssettja:

- **URL tas-server** — l-għerq tas-server, eż. `http://192.168.0.15:20128`. Is-suffiss `/v1`
  jiżdied mill-estensjoni; tinkludihx.
- **Ċavetta tal-API** — biss meta s-server jistabbilixxi `REQUIRE_API_KEY`. Tinħażen fil-keychain tal-OS permezz ta’
  VS Code SecretStorage, u qatt f’`settings.json`.

## X’se juri s-selettur

L-estensjoni ma turix direttament il-payload ta’ `GET /v1/models` — tifformattjah, u l-għadd li
tara huwa iżgħar mid-daqs tal-katalgu għal żewġ raġunijiet intenzjonati.

### Titlob id wieħed għal kull mudell

`MODELS_CATALOG_PREFIX_MODE` għandu **`dual`** bħala valur predefinit, li jirreklama kull mudell darbtejn — darba
taħt il-prefiss qasir tal-alias u darba taħt il-prefiss kanoniku tal-fornitur — sabiex konfigurazzjonijiet
eqdem tal-klijenti jibqgħu jirriżolvu ż-żewġ forom:

```
cc/claude-sonnet-4-6        ← prefiss tal-alias
claude/claude-sonnet-4-6    ← prefiss kanoniku, l-istess mudell
```

L-estensjoni titlob **`GET /v1/models?prefix=alias`** sabiex jasal id wieħed għal kull mudell, mingħajr
ma tbiddel is-setting tas-server kollu għall-klijenti l-oħra tiegħek. Fuq istanza ta’ referenza dan naqqas
**2345 entrata għal 1396 — 949 duplikat, żero mudelli mitlufa.**

Jekk tippreferi tirranġa dan fis-server kollu għal _kull_ klijent, issettja l-feature flag
`MODELS_CATALOG_PREFIX_MODE` għal `alias` fid-dashboard. Ara
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) għall-parametru
tal-query u t-tabella għal kull modalità.

### Taħbi mudelli li ma jistgħux jiċċettjaw

Il-katalgu jelenka wkoll mudelli tal-immaġni, tal-vidjo, tal-awdjo, tar-reranking, tal-embedding u tal-moderazzjoni. Dawn
xorta jiġu rrifjutati f’talba taċ-chat:

```
HTTP 400 — Il-mudell '<id>' huwa mudell għall-ġenerazzjoni tal-immaġnijiet u ma jistax jintuża fuq
/v1/chat/completions. Minflok uża POST /v1/images/generations.
```

għalhekk jiġu ffiltrati skont il-field `type` tagħhom qabel ma jaslu fis-selettur. **Il-mudelli tal-Responses-API
jinżammu** — kull entrata Codex / GPT-5.x tirreklama `supported_endpoints: ["responses"]`,
u OmniRoute jittraduċihom għal `/v1/chat/completions`, għalhekk jistgħu jintużaw perfettament.

### Fornituri li qatt ma kkonfigurajt

Il-katalgu jelenka mudelli minn fornituri b’**konnessjoni attiva** _flimkien ma’_ kull fornitur **noAuth**
— dawk mingħajr ċavetta li jiffurmaw parti kbira mil-livell bla ħlas. Dan huwa intenzjonat. Biex taħbihom,
żidhom ma’ `blockedProviders` fis-settings tad-dashboard; ma jinbidel xejn fl-estensjoni.

## Dashboard ġewwa tab ta' VS Code

`omnicopilot.dashboardOpen: "editor"` jirrendi d-dashboard ta' OmniRoute f'tab tal-editur permezz tas-
Simple Browser minflok fi browser estern. L-inkorporazzjoni trid tiġi **attivata espliċitament fuq is-server** permezz ta'
`DASHBOARD_ALLOW_EMBED=vscode`, li jservi l-paġni HTML b'
`frame-ancestors 'self' vscode-webview:` minflok il-valur awtomatiku `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Is-superfiċje tal-API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) iżżomm l-
headers stretti fiż-żewġ każijiet.

> ⚠️ **Din hija marka tal-ħin tal-build, mhux tar-runtime.** Next.js jikkompila `headers()` fil-manifest tar-route,
> għalhekk `next.config.mjs` jaqra l-varjabbli waqt li jkun qed jinbena l-bundle
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> L-esportazzjoni tagħha qabel server li diġà nbena ma tbiddel xejn — l-headers ikunu inkorporati fil-build.

```bash
# il-varjabbli trid tkun preżenti fil-kmand tal-BUILD
DASHBOARD_ALLOW_EMBED=vscode npm run build        # jew npm run build:release
npm start
```

| Kif installajtu            | Tista' tattiva l-inkorporazzjoni?                                                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mis-source                 | ✅ issettja l-varjabbli fil-kmand tal-build, kif muri hawn fuq                                                                                                    |
| `npm install -g omniroute` | ❌ il-pakkett ippubblikat jiġi ma' bundle mibni minn qabel — minflok ibni mis-source                                                                              |
| Immaġni Docker             | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — l-immaġni mibnija minn qabel fuq Docker Hub mhix attivata għall-inkorporazzjoni |

Mingħajr build attivat għall-inkorporazzjoni, il-paġna tirrifjuta li tidher f'frame; l-estensjoni tinduna b'dan mill-
headers tar-rispons u terġa' lura għall-browser estern — xejn ma jinkiser, u tavżak darba.
Ara [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) u l-issue
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Il-konfigurazzjoni tal-għodod l-oħra tiegħek minn ġewwa VS Code

**`OmniRoute: Configure Coding CLI`** juża s-CLI `omniroute` biex jikteb profili lesti għall-użu
għal Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo u Roo — l-istess konfigurazzjonijiet deskritti f'
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). Iċ-ċavetta tal-API tingħata lis-CLI permezz tal-
varjabbli tal-ambjent `OMNIROUTE_API_KEY`, u qatt mil-linja tal-kmand.

## Soluzzjoni tal-problemi

| Sintomu                                                             | Kawża / soluzzjoni                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ma jidhrux mudelli ta' OmniRoute fis-selettur                       | Is-server ma jistax jintlaħaq. It-tikka fl-istrixxa tal-istatus issir griża; ħaddem `OmniRoute: Check Connection`. L-iskoperta hija siekta apposta u ma żżid ebda mudell minflok ma turi mistoqsija.                                                                                 |
| Kull mudell jidher darbtejn                                         | Qed tuża verżjoni ta' OmniCopilot eqdem minn 1.0.1 — aġġorna. L-estensjoni issa titlob `?prefix=alias`.                                                                                                                                                                              |
| Mudell tal-immaġni/awdjo kien jidher u issa sparixxa                | Dan huwa intenzjonat minn 1.0.1 'l hawn — qatt ma seta' jwieġeb talba taċ-chat.                                                                                                                                                                                                      |
| Il-panel nieqes mill-Activity Bar                                   | VS Code jmexxi l-kontenituri żejda tal-veduti lejn l-overflow **"…"** fil-qiegħ tal-Activity Bar, u kontenitur moħbi permezz ta' klikk bil-lemin jibqa' moħbi. Ikklikkja bil-lemin fuq l-Activity Bar → immarka **OmniRoute**, jew iftaħ permezz ta' `OmniRoute: Manage Connection`. |
| Id-dashboard jinfetaħ fil-browser minkejja l-modalità `editor`      | Is-server ma kienx **mibni** b'`DASHBOARD_ALLOW_EMBED=vscode` (ara hawn fuq) — l-issettjar tiegħu waqt l-istartjar fuq installazzjoni mibnija minn qabel ma jagħmel xejn. Ir-ritorn alternattiv huwa intenzjonat.                                                                    |
| Il-lista tal-mudelli ma tiġix aġġornata wara li tibdel il-fornituri | `OmniRoute: Refresh Models`, jew il-link ↻ fil-panel.                                                                                                                                                                                                                                |
