`@omniroute/opencode-plugin-v2` iqiegħed il-katalgu kollu tiegħek ta’ OmniRoute — mudelli, combos u
auto-combos — fis-selettur tal-mudelli ta’ OpenCode v2, b’ismijiet għall-wiri, prezzijiet u
baġits tal-livell bla ħlas.

Dan huwa pakkett separat minn `@omniroute/opencode-plugin` għax OpenCode v1 u v2 jgħabbu
l-plugins permezz ta’ kuntratti differenti. Agħżel dak li jaqbel mal-verżjoni ewlenija ta’ OpenCode tiegħek; ma
jaqsmu xejn bejniethom, għalhekk l-aġġornament ta’ wieħed qatt ma jobbligak taġġorna lill-ieħor.

## Rekwiżiti

- OpenCode v2.
- Gateway ta’ OmniRoute li jista’ jintlaħaq (`http://localhost:20128` b’mod awtomatiku).
- Node.js 22 jew 24.

## Installazzjoni

Żid il-plugin ma’ `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Il-mudelli mbagħad jidhru bħala `omniroute/<provider>/<model>`; `providerId` jiddetermina dak il-prefiss u
l-id tal-integrazzjoni li taħtu OpenCode jaħżen il-kredenzjali.

## Kredenzjali

Il-plugin ifittex ċavetta tal-gateway fi tliet postijiet, f’din l-ordni:

1. **Il-kredenzjali li kkonnettjajt f’OpenCode.** Il-plugin jirreġistra integrazzjoni, għalhekk
   il-fluss ta’ awtentikazzjoni ta’ OpenCode stess jista’ jaħżen iċ-ċavetta. Xejn ma jidħol f’`opencode.json` — ippreferi dan.
2. `apiKey` fl-għażliet tal-plugin, għal override għal kull proġett. Dan ipoġġi ċ-ċavetta f’fajl li
   tista’ tkun qed tikkommetti.
3. `OMNIROUTE_API_KEY` fl-ambjent.

Jekk ma jkun hemm l-ebda waħda mit-tlieta, il-katalgu jkun vojt u l-plugin jgħidlek dan darba waqt l-istartjar minflok
iħallik b’selettur vojt mingħajr ebda twissija.

### It-token tal-ġestjoni huwa ċavetta differenti

Il-combos, is-saħħa tal-fornituri u l-arrikkiment (ismijiet għall-wiri, prezzijiet, baġits tal-livell bla ħlas) jiġu
mill-endpoints `/api/*` tal-gateway, li fil-biċċa l-kbira tad-deployments ikunu protetti b’token tal-**ġestjoni**
minflok biċ-ċavetta tal-inferenza:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token tal-qari tal-ġestjoni>"
}
```

Jekk `managementReadToken` ma jiġix issettjat, jaqa’ lura fuq `apiKey`. Meta gateway jirrifjuta dan il-fallback,
il-katalgu xorta jiġi ppubblikat, iżda b’ids mhux ipproċessati tal-mudelli minflok ismijiet għall-wiri, mingħajr
tneħħija ta’ duplikati ta’ aliases kanoniċi, mingħajr prezzijiet u mingħajr combos. Il-plugin iwissi darba għal kull endpoint meta jiġri dan,
billi jsemmi l-endpoint u x’intilef — għalhekk selettur degradat qatt ma jkun misteru.

## Għażliet

| Ċavetta                          | Valur awtomatiku                                   | Noti                                                                                                                            |
| -------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                      | Id tal-fornitur, id tal-integrazzjoni, u l-prefiss li taħtu jidhru l-mudelli                                                    |
| `baseURL`                        | meħtieġ                                            | Għerq tal-gateway, `http(s)` biss; is-suffiss `/v1` jiżdied fejn ikun meħtieġ                                                   |
| `apiKey`                         | kredenzjali konnessi, imbagħad `OMNIROUTE_API_KEY` | Ċavetta taċ-chat għal `/v1/*`                                                                                                   |
| `managementReadToken`            | jaqa’ lura fuq `apiKey`                            | Ċavetta għal `/api/*` — normalment **mhijiex** l-istess waħda                                                                   |
| `displayName`                    | `"OmniRoute"`                                      | Isem il-fornitur fis-selettur                                                                                                   |
| `timeoutMs`                      | `10000`                                            | Timeout tal-ġbir għal kull endpoint (l-auto-combos jużaw 5s)                                                                    |
| `modelCacheTtlMs`                | `300000`                                           | TTL tal-cache tal-katalgu; snapshot fuq id-diska jħaffef l-istartjar kiesaħ                                                     |
| `timeouts`                       | jaqa’ lura fuq `timeoutMs`                         | Baġits għal kull endpoint f’ms: `models`, `combos`, `autoCombos`, `enrichment`                                                  |
| `enrichment`                     | `true`                                             | Iġbor ismijiet, prezzijiet u baġits tal-livell bla ħlas                                                                         |
| `providerTag`                    | `true`                                             | Żid bħala prefiss ma’ isem għall-wiri l-fornitur upstream li lejh jidderieġi                                                    |
| `usableOnly`                     | `false`                                            | Żomm biss il-fornituri li l-gateway jirrapporta bħala pprovduti                                                                 |
| `visibleModels` / `hiddenModels` | `[]`                                               | Listi ta’ permessi b’qbil eżatt jew tas-suffiss; iċ-ċaħda tieħu preċedenza                                                      |
| `geminiSanitization`             | `true`                                             | Neħħi mill-iskemi tal-għodod il-kliem ewlieni ta’ JSON-Schema li Gemini jirrifjuta (għodod b’`$ref` jintbagħtu mingħajr tibdil) |
| `apiFormat.allowAnthropic`       | `false`                                            | Idderieġi l-ids fil-lista ta’ permessi permezz tal-blokka tal-API ta’ Anthropic                                                 |
| `apiFormat.anthropicModels`      | `[]`                                               | Ids sħaħ tal-mudelli diretti lejn Anthropic                                                                                     |
| `logLevel` / `startupDebug`      | `warn` / `false`                                   | Livell ta’ dettall tal-logger                                                                                                   |

## Kif il-katalgu jibqa’ aġġornat

Il-katalgu jinġieb b’mod differit u jinżamm fil-cache għal `modelCacheTtlMs`, filwaqt li snapshot fuq id-diska jżomm l-aħħar katalgu magħruf disponibbli meta l-gateway ma jkunx jista’ jintlaħaq — qtugħ fis-servizz ma jiswielek xejn ħlief l-aġġornament. Il-mudelli u l-combos jiġu ppubblikati malli jaslu; l-auto-combos, il-lista tal-fornituri u s-saff addizzjonali ta’ arrikkiment jiġu inkorporati meta jaslu, sabiex endpoint wieħed kajman ma jkunx jista’ jżomm is-selettur kollu ostaġġ.

L-ismijiet jinkludu dak li jaf il-gateway: il-fornitur upstream li lejh jiġi dirett mudell, markatur `[Free]` u l-baġit li jiġi miegħu — sabiex żewġ konnessjonijiet li jbigħu l-istess mudell jibqgħu jintgħarfu minn xulxin. Itfi l-prefiss permezz ta’ `"providerTag": false`.

Ma jeżistix kmand manwali għall-aġġornament: il-kmandi ta’ OpenCode v2 huma mudelli ta’ prompts, mhux callbacks, għalhekk plugin ma jistax jesponi wieħed. L-aġġornamenti jsegwu t-TTL; il-host jintalab jerġa’ jgħabbi biss meta l-katalgu jew is-saff addizzjonali jkunu fil-fatt inbidlu, u qatt darba għal kull aġġornament.

## Sejħiet ta’ għodod fuq Gemini

Gemini jirrifjuta talba sħiħa li d-dikjarazzjonijiet tal-għodod tagħha jkun fihom `$schema` jew `additionalProperties`, u jwieġeb b’`400 INVALID_ARGUMENT`. Il-plugin ineħħi dawk il-kliem ewlieni mill-iskemi tal-għodod maħsuba għal mudell Gemini ta’ dan il-fornitur u jħalli kull talba oħra mhux mittiefsa. Għodda li jkun fiha `$ref` tintbagħat kif inhi minflok ma titneħħielha xi ħaġa, peress li t-tneħħija tar-referenza twessa’ l-iskema biex “taċċetta kollox”.
Issettja `"geminiSanitization": false` biex titfiha.

## Soluzzjoni tal-problemi

| Sintomu                                                         | Kawża                                                                                                               |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Is-selettur ma juri l-ebda mudell OmniRoute                     | Ma ġiet riżolta l-ebda ċavetta (iċċekkja t-twissija waqt l-istartjar), jew il-gateway ma jistax jintlaħaq           |
| IDs mhux ipproċessati tal-mudelli, ebda combos, ebda prezzijiet | L-endpoints tal-ġestjoni rrifjutaw it-token — issettja `managementReadToken`                                        |
| Sessjoni marbuta ma’ `opencode-<id>/…`                          | Il-plugin v1 ippubblika `opencode-<id>`; v2 jippubblika `<id>` waħdu, għalhekk erġa’ agħżel il-mudell taħt `<id>/…` |
