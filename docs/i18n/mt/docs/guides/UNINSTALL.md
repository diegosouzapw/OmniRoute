## Diżinstallazzjoni Rapida (v3.6.2+)

OmniRoute jipprovdi żewġ skripts integrati għal tneħħija nadifa:

### Żomm id-Data Tiegħek

```bash
npm run uninstall
```

Dan ineħħi l-applikazzjoni OmniRoute iżda **jippreserva** l-bażi tad-data, il-konfigurazzjonijiet, iċ-ċwievet tal-API, u s-settings tal-fornituri tiegħek f’`~/.omniroute/`. Uża dan jekk qed tippjana li terġa’ tinstalla aktar tard u trid iżżomm il-konfigurazzjoni tiegħek.

### Tneħħija Sħiħa

```bash
npm run uninstall:full
```

Dan ineħħi l-applikazzjoni **u jħassar b’mod permanenti** id-data kollha:

- Il-bażi tad-data (`storage.sqlite`)
- Il-konfigurazzjonijiet tal-fornituri u ċ-ċwievet tal-API
- Il-fajls tal-backup
- Il-fajls tal-log
- Il-fajls kollha fid-direttorju `~/.omniroute/`

> ⚠️ **Twissija:** `npm run uninstall:full` ma jistax jitreġġa’ lura. Il-konnessjonijiet kollha mal-fornituri, il-combos, iċ-ċwievet tal-API, u l-istorja tal-użu tiegħek se jitħassru b’mod permanenti.

## Diżinstallazzjoni Manwali

### Installazzjoni Globali b’NPM

```bash
# Neħħi l-pakkett globali
npm uninstall -g omniroute

# (Fakultattiv) Neħħi d-direttorju tad-data
rm -rf ~/.omniroute
```

### Installazzjoni Globali b’pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Waqqaf u neħħi l-kontenitur
docker stop omniroute
docker rm omniroute

# Neħħi l-volum (iħassar id-data kollha)
docker volume rm omniroute-data

# (Fakultattiv) Neħħi l-immaġni
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Waqqaf u neħħi l-kontenituri
docker compose down

# Neħħi wkoll il-volumi (iħassar id-data kollha)
docker compose down -v
```

### Installazzjoni mis-Sors (git clone)

```bash
# Neħħi d-direttorju kklonat
rm -rf /path/to/omniroute

# (Fakultattiv) Neħħi d-direttorju tad-data
rm -rf ~/.omniroute
```

## Direttorji tad-Data

B’mod awtomatiku, OmniRoute jaħżen id-data fil-postijiet li ġejjin:

| Pjattaforma      | Mogħdija Awtomatika           | Sostituzzjoni                           |
| ---------------- | ----------------------------- | --------------------------------------- |
| Linux            | `~/.omniroute/`               | Varjabbli tal-ambjent `DATA_DIR`        |
| macOS            | `~/.omniroute/`               | Varjabbli tal-ambjent `DATA_DIR`        |
| Windows          | `%APPDATA%/omniroute/`        | Varjabbli tal-ambjent `DATA_DIR`        |
| Docker           | `/app/data/` (volum immuntat) | Varjabbli tal-ambjent `DATA_DIR`        |
| Konformi ma’ XDG | `$XDG_CONFIG_HOME/omniroute/` | Varjabbli tal-ambjent `XDG_CONFIG_HOME` |

### Fajls fid-direttorju tad-data

| Fajl/Direttorju      | Deskrizzjoni                                                  |
| -------------------- | ------------------------------------------------------------- |
| `storage.sqlite`     | Bażi tad-data ewlenija (fornituri, combos, settings, ċwievet) |
| `storage.sqlite-wal` | Log ta’ kitba bil-quddiem ta’ SQLite (temporanju)             |
| `storage.sqlite-shm` | Memorja kondiviża ta’ SQLite (temporanja)                     |
| `call_logs/`         | Arkivji tad-data tat-talbiet                                  |
| `backups/`           | Backups awtomatiċi tal-bażi tad-data                          |
| `log.txt`            | Log preċedenti tat-talbiet (fakultattiv)                      |

## Ivverifika t-Tneħħija Kompleta

Wara li tiddiżinstalla, ivverifika li ma jkun fadal l-ebda fajl:

```bash
# Iċċekkja għall-pakkett npm globali
npm list -g omniroute 2>/dev/null

# Iċċekkja għad-direttorju tad-data
ls -la ~/.omniroute/ 2>/dev/null

# Iċċekkja għal proċessi li qed jaħdmu
pgrep -f omniroute
```

Jekk għad hemm xi proċess jaħdem, waqqfu:

```bash
pkill -f omniroute
```
