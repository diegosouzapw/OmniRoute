> **Dashboard:** Settings → **AI** → Baġit tal-Ħsieb  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **Sors:** `open-sse/services/thinkingBudget.ts`

Il-Baġit tal-Ħsieb jikkontrolla jekk OmniRoute **jikteb mill-ġdid il-parametri tal-ħsieb/raġunament tal-klijent** fit-triq lejn il-fornituri. Dan **ma** jixgħelx jew jitfi l-kompressjoni, ir-routing, jew il-cache tal-prompt.

## Modi

| Mod                         | X'jagħmel OmniRoute                                                                                                                  | Meta għandek tużah                                                                                                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (default) | Iħalli l-fields tal-klijent kif inhuma (`reasoning`, `reasoning_effort`, `thinking` ta' Claude, `thinking_config` ta' Gemini, eċċ.). | **Codex / Desktop / kwalunkwe klijent li għandu jikkontrolla l-isforz u s-sommarji tar-raġunament.** Meħtieġ għal panels tal-ħsieb viżibbli meta l-klijent jitlob `reasoning.summary`. |
| **`auto`**                  | **Ineħħi l-fields kollha** tal-ħsieb/raġunament mill-body tat-talba qabel ma tintbagħat upstream.                                    | Biss meta deliberatament trid li l-**fornitur** joħloq valuri default u **ma** teħtieġx ħsieb ikkontrollat mill-klijent. **Mhux** “uri l-ħsieb awtomatikament”.                        |
| **`custom`**                | Jissostitwixxi l-valur f'kull talba b'baġit fiss ta' tokens tal-ħsieb.                                                               | Limitu massimu strett fuq it-tokens tal-ħsieb għat-traffiku kollu.                                                                                                                     |
| **`adaptive`**              | Jiskala l-baġit minn sforz bażi billi juża l-għadd ta' messaġġi, l-għodod, u t-tul tal-prompt.                                       | Kontroll flessibbli tat-tokens mingħajr ma titneħħa kompletament l-intenzjoni tal-klijent.                                                                                             |

### X'ineħħi `auto`

Meta l-mod ikun `auto`, `stripThinkingConfig()` iħassar (fost oħrajn):

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, u `output_config.effort` meta jkun preżenti
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

Jekk klijent (eż. Codex Desktop) bagħat `reasoning: { effort: "ultra", summary: "detailed" }`, **auto jneħħi dak l-oġġett**. Is-servizz upstream xorta jista' jitlob ħlas għal xi tokens tar-raġunament, iżda spiss jirritorna elementi tar-raġunament **vojta jew kriptati biss** — għalhekk l-UI ma turi ebda stream tal-ħsieb utli.

## X'inhu **mhux**

| Karatteristika                                          | Relazzjoni                                                                                                                                      |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Kompressjoni** (Caveman, RTK, stacked, …)             | Pipeline separat. Taħdem taħt kull mod tal-baġit tal-ħsieb.                                                                                     |
| **Cache tal-prompt / semantika**                        | Separat. Mhux affettwat mill-mod tal-baġit tal-ħsieb.                                                                                           |
| **Routing ikkombinat / fallbacks**                      | Separat. Mhux affettwat.                                                                                                                        |
| **Limiti tat-tokens tal-API key / baġits tal-ispejjeż** | Separati. Mhux affettwati.                                                                                                                      |
| **Cache għar-replay tar-raġunament**                    | Injezzjoni mill-ġdid fuq diversi turns għal fornituri stretti (DeepSeek, Kimi, Qwen-thinking, …). Mhux l-istess bħal “uri l-ħsieb” ta' Desktop. |
| **Dekriptaġġ ta' `encrypted_content`**                  | **Impossibbli.** Il-blobs privati tar-raġunament ta' OpenAI/Codex huma opaki. OmniRoute qatt ma jiddekriptahom (#7095 / #7176 / #7304).         |

## Ħsieb viżibbli (klijenti Codex / Responses)

Biex klijent juri t-test tal-ħsieb, għandek bżonn **dawn kollha**:

1. Il-modalità Thinking Budget = **`passthrough`** (jew custom/adaptive li xorta tħalli t-talbiet għal sommarju intatti biżżejjed għall-fluss li tuża).
2. Il-klijent jitlob sommarju, eż. Codex `model_reasoning_summary = "detailed"` / `auto` (mhux `none`).
3. Is-servizz upstream effettivament jistrimja `response.reasoning_summary_text.*` (jew `reasoning.summary` mhux vojt fuq l-element).

Jekk tirċievi biss “raġunament privat ikkriptat”, allura jew:

- il-modalità kienet **`auto`** (it-talba tal-klijent tneħħiet), jew
- is-servizz upstream irritorna `encrypted_content` mingħajr test ta’ sommarju (limitazzjoni tal-fornitur; OmniRoute jista’ juri biss placeholder, mhux test sempliċi).

## Eżempji tal-API

```bash
# Aqra
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Rakkomandat għall-viżibbiltà tal-ħsieb f'Codex / Desktop
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Skema (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier` huma fakultattivi.

### Persistenza / ristartjar

Il-valur jinħażen taħt iċ-ċavetta tas-settings `thinkingBudget` u jitgħabba fil-bidu tal-proċess (`hydrateThinkingBudgetConfig`). Wara li tibdlu permezz tad-DB jew ta’ xi mogħdijiet mhux tal-API, **erġa’ ibda l-proċess OmniRoute** sabiex is-singleton fil-memorja jaqbel ma’ dak fuq id-diska.

## Lista ta’ kontroll għall-operatur

- [ ] Utenti ta’ Codex / Desktop: modalità = **passthrough**
- [ ] Żomm il-kompressjoni attivata jekk trid tiffranka tokens fuq il-**messaġġi**, mhux billi tneħħi l-ħsieb
- [ ] Tistenniex li `auto` “juri aktar ħsieb”
- [ ] Sommarji kriptati biss huma mġiba tal-**fornitur**; passthrough ma jistax jiddekriptahom
