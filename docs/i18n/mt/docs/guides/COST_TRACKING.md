## X'inhu (u x'mhuwiex)

OmniRoute jattribwixxi spiża f'USD għal kull talba lil kull completion billi jimmultiplika l-għadd ta' tokens bir-rati tal-ipprezzar ta' mudell. Dawn in-numri jħaddmu d-dashboard tal-**Ispejjeż**, il-CLI `omniroute cost` / `omniroute usage`, l-esportazzjonijiet CSV/JSON, u l-baġits għal kull API key.

> **L-"ispiża" fid-dashboard hija traċċatur tal-iffrankar, mhux kont.** OmniRoute qatt ma jiċċarġjak
> — huwa jgħaddi t-talbiet tiegħek għand fornituri li diġà kkonnettjajt (l-abbonamenti,
> il-livelli bla ħlas, u l-API keys tiegħek stess). "$290 spiża totali" akkumulata kollha fuq mudelli
> bla ħlas tfisser bejn wieħed u ieħor **$290 li _ma ħallastx_** lil API bi ħlas. Iċ-ċifra hija _stima_
> ta' kemm kien jiswa l-istess traffiku bil-prezzijiet standard ippubblikati, sabiex tkun tista' tara fejn
> huwa kkonċentrat l-użu tiegħek u kemm qed tiffranka billi tgħaddi t-traffiku għand fornituri orħos/bla ħlas.

Din l-interpretazzjoni hija ddikjarata direttament fil-[README](../../README.md) tal-proġett ("l-'ispiża'
fid-dashboard hija traċċatur tal-iffrankar, mhux kont").

Minħabba li n-numru huwa stima:

- Jiddependi mit-tabella tal-ipprezzar li OmniRoute għandu għal kull mudell. Mudell mingħajr entrata
  tal-ipprezzar jikkontribwixxi spiża ta' `0` (jidher bħala ringiela "Legacy / Free" fl-esploratur).
- It-traffiku tal-livelli bla ħlas u tal-abbonamenti xorta jakkumula spiża _stmata_ — dak huwa
  l-ammont li qed tiffranka, mhux ammont dovut.

## Kif jiġu stmati l-ispejjeż

### Is-sors tal-ipprezzar

L-ispejjeż jiġu minn tabella tal-ipprezzar riżolta skont din l-ordni ta' preċedenza
([`src/lib/pricingSync.ts`](../../src/lib/pricingSync.ts)):

1. **Sovrastrutturi tal-utent** — prezzijiet li tissettja fid-dashboard / permezz ta' `PATCH /api/pricing`.
2. **Ipprezzar estern sinkronizzat** — miksub mill-
   `model_prices_and_context_window.json` pubbliku ta' LiteLLM meta s-sinkronizzazzjoni tkun attivata (maħżun fi namespace
   `pricing_synced` separat sabiex qatt ma jissostitwixxi s-sovrastrutturi tiegħek).
3. **Valuri predefiniti hardcoded** — inklużi ma' OmniRoute.

Is-sinkronizzazzjoni tal-ipprezzar estern hija **opt-in**, diżattivata b'mod predefinit. Il-varjabbli tal-ambjent rilevanti
(ara [`.env.example`](../../.env.example)):

| Varjabbli tal-ambjent   | Valur predefinit | Għan                                                                             |
| ----------------------- | ---------------- | -------------------------------------------------------------------------------- |
| `PRICING_SYNC_ENABLED`  | `false`          | Attiva s-sinkronizzazzjoni tal-ipprezzar ta' LiteLLM fl-isfond waqt l-istartjar. |
| `PRICING_SYNC_INTERVAL` | `86400`          | Intervall tas-sinkronizzazzjoni f'**sekondi** (kuljum b'mod predefinit).         |
| `PRICING_SYNC_SOURCES`  | `litellm`        | Lista ta' sorsi separati b'virgola (illum huwa appoġġjat biss `litellm`).        |

### Il-formula tal-ispiża

L-ispiża tiġi kkalkulata għal kull talba mill-għadd ta' tokens u mir-rati għal kull miljun token fi
[`src/lib/usage/costCalculator.ts`](../../src/lib/usage/costCalculator.ts)
(`computeCostFromPricing` / `calculateCost`):

- **Tokens tal-input** (mingħajr il-qari mill-cache u t-tokens tal-ħolqien tal-cache) × ir-rata `input`.
- **Tokens moqrija mill-cache** × ir-rata `cached` (jekk ma tkunx disponibbli, tintuża r-rata tal-input).
- **Tokens tal-ħolqien tal-cache** × ir-rata `cache_creation` (jekk ma tkunx disponibbli, tintuża r-rata tal-input).
- **Tokens tal-output** × ir-rata `output`.
- **Tokens tar-raġunament** × ir-rata `reasoning` (jekk ma tkunx disponibbli, tintuża r-rata tal-output).

Ir-rati kollha jiġu interpretati bħala USD għal kull 1,000,000 token. Livell ta' servizz Codex "fast"/"priority" jew
"flex" japplika multiplikatur tal-ispiża (`getCodexFastCostMultiplier`) — pereżempju, flex
jiġi ċċarġjat bi skont ta' 50% fuq it-tokens, muri bħala **ffrankar flex** fid-dashboard.

L-ismijiet tal-mudelli jiġu normalizzati l-ewwel (prefissi tal-mogħdijiet tal-fornituri bħal `openai/` jew
`accounts/fireworks/models/` jitneħħew) sabiex ringieli storiċi xorta jaqblu ma' prezz.

### Kif jiġi rreġistrat l-infiq

- L-ispiża għal kull talba tiġi kkalkulata wara r-risposta u rreġistrata mingħajr stennija għar-riżultat sabiex
  qatt ma żżid latenza għall-klijent. Il-konsum tal-kwota kondiviża jiġi skedat fit-tick li jmiss
  tal-event loop permezz ta' [`src/lib/quota/spendRecorder.ts`](../../src/lib/quota/spendRecorder.ts).
- L-infiq tal-API keys jinżamm f'buffer u jintbagħat f'lottijiet mill-
  [`SpendBatchWriter`](../../src/lib/spend/batchWriter.ts) (intervall predefinit ta' 60s bejn kull flush,
  buffer ta' 1,000 entrata). Jista' jiġi rregolat permezz ta':

  | Varjabbli tal-ambjent               | Valur predefinit | Għan                                                 |
  | ----------------------------------- | ---------------- | ---------------------------------------------------- |
  | `OMNIROUTE_SPEND_FLUSH_INTERVAL_MS` | `60000`          | Intervall tal-flush f'millisekondi.                  |
  | `OMNIROUTE_SPEND_MAX_BUFFER_SIZE`   | `1000`           | Għadd massimu ta' entrati fil-buffer qabel il-flush. |

Iċ-ċifri tal-ispejjeż fid-dashboard **ma** jinqrawx minn ammont f'dollari maħżun għal kull ringiela — jiġu
kkalkulati mill-ġdid dak il-ħin mill-għadd ta' tokens u mit-tabella attwali tal-ipprezzar kull darba li
jitħaddem l-endpoint tal-analytics. Dan ifisser li l-korrezzjoni ta' prezz ħażin (u s-sinkronizzazzjoni mill-ġdid) taġġorna
b'mod retroattiv l-istimi storiċi tal-ispejjeż.

## Dashboard: il-paġna tal-Ispejjeż

Il-paġna **Spejjeż** tinsab f’`/dashboard/costs`
(`src/app/(dashboard)/dashboard/costs/`).
Il-veduta ewlenija tagħha hija t-tab **Ħarsa Ġenerali lejn l-Ispejjeż**
(`src/app/(dashboard)/dashboard/costs/CostOverviewTab.tsx`),
li ttella’ kollox minn `GET /api/usage/analytics`.

Dak li turi:

- **Kaxxi tal-infiq** — l-infiq stmat għal _Illum (1d)_, _7d_, _30d_, u l-perjodu
  magħżul. Selettur tal-medda: `7d`, `30d`, `90d`, `all`.
- **Metriċi ewlenin** — talbiet fil-perjodu, fornituri attivi, mudelli attivi, spiża
  medja għal kull talba.
- **Esploratur tal-Ispejjeż** — tabella li tista’ tiġi magħżula u ffiltrata, miġbura skont
  **fornitur**, **mudell**, **ċavetta tal-API**, **kont**, jew **livell tas-servizz**, bl-ispiża,
  it-talbiet, it-tokens, l-ispiża medja għal kull talba, u s-sehem perċentwali mit-total.
- **Użu tat-tokens** — tokens totali / tal-input / tal-output u l-proporzjon input:output.
- **Effiċjenza tar-routing** — għadd ta’ fallbacks, rata ta’ fallback, u kopertura tal-mudell mitlub.
- **Tbassir ta’ kull xahar** — jipproġetta l-infiq sa tmiem ix-xahar mill-medja riċenti ta’ kuljum.
- **Tqabbil tal-perjodi** — il-bidla perċentwali bejn l-ewwel u t-tieni nofs tal-perjodu.
- **Ċarts** — xejra tal-ispiża ta’ kuljum, sehem skont il-fornitur (pie), l-aqwa fornituri,
  l-aqwa mudelli, spiża skont iċ-ċavetta tal-API, spiża skont il-kont, mudell ta’ użu ta’
  kull ġimgħa, u mappa tas-sħana tal-attività.
- **Esportazzjoni** — niżżel il-perjodu attwali bħala **CSV** jew **JSON** (il-buttuni jidhru
  ladarba jkun hemm data tal-ispejjeż akbar minn żero).

Meta ma jkun hemm ebda traffiku bi prezz, ir-ringieli jintwerew bit-tikketta "Legat / Bla ħlas" minflok `$0`,
biex jirriflettu l-mudell tat-traċċar tal-iffrankar.

### Subpaġni relatati mal-Ispejjeż

Iż-żona tal-Ispejjeż tinkludi wkoll (kollha taħt `/dashboard/costs/`):

- **Ipprezzar** (`/dashboard/costs/pricing`) — ara u ssostitwixxi l-prezzijiet għal kull mudell (turi
  t-tab kondiviża tal-Ipprezzar).
- **Baġit** (`/dashboard/costs/budget`) — issettja limiti tal-infiq għal kull ambitu (turi t-tab
  kondiviża tal-Baġit).
- **Kondiviżjoni tal-Kwota** (`/dashboard/costs/quota-share`) — pools ta’ kwoti kondiviżi u veduti
  tar-rata tal-konsum.

## Endpoints tal-API

Dawn kollha jeħtieġu awtentikazzjoni tal-ġestjoni (loopback/JWT, permezz ta’ `requireManagementAuth`) sakemm
ma jkunx indikat mod ieħor.

### Analitika tal-użu u tal-ispejjeż

| Metodu | Endpoint                 | Għan                                                                                                                                                                                |
| ------ | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`  | `/api/usage/analytics`   | Analitika sħiħa tal-ispejjeż/użu: sommarju, xejra ta’ kuljum, skont il-fornitur/mudell/ċavetta tal-API/kont/livell. Query: `range`, `startDate`, `endDate`, `apiKeyIds`, `presets`. |
| `GET`  | `/api/usage/utilization` | Użu tal-kwota għal kull fornitur matul iż-żmien. Query: `range` (`1h`/`24h`/`7d`/`30d`), `provider`.                                                                                |
| `GET`  | `/api/usage/history`     | Ringieli mhux ipproċessati tal-istorja tal-użu.                                                                                                                                     |
| `GET`  | `/api/usage/call-logs`   | Reġistri tas-sejħiet għal kull talba (mudell, tokens, spiża, latenza, status).                                                                                                      |
| `GET`  | `/api/usage/quota`       | Status tal-kwota tal-fornitur.                                                                                                                                                      |
| `GET`  | `/api/usage/proxy-logs`  | Reġistri tat-talbiet tal-proxy.                                                                                                                                                     |

### Baġits

| Metodu | Endpoint                 | Għan                                                                                                                    |
| ------ | ------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| `GET`  | `/api/usage/budget`      | Sommarju tal-ispejjeż + verifika tal-baġit għal ċavetta tal-API waħda (il-parametru tal-query `apiKeyId` huwa meħtieġ). |
| `POST` | `/api/usage/budget`      | Issettja limiti ta’ kuljum/kull ġimgħa/kull xahar f’USD + limitu ta’ twissija għal ċavetta tal-API.                     |
| `GET`  | `/api/usage/budget/bulk` | Sommarji tal-baġit bl-ingrossa fost iċ-ċwievet tal-API.                                                                 |

> L-API tal-baġit hija limitata għal kull **ċavetta tal-API** (`apiKeyId`). Il-limiti rritornati minn
> `GET /api/usage/budget` jinkludu `dailyLimitUsd`, `weeklyLimitUsd`, `monthlyLimitUsd`,
> `warningThreshold`, u t-totali kurrenti (`totalCostToday`, `totalCostMonth`, …).

### Ipprezzar

| Metodu   | Endpoint                | Għan                                                                                                                       |
| -------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `GET`    | `/api/pricing`          | Ipprezzar magħqud attwali (tal-utent + sinkronizzat + predefinit). `?includeSources=1` biex tara s-sors għal kull entrata. |
| `PATCH`  | `/api/pricing`          | Issostitwixxi l-ipprezzar għal `{ provider: { model: { input, output, cached, … } } }`.                                    |
| `DELETE` | `/api/pricing`          | Irrisettja l-ipprezzar għall-valuri predefiniti (b’mod fakultattiv limitat permezz ta’ `?provider=&model=`).               |
| `GET`    | `/api/pricing/defaults` | Uri r-rati predefiniti ta’ fallback għal kull miljun.                                                                      |
| `GET`    | `/api/pricing/models`   | Ipprezzar organizzat skont il-mudell.                                                                                      |
| `POST`   | `/api/pricing/sync`     | Attiva sinkronizzazzjoni manwali minn sorsi esterni (LiteLLM).                                                             |
| `GET`    | `/api/pricing/sync`     | Status attwali tas-sinkronizzazzjoni.                                                                                      |
| `DELETE` | `/api/pricing/sync`     | Ħassar id-data kollha tal-ipprezzar sinkronizzat.                                                                          |

### Endpoints oħra rilevanti għall-ispejjeż

| Metodu | Endpoint                      | Għan                                                                                          |
| ------ | ----------------------------- | --------------------------------------------------------------------------------------------- |
| `GET`  | `/api/free-tier/summary`      | Total ta’ tokens ta’ mudelli bla ħlas, dawk użati dan ix-xahar, u l-bqija tal-kwota bla ħlas. |

## CLI

Is-CLI ta’ OmniRoute jesponi kmandi għall-ispejjeż, l-użu u l-ipprezzar (irreġistrati f’
[`bin/cli/commands/registry.mjs`](../../bin/cli/commands/registry.mjs)).

### `omniroute cost`

Rapport tal-ispejjeż aggregat minn `/api/usage/analytics`.

```bash
omniroute cost                          # l-aħħar 30 jum, raggruppati skont il-fornitur
omniroute cost --period 7d              # l-aħħar 7 ijiem
omniroute cost --group-by model         # raggruppa skont provider | model | combo | api-key | day
omniroute cost --since 2026-06-01 --until 2026-06-13
omniroute cost --api-key <key> --limit 50
```

Kolonni: grupp, talbiet, tokens ta’ dħul/ħruġ, spiża (USD), u % tat-total. Linja bit-total ġenerali
tiġi stampata fl-aħħar (titneħħa b’`--quiet` jew `--output json`).

### `omniroute usage`

```bash
omniroute usage analytics --period 30d [--provider <id>]   # sommarju tal-ispejjeż għal kull fornitur
omniroute usage logs [--limit 100] [--follow] [--api-key <k>] [--search <q>]
omniroute usage quota [--provider <id>] [--check]
omniroute usage utilization [--api-key <k>]
omniroute usage history [--limit 100]
omniroute usage proxy-logs [--limit 100]

# Baġits
omniroute usage budget list
omniroute usage budget get [scope]
omniroute usage budget set <amount> [--scope global] [--period monthly]
omniroute usage budget reset [scope]
```

### `omniroute pricing`

```bash
omniroute pricing list [--provider <p>] [--model <m>] [--limit 200]
omniroute pricing get <model>
omniroute pricing sync [--provider <p>] [--force]   # POST /api/pricing/sync
omniroute pricing diff [--model <m>]
omniroute pricing defaults show
omniroute pricing defaults set [--input <p>] [--output <p>] [--cache-read <p>] [--cache-write <p>]
```

> `pricing defaults show` jaqra `GET /api/pricing/defaults`. Minflok, biex teditja l-prezzijiet
> ta’ mudelli individwali, uża l-paġna **Prezzijiet** tad-dashboard jew `PATCH /api/pricing`.

## Soluzzjoni tal-problemi

- **L-ispejjeż kollha jidhru bħala $0 / "Legat / Bla ħlas".** Il-mudelli li qed jintużaw ma għandhomx entrata tal-ipprezzar.
  Ippermetti s-sinkronizzazzjoni esterna (`PRICING_SYNC_ENABLED=true`) u ħaddem `omniroute pricing sync`, jew
  issettja l-prezzijiet manwalment permezz tal-paġna Prezzijiet / `PATCH /api/pricing`.
- **Mudell storiku għandu prezz żbaljat.** Irranġa l-prezz (issostitwih jew erġa’ ssinkronizzah) — l-ispiża tiġi
  kkalkolata mill-ġdid mill-għadd ta’ tokens ma’ kull qari tal-analitika, għalhekk l-istimi jiġu aġġornati retroattivament.
- **L-infiq jibqa’ lura mill-ħin reali.** L-infiq għal kull ċavetta jiġi pproċessat f’lottijiet; naqqas
