> **Fil-qosor**: OmniRoute jikklassifika l-fornituri **bla ħlas** tiegħu skont il-kwalità tal-mudell billi juża **punteġġi ELO ta’ Arena AI
> (stil LMArena)**. Iftaħ il-paġna **Klassifikazzjonijiet tal-Fornituri Bla Ħlas** fid-
> dashboard biex tara liema fornituri bla ħlas joffru l-aktar mudelli b’saħħithom għall-kompitu tiegħek —
> b’mod ġenerali, jew iffiltrati skont il-kategorija (kodifikazzjoni, reviżjoni, dokumentazzjoni, debugging).

## X’Inhu

OmniRoute jirreġistra 329 fornitur, inklużi 155 entrata fil-katalgu mmarkati bħala **bla ħlas/ebda awtentikazzjoni**
(ebda awtentikazzjoni,
OAuth b’livell bla ħlas, jew API key b’livell bla ħlas — ara l-
[Gwida għal-Livelli Bla Ħlas](../getting-started/FREE-TIERS-GUIDE.md) u d-
[Direttorju tal-Livelli Bla Ħlas](../reference/FREE_TIERS.md) sħiħ). Il-problema hi li l-fornituri bla ħlas ivarjaw
ħafna fil-kwalità tal-mudelli. Fornitur mingħajr awtentikazzjoni li joffri mudell avvanzat nett huwa ferm aktar utli
minn wieħed li joffri mudell antik u żgħir.

**Klassifikazzjonijiet tal-Fornituri Bla Ħlas** iwieġeb il-mistoqsija "**liema fornitur bla ħlas jagħtini l-aħjar mudell?**" billi
jgħaqqad il-katalgu ta’ kull fornitur bla ħlas ma’ **punteġġi tal-kwalità miksuba mill-pubbliku** mil-
**leaderboard ta’ Arena AI** (ELO tal-preferenzi umani, l-istess idea wara l-arena taċ-chatbots ta’ LMArena).
Il-fornituri mbagħad jiġu kklassifikati skont is-saħħa tal-**aħjar mudell bla ħlas** tagħhom.

Il-klassifikazzjoni tiġi kkalkolata minn tliet sorsi reali:

1. Il-listi tal-fornituri bla ħlas — `NOAUTH_PROVIDERS`, flimkien mal-entrati `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` immarkati b’`hasFree`
   (`src/shared/constants/providers.ts`).
2. Il-katalgu tal-mudelli ta’ kull fornitur mir-reġistru tal-fornituri
   (`open-sse/config/providerRegistry.ts`).
3. Punteġġi tal-adegwatezza għall-kompitu derivati mill-ELO u maħżuna fit-tabella `model_intelligence` tad-DB mill-
   magna tas-sinkronizzazzjoni tal-ELO ta’ Arena (`src/lib/arenaEloSync.ts`).

Il-loġika tal-għaqda tinsab f’`src/lib/freeProviderRankings.ts`.

## Kif Taċċessah

### Paġna tad-dashboard

Iftaħ id-dashboard u mur fuq **Spejjeż → Klassifikazzjonijiet tal-Fornituri Bla Ħlas**, jew innaviga direttament lejn:

```
/dashboard/free-provider-rankings
```

Il-paġna (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) turi:

- **Podju tal-aqwa 3** (🥇 🥈 🥉) fornituri bla ħlas bl-ogħla klassifikazzjoni.
- **Tabella tal-klassifikazzjoni** sħiħa bil-kolonni: **Pożizzjoni**, **Fornitur**, **L-Aqwa Mudell**,
  **Punteġġ**, **Punteġġ Medju**, **Mudelli**, **Tip**.
- **Buttuni tal-filtru tal-kategoriji**: _Il-Kategoriji Kollha_, _Predefinita_, _Kodifikazzjoni_, _Reviżjoni_,
  _Dokumentazzjoni_, _Debugging_.

Il-badge tat-**Tip** ta’ kull fornitur tindika kif dan huwa bla ħlas:

| Badge    | Tifsira                                            |
| -------- | -------------------------------------------------- |
| `NOAUTH` | Dejjem bla ħlas, ma huma meħtieġa ebda kredenzjali |
| `OAUTH`  | Fornitur OAuth b’livell bla ħlas (`hasFree`)       |
| `APIKEY` | Fornitur b’API key u b’livell bla ħlas (`hasFree`) |

Il-punteġġi jintwerew bħala tikketti li jinqraw faċilment mill-bniedem (eż. _Elite_, _Eċċellenti_, _Tajjeb Ħafna_,
_Tajjeb_, _Medju_) minflok bħala numri mhux ipproċessati, għax il-valur sottostanti huwa kwalità relattiva
tal-klassifikazzjoni, mhux perċentwal.

### Endpoint tal-API

Il-paġna hija appoġġata minn endpoint pubbliku tal-qari
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parametri tal-query (ivvalidati b’Zod):

| Parametru  | Tip    | Predefinit | Noti                                                                                                                     |
| ---------- | ------ | ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| `category` | string | (xejn)     | Wieħed minn `default`, `coding`, `review`, `documentation`, `debugging`. Ħallih barra għall-klassifikazzjoni kkombinata. |
| `limit`    | number | `50`       | Limitat għall-firxa `1–100`.                                                                                             |

Struttura tar-rispons:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` huwa l-valur ELO oriġinali ta’ Arena; `score` huwa l-valur normalizzat tal-adegwatezza
għall-kompitu (ara hawn taħt). Il-fornituri mingħajr mudelli b’punteġġ jitħallew barra mir-rispons.

## Kif Jaħdmu l-Punteġġi

### Sors: il-klassifika Arena AI

Il-magna tas-sinkronizzazzjoni Arena ELO (`src/lib/arenaEloSync.ts`) tikseb żewġ klassifiki — `text`
u `code` — mill-API tal-klassifika Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Kull entrata fil-klassifika
tinkludi isem tal-mudell, fornitur, `score` ELO, intervall ta’ kunfidenza, u għadd ta’ voti.

Il-kategoriji tal-klassifika jikkorrispondu mal-kategoriji tal-kompiti ta’ OmniRoute:

| Klassifika Arena | Kategoriji tal-kompiti ta’ OmniRoute              |
| ---------------- | ------------------------------------------------- |
| `text`           | `default`, `review`, `documentation`, `debugging` |
| `code`           | `coding`                                          |

### Normalizzazzjoni (punteġġ tal-adegwatezza għall-kompitu)

Il-punteġġi ELO mhux ipproċessati jiġu normalizzati għal kull klassifika f’**valur tal-adegwatezza għall-kompitu fil-medda `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Il-punteġġ qatt ma jilħaq `0` jew `1`, u b’hekk jitħalla spazju għall-aġġustamenti tal-utent. Dan huwa l-qasam
`score` li tara fit-tweġiba tal-API u t-tikketta murija fid-dashboard.

### Kunfidenza

Kull entrata tingħata livell ta’ kunfidenza bbażat fuq l-għadd ta’ voti f’Arena:

| Kunfidenza | Voti    |
| ---------- | ------- |
| `high`     | ≥ 5,000 |
| `medium`   | ≥ 1,000 |
| `low`      | < 1,000 |

### Ħżin u aġġornament

L-entrati normalizzati jinkitbu fit-tabella tad-DB `model_intelligence` b’
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). L-entrati **jiskadu wara
7 ijiem**, għalhekk fornitur li jieqaf jissinkronizza eventwalment jitneħħa minflok ma jkompli jipprovdi
data skaduta.

Is-sinkronizzazzjoni taħdem **awtomatikament b’mod predefinit**:

- Taħdem darba meta jitħaddem is-server u mbagħad fuq tajmer perjodiku
  (`src/lib/arenaEloSync.ts`, ikkonnettjat minn `src/instrumentation-node.ts`).
- Hija **mhux imblokkanti u qatt ma tkun fatali** — jekk il-ġbir tad-data mis-sors estern ifalli, OmniRoute jibqa’
  jaħdem u l-klassifiki sempliċement juru l-aħħar data valida (jew stat vojt).

Żewġ varjabbli tal-ambjent jikkontrollawha (dokumentati f’
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Varjabbli                 | Valur predefinit | Għan                                                              |
| ------------------------- | ---------------- | ----------------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`           | Issettja għal `false` biex ma ssirx is-sinkronizzazzjoni esterna. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h)    | Intervall tas-sinkronizzazzjoni, f’sekondi.                       |

### Sinkronizzazzjoni manwali / status / tħassir

Għall-operaturi, endpoint ta’ ġestjoni awtentikat jipprovdi kontroll manwali
(`src/app/api/intelligence/sync/route.ts` — jeħtieġ awtentikazzjoni ta’ ġestjoni):

```
GET    /api/intelligence/sync          # l-istatus attwali tas-sinkronizzazzjoni (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # attiva sinkronizzazzjoni manwali; body: { "dryRun": true } għal previżjoni mingħajr kitba
DELETE /api/intelligence/sync          # ħassar l-entrati kollha sinkronizzati tal-intelliġenza arena_elo
```

Jekk il-paġna tal-klassifiki tkun vojta, `POST /api/intelligence/sync` manwali (jew sempliċement
it-tħaddim mill-ġdid tas-server) jerġa’ jimliha.

### Tqabbil tal-mudelli mal-klassifika

L-IDs tal-mudelli fir-reġistru u l-ismijiet tal-mudelli f’Arena mhux dejjem jaqblu eżattament. Il-klassifika tuża
tqabbil flessibbli (`findMatchingIntelligence` f’`src/lib/freeProviderRankings.ts`):

1. Tqabbil eżatt mal-ID normalizzat tal-mudell.
2. Tqabbil wara li jitneħħa suffiss tal-verżjoni fit-tarf (eż. `kimi-k2.6` → `kimi-k2`).
3. Tqabbil tal-prefiss (isem ta’ mudell fil-klassifika jkun prefiss tal-ID fir-reġistru).

Min-naħa tas-sinkronizzazzjoni, il-prefissi magħrufa tal-fornituri (`anthropic/`, `openai/`, `google/`, …) jiġu
mneħħija u mappa żgħira tal-psewdonimi tespandi l-ismijiet kanoniċi fil-varjanti li OmniRoute juża
internament, sabiex il-mudelli jibqgħu jistgħu jinstabu taħt kwalunkwe isem.

### Kif jiġi kklassifikat fornitur

Għal kull fornitur bla ħlas, il-magna tikkalkula punteġġ għal kull mudell fil-katalgu tiegħu, imbagħad:

- **L-Aqwa Mudell** = il-mudell tal-fornitur bl-ogħla punteġġ.
- **Punteġġ Medju** = il-medja tal-punteġġi tal-mudelli kollha ta’ dak il-fornitur li kellhom punteġġ.
- **Mudelli** = kemm mill-mudelli tal-fornitur kellhom punteġġ Arena.

Il-fornituri jiġu magħżula l-ewwel skont il-**punteġġ tal-aqwa mudell**, imbagħad skont il-punteġġ medju. Dan jippremja
fornitur li joffri mill-inqas mudell wieħed b’saħħtu u bla ħlas.

## Kif Tużah biex Tagħżel Fornituri Bla Ħlas

1. **Agħżel il-kategorija t-tajba.** Uża l-filtru **Coding** għal xogħlijiet aġentiċi/ta' kodifikazzjoni, jew
   ħallih fuq **All Categories** / **Default** għal konverżazzjoni ġenerali. L-istess fornitur jista'
   jikklassifika b'mod differenti bejn il-kategoriji għax l-aqwa mudell tiegħu jvarja skont il-klassifika.
2. **Ippreferi l-podju għal konfigurazzjonijiet ta' darba.** Jekk trid tikkonnettja biss fornitur wieħed jew tnejn bla
   ħlas, ibda b'dawk fl-ogħla pożizzjonijiet għall-kategorija tiegħek.
3. **Iċċekkja l-badge tat-Tip.** Il-fornituri `NOAUTH` huma l-aktar veloċi biex tikkonnettjahom (mingħajr
   kredenzjali). Il-pjanijiet bla ħlas `OAUTH` / `APIKEY` jeħtieġu reġistrazzjoni malajr iżda spiss joffru
   mudelli aktar b'saħħithom. Ara l-[Gwida għall-Pjanijiet Bla Ħlas](../getting-started/FREE-TIERS-GUIDE.md) għall-
   passi tal-konnessjoni.
4. **Ikkonnettja diversi fornituri u ħalli lil Auto-Combo jiddeċiedi.** L-istess data ta' Arena ELO li tħaddem
   din il-paġna tintuża wkoll mill-**fattur tal-adegwatezza għall-kompitu** tal-magna ta' punteġġ Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, ordni tar-
   riżoluzzjoni `user_override → arena_elo → models_dev_tier → static table`). Għalhekk, wara li tikkonnettja
   l-aqwa fornituri bla ħlas, ir-routing b'`model: "auto"` (eż. `auto/coding`) awtomatikament
   jippreferi l-mudelli bla ħlas ta' kwalità ogħla għal kull talba. Ara
   [Auto-Combo](../routing/AUTO-COMBO.md) għall-punteġġ sħiħ b'16-il fattur.
