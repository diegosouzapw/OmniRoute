## 1. Antigravity vs Antigravity CLI (agy)

Iż-żewġ fornituri jużaw l-**istess backend ta’ Google** — klijent OAuth identiku, aġġornament tat-token, endpoints, u kontijiet ta’ Google. Id-differenza hija liema mudelli tara.

> Ara l-[avviż dwar l-Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli) għat-tqabbil uffiċjali ta’ Google.

| Aspett                     | `antigravity` (IDE)                                         | `agy` (CLI)                                                           |
| -------------------------- | ----------------------------------------------------------- | --------------------------------------------------------------------- |
| **Prodott ta’ Google**     | Antigravity 2.0 / Antigravity IDE                           | Antigravity CLI                                                       |
| **Backend**                | L-istess Google Cloud Code API                              | L-istess Google Cloud Code API                                        |
| **OAuth / Token**          | L-istess klijent, l-istess aġġornament                      | L-istess klijent, l-istess aġġornament                                |
| **Katalgu tal-mudelli**    | Lista statika kkurata (inkorporata direttament f’OmniRoute) | Eżaminata direttament minn Google permezz ta’ `:fetchAvailableModels` |
| **Mudelli Claude**         | Sonnet 4.6, Opus 4.6 (4 varjanti kull wieħed)               | Sonnet 4.6, Opus 4.6 (4 varjanti kull wieħed)                         |
| **Ismijiet ta’ Gemini**    | Tikketti ċari (Baxx/Medju/Għoli)                            | IDs upstream (extra-low/low/agent)                                    |
| **Mudelli addizzjonali**   | `gpt-oss-120b-medium`                                       | Jista’ jinkludi mudelli addizzjonali minn Google                      |
| **Każ ta’ użu predefinit** | Integrazzjoni mal-IDE (VS Code, JetBrains)                  | Aċċess permezz tas-CLI / API                                          |
| **Kwota**                  | Kondiviża ma’ agy (l-istess kont ta’ Google)                | Kondiviża ma’ antigravity (l-istess kont ta’ Google)                  |

**Mudelli disponibbli (ivverifikati permezz ta’ esperiment, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (diversi livelli ta’ ħsieb)
- Claude: Sonnet 4.6, Opus 4.6 (kull wieħed b’varjanti predefiniti/baxxi/medji/għoljin)
- Oħrajn: GPT-OSS 120B Medium
- **Claude Sonnet 5 MHUX disponibbli** — huma appoġġjati biss il-varjanti 4.6

**Għaliex il-katalgu tal-mudelli huwa differenti**: Is-CLI ta’ Google huwa “ottimizzat għall-veloċità u għal overhead baxx” u “koottimizzat mal-mudelli Gemini” (skont il-blog uffiċjali ta’ Google). Il-prodott tal-Web/IDE huwa “ottimizzat għall-kompletezza.” Is-CLI juża `:fetchAvailableModels` biex jiskopri l-mudelli b’mod dinamiku, filwaqt li l-IDE juża lista statika kkurata.

**Fil-prattika**: Uża l-prefiss `agy/` għall-mudelli Gemini (eż. `agy/gemini-3.7-flash-high`). Uża `antigravity/` għal-lista statika kkurata. It-tnejn jużaw l-istess backend ta’ Google, iżda jesponu ismijiet differenti għall-mudelli. Il-kwota hija kondiviża — l-użu ta’ kwalunkwe fornitur jgħodd mal-limiti tal-istess kont ta’ Google.

**Meta l-kont tiegħek jiġi eżawrit**: OmniRoute jerġa’ jipprova awtomatikament bil-kont disponibbli li jmiss fir-rotta kkombinata. Ma huwa meħtieġ l-ebda intervent manwali.

## 3. Kif Tikseb projectId

Kull konnessjoni antigravity/agy teħtieġ `projectId` ta’ Google Cloud Code. Mingħajru, l-endpoint `/v1internal:models` jirritorna 404.

### Metodu A: Awtomatiku (Rakkomandat)

OmniRoute jieħu ħsieb dan awtomatikament. Meta żżid kont ġdid ta’ Google permezz ta’ Dashboard OAuth:

1. OmniRoute jġedded it-token
2. Isejjaħ `loadCodeAssist` biex jiskopri l-projectId
3. Jekk ma jeżisti l-ebda proġett, isejjaħ `onboardUser` biex joħloq wieħed
4. Jerġa’ jipprova `loadCodeAssist` biex jikseb il-projectId li jkun għadu kif inħoloq
5. Isalvah fid-database

**Dan jaħdem għall-biċċa l-kbira tal-kontijiet** — ma huma meħtieġa l-ebda passi manwali.

### Metodu B: Manwali permezz ta’ agy CLI

Jekk l-iskoperta awtomatika tfalli (ara t-Taqsima 5 għal meta jiġri dan):

```bash
# Installa agy CLI (jekk għadu mhux installat)
npm install -g @anthropic-ai/agy

# Idħol bil-kont ta’ Google tiegħek
agy login

# Agħżel il-kont li jeħtieġ l-onboarding
# Dan jattiva r-reġistrazzjoni ta’ Cloud Code u jassenja projectId
```

Wara li `agy login` jirnexxi, ġedded it-token fid-Dashboard ta’ OmniRoute. Il-projectId jiġi skopert awtomatikament.

### Kif tivverifika

Iċċekkja d-database:

```bash
# Ġewwa l-container ta’ OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Jew iċċekkja l-logs:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. URI ta' Ridirezzjoni OAuth

### Il-Problema

Google OAuth jirrikjedi URI ta' ridirezzjoni validu. Il-valur predefinit ta' OmniRoute juża `http://127.0.0.1:20128/callback` (loopback). Dan jaħdem għal builds lokali iżda **ma jaħdimx għal deployments remoti** (eż., server aċċessat permezz ta' indirizz IP tal-LAN).

Google jirrifjuta URIs ta' ridirezzjoni li:

- Jużaw indirizzi IP (irid ikun domain li jispiċċa b'`.com`, `.org`, eċċ.)
- Ma jaqblux mal-URIs ta' ridirezzjoni rreġistrati fil-konfigurazzjoni tal-klijent OAuth

### Is-Soluzzjoni

**Għażla A: Uża l-fluss OAuth inkorporat (predefinit)**

- Jaħdem meta taċċessa OmniRoute minn `localhost` jew `127.0.0.1`
- Ma hija meħtieġa l-ebda konfigurazzjoni

**Għażla B: Kredenzjali OAuth personalizzati**

- Issettja `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` fl-ambjent tiegħek
- Ipprovdi l-kredenzjali Google OAuth tiegħek stess:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Irreġistra `https://your-domain.com/callback` bħala URI ta' ridirezzjoni awtorizzat fil-Google Cloud Console

**Għażla C: Uża agy CLI għall-ewwel login**

- Ħaddem `agy login` fuq il-magna li se taċċessa OmniRoute
- Il-fluss OAuth jitlesta lokalment u t-tokens jinħażnu
- Importa l-konnessjoni f'OmniRoute permezz tad-Dashboard

### Limitazzjonijiet

- Kredenzjali OAuth personalizzati jirrikjedu isem ta' domain (Google ma jaċċettax indirizzi IP bħala URIs ta' ridirezzjoni)
- Jekk m'għandekx domain, uża l-Għażla A jew C minflok

## 5. Soluzzjoni tal-Problemi: Meta l-Konfigurazzjoni Awtomatika Tfalli

OmniRoute jieħu ħsieb awtomatikament l-iskoperta ta' projectId u l-onboarding għall-biċċa l-kbira tal-kontijiet. Meta dan ifalli, il-kawża ewlenija normalment tkun waħda minn dawn:

### Ir-reġjun tal-kont huwa mblukkat

**Sintomu**: `agy login` jirritorna "Il-verifika tal-eliġibbiltà falliet: Il-kont attwali tiegħek mhuwiex eliġibbli għal Antigravity, għax bħalissa mhuwiex disponibbli fil-post fejn tinsab."

**Kawża ewlenija**: Il-kontijiet Google għandhom qasam backend imsejjaħ "Country Association" li jiġi ssettjat waqt ir-reġistrazzjoni. L-agy CLI u l-Cloud Code API jivverifikaw dan il-qasam b'mod strett — b'differenza minn Gemini fuq il-web, li jivverifika biss l-IP attwali tiegħek.

> Biex tivverifika jew tibdel ir-reġjun assoċjat mal-kont tiegħek, żur il-[Formola ta' Google għall-Assoċjazzjoni tal-Pajjiż](https://policies.google.com/country-association-form).

**Għaliex Gemini fuq il-web jaħdem iżda agy le**:

- Gemini fuq il-web / Google One: jivverifika biss l-IP attwali (il-proxy jgħaddi)
- agy CLI / Cloud Code API: jaqra l-qasam backend Country Association (il-proxy ma jgħinx)

**Soluzzjoni**:

1. Żur il-[Formola ta' Google għall-Assoċjazzjoni tal-Pajjiż](https://policies.google.com/country-association-form) waqt li tkun qed tuża IP tal-Istati Uniti
2. Ibgħat talba biex tbiddel ir-reġjun (agħżel "Ngħix f'pajjiż differenti")
3. Stenna bejn siegħa u 24 siegħa biex Google jipproċessa t-talba u jibgħat notifika bil-posta elettronika
4. Imbagħad `agy login` għandu jirnexxi

### Il-kont m'għandux proġett Cloud Code

**Sintomu**: Ir-reġistri juru `loadCodeAssist returned no project id` u `onboardUser failed (400)`.

**Kawża ewlenija**: Il-kont qatt ma ġie rreġistrat ma' Google Cloud Code, u l-onboarding awtomatiku falla.

**Soluzzjoni**: Ħaddem `agy login` manwalment biex tiskatta r-reġistrazzjoni ta' Cloud Code, imbagħad aġġorna t-token fid-Dashboard ta' OmniRoute.

### It-token skada jew ġie revokat

**Sintomu**: Żbalji 401 fir-reġistri, jew messaġġi "It-token skada".

**Soluzzjoni**: Aġġorna t-token f'Dashboard → Providers → agy → Ikklikkja l-ikona tal-aġġornament. Jekk ir-refresh token innifsu ġie revokat, ikollok terġa' tawtentika permezz ta' OAuth.
