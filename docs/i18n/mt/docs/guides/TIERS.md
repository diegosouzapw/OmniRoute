OmniRoute jorganizza t-352 fornitur appoġġjat fi 3 livelli ekonomiċi. Kull
talba tgħaddi minnhom skont l-ordni sakemm wieħed jirritorna b'suċċess — int
tikseb l-orħos tweġiba vijabbli mingħajr qatt ma tikteb kodiċi ta' riżerva.

## Livell 1 — Abbonament

**Fornituri li diġà tħallas għalihom.** OmniRoute juża kull qatra tal-kwota qabel
ma tiskadi.

| Fornitur                          | Għaliex Livell 1                                  |
| --------------------------------- | ------------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — rata fissa, spiss mhux użata |
| OpenAI Codex (abbonament ChatGPT) | Plus/Team jinkludi kwota ta' Codex                |
| GitHub Copilot                    | Għal kull post — il-kwota tiġġedded kull xahar    |
| Cursor IDE                        | Kwota tal-pjan Pro                                |
| Antigravity / Devin Desktop       | Kwoti integrati                                   |

**Strateġija**: idderieġi hawn l-ewwel kull talba li taqbel mal-kapaċitajiet
tal-mudell. It-traċċatur tal-kwota jimmonitorja meta t-tiġdid ikun qed joqrob, u
l-istrateġija kombinata `reset-aware` tipprijoritizza kif xieraq. Biex tidderieġi
lejn Livell 1 l-ewwel u tgħaddi għal livelli bi ħlas biss hekk kif tispiċċa
l-kwota, uża l-id `auto/thrifty` — jew `auto/subscription` biex tibqa' tuża
l-kapaċità inkluża fil-pjan u twaqqaf it-talba jekk din ma tkunx disponibbli. Ara
[Rotot bl-abbonament l-ewwel](../routing/SUBSCRIPTION_LADDER.md).

## Livell 2 — Irħis

**Fornituri bi ħlas għal kull token taħt $1/1M tokens.** Riżervati għal xogħol
b'volum għoli jew wara li l-kwoti ta' Livell 1 jilħqu l-limiti.

| Fornitur                            | Prezz (input/output)  | Punti b'saħħithom     |
| ----------------------------------- | --------------------- | --------------------- |
| DeepSeek V4 Pro                     | $0.27 / $1.10 għal 1M | Kodiċi, raġunament    |
| GLM-4.5                             | $0.60 / $2.20 għal 1M | Kuntest twil          |
| MiniMax M1                          | $0.20 / $1.10 għal 1M | Veloċità              |
| Qwen Coder                          | $0.30 / $1.20 għal 1M | Kodiċi                |
| OpenRouter (ottimizzat għall-prezz) | ivarja                | 100+ mudell, dinamiku |

**Strateġija**: il-kombinazzjoni `cost-optimized` tagħżel il-mudell bl-inqas
$/token li jissodisfa l-filtru tal-kapaċitajiet tal-kompitu (viżjoni, modalità
JSON, għodod, kuntest massimu).

## Livell 3 — Bla ħlas

**Fornituri mingħajr spiża** — livelli bla ħlas, programmi ta' kreditu, kwoti
OAuth ta' kuljum.

| Fornitur         | Kwota bla ħlas / krediti                  |
| ---------------- | ----------------------------------------- |
| Kiro AI          | Livell Claude bla ħlas (użu ġust ġeneruż) |
| OpenCode Free    | Mingħajr awtentikazzjoni, limiti ġenerużi |
| Qoder            | OAuth bla ħlas                            |
| Google Vertex AI | $300 fi krediti għal kontijiet ġodda      |
| Amazon Q         | Livell bla ħlas għall-utenti ta' AWS      |
| Pollinations     | API pubblika miftuħa                      |
| Cloudflare AI    | Livell bla ħlas ta' Workers AI            |

**Strateġija**: il-kombinazzjoni `auto` b'limitu tal-baġit tidderieġi hawn meta
Livell 1+2 ifallu jew meta `useFreeOnly=true` ikun issettjat. Il-fornituri bla
ħlas spiss ikollhom limiti tar-rata aktar stretti — is-circuit breaker
jirkuprahom wara l-perjodu ta' stennija.

## Konfigurazzjoni tal-livelli

Dashboard → **Livelli** → assenja l-fornituri tiegħek. Il-valuri predefiniti
(minn `tierDefaults.json`) huma raġonevoli; editjahom meta jkollok abbonamenti
speċifiċi x'tipprijoritizza jew fornituri x'teskludi.

Il-punteġġar ta' Auto-Combo b'16-il fattur iqis ukoll il-livell. Ara
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetrija

Dashboard → **Użu** juri t-tokens użati għal kull livell kuljum. Uża dan biex:

- Tikkonferma li Livell 1 qed jintuża bis-sħiħ (inkella qed taħli l-valur tal-abbonament)
- Tidentifika liema mudelli ta' Livell 2 jintgħażlu l-aktar (ikkonsolidahom għal 1-2)
- Tivverifika li Livell 3 jiffranka l-flus fuq xogħlijiet ta' ttestjar/esplorazzjoni

## Mudelli komuni

### Xogħol kompletament bla ħlas

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Jimbotta bil-qawwa lejn Livell 3; juża Livell 2 biss jekk Livell 3 ma jkunx
disponibbli.

### Abbonament l-ewwel b'riżerva rħisa

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Lista espliċita u ordnata li taqbel ma' Livell 1 → Livell 2 → Livell 3.
