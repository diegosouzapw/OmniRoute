OmniRoute joffri **żewġ** modi kif tuża OpenAI Codex:

| Fornitur               | Kif jikkomunika ma’ OpenAI                                                                                                                                                                                                     | Riżerva dwar l-użu                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| **`codex`**            | Jibgħat mill-ġdid it-token OAuth tiegħek ta’ ChatGPT/OpenAI direttament lill-Responses API                                                                                                                                     | **Iva** — is-sessjoni uffiċjali mhijiex awtorizzata għall-użu ma’ proxy/router |
| **`codex-app-server`** | Jikkontrolla l-**`codex app-server` proprju tal-Codex CLI** permezz ta’ JSON-RPC/WebSocket; is-CLI jieħu ħsieb l-OAuth tiegħu stess u jġeddu awtomatikament (`~/.codex/auth.json`) eżatt bħal sessjoni interattiva ta’ `codex` | **Le** — OmniRoute qatt ma jerġa’ jibgħat token lill-API                       |

Minħabba li `codex-app-server` qatt ma jerġa’ jibgħat token, ma għandux ir-riżerva
dwar l-użu marbuta mar-riproduzzjoni tas-sessjoni. Madankollu, jeħtieġ **Codex CLI
aċċessibbli fil-URL tal-app-server ikkonfigurat**, u dak is-CLI jrid ikun **illoggjat**.

---

## 1. Arkitettura

```
┌─ App OmniRoute ──────────────────┐        ┌─ Sidecar codex-app-server ──────────┐
│  CodexAppServerExecutor          │  WS    │  codex app-server                   │
│  ws://codex-app-server:1456 ─────┼───────▶│  --listen ws://0.0.0.0:1456         │
│  (+ token tal-kapaċità)           │  JSON  │  --ws-auth capability-token         │
│                                  │  RPC   │  jimmaniġġja l-OpenAI OAuth waħdu  │
└──────────────────────────────────┘        │  (~/.codex/auth.json, tiġdid awtom.)│
        │ jaqsam (volumi compose)            └─────────────────────────────────────┘
        ▼
  codex-appserver-token   → it-token tal-kapaċità WS (it-tnejn jimmuntawh)
  codex-appserver-home    → ~/.codex (auth.json jinkiteb mid-dashboard,
                             jinqara mill-codex app-server tas-sidecar)
```

- Is-sidecar jisma’ **biss** fuq in-network intern ta’ compose
  (`ws://codex-app-server:1456`) wara token tal-kapaċità. Dan **qatt** ma jiġi
  ppubblikat fuq il-host jew l-internet.
- Il-Codex CLI huwa inkorporat f’`omniroute:base`, għalhekk ma hija meħtieġa
  l-ebda installazzjoni ta’ codex fuq il-host jew il-magna tal-utent meta tħaddem
  is-sidecar.

## 2. Ħaddmu

```bash
# Ibda l-istack BIL-profil tas-sidecar codex app-server:
docker compose --profile base --profile codex-app-server up -d
# (podman: podman compose --profile base --profile codex-app-server up -d)
```

Is-sidecar joħloq it-token tal-kapaċità WS tiegħu mal-ewwel boot (fil-volum
kondiviż `codex-appserver-token`) u l-app taqra l-istess token permezz ta’
`OMNIROUTE_CODEX_APPSERVER_WS_TOKEN_FILE`. Ma hemmx bżonn li t-token jiġi
kkonfigurat manwalment.

## 3. Ikkonnettja u illoggja

1. Fid-dashboard, żid konnessjoni għal **OpenAI Codex (App-Server)**. Ma hija
   meħtieġa l-ebda API key jew token (huwa fornitur mingħajr awtentikazzjoni —
   is-sidecar jieħu ħsieb l-awtentikazzjoni).
2. Jekk il-Codex CLI tas-sidecar **għadu mhux illoggjat**, il-verifika tas-saħħa
   tal-konnessjoni tirrapporta _"qed jaħdem iżda mhux illoggjat"_ (mhux żball
   aħmar tal-awtentikazzjoni). Uża **Idħol b’ChatGPT**: dan iħaddem l-OAuth
   standard tal-apparat ta’ Codex fil-browser tiegħek u mbagħad jikteb
   `~/.codex/auth.json` fil-volum kondiviż permezz ta’ **Applika
   l-awtentikazzjoni** (l-istess login wieħed iservi kemm lill-fornituri `codex`
   kif ukoll lil `codex-app-server`).
3. Ladarba tkun illoggjajt, il-verifika tas-saħħa ssir ħadra (tivverifika kemm
   `/readyz` **kif ukoll** `account/read` — jiġifieri li s-servizz qed jaħdem
   _u_ huwa awtentikat) u tibda tieħu x-xogħol.

Id-dashboard qatt ma jissostitwixxi `~/.codex/auth.json` eżistenti u validu —
jikteb biss meta l-fajl ikun nieqes jew it-token tiegħu jkun skada (dejjem
tittieħed kopja ta’ riżerva).

## 4. Xenarji ta’ skjerament

- **Operatur b’Codex CLI diġà awtentikat** — immonta `~/.codex` tal-host tiegħek
  fis-sidecar (`codex-appserver-home`) u aqbeż il-pass tal-login.
- **Utent pubbliku, mingħajr codex installat lokalment** — dan ma jimpurtax:
  is-sidecar għandu s-CLI. L-utent jawtentika ruħu biss permezz tad-dashboard.
- **OmniRoute fuq bare metal (mingħajr sidecar, codex fuq il-host)** — issettja
  `OMNIROUTE_CODEX_APPSERVER_WS` biex jipponta lejn il-`codex app-server` tiegħek
  u żgura li codex fuq il-host ikun illoggjat; il-ħjiel "codex mhux installat"
  jidher jekk il-binary ikun nieqes.

## 5. Ħruġ residenzjali / UDP (żieda għall-operatur, mhux inkluża)

Is-sidecar ġeneriku ta’ hawn fuq joħroġ permezz tan-network normali tal-container.
Operatur li jeħtieġ li t-traffiku ta’ Codex joħroġ minn **punt ta’ ħruġ
residenzjali** (eż. sidecar TUN ta’ tailscale li jġorr TCP + UDP/QUIC) iħaddmu
bħala override separat ta’ compose; dan intenzjonalment **mhuwiex** parti
mill-profil `codex-app-server` inkluż. Ara r-runbook intern tal-operazzjonijiet
għal dik il-konfigurazzjoni.
