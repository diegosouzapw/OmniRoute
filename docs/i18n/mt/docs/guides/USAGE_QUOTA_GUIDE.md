## Ħarsa Ġenerali

Kull talba li tgħaddi minn OmniRoute tiġġenera **rekord tal-użu** li jiġbor:

- **Identità**: liema ċavetta API, fornitur, mudell u kombinazzjoni
- **Tokens**: tokens tal-prompt, tokens tat-tlestija, tokens fil-cache u t-total
- **Spiża**: ammont f’USD (ikkalkulat mid-data tal-prezzijiet)
- **Ħinijiet**: latenza u timestamps tal-bidu/tmiem
- **Status**: suċċess, żball, limitazzjoni tar-rata, eċċ.

Dawn ir-rekords jiġu aggregati f’**analitika**, maħżuna bħala **snapshots tal-kwota**, u użati biex jiġu infurzati **limiti tal-baġit għal kull ċavetta**.

```
Talba ──▶ chatCore ──▶ usage.record() ──▶ SQLite
                                  │
                          ┌───────┼───────┐
                          ▼       ▼       ▼
                    analitika  kwota   fatturazzjoni
                    (dashboard) (infurzar) (esportazzjoni)
```

Is-servizz `usage.ts` jiġbor **avveniment tal-użu** għal kull talba:

| Kamp               | Tip     | Sors                                                            |
| ------------------ | ------- | --------------------------------------------------------------- |
| `id`               | string  | UUID iġġenerat waqt ir-reġistrazzjoni                           |
| `apiKeyId`         | string  | Iċ-ċavetta API li bdiet it-talba                                |
| `provider`         | string  | ID tal-fornitur (openai, anthropic, eċċ.)                       |
| `model`            | string  | ID tal-mudell (gpt-5, claude-opus-4-6, eċċ.)                    |
| `comboId`          | string? | ID tal-kombinazzjoni jekk ir-rotta għaddiet minn waħda          |
| `promptTokens`     | number  | Mir-rispons upstream                                            |
| `completionTokens` | number  | Mir-rispons upstream                                            |
| `cachedTokens`     | number  | Tokens milħuqa fil-cache (cache tal-prompt ta’ Anthropic, eċċ.) |
| `totalTokens`      | number  | prompt + tlestija                                               |
| `costUsd`          | number  | Ikkalkulat mid-data tal-prezzijiet                              |
| `latencyMs`        | number  | Tul tat-talba mill-bidu sat-tmiem                               |
| `status`           | enum    | `success`, `error`, `rate_limited`, `timeout`, `cancelled`      |
| `errorClass`       | string? | Klassi tal-iżball jekk status != success                        |
| `timestamp`        | string  | ISO 8601 UTC                                                    |
| `metadata`         | object  | Data personalizzata injettata minn plugin                       |

### Minn Fejn Jiġu t-Tokens

It-tokens jiġu estratti mir-rispons tal-fornitur upstream fil-**handler tar-rispons**:

```ts
// Minn open-sse/handlers/chatCore.ts
const response = await providerExecutor.execute(provider, request);
const usage = response.usage || {
  prompt_tokens: 0,
  completion_tokens: 0,
  cached_tokens: 0,
};
```

Għall-fornituri li ma jirritornawx l-użu (xi fornituri li jużaw cookies tal-web), OmniRoute **jistma** t-tokens permezz tal-euristika `~4 chars per token` (ara `open-sse/services/autoCombo/pipelineRouter.ts`).

### Tokens fil-Cache

OmniRoute jsegwi `cached_tokens` separatament minn `prompt_tokens` għaliex:

- Il-cache tal-prompt ta’ Anthropic jitlob rata mnaqqsa għat-tokens fil-cache (10% tar-rata normali)
- Xi fornituri jirritornaw `cache_read_input_tokens` li għandhom jiġu pprezzati b’mod differenti
- L-analitika tista’ turi r-**rata ta’ suċċess tal-cache** = `cached_tokens / prompt_tokens`

## Kalkolu tal-Ispejjeż

L-ispejjeż jiġu kkalkolati minn **data tal-ipprezzar** sinkronizzata minn LiteLLM (`src/lib/pricingSync.ts`):

| Mudell            | Input $/1M | Output $/1M | Fil-cache $/1M |
| ----------------- | ---------- | ----------- | -------------- |
| gpt-5             | $2.50      | $10.00      | —              |
| claude-opus-4-6   | $15.00     | $75.00      | $1.50          |
| claude-sonnet-4-5 | $3.00      | $15.00      | $0.30          |
| gemini-2.5-pro    | $1.25      | $10.00      | —              |

Il-formula tal-ispiża (`src/lib/usage/costCalculator.ts`):

```ts
cost =
  (prompt_tokens - cached_tokens) * input_price +
  cached_tokens * cached_price +
  completion_tokens * output_price;
```

> **Għaliex jitnaqqsu t-tokens fil-cache mill-prompt?** Il-porzjon fil-cache għandu prezz separat; jekk jiġi applikat il-prezz tal-input għall-prompt kollu, l-ispiża tingħadd iżżejjed.

### Sinkronizzazzjoni tal-Ipprezzar

Id-data tal-ipprezzar tiġi sinkronizzata awtomatikament minn LiteLLM permezz tal-endpoint `/api/pricing/sync` (attivat mill-kompitu cron integrat, mhux minn varjabbli tal-ambjent għall-utent):

```bash
# Attivazzjoni manwali
curl -X POST http://localhost:20128/api/pricing/sync
```

Għal mudelli mingħajr data tal-ipprezzar, OmniRoute jirrikorri għal **stima tal-ispiża** bl-użu ta’ rati medji interni (meħuda mid-data tal-ipprezzar ta’ LiteLLM).

## Infurzar tal-Kwota

Il-kwota għal kull ċavetta API tiġi infurzata f’żewġ postijiet:

1. **Limitu mhux strett** (`quotaWarnAt`): twissija fid-dashboard meta l-użu jaqbeż il-livell limitu
2. **Limitu strett** (`quotaLimit`): it-talba tiġi miċħuda b’HTTP 429 meta jinqabeż

### Konfigurazzjoni

```ts
// Għal kull ċavetta API
await updateApiKey(keyId, {
  quotaWarnAt: 5_00,    // $5.00 — uri twissija
  quotaLimit: 10_00,    // $10.00 — waqfien strett
  quotaWindow: "month", // "day" | "week" | "month" | "all"
});
````

### Fluss tal-Infurzar

```
Talba ──▶ quotaCheck()
              │
              ├── Fil-limitu?  ──▶ ippermetti
              │
              └── Fuq il-limitu?  ──▶ 429 Too Many Requests
                                      bl-intestazzjoni Retry-After
```

### Snapshots tal-Kwota

It-tabella `quotaSnapshots` taħżen **l-istat storiku tal-kwota** għall-analiżi tax-xejriet:

| Qasam | Deskrizzjoni |
| ----------- | ------------------------------------ | ------ | ------- |
| `apiKeyId` | Iċ-ċavetta li qed tiġi intraċċata |
| `window` | "day" | "week" | "month" |
| `used` | L-ispiża użata f’din it-tieqa (ċenteżmi) |
| `limit` | Il-limitu (ċenteżmi) |
| `resetAt` | Meta tiġi rrisettjata t-tieqa |
| `createdAt` | Meta ttieħed l-isnapshot |

L-isnapshots jittieħdu **ma’ kull talba** li tuża spiża > 0, u jintużaw biex:

- Jirrendu l-istrixxa tal-progress tal-kwota fid-dashboard
- Juru ċarts tax-xejriet tal-kwota fuq 30 jum
- Jiskattaw allerti meta l-użu joqrob lejn il-limitu

## Żamma u Tindif

Id-data dwar l-użu tikber b'~1-10KB għal kull talba. Fuq skala kbira, dan jista' jkun sinifikanti.

### Settings taż-Żamma

Iż-żamma tal-istorja tal-użu tiġi kkonfigurata permezz tas-Settings tad-Database fl-interfaċċa tal-utent jew permezz ta' `/api/settings/database`.

B'mod awtomatiku, l-istorja tal-użu tinżamm għal **90 jum**.

### Tindif

Ir-rekords qodma jitnaddfu minn `src/lib/db/cleanup.ts`:

- Jitħaddem mill-proċess cron fl-isfond
- Iħassar rekords minn `usage_history` li jkunu eqdem mill-perjodu taż-żamma kkonfigurat fl-issettjar `usageHistory`

### Stima tal-Ħażna

| Rata tat-talbiet  | Ħażna għal 30 jum | Ħażna għal 90 jum |
| ----------------- | ----------------- | ----------------- |
| 100 talba/jum     | ~3MB              | ~9MB              |
| 1,000 talba/jum   | ~30MB             | ~90MB             |
| 10,000 talba/jum  | ~300MB            | ~900MB            |
| 100,000 talba/jum | ~3GB              | ~9GB              |

Għal traffiku għoli ħafna, ikkunsidra:

- Li tnaqqas il-perjodu taż-żamma permezz tas-Settings tad-Database
- Li tuża `aggregated_metrics` minflok rekords mhux ipproċessati (għall-analitika biss)

## Suġġerimenti għall-Ottimizzazzjoni tal-Ispejjeż

### 1. Uża l-Mudell it-Tajjeb

```bash

# Kompitu kumpless — uża kwalità għolja
curl -d '{"model":"auto/smart","messages":[...]}'
```

### 2. Attiva l-Caching

Il-caching tal-prompt ta' Anthropic jiffranka **90% fuq kuntest ripetut**:

```ts
// Il-caching huwa awtomatiku — inkludi biss l-istess prompt tas-sistema twil
const response = await openai.chat({
  model: "claude-sonnet-4-5",
  system: longSystemPrompt, // Se jinħażen fil-cache awtomatikament
  messages: [{ role: "user", content: "..." }],
});
```

### 3. Uża l-Kompressjoni

Il-kompressjoni RTK + Caveman tiffranka **15-95% f'sessjonijiet b'użu intensiv tal-għodod**:

```ts
const config = {
  compression: {
    engine: "rtk",
    intensity: "aggressive",
  },
};
```

### 4. Issettja Kwoti għal Kull Ċavetta

Dejjem issettja `quotaLimit` biex tevita spejjeż bla kontroll:

```ts
await updateApiKey(keyId, { quotaLimit: 10_00 }); // Limitu ta' $10/xahar
```

### 5. Awditja l-Akbar Konsumaturi

Uża d-dashboard jew **`/api/usage/analytics`** biex tiġbor skont iċ-ċavetta tal-API u tissortja skont l-ispiża:

```bash
GET /api/usage/analytics?groupBy=apiKey
```

## Soluzzjoni tal-Problemi

### "L-ispiża hija ogħla milli mistenni"

1. Iċċekkja **`/api/usage/analytics?groupBy=model`** — sib il-mudell għali
2. Iċċekkja **`/api/usage/analytics?groupBy=apiKey`** — sib il-konsumatur ewlieni
3. Ivverifika li d-data tal-ipprezzar hija aġġornata: `POST /api/pricing/sync`

### "Rekords neqsin"

- Iċċekkja s-settings taż-żamma tad-DB taħt Dashboard → Database → Cleanup — ir-rekords qodma jitħassru mill-kompitu perjodiku tat-tindif (`src/lib/db/cleanup.ts`)
