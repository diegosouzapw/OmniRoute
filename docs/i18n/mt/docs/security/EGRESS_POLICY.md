> **Orbot it-traffiku ħiereġ ma' familja IP waħda — `auto`, `ipv4`, jew `ipv6` — għal kull proxy, sabiex ħruġ IPv6-only qatt ma jerġa' jgħaddi b'mod sieket minn IPv4.**

> **Sors awtorevoli:** `open-sse/utils/proxyFamily.ts`, `open-sse/utils/proxyDispatcher.ts`, `open-sse/utils/proxyFetch.ts`, `open-sse/utils/socksConnectorWithFamily.ts`, `open-sse/utils/proxyFamilyResolve.ts`, `src/shared/validation/schemas.ts`, `src/lib/db/proxies.ts`, `src/lib/db/upstreamProxy.ts`, `src/lib/db/migrations/099_proxy_family.sql`

OmniRoute jippermetti li kull proxy jkollu **direttiva tal-familja tal-indirizz għall-ħruġ**. B'mod awtomatiku, is-sistema operattiva tagħżel IPv4 jew IPv6 (dual-stack, "Happy Eyeballs"). Meta tissettja d-direttiva għal `ipv4` jew `ipv6`, OmniRoute jorbot kull konnessjoni minn dak il-proxy mal-familja magħżula u **jfalli b'mod magħluq** minflok ma jaqleb lura għall-familja l-oħra.

Din il-paġna tiddokumenta x'inhi d-direttiva, għaliex teżisti, fejn tikkonfiguraha, u kif tiġi riżolta waqt l-eżekuzzjoni.

## X'Inhi

Kull proxy fir-reġistru għandu kamp `family` bi tliet valuri possibbli, ivvalidati permezz ta' enum ta' Zod:

```ts
// src/shared/validation/schemas.ts
family: z.enum(["auto", "ipv4", "ipv6"]).optional().default("auto"),
```

Il-valur awtomatiku tal-kamp huwa `"auto"`, li jippreserva l-imġiba dual-stack preċedenti. Jekk tissettjah għal `ipv4` jew `ipv6`, il-familja tal-konnessjoni għal dak il-proxy tiġi marbuta mal-valur magħżul.

Id-direttiva tiġi normalizzata kullimkien permezz ta' helper wieħed sabiex kwalunkwe valur mhux magħruf jinbidel għal `auto`:

```ts
// open-sse/utils/proxyFamily.ts
export type ProxyFamily = "auto" | "ipv4" | "ipv6";

export function parseProxyFamily(value: unknown): ProxyFamily {
  return value === "ipv4" || value === "ipv6" ? value : "auto";
}
```

## Għaliex Teżisti

Ġiet introdotta fil-PR [#3777](https://github.com/diegosouzapw/OmniRoute/pull/3777). Il-problemi li wasslu għaliha:

| Problema                                           | X'tirranġa d-direttiva                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ħruġ IPv6-only li jnixxi lejn IPv4**             | Meta host ta' proxy jkollu kemm rekords A kif ukoll AAAA (jew meta s-sistema operattiva tippreferi IPv4), Happy Eyeballs jista' jistabbilixxi konnessjoni ħierġa fuq IPv4 anke meta tkun trid mogħdija IPv6-only. L-irbit ma' `ipv6` jelimina dan it-tnixxija.                                                                                                        |
| **Revoka minħabba anomalija ta' ħruġ kondiviż**    | Fornituri b'rotazzjoni (codex/openai) jirrevokaw tokens meta ħafna kontijiet joħorġu mill-**istess** IP b'volum għoli. Il-kontroll tal-familja tal-ħruġ jgħin biex il-kontijiet jinżammu fuq mogħdijiet tal-ħruġ distinti u prevedibbli (ara [`src/lib/proxyEgress.ts`](../../src/lib/proxyEgress.ts) għad-dijanjostika tal-IP tal-ħruġ li tintuża flimkien ma' dan). |
| **Ħruġ deterministiku għall-konformità/ittestjar** | Meta trid tiggarantixxi li t-traffiku joħroġ permezz ta' familja speċifika, `auto` mhuwiex biżżejjed.                                                                                                                                                                                                                                                                 |

Id-direttiva hija intenzjonalment **għal kull proxy**, mhux globali — proxies differenti fil-pool tiegħek jista' jkollhom politiki differenti.

## Kif Tikkonfigurah

### Dashboard

Is-selettur jinsab fil-formola tal-proxy fit-tab **Proxy Pool**:

1. Iftaħ **Dashboard → Settings → Proxy → Proxy Pool**
2. Żid jew editja proxy
3. Issettja l-lista dropdown **IP family** għal `Awtomatiku (dual-stack)`, `IPv4 biss`, jew `IPv6 biss`
4. Issejvja

Il-kontroll jiġi rrendjat minn `ProxyRegistryManager.tsx` (immuntat f’`proxy/ProxyPoolTab.tsx`).

### API

Il-field `family` huwa parti mill-payloads għall-ħolqien/aġġornament tar-reġistru tal-proxy, ivvalidat minn `createProxyRegistrySchema` / `updateProxyRegistrySchema` (`src/shared/validation/schemas.ts`) u pproċessat minn `POST` / `PATCH /api/v1/management/proxies`:

```bash
# Oħloq proxy għal IPv6 biss
curl -X POST http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{
    "name": "IPv6 egress",
    "type": "socks5",
    "host": "proxy.example.com",
    "port": 1080,
    "family": "ipv6"
  }'

# Ibdel proxy eżistenti għal IPv4 biss
curl -X PATCH http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{ "id": "proxy-uuid-here", "family": "ipv4" }'
```

L-istess field huwa aċċettat ukoll mill-oġġett inline tal-konfigurazzjoni tal-proxy użat għall-entrati tal-upstream proxy (`upstream_proxy_config.family`, ara [Mudell tad-Data](#data-model)).

Għall-bqija tal-API tal-CRUD/assenjazzjoni tal-proxy, ara [PROXY_GUIDE.md](../ops/PROXY_GUIDE.md).

## Kif Jiġi Riżolt `auto`

Meta `family` ikun `auto`, OmniRoute **ma** jżid l-ebda direttiva — il-URL tal-proxy jintuża kif inhu u l-familja tal-konnessjoni tiġi ddeterminata intrinsikament.

Meta jinbena l-URL (`proxyConfigToUrl` / `normalizeProxyUrl` f’`open-sse/utils/proxyDispatcher.ts`), proxy `auto` jipproduċi URL sempliċi mingħajr markatur:

```ts
// open-sse/utils/proxyDispatcher.ts
const fam = parseProxyFamily(config.family);
const normalized = normalizeProxyUrl(proxyUrlStr, "context proxy", {
  allowSocks5,
});
return fam === "auto" ? normalized : `${normalized}?family=${fam}`;
```

Meta jsir id-dispatch (`resolveDispatcherFamily`), `auto` jiġi riżolt għall-familja intrinsika ta’ host speċifikat bħala indirizz IP litterali, jew għal `null` (biex l-OS jiddeċiedi) għal hostname:

```ts
// open-sse/utils/proxyDispatcher.ts
function resolveDispatcherFamily(parsed: URL): 4 | 6 | null {
  const directive = parseProxyFamily(parsed.searchParams.get("family") ?? undefined);
  const literal = detectIpLiteralFamily(parsed.hostname);
  if (directive === "auto") return literal; // null għal hostname → l-OS jagħżel
  // ...
}
```

Għalhekk:

- `auto` + host speċifikat bħala indirizz IP litterali (`192.0.2.1` / `[2001:db8::1]`) → il-familja ta’ dak l-indirizz.
- `auto` + hostname → `null` → riżoluzzjoni dual-stack standard tal-OS.

## Kif Jiġu Infurzati `ipv4` / `ipv6`

Direttiva li mhijiex `auto` tivvjaġġa bħala markatur sintetiku wieħed fil-query — `?family=ipv4` jew `?family=ipv6` — miżjud darba biss mal-URL normalizzat tal-proxy. `normalizeProxyUrl` joqgħod attent li jneħħi u jerġa’ jżid dan il-markatur eżattament darba sabiex qatt ma jikkorrompi l-analiżi tal-port.

Meta jinbena d-dispatcher, il-markatur jinqara u jiġi kkonvertit f’familja konkreta għall-konnessjoni. Jekk il-host ikun literal IP tal-familja **opposta**, OmniRoute jiġġenera żball (f’każ ta’ kontradizzjoni, l-imġiba tkun fail-closed):

```ts
// open-sse/utils/proxyDispatcher.ts
const want = directive === "ipv6" ? 6 : 4;
if (literal !== null && literal !== want) {
  throw new Error(
    `[ProxyDispatcher] Proxy family directive ${directive} contradicts ${literal === 6 ? "IPv6" : "IPv4"} literal host`
  );
}
```

Il-familja konkreta mbagħad tiġi ffissata fuq il-connector:

- **Proxies HTTP/HTTPS** (`ProxyAgent`): `proxyTls: { family, autoSelectFamily: false }` — dan jiddiżattiva Happy Eyeballs sabiex il-familja magħżula tkun l-unika waħda li tiġi kkuntattjata.
- **Proxies SOCKS5**: connector personalizzat jgħaddi `socket_options: { family, autoSelectFamily: false }` lill-klijent SOCKS (ara [Kompatibbiltà ma’ SOCKS5](#socks5-compatibility)).

## Kompatibbiltà ma’ SOCKS5

L-iffissar tal-familja jaħdem mal-proxies SOCKS5, iżda l-verżjoni standard ta’ `fetch-socks` ma tesponix l-għażliet tas-socket meħtieġa biex tiġi ffissata l-familja tal-pass permezz tal-proxy. Għalhekk, OmniRoute jipprovdi l-connector tiegħu stess:

```ts
// open-sse/utils/socksConnectorWithFamily.ts
export function buildSocksFamilySocketOptions(family: 4 | 6 | null): Record<string, unknown> {
  if (family === 6) return { family: 6, autoSelectFamily: false };
  if (family === 4) return { family: 4, autoSelectFamily: false };
  return {};
}
```

Id-dispatches SOCKS5 kollha jgħaddu minn `createSocksDispatcherWithFamily` irrispettivament minn `family` (inkluż `null` / `auto` fuq hostname): `buildSocksFamilySocketOptions(null)` jagħti `{}`, u tintuża l-istess mogħdija `SocksClient.createConnection` + TLS `buildConnector` bl-iffissar permezz ta’ `socket_options`, sabiex Happy Eyeballs ma jkunx jista’ jagħżel IPv4 għal politika ta’ egress esklużivament IPv6.

L-appoġġ għal SOCKS5 innifsu huwa attivat awtomatikament (tista’ tagħżel li tiddiżattivah permezz ta’ `ENABLE_SOCKS5_PROXY=false`); ara [PROXY_GUIDE.md → Varjabbli tal-Ambjent](../ops/PROXY_GUIDE.md#environment-variables).

## Imġiba Fail-Closed

L-għan kollu tad-direttiva huwa li **tirrifjuta** aktar milli terġa’ lura b’mod silenzjuż għall-familja żbaljata. Żewġ kontrolli jinfurzaw dan:

1. **Kontradizzjoni ma’ literal** — direttiva li tikkontradixxi host li jkun literal IP tiġġenera żball waqt il-bini tad-dispatcher (`resolveDispatcherFamily`, murija hawn fuq).

2. **Kontroll DNS preliminari tal-hostname** — għal proxy b’hostname u familja ffissata, `proxyFetch.ts` jivverifika li l-hostname fil-fatt għandu rekord fil-familja meħtieġa **qabel** ma jwettaq l-egress, permezz ta’ `assertHostnameSupportsFamily`:

   ```ts
   // open-sse/utils/proxyFamilyResolve.ts
   const hasFamily = records.some((r) => r.family === family);
   if (!hasFamily) {
     throw new Error(
       `[ProxyFamily] Proxy host ${host} has no ${family === 6 ? "IPv6 (AAAA)" : "IPv4 (A)"} record; ` +
         `refusing ${family === 6 ? "IPv6" : "IPv4"}-only egress (fail-closed)`
     );
   }
   ```

   F’każ ta’ falliment, `proxyFetch.ts` jimmarka l-iżball b’`code = "PROXY_FAMILY_UNAVAILABLE"` u `statusCode = 503`. Falliment fir-riżoluzzjoni DNS jiġi ttrattat bl-istess mod bħala fail-closed (l-egress jiġi rrifjutat).

Il-hosts li huma literals IP ma jeħtieġu l-ebda azzjoni fil-kontroll DNS preliminari — il-familja tagħhom hija intrinsika u ma teħtieġ ebda lookup.

## Mudell tad-Data

Il-kolonna `family` ġiet miżjuda mill-migrazzjoni `099_proxy_family.sql` ma’ **żewġ** tabelli:

```sql
-- src/lib/db/migrations/099_proxy_family.sql
ALTER TABLE proxy_registry ADD COLUMN family TEXT NOT NULL DEFAULT 'auto';
ALTER TABLE upstream_proxy_config ADD COLUMN family TEXT NOT NULL DEFAULT 'auto';
```

- `proxy_registry.family` — id-direttiva għal kull proxy għall-entrati fir-reġistru (`src/lib/db/proxies.ts`). Il-mistoqsijiet tar-riżoluzzjoni jagħżlu `family` flimkien mal-kolonni l-oħra tal-proxy, u valur nieqes jew li mhuwiex string jiġi kkonvertit għal `"auto"`.
- `upstream_proxy_config.family` — id-direttiva għall-entrati tal-proxy upstream (`src/lib/db/upstreamProxy.ts`), bl-istess valur predefinit `"auto"`.

Meta oġġett ta’ proxy riżolt ikollu `family` li mhuwiex `auto`, `proxyConfigToUrl` iżid il-markatur `?family=` sabiex l-issettjar fiss jibqa’ ppreservat sat-dispatcher.
