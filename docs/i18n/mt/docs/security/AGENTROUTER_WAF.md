Il-gateway upstream `agentrouter` iħaddem filtru tal-kontenut ibbażat fuq kliem ewlieni fuq
`messages[].content`. Il-filtru huwa parzjalment deterministiku (dejjem jimblokka
ċerti frażijiet) u parzjalment probabilistiku (sensittiv għal żieda f’daqqa fit-talbiet — isir
aktar aggressiv wara talbiet rapidi u jirkupra wara perjodu ta’ stennija).

Meta l-WAF jimblokka talba, jirritorna:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Ambitu tal-filtru

Il-WAF jispezzjona `messages[].content` biss. **Ma** jispezzjonax:

- Il-prompt `system`
- Blokok ta’ kontenut strutturat (`tool_result`, `tool_use`, `thinking`, `image`)
- L-oqsma `description` u `input_schema` tal-għodod
- Metadata tat-talba, headers, jew l-id tal-mudell

## Mudelli dejjem imblukkati (mingħajr distinzjoni bejn ittri kbar u żgħar)

| Mudell                              | Noti                                                  |
| ----------------------------------- | ----------------------------------------------------- |
| Kwalunkwe varjant ta’ `Lorem ipsum` | Il-vokabularju Latin lorem kollu huwa mblukkat        |
| `language model` (waħdu)            | "the language model" u "large language model" jgħaddu |
| `virtual assistant`                 | "AI assistant" jgħaddi                                |
| `I'm here to help`                  | "here to help" waħdu jiġi mblukkat ukoll              |
| `Claude, made by Anthropic`         | Il-frażi sħiħa biss                                   |

## Mudelli kważi dejjem imblukkati

| Mudell                                                  | Noti                                                    |
| ------------------------------------------------------- | ------------------------------------------------------- |
| `placeholder`                                           | Meta jidher waħdu (mhux bħala isem ta’ parametru, eċċ.) |
| `dummy data`                                            | Frażi inizjali komuni għall-fixtures                    |
| `foo bar baz`                                           | Frażi placeholder kanonika                              |
| Tokens qosra ripetuti (`AAA BBB CCC`, `test test test`) | Ditekter għall-mili żejjed bi kliem ewlieni             |

## Imġiba taħt tagħbija

Wara madwar 5 talbiet rapidi f’intervall qasir, il-WAF jibda jimblokka kontenut
li normalment jgħaddi. Il-bucket jirrilassa wara madwar 5–10 sekondi mingħajr
attività. Dan huwa l-istess rate limiter marbut mal-IP u maċ-ċavetta li jikkawża
żbalji intermittenti `400 content-blocked` meta Claude Code jew Codex CLI
jagħmel diversi sejħiet ta’ użu ta’ għodod / bgħit ta’ messaġġi wara xulxin malajr.

## Mitigazzjonijiet diġà applikati f’OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — protezzjoni kontra żidiet f’daqqa li tinforza
   intervall minimu ta’ 500 ms bejn talbiet outbound lejn kwalunkwe URL
   `agentrouter:*`. L-intervall huwa ferm taħt il-latenza li tista’ tinħass mill-bniedem u jipprevjeni
   lill-WAF milli jattiva fuq traffiku normali.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — meta upstream jirritorna
   `400 content-blocked`, l-eżekutur jerġa’ jipprova l-istess URL b’
   backoff esponenzjali (1.5 s, 3.0 s, massimu ta’ 2 tentattivi). Wara l-backoff,
   il-WAF normalment jirrilassa u t-tentattiv mill-ġdid jirnexxi.

3. **`tests/unit/compression/harness.test.ts`** — il-fixture tat-test
   `longInput` inbidel minn `"lorem ipsum dolor sit amet ".repeat(40)`
   għal `"example content for testing purposes ".repeat(40)` sabiex meta
   Claude Code jaqra dan il-fajl permezz tal-għodda `Read`, il-kontenut tal-fajl
   ma jerġax jgħaddi minn blokka `tool_result` u jattiva l-WAF.

## Gwida għall-prompts u għall-output tal-għodod

Jekk sessjoni ta’ Claude Code jew Codex CLI tiltaqa’ ripetutament ma’
`400 content-blocked`, iċċekkja l-aktar messaġġ reċenti tal-utent u l-aktar
riżultat reċenti ta’ għodda għal xi wieħed mill-mudelli ta’ hawn fuq u fformula mill-ġdid. Soluzzjonijiet
alternattivi komuni:

- Ibdel `Lorem ipsum …` b’`example text …` jew bil-kontenut reali
  li t-test jew il-fixture qed jipprova jirrappreżenta.
- Ibdel `placeholder` (meta jidher waħdu) b’`example value`,
  `sample value`, jew bil-valur reali.
- Ibdel `language model` b’`large language model` jew `the model`.
- Ibdel `dummy data` b’`sample data` jew b’valuri inizjali realistiċi.
- Ibdel `I'm here to help` / `here to help` b’introduzzjoni aktar speċifika
  (eż. "I'll review the file you mentioned").

## Rapportar tal-pożittivi foloz lill-upstream

Il-filtru attwali huwa aggressiv iżżejjed — jimblokka "Lorem ipsum" fi
blokok `tool_result` minkejja li l-operatur b’mod ċar ma kellux l-intenzjoni li
jinjetta prompt. Operaturi li jixtiequ li dan jiġi rranġat fis-sors għandhom
jikkuntattjaw lil `agentrouter.org` biex jirrapportaw il-pożittivi foloz. Il-blocklist
ta’ hawn fuq hija r-riżultat empiriku tal-ittestjar tal-upstream sad-data 2026-08-03.
