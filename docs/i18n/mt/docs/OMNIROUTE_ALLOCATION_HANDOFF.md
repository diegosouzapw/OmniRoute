L-allokazzjoni mhijiex il-kwota tal-fornitur.

Il-pools tal-kwota jiddefinixxu liema ċwievet tal-API jistgħu jużaw pool ta’ fornitur u kif japplikaw il-politiki stretti, flessibbli jew ta’ żieda temporanja. Il-kwota tal-fornitur hija kapaċità esterna rrappurtata minn fornitur jew minn sors ikkonfigurat b’mod espliċitu. Il-baġits interni ta’ Ghostlight huma limiti ta’ governanza ddefiniti mill-amministratur.

L-operazzjoni `ensurePool` hija idempotenti: pool identiku jibqa’ mhux mibdul, allokazzjoni mibdula tiġi aġġornata, u pool nieqes jinħoloq. Din hija maħsuba għall-awtomatizzazzjoni u għal klijenti tal-API b’limiti definiti.

L-endpoint tal-istatus għall-qari biss huwa `GET /api/omniroute/status`. Il-kmand ta’ verifika huwa `npm run omniroute:verify`; dan ma jagħmel l-ebda talba diretta lil mudell.
