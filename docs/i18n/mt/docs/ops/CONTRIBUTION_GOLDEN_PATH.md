Uża din il-gwida biex tagħżel l-iżgħar ċiklu ta’ żvilupp affidabbli għal pull request. Din ma
tissostitwixxix id-dokumenti tal-arkitettura u tas-sigurtà speċifiċi għall-qasam marbuta hawn taħt;
tgħaqqad kull tip komuni ta’ bidla mal-kuntratti, il-kontrolli ffukati, u l-kopertura tas-CI tiegħu.

## Il-perkors li ssegwi kull bidla

1. **Agħżel il-bażi qabel tibda teditja.** Sib l-ogħla branch attiv `release/v*` u oħloq branch mill-aħħar
   commit tiegħu. Immira lejn dak il-branch, mhux lejn `main`. Jekk ikun hemm waqfien temporanju attiv
   għal release, timmirax lejn il-branch iffriżat; uża ċ-ċiklu attiv li jmiss deskritt f’
   [Mudell tal-Branching u tar-Release](BRANCHING_MODEL.md).
2. **Semmi l-kuntratti.** Identifika kull katalgu, schema, artefatt iġġenerat, API pubblika, jew
   interfaċċa tal-utent li l-bidla taffettwa. It-tabella ta’ hawn taħt tagħti s-sett minimu inizjali.
3. **Ikteb jew aġġorna testijiet iffukati.** Bidliet tal-produzzjoni f’`src/`, `open-sse/`, `electron/`, jew
   `bin/` jeħtieġu test awtomatizzat fl-istess PR. Ħaddem l-iżgħar fajls tat-test li jipprovaw
   l-imġiba, imbagħad il-kontrolli ffukati elenkati.
4. **Ħalli s-CI tħaddem il-matriċi wiesgħa.** Is-segmenti sħaħ tat-testijiet unitarji, Vitest, il-limitu
   progressiv tal-kopertura, u l-build tal-produzzjoni jitħaddmu fuq il-PR. Ħaddem sett wiesa’ ta’
   testijiet lokalment biss meta falliment iffukat jindika impatt usa’ jew meta l-bidla tkopri diversi sottosistemi.
5. **Irrikonċilja qabel ir-rieżami.** Iġbed il-bażi attiva, eżamina l-commits il-ġodda tagħha u d-diff
   tiegħek magħha, imbagħad agħmel rebase jew merge tal-bażi skont il-fluss tax-xogħol tal-kontributuri.
   Issolvi l-kunflitti fil-fajls iġġenerati u fil-katalgi mis-sors tagħhom, iġġenerahom mill-ġdid,
   erġa’ ħaddem iċ-ċiklu ffukat, u kkonferma li l-PR għadu jimmira lejn il-branch attiv tar-release.
6. **Irreġistra l-evidenza.** Fit-template tal-PR, elenka l-kmandi mħaddma, kull fajl tat-test miżjud jew
   mibdul, il-migrazzjonijiet jew il-feature flags, u kwalunkwe validazzjoni li ssir biss fis-CI u li għadha pendenti.

## Perkorsi ewlenin skont it-tip ta’ bidla

Il-kmandi ta’ hawn taħt huma kontrolli ffukati minimi, mhux permess biex taqbeż test li jkopri
direttament l-imġiba li bdilt.

### Fornitur

**Kuntratti**

- Id-definizzjoni tal-fornitur f’`src/shared/constants/providers/` u l-kompożizzjoni tagħha f’
  `src/shared/constants/providers.ts`.
- Mudelli u kapaċitajiet f’`open-sse/config/providerRegistry.ts` jew fil-fajls estratti tar-reġistru tiegħu.
- L-għażla tal-eżekutur/traduttur, il-konfigurazzjoni ta’ OAuth jew taċ-ċavetta tal-API, l-assi tad-dashboard,
  u r-referenza ġġenerata tal-fornitur fejn applikabbli.
- Il-kredenzjali pubbliċi jridu jużaw `resolvePublicCred()`; it-tweġibiet ta’ żball iridu jużaw l-għodod
  awżiljarji kondiviżi għas-sanitizzazzjoni tal-iżbalji. Ara `docs/security/PUBLIC_CREDS.md` (git; mhux
  ikkompilat f’`/docs`) u
  [Sanitizzazzjoni tal-Iżbalji](../security/ERROR_SANITIZATION.md).

**Ċiklu ffukat**

```bash
npm run check:provider-consistency
npm run check:provider-assets
node --import tsx/esm --test tests/unit/provider-translate-path-golden.test.ts
node --import tsx/esm --test tests/unit/<provider-or-executor>.test.ts
npm run gen:provider-reference   # meta jinbidel il-katalgu; ikkommetti d-diff iġġenerat
npm run lint
```

Ittestja wkoll kull familja ta’ requests affettwata: chat, Responses, stampi, embeddings, awdjo, jew vidjo.
Irrevedi d-diffs tal-katalgu ġġenerat u tad-dejta golden bħala bidliet fil-kuntratti; taċċettahomx bla eżami.

### Routing

**Kuntratti**

- Il-valuri pubbliċi tal-istrateġija u l-metadata tal-UI f’`src/shared/constants/routingStrategies.ts`.
- Id-dispaċċ u l-ordni taħt `open-sse/services/combo.ts` u `open-sse/services/combo/`.
- L-iskemi tal-combo, il-persistenza, l-istat tar-reżiljenza, il-kapaċitajiet tal-mudelli, u l-kontrolli
  tal-API/UI.
- [Magna Auto-Combo](../routing/AUTO-COMBO.md) u d-dokumentazzjoni tar-reżiljenza meta tinbidel l-imġiba.

**Ċiklu ffukat**

```bash
node --import tsx/esm --test tests/unit/combo-<behavior>.test.ts
npm run test:combo:matrix        # bidliet fl-istrateġija jew fid-dispaċċ
npm run check:known-symbols      # bidliet fir-reġistrazzjoni tal-istrateġija
npm run lint
```

Uża lokalment testijiet deterministiċi b’upstream simulat. It-testijiet smoke live tal-combo jeħtieġu
kredenzjali u jsiru manwalment; mhumiex sostituti għas-CI.

### UI / UX

**Kuntratti**

- Ir-route/page ta’ Next.js u l-konfini tal-komponenti kondiviżi taħt `src/app/` u
  `src/shared/components/`.
- Il-forom tat-tweġibiet tal-API, l-istati ta’ tagħbija/vojta/żball, l-imġiba tat-tastiera u tal-screen reader,
  il-layout adattiv, it-temi, u l-espansjoni tal-locales.
- Is-strings sors tal-UI bl-Ingliż f’`src/i18n/messages/en.json`; tiktibx kopja ġdida għall-utent direttament
  fil-kodiċi.

**Ċiklu ffukat**

```bash
node --import tsx --test tests/unit/dashboard/<feature>.test.ts
npx vitest run --config vitest.config.ts tests/unit/ui/<component>.test.tsx
npm run check:dashboard-typecheck
npm run lint
```

Ħaddem l-applikazzjoni għal bidliet fl-interazzjoni jew viżivi u ċċekkja kemm viewports dojoq kif ukoll
wesgħin. Is-CI tħaddem il-build tal-produzzjoni u settijiet usa’ ta’ testijiet; l-imġiba viżiva xorta teħtieġ
komponent iffukat, Playwright, jew kontroll manwali dokumentat xieraq għall-bidla.

### i18n

**Kuntratti**

- `src/i18n/messages/en.json` huwa s-sors tal-UI; `config/i18n.json` huwa s-sors tal-locales.
- Il-katalgi tas-CLI jinsabu separatament taħt `bin/cli/locales/`.
- Żomm il-placeholders u t-tags ta’ ICU eżattament kif inhuma. Tittraduċix ismijiet ta’
  prodotti/fornituri/mudelli, ismijiet ta’ protokolli u headers, kmandi, identifikaturi tal-kodiċi/JSON,
  URLs, varjabbli tal-ambjent, jew termini protetti bħal `OmniRoute`, `OAuth`, `MCP`, u `A2A`.
  Il-lista sors attwali hija `scripts/i18n/glossary/protected-terms.json`.

**Ċiklu ffukat**

```bash
npm run i18n:sync-ui:dry
npm run i18n:check-ui-coverage
npm run i18n:check-value-drift
npm run i18n:check-glossary
npm run check:cli-i18n          # meta jinbidlu l-strings/katalgi tas-CLI
npm run lint
```

Din hija gwida għas-sistema eżistenti, mhux stedina biex tespandi l-għodod jew il-mudell taċ-ċwievet tagħha.
Żomm il-patches tal-i18n preċiżi u limitati waqt li tkun qed tiġi ddisinjata s-sistema sostituttiva.
Tħaddimx kmandi tat-traduzzjoni li jsejħu servizzi esterni sakemm il-kompitu ma jkunx jeħtieġ
espliċitament traduzzjonijiet iġġenerati u tkun irrevedejt id-diff riżultanti.

### CLI

**Kuntratti**

- Kmandi u flags pubbliċi f’`bin/cli/`, kmandi API ġġenerati, kodiċijiet tal-ħruġ, stdout/stderr u

- Is-strings tas-CLI li jidhru lill-utent iridu jużaw is-saff i18n tas-CLI u jżommu l-katalgi `en`/`pt-BR` allinjati.


Uża l-kmand eżatt f’direttorju temporanju tad-data meta l-imġiba tiddependi mill-parsing, mill-fajls, jew
mill-istatus tal-ħruġ. Is-CI jwettaq il-kontrolli usa’ tal-artefatti tal-pakkett u tal-ekosistema.

### Bażi tad-data

**Kuntratti**

- Moduli tad-dominju taħt `src/lib/db/`; importa direttament moduli speċifiċi (is-saff l-antik ta’ esportazzjoni mill-ġdid `localDb.ts` tneħħa).
- Migrazzjonijiet SQL innumerati u idempotenti taħt `src/lib/db/migrations/`, sikurezza tat-tranżazzjonijiet, imġiba
  tal-aġġornament, indiċijiet, u kull min isejjaħhom li hu affettwat mill-iskema.
- Ir-routes u l-handlers qatt ma joħorġu SQL mhux ipproċessat direttament.

**Ċiklu ffukat**


Meta żżid migrazzjoni, ittestja kemm bażi tad-data ġdida kif ukoll aġġornament mill-iskema preċedenti. It-testijiet tal-bażi tad-data
jridu jagħlqu l-handles u jsejħu `resetDbInstance()` waqt it-tindif. Ħaddem `npm run test:bun:db` biss meta
tinbidel il-mogħdija tal-adapter Bun li taħdem fuq bażi tal-aħjar sforz; Node jibqa’ l-awtorità.

### Build / skjerament

**Kuntratti**

- Manifests/lockfile tar-root u tal-workspace, `scripts/build/`, l-assemblaġġ standalone ta’ Next.js, il-kontenut tal-pakkett
  `dist/`, metadata tal-pjattaforma Electron, workflows tas-CI, u sentinelli tal-iskjerament.
- Il-firxiet appoġġjati ta’ Node u l-użu ta’ Bun fil-lista permessa f’`CLAUDE.md` iridu jibqgħu intatti.
- L-artefatti tal-build jibqgħu mhux tracked; japplikaw il-politiki tad-dipendenzi, tal-liċenzji, tal-workflows, u tal-pakketti.

**Ċiklu ffukat**

```bash
node --import tsx/esm --test tests/unit/build/<behavior>.test.ts
npm run check:build-scope
npm run check:lockfile         # bidliet fid-dipendenzi jew fil-lockfile
npm run check:pack-policy      # bidliet fis-superfiċje tal-pakkett ippubblikat
npm run lint
```

Uża `npm run build` lokalment biss meta l-bidla taffettwa l-kompilazzjoni, l-assemblaġġ standalone, l-assets,
jew il-ġbir tar-runtime f’bundle. Uża `npm run build:release` biss għall-validazzjoni tar-rilaxx/tal-iskjerament. Il-build tas-CI huwa
s-sinjal finali bejn il-pjattaformi; bidliet ta’ Electron speċifiċi għal pjattaforma jeħtieġu l-build iffukat korrispondenti
jew evidenza minn smoke test.

## Ċiklu lokali tal-kandidat

It-testijiet tas-sors ma jistgħux jagħtu prova li l-artefatt ippakkjat jibda: il-listi tal-ippakkjar, id-dipendenzi mnaqqsa,
u l-binarji nattivi jfallu biss ladarba t-tarball jiġi installat u jinbeda. `npm run dev:candidate`
(`scripts/dev/candidate.mjs`) huwa n-naħa lokali tal-fluss ibni-darba / ivvalida / ippromwovi minn
RFC #8084: jibni kandidat wieħed, jivvalida eżattament dak l-artefatt, jippromwovih billi jibdel
l-ismijiet tad-direttorji, u jreġġgħu lura meta l-islott promoss ifalli l-kontroll tal-istat tiegħu.

```bash
npm run dev:candidate -- run --dry-run --json  # uri l-pjan, tibdel xejn
npm run dev:candidate -- run                   # ibni + ivvalida + ippromwovi, treġġigħ lura awtomatiku
npm run dev:candidate -- build                 # npm pack + installa f'_artifacts/candidate/<id>/
npm run dev:candidate -- validate --id <id>    # ibda fuq port liberu, /api/health + /v1/models
npm run dev:candidate -- promote --id <id>     # <id> → current, current → previous
npm run dev:candidate -- rollback              # skambja current u previous
npm run dev:candidate -- run --from-tarball <file.tgz>  # erġa' uża tarball mibni band'oħra (CI)
```

- **Ibni darba.** `build` jippakkja s-siġra attwali (jeħtieġ `dist/server.js`, għalhekk l-ewwel ħaddem
  `npm run build:release`) jew jikkopja `--from-tarball`, imbagħad jinstalla t-tarball fi prefiss npm
  iżolat, għax it-tarball ma jinkludix `node_modules`. L-id huwa x-sha qasir ta' `HEAD`
  (`-dirty` meta s-siġra jkollha bidliet lokali) jew `tgz-<sha256>` għal tarball. Id nadif li jkun
  diġà nbena jerġa' jintuża minflok jinbena mill-ġdid; għaddi `--force` biex terġa' tibnih.
- **Ivvalida l-pakkett, mhux is-sors.** `validate` jibda s-CLI installat
  (`serve --port <free port>`) b'`DATA_DIR=<candidate>/data` ġdid, sigrieti foloz, u
  `OMNIROUTE_API_KEY`, `STORAGE_ENCRYPTION_KEY` u `INITIAL_PASSWORD` tal-operatur imneħħija
  mill-ambjent, sabiex jiċċekkja l-konfigurazzjoni loopback mingħajr ċavetta ta' installazzjoni ġdida.
  Jistenna li `GET /api/health` jirritorna 200, jeħtieġ li `GET /v1/models` jirritorna 200, iwaqqaf
  il-grupp tal-proċessi, u jirreġistra r-riżultat f'`validation.json` flimkien mal-hash tat-tarball.
- **Ippromwovi l-istess artefatt.** `promote` jirrifjuta kandidat mingħajr validazzjoni li għaddiet
  għall-hash attwali tat-tarball tiegħu. L-islott attiv predefinit huwa
  `_artifacts/candidate/current`; `--target <dir>` jagħżel direttorju ieħor fuq l-istess sistema
  tal-fajls, u l-islott preċedenti tiegħu jkun `<dir>.previous`. Kull tibdil ta' isem huwa atomiku,
  u falliment f'nofs il-proċess ireġġa' lura t-tibdiliet fl-ismijiet li jkunu diġà saru.
- **Erġa' lura.** `run` jerġa' jivvalida l-islott promoss u jiskambja `current` u `previous` lura
  meta dak il-kontroll ifalli. Kandidat li jfalli l-ewwel validazzjoni qatt ma jiġi promoss.

Kollox jinkiteb taħt `_artifacts/candidate/`, li huwa injorat minn git; installazzjoni eżistenti ta'
OmniRoute u d-direttorju tad-data tagħha qatt ma jintmessu. Is-CLI promoss huwa
`_artifacts/candidate/current/prefix/bin/omniroute`; ibdieh bid-`DATA_DIR` tiegħek meta tużah.
Kodiċijiet tal-ħruġ: `0` suċċess, `1` validazzjoni jew promozzjoni falluta, `2` żball fl-użu jew
build nieqes.

| Testijiet diretti tal-imġiba u l-kontrolli tal-kategoriji ta’ hawn fuq                        | Sett sħiħ ta’ unit tests maqsum f’partijiet u testijiet sekwenzjali                         |
| `npm run lint`                                                                                | Settijiet ta’ testijiet Vitest u mekkaniżmi progressivi għall-kopertura/kwalità             |
| Iċċekkja t-tipi jew ibni biss meta l-kuntratt affettwat ikun jeħtieġ dan                      | Build tal-produzzjoni, kontrolli tas-sigurtà, dokumentazzjoni, dipendenzi u politika tal-PR |
| Interazzjoni manwali/verifiki live biss meta l-awtomazzjoni ma tkunx tista’ tipprova l-imġiba | Integrazzjoni bejn jobs u verifiki tal-pjattaforma kkonfigurati mill-workflow               |

Ċiklu ffukat li jirnexxi huwa evidenza dwar il-kuntratt mibdul, mhux prova li l-verifiki mhux relatati ta’ CI
se jgħaddu. Min-naħa l-oħra, iġġiegħelx kull bidla lokali tistenna l-matriċi sħiħa tar-repożitorju.

## Lista ta’ verifika għar-rikonċiljazzjoni

Qabel titlob rieżami:

- Ikkonferma li l-bażi tal-PR għadha l-ogħla branch attiva `release/v*`.
- Ġib dik il-bażi u rrivedi l-commits li ġew integrati minn meta ħloqt il-branch tiegħek.
- Irrivedi `git diff <active-base>...HEAD` għal tibdil aċċidentali jew iġġenerat.
- Solvi l-kunflitti fil-katalgu u fid-dokumenti ġġenerati billi taġġorna s-sors u terġa’ tiġġenera l-output.
- Erġa’ ħaddem kull test/kontroll iffukat elenkat fid-deskrizzjoni tal-PR wara r-rikonċiljazzjoni.
- Qatt iddgħajjef l-asserzjonijiet jew tneħħi testijiet meħtieġa sempliċement biex tqabbel bażi li nbidlet.
