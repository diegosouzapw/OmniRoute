Uża din il-gwida biex tagħżel l-iżgħar ċiklu ta’ żvilupp affidabbli għal pull request. Din ma
tissostitwixxix id-dokumenti tal-arkitettura u tas-sigurtà speċifiċi għaż-żona marbuta hawn taħt; hija tgħaqqad kull tip
komuni ta’ bidla mal-kuntratti, il-verifiki ffukati, u l-kopertura tas-CI tiegħu.

## It-triq li ssegwi kull bidla

1. **Agħżel il-bażi qabel tibda teditja.** Sib l-ogħla branch attiv `release/v*` u oħloq branch mill-aħħar
   commit tiegħu. Immira lejn dak il-branch, mhux lejn `main`. Jekk hemm iffriżar tar-rilaxx attiv, timmirax lejn il-branch
   iffriżat; uża ċ-ċiklu attiv li jmiss deskritt f’
   [Mudell tal-Branches u tar-Rilaxxi](BRANCHING_MODEL.md).
2. **Semmi l-kuntratti.** Identifika kull katalgu, schema, artefatt iġġenerat, API pubblika, jew interfaċċa
   tal-utent li l-bidla taffettwa. It-tabella ta’ hawn taħt tagħti s-sett minimu inizjali.
3. **Ikteb jew aġġorna testijiet iffukati.** Bidliet fil-produzzjoni f’`src/`, `open-sse/`, `electron/`, jew
   `bin/` jeħtieġu test awtomatizzat fl-istess PR. Ħaddem l-iżgħar fajls tat-test li jagħtu prova tal-
   imġiba, imbagħad il-verifiki ffukati elenkati.
4. **Ħalli lis-CI tħaddem il-matriċi wiesgħa.** Ix-shards sħaħ tal-unit tests, Vitest, il-livell progressiv tal-kopertura, u
   l-build tal-produzzjoni jitħaddmu fuq il-PR. Ħaddem suite wiesgħa lokalment biss meta falliment iffukat jindika
   impatt usa’ jew meta l-bidla tinvolvi diversi sottosistemi.
5. **Irrikonċilja qabel ir-rieżami.** Iġbed il-bażi attiva, spezzjona l-commits il-ġodda tagħha u d-diff tiegħek meta mqabbel
   magħha, imbagħad agħmel rebase jew merge tal-bażi skont il-fluss tax-xogħol tal-kontributuri. Solvi l-kunflitti tal-fajls
   iġġenerati u tal-katalgi mis-sors tagħhom, iġġenerahom mill-ġdid, erġa’ ħaddem iċ-ċiklu ffukat, u kkonferma li l-
   PR għadu jimmira lejn il-branch attiv tar-rilaxx.
6. **Irreġistra l-evidenza.** Fil-mudell tal-PR, elenka l-kmandi mħaddma, kull fajl tat-test miżjud jew mibdul,
   il-migrazzjonijiet jew il-feature flags, u kwalunkwe validazzjoni li ssir biss mis-CI u li għadha pendenti.

## Rotot rakkomandati skont it-tip ta’ bidla

Il-kmandi ta’ hawn taħt huma l-verifiki ffukati minimi, mhux permess biex taqbeż test li jkopri direttament l-
imġiba li bdilt.

### Fornitur

**Kuntratti**

- Id-definizzjoni tal-fornitur f’`src/shared/constants/providers/` u l-kompożizzjoni tagħha f’
  `src/shared/constants/providers.ts`.
- Il-mudelli u l-kapaċitajiet f’`open-sse/config/providerRegistry.ts` jew fil-fajls tar-reġistru estratti tiegħu.
- L-għażla tal-eżekutur/traduttur, il-konfigurazzjoni ta’ OAuth jew tal-API key, l-assi tad-dashboard, u r-referenza
  ġġenerata tal-fornitur fejn applikabbli.
- Il-kredenzjali pubbliċi għandhom jużaw `resolvePublicCred()`; it-tweġibiet ta’ żball għandhom jużaw l-għodod kondiviżi
  għat-tindif tal-iżbalji. Ara `docs/security/PUBLIC_CREDS.md` (git; mhux ikkompilat f’`/docs`) u
  [Tindif tal-Iżbalji](../security/ERROR_SANITIZATION.md).

**Ċiklu ffukat**

```bash
npm run check:provider-consistency
npm run check:provider-assets
node --import tsx/esm --test tests/unit/provider-translate-path-golden.test.ts
node --import tsx/esm --test tests/unit/<provider-or-executor>.test.ts
npm run gen:provider-reference   # meta jinbidel il-katalgu; ikkommetti d-diff iġġenerat
npm run lint
```

Ittestja wkoll kull familja ta’ talbiet affettwata: chat, Responses, immaġnijiet, embeddings, awdjo, jew vidjo.
Irrevedi d-diffs tal-katalgu ġġenerat u dawk golden bħala bidliet fil-kuntratt; taċċettahomx bl-għama.

### Routing

**Kuntratti**

- Il-valuri pubbliċi tal-istrateġiji u l-metadata tal-UI f’`src/shared/constants/routingStrategies.ts`.
- Id-dispaċċ u l-ordni taħt `open-sse/services/combo.ts` u `open-sse/services/combo/`.
- L-iskemi tal-combo, il-persistenza, l-istat tar-reżiljenza, il-kapaċitajiet tal-mudell, u l-kontrolli tal-API/UI.
- [Magna Auto-Combo](../routing/AUTO-COMBO.md) u d-dokumentazzjoni tar-reżiljenza meta tinbidel l-imġiba.

**Ċiklu ffukat**

```bash
node --import tsx/esm --test tests/unit/combo-<behavior>.test.ts
npm run test:combo:matrix        # bidliet fl-istrateġija jew fid-dispaċċ
npm run check:known-symbols      # bidliet fir-reġistrazzjoni tal-istrateġija
npm run lint
```

Uża lokalment testijiet deterministiċi b’upstream simulat. It-testijiet smoke live tal-combo jeħtieġu kredenzjali u huma
manwali, mhux sostituti tas-CI.

### UI / UX

**Kuntratti**

- Ir-route/page ta’ Next.js u l-konfini tal-komponenti kondiviżi taħt `src/app/` u
  `src/shared/components/`.
- Il-forom tat-tweġibiet tal-API, l-istati ta’ tagħbija/vojta/żball, l-imġiba tat-tastiera u tal-screen reader,
  it-tqassim responsiv, it-temi, u l-espansjoni tal-lokalizzazzjoni.
- Is-strings sors tal-UI bl-Ingliż f’`src/i18n/messages/en.json`; tiktibx direttament kopja ġdida li tidher lill-utent.

**Ċiklu ffukat**

```bash
node --import tsx --test tests/unit/dashboard/<feature>.test.ts
npx vitest run --config vitest.config.ts tests/unit/ui/<component>.test.tsx
npm run check:dashboard-typecheck
npm run lint
```

Ħaddem l-app għal bidliet fl-interazzjoni jew viżivi u ċċekkja kemm viewports dojoq kif ukoll wesgħin. Is-CI tħaddem il-
build tal-produzzjoni u suites usa’; l-imġiba viżiva xorta teħtieġ komponent iffukat, Playwright,
jew verifika manwali dokumentata xierqa għall-bidla.

### i18n

**Kuntratti**

- `src/i18n/messages/en.json` huwa s-sors tal-UI; `config/i18n.json` huwa s-sors tal-lokalizzazzjonijiet.
- Il-katalgi tas-CLI jinsabu separatament taħt `bin/cli/locales/`.
- Ippreserva l-placeholders u t-tags tal-ICU eżattament. Tittraduċix ismijiet ta’ prodotti/fornituri/mudelli,
  ismijiet ta’ protokolli u headers, kmandi, identifikaturi tal-code/JSON, URLs, varjabbli tal-ambjent, jew
  termini protetti bħal `OmniRoute`, `OAuth`, `MCP`, u `A2A`. Il-lista sors attwali hija
  `scripts/i18n/glossary/protected-terms.json`.

**Ċiklu ffukat**

```bash
npm run i18n:sync-ui:dry
npm run i18n:check-ui-coverage
npm run i18n:check-value-drift
npm run i18n:check-glossary
npm run check:cli-i18n          # meta jinbidlu l-strings/il-katalgi tas-CLI
npm run lint
```

Din hija gwida għas-sistema eżistenti, mhux stedina biex tespandi l-għodod jew il-mudell tal-keys tagħha.
Żomm il-patches tal-i18n immirati waqt li tkun qed titfassal is-sistema ta’ sostituzzjoni. Tħaddimx kmandi tat-traduzzjoni
li jsejħu servizzi esterni sakemm il-kompitu ma jkunx jeħtieġ espliċitament traduzzjonijiet iġġenerati u
tkun irrevedejt id-diff li jirriżulta.

### CLI

**Kuntratti**

- Kmandi u flags pubbliċi f’`bin/cli/`, kmandi tal-API ġġenerati, kodiċijiet tal-ħruġ, stdout/stderr u
  l-forom tal-output JSON, l-imġiba tal-konfigurazzjoni/ambjent, u l-fajls inklużi fil-pakkett.
- Is-strings tas-CLI li jintwerew lill-utent iridu jużaw is-saff i18n tas-CLI u jżommu l-katalgi `en`/`pt-BR` allinjati.
- Żomm Node bħala r-runtime appoġġjat u ppreserva l-kuntratt tal-binary ippubblikat.

**Ċiklu ffukat**

```bash
node --import tsx/esm --test tests/unit/cli/<command>.test.ts
npm run check:cli-i18n
npm run build:cli             # bidliet fis-CLI ġġenerata/miġbura f'bundle
npm run check:pack-policy     # bidliet fis-superfiċje tal-pakkett
npm run lint
```

Uża l-kmand eżatt f’direttorju temporanju tad-data meta l-imġiba tiddependi mill-parsing, mill-fajls, jew mill-istatus
tal-ħruġ. Is-CI jwettaq il-verifiki usa’ tal-artefatt tal-pakkett u tal-ekosistema.

### Database

**Kuntratti**

- Moduli tad-dominju taħt `src/lib/db/`; importa moduli speċifiċi direttament (is-saff l-antik ta’ esportazzjoni mill-ġdid `localDb.ts` tneħħa).
- Migrazzjonijiet SQL innumerati u idempotenti taħt `src/lib/db/migrations/`, is-sikurezza tat-tranżazzjonijiet, l-imġiba
  tal-aġġornament, l-indiċijiet, u kull min isejħilhom u huwa affettwat mill-iskema.
- Ir-routes u l-handlers qatt ma joħorġu SQL mhux ipproċessat direttament.

**Ċiklu ffukat**

```bash
npm run check:migration-numbering
npm run check:db-rules
node --import tsx/esm --test tests/unit/db/<domain>.test.ts
node --import tsx/esm --test tests/unit/db/migration-<number>.test.ts
npm run lint
```

Meta żżid migrazzjoni, ittestja kemm database ġdida kif ukoll aġġornament mill-iskema preċedenti. It-testijiet tad-database
iridu jagħlqu l-handles u jsejħu `resetDbInstance()` waqt it-tindif. Ħaddem `npm run test:bun:db` biss meta
tinbidel il-mogħdija tal-adapter Bun li taħdem fuq bażi tal-aħjar sforz; Node jibqa’ awtorevoli.

### Bini / skjerament

**Kuntratti**

- Manifests/lockfile tal-għerq u tal-workspace, `scripts/build/`, l-assemblaġġ standalone ta’ Next.js, il-kontenut tal-pakkett
  `dist/`, il-metadata tal-pjattaforma Electron, il-workflows tas-CI, u s-sentinelli tal-iskjerament.
- Il-firxiet appoġġjati ta’ Node u l-użu ta’ Bun fil-lista ta’ permessi f’`CLAUDE.md` iridu jibqgħu intatti.
- L-artefatti tal-bini jibqgħu mhux traċċati; japplikaw il-politiki tad-dipendenzi, tal-liċenzji, tal-workflows, u tal-pakketti.

**Ċiklu ffukat**

```bash
node --import tsx/esm --test tests/unit/build/<behavior>.test.ts
npm run check:build-scope
npm run check:lockfile         # bidliet fid-dipendenzi jew fil-lockfile
npm run check:pack-policy      # bidliet fis-superfiċje tal-pakkett ippubblikat
npm run lint
```

Uża `npm run build` lokalment biss meta l-bidla taffettwa l-kompilazzjoni, l-assemblaġġ standalone, l-assets,
jew il-bundling tar-runtime. Uża `npm run build:release` biss għall-validazzjoni tar-rilaxx/skjerament. Il-bini tas-CI huwa
s-sinjal finali bejn il-pjattaformi; bidliet ta’ Electron speċifiċi għal pjattaforma jeħtieġu l-bini ffukat korrispondenti
jew evidenza minn smoke test.

## Ċiklu lokali kontra CI

| Ħaddem lokalment għal kull patch                                                            | CI jipprovdi s-sinjal wiesa’                                                                 |
| ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Testijiet diretti tal-imġiba u l-kontrolli tal-kategoriji ta’ hawn fuq                      | Sett sħiħ maqsum ta’ testijiet tal-unità u testijiet sekwenzjali                             |
| `npm run lint`                                                                              | Settijiet ta’ testijiet Vitest u limiti progressivi ta’ kopertura/kwalità                    |
| Iċċekkja t-tipi jew ibni biss meta l-kuntratt affettwat ikun jeħtieġ dan                    | Build tal-produzzjoni, sigurtà, dokumentazzjoni, dipendenzi, u kontrolli tal-politika tal-PR |
| Interazzjoni manwali/kontrolli diretti biss meta l-awtomazzjoni ma tistax tipprova l-imġiba | Kontrolli tal-integrazzjoni bejn jobs u tal-pjattaforma kkonfigurati mill-workflow           |

Ċiklu ffukat li jgħaddi b’suċċess huwa evidenza dwar il-kuntratt mibdul, mhux prova li l-kontrolli mhux relatati tas-CI
se jgħaddu. Min-naħa l-oħra, iġġiegħelx kull bidla lokali tistenna l-matriċi sħiħa tar-repożitorju.

## Lista ta’ kontroll għar-rikonċiljazzjoni

Qabel titlob rieżami:

- Ikkonferma li l-bażi tal-PR għadha l-ogħla branch attiva `release/v*`.
- Ġib dik il-bażi u rrivedi l-commits li daħlu minn meta ħloqt il-branch tiegħek.
- Irrevedi `git diff <active-base>...HEAD` għal bidliet aċċidentali jew iġġenerati.
- Solvi l-kunflitti fil-katalgu u fid-dokumenti ġġenerati billi taġġorna s-sors u terġa’ tiġġenera l-output.
- Erġa’ ħaddem kull test/kontroll iffukat elenkat fid-deskrizzjoni tal-PR wara r-rikonċiljazzjoni.
- Qatt iddgħajjef l-asserzjonijiet jew tneħħi testijiet meħtieġa sempliċement biex taqbel ma’ bażi li nbidlet.

Għar-regoli dwar l-iffriżar tar-rilaxx u l-immirar mill-ġdid, uża
[Il-Mudell tal-Branching u tar-Rilaxx](BRANCHING_MODEL.md). Għall-inventarju sħiħ tas-CI, uża
[Referenza tal-Kontrolli tal-Kwalità](../architecture/QUALITY_GATES.md).
