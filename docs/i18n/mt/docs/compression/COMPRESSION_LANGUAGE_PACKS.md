Il-kompressjoni Caveman tista’ ttella’ pakketti ta’ regoli speċifiċi għal-lingwa flimkien mar-regoli integrati tal-Ingliż.
Dan iżomm il-magna ewlenija stabbli filwaqt li jippermetti lill-pakketti tal-Portugiż, l-Ispanjol, il-Ġermaniż, il-Franċiż, it-Taljan, il-Ġappuniż, u
lill-pakketti futuri tal-lingwi jevolvu b’mod indipendenti.

## Post

Il-pakketti tal-lingwi jinsabu taħt:

```txt
open-sse/services/compression/rules/<language>/
```

Il-pakketti attwalment inklużi (ivverifikati mal-kontenut tad-direttorju `rules/`):

| Lingwa            | Direttorju     | Kategoriji ta’ regoli preżenti                      |
| ----------------- | -------------- | --------------------------------------------------- |
| Ingliż            | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spanjol           | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugiż (Brażil) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indoneżjan        | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Taljan            | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Ġermaniż          | `rules/de/`    | `context`, `filler`, `structural`                   |
| Franċiż           | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Ġappuniż          | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Nota dwar il-parità:** Il-pakketti `en`, `es`, `pt-BR`, `id`, u `it` għandhom il-5 kategoriji kollha; `de`, `fr`, u `ja` jiġu bi 3 kategoriji. Il-kategoriji neqsin `dedup` u `ultra` jaqgħu lura awtomatikament għar-regoli integrati tal-Ingliż mingħajr ebda avviż. Il-kontribuzzjonijiet biex jiżdiedu `dedup.json` u `ultra.json` mal-pakketti iżgħar huma milqugħa.
>
> Il-pakkett `pt-BR` huwa bbażat fuq **[Troglodita](https://github.com/leninejunior/troglodita)** ta’ Lenine Júnior — sistema ta’ kompressjoni mfassla mill-bidu għall-grammatika tal-Portugiż Brażiljan (tnaqqis tal-pleonażmi, tneħħija ta’ kliem żejjed tal-PT-BR, abbrevjazzjonijiet tekniċi għall-komunità tal-iżviluppaturi Brażiljani).
>
> Il-lista kanonika tal-kategoriji u l-iskema għal kull kategorija jinsabu f’[`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema abbozz 2020-12).

## Sejbien tal-Lingwa

`languageDetector.ts` juża euristiċi ħfief biex jiddeduċi l-lingwa mit-test tal-prompt. Il-lingwa
predefinita kkonfigurata xorta tiġi rispettata, u s-sejbien jista’ jiġi diżattivat permezz tal-konfigurazzjoni meta jkun meħtieġ
kontroll preċiż.

L-output tas-sejbien jintuża biss biex jintgħażlu l-pakketti tar-regoli. Ma jbiddilx ir-routing tal-fornitur, l-għażla
tal-locale, jew il-lingwa tal-interfaċċa tal-utent.

## Struttura tal-Konfigurazzjoni

Is-settings tal-kompressjoni jistgħu jinkludu:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` jikkontrolla l-valuri predefiniti tad-dashboard/tal-preview. `cavemanConfig` hija l-konfigurazzjoni tal-magna waqt l-eżekuzzjoni
użata meta Caveman jikkompressa t-test tal-messaġġ.

## Żieda ta' Pakkett tal-Lingwa

1. Oħloq `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Uża l-format tar-regoli Caveman minn `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Żomm is-sostituzzjonijiet konservattivi u evita li tibdel kodiċi, identifikaturi, URLs, jew JSON.
4. Żid jew aġġorna t-testijiet għall-għażla tal-lingwa u għall-imġiba tas-sostituzzjoni.
5. Esponi tikketti ġodda tad-dashboard/i18n jekk il-lingwa tidher fis-seletturi tal-UI.

## API

Il-pakketti disponibbli jistgħu jiġu mistoqsija permezz ta':

```bash
curl http://localhost:20128/api/compression/language-packs
```

L-endpoint tal-previżjoni jaċċetta konfigurazzjonijiet tal-lingwa li jegħlbu dawk eżistenti:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Is-6 pakketti tal-lingwa kollha rċevew klawżola `SHARED_BOUNDARIES` f'v3.8.0 li tiġi applikata f'kull
intensità Caveman (LITE, FULL, ULTRA). Din tagħti struzzjonijiet lill-magna biex tippreserva dawn il-mudelli eżattament,
irrispettivament mit-tneħħija ta' kliem żejjed madwarhom:

| Tip ta' mudell                         | Eżempju                                |
| -------------------------------------- | -------------------------------------- |
| Blokki tal-kodiċi magħluqa             | ` ```python\n...\n``` `                |
| Kodiċi inline                          | `` `my_var` ``                         |
| URLs                                   | `https://example.com/path`             |
| Paths tal-fajls (assoluti + relattivi) | `/etc/hosts`, `./src/index.ts`         |
| Headers tal-iżbalji                    | `Error:`, `TypeError:`, `SyntaxError:` |
| Linji ta' stack trace                  | `  at functionName (file.ts:12:3)`     |

Dawn il-mudelli jiddaħħlu f'`DEFAULT_CAVEMAN_CONFIG.preservePatterns` (qabel kienet `[]`). Il-
kostanti tinsab f'`open-sse/services/compression/types.ts`.

### Għaliex dan huwa importanti

Mingħajr SHARED_BOUNDARIES, il-modi Caveman aggressivi jistgħu jneħħu kontenut li jidher bħal proża
ripetittiva iżda li fil-fatt ikun silta ta' kodiċi, path ta' fajl, jew stack ta' żball. SHARED_BOUNDARIES taġixxi bħala
xibka ta' sikurezza indipendenti mil-lingwa li tiġi applikata qabel jitħaddmu r-regoli tat-tneħħija tal-kliem żejjed.

### Personalizzazzjoni ta' preservePatterns

Jistgħu jiżdiedu mudelli addizzjonali waqt l-eżekuzzjoni permezz tas-settings tal-kompressjoni:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Il-mudelli personalizzati jestendu (mhux jissostitwixxu) s-6 valuri predefiniti.

## Noti Operazzjonali

- Ir-regoli integrati tal-Ingliż jibqgħu l-għażla ta' riżerva meta pakkett tal-lingwa jkun nieqes.
- Pakketti JSON integrati invalidi ma jgħaddux mill-validazzjoni sabiex l-assi tar-rilaxx ma jiddegradawx mingħajr indikazzjoni.
- Il-pakketti tar-regoli fihom data biss u m'għandhomx jimportaw kodiċi jew iħaddmu loġika arbitrarja.
- Is-saff tal-analitika tal-kompressjoni jirreġistra l-modalità u l-magna magħżula, mhux it-test sħiħ tal-prompt.
