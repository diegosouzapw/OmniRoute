`devin-cli-agentic` jippermetti lir-runtime reali ta’ Claude Code juża l-endpoint lokali ta’
Anthropic Messages ta’ OmniRoute filwaqt li s-CLI uffiċjali ta’ Devin jipprovdi t-tweġibiet
tal-mudell permezz ta’ ACP stdio. Dan ma jimmodifikax il-fornituri eżistenti ta’ Anthropic,
Claude OAuth, Claude Web, jew `devin-cli`.

> **Status attwali: Claude Code `2.1.258` iffissat; il-validazzjoni offline u live ġiet
> irreġistrata l-aħħar fuq `2.1.220`.** Il-verżjoni ffissata `2.1.220` lestiet tliet xenarji
> iżolati permezz ta’ Devin CLI `3000.2.17` u l-mudell `swe-1-7-lightning`; dik l-aħħar
> eżekuzzjoni live wriet dawriet `Read`, `Edit`, u `Bash` ikkontrollati mill-klijent,
> riżultati ta’ `npm test` li rnexxew, l-iskoperta ta’ kmandi u skills tal-proġett,
> routing esklussivament permezz ta’ Devin, u ebda traffiku ’l barra lejn Claude. Il-verżjoni
> ffissata mbagħad ittellgħet għal `2.1.258` (il-ġenerazzjoni tas-CLI li l-identità Claude
> ta’ OmniRoute tippersonifika, u l-ewwel linja li tinkludi t-tier Fable 5.1 b’mod nattiv).
> Fuq il-verżjoni l-ġdida, is-saff tal-installazzjoni u `claude --version` ġew ivverifikati
> fuq l-immaġni bażi ffissata, u jgħaddu s-sett tat-testijiet unit tal-bridge, `compose config`
> u l-prova statika tal-iżolament — iżda x-xenarju mock offline u s-sett live ta’ tliet
> xenarji għadhom ma ġewx eżegwiti mill-ġdid. Erġa’ eżegwihom (ara “Aġġornament tal-għodod
> iffissati”) qabel ma tiddependi fuq il-bridge b’din il-verżjoni ffissata.

## Arkitettura

```text
Claude Code 2.1.258 (container Linux iżolat mhux root)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (fornitur fil-format Claude, mingħajr awtentikazzjoni)
  -> devin acp --agent-type summarizer (ACP stdio uffiċjali, mingħajr għodod Devin)
  -> Kont Devin fil-volume dedikat devin-auth
```

L-aġent ACP default tas-CLI uffiċjali jista’ jeżegwixxi l-għodod tiegħu stess, għalhekk dan
il-bridge ma jużahx. Huwa jibda l-aġent ACP fiss `summarizer`, li l-modalità uffiċjali tiegħu
fis-CLI ma għandhiex għodod, u jqiegħed it-talba serjalizzata ta’ Anthropic fil-forma ta’
traċċa tal-eżekuzzjoni. Meta tkun meħtieġa azzjoni oħra kkontrollata minn Claude, it-tweġiba
għandu jkun fiha eżattament envelope wieħed ta’ għodda tal-klijent. Kwalunkwe `tool_call`
jew `tool_call_update` ta’ ACP jiġi rrifjutat qabel ma tweġiba tkun tista’ tiġi rrappurtata
bħala waħda li rnexxiet.

Is-serializer f’`open-sse/executors/devin-agentic/serializer.ts` jippreserva `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, u l-għodod
ipprovduti minn Claude Code. L-immaġnijiet u l-blocks mhux magħrufa jfallu b’mod espliċitu.
Riżultati kbar tal-għodod jużaw markatur viżibbli tat-truncation.

Il-parser jaċċetta envelope awtonomu wieħed `<tool>{...}</tool>` għal kull dawra tal-mudell.
Huwa jiċċekkja l-isem mal-lista tal-għodod fit-talba, jivvalida l-arguments kontra l-JSON
Schema ta’ dik l-għodda, jirrifjuta narrattiva u azzjonijiet imħallta, u jippermetti tentattiv
wieħed limitat ta’ tiswija. Claude Code mbagħad jeżegwixxi lokalment it-`tool_use` ta’
Anthropic li jirriżulta u jibgħat it-`tool_result` lura permezz ta’ OmniRoute.

## Mudell tal-iżolament u tat-theddid

L-installazzjoni, il-kont u l-konfigurazzjoni ta’ Claude fuq il-host huma barra mill-ambitu
u jitqiesu bħala pprojbiti. Is-servizzi Compose:

- jaħdmu bħala UID/GID `10001:10001`, b’filesystem root li jinqara biss, capabilities
  mneħħija, u `no-new-privileges`;
- jużaw `/home/bridge` privat, volume dedikat għall-konfigurazzjoni ta’ Claude, data iżolata
  ta’ OmniRoute, u volume separat `devin-auth`;
- jimmuntaw biss workspaces/evidenza temporanji f’`.sandbox`;
- ma jimmuntawx il-home tal-host, Keychain, SSH, kredenzjali tal-cloud, jew is-socket ta’
  Docker;
- jibnu environments espliċiti u jneħħu l-variables tal-API/OAuth/routing ta’ Anthropic;
- jidderieġu l-inference ta’ Claude Code biss lejn `http://omniroute:20128` b’key lokali biss.

Il-profile offline juża network intern. Fil-profile live, OmniRoute jilħaq l-endpoints
uffiċjali ta’ Devin biss permezz ta’ `network-guard`; destinazzjonijiet mhux relatati jiġu
miċħuda. Claude Code għandu guard separat li jiċħad kull egress u jista’ jilħaq biss
is-servizz lokali OmniRoute permezz ta’ `NO_PROXY`. Il-files tal-audit tal-guard jiġu
mmuntati biss mill-proċess tal-guard rispettiv tagħhom. L-iskripts jivverifikaw is-sjieda
tal-file, il-mode, l-għadd tal-links, u kull deċiżjoni qabel ma jesportaw evidenza mingħajr
tokens.

Eżegwixxi l-prova tal-iżolament b’mod indipendenti:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Din tivvalida t-topoloġija, il-mounts bl-isem, is-settings mhux root/ta’ qari biss,
ir-routing lokali espliċitu, in-nuqqas ta’ environment variables sensittivi, in-nuqqas
tas-socket ta’ Docker, l-aċċess imblukkat għal `api.anthropic.com` u `claude.ai`,
l-għażla ta’ fornitur Devin biss, u falliment espliċitu meta l-backend ACP ma jkunx
disponibbli.

## Konfigurazzjoni inizjali u użu normali

Ibni l-immaġni bil-verżjonijiet iffissati:

```bash
./scripts/devin-bridge/build
```

Awtentika biss il-volum iżolat ta' Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Il-kmand tal-login juża l-fluss uffiċjali b'token manwali maħsub għal ambjenti remoti/f'containers. Il-valur jiddaħħal direttament fil-prompt tas-CLI; ma jiġix mgħoddi bħala argument tal-proċess, miktub f'Git, jew ikkupjat mill-host.

Niedi l-ambjent ta' eżekuzzjoni iżolat ta' Claude Code:

```bash
./scripts/devin-bridge/launch
```

`launch` jerġa' jivverifika l-iżolament, l-awtentikazzjoni ta' Devin, u l-iskoperta tal-mudelli qabel ma jibda Claude Code fil-container. Qatt ma jħaddem l-eżegwibbli ta' Claude tal-host. L-aliases tal-mudelli jistgħu jiġu ssettjati f'`.env.devin-bridge`; kull valur ikkonfigurat għandu jżomm il-prefiss `devin-cli-agentic/`.

## Kmandi ta' validazzjoni

Il-perkors offline riproduċibbli ma jeħtieġ ebda kont ta' Devin u ma jkollu ebda aċċess għall-Internet waqt l-eżekuzzjoni:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Il-perkors live awtentikat, li jeħtieġ attivazzjoni espliċita, huwa:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

L-eżekutur live jistenna bejn xenarju u ieħor biex jevita li jiftaħ sessjonijiet ACP f'daqqa u jivvalida avvenimenti strutturati tal-fluss ta' Claude minflok ma jafda dikjarazzjonijiet testwali. It-tliet xenarji tiegħu jagħtu prova ta':

1. qari dirett tal-proġett u analiżi tad-difetti;
2. `Edit` reali, `Bash` `npm test` taħt il-kontroll tal-klijent, u riżultat finali;
3. `/bridge-check` flimkien mal-iskoperta ta' `bridge-proof`, qari tal-proġett, `npm test` ieħor taħt il-kontroll tal-klijent li jirnexxi, u tlestija mingħajr xogħol pendenti.

Il-verifika finali tivverifika wkoll l-awditu tan-network ta' Devin u teħtieġ li l-awditu tat-traffiku ħiereġ ta' Claude jibqa' vojt.

## Aġġornament tal-għodod b'verżjonijiet iffissati

L-immaġni tiffissa l-verżjonijiet ta' Node, Claude Code, u Devin CLI f'`docker/devin-bridge/Dockerfile`. Biex taġġorna:

1. ibdel il-verżjonijiet espliċiti;
2. ibdel iż-żewġ checksums tal-arkivju ta' Devin speċifiċi għall-arkitettura bil-valuri tal-artifatt uffiċjali;
3. erġa' ibni u ħaddem kull kmand ta' validazzjoni offline;
4. ikkonferma l-verżjonijiet ġewwa l-immaġni;
5. erġa' ħaddem is-sett live awtentikat ta' tliet xenarji.

Tinstallax xi wieħed miż-żewġ CLI globalment fuq il-host u tissostitwixxix il-verifika taċ-checksum b'download mhux ivverifikat.

## Dijanjosi u tindif

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  juri r-routing lokali u żbalji sanitizzati tal-eżekutur.
- `.sandbox/evidence/mock-acp.jsonl` jirreġistra azzjonijiet mock ACP deterministiċi.
- `.sandbox/evidence/claude-stream.jsonl` jirreġistra l-eżekuzzjoni offline reali ta' Claude Code.
- `.sandbox/evidence/live-*.jsonl` jirreġistra t-tliet flussi live vvalidati.
- `.sandbox/evidence/egress.jsonl` u `.sandbox/evidence/claude-egress.jsonl` huma kopji vvalidati u mingħajr tokens tal-awditi ta' protezzjoni.

Waqqaf il-containers u n-networks proprjetà tal-bridge filwaqt li tippreserva l-volumi tal-login/konfigurazzjoni:

```bash
./scripts/devin-bridge/clean
```

Neħħi l-ambjent sħiħ proprjetà tal-bridge, inklużi l-volumi bl-ismijiet:

```bash
./scripts/devin-bridge/clean --all
```

## Limiti

- Il-bridge jiddependi fuq ir-rwol fiss `summarizer` mingħajr għodod minħabba li Devin CLI `3000.2.17`
  ma jesponix aġent ACP newtrali mingħajr għodod. L-adapter jikkumpensa għal tweġibiet intermedji
  f’għamla ta’ sommarju, iżda tentattiv wieħed limitat ta’ tiswija xorta jista’ jfalli b’mod espliċitu.
- Sejħiet ACP diretti jistgħu jirritornaw tweġibiet temporanji `502`/`504`. Il-harness iqassam ix-xenarji
  f’intervalli; falliment persistenti jibqa’ magħluq b’mod sikur u qatt ma jagħżel fornitur ieħor.
- Il-kuntest ACP jiġi rikostruwit minn kull talba Anthropic; ma hemm l-ebda affinità
  ma’ proċess/sessjoni.
- Sejħa waħda għal għodda hija appoġġjata għal kull tweġiba tal-mudell; sejħiet paralleli jiġu miċħuda.
- L-immaġnijiet espliċitament mhumiex appoġġjati. Il-viżjoni, l-output tal-ħsieb, il-kontrolli tal-isforz, u tieqa tal-kuntest ta’ 1M
  mhumiex reklamati.
- SSE juża avvenimenti validi taċ-ċiklu tal-ħajja ta’ Anthropic, iżda dawn jintbagħtu wara li jinġabar it-turn ACP limitat;
  il-biċċiet ACP ma jiġux mgħoddija b’mod inkrementali.
