## Għaliex jeżisti dan

OmniRoute diġà jwieġeb żewġ mistoqsijiet dwar l-ispejjeż, iżda l-ebda waħda minnhom ma hija dik li jistaqsu l-biċċa l-kbira tal-operaturi.

| Mekkaniżmu eżistenti                                     | Iwieġeb                                            |
| -------------------------------------------------------- | -------------------------------------------------- |
| `hidePaidModels` (`autoCombo/paidModelFilter.ts`)        | "dan il-mudell huwa kkatalogat bla ħlas?"          |
| `freeAccessPolicy: "strict"` (`strictZeroCostFilter.ts`) | "din il-konnessjoni tista' qatt tiċċarġjani?"      |
| `quotaPreflight` (`combo/quotaExhaustionCutoff.ts`)      | "din il-konnessjoni tinsab qrib il-limitu tagħha?" |
| `budgetCap` / `budgetFallback` (`autoCombo/engine.ts`)   | "illimita l-infiq, aqleb għall-orħos għażla"       |

Kull mekkaniżmu li jippermetti biss għażliet bla ħlas **jagħlaq f'każ ta' falliment** — pool bla ħlas li jkun eżawrit isir pool vojt, u qatt
ma jaqleb għal għażla bi ħlas — u kull mekkaniżmu tan-naħa bi ħlas ma jagħmilx distinzjoni bejn il-livelli. L-ebda wieħed ma jwieġeb:

> "Uża l-kwota li diġà nħallas għaliha. Meta tispiċċa, jew waqqaf, jew itla' tarġa waħda kull darba
> permezz tal-orħos għażliet bi ħlas — u erġa' lura malli tiġi rrisettjata."

## Il-kontijiet huma fatt tal-konnessjoni, mhux fatt tal-mudell

`classifyTier()` (`open-sse/services/tierResolver.ts`) juża `(provider, model)` bħala ċavetta u jirritorna
`free | cheap | premium` mill-ipprezzar tal-katalgu. Iżda jekk talba tiswiex flus addizzjonali
jiddependi minn **liema konnessjoni taqdiha**: l-istess mudell ikun inkluż fil-pjan permezz ta' konnessjoni OAuth ta' Claude Code
u ċċarġjat għal kull token permezz ta' konnessjoni b'API key.

`provider_connections.auth_type` mhuwiex indikatur indirett affidabbli fl-ebda direzzjoni — jeżistu konnessjonijiet OAuth
imkejla, u jeżistu konnessjonijiet b'API key inklużi fil-pjan (token ta' post Copilot mhuwiex
API key imkejla). Għalhekk il-klassi tal-kontijiet tiġi minn **katalgu kkurat**,
`open-sse/config/connectionBillingCatalog.ts`, issettjat manwalment skont it-termini ppubblikati ta' kull fornitur —
l-istess mudell li `FreeModelBudget.hardStopGuaranteed` diġà stabbilixxa għall-mudelli bla ħlas.

```ts
type ConnectionBillingClass = "subscription" | "metered" | "keyless" | "unknown";
type ConnectionOverageBehavior = "hard-stop" | "meters-to-paid" | "unknown";
```

Ordni tar-riżoluzzjoni (`autoCombo/connectionBilling.ts`): is-sentinel sintetiku mingħajr awtentikazzjoni →
`keyless`; entrata fil-katalgu li taqbel mal-fornitur **u** ma' `authType`; entrata għall-fornitur kollu;
inkella `unknown`. **Dak li mhuwiex ikkurat mhuwiex bla ħlas** — `unknown` jiġi ttrattat bħala `metered`
kullimkien, għalhekk fornitur miżjud għada jibda barra mit-tarġa tal-abbonament u jrid jiġi
inkluż deliberatament fil-katalgu.

## Il-mudell tat-taraġ

Ħames turġien fl-ordni tal-eskalazzjoni. Huma differenti f'aktar mill-prezz — kull wieħed għandu s-sinjal ta' eżawriment **tiegħu stess**,
u għalhekk dan mhuwiex sempliċement issortjar.

| #   | Tarġa          | Sħubija                                            | Eżawrita meta                                  |
| --- | -------------- | -------------------------------------------------- | ---------------------------------------------- |
| 0   | `subscription` | `billing: "subscription"` ikkurat                  | il-perjodu tal-kwota jkun fil-limitu jew taħtu |
| 1   | `keyless`      | il-mogħdija sintetika mingħajr awtentikazzjoni     | cooldown tal-konnessjoni / circuit breaker     |
| 2   | `free`         | konnessjoni mkejla, `classifyTier() === "free"`    | l-allokazzjoni bla ħlas tkun eżawrita          |
| 3   | `cheap`        | konnessjoni mkejla, `classifyTier() === "cheap"`   | il-baġit għal dik it-tarġa jkun intuża         |
| 4   | `premium`      | konnessjoni mkejla, `classifyTier() === "premium"` | il-baġit għal dik it-tarġa jkun intuża         |

It-turġien 0-2 jiġu eżawriti skont il-**kwota**, li tista' tiġi osservata u diġà tiġi ttraċċata. It-turġien 3-4 ma għandhomx
kwota — konnessjoni bi ħlas tibqa' taqdi għal dejjem — għalhekk l-uniku sinjal sensibbli ta' eżawriment tagħhom huwa
**baġit** għal kull tarġa. Mingħajr wieħed, "eskala meta l-għażla rħisa tkun eżawrita" ma jkollu l-ebda skattatur.

## `auto/subscription` — agħlaq f’każ ta’ falliment

Pool = l-iskaluna 0 biss, ristretta għal konnessjonijiet li l-użu żejjed tagħhom huwa `hard-stop` dokumentat, u li għal kull waħda minnhom jiġi vverifikat direttament li għad għandhom kwota disponibbli. Kull ħaġa ambigwa hija eskluża: fornitur mhux ikkurat, qari tal-kwota li ma jistax jiġi vverifikat, qari skadut, jew użu żejjed li jiġi mkejjel bħala bi ħlas.

Pool vojt huwa r-risposta **maħsuba**, mhux difett — il-fluss eżistenti tas-sejjieħ għal pool vojt jibdlu fi żball ċar minflok fallback sieket u fatturabbli. Dik hija l-wegħda kollha tal-id.

`keyless` deliberatament **ma** jikkwalifikax: dan ir-raggruppament ifisser “il-pjan li nħallas għalih”, għalhekk backend mingħajr awtentikazzjoni ma jagħmilx parti minnu. Uża `auto/thrifty` (jew `auto/best-free`) għal dan.

### Sikurezza tal-konnessjoni

Kandidat mhux dejjem marbut ma’ konnessjoni waħda — kandidat loġiku jġorr allowlist `allowedConnectionIds`, u l-kont li fil-fatt jintuża jintgħażel aktar tard, waqt id-dispaċċ, minn `open-sse/services/combo/autoStrategy.ts`. Għalhekk, iż-żewġ raggruppamenti jivverifikaw **kull konnessjoni individwalment** u jerġgħu jiktbu `allowedConnectionIds` biex ikun fih eżattament is-subsett li jibqa’ validu — qatt il-lista oriġinali sħiħa, u qatt membru wieħed magħżul arbitrarjament. Minħabba li `autoStrategy.ts` diġà jinforza dak l-array bħala allowlist stretta, il-kitba mill-ġdid tiegħu hawn tagħmel “ivverifikat” u “użat fil-fatt” l-istess sett mill-kostruzzjoni tiegħu stess. Dan huwa l-istess invariant, u l-istess raġunament, bħal
[STRICT_ZERO_COST](./STRICT_ZERO_COST.md).

## `auto/thrifty` — itla’ skaluna waħda kull darba

Pool = l-iskaluni kollha, ordnati skont l-indiċi tal-iskaluna, bil-kandidati eżawriti esklużi permezz ta’ gating. Il-magna `auto` xorta waħda tagħti punteġġi **fi ħdan** il-pool li jibqa’: is-sellum jiddeċiedi liema skaluni jidħlu fis-seħħ, filwaqt li l-għoti tal-punteġġi jiddeċiedi liema kandidat jirbaħ fosthom. L-ordni hija stabbli fi ħdan kull skaluna, għalhekk il-klassifikazzjoni proprja tal-mekkaniżmu tal-punteġġi qatt ma tiġi rranġata mill-ġdid minn dan l-overlay.

Dan huwa overlay ta’ ordni + gating, **mhux** dispatcher ġdid: il-loop spekulattiv ta’ `combo.ts` diġà jgħaddi mit-targets skont l-ordni u, f’każ ta’ falliment, ikompli għal dak li jmiss; għalhekk, jekk waqt l-eżekuzzjoni sseħħ eżawriment li l-preflight ma jkunx induna bih, xorta jitla’ għall-iskaluna li jmiss fl-istess request.

Filwaqt li `auto/subscription` jagħlaq **f’każ ta’ falliment**, `auto/thrifty` jibqa’ **miftuħ**: konnessjoni inkluża fil-pjan li ma jkollhiex qari tal-kwota li jista’ jintuża xorta tiġi ppruvata l-ewwel. Li tipprovaha ma jiswa xejn, u jekk jirriżulta li hija eżawrita, il-fall-through jasal għall-iskaluna li jmiss xorta waħda — filwaqt li r-rifjut li tiġi ppruvata jibgħat ir-request lejn skaluna bi ħlas meta tkun nieqsa t-telemetrija, eżattament ir-riżultat li dan ir-raggruppament jeżisti biex jevita.

## Ritorn lejn il-pjan wara reset

Tliet affarijiet indipendenti jridu jiskadu qabel ir-routing jirritorna għall-iskaluna 0. Jekk tissewwa waħda biss, is-sellum jibqa’ mwaħħal fuq skaluni bi ħlas għal ħafna żmien wara li l-pjan ikun reġa’ mtela.

1. **Il-cache tal-istat tal-kwota** — `freeAccessQuota.ts` iżomm cache għal kull `(provider, connection)` b’TTL ta’
   180s. Entry fil-cache li r-`resetAt` tagħha stess ikun diġà għadda tiddeskrivi window li
   m’għadhiex teżisti, għalhekk issa titqies bħala skaduta **irrispettivament mill-età** u ġġiegħel
   li jsir refresh. Mingħajr dan, pjan li reġa’ mtela f’nofsillejl jibqa’ jidher eżawrit sakemm
   it-TTL jinzerta jiskadi.
2. **L-istat proprju tas-sellum** — ma hemm ebda stat, skont id-disinn. L-eliġibbiltà tal-iskaluni tiġi kkalkulata mill-ġdid
   mill-istat dirett tal-kwota kull darba li jinbena pool; ma jeżisti ebda rekord persistenti “bħalissa fuq l-iskaluna 3” li
   jista’ jibqa’ ħaj wara reset u jimblokka r-routing.
3. **Il-cooldown tal-konnessjoni** — il-429 tal-eżawriment jistabbilixxi `rateLimitedUntil` minn backoff
   esponenzjali, li għal konnessjoni ta’ pjan jista’ jaqbeż il-ħin reali tar-reset. `clampCooldownToReset()`
   (`subscriptionLadder.ts`) iqassar cooldown sal-mument tar-reset proprju tal-upstream u
   qatt ma jista’ jestendih. **Huwa implimentat u ttestjat iżda għadu mhux ikkollegat**: il-cache tal-kwota tiġi
   invalidata f’`src/sse/services/auth.ts` _qabel_ ma jinkiteb kwalunkwe cooldown, għalhekk `resetAt`
   irid jinqabad aktar kmieni f’dik il-funzjoni — bidla fil-hot path tar-reżiljenza li
   għandha tkun fi PR separat u rieżaminat. Sa dak iż-żmien, id-dħul mill-ġdid jistenna li jgħaddi l-cooldown tal-konnessjoni
   (li diġà jippreferi l-indikazzjonijiet upstream ta’ `Retry-After` meta l-fornitur jibgħathom).

### Kontra ċ-ċaqliq ripetut

Skaluna li tkun għadha kemm għamlet reset terġa’ tiddaħħal biss meta tkun ’il fuq minn `reentryMinRemainingPercent` (default 5),
filwaqt li konnessjoni li diġà qed tintuża trid biss tibqa’ ’l fuq minn `exitCutoffPercent` (default 2,
li jaqbel ma’ `quotaPreflight.defaultThresholdPercent`). Id-differenza hija l-faxxa tal-istereżi — mingħajrha,
konnessjoni li tibqa’ qrib il-limitu taqleb bejn l-iskaluni fuq requests konsekuttivi.

## Konfigurazzjoni

Irfinar biss. Apposta **m'hemm l-ebda** flag `enabled`: swiċċ li jista' jitfihom
iħalli lil `auto/subscription` iservi bil-kwiet mill-pool kollu — inklużi l-mudelli bi ħlas — taħt
isem li jwiegħed l-oppost.

```jsonc
{
  "subscriptionLadder": {
    "exitCutoffPercent": 2,
    "reentryMinRemainingPercent": 5,
    "rungBudgetUsd": { "cheap": 5.0, "premium": 0 }, // 0 jiddiżattiva skaluna kompletament
  },
}
```

Il-kontroll skont il-baġit jibqa' inattiv sakemm jiġi kkonnettjat resolver tal-infiq: meta ma jkun hemm l-ebda kontabbiltà disponibbli, skaluna
bi ħlas tiġi ordnata iżda qatt ma tiġi ristretta. Minn v3.8.51, is-setting `rungBudgetUsd` huwa aċċettat mill-
iskema iżda GĦADU MHUX infurzat — ittrattah bħala konfigurazzjoni riżervata, mhux bħala limitu attiv tal-infiq. L-ordni tal-iskaluni, l-eżawriment ibbażat fuq il-kwota, u d-dħul mill-ġdid wara reset kollha
jaħdmu mingħajru.

## Kompożizzjoni

`subscription` u `thrifty` huma valuri `AutoTier`, għalhekk jistgħu jiġu kkombinati ma' kull kategorija:
`auto/coding:thrifty`, `auto/reasoning:subscription`, u l-bqija. Iż-żewġ ids sempliċi
(`auto/subscription`, `auto/thrifty`) jiġu rreklamati f'`/v1/models` u fid-dashboard.

L-ebda wieħed miż-żewġ ids mhu tat-tier bi ħlas, għalhekk `isPaidTierAutoId()` jirritorna `false` għat-tnejn u
`auto/subscription` jibqa' disponibbli ma' `hidePaidModels`.
