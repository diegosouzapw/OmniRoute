## Routing Awtomatiku Mingħajr Konfigurazzjoni (prefiss `auto/`)

> **ĠDID:** M’hemmx għalfejn toħloq combo. Uża l-prefiss `auto/` direttament fi kwalunkwe klijent.

### Eżempji Rapidi

| ID tal-Mudell  | Varjant | Imġiba                                                                                      |
| -------------- | ------- | ------------------------------------------------------------------------------------------- |
| `auto`         | default | Il-fornituri konnessi kollha, strateġija LKGP, piżijiet ibbilanċjati                        |
| `auto/coding`  | coding  | Piżijiet li jagħtu prijorità lill-kwalità, adattati għall-ġenerazzjoni tal-kodiċi           |
| `auto/fast`    | fast    | Għażla ppeżata b’latenza baxxa                                                              |
| `auto/cheap`   | cheap   | Routing ottimizzat għall-ispiża (l-inqas spiża l-ewwel)                                     |
| `auto/offline` | offline | Jiffavorixxi l-fornituri bl-ogħla disponibbiltà ta’ kwota                                   |
| `auto/smart`   | smart   | Prijorità lill-kwalità + rata ogħla ta’ esplorazzjoni (10%) għal skoperta aħjar tal-mudelli |
| `auto/lkgp`    | lkgp    | LKGP espliċitu (l-istess bħall-`auto` default)                                              |
| `auto/chaos`   | chaos   | Piżijiet ta’ injezzjoni ta’ ħsarat għall-ittestjar tar-reżiljenza (inġinerija tal-kaos)     |

### Kompożizzjoni ta’ Kategorija × Livell (`auto/<category>:<tier>`)

Is-suffissi fl-istil ta’ OpenRouter jisseparaw **x’tip ta’ rotta** (kategorija) minn **kif tiġi ottimizzata** (livell), sabiex tkun tista’ tikkombinahom liberament (#4235 Fażi B, `open-sse/services/autoCombo/suffixComposition.ts`):

- **Kategoriji** (jiffiltraw il-grupp ta’ kandidati skont il-kapaċità): `coding` · `reasoning` · `vision` · `chat` · `multimodal`. `vision`/`multimodal` iżommu mudelli b’kapaċitajiet viżivi; `reasoning` iżomm mudelli ta’ raġunament/ħsieb.
- **Livelli** (jagħżlu l-piżijiet tal-punteġġ / il-filtru tal-grupp): `fast` (rilaxx rapidu) · `cheap` (alias `floor`, iffrankar tal-ispejjeż) · `reliable` (saħħa tas-circuit breaker + stabbiltà tal-latenza) · `free` / `pro` (jiffiltraw il-grupp skont il-livell tal-mudell permezz ta’ `classifyTier` — livell bla ħlas kontra premium).

| Eżempju                | Jissarraf fi                                                          |
| ---------------------- | --------------------------------------------------------------------- |
| `auto/coding:fast`     | grupp tal-coding, piżijiet b’latenza baxxa                            |
| `auto/coding:cheap`    | grupp tal-coding, ottimizzat għall-ispiża (alias `auto/coding:floor`) |
| `auto/reasoning:pro`   | mudelli ta’ raġunament/ħsieb biss, livell premium                     |
| `auto/vision`          | mudelli b’kapaċitajiet viżivi (l-ebda livell → piżijiet ibbilanċjati) |
| `auto/multimodal:free` | mudelli b’kapaċitajiet multimodali, livell bla ħlas biss              |

Kwalunkwe `auto/<category>[:<tier>]` validu jiġi solvut fuq talba; sottogrupp magħżul jiġi rreklamat f’`/v1/models` u fid-dashboard (`AUTO_SUFFIX_VARIANTS` f’`open-sse/services/autoCombo/builtinCatalog.ts`). L-iffiltrar huwa **fail-open** — jekk restrizzjoni ma taqbel ma’ ebda mudell konness, jintuża l-grupp sħiħ sabiex ir-routing qatt ma jieqaf jaħdem. Il-mekkaniżmu ewlieni tal-punteġġ (`combo.ts`) jibqa’ l-istess; il-filtru tal-kategorija/livell jiġi applikat f’`buildAutoCandidates`.

> **Intelliġenza diretta dwar il-mudelli:** l-adegwatezza tar-routing awtomatiku hija infurmata minn klassifiki diretti ta’ **Arena ELO** + data dwar il-livelli minn **models.dev** meta l-flag `ARENA_ELO_SYNC_ENABLED` ikun attivat (inkella jerġa’ juża l-mappa statika tal-adegwatezza).

**Kif tużah:**

```bash
# Kwalunkwe għodda IDE jew CLI li tappoġġja l-format OpenAI
Base URL: http://localhost:20128/v1
API Key:  <your-endpoint-key>

# Fil-kodiċi/konfigurazzjoni tiegħek, issettja l-mudell għal:
model: "auto"                 # default ibbilanċjat
model: "auto/coding"          # l-aħjar għal kompiti ta’ coding
model: "auto/fast"            # l-aktar wieħed rapidu disponibbli
model: "auto/cheap"           # l-irħas għal kull token
```

**X’jiġri:**

1. OmniRoute jidentifika l-prefiss `auto/` f’`src/sse/handlers/chat.ts`
2. Jikkonsulta l-**konnessjonijiet attivi kollha tal-fornituri** mid-database
3. Jiffiltra għal dawk bi kredenzjali validi (ċavetta API jew token OAuth)
4. Jiddetermina l-mudell għal kull konnessjoni (`connection.defaultModel` jew l-ewwel mudell tal-fornitur)
5. Jibni **combo virtwali** fil-memorja (ma jinħażinx fid-DB)
6. Jagħmel ir-routing billi juża l-profil tal-piżijiet tal-varjant magħżul + l-istrateġija LKGP

**Karatteristiċi ewlenin:**

- ✅ **Dejjem attiv:** Ebda toggle, ebda ħolqien ta’ combo, ebda konfigurazzjoni meħtieġa
- ✅ **Dinamiku:** Jirrifletti awtomatikament il-fornituri konnessi bħalissa
- ✅ **Persistenza tas-sessjoni:** LKGP jiżgura li tingħata prijorità lill-aħħar fornitur li rnexxa
- ✅ **Konxju minn kontijiet multipli:** Kull konnessjoni ta’ fornitur issir kandidat separat
- ✅ **Ebda kitba fid-DB:** Il-combo virtwali jeżisti biss għat-talba, mingħajr spejjeż żejda ta’ persistenza

### Kontroll tal-kandidati għal kull ċavetta (#7819, Livell 1+2)

`GET /v1/auto-combo/{channel}/candidates` (`{channel}` = is-suffiss wara `auto/`, jew
il-valur litterali `auto` għall-kanal bażi) huwa endpoint **għall-qari biss** li jelenka
l-grupp attwali ta’ kandidati ta’ kanal `auto/*`, imżejjen b’informazzjoni diretta dwar
l-aċċessibbiltà, filwaqt li jerġa’ juża l-qari eżistenti tar-reżiljenza (qatt l-`state`
mhux ipproċessat tal-breaker):

- circuit breaker tal-fornitur — `getCircuitBreaker(provider).getStatus()` / `.canExecute()`
- cooldown tal-konnessjoni — `rateLimitedUntil` / `testStatus` fuq ir-ringiela solvuta
  ta’ `provider_connections`
- imblukkar tal-mudell — `isModelLocked(provider, connectionId, model)`

Kull kandidat iġorr ukoll il-flag `excluded` ta’ din iċ-ċavetta API. L-esklużjonijiet
jinħażnu għal kull ċavetta API (tabella `auto_candidate_overrides`, migrazzjoni `128`) —
OmniRoute huwa single-tenant mingħajr tabella `users`, għalhekk `apiKeyId` huwa l-eqreb
identità reali għal kull min jagħmel sejħa — u jiġu infurzati fil-punt kritiku tal-grupp
ta’ kandidati f’`open-sse/services/autoCombo/virtualFactory.ts` permezz ta’
`filterExcludedCandidates()` pur u ttestjat b’testijiet unitarji
(`open-sse/services/autoCombo/candidateOverrides.ts`). Il-filtru huwa **fail-open**:
apiKeyId/kanal mhux issettjat jew falliment f’konsultazzjoni tad-DB it-tnejn iħallu
l-grupp mhux iffiltrat, sabiex operatur mingħajr overrides ikkonfigurati jara routing
identiku byte b’byte għal kif kien qabel din il-karatteristika.

**Differit għal kwistjoni ta’ segwitu:** piżijiet għal kull kandidat + ordni espliċitu (Livell 3
— jidħol fil-flussi eżistenti tal-istrateġija peżata/tal-prijità) u l-iffissar ta’ strateġija
`combo.ts` speċifika għal kull kanal `auto/*` (Livell 4). Ara l-pjan #7819 għall-mistoqsija
miftuħa dwar jekk is-sovrascritturi għandhomx jibqgħu għal kull ċavetta tal-API jew isiru
globali minħabba l-mudell b’inkwilin wieħed.

**Wara l-kwinti:**

```txt
Talba: { model: "auto/coding" }
   ↓
src/sse/handlers/chat.ts jidentifika l-prefiss
   ↓
createVirtualAutoCombo('coding') → candidatePool mill-konnessjonijiet attivi
   ↓
handleComboChat (l-istess magna bħall-combos persistiti)
   ↓
L-iskorjar awtomatiku jagħżel l-aħjar fornitur/mudell għal kull talba
```

**Fajls tal-implimentazzjoni:**

| Fajl                                                      | Għan                                                      |
| --------------------------------------------------------- | --------------------------------------------------------- |
| `open-sse/services/autoCombo/autoPrefix.ts`               | Analizzatur tal-prefiss (`parseAutoPrefix`)               |
| `open-sse/services/autoCombo/virtualFactory.ts`           | Joħloq oġġetti virtwali `AutoComboConfig`                 |
| `open-sse/services/autoCombo/providerRegistryAccessor.ts` | Hook tat-test għall-immudellar tar-reġistru tal-fornituri |
| `src/sse/handlers/chat.ts`                                | Integrazzjoni: short-circuit tal-prefiss auto             |
| `src/shared/constants/providers.ts`                       | Entrata tas-sistema `SYSTEM_PROVIDERS.auto`               |

## Ismijiet ta’ Kombinazzjonijiet li Jaqblu ma’ Id ta’ Mudell Reali

Kombinazzjoni li l-`name` tagħha huwa identiku għal id ta’ mudell mhux ikkwalifikat (eż. kombinazzjoni bl-isem
`gpt-5.5`) hija **mudell intenzjonat u appoġġjat**, mhux bug: dan huwa l-mekkaniżmu għall-użu ta’ fornitur alternattiv għal kull id ta’ mudell, kif iddokumentat f’
[#6940](https://github.com/diegosouzapw/OmniRoute/issues/6940). Minħabba li r-riżoluzzjoni tal-kombinazzjonijiet tiġi ċċekkjata qabel ir-riżoluzzjoni tal-id ta’ mudell mhux ikkwalifikat
(`getComboForModel()` f’`src/sse/services/model.ts`), talba għall-id mhux ikkwalifikat
`gpt-5.5` tiġi diretta permezz tal-miri tal-kombinazzjoni (eż.
`acme-responses/gpt-5.5`, `backup-responses/gpt-5.5`) minflok direttament lejn fornitur wieħed — dan jerġa’ juża l-preċedenza tal-kombinazzjoni qabel il-kitba mill-ġdid, mibnija għal
[#3227/#3233](https://github.com/diegosouzapw/OmniRoute/issues/3227), u hija ttestjata kontra rigressjonijiet minn `tests/unit/responses-combo-resolution-3227.test.ts` u
`tests/unit/combo-name-codex-responses-rewrite.test.ts`.

Il-ħolqien jew il-bdil tal-isem ta’ kombinazzjoni għal isem li jgħatti id ta’ mudell reali
**qatt ma jiġi miċħud** — jekk isir hekk, dan il-fluss tax-xogħol iddokumentat ma jibqax jaħdem. Minflok
(#8530), `POST /api/combos` u `PUT /api/combos/[id]` iżidu kamp `warning` li ma jimblokkax mar-risposta meta l-isem (il-ġdid) jaħbat ma’ id ta’ mudell reali:

```json
{
  "warning": {
    "code": "COMBO_NAME_SHADOWS_MODEL",
    "modelId": "gpt-5.5",
    "providerId": "openai"
  }
}
```

Waqt it-tħaddim inizjali, `scanComboModelNameCollisionsAtBoot()`
(`src/instrumentation-node.ts`) jirreġistra wkoll twissija `[STARTUP]` ta’ linja waħda li telenka kull kombinazzjoni eżistenti li tgħatti id ta’ mudell, sabiex l-operaturi li jiltaqgħu ma’ dan aċċidentalment (minflok intenzjonalment, skont #6940) ikollhom indikazzjoni.
L-għodda awżiljarja tad-detezzjoni tinsab f’`src/lib/combos/modelNameCollision.ts`.

## Kif Issejjaħ Kombinazzjoni Personalizzata Minn Klijent

Il-kombinazzjonijiet persistenti (Settings → Combos) jintużaw biss meta l-klijent jibgħat l-**isem eżatt** tal-kombinazzjoni fil-kamp `model` — ma jsir ebda tqabbil approssimattiv jew parzjali tal-isem tal-kombinazzjoni, u ma jintuża ebda prefiss `auto/`. L-ordni tar-riżoluzzjoni (`getComboForModel()` f’`src/sse/services/model.ts`):

1. tqabbil eżatt mal-isem tal-kombinazzjoni (`model: "my-combo"`),
2. il-prefiss `combo/<name>` (`model: "combo/my-combo"`),
3. immappjar glob minn mudell għal kombinazzjoni (`/api/model-combo-mappings`).

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-combo","messages":[{"role":"user","content":"Hello"}]}'
```

Żewġ żbalji komuni:

- **`auto` ma jużax il-kombinazzjonijiet tiegħek.** `auto`/`auto/*` jibni l-ġabra tiegħu stess ta’ kandidati mingħajr konfigurazzjoni u jikkonsulta l-kombinazzjonijiet persistenti biss jekk kombinazzjoni tkun litteralment jisimha `auto` (mhux rakkomandat). Biex tidderieġi t-talbiet permezz ta’ kombinazzjoni, ibgħat l-isem eżatt tagħha — mhux `auto`.
- **`openrouter/auto` huwa prodott reali bi ħlas ta’ OpenRouter** ("Auto Best Available"), mhux alias ta’ OmniRoute. Huwa l-unika entrata statika ta’ mudell fir-reġistru ta’ OpenRouter (`open-sse/config/providers/registry/openrouter/index.ts`) u jiġi ċċarġjat separatament. Uża Settings → Routing → Hide paid models biex teskludih mill-ġabriet `auto`.

Ara [#7992](https://github.com/diegosouzapw/OmniRoute/issues/7992) u [#7111](https://github.com/diegosouzapw/OmniRoute/issues/7111) għall-konfużjoni oriġinali li dan jiddokumenta.

## Kif Jaħdem (Auto-Combos Persistiti)

L-Auto-Combo Engine jagħżel dinamikament l-aħjar fornitur/mudell għal kull talba permezz ta’ **funzjoni ta’ punteġġ bi 16-il fattur** (definita f’`open-sse/services/autoCombo/scoring.ts` → `DEFAULT_WEIGHTS`). Il-piżijiet predefiniti jammontaw għal `1.0`; il-piżijiet personalizzati jiġu normalizzati mill-ġdid minn `normalizeScoringWeights()`. Tnejn mis-sittax — `cacheAffinity` u `resetWindowAffinity` — għandhom piż predefinit ta’ `0`; `reliability` għandu `0` f’`DEFAULT_WEIGHTS` iżda `0.03` f’pakketti ġeneriċi u `0.04` f’`reliability-first`, filwaqt li `quality` għandu `0.02` fil-pakketti (`0.03` f’`quality-first`): xorta waħda jiġu kkalkolati għal kull kandidat, u `cacheAffinity` jikkontrolla d-deduplikazzjoni tal-cache tal-prompt barra mill-punteġġ, għalhekk il-fatturi bi żero bħala valur predefinit sempliċement ma jivvutawx b’mod predefinit, filwaqt li l-pakketti jagħmlu dan.

### Semantika ta' `weighted`

`weighted` huwa **tlugħ każwali proporzjonali għal kull talba**
(`open-sse/services/combo/targetSorters.ts` → `selectWeightedTarget`), mhux mekkaniżmu ta' ekwalizzazzjoni:

- Kull talba tiġbed **pass wieħed** bi probabbiltà `weight / totalWeight`; il-passi li jifdal
  jiġu ordnati skont il-piż f'ordni dixxendenti bħala l-katina ta' riżerva għal dik it-talba.
- Pass li l-piż tiegħu huwa `0` (jew nieqes) **qatt ma jintgħażel** waqt li xi pass ieħor ikollu
  piż > 0 — jista' jservi biss bħala riżerva wara li l-pass magħżul ifalli. Huwa biss meta l-piżijiet
  **kollha** jkunu 0 li l-għażla ssir uniformi.
- Il-passi li l-miri tagħhom ikunu kollha mhux disponibbli — circuit breaker tal-fornitur `OPEN`, perjodu
  ta' stennija tal-konnessjoni, imblukkar tal-mudell — jitneħħew mit-tlugħ qabel ma jsir
  (`open-sse/services/combo/targetResolution.ts`), għalhekk pass wieħed li jkun operattiv jista' temporanjament
  jirbaħ kull talba.
- `stickyWeightedLimit` (konfigurazzjoni tal-combo, valur default `1` = mitfi) jillokkja l-pass magħżul għal dak l-għadd
  ta' suċċessi konsekuttivi qabel ma jerġa' jsir it-tlugħ.

Għal rotazzjoni stretta uża `round-robin`; piżijiet indaqs f'`weighted` jagħtu bilanċ statistiku — mhux
strett.

## Strateġija ta’ Fużjoni

`fusion` hija l-unika strateġija li **ma** tagħżilx mira waħda. Hija tqassam il-prompt
lil **kull mudell fil-panel b’mod parallel**, imbagħad **mudell ġudikatur** konfigurabbli jissintetizza
tweġiba finali waħda mit-tweġibiet kollha tal-panel. Adattata mill-proġett upstream `decolua/9router`
(id-disinn Fusion ta’ OpenRouter); l-implimentazzjoni tinsab f’`open-sse/services/fusion.ts`.

Kif taħdem:

0. **Qbiż għal talbiet b’għodod** — talba li ġġorr array `tools` mhux vojt b’
   `tool_choice` mhux issettjat espliċitament għal `"none"` taqbeż il-panel kompletament: tiġi diretta
   lejn mudell wieħed (il-ġudikatur konfigurat, jew `panel[0]`) b’`tools`/`tool_choice`
   mgħoddija mingħajr tibdil. Il-membri tal-panel ma għandhomx aċċess għall-għodod u d-direttiva
   ta’ sinteżi tal-ġudikatur tiskoraġġixxi l-ħruġ ta’ sejħiet tal-għodod, sabiex il-klijenti
   aġentiċi/li jsejħu l-għodod jirċievu deċiżjoni reali ta’ sejħa tal-għodda minflok proża sintetizzata (#6771).
1. **Tqassim mifrux** (għal talbiet mingħajr għodod biss) — il-prompt jintbagħat lil kull mudell
   tal-panel f’daqqa, b’non-streaming sfurzat u bl-għodod imneħħija (il-ġudikatur jeħtieġ
   proża kompluta biex jissintetizza).
2. **Ġbir b’kworum u perjodu ta’ grazzja** — malli jaslu `minPanel` tweġibiet, jibda timer
   qasir ta’ grazzja għal dawk li għadhom lura, imbagħad il-fużjoni tipproċedi b’dak kollu li jkun inġabar.
   Dan jillimita l-penali tal-aktar mudell kajman fuq il-ħin totali, soġġett għal timeout riġidu.
3. **Sinteżi mill-ġudikatur** — it-tweġibiet tal-panel jiġu anonimizzati (`Sors 1`, `Sors 2`, … — sabiex
   il-ġudikatur jiżen is-sustanza, mhux il-marka tal-mudell) u jingħataw lill-ġudikatur, li janalizza
   l-kunsens / il-kontradizzjonijiet / il-kopertura parzjali / l-għarfien uniku / il-punti mhux meqjusa, imbagħad
   jikteb tweġiba awtorevoli **waħda**. Is-sejħa lill-ġudikatur iżżomm il-flag `stream` oriġinali
   tal-klijent flimkien mal-għodod, sabiex l-istreaming u l-użu sussegwenti tal-għodod jibqgħu jaħdmu.
4. **Degradazzjoni gradwali** — 0 tweġibiet mill-panel → `503`; superstiti wieħed eżatt → dik it-tweġiba
   tintbagħat direttament (ma hemm xejn x’jiġi fuż); panel b’mudell wieħed iwieġeb direttament.

Membru tal-panel jista’ jkun ukoll pass `combo-ref` (`{kind: "combo-ref", comboName: "..."}`) li jirreferi
għal combo ieħor — jiġi riżolt bħala **vuċi waħda tal-panel bħala black box** (dispatch rikursiv sħiħ lejn
il-combo referenzjat, mhux tqassim mifrux lejn il-miri tal-istess combo), bl-istess protezzjoni tal-fond/ċiklu
li diġà tuża kull strateġija oħra li tikkonsma combo-ref (#6764).

## Fabbrika Virtwali tal-Auto-Combo

Il-magna Auto Combo ma teħtieġx combos definiti minn qabel. Minflok, `open-sse/services/autoCombo/virtualFactory.ts` tibni l-kandidati minnufih:

1. Tiġbed `getProviderConnections({ isActive: true })` (il-konnessjonijiet attivati kollha)
2. Tiffiltra dawk li għandhom kredenzjali validi (API key jew token OAuth mhux skadut permezz ta’ `hasUsableOAuthToken()`)
3. Tqabbel ma’ `getProviderRegistry()` għad-disponibbiltà tal-mudelli u l-prezzijiet
4. Għal kull tuple `(provider, model, connection)`, tibni `VirtualAutoComboCandidate`
5. Tagħżel `connection.defaultModel` (jew l-ewwel mudell fir-reġistru) bħala d-destinazzjoni tad-dispaċċ
6. Tagħti punteġġ lil kull kandidat permezz tal-`scorePool()` b’16-il fattur u l-pakkett ta’ piżijiet tal-varjant
7. Tirritorna l-`AutoComboConfig` li jirriżulta fil-memorja għal `handleComboChat()` — qatt ma jiġi ppersistit fid-DB

Dan ifisser li **ż-żieda ta’ fornitur ġdid b’`auto/*` attivat tespandi awtomatikament il-pool tal-kandidati** — mhu meħtieġ ebda editjar manwali tal-combo. Il-combo virtwali jerġa’ jinbena għal kull talba, għalhekk konnessjonijiet miżjuda reċentement jew li reġgħu saru tajbin jintużaw immedjatament.

## Awtoriparazzjoni

- **Esklużjoni temporanja**: Punteġġ < 0.2 → eskluż għal 5 min (backoff progressiv, massimu ta’ 30 min)
- **Għarfien tas-circuit breaker**: OPEN → awtomatikament eskluż; HALF_OPEN → talbiet ta’ prova
- **Modalità ta’ inċident**: >50% OPEN → iddiżattiva l-esplorazzjoni, timmassimizza l-istabbiltà
- **Irkupru wara l-cooldown**: Wara l-esklużjoni, l-ewwel talba tkun "prova" b’timeout imnaqqas

## Esplorazzjoni Bandit

5% tat-talbiet (konfigurabbli) jiġu direzzjonati lejn fornituri każwali għall-esplorazzjoni. Din tiġi diżattivata fil-modalità ta’ inċident.

## API

**Ma jeżisti ebda endpoint iddedikat `POST /api/combos/auto`** — Auto-Combo jintuża b’żewġ modi:

1. **Mingħajr konfigurazzjoni (rakkomandat):** Ibgħat kwalunkwe talba ta’ tlestija taċ-chat b’`model: "auto"` jew `model: "auto/<variant>"`. Il-fabbrika virtwali tibni l-combo għal kull talba — mhu meħtieġ ebda ppersistir u ebda sejħa tal-API.

2. **Combo ppersistit bi `strategy: "auto"`:** Oħloq combo regolari permezz ta’ `POST /api/combos` u ssettja `strategy: "auto"` flimkien ma’ `config.auto.weights` / `config.auto.candidatePool`. Tintuża l-istess magna tal-punteġġ; il-combo jinħażen f’`combos` u jista’ jerġa’ jintuża permezz tal-ID.

Għall-iskoperta, `GET /api/combos/auto` jelenka kull varjant bil-pool tal-kandidati riżolt tiegħu flimkien ma’ `context_length` / `max_output_tokens` — il-MASSIMU fost it-twieqi tal-pool tal-kandidati. Il-klijenti (eż. il-plugin opencode) iridu jirreklamaw dawn il-valuri minflok `0`: kuntest żero jiddiżattiva kompletament l-awtokompattazzjoni ta’ opencode, u jħalli s-sessjonijiet jikbru sakemm it-tindif tal-istorja tal-gateway jeqred il-kuntest. Il-MASSIMU huwa sikur biex jiġi rreklamat għax il-prefiltru tal-kuntest tal-auto-combo jidderieġi talbiet kbar wisq lejn kandidati bi twieqi kbar.

```bash
# Użu mingħajr konfigurazzjoni (mingħajr ħolqien ta’ combo)
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto/coding","messages":[{"role":"user","content":"Hello"}]}'

# Combo awtomatiku ppersistit permezz tal-endpoint regolari tal-combos
curl -X POST http://localhost:20128/api/combos \
  -H "Content-Type: application/json" \
  -d '{"id":"my-auto","name":"Auto Coder","strategy":"auto","config":{"auto":{"candidatePool":["anthropic","google","openai"],"weights":{"quota":0.15,"health":0.3,"costInv":0.05,"latencyInv":0.35,"taskFit":0.1,"stability":0,"tierPriority":0.05}}}}'
```

### Strateġiji tar-router awtomatiku

Combos ippersistiti bi `strategy: "auto"` jistgħu jissettjaw `config.routerStrategy` (jew il-format preċedenti
`config.auto.routerStrategy`) għal wieħed minn dawn:

- `rules` — punteġġ ponderat predefinit
- `score` — jagħżel l-ogħla punteġġ ponderat ikkonfigurat. F’każ ta’ punteġġi eżattament indaqs jinżamm l-ordni kkonfigurat
  tal-kandidati; l-`explorationRate` eżistenti jieħu kampjun mill-pool ikklassifikat kollu.
- `cost` / `eco` — l-orħos fornitur f’saħħtu
- `latency` / `fast` — l-inqas latenza p95 b’penali għall-affidabbiltà
- `sla-aware` / `sla` — jippreferi kandidati li jissodisfaw il-latenza p95, ir-rata ta’ żbalji, u SLOs fakultattivi
  tal-ispejjeż
- `lkgp` — l-ewwel il-fornitur li kien magħruf l-aħħar bħala tajjeb

### L-istrateġiji tar-router fid-dettall

Il-magna auto-combo tesponi 6 implimentazzjonijiet **RouterStrategy** modulari li
tista’ tibdel permezz ta’ `config.routerStrategy` (jew il-format preċedenti `config.auto.routerStrategy`).
Kull strateġija tagħżel fornitur wieħed mill-pool tal-kandidati, abbażi ta’ `RoutingContext`
(tip ta’ kompitu, indikazzjonijiet dwar għodod/viżjoni, stima tat-tokens, politika SLA fakultattiva, fornitur fakultattiv
li kien magħruf l-aħħar bħala tajjeb).

#### 1. `rules` (predefinit) — punteġġ ponderat b’16-il fattur

Tinkapsula l-magna tal-punteġġ eżistenti. Tiffiltra l-kandidati tas-circuit breaker
bi stat `OPEN`, imbagħad tħaddem `scorePool()` bit-tip ta’ kompitu attwali u `getTaskFitness()`,
u tagħżel il-fornitur bl-ogħla punteġġ.

```ts
class RulesStrategyImpl implements RouterStrategy {
  readonly name = "rules";
  readonly description = "16-factor weighted scoring (see DEFAULT_WEIGHTS)";

  select(pool, context) {
    const eligible = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const ranked = scorePool(
      eligible.length > 0 ? eligible : pool,
      context.taskType,
      undefined,
      getTaskFitness
    );
    return { provider: ranked[0].provider /* ... */ };
  }
}
```

**Meta tużaha**: Predefinita. Użaha meta trid bilanċ bejn is-sinjali kollha.

**Alias**: `rules` (mingħajr alias)

---

#### 2. `cost` / `eco` — l-orħos fornitur f’saħħtu

Tissortja l-pool tal-kandidati skont `costPer1MTokens` (f’ordni axxendenti) u tagħżel l-orħos wieħed.
L-ewwel tiffiltra l-kandidati bi stat `OPEN`.

```ts
class CostStrategyImpl implements RouterStrategy {
  readonly name = "cost";
  readonly description = "Always selects cheapest available provider";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort((a, b) => a.costPer1MTokens - b.costPer1MTokens);
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Meta tużaha**: Tagħbijiet tax-xogħol sensittivi għall-ispejjeż, ipproċessar f’lottijiet, jew kompiti fl-isfond.

**Aliases**: `cost`, `eco`

---

#### 3. `latency` / `fast` — l-inqas latenza p95 b’penali għall-affidabbiltà

Jissortja skont `p95LatencyMs + (errorRate * 1000)`. Il-penali għar-rata tal-iżbalji tiżgura
li l-fornituri mhux affidabbli jiġu kklassifikati aktar fil-baxx anki jekk il-latenza nominali tagħhom tkun baxxa.

```ts
class LatencyStrategyImpl implements RouterStrategy {
  readonly name = "latency";
  readonly description = "Prioritizes lowest p95 latency with reliability weighting";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort(
      (a, b) => a.p95LatencyMs + a.errorRate * 1000 - (b.p95LatencyMs + b.errorRate * 1000)
    );
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Meta tużaha**: Piżijiet tax-xogħol sensittivi għal-latenza bħal chat f’ħin reali, awtokompletament, jew
assistenti interattivi għall-ipprogrammar.

**Psewdonimi**: `latency`, `fast`

---

#### 4. `sla-aware` / `sla` — konformità mal-SLO għal-latenza/l-iżbalji/l-ispiża

Jagħti punteġġ lil kull kandidat skont kemm jissodisfa tajjeb il-politika SLO kkonfigurata:

| Fattur                 | Piż | Formula                                                   |
| ---------------------- | --- | --------------------------------------------------------- |
| Punteġġ tal-latenza    | 35% | `threshold / max(value, ε)`                               |
| Punteġġ tal-iżbalji    | 35% | `threshold / max(value, ε)`                               |
| Punteġġ tas-saħħa      | 15% | `1.0` (CLOSED) / `0.5` (HALF_OPEN) / `0.0` (OPEN)         |
| Punteġġ tal-ispiża     | 10% | `threshold / max(value, ε)` jew normalizzat inversament   |
| Punteġġ tal-istabbiltà | 5%  | devjazzjoni standard tal-latenza normalizzata inversament |

Meta `hardConstraints: true`, il-kandidati jiġu ssurtjati primarjament skont il-**punteġġ tal-ksur**
(kemm jaqbżu xi SLO), u mbagħad skont il-punteġġ kompost. Inkella jintuża biss
il-punteġġ kompost.

```ts
class SLAStrategyImpl implements RouterStrategy {
  readonly name = "sla-aware";
  readonly description =
    "Selects the provider most likely to satisfy latency, error-rate, and cost SLOs";

  select(pool, context) {
    // ... jagħti punteġġ lil kull kandidat skont il-politika: { targetP95Ms, maxErrorRate, maxCostPer1MTokens, hardConstraints }
  }
}
```

**Oqsma SLA** (issettjati fil-konfigurazzjoni combo):

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "sla-aware",
    "slaTargetP95Ms": 1500,
    "slaMaxErrorRate": 0.05,
    "slaMaxCostPer1MTokens": 5,
    "slaHardConstraints": true
  }
}
```

**Meta tużaha**: Piżijiet tax-xogħol tal-produzzjoni b’baġits stretti għal-latenza, ir-rata tal-iżbalji, jew l-ispiża.

**Psewdonimi**: `sla-aware`, `sla`

---

#### 5. `lkgp` — l-aħħar fornitur magħruf bħala tajjeb l-ewwel

Jipprova l-**aħħar fornitur magħruf bħala tajjeb** (jekk issettjat) l-ewwel, imbagħad jirrikorri għall-istrateġija
`rules`. Utli għall-persistenza tas-sessjoni — l-istess fornitur jittratta
t-talbiet ta’ segwitu f’konverżazzjoni.

```ts
class LKGPStrategyImpl implements RouterStrategy {
  readonly name = "lkgp";
  readonly description = "Tries last known good provider first, then falls back to rules";

  select(pool, context) {
    if (context.lkgpEnabled === false) {
      return getStrategy("rules").select(pool, context);
    }

    if (context.lastKnownGoodProvider) {
      const candidates = pool.filter(
        (c) => c.provider === context.lastKnownGoodProvider && c.circuitBreakerState !== "OPEN"
      );
      if (candidates.length > 0) {
        return { provider: candidates[0].provider /* ... */ };
      }
    }

    // Irrikorri għall-istrateġija rules
    return getStrategy("rules").select(pool, context);
  }
}
```

**Meta tużaha**: Konverżazzjonijiet b’diversi skambji fejn trid li l-istess fornitur jittratta
t-talbiet ta’ segwitu (eż., għall-ħażna temporanja, il-kontinwità tal-kuntest, jew il-konsistenza tal-prezzijiet).

**Psewdonimu**: `lkgp` (l-ebda psewdonimu)

### Strateġiji personalizzati tar-router

Tista’ tirreġistra l-implimentazzjoni tiegħek ta’ `RouterStrategy` permezz tal-API pubblika:

```ts
import {
  registerStrategy,
  type RouterStrategy,
} from "@omniroute/open-sse/services/autoCombo/routerStrategy";

class MyCustomStrategy implements RouterStrategy {
  readonly name = "my-custom";
  readonly description = "My custom routing strategy";

  select(pool, context) {
    // Il-loġika tar-routing tiegħek hawnhekk
    return {
      provider: pool[0].provider,
      model: pool[0].model,
      strategy: this.name,
      reason: "MyCustomStrategy: ...",
      candidatesConsidered: pool.length,
      finalScore: 1.0,
    };
  }
}

registerStrategy("my-custom", new MyCustomStrategy());
```

Imbagħad użaha:

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "my-custom"
  }
}
```

## Kif il-livelli jidħlu f’Auto-Combo

Il-funzjoni tal-punteġġ b’16-il fattur (`open-sse/services/autoCombo/scoring.ts`) tittratta s-sħubija
f’livell bħala żewġ sinjali: `tierPriority` (0.0476) u `tierAffinity` (0.0476). Ara t-
[tabella kanonika tal-fatturi tal-punteġġ](#how-it-works-persisted-auto-combos) hawn fuq għas-sett sħiħ ta’
`DEFAULT_WEIGHTS` — is-sostituzzjonijiet għal kull pakkett (ship-fast/cost-saver/quality-first/
offline-friendly) huma elenkati fit-tabella “Profili tal-piż għal kull pakkett”.

Il-livell waħdu **ma** jġegħilx lil Tier 1 jiġi l-ewwel — jekk il-latenza ta’ Tier 1 tkun ħażina jew
il-proporzjon bejn l-ispiża u l-kwalità ma jkunx ottimali, jirbaħ Tier 2. Biex timponi l-ordni tal-livelli, uża l-istrateġija
`priority` tal-combo u rranġa l-fornituri skont il-livell.

Biex tagħti preferenza qawwija lil Tier 1 (abbonament), żid il-piż ta’ `tierPriority`:

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "tierPriority": 0.3, "costInv": 0.05 } } }
}
```

Ara `docs/marketing/TIERS.md` għad-definizzjonijiet tal-livelli u l-klassifikazzjoni tal-fornituri.

Din is-suite titħaddem fis-CI (il-job `test:integration`) b’`--test-concurrency=1` u
