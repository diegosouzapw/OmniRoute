## Ħarsa ġenerali

Il-Magna tal-Kondiviżjoni tal-Kwota tqassam b'mod ġust il-kwota bbażata fuq il-ħin ta' fornitur (eż. it-tieqa ta'
5 sigħat ta' Codex, 1500 talba/siegħa ta' Kimi) bejn diversi ċwievet tal-API li jikkondividu
l-istess konnessjoni.

**Il-problema li ssolvi:** OmniRoute jgħaddi ħafna ċwievet tal-API permezz tal-istess kont
tal-fornitur upstream. Mingħajr loġika ta' kondiviżjoni, żieda f'daqqa mit-ċavetta A tista' teżawrixxi
l-kwota tal-fornitur għal dik is-siegħa, u tħalli ċ-ċwievet B u C imblukkati sakemm it-tieqa tiġi ssettjata mill-ġdid.
Il-magna tipprevjeni dan billi:

1. Issegwi l-konsum kontinwu ta' kull ċavetta għal kull dimensjoni (%, talbiet, tokens, $).
2. Tapplika algoritmu ta' sehem ġust li jikkonserva x-xogħol: ċavetta tista' tissellef minn ishma
   mhux użati sakemm il-ġabra globali ma tkunx saturata.
3. Tinforza r-riżultat fil-mogħdija kritika (`chatCore.ts`) qabel ma t-talba
   tasal għand l-eżekutur upstream.

## Algoritmu: Sehem Ġust li Jikkonserva x-Xogħol

Implimentat f'`src/lib/quota/fairShare.ts`.

### Modi

| Kundizzjoni                                | Mod         | Imġiba                                                                            |
| ------------------------------------------ | ----------- | --------------------------------------------------------------------------------- |
| `globalUsedPercent < saturationThreshold`  | **Ġeneruż** | Iċ-ċavetta tista' tissellef sal-limitu globali bit-total ikkunsmat imnaqqas minnu |
| `globalUsedPercent >= saturationThreshold` | **Strett**  | Jinforza strettament is-sehem ġust individwali                                    |

Il-valur predefinit huwa `saturationThreshold = 0.5` (varjabbli tal-ambjent `QUOTA_SATURATION_THRESHOLD`).

### Deċiżjoni għal kull dimensjoni

Għal kull dimensjoni attiva fil-ġabra, il-magna tikkalkula:

```
fairShareAllowed = poolLimit × (allocationWeight / 100)
consumed        = il-valur kontinwu attwali għal din iċ-ċavetta (minn QuotaStore.peek)
remaining       = fairShareAllowed - consumed
```

Imbagħad:

- **`policy = hard`**: jekk `consumed > fairShareAllowed` u l-mod ikun strett → **ibblokka**.
- **`policy = soft`**: jekk `consumed > fairShareAllowed` u l-mod ikun strett → **ippenalizza** (agħti prijorità aktar baxxa fil-kombinazzjoni; qatt timblokka għalkollox).
- **`policy = burst`**: ippermetti sakemm ikun għad hemm kapaċità globali, irrispettivament mis-sehem ġust.

### Limitu assolut

`capValue` + `capUnit` fuq allokazzjoni huma limitu massimu strett, indipendenti mill-mod jew
mill-politika. Kwalunkwe dimensjoni fejn `consumed >= capValue` dejjem **timblokka** t-talba.

### Verifika ta' diversi dimensjonijiet

Talba tiġi mblukkata jekk **kwalunkwe** dimensjoni fil-ġabra timblokkaha. Id-dimensjonijiet
huma indipendenti — l-eżawriment ta' 5h% ma jaffettwax id-dimensjoni weekly%.

### Self

Fil-mod ġeneruż, ċavetta li l-allokazzjoni tagħha tkun ġiet ikkunsmata inqas milli suppost tista' tuża l-eċċess mill-
ishma mhux allokati ta' ċwievet oħra. Il-formula hija:

```
maxAllowed = globalLimit - consumedByOtherKeys
```

fejn `consumedByOtherKeys = consumedTotal - consumedByThisKey`. Il-limitu massimu globali
(`limit` tal-ġabra għal dik id-dimensjoni) huwa dejjem il-limitu massimu strett.

## Għadd Integrat fuq Tieqa Mobbli

Implimentat f'`src/lib/quota/sqliteQuotaStore.ts` u `redisQuotaStore.ts`.

Żewġ kompartimenti għal kull `(apiKeyId, dimensionKey)`:

- `curr`: il-kompartiment attwali (`floor(nowMs / windowMs)`)
- `prev`: il-kompartiment preċedenti (`curr - 1`)

Valur kontinwu effettiv:

```
effectiveBucketIndex = floor(nowMs / windowMs)
bucketStartMs        = effectiveBucketIndex × windowMs
elapsed              = nowMs - bucketStartMs
weight               = 1 - elapsed / windowMs

effective = prev × weight + curr
```

**Preċiżjoni**: preċiż għal madwar 99%. L-iżball huwa ta' mhux aktar minn 1% tad-daqs tat-tieqa fil-
konfini bejn il-kompartimenti (inerenti għall-approssimazzjoni b'żewġ kompartimenti).

### Konkorrentiżmu

Driver ta' SQLite: mutex fil-memorja għal kull ċavetta `(apiKeyId | dimensionKey)` jipprevjeni l-
kundizzjoni ta' tellieqa bejn il-qari, il-modifika u l-kitba. Id-disinn isegwi l-mudell kontra t-thundering herd ta' `src/sse/services/auth.ts`.

Driver ta' Redis: skript Lua EVAL għal inkrement atomiku — jitħaddem bħala kmand wieħed ta' Redis.

### SQLite (predefinit, mingħajr installazzjoni)

- Tabella: `quota_consumption` (ara l-migrazzjoni `073_quota_pools.sql` / `074_quota_consumption.sql`).

### Redis (fakultattiv, b’diversi istanzi)

- Jeħtieġ il-pakkett npm `ioredis`.
- Il-kontaturi jinħażnu f’Redis; il-metadejta (pools/allokazzjonijiet) tibqa’ f’SQLite.
- L-aħjar għal skjeramenti b’diversi repliki fejn il-kontaturi jridu jkunu kondiviżi.

### Qlib bejn is-sewwieqa

Permezz tal-interfaċċa tas-settings (`/dashboard/settings` → Ħażna tal-Kwoti), jew permezz ta’ varjabbli tal-ambjent:

```bash
QUOTA_STORE_DRIVER=redis
QUOTA_STORE_REDIS_URL=redis://localhost:6379
```

Is-setting tad-DB għandu preċedenza fuq l-ambjent. Jekk `driver=redis` iżda l-URL huwa nieqes jew
`ioredis` mhuwiex installat, il-fabbrika terġa’ taqleb għal SQLite u tirreġistra twissija fil-log.

Ordni tal-għażla tas-sewwieq:

1. Setting tad-DB `quotaStore.driver`
2. Varjabbli tal-ambjent `QUOTA_STORE_DRIVER`
3. Predefinit: `sqlite`

## Integrazzjoni fil-Pipeline

### Hook PRE (`open-sse/handlers/chatCore.ts`)

Jitħaddem qabel l-eżekutur upstream, wara l-kontrolli tal-awtentikazzjoni u tal-politika:

```
resolveComboTargets / handleSingleModel
  → enforceQuotaShare(apiKeyId, connectionId, provider, estimatedCost)
      → getQuotaStore().peek() għal kull dimensjoni
      → fairShare.decideFairShare()
      → jekk imblukkat → irritorna 429 (buildErrorBody, Regola Stretta #12)
      → jekk permess + tnaqqis fil-prijorità → issettja quotaSoftPenalty=true fuq il-kandidat
  → executor.execute()
```

**Fail-open**: jekk `enforceQuotaShare` jitfa’ eċċezzjoni, it-talba titħalla tgħaddi
b’reġistrazzjoni `pino.warn` fil-log. Dan jipprevjeni bug fil-magna tal-kwoti milli jimblokka t-traffiku
kollu.

### Hook POST (irreġistra l-konsum)

Wara tweġiba b’suċċess:

```
l-eżekutur jirritorna suċċess
  → spendRecorder.recordConsumption(apiKeyId, connectionId, provider, actualCost)
      → getQuotaStore().consume() għal kull dimensjoni
      → fail-open: l-iżbalji jiġu rreġistrati bħala pino.warn, u qatt ma jiġu propagati lill-klijent
```

**Nota dwar id-devjazzjoni**: jekk `consume` ifalli wara t-tweġiba, il-kontatur kontinwu jirreġistra konsum aktar baxx minn dak reali.
Is-sinjal ta’ saturazzjoni mill-fornitur (eż. `anthropic-ratelimit-unified-5h-utilization`)
jikkoreġi l-istima globali mat-talba li jmiss.

### Penali ratba għall-combo (`open-sse/services/combo.ts`)

Meta `decision.deprioritize === true`:

```ts
if (candidate.quotaSoftPenalty) {
  score *= QUOTA_SOFT_DEPRIORITIZE_FACTOR; // valur predefinit 0.7
}
```

Il-penali tiġi applikata wara l-fatturi l-oħra kollha tal-punteġġ. Din tnaqqas il-probabbiltà li l-auto-combo
jagħżel ċavetta saturata mingħajr ma jimblokkaha kompletament.

## Soluzzjoni tal-Problemi

### Redis huwa kkonfigurat iżda mhux qed jikkonnettja

Iċċekkja li `ioredis` huwa installat (`npm ls ioredis`) u li `QUOTA_STORE_REDIS_URL`
huwa aċċessibbli. Jekk il-konnessjoni tfalli, il-factory jaqleb lura għal SQLite (irreġistrat bħala
`warn`).

### `peek` jirritorna data skaduta / fail-open

Jekk `peek` joħroġ żball, `enforceQuotaShare` jittratta r-riżultat bħala "ippermetti" (fail-open).
Iċċekkja l-logs ta’ `pino` għal entrati `quota:enforce` u `quota:factory` biex tidentifika
l-kawża ewlenija.

### Devjazzjoni fil-counter tal-konsum

Jekk l-użu reali tal-fornitur ikun differenti mill-counters, dan huwa mistenni — it-tieqa
li tiżżerżaq b’2 buckets għandha żball ta’ madwar 1% fil-konfini tat-tieqa, u `consume`
jitħaddem mingħajr stennija wara r-rispons. Is-sinjal tas-saturazzjoni (`saturationSignals.ts`)
jaqra l-utilizzazzjoni reali tal-fornitur b’TTL ta’ 30 sekonda u jaġġusta `globalUsedPercent`
kif meħtieġ.

### Il-pool juri "ebda data" għar-rata ta’ konsum

`computeBurnRate` jeħtieġ mill-inqas 2 kampjuni storiċi. Pools ġodda mingħajr sejħiet
preċedenti lil `consume` juru `tokensPerSecond: 0` u `timeToExhaustionMs: null`.

## Sommarju tal-Iskema tad-DB

Tliet tabelli miżjuda mill-migrazzjonijiet `078`, `079` u `085`:

- `quota_pools` + `quota_allocations` — definizzjonijiet tal-pools u allokazzjonijiet għal kull key.
- `quota_consumption` — counters kontinwi b’2 buckets għal kull `(apiKeyId, dimensionKey)`.
- `provider_plans` — overrides manwali tal-pjanijiet tal-fornituri (dimensjonijiet JSON għal kull connectionId).

It-tabelli kollha ġew miżjuda permezz ta’ migrazzjonijiet idempotenti `CREATE TABLE IF NOT EXISTS`.
