[Il-Ħarġa #7854](https://github.com/diegosouzapw/OmniRoute/issues/7854). Il-prodotti pubbliċi huma
rrappreżentati bħala erba’ familji ta’ fornituri. Ir-reġjun huwa data tal-konnessjoni, mhux prodott separat.

## Deċiżjoni

| Familja tal-fornitur                            | ID ta’ OmniRoute        | Reġjun globali | Reġjun taċ-Ċina |
| ----------------------------------------------- | ----------------------- | -------------- | --------------- |
| Alibaba Cloud Model Studio (ħallas skont l-użu) | `alibaba`               | Singapore      | Beijing         |
| Alibaba Cloud Token Plan                        | `bailian-coding-plan`   | Singapore      | Beijing         |
| Qwen Cloud (ħallas skont l-użu)                 | `qwen-cloud`            | Global         | Beijing         |
| Qwen Cloud Token Plan                           | `qwen-cloud-token-plan` | Singapore      | Beijing         |

L-ID eżistenti `alibaba-cn` jibqa’ alias ta’ kompatibbiltà waqt l-eżekuzzjoni għal konnessjonijiet salvati, rotot
tal-mudelli, kombinazzjonijiet, u użu storiku. Il-kard tiegħu fid-dashboard hija inkorporata f’`alibaba`; mhi meħtieġa
ebda kitba mill-ġdid tad-database.

Il-prodott Qwen Cloud bi ħlas skont l-użu u Alibaba Cloud Model Studio bħalissa jużaw l-istess hosts waqt l-eżekuzzjoni
kompatibbli ma’ DashScope, iżda jibqgħu identitajiet ta’ fornituri separati minħabba li l-utenti jiksbu ċ-ċwievet u jimmaniġġjaw
il-kontijiet permezz ta’ interfaċċi ta’ prodotti differenti. Il-prodotti Alibaba u Qwen Cloud Token Plan jużaw
familji differenti ta’ endpoints, għalhekk l-erba’ prodotti kollha jibqgħu IDs ta’ fornituri separati.

## Matriċi tal-endpoints

| Familja tal-fornitur    | `global-sg`                                                              | `china-beijing`                                                      | Format tat-trażmissjoni |
| ----------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------- | ----------------------- |
| `alibaba`               | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI                  |
| `bailian-coding-plan`   | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/apps/anthropic/v1`  | `https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic/v1`  | Anthropic               |
| `qwen-cloud`            | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI                  |
| `qwen-cloud-token-plan` | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` | `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | OpenAI                  |

Iċ-ċavetta tal-API u l-endpoint iridu jappartjenu għall-istess prodott u reġjun. L-għażla ta’ reġjun tibdel
l-endpoint issettjat minn qabel li jintuża għall-validazzjoni u għat-talbiet normali.

## Kuntratt tal-konnessjoni

Konnessjonijiet ġodda jaħżnu ċ-ċavetta stabbli tar-reġjun f’`providerSpecificData`:

```json
{
  "region": "global-sg"
}
```

Il-valuri permessi huma `global-sg` u `china-beijing`. L-endpoint jiġi derivat ċentralment mill-
ID tal-fornitur u mir-reġjun. `providerSpecificData.baseUrl` li mhuwiex issettjat minn qabel jibqa’ override espliċitu tal-operatur
u jieħu preċedenza, filwaqt li URLs issettjati minn qabel u salvati qabel jiġu normalizzati lura għall-matriċi
reġjonali.

Dan iżomm l-iskema tal-konnessjoni estensibbli: jista’ jiżdied reġjun ieħor mar-resolver mingħajr
ma tinħoloq kard oħra tal-fornitur jew jinbidlu l-IDs tal-fornituri salvati.

## Kompatibbiltà u introduzzjoni gradwali

1. Żid ir-resolver tal-endpoint reġjonali u żomm il-valuri prestabbiliti globali attwali.
2. Uża l-iskoperta diretta reġjonali ta’ DashScope `/models` għal `alibaba`, l-ID ta’ kompatibbiltà tiegħu `alibaba-cn`, u `qwen-cloud`. It-tweġibiet tagħhom l-ewwel jgħaddu minn filtru wieħed għall-ġenerazzjoni tat-test, għax l-endpoint ġeneriku jirritorna wkoll mudelli tal-immaġnijiet, tal-vidjow, tal-awdjo, tal-embeddings, u mudelli oħra li mhumiex taċ-chat. Imbagħad `qwen-cloud` japplika l-lista ta’ permessi miżmuma ddikjarata fir-reġistru tal-fornitur tiegħu. Alibaba Model Studio u Qwen Cloud iżommu katalgi kkurati separati minkejja li bħalissa jużaw l-istess hosts waqt it-tħaddim.
3. Irreġistra `qwen-cloud-token-plan` bil-lista ta’ permessi attwali tal-mudelli tat-test tat-Token Plan.
4. Żid selettur tar-reġjun b’tip definit mad-djalogi għaż-żieda/modifika ta’ konnessjoni.
5. Aħbi l-kard duplikata `alibaba-cn` u inkludi l-konnessjonijiet eżistenti tagħha fil-paġna tal-fornitur `alibaba`.
6. Żomm is-sostituzzjonijiet personalizzati tal-endpoint disponibbli għal skjeramenti avvanzati u speċifiċi għall-workspace.

Il-mudelli tal-midja tat-Token Plan jibqgħu barra mill-katalgu taċ-chat għax jużaw endpoints iddedikati.
`wan2.7-image` u `wan2.7-image-pro` huma rreġistrati f’`open-sse/config/imageRegistry.ts`;
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, u `happyhorse-1.1-r2v` huma rreġistrati
f’`open-sse/config/videoRegistry.ts`. Iż-żewġ reġistri jerġgħu jużaw l-identità tal-konnessjoni
`qwen-cloud-token-plan` u l-kredenzjali speċifiċi għar-reġjun tagħha.

Il-Qwen Cloud regolari għandu katalgi separati tal-immaġnijiet u tal-vidjow bi ħlas skont l-użu taħt
l-identità `qwen-cloud`. Il-mudelli tal-immaġnijiet tiegħu huma `wan2.7-image-pro`, `wan2.7-image`,
`qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0-2026-03-03`, u
`z-image-turbo`. Il-mudelli tal-vidjow tiegħu huma `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`,
`happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`, `wan2.7-t2v`, `wan2.7-i2v`,
`wan2.7-r2v-2026-06-12`, u `wan2.7-videoedit`. Dawn il-mudelli jerġgħu jużaw biss il-konnessjoni
regolari `qwen-cloud` u l-endpoint reġjonali tal-midja ta’ DashScope. Ir-reġistri tat-Token Plan u
dawk bi ħlas skont l-użu la jirtu u lanqas jgħaqqdu l-listi tal-mudelli ta’ xulxin.

L-identità `bailian-coding-plan` għandha wkoll il-listi ta’ permessi tal-midja tagħha stess:
`wan2.7-image`, `wan2.7-image-pro`, `qwen-image-2.0`, u `qwen-image-2.0-pro` għall-ġenerazzjoni
tal-immaġnijiet, flimkien ma’
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, u `happyhorse-1.1-r2v` għall-ġenerazzjoni
tal-vidjow. Din tuża biss il-konnessjoni ta’ Bailian Coding Plan u l-endpoint reġjonali ta’ Coding Plan.
Ir-reġistri tal-immaġnijiet u tal-vidjow tagħha la jirtu minn u lanqas jingħaqdu ma’ xi wieħed mill-fornituri ta’ Qwen Cloud.

L-identità regolari `alibaba` għandha listi ta’ permessi separati għall-immaġnijiet u għall-vidjow. Il-mudelli tal-immaġnijiet tagħha huma
`qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0`,
`z-image-turbo`, u `wan2.6-t2i`. Il-mudelli tal-vidjow miżjuda tagħha huma `happyhorse-1.1-i2v`,
`happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`,
`wan2.7-i2v-2026-04-25`, `wan2.6-i2v-flash`, `wan2.7-t2v-2026-06-12`,
`wan2.7-r2v-2026-06-12`, u `wan2.7-videoedit`. Dawn il-mudelli jużaw biss il-konnessjoni ta’ Alibaba Model Studio
u l-endpoint reġjonali tal-midja magħżul tagħha; ma jiżdiedu ma’ ebda reġistru ta’ Coding Plan jew Qwen
Cloud.

Il-katalgu taċ-chat tal-Qwen Cloud Token Plan isegwi l-lista eżatta ta’ permessi tat-test tal-pjan Individual:
`qwen3.8-max-preview`, `qwen3.7-max`, `qwen3.7-plus`, `qwen3.6-flash`, `glm-5.2`, u
`deepseek-v4-pro`. L-entrati Wan u HappyHorse jappartjenu għall-APIs separati tal-ġenerazzjoni tal-immaġnijiet/vidjow.

Alibaba Token Plan jesponi l-istess sitt IDs attwali tal-mudelli għall-ġenerazzjoni tat-test permezz tal-endpoint tiegħu
kompatibbli ma’ Anthropic. L-għażla tiegħu ta’ Singapore taħżen iċ-ċavetta tar-reġjun eżistenti `global-sg`;
hija biss it-tikketta li tidher lill-utent li tvarja mill-familji ta’ fornituri li jsejħu r-reġjun Global.

Il-katalgu regolari taċ-chat ta’ Qwen Cloud huwa intenzjonalment idjaq mit-tweġiba diretta sħiħa tat-test. Il-lista
ta’ permessi miżmuma tiegħu tinsab f’`open-sse/config/providers/registry/qwen-cloud/index.ts`; l-iskoperta
diretta tirritorna biss IDs preżenti kemm fit-tweġiba upstream kif ukoll f’dik il-lista tar-reġistru.

Alibaba Model Studio isegwi l-istess regola ta’ intersezzjoni diretta bil-lista ta’ permessi tiegħu, miżmuma b’mod indipendenti,
f’`open-sse/config/providers/registry/alibaba/index.ts`. Il-fornitur ta’ kompatibbiltà `alibaba-cn`
jerġa’ juża dak il-katalgu filwaqt li jirriżolvi l-iskoperta mal-endpoint ta’ Beijing.
