`copilot-m365-web` (magħruf ukoll bħala `m365copilot`) jibgħat talbiet taċ-chat fil-format OpenAI permezz ta’
sessjoni awtentikata tal-browser ta’ Microsoft 365 Copilot BizChat fuq
`m365.cloud.microsoft/chat`. Din hija integrazzjoni mhux uffiċjali.

> **Għadek kif bdejt tuża fornituri tal-Web Cookie?**
>
> Aqra **`docs/getting-started/WEB-COOKIE-GUIDE.md`** għall-proċess ġenerali tal-konfigurazzjoni, gwida dwar l-awtentikazzjoni, limitazzjonijiet, u soluzzjoni tal-problemi qabel issegwi din il-gwida speċifika għall-fornitur.
>
> **Importanti:** Il-kredenzjali għal dan il-fornitur **mhijiex cookie**. Tikkupjax
> cookies minn `m365.cloud.microsoft`. Il-kredenzjali hija parametru tal-query ta’ URL tal-WebSocket
> u segment tal-path, it-tnejn moqrija mit-tab Network ta’ DevTools.

## Prerekwiżiti

- Kont ta’ Microsoft 365 b’aċċess għal BizChat fuq `m365.cloud.microsoft/chat`
- Browser ibbażat fuq Chromium (Chrome, Edge) għall-ispezzjoni tal-WebSocket f’DevTools
- Liċenzja ta’ M365 Copilot (inkluża ma’ ħafna pjanijiet Microsoft 365 Business/Enterprise)

## Qbid tal-kredenzjali (metodu WebSocket)

1. Idħol fuq `https://m365.cloud.microsoft/chat` u ibda konverżazzjoni.
2. Iftaħ **DevTools → Network**.
3. Iffiltra skont **WS** (WebSocket).
4. Ikklikkja l-konnessjoni WebSocket ta’ Chathub. Fittex URL li jibda b’
   `wss://substrate.office.com/m365Copilot/Chathub/`.
5. Mill-**Request URL** tagħha, ikkopja:
   - Il-valur tal-parametru tal-query `access_token` (JWT b’ħajja qasira).
   - Is-segment tal-path ta’ Chathub wara `/Chathub/` (eż. `<oid>@<tenant>`).

Il-URL sħiħ għandu din il-forma:

```
wss://substrate.office.com/m365Copilot/Chathub/<oid>@<tenant>?...&access_token=<jwt>
```

6. F’OmniRoute, mur **Providers → Add Provider**, agħżel **Microsoft 365 Copilot
   (BizChat)**, u waħħal il-kredenzjali fil-format:

```
access_token=<jwt>; chathubPath=<oid>@<tenant>
```

7. Ikklikkja **Test Connection** u **Save**.

## Qbid tal-kredenzjali (importazzjoni HAR)

Minflok tikkopja l-valuri manwalment mill-URL tal-WebSocket, tista’ tesporta fajl HAR minn DevTools:

1. Iftaħ **DevTools → Network**.
2. Ibda jew kompli konverżazzjoni f’BizChat (dan jattiva l-konnessjoni WebSocket).
3. Ikklikkja bil-lemin fil-pannell Network u agħżel **Save all as HAR with content**.
4. F’OmniRoute, uża l-buttuna **Import .har file** fid-djalogu tal-konnessjoni tal-fornitur.

OmniRoute jiskennja l-HAR għall-URL tal-WebSocket ta’ Chathub, jestratta
`access_token` u `chathubPath`, u jimla l-oqsma tal-kredenzjali awtomatikament. L-importazzjoni
tal-HAR tiddekodifika l-iskadenza tal-JWT u turi kemm fadal żmien qabel jiskadi t-token.

> **Qatt tikkommetti esportazzjoni HAR reali, access token, jew refresh token.** Il-valuri tat-test u
> tad-dokumentazzjoni għandhom dejjem ikunu placeholders.

## Tul ta’ ħajja u tiġdid tat-token

L-`access_token` għandu ħajja qasira (tipikament **~75 minuta**). Wara li jiskadi, il-fornitur
jirrapporta żball fil-konnessjoni u jkollok terġa’ taqbad il-kredenzjali.

### Tiġdid awtomatiku b’`refreshToken`

Biex tevita li terġa’ taqbadha manwalment, tista’ taħżen refresh token ta’ Microsoft fis-
**Advanced Settings → providerSpecificData** tal-konnessjoni:

| Qasam          | Deskrizzjoni                                                                 |
| -------------- | ---------------------------------------------------------------------------- |
| `refreshToken` | Refresh token ta’ Microsoft OAuth għall-ambitu `substrate.office.com/sydney` |
| `tier`         | `individual` (predefinit), `edu`, jew `enterprise`                           |

Ikseb ir-refresh token minn fluss ta’ device-code jew authorization-code ta’ Microsoft
bl-ambitu `substrate.office.com/sydney`. Meta `refreshToken` ikun issettjat, OmniRoute
iġedded minn qabel l-`access_token` qabel kull talba, għalhekk ma jkollokx għalfejn
terġa’ taqbdu wara kull skadenza ta’ madwar 75 minuta.

Jekk `refreshToken` ma jkunx issettjat, ikollok terġa’ taqbad il-kredenzjali tal-WebSocket manwalment
wara kull skadenza.

### Għażla tal-livell

| Livell       | Alias          | Interfaċċa                     |
| ------------ | -------------- | ------------------------------ |
| `individual` | _(predefinit)_ | M365 Copilot għall-konsumaturi |
| `edu`        | `included`     | M365 Copilot għall-edukazzjoni |
| `enterprise` | `work`         | M365 Copilot għax-xogħol       |

Issettja l-livell f’**Advanced Settings → providerSpecificData → tier**. Il-livell jaffettwa
r-routing ta’ BizChat u l-aċċess għall-mudelli.

## Mudell tas-sigurtà

- **Integrazzjoni mhux uffiċjali.** Dan il-fornitur jagħmel reverse engineering tal-protokoll WebSocket ta’ BizChat. Jista’ jieqaf jaħdem mingħajr avviż meta Microsoft tibdel l-endpoint.
- Il-flag `subscriptionRisk: true` jirrifletti li l-integrazzjoni tiddependi fuq endpoint mhux dokumentat. Restrizzjonijiet fuq il-kont huma possibbli iżda mhux ikkonfermati.
- It-token tal-aċċess huwa JWT b’validità qasira. Ittrattah bħal password: tikkommettihx, tirreġistrahx fil-logs, u tikkondividihx.
- It-token ta’ tiġdid jagħti aċċess fit-tul għall-interfaċċa ta’ BizChat. Aħżnu bl-istess attenzjoni bħal API key.

## Soluzzjoni tal-problemi

### L-awtentikazzjoni tfalli minnufih

- Ivverifika li kkupjajt mill-**URL tal-WebSocket**, mhux minn talba XHR/Fetch. Il-kredenzjali tinsab fil-parametru tal-query `access_token` tal-konnessjoni WebSocket ta’ Chathub — mhux f’header `Authorization: Bearer`.
- Kun żgur li `chathubPath` jinkludi s-segment sħiħ `<oid>@<tenant>` mill-path tal-URL.

### It-token jiskadi wara madwar 75 minuta

Dan huwa mistenni. Mingħajr `refreshToken`, it-token tal-aċċess ikollu validità qasira. Tista’ jew:

- Terġa’ taqbad il-kredenzjali minn DevTools, jew
- Tikkonfigura `refreshToken` f’Advanced Settings għal tiġdid awtomatiku.

### Test Connection jirnexxi iżda ċ-chat jirritorna 401

It-token jista’ jkun skada bejn il-validazzjoni u l-ewwel talba. Erġa’ aqbad kredenzjali ġdida.

### Copilot ma jidhirx fil-lista tal-fornituri

Kun żgur li `copilot-m365-web` huwa attivat f’**Dashboard → Providers**. Il-fornitur jista’ jkun moħbi awtomatikament f’ċerti livelli.
