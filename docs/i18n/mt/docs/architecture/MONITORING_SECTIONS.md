## Navigazzjoni ta' Livell Għoli

L-istrixxa tal-ġenb tad-dashboard (wara Grupp B) għandha dawn it-taqsimiet tal-ogħla livell, f'din l-ordni:

```
Paġna Ewlenija
Fornituri
Kombinazzjonijiet
Ċwievet tal-API
Settings
Analitika
Spejjeż          ← ĠDID (Grupp B, pjan 16)
Monitoraġġ       ← ORGANIZZAT MILL-ĠDID (Grupp B, pjan 16)
...
```

## Taqsima tal-Ispejjeż (ġdida, livell 1)

Prefiss tal-perkors: `/dashboard/costs/`

| Element                  | URL                                  | Deskrizzjoni                                              |
| ------------------------ | ------------------------------------ | --------------------------------------------------------- |
| Ħarsa Ġenerali           | `/dashboard/costs`                   | Dashboard aggregat tal-ispejjeż (imċaqlaq mill-Analitika) |
| Ipprezzar                | `/dashboard/costs/pricing`           | Tabella tal-ipprezzar għal kull mudell                    |
| Baġit                    | `/dashboard/costs/budget`            | Limiti tal-baġit + twissijiet                             |
| Kondiviżjoni tal-Kwota   | `/dashboard/costs/quota-share`       | Pools tal-Kondiviżjoni tal-Kwota + użu                    |
| Konfigurazzjoni tal-Pjan | `/dashboard/costs/quota-share/plans` | Sostituzzjonijiet tal-pjan għal kull fornitur             |

**Raġuni**: L-Ipprezzar, il-Baġit u l-Kondiviżjoni tal-Kwota qabel kienu taħt
`Monitoring > Costs Parameters`. Iċ-ċaqliq tagħhom għal taqsima ddedikata tal-ogħla livell
jagħmilhom faċli biex jinstabu mingħajr il-ħtieġa li wieħed jinnaviga fl-għodod tal-osservabbiltà.

## Taqsima tal-Monitoraġġ (organizzata mill-ġdid)

It-taqsima tal-Monitoraġġ issa għandha **Attività fil-parti ta' fuq**, segwita minn **3 sottogruppi**:

```
Monitoraġġ
├── Attività             ← Feed kronoloġiku (element tal-ogħla livell)
├── Grupp tar-Reġistri
│   ├── Reġistri (kollha)
│   ├── Reġistri tal-Proxy
│   └── Reġistri tal-Console
├── Grupp tal-Awditjar
│   ├── Reġistru tal-Awditjar
│   ├── Awditjar MCP
│   └── Awditjar A2A
└── Grupp tas-Sistema
    ├── Saħħa
    └── Runtime
```

### X'inbidel mill-istruttura l-qadima

| Qabel                                                                                         | Wara                                                   |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| Attività = tab ġewwa r-Reġistri li kien juri r-Reġistru tal-Awditjar                          | Attività = feed iddedikat (`/dashboard/activity`)      |
| Grupp tal-Parametri tal-Ispejjeż fil-Monitoraġġ                                               | Imċaqlaq għat-taqsima tal-Ispejjeż                     |
| Lista ċatta: Reġistri, Attività (reġistri), Awditjar, Saħħa, Runtime, Ipprezzar, Baġit, Kwota | Struttura bi 3 gruppi + taqsima ddedikata tal-Ispejjeż |

## Attività u Reġistru tal-Awditjar

Dawn it-tnejn issa huma distinti:

| Dimensjoni             | Attività (`/dashboard/activity`)                                      | Reġistru tal-Awditjar (`/dashboard/audit`) |
| ---------------------- | --------------------------------------------------------------------- | ------------------------------------------ |
| **Għan**               | Feed ta' avvenimenti għall-utent ("x'ġara dan l-aħħar")               | Reġistru ta' konformità / sigurtà          |
| **Sors tad-data**      | `GET /api/compliance/audit-log?level=high`                            | `GET /api/compliance/audit-log?level=all`  |
| **Format**             | Kronoloġija, miġbura skont il-jum, verbi li jinqraw faċilment + ikoni | Tabella densa b'paġnazzjoni, 50/paġna      |
| **Filtri**             | Kategorija tat-tip ta' avveniment                                     | Azzjoni, severità, attur, medda ta' dati   |
| **Esportazzjoni**      | Mhux disponibbli                                                      | Esportazzjoni JSON                         |
| **Filtru tal-attur**   | Mhux applikabbli                                                      | Jista' jiġi ffiltrat skont l-attur         |
| **Avvenimenti murija** | Azzjonijiet ta' livell għoli biss (lista permessa)                    | L-avvenimenti kollha tal-awditjar          |

### Lista permessa ta' Azzjonijiet ta' Livell Għoli

Iddefinita f'`src/lib/audit/highLevelActions.ts`. Tikkontrolla liema avvenimenti jidhru fil-
feed tal-Attività. Il-lista permessa tinkludi:

- Avvenimenti taż-żieda/tneħħija/ittestjar ta' fornitur
- Ħolqien/aġġornament/tħassir ta' kombinazzjoni
- Ċiklu tal-ħajja taċ-ċavetta tal-API (ħolqien, revoka, rotazzjoni)
- Ilħuq tal-limitu tal-baġit
- Login/logout tal-awtentikazzjoni
- Ħolqien ta' sessjoni ta' aġent tal-cloud
- Reġistrazzjoni ta' għodda MCP
- Ħolqien/tħassir ta' webhook
- Bidliet fil-pool/pjan tal-kwota (azzjonijiet `quota.*`, Grupp B)
- Avvenimenti tal-pjattaforma (aġġornament, deployment)
- Installazzjoni/tneħħija ta' ħila

Avvenimenti li mhumiex f'din il-lista jidhru biss fir-Reġistru tal-Awditjar.

### Żieda ta' azzjoni ġdida ta' livell għoli

Editja `src/lib/audit/highLevelActions.ts` u żid is-sekwenza tal-azzjoni ma'
`HIGH_LEVEL_ACTIONS`. Dan jeħtieġ PR (il-lista hija kodiċi, mhux konfigurabbli mid-DB).
L-ikona korrispondenti tista' tiżdied ma' `src/lib/audit/activityIcons.ts`.

## Ridirezzjoni: `/dashboard/logs/activity`

Il-perkors il-qadim `/dashboard/logs/activity` jiġi ridirett b'mod permanenti (HTTP 308) lejn
`/dashboard/activity` permezz ta' `permanentRedirect()` f'
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

L-ID preċedenti tal-istrixxa tal-ġenb `logs-activity` huwa ppreservat f'`HIDEABLE_SIDEBAR_ITEM_IDS`
(iżda tneħħa minn `SIDEBAR_DEFINITIONS`) sabiex ma jitkissrux il-presets tal-utenti li
jirreferu għall-ID il-qadim.

## i18n

Namespaces miżjuda minn Grupp B:

| Ċavetta tan-namespace   | Tkopri                                                                      |
| ----------------------- | --------------------------------------------------------------------------- |
| `sidebar.costsSection`  | Tikketta tat-taqsima tal-Ispejjeż                                           |
| `sidebar.activity`      | Element tal-Attività fl-istrixxa tal-ġenb                                   |
| `sidebar.logsGroup`     | Tikketta tas-sottogrupp tar-Reġistri                                        |
| `sidebar.systemGroup`   | Tikketta tas-sottogrupp tas-Sistema                                         |
| `sidebar.costsOverview` | Element tal-ħarsa ġenerali lejn l-ispejjeż                                  |
| `activity.*`            | Is-sekwenzi kollha tal-paġna tal-Attività (titlu, verbi, filtri, stat vojt) |

Il-lokalitajiet tas-sors awtorevoli huma: `pt-BR` u `en`. L-40 lokalità l-oħra kollha jużaw
l-Ingliż bħala riżerva permezz tal-mekkaniżmu ta' fallback ta' `next-intl` (ikkonfigurat f'`src/i18n/config.ts`).
