## 1. Verità bażi tas-servizz (dokumentazzjoni uffiċjali, kontroverifikata)

- URL bażi: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - parametri: `query` (meħtieġ), `max_results` (1-10, valur predefinit 10), `tag` (`{domain}.{sub_domain}` direzzjonar vertikali), `zone` (cn/intl), `language`, `params` (oqsma vertikali strutturati), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - katalgu tal-kapaċitajiet, MA jgħoddx mal-kwota.
- `POST /v1/extract` - iġib/jestratta `{url, title, content}`; korp JSON strett, limitu ta' 16 KiB.
- `POST /v1/auth/email/register` - reġistrazzjoni b'sejħa waħda, jirritorna ċavetta f'test ċar ta' darba `as_sk_...`.
- Awtentikazzjoni: `Authorization: Bearer <as_sk_...>` fakultattiva; aċċess anonimu jiġi degradat għal limiti għal kull IP li jikkunsmaw il-kwota bla ħlas ta' kuljum; ċavetta invalida tirritorna 401/403 MINGĦAJR fallback anonimu sieket.
- Livell bla ħlas: 1000 talba/jum, 20 QPS għal kull ċavetta. Livell bi ħlas: prezz għadu mhux stabbilit (Dalwaqt).
- Envelopp tar-rispons: suċċess `{code: 0, message: "success", request_id, data}`; falliment `{code: -1, message}`. L-iżbalji tal-awtentikazzjoni/tal-kwota ma jinkludux `error_code` strutturat (it-test tal-messaġġ huwa s-sinjal); l-iżbalji speċifiċi għall-estrazzjoni jinkludu `error_code` (`invalid_extract_url`, `extract_failed`). Ebda header `Retry-After` fuq 429.

## 3. Deċiżjonijiet (kollha milħuqa 2026-08-26)

1. **Pożizzjoni tar-routing: `fallbackOnly`.** Raġuni: fornitur bla ħlas bi spiża 0 qatt ma għandu jiddomina r-routing awtomatiku skont l-ispiża; l-għażla espliċita u r-ritorn għall-failover ma jiġux affettwati. Preċedent: l-entrata xquik li ġiet integrata.
2. **Ambitu: webSearch + webFetch permezz ta’ `POST /v1/extract` fil-v1.** Allinjat mal-mudell mentali ta’ kapaċità doppja ta’ tavily/exa. Is-superfiċji vertikali (`tag`, `sub-domains`, `batch_search`) jibqgħu barra mill-ambitu — illum ma jeżisti l-ebda IR għall-parametri vertikali.
3. **Wiri tal-kwota: `freeMonthlyQuota: 0`** (wiri konservattiv fl-istil ta’ xquik). L-allokazzjoni reali (1000 talba/jum, b’reset kuljum) minflok hija inkluża fit-test `authHint` tal-katalgu tal-UI. Raġuni: il-wiri tal-kwota jrid jaqbel mas-semantika tar-reset; il-konverżjoni ta’ limitu ta’ kuljum għal ekwivalenti fix-xahar (30000) hija wegħda falza li l-UI ma tistax tonora.
4. **searchTypes: `["web"]` biss.** Ma teżisti l-ebda evidenza pubblika ta’ vertikali għall-aħbarijiet/immaġnijiet fl-API ta’ AnySearch; gateways li jintegraw APIs mingħajr vertikali dokumentati (eż. Google Custom Search) jesponu l-web biss minflok jimmappjaw b’mod sieket news -> web.
5. **Pożizzjoni dwar iċ-ċavetta:** jaħdem mingħajr ċavetta; ċavetta invalida tirritorna 401/403 u qatt ma tiġi degradata b’mod sieket għal aċċess anonimu (b’rifless tal-kuntratt upstream).
6. **Esklużjonijiet intenzjonati:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (l-interċettazzjoni taċ-chat tibqa’ firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (l-endpoints remoti anonimi jaqsmu pool wieħed limitat skont l-IP għal kull IP tal-egress, għalhekk l-extract mingħajr ċavetta huwa opt-in, mhux kandidat għar-routing awtomatiku); `QUOTA_STATUS_PROVIDERS` (AnySearch jindika l-kwota permezz ta’ 429/envelope, mhux status 402/403).
