కేటాయింపు అనేది ప్రొవైడర్ కోటా కాదు.

ఏ API కీలు ఒక ప్రొవైడర్ పూల్ను వినియోగించవచ్చో, అలాగే కఠిన, సాఫ్ట్ లేదా బర్స్ట్ విధానాలు ఎలా వర్తిస్తాయో కోటా పూల్లు నిర్వచిస్తాయి. ప్రొవైడర్ కోటా అనేది ప్రొవైడర్ నివేదించిన లేదా స్పష్టంగా కాన్ఫిగర్ చేసిన మూలం నుంచి వచ్చిన బాహ్య సామర్థ్యం. Ghostlight అంతర్గత బడ్జెట్లు అడ్మినిస్ట్రేటర్ నిర్వచించిన పాలనా పరిమితులు.

`ensurePool` ఆపరేషన్ ఐడెంపోటెంట్గా ఉంటుంది: ఒకేలా ఉన్న పూల్ మారదు, మారిన కేటాయింపు నవీకరించబడుతుంది, లేని పూల్ సృష్టించబడుతుంది. ఇది ఆటోమేషన్ మరియు పరిమిత API కాలర్ల కోసం ఉద్దేశించబడింది.

చదవడానికి మాత్రమే ఉద్దేశించిన స్థితి ఎండ్పాయింట్ `GET /api/omniroute/status`. ధృవీకరణ కమాండ్ `npm run omniroute:verify`; ఇది ఎలాంటి ప్రత్యక్ష మోడల్ అభ్యర్థనను చేయదు.
