Caveman కంప్రెషన్లో అంతర్నిర్మిత ఇంగ్లీష్ నియమాలతో పాటు భాష-నిర్దిష్ట నియమాల ప్యాక్లను లోడ్ చేయవచ్చు.
ఇది ప్రధాన ఇంజిన్ను స్థిరంగా ఉంచుతూ, పోర్చుగీస్, స్పానిష్, జర్మన్, ఫ్రెంచ్, ఇటాలియన్, జపనీస్ మరియు
భవిష్యత్ భాషా ప్యాక్లు స్వతంత్రంగా అభివృద్ధి చెందడానికి వీలు కల్పిస్తుంది.

## స్థానం

భాషా ప్యాక్లు ఇక్కడ ఉంటాయి:

```txt
open-sse/services/compression/rules/<language>/
```

ప్రస్తుతం అందించబడుతున్న ప్యాక్లు (`rules/` డైరెక్టరీలోని విషయాలతో ధృవీకరించబడినవి):

| భాష                   | డైరెక్టరీ      | అందుబాటులో ఉన్న నియమాల వర్గాలు                      |
| --------------------- | -------------- | --------------------------------------------------- |
| ఇంగ్లీష్              | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| స్పానిష్              | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| పోర్చుగీస్ (బ్రెజిల్) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ఇండోనేషియన్           | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ఇటాలియన్              | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| జర్మన్                | `rules/de/`    | `context`, `filler`, `structural`                   |
| ఫ్రెంచ్               | `rules/fr/`    | `context`, `filler`, `structural`                   |
| జపనీస్                | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **సమానత్వ గమనిక:** `en`, `es`, `pt-BR`, `id` మరియు `it` ప్యాక్లలో మొత్తం 5 వర్గాలు ఉన్నాయి; `de`, `fr`, `ja` ప్యాక్లు 3 వర్గాలతో అందించబడతాయి. లేని `dedup` మరియు `ultra` వర్గాలు ఎలాంటి హెచ్చరిక లేకుండా అంతర్నిర్మిత ఇంగ్లీష్ నియమాలను ప్రత్యామ్నాయంగా ఉపయోగిస్తాయి. చిన్న ప్యాక్లకు `dedup.json` మరియు `ultra.json` జోడించడానికి సహకారాలు స్వాగతం.
>
> `pt-BR` ప్యాక్ Lenine Júnior రూపొందించిన **[Troglodita](https://github.com/leninejunior/troglodita)** ఆధారంగా రూపొందించబడింది — ఇది బ్రెజిలియన్ పోర్చుగీస్ వ్యాకరణం కోసం మొదటి నుంచి రూపొందించిన కంప్రెషన్ సిస్టమ్ (అనవసర పునరుక్తి తగ్గింపు, PT-BR పూరక పదాల తొలగింపు, dev BR కమ్యూనిటీ కోసం సాంకేతిక సంక్షిప్తీకరణలు).
>
> ప్రామాణిక వర్గాల జాబితా మరియు ప్రతి వర్గానికి సంబంధించిన స్కీమా [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json)లో ఉన్నాయి (JSON Schema డ్రాఫ్ట్ 2020-12).

## భాష గుర్తింపు

`languageDetector.ts` ప్రాంప్ట్ టెక్స్ట్ నుంచి భాషను అంచనా వేయడానికి తేలికపాటి హ్యూరిస్టిక్లను ఉపయోగిస్తుంది. కాన్ఫిగర్ చేసిన డిఫాల్ట్ భాషను ఇప్పటికీ గౌరవిస్తుంది; ఖచ్చితమైన
నియంత్రణ అవసరమైనప్పుడు కాన్ఫిగ్ ద్వారా గుర్తింపును నిలిపివేయవచ్చు.

గుర్తింపు అవుట్పుట్ నియమాల ప్యాక్లను ఎంచుకోవడానికి మాత్రమే ఉపయోగించబడుతుంది. ఇది ప్రొవైడర్ రూటింగ్, లోకేల్
ఎంపిక లేదా UI భాషను మార్చదు.

## కాన్ఫిగ్ నిర్మాణం

కంప్రెషన్ సెట్టింగ్లలో ఇవి ఉండవచ్చు:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` డ్యాష్బోర్డ్/ప్రివ్యూ డిఫాల్ట్లను నియంత్రిస్తుంది. `cavemanConfig` అనేది Caveman సందేశ టెక్స్ట్ను కంప్రెస్ చేసేటప్పుడు
ఉపయోగించే రన్టైమ్ ఇంజిన్ కాన్ఫిగ్.

## భాషా ప్యాక్ను జోడించడం

1. `open-sse/services/compression/rules/<language>/<pack>.json`ను సృష్టించండి.
2. `docs/compression/COMPRESSION_RULES_FORMAT.md`లోని Caveman నియమ ఆకృతిని ఉపయోగించండి.
3. ప్రత్యామ్నాయాలను పరిమితంగా ఉంచండి మరియు కోడ్, ఐడెంటిఫైయర్లు, URLలు లేదా JSONను మార్చకుండా ఉండండి.
4. భాష ఎంపిక మరియు ప్రత్యామ్నాయ ప్రవర్తన కోసం పరీక్షలను జోడించండి లేదా నవీకరించండి.
5. UI సెలెక్టర్లలో భాష కనిపిస్తే, కొత్త డ్యాష్బోర్డ్/i18n లేబుల్లను అందుబాటులో ఉంచండి.

## API

అందుబాటులో ఉన్న ప్యాక్లను దీనితో ప్రశ్నించవచ్చు:

```bash
curl http://localhost:20128/api/compression/language-packs
```

ప్రివ్యూ ఎండ్పాయింట్ భాషా కాన్ఫిగరేషన్ ఓవర్రైడ్లను అంగీకరిస్తుంది:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

మొత్తం 6 భాషా ప్యాక్లు v3.8.0లో ప్రతి Caveman తీవ్రత స్థాయి (LITE, FULL, ULTRA) వద్ద వర్తించే `SHARED_BOUNDARIES` క్లాజ్ను పొందాయి. చుట్టూ ఉన్న అనవసర పదాలను తొలగించినప్పటికీ, ఈ నమూనాలను యథాతథంగా సంరక్షించమని ఇది ఇంజిన్కు సూచిస్తుంది:

| నమూనా రకం                       | ఉదాహరణ                                 |
| ------------------------------- | -------------------------------------- |
| ఫెన్స్డ్ కోడ్ బ్లాక్లు          | ` ```python\n...\n``` `                |
| ఇన్లైన్ కోడ్                    | `` `my_var` ``                         |
| URLలు                           | `https://example.com/path`             |
| ఫైల్ పాత్లు (సంపూర్ణ + సాపేక్ష) | `/etc/hosts`, `./src/index.ts`         |
| ఎర్రర్ హెడర్లు                  | `Error:`, `TypeError:`, `SyntaxError:` |
| స్టాక్ ట్రేస్ లైన్లు            | `  at functionName (file.ts:12:3)`     |

ఈ నమూనాలు `DEFAULT_CAVEMAN_CONFIG.preservePatterns`లో (గతంలో `[]`) నింపబడతాయి. ఈ స్థిరాంకం `open-sse/services/compression/types.ts`లో ఉంటుంది.

### ఇది ఎందుకు ముఖ్యం

SHARED_BOUNDARIES లేకుండా, దూకుడైన Caveman మోడ్లు పునరావృత గద్యంలా కనిపించినప్పటికీ వాస్తవానికి కోడ్ స్నిపెట్, ఫైల్ పాత్ లేదా ఎర్రర్ స్టాక్ అయిన కంటెంట్ను తొలగించవచ్చు. అనవసర పదాల నియమాలు అమలయ్యే ముందు వర్తించే భాషతో సంబంధం లేని భద్రతా వలయంగా SHARED_BOUNDARIES పనిచేస్తుంది.

### preservePatternsను అనుకూలీకరించడం

కంప్రెషన్ సెట్టింగ్ల ద్వారా రన్టైమ్లో అదనపు నమూనాలను జోడించవచ్చు:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

అనుకూల నమూనాలు 6 డిఫాల్ట్లను భర్తీ చేయకుండా, వాటిని విస్తరిస్తాయి.

## నిర్వహణ గమనికలు

- భాషా ప్యాక్ లేనప్పుడు ఇంగ్లీష్ బిల్ట్-ఇన్ నియమాలు ఫాల్బ్యాక్గా కొనసాగుతాయి.
