## ఇది ఏమిటి

OmniRoute ఒక **Notion** వర్క్స్పేస్కు **సందర్భ మూలం**గా కనెక్ట్ కాగలదు — అంతర్నిర్మిత
MCP సర్వర్ ద్వారా ఏజెంట్లు యాక్సెస్ చేసే రీడ్/రైట్ నాలెడ్జ్ బేస్. Notion
ఇంటిగ్రేషన్ టోకెన్ను కాన్ఫిగర్ చేసిన తర్వాత, MCP సాధనాలు LLMకు పేజీలు మరియు డేటాబేస్లను
శోధించడం, పేజీ కంటెంట్ మరియు బ్లాక్ ట్రీలను చదవడం, ఫిల్టర్లు/సార్ట్లతో డేటాబేస్లను క్వెరీ చేయడం,
కొత్త బ్లాక్లను జోడించడం వంటి సామర్థ్యాలను అందిస్తాయి — ఇవన్నీ OmniRoute ద్వారా ప్రాక్సీ చేయబడతాయి
(రీట్రై, టైమ్అవుట్ మరియు ఎర్రర్ వర్గీకరణతో), కాబట్టి మోడల్ ఎప్పుడూ Notion APIని నేరుగా యాక్సెస్ చేయదు.

ఈ ఇంటిగ్రేషన్ అధికారిక Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`)పై నిర్మించిన సరళమైన, దృఢీకరించిన ర్యాపర్.
క్లయింట్ (`src/lib/notion/api.ts`) వీటిని జోడిస్తుంది:

- `429` మరియు `5xx` కోసం **ఎక్స్పోనెన్షియల్ బ్యాక్ఆఫ్తో రీట్రై** (గరిష్ఠంగా 3 ప్రయత్నాలు).
- `AbortController` ద్వారా **55-సెకన్ల రిక్వెస్ట్ టైమ్అవుట్**.
- **టైప్ చేసిన ఎర్రర్ వర్గీకరణ** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  సూచనలను గౌరవిస్తుంది), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- బయటకు చూపించే ముందు స్టాక్-ట్రేస్ను పోలిన భాగాలను తొలగించే **సందేశ శుద్ధీకరణ**.

## సెటప్

Notion టోకెన్ కోసం **ఎలాంటి ఎన్విరాన్మెంట్ వేరియబుల్ లేదు** — ఇది
`src/lib/db/notion.ts` ద్వారా SQLite `key_value` పట్టికలో (నేమ్స్పేస్ `notion`,
కీ `integration_token`) నిల్వ చేయబడుతుంది. Endpoint డ్యాష్బోర్డ్లోని **Context Sources**
ట్యాబ్ (`ObsidianSourceCard`కు పక్కనున్న `NotionSourceCard`) నుంచి లేదా సెట్టింగ్ల REST API
ద్వారా దీన్ని కాన్ఫిగర్ చేయండి.

> [!NOTE]
> ఈ టోకెన్ ఒక **Notion అంతర్గత ఇంటిగ్రేషన్ టోకెన్**.
> <https://www.notion.com/my-integrations> వద్ద ఒక ఇంటిగ్రేషన్ను సృష్టించి, ఆపై OmniRoute
> యాక్సెస్ చేయాలనుకునే పేజీలు/డేటాబేస్లను ఆ ఇంటిగ్రేషన్తో షేర్ చేయండి (Notion అనుమతి నమూనా
> షేర్-ఆధారితమైనది, వర్క్స్పేస్-వ్యాప్తంగా ఉండేది కాదు).

### REST ద్వారా కాన్ఫిగర్ చేయడం

```bash
# ఇంటిగ్రేషన్ టోకెన్ను సేవ్ చేసి ధ్రువీకరించండి (POST ఒక పరీక్షా శోధనను పంపడం ద్వారా ధ్రువీకరిస్తుంది)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# కనెక్షన్ స్థితిని తనిఖీ చేయండి
curl http://localhost:20128/api/settings/notion

# డిస్కనెక్ట్ చేయండి (నిల్వ చేసిన టోకెన్ను తొలగిస్తుంది)
curl -X DELETE http://localhost:20128/api/settings/notion
```

ఈ మూడు పద్ధతులకూ డ్యాష్బోర్డ్ ప్రామాణీకరణ (`isAuthenticated`) అవసరం. `POST` చేసినప్పుడు,
OmniRoute టోకెన్ను సేవ్ చేసి వెంటనే 1-ఫలిత పరీక్షా శోధనను అమలు చేస్తుంది; Notion
ఒక ఎర్రర్ ఆబ్జెక్ట్ను తిరిగి పంపితే, టోకెన్ తొలగించబడుతుంది మరియు కాల్ `400`తో విఫలమవుతుంది.

## MCP సాధనాలు (6)

`open-sse/mcp-server/tools/notionTools.ts`లో నిర్వచించబడ్డాయి. కాల్
సమయంలో `getNotionToken()` ద్వారా టోకెన్ పరిష్కరించబడుతుంది; ఏదీ కాన్ఫిగర్ చేయకపోతే సాధనం
`"Notion integration token not configured. Set it in Settings > Context Sources."`
అనే ఎర్రర్ను విసురుతుంది.

| సాధనం                        | స్కోప్         | వివరణ                                                                                                                  |
| ---------------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | టెక్స్ట్ క్వెరీ ద్వారా పేజీలు మరియు డేటాబేస్లను శోధిస్తుంది (శీర్షికలు, IDలు, URLలను అందిస్తుంది). పేజినేట్ చేయబడింది. |
| `notion_get_page`            | `read:notion`  | పేజీ ID ద్వారా దాని కంటెంట్ మరియు మెటాడేటాను పొందుతుంది.                                                               |
| `notion_list_block_children` | `read:notion`  | బ్లాక్ లేదా పేజీలోని అన్ని చైల్డ్ బ్లాక్లను (బ్లాక్ ట్రీని) జాబితా చేస్తుంది. పేజినేట్ చేయబడింది.                      |
| `notion_query_database`      | `read:notion`  | ఐచ్ఛిక `filter` + `sorts`తో (Notion API ఫార్మాట్) డేటాబేస్ను క్వెరీ చేస్తుంది. పేజినేట్ చేయబడింది.                     |
| `notion_get_database`        | `read:notion`  | ID ద్వారా డేటాబేస్ స్కీమా/మెటాడేటాను పొందుతుంది.                                                                       |
| `notion_append_blocks`       | `write:notion` | ఇప్పటికే ఉన్న బ్లాక్ లేదా పేజీకి చైల్డ్ బ్లాక్లను జోడిస్తుంది (ఒక్కో రిక్వెస్ట్కు గరిష్ఠంగా 100 బ్లాక్లు).             |

### ఇన్పుట్ పారామీటర్లు

- `notion_search` — `query` (1–500 అక్షరాలు), `pageSize` (1–100, డిఫాల్ట్ 20),
  `startCursor` (ఐచ్ఛికం).
- `notion_get_page` — `pageId` (32-అక్షరాల హెక్స్ లేదా UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, డిఫాల్ట్ 50),
  `startCursor` (ఐచ్ఛికం).
- `notion_query_database` — `databaseId`, `filter` (ఐచ్ఛికం, Notion ఫిల్టర్ ఫార్మాట్),
  `sorts` (ఐచ్ఛిక అర్రే), `pageSize` (1–100, డిఫాల్ట్ 50), `startCursor` (ఐచ్ఛికం).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (బ్లాక్ ఆబ్జెక్ట్ల అర్రే),
  `after` (ఐచ్ఛిక స్థానం).

### స్కోప్లు

రీడ్ సాధనాలకు `read:notion`, రైట్ సాధనానికి `write:notion` అవసరం.
`OMNIROUTE_MCP_ENFORCE_SCOPES=true`గా ఉన్నప్పుడు మాత్రమే
`open-sse/mcp-server/server.ts`లోని `withScopeEnforcement()` ద్వారా స్కోప్లు అమలు చేయబడతాయి;
కాలర్కు అనుమతించబడిన స్కోప్లు `OMNIROUTE_MCP_SCOPES` (కామాలతో వేరు చేసినవి) లేదా
ప్రామాణీకరించిన API కీ స్కోప్ సందర్భం నుంచి వస్తాయి. పూర్తి స్కోప్ నమూనా కోసం
[MCP-SERVER.md](./MCP-SERVER.md) చూడండి.

## ఎండ్పాయింట్లు

| పద్ధతి   | పాత్                   | ఉద్దేశ్యం                                                  |
| -------- | ---------------------- | ---------------------------------------------------------- |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }`ను తిరిగి ఇస్తుంది.               |
| `POST`   | `/api/settings/notion` | ఇంటిగ్రేషన్ టోకెన్ను సేవ్ చేసి ధృవీకరిస్తుంది.             |
| `DELETE` | `/api/settings/notion` | డిస్కనెక్ట్ చేస్తుంది (నిల్వ చేసిన టోకెన్ను తొలగిస్తుంది). |

> ఇవి డ్యాష్బోర్డ్ సెట్టింగ్ల రూట్లు. పబ్లిక్ `/v1` Notion ప్రాక్సీ
> ఎండ్పాయింట్ **లేదు** — పైన ఉన్న MCP టూల్స్ ద్వారానే Notionను యాక్సెస్ చేయవచ్చు.

## వినియోగ సందర్భాలు

- **నాలెడ్జ్ ఆధారిత సమాధానాలు** — సమాధానం ఇచ్చే ముందు ఏజెంట్తో వర్క్స్పేస్లో `notion_search`
  చేయించి, అగ్ర ఫలితాన్ని `notion_get_page` చేయించండి; తద్వారా సమాధానాలు నిజమైన అంతర్గత డాక్యుమెంట్లను ఉదహరిస్తాయి.
- **డేటాబేస్ ఆధారిత వర్క్ఫ్లోలు** — ఫిల్టర్లు + సార్ట్లతో టాస్క్లు/CRM డేటాబేస్ను
  `notion_query_database` చేసి, ఆపై వరుసలను సంగ్రహించండి లేదా ప్రాధాన్యత క్రమంలో వర్గీకరించండి.
- **రైట్-బ్యాక్ / లాగింగ్** — మీటింగ్ నోట్స్, రన్ సారాంశాలు లేదా ఏజెంట్ అవుట్పుట్ను ఇప్పటికే ఉన్న పేజీకి
  జోడించడానికి `notion_append_blocks` ఉపయోగించండి (జోడించడం మాత్రమే; విధ్వంసకర సవరణలు ఉండవు).
- **నిర్మాణ అన్వేషణ** — పేజీ బ్లాక్ ట్రీలో నావిగేట్ చేయడానికి `notion_list_block_children`
  లేదా డేటాబేస్ను క్వెరీ చేసే ముందు దాని ప్రాపర్టీ స్కీమాను తెలుసుకోవడానికి `notion_get_database` ఉపయోగించండి.
