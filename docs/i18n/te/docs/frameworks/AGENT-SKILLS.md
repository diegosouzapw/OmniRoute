> **చివరిగా నవీకరించబడింది:** 2026-08-02 — v3.8.50

Agent Skills అనేవి బాహ్య ఏజెంట్లు, MCP క్లయింట్లు మరియు A2A ఆర్కెస్ట్రేటర్లకు OmniRoute యొక్క REST API మరియు CLIని ఎలా ఉపయోగించాలో నేర్పే నిర్మిత SKILL.md ఫైళ్లు. [Omni Skills](./SKILLS.md)కు భిన్నంగా (అవి OmniRoute లోపల అమలు చేయబడే LLM సాధన నిర్వచనాలు), Agent Skills ఒక _డాక్యుమెంటేషన్ కేటలాగ్_ — ఏజెంట్ సందర్భంలోకి నేరుగా అందించగల స్థిరమైన markdown.

## అవలోకనం

ఈ కేటలాగ్లో **45 Agent Skills** ఉన్నాయి (23 REST API + 21 CLI + 1 కాన్ఫిగరేషన్ వర్క్ఫ్లో). ప్రతి స్కిల్లో ఇవి ఉంటాయి:

- ఒక **కానానికల్ ID** (`omni-auth`, `cli-serve` మొదలైనవి)
- YAML ఫ్రంట్మ్యాటర్ (`name`, `description`) + సమగ్ర markdown బాడీతో కూడిన `skills/{id}/SKILL.md`లోని ఒక **SKILL.md** ఫైల్
- OpenAPI స్పెక్ మరియు CLI రిజిస్ట్రీ నుండి ఉత్పన్నమైన **REST ఎండ్పాయింట్లు** (API స్కిల్స్) లేదా **CLI సబ్కమాండ్లు** (CLI స్కిల్స్)
- ప్రత్యక్షంగా పొందడం కోసం ఒక **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API అన్వేషణ

| ఎండ్పాయింట్                  | పద్ధతి | వివరణ                                                                      | ప్రామాణీకరణ |
| :--------------------------- | :----- | :------------------------------------------------------------------------- | :---------- |
| `/api/agent-skills`          | GET    | కేటలాగ్ను జాబితా చేయండి (ఐచ్ఛికం `?category=api\|cli\|config&area=<area>`) | ఏదీ లేదు    |
| `/api/agent-skills/{id}`     | GET    | ఒకే నైపుణ్యానికి సంబంధించిన మెటాడేటాను పొందండి                             | ఏదీ లేదు    |
| `/api/agent-skills/{id}/raw` | GET    | SKILL.mdను `text/markdown`గా పొందండి                                       | ఏదీ లేదు    |
| `/api/agent-skills/coverage` | GET    | కవరేజ్ గణాంకాలు (ఎన్ని SKILL.md ఫైళ్లు ఉన్నాయో)                            | ఏదీ లేదు    |
| `/api/agent-skills/generate` | POST   | జనరేటర్ను ప్రారంభించండి (dryRun/prune/onlyIds)                             | నిర్వహణ     |

ఉదాహరణ — అన్ని API నైపుణ్యాలను జాబితా చేయండి:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ఉదాహరణ — ఒకే SKILL.mdను పొందండి:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP అన్వేషణ

`read:catalog` స్కోప్ కింద మూడు MCP సాధనాలు నమోదు చేయబడ్డాయి:

| సాధనం                             | వివరణ                                                                 |
| :-------------------------------- | :-------------------------------------------------------------------- |
| `omniroute_agent_skills_list`     | నైపుణ్యాలను జాబితా చేయండి (ఐచ్ఛిక `category` / `area` ఫిల్టర్లు)      |
| `omniroute_agent_skills_get`      | `id` ఆధారంగా ఒక నైపుణ్యానికి సంబంధించిన మెటాడేటా + SKILL.mdను పొందండి |
| `omniroute_agent_skills_coverage` | కవరేజ్ గణాంకాలు (API/CLI అందుబాటులో ఉన్నవి/మొత్తం)                    |

స్కోప్ వైరింగ్ మరియు ప్రామాణీకరణ కోసం [MCP-SERVER.md](./MCP-SERVER.md) చూడండి.

## A2A అన్వేషణ

A2A నైపుణ్యం `list-capabilities`, మొత్తం 45 నైపుణ్యాల కేటలాగ్ను markdown పట్టిక ఆర్టిఫాక్ట్గా అందిస్తుంది. బాహ్య ఆర్కెస్ట్రేటర్లు దీన్ని ఈ విధంగా అమలు చేయవచ్చు:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

ప్రోటోకాల్ వివరాల కోసం [A2A-SERVER.md](./A2A-SERVER.md) చూడండి.

## బాహ్య ఏజెంట్లు స్కిల్స్ను ఎలా వినియోగిస్తాయి

### 1. REST ద్వారా డిస్కవరీ

```bash
# పూర్తి కేటలాగ్ను పొందండి
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# కాంటెక్స్ట్ ఇంజెక్షన్ కోసం SKILL.mdను పొందండి
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP ద్వారా డిస్కవరీ

```typescript
// Claude Desktop / Cursor MCP క్లయింట్లో:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",

// result.skills → ప్రతి దానికి rawUrl ఉన్న AgentSkill అర్రే
```

### 3. A2A ద్వారా డిస్కవరీ

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={

# table అనేది మొత్తం 45 స్కిల్ IDలు + rawUrl కాలమ్లతో కూడిన markdown పట్టిక
```

## జనరేటర్

జనరేటర్ క్యూరేట్ చేసిన కేటలాగ్ + OpenAPI స్పెక్ + CLI రిజిస్ట్రీని చదివి, ప్రతి ఎంట్రీ కోసం `skills/{id}/SKILL.md`ను రాస్తుంది:

```bash
# ప్రివ్యూ (డ్రై రన్, ఎలాంటి రైట్స్ ఉండవు)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# పూర్తి రీజనరేషన్
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# నిర్దిష్ట IDలను రీజనరేట్ చేయండి
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

జనరేటర్ ప్రతిస్పందన ఒక `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
