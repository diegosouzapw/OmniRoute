## ప్రొవైడర్ అంటే ఏమిటి?

ప్రొవైడర్ను ఒక **ఫోన్ క్యారియర్** లాగా భావించండి. కాల్స్ చేయడానికి మీకు ఫోన్ క్యారియర్ ఎలా అవసరమో, AI మోడళ్లను ఉపయోగించడానికి AI ప్రొవైడర్ కూడా అలాగే అవసరం. OmniRoute అనేది **అన్ని క్యారియర్లతో** పనిచేసే ఫోన్ లాంటిది — మీరు వాటి మధ్య స్వయంచాలకంగా మారవచ్చు.

### ప్రొవైడర్ల రకాలు

| రకం           | అది ఏమిటి                        | ఉదాహరణలు                          | ఖర్చు                        |
| ------------- | -------------------------------- | --------------------------------- | ---------------------------- |
| **ఉచితం**     | చెల్లింపు అవసరం లేదు             | Kiro, OpenCode Free, Pollinations | $0                           |
| **API కీ**    | మీకు API కీ అవసరం                | OpenAI, Anthropic, Google         | వినియోగాన్ని బట్టి చెల్లింపు |
| **OAuth**     | మీ ఖాతాతో లాగిన్ అవ్వండి         | Claude Code, GitHub Copilot       | సబ్స్క్రిప్షన్               |
| **వెబ్ కుకీ** | మీ బ్రౌజర్ సెషన్ను ఉపయోగిస్తుంది | ChatGPT Web (Codex), Gemini Web   | $0 (మీ ఖాతాను ఉపయోగిస్తుంది) |

### వెబ్ కుకీ ప్రొవైడర్లు

సాధారణ సెటప్ సూచనలు, పరిమితులు, సమస్య పరిష్కారం మరియు ప్రొవైడర్-నిర్దిష్ట ప్రామాణీకరణ మార్గదర్శకాల కోసం **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** చూడండి.

## త్వరిత ప్రారంభం: మీ మొదటి ప్రొవైడర్ను కనెక్ట్ చేయండి

### ఐచ్ఛిక మొదటి-రన్ ఉచిత-ప్రొవైడర్ సెటప్

మొదటి-రన్ విజార్డ్ స్పష్టమైన **ఉచిత ప్రొవైడర్లను సెటప్ చేయండి** కార్డ్ను అందిస్తుంది. ఇది OmniRoute యొక్క ప్రామాణీకరణ-అవసరం-లేని ప్రొవైడర్ రిజిస్ట్రీ నుండి ప్రస్తుత
అర్హత కలిగిన జాబితాను రూపొందించి, నిర్ధారించే ముందు ప్రతి
ప్రొవైడర్ను సమీక్షించి ఎంపికను తీసివేయడానికి మిమ్మల్ని అనుమతిస్తుంది. OmniRoute ప్రొవైడర్ యొక్క హెచ్చరిక నోటీసును మరియు దాని సైట్కు లింక్ను చూపిస్తుంది,
తద్వారా మీరు ముందుగా మూడవ-పక్ష నిబంధనలు, గోప్యత, లభ్యత మరియు రేట్ పరిమితులను సమీక్షించవచ్చు.

ఈ చర్య ఐచ్ఛికం: విజార్డ్ను పూర్తి చేయడం వలన ఉచిత-ప్రొవైడర్ కనెక్షన్లు ఎప్పుడూ నిశ్శబ్దంగా సృష్టించబడవు.
ఇది ఇంకా లేని ప్రొవైడర్లను మాత్రమే సృష్టిస్తుంది, ఇప్పటికే అనుకూలీకరించిన కనెక్షన్లను
మార్చకుండా ఉంచుతుంది మరియు సృష్టించిన, ఇప్పటికే-కాన్ఫిగర్ చేసిన మరియు విఫలమైన ప్రొవైడర్లను విడివిడిగా నివేదిస్తుంది. పాక్షిక ఫలితం తర్వాత
విఫలమైన వాటిని మాత్రమే మీరు సురక్షితంగా మళ్లీ ప్రయత్నించవచ్చు.

### ఎంపిక A: ఉచిత ప్రొవైడర్ (క్రెడిట్ కార్డ్ అవసరం లేదు)

1. `http://localhost:20128` వద్ద డ్యాష్బోర్డ్ను తెరవండి
2. **ప్రొవైడర్లు** → **ప్రొవైడర్ను జోడించండి**కు వెళ్లండి
3. ఈ ఉచిత ప్రొవైడర్లలో ఒకదాన్ని ఎంచుకోండి:
   - **Kiro AI** — ఉచిత Claude మోడళ్లు (ప్రామాణీకరణ అవసరం లేదు)
   - **OpenCode Free** — ఉచిత GPT మోడళ్లు (ప్రామాణీకరణ అవసరం లేదు)
   - **Pollinations** — ఉచిత GPT-5, Claude, Gemini (కీ అవసరం లేదు)
   - **LongCat** — 10M టోకెన్లు ఉచితం (ఒకసారి మాత్రమే మంజూరు, ఖాతా + KYC అవసరం)
   - **Cloudflare AI** — 50+ మోడళ్లు, రోజుకు 10K న్యూరాన్లు
   - **MLX Gemma 26B** — స్థానిక Apple Silicon మోడల్ (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — స్థానిక Apple Silicon మోడల్ (~9.1 tok/s, ~13.1GB RAM)
4. **కనెక్ట్ చేయండి** క్లిక్ చేయండి
5. పూర్తయింది! ఇప్పుడు మీకు ఉచిత AI యాక్సెస్ ఉంది.

   - **OpenAI**: https://platform.openai.com/api-keys

   - **Google**: https://aistudio.google.com/apikey

3. **ప్రొవైడర్లు** → **ప్రొవైడర్ను జోడించండి**కు వెళ్లండి
4. మీ ప్రొవైడర్ను ఎంచుకోండి

7. పూర్తయింది! ఇప్పుడు మీకు ఆ ప్రొవైడర్ మోడళ్లకు యాక్సెస్ ఉంది.

### ఎంపిక C: OAuth ప్రొవైడర్ (సబ్స్క్రిప్షన్)

1. `http://localhost:20128` వద్ద డ్యాష్బోర్డ్ను తెరవండి
2. **ప్రొవైడర్లు** → **ప్రొవైడర్ను జోడించండి**కు వెళ్లండి
3. మీ ప్రొవైడర్ను ఎంచుకోండి (ఉదా., Claude Code, GitHub Copilot)

6. పూర్తయింది! ఇప్పుడు మీకు మీ సబ్స్క్రిప్షన్ మోడళ్లకు యాక్సెస్ ఉంది.

### ఎంపిక D: స్థానిక MLX మోడళ్లు (Apple Silicon)

యూనిఫైడ్ మెమరీ కలిగిన Apple Silicon Macs కోసం, `mlx-lm.server` ద్వారా నడుస్తున్న స్థానిక MLX మోడళ్లను సాధారణ OpenAI-అనుకూల స్థానిక ప్రొవైడర్లుగా కనెక్ట్ చేయడానికి OmniRoute మద్దతు ఇస్తుంది.

#### ముందస్తు అవసరాలు

- 24GB+ యూనిఫైడ్ మెమరీ కలిగిన **Apple Silicon Mac** (M1/M2/M3/M4) సిఫార్సు చేయబడింది
- **uv** ప్యాకేజీ మేనేజర్: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### త్వరిత ప్రారంభం

1. **డిపెండెన్సీలను ఇన్స్టాల్ చేయండి**:

   ```bash
   # ఇప్పటికే ఇన్స్టాల్ చేయకపోతే uvను ఇన్స్టాల్ చేయండి
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lmను ఇన్స్టాల్ చేయండి
   uv pip install mlx-lm
   ```

2. **MLX సర్వర్లను మాన్యువల్గా ప్రారంభించండి** (వేర్వేరు టెర్మినళ్లలో):

   ```bash
   # టెర్మినల్ 1: Gemma 4 26B A4B IT-QAT (పోర్ట్ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # టెర్మినల్ 2: Qwen 3.8 27B MLX Mixed (పోర్ట్ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute డ్యాష్బోర్డ్లో కనెక్ట్ చేయండి**:
   - **ప్రొవైడర్లు** → **ప్రొవైడర్ను జోడించండి**కు వెళ్లండి
   - **MLX Gemma 26B** లేదా **MLX Qwen 3.8 27B** ఎంచుకోండి
   - **కనెక్ట్ చేయండి** క్లిక్ చేయండి (API కీ అవసరం లేదు)

4. **OpenCodeతో ఉపయోగించండి**:
   ```bash
   # OmniRouteను ఉపయోగించేలా OpenCodeను కాన్ఫిగర్ చేయండి
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX మోడళ్లను ఉపయోగించండి
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### మెమరీ నిర్వహణ

**ముఖ్యం**: 24GB యూనిఫైడ్ మెమరీతో, ఒకేసారి **ఒక పెద్ద MLX మోడల్ మాత్రమే అమలు కాగలదు**.

- Gemma 26B: ~15.9GB గరిష్ఠ మెమరీ
- Qwen 3.8 27B: ~13.1GB గరిష్ఠ మెమరీ

మీరు దీన్ని మాన్యువల్గా నిర్వహించాలి:

- ఒకేసారి ఒక MLX సర్వర్ను మాత్రమే అమలు చేయండి, లేదా
- రెండింటినీ వేర్వేరు మెషీన్లపై అమలు చేయండి, లేదా
- మరొకదాన్ని ప్రారంభించే ముందు ఒకదాన్ని ఆపివేయండి

OmniRoute MLX సర్వర్ ప్రాసెస్లను స్వయంచాలకంగా నిర్వహించదు — ఇది మీరు కాన్ఫిగర్ చేసే OpenAI-అనుకూల ఎండ్పాయింట్లకు అభ్యర్థనలను మాత్రమే రూట్ చేస్తుంది.

### దశ 4: మీ ప్రొవైడర్ను ఎంచుకోండి

జాబితాను బ్రౌజ్ చేయండి లేదా మీ ప్రొవైడర్ కోసం శోధించండి. దానిపై క్లిక్ చేయండి.

### దశ 5: ఆధారాలను నమోదు చేయండి

- **ఉచిత ప్రొవైడర్లు**: ఆధారాలు అవసరం లేదు — **Connect**పై క్లిక్ చేయండి
- **API కీ ప్రొవైడర్లు**: మీ API కీని పేస్ట్ చేయండి
- **OAuth ప్రొవైడర్లు**: **Connect with OAuth**పై క్లిక్ చేసి లాగిన్ చేయండి

### దశ 6: కనెక్షన్ను పరీక్షించండి

ఇది పనిచేస్తోందని ధృవీకరించడానికి **Test Connection**పై క్లిక్ చేయండి.

మీ ప్రొవైడర్ ఇప్పుడు కనెక్ట్ అయింది. మీరు దీన్ని `model: "auto"`తో ఉపయోగించవచ్చు లేదా ప్రొవైడర్ను నేరుగా పేర్కొనవచ్చు.

### "నేను ఏ ప్రొవైడర్తో ప్రారంభించాలి?"

**Kiro AI**తో ప్రారంభించండి — ఇది ఉచితం, API కీ అవసరం లేదు, అలాగే Claude మోడళ్లకు యాక్సెస్ను అందిస్తుంది. ఆపై అవసరాన్ని బట్టి మరిన్ని ప్రొవైడర్లను జోడించండి.

### "నేను ఒకేసారి బహుళ ప్రొవైడర్లను ఉపయోగించవచ్చా?"
