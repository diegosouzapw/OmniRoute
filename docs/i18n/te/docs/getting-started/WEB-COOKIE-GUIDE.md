Web Cookie ప్రొవైడర్లు, API కీకి బదులుగా మీ ప్రస్తుత బ్రౌజర్ సెషన్ ద్వారా AI సేవను ఉపయోగించడానికి OmniRouteను అనుమతిస్తాయి. మీరు ఇప్పటికే ఒక సేవకు దాని వెబ్సైట్ ద్వారా యాక్సెస్ కలిగి ఉండి, అదే ప్రామాణీకరించబడిన సెషన్ను OmniRoute ఉపయోగించాలని కోరుకున్నప్పుడు ఇవి ఉపయోగకరంగా ఉంటాయి.

API-key ప్రొవైడర్లకు భిన్నంగా, Web Cookie ప్రొవైడర్లు మీ బ్రౌజర్ వెబ్సైట్కు పంపే ఆధారాలను ఉపయోగించి ప్రామాణీకరిస్తాయి.

# ప్రారంభించే ముందు

> **ముఖ్యమైనది:** ఆధారాలను ఎల్లప్పుడూ **ప్రత్యక్ష నెట్వర్క్ అభ్యర్థన** నుండి కాపీ చేయండి, మీ బ్రౌజర్ Cookie నిల్వ నుండి **కాదు**.

Cookiesను తప్పు ప్రదేశం నుండి కాపీ చేయడం వల్ల అనేక ప్రామాణీకరణ సమస్యలు ఏర్పడతాయి.

## Cookie నిల్వ నుండి కాపీ చేయవద్దు

చాలా బ్రౌజర్లు నిల్వ చేసిన Cookiesను ఈ మార్గం ద్వారా చూపిస్తాయి:

```
DevTools
→ Application (లేదా Storage)
→ Cookies
```

ఈ Cookies సరైనవిగా కనిపించినప్పటికీ, అవి:

- పాతవి అయి ఉండవచ్చు
- అసంపూర్ణంగా ఉండవచ్చు
- ప్రామాణీకరించబడిన అభ్యర్థనలపై మాత్రమే పంపబడే Cookiesను కలిగి ఉండకపోవచ్చు

ఈ విలువలు చెల్లుబాటు అయ్యేవిగా కనిపించినప్పటికీ, వాటిని ఉపయోగించడం వల్ల ప్రామాణీకరణ విఫలం కావచ్చు.

## ప్రత్యక్ష అభ్యర్థన నుండి కాపీ చేయండి

దానికి బదులుగా, విజయవంతమైన అభ్యర్థనలోని Cookiesను ఉపయోగించండి:

```
DevTools
→ Network
→ పేజీని రిఫ్రెష్ చేయండి
→ చాట్ లేదా సంభాషణ అభ్యర్థనను తెరవండి
→ Request Headers
→ Cookie
```

`Cookie` అభ్యర్థన హెడర్లో మీ బ్రౌజర్ విజయవంతంగా ఉపయోగించిన ఖచ్చితమైన ప్రామాణీకరణ సమాచారం ఉంటుంది.

చాలా Web Cookie ప్రొవైడర్ల కోసం, OmniRouteలో అతికించాల్సిన విలువ ఇదే.

# సాధారణ సెటప్

చాలా Web Cookie ప్రొవైడర్లకు సెటప్ ప్రక్రియ ఒకే విధంగా ఉంటుంది.

1. ప్రొవైడర్ వెబ్సైట్కు సైన్ ఇన్ చేయండి.
2. బ్రౌజర్ Developer Toolsను తెరవండి.
3. **Network** ట్యాబ్ను తెరవండి.
4. పేజీని రిఫ్రెష్ చేయండి.
5. ప్రామాణీకరించబడిన చాట్ లేదా సంభాషణ అభ్యర్థనను తెరవండి.
6. అవసరమైన ప్రామాణీకరణ ఆధారాలను కాపీ చేయండి.
7. OmniRouteను తెరవండి.
8. **Providers → Add Provider**కు వెళ్లండి.
9. మీ Web Cookie ప్రొవైడర్ను ఎంచుకోండి.
10. ఆధారాలను అతికించండి.
11. **Test Connection**పై క్లిక్ చేయండి.
12. ప్రొవైడర్ను సేవ్ చేయండి.

అవసరమైన ఖచ్చితమైన ఆధారాలు ప్రొవైడర్పై ఆధారపడి ఉంటాయి.

# Web Cookie ప్రొవైడర్లు చేయగలిగేవి మరియు చేయలేనివి

Web Cookie ప్రొవైడర్లు వెబ్సైట్ చాట్ ఇంటర్ఫేస్ను తిరిగి ఉపయోగిస్తాయి. అవి అధికారిక APIలతో సమానమైన సామర్థ్యాలను అందించవు.

## మద్దతు ఉన్నవి

- మీ ప్రస్తుత బ్రౌజర్ సెషన్ను ఉపయోగించి ప్రామాణీకరించడం
- మీ ఖాతా ద్వారా అందుబాటులో ఉన్న మోడళ్లను యాక్సెస్ చేయడం
- చాట్ ప్రతిస్పందనలను స్ట్రీమ్ చేయడం
- API కీ అవసరం లేదు

## మద్దతు లేనివి

- ఫంక్షన్ కాలింగ్
- టూల్ కాలింగ్
- ఆటోమేటిక్ ఫైల్ ఎడిటింగ్
- ఏజెంటిక్ IDE వర్క్ఫ్లోలు
- APIలో మాత్రమే లభించే ఫీచర్లు

ఇది ఆశించిన ప్రవర్తనే మరియు ఇది బగ్ **కాదు**.

మీకు టూల్ అమలు, ఆటోమేటిక్ ఫైల్ ఎడిటింగ్ లేదా ఇతర ఏజెంట్ వర్క్ఫ్లోలు అవసరమైతే, Web Cookie ప్రొవైడర్కు బదులుగా **API-key ప్రొవైడర్**ను ఉపయోగించండి.

# ధ్రువీకరణ పరిమితి

విజయవంతమైన **Test Connection** లేదా Cookie ధ్రువీకరణ, అందించిన ఆధారాలు ఆశించిన ఫార్మాట్లో ఉన్నట్లుగా కనిపిస్తున్నాయని మాత్రమే ధ్రువీకరిస్తుంది.

Issue #7857 పరిష్కారమయ్యే వరకు, విజయవంతమైన ధ్రువీకరణ ప్రొవైడర్ విజయవంతంగా ప్రామాణీకరించబడుతుందని **హామీ ఇవ్వదు**.

ప్రామాణీకరణ ఇప్పటికీ విఫలమైతే, మీరు ఆధారాలను బ్రౌజర్ Cookie నిల్వకు బదులుగా ప్రత్యక్ష నెట్వర్క్ అభ్యర్థన నుండి కాపీ చేశారో లేదో ధ్రువీకరించండి.

---

# సమస్య పరిష్కారం

## ప్రామాణీకరణ విఫలమవుతోంది

ఆధారాలు ఈ ప్రదేశం నుండి కాపీ చేయబడ్డాయని ధ్రువీకరించండి:

```
Network
→ Request Headers
→ Cookie
```

ఈ ప్రదేశం నుండి **కాదని** నిర్ధారించండి:

```
Application
→ Cookies
```

---

## Cookie బ్రౌజర్లో పనిచేస్తుంది కానీ OmniRouteలో పనిచేయదు

కొన్ని ప్రొవైడర్లు ప్రామాణీకరించబడిన అభ్యర్థనల సమయంలో మాత్రమే పంపబడే Cookiesను కలిగి ఉంటాయి.

సంభాషణను విజయవంతంగా తెరిచిన తర్వాత, కొత్త నెట్వర్క్ అభ్యర్థన నుండి ఆధారాలను మళ్లీ కాపీ చేయండి.

---

## సెషన్ గడువు ముగిసింది

Web Cookie ప్రొవైడర్లు మీ ప్రస్తుత బ్రౌజర్ సెషన్ను ఉపయోగిస్తాయి.

మీ బ్రౌజర్ సెషన్ గడువు ముగిసినా లేదా మీరు సైన్ అవుట్ చేసినా, మీరు కొత్త ఆధారాల సమితిని కాపీ చేయాలి.

# ఉత్తమ పద్ధతులు

- కొత్తగా ప్రామాణీకరించబడిన అభ్యర్థన నుండి ఆధారాలను కాపీ చేయండి.
- పాత Cookiesను తిరిగి ఉపయోగించడం నివారించండి.
- Web Cookie ప్రొవైడర్లను ఉపయోగిస్తున్నప్పుడు మీ బ్రౌజర్ సెషన్ను సక్రియంగా ఉంచండి.
- కాపీ చేసిన Cookiesను సున్నితమైన ఆధారాలుగా పరిగణించండి.
- మీకు ఫంక్షన్ కాలింగ్ లేదా ఏజెంట్ వర్క్ఫ్లోలు అవసరమైనప్పుడు API-key ప్రొవైడర్లను ఉపయోగించండి.
