## దశ 1: OmniRouteను ఇన్స్టాల్ చేయండి

మీకు నచ్చిన పద్ధతిని ఎంచుకోండి:

### ఎంపిక A: npm (సిఫార్సు చేయబడింది)

```bash
npm install -g omniroute
```

### ఎంపిక B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` అనేది **ప్రచురించబడిన** అత్యధిక స్థిరమైన SemVer. ఇది git `main`ను అనుసరించదు. GitOps కోసం `diegosouzapw/omniroute:X.Y.Z`ను పిన్ చేయండి. [ఇమేజ్ ట్యాగ్లు / విడుదల ఛానెల్లు](../guides/DOCKER_GUIDE.md#release-channels) చూడండి.

### ఎంపిక C: సోర్స్ నుండి

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## దశ 2: OmniRouteను ప్రారంభించండి

```bash
omniroute
```

OmniRoute `http://localhost:20128` వద్ద ప్రారంభమవుతుంది. డ్యాష్బోర్డ్ స్వయంచాలకంగా తెరుచుకుంటుంది.

---

## దశ 3: ఉచిత ప్రొవైడర్ను కనెక్ట్ చేయండి

ఉచిత ప్రొవైడర్ను కనెక్ట్ చేయడం ద్వారా మీరు **ఎలాంటి చెల్లింపూ చేయకుండా** OmniRouteను ఉపయోగించవచ్చు.

### ఎంపిక A: Kiro (ఉచిత Claude — క్రెడిట్ కార్డ్ అవసరం లేదు)

1. `http://localhost:20128` వద్ద డ్యాష్బోర్డ్ను తెరవండి
2. **Providers** → **Add Provider**కు వెళ్లండి
3. **Kiro AI**ని ఎంచుకోండి
4. **Connect**పై క్లిక్ చేయండి (API key అవసరం లేదు!)
5. పూర్తయింది! ఇప్పుడు మీకు Claude మోడళ్లకు ఉచిత యాక్సెస్ ఉంది.

### ఎంపిక B: OpenCode Free (ప్రామాణీకరణ అవసరం లేదు)

1. `http://localhost:20128` వద్ద డ్యాష్బోర్డ్ను తెరవండి
2. **Providers** → **Add Provider**కు వెళ్లండి
3. **OpenCode Free**ని ఎంచుకోండి
4. **Connect**పై క్లిక్ చేయండి (API key అవసరం లేదు!)
5. పూర్తయింది! ఇప్పుడు మీకు అనేక మోడళ్లకు ఉచిత యాక్సెస్ ఉంది.

### ఎంపిక C: Pollinations (కీ అవసరం లేదు)

1. `http://localhost:20128` వద్ద డ్యాష్బోర్డ్ను తెరవండి
2. **Providers** → **Add Provider**కు వెళ్లండి
3. **Pollinations**ను ఎంచుకోండి
4. **Connect**పై క్లిక్ చేయండి (API key అవసరం లేదు!)
5. పూర్తయింది! ఇప్పుడు మీకు GPT-5, Claude, Geminiతో పాటు మరిన్ని మోడళ్లకు ఉచిత యాక్సెస్ ఉంది.

## దశ 4: ఇది పనిచేస్తోందో లేదో ధృవీకరించండి

[API Keys](http://localhost:20128/dashboard/api-manager) నుండి కొత్త కీని సృష్టించండి. ఈ కీ మళ్లీ కనిపించదు కాబట్టి దాన్ని భద్రపరచండి. ఈ కీ అప్స్ట్రీమ్ ప్రొవైడర్లను యాక్సెస్ చేయడానికి కాదని, సాధనాలు OmniRouteను యాక్సెస్ చేయడానికి అని గమనించండి.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

మీరు కనెక్ట్ చేసిన మోడళ్లు జాబితాలో కనిపించాలి.

---

## దశ 5: మీ IDE లేదా CLIని OmniRouteకు మళ్లించండి

మీ IDE లేదా CLI సాధనంలో వీటిని సెట్ చేయండి:

```
Base URL: http://localhost:20128/v1
API Key:  [డ్యాష్బోర్డ్ → Endpoints నుండి కాపీ చేయండి]
Model:    auto
```

అంతే! ఇప్పుడు మీ IDE స్వయంచాలక ప్రొవైడర్ ఎంపికతో OmniRouteను ఉపయోగిస్తుంది.

### IDE ఉదాహరణ: VSCode/Continue.dev

1. VSCodeలో [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ఎక్స్టెన్షన్ను ఇన్స్టాల్ చేయండి.
2. కింది పంక్తులను జోడించడానికి మీ `~/.continue/config.yaml`ను నవీకరించండి:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev చాట్ పేన్లో `OmniRoute - Auto`ను ఎంచుకోండి; అప్పుడు మీరు OmniRouteకు అభ్యర్థనలు పంపుతారు.
4. (ఐచ్ఛికం) పాఠకునికి అభ్యాసం — ముందే రూపొందించిన ఇతర కాన్ఫిగరేషన్లన్నింటితో `config.yaml`ను మీ IDE ద్వారా నవీకరించండి 😊

### CLI ఉదాహరణ: Codex CLI

1. మీ ఆపరేటింగ్ సిస్టమ్లో ఎన్విరాన్మెంట్ వేరియబుల్ను శాశ్వతంగా సెట్ చేయండి.
   macOS/Linux కోసం (మీ `~/.bashrc` లేదా `~/.zshrc`కు జోడించండి):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows కోసం (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. ఇప్పుడు OmniRoute కోసం కాన్ఫిగర్ చేసిన Codexను ప్రారంభిద్దాం. దీన్ని అమలు చేయండి:

```
omniroute launch-codex --model auto
```

ఎండ్పాయింట్ మరియు API keyని పేర్కొనడానికి `codex` మరియు కమాండ్ లైన్ పారామీటర్ల ద్వారా మీరు దీన్ని మాన్యువల్గా చేయవచ్చు; కానీ పై కమాండ్తో OmniRoute మీ కోసం అన్నింటినీ చూసుకుంటుంది.

ఇదే ఒకే-కమాండ్ ప్రారంభ విధానం జెనరిక్ లాంచర్ ద్వారా ఇతర CLIలకు కూడా పనిచేస్తుంది — `omniroute run <target>` అనేది `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, మరియు `gemini`కు మద్దతు ఇస్తుంది ([CLI ఇంటిగ్రేషన్లు](../guides/CLI-INTEGRATIONS.md) చూడండి).

3. ఇప్పుడు CLI అభ్యర్థనలను OmniRouteకు పంపుతూ ఉండాలి.

### మీ సాధనం OmniRouteకు రూట్ చేస్తోందని నిర్ధారించండి

ఎడమ సైడ్బార్లోని [Monitoring/Logs](http://localhost:20128/dashboard/logs)పై క్లిక్ చేయడం ద్వారా అభ్యర్థన వివరాలను చూడవచ్చు. లోపలికి క్లిక్ చేస్తే మరిన్ని వివరాలు కనిపిస్తాయి. అదనపు సమాచారంగా, మీకు ఇష్టమైన హార్నెస్ నుండి ఏ సమాచారం పంపబడుతుందో కూడా చూడవచ్చు. ఇది నేర్చుకోవడం మరియు డీబగ్గింగ్ పరంగా ఉపయోగకరంగా ఉంటుంది.

## సాధారణ ప్రశ్నలు

### "నాకు API key అవసరమా?"

**లేదు!** మీరు ఎలాంటి API key లేకుండానే ఉచిత ప్రొవైడర్లను (Kiro, OpenCode Free, Pollinations) ఉపయోగించవచ్చు. వాటిని డ్యాష్బోర్డ్లో కనెక్ట్ చేస్తే చాలు.

### "`auto` అంటే ఏమిటి?"

ప్రతి అభ్యర్థనకు ఉత్తమ ప్రొవైడర్ను స్వయంచాలకంగా ఎంచుకోమని `auto` OmniRouteకు తెలియజేస్తుంది. ఇది వేగం, ఖర్చు, నాణ్యత మరియు లభ్యతను పరిగణనలోకి తీసుకుంటుంది. వివరాల కోసం [Auto-Combo మార్గదర్శిని](./AUTO-COMBO-GUIDE.md) చూడండి.

### "దీనికి ఎంత ఖర్చవుతుంది?"

OmniRoute స్వయంగా **ఉచితం మరియు ఓపెన్-సోర్స్**. మీరు ఉపయోగించే ప్రొవైడర్లకు మాత్రమే చెల్లిస్తారు. చాలా ప్రొవైడర్లకు ఉచిత టియర్లు ఉన్నాయి — [ఉచిత టియర్ల మార్గదర్శిని](./FREE-TIERS-GUIDE.md) చూడండి.

### "నేను దీన్ని Claude Code / Cursor / Copilotతో ఉపయోగించవచ్చా?"

**అవును!** OpenAI ఫార్మాట్కు మద్దతు ఇచ్చే ఏ సాధనంతోనైనా OmniRoute పనిచేస్తుంది. Base URLను `http://localhost:20128/v1`కు సెట్ చేయండి. నిర్దిష్ట సెటప్ సూచనల కోసం [CLI సాధనాల మార్గదర్శిని](../reference/CLI-TOOLS.md) చూడండి.

### "ఒక ప్రొవైడర్ పనిచేయకపోతే ఏమవుతుంది?"

విఫలమైన ప్రొవైడర్లను OmniRoute స్వయంచాలకంగా దాటవేసి, తదుపరి ప్రొవైడర్ను ప్రయత్నిస్తుంది. మీరు ఏమీ చేయాల్సిన అవసరం లేదు. వివరాల కోసం [Auto-Combo మార్గదర్శిని](./AUTO-COMBO-GUIDE.md) చూడండి.
