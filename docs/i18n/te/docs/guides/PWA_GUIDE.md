OmniRoute పూర్తిగా ఇన్స్టాల్ చేయగల Progressive Web Appగా అందించబడుతుంది. మీరు ఏదైనా మొబైల్ బ్రౌజర్ — Android (Chrome) లేదా iOS (Safari) — నుండి డ్యాష్బోర్డ్ను యాక్సెస్ చేసినప్పుడు, **"హోమ్ స్క్రీన్కు జోడించు"** ఎంపికను ఉపయోగించి, యాప్ స్టోర్ అవసరం లేకుండానే స్థానిక యాప్ లాంటి అనుభవాన్ని పొందవచ్చు.

## PWA అంటే ఏమిటి?

Progressive Web App, OmniRoute వెబ్ డ్యాష్బోర్డ్ను స్థానిక మొబైల్ యాప్లా కనిపించేలా, అలాగే అనుభూతి కలిగించేలా మారుస్తుంది. ఒకసారి ఇన్స్టాల్ చేసిన తర్వాత, అది:

- దాని స్వంత ఐకాన్తో మీ హోమ్ స్క్రీన్ నుండి ప్రారంభమవుతుంది
- పూర్తి స్క్రీన్లో తెరుచుకుంటుంది — బ్రౌజర్ అడ్రస్ బార్ లేదా ట్యాబ్ UI ఉండదు
- ప్రత్యేక కనెక్టివిటీ పేజీతో ఆఫ్లైన్లో పనిచేస్తుంది
- వేగంగా లోడ్ కావడానికి స్టాటిక్ అసెట్లను క్యాష్ చేస్తుంది
- పోర్ట్రెయిట్ మరియు ల్యాండ్స్కేప్ ఓరియంటేషన్లు రెండింటికీ మద్దతు ఇస్తుంది

## ఇన్స్టాలేషన్

### Android (Chrome)

1. Chromeలో OmniRoute డ్యాష్బోర్డ్ను తెరవండి: `http://YOUR_IP:20128`
2. Chrome స్వయంచాలకంగా **"OmniRouteను హోమ్ స్క్రీన్కు జోడించండి"** బ్యానర్ను చూపుతుంది, లేదా:
   - **⋮** మెనూ (మూడు చుక్కలు) → **"హోమ్ స్క్రీన్కు జోడించు"** లేదా **"యాప్ను ఇన్స్టాల్ చేయి"** నొక్కండి
3. ప్రాంప్ట్ను నిర్ధారించండి
4. OmniRoute మీ హోమ్ స్క్రీన్పై స్వతంత్ర యాప్గా కనిపిస్తుంది

### iOS (Safari)

1. Safariలో OmniRoute డ్యాష్బోర్డ్ను తెరవండి: `http://YOUR_IP:20128`
2. **Share** బటన్ను (బాణం ఉన్న బాక్స్) నొక్కండి
3. క్రిందికి స్క్రోల్ చేసి **"హోమ్ స్క్రీన్కు జోడించు"** నొక్కండి
4. దానికి పేరు పెట్టి (డిఫాల్ట్గా "OmniRoute" ఉంటుంది), **జోడించు** నొక్కండి
5. OmniRoute యాప్ ఐకాన్తో మీ హోమ్ స్క్రీన్పై కనిపిస్తుంది

### డెస్క్టాప్ (Chrome / Edge)

1. OmniRoute డ్యాష్బోర్డ్ను తెరవండి
2. అడ్రస్ బార్లోని **ఇన్స్టాల్ ఐకాన్**ను క్లిక్ చేయండి (లేదా ⋮ → "OmniRouteను ఇన్స్టాల్ చేయి...")
3. ప్రాంప్ట్ను నిర్ధారించండి
4. OmniRoute స్వతంత్ర విండోగా తెరుచుకుంటుంది — ట్యాబ్లు ఉండవు, అడ్రస్ బార్ ఉండదు

## ఫీచర్లు

### పూర్తి స్క్రీన్ అనుభవం

మేనిఫెస్ట్ `display: "fullscreen"`తో కాన్ఫిగర్ చేయబడింది, అంటే ఇన్స్టాల్ చేసిన యాప్ మొత్తం స్క్రీన్ను ఉపయోగిస్తుంది — బ్రౌజర్ UI ఉండదు, స్టేటస్ బార్ ఓవర్ల్యాప్ ఉండదు. దీనివల్ల డ్యాష్బోర్డ్ నిజమైన స్థానిక యాప్లా అనిపిస్తుంది.

### ఆఫ్లైన్ మద్దతు

OmniRoute తెలివైన క్యాషింగ్ను అందించే service worker (`sw.js`)ను కలిగి ఉంటుంది:

| అసెట్ రకం                                                     | వ్యూహం                                | ప్రవర్తన                                                                                                    |
| ------------------------------------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **యాప్ షెల్**                                                 | ముందుగా క్యాష్                        | `/`, `/offline`, మేనిఫెస్ట్ మరియు ఐకాన్లు ఇన్స్టాలేషన్ సమయంలో ముందుగానే క్యాష్ చేయబడతాయి                    |
| **స్టాటిక్ అసెట్లు** (CSS, JS, చిత్రాలు, ఫాంట్లు)             | క్యాష్ ఫాల్బ్యాక్తో ముందుగా నెట్వర్క్ | నెట్వర్క్ నుండి తాజా వాటిని పొందుతుంది; ఆఫ్లైన్లో ఉంటే క్యాష్ను ఉపయోగిస్తుంది                               |
| **Next.js బండిల్లు** (`/_next/`)                              | క్యాష్ అప్డేట్తో ముందుగా నెట్వర్క్    | నెట్వర్క్ నుండి పొందడంతో పాటు క్యాష్ను అప్డేట్ చేస్తుంది; ఆఫ్లైన్లో ఉంటే క్యాష్ చేసిన వెర్షన్ను అందిస్తుంది |
| **నావిగేషన్ అభ్యర్థనలు**                                      | బైపాస్ (ఎప్పుడూ ఇంటర్సెప్ట్ చేయబడవు)  | HTTP/3→HTTP/2 ఫాల్బ్యాక్ను బ్రౌజర్ నిర్వహిస్తుంది; పనిచేయని QUIC సాకెట్ `Response.error()`గా మారకూడదు       |
| **API / డ్యాష్బోర్డ్ రూట్లు** (`/api/`, `/a2a`, `/dashboard`) | బైపాస్ (ఎప్పుడూ క్యాష్ చేయబడవు)       | ఎల్లప్పుడూ నేరుగా సర్వర్కు వెళ్తుంది — service worker ద్వారా ఎప్పుడూ ఇంటర్సెప్ట్ చేయబడదు                    |

### ఆఫ్లైన్ పేజీ

నెట్వర్క్ అందుబాటులో లేనప్పుడు, వినియోగదారు కొత్త పేజీకి నావిగేట్ చేస్తే, service worker ప్రత్యేక `/offline` పేజీని అందిస్తుంది, అది:

- స్పష్టమైన **"కనెక్టివిటీ సమస్య"** సందేశాన్ని ప్రదర్శిస్తుంది
- నిజ సమయంలో అప్డేట్ అయ్యే ప్రత్యక్ష **ఆన్లైన్/ఆఫ్లైన్ స్థితి సూచిక**ను చూపుతుంది
- కనెక్టివిటీ తిరిగి వచ్చినప్పుడు రీలోడ్ చేయడానికి **"కనెక్షన్ను మళ్లీ ప్రయత్నించు"** బటన్ను అందిస్తుంది
- డయాగ్నస్టిక్స్ కోసం **స్థితి పేజీ**కి లింక్ను అందిస్తుంది

### యాప్ ఐకాన్లు

OmniRoute ప్రతి ప్లాట్ఫారమ్ కోసం ఆప్టిమైజ్ చేసిన ఐకాన్లను అందిస్తుంది:

| ఫైల్                   | పరిమాణం           | ఉపయోగించేది                                    |
| ---------------------- | ----------------- | ---------------------------------------------- |
| `icon-512.png`         | 512×512           | Android ఇన్స్టాల్ ప్రాంప్ట్, స్ప్లాష్ స్క్రీన్ |
| `apple-touch-icon.png` | 180×180           | iOS హోమ్ స్క్రీన్ ఐకాన్                        |
| `icon-192.svg`         | 192×192 (వెక్టర్) | Android అడాప్టివ్ ఐకాన్                        |
| `apple-touch-icon.svg` | 180×180 (వెక్టర్) | Apple ఫాల్బ్యాక్                               |
| `favicon.svg`          | వెక్టర్           | బ్రౌజర్ ట్యాబ్లు                               |
| `favicon.ico`          | బహుళ పరిమాణాలు    | పాత బ్రౌజర్లు                                  |

### స్వయంచాలక రిజిస్ట్రేషన్

service worker, రూట్ లేఅవుట్లోని `<PwaRegister />` కాంపోనెంట్ ద్వారా స్వయంచాలకంగా రిజిస్టర్ చేయబడుతుంది. వినియోగదారు ఎలాంటి చర్య తీసుకోవాల్సిన అవసరం లేదు — చెల్లుబాటు అయ్యే మేనిఫెస్ట్ మరియు service workerను బ్రౌజర్ గుర్తించిన వెంటనే యాప్ ఇన్స్టాల్ చేయగలిగేదిగా మారుతుంది.

## సాంకేతిక నిర్మాణం

### వెబ్ యాప్ మానిఫెస్ట్ (`manifest.webmanifest`)

`src/app/manifest.ts` ద్వారా Next.js రూపొందిస్తుంది:

```json
{
  "name": "OmniRoute",
  "short_name": "OmniRoute",
  "description": "OmniRoute is an AI gateway for multi-provider LLMs. One endpoint for all your AI providers.",
  "start_url": "/",
  "scope": "/",
  "display": "fullscreen",
  "orientation": "any",
  "background_color": "#0b0f1a",
  "theme_color": "#0b0f1a",
  "icons": [
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    },
    { "src": "/apple-touch-icon.png", "sizes": "180x180", "type": "image/png" }
  ]
}
```

### సర్వీస్ వర్కర్ (`public/sw.js`)

ఫ్రేమ్వర్క్ డిపెండెన్సీలు లేని సాధారణ సర్వీస్ వర్కర్, ఇందులో:

- **ఇన్స్టాల్ దశ**: యాప్ షెల్ను ముందుగానే క్యాష్ చేస్తుంది (రూట్, ఆఫ్లైన్ పేజీ, మానిఫెస్ట్, ఐకాన్లు)
- **యాక్టివేట్ దశ**: పాత క్యాష్ వెర్షన్లను తొలగించి, అన్ని క్లయింట్లపై నియంత్రణను పొందుతుంది
- **ఫెచ్ దశ**: అభ్యర్థన రకం ఆధారంగా తెలివైన రూటింగ్ను నిర్వహిస్తుంది (నావిగేషన్, స్టాటిక్ అసెట్, API)
- **క్యాష్ వెర్షనింగ్**: `omniroute-pwa-v3` — అప్డేట్ చేసినప్పుడు తాజా క్యాష్ను తప్పనిసరిగా సృష్టించడానికి దీన్ని పెంచండి

### లేఅవుట్ మెటాడేటా (`src/app/layout.tsx`)

రూట్ లేఅవుట్ PWA అనుకూలతకు అవసరమైన అన్ని మెటా ట్యాగ్లను అందిస్తుంది:

- `/manifest.webmanifest`కు `manifest` లింక్
- iOS స్వతంత్ర మోడ్ కోసం `apple-web-app-capable: true`
- `apple-web-app-status-bar-style: black-translucent`
- Android Chrome కోసం `mobile-web-app-capable: yes`
- `theme-color: #0b0f1a`
- అంచు నుంచి అంచు వరకు రెండరింగ్ కోసం `viewport-fit: cover`

### కాంపోనెంట్: `PwaRegister`

`src/shared/components/PwaRegister.tsx`లో ఉన్న ఈ క్లయింట్ కాంపోనెంట్:

1. మౌంట్ అయినప్పుడు రన్ అవుతుంది (క్లయింట్ వైపు మాత్రమే)
2. బ్రౌజర్లో `serviceWorker` మద్దతు ఉందో లేదో తనిఖీ చేస్తుంది
3. `/sw.js`ను నిశ్శబ్దంగా నమోదు చేస్తుంది (యాప్ను బ్లాక్ చేయకుండా ఉండేందుకు లోపాలు విస్మరించబడతాయి)
4. ఏమీ రెండర్ చేయదు (`return null`) — ఇది సైడ్-ఎఫెక్ట్ కోసం మాత్రమే ఉపయోగించే కాంపోనెంట్

## Termuxతో ఉపయోగించడం (Android)

Androidలో Termux ద్వారా OmniRouteను రన్ చేస్తున్నప్పుడు, PWA ఎటువంటి అంతరాయం లేకుండా పనిచేస్తుంది:

1. Termuxలో OmniRouteను ప్రారంభించండి: `npx omniroute`
2. అదే ఫోన్లో Chromeను తెరవండి: `http://localhost:20128`
3. "హోమ్ స్క్రీన్కు జోడించు" ద్వారా PWAను ఇన్స్టాల్ చేయండి
4. PWA స్థానిక Termux సర్వర్కు కనెక్ట్ అవుతుంది — ప్రతిదీ పరికరంపైనే రన్ అవుతుంది

ఈ కలయికతో మీ Android ఫోన్ **సర్వర్** (Termux)గానూ, **క్లయింట్** (PWA)గానూ పనిచేస్తుంది — ఇది పూర్తిగా స్వయం సమృద్ధమైన AI గేట్వే.

## ఇతర పరికరాల నుంచి ఉపయోగించడం

మీ OmniRoute సర్వర్కు బ్రౌజర్ యాక్సెస్ ఉన్న ఏ పరికరంలోనైనా PWAను ఇన్స్టాల్ చేయండి:

- **మరొక ఫోన్/టాబ్లెట్**: `http://PHONE_IP:20128`కు వెళ్లి PWAను ఇన్స్టాల్ చేయండి
- **ల్యాప్టాప్**: Chrome/Edgeను తెరిచి, దాన్ని డెస్క్టాప్ PWAగా ఇన్స్టాల్ చేయండి
- **బ్రౌజర్ ఉన్న స్మార్ట్ టీవీ**: డ్యాష్బోర్డ్ను పూర్తి స్క్రీన్లో యాక్సెస్ చేయండి

## అనుకూలీకరణ

### ఇన్స్టాన్స్ పేరు

PWA శీర్షిక `Dashboard → Settings`లోని **ఇన్స్టాన్స్ పేరు** సెట్టింగ్ను అనుసరిస్తుంది. మీరు మీ ఇన్స్టాన్స్ పేరును "నా AI గేట్వే"గా మార్చితే, ఇన్స్టాల్ చేసిన PWAలో అదే పేరు కనిపిస్తుంది.

### అనుకూల ఫేవికాన్

మీరు `Dashboard → Settings` ద్వారా అనుకూల ఫేవికాన్ను అప్లోడ్ చేస్తే, డెస్క్టాప్లోని PWA ఐకాన్ ఆ అనుకూల ఐకాన్ను ప్రదర్శిస్తుంది. మొబైల్ హోమ్ స్క్రీన్ ఐకాన్లు ముందే రూపొందించిన `icon-512.png` మరియు `apple-touch-icon.png` ఫైల్లను ఉపయోగిస్తాయి.

## పరిమితులు

- **పుష్ నోటిఫికేషన్లు లేవు** — సర్వీస్ వర్కర్ Push APIని అమలు చేయదు. బదులుగా నోటిఫికేషన్లను Electron యాప్ నిర్వహిస్తుంది.
- **బ్యాక్గ్రౌండ్ సింక్ లేదు** — ఆఫ్లైన్ చర్యలను తర్వాత మళ్లీ అమలు చేయడానికి క్యూలో ఉంచరు. PWA ప్రధానంగా డ్యాష్బోర్డ్ వీక్షకంగా పనిచేస్తుంది.
- **iOS పరిమితులు** — iOSలోని Safari అన్ని PWA ఫీచర్లకు మద్దతు ఇవ్వదు (ఉదా., ఇన్స్టాల్ ప్రాంప్ట్లను మాన్యువల్గా ప్రారంభించాలి, అలాగే బ్యాక్గ్రౌండ్ సర్వీస్ వర్కర్లకు పరిమితులు ఉంటాయి).
- **క్యాష్ పరిమాణం** — సర్వీస్ వర్కర్ స్టాటిక్ అసెట్లను మాత్రమే క్యాష్ చేస్తుంది. `/api/` రూట్ల నుండి వచ్చే పెద్ద రెస్పాన్స్ పేలోడ్లను ఎప్పుడూ క్యాష్ చేయదు.
- **మొబైల్లో అనుకూల ఐకాన్లు** — సెట్టింగ్లలో ఫేవికాన్ను మార్చడం వల్ల మొబైల్లోని హోమ్ స్క్రీన్ ఐకాన్ అప్డేట్ కాదు (దీని కోసం PWA ఐకాన్లను మళ్లీ రూపొందించాలి).
