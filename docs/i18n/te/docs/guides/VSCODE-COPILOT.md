**OmniCopilot** మీ OmniRoute అందించే ప్రతి మోడల్ను _స్థానిక_ GitHub Copilot Chat
మోడల్ పికర్లో ఉంచుతుంది. రెండవ సైడ్బార్ లేదు, ప్రత్యేక చాట్ UI లేదు — Copilot యొక్క ఏజెంట్ మోడ్, టూల్ కాలింగ్,
MCP సర్వర్లు మరియు అనుకూల సూచనలు అన్నీ పనిచేస్తూనే ఉంటాయి; మీరు ఎంచుకున్న మోడల్పై మాత్రమే రన్ అవుతాయి.

## సెటప్

1. **OmniRouteను రన్ చేయండి** — `npm install -g omniroute && omniroute` (`http://localhost:20128`లో డాష్బోర్డ్).
2. **ఎక్స్టెన్షన్ను ఇన్స్టాల్ చేయండి** — Extensions వీక్షణలో "OmniRoute" కోసం శోధించండి.
3. **మోడల్ను ఎంచుకోండి** — Copilot Chat → మోడల్ పికర్ → **మోడల్లను నిర్వహించండి…** → **OmniRoute**, ఆపై
   మీకు కావాల్సిన వాటిని టిక్ చేయండి.

OmniRoute డిఫాల్ట్ పోర్ట్లో రన్ అవుతున్నప్పుడు ఏదీ కాన్ఫిగర్ చేయాల్సిన అవసరం లేదు. రిమోట్ ఇన్స్టాన్స్ కోసం,
**Activity Barలోని OmniRoute చిహ్నాన్ని** తెరవండి (లేదా `OmniRoute: Manage Connection`ను రన్ చేయండి) మరియు వీటిని సెట్ చేయండి:

- **సర్వర్ URL** — సర్వర్ రూట్, ఉదా. `http://192.168.0.15:20128`. `/v1` సఫిక్స్ను
  ఎక్స్టెన్షన్ జోడిస్తుంది; దాన్ని చేర్చవద్దు.
- **API కీ** — సర్వర్ `REQUIRE_API_KEY`ను సెట్ చేసినప్పుడు మాత్రమే. VS
  Code SecretStorage ద్వారా OS కీచైన్లో నిల్వ చేయబడుతుంది, `settings.json`లో ఎప్పుడూ నిల్వ చేయబడదు.

## పికర్లో ఏమి కనిపిస్తుంది

ఎక్స్టెన్షన్ ముడి `GET /v1/models` పేలోడ్ను చూపదు — అది దానికి తగిన రూపాన్ని ఇస్తుంది, అలాగే మీరు
చూసే సంఖ్య రెండు ఉద్దేశపూర్వక కారణాల వల్ల కేటలాగ్ పరిమాణం కంటే తక్కువగా ఉంటుంది.

### ఇది ఒక్కో మోడల్కు ఒక idను అడుగుతుంది

`MODELS_CATALOG_PREFIX_MODE` డిఫాల్ట్గా **`dual`** ఉంటుంది, ఇది ప్రతి మోడల్ను రెండుసార్లు ప్రకటిస్తుంది — ఒకసారి
సంక్షిప్త అలియాస్ ప్రిఫిక్స్ కింద, మరొకసారి ప్రామాణిక ప్రొవైడర్ ప్రిఫిక్స్ కింద — తద్వారా పాత క్లయింట్
కాన్ఫిగరేషన్లు ఏ రూపాన్నైనా పరిష్కరించగలుగుతాయి:

```
cc/claude-sonnet-4-6        ← అలియాస్ ప్రిఫిక్స్
claude/claude-sonnet-4-6    ← ప్రామాణిక ప్రిఫిక్స్, అదే మోడల్
```

ఎక్స్టెన్షన్ **`GET /v1/models?prefix=alias`**ను అభ్యర్థిస్తుంది, అందువల్ల మీ ఇతర క్లయింట్ల కోసం
సర్వర్-వ్యాప్త సెట్టింగ్ను మార్చకుండానే ఒక్కో మోడల్కు ఒక id వస్తుంది. ఒక రిఫరెన్స్ ఇన్స్టాన్స్లో ఇది
**2345 ఎంట్రీలను 1396కు కుదించింది — 949 నకళ్లు, కోల్పోయిన మోడల్లు సున్నా.**

మీరు దీన్ని _ప్రతి_ క్లయింట్ కోసం సర్వర్-వ్యాప్తంగా పరిష్కరించాలనుకుంటే, డాష్బోర్డ్లో
`MODELS_CATALOG_PREFIX_MODE` ఫీచర్ ఫ్లాగ్ను `alias`కు సెట్ చేయండి. క్వెరీ పరామితి మరియు
ఒక్కో మోడ్కు సంబంధించిన పట్టిక కోసం [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) చూడండి.

### చాట్ చేయలేని మోడల్లను ఇది దాచుతుంది

కేటలాగ్లో ఇమేజ్, వీడియో, ఆడియో, రీర్యాంక్, ఎంబెడింగ్ మరియు మోడరేషన్ మోడల్లు కూడా జాబితా చేయబడతాయి. చాట్ అభ్యర్థనలో
అవి ఎలాగైనా తిరస్కరించబడతాయి:

```
HTTP 400 — మోడల్ '<id>' ఒక ఇమేజ్-జనరేషన్ మోడల్ మరియు దాన్ని
/v1/chat/completionsలో ఉపయోగించలేరు. బదులుగా POST /v1/images/generationsను ఉపయోగించండి.
```

కాబట్టి అవి పికర్కు చేరకముందే వాటి `type` ఫీల్డ్ ఆధారంగా ఫిల్టర్ చేయబడతాయి. **Responses-API
మోడల్లు ఉంచబడతాయి** — ప్రతి Codex / GPT-5.x ఎంట్రీ `supported_endpoints: ["responses"]`ను ప్రకటిస్తుంది,
మరియు OmniRoute వాటిని `/v1/chat/completions` కోసం అనువదిస్తుంది, కాబట్టి అవి పూర్తిగా ఉపయోగించదగినవి.

### మీరు ఎప్పుడూ కాన్ఫిగర్ చేయని ప్రొవైడర్లు

కేటలాగ్లో **యాక్టివ్ కనెక్షన్** ఉన్న ప్రొవైడర్ల మోడల్లతో పాటు ప్రతి **noAuth**
ప్రొవైడర్ కూడా జాబితా చేయబడుతుంది — ఫ్రీ టైర్లో ఎక్కువ భాగాన్ని అందించే కీ అవసరం లేని ప్రొవైడర్లు ఇవే. ఇది ఉద్దేశపూర్వకం. వాటిని దాచడానికి,
డాష్బోర్డ్ సెట్టింగ్లలోని `blockedProviders`కు వాటిని జోడించండి; ఎక్స్టెన్షన్లో
ఏదీ మారదు.

## VS Code ట్యాబ్లోని Dashboard

`omnicopilot.dashboardOpen: "editor"` బాహ్య బ్రౌజర్కు బదులుగా Simple Browser ద్వారా OmniRoute dashboardను editor ట్యాబ్లో రెండర్ చేస్తుంది. ఎంబెడింగ్ను **సర్వర్లో ప్రత్యేకంగా ప్రారంభించాలి**; ఇందుకు `DASHBOARD_ALLOW_EMBED=vscode` ఉపయోగించాలి. ఇది HTML పేజీలను డిఫాల్ట్ `frame-ancestors 'none'` + `X-Frame-Options: DENY`కు బదులుగా `frame-ancestors 'self' vscode-webview:`తో అందిస్తుంది. ఏ విధానాన్ని ఉపయోగించినా API ఉపరితలం (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) కఠినమైన హెడర్లను అలాగే ఉంచుతుంది.

> ⚠️ **ఇది build-time ఫ్లాగ్, runtime ఫ్లాగ్ కాదు.** Next.js `headers()`ను route manifestలో కంపైల్ చేస్తుంది, కాబట్టి bundleను build చేస్తున్నప్పుడు `next.config.mjs` ఈ వేరియబుల్ను చదువుతుంది
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> ఇప్పటికే build చేసిన సర్వర్ను ప్రారంభించే ముందు దీన్ని export చేయడం వల్ల ఏ మార్పూ ఉండదు — హెడర్లు buildలోనే స్థిరంగా పొందుపరచబడతాయి.

```bash
# వేరియబుల్ BUILD కమాండ్ అమలయ్యే సమయంలో తప్పనిసరిగా ఉండాలి
DASHBOARD_ALLOW_EMBED=vscode npm run build        # లేదా npm run build:release
npm start
```

## VS Code లోపల నుంచే మీ ఇతర సాధనాలను కాన్ఫిగర్ చేయడం

**`OmniRoute: Configure Coding CLI`** అనేది Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code, Kilo మరియు Roo కోసం వెంటనే ఉపయోగించగల profilesను రాయడానికి `omniroute` CLIని నడిపిస్తుంది — ఇవే కాన్ఫిగరేషన్లు
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md)లో వివరించబడ్డాయి. API key ఎప్పుడూ command lineలో ఇవ్వబడదు; అది `OMNIROUTE_API_KEY` environment variable ద్వారా CLIకి అందించబడుతుంది.
