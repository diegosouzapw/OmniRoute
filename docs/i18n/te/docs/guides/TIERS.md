OmniRoute మద్దతిచ్చే 352 ప్రొవైడర్లను 3 ఆర్థిక స్థాయిలుగా నిర్వహిస్తుంది. ప్రతి
అభ్యర్థన విజయవంతమైన ప్రతిస్పందన లభించే వరకు వాటి గుండా క్రమంగా ప్రయాణిస్తుంది — దీనివల్ల
ఫాల్బ్యాక్ కోడ్ను ఎప్పుడూ రాయకుండానే, అందుబాటులో ఉన్న అత్యంత చౌకైన ప్రతిస్పందనను పొందుతారు.

## స్థాయి 1 — సబ్స్క్రిప్షన్

**మీరు ఇప్పటికే చెల్లిస్తున్న ప్రొవైడర్లు.** కోటా గడువు ముగియడానికి ముందు OmniRoute
దానిలోని ప్రతి భాగాన్నీ ఉపయోగిస్తుంది.

| ప్రొవైడర్                             | స్థాయి 1 కావడానికి కారణం                           |
| ------------------------------------- | -------------------------------------------------- |
| Claude Code OAuth                     | Anthropic Pro/Team — స్థిర ధర, తరచుగా ఉపయోగించబడదు |
| OpenAI Codex (ChatGPT సబ్స్క్రిప్షన్) | Plus/Teamలో Codex కోటా ఉంటుంది                     |
| GitHub Copilot                        | ఒక్కో సీటుకు — కోటా నెలవారీగా రీసెట్ అవుతుంది      |
| Cursor IDE                            | Pro ప్లాన్ కోటా                                    |
| Antigravity / Devin Desktop           | అంతర్నిర్మిత కోటాలు                                |

**వ్యూహం**: మోడల్ సామర్థ్యాలకు సరిపోయే ప్రతి అభ్యర్థనను ముందుగా ఇక్కడికి రూట్ చేయండి.
కోటా ట్రాకర్ సమీపిస్తున్న రీసెట్లను పర్యవేక్షిస్తుంది, అలాగే `reset-aware`
కాంబో వ్యూహం దానికి అనుగుణంగా ప్రాధాన్యత ఇస్తుంది. ముందుగా స్థాయి 1కి రూట్ చేసి,
కోటా అయిపోయినప్పుడు మాత్రమే చెల్లింపు స్థాయిలకు వెళ్లడానికి `auto/thrifty` idని ఉపయోగించండి — లేదా
ప్లాన్లో చేర్చబడిన సామర్థ్యానికే పరిమితమై, అది అందుబాటులో లేకపోతే విఫలం కావడానికి `auto/subscription`
ఉపయోగించండి. [సబ్స్క్రిప్షన్-ప్రథమ రూటింగ్](../routing/SUBSCRIPTION_LADDER.md) చూడండి.

## స్థాయి 2 — చౌకైనవి

**1M టోకెన్లకు $1 కంటే తక్కువ ధరగల, టోకెన్కు చెల్లించే ప్రొవైడర్లు.** అధిక-పరిమాణ పనుల కోసం
లేదా స్థాయి 1 కోటాలు పరిమితులను చేరుకున్న తర్వాత ఉపయోగించడానికి కేటాయించబడ్డాయి.

| ప్రొవైడర్                           | ధర (ఇన్పుట్/అవుట్పుట్) | సామర్థ్యాలు            |
| ----------------------------------- | ---------------------- | ---------------------- |
| DeepSeek V4 Pro                     | 1Mకు $0.27 / $1.10     | కోడ్, తార్కిక విశ్లేషణ |
| GLM-4.5                             | 1Mకు $0.60 / $2.20     | సుదీర్ఘ కాంటెక్స్ట్    |
| MiniMax M1                          | 1Mకు $0.20 / $1.10     | వేగం                   |
| Qwen Coder                          | 1Mకు $0.30 / $1.20     | కోడ్                   |
| OpenRouter (ధర-ఆప్టిమైజ్ చేయబడినది) | మారుతుంది              | 100+ మోడళ్లు, డైనమిక్  |

**వ్యూహం**: పని యొక్క సామర్థ్య ఫిల్టర్కు (విజన్, JSON మోడ్, టూల్స్, గరిష్ఠ-కాంటెక్స్ట్)
సరిపోయే అత్యల్ప $/token మోడల్ను `cost-optimized` కాంబో ఎంచుకుంటుంది.

## స్థాయి 3 — ఉచితం

**సున్నా-ఖర్చు ప్రొవైడర్లు** — ఉచిత స్థాయిలు, క్రెడిట్ ప్రోగ్రామ్లు, OAuth రోజువారీ కోటాలు.

| ప్రొవైడర్        | ఉచిత కోటా / క్రెడిట్లు                                  |
| ---------------- | ------------------------------------------------------- |
| Kiro AI          | ఉచిత Claude స్థాయి (ఉదారమైన న్యాయసమ్మత-వినియోగ పరిమితి) |
| OpenCode Free    | ప్రామాణీకరణ అవసరం లేదు, ఉదారమైన రేట్ పరిమితులు          |
| Qoder            | ఉచిత OAuth                                              |
| Google Vertex AI | కొత్త ఖాతాకు $300 క్రెడిట్లు                            |
| Amazon Q         | AWS వినియోగదారులకు ఉచిత స్థాయి                          |
| Pollinations     | ఓపెన్ పబ్లిక్ API                                       |
| Cloudflare AI    | Workers AI ఉచిత స్థాయి                                  |

**వ్యూహం**: స్థాయి 1+2 విఫలమైనప్పుడు లేదా `useFreeOnly=true` సెట్ చేసినప్పుడు,
బడ్జెట్ పరిమితితో కూడిన `auto` కాంబో అభ్యర్థనలను ఇక్కడికి రూట్ చేస్తుంది. ఉచిత ప్రొవైడర్లకు తరచుగా బలహీనమైన
రేట్ పరిమితులు ఉంటాయి — బ్యాక్ఆఫ్ సమయంలో సర్క్యూట్ బ్రేకర్ వాటిని తిరిగి అందుబాటులోకి తెస్తుంది.

## స్థాయిలను కాన్ఫిగర్ చేయడం

డ్యాష్బోర్డ్ → **స్థాయిలు** → మీ ప్రొవైడర్లను కేటాయించండి. డిఫాల్ట్లు (`tierDefaults.json` నుండి)
సముచితంగా ఉంటాయి; ప్రాధాన్యత ఇవ్వాల్సిన నిర్దిష్ట సబ్స్క్రిప్షన్లు లేదా మినహాయించాల్సిన ప్రొవైడర్లు ఉన్నప్పుడు వాటిని సవరించండి.

Auto-Combo యొక్క 16-కారకాల స్కోరింగ్ స్థాయిని కూడా పరిగణనలోకి తీసుకుంటుంది.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) చూడండి.

## టెలిమెట్రీ

డ్యాష్బోర్డ్ → **వినియోగం** ప్రతి స్థాయిలో రోజుకు ఖర్చయిన టోకెన్లను చూపిస్తుంది. దీన్ని వీటి కోసం ఉపయోగించండి:

- స్థాయి 1 పూర్తిగా ఉపయోగించబడుతోందని నిర్ధారించండి (లేకపోతే మీరు సబ్స్క్రిప్షన్ విలువను వృథా చేస్తున్నారు)
- ఏ స్థాయి 2 మోడళ్లు ఎక్కువగా ఎంచుకోబడుతున్నాయో గుర్తించండి (వాటిని 1-2కు ఏకీకృతం చేయండి)
- పరీక్ష/అన్వేషణ వర్క్లోడ్లపై స్థాయి 3 డబ్బు ఆదా చేస్తోందని ధృవీకరించండి

## సాధారణ నమూనాలు

### పూర్తిగా ఉచిత వర్క్లోడ్

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

స్థాయి 3 వైపు బలంగా మళ్లిస్తుంది; స్థాయి 3 అందుబాటులో లేకపోతే మాత్రమే స్థాయి 2ను ఉపయోగిస్తుంది.

### చౌకైన ఫాల్బ్యాక్తో సబ్స్క్రిప్షన్కు ప్రథమ ప్రాధాన్యత

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

స్థాయి 1 → స్థాయి 2 → స్థాయి 3కు సరిపోలే స్పష్టమైన క్రమబద్ధ జాబితా.
