OmniRoute బాహ్య ప్రొవైడర్ల (1proxy, proxifly, iplocate, webshare) నుండి సమకాలీకరించబడిన, ఎంపిక చేసిన ఉచిత ప్రాక్సీల సమూహాన్ని `free_proxies` పట్టికలో అందిస్తుంది. డ్యాష్బోర్డ్ వీటిని **Settings → Free Proxies** కింద ప్రదర్శిస్తుంది. జాబితా రూట్ అందించే సర్వర్-సైడ్ ఫిల్టరింగ్, సార్టింగ్, కౌంటింగ్ మరియు సమకాలీకరణ-లోపాల నివేదనను ఈ పత్రం వివరిస్తుంది.

## జాబితా రూట్ — `GET /api/settings/free-proxies`

మొత్తం సంఖ్యతో పాటు ఫిల్టర్ చేసిన, క్రమబద్ధీకరించిన, పేజినేట్ చేసిన భాగాన్ని తిరిగి ఇస్తుంది. ఫిల్టరింగ్ మరియు కౌంటింగ్ SQLలో జరుగుతాయి, కాబట్టి ప్రతి వరుసను మెమరీలోకి లోడ్ చేయకుండానే UI వాస్తవ మొత్తాన్ని (ఉదా. `Total: 0`) చూపగలదు.

### క్వెరీ పారామీటర్లు

| పారామ్            | రకం                                | డిఫాల్ట్  | అర్థం                                                                                                                     |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------- |
| `search`          | స్ట్రింగ్                          | `""`      | హోస్ట్ (మరియు సోర్స్) కాలమ్పై కేస్-సెన్సిటివ్ `LIKE`.                                                                     |
| `protocol`        | స్ట్రింగ్                          | `""`      | `type` ఫిల్టర్: `http` / `https` / `socks4` / `socks5`. ఖాళీగా ఉంటే = అన్నీ.                                              |
| `country`         | స్ట్రింగ్                          | `""`      | `countryCode` ఫిల్టర్ (ISO-2). ఖాళీగా ఉంటే = అన్నీ.                                                                       |
| `minQuality`      | సంఖ్య                              | `0`       | `qualityScore >= minQuality` ఉన్న వరుసలు మాత్రమే. `0` = కనిష్ఠ పరిమితి లేదు.                                              |
| `disabledSources` | స్ట్రింగ్                          | `""`      | మినహాయించాల్సిన, కామాలతో వేరు చేసిన సోర్స్ idలు (ఉదా. `proxifly,webshare`).                                               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = స్కోర్ అవరోహణ క్రమం; `latency` = లేటెన్సీ ఆరోహణ క్రమం (nullలు చివర); `recent` = `lastValidated` అవరోహణ క్రమం. |
| `offset`          | సంఖ్య                              | `0`       | పేజినేషన్ ప్రారంభం.                                                                                                       |
| `limit`           | సంఖ్య                              | `50`      | పేజీ పరిమాణం (సర్వర్ వైపు గరిష్ఠ పరిమితి విధించబడుతుంది).                                                                 |

### ప్రతిస్పందన

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` అనేది పేజినేషన్కు **ముందు** ఉన్న ఫిల్టర్ చేసిన మొత్తాన్ని సూచిస్తుంది, కాబట్టి UI `Total: N` మరియు `hasMore`ను స్వతంత్రంగా రెండర్ చేయగలదు. `syncErrors` సోర్స్ id ఆధారంగా కీ చేయబడుతుంది మరియు చివరి సమకాలీకరణ విఫలమైన సోర్స్లకు మాత్రమే పూరించబడుతుంది — `Total: 0` ఫలితం ఎప్పుడూ ఎటువంటి సమాచారం లేకుండా ఉండదు.

## పూల్కు జోడించడం — `POST /api/settings/free-proxies/[id]/add-to-pool`

ఉచిత ప్రాక్సీని నిర్వహిత `proxy_registry` పూల్లోకి ప్రమోట్ చేస్తుంది. ముందుగా అప్స్ట్రీమ్ను ధృవీకరిస్తుంది; విజయవంతమైతే కొత్త పూల్ ప్రాక్సీ id మరియు కొలిచిన లేటెన్సీని తిరిగి ఇస్తుంది.

## సమకాలీకరణ — `POST /api/settings/free-proxies/sync`

ప్రారంభించబడిన అన్ని సోర్స్లను (లేదా `{ "sources": [...] }`లోని ఉపసమితిని) మళ్లీ పొందుతుంది. ప్రతి సోర్స్ స్వతంత్రంగా సమకాలీకరించబడుతుంది; విఫలమైన సోర్స్ `syncErrors`లో నమోదు చేయబడుతుంది మరియు మిగిలినవి పూర్తవుతూనే ఉంటాయి, కాబట్టి పాక్షిక సమకాలీకరణలు గతంలోని మంచి డేటాను ఎప్పుడూ తొలగించవు.

## గణాంకాలు — `GET /api/settings/free-proxies/stats`

వరుసల పేలోడ్ లేకుండా `total / inPool / avgQuality / bySource / lastSyncAt` సమగ్ర గణాంకాలను తిరిగి ఇస్తుంది — దీనిని డ్యాష్బోర్డ్ హెడర్ విడ్జెట్లు ఉపయోగిస్తాయి.
