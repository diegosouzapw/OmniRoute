## వర్గాలు

- **ఉచితం** — API కీతో ఉచిత స్థాయి (డ్యాష్బోర్డ్ ద్వారా కాన్ఫిగర్ చేయబడుతుంది)
- **ప్రామాణీకరణ లేదు** — ఎలాంటి కీ లేదా సైన్-ఇన్ అవసరం లేని పబ్లిక్ ఎండ్పాయింట్లు
- **OAuth** — OmniRoute నిర్వహించే సైన్-ఇన్ ప్రవాహం, API కీ అవసరం లేదు
- **వెబ్ కుకీ** — కుకీ ప్రామాణీకరణ ద్వారా ప్రొవైడర్ వెబ్ యాప్ను ర్యాప్ చేస్తుంది
- **API కీ** — API కీ ద్వారా కాన్ఫిగర్ చేయబడే చెల్లింపు ప్రొవైడర్ (ఉచిత క్రెడిట్లు వర్తించవచ్చు)
- **స్థానికం** — వినియోగదారు మెషీన్పై నడుస్తుంది (Ollama, LM Studio, vLLM మొదలైనవి)
- **శోధన** — వెబ్ శోధన ప్రొవైడర్లు
- **ఆడియో** — ఆడియో-మాత్రమే అందించే ప్రొవైడర్లు (TTS/STT)
- **అప్స్ట్రీమ్ ప్రాక్సీ** — ఇతర ప్రొవైడర్లకు ప్రాక్సీగా వ్యవహరించే ప్రొవైడర్లు
- **క్లౌడ్ ఏజెంట్** — దీర్ఘకాలం నడిచే కోడింగ్ ఏజెంట్లు (Codex Cloud, Devin, Jules)
- **సిస్టమ్** — OmniRoute అంతర్గత ప్రొవైడర్లు (లూప్బ్యాక్ మొదలైనవి)

అదనపు ట్యాగ్లు: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (చూపించిన చోట): `native` — నిజమైన ఫంక్షన్-కాలింగ్ API; `emulated` — `tools` అర్రే `webTools.ts` ద్వారా ప్రాంప్ట్-ఎమ్యులేట్ చేయబడుతుంది (రెగ్యులర్ ఎక్స్ప్రెషన్తో పార్స్ చేసిన `<tool>{...}</tool>` బ్లాక్లు); `none` — ప్రస్తుతం `tools` ఎలాంటి సమాచారం ఇవ్వకుండా తొలగించబడుతుంది. #7286 చూడండి.

ప్రతి ప్రొవైడర్ను ప్రారంభించడానికి, కాన్ఫిగర్ చేయడానికి మరియు పరీక్షించడానికి `/dashboard/providers` వద్ద ఉన్న డ్యాష్బోర్డ్ను ఉపయోగించండి.
