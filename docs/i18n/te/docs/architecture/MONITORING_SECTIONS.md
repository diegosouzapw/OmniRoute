```
...
```

## ఖర్చుల విభాగం (కొత్తది, స్థాయి 1)

పాత్ ప్రిఫిక్స్: `/dashboard/costs/`

| అంశం            | URL                                  | వివరణ                                                     |
| --------------- | ------------------------------------ | --------------------------------------------------------- |
| అవలోకనం         | `/dashboard/costs`                   | సమగ్ర ఖర్చుల డ్యాష్బోర్డ్ (అనలిటిక్స్ నుండి తరలించబడింది) |
| ధరలు            | `/dashboard/costs/pricing`           | ప్రతి మోడల్కు ధరల పట్టిక                                  |
| బడ్జెట్         | `/dashboard/costs/budget`            | బడ్జెట్ పరిమితులు + హెచ్చరికలు                            |
| కోటా షేరింగ్    | `/dashboard/costs/quota-share`       | కోటా షేర్ పూల్స్ + వినియోగం                               |
| ప్లాన్ కాన్ఫిగ్ | `/dashboard/costs/quota-share/plans` | ప్రతి ప్రొవైడర్కు ప్లాన్ ఓవర్రైడ్లు                       |

**హేతువు**: ధరలు, బడ్జెట్ మరియు కోటా షేరింగ్ గతంలో
`మానిటరింగ్ > ఖర్చుల పారామీటర్లు` కింద ఉండేవి. వాటిని ప్రత్యేక ఉన్నత-స్థాయి విభాగానికి
తరలించడం వల్ల, అబ్జర్వబిలిటీ సాధనాల ద్వారా నావిగేట్ చేయకుండానే వాటిని కనుగొనవచ్చు.

## మానిటరింగ్ విభాగం (పునర్వ్యవస్థీకరించబడింది)

మానిటరింగ్ విభాగంలో ఇప్పుడు **ఎగువన యాక్టివిటీ**, దాని తర్వాత **3 ఉపసమూహాలు** ఉన్నాయి:

```
మానిటరింగ్
├── యాక్టివిటీ             ← టైమ్లైన్ ఫీడ్ (ఉన్నత-స్థాయి అంశం)
├── లాగ్ల సమూహం
│   ├── లాగ్లు (అన్నీ)
│   ├── ప్రాక్సీ లాగ్లు
│   └── కన్సోల్ లాగ్లు
├── ఆడిట్ సమూహం
│   ├── ఆడిట్ లాగ్
│   ├── MCP ఆడిట్
│   └── A2A ఆడిట్
└── సిస్టమ్ సమూహం
    ├── హెల్త్
    └── రన్టైమ్
```

### పాత నిర్మాణంతో పోలిస్తే మారినవి

| ముందు                                                                                 | తర్వాత                                             |
| ------------------------------------------------------------------------------------- | -------------------------------------------------- |
| యాక్టివిటీ = ఆడిట్ లాగ్ను రెండర్ చేసే లాగ్లలోని ట్యాబ్                                | యాక్టివిటీ = ప్రత్యేక ఫీడ్ (`/dashboard/activity`) |
| మానిటరింగ్లో ఖర్చుల పారామీటర్ల సమూహం                                                  | ఖర్చుల విభాగానికి తరలించబడింది                     |
| సమతల జాబితా: లాగ్లు, యాక్టివిటీ (లాగ్లు), ఆడిట్, హెల్త్, రన్టైమ్, ధరలు, బడ్జెట్, కోటా | నిర్మాణాత్మక 3-సమూహాలు + ప్రత్యేక ఖర్చుల విభాగం    |

## యాక్టివిటీ vs ఆడిట్ లాగ్

ఇవి రెండూ ఇప్పుడు వేర్వేరు:

| కొలమానం             | యాక్టివిటీ (`/dashboard/activity`)                                  | ఆడిట్ లాగ్ (`/dashboard/audit`)                      |
| ------------------- | ------------------------------------------------------------------- | ---------------------------------------------------- |
| **ఉద్దేశ్యం**       | వినియోగదారుకు కనిపించే ఈవెంట్ ఫీడ్ ("ఇటీవల ఏమి జరిగింది")           | కంప్లయెన్స్ / భద్రతా లాగ్                            |
| **డేటా మూలం**       | `GET /api/compliance/audit-log?level=high`                          | `GET /api/compliance/audit-log?level=all`            |
| **ఫార్మాట్**        | రోజు వారీగా సమూహపరచిన టైమ్లైన్, సులభంగా అర్థమయ్యే క్రియలు + ఐకాన్లు | సాంద్రమైన పేజీలుగా విభజించిన పట్టిక, ఒక్కో పేజీకి 50 |
| **ఫిల్టర్లు**       | ఈవెంట్ రకం వర్గం                                                    | చర్య, తీవ్రత, యాక్టర్, తేదీ పరిధి                    |
| **ఎగుమతి**          | అందుబాటులో లేదు                                                     | JSON ఎగుమతి                                          |
| **యాక్టర్ ఫిల్టర్** | వర్తించదు                                                           | యాక్టర్ ఆధారంగా ఫిల్టర్ చేయవచ్చు                     |
| **చూపబడే ఈవెంట్లు** | ఉన్నత-స్థాయి చర్యలు మాత్రమే (అనుమతి జాబితా)                         | అన్ని ఆడిట్ ఈవెంట్లు                                 |

### ఉన్నత-స్థాయి చర్యల అనుమతి జాబితా

`src/lib/audit/highLevelActions.ts`లో నిర్వచించబడింది. యాక్టివిటీ ఫీడ్లో ఏ ఈవెంట్లు
కనిపించాలో ఇది నియంత్రిస్తుంది. అనుమతి జాబితాలో ఇవి ఉంటాయి:

- ప్రొవైడర్ జోడింపు/తొలగింపు/పరీక్ష ఈవెంట్లు
- కాంబో సృష్టి/నవీకరణ/తొలగింపు
- API కీ జీవితచక్రం (సృష్టించడం, రద్దు చేయడం, రొటేట్ చేయడం)
- బడ్జెట్ పరిమితిని చేరుకోవడం
- Auth లాగిన్/లాగ్అవుట్
- క్లౌడ్ ఏజెంట్ సెషన్ సృష్టి
- MCP టూల్ నమోదు
- వెబ్హుక్ సృష్టి/తొలగింపు
- కోటా పూల్/ప్లాన్ మార్పులు (`quota.*` చర్యలు, Group B)
- ప్లాట్ఫారమ్ ఈవెంట్లు (నవీకరణ, డిప్లాయ్మెంట్)
- స్కిల్ ఇన్స్టాలేషన్/తొలగింపు

ఈ జాబితాలో లేని ఈవెంట్లు ఆడిట్ లాగ్లో మాత్రమే కనిపిస్తాయి.

### కొత్త ఉన్నత-స్థాయి చర్యను జోడించడం

`src/lib/audit/highLevelActions.ts`ను సవరించి, చర్య స్ట్రింగ్ను
`HIGH_LEVEL_ACTIONS`కు జోడించండి. దీనికి PR అవసరం (ఈ జాబితా కోడ్లో ఉంటుంది, DB ద్వారా కాన్ఫిగర్ చేయలేరు).
సంబంధిత ఐకాన్ను `src/lib/audit/activityIcons.ts`కు జోడించవచ్చు.

## రీడైరెక్ట్: `/dashboard/logs/activity`

పాత పాత్ `/dashboard/logs/activity`, `src/app/(dashboard)/dashboard/logs/activity/page.tsx`లోని
`permanentRedirect()` ద్వారా `/dashboard/activity`కు శాశ్వతంగా రీడైరెక్ట్ చేయబడుతుంది (HTTP 308).

పాత IDని సూచించే వినియోగదారు ప్రీసెట్లు దెబ్బతినకుండా ఉండేందుకు, లెగసీ సైడ్బార్ ID `logs-activity`
`HIDEABLE_SIDEBAR_ITEM_IDS`లో భద్రపరచబడింది
(కానీ `SIDEBAR_DEFINITIONS` నుండి తొలగించబడింది).
