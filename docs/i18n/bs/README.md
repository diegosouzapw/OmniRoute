## 💰 ~1,62 milijarde besplatnih tokena / mjesečno

</div>

> Ručno slaganje besplatnih nivoa je mukotrpno — desetine SDK-ova, desetine ograničenja brzine, a nemate pojma koliko zapravo imate. OmniRoute katalogizira **491 unosa besplatnog nivoa u 35 ponavljajućih ključeva bazena** i izračunava naslov tokena iz **17 bazena sa objavljenim pozitivnim mjesečnim budžetom plus pet ograničenja Groq-a po modelu**, dedupliciranih dijeljenim bazenom. Kvote koje se otvaraju tek nakon provjere regionalnog identiteta (danas: ModelScope) prikazane su odvojeno, +~6M iza verifikacije regionalnog identiteta, i nikada se ne sumiraju u naslov. Rezultat ostaje vidljiv na kontrolnoj tabli (`/dashboard/free-tiers`).

<img src="./docs/diagrams/free-tier-budget.svg" width="100%" alt="OmniRoute kartica s budžetom za besplatni nivo: ~1,62 milijarde besplatnih tokena mjesečno konstantno, do ~2,22 milijarde u prvom mjesecu s kreditima za registraciju, od 35 dokumentiranih ključeva ponavljajućeg fonda koji pokrivaju 491 katalogizirani unos besplatnog nivoa iza jedne krajnje tačke. Iskrena matematika bez dupliciranog fonda — svaki dijeljeni fond se računa jednom, uključujući 17 ponavljajućih fonda s objavljenim pozitivnim mjesečnim budžetom tokena plus pet ograničenja Groq po modelu; 13 dobavljača je označeno kao izbjegavano u katalogu rizika uvjeta, pa vi odlučujete. Traka budžeta uključuje Mistral 1B, Nara 210M, LLM7 150M, xKiro 150M, Groq 30M (pet ograničenja po modelu) i manje fondove, plus kredite za registraciju za prvi mjesec i trajno besplatne dobavljače bez ograničenja tokena koji se pojavljuju odvojeno kako nikada ne bi napuhali naslov. Aktivno korišteno/preostalo /kontrolna-tabla/slobodni-nivoi."/>

> Animirani sažetak stranice `/dashboard/free-tiers` uživo. Potpuna metodologija (deduplikatizacija bazena, kreditni nivoi, uslovi pružatelja usluga): **[docs/reference/FREE_TIERS.md](docs/reference/FREE_TIERS.md)**.
>
> <sub>Ove brojke se ponovo revidiraju svake dvije sedmice u odnosu na aktivni katalog i **kreću se u oba smjera** — ako provajder završi besplatni nivo, broj opada; ako se pojavi novi, broj raste. Objavljujemo ono što katalog zapravo izračuna, nikada zaokruženi najbolji slučaj.</sub>

## 📡 OmniRoute radar

Glavni naslov besplatnog nivoa ostaje **~1,62 milijarde tokena mjesečno** iz dokumentovanog,
Iznad je katalog bez duplikata iz bazena. Privremeni krediti za registraciju dobavljača mogu zasebno podići prvi
mjesečno do **~2,22 milijarde**. Radar je opcionalni, potpisani kataloški sloj za ljude koji žele svježije
dostupnost besplatnih modela između izdanja OmniRoute-a; katalog zajednice i svaki postojeći besplatni
funkcija ostaje besplatna.

Podržavaoci mogu dobiti katalog uživo i dodatne mogućnosti pružatelja usluga. To je odvojeno,
Promjenjivi limit je **najviše približno 3 milijarde tokena mjesečno**, ovisno o dostupnosti provajdera.
Taj limit nije garancija: pružaoci usluga mogu mijenjati kvote, podobnost, modele ili regije na
bilo kada.

Radar se koristi uz pretplatu i samo putem GET protokola. OmniRoute klijent ne prenosi upite, promet, podatke o provajderu.
konfiguracija, telemetrija korištenja ili lokalno stanje odbacivanja najava. Saznajte više o ispunjavanju uslova i

## 🔌 Potpuni CLI + A2A i MCP

</div>

> Pored servera, OmniRoute je **potpuni kokpit komandne linije** sa **80+ komandi**, plus otvorenim protokolima za agente tako da ga AI agent može upravljati **samostalno**.

### ⌨️ Pravi CLI (ne samo `start`)

bash
omniroute # serve gateway + dashboard (port 20128)
omniroute chat # interaktivni TUI chat klijent (kosa crta: /model /combo /skill /memory)
omniroute podešavanje # vođeni čarobnjak za prvo pokretanje
omniroute doktor # dijagnostički pružatelji usluga, portovi, izvorni odjeli

```

### 🛰️ Udaljeni način rada — pokrenite CLI ovdje, OmniRoute na VPS-u

OmniRoute na serveru? Pokrećete ga sa svog laptopa pomoću **istog CLI**. Prijavite se jednom.
sa tokenom za pristup sa ograničenim opsegom; svaka komanda zatim cilja daljinski upravljač.

bash
omniroute connect 192.168.0.15 # lozinka → token sa ograničenim opsegom, sačuvan kao kontekst
lista omniroute modela # ← se pokreće na UDALJENOM serveru
omniroute configure codex # ← bira udaljeni model, piše lokalni Codex profil
omniroute tokeni kreiraj --name ci --scope čitaj # kovat uže tokene za druge mašine
omniroute konteksti koriste zadani # ← prebaci se nazad na lokalni server
```

Tokeni su ograničeni na `čitanje` / `pisanje` / `admin`; rute koje pokreću procese ostaju samo povratne petlje.

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute kompresijski cjevovod: ilustrativni klijentski zahtjev od 10.000 tokena prolazi kroz 12 kompozibilnih mehanizama — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra i OmniGlyph — i može doći do dobavljača s oko 1.080 tokena u dokumentiranom složenom primjeru. Strukturirani sadržaj je zaštićen zaštitama očuvanja i pokoračnim vratima vjernosti; eksplicitni gubici ili eksperimentalni načini mogu transformirati odgovarajući sadržaj."/>

Zadana složena kombinacija pokreće `RTK → Caveman`. Kada oba djeluju na isti alat/kontekst, ušteda se povećava:

```txt
kombinovano = 1 − (1 − RTK) × (1 − Caveman_input)
prosjek = 1 − (1 − 0,80) × (1 − 0,46) = 89,2%
raspon = 78,4 – 94,6%
````

Blokovi koda, URL-ovi, JSON i strukturirani podaci su **uvijek zaštićeni** mehanizmom za očuvanje.

> **Zašto koristiti mnogo tokena kada je dovoljno malo tokena?** Svaki zahtjev prolazi kroz OmniRouteov kompresijski kanal **transparentno** — klijent se ne mijenja. Sada je to **stek od 12 kompozibilnih mehanizama** koji se izvršavaju po redu i miješaju i usklađuju po kombinaciji usmjeravanja — gradeći na idejama iz [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K+), [LLMLingua-2](https://github.com/microsoft/LLMLingua) i [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

### 🎚️ Izvan mehanizama — stilovi izlaza, prilagodljivo biranje i kontrola po zahtjevu

Gornjih 12 mehanizama smanjuju ono što **ulazi**. Tri dodatna sloja oblikuju **kako**, **kada** i ono što **izlazi**:

- **🪄 Izlazni stilovi** _(upravljanje izlaznom osom)_ — ubrizgavanje determinističkih, keš-bezbednih instrukcija za oblikovanje odgovora; kombinovatelno, svaka sa `lite` / `punim` / `ultra` intenzitetom. Dodavanje stila je unos u registar od jednog reda:
- **Kratka proza** — popunjavanje teksta / članci / zaštita od opasnosti; tehnička suština mora biti tačna.
- **Manje koda** — "lijeni senior programer" YAGNI: najmanja radna promjena, nema neželjenog scaffoldinga.
- **Rep (lijeni senior developer)** — penjanje uz YAGNI ljestvicu, rješavanje uzroka, najmanja ispravna razlika.
- **Imam ADHD (prvo akcija)** — sljedeća akcija vodi, koraci su numerisani, jedan konkretan sljedeći korak, bez uvoda.
- **Sažet CJK (文言)** — klasično-kineski ultra-sažet stil (lokalno ograničen na `zh`).
- **🎯 Adaptivni kontekstualni budžet** _(brojčanik)_ — umjesto jednog praga za uključivanje/isključivanje tokena, eskalirajte najjeftinije mehanizme s najmanje gubitaka samo onoliko koliko je potrebno da se **uklope u kontekstni prozor modela**. Politika: `rezervni izlaz` (zadano, svjesno modela) · `procenat` · `apsolutno`. Način rada: `pod` (garantovano uklapanje) · `automatska zamjena` (vaš eksplicitni izbor pobjeđuje) · `isključeno` (zaslijeđeni prag).
- **🎛️ Gdje se određuje kompresija** _(prioritet, visoka → niska)_ — zaglavlje `x-omniroute-compression` po zahtjevu › prepisivanje kombinacije usmjeravanja › aktivni imenovani profil › adaptivni / automatski okidač › zadana vrijednost panela › isključeno. Primijenjeni plan se odražava u zaglavlju odgovora `X-OmniRoute-Compression: <mode>; source=<source>`.

Automatsko pokretanje prema pragu tokena, uključivanje adaptivnog biranja, zakačenje imenovanog profila, postavljanje jednokratne akcije po zahtjevu ili dodjeljivanje cjevovoda po kombinaciji usmjeravanja - što god odgovara radnom opterećenju. Opt-in offline **eval harness** (`npm run eval:compression`) ocjenjuje vjernost u odnosu na uštede na zakačenom korpusu prije nego što promovirate promjenu.

## 📦 Više metoda instalacije — Docker, izvorni kod, pnpm, Arch

**🐳 Docker**

bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
-p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest

```

`:latest` prati najvišu **objavljenu** stabilnu SemVer. Ne prati git `main`. Zakačite `:X.Y.Z` za GitOps. Pogledajte [Docker Release Channels](docs/guides/DOCKER_GUIDE.md#release-channels). Slika je zakačena za **`OMNIROUTE_MEMORY_MB=1024`**. To je dovoljno za kontrolnu ploču i lagani razgovor. **Agenti za kodiranje** (`POST /v1/responses` iz Claude Code, Codex, Grok, …) trebaju mnogo veći V8 heap ili proces `FATAL ERROR`s na ~12GiB pod dva preklapajuća duga konteksta. Odredite veličinu kontejnera iznad heapa (nativni baferi se nalaze izvan V8):

| Radno opterećenje | Hip (`-e OMNIROUTE_MEMORY_MB`) | Kontejner (`--memory`) |
| ----------------------------------- | ---------------- | ---------------------- |
| Kontrolna ploča / lagani chat | `1024` (zadana slika) | ≥2g |
| Jedan kodirajući agens | `8192` | ≥10g |
| Dva istovremena duga `/v1/odgovora` | `10240`–`12288` | ≥12–16g |

bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
-e OMNIROUTE_MEMORY_MB=8192 --memorija=10g \
-p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest
```
