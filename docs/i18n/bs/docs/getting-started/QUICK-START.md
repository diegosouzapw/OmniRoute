# Brzi početak: Pokrenite OmniRoute za 3 minute

> **TL;DR**: Instalirajte → Povežite besplatnog provajdera → Usmjerite svoj IDE na OmniRoute. Gotovo.

---

## Korak 1: Instalirajte OmniRoute

Odaberite željeni metod:

### Opcija A: npm (Preporučeno)

```bash
npm install -g omniroute
```

### Opcija B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` je najviša **objavljena** stabilna SemVer verzija. Ona **ne** prati git `main`. Fiksirajte (pin) `diegosouzapw/omniroute:X.Y.Z` za GitOps. Pogledajte [Image Tags / Release Channels](../guides/DOCKER_GUIDE.md#release-channels).

### Opcija C: Iz izvornog koda

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Korak 2: Pokrenite OmniRoute

```bash
omniroute
```

OmniRoute se pokreće na `http://localhost:20128`. Kontrolna tabla se otvara automatski.

---

## Korak 3: Povežite besplatnog provajdera

Možete koristiti OmniRoute **bez ikakvog plaćanja** povezivanjem besplatnog provajdera.

### Opcija A: Kiro (Besplatni Claude — Bez kreditne kartice)

1. Otvorite kontrolnu tablu na `http://localhost:20128`
2. Idite na **Providers** → **Add Provider**
3. Odaberite **Kiro AI**
4. Kliknite na **Connect** (nije potreban API ključ!)
5. Gotovo! Sada imate besplatan pristup Claude modelima.

### Opcija B: OpenCode Free (Bez autorizacije)

1. Otvorite kontrolnu tablu na `http://localhost:20128`
2. Idite na **Providers** → **Add Provider**
3. Odaberite **OpenCode Free**
4. Kliknite na **Connect** (nije potreban API ključ!)
5. Gotovo! Sada imate besplatan pristup više modela.

### Opcija C: Pollinations (Nije potreban ključ)

1. Otvorite kontrolnu tablu na `http://localhost:20128`
2. Idite na **Providers** → **Add Provider**
3. Odaberite **Pollinations**
4. Kliknite na **Connect** (nije potreban API ključ!)
5. Gotovo! Sada imate besplatan pristup GPT-5, Claude, Gemini i drugim modelima.

---

## Korak 4: Provjerite da li radi

Sa [API Keys](http://localhost:20128/dashboard/api-manager), kreirajte novi ključ. Sačuvajte ovaj ključ jer se više neće prikazivati. Imajte na umu da je ovaj ključ namijenjen alatima za pristup OmniRoute-u, a ne za pristup izvornim (upstream) provajderima.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Trebali biste vidjeti listu povezanih modela.

---

## Korak 5: Usmjerite svoj IDE ili CLI na OmniRoute

U svom IDE-u ili CLI alatu, podesite:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

To je to! Vaš IDE sada koristi OmniRoute sa automatskim odabirom provajdera.

### Primjer za IDE: VSCode/Continue.dev

1. U VSCode-u, instalirajte [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ekstenziju.
2. Ažurirajte svoj `~/.continue/config.yaml` dodavanjem sljedećih linija:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. U Continue.dev prozoru za razgovor, odaberite `OmniRoute - Auto` i slaćete zahtjeve ka OmniRoute-u.
4. (Opciono) Vježba za čitaoca - neka vaš IDE ažurira `config.yaml` sa svim ostalim unaprijed napravljenim konfiguracijama 😊

### Primjer za CLI: Codex CLI

1. U svom operativnom sistemu, trajno podesite varijablu okruženja.
   Za macOS/Linux (dodajte u svoj `~/.bashrc` ili `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Za Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Sada pokrenimo Codex, ali konfigurisan za OmniRoute. Pokrenite:

```
omniroute launch-codex --model auto
```

Ovo možete uraditi ručno putem `codex` i parametara komandne linije kako biste naveli endpoint i api ključ, ali sa gornjom komandom, OmniRoute se brine o svemu za vas.

Isto pokretanje jednom komandom radi i za druge CLI alate putem generičkog pokretača — `omniroute run <target>` podržava `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` i `gemini` (pogledajte [CLI Integrations](../guides/CLI-INTEGRATIONS.md)).

3. CLI bi sada trebao slati zahtjeve ka OmniRoute-u.

### Potvrdite da vaš alat usmjerava ka OmniRoute-u

Detalje zahtjeva možete vidjeti klikom na [Monitoring/Logs](http://localhost:20128/dashboard/logs) u lijevoj bočnoj traci. Klikom na njih prikazuju se dodatni detalji. Uzgred, možete vidjeti koje informacije se šalju iz vašeg omiljenog alata. Ovo je korisno iz edukativne i perspektive otklanjanja grešaka (debugging).

## Česta pitanja

### "Da li mi treba API ključ?"

**Ne!** Možete koristiti besplatne provajdere (Kiro, OpenCode Free, Pollinations) bez ikakvog API ključa. Samo ih povežite na kontrolnoj tabli.

### "Šta je `auto`?"

`auto` govori OmniRoute-u da automatski odabere najboljeg provajdera za svaki zahtjev. Uzima u obzir brzinu, cijenu, kvalitet i dostupnost. Pogledajte [Vodič za Auto-Combo](./AUTO-COMBO-GUIDE.md) za detalje.

### "Koliko to košta?"

Sam OmniRoute je **besplatan i otvorenog koda**. Plaćate samo provajdere koje koristite. Mnogi provajderi imaju besplatne pakete — pogledajte [Vodič za besplatne pakete](./FREE-TIERS-GUIDE.md).

### "Mogu li ga koristiti sa Claude Code / Cursor / Copilot?"

**Da!** OmniRoute radi sa bilo kojim alatom koji podržava OpenAI format. Samo postavite osnovni URL na `http://localhost:20128/v1`. Pogledajte [Vodič za CLI alate](../reference/CLI-TOOLS.md) za specifična uputstva za podešavanje.

### "Šta ako provajder prestane sa radom?"

OmniRoute automatski preskače neuspjele provajdere i pokušava sa sljedećim. Ne morate ništa raditi. Pogledajte [Vodič za Auto-Combo](./AUTO-COMBO-GUIDE.md) za detalje.
