Alokacija nije kvota provajdera.

Bazeni kvota definišu koji API ključevi mogu koristiti bazen provajdera i kako se primjenjuju hard, soft ili burst politike. Kvota provajdera je eksterni kapacitet o kojem izvještava provajder ili eksplicitno konfigurisan izvor. Interni budžeti Ghostlight-a su upravljačka ograničenja koja definiše administrator.

Operacija `ensurePool` je idempotentna: identičan bazen ostaje nepromijenjen, izmijenjena alokacija se ažurira, a nedostajući bazen se kreira. Ovo je namijenjeno za automatizaciju i ograničene API pozivaoce.

Endpoint statusa samo za čitanje je `GET /api/omniroute/status`. Komanda za verifikaciju je `npm run omniroute:verify`; ona ne šalje zahtjeve modelu uživo.
