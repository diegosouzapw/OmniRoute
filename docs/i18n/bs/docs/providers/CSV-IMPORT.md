# Uvoz provajdera iz CSV ili JSON datoteke

Dashboard → Providers → **Import from file** kreira konekcije sa API ključevima iz CSV ili JSON liste. Svaki red može ciljati drugog provajdera. Djelimični neuspjeh je dio ugovora: validni redovi se i dalje uvoze kada drugi ne uspiju, a modal prikazuje zašto su neuspješni redovi odbijeni.

Ovaj uvoz **ne** kreira nove OpenAI/Anthropic-kompatibilne krajnje čvorove (endpoint nodes). Prvo kreirajte njih (Dashboard → Providers → Add OpenAI-Compatible, ili `omniroute nodes add`), a zatim uvezite redove čija je `provider` kolona ID tog čvora. `baseUrl` po redu i dalje može nadjačati URL čvora.

## CSV (pozicioni)

Nazivi kolona su kozmetičke prirode. Parser dijeli svaki red i destrukturira ga prema indeksu:

| Indeks | Polje      | Obavezno | Napomene                                                                                                                              |
| ------ | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 0      | `provider` | da       | ID postojećeg upravljanog provajdera (`openai`, `anthropic`, …) **ili** ID već registrovanog OpenAI/Anthropic-kompatibilnog **čvora** |
| 1      | `name`     | da       | Prikazno ime konekcije                                                                                                                |
| 2      | `apiKey`   | da       | API ključ                                                                                                                             |
| 3      | `baseUrl`  | ne       | Nadjačavanje URL-a po redu                                                                                                            |
| 4      | `priority` | ne       | Cijeli broj 1–100                                                                                                                     |

Prva linija čija je prva kolona doslovna riječ `provider` (bilo koje veličine slova) se preskače kao zaglavlje. Prazne linije i `#` komentari se preskaču.

Preuzmite početnu datoteku iz modala za uvoz (**Download CSV template**). Primjer:

```csv
# OmniRoute uvoz provajdera (pozicione kolone)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Izmišljeni ID kao što je `openai-compatible-chat-001` nije čvor. API vraća `Unknown or unsupported provider` za taj red; modal to prikazuje pored imena reda.

## JSON

JSON niz objekata sa istim poljima (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Za razliku od CSV-a, JSON ključevi su imenovani.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
