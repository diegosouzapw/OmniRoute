# Jezički paketi za kompresiju

Caveman kompresija može učitati jezički specifične pakete pravila pored ugrađenih engleskih pravila. Ovo održava osnovni mehanizam stabilnim, istovremeno omogućavajući portugalskom, španskom, njemačkom, francuskom, italijanskom, japanskom i budućim jezičkim paketima da se nezavisno razvijaju.

## Lokacija

Jezički paketi se nalaze u:

```txt
open-sse/services/compression/rules/<language>/
```

Trenutno isporučeni paketi (verifikovani prema sadržaju `rules/` direktorija):

| Jezik                | Direktorij     | Prisutne kategorije pravila                         |
| -------------------- | -------------- | --------------------------------------------------- |
| Engleski             | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Španski              | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugalski (Brazil) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonežanski         | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italijanski          | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Njemački             | `rules/de/`    | `context`, `filler`, `structural`                   |
| Francuski            | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japanski             | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Napomena o paritetu:** Paketi `en`, `es`, `pt-BR`, `id` i `it` imaju svih 5 kategorija; `de`, `fr`, `ja` isporučuju 3 kategorije. Nedostajuće `dedup` i `ultra` kategorije se neprimjetno vraćaju na engleske ugrađene vrijednosti. Doprinosi za dodavanje `dedup.json` i `ultra.json` za manje pakete su dobrodošli.
>
> Paket `pt-BR` je zasnovan na **[Troglodita](https://github.com/leninejunior/troglodita)** autora Lenine Júnior — sistemu za kompresiju dizajniranom od nule za gramatiku brazilskog portugalskog (redukcija pleonazama, uklanjanje PT-BR poštapalica, tehničke skraćenice za BR programersku zajednicu).
>
> Kanonska lista kategorija i shema po kategorijama se nalaze u [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12).

## Detekcija jezika

`languageDetector.ts` koristi lagane heuristike za zaključivanje jezika iz teksta upita. Konfigurisani podrazumijevani jezik se i dalje poštuje, a detekcija se može onemogućiti putem konfiguracije kada je potrebna precizna kontrola.

Izlaz detekcije se koristi samo za odabir paketa pravila. To ne mijenja rutiranje provajdera, odabir lokacije ili jezik korisničkog interfejsa.

## Oblik konfiguracije

Postavke kompresije mogu uključivati:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` kontroliše podrazumijevane vrijednosti kontrolne table/pregleda. `cavemanConfig` je konfiguracija mehanizma za vrijeme izvršavanja koja se koristi kada Caveman komprimuje tekst poruke.

## Dodavanje jezičkog paketa

1. Kreirajte `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Koristite Caveman format pravila iz `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Neka zamjene budu konzervativne i izbjegavajte mijenjanje koda, identifikatora, URL-ova ili JSON-a.
4. Dodajte ili ažurirajte testove za odabir jezika i ponašanje zamjene.
5. Izložite nove kontrolne ploče/i18n oznake ako se jezik pojavljuje u UI selektorima.

## API

Dostupni paketi se mogu upitati sa:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Preview krajnja tačka (endpoint) prihvata nadjačavanja konfiguracije jezika:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Svih 6 jezičkih paketa je dobilo `SHARED_BOUNDARIES` klauzulu u v3.8.0 koja se primjenjuje pri svakom Caveman intenzitetu (LITE, FULL, ULTRA). Ona instruiše mehanizam da sačuva ove obrasce doslovno, bez obzira na uklanjanje okolne ispune:

| Tip obrasca                              | Primjer                                |
| ---------------------------------------- | -------------------------------------- |
| Ograđeni blokovi koda                    | ` ```python\n...\n``` `                |
| Umetnuti kod                             | `` `my_var` ``                         |
| URL-ovi                                  | `https://example.com/path`             |
| Putanja datoteka (apsolutna + relativna) | `/etc/hosts`, `./src/index.ts`         |
| Zaglavlja grešaka                        | `Error:`, `TypeError:`, `SyntaxError:` |
| Linije traga steka (stack trace)         | `  at functionName (file.ts:12:3)`     |

Ovi obrasci su popunjeni u `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (prethodno `[]`). Konstanta se nalazi u `open-sse/services/compression/types.ts`.

### Zašto je ovo važno

Bez SHARED_BOUNDARIES, agresivni Caveman režimi bi mogli ukloniti sadržaj koji je izgledao kao ponavljajuća proza, ali je zapravo bio isječak koda, putanja datoteke ili stek grešaka. SHARED_BOUNDARIES djeluje kao sigurnosna mreža nezavisna od jezika koja se primjenjuje prije pokretanja pravila za uklanjanje ispune.

### Prilagođavanje preservePatterns

Dodatni obrasci se mogu dodati tokom izvršavanja putem postavki kompresije:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Prilagođeni obrasci proširuju (ne zamjenjuju) 6 zadanih.

## Operativne napomene

- Ugrađena pravila za engleski jezik ostaju rezervna opcija kada nedostaje jezički paket.
- Nevažeći ugrađeni JSON paketi ne prolaze validaciju tako da se izdanja (release assets) ne degradiraju neprimjetno.
- Paketi pravila su samo podaci i ne bi trebali uvoziti kod ili pokretati proizvoljnu logiku.
- Sloj analitike kompresije bilježi odabrani režim i mehanizam, a ne puni tekst upita.
