# agentrouter.org WAF (Web Application Firewall)

`agentrouter` upstream gateway pokreće filter sadržaja zasnovan na ključnim riječima nad `messages[].content`. Filter je djelimično deterministički (uvijek blokira određene fraze) i djelimično probabilistički (osjetljiv na nalete — postaje agresivniji nakon brzih zahtjeva, oporavlja se nakon perioda hlađenja).

Kada WAF blokira zahtjev, vraća:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Opseg filtera

WAF provjerava samo `messages[].content`. On **ne** provjerava:

- `system` prompt
- Strukturirane blokove sadržaja (`tool_result`, `tool_use`, `thinking`, `image`)
- Polja `description` i `input_schema` alata
- Metadatke zahtjeva, zaglavlja ili ID modela

## Uvijek blokirani obrasci (ne razlikuje velika i mala slova)

| Obrazac                           | Napomene                                              |
| --------------------------------- | ----------------------------------------------------- |
| Bilo koja varijanta `Lorem ipsum` | Cjelokupan latinski lorem vokabular je blokiran       |
| `language model` (samostalno)     | "the language model" i "large language model" prolaze |
| `virtual assistant`               | "AI assistant" prolazi                                |
| `I'm here to help`                | "here to help" samostalno također blokira             |
| `Claude, made by Anthropic`       | Samo puna fraza                                       |

## Gotovo uvijek blokirani obrasci

| Obrazac                                                    | Napomene                                                   |
| ---------------------------------------------------------- | ---------------------------------------------------------- |
| `placeholder`                                              | Kada stoji samostalno (ne kao naziv parametra, itd.)       |
| `dummy data`                                               | Uobičajena početna fraza za fixture                        |
| `foo bar baz`                                              | Kanonizirana fraza čuvara mjesta (placeholder)             |
| Ponavljani kratki tokeni (`AAA BBB CCC`, `test test test`) | Detektor za "keyword stuffing" (gomilanje ključnih riječi) |

## Ponašanje pod opterećenjem

Nakon ~5 brzih zahtjeva u kratkom vremenskom prozoru, WAF počinje blokirati sadržaj koji bi inače prošao. "Kanta" (bucket) se opušta nakon ~5–10 sekundi neaktivnosti. Ovo je isti ograničavač brzine (rate limiter) vezan za IP i ključ koji uzrokuje povremene `400 content-blocked` greške kada Claude Code ili Codex CLI upućuju više poziva za korištenje alata / slanje poruka u brzom nizu.

## Ublažavanja (mitigations) već primijenjena u OmniRoute

1. `open-sse/services/wafRateLimit.ts` — zaštita od naleta (burst guard) koja nameće minimalni razmak od 500 ms između odlaznih zahtjeva prema bilo kojem `agentrouter:*` URL-u. Razmak je znatno ispod ljudske percepcije latencije i sprječava aktivaciju WAF-a pri normalnom prometu.

2. `BaseExecutor.WAF_RETRY_CONFIG` — kada upstream vrati `400 content-blocked`, izvršilac (executor) ponovo pokušava isti URL uz eksponencijalno čekanje (1.5 s, 3.0 s, maksimalno 2 pokušaja). Nakon čekanja, WAF se obično opusti i ponovni pokušaj uspijeva.

3. `tests/unit/compression/harness.test.ts` — test fixture `longInput` je promijenjen iz `"lorem ipsum dolor sit amet ".repeat(40)` u `"example content for testing purposes ".repeat(40)` tako da kada Claude Code čita ovu datoteku putem `Read` alata, sadržaj datoteke ne prolazi nazad kroz `tool_result` blok i ne aktivira WAF.

## Smjernice za upite i izlaz alata

Ako Claude Code ili Codex CLI sesija opetovano nailazi na `400 content-blocked`, provjerite najnoviju korisničku poruku i najnoviji rezultat alata za bilo koji od gore navedenih obrazaca i preformulišite ih. Uobičajena zaobilazna rješenja:

- Zamijenite `Lorem ipsum …` sa `example text …` ili stvarnim sadržajem koji test ili fixture pokušava modelirati.
- Zamijenite `placeholder` (kada stoji samostalno) sa `example value`, `sample value` ili stvarnom vrijednošću.
- Zamijenite `language model` sa `large language model` ili `the model`.
- Zamijenite `dummy data` sa `sample data` ili realističnim početnim vrijednostima.
- Zamijenite `I'm here to help` / `here to help` sa specifičnijim uvodom (npr. "I'll review the file you mentioned").

## Prijavljivanje lažno pozitivnih rezultata upstream-u

Trenutni filter je pretjerano agresivan — blokira "Lorem ipsum" u `tool_result` blokovima iako operater očigledno nije namjeravao ubaciti upit. Operateri koji žele da se ovo popravi na izvoru trebaju kontaktirati `agentrouter.org` kako bi prijavili lažno pozitivne rezultate. Gore navedena lista blokiranih stavki je empirijski rezultat testiranja upstream-a na dan 2026-08-03.
