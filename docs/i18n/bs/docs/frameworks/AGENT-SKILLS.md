# Katalog vještina OmniRoute agenata

> **Izvor istine:** `src/lib/agentSkills/` (katalog, generator, parseri) + `skills/` direktorij (SKILL.md datoteke)
> **Posljednje ažurirano:** 2026-08-02 — v3.8.50

Vještine agenata (Agent Skills) su strukturirane SKILL.md datoteke koje podučavaju vanjske agente, MCP klijente i A2A orkestratore kako koristiti OmniRoute REST API i CLI. Za razliku od [Omni vještina](./SKILLS.md) (koje su definicije LLM alata izvršene unutar OmniRoute-a), Vještine agenata su _katalog dokumentacije_ — statični markdown koji se može direktno unijeti u kontekst agenta.

---

## Pregled

Katalog sadrži **45 vještina agenata** (23 REST API + 21 CLI + 1 konfiguracijski radni tok). Svaka vještina ima:

- **Konični ID** (`omni-auth`, `cli-serve`, itd.)
- Datoteku **SKILL.md** u `skills/{id}/SKILL.md` sa YAML zaglavljem (`name`, `description`) + bogatim markdown tijelom
- **REST krajnje tačke** (API vještine) ili **CLI podkomande** (CLI vještine) izvedene iz OpenAPI specifikacije i CLI registra
- **GitHub raw URL** za preuzimanje uživo: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

---

## Arhitektura

```
src/shared/constants/agentSkills.ts    — kurirana lista od 45 unosa (ime/opis/kategorija/područje/ikona)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() zapisuje SKILL.md u skills/{id}/
  openapiParser.ts                     — ekstrahuje REST krajnje tačke iz docs/openapi.yaml
  cliRegistryParser.ts                 — ekstrahuje CLI podkomande iz bin/cli-registry.ts
  schemas.ts                           — Zod sheme: AgentSkillSchema, SkillCoverageSchema, itd.
  types.ts                             — TypeScript interfejsi: AgentSkill, SkillCoverage, itd.

skills/{id}/SKILL.md                   — Generisane + kurirane markdown datoteke (ukupno 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (potrebna autentifikacija)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 MCP alata (list, get, coverage)
src/lib/a2a/skills/listCapabilities.ts        — A2A vještina: list-capabilities
```

## Format SKILL.md

```markdown
---
name: omni-providers
description: "Upravljanje konekcijama provajdera: dodavanje, testiranje, rotacija i uklanjanje akreditiva."
---

<!-- generisano pomoću src/lib/agentSkills/generator.ts; ručne izmjene će biti prepisane -->

## Pregled

...

## Autentifikacija

...

## Krajnje tačke

...

<!-- skill:custom-start -->

## Prilagođena sekcija (sačuvana tokom regeneracije)

...

<!-- skill:custom-end -->
```

Generator čuva sadržaj između `<!-- skill:custom-start -->` i `<!-- skill:custom-end -->` prilikom regeneracije. Deset vještina ima kurirane prilagođene blokove:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Otkrivanje REST API-ja

| Endpoint                     | Metoda | Opis                                                                 | Autorizacija |
| :--------------------------- | :----- | :------------------------------------------------------------------- | :----------- |
| `/api/agent-skills`          | GET    | Lista kataloga (opcionalno `?category=api\|cli\|config&area=<area>`) | nema         |
| `/api/agent-skills/{id}`     | GET    | Dohvati metapodatke pojedinačne vještine                             | nema         |
| `/api/agent-skills/{id}/raw` | GET    | Dohvati SKILL.md kao `text/markdown`                                 | nema         |
| `/api/agent-skills/coverage` | GET    | Statistika pokrivenosti (koliko SKILL.md datoteka postoji)           | nema         |
| `/api/agent-skills/generate` | POST   | Pokreni generator (dryRun/prune/onlyIds)                             | upravljanje  |

Primjer — izlistaj sve API vještine:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Primjer — dohvati pojedinačni SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## A2A Otkrivanje

A2A vještina `list-capabilities` vraća kompletan katalog od 45 vještina kao markdown tabelarni artefakt. Vanjski orkestratori je mogu pozvati putem:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

Pogledajte [A2A-SERVER.md](./A2A-SERVER.md) za detalje protokola.

## Kako vanjski agenti koriste vještine

### 1. Otkrivanje putem REST-a

```bash
# Dobavi puni katalog
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Dobavi SKILL.md za ubacivanje konteksta
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Otkrivanje putem MCP-a

```typescript
// U Claude Desktop / Cursor MCP klijentu:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → niz AgentSkill objekata sa rawUrl za svaki
```

### 3. Otkrivanje putem A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# tabela je markdown tabela sa svih 45 ID-ova vještina + rawUrl kolonama
```

### 4. Direktno preuzimanje sa GitHub-a (nije potreban server)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generator

Generator čita uređeni katalog + OpenAPI specifikaciju + CLI registar i zapisuje `skills/{id}/SKILL.md` za svaki unos:

```bash
# Pregled (probno pokretanje, bez zapisivanja)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Puna regeneracija
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Regeneriši specifične ID-ove
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Odgovor generatora je `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
