# Izvor konteksta lokalnog korpusa

> **Izvor istine:** `src/lib/localCorpus/index.ts` (indeks ograničenog teksta),
> `src/lib/localCorpus/configured.ts` (konfigurisano vrijeme izvršavanja),
> `src/lib/db/localCorpus.ts` (perzistencija korijenske putanje),
> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 MCP alata samo za čitanje), i
> `src/app/api/settings/local-corpus/route.ts` (API za postavke).

## Šta je to

Lokalni korpus (Local Corpus) omogućava operateru da izloži jedan eksplicitno odobreni direktorij tekstualnih datoteka OmniRoute MCP serveru. Datoteke ostaju u svom originalnom direktoriju: OmniRoute pohranjuje samo kanonsku korijensku putanju u SQLite i održava indeks pretraživanja u memoriji. Ne kopira sadržaj korpusa u repozitorij ili bazu podataka.

Osvježavanje indeksa je inkrementalno. Nepromijenjene datoteke se ponovo koriste na osnovu veličine i vremena izmjene, promijenjene datoteke se ponovo čitaju i heširaju pomoću SHA-256, a izbrisane datoteke se uklanjaju. Pretraga osvježava indeks stariji od 30 sekundi; pozivaoci također mogu zatražiti trenutno osvježavanje.

## Konfigurisanje izvora

Ruta za postavke zahtijeva istu autentifikaciju upravljanja kao i drugi API-ji za postavke. Dostavljena putanja mora već postojati i mora biti apsolutna putanja direktorija.

```bash
# Povezivanje odobrenog direktorija
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Provjera konfiguracije i statusa indeksa
curl http://localhost:20128/api/settings/local-corpus

# Prekid veze bez promjene izvornih datoteka
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP alati

Sva tri alata zahtijevaju `read:local-corpus`. Odgovori alata izlažu relativne putanje i osnovno ime (basename) korijenskog direktorija, nikada njegovu apsolutnu putanju.

| Alat                  | Opis                                                                                                  |
| :-------------------- | :---------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Izvještaj o stanju konfiguracije, veličini indeksa, ograničenjima i vremenu posljednjeg osvježavanja  |
| `local_corpus_search` | Pretraživanje indeksiranog teksta i vraćanje ograničenih isječaka sa opsegom linija (do 20 rezultata) |
| `local_corpus_read`   | Čitanje ograničenog raspona linija iz jedne dozvoljene datoteke relativne u odnosu na korpus          |

Primjeri MCP unosa:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Sigurnosne granice

- Lista dozvoljenih datoteka je orijentisana na tekst: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, i `.yml`.
- Simboličke veze (symlinks) se preskaču. Putanje za čitanje se kanonizuju i moraju ostati unutar konfigurisanog korijena; apsolutne putanje i pokušaji prolaska kroz direktorije (traversal) se odbijaju.
- Osjetljiva i generisana imena direktorija su isključena: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, i `secrets`.
- Zadana ograničenja su 5.000 datoteka, 1 MiB po datoteci, 64 MiB ukupnog indeksiranog sadržaja, približno 4.000 znakova po isječku pretrage i 400 linija po čitanju.
- Datoteke koje sadrže NUL znakove tretiraju se kao netekstualne i preskaču se ili odbijaju.

Binarni dokumenti kao što su PDF, DOCX, slike i arhive namjerno nisu podržani.
Pretvorite ih u odobreni tekstualni format u konfigurisanom direktoriju prije indeksiranja.

## Operativne napomene

- Promjena ili brisanje konfigurisanog korijena briše dijeljeni indeks u memoriji.
- Ponovno pokretanje procesa odbacuje indeks; sljedeća pretraga ga ponovo gradi iz konfigurisanog izvora.
- `local_corpus_status` ne forsira skeniranje. Koristite `local_corpus_search` sa `refresh: true` kada je potrebno trenutno ponovno skeniranje.
- Neuspjesi skeniranja i čitanja se broje ili vraćaju kao sanitizovane greške; izvorne datoteke se nikada ne mijenjaju.
