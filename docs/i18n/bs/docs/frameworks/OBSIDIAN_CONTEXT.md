# Obsidian Context Source

> **Izvor istine:** `src/lib/obsidian/api.ts` (REST + sync klijent),
> `src/lib/db/obsidian.ts` (token / base-URL / WebDAV perzistencija),
> `src/lib/obsidianSync.ts` (WebDAV sinhronizacija trezora), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP alata), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API-ji za postavke). Registracija alata
> i povezivanje opsega se nalazi u `open-sse/mcp-server/server.ts`.

## Šta je to

OmniRoute se povezuje na **Obsidian** trezor kao **izvor konteksta** — lokalnu Markdown
bazu znanja koju agenti čitaju i pišu putem ugrađenog MCP servera.
Integracija komunicira sa **Obsidian Local REST API** zajedničkim dodatkom koji radi unutar
desktop aplikacije, tako da agenti mogu pretraživati bilješke, čitati/pisati/ažurirati datoteke, izlistati trezor, raditi sa dnevnim/sedmičnim periodičnim bilješkama, upravljati oznakama, pokretati Obsidian komande i (opciono) koordinirati dvosmjernu desktop↔mobilnu sinhronizaciju trezora.

Klijent (`src/lib/obsidian/api.ts`) obavija Local REST API sa:

- **Ponovnim pokušajem sa odgodom (backoff)** za prolazne `5xx` greške, **30-sekundni timeout** putem `AbortController`.
- **Tipiziranom klasifikacijom grešaka** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Prijateljskim savjetom "ne mogu pristupiti Obsidianu"** koji ukazuje na čestu grešku sa portom
  (HTTP na `27123`, **ne** MCP krajnja tačka na `27124`) i Tailscale formu.
- Relativnim **kodiranjem putanje** trezora tako da su putanje bilješki sa razmacima/kosim crtama sigurne.

## Postavljanje

Ne postoji **environment variable** za Obsidian token ili bazni URL — oba su
pohranjena u SQLite `key_value` tabeli (namespace `obsidian`) putem
`src/lib/db/obsidian.ts`. Token je **šifriran u mirovanju** (AES-256-GCM, sa
povratnom kompatibilnošću za običan tekst). Konfigurišite iz kartice **Context Sources**
na kontrolnoj tabli krajnje tačke (`ObsidianSourceCard`), ili putem REST API-ja za postavke.

> [!IMPORTANT]
> Dodatak **Obsidian Local REST API** mora biti instaliran i pokrenut. Njegov REST
> interfejs sluša na **HTTP `127.0.0.1:27123`** (podrazumijevani bazni URL). Port `27124`
> je _zasebna_ MCP/HTTPS krajnja tačka i eksplicitno je odbijen od strane rute za postavke.
> Ako se povezujete sa drugog uređaja, koristite `http://<tailscale-ip>:27123`.

### Konfiguracijski ključevi (SQLite `key_value`, namespace `obsidian`)

| Ključ             | Namjena                                                      | Šifrirano |
| ----------------- | ------------------------------------------------------------ | --------- |
| `api_key`         | Lokalni REST API bearer token                                | da        |
| `base_url`        | REST bazni URL (podrazumijevano `http://127.0.0.1:27123`)    | ne        |
| `vault_path`      | Apsolutna putanja do direktorija trezora (za sinhronizaciju) | ne        |
| `webdav_username` | Generisano WebDAV korisničko ime (sinhronizacija trezora)    | ne        |
| `webdav_password` | Generisana WebDAV lozinka (sinhronizacija trezora)           | da        |
| `webdav_enabled`  | Da li je omogućena WebDAV sinhronizacija trezora             | ne        |

### Konfiguracija putem REST-a

```bash
# Sačuvaj + validiraj Local REST API token (POST validira putem provjere statusa)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Provjeri status veze (vraća connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Prekini vezu (briše pohranjeni token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Sve metode zahtijevaju autentifikaciju na kontrolnoj tabli. `POST` odbija bilo koji URL na portu `27124`
i validira token pozivanjem krajnje tačke statusa Local REST API-ja prije pohranjivanja.

### WebDAV sinhronizacija trezora

`src/app/api/settings/obsidian/webdav/route.ts` upravlja opcionom sinhronizacijom trezora zasnovanom na WebDAV-u (pokreće je `src/lib/obsidianSync.ts`). Omogućavanje usmjerava OmniRoute na lokalni direktorij trezora i generiše nasumični par WebDAV korisničkog imena/lozinke:

```bash
# Omogući WebDAV sinhronizaciju za direktorij trezora (generiše korisničko ime/lozinku)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Dobavi status WebDAV sinhronizacije (akreditivi se vraćaju samo dok je omogućeno)
curl http://localhost:20128/api/settings/obsidian/webdav

# Onemogući WebDAV sinhronizaciju (briše akreditive + upravljani .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Izvor konteksta po API ključu (opciono)

Obsidian konfiguracija se može ograničiti **po API ključu** putem `api_key_context_sources` tabele
(`src/lib/db/apiKeyContextSources.ts`). Kada MCP poziv nosi autentifikovani ID API ključa,
`getObsidianConfigForApiKey()` preferira token/bazni-URL/putanju-trezora tog ključa
(`source: "api_key"`) i u suprotnom se vraća na globalnu konfiguraciju (`source: "global"`).

## MCP alati (22)

Definisano u `open-sse/mcp-server/tools/obsidianTools.ts`. Token/base-URL se razrješavaju po pozivu (prvo po API ključu, zatim globalno). Alati koji pristupaju OmniRoute **serveru za sinhronizaciju** (četiri `obsidian_sync_*` alata) dodatno zahtijevaju autentifikacijski token za sinhronizaciju konfigurisan u OmniRoute postavkama.

### Alati za čitanje (`read:obsidian`)

| Alat                         | Opis                                                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Provjerite da li je lokalni REST API dostupan i autentifikovan.                                                 |
| `obsidian_search_simple`     | Pretraga punog teksta sadržaja bilješki; vraća isječke sa putanjama datoteka.                                   |
| `obsidian_search_structured` | Pretraga koristeći JSON Logic izraz (and/or/regex/filteri putanja).                                             |
| `obsidian_read_note`         | Čitanje bilješke putem putanje relativne u odnosu na trezor; opciono određeni naslov/blok/frontmatter.          |
| `obsidian_list_vault`        | Listanje datoteka i direktorija u trezoru (stablo unosa).                                                       |
| `obsidian_get_document_map`  | Dobijanje strukture naslova bilješke kao mape naslova → brojeva linija.                                         |
| `obsidian_get_note_metadata` | Dobijanje frontmatter-a, oznaka (tags), linkova, broja znakova/riječi bez punog sadržaja.                       |
| `obsidian_get_active_file`   | Dobijanje putanje + sadržaja trenutno aktivne datoteke u Obsidianu.                                             |
| `obsidian_get_periodic_note` | Dobijanje dnevne/sedmične/mjesečne periodične bilješke za datum (danas ako je izostavljeno).                    |
| `obsidian_get_tags`          | Listanje svih oznaka (tags) trezora sa njihovim učestalostima.                                                  |
| `obsidian_list_commands`     | Listanje dostupnih ID-ova Obsidian komandi (koristiti sa `obsidian_execute_command`).                           |
| `obsidian_sync_status`       | Status OmniRoute servera za sinhronizaciju: pokrenut, naziv trezora, port, vrijeme rada, zadnja sinhronizacija. |
| `obsidian_sync_conflicts`    | Listanje neriješenih konflikata sinhronizacije (putanja, putanja konflikta, vrijeme detekcije).                 |

### Alati za pisanje (`write:obsidian`)

| Alat                             | Opis                                                                                                |
| -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Kreiranje ili prepisivanje bilješke sa datim Markdown sadržajem.                                    |
| `obsidian_append_note`           | Dodavanje sadržaja bilješci; opciono na određeni naslov/blok.                                       |
| `obsidian_patch_note`            | Hirurško dodavanje/prethodno dodavanje/zamjena na naslovu, bloku ili frontmatter polju.             |
| `obsidian_delete_note`           | Trajno brisanje bilješke iz trezora.                                                                |
| `obsidian_move_note`             | Premještanje ili preimenovanje bilješke unutar trezora.                                             |
| `obsidian_execute_command`       | Izvršavanje Obsidian komande putem njenog ID-a.                                                     |
| `obsidian_open_file`             | Otvaranje datoteke u Obsidianu (kreira je ako ne postoji).                                          |
| `obsidian_sync_trigger`          | Pokretanje trenutne dvosmjerne sinhronizacije trezora desktop↔mobilni uređaj.                       |
| `obsidian_sync_resolve_conflict` | Rješavanje konflikta sinhronizacije: zadrži `local` (mobilni), `remote` (desktop), ili `keep-both`. |

> [!NOTE]
> Mete `obsidian_patch_note` prihvataju `targetType` vrijednosti `heading | block | frontmatter`
> i `operation` vrijednosti `append | prepend | replace`, uz opcioni
> `createTargetIfMissing`. Četiri `obsidian_sync_*` alata komuniciraju sa lokalnim serverom za sinhronizaciju
> (`http://127.0.0.1:27781` po defaultu) i zahtijevaju token za sinhronizaciju.

### Opsezi (Scopes)

Alati za čitanje zahtijevaju `read:obsidian`; alati za pisanje zahtijevaju `write:obsidian`. Sprovođenje je identično kao kod Notion-a — obrađuje ga `withScopeEnforcement()` u `open-sse/mcp-server/server.ts`, kontrolisano sa `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, sa dozvoljenim opsezima preuzetim iz `OMNIROUTE_MCP_SCOPES` ili konteksta opsega API ključa. Pogledajte [MCP-SERVER.md](./MCP-SERVER.md).

## Krajnje tačke

| Metoda   | Putanja                         | Svrha                                                           |
| -------- | ------------------------------- | --------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Vraća `{ connected, hasToken, baseUrl, vaultPath }`.            |
| `POST`   | `/api/settings/obsidian`        | Spremi + validiraj token (odbija port `27124`).                 |
| `DELETE` | `/api/settings/obsidian`        | Prekini vezu (briše pohranjeni token).                          |
| `GET`    | `/api/settings/obsidian/webdav` | Status WebDAV sinhronizacije + vjerodajnice (dok je omogućeno). |
| `POST`   | `/api/settings/obsidian/webdav` | Omogući WebDAV sinhronizaciju za direktorij trezora.            |
| `DELETE` | `/api/settings/obsidian/webdav` | Onemogući WebDAV sinhronizaciju.                                |

> Ovo su rute za postavke kontrolne ploče. Samom trezoru se pristupa putem Obsidian Local REST API-ja (konfigurisani `base_url`) i putem MCP alata iznad — ne postoji javna `/v1` Obsidian proxy krajnja tačka.

## Slučajevi upotrebe

- **Odgovori utemeljeni na trezoru** — `obsidian_search_simple` / `obsidian_search_structured`
  zatim `obsidian_read_note` kako bi agent odgovarao na osnovu vaših stvarnih bilješki.
- **Pisanje bilješki / vođenje dnevnika** — `obsidian_write_note`, `obsidian_append_note`, ili
  hirurški precizan `obsidian_patch_note` za bilježenje izlaza agenta, sažetaka ili dnevnih bilješki
  (`obsidian_get_periodic_note`) u trezor.
- **Navigacija kroz trezor** — `obsidian_list_vault`, `obsidian_get_document_map`, i
  `obsidian_get_tags` za istraživanje strukture prije čitanja/pisanja.
- **Obsidian automatizacija** — `obsidian_list_commands` + `obsidian_execute_command` za
  upravljanje dodacima/komandama od strane agenta; `obsidian_open_file` za prikaz bilješke u korisničkom interfejsu.
- **Mobilna sinhronizacija** — omogućite WebDAV sinhronizaciju, zatim `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  za koordinaciju desktop↔mobilni uređaj i rješavanje konflikata.
