# Playground Studio

> **Funkcionalnost:** Playground Studio — jedinstveno radno okruženje za testiranje AI-a za `/dashboard/playground`.
> **Planovi:** `17-playground-studio-redesign.plan.md` + `_orchestration/master-plan-group-C.md`
> **Status:** Objavljeno u v3.8.6

---

## Pregled

Playground Studio transformiše `/dashboard/playground` iz jednostavnog uređivača zasnovanog na Monaco-u u potpuno opremljeno radno okruženje za testiranje. On zamjenjuje naslijeđeni `page.tsx` sa `PlaygroundStudio` ljuskom koja renderuje četiri kartice i zajedničko okno za konfiguraciju.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Chat] [⚖ Compare] [{} API] [🔧 Build]     142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {active tab content}                    │ ─ Config                  │
│                                          │ Endpoint  [chat ∨]        │
│                                          │ Model     [gpt-5.4 ∨]     │
│                                          │ System    [textarea]      │
│                                          │ Temp      ▕▕▔▔ 0.7        │
│                                          │ Presets [▾ load][save]    │
│                                          │ [✨ Improve prompt]        │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Kartice

### Kartica Chat

Razvija `ChatPlayground.tsx` u radnu stanicu za streaming sa više razmjena (multi-turn):

- Potpuno renderovanje markdown-a putem `MarkdownMessage.tsx` (blokovi koda, tabele, liste, linkovi).
- Sistemski prompt preuzet iz zajedničkog okna za konfiguraciju.
- Token/trošak po poruci (prompt + tokeni za dovršavanje).
- Ponovo generiši posljednji odgovor.
- Šalje na `POST /v1/chat/completions` uz SSE streaming.

### Kartica Compare

Ključni diferencijator za proxy: pokrenite 1 prompt na do **4 modela paralelno**.

- Do 4 kolone, svaka nezavisno streamuje sa `/v1/chat/completions`.
- Dugme `+ Add model` (prečica Cmd+K) za dodavanje kolona.
- `Run all ▶` pokreće sve streamove istovremeno putem `Promise.all` + `AbortController` po koloni.
- Globalno **Cancel all** prekida svaki stream koji je u toku.
- `ProviderMetrics` po koloni prikazuje TTFT, TPS, tokene i procijenjeni trošak u realnom vremenu.
- Metrike označene kao **"client-side estimate"** (D12) — mjereno od prvog SSE chunk-a.

### Kartica API

Zadržava 100% originalnog Monaco uređivača za napredne korisnike (D14):

- 10 endpointa: chat completions, completions, embeddings, images, audio, speech, transcriptions, moderations, rerank, search.
- Multimodalno otpremanje datoteka.
- SSE streaming sa izlazom u realnom vremenu.
- Upakovano kao `ApiTab.tsx` (lazy-loaded, `ssr: false`).

### Kartica Build

UI za pozivanje alata/funkcija i strukturirani izlaz:

- `ToolsBuilder.tsx` — dodavanje/uređivanje/uklanjanje `tools[]` sa JSON schema uređivačem po alatu.
  Validira parametre putem `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — prebacivanje JSON moda + JSON schema uređivač.
  Validira odgovor prema šemi putem `StructuredOutputSchema` (Zod).
- Šalje zahtjev na `/v1/chat/completions` sa `tools[]` i/ili `response_format`.

## Konfiguracijski panel (Dijeljeno)

`StudioConfigPane.tsx` — uvijek vidljiv, sklopiv.

| Polje          | Komponenta            | Bilješke                                                                                  |
| -------------- | --------------------- | ----------------------------------------------------------------------------------------- |
| Endpoint       | `<select>`            | 10 opcija koje odgovaraju `PlaygroundEndpoint`                                            |
| Model          | `<input>`             | slobodan tekst, npr. `openai/gpt-4o`                                                      |
| Sistemski upit | `<textarea>`          | proslijeđeno svim karticama                                                               |
| Parametri      | `ParamSliders`        | temperature, max_tokens, top_p, kazna za prisutnost/učestalost, seed, stop                |
| Preseti        | `PresetPicker`        | učitavanje/spremanje imenovanih snimaka konfiguracije (trajno pohranjeno u bazi podataka) |
| Poboljšaj upit | `ImprovePromptButton` | otvara modal upozorenja o kvoti, poziva `/api/playground/improve-prompt`                  |

Stanje (State) se podiže na `PlaygroundStudio.tsx` i prosljeđuje svim karticama. Prebacivanje kartica čuva stanje konfiguracije.

## Gornja traka

`StudioTopBar.tsx`:

- Prebacivač kartica (role="tablist").
- `TokenCostCounter` — prikaz tokena uživo (↑/↓) i procijenjenog troška.
- Dugme za izvoz koda (`</>`) — otvara `ExportCodeModal`.

---

## Modal za izvoz koda

`ExportCodeModal.tsx` koristi `codeExport.ts` za generisanje curl / Python / TypeScript isječaka iz trenutnog `PlaygroundState`. Rezervirano mjesto za API ključ je uvijek `$OMNIROUTE_API_KEY` (D11).

---

## Poboljšivač upita

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Modal upozorava "potrošit će kvotu".
2. Nakon potvrde, šalje `{ system, prompt, model, tone }` na rutu.
3. Ruta interno poziva `/v1/chat/completions` sa `promptImprover.META_SYSTEM_PROMPT`.
4. Vraća `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. UI ažurira sistemski upit u konfiguracijskom panelu i korisnički upit u kartici Chat.

---

## Preseti

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Pohranjeno u `playground_presets` SQLite tabeli (migracija `084_playground_presets.sql`).
- Svaki preset pohranjuje: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: `GET` lista, `POST` kreiranje, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Metrike strima

`useStreamMetrics.ts` + `streamMetrics.ts` (čista funkcija):

- `start()` — bilježi vrijeme početka zahtjeva.
- `onFirstChunk()` — bilježi TTFT.
- `onChunk(n)` — akumulira broj tokena završetka.
- `finish(usage?)` — izračunava konačne metrike: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Cijene iz statičke tabele u `src/lib/playground/types.ts` (označeno kao "procijenjeno" — D13).

| Metoda   | Putanja                          | Handler                                                                                 |
| -------- | -------------------------------- | --------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | Zod-validira `ImprovePromptRequestSchema`; poziva `/v1/chat/completions` sa meta-upitom |
| `GET`    | `/api/playground/presets`        | Vraća `{ presets: PlaygroundPresetListItem[] }`                                         |
| `POST`   | `/api/playground/presets`        | Kreira preset; validira `PlaygroundPresetCreateSchema`                                  |
| `GET`    | `/api/playground/presets/:id`    | Vraća jedan preset ili 404                                                              |
| `PUT`    | `/api/playground/presets/:id`    | Djelimično ažuriranje                                                                   |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                     |

Autentifikacija: opciona (`REQUIRE_API_KEY`). Greške putem `buildErrorBody()` (Hard Rule #12).

## Rješavanje problema

| Simptom                                          | Uzrok                                  | Rješenje                                                                                                    |
| ------------------------------------------------ | -------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Monaco editor se ne prikazuje na API kartici     | SSR učitao Monaco                      | Provjerite da li ApiTab koristi `dynamic(..., { ssr: false })`                                              |
| Upoređivanje streamova se izvršava sekvencijalno | Pogrešna upotreba `Promise.all`        | Sva pokretanja streamova moraju biti poslana u jednom `Promise.all` pozivu                                  |
| Metrike prikazuju `null` TTFT                    | Handler za prvi chunk nije povezan     | Provjerite da li je `useStreamMetrics.onFirstChunk()` pozvan u SSE reader petlji                            |
| Preset se ne čuva                                | Migracija baze podataka nije pokrenuta | Pokrenite `npm run db:migrate` ili ponovo pokrenite server (migracija se automatski pokreće pri pokretanju) |
| Improve prompt vraća 502                         | Model nije postavljen u Config         | Korisnik mora unijeti naziv modela u Config panelu prije poboljšanja                                        |
| Export koda prikazuje `MISSING_API_KEY`          | Placeholder nije umetnut               | `codeExport.ts` uvijek koristi `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"`                                 |
