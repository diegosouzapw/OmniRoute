## Brzo deinstaliranje (v3.6.2+)

OmniRoute nudi dvije ugrađene skripte za potpuno uklanjanje:

### Zadržite svoje podatke

```bash
npm run uninstall
```

Ovo uklanja OmniRoute aplikaciju, ali **zadržava** vašu bazu podataka, konfiguracije, API ključeve i postavke provajdera u `~/.omniroute/`. Koristite ovo ako planirate ponovnu instalaciju kasnije i želite zadržati svoje postavke.

### Potpuno uklanjanje

```bash
npm run uninstall:full
```

Ovo uklanja aplikaciju **i trajno briše** sve podatke:

- Baza podataka (`storage.sqlite`)
- Konfiguracije provajdera i API ključevi
- Datoteke rezervnih kopija (backup)
- Log datoteke
- Sve datoteke u direktorijumu `~/.omniroute/`

> ⚠️ **Upozorenje:** `npm run uninstall:full` je nepovratna radnja. Sve vaše veze sa provajderima, kombi, API ključevi i historija korištenja bit će trajno izbrisani.

## Ručno deinstaliranje

### NPM Globalna instalacija

```bash
# Ukloni globalni paket
npm uninstall -g omniroute

# (Opcionalno) Ukloni direktorijum sa podacima
rm -rf ~/.omniroute
```

### pnpm Globalna instalacija

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Zaustavi i ukloni kontejner
docker stop omniroute
docker rm omniroute

# Ukloni volume (briše sve podatke)
docker volume rm omniroute-data

# (Opcionalno) Ukloni image
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Zaustavi i ukloni kontejnere
docker compose down

# Također ukloni volume (briše sve podatke)
docker compose down -v
```

### Electron Desktop aplikacija

**Windows:**

- Otvorite `Postavke → Aplikacije → OmniRoute → Deinstaliraj`
- Ili pokrenite NSIS deinstalator iz instalacionog direktorijuma

**macOS:**

- Prevucite `OmniRoute.app` iz `/Applications` u Trash
- Uklonite podatke: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Uklonite AppImage datoteku
- Uklonite podatke: `rm -rf ~/.omniroute`

### Instalacija iz izvornog koda (git clone)

```bash
# Ukloni klonirani direktorijum
rm -rf /path/to/omniroute

# (Opcionalno) Ukloni direktorijum sa podacima
rm -rf ~/.omniroute
```

## Direktorijumi sa podacima

OmniRoute po defaultu pohranjuje podatke na sljedećim lokacijama:

| Platforma        | Defaultna putanja             | Override                  |
| ---------------- | ----------------------------- | ------------------------- |
| Linux            | `~/.omniroute/`               | `DATA_DIR` env var        |
| macOS            | `~/.omniroute/`               | `DATA_DIR` env var        |
| Windows          | `%APPDATA%/omniroute/`        | `DATA_DIR` env var        |
| Docker           | `/app/data/` (mounted volume) | `DATA_DIR` env var        |
| XDG-kompatibilno | `$XDG_CONFIG_HOME/omniroute/` | `XDG_CONFIG_HOME` env var |

### Datoteke u direktorijumu sa podacima

| Datoteka/Direktorijum | Opis                                                         |
| --------------------- | ------------------------------------------------------------ |
| `storage.sqlite`      | Glavna baza podataka (provajderi, kombi, postavke, ključevi) |
| `storage.sqlite-wal`  | SQLite write-ahead log (privremeno)                          |
| `storage.sqlite-shm`  | SQLite zajednička memorija (privremeno)                      |
| `call_logs/`          | Arhive payload-a zahtjeva                                    |
| `backups/`            | Automatske rezervne kopije baze podataka                     |
| `log.txt`             | Stari log zahtjeva (opcionalno)                              |

## Provjera potpunog uklanjanja

Nakon deinstalacije, provjerite da nema preostalih datoteka:

```bash
# Provjera globalnog npm paketa
npm list -g omniroute 2>/dev/null

# Provjera direktorija sa podacima
ls -la ~/.omniroute/ 2>/dev/null

# Provjera aktivnih procesa
pgrep -f omniroute
```

Ako je neki proces još uvijek aktivan, zaustavite ga:

```bash
pkill -f omniroute
```
