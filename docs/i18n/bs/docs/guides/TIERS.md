# OmniRoute nivoi — Korisničko uputstvo

OmniRoute organizuje 352 podržana provajdera u 3 ekonomska nivoa. Svaki zahtjev prolazi kroz njih redom dok jedan ne vrati uspješan odgovor — dobijate najjeftiniji održivi odgovor bez potrebe za pisanjem koda za rezervne opcije (fallback).

## Nivo 1 — Pretplata

**Provajderi koje već plaćate.** OmniRoute koristi svaku kap kvote prije nego što istekne.

| Provajder                           | Zašto Nivo 1                                            |
| ----------------------------------- | ------------------------------------------------------- |
| Claude Code OAuth                   | Anthropic Pro/Team — fiksna cijena, često neiskorišteno |
| OpenAI Codex (ChatGPT subscription) | Plus/Team uključuje Codex kvotu                         |
| GitHub Copilot                      | Po sjedištu — kvota se resetuje mjesečno                |
| Cursor IDE                          | Pro plan kvota                                          |
| Antigravity / Devin Desktop         | Ugrađene kvote                                          |

**Strategija**: usmjerite ovdje prvo za svaki zahtjev koji odgovara prednostima modela. Praćenje kvota nadgleda približavanje reseta, a `reset-aware` combo strategija daje prioritet u skladu s tim. Da biste prvo usmjerili Nivo 1 i prešli na plaćene nivoe tek kada kvota istekne, koristite `auto/thrifty` ID — ili `auto/subscription` da ostanete na kapacitetu uključenom u plan i umjesto toga zatvorite zahtjev (fail closed). Pogledajte [Subscription-first routing](../routing/SUBSCRIPTION_LADDER.md).

## Nivo 2 — Jeftino

**Provajderi sa plaćanjem po tokenu ispod $1/1M tokena.** Rezervisano za rad velikog obima ili nakon što kvote Nivoa 1 dostignu limite.

| Provajder                    | Cijena (ulaz/izlaz) | Prednosti              |
| ---------------------------- | ------------------- | ---------------------- |
| DeepSeek V4 Pro              | $0.27 / $1.10 po 1M | Kod, rezonovanje       |
| GLM-4.5                      | $0.60 / $2.20 po 1M | Dugačak kontekst       |
| MiniMax M1                   | $0.20 / $1.10 po 1M | Brzina                 |
| Qwen Coder                   | $0.30 / $1.20 po 1M | Kod                    |
| OpenRouter (price-optimized) | varira              | 100+ modela, dinamično |

**Strategija**: combo `cost-optimized` bira model sa najnižom cijenom po tokenu koji ispunjava filter sposobnosti zadatka (vid, JSON režim, alati, maksimalni kontekst).

## Nivo 3 — Besplatno

**Provajderi bez troškova** — besplatni nivoi, kreditni programi, dnevne OAuth kvote.

| Provajder        | Besplatna kvota / krediti                        |
| ---------------- | ------------------------------------------------ |
| Kiro AI          | Besplatan Claude nivo (velikodušna fer upotreba) |
| OpenCode Free    | Bez autorizacije, velikodušni limiti brzine      |
| Qoder            | Besplatan OAuth                                  |
| Google Vertex AI | $300 kredita za nove naloge                      |
| Amazon Q         | Besplatan nivo za AWS korisnike                  |
| Pollinations     | Otvoren javni API                                |
| Cloudflare AI    | Workers AI besplatan nivo                        |

**Strategija**: combo `auto` sa budžetskim ograničenjem usmjerava ovdje kada Nivo 1+2 ne uspiju ili kada je postavljeno `useFreeOnly=true`. Besplatni provajderi često imaju slabije limite brzine — prekidač strujnog kola (circuit breaker) ih oporavlja pri usporavanju (backoff).

## Konfigurisanje nivoa

Kontrolna tabla → **Nivoi** → dodijelite svoje provajdere. Podrazumijevane vrijednosti (iz `tierDefaults.json`) su razumne; uredite ih kada imate specifične pretplate kojima želite dati prioritet ili provajdere koje želite isključiti.

Auto-Combo bodovanje od 16 faktora takođe uzima u obzir nivo. Pogledajte [`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetrija

Kontrolna tabla → **Upotreba** prikazuje tokene potrošene po nivou dnevno. Koristite ovo da:

- Potvrdite da se Nivo 1 u potpunosti koristi (u suprotnom trošite vrijednost pretplate)
- Identifikujete koji modeli Nivoa 2 se najviše biraju (konsolidujte na 1-2)
- Provjerite da li Nivo 3 štedi novac na testnim/istraživačkim radnim opterećenjima

## Uobičajeni obrasci

### Čisto besplatno radno opterećenje

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Snažno forsira Nivo 3; koristi Nivo 2 samo ako Nivo 3 nije dostupan.

### Prvo pretplata sa jeftinom rezervnom opcijom

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Eksplicitna uređena lista koja odgovara Nivo 1 → Nivo 2 → Nivo 3.
