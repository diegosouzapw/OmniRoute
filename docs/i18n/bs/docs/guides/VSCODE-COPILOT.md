# VS Code Copilot Chat — OmniCopilot ekstenzija

**OmniCopilot** postavlja svaki model koji vaš OmniRoute nudi u _izvorni_ GitHub Copilot Chat birač modela. Nema druge bočne trake, nema zasebnog chat interfejsa — Copilotov agent mod, pozivanje alata, MCP serveri i prilagođene instrukcije nastavljaju raditi, samo pokrenuti na modelu koji odaberete.

|                            |                                                                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Instalacija (VS Code)**  | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Instalacija (forkovi)**  | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Izvorni kod / problemi** | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Zahtijeva**              | VS Code 1.104+                                                                                                                                  |

> **Nije potrebna Copilot pretplata.** Od verzije VS Code 1.122, provajder jezičnog modela radi bez GitHub prijave i bez ikakvog Copilot plana. Inline dopune i funkcionalnosti temeljene na embeddings-ima ostaju izvan API-ja provajdera i još uvijek zahtijevaju Copilot.

---

## Postavljanje

1. **Pokrenite OmniRoute** — `npm install -g omniroute && omniroute` (kontrolna ploča na `http://localhost:20128`).
2. **Instalirajte ekstenziju** — pretražite "OmniRoute" u prikazu ekstenzija.
3. **Odaberite model** — Copilot Chat → birač modela → **Manage Models…** → **OmniRoute**, zatim označite ono što želite.

Nema ništa za konfigurisanje kada OmniRoute radi na zadanom portu. Za udaljenu instancu, otvorite **OmniRoute ikonu u Activity Bar-u** (ili pokrenite `OmniRoute: Manage Connection`) i postavite:

- **Server URL** — korijen servera, npr. `http://192.168.0.15:20128`. Sufiks `/v1` dodaje ekstenzija; nemojte ga uključivati.
- **API ključ** — samo kada server postavi `REQUIRE_API_KEY`. Pohranjeno u OS keychain putem VS Code SecretStorage, nikada u `settings.json`.

---

## Šta će birač prikazati

Ekstenzija ne prikazuje sirovi `GET /v1/models` payload — ona ga oblikuje, a broj koji vidite je manji od veličine kataloga iz dva namjerna razloga.

### Traži jedan ID po modelu

`MODELS_CATALOG_PREFIX_MODE` je po zadanom **`dual`**, što reklamira svaki model dvaput — jednom pod kratkim alias prefiksom i jednom pod kanonskim prefiksom provajdera — tako da starije konfiguracije klijenata nastavljaju razrješavati oba oblika:

```
cc/claude-sonnet-4-6        ← alias prefiks
claude/claude-sonnet-4-6    ← kanonski prefiks, isti model
```

Ekstenzija zahtijeva **`GET /v1/models?prefix=alias`** tako da stiže jedan ID po modelu, bez promjene postavke na razini servera za vaše druge klijente. Na referentnoj instanci ovo je saželo **2345 unosa na 1396 — 949 duplikata, nula izgubljenih modela.**

Ako radije želite to popraviti na razini servera za _svakog_ klijenta, postavite `MODELS_CATALOG_PREFIX_MODE` feature flag na `alias` u kontrolnoj ploči. Pogledajte [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) za parametar upita i tabelu po modovima.

### Skriva modele koji ne mogu chatati

Katalog također navodi modele za slike, video, audio, rerank, embedding i moderaciju. Oni se ionako odbijaju pri zahtjevu za chat:

```
HTTP 400 — Model '<id>' is an image-generation model and cannot be used on
/v1/chat/completions. Use POST /v1/images/generations instead.
```

pa se filtriraju prema njihovom `type` polju prije nego što stignu do birača. **Responses-API modeli su zadržani** — svaki Codex / GPT-5.x unos reklamira `supported_endpoints: ["responses"]`, a OmniRoute ih prevodi za `/v1/chat/completions`, tako da su savršeno upotrebljivi.

### Provajderi koje nikada niste konfigurirali

Katalog navodi modele od provajdera s **aktivnom vezom** _plus_ svakog **noAuth** provajdera — one bez ključa koji čine veći dio besplatnog nivoa. To je namjerno. Da biste ih sakrili, dodajte ih u `blockedProviders` u postavkama kontrolne ploče; ništa se ne mijenja u ekstenziji.

## Kontrolna tabla unutar VS Code kartice

`omnicopilot.dashboardOpen: "editor"` prikazuje OmniRoute kontrolnu tablu u kartici editora putem Simple Browser-a umjesto u eksternom pretraživaču. Ugrađivanje je **opciono na serveru** putem `DASHBOARD_ALLOW_EMBED=vscode`, što servira HTML stranice sa `frame-ancestors 'self' vscode-webview:` umjesto podrazumijevanog `frame-ancestors 'none'` + `X-Frame-Options: DENY`. API površina (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) zadržava stroga zaglavlja u svakom slučaju.

> ⚠️ **Ovo je flag za vrijeme izgradnje (build-time), a ne za vrijeme izvršavanja (runtime).** Next.js kompajlira `headers()` u manifest rute, tako da `next.config.mjs` čita varijablu dok se bundle gradi (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`). Exportovanje iste ispred već izgrađenog servera ne mijenja ništa — zaglavlja su fiksirana.

```bash
# varijabla mora biti prisutna na BUILD komandi
DASHBOARD_ALLOW_EMBED=vscode npm run build        # ili npm run build:release
npm start
```

| Kako ste instalirali       | Možete li omogućiti ugrađivanje?                                                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Iz izvornog koda           | ✅ postavite varijablu na build komandi, kao iznad                                                                                               |
| `npm install -g omniroute` | ❌ objavljeni paket isporučuje već izgrađeni bundle — umjesto toga izgradite iz izvornog koda                                                    |
| Docker slika               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — već izgrađena slika na Docker Hub-u nema omogućeno ugrađivanje |

Bez build-a sa omogućenim ugrađivanjem, stranica odbija da se prikaže u okviru (frame), ekstenzija to detektuje iz zaglavlja odgovora i vraća se na eksterni pretraživač — ništa se ne kvari, i to se prijavi samo jednom. Pogledajte [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) i issue [#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Konfigurisanje vaših drugih alata iz VS Code-a

**`OmniRoute: Configure Coding CLI`** pokreće `omniroute` CLI da zapiše profile spremne za upotrebu za Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code, Kilo i Roo — iste konfiguracije opisane u [`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). API ključ se prosljeđuje CLI-u putem `OMNIROUTE_API_KEY` varijable okruženja, nikada putem komandne linije.

## Rješavanje problema

| Simptom                                                         | Uzrok / rješenje                                                                                                                                                                                                                                                               |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Nema OmniRoute modela u biraču                                  | Server nije dostupan. Tačka na statusnoj traci postaje siva; pokrenite `OmniRoute: Check Connection`. Otkrivanje je tiho po dizajnu i ne dodaje modele umjesto da vas upozori.                                                                                                 |
| Svaki model se pojavljuje dvaput                                | Koristite OmniCopilot stariji od 1.0.1 — ažurirajte. Ekstenzija sada zahtijeva `?prefix=alias`.                                                                                                                                                                                |
| Model za sliku/audio je bio naveden, a sada ga nema             | Namjerno od 1.0.1 — nikada nije mogao odgovoriti na zahtjev za chat.                                                                                                                                                                                                           |
| Panel nedostaje na traci aktivnosti (Activity Bar)              | VS Code pomjera dodatne kontejnere prikaza u "…" preliv (overflow) na dnu trake aktivnosti, a kontejner sakriven desnim klikom ostaje sakriven. Kliknite desnim tasterom miša na traku aktivnosti → označite **OmniRoute**, ili ga otvorite sa `OmniRoute: Manage Connection`. |
| Kontrolna tabla se otvara u pretraživaču uprkos `editor` režimu | Server nije **izgrađen** sa `DASHBOARD_ALLOW_EMBED=vscode` (pogledajte iznad) — postavljanje pri pokretanju na već izgrađenoj instalaciji ne radi ništa. Rezervna opcija (fallback) je namjerna.                                                                               |
| Lista modela je zastarjela nakon promjene provajdera            | `OmniRoute: Refresh Models`, ili ↻ link u panelu.                                                                                                                                                                                                                              |
