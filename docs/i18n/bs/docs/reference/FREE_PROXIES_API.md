# API za besplatne proksije

OmniRoute isporučuje odabranu grupu besplatnih proksija u tabeli `free_proxies`, sinhronizovanih sa eksternih provajdera (1proxy, proxifly, iplocate, webshare). Kontrolna tabla ih prikazuje pod **Settings → Free Proxies**. Ovaj dokument pokriva filtriranje na strani servera, sortiranje, brojanje i izvještavanje o greškama pri sinhronizaciji koje izlaže ruta za listanje.

## Ruta za listanje — `GET /api/settings/free-proxies`

Vraća filtrirani, sortirani, paginirani isječak plus ukupan broj. Filtriranje i brojanje se dešavaju u SQL-u, tako da korisnički interfejs (UI) može prikazati stvarni ukupan broj (npr. `Total: 0`) bez učitavanja svakog reda u memoriju.

### Parametri upita

| Parametar         | Tip                                | Podrazumijevano | Značenje                                                                                       |
| ----------------- | ---------------------------------- | --------------- | ---------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`            | Case-sensitive `LIKE` na koloni host (i source).                                               |
| `protocol`        | string                             | `""`            | `type` filter: `http` / `https` / `socks4` / `socks5`. Prazno = sve.                           |
| `country`         | string                             | `""`            | `countryCode` filter (ISO-2). Prazno = sve.                                                    |
| `minQuality`      | number                             | `0`             | Samo redovi sa `qualityScore >= minQuality`. `0` = bez donje granice.                          |
| `disabledSources` | string                             | `""`            | ID-ovi izvora razdvojeni zarezima za isključivanje (npr. `proxifly,webshare`).                 |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`       | `quality` = score desc; `latency` = latency asc (nulls last); `recent` = `lastValidated` desc. |
| `offset`          | number                             | `0`             | Početak paginacije.                                                                            |
| `limit`           | number                             | `50`            | Veličina stranice (ograničeno na strani servera).                                              |

### Odgovor

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` odražava filtrirani ukupan broj **prije** paginacije, tako da UI može nezavisno prikazati `Total: N` i `hasMore`. `syncErrors` je ključiran prema ID-u izvora i popunjen je samo za izvore čija je posljednja sinhronizacija neuspješna — rezultat `Total: 0` nikada nije bez objašnjenja.

## Dodavanje u grupu — `POST /api/settings/free-proxies/[id]/add-to-pool`

Promoviše besplatni proksi u upravljanu `proxy_registry` grupu. Prvo validira upstream; po uspjehu vraća ID novog proksija u grupi i izmjerenu latenciju.

## Sinhronizacija — `POST /api/settings/free-proxies/sync`

Ponovo povlači sve omogućene izvore (ili podskup u `{ "sources": [...] }`). Svaki izvor se sinhronizuje nezavisno; izvor koji ne uspije se bilježi u `syncErrors`, a ostali se i dalje završavaju, tako da djelimične sinhronizacije nikada ne brišu prethodne dobre podatke.

## Statistika — `GET /api/settings/free-proxies/stats`

Vraća agregat `total / inPool / avgQuality / bySource / lastSyncAt` bez sadržaja redova — koristi se za vidžete zaglavlja kontrolne table.
