## 개요

Local Corpus를 사용하면 운영자가 명시적으로 승인된 하나의 텍스트 파일 디렉터리를
OmniRoute의 MCP 서버에 공개할 수 있습니다. 파일은 원래 디렉터리에 그대로 유지됩니다. OmniRoute는
SQLite에 정규화된 루트 경로만 저장하고 메모리 내 검색 인덱스를 유지합니다. 코퍼스 콘텐츠를
리포지토리나 데이터베이스에 복사하지 않습니다.

인덱스 새로 고침은 증분 방식으로 수행됩니다. 변경되지 않은 파일은 크기와 수정 시간을 기준으로
재사용하고, 변경된 파일은 다시 읽은 후 SHA-256으로 해시하며, 삭제된 파일은 제거합니다.
검색 시 30초보다 오래된 인덱스는 새로 고칩니다. 호출자가 즉시 새로 고침을 요청할 수도 있습니다.

## 소스 구성

설정 라우트에는 다른 설정 API와 동일한 관리 인증이 필요합니다.
제출하는 경로는 이미 존재해야 하며 절대 디렉터리 경로여야 합니다.

```bash
# 승인된 디렉터리 연결
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# 구성 및 인덱스 상태 확인
curl http://localhost:20128/api/settings/local-corpus

# 소스 파일을 변경하지 않고 연결 해제
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP 도구

세 도구 모두 `read:local-corpus`가 필요합니다. 도구 응답에는 상대 경로와
루트 디렉터리의 기본 이름만 노출되며, 절대 경로는 절대 노출되지 않습니다.

| 도구                  | 설명                                                                            |
| :-------------------- | :------------------------------------------------------------------------------ |
| `local_corpus_status` | 구성 상태, 인덱스 크기, 제한 및 마지막 새로 고침 시간을 보고합니다              |
| `local_corpus_search` | 인덱싱된 텍스트를 검색하고 행 범위로 제한된 스니펫을 반환합니다(최대 20개 결과) |
| `local_corpus_read`   | 허용된 코퍼스 상대 경로 파일 하나에서 제한된 행 범위를 읽습니다                 |

MCP 입력 예시:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## 안전 경계

- 허용 목록은 텍스트 형식을 대상으로 합니다: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, `.yml`.
- 심볼릭 링크는 건너뜁니다. 읽기 경로는 정규화되며 구성된 루트 내부에 있어야 합니다.
  절대 경로와 경로 순회 시도는 거부됩니다.
- 민감하거나 생성된 디렉터리 이름은 제외됩니다: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`,
  `secrets`.
- 기본 제한은 파일 5,000개, 파일당 1 MiB, 인덱싱된 전체 콘텐츠 64 MiB,
  검색 청크당 약 4,000자, 읽기당 400행입니다.
- NUL이 포함된 파일은 텍스트가 아닌 것으로 간주하여 건너뛰거나 거부합니다.

PDF, DOCX, 이미지, 아카이브 같은 바이너리 문서는 의도적으로 지원하지 않습니다.
인덱싱하기 전에 구성된 디렉터리에서 승인된 텍스트 형식으로 변환하십시오.

## 운영 참고 사항

- 구성된 루트를 변경하거나 삭제하면 공유 메모리 내 인덱스가 지워집니다.
- 프로세스를 다시 시작하면 인덱스가 폐기됩니다. 다음 검색 시 구성된
  소스에서 인덱스를 다시 빌드합니다.
- `local_corpus_status`는 스캔을 강제로 실행하지 않습니다. 즉시 재스캔해야 할 경우
  `refresh: true`를 사용하여 `local_corpus_search`를 호출하십시오.
- 스캔 및 읽기 실패는 집계되거나 정제된 오류로 반환되며, 소스 파일은
  절대 수정되지 않습니다.
