> **신뢰할 수 있는 원본:** `src/lib/agentSkills/`(카탈로그, 생성기, 파서) + `skills/` 디렉터리(SKILL.md 파일)
> **마지막 업데이트:** 2026-08-02 — v3.8.50

Agent Skills는 외부 에이전트, MCP 클라이언트 및 A2A 오케스트레이터에 OmniRoute의 REST API와 CLI 사용법을 안내하는 구조화된 SKILL.md 파일입니다. [Omni Skills](./SKILLS.md)(OmniRoute 내부에서 실행되는 LLM 도구 정의)와 달리 Agent Skills는 에이전트 컨텍스트에 직접 제공할 수 있는 정적 마크다운으로 구성된 _문서 카탈로그_입니다.

---

## 개요

카탈로그에는 **45개의 Agent Skills**(REST API 23개 + CLI 21개 + 구성 워크플로 1개)가 포함되어 있습니다. 각 스킬에는 다음 항목이 있습니다.

- **정식 ID**(`omni-auth`, `cli-serve` 등)
- YAML 프런트매터(`name`, `description`)와 풍부한 마크다운 본문을 포함하는 `skills/{id}/SKILL.md`의 **SKILL.md** 파일
- OpenAPI 명세 및 CLI 레지스트리에서 파생된 **REST 엔드포인트**(API 스킬) 또는 **CLI 하위 명령어**(CLI 스킬)
- 실시간 가져오기를 위한 **GitHub 원시 URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## REST API 탐색

| 엔드포인트                   | 메서드 | 설명                                                               | 인증 |
| :--------------------------- | :----- | :----------------------------------------------------------------- | :--- |
| `/api/agent-skills`          | GET    | 카탈로그 목록(선택 사항: `?category=api\|cli\|config&area=<area>`) | 없음 |
| `/api/agent-skills/{id}`     | GET    | 단일 스킬 메타데이터 조회                                          | 없음 |
| `/api/agent-skills/{id}/raw` | GET    | SKILL.md를 `text/markdown`으로 가져오기                            | 없음 |
| `/api/agent-skills/coverage` | GET    | 커버리지 통계(존재하는 SKILL.md 파일 수)                           | 없음 |
| `/api/agent-skills/generate` | POST   | 생성기 실행(dryRun/prune/onlyIds)                                  | 관리 |

예시 — 모든 API 스킬 나열:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

예시 — 단일 SKILL.md 가져오기:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## 외부 에이전트가 스킬을 사용하는 방법

### 1. REST를 통한 검색

```bash
# 전체 카탈로그 가져오기
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# 컨텍스트 주입을 위한 SKILL.md 가져오기
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP를 통한 검색

```typescript
// Claude Desktop / Cursor MCP 클라이언트에서:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → 각각에 rawUrl이 포함된 AgentSkill 배열
```

### 3. A2A를 통한 검색

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table은 45개 스킬 ID 전체와 rawUrl 열이 포함된 마크다운 테이블
```

### 4. GitHub 원시 파일 직접 가져오기(서버 불필요)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## 생성기

생성기는 선별된 카탈로그 + OpenAPI 명세 + CLI 레지스트리를 읽고 각 항목에 대해 `skills/{id}/SKILL.md`를 작성합니다.

```bash
# 미리보기(드라이 런, 파일을 작성하지 않음)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# 전체 재생성
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# 특정 ID 재생성
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

생성기 응답은 `GeneratorReport`입니다.

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
