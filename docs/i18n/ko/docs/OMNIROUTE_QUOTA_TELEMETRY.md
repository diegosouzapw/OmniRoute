OmniRoute는 공급자 할당량 텔레메트리와 Ghostlight 회계를 분리합니다.

## 정확한 상태

- `healthy`는 소스가 사용 가능한 잔여 용량을 보고했음을 의미합니다.
- `approaching_limit`는 소스가 구성된 임계값 이하의 잔여 용량을 보고했음을 의미합니다.
- `exhausted`는 소스가 용량이 0이거나 사용량이 한도에 도달했다고 보고한 경우에만 생성됩니다.
- `unavailable`은 지원되는 소스에서 데이터를 반환하지 못했음을 의미합니다.
- `unknown`은 지원되는 소스가 없거나 알려진 공급자 한도가 없음을 의미합니다.

알 수 없음은 소진된 상태가 아니며 공급자를 비활성화하지 않습니다.

소스는 공식 공급자 API, 인증된 사용량 API, 명시적으로 매핑된 응답 헤더, 관리자 구성, 로컬 추정치, 알 수 없음 순으로 우선 사용됩니다. 로컬 추정치는 공급자 청구 데이터로 표시되지 않습니다.

응답 헤더는 명시적인 공급자 매핑을 통해서만 구문 분석됩니다. 일반적인 헤더 이름이 전역적으로 적용된다고 가정하지 않습니다.
