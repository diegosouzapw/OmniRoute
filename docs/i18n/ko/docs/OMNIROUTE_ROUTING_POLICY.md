라우팅은 기존 기능 및 조합 선택 로직을 유지한 다음, 할당, 상태, 회로, 할당량, 지연 시간, 안정성, 모델 선호도 및 비용 선호도 요소를 적용합니다.

적응형 점수는 설명 가능하며, 선택된 후보와 순위가 지정된 모든 후보를 모두 반환합니다. 할당량이 소진되었거나, 할당이 거부되었거나, 회로가 열린 후보는 대상에서 제외됩니다. 할당량을 알 수 없는 후보는 중립적인 할당량 요소가 적용된 상태로 대상에 포함됩니다.

라우팅 미리보기는 결정론적으로 동작하며 업스트림 모델 요청을 전혀 수행하지 않습니다.

`POST /api/omniroute/route/preview`

응답에는 후보 점수, 요소, 이유, 선택된 제공자 및 `liveRequestExecuted: false`가 포함됩니다.
