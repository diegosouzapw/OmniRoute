Caveman 압축은 기본 제공 영어 규칙 외에도 언어별 규칙 팩을 로드할 수 있습니다.
이를 통해 핵심 엔진을 안정적으로 유지하면서 포르투갈어, 스페인어, 독일어, 프랑스어, 이탈리아어, 일본어 및
향후 추가될 언어 팩을 독립적으로 발전시킬 수 있습니다.

## 위치

언어 팩은 다음 경로에 있습니다.

```txt
open-sse/services/compression/rules/<language>/
```

현재 제공되는 팩(`rules/` 디렉터리의 내용을 기준으로 확인됨):

| 언어               | 디렉터리       | 제공되는 규칙 카테고리                              |
| ------------------ | -------------- | --------------------------------------------------- |
| 영어               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| 스페인어           | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| 포르투갈어(브라질) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| 인도네시아어       | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| 이탈리아어         | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| 독일어             | `rules/de/`    | `context`, `filler`, `structural`                   |
| 프랑스어           | `rules/fr/`    | `context`, `filler`, `structural`                   |
| 일본어             | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **동등성 참고:** `en`, `es`, `pt-BR`, `id`, `it` 팩에는 5개 카테고리가 모두 포함되어 있으며, `de`, `fr`, `ja` 팩에는 3개 카테고리가 제공됩니다. 누락된 `dedup` 및 `ultra` 카테고리는 별도의 알림 없이 기본 제공 영어 규칙으로 대체됩니다. 규모가 작은 팩에 `dedup.json`과 `ultra.json`을 추가하는 기여를 환영합니다.
>
> `pt-BR` 팩은 Lenine Júnior가 브라질 포르투갈어 문법을 위해 처음부터 설계한 압축 시스템인 **[Troglodita](https://github.com/leninejunior/troglodita)**를 기반으로 합니다(동어 반복 축소, PT-BR 불필요 표현 제거, 브라질 개발자 커뮤니티를 위한 기술 약어).
>
> 표준 카테고리 목록과 카테고리별 스키마는 [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json)에 있습니다(JSON Schema 초안 2020-12).

## 언어 감지

`languageDetector.ts`는 가벼운 휴리스틱을 사용하여 프롬프트 텍스트의 언어를 추론합니다.
설정된 기본 언어는 계속 적용되며, 정확한 제어가 필요한 경우 구성을 통해 감지를 비활성화할 수 있습니다.

감지 결과는 규칙 팩을 선택하는 데만 사용됩니다. 공급자 라우팅, 로케일 선택 또는 UI 언어는
변경하지 않습니다.

## 구성 형태

압축 설정에는 다음을 포함할 수 있습니다.

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig`는 대시보드/미리보기의 기본값을 제어합니다. `cavemanConfig`는 Caveman이 메시지 텍스트를 압축할 때
사용하는 런타임 엔진 구성입니다.

## 언어 팩 추가

1. `open-sse/services/compression/rules/<language>/<pack>.json`을 생성합니다.
2. `docs/compression/COMPRESSION_RULES_FORMAT.md`의 Caveman 규칙 형식을 사용합니다.
3. 치환은 보수적으로 적용하고 코드, 식별자, URL 또는 JSON을 변경하지 마세요.
4. 언어 선택 및 치환 동작에 대한 테스트를 추가하거나 업데이트합니다.
5. 해당 언어가 UI 선택기에 표시되는 경우 새로운 대시보드/i18n 레이블을 노출합니다.

## API

사용 가능한 팩은 다음과 같이 조회할 수 있습니다.

```bash
curl http://localhost:20128/api/compression/language-packs
```

미리 보기 엔드포인트는 언어 구성 재정의를 허용합니다.

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

v3.8.0에서는 6개의 모든 언어 팩에 모든 Caveman 강도(LITE, FULL, ULTRA)에서 적용되는 `SHARED_BOUNDARIES` 절이 추가되었습니다. 이 절은 주변의 군더더기 표현 제거 여부와 관계없이 엔진이 다음 패턴을 원문 그대로 보존하도록 지시합니다.

| 패턴 유형              | 예시                                   |
| ---------------------- | -------------------------------------- |
| 펜스 코드 블록         | ` ```python\n...\n``` `                |
| 인라인 코드            | `` `my_var` ``                         |
| URL                    | `https://example.com/path`             |
| 파일 경로(절대 + 상대) | `/etc/hosts`, `./src/index.ts`         |
| 오류 헤더              | `Error:`, `TypeError:`, `SyntaxError:` |
| 스택 추적 줄           | `  at functionName (file.ts:12:3)`     |

이러한 패턴은 `DEFAULT_CAVEMAN_CONFIG.preservePatterns`(이전에는 `[]`)에 채워집니다. 이 상수는 `open-sse/services/compression/types.ts`에 있습니다.

### 이것이 중요한 이유

SHARED_BOUNDARIES가 없으면 공격적인 Caveman 모드가 반복되는 산문처럼 보이지만 실제로는 코드 조각, 파일 경로 또는 오류 스택인 콘텐츠를 제거할 수 있습니다. SHARED_BOUNDARIES는 군더더기 규칙이 실행되기 전에 적용되는 언어 독립적인 안전망 역할을 합니다.

### preservePatterns 사용자 지정

압축 설정을 통해 런타임에 패턴을 추가할 수 있습니다.

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

사용자 지정 패턴은 6개의 기본값을 대체하지 않고 확장합니다.

## 운영 참고 사항

- 언어 팩이 없으면 영어 기본 제공 규칙이 폴백으로 유지됩니다.
- 유효하지 않은 기본 제공 JSON 팩은 릴리스 자산의 품질이 조용히 저하되지 않도록 유효성 검사에 실패합니다.
- 규칙 팩은 데이터 전용이며 코드를 가져오거나 임의의 로직을 실행해서는 안 됩니다.
- 압축 분석 계층은 전체 프롬프트 텍스트가 아니라 선택된 모드와 엔진을 기록합니다.
