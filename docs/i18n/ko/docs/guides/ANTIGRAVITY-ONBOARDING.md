## 1. Antigravity와 Antigravity CLI (agy) 비교

두 제공자는 **동일한 Google 백엔드**를 공유합니다. 즉, OAuth 클라이언트, 토큰 갱신, 엔드포인트 및 Google 계정이 모두 동일합니다. 차이점은 표시되는 모델입니다.

> Google의 공식 비교는 [Antigravity CLI 발표](https://antigravity.google/blog/introducing-google-antigravity-cli)를 참조하세요.

| 항목                 | `antigravity` (IDE)                    | `agy` (CLI)                                           |
| -------------------- | -------------------------------------- | ----------------------------------------------------- |
| **Google 제품**      | Antigravity 2.0 / Antigravity IDE      | Antigravity CLI                                       |
| **백엔드**           | 동일한 Google Cloud Code API           | 동일한 Google Cloud Code API                          |
| **OAuth / 토큰**     | 동일한 클라이언트, 동일한 갱신 방식    | 동일한 클라이언트, 동일한 갱신 방식                   |
| **모델 카탈로그**    | 정적 선별 목록(OmniRoute에 하드코딩됨) | `:fetchAvailableModels`를 통해 Google에서 실시간 조회 |
| **Claude 모델**      | Sonnet 4.6, Opus 4.6(각각 4개 변형)    | Sonnet 4.6, Opus 4.6(각각 4개 변형)                   |
| **Gemini 명명 방식** | 깔끔한 레이블(Low/Medium/High)         | 업스트림 ID(extra-low/low/agent)                      |
| **추가 모델**        | `gpt-oss-120b-medium`                  | Google의 추가 모델이 포함될 수 있음                   |
| **기본 사용 사례**   | IDE 통합(VS Code, JetBrains)           | CLI / API 액세스                                      |
| **할당량**           | agy와 공유(동일한 Google 계정)         | antigravity와 공유(동일한 Google 계정)                |

**사용 가능한 모델(실험을 통해 검증됨, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash(다양한 사고 수준)
- Claude: Sonnet 4.6, Opus 4.6(각각 default/low/medium/high 변형 제공)
- 기타: GPT-OSS 120B Medium
- **Claude Sonnet 5는 사용할 수 없습니다** — 4.6 변형만 지원됩니다

**모델 카탈로그가 다른 이유**: Google의 공식 블로그에 따르면 Google의 CLI는 "속도와 낮은 오버헤드에 최적화"되어 있으며 "Gemini 모델과 공동 최적화"되어 있습니다. Web/IDE 제품은 "포괄성에 최적화"되어 있습니다. CLI는 `:fetchAvailableModels`를 사용하여 모델을 동적으로 검색하는 반면, IDE는 정적으로 선별된 목록을 사용합니다.

**실제 사용 시**: Gemini 모델에는 `agy/` 접두사를 사용하세요(예: `agy/gemini-3.7-flash-high`). 정적으로 선별된 목록에는 `antigravity/`를 사용하세요. 둘 다 동일한 Google 백엔드를 사용하지만 모델 명명 방식은 서로 다릅니다. 할당량은 공유되므로 어느 제공자를 사용하든 동일한 Google 계정의 한도에 반영됩니다.

## 2. Google One AI Pro: 할당량 시스템

> 공식 할당량에 대한 자세한 내용은 [Antigravity 문서: 요금제](https://antigravity.google/docs/plans)를, 최신 가격 변경 사항은 [Antigravity 요금제 변경 사항](https://antigravity.google/blog/changes-to-antigravity-plans)을 참조하세요.

Google Antigravity는 메시지 수가 아닌 "수행된 작업량"(연산 가중치)을 기준으로 하는 **이중 계층 할당량**을 사용합니다.

### 두 가지 계층

| 계층               | 설명                         | 갱신 주기                                                              |
| ------------------ | ---------------------------- | ---------------------------------------------------------------------- |
| **5시간 스프린트** | 즉시 사용 가능한 "작업량" 풀 | 세션의 첫 번째 요청 후 5시간이 지나면 초기화됩니다                     |
| **7일 기준선**     | 주간 최대 한도               | 이 한도에 도달하면 5시간 갱신보다 우선하며, 다음 7일 주기까지 잠깁니다 |

**"수행된 작업량" 계산 방식**: 에이전트를 많이 사용하는 작업(예: "이 저장소 전체를 리팩터링해 줘")은 간단한 작업(예: "이 함수를 수정해 줘")보다 할당량을 훨씬 빠르게 소모합니다. 사용량을 보여 주는 실시간 대시보드는 없습니다.

### 요금제 등급

| 요금제       | 가격       | 할당량                            | 주간 한도                         |
| ------------ | ---------- | --------------------------------- | --------------------------------- |
| Free         | $0         | 충분한 할당량, 매주 갱신          | 있음                              |
| AI Pro       | $19.99/월  | 높은 할당량, 5시간 단위 순환 갱신 | 있음(도달 시 5시간 갱신보다 우선) |
| AI Ultra 5x  | $99.99/월  | Pro 할당량의 5배                  | 주간 한도 없음                    |
| AI Ultra 20x | $199.99/월 | Pro 할당량의 20배                 | 주간 한도 없음                    |

### Gemini 모델과 비-Gemini 모델 비교

- **Gemini 모델**(Flash + Pro): API 가격에 따라 차감되는 하나의 속도 제한을 공유합니다. Flash가 Pro보다 8배 저렴하다면 Flash 토큰을 8배 더 많이 사용할 수 있습니다.
- **비-Gemini 모델**(Claude, GPT-OSS): **별도의** 속도 제한이 적용됩니다. Gemini가 잠긴 경우에도 계속 사용할 수 있습니다.

### AI 크레딧(초과 사용분)

> 크레딧 작동 방식은 [Google One AI 크레딧](https://support.google.com/googleone/answer/14534406)을 참조하세요.

기준선 할당량이 소진된 경우:

- **사용 안 함**: 할당량이 갱신될 때까지 기다리며, "기준선 모델 할당량에 도달함"이 표시됩니다
- **항상 사용**: AI 크레딧을 자동으로 사용하며, 기준선 할당량이 갱신되면 다시 기준선으로 전환됩니다

크레딧은 별도로 구매하며 표준 API 가격에 따라 차감됩니다.

### 주요 세부 정보

- 할당량은 **계정 수준에서 공유**됩니다. Antigravity IDE, CLI 및 OmniRoute에서 동일한 Google 계정을 사용하면 하나의 할당량 풀을 공유합니다
- 각 Google 계정에는 독립적인 할당량이 있습니다. 즉, 여러 계정을 사용하면 여러 할당량 풀을 사용할 수 있습니다
- AI Pro 사용자는 주간 기준선에 도달했을 때 5시간 후 초기화되는 대신 **7일 동안 잠기는 현상**을 보고했습니다(Google은 수요가 많을 때 의도된 동작임을 확인했습니다)

**계정의 할당량이 소진된 경우**: OmniRoute는 조합 경로에서 다음으로 사용 가능한 계정을 이용해 자동으로 재시도합니다. 수동 개입은 필요하지 않습니다.

## 3. projectId를 얻는 방법

모든 antigravity/agy 연결에는 Google Cloud Code `projectId`가 필요합니다. 이것이 없으면 `/v1internal:models` 엔드포인트가 404를 반환합니다.

### 방법 A: 자동(권장)

OmniRoute가 이를 자동으로 처리합니다. Dashboard OAuth를 통해 새 Google 계정을 추가하면 다음 작업이 수행됩니다.

1. OmniRoute가 토큰을 갱신합니다
2. `loadCodeAssist`를 호출하여 projectId를 찾습니다
3. 프로젝트가 없으면 `onboardUser`를 호출하여 프로젝트를 생성합니다
4. `loadCodeAssist`를 다시 호출하여 새로 생성된 projectId를 가져옵니다
5. 데이터베이스에 저장합니다

**대부분의 계정에서 작동합니다**. 수동 단계는 필요하지 않습니다.

### 방법 B: agy CLI를 통한 수동 설정

자동 검색에 실패하는 경우(발생 조건은 섹션 5 참조):

```bash
# agy CLI 설치(아직 설치하지 않은 경우)
npm install -g @anthropic-ai/agy

# Google 계정으로 로그인
agy login

# 온보딩이 필요한 계정 선택
# 이렇게 하면 Cloud Code 등록이 트리거되고 projectId가 할당됩니다
```

`agy login`에 성공한 후 OmniRoute Dashboard에서 토큰을 갱신하세요. projectId가 자동으로 검색됩니다.

### 확인 방법

데이터베이스를 확인하세요.

```bash
# OmniRoute 컨테이너 내부에서
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

또는 로그를 확인하세요.

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuth 리디렉션 URI

### 문제

Google OAuth에는 유효한 리디렉션 URI가 필요합니다. OmniRoute는 기본적으로 `http://127.0.0.1:20128/callback`(루프백)을 사용합니다. 로컬 빌드에서는 작동하지만 **원격 배포에서는 실패합니다**(예: LAN IP를 통해 접속하는 서버).

Google은 다음과 같은 리디렉션 URI를 거부합니다.

- IP 주소를 사용하는 경우(`.com`, `.org` 등으로 끝나는 도메인이어야 함)
- OAuth 클라이언트 설정에 등록된 리디렉션 URI와 일치하지 않는 경우

### 해결 방법

**옵션 A: 기본 제공 OAuth 흐름 사용(기본값)**

- `localhost` 또는 `127.0.0.1`에서 OmniRoute에 접속하는 경우 작동합니다.
- 별도의 설정이 필요하지 않습니다.

**옵션 B: 사용자 지정 OAuth 자격 증명**

- 환경에서 `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web`을 설정합니다.
- 자체 Google OAuth 자격 증명을 제공합니다.
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Google Cloud Console에서 `https://your-domain.com/callback`을 승인된 리디렉션 URI로 등록합니다.

**옵션 C: 초기 로그인에 agy CLI 사용**

- OmniRoute에 접속할 시스템에서 `agy login`을 실행합니다.
- OAuth 흐름이 로컬에서 완료되고 토큰이 저장됩니다.
- Dashboard를 통해 연결을 OmniRoute로 가져옵니다.

### 제한 사항

- 사용자 지정 OAuth 자격 증명을 사용하려면 도메인 이름이 필요합니다(Google은 IP 주소를 리디렉션 URI로 허용하지 않음).
- 도메인이 없는 경우 옵션 A 또는 C를 대신 사용하세요.

## 5. 문제 해결: 자동 설정에 실패하는 경우

OmniRoute는 대부분의 계정에서 projectId 검색 및 온보딩을 자동으로 처리합니다. 실패하는 경우 근본 원인은 일반적으로 다음 중 하나입니다.

### 계정 지역이 차단됨

**증상**: `agy login`이 "Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location."을 반환합니다.

**근본 원인**: Google 계정에는 등록 시 설정되는 백엔드 "Country Association" 필드가 있습니다. 현재 IP만 확인하는 웹 Gemini와 달리, agy CLI 및 Cloud Code API는 이 필드를 엄격하게 확인합니다.

> 계정에 연결된 지역을 확인하거나 변경하려면 [Google Country Association Form](https://policies.google.com/country-association-form)을 방문하세요.

**웹 Gemini는 작동하지만 agy는 작동하지 않는 이유**:

- 웹 Gemini / Google One: 현재 IP만 확인함(프록시로 통과 가능)
- agy CLI / Cloud Code API: 백엔드 Country Association 필드를 읽음(프록시가 도움이 되지 않음)

**해결 방법**:

1. 미국 IP를 사용하는 상태에서 [Google Country Association Form](https://policies.google.com/country-association-form)을 방문합니다.
2. 지역 변경 요청을 제출합니다("I live in a different country" 선택).
3. Google의 처리 및 이메일 알림을 1~24시간 기다립니다.
4. 이후 `agy login`이 정상적으로 완료됩니다.

### 계정에 Cloud Code 프로젝트가 없음

**증상**: 로그에 `loadCodeAssist returned no project id` 및 `onboardUser failed (400)`이 표시됩니다.

**근본 원인**: 해당 계정이 Google Cloud Code에 등록된 적이 없으며 자동 온보딩에 실패했습니다.

**해결 방법**: `agy login`을 수동으로 실행하여 Cloud Code 등록을 시작한 다음, OmniRoute Dashboard에서 토큰을 새로 고칩니다.

### 토큰이 만료되었거나 취소됨

**증상**: 로그에 401 오류 또는 "Token has expired" 메시지가 표시됩니다.

**해결 방법**: Dashboard → Providers → agy에서 새로 고침 아이콘을 클릭하여 토큰을 새로 고칩니다. 새로 고침 토큰 자체가 취소된 경우 OAuth를 통해 다시 인증해야 합니다.

## 결정 흐름도

```
계정이 작동하지 않나요?
│
├─ 데이터베이스에 projectId가 있나요?
│  ├─ 예 → 다른 곳에 문제가 있음(토큰 만료, 요청 한도 초과 등)
│  └─ 아니요 ↓
│
├─ 계정의 국가 연결이 제한된 지역으로 설정되어 있나요?
│  ├─ 예 → Google 국가 연결 양식에서 지역 변경
│  │         (https://policies.google.com/country-association-form)
│  │         1~24시간 기다린 후 다시 시도
│  └─ 아니요 ↓
│
├─ 계정에 Google One AI Pro 구독이 있나요?
│  ├─ 아니요 → 먼저 one.google.com에서 구독
│  └─ 예 ↓
│
├─ 자동 검색 시도(대시보드에서 토큰 새로고침)
│  ├─ 성공 → 완료
│  └─ 여전히 실패 ↓
│
└─ 수동: 해당 머신에서 `agy login` 실행
   ├─ 성공 → 대시보드에서 토큰을 새로고침하면 projectId가 검색됨
   └─ 실패 → 오류 메시지 확인. 지역 또는 구독 문제일 가능성이 높음
```
