## 빠른 제거 (v3.6.2+)

OmniRoute는 깔끔한 제거를 위해 두 가지 기본 제공 스크립트를 제공합니다.

### 데이터 유지

```bash
npm run uninstall
```

이 명령은 OmniRoute 애플리케이션을 제거하지만 `~/.omniroute/`에 있는 데이터베이스, 구성, API 키 및 공급자 설정은 **보존**합니다. 나중에 다시 설치할 계획이며 기존 설정을 유지하려면 이 명령을 사용하세요.

### 완전 제거

```bash
npm run uninstall:full
```

이 명령은 애플리케이션을 제거하고 모든 데이터도 **영구적으로 삭제**합니다.

- 데이터베이스(`storage.sqlite`)
- 공급자 구성 및 API 키
- 백업 파일
- 로그 파일
- `~/.omniroute/` 디렉터리의 모든 파일

> ⚠️ **경고:** `npm run uninstall:full`은 되돌릴 수 없습니다. 모든 공급자 연결, 콤보, API 키 및 사용 기록이 영구적으로 삭제됩니다.

## 수동 제거

### NPM 전역 설치

```bash
# 전역 패키지 제거
npm uninstall -g omniroute

# (선택 사항) 데이터 디렉터리 제거
rm -rf ~/.omniroute
```

### pnpm 전역 설치

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# 컨테이너 중지 및 제거
docker stop omniroute
docker rm omniroute

# 볼륨 제거(모든 데이터 삭제)
docker volume rm omniroute-data

# (선택 사항) 이미지 제거
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# 컨테이너 중지 및 제거
docker compose down

# 볼륨도 함께 제거(모든 데이터 삭제)
docker compose down -v
```

### Electron 데스크톱 앱

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall`을 엽니다.
- 또는 설치 디렉터리에서 NSIS 제거 프로그램을 실행합니다.

**macOS:**

- `/Applications`에서 `OmniRoute.app`을 휴지통으로 드래그합니다.
- 데이터 제거: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage 파일을 제거합니다.
- 데이터 제거: `rm -rf ~/.omniroute`

### 소스 설치(git clone)

```bash
# 복제한 디렉터리 제거
rm -rf /path/to/omniroute

# (선택 사항) 데이터 디렉터리 제거
rm -rf ~/.omniroute
```

## 데이터 디렉터리

OmniRoute는 기본적으로 다음 위치에 데이터를 저장합니다.

| 플랫폼   | 기본 경로                     | 재정의                      |
| -------- | ----------------------------- | --------------------------- |
| Linux    | `~/.omniroute/`               | `DATA_DIR` 환경 변수        |
| macOS    | `~/.omniroute/`               | `DATA_DIR` 환경 변수        |
| Windows  | `%APPDATA%/omniroute/`        | `DATA_DIR` 환경 변수        |
| Docker   | `/app/data/`(마운트된 볼륨)   | `DATA_DIR` 환경 변수        |
| XDG 호환 | `$XDG_CONFIG_HOME/omniroute/` | `XDG_CONFIG_HOME` 환경 변수 |

### 데이터 디렉터리의 파일

| 파일/디렉터리        | 설명                                      |
| -------------------- | ----------------------------------------- |
| `storage.sqlite`     | 기본 데이터베이스(공급자, 콤보, 설정, 키) |
| `storage.sqlite-wal` | SQLite 미리 쓰기 로그(임시)               |
| `storage.sqlite-shm` | SQLite 공유 메모리(임시)                  |
| `call_logs/`         | 요청 페이로드 아카이브                    |
| `backups/`           | 자동 데이터베이스 백업                    |
| `log.txt`            | 레거시 요청 로그(선택 사항)               |

## 완전히 제거되었는지 확인

제거 후 남아 있는 파일이 없는지 확인합니다:

```bash
# 전역 npm 패키지 확인
npm list -g omniroute 2>/dev/null

# 데이터 디렉터리 확인
ls -la ~/.omniroute/ 2>/dev/null

# 실행 중인 프로세스 확인
pgrep -f omniroute
```

아직 실행 중인 프로세스가 있으면 중지합니다:

```bash
pkill -f omniroute
```
