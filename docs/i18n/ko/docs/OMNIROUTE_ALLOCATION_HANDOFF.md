할당은 공급자 할당량이 아닙니다.

할당량 풀은 어떤 API 키가 공급자 풀을 사용할 수 있는지와 하드, 소프트 또는 버스트 정책이 어떻게 적용되는지를 정의합니다. 공급자 할당량은 공급자가 보고하거나 명시적으로 구성된 소스에서 제공하는 외부 용량입니다. Ghostlight 내부 예산은 관리자가 정의한 거버넌스 한도입니다.

`ensurePool` 작업은 멱등성을 보장합니다. 동일한 풀은 변경되지 않고, 변경된 할당은 업데이트되며, 누락된 풀은 생성됩니다. 이는 자동화 및 제한된 API 호출자를 위한 것입니다.

읽기 전용 상태 엔드포인트는 `GET /api/omniroute/status`입니다. 검증 명령은 `npm run omniroute:verify`이며, 라이브 모델 요청을 수행하지 않습니다.
