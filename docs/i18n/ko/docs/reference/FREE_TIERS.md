> **마지막 조사일:** 2026-06-17 — 공급자별 웹 조사(공식 문서 + 최근 7일 뉴스, 적대적 검증을 포함한 50개 에이전트 검토)를 통해 모든 무료 티어 할당량과 이용약관을 갱신했습니다. **2026-09-02 부분 재감사**(`gemini`, `ollama-cloud`, `groq`, `nara`, `mistral` — 아래의 날짜가 명시된 참고 사항 참조).

## TL;DR — OmniRoute가 실제로 집계하는 무료 추론량은 얼마인가?

| 지표                                       | 토큰 / 월     | 의미                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------ | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| **+ 지역 신원 확인 필요**                  | **+~6M**      | `modelscope`(Alibaba Cloud 연동 + 중국 본토 실명 인증). 실제 반복 할당량이며, `gatedRecurringTokens` / `gatedProviders` 및 대시보드에 표시됩니다. 헤드라인 수치에는 절대 합산하지 않습니다. 지역 신원 인증을 거치면 +~6M입니다.                                                                                                 |
| 이론적 상한(모든 요청 속도 제한, 연중무휴) | ~10B          | 모든 제공업체의 요청 속도 제한을 중단 없이 사용한다고 가정해 환산한 합계입니다. **보장된 수치가 아니므로** 헤드라인으로 사용하지 마세요.                                                                                                                                                                                        |

**정직한 헤드라인:** _OmniRoute는 35개의 무료 티어 풀에서 **매월 문서화된 무료 토큰 약 1.62B**를 집계합니다(가입 크레딧을 포함하면 첫 달에는 최대 약 2.22B). 여기에 영구 무료이면서 한도가 없는 여러 제공업체가 추가되며, RTK + Caveman 압축(토큰 15~95% 절감)을 통해 이를 더욱 효율적으로 활용할 수 있습니다._

> **이전의 약 1.94B에서 감소한 이유.** 2026-06-17 갱신은 손실이 아니라 정확성을 위한 정정입니다. 이제 `gemini`는 풀 단위로 중복 제거됩니다(이전에는 각 Flash 변형을 별도로 계산해 462M → 60M으로 과대 산정). `cloudflare-ai`는 실제 일일 10k-Neurons에 맞게 정정되었고(122M → 30M), `doubao`는 반복 제공량이 아닌 일회성 가입 크레딧으로 재분류되었으며, 종료된 티어(`chutes`/`phind`/`kluster`)는 제거되었습니다. 이러한 감소분은 `llm7`(정확한 일일 5M → 150M)과 새로운 무료 제공업체(Kilo, OpenCode Zen, Z.AI GLM-Flash)로 일부 상쇄되었습니다.
>
> **v3.8.42에서 약 1.37B로 추가 정정:** `longcat`의 무료 프리뷰가 종료된 후, 월 150M의 반복 제공량에서 일회성 10M 가입 크레딧으로 재분류되었습니다. 동일한 정직성 원칙에 따른 조정이며, 실수로 누락된 제공업체는 없습니다.
>
> **Felo Web 중단 후 2026-08-26에 갱신:** Felo Web은 GPL 파생 출처/라이선스 문제가 보류(HOLD) 상태인 동안 제외됩니다. 당시 소스에는 38개의 풀 키가 보고되었습니다. 풀 수는 실시간으로 관리되고 CI 검증을 거칩니다(`computeFreeModelTotals()`와 위 수치가 달라지면 `check:docs-counts`가 빌드에 실패합니다).
>
> **2026-09-02에 제공업체의 자체 페이지를 기준으로 재감사**(출처: `open-sse/config/freeModelCatalog.data.ts`에서 재감사된 각 항목 옆의 `// evidence:` 주석): `gemini`와 `ollama-cloud`는 더 이상 토큰 수치를 공개하지 않습니다(Google은 2025-12-23에 모델별 무료 표를 삭제했고, Ollama의 Free 플랜은 "starter usage credits"입니다). 따라서 이제 **무제한**으로 기재되며 절대 합산하지 않습니다(−80M). `groq`에는 각각 200K-TPD 한도가 적용되는 5개의 **모델별** 풀이 있으며(각 6M, +15M), 폐기된 ID 3개는 제거되었습니다. `nara`는 일일 7M의 단일 버킷입니다(+60M, 210M). `mistral`의 1B는 계정 콘솔에서만 확인할 수 있습니다. 자세한 내용은 방법론의 _증거 분류_를 참조하세요.
>
> **2026-09-03에 정정(#11773):** `cerebras`는 월 30M의 반복 제공량(이전의 카드 불필요 일일 1M 토큰 체험)에서 결제 수단이 필요한 일회성 $5 가입 크레딧으로 재분류되었습니다. LongCat과 동일한 정직성 원칙에 따른 조정입니다.
>
> **xKiro 추가(2026-09-03):** 새로운 `xkiro-free` 풀(월 150M)이 35번째 반복 풀 키로 추가되었습니다. Felo Web은 GPL 파생 출처/라이선스 문제가 보류(HOLD) 상태인 동안 계속 제외됩니다. 이제 소스에는 **35개의 반복 풀 키**와 **약 1.62B의 상시 제공량**이 보고됩니다. 이는 실시간으로 관리되고 CI 검증을 거치는 수치입니다(`computeFreeModelTotals()`와 달라지면 `check:docs-counts`가 빌드에 실패합니다).

가장 큰 **문서화된** 기여 항목: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M(모델별 한도 5개), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat`은 제외됩니다. LongCat-2.0의 10M 제공량은 반복되는 월간 예산이 아니라 KYC가 필요한 일회성 가입 크레딧입니다.)

> ⚠️ 이론적 상한선(~10B)은 **공개된 토큰 한도가 없는** 속도 제한 기반 제공업체(`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`)로 인해 부풀려진 수치입니다. 이들의 수치는 `RPM/TPM × 24/7 × 30d`로 계산되며, 이는 단일 계정으로는 지속할 수 없는 이론적 최댓값입니다. 따라서 이들은 근거를 제시할 수 있는 수치에서 **제외**되며(대신 "영구 무료, 한도 없음" 행에 표시됨), 경쟁업체들의 수십억 단위 주장을 신뢰하기 어렵게 만드는 것과 동일한 과장 방식입니다.

## 2026-06-17 갱신 — 2026-06-05 이후 변경 사항

50개 에이전트를 활용한 웹 조사(공식 문서 + 최근 7일간의 뉴스, 적대적 검증 수행)를 통해 전체 카탈로그를 갱신했습니다. 주요 변경 사항:

- **제거됨 / 무료 티어 없음(2026):** `chutes`(무료 티어 2026-03 종료), `phind`(회사 2026-01 폐업), `kluster`(2026-06-09 서비스 종료 → MITO), `gitlawb` + `gitlawb-gmi`(MiMo 무료 제공 2026-05-24 철회, Nemotron 프로모션 2026-06 종료 — 2026-06-18 재검증), `aimlapi`(무료 티어 일시 중단 — 2026-06-18 재검증), `yi`(Yi-Light 사용 종료, 종량제 전환 — 2026-06-18 재검증), `featherless-ai`(현재 무료 티어 없음), `chipotle`(Chipotle의 "Pepper AI" — 제공자가 연결하던 리버스 엔지니어링된 `amelia.chipotle.com` Amelia 채팅 위젯이 루트를 포함한 모든 경로에서 현재 404를 반환함. 백엔드가 폐기되었거나 이전되었으며 2026-09-15 확인 — 카탈로그에서 완전히 제거, #13131/#4037). `iflytek` / `sparkdesk`는 계속 등재되지만 ToS 주의 문구가 표시됩니다(Spark Lite는 무료지만 ToS에서 프록시/릴레이 사용을 제한함).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite`는 2026-06-01에 종료되었고, `2.5 Pro`는 무료 티어에서 제외되었습니다(2026-04). 현재 무료 티어는 **Flash 계열만** 제공합니다(2.5/3/3.1/3.5 Flash + Gemma). 이제 카탈로그에서는 Flash 계열을 **통합 집계**합니다(이전에는 각 변형을 별도로 집계하여 수치가 부풀려졌음: 462M → 60M).
- **수치 수정:** `cloudflare-ai` 122M → **30M**(실제 한도는 일일 10k Neurons), `doubao`는 반복 제공이 아닌 일회성 가입 크레딧으로 재분류, `llm7` 4M → **150M**(문서상 일일 토큰 5M), `together`의 "-Free" 엔드포인트 종료 → $25 가입 크레딧도 제거됨($5 이상 구매 필요, 무료 체험 없음), `longcat` Preview 종료 + Flash 모델 사용 종료 → **LongCat-2.0**만 제공하며, 일회성 **10M** 토큰 가입 크레딧으로 재분류(KYC 필요, 반복 제공 아님).
- **새로 발견된 무료 제공업체:** ⭐ **Kilo Code**(`kilo-gateway` — 순환식 "Auto Free" 모델군: NVIDIA Nemotron 3 계열, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen**(`opencode-zen` — 순환식 무료 코딩 모델 6개), ⭐ **Z.AI / Zhipu**(`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash 영구 무료 + 가입 보너스 20M), 그리고 `arcee-ai` Trinity Large Preview.
- **새로운 투명한 티어**(방법론 참조): _영구 무료이지만 한도 없음_ 범주(실제로 반복 제공되는 액세스이지만 집계할 토큰 한도가 없음)와 _예치금 잠금 해제 부스트_(OpenRouter $10 → 월 +24M)를 추가했습니다. 둘 다 헤드라인 수치를 부풀리지 않도록 **별도로** 표시됩니다.

> 아래의 제공업체별 상세 표는 **2026-06-05 스냅샷**이며, 위의 변경 사항이 해당 내용을 대체합니다. 최신 공식 소스는 모델별 카탈로그인 `open-sse/config/freeModelCatalog.ts`입니다.

## 두 가지 체계 — 집계와 판정

OmniRoute는 의도적으로 서로 다른 소스를 참조하는 두 가지 체계를 통해 "무료인가?"라는 질문에 답합니다.

## 방법론 및 주의사항

- 수치는 웹 조사를 통해 수집한 **2026-06-17** 기준 각 제공업체의 문서화된 무료 티어 한도에 따른 **상한 추정치**입니다. 무료 티어는 수시로 변경되므로, 수치에 의존하기 전에 다시 확인하세요.
- **각 항목이 실제로 보증하는 내용.** 항목별 신뢰도 등급은 없으며 API에서도 이를 제공하지 않습니다. 위의 모든 수치는 명시되지 않은 동일한 품질 수준의 추정치로 간주하세요. 다만 다음 두 가지 사실은 추론된 것이 아니라 수작업으로 선별되었으므로 다릅니다. 44개 항목에는 독립적으로 문서화된 하드 스톱이 있으며(그중 39개는 모두 하나의 일일 허용량을 공유하는 xKiro 행), 13개 항목에는 프롬프트 학습 관련 고지가 있습니다. `hardStopGuaranteed`는 무료 허용량을 초과할 경우 별도 안내 없이 과금을 시작하는 대신 요청을 거부한다고 제공업체 자체 약관에 명시된 경우에만 설정되며, 출처는 해당 항목 옆의 주석에 기재됩니다. 이 값은 기본적으로 `true`로 설정되지 않으며, 아무도 검증하지 않은 항목은 미설정 상태로 유지됩니다. 따라서 하드 스톱 플래그가 없다는 것은 "확인되지 않음"을 의미하며, "과금되는 것으로 확인됨"을 의미하지 않습니다. **STRICT 모드**(옵트인 `freeAccessPolicy=strict` 라우팅 가드)는 이 플래그가 있는 항목만 신뢰합니다. 그 외 모든 무료 티어는 `no-hard-stop`으로 제외됩니다(`open-sse/services/autoCombo/strictZeroCostFilter.ts` 참조).
- `estMonthlyFreeTokens` = 매월 반복 제공되는 토큰만 해당합니다. **일회성 가입 크레딧은 반복 제공되지 않으며** 0으로 계산됩니다. 중단된 티어도 0입니다.
- 일일 토큰 한도 → `monthly = daily × 30`. RPD만 문서화된 경우 → `RPD × ~800 output tokens × 30`. RPM/TPM만 있고 일일 한도가 없는 경우 → **무제한**(아래 참조).
- **영구 무료이지만 공개된 토큰 한도가 없는 경우**(`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): 실제로 반복 제공되는 무료 액세스이며, 속도/동시성 제한이 적용됩니다. 이를 `recurring-uncapped`으로 분류하고 **합계에는 절대 포함하지 않습니다**. `RPM × 24/7 × 30d`를 곱하면 비현실적인 상한이 산출되기 때문입니다(이러한 과장은 배제합니다). 해당 서비스가 존재한다는 사실을 알 수 있도록 목록에는 포함합니다.
- **예치금 잠금 해제 부스트:** 일회성 소액 충전으로 무료 할당량이 영구적으로 증가하는 경우입니다(OpenRouter: $10 → 1000 req/day ≈ +24M/mo). 별도 수치로 보고하며, 지속적 제공량을 나타내는 주요 수치에서는 제외합니다.
- **자격 요건이 적용되는 할당량**(`eligibilityGate: "regional-identity"`): 지역에 종속된 신원 확인(현재는 중국 본토 실명 인증)을 완료한 후에만 제공되는 실제 반복 할당량입니다. 동일한 풀 중복 제거 규칙을 적용해 별도 수치(`gatedRecurringTokens`)에 포함하며, 지속적 제공량을 나타내는 주요 수치에는 절대 포함하지 않습니다. 체계(`freeType`)는 변경되지 않으므로 라우팅도 변경되지 않습니다.
- **근거 분류.** 규칙은 다음과 같습니다. 카탈로그의 수치는 해당 항목 옆의 `// evidence:` 주석에 출처를 명시합니다. 출처 유형은 `public-page`(누구나 열람할 수 있는 제공업체 페이지), `api-public`(인증 없이 접근할 수 있는 제공업체 엔드포인트, 예: router.bynara.id에 있는 NaraRouter의 공개 요금제 엔드포인트), 또는 `console-verified <date> por <who>`(수치가 계정 콘솔 내부에서만 확인 가능하며, 주석에는 이를 확인한 사람과 날짜, 그리고 한도가 존재한다고 명시한 공개 페이지를 기록)입니다. 현재 상태는 다음과 같습니다. 2026-09-02에 재감사한 5개 블록(`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`)에는 이 정보가 포함되어 있습니다. 2026-09-02 재감사 이전의 항목은 수정될 때까지 기존 조사 결과를 그대로 따릅니다. 근거 주석이 없는 **신규 또는 변경된** 수치는 버그입니다. 현재 `console-verified`로 분류된 것은 `mistral`뿐입니다.

## 당사의 수치가 다른 애그리게이터보다 작은 이유

이 분야의 대부분의 "월간 무료 토큰" 수치는 모델별로 표시된 값을 합산한 것입니다. 당사는 의도적으로 그렇게 계산하지 않습니다.

- **각 공유 풀은 한 번만 계산합니다.** Mistral의 무료 플랜은 조직당 월 1B의 단일 할당량입니다. 이를 5개 모델 아래에 나열한다고 해서 5B가 되지는 않습니다. 모델별로 합산하면 당사 카탈로그도 **~7.4B**로 표시될 수 있습니다(2026-09-03에 재계산됨. 이 수치는 CI로 검증되지 않으므로 카탈로그가 변경될 때마다 다시 측정해야 합니다). 하지만 각 제공업체의 계정 하나로 실제 사용할 수 있는 양은 **~1.47B**이므로 헤드라인에는 이 수치를 표시합니다.
- **일일 한도는 환산하지만, 속도 제한은 환산하지 않습니다.** 문서화된 일일 토큰 한도는 `× 30`으로 환산하고, 문서화된 일일 요청 한도는 `RPD × ~800 tokens × 30`으로 환산합니다. 분당 요청 수만 공개하는 제공업체에는 월간 수치를 부여하지 않고 _무제한_으로 표시하며, 합산에도 포함하지 않습니다. 속도 제한에 24/7을 곱해 수치를 부풀리는 방식은 사용하지 않습니다.
- **지역 신원 확인이 필요한 할당량은 별도로 표시합니다** (`+지역 신원 확인 시 ~6M`). 대부분의 독자는 이를 사용할 수 없기 때문입니다.
- **가입 크레딧은 첫 달에만 적용되며**, 지속적으로 제공되는 수치에 섞지 않고 두 번째 수치로 별도 보고합니다.
- **이 수치는 CI로 검증됩니다.** `npm run check:docs-counts`는 카탈로그에서 총합을 다시 계산하며, 이 파일이나 README 또는 예산 카드의 수치가 카탈로그와 달라지면 빌드에 실패합니다.

## ToS 주의 사항 표

> **ToS 플래그는 참고용이며 라우팅을 차단하지 않습니다.** `tos`로 표시된 제공업체도 기본적으로 라우팅 및 조합/폴백에 포함됩니다. 이 플래그는 `/dashboard/free-tiers` 및 `/api/free-tier/summary`에만 표시됩니다. `excludeTosAvoid` 쿼리 매개변수는 요약 보기에만 영향을 주며 전역 라우팅에는 영향을 주지 않습니다. 판정 정보는 `open-sse/config/freeTierCatalog.ts`에 있습니다(참고용이며 라우팅 엔진에서는 읽지 않음).

> 자체 호스팅되는 단일 사용자용 개인 프록시와 관련된 각 제공업체의 약관을 간략히 검토한 내용입니다. `caution` = 확인할 필요가 있는 개인적 사용 또는 프록시 관련 조항, `ambiguous` = 불명확함, `ok` = 명시적으로 허용됨. 참고용 정보이며 법률 자문이 아닙니다. 판단은 본인이 내려야 합니다.
