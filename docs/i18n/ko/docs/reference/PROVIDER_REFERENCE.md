## 카테고리

- **무료** — API 키를 사용하는 무료 요금제(대시보드에서 구성)
- **인증 없음** — 키나 로그인이 전혀 필요하지 않은 공개 엔드포인트
- **OAuth** — OmniRoute에서 처리하는 로그인 흐름으로, API 키가 필요 없음
- **웹 쿠키** — 쿠키 인증을 통해 제공자의 웹 앱을 래핑
- **API 키** — API 키로 구성하는 유료 제공자(무료 크레딧이 제공될 수 있음)
- **로컬** — 사용자의 컴퓨터에서 실행(Ollama, LM Studio, vLLM 등)
- **검색** — 웹 검색 제공자
- **오디오** — 오디오 전용 제공자(TTS/STT)
- **업스트림 프록시** — 다른 제공자로 요청을 프록시하는 제공자
- **클라우드 에이전트** — 장시간 실행되는 코딩 에이전트(Codex Cloud, Devin, Jules)
- **시스템** — OmniRoute 내부 제공자(루프백 등)

추가 태그: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`도구 호출`(표시되는 경우): `native` — 실제 함수 호출 API, `emulated` — `tools` 배열이 `webTools.ts`를 통해 프롬프트로 에뮬레이션됨(정규식으로 파싱되는 `<tool>{...}</tool>` 블록), `none` — 현재 `tools`가 아무 알림 없이 삭제됨. #7286을 참조하세요.

`/dashboard/providers`의 대시보드를 사용하여 각 제공자를 활성화하고 구성하고 테스트하세요.
