OmniRoute는 외부 제공업체(1proxy, proxifly, iplocate, webshare)에서 동기화된 엄선된 무료 프록시 풀을 `free_proxies` 테이블로 제공합니다.
대시보드에서는 **Settings → Free Proxies** 아래에 이러한 프록시가 표시됩니다. 이 문서에서는
목록 라우트가 제공하는 서버 측 필터링, 정렬, 집계 및 동기화 오류 보고를
다룹니다.

## 목록 라우트 — `GET /api/settings/free-proxies`

필터링 및 정렬되고 페이지네이션된 일부 데이터와 전체 개수를 반환합니다. 필터링과
집계는 SQL에서 수행되므로, UI는 모든 행을 메모리에 로드하지 않고도 실제 전체 개수(예: `Total: 0`)를
표시할 수 있습니다.

### 쿼리 매개변수

| 매개변수          | 타입                               | 기본값    | 의미                                                                                                                 |
| ----------------- | ---------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `search`          | 문자열                             | `""`      | 호스트(및 소스) 열에 대해 대소문자를 구분하는 `LIKE` 검색을 수행합니다.                                              |
| `protocol`        | 문자열                             | `""`      | `type` 필터: `http` / `https` / `socks4` / `socks5`. 비어 있으면 모두 포함합니다.                                    |
| `country`         | 문자열                             | `""`      | `countryCode` 필터(ISO-2). 비어 있으면 모두 포함합니다.                                                              |
| `minQuality`      | 숫자                               | `0`       | `qualityScore >= minQuality`인 행만 포함합니다. `0`이면 최솟값을 적용하지 않습니다.                                  |
| `disabledSources` | 문자열                             | `""`      | 제외할 소스 ID를 쉼표로 구분한 목록입니다(예: `proxifly,webshare`).                                                  |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = 점수 내림차순, `latency` = 지연 시간 오름차순(null은 마지막), `recent` = `lastValidated` 내림차순입니다. |
| `offset`          | 숫자                               | `0`       | 페이지네이션 시작 위치입니다.                                                                                        |
| `limit`           | 숫자                               | `50`      | 페이지 크기입니다(서버 측에서 상한이 적용됨).                                                                        |

### 응답

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total`은 페이지네이션을 적용하기 **전**의 필터링된 전체 개수를 나타내므로, UI는
`Total: N`과 `hasMore`를 독립적으로 렌더링할 수 있습니다. `syncErrors`는 소스 ID를 키로 사용하며,
마지막 동기화에 실패한 소스에 대해서만 채워집니다. 따라서 `Total: 0` 결과가
아무런 설명 없이 표시되는 일은 없습니다.

## 풀에 추가 — `POST /api/settings/free-proxies/[id]/add-to-pool`

무료 프록시를 관리형 `proxy_registry` 풀로 승격합니다. 먼저
업스트림을 검증하며, 성공하면 새 풀 프록시 ID와 측정된 지연 시간을 반환합니다.

## 동기화 — `POST /api/settings/free-proxies/sync`

활성화된 모든 소스(또는 `{ "sources": [...] }`에 지정된 소스)를 다시 가져옵니다. 각
소스는 독립적으로 동기화됩니다. 실패한 소스는 `syncErrors`에 기록되고
나머지 소스는 계속 완료되므로, 부분 동기화로 인해 기존의 정상 데이터가 삭제되는 일은 없습니다.

## 통계 — `GET /api/settings/free-proxies/stats`

행 페이로드 없이 `total / inPool / avgQuality / bySource / lastSyncAt` 집계 정보를
반환합니다. 대시보드 헤더 위젯에서 사용됩니다.
