## 1. 서비스 기준 정보(공식 문서, 교차 확인 완료)

- 기본 URL: `https://api.anysearch.com`(REST) + `POST /mcp`(MCP, JSON-RPC 2.0).
- `POST /v1/search` - 매개변수: `query`(필수), `max_results`(1~10, 기본값 10), `tag`(`{domain}.{sub_domain}` 버티컬 라우팅), `zone`(cn/intl), `language`, `params`(구조화된 버티컬 필드), `format`(json/markdown).
- `GET /v1/sub-domains?domain=...` - 기능 카탈로그이며, 할당량에 포함되지 않음.
- `POST /v1/extract` - `{url, title, content}` 가져오기/추출. 엄격한 JSON 본문, 16 KiB 제한.
- `POST /v1/auth/email/register` - 단일 호출 등록이며, 일회성 평문 키 `as_sk_...`를 반환.
- 인증: 선택적 `Authorization: Bearer <as_sk_...>`. 익명 사용 시 일일 무료 할당량을 소모하는 IP별 제한으로 성능이 저하됨. 유효하지 않은 키는 조용한 익명 폴백 없이 401/403을 반환.
- 무료 티어: 하루 1000개 요청, 키당 20 QPS. 유료 티어: 가격 미정(출시 예정).
- 응답 엔벨로프: 성공 `{code: 0, message: "success", request_id, data}`, 실패 `{code: -1, message}`. 인증/할당량 오류에는 구조화된 `error_code`가 없으며(메시지 텍스트가 신호 역할을 함), 추출 관련 오류에는 `error_code`(`invalid_extract_url`, `extract_failed`)가 포함됨. 429 응답에는 `Retry-After` 헤더가 없음.

## 3. 결정 사항 (모두 2026-08-26에 확정)

1. **라우팅 방침: `fallbackOnly`.** 근거: 비용이 0인 무료 제공자가 자동 비용 기반 라우팅을 절대 지배해서는 안 되며, 명시적 선택과 장애 조치 후 복귀에는 영향을 주지 않는다. 선례: 병합된 xquik 항목.
2. **범위: v1에서 `POST /v1/extract`를 통한 webSearch + webFetch.** tavily/exa의 이중 기능 멘탈 모델에 부합한다. 수직형 기능 영역(`tag`, `sub-domains`, `batch_search`)은 범위에서 제외한다. 현재 수직형 매개변수를 위한 IR이 없기 때문이다.
3. **할당량 표시: `freeMonthlyQuota: 0`**(xquik 방식의 보수적 표시). 실제 허용량(일일 요청 1000건, 매일 초기화)은 대신 UI 카탈로그의 `authHint` 문구에 명시한다. 근거: 할당량 표시는 초기화 주기와 일치해야 하며, 일일 한도를 월간 환산치(30000)로 변환하면 UI가 보장할 수 없는 잘못된 약속이 된다.
4. **searchTypes: `["web"]`만 지원.** AnySearch API에 뉴스/이미지 수직형 검색이 있다는 공개 근거가 없다. 문서화된 수직형 검색 없이 API를 통합하는 게이트웨이(예: Google Custom Search)는 news를 web으로 조용히 매핑하지 않고 web만 노출한다.
5. **키 방침:** 키 없이도 작동한다. 유효하지 않은 키는 401/403을 반환하며, 익명 방식으로 조용히 다운그레이드되지 않는다(업스트림 계약과 동일).
6. **의도적인 제외 사항:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend`(채팅 인터셉션은 계속 firecrawl/jina/tavily 사용), `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS`(익명 원격 엔드포인트는 송신 IP별로 하나의 IP 제한 풀을 공유하므로, 키 없는 extract는 선택적으로 사용해야 하며 자동 라우팅 후보가 아님), `QUOTA_STATUS_PROVIDERS`(AnySearch는 402/403 상태가 아니라 429/엔벌로프를 통해 할당량을 알림).
