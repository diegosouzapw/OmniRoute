1. 기존 단일 키 세마포어 계약과 새로운 원자적 다중 키 계약을 집중 테스트로 고정합니다: 부분 예약 없음, FIFO 큐잉, 중단, 타임아웃, 큐 가득 참, 멱등적 해제, 통계, 정리.
2. 기존 계정 세마포어를 제자리에서 일반화합니다. `acquire()`는 `acquireMany()`를 감싸는 호환성 래퍼로 유지하고, 두 번째 스케줄러나 종속성을 추가하지 않습니다.
3. `chatCore`의 계정 전용 획득을 `withRateLimit` 직전에 수행되는 하나의 누적된 전역/제공자/계정 획득으로 교체합니다. 계정 순환으로 연결이 변경될 때마다 전체 세트를 다시 획득하고, 스트리밍이 완료될 때까지 해제를 유지합니다.
4. 기존 복원력 설정 파이프라인(타입, 기본값, 정규화, 스키마, API 응답, UI, 번역)에 전역 및 제공자 상한을 추가합니다. 기존 Bottleneck 동시성 제어의 실제 범위가 명확히 드러나도록 연결/할당량 범위 동시성으로 레이블을 변경합니다.
5. 집중 테스트, 린트, 타입 검사, 정적 검사 및 전체 테스트 스위트를 실행하고, 동작 변경 사항을 변경 로그에 문서화합니다.

의도적으로 유지되는 동작: 0/null 동시성은 게이트를 우회하고, 계정 전용 호출자는 계속 `acquire()`를 사용하며, 차단된 계정 제어는 기존 키 형식과 API를 유지하고, 제공자 속도 제한 큐 동작은 변경되지 않습니다.
