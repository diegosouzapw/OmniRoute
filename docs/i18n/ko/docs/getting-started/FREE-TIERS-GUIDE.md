## 무료 티어란 무엇인가요?

많은 AI 제공업체가 어떤 형태로든 **무료 액세스**를 제공합니다. 제공업체에 따라 인증이 필요 없는 엔드포인트, 반복적으로 갱신되는 할당량, 사용량 제한은 없지만 요청 속도가 제한된 액세스, 가입 시 제공되는 크레딧, 수동 승인 또는 한시적 프로모션을 의미할 수 있습니다. 일부 옵션을 이용하려면 계정, API 키, 신용카드, KYC 또는 제공업체별 약관 동의가 필요합니다.

OmniRoute는 구성된 연결을 하나의 엔드포인트로 **통합**합니다. 계정이 필요한 각 제공업체에는 여전히 별도로 가입해야 합니다. 해당 계정을 연결하고 `model: "auto"`를 사용하면 이용 가능한 대상 간에 요청을 라우팅할 수 있습니다. 새로 설치한 환경에는 키 없이 이용 가능한 대상이 없을 수 있으며, OmniRoute를 설치하는 것만으로 채팅 응답이 성공적으로 반환되는 것은 아닙니다.

## 무료 티어를 중첩하는 방법

OmniRoute의 핵심은 **무료 티어 중첩**입니다. 하나의 제공업체에 의존하는 대신 여러 무료 제공업체를 연결하면, OmniRoute가 각 요청에 가장 적합한 제공업체를 자동으로 선택합니다.

### 예시: 더 폭넓은 무료 티어 활용

단일 할당량에 대한 의존도를 줄이려면 여러 제공업체를 연결하세요.

1. **Gemini** — 주기적으로 갱신되는 API 키 할당량
2. **Groq** — 주기적으로 갱신되는 API 키 할당량
3. **Pollinations** — 키 없이 이용 가능한, 사용량 제한이 적용된 액세스
4. **LongCat** — 가입 시 한 번 제공되는 크레딧(KYC 필요)

그런 다음 `model: "auto"`를 사용하면 OmniRoute는 다음과 같이 작동합니다.

- 사용 가능한 연결 중 우선순위가 가장 높은 연결을 먼저 시도합니다.
- 해당 연결의 할당량이 소진되었거나 상태 확인에 실패하면 → 다음으로 구성된 제공업체를 시도합니다.
- 키가 필요 없는 제공업체를 이용할 수 없으면 → 나머지 대상으로 계속 진행합니다.
- 사용 가능한 연결이 모두 실패하면 → 오류를 반환합니다. 가입 크레딧은 유효하며 사용 가능한 동안에만 이용할 수 있습니다.

**결과**: 자동 대체 기능을 통해 무료 티어를 더 폭넓게 활용할 수 있지만, 무제한 용량을 보장하지는 않습니다.

## 무료 제공업체 연결 방법

### 1단계: 대시보드 열기

브라우저에서 `http://localhost:20128`로 이동합니다.

### 2단계: 제공업체로 이동

사이드바에서 **제공업체**를 클릭합니다.

### 3단계: 제공업체 추가 클릭

**+ 제공업체 추가** 버튼을 클릭합니다.

### 4단계: 무료 제공업체 선택

카탈로그를 탐색하고 각 제공업체의 현재 `hasFree`, 인증, 할당량, 개인정보 보호 및
서비스 약관(ToS) 메타데이터를 확인합니다. 제공업체 카드와
[무료 티어 참고 자료](../reference/FREE_TIERS.md)에서는 정기적으로 갱신되는 할당량,
무제한/키 없는 액세스, 가입 크레딧, 중단된 항목 및 위험도가 더 높은 소스를 구분합니다.

### 5단계: 연결 클릭

`NOAUTH` 제공업체의 경우 OmniRoute는 업스트림 자격 증명을 요청하지 않습니다. 그렇다고 해서 업스트림이 타사 클라이언트를 허용하거나 사용 가능한 용량을 보유하고 있다는 보장은 없습니다. OAuth 및 API 키 제공업체는 해당 업체에서 안내하는 계정 절차를 통해 연결해야 합니다. 라우터 인증이 활성화된 경우에도 클라이언트는 **대시보드 → 엔드포인트**에 표시된 OmniRoute API 키를 사용합니다.

### 6단계: 반복

약관과 개인정보 보호 모델이 사용 사례에 적합한 여러 제공업체를 연결합니다.

## 카탈로그를 올바르게 읽는 방법

- `NOAUTH`는 OmniRoute가 제공업체 자격 증명을 요구하지 않는다는 의미이며, 가동 시간, 개인정보 보호 또는 무제한 용량을 보장하지는 않습니다.
- `hasFree`는 검색용 메타데이터입니다. 반복 제공되는 할당량, 키 없는 액세스, 가입 크레딧, 승인 프로그램 또는 프로모션을 나타낼 수 있습니다.
- `recurring-uncapped`는 공개된 토큰 상한을 확인할 수 없다는 의미이며, 속도 및 동시성 제한은 여전히 적용됩니다.
- `one-time-initial`은 가입 시 제공된 할당량을 모두 사용한 후에는 다시 제공되지 않습니다.
- `tos: avoid` 제공업체는 기본적으로 자동 라우팅에서 제외됩니다(`excludeTosAvoid`). 계정을 연결해도 이 필터를 우회하지 않습니다. 운영자가 이를 재정의하려면 먼저 제공업체 약관과 계정 위험을 검토해야 합니다.
- `discontinued`로 표시된 항목은 과거 기록으로 유지되며, 현재 무료인 것으로 안내해서는 안 됩니다.

## OmniRoute가 무료 티어의 활용도를 높이는 방법

### 1. 자동 대체

한 무료 제공업체가 혼잡하거나 중단되면 OmniRoute가 자동으로 다음 제공업체를 시도합니다. 별도로 수행할 작업은 없습니다.

### 2. 스마트 라우팅

OmniRoute는 다음 요소를 기준으로 각 요청에 **가장 적합한 무료 제공업체**를 선택합니다.

- 속도 — 현재 가장 빠른 제공업체는 어디인가?
- 품질 — 이 작업에 가장 적합한 제공업체는 어디인가?
- 용량 — 할당량이 남아 있는 제공업체는 어디인가?

### 3. 토큰 절약

OmniRoute의 압축 파이프라인은 압축 가능한 프롬프트 및 도구 출력 토큰을 줄일 수 있습니다.
실제 절감량은 콘텐츠, 선택한 엔진, 제공업체의 사용량 계산 방식, 충실도 설정에 따라 달라지며,
압축을 사용한다고 해서 모든 제공업체의 할당량이 일정한 배수로 늘어나는 것은 아닙니다.

### 4. 다중 계정 지원

제공업체 약관에서 여러 계정 또는 자격 증명을 허용하는 경우, OmniRoute는 각
연결을 별도의 라우팅 후보로 처리할 수 있습니다. 제공업체의 할당량 또는 액세스 정책을
우회하기 위해 추가 계정을 생성해서는 안 됩니다.

## 무료 티어 계산

현재 라이브 풀 중복 제거 카탈로그에 따르면 다음과 같습니다.

| 지표                            |     현재 감사된 값 | 해석                                                        |
| ------------------------------- | -----------------: | ----------------------------------------------------------- |
| 반복적으로 제공되는 정량 할당량 | **월 ~1.62B 토큰** | 공유 풀은 한 번만 계산하며, 무제한 제공자는 합계에서 제외함 |
| 가입 할당량이 포함된 첫 달      |    **~2.22B 토큰** | 반복 합계에 일회성 및 반복 크레딧을 더한 값                 |

이는 서로 독립된 적격 계정 전체에 대한 카탈로그 수준의 추정치이며, OmniRoute에서 제공하는 할당량이나 새로 설치했을 때의 예측치가 아닙니다. 실제로 사용할 수 있는 용량은 연결한 제공자와 해당 제공자의 현재 조건에 따라 달라집니다. 이 값은 `open-sse/config/freeModelCatalog.ts`에서 계산됩니다. 풀 중복 제거, ToS 플래그,
중단된 항목 및 가입 크레딧 산정 방법론은
[무료 티어 참고 자료](../reference/FREE_TIERS.md)를 참조하세요.

## 자주 묻는 질문

### "정말 무료인가요?"

카탈로그에는 제공업체가 공개한 약관과 프로젝트 조사 결과가 기록되어 있지만, 혜택은 변경될 수 있습니다.
사용하기 전에 제공업체의 현재 가격, 할당량, 개인정보 처리방침 및 자격 요건을 확인하세요.

### "무료 티어 할당량이 소진될 수 있나요?"

모든 제공업체는 사용량을 제한하거나, 모델을 변경하거나, 액세스를 중단하거나, 오프라인 상태가 될 수 있습니다. 여러
연결을 사용하면 대체 경로의 범위가 넓어지지만 사용 가능한 무료 경로를 보장하지는 않습니다.

### "무료 제공업체를 프로덕션 환경에서 사용할 수 있나요?"

제공업체의 SLA, 데이터 처리 방식, 제한 및 약관이 프로덕션
요구사항을 충족하는 경우에만 가능합니다. 중요 워크로드에는 모니터링되며 계약상 적합한 대체 경로가 있어야 합니다.

### "어떤 대가가 있나요?"

엄격한 제한, 대기자 명단, KYC, 신용카드 인증, 프롬프트를 이용한
학습, 취약한 개인정보 보호, SLA 부재, 잦은 모델 변경, 지역 제한, 유료 초과 사용 또는
계정 정책 관련 위험 등의 상충 요소가 있을 수 있습니다. OmniRoute는 사용 가능한 메타데이터를 표시하며, 활성화할 항목은 사용자가 선택합니다.

### "무료 할당량을 늘리려면 어떻게 해야 하나요?"

1. 더 많은 무료 제공업체 연결
2. 적절한 압축 엔진을 활성화하고 워크로드의 절감 효과 측정
3. `auto/cheap`을 사용하여 무료/저가 제공업체 우선 선택
4. 제공업체 약관을 위반하지 않는 범위에서 추가로 허용된 제공업체 또는 자격 증명 추가

### "무료 제공업체는 품질이 더 낮나요?"

반드시 그렇지는 않습니다. 일부 제공업체는 유료
경로에서 이용 가능한 것과 동일한 모델 제품군을 제공하지만, 제한, 지연 시간, 개인정보 보호, 안정성 및 모델 버전은 다를 수 있습니다.
무료 제공업체 순위 페이지를 품질 지표로 활용하고 실제로 제공되는 모델을 확인하세요.
