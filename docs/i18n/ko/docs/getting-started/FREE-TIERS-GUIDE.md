## 무료 티어란 무엇인가요?

많은 AI 공급자가 일정한 형태의 **무료 액세스**를 제공합니다. 공급자에 따라 인증이 필요 없는 엔드포인트, 반복 갱신되는 할당량, 사용량 제한은 없지만 요청 속도가 제한되는 액세스, 가입 보너스, 수동 승인 또는 한시적 프로모션의 형태일 수 있습니다. 일부 옵션은 계정, API 키, 신용카드, KYC 또는 공급자별 약관 동의를 요구합니다.

OmniRoute는 이러한 무료 티어를 하나의 엔드포인트로 **통합**합니다. 10개의 서로 다른 서비스에 각각 가입하는 대신, 모든 서비스를 OmniRoute에 연결하고 `model: "auto"`를 사용하여 각 요청에 가장 적합한 무료 옵션을 자동으로 선택할 수 있습니다.

## 무료 티어를 중첩하는 방법

OmniRoute의 핵심은 **무료 티어 중첩**입니다. 하나의 제공업체에만 의존하는 대신 여러 무료 제공업체를 연결하면, OmniRoute가 각 요청에 가장 적합한 제공업체를 자동으로 선택합니다.

### 예시: 더 폭넓은 무료 티어 범위

단일 할당량에 대한 의존도를 낮추려면 여러 제공업체를 연결하세요.

1. **Gemini** — 주기적으로 갱신되는 API 키 할당량
2. **Groq** — 주기적으로 갱신되는 API 키 할당량
3. **Pollinations** — 키 없이 이용할 수 있으며 속도 제한이 적용되는 액세스
4. **LongCat** — 가입 시 한 번만 제공되는 혜택(KYC 필요)

그런 다음 `model: "auto"`를 사용하면 OmniRoute는 다음과 같이 작동합니다.

- 사용 가능한 연결 중 순위가 가장 높은 연결을 먼저 시도
- 해당 연결의 할당량이 소진되었거나 상태 확인에 실패한 경우 → 구성된 다음 제공업체를 시도
- 키 없는 제공업체를 사용할 수 없는 경우 → 나머지 대상으로 계속 진행
- 모두 실패한 경우 → LongCat을 백업으로 사용

**결과**: 자동 대체 기능을 통해 무료 티어를 더 폭넓게 활용할 수 있지만, 무제한 용량이 보장되는 것은 아닙니다.

## 무료 제공업체를 연결하는 방법

### 1단계: 대시보드 열기

브라우저에서 `http://localhost:20128`로 이동합니다.

### 2단계: 제공업체로 이동

사이드바에서 **제공업체**를 클릭합니다.

### 3단계: 제공업체 추가 클릭

**+ 제공업체 추가** 버튼을 클릭합니다.

### 4단계: 무료 제공업체 선택

카탈로그를 탐색하고 각 제공업체의 현재 `hasFree`, 인증, 할당량, 개인정보 보호,
서비스 약관 메타데이터를 확인합니다. 제공업체 카드와
[무료 티어 참고 자료](../reference/FREE_TIERS.md)에서는 주기적으로 갱신되는 풀,
상한이 없거나 키가 필요 없는 액세스, 가입 크레딧, 중단된 항목, 위험도가 높은 소스를 구분합니다.

### 5단계: 연결 클릭

`NOAUTH` 제공업체에는 자격 증명이 필요하지 않습니다. OAuth 및 API 키 제공업체는
문서화된 계정 절차를 통해 연결해야 합니다.

### 6단계: 반복

이용 약관과 개인정보 보호 모델이 사용 사례에 적합한 제공업체를 여러 개 연결합니다.

## 카탈로그를 올바르게 읽는 방법

- `NOAUTH`는 OmniRoute가 제공업체 자격 증명을 요청하지 않는다는 의미이며,
  가동 시간, 개인정보 보호 또는 무제한 용량을 보장하지는 않습니다.
- `hasFree`는 검색용 메타데이터입니다. 주기적으로 갱신되는 할당량, 키 없는 액세스,
  가입 크레딧, 승인 프로그램 또는 프로모션을 나타낼 수 있습니다.
- `recurring-uncapped`는 공개된 토큰 상한을 확인할 수 없다는 의미이며, 요청 속도와
  동시 실행 수 제한은 여전히 적용됩니다.
- `one-time-initial`은 가입 시 제공된 혜택을 소진한 후에는 갱신되지 않습니다.
- `tos: avoid`는 사용 전에 제공업체 약관과 계정 위험을 검토해야 한다는 경고입니다.
- `discontinued`로 표시된 항목은 과거 기록으로 유지되며, 현재 무료로 제공되는 것처럼
  안내해서는 안 됩니다.

## OmniRoute가 무료 티어의 활용도를 높이는 방법

### 1. 자동 대체

한 무료 제공업체가 혼잡하거나 중단되면 OmniRoute가 자동으로 다음 제공업체를 시도합니다. 별도로 수행할 작업은 없습니다.

### 2. 스마트 라우팅

OmniRoute는 다음 요소를 기준으로 각 요청에 **가장 적합한 무료 제공업체**를 선택합니다.

- 속도 — 현재 가장 빠른 제공업체는 어디인가?
- 품질 — 이 작업에 가장 적합한 제공업체는 어디인가?
- 용량 — 할당량이 남아 있는 제공업체는 어디인가?

### 3. 토큰 절약

OmniRoute의 압축 파이프라인은 압축 가능한 프롬프트 및 도구 출력 토큰을 줄일 수 있습니다.
실제 절감량은 콘텐츠, 선택한 엔진, 제공업체의 사용량 계산 방식, 충실도 설정에 따라 달라지며,
압축을 사용한다고 해서 모든 제공업체의 할당량이 일정한 배수로 늘어나는 것은 아닙니다.

### 4. 다중 계정 지원

제공업체 약관에서 여러 계정 또는 자격 증명을 허용하는 경우, OmniRoute는 각
연결을 별도의 라우팅 후보로 처리할 수 있습니다. 제공업체의 할당량 또는 액세스 정책을
우회하기 위해 추가 계정을 생성해서는 안 됩니다.

## 자주 묻는 질문

### "정말 무료인가요?"

카탈로그에는 제공업체가 공개한 약관과 프로젝트 조사 결과가 기록되어 있지만, 혜택은 변경될 수 있습니다.
사용하기 전에 제공업체의 현재 가격, 할당량, 개인정보 처리방침 및 자격 요건을 확인하세요.

### "무료 티어 할당량이 소진될 수 있나요?"

모든 제공업체는 사용량을 제한하거나, 모델을 변경하거나, 액세스를 중단하거나, 오프라인 상태가 될 수 있습니다. 여러
연결을 사용하면 대체 경로의 범위가 넓어지지만 사용 가능한 무료 경로를 보장하지는 않습니다.

### "무료 제공업체를 프로덕션 환경에서 사용할 수 있나요?"

제공업체의 SLA, 데이터 처리 방식, 제한 및 약관이 프로덕션
요구사항을 충족하는 경우에만 가능합니다. 중요 워크로드에는 모니터링되며 계약상 적합한 대체 경로가 있어야 합니다.

### "어떤 대가가 있나요?"

엄격한 제한, 대기자 명단, KYC, 신용카드 인증, 프롬프트를 이용한
학습, 취약한 개인정보 보호, SLA 부재, 잦은 모델 변경, 지역 제한, 유료 초과 사용 또는
계정 정책 관련 위험 등의 상충 요소가 있을 수 있습니다. OmniRoute는 사용 가능한 메타데이터를 표시하며, 활성화할 항목은 사용자가 선택합니다.

### "무료 할당량을 늘리려면 어떻게 해야 하나요?"

1. 더 많은 무료 제공업체 연결
2. 적절한 압축 엔진을 활성화하고 워크로드의 절감 효과 측정
3. `auto/cheap`을 사용하여 무료/저가 제공업체 우선 선택
4. 제공업체 약관을 위반하지 않는 범위에서 추가로 허용된 제공업체 또는 자격 증명 추가

### "무료 제공업체는 품질이 더 낮나요?"

반드시 그렇지는 않습니다. 일부 제공업체는 유료
경로에서 이용 가능한 것과 동일한 모델 제품군을 제공하지만, 제한, 지연 시간, 개인정보 보호, 안정성 및 모델 버전은 다를 수 있습니다.
무료 제공업체 순위 페이지를 품질 지표로 활용하고 실제로 제공되는 모델을 확인하세요.
