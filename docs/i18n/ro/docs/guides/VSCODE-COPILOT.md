**OmniCopilot** adaugă fiecare model furnizat de OmniRoute în selectorul de modele _nativ_ din GitHub Copilot Chat.
Fără o a doua bară laterală, fără o interfață de chat separată — modul agent al Copilot, apelarea instrumentelor,
serverele MCP și instrucțiunile personalizate continuă să funcționeze, doar că rulează pe modelul ales de dvs.

|                          |                                                                                                                                                 |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Instalare (VS Code)**  | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Instalare (fork-uri)** | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Sursă / probleme**     | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Necesită**             | VS Code 1.104+                                                                                                                                  |

> **Nu este necesar un abonament Copilot.** Începând cu VS Code 1.122, un furnizor de modele lingvistice funcționează
> fără autentificare GitHub și fără niciun plan Copilot. Completările inline și
> funcționalitățile bazate pe înglobări nu fac parte din API-ul furnizorului și necesită în continuare Copilot.

## Configurare

1. **Rulați OmniRoute** — `npm install -g omniroute && omniroute` (panoul de control la `http://localhost:20128`).
2. **Instalați extensia** — căutați „OmniRoute” în vizualizarea Extensions.
3. **Alegeți un model** — Copilot Chat → selectorul de modele → **Manage Models…** → **OmniRoute**, apoi bifați
   modelele dorite.

Nu trebuie configurat nimic atunci când OmniRoute rulează pe portul implicit. Pentru o instanță la distanță, deschideți
**pictograma OmniRoute din Activity Bar** (sau rulați `OmniRoute: Manage Connection`) și setați:

- **URL-ul serverului** — rădăcina serverului, de exemplu `http://192.168.0.15:20128`. Sufixul `/v1` este
  adăugat de extensie; nu îl includeți.
- **Cheia API** — doar atunci când serverul setează `REQUIRE_API_KEY`. Este stocată în seiful de chei al sistemului de operare prin
  VS Code SecretStorage, niciodată în `settings.json`.

## Ce va afișa selectorul

Extensia nu afișează răspunsul brut `GET /v1/models` — îl prelucrează, iar numărul pe care îl
vedeți este mai mic decât dimensiunea catalogului din două motive deliberate.

### Solicită un singur id pentru fiecare model

Valoarea implicită a `MODELS_CATALOG_PREFIX_MODE` este **`dual`**, ceea ce face ca fiecare model să fie publicat de două ori — o dată
cu prefixul scurt al aliasului și o dată cu prefixul canonic al furnizorului — astfel încât configurațiile
clienților mai vechi să poată rezolva în continuare ambele forme:

```
cc/claude-sonnet-4-6        ← prefix alias
claude/claude-sonnet-4-6    ← prefix canonic, același model
```

Extensia solicită **`GET /v1/models?prefix=alias`**, astfel încât să fie returnat un singur id pentru fiecare model, fără
a modifica setarea globală a serverului pentru ceilalți clienți. Pe o instanță de referință, aceasta a redus
**2345 de intrări la 1396 — 949 de duplicate, zero modele pierdute.**

Dacă preferați să remediați situația la nivel de server pentru _fiecare_ client, setați indicatorul de funcționalitate
`MODELS_CATALOG_PREFIX_MODE` la `alias` în panoul de control. Consultați
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) pentru
parametrul de interogare și tabelul aferent fiecărui mod.

### Ascunde modelele care nu pot fi folosite pentru chat

Catalogul include și modele pentru imagini, video, audio, reranking, înglobări și moderare. Oricum, acestea sunt
respinse la o solicitare de chat:

```
HTTP 400 — Model '<id>' is an image-generation model and cannot be used on
/v1/chat/completions. Use POST /v1/images/generations instead.
```

prin urmare, sunt filtrate după câmpul `type` înainte de a ajunge în selector. **Modelele Responses-API
sunt păstrate** — fiecare intrare Codex / GPT-5.x declară `supported_endpoints: ["responses"]`,
iar OmniRoute le convertește pentru `/v1/chat/completions`, astfel încât pot fi utilizate fără probleme.

### Furnizori pe care nu i-ați configurat niciodată

Catalogul afișează modele de la furnizori cu o **conexiune activă**, plus toți furnizorii **noAuth** —
cei fără cheie care alcătuiesc o mare parte din nivelul gratuit. Acest comportament este intenționat. Pentru a-i ascunde,
adăugați-i la `blockedProviders` în setările panoului de control; nu trebuie modificat nimic în
extensie.

## Panou de control într-o filă VS Code

`omnicopilot.dashboardOpen: "editor"` afișează panoul de control OmniRoute într-o filă de editor prin
Simple Browser, în locul unui browser extern. Încorporarea este **opțională pe server** prin
`DASHBOARD_ALLOW_EMBED=vscode`, care servește paginile HTML cu
`frame-ancestors 'self' vscode-webview:` în locul valorilor implicite `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Suprafața API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) păstrează
antetele stricte în ambele cazuri.

> ⚠️ **Este un indicator configurat la compilare, nu la rulare.** Next.js compilează `headers()` în manifestul
> rutelor, astfel încât `next.config.mjs` citește variabila în timp ce pachetul este compilat
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Exportarea acesteia înaintea pornirii unui server deja compilat nu schimbă nimic — antetele sunt incluse în pachet.

```bash
# variabila trebuie să fie prezentă în comanda de COMPILARE
DASHBOARD_ALLOW_EMBED=vscode npm run build        # sau npm run build:release
npm start
```

| Cum ați instalat           | Puteți activa încorporarea?                                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Din surse                  | ✅ setați variabila în comanda de compilare, ca mai sus                                                                                          |
| `npm install -g omniroute` | ❌ pachetul publicat include un pachet precompilat — compilați din surse în schimb                                                               |
| Imagine Docker             | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — imaginea precompilată de pe Docker Hub nu permite încorporarea |

Fără un pachet compilat cu încorporarea activată, pagina refuză să fie afișată într-un cadru, extensia detectează acest lucru din
antetele răspunsului și revine la browserul extern — nimic nu se defectează, iar extensia vă informează o singură dată.
Consultați [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) și problema
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Configurarea celorlalte instrumente din VS Code

**`OmniRoute: Configure Coding CLI`** utilizează CLI-ul `omniroute` pentru a scrie profiluri gata de utilizare
pentru Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo și Roo — aceleași configurații descrise în
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). Cheia API este transmisă CLI-ului prin variabila de mediu
`OMNIROUTE_API_KEY`, niciodată în linia de comandă.

## Depanare

| Simptom                                                            | Cauză / soluție                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Niciun model OmniRoute în selector                                 | Serverul nu este accesibil. Punctul din bara de stare devine gri; rulați `OmniRoute: Check Connection`. Detectarea nu afișează mesaje prin proiectare și nu furnizează niciun model, în loc să solicite intervenția utilizatorului.                                                                        |
| Fiecare model apare de două ori                                    | Utilizați o versiune OmniCopilot mai veche de 1.0.1 — actualizați-o. Extensia solicită acum `?prefix=alias`.                                                                                                                                                                                               |
| Un model de imagine/audio care era listat a dispărut               | Intenționat începând cu versiunea 1.0.1 — acesta nu putea răspunde niciodată unei solicitări de chat.                                                                                                                                                                                                      |
| Panoul lipsește din bara de activități                             | VS Code mută containerele de vizualizare suplimentare în meniul de depășire **„…”** din partea de jos a barei de activități, iar un container ascuns prin clic dreapta rămâne ascuns. Faceți clic dreapta pe bara de activități → bifați **OmniRoute** sau deschideți-l cu `OmniRoute: Manage Connection`. |
| Panoul de control se deschide în browser în ciuda modului `editor` | Serverul nu a fost **compilat** cu `DASHBOARD_ALLOW_EMBED=vscode` (consultați mai sus) — setarea acestei variabile la pornirea unei instalări precompilate nu schimbă nimic. Revenirea la browser este intenționată.                                                                                       |
| Lista de modele este învechită după schimbarea furnizorilor        | `OmniRoute: Refresh Models` sau linkul ↻ din panou.                                                                                                                                                                                                                                                        |
