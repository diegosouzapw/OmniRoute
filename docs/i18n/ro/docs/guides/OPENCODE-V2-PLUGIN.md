`@omniroute/opencode-plugin-v2` adaugă întregul catalog OmniRoute — modele, combinații și
combinații automate — în selectorul de modele din OpenCode v2, împreună cu denumirile afișate,
prețurile și limitele nivelului gratuit.

Este un pachet separat de `@omniroute/opencode-plugin`, deoarece OpenCode v1 și v2 încarcă
pluginurile prin contracte diferite. Alegeți-l pe cel care corespunde versiunii majore OpenCode;
nimic nu este partajat între ele, astfel încât actualizarea unuia nu impune niciodată actualizarea
celuilalt.

## Cerințe

- OpenCode v2.
- Un gateway OmniRoute accesibil (`http://localhost:20128` în mod implicit).
- Node.js 22 sau 24.

## Instalare

Adăugați pluginul în `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modelele apar apoi sub forma `omniroute/<provider>/<model>`; `providerId` determină acel prefix și
id-ul integrării sub care OpenCode stochează acreditarea.

## Acreditări

Pluginul caută o cheie pentru gateway în trei locuri, în această ordine:

1. **Acreditarea pe care ați conectat-o în OpenCode.** Pluginul înregistrează o integrare, astfel încât
   fluxul propriu de autentificare al OpenCode poate stoca cheia. Nimic nu ajunge în `opencode.json` — preferați această opțiune.
2. `apiKey` din opțiunile pluginului, pentru o suprascriere la nivel de proiect. Aceasta introduce cheia într-un fișier pe care
   este posibil să-l includeți în commituri.
3. `OMNIROUTE_API_KEY` din mediu.

Dacă niciuna dintre cele trei nu este disponibilă, catalogul este gol, iar pluginul menționează acest lucru o singură dată la pornire,
în loc să vă lase cu un selector gol fără nicio explicație.

### Tokenul de administrare este o cheie diferită

Combinațiile, starea furnizorilor și îmbogățirea datelor (denumiri afișate, prețuri, limitele nivelului gratuit) provin de la
endpointurile `/api/*` ale gateway-ului, pe care majoritatea implementărilor le protejează cu un token de
**administrare**, nu cu cheia de inferență:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token de citire pentru administrare>"
}
```

Dacă nu este setat, `managementReadToken` revine la `apiKey`. Atunci când un gateway respinge această soluție de rezervă,
catalogul este publicat în continuare, dar cu id-urile brute ale modelelor în locul denumirilor afișate, fără
deduplicarea aliasurilor canonice, fără prețuri și fără combinații. Pluginul emite un avertisment o singură dată pentru fiecare endpoint
atunci când se întâmplă acest lucru, indicând endpointul și ceea ce s-a pierdut — astfel încât un selector degradat nu rămâne niciodată un mister.

## Opțiuni

| Cheie                            | Valoare implicită                               | Note                                                                                                                                  |
| -------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                   | Id-ul furnizorului, id-ul integrării și prefixul sub care apar modelele                                                               |
| `baseURL`                        | obligatoriu                                     | Rădăcina gateway-ului, numai `http(s)`; sufixul `/v1` este adăugat acolo unde este necesar                                            |
| `apiKey`                         | acreditarea conectată, apoi `OMNIROUTE_API_KEY` | Cheie de chat pentru `/v1/*`                                                                                                          |
| `managementReadToken`            | revine la `apiKey`                              | Cheie pentru `/api/*` — de obicei **nu** este aceeași                                                                                 |
| `displayName`                    | `"OmniRoute"`                                   | Numele furnizorului în selector                                                                                                       |
| `timeoutMs`                      | `10000`                                         | Timpul-limită pentru preluare per endpoint (combinațiile automate folosesc 5 s)                                                       |
| `modelCacheTtlMs`                | `300000`                                        | TTL-ul cache-ului catalogului; un instantaneu pe disc accelerează pornirile la rece                                                   |
| `timeouts`                       | revine la `timeoutMs`                           | Limite per endpoint în ms: `models`, `combos`, `autoCombos`, `enrichment`                                                             |
| `enrichment`                     | `true`                                          | Preia denumirile, prețurile și limitele nivelului gratuit                                                                             |
| `providerTag`                    | `true`                                          | Prefixează denumirea afișată cu furnizorul din amonte către care direcționează                                                        |
| `usableOnly`                     | `false`                                         | Păstrează numai furnizorii pe care gateway-ul îi raportează ca fiind configurați                                                      |
| `visibleModels` / `hiddenModels` | `[]`                                            | Liste de permisiuni cu potrivire exactă sau după sufix; interdicția are prioritate                                                    |
| `geminiSanitization`             | `true`                                          | Elimină din schemele instrumentelor cuvintele-cheie JSON-Schema respinse de Gemini (instrumentele `$ref` sunt transmise nemodificate) |
| `apiFormat.allowAnthropic`       | `false`                                         | Direcționează id-urile din lista de permisiuni prin blocul API Anthropic                                                              |
| `apiFormat.anthropicModels`      | `[]`                                            | Id-urile complete ale modelelor direcționate către Anthropic                                                                          |
| `logLevel` / `startupDebug`      | `warn` / `false`                                | Nivelul de detaliere al jurnalizării                                                                                                  |

## Cum rămâne actualizat catalogul

Catalogul este preluat la cerere și memorat în cache pentru `modelCacheTtlMs`, iar un instantaneu pe disc păstrează disponibil ultimul catalog cunoscut atunci când gateway-ul este inaccesibil — o întrerupere nu vă costă nimic în afară de actualitate. Modelele și combinațiile sunt publicate imediat ce sosesc; combinațiile automate, lista furnizorilor și stratul suplimentar de îmbogățire sunt integrate pe măsură ce devin disponibile, astfel încât un endpoint lent să nu poată bloca întregul selector.

Numele includ informațiile cunoscute de gateway: furnizorul din amonte către care este direcționat un model, un marcaj `[Free]` și bugetul aferent — astfel încât două conexiuni care oferă același model rămân ușor de diferențiat. Dezactivați prefixul cu `"providerTag": false`.

Nu există nicio comandă de reîmprospătare manuală: comenzile OpenCode v2 sunt șabloane de prompturi, nu callback-uri, astfel încât un plugin nu poate expune o asemenea comandă. Reîmprospătările respectă TTL-ul; gazdei i se solicită reîncărcarea numai când catalogul sau stratul suplimentar s-a schimbat efectiv, niciodată la fiecare reîmprospătare.

## Apelarea instrumentelor în Gemini

Gemini respinge în întregime o solicitare ale cărei declarații de instrumente conțin `$schema` sau `additionalProperties`, răspunzând cu `400 INVALID_ARGUMENT`. Pluginul elimină acele cuvinte-cheie din schemele instrumentelor destinate unui model Gemini al acestui furnizor și lasă neschimbate toate celelalte solicitări. Un instrument care conține un `$ref` este transmis fără modificări, în loc să fie eliminat, deoarece eliminarea referinței ar extinde schema pentru a „accepta orice”.
Setați `"geminiSanitization": false` pentru a dezactiva această funcționalitate.

## Depanare

| Simptom                                                 | Cauză                                                                                                           |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Selectorul nu afișează niciun model OmniRoute           | Nu a fost găsită nicio cheie (verificați avertismentul de la pornire) sau gateway-ul este inaccesibil           |
| ID-uri brute de modele, fără combinații și fără prețuri | Endpoint-urile de administrare au refuzat tokenul — setați `managementReadToken`                                |
| O sesiune fixată la `opencode-<id>/…`                   | Pluginul v1 a publicat `opencode-<id>`; v2 publică direct `<id>`, așadar selectați din nou modelul sub `<id>/…` |
