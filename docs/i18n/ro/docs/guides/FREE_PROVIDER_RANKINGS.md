> **Pe scurt**: OmniRoute clasifică furnizorii săi **gratuiți** în funcție de calitatea modelelor, utilizând **scorurile ELO Arena AI
> (în stil LMArena)**. Deschideți pagina **Clasamentul furnizorilor gratuiți** din
> panoul de control pentru a vedea ce furnizori gratuiți oferă cele mai performante modele pentru sarcina dvs. —
> per ansamblu sau filtrate după categorie (programare, revizuire, documentație, depanare).

---

## Ce este

OmniRoute înregistrează 329 de furnizori, inclusiv 155 de intrări în catalog marcate drept **gratuite/fără autentificare**
(fără autentificare,
OAuth cu nivel gratuit sau cheie API cu nivel gratuit — consultați
[Ghidul nivelurilor gratuite](../getting-started/FREE-TIERS-GUIDE.md) și
[directorul complet al nivelurilor gratuite](../reference/FREE_TIERS.md)). Problema: furnizorii gratuiți diferă
foarte mult în ceea ce privește calitatea modelelor. Un furnizor fără autentificare care oferă un model de ultimă generație este mult mai util
decât unul care oferă un model vechi și de mici dimensiuni.

**Clasamentul furnizorilor gratuiți** răspunde la întrebarea „**care furnizor gratuit îmi oferă cel mai bun model?**” prin
corelarea catalogului fiecărui furnizor gratuit cu **scorurile de calitate obținute prin contribuția comunității** din
**clasamentul Arena AI** (ELO bazat pe preferințele umane, aceeași idee care stă la baza arenei de
chatboți LMArena). Furnizorii sunt apoi clasificați în funcție de performanța **celui mai bun model gratuit** al lor.

Clasamentul este calculat pe baza a trei surse reale:

1. Listele furnizorilor gratuiți — `NOAUTH_PROVIDERS`, plus intrările `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` marcate cu `hasFree`
   (`src/shared/constants/providers.ts`).
2. Catalogul de modele al fiecărui furnizor din registrul furnizorilor
   (`open-sse/config/providerRegistry.ts`).
3. Scorurile de adecvare pentru sarcini derivate din ELO, stocate în tabelul DB `model_intelligence` de către
   motorul de sincronizare Arena ELO (`src/lib/arenaEloSync.ts`).

Logica de corelare se află în `src/lib/freeProviderRankings.ts`.

## Cum se accesează

### Pagina panoului de control

Deschideți panoul de control și accesați **Costuri → Clasamentul furnizorilor gratuiți** sau navigați direct la:

```
/dashboard/free-provider-rankings
```

Pagina (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) afișează:

- Un **podium pentru primii 3** (🥇 🥈 🥉) furnizori gratuiți cu cele mai bune poziții în clasament.
- Un **tabel complet al clasamentului** cu coloanele: **Poziție**, **Furnizor**, **Cel mai bun model**,
  **Scor**, **Scor mediu**, **Modele**, **Tip**.
- **Butoane de filtrare după categorie**: _Toate categoriile_, _Implicit_, _Programare_, _Revizuire_,
  _Documentație_, _Depanare_.

Insigna **Tip** a fiecărui furnizor indică modul în care acesta este gratuit:

| Insignă  | Semnificație                                                  |
| -------- | ------------------------------------------------------------- |
| `NOAUTH` | Întotdeauna gratuit, fără acreditări necesare                 |
| `OAUTH`  | Furnizor OAuth cu un nivel gratuit (`hasFree`)                |
| `APIKEY` | Furnizor pe bază de cheie API cu un nivel gratuit (`hasFree`) |

Scorurile sunt afișate sub formă de etichete ușor de înțeles (de exemplu, _Elită_, _Excelent_, _Foarte bun_,
_Bun_, _Mediu_), nu ca numere brute, deoarece valoarea de bază reprezintă o calitate relativă
a clasamentului, nu un procent.

### Endpoint API

Pagina este susținută de un endpoint public pentru citire
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parametrii interogării (validați cu Zod):

| Parametru  | Tip              | Valoare implicită | Observații                                                                                                   |
| ---------- | ---------------- | ----------------- | ------------------------------------------------------------------------------------------------------------ |
| `category` | șir de caractere | (niciuna)         | Una dintre `default`, `coding`, `review`, `documentation`, `debugging`. Omiteți pentru clasamentul combinat. |
| `limit`    | număr            | `50`              | Limitat la intervalul `1–100`.                                                                               |

Structura răspunsului:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` este valoarea ELO Arena originală; `score` este valoarea normalizată de adecvare pentru sarcină
(consultați mai jos). Furnizorii fără modele evaluate sunt omiși din răspuns.

## Cum funcționează scorurile

### Sursă: clasamentul Arena AI

Motorul de sincronizare Arena ELO (`src/lib/arenaEloSync.ts`) preia două clasamente — `text`
și `code` — din API-ul clasamentului Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Fiecare intrare din clasament
conține numele modelului, furnizorul, `score` ELO, intervalul de încredere și numărul de voturi.

Categoriile clasamentului corespund categoriilor de sarcini OmniRoute:

| Clasament Arena | Categorii de sarcini OmniRoute                    |
| --------------- | ------------------------------------------------- |
| `text`          | `default`, `review`, `documentation`, `debugging` |
| `code`          | `coding`                                          |

### Normalizare (scor de adecvare pentru sarcină)

Scorurile ELO brute sunt normalizate pentru fiecare clasament într-o **valoare de adecvare pentru sarcină din intervalul `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Scorul nu ajunge niciodată la `0` sau `1`, lăsând o marjă pentru suprascrierile utilizatorului. Acesta este
câmpul `score` pe care îl vedeți în răspunsul API și eticheta afișată în panoul de control.

### Nivel de încredere

Fiecare intrare primește un nivel de încredere bazat pe numărul de voturi din Arena:

| Nivel de încredere | Voturi  |
| ------------------ | ------- |
| `high`             | ≥ 5.000 |
| `medium`           | ≥ 1.000 |
| `low`              | < 1.000 |

### Stocare și actualitate

Intrările normalizate sunt scrise în tabelul DB `model_intelligence`, cu
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Intrările **expiră după
7 zile**, astfel încât un furnizor care nu se mai sincronizează este eliminat în cele din urmă, în loc să furnizeze
date învechite.

Sincronizarea rulează **implicit**:

- Rulează o dată la pornirea serverului și apoi periodic, pe baza unui temporizator
  (`src/lib/arenaEloSync.ts`, conectat din `src/instrumentation-node.ts`).
- Este **neblocantă și nu cauzează niciodată o eroare fatală** — dacă preluarea din sursa din amonte eșuează, OmniRoute continuă să
  ruleze, iar clasamentele afișează pur și simplu ultimele date valide (sau o stare fără date).

Două variabile de mediu o controlează (documentate în
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Variabilă                 | Valoare implicită | Scop                                                        |
| ------------------------- | ----------------- | ----------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`            | Setați la `false` pentru a dezactiva sincronizarea externă. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h)     | Intervalul de sincronizare, în secunde.                     |

### Sincronizare manuală / stare / ștergere

Pentru operatori, un endpoint de administrare autentificat oferă control manual
(`src/app/api/intelligence/sync/route.ts` — necesită autentificare de administrare):

```
GET    /api/intelligence/sync          # starea curentă a sincronizării (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # declanșează o sincronizare manuală; corp: { "dryRun": true } pentru previzualizare fără scriere
DELETE /api/intelligence/sync          # șterge toate intrările de inteligență arena_elo sincronizate
```

Dacă pagina clasamentelor este goală, un `POST /api/intelligence/sync` manual (sau simpla
repornire a serverului) o repopulează.

### Asocierea modelelor cu clasamentul

ID-urile modelelor din registru și numele modelelor din Arena nu corespund întotdeauna exact. Clasamentul utilizează
o asociere flexibilă (`findMatchingIntelligence` din `src/lib/freeProviderRankings.ts`):

1. Potrivire exactă după ID-ul normalizat al modelului.
2. Potrivire după eliminarea unui sufix final de versiune (de exemplu, `kimi-k2.6` → `kimi-k2`).
3. Potrivire după prefix (numele unui model din clasament este un prefix al ID-ului din registru).

În etapa de sincronizare, prefixele cunoscute ale furnizorilor (`anthropic/`, `openai/`, `google/`, …) sunt
eliminate, iar o mică hartă de aliasuri extinde numele canonice în variantele pe care OmniRoute le utilizează
intern, astfel încât modelele să poată fi găsite sub orice nume.

### Cum este clasificat un furnizor

Pentru fiecare furnizor gratuit, motorul evaluează fiecare model din catalogul său, apoi:

- **Model de top** = modelul furnizorului cu cel mai mare scor.
- **Scor mediu** = scorul mediu pentru toate modelele evaluate ale furnizorului respectiv.
- **Modele** = numărul modelelor furnizorului care au avut un scor Arena.

Furnizorii sunt sortați mai întâi după **scorul modelului de top**, apoi după scorul mediu. Astfel este recompensat un
furnizor care oferă cel puțin un model gratuit performant.

## Utilizarea sa pentru alegerea furnizorilor gratuiți

1. **Alegeți categoria potrivită.** Utilizați filtrul **Coding** pentru sarcini de tip agent/cod sau
   păstrați **All Categories** / **Default** pentru conversații generale. Același furnizor poate
   avea poziții diferite în funcție de categorie, deoarece modelul său principal diferă de la un clasament la altul.
2. **Preferați podiumul pentru configurările cu o singură încercare.** Dacă doriți să conectați doar unul sau doi furnizori
   gratuiți, începeți cu cei mai bine clasați din categoria dvs.
3. **Verificați insigna Type.** Furnizorii `NOAUTH` sunt cel mai rapid de conectat (fără
   date de autentificare). Nivelurile gratuite `OAUTH` / `APIKEY` necesită o înregistrare rapidă, dar oferă adesea
   acces la modele mai performante. Consultați [Ghidul nivelurilor gratuite](../getting-started/FREE-TIERS-GUIDE.md) pentru
   pașii de conectare.
4. **Conectați mai mulți furnizori și lăsați Auto-Combo să decidă.** Aceleași date Arena ELO care alimentează
   această pagină sunt utilizate și pentru **factorul de adecvare la sarcină** al motorului de punctare Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, ordinea de rezolvare
   `user_override → arena_elo → models_dev_tier → static table`). Astfel, după ce conectați
   cei mai buni furnizori gratuiți, rutarea cu `model: "auto"` (de exemplu, `auto/coding`) va
   prefera automat, pentru fiecare solicitare, modelele gratuite de calitate superioară. Consultați
   [Auto-Combo](../routing/AUTO-COMBO.md) pentru sistemul complet de punctare cu 16 factori.
