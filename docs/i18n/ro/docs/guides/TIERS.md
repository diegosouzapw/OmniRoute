OmniRoute organizează cei 352 de furnizori acceptați în 3 niveluri economice. Fiecare
solicitare îi parcurge în ordine până când unul răspunde cu succes — obțineți
cel mai ieftin răspuns viabil fără să scrieți vreodată cod de rezervă.

## Nivelul 1 — Abonament

**Furnizori pentru care plătiți deja.** OmniRoute utilizează întreaga cotă înainte
ca aceasta să expire.

| Furnizor                         | De ce este în Nivelul 1                          |
| -------------------------------- | ------------------------------------------------ |
| Claude Code OAuth                | Anthropic Pro/Team — tarif fix, adesea nefolosit |
| OpenAI Codex (abonament ChatGPT) | Plus/Team include cotă Codex                     |
| GitHub Copilot                   | Per utilizator — cota se resetează lunar         |
| Cursor IDE                       | Cota planului Pro                                |
| Antigravity / Devin Desktop      | Cote încorporate                                 |

**Strategie**: direcționați mai întâi aici fiecare solicitare care se potrivește
punctelor forte ale modelului. Instrumentul de monitorizare a cotelor urmărește
resetările care se apropie, iar strategia combinată `reset-aware` stabilește
prioritățile în consecință. Pentru a direcționa mai întâi către Nivelul 1 și a
trece la nivelurile cu plată numai pe măsură ce cota se epuizează, utilizați ID-ul
`auto/thrifty` — sau `auto/subscription` pentru a rămâne la capacitatea inclusă în
plan și a opri solicitarea în caz contrar. Consultați
[Direcționarea cu prioritate pentru abonamente](../routing/SUBSCRIPTION_LADDER.md).

## Nivelul 2 — Ieftin

**Furnizori cu plată per token sub 1 USD/1 milion de tokenuri.** Rezervați pentru
volume mari de lucru sau după ce cotele Nivelului 1 își ating limitele.

| Furnizor                         | Preț (intrare/ieșire) | Puncte forte                 |
| -------------------------------- | --------------------- | ---------------------------- |
| DeepSeek V4 Pro                  | $0.27 / $1.10 per 1M  | Cod, raționament             |
| GLM-4.5                          | $0.60 / $2.20 per 1M  | Context extins               |
| MiniMax M1                       | $0.20 / $1.10 per 1M  | Viteză                       |
| Qwen Coder                       | $0.30 / $1.20 per 1M  | Cod                          |
| OpenRouter (optimizat după preț) | variază               | Peste 100 de modele, dinamic |

**Strategie**: combinația `cost-optimized` alege modelul cu cel mai mic cost
$/token care îndeplinește filtrul de capabilități al sarcinii (viziune, mod JSON,
instrumente, context maxim).

## Nivelul 3 — Gratuit

**Furnizori fără costuri** — niveluri gratuite, programe de credite, cote OAuth zilnice.

| Furnizor         | Cotă gratuită / credite                               |
| ---------------- | ----------------------------------------------------- |
| Kiro AI          | Nivel Claude gratuit (utilizare rezonabilă generoasă) |
| OpenCode Free    | Fără autentificare, limite de rată generoase          |
| Qoder            | OAuth gratuit                                         |
| Google Vertex AI | Credite de 300 USD pentru conturi noi                 |
| Amazon Q         | Nivel gratuit pentru utilizatorii AWS                 |
| Pollinations     | API public deschis                                    |
| Cloudflare AI    | Nivel gratuit Workers AI                              |

**Strategie**: combinația `auto` cu plafon bugetar direcționează aici când Nivelurile
1 și 2 eșuează sau când este setat `useFreeOnly=true`. Furnizorii gratuiți au adesea
limite de rată mai restrictive — întrerupătorul de circuit îi recuperează după
perioada de așteptare.

## Configurarea nivelurilor

Panou de control → **Niveluri** → atribuiți furnizorii. Valorile implicite (din `tierDefaults.json`) sunt
rezonabile; modificați-le când aveți anumite abonamente cărora doriți să le acordați prioritate sau furnizori pe care doriți să-i excludeți.

Evaluarea pe baza a 16 factori din Auto-Combo ia în considerare și nivelul. Consultați
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetrie

Panou de control → **Utilizare** afișează tokenurile consumate zilnic pentru fiecare nivel. Utilizați aceste informații pentru:

- A confirma că Nivelul 1 este utilizat complet (altfel irosiți valoarea abonamentului)
- A identifica modelele din Nivelul 2 alese cel mai des (restrângeți-le la 1-2)
- A verifica dacă Nivelul 3 economisește bani pentru sarcinile de testare/explorare

## Modele comune de utilizare

### Sarcină exclusiv gratuită

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Direcționează ferm către Nivelul 3; utilizează Nivelul 2 numai dacă Nivelul 3 nu este disponibil.

### Abonament prioritar, cu alternativă ieftină

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Listă ordonată explicit care corespunde Nivelului 1 → Nivelului 2 → Nivelului 3.
