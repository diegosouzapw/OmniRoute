Compresia Caveman poate încărca pachete de reguli specifice limbii, pe lângă regulile integrate pentru limba engleză.
Astfel, motorul de bază rămâne stabil, iar pachetele pentru portugheză, spaniolă, germană, franceză, italiană, japoneză și
alte limbi viitoare pot evolua independent.

## Locație

Pachetele lingvistice se află în:

```txt
open-sse/services/compression/rules/<language>/
```

Pachete distribuite în prezent (verificate pe baza conținutului directorului `rules/`):

| Limbă                 | Director       | Categorii de reguli prezente                        |
| --------------------- | -------------- | --------------------------------------------------- |
| Engleză               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spaniolă              | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugheză (Brazilia) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indoneziană           | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italiană              | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Germană               | `rules/de/`    | `context`, `filler`, `structural`                   |
| Franceză              | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japoneză              | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Notă privind paritatea:** Pachetele `en`, `es`, `pt-BR`, `id` și `it` au toate cele 5 categorii; `de`, `fr` și `ja` sunt distribuite cu 3 categorii. Pentru categoriile `dedup` și `ultra` lipsă se utilizează automat și fără notificare implementările integrate pentru limba engleză. Contribuțiile pentru adăugarea fișierelor `dedup.json` și `ultra.json` la pachetele mai mici sunt binevenite.
>
> Pachetul `pt-BR` se bazează pe **[Troglodita](https://github.com/leninejunior/troglodita)**, creat de Lenine Júnior — un sistem de compresie conceput de la zero pentru gramatica portughezei braziliene (reducerea pleonasmelor, eliminarea cuvintelor de umplutură în PT-BR, abrevieri tehnice pentru comunitatea braziliană de dezvoltatori).
>
> Lista canonică de categorii și schema fiecărei categorii se află în [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema, versiunea preliminară 2020-12).

## Detectarea limbii

`languageDetector.ts` utilizează euristici simple pentru a deduce limba din textul promptului. Limba
implicită configurată este în continuare respectată, iar detectarea poate fi dezactivată prin configurare atunci când este necesar
un control exact.

Rezultatul detectării este utilizat numai pentru alegerea pachetelor de reguli. Acesta nu modifică rutarea către furnizor, selectarea
setărilor regionale sau limba interfeței cu utilizatorul.

## Structura configurației

Setările de compresie pot include:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` controlează valorile implicite pentru panoul de control și previzualizare. `cavemanConfig` este configurația motorului la rulare,
utilizată atunci când Caveman comprimă textul mesajelor.

## Adăugarea unui pachet lingvistic

1. Creați `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Utilizați formatul regulilor Caveman din `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Păstrați înlocuirile conservatoare și evitați modificarea codului, a identificatorilor, a URL-urilor sau a JSON-ului.
4. Adăugați sau actualizați testele pentru selectarea limbii și comportamentul înlocuirilor.
5. Expuneți noile etichete pentru panoul de control/i18n dacă limba apare în selectoarele din interfața cu utilizatorul.

## API

Pachetele disponibile pot fi interogate cu:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Endpointul de previzualizare acceptă suprascrieri ale configurației lingvistice:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Toate cele 6 pachete lingvistice au primit în v3.8.0 o clauză `SHARED_BOUNDARIES`, care este aplicată la fiecare
nivel de intensitate Caveman (LITE, FULL, ULTRA). Aceasta indică motorului să păstreze textual aceste tipare,
indiferent de eliminarea expresiilor de umplutură din jur:

| Tip de tipar                         | Exemplu                                |
| ------------------------------------ | -------------------------------------- |
| Blocuri de cod delimitate            | ` ```python\n...\n``` `                |
| Cod inline                           | `` `my_var` ``                         |
| URL-uri                              | `https://example.com/path`             |
| Căi de fișiere (absolute + relative) | `/etc/hosts`, `./src/index.ts`         |
| Antete de eroare                     | `Error:`, `TypeError:`, `SyntaxError:` |
| Linii din stiva de apeluri           | `  at functionName (file.ts:12:3)`     |

Aceste tipare sunt incluse în `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (anterior `[]`). Constanta
se află în `open-sse/services/compression/types.ts`.

### De ce este important

Fără SHARED_BOUNDARIES, modurile Caveman agresive ar putea elimina conținut care părea text repetitiv,
dar care era, de fapt, un fragment de cod, o cale de fișier sau o stivă de erori. SHARED_BOUNDARIES acționează ca o
plasă de siguranță independentă de limbă, aplicată înainte de executarea regulilor pentru expresiile de umplutură.

### Personalizarea preservePatterns

Pot fi adăugate tipare suplimentare în timpul rulării prin intermediul setărilor de compresie:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Tiparele personalizate le extind (nu le înlocuiesc) pe cele 6 implicite.

## Note operaționale

- Regulile încorporate pentru limba engleză rămân opțiunea de rezervă atunci când lipsește un pachet lingvistic.
- Pachetele JSON încorporate nevalide nu trec validarea, astfel încât resursele versiunii să nu se degradeze fără avertisment.
- Pachetele de reguli conțin exclusiv date și nu trebuie să importe cod sau să execute logică arbitrară.
- Stratul de analiză a compresiei înregistrează modul și motorul selectate, nu textul integral al solicitării.
