Dashboard → Providers → **Importă din fișier** creează conexiuni cu chei API dintr-o listă CSV sau JSON. Fiecare rând poate viza un furnizor diferit. Eșecul parțial face parte din comportamentul prevăzut: rândurile valide sunt importate chiar dacă altele eșuează, iar fereastra modală afișează motivele pentru care rândurile nereușite au fost respinse.

Acest import **nu** creează noduri noi de endpoint compatibile cu OpenAI/Anthropic. Creați-le mai întâi (Dashboard → Providers → Add OpenAI-Compatible sau `omniroute nodes add`), apoi importați rânduri în care coloana `provider` conține id-ul nodului respectiv. Un `baseUrl` specific fiecărui rând poate în continuare să suprascrie URL-ul nodului.

## CSV (pozițional)

Numele coloanelor sunt pur cosmetice. Parserul împarte fiecare rând și îi destructurează valorile după index:

| Index | Câmp       | Obligatoriu | Observații                                                                                                                                    |
| ----- | ---------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 0     | `provider` | da          | Id-ul unui furnizor gestionat existent (`openai`, `anthropic`, …) **sau** id-ul unui **nod** compatibil cu OpenAI/Anthropic, deja înregistrat |
| 1     | `name`     | da          | Numele afișat al conexiunii                                                                                                                   |
| 2     | `apiKey`   | da          | Cheia API                                                                                                                                     |
| 3     | `baseUrl`  | nu          | Suprascrierea URL-ului pentru fiecare rând                                                                                                    |
| 4     | `priority` | nu          | Număr întreg între 1 și 100                                                                                                                   |

Prima linie este omisă ca antet dacă prima sa coloană conține cuvântul literal `provider` (indiferent de scrierea cu majuscule sau minuscule). Liniile goale și comentariile `#` sunt omise.

Descărcați un fișier inițial din fereastra modală de import (**Descărcați șablonul CSV**). Exemplu:

```csv
# Importul furnizorilor OmniRoute (coloane poziționale)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Un id inventat, precum `openai-compatible-chat-001`, nu reprezintă un nod. API-ul returnează `Unknown or unsupported provider` pentru rândul respectiv; fereastra modală îl afișează lângă numele rândului.

## JSON

O matrice JSON de obiecte cu aceleași câmpuri (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Spre deosebire de CSV, cheile JSON au nume.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
