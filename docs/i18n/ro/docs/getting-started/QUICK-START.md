---

## Pasul 1: Instalați OmniRoute

Alegeți metoda preferată:

### Opțiunea A: npm (Recomandată)

```bash
npm install -g omniroute
```

### Opțiunea B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` este cea mai recentă versiune SemVer stabilă **publicată**. Aceasta **nu** urmărește ramura git `main`. Pentru GitOps, fixați versiunea la `diegosouzapw/omniroute:X.Y.Z`. Consultați [Etichetele imaginilor / Canalele de lansare](../guides/DOCKER_GUIDE.md#release-channels).

### Opțiunea C: Din codul sursă

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Pasul 2: Porniți OmniRoute

```bash
omniroute
```

OmniRoute pornește la `http://localhost:20128`. Panoul de control se deschide automat.

---

## Pasul 3: Conectați un furnizor gratuit

Puteți utiliza OmniRoute **fără să plătiți nimic**, conectând un furnizor gratuit.

### Opțiunea A: Kiro (Claude gratuit — Fără card de credit)

1. Deschideți panoul de control la `http://localhost:20128`
2. Accesați **Furnizori** → **Adăugați un furnizor**
3. Selectați **Kiro AI**
4. Faceți clic pe **Conectare** (nu este necesară nicio cheie API!)
5. Gata! Acum aveți acces gratuit la modelele Claude.

### Opțiunea B: OpenCode Free (Fără autentificare)

1. Deschideți panoul de control la `http://localhost:20128`
2. Accesați **Furnizori** → **Adăugați un furnizor**
3. Selectați **OpenCode Free**
4. Faceți clic pe **Conectare** (nu este necesară nicio cheie API!)
5. Gata! Acum aveți acces gratuit la mai multe modele.

### Opțiunea C: Pollinations (Nu este necesară nicio cheie)

1. Deschideți panoul de control la `http://localhost:20128`
2. Accesați **Furnizori** → **Adăugați un furnizor**
3. Selectați **Pollinations**
4. Faceți clic pe **Conectare** (nu este necesară nicio cheie API!)
5. Gata! Acum aveți acces gratuit la GPT-5, Claude, Gemini și multe altele.

---

## Pasul 4: Verificați dacă funcționează

Din [Chei API](http://localhost:20128/dashboard/api-manager), creați o cheie nouă. Păstrați această cheie, deoarece nu va mai fi afișată. Rețineți că această cheie este destinată instrumentelor care accesează OmniRoute, nu accesării furnizorilor din amonte.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Ar trebui să vedeți listate modelele conectate.

## Pasul 5: Direcționați IDE-ul sau CLI-ul către OmniRoute

În instrumentul IDE sau CLI, setați:

```
URL de bază: http://localhost:20128/v1
Cheie API:    [copiați din Panoul de control → Puncte finale]
Model:        auto
```

Asta este tot! IDE-ul utilizează acum OmniRoute, cu selectarea automată a furnizorului.

### Exemplu de IDE: VSCode/Continue.dev

1. În VSCode, instalați extensia [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Actualizați fișierul `~/.continue/config.yaml` pentru a adăuga următoarele linii:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. În panoul de chat Continue.dev, selectați `OmniRoute - Auto` și veți trimite solicitări către OmniRoute.
4. (Opțional) Exercițiu pentru cititor — solicitați IDE-ului să actualizeze `config.yaml` cu toate celelalte configurații prestabilite 😊

### Exemplu de CLI: Codex CLI

1. În sistemul de operare, setați variabila de mediu în mod persistent.
   Pentru macOS/Linux (adăugați în `~/.bashrc` sau `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Pentru Windows (Linie de comandă):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Acum să pornim Codex, dar configurat pentru OmniRoute. Rulați:

```
omniroute launch-codex --model auto
```

Puteți face acest lucru manual prin `codex` și parametrii liniei de comandă pentru a specifica punctul final și cheia API, dar, cu comanda de mai sus, OmniRoute se ocupă de tot în locul dumneavoastră.

Aceeași pornire printr-o singură comandă funcționează și pentru alte instrumente CLI prin lansatorul generic — `omniroute run <target>` acceptă `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` și `gemini` (consultați [Integrările CLI](../guides/CLI-INTEGRATIONS.md)).

3. CLI-ul ar trebui să trimită acum solicitări către OmniRoute.

### Confirmați că instrumentul direcționează traficul către OmniRoute

Puteți vedea detaliile solicitării făcând clic pe [Monitorizare/Jurnale](http://localhost:20128/dashboard/logs) în bara laterală din stânga. Dacă faceți clic pentru a continua, veți vedea mai multe detalii. Ca observație suplimentară, puteți vedea ce informații sunt trimise de instrumentul dumneavoastră preferat. Acest lucru este util din perspectiva învățării și a depanării.

## Întrebări frecvente

### „Am nevoie de o cheie API?”

**Nu!** Puteți utiliza furnizori gratuiți (Kiro, OpenCode Free, Pollinations) fără nicio cheie API. Trebuie doar să îi conectați în panoul de control.

### „Ce este `auto`?”

`auto` îi indică OmniRoute să aleagă automat cel mai bun furnizor pentru fiecare solicitare. Acesta ia în considerare viteza, costul, calitatea și disponibilitatea. Consultați [Ghidul Auto-Combo](./AUTO-COMBO-GUIDE.md) pentru detalii.

### „Cât costă?”

OmniRoute este **gratuit și open-source**. Plătiți doar pentru furnizorii pe care îi utilizați. Mulți furnizori au niveluri gratuite — consultați [Ghidul nivelurilor gratuite](./FREE-TIERS-GUIDE.md).

### „Îl pot utiliza cu Claude Code / Cursor / Copilot?”

**Da!** OmniRoute funcționează cu orice instrument care acceptă formatul OpenAI. Trebuie doar să setați URL-ul de bază la `http://localhost:20128/v1`. Consultați [Ghidul instrumentelor CLI](../reference/CLI-TOOLS.md) pentru instrucțiuni specifice de configurare.

### „Ce se întâmplă dacă un furnizor devine indisponibil?”

OmniRoute omite automat furnizorii care au eșuat și îl încearcă pe următorul. Nu trebuie să faceți nimic. Consultați [Ghidul Auto-Combo](./AUTO-COMBO-GUIDE.md) pentru detalii.
