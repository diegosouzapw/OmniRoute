OmniRoute include un set atent selecționat de proxy-uri gratuite în tabelul `free_proxies`,
sincronizat de la furnizori externi (1proxy, proxifly, iplocate, webshare).
Panoul de control le afișează în **Setări → Proxy-uri gratuite**. Acest document
descrie filtrarea, sortarea, numărarea și raportarea erorilor de sincronizare pe
partea de server, expuse de ruta de listare.

## Ruta de listare — `GET /api/settings/free-proxies`

Returnează un subset filtrat, sortat și paginat, împreună cu numărul total. Filtrarea și
numărarea au loc în SQL, astfel încât interfața poate afișa totalul real (de exemplu, `Total: 0`)
fără a încărca fiecare rând în memorie.

### Parametri de interogare

| Parametru         | Tip                                | Implicit  | Semnificație                                                                                                |
| ----------------- | ---------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------- |
| `search`          | șir de caractere                   | `""`      | `LIKE` sensibil la litere mari și mici pentru coloana gazdă (și sursă).                                     |
| `protocol`        | șir de caractere                   | `""`      | Filtru `type`: `http` / `https` / `socks4` / `socks5`. Gol = toate.                                         |
| `country`         | șir de caractere                   | `""`      | Filtru `countryCode` (ISO-2). Gol = toate.                                                                  |
| `minQuality`      | număr                              | `0`       | Numai rândurile cu `qualityScore >= minQuality`. `0` = fără limită minimă.                                  |
| `disabledSources` | șir de caractere                   | `""`      | ID-uri de surse separate prin virgulă care trebuie excluse (de exemplu, `proxifly,webshare`).               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = scor desc.; `latency` = latență asc. (valorile nule la final); `recent` = `lastValidated` desc. |
| `offset`          | număr                              | `0`       | Începutul paginării.                                                                                        |
| `limit`           | număr                              | `50`      | Dimensiunea paginii (limitată pe partea de server).                                                         |

### Răspuns

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` reflectă totalul filtrat **înainte de** paginare, astfel încât interfața poate afișa
`Total: N` și `hasMore` independent. `syncErrors` este indexat după ID-ul sursei și
completat numai pentru sursele a căror ultimă sincronizare a eșuat — un rezultat `Total: 0`
nu este niciodată lipsit de explicații.

## Adăugare în pool — `POST /api/settings/free-proxies/[id]/add-to-pool`

Promovează un proxy gratuit în pool-ul administrat `proxy_registry`. Validează mai întâi
sursa din amonte; la succes, returnează ID-ul noului proxy din pool și latența măsurată.

## Sincronizare — `POST /api/settings/free-proxies/sync`

Preia din nou toate sursele activate (sau subsetul din `{ "sources": [...] }`). Fiecare
sursă se sincronizează independent; o sursă care eșuează este înregistrată în `syncErrors`, iar
celelalte se finalizează în continuare, astfel încât sincronizările parțiale nu șterg niciodată datele valide existente.

## Statistici — `GET /api/settings/free-proxies/stats`

Returnează agregarea `total / inPool / avgQuality / bySource / lastSyncAt`
fără datele rândurilor — utilizată de widgeturile din antetul panoului de control.
