> **Sursa de referință:** `src/lib/localCorpus/index.ts` (index de text cu dimensiune limitată),
> `src/lib/localCorpus/configured.ts` (mediu de execuție configurat),
> `src/lib/db/localCorpus.ts` (persistența căii rădăcină),
> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 instrumente MCP doar pentru citire) și
> `src/app/api/settings/local-corpus/route.ts` (API-ul pentru setări).

## Ce este

Local Corpus îi permite unui operator să expună serverului MCP al OmniRoute un singur
director de fișiere text, aprobat în mod explicit. Fișierele rămân în directorul lor
original: OmniRoute stochează în SQLite doar calea rădăcină canonică și menține un index
de căutare în memorie. Conținutul corpusului nu este copiat în depozit sau în baza de date.

Actualizarea indexului este incrementală. Fișierele nemodificate sunt reutilizate pe baza
dimensiunii și a datei modificării, fișierele modificate sunt recitite și li se calculează
hashul cu SHA-256, iar fișierele șterse sunt eliminate. Căutarea actualizează un index mai
vechi de 30 de secunde; apelanții pot solicita și o actualizare imediată.

## Configurarea sursei

Ruta pentru setări necesită aceeași autentificare de administrare ca celelalte API-uri
pentru setări. Calea trimisă trebuie să existe deja și trebuie să fie o cale absolută
către un director.

```bash
# Conectați un director aprobat
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Verificați configurarea și starea indexului
curl http://localhost:20128/api/settings/local-corpus

# Deconectați fără a modifica fișierele sursă
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Instrumente MCP

Toate cele trei instrumente necesită `read:local-corpus`. Răspunsurile instrumentelor
expun căi relative și numele de bază al directorului rădăcină, niciodată calea sa absolută.

| Instrument            | Descriere                                                                                               |
| :-------------------- | :------------------------------------------------------------------------------------------------------ |
| `local_corpus_status` | Raportează starea configurării, dimensiunea indexului, limitele și ora ultimei actualizări              |
| `local_corpus_search` | Caută în textul indexat și returnează fragmente limitate, delimitate pe linii (până la 20 de rezultate) |
| `local_corpus_read`   | Citește un interval limitat de linii dintr-un fișier permis, cu o cale relativă la corpus               |

Exemple de intrări MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Limite de siguranță

- Lista de permisiuni este orientată spre text: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` și `.yml`.
- Legăturile simbolice sunt omise. Căile de citire sunt canonizate și trebuie să rămână
  în interiorul rădăcinii configurate; căile absolute și încercările de traversare sunt respinse.
- Numele directoarelor sensibile și generate sunt excluse: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` și
  `secrets`.
- Limitele implicite sunt de 5.000 de fișiere, 1 MiB per fișier, 64 MiB de conținut
  indexat în total, aproximativ 4.000 de caractere per fragment de căutare și 400 de linii per citire.
- Fișierele care conțin NUL sunt tratate ca fișiere non-text și sunt omise sau respinse.

Documentele binare precum PDF, DOCX, imaginile și arhivele nu sunt acceptate în mod
intenționat. Convertiți-le într-un format text aprobat în directorul configurat înainte
de indexare.

## Note operaționale

- Modificarea sau ștergerea rădăcinii configurate golește indexul partajat din memorie.
- O repornire a procesului elimină indexul; următoarea căutare îl reconstruiește din
  sursa configurată.
- `local_corpus_status` nu forțează o scanare. Utilizați `local_corpus_search` cu
  `refresh: true` atunci când este necesară o rescanare imediată.
- Erorile de scanare și citire sunt contorizate sau returnate sub formă de erori
  sanitizate; fișierele sursă nu sunt modificate niciodată.
