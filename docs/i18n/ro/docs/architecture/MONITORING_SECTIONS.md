## Navigare de nivel înalt

Bara laterală a panoului de control (după Grupa B) are următoarele secțiuni de nivel superior, în această ordine:

```
Acasă
Furnizori
Combinații
Chei API
Setări
Analiză
Costuri          ← NOU (Grupa B, planul 16)
Monitorizare     ← REORGANIZAT (Grupa B, planul 16)
...
```

---

## Secțiunea Costuri (nouă, nivelul 1)

Prefixul căii: `/dashboard/costs/`

| Element               | URL                                  | Descriere                                         |
| --------------------- | ------------------------------------ | ------------------------------------------------- |
| Prezentare generală   | `/dashboard/costs`                   | Panou agregat al costurilor (mutat din Analiză)   |
| Tarife                | `/dashboard/costs/pricing`           | Tabel cu tarifele pentru fiecare model            |
| Buget                 | `/dashboard/costs/budget`            | Praguri bugetare + alerte                         |
| Partajarea cotei      | `/dashboard/costs/quota-share`       | Grupuri de partajare a cotei + utilizare          |
| Configurarea planului | `/dashboard/costs/quota-share/plans` | Suprascrieri ale planului pentru fiecare furnizor |

**Motivație**: Tarifele, Bugetul și Partajarea cotei se aflau anterior în
`Monitorizare > Parametri de cost`. Mutarea lor într-o secțiune dedicată de nivel superior
le face mai ușor de găsit, fără navigarea prin instrumentele de observabilitate.

## Secțiunea Monitorizare (reorganizată)

Secțiunea Monitorizare are acum **Activitate în partea de sus**, urmată de **3 subgrupuri**:

```
Monitorizare
├── Activitate             ← Flux cronologic (element de nivel superior)
├── Grupul Jurnale
│   ├── Jurnale (toate)
│   ├── Jurnale proxy
│   └── Jurnale de consolă
├── Grupul Audit
│   ├── Jurnal de audit
│   ├── Audit MCP
│   └── Audit A2A
└── Grupul Sistem
    ├── Stare
    └── Execuție
```

### Ce s-a schimbat față de structura veche

| Înainte                                                                                  | După                                               |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Activitate = filă din Jurnale care reda Jurnalul de audit                                | Activitate = flux dedicat (`/dashboard/activity`)  |
| Grupul Parametri de cost din Monitorizare                                                | Mutat în secțiunea Costuri                         |
| Listă simplă: Jurnale, Activitate (jurnale), Audit, Stare, Execuție, Tarife, Buget, Cotă | Structură cu 3 grupuri + secțiune dedicată Costuri |

## Activitate comparativ cu Jurnalul de audit

Acestea sunt acum distincte:

| Dimensiune             | Activitate (`/dashboard/activity`)                                | Jurnal de audit (`/dashboard/audit`)         |
| ---------------------- | ----------------------------------------------------------------- | -------------------------------------------- |
| **Scop**               | Flux de evenimente pentru utilizatori („ce s-a întâmplat recent”) | Jurnal de conformitate/securitate            |
| **Sursă de date**      | `GET /api/compliance/audit-log?level=high`                        | `GET /api/compliance/audit-log?level=all`    |
| **Format**             | Cronologie, grupată pe zile, verbe ușor de înțeles + pictograme   | Tabel dens paginat, 50/pagină                |
| **Filtre**             | Categoria tipului de eveniment                                    | Acțiune, severitate, actor, interval de date |
| **Export**             | Indisponibil                                                      | Export JSON                                  |
| **Filtru după actor**  | Nu se aplică                                                      | Se poate filtra după actor                   |
| **Evenimente afișate** | Numai acțiuni de nivel înalt (listă de permisiuni)                | Toate evenimentele de audit                  |

### Lista de permisiuni pentru acțiunile de nivel înalt

Definită în `src/lib/audit/highLevelActions.ts`. Controlează ce evenimente apar în
fluxul Activitate. Lista de permisiuni include:

- Evenimente de adăugare/eliminare/testare a furnizorilor
- Crearea/actualizarea/ștergerea combinațiilor
- Ciclul de viață al cheilor API (creare, revocare, rotire)
- Atingerea pragului bugetar
- Autentificare/deconectare
- Crearea sesiunilor agenților cloud
- Înregistrarea instrumentelor MCP
- Crearea/ștergerea webhookurilor
- Modificări ale grupurilor/planurilor de cote (acțiuni `quota.*`, Grupa B)
- Evenimente de platformă (actualizare, implementare)
- Instalarea/eliminarea abilităților

Evenimentele care nu se află în această listă apar numai în Jurnalul de audit.

### Adăugarea unei noi acțiuni de nivel înalt

Editați `src/lib/audit/highLevelActions.ts` și adăugați șirul acțiunii în
`HIGH_LEVEL_ACTIONS`. Aceasta necesită un PR (lista este definită în cod, nu poate fi
configurată prin baza de date). Pictograma corespunzătoare poate fi adăugată în `src/lib/audit/activityIcons.ts`.

## Redirecționare: `/dashboard/logs/activity`

Calea veche `/dashboard/logs/activity` este redirecționată permanent (HTTP 308) către
`/dashboard/activity` prin `permanentRedirect()` în
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

ID-ul vechi al barei laterale `logs-activity` este păstrat în `HIDEABLE_SIDEBAR_ITEM_IDS`
(dar eliminat din `SIDEBAR_DEFINITIONS`) pentru a evita deteriorarea presetărilor utilizatorilor care
fac referire la ID-ul vechi.

## i18n

Spații de nume adăugate de Grupa B:

| Cheia spațiului de nume | Acoperă                                                               |
| ----------------------- | --------------------------------------------------------------------- |
| `sidebar.costsSection`  | Eticheta secțiunii Costuri                                            |
| `sidebar.activity`      | Elementul Activitate din bara laterală                                |
| `sidebar.logsGroup`     | Eticheta subgrupului Jurnale                                          |
| `sidebar.systemGroup`   | Eticheta subgrupului Sistem                                           |
| `sidebar.costsOverview` | Elementul de prezentare generală a costurilor                         |
| `activity.*`            | Toate șirurile paginii Activitate (titlu, verbe, filtre, stare goală) |

Localizările considerate sursa adevărului sunt: `pt-BR` și `en`. Toate celelalte 40 de localizări folosesc
engleza ca variantă de rezervă prin mecanismul de rezervă `next-intl` (configurat în `src/i18n/config.ts`).
