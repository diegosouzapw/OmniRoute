O OmniRoute separa a telemetria de cotas do provedor da contabilização do Ghostlight.

## Estados fidedignos

- `healthy` significa que uma fonte informou capacidade restante utilizável.
- `approaching_limit` significa que uma fonte informou capacidade restante igual ou inferior ao limite configurado.
- `exhausted` é emitido somente quando uma fonte informa capacidade zero ou uso no limite.
- `unavailable` significa que uma fonte compatível não conseguiu retornar dados.
- `unknown` significa que não existe uma fonte compatível ou que nenhum limite do provedor é conhecido.

Desconhecido não significa esgotado e não desabilita um provedor.

As fontes são priorizadas nesta ordem: API oficial do provedor, API de uso autenticada, cabeçalhos de resposta explicitamente mapeados, configuração do administrador, estimativas locais, desconhecido. As estimativas locais nunca são apresentadas como dados de faturamento do provedor.

Os cabeçalhos de resposta são analisados somente por meio de um mapeamento explícito do provedor. Não se presume que nomes genéricos de cabeçalhos sejam válidos globalmente.
