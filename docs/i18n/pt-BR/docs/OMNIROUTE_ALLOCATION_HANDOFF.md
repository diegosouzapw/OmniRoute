A alocação não é a cota do provedor.

Os pools de cotas definem quais chaves de API podem consumir um pool de provedor e como as políticas rígidas, flexíveis ou de pico são aplicadas. A cota do provedor é a capacidade externa informada por um provedor ou por uma fonte configurada explicitamente. Os orçamentos internos do Ghostlight são limites de governança definidos pelo administrador.

A operação `ensurePool` é idempotente: um pool idêntico permanece inalterado, uma alocação modificada é atualizada e um pool ausente é criado. Isso se destina à automação e a chamadores de API com limites definidos.

O endpoint de status somente leitura é `GET /api/omniroute/status`. O comando de verificação é `npm run omniroute:verify`; ele não faz nenhuma solicitação real a um modelo.
