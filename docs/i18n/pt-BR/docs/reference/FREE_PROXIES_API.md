O OmniRoute fornece um conjunto selecionado de proxies gratuitos na tabela `free_proxies`,
sincronizado a partir de provedores externos (1proxy, proxifly, iplocate, webshare). O
dashboard exibe esses proxies em **Configurações → Proxies gratuitos**. Este documento
aborda a filtragem, a ordenação, a contagem e o relatório de erros de sincronização
no lado do servidor disponibilizados pela rota de listagem.

## Rota de listagem — `GET /api/settings/free-proxies`

Retorna uma parte filtrada, ordenada e paginada, além de uma contagem total. A filtragem e a
contagem ocorrem no SQL, permitindo que a interface exiba o total real (por exemplo, `Total: 0`)
sem carregar todas as linhas na memória.

### Parâmetros de consulta

| Parâmetro         | Tipo                               | Padrão    | Significado                                                                                                                   |
| ----------------- | ---------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`      | `LIKE` sensível a maiúsculas e minúsculas na coluna de host (e de origem).                                                    |
| `protocol`        | string                             | `""`      | Filtro `type`: `http` / `https` / `socks4` / `socks5`. Vazio = todos.                                                         |
| `country`         | string                             | `""`      | Filtro `countryCode` (ISO-2). Vazio = todos.                                                                                  |
| `minQuality`      | number                             | `0`       | Apenas linhas com `qualityScore >= minQuality`. `0` = sem limite mínimo.                                                      |
| `disabledSources` | string                             | `""`      | IDs de origens separados por vírgulas a serem excluídos (por exemplo, `proxifly,webshare`).                                   |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = pontuação decrescente; `latency` = latência crescente (nulos por último); `recent` = `lastValidated` decrescente. |
| `offset`          | number                             | `0`       | Início da paginação.                                                                                                          |
| `limit`           | number                             | `50`      | Tamanho da página (limitado no lado do servidor).                                                                             |

### Resposta

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` reflete o total filtrado **antes** da paginação, permitindo que a interface renderize
`Total: N` e `hasMore` de forma independente. `syncErrors` usa o ID da origem como chave e
é preenchido apenas para origens cuja última sincronização falhou — um resultado `Total: 0`
nunca fica sem explicação.

## Adicionar ao conjunto — `POST /api/settings/free-proxies/[id]/add-to-pool`

Promove um proxy gratuito para o conjunto gerenciado `proxy_registry`. Primeiro, valida o
serviço upstream; em caso de sucesso, retorna o ID do novo proxy no conjunto e a latência medida.

## Sincronização — `POST /api/settings/free-proxies/sync`

Busca novamente todas as origens habilitadas (ou o subconjunto em `{ "sources": [...] }`). Cada
origem é sincronizada de forma independente; uma origem com falha é registrada em `syncErrors`, e as
outras ainda são concluídas, portanto sincronizações parciais nunca apagam dados válidos anteriores.

## Estatísticas — `GET /api/settings/free-proxies/stats`

Retorna o agregado `total / inPool / avgQuality / bySource / lastSyncAt`
sem o conteúdo das linhas — usado pelos widgets do cabeçalho do dashboard.
