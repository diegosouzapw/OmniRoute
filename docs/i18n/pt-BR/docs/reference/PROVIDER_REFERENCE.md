## Categorias

- **Gratuito** — nível gratuito com chave de API (configurada pelo painel)
- **Sem autenticação** — endpoints públicos que não exigem chave nem login
- **OAuth** — fluxo de login gerenciado pelo OmniRoute, sem necessidade de chave de API
- **Cookie da web** — encapsula o aplicativo web do provedor usando autenticação por cookie
- **Chave de API** — provedor pago configurado por chave de API (créditos gratuitos podem estar disponíveis)
- **Local** — executado na máquina do usuário (Ollama, LM Studio, vLLM etc.)
- **Pesquisa** — provedores de pesquisa na web
- **Áudio** — provedores exclusivos de áudio (TTS/STT)
- **Proxy upstream** — provedores que atuam como proxy para outros provedores
- **Agente de nuvem** — agentes de programação de longa duração (Codex Cloud, Devin, Jules)
- **Sistema** — provedores internos do OmniRoute (loopback etc.)

Tags adicionais: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Chamada de ferramentas` (quando exibida): `native` — API real de chamada de funções; `emulated` — o array `tools` é emulado via prompt por meio de `webTools.ts` (blocos `<tool>{...}</tool>` analisados por regex); `none` — atualmente, `tools` é descartado silenciosamente. Veja #7286.

Use o painel em `/dashboard/providers` para habilitar, configurar e testar cada provedor.
