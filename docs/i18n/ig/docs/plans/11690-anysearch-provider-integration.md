## 1. Eziokwu ntọala nke ọrụ ahụ (akwụkwọ ntụaka gọọmentị, enyochakwara ya n'akụkụ ndị ọzọ)

- Base URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - params: `query` (achọrọ), `max_results` (1-10, ndabara 10), `tag` (`{domain}.{sub_domain}` maka iduzi vertical), `zone` (cn/intl), `language`, `params` (ogige vertical ahaziri ahazi), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - katalọgụ ike ọrụ, anaghị agụ ya n'ime quota.
- `POST /v1/extract` - na-ebute/na-ewepụta `{url, title, content}`; body JSON siri ike, oke 16 KiB.
- `POST /v1/auth/email/register` - ndebanye aha site n'otu oku, na-eweghachi key ederede nkịtị a na-eji naanị otu ugboro `as_sk_...`.
- Nkwenye njirimara: `Authorization: Bearer <as_sk_...>` bụ nhọrọ; ojiji na-enweghị njirimara na-adalata ruo na oke kwa IP nke na-eri quota efu kwa ụbọchị; key na-adịghị irè na-eweghachi 401/403 na-ENWEGHỊ nlọghachi nkịtị na ọnọdụ na-enweghị njirimara.
- Ọkwa efu: arịrịọ 1000 kwa ụbọchị, 20 QPS kwa key. Ọkwa akwụ ụgwọ: enweghị ọnụahịa (Na-abịa N'oge Na-adịghị Anya).
- Akpa nzaghachi: ihe ịga nke ọma `{code: 0, message: "success", request_id, data}`; ọdịda `{code: -1, message}`. Njehie nkwenye njirimara/quota enweghị `error_code` ahaziri ahazi (ederede ozi ahụ bụ akara ngosi); njehie ndị metụtara extract nwere `error_code` (`invalid_extract_url`, `extract_failed`). Enweghị header `Retry-After` na 429.

## 3. Mkpebi (e mere ha niile na 2026-08-26)

1. **Ụzọ nhazi ntụgharị: `fallbackOnly`.** Ihe kpatara ya: onye na-eweta ọrụ efu nke ọnụ ahịa ya bụ 0 agaghị achịkwa ntụgharị akpaka dabere na ọnụ ahịa; nhọrọ doro anya na nlọghachi failover anaghị agbanwe agbanwe. Ihe atụ e ji mee ụkpụrụ: ntinye xquik e jikọtara.
2. **Oke ọrụ: webSearch + webFetch site na `POST /v1/extract` na v1.** Nke a kwekọrọ n'ụdị echiche ikike abụọ nke tavily/exa. Akụkụ ọrụ vetikal (`tag`, `sub-domains`, `batch_search`) anọghị n'oke ọrụ — enweghị IR maka paramita vetikal ugbu a.
3. **Ngosipụta oke ojiji: `freeMonthlyQuota: 0`** (ngosipụta akpachapụ anya dịka xquik). Kama nke ahụ, a na-etinye oke ojiji n'ezie (arịrịọ 1000 kwa ụbọchị, nrụgharị kwa ụbọchị) n'ime ederede `authHint` nke katalọgụ UI. Ihe kpatara ya: ngosipụta oke ojiji ga-adaba n'usoro nrụgharị ya; ịgbanwe oke kwa ụbọchị ka ọ bụrụ nke yiri oke kwa ọnwa (30000) bụ nkwa ụgha UI na-enweghị ike imezu.
4. **searchTypes: `["web"]` naanị.** Enweghị ihe akaebe ọha na eze na API AnySearch nwere vetikal akụkọ/onyonyo; ọnụ ụzọ na-ejikọta API na-enweghị vetikal edekọtara n'akwụkwọ (dịka Google Custom Search) na-egosi naanị web kama iji nzuzo tụgharịa news -> web.
5. **Usoro igodo:** ọrụ na-enweghị igodo na-arụ ọrụ; igodo na-ezighi ezi na-eweghachi 401/403, a naghịkwa eweda ya na nzuzo ka ọ bụrụ anonymous (nke a na-agbaso nkwekọrịta nke upstream).
6. **Ihe e kpachapụrụ anya wepụ:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (nkwụchi chat ka na-eji firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (endpoint ndị dịpụrụ adịpụ na-enweghị njirimara na-ekekọrịta otu ọdọ mmiri nwere oke IP maka IP egress ọ bụla, ya mere extract na-enweghị igodo bụ nhọrọ a ga-eji aka họrọ, ọ bụghị onye a ga-atụle maka ntụgharị akpaka); `QUOTA_STATUS_PROVIDERS` (AnySearch na-egosi oke ojiji site na 429/envelope, ọ bụghị ọnọdụ 402/403).
