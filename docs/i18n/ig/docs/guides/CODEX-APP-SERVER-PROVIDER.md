OmniRoute na-enye ụzọ **abụọ** iji OpenAI Codex:

| Onye na-eweta ọrụ      | Otu o si agwa OpenAI okwu                                                                                                                                                                          | Ịdọ aka ná ntị gbasara ojiji                                  |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| **`codex`**            | Na-ezigara Responses API token OAuth ChatGPT/OpenAI gị ozugbo                                                                                                                                      | **Ee** — enyeghị nnọkọ gọọmentị ikike maka ojiji proxy/router |
| **`codex-app-server`** | Na-achịkwa **`codex app-server` nke Codex CLI n'onwe ya** site na JSON-RPC/WebSocket; CLI na-ejikwa ma na-emegharị OAuth ya n'onwe ya (`~/.codex/auth.json`) kpọmkwem dịka nnọkọ `codex` mmekọrịta | **Mba** — OmniRoute anaghị ezigharị token na API              |

Ebe ọ bụ na `codex-app-server` anaghị ezigharị token, ịdọ aka ná ntị
gbasara ojiji nke izigharị nnọkọ anaghị emetụta ya. Ọ chọrọ ka **Codex CLI dị
na URL app-server ahaziri**, ma CLI ahụ ga-abụrịrị na **abanyela na akaụntụ**.

## 1. Nhazi usoro

```
┌─ Ngwa OmniRoute ────────────────┐        ┌─ sidecar codex-app-server ──────────┐
│  CodexAppServerExecutor          │  WS    │  codex app-server                   │
│  ws://codex-app-server:1456 ─────┼───────▶│  --listen ws://0.0.0.0:1456         │
│  (+ token ikike)                 │  JSON  │  --ws-auth capability-token         │
│                                  │  RPC   │  na-ejikwa OpenAI OAuth n'onwe ya   │
└──────────────────────────────────┘        │  (~/.codex/auth.json, mmegharị onwe)│
        │ na-ekekọrịta (compose volumes)     └─────────────────────────────────────┘
        ▼
  codex-appserver-token   → token ikike WS (ha abụọ na-etinye ya)
  codex-appserver-home    → ~/.codex (auth.json nke dashboard dere,
                             nke codex app-server dị na sidecar na-agụ)
```

- Sidecar na-ege ntị **naanị** na netwọkụ compose dị n'ime
  (`ws://codex-app-server:1456`) n'azụ token ikike. **Ọ dịghị mgbe**
  a na-eme ka host ma ọ bụ ịntanetị nweta ya.
- E tinyelarị Codex CLI n'ime `omniroute:base`, ya mere ọ dịghị mkpa ịwụnye codex na
  host ma ọ bụ igwe onye ọrụ mgbe ị na-agba sidecar ahụ.

## 2. Malite ya

```bash
# Malite stack ahụ YA NA profaịlụ sidecar codex app-server:
docker compose --profile base --profile codex-app-server up -d
# (podman: podman compose --profile base --profile codex-app-server up -d)
```

Sidecar na-emepụta token ikike WS ya n'oge mbido mbụ (n'ime volume
`codex-appserver-token` a na-ekekọrịta), ngwa ahụ na-agụkwa otu token ahụ site na
`OMNIROUTE_CODEX_APPSERVER_WS_TOKEN_FILE`. Ọ dịghị mkpa ijikọ token n'aka.

## 3. Jikọọ + banye na akaụntụ

1. Na dashboard, tinye njikọ maka **OpenAI Codex (App-Server)**. Achọghị API
   key ma ọ bụ token (ọ bụ onye na-eweta ọrụ na-achọghị auth — sidecar na-ejikwa auth).
2. Ọ bụrụ na Codex CLI nke sidecar **abanyebeghị na akaụntụ**, nyocha ahụike
   njikọ ga-egosi _"ọ na-agba mana abanyebeghị na akaụntụ"_ (ọ bụghị njehie auth uhie). Jiri
   **ChatGPT banye**: nke a na-agba device-OAuth Codex ọkọlọtọ n'ime
   ihe nchọgharị gị, wee dee `~/.codex/auth.json` n'ime volume a na-ekekọrịta site na
   **Tinye auth** (otu nbanye ahụ na-ejere ma ndị na-eweta ọrụ `codex` ma
   `codex-app-server` ozi).
3. Ozugbo abanyechara, nyocha ahụike ga-acha akwụkwọ ndụ (ọ na-enyocha ma `/readyz` **ma**
   `account/read` — ya bụ, ọ na-agba ọrụ _ma_ enyochala njirimara ya) wee malite ịrụ ọrụ.

Dashboard anaghị edegharị `~/.codex/auth.json` dị mma nke dị adị — ọ na-ede
naanị mgbe faịlụ ahụ adịghị ma ọ bụ mgbe token ya ochie (a na-emepụta nkwado ndabere mgbe niile).

## 4. Ọnọdụ ntinye n'ọrụ

- **Onye na-ahụ maka sistemụ nwere Codex CLI enyochalarị njirimara ya** — tinye
  `~/.codex` nke host gị n'ime sidecar (`codex-appserver-home`) ma hapụ usoro nbanye.
- **Onye ọrụ ọha, codex adịghị na kọmputa ya** — nke a adịghị mkpa: sidecar nwere
  CLI. Onye ọrụ na-enyocha njirimara naanị site na dashboard.
- **OmniRoute bare-metal (enweghị sidecar, codex dị na host)** — mee ka
  `OMNIROUTE_CODEX_APPSERVER_WS` rụtụ aka na `codex app-server` nke gị ma hụ na
  codex nke host abanyela na akaụntụ; ntụnye "codex adịghị awụnye" ga-apụta ma ọ bụrụ na binary
  ahụ adịghị.

## 5. Ọpụpụ residential / UDP (mgbakwunye onye na-ahụ maka sistemụ, esoghị na ngwugwu)

Sidecar izugbe dị n'elu na-apụ site na netwọkụ nkịtị nke container. Onye
na-ahụ maka sistemụ chọrọ ka okporo ụzọ Codex pụọ site na **ụzọ ọpụpụ residential** (dịka TUN
tailscale sidecar na-ebu TCP + UDP/QUIC) na-agba nke ahụ dịka compose
override dị iche; e kpachaara anya mee ka ọ **ghara** ịbụ akụkụ nke profaịlụ
`codex-app-server` e wepụtara. Lee akwụkwọ ntuziaka arụmọrụ dị n'ime maka nhazi ahụ.
