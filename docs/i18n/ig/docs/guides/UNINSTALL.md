## Mwepụ Ngwa Ọsọ (v3.6.2+)

OmniRoute nwere skript abụọ arụnyere n'ime ya maka iwepụ ngwa nke ọma:

### Debe Data Gị

```bash
npm run uninstall
```

Nke a na-ewepụ ngwa OmniRoute mana ọ **na-echekwa** nchekwa data gị, nhazi, igodo API, na ntọala ndị na-eweta ọrụ dị na `~/.omniroute/`. Jiri nke a ma ọ bụrụ na ị na-eme atụmatụ ịwụnye ya ọzọ ma chọọ idobe ntọala gị.

### Mwepụ Zuru Ezu

```bash
npm run uninstall:full
```

Nke a na-ewepụ ngwa ahụ **ma hichapụ data niile kpamkpam**:

- Ebe nchekwa data (`storage.sqlite`)
- Nhazi ndị na-eweta ọrụ na igodo API
- Faịlụ ndabere
- Faịlụ ndekọ
- Faịlụ niile dị na ndekọ `~/.omniroute/`

> ⚠️ **Ịdọ aka ná ntị:** A pụghị ịtụgharị `npm run uninstall:full` azụ. A ga-ehichapụ njikọ ndị na-eweta ọrụ gị, ngwakọta, igodo API, na akụkọ ojiji gị kpamkpam.

## Iji Aka Wepụ Ngwa

### Nwụnye NPM Global

```bash
# Wepụ package global ahụ
npm uninstall -g omniroute

# (Nhọrọ) Wepụ ndekọ data
rm -rf ~/.omniroute
```

### Nwụnye pnpm Global

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Kwụsị ma wepụ container ahụ
docker stop omniroute
docker rm omniroute

# Wepụ volume ahụ (na-ehichapụ data niile)
docker volume rm omniroute-data

# (Nhọrọ) Wepụ image ahụ
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Kwụsị ma wepụ containers
docker compose down

# Wepụkwa volumes (na-ehichapụ data niile)
docker compose down -v
```

### Ngwa Desktọpụ Electron

**Windows:**

- Mepee `Settings → Apps → OmniRoute → Uninstall`
- Ma ọ bụ mee NSIS uninstaller site na ndekọ nwụnye

**macOS:**

- Dọrọ `OmniRoute.app` site na `/Applications` gaa na Trash
- Wepụ data: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Wepụ faịlụ AppImage
- Wepụ data: `rm -rf ~/.omniroute`

### Nwụnye Site na Source (git clone)

```bash
# Wepụ ndekọ e mere clone
rm -rf /path/to/omniroute

# (Nhọrọ) Wepụ ndekọ data
rm -rf ~/.omniroute
```

## Ndekọ Data

Na ndabara, OmniRoute na-echekwa data n'ebe ndị a:

| Platform           | Ụzọ Ndabara                      | Mgbanwe                   |
| ------------------ | -------------------------------- | ------------------------- |
| Linux              | `~/.omniroute/`                  | env var `DATA_DIR`        |
| macOS              | `~/.omniroute/`                  | env var `DATA_DIR`        |
| Windows            | `%APPDATA%/omniroute/`           | env var `DATA_DIR`        |
| Docker             | `/app/data/` (volume e jikọtara) | env var `DATA_DIR`        |
| Nke kwekọrọ na XDG | `$XDG_CONFIG_HOME/omniroute/`    | env var `XDG_CONFIG_HOME` |

### Faịlụ ndị dị na ndekọ data

| Faịlụ/Ndekọ          | Nkọwa                                                               |
| -------------------- | ------------------------------------------------------------------- |
| `storage.sqlite`     | Ebe nchekwa data bụ isi (ndị na-eweta ọrụ, ngwakọta, ntọala, igodo) |
| `storage.sqlite-wal` | Ndekọ SQLite write-ahead (nke nwa oge)                              |
| `storage.sqlite-shm` | Ebe nchekwa nkekọrịta SQLite (nke nwa oge)                          |
| `call_logs/`         | Ebe nchekwa payload arịrịọ                                          |
| `backups/`           | Ndabere ebe nchekwa data akpaka                                     |
| `log.txt`            | Ndekọ arịrịọ ochie (nhọrọ)                                          |

## Nyochaa na E wepụchara Ya kpamkpam

Mgbe i wepụchara ya, nyochaa na ọ dịghị faịlụ ọ bụla fọdụrụ:

```bash
# Lelee ma ngwugwu npm zuru ụwa ọnụ ọ̀ dị
npm list -g omniroute 2>/dev/null

# Lelee ma ndekọ data ọ̀ dị
ls -la ~/.omniroute/ 2>/dev/null

# Lelee ma e nwere usoro ndị na-arụ ọrụ
pgrep -f omniroute
```

Ọ bụrụ na usoro ọ bụla ka na-arụ ọrụ, kwụsị ya:

```bash
pkill -f omniroute
```
