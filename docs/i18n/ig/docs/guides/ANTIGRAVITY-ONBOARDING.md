## 1. Antigravity na Antigravity CLI (agy)

Ndị na-eweta ọrụ abụọ a na-eji **otu Google backend ahụ** — otu OAuth client, mmegharị token, endpoints, na akaụntụ Google. Ihe dị iche bụ ụdị ndị ị na-ahụ.

> Lee [ọkwa Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli) maka ntụnyere gọọmentị Google.

| Akụkụ                   | `antigravity` (IDE)                                               | `agy` (CLI)                                                           |
| ----------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------- |
| **Ngwaahịa Google**     | Antigravity 2.0 / Antigravity IDE                                 | Antigravity CLI                                                       |
| **Backend**             | Otu Google Cloud Code API ahụ                                     | Otu Google Cloud Code API ahụ                                         |
| **OAuth / Token**       | Otu client, otu mmegharị                                          | Otu client, otu mmegharị                                              |
| **Katalọgụ ụdị**        | Ndepụta ahọpụtara na-adịghị agbanwe agbanwe (OmniRoute hardcoded) | A na-enyocha ya ozugbo site na Google site na `:fetchAvailableModels` |
| **Ụdị Claude**          | Sonnet 4.6, Opus 4.6 (ụdịdị 4 nke ọ bụla)                         | Sonnet 4.6, Opus 4.6 (ụdịdị 4 nke ọ bụla)                             |
| **Ịkpọ Gemini aha**     | Aha ndị doro anya (Low/Medium/High)                               | Upstream IDs (extra-low/low/agent)                                    |
| **Ụdị ndị ọzọ**         | `gpt-oss-120b-medium`                                             | O nwere ike ịgụnye ụdị ndị ọzọ sitere na Google                       |
| **Ọnọdụ ojiji ndabere** | Njikọ IDE (VS Code, JetBrains)                                    | Ohere iji CLI / API                                                   |
| **Oke ojiji**           | A na-ekekọrịta ya na agy (otu akaụntụ Google ahụ)                 | A na-ekekọrịta ya na antigravity (otu akaụntụ Google ahụ)             |

**Ụdị ndị dị (nke nnwale kwadoro, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (ọkwa iche echiche dị iche iche)

**N'ọrụ n'ezie**: Jiri prefix `agy/` maka ụdị Gemini (dịka `agy/gemini-3.7-flash-high`). Jiri `antigravity/` maka ndepụta ahọpụtara na-adịghị agbanwe agbanwe. ## 3. Otu E Si Enweta projectId

Njikọ antigravity/agy ọ bụla chọrọ Google Cloud Code `projectId`. Na-enweghị ya, endpoint `/v1internal:models` na-eweghachi 404.

### Usoro A: Akpaka (Akwadoro)

OmniRoute na-eme nke a na-akpaghị aka. Mgbe ị gbakwunyere akaụntụ Google ọhụrụ site na Dashboard OAuth:

1. OmniRoute na-emegharị token ahụ
2. Ọ na-akpọ `loadCodeAssist` iji chọpụta projectId
3. Ọ bụrụ na project adịghị, ọ na-akpọ `onboardUser` iji mepụta otu
4. Ọ na-anwale `loadCodeAssist` ọzọ iji nweta projectId e mepụtara ọhụrụ
5. Ọ na-echekwa ya na database

**Nke a na-arụ ọrụ maka ọtụtụ akaụntụ** — enweghị usoro aka a chọrọ.

### Usoro B: Iji agy CLI Mee Ya N'Aka

Ọ bụrụ na nchọpụta akpaka ada (lee Nkebi 5 maka mgbe nke a na-eme):

```bash
# Wụnye agy CLI (ọ bụrụ na awụnyebeghị ya)
npm install -g @anthropic-ai/agy

# Jiri akaụntụ Google gị banye
agy login

# Họrọ akaụntụ chọrọ onboarding
# Nke a na-ebute ndebanye Cloud Code ma kenye projectId
```

Mgbe `agy login` gara nke ọma, mee ka token ahụ dị ọhụrụ na OmniRoute Dashboard. A ga-achọpụta projectId na-akpaghị aka.

### Otu E Si Nyochaa Ya

Lelee database:

```bash
# N'ime container OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Ma ọ bụ lelee logs:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. URI Ntụgharị OAuth

### Nsogbu Ahụ

Google OAuth chọrọ URI ntụgharị ziri ezi. Nke ndabara OmniRoute na-eji `http://127.0.0.1:20128/callback` (loopback). Nke a na-arụ ọrụ maka build mpaghara mana ọ **na-ada maka nnyefe dịpụrụ adịpụ** (dịka ọmụmaatụ, sava a na-enweta site na IP LAN).

Google na-ajụ URI ntụgharị ndị:

- Na-eji adreesị IP (ọ ga-abụrịrị ngalaba na-agwụ na `.com`, `.org`, wdg.)
- Na-adabaghị na URI ntụgharị ndị edebanyere aha na nhazi client OAuth

### Ngwọta Ya

**Nhọrọ A: Jiri usoro OAuth arụnyere n'ime ya (nke ndabara)**

- Ọ na-arụ ọrụ mgbe ị na-enweta OmniRoute site na `localhost` ma ọ bụ `127.0.0.1`
- Enweghị nhazi achọrọ

**Nhọrọ B: Ozi njirimara OAuth ahaziri iche**

- Tọọ `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` na environment gị
- Nye ozi njirimara Google OAuth nke gị:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Debanye `https://your-domain.com/callback` dịka URI ntụgharị enyere ikike na Google Cloud Console

**Nhọrọ C: Jiri agy CLI maka nbanye mbụ**

- Gbaa `agy login` na kọmputa ga-enweta OmniRoute
- Usoro OAuth ga-agwụcha na mpaghara ahụ, a ga-echekwa token
- Bubata njikọ ahụ n'ime OmniRoute site na Dashboard

### Mmachi

- Ozi njirimara OAuth ahaziri iche chọrọ aha ngalaba (Google anaghị anabata adreesị IP dịka URI ntụgharị)
- Ọ bụrụ na i nweghị ngalaba, jiri Nhọrọ A ma ọ bụ C kama

## 5. Nchọpụta na Ndozi Nsogbu: Mgbe Ntọlite Akpaka Dara

OmniRoute na-ejikwa ịchọpụta projectId na onboarding na-akpaghị aka maka ọtụtụ akaụntụ. Mgbe ọ dara, ihe kpatara ya na-abụkarị otu n'ime ihe ndị a:

### A gbochiri mpaghara akaụntụ ahụ

**Ihe mgbaàmà**: `agy login` na-eweghachi "Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location."

**Isi ihe kpatara ya**: Akaụntụ Google nwere oghere backend a na-akpọ "Country Association" nke a na-ahazi n'oge ndebanye aha. agy CLI na Cloud Code API na-enyocha oghere a nke ọma — n'adịghị ka Gemini webụ nke na-enyocha naanị IP gị ugbu a.

> Iji lelee ma ọ bụ gbanwee mpaghara e jikọtara na akaụntụ gị, gaa na [Google Country Association Form](https://policies.google.com/country-association-form).

**Ihe mere Gemini webụ ji arụ ọrụ mana agy anaghị arụ ọrụ**:

- Gemini webụ / Google One: na-enyocha naanị IP dị ugbu a (proxy na-agafe)
- agy CLI / Cloud Code API: na-agụ oghere Country Association dị na backend (proxy anaghị enyere aka)

**Ndozi**:

1. Gaa na [Google Country Association Form](https://policies.google.com/country-association-form) mgbe ị nọ na IP US
2. Nyefee arịrịọ mgbanwe mpaghara (họrọ "I live in a different country")
3. Chere awa 1-24 ka Google hazie ya + ọkwa email
4. Mgbe ahụ `agy login` kwesịrị ịga nke ọma

### Akaụntụ ahụ enweghị project Cloud Code

**Ihe mgbaàmà**: Logs na-egosi `loadCodeAssist returned no project id` na `onboardUser failed (400)`.

**Isi ihe kpatara ya**: Edebanyebeghị akaụntụ ahụ na Google Cloud Code, ntinye onboarding akpaka ahụ adakwara.

**Ndozi**: Jiri aka gbaa `agy login` iji kpalite ndebanye aha Cloud Code, wee mee token ahụ refresh na OmniRoute Dashboard.

### Token kubiela ma ọ bụ kagbuo

**Ihe mgbaàmà**: Njehie 401 na logs, ma ọ bụ ozi "Token has expired".

**Ndozi**: Mee token ahụ refresh na Dashboard → Providers → agy → Pịa akara refresh. Ọ bụrụ na a kagbuola refresh token ahụ n'onwe ya, ị ga-eji OAuth mee njirimara ọzọ.
