> **TOML bụ naanị usoro na-arụ ọrụ.** Codex ọgbara ọhụrụ na-agụ naanị
> `~/.codex/config.toml` (e jiri codex-cli 0.147.0 nyochaa ya: `codex --help`
> kọwara na `-c/--config` na-akagbu ntọala ndị “loaded from
> `~/.codex/config.toml`”). `~/.codex/config.yaml` ochie bụ nke npm CLI
> gara aga, a na-eleghara ya anya n’enweghị ọkwa ọ bụla. Ihe nrụpụta ntọala
> dị na dashboard (`/api/cli-tools/apply`, ngwá ọrụ `codex`) na-ede TOML site
> na njikọta akpachapụ anya — a na-echekwa keys ndị dịbu na blocks nke providers
> ndị ọzọ, API key na-anọgide na `OMNIROUTE_API_KEY` (ọ dịghị mgbe ọ na-abanye
> na faịlụ ahụ), a na-akọkwa `config.yaml` ochie fọdụrụ dịka ndetu migration
> n’emetụghị ya aka.

## config.toml dị njikere ka e detuo ma mado

Jiri ụkpụrụ nke gị dochie `<YOUR_HOST>` na `<YOUR_KEY>`:

```toml
# ~/.codex/config.toml
model                          = "cx/gpt-5.5"
model_provider                 = "omniroute"
model_reasoning_effort         = "xhigh"
model_context_window           = 400000
model_auto_compact_token_limit = 350000
tool_output_token_limit        = 32768    # oke nchekwa akụkọ ihe mere eme maka oku ngwá ọrụ ọ bụla

[model_providers.omniroute]
name                 = "OmniRoute"
base_url             = "http://<YOUR_HOST>:20128/v1"
env_key              = "OMNIROUTE_API_KEY"
requires_openai_auth = false
wire_api             = "responses"
```

```bash
# ~/.bashrc ma ọ bụ ~/.zshrc — ezigbo uru key, etinyela ya na config.toml
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

### macOS: Codex etinyere n’ime ngwa ChatGPT

Ọ bụrụ na i tinyere Codex site na ngwa desktop ChatGPT, `codex` binary nwere ike
ịdị naanị n’ime app bundle ma ọ gaghị adị na shell `PATH` gị. Tinye resources
directory na faịlụ mmalite shell gị:

```bash
export PATH="/Applications/ChatGPT.app/Contents/Resources:$PATH"
```

Mepee shell ọhụrụ, wee nyochaa ya:

```bash
command -v codex
codex --version
```

### OmniRoute mpaghara na-enweghị authentication: placeholder key ezuru

Codex na-enyocha na environment variable nke `env_key` kpọrọ aha dị
**tupu** arịrịọ mbụ apụ na CLI. Ọ bụrụ na instance OmniRoute **mpaghara** gị
achọghị auth, placeholder ọ bụla na-abụghị ihe efu ga-arụ ọrụ:

```bash
export OMNIROUTE_API_KEY="${OMNIROUTE_API_KEY:-local}"
```

Jiri ezigbo key kama nke ahụ mgbe e chebere server OmniRoute gị ma ọ bụ mgbe ọ dị n’ebe dị anya.

> **Nhọrọ host ndị a na-ejikarị**
>
> | Ụzọ nnweta       | URL                           |
> | ---------------- | ----------------------------- |
> | Netwọkụ mpaghara | `http://192.168.0.1:20128/v1` |
> | Tailscale        | `http://100.x.x.x:20128/v1`   |
> | Loopback         | `http://localhost:20128/v1`   |

## `wire_api = "responses"` — ihe mere o ji arụ ọrụ maka models niile

Codex CLI kwụsịrị ịkwado `wire_api = "chat"` (Chat Completions) na Febrụwarị 2026 ma ugbu a **na-achọ** `wire_api = "responses"` (OpenAI Responses API). Ịtọ `wire_api = "chat"` na-eme ka mmalite daa ozugbo kemgbe v0.138.

Ọtụtụ providers, gụnyere GLM na Kimi, ka na-enye naanị Chat Completions endpoint. DeepSeek V4 na-enyezi Responses API nke ya yana endpoint dakọtara na Anthropic; OmniRoute na-eji Responses dịka ndabara ma na-enye connection DeepSeek ọ bụla ohere ịhọrọ ndakọrịta Anthropic.

**OmniRoute na-edozi nke a n’ụzọ doro onye ọrụ anya:**

```
Codex CLI
  → wire_api = "responses"
  → POST /v1/responses (OmniRoute)
    → OmniRoute na-ahọrọ protocol nke provider ahụ ma na-atụgharị ya mgbe ọ dị mkpa
    → POST /responses (DeepSeek V4) ma ọ bụ /chat/completions (Mistral / GLM / Kimi / ndị ọzọ)
```

Ọ dịghị mgbe ị ga-achọ translation proxy dị iche mgbe ị na-eji OmniRoute. **Models niile na-eji `wire_api = "responses"`** — OmniRoute na-ahụ maka ihe ndị ọzọ.

> **`wire_api` bụ ndabara** — field ahụ na-eji `"responses"` dịka ndabara, a pụkwara iwepụ ya kpamkpam na `config.toml`. Tọọ ya kpọmkwem naanị ma ọ bụrụ na ị na-edekọ ebumnuche ahụ.

## Windo ọnọdụ na mkpakọ

### Oghere nhazi token

| Oghere                           | Nkọwa                                                                                                                                                                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model_context_window`           | Ngụkọta oke token maka model na-arụ ọrụ. Tọọ ya ka ọ bụrụ oke model ahụ kwupụtara.                                                                                                                                   |
| `model_auto_compact_token_limit` | Ọnụ ụzọ na-akpalite mkpakọ akụkọ ihe mere eme na-akpaghị aka. **Kachasị elu: 90% nke `model_context_window`** — a na-eleghara ụkpụrụ karịrị 90% anya na-enweghị ọkwa.                                                |
| `tool_output_token_limit`        | Oke token a na-echekwa maka nsonaazụ oku tool ọ bụla n'akụkọ ihe mere eme. Ọ na-egbochi otu nnukwu nzaghachi tool ijupụta na windo ahụ. **Nke a abụghị nsonaazụ kachasị elu** — ọ bụ oke nchekwa akụkọ ihe mere eme. |
| `compact_prompt`                 | Ntọgharị inline maka system prompt a na-eji mgbe a na-eme mkpakọ (v0.138+).                                                                                                                                          |

> **Nkọwa gbasara `model_max_output_tokens`**: Oghere a **abụghị akụkụ nke schema nhazi Codex CLI** (ọ dịghị na codebase Codex Rust). Ọ bụrụ na atọọ ya, a na-eleghara ya anya na-enweghị ọkwa. Atụkwasịla ya obi — jiri `tool_output_token_limit` chịkwaa oke nsonaazụ tool a na-echekwa n'akụkọ ihe mere eme.

## Mgbalị Ntụgharị Uche

Na-achịkwa ókè ụdịdị ahụ ga-eji “chee echiche” tupu ọ zaghachi.

| Uru      | Jiri ya maka                                          |
| -------- | ----------------------------------------------------- |
| `none`   | Enweghị ntụgharị uche — nzaghachi ozugbo              |
| `low`    | Ọrụ ndị dị mfe (ịgbanwe aha, ịhazi usoro)             |
| `medium` | **Ndabara sava** mgbe akọwapụtaghị ya                 |
| `high`   | Ọrụ etiti (imegharị koodu, ịchọta njehie)             |
| `xhigh`  | Nhazi ụlọ, nyocha miri emi, nsogbu ndị mgbagwoju anya |

```bash
# Gbanwee maka otu mkpọku
codex -c model_reasoning_effort=low "rename variable x to count"
codex -c model_reasoning_effort=xhigh "design the auth module"
```

Tọọkwa **nchịkọta** ntụgharị uche ka Desktop nwee ike igosipụta ederede echiche (ọ bụghị naanị ngwugwu ezoro ezo):

```toml
# ~/.codex/config.toml
model_reasoning_effort = "xhigh"   # ma ọ bụ ultra mgbe a na-akwado ya
model_reasoning_summary = "detailed"  # auto | concise | detailed | none
```

### Oke Echiche OmniRoute (ntọala sava)

N’elu igwe nnabata OmniRoute, **Settings → AI → Thinking Budget** ga-abụrịrị **`passthrough`** ka mgbalị/nchịkọta Codex ruo n’ọrụ dị n’elu. Ọnọdụ **`auto` strips** na-ewepụ oghere `reasoning` / `reasoning_effort` niile nke klayenti ma mee ka panel echiche tọgbọ chakoo ọbụna mgbe ahaziri Codex nke ọma.

Ntuziaka zuru ezu: [THINKING_BUDGET.md](./THINKING_BUDGET.md).

Mkpakọ na cache prompt anaghị adabere na nke a ma na-aga n’ihu ịrụ ọrụ n’okpuru `passthrough`.

## Profaịlụ — nhazi ndị a kpọrọ aha maka ụdịdị/usoro ọrụ ọ bụla

Profaịlụ na-enye gị ohere iji otu ọkọlọtọ gbanwee ụdịdị + windo context. Profaịlụ ọ bụla bụ faịlụ dị larịị
`~/.codex/<name>.config.toml` nke na-ekpuchi akụkụ nke `config.toml` bụ isi.

> **Iwu ịkpọ aha (Codex CLI v0.137+):** faịlụ ahụ ga-abụrịrị `~/.codex/<name>.config.toml` — **etinyela prefix `profile-`**.
> CLI na-atụgharị `-p kimi-k27` → `~/.codex/kimi-k27.config.toml`. Ọ bụrụ na ahụghị faịlụ ahụ, a ga-eji ndabara n’enweghị ọkwa ọ bụla.

```bash
codex --profile kimi-k27 "analyze 10k lines of this codebase"
codex -p glm52 "architecture review"
codex --profile deepseek-flash "rename variable"   # ngwa ngwa, dị ọnụ ala
```

## Ọrụ ndị na-ewe ogologo oge

Ndabara OmniRoute abụọ nwere ike imebi session Codex CLI na-ewe ọtụtụ awa n'enweghị ọkwa. Ọ dịghị nke ọ bụla n'ime ha bụ ntọala Codex CLI — ha abụọ dị n'akụkụ OmniRoute. Ndị ọrụ na-ebufe nhazi site na proxy upstream ndị na-ejikọ account n'otu ebe ma gbanyụọ nkwụsị n'ihi ịnọ nkịtị na-ezutekarị ha abụọ, wee kwubie na OmniRoute “enweghị ike idobe session ogologo oge.”

| Mgbaàmà                                                                              | Ihe nwere ike ịkpata ya                                                      | Ihe njikwa               |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- | ------------------------ |
| Session na-agbanwe account mgbe niile / a na-atụfu ịdịgide prompt-cache n'etiti turn | TTL nke session affinity bụ `0` (agbanyụrụ)                                  | `sessionAffinityTtlMs`   |
| Njikọ na-anwụ n'etiti reasoning n'enweghị prompt a na-egosi client                   | Stream idle watchdog malitere mgbe nkeji 10 gachara n'enweghị chunk upstream | `STREAM_IDLE_TIMEOUT_MS` |

Mkparịta ụka ndị metụtara ya: [#7126](https://github.com/diegosouzapw/OmniRoute/discussions/7126) (ọrụ ogologo na-akwụsị), [#5718](https://github.com/diegosouzapw/OmniRoute/discussions/5718) (ihe mere affinity ji bụrụ agbanyụrụ na ndabara). Nsuso: [#7287](https://github.com/diegosouzapw/OmniRoute/issues/7287).

### 1. Session affinity — jikọta otu mkparịta ụka na otu account

**Ndabara:** `sessionAffinityTtlMs = 0` (agbanyụrụ).

**Ebe a ga-etinye ya**

- Dashboard → **Settings → Routing** → **Session affinity** → **Affinity TTL (seconds)** (`ComboDefaultsTab`)
- Ma ọ bụ jiri PATCH hazie settings site na `sessionAffinityTtlMs` n'ime **milliseconds** (oke Zod `0`–`86_400_000`, ya bụ, ruo awa 24)

> A gbanwere aha ya na #7274 site na `codexSessionAffinityTtlMs` nke bụ naanị maka Codex. A ka na-anabata key ochie ahụ dịka alias a na-agụ naanị; nhazi ọhụrụ kwesịrị iji `sessionAffinityTtlMs`. Ugbu a, affinity na-emetụta provider **ọ bụla** ozugbo TTL karịrị `0`, ọ bụghị naanị Codex — lee [`docs/architecture/RESILIENCE_GUIDE.md`](../architecture/RESILIENCE_GUIDE.md) → Session affinity.

**Ihe na-emebi mgbe ọ nọgidere na 0**

A na-eme routing nke turn ọ bụla n'ime mkparịta ụka Codex nwere ọtụtụ turn n'onwe ya site na combo strategy na-arụ ọrụ, ọ nwekwara ike ịbanye na **account dị iche n'oge turn ọ bụla**. Nke ahụ na-emebi ịdịgide session / prompt-cache upstream. OmniRoute na-enyocha naanị header session Codex (`x-codex-session-id` / `x-session-id` / `x-omniroute-session`) na field body dịka `prompt_cache_key` / `session_id` mgbe TTL karịrị `0` (`extractSessionAffinityKey` n'ime `src/sse/services/auth.ts`).

**Ihe akwadoro maka otu ọrụ na-ewe ọtụtụ awa**

Tọọ TTL ka ọ dị **elu karịa ogologo oge wall-clock a tụrụ anya na ọrụ ahụ ga-ewe** (oke kachasị na UI bụ **sekọnd 86400** = awa 24):

| Ogologo oge ọrụ a tụrụ anya | Affinity TTL (UI, sekọnd) | `sessionAffinityTtlMs` |
| --------------------------- | ------------------------- | ---------------------- |
| Awa ole na ole              | `14400` (4h)              | `14400000`             |
| Abalị dum / ~12h            | `43200` (12h)             | `43200000`             |
| Otu ụbọchị zuru ezu         | `86400` (24h, kacha elu)  | `86400000`             |

Ịhọrọ ịgbanye ya bụ mkpebi e mere ụma: ịgbanyụ affinity na-akwado load-balancing n'etiti account; ịgbanye ya na-akwado ịdịgide maka otu session agent ogologo oge. Nduzi a **anaghị** agbanwe ndabara — ndị operator na-eme ọrụ Codex ogologo oge ga-ahọrọ ịgbanye ya.

### 2. Oge njedebe stream mgbe ọ nọ nkịtị — akwụsịla turn reasoning ndị dị jụụ

**Ndabara:** `STREAM_IDLE_TIMEOUT_MS = 600000` (nkeji 10). Ọ na-eketa site na `REQUEST_TIMEOUT_MS` mgbe a na-edoghị ya; baseline a na-ekekọrịta bụkwa 600000. Lee [`docs/guides/SETUP_GUIDE.md`](SETUP_GUIDE.md) → Oge njedebe.

**Ihe na-emebi na ndabara**

Ntugharị echiche / ngwá ọrụ Codex nke gbara nkịtị ihe karịrị nkeji 10 na-enweghị **ezigbo iberibe data si upstream** ga-emechi n’ike site na SSE idle watchdog (`open-sse/utils/stream.ts`). Onye ahịa na-ahụkarị naanị njikọ dara na-enweghị ozi ọ bụla — nke dabara na “kwụsịrị n’onwe ya na-enweghị ọkwa ọ bụla.”

Nkọwa dị oke mkpa: SSE **heartbeat** nke OmniRoute mepụtara anaghị eme ka elekere idle malitegharịa. Ọ bụ naanị ezigbo iberibe body si upstream na-emelite `lastChunkTime`. N’anya watchdog ahụ, model dị jụụ nke ka “na-eche echiche” yiri nnọọ upstream kwụsịrị ịzaghachi.

Oge enweghị ọrụ body nke Undici metụtara nke a: `FETCH_BODY_TIMEOUT_MS` (ọ na-eji otu ntọala mbụ nke nkeji 10; `0` na-agbanyụ ya). Maka streaming, `FETCH_TIMEOUT_MS` na-emetụta naanị nhazi njikọ / headers mbụ — ozugbo stream malitere ịrụ ọrụ, `STREAM_IDLE_TIMEOUT_MS` na `FETCH_BODY_TIMEOUT_MS` na-achịkwa nkwụsị.

**Ihe akwadoro maka otu task na-ewe ọtụtụ awa**

N’ime environment nke process OmniRoute (`.env` / compose / systemd):

```bash
# Gbanyụọ oke nkwụsị n'ihi stream idle na body inactivity maka ntụgharị echiche dị ogologo
STREAM_IDLE_TIMEOUT_MS=0
FETCH_BODY_TIMEOUT_MS=0
```

Ma ọ bụ bulie ha karịa oge ịgbachi nkịtị kachasị ogologo ị na-atụ anya ya (ụkpụrụ ndị a bụ milliseconds):

```bash
# Ọmụmaatụ: kwe ka ịgbachi nkịtị ruo awa 2 n'etiti iberibe data si upstream
STREAM_IDLE_TIMEOUT_MS=7200000
FETCH_BODY_TIMEOUT_MS=7200000
```

Malitegharịa OmniRoute mgbe ị gbanwechara env vars ndị a.

### Usoro doro anya — task Codex na-ewe ọtụtụ awa

1. **Kpọgide account ahụ:** Dashboard → Settings → Routing → Session affinity → Affinity TTL = `43200` (12h) ma ọ bụ `86400` (24h kachasị).
2. **Bulie / gbanyụọ oke idle** n’ime environment OmniRoute:

```bash
STREAM_IDLE_TIMEOUT_MS=0
FETCH_BODY_TIMEOUT_MS=0
```

3. Debe `config.toml` Codex a na-ejikarị (`wire_api = "responses"`, `base_url` ziri ezi, `OMNIROUTE_API_KEY`) — enweghị nhazi affinity/idle n’akụkụ Codex maka omume abụọ a.
4. Malitegharịa OmniRoute, wee malite task Codex ahụ dị ogologo.

### Mkpebi maka ndabara (#7287)

| Nhazi                    | Ndabara e wepụtara | Gbanwee ya na ntuziaka a?                                                                                     |
| ------------------------ | ------------------ | ------------------------------------------------------------------------------------------------------------- |
| `sessionAffinityTtlMs`   | `0` (agbanyụrụ)    | **Mba** — ọ ka bụ ihe a na-ahọrọ ịgbanye (load-balancing vs continuity; lee Discussion #5718)                 |
| `STREAM_IDLE_TIMEOUT_MS` | `600000` (10 min)  | **Mba** — ọ ka bụ nkeji 10 maka traffic izugbe; ndị na-ahụ maka Codex ogologo oge na-ebuli ma ọ bụ gbanyụọ ya |

Ịgbanwe nke ọ bụla n’ime ndabara ndị a n’ụwa niile ga-agbanwe omume maka onye ahịa ọ bụla nke instance ahụ, ọ bụghị naanị Codex. Detuo nhazi ndị ahụ n’akwụkwọ; hapụ ndabara ndị ahụ otu ha dị ruo mgbe mkpebi doro anya sitere n’aka operator kwuru ihe ọzọ.

### Ịchọpụta nkwụsị idle

Mgbe idle watchdog rụrụ ọrụ, OmniRoute na-edekọ ahịrị yiri nke a:

```text
[STREAM] Idle timeout: no data from codex for 600000ms (model: cx/gpt-5.5)
```

Jiri grep chọọ `Idle timeout: no data from` (ma ọ bụ code `stream_idle_timeout` / aha error `StreamIdleTimeoutError`). Akụkụ provider ahụ bụ ihe ọ bụla OmniRoute jiri maka request ahụ (`codex`, id provider ọzọ, ma ọ bụ `provider` ma ọ bụrụ na amaghị ya) — ọ bụghị mgbe niile ka ọ bụ kpọmkwem eriri `codex`.

## Nchọpụta na idozi nsogbu

**`Error: wire_api = "chat" is no longer supported`**
Wepụ `wire_api = "chat"` na nhazi gị. Tọọ `wire_api = "responses"` ma ọ bụ hapụ oghere ahụ (ọ na-eji `"responses"` na ndabara kemgbe v0.138).

**`Error: model not found`**
Nyochaa na model ahụ dị na OmniRoute ma nwee prefix ziri ezi. Jiri `omniroute models list` ma ọ bụ mepee `/dashboard/providers/<provider>`.

**`Authentication error`**
Kwenye na ebupụla `OMNIROUTE_API_KEY`: `echo $OMNIROUTE_API_KEY`.

**`ERROR: Missing environment variable: OMNIROUTE_API_KEY`**
Codex na-enyocha na env var ahụ dị tupu o zipụ arịrịọ mbụ. Bupụ
igodo n'ezie maka sava e chebere, ma ọ bụ placeholder na-abụghị ihe tọgbọ chakoo dịka
`OMNIROUTE_API_KEY=local` mgbe instance OmniRoute **local** gị anaghị
achọ nkwenye njirimara. Malitegharịa shell ma ọ bụrụ na ị gbakwunyere ya na `~/.bashrc` ma ọ bụ `~/.zshrc`.

**`Connection refused`**
Nyochaa na OmniRoute na-arụ ọrụ nakwa na host/port nke `base_url` ziri ezi maka netwọkụ gị (local vs Tailscale vs VPS).

**Session na-akwụsị na mberede mgbe ọ rutere nso oke context**
Tọọ `model_context_window` na `model_auto_compact_token_limit` kpọmkwem. Lee tebụl context window dị n'elu.

**Compaction na-amalite oge gafere**
Belata `model_auto_compact_token_limit` ruo 80–85% nke window ahụ. Etinyekwala ya karịa 90%.

**Profile anaghị ebunye (`-p <name>` ka a na-eleghara anya n'enweghị ozi)**
Kwenye na faịlụ ahụ dị na `~/.codex/<name>.config.toml` (enweghị prefix `profile-`). Gbaa `ls ~/.codex/*.config.toml`.

**Ọrụ Codex toro ogologo na-akwụsị n'etiti ya / na-agbanwe akaụntụ n'etiti turns**
Lee [Ọrụ na-ewe ogologo oge](#long-running-tasks). Kwado session affinity (TTL karịrị ogologo oge ọrụ ahụ) ma bulie ma ọ bụ gbanyụọ `STREAM_IDLE_TIMEOUT_MS` / `FETCH_BODY_TIMEOUT_MS`. Jiri grep chọọ `Idle timeout: no data from` n'ime log OmniRoute.
