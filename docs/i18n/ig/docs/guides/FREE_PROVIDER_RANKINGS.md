> **Nchịkọta dị mkpirikpi**: OmniRoute na-ahazi ndị na-enye ọrụ **n’efu** dịka ogo ụdị ha si dị site n’iji **akara ELO nke Arena AI
> (ụdị LMArena)**. Mepee ibe **Nhazi Ndị Na-enye Ọrụ N’efu** na
> dashboard ka ị hụ ndị na-enye ọrụ n’efu na-eweta ụdị kacha ike maka ọrụ gị —
> n’ozuzu, ma ọ bụ mgbe e nyochara ha dịka ngalaba si dị (ide koodu, ntụle, akwụkwọ nkọwa, ịchọpụta ma dozie njehie).

## Ihe Ọ Bụ

OmniRoute debanyere ndị na-enye ọrụ 329, gụnyere ndenye katalọgụ 155 e depụtara dịka **n’efu/anaghị achọ nkwenye njirimara**
(no-auth,
OAuth nke ọkwa efu, ma ọ bụ API key nke ọkwa efu — lee
[Ntuziaka Ọkwa Efefu](../getting-started/FREE-TIERS-GUIDE.md) na
[Ndepụta Ọkwa Efefu](../reference/FREE_TIERS.md) zuru ezu). Nsogbu bụ na: ogo ụdị nke ndị na-enye ọrụ n’efu
dịgasị nnọọ iche. Onye na-enye ọrụ na-achọghị nkwenye njirimara nke na-enye ụdị ọgbara ọhụrụ kacha elu bara uru karịa
onye na-enye obere ụdị ochie.

**Nhazi Ndị Na-enye Ọrụ N’efu** na-aza ajụjụ "**olee onye na-enye ọrụ n’efu na-enye m ụdị kacha mma?**" site
n’ijikọ katalọgụ onye na-enye ọrụ n’efu ọ bụla na **akara ogo sitere n’aka ìgwè mmadụ** site na
**bọọdụ ndị ndu Arena AI** (ELO nke dabere na nhọrọ mmadụ, otu echiche ahụ dị n’azụ ebe asọmpi chatbot
LMArena). A na-ahazi ndị na-enye ọrụ dịka ike nke **ụdị n’efu ha kacha mma** si dị.

A na-agbakọ nhazi ahụ site na isi mmalite atọ n’ezie:

1. Ndepụta ndị na-enye ọrụ n’efu — `NOAUTH_PROVIDERS`, tinyere ndenye `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` ndị nwere ọkọlọtọ `hasFree`
   (`src/shared/constants/providers.ts`).
2. Katalọgụ ụdị nke onye na-enye ọrụ ọ bụla sitere na ndekọ ndị na-enye ọrụ
   (`open-sse/config/providerRegistry.ts`).
3. Akara ndakọrịta ọrụ ewepụtara na ELO nke injin mmekọrịta Arena ELO na-echekwa na tebụl DB `model_intelligence`
   (`src/lib/arenaEloSync.ts`).

Usoro njikọta ahụ dị na `src/lib/freeProviderRankings.ts`.

## Otu E Si Enweta Ya

### Ibe dashboard

Mepee dashboard wee gaa na **Costs → Free Provider Rankings**, ma ọ bụ gaa ozugbo na:

```
/dashboard/free-provider-rankings
```

Ibe ahụ (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) na-egosi:

- **Ebe nrịgo atọ kacha elu** (🥇 🥈 🥉) nke ndị na-enye ọrụ n’efu kacha dị elu na nhazi.
- **Tebụl nhazi** zuru ezu nke nwere kọlụm ndị a: **Ọkwa**, **Onye Na-enye Ọrụ**, **Ụdị Kacha Elu**,
  **Akara**, **Nkezi Akara**, **Ụdị**, **Ụdị Ọrụ**.
- **Bọtịnụ nzacha ngalaba**: _Ngalaba Niile_, _Ndabara_, _Ide Koodu_, _Ntụle_,
  _Akwụkwọ Nkọwa_, _Ịchọpụta ma Dozie Njehie_.

Baajị **Ụdị Ọrụ** nke onye na-enye ọrụ ọ bụla na-agwa gị otu o si bụrụ n’efu:

| Baajị    | Ihe Ọ Pụtara                                        |
| -------- | --------------------------------------------------- |
| `NOAUTH` | Ọ bụ n’efu mgbe niile, achọghị ozi njirimara        |
| `OAUTH`  | Onye na-enye OAuth nke nwere ọkwa efu (`hasFree`)   |
| `APIKEY` | Onye na-enye API key nke nwere ọkwa efu (`hasFree`) |

A na-egosi akara dịka aha mmadụ nwere ike ịghọta (dịka _Kacha Elu_, _Magburu Onwe Ya_, _Dị Ezigbo Mma_,
_Ọma_, _Nkezi_) kama ọnụọgụ nkịtị, n’ihi na uru dị n’okpuru ya bụ ogo nhazi
e jiri tụnyere ibe ya, ọ bụghị pasent.

### Endpoint API

Endpoint ọgụgụ ọha na-akwado ibe ahụ
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Paramita ajụjụ (eji Zod kwado ha):

| Paramita   | Ụdị    | Ndabara   | Nkọwa                                                                                               |
| ---------- | ------ | --------- | --------------------------------------------------------------------------------------------------- |
| `category` | string | (ọ dịghị) | Otu n’ime `default`, `coding`, `review`, `documentation`, `debugging`. Wepụ ya maka nhazi ngwakọta. |
| `limit`    | number | `50`      | A kpaara ya na oke `1–100`.                                                                         |

Ọdịdị nzaghachi:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` bụ uru Arena ELO mbụ; `score` bụ uru ndakọrịta ọrụ e haziri ka ọ daba n’otu nha
(lee n’okpuru). A naghị etinye ndị na-enye ọrụ na-enweghị ụdị e nyere akara na nzaghachi ahụ.

## Otu Akara Ndị A Si Arụ Ọrụ

### Isi mmalite: bọọdụ ndị-isi Arena AI

Injin mmekọrịta Arena ELO (`src/lib/arenaEloSync.ts`) na-eweta bọọdụ ndị-isi abụọ — `text`
na `code` — site na API bọọdụ ndị-isi Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Ndenye ọ bụla na bọọdụ ndị-isi
nwere aha model, vendor, `score` ELO, etiti ntụkwasị obi, na ọnụọgụ votu.

Ụdịdị bọọdụ ndị-isi na-adaba na ụdịdị ọrụ OmniRoute:

| Bọọdụ ndị-isi Arena | Ụdịdị ọrụ OmniRoute                               |
| ------------------- | ------------------------------------------------- |
| `text`              | `default`, `review`, `documentation`, `debugging` |
| `code`              | `coding`                                          |

### Ịhazigharị (akara ndabara na ọrụ)

A na-ahazigharị akara ELO nke mbụ n'ime bọọdụ ndị-isi ọ bụla ka ọ bụrụ **uru ndabara na ọrụ dị na `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Akara ahụ anaghị eru `0` ma ọ bụ `1`, nke na-ahapụ ohere maka mgbanwe onye ọrụ. Nke a bụ
oghere `score` ị na-ahụ na nzaghachi API na akara aha e gosiri na dashboard.

### Ntụkwasị obi

Ndenye ọ bụla na-enweta ọkwa ntụkwasị obi dabere na ọnụọgụ votu Arena:

| Ntụkwasị obi | Votu    |
| ------------ | ------- |
| `high`       | ≥ 5,000 |
| `medium`     | ≥ 1,000 |
| `low`        | < 1,000 |

### Nchekwa na ịdị ọhụrụ

A na-ede ndenye ndị a hazigharịrị na tebụl DB `model_intelligence` na
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Ndenye **na-agwụ mgbe
ụbọchị 7 gachara**, ya mere provider kwụsịrị ime mmekọrịta ga-emecha pụọ kama inye
data ochie.

Mmekọrịta ahụ na-arụ ọrụ **na ndabara**:

- Ọ na-agba otu ugboro mgbe server malitere, ma mesịa na-agba site na timer oge n'ogologo
  (`src/lib/arenaEloSync.ts`, nke ejikọrọ site na `src/instrumentation-node.ts`).
- Ọ **anaghị egbochi ọrụ ma ọ dịghị mgbe ọ na-ebute ọdịda zuru ezu** — ọ bụrụ na iwetara data site n'isi mmalite adaa, OmniRoute ga-anọgide
  na-arụ ọrụ, ebe nhazi ọkwa ga-egosi naanị data ọma ikpeazụ (ma ọ bụ ọnọdụ efu).

Environment variables abụọ na-achịkwa ya (a kọwara ha na
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Variable                  | Ndabara       | Ebumnuche                                                |
| ------------------------- | ------------- | -------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Tọọ ya ka ọ bụrụ `false` iji kwụsị mmekọrịta na-apụ apụ. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | Ogologo oge n'etiti mmekọrịta, na sekọnd.                |

### Mmekọrịta aka / ọnọdụ / ihichapụ

Maka ndị na-ahụ maka sistemụ, endpoint njikwa e mere authentication na-enye njikwa aka
(`src/app/api/intelligence/sync/route.ts` — chọrọ management auth):

```
GET    /api/intelligence/sync          # ọnọdụ mmekọrịta ugbu a (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # kpalite mmekọrịta aka; body: { "dryRun": true } iji hụ ihe ga-eme tupu e dee ya
DELETE /api/intelligence/sync          # hichapụ ndenye intelligence arena_elo niile e mekọrịtara
```

Ọ bụrụ na ibe nhazi ọkwa tọgbọ chakoo, `POST /api/intelligence/sync` e ji aka mee (ma ọ bụ naanị
ịmalitegharị server) ga-ejupụta ya ọzọ.

### Ijikọta model na bọọdụ ndị-isi

Registry model IDs na aha model Arena anaghị adakọ mgbe niile. Nhazi ọkwa ahụ na-eji
ndakọrịta na-agbanwe agbanwe (`findMatchingIntelligence` na `src/lib/freeProviderRankings.ts`):

1. Ndakọrịta zuru oke na model ID a hazigharịrị.
2. Ndakọrịta mgbe e wepụchara suffix version dị n'azụ (dịka ọmụmaatụ `kimi-k2.6` → `kimi-k2`).
3. Ndakọrịta prefix (aha model dị na bọọdụ ndị-isi bụ prefix nke registry ID).

N'akụkụ mmekọrịta, a na-ewepụ prefix vendor ndị a maara (`anthropic/`, `openai/`, `google/`, …)
ma otu obere map alias na-agbasawanye aha canonical ka ọ bụrụ variant ndị OmniRoute na-eji
n'ime ya, ka e wee nwee ike ịchọta model n'okpuru aha ọ bụla.

### Otu e si ahazi provider n'ọkwa

Maka provider efu ọ bụla, injin ahụ na-enye model ọ bụla dị na catalog ya akara, wee:

- **Model Kachasị Elu** = model provider ahụ nwere akara kachasị elu.
- **Nkezi Akara** = nkezi akara nke model provider ahụ niile nwere akara.
- **Model** = ọnụọgụ model provider ahụ nwere akara Arena.

A na-ahazi provider site na **akara model kachasị elu** na mbụ, wee jiri nkezi akara. Nke a na-akwụghachi
provider nke na-enye opekata mpe otu model efu siri ike.

## Iji Ya Họrọ Ndị Na-enye Ọrụ n’Efu

1. **Họrọ ngalaba kwesịrị ekwesị.** Jiri nzacha **Coding** maka ọrụ ndị ejenti/koodu, ma ọ bụ
   hapụ ya na **All Categories** / **Default** maka mkparịta ụka izugbe. Otu onye na-enye ọrụ
   nwere ike ịnọ n’ọkwa dị iche iche n’etiti ngalaba n’ihi na ụdị kachasị mma ya na-adị iche n’otu leaderboard gaa n’ọzọ.
2. **Họrọ ndị nọ n’ọkwa atọ kachasị elu maka nhazi otu-ugboro.** Ọ bụrụ na naanị ihe ị chọrọ bụ ijikọ otu ma ọ bụ abụọ n’ime
   ndị na-enye ọrụ n’efu, malite na ndị nwere ọkwa kachasị elu na ngalaba gị.
3. **Lelee akara Type.** Ndị na-enye ọrụ `NOAUTH` bụ ndị kachasị ngwa ijikọ (enweghị
   ozi njirimara). Ọkwa efu nke `OAUTH` / `APIKEY` chọrọ ndebanye ngwa ngwa mana ha na-emekarị ka
   ụdị ndị ka ike dịrị gị. Lee [Ntuziaka Ọkwa Efu](../getting-started/FREE-TIERS-GUIDE.md) maka
   usoro njikọ.
4. **Jikọọ ọtụtụ ma hapụ Auto-Combo ka ọ kpebie.** Otu data Arena ELO ahụ na-akwado
   ibe a na-enyekwa **ihe ntụle ndabara ọrụ** nke injin inye akara Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, usoro mkpebi
   `user_override → arena_elo → models_dev_tier → static table`). Ya mere, mgbe i jikọchara
   ndị na-enye ọrụ n’efu kachasị elu, ntụgharị ụzọ site na `model: "auto"` (dịka `auto/coding`) ga-
   ahọrọ ụdị efu ndị ka mma na-akpaghị aka maka arịrịọ ọ bụla. Lee
   [Auto-Combo](../routing/AUTO-COMBO.md) maka usoro inye akara nwere ihe ntụle 16 zuru ezu.
