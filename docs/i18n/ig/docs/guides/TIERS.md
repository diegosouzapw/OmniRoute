OmniRoute na-ahazi ndị na-eweta ọrụ 352 ọ na-akwado n'ọkwa akụ na ụba 3. Arịrịọ ọ bụla na-agafe ha n'usoro ruo mgbe otu n'ime ha zaghachiri nke ọma — ị ga-enweta nzaghachi kachasị ọnụ ala nke na-arụ ọrụ n'edeghị koodu ndabere ọ bụla.

## Ọkwa 1 — Ndebanye aha

**Ndị na-eweta ọrụ ị na-akwụlarị ụgwọ ha.** OmniRoute na-eji oke ọrụ gị niile tupu oge ya agwụ.

| Onye na-eweta ọrụ                   | Ihe kpatara Ọkwa 1                                      |
| ----------------------------------- | ------------------------------------------------------- |
| Claude Code OAuth                   | Anthropic Pro/Team — ọnụahịa kwụ ọtọ, anaghị ejikarị ya |
| OpenAI Codex (ndebanye aha ChatGPT) | Plus/Team gụnyere oke Codex                             |
| GitHub Copilot                      | Kwa oche — oke ahụ na-amalitegharị kwa ọnwa             |
| Cursor IDE                          | Oke atụmatụ Pro                                         |
| Antigravity / Devin Desktop         | Oke arụnyere n'ime ya                                   |

**Atụmatụ**: buru ụzọ duzie arịrịọ ọ bụla dabara n'ike ụdị ahụ n'ebe a. Ihe nleba anya oke na-enyocha oge mmalitegharị na-abịaru nso, ebe atụmatụ ngwakọta `reset-aware` na-enye ha mkpa dịka o kwesịrị. Iji buru ụzọ duzie n'Ọkwa 1 ma gafee naanị n'ọkwa ndị a na-akwụ ụgwọ mgbe oke gwụrụ, jiri id `auto/thrifty` — ma ọ bụ `auto/subscription` iji nọgide n'ikike atụmatụ ahụ gụnyere ma mechie mgbe ọ dara kama. Lee
[Ndúgharị na-ebute ndebanye aha ụzọ](../routing/SUBSCRIPTION_LADDER.md).

## Ọkwa 2 — Dị ọnụ ala

**Ndị na-eweta ọrụ a na-akwụ kwa token nke na-erughị $1/1M tokens.** E debere ha maka ọrụ buru ibu ma ọ bụ mgbe oke Ọkwa 1 ruru njedebe.

| Onye na-eweta ọrụ                 | Ọnụahịa (ntinye/mmepụta) | Ike                          |
| --------------------------------- | ------------------------ | ---------------------------- |
| DeepSeek V4 Pro                   | $0.27 / $1.10 kwa 1M     | Koodu, ntụgharị uche         |
| GLM-4.5                           | $0.60 / $2.20 kwa 1M     | Ọnọdụ ogologo                |
| MiniMax M1                        | $0.20 / $1.10 kwa 1M     | Ọsọ                          |
| Qwen Coder                        | $0.30 / $1.20 kwa 1M     | Koodu                        |
| OpenRouter (ahaziri maka ọnụahịa) | na-agbanwe               | Ụdị 100+, na-agbanwe agbanwe |

**Atụmatụ**: ngwakọta `cost-optimized` na-ahọrọ ụdị nwere $/token kacha ala nke na-emezu nzacha ikike ọrụ ahụ (ọhụụ, ọnọdụ JSON, ngwaọrụ, ọnọdụ kachasị ogologo).

## Ọkwa 3 — N'efu

**Ndị na-eweta ọrụ na-enweghị ụgwọ** — ọkwa efu, mmemme kredit, oke OAuth kwa ụbọchị.

| Onye na-eweta ọrụ | Oke efu / kredit                            |
| ----------------- | ------------------------------------------- |
| Kiro AI           | Ọkwa Claude efu (ojiji ziri ezi buru ibu)   |
| OpenCode Free     | Enweghị nkwenye njirimara, oke ọsọ buru ibu |
| Qoder             | OAuth efu                                   |
| Google Vertex AI  | Kredit $300 maka akaụntụ ọhụrụ              |
| Amazon Q          | Ọkwa efu maka ndị ọrụ AWS                   |
| Pollinations      | API ọha mepere emepe                        |
| Cloudflare AI     | Ọkwa efu Workers AI                         |

**Atụmatụ**: ngwakọta `auto` nwere oke mmefu na-eduga arịrịọ n'ebe a mgbe Ọkwa 1+2 dara ma ọ bụ mgbe edobere `useFreeOnly=true`. Ndị na-eweta ọrụ efu na-enwekarị oke ọsọ adịghị ike — circuit breaker na-eweghachi ha mgbe oge nchere gasịrị.

## Ịhazigharị ọkwa

Dashboard → **Ọkwa** → kenye ndị na-eweta ọrụ gị. Ntọala ndabara (sitere na `tierDefaults.json`) dabara adaba; dezie ha mgbe i nwere ndebanye aha ụfọdụ ịchọrọ ibute ụzọ ma ọ bụ ndị na-eweta ọrụ ịchọrọ iwepụ.

Ntụle ihe 16 nke Auto-Combo na-atụlekwa ọkwa. Lee
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetry

Dashboard → **Ojiji** na-egosi tokens e mefuru kwa ọkwa kwa ụbọchị. Jiri nke a mee ihe ndị a:

- Gbaa mbọ hụ na a na-eji Ọkwa 1 eme ihe n'uju (ma ọ bụghị ya, ị na-emefusị uru ndebanye aha)
- Chọpụta ụdị Ọkwa 2 ndị a na-ahọrọkarị (chịkọta ha ka ha bụrụ 1-2)
- Nyochaa na Ọkwa 3 na-echekwa ego n'ọrụ nnwale/nyocha

## Ụkpụrụ ndị a na-ahụkarị

### Ọrụ efu kpamkpam

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Na-akwalite nke ukwuu n'Ọkwa 3; ọ na-eji naanị Ọkwa 2 ma ọ bụrụ na Ọkwa 3 adịghị.

### Ndebanye aha ụzọ, yana ndabere dị ọnụ ala

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Ndepụta doro anya ahaziri n'usoro kwekọrọ na Ọkwa 1 → Ọkwa 2 → Ọkwa 3.
