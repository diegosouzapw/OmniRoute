sava MCP na ntuziaka ahaziri iche niile ka na-arụ ọrụ, naanị na ha na-agba ọsọ na model ị họọrọ.

## Nhazi

1. **Gbaa OmniRoute** — `npm install -g omniroute && omniroute` (dashboard dị na `http://localhost:20128`).
2. **Wụnye extension ahụ** — chọọ "OmniRoute" na nlele Extensions.
3. **Họrọ model** — Copilot Chat → ihe nhọpụta model → **Manage Models…** → **OmniRoute**, wee kaa
   ihe ndị ị chọrọ.

Ọ dịghị ihe a ga-ahazi mgbe OmniRoute na-agba ọsọ na port ndabara. Maka instance dị anya, mepee
**akara ngosi OmniRoute na Activity Bar** (ma ọ bụ gbaa `OmniRoute: Manage Connection`) ma tọọ:

- **URL sava** — mgbọrọgwụ sava ahụ, dịka `http://192.168.0.15:20128`. Extension ahụ na-agbakwunye
  suffix `/v1`; etinyela ya.
- **Igodo API** — naanị mgbe sava ahụ tọrọ `REQUIRE_API_KEY`. A na-echekwa ya na keychain OS site na VS
  Code SecretStorage, ọ dịghị mgbe a na-echekwa ya na `settings.json`.

## Ihe ihe nhọpụta ahụ ga-egosi

Extension ahụ anaghị egosi payload `GET /v1/models` dịka ọ dị — ọ na-ahazi ya, ọnụ ọgụgụ ị
na-ahụ dịkwa ala karịa nha catalog ahụ n’ihi ihe abụọ e kpachapụrụ anya mee.

### Ọ na-arịọ otu id maka model ọ bụla

`MODELS_CATALOG_PREFIX_MODE` na-eji **`dual`** dịka ndabara, nke na-akpọsa model ọ bụla ugboro abụọ — otu ugboro
n’okpuru prefix alias dị mkpụmkpụ na otu ugboro n’okpuru prefix canonical nke provider — ka nhazi client
ochie wee nwee ike ịchọta ụdị nke ọ bụla:

```
cc/claude-sonnet-4-6        ← prefix alias
claude/claude-sonnet-4-6    ← prefix canonical, otu model ahụ
```

Extension ahụ na-arịọ **`GET /v1/models?prefix=alias`** ka otu id bịarute maka model ọ bụla, n’ebughị
ntọala sava niile maka client ndị ọzọ gị. Na instance e ji atụnyere, nke a belatara
**ndekọ 2345 ruo 1396 — oyiri 949, ọ dịghị model furu efu.**

Ọ bụrụ na ị ga-ahọrọ idozi ya n’ogo sava niile maka client _ọ bụla_, tọọ feature flag
`MODELS_CATALOG_PREFIX_MODE` ka ọ bụrụ `alias` na dashboard. Lee
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) maka
query parameter na tebụl nke ọnọdụ ọ bụla.

### Ọ na-ezo model ndị na-enweghị ike ịkparịta ụka

Catalog ahụ na-edekwa model image, video, audio, rerank, embedding na moderation. A ga-ajụkwa
ndị ahụ na arịrịọ nkata:

```
HTTP 400 — Model '<id>' bụ model na-emepụta image, enweghịkwa ike iji ya na
/v1/chat/completions. Jiri POST /v1/images/generations kama.
```

ya mere, a na-eji field `type` ha wepụ ha tupu ha erute n’ihe nhọpụta ahụ. **A na-edobe model
Responses-API** — ndekọ Codex / GPT-5.x ọ bụla na-akpọsa `supported_endpoints: ["responses"]`,
OmniRoute na-atụgharịkwa ndị ahụ maka `/v1/chat/completions`, ya mere enwere ike iji ha nke ọma.

### Provider ndị ị na-ahazibeghị

Catalog ahụ na-edepụta model sitere na provider nwere **njikọ na-arụ ọrụ** _yana_ provider **noAuth**
niile — ndị na-achọghị igodo nke mejupụtara ọtụtụ n’ime ọkwa efu. E mere nke ahụ ụma. Iji zoo
ha, tinye ha na `blockedProviders` na ntọala dashboard; ọ dịghị ihe na-agbanwe na
extension ahụ.

## Dashboard dị n'ime taabụ VS Code

`omnicopilot.dashboardOpen: "editor"` na-egosipụta dashboard OmniRoute n'ime taabụ edita site na
Simple Browser kama iji ihe nchọgharị mpụga. Ịtinye ya n'ime edita bụ **nhọrọ a ga-agbanye na sava** site na
`DASHBOARD_ALLOW_EMBED=vscode`, nke na-ewepụta ibe HTML nwere
`frame-ancestors 'self' vscode-webview:` kama ndabara `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Akụkụ API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) ka na-eji
nkụnye isi ndị siri ike n'agbanyeghị usoro e ji mee ya.

> ⚠️ **Ọ bụ ọkọlọtọ oge-build, ọ bụghị nke oge-runtime.** Next.js na-achịkọta `headers()` n'ime route
> manifest, ya mere `next.config.mjs` na-agụ mgbanwe ahụ mgbe a na-ewu bundle ahụ
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Izipụ ya n'ihu sava e wurula agaghị agbanwe ihe ọ bụla — e tinyelarị nkụnye isi ndị ahụ n'ime ya.

```bash
# mgbanwe ahụ ga-adịrịrị na iwu BUILD
DASHBOARD_ALLOW_EMBED=vscode npm run build        # ma ọ bụ npm run build:release
npm start
```

| Otu i siri wụnye ya        | Ị nwere ike ịgbanye ntinye n'ime edita?                                                                                                 |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Site na source             | ✅ tọọ mgbanwe ahụ n'iwu build, dịka e gosiri n'elu                                                                                     |
| `npm install -g omniroute` | ❌ package e bipụtara nwere bundle e wurula — kama nke ahụ, wuo ya site na source                                                       |
| Image Docker               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — image e wurula na Docker Hub anaghị akwado ntinye ahụ |

Ọ bụrụ na build anaghị akwado ntinye ahụ, ibe ahụ agaghị ekwe ka e tinye ya n'ime frame; extension ahụ ga-achọpụta nke a site na
nkụnye isi nzaghachi wee laghachi n'iji ihe nchọgharị mpụga — ọ dịghị ihe ga-emebi, ọ ga-ekwukwa ya otu ugboro.
Lee [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) na issue
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).
