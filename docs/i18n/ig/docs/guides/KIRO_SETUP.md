Ntuziaka a na-akọwa otu esi etinye akaụntụ Kiro (onye enyemaka ide koodu AI nke AWS na-akwado) na OmniRoute,
na-elekwasị anya n’iji ọtụtụ akaụntụ n’otu oge na-enweghị esemokwu nnọkọ.

---

## Ndabere: Ihe Mere Akaụntụ Kiro Ji Enwe Esemokwu

Backend Kiro na-eji ndebanye AWS SSO OIDC client eso nnọkọ ndị na-arụ ọrụ.
Ihe mgbochi dị mkpa bụ: **ndebanye OIDC client ọ bụla na-akwado naanị otu nnọkọ
na-arụ ọrụ n’otu oge**. Mgbe ngwaọrụ ma ọ bụ onye ọrụ nke abụọ jiri otu
client ahụ edebanyere aha mee nkwenye njirimara, backend ahụ na-eme ka refresh token nke akaụntụ mbụ ghara ịdị irè.

Nke a bụ otu usoro ahụ na-ebute nsogbu mgbe a na-agba `kiro-cli login` na
igwe ebe akaụntụ Kiro ọzọ abanyelarị — nbanye ọhụrụ ahụ na-akagbu token nke
akaụntụ mbụ.

---

## Otu OmniRoute Si Edozi Nke A (v3.8.0+)

Malite na v3.8.0, OmniRoute na-akpọ `registerClient()` (AWS SSO OIDC) n’oge mbubata
njikọ Kiro ọ bụla. Nke a na-enye njikọ OmniRoute ọ bụla ndebanye OIDC
client nke ya. Ebe ndebanye client ọ bụla nọọrọ onwe ya, imegharị ma ọ bụ
ime nkwenye njirimara ọzọ n’otu akaụntụ anaghị emetụta refresh token nke akaụntụ ọzọ.

Nkewapụ a metụtara usoro mbubata refresh-token, ebe nkwenye API-key na-ezere
nnọkọ ume ọhụrụ OIDC kpamkpam:

| Usoro mbubata                                  | Ọnọdụ nkewapụ                                                                                        |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| AWS Builder ID / Usoro device-code IDC         | E kewapụrụ ya kemgbe e webatara usoro device-code                                                    |
| **Import Token** (iji aka mado refresh token)  | E kewapụrụ ya malite na v3.8.0                                                                       |
| **Nbanye mmekọrịta Google / GitHub**           | E kewapụrụ ya malite na v3.8.0                                                                       |
| **Auto-Import** (kiro-cli SQLite)              | E kewapụrụ ya malite na v3.8.0 (ụzọ SQLite kewapụrụlarị; usoro ndabere SSO-cache kewapụkwara ugbu a) |
| **API Key** (igodo CodeWhisperer na-adịte aka) | Enweghị nnọkọ ume ọhụrụ; a na-enyocha igodo ahụ ma chekwaa ya dịka nzere bearer                      |

## Nkọwa Mbugharị Maka Njikọ E Mepụtara Tupu v3.8.0

Njikọ ndị e bubatara tupu v3.8.0 enweghị ndebanye OIDC client nke ha
e debere na `providerSpecificData`. Njikọ ndị a ka na-arụ ọrụ mana ha na-eji endpoint
ume ọhụrụ social-auth a na-ekekọrịta, nke pụtara na njikọ abụọ dị otu a ka nwere ike ime ka
nke ibe ha ghara ịdị irè.

**Iji nweta nkewapụ:** hichapụ njikọ ochie ahụ na **Dashboard → Providers** ma
bubata ya ọzọ site n’iji usoro mbubata ọ bụla a na-akwado. Njikọ ọhụrụ niile a mepụtara ga-
enweta ndebanye client nke ha na-akpaghị aka.

## Ịtinye Akaụntụ Kiro Abụọ N’akụkụ Ibe Ha

### Ihe Ndị Dị Mkpa Tupu Amalite

- OmniRoute v3.8.0 ma ọ bụ nke ka ọhụrụ.
- Akaụntụ Kiro na-arụ ọrụ (email + okwuntughe, Google, ma ọ bụ nbanye GitHub).
- Akaụntụ Kiro nke abụọ ma ọ bụrụ na ịchọrọ.

### Nzọụkwụ 1: Bubata akaụntụ mbụ

1. Mepee **Dashboard → Providers → Add Provider → Kiro**.
2. Họrọ otu n’ime ndị a:
   - **Import Token** — mado refresh token nke na-amalite na `aorAAAAAG`.
   - **API Key** — mado API key Kiro / CodeWhisperer na-adịte aka.
   - **Nbanye Google / GitHub** — mezue usoro OAuth na ihe nchọgharị.
   - **Auto-Import** — pịa bọtịnụ ahụ; OmniRoute ga-agụ nzere site na
     nchekwa data kiro-cli dị na mpaghara ma ọ bụ `~/.aws/sso/cache`.
3. A na-echekwa njikọ ahụ. Usoro refresh-token na-edebanye OIDC
   client pụrụ iche na-akpaghị aka. Usoro API-key na-eji AWS enyocha igodo ahụ ma ha anaghị echekwa refresh token.

### Nzọụkwụ 2: Bubata akaụntụ nke abụọ

Tinyegharịa nzọụkwụ 1 maka akaụntụ nke abụọ. Ebe mbubata ọ bụla na-emepụta ndebanye OIDC
client dị iche, njikọ abụọ ahụ kewapụrụ kpamkpam.

### Nzọụkwụ 3: Nyochaa na njikọ abụọ ahụ na-arụ ọrụ

1. **Dashboard → Providers** — njikọ Kiro abụọ ahụ kwesịrị igosi ọnọdụ **Active**.
2. **Dashboard → Health** — njikọ abụọ ahụ kwesịrị ịgafe nyocha ahụike token ha.

### Nzọụkwụ 4: Jiri combo hazie ụzọ n’etiti akaụntụ

Mepụta combo nke nwere njikọ abụọ ahụ dịka ebe a ga-eziga arịrịọ iji kesaa ibu ma ọ bụ jiri otu dochie nke ọzọ ma ọ daa:

```
kiro/kiro-dev → kiro/kiro-pro
```

Lee [FEATURES.md](./FEATURES.md) na akwụkwọ ntuziaka nhazi ụzọ maka nhazi combo.

## Ndị Ọrụ Enterprise / IDC

Maka akaụntụ AWS IAM Identity Center (IDC), jiri usoro **AWS Builder ID / IDC device-code**
nke dị na **Dashboard → Providers → Kiro → Device Code**. Usoro device-code ahụ adịla
iche kpamkpam mgbe niile. Ọ dịghị mkpa ibubata njikọ ndị a ọzọ.

Ndị ọrụ Enterprise na-eji mpaghara AWS na-abụghị nke ndabara nwere ike ịkọwapụta mpaghara ahụ mgbe
ha na-eji Import Token API ebubata:

```bash
curl -X POST http://localhost:20128/api/oauth/kiro/import \
  -H "Content-Type: application/json" \
  -d '{"refreshToken": "aorAAAAAG...", "region": "eu-west-1"}'
```

Ọ bụrụ na ahapụrụ oghere `region`, uru ndabara ya bụ `us-east-1`.

## Usoro Mbubata API-Key

Nkwenye API-key bụ maka nzere bearer Kiro / AWS CodeWhisperer na-adịte aka. Ọ naghị
eji mmelite OAuth, ya mere ọ na-ezere imebi session OIDC a na-ekekọrịta.

### Dashboard

1. Mepee **Dashboard -> Providers -> Kiro**.
2. Họrọ **API Key**.
3. Mado API key ahụ na mpaghara AWS nhọrọ (`us-east-1` bụ ndabara).
4. OmniRoute na-enyocha key ahụ ma chekwaa njikọ ahụ.

### API

```bash
curl -X POST http://localhost:20128/api/oauth/kiro/api-key \
  -H "Content-Type: application/json" \
  -d '{"apiKey": "kiro_or_codewhisperer_key", "region": "us-east-1"}'
```

### Nkwekọrịta Ime

Ụzọ API ahụ na-enyocha key ahụ site n'ịkpọ `KiroService.validateApiKey()`, nke
na-eji `ListAvailableProfiles` megide endpoint CodeWhisperer/Amazon Q dabara na mpaghara ahụ
ma chọpụta `profileArn`.

Njikọ echekwara na-eji:

```json
{
  "authType": "apikey",
  "providerSpecificData": {
    "authMethod": "api_key",
    "region": "us-east-1",
    "profileArn": "arn:aws:codewhisperer:..."
  }
}
```

Mgbe usoro ahụ na-arụ ọrụ, `KiroExecutor.buildHeaders()` na-eziga key ahụ dị ka
`Authorization: Bearer <key>` ma tinye `tokentype: API_KEY`. Oku quota/profile
na-eji otu akara ahụ ka AWS wee were bearer ahụ dị ka API key na-adịte aka kama
token nnweta OIDC ma ọ bụ nke social.

## Mmebi Oge nke OIDC Client

Ndị client ọha nke AWS SSO OIDC na-emebikarị mgbe ụbọchị 90 gachara
(`clientSecretExpiresAt`). OmniRoute na-echekwa timestamp a na `providerSpecificData`
maka nlekọta. Ọ bụrụ na njikọ akwụsị imelite mgbe ihe dị ka ụbọchị 90 gachara, bubata
njikọ ahụ ọzọ iji nweta ndebanye OIDC client ọhụrụ. A na-edekọ ndebanye ọhụrụ akpaka
mgbe oge gwụsịrị dịka mmelite a ga-eme n'ọdịnihu.

Njikọ API-key enweghị mmebi oge OIDC client n'ihi na ha anaghị emelite
site na AWS SSO OIDC.

## Ịdozi Nsogbu

### Akaụntụ nke abụọ na-aga n'ihu na-apụ na sistemụ

- Lelee njikọ abụọ ahụ na **Dashboard → Providers** ma gosi na nke ọ bụla nwere
  `clientId` na-abụghị null na JSON raw ya (a na-ahụ ya site na akara info). Ọ bụrụ na otu njikọ enweghị
  `clientId`, e bubatara ya tupu v3.8.0 — bubata ya ọzọ.

### Mbubata dara na "Nnyocha token dara"

- Gbaa mbọ hụ na refresh token ahụ na-amalite na `aorAAAAAG`.
- Gbaa mbọ hụ na OmniRoute nwere ike iru `https://oidc.us-east-1.amazonaws.com` (ma ọ bụ mpaghara
  ahaziri). Ọ bụrụ na ị nọ n'azụ proxy ụlọ ọrụ, tọọ proxy ọkwa provider na
  **Dashboard → Settings → Proxies**.

### Mbubata API-key dara

- Gosi na key ahụ bụ API key Kiro / CodeWhisperer, ọ bụghị refresh token.
- Gosi na mpaghara AWS dabara na key/akaụntụ ahụ. `us-east-1` bụ ndabara.
- Key ahụ ga-enwerịrị ike ịkpọ `ListAvailableProfiles`; ma ọ bụghị ya, OmniRoute agaghị enwe ike
  ịchọpụta `profileArn` achọrọ.

Maka nsogbu ndị ọzọ, lee [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) bụ isi.
