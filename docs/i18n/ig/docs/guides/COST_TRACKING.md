## Ihe ọ bụ (na ihe ọ na-abụghị)

OmniRoute na-enye mmecha ọ bụla ọnụ ahịa USD kwa arịrịọ site n'ịmụba ọnụọgụ token
na ọnụego ọnụahịa model. Ọnụọgụ ndị a na-akwado dashboard **Ọnụ Ahịa**, CLI
`omniroute cost` / `omniroute usage`, mbupụ CSV/JSON, na mmefu ego kwa API key.

> **"Ọnụ ahịa" dị na dashboard bụ ihe na-enyocha ego echekwara, ọ bụghị ụgwọ.** OmniRoute anaghị ana gị
> ego — ọ na-ebuga arịrịọ gị na ndị provider ị jikọrọla (subscription nke gị,
> free tier, na API key). “Ọnụ ahịa zuru ezu nke $290” nke gbakọtara kpamkpam site na model efu
> pụtara ihe dịka **$290 ị _na-akwụghị_ API a na-akwụ ụgwọ**. Ọnụọgụ ahụ bụ _atụmatụ_
> nke ego otu traffic ahụ gaara eri n'ọnụahịa ndepụta nkịtị, ka ị nwee ike ịhụ ebe
> ojiji gị kacha gbakọta na ego ole iziga ya na provider dị ọnụ ala/efu na-echekwara gị.

E kwuru nkọwa a ozugbo na [README](../../README.md) nke project ahụ (“'ọnụ ahịa' dị na dashboard
bụ ihe na-enyocha ego echekwara, ọ bụghị ụgwọ”).

N'ihi na ọnụọgụ ahụ bụ atụmatụ:

- Ọ dabere na tebụl ọnụahịa OmniRoute nwere maka model ọ bụla. Model na-enweghị ndekọ ọnụahịa
  na-etinye ọnụ ahịa `0` (ọ na-apụta dị ka ahịrị “Legacy / Free” n'ime explorer).
- Traffic nke free-tier na subscription ka na-agbakọta ọnụ ahịa _atụpụtara_ — nke ahụ bụ
  ego ị na-echekwa, ọ bụghị ego i ji akwụ.

## Otu e si atụpụta ọnụ ahịa

### Isi mmalite ọnụahịa

Ọnụ ahịa na-abịa site na tebụl ọnụahịa a na-ahọrọ n'usoro mkpa a
([`src/lib/pricingSync.ts`](../../src/lib/pricingSync.ts)):

1. **Mgbanwe onye ọrụ** — ọnụahịa ndị ị debere na dashboard / site na `PATCH /api/pricing`.
2. **Ọnụahịa mpụga emekọrịtara** — nke a na-eweta site na LiteLLM public
   `model_prices_and_context_window.json` mgbe agbanyere mmekọrịta (a na-echekwa ya n'ime namespace
   `pricing_synced` dị iche ka ọ ghara idechi mgbanwe gị).
3. **Ntọala etinyere kpọmkwem** — nke so OmniRoute abịa.

Mmekọrịta ọnụahịa mpụga bụ **opt-in**, a gbanyụrụ ya na ndabara. Env var ndị metụtara ya
(hụ [`.env.example`](../../.env.example)):

| Env var                 | Ndabara   | Ebumnuche                                                                |
| ----------------------- | --------- | ------------------------------------------------------------------------ |
| `PRICING_SYNC_ENABLED`  | `false`   | Gbanwuo mmekọrịta ọnụahịa LiteLLM n'azụ mgbe mmalite.                    |
| `PRICING_SYNC_INTERVAL` | `86400`   | Oge etiti mmekọrịta n'ime **sekọnd** (ndabara bụ kwa ụbọchị).            |
| `PRICING_SYNC_SOURCES`  | `litellm` | Ndepụta isi mmalite e kewara na comma (naanị `litellm` ka akwadoro taa). |

### Usoro mgbako ọnụ ahịa

A na-agbakọ ọnụ ahịa kwa arịrịọ site na ọnụọgụ token na ọnụego kwa nde token dị na
[`src/lib/usage/costCalculator.ts`](../../src/lib/usage/costCalculator.ts)
(`computeCostFromPricing` / `calculateCost`):

- **Input token** (ewepụrụ cache read na token imepụta cache) × ọnụego `input`.
- **Cache-read token** × ọnụego `cached` (ọ bụrụ na ọ dịghị, ọ na-eji ọnụego input).
- **Cache-creation token** × ọnụego `cache_creation` (ọ bụrụ na ọ dịghị, ọ na-eji ọnụego input).
- **Output token** × ọnụego `output`.
- **Reasoning token** × ọnụego `reasoning` (ọ bụrụ na ọ dịghị, ọ na-eji ọnụego output).

A na-akọwa ọnụego niile dịka USD kwa token 1,000,000. Service tier Codex “fast”/“priority” ma ọ bụ
“flex” na-etinye cost multiplier (`getCodexFastCostMultiplier`) — dịka ọmụmaatụ, a na-agbakọ ụgwọ flex
site na mbelata ọnụahịa token nke 50%, nke a na-egosi dịka **ego flex chekwara** na dashboard.

A na-ebu ụzọ hazie aha model ka ha bụrụ otu ụdị (a na-ewepụ prefix nke provider-path dịka `openai/` ma ọ bụ
`accounts/fireworks/models/`) ka ahịrị akụkọ ihe mere eme ka nwee ike dakọtara na ọnụahịa.

### Otu e si edekọ mmefu

- A na-agbakọ ọnụ ahịa kwa arịrịọ mgbe nzaghachi gasịrị ma dekọọ ya n'ụdị fire-and-forget ka ọ ghara
  itinye latency n'ebe client nọ. A na-ahazi ojiji shared-quota na tick event-loop na-esote
  site na [`src/lib/quota/spendRecorder.ts`](../../src/lib/quota/spendRecorder.ts).
- A na-etinye mmefu API key na buffer ma zipụ ya n'ìgwè site na
  [`SpendBatchWriter`](../../src/lib/spend/batchWriter.ts) (ndabara bụ oge flush nke 60s,
  buffer nwere ndekọ 1,000). Enwere ike ịhazi ya site na:

  | Env var                             | Ndabara | Ebumnuche                                         |
  | ----------------------------------- | ------- | ------------------------------------------------- |
  | `OMNIROUTE_SPEND_FLUSH_INTERVAL_MS` | `60000` | Oge etiti flush n'ime millisecond.                |
  | `OMNIROUTE_SPEND_MAX_BUFFER_SIZE`   | `1000`  | Ọnụọgụ kachasị nke ndekọ dị na buffer tupu flush. |

A naghị agụ ọnụ ọgụgụ ọnụ ahịa dị na dashboard site na ego dollar kwa ahịrị echekwara — kama,
a na-agbakọgharị ha ozugbo site na ọnụọgụ token na tebụl ọnụahịa dị ugbu a oge ọ bụla
analytics endpoint na-arụ ọrụ. Nke a pụtara na idozi ọnụahịa na-ezighị ezi (na ịmekọrịta ọzọ)
na-emelite atụmatụ ọnụ ahịa akụkọ ihe mere eme n'ụzọ na-emetụta oge gara aga.

## Dashboard: ibe Costs

Ibe **Costs** dị na `/dashboard/costs`
(`src/app/(dashboard)/dashboard/costs/`).
Nlele ya bụ isi bụ taabụ **Cost Overview**
(`src/app/(dashboard)/dashboard/costs/CostOverviewTab.tsx`),
nke na-ebunye ihe niile site na `GET /api/usage/analytics`.

Ihe ọ na-egosi:

- **Taịl mmefu** — ego mmefu e mere atụmatụ ya maka _Taa (1d)_, _7d_, _30d_, na
  oge ahọpụtara. Ihe nhọpụta oke oge: `7d`, `30d`, `90d`, `all`.
- **Metrik ndị bụ isi** — arịrịọ n'ime oge ahụ, ndị na-eweta ọrụ na-arụ ọrụ, ụdịdị na-arụ ọrụ,
  nkezi ọnụahịa kwa arịrịọ.
- **Cost Explorer** — tebụl enwere ike ịhazi/nzacha nke a chịkọtara dịka **onye na-eweta ọrụ**, **ụdịdị**,
  **API key**, **akaụntụ**, ma ọ bụ **ọkwa ọrụ**, yana ọnụahịa, arịrịọ, token, nkezi
  ọnụahịa/arịrịọ, na pasent nke oke mkpokọta.
- **Ojiji token** — mkpokọta / token ntinye / token mmepụta na oke ntinye:mmepụta.
- **Ịrụmọrụ routing** — ọnụọgụ fallback, ọnụego fallback, na mkpuchi ụdịdị a rịọrọ.
- **Amụma kwa ọnwa** — na-eme atụmatụ mmefu ruo ngwụcha ọnwa site na nkezi kwa ụbọchị n'oge na-adịbeghị anya.
- **Ntụnyere oge** — mgbanwe pasent n'etiti ọkara mbụ na ọkara nke abụọ nke oge ahụ.
- **Chaatị** — usoro ọnụahịa kwa ụbọchị, oke onye na-eweta ọrụ (pai), ndị na-eweta ọrụ kacha elu, ụdịdị kacha elu, ọnụahịa
  dịka API key, ọnụahịa dịka akaụntụ, ụkpụrụ ojiji kwa izu, na heatmap mmemme.
- **Mbupụ** — budata oge dị ugbu a dịka **CSV** ma ọ bụ **JSON** (bọtịnụ ndị ahụ na-apụta
  ozugbo enwere data ọnụahịa karịrị efu).

Mgbe enweghị okporo ụzọ akwụnyere ọnụahịa, ahịrị na-egosi akara "Nke ochie / N'efu" kama `$0`,
nke na-egosipụta ụdị savings-tracker.

### Ibe nta Costs ndị metụtara ya

Mpaghara Costs nwekwara ihe ndị a (ha niile dị n'okpuru `/dashboard/costs/`):

- **Pricing** (`/dashboard/costs/pricing`) — lee ma gbanwee ọnụahịa kwa ụdịdị (na-egosi
  taabụ Pricing a na-ekekọrịta).
- **Budget** (`/dashboard/costs/budget`) — tọọ oke mmefu kwa scope (na-egosi taabụ
  Budget a na-ekekọrịta).
- **Quota Share** (`/dashboard/costs/quota-share`) — pool quota a na-ekekọrịta na nlele burn-rate.

### Budget

| Usoro  | Endpoint                 | Ebumnuche                                                                           |
| ------ | ------------------------ | ----------------------------------------------------------------------------------- |
| `GET`  | `/api/usage/budget`      | Nchịkọta ọnụahịa + nyocha budget maka otu API key (`apiKeyId` query param dị mkpa). |
| `POST` | `/api/usage/budget`      | Tọọ oke USD kwa ụbọchị/izu/ọnwa + warning threshold maka API key.                   |
| `GET`  | `/api/usage/budget/bulk` | Nchịkọta budget n'ọtụtụ API key.                                                    |

> `GET /api/usage/budget` weghachiri gụnyere `dailyLimitUsd`, `weeklyLimitUsd`, `monthlyLimitUsd`,

| `GET`    | `/api/pricing/sync`     | Ọnọdụ sync ugbu a.                                                                                                            |

## CLI

CLI nke OmniRoute na-enye iwu maka ụgwọ, ojiji, na ọnụahịa (e debanyere ha na
[`bin/cli/commands/registry.mjs`](../../bin/cli/commands/registry.mjs)).

### `omniroute cost`

Akụkọ ụgwọ a chịkọtara site na `/api/usage/analytics`.

```bash
omniroute cost                          # ụbọchị 30 gara aga, e kewara ya dịka provider
omniroute cost --period 7d              # ụbọchị 7 gara aga
omniroute cost --group-by model         # kewaa dịka provider | model | combo | api-key | day
omniroute cost --since 2026-06-01 --until 2026-06-13
omniroute cost --api-key <key> --limit 50
```

Kọlụm: otu, arịrịọ, token mbata/ọpụpụ, ụgwọ (USD), na % nke mkpokọta. A na-ebipụta ahịrị mkpokọta niile
na ngwụcha (a na-egbochi ya site na `--quiet` ma ọ bụ `--output json`).

### `omniroute usage`

```bash
omniroute usage analytics --period 30d [--provider <id>]   # nchịkọta ụgwọ maka provider ọ bụla
omniroute usage logs [--limit 100] [--follow] [--api-key <k>] [--search <q>]
omniroute usage quota [--provider <id>] [--check]
omniroute usage utilization [--api-key <k>]
omniroute usage history [--limit 100]
omniroute usage proxy-logs [--limit 100]

# Mmefu e mere atụmatụ ya
omniroute usage budget list
omniroute usage budget get [scope]
omniroute usage budget set <amount> [--scope global] [--period monthly]
omniroute usage budget reset [scope]
```

### `omniroute pricing`

```bash
omniroute pricing list [--provider <p>] [--model <m>] [--limit 200]
omniroute pricing get <model>
omniroute pricing sync [--provider <p>] [--force]   # POST /api/pricing/sync
omniroute pricing diff [--model <m>]
omniroute pricing defaults show
omniroute pricing defaults set [--input <p>] [--output <p>] [--cache-read <p>] [--cache-write <p>]
```

> `pricing defaults show` na-agụ `GET /api/pricing/defaults`. Kama nke ahụ, iji dezie ọnụahịa model
> nke ọ bụla, jiri ibe dashboard **Pricing** ma ọ bụ `PATCH /api/pricing`.

## Nchọpụta na ndozi nsogbu

- **Ụgwọ niile na-egosi $0 / "Legacy / Free".** Model ndị a na-eji enweghị ndenye ọnụahịa.
  Kwado mmekọrịta mpụga (`PRICING_SYNC_ENABLED=true`) ma mee `omniroute pricing sync`, ma ọ bụ
  jiri aka gị tọọ ọnụahịa site na ibe Pricing / `PATCH /api/pricing`.
- **Ọnụahịa model akụkọ ihe mere eme ezighi ezi.** Dozie ọnụahịa ahụ (jiri nke ọzọ dochie ya ma ọ bụ megharịa mmekọrịta) — a na-agbakọgharị ụgwọ
  site na ọnụọgụ token mgbe ọ bụla a na-agụ analytics, ya mere atụmatụ ndị ahụ na-emelitekwa maka oge gara aga.
- **Mmefu na-anọ n'azụ oge dị ugbu a.** A na-achịkọta mmefu nke key ọ bụla n'ìgwè; belata
  `OMNIROUTE_SPEND_FLUSH_INTERVAL_MS` ma ọ bụrụ na ịchọrọ ọnụọgụ ndị dị ọhụrụ karị.
