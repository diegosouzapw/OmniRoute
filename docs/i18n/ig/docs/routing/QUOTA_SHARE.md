## Nchịkọta

Quota Sharing Engine na-ekesa oke ojiji dabere na oge nke onye na-enye ọrụ (dịka windo Codex
nke awa 5, Kimi 1500 req/h) n'ụzọ ziri ezi n'etiti ọtụtụ API keys na-eji otu
njikọ ahụ ọnụ.

**Nsogbu ọ na-edozi:** OmniRoute na-ebufe ọtụtụ API keys site n'otu akaụntụ
onye na-enye ọrụ upstream ahụ. Enweghị usoro nkekọrịta, nnukwu arịrịọ sitere na key A nwere ike imecha
oke onye na-enye ọrụ maka otu awa ahụ, mee ka keys B na C ghara ịrụ ọrụ ruo mgbe windo ahụ malitegharịrị.
Engine ahụ na-egbochi nke a site na:

1. Iso ojiji na-agagharị agagharị nke key ọ bụla n'akụkụ ọ bụla (%, arịrịọ, tokens, $).
2. Itinye algọridim fair-share na-echekwa ọrụ: key nwere ike ibiri n'aka oke ndị
   na-adịghị arụ ọrụ ma ọ bụrụ na pool zuru ụwa ọnụ erubeghị oke saturation.
3. Ịmanye nsonaazụ ahụ n'ime hot path (`chatCore.ts`) tupu arịrịọ ahụ
   erute upstream executor.

## Algọridim: Fair-Share Na-echekwa Ọrụ

E tinyere ya na `src/lib/quota/fairShare.ts`.

### Ụdịọrụ

| Ọnọdụ                                      | Ụdịọrụ          | Omume                                                                  |
| ------------------------------------------ | --------------- | ---------------------------------------------------------------------- |
| `globalUsedPercent < saturationThreshold`  | **Mmesapụ aka** | Key nwere ike ibiri ruo na oke zuru ụwa ọnụ ma e wepụ ngụkọta e jirila |
| `globalUsedPercent >= saturationThreshold` | **Siri ike**    | Manye oke ziri ezi nke onye ọ bụla n'ụzọ siri ike                      |

Ndabara `saturationThreshold = 0.5` (env `QUOTA_SATURATION_THRESHOLD`).

### Mkpebi maka akụkụ ọ bụla

Maka akụkụ ọ bụla na-arụ ọrụ n'ime pool ahụ, engine na-agbakọ:

```
fairShareAllowed = poolLimit × (allocationWeight / 100)
consumed        = uru na-agagharị agagharị ugbu a maka key a (site na QuotaStore.peek)
remaining       = fairShareAllowed - consumed
```

Mgbe ahụ:

- **`policy = hard`**: ọ bụrụ na `consumed > fairShareAllowed` ma ụdịọrụ ahụ siri ike → **gbochie**.
- **`policy = soft`**: ọ bụrụ na `consumed > fairShareAllowed` ma ụdịọrụ ahụ siri ike → **taa ya ahụhụ** (wedata mkpa ya na combo; anaghị egbochi ya kpamkpam).
- **`policy = burst`**: kwe ka ọ gaa n'ihu ma ọ bụrụ na ohere zuru ụwa ọnụ ka dị, n'agbanyeghị fair share.

### Oke kachasị zuru oke

`capValue` + `capUnit` dị na allocation bụ oke kachasị siri ike nke na-adabereghị n'ụdịọrụ ma ọ bụ
policy. Akụkụ ọ bụla ebe `consumed >= capValue` na-**egbochi** arịrịọ ahụ mgbe niile.

### Nnyocha ọtụtụ akụkụ

A na-egbochi arịrịọ ma ọ bụrụ na **akụkụ ọ bụla** n'ime pool ahụ ga-egbochi ya. Akụkụ ndị ahụ
nọọrọ onwe ha — imecha 5h% anaghị emetụta akụkụ weekly%.

### Mgbaziri

N'ụdịọrụ mmesapụ aka, key nke allocation ya erubeghị oke ojiji nwere ike iji njupụta sitere na
oke keys ndị ọzọ na-ejighị. Usoro mgbakọ ya bụ:

```
maxAllowed = globalLimit - consumedByOtherKeys
```

ebe `consumedByOtherKeys = consumedTotal - consumedByThisKey`. Oke kachasị zuru ụwa ọnụ
(pool `limit` maka akụkụ ahụ) bụ oke siri ike mgbe niile.

## Counter Windo Na-agagharị Agagharị

E tinyere ya na `src/lib/quota/sqliteQuotaStore.ts` na `redisQuotaStore.ts`.

Buckets abụọ maka `(apiKeyId, dimensionKey)` ọ bụla:

- `curr`: bucket dị ugbu a (`floor(nowMs / windowMs)`)
- `prev`: bucket gara aga (`curr - 1`)

Uru rolling dị irè:

```
effectiveBucketIndex = floor(nowMs / windowMs)
bucketStartMs        = effectiveBucketIndex × windowMs
elapsed              = nowMs - bucketStartMs
weight               = 1 - elapsed / windowMs

effective = prev × weight + curr
```

**Izi ezi**: izi ezi ruru ~99%. Njehie ya anaghị agafe 1% nke nha windo ahụ na
ókè dị n'etiti buckets (nke a bụ njirimara ebumpụta ụwa nke atụmatụ buckets 2).

### Ịrụ ọrụ n'otu oge

SQLite driver: mutex dị na ebe nchekwa maka key `(apiKeyId | dimensionKey)` ọ bụla na-egbochi
asọmpi read-modify-write. Ụkpụrụ a yiri mgbochi anti-thundering-herd dị na `src/sse/services/auth.ts`.

Redis driver: Lua EVAL script maka increment atomic — ọ na-agba ọsọ dịka otu iwu Redis.

## Njikọta Pipeline

### Nko PRE (`open-sse/handlers/chatCore.ts`)

Ọ na-agba tupu onye mmezu upstream, mgbe nyocha auth na iwu gasịrị:

```
resolveComboTargets / handleSingleModel
  → enforceQuotaShare(apiKeyId, connectionId, provider, estimatedCost)
      → getQuotaStore().peek() maka akụkụ ọ bụla
      → fairShare.decideFairShare()
      → ọ bụrụ na egbochi → weghachite 429 (buildErrorBody, Iwu Siri Ike #12)
      → ọ bụrụ na ekwe + belata-ebute-ụzọ → tọọ quotaSoftPenalty=true na onye a na-atụle
  → executor.execute()
```

**Kwe ka ọ gafere mgbe njehie mere**: ọ bụrụ na `enforceQuotaShare` tụnye njehie, a ga-ekwe ka arịrịọ ahụ gafere
yana ndekọ `pino.warn`. Nke a na-egbochi ntụpọ n'ime quota-engine igbochi
okporo ụzọ niile.

### Nko POST (dekọọ oriri)

Mgbe nzaghachi gara nke ọma gasịrị:

```
executor na-eweghachi ihe ịga nke ọma
  → spendRecorder.recordConsumption(apiKeyId, connectionId, provider, actualCost)
      → getQuotaStore().consume() maka akụkụ ọ bụla
      → kwe ka ọ gafere mgbe njehie mere: a na-edekọ njehie dịka pino.warn, anaghị ezigara ya onye ahịa
```

**Ihe edeturu maka mwepu**: ọ bụrụ na `consume` ada mgbe nzaghachi gasịrị, onye ngụ na-agagharị ga-agụ ihe
dị ala karịa nke bụ eziokwu. Mgbaàmà njupụta sitere n'aka onye na-eweta (dịka `anthropic-ratelimit-unified-5h-utilization`)
na-agbazi atụmatụ zuru ụwa ọnụ na arịrịọ na-esote.

### Ntaramahụhụ dị nro nke Combo (`open-sse/services/combo.ts`)

Mgbe `decision.deprioritize === true`:

```ts
if (candidate.quotaSoftPenalty) {
  score *= QUOTA_SOFT_DEPRIORITIZE_FACTOR; // ndabara 0.7
}
```

A na-etinye ntaramahụhụ ahụ mgbe ihe ndị ọzọ niile e ji agbakọ akara gasịrị. Ọ na-ebelata ohere auto-combo
ga-eji họrọ igodo jupụtara n'egbochighị ya kpamkpam.

## Nchọpụta na Ndozi Nsogbu

### Ahaziri Redis mana ọ naghị ejikọ

Lelee na etinyere `ioredis` (`npm ls ioredis`) nakwa na enwere ike iru `QUOTA_STORE_REDIS_URL`.
Ọ bụrụ na njikọ ada, factory ahụ na-alaghachi na SQLite (a na-edekọ ya na
`warn`).

### `peek` na-eweghachi data ochie / fail-open

Ọ bụrụ na `peek` atụpụ njehie, `enforceQuotaShare` na-ewere nsonaazụ ahụ dịka "kwe ka ọ gafee" (fail-open).
Lelee ndekọ `pino` maka ntinye `quota:enforce` na `quota:factory` iji chọpụta
isi ihe kpatara ya.

### Mwepụ nke ngụkọta ojiji

Ọ bụrụ na ojiji onye na-eweta ọrụ n'ezie dị iche na ngụkọta ndị ahụ, a tụrụ anya ya — windo
na-amị amị nke bọket abụọ nwere njehie ihe dịka 1% n'ókè windo, ebe `consume`
na-arụ ọrụ n'ebughị ụzọ chere nsonaazụ mgbe azịza gachara. Ihe mgbaàmà njupụta (`saturationSignals.ts`)
na-agụ ojiji onye na-eweta ọrụ n'ezie site na TTL nke 30s ma na-emegharị `globalUsedPercent`
n'ụzọ kwekọrọ.

### Ọdọ mmiri na-egosi "enweghị data" maka ọsọ ojiji

`computeBurnRate` chọrọ opekata mpe ihe nlele akụkọ ihe mere eme 2. Ọdọ mmiri ọhụrụ na-enweghị oku
`consume` gara aga ga-egosi `tokensPerSecond: 0` na `timeToExhaustionMs: null`.

na-enyocha:

Ọ bụrụ na ha abụọ bụ eziokwu, ọ na-eziga pool ochie ọ bụla na `POST /api/quota/pools` n'otu batch,
ma wepụzie key localStorage ahụ. Mbugharị ahụ bụ idempotent: ọnọdụ nke 2 na-egbochi
mbugharị ọzọ.

`quota-share` bụ strategy routing **maka naanị ime sistemụ** (`INTERNAL_ROUTING_STRATEGY_VALUES` dị na
`src/shared/constants/routingStrategies.ts`). Naanị combo pool `qtSd/` nke sistemụ mepụtara
na-eji ya, a kpachapụrụkwa anya wepụ ya na `ROUTING_STRATEGY_VALUES` ka ọ ghara
ịpụta dịka nhọrọ onye ọrụ nwere ike ịhọrọ na UI ma ọ bụ API.

## Nchịkọta Schema DB

Tebụl atọ ndị migrations `078`, `079` na `085` gbakwunyere:

- `quota_pools` + `quota_allocations` — nkọwa pool na allocations nke key ọ bụla.
- `quota_consumption` — counters 2-bucket na-agagharị maka `(apiKeyId, dimensionKey)` ọ bụla.
- `provider_plans` — overrides plan provider nke aka mere (dimensions JSON maka connectionId ọ bụla).

E tinyere tebụl niile site na migrations `CREATE TABLE IF NOT EXISTS` ndị bụ idempotent.
