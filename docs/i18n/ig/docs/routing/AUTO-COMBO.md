## Ntụgharị-Ụzọ Akpaaka Na-Enweghị Nhazi (`auto/` prefix)

> **IHE ỌHỤRỤ:** Ọ dịghị mkpa ịmepụta combo. Jiri `auto/` prefix ozugbo n'ime client ọ bụla.

### Ọmụmaatụ Ngwa Ngwa

| ID Model       | Ụdị     | Omume                                                                                     |
| -------------- | ------- | ----------------------------------------------------------------------------------------- |
| `auto`         | ndabara | Ndị na-eweta ọrụ niile ejikọrọ, atụmatụ LKGP, arọ ndị ahaziri nhata                       |
| `auto/coding`  | coding  | Arọ ndị na-ebute ogo ụzọ, dabara maka imepụta koodu                                       |
| `auto/fast`    | fast    | Nhọrọ nwere arọ na obere latency                                                          |
| `auto/cheap`   | cheap   | Ntụgharị-ụzọ ahaziri iji belata ọnụ ahịa (ọnụ ahịa kacha ala na mbụ)                      |
| `auto/offline` | offline | Na-akwado ndị na-eweta ọrụ nwere oke ojiji kacha dị ukwuu                                 |

### Ngwakọta Otu × Ọkwa (`auto/<category>:<tier>`)

Suffix ndị yiri nke OpenRouter na-ekewa **ụdị ụzọ ọ bụ** (otu) na **otu esi ahazi ya nke ọma** (ọkwa), ka ị nwee ike ijikọta ha n'enweghị mgbochi (#4235 Phase B, `open-sse/services/autoCombo/suffixComposition.ts`):

- **Otu dị iche iche** (na-enyocha ọdọ ndị a ga-ahọrọ dịka ike ha si dị): `coding` · `reasoning` · `vision` · `chat` · `multimodal`. `vision`/`multimodal` na-edobe model ndị nwere ike vision; `reasoning` na-edobe model ndị nwere ike reasoning/thinking.
- **Ọkwa dị iche iche** (na-ahọrọ arọ akara / ihe nzacha ọdọ): `fast` (zipụ-ngwa-ngwa) · `cheap` (aha ọzọ bụ `floor`, onye na-echekwa ọnụ ahịa) · `reliable` (ahụike circuit-breaker + nkwụsi ike latency) · `free` / `pro` (na-eji `classifyTier` enyocha ọdọ ahụ dịka ọkwa model si dị — ọkwa efu megide nke premium).

| Ọmụmaatụ               | Na-aghọ                                                             |
| ---------------------- | ------------------------------------------------------------------- |
| `auto/coding:fast`     | ọdọ coding, arọ nwere obere latency                                 |
| `auto/coding:cheap`    | ọdọ coding, nke ahaziri maka ọnụ ahịa (aha ọzọ `auto/coding:floor`) |
| `auto/reasoning:pro`   | naanị model reasoning/thinking, ọkwa premium                        |
| `auto/vision`          | model ndị nwere ike vision (enweghị ọkwa → arọ ndị ahaziri nhata)   |
| `auto/multimodal:free` | model ndị nwere ike multimodal, naanị ọkwa efu                      |

`auto/<category>[:<tier>]` ọ bụla ziri ezi na-edozi mgbe achọrọ ya; a na-egosi obere nchịkọta a họpụtara nke ọma na `/v1/models` nakwa na dashboard (`AUTO_SUFFIX_VARIANTS` dị na `open-sse/services/autoCombo/builtinCatalog.ts`). Nzacha a bụ **fail-open** — ọ bụrụ na iwu enweghị model ejikọrọ ọ bụla dabara na ya, a ga-eji ọdọ niile ka ntụgharị-ụzọ ghara ịkwụsị ịrụ ọrụ. Onye isi na-enye akara (`combo.ts`) agbanwebeghị; a na-etinye ihe nzacha otu/ọkwa n'ime `buildAutoCandidates`.

> **Ọgụgụ isi model ozugbo:** ọkwa **Arena ELO** ndị dị ugbu a + data ọkwa **models.dev** na-enye aka n'ịtụ ịdị mma nke ntụgharị-ụzọ akpaaka mgbe flag `ARENA_ELO_SYNC_ENABLED` dị ọkụ (ma ọ bụghị ya, ọ na-alaghachi na map ịdị mma static).

**Otu esi eji ya:**

```bash
# IDE ma ọ bụ ngwa CLI ọ bụla na-akwado usoro OpenAI
Base URL: http://localhost:20128/v1
API Key:  <igodo-endpoint-gị>

# N'ime koodu/nhazi gị, tọọ model ka ọ bụrụ:
model: "auto"                 # ndabara ahaziri nhata
model: "auto/coding"          # kacha mma maka ọrụ coding
model: "auto/fast"            # nke kacha ọsọ dị
model: "auto/cheap"           # nke kacha ọnụ ala kwa token
```

**Ihe na-eme:**

1. OmniRoute na-achọpụta `auto/` prefix n'ime `src/sse/handlers/chat.ts`
2. Na-ajụ nchekwa data maka **njikọ ndị na-eweta ọrụ niile nọ n'ọrụ**
3. Na-enyocha ma hapụ naanị ndị nwere nzere ziri ezi (API key ma ọ bụ OAuth token)
4. Na-ekpebi model maka njikọ ọ bụla (`connection.defaultModel` ma ọ bụ model mbụ nke onye na-eweta ọrụ)
5. Na-ewulite **virtual combo** n'ime ebe nchekwa (anaghị echekwa ya na DB)
6. Na-eme ntụgharị-ụzọ site na iji profaịlụ arọ nke ụdị ahọpụtara + atụmatụ LKGP

**Njirimara ndị bụ isi:**

- ✅ **Na-arụ ọrụ mgbe niile:** Enweghị toggle, enweghị imepụta combo, enweghị nhazi achọrọ
- ✅ **Na-agbanwe agbanwe:** Na-egosipụta ndị na-eweta ọrụ ejikọrọ ugbu a na-akpaghị aka
- ✅ **Ịrapara na session:** LKGP na-ahụ na a na-ebute onye na-eweta ọrụ ikpeazụ rụrụ nke ọma ụzọ
- ✅ **Na-aghọta ọtụtụ account:** Njikọ onye na-eweta ọrụ ọ bụla na-aghọ candidate dị iche
- ✅ **Enweghị ide na DB:** Virtual combo dị naanị maka request ahụ, enweghị ibu persistence ọ bụla

### Njikwa candidate nke igodo ọ bụla (#7819, Ọkwa 1+2)

`GET /v1/auto-combo/{channel}/candidates` (`{channel}` = suffix na-esote `auto/`, ma ọ bụ
`auto` kpọmkwem maka channel bụ isi) bụ endpoint **naanị maka ịgụ** nke na-edepụta
ọdọ candidate dị ugbu a nke channel `auto/*`, tinyere ozi nnweta ozugbo, site n'iji
ọgụgụ resilience ndị dị ugbu a emegharị (ọ bụghị breaker `state` raw):

- circuit breaker nke onye na-eweta ọrụ — `getCircuitBreaker(provider).getStatus()` / `.canExecute()`
- cooldown nke njikọ — `rateLimitedUntil` / `testStatus` n'ahịrị
  `provider_connections` e kpebiri
- mkpọchi model — `isModelLocked(provider, connectionId, model)`

Candidate ọ bụla nwekwara flag `excluded` nke API key a. A na-echekwa mwepu
maka API-key ọ bụla (`auto_candidate_overrides` table, migration `128`) — OmniRoute bụ
single-tenant na-enweghị table `users`, ya mere `apiKeyId` bụ njirimara onye na-akpọ oku
kachasị nso n'ezie — a na-etinyekwa ya n'ọrụ n'ebe njedebe ọdọ candidate dị na
`open-sse/services/autoCombo/virtualFactory.ts` site na `filterExcludedCandidates()`
dị ọcha ma nwalee unit (`open-sse/services/autoCombo/candidateOverrides.ts`).
Ihe nzacha ahụ bụ **fail-open**: apiKeyId/channel a na-edobeghị ma ọ bụ ọdịda nchọta DB
ga-ahapụ ọdọ ahụ n'enweghị nzacha, ka onye nchịkwa na-enweghị override ọ bụla ahaziri
wee hụ ntụgharị-ụzọ nke byte ọ bụla yiri nnọọ nke dị tupu atụmatụ a.

**Ebugharịrị gaa n'okwu a ga-esochi:** ibu arọ nke onye ndọrọ ọ bụla + nhazi pořọdụ doro anya (Ọkwa 3
— na-abanye n'ụzọ atụmatụ ibu arọ/ebute ụzọ ndị dị ugbu a) na ịtụgide atụmatụ
`combo.ts` akọwapụtara maka channel `auto/*` ọ bụla (Ọkwa 4). Lee atụmatụ #7819 maka ajụjụ
ka ghe oghe gbasara ma overrides kwesịrị ịdịgide n'otu API key ọ bụla, ka ọ bụ bụrụ nke zuru ụwa ọnụ n'ihi
ụdị single-tenant ahụ.

## Aha Combo Ndị Dabara na Ezigbo Model Id

Combo nke `name` ya bụ otu ihe kpọmkwem na model id nkịtị (dịka ọmụmaatụ, combo a kpọrọ
`gpt-5.5`) bụ **usoro e bu n’obi ma na-akwado**, ọ bụghị ntụpọ: ọ bụ
usoro eji eme ndabere provider maka model-id ọ bụla nke akọwara na
[#6940](https://github.com/diegosouzapw/OmniRoute/issues/6940). Ebe ọ bụ na a na-ebu ụzọ elele
mkpebi combo tupu mkpebi bare-model-id
(`getComboForModel()` dị na `src/sse/services/model.ts`), a na-eziga arịrịọ maka id nkịtị
`gpt-5.5` site na targets nke combo ahụ (dịka ọmụmaatụ
`acme-responses/gpt-5.5`, `backup-responses/gpt-5.5`) kama iziga ya ozugbo na
otu provider — nke a na-eji ọzọ combo-before-rewrite precedence e wuru maka
[#3227/#3233](https://github.com/diegosouzapw/OmniRoute/issues/3227), a na-ejikwa
`tests/unit/responses-combo-resolution-3227.test.ts` na
`tests/unit/combo-name-codex-responses-rewrite.test.ts` nwalee ya iji gbochie regression.

A naghị **ajụ ma ọlị** imepụta combo ma ọ bụ ịgbanwe aha ya ka ọ bụrụ aha na-ekpuchi ezigbo model id — ime nke ahụ ga-emebi usoro ọrụ a edekọtara. Kama nke ahụ
(#8530), `POST /api/combos` na `PUT /api/combos/[id]` na-agbakwunye field
`warning` nke na-adịghị egbochi ọrụ na response mgbe aha (ọhụrụ) ahụ dakọtara na ezigbo
model id:

```json
{
  "warning": {
    "code": "COMBO_NAME_SHADOWS_MODEL",
    "modelId": "gpt-5.5",
    "providerId": "openai"
  }
}
```

Mgbe usoro na-ebido, `scanComboModelNameCollisionsAtBoot()`
(`src/instrumentation-node.ts`) na-edekwa ịdọ aka ná ntị `[STARTUP]` nke otu ahịrị
nke na-edepụta combo niile dị adị na-ekpuchi model id, ka ndị na-ahụ maka sistemụ
ndị zutere nke a na mberede (kama ime ya n’ebumnobi, dịka #6940 si kwuo) nwee ihe ngosi.
Helper nchọpụta ahụ dị na `src/lib/combos/modelNameCollision.ts`.

## Ịkpọ Custom Combo Site na Client

A na-eji combos echekwara (Ntọala → Combos) naanị mgbe client zigara **aha combo ahụ kpọmkwem** na field `model` — enweghị fuzzy matching ma ọ bụ partial matching nke aha combo ahụ, a naghịkwa eji prefix `auto/`. Usoro mkpebi (`getComboForModel()` dị na `src/sse/services/model.ts`):

1. ndakọrịta aha combo kpọmkwem (`model: "my-combo"`),
2. prefix `combo/<name>` (`model: "combo/my-combo"`),
3. model→combo glob mappings (`/api/model-combo-mappings`).

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-combo","messages":[{"role":"user","content":"Hello"}]}'
```

Nsogbu abụọ a na-ahụkarị:

- **`auto` anaghị eji combos gị.** `auto`/`auto/*` na-ewu candidate pool nke ya na-achọghị nhazi ọ bụla, ọ na-elelekwa combos echekwara naanị ma ọ bụrụ na e nwere combo a kpọrọ `auto` kpọmkwem (anaghị atụ aro ya). Iji zipụ arịrịọ site na combo, ziga aha ya kpọmkwem — ọ bụghị `auto`.
- **`openrouter/auto` bụ ezigbo ngwaahịa OpenRouter a na-akwụ ụgwọ maka ya** ("Auto Best Available"), ọ bụghị alias OmniRoute. Ọ bụ otu static model entry dị na registry OpenRouter (`open-sse/config/providers/registry/openrouter/index.ts`), a na-akwụkwa ụgwọ ya iche. Jiri Ntọala → Routing → Zoo models a na-akwụ ụgwọ iji wepụ ya na `auto` pools.

Lee [#7992](https://github.com/diegosouzapw/OmniRoute/issues/7992) na [#7111](https://github.com/diegosouzapw/OmniRoute/issues/7111) maka mgbagwoju anya mbụ nke akwụkwọ a na-akọwa.

## Otu O Si Arụ Ọrụ (Auto-Combos Echekwara)

Auto-Combo Engine na-ahọrọ provider/model kacha mma n'ụzọ na-agbanwe agbanwe maka arịrịọ ọ bụla site n'iji **ọrụ inye akara nwere ihe 16** (akọwapụtara na `open-sse/services/autoCombo/scoring.ts` → `DEFAULT_WEIGHTS`). Nchịkọta arọ ndabara bụ `1.0`; `normalizeScoringWeights()` na-emegharị arọ ndị ahaziri ka nchịkọta ha kwekọọ. Abụọ n'ime ihe iri na isii ahụ — `cacheAffinity` na `resetWindowAffinity` — nwere arọ ndabara nke `0`; `reliability` nwere `0` na `DEFAULT_WEIGHTS` mana o nwere `0.03` na ngwugwu izugbe yana `0.04` na `reliability-first`, ebe `quality` nwere `0.02` na ngwugwu (`0.03` na `quality-first`): a ka na-agbakọ ha maka onye ndoro-ndoro ọ bụla, `cacheAffinity` na-achịkwa iwepụ oyiri prompt-cache n'èzí akara ahụ, ya mere ihe ndị nwere efu dịka ndabara anaghị atụ vootu na ndabara, ebe ngwugwu na-eme ya.

### Nkọwa omume `weighted`

`weighted` bụ **nhọpụta enweghị usoro nke dabara n’ogo maka arịrịọ ọ bụla**
(`open-sse/services/combo/targetSorters.ts` → `selectWeightedTarget`), ọ bụghị ihe na-eme ka ha hara nhata:

- Arịrịọ ọ bụla na-ahọrọ usoro **otu** site na ohere `weight / totalWeight`; a na-ahazi usoro ndị fọdụrụ
  site n’arọ kachasị ruo n’arọ kacha nta ka ha bụrụ usoro ndabere maka arịrịọ ahụ.
- Usoro nke arọ ya bụ `0` (ma ọ bụ nke na-enweghị arọ) **anaghị ahọrọ ma ọlị** mgbe usoro ọ bụla ọzọ nwere
  arọ > 0 — naanị mgbe usoro ahọpụtara dara ka ọ nwere ike bụrụ ndabere. Ọ bụ naanị mgbe arọ **niile**
  bụ 0 ka nhọrọ ga-enwe ohere hà nhata.
- A na-ewepụ usoro ndị ebumnuche ha niile adịghị — circuit breaker nke onye na-eweta ọrụ dị `OPEN`, njikọ
  nọ na cooldown, ma ọ bụ model nọ na lockout — n’ime nhọrọ tupu e mee ya
  (`open-sse/services/combo/targetResolution.ts`), ya mere otu usoro dị mma nwere ike imeri arịrịọ ọ bụla nwa oge.
- `stickyWeightedLimit` (nhazi combo, ndabara `1` = agbanyụrụ) na-eme ka usoro ahọpụtara nọgide maka
  ihe ịga nke ọma ndị na-esochi ibe ha ruo n’ọnụọgụ ahụ tupu e mee nhọrọ ọzọ.

Maka ntụgharị siri ike, jiri `round-robin`; ịdị arọ hà nhata na `weighted` na-enye nguzozi nke ọnụ ọgụgụ — ọ bụghị
nke siri ike.

### Ọnọdụ pipeline nke agentic

Ngwakọta `pipeline` nwere opekata mpe model abụọ nwere ike ịhọrọ iji nhazi ụzọ planner/executor site na
`config.agenticOrchestration.enabled`. Target nke mbụ na-ahụ maka ime atụmatụ na azịza ikpeazụ;
target nke abụọ na-ewepụta oku tool nke kwekọrọ na client. OmniRoute na-achọpụta njikọ na-aga n'ihu nke tool-result
site na protocol nke arịrịọ ahụ, jụọ planner ma achọrọ okirikiri tool ọzọ,
ma mee ka executor ma ọ bụ planner bụrụ nzọụkwụ ikpeazụ client ga-ahụ n'ụzọ na-agbanwe agbanwe.

Model ndị ọzọ dị mgbe target nke abụọ gasịrị bụ executor ndabere ahaziri n'usoro. Nzaghachi
HTTP dara ada ma ọ bụ transport exception na-eme ka usoro ahụ gaa na executor na-esote, na-eburu
otu mkpebi planner ahụ na native tools mana jiri step prompt nke executor ahụ n'onwe ya na
njikọ edoziri. A na-eweghachi nzaghachi izizi gara nke ọma n'enweghị mgbanwe, gụnyere
SSE streaming; enweghị ike ịnwale ọdịda ọzọ ebe a ma ọ bụrụ na stream gara nke ọma amalitela.
Ọ bụrụ na executor niile adaa, a na-eweghachi ọdịda ikpeazụ. Nkwụsị sitere n'aka client na-akwụsị dispatch.

```json
{
  "strategy": "pipeline",
  "models": [{ "model": "provider/planner" }, { "model": "provider/executor" }],
  "config": {
    "agenticOrchestration": { "enabled": true, "maxToolRounds": 8 }
  }

```

Executor nwere ike iwepụta ọtụtụ oku nọọrọ onwe ha n'otu nzaghachi. A na-ahazi oku ndị
dabere n'ibe ha na ntụgharị tool-result nke client ndị na-esote, ebe planner na-enyocha nsonaazụ ọ bụla.
`maxToolRounds` nwere ndabara `8` ma na-anabata `1`–`32`; ozugbo e ruru ya, planner ga-
ewepụta azịza ikpeazụ kacha mma dị. A na-echekwa mkpebi ime planner na buffer, ebe
nzaghachi ahọpụtara nke client ga-ahụ na-edobe mmasị streaming mbụ.

### Batch nke `round-robin` na-anọgide otu ebe na mgbasawanye akaụntụ

A na-eme round-robin na batch, ọ bụghị otu arịrịọ kwa nzọụkwụ:

- `stickyRoundRobinLimit` (config ngwakọta, emesịa `comboStickyRoundRobinLimit`, emesịa
  `settings.stickyRoundRobinLimit`, ndabara **3**) na-edobe otu target ahụ ruo ọnụ ọgụgụ
  ihe ịga nke ọma na-aga n'ihu ahụ tupu ntụgharị. Tọọ override nke ngwakọta ka ọ bụrụ `1` maka ntụgharị otu arịrịọ.
  Editor ngwakọta na-egosi uru dị irè na layer o si bịa.
- `connectionAwareExpansion` (config ngwakọta, emesịa settings, ndabara **false**) na-agbasa
  nzọụkwụ ọ bụla dị n'ọkwa provider ka ọ bụrụ target kwa akaụntụ tupu ntụgharị. Strategy Group-B
  (priority, weighted, round-robin, random, p2c, least-used, cost-optimized, lkgp,
  fill-first, strict-random, context-optimized, cache-optimized, context-relay, fusion,
  pipeline) na-edobe nlele dị n'ọkwa provider ruo mgbe agbanyere nke a. Editor ngwakọta na-enye
  inherit / on / off; inherit na-eji ndabara zuru ụwa ọnụ (off).
- Nhazi ụzọ dabere na ịdị nso nke prompt-cache (`promptCacheAffinityEnabled`, ndabara **true**) na-ahazigharị
  njikọ ndị a kpọgidere ka cache key ndị kwekọrọ nọrọ n'otu akaụntụ. Ọ na-ebute ụzọ karịa
  ntụgharị round-robin na weighted n'ofe nzọụkwụ kwa akaụntụ ndị a kpọgidere. Gbanyụọ ya n'okpuru
  Settings → Combo defaults ma ọ bụrụ na ịchọrọ ntụgharị siri ike. Enweghị override kwa ngwakọta.

Maka ntụgharị ọtụtụ akaụntụ n'otu model, họrọ **otu nzọụkwụ dynamic-account** (`connectionId` tọgbọ chakoo,
pool dum) nwere sticky limit `1`, ọ bụghị `connectionId` atọ a kpọgidere.
Nzọụkwụ ndị a kpọgidere tinyere affinity na-adakọ n'otu akaụntụ ahụ ọbụlagodi mgbe counter RR
na-aga n'ihu.

## Atụmatụ Fusion

`fusion` bụ naanị atụmatụ nke **na-adịghị** ahọrọ otu ebumnuche. Ọ na-eziga prompt ahụ
gaa na **ụdị nlereanya panel niile n'otu oge**, mgbe ahụ **ụdị nlereanya ọkaikpe** a pụrụ ịhazi
na-achịkọta otu azịza ikpeazụ site na nzaghachi panel niile. E si na `decolua/9router`
nke upstream bugharịa ya (nhazi Fusion nke OpenRouter); mmejuputa ya dị na `open-sse/services/fusion.ts`.

Otu o si arụ ọrụ:

0. **Ịgafe panel maka arịrịọ nwere ngwaọrụ** — arịrịọ nwere array `tools` na-adịghị efu, nke
   `tool_choice` ya abụghị `"none"` kpọmkwem, na-awụfe panel kpamkpam: a na-ebuga ya ozugbo na
   otu ụdị nlereanya (ọkaikpe ahaziri, ma ọ bụ `panel[0]`), ebe a na-ebufe `tools`/`tool_choice`
   n'enweghị mgbanwe. Ndị otu panel enweghị ohere iji ngwaọrụ, ntuziaka nchịkọta nke ọkaikpe
   na-egbochikwa iwepụta oku ngwaọrụ, ya mere ndị ahịa agentic/ndị na-akpọ ngwaọrụ
   na-enweta ezigbo mkpebi oku ngwaọrụ kama prose a chịkọtara (#6771).
1. **Mgbasa n'akụkụ niile** (naanị maka arịrịọ na-enweghị ngwaọrụ) — a na-eziga prompt ahụ na ụdị
   nlereanya panel niile n'otu oge, na-amanye ha ka ha ghara iji streaming ma wepụ ngwaọrụ
   (ọkaikpe chọrọ prose zuru ezu iji chịkọta azịza).
2. **Nchịkọta quorum-grace** — ozugbo azịza `minPanel` rutere, obere grace
   timer na-amalite maka ndị na-egbu oge, mgbe ahụ fusion na-eji ihe ọ bụla anakọtara gaa n'ihu.
   Nke a na-amachi ntaramahụhụ ụdị nlereanya kacha nwayọọ na-etinye na wall time, site na hard timeout.
3. **Nchịkọta nke ọkaikpe** — a na-ezo aha azịza panel (`Isi Mmalite 1`, `Isi Mmalite 2`, … — ka
   ọkaikpe wee tụọ ọdịnaya, ọ bụghị aha ụdị nlereanya), ma nyefee ha n'aka ọkaikpe, nke na-enyocha
   nkwekọrịta / esemokwu / mkpuchi ezughị ezu / nghọta pụrụ iche / ebe a na-ahụghị anya, ma mesịa
   dee **otu** azịza nwere ikike. Oku ọkaikpe ahụ na-edowe flag `stream` mbụ nke onye ahịa
   yana ngwaọrụ, ka streaming na ojiji ngwaọrụ downstream wee ka na-arụ ọrụ.
4. **Mbelata ọrụ n'enweghị ndakpọ** — azịza panel 0 → `503`; naanị otu nke fọdụrụ → a na-eweghachi
   azịza ahụ ozugbo (ọ dịghị ihe a ga-ejikọta); panel nwere naanị otu ụdị nlereanya na-aza ozugbo.

Onye otu panel nwekwara ike ịbụ nzọụkwụ `combo-ref` (`{kind: "combo-ref", comboName: "..."}`) nke na-arụtụ aka
na combo ọzọ — a na-edozi ya dị ka **otu olu panel black-box** (dispatch recursive zuru ezu banye na
combo ahụ a kpọtụrụ aka, ọ bụghị fan-out nke ebumnuche combo ahụ), yana nchedo depth/cycle
ahụ atụmatụ ndị ọzọ niile na-eji combo-ref na-ejibu (#6764).

### Nhazi

A na-ahazi ya na blob `config` nke combo ahụ (enweghị mbugharị schema — ọ na-eji tebụl
`combos` dị ugbu a ọzọ):

| Field                                    | Type     | Default                 | Purpose                                                                                  |
| :--------------------------------------- | :------- | :---------------------- | :--------------------------------------------------------------------------------------- |
| `config.judgeModel`                      | `string` | ụdị nlereanya panel mbụ | Ụdị nlereanya na-achịkọta azịza ikpeazụ                                                  |

| `config.fusionTuning.panelHardTimeoutMs` | `number` | `90000`                 | Oke zuru oke ka otu ụdị nlereanya kwụsịrị ịrụ ọrụ ghara igbochi arịrịọ ahụ               |

## Ụlọ Ọrụ Virtual Auto-Combo

Injin Auto Combo anaghị achọ ka akọwapụta combo tupu oge eruo. Kama nke ahụ, `open-sse/services/autoCombo/virtualFactory.ts` na-emepụta ndị a ga-atụle ozugbo:

1. Ọ na-ewepụta `getProviderConnections({ isActive: true })` (njikọ niile enyere aka)
2. Ọ na-enyocha ma hapụ naanị ndị nwere credentials ziri ezi (API key ma ọ bụ OAuth token na-agwụbeghị oge site na `hasUsableOAuthToken()`)
3. Ọ na-atụnyere ha na `getProviderRegistry()` maka nnweta model + ọnụahịa
4. Maka tuple ọ bụla `(provider, model, connection)`, ọ na-emepụta `VirtualAutoComboCandidate`
5. Ọ na-ahọrọ `connection.defaultModel` (ma ọ bụ model mbụ dị na registry) dịka ebe a ga-eziga arịrịọ
6. Ọ na-enye candidate ọ bụla akara site na iji `scorePool()` nwere ihe 16 na ngwugwu weight nke variant ahụ
7. Ọ na-eweghachi `AutoComboConfig` nke sitere na ya ma dị na memory maka `handleComboChat()` — anaghị echekwa ya na DB ma ọlị

Nke a pụtara na **ịgbakwunye provider ọhụrụ nke enyere `auto/*` aka na-agbasawanye candidate pool na-akpaghị aka** — ọ dịghị mkpa iji aka dezie combo. A na-ewughachi virtual combo maka arịrịọ ọ bụla, ya mere a na-achọpụta njikọ ọhụrụ agbakwunyere ma ọ bụ ndị laghachiri n'ọnọdụ ahụike ozugbo.

## Mmezi Onwe Ya

- **Mwepụ nwa oge**: Score < 0.2 → ewepụ ya maka nkeji 5 (backoff na-abawanye nwayọ nwayọ, nke kachasị bụ nkeji 30)
- **Ịmara ọnọdụ circuit breaker**: OPEN → ewepụ ya na-akpaghị aka; HALF_OPEN → arịrịọ nnwale
- **Ọnọdụ nsogbu**: >50% OPEN → gbanyụọ exploration, mee ka nkwụsi ike ruo ogo kachasị
- **Nlaghachi mgbe cooldown gasịrị**: Mgbe mwepụ ahụ kwụsịrị, arịrịọ mbụ bụ "probe" nwere timeout ebelatara

A na-eziga 5% nke arịrịọ (enwere ike ịhazi ya) n'aka provider ndị ahọrọghị n'usoro maka exploration. A na-agbanyụ ya n'ọnọdụ nsogbu.

### Atụmatụ auto router

Combos `strategy: "auto"` echekwara nwere ike ịtọ `config.routerStrategy` (ma ọ bụ nke ochie
`config.auto.routerStrategy`) ka ọ bụrụ otu n'ime ndị a:

- `rules` — scoring ndabara nwere weight
- `score` — na-ahọrọ weighted score ahaziri nke kachasị elu. Ties ndị hà nhata kpọmkwem na-edobe usoro
  candidate ahaziri; `explorationRate` dị ugbu a na-ewere sample site na ranked pool niile.
- `cost` / `eco` — provider ahụike kachasị ọnụ ala
- `latency` / `fast` — p95 latency kachasị ala nwere ntaramahụhụ reliability
- `sla-aware` / `sla` — na-enye candidates na-emezu p95 latency, error-rate, na SLOs
  cost nhọrọ ụzọ
- `lkgp` — provider ikpeazụ amaara na ọ dị mma na mbụ
- `nadir` — jụọ API mkpebi nke [Nadir](https://getnadir.com) model nke dị na pool ahụ
  prompt chọrọ; opt-in, ma ọ bụrụ na ọ daa, ọ ga-eji `rules`

### Nkọwa zuru ezu banyere atụmatụ router

Engine auto-combo na-enye implementations **RouterStrategy** 7 a pụrụ itinye ma wepụ, nke
ị nwere ike ịgbanwe site na `config.routerStrategy` (ma ọ bụ `config.auto.routerStrategy` ochie).
Atụmatụ ọ bụla na-ahọrọ otu provider n'ime candidate pool, dabere na `RoutingContext`
(ụdị task, ihe ngosi tool/vision, atụmatụ tokens, policy SLA nhọrọ, provider
ikpeazụ amaara na ọ dị mma nke bụ nhọrọ).

#### 1. `rules` (ndabara) — scoring nwere weight nke ihe 16

Ọ na-ekpuchi scoring engine dị ugbu a. Ọ na-ewepụ candidates circuit-breaker
ha bụ `OPEN`, wee mee `scorePool()` site na iji ụdị task ugbu a na `getTaskFitness()`,
ma họrọ provider nwere score kachasị elu.

```ts
class RulesStrategyImpl implements RouterStrategy {
  readonly name = "rules";
  readonly description = "16-factor weighted scoring (see DEFAULT_WEIGHTS)";

  select(pool, context) {
    const eligible = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const ranked = scorePool(
      eligible.length > 0 ? eligible : pool,
      context.taskType,
      undefined,
      getTaskFitness
    );
    return { provider: ranked[0].provider /* ... */ };
  }
}
```

**Mgbe e kwesịrị iji ya**: Ndabara. Jiri ya mgbe ịchọrọ nguzozi kwesịrị ekwesị n'etiti signals niile.

**Aha ọzọ**: `rules` (enweghị aha ọzọ)

---

#### 2. `cost` / `eco` — provider ahụike kachasị ọnụ ala

Ọ na-ahazi candidate pool site na `costPer1MTokens` (site na nke nta ruo nke ukwu) ma họrọ nke kachasị ọnụ ala.
Ọ na-ebu ụzọ wepụ candidates `OPEN`.

```ts
class CostStrategyImpl implements RouterStrategy {
  readonly name = "cost";
  readonly description = "Always selects cheapest available provider";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort((a, b) => a.costPer1MTokens - b.costPer1MTokens);
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Mgbe e kwesịrị iji ya**: Workloads na-elebara cost anya, batch processing, ma ọ bụ ọrụ ndị na-aga n'azụ.

**Aha ndị ọzọ**: `cost`, `eco`

---

#### 3. `latency` / `fast` — p95 latency kachasị ala nwere ntaramahụhụ reliability

Ọ na-ahazi site na `p95LatencyMs + (errorRate * 1000)`. Ntaramahụhụ error-rate na-eme ka
providers a na-apụghị ịtụkwasị obi nweta ọkwa dị ala ọbụlagodi ma nominal latency ha dị ala.

```ts
class LatencyStrategyImpl implements RouterStrategy {
  readonly name = "latency";
  readonly description = "Prioritizes lowest p95 latency with reliability weighting";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort(
      (a, b) => a.p95LatencyMs + a.errorRate * 1000 - (b.p95LatencyMs + b.errorRate * 1000)
    );
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Mgbe e kwesịrị iji ya**: Workloads na-elebara latency anya dịka real-time chat, autocomplete, ma ọ bụ
interactive coding assistants.

**Aha ndị ọzọ**: `latency`, `fast`

#### 4. `sla-aware` / `sla` — nrubeisi latency/error/cost SLO

Ọ na-enye candidate ọ bụla score dabere n'otú o si emezu policy SLO ahaziri:

| Ihe nrụtụ aka    | Ibu | Usoro mgbakọ                                                   |
| ---------------- | --- | -------------------------------------------------------------- |
| Akara nkwụsị oge | 35% | `threshold / max(value, ε)`                                    |
| Akara njehie     | 35% | `threshold / max(value, ε)`                                    |
| Akara ahụike     | 15% | `1.0` (CLOSED) / `0.5` (HALF_OPEN) / `0.0` (OPEN)              |
| Akara ọnụ ahịa   | 10% | `threshold / max(value, ε)` ma ọ bụ nke ahaziri n'ụzọ ntụgharị |
| Akara nkwụsi ike | 5%  | stddev nkwụsị oge ahaziri n'ụzọ ntụgharị                       |

(ókè ha gafere SLO ọ bụla), emesịa site na akara ngwakọta. Ma ọ bụghị ya, ọ bụ naanị
akara ngwakọta.

```ts
class SLAStrategyImpl implements RouterStrategy {
  readonly name = "sla-aware";

    "Selects the provider most likely to satisfy latency, error-rate, and cost SLOs";

  }

```

**Aha ndị ọzọ**: `sla-aware`, `sla`

#### 5. `lkgp` — buru ụzọ jiri onye na-enye ọrụ ikpeazụ a maara na ọ dị mma

Ọ na-ebu ụzọ nwalee **onye na-enye ọrụ ikpeazụ a maara na ọ dị mma** (ọ bụrụ na edobere ya), emesịa jiri
atụmatụ `rules` dị ka nkwado. Ọ bara uru maka ijigide otu onye na-enye ọrụ n'otu nnọkọ — otu onye na-enye ọrụ ahụ na-ahụ maka
arịrịọ ndị na-esote na mkparịta ụka.

```ts
class LKGPStrategyImpl implements RouterStrategy {
  readonly name = "lkgp";
  readonly description = "Tries last known good provider first, then falls back to rules";

  select(pool, context) {
    if (context.lkgpEnabled === false) {
      return getStrategy("rules").select(pool, context);
    }

    if (context.lastKnownGoodProvider) {
      const candidates = pool.filter(
        (c) => c.provider === context.lastKnownGoodProvider && c.circuitBreakerState !== "OPEN"
      );
      if (candidates.length > 0) {
        return { provider: candidates[0].provider /* ... */ };
      }
    }

    // Jiri atụmatụ rules dị ka nkwado
    return getStrategy("rules").select(pool, context);
  }
}
```

**Mgbe a ga-eji ya**: Mkparịta ụka nwere ọtụtụ ntụgharị ebe ịchọrọ ka otu onye na-enye ọrụ ahụ na-ahụ maka
arịrịọ ndị na-esote (dịka ọmụmaatụ, maka nchekwa cache, ịga n'ihu nke context, ma ọ bụ ịdị n'otu nke ọnụahịa).

**Aha ọzọ**: `lkgp` (enweghị aha ọzọ)

#### 6. `nadir` — ịhọrọ model nke na-adabere na prompt site na Nadir

Atụmatụ niile dị n'elu na-ahazi ndị a ga-ahọrọ dịka telemetry nke ha si dị; ọ dịghị nke na-agụ
arịrịọ ahụ. `nadir` na-eziga ntụgharị ikpeazụ nke onye ọrụ yana model ids dị na pool gaa na
API mkpebi nke [Nadir](https://getnadir.com) (`POST /v1/bucket`) ma zipụ arịrịọ ahụ na model
Nadir họọrọ n'ime ndepụta ahụ (`simple` → model kachasị ọnụ ala nke nwere ikike, `complex` → nke
frontier). `rules` ka na-ahọrọ njikọ na-enye model ahụ, ya mere quota,
ahụike na ọnụ ahịa ka na-ekpebi akaụntụ a ga-eji.

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "nadir",
    "nadir": {
      "apiKey": "ndr_...",
      "baseUrl": "https://api.getnadir.com",
      "timeoutMs": 2000
    }
  }
}
```

`OMNIROUTE_NADIR_API_KEY` na `OMNIROUTE_NADIR_BASE_URL` bụ env fallbacks maka eriri abụọ ahụ.
`baseUrl` dị naanị mkpa maka Nadir nke ị na-akwado n'onwe gị (a na-anabata `/v1` dị n'azụ ya).
Oku na-enweghị key na-abanye na ọkwa anonymous nke Nadir, nke nwere oke ọnụego maka IP ọ bụla.

Ihe na-apụ na box ahụ: ederede ozi ikpeazụ nke onye ọrụ (mkpụrụedemede 16k mbụ), model ids
nke ndị a ga-ahọrọ yana channel tag `source: "omniroute"`. Ọ dịghị system prompt, akụkọ ihe mere eme, tools ma ọ bụ
headers.

Omume mgbe ọdịda mere bụ fail-open: timeout (ndabara bụ 2000 ms), nzaghachi na-abụghị 2xx, host a na-apụghị iru,
nzaghachi emebiri emebi ma ọ bụ nhọrọ na-adịghị na pool ga-eduga na mkpebi `rules`,
a ga-etinyekwa `NadirStrategy: fallback (…)` n'ihu ihe kpatara ya. Mgbe oku dara, atụmatụ ahụ
na-awụfe network maka 30 s, ya mere nsogbu ọrụ na-eri otu timeout n'ime 30 s ọ bụla kama
otu maka arịrịọ ọ bụla. Ihe omume routing na-akọ `strategy: "nadir"` naanị mgbe Nadir mere
nhọrọ ahụ n'ezie.

**Mgbe a ga-eji ya**: okporo data nwere ọkwa isi ike dị iche iche n'ime pool nke nwere model tiers dị iche iche (obere, nke etiti
na frontier model), ebe ịchọrọ ibelata ọnụ ahịa nke iji frontier mgbe niile.

**Aha ọzọ**: `nadir` (enweghị aha ọzọ)

class MyCustomStrategy implements RouterStrategy {

## Otu tiers si daba na Auto-Combo

Ọrụ ntule nwere ihe 16 (`open-sse/services/autoCombo/scoring.ts`) na-ewere ịbụ onye otu tier dị ka akara abụọ: `tierPriority` (0.0476) na `tierAffinity` (0.0476). Lee [tebụl ihe ntule bụ isi](#how-it-works-persisted-auto-combos) dị n’elu maka nchịkọta `DEFAULT_WEIGHTS` zuru ezu — edepụtara mgbanwe pụrụ iche maka pack ọ bụla (ship-fast/cost-saver/quality-first/
offline-friendly) na tebụl "Profaịlụ ibu maka pack ọ bụla".

Tier naanị ya **anaghị** eme ka Tier 1 buru ụzọ — ọ bụrụ na latency nke Tier 1 adịghị mma ma ọ bụ na ntụnyere ọnụahịa na ogo adịghị mma, Tier 2 ga-emeri. Iji manye usoro tier, jiri atụmatụ combo `priority` ma hazie ndị na-eweta ọrụ dịka tier ha si dị.

Iji nye Tier 1 (ndebanye aha) nnukwu uru, bulie ibu `tierPriority`:

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "tierPriority": 0.3, "costInv": 0.05 } } }
}
```

Lee [`docs/guides/TIERS.md`](../guides/TIERS.md) maka nkọwa tier na nhazi ndị na-eweta ọrụ.
