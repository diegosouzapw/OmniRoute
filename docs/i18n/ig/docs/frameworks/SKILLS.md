OmniRoute nwere ike itinye skills dịka nkọwa ngwá ọrụ n’ime arịrịọ ndị a na-ezipụ, jide oku ngwá ọrụ ndị si n’ụdị asụsụ ahụ lọta, mee handler kwekọrọ na ya, ma zighachite nsonaazụ ahụ n’ụdị asụsụ ahụ ka mkparịta ụka wee gaa n’ihu. Ụdị asụsụ ahụ anaghị ahụ implementation ahụ — ọ na-ahụ naanị interface ngwá ọrụ ahụ.

## Agent Skills na Omni Skills

OmniRoute nwere sistemụ skill abụọ dị iche mana na-arụkọ ọrụ:

| Akụkụ                   | **Omni Skills** (akwụkwọ a)                                             | **Agent Skills**                                                                               |
| :---------------------- | :---------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------- |
| Ebumnuche               | Ntinye ngwá ọrụ LLM + ịrụ ọrụ n’ebe e kewapụrụ iche                     | Katalọgụ SKILL.md nke ndị agent mpụga ga-achọpụta ma jiri                                      |
| Isi mmalite nke eziokwu | `src/lib/skills/` + ahịa                                                | `src/lib/agentSkills/` + ndekọ `skills/`                                                       |
| Ụdị runtime             | A na-etinye ya n’arịrịọ ndị a na-ezipụ, a na-arụ ya mgbe tool-call mere | Katalọgụ markdown kwụụrụ onwe ya + endpoint nchọpụta REST/MCP/A2A                              |
| Ndị na-eji ya           | OmniRoute n’onwe ya (combo routing, oku LLM ndị na-abata)               | Ndị agent mpụga, ndị ahịa MCP, ndị nhazi A2A                                                   |
| Ọnụọgụ                  | Na-agbanwe (ahịa na-achịkwa ya)                                         | Ndenye katalọgụ 45 (23 API + 21 CLI + 1 nhazi)                                                 |
| Ọdịdị                   | `SkillDefinition` nwere schema ngwá ọrụ + handler                       | frontmatter `SKILL.md` + ahụ markdown                                                          |
| Nchọpụta                | `/api/skills/*` REST + ngwá ọrụ MCP `omniroute_skills_*`                | `/api/agent-skills/*` REST + ngwá ọrụ MCP `omniroute_agent_skills_*` + A2A `list-capabilities` |

**Omni Skills** bụ engine mmejuputa — ha na-akọwa ihe OmniRoute _nwere ike ime_ mgbe LLM kpọrọ ngwá ọrụ.

**Agent Skills** bụ katalọgụ akwụkwọ nkọwa — ha na-akọwara ndị agent mpụga _otu e si eji_ REST API na CLI nke OmniRoute, site na faịlụ SKILL.md ahaziri nke ọma nke enwere ike itinye ozugbo na prompt ndị agent.

Maka katalọgụ Agent Skills, generator, ngwá ọrụ MCP, na skill A2A, lee [docs/frameworks/AGENT-SKILLS.md](./AGENT-SKILLS.md).

## Echiche ndị bụ isi

### Ebe Skills Si Abịa

Ebe atọ skills si abịa na-ebikọ n’otu registry ahụ:

1. **Skills arụnyere n’ime sistemụ** (`src/lib/skills/builtins.ts`) — na-eso OmniRoute abịa. Ha na-ekpuchi ọnọdụ ndị a na-ahụkarị:
   - `file_read`, `file_write` — workspace sandbox maka API key ọ bụla n’okpuru `<DATA_DIR>/skills/workspaces/<hashed-key>/`
   - `http_request` — HTTP a na-ezipụ site na `safeOutboundFetch` nwere `guard: "public-only"`
   - `web_search` — provider ọchụchọ enwere ike ịgbanwe, nwere caching (`executeWebSearch`)
   - `eval_code` — mmejuputa `node` ma ọ bụ `python` n’ime sandbox Docker
   - `execute_command` — iwu shell a na-eme n’ime sandbox Docker
   - `browser` — ntọala scaffolding nke Playwright na-akwado, agbanyụrụ ya na ndabara (`builtin/browser.ts`)
2. **SkillsMP** (Ahịa OmniRoute) — a na-eweta ya site na `https://skillsmp.com/api/v1/skills/search`. Ọ chọrọ `skillsmpApiKey` na Settings.
3. **SkillsSH** (katalọgụ obodo `skills.sh`) — a na-eweta ya site na `https://skills.sh/api/search`. Ọ dịghị auth achọrọ; a na-adọta ọdịnaya SKILL.md site na GitHub raw.

Otu "active provider" na-achịkwa katalọgụ dashboard na-esi wụnye (`src/lib/skills/providerSettings.ts`). Gbanwee ya n’okpuru **Settings → Memory & Skills**. Ndabara: `skillsmp`.

### Njirimara Skill

A na-eji `name@version` dịka key maka skills n’ime registry dị na memory (`src/lib/skills/registry.ts`). Version ga-abụrịrị semver (`^\d+\.\d+\.\d+$`). `resolveVersion()` na-aghọta constraints `^`, `~`, `>`, `>=`, `<`, `<=`, `==`, na exact-match.

### Ụdị Skill

Skill ọ bụla nwere runtime mode nke na-achịkwa mgbe a ga-etinye ya:

| Mode   | Omume                                                                                                             |
| ------ | ----------------------------------------------------------------------------------------------------------------- |
| `on`   | A na-etinye ya mgbe niile dịka nkọwa ngwá ọrụ                                                                     |
| `off`  | A naghị etinye ya ma ọlị, a pụghịkwa ime ya                                                                       |
| `auto` | A na-enye ya akara megide arịrịọ na-abata; a na-etinye ya naanị ma ọ bụrụ na akara ≥ `AUTO_MIN_SCORE` (ndabara 3) |

`auto` bụ ndabara maka skills ndị e si n’ahịa wụnye. `enabled=true` na `mode="off"` ọnụ pụtara "edebanyere aha mana ọ naghị arụ ọrụ" — ịgbanwe `enabled` site na kọlụm legacy na-akwalitekwa `mode` ka codepaths ochie wee nọgide na-arụkọ ọrụ n’otu ụzọ (`src/app/api/skills/[id]/route.ts`).

### Ọnọdụ (mmejuputa)

A na-esochi mmejuputa skill na tebụl `skill_executions` site na statuses ndị a (`src/lib/skills/types.ts`):

```ts
enum SkillStatus {
  PENDING = "pending",
  RUNNING = "running",
  SUCCESS = "success",
  ERROR = "error",
  TIMEOUT = "timeout",
}
```

### Cache Registry

`SkillRegistry` bụ singleton nwere cache TTL nke sekọnd 60 (`registry.ts:14`). `loadFromDatabase()` bụ idempotent ma na-ewepụ oku ndị na-eme n’otu oge ugboro abụọ site na `pendingLoad`. Edemede ọ bụla (`register`/`unregister`/`unregisterById`) na-eme ka cache ghara ịdị irè. Jiri `getSkillVersions(name)` na `resolveVersion(name, constraint)` chọọ versions.

### Ntinye Na-eburu Provider n’Uche

`injectSkills()` dị na `src/lib/skills/injection.ts` bụ ebe mbata nke na-agbanwe skills ndị edebanyere aha ka ha bụrụ nkọwa ngwá ọrụ dabara na provider:

- **OpenAI** — `{ type: "function", function: { name, description, parameters } }`
- **Anthropic** — `{ name, description, input_schema }`
- **Google (Gemini)** — `{ name, description, parameters }`

A na-edekọ aha ngwa ọrụ ahụ dịka `name@version` ka onye njikwa ahụ nwee ike ịhọrọ ụdị ziri ezi mgbe model ahụ kpọghachiri ya.

### Ntụnye Akara AUTO

Mgbe `mode="auto"`, a na-atụnyere akara nka ọ bụla a họpụtara na ọnọdụ arịrịọ ahụ (`scoreAutoSkill()` n'ime `injection.ts`):

| Ihe ngosi                                              | Akara        |
| ------------------------------------------------------ | ------------ |
| Aha nka pụtara kpọmkwem n'ime ọnọdụ ahụ                | +6           |
| Token aha ọ bụla dabara na token ọnọdụ                 | +2           |
| Mpekere tag ọ bụla dabara na ọnọdụ                     | +3           |
| Token nkọwa ọ bụla dabara na ọnọdụ                     | +1           |
| Ihe kpatara ndabere dabara na token aha                | +2 kwa token |
| Ihe kpatara ndabere dabara na tag                      | +2 kwa token |
| Ntuziaka provider dị na tags dabara na provider arịrịọ | +2 / −2      |

A na-etinye nka `AUTO_MAX_SKILLS = 5` kachasị elu nwere `score >= AUTO_MIN_SCORE = 3`. A na-ekpebi ndị nwere otu akara site na `installCount` (site n'elu ruo n'ala), emesịa site n'usoro mkpụrụedemede nke aha (`injection.ts:225-235`).

### Ịkwụsị Oku Ngwa Ọrụ N'etiti

Onye njikwa nkata na-akpọ `handleToolCallExecution()` dị na `src/lib/skills/interception.ts` mgbe upstream weghachiri nzaghachi na-akpọ ngwa ọrụ:

1. `extractToolCalls()` na-agụ usoro ndị metụtara provider ọ bụla (OpenAI `tool_calls` / Responses `function_call`, Anthropic `tool_use`, Gemini `functionCalls`).
2. A na-ebu ụzọ dozie aha nnọchi nke ngwa ọrụ arụnyere n'ime sistemụ (dịka `omniroute_web_search` → `web_search`). Ndị njikwa arụnyere n'ime sistemụ na-arụ ọrụ ozugbo n'ime usoro ahụ.
3. Ihe ọ bụla ọzọ na-aga site na `skillExecutor.execute(name@version, args, { apiKeyId, sessionId })`.
4. A na-etinye nsonaazụ ndị ahụ azụ n'ime nzaghachi ahụ — ihe `tool_results`, `function_call_output`, ma ọ bụ blọk Anthropic `tool_result`, dịka o kwesịrị.

Enwere ike ịtọ `customSkillExecutionEnabled` dị n'ime ọnọdụ mmezu ka ọ bụrụ `false` iji kwe naanị nkwụsị nke ngwa ọrụ arụnyere n'ime sistemụ (ụzọ arịrịọ ndị na-agbanyụ ndị njikwa onye ọrụ kọwara n'ụzọ doro anya na-eji nke a).

## Docker Sandbox

Ụzọ koodu ndị na-abụghị nke arụnyere n'ime (`eval_code`, `execute_command`) na-arụ ọrụ n'ime Docker site na `SandboxRunner` (`src/lib/skills/sandbox.ts`). A na-ebido konteena ọ bụla na:

```
--rm --network none|bridge --cap-drop ALL
--security-opt no-new-privileges --pids-limit 100
--cpus <cpuLimit/1000> --memory <memoryLimit>m
--tmpfs /tmp:rw,noexec,nosuid,size=64m
--tmpfs /workspace:rw,noexec,nosuid,size=64m
--read-only (mgbe readOnly=true)
```

Ntọala ndabara (`SandboxRunner.DEFAULT_CONFIG`):

| Ogige            | Ndabara         | Nkọwa                                                   |
| ---------------- | --------------- | ------------------------------------------------------- |
| `cpuLimit`       | 100 (= 0.1 CPU) | A na-ekewa ya site na 1000 tupu ebufee ya na `--cpus`   |
| `memoryLimit`    | 256 MB          | Oke siri ike                                            |
| `timeout`        | 30000 ms        | Nkwụsị dị nro site na `SIGTERM` + `docker kill`         |
| `networkEnabled` | `false`         | Ọ na-aghọ `--network none`                              |
| `readOnly`       | `true`          | Root FS bụ naanị ọgụgụ; `/tmp` na `/workspace` bụ tmpfs |

E mepere `SandboxRunner.kill(id)` na `killAll()` maka mmechi; a na-esochi konteena ndị na-arụ ọrụ na `runningContainers: Map<string, ChildProcess>`.

### Mgbanwe Gburugburụ nke Sandbox

A na-ahazi ha site na `process.env` n'ime `src/lib/skills/builtins.ts`:

| Mgbanwe Gburugburụ                | Ndabara          | Ebumnuche                                                                                |
| --------------------------------- | ---------------- | ---------------------------------------------------------------------------------------- |
| `SKILLS_MAX_FILE_BYTES`           | `1048576` (1 MB) | Oke maka `file_read` na `file_write`                                                     |
| `SKILLS_MAX_HTTP_RESPONSE_BYTES`  | `256000`         | Oke maka ahụ nzaghachi `http_request`                                                    |
| `SKILLS_MAX_SANDBOX_OUTPUT_CHARS` | `100000`         | Oke maka stdout/stderr eweghachiri onye kpọrọ ya                                         |
| `SKILLS_SANDBOX_TIMEOUT_MS`       | `10000`          | Oge nkwụsị ndabara maka iwu ndị dị na sandbox; oke ya bụ 60 s                            |
| `SKILLS_SANDBOX_NETWORK_ENABLED`  | `false`          | Ọnụ ụzọ ukwu maka okporo ụzọ ọpụpụ. Tọọ `1` ma ọ bụ `true` iji kwe ka ịhọrọ ya n'otu oku |
| `SKILLS_ALLOWED_SANDBOX_IMAGES`   | (lee n'okpuru)   | Ndepụta oyiyi Docker ndị ekwere, nke rikoma kewara                                       |

Oyiyi ndị a na-ekwe na ndabara: `alpine:3.20`, `node:22-alpine`, `python:3.12-alpine`. A na-ejikọta mgbakwunye ọ bụla sitere na `SKILLS_ALLOWED_SANDBOX_IMAGES` na ndị ndabara; `normalizeImage()` na-ajụ oyiyi ndị a na-amaghị.

> Rịba ama: enweghị mgbanwe gburugburụ `SKILLS_EXECUTION_TIMEOUT_MS` dị iche. E dere oge nkwụsị nke njikwa na-abụghị sandbox ozugbo ka ọ bụrụ 30 s n'ime `SkillExecutor` (`executor.ts:13`), mana enwere ike iji `skillExecutor.setTimeout(ms)` gbanwee ya n'oge ọrụ.

### Nkewapụ Ebe Ọrụ

`file_read` na `file_write` na-edozi ụzọ ọ bụla ka ọ dabere na ebe ọrụ nke igodo API ọ bụla na `<DATA_DIR>/skills/workspaces/<sha256(apiKeyId).slice(0,24)>/`. A na-ajụ ịgafe ụzọ (`..`) na akụkụ ndị amachibidoro (`.env`, `.git`, `.ssh`, `.omniroute`, `.codex`, `secrets`) tupu I/O diski ọ bụla.

### Ime Ka HTTP Sie Ike

`http_request` (`builtins.ts:257`):

- Ndepụta usoro ndị ekwere: `GET, HEAD, POST, PUT, PATCH, DELETE`
- Isiokwu ọpụpụ ndị egbochiri: `host, connection, content-length, cookie, set-cookie, authorization, proxy-authorization`
- Agbanyụrụ ntụgharị (`allowRedirect: false`)
- A na-ebufe ya site na `safeOutboundFetch` nwere `guard: "public-only"` (a na-egbochi mpaghara nzuzo/loopback)
- A na-egbutu nzaghachi n'ókè `SKILLS_MAX_HTTP_RESPONSE_BYTES`; onye ahịa na-ahụ `truncated: true`

| `/api/skills/skillssh` | GET | Chọọ katalọgụ skills.sh (`?q=&limit=`, nke oke ya bụ 100) |
| `/api/skills/skillssh/install` | POST | Wụnye nka skills.sh (chọrọ onye na-eweta ọrụ nọ n'ọrụ = `skillssh`) |
| `/api/skills/executions` | GET | Akụkọ mmezu e kewara na peeji (`?apiKeyId=`) |
| `/api/skills/executions` | POST | Mee nka edebanyere aha ozugbo |

Endpoint `POST /api/skills/executions` na-eweghachi HTTP `503` tinyere `{ error: "Skills execution is disabled..." }` mgbe `settings.skillsEnabled === false` (`executor.ts:42-45`). Ndị na-ahụ maka sistemụ nwere ike ịgbanwe isi mgba ọkụ site na **Ntọala → AI**.

### Ọmụmaatụ: wụnye nka ahaziri iche

```bash
curl -X POST http://localhost:20128/api/skills/install \
  -H "Authorization: Bearer $OMNIROUTE_MGMT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "reverse-text",
    "version": "1.0.0",
    "description": "Reverses a string",
    "schema": {
      "input":  { "type": "object", "properties": { "text": { "type": "string" } }, "required": ["text"] },
      "output": { "type": "object", "properties": { "reversed": { "type": "string" } } }
    },
    "handlerCode": "echo-handler",
    "apiKeyId": "your-api-key-id"

```

Eriri `handlerCode` bụ **nchọ aha handler** — ọ bụghị koodu enwere ike imezu. Onye mmezu na-eji `skillExecutor.registerHandler(name, fn)` kee ya ụzọ (`executor.ts:25`). Nwụnye sitere n'ahịa na-echekwa ederede SKILL.md n'ọhịa a dị ka akwụkwọ nkọwa ma na-eziga mmezu site na oku ngwa ọrụ nke model mepụtara. A naghị eji eval mee isi mmalite onye ọrụ nyere n'ụzọ aka ike.

## Ndụmọdụ Maka Ọrụ

- **Isi mgba ọkụ:** `settings.skillsEnabled = false` na-egbochi mmezu niile ma weghachite HTTP `503` na `/api/skills/executions`. Registry ahụ na-aga n’ihu ibu data.
- **Mechie ụzọ ọpụpụ:** hapụ `SKILLS_SANDBOX_NETWORK_ENABLED` ka edoghị ya (ndabara) maka sandboxing kewapụrụ kpamkpam na netwọkụ. `networkEnabled: true` nke oku ọ bụla ka chọrọ isi gate ahụ.
- **Kwe ka images ụfọdụ:** tọọ `SKILLS_ALLOWED_SANDBOX_IMAGES="myorg/sandbox:1.0,node:22-alpine"` iji gbasaa allowlist.
- **Nyochaa mmezu:** `/dashboard/skills/executions` na `omniroute_skills_executions` abụọ na-ajụ `skill_executions`. Mmezu gara nke ọma nwere `durationMs`; ndị dara ada nwere `errorMessage`.
- **Ime ka cache ghara ịdị ire:** kpọọ `skillRegistry.invalidateCache()` mgbe i ji aka dezie DB; ma ọ bụghị ya, chere 60 s.
- **Workspace amaghị onye nwe ya:** mgbe `apiKeyId` tọgbọ chakoo, oku niile na-enweta otu hash gaa na workspace `"anonymous"` ahụ — koodu na-eburu nkekọ n’uche kwesịrị izipu ezigbo key mgbe niile.

## Usoro Ndụ Mmezu (v3.8.16+)

`SkillExecutor` (`src/lib/skills/executor.ts`) bụ **singleton** nke na-achịkwa kpọkuo nkà ọ bụla. Ịghọta usoro ndụ ya dị oke mkpa maka idozi nsogbu oge mmezu gafere, nnwale ọzọ, na ọnọdụ mmezu.

### Usoro Ndụ Nwere Nzọụkwụ 5

```
   a kpọrọ execute()
        │
        ▼
  ┌─────────────┐
  │  PENDING    │  ← nọ n'ahịrị, amalitebeghị (e kere ahịrị DB)
  └──────┬──────┘
         │ malite handler
         ▼
  ┌─────────────┐
  │  RUNNING    │  ← a kpọrọ handler nwere oke oge
  └──────┬──────┘
         │
    ┌────┴────┬──────────┬──────────┐
    │         │          │          │
    ▼         ▼          ▼          ▼
  SUCCESS   ERROR     TIMEOUT   (ọ dịghị ụzọ ọzọ — parent kwụsịrị ya)
    │         │          │
    └────┬────┴──────────┘
         │
         ▼
   E ji status, output, durationMs melite ahịrị DB
```

### Nhazi Ndabara

| Ntọala       | Ndabara       | Enwere ike ịhazi ya site na          |
| ------------ | ------------- | ------------------------------------ |
| `timeout`    | `30000` (30s) | `skillExecutor.setTimeout(ms)`       |
| `maxRetries` | `3`           | `skillExecutor.setMaxRetries(count)` |

> **Ihe dị mkpa**: Executor bụ singleton — ịkpọ `setTimeout()` na-emetụta kpọkuo niile sochirinụ n'ụwa niile. A naghị akwado oke oge pụrụ iche maka nkà ọ bụla ugbu a; ọ bụrụ na ịchọrọ oke oge dị iche iche maka nkà ọ bụla, zipụ usoro dị iche iche ma ọ bụ mepụta fork nke executor.

### Uru Ọnọdụ

Site na `src/lib/skills/types.ts`:

```ts
enum SkillStatus {
  PENDING = "pending", // Nọ n'ahịrị, amalitebeghị
  RUNNING = "running", // A kpọrọ handler
  SUCCESS = "success", // Handler weghachiri output ziri ezi
  ERROR = "error", // Handler tụbara exception
  TIMEOUT = "timeout", // Gafere oke oge executor
}
```

> **Ndetu**: A kọwara ọnọdụ `TIMEOUT` na enum mana mmejuputa executor dị ugbu a **anaghị ede ya n'ezie na DB** — ngafe oge na-apụta dị ka `ERROR` yana ozi `"Skill execution timed out"`. E debeela enum ọnọdụ ahụ maka ojiji n'ọdịnihu.

### Inyocha Mmezu

```ts
import { skillExecutor } from "omniroute/skills/executor";

// Nweta otu mmezu kpọmkwem site na ID
const exec = skillExecutor.getExecution("exec-uuid-123");
if (exec) {
  console.log(`${exec.skillName}: ${exec.status} in ${exec.durationMs}ms`);
}

// Depụta mmezu ndị na-adịbeghị anya maka API key
const recent = skillExecutor.listExecutions("api-key-id", 50, 0);
for (const e of recent) {
  console.log(`${e.skillName} → ${e.status} (${e.durationMs}ms)`);
}

// Gụọ mkpokọta mmezu niile
const total = skillExecutor.countExecutions("api-key-id");
```

### Omume Nnwale Ọzọ

A na-echekwa ntọala `maxRetries` mana usoro `execute()` nke executor **anaghị eji ya ugbu a** — ọ na-eme naanị otu nnwale. E kpughere uru `maxRetries` maka mmejuputa n'ọdịnihu na maka hooks chọrọ ịgụ ya.

Maka ugbu a, a ga-emejuputa nnwale ọzọ n'ime skill handler n'onwe ya. A na-edebanye
nkà ndị arụnyere n'ime sistemụ n'aka executor (dịka `registerBuiltinSkills(executor)`
/ `registerBrowserSkill(executor)` na `src/lib/skills/builtin/`); handler ọ bụla
ị debanyere nwere ike ịkechie loop nnwale ọzọ nke ya:

```ts
// n'ime skill handler
async function handler(input, ctx) {
  const maxRetries = 3;
  let lastError: Error | null = null;

  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      return await fetchSomething(input);
    } catch (err) {
      lastError = err as Error;
      if (attempt < maxRetries) {
        await new Promise((r) => setTimeout(r, 1000 * attempt));
      }
    }
  }
  throw lastError;
}
```

## Nkọwa Zuru Ezu Banyere SkillMode

Enum `SkillMode` (`src/lib/skills/types.ts`) na-achịkwa **mgbe na otu** e si akpọ skills:

```ts
enum SkillMode {
  AUTO = "auto", // LLM na-ekpebi mgbe a ga-akpọ skill
  MANUAL = "manual", // A na-akpọ ya naanị site na arịrịọ onye ọrụ doro anya
  HYBRID = "hybrid", // Ntụle AUTO + iji aka gbanwee ya
}
```

> **Rịba ama**: Codebase ahụ na-akọwa `SkillMode` (AUTO/MANUAL/HYBRID), ebe field `Skill.mode` na-eji ọdịdị dị iche (`"on" | "off" | "auto"`). Ha nwere njikọ mana ha abụghị otu ihe — `SkillMode` bụ maka iwu executor, `Skill.mode` bụ maka ime ka skill nke ọ bụla rụọ ọrụ ma ọ bụ ghara ịrụ ọrụ.

### Mgbe A Ga-eji Mode Nke Ọ Bụla

| Mode     | Omume LLM                                                                     | Ebe e ji ya eme ihe                                  |
| -------- | ----------------------------------------------------------------------------- | ---------------------------------------------------- |
| `AUTO`   | LLM nwere ike ịkpọ skill mgbe ọ hụrụ na ọ dị mkpa                             | Skills maka ọrụ izugbe (ịgụ faịlụ, arịrịọ HTTP)      |
| `MANUAL` | LLM enweghị ike ịkpọ skill; naanị oku API `executeSkill` doro anya na-akpọ ya | Ọrụ ndị chọrọ nlezianya (ide na database, ịkwụ ụgwọ) |
| `HYBRID` | LLM nwere ike ịtụ aro skill ahụ; onye ọrụ ga-ekwenyerịrị                      | Skills nwere mmetụta ndị ọzọ mana na-adịghị ize ndụ  |

### Ntụle AUTO

Mgbe mode `AUTO` na-arụ ọrụ, a na-enyocha skill ọ bụla nwere ike ịhọrọ megide context nke arịrịọ ahụ
site na `scoreAutoSkill()` dị na `src/lib/skills/injection.ts` — usoro isi ihe integer
a na-agbakwụnye ọnụ (ndakọrịta aha skill, mkpụrụokwu aha/tag/nkọwa ndị dakọtara,
ntụziaka background-reason, mgbakwunye/mwepu isi ihe provider-hint). Skills
`AUTO_MAX_SKILLS = 5` kacha elu nwere `score >= AUTO_MIN_SCORE = 3` ka a na-etinye dị ka
tools enwere ike ịkpọ, ebe a na-eji `installCount`, ma emesịa aha, kewaa ndị nwere otu akara. Lee tebụl isi ihe zuru ezu
na [**Mmepụta Tool Schema → Ntụle AUTO**](#auto-scoring) nke dị na mbụ n'ime
akwụkwọ a; enweghị threshold float ụdị `0.6`, ọ dịghịkwa ntụle `registry.ts`.
