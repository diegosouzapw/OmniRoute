AgentBridge bụ proxy MITM (Man-in-the-Middle) nke OmniRoute, nke na-egbochi okporo HTTPS sitere n’aka ndị nnọchi anya AI nke IDE ma na-ebughachi ya site na injin ntụgharị ụzọ jikọtara ọnụ nke OmniRoute. Ọ na-akwado **ndị nnọchi anya IDE 10** — Antigravity, Kiro, GitHub Copilot, GHE Copilot, OpenAI Codex, Cursor, Zed, Claude Code, Open Code, na Trae (a ka na-enyocha ya) — nke na-eme ka OmniRoute bụrụ proxy MITM nwere nkwado kacha gbasaa maka ndị enyemaka AI na-ede koodu n’ahịa.

**Ebe dashboard dị:** `/dashboard/tools/agent-bridge`
**Otu sidebar:** Ngwaọrụ (mgbe Cloud Agents gasịrị)
**Hụkwa:** [`TRAFFIC_INSPECTOR.md`](./TRAFFIC_INSPECTOR.md) — nyochaa okporo niile e gbochiri ozugbo; `docs/security/MITM-TPROXY-DECRYPT.md` (git; anaghị etinye ya na `/docs` mgbe a na-achịkọta ya) — ọnọdụ njide transparent-decrypt nke Linux TPROXY, nke ụzọ `/api/tools/agent-bridge/tproxy` na-achịkwa.

## §1 Nchịkọta

### Gịnị bụ AgentBridge?

Mgbe onye nnọchi anya IDE (dịka GitHub Copilot, Cursor, Claude Code) na-eme oku API, ọ na-ejikọta ozugbo na onye na-eweta AI dị n’elu (OpenAI, Anthropic, wdg.). AgentBridge na-egbochi njikọ ahụ n’enweghị ihe onye ọrụ ga-achọpụta na ọkwa TLS — na-achọghị mgbanwe nhazi ọ bụla n’aka onye nnọchi anya — ma degharịa arịrịọ ahụ ka ọ gafee na OmniRoute.

Nke a pụtara na ị nwere ike:

- **Tụgharịa onye nnọchi anya ọ bụla gaa na onye na-eweta ọ bụla**: Copilot na-ekwurịta okwu na OpenAI? Duzie ya gaa na Anthropic Claude, Gemini, ma ọ bụ onye ọ bụla n’ime ndị na-eweta 352 nke OmniRoute.
- **Tinye mapịng ụdịdị**: `gemini-3-flash` → `claude-sonnet-4.7` n’enweghị ihe onye ọrụ ga-achọpụta n’ọkwa handler.
- **Lelee okporo niile nke ndị nnọchi anya**: a na-ebipụta arịrịọ ọ bụla e gbochiri na [Traffic Inspector](./TRAFFIC_INSPECTOR.md).
- **Tinye nkwụsi ike nke OmniRoute**: ntụgharị ụzọ ngwakọta, circuit breakers, fallbacks, na nsuso ụgwọ na-arụkwa ọrụ maka okporo ndị nnọchi anya IDE.

## §2 Nhazi ụlọọrụ

### 2.1 Nchịkọta ihe mejupụtara ya

```
IDE Agent (VS Code / Cursor / wdg.)
    │  HTTPS (ọdụ ụgbọ mmiri 443)
    ▼
/etc/hosts — 127.0.0.1 api.githubcopilot.com   ← ntụgharị DNS
    │
    ▼
src/mitm/server.cjs  (ọdụ ụgbọ mmiri 443, usoro nwa CJS)
    │  na-achọpụta ebe a na-aga site na SNI nke nkụnyeisi Host
    │  na-emepụta asambodo TLS maka SNI ọ bụla nke AgentBridge CA bịanyere aka na ya
    ├── Ọ dabara na ndepụta ngafe? → ngafe TCP ozugbo (enweghị izochapụ ezoro ezo)
    ├── Ọ dabara na ebe a na-aga? → fetch → rawụta OmniRoute (ọdụ ụgbọ mmiri 20128)
    │       └── handler.intercept() — TypeScript
    │               ├── maskSecrets() n'ahụ/nkụnyeisi arịrịọ
    │               ├── TrafficBuffer.push() — na-ebipụta na Traffic Inspector
    │               └── fetchRouter() → /v1/chat/completions
    └── Enweghị ndakọrịta? → ngafe TCP ozugbo (enweghị izochapụ ezoro ezo)
```

### 2.2 Sava MITM (`src/mitm/server.cjs`)

Sava MITM bụ isi na-arụ ọrụ dị ka usoro nwa Node.js CJS (iji zere idegharị ebe koodu CJS dị ugbu a). Ọ:

- Na-ege ntị n'ọdụ ụgbọ mmiri 443 (ọ chọrọ ikike ma ọ bụ `authbind`/`setcap`)
- Na-anata ọwara CONNECT sitere na OS (site na ntụgharị DNS nke `/etc/hosts`)
- Na-emepụta asambodo TLS maka SNI ọ bụla nke AgentBridge CA (`DATA_DIR/mitm/ca.crt`) bịanyere aka na ya
- Na-achọpụta agent ebumnuche site na nkụnyeisi Host site na ndebanye aha `targets/index.ts`
- Na-eziga ya na oyi akwa njikwa TypeScript site na HTTP gaa na `http://127.0.0.1:20128`

A na-ebunye `TARGET_HOSTS` site na `DATA_DIR/mitm/targets.json` (nke `targets/index.ts` na-ede mgbe usoro na-amalite), nke na-enye ohere mmelite na-agbanwe agbanwe n’enweghị ịmalitegharị sava CJS.

> **Ụdị Root-CA (#6684).** Nkọwa asambodo maka SNI ọ bụla nke CA bịanyere aka na ya dị n’elu
> bụ ụdị root-CA a na-echekwa nke agbakwunyere na #6684 (`src/mitm/cert/rootCa.ts` +
> `src/mitm/_internal/rootCaShim.cjs`, na-ejigharị kriptografi CA/leaf nke
> egosila na ọ na-arụ ọrụ maka TPROXY na `src/mitm/tproxy/dynamicCert.ts`) — ọ na-anọchi
> leaf ochie kwụ otu ebe nke bịanyere onwe ya aka (`src/mitm/cert/generate.ts`, nke ka
> metụtara naanị host antigravity) nke ụzọ `server.crt`/`server.key`
> nkịtị dị na diski na-egosi. **Omume mbugharị**: nrụnye ọhụrụ (enweghị
> `server.crt` gara aga) na-enweta ụdị root-CA na-akpaghị aka; nrụnye nke
> tụkwasịlarị leaf ochie kwụ otu ebe obi na-aga n'ihu iji ya ruo mgbe onye njikwa setịpụrụ
> `MITM_ROOT_CA_ENABLED=true` ma malitegharịa bridge ahụ (`src/mitm/cert/migration.ts`
> bụ ọrụ mkpebi dị ọcha — CA MITM a tụkwasịrị obi nke nwere ike ịbịanye aka na leaf maka
> host **ọ bụla** nwere ikike dị ukwuu karịa leaf ochie nwere SAN a kapịrị ọnụ, ya mere
> mgbanwe ahụ anaghị eme na nzuzo maka nrụnye a tụkwasịlarị obi). A na-etinye asambodo CA
> n’otu oghere trust-store `omniroute-mitm.crt` ahụ leaf ochie ji
> (`cert/install.ts::installCaCert`) — nhicha ntụkwasị-obi abụọ adịghị mkpa.

### 2.3 Ntọala handler (`src/mitm/handlers/base.ts`)

Handler agent niile na-agbatị `MitmHandlerBase`:

```ts
export abstract class MitmHandlerBase {
  abstract readonly agentId: AgentId;

  abstract intercept(
    req: IncomingMessage,
    res: ServerResponse,
    body: Buffer,
    mappedModel: string
  ): Promise<void>;

  // Ndị enyemaka echekwara: fetchRouter, pipeSSE, hookBufferStart, hookBufferUpdate
}
```

Handler ọ bụla na-akpọ `hookBufferStart()` tupu ọ gafee site na proxy, ma kpọọ `hookBufferUpdate()` mgbe ọ gwụchara. Ndị a na-etinye ndebanye `InterceptedRequest` n'ime `globalTrafficBuffer` (lee [Traffic Inspector](./TRAFFIC_INSPECTOR.md) §4).

### 2.4 Ndebanye aha ebumnuche (`src/mitm/targets/`)

Agent ọ bụla nwere faịlụ ebumnuche nkọwapụta:

```ts
// src/mitm/targets/copilot.ts
export const COPILOT_TARGET: MitmTarget = {
  id: "copilot",
  name: "GitHub Copilot",
  hosts: ["api.githubcopilot.com", "copilot-proxy.githubusercontent.com"],
  port: 443,
  endpointPatterns: ["/chat/completions", "/v1/chat/completions"],
  defaultModels: [{ id: "gpt-4o", name: "GPT-4o", alias: "gpt-4o" }],
  handler: () => import("../handlers/copilot"),
  riskNoticeKey: "providers.riskNotice.oauth",
};
```

Ndebanye aha ahụ (`targets/index.ts`) na-ebupụ `ALL_TARGETS` ma na-ewepụta `DATA_DIR/mitm/targets.json` mgbe usoro na-amalite.

### 2.5 Ngafe ozugbo na ndepụta ngafe (`src/mitm/passthrough.ts`)

**Ndepụta ngafe** (a na-enyocha ya mbụ, ọ na-ebute ụzọ karịa ndakọrịta ebumnuche):

- Ụkpụrụ ndabara: host ụlọ akụ, `.gov.`, ndị na-eweta OAuth/SSO (Okta, Auth0), wdg.
- Ụkpụrụ onye ọrụ: echekwara na tebụl DB `agent_bridge_bypass`
- Host ndị a gafere na-enweta ọwara TCP doro anya — a **dịghị mgbe** ezopụ TLS

**Ndabara ngafe ozugbo** (enweghị ndakọrịta ebumnuche, ọ dịghịkwa na ndepụta ngafe):

- Na-enwetakwa ọwara TCP — a dịghị mgbe ebipụ njikọ
- Na-egbochi AgentBridge imebi okporo ụzọ HTTPS izugbe nke sistemụ

Usoro mkpa nke rawụta:

```
ndepụta ngafe → ndakọrịta ebumnuche → ngafe ozugbo
```

### 2.6 Asambodo CA nke upstream (`src/mitm/upstreamTrust.ts`)

Maka gburugburu netwọk ụlọọrụ nwere CA ahaziri iche:

```bash
AGENTBRIDGE_UPSTREAM_CA_CERT=/path/to/corporate-ca.pem
```

Mgbe edobere ya, ọ na-ahazi global dispatcher nke `undici` site na asambodo CA mgbakwunye ahụ, na-eme ka AgentBridge nwee ike iru ndị na-eweta upstream site na proxy nkwụsị TLS nke ụlọọrụ.

### 2.7 Ikpuchi ihe nzuzo (`src/mitm/maskSecrets.ts`)

A na-etinye ihe nyocha clean-room nọọrọ onwe ya n'ahụ arịrịọ na nkụnyeisi nzere
**tupu** ha abanye na buffer Traffic Inspector ma ọ bụ ndekọ ọ bụla. Ọ na-eme otu ngafe kwụ ọtọ:

- Token nwere prefix `sk-` / `ak-` / `pk-` (ụdị OpenAI/Anthropic)
- Nzere RFC 6750 `Authorization: Bearer <token>`, ebe token dum na-ebute ụzọ
- Token izugbe ogologo na-adịghị enye nkọwa (≥40 mkpụrụedemede), gụnyere ụdị nwere ntụpọ na padding

`sanitizeHeaders()` na-agbanwe aha ndị echekwara ka ha bụrụ mkpụrụedemede nta, na-ejikọta uru array n'ụzọ a kara aka, na-ewepụ
ndepụta mgbochi hop-by-hop/framing a na-ekekọrịta (gụnyere nyocha njirimara proxy), na-ekpuchi `cookie` na
`set-cookie` kpamkpam, ma na-enyefe uru nzere n'aka ihe nyocha ahụ.

### 3.2 Tụkwasị asambodo ahụ obi

OS ga-atụkwasịrịrị asambodo CA nke AgentBridge obi tupu IDE anabata njikọ MITM ahụ.

**Linux (NSS — Chrome/Firefox):**

```bash
certutil -A -d sql:$HOME/.pki/nssdb -n "OmniRoute AgentBridge" -t CT,, -i ~/.omniroute/mitm/ca.crt
```

**macOS (Keychain):**

```bash
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/.omniroute/mitm/ca.crt
```

**Windows (certmgr):**

```powershell
certutil -addstore -f Root $env:USERPROFILE\.omniroute\mitm\ca.crt
```

Ma ọ bụ jiri bọtịnụ "Tụkwasị Asambodo Obi" dị na dashboard (ọ na-eme iwu kwesịrị ekwesị maka OS gị, tinyere arịrịọ sudo ma ọ bụrụ na achọrọ ya).

#### IDE ndị dabeere na Electron anaghị eji ebe OS na-edobe asambodo ntụkwasị obi (`NODE_EXTRA_CA_CERTS`)

Ụfọdụ IDE — karịsịa **Antigravity IDE**, na ngwa ndị ọzọ sitere na Electron / VS Code — na-etinye
runtime Node.js nke ha, nke **na-adịghị eleba anya n'ebe OS na-edobe asambodo ntụkwasị obi** maka
`fetch`/HTTPS na-apụ apụ. Ịtụkwasị CA obi n'ọkwa OS/NSS zuru ezu maka **backend** nke IDE
dị ka ọ dị n'ime sistemụ (dịka ọmụmaatụ, sava asụsụ Go, nke na-eji ngwugwu CA nke OS), mana
**frontend Electron** ka ga-enwe ọdịda TLS — nke a na-apụta dịka a _kpọpụla onye ọrụ_ na ngwa ahụ
ma ọ bụ na ọ na-egosi _"njehie njikọ"_ n'agbanyeghị na ndekọ MITM na-egosi na oku mbido nke
backend na-eweghachi `200`. A chọrọ usoro abụọ, ha abụọ dịkwa mkpa:

1. Tụnye runtime aka na CA ahụ kpọmkwem:
   ```bash
   export NODE_EXTRA_CA_CERTS=/path/to/omniroute-agentbridge-ca.crt
   ```
2. **Si na shell ahụ malite IDE.** Ịmalite ya site na akara ngosi desktop / Dock / menu Start
   **anaghị** eketa exports nke shell, ebe `~/.config/environment.d/*.conf` na-amalite ịrụ ọrụ naanị
   mgbe nbanye eserese ọhụrụ gasịrị. Buru ụzọ mechie IDE kpamkpam — mkpọchi singleton nke Electron
   pụtara na mbido nke abụọ ga-elekwasị naanị anya n'usoro dị ugbu a, a ga-elegharakwa gburugburu ọhụrụ ahụ anya.

Usoro OS-trust + NSS dị n'elu ka dị mkpa (ngwugwu netwọkụ Chromium nke ụfọdụ usoro
njirimara na-eji na-agụ ebe NSS nke onye ọrụ ọ bụla na-edobe asambodo, ma nwee pin static nke ya
maka `*.googleapis.com` nke CA a tụkwasịrị obi n'ime mpaghara ahụ na-akagbu). `NODE_EXTRA_CA_CERTS`
na-ekpuchi ụzọ `fetch` nke Node n'elu nke ahụ.

### 3.3 Nduzi DNS

### 3.7 Mbubata/mbupụ nhazi a pụrụ ibugharị

AgentBridge nwere ike ịtụgharị ọnọdụ **onye na-arụ ọrụ nwere ike ịhazigharị** ka ọ bụrụ ngwugwu JSON nwere ụdị mbipụta, ka e nwee ike imepụtaghachi nhazi ahụ n’igwe dị iche iche. Serializer ahụ bụ `src/lib/inspector/configPortability.ts` (`exportConfig()` / `importConfig()`), nke `AgentBridgeConfigSchema` na-enyocha.

Mbupụ ahụ nwere kpọmkwem akụkụ atọ (a kpachapụrụ anya **ỊGHỊ** ebupụ ụkpụrụ ndabara arụnyere n’ime ya, ka mbubata ghara imepụtaghachi ha ugboro abụọ ma ọ bụ ịlụso ha ọgụ):

| Field            | Isi mmalite                                                   | Nkọwa                                                                  |
| ---------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `bypassPatterns` | bypass patterns onye ọrụ kọwara (`agent_bridge_bypass`)       | ewepụrụ pattern ndabara nke bank/gov/okta                              |
| `customHosts`    | custom hosts nke Traffic Inspector (`inspector_custom_hosts`) | nke ọ bụla: `{ host, kind: "llm"\|"app"\|"custom", label? }`           |
| `agentMappings`  | model mappings nke agent ọ bụla (`agent_bridge_mappings`)     | `{ [agentId]: [{ source, target }] }` maka agent ọ bụla nwere mappings |

```jsonc
// GET /api/tools/agent-bridge/config
{
  "version": 1,
  "bypassPatterns": ["*.internal.example.com"],
  "customHosts": [{ "host": "api.example.com", "kind": "llm", "label": null }],
  "agentMappings": {
    "copilot": [{ "source": "gpt-4o", "target": "claude-sonnet-4.7" }],
  },
}
```

**Omume mbubata** (`POST /api/tools/agent-bridge/config`): bypass patterns na mappings nke agent ọ bụla **na-anọchi ihe niile**; a na-agbakwunye custom hosts **n’ụzọ idempotent** (`INSERT OR IGNORE`). Nzaghachi ahụ na-akọ ole n’ime nke ọ bụla etinyere:

```jsonc
{ "ok": true, "bypassPatterns": 1, "customHosts": 1, "agents": 1 }
```

Ihe ndị **NA-ADỊGHỊ** na nhazi ahụ: ọnọdụ ọrụ sava, ụzọ faịlụ asambodo, ọnọdụ DNS nke onye nnọchi anya ọ bụla, ụzọ upstream CA, na ntọala TPROXY — ihe ndị ahụ bụ ọnọdụ host/runtime, ọ bụghị mmasị ndị enwere ike ibugharị.

### Ndepụta bypass maka hosts nwere mmetụta pụrụ iche

Ndepụta bypass na-eme ka ụlọ ọrụ ego, ndị na-enye OAuth/SSO, na hosts ndị ọzọ nwere mmetụta pụrụ iche ghara ịbụ ndị a na-ewepụtụ encryption ha **mgbe ọ bụla**. Okporo TLS ha na-agafe dịka transparent TCP tunnel — OmniRoute anaghị ahụ plaintext ahụ mgbe ọ bụla.

Ụkpụrụ bypass ndabara gụnyere:

- `*.bank.*`, `*.gov.*` (ego/gọọmentị)
- `*.okta.com`, `*.auth0.com`, `*.microsoft.com` (SSO/njirimara)
- `*.apple.com`, `*.icloud.com` (ọrụ sistemụ Apple)

A na-echekwa ụkpụrụ bypass onye ọrụ gbakwunyere na tebụl `agent_bridge_bypass`, ha na-ebute ihe ndị ọzọ niile ụzọ.

### Ikpuchi ihe nzuzo

A na-etinye `maskSecrets()` sitere na `src/mitm/maskSecrets.ts`:

- N'ahụ request ọ bụla tupu `TrafficBuffer.push()`
- Na header ọ bụla tupu logging ma ọ bụ broadcasting

Ụkpụrụ: tokens nwere prefix `sk-`/`ak-`/`pk-`, tokens `Bearer`, na tokens izugbe nwere mkpụrụedemede ≥40.

### Upstream CA cert

Mgbe edobere `AGENTBRIDGE_UPSTREAM_CA_CERT`, a na-agụ faịlụ ahụ mgbe mmalite. Ọ bụrụ na path ahụ dị mana enweghị ike ịgụ faịlụ ahụ, AgentBridge na-edekọ njehie doro anya ma jụ ịmalite (nke a na-egbochi ọdịda TLS na-enweghị ọkwa n'ime gburugburu ụlọ ọrụ).

### Mmachi ndị a maara

- **Port 443 chọrọ ikike pụrụ iche**: Na Linux, AgentBridge chọrọ `setcap 'cap_net_bind_service=+ep'` na Node binary, ma ọ bụ ka e jiri `authbind` mee ya. Ọkachamara Nhazi na-egosi ntuziaka ndị metụtara OS.
- **A ghaghị ịmalitegharị IDE**: Mgbe ntụgharị DNS gasịrị, a ghaghị ịmalitegharị IDE ka mkpebi host ọhụrụ ahụ malite ịrụ ọrụ.
- **OAuth tokens ndị e tinyere kpọmkwem n'ime sistemụ**: Ụfọdụ agents (Kiro, Antigravity) na-echekwa OAuth refresh tokens n'ógbè ngwaọrụ. Ihe ndị a na-apụta ìhè nye AgentBridge — ọ na-ahụ Bearer token na request ọ bụla, nke a na-ekpuchi tupu logging.
- **Electron frontends chọrọ `NODE_EXTRA_CA_CERTS`**: IDE ndị frontend ha na-arụ n'elu Node/Electron runtime ejikọtara ọnụ na-eleghara OS/NSS trust store anya, a ga-ebido ha site na shell ebe edobere `NODE_EXTRA_CA_CERTS` (lee §3.2). Ihe mgbaàmà mgbe ọ na-adịghị: IDE backend na-eme authentication (MITM na-egosi `200`s) mana UI ka nọ n'ọnọdụ logged out.
- **Nrụnye IDE dị iche iche nke otu ụdị na-arụ ọrụ n'adabereghị onwe ha**: nrụnye sistemụ (dịka ọmụmaatụ `/usr/share/antigravity/antigravity`) na nrụnye "Full" nke onye ọrụ n'ógbè ya (dịka ọmụmaatụ `~/AntigravityIDE_Full/antigravity-ide`) bụ processes dị iche iche nwere runtimes nke ha — a ga-ebido nke ọ bụla ọzọ ka etinyere CA n'ime ya. Chọpụta nke na-arụ ọrụ site na binary path ya tupu ịmalitegharị ya.
- **System prompt nke agent na-ekpebi njirimara, ọ bụghị model e zigara request ahụ na ya**: mgbe ị jikọtara model nke agent na provider ọzọ, nzaghachi ahụ ka na-ekwu na ọ bụ njirimara mbụ nke agent ahụ (dịka ọmụmaatụ Antigravity na-aza "Gemini na-enye m ike") n'ihi na IDE na-etinye nke ahụ n'ime system prompt. Kwenye ezigbo backend n'ime `call_logs` / `proxy_logs` (`provider`, `model`, `target_format`), ọ bụghị site n'ịjụ model onye ọ bụ.

### Esemokwu na port 443

Ọ bụrụ na usoro ọzọ amalitelarị ige ntị na port 443 (sava weebụ, VPN, wdg.):


### A tụkwasịghị asambodo ahụ obi

Ọ bụrụ na IDE gosipụta njehie TLS mgbe ịmalitechara AgentBridge:

1. Nyochaa na etinyere asambodo ahụ: `security find-certificate -c "OmniRoute AgentBridge"` (macOS) ma ọ bụ `certutil -L -d sql:$HOME/.pki/nssdb` (Linux/NSS)
2. Ụfọdụ ngwa na-edobe ebe nchekwa ntụkwasị obi nke ha (Firefox, Chrome na Linux). Gbaa "Trust Cert" ọzọ ma lelee ebe nchekwa asambodo pụrụ iche nke NSS/Firefox.
3. Malitegharịa IDE mgbe ị tụkwasịrị asambodo ahụ obi — nnọkọ TLS ndị na-aga n'ihu na-eji ọnọdụ ntụkwasị obi ochie.

### IDE apụọla na akaụntụ / "connection error" n'agbanyeghị CA a tụkwasịrị obi

Ihe mgbaàmà: mgbe e megharịrị ntụgharị DNS ma tụkwasị CA obi, IDE dabere na Electron (dịka Antigravity)
na-emepe mgbe **apụla na akaụntụ** ma ọ bụ na-egosi njehie njirimara/njikọ, ma ndekọ MITM na-egosi na
oku mmalite (`loadCodeAssist`, `fetchAvailableModels`, …) na-eweghachi `200`.

Ihe kpatara ya: **Node/Electron runtime e tinyere n'ime IDE na-eleghara ebe nchekwa ntụkwasị obi OS anya**. Backend
nke sistemụ ahụ n'onwe ya (sava asụsụ Go) na-atụkwasị OS CA obi ma na-eme njirimara, mana frontend Electron
anaghị eme ya — ya mere UI na-eche na ọ nọghị n'ịntanetị.

Ndozi (usoro abụọ ahụ): mbupụ `NODE_EXTRA_CA_CERTS=<ca.crt>` **ma malitegharịa IDE site na
shell ahụ**, ọ bụghị site na akara ngosi desktọpụ. Buru ụzọ mechie IDE kpamkpam — mkpọchi singleton nke Electron pụtara na
mmalite nke abụọ ga-elekwasị anya naanị na usoro dị adị, a ga-elegharakwa gburugburu ọhụrụ ahụ anya. Lee §3.2.
Nke a yiri akụkọ upstream ka ghe oghe ebe agent kwụụrụ onwe ya na-arụ ọrụ site na MITM mana ụdị IDE
anaghị arụ ọrụ n'okpuru otu nhazi ahụ.

## §8 Atụmatụ ụzọ

### Nnyocha Trae

Trae bụ onye enyemaka AI maka ide koodu nke ka dị ọhụrụ. Tupu etinye njikwa n'ọrụ:

1. Chọpụta faịlụ binary/mgbakwunye ya n'ahịa VS Code / JetBrains ma ọ bụ dịka ngwa kwụụrụ onwe ya
2. Jiri mitmproxy jide okporo data iji chọpụta ndị nnabata API na ọdịdị endpoint
3. Chọpụta usoro nyocha njirimara
4. Mee mkpebi ịga n'ihu/ịghara ịga n'ihu dabere na TOS na etu o si dị mfe ịchọpụta API

Ruo mgbe nnyocha ahụ ga-agwụ, kaadị Trae dị na dashboard na-egosi akara "A na-enyocha" nke nwere njikọ "Kọọ ma ọ ga-ekwe omume". Stub njikwa dị na `src/mitm/handlers/trae.ts` na-ewepụta njehie ahaziri ahazi `Not yet implemented`.

### Ndị agent nọ na backlog (MITM dị mkpa — enweghị nkwado maka base URL ahaziri iche)

Ngwa ndị a anaghị akwado base URL ahaziri iche na ụdị ha dị ugbu a, nke mere na MITM bụ naanị ụzọ e si egbochi okporo data. Ntụle ma ha ga-ekwe omume ka na-echere:

- **Windsurf** (Codeium/Cognition)
- **Amp** (Sourcegraph)
- **Amazon Q / Kiro CLI** (AWS Bedrock — dị iche na Kiro IDE)
- **Cowork** (Anthropic desktop)

Rịba ama: GitHub Copilot CLI ≥v1.0.19 na-akwado `COPILOT_PROVIDER_BASE_URL` — jiri nhazi ozugbo kama MITM maka ngwa ahụ.
