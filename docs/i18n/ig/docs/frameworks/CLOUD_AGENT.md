Ọrụ Onye Nnọchi Anya Igwe Ojii **abụghị** mmecha nkata nkịtị. Ọ bụ ngalaba ọrụ na-adịgide adịgide,
nwere ọtụtụ usoro, nke nwere ike iwe nkeji ruo ọtụtụ awa, nwee ike ịmepụta Pull Request dị ka
artifact ya, ma na-akwado ozi ndị ọzọ na-esochi na (n'aka ụfọdụ ndị na-eweta ọrụ) ọnụ ụzọ nkwado atụmatụ.

## Nhazi Sistemụ

```
Onye ahịa (Dashboard / CLI / API)
  → POST /api/v1/agents/tasks (achọrọ njirimara njikwa)
    → Nnyocha CreateCloudAgentTaskSchema (Zod)
    → registry.getAgent(providerId)
    → getCloudAgentCredentials(providerId)
      └─ na-ewepụta site na getProviderConnections({ provider, isActive: true })
         (apiKey buru ụzọ, laghachi na accessToken ma ọ bụrụ na ọ dịghị)
    → agent.createTask({ prompt, source, options }, credentials)
      └─ HTTP POST gaa na API nke onye na-eweta upstream
      └─ na-eweghachi CloudAgentTask nwere id ime + externalId
    → insertCloudAgentTask(...) n'ime cloud_agent_tasks (SQLite)

Nnyocha ugboro ugboro (mmekọrịta umengwụ mgbe a na-agụ):
  GET /api/v1/agents/tasks/[id]
    → getCloudAgentTaskById(id)
    → agent.getStatus(externalId, credentials)  // na-emelite ọnọdụ + mmemme
    → updateCloudAgentTask(...) site na ọnọdụ ọhụrụ, nsonaazụ, completed_at
    → weghachite ọrụ e mere serialization

Mmekọrịta:
  POST /api/v1/agents/tasks/[id]  ahụ: { action: "approve" | "message" | "cancel" }
    → agent.approvePlan(externalId, credentials)        maka "approve"
    → agent.sendMessage(externalId, message, credentials) maka "message"
    → ọnọdụ na-agbanwe gaa na "cancelled"               maka "cancel" (naanị n'ime sistemụ)
```

Mmekọrịta bụ **umengwụ**: a na-eme ka ọnọdụ dị ọhụrụ site na upstream na `GET /tasks/[id]`
ọ bụla. Enweghị poller ndabere. Dashboard ndị chọrọ ọnọdụ ọhụrụ kwesịrị ịna-ajụ endpoint GET
n'ogologo oge kwesịrị ekwesị.

## Ọdịdị ihu `CloudAgentBase`

Isi mmalite: `src/lib/cloudAgent/baseAgent.ts`

```typescript
export interface AgentCredentials {
  apiKey: string;
  baseUrl?: string;
}

export interface CreateTaskParams {
  prompt: string;
  source: CloudAgentSource;
  options: {
    autoCreatePr?: boolean;
    planApprovalRequired?: boolean;
    environment?: Record<string, string>;
  };
}

export interface GetStatusResult {
  status: CloudAgentStatus;
  externalId?: string;
  result?: CloudAgentResult;
  activities: CloudAgentActivity[];
  error?: string;
}

export abstract class CloudAgentBase {
  abstract readonly providerId: string;
  abstract readonly baseUrl: string;

  abstract createTask(p: CreateTaskParams, c: AgentCredentials): Promise<CloudAgentTask>;
  abstract getStatus(externalId: string, c: AgentCredentials): Promise<GetStatusResult>;
  abstract approvePlan(externalId: string, c: AgentCredentials): Promise<void>;
  abstract sendMessage(
    externalId: string,
    message: string,
    c: AgentCredentials
  ): Promise<CloudAgentActivity>;
  abstract listSources(
    c: AgentCredentials
  ): Promise<{ name: string; url: string; branch?: string }[]>;

  protected mapStatus(raw: string): CloudAgentStatus; // usoro ntule upstream-string → enum
  protected generateTaskId(): string; // `task_<ts>_<rand>`
  protected generateActivityId(): string; // `act_<ts>_<rand>`
}
```

`CodexCloudAgent.approvePlan` na-atụpụ njehie ụma — Codex Cloud na-emepụta atụmatụ na-akpaghị aka, ọ nweghịkwa
ọnụ ụzọ nkwado. `CodexCloudAgent.listSources` na-eweghachi `[]`.

`CursorCloudAgent` na-achịkwa Background / Cloud Agents nke Cursor site na REST
API gọọmentị ya (`api.cursor.com/v0`) site na iji **igodo API nke onye ọrụ ma ọ bụ akaụntụ ọrụ** — ụzọ ọzọ dị nchebe,
nke sitere n'aka ndị nwe ya kama iji nnọkọ OAuth nke Cursor IDE ọzọ (onye na-eweta `cursor`,
nke nwere ịdọ aka ná ntị gbasara ihe ize ndụ nke mmachibido). Ọ bụ ihe nkwụnye REST nkịtị (ọ nweghị ndabere
native nke `@cursor/sdk`). `approvePlan` na-atụpụ njehie (ndị ọrụ Cursor na-arụ ọrụ n'onwe ha); `listSources` na-edepụta
ebe nchekwa ndị igodo ahụ nwere ike iru. Cursor na-eweghachi enum ọnọdụ e ji mkpụrụedemede ukwu dee
(`CREATING`/`RUNNING`/`FINISHED`/`ERROR`), nke a na-ejikọta n'ụzọ doro anya na
`CloudAgentStatus` a na-ekekọrịta. Enwere ike iji nzere ọ bụla dochie `baseUrl` ka e nwee ike
imezi ụdị/ụzọ API n'agbanweghị koodu.

## REST API — Usoro ndụ ọrụ

**Nyocha ikike:** Endpoint `/api/v1/agents/tasks*` niile chọrọ **nyocha ikike njikwa**

| OPTIONS | `/api/v1/agents/tasks`        | Nnyocha mbido CORS                                            |

## REST API — Nhazi Njikọ nke Ndị Na-enye Cloud

Ndị endpoint enyemaka ndị a dị n'okpuru `src/app/api/cloud/` ka ndị ahịa dịpụrụ adịpụ
(CLI, ngwa Electron, ma ọ bụ ndị ọrụ mmekọrịta) ji agụ metadata njikọ nke onye na-enye ọrụ
ma chọpụta alias nke model. A na-eji **API key nkịtị** eme nkwenye njirimara ha
(site na `validateApiKey`), ọ bụghị nkwenye njirimara nchịkwa nke endpoint ọrụ na-eji.

| Usoro | Ụzọ                             | Ebumnuche                                                                          |
| ----- | ------------------------------- | ---------------------------------------------------------------------------------- |
| POST  | `/api/cloud/auth`               | Nyochaa API key, weghachite metadata njikọ ezoro akụkụ ya + alias model            |
| PUT   | `/api/cloud/credentials/update` | Mee `accessToken` / `refreshToken` / `expiresAt` ka ha dị ọhụrụ                    |
| POST  | `/api/cloud/model/resolve`      | Chọpụta alias model ka ọ bụrụ `{ provider, model }`                                |
| GET   | `/api/cloud/models/alias`       | Depụta alias model niile                                                           |
| PUT   | `/api/cloud/models/alias`       | Tọọ alias model (ma mekọrịta ya na Cloud na-akpaghị aka ma ọ bụrụ na agbanyere ya) |

`/api/cloud/auth` anaghị eweghachite `apiKey` / `accessToken` / `refreshToken` ndị
na-ezoghị ezo. Ọ na-eweghachite `hasApiKey`, `hasAccessToken`, `hasRefreshToken`, na nlele
ezoro akụkụ ya (`maskedApiKey`: mkpụrụedemede 4 mbụ + `****` + mkpụrụedemede 4 ikpeazụ).

## Nchọpụta Credentials

`getCloudAgentCredentials(providerId)` dị na `src/lib/cloudAgent/api.ts`:

1. Ọ na-ebunye njikọ ndị na-enye ọrụ na-arụ ọrụ site na `getProviderConnections({ provider: providerId, isActive: true })`.
2. Maka njikọ ọ bụla, ọ na-ebu ụzọ họrọ `apiKey` (e wepụla oghere ndị dị na nsọtụ ya). Ọ bụrụ na nke ahụ adịghị, ọ na-eji `accessToken`.
3. Ọ na-eweghachite token mbụ na-adịghị efu n'ụdị `{ apiKey: token }`.
4. Ọ na-eweghachite `null` ma ọ bụrụ na ahụghị token a pụrụ iji — API ahụ na-aza `400` na
   `"No active credentials configured for cloud agent provider: <id>"`.

Nke a pụtara na Cloud Agents na-ejikwa otu tebụl Provider Connection ahụ ndị na-enye LLM
nkịtị na-eji. Iji gbanye Jules, mepụta njikọ na-arụ ọrụ nke nwere `provider: "jules"`
na `apiKey` e dejupụtara.

- Na-eziga ọrụ ọhụrụ site na fọm dabara na `CreateCloudAgentTaskSchema`.
- Na-egosi akara ọnọdụ (`queued`, `running`, `awaiting_approval`, `completed`,
  `failed`, `cancelled`) ma na-egosipụta usoro oge `activities[]`.
- Na-egosipụta `result.prUrl` / `commitMessage` / `summary` mgbe `status === "completed"`.

## Njikọta na A2A

Enwere ike ikpughe Cloud Agents dịka nka A2A site n'ịdebanye aha nka A2A nke na-enyefe
handler `tasks/send` ya n'aka `getAgent(...).createTask(...)` ma na-atụgharị event ọnọdụ ọrụ A2A
ka ha kwekọọ na protocol JSON-RPC 2.0. Lee [A2A-SERVER.md](./A2A-SERVER.md).

## Ịgbakwunye Cloud Agent Ọhụrụ

1. Mepụta `src/lib/cloudAgent/agents/<name>.ts` nke na-agbatị `CloudAgentBase`.
2. Mejuputa `createTask`, `getStatus`, `approvePlan` (ma ọ bụ tụpụ njehie ma ọ bụrụ na ọ dịghị mkpa),
   `sendMessage`, `listSources`. Jiri `this.mapStatus(...)` maka ime ka ọnọdụ bụrụ otu ụdị.
3. Debanye ya aha na `src/lib/cloudAgent/registry.ts` n'okpuru `providerId` na-adịghị agbanwe agbanwe.
4. Gbatịa njikọ literal nke `providerId` na `src/lib/cloudAgent/types.ts`
   (`CloudAgentTask.providerId` na `CreateCloudAgentTaskSchema`).
5. Tinye onye na-enye ọrụ ahụ na `src/shared/constants/providers.ts` ma ọ bụrụ na ọ chọrọ ndekọ
   njikọ. Ndị na-enye ọrụ dabere na OAuth chọkwara `src/lib/oauth/providers/`.
6. Tinye ule n'okpuru `tests/unit/cloud-agent-*.test.ts`.
7. Melite akwụkwọ a na constant `CLOUD_AGENTS` nke dashboard.
