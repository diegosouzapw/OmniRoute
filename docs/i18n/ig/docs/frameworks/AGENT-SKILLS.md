> **Emelitere ikpeazụ:** 2026-08-02 — v3.8.50

Agent Skills bụ faịlụ SKILL.md ahaziri nke na-akụziri ndị nnọchiteanya mpụga, ndị ahịa MCP, na ndị nhazi A2A otu esi eji REST API na CLI nke OmniRoute. N'adịghị ka [Omni Skills](./SKILLS.md) (nke bụ nkọwa ngwá ọrụ LLM a na-eme n'ime OmniRoute), Agent Skills bụ _katalọgụ akwụkwọ nkọwa_ — markdown anaghị agbanwe agbanwe nke enwere ike itinye ozugbo n'ime ọnọdụ onye nnọchiteanya.

---

## Nchịkọta

Katalọgụ ahụ nwere **Agent Skills 45** (REST API 23 + CLI 21 + usoro nhazi 1). Nkà ọ bụla nwere:

- **ID iwu kwadoro** (`omni-auth`, `cli-serve`, wdg.)
- Faịlụ **SKILL.md** dị na `skills/{id}/SKILL.md` nwere YAML frontmatter (`name`, `description`) + ọdịnaya markdown zuru ezu
- **REST endpoints** (nkà API) ma ọ bụ **CLI subcommands** (nkà CLI) ndị sitere na nkọwa OpenAPI na ndekọ CLI
- **URL raw GitHub** maka iweta ya ozugbo: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Nchọpụta REST API

| Endpoint                     | Method | Nkọwa                                                                   | Nnyenye ikike |
| :--------------------------- | :----- | :---------------------------------------------------------------------- | :------------ |
| `/api/agent-skills`          | GET    | Depụta katalọgụ (`?category=api\|cli\|config&area=<area>` bụ nke nhọrọ) | enweghị       |
| `/api/agent-skills/{id}`     | GET    | Nweta metadata nke otu nka                                              | enweghị       |
| `/api/agent-skills/{id}/raw` | GET    | Weta SKILL.md dịka `text/markdown`                                      | enweghị       |
| `/api/agent-skills/coverage` | GET    | Ndekọ mkpuchi (faịlụ SKILL.md ole dị)                                   | enweghị       |
| `/api/agent-skills/generate` | POST   | Kpalite generator (dryRun/prune/onlyIds)                                | njikwa        |

Ọmụmaatụ — depụta nka API niile:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Ọmụmaatụ — weta otu SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Otu Ndị Nnọchi Anya Mpụga Si Eji Nkà

### 1. Nchọpụta site na REST

```bash
# Nweta katalọgụ zuru ezu
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Nweta SKILL.md maka itinye ọnọdụ gbara ya gburugburu
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Nchọpụta site na MCP

```typescript
// N'ime klayenti MCP nke Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → usoro AgentSkill nwere rawUrl maka nke ọ bụla
```

### 3. Nchọpụta site na A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table bụ tebụl markdown nwere ID nkà 45 niile + kọlụm rawUrl
```

### 4. Nweta raw ozugbo na GitHub (achọghị sava)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Ihe Nwepụta

Ihe nrụpụta ahụ na-agụ katalọgụ ahaziri ahazi + nkọwapụta OpenAPI + ndekọ CLI wee dee `skills/{id}/SKILL.md` maka ndenye ọ bụla:

```bash
# Lelee tupu oge eruo (nnwale akọrọ, enweghị ide ihe)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Mmepụta ọhụrụ zuru ezu
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Mepụta ID ụfọdụ ọzọ
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Nzaghachi ihe nrụpụta ahụ bụ `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
