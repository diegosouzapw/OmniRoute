## Nchịkọta

Playground Studio na-agbanwe `/dashboard/playground` site na editọ dị mfe nke dabere na Monaco gaa
na oghere ọrụ nnwale zuru oke. Ọ na-eji shei `PlaygroundStudio` dochie `page.tsx` ochie,
nke na-egosipụta taabụ anọ na panel nhazi nke ha niile na-eji ọnụ.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Mkparịta ụka] [⚖ Tulee] [{} API] [🔧 Wuo] 142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {ọdịnaya taabụ nọ n'ọrụ}                │ ─ Nhazi                  │
│                                          │ Endpoint  [chat ∨]        │
│                                          │ Model     [gpt-5.4 ∨]     │
│                                          │ Sistemụ   [textarea]      │
│                                          │ Okpomọkụ  ▕▕▔▔ 0.7        │
│                                          │ Nhazi mbu [▾ buo][chekwaa]│
│                                          │ [✨ Meziwanye prompt]      │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Taabụ

### Taabụ Mkparịta ụka

Ọ na-eme ka `ChatPlayground.tsx` ghọọ ebe ọrụ nkwanye data n'usoro nwere ọtụtụ ntụgharị:

- Ngosipụta markdown zuru oke site na `MarkdownMessage.tsx` (ngọngọ koodu, tebụl, ndepụta, njikọ).
- A na-enweta prompt sistemụ site na panel Nhazi nke a na-eji ọnụ.
- Token/ọnụahịa maka ozi ọ bụla (token prompt + token mmecha).
- Mepụta nzaghachi ikpeazụ ọzọ.
- Na-eziga na `POST /v1/chat/completions` site na nkwanye data SSE n'usoro.

### Taabụ Ntụnyere

Ihe bụ isi na-eme proxy a iche: mee ka 1 prompt rụọ ọrụ n'ofe ihe ruru **model 4 n'otu oge**.

- Ihe ruru kọlụm 4, nke ọ bụla na-anata nkwanye data n'usoro n'onwe ya site na `/v1/chat/completions`.
- Bọtịnụ `+ Tinye model` (ụzọ mkpirisi Cmd+K) iji tinye kọlụm.
- `Mee ha niile ▶` na-amalite nkwanye data niile n'otu oge site na `Promise.all` + `AbortController` maka kọlụm ọ bụla.
- **Kagbuo ha niile** zuru ụwa ọnụ na-akwụsị nkwanye data niile ka na-aga.
- `ProviderMetrics` nke kọlụm ọ bụla na-egosi TTFT, TPS, token, na atụmatụ ọnụahịa ozugbo.
- Metrik nwere akara **"atụmatụ n'akụkụ klayent"** (D12) — a na-atụ ya site na iberibe SSE mbụ.

### Taabụ API

Ọ na-echekwa 100% nke editọ Monaco mbụ maka ndị ọrụ nwere ahụmịhe dị elu (D14):

- Endpoint 10: mmecha mkparịta ụka, mmecha, embeddings, onyonyo, ọdịyo, okwu, ntụgharị okwu, moderations, rerank, ọchụchọ.
- Nbulite faịlụ multimodal.
- Nkwanye data SSE n'usoro nwere mmepụta ozugbo.
- E kechiri ya dịka `ApiTab.tsx` (a na-ebudata ya naanị mgbe achọrọ ya, `ssr: false`).

### Taabụ Mwube

UI maka tools/function calling na mmepụta ahaziri ahazi:

- `ToolsBuilder.tsx` — tinye/dezie/wepụ `tools[]` site na editọ schema JSON maka ngwaọrụ ọ bụla.
  Na-enyocha parameters site na `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — gbanye ma ọ bụ gbanyụọ ọnọdụ JSON + editọ schema JSON.
  Na-enyocha nzaghachi megide schema site na `StructuredOutputSchema` (Zod).
- Na-eziga arịrịọ na `/v1/chat/completions` site na `tools[]` na/ma ọ bụ `response_format`.

## Ogwe Nhazi (Nkekọrịta)

`StudioConfigPane.tsx` — na-apụta mgbe niile, enwere ike ịkpọkọta ya.

| Ubi                | Ngwa                  | Nkọwa                                                                                  |
| ------------------ | --------------------- | -------------------------------------------------------------------------------------- |
| Endpoint           | `<select>`            | nhọrọ 10 kwekọrọ na `PlaygroundEndpoint`                                               |
| Model              | `<input>`             | ederede efu, dịka `openai/gpt-4o`                                                      |
| Ntụziaka sistemụ   | `<textarea>`          | a na-etinye ya na taabụ niile                                                          |
| Paramita           | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop                 |
| Nhazi echekwara    | `PresetPicker`        | budata/chekwaa nseta nhazi nwere aha (echekwara na DB)                                 |
| Meziwanye ntụziaka | `ImprovePromptButton` | na-emepe modal ịdọ aka ná ntị maka oke ojiji, na-akpọ `/api/playground/improve-prompt` |

A na-ebuli steeti gaa na `PlaygroundStudio.tsx` ma nyefee ya na taabụ niile. Ịgbanwe taabụ
na-edobe steeti nhazi.

`ExportCodeModal.tsx` na-eji `codeExport.ts` emepụta iberibe koodu curl / Python / TypeScript
site na `PlaygroundState` dị ugbu a. Ihe nnọchi anya API key na-abụkarị `$OMNIROUTE_API_KEY` (D11).

## Ihe Ndozi Ntụziaka

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Modal na-adọ aka ná ntị na "ọ ga-eji oke ojiji".
2. Mgbe akwadoro ya, ọ na-eziga `{ system, prompt, model, tone }` na route ahụ.
3. Route ahụ na-akpọ `/v1/chat/completions` n'ime sistemụ site na iji `promptImprover.META_SYSTEM_PROMPT`.
4. Ọ na-eweghachi `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. UI na-emelite ntụziaka sistemụ dị na ogwe Nhazi na ntụziaka onye ọrụ dị na taabụ Mkparịta ụka.

---

## Nhazi Echekwara

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Echekwara ya na tebụl SQLite `playground_presets` (migration `084_playground_presets.sql`).
- Nhazi echekwara ọ bụla na-echekwa: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: ndepụta `GET`, mmepụta `POST`, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Metrik Stream

`useStreamMetrics.ts` + `streamMetrics.ts` (ọrụ dị ọcha):

- `start()` — na-edekọ oge arịrịọ malitere.
- `onFirstChunk()` — na-edekọ TTFT.
- `onChunk(n)` — na-achịkọta ọnụọgụ token mmecha.
- `finish(usage?)` — na-agbakọ metrik ikpeazụ: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Ọnụ ahịa sitere na tebụl static dị na `src/lib/playground/types.ts` (akpọrọ "e mere atụmatụ" — D13).

## Route Backend

| Usoro    | Path                             | Handler                                                                                            |
| -------- | -------------------------------- | -------------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | Na-eji Zod akwado `ImprovePromptRequestSchema`; na-akpọ `/v1/chat/completions` site na meta-prompt |
| `GET`    | `/api/playground/presets`        | Na-eweghachi `{ presets: PlaygroundPresetListItem[] }`                                             |
| `POST`   | `/api/playground/presets`        | Na-emepụta nhazi echekwara; na-akwado `PlaygroundPresetCreateSchema`                               |
| `GET`    | `/api/playground/presets/:id`    | Na-eweghachi otu nhazi echekwara ma ọ bụ 404                                                       |
| `PUT`    | `/api/playground/presets/:id`    | Mmelite akụkụ ụfọdụ                                                                                |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                |

Nyocha njirimara: nhọrọ (`REQUIRE_API_KEY`). Njehie site na `buildErrorBody()` (Iwu Siri Ike #12).
