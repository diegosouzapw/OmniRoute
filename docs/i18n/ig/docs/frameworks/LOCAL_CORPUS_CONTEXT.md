## Ihe ọ bụ

Local Corpus na-enye onye njikwa ohere ime ka sava MCP nke OmniRoute nweta otu folda
faịlụ ederede a kwadoro nke ọma. Faịlụ na-anọ n'ime folda mbụ ha: OmniRoute na-echekwa
naanị ụzọ mgbọrọgwụ canonical na SQLite ma na-ejikwa ndekọ ọchụchọ dị na ebe nchekwa.
Ọ naghị edetuo ọdịnaya corpus n'ime repository ma ọ bụ database.

Mmelite ndekọ ahụ na-eme n'ụzọ incremental. A na-eji faịlụ ndị na-agbanwebeghị eme ihe
ọzọ dabere na nha na oge mgbanwe ha, a na-agụgharị faịlụ ndị gbanwere ma jiri SHA-256
mee hash ha, ebe a na-ewepụkwa faịlụ ndị ehichapụla. Ọchụchọ na-emelite ndekọ karịrị
sekọnd 30; ndị na-akpọ ya nwekwara ike ịrịọ mmelite ozugbo.

## Hazie isi mmalite ahụ

Ụzọ ntọala ahụ chọrọ otu njirimara njikwa ahụ API ntọala ndị ọzọ chọrọ.
Ụzọ e zitere ga-adịrịrị adị ma bụrụkwa ụzọ folda absolute.

```bash
# Jikọọ folda a kwadoro
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Lelee nhazi na ọnọdụ ndekọ
curl http://localhost:20128/api/settings/local-corpus

# Kwụpụ njikọ na-agbanweghị faịlụ isi mmalite
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Ngwaọrụ MCP

Ngwaọrụ atọ ahụ niile chọrọ `read:local-corpus`. Nzaghachi ngwaọrụ na-egosi ụzọ relative
na basename nke folda mgbọrọgwụ, ma ọ dịghị mgbe ha na-egosi ụzọ absolute ya.

| Ngwaọrụ               | Nkọwa                                                                                      |
| :-------------------- | :----------------------------------------------------------------------------------------- |
| `local_corpus_status` | Kọwaa ọnọdụ nhazi, nha ndekọ, oke, na oge mmelite ikpeazụ                                  |
| `local_corpus_search` | Chọọ ederede edekọtara ma weghachite iberibe nwere oke, nke ahịrị kewara (ruo nsonaazụ 20) |
| `local_corpus_read`   | Gụọ ahịrị ole na ole nwere oke site n'otu faịlụ corpus-relative e nyere ikike              |

Ọmụmaatụ ntinye MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Oke nchekwa

- Allowlist ahụ lekwasịrị anya n'ederede: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, na `.yml`.
- A na-amafe symlink. A na-eme ụzọ ọgụgụ ka ha bụrụ canonical, ha ga-anọgidekwa n'ime
  mgbọrọgwụ ahaziri; a na-ajụ ụzọ absolute na mbọ ịgafe ụzọ.
- A na-ewepụ aha folda nwere ihe nzuzo na ndị emepụtara: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, na
  `secrets`.
- Oke ndabara bụ faịlụ 5,000, 1 MiB maka faịlụ ọ bụla, 64 MiB nke mkpokọta ọdịnaya
  edekọtara, ihe dị ka mkpụrụedemede 4,000 maka ibe ọchụchọ ọ bụla, na ahịrị 400 maka ọgụgụ ọ bụla.
- A na-ewere faịlụ nwere NUL dị ka nke na-abụghị ederede, ya mere a na-amafe ma ọ bụ jụ ha.

A kpachaara anya ghara ịkwado akwụkwọ binary dịka PDF, DOCX, onyonyo, na archive.
Tụgharịa ha ka ha bụrụ usoro ederede a kwadoro n'ime folda ahaziri tupu e tinye ha na ndekọ.

## Nkọwa gbasara arụmọrụ

- Ịgbanwe ma ọ bụ ihichapụ mgbọrọgwụ ahaziri na-ekpochapụ ndekọ in-memory a na-ekekọrịta.
- Ịmalitegharị process na-atụfu ndekọ ahụ; ọchụchọ na-esote ga-ewughachi ya site na isi
  mmalite ahaziri.
- `local_corpus_status` anaghị amanye scan. Jiri `local_corpus_search` tinyere
  `refresh: true` mgbe achọrọ rescan ozugbo.
- A na-agụta ọdịda scan na ọgụgụ ma ọ bụ weghachite ha dịka njehie e sachara; a naghị
  agbanwe faịlụ isi mmalite ma ọlị.
