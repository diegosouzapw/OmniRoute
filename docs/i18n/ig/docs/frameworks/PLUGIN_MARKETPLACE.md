> **Isi mmalite eziokwu:** `src/lib/plugins/` (`marketplace.ts`, `manager.ts`, `manifest.ts`,
> `scanner.ts`, `loader.ts`), `src/app/api/plugins/`, na
> `src/app/(dashboard)/dashboard/plugins/`
> **Mmelite ikpeazụ:** 2026-06-28 — v3.8.40

OmniRoute na-abịa na sistemụ plugin yiri nke WordPress. Plugins bụ ndekọ
nwere onwe ha — nke ọ bụla nwere manifest `plugin.json` na faịlụ mbata — ndị na-ejikọta
na usoro nhazi arịrịọ (`onRequest` / `onResponse` / `onError`) nakwa na
mmemme okirikiri ndụ (`onInstall` / `onActivate` / `onDeactivate` / `onUninstall`).

**Ebe Ahịa Plugin** bụ oyi akwa nchọpụta dị n'elu sistemụ ahụ. Ọ
na-enye katalọgụ plugins enwere ike ịgagharị ma wụnye. Na ndabara, katalọgụ ahụ bụ
obere ndekọ mkpụrụ arụnyere n'ime ya; onye nchịkwa nwere ike iduzi ya gaa na URL
ndekọ mpụga ahaziri iche, ebe a na-eme ka nchọta ahụ sie ike site na ihe nche SSRF
na-edozi DNS (lee [Nchekwa](#security)).

Ụzọ plugin ọ bụla bụ **maka loopback naanị** (Tier 1 — `LOCAL_ONLY`): plugins na-ebunye
ma na-agba koodu n'ime child processes, ya mere enweghị ike iru ụzọ ndị ahụ site na
isi mmalite na-abụghị loopback n'agbanyeghị nkwenye njirimara. Lee
[`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md).

## Otu O Si Arụkọ Ọrụ

```
Dashboard (/dashboard/plugins)
  ├─ Taabụ "Installed"  → GET /api/plugins            (listPlugins)
  │                       POST /api/plugins/scan      (pluginManager.scan)
  │                       POST /api/plugins/{name}/activate|deactivate
  │                       DELETE /api/plugins/{name}   (iwepụ nrụnye)
  └─ Taabụ "Marketplace" → GET /api/plugins/marketplace
                            → listMarketplacePlugins()
                              ├─ enweghị URL ahaziri iche → SEED_REGISTRY arụnyere n'ime ya
                              └─ URL ahaziri iche → ihe nche SSRF isSafeMarketplaceUrl()
                                                 → safeOutboundFetch(guard:"public-only")
```

- **Oyi akwa ndekọ** — `src/lib/plugins/marketplace.ts`: na-edepụta / na-achọ
  katalọgụ ahụ, ma laghachi na ndekọ mkpụrụ ma ọ bụrụ na ihe ọ bụla ada.
- **Oyi akwa okirikiri ndụ** — `src/lib/plugins/manager.ts` (`pluginManager` singleton):
  ịwụnye, imelite, ime ka ọ rụọ ọrụ, ịkwụsị ya, iwepụ nrụnye, nyocha, ibunye mgbe usoro malitere.
- **Oyi akwa manifest** — `src/lib/plugins/manifest.ts`: schema Zod + ụkpụrụ ndabara maka
  `plugin.json`.
- **Ngwa nyocha** — `src/lib/plugins/scanner.ts`: na-achọpụta plugins dị na diski n'okpuru
  ndekọ plugin.
- **Ngwa mbunye** — `src/lib/plugins/loader.ts`: na-amalite plugin ọ bụla n'ime
  child process e kewapụrụ iche ma na-ahazi oku hook site na IPC.

## Katalọgụ Ebe Ahịa

`listMarketplacePlugins()` (`src/lib/plugins/marketplace.ts`) na-eweghachi ndepụta
ihe `MarketplaceEntry`:

| Oghere        | Ụdị      | Nkọwa                                            |
| ------------- | -------- | ------------------------------------------------ |
| `name`        | string   | Aha plugin n'ụdị kebab-case                      |
| `version`     | string   | semver                                           |
| `description` | string   | Nchịkọta dị mkpirikpi                            |
| `author`      | string   | Onye odee / ụlọ ọrụ                              |
| `license`     | string   | NJ ikike n'ụdị SPDX                              |
| `downloadUrl` | string   | URL nbudata isi mmalite (ọ nwere ike ịbụ oghere) |
| `repository`  | string?  | URL repository nhọrọ                             |
| `tags`        | string[] | Tags ọchụchọ/nzacha                              |
| `downloads`   | number   | Ọnụọgụ nbudata                                   |
| `rating`      | number   | 0–5                                              |
| `verified`    | boolean  | Ma akara ntinye ahụ egosiri na a kwadoro ya      |
| `lastUpdated` | string   | Eriri ụbọchị yiri ISO                            |

Mgbe ahazighị URL ndekọ pụrụ iche, katalọgụ ahụ bụ
`SEED_REGISTRY` arụnyere n'ime ya (ugbu a `request-logger`, `rate-limiter`, `cost-tracker`, na

ndekọ mpụga ahaziri, ọ weghachite ọnọdụ na-abụghị `200`, ma ọ bụ weghachite ahụ
a na-amaghị, `listMarketplacePlugins()` na-edekọ ịdọ aka ná ntị ma laghachi na ndepụta mkpụrụ.

> Rịba ama: ejikọtala **katalọgụ** ebe ahịa (ịgagharị/ịchọ) site na mmalite ruo na njedebe, mana
> **nrụnye** otu-pịa sitere na katalọgụ ahụ amalitebeghị — bọtịnụ "Install" nke
> dashboard dị na ntinye ebe ahịa na-egosi ugbu a ọkwa
> "coming soon". Nrụnye taa na-aga site na usoro nrụnye nke ụzọ mpaghara
> (`POST /api/plugins`) na nchọpụta dị na diski (`POST /api/plugins/scan`).

## REST API

Endpoint niile chọrọ njirimara njikwa (`requireManagementAuth`) **ma** bụrụkwa
naanị maka loopback — e depụtara `/api/plugins` na `/api/plugins/` na
`LOCAL_ONLY_API_PREFIXES` (`src/server/authz/routeGuard.ts`).

| Endpoint                         | Method | Nkọwa                                               |
| -------------------------------- | ------ | --------------------------------------------------- |
| `/api/plugins`                   | GET    | Depụta plugin arụnyere (nzacha `?status=` bụ nhọrọ) |
| `/api/plugins`                   | POST   | Wụnye plugin site n'ụzọ mpaghara zuru oke           |
| `/api/plugins/scan`              | POST   | Nyochaa ndekọ plugin ma debanye plugin ọhụrụ        |
| `/api/plugins/marketplace`       | GET    | Depụta ndenye katalọgụ marketplace                  |
| `/api/plugins/[name]`            | GET    | Nweta nkọwa plugin arụnyere                         |
| `/api/plugins/[name]`            | DELETE | Wepụ plugin                                         |
| `/api/plugins/[name]/activate`   | POST   | Mee ka ọ rụọ ọrụ (bulite + debanye hooks)           |
| `/api/plugins/[name]/deactivate` | POST   | Kwụsị ya (kpọọ `onDeactivate`, wepụ ndebanye hooks) |
| `/api/plugins/[name]/config`     | GET    | Nweta nhazi plugin + schema nhazi                   |
| `/api/plugins/[name]/config`     | PUT    | Melite nhazi plugin (a na-enyocha ya megide schema) |

Nzacha `status` nke `GET /api/plugins` na-anabata otu n'ime
`installed` / `active` / `inactive` / `error`. Uru na-adịghị irè na-eweghachi `400`.

### Depụta plugin arụnyere

```bash
curl http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..."
```

### Wụnye site n'ụzọ mpaghara

```bash
curl -X POST http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "path": "/absolute/path/to/my-plugin" }'
```

`path` ga-abụrịrị ụzọ **zuru oke**, ọ gaghịkwa enwe ngalaba ngafe `..` ma ọ bụ
null bytes (Zod na-amanye nke a). Ndekọ isi mmalite ga-enwerịrị
`plugin.json` ziri ezi (ma ọ bụ bụrụ ndekọ nne na nna nke nwere otu). Mgbe ọ gara nke ọma, nzaghachi bụ `201` yana
ahịrị plugin arụnyere.

### Chọgharịa marketplace

```bash
curl http://localhost:20128/api/plugins/marketplace \
  -H "Cookie: auth_token=..."
```

### Melite nhazi plugin

```bash
curl -X PUT http://localhost:20128/api/plugins/my-plugin/config \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "config": { "level": "debug", "maxItems": 100 } }'
```

`PUT .../config` na-enyocha uru ọ bụla enyere megide
`configSchema` nke plugin (nke ekwupụtara na manifest): ngalaba `number` na-erube isi na `min`/`max`,
ngalaba `select` ga-adabarịrị na `enum` ekwupụtara. A na-ahapụ igodo ndị na-adịghị na schema
ka ha gafee.

## Nhazi

### Ndekọ plugin

Plugin dị n'okpuru ndekọ data OmniRoute:

```
~/.omniroute/plugins/<plugin-name>/
  ├─ plugin.json
  └─ index.js          # (ma ọ bụ faịlụ ọ bụla manifest.main na-arụtụ aka na ya)
```

`getDefaultPluginDir()` (`src/lib/plugins/scanner.ts`) na-ekpebi ndekọ ahụ site na
nzọụkwụ atọ:

1. **`OMNIROUTE_PLUGINS_DIR`**, mgbe edobere ya — a na-eji ya kpọmkwem dịka ọ dị, n'agbanyeghị ihe `HOME` kwuru. Nke a bụ
   njikwa doro anya maka Docker/K8s, ebe a na-eme bind-mount nke osisi plugin n'ụzọ
   nke na-enweghịkarị ihe jikọrọ ya na ndekọ ụlọ nke container (#11827).
2. `<home>/.omniroute/plugins`, ebe `<home>` si na environment variables `HOME` / `USERPROFILE`
   abịa.
3. `/tmp/.omniroute/plugins`, mgbe process ahụ na-ebupụghị ebe obibi ọ bụla ma ọlị.

A na-edekọ ndekọ ekpebiri otu ugboro mgbe mmalite dịka `scanner.dir_resolved`, na-akpọ aha
ntinye meriri (`OMNIROUTE_PLUGINS_DIR`, `home`, ma ọ bụ `no-home-fallback`) — ya mere image
nke rutere na nzọụkwụ 3 na nzuzo na-ekwu ya, kama naanị ịkọpụta ndepụta plugin tọgbọ chakoo.
`POST /api/plugins/scan` na-achọpụta subdirectory ọ bụla nọ ebe ahụ nke nwere
`plugin.json` ziri ezi ma debanye ya; otu ndekọ ahụ bụkwa root ebe
`pluginManager.install()` na-edepụta plugin banye, ya mere override na-ebukọ nchọpụta na
nwụnye ọnụ.

> **`OMNIROUTE_PLUGINS_DIR` abụghị `OMNIROUTE_PLUGIN_PATH`.** A na-agụ nke ikpeazụ naanị site na
> CLI command-plugin loader (`bin/cli/plugins.mjs`) iji chọta ngwugwu npm `omniroute-cmd-*`
> ndị na-agbakwunye subcommand `omniroute` — ọ naghị emetụta runtime scanner
> a kọwara ebe a. Lee [PLUGINS.md](./PLUGINS.md) maka akụkụ ahụ.

### URL registry marketplace ahaziri iche

A na-agụ isi mmalite katalọgụ marketplace site na ntọala `pluginMarketplaceUrl`
(`src/lib/plugins/marketplace.ts` na-agụ `settings.pluginMarketplaceUrl`). Mgbe
edobere ya ka ọ bụrụ URL `http(s)`, `listMarketplacePlugins()` na-fetch URL ahụ ma nabata
ma JSON array nke ndenye dị n'ogo kachasị elu ma ọ bụ object nwere array `plugins`;
a na-ewepụ ndenye ndị na-enweghị `name` nke bụ string. Mgbe edoghị ya (ma ọ bụ mgbe fetch
dara na nchedo SSRF / weghachiri nzaghachi ọjọọ), a na-eji seed registry e wuru n'ime.

Taabụ "Marketplace" nke dashboard na-egosi field maka URL a (nke a na-agụghachi site na
`GET /api/settings`).

> Ndetu mmejuputa: omume "Save" nke dashboard na-eziga
> `pluginMarketplaceUrl` na `PATCH /api/settings`. N'oge edere nke a,
> ekwupụtaghị key a na `updateSettingsSchema`
> (`src/shared/validation/settingsSchemas.ts`), ya mere nyochaa na ọ na-adịgide na
> release gị tupu ịdabere na ya — ụzọ **ọgụgụ** (`getSettings()` →
> `listMarketplacePlugins()`) na-asọpụrụ key ahụ ozugbo ọ dị na settings
> store.

## Nchekwa

### Ọkwa ụzọ — naanị loopback

Plugins na-eme koodu n’ime child processes e mepụtara, ya mere a na-ahazi elu `/api/plugins`
dum dịka `LOCAL_ONLY` (Ọkwa 1). Nkwado loopback na-arụ ọrụ
n’enweghị ọnọdụ ọ bụla **tupu** nyocha auth ọ bụla, ya mere ọbụna management token e kpughere nke rutere
igbe ahụ site na tunnel enweghị ike ịwụnye, ime ka ọ rụọ ọrụ, ma ọ bụ iwepụ plugin.
Lee [`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md) na
Iwu Siri Ike #15 / #17.

### Nchedo SSRF nke ndekọ marketplace

URL ndekọ ahaziri iche bụ nhazi onye mwakpo nwere ike imetụta, ya mere tupu
e nweta ya, `listMarketplacePlugins()` na-ebufe ya n’usoro nchedo abụọ:

1. **`isSafeMarketplaceUrl(url)`** (`src/lib/plugins/marketplace.ts`):
   - Na-ajụ ihe ọ bụla na-abụghị `http:` / `https:`.
   - Na-ajụ hosts nzuzo/loopback/link-local/ULA e dere kpọmkwem (IPv4 **na** IPv6,
     gụnyere IPv4-mapped) site na `isPrivateHost` canonical
     (`src/shared/network/outboundUrlGuard.ts`).
   - Na-achọpụta ndekọ **abụọ ahụ** `A` na `AAAA`, ma jụ ma ọ bụrụ na adreesị
     ọ bụla achọpụtara bụ nke nzuzo — nke a na-emechi ụzọ mgbapụ public-hostname → private-IP.
   - **Na-ajụ mgbe ọdịda mere**: ọdịda DNS resolution na-eme ka a jụ URL ahụ.
2. **`safeOutboundFetch(url, { guard: "public-only", timeoutMs: 5000 })`**
   (`src/shared/network/safeOutboundFetch.ts`): na-etinyeghachi nchedo URL nke public-only
   n’oge fetch ma **na-egbochi redirects** (enweghị ntụgharị public → private `30x`
   pivot).

URL nke dara n’otu n’ime ọkwa abụọ ahụ anaghị akwụsị arịrịọ ahụ — marketplace ahụ
na-alaghachi nwayọ na ndekọ seed dị n’ime ya ma dekọọ ịdọ aka ná ntị.

> E mere ka nchedo a sie ike na PR #3774 kpọmkwem iji chọpụta A + AAAA ma jiri
> `isPrivateHost` canonical kama nyocha na-ele naanị IPv4.

### Ikewapụ mmezu plugin

- **Ikewapụ process** — `loadPlugin()` (`src/lib/plugins/loader.ts`) na-emepụta
  plugin ọ bụla n’ime Node.js child process dị iche ma na-ekwurịta okwu site na IPC.
  Oku hook nwere timeout nke nwere mbuli `SIGTERM` → `SIGKILL`.
- **Ndepụta env enyere ikike** — child ahụ na-enweta naanị otu environment
  variables e nyere ikike; a na-enye naanị set sara mbara mgbe manifest rịọrọ
  ikike `env`.
- **Ijide path n’ókè** — install/upgrade/uninstall na-achọpụta na directory plugin
  na `manifest.main` na-edobe ụzọ ha **n’ime** mgbọrọgwụ plugin a na-achịkwa
  tupu copy ọ bụla ma ọ bụ recursive delete (na-echebe megide ụzọ DB e mebiri emebi na
  njem `../` dị na `manifest.main`). Activation na-achọpụta symlinks site na
  `realpath` ma jụ ibunye entry point nke gbapụrụ n’ime directory plugin.
- **Integrity pin nhọrọ** — manifest nwere ike ikwupụta field `integrity`
  (`sha256-<base64>`, usoro SRI). Mgbe ọ dị, loader na-enyocha hash nke
  entry file n’oge load ma jụ activation ma ọ bụrụ na ha adabaghị. Ọ bụ
  nchọpụta mmebi a na-ahọrọ iji, **ọ bụghị** ókè nchekwa — routing nke loopback-only
  na permission model bụ ezigbo ókè.

## Usoro Lifecycle

```
install (POST /api/plugins, path)
  → nyochaa/kwado manifest → detuo ya na staging → hụ na main dị n'ime dir
  → jiri atomic rename bugharịa ya na ~/.omniroute/plugins/<name> → tinye ahịrị DB
  → kpọọ onInstall → ọ bụrụ na enabledByDefault: activate

activate (POST /api/plugins/{name}/activate)
  → lelee njide realpath → loadPlugin() (malite child process)
  → debanye hooks ndị ekwuputara → status = "active" → kpọọ onActivate

deactivate (POST /api/plugins/{name}/deactivate)
  → kpọọ onDeactivate (TUPU unregister) → unregister hooks
  → kwụsị child process → status = "inactive"

uninstall (DELETE /api/plugins/{name})
  → deactivate ma ọ bụrụ na ọ na-arụ ọrụ → kpọọ onUninstall
  → hichapụ plugin dir n'ụzọ recursive mgbe enyochachara njide ya → hichapụ ahịrị DB
```

Ịgba `install` ọzọ megide directory nke ụdị manifest ya **dị ọhụrụ karịa kpọmkwem**
ụdị arụnyere ga-eme auto-upgrade (nrụnye ọhụrụ dị ọcha; config ga-alaghachi
na defaults). A ga-ajụ ụdị bụ otu ma ọ bụ nke ochie.
