## Ihe ọ bụ

OmniRoute na-ejikọta na vault **Obsidian** dịka **isi iyi ọnọdụ** — ebe nchekwa ihe ọmụma
Markdown nke dị na kọmputa, nke ndị agent na-agụ ma na-ede site na sava MCP e wuru n'ime ya.
Njikọ ahụ na-akparịta ụka na plugin obodo **Obsidian Local REST API** nke na-agba n'ime
ngwa desktọpụ ahụ, ka ndị agent nwee ike ịchọ ndetu, ịgụ/ide/mezie faịlụ, depụta ihe dị na
vault, rụọ ọrụ na ndetu kwa ụbọchị/kwa izu, jikwaa tag, mee iwu Obsidian, ma (ọ bụrụ na achọrọ)
hazie mmekọrịta vault ụzọ abụọ n'etiti desktọpụ↔mobile.

Onye ahịa ahụ (`src/lib/obsidian/api.ts`) na-ekpuchi Local REST API site na:

- **Ịnwale ọzọ site na backoff** maka njehie `5xx` na-adịru nwa oge, **oge nkwụsị nke sekọnd 30** site na `AbortController`.
- **Nhazi njehie nwere ụdị** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Ndụmọdụ dị mfe nghọta nke "enweghị ike iru Obsidian"** nke na-akọwapụta njehie port a na-ahụkarị
  (HTTP na `27123`, **ọ bụghị** endpoint MCP dị na `27124`) yana ụdị Tailscale.
- **Nkodị ụzọ dabere na vault** ka ụzọ ndetu nwere oghere/slash wee dị nchebe.

## Nhazi

E nweghị **environment variable** maka token Obsidian ma ọ bụ base URL — a na-echekwa ha abụọ
na tebụl SQLite `key_value` (namespace `obsidian`) site na
`src/lib/db/obsidian.ts`. A na-**ezobe token mgbe echekwara ya** (AES-256-GCM, yana
ndaghachi ndakọrịta azụ nke plaintext). Hazie ya site na taabụ **Context Sources** nke
dashboard Endpoint (`ObsidianSourceCard`), ma ọ bụ site na API REST nke ntọala.

> [!IMPORTANT]
> A ghaghị ịwụnye plugin **Obsidian Local REST API** ma mee ka ọ na-agba. Interface REST ya
> na-ege ntị na **HTTP `127.0.0.1:27123`** (base URL ndabara). Port `27124`
> bụ endpoint MCP/HTTPS _dị iche_ ma route ntọala na-ajụ ya kpọmkwem.
> Ọ bụrụ na ị na-ejikọta site na ngwaọrụ ọzọ, jiri `http://<tailscale-ip>:27123`.

### Igodo nhazi (SQLite `key_value`, namespace `obsidian`)

| Igodo             | Ebumnuche                                        | Ezobere |
| ----------------- | ------------------------------------------------ | ------- |
| `api_key`         | Token bearer nke Local REST API                  | ee      |
| `base_url`        | Base URL REST (ndabara `http://127.0.0.1:27123`) | mba     |
| `vault_path`      | Ụzọ zuru oke gaa na ndekọ vault (maka mmekọrịta) | mba     |
| `webdav_username` | Aha njirimara WebDAV emepụtara (mmekọrịta vault) | mba     |
| `webdav_password` | Okwuntughe WebDAV emepụtara (mmekọrịta vault)    | ee      |
| `webdav_enabled`  | Ma agbanyere mmekọrịta vault WebDAV              | mba     |

### Hazie site na REST

```bash
# Chekwaa + nyochaa token Local REST API (POST na-enyocha ya site na nyocha ọnọdụ)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Lelee ọnọdụ njikọ (na-eweghachi connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Kwụsị njikọ (na-ehichapụ token echekwara)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Usoro niile chọrọ nkwenye njirimara dashboard. `POST` na-ajụ URL ọ bụla dị na port `27124`
ma na-enyocha token site n'ịkpọ endpoint ọnọdụ nke Local REST API tupu echekwaa ya.

### Mmekọrịta vault WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` na-ejikwa mmekọrịta vault WebDAV nhọrọ
(nke `src/lib/obsidianSync.ts` na-akwalite). Ịgbanye ya na-eme ka OmniRoute jiri
ndekọ vault dị na kọmputa ma mepụta aha njirimara/okwuntughe WebDAV enweghị usoro:

```bash
# Gbanye mmekọrịta WebDAV maka ndekọ vault (na-emepụta aha njirimara/okwuntughe)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Nweta ọnọdụ mmekọrịta WebDAV (a na-eweghachi nzere naanị mgbe agbanyere ya)
curl http://localhost:20128/api/settings/obsidian/webdav

# Gbanyụọ mmekọrịta WebDAV (na-ehichapụ nzere + .stignore a na-ejikwa)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Isi iyi ọnọdụ maka API key ọ bụla (nhọrọ)

Enwere ike ịkpa ókè nhazi Obsidian **maka API key ọ bụla** site na tebụl `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Mgbe oku MCP nwere id API key akwadoro,
`getObsidianConfigForApiKey()` na-ebu ụzọ họrọ token/base-URL/vault-path nke key ahụ
(`source: "api_key"`) ma ọ bụrụ na ọ dịghị, ọ laghachi na nhazi zuru ụwa ọnụ (`source: "global"`).

## Ngwaọrụ MCP (22)

A kọwara ha na `open-sse/mcp-server/tools/obsidianTools.ts`. A na-ekpebi token/base-URL
maka oku ọ bụla (nke API-key buru ụzọ, emesịa nke zuru ụwa ọnụ). Ngwaọrụ ndị na-akpọ sava **sync**
nke OmniRoute (ngwaọrụ `obsidian_sync_*` anọ ahụ) chọkwara token nkwenye sync ahaziri
na ntọala OmniRoute.

### Ngwaọrụ ọgụgụ (`read:obsidian`)

| Ngwaọrụ                      | Nkọwa                                                                                                     |
| ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Lelee ma Local REST API dị njikere ma enyochala ikike ya.                                                 |
| `obsidian_search_simple`     | Chọọ ederede zuru ezu n'ime ọdịnaya ndetu; ọ na-eweghachi iberibe ederede tinyere ụzọ faịlụ.              |
| `obsidian_search_structured` | Jiri nkwupụta JSON Logic chọọ ihe (ihe nzacha and/or/regex/path).                                         |
| `obsidian_read_note`         | Gụọ ndetu site n'ụzọ ya metụtara vault; ma ọ bụrụ na achọrọ, naanị heading/block/frontmatter akọwapụtara. |
| `obsidian_list_vault`        | Depụta faịlụ na ndekọ dị na vault (osisi ndenye).                                                         |
| `obsidian_get_document_map`  | Nweta nhazi heading nke ndetu dịka maapụ headings → nọmba ahịrị.                                          |
| `obsidian_get_note_metadata` | Nweta frontmatter, tags, njikọ, na ọnụọgụ mkpụrụedemede/okwu n'enweghị ọdịnaya zuru ezu.                  |
| `obsidian_get_active_file`   | Nweta ụzọ + ọdịnaya faịlụ na-arụ ọrụ ugbu a na Obsidian.                                                  |
| `obsidian_get_periodic_note` | Nweta ndetu oge niile nke ụbọchị/izu/ọnwa maka otu ụbọchị (taa ma ọ bụrụ na akọwaghị ya).                 |
| `obsidian_get_tags`          | Depụta tags niile dị na vault tinyere ugboro ole ha pụtara.                                               |
| `obsidian_list_commands`     | Depụta ID iwu Obsidian ndị dị (jiri ya na `obsidian_execute_command`).                                    |
| `obsidian_sync_status`       | Ọnọdụ sava sync OmniRoute: ma ọ na-arụ ọrụ, aha vault, port, uptime, na sync ikpeazụ.                     |
| `obsidian_sync_conflicts`    | Depụta esemokwu sync ndị a na-edozibeghị (ụzọ, ụzọ esemokwu, oge-achọpụtara).                             |

### Ngwaọrụ odide (`write:obsidian`)

| Ngwaọrụ                          | Nkọwa                                                                                                    |
| -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Mepụta ma ọ bụ dochie ndetu site n'ọdịnaya Markdown enyere.                                              |
| `obsidian_append_note`           | Tinye ọdịnaya na ngwụcha ndetu; ma ọ bụrụ na achọrọ, n'okpuru heading/block akọwapụtara.                 |
| `obsidian_patch_note`            | Jiri nlezianya tinye na ngwụcha/mmalite ma ọ bụ dochie ihe na heading, block, ma ọ bụ ogige frontmatter. |
| `obsidian_delete_note`           | Hichapụ ndetu kpamkpam na vault.                                                                         |
| `obsidian_move_note`             | Bugharịa ma ọ bụ nye ndetu aha ọhụrụ n'ime vault.                                                        |
| `obsidian_execute_command`       | Mee iwu Obsidian site na command ID ya.                                                                  |
| `obsidian_open_file`             | Mepee faịlụ na Obsidian (ọ na-emepụta ya ma ọ bụrụ na ọ dịghị).                                          |
| `obsidian_sync_trigger`          | Kpalite sync vault desktọpụ↔ekwentị nke ụzọ abụọ ozugbo.                                                 |
| `obsidian_sync_resolve_conflict` | Dozie esemokwu sync: debe `local` (ekwentị), `remote` (desktọpụ), ma ọ bụ `keep-both`.                   |

> [!NOTE]
> Ebe `obsidian_patch_note` na-elekwasị anya na-anabata `targetType` nke `heading | block | frontmatter`
> na `operation` nke `append | prepend | replace`, tinyere
> `createTargetIfMissing` nke bụ nhọrọ. Ngwaọrụ `obsidian_sync_*` anọ ahụ na-ekwurịta okwu na sava sync
> mpaghara (`http://127.0.0.1:27781` na ndabara) ma chọọ token sync.

### Oke ikike

Ngwaọrụ ọgụgụ chọrọ `read:obsidian`; ngwaọrụ odide chọrọ `write:obsidian`. Mmanye iwu a
bụ otu ihe ahụ dị na Notion — `withScopeEnforcement()` na-ahụ maka ya n'ime
`open-sse/mcp-server/server.ts`, `OMNIROUTE_MCP_ENFORCE_SCOPES=true` na-achịkwa ya, ebe
a na-enweta oke ikike ndị anabatara site na `OMNIROUTE_MCP_SCOPES` ma ọ bụ ọnọdụ oke ikike nke API key. Lee
[MCP-SERVER.md](./MCP-SERVER.md).

## Ọnọdụ ojiji

- **Azịza dabere na vault** — `obsidian_search_simple` / `obsidian_search_structured`
  emesịa `obsidian_read_note` ka onye nnọchi anya wee zaa site na ndetu gị n'ezie.
- **Ide ndetu / ide akwụkwọ ụbọchị** — `obsidian_write_note`, `obsidian_append_note`, ma ọ bụ
  `obsidian_patch_note` nke na-eme mgbanwe kpọmkwem iji dekọọ nsonaazụ onye nnọchi anya, nchịkọta, ma ọ bụ ndetu ụbọchị
  (`obsidian_get_periodic_note`) n'ime vault.
- **Ịgagharị na vault** — `obsidian_list_vault`, `obsidian_get_document_map`, na
  `obsidian_get_tags` iji nyochaa nhazi tupu ịgụ/ide.
- **Akpaaka Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` iji
  mee ka onye nnọchi anya chịkwaa plugins/iwu; `obsidian_open_file` iji gosipụta ndetu na UI.
- **Mmekọrịta ekwentị mkpanaaka** — kwado mmekọrịta WebDAV, emesịa `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  iji hazie kọmputa desktọọpụ↔ekwentị mkpanaaka ma dozie esemokwu.
