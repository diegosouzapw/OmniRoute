`npm-publish.yml` na-ebipụta site na **npm Trusted Publishing (OIDC)** na ndabara: ọrụ
`stage-npm` (nke GitHub na-akwado) na-agbanwe id-token GitHub ka ọ bụrụ nzere npm
nke na-adịru obere oge maka ọsọ ahụ — enweghị token npm na-adịte aka n'ime ihe nzuzo repository, enweghị arịrịọ 2FA, ma agbakwunyere provenance.
Nke ahụ bụ ụzọ ịgafe ihe npm kwadoro ugbu a ka a na-akwụsị token ndị na-amafere 2FA;
ọ na-eweghachi usoro akpaaka zuru ezu nke project ahụ nwere ruo v3.8.48 ma ka na-edobe
nkwa WS1.3 (token agbapụtara enweghị ike ibipụta naanị ya — token adịghị).

**Nhazi otu ugboro (onye nwe ya):** npmjs.com → package `omniroute` → Settings → _Trusted
Publisher_ → GitHub: owner `diegosouzapw`, repo `OmniRoute`, workflow `npm-publish.yml`
(environment: none). Ruo mgbe nke ahụ dị, nzọụkwụ akpaaka ahụ ga-ada na `ENEEDAUTH`:
ziga ya ọzọ site na `publish_mode=staged` (n'okpuru) ma ọ bụ `direct`.

### Mbipụta e debere n'ọkwa (mgbe a rịọrọ ya — `publish_mode=staged`)

Workflow npm-publish anaghịzi ebipụta ozugbo: ọ na-ebido tarball e kwakọrọ
(`check:pack-boot`) ma mesịa gbaa `npm stage publish` — a na-edobe kpọmkwem bytes ahụ na
registry, **enweghị ike ịwụnye ha** ruo mgbe onye nwe ya kwadoro. E bugharịla ọnụ ụzọ 2FA mmadụ
gaa MGBE ihe akaebe gasịrị, ọ bụghị tupu ya.

**Usoro onye nwe ya mgbe workflow ghọrọ green:**

1. `npm stage list omniroute` — chọta stage id (a na-ebipụtakwa ya na nchịkọta workflow).
2. Nyochaa bytes e debere n'ọkwa (a na-atụ aro ya): `npm stage download <id>`, wee wụnye
   tarball ebudatara n'ime temp prefix ma malite ya (`npm run check:pack-boot` na-eme
   otu mkpebi pack→install→boot ahụ na-akpaghị aka na CI).
3. `npm stage approve <id>` — arịrịọ 2FA BỤ mbipụta ahụ. `npm stage reject <id>` na-atụfu ya.
4. Nchedo mgbe mbipụta gasịrị: onye nyocha mgbe mbipụta gasịrị (WS1.4 nke atụmatụ v3.8.49) na-etinye
   ụdị e bipụtara site na public registry n'ime container dị ọcha ma malite ya.

**Ụzọ ndabere mberede:** `workflow_dispatch` nwere `publish_mode=direct` na-eweghachi
`npm publish` ozugbo nke usoro ochie (jiri naanị ma ọ bụrụ na staging n'onwe ya anaghị arụ ọrụ nke ọma; detuo ihe kpatara ya).

**Ime ka o sie ike otu ugboro (onye nwe ya, npmjs.com):** hazie Trusted Publisher maka
`omniroute` na ọnọdụ stage-only ka token na-adịte aka agbapụtara ghara inwe ike ime `npm publish`
ozugbo site n'ebe ọ bụla — CI nwere ike naanị idobe ya n'ọkwa; naanị 2FA onye nwe ya na-ewepụta ya.

**Usoro maka artifact mebiri emebi (agbanwebeghị):** `npm deprecate omniroute@<bad> "<reason> — use <fixed>"`
dịka mmeghachi omume ndabara (n'ime nkeji, enwere ike iweghachi ya); jiri `npm unpublish` naanị n'ime windo
awa 72/enweghị-dependents, ọ bụghịkwa dịka nzọụkwụ mbụ. Docker: edegharịla version tag mgbe ọ bụla — rollback bụ
ịtụgharị `latest` ka ọ rụtụ aka na digest ikpeazụ dị mma.

**Docker Hub `latest` (achọrọ na mbipụta SemVer stable ọ bụla):** workflow
`docker-publish` ga-etinyerịrị tag na **ma** `X.Y.Z` **ma**, mgbe
`should-promote-latest.sh` kwetara na nke a bụ SemVer stable kachasị elu, `:latest`
nwere **otu digest ahụ**. Mgbe ọrụ ahụ gasịrị: digest Hub `latest` ga-abụ otu ihe na digest
SemVer ọhụrụ ahụ, `last_updated` agbanwekwala. Ahapụla `:latest` n'elu
build ochie mgbe ndetu mwepụta na-ekwu maka ndozi ndị dị naanị na git. Compose
quickstarts na-eji `:latest`; GitOps kwesịrị ịnọgide na-atụgide `X.Y.Z`. Lee
[Ọwa mwepụta Docker](../guides/DOCKER_GUIDE.md#release-channels) na #10317.

## Ụzọ Ọsọ Hotfix (akara `hotfix`)

PR e nyere akara `hotfix` na-awụfe nnukwu matriks CI (E2E nwere shard 9, coverage ratchet,
quality-gate, quality-extended) ma debe ụzọ nyocha ndị dị ọsọ ma na-enye akara doro anya: build,
unit shards, integration, vitest, lint/typecheck, docs-sync, `check:pack-artifact`
na nnwale boot-smoke nke tarball (`check:pack-boot`). Ebumnuche: ka ihe niile bụrụ green n'ime ≤15min kama ~33min.

**Iwu mbata — a chọrọ ha anọ niile (e mere ya dịka ụzọ mberede Chromium/VS Code/Node):**

1. **Ogo nsogbu**: production emebiela — artifact e bipụtara na-adaba mgbe ọ na-amalite / mmezi
   nchekwa / nsogbu ahụ metụtara onye ọrụ ọ bụla nke release ahụ. "Dị mkpa" abụghị "emebiela".
2. **Ikike**: naanị onye nwe repository na-etinye akara `hotfix`. Akara ahụ BỤ
   nkwado ahụ — emela ya n'onwe gị na PR campaign.
3. **Ihe akaebe**: ahụ PR na-ejikọta run heavy gara aga nke zuru oke ma bụrụ green (suite nke
   ọrụ ndị a wụfere gaara enyocha ọzọ) tinyere nnwale nke mmezi ahụ nke dara na mbụ ma gafee emesịa.
4. **Oke**: naanị cherry-pick — mmezi kacha nta, enweghị refactor, enweghị mgbanwe ndị ọzọ esonyere ya.

A na-enyocha ọzọ akụkụ coverage/ratchet a wụfere na full run na-esote na
branch release (release-green na-aga n'ihu) — ụzọ a na-awụfe naanị ICHERE, ọ naghị awụfe validation.
Diff ndị bụ naanị nnwale (faịlụ niile dị n'okpuru `tests/`, ọ dịghị nke dị n'okpuru `tests/e2e/`) na-awụfe matriks E2E
na-akpaghị aka, na-enweghị akara ọ bụla.

### Hook (Husky kwadoro)

Hook Husky dị na `.husky/` ma na-agba na-akpaghị aka mgbe a na-eme ọrụ git.

- **pre-commit:** `npx lint-staged + node scripts/check/check-docs-sync.mjs + npm run check:any-budget:t11`
- **pre-push:** gate deterministic ndị dị ọsọ — `npm run check:any-budget:t11 && npm run check:tracked-artifacts` (arụnyere ọrụ na 2026-06-13). A kpachapụrụ anya wepụ `test:unit` (ọ dị nwayọ; ọrụ CI `test-unit` na-ekpuchi ya).
  - Jiri aka gbaa `npm run test:unit` tupu ị push branch release.

Ọ bụrụ na hook ada: dozie nsogbu kpatara ya, ejila `--no-verify` gafere ya.

### Conventional Commits

### Nhazi Build

Repository a na-eji directory mmepụta atọ dị iche iche — agwakọtala ha:

| Directory | Ebumnuche                                                  | A na-esochi ya?  |
| --------- | ---------------------------------------------------------- | ---------------- |
| `src/`    | Isi mmalite application (TypeScript / TSX)                 | Ee               |
| `.build/` | Ihe etiti build — mmepụta `next build` (`distDir`)         | Mba (gitignored) |
| `dist/`   | Nchịkọta npm a pụrụ ibupu — `assembleStandalone` haziri ya | Mba (gitignored) |

> **Ndetu onye ọrụ:** directory image VPS dị anya ka bụ `/usr/lib/node_modules/omniroute/app/`.
> Naanị mmepụta build dị **n’ime repository** ka e bugharịrị (`app/` → `dist/`). Skill deploy na-eji rsync ebuga
> ọdịnaya `dist/` n’ime directory `app/` dị anya — enweghị mgbanwe path VPS achọrọ.

**Usoro otu build:**

```
npm run build:release
  └─ rm -rf .build dist          (nhicha)
  └─ next build → .build/next/   (ihe etiti)
  └─ assembleStandalone          (na-edetuo standalone + static + public + natives → dist/)
  └─ writes dist/BUILD_SHA       (sentinel HEAD)
```

AGBALỊLA ịgba `npm run build` wee soro ya gbaa `npm run build:cli` iche maka deploy — jiri
`npm run build:release`, nke na-eme rebuild dị ọcha + sentinel n’otu command.
