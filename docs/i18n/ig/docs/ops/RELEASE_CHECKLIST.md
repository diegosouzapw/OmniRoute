## Mbipụta Ntụkwasị Obi nke npm (ndabara kemgbe v3.8.51) — staged mgbe a rịọrọ ya, direct dịka nhọrọ ndabere

`npm-publish.yml` na-ebipụta site na **npm Trusted Publishing (OIDC)** na ndabara: ọrụ
`stage-npm` (nke GitHub na-akwado) na-agbanwe id-token nke GitHub maka nzere npm
nke na-adị obere oge maka ọsọ ahụ — enweghị token npm na-adị ogologo oge n'ime ihe nzuzo repository, enweghị arịrịọ 2FA, a na-etinyekwa provenance.
Nke ahụ bụ ụzọ ngafe npm kwadoro ugbu a ebe a na-akwụsị token ndị na-awụfe 2FA;
ọ na-eweghachi usoro akpaaka zuru oke nke project ahụ nwere ruo v3.8.48 ma na-edobe
nkwa WS1.3 (token gbapụtara enweghị ike ibipụta naanị ya — n'ihi na ọ dịghị token).

**Nhazi otu ugboro (onye nwe ya):** npmjs.com → package `omniroute` → Settings → _Trusted
Publisher_ → GitHub: owner `diegosouzapw`, repo `OmniRoute`, workflow `npm-publish.yml`
(environment: none). Ruo mgbe nke ahụ dị, nzọụkwụ akpaaka ahụ ga-ada na `ENEEDAUTH`:
jiri `publish_mode=staged` (n'okpuru) ma ọ bụ `direct` ziga ya ọzọ.

### Mbipụta staged (mgbe a rịọrọ ya — `publish_mode=staged`)

Workflow npm-publish anaghịzi ebipụta ozugbo: ọ na-ebido tarball a kwakọtara
(`check:pack-boot`) wee gbaa `npm stage publish` — a na-edobe bytes ndị ahụ kpọmkwem na
registry, **agaghị enwe ike ịwụnye ha** ruo mgbe onye nwe ya kwadoro. A kwagara ọnụ ụzọ 2FA
nke mmadụ gaa MGBE ihe akaebe ahụ gasịrị, ọ bụghị tupu ya.

**Usoro onye nwe ya mgbe workflow ghọrọ green:**

1. `npm stage list omniroute` — chọta stage id (a na-ebipụtakwa ya na nchịkọta workflow).
2. Nyochaa bytes ndị e tinyere na stage (a na-atụ aro ya): `npm stage download <id>`, wee wụnye
   tarball ebudatara n'ime temp prefix ma bidokwa ya (`npm run check:pack-boot` na-eme
   otu mkpebi pack→install→boot ahụ na CI na-akpaghị aka).
3. `npm stage approve <id>` — arịrịọ 2FA BỤ mbipụta ahụ. `npm stage reject <id>` na-atụfu ya.
4. Nchedo mgbe mbipụta gasịrị: onye nyocha post-publish (WS1.4 nke atụmatụ v3.8.49) na-etinye
   version e bipụtara site na public registry n'ime container dị ọcha ma bidokwa ya.

**Nhọrọ ndabere mberede:** `workflow_dispatch` nwere `publish_mode=direct` na-eweghachi
`npm publish` ozugbo nke ochie (jiri naanị ma ọ bụrụ na staging n'onwe ya anaghị arụ ọrụ nke ọma; dekọọ ihe kpatara ya).

**Nchekwube otu ugboro (onye nwe ya, npmjs.com):** hazie Trusted Publisher maka
`omniroute` na ọnọdụ stage-only ka token na-adị ogologo oge nke gbapụtara ghara inwe ike ime `npm publish`
ozugbo site n'ebe ọ bụla — CI nwere ike naanị itinye na stage; naanị 2FA onye nwe ya na-ahapụ mwepụta.

**Usoro maka artifact mebiri emebi (agbanweghị):** `npm deprecate omniroute@<bad> "<reason> — use <fixed>"`
dịka mmeghachi omume ndabara (nkeji ole na ole, enwere ike ịtụgharị ya); jiri `npm unpublish` naanị n'ime
ohere 72h/no-dependents, emekwala ya dịka nzọụkwụ mbụ. Docker: edegharịla version tag — rollback bụ
ịtụgharị `latest` gaa na digest ikpeazụ dị mma.

**Docker Hub `latest` (achọrọ na mbipụta stable SemVer ọ bụla):** workflow
`docker-publish` ga-etinye tag na **ma** `X.Y.Z` **ma**, mgbe
`should-promote-latest.sh` kwetara na nke a bụ stable SemVer kachasị elu, `:latest`
nwere **otu digest ahụ**. Mgbe ọrụ ahụ gasịrị: digest `latest` nke Hub hà nhata digest SemVer
ọhụrụ, `last_updated` agbanwekwala. Ahapụla `:latest` na build ochie
ebe release notes na-ekwu maka ndozi ndị dị naanị na git. Compose
quickstarts na-eji `:latest`; GitOps kwesịrị ịnọgide na-atụnye `X.Y.Z`. Lee
[Ọwa mwepụta Docker](../guides/DOCKER_GUIDE.md#release-channels) na #10317.

## Ụzọ Ọsọ maka Hotfix (label `hotfix`)

PR e tinyere label `hotfix` na-amafere matriks CI dị arọ (E2E nwere shard 9, coverage ratchet,
quality-gate, quality-extended) ma debe ọnụ ụzọ dị ngwa ma na-enye akara doro anya: build,
unit shards, integration, vitest, lint/typecheck, docs-sync, `check:pack-artifact`
na nnwale boot-smoke nke tarball (`check:pack-boot`). Ebumnuche: ka ihe niile bụrụ green n'ime ≤15min kama ~33min.

**Iwu nnabata — a chọrọ ha anọ niile (e mere ya dịka ụzọ mberede Chromium/VS Code/Node):**

1. **Ogo nsogbu**: production emebiela — artifact e bipụtara na-akụda mgbe ọ na-amalite / ndozi
   nchekwa / ọ metụtara onye ọrụ ọ bụla nke release ahụ. "Dị mkpa" abụghị "emebiela".
2. **Ikike**: naanị onye nwe repository na-etinye label `hotfix`. Label ahụ BỤ
   nkwado ahụ — ejila aka gị tinye ya na PR campaign.
3. **Ihe akaebe**: body PR ahụ na-ejikọ run dị arọ gara aga nke mechara green kpamkpam (suite nke
   jobs ndị a mafere gaara enyocha ọzọ) yana test nke ndozi ahụ nke dara na mbụ ma mesịa gafee.
4. **Oke**: naanị cherry-pick — ndozi kacha nta, enweghị refactor, enweghị mgbanwe ndị ọzọ e tinyere n'ụzọ.

Run zuru ezu na-esote na release branch (release-green na-aga n'ihu) ga-enyocha ọzọ
akụkụ coverage/ratchet ndị a mafere — ụzọ ahụ na-amafere naanị ICHERE, ọ dịghị mgbe ọ na-amafere validation.
Diffs nke metụtara naanị tests (faịlụ niile dị n'okpuru `tests/`, ọ dịghị nke dị n'okpuru `tests/e2e/`) na-amafere matriks E2E
na-akpaghị aka, na-enweghị label ọ bụla.

### Hooks (Husky kwadoro)

Hooks Husky dị na `.husky/` ma na-agba na-akpaghị aka n'oge operations git.

- **pre-commit:** `npx lint-staged + node scripts/check/check-docs-sync.mjs + npm run check:any-budget:t11`

Ọ bụrụ na hook adaa: dozie nsogbu kpatara ya, ejila `--no-verify` gafee ya.

