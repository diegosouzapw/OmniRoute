## 1. Hazie VM

### 1.1 Mepụta instance ahụ

N'ebe onye na-enye VPS nke masịrị gị nọ:

- Họrọ Ubuntu 24.04 LTS
- Họrọ atụmatụ kacha nta (1 vCPU / 1 GB RAM)
- Tọọ okwuntughe root siri ike ma ọ bụ hazie igodo SSH
- Detuo **public IP** ahụ (dịka ọmụmaatụ, `203.0.113.10`)

### 1.2 Jikọọ site na SSH

```bash
ssh root@203.0.113.10
```

### 1.3 Melite sistemụ ahụ

```bash
apt update && apt upgrade -y
```

### 1.4 Wụnye Docker

```bash
# Wụnye ihe ndị ọ dabere na ha
apt install -y ca-certificates curl gnupg

# Tinye ebe nchekwa Docker gọọmentị
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $ (. /etc/os-release && echo "$VERSION_CODENAME") stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

### 1.5 Wụnye nginx

```bash
apt install -y nginx
```

### 1.6 Hazie Firewall (UFW)

```bash
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp    # SSH
ufw allow 80/tcp    # HTTP (ntụgharị ụzọ)
ufw allow 443/tcp   # HTTPS
ufw enable
```

> **Ndụmọdụ**: Maka nchekwa kachasị elu, kwe ka naanị IP Cloudflare nweta ọdụ mmiri 80 na 443. Lee ngalaba [Nchekwa Dị Elu](#advanced-security).

## 2. Wụnye OmniRoute

### 2.1 Mepụta ndekọ nhazi

```bash
mkdir -p /opt/omniroute
```

### 2.2 Mepụta faịlụ mgbanwe gburugburu

```bash
cat > /opt/omniroute/.env << 'EOF'
# === Nchekwa ===
JWT_SECRET=CHANGE-TO-A-UNIQUE-64-CHAR-SECRET-KEY
INITIAL_PASSWORD=YourSecurePassword123!
API_KEY_SECRET=REPLACE-WITH-ANOTHER-SECRET-KEY
STORAGE_ENCRYPTION_KEY=REPLACE-WITH-THIRD-SECRET-KEY
STORAGE_ENCRYPTION_KEY_VERSION=v1
MACHINE_ID_SALT=CHANGE-TO-A-UNIQUE-SALT
OMNIROUTE_WS_BRIDGE_SECRET=REPLACE-WITH-WS-BRIDGE-SECRET  # ACHỌRỌ na production: Codex Responses WS bridge na-eji ya

# === Ngwa ===
PORT=20128
NODE_ENV=production
HOSTNAME=0.0.0.0
DATA_DIR=/app/data
APP_LOG_TO_FILE=true
AUTH_COOKIE_SECURE=true
REQUIRE_API_KEY=false

# === URL (gbanwee ka ọ bụrụ domain gị) ===
# URL ntọala dị n'ime maka nkwukọrịta server-na-server maka ọrụ ahaziri oge / self-fetches.
BASE_URL=http://127.0.0.1:20128
# URL nke ihe nchọgharị na-ahụ, nke a na-eji maka OAuth callbacks, njikọ dashboard, na URL ọha emepụtara.
NEXT_PUBLIC_BASE_URL=https://llms.seudominio.com
# Nhọrọ iji kọwaa kpọmkwem public origin ga-anọchi nke ndabara maka URL asset ọha emepụtara.
# OMNIROUTE_PUBLIC_BASE_URL=https://llms.seudominio.com

# === Cloud Sync (nhọrọ) ===
# CLOUD_URL=https://cloud.omniroute.online
# NEXT_PUBLIC_CLOUD_URL=https://cloud.omniroute.online
EOF
```

> ⚠️ **DỊ MKPA**: Mepụta igodo nzuzo pụrụ iche! Jiri `openssl rand -hex 32` maka igodo ọ bụla.

### 2.3 Malite container ahụ

```bash

  --name omniroute \
  --restart unless-stopped \
  --env-file /opt/omniroute/.env \
  -p 20128:20128 \
  -v omniroute-data:/app/data \
```

```bash
docker ps | grep omniroute

```

## 3. Hazie nginx (Reverse Proxy)

### 3.1 Mepụta asambodo SSL (Cloudflare Origin)

Na dashboard Cloudflare:

1. Gaa na **SSL/TLS → Origin Server**
2. Pịa **Create Certificate**
3. Hapụ ntọala ndabara (afọ 15, \*.yourdomain.com)
4. Detuo **Origin Certificate** na **Private Key**

```bash
mkdir -p /etc/nginx/ssl

# Manye asambodo ahụ
nano /etc/nginx/ssl/origin.crt

# Manye igodo nzuzo ahụ
nano /etc/nginx/ssl/origin.key

chmod 600 /etc/nginx/ssl/origin.key
```

### 3.2 Nhazi Nginx

```bash
cat > /etc/nginx/sites-available/omniroute << 'NGINX'
# Sava ndabara — na-egbochi nnweta ozugbo site na IP
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    listen 443 ssl default_server;
    listen [::]:443 ssl default_server;
    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    server_name _;
    return 444;
}

# OmniRoute — HTTPS
server {
    listen 443 ssl;
    listen [::]:443 ssl;
    server_name llms.yourdomain.com;  # Gbanwee ya ka ọ bụrụ ngalaba gị

    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    client_max_body_size 100M;

    location / {
        proxy_pass http://127.0.0.1:20128;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Nkwado WebSocket
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # SSE (Server-Sent Events) — nzaghachi AI a na-ezipụ n'usoro iyi
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }
}

# Ntugharị HTTP → HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name llms.yourdomain.com;
    return 301 https://$server_name$request_uri;
}
NGINX
```

Mee ka oge ngwụcha iyi reverse-proxy kwekọọ na env vars oge ngwụcha OmniRoute gị. Ọ bụrụ na i bulie
`FETCH_TIMEOUT_MS` / `STREAM_IDLE_TIMEOUT_MS`, buliekwa `proxy_read_timeout` / `proxy_send_timeout`
karịa otu oke ahụ.

OmniRoute na-eji `NEXT_PUBLIC_BASE_URL` dịka origin iwu nke ihe nchọgharị na-ahụ maka callback
OAuth na njikọ ọhaneze ndị emepụtara. Arịrịọ ide na dashboard nke achọpụtara onye ọrụ na-eji arịrịọ same-origin
tinyere nchedo CSRF e jikọrọ na session, ya mere ha anaghị achọ URL ntọala ọhaneze na-adịghị agbanwe agbanwe. Header
`X-Forwarded-*` ndị dị n'elu ka bụ metadata routing bara uru, mana ha abụghị ihe nnọchi
maka ịtọ URL ọhaneze doro anya mgbe OAuth ma ọ bụ njikọ ihe nchọgharị emepụtara chọrọ ya. Kwado naanị
`OMNIROUTE_TRUST_PROXY` ma ọ bụrụ na ndị ahịa enweghị ike iru OmniRoute ozugbo ma proxy gị
na-ewepụ/na-ewughachi header forwarded ndị na-abata.

### 3.3 Kwado ma Nwalee

```bash
# Wepụ nhazi ndabara
rm -f /etc/nginx/sites-enabled/default

# Kwado OmniRoute
ln -sf /etc/nginx/sites-available/omniroute /etc/nginx/sites-enabled/omniroute

# Nwalee ma bugharịa ọzọ
nginx -t && systemctl reload nginx
```

- Ndegharị HTTPS Akpaka: ✅ Agbanyere

```bash
curl -sI https://llms.seudominio.com/health
```

## Nkwalite maka Nchekwa Dị Ala / Obere VPS

Maka mbugharị na obere VPS (RAM 1 GB ma ọ bụ nke na-erughị ya):

- **Gbanyụọ ọrụ ndabere** — tọọ `OMNIROUTE_DISABLE_BACKGROUND_SERVICES=1` ka a ghara ịgba scheduler, MCP server, na ọrụ mmezi oge niile. Lee `docs/reference/ENVIRONMENT.md`.
- **Jiri ọnọdụ SQLite WAL** — agbanyere ya na ndabara, ọ na-ebelata oke ojiji ebe nchekwa n'oge ọgụgụ ndị na-eme n'otu oge.
- **Kpaara heap V8 oke** — tọọ `OMNIROUTE_MEMORY_MB` (dịka `512`) ka runtime ghara ịhazi oke dị elu karịa nke VM. Lee `docs/reference/ENVIRONMENT.md`.
- **Nnabata ọrụ dị arọ na-agbanwe nha n'onwe ya dabere na oke heap** -- ozugbo atọrọ `OMNIROUTE_MEMORY_MB` dịka akọwara n'elu, mmefu baitị nnabata (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) na-enweta uru ya site n'otu oke ahụ, ya mere VM nwere ebe nchekwa pere mpe ga-enweta mmefu arịrịọ ndị na-eme n'otu oge nke pere mpe na-enweghị nhazi ọzọ; arịrịọ ndị karịrị oke ga-enweta `503` nke enwere ike ịnwale ọzọ, tinyere `Retry-After`, kama ịsọ mpi maka ebe nchekwa. Tọọ oke ọnụọgụ arịrịọ ochie `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` naanị ma ọ bụrụ na ịchọrọ oke siri ike n'elu nke ahụ.
- **Zere `next build` na VPS** — wuo ya na kọmputa mpaghara ma bugharịa mmepụta standalone (`.next/standalone/`).
- **Jiri `top` / `free -m` nyochaa ya** — OmniRoute na-ejikarị 200-400 MB RSS mgbe ọ naghị arụ ọrụ na VM nwere 1 GB.
