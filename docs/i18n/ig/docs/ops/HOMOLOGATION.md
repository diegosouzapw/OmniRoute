Nkwado E2E n'ime ezigbo gburugburu ebe deploy OmniRoute na-agba na VPS nnabata
(`HOMOLOG_BASE_URL`, dịka `http://192.168.0.15:20128`). Otu iwu na-eji ọsọ akpaghị aka nke na-emepụta ihe akaebe dochie
ndepụta nyocha STOP #2 nke mwepụta a na-eji aka eme.

## Ihe ọ na-ekpuchi

| Ọkwa                         | Ihe ọ na-enyocha                                                                                                                                                                                                         | Mmejuputa                                                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| L0 — ahụike/ndakọrịta        | `/api/monitoring/health` na-aza `200` na `status: "healthy"` yana ụdị a tụrụ anya ya                                                                                                                                     | `scripts/homolog/lib/parity.mjs`                                              |
| L1a — igodo nwa oge          | Nbanye admin → `POST /api/keys` na-emepụta igodo API nwere oke maka ọsọ ahụ, nke a na-akagbu (`DELETE /api/keys/:id`) n'ime ngọngọ `finally` n'agbanyeghị ihe si na ya pụta                                              | `scripts/homolog/lib/adminClient.mjs`                                         |
| L1b — akụkụ API              | Katalọgụ `/v1/models`, mmecha nkata n'ezie na-enweghị streaming (model dị mkpa maka tier, `max_tokens: 5`), `401` maka igodo na-ezighi ezi, yana `/api/monitoring/health` ọha                                            | `tests/homolog/api/core.http` (httpYac)                                       |
| L1c — streaming SSE          | Mmecha nkata streaming n'ezie; na-akwado `text/event-stream`, opekata mpe otu delta ọdịnaya, yana akara njedebe `[DONE]`                                                                                                 | `scripts/homolog/lib/sseCheck.mjs`                                            |
| L2 — ndị na-eweta ọrụ n'ezie | Otu arịrịọ nkata dị ọnụ ala kacha nta maka onye na-eweta ọrụ ọ bụla dị mkpa nke dị na katalọgụ `/v1/models` dị ndụ, nke promptfoo na-emepụta ozugbo                                                                      | `scripts/homolog/gen-promptfoo.mjs` + `scripts/homolog/lib/providerTiers.mjs` |
| L4a — nkwenye njirimara UI   | Na-abanye otu ugboro site na fọm nbanye n'ezie ma jiri otu nnọkọ ahụ (`storageState`) ọzọ n'ofe ọkwa UI                                                                                                                  | `tests/homolog/ui/auth.setup.ts`                                              |

## Ihe ndị achọrọ tupu amalite

1. Detuo `.env.homolog.example` gaa na `.env.homolog` (git na-eleghara ya anya — etinyela ya na commit ma ọlị) ma dejupụta:
   - `HOMOLOG_BASE_URL` — deploy a na-achọ ịnwale, dịka `http://192.168.0.15:20128`.
   - `HOMOLOG_ADMIN_PASSWORD` — okwuntughe njikwa dashboard maka deploy ahụ.
   - `HOMOLOG_CRITICAL_PROVIDERS` — prefixes nke providers ndị e ji rikoma kewaa, bụ́ ndị ga-enweta ezigbo
     arịrịọ smoke chat (dịka `openai,anthropic,gemini,codex,grok,glm,deepseek,openrouter`).
   - `HOMOLOG_API_KEY` — hapụ ya oghere na run nkịtị; suite ahụ na-emepụta ma na-akagbu
     ephemeral key nke ya. Tọọ nke a naanị iji debug otu layer n'onwe ya.
2. Mee `npm install` n'ime repo (dependencies nke suite ahụ — `httpyac`, `promptfoo`,
   `playwright-ctrf-json-reporter`, `junit-to-ctrf`, `ctrf` — bụ devDependencies nkịtị).
3. Mee `npx playwright install` ma ọ bụrụ na browser binaries adịbeghị.

## Otu esi eme run

```bash
npm run homolog
```

Iji mee validation megide deploy nke version ya adabaghị na `package.json` dị na mpaghara
(dịka igbe homologation ka nọ na patch release gara aga), jiri aka gị dochie version
a na-atụ anya ya:

```bash
HOMOLOG_EXPECT_VERSION=3.8.47 npm run homolog
```

Run ahụ ga-eji status na-abụghị efu kwụsị ma ọ bụrụ na layer ọ bụla daa, ọ na-agbalịkwa mgbe niile ịkagbu ephemeral
API key o mepụtara, ọbụlagodi mgbe ọdịda mere (`finally` block dị na `scripts/homolog/run.mjs`).

## Otu esi agụ report ahụ

Output niile na-abanye na `homolog-report/` (git na-eleghara ya anya):

- `summary.md` — otu table ahụ e bipụtara na stdout, otu row maka layer ọ bụla (✅/❌ + nkọwa).
- `homolog-ctrf.json` — report CTRF ejikọtara ọnụ (njikọ nke nsonaazụ API/SSE, provider-smoke, na
  UI) — nke a bụ artifact a ga-etinye na checklist STOP #2 nke release.
- `httpyac-junit.xml`, `api-ctrf.json`, `providers-ctrf.json`, `ui-ctrf.json` — report
  raw/intermediate nke layer ọ bụla.
- `promptfooconfig.yaml`, `provider-misses.json` — config promptfoo emepụtara maka
  run dị ugbu a na critical providers ọ bụla na-anọghị na live catalog.

L0 dara ada na-eme ka usoro ahụ kwụsị ozugbo (a naghị emepụta ephemeral key) n'ihi na version/health
na-adabaghị pụtara na layer niile na-esote ga na-eme validation megide deploy na-ezighi ezi.

## Ịtọgharị baseline mgbe UI gbanwere n'ụzọ ziri ezi

Ezigbo DOM locators, ọ bụghị snapshots, na-achịkwa L4b (route smoke) na L4c (API-key UI flow),
ya mere ọtụtụ mgbanwe UI ziri ezi anaghị achọ mmelite ọ bụla na suite ahụ. Mgbe mgbanwe
mebiri locator (dịka label button a gbanwere aha ma ọ bụ settings page e bugara ebe ọzọ):

1. Nyochagharịa locator ahụ megide source dị ugbu a (specs ndị ahụ edepụtalarị
   file/line nke e ji kwado locator ọ bụla — soro otu usoro ahụ, echepụtala ya n'isi).
2. Melite spec dị na `tests/homolog/ui/`.
3. Mee `npm run homolog` ọzọ (ma ọ bụ naanị Playwright spec metụtara) megide VPS iji
   kwado ndozi ahụ, wee mee commit.

Enweghị visual/pixel baseline na suite a (F1) — lee Roadmap maka nke ahụ.

## Roadmap (F2 / F3)

Design na phased rollout dị na internal planning spec
`_tasks/superpowers/specs/2026-07-13-homolog-e2e-suite-design.md` (ejikọtaghị ya — ọ bụ internal
`_tasks/` artifact, ọ bụghị akụkụ nke tracked docs nke repo a). Nchịkọta:

- **F2** — ndekọ walkthrough zuru ezu → Playwright Test Agents (`planner`/`generator`)
  na-atụgharị ya ka ọ bụrụ flow specs (mepụta combo, nwalee provider, dezie settings, MCP tools) +
  visual regression baseline (Lost Pixel) nwere masks n'elu dynamic data (metrics,
  timestamps, logs) + usoro mmezi `healer` maka release ọ bụla.
- **F3** — coverage maka resilience/contract/wiring: toxiproxy + provider adịgboroja dakọtara na OpenAI
  na devbox, combo `homolog-resilience` na VPS nke a tụrụ aka na ya
  (timeout etinyere → kwadoo fallback + mmeghe/mmechi circuit breaker site na
  `/api/monitoring/health`); gated Schemathesis contract testing megide
  `docs/openapi.yaml` (`--max-examples` dị ala, seeds edoziri, naanị endpoints na-abụghị LLM); na
  ijikọ `npm run homolog` + `summary.md` ya n'ime phase STOP #2 nke `/generate-release`.
