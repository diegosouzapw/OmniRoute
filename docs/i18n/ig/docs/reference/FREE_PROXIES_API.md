OmniRoute na-eweta nchịkọta proxy efu ahọpụtara nke ọma na tebụl `free_proxies`,
nke a na-emekọrịta site n’aka ndị na-enye ọrụ mpụga (1proxy, proxifly, iplocate, webshare). Dashboard ahụ
na-egosi ha n’okpuru **Settings → Free Proxies**. Akwụkwọ a
na-akọwa nzacha, nhazi, ngụkọta, na mkpesa njehie mmekọrịta n’akụkụ sava
nke ụzọ ndepụta ahụ na-enye.

## Ụzọ ndepụta — `GET /api/settings/free-proxies`

Na-eweghachi akụkụ data a nzachara, haziri, ma kewaa n’ibe, tinyere ngụkọta zuru ezu. Nzacha na
ngụkọta na-eme na SQL, ka UI nwee ike igosi ngụkọta ziri ezi (dịka `Total: 0`)
na-enweghị ibubata ahịrị niile n’ebe nchekwa.

### Paramita ajụjụ

| Param             | Ụdị                                | Ndabara   | Ihe ọ pụtara                                                                                                                                             |
| ----------------- | ---------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | eriri                              | `""`      | `LIKE` na-eburu mkpụrụedemede ukwu na nta n’uche na kọlụm host (na source).                                                                              |
| `protocol`        | eriri                              | `""`      | Nzacha `type`: `http` / `https` / `socks4` / `socks5`. Oghere efu = ha niile.                                                                            |
| `country`         | eriri                              | `""`      | Nzacha `countryCode` (ISO-2). Oghere efu = ha niile.                                                                                                     |
| `minQuality`      | ọnụọgụ                             | `0`       | Naanị ahịrị nwere `qualityScore >= minQuality`. `0` = enweghị oke ala.                                                                                   |
| `disabledSources` | eriri                              | `""`      | Id source ndị e ji rikoma kewaa ka ewepụ (dịka `proxifly,webshare`).                                                                                     |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = score site n’elu ruo n’ala; `latency` = latency site n’ala ruo n’elu (nulls n’ikpeazụ); `recent` = `lastValidated` site n’ọhụrụ ruo n’ochie. |
| `offset`          | ọnụọgụ                             | `0`       | Ebe nkewa ibe ga-amalite.                                                                                                                                |
| `limit`           | ọnụọgụ                             | `50`      | Ogo ibe (sava na-etinye oke).                                                                                                                            |

### Nzaghachi

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` na-egosi ngụkọta a nzachara **tupu** nkewa ibe, ka UI nwee ike igosipụta
`Total: N` na `hasMore` n’adabereghị ibe ha. A na-eji id source dị ka key maka `syncErrors`, a na-etinyekwa
ozi naanị maka source ndị mmekọrịta ikpeazụ ha dara — nsonaazụ `Total: 0`
anaghị adị mgbe ọ bụla n’enweghị nkọwa.

## Tinye-na-pool — `POST /api/settings/free-proxies/[id]/add-to-pool`

Na-ebuli proxy efu ka ọ banye na pool `proxy_registry` a na-achịkwa. Ọ na-enyocha
upstream na mbụ; ma ọ bụrụ na ọ gaa nke ọma, ọ na-eweghachi id proxy ọhụrụ dị na pool na latency a tụrụ.

## Mmekọrịta — `POST /api/settings/free-proxies/sync`

Na-adọtakwa source niile enyere ikike (ma ọ bụ naanị ndị dị na `{ "sources": [...] }`). Source
ọ bụla na-emekọrịta n’onwe ya; a na-edekọ source dara ada na `syncErrors`, ebe ndị
ọzọ ka na-emecha, ya mere mmekọrịta akụkụ ụfọdụ anaghị ehichapụ data ọma dịbu adị.

## Ndekọ ọnụọgụ — `GET /api/settings/free-proxies/stats`

Na-eweghachi nchịkọta `total / inPool / avgQuality / bySource / lastSyncAt`
na-enweghị payload ahịrị — widget ndị dị n’isi dashboard na-eji ya.
