Relays (Vercel, Deno, Cloudflare) na-akwụsị njikọ upstream na backend
serverless ka OmniRoute nwee ike isi na mpaghara kwụsiri ike zipụ okporoụzọ, ma na-edobe
igodo API nke provider n'akụkụ sava. Akwụkwọ a na-akọwa ụdị ọdịda abụọ
ndị ọrụ na-ahụ na production na ụzọ mgbake OmniRoute na-enye maka
nke ọ bụla.

## Otu esi echekwa relay auth

Mgbe ị na-ebunye relay site na **Ntọala → Proxy Pool → Bubata Relay**,
usoro mbubata ahụ na-echekwa token auth nke relay n'ime oghere JSON `notes`
nke proxy:

- Ọ bụrụ na edobere `STORAGE_ENCRYPTION_KEY`, a na-ede token ahụ dịka `relayAuthEnc`
  (eji AES ezoro ya mgbe echekwara ya).
- Ma ọ bụghị ya, a na-ede ya dịka plaintext `relayAuth`.

N'oge arịrịọ, `extractRelayAuth(notes)` na-eweghachi ụdị ọ bụla dị,
ya mere relay ahụ na-aga n'ihu ịrụ ọrụ mgbe ebidoghachiri sistemụ.

## Ụdị ọdịda 1 — enweghị ike ịkọpụ izo token mgbe agbanwechara igodo

**Mgbaàmà:** relays ndị na-arụbu ọrụ na-eweghachi njehie upstream `401`/auth
mgbe agbanwechara `STORAGE_ENCRYPTION_KEY` na environment ma ọ bụ
secret-manager. Enweghịzi ike ịkọpụ izo blob `relayAuthEnc` echekwara,
ya mere `extractRelayAuth` na-eweghachi eriri efu, relay ahụ anaghịkwa eziga
auth ọ bụla.

**Mgbake — rụzie ya ebe ọ dị (enweghị mbubata ọzọ):**

1. Mepee **Ntọala → Proxy Pool**.
2. Ahịrị relay ndị auth ha na-efu na-egosi baajị odo `auth na-efu` na
   bọtịnụ **Rụzie**.
3. Pịa **Rụzie**. OmniRoute na-akpọ
   `POST /api/settings/proxies/[id]/repair-relay`, nke na-eme ihe ndị a:
   - jiri igodo **dị ugbu a** kọpụ izo `relayAuthEnc`,
   - deghachi plaintext `relayAuth` n'ime `notes`,
   - weghachite `{ repaired: true, mode: "recovered" }`.

Relay ahụ na-amaliteghachi inye ọrụ na-enweghị itinyeghachi ozi nzere mbubata ọ bụla.

Nke a na-arụ ọrụ naanị ma ọ bụrụ na `STORAGE_ENCRYPTION_KEY` dị ugbu a ka nwere ike
ịkọpụ izo blob ahụ. Ọ bụrụ na ị gbanwere igodo ahụ **na-enweghị** migration,
enweghị ike iweghachite blob ahụ.

## Ụdị ọdịda 2 — token a na-apụghị iweghachite (ewepụla igodo ochie)

**Mgbaàmà:** ị pịrị **Rụzie** wee nweta
`{ repaired: false, mode: "redeploy", status: 409 }`.

**Mgbake — bubatagharịa:**

Enweghị ike iji igodo dị ugbu a weghachite token echekwara. Bubatagharịa relay ahụ
site n'otu modal ahụ i jiri na mbụ (**menu Bubata Relay** → Vercel / Deno
/ Cloudflare). Usoro mbubata ahụ na-ede token ọhụrụ (nke e ji igodo dị ugbu a
zoo), baajị `auth na-efu` dị n'ahịrị ahụ ga-apụkwa.

N'ime UI, bọtịnụ **Rụzie** n'onwe ya na-emepe modal mbubata ọzọ mgbe
a na-apụghị iweghachite token ahụ, ya mere ị gaghị achọgharị ya n'onwe gị.

## Ụdị ọdịda 3 — enwere ike iru relay mana ọnọdụ ya adịghị mma

**Mgbaàmà:** nnwale proxy (bọtịnụ `speed`) na-egosi na relay ahụ dị ndụ, mana arịrịọ
ka na-ada mgbe ụfọdụ.

Lelee headers ngosipụta ọnọdụ relay nke probe auto-test OmniRoute weghachiri
(lee **Ntọala → Proxy Pool** na counters `relayTested` / `relayAlive`):

- `x-relay-url` — backend relay nke zara.
- `x-relay-mode` — `ts` | `bifrost` | `auto` maka arịrịọ ahụ.
- `x-relay-attempts` — ọnụ ọgụgụ relay hops a nwara tupu ọ gaa nke ọma.
- `x-relay-fallback` — `true` mgbe arịrịọ ahụ si na backend a họọrọ
  laghachi na relay TypeScript.

Ọnụego `x-relay-fallback` dị elu yana `relayAlive` dị ala pụtara na backend
sidecar adịghị mma; ị kwesịrị ịrụzi ya ma ọ bụ gbanwee atụmatụ backend relay
ka ọ bụrụ `ts` (lee `RELAY_BACKEND_STRATEGY.md`).

## Ntụaka API

| Method | Path                                      | Body                    | Ọganiihu                                                                                                                            | Ọdịda                                                                                          |
| ------ | ----------------------------------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `POST` | `/api/settings/proxies/[id]/repair-relay` | `{ "id": "<proxyId>" }` | `200 { repaired: true, mode: "recovered" }` mgbe ewepụtaghachiri ya; `200 { repaired: false, mode: "noop" }` mgbe plaintext adịlarị | `409 { mode: "redeploy" }` enweghị ike iweghachite ya; `400` abụghị ụdị relay; `404` ahụghị ya |

Route ndepụta `GET /api/settings/proxies` na-agbakwunye
`relayInfo: { isRelay, authMissing, repairMode }` nke na-enweghị secret na item ọ bụla,
ka dashboard nwee ike igosi nhọrọ nrụzi na-enweghị ikpughe token ahụ ma ọlị.
