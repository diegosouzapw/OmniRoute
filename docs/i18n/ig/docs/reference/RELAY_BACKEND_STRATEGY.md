## Nchịkọta

OmniRoute na-akwadozi ụdị relay atọ maka `/api/v1/relay/chat/completions`:

- `ts`: Jiri relay TypeScript n'ime usoro ahụ.
- `bifrost`: Manye gateway Bifrost.
- `auto`: Họrọ Bifrost mgbe ọ dị, ma laghachi na TypeScript ma ọ bụrụ na ọ daa.

Mgbe ị na-arụ ọrụ n'ọ̀tụ̀ request dị elu (ọtụtụ token kwa ụbọchị, throughput nke fọrọ nke nta ka ọ ghara ịkwụsị), atụmatụ kacha mma bụ ime ka ụzọ fallback doo anya ma dị ngwa ka ụzọ a na-ejikarị eme ihe ghara ichere sidecar nwụrụ anwụ.

## Omume ụdịdị

- `ts`
  - Mgbagwoju anya ọrụ kacha nta.
  - Routing na validation niile na-arụ na Node.
  - Enweghị ndabere na sidecar maka availability.
- `bifrost`
  - Manye request niile ịgafe na gateway sidecar.
  - Enweghị fallback akpaka.
  - Ọ bara uru naanị mgbe e kwere nkwa ahụike na latency nke sidecar.
- `auto`
  - A na-eji sidecar mgbe enwere ike iru ya ma agbanyere ya.
  - Mgbalị dara ada na-akpalite header fallback ma na-eweghachi traffic na TS ka oge mmecha nke request gara nke ọma nwee oke doro anya.
  - Ụdị a bụ nhọrọ kacha nwee nchekwa maka production mgbe uptime dị mkpa karịa routing siri ike nke na-eji naanị sidecar.

## 9router megide CLIPROXYAPI taa

9router na CLIPROXYAPI bụ integration abụọ nke, n'akụkọ ihe mere eme, nyere compatibility path maka provider upstream.

- 9router bụ ụzọ etinyere n'ime sistemụ maka nhazi upstream na omume compatibility.
- CLIPROXYAPI bụ àkwà mmiri proxy API maka traffic ụdị CLI / SDK.
- A na-eme ka Bifrost kwụsie ike dịka ụzọ e wepụtara n'èzí mgbe ịchọrọ ngafe pụrụ iche yiri sidecar na dispatch mpaghara nwere latency dị ala.

Ọ bụrụ na ị na-atụnyere 9router/CLIPROXYAPI ugbu a:

- Debe request signing, allowlist check, na DB policy gate n'ime API route tupu handoff.
- Ọ bụrụ na workflow chọrọ omume sidecar siri ike na mgbanwe pere mpe n'etiti request, jiri `OMNIROUTE_RELAY_BACKEND=bifrost`.
- Ọ bụrụ na ịchọrọ nkwụsi ike sidecar yana graceful degradation n'oge nsogbu, jiri `OMNIROUTE_RELAY_BACKEND=auto`.

## Nkwekọrịta ókè backend

Ókè ngwaahịa kwụsiri ike bụ OmniRoute relay API, ọ bụghị mmejuputa dashboard. Dashboard Next.js nwere ike iwunye, hazie, ma lekọta service mpaghara, mana request routing kwesịrị ịbanye site na relay API wee nyefee ọrụ n'azụ ókè ahụ.

Nhọrọ backend ogologo oge:

- Debe relay TypeScript dịka ụzọ policy na fallback nke dị n'ime usoro ahụ. Auth, allowlist, request normalization, accounting, na safety check ga-anọ ebe a tupu handoff backend ọ bụla.
- Jiri Bifrost dịka sidecar Tier-1 kachasị amasị maka throughput dị elu mgbe deployment chọrọ mgbanwe routing dị ala, provider rotation etinyere n'otu ebe, ma ọ bụ scale-out gafee ọtụtụ replica OmniRoute.
- Debe 9router na CLIPROXYAPI dịka service compatibility etinyere n'ime sistemụ. Ha na-arụ dịka process mpaghara a na-elekọta ma baa uru mgbe omume provider/CLI ha bụ adapter achọrọ, mana ha ekwesịghị ịghọ engine routing Tier-1 ndabara.
- Ekwela ka dashboard nyefee URL service ọ bụla n'ụzọ a na-ejikarị eme ihe. URL nke UI nyere bụ input nhazi; code routing kwesịrị ịchọta backend edebanyere aha ma gafee health check site na setting dị n'akụkụ server na state supervisor.
- Họrọ loopback HTTP maka service a na-elekọta taa n'ihi na process ndị a na-achịkwa enyelarị API dakọtara na HTTP, route guard nwere ike inyocha ókè ahụ, a na-ahụkwa omume failure/fallback na request log. Ọ bara uru ịgbakwunye SDK ma ọ bụ socket transport n'ọdịnihu naanị ma ọ bụrụ na ọ na-ebelata latency routing p99 n'ụzọ a pụrụ ịtụ ma ghara imebi isolation ma ọ bụ semantics fallback.

Ya mere, maka deployment nwere throughput dị nnọọ elu, azịza ndabara bụ `auto` ebe agbanyere Bifrost: jiri sidecar Go n'ụzọ a na-ejikarị eme ihe ma debe fallback TypeScript iji chekwaa success rate. Jiri `bifrost` naanị mgbe omume siri ike nke na-eji naanị sidecar dị mkpa karịa graceful degradation.

## Nduzi maka throughput dị elu

Maka RPM/RPS dị elu na-adịgide adịgide yana success SLO siri ike:

1. Jiri `auto` tinyere cooldown bara uru na telemetry failure.
2. Debe validation upstream na API-key check n'ókè route TypeScript.
3. Gbanye header/counter doro anya ka alerting gị hụ ugboro fallback na ihe kpatara ya.
4. Hazie timeout sidecar ka ọ daa ngwa ngwa, ọ bụghị ka ọ chere ruo mgbe ebighị ebi.
5. Mee ka auto-restart service na loop telemetry ahụike nọgide na-arụ ọrụ nke ọma ka fallback bụrụ ihe pụrụ iche n'ezie.

## Ntọala ndabere a tụrụ aro

- `OMNIROUTE_RELAY_BACKEND=auto`
- `BIFROST_ENABLED=1`
- Hapụ API key, allowlist, sanitizer, na rate-limit check ka ha nọgide na-arụ ọrụ n'ime route handler (ha na-arụ ọrụ mgbe niile tupu forwarding downstream).
- Bupụ metric fallback site na reverse proxy na request log gị ka a hụ outage sidecar n'ime otu nkeji.
