## Otu dị iche iche

- **N'efu** — ọkwa efu nwere igodo API (a na-ahazi ya site na dashboard)
- **Enweghị njirimara** — ebe njedebe ọha na eze na-achọghị igodo ma ọ bụ nbanye ma ọlị
- **OAuth** — usoro nbanye nke OmniRoute na-ahụ maka ya, achọghị igodo API
- **Kuki webụ** — na-eji njirimara kuki kpuchie ngwa webụ nke onye na-eweta ọrụ
- **Igodo API** — onye na-eweta ọrụ a na-akwụ ụgwọ nke a na-ahazi site na igodo API (kredit efu nwere ike ịdị)
- **Mpaghara** — na-arụ ọrụ na kọmputa onye ọrụ (Ollama, LM Studio, vLLM, wdg.)
- **Ọchụchọ** — ndị na-eweta ọrụ ọchụchọ webụ
- **Ọdịyo** — ndị na-eweta naanị ọdịyo (TTS/STT)
- **Proksi nke elu** — ndị na-eweta ọrụ na-ezigara ndị ọzọ arịrịọ dịka proksi
- **Ajẹntị igwe ojii** — ajẹntị ide koodu na-arụ ọrụ ogologo oge (Codex Cloud, Devin, Jules)
- **Sistemụ** — ndị na-eweta ọrụ dị n'ime OmniRoute (loopback, wdg.)

Mkpado ndị ọzọ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (ebe egosiri ya): `native` — API ezigbo ịkpọ fọnkụshọn; `emulated` — a na-eme ka n'usoro `tools` site na prompt site na `webTools.ts` (a na-eji regex tụ解析 blọk `<tool>{...}</tool>`); `none` — ugbu a, a na-atụfu `tools` n'enweghị ozi ọ bụla. Lee #7286.

Jiri dashboard dị na `/dashboard/providers` iji mee ka onye na-eweta ọrụ ọ bụla rụọ ọrụ, hazie ya, ma nwalee ya.
