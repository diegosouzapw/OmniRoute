Akwụkwọ a na-edekọ mkpebi mmejuputa maka
[Issue #7854](https://github.com/diegosouzapw/OmniRoute/issues/7854). A na-anọchi anya ngwaahịa ọha dịka ezinụlọ ndị na-eweta ọrụ anọ. Mpaghara bụ data njikọ, ọ bụghị ngwaahịa dị iche.

## Mkpebi

| Ezinụlọ onye na-eweta ọrụ                     | OmniRoute ID            | Mpaghara ụwa | Mpaghara China |
| --------------------------------------------- | ----------------------- | ------------ | -------------- |
| Alibaba Cloud Model Studio (kwụọ ka ị na-eji) | `alibaba`               | Singapore    | Beijing        |
| Alibaba Cloud Token Plan                      | `bailian-coding-plan`   | Singapore    | Beijing        |
| Qwen Cloud (kwụọ ka ị na-eji)                 | `qwen-cloud`            | Global       | Beijing        |
| Qwen Cloud Token Plan                         | `qwen-cloud-token-plan` | Singapore    | Beijing        |

`alibaba-cn` ID dị ugbu a ka na-adị dịka aha ọzọ maka ndakọrịta n'oge mmemme maka njikọ echekwara, ụzọ
model, ngwakọta, na ojiji gara aga. A na-etinye kaadị dashboard ya n'ime `alibaba`; ọ dịghị mkpa
idegharị nchekwa data.

Qwen Cloud nke ịkwụ ụgwọ dịka ojiji na Alibaba Cloud Model Studio na-eji otu runtime host ndị dakọtara
na DashScope ugbu a, mana ha ka bụ njirimara ndị na-eweta ọrụ dị iche n'ihi na ndị ọrụ na-enweta key ma na-achịkwa
akaụntụ site na oghere ngwaahịa dị iche iche. Ngwaahịa Alibaba na Qwen Cloud Token Plan na-eji
ezinụlọ endpoint dị iche iche, ya mere ngwaahịa anọ ahụ niile ka nwere provider ID dị iche iche.

## Nkwekọrịta njikọ

Njikọ ọhụrụ na-echekwa key mpaghara kwụsiri ike n'ime `providerSpecificData`:

```json
{
  "region": "global-sg"
}
```

Ụkpụrụ ndị anabatara bụ `global-sg` na `china-beijing`. A na-enweta endpoint site n'otu ebe dabere na
provider ID na mpaghara. `providerSpecificData.baseUrl` na-abụghị nke atọrọla ka bụ mgbanwe doro anya nke onye
ọrụ na-ahazi ma nwee ikike karịa, ebe a na-eme ka URL atọrọla ochie ndị echekwara laghachi n'usoro
mpaghara ahụ.

Nke a na-eme ka schema njikọ nwee ike ịgbasawanye: enwere ike ịgbakwunye mpaghara ọzọ na resolver n'enweghị
ịmepụta kaadị onye na-eweta ọrụ ọzọ ma ọ bụ ịgbanwe provider ID ndị echekwara.

## Ndakọrịta na mwepụta

1. Tinye ihe na-achọpụta endpoint mpaghara ma debe ndabara zuru ụwa ọnụ ndị dị ugbu a.
2. Jiri nchọpụta DashScope `/models` mpaghara dị ndụ maka `alibaba`, ID ndakọrịta ya bụ `alibaba-cn`,
   na `qwen-cloud`. Nzaghachi ha ga-ebu ụzọ gafee otu nzacha mmepụta-ederede n’ihi na endpoint izugbe
   na-eweghachikwa ụdịdị onyonyo, vidio, ọdịyo, embedding, na ụdịdị ndị ọzọ na-abụghị nkata. `qwen-cloud`
   ga-emesịa tinye allowlist a na-elekọta nke ekwuputara na ndekọ provider ya. Alibaba Model Studio
   na Qwen Cloud na-edobe katalọgụ ahọpụtara iche iche n’agbanyeghị na ha na-eji otu runtime hosts ugbu a.
3. Debanye `qwen-cloud-token-plan` na allowlist ụdịdị ederede Token Plan dị ugbu a.
4. Tinye ihe nhọpụta mpaghara nwere type na dialog njikọ maka ịgbakwunye/dezie.
5. Zoo kaadị `alibaba-cn` e megharịrị ugboro abụọ ma tinye njikọ ya ndị dị ugbu a na peeji provider
   `alibaba`.
6. Debe nhọrọ iji custom endpoint dochie ndabara maka mwepụta dị elu na ndị akọwapụtara maka workspace.

Ụdịdị mgbasa ozi Token Plan ka dị n’èzí katalọgụ nkata n’ihi na ha na-eji endpoint ndị pụrụ iche.
E debanyere `wan2.7-image` na `wan2.7-image-pro` na `open-sse/config/imageRegistry.ts`;
e debanyere `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, na `happyhorse-1.1-r2v` na
`open-sse/config/videoRegistry.ts`. Ndekọ abụọ ahụ na-ejigharị njirimara njikọ
`qwen-cloud-token-plan` na nzere ya ndị akọwapụtara dịka mpaghara si dị.

Qwen Cloud nkịtị nwere katalọgụ onyonyo na vidio pay-as-you-go dị iche n’okpuru njirimara
`qwen-cloud`. Ụdịdị onyonyo ya bụ `wan2.7-image-pro`, `wan2.7-image`, `qwen-image-3.0-pro`,
`qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0-2026-03-03`, na `z-image-turbo`. Ụdịdị vidio ya
bụ `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`,
`happyhorse-1.0-video-edit`, `wan2.7-t2v`, `wan2.7-i2v`, `wan2.7-r2v-2026-06-12`, na
`wan2.7-videoedit`. Ụdịdị ndị a na-ejigharị naanị njikọ `qwen-cloud` nkịtị na endpoint mgbasa ozi
DashScope mpaghara. Ndekọ Token Plan na pay-as-you-go anaghị eketa ma ọ bụ jikọta ndepụta ụdịdị
nke ibe ha.

Njirimara `bailian-coding-plan` nwekwara allowlist mgbasa ozi nke ya:
`wan2.7-image`, `wan2.7-image-pro`, `qwen-image-2.0`, na `qwen-image-2.0-pro` maka mmepụta
onyonyo, tinyere
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, na `happyhorse-1.1-r2v` maka mmepụta
vidio. Ọ na-eji naanị njikọ Bailian Coding Plan na endpoint Coding Plan mpaghara.
Ndekọ onyonyo na vidio ya anaghị eketa n’aka ma ọ bụ jikọta na provider Qwen Cloud nke ọ bụla.

Njirimara `alibaba` nkịtị nwere allowlist onyonyo na vidio dị iche iche. Ụdịdị onyonyo ya bụ
`qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0`,
`z-image-turbo`, na `wan2.6-t2i`. Ụdịdị vidio agbakwunyere ya bụ `happyhorse-1.1-i2v`,
`happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`,
`wan2.7-i2v-2026-04-25`, `wan2.6-i2v-flash`, `wan2.7-t2v-2026-06-12`,
`wan2.7-r2v-2026-06-12`, na `wan2.7-videoedit`. Ụdịdị ndị a na-eji naanị njikọ Alibaba Model Studio
na endpoint mgbasa ozi mpaghara ahọpụtara ya; a naghị etinye ha na ndekọ Coding Plan ma ọ bụ Qwen
Cloud ọ bụla.

Katalọgụ nkata Qwen Cloud Token Plan na-agbaso allowlist ederede exact-string nke atụmatụ Individual:
`qwen3.8-max-preview`, `qwen3.7-max`, `qwen3.7-plus`, `qwen3.6-flash`, `glm-5.2`, na
`deepseek-v4-pro`. Ndenye Wan na HappyHorse bụ nke API mmepụta onyonyo/vidio ndị dị iche.

Alibaba Token Plan na-egosipụta otu ID ụdịdị mmepụta-ederede isii ndị ahụ dị ugbu a site na
endpoint ya dakọtara na Anthropic. Nhọrọ Singapore ya na-echekwa igodo mpaghara `global-sg` dị ugbu a;
naanị label onye ọrụ na-ahụ dị iche na ezinụlọ provider ndị na-akpọ mpaghara ahụ Global.

E ji ụma mee ka katalọgụ nkata Qwen Cloud nkịtị dị warara karịa nzaghachi ederede dị ndụ zuru ezu.
Allowlist ya a na-elekọta dị na `open-sse/config/providers/registry/qwen-cloud/index.ts`; nchọpụta
dị ndụ na-eweghachi naanị ID ndị dị ma na nzaghachi upstream ma na ndepụta ndekọ ahụ.

Alibaba Model Studio na-agbaso otu iwu njikọ-ndepụta dị ndụ ahụ site na allowlist ya a na-elekọta
n’onwe ya dị na `open-sse/config/providers/registry/alibaba/index.ts`. Provider ndakọrịta
`alibaba-cn` na-ejigharị katalọgụ ahụ ma na-achọpụta discovery site na endpoint Beijing.
