OmniRoute na-eme ka **mmepụta onyonyo** nke atụmatụ Cursor dị na `POST /v1/images/generations` site n'otu id onye na-eweta ọrụ ahụ dị ka nkata: `cursor` (aha ọzọ `cu`).

| Oghere               | Uru                                                                                            |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| id `IMAGE_PROVIDERS` | `cursor`                                                                                       |
| Ọdịdị                | `cursor-agent-image`                                                                           |
| Nyocha njirimara     | Otu njikọ OAuth / API-key ahụ a na-eji maka nkata (`provider_connections.provider = "cursor"`) |
| Ụdịdị                | `cursor/auto`, `cursor/composer-2`, `cursor/composer-2.5`                                      |

## Ihe kpatara Agent CLI

Nkata Cursor dị na OmniRoute na-eji `agent.v1.AgentService/Run` (protobuf). Ụzọ ahụ **na-ajụ** ngwaọrụ ndị e wuru n'ime klayenti (shell, write, …). Mmepụta onyonyo bụ ngwaọrụ nke Cursor n'onwe ya nke **`agent` CLI** na-arụ megide seat ahụ. Ya mere, ihe njikwa onyonyo na-ebido `agent` site na prompt akpọchiri akpọchi na ebe ọrụ nwa oge maka arịrịọ ọ bụla (n'otu usoro ahụ dị ka njikọ seat ndị obodo mepụtara), wee weghachite `b64_json` dakọtara na OpenAI.

## Mmachi nnweta (Iwu Siri Ike #15 + #17)

Nke a bụ naanị usoro `IMAGE_PROVIDERS` na-ebido child process (binary `agent`
ahụ). Ebe ọ bụ na ihe dị ka ndị na-eweta onyonyo 40 ndị ọzọ na-adịghị ebido process,
ndị na-akpọ site n'ebe dịpụrụ adịpụ na-eji n'ụzọ ziri ezi, na-ejikwa `POST /v1/images/generations`,
e kewaghị route ahụ dum dịka `LOCAL_ONLY` — kama nke ahụ, `handleCursorAgentImageGeneration`
na-etinye ọnụ ụzọ njikwa nke ya site na mkpebi `AUTHZ_HEADER_PEER_LOCALITY` a tụkwasịrị obi,
nke usoro authz na-akanye na arịrịọ ọ bụla (site na TCP peer n'ezie, ọ bụghị header `Host`
a pụrụ ịghọgbu): naanị ndị na-akpọ sitere na `loopback` na `lan` nwere ike iru ebe a na-ebido
process; ndị ọzọ niile (gụnyere API key furu efu e ji megharịa arịrịọ site na public tunnel)
ga-enweta `403` tupu nchọgharị credential ọ bụla ma ọ bụ mmalite process emee. Lee
`src/server/authz/policies/management.ts` maka otu iwu ahụ etinyere na akụkụ `LOCAL_ONLY`
ndị ọzọ.

## Ọnụ ụzọ concurrency dị n'ọkwa modulu (mmachi nke otu instance)

A na-amanye `CURSOR_IMG_MAX_CONCURRENT` site na counter/queue dị na ebe nchekwa nke
instance modulu Node (`open-sse/handlers/imageGeneration/providers/cursorAgentImage.ts`).
Ọ na-amachi mmalite `agent` ndị na-eme n'otu oge nke ọma n'ime otu process OmniRoute, mana
ọ **naghị** ahazi n'etiti ọtụtụ process/instance na-ekekọrịta otu seat Cursor ahụ
(dịka ọmụmaatụ, deployment nwere ọtụtụ replica) — instance ọ bụla na-amanye mmachi nke ya
n'adabereghị na ndị ọzọ. Maka deployment nwere otu instance (nke bụ ndabara), nke a ziri ezi;
deployment ndị a gbasapụrụ n'ụzọ kwụ ọtọ kwesịrị idobe `CURSOR_IMG_MAX_CONCURRENT` n'ogo dị
ala nke ọma maka instance ọ bụla, ma ọ bụ ziga okporoụzọ onyonyo Cursor niile n'otu instance.

## Ihe ndị achọrọ

1. Akaụntụ Cursor ejikọrọ na dashboard (OAuth ma ọ bụ API key `crsr_…`).
2. Binary Cursor Agent ga-adị maka process OmniRoute:
   - env `CURSOR_AGENT_BIN=/path/to/agent`, ma ọ bụ
   - `~/.local/bin/agent`, ma ọ bụ
   - `providerSpecificData.agentBin` na njikọ Cursor.

Nhazi ndị ọzọ a na-ahọrọ:

| Env                         | Ndabara                 | Ihe ọ pụtara                                 |
| --------------------------- | ----------------------- | -------------------------------------------- |
| `CURSOR_IMG_TIMEOUT_MS`     | `210000`                | Oge elekere mgbidi maka onyonyo ọ bụla       |
| `CURSOR_IMG_MAX_CONCURRENT` | `2`                     | Ọnụ ụzọ concurrency maka seat a na-ekekọrịta |
| `CURSOR_IMG_MODEL`          | (ụdịdị arịrịọ / `auto`) | Dochie `--model` nke CLI                     |

## Ọmụmaatụ

```bash
curl -sS https://<host>/v1/images/generations \
  -H "Authorization: Bearer <omni-api-key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"cursor/auto","prompt":"a lantern in fog","size":"1024x1024"}'
```

Mmepụta na-ewekarị nkeji 1–2. Họrọ ụzọ netwọk ime; edge proxy nwere timeout dị ihe dị ka sekọnd 100 ga-ada.
