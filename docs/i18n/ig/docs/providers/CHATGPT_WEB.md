`chatgpt-web-codex` (aha ọzọ ya bụ `cgpt-codex`) na-ejikọta ntụgharị Codex Responses site na
nnọkọ ihe nchọgharị ChatGPT e nyochara njirimara ya. Ọ dị iche na common provider
`chatgpt-web` nke a kwụsịrịla, ma na-eji mmejuputa nwere ọkwa MIT dị n'okpuru
`open-sse/vendor/codex-chatgpt-web/`, nke e melitere site na commit upstream v4.0.7
`b59d7dc51b84fb1f465ff1d00f5207f3b2b4a494`.

## Nkwụsị common provider

A naghịzi ebunye ID common provider ochie ndị bụ `chatgpt-web` na `cgpt-web` n'ihi na
enweghị ike ikwenye ebe mmejuputa pre-key/proof-of-work ha siri pụta. Arịrịọ doro anya
ọ bụla e zigara nke ọ bụla n'ime ID ndị ahụ, gụnyere ID model nwere slash n'ihu na alias
e chekwara, na-ada ozugbo n'ụzọ nchekwa site na HTTP `410` na koodu **PROVIDER_RETIRED**
tupu e ziga arịrịọ upstream ọ bụla.

Migration `168_retire_chatgpt_web.sql` na-akara njikọ provider ndị dabara adaba dịka ndị
a kwụsịrị ma kagbuo lease nnọkọ ha ndị ka na-arụ ọrụ. Ọ na-echekwa akụkọ njikọ na
allowlist API-key; ọ naghị etinye ohere nnọchi n'allowlist. Nkwụsị a anaghị emetụta
Codex provider na njikọ ya.

## Ihe ndị achọrọ tupu amalite

- header Cookie zuru ezu sitere na nnọkọ ChatGPT nke abanyelarị;
- Chrome ma ọ bụ Chromium tinyere nnọkọ eserese ma ọ bụ ngosi Xvfb maka nrụnye npm, systemd, na PM2;
- mgbe a na-eji profaịlụ Docker `web`, ọrụ Chromium nke ime sitere na
  `docker-compose.yml`;
- OpenAI `tunnel-client` v0.0.13 na custom connector ChatGPT maka ngwa Codex mpaghara.

A chọrọ tunnel naanị maka ntụgharị ndị na-eji ngwa. Route ọ bụla edepụtara, gụnyere `pro`, nwere ike iji
otu ikike ngwa mpaghara ahụ e kegidere na ntụgharị mgbe a haziri tunnel na connector.

## Model na combo

Route model ndị a kapịrị ọnụ bụ:

- `chatgpt-web-codex/luna` — GPT-5.6 Luna, mgbalị dị ala
- `chatgpt-web-codex/think` — GPT-5.6 Luna, mgbalị etiti
- `chatgpt-web-codex/instant`
- `chatgpt-web-codex/medium`
- `chatgpt-web-codex/high`
- `chatgpt-web-codex/extra-high`
- `chatgpt-web-codex/pro`

Tinye otu n'ime ha na combo dịka model ọ bụla ọzọ. Ngwa Codex na-eziga aha combo ahụ dịka
`model` gaa na endpoint Responses nkịtị, `/v1/responses`; enweghị endpoint Codex
dị iche ma ọ bụ mgba ọkụ mode.

Akaụntụ Free/Go na-eme ka route Luna dị. Akaụntụ nwere ikike Sol na-eme ka Instant ruo
High dị, ebe akaụntụ nwere ikike Pro na-emekwa ka Extra High na Pro dị. Route ọ bụla nwere
model backend na reasoning effort a kapịrị ọnụ; Responses effort e kwuru hoo haa nke na-emegide ya
ga-ada ozugbo n'ụzọ nchekwa kama ịgbanwe mode ihe nchọgharị ahọpụtara na nzuzo.

Agbanwela aha ma ọ bụ jiri connector ochie `Codex Native` ma ọ bụ `OmniRoute Codex` ọzọ. ChatGPT
na-echekwa contract MCP ọha na cache dabere na njirimara connector, ebe bridge e melitere na-eji
contract turn-token ọhụrụ kpọmkwem. Runtime na-ajụ njirimara ochie ndị ahụ ma chọọ
connector ọhụrụ `OmniRoute Codex v2`.

## Ụdị nchekwa

- Ụzọ native chọrọ arịrịọ Responses, ahịa Codex a maara, yana njirimara thread na turn kwekọrọ.
- Workspace, sandbox, iwu nkwado, na katalọgụ ngwaọrụ na-esite na shell native nke Codex; ederede prompt a na-ede n’ụdị nnwere onwe enweghị ikike ịchịkwa ha.
- ChatGPT na-enweta naanị ikike dị mkpụmkpụ maka turn ọ bụla. Onye ogbugbo MCP na-anabata naanị ngwaọrụ Codex nyere n’otu turn ahụ kpọmkwem.
- Ịkwado **Allow once** na-akpaghị aka na-eweghachiri Codex arịrịọ ngwaọrụ ahụ naanị. Ọ bụ naanị Codex na-ekpebi nkwado na mmezu.
- Tupu mmepụta mbụ, combo nwere ike ịlaghachi na target ọzọ dakọtara. Mgbe mmepụta malitere, provider, model, connection, na browser turn ga-anọgide n’otu ọnọdụ ruo mgbe turn ahụ gwụsịrị.
- Cookies, runtime keys, storage state, na capability tokens anaghị apụta na nzaghachi provider ma ọ bụ ndekọ arịrịọ.

## VPS na-enweghị ihuenyo na Docker

Maka nrụnye npm, systemd, na PM2, OmniRoute na-achọpụta ụzọ Chrome na Chromium ndị a na-ahụkarị.
N’ụzọ ọzọ, tọọ `CHATGPT_WEB_CODEX_CHROME_PATH`. Runtime turns na-eji Chrome nwere interface n’ụma
n’ihi na ChatGPT na-ajụ nhazi browser nke bụ true-headless. Ya mere, host na-enweghị ihuenyo ga-eji
private Xvfb display mee ka OmniRoute rụọ ọrụ; naanị ịtọ ụzọ Chrome anaghị enye display.

Profaịlụ Docker `web` na-amalite `chatgpt-web-codex-browser` na netwọkụ Compose dị n’ime.
Sidecar ahụ na-eme Chrome nwere interface ka ọ rụọ ọrụ n’ime Xvfb, ya mere, a chọghị ihuenyo anụ ahụ. A naghị
ebipụta port CDP ya na host. Volume profaịlụ browser e chebere dị iche na
volume data OmniRoute, browser ahụ na-enwetakwa shared memory zuru ezu. Proxy CDP dị n’ime
na-ege ntị naanị na port `9223` n’ime netwọkụ Compose; Chrome ka na-ejikọta naanị na loopback n’ime
sidecar.

Supervisor lease dị n’okpuru `DATA_DIR` na-egbochi ọtụtụ process OmniRoute inwe
otu tunnel na broker state. Doctor na-akọ esemokwu ọ bụla.

## Mgbake mmekọrịta

Ụzọ Docker akpaghị aka enweghị windo host nwere ike ịhụ, mana Chrome n’onwe ya nwere interface n’ime
private Xvfb display. Mgbe ChatGPT chọrọ nbanye mmekọrịta ma ọ bụ challenge, enwere ike iji akụrụngwa
browser VNC dị adị maka mgbake. Browser UI na CDP ga-anọgide na-enweta naanị
site na loopback, njikọ njikwa nwere nkwenye njirimara, ma ọ bụ SSH tunnel; noVNC ga-anọgide bụrụ nke agbanyụrụ
n’oge ọrụ nkịtị.

## WebSocket fallback

Mgbe combo nwere ChatGPT Web (Codex), bridge Responses WebSocket na-arịọ
HTTP/SSE fallback tupu ọ jikọọ na upstream. Mgbe ahụ, mbufe ahụ na-aga site na
`/v1/responses`.
