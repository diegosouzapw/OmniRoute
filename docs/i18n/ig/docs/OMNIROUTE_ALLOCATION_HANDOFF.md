Nkesa abụghị oke ojiji nke onye na-eweta ọrụ.

Otu ọdọ oke ojiji na-akọwa igodo API ndị nwere ike iji ọdọ nke onye na-eweta ọrụ, yana otu iwu siri ike, dị nro, ma ọ bụ nke mmụba mberede si arụ ọrụ. Oke ojiji nke onye na-eweta ọrụ bụ ikike mpụga nke onye na-eweta ọrụ kọrọ ma ọ bụ nke isi mmalite ahaziri kpọmkwem nyere. Mmefu ego ime Ghostlight bụ oke nchịkwa nke onye nchịkwa kọwara.

Ọrụ `ensurePool` bụ idempotent: ọdọ yiri nke dị adị anaghị agbanwe, a na-emelite nkesa gbanwere agbanwe, a na-emepụtakwa ọdọ na-adịghị adị. Ezubere nke a maka akpaaka na ndị na-akpọ API nwere oke.

Ebe njedebe ọkwa a na-agụ naanị bụ `GET /api/omniroute/status`. Iwu nkwenye bụ `npm run omniroute:verify`; ọ naghị eziga arịrịọ ọ bụla ozugbo na model.
