Mkpokọta RTK bụ injin mkpokọta OmniRoute nke maara iwu, maka nsonaazụ terminal na ngwaọrụ. E
mepụtara ya maka nnọkọ coding-agent ebe ọtụtụ uto context si na ndekọ ule, nsonaazụ build,
mkpọtụ package manager, transcript shell, nsonaazụ Docker, nsonaazụ git, na stack trace.

RTK nwere ike iji `defaultMode: "rtk"` rụọ ọrụ ozugbo ma ọ bụ bụrụ nzọụkwụ mbụ na pipeline e jikọtara ọnụ, nke na-abụkarị:

```txt
rtk -> caveman
```

Usoro ahụ na-ebu ụzọ chịkọta nsonaazụ igwe nwere mkpọtụ, wee kwe ka Caveman chịkọta prose fọdụrụ.

RTK upstream na-akọ na a na-echekwa `60-90%` nke nsonaazụ iwu. Nnọkọ atụ dị na README ya si na
token ọkọlọtọ `~118,000` gbadaa na token RTK `~23,900`, nke pụtara na echekwara `79.7%` (`~80%`). OmniRoute na-eji
nkezi upstream ahụ maka mgbakọ ego echekwara site na nchịkọta e jikọtara ọnụ ya na mkpokọta input Caveman:

```txt
Nkezi RTK:      echekwara 80%
Input Caveman:  echekwara 46%
Ejikọtara ọnụ: 1 - (1 - 0.80) * (1 - 0.46) = echekwara 89.2%
Oke:           1 - (1 - 0.60..0.90) * (1 - 0.46) = 78.4-94.6%
```

## Mkpebi Filter

RTK na-ebunye filter n'usoro a:

1. Filter project sitere na `.rtk/filters.toml` na `.rtk/filters.json`, naanị mgbe a tụkwasịrị ha obi.
2. Filter global sitere na `DATA_DIR/rtk/filters.toml` na `DATA_DIR/rtk/filters.json`.
3. Filter e wuru n'ime ya sitere na `open-sse/services/compression/engines/rtk/filters/`.

N'ime scope otu, filter RTK TOML schema v1 na-ebute filter OmniRoute JSON ụzọ. A na-enyocha expression TOML
`match_command` tupu command-type matching ka filter a bubatara nke metụtara otu iwu kpọmkwem nwee ike dochie
filter sara mbara n'ime scope ahụ. Scope project ka na-ebute scope global ụzọ,
n'agbanyeghị format faịlụ.

A na-ama ụma achọ ntụkwasị obi maka filter project n'ihi na filter regex nwere ike ịgbanwe otu esi
egosi agent nsonaazụ ngwaọrụ. A na-anabata faịlụ filter project mgbe otu n'ime ihe ndị a bụ eziokwu:

- `rtkConfig.trustProjectFilters` bụ `true`.
- Etinyere `OMNIROUTE_RTK_TRUST_PROJECT_FILTERS=1`.
- `.rtk/trust.json` nwere hash SHA-256 kwekọrọ na faịlụ filter project ahụ.

Ihe atụ faịlụ ntụkwasị obi:

```json
{
  "filtersSha256": "0123456789abcdef...",
  "filtersTomlSha256": "fedcba9876543210..."
}
```

Hash ndị ahụ dị iche: `filtersSha256` tụkwasịrị `.rtk/filters.json` obi, ebe `filtersTomlSha256`
tụkwasịrị `.rtk/filters.toml` obi. Idezi nke ọ bụla n'ime faịlụ ndị ahụ na-eme ka naanị ntinye ntụkwasị obi nke ya ghara ịdị irè. Faịlụ global
bụ ndị administrator wụnyere ma na-eji omume ntụkwasị obi filter global dịbu adị.

Filter omenala nwere ike ịbụ otu object filter ma ọ bụ array nke object filter. A na-amafere filter omenala na-adịghị irè
ma `/api/context/rtk/filters` diagnostics na-akọ ha. Filter e wuru n'ime ya na-adịghị irè na-eme ka usoro ahụ daa ozugbo.

## Ndakọrịta RTK TOML schema v1

OmniRoute nwere ike ịgụ, nyochaa, nwalee, ma wụnye faịlụ nzacha ndị e kọwara n'ụzọ nkwupụta site na iji RTK TOML schema v1.
Ubi ndị a na-akwado bụ `description`, `match_command`, `strip_ansi`, `filter_stderr`,
`strip_lines_matching`, `keep_lines_matching`, `replace`, `match_output`, `truncate_lines_at`,
`head_lines`, `tail_lines`, `max_lines`, `on_empty`, na nnwale inline `[[tests.<filter>]]`.
A na-ajụ ubi ndị a na-amaghị, regular expressions ndị na-ezighi ezi ma ọ bụ na-adịghị nchebe, iwu strip/keep ndị e tinyere n'otu oge, faịlụ karịrị
1 MiB, na ntụaka na nzacha ndị a na-amaghị. Enwere ike inyocha faịlụ nke nnwale inline ya dara maka nyocha, mana enweghị ike
ịwụnye ma ọ bụ budata ya. Ọdịda n'ịbudata faịlụ omenala ka na-eji usoro
fail-open: a na-amafe faịlụ na-ezighi ezi, ebe nzacha ndị ọzọ na-aga n'ihu na-arụ ọrụ.

OmniRoute na-anata nsonaazụ ngwá ọrụ mgbe client ahụ nwụcharala ya, ya mere `filter_stderr = true`
enweghị ike ịgbanwe otu e si ejide process ahụ. A na-anabata ubi ahụ dị ka no-op, nyocha nkwado ahụ na-ewepụtakwa ịdọ aka ná ntị.
A na-akọwa nke a ụma dị ka **ndakọrịta RTK TOML schema v1**, ọ bụghị ndakọrịta zuru oke
na RTK executable, shell hooks, mmejuputa iwu Rust, ma ọ bụ nhazi trust-store ya.

Nlele RTK dị elu nke dashboard na-anabata TOML e mado ma ọ bụ e bulite. Nnyocha nkwado bụ naanị maka ịgụ.
Nwụnye na-ede `DATA_DIR/rtk/filters.toml` n'ụzọ atomic yana ikikere siri ike ma na-eme ka
katalọgụ nzacha dị ndụ dị ọhụrụ na-enweghị restart. Iji dochie faịlụ dị adị chọrọ nkwenye `overwrite`
doro anya ma buru ụzọ mepụta `DATA_DIR/rtk/filters.toml.bak`.

## DSL nzacha

Nzacha na-eji JSON schema a kọwara na [Ụdị Iwu Mkpakọ](./COMPRESSION_RULES_FORMAT.md).
Runtime na-etinye usoro ndị a n'usoro:

```txt
stripAnsi -> filterStderr -> replace -> matchOutput -> tụfuo/tinye ahịrị
  -> truncateLineAt -> head/tail/maxLines -> onEmpty
```

Ubi ndị dị mkpa:

| Ubi                          | Ebumnuche                                                           |
| ---------------------------- | ------------------------------------------------------------------- |
| `rules.stripAnsi`            | Wepụ usoro agba/njikwa terminal tupu matching                       |
| `rules.filterStderr`         | Hazie prefixes stderr ndị a na-ahụkarị tupu matching/filtering      |
| `rules.replace`              | Tinye nnọchi regex n'usoro                                          |
| `rules.matchOutput`          | Weghachite nchịkọta mkpirikpi mgbe nsonaazụ dabara na ọnọdụ a maara |
| `rules.matchOutput[].unless` | Mafere ụzọ mkpirisi ahụ mgbe ụkpụrụ njehie/ọdịda dị                 |
| `rules.dropPatterns`         | Wepụ ahịrị ndị na-eme mkpọtụ                                        |
| `rules.includePatterns`      | Nye ahịrị ndị a pụrụ ime ihe na ha mkpa                             |
| `rules.collapsePatterns`     | Kpokọta ahịrị ndị na-emegharị ugboro ugboro ma kwekọọ               |
| `rules.deduplicate`          | Opt-in maka nzacha ọ bụla: kpokọta ahịrị oyiri ndị na-esochi ibe ha |
| `rules.truncateLineAt`       | Mbepụ ahịrị ọ bụla nke na-echekwa Unicode                           |
| `rules.onEmpty`              | Ozi ndabere ma ọ bụrụ na e wepụ ahịrị niile                         |
| `tests[]`                    | Ihe nlele inline nke verify gate na-eji                             |

A na-atụ anya na nzacha arụnyere n'ime ga-agụnye ihe nlele inline `tests[]`. Nzacha omenala kwesịkwara ịgụnye
ha, karịsịa mgbe a na-ekekọrịta ha n'etiti projects.

## Iwepụ Ahịrị Ndị Megharịrị Emegharị (ọkwa abụọ)

RTK na-ejikọta ahịrị ndị megharịrị emegharị n'ọkwa abụọ na-adabereghị onwe ha:

1. **`deduplicate` nke nzacha ọ bụla (a ga-ahọrọ itinye ya n'ọrụ, ndabara bụ `false`).** Nzacha nwere ike ịtọ `rules.deduplicate: true`
   iji jikọta ahịrị ndị megharịrị emegharị nke na-esochi onwe ha _n'ime nsonaazụ dabara na nzacha ahụ_, tupu ebipụ ya.
   Nke a na-arụ ọrụ n'ime `lineFilter.ts`. Maka nzacha ochie, a na-eme ka ọ rụọ ọrụ na-akpaghị aka mgbe nzacha ahụ kọwara
   `collapsePatterns`. Schema: `deduplicate: z.boolean().default(false)` n'ime
   `open-sse/services/compression/engines/rtk/filterSchema.ts`.
2. **`deduplicateThreshold` nke injin niile (ndabara bụ `3`).** Mgbe nzacha niile rụchara ọrụ, injin ahụ na-ejikọta
   usoro ọ bụla nwere `>= deduplicateThreshold` ahịrị yiri onwe ha kpamkpam nke na-esochi onwe ha n'ime nsonaazụ niile
   (`deduplicateRepeatedLines`, nke etinyere n'ọrụ na `engines/rtk/index.ts`). A na-amachi uru ahụ n'etiti 2–100 mgbe
   a na-eme nhazi ya ka ọ bụrụ otu ụkpụrụ.

Usoro nke nzacha ọ bụla na-ebu ụzọ rụọ ọrụ (n'ime nzacha ahụ), usoro nke injin niile na-arụ ọrụ n'ikpeazụ (n'elu
nsonaazụ ejikọtara ọnụ), ya mere ha abụọ na-arụkọ ọrụ n'agụghị otu ihe ugboro abụọ.

## Ịchịkọta Ahịrị (`enableGrouping`)

Mgbe `rtkConfig.enableGrouping` bụ `true` (ndabara bụ `false`), RTK na-agba usoro `groupSimilarLines`
ọzọ n'elu nsonaazụ e wepụcharala ihe ndị megharịrị emegharị, nke na-ejikọta usoro ahịrị ndị _fọrọ nke nta ka ha bụrụ otu_ (ọ bụghị ndị yiri onwe ha n'otu byte n'otu byte)
ma na-esochi onwe ha. `rtkConfig.groupingThreshold` (ndabara bụ `3`) bụ ogologo usoro kacha nta nke na-akpalite
ịchịkọta. Nke a bụ ogbo nhazi nke kwekọrọ na `deduplicateThreshold`: dedup na-ahụ maka nkwughachi ndị yiri onwe ha kpamkpam,
ịchịkọta na-ahụ maka "otu nhazi ahụ nwere obere ọdịiche". Ọkọlọtọ abụọ ahụ bụ akụkụ nke JSON `rtkConfig`
echekwara n'ime tebụl `key_value` (lee Nhazi dị n'elu), ya mere ntọala ahụ na-adịgide mgbe ebidogharịrị sistemụ.

## Iwepụ Nkwupụta Koodu (`stripCodeComments` / `preserveDocstrings`)

Mgbe agbanyere `rtkConfig.applyToCodeBlocks`, RTK nwekwara ike iwepụ nkwupụta n'ime ngọngọ koodu ndị e ji fence kaa ókè:

- `stripCodeComments` (ndabara bụ `false`) — a ga-ahọrọ itinye ya n'ọrụ. Mgbe ọ bụ `true`, RTK na-ewepụ nkwupụta n'ime ngọngọ JavaScript
  na TypeScript ndị e ji fence kaa ókè. N'akụkọ ihe mere eme, a na-agụ ọkọlọtọ ahụ mana anaghị etinye ya n'ọrụ, ya mere ndabara ahụ ka bụ
  "chekwaa" iji zere mgbanwe mmepụta nke mere na-enweghị ọkwa.
- `preserveDocstrings` (ndabara bụ `true`) — mgbe a na-ewepụ nkwupụta, a na-edobe nkwupụta ngọngọ JSDoc/`/** … */`
  (ha nwere akwụkwọ API bara uru karịa bytes ha na-eri). Tọọ ya ka ọ bụrụ `false` iji wepụkwa
  ha.

E tinyere iwepụ nkwupụta n'ọrụ n'ime `open-sse/services/compression/engines/rtk/codeStripper.ts`. Ọ na-eji
**parser TypeScript** (ọ bụghị regex) ka e wee ghara iwere string, template, na regex literals
dị ka nkwupụta n'amaghị ama, ọ na-akwụsịkwa usoro ahụ kpamkpam mgbe achọpụtara JSX (ka a ghara
imebi nkwupụta dị n'ime expression-container nke JSX). Ka ọ dị ugbu a, iwepụ nkwupụta na-emetụta naanị **JavaScript na TypeScript** — asụsụ
ndị ọzọ dị na setị `CodeLanguage` nke stripper (Python, Rust, Go, Ruby, Java) nwere mkpakọ ahịrị efu na
oghere ọcha, mana ha enweghị iwepụ nkwupụta. A na-enye usoro ngọngọ e wepụchara akara `rtk:code-strip` n'ime
`rulesApplied`.

> **Mara — GCF / encoding tebụl bụ injin dị iche.** RTK enweghị **"GCF"**
> (Graph Compact Format) encoder JSON nke tebụl/kọlụm. Encoder ahụ — nke nọchiri encoder ochie
> `omni-tabular` — dị n'ime injin **headroom**
> (`open-sse/services/compression/engines/headroom/`, ebe codec e tinyere n'ime ngwugwu dị n'okpuru
> `headroom/gcf/`). O nweghị njikọ na pipeline nzacha RTK akọwara ebe a.

## Nhazi

Ntọala zuru ụwa ọnụ dị site na `/api/settings/compression`. Ntọala ndị metụtara RTK dịkwa
site na `/api/context/rtk/config`.

```json
{
  "defaultMode": "stacked",
  "autoTriggerMode": "stacked",
  "autoTriggerTokens": 32000,
  "stackedPipeline": [
    { "engine": "rtk", "intensity": "standard" },
    { "engine": "caveman", "intensity": "full" }
  ],
  "rtkConfig": {
    "enabled": true,
    "intensity": "standard",
    "applyToToolResults": true,
    "applyToCodeBlocks": false,
    "applyToAssistantMessages": false,
    "enabledFilters": [],
    "disabledFilters": [],
    "maxLinesPerResult": 120,
    "maxCharsPerResult": 12000,
    "deduplicateThreshold": 3,
    "customFiltersEnabled": true,
    "trustProjectFilters": false,
    "rawOutputRetention": "never",
    "rawOutputMaxBytes": 1048576,
    "enableGrouping": false,
    "groupingThreshold": 3,
    "stripCodeComments": false,
    "preserveDocstrings": true
  }
}
```

`enabledFilters` na `disabledFilters` na-eji NJ ndị nzacha, dịka ọmụmaatụ `test-vitest` ma ọ bụ `git-diff`.

A kọwara ọdịdị `rtkConfig` zuru ezu site na `RtkConfig` / `DEFAULT_RTK_CONFIG` n'ime
`open-sse/services/compression/types.ts`. A na-echekwa ihe ahụ niile dịka otu uru JSON n'ime
tebụl SQLite `key_value` n'okpuru `namespace = "compression"`, `key = "rtkConfig"`
(`src/lib/db/compression.ts`), `normalizeRtkConfig` na-ahazikwa ya mgbe a na-agụ ya. Ya mere, mpaghara ọ bụla dị n'okpuru
— gụnyere `enableGrouping`, `groupingThreshold`, `stripCodeComments`, na `preserveDocstrings` —
na-agafe otu ebe nchekwa ahụ ma na-adịgide mgbe ebidogharịrị sistemụ.

RTK na-akwado **ọkwa ike 3** nke na-eme mgbanwe n'etiti **ike compression** na **nchekwa**. A na-edobe ọkwa ahụ site na `config.intensity` n'ime config nke engine.

### Ọkwa 3 Ahụ

| Ọkwa                 | Oke truncation       | Nchekwa token | Ihe ize ndụ | Nke kacha mma maka                   |
| -------------------- | -------------------- | ------------- | ----------- | ------------------------------------ |
| `minimal`            | Ahịrị 24 kwa ngalaba | ~20-40%       | Dị nnọọ ala | Production nwere context dị oke mkpa |
| `standard` (ndabara) | Ahịrị 24 kwa ngalaba | ~50-70%       | Ala         | Oge coding kwa ụbọchị                |
| `aggressive`         | Ahịrị 16 kwa ngalaba | ~70-90%       | Etiti       | Oge ogologo, nchekwa kachasị ukwuu   |

### Ebe Truncation Na-eme

Oke truncation na-emetụta `lineFilter.ts`:

```ts
// Site na open-sse/services/compression/engines/rtk/index.ts:329-330

config.intensity === "aggressive" ? 16 : 24,
```

A na-edobe ma **isi** ma **ọdụ** nke ngalaba ọ bụla; a na-ewepụ ọdịnaya dị n'etiti mgbe truncation malitere.

A na-enyocha nzacha megide schema Zod mgbe a na-ebunye ha. Nzacha nwere nhazi na-adịghị mma agaghị ebunye, ọ ga-edekwa njehie:

### Omume Kachasị Mma

1. **Na-etinye `tests[]` mgbe niile** — ha na-egosi na nzacha gị na-arụ ọrụ ma na-egbochi nlọghachi nke mmejọ
2. **Jiri `matchOutput` maka nkwụsị ngwa ngwa** — ọ bụrụ na otu ahịrị na-akọwa ihe niile, jiri ya dochie ngọngọ ahụ dum

4. **Nwalee n'ọkwa ike atọ niile** — `minimal` ekwesịghị ime mgbanwe ọ bụla, ebe `aggressive` ka kwesịrị ichekwa njehie
5. **Jiri mpaghara `unless`** — jiri “akpalitela ma ọ bụrụ na X dị” chekwaa nkwụsị ngwa ngwa

### Ọnụ Ụzọ Nkwenye

**Nkwenye Nzacha RTK** (`open-sse/services/compression/engines/rtk/verify.ts`) na-enyocha nzacha niile site na `tests[]` ha ma hụ na omume ha ziri ezi n'ọkwa ike 3 niile.

**Kpọọ `runRtkFilterTests()`** iji mee nkwenye:

```ts

const result = runRtkFilterTests();
console.log(`Passed: ${result.outcomes.filter((o) => o.passed).length}`);
console.log(`Failed: ${result.outcomes.filter((o) => !o.passed).length}`);
if (!result.passed) {
  console.error("Filters failed verification");
  result.outcomes
    .filter((o) => !o.passed)
    .forEach((o) => {
      console.error(
        `  - ${o.filterId} / ${o.testName}: expected "${o.expected}", got "${o.actual}"`
      );
    });
}
```

**Ihe ọ na-enyocha**:

1. Nzacha ọ bụla na-eburu nke ọma ma gafee nkwenye schema
2. Ndenye ọ bụla dị na `tests[]` na-emepụta mmepụta a tụrụ anya ya
3. Ọkwa ike `minimal` anaghị eme mgbanwe ọ bụla (ọ na-edobe nke izizi, ma na-etinye naanị nzacha nhazi)
4. Ọkwa ike `aggressive` na-edobe njehie, ọdịda ule, na stack traces
