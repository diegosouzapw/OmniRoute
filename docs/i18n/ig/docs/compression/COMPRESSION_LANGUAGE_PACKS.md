Mkpakọ Caveman nwere ike ibunye ngwugwu iwu ndị akọwapụtara maka asụsụ dị iche iche na mgbakwunye na iwu Bekee ndị e wuru n’ime ya.
Nke a na-eme ka injin bụ isi kwụsie ike ma na-enye ohere ka ngwugwu asụsụ Portuguese, Spanish, German, French, Italian, Japanese, na
ngwugwu asụsụ ndị ọzọ n’ọdịnihu nwee ike ịga n’ihu iche iche.

## Ebe

Ngwugwu asụsụ dị n’okpuru:

```txt
open-sse/services/compression/rules/<language>/
```

Ngwugwu ndị a na-ebunye ugbu a (enyochala ha megide ọdịnaya ndekọ `rules/`):

| Asụsụ               | Ndekọ          | Ụdị iwu ndị dị                                      |
| ------------------- | -------------- | --------------------------------------------------- |
| Bekee               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spanish             | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portuguese (Brazil) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonesian          | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italian             | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| German              | `rules/de/`    | `context`, `filler`, `structural`                   |
| French              | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japanese            | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Ndetu gbasara nha nhata:** Ngwugwu `en`, `es`, `pt-BR`, `id`, na `it` nwere ụdị ise niile; `de`, `fr`, `ja` na-ebunye ụdị atọ. Ụdị `dedup` na `ultra` ndị na-adịghị na ha na-eji iwu Bekee ndị e wuru n’ime ya na-akpaghị aka n’emeghị mkpọtụ. A na-anabata onyinye iji tinye `dedup.json` na `ultra.json` maka ngwugwu ndị pere mpe.
>
> Ngwugwu `pt-BR` dabeere na **[Troglodita](https://github.com/leninejunior/troglodita)** nke Lenine Júnior mepụtara — usoro mkpakọ e si na ntọala kee maka ụtọasụsụ Portuguese nke Brazil (ibelata pleonasm, iwepụ okwu ndochi PT-BR, na ndebiri teknụzụ maka obodo ndị nrụpụta sọftụwia BR).
>
> Ndepụta ụdị iwu izizi na schema nke ụdị ọ bụla dị na [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12).

## Nchọpụta Asụsụ

`languageDetector.ts` na-eji ụzọ ntule dị mfe chọpụta asụsụ site n’ederede prompt. A ka na-asọpụrụ
asụsụ ndabara ahaziri, a pụkwara gbanyụọ nchọpụta site na config mgbe achọrọ njikwa
kpọmkwem.

A na-eji nsonaazụ nchọpụta naanị ahọrọ ngwugwu iwu. Ọ naghị agbanwe ntụgharị onye na-eweta ọrụ, nhọrọ
locale, ma ọ bụ asụsụ UI.

## Ọdịdị Config

Ntọala mkpakọ nwere ike ịgụnye:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` na-achịkwa ndabara dashboard/preview. `cavemanConfig` bụ config injin runtime
a na-eji mgbe Caveman na-akpakọ ederede ozi.

## Ịgbakwunye Ngwugwu Asụsụ

1. Mepụta `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Jiri usoro iwu Caveman dị na `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Mee ka nnọchi bụrụ nke akpachapụ anya ma zere ịgbanwe koodu, ihe njirimara, URL, ma ọ bụ JSON.
4. Tinye ma ọ bụ melite ule maka nhọpụta asụsụ na omume nnọchi.
5. Gosipụta akara dashboard/i18n ọhụrụ ma ọ bụrụ na asụsụ ahụ pụtara na ihe nhọpụta UI.

## API

Enwere ike iji nke a jụọ maka ngwugwu ndị dị:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Endpoint nlele mbụ na-anabata mgbanwe nhazi asụsụ:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Ngwugwu asụsụ isii niile natara nkebi ahịrịokwu `SHARED_BOUNDARIES` na v3.8.0, nke a na-etinye n'ogo ike Caveman ọ bụla (LITE, FULL, ULTRA). Ọ na-agwa engine ka ọ chekwaa ụkpụrụ ndị a kpọmkwem dịka ha dị, n'agbanyeghị iwepụ okwu ndochi ndị gbara ha gburugburu:

| Ụdị ụkpụrụ                      | Ọmụmaatụ                               |
| ------------------------------- | -------------------------------------- |
| Blọk koodu nwere ogige          | ` ```python\n...\n``` `                |
| Koodu dị n'ime ahịrị            | `` `my_var` ``                         |
| URL                             | `https://example.com/path`             |
| Ụzọ faịlụ (zuru oke + metụtara) | `/etc/hosts`, `./src/index.ts`         |
| Isiokwu njehie                  | `Error:`, `TypeError:`, `SyntaxError:` |
| Ahịrị stack trace               | `  at functionName (file.ts:12:3)`     |

A na-etinye ụkpụrụ ndị a na `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (nke bụbu `[]`). Constant ahụ dị na `open-sse/services/compression/types.ts`.

### Ihe mere nke a ji dị mkpa

Na-enweghị SHARED_BOUNDARIES, ụdị Caveman ndị na-arụ ọrụ ike nwere ike ihichapụ ọdịnaya yiri prose na-emegharị onwe ya, mana nke bụ n'ezie iberibe koodu, ụzọ faịlụ, ma ọ bụ stack njehie. SHARED_BOUNDARIES na-arụ ọrụ dịka nchekwa na-adabereghị n'asụsụ, nke a na-etinye tupu iwu iwepụ okwu ndochi amalite.

### Ịhazigharị preservePatterns

Enwere ike ịgbakwunye ụkpụrụ ndị ọzọ n'oge ngwanrọ na-arụ ọrụ site na ntọala mkpakọ:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Ụkpụrụ ahaziri iche na-agbatị ụkpụrụ ndabara isii ahụ (ha anaghị edochi ha).

## Ndetu Maka Ọrụ

- Iwu Bekee arụnyere n'ime sistemụ ka bụ nhọrọ ndabere mgbe ngwugwu asụsụ adịghị.
- Ngwugwu JSON arụnyere n'ime sistemụ ndị na-adịghị irè agaghị agafe nkwado, ka akụ mbipụta ghara ịdalata ogo na nzuzo.
- Ngwugwu iwu nwere naanị data, ha ekwesịghị ibubata koodu ma ọ bụ mee ka mgbagha aka ike rụọ ọrụ.
- Oyi akwa nyocha mkpakọ na-edekọ mode na engine ahọpụtara, ọ bụghị ederede prompt zuru ezu.
