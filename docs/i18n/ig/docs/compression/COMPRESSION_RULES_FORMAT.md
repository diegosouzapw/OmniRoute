Iwu mkpakọ bụ faịlụ JSON ndị a na-ebunye n'oge mmemme na-agba. E ji ụma mee ka ha bụrụ naanị data ka e nwee ike inyocha ngwugwu asụsụ ọhụrụ na nzacha iwu RTK n’agbanweghị koodu injin ahụ.

> **Skima iwu (isi iyi nke eziokwu):** [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12).
> Ihe atụ ndị dị n'okpuru bụ naanị maka nkọwa — mgbe ị na-ejighị n'aka, jiri `_schema.json` nyochaa ngwugwu gị.

## Ngwugwu Iwu Caveman

Ngwugwu iwu Caveman dị n'okpuru:

```txt
open-sse/services/compression/rules/<language>/<pack>.json
```

Ngwugwu ọ bụla nwere nnọchi ndị a na-etinye na ederede nkịtị mgbe e kewapụrụ mpaghara ndị e chebere.

```json
{
  "language": "en",
  "category": "filler",
  "rules": [
    {
      "name": "question_to_directive",
      "pattern": "\\b(?:Can you explain why|Could you show me how)\\b\\s*",
      "replacement": "Explain why ",
      "replacementMap": {
        "can you explain why": "Explain why ",
        "could you show me how": "Show how "
      },
      "flags": "gi",
      "context": "all",
      "category": "context",
      "minIntensity": "lite",
      "description": "Convert verbose questions into direct requests."
    }
  ]
}
```

### Ubi Ngwugwu Caveman

| Ubi                      | Achọrọ | Nkọwa                                                                            |
| ------------------------ | ------ | -------------------------------------------------------------------------------- |
| `language`               | ee     | Igodo asụsụ yiri BCP-47 dịka `en`, `pt-BR`, `es`                                 |
| `category`               | ee     | Aha faịlụ/ụdị nke ngwugwu, dịka ọmụmaatụ `filler` ma ọ bụ `dedup`                |
| `rules`                  | ee     | Ndepụta ahaziri nke iwu nnọchi regex                                             |
| `rules[].name`           | ee     | Aha iwu na-adịghị agbanwe agbanwe                                                |
| `rules[].pattern`        | ee     | Isi iyi regex JavaScript                                                         |
| `rules[].flags`          | mba    | Ọkọlọtọ regex JavaScript; ndabara bụ `gi`                                        |
| `rules[].replacement`    | mba    | Eriri nnọchi ma ọ bụ ihe ndabere mgbe `replacementMap` na-ahụghị nke dabara      |
| `rules[].replacementMap` | mba    | Nnọchi ndị akọwapụtara maka ndakọrịta, nke ederede ndakọrịta ahaziri bụ igodo ha |
| `rules[].context`        | mba    | `all`, `user`, `assistant`, ma ọ bụ `system`; ndabara bụ `all`                   |
| `rules[].category`       | mba    | `filler`, `context`, `structural`, `dedup`, `terse`, ma ọ bụ `ultra`             |
| `rules[].minIntensity`   | mba    | `lite`, `full`, ma ọ bụ `ultra`; ndabara bụ `lite`                               |
| `rules[].description`    | mba    | Nchịkọta iwu mmadụ nwere ike ịgụ                                                 |

Jiri `flags` mgbe ndakọrịta na-eleba anya na mkpụrụedemede ukwu na nke nta dị mkpa, dịka ọmụmaatụ iwepụ article tupu ederede mkpụrụedemede nta n’ewepụghị `the OpenAI API`. Jiri `replacementMap` mgbe otu regex nwere ọtụtụ nhọrọ ndị chọrọ nsonaazụ dị iche iche; nke a na-eme ka ngwugwu iwu JSON bụrụ naanị data ma na-echekwa omume nke ọrụ nnọchi TypeScript arụnyere n’ime sistemụ, ndị ka nwee ọtụtụ ikike.

## Ngwugwu Nzacha RTK

Nzacha RTK dị n'okpuru:

```txt
open-sse/services/compression/engines/rtk/filters/<filter>.json
```

Nzacha ọ bụla na-akọwa otu esi amata ma kpokọta ezinụlọ mmepụta-iwu.

```json
{
  "id": "test-vitest",
  "label": "Vitest output",
  "category": "test",
  "priority": 92,
  "match": {
    "outputTypes": ["test-vitest"],
    "commands": ["vitest", "npm test", "npm run test"],
    "patterns": ["\\bFAIL\\b", "\\bPASS\\b", "\\bTest Files\\b"]
  },
  "rules": {
    "stripAnsi": true,
    "replace": [{ "pattern": "\\s+\\[[0-9]+ms\\]", "replacement": "" }],
    "matchOutput": [
      {
        "pattern": "All tests passed",
        "message": "vitest: ok",
        "unless": "FAIL|Error:"
      }
    ],
    "includePatterns": ["FAIL", "Error:", "Test Files", "Tests"],
    "dropPatterns": ["^\\s*$", "Duration\\s+\\d+"],
    "collapsePatterns": ["^\\s+at "],
    "deduplicate": true,
    "truncateLineAt": 240,
    "maxLines": 160,
    "headLines": 24,
    "tailLines": 40,
    "onEmpty": "vitest: ok",
    "filterStderr": false
  },
  "preserve": {
    "errorPatterns": ["FAIL", "Error:", "AssertionError"],
    "summaryPatterns": ["Test Files", "Tests", "Snapshots"]
  },
  "tests": [
    {
      "name": "keeps failing tests",
      "command": "vitest",
      "input": "FAIL test/a.test.ts\\nError: boom\\nTest Files 1 failed",
      "expected": "FAIL test/a.test.ts\\nError: boom\\nTest Files 1 failed"
    }
  ]
}
```

### Ogige RTK

| Ogige                      | Achọrọ | Nkọwa                                                                           |
| -------------------------- | ------ | ------------------------------------------------------------------------------- |
| `id`                       | ee     | Id nzacha na-adịghị agbanwe agbanwe                                             |
| `label`                    | ee     | Aha dashboard nwere ike ịgụ                                                     |
| `category`                 | ee     | Ezinụlọ nzacha: git, test, build, shell, docker, package, infra, cloud, generic |
| `priority`                 | mba    | Nke nwere mkpa dị elu na-emeri mgbe ọtụtụ nzacha dakọtara                       |
| `match.outputTypes`        | mba    | Id mmepụta detector ndị na-ahọrọ nzacha a                                       |
| `match.commands`           | mba    | Token iwu ndị na-ahọrọ nzacha a                                                 |
| `match.patterns`           | mba    | Ụkpụrụ regex ndị na-ahọrọ nzacha a site na ederede mmepụta                      |
| `rules.stripAnsi`          | mba    | Wepụ usoro mgbapụ ANSI tupu usoro regex                                         |
| `rules.replace`            | mba    | Nnọchi regex ahaziri n'usoro nke a na-etinye n'ahịrị n'ahịrị                    |
| `rules.matchOutput`        | mba    | Iwu mmepụta na-akwụsị usoro ozugbo, nke nwere nche `unless` ma ọ bụrụ na achọrọ |
| `rules.includePatterns`    | mba    | Ahịrị ndị a ga-ahọrọ ichekwa karịa                                              |
| `rules.dropPatterns`       | mba    | Ahịrị ndị a ga-ewepụ dịka mkpọtụ                                                |
| `rules.collapsePatterns`   | mba    | Ahịrị dakọtara ugboro ugboro ndị enwere ike ijikọta                             |
| `rules.deduplicate`        | mba    | Jikọta ahịrị ndị ahazirila nke yiri ibe ha                                      |
| `rules.truncateLineAt`     | mba    | Oke mkpụrụedemede Unicode dị nchebe maka ahịrị ọ bụla                           |
| `rules.maxLines`           | mba    | Ọnụọgụ ahịrị kachasị elu a ga-edowe tupu ichekwa akụkụ ikpeazụ                  |
| `rules.headLines`          | mba    | Ahịrị mmalite ndị a na-edowe mgbe a na-ebipụ                                    |
| `rules.tailLines`          | mba    | Ahịrị ikpeazụ ndị a na-edowe maka ọnọdụ nso nso a                               |
| `rules.onEmpty`            | mba    | Ozi ndabere mgbe nzacha wepụrụ ọdịnaya niile                                    |
| `rules.filterStderr`       | mba    | Hazie prefix stderr ndị a na-ahụkarị tupu usoro nzacha ndị na-esote             |
| `preserve.errorPatterns`   | mba    | Ahịrị njehie ndị kwesịrị ịlanarị mbipụ                                          |
| `preserve.summaryPatterns` | mba    | Ahịrị nchịkọta ndị kwesịrị ịlanarị mbipụ                                        |
| `tests[]`                  | mba    | Ihe atụ nkwenye dị n'ime nke ọnụ ụzọ verify RTK na-eji                          |

RTK na-etinye usoro nkwupụta n'usoro a: `stripAnsi`, `filterStderr`, `replace`,
`matchOutput`, `dropPatterns`/`includePatterns`, `truncateLineAt`, `headLines`/`tailLines`,
`maxLines`, na `onEmpty`.

Enwere ike ibunye nzacha ahaziri iche site na:

1. Faịlụ `.rtk/filters.json` nke ọrụ ahụ naanị mgbe hash `.rtk/trust.json` dakọtara dị ma ọ bụ
   agbanyere `trustProjectFilters`.
2. `DATA_DIR/rtk/filters.json` zuru ụwa ọnụ.
3. Nzacha ndị arụnyere n'ime.

Faịlụ ahaziri iche nke ọrụ/zuru ụwa ọnụ nwere ike ịnwe otu ihe nzacha ma ọ bụ array nke ihe nzacha. A na-amafe
nzacha ahaziri iche na-adịghị mma ma nye nchọpụta; nzacha arụnyere n'ime na-adịghị mma na-eme ka nkwado daa.

Faịlụ ntụkwasị obi nke ọrụ:

```json
{
  "filtersSha256": "0123456789abcdef..."
}
```

Ndochi gburugburu `OMNIROUTE_RTK_TRUST_PROJECT_FILTERS=1` na-atụkwasị nzacha ọrụ obi na-enweghị
hash, a kwesịkwara ịmachi ya naanị na mmepe mpaghara a na-achịkwa.

## Iwu Nchedo

- Debe iwu ka ha bụrụ idempotent: ịgba otu filter ahụ ugboro abụọ ekwesịghị imebi nsonaazụ.
- Chekwaa ederede njehie kpọmkwem, ụzọ faịlụ, nọmba ahịrị, na nchịkọta iwu ebe o kwere mee.
- Zere iwu ndị na-agbanwe ngọngọ koodu, payload JSON, URL, ma ọ bụ ihe nzuzo.
- Tinye mkpuchi unit maka ezinụlọ iwu ọhụrụ n’ule detector/filter.
- Tinye ihe atụ `tests[]` na filter ọ bụla e wuru n'ime ya nakwa na filter omenala ndị a na-ekekọrịta.

## Nkwado izi ezi

A na-enyocha ngwugwu iwu tupu e jiri ha. Ngwugwu Caveman ndị e wuru n'ime ya na filter RTK ndị e wuru n'ime ya na-akwụsị ozugbo
mgbe nkwado izi ezi dara, ka e wee chọpụta akụrụngwa mbipụta ndị mebiri emebi tupu ezipụ ha. A na-amafe filter RTK omenala
ma nye ozi nchọpụta mgbe parsing ma ọ bụ nkwado ntụkwasị obi dara.

Nkwado izi ezi akọwapụtara:

```bash
node --import tsx/esm --test tests/unit/compression/rule-loader.test.ts tests/unit/compression/language-packs.test.ts
node --import tsx/esm --test tests/unit/compression/rtk-verify.test.ts tests/unit/compression/rtk-dsl-pipeline.test.ts
```
