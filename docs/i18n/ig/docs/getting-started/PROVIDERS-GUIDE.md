## Gịnị Bụ Onye Na-enye Ọrụ?

Were onye na-enye ọrụ dịka **ụlọ ọrụ netwọkụ ekwentị**. Dịka ịchọrọ ụlọ ọrụ netwọkụ ekwentị iji kpọọ oku, ịchọrọ onye na-enye ọrụ AI iji ụdị AI. OmniRoute dị ka ekwentị na-arụ ọrụ na **netwọkụ niile** — ị nwere ike ịgbanwe n'etiti ha na-akpaghị aka.

### Ụdị Ndị Na-enye Ọrụ

| Ụdị            | Ihe Ọ Bụ                      | Ọmụmaatụ                          | Ọnụ Ahịa                   |
| -------------- | ----------------------------- | --------------------------------- | -------------------------- |
| **N'efu**      | Achọghị ịkwụ ụgwọ             | Kiro, OpenCode Free, Pollinations | $0                         |
| **API Key**    | Ị chọrọ API key               | OpenAI, Anthropic, Google         | Kwụọ ụgwọ dịka ojiji si dị |
| **OAuth**      | Jiri akaụntụ gị banye         | Claude Code, GitHub Copilot       | Ndebanye aha               |
| **Web Cookie** | Na-eji nnọkọ ihe nchọgharị gị | ChatGPT Web (Codex), Gemini Web   | $0 (na-eji akaụntụ gị)     |

### Ndị Na-enye Ọrụ Web Cookie

Lee **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** maka ntuziaka nhazi izugbe, oke, idozi nsogbu, na ntụziaka nyocha njirimara kpọmkwem maka onye na-enye ọrụ ọ bụla.

## Mmalite Ngwa Ngwa: Jikọọ Onye Na-enye Ọrụ Mbụ Gị

### Nhazi ndị na-enye ọrụ n'efu n'oge mbido mbụ, ma ọ bụrụ na ịchọrọ

Ọkachamara nhazi nke mbido mbụ na-enye kaadị **Hazie ndị na-enye ọrụ n'efu** nke doro anya. Ọ na-ewepụta ndepụta ndị tozuru ugbu a site na ndekọ ndị na-enye ọrụ OmniRoute ndị na-achọghị nyocha njirimara, wee nye gị ohere inyocha ma wepụ nhọrọ onye na-enye ọrụ ọ bụla tupu ịkwado. OmniRoute na-egosi ọkwa ịkpachara anya nke onye na-enye ọrụ ahụ na njikọ gaa na saịtị ya ka ị nwee ike buru ụzọ nyochaa usoro ndị ọzọ, nzuzo, nnweta, na oke ọnụego.

Omume a bụ nke nhọrọ: imecha ọkachamara nhazi anaghị emepụta njikọ ndị na-enye ọrụ n'efu na nzuzo. Ọ na-emepụta naanị ndị na-enye ọrụ ka na-efu, na-ahapụ njikọ ndị dịbu ma hazie ha dịka ọchịchọ gị ka ha dị, ma na-akọ onye ọ bụla e mepụtara, ndị ahaziela, na ndị dara n'otu n'otu. Ị nwere ike ịnwale naanị ndị dara ọzọ n'enweghị nsogbu ma ọ bụrụ na nsonaazụ ahụ ezughị ezu.

### Nhọrọ A: Onye Na-enye Ọrụ N'efu (Achọghị Kaadị Ebe E Si Anata Ego)

1. Mepee dashboard na `http://localhost:20128`
2. Gaa na **Ndị Na-enye Ọrụ** → **Tinye Onye Na-enye Ọrụ**
3. Họrọ otu n'ime ndị na-enye ọrụ n'efu ndị a:
   - **Kiro AI** — Ụdị Claude n'efu (achọghị nyocha njirimara)
   - **OpenCode Free** — Ụdị GPT n'efu (achọghị nyocha njirimara)
   - **Pollinations** — GPT-5, Claude, Gemini n'efu (achọghị key)
   - **LongCat** — Token 10M n'efu (onyinye otu ugboro, chọrọ akaụntụ + KYC)
   - **Cloudflare AI** — Ụdị 50+, neuron 10K kwa ụbọchị
   - **MLX Gemma 26B** — Ụdị Apple Silicon mpaghara (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — Ụdị Apple Silicon mpaghara (~9.1 tok/s, ~13.1GB RAM)
4. Pịa **Jikọọ**
5. Emechala! Ugbu a ị nwere ohere iji AI n'efu.

### Nhọrọ B: Onye Na-enye Ọrụ API Key (A Na-akwụ Ụgwọ)

1. Nweta API key site na webụsaịtị onye na-enye ọrụ:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Mepee dashboard na `http://localhost:20128`
3. Gaa na **Ndị Na-enye Ọrụ** → **Tinye Onye Na-enye Ọrụ**
4. Họrọ onye na-enye ọrụ gị
5. Mado API key gị
6. Pịa **Jikọọ**
7. Emechala! Ugbu a ị nwere ohere iji ụdị nke onye na-enye ọrụ ahụ.

### Nhọrọ C: Onye Na-enye Ọrụ OAuth (Ndebanye Aha)

1. Mepee dashboard na `http://localhost:20128`
2. Gaa na **Ndị Na-enye Ọrụ** → **Tinye Onye Na-enye Ọrụ**
3. Họrọ onye na-enye ọrụ gị (dịka, Claude Code, GitHub Copilot)
4. Pịa **Jiri OAuth Jikọọ**
5. Jiri akaụntụ gị banye
6. Emechala! Ugbu a ị nwere ohere iji ụdị dị na ndebanye aha gị.

### Nhọrọ D: Ụdị MLX Mpaghara (Apple Silicon)

Maka Mac Apple Silicon ndị nwere ebe nchekwa jikọtara ọnụ, OmniRoute na-akwado ijikọ na ụdị MLX mpaghara na-arụ site na `mlx-lm.server` dịka ndị na-enye ọrụ mpaghara kwekọrọ na OpenAI.

#### Ihe Ndị A Chọrọ Tupu Ebido

- **Apple Silicon Mac** (M1/M2/M3/M4) nwere ebe nchekwa jikọtara ọnụ 24GB+ ka akwadoro
- Ihe njikwa ngwugwu **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Mmalite Ngwa Ngwa

1. **Wụnye ihe ndị a dabere na ha**:

   ```bash
   # Wụnye uv ma ọ bụrụ na awụnyebeghị ya
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Wụnye mlx-lm
   uv pip install mlx-lm
   ```

2. **Jiri aka bido sava MLX** (na terminal dị iche iche):

   ```bash
   # Terminal 1: Gemma 4 26B A4B IT-QAT (port 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Terminal 2: Qwen 3.8 27B MLX Mixed (port 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Jikọọ na Dashboard OmniRoute**:
   - Gaa na **Ndị Na-enye Ọrụ** → **Tinye Onye Na-enye Ọrụ**
   - Họrọ **MLX Gemma 26B** ma ọ bụ **MLX Qwen 3.8 27B**
   - Pịa **Jikọọ** (achọghị API key)

4. **Jiri ya na OpenCode**:
   ```bash
   # Hazie OpenCode ka ọ jiri OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Jiri ụdị MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Njikwa Ebe Nchekwa

**Ihe dị mkpa**: Site na ebe nchekwa jikọtara ọnụ 24GB, naanị **otu nnukwu ụdị MLX nwere ike ịrụ ọrụ n'otu oge**.

- Gemma 26B: ~15.9GB ebe nchekwa kachasị elu
- Qwen 3.8 27B: ~13.1GB ebe nchekwa kachasị elu

Ị ga-eji aka jikwaa nke a:

- Mee ka naanị otu sava MLX rụọ ọrụ n'otu oge, ma ọ bụ
- Mee ka ha abụọ rụọ ọrụ na kọmputa dị iche iche, ma ọ bụ
- Kwụsị otu tupu ịmalite nke ọzọ

OmniRoute anaghị ejikwa usoro sava MLX na-akpaghị aka — ọ na-ebuga naanị arịrịọ gaa na endpoint ndị kwekọrọ na OpenAI ị haziri.

#### Nkwado Ịkpọ Ngwaọrụ

Ụdị abụọ ahụ na-akwado ịkpọ ngwaọrụ kwekọrọ na OpenAI. Jiri nke a nwalee:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Nchọpụta na idozi nsogbu

| Nsogbu                         | Ngwọta                                                                                       |
| ------------------------------ | -------------------------------------------------------------------------------------------- |
| Sava anaghị ebido              | Lelee `uv run mlx_lm.server --help` ma nyochaa NJ model                                      |
| Ebe nchekwa agwụla             | Gbaa mbọ hụ na naanị otu model na-arụ ọrụ; mechie ngwa ndị ọzọ; lelee Activity Monitor       |
| Ajụrụ njikọ                    | Nyochaa na sava na-arụ ọrụ na pọtụ ziri ezi (11435/11436)                                    |
| Nzaghachi ndị na-egbu oge      | Arịrịọ mbụ na-ebunye model n'ime ebe nchekwa (~30-60s); arịrịọ ndị na-esote na-adị ngwa ngwa |
| Ọkpụkpọ ngwaọrụ anaghị arụ ọrụ | Gbaa mbọ hụ na model na-akwado ngwaọrụ; lelee ndekọ OmniRoute maka njehie ntụgharị asụsụ     |

## Otu E Si Jikọọ Onye Na-enye Ọrụ (Nzọụkwụ n'Otu n'Otu)

### Nzọụkwụ 1: Mepee Dashboard

Gaa na `http://localhost:20128` na ihe nchọgharị gị.

### Nzọụkwụ 2: Gaa na Providers

Pịa **Providers** n'akụkụ menu.

### Nzọụkwụ 3: Pịa Add Provider

Pịa bọtịnụ **+ Add Provider**.

### Nzọụkwụ 4: Họrọ Onye Na-enye Gị Ọrụ

Legharịa ndepụta ahụ anya ma ọ bụ chọọ onye na-enye gị ọrụ. Pịa ya.

### Nzọụkwụ 5: Tinye Ozi Nnweta

- **Ndị na-enye ọrụ efughị ego**: Achọghị ozi nnweta — naanị pịa **Connect**
- **Ndị na-enye ọrụ API key**: Mado API key gị
- **Ndị na-enye ọrụ OAuth**: Pịa **Connect with OAuth** wee banye

### Nzọụkwụ 6: Nwalee Njikọ Ahụ

Pịa **Test Connection** iji chọpụta na ọ na-arụ ọrụ.

### Nzọụkwụ 7: Emechala!

Ejikọọla onye na-enye gị ọrụ ugbu a. Ị nwere ike iji ya na `model: "auto"` ma ọ bụ họpụta onye na-enye ọrụ ahụ ozugbo.

## Iji Ọtụtụ Ndị Na-enye Ọrụ

OmniRoute na-arụ ọrụ nke ọma karịa mgbe e nwere **ọtụtụ ndị na-enye ọrụ**. Nke a na-enye gị:

- **Iji nhọrọ ọzọ na-akpaghị aka** — Ọ bụrụ na otu onye na-enye ọrụ ada, OmniRoute ga-anwale onye na-esote
- **Ịkwalite ọnụ ahịa** — OmniRoute na-ahọrọ onye na-enye ọrụ dị ọnụ ala karịa maka arịrịọ ọ bụla
- **Ịkwalite ọsọ** — OmniRoute na-ahọrọ onye na-enye ọrụ kachasị ọsọ maka arịrịọ ọ bụla
- **Ịkwalite ogo** — OmniRoute na-ahọrọ onye na-enye ọrụ kachasị mma maka ọrụ ọ bụla

### Nhazi A Tụrụ Aro

Jikọọ opekata mpe **ndị na-enye ọrụ 3** iji nweta ahụmịhe kachasị mma:

1. **Otu onye na-enye ọrụ efughị ego** (Kiro, OpenCode Free, ma ọ bụ Pollinations) — Ọ na-adị mgbe niile
2. **Otu onye na-enye ọrụ ọsọ ọsọ** (Groq, Cerebras) — Maka nzaghachi ngwa ngwa

## Ajụjụ Ndị A Na-ajụkarị

### "Ọ dị m mkpa ịkwụ ụgwọ iji jiri OmniRoute?"

**Mba!** OmniRoute bụ n'efu ma bụrụ open-source. Ị nwere ike iji ndị na-enye ọrụ n'efu (Kiro, OpenCode Free, Pollinations) n'akwụghị ụgwọ ọ bụla. Naanị mgbe ị họọrọ iji ndị na-enye ọrụ a na-akwụ ụgwọ ka ị ga-akwụ ụgwọ.

### "Kedu onye na-enye ọrụ m kwesịrị ibido na ya?"

Bido na **Kiro AI** — ọ bụ n'efu, ọ chọghị API key, ma na-enye gị ohere iji ụdị Claude. Mgbe ahụ, tinye ndị na-enye ọrụ ndị ọzọ dịka mkpa gị siri dị.

### "Enwere m ike iji ọtụtụ ndị na-enye ọrụ n'otu oge?"

**Ee!** Nke ahụ bụ isi ebumnuche OmniRoute. Jikọọ ọtụtụ ndị na-enye ọrụ ma jiri `model: "auto"` ka OmniRoute họrọ nke kacha mma maka arịrịọ ọ bụla.

### "Gịnị ga-eme ma ọ bụrụ na onye na-enye ọrụ akwụsị ịrụ ọrụ?"

OmniRoute na-awụfe ndị na-enye ọrụ dara ada na-akpaghị aka ma nwalee nke na-esote. Ọ dịghị ihe ị ga-eme.

### "Kedu ka m ga-esi kwụpụ onye na-enye ọrụ?"

Gaa na Ndị Na-enye Ọrụ → pịa onye na-enye ọrụ ahụ → pịa **Kwụpụ**.

### "Enwere m ike iji API key ndị m nwere ugbu a?"

**Ee!** Ọ bụrụ na i nweelarị API key maka OpenAI, Anthropic, Google, wdg., ị nwere ike iji ha na OmniRoute. Naanị tapawa ha mgbe ị na-ejikọta onye na-enye ọrụ.
