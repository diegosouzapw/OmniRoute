## Nzọụkwụ 1: Wụnye OmniRoute

Họrọ usoro masịrị gị:

### Nhọrọ A: npm (A tụrụ aro)

```bash
npm install -g omniroute
```

### Nhọrọ B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` bụ SemVer kwụsiri ike kachasị elu e **bipụtara**. Ọ naghị eso git `main`. Jiri `diegosouzapw/omniroute:X.Y.Z` kpọchie ụdị ahụ maka GitOps. Lee [Mkpado Image / Ọwa Mwepụta](../guides/DOCKER_GUIDE.md#release-channels).

### Nhọrọ C: Site na Source

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Nzọụkwụ 2: Malite OmniRoute

```bash
omniroute
```

OmniRoute na-amalite na `http://localhost:20128`. Dashboard ga-emeghe na-akpaghị aka.

## Nzọụkwụ 3: Jikọọ Onye Na-eweta Ọrụ Efu

Ị nwere ike iji OmniRoute **n'akwụghị ụgwọ ọ bụla** site na ijikọ onye na-eweta ọrụ efu.

### Nhọrọ A: Kiro (Claude Efu — Achọghị Kaadị Ebe E Si Enweta Ego)

1. Mepee dashboard na `http://localhost:20128`
2. Gaa na **Ndị Na-eweta Ọrụ** → **Tinye Onye Na-eweta Ọrụ**
3. Họrọ **Kiro AI**
4. Pịa **Jikọọ** (achọghị API key!)
5. Emechaala! Ị nwerezi ohere efu iji ụdị Claude.

### Nhọrọ B: OpenCode Free (Achọghị Nyocha Njirimara)

1. Mepee dashboard na `http://localhost:20128`
2. Gaa na **Ndị Na-eweta Ọrụ** → **Tinye Onye Na-eweta Ọrụ**
3. Họrọ **OpenCode Free**
4. Pịa **Jikọọ** (achọghị API key!)
5. Emechaala! Ị nwerezi ohere efu iji ọtụtụ ụdị.

### Nhọrọ C: Pollinations (Achọghị Key)

1. Mepee dashboard na `http://localhost:20128`
2. Gaa na **Ndị Na-eweta Ọrụ** → **Tinye Onye Na-eweta Ọrụ**
3. Họrọ **Pollinations**
4. Pịa **Jikọọ** (achọghị API key!)
5. Emechaala! Ị nwerezi ohere efu iji GPT-5, Claude, Gemini, na ndị ọzọ.

## Nzọụkwụ 4: Nyochaa na Ọ Na-arụ Ọrụ

Site na [API Keys](http://localhost:20128/dashboard/api-manager), mepụta key ọhụrụ. Chekwaa key a n'ihi na ọ gaghị apụta ọzọ. Rịba ama na key a bụ maka ngwaọrụ iji nweta OmniRoute, ọ bụghị iji nweta ndị na-eweta ọrụ dị n'elu.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Ị kwesịrị ịhụ ndepụta ụdị ndị ị jikọrọ.

## Nzọụkwụ 5: Tụnye IDE ma ọ bụ CLI Gị Aka na OmniRoute

N'ime IDE ma ọ bụ ngwaọrụ CLI gị, hazie:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

Ọ bụ ya! IDE gị na-eji OmniRoute ugbu a, tinyere nhọpụta onye na-eweta ọrụ na-akpaghị aka.

### Ọmụmaatụ IDE: VSCode/Continue.dev

1. N'ime VSCode, wụnye mgbakwunye [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Melite `~/.continue/config.yaml` gị iji tinye ahịrị ndị a:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. N'ime pane nkata Continue.dev, họrọ `OmniRoute - Auto`, ị ga-ezigakwa arịrịọ na OmniRoute.
4. (Nhọrọ) Ihe omume maka onye na-agụ akwụkwọ — mee ka IDE gị jiri nhazi ndị ọzọ niile e wuru tupu oge eruo melite `config.yaml` 😊

### Ọmụmaatụ CLI: Codex CLI

1. N'ime sistemụ arụmọrụ gị, hazie environment variable ahụ ka ọ na-adịgide.
   Maka macOS/Linux (tinye ya na `~/.bashrc` ma ọ bụ `~/.zshrc` gị):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Maka Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Ugbu a, ka anyị malite Codex, mana hazie ya maka OmniRoute. Gbaa:

```
omniroute launch-codex --model auto
```

Ị nwere ike iji aka gị mee nke a site na `codex` na command line parameters iji kọwaa endpoint na api key, mana site na command ahụ dị n'elu, OmniRoute na-elekọta ihe niile maka gị.

Otu command a na-amalitekwa CLI ndị ọzọ site na generic launcher — `omniroute run <target>` na-akwado `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, na `gemini` (lee [Njikọta CLI](../guides/CLI-INTEGRATIONS.md)).

3. CLI kwesịrị ịdị na-ezigara OmniRoute arịrịọ ugbu a.

### Gbaa mbọ hụ na ngwaọrụ gị na-ebufe arịrịọ na OmniRoute

Ị nwere ike ịhụ nkọwa arịrịọ ahụ site na ịpị [Nlekota/Logs](http://localhost:20128/dashboard/logs) n'akụkụ aka ekpe. Ịpịga n'ihu ga-egosi gị nkọwa ndị ọzọ. Dị ka ihe mgbakwunye, ị nwere ike ịhụ ozi ngwaọrụ ọkacha mmasị gị na-eziga. Nke a bara uru maka mmụta na debugging.

## Ajụjụ Ndị A Na-ajụkarị

### "Achọrọ m API key?"

**Mba!** Ị nwere ike iji ndị na-eweta ọrụ efu (Kiro, OpenCode Free, Pollinations) na-enweghị API key ọ bụla. Naanị jikọọ ha na dashboard.

### "Gịnị bụ `auto`?"

`auto` na-agwa OmniRoute ka ọ họrọ onye na-eweta ọrụ kacha mma maka arịrịọ ọ bụla na-akpaghị aka. Ọ na-atụle ọsọ, ọnụahịa, ogo, na ịdị adị. Lee [Ntuziaka Auto-Combo](./AUTO-COMBO-GUIDE.md) maka nkọwa.

### "Ego ole ka ọ na-efu?"

OmniRoute n'onwe ya bụ **n'efu ma bụrụ open-source**. Naanị ndị na-eweta ọrụ ị na-eji ka ị ga-akwụ ụgwọ maka ha. Ọtụtụ ndị na-eweta ọrụ nwere free tiers — lee [Ntuziaka Free Tiers](./FREE-TIERS-GUIDE.md).

### "Enwere m ike iji ya na Claude Code / Cursor / Copilot?"

**Ee!** OmniRoute na-arụ ọrụ na ngwaọrụ ọ bụla na-akwado usoro OpenAI. Naanị hazie base URL ka ọ bụrụ `http://localhost:20128/v1`. Lee [Ntuziaka Ngwaọrụ CLI](../reference/CLI-TOOLS.md) maka ntuziaka nhazi akọwapụtara.

### "Gịnị ma ọ bụrụ na onye na-eweta ọrụ akwụsị ịrụ ọrụ?"

OmniRoute na-awụfe ndị na-eweta ọrụ dara ada na-akpaghị aka wee nwalee nke na-esote. Ọ dịghị ihe ị ga-eme. Lee [Ntuziaka Auto-Combo](./AUTO-COMBO-GUIDE.md) maka nkọwa.
