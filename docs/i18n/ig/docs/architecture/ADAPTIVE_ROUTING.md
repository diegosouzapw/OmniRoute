Akwụkwọ a na-akọwa ntọala nhazi ụzọ na-agbanwe agbanwe nke nzaghachi na-eduzi, nke agbakwunyere na
OmniRoute. E kpachapụrụ anya mee ka ọ dị obere: ọ na-ewebata ọwa nsonaazụ-nhazi-ụzọ
nwere ụdị akọwapụtara, mgbaàmà ogo na-arụ ọrụ ozugbo nke na-enye onye na-agbakọ akara auto-combo dị ugbu a ozi, onye
na-ebupụ OpenTelemetry enwere ike ịhọrọ, yana endpoint nkọwa. Ọ **dịghị**
edochi usoro nkwụsi ike dị ugbu a (circuit breaker, connection cooldown,
model lockout, health matrix, autopilot) — kama, ọ na-emeju ya.

## 1. Ọnọdụ nhazi ụlọ sistemụ

OmniRoute bụ data plane nwere **ụzọ ngwa ngwa nke arịrịọ** na **control/intelligence
plane**. Ụzọ ngwa ngwa ahụ ga-anọgide na-adị ọsọ, na-eji ebe nchekwa nke ọma, asynchronous, na-eguzogide nsogbu ma
na-arụ ọrụ dịka a tụrụ anya ya. Ntụle, ịgbakọ akara ogo, nnwale na nyocha akụkọ ihe mere eme
dịịrị control plane.

```
AI Agent / IDE
      │
      ▼
┌─────────────────────┐
│    OmniRoute        │   data plane (ọsọ, sync, n'ime ebe nchekwa)
│  nhazi ụzọ / failover │
│  ahụike / guardrail │
│  cache / streaming  │
└──────────┬──────────┘
           │ RoutingEvent (zipụ-ma-echekwala, ~0.2µs)
           ▼
┌─────────────────────┐
│  Ebe nnata nzaghachi │   control plane (async, mgbalị-kachasị-mma)
│  onye na-esochi ogo │
│  onye na-ebupụ OTel │
│  ebe nchekwa nkọwa │
└──────────┬──────────┘
           ▼  akara ogo
      onye na-agbakọ akara auto-combo
```

### Ihe dịlarị (enyochara, emeghị ya ọzọ)

| Echiche                                 | Mmejuputa dị ugbu a                                                                                   |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Ịdị adị (anyị nwere ike izipu traffic?) | Circuit breaker (CLOSED/DEGRADED/OPEN/HALF_OPEN, echekwara na DB), connection cooldown, model lockout |
| Nkwupụta ahụike                         | `providerHealthMatrix.ts`, `providerHealthAutopilot.ts`                                               |
| Shadow traffic                          | `open-sse/services/combo/shadowRouting.ts`                                                            |
| Guardrails                              | `src/lib/guardrails/` (hooks tupu/mgbe e mesịrị)                                                      |
| Exact cache                             | `src/lib/semanticCache.ts` (dabere na signature)                                                      |
| Ndị ntụle / nhazi ụzọ nke eval na-eduzi | `src/lib/evals/`, `open-sse/services/evalRouting.ts`                                                  |
| Nkọwa mkpebi Combo                      | `open-sse/services/combo/decisionTrace.ts`                                                            |
| Ihe omume dashboard ozugbo              | `src/lib/events/eventBus.ts` (ọwa ọkwa UI, payloads `unknown`, akụkọ ihe omume 100)                   |

Routing-event layer **abụghị** mmejuputa ọzọ nke `eventBus`: bus ahụ bụ
ọwa ọkwa ozugbo nke dashboard (aha _ihe omume_ nwere ụdị akọwapụtara, payloads
na-apụtaghị ìhè, ndị na-eji UI). `RoutingEvent` bụ struct _nsonaazụ_ nwere ụdị akọwapụtara
(latency/tokens/cost/outcome/finish-reason) nke ebe nnata nzaghachi nke control plane
na-eji (onye na-esochi ogo, onye na-ebupụ OTel, ebe nchekwa nkọwa).

### Ihe na-adịghị (agbakwunyere ebe a)

1. **Ihe omume nsonaazụ-nhazi-ụzọ nwere ụdị akọwapụtara + abstraction nke sink** (`RoutingEvent` /
   `RoutingEventSink`). `decisionTrace` metụtara naanị combo ma dị naanị n'ime ebe nchekwa;
   `comboMetrics` bụ counter na-agbakọta ọnụ; `call_logs` bụ raw async persistence.
   Ọ dịghị nke bụ ọwa nsonaazụ nwere ụdị akọwapụtara ma dabere na sink nke onye na-esochi ogo, onye na-ebupụ OTel,
   ma ọ bụ onye ntụle yiri Future-AGI nwere ike ịdebanye aha na ya.
2. **Mgbaàmà ogo na-arụ ọrụ ozugbo** (EWMA) maka ogo output — na mbụ, onye na-agbakọ akara
   na-eji naanị static task fitness na eval pass-rates a họọrọ iji nọchite anya "ogo".
3. **Onye na-ebupụ OTel a pụrụ ịhọrọ, na-enweghị dependency** nke na-eji GenAI semantic conventions.
4. **Endpoint nkọwa** nke na-eweghachi ezigbo mkpebi nhazi ụzọ + ọnọdụ ogo.

## 2. Ihe Omume Routing (ntọala nzaghachi)

Faịlụ: `open-sse/services/routing/events.ts`, `.../index.ts`

`RoutingEvent` na-ebu naanị metadata routing:

```ts
interface RoutingEvent {
  requestId: string;
  provider: string;
  model: string;
  strategy: string; // "auto" | "priority" | "direct" | ...
  latencyMs: number;
  ttftMs: number | null;
  inputTokens: number | null;
  outputTokens: number | null;
  cost: number | null;
  retries: number;
  fallbackUsed: boolean;
  outcome: RoutingOutcome; // union e depụtara na ndepụta ikike
  status: number | null;
  finishReason: string | null;
  connectionId: string | null;
  ts: number;
}
```

`RoutingEventSink` bụ trait yiri `Send+Sync` na TypeScript:

```ts
interface RoutingEventSink {
  readonly name: string;
  record(event: RoutingEvent): void; // ga-abụrịrị O(1), enweghị I/O mmekọrịta ozugbo
}
```

Ụzọ a na-ejikarị eme ihe na-akpọ `emitRoutingEvent(event)` otu ugboro maka arịrịọ ọ bụla emechara
(callback mmecha streaming, ụzọ ihe ịga nke ọma na-enweghị streaming, na ụzọ ọdịda
malformed-200 dị na `handleChatCore`). Nkesa bụ fan-out mmekọrịta ozugbo
gaa na sinks e debanyere aha, mana sink ọ bụla na-etinye naanị n'ahịrị ma ọ bụ na-emelite ọnọdụ dị na ebe nchekwa. **Enweghị
ide ihe na database n'ụzọ mmekọrịta ozugbo, enweghị network I/O n'ụzọ a na-ejikarị eme ihe.**

Sinks ndabara:

- `MemoryRoutingEventStore` — ring buffer nwere oke (500), nke kachasị ọhụrụ na-abịa mbụ, maka
  endpoint nkọwa.
- Onye na-eji `QualityTracker` — na-emelite atụmatụ ogo EWMA.
- `OtlpHttpsEventSink` — nhọrọ, a na-eme ka ọ rụọ ọrụ naanị mgbe edobere `OMNIROUTE_OTEL_ENDPOINT`
  (ma ọ bụ `OTEL_EXPORTER_OTLP_ENDPOINT`).

### Mmụba ọrụ a tụrụ (ntụnyere eziokwu)

`npm run bench:routing-events` na workstation a (iterations 100k; ops ndị na-erughị µs
ka a tụrụ dịka mkpokọta µs/op n'ihi na percentile nke op ọ bụla dị n'okpuru
mkpebi oge nke `performance.now()`):

| Ọnọdụ                             | µs/op  | ops/s  |
| --------------------------------- | ------ | ------ |
| baseline (naanị scoring)          | ~0.045 | ~22 M  |
| baseline + RoutingEvent (sinks 2) | ~0.168 | ~5.9 M |
| baseline + event + OTel enqueue   | ~0.163 | ~6.1 M |
| concurrent (bursts 8 agwakọtara)  | ~0.18  | —      |

Ọdịiche event-dispatch karịa baseline scoring bụ ~0.12 µs/request; sink OTel
na-etinye naanị n'ahịrị (ntinye buffer O(1)), na-enweghị ihe mgbakwunye a pụrụ ịtụ. Ọnụọgụ ndị a
dabere n'igwe ma bụrụ nke ntụnyere — ha abụghị nkwa maka production. Ọnụọgụ v1 "~0.2 µs"
bụ atụmatụ mkpokọta; usoro a na-ekewa baseline scoring
na ọnụ ahịa event-dispatch.

## 3. Akara Ogo (ọnọdụ provider nke nzaghachi na-akwalite)

Faịlụ: `open-sse/services/routing/quality.ts`

v2 na-ekewa ogo **ọrụ** na ogo **semantic**:

- **Ọrụ** — sitere n'ụzọ routing a na-ejikarị eme ihe (HTTP 4xx/5xx, ọdịda connection,
  429s, nzaghachi malformed, nkwụsị stream, `finish_reason=length`,
  ihe ịga nke ọma nwere output efu, latency/TTFT EWMA). A naghị ewere 200 dịka ogo
  semantic.
- **Semantic** — uru n'ezie nke output emepụtara. Ọ bụ naanị evaluator na-emepụta ya
  site na `setSemanticQuality()`. Ọ bụ `null` ruo mgbe otu evaluator nyere ya, ọ dịghịkwa mgbe ọ
  na-abanye na akara ọrụ.

Ọnọdụ maka (provider, model) ọ bụla (EWMA + counters nwere oke):

- `successEwma` — EWMA (α=0.2) nke ihe ịga nke ọma nke outcome.
- `latencyEwma` / `ttftEwma` — EWMA nke latency (α=0.1).
- `samples`, `anomalies`, `rateLimited`, `semantic`, `semanticConfidence`.
- `recencyMs` — ogologo oge kemgbe a hụrụ model ahụ ikpeazụ.

### Mmata confidence / sample

`confidence = clamp01(samples / 50)`, a na-agwakọtakwa akara e weghachiri na scorer
ka ọ bịaruo ebe etiti na-anọpụ iche:

```
score = 0.5 + confidence * (operational - 0.5)
```

Nsonaazụ (ule kwadoro):

- Provider oyi (samples 0) na-enweta akara **0.5** — a naghị ata ya ahụhụ n'ụzọ na-ezighị ezi, mana
  ọ pụghị ịkarị provider nwere puku kwuru puku nlele siri ike.
- Provider nwere ihe ịga nke ọma 7 sitere na ihu ọma ka a na-adọta n'akụkụ 0.5 (ọ dịghị mgbe ọ na-akarị ndị ọzọ site
  na initialization nwere olileanya gabigara ókè).
- Provider nwere samples 50+ na-erute akara ọrụ ya n'ezie.
- Mbelata na mgbake na-eji nwayọọ nwayọọ eme (EWMA), otu ọdịda naanị ya anaghịkwa
  emebi provider dị mma.

`ProviderQuality` na-ekpughe `{ operational, semantic, confidence, samples, anomalies,
rateLimited, successEwma, latencyEwmaMs, ttftEwmaMs, recencyMs }`.

Nke a na-abanye na auto-combo scorer dịka factor scoring `quality`:

- `ScoringFactors.quality` / `ScoringWeights.quality` dị na
  `open-sse/services/autoCombo/scoring.ts`.
- `DEFAULT_WEIGHTS`: `health` 0.1905 → 0.1605, `quality` 0.03. Mkpokọta na-anọgide 1.0.
- `buildAutoCandidates` na-etinye ogo sitere na tracker na `candidate.quality`; candidates
  na-enweghị data na-eji ndabara na-anọpụ iche **0.5** (a naghị akwalite candidate oyi, a naghịkwa
  ata ya ahụhụ).

Okirikiri mechiri emechi:

```
RoutingEvent → QualityTracker → getQualityScore → factor ogo auto-combo
      ↑                                                    │
      └────── outcome arịrịọ (handleChatCore) ←────────────┘
```

### Mwepụ siri ike na ntaramahụhụ dị nro

Akara ogo bụ naanị **mmasị mmegharị dị nro**. Mwepụ siri ike ka dị
na resilience stack dị ugbu a: circuit breaker OPEN, quota agwụla,
ọdịda auth, model lockout — akara ogo anaghị emetụta nke ọ bụla n'ime ndị a.
Provider nke akara ogo ya dara nwa oge ga-enweta obere mmasị, ọ dịghị mgbe
a ga-agbanyụ ya kpamkpam.

## 3b. Nhazi oge stream canonical (TTFT / ITL)

Faịlụ: `open-sse/utils/streamTiming.ts`

`createStreamTiming()` bụ otu ebe instrumentation maka ụzọ streaming,
e jikọtara ya na `createSSEStream` (open-sse/utils/stream.ts):

- `markByte()` — chunk mbụ sitere upstream a natara.
- `markForward()` — chunk mbụ e zigara client (nke a na-eji maka TTFT).
- `markInterrupted()` — timeout/abort/error nke stream tupu ọ gwụchaa nke ọma.
- `ttft()` = latency ruo mgbe e zigara SSE chunk mbụ. **Nke a ABỤGHỊ TTFT n'ogo token** —
  otu SSE chunk nwere ike ibu token efu/otu/ọtụtụ. E depụtara nke a nke ọma.
- `avgItlMs()` = nkezi oghere oge n'etiti chunk (proxy latency nke chunk maka ITL).

TTFT/ITL/interrupted na-abanye na `RoutingEvent` (`ttftMs`, `itlMs`) ma a na-ebupụ
ha dịka àgwà span GenAI/OmniRoute site na sink OTel.

## 4. Nlele OpenTelemetry / GenAI

Faịlụ: `open-sse/services/routing/otel.ts`

- OTLP/HTTP JSON exporter na-enweghị dependency (na-eji `fetch` zuru ụwa ọnụ, enweghị
  SDK `@opentelemetry/*`).
- Spans na-agbaso ụkpụrụ semantic GenAI (`gen_ai.provider.name`,
  `gen_ai.request.model`, `gen_ai.usage.input_tokens/output_tokens`,
  `gen_ai.completion.finish_reason`, `gen_ai.system`) tinyere àgwà routing
  OmniRoute (outcome, status, ttft, retries, fallback).
- `record()` na-etinye naanị ihe n'ahịrị nchere buffer nwere oke (O(1)); timer dị
  n'azụ na-eme flush site na `POST {endpoint}/v1/traces` n'ụzọ asynchronous. Mgbe
  ibu karịrị akarị, a na-atụfu events kacha ochie (counter `dropped`) — ọ naghị
  etinye backpressure na data plane ma ọlị.
- **Agbanyụrụ ya ma ọ bụrụ na ahazighị ya.** A ga-edobe `OMNIROUTE_OTEL_ENDPOINT`
  (ma ọ bụ `OTEL_EXPORTER_OTLP_ENDPOINT`); ma ọ bụghị ya, a naghị edebanye sink ahụ
  ma ọ dịghị code OTel ọ bụla ga-agba ọsọ.

## 5. Ikike ịkọwa mkpebi

- `GET /v1/explain/routing` na-eweghachi `RoutingEvent`s ndị mere n'oge na-adịbeghị
  anya (mkpebi ndị ahụ n'ezie, nke kachasị ọhụrụ na mbụ) na snapshot quality nke
  provider/model ọ bụla.
- Auth yiri nke `/v1/combos` (Bearer API key ma ọ bụ session dashboard; a na-ekwe
  ka anonymous na deployment local nke otu onye ọrụ nwere `REQUIRE_API_KEY=false`).
- Traces nke invocation ọ bụla n'ogo combo ka dị site na `decisionTrace.ts` dị
  ugbu a (header `X-OmniRoute-Combo-Trace`).
- Nchekwa: events na-ebu naanị metadata routing, ọ bụghị prompts/bodies/credentials.

## 6. Njikọ evaluation-plane (Njikere maka Future AGI)

OmniRoute na-ele Future AGI (ma ọ bụ evaluator ọ bụla) anya dịka **backend nwere
ike ịnye ọgụgụ isi/evaluation, ọ bụghị dependency**. Ebe njikọ ndị ahụ bụ:

- `RoutingEventSink` nwere ike izigara evaluator events n'ụzọ asynchronous.
- `MemoryRoutingEventStore` + snapshot quality na-enye evaluator stream mkpebi
  raw.
- `Evaluator` n'ọdịnihu (deterministic, local judge, HTTP, WASM) ga-anata
  events/traces wee weghachi `QualityScore` nke na-abanye n'otu ụzọ
  `getQualityScore`/quality-factor ahụ.
- Routing nke eval na-achị dị ugbu a (`open-sse/services/evalRouting.ts`) emeelarị
  nhazi combo targets ọzọ dabere na pass-rates nke `eval_runs` mgbe agbanyere ya.

Ọ dịghị evaluation na-agba ọsọ synchronously n'ụzọ request, gateway ahụ na-arụkwa
ọrụ n'ụzọ zuru ezu mgbe evaluator adịghị.

## 7. Nyocha architecture ikpeazụ

1. **Gịnị ka fọdụrụ n'ụzọ synchronous hot path?** Routing/scoring, pre-checks
   guardrail, nyocha cache, na otu fan-out `emitRoutingEvent` (~0.12 µs karịa
   baseline scoring) gaa na sinks dị na memory.
2. **Gịnị ka e bugara na nhazi asynchronous?** Mbupụ OTel (timer + fetch),
   persistence nke `call_logs`/usage, ide semantic-cache; quality dị na memory
   ma bụrụ O(1) (async adịghị mkpa).
3. **Kedu ka outcome routing si aghọ feedback?** `handleChatCore` na-ewepụta
   `RoutingEvent` → `QualityTracker` na-emelite state EWMA → `getQualityScore`
   na-enye factor `quality` nke auto-combo.
4. **Kedu ka quality si emetụta routing n'ọdịnihu?** Quality score dị ala na-ebelata
   weighted score nke provider/model ahụ na `scoreAutoTargets`, ya mere a na-eji
   nwayọọ belata mmasị n'ebe models ndị arụmọrụ ha dara ada nọ, ha na-agbakwa
   ọzọ ka EWMA ha na-akawanye mma.
5. **Kedu ka Future AGI ga-esi jikọọ n'aghọghị dependency?** Site na interface
   `RoutingEventSink` / adapter `Evaluator` n'ọdịnihu — enweghị dependency
   etinyere kpọmkwem na code.
6. **Gịnị na-eme mgbe evaluator adịghị?** Ọ naghị emetụta routing;
   quality na-alaghachi na neutral (1.0) maka models na-enweghị signal a hụrụ.
7. **Gịnị na-eme mgbe telemetry adịghị?** A naghị edebanye sink OTel ahụ;
   akụkụ routing ndị ọzọ na-aga n'ihu n'enweghị mgbanwe.
8. **Gịnị na-eme mgbe ibu karịrị akarị?** Buffer OTel na-atụfu events kacha ochie;
   quality na ring buffer nwere oke site na nhazi ha; enweghị backpressure.
9. **Kedu ka state provider si agbake mgbe arụmọrụ dara?** EWMA na-alọghachi n'usoro
   ka successes na-abawanye; warmup na-eme ka cold models nọgide na neutral;
   circuit breaker na-agbake n'onwe ya site na probes HALF_OPEN.
10. **Kedu features ndị a tụrụ aro e kpachaara anya GHARA imepụta, gịnịkwa kpatara ya?**
    - Shadow traffic / experiments — emeelarị ha
      (`combo/shadowRouting.ts`); e wughachighị ha.
    - Guardrails — emeelarị ha (`src/lib/guardrails/`); e mepụtaghị oyiri ha.
    - Semantic cache — emeelarị ya (`src/lib/semanticCache.ts`); e mepụtaghị
      oyiri ya.
    - Platform zuru ezu maka experiment-management, dataset tooling, platform
      prompt-optimization, vector DB, ma ọ bụ infrastructure OTel mpụga a
      manyere iwu — ha esoghị scope nke data plane dị mfe.
    - Struct `RoutingEvent` nke Rust — data plane ahụ bụ TypeScript; type TS
      ahụ bụ ihe kwekọrọ na ya nke a gbanwere.
