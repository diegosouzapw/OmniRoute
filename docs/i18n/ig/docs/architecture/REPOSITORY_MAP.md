## `src/` — Ngwa Next.js

```
src/
├── app/                 # App Router (peeji + ụzọ API + peeji ọkwa + peeji mbata)
├── lib/                 # Ọba akwụkwọ ndị bụ isi / modulu ngalaba (subdir 80 + ihe dị ka faịlụ ọkwa-elu 70)
```
