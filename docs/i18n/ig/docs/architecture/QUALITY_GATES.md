Ọ na-akọwa ọnụ ụzọ ọ bụla, ihe ọ na-enyocha, ọrụ CI ọ na-arụ n'ime ya, ma ọ na-eji
ntọala ratchet ma ọ bụ iwu ngafe/ọdịda, yana ma ọ na-egbochi build ka ọ bụ naanị ndụmọdụ.

Maka nchịkọta dị mkpirikpi na iwu allowlist, lee ngalaba "Quality Gates & Ratchets"
dị na `AGENTS.md`. Maka nyocha dị mkpa, nhazi ọkwa ntozu-oke, na atụmatụ mmegharị
nke otu sistemụ ahụ na-adabereghị na ngwá ọrụ ọ bụla, lee
[Quality Gate Playbook](../ops/QUALITY_GATE_PLAYBOOK.md).

## Ndepụta Gate (~90 scripts)

Scripts dị n'okpuru `scripts/check/` (policy gates) na `scripts/quality/` (ratchet engine).
Ebe eziokwu CI si abịa bụ `.github/workflows/ci.yml`.

### Ụzọ-ngwa-ngwa PR ntọhapụ (`quality.yml`)

`.github/workflows/quality.yml` na-arụ ọrụ na PR ndị na-elekwasị anya na `release/**`. Ọ na-eme ka alaka ndị na-enye aka
na-aga n'ihu site na gate ngwa-ngwa ndị a na-enyocha dịka path si dị, tinyere otu akara ndụmọdụ production-build maka mgbanwe
koodu:

| Job                                              | Oke                                                                                                                                                                                                                            | Na-egbochi                                                                                           |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `Build (advisory)`                               | PR koodu ndị na-abụghị draft na alaka Mergify queue; Node 24, `npm-ci-retry`, `check:node-runtime`, `npm run build` ya na `OMNIROUTE_USE_TURBOPACK=1`; enweghị artifact upload n’ihi na ọ dịghị quality job na-esote na-eji ya | **Ndụmọdụ** (`continue-on-error: true`; wepụ ya mgbe otu izu nke release-PR runs kwụsiri ike gasịrị) |

#### Akụkọ forgotten sibling tests

`npm run check:forgotten-sibling-tests` na-eji ọzọ import resolver dị n’azụ test-impact map.
Maka production module ọ bụla gbanwere, ọ na-akọ chains ndị a na-ekpebi n’enweghị mgbanwe:
`changed module/symbol -> static consumer -> candidate sibling test` mgbe candidate
test adịghị na diff pull-request ahụ. A na-edobe nchịkọta Markdown na nsonaazụ JSON dịka
artifact workflow `forgotten-sibling-tests` maka calibration tupu blocking rollout ọ bụla.

Barrel re-exports na dynamic imports bụ naanị resolution diagnostics; ha anaghị emepụta
blocking finding. Exceptions ndị a nyochara dị na
`config/quality/forgotten-sibling-allowlist.json`. Entry ọ bụla ga-akpọ consumer na candidate
test aha, nye kpọmkwem ihe kpatara ya, ma jikọọ GitHub issue ma ọ bụ pull request. Entries ndị ezughị oke na-ada
n’ụzọ mechiri emechi. Exceptions enweghị ike izochi candidate test ehichapụrụ ma ọ bụ diff nke na-agbakwunye `.skip`/`.todo`;
ime ka assertion ghara ịdị ike na masking ndị ọzọ ka bụ ọrụ gate
`check:test-masking` nke na-egbochi n’onwe ya.

#### `check-ui-value-drift` — gate ntụgharị ochie

Ọ na-achọpụta otu regression i18n nke gates ndị ọzọ enweghị ike ịhụ n'ụzọ nhazi: a degharịrị value Bekee,
mana ntụgharị ndị sitere na Bekee _gara aga_ ka nọ ebe ahụ, ya mere
ndị ọrụ na-adịghị asụ Bekee ka na-agụ ederede e ji obi ike dee, ma nke na-ezighi ezi ugbu a.

Nke a pụtara n'ezie na release. E degharịrị `oauthModal.googleOAuthWarning` mgbe helper nbanye Antigravity
batara (#5203); **locale 39 n'ime 43** ka nwere ederede na-agwa ndị ọrụ ka ha "detuo URL
zuru ezu ma mado ya n'okpuru" — usoro nke na-enweghị ike ịrụcha maka provider ahụ. A hụghị
ya ruo #8463 n'ihi na:

- `sync-ui-keys` na-emeju naanị keys ndị **na-adịghị**, ọ naghị emeju ndị **ochie**;
- `check-ui-keys-coverage` na-agụ ọnụnọ key, ya mere a na-agụ ntụgharị ochie dị ka nke e kpuchiri;
- `check-translation-drift` na-esochi oyiri akwụkwọ `docs/i18n/<locale>/**.md` —
  ọ naghị agụ `src/i18n/messages/*.json`. Ọ na-egbochi na ọrụ `docs-sync-strict` kemgbe
  re-sync 2026-09: dezie core doc → `npm run i18n:run -- --files=<doc>` (n'ọkwa section, dị ọnụ ala).

**Ọ na-amata diff, ọ bụghị baseline na-akwado ya.** Ọ na-atụnyere `en.json` dị na merge base na
working tree; maka key ọ bụla uru Bekee ya gbanwere, locale ọ bụla ka nwere
ntụgharị a na-emetụghị aka adịkwaghị ọhụrụ. Nke a kpachapụrụ anya **na-eme ka ụgwọ dịbu adị ghara ịgbanwe** — diff
enweghị ike igosi Bekee ochie nke ntụgharị dịtere aka siri na ya pụta, ya mere gate ahụ na-enyocha
naanị ihe mgbanwe dị ugbu a metụtara. Nhọrọ ọzọ (baseline hash maka key ọ bụla) ga-achọ
faịlụ emepụtara nke ruru ~600 KB, nke ji okpukpu 3 karịa baseline kacha ibu dị ugbu a, ma na-agbanwe n’ime PR i18n ọ bụla.

E nwere ụzọ abụọ isi mezuo ya:

1. melite ntụgharị ndị o metụtara, ma ọ bụ
2. tọọ ha ka ha bụrụ `__MISSING__:<new english>` — runtime ga-enyezi Bekee ahụ e doziri
   (`src/i18n/request.ts::deepMergeFallback`, #7258), key ahụ abanyekwa n’ahịrị ntụgharị.

Ọ bụrụ na **ihe eriri ahụ pụtara** gbanwere, họrọ **ịgbanwe aha key ahụ**: key ọhụrụ enweghị ike iketa
ntụgharị ochie na-abụghịzi nke ọhụrụ. Nke ahụ bụ ụkpụrụ #8463 jiri.

```bash
npm run i18n:check-value-drift          # siri ike (nke CI na-agba)
npm run i18n:check-value-drift:warn     # naanị mkpesa
```

## Ntọala Ratchet (`quality-baseline.json`)

## Iwu Ndepụta Ikike

Ọnụ ụzọ nyocha ọ bụla nke na-agaghị ada n’ihi mmebi ndị dịbu adị na-eji ndepụta ikike a kpọchiri akpọchi

enweghị ike idozi ya n’otu PR ahụ.**

Mgbe ị na-agbakwunye ntinye na ndepụta ikike:

1. Tinye nkọwa na-akọwa ihe mere e ji mee ya.
2. Rụtụ aka n’okwu nlekota ahụ (dịka, `// #3498 — Njirimara Phase 2, emebebeghị ya`).
3. Wepụ ntinye ahụ n’otu PR ahụ nke na-edozi mmebi ahụ — ntinye ochie nke na-anaghịzi
   egbochi mmebi na-arụ ọrụ bụkwa ntụpọ (mmanye iwu megide ntinye ochie nke 6A.3 ga-eme ka
   ọnụ ụzọ nyocha ahụ daa n’ihi ntinye ndepụta ikike na-enweghịzi ihe ọ metụtara ozugbo etinyere ya n’ọrụ).

**Etinyela** ntinye na ndepụta ikike iji mee ka ule gafee ngwa ngwa. Ọnụ ụzọ nyocha na-acha akwụkwọ ndụ ebe
ndepụta ikike na-aga n’ihu na-eto eto na-enye echiche ụgha banyere ịdịmma.

### Mgbe ọnụ ụzọ nyocha dara na PR gị

1. **Jiri nlezianya gụọ nsonaazụ ọnụ ụzọ nyocha ahụ** — ọ na-agwa gị kpọmkwem faịlụ ma ọ bụ akara nke
   mebiri iwu ahụ.

   koodu ahụ ziri ezi.
3. **Ọ bụrụ na mmebi ahụ dịbu adị** (ya bụ, ọ bụghị gị webatara ya mana ọnụ ụzọ nyocha ahụ
   amalitela ikpuchi ya): gbakwunye ntinye ndepụta ikike nwere nkọwa ihe kpatara ya na okwu nlekota.
4. **Ọ bụrụ na ọnụ ụzọ nyocha ahụ bụ ratchet** (mkpuchi, ịdọ aka ná ntị ESLint, mmegharị otu ihe ugboro ugboro, mgbagwoju anya):

   mbelata metrik ahụ — mana kọwaa ihe kpatara ya na nkọwa PR.
5. **Ọnụ ụzọ nyocha ndụmọdụ** (`continue-on-error: true`) bụ naanị maka ozi — ha anaghị egbochi
   njikọta mana ha na-apụta na nchịkọta CI. Dozie ha n’agbanyeghị nke ahụ.
