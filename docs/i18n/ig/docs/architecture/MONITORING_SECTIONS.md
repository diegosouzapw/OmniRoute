## Ngalaba Costs (ọhụrụ, ọkwa 1)

Mmalite ụzọ: `/dashboard/costs/`

| Ihe         | URL                                  | Nkọwa                                               |
| ----------- | ------------------------------------ | --------------------------------------------------- |
| Nchịkọta    | `/dashboard/costs`                   | Dashboard ọnụahịa achịkọtara (ewepụrụ na Analytics) |
| Ọnụahịa     | `/dashboard/costs/pricing`           | Tebụl ọnụahịa maka model ọ bụla                     |
| Mmefu Ego   | `/dashboard/costs/budget`            | Oke mmefu ego + ọkwa ịdọ aka ná ntị                 |
| Nkekọ Quota | `/dashboard/costs/quota-share`       | Otu ọdọ mmiri Quota Share + ojiji                   |
| Nhazi Plan  | `/dashboard/costs/quota-share/plans` | Mgbanwe plan maka provider ọ bụla                   |

**Ihe kpatara ya**: Ọnụahịa, Mmefu Ego, na Nkekọ Quota dịbu n'okpuru
`Monitoring > Costs Parameters`. Ịkwaga ha na ngalaba ọkwa elu nke ha
na-eme ka a chọta ha ngwa ngwa n'agaghị ebu ụzọ gafee ngwa nlekọta sistemụ.

## Ngalaba Monitoring (edozigharịrị)

Ngalaba Monitoring nwerezi **Activity n'elu** nke **otu nta 3** na-esochi:

```
Monitoring
├── Activity             ← Ndepụta usoro ihe omume (ihe ọkwa elu)
├── Otu Logs
│   ├── Logs (niile)
│   ├── Proxy Logs
│   └── Console Logs
├── Otu Audit
│   ├── Audit Log
│   ├── MCP Audit
│   └── A2A Audit
└── Otu System
    ├── Health
    └── Runtime
```

### Ihe gbanwere site na nhazi ochie

| Tupu                                                                                   | Mgbe E Mesịrị                                                |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Activity = taabụ dị n'ime Logs nke gosipụtara Audit Log                                | Activity = ndepụta raara onwe ya nye (`/dashboard/activity`) |
| Otu Costs Parameters dị na Monitoring                                                  | Ebugara ya na ngalaba Costs                                  |
| Ndepụta kwụ ọtọ: Logs, Activity (logs), Audit, Health, Runtime, Pricing, Budget, Quota | Nhazi otu 3 + ngalaba Costs raara onwe ya nye                |

## Activity na Audit Log

Ha abụọ dị iche ugbu a:

| Akụkụ                   | Activity (`/dashboard/activity`)                                        | Audit Log (`/dashboard/audit`)               |
| ----------------------- | ----------------------------------------------------------------------- | -------------------------------------------- |
| **Ebumnuche**           | Ndepụta ihe omume maka onye ọrụ ("gịnị mere n'oge na-adịbeghị anya")    | Ndekọ nrubeisi / nchekwa                     |
| **Ebe data si**         | `GET /api/compliance/audit-log?level=high`                              | `GET /api/compliance/audit-log?level=all`    |
| **Ụdị**                 | Usoro oge, ahaziri dịka ụbọchị, ngwaa mmadụ nwere ike ịgụ + akara ngosi | Tebụl juputara, kewara ibe, 50/ibe           |
| **Ihe nzacha**          | Ụdị ihe omume                                                           | Omume, ogo ịdị njọ, onye mere ya, oke ụbọchị |
| **Mbupụ**               | Adịghị                                                                  | Mbupụ JSON                                   |
| **Nzacha onye mere ya** | Anaghị emetụta                                                          | Enwere ike iji onye mere ya zacha            |
| **Ihe omume egosiri**   | Naanị omume ọkwa elu (ndepụta ndị anabatara)                            | Ihe omume audit niile                        |

### Ndepụta omume ọkwa elu ndị anabatara

A kọwara ya na `src/lib/audit/highLevelActions.ts`. Ọ na-achịkwa ihe omume ndị
ga-apụta na ndepụta Activity. Ndepụta ndị anabatara gụnyere:

- Ihe omume ịgbakwunye/iwepụ/inwale provider
- Ịmepụta/imelite/ihichapụ combo
- Usoro ndụ API key (ịmepụta, ịkagbu, ịtụgharị)
- Iru oke mmefu ego
- Mbanye/ọpụpụ auth
- Mmepụta session nke cloud agent
- Ndebanye aha ngwa MCP
- Ịmepụta/ihichapụ webhook
- Mgbanwe ọdọ mmiri/plan quota (`quota.*` actions, Group B)
- Ihe omume platform (mmelite, ibuga)
- Ịwụnye/iwepụ skill

Ihe omume ndị na-adịghị na ndepụta a na-apụta naanị na Audit Log.

### Ịgbakwunye omume ọkwa elu ọhụrụ

Dezie `src/lib/audit/highLevelActions.ts` ma tinye eriri action ahụ na
`HIGH_LEVEL_ACTIONS`. Nke a chọrọ PR (ndepụta ahụ bụ code, enweghị ike ịhazi ya
site na DB). Enwere ike ịgbakwunye akara ngosi kwekọrọ na ya na
`src/lib/audit/activityIcons.ts`.

## Ntụgharị ụzọ: `/dashboard/logs/activity`

A na-atụgharị ụzọ ochie `/dashboard/logs/activity` kpamkpam (HTTP 308) gaa na
`/dashboard/activity` site na `permanentRedirect()` dị na
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

A ka na-edobe ID ogwe akụkụ ochie `logs-activity` na `HIDEABLE_SIDEBAR_ITEM_IDS`
(mana ewepụla ya na `SIDEBAR_DEFINITIONS`) iji zere imebi preset ndị ọrụ
na-arụtụ aka na ID ochie ahụ.
