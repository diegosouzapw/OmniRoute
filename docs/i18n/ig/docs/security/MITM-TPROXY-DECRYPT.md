Mgbasa koodu nzuzo doro anya nke TPROXY bụ **ụzọ njide nke 5** nke OmniRoute maka nchịkọta MITM nke
[Traffic Inspector](../frameworks/TRAFFIC_INSPECTOR.md) / [AgentBridge](../frameworks/AGENTBRIDGE.md).
Ọ na-egbochi ma **na-ewepụ koodu nzuzo** na okporo HTTPS mpaghara na-apụ apụ na Linux
site n’iji TPROXY kernel + ntụgharị ụzọ dabere na amụma — **na-enweghị** imegharị `/etc/hosts` dịka adịgboroja ma
**na-enweghị** ịgbanwe ntọala proxy sistemụ nke OS dum. Ọ dabara maka ịrụ ọrụ na-enweghị interface eserese
(enweghị ndezi DNS a ga-ehichapụ), iwu firewall ya na-ehichapụkwa onwe ha mgbe e bidoro sistemụ ọzọ.

N’adịghị ka ụzọ njide ndị ọzọ, TPROXY achọghị nhazi pụrụ iche maka host ọ bụla: ọ na-egbochi n’ụzọ doro anya
host ebe aga **ọ bụla** na port ebumnuche, na-akwụsị TLS site na
asambodo leaf ọ na-enye ozugbo maka aha host SNI ọ bụla, na-ejide mgbanwe ozi e wepụụrụ
koodu nzuzo, ma tinyeghachi koodu nzuzo n’arịrịọ ahụ tupu iziga ya n’ebe mbụ e bu n’obi.

> **Naanị Linux, naanị root, a ga-ahọrọ ya n’onwe.** Ụzọ a chọrọ Linux, addon native
> nke e ji toolchain C wuo, yana ikike **CAP_NET_ADMIN** (nke na-abụkarị root). E tinyere ya
> n’azụ API AgentBridge nke na-arụ naanị na loopback, ma gbanyụọ ya na ndabara. CA
> MITM a tụkwasịrị obi nke nwere ike ịbịanye aka maka host ọ bụla bụ ikike dị ike — lee [§6 Nche](#6-security).

**Isi mmalite:** `src/mitm/tproxy/`
**Ụzọ API:** `GET / POST / DELETE /api/tools/agent-bridge/tproxy`

## §1 Ihe ọ bụ na mgbe e kwesịrị iji ya

Ụzọ njide anọ ndị ọzọ nwere oke nke ọ bụla:

| Ụzọ               | Otu e si eduzi okporo                                              | Oke                                               |
| ----------------- | ------------------------------------------------------------------ | ------------------------------------------------- |
| AgentBridge       | Imegharị DNS `/etc/hosts` dịka adịgboroja maka otu host a kara aka | naanị host IDE-agent ndị e debanyere aha          |
| Host Ahaziri      | Imegharị DNS `/etc/hosts` dịka adịgboroja maka host ọ bụla         | otu ntinye maka host ọ bụla; sudo iji dezie hosts |
| HTTP_PROXY        | env `HTTP_PROXY`/`HTTPS_PROXY`                                     | naanị ngwa ndị na-asọpụrụ env var                 |
| Proxy sistemụ dum | Ntọala proxy OS                                                    | na-agbanwe ọnọdụ zuru ụwa ọnụ; chọrọ iweghachi ya |

Kama nke ahụ, mgbasa koodu nzuzo doro anya nke TPROXY na-eduzi okporo na ọkwa **kernel**. Ọ
na-etinye akara na njikọ TCP mpaghara ọhụrụ na-apụ apụ gaa na port ebumnuche (ndabara bụ `443`) n’ime
chain `mangle OUTPUT`; `ip rule` na-atụgharị ngwugwu e tinyere akara ka e nyefee ha n’ime mpaghara,
ma mgbe ha batara ọzọ, target `TPROXY` nke `mangle PREROUTING` na-enyefe ha n’aka
listener **IP_TRANSPARENT** — nke na-akwụsị TLS ma jide ederede nkịtị ahụ.

Jiri ya mgbe ịchọrọ ijide ma wepụ koodu nzuzo n’okporo sitere na process nke:

- na-ekwurịta okwu na host AgentBridge na-edebanyeghị aha, ma
- anaghị asọpụrụ `HTTP_PROXY`, ma
- ị chọghị iji mgbanwe proxy nke sistemụ dum kpaghasịa ya.

N’ihi na mgbochi ahụ na-eme n’ime kernel, process malitere njikọ ahụ achọghị **mgbanwe
nhazi ọ bụla** — mana process ahụ ga-atụkwasị CA dynamic nke OmniRoute
wụnyere obi (lee [§4](#4-the-per-sni-dynamic-ca-and-trust-store-installer)).

## §3 Native addon IP_TRANSPARENT

Module `net` nke Node enweghị ike ime `setsockopt(IP_TRANSPARENT)` _tupu_ `bind()`, nke
TPROXY chọrọ (ma ọ bụghị ya, kernel ga-atụfu packet ndị e redirectere). Addon ahụ
(`src/mitm/tproxy/native/transparent.c`, nke e ji `binding.gyp` wuo) bụ obere module N-API
nke na-ekpughe function atọ, nke a na-eji site na `transparentSocket.ts`:

| Function addon                        | Ọrụ socket                                                                                      | Ihe e ji ya eme                                                                             |
| ------------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `createTransparentListener(ip, port)` | `socket()` + **SO_REUSEADDR** + **IP_TRANSPARENT** + `bind()` + `listen()`, na-eweghachi raw fd | listener maka transparent capture (Node na-anakwere fd ahụ site na `server.listen({ fd })`) |
| `setSocketMark(fd, mark)`             | `setsockopt` **SO_MARK** n’elu fd dị adị                                                        | igbochi loop (itinye mark na socket nke proxy n’onwe ya)                                    |
| `connectMarked(ip, port, mark)`       | `socket()` + **SO_MARK** **tupu** `connect()` na-adịghị egbochi ọrụ, na-eweghachi fd            | forward upstream e zoro ezo ọzọ (SYN na-ebu mark ahụ)                                       |

A na-agụ ebe mbido izizi site na `socket.localAddress`/`localPort` — TPROXY
na-echekwa ya, ya mere enweghị nchọgharị **SO_ORIGINAL_DST**/NAT.

### Iwu addon ahụ

```bash
npm run build:native:tproxy      # banye na src/mitm/tproxy/native ma mee node-gyp rebuild
                                 # -> native/build/Release/transparent.node
```

- N’oge `npm run build`, `scripts/build/build-tproxy-native.mjs` na-eme `node-gyp
rebuild`. Ọ bụ **naanị maka Linux ma njehie ya anaghị akwụsị usoro ahụ** — toolchain na-adịghị adị ga-eme naanị ka
  capture mode ghara ịdị.
- `assembleStandalone.mjs` na-edepụta `build/Release/transparent.node` n’ime
  standalone bundle; `transparentSocket.ts` na-achọta ya ma n’ebe metụtara module ma
  n’ebe metụtara cwd (`<cwd>/src/mitm/tproxy/native/...`).
- Git na-eleghara `build/` na `prebuilds/` anya — a na-**ewu binary ahụ, anaghị
  etinye ya na commit**.

Loader ahụ na-enyocha, dịka usoro mkpa si dị:
`native/build/Release/transparent.node`, emesịa `native/prebuilds/transparent.node`
(ha abụọ n’ebe metụtara module nakwa n’okpuru `<cwd>/src/mitm/tproxy/`).

## §4 CA di omimi nke SNI ọ bụla na onye nrụnye trust-store

> **Mmelite #6684:** sava static nke AgentBridge (`src/mitm/server.cjs`) na-eji
> otu ụkpụrụ nhazi CA/leaf a ugbu a kama iji naanị otu leaf static
> self-signed. Ọ na-eji ụdị CA **dị iche**
> (`src/mitm/cert/rootCa.ts`, nke echekwara na `<DATA_DIR>/mitm/ca.key`/`ca.crt`)
> ma na-etinye ya n'okpuru oghere trust-store `omniroute-mitm.crt` dịbu adị
> (na-anọchi otu leaf ochie dị ebe ahụ — ọ dịghị mkpa ihichapụ ntụkwasị obi abụọ),
> ma debe ya kpamkpam iche na oghere TPROXY nke ya, `omniroute-tproxy-ca.crt`,
> nke dị n'okpuru. Nrụnye AgentBridge ọhụrụ na-enweta ụdị CA ahụ na-akpaghị aka;
> nrụnye nke tụkwasịrị leaf static ochie obi ga-anọgide na-eji ya ruo mgbe onye
> na-ahụ maka ya họrọ ịbanye site na `MITM_ROOT_CA_ENABLED=true` (lee
> `src/mitm/cert/migration.ts`) — CA MITM a tụkwasịrị obi nke nwere ike ịbịanye
> leaf maka **host ọ bụla** dị ike nke ukwuu karịa leaf fixed-SAN ochie, ya mere
> mgbanwe ahụ anaghị eme n'enweghị ọkwa na nrụnye a tụkwasịrị obi ugbua.

N'akụkọ ihe mere eme, asambodo MITM static nke AgentBridge na-arụ ọrụ naanị
n'ihi na AgentBridge na-eme DNS-spoofing nke otu nchịkọta host **a kapịrị ọnụ**
(nke ejikọtara ugbu a na ụdị dị n'okpuru). TPROXY na-egbochi host **ọ bụla**,
ya mere listener ya ga-eweta leaf ziri ezi maka SNI ọ bụla client rịọrọ — otu
ihe ahụ AgentBridge chọrọ ugbu a maka nchịkọta `MITM_TOOL_HOSTS` zuru ezu
(ndebanye tool 9) kama naanị host antigravity 4.

### CA di omimi (`src/mitm/tproxy/dynamicCert.ts`)

`DynamicCertStore` na-agba CA mpaghara (nke e wuru n'elu dependency `selfsigned`) nke:

- Na-emepụta CA ga-adịte aka site na `generateMitmCa()` (CN `"OmniRoute MITM CA"`,
  oge ịdị ire nke afọ 10, `basicConstraints CA=true` + `keyUsage keyCertSign,cRLSign`,
  RSA bit 2048 / SHA-256).
- Na-enye **leaf maka hostname SNI ọ bụla mgbe achọrọ ya** site na `issueLeafCert()`
  (oge ịdị ire nke otu afọ, `subjectAltName` = host SNI) ma na-echekwa otu
  `tls.SecureContext` n'ime cache maka hostname ọ bụla.
- Na-ewepụta `createSNICallback()` maka sava na-akwụsị TLS (lee [§5](#5-how-decrypt-and-capture-work)).
- Enwere ike iji `existingCa` mepụta ya iji mee ka CA ghara ịgbanwe n'etiti
  restarts (ka ọ ghara ịdị mkpa ịwụnye trust store ọzọ).

Private key nke CA **anaghị apụ n'igwe ahụ ma ọlị**.

### Onye nrụnye trust-store (`src/mitm/tproxy/caTrust.ts`)

Client a na-egbochi ga-atụkwasịrị CA di omimi ahụ obi, ya mere ịmalite capture
mode na-etinye asambodo CA ahụ n'ime trust store nke OS n'okpuru **oghere pụrụ
iche** — `omniroute-tproxy-ca.crt` (constant `TPROXY_CA_CERT_NAME`) — nke e
debere iche na oghere asambodo MITM static (`omniroute-mitm.crt`) ka ha abụọ
ghara idechi ibe ha.

`installTproxyCa(caPem, sudoPassword?)` na-achọpụta anchor directory nke distro
(n'usoro: ụdị Debian buru ụzọ) ma na-agba refresh command kwekọrọ na ya:

| Anchor directory                            | Refresh command          |
| ------------------------------------------- | ------------------------ |
| `/usr/local/share/ca-certificates`          | `update-ca-certificates` |
| `/etc/ca-certificates/trust-source/anchors` | `update-ca-trust`        |
| `/etc/pki/ca-trust/source/anchors`          | `update-ca-trust`        |
| `/etc/pki/trust/anchors`                    | `update-ca-certificates` |

Nrụnye na-ebu ụzọ tinye PEM n'ime temp file, mgbe ahụ, site na ikike dị elu,
na-eji `mkdir -p` mepụta anchor dir, jiri `cp` detuo staged file ahụ n'ime ya,
ma gbaa refresh command. `uninstallTproxyCa()` na-ewepụ naanị oghere ahụ pụrụ
iche (na-ahapụ asambodo MITM static ka ọ dị) ma na-eme refresh — ọ naghị eme
ihe ọ bụla na sistemụ na-abụghị Linux.

A na-agba command niile chọrọ ikike dị elu site na `execFileWithPassword`
(`src/mitm/systemCommands.ts`) — `spawn` nwere **arg arrays, enweghị shell,
enweghị string interpolation** (Iwu Siri Ike #13). Mgbe process ahụ bụ root
(dịka ọmụmaatụ, VPS), target ahụ na-agba ozugbo, ọ dịghịkwa password achọrọ;
na desktop na-abụghị root, a na-ebufe `sudoPassword` site na `sudo -S` na stdin.

> A na-enye `sudoPassword` nke desktop n'ime POST body iji nye ikike maka
> nrụnye trust-store; a na-eleghara ya anya kpamkpam mgbe process ahụ bụ root.

## §5 Otu decrypt na capture si arụ ọrụ

Pipeline ahụ (ha niile dị n'okpuru `src/mitm/tproxy/`):

```
ngwa mpaghara  ──TCP/443──▶  mangle OUTPUT na-etinye akara na njikọ ahụ (fwmark)
                              ip rule → tebụl route mpaghara → lo
                              mangle PREROUTING TPROXY → listener IP_TRANSPARENT (port 8443)
                                  │  captureMode.ts: na-agụ ebe izizi a na-aga site na socket.localAddress
                                  ▼
                              tlsCapture.ts:
                                1. Jiri leaf kwa-SNI (dynamicCert) mechie TLS nke CLIENT
                                2. http.Server dị n'ime na-enyocha plaintext e decryptara
                                3. capture → globalTrafficBuffer.push() nwere source: "tproxy"
                                   (etinyere sanitizeHeaders + maskSecret)
                                4. ziga ya n'ebe izizi a na-aga ka e mechara RE-encrypt ya
                                   site na socket nwere bypass mark (connectMarked, anti-loop)
                                  │
                                  ▼
                              upstream izizi (api.example.com)
```

- **Nkwụsị TLS** (`createTlsCaptureServer`): na-etinye socket raw e jidere n'ime
  `tls.TLSSocket` nke akụkụ server site n'iji callback SNI nke dynamic CA,
  wee nyefee stream e decryptara n'aka `http.Server` dị n'ime (usoro MITM
  termination a na-ejikarị eme ihe). `MITM_IDLE_TIMEOUT_MS` na-amachi ogologo
  oge socket ga-adị ndụ ka tunnel kwụsịrị ịrụ ọrụ ghara ime ka file descriptors gwụ.
- **Capture** (`handleDecryptedRequest`): na-etinye `InterceptedRequest` nwere
  `source: "tproxy"`, status na-amalite na `"in-flight"`, headers ndị ebufere na
  `sanitizeHeaders()` na bodies ndị ebufere na `maskSecret()` tupu ha abanye na
  buffer. Mgbe ahụ, a na-emelite entry ahụ site na response, sizes, na latency.
- **Nzipụ e re-encryptara** (`createForward` / `realForward`): na-emegharị encryption
  tupu iziga ya n'ebe izizi a na-aga. `rejectUnauthorized` na-eji **`true`** dịka
  ndabara (nchekwa dịka ndabara) — a na-enyocha cert nke upstream megide SNI/Host
  client rịọrọ, ya mere proxy na-ajụ kpọmkwem ihe client izizi ga-ajụ.

### Mgbochi loop (SO_MARK)

N'ihi na rules na-etinye akara na njikọ outbound mpaghara ọhụrụ, nzipụ proxy ahụ
n'onwe ya e re-encryptara ga-adịkarị ka a ga-ejide ya ọzọ — nke ga-ebute loop na-enweghị
njedebe. Forward path na-eji bypass socket mark (**SO_MARK**) echebe onwe ya pụọ na nke a:

- `realForward` na-emepe upstream socket ya site na `connectMarked(ip, port, DEFAULT_BYPASS_MARK)`
  — `DEFAULT_BYPASS_MARK = 0x539` — nke na-edobe **SO_MARK** **tupu** `connect()`,
  ka SYN nke forward ahụ buru bypass mark.
- Rule `mangle OUTPUT` na-ewepụ njikọ ndị nwere bypass mark ugbua
  (`-m mark ! --mark <bypassMark>`), ya mere a **gaghị** etinye akara ọzọ na forward
  nke proxy ma ọ gaghị alaghachi na TPROXY.

> Nkọwa implementation: a ga-etinyerịrị socket nwere bypass mark na
> `createConnection` nke agent ahụ (`https.request({ createConnection })` anaghị eme
> ihe n'amaghị ama mgbe agent dị), ma ọ bụghị ya, forward ahụ ga-emepe socket na-enweghị
> akara, loop ahụ alọghachikwa. Nke a bụ ndozi anti-loop e2e kwadoro.

## §7 Itinye / iweghachi firewall n'ụzọ transactional

Ọdịda usoro ekwesịghị ịhapụ iwu `mangle` ma ọ bụ route ochie mgbe ọ bụla. Onye na-ewulite command
(`src/mitm/tproxy/commands.ts`) na onye na-agba ya (`src/mitm/tproxy/setup.ts`) na-ekwe nkwa na
**revert bụ kpọmkwem inverse nke apply, n'usoro ntụgharị**.

`applyTproxy(cfg)` na-agba command apply n'usoro; mgbe ọdịda **ọ bụla** mere, ọ na-agba
`revertTproxy(cfg)` zuru ezu dịka o nwere ike ma tụpụkwa njehie ahụ ọzọ — ya mere, a ga-etinye
firewall n'ụzọ zuru ezu ma ọ bụ weghachite ya n'ụzọ zuru ezu, ọ gaghị abụ nke etinyere ọkara. `revertTproxy(cfg)` na-agba
command inverse n'usoro ntụgharị ma na-eleghara ọdịda anya (ọ bụ idempotent — ọ dị nchebe ịkpọ ya
n'enweghị ọnọdụ ọ bụla, dịka ọmụmaatụ, site na nhicha AgentBridge `repairMitm()`).

`validateTproxyConfig(cfg)` na-agba tupu command ọ bụla: ports ga-adị n'etiti `1–65535`,
`mark`/`routeTable`/`bypassMark` ga-abụrịrị integer dị mma, `bypassMark` aghaghịkwa
ịdị iche na `mark` (mgbochi loop).

### Command apply (n'usoro)

```bash
ip rule add fwmark <mark> lookup <routeTable>
ip route add local 0.0.0.0/0 dev lo table <routeTable>
iptables -t mangle -A OUTPUT -p tcp --dport <dport> -m mark ! --mark <bypassMark> -j MARK --set-mark <mark>
iptables -t mangle -A PREROUTING -p tcp --dport <dport> -m mark --mark <mark> -j TPROXY --on-port <onPort> --tproxy-mark <mark>
```

Revert na-ehichapụ ha n'usoro ntụgharị: `PREROUTING -D`, `OUTPUT -D`, `ip route del`, `ip rule del`.

> Usoro a dabere na **OUTPUT** n'ihi na ọnọdụ ojiji MITM bụ traffic outbound nke dị _local_
> (ngwa dị n'otu host ahụ), nke TPROXY dị naanị na `PREROUTING` anaghị
> ahụ — `PREROUTING` na-ahụ naanị traffic ebufere. Chain `OUTPUT` na-etinye mark na connection
> local ọhụrụ, `ip rule` na-emegharị ụzọ ha gaa na nnyefe local (`lo`), mgbe ahụ
> `PREROUTING` na-ekenye ha listener transparent ahụ.

## §8 Nhazi

Arịrịọ mmalite (`POST /api/tools/agent-bridge/tproxy`) na-anabata
field ndị na-esonụ, nke `StartTproxyBodySchema` (`tproxy/route.ts`) na-enyocha. Ha niile bụ nhọrọ
ma jiri default ha ma ọ bụrụ na enyeghị ha:

| Field            | Ụdị                | Default  | Nkọwa                                                                                                                  |
| ---------------- | ------------------ | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| **dport**        | int (1–65535)      | `443`    | Port TCP njedebe a ga-ejide n'ụzọ transparent                                                                          |
| **mark**         | int (≥1)           | `0x2333` | Mark firewall edobere na `OUTPUT`, nke `ip rule` + `PREROUTING` na-adakọrịta                                           |
| **onPort**       | int (1–65535)      | `8443`   | Port nke listener transparent (**IP_TRANSPARENT**) na-ejikọta na ya                                                    |
| **routeTable**   | int (≥1)           | `233`    | Id table policy-routing nke nwere route `local 0.0.0.0/0`                                                              |
| **bypassMark**   | int (≥1, ≠ `mark`) | `0x539`  | Mark socket bypass (**SO_MARK**) nke proxy na-edobe na connection upstream nke ya; ewepụ ya na `OUTPUT` (mgbochi loop) |
| **sudoPassword** | string             | —        | Naanị desktop na-abụghị root: na-enye ikike ịwụnye trust-store; a na-eleghara ya anya mgbe ọ bụ root                   |

Enweghị **environment variables ọ bụla** maka TPROXY — nhazi niile sitere na
body POST ma ọ bụ default ndị dị n'elu.

## §10 Ịchọpụta na idozi nsogbu

### Agbanyụrụ toggle ahụ

Enweghị ike ibunye native addon ahụ. Kwenye na: ị nọ na Linux, ị wulitere addon ahụ
(`npm run build:native:tproxy`), nakwa na process ahụ nwere ike ibunye `transparent.node`.
`isTransparentSocketAvailable()` na-achịkwa toggle ahụ; `GET /api/tools/agent-bridge/tproxy`
na-eweghachi `available: false` mgbe addon ahụ na-efu.

### Ọ dịghị ihe e jidere

- Kwenye na process a na-ejide na-ejikọta n'ezie na `dport`
  ahaziri (ndabara bụ `443`).
- Kwenye na process ahụ tụkwasịrị CA na-agbanwe agbanwe obi. A na-etinye CA ahụ dị ka
  `omniroute-tproxy-ca.crt`; ngwa nwere ụlọ nchekwa ntụkwasị obi nke ha (Firefox/Chrome NSS)
  nwere ike ịchọ ka agbakwụnye cert ahụ n'ebe ahụ kwa.
- Gbaa nnwale onwe **Diagnose** nke AgentBridge (lee
  [`AGENTBRIDGE.md`](../frameworks/AGENTBRIDGE.md)) maka nyocha ntụkwasị obi cert / ọnọdụ
  server.

### Iwu firewall ochie fọdụrụ mgbe crash gasịrị

`revertTproxy()` bụ kpọmkwem ntụgharị nke apply ma bụrụ idempotent. Ịkwụsị
mode ahụ na-eweghachite iwu ndị ahụ; ọ bụrụ na e gburu OmniRoute n'etiti nnọkọ, jiri omume
**Repair** nke AgentBridge (`POST /api/tools/agent-bridge/repair`) iji kagbuo ọnọdụ system
ahapụrụ n'enweghị onye na-elekọta ya (DNS spoof, root CA, system proxy). Iwu `mangle` nke TPROXY na route ahụ
na-ekpochapụkwa onwe ha mgbe e mere reboot.

### Loop na-enweghị njedebe / proxy ahụ na-ejide forward nke ya

Nke a bụ ọnọdụ anti-loop. Kwenye na `bypassMark` dị iche na `mark` (validation
na-amanye nke a) nakwa na forward ahụ na-eji `connectMarked` (ọ na-eji ya na `realForward`).
Lee [§5 Anti-loop](#anti-loop-so_mark).
