> **Kụchie okporoụzọ na-apụ apụ n'otu ezinụlọ IP — `auto`, `ipv4`, ma ọ bụ `ipv6` — maka proxy ọ bụla, ka egress nke bụ naanị IPv6 ghara ịlaghachi na IPv4 na nzuzo.**

> **Isi mmalite nke eziokwu:** `open-sse/utils/proxyFamily.ts`, `open-sse/utils/proxyDispatcher.ts`, `open-sse/utils/proxyFetch.ts`, `open-sse/utils/socksConnectorWithFamily.ts`, `open-sse/utils/proxyFamilyResolve.ts`, `src/shared/validation/schemas.ts`, `src/lib/db/proxies.ts`, `src/lib/db/upstreamProxy.ts`, `src/lib/db/migrations/099_proxy_family.sql`

OmniRoute na-enye proxy ọ bụla ohere ịnwe **ntụziaka ezinụlọ adreesị maka egress**. Na ndabara, OS na-ahọrọ IPv4 ma ọ bụ IPv6 (dual-stack, "Happy Eyeballs"). Mgbe ị debere ntụziaka ahụ ka ọ bụrụ `ipv4` ma ọ bụ `ipv6`, OmniRoute na-akụchi njikọ ọ bụla na-agafe na proxy ahụ n'ezinụlọ ahọrọ ma **jụ njikọ kpamkpam** kama ịlaghachi n'ezinụlọ nke ọzọ.

Ibe a na-akọwa ihe ntụziaka ahụ bụ, ihe mere o ji dị, ebe ị ga-ahazi ya, na otu runtime si ekpebi ya.

## Ihe Ọ Bụ

Proxy ọ bụla dị na ndekọ ahụ nwere field `family` nwere ụkpụrụ atọ enwere ike iji, nke Zod enum na-enyocha:

```ts
// src/shared/validation/schemas.ts
family: z.enum(["auto", "ipv4", "ipv6"]).optional().default("auto"),
```

Field ahụ na-eji `"auto"` dịka ndabara, nke na-echekwa omume dual-stack e nwere na mbụ. Ido ya ka ọ bụrụ `ipv4` ma ọ bụ `ipv6` na-akụchi ezinụlọ njikọ maka proxy ahụ.

A na-ahazigharị ntụziaka ahụ n'ebe niile site n'otu helper ka ụkpụrụ ọ bụla a na-amaghị wee ghọọ `auto`:

```ts
// open-sse/utils/proxyFamily.ts
export type ProxyFamily = "auto" | "ipv4" | "ipv6";

export function parseProxyFamily(value: unknown): ProxyFamily {
  return value === "ipv4" || value === "ipv6" ? value : "auto";
}
```

## Ihe Mere O Ji Dị

E webatara ya na PR [#3777](https://github.com/diegosouzapw/OmniRoute/pull/3777). Nsogbu ndị kpaliri ya:

| Nsogbu                                        | Ihe ntụziaka ahụ na-edozi                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Egress nke bụ naanị IPv6 na-asọba na IPv4** | Mgbe host proxy nwere ma ndekọ A ma ndekọ AAAA (ma ọ bụ OS na-ahọrọ IPv4), Happy Eyeballs nwere ike iji IPv4 kpọọ njikọ na-apụ apụ ọbụna mgbe ebumnuche gị bụ okporoụzọ nke bụ naanị IPv6. Ịkụchi `ipv6` na-ewepụ nsọpụta ahụ.                                                                                                                        |
| **Ịkagbu n'ihi nsogbu egress a na-ekekọrịta** | Ndị na-eweta ọrụ na-agbanwe agbanwe (codex/openai) na-akagbu token mgbe ọtụtụ account na-apụ site na **otu** IP n'ogo dị elu. Ịchịkwa ezinụlọ egress bụ akụkụ nke idebe account n'okporoụzọ egress dị iche iche, nke a pụrụ ibu amụma (lee [`src/lib/proxyEgress.ts`](../../src/lib/proxyEgress.ts) maka nyocha IP egress ndị na-arụkọ ọrụ na nke a). |
| **Egress a kara aka maka nrubeisi/nwale**     | Mgbe ị ga-ekwe nkwa na traffic na-apụ site n'otu ezinụlọ akọwapụtara, `auto` ezughị.                                                                                                                                                                                                                                                                  |

E ji ụma mee ka ntụziaka ahụ bụrụ **maka proxy ọ bụla**, ọ bụghị nke zuru ụwa ọnụ — proxy dị iche iche n'ime pool gị nwere ike inwe atumatu dị iche iche.

`ProxyRegistryManager.tsx` na-emepụta njikwa ahụ (etinyere ya na `proxy/ProxyPoolTab.tsx`).

### API

Field `family` bụ akụkụ nke payload ndị e ji emepụta/emelite proxy registry, nke `createProxyRegistrySchema` / `updateProxyRegistrySchema` (`src/shared/validation/schemas.ts`) na-enyocha ma `POST` / `PATCH /api/v1/management/proxies` na-ahazi:

```bash
# Mepụta proxy nke na-eji naanị IPv6
curl -X POST http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{
    "name": "IPv6 egress",
    "type": "socks5",
    "host": "proxy.example.com",
    "port": 1080,
    "family": "ipv6"
  }'

# Gbanwee proxy dị adị ka ọ jiri naanị IPv4
curl -X PATCH http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{ "id": "proxy-uuid-here", "family": "ipv4" }'
```

A na-anabatakwa otu field ahụ n'ime inline proxy config object a na-eji maka upstream-proxy entries (`upstream_proxy_config.family`, lee [Ụdị Data](#data-model)).

Maka akụkụ ndị ọzọ nke API CRUD/assignment nke proxy, lee [PROXY_GUIDE.md](../ops/PROXY_GUIDE.md).

## Otu `auto` Si Ekpebi Ụdị IP

Mgbe `family` bụ `auto`, OmniRoute **anaghị** agbakwunye directive ọ bụla — a na-eji URL proxy ahụ otu ọ dị, a na-ekpebikwa ụdị IP njikọ ahụ n'onwe ya.

N'oge a na-ewu URL (`proxyConfigToUrl` / `normalizeProxyUrl` na `open-sse/utils/proxyDispatcher.ts`), proxy `auto` na-ewepụta URL nkịtị na-enweghị marker:

```ts
// open-sse/utils/proxyDispatcher.ts
const fam = parseProxyFamily(config.family);
const normalized = normalizeProxyUrl(proxyUrlStr, "context proxy", {
  allowSocks5,
});
return fam === "auto" ? normalized : `${normalized}?family=${fam}`;
```

N'oge dispatch (`resolveDispatcherFamily`), `auto` na-aghọ ụdị IP dị n'ime IP-literal host ahụ, ma ọ bụ `null` (ka OS kpebie) maka hostname:

```ts
// open-sse/utils/proxyDispatcher.ts
function resolveDispatcherFamily(parsed: URL): 4 | 6 | null {
  const directive = parseProxyFamily(parsed.searchParams.get("family") ?? undefined);
  const literal = detectIpLiteralFamily(parsed.hostname);
  if (directive === "auto") return literal; // null maka hostname → OS na-ahọrọ
  // ...
}
```

Ya mere:

- `auto` + IP-literal host (`192.0.2.1` / `[2001:db8::1]`) → ụdị IP nke literal ahụ.
- `auto` + hostname → `null` → mkpebi dual-stack ọkọlọtọ nke OS.

## Otu E Si Amanye `ipv4` / `ipv6`

Ntụziaka na-abụghị `auto` na-aga dị ka otu akara ajụjụ arụpụtara — `?family=ipv4` ma ọ bụ `?family=ipv6` — nke a na-agbakwunye naanị otu ugboro na URL proxy ahaziri nke ọma. `normalizeProxyUrl` na-akpachapụ anya iwepụ ma tinyeghachi akara a naanị otu ugboro ka ọ ghara imebi nyocha port ma ọlị.

Mgbe a na-ewu dispatcher, a na-agụ akara ahụ ma gbanwee ya ka ọ bụrụ connect family doro anya. Ọ bụrụ na host ahụ bụ IP literal nke family **na-abụghị** nke ahọpụtara, OmniRoute na-atụpụ njehie (mgbe enwere esemokwu, ọ na-emechi kpamkpam):

```ts
// open-sse/utils/proxyDispatcher.ts
const want = directive === "ipv6" ? 6 : 4;
if (literal !== null && literal !== want) {
  throw new Error(
    `[ProxyDispatcher] Proxy family directive ${directive} contradicts ${literal === 6 ? "IPv6" : "IPv4"} literal host`
  );
}
```

A na-akpọgidezi family ahụ doro anya na connector:

- **Proxy HTTP/HTTPS** (`ProxyAgent`): `proxyTls: { family, autoSelectFamily: false }` — nke a na-agbanyụ Happy Eyeballs ka ọ bụrụ naanị family ahọpụtara ka a na-akpọ njikọ ya.
- **Proxy SOCKS5**: connector pụrụ iche na-ebufe `socket_options: { family, autoSelectFamily: false }` n'ime client SOCKS (lee [Ndakọrịta SOCKS5](#socks5-compatibility)).

## Ndakọrịta SOCKS5

Ịkpọgide family na-arụ ọrụ na proxy SOCKS5, mana `fetch-socks` nkịtị anaghị ewepụta nhọrọ socket ndị achọrọ iji kpọgide family nke proxy hop. OmniRoute na-eweta connector nke ya maka nke ahụ:

```ts
// open-sse/utils/socksConnectorWithFamily.ts
export function buildSocksFamilySocketOptions(family: 4 | 6 | null): Record<string, unknown> {
  if (family === 6) return { family: 6, autoSelectFamily: false };
  if (family === 4) return { family: 4, autoSelectFamily: false };
  return {};
}
```

Dispatch SOCKS5 niile na-agafe na `createSocksDispatcherWithFamily` n'agbanyeghị `family` (gụnyere `null` / `auto` site na hostname): `buildSocksFamilySocketOptions(null)` na-ewepụta `{}`, a na-ejikwa otu ụzọ `SocksClient.createConnection` + TLS `buildConnector` ahụ yana ịkpọgide `socket_options`, ka Happy Eyeballs ghara ịhọrọ IPv4 maka iwu egress nke na-anabata naanị IPv6.

Nkwado SOCKS5 n'onwe ya na-arụ ọrụ na ndabara (ị nwere ike ịpụ na ya site na `ENABLE_SOCKS5_PROXY=false`); lee [PROXY_GUIDE.md → Environment Variables](../ops/PROXY_GUIDE.md#environment-variables).

## Omume Imechi Kpamkpam Mgbe E Nwere Nsogbu

Ebumnuche niile nke ntụziaka ahụ bụ **ịjụ** kama ịlaghachi na nzuzo n'iji family na-ezighi ezi. Ihe nche abụọ na-amanye nke a:

1. **Esemokwu literal** — ntụziaka nke na-emegide host IP-literal na-atụpụ njehie n'oge a na-ewu dispatcher (`resolveDispatcherFamily`, nke egosiri n'elu).

2. **Nnyocha DNS tupu ojiji maka hostname** — maka proxy hostname nwere family akpọgidere, `proxyFetch.ts` na-enyocha na hostname ahụ nwere record n'ezie n'ime family achọrọ **tupu** egress, site na `assertHostnameSupportsFamily`:

   ```ts
   // open-sse/utils/proxyFamilyResolve.ts
   const hasFamily = records.some((r) => r.family === family);
   if (!hasFamily) {
     throw new Error(
       `[ProxyFamily] Proxy host ${host} has no ${family === 6 ? "IPv6 (AAAA)" : "IPv4 (A)"} record; ` +
         `refusing ${family === 6 ? "IPv6" : "IPv4"}-only egress (fail-closed)`
     );
   }
   ```

   Mgbe ọ dara, `proxyFetch.ts` na-etinye akara `code = "PROXY_FAMILY_UNAVAILABLE"` na `statusCode = 503` na njehie ahụ. A na-emesokwa ọdịda mkpebi DNS dị ka ọnọdụ imechi kpamkpam (ịjụ ime egress).

Host IP-literal anaghị eme ihe ọ bụla na nnyocha DNS tupu ojiji — family ha dị n'ime ha n'onwe ya, ya mere ọchụchọ adịghị mkpa.

## Ụdị Data

E tinyere kọlụm `family` site na migration `099_proxy_family.sql` n'ime tebụl **abụọ**:

```sql
-- src/lib/db/migrations/099_proxy_family.sql
ALTER TABLE proxy_registry ADD COLUMN family TEXT NOT NULL DEFAULT 'auto';
ALTER TABLE upstream_proxy_config ADD COLUMN family TEXT NOT NULL DEFAULT 'auto';
```

- `proxy_registry.family` — ntuziaka proxy nke ọ bụla maka ndenye registry (`src/lib/db/proxies.ts`). Ajụjụ mkpebi na-ahọrọ `family` yana kọlụm proxy ndị ọzọ, a na-agbanwekwa uru na-adịghị adị ma ọ bụ nke na-abụghị string ka ọ bụrụ `"auto"`.
- `upstream_proxy_config.family` — ntuziaka maka ndenye upstream-proxy (`src/lib/db/upstreamProxy.ts`), nke nwekwara `"auto"` dịka uru ndabara.

Mgbe proxy object e kpebiri nwere `family` na-abụghị `auto`, `proxyConfigToUrl` na-agbakwunye akara `?family=` ka ntọala ahụ wee ruo dispatcher n'enweghị mgbanwe.
