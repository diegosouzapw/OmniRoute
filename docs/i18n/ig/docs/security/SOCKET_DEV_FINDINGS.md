## §1 — Ntinye root-CA maka MITM (`77484.js`)

**Faịlụ koodu isi mmalite**:

- `src/mitm/cert/install.ts` — `installCert()` / `uninstallCert()` ọha,
  na `installCertWindows/Mac/Linux` nke nyiwe ọ bụla.
- `src/mitm/systemCommands.ts` — enyemaka `execFile` / `spawn` / PowerShell
  ndị ụzọ ntinye ahụ na-ejikọta iji.

**Ihe na-akpalite ya**: onye ọrụ pịa "Kwado MITM proxy" na dashboard mpaghara dị na
`/dashboard/cli-tools/mitm`. Route ahụ bụ naanị maka loopback — lee iwu siri ike #17 na
`CLAUDE.md` na `src/server/authz/routeGuard.ts::isLocalOnlyPath()`. JWT
agbapụtara site na tunnel **enweghị ike** ịkpalite ụzọ koodu a.

**Ọrụ chọrọ ikike dị elu a na-arụ (maka nyiwe ọ bụla)**:

| OS                     | Iwu                                                                                                               |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Windows                | `certutil -addstore Root <cert>` site na UAC                                                                      |
| macOS                  | `sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain <cert>`                     |
| Linux                  | `sudo cp <cert> <distro-trust-dir>` + `sudo update-ca-certificates` (Debian) / `sudo update-ca-trust` (RHEL/SUSE) |
| Linux+Firefox/Chromium | mmelite NSS DB nke profaịlụ ọ bụla site na `certutil -d sql:<profile>`                                            |

Ndị a bụ otu iwu ndị `mitmproxy`, Charles Proxy, Fiddler, na
Caddy na-eji. E dere eziokwu na ha dị na OmniRoute na
`docs/security/STEALTH_GUIDE.md`.

**Usoro mbelata ihe ize ndụ nke v3.8.6**:

- `runElevatedPowerShell()` anaghịzi eji `-EncodedCommand <base64utf16le>`.
  A na-ede payload nwere ikike dị elu n'ime faịlụ `.ps1` nwa oge maka oku ọ bụla (mode 0o600,
  n'ime ndekọ `mkdtempSync` nzuzo), ma jiri `-File` rụtụ aka na ya. A na-ewepụ
  faịlụ ahụ na `finally`. Nke a na-ewepụ akara njirimara a ma ama nke
  ibuli-ikike-site-na-PowerShell-site-na-base64 nke ngwa nhazi AI nke Socket.dev
  kara akara.
- `installCertWindows` nwere ngọngọ `SECURITY-AUDITOR-NOTE:` n'ime koodu
  nke na-arụtụ aka ebe a.

**Ihe mere anyị ji debe ya**: MITM proxy bụ atụmatụ e dere nkọwa ya nke
`docs/security/STEALTH_GUIDE.md` na `docs/frameworks/MITM-PROXY.md` na-eji. Iwepụ
ya ga-emebi atụmatụ agent-bridge.

## §2 — Mbubata nzere Zed (`app/api/providers/zed/import/route.js`)

**Faịlụ isi mmalite**:

- `src/app/api/providers/zed/discover/route.ts` _(ọhụrụ na v3.8.6)_
- `src/app/api/providers/zed/import/route.ts`
- `src/lib/zed-oauth/keychain-reader.ts`
- `src/lib/zed-oauth/credentialFingerprint.ts` _(ọhụrụ na v3.8.6)_

**Ihe na-akpalite ya**: onye ọrụ pịa "Bubata site na Zed" na peeji Providers
nke dashboard mpaghara. `requireManagementAuth` na-echekwa endpoint ahụ. Editọ Zed
n'onwe ya na-edekọ igodo API nke ndị na-eweta ọrụ ya na keychain OS n'okpuru aha ọrụ
e depụtara n'akwụkwọ — lee https://zed.dev/docs/ai/llm-providers.

**Omume v3.8.5 (nke Socket.dev gosipụtara)**:

`POST /import` chọpụtara nzere ndị ahụ ma chekwaa ha ozugbo na nchekwa SQLite
mpaghara n'otu njem arịrịọ-na-azịza. Enweghị nkwenye maka akaụntụ ọ bụla, enweghị
fingerprint, naanị "achọtara token N, a bubatara ha niile."

**Mbelata ihe ize ndụ na v3.8.6 — nkwenye nzọụkwụ 2**:

1. **`POST /api/providers/zed/discover`** na-eweghachi
   `{ candidates: [{ provider, service, account, fingerprint }] }`. A naghị ezipụ
   token izizi ahụ **mgbe ọ bụla**. Fingerprint ahụ bụ
   `sha256(service|account|token).slice(0,16)`.
2. Dashboard ahụ na-egosipụta ndepụta ndị a chọpụtara, onye nchịkwa ahọrọ ndị ọ chọrọ
   ibubata, wee ziga `{ confirmedAccounts: [{ service, account, fingerprint }] }`
   na **`POST /api/providers/zed/import`**.
3. Endpoint mbubata ahụ **na-agụgharị keychain na sava ahụ** ma na-enyocha site na
   `(service, account, fingerprint)`. Nzaghachi discover e mebiri ma ọ bụ e ji ọzọ
   enweghị ike iduhie endpoint mbubata ka ọ chekwaa token na-enweghị njikọ —
   ọ bụrụ na token dị ugbu a agbanweela kemgbe discover, fingerprint agaghịzi
   adaba, a ga-amafekwa nzere ahụ.

Ọkọlọtọ env `OMNIROUTE_ZED_IMPORT_LEGACY_ONE_STEP=true` na-echekwa omume v3.8.5
maka ndị nchịkwa na-emelitebeghị automation ha. A ga-ewepụ ya na v3.9.

**Ihe mere anyị ji debe ya**: Mbubata Zed bụ ụzọ onboarding kacha mfe maka ndị ọrụ
na-eji Zed ugbu a ma chọọ iṅomi igodo ndị na-eweta ọrụ ha n'ime OmniRoute
na-enweghị ịtinyegharị ha.

## §3 — `execFile` / `spawn` / PowerShell nwere ikike dị elu (`21843.js`)

**Faịlụ isi mmalite**: `src/mitm/systemCommands.ts`.

**Ihe mere e ji gosi ya**: chunk ahụ na-ebupụgharị `execFileWithPassword`,
`runElevatedPowerShell`, na helper `quotePowerShell` a na-ekerịta. Classifier AI
nke Socket.dev na-ahụ ha dịka ngwáọrụ izugbe maka "ime ihe na host + ibuli ikike."
N'ime OmniRoute, a na-eji ha naanị n'ụzọ nrụnye asambodo MITM (§1), nakwa site na
`execFileWithPassword` maka ime iwu `sudo`.

**Mbelata ihe ize ndụ na v3.8.6**:

- Nhazigharị `runElevatedPowerShell` (lee §1).
- Blọk `SECURITY-AUDITOR-NOTE:` etinyere ozugbo na
  `runElevatedPowerShell` na `execFileWithPassword` na-akọwa ndị na-akpọ ọrụ ahụ
  nọ na allowlist na ndepụta executable a kpachiri.
- Oku `spawn()` nke `execFileWithPassword` nwere akara `nosemgrep` yana
  allowlist nke executable ndị helper ahụ nwere ikike ịnata — e nweghị
  **ụzọ ọ bụla sitere na ntinye onye ọrụ gaa na `finalCommand`/`finalArgs`**.

## §4 / §6 — Onye nlekọta ọrụ 9router (`api/services/9router/{start,restart}/route.js`)

**Faịlụ isi mmalite**:

- `src/app/api/services/9router/_lib.ts` — factory onye nlekọta.
- `src/app/api/services/9router/{start,stop,restart,status,install,update,auto-start}/route.ts`.
- `src/lib/services/ServiceSupervisor.ts` — spawn izugbe / health-poll / log-buffer.

**Ihe na-akpalite ya**: onye ọrụ pịa "Wụnye" / "Malite" na peeji ọrụ agbakwunyere
n'ime dashboard mpaghara.

**Nchedo ndị dịla adị**:

- Route `/api/services/*` niile bụ LOCAL_ONLY dịka
  `src/server/authz/routeGuard.ts` si dị (iwu siri ike #17). A na-amanye loopback
  tupu nyocha auth ọ bụla — JWT gbapụtara enweghị ike iru ha.
- A na-etinye row DB nke 9router dịka `status='not_installed', auto_start=0` (lee
  `src/lib/db/migrations/071_services.sql:19`). Ọrụ ahụ **anaghị** amalite
  na mmalite mbụ.
- A na-akpọ `spawn()` site na path binary nke
  `resolveSpawnArgs(apiKey, PORT)` weghachiri na `src/lib/services/installers/ninerouter.ts`,
  nke bụ allowlist a kapịrị ọnụ nke binary ndị a na-akwado.
- A na-echekwa stdout/stderr na memory buffer (oke 5 MB, lee `_lib.ts`) — enweghị
  ide ihe na disk belụsọ ma onye ọrụ mee ka logging rụọ ọrụ site na dashboard.

**Mbelata ihe ize ndụ na v3.8.6**: enweghị mgbanwe n'ọrụ. Profaịlụ build kacha nta
(`OMNIROUTE_BUILD_PROFILE=minimal`) na-eji stub dochie
`src/lib/services/installers/ninerouter.ts` maka ndị ọrụ chọrọ ka e wepụ
ụzọ ndị nwere ikike dị elu kpamkpam na bundle ahụ.

**Ihe mere anyị ji debe ya**: 9router bụ ọrụ enyemaka nhọrọ a pụrụ ịwụnye na mpaghara
(chee ya dịka: plugin ụdị WordPress) — a ga-ahọrọrịrị ya n'ụzọ doro anya.

## §5 — Nlaghachite nzere OmniRoute Cloud Sync (`api/keys/[id]/route.js`)

**Faịlụ mmalite**:

- `src/lib/cloudSync.ts` — `syncToCloud()` / `updateLocalTokens()`.
- `src/app/api/keys/[id]/route.ts` — na-akpọ `syncKeysToCloudIfEnabled()`.

**Ihe na-akpalite ya**: `isCloudEnabled()` na-eweghachi `true` (nke e setịpụrụ site na dashboard) **ma**
ahaziela `CLOUD_URL`. Mgbe agbanyụrụ ha abụọ, a naghị akpọ netwọkụ mpụga gaa na
endpoint Cloud.

**Omume v3.8.5 (njehie Socket.dev chọpụtara n'ụzọ ziri ezi)**:

`updateLocalTokens()` dochiri `accessToken`, `refreshToken`, na
`providerSpecificData` site na nzaghachi Cloud mgbe
`cloudUpdatedAt > localUpdatedAt`. Enweghị HMAC, enweghị mbinye aka, enweghị checksum.
`CLOUD_URL` a haziri n'ụzọ na-ezighị ezi ma ọ bụ nke iro (ma ọ bụ MITM nọ na channel ahụ) nwere ike iji nwayọ
gbanwee token OAuth nke provider.

**Usoro mgbochi v3.8.6**:

1. **Nyocha HMAC**: `verifyCloudSignature(rawBody, sigHeader)` na-enyocha
   header `X-Cloud-Sig` (`HMAC-SHA256(OMNIROUTE_CLOUD_SYNC_SECRET,
rawBody)`) tupu a parse JSON. Ọ bụrụ na e setịpụla secret ahụ, mbinye aka ahụ
   bụ iwu. Ọ bụrụ na e setịpụghị ya (ọnọdụ legacy), a na-edekọ ịdọ aka ná ntị ma nabata
   nzaghachi ahụ — secret ahụ ga-abụ iwu na v3.9.
2. **Nkwenye maka field nzuzo**: A na-edegharị `accessToken` / `refreshToken` /
   `providerSpecificData` **naanị** mgbe
   `OMNIROUTE_CLOUD_SYNC_SECRETS=true`. Ọnọdụ ndabara na-emekọrịta naanị
   metadata na-abụghị nzere (`expiresAt`, `status`, `lastError*`,
   `rateLimitedUntil`, `updatedAt`). Nke a bụ **mgbanwe na-emebi ndakọrịta** maka ndị ọrụ
   dabere na mmekọrịta token dịpụrụ adịpụ — ha ga-ekwenyerịrị ya n'ụzọ doro anya.

**Ihe mere anyị ji edobe ya**: Cloud Sync bụ naanị ụzọ onye tenant OmniRoute Cloud
ga-esi chịkọta nzere otu n'otu ebe. Ndozi ahụ na-eme ka threat model doo anya:
"server na-etinye mbinye aka, client na-enyocha, operator na-ekwenye."

## Profaịlụ build: `minimal`

Maka ndị ọrụ chọrọ artifact dakọtara na Socket, jiri nke a mee build:

```bash
OMNIROUTE_BUILD_PROFILE=minimal npm run build
```

Webpack `NormalModuleReplacementPlugin` na-eme alias modul anọ ka ha bụrụ stub:

| Modul                                       | Stub                                             |
| ------------------------------------------- | ------------------------------------------------ |
| `src/mitm/cert/install.ts`                  | `src/mitm/cert/install.stub.ts`                  |
| `src/lib/zed-oauth/keychain-reader.ts`      | `src/lib/zed-oauth/keychain-reader.stub.ts`      |
| `src/lib/cloudSync.ts`                      | `src/lib/cloudSync.stub.ts`                      |
| `src/lib/services/installers/ninerouter.ts` | `src/lib/services/installers/ninerouter.stub.ts` |

Stub ọ bụla na-export otu interface ahụ, mana function ọ bụla na-atụpụ
`featureDisabledError(name)` n'oge runtime. Route ndị dabere na modul agbanyụrụ
na-eweghachi HTTP 503 nwere ozi doro anya kama ịgbalite
ụzọ code ahụ nwere mmetụta pụrụ iche.

Ezubere bundle sitere na ya ka e bipụta ya dịka `omniroute-secure`. Lee
`docs/ops/PUBLISHING_SECURE.md` maka usoro mbipụta.

## Nkewa plọgịn (a na-esochi maka v4)

N’ọdịnihu, anyị bu n’obi ikewa ngwugwu npm ka ọ bụrụ
modul ndị enwere ike inyocha iche iche. Hụ ihe mgbaru ọsọ v4 dị na GitHub issue tracker maka
