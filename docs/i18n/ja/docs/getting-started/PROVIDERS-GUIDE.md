> **要約**: プロバイダーとは、AI サービス（OpenAI、Anthropic、Google など）への接続です。OmniRoute を使用するには、少なくとも 1 つのプロバイダーが必要です。

## プロバイダーとは？

プロバイダーは、**携帯電話会社**のようなものだと考えてください。電話をかけるために携帯電話会社が必要なのと同様に、AI モデルを使用するには AI プロバイダーが必要です。OmniRoute は、**すべての携帯電話会社**に対応する電話のようなもので、プロバイダーを自動的に切り替えられます。

### プロバイダーの種類

| 種類           | 概要                       | 例                                | コスト                 |
| -------------- | -------------------------- | --------------------------------- | ---------------------- |
| **無料**       | 支払い不要                 | Kiro、OpenCode Free、Pollinations | $0                     |
| **API キー**   | API キーが必要             | OpenAI、Anthropic、Google         | 従量課金               |
| **OAuth**      | アカウントでログイン       | Claude Code、GitHub Copilot       | サブスクリプション     |
| **Web Cookie** | ブラウザーセッションを使用 | ChatGPT Web (Codex)、Gemini Web   | $0（アカウントを使用） |

### Web Cookie プロバイダー

一般的なセットアップ手順、制限事項、トラブルシューティング、プロバイダー固有の認証ガイダンスについては、**[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**を参照してください。

## クイックスタート：最初のプロバイダーを接続する

### 初回実行時の無料プロバイダー設定（任意）

初回実行ウィザードには、明示的な**無料プロバイダーを設定**カードがあります。OmniRoute の認証不要プロバイダーレジストリから、現在利用可能な
リストを生成し、確認前に各プロバイダーを確認して選択解除できます。OmniRoute はプロバイダーの注意事項と、そのサイトへのリンクを表示するため、
サードパーティの利用規約、プライバシー、可用性、レート制限を事前に確認できます。

この操作は任意です。ウィザードを完了しても、無料プロバイダー接続が暗黙的に作成されることはありません。
まだ存在しないプロバイダーのみが作成され、既存のカスタマイズ済み接続は
変更されません。また、作成済み、設定済み、失敗したプロバイダーが個別に報告されます。部分的な結果になった場合は、
失敗したプロバイダーのみを安全に再試行できます。

### オプション A：無料プロバイダー（クレジットカード不要）

1. `http://localhost:20128` でダッシュボードを開きます
2. **プロバイダー** → **プロバイダーを追加**に移動します
3. 次の無料プロバイダーのいずれかを選択します：
   - **Kiro AI** — 無料の Claude モデル（認証不要）
   - **OpenCode Free** — 無料の GPT モデル（認証不要）
   - **Pollinations** — 無料の GPT-5、Claude、Gemini（キー不要）
   - **LongCat** — 10M トークンが無料（1 回限りの付与、アカウントと KYC が必要）
   - **Cloudflare AI** — 50 以上のモデル、1 日あたり 10K ニューロン
   - **MLX Gemma 26B** — ローカル Apple Silicon モデル（約 38.5 tok/s、約 15.9GB RAM）
   - **MLX Qwen 3.8 27B** — ローカル Apple Silicon モデル（約 9.1 tok/s、約 13.1GB RAM）
4. **接続**をクリックします
5. 完了です！無料で AI を利用できるようになりました。

### オプション B：API キープロバイダー（有料）

1. プロバイダーの Web サイトから API キーを取得します：
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` でダッシュボードを開きます
3. **プロバイダー** → **プロバイダーを追加**に移動します
4. プロバイダーを選択します
5. API キーを貼り付けます
6. **接続**をクリックします
7. 完了です！そのプロバイダーのモデルを利用できるようになりました。

### オプション C：OAuth プロバイダー（サブスクリプション）

1. `http://localhost:20128` でダッシュボードを開きます
2. **プロバイダー** → **プロバイダーを追加**に移動します
3. プロバイダー（Claude Code、GitHub Copilot など）を選択します
4. **OAuth で接続**をクリックします
5. アカウントでログインします
6. 完了です！サブスクリプションに含まれるモデルを利用できるようになりました。

### オプション D：ローカル MLX モデル（Apple Silicon）

ユニファイドメモリを搭載した Apple Silicon Mac 向けに、OmniRoute は `mlx-lm.server` で実行されるローカル MLX モデルを、通常の OpenAI 互換ローカルプロバイダーとして接続する機能をサポートしています。

#### 前提条件

- **Apple Silicon Mac**（M1/M2/M3/M4）。24GB 以上のユニファイドメモリを推奨
- **uv** パッケージマネージャー：`curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**：`uv pip install mlx-lm`

#### クイックスタート

1. **依存関係をインストールします**：

   ```bash
   # uv がまだインストールされていない場合はインストール
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm をインストール
   uv pip install mlx-lm
   ```

2. **MLX サーバーを手動で起動します**（別々のターミナルで）：

   ```bash
   # ターミナル 1：Gemma 4 26B A4B IT-QAT（ポート 11435）
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ターミナル 2：Qwen 3.8 27B MLX Mixed（ポート 11436）
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ダッシュボードで接続します**：
   - **プロバイダー** → **プロバイダーを追加**に移動します
   - **MLX Gemma 26B**または**MLX Qwen 3.8 27B**を選択します
   - **接続**をクリックします（API キー不要）

4. **OpenCode で使用します**：
   ```bash
   # OmniRoute を使用するように OpenCode を設定
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX モデルを使用
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### メモリ管理

**重要**：24GB のユニファイドメモリでは、一度に実行できる大規模 MLX モデルは**1 つだけ**です。

- Gemma 26B：ピークメモリ約 15.9GB
- Qwen 3.8 27B：ピークメモリ約 13.1GB

これは手動で管理する必要があります：

- 一度に 1 つの MLX サーバーのみを実行する、または
- 別々のマシンで両方を実行する、または
- 一方を停止してから、もう一方を起動する

OmniRoute は MLX サーバープロセスを自動的に管理しません。設定した OpenAI 互換エンドポイントにリクエストをルーティングするだけです。

#### ツール呼び出しのサポート

両方のモデルが OpenAI 互換のツール呼び出しをサポートしています。次の方法でテストしてください：

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### トラブルシューティング

| 問題                     | 解決策                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------- |
| サーバーが起動しない     | `uv run mlx_lm.server --help` を確認し、モデル ID を検証する                           |
| メモリ不足               | 実行するモデルを 1 つだけにし、他のアプリを閉じて、アクティビティモニタを確認する      |
| 接続が拒否される         | サーバーが正しいポート（11435/11436）で実行されていることを確認する                    |
| 応答が遅い               | 最初のリクエストではモデルがメモリに読み込まれる（約30～60秒）。以降のリクエストは高速 |
| ツール呼び出しに失敗する | モデルがツールをサポートしていることを確認し、OmniRoute のログで変換エラーを確認する   |

## 複数のプロバイダーを使用する

OmniRouteは、**複数のプロバイダー**を使用すると最も効果的に機能します。これにより、以下のメリットが得られます。

- **自動フォールバック** — あるプロバイダーでエラーが発生した場合、OmniRouteは次のプロバイダーを試します
- **コスト最適化** — OmniRouteはリクエストごとに最も安価なプロバイダーを選択します
- **速度最適化** — OmniRouteはリクエストごとに最も高速なプロバイダーを選択します
- **品質最適化** — OmniRouteはタスクごとに最適なプロバイダーを選択します

### 推奨構成

最適な環境を実現するには、少なくとも**3つのプロバイダー**に接続してください。

1. **無料プロバイダーを1つ**（Kiro、OpenCode Free、またはPollinations）— 常時利用可能
2. **高速なプロバイダーを1つ**（Groq、Cerebras）— 素早い応答向け
3. **高品質なプロバイダーを1つ**（OpenAI、Anthropic、Google）— 複雑なタスク向け

その後、`model: "auto"`を使用すると、OmniRouteがリクエストごとに最適なプロバイダーを自動的に選択します。

## よくある質問

### 「OmniRouteを使用するには料金がかかりますか？」

**いいえ！** OmniRouteは無料のオープンソースです。無料プロバイダー（Kiro、OpenCode Free、Pollinations）は、料金を一切支払わずに使用できます。有料プロバイダーの使用を選択した場合にのみ料金が発生します。

### 「どのプロバイダーから始めればよいですか？」

**Kiro AI**から始めましょう。無料でAPIキーも不要なうえ、Claudeモデルを利用できます。その後、必要に応じて他のプロバイダーを追加してください。

### 「複数のプロバイダーを同時に使用できますか？」

**はい！** それこそがOmniRouteの目的です。複数のプロバイダーを接続し、`model: "auto"`を使用すると、リクエストごとにOmniRouteが最適なプロバイダーを選択します。

### 「プロバイダーが停止した場合はどうなりますか？」

OmniRouteは、障害が発生したプロバイダーを自動的にスキップし、次のプロバイダーを試します。何もする必要はありません。

### 「プロバイダーの接続を解除するにはどうすればよいですか？」

プロバイダー → 対象のプロバイダーをクリック → **接続解除**をクリックします。

### 「既存のAPIキーを使用できますか？」

**はい！** OpenAI、Anthropic、GoogleなどのAPIキーをすでにお持ちの場合は、OmniRouteで使用できます。プロバイダーへの接続時に貼り付けるだけです。
