> **信頼できる情報源:** `src/lib/agentSkills/`（カタログ、ジェネレーター、パーサー）+ `skills/` ディレクトリ（SKILL.md ファイル）
> **最終更新:** 2026-08-02 — v3.8.50

Agent Skills は、外部エージェント、MCP クライアント、A2A オーケストレーターに OmniRoute の REST API と CLI の使用方法を教える、構造化された SKILL.md ファイルです。[Omni Skills](./SKILLS.md)（OmniRoute 内部で実行される LLM ツール定義）とは異なり、Agent Skills は_ドキュメントカタログ_であり、エージェントのコンテキストに静的な Markdown として直接提供できます。

---

## 概要

このカタログには **45 個の Agent Skills**（REST API 23 個 + CLI 21 個 + 設定ワークフロー 1 個）が含まれています。各スキルには以下があります。

- **正規 ID**（`omni-auth`、`cli-serve` など）
- YAML フロントマター（`name`、`description`）と内容豊富な Markdown 本文を含む、`skills/{id}/SKILL.md` の **SKILL.md** ファイル
- OpenAPI 仕様と CLI レジストリから派生した **REST エンドポイント**（API スキル）または **CLI サブコマンド**（CLI スキル）
- ライブ取得用の **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## アーキテクチャ

```
src/shared/constants/agentSkills.ts    — 45 エントリの選定済みリスト（名前/説明/カテゴリー/領域/アイコン）
src/lib/agentSkills/
  catalog.ts                           — getCatalog()、getSkillById()、filterCatalog()、computeCoverage()
  generator.ts                         — generateAgentSkills() が SKILL.md を skills/{id}/ に書き込む
  openapiParser.ts                     — docs/openapi.yaml から REST エンドポイントを抽出
  cliRegistryParser.ts                 — bin/cli-registry.ts から CLI サブコマンドを抽出
  schemas.ts                           — Zod スキーマ: AgentSkillSchema、SkillCoverageSchema など
  types.ts                             — TypeScript インターフェース: AgentSkill、SkillCoverage など

skills/{id}/SKILL.md                   — 生成済み + 選定済みの Markdown ファイル（合計 45 個）

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw（text/markdown）
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate（認証必須）

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 個の MCP ツール（一覧、取得、カバレッジ）
src/lib/a2a/skills/listCapabilities.ts        — A2A スキル: list-capabilities
```

## SKILL.md の形式

```markdown
---
name: omni-providers
description: "プロバイダー接続を管理します。認証情報の追加、テスト、ローテーション、削除を行います。"
---

<!-- src/lib/agentSkills/generator.ts によって生成されます。手動での編集は上書きされます -->

## 概要

...

## 認証

...

## エンドポイント

...

<!-- skill:custom-start -->

## カスタムセクション（再生成後も保持）

...

<!-- skill:custom-end -->
```

ジェネレーターは、再生成時に `<!-- skill:custom-start -->` と `<!-- skill:custom-end -->` の間の内容を保持します。10 個のスキルには、選定済みのカスタムブロックがあります。

`omni-mcp`、`omni-compression`、`cli-providers`、`cli-eval`、`omni-agents-a2a`、`omni-combos-routing`、`omni-auth`、`omni-resilience`、`omni-inference`、`cli-serve`。

## REST API ディスカバリー

| エンドポイント               | メソッド | 説明                                                            | 認証   |
| :--------------------------- | :------- | :-------------------------------------------------------------- | :----- |
| `/api/agent-skills`          | GET      | カタログ一覧（任意で `?category=api\|cli\|config&area=<area>`） | なし   |
| `/api/agent-skills/{id}`     | GET      | 単一スキルのメタデータを取得                                    | なし   |
| `/api/agent-skills/{id}/raw` | GET      | SKILL.md を `text/markdown` として取得                          | なし   |
| `/api/agent-skills/coverage` | GET      | カバレッジ統計（存在する SKILL.md ファイル数）                  | なし   |
| `/api/agent-skills/generate` | POST     | ジェネレーターを実行（dryRun/prune/onlyIds）                    | 管理用 |

例 — すべての API スキルを一覧表示：

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

例 — 単一の SKILL.md を取得：

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP ディスカバリー

`read:catalog` スコープには、次の 3 つの MCP ツールが登録されています：

| ツール                            | 説明                                                        |
| :-------------------------------- | :---------------------------------------------------------- |
| `omniroute_agent_skills_list`     | スキル一覧（任意の `category` / `area` フィルター）         |
| `omniroute_agent_skills_get`      | `id` を指定して、1 つのスキルのメタデータと SKILL.md を取得 |
| `omniroute_agent_skills_coverage` | カバレッジ統計（API/CLI の保有数/総数）                     |

スコープの設定と認証については、[MCP-SERVER.md](./MCP-SERVER.md) を参照してください。

## A2A ディスカバリー

A2A スキル `list-capabilities` は、全 45 スキルのカタログを Markdown テーブルのアーティファクトとして返します。外部オーケストレーターは、次のように呼び出すことができます：

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

プロトコルの詳細については、[A2A-SERVER.md](./A2A-SERVER.md) を参照してください。

## 外部エージェントがスキルを利用する方法

### 1. REST 経由での検出

```bash
# カタログ全体を取得
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# コンテキスト注入用の SKILL.md を取得
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP 経由での検出

```typescript
// Claude Desktop / Cursor MCP クライアント内:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → 各項目に rawUrl を含む AgentSkill の配列
```

### 3. A2A 経由での検出

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table は、45 個すべてのスキル ID と rawUrl 列を含む Markdown テーブル
```

### 4. GitHub raw からの直接取得（サーバー不要）

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## ジェネレーター

ジェネレーターは、キュレーションされたカタログ、OpenAPI 仕様、CLI レジストリを読み込み、各エントリの `skills/{id}/SKILL.md` を生成します。

```bash
# プレビュー（ドライラン、書き込みなし）
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# 完全な再生成
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# 指定した ID を再生成
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

ジェネレーターのレスポンスは `GeneratorReport` です。

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
