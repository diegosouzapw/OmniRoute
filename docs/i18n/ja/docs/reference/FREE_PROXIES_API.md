OmniRoute は、外部プロバイダー（1proxy、proxifly、iplocate、webshare）から同期された、厳選済みの無料プロキシプールを `free_proxies` テーブルで提供します。ダッシュボードでは、これらを **Settings → Free Proxies** に表示します。このドキュメントでは、一覧ルートが提供するサーバーサイドのフィルタリング、並べ替え、件数集計、同期エラー報告について説明します。

## 一覧ルート — `GET /api/settings/free-proxies`

フィルタリング、並べ替え、ページネーションが適用されたデータと合計件数を返します。フィルタリングと件数集計は SQL で行われるため、UI はすべての行をメモリに読み込むことなく、実際の合計件数（例：`Total: 0`）を表示できます。

### クエリパラメーター

| パラメーター      | 型                                 | デフォルト | 意味                                                                                                         |
| ----------------- | ---------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------ |
| `search`          | string                             | `""`       | ホスト（およびソース）列に対する、大文字と小文字を区別する `LIKE`。                                          |
| `protocol`        | string                             | `""`       | `type` フィルター：`http` / `https` / `socks4` / `socks5`。空の場合はすべて。                                |
| `country`         | string                             | `""`       | `countryCode` フィルター（ISO-2）。空の場合はすべて。                                                        |
| `minQuality`      | number                             | `0`        | `qualityScore >= minQuality` の行のみ。`0` の場合は下限なし。                                                |
| `disabledSources` | string                             | `""`       | 除外するソース ID のカンマ区切りリスト（例：`proxifly,webshare`）。                                          |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`  | `quality` = スコアの降順、`latency` = レイテンシーの昇順（null は最後）、`recent` = `lastValidated` の降順。 |
| `offset`          | number                             | `0`        | ページネーションの開始位置。                                                                                 |
| `limit`           | number                             | `50`       | ページサイズ（サーバー側で上限あり）。                                                                       |

### レスポンス

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` はページネーション適用**前**のフィルタリング済み合計件数を示すため、UI は `Total: N` と `hasMore` をそれぞれ独立して表示できます。`syncErrors` はソース ID をキーとし、直近の同期に失敗したソースについてのみ設定されます。そのため、`Total: 0` という結果であっても、エラーが通知されないことはありません。

## プールへの追加 — `POST /api/settings/free-proxies/[id]/add-to-pool`

無料プロキシを管理対象の `proxy_registry` プールに昇格させます。最初にアップストリームを検証し、成功すると新しいプールプロキシ ID と測定されたレイテンシーを返します。

## 同期 — `POST /api/settings/free-proxies/sync`

有効化されているすべてのソース（または `{ "sources": [...] }` で指定されたサブセット）を再取得します。各ソースは独立して同期されます。失敗したソースは `syncErrors` に記録され、ほかのソースは引き続き処理されるため、部分的な同期によって以前の有効なデータが消去されることはありません。

## 統計 — `GET /api/settings/free-proxies/stats`

行データを含めずに、`total / inPool / avgQuality / bySource / lastSyncAt` の集計値を返します。これはダッシュボードのヘッダーウィジェットで使用されます。
