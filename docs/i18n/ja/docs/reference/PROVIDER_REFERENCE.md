## カテゴリ

- **無料** — API キーを使用できる無料枠（ダッシュボードで設定）
- **認証不要** — キーもサインインも一切必要としない公開エンドポイント
- **OAuth** — OmniRoute が処理するサインインフロー。API キーは不要
- **Web Cookie** — Cookie 認証を介してプロバイダーの Web アプリをラップ
- **API キー** — API キーで設定する有料プロバイダー（無料クレジットが提供される場合あり）
- **ローカル** — ユーザーのマシン上で実行（Ollama、LM Studio、vLLM など）
- **検索** — Web 検索プロバイダー
- **音声** — 音声専用プロバイダー（TTS/STT）
- **アップストリームプロキシ** — 他のプロバイダーへのプロキシとして機能するプロバイダー
- **クラウドエージェント** — 長時間実行されるコーディングエージェント（Codex Cloud、Devin、Jules）
- **システム** — OmniRoute 内部のプロバイダー（ループバックなど）

追加タグ: `image`、`video`、`aggregator`、`enterprise`、`embed/rerank`、`self-hosted`。

`Tool calling`（表示される場合）: `native` — 実際の関数呼び出し API、`emulated` — `tools` 配列を `webTools.ts` によりプロンプト内でエミュレート（正規表現で解析される `<tool>{...}</tool>` ブロック）、`none` — 現在、`tools` は通知なく破棄されます。#7286 を参照してください。

各プロバイダーを有効化、設定、テストするには、`/dashboard/providers` のダッシュボードを使用してください。
