## TL;DR — OmniRoute は実際にどれだけの無料推論を集約しているのか？

| 指標                                       | トークン / 月 | 意味                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------ | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文書化された継続付与量（定常時）**       | **~1.62B**    | 無料枠の**プール**（モデル別カタログ）。共有プールはそれぞれ**一度だけ**カウントされます。`/api/free-tier/summary` とダッシュボードの Free-Tier Budget ページが参照するライブソースです。**この数値を使用してください。**                                                                                                  |
| **+ サインアップクレジットを含む初月**     | **~2.22B**    | 定常分 + 1 回限りのサインアップクレジット（Z.AI 20M、DeepSeek 5M、…）。アカウントごとに重複排除されています。**初月のみ**で、更新されません。                                                                                                                                                                              |
| **+ 恒久無料、公開上限なし**               | _定量化不能_  | `siliconflow`、`glm-cn`（GLM-4-Flash）、`tencent`、`baidu`、`kilo-gateway`、`opencode-zen`、`gemini`、`ollama-cloud` — 実際に継続利用でき、レートや同時実行数には制限がありますが、**集計可能なトークン上限はありません**。一覧には掲載しますが、合計には含めません（`RPM×24/7` で計算するような水増しは排除しています）。 |

## 2 つの運用方式 — 集計と判定

OmniRoute は「無料か？」という問いに対し、意図的に異なるソースを参照する 2 つの運用方式で回答します：

| 運用方式        | 信頼できる情報源                                                                                                                                                                 | 適用箇所                                                                                                                                       |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **集計 / 表示** | 解決済みカタログ — 配布時のベースラインに Radar フィード（`getRadarCatalog`）を重ね合わせたもの                                                                                  | 無料枠の合計、予算カード、ダッシュボード                                                                                                       |
| **判定**        | 配布済みカタログのみ（`open-sse/config/freeModelCatalog.data.ts` 内の `FREE_MODEL_BUDGETS`）とローカルヒューリスティクス（`:free` サフィックス、料金がゼロ、`grantsFreeAccess`） | `src/shared/utils/freeModels.ts` を使用するすべての箇所：モデルのインポート、`auto/*` ルーティング、`GET /v1/models`、およびブラウザプレビュー |

フィードが利用可能であれば、集計は随時改善できます。一方、判定はリリース成果物に固定されるため、ブラウザとサーバーで回答が一致し、オフラインでも再現可能で、データベースなしでもテストできます。ブラウザプレビューとサーバー側のインポートが異なるソースを参照すると、プレビュー内容とクリック時の実際の動作が一致しなくなるため、この分離は意図的に維持されています。

## 方法論と注意事項

- 数値は、ウェブ調査で収集した、**2026-06-17** 時点における各プロバイダーの文書化された無料枠上限に基づく**上限推定値**です。無料枠は頻繁に変更されるため、数値を利用する前に再確認してください。
- **各エントリが実際に保証する内容。** エントリごとの信頼度評価はなく、API からも提供されません。上記のすべての数値は、明示されていない同一水準の品質を持つ推定値として扱ってください。ただし、推測ではなく手作業で精査されているため、次の 2 つの事実は異なります。44 件のエントリには、独立して文書化されたハードストップがあり（うち 39 件は、すべて同一の日次割り当てを共有する xKiro の行）、13 件のエントリにはプロンプトの学習利用に関する開示があります。`hardStopGuaranteed` は、無料割り当てを超過した際に、プロバイダー自身の規約で、黙って課金を開始するのではなくリクエストを拒否すると明記されている場合にのみ設定され、その出典はエントリの隣のコメントに記載されます。デフォルトで `true` に設定されることはなく、誰も検証していないエントリでは未設定のままです。したがって、ハードストップフラグがないことは「確認されていない」という意味であり、「課金されることが判明している」という意味ではありません。**STRICT モード**（オプトインの `freeAccessPolicy=strict` ルーティングガード）は、このフラグが付いたエントリのみを信頼します。それ以外の無料枠はすべて `no-hard-stop` として除外されます（`open-sse/services/autoCombo/strictZeroCostFilter.ts` を参照）。
- `estMonthlyFreeTokens` = 毎月継続的に付与されるトークンのみ。**初回登録時に一度だけ付与されるクレジットは継続しない**ため、0 として数えます。廃止された枠も 0 です。
- 日次トークン上限 → `monthly = daily × 30`。RPD のみが文書化されている場合 → `RPD × 約800出力トークン × 30`。RPM/TPM のみで日次上限がない場合 → **上限なし**（以下を参照）。
- **恒久的に無料だが、公開されたトークン上限がないもの**（`siliconflow`、`glm-cn`、`tencent`、`baidu`、`kilo-gateway`、`opencode-zen`、`gemini`、`ollama-cloud`）：これらは、レートや同時実行数に制限がある、実在する継続的な無料アクセスです。これらを `recurring-uncapped` に分類し、**合計には決して含めません**。`RPM × 24/7 × 30d` として乗算すると、非現実的な上限値になるためです（このような水増しは採用しません）。利用可能な選択肢として把握できるよう、一覧には掲載しています。
- **入金による上限引き上げ：** 一度だけ少額を入金することで、無料クォータが恒久的に引き上げられる仕組みです（OpenRouter：$10 → 1000 req/day ≈ +24M/mo）。通常時の主要数値には含めず、別の数値として報告します。
- **利用資格によって制限されるクォータ**（`eligibilityGate: "regional-identity"`）：地域に紐づく本人確認（現在は中国本土の実名認証）を完了した後にのみ利用可能になる、実在する継続的なクォータです。同一プールの重複排除ルールを適用して、別の数値（`gatedRecurringTokens`）として集計し、通常時の主要数値には決して含めません。区分（`freeType`）は変わらないため、ルーティングも変わりません。
- **証拠クラス。** ルール：カタログ内の数値は、そのエントリの隣にある `// evidence:` コメントで出典を示します。`public-page`（誰でも閲覧できるプロバイダーのページ）、`api-public`（プロバイダーの認証不要エンドポイント。例：router.bynara.id にある NaraRouter の公開プランエンドポイント）、または `console-verified <date> por <who>`（数値がアカウントコンソール内でのみ確認可能な場合。コメントには、誰がいつ確認したか、および上限の存在を示す公開ページを記録）です。現在の状況：2026-09-02 に再監査された 5 つのブロック（`gemini`、`groq`、`mistral`、`ollama-cloud`、`nara`）には、このコメントがあります。2026-09-02 の再監査より前から存在するエントリは、更新されるまでは以前の調査結果を引き継ぎます。証拠コメントのない**新規または変更された**数値はバグです。現在、console-verified なのは `mistral` のみです。

## 当社の数値が他のアグリゲーターより小さい理由

この分野で見られる「1か月あたりの無料トークン」の数値の大半は、モデルごとの表示値を合計したものです。当社では意図的にそうしていません：

- **各共有プールは1回だけ数えます。** Mistral の無料プランは、組織ごとに月間 1B の割り当てが1つです。5つのモデルに分けて掲載しても 5B にはなりません。モデルごとに合計すると、当社自身のカタログは **~7.4B** になります（2026-09-03 に再計算。この数値は CI で検証されていないため、カタログが変更されるたびに再測定してください）が、見出しでは **~1.47B** としています。これは、各プロバイダーのアカウントを1つずつ持つ場合に実際に利用できる量だからです。
- **日次上限は換算しますが、レート制限は換算しません。** 文書化された tokens/day の上限は `× 30`、文書化された requests/day の上限は `RPD × ~800 tokens × 30` として換算します。requests-per-minute のみを公開しているプロバイダーには月間数値を設定せず、_上限なし_ として掲載し、合計には決して含めません。レート制限を 24/7 で掛け合わせるような水増しは行いません。
- **地域別の本人確認が必要なクォータは別に表示します**（`+~6M behind regional identity verification`）。ほとんどの読者は利用できないためです。
- **サインアップクレジットは初月限定**であり、通常時の数値には混ぜず、2つ目の数値として報告します。
- **この数値は CI によって強制的に検証されます。** `npm run check:docs-counts` はカタログから合計を再計算し、このファイル、README、または予算カードの数値と一致しなくなった場合にビルドを失敗させます。

## 用語集

| 用語                   | 意味                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| **RPM / RPD / RPH**    | 1分あたり / 1日あたり / 1時間あたりのリクエスト数                                                      |
| **TPM / TPD**          | 1分あたり / 1日あたりのトークン数                                                                      |
| **文書化された付与量** | プロバイダーが明示的な1日または1か月あたりのトークン上限を公開しているもの（根拠として提示可能な予算） |
| **理論上の上限**       | `rate-limit × 24/7 × 30d` — 付与された予算ではなく、最大値                                             |
| **Neuron**             | Cloudflareのコンピューティング単位（出力トークン約1個分）                                              |
