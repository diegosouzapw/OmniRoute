ルーティングでは、既存のケイパビリティおよびコンボ選択ロジックを維持したうえで、割り当て、ヘルス、サーキット、クォータ、レイテンシ、信頼性、モデル優先度、コスト優先度の各要因を適用します。

適応型スコアは説明可能であり、選択された候補と、ランキングされたすべての候補の両方を返します。クォータを使い切った候補、割り当てを拒否された候補、サーキットが開いている候補は対象外です。クォータが不明な候補は、中立的なクォータ係数で引き続き対象となります。

ルートプレビューは決定論的に動作し、上流モデルへのリクエストを一切実行しません。

`POST /api/omniroute/route/preview`

レスポンスには、候補のスコア、各要因、理由、選択されたプロバイダー、および `liveRequestExecuted: false` が含まれます。
