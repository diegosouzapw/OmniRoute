Ang alokasyon ay hindi quota ng provider.

Tinutukoy ng mga quota pool kung aling mga API key ang maaaring gumamit ng provider pool at kung paano inilalapat ang mga hard, soft, o burst na patakaran. Ang provider quota ay panlabas na kapasidad na iniulat ng isang provider o ng isang tahasang na-configure na source. Ang mga panloob na badyet ng Ghostlight ay mga limitasyon sa pamamahala na itinakda ng administrator.

Idempotent ang operasyong `ensurePool`: hindi binabago ang magkaparehong pool, ina-update ang nabagong alokasyon, at ginagawa ang nawawalang pool. Nilayon ito para sa automation at mga API caller na may itinakdang hangganan.

Ang read-only na status endpoint ay `GET /api/omniroute/status`. Ang command sa pag-verify ay `npm run omniroute:verify`; hindi ito nagsasagawa ng live na model request.
