Pinaghihiwalay ng OmniRoute ang telemetriya ng quota ng provider mula sa accounting ng Ghostlight.

## Mga tapat na estado

- Ang `healthy` ay nangangahulugang nag-ulat ang isang source ng magagamit na natitirang kapasidad.
- Ang `approaching_limit` ay nangangahulugang nag-ulat ang isang source ng natitirang kapasidad na katumbas o mas mababa sa naka-configure na threshold.
- Inilalabas lamang ang `exhausted` kapag nag-ulat ang isang source ng serong kapasidad o paggamit na nasa limitasyon nito.
- Ang `unavailable` ay nangangahulugang nabigo ang isang sinusuportahang source na magbalik ng data.
- Ang `unknown` ay nangangahulugang walang sinusuportahang source o walang nalalamang limitasyon ng provider.

Ang unknown ay hindi exhausted at hindi nito dini-disable ang isang provider.

Mas pinipili ang mga source sa ganitong pagkakasunod-sunod: opisyal na provider API, authenticated usage API, tahasang naka-map na mga response header, configuration ng administrator, mga lokal na pagtatantiya, unknown. Ang mga lokal na pagtatantiya ay hindi kailanman inilalahad bilang data sa pagsingil ng provider.

Pina-parse lamang ang mga response header sa pamamagitan ng tahasang provider mapping. Hindi ipinapalagay na nalalapat sa lahat ang mga generic na pangalan ng header.
