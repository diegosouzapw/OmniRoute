Ang compression ng Caveman ay maaaring mag-load ng mga rule pack na partikular sa wika bukod sa mga built-in na panuntunan para sa English.
Pinananatili nitong matatag ang pangunahing engine habang nagbibigay-daan sa mga pack para sa Portuguese, Spanish, German, French, Italian, Japanese, at
mga pack para sa iba pang wika sa hinaharap na umunlad nang magkakahiwalay.

## Lokasyon

Matatagpuan ang mga language pack sa ilalim ng:

```txt
open-sse/services/compression/rules/<language>/
```

Mga kasalukuyang kasamang pack (na-verify batay sa mga nilalaman ng direktoryong `rules/`):

| Wika                | Direktoryo     | Mga kasalukuyang kategorya ng panuntunan            |
| ------------------- | -------------- | --------------------------------------------------- |
| English             | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spanish             | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portuguese (Brazil) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonesian          | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italian             | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| German              | `rules/de/`    | `context`, `filler`, `structural`                   |
| French              | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japanese            | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Tala tungkol sa pagkakapantay-pantay:** May kumpletong 5 kategorya ang mga pack na `en`, `es`, `pt-BR`, `id`, at `it`; 3 kategorya ang kasama sa `de`, `fr`, at `ja`. Tahimik na bumabalik sa mga built-in na panuntunan ng English ang mga nawawalang kategoryang `dedup` at `ultra`. Malugod na tinatanggap ang mga kontribusyon upang idagdag ang `dedup.json` at `ultra.json` para sa mas maliliit na pack.
>
> Nakabatay ang pack na `pt-BR` sa **[Troglodita](https://github.com/leninejunior/troglodita)** ni Lenine Júnior — isang compression system na idinisenyo mula sa simula para sa gramatika ng Brazilian Portuguese (pagbabawas ng pleonasm, pag-aalis ng mga filler sa PT-BR, at mga teknikal na daglat para sa komunidad ng mga developer sa Brazil).
>
> Matatagpuan ang canonical na listahan ng mga kategorya at schema ng bawat kategorya sa [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12).

## Pagtukoy ng Wika

Gumagamit ang `languageDetector.ts` ng magagaan na heuristic upang matukoy ang wika mula sa text ng prompt. Sinusunod pa rin ang
naka-configure na default na wika, at maaaring i-disable ang pagtukoy sa pamamagitan ng config kapag kailangan ang eksaktong
kontrol.

Ginagamit lamang ang output ng pagtukoy upang pumili ng mga rule pack. Hindi nito binabago ang provider routing, pagpili ng locale,
o wika ng UI.

## Anyo ng Config

Maaaring kabilang sa mga setting ng compression ang:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

Kinokontrol ng `languageConfig` ang mga default ng dashboard/preview. Ang `cavemanConfig` ang runtime engine config
na ginagamit kapag kino-compress ng Caveman ang text ng mensahe.

## Pagdaragdag ng Pakete ng Wika

1. Gumawa ng `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Gamitin ang format ng panuntunang Caveman mula sa `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Panatilihing konserbatibo ang mga pagpapalit at iwasang baguhin ang code, mga identifier, URL, o JSON.
4. Magdagdag o mag-update ng mga test para sa pagpili ng wika at gawi ng pagpapalit.
5. Ilantad ang mga bagong label ng dashboard/i18n kung lumalabas ang wika sa mga selector ng UI.

## API

Maaaring i-query ang mga available na pakete gamit ang:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Tumatanggap ang preview endpoint ng mga override sa configuration ng wika:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Nakatanggap ang lahat ng 6 na pakete ng wika ng clause na `SHARED_BOUNDARIES` sa v3.8.0 na inilalapat sa bawat
antas ng intensity ng Caveman (LITE, FULL, ULTRA). Inaatasan nito ang engine na panatilihin nang eksakto ang mga pattern na ito,
anuman ang pag-aalis ng nakapaligid na filler:

| Uri ng pattern                      | Halimbawa                              |
| ----------------------------------- | -------------------------------------- |
| Mga fenced code block               | ` ```python\n...\n``` `                |
| Inline code                         | `` `my_var` ``                         |
| Mga URL                             | `https://example.com/path`             |
| Mga file path (absolute + relative) | `/etc/hosts`, `./src/index.ts`         |
| Mga header ng error                 | `Error:`, `TypeError:`, `SyntaxError:` |
| Mga linya ng stack trace            | `  at functionName (file.ts:12:3)`     |

Inilalagay ang mga pattern na ito sa `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (dating `[]`). Ang
constant ay nasa `open-sse/services/compression/types.ts`.

### Bakit ito mahalaga

Kung walang SHARED_BOUNDARIES, maaaring alisin ng mga agresibong Caveman mode ang content na mukhang paulit-ulit na
prosa ngunit isa palang code snippet, file path, o error stack. Nagsisilbi ang SHARED_BOUNDARIES bilang
safety net na hindi nakadepende sa wika at inilalapat bago patakbuhin ang mga panuntunan sa filler.

### Pag-customize ng preservePatterns

Maaaring magdagdag ng mga karagdagang pattern sa runtime sa pamamagitan ng mga setting ng compression:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Dinadagdagan ng mga custom na pattern (hindi pinapalitan) ang 6 na default.

## Mga Tala sa Operasyon

- Nananatiling fallback ang mga built-in na panuntunan sa English kapag walang pakete ng wika.
- Nabibigo sa validation ang mga di-wastong built-in na JSON pack upang hindi tahimik na bumaba ang kalidad ng mga release asset.
- Data-only ang mga rule pack at hindi dapat mag-import ng code o magpatakbo ng arbitraryong logic.
- Itinatala ng compression analytics layer ang napiling mode at engine, hindi ang buong text ng prompt.
