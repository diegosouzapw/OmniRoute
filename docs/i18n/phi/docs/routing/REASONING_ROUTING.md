Pinapalawak ng mga panuntunan sa pagruruta ng pangangatwiran ang kasalukuyang pagruruta ng modelo at combo. Kapag walang tumugmang aktibong panuntunan,
mananatiling hindi nagbabago ang kasalukuyang gawi para sa pag-iisip, suffix, default ng koneksyon, at pagsasalin ng provider.

## Pamamahala

Makikita ang pamamahala ng panuntunan sa **Settings → Global Routing**. Nagbibigay ang editor ng API key ng
parehong UI sa pamamahala na sinala para sa napiling key.

Inilalantad ang management API sa pamamagitan ng mga rutang ito:

- `GET` at `POST` sa `/api/settings/reasoning-routing-rules`
- `GET`, `PATCH`, at `DELETE` sa `/api/settings/reasoning-routing-rules/[id]`
- `POST` sa `/api/settings/reasoning-routing-rules/simulate`

Ginagamit ng lahat ng ruta ang `requireManagementAuth`. Bine-validate ang mga input gamit ang mga schema sa
`src/shared/validation/schemas/reasoningRouting.ts`. Hindi kailanman gumagawa ng upstream na tawag ang simulator.

## Paglutas ng Panuntunan

Eksaktong isang panuntunan ang pinipili ng maagang pagsusuri. Sinusuri ang mga saklaw sa ganitong pagkakasunod-sunod:

1. `apiKey`
2. `combo`
3. `model`
4. `global`

Sa loob ng isang saklaw, unang nananalo ang mas mataas na `priority`, kasunod ang eksaktong pagtutugma ng modelo kaysa sa glob pattern,
at pagkatapos ay ang matatag na pagkakasunod-sunod ng `createdAt` at `id`. Eksklusibong binabasa ang `requestTags` mula sa `metadata.tags`
at sinusuportahan nito ang pagtutugmang `any` o `all`.

Sinusuri lamang ang isang panuntunang `connection` kapag walang nanalo sa maagang pagsusuri at napili na
ang isang partikular na koneksyon ng provider. Maaari lamang nitong baguhin ang effort at budget.

## Effort at Budget

Tinatanggap ng `sourceEffort` ang `any`, `missing`, `none`, `low`, `medium`, `high`, `xhigh`, `max`, at
`ultra`. Ang `missing` ay nangangahulugang walang discrete effort, toggle ng pag-iisip,
o budget sa pag-iisip ang kahilingan. Samakatuwid, ang signal na budget lamang ay tinutugma lang ng `any`.

May tatlong variant ang `effortMode`:

- Pinananatili ng `inherit` ang effort ng client habang pinapayagan pa ring magbago ang modelo o combo.
- Itinatakda ng `default` ang `targetEffort` kapag walang tahasang signal ng pangangatwiran.
- Pinapalitan ng `force` ang discrete effort ng `targetEffort`.

Nang hiwalay, maaaring maging `preserve`, `remove`, o `set` ang `budgetAction`. Inaalis ng `force` na may `none`
ang lahat ng kinikilalang field ng effort at budget. Hindi valid ang `none` kasama ng `set`.

Tinatanggihan bago ang upstream na tawag ang mga kahilingang nagta-target sa mga modelong kilalang hindi compatible. Para sa mga combo
target, inaalis ang mga hindi compatible na entry; kung walang matira, magbabalik ang kahilingan ng status na `400`.
Naglalabas ng babala ang hindi kilalang capability data at pinananatiling aktibo ang panuntunan.

## Seguridad at mga Transport

Ang source at target na modelo, o source at target na combo, ay nananatiling saklaw ng kasalukuyang patakaran ng API key.
Hindi kailanman pinalalawak ng panuntunan sa pangangatwiran ang mga pahintulot sa modelo, combo, o quota.

Naka-integrate ang engine sa Chat Completions, Responses, Anthropic Messages, at sa internal
na Codex WebSocket path. Mga Codex target model lamang ang tinatanggap ng WebSocket path; hindi maaaring
ipatupad doon ang mga combo target. Iniimbak ang desisyon ng panuntunan sa kasalukuyang route trace nang walang mga secret.

## Persistence

Ginagawa ng migration na `src/lib/db/migrations/126_reasoning_routing_rules.sql` ang
table na `reasoning_routing_rules`. Tinutukoy ng mga panuntunan ang mga nakaimbak na API key, combo, at koneksyon ng provider.
Nililinis ng mga pag-delete ang mga kaugnay na panuntunan. Nagpapanatili ang database access layer sa
`src/lib/db/reasoningRoutingRules.ts` ng cache na maaaring i-invalidate para sa request path.

Kasama ang mga panuntunan sa mga SQLite backup, sa buong database export, at sa config-sync bundle.
Dini-disable ng `reconcileReasoningRulesForSync` ang mga na-import na panuntunang may mga nawawalang reference at iniuulat ang mga
conflict na iyon.
