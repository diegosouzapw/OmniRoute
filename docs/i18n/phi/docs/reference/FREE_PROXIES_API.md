Nagbibigay ang OmniRoute ng piniling koleksiyon ng mga libreng proxy sa talahanayang `free_proxies`,
na sini-sync mula sa mga panlabas na provider (1proxy, proxifly, iplocate, webshare). Makikita
ang mga ito sa dashboard sa ilalim ng **Settings → Free Proxies**. Tinatalakay ng dokumentong ito
ang pag-filter, pag-sort, pagbibilang, at pag-uulat ng mga error sa pag-sync sa panig ng server
na inilalantad ng route para sa listahan.

## Route ng listahan — `GET /api/settings/free-proxies`

Nagbabalik ng na-filter, na-sort, at na-pagination na bahagi kasama ang kabuuang bilang. Isinasagawa
ang pag-filter at pagbibilang sa SQL, kaya maipapakita ng UI ang aktuwal na kabuuan (hal. `Total: 0`)
nang hindi nilo-load sa memory ang bawat row.

### Mga query parameter

| Parameter         | Uri                                | Default   | Kahulugan                                                                                                           |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`      | Case-sensitive na `LIKE` sa column ng host (at source).                                                             |
| `protocol`        | string                             | `""`      | Filter na `type`: `http` / `https` / `socks4` / `socks5`. Walang laman = lahat.                                     |
| `country`         | string                             | `""`      | Filter na `countryCode` (ISO-2). Walang laman = lahat.                                                              |
| `minQuality`      | number                             | `0`       | Mga row lang na may `qualityScore >= minQuality`. `0` = walang minimum.                                             |
| `disabledSources` | string                             | `""`      | Mga source id na pinaghihiwalay ng kuwit at hindi isasama (hal. `proxifly,webshare`).                               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = pababang score; `latency` = pataas na latency (huli ang mga null); `recent` = pababang `lastValidated`. |
| `offset`          | number                             | `0`       | Simula ng pagination.                                                                                               |
| `limit`           | number                             | `50`      | Laki ng page (nililimitahan sa panig ng server).                                                                    |

### Tugon

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 mula sa upstream"],
    "webshare": ["timeout ng network"]
  }
}
```

Ipinapakita ng `total` ang na-filter na kabuuan **bago** ang pagination, kaya maaaring i-render ng UI
ang `Total: N` at `hasMore` nang magkahiwalay. Ang `syncErrors` ay gumagamit ng source id bilang key at
nilalagyan lamang ng data para sa mga source na nabigo sa huli nilang pag-sync — hindi kailanman
mananatiling walang paliwanag ang resultang `Total: 0`.

## Pagdaragdag sa pool — `POST /api/settings/free-proxies/[id]/add-to-pool`

Inililipat ang isang libreng proxy sa pinamamahalaang pool na `proxy_registry`. Bine-validate muna ang
upstream; kapag matagumpay, ibinabalik ang bagong proxy id sa pool at ang nasukat na latency.

## Pag-sync — `POST /api/settings/free-proxies/sync`

Muling kinukuha ang lahat ng naka-enable na source (o ang subset sa `{ "sources": [...] }`). Ang bawat
source ay sini-sync nang hiwalay; ang isang nabigong source ay itinatala sa `syncErrors` at
nakukumpleto pa rin ang iba, kaya hindi kailanman binubura ng mga bahagyang pag-sync ang dating
wastong data.

## Mga istatistika — `GET /api/settings/free-proxies/stats`

Ibinabalik ang pinagsama-samang `total / inPool / avgQuality / bySource / lastSyncAt`
nang walang payload ng mga row — ginagamit ng mga header widget ng dashboard.
