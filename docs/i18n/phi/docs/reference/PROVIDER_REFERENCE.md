## Mga Kategorya

- **Libre** — libreng antas na may API key (kino-configure sa dashboard)
- **Walang auth** — mga pampublikong endpoint na hindi nangangailangan ng key o pag-sign in
- **OAuth** — proseso ng pag-sign in na pinangangasiwaan ng OmniRoute, hindi kailangan ng API key
- **Web cookie** — binabalot ang web app ng provider gamit ang cookie auth
- **API key** — bayad na provider na kino-configure gamit ang API key (maaaring may libreng credits)
- **Lokal** — tumatakbo sa makina ng user (Ollama, LM Studio, vLLM, atbp.)
- **Paghahanap** — mga provider ng paghahanap sa web
- **Audio** — mga provider na para lamang sa audio (TTS/STT)
- **Upstream proxy** — mga provider na nagsisilbing proxy sa iba pang mga provider
- **Cloud agent** — mga matagal tumakbong coding agent (Codex Cloud, Devin, Jules)
- **System** — mga panloob na provider ng OmniRoute (loopback, atbp.)

Mga karagdagang tag: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Pagtawag sa tool` (kung ipinapakita): `native` — tunay na function-calling API; `emulated` — ang array na `tools` ay ginagaya sa prompt sa pamamagitan ng `webTools.ts` (mga block na `<tool>{...}</tool>` na pina-parse gamit ang regex); `none` — kasalukuyang tahimik na hindi isinasama ang `tools`. Tingnan ang #7286.

Gamitin ang dashboard sa `/dashboard/providers` upang i-enable, i-configure, at subukan ang bawat provider.
