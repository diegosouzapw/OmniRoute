Dashboard → Providers → Lumilikha ang **Import from file** ng mga koneksyon gamit ang API key mula sa isang listahang CSV o JSON. Maaaring tumukoy ang bawat row sa ibang provider. Ang bahagyang pagkabigo ang inaasahang gawi: mai-import pa rin ang mga wastong row kapag nabigo ang iba, at ililista sa modal kung bakit tinanggihan ang mga nabigong row.

Ang pag-import na ito ay **hindi** lumilikha ng mga bagong endpoint node na compatible sa OpenAI/Anthropic. Likhain muna ang mga iyon (Dashboard → Providers → Add OpenAI-Compatible, o `omniroute nodes add`), pagkatapos ay mag-import ng mga row kung saan ang column na `provider` ay id ng node na iyon. Maaari pa ring palitan ng `baseUrl` sa bawat row ang URL ng node.

## CSV (ayon sa posisyon)

Pamporma lamang ang mga pangalan ng column. Hinahati ng parser ang bawat row at kinukuha ang mga value ayon sa index:

| Index | Field      | Kinakailangan | Mga Tala                                                                                                                                        |
| ----- | ---------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 0     | `provider` | oo            | Id ng kasalukuyang pinamamahalaang provider (`openai`, `anthropic`, …) **o** id ng nakarehistro nang **node** na compatible sa OpenAI/Anthropic |
| 1     | `name`     | oo            | Ipinapakitang pangalan ng koneksyon                                                                                                             |
| 2     | `apiKey`   | oo            | API key                                                                                                                                         |
| 3     | `baseUrl`  | hindi         | Pagpalit sa URL para sa bawat row                                                                                                               |
| 4     | `priority` | hindi         | Integer mula 1–100                                                                                                                              |

Nilalaktawan bilang header ang unang linya kung ang unang column nito ay ang literal na salitang `provider` (anumang capitalization). Nilalaktawan din ang mga blangkong linya at komentong `#`.

Mag-download ng panimulang file mula sa import modal (**Download CSV template**). Halimbawa:

```csv
# Pag-import ng provider sa OmniRoute (mga column ayon sa posisyon)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Ang gawa-gawang id gaya ng `openai-compatible-chat-001` ay hindi isang node. Ibinabalik ng API ang `Unknown or unsupported provider` para sa row na iyon; ipinapakita ito ng modal katabi ng pangalan ng row.

## JSON

Isang JSON array ng mga object na may parehong mga field (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Hindi tulad ng CSV, may mga pangalan ang mga JSON key.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
