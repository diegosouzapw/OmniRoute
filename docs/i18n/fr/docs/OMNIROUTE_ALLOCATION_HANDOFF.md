L’allocation n’est pas le quota du fournisseur.

Les pools de quotas définissent quelles clés API peuvent consommer un pool de fournisseur et comment les politiques strictes, souples ou de dépassement temporaire s’appliquent. Le quota du fournisseur correspond à la capacité externe signalée par un fournisseur ou par une source explicitement configurée. Les budgets internes de Ghostlight sont des limites de gouvernance définies par l’administrateur.

L’opération `ensurePool` est idempotente : un pool identique reste inchangé, une allocation modifiée est mise à jour et un pool manquant est créé. Elle est destinée à l’automatisation et aux appelants d’API soumis à des limites.

Le point de terminaison d’état en lecture seule est `GET /api/omniroute/status`. La commande de vérification est `npm run omniroute:verify` ; elle n’effectue aucune requête réelle auprès d’un modèle.
