## Étape 1 : Installer OmniRoute

Choisissez votre méthode préférée :

### Option A : npm (recommandé)

```bash
npm install -g omniroute
```

### Option B : Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` correspond à la version stable SemVer **publiée** la plus récente. Cette étiquette ne suit **pas** la branche git `main`. Utilisez une version fixe, telle que `diegosouzapw/omniroute:X.Y.Z`, pour GitOps. Consultez [Étiquettes d’image / Canaux de publication](../guides/DOCKER_GUIDE.md#release-channels).

### Option C : Depuis les sources

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Étape 2 : Démarrer OmniRoute

```bash
omniroute
```

OmniRoute démarre à l’adresse `http://localhost:20128`. Le tableau de bord s’ouvre automatiquement.

---

## Étape 3 : Connecter un fournisseur gratuit

Vous pouvez utiliser OmniRoute **sans rien payer** en connectant un fournisseur gratuit.

### Option A : Kiro (Claude gratuit — aucune carte bancaire)

1. Ouvrez le tableau de bord à l’adresse `http://localhost:20128`
2. Accédez à **Fournisseurs** → **Ajouter un fournisseur**
3. Sélectionnez **Kiro AI**
4. Cliquez sur **Connecter** (aucune clé API nécessaire !)
5. C’est fait ! Vous disposez désormais d’un accès gratuit aux modèles Claude.

### Option B : OpenCode Free (aucune authentification)

1. Ouvrez le tableau de bord à l’adresse `http://localhost:20128`
2. Accédez à **Fournisseurs** → **Ajouter un fournisseur**
3. Sélectionnez **OpenCode Free**
4. Cliquez sur **Connecter** (aucune clé API nécessaire !)
5. C’est fait ! Vous disposez désormais d’un accès gratuit à plusieurs modèles.

### Option C : Pollinations (aucune clé nécessaire)

1. Ouvrez le tableau de bord à l’adresse `http://localhost:20128`
2. Accédez à **Fournisseurs** → **Ajouter un fournisseur**
3. Sélectionnez **Pollinations**
4. Cliquez sur **Connecter** (aucune clé API nécessaire !)
5. C’est fait ! Vous disposez désormais d’un accès gratuit à GPT-5, Claude, Gemini et bien d’autres modèles.

---

## Étape 4 : Vérifier que tout fonctionne

Depuis la page [Clés API](http://localhost:20128/dashboard/api-manager), créez une nouvelle clé. Conservez-la, car elle ne sera plus affichée. Notez que cette clé permet aux outils d’accéder à OmniRoute, et non d’accéder aux fournisseurs en amont.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

La liste de vos modèles connectés devrait s’afficher.

---

## Étape 5 : Faire pointer votre IDE ou votre CLI vers OmniRoute

Dans votre IDE ou votre outil CLI, définissez les paramètres suivants :

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

C’est tout ! Votre IDE utilise désormais OmniRoute avec une sélection automatique du fournisseur.

### Exemple d’IDE : VSCode/Continue.dev

1. Dans VSCode, installez l’extension [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Mettez à jour votre fichier `~/.continue/config.yaml` pour ajouter les lignes suivantes :

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Dans le volet de discussion de Continue.dev, sélectionnez `OmniRoute - Auto` pour envoyer des requêtes à OmniRoute.
4. (Facultatif) Exercice pour le lecteur : demandez à votre IDE de mettre à jour le fichier `config.yaml` avec toutes les autres configurations prédéfinies 😊

### Exemple de CLI : Codex CLI

1. Dans votre système d’exploitation, définissez la variable d’environnement de manière persistante.
   Sous macOS/Linux (ajoutez-la à votre fichier `~/.bashrc` ou `~/.zshrc`) :

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Sous Windows (Invite de commandes) :

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Lançons maintenant Codex en le configurant pour OmniRoute. Exécutez :

```
omniroute launch-codex --model auto
```

Vous pouvez effectuer cette configuration manuellement avec `codex` et des paramètres de ligne de commande pour spécifier le point de terminaison et la clé API, mais avec la commande ci-dessus, OmniRoute s’occupe de tout pour vous.

Le même lancement à l’aide d’une seule commande fonctionne pour d’autres CLI grâce au lanceur générique : `omniroute run <target>` prend en charge `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` et `gemini` (consultez [Intégrations CLI](../guides/CLI-INTEGRATIONS.md)).

3. La CLI devrait maintenant envoyer ses requêtes à OmniRoute.

### Vérifier que votre outil achemine les requêtes vers OmniRoute

Vous pouvez consulter les détails de la requête en cliquant sur [Surveillance/Journaux](http://localhost:20128/dashboard/logs) dans la barre latérale gauche. Cliquez sur une entrée pour afficher davantage de détails. Vous pouvez également voir quelles informations votre outil préféré transmet. Cela s’avère utile à des fins pédagogiques et de débogage.

## Questions fréquentes

### « Ai-je besoin d’une clé API ? »

**Non !** Vous pouvez utiliser des fournisseurs gratuits (Kiro, OpenCode Free, Pollinations) sans aucune clé API. Il vous suffit de les connecter depuis le tableau de bord.

### « Qu’est-ce que `auto` ? »

`auto` demande à OmniRoute de sélectionner automatiquement le meilleur fournisseur pour chaque requête. Il prend en compte la vitesse, le coût, la qualité et la disponibilité. Consultez le [Guide Auto-Combo](./AUTO-COMBO-GUIDE.md) pour plus de détails.

### « Combien cela coûte-t-il ? »

OmniRoute est **gratuit et open source**. Vous ne payez que les fournisseurs que vous utilisez. De nombreux fournisseurs proposent des offres gratuites — consultez le [Guide des offres gratuites](./FREE-TIERS-GUIDE.md).

### « Puis-je l’utiliser avec Claude Code / Cursor / Copilot ? »

**Oui !** OmniRoute fonctionne avec tous les outils qui prennent en charge le format OpenAI. Il suffit de définir l’URL de base sur `http://localhost:20128/v1`. Consultez le [Guide des outils CLI](../reference/CLI-TOOLS.md) pour obtenir des instructions de configuration spécifiques.

### « Que se passe-t-il si un fournisseur devient indisponible ? »

OmniRoute ignore automatiquement les fournisseurs défaillants et essaie le suivant. Vous n’avez rien à faire. Consultez le [Guide Auto-Combo](./AUTO-COMBO-GUIDE.md) pour plus de détails.
