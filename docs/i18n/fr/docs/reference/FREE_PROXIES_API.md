OmniRoute fournit un ensemble sélectionné de proxys gratuits dans la table `free_proxies`,
synchronisé depuis des fournisseurs externes (1proxy, proxifly, iplocate, webshare). Le
tableau de bord les affiche sous **Paramètres → Proxys gratuits**. Ce document
décrit le filtrage, le tri, le comptage et le signalement des erreurs de synchronisation
côté serveur proposés par la route de liste.

## Route de liste — `GET /api/settings/free-proxies`

Renvoie une partie filtrée, triée et paginée, ainsi qu’un nombre total. Le filtrage et
le comptage sont effectués en SQL, afin que l’interface utilisateur puisse afficher le total réel (par ex. `Total : 0`)
sans charger toutes les lignes en mémoire.

### Paramètres de requête

| Paramètre         | Type                               | Valeur par défaut | Signification                                                                                                                        |
| ----------------- | ---------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `search`          | chaîne                             | `""`              | `LIKE` sensible à la casse sur la colonne de l’hôte (et de la source).                                                               |
| `protocol`        | chaîne                             | `""`              | Filtre `type` : `http` / `https` / `socks4` / `socks5`. Vide = tous.                                                                 |
| `country`         | chaîne                             | `""`              | Filtre `countryCode` (ISO-2). Vide = tous.                                                                                           |
| `minQuality`      | nombre                             | `0`               | Uniquement les lignes où `qualityScore >= minQuality`. `0` = aucun seuil minimal.                                                    |
| `disabledSources` | chaîne                             | `""`              | Identifiants de source séparés par des virgules à exclure (par ex. `proxifly,webshare`).                                             |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`         | `quality` = score décroissant ; `latency` = latence croissante (valeurs nulles en dernier) ; `recent` = `lastValidated` décroissant. |
| `offset`          | nombre                             | `0`               | Début de la pagination.                                                                                                              |
| `limit`           | nombre                             | `50`              | Taille de la page (plafonnée côté serveur).                                                                                          |

### Réponse

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 du serveur en amont"],
    "webshare": ["expiration du délai réseau"]
  }
}
```

`total` indique le total filtré **avant** la pagination, afin que l’interface utilisateur puisse afficher
`Total : N` et `hasMore` indépendamment. `syncErrors` est indexé par identifiant de source et
renseigné uniquement pour les sources dont la dernière synchronisation a échoué — un résultat `Total : 0`
n’est jamais silencieux.

## Ajout à l’ensemble — `POST /api/settings/free-proxies/[id]/add-to-pool`

Ajoute un proxy gratuit à l’ensemble géré `proxy_registry`. Valide d’abord le
serveur en amont ; en cas de réussite, renvoie le nouvel identifiant du proxy de l’ensemble et la latence mesurée.

## Synchronisation — `POST /api/settings/free-proxies/sync`

Récupère à nouveau toutes les sources activées (ou le sous-ensemble indiqué dans `{ "sources": [...] }`). Chaque
source est synchronisée indépendamment ; une source en échec est enregistrée dans `syncErrors` et les
autres peuvent tout de même terminer, de sorte que les synchronisations partielles n’effacent jamais les données valides antérieures.

## Statistiques — `GET /api/settings/free-proxies/stats`

Renvoie l’agrégat `total / inPool / avgQuality / bySource / lastSyncAt`
sans les données des lignes — utilisé par les widgets d’en-tête du tableau de bord.
