> **Fonte fidedigna:** `src/lib/agentSkills/` (catálogo, gerador, analisadores) + diretório `skills/` (ficheiros SKILL.md)
> **Última atualização:** 2026-08-02 — v3.8.50

As Agent Skills são ficheiros SKILL.md estruturados que ensinam agentes externos, clientes MCP e orquestradores A2A a utilizar a API REST e a CLI do OmniRoute. Ao contrário das [Omni Skills](./SKILLS.md) (que são definições de ferramentas LLM executadas no OmniRoute), as Agent Skills constituem um _catálogo de documentação_ — markdown estático que pode ser fornecido diretamente ao contexto do agente.

---

## Visão geral

O catálogo contém **45 Agent Skills** (23 de API REST + 21 de CLI + 1 fluxo de trabalho de configuração). Cada skill tem:

- Um **ID canónico** (`omni-auth`, `cli-serve`, etc.)
- Um ficheiro **SKILL.md** em `skills/{id}/SKILL.md` com frontmatter YAML (`name`, `description`) + um corpo em markdown detalhado
- **Endpoints REST** (skills de API) ou **subcomandos da CLI** (skills de CLI) derivados da especificação OpenAPI e do registo da CLI
- Um **URL raw do GitHub** para obtenção em tempo real: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Arquitetura

```
src/shared/constants/agentSkills.ts    — Lista selecionada de 45 entradas (nome/descrição/categoria/área/ícone)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() escreve SKILL.md em skills/{id}/
  openapiParser.ts                     — extrai endpoints REST de docs/openapi.yaml
  cliRegistryParser.ts                 — extrai subcomandos da CLI de bin/cli-registry.ts
  schemas.ts                           — Esquemas Zod: AgentSkillSchema, SkillCoverageSchema, etc.
  types.ts                             — Interfaces TypeScript: AgentSkill, SkillCoverage, etc.

skills/{id}/SKILL.md                   — Ficheiros markdown gerados + selecionados (45 no total)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (autenticação necessária)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 ferramentas MCP (listar, obter, cobertura)
src/lib/a2a/skills/listCapabilities.ts        — Skill A2A: list-capabilities
```

## Formato do SKILL.md

```markdown
---
name: omni-providers
description: "Gerir ligações a fornecedores: adicionar, testar, rodar e remover credenciais."
---

<!-- gerado por src/lib/agentSkills/generator.ts; as edições manuais serão substituídas -->

## Visão geral

...

## Autenticação

...

## Endpoints

...

<!-- skill:custom-start -->

## Secção personalizada (preservada entre regenerações)

...

<!-- skill:custom-end -->
```

O gerador preserva o conteúdo entre `<!-- skill:custom-start -->` e `<!-- skill:custom-end -->` durante a regeneração. Dez skills têm blocos personalizados selecionados:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Descoberta da API REST

| Endpoint                     | Método | Descrição                                                            | Autenticação |
| :--------------------------- | :----- | :------------------------------------------------------------------- | :----------- |
| `/api/agent-skills`          | GET    | Lista o catálogo (`?category=api\|cli\|config&area=<area>` opcional) | nenhuma      |
| `/api/agent-skills/{id}`     | GET    | Obtém os metadados de uma competência                                | nenhuma      |
| `/api/agent-skills/{id}/raw` | GET    | Obtém o SKILL.md como `text/markdown`                                | nenhuma      |
| `/api/agent-skills/coverage` | GET    | Estatísticas de cobertura (quantos ficheiros SKILL.md existem)       | nenhuma      |
| `/api/agent-skills/generate` | POST   | Aciona o gerador (dryRun/prune/onlyIds)                              | gestão       |

Exemplo — listar todas as competências da API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Exemplo — obter um único SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Descoberta MCP

Estão registadas três ferramentas MCP no âmbito `read:catalog`:

| Ferramenta                        | Descrição                                                     |
| :-------------------------------- | :------------------------------------------------------------ |
| `omniroute_agent_skills_list`     | Lista competências (filtros `category` / `area` opcionais)    |
| `omniroute_agent_skills_get`      | Obtém metadados + SKILL.md de uma competência através do `id` |
| `omniroute_agent_skills_coverage` | Estatísticas de cobertura (API/CLI existentes/total)          |

Consulte [MCP-SERVER.md](./MCP-SERVER.md) para obter informações sobre a configuração de âmbitos e a autenticação.

## Descoberta A2A

A competência A2A `list-capabilities` devolve o catálogo completo de 45 competências como um artefacto de tabela markdown. Os orquestradores externos podem invocá-la através de:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

Consulte [A2A-SERVER.md](./A2A-SERVER.md) para obter detalhes do protocolo.

## Como os agentes externos consomem competências

### 1. Descoberta através de REST

```bash
# Obter o catálogo completo
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Obter o SKILL.md para injeção de contexto
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Descoberta através de MCP

```typescript
// Num cliente MCP do Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → matriz de AgentSkill com rawUrl para cada um
```

### 3. Descoberta através de A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table é uma tabela markdown com os 45 IDs de competências + colunas rawUrl
```

### 4. Obtenção direta do conteúdo raw do GitHub (não requer servidor)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Gerador

O gerador lê o catálogo selecionado + a especificação OpenAPI + o registo da CLI e escreve `skills/{id}/SKILL.md` para cada entrada:

```bash
# Pré-visualizar (execução de teste, sem escritas)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Regeneração completa
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Regenerar IDs específicos
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

A resposta do gerador é um `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
