> **TL;DR**: Instale → Ligue um fornecedor gratuito → Aponte o seu IDE para o OmniRoute. Está feito.

---

## Passo 1: Instalar o OmniRoute

Escolha o método que preferir:

### Opção A: npm (Recomendado)

```bash
npm install -g omniroute
```

### Opção B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` corresponde à versão SemVer estável **publicada** mais recente. **Não** acompanha o `main` do git. Fixe `diegosouzapw/omniroute:X.Y.Z` para GitOps. Consulte [Etiquetas de Imagem/Canais de Lançamento](../guides/DOCKER_GUIDE.md#release-channels).

### Opção C: A Partir do Código-Fonte

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Passo 2: Iniciar o OmniRoute

```bash
omniroute
```

O OmniRoute é iniciado em `http://localhost:20128`. O painel abre automaticamente.

---

## Passo 3: Ligar um Fornecedor Gratuito

Pode utilizar o OmniRoute **sem pagar nada**, ligando um fornecedor gratuito.

### Opção A: Kiro (Claude Gratuito — Sem Cartão de Crédito)

1. Abra o painel em `http://localhost:20128`
2. Aceda a **Fornecedores** → **Adicionar Fornecedor**
3. Selecione **Kiro AI**
4. Clique em **Ligar** (não é necessária uma chave de API!)
5. Está feito! Agora tem acesso gratuito aos modelos Claude.

### Opção B: OpenCode Free (Sem Autenticação)

1. Abra o painel em `http://localhost:20128`
2. Aceda a **Fornecedores** → **Adicionar Fornecedor**
3. Selecione **OpenCode Free**
4. Clique em **Ligar** (não é necessária uma chave de API!)
5. Está feito! Agora tem acesso gratuito a vários modelos.

### Opção C: Pollinations (Não É Necessária uma Chave)

1. Abra o painel em `http://localhost:20128`
2. Aceda a **Fornecedores** → **Adicionar Fornecedor**
3. Selecione **Pollinations**
4. Clique em **Ligar** (não é necessária uma chave de API!)
5. Está feito! Agora tem acesso gratuito ao GPT-5, Claude, Gemini e muito mais.

---

## Passo 4: Verificar se Funciona

Em [Chaves de API](http://localhost:20128/dashboard/api-manager), crie uma nova chave. Guarde esta chave, pois não voltará a ser apresentada. Tenha em atenção que esta chave se destina a permitir que as ferramentas acedam ao OmniRoute, não aos fornecedores a montante.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Deverá ver os modelos ligados na lista.

---

## Passo 5: Apontar o Seu IDE ou CLI para o OmniRoute

No seu IDE ou ferramenta CLI, defina:

```
URL base:  http://localhost:20128/v1
Chave API: [copie de Painel → Endpoints]
Modelo:    auto
```

É tudo! O seu IDE utiliza agora o OmniRoute com seleção automática de fornecedor.

### Exemplo de IDE: VSCode/Continue.dev

1. No VSCode, instale a extensão [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Atualize o seu `~/.continue/config.yaml` para adicionar as seguintes linhas:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. No painel de conversa do Continue.dev, selecione `OmniRoute - Auto` para efetuar pedidos ao OmniRoute.
4. (Opcional) Exercício para o leitor: peça ao seu IDE para atualizar o `config.yaml` com todas as outras configurações predefinidas 😊

### Exemplo de CLI: Codex CLI

1. No seu sistema operativo, defina a variável de ambiente de forma persistente.
   Para macOS/Linux (adicione ao seu `~/.bashrc` ou `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Para Windows (Linha de Comandos):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Agora vamos iniciar o Codex, mas configurado para o OmniRoute. Execute:

```
omniroute launch-codex --model auto
```

Pode fazê-lo manualmente através de `codex` e de parâmetros da linha de comandos para especificar o endpoint e a chave de API, mas, com o comando acima, o OmniRoute trata de tudo por si.

O mesmo arranque com um único comando funciona para outras ferramentas CLI através do iniciador genérico — `omniroute run <target>` suporta `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` e `gemini` (consulte [Integrações CLI](../guides/CLI-INTEGRATIONS.md)).

3. A CLI deverá estar agora a enviar pedidos ao OmniRoute.

### Confirmar que a sua ferramenta está a encaminhar pedidos para o OmniRoute

Pode ver os detalhes do pedido clicando em [Monitorização/Registos](http://localhost:20128/dashboard/logs) na barra lateral esquerda. Ao clicar, são apresentados mais detalhes. Como nota adicional, pode ver quais as informações enviadas pela sua ferramenta preferida. Isto é útil para fins educativos e de depuração.

## Perguntas Frequentes

### "Preciso de uma chave de API?"

**Não!** Pode utilizar fornecedores gratuitos (Kiro, OpenCode Free, Pollinations) sem qualquer chave de API. Basta ligá-los no painel.

### "O que é `auto`?"

`auto` indica ao OmniRoute para escolher automaticamente o melhor fornecedor para cada pedido. Tem em conta a velocidade, o custo, a qualidade e a disponibilidade. Consulte o [Guia do Auto-Combo](./AUTO-COMBO-GUIDE.md) para obter mais detalhes.

### "Quanto custa?"

O OmniRoute é **gratuito e de código aberto**. Paga apenas pelos fornecedores que utilizar. Muitos fornecedores têm planos gratuitos — consulte o [Guia de Planos Gratuitos](./FREE-TIERS-GUIDE.md).

### "Posso utilizá-lo com Claude Code/Cursor/Copilot?"

**Sim!** O OmniRoute funciona com qualquer ferramenta que suporte o formato OpenAI. Basta definir o URL base como `http://localhost:20128/v1`. Consulte o [Guia de Ferramentas CLI](../reference/CLI-TOOLS.md) para obter instruções de configuração específicas.

### "E se um fornecedor ficar indisponível?"

O OmniRoute ignora automaticamente os fornecedores que falharem e tenta o seguinte. Não precisa de fazer nada. Consulte o [Guia do Auto-Combo](./AUTO-COMBO-GUIDE.md) para obter mais detalhes.
