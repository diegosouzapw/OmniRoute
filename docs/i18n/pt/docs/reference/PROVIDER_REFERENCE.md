## Categorias

- **Gratuito** — nível gratuito com chave de API (configurada através do painel)
- **Sem autenticação** — endpoints públicos que não exigem qualquer chave ou início de sessão
- **OAuth** — fluxo de início de sessão gerido pelo OmniRoute, sem necessidade de chave de API
- **Cookie Web** — encapsula a aplicação Web do fornecedor através de autenticação por cookies
- **Chave de API** — fornecedor pago configurado através de uma chave de API (poderão aplicar-se créditos gratuitos)
- **Local** — executado na máquina do utilizador (Ollama, LM Studio, vLLM, etc.)
- **Pesquisa** — fornecedores de pesquisa na Web
- **Áudio** — fornecedores exclusivamente de áudio (TTS/STT)
- **Proxy a montante** — fornecedores que atuam como proxy para outros fornecedores
- **Agente na nuvem** — agentes de programação de longa duração (Codex Cloud, Devin, Jules)
- **Sistema** — fornecedores internos do OmniRoute (loopback, etc.)

Etiquetas adicionais: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (quando apresentado): `native` — API real de chamada de funções; `emulated` — o array `tools` é emulado através de instruções por `webTools.ts` (blocos `<tool>{...}</tool>` analisados por expressões regulares); `none` — atualmente, `tools` é silenciosamente ignorado. Consulte #7286.

Utilize o painel em `/dashboard/providers` para ativar, configurar e testar cada fornecedor.
