O OmniRoute inclui um conjunto selecionado de proxies gratuitos na tabela `free_proxies`,
sincronizado a partir de fornecedores externos (1proxy, proxifly, iplocate, webshare). O
painel apresenta-os em **Definições → Proxies gratuitos**. Este documento
descreve a filtragem, ordenação, contagem e comunicação de erros de sincronização
do lado do servidor disponibilizadas pela rota de listagem.

## Rota de listagem — `GET /api/settings/free-proxies`

Devolve uma parte filtrada, ordenada e paginada, juntamente com a contagem total. A filtragem e
a contagem são efetuadas em SQL, para que a interface possa apresentar o total real (por exemplo, `Total: 0`)
sem carregar todas as linhas para a memória.

### Parâmetros de consulta

| Parâmetro         | Tipo                               | Predefinição | Significado                                                                                                                       |
| ----------------- | ---------------------------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`         | `LIKE` sensível a maiúsculas e minúsculas na coluna de anfitrião (e de origem).                                                   |
| `protocol`        | string                             | `""`         | Filtro `type`: `http` / `https` / `socks4` / `socks5`. Vazio = todos.                                                             |
| `country`         | string                             | `""`         | Filtro `countryCode` (ISO-2). Vazio = todos.                                                                                      |
| `minQuality`      | number                             | `0`          | Apenas linhas com `qualityScore >= minQuality`. `0` = sem limite mínimo.                                                          |
| `disabledSources` | string                             | `""`         | IDs de origens separados por vírgulas a excluir (por exemplo, `proxifly,webshare`).                                               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`    | `quality` = pontuação decrescente; `latency` = latência crescente (valores nulos no fim); `recent` = `lastValidated` decrescente. |
| `offset`          | number                             | `0`          | Início da paginação.                                                                                                              |
| `limit`           | number                             | `50`         | Tamanho da página (limitado no lado do servidor).                                                                                 |

### Resposta

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` reflete o total filtrado **antes** da paginação, para que a interface possa apresentar
`Total: N` e `hasMore` de forma independente. `syncErrors` usa o ID da origem como chave e
é preenchido apenas para as origens cuja última sincronização falhou — um resultado `Total: 0`
nunca ocorre sem indicação do motivo.

## Adicionar ao conjunto — `POST /api/settings/free-proxies/[id]/add-to-pool`

Promove um proxy gratuito para o conjunto gerido `proxy_registry`. Valida primeiro o
serviço de origem; em caso de sucesso, devolve o ID do novo proxy do conjunto e a latência medida.

## Sincronização — `POST /api/settings/free-proxies/sync`

Volta a obter todas as origens ativadas (ou o subconjunto indicado em `{ "sources": [...] }`). Cada
origem é sincronizada de forma independente; uma origem com falhas é registada em `syncErrors` e as
restantes continuam até à conclusão, pelo que as sincronizações parciais nunca eliminam dados válidos anteriores.

## Estatísticas — `GET /api/settings/free-proxies/stats`

Devolve o agregado `total / inPool / avgQuality / bySource / lastSyncAt`
sem os dados das linhas — utilizado pelos widgets do cabeçalho do painel.
