Dashboard → Providers → **Import from file** cria ligações através de chave de API a partir de uma lista CSV ou JSON. Cada linha pode destinar-se a um fornecedor diferente. A falha parcial faz parte do funcionamento previsto: as linhas válidas continuam a ser importadas quando outras falham, e a janela modal indica os motivos pelos quais as linhas com falhas foram rejeitadas.

Esta importação **não** cria novos nós de endpoint compatíveis com OpenAI/Anthropic. Crie-os primeiro (Dashboard → Providers → Add OpenAI-Compatible ou `omniroute nodes add`) e, em seguida, importe linhas cuja coluna `provider` corresponda ao id desse nó. Um `baseUrl` por linha pode ainda substituir o URL do nó.

## CSV (posicional)

Os nomes das colunas são meramente visuais. O analisador divide cada linha e desestrutura-a por índice:

| Índice | Campo      | Obrigatório | Notas                                                                                                                               |
| ------ | ---------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 0      | `provider` | sim         | id de um fornecedor gerido existente (`openai`, `anthropic`, …) **ou** id de um **nó** compatível com OpenAI/Anthropic já registado |
| 1      | `name`     | sim         | Nome de apresentação da ligação                                                                                                     |
| 2      | `apiKey`   | sim         | Chave de API                                                                                                                        |
| 3      | `baseUrl`  | não         | Substituição do URL por linha                                                                                                       |
| 4      | `priority` | não         | Número inteiro de 1 a 100                                                                                                           |

Uma primeira linha cuja primeira coluna seja a palavra literal `provider` (independentemente de maiúsculas e minúsculas) é ignorada como cabeçalho. As linhas em branco e os comentários iniciados por `#` são ignorados.

Transfira um ficheiro inicial a partir da janela modal de importação (**Download CSV template**). Exemplo:

```csv
# Importação de fornecedores do OmniRoute (colunas posicionais)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Um id inventado, como `openai-compatible-chat-001`, não é um nó. A API devolve `Unknown or unsupported provider` para essa linha; a janela modal apresenta-o junto ao nome da linha.

## JSON

Uma matriz JSON de objetos com os mesmos campos (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Ao contrário do CSV, as chaves JSON têm nomes.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
