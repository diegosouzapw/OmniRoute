## ارائهدهنده چیست؟

ارائهدهنده را مانند یک **اپراتور تلفن همراه** در نظر بگیرید. همانطور که برای برقراری تماس به اپراتور تلفن همراه نیاز دارید، برای استفاده از مدلهای هوش مصنوعی نیز به یک ارائهدهنده هوش مصنوعی نیاز دارید. OmniRoute مانند تلفنی است که با **همه اپراتورها** کار میکند — میتوانید بهصورت خودکار بین آنها جابهجا شوید.

### انواع ارائهدهندگان

| نوع          | چیست                             | نمونهها                           | هزینه                          |
| ------------ | -------------------------------- | --------------------------------- | ------------------------------ |
| **رایگان**   | نیازی به پرداخت ندارد            | Kiro, OpenCode Free, Pollinations | $0                             |
| **کلید API** | به یک کلید API نیاز دارید        | OpenAI, Anthropic, Google         | پرداخت بهازای مصرف             |
| **OAuth**    | ورود با حساب کاربری خود          | Claude Code, GitHub Copilot       | اشتراک                         |
| **کوکی وب**  | از نشست مرورگر شما استفاده میکند | ChatGPT Web (Codex), Gemini Web   | $0 (از حساب شما استفاده میکند) |

### ارائهدهندگان کوکی وب

برای دستورالعملهای عمومی راهاندازی، محدودیتها، عیبیابی و راهنمای احراز هویت مختص هر ارائهدهنده، به **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** مراجعه کنید.

## شروع سریع: نخستین ارائهدهنده خود را متصل کنید

### راهاندازی اختیاری ارائهدهندگان رایگان هنگام اولین اجرا

جادوگر اولین اجرا، کارت مستقلی با عنوان **راهاندازی ارائهدهندگان رایگان** ارائه میدهد. این جادوگر فهرست واجد شرایط فعلی را از رجیستری ارائهدهندگان بدون نیاز به احراز هویت OmniRoute استخراج میکند و سپس به شما امکان میدهد پیش از تأیید، هر ارائهدهنده را بررسی کرده و موارد دلخواه را از حالت انتخاب خارج کنید. OmniRoute هشدار احتیاطی ارائهدهنده و پیوندی به وبسایت آن را نمایش میدهد تا ابتدا شرایط استفاده اشخاص ثالث، حریم خصوصی، دسترسپذیری و محدودیتهای نرخ را بررسی کنید.

این اقدام اختیاری است: تکمیل جادوگر هرگز بهصورت پنهانی اتصالهای ارائهدهندگان رایگان را ایجاد نمیکند.
تنها ارائهدهندگانی را ایجاد میکند که هنوز وجود ندارند، اتصالهای سفارشیشده موجود را بدون تغییر باقی میگذارد و ارائهدهندگان ایجادشده، ازپیش پیکربندیشده و ناموفق را بهصورت جداگانه گزارش میکند. پس از دریافت نتیجهای جزئی، میتوانید با خیال راحت فقط موارد ناموفق را دوباره امتحان کنید.

### گزینه A: ارائهدهنده رایگان (بدون کارت اعتباری)

1. داشبورد را در `http://localhost:20128` باز کنید
2. به **ارائهدهندگان** → **افزودن ارائهدهنده** بروید
3. یکی از این ارائهدهندگان رایگان را انتخاب کنید:
   - **Kiro AI** — مدلهای رایگان Claude (بدون نیاز به احراز هویت)
   - **OpenCode Free** — مدلهای رایگان GPT (بدون نیاز به احراز هویت)
   - **Pollinations** — دسترسی رایگان به GPT-5، Claude و Gemini (بدون نیاز به کلید)
   - **LongCat** — 10M توکن رایگان (اعتبار یکباره، نیازمند حساب کاربری + KYC)
   - **Cloudflare AI** — بیش از 50 مدل، 10K نورون در روز
   - **MLX Gemma 26B** — مدل محلی Apple Silicon (حدود 38.5 توکن بر ثانیه، حدود 15.9GB حافظه RAM)
   - **MLX Qwen 3.8 27B** — مدل محلی Apple Silicon (حدود 9.1 توکن بر ثانیه، حدود 13.1GB حافظه RAM)
4. روی **اتصال** کلیک کنید
5. تمام شد! اکنون به هوش مصنوعی رایگان دسترسی دارید.

### گزینه B: ارائهدهنده کلید API (پولی)

1. یک کلید API از وبسایت ارائهدهنده دریافت کنید:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. داشبورد را در `http://localhost:20128` باز کنید
3. به **ارائهدهندگان** → **افزودن ارائهدهنده** بروید
4. ارائهدهنده خود را انتخاب کنید
5. کلید API خود را جایگذاری کنید
6. روی **اتصال** کلیک کنید
7. تمام شد! اکنون به مدلهای آن ارائهدهنده دسترسی دارید.

### گزینه C: ارائهدهنده OAuth (اشتراکی)

1. داشبورد را در `http://localhost:20128` باز کنید
2. به **ارائهدهندگان** → **افزودن ارائهدهنده** بروید
3. ارائهدهنده خود را انتخاب کنید (برای مثال Claude Code یا GitHub Copilot)
4. روی **اتصال با OAuth** کلیک کنید
5. با حساب کاربری خود وارد شوید
6. تمام شد! اکنون به مدلهای اشتراک خود دسترسی دارید.

### گزینه D: مدلهای محلی MLX (Apple Silicon)

OmniRoute برای رایانههای Mac مجهز به Apple Silicon و حافظه یکپارچه، از اتصال به مدلهای محلی MLX که از طریق `mlx-lm.server` اجرا میشوند، بهعنوان ارائهدهندگان محلی معمولی و سازگار با OpenAI پشتیبانی میکند.

#### پیشنیازها

- **رایانه Mac مجهز به Apple Silicon** (M1/M2/M3/M4)؛ حافظه یکپارچه 24GB یا بیشتر توصیه میشود
- مدیر بسته **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### شروع سریع

1. **وابستگیها را نصب کنید**:

   ```bash
   # اگر uv از قبل نصب نشده است، آن را نصب کنید
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm را نصب کنید
   uv pip install mlx-lm
   ```

2. **سرورهای MLX را بهصورت دستی راهاندازی کنید** (در ترمینالهای جداگانه):

   ```bash
   # ترمینال 1: Gemma 4 26B A4B IT-QAT (درگاه 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ترمینال 2: Qwen 3.8 27B MLX Mixed (درگاه 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **در داشبورد OmniRoute متصل شوید**:
   - به **ارائهدهندگان** → **افزودن ارائهدهنده** بروید
   - **MLX Gemma 26B** یا **MLX Qwen 3.8 27B** را انتخاب کنید
   - روی **اتصال** کلیک کنید (نیازی به کلید API نیست)

4. **با OpenCode استفاده کنید**:
   ```bash
   # OpenCode را برای استفاده از OmniRoute پیکربندی کنید
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # از مدلهای MLX استفاده کنید
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### مدیریت حافظه

**مهم**: با 24GB حافظه یکپارچه، در هر لحظه فقط **یک مدل بزرگ MLX میتواند اجرا شود**.

- Gemma 26B: حدود 15.9GB مصرف اوج حافظه
- Qwen 3.8 27B: حدود 13.1GB مصرف اوج حافظه

باید این موضوع را بهصورت دستی مدیریت کنید:

- در هر لحظه فقط یک سرور MLX را اجرا کنید، یا
- هر دو را روی دستگاههای جداگانه اجرا کنید، یا
- پیش از راهاندازی یکی، دیگری را متوقف کنید

OmniRoute فرایندهای سرور MLX را بهصورت خودکار مدیریت نمیکند — فقط درخواستها را به نقاط پایانی سازگار با OpenAI که پیکربندی کردهاید هدایت میکند.

#### پشتیبانی از فراخوانی ابزار

هر دو مدل از فراخوانی ابزار سازگار با OpenAI پشتیبانی میکنند. برای آزمایش:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### عیبیابی

| مشکل                      | راهحل                                                                                        |
| ------------------------- | -------------------------------------------------------------------------------------------- |
| سرور راهاندازی نمیشود     | `uv run mlx_lm.server --help` را بررسی و شناسههای مدل را تأیید کنید                          |
| کمبود حافظه               | مطمئن شوید فقط یک مدل اجرا میشود؛ سایر برنامهها را ببندید؛ Activity Monitor را بررسی کنید    |
| اتصال رد میشود            | بررسی کنید که سرور روی پورت صحیح (11435/11436) در حال اجرا باشد                              |
| پاسخدهی کند است           | درخواست اول مدل را در حافظه بارگذاری میکند (~30-60s)؛ درخواستهای بعدی سریع هستند             |
| فراخوانی ابزار ناموفق است | مطمئن شوید مدل از ابزارها پشتیبانی میکند؛ گزارشهای OmniRoute را برای خطاهای ترجمه بررسی کنید |

## نحوه اتصال یک ارائهدهنده (گامبهگام)

### گام 1: داشبورد را باز کنید

در مرورگر خود به `http://localhost:20128` بروید.

### گام 2: به بخش ارائهدهندگان بروید

در نوار کناری روی **ارائهدهندگان** کلیک کنید.

### گام 3: روی افزودن ارائهدهنده کلیک کنید

روی دکمه **+ افزودن ارائهدهنده** کلیک کنید.

### گام 4: ارائهدهنده خود را انتخاب کنید

فهرست را مرور کنید یا ارائهدهنده موردنظر خود را جستوجو کنید. روی آن کلیک کنید.

### گام 5: اطلاعات احراز هویت را وارد کنید

- **ارائهدهندگان رایگان**: نیازی به اطلاعات احراز هویت نیست — فقط روی **اتصال** کلیک کنید
- **ارائهدهندگان دارای کلید API**: کلید API خود را جایگذاری کنید
- **ارائهدهندگان OAuth**: روی **اتصال با OAuth** کلیک کرده و وارد شوید

### گام 6: اتصال را آزمایش کنید

برای اطمینان از عملکرد صحیح، روی **آزمایش اتصال** کلیک کنید.

### گام 7: تمام شد!

ارائهدهنده شما اکنون متصل است. میتوانید از آن با `model: "auto"` استفاده کنید یا ارائهدهنده را مستقیماً مشخص کنید.

## استفاده از چندین ارائهدهنده

OmniRoute با **چندین ارائهدهنده** بهترین عملکرد را دارد. این قابلیت مزایای زیر را فراهم میکند:

- **جایگزینی خودکار** — اگر یک ارائهدهنده با مشکل مواجه شود، OmniRoute ارائهدهنده بعدی را امتحان میکند
- **بهینهسازی هزینه** — OmniRoute برای هر درخواست، ارزانترین ارائهدهنده را انتخاب میکند
- **بهینهسازی سرعت** — OmniRoute برای هر درخواست، سریعترین ارائهدهنده را انتخاب میکند
- **بهینهسازی کیفیت** — OmniRoute برای هر وظیفه، بهترین ارائهدهنده را انتخاب میکند

### پیکربندی پیشنهادی

برای بهترین تجربه، حداقل **3 ارائهدهنده** را متصل کنید:

1. **یک ارائهدهنده رایگان** (Kiro، OpenCode Free یا Pollinations) — همیشه در دسترس
2. **یک ارائهدهنده سریع** (Groq، Cerebras) — برای پاسخهای سریع
3. **یک ارائهدهنده باکیفیت** (OpenAI، Anthropic، Google) — برای وظایف پیچیده

سپس از `model: "auto"` استفاده کنید تا OmniRoute بهطور خودکار بهترین گزینه را برای هر درخواست انتخاب کند.

## پرسشهای متداول

### «آیا برای استفاده از OmniRoute باید هزینهای پرداخت کنم؟»

**خیر!** OmniRoute رایگان و متنباز است. میتوانید بدون پرداخت هیچ هزینهای از ارائهدهندگان رایگان (Kiro، OpenCode Free، Pollinations) استفاده کنید. تنها در صورتی هزینه پرداخت میکنید که ارائهدهندگان پولی را انتخاب کنید.

### «کار را با کدام ارائهدهنده شروع کنم؟»

با **Kiro AI** شروع کنید — رایگان است، به کلید API نیاز ندارد و دسترسی به مدلهای Claude را در اختیارتان میگذارد. سپس در صورت نیاز ارائهدهندگان بیشتری اضافه کنید.

### «آیا میتوانم همزمان از چند ارائهدهنده استفاده کنم؟»

**بله!** هدف اصلی OmniRoute همین است. چندین ارائهدهنده را متصل کنید و از `model: "auto"` استفاده کنید تا OmniRoute بهترین گزینه را برای هر درخواست انتخاب کند.

### «اگر یک ارائهدهنده از دسترس خارج شود چه اتفاقی میافتد؟»

OmniRoute بهطور خودکار ارائهدهندگان ناموفق را نادیده میگیرد و ارائهدهنده بعدی را امتحان میکند. لازم نیست کاری انجام دهید.

### «چگونه اتصال یک ارائهدهنده را قطع کنم؟»

به بخش ارائهدهندگان بروید → روی ارائهدهنده کلیک کنید → روی **قطع اتصال** کلیک کنید.

### «آیا میتوانم از کلیدهای API فعلی خود استفاده کنم؟»

**بله!** اگر از قبل برای OpenAI، Anthropic، Google و غیره کلید API دارید، میتوانید از آنها در OmniRoute استفاده کنید. کافی است هنگام اتصال ارائهدهنده، آنها را جایگذاری کنید.
