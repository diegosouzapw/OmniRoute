## مرحله ۱: نصب OmniRoute

روش دلخواه خود را انتخاب کنید:

### گزینه A: npm (پیشنهادشده)

```bash
npm install -g omniroute
```

### گزینه B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` بالاترین نسخه پایدار SemVer **منتشرشده** است. این تگ شاخه `main` در git را دنبال **نمیکند**. برای GitOps، نسخه `diegosouzapw/omniroute:X.Y.Z` را ثابت کنید. به [تگهای ایمیج / کانالهای انتشار](../guides/DOCKER_GUIDE.md#release-channels) مراجعه کنید.

### گزینه C: از کد منبع

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## مرحله ۲: اجرای OmniRoute

```bash
omniroute
```

OmniRoute در `http://localhost:20128` اجرا میشود. داشبورد بهطور خودکار باز خواهد شد.

---

## مرحله ۳: اتصال یک ارائهدهنده رایگان

با اتصال یک ارائهدهنده رایگان، میتوانید **بدون پرداخت هیچ هزینهای** از OmniRoute استفاده کنید.

### گزینه A: Kiro (دسترسی رایگان به Claude — بدون کارت اعتباری)

1. داشبورد را در `http://localhost:20128` باز کنید
2. به **Providers** ← **Add Provider** بروید
3. **Kiro AI** را انتخاب کنید
4. روی **Connect** کلیک کنید (به کلید API نیازی نیست!)
5. تمام! اکنون بهصورت رایگان به مدلهای Claude دسترسی دارید.

### گزینه B: OpenCode Free (بدون احراز هویت)

1. داشبورد را در `http://localhost:20128` باز کنید
2. به **Providers** ← **Add Provider** بروید
3. **OpenCode Free** را انتخاب کنید
4. روی **Connect** کلیک کنید (به کلید API نیازی نیست!)
5. تمام! اکنون بهصورت رایگان به چندین مدل دسترسی دارید.

### گزینه C: Pollinations (بدون نیاز به کلید)

1. داشبورد را در `http://localhost:20128` باز کنید
2. به **Providers** ← **Add Provider** بروید
3. **Pollinations** را انتخاب کنید
4. روی **Connect** کلیک کنید (به کلید API نیازی نیست!)
5. تمام! اکنون بهصورت رایگان به GPT-5، Claude، Gemini و مدلهای بیشتری دسترسی دارید.

## مرحله ۴: اطمینان از عملکرد صحیح

از بخش [API Keys](http://localhost:20128/dashboard/api-manager)، یک کلید جدید ایجاد کنید. این کلید را ذخیره کنید، زیرا دوباره نمایش داده نخواهد شد. توجه داشته باشید که این کلید برای دسترسی ابزارها به OmniRoute است، نه برای دسترسی به ارائهدهندگان بالادستی.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

باید فهرست مدلهای متصلشده خود را ببینید.

## مرحله ۵: اتصال IDE یا CLI به OmniRoute

در ابزار IDE یا CLI خود، مقادیر زیر را تنظیم کنید:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

تمام! اکنون IDE شما با انتخاب خودکار ارائهدهنده از OmniRoute استفاده میکند.

### نمونه IDE: VSCode/Continue.dev

1. در VSCode، افزونه [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) را نصب کنید.
2. فایل `~/.continue/config.yaml` خود را بهروزرسانی کرده و خطوط زیر را اضافه کنید:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. در پنل گفتوگوی Continue.dev، گزینه `OmniRoute - Auto` را انتخاب کنید تا درخواستها به OmniRoute ارسال شوند.
4. (اختیاری) تمرینی برای خواننده: از IDE خود بخواهید فایل `config.yaml` را با سایر پیکربندیهای ازپیشساختهشده بهروزرسانی کند 😊

### نمونه CLI: Codex CLI

1. در سیستمعامل خود، متغیر محیطی را بهصورت دائمی تنظیم کنید.
   برای macOS/Linux (آن را به `~/.bashrc` یا `~/.zshrc` اضافه کنید):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

برای Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. اکنون Codex را با پیکربندی مخصوص OmniRoute اجرا کنیم. دستور زیر را اجرا کنید:

```
omniroute launch-codex --model auto
```

میتوانید این کار را بهصورت دستی با `codex` و پارامترهای خط فرمان برای مشخصکردن endpoint و کلید API انجام دهید، اما با دستور بالا، OmniRoute همهچیز را برای شما مدیریت میکند.

همین اجرای تکدستوری برای سایر CLIها نیز از طریق اجراکننده عمومی امکانپذیر است—`omniroute run <target>` از `claude`، `codex`، `aider`، `goose`، `opencode`، `qwen` و `gemini` پشتیبانی میکند (به [یکپارچهسازیهای CLI](../guides/CLI-INTEGRATIONS.md) مراجعه کنید).

3. اکنون CLI باید درخواستها را به OmniRoute ارسال کند.

### تأیید هدایت ابزار شما به OmniRoute

میتوانید با کلیک روی [Monitoring/Logs](http://localhost:20128/dashboard/logs) در نوار کناری سمت چپ، جزئیات درخواست را مشاهده کنید. با کلیک و ورود به هر مورد، جزئیات بیشتری نمایش داده میشود. همچنین میتوانید ببینید چه اطلاعاتی از ابزار موردعلاقهتان ارسال میشود. این قابلیت از دیدگاه آموزشی و اشکالزدایی مفید است.

## پرسشهای متداول

### «آیا به کلید API نیاز دارم؟»

**خیر!** میتوانید بدون هیچ کلید API از ارائهدهندگان رایگان (Kiro، OpenCode Free و Pollinations) استفاده کنید. کافی است آنها را در داشبورد متصل کنید.

### «`auto` چیست؟»

`auto` به OmniRoute میگوید که برای هر درخواست، بهترین ارائهدهنده را بهطور خودکار انتخاب کند. این انتخاب با درنظرگرفتن سرعت، هزینه، کیفیت و دردسترسبودن انجام میشود. برای جزئیات بیشتر به [راهنمای Auto-Combo](./AUTO-COMBO-GUIDE.md) مراجعه کنید.

### «هزینه آن چقدر است؟»

خود OmniRoute **رایگان و متنباز** است. شما فقط هزینه ارائهدهندگانی را پرداخت میکنید که استفاده میکنید. بسیاری از ارائهدهندگان سطح رایگان دارند—به [راهنمای سطوح رایگان](./FREE-TIERS-GUIDE.md) مراجعه کنید.

### «آیا میتوانم از آن با Claude Code / Cursor / Copilot استفاده کنم؟»

**بله!** OmniRoute با هر ابزاری که از قالب OpenAI پشتیبانی کند، کار میکند. کافی است URL پایه را روی `http://localhost:20128/v1` تنظیم کنید. برای دستورالعملهای راهاندازی مختص هر ابزار، به [راهنمای ابزارهای CLI](../reference/CLI-TOOLS.md) مراجعه کنید.

### «اگر یک ارائهدهنده از دسترس خارج شود چه اتفاقی میافتد؟»

OmniRoute بهطور خودکار ارائهدهندگان ناموفق را نادیده میگیرد و ارائهدهنده بعدی را امتحان میکند. لازم نیست کاری انجام دهید. برای جزئیات بیشتر به [راهنمای Auto-Combo](./AUTO-COMBO-GUIDE.md) مراجعه کنید.
