## `claude-web`

`claude-web` درخواستهای چت با قالب OpenAI را از طریق یک نشست مرورگر احراز هویتشده در `claude.ai` ارسال میکند. اجراکننده، کوکی ارائهشده را نرمالسازی میکند، یک سازمان احراز هویتشده را شناسایی میکند، وضعیت مکالمه را آماده میسازد، انتقال مستقیم یا مرورگر را انتخاب میکند و پاسخ SSE بالادستی را بهطور سختگیرانه ترجمه میکند. هماهنگسازی در `open-sse/executors/claude-web.ts:320` انجام میشود.

> **با ارائهدهندگان Web Cookie تازه آشنا شدهاید؟**
>
> پیش از دنبال کردن این راهنمای مختص ارائهدهنده، برای فرایند راهاندازی عمومی، راهنمای احراز هویت، محدودیتها و عیبیابی، **`docs/getting-started/WEB-COOKIE-GUIDE.md`** را مطالعه کنید.

### فهرست مدلها

رجیستری ارائهدهنده در حال حاضر دقیقاً این هفت شناسه مدل ایستا را ارائه میکند
(`open-sse/config/providers/registry/claude/web/index.ts:11`):

| شناسه مدل                   | نام نمایشی             |
| --------------------------- | ---------------------- |
| `claude-fable-5`            | Claude Fable 5 (وب)    |
| `claude-opus-4-8`           | Claude Opus 4.8 (وب)   |
| `claude-sonnet-5`           | Claude Sonnet 5 (وب)   |
| `claude-haiku-4-5-20251001` | Claude Haiku 4.5 (وب)  |
| `claude-opus-4-7`           | Claude Opus 4.7 (وب)   |
| `claude-opus-4-6`           | Claude Opus 4.6 (وب)   |
| `claude-sonnet-4-6`         | Claude Sonnet 4.6 (وب) |

کشف پویای مدل برای این ارائهدهنده پیادهسازی نشده است. فهرست بالا، کاتالوگ زمان اجرا است.

### اطلاعات احراز هویت و شناسایی سازمان

هدر کامل Cookie مربوط به `claude.ai` یا یک مقدار نشست خام را ارائه کنید. مقادیر خام به `sessionKey` نرمالسازی میشوند؛ اگر کوکیهای دیگری ارائه شده باشند، حفظ میشوند. اجراکننده کوکی را از طریق `cookie` یا `apiKey` میپذیرد و مقادیر اختیاری `deviceId` و `orgId` را از دادههای اتصال میخواند
(`open-sse/executors/claude-web.ts:72`).

اگر `orgId` وجود نداشته باشد، اجراکننده `GET https://claude.ai/api/organizations` را فراخوانی میکند و از نخستین سازمان بازگرداندهشده توسط نشست احراز هویتشده Claude Web استفاده میکند
(`open-sse/executors/claude-web.ts:141`). اگر هیچ سازمان معتبری بازگردانده نشود، عملیات را بهصورت بسته و امن متوقف میکند، رد شدن مجوز نشست را با کد 401 گزارش میدهد و چالش Cloudflare را از شکست احراز هویت متمایز میکند.

### عملیات مکالمه

شیء اختیاری سطح بالای `claude_web` سختگیرانه است. فیلدهای ناشناخته رد میشوند. فیلدهای پذیرفتهشده آن در `open-sse/executors/claude-web/session.ts:50` تعریف شدهاند:

| فیلد                  | معنا                                                              |
| --------------------- | ----------------------------------------------------------------- |
| `operation`           | بهطور پیشفرض `completion`؛ برای تلاش مجدد از `retry` استفاده کنید |
| `conversation_id`     | UUID صریح برای یک مکالمه موجود                                    |
| `parent_message_uuid` | UUID صریح برای پیام دستیار والد                                   |
| `timezone`            | نام معتبر منطقه زمانی IANA                                        |
| `locale`              | محلیسازی دارای ساختار معتبر                                       |
| `tool_states`         | آرایه اختیاری وضعیت ابزارهای حساب، محدود به 128 ورودی             |

درخواستهای آمادهشده از یکی از دو نقطه پایانی بالادستی استفاده میکنند
(`open-sse/executors/claude-web.ts:203`):

- یک نوبت جدید یا پیگیری به
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/completion` ارسال میشود.
- یک تلاش مجدد به
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion` ارسال میشود.

یک نوبت جدید شامل `create_conversation_params` است. یک پیگیری کششده یا دارای پیوند صریح، شامل `parent_message_uuid` است و `create_conversation_params` را حذف میکند. تلاش مجدد به وضعیت مکالمه و پیام والد نیاز دارد و هیچ پرامپتی ارسال نمیکند
(`open-sse/executors/claude-web/session.ts:254`). مکالمههای جدید رابط کاربری احراز هویتشده را در `/new` باز میکنند؛ پیگیریهای کششده یا دارای پیوند صریح، صفحه دقیق مکالمه را باز میکنند
(`open-sse/executors/claude-web/session.ts:324`).

وضعیت مکالمه یک کش درونحافظهای است که بر اساس محدوده حساب SHA-256 و رونوشت متعارف فراخواننده کلیدگذاری میشود. ورودیها پس از 30 دقیقه منقضی میشوند و کش به 5,000 ورودی محدود است
(`open-sse/executors/claude-web/session.ts:12`). وضعیت تنها پس از آن ثبت میشود که تجزیهگر سختگیرانه جریان، `message_stop` را مشاهده کند؛ راهاندازی مجدد فرایند آن را حذف میکند. در صورت عدم تطابق کش، یک درخواست چندپیامی بهجای حذف بیسروصدای پیامهای قبلی، در قالب یک پرامپت بازیابی واحد سریالسازی میشود.

محلیسازی و منطقه زمانی از این ترتیب تقدم استفاده میکنند: مقدار `claude_web` درخواست، مقدار اتصال، مقدار زمان اجرا، سپس `en-US` برای محلیسازی یا `UTC` برای منطقه زمانی
(`open-sse/executors/claude-web/session.ts:218`).

### ابزارها و بارهای درخواست

درخواستهای مستقیم فقط ابزارهای تابع OpenAI با ساختار معتبر را که فراخواننده ارائه کرده است تبدیل میکنند. هیچ فهرست پیشفرض ایستای ساختگی از ابزارها وجود ندارد
(`open-sse/executors/claude-web/payload.ts:102`).

در مقابل، درخواستهای مرورگر، درخواست رابط کاربری احراز هویتشده را ثبت کرده و ابزارهای حساب، وضعیت ابزارها و سبکهای شخصیسازیشده آن را حفظ میکنند. فیلدهای آمادهشده مکالمه، مدل، استدلال، پرامپت و UUID پیام همچنان درخواست ثبتشده را بازنویسی میکنند
(`open-sse/executors/claude-web/browserTransport.ts:175`). قالبهای مرورگر بر اساس هش حساب، سازمان، کوکی، محلیسازی و منطقه زمانی محدودهبندی میشوند و پس از 30 دقیقه منقضی میشوند
(`open-sse/executors/claude-web/browserTransport.ts:11`,
`open-sse/executors/claude-web/browserTransport.ts:158`). هنگامی که یک درخواست مستقیم هیچ ابزاری از فراخواننده نداشته باشد، میتواند از آن قالب محدودهبندیشده مجدداً استفاده کند؛ ابزارهای صریح فراخواننده اولویت دارند
(`open-sse/executors/claude-web/browserTransport.ts:214`).

### انتخاب انتقال

مسیر پیشفرض `sendClaudeWebDirect()` است که `tlsFetchClaude()` را با پروفایل پیکربندیشده Chrome 146 و کوکی ارائهشده فراخوانی میکند (`open-sse/services/claudeTlsClient.ts:23`). این مسیر هیچ حلکنندهای را اجرا نمیکند و کوکی جایگزینی نمیسازد.

برای تبدیل آداپتور مرورگرِ محدود به حساب به انتقال اصلی، مقدار `WEB_COOKIE_USE_BROWSER` را روی `1`، `true` یا `on` تنظیم کنید. برای اینکه در صورت شناسایی چالش 403 مربوط به Cloudflare، انتقال مستقیم بتواند به آداپتور مرورگر بازگردد، مقدار `OMNIROUTE_BROWSER_POOL` را روی یکی از همین مقادیر تنظیم کنید (`open-sse/executors/claude-web.ts:195`). سایر خطاهای HTTP این سازوکار بازگشت را فعال نمیکنند.

آداپتور مرورگر، کوکیها را داخل همان context تجمیعشده Playwright نگه میدارد، از کلید هششده و محدود به دامنه که در بالا توضیح داده شد استفاده میکند و completion را از همان context ارسال میکند (`open-sse/executors/claude-web/browserTransport.ts:444`). این آداپتور هرگز کوکی حلشده توسط مرورگر را به کلاینت مستقیم TLS صادر نمیکند. تلاشهای مجدد مرورگر به یک قالب UI منقضینشده نیاز دارند که به همان context واقعی Playwright متصل باشد (`open-sse/executors/claude-web/browserTransport.ts:467`). خواندن پاسخ مرورگر بهصورت افزایشی در صفحه احراز هویتشده انجام میشود، لغو درخواست را رعایت میکند و بهمحض عبور حجم بدنه بالادستی از 16 MiB، آن را لغو میکند (`open-sse/executors/claude-web/browserTransport.ts:259`).

اجراکننده یک نمای ممیزی ویرایششده را به ثبتکننده مشترک درخواست بازمیگرداند: UUIDهای سازمان، مکالمه و پیام، متن prompt، تعریف ابزارها، کوکیها و شناسههای دستگاه حذف میشوند (`open-sse/executors/claude-web.ts:237`،
`open-sse/executors/claude-web.ts:252`). استثناهای انتقال نیز بهجای پیام پرتابشده، یک خطای عمومی اتصال بازمیگردانند.

### رفتار SSE

`createClaudeWebResponse()` قاببندی LF یا CRLF و فیلدهای چندخطی `data:` را مدیریت میکند. این تابع دلتاهای متن را به `content`، دلتاهای تفکر را به `reasoning_content` و رویدادهای فراداده شناختهشده را به افزونه پاسخ `claude_web` نگاشت میکند. هر رویداد فراداده از طریق فهرست مجاز فیلدهای مختص خودش فرافکنی میشود (`open-sse/executors/claude-web/stream.ts:37`). فراداده مکالمه، پیام والد، پیام دستیار و عملیات نیز در هدرهای `X-OmniRoute-Claude-Web-*` بازگردانده میشود (`open-sse/executors/claude-web/stream.ts:364`).

تجزیهگر در مواجهه با JSON بدقالب، رویدادهای بالادستی `error`، انواع رویداد ناشناخته، ترتیب نامعتبر، عدم تطابق بلوکهای محتوا یا رسیدن به EOF پیش از `message_stop`، بهصورت ایمن متوقف میشود. خروجی جریانی یک قطعه پایان و یک `[DONE]` منتشر میکند؛ خروجی بافرشده نیز از همان تجزیهگر استفاده میکند. تجزیهگر، `message_stop` را بلافاصله پایانی تلقی میکند، دادههای بالادستی پس از آن را لغو میکند و لغو پاییندستی را به خواننده بالادستی منتقل میکند (`open-sse/executors/claude-web/stream.ts:461`،
`open-sse/executors/claude-web/stream.ts:563`). خطوط خاتمهنیافته SSE و رویدادهای انباشتهشده به 1 MiB محدود میشوند (`open-sse/executors/claude-web/stream.ts:17`،
`open-sse/executors/claude-web/stream.ts:62`).

### آزمایش

مجموعه آزمایش قطعی Claude Web را بدون اعتبارنامه واقعی اجرا کنید:

```powershell

```

موارد وابسته به Playwright در `tests/unit/claude-web-auto-refresh.test.ts` صراحتاً نادیده گرفته میشوند. این مخزن در حال حاضر اسکریپتی برای آزمایش زنده Claude Web با اعتبارنامه تعریف نمیکند؛ بنابراین، موارد نادیدهگرفتهشده مدرکی برای عملکرد در زمان اجرا محسوب نمیشوند.

### راهاندازی

1. OmniRoute را با `npm run dev` یا از طریق یک نصب buildشده راهاندازی کنید.
2. مسیر داشبورد ← ارائهدهندگان ← افزودن ارائهدهنده را باز کنید.
3. دسته «کوکی وب» و سپس Claude Web را انتخاب کنید.
4. هدر کامل Cookie کپیشده از یک درخواست احراز هویتشده `claude.ai` را جایگذاری کنید.
