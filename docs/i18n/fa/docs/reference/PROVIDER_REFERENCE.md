تعداد کل ارائهدهندگان: **360**. تفکیک بر اساس دستهبندی را در ادامه ببینید.

## دستهبندیها

- **رایگان** — سطح رایگان با کلید API (پیکربندی از طریق داشبورد)
- **بدون احراز هویت** — نقاط پایانی عمومی که اصلاً به کلید یا ورود نیاز ندارند
- **OAuth** — فرایند ورود توسط OmniRoute مدیریت میشود و به کلید API نیازی نیست
- **کوکی وب** — برنامهٔ وب ارائهدهنده را از طریق احراز هویت مبتنی بر کوکی در بر میگیرد
- **کلید API** — ارائهدهندهٔ پولی که از طریق کلید API پیکربندی میشود (ممکن است اعتبار رایگان ارائه شود)
- **محلی** — روی دستگاه کاربر اجرا میشود (Ollama، LM Studio، vLLM و غیره)
- **جستجو** — ارائهدهندگان جستجوی وب
- **صوتی** — ارائهدهندگان صرفاً صوتی (TTS/STT)
- **پروکسی بالادستی** — ارائهدهندگانی که درخواستها را به سایر ارائهدهندگان پروکسی میکنند
- **عامل ابری** — عاملهای برنامهنویسی با اجرای طولانیمدت (Codex Cloud، Devin، Jules)
- **سیستمی** — ارائهدهندگان داخلی OmniRoute (loopback و غیره)

برچسبهای اضافی: `image`، `video`، `aggregator`، `enterprise`، `embed/rerank`، `self-hosted`.

`فراخوانی ابزار` (در مواردی که نمایش داده شده است): `native` — API واقعی فراخوانی تابع؛ `emulated` — آرایهٔ `tools` از طریق `webTools.ts` در پرامپت شبیهسازی میشود (بلوکهای `<tool>{...}</tool>` با عبارت منظم تجزیه میشوند)؛ `none` — در حال حاضر `tools` بدون اطلاع نادیده گرفته میشود. #7286 را ببینید.

برای فعالسازی، پیکربندی و آزمایش هر ارائهدهنده، از داشبورد در `/dashboard/providers` استفاده کنید.
