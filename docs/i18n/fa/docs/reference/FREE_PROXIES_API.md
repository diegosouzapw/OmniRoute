OmniRoute مجموعهای گزینششده از پراکسیهای رایگان را در جدول `free_proxies` ارائه میکند
که با ارائهدهندگان خارجی (1proxy، proxifly، iplocate و webshare) همگامسازی میشود. داشبورد
این پراکسیها را در بخش **تنظیمات ← پراکسیهای رایگان** نمایش میدهد. این سند
فیلترکردن، مرتبسازی، شمارش و گزارش خطاهای همگامسازی در سمت سرور را
که مسیر فهرست ارائه میدهد، شرح میدهد.

## مسیر فهرست — `GET /api/settings/free-proxies`

یک بخش فیلترشده، مرتبشده و صفحهبندیشده را بههمراه تعداد کل برمیگرداند. فیلترکردن و
شمارش در SQL انجام میشوند؛ بنابراین رابط کاربری میتواند مجموع واقعی (برای مثال، `مجموع: 0`)
را بدون بارگذاری همهٔ ردیفها در حافظه نمایش دهد.

### پارامترهای کوئری

| پارامتر           | نوع                                | پیشفرض    | مفهوم                                                                                                       |
| ----------------- | ---------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------- |
| `search`          | رشته                               | `""`      | اجرای `LIKE` حساس به بزرگی و کوچکی حروف روی ستون میزبان (و منبع).                                           |
| `protocol`        | رشته                               | `""`      | فیلتر `type`:‏ `http` / `https` / `socks4` / `socks5`. مقدار خالی = همه.                                    |
| `country`         | رشته                               | `""`      | فیلتر `countryCode`‏ (ISO-2). مقدار خالی = همه.                                                             |
| `minQuality`      | عدد                                | `0`       | فقط ردیفهایی که `qualityScore >= minQuality` دارند. `0` = بدون حداقل.                                       |
| `disabledSources` | رشته                               | `""`      | شناسههای منبع جداشده با ویرگول برای حذف (برای مثال، `proxifly,webshare`).                                   |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = امتیاز نزولی؛ `latency` = تأخیر صعودی (مقادیر null در انتها)؛ `recent` = `lastValidated` نزولی. |
| `offset`          | عدد                                | `0`       | نقطهٔ شروع صفحهبندی.                                                                                        |
| `limit`           | عدد                                | `50`      | اندازهٔ صفحه (با سقف تعیینشده در سمت سرور).                                                                 |

### پاسخ

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 از سرویس بالادستی"],
    "webshare": ["مهلت اتصال شبکه به پایان رسید"]
  }
}
```

`total` مجموع فیلترشده را **پیش از** صفحهبندی نشان میدهد؛ بنابراین رابط کاربری میتواند
`مجموع: N` و `hasMore` را مستقل از یکدیگر نمایش دهد. کلیدهای `syncErrors` شناسهٔ منبع هستند و
این بخش فقط برای منابعی مقداردهی میشود که آخرین همگامسازی آنها ناموفق بوده است؛ نتیجهٔ `مجموع: 0`
هرگز بدون توضیح باقی نمیماند.

## افزودن به مجموعه — `POST /api/settings/free-proxies/[id]/add-to-pool`

یک پراکسی رایگان را به مجموعهٔ مدیریتشدهٔ `proxy_registry` ارتقا میدهد. ابتدا سرویس
بالادستی را اعتبارسنجی میکند؛ در صورت موفقیت، شناسهٔ پراکسی جدید مجموعه و تأخیر اندازهگیریشده را برمیگرداند.

## همگامسازی — `POST /api/settings/free-proxies/sync`

همهٔ منابع فعال (یا زیرمجموعهٔ مشخصشده در `{ "sources": [...] }`) را دوباره دریافت میکند. هر
منبع بهطور مستقل همگامسازی میشود؛ خطای یک منبع در `syncErrors` ثبت میشود و
سایر منابع همچنان تکمیل میشوند، بنابراین همگامسازیهای جزئی هرگز دادههای معتبر قبلی را پاک نمیکنند.

## آمار — `GET /api/settings/free-proxies/stats`

مجموعهٔ آماری `total / inPool / avgQuality / bySource / lastSyncAt` را
بدون دادههای ردیفها برمیگرداند؛ این مسیر توسط ویجتهای سربرگ داشبورد استفاده میشود.
