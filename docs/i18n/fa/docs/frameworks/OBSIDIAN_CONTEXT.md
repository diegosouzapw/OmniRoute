## چیست

OmniRoute به یک مخزن **Obsidian** بهعنوان **منبع زمینه** متصل میشود — یک پایگاه دانش
محلی Markdown که عاملها از طریق سرور داخلی MCP آن را میخوانند و در آن مینویسند.
این یکپارچهسازی با افزونهٔ عمومی **Obsidian Local REST API** که درون برنامهٔ دسکتاپ
اجرا میشود ارتباط برقرار میکند؛ بنابراین عاملها میتوانند یادداشتها را جستوجو کنند،
فایلها را بخوانند/بنویسند/وصله کنند، محتوای مخزن را فهرست کنند، با یادداشتهای دورهای
روزانه/هفتگی کار کنند، برچسبها را مدیریت کنند، فرمانهای Obsidian را اجرا کنند و
(بهصورت اختیاری) همگامسازی دوطرفهٔ مخزن بین دسکتاپ↔موبایل را هماهنگ کنند.

کلاینت (`src/lib/obsidian/api.ts`) قابلیتهای زیر را پیرامون Local REST API فراهم میکند:

- **تلاش مجدد با تأخیر افزایشی** برای خطاهای گذرای `5xx` و **مهلت زمانی ۳۰ ثانیهای** از طریق `AbortController`.
- **دستهبندی نوعدار خطاها** — `ObsidianAuthError` (401/403)،
  `ObsidianNotFoundError` (404)، `ObsidianServerError` (5xx)، `ObsidianTimeoutError`.
- یک **راهنمای دوستانه برای «عدم دسترسی به Obsidian»** که اشتباه رایج در انتخاب پورت
  را توضیح میدهد (HTTP روی `27123`، **نه** نقطهٔ پایانی MCP روی `27124`) و قالب Tailscale را ذکر میکند.
- **کدگذاری مسیر** نسبت به ریشهٔ مخزن، تا مسیر یادداشتهایی که فاصله یا اسلش دارند ایمن باشند.

## راهاندازی

برای توکن یا URL پایهٔ Obsidian **هیچ متغیر محیطیای وجود ندارد** — هر دو از طریق
`src/lib/db/obsidian.ts` در جدول SQLite با نام `key_value` (فضای نام `obsidian`)
ذخیره میشوند. توکن **در حالت ذخیرهشده رمزنگاری میشود** (AES-256-GCM، با مسیر
جایگزین سازگار با نسخههای قبلی برای متن ساده). آن را از زبانهٔ **منابع زمینه** در
داشبورد Endpoint (`ObsidianSourceCard`) یا از طریق REST API تنظیمات پیکربندی کنید.

> [!IMPORTANT]
> افزونهٔ **Obsidian Local REST API** باید نصب و در حال اجرا باشد. رابط REST آن
> روی **HTTP `127.0.0.1:27123`** (URL پایهٔ پیشفرض) گوش میدهد. پورت `27124`
> یک نقطهٔ پایانی _جداگانه_ برای MCP/HTTPS است و مسیر تنظیمات صراحتاً آن را رد میکند.
> اگر از دستگاه دیگری متصل میشوید، از `http://<tailscale-ip>:27123` استفاده کنید.

### کلیدهای پیکربندی (SQLite `key_value`، فضای نام `obsidian`)

| کلید              | کاربرد                                           | رمزنگاریشده |
| ----------------- | ------------------------------------------------ | ----------- |
| `api_key`         | توکن حامل Local REST API                         | بله         |
| `base_url`        | URL پایهٔ REST (پیشفرض `http://127.0.0.1:27123`) | خیر         |
| `vault_path`      | مسیر مطلق پوشهٔ مخزن (برای همگامسازی)            | خیر         |
| `webdav_username` | نام کاربری تولیدشدهٔ WebDAV (همگامسازی مخزن)     | خیر         |
| `webdav_password` | گذرواژهٔ تولیدشدهٔ WebDAV (همگامسازی مخزن)       | بله         |
| `webdav_enabled`  | فعال بودن یا نبودن همگامسازی مخزن با WebDAV      | خیر         |

### پیکربندی از طریق REST

```bash
# ذخیره و اعتبارسنجی توکن Local REST API (درخواست POST با بررسی وضعیت اعتبارسنجی میکند)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# بررسی وضعیت اتصال (connected، hasToken، baseUrl و vaultPath را برمیگرداند)
curl http://localhost:20128/api/settings/obsidian

# قطع اتصال (توکن ذخیرهشده را پاک میکند)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

همهٔ متدها به احراز هویت داشبورد نیاز دارند. `POST` هر URL روی پورت `27124` را رد
میکند و پیش از ذخیرهسازی، توکن را با فراخوانی نقطهٔ پایانی وضعیت Local REST API
اعتبارسنجی میکند.

### همگامسازی مخزن با WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` یک همگامسازی اختیاری مخزن مبتنی بر
WebDAV را مدیریت میکند (با راهبری `src/lib/obsidianSync.ts`). فعالسازی آن OmniRoute
را به یک پوشهٔ مخزن محلی متصل میکند و یک جفت نام کاربری/گذرواژهٔ تصادفی WebDAV میسازد:

```bash
# فعالسازی همگامسازی WebDAV برای یک پوشهٔ مخزن (نام کاربری/گذرواژه میسازد)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# دریافت وضعیت همگامسازی WebDAV (اعتبارنامهها فقط هنگام فعال بودن برگردانده میشوند)
curl http://localhost:20128/api/settings/obsidian/webdav

# غیرفعالسازی همگامسازی WebDAV (اعتبارنامهها و .stignore مدیریتشده را پاک میکند)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### منبع زمینه بهازای هر کلید API (اختیاری)

پیکربندی Obsidian را میتوان از طریق جدول `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`) **بهازای هر کلید API** محدود کرد. هنگامی که یک
فراخوانی MCP دارای شناسهٔ کلید API احراز هویتشده باشد، `getObsidianConfigForApiKey()`
توکن/URL پایه/مسیر مخزن اختصاصی همان کلید (`source: "api_key"`) را ترجیح میدهد و در
غیر این صورت به پیکربندی سراسری (`source: "global"`) بازمیگردد.

## ابزارهای MCP (22)

در `open-sse/mcp-server/tools/obsidianTools.ts` تعریف شدهاند. توکن/نشانی URL پایه در هر فراخوانی تعیین میشود (ابتدا بر اساس کلید API و سپس بهصورت سراسری). ابزارهایی که به **سرور همگامسازی** OmniRoute متصل میشوند (چهار ابزار `obsidian_sync_*`)، علاوه بر این به توکن احراز هویت همگامسازی که در تنظیمات OmniRoute پیکربندی شده است نیاز دارند.

### ابزارهای خواندن (`read:obsidian`)

| ابزار                        | توضیحات                                                                                               |
| ---------------------------- | ----------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | بررسی میکند که آیا Local REST API در دسترس است و احراز هویت شده است.                                  |
| `obsidian_search_simple`     | جستوجوی تماممتنی در محتوای یادداشتها؛ قطعههای متن را همراه با مسیر فایلها برمیگرداند.                 |
| `obsidian_search_structured` | جستوجو با استفاده از یک عبارت JSON Logic (فیلترهای and/or/regex/path).                                |
| `obsidian_read_note`         | خواندن یادداشت بر اساس مسیر نسبی به vault؛ بهصورت اختیاری یک عنوان/بلوک/frontmatter مشخص.             |
| `obsidian_list_vault`        | فهرستکردن فایلها و پوشههای vault (درخت ورودیها).                                                      |
| `obsidian_get_document_map`  | دریافت ساختار عنوانهای یادداشت بهشکل نگاشت عنوانها → شماره خطوط.                                      |
| `obsidian_get_note_metadata` | دریافت frontmatter، برچسبها، پیوندها و تعداد نویسهها/واژهها بدون محتوای کامل.                         |
| `obsidian_get_active_file`   | دریافت مسیر و محتوای فایل فعال فعلی در Obsidian.                                                      |
| `obsidian_get_periodic_note` | دریافت یادداشت دورهای روزانه/هفتگی/ماهانه برای یک تاریخ (در صورت حذف، امروز).                         |
| `obsidian_get_tags`          | فهرستکردن همه برچسبهای vault همراه با تعداد تکرار آنها.                                               |
| `obsidian_list_commands`     | فهرستکردن شناسههای فرمان موجود Obsidian (برای استفاده با `obsidian_execute_command`).                 |
| `obsidian_sync_status`       | وضعیت سرور همگامسازی OmniRoute: در حال اجرا بودن، نام vault، درگاه، مدتزمان فعالیت و آخرین همگامسازی. |
| `obsidian_sync_conflicts`    | فهرستکردن تعارضهای حلنشده همگامسازی (مسیر، مسیر تعارض و زمان شناسایی).                                |

### ابزارهای نوشتن (`write:obsidian`)

| ابزار                            | توضیحات                                                                             |
| -------------------------------- | ----------------------------------------------------------------------------------- |
| `obsidian_write_note`            | ایجاد یا بازنویسی یک یادداشت با محتوای Markdown دادهشده.                            |
| `obsidian_append_note`           | افزودن محتوا به یک یادداشت؛ بهصورت اختیاری در یک عنوان/بلوک مشخص.                   |
| `obsidian_patch_note`            | افزودن/پیشافزودن/جایگزینی دقیق در یک عنوان، بلوک یا فیلد frontmatter.               |
| `obsidian_delete_note`           | حذف دائمی یک یادداشت از vault.                                                      |
| `obsidian_move_note`             | جابهجایی یا تغییر نام یک یادداشت درون vault.                                        |
| `obsidian_execute_command`       | اجرای یک فرمان Obsidian بر اساس شناسه فرمان آن.                                     |
| `obsidian_open_file`             | بازکردن یک فایل در Obsidian (اگر وجود نداشته باشد، آن را ایجاد میکند).              |
| `obsidian_sync_trigger`          | راهاندازی یک همگامسازی دوطرفه فوری vault بین دسکتاپ↔موبایل.                         |
| `obsidian_sync_resolve_conflict` | حل یک تعارض همگامسازی: نگهداشتن `local` (موبایل)، `remote` (دسکتاپ) یا `keep-both`. |

> [!NOTE]
> مقصدهای `obsidian_patch_note` مقدار `targetType` از نوع `heading | block | frontmatter`
> و مقدار `operation` از نوع `append | prepend | replace` را میپذیرند و
> `createTargetIfMissing` اختیاری است. چهار ابزار `obsidian_sync_*` با سرور همگامسازی
> محلی (`http://127.0.0.1:27781` بهصورت پیشفرض) ارتباط برقرار میکنند و به توکن همگامسازی نیاز دارند.

### دامنهها

ابزارهای خواندن به `read:obsidian` و ابزارهای نوشتن به `write:obsidian` نیاز دارند. اعمال محدودیت
همانند Notion است — توسط `withScopeEnforcement()` در
`open-sse/mcp-server/server.ts` مدیریت میشود، با `OMNIROUTE_MCP_ENFORCE_SCOPES=true` فعال
میشود و دامنههای مجاز از `OMNIROUTE_MCP_SCOPES` یا زمینه دامنه کلید API گرفته میشوند. به
[MCP-SERVER.md](./MCP-SERVER.md) مراجعه کنید.

## نقاط پایانی

| متد      | مسیر                            | هدف                                                         |
| -------- | ------------------------------- | ----------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | برگرداندن `{ connected, hasToken, baseUrl, vaultPath }`.    |
| `POST`   | `/api/settings/obsidian`        | ذخیره و اعتبارسنجی توکن (پورت `27124` را رد میکند).         |
| `DELETE` | `/api/settings/obsidian`        | قطع اتصال (پاککردن توکن ذخیرهشده).                          |
| `GET`    | `/api/settings/obsidian/webdav` | وضعیت همگامسازی WebDAV و اطلاعات احراز هویت (در حالت فعال). |
| `POST`   | `/api/settings/obsidian/webdav` | فعالکردن همگامسازی WebDAV برای یک دایرکتوری مخزن.           |
| `DELETE` | `/api/settings/obsidian/webdav` | غیرفعالکردن همگامسازی WebDAV.                               |

> اینها مسیرهای تنظیمات داشبورد هستند. خود مخزن از طریق API محلی REST آبسیدین
> (`base_url` پیکربندیشده) و ابزارهای MCP بالا قابل دسترسی است — هیچ نقطه پایانی عمومی
> پراکسی آبسیدین در `/v1` وجود ندارد.

## موارد استفاده

- **پاسخهای مبتنی بر مخزن** — ابتدا `obsidian_search_simple` / `obsidian_search_structured`
  و سپس `obsidian_read_note` تا عامل بر اساس یادداشتهای واقعی شما پاسخ دهد.
- **نگارش یادداشت / روزنگاری** — استفاده از `obsidian_write_note`، `obsidian_append_note` یا
  `obsidian_patch_note` برای ویرایش دقیق، با هدف ثبت خروجی عامل، خلاصهها یا یادداشتهای روزانه
  (`obsidian_get_periodic_note`) در مخزن.
- **پیمایش مخزن** — استفاده از `obsidian_list_vault`، `obsidian_get_document_map` و
  `obsidian_get_tags` برای بررسی ساختار پیش از خواندن/نوشتن.
- **خودکارسازی آبسیدین** — استفاده از `obsidian_list_commands` + `obsidian_execute_command` برای
  اجرای افزونهها/فرمانها توسط عامل؛ و `obsidian_open_file` برای نمایش یک یادداشت در رابط کاربری.
- **همگامسازی موبایل** — همگامسازی WebDAV را فعال کنید، سپس از `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  برای هماهنگی دسکتاپ↔موبایل و رفع تعارضها استفاده کنید.
