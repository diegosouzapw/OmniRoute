> **منبع حقیقت:** `src/lib/agentSkills/` (کاتالوگ، مولد، تجزیهگرها) + دایرکتوری `skills/` (فایلهای SKILL.md)
> **آخرین بهروزرسانی:** 2026-08-02 — v3.8.50

Agent Skills فایلهای ساختاریافتهٔ SKILL.md هستند که به عاملهای خارجی، کلاینتهای MCP و هماهنگکنندههای A2A آموزش میدهند چگونه از REST API و CLI در OmniRoute استفاده کنند. برخلاف [Omni Skills](./SKILLS.md) (که تعاریف ابزارهای LLM هستند و درون OmniRoute اجرا میشوند)، Agent Skills یک _کاتالوگ مستندات_ هستند — Markdown ایستا که میتوان آن را مستقیماً در زمینهٔ عامل قرار داد.

---

## نمای کلی

این کاتالوگ شامل **45 مهارت عامل** است (23 مورد REST API + 21 مورد CLI + 1 گردشکار پیکربندی). هر مهارت دارای موارد زیر است:

- یک **شناسهٔ متعارف** (`omni-auth`، `cli-serve` و غیره)
- یک فایل **SKILL.md** در `skills/{id}/SKILL.md` با فرادادهٔ YAML (`name`، `description`) + بدنهٔ غنی Markdown
- **نقاط پایانی REST** (مهارتهای API) یا **زیرفرمانهای CLI** (مهارتهای CLI) که از مشخصات OpenAPI و رجیستری CLI استخراج شدهاند
- یک **نشانی خام GitHub** برای دریافت زنده: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

  openapiParser.ts                     — نقاط پایانی REST را از docs/openapi.yaml استخراج میکند

## نمای کلی

...

## احراز هویت

...

## نقاط پایانی

...

<!-- skill:custom-start -->

## بخش سفارشی (در بازتولید حفظ میشود)

مولد هنگام بازتولید، محتوای میان `<!-- skill:custom-start -->` و `<!-- skill:custom-end -->` را حفظ میکند. ده مهارت دارای بلوکهای سفارشی گردآوریشده هستند:

`omni-mcp`، `omni-compression`، `cli-providers`، `cli-eval`، `omni-agents-a2a`، `omni-combos-routing`، `omni-auth`، `omni-resilience`، `omni-inference`، `cli-serve`.

## کشف REST API

| نقطه پایانی                  | متد  | توضیحات                                                              | احراز هویت |
| :--------------------------- | :--- | :------------------------------------------------------------------- | :--------- |
| `/api/agent-skills`          | GET  | فهرست کاتالوگ (`?category=api\|cli\|config&area=<area>` اختیاری است) | ندارد      |
| `/api/agent-skills/{id}`     | GET  | دریافت فراداده یک مهارت                                              | ندارد      |
| `/api/agent-skills/{id}/raw` | GET  | دریافت SKILL.md بهصورت `text/markdown`                               | ندارد      |
| `/api/agent-skills/coverage` | GET  | آمار پوشش (تعداد فایلهای موجود SKILL.md)                             | ندارد      |
| `/api/agent-skills/generate` | POST | راهاندازی مولد (dryRun/prune/onlyIds)                                | مدیریتی    |

مثال — فهرستکردن همه مهارتهای API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

مثال — دریافت یک SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## کشف MCP

سه ابزار MCP تحت محدوده `read:catalog` ثبت شدهاند:

| ابزار                             | توضیحات                                                 |
| :-------------------------------- | :------------------------------------------------------ |

| `omniroute_agent_skills_get`      | دریافت فراداده و SKILL.md یک مهارت بر اساس `id`         |
| `omniroute_agent_skills_coverage` | آمار پوشش (موجود/کل برای API/CLI)                       |

برای سیمبندی محدوده و احراز هویت، [MCP-SERVER.md](./MCP-SERVER.md) را ببینید.

## کشف A2A

مهارت A2A با نام `list-capabilities`، کاتالوگ کامل 45 مهارت را بهصورت یک مصنوع جدول مارکداون برمیگرداند. هماهنگکنندههای خارجی میتوانند آن را بهشکل زیر فراخوانی کنند:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

برای جزئیات پروتکل، [A2A-SERVER.md](./A2A-SERVER.md) را ببینید.

## عاملهای خارجی چگونه از مهارتها استفاده میکنند

### 1. کشف از طریق REST

```bash
# دریافت کاتالوگ کامل
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# دریافت SKILL.md برای تزریق زمینه
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. کشف از طریق MCP

```typescript
// در یک کلاینت MCP مربوط به Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → آرایهای از AgentSkill که هر مورد دارای rawUrl است
```

### 3. کشف از طریق A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table یک جدول مارکداون شامل همه 45 شناسهٔ مهارت و ستونهای rawUrl است
```

### 4. دریافت مستقیم فایل خام از GitHub (بدون نیاز به سرور)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## مولد

مولد، کاتالوگ گردآوریشده + مشخصات OpenAPI + رجیستری CLI را میخواند و برای هر ورودی، فایل `skills/{id}/SKILL.md` را مینویسد:

```bash
# پیشنمایش (اجرای آزمایشی، بدون نوشتن)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# بازتولید کامل
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# بازتولید شناسههای مشخص
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

پاسخ مولد یک `GeneratorReport` است:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
