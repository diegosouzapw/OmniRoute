درگاه بالادستی `agentrouter` یک فیلتر محتوای مبتنی بر کلیدواژه را روی
`messages[].content` اجرا میکند. این فیلتر تا حدی قطعی است (برخی عبارتها را
همیشه مسدود میکند) و تا حدی احتمالی است (به درخواستهای متوالی حساس است — پس از
ارسال سریع درخواستها سختگیرتر میشود و بعد از یک دوره انتظار بازیابی میشود).

وقتی WAF درخواستی را مسدود میکند، پاسخ زیر را برمیگرداند:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## دامنه عملکرد فیلتر

WAF فقط `messages[].content` را بررسی میکند. موارد زیر را بررسی **نمیکند**:

- پرامپت `system`
- بلوکهای محتوای ساختاریافته (`tool_result`، `tool_use`، `thinking`، `image`)
- فیلدهای `description` و `input_schema` ابزار
- فراداده درخواست، هدرها یا شناسه مدل

## الگوهایی که همیشه مسدود میشوند (بدون حساسیت به بزرگی و کوچکی حروف)

| الگو                        | توضیحات                                                            |
| --------------------------- | ------------------------------------------------------------------ |
| هر نوع عبارت `Lorem ipsum`  | تمام واژگان لاتین lorem مسدود میشوند                               |
| `language model` (بهتنهایی) | عبارتهای "the language model" و "large language model" عبور میکنند |
| `virtual assistant`         | عبارت "AI assistant" عبور میکند                                    |
| `I'm here to help`          | عبارت "here to help" بهتنهایی نیز مسدود میشود                      |
| `Claude, made by Anthropic` | فقط عبارت کامل                                                     |

## الگوهایی که تقریباً همیشه مسدود میشوند

| الگو                                                  | توضیحات                                                  |
| ----------------------------------------------------- | -------------------------------------------------------- |
| `placeholder`                                         | وقتی بهتنهایی استفاده شود (نه مثلاً بهعنوان نام پارامتر) |
| `dummy data`                                          | عبارت اولیه رایج برای fixtureها                          |
| `foo bar baz`                                         | عبارت متعارف برای متن جایگزین                            |
| تکرار توکنهای کوتاه (`AAA BBB CCC`، `test test test`) | تشخیصدهنده انباشت کلیدواژهها                             |

## رفتار تحت بار

پس از حدود ۵ درخواست سریع در یک بازه کوتاه، WAF شروع به مسدود کردن محتوایی
میکند که در حالت عادی عبور میکرد. bucket پس از حدود ۵ تا ۱۰ ثانیه بیکاری
آزاد میشود. این همان محدودکننده نرخ وابسته به IP و کلید است که وقتی Claude Code
یا Codex CLI چندین فراخوانی استفاده از ابزار / ارسال پیام را پشتسرهم و با سرعت
انجام میدهد، باعث بروز خطاهای متناوب `400 content-blocked` میشود.

## راهکارهای کاهشی که قبلاً در OmniRoute اعمال شدهاند

1. **`open-sse/services/wafRateLimit.ts`** — محافظ درخواستهای متوالی که حداقل
   فاصله ۵۰۰ میلیثانیهای را میان درخواستهای خروجی به هر URL از نوع `agentrouter:*`
   اعمال میکند. این فاصله بسیار کمتر از آستانه ادراک تأخیر توسط انسان است و از
   فعال شدن WAF در ترافیک عادی جلوگیری میکند.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — وقتی یک سرویس بالادستی پاسخ
   `400 content-blocked` را برمیگرداند، executor همان URL را با
   عقبنشینی نمایی دوباره امتحان میکند (۱٫۵ ثانیه، ۳٫۰ ثانیه، حداکثر ۲ تلاش).
   پس از این عقبنشینی، WAF معمولاً آزاد میشود و تلاش مجدد موفق خواهد بود.

3. **`tests/unit/compression/harness.test.ts`** — fixture آزمون
   `longInput` از `"lorem ipsum dolor sit amet ".repeat(40)`
   به `"example content for testing purposes ".repeat(40)` تغییر کرد تا وقتی
   Claude Code این فایل را از طریق ابزار `Read` میخواند، محتوای فایل
   دوباره از طریق یک بلوک `tool_result` جریان پیدا نکند و WAF را فعال نکند.

## راهنمای پرامپتها و خروجی ابزار

اگر یک نشست Claude Code یا Codex CLI مکرراً با
`400 content-blocked` مواجه میشود، جدیدترین پیام کاربر و جدیدترین نتیجه ابزار
را برای یافتن هر یک از الگوهای بالا بررسی و آن را بازنویسی کنید. راهکارهای
جایگزین رایج:

- `Lorem ipsum …` را با `example text …` یا محتوای واقعیای که
  آزمون یا fixture سعی در مدلسازی آن دارد جایگزین کنید.
- `placeholder` را (وقتی بهتنهایی استفاده شده است) با `example value`،
  `sample value` یا مقدار واقعی جایگزین کنید.
- `language model` را با `large language model` یا `the model` جایگزین کنید.
- `dummy data` را با `sample data` یا مقادیر اولیه واقعگرایانه جایگزین کنید.
- `I'm here to help` / `here to help` را با شروعی مشخصتر
  جایگزین کنید (برای نمونه، "I'll review the file you mentioned").

## گزارش مثبتهای کاذب به سرویس بالادستی

فیلتر فعلی بیش از حد سختگیرانه است — این فیلتر "Lorem ipsum" را حتی در
بلوکهای `tool_result` مسدود میکند، با اینکه واضح است اپراتور قصد تزریق
پرامپت نداشته است. اپراتورهایی که میخواهند این مشکل از منبع برطرف شود، باید
برای گزارش مثبتهای کاذب با `agentrouter.org` تماس بگیرند. فهرست مسدودی بالا
نتیجه تجربی بررسی سرویس بالادستی تا تاریخ 2026-08-03 است.
