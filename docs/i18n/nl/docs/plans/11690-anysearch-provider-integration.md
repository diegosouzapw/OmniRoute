## 1. Feitelijke servicegegevens (officiële documentatie, kruiselings gecontroleerd)

- Basis-URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - parameters: `query` (verplicht), `max_results` (1-10, standaard 10), `tag` (`{domain}.{sub_domain}` verticale routering), `zone` (cn/intl), `language`, `params` (gestructureerde verticale velden), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - catalogus met mogelijkheden, telt NIET mee voor het quotum.
- `POST /v1/extract` - haalt `{url, title, content}` op en extraheert deze; strikte JSON-body, limiet van 16 KiB.
- `POST /v1/auth/email/register` - registratie via één aanroep, retourneert een eenmalige platte-tekstsleutel `as_sk_...`.
- Authenticatie: optionele `Authorization: Bearer <as_sk_...>`; anonieme toegang wordt beperkt tot limieten per IP en verbruikt het dagelijkse gratis quotum; een ongeldige sleutel retourneert 401/403 ZONDER stille terugval op anonieme toegang.
- Gratis abonnement: 1000 verzoeken/dag, 20 QPS per sleutel. Betaald abonnement: nog niet geprijsd (binnenkort beschikbaar).
- Responsenvelop: succes `{code: 0, message: "success", request_id, data}`; fout `{code: -1, message}`. Authenticatie-/quotumfouten bevatten geen gestructureerde `error_code` (de berichttekst is het signaal); extractiespecifieke fouten bevatten wel een `error_code` (`invalid_extract_url`, `extract_failed`). Geen `Retry-After`-header bij 429.

## 3. Besluiten (alle genomen op 2026-08-26)

1. **Routeringsbeleid: `fallbackOnly`.** Reden: een gratis provider met kosten 0 mag nooit de automatische routering op basis van kosten domineren; expliciete selectie en terugkeer na failover blijven ongewijzigd. Precedent: samengevoegde xquik-vermelding.
2. **Reikwijdte: webSearch + webFetch via `POST /v1/extract` in v1.** In lijn met het mentale model van tavily/exa met dubbele functionaliteit. Verticale interfaces (`tag`, `sub-domains`, `batch_search`) blijven buiten de reikwijdte — er bestaat momenteel geen IR voor verticale parameters.
3. **Quotumweergave: `freeMonthlyQuota: 0`** (conservatieve weergave in xquik-stijl). De werkelijke limiet (1000 verzoeken/dag, dagelijkse reset) wordt in plaats daarvan vermeld in de `authHint`-tekst van de UI-catalogus. Reden: de quotumweergave moet overeenkomen met de resetsemantiek; het omrekenen van een dagelijkse limiet naar een maandelijks equivalent (30000) is een loze belofte die de UI niet kan waarmaken.
4. **searchTypes: alleen `["web"]`.** Er is geen openbaar bewijs voor een verticale nieuws- of afbeeldingenzoekfunctie in de AnySearch API; gateways die API's zonder een gedocumenteerde verticale zoekfunctie integreren (bijv. Google Custom Search), bieden alleen zoeken op het web aan in plaats van nieuws stilzwijgend naar web om te leiden.
5. **Sleutelbeleid:** zonder sleutel werkt; een ongeldige sleutel retourneert 401/403 en wordt nooit stilzwijgend teruggezet naar anonieme toegang (overeenkomstig het upstreamcontract).
6. **Bewuste uitsluitingen:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (chatinterceptie blijft bij firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (anonieme externe endpoints delen één IP-gelimiteerde pool per uitgaand IP-adres, dus extractie zonder sleutel is opt-in en geen kandidaat voor automatische routering); `QUOTA_STATUS_PROVIDERS` (AnySearch signaleert het quotum via 429/envelope, niet via de status 402/403).
