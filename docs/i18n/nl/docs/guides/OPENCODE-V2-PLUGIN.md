`@omniroute/opencode-plugin-v2` voegt je volledige OmniRoute-catalogus — modellen, combo's en
auto-combo's — toe aan de modelkiezer van OpenCode v2, inclusief weergavenamen, prijzen en
budgetten voor de gratis laag.

Het is een afzonderlijk pakket van `@omniroute/opencode-plugin`, omdat OpenCode v1 en v2
plug-ins via verschillende contracten laden. Kies het pakket dat overeenkomt met je
hoofdversie van OpenCode; er wordt niets tussen beide gedeeld, dus het bijwerken van het ene
dwingt nooit een update van het andere af.

## Vereisten

- OpenCode v2.
- Een bereikbare OmniRoute-gateway (standaard `http://localhost:20128`).
- Node.js 22 of 24.

## Installatie

Voeg de plug-in toe aan `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modellen worden vervolgens weergegeven als `omniroute/<provider>/<model>`; `providerId`
bepaalt dat voorvoegsel en de id van de integratie waaronder OpenCode de inloggegevens opslaat.

## Inloggegevens

De plug-in zoekt op drie plaatsen naar een gatewaysleutel, in deze volgorde:

1. **De inloggegevens die je in OpenCode hebt gekoppeld.** De plug-in registreert een
   integratie, zodat de eigen authenticatiestroom van OpenCode de sleutel kan opslaan. Er wordt
   niets in `opencode.json` geplaatst — dit heeft de voorkeur.
2. `apiKey` in de plug-inopties, voor een projectspecifieke overschrijving. Hierdoor komt de
   sleutel terecht in een bestand dat je mogelijk commit.
3. `OMNIROUTE_API_KEY` in de omgeving.

Als geen van de drie aanwezig is, blijft de catalogus leeg en meldt de plug-in dit eenmaal bij
het opstarten, in plaats van je met een stilzwijgend lege kiezer achter te laten.

### Het beheertoken is een andere sleutel

Combo's, providerstatus en verrijking (weergavenamen, prijzen en budgetten voor de gratis laag)
zijn afkomstig van de `/api/*`-endpoints van de gateway. Bij de meeste implementaties worden
deze beschermd met een **beheer**token in plaats van de inferentiesleutel:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Als `managementReadToken` niet is ingesteld, wordt teruggevallen op `apiKey`. Wanneer een
gateway die terugvaloptie weigert, wordt de catalogus nog steeds gepubliceerd, maar met
onbewerkte model-id's in plaats van weergavenamen, zonder deduplicatie van canonieke aliassen,
zonder prijzen en zonder combo's. De plug-in waarschuwt eenmaal per endpoint wanneer dit
gebeurt en vermeldt daarbij het endpoint en wat verloren is gegaan — zodat een beperkte
kiezer nooit een raadsel is.

## Opties

| Sleutel                          | Standaard                                            | Opmerkingen                                                                                                                  |
| -------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                        | Provider-id, integratie-id en het voorvoegsel waaronder modellen worden weergegeven                                          |
| `baseURL`                        | vereist                                              | Gatewayroot, alleen `http(s)`; het achtervoegsel `/v1` wordt waar nodig toegevoegd                                           |
| `apiKey`                         | gekoppelde inloggegevens, daarna `OMNIROUTE_API_KEY` | Chatsleutel voor `/v1/*`                                                                                                     |
| `managementReadToken`            | valt terug op `apiKey`                               | Sleutel voor `/api/*` — meestal **niet** dezelfde                                                                            |
| `displayName`                    | `"OmniRoute"`                                        | Providernaam in de kiezer                                                                                                    |
| `timeoutMs`                      | `10000`                                              | Ophaaltime-out per endpoint (auto-combo's gebruiken 5 s)                                                                     |
| `modelCacheTtlMs`                | `300000`                                             | TTL van de cataloguscache; een momentopname op schijf versnelt koude starts                                                  |
| `timeouts`                       | valt terug op `timeoutMs`                            | Budgetten per endpoint in ms: `models`, `combos`, `autoCombos`, `enrichment`                                                 |
| `enrichment`                     | `true`                                               | Namen, prijzen en budgetten voor de gratis laag ophalen                                                                      |
| `providerTag`                    | `true`                                               | Een weergavenaam vooraf laten gaan door de upstreamprovider waarnaar deze routeert                                           |
| `usableOnly`                     | `false`                                              | Alleen providers behouden die volgens de gateway zijn geconfigureerd                                                         |
| `visibleModels` / `hiddenModels` | `[]`                                                 | Toestaanlijsten op basis van exacte overeenkomst of achtervoegsel; weigeren heeft voorrang                                   |
| `geminiSanitization`             | `true`                                               | De JSON-Schema-sleutelwoorden die Gemini weigert uit toolschema's verwijderen (`$ref`-tools worden ongewijzigd doorgestuurd) |
| `apiFormat.allowAnthropic`       | `false`                                              | Id's op de toestaanlijst via het Anthropic API-blok routeren                                                                 |
| `apiFormat.anthropicModels`      | `[]`                                                 | Volledige model-id's die naar Anthropic worden gerouteerd                                                                    |
| `logLevel` / `startupDebug`      | `warn` / `false`                                     | Uitgebreidheid van de logboekregistratie                                                                                     |

## Hoe de catalogus actueel blijft

De catalogus wordt lui opgehaald en gedurende `modelCacheTtlMs` gecachet, en een momentopname op schijf zorgt ervoor dat de laatst bekende catalogus beschikbaar blijft wanneer de gateway onbereikbaar is — een storing kost u niets behalve actualiteit. Modellen en combo's worden gepubliceerd zodra ze binnenkomen; auto-combo's, de providerlijst en de verrijkingsoverlay worden verwerkt zodra ze beschikbaar zijn, zodat één traag eindpunt niet de hele modelkiezer kan blokkeren.

Namen bevatten wat de gateway weet: de upstreamprovider waarnaar een model wordt gerouteerd, een `[Free]`-markering en het bijbehorende budget — zodat twee verbindingen die hetzelfde model aanbieden van elkaar te onderscheiden blijven. Schakel het voorvoegsel uit met `"providerTag": false`.

Er is geen handmatige vernieuwingsopdracht: OpenCode v2-opdrachten zijn promptsjablonen, geen callbacks, dus een plugin kan er geen aanbieden. Vernieuwingen volgen de TTL; de host wordt alleen gevraagd opnieuw te laden wanneer de catalogus of de overlay daadwerkelijk is gewijzigd, nooit bij elke vernieuwing.

## Toolaanroepen in Gemini

Gemini weigert een volledige aanvraag wanneer de tooldeclaraties `$schema` of `additionalProperties` bevatten en antwoordt met `400 INVALID_ARGUMENT`. De plugin verwijdert die trefwoorden uit toolschema's die bestemd zijn voor een Gemini-model van deze provider en laat alle andere aanvragen ongewijzigd. Een tool met een `$ref` wordt ongewijzigd doorgestuurd in plaats van opgeschoond, omdat het verwijderen van de verwijzing het schema zou verruimen tot "alles accepteren".
Stel `"geminiSanitization": false` in om dit uit te schakelen.

## Probleemoplossing

| Symptoom                                    | Oorzaak                                                                                                               |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Modelkiezer toont geen OmniRoute-model      | Geen sleutel gevonden (controleer de waarschuwing bij het opstarten), of de gateway is onbereikbaar                   |
| Ruwe model-id's, geen combo's, geen prijzen | De beheereindpunten hebben het token geweigerd — stel `managementReadToken` in                                        |
| Een sessie vastgezet op `opencode-<id>/…`   | De v1-plugin publiceerde `opencode-<id>`; v2 publiceert alleen `<id>`, dus selecteer het model opnieuw onder `<id>/…` |
