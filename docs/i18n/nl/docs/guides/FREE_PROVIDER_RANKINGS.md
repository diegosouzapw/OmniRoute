> **Kort samengevat**: OmniRoute rangschikt zijn **gratis** providers op modelkwaliteit met behulp van **Arena AI
> (LMArena-achtige) ELO-scores**. Open de pagina **Free Provider Rankings** in het
> dashboard om te zien welke gratis providers de sterkste modellen voor jouw taak aanbieden —
> algemeen of gefilterd op categorie (programmeren, beoordeling, documentatie, foutopsporing).

---

## Wat het is

OmniRoute registreert 329 providers, waaronder 155 catalogusvermeldingen die als **gratis/zonder authenticatie**
zijn gemarkeerd (zonder authenticatie,
OAuth met gratis niveau of API-sleutel met gratis niveau — zie de
[Handleiding voor gratis niveaus](../getting-started/FREE-TIERS-GUIDE.md) en de volledige
[Map met gratis niveaus](../reference/FREE_TIERS.md)). Het nadeel: gratis providers verschillen
sterk in modelkwaliteit. Een provider zonder authenticatie die een geavanceerd model aanbiedt, is veel nuttiger
dan een provider die een klein verouderd model aanbiedt.

**Free Provider Rankings** beantwoordt de vraag "**welke gratis provider geeft mij het beste model?**" door
de catalogus van elke gratis provider te combineren met **crowd-sourced kwaliteitsscores** van het
**Arena AI-klassement** (ELO op basis van menselijke voorkeuren, hetzelfde concept als achter de
LMArena-chatbotarena). Providers worden vervolgens gerangschikt op basis van de kwaliteit van hun **beste gratis model**.

De rangschikking wordt berekend aan de hand van drie echte bronnen:

1. De lijsten met gratis providers — `NOAUTH_PROVIDERS`, plus vermeldingen in `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` die zijn gemarkeerd met `hasFree`
   (`src/shared/constants/providers.ts`).
2. De modelcatalogus van elke provider uit het providerregister
   (`open-sse/config/providerRegistry.ts`).
3. Uit ELO afgeleide scores voor taakgeschiktheid die door de
   Arena ELO-synchronisatie-engine zijn opgeslagen in de DB-tabel `model_intelligence` (`src/lib/arenaEloSync.ts`).

De koppelingslogica staat in `src/lib/freeProviderRankings.ts`.

## Toegang

### Dashboardpagina

Open het dashboard en ga naar **Costs → Free Provider Rankings**, of navigeer rechtstreeks naar:

```
/dashboard/free-provider-rankings
```

De pagina (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) toont:

- Een **podium met de top 3** (🥇 🥈 🥉) van de hoogst gerangschikte gratis providers.
- Een volledige **rangschikkingstabel** met de kolommen: **Rang**, **Provider**, **Topmodel**,
  **Score**, **Gem. score**, **Modellen**, **Type**.
- **Filterknoppen voor categorieën**: _Alle categorieën_, _Standaard_, _Programmeren_, _Beoordeling_,
  _Documentatie_, _Foutopsporing_.

De **Type**-badge van elke provider geeft aan op welke manier deze gratis is:

| Badge    | Betekenis                                             |
| -------- | ----------------------------------------------------- |
| `NOAUTH` | Altijd gratis, geen inloggegevens nodig               |
| `OAUTH`  | OAuth-provider met een gratis niveau (`hasFree`)      |
| `APIKEY` | API-sleutelprovider met een gratis niveau (`hasFree`) |

Scores worden weergegeven als voor mensen leesbare labels (bijv. _Elite_, _Uitstekend_, _Zeer goed_,
_Goed_, _Gemiddeld_) in plaats van als ruwe getallen, omdat de onderliggende waarde een relatieve
rangschikking van kwaliteit is en geen percentage.

### API-endpoint

De pagina wordt ondersteund door een openbaar leesendpoint
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Queryparameters (gevalideerd met Zod):

| Parameter  | Type   | Standaard | Opmerkingen                                                                                                        |
| ---------- | ------ | --------- | ------------------------------------------------------------------------------------------------------------------ |
| `category` | string | (geen)    | Een van `default`, `coding`, `review`, `documentation`, `debugging`. Laat weg voor de gecombineerde rangschikking. |
| `limit`    | number | `50`      | Begrensd tot het bereik `1–100`.                                                                                   |

Structuur van het antwoord:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` is de oorspronkelijke Arena ELO-waarde; `score` is de genormaliseerde waarde voor
taakgeschiktheid (zie hieronder). Providers zonder modellen met een score worden weggelaten uit het antwoord.

## Hoe de scores werken

### Bron: Arena AI-klassement

De Arena ELO-synchronisatie-engine (`src/lib/arenaEloSync.ts`) haalt twee klassementen op — `text`
en `code` — via de Arena AI-klassement-API
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Elke vermelding in het klassement
bevat een modelnaam, leverancier, ELO-`score`, betrouwbaarheidsinterval en aantal stemmen.

Klassementscategorieën worden als volgt gekoppeld aan OmniRoute-taakcategorieën:

| Arena-klassement | OmniRoute-taakcategorieën                         |
| ---------------- | ------------------------------------------------- |
| `text`           | `default`, `review`, `documentation`, `debugging` |
| `code`           | `coding`                                          |

### Normalisatie (taakgeschiktheidsscore)

Ruwe ELO-scores worden per klassement genormaliseerd tot een **taakgeschiktheidswaarde in `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

De score bereikt nooit `0` of `1`, zodat er ruimte blijft voor gebruikersoverschrijvingen. Dit is het
`score`-veld dat u in de API-respons ziet en het label dat op het dashboard wordt weergegeven.

### Betrouwbaarheid

Elke vermelding krijgt een betrouwbaarheidsniveau op basis van het aantal Arena-stemmen:

| Betrouwbaarheid | Stemmen |
| --------------- | ------- |
| `high`          | ≥ 5.000 |
| `medium`        | ≥ 1.000 |
| `low`           | < 1.000 |

### Opslag en actualiteit

Genormaliseerde vermeldingen worden naar de DB-tabel `model_intelligence` geschreven met
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Vermeldingen **verlopen na
7 dagen**, zodat een leverancier die stopt met synchroniseren uiteindelijk verdwijnt in plaats van
verouderde gegevens aan te bieden.

De synchronisatie wordt **standaard uitgevoerd**:

- Deze wordt eenmaal uitgevoerd wanneer de server wordt gestart en vervolgens periodiek via een timer
  (`src/lib/arenaEloSync.ts`, gekoppeld vanuit `src/instrumentation-node.ts`).
- Deze is **niet-blokkerend en nooit fataal** — als het ophalen bij de externe bron mislukt, blijft OmniRoute
  actief en tonen de ranglijsten gewoon de laatst correct opgehaalde gegevens (of een lege status).

Twee omgevingsvariabelen regelen dit (gedocumenteerd in
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Variabele                 | Standaardwaarde  | Doel                                                                |
| ------------------------- | ---------------- | ------------------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`           | Stel in op `false` om de uitgaande synchronisatie uit te schakelen. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24 uur) | Synchronisatie-interval, in seconden.                               |

### Handmatig synchroniseren / status / wissen

Voor beheerders biedt een geauthenticeerd beheerendpoint handmatige bediening
(`src/app/api/intelligence/sync/route.ts` — vereist beheerauthenticatie):

```
GET    /api/intelligence/sync          # huidige synchronisatiestatus (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # activeer een handmatige synchronisatie; body: { "dryRun": true } voor een voorbeeld zonder te schrijven
DELETE /api/intelligence/sync          # wis alle gesynchroniseerde arena_elo-intelligentievermeldingen
```

Als de ranglijstpagina leeg is, wordt deze opnieuw gevuld met een handmatige
`POST /api/intelligence/sync` (of door simpelweg de server opnieuw te starten).

### Modellen koppelen aan het klassement

Model-ID's in het register en Arena-modelnamen komen niet altijd exact overeen. De rangschikking gebruikt
flexibele koppeling (`findMatchingIntelligence` in `src/lib/freeProviderRankings.ts`):

1. Exacte overeenkomst met de genormaliseerde model-ID.
2. Overeenkomst na het verwijderen van een versiesuffix aan het einde (bijvoorbeeld `kimi-k2.6` → `kimi-k2`).
3. Voorvoegselovereenkomst (een modelnaam uit het klassement is een voorvoegsel van de register-ID).

Aan de synchronisatiezijde worden bekende leveranciersvoorvoegsels (`anthropic/`, `openai/`, `google/`, …)
verwijderd en breidt een kleine aliasmap canonieke namen uit naar de varianten die OmniRoute
intern gebruikt, zodat modellen onder elke naam vindbaar blijven.

### Hoe een leverancier wordt gerangschikt

Voor elke gratis leverancier berekent de engine een score voor elk model in diens catalogus, waarna:

- **Topmodel** = het model van de leverancier met de hoogste score.
- **Gem. score** = de gemiddelde score van alle gescoorde modellen van die leverancier.
- **Modellen** = het aantal modellen van de leverancier dat een Arena-score had.

Leveranciers worden eerst gesorteerd op **topmodelscore** en daarna op gemiddelde score. Hiermee wordt een
leverancier beloond die ten minste één sterk gratis model aanbiedt.

## Gebruiken om gratis providers te kiezen

1. **Kies de juiste categorie.** Gebruik het filter **Coding** voor agentische programmeerworkloads, of
   laat het op **All Categories** / **Default** staan voor algemene chats. Dezelfde provider kan
   per categorie anders scoren, omdat het topmodel per leaderboard verschilt.
2. **Geef voorrang aan het podium bij eenmalige configuraties.** Als je slechts één of twee gratis
   providers wilt verbinden, begin dan met de hoogst gerangschikte providers voor jouw categorie.
3. **Controleer de Type-badge.** `NOAUTH`-providers zijn het snelst te verbinden (geen
   inloggegevens nodig). Gratis niveaus met `OAUTH` / `APIKEY` vereisen een snelle registratie, maar bieden vaak
   krachtigere modellen. Zie de [Handleiding voor gratis niveaus](../getting-started/FREE-TIERS-GUIDE.md) voor
   de verbindingsstappen.
4. **Verbind er meerdere en laat Auto-Combo beslissen.** Dezelfde Arena ELO-gegevens waarop
   deze pagina is gebaseerd, worden ook gebruikt voor de **taakgeschiktheidsfactor** van de Auto-Combo-score-engine
   (`open-sse/services/autoCombo/taskFitness.ts`, verwerkingsvolgorde
   `user_override → arena_elo → models_dev_tier → static table`). Nadat je dus
   de beste gratis providers hebt verbonden, zal routering met `model: "auto"` (bijv. `auto/coding`)
   per aanvraag automatisch de voorkeur geven aan gratis modellen van hogere kwaliteit. Zie
   [Auto-Combo](../routing/AUTO-COMBO.md) voor de volledige scoreberekening met 16 factoren.
