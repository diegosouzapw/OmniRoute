OmniRoute wordt geleverd met een zorgvuldig samengestelde verzameling gratis proxy's in de tabel `free_proxies`,
die wordt gesynchroniseerd vanuit externe providers (1proxy, proxifly, iplocate, webshare). Het
dashboard toont deze onder **Instellingen → Gratis proxy's**. Dit document
beschrijft de server-side filtering, sortering, telling en rapportage van
synchronisatiefouten die door de lijstroute worden aangeboden.

## Lijstroute — `GET /api/settings/free-proxies`

Retourneert een gefilterd, gesorteerd en gepagineerd deel plus het totale aantal. Filteren en
tellen gebeuren in SQL, zodat de UI het werkelijke totaal kan tonen (bijv. `Totaal: 0`)
zonder elke rij in het geheugen te laden.

### Queryparameters

| Parameter         | Type                               | Standaard | Betekenis                                                                                                                  |
| ----------------- | ---------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`      | Hoofdlettergevoelige `LIKE` op de kolom host (en source).                                                                  |
| `protocol`        | string                             | `""`      | `type`-filter: `http` / `https` / `socks4` / `socks5`. Leeg = alles.                                                       |
| `country`         | string                             | `""`      | `countryCode`-filter (ISO-2). Leeg = alles.                                                                                |
| `minQuality`      | number                             | `0`       | Alleen rijen met `qualityScore >= minQuality`. `0` = geen ondergrens.                                                      |
| `disabledSources` | string                             | `""`      | Door komma's gescheiden bron-id's die moeten worden uitgesloten (bijv. `proxifly,webshare`).                               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = score aflopend; `latency` = latentie oplopend (null-waarden als laatste); `recent` = `lastValidated` aflopend. |
| `offset`          | number                             | `0`       | Beginpunt van de paginering.                                                                                               |
| `limit`           | number                             | `50`      | Paginagrootte (begrensd aan de serverzijde).                                                                               |

### Respons

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 van upstream"],
    "webshare": ["netwerktime-out"]
  }
}
```

`total` geeft het gefilterde totaal **vóór** paginering weer, zodat de UI
`Totaal: N` en `hasMore` onafhankelijk van elkaar kan weergeven. `syncErrors` gebruikt de bron-id
als sleutel en wordt alleen gevuld voor bronnen waarvan de laatste synchronisatie is mislukt — een resultaat
van `Totaal: 0` blijft nooit zonder melding.

## Toevoegen aan pool — `POST /api/settings/free-proxies/[id]/add-to-pool`

Promoveert een gratis proxy naar de beheerde `proxy_registry`-pool. Valideert eerst de
upstream; bij succes worden de nieuwe proxy-id in de pool en de gemeten latentie geretourneerd.

## Synchroniseren — `POST /api/settings/free-proxies/sync`

Haalt alle ingeschakelde bronnen opnieuw op (of de subset in `{ "sources": [...] }`). Elke
bron wordt onafhankelijk gesynchroniseerd; een mislukte bron wordt vastgelegd in `syncErrors` en de
andere worden alsnog voltooid, zodat gedeeltelijke synchronisaties nooit eerdere geldige gegevens wissen.

## Statistieken — `GET /api/settings/free-proxies/stats`

Retourneert de aggregatie `total / inPool / avgQuality / bySource / lastSyncAt`
zonder de rijgegevens — gebruikt door de widgets in de dashboardheader.
