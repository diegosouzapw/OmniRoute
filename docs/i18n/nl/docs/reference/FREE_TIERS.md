Grootste **gedocumenteerde** bijdragers: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (vijf limieten per model), `cloudflare-ai` 30M, `api-airforce` 24M. Hun cijfers zouden worden berekend als `RPM/TPM × 24/7 × 30d` — een theoretisch maximum dat geen enkel account kan volhouden. Ze zijn **uitgesloten** van het verdedigbare aantal (en worden in plaats daarvan weergegeven in de rij 'permanent gratis, geen limiet'). Dit is dezelfde vertekening die de miljardenclaims van concurrenten onbetrouwbaar maakt.

## Vernieuwing van 2026-06-17 — wat is er veranderd sinds 2026-06-05

Een webonderzoek door 50 agents (officiële documentatie + nieuws van de afgelopen 7 dagen, antagonistisch geverifieerd) heeft de volledige catalogus bijgewerkt. Hoogtepunten:

- **Verwijderd / geen gratis niveau (2026):** `chutes` (gratis niveau beëindigd in 2026-03), `phind` (bedrijf opgeheven in 2026-01), `kluster` (stopgezet op 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (gratis MiMo-toegang ingetrokken op 2026-05-24, Nemotron-promotie beëindigd in 2026-06 — opnieuw geverifieerd op 2026-06-18), `aimlapi` (gratis niveau gepauzeerd — opnieuw geverifieerd op 2026-06-18), `yi` (Yi-Light uitgefaseerd, betalen naar gebruik — opnieuw geverifieerd op 2026-06-18), `featherless-ai` (momenteel geen gratis niveau), `chipotle` (Chipotle's "Pepper AI" — de via reverse-engineering ontsloten Amelia-chatwidget op `amelia.chipotle.com` waarmee de provider communiceerde, retourneert nu op elke route een 404, inclusief de root; backend buiten gebruik gesteld/verplaatst, bevestigd op 2026-09-15 — volledig uit de catalogus verwijderd, #13131/#4037). `iflytek` / `sparkdesk` blijven vermeld, maar bevatten een waarschuwing over de gebruiksvoorwaarden (Spark Lite is gratis; de gebruiksvoorwaarden beperken gebruik als proxy/relay).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` zijn op 2026-06-01 stopgezet en `2.5 Pro` heeft het gratis niveau verlaten (2026-04); het gratis niveau bestaat nu **uitsluitend uit de Flash-familie** (2.5/3/3.1/3.5 Flash + Gemma). De catalogus **bundelt** nu de Flash-familie (voorheen opgeblazen doordat elke variant afzonderlijk werd geteld: 462M → 60M).
- **Gecorrigeerde aantallen:** `cloudflare-ai` 122M → **30M** (werkelijk 10k Neurons/dag), `doubao` opnieuw geclassificeerd als een eenmalig registratietegoed (niet periodiek), `llm7` 4M → **150M** (gedocumenteerd: 5M tokens/dag), `together` "-Free"-endpoints stopgezet → registratietegoed van $25 eveneens verwijderd (vereist een minimale aankoop van $5, geen gratis proefperiode), `longcat` Preview beëindigd + Flash-modellen uitgefaseerd → uitsluitend **LongCat-2.0**, opnieuw geclassificeerd als een eenmalig registratietegoed van **10M** tokens (KYC vereist, niet periodiek).
- **Nieuwe gratis providers ontdekt:** ⭐ **Kilo Code** (`kilo-gateway` — wisselende "Auto Free"-selectie: NVIDIA Nemotron 3-familie, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 wisselende gratis programmeermodellen), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash permanent gratis + registratiebonus van 20M), en `arcee-ai` Trinity Large Preview.
- **Nieuwe eerlijke niveaus** (zie Methodologie): een categorie _permanent-gratis-maar-zonder-limiet_ (echte periodieke toegang, zonder tokenlimiet die kan worden meegeteld) en een _stortingsgebonden verhoging_ (OpenRouter $10 → +24M/mnd), die beide **afzonderlijk** worden weergegeven, zodat ze het hoofdcijfer nooit opblazen.

> De gedetailleerde tabel per provider verderop is de **momentopname van 2026-06-05**; de bovenstaande wijzigingen hebben voorrang. De actuele, canonieke bron is de catalogus per model in `open-sse/config/freeModelCatalog.ts`.

## Twee regimes — tellen versus beslissen

OmniRoute beantwoordt de vraag "is het gratis?" via twee regimes die bewust
verschillende bronnen raadplegen:

| Regime                 | Bron van waarheid                                                                                                                                                                            | Toepassingsgebieden                                                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Tellen / weergeven** | Opgeloste catalogus — de meegeleverde basis waarop de Radar-feed (`getRadarCatalog`) wordt toegepast                                                                                         | Totalen van de gratis laag, budgetkaart, dashboards                                                                             |
| **Beslissen**          | Alleen de meegeleverde catalogus (`FREE_MODEL_BUDGETS` in `open-sse/config/freeModelCatalog.data.ts`) plus de lokale heuristieken (achtervoegsel `:free`, prijs van nul, `grantsFreeAccess`) | Elke gebruiker van `src/shared/utils/freeModels.ts`: modelimport, `auto/*`-routering, `GET /v1/models` en de browservoorbeelden |

Het tellen kan verbeteren wanneer er een feed beschikbaar is. Beslissingen
blijven gebaseerd op het release-artefact, zodat het antwoord in de browser en
op de server identiek is, offline kan worden gereproduceerd en zonder database
kan worden getest. Als het browservoorbeeld de ene bron zou raadplegen terwijl
de serverimport een andere gebruikt, zou het voorbeeld niet overeenkomen met
wat er na een klik gebeurt — deze scheiding is bewust behouden.

## Methodologie & kanttekeningen

- De cijfers zijn **bovengrensschattingen** op basis van de gedocumenteerde limieten van de gratis laag van elke provider per **2026-06-17**, verzameld via webonderzoek. Gratis lagen veranderen voortdurend — verifieer ze opnieuw voordat u op een cijfer vertrouwt.
- **Waar een vermelding daadwerkelijk voor instaat.** Geen enkele vermelding heeft een betrouwbaarheidsbeoordeling per rij en de API levert die evenmin — beschouw elk cijfer hierboven als een schatting van dezelfde, niet-vermelde kwaliteit. Twee feiten zijn anders, omdat ze handmatig zijn samengesteld in plaats van afgeleid: 44 vermeldingen hebben een onafhankelijk gedocumenteerde harde stop (waarvan 39 de xKiro-rijen zijn, die allemaal dezelfde dagelijkse limiet delen) en 13 vermeldingen hebben een openbaarmaking over prompttraining. `hardStopGuaranteed` wordt alleen ingesteld wanneer in de eigen voorwaarden van de provider staat dat bij overschrijding van de gratis limiet het verzoek wordt geweigerd in plaats van dat er stilzwijgend kosten in rekening worden gebracht, met de bron in een opmerking naast de vermelding; de waarde wordt nooit standaard op `true` ingesteld en blijft uitgeschakeld voor een vermelding die door niemand is geverifieerd. Een ontbrekende vlag voor een harde stop betekent dus „niet vastgesteld”, niet „bekend dat er kosten in rekening worden gebracht”. **STRICT-modus** (de optionele routeringsbeveiliging `freeAccessPolicy=strict`) vertrouwt alleen vermeldingen die deze vlag hebben; elke andere gratis laag wordt uitgesloten als `no-hard-stop` (zie `open-sse/services/autoCombo/strictZeroCostFilter.ts`).
- `estMonthlyFreeTokens` = uitsluitend maandelijks terugkerende tokens. **Eenmalige registratiecredits keren niet terug** en tellen als 0. Stopgezette lagen tellen eveneens als 0.
- Dagelijkse tokenlimiet → `monthly = daily × 30`. Alleen RPD gedocumenteerd → `RPD × ~800 output tokens × 30`. Alleen RPM/TPM (geen dagelijkse limiet) → **onbegrensd** (zie hieronder).
- **Permanent gratis, maar zonder gepubliceerde tokenlimiet** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): dit is echte, terugkerende gratis toegang, beperkt door gebruiksfrequentie/concurrentie. We classificeren deze als `recurring-uncapped` en **tellen ze nooit op** — vermenigvuldiging van `RPM × 24/7 × 30d` zou een fictief maximum opleveren (de vertekening die we afwijzen). Ze worden vermeld zodat u weet dat ze bestaan.
- **Verhoging na storting:** een eenmalige kleine opwaardering die een gratis quotum permanent verhoogt (OpenRouter: $10 → 1000 verzoeken/dag ≈ +24M/maand). Wordt als afzonderlijk cijfer gerapporteerd en buiten het vaste hoofdcijfer gehouden.
- **Aan geschiktheid gebonden quota** (`eligibilityGate: "regional-identity"`): een echt terugkerend quotum dat pas beschikbaar wordt na een regiogebonden identiteitscontrole (momenteel verificatie met een echte naam voor het Chinese vasteland). Wordt met dezelfde regel voor het dedupliceren van pools meegeteld in een afzonderlijk cijfer (`gatedRecurringTokens`), nooit in het vaste hoofdcijfer. Het regime (`freeType`) blijft ongewijzigd, dus de routering blijft ongewijzigd.
- **Bewijsklassen.** De regel: een getal in de catalogus vermeldt de bron ervan in een `// evidence:`-opmerking naast de vermelding — `public-page` (een providerpagina die iedereen kan lezen), `api-public` (een endpoint van de provider waarvoor geen authenticatie vereist is, bijvoorbeeld het openbare plannenendpoint van NaraRouter op router.bynara.id), of `console-verified <date> por <who>` (het cijfer is alleen zichtbaar binnen een accountconsole; de opmerking vermeldt wie het heeft gezien en wanneer, evenals de openbare pagina waarop staat dat de limiet bestaat). De huidige stand: de vijf blokken die op 2026-09-02 opnieuw zijn gecontroleerd, bevatten dit (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); vermeldingen van vóór de hercontrole van 2026-09-02 nemen het eerdere onderzoek over totdat ze worden aangepast; elk **nieuw of gewijzigd** getal zonder bewijsopmerking is een bug. Momenteel is alleen `mistral` via de console geverifieerd.

## Waarom ons aantal lager is dan dat van andere aggregators

De meeste cijfers voor „gratis tokens per maand” op dit gebied zijn optelsommen van labels per model. Het onze is dat bewust niet:

- **Elke gedeelde pool wordt één keer meegeteld.** Het gratis abonnement van Mistral omvat één tegoed van 1B/maand per organisatie; dit bij vijf modellen vermelden maakt er geen 5B van. Opgeteld per model zou onze eigen catalogus **~7.4B** aangeven (opnieuw berekend op 2026-09-03; dit cijfer wordt niet door CI bewaakt — meet het opnieuw wanneer de catalogus verandert) — de kop vermeldt **~1.47B**, omdat dat is wat één account bij elke provider daadwerkelijk kan besteden.
- **Daglimieten worden omgerekend, snelheden niet.** Een gedocumenteerde limiet in tokens/dag wordt `× 30`; een gedocumenteerde limiet in verzoeken/dag wordt `RPD × ~800 tokens × 30`; een provider die alleen verzoeken per minuut publiceert, heeft **geen** maandcijfer en wordt vermeld als _onbegrensd_, en nooit opgeteld. Een snelheidslimiet vermenigvuldigen met 24/7 is de inflatie waaraan wij niet meedoen.
- **Quota waarvoor een regionale identiteitscontrole vereist is, worden apart weergegeven** (`+~6M achter regionale identiteitsverificatie`), omdat de meeste lezers ze niet kunnen gebruiken.
- **Registratietegoeden gelden alleen voor de eerste maand** en worden als een tweede cijfer vermeld, nooit vermengd met het structurele aantal.
- **Het cijfer wordt door CI afgedwongen.** `npm run check:docs-counts` berekent de totalen opnieuw op basis van de catalogus en laat de build mislukken wanneer dit bestand, de README of de budgetkaart daarvan afwijkt.

## ToS-aandachtstabel

> **De ToS-markering is adviserend en vormt geen routeringsblokkade.** Providers die als `tos` zijn gemarkeerd, worden standaard nog steeds opgenomen in routering en combo/fallback; de markering wordt alleen weergegeven op `/dashboard/free-tiers` en `/api/free-tier/summary`. De queryparameter `excludeTosAvoid` is alleen van invloed op de samenvattingsweergave, niet op de globale routering. Het oordeel staat in `open-sse/config/freeTierCatalog.ts` (informatief, niet uitgelezen door routeringsengines).

> Een beknopt overzicht van de voorwaarden van elke provider voor een zelfgehoste persoonlijke proxy voor één gebruiker. `caution` = een clausule over persoonlijk gebruik of proxygebruik die het controleren waard is; `ambiguous` = onduidelijk; `ok` = expliciet toegestaan. | ------------------------------ | -------------------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**            | Verzoeken per minuut / dag / uur                                                             |
| **TPM / TPD**                  | Tokens per minuut / dag                                                                      |
| **Gedocumenteerde toekenning** | Provider publiceert een expliciete dagelijkse/maandelijkse tokenlimiet (verdedigbaar budget) |
| **Theoretisch maximum**        | `rate-limit × 24/7 × 30d` — een maximum, geen toegekend budget                               |
| **Neuron**                     | Cloudflare-rekeneenheid (~1 uitvoertoken)                                                    |

> Gegenereerd op basis van onderzoek per provider op 2026-06-05. Voer de onderzoeksworkflow opnieuw uit (zie `_tasks/features-v3.8.12`) om deze informatie bij te werken.
