Dashboard → Providers → **Importeren uit bestand** maakt API-sleutelverbindingen aan vanuit een CSV- of JSON-lijst. Elke rij kan op een andere provider zijn gericht. Gedeeltelijk mislukken is onderdeel van het contract: geldige rijen worden nog steeds geïmporteerd wanneer andere mislukken, en het dialoogvenster vermeldt waarom de mislukte rijen zijn afgewezen.

Deze import maakt **geen** nieuwe OpenAI/Anthropic-compatibele endpointnodes aan. Maak deze eerst aan (Dashboard → Providers → OpenAI-compatibele toevoegen, of `omniroute nodes add`) en importeer vervolgens rijen waarvan de kolom `provider` de id van die node bevat. Een `baseUrl` per rij kan de URL van de node nog steeds overschrijven.

## CSV (positioneel)

Kolomnamen zijn slechts ter versiering. De parser splitst elke rij en destructureert deze op basis van de index:

| Index | Veld       | Vereist | Opmerkingen                                                                                                                                       |
| ----- | ---------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0     | `provider` | ja      | Bestaande id van een beheerde provider (`openai`, `anthropic`, …) **of** de id van een reeds geregistreerde OpenAI/Anthropic-compatibele **node** |
| 1     | `name`     | ja      | Weergavenaam van de verbinding                                                                                                                    |
| 2     | `apiKey`   | ja      | API-sleutel                                                                                                                                       |
| 3     | `baseUrl`  | nee     | URL-overschrijving per rij                                                                                                                        |
| 4     | `priority` | nee     | Geheel getal van 1–100                                                                                                                            |

Een eerste regel waarvan de eerste kolom het letterlijke woord `provider` bevat (ongeacht hoofdlettergebruik), wordt overgeslagen als koptekst. Lege regels en `#`-commentaar worden overgeslagen.

Download een startbestand vanuit het importdialoogvenster (**CSV-sjabloon downloaden**). Voorbeeld:

```csv
# OmniRoute-providerimport (positionele kolommen)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Een verzonnen id zoals `openai-compatible-chat-001` is geen node. De API retourneert `Unknown or unsupported provider` voor die rij; het dialoogvenster toont dit naast de naam van de rij.

## JSON

Een JSON-array met objecten met dezelfde velden (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Anders dan bij CSV hebben JSON-sleutels een naam.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
