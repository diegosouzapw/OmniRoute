Caveman-compressie kan naast de ingebouwde Engelse regels ook taalspecifieke regelpakketten laden.
Hierdoor blijft de kernengine stabiel, terwijl pakketten voor Portugees, Spaans, Duits, Frans, Italiaans, Japans en
toekomstige talen zich onafhankelijk kunnen ontwikkelen.

## Locatie

Taalpakketten bevinden zich onder:

```txt
open-sse/services/compression/rules/<language>/
```

Momenteel meegeleverde pakketten (geverifieerd aan de hand van de inhoud van de map `rules/`):

| Taal                 | Map            | Aanwezige regelcategorieën                          |
| -------------------- | -------------- | --------------------------------------------------- |
| Engels               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spaans               | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugees (Brazilië) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonesisch          | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italiaans            | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Duits                | `rules/de/`    | `context`, `filler`, `structural`                   |
| Frans                | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japans               | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Opmerking over gelijkwaardigheid:** de pakketten `en`, `es`, `pt-BR`, `id` en `it` bevatten alle 5 categorieën; `de`, `fr` en `ja` worden met 3 categorieën geleverd. Voor de ontbrekende categorieën `dedup` en `ultra` wordt zonder melding teruggevallen op de ingebouwde Engelse regels. Bijdragen om `dedup.json` en `ultra.json` aan de kleinere pakketten toe te voegen, zijn welkom.
>
> Het pakket `pt-BR` is gebaseerd op **[Troglodita](https://github.com/leninejunior/troglodita)** van Lenine Júnior — een compressiesysteem dat volledig vanaf nul is ontworpen voor de Braziliaans-Portugese grammatica (vermindering van pleonasmen, verwijdering van PT-BR-opvulwoorden en technische afkortingen voor de Braziliaanse ontwikkelaarsgemeenschap).
>
> De canonieke categorielijst en het schema per categorie zijn te vinden in [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema-conceptversie 2020-12).

## Taaldetectie

`languageDetector.ts` gebruikt lichtgewicht heuristieken om de taal uit de prompttekst af te leiden. De
geconfigureerde standaardtaal wordt nog steeds gerespecteerd en detectie kan via de configuratie worden uitgeschakeld wanneer nauwkeurige
controle vereist is.

De detectie-uitvoer wordt alleen gebruikt om regelpakketten te kiezen. Deze verandert niets aan de routering naar providers, de selectie
van de landinstelling of de UI-taal.

## Configuratiestructuur

Compressie-instellingen kunnen het volgende bevatten:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` bepaalt de standaardinstellingen voor het dashboard en de voorbeeldweergave. `cavemanConfig` is de runtimeconfiguratie van de engine
die wordt gebruikt wanneer Caveman berichttekst comprimeert.

## Een taalpakket toevoegen

1. Maak `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Gebruik de Caveman-regelindeling uit `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Houd vervangingen terughoudend en voorkom dat code, identifiers, URL's of JSON worden gewijzigd.
4. Voeg tests toe of werk tests bij voor taalselectie en vervangingsgedrag.
5. Maak nieuwe dashboard-/i18n-labels beschikbaar als de taal in UI-selectors voorkomt.

## API

Beschikbare pakketten kunnen worden opgevraagd met:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Het preview-eindpunt accepteert overschrijvingen van de taalconfiguratie:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Alle 6 taalpakketten hebben in v3.8.0 een `SHARED_BOUNDARIES`-clausule gekregen die op elke
Caveman-intensiteit (LITE, FULL, ULTRA) wordt toegepast. Deze instrueert de engine om deze patronen letterlijk te behouden,
ongeacht de verwijdering van omringende opvultekst:

| Patroontype                         | Voorbeeld                              |
| ----------------------------------- | -------------------------------------- |
| Afgeschermde codeblokken            | ` ```python\n...\n``` `                |
| Inlinecode                          | `` `my_var` ``                         |
| URL's                               | `https://example.com/path`             |
| Bestandspaden (absoluut + relatief) | `/etc/hosts`, `./src/index.ts`         |
| Foutkoppen                          | `Error:`, `TypeError:`, `SyntaxError:` |
| Stacktraceregels                    | `  at functionName (file.ts:12:3)`     |

Deze patronen worden opgenomen in `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (voorheen `[]`). De
constante bevindt zich in `open-sse/services/compression/types.ts`.

### Waarom dit belangrijk is

Zonder SHARED_BOUNDARIES konden agressieve Caveman-modi inhoud verwijderen die op herhalend
proza leek, maar in werkelijkheid een codefragment, bestandspad of foutstack was. SHARED_BOUNDARIES fungeert als een
taalonafhankelijk vangnet dat wordt toegepast voordat de regels voor opvultekst worden uitgevoerd.

### preservePatterns aanpassen

Aanvullende patronen kunnen tijdens runtime via de compressie-instellingen worden toegevoegd:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Aangepaste patronen breiden de 6 standaardpatronen uit (ze vervangen deze niet).

## Operationele opmerkingen

- Ingebouwde Engelse regels blijven de terugvaloptie wanneer een taalpakket ontbreekt.
- Ongeldige ingebouwde JSON-pakketten doorstaan de validatie niet, zodat release-assets niet ongemerkt verslechteren.
- Regelpakketten bevatten uitsluitend gegevens en mogen geen code importeren of willekeurige logica uitvoeren.
- De analyse-laag voor compressie registreert de geselecteerde modus en engine, niet de volledige prompttekst.
