Toewijzing is geen providerquotum.

Quotapools bepalen welke API-sleutels een providerpool mogen gebruiken en hoe harde, zachte of burstbeleidsregels worden toegepast. Providerquotum is externe capaciteit die door een provider of een expliciet geconfigureerde bron wordt gerapporteerd. Interne budgetten van Ghostlight zijn governancelimieten die door de beheerder zijn vastgesteld.

De bewerking `ensurePool` is idempotent: een identieke pool blijft ongewijzigd, een gewijzigde toewijzing wordt bijgewerkt en een ontbrekende pool wordt aangemaakt. Dit is bedoeld voor automatisering en begrensde API-clients.

Het alleen-lezen-statuseindpunt is `GET /api/omniroute/status`. De verificatieopdracht is `npm run omniroute:verify`; hiermee wordt geen live modelaanvraag uitgevoerd.
