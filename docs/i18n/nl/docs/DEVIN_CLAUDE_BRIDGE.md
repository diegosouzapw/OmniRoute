`devin-cli-agentic` laat de echte Claude Code-runtime OmniRoute's lokale Anthropic
Messages-endpoint gebruiken, terwijl de officiële Devin CLI modelantwoorden via ACP stdio levert. Het
wijzigt de bestaande Anthropic-, Claude OAuth-, Claude Web- of `devin-cli`-providers niet.

> **Huidige status: vastgezet op Claude Code `2.1.258`; offline- en livevalidatie voor het laatst vastgelegd
> op `2.1.220`.** Met de vastgezette versie `2.1.220` zijn drie geïsoleerde scenario's uitgevoerd via Devin CLI
> `3000.2.17` en model `swe-1-7-lightning`; die laatste live-uitvoering bevestigde door de client beheerde `Read`-,
> `Edit`- en `Bash`-beurten, succesvolle `npm test`-resultaten, detectie van projectcommando's en skills,
> routering uitsluitend via Devin en geen enkel uitgaand verkeer naar Claude. De vastgezette versie is vervolgens verhoogd naar `2.1.258`
> (de CLI-generatie die door OmniRoute's Claude-identiteit wordt geïmiteerd en de eerste lijn die
> het Fable 5.1-niveau standaard meelevert). Met de nieuwe vastgezette versie zijn de installatielaag en `claude --version`
> geverifieerd op de vastgezette basisimage en slagen de unittestsuite van de bridge, `compose config` en het
> statische isolatiebewijs — maar het offline mockscenario en de live suite met drie scenario's
> zijn nog niet opnieuw uitgevoerd. Voer deze opnieuw uit (zie "Vastgezette tools bijwerken") voordat u
> met deze vastgezette versie op de bridge vertrouwt.

## Architectuur

```text
Claude Code 2.1.258 (geïsoleerde Linux-container zonder rootrechten)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-indeling, provider zonder authenticatie)
  -> devin acp --agent-type summarizer (officiële ACP stdio, zonder Devin-tools)
  -> Devin-account in het toegewezen devin-auth-volume
```

De standaard-ACP-agent van de officiële CLI kan zijn eigen tools uitvoeren, dus deze bridge gebruikt
deze niet. De bridge start de vaste `summarizer`-ACP-agent, waarvan de officiële CLI-modus geen tools heeft, en
formatteert het geserialiseerde Anthropic-verzoek als een uitvoeringstrace. Wanneer een andere door Claude beheerde
actie nodig is, moet het antwoord exact één clienttool-envelope bevatten. Elke ACP-
`tool_call` of `tool_call_update` wordt geweigerd voordat een antwoord als
succesvol kan worden gerapporteerd.

De serializer in `open-sse/executors/devin-agentic/serializer.ts` behoudt `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` en de
door Claude Code aangeleverde tools. Afbeeldingen en onbekende blokken leiden expliciet tot een fout. Grote toolresultaten
gebruiken een zichtbare afkappingsmarkering.

De parser accepteert per modelbeurt één zelfstandig `<tool>{...}</tool>`-envelope. Deze controleert
de naam aan de hand van de toollijst van het verzoek, valideert argumenten aan de hand van het JSON
Schema van die tool, weigert combinaties van verhalende tekst en acties, en staat één begrensde herstelpoging toe. Claude Code voert vervolgens
de resulterende Anthropic-`tool_use` lokaal uit en stuurt het `tool_result` via
OmniRoute terug.

## Isolatie- en dreigingsmodel

De Claude-installatie, het account en de configuratie van de host vallen buiten het bereik en worden als
verboden beschouwd. De Compose-services:

- draaien als UID/GID `10001:10001`, met een alleen-lezen rootbestandssysteem, ingetrokken capabilities en
  `no-new-privileges`;
- gebruiken een privémap `/home/bridge`, een toegewezen Claude-configuratievolume, geïsoleerde OmniRoute-data
  en een afzonderlijk `devin-auth`-volume;
- koppelen alleen wegwerpbare `.sandbox`-werkruimten/bewijsmaterialen;
- koppelen niet de homemap van de host, Keychain, SSH, cloudreferenties of de Docker-socket;
- stellen expliciete omgevingen samen en verwijderen Anthropic API-/OAuth-/routeringsvariabelen;
- sturen Claude Code-inferentie uitsluitend naar `http://omniroute:20128` met een sleutel die alleen lokaal geldig is.

Het offlineprofiel gebruikt een intern netwerk. In het liveprofiel bereikt OmniRoute de
officiële Devin-endpoints uitsluitend via `network-guard`; niet-gerelateerde bestemmingen worden geweigerd.
Claude Code heeft een afzonderlijke egress-guard die alles weigert en kan alleen de lokale OmniRoute-
service bereiken via `NO_PROXY`. Auditbestanden van guards worden uitsluitend door hun guardproces gekoppeld. De
scripts verifiëren bestandseigendom, modus, aantal links en elke beslissing voordat
tokenvrij bewijsmateriaal wordt geëxporteerd.

Voer het isolatiebewijs onafhankelijk uit:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Dit valideert de topologie, benoemde mounts, instellingen voor uitvoering zonder rootrechten en alleen-lezen toegang, expliciete lokale routering,
afwezigheid van gevoelige omgevingsvariabelen, afwezigheid van de Docker-socket, geblokkeerde toegang tot
`api.anthropic.com` en `claude.ai`, providerselectie uitsluitend via Devin en expliciete fouten wanneer
de ACP-backend niet beschikbaar is.

## Eerste installatie en normaal gebruik

Bouw de vastgezette image:

```bash
./scripts/devin-bridge/build
```

Verifieer alleen het geïsoleerde Devin-volume:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

De aanmeldopdracht gebruikt de officiële handmatige tokenprocedure die bedoeld is voor externe/containeromgevingen. De waarde wordt rechtstreeks ingevoerd in de CLI-prompt; deze wordt niet doorgegeven als procesargument, naar Git geschreven of vanaf de host gekopieerd.

Start de geïsoleerde Claude Code-runtime:

```bash
./scripts/devin-bridge/launch
```

`launch` controleert de isolatie, Devin-authenticatie en modeldetectie opnieuw voordat de gecontaineriseerde Claude Code wordt gestart. Het Claude-uitvoerbare bestand van de host wordt nooit uitgevoerd. Modelaliassen kunnen worden ingesteld in `.env.devin-bridge`; elke geconfigureerde waarde moet het voorvoegsel `devin-cli-agentic/` behouden.

## Validatieopdrachten

Het reproduceerbare offlinepad vereist geen Devin-account en heeft tijdens runtime geen internettoegang:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Het geauthenticeerde, optionele livepad is:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

De live-runner wacht tussen scenario's om te voorkomen dat ACP-sessies kort na elkaar worden geopend en valideert gestructureerde Claude-streamgebeurtenissen in plaats van tekstuele beweringen te vertrouwen. De drie scenario's bewijzen:

1. directe projectuitlezingen en defectanalyse;
2. een echte `Edit`, een `Bash`-`npm test` onder beheer van de client en een eindresultaat;
3. detectie van `/bridge-check` plus `bridge-proof`, projectuitlezingen, nog een succesvolle `npm test` onder beheer van de client en voltooiing zonder openstaand werk.

De laatste controle controleert ook de Devin-netwerkaudit en vereist dat de Claude-uitgaande-verkeersaudit leeg blijft.

## Vastgezette tools bijwerken

De image zet Node, Claude Code en Devin CLI vast in `docker/devin-bridge/Dockerfile`. Bijwerken:

1. wijzig de expliciete versies;
2. vervang beide architectuurspecifieke checksums van het Devin-archief door waarden voor het officiële artefact;
3. bouw opnieuw en voer elke offlinevalidatieopdracht uit;
4. bevestig de versies in de image;
5. voer de geauthenticeerde livesuite met drie scenario's opnieuw uit.

Installeer geen van beide CLI's globaal op de host en vervang checksumverificatie niet door een niet-geverifieerde download.

## Diagnose en opschoning

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  toont lokale routering en opgeschoonde executorfouten.
- `.sandbox/evidence/mock-acp.jsonl` registreert deterministische mock-ACP-acties.
- `.sandbox/evidence/claude-stream.jsonl` registreert de echte offline-uitvoering van Claude Code.
- `.sandbox/evidence/live-*.jsonl` registreert de drie gevalideerde livestreampjes.
- `.sandbox/evidence/egress.jsonl` en `.sandbox/evidence/claude-egress.jsonl` zijn gevalideerde, tokenvrije kopieën van de guard-audits.

Stop containers en netwerken in eigen beheer, maar behoud de aanmeldings-/configuratievolumes:

```bash
./scripts/devin-bridge/clean
```

Verwijder de volledige omgeving die bij de bridge hoort, inclusief benoemde volumes:

```bash
./scripts/devin-bridge/clean --all
```

## Beperkingen

- De bridge is afhankelijk van de vaste `summarizer`-rol zonder tools, omdat Devin CLI `3000.2.17`
  geen neutrale ACP-agent zonder tools beschikbaar stelt. De adapter compenseert voor
  tussentijdse antwoorden in samenvattingsvorm, maar één begrensde herstelpoging kan nog steeds expliciet mislukken.
- Live ACP-aanroepen kunnen tijdelijke `502`/`504`-antwoorden retourneren. De testomgeving
  spreidt scenario's; aanhoudende fouten blijven fail-closed en er wordt nooit een andere provider geselecteerd.
- De ACP-context wordt opnieuw opgebouwd op basis van elk Anthropic-verzoek; er is geen
  proces-/sessieaffiniteit.
- Er wordt één toolaanroep per modelantwoord ondersteund; parallelle aanroepen worden geweigerd.
- Afbeeldingen worden expliciet niet ondersteund. Vision, thinking-uitvoer, effort-instellingen en een
  contextvenster van 1M worden niet aangeboden.
- SSE gebruikt geldige Anthropic-lifecycle-events, maar wordt verzonden nadat de begrensde ACP-beurt is
  verzameld; ACP-chunks worden niet incrementeel doorgestuurd.
