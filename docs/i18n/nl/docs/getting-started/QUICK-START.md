> **TL;DR**: Installeren → Een gratis provider verbinden → Je IDE naar OmniRoute verwijzen. Klaar.

---

## Stap 1: OmniRoute installeren

Kies de methode van je voorkeur:

### Optie A: npm (aanbevolen)

```bash
npm install -g omniroute
```

### Optie B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` is de hoogste **gepubliceerde** stabiele SemVer-versie. Deze volgt niet automatisch git `main`. Zet voor GitOps de versie vast op `diegosouzapw/omniroute:X.Y.Z`. Zie [Image-tags/releasekanalen](../guides/DOCKER_GUIDE.md#release-channels).

### Optie C: Vanuit de broncode

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Stap 2: OmniRoute starten

```bash
omniroute
```

OmniRoute start op `http://localhost:20128`. Het dashboard wordt automatisch geopend.

---

## Stap 3: Een gratis provider verbinden

Je kunt OmniRoute **geheel kosteloos gebruiken** door een gratis provider te verbinden.

### Optie A: Kiro (gratis Claude — geen creditcard)

1. Open het dashboard op `http://localhost:20128`
2. Ga naar **Providers** → **Provider toevoegen**
3. Selecteer **Kiro AI**
4. Klik op **Verbinden** (geen API-sleutel nodig!)
5. Klaar! Je hebt nu gratis toegang tot Claude-modellen.

### Optie B: OpenCode Free (geen authenticatie)

1. Open het dashboard op `http://localhost:20128`
2. Ga naar **Providers** → **Provider toevoegen**
3. Selecteer **OpenCode Free**
4. Klik op **Verbinden** (geen API-sleutel nodig!)
5. Klaar! Je hebt nu gratis toegang tot meerdere modellen.

### Optie C: Pollinations (geen sleutel nodig)

1. Open het dashboard op `http://localhost:20128`
2. Ga naar **Providers** → **Provider toevoegen**
3. Selecteer **Pollinations**
4. Klik op **Verbinden** (geen API-sleutel nodig!)
5. Klaar! Je hebt nu gratis toegang tot GPT-5, Claude, Gemini en meer.

---

## Stap 4: Controleren of het werkt

Maak via [API-sleutels](http://localhost:20128/dashboard/api-manager) een nieuwe sleutel aan. Bewaar deze sleutel, want hij wordt niet opnieuw weergegeven. Houd er rekening mee dat deze sleutel bedoeld is om tools toegang tot OmniRoute te geven, niet om toegang te krijgen tot externe providers.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Je verbonden modellen zouden nu in de lijst moeten staan.

## Stap 5: Je IDE of CLI naar OmniRoute verwijzen

Stel in je IDE- of CLI-tool het volgende in:

```
Basis-URL: http://localhost:20128/v1
API-sleutel:  [kopieer vanuit Dashboard → Endpoints]
Model:    auto
```

Dat is alles! Je IDE gebruikt nu OmniRoute met automatische providerselectie.

### IDE-voorbeeld: VSCode/Continue.dev

1. Installeer in VSCode de extensie [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Werk je `~/.continue/config.yaml` bij door de volgende regels toe te voegen:

```
  - name: OmniRoute - Automatisch
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Selecteer in het chatvenster van Continue.dev `OmniRoute - Automatisch`. Je verzoeken worden dan naar OmniRoute verzonden.
4. (Optioneel) Oefening voor de lezer: laat je IDE het bestand `config.yaml` bijwerken met alle andere vooraf samengestelde configuraties 😊

### CLI-voorbeeld: Codex CLI

1. Stel de omgevingsvariabele permanent in op je besturingssysteem.
   Voor macOS/Linux (voeg dit toe aan `~/.bashrc` of `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Voor Windows (Opdrachtprompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Nu starten we Codex, maar dan geconfigureerd voor OmniRoute. Voer het volgende uit:

```
omniroute launch-codex --model auto
```

Je kunt dit handmatig doen via `codex` en opdrachtregelparameters gebruiken om het endpoint en de API-sleutel op te geven, maar met de bovenstaande opdracht regelt OmniRoute alles voor je.

Dezelfde startmethode met één opdracht werkt voor andere CLI's via de generieke launcher — `omniroute run <target>` ondersteunt `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` en `gemini` (zie [CLI-integraties](../guides/CLI-INTEGRATIONS.md)).

3. De CLI zou nu verzoeken naar OmniRoute moeten verzenden.

### Controleren of je tool via OmniRoute routeert

Je kunt de details van het verzoek bekijken door in de linkerzijbalk op [Monitoring/logboeken](http://localhost:20128/dashboard/logs) te klikken. Door verder te klikken krijg je meer details te zien. Daarnaast kun je bekijken welke informatie vanuit je favoriete harness wordt verzonden. Dit is nuttig voor educatieve doeleinden en foutopsporing.

## Veelgestelde vragen

### "Heb ik een API-sleutel nodig?"

**Nee!** Je kunt gratis providers (Kiro, OpenCode Free en Pollinations) zonder API-sleutel gebruiken. Verbind ze eenvoudig via het dashboard.

### "Wat is `auto`?"

`auto` geeft OmniRoute de opdracht om automatisch voor elk verzoek de beste provider te kiezen. Daarbij wordt rekening gehouden met snelheid, kosten, kwaliteit en beschikbaarheid. Zie de [Auto-Combo-handleiding](./AUTO-COMBO-GUIDE.md) voor meer informatie.

### "Hoeveel kost het?"

OmniRoute zelf is **gratis en opensource**. Je betaalt alleen voor de providers die je gebruikt. Veel providers hebben gratis abonnementen — zie de [Handleiding voor gratis abonnementen](./FREE-TIERS-GUIDE.md).

### "Kan ik het gebruiken met Claude Code / Cursor / Copilot?"

**Ja!** OmniRoute werkt met elke tool die de OpenAI-indeling ondersteunt. Stel de basis-URL eenvoudig in op `http://localhost:20128/v1`. Zie de [Handleiding voor CLI-tools](../reference/CLI-TOOLS.md) voor specifieke installatie-instructies.

### "Wat gebeurt er als een provider uitvalt?"

OmniRoute slaat providers die niet werken automatisch over en probeert de volgende. Je hoeft niets te doen. Zie de [Auto-Combo-handleiding](./AUTO-COMBO-GUIDE.md) voor meer informatie.
