## 1 veiksmas: įdiekite OmniRoute

Pasirinkite pageidaujamą būdą:

### A parinktis: npm (rekomenduojama)

```bash
npm install -g omniroute
```

### B parinktis: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` yra naujausia **paskelbta** stabili SemVer versija. Ji **neseka** git šakos `main`. Naudodami GitOps, prisekite `diegosouzapw/omniroute:X.Y.Z`. Žr. [atvaizdų žymas / leidimų kanalus](../guides/DOCKER_GUIDE.md#release-channels).

### C parinktis: iš pirminio kodo

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## 2 veiksmas: paleiskite OmniRoute

```bash
omniroute
```

OmniRoute paleidžiama adresu `http://localhost:20128`. Valdymo skydelis atidaromas automatiškai.

---

## 3 veiksmas: prijunkite nemokamą teikėją

OmniRoute galite naudoti **visiškai nemokamai**, prijungę nemokamą teikėją.

### A parinktis: Kiro (nemokamas Claude — nereikia kredito kortelės)

1. Atidarykite valdymo skydelį adresu `http://localhost:20128`
2. Eikite į **Teikėjai** → **Pridėti teikėją**
3. Pasirinkite **Kiro AI**
4. Spustelėkite **Prisijungti** (API rakto nereikia!)
5. Baigta! Dabar galite nemokamai naudotis Claude modeliais.

### B parinktis: OpenCode Free (nereikia autentifikuotis)

1. Atidarykite valdymo skydelį adresu `http://localhost:20128`
2. Eikite į **Teikėjai** → **Pridėti teikėją**
3. Pasirinkite **OpenCode Free**
4. Spustelėkite **Prisijungti** (API rakto nereikia!)
5. Baigta! Dabar galite nemokamai naudotis keliais modeliais.

### C parinktis: Pollinations (rakto nereikia)

1. Atidarykite valdymo skydelį adresu `http://localhost:20128`
2. Eikite į **Teikėjai** → **Pridėti teikėją**
3. Pasirinkite **Pollinations**
4. Spustelėkite **Prisijungti** (API rakto nereikia!)
5. Baigta! Dabar galite nemokamai naudotis GPT-5, Claude, Gemini ir kitais modeliais.

## 4 veiksmas: patikrinkite, ar viskas veikia

Skiltyje [API raktai](http://localhost:20128/dashboard/api-manager) sukurkite naują raktą. Išsaugokite šį raktą, nes jis daugiau nebus rodomas. Atkreipkite dėmesį, kad šis raktas skirtas įrankiams pasiekti OmniRoute, o ne išorinius teikėjus.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Turėtumėte matyti prijungtų modelių sąrašą.

## 5 veiksmas: nukreipkite savo IDE arba CLI į OmniRoute

Savo IDE arba CLI įrankyje nustatykite:

```
Bazinis URL: http://localhost:20128/v1
API raktas:  [nukopijuokite iš Valdymo skydelis → Galiniai taškai]
Modelis:     auto
```

Štai ir viskas! Dabar jūsų IDE naudoja OmniRoute su automatiniu teikėjo parinkimu.

### IDE pavyzdys: VSCode/Continue.dev

1. VSCode įdiekite [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) plėtinį.
2. Atnaujinkite savo `~/.continue/config.yaml`, pridėdami šias eilutes:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev pokalbių srityje pasirinkite `OmniRoute - Auto` ir užklausos bus siunčiamos į OmniRoute.
4. (Pasirinktinai) Užduotis skaitytojui – paprašykite savo IDE atnaujinti `config.yaml`, įtraukiant visas kitas iš anksto parengtas konfigūracijas 😊

### CLI pavyzdys: Codex CLI

1. Savo operacinėje sistemoje nustatykite nuolatinį aplinkos kintamąjį.
   macOS/Linux sistemose (pridėkite prie `~/.bashrc` arba `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows sistemoje (komandų eilutėje):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Dabar paleiskime Codex, sukonfigūruotą naudoti OmniRoute. Vykdykite:

```
omniroute launch-codex --model auto
```

Tai galite atlikti rankiniu būdu naudodami `codex` ir komandų eilutės parametrus galiniam taškui bei API raktui nurodyti, tačiau naudojant pirmiau pateiktą komandą OmniRoute viskuo pasirūpins už jus.

Toks pats paleidimas viena komanda veikia ir su kitais CLI naudojant bendrąją paleidyklę — `omniroute run <target>` palaiko `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` ir `gemini` (žr. [CLI integracijas](../guides/CLI-INTEGRATIONS.md)).

3. Dabar CLI turėtų siųsti užklausas į OmniRoute.

### Patvirtinkite, kad jūsų įrankis nukreipia užklausas į OmniRoute

Užklausos informaciją galite peržiūrėti kairėje šoninėje juostoje spustelėję [Stebėjimas / žurnalai](http://localhost:20128/dashboard/logs). Spustelėję toliau matysite daugiau informacijos. Taip pat galite pamatyti, kokią informaciją siunčia jūsų mėgstama vykdymo aplinka. Tai naudinga mokantis ir derinant problemas.

## Dažniausi klausimai

### „Ar man reikia API rakto?“

**Ne!** Nemokamais teikėjais (Kiro, OpenCode Free, Pollinations) galite naudotis be jokio API rakto. Tiesiog prijunkite juos valdymo skydelyje.

### „Kas yra `auto`?“

`auto` nurodo OmniRoute automatiškai parinkti tinkamiausią teikėją kiekvienai užklausai. Atsižvelgiama į greitį, kainą, kokybę ir pasiekiamumą. Išsamesnės informacijos rasite [Auto-Combo vadove](./AUTO-COMBO-GUIDE.md).

### „Kiek tai kainuoja?“

Pati OmniRoute yra **nemokama ir atvirojo kodo**. Mokate tik už naudojamus teikėjus. Daugelis teikėjų siūlo nemokamus planus — žr. [nemokamų planų vadovą](./FREE-TIERS-GUIDE.md).

### „Ar galiu ją naudoti su Claude Code / Cursor / Copilot?“

**Taip!** OmniRoute veikia su bet kuriuo įrankiu, palaikančiu OpenAI formatą. Tiesiog nustatykite bazinį URL į `http://localhost:20128/v1`. Konkrečias sąrankos instrukcijas rasite [CLI įrankių vadove](../reference/CLI-TOOLS.md).

### „Kas nutiks, jei teikėjas nustos veikti?“

OmniRoute automatiškai praleidžia neveikiančius teikėjus ir bando kitą. Jums nieko daryti nereikia. Išsamesnės informacijos rasite [Auto-Combo vadove](./AUTO-COMBO-GUIDE.md).
