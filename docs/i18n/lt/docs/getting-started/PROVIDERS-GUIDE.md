## Kas yra teikėjas?

Įsivaizduokite teikėją kaip **mobiliojo ryšio operatorių**. Kaip skambinti reikia mobiliojo ryšio operatoriaus, taip DI modeliams naudoti reikia DI teikėjo. OmniRoute yra tarsi telefonas, veikiantis su **visais operatoriais** — galite automatiškai juos perjungti.

### Teikėjų tipai

| Tipas                     | Kas tai yra                     | Pavyzdžiai                        | Kaina                       |
| ------------------------- | ------------------------------- | --------------------------------- | --------------------------- |
| **Nemokamas**             | Mokėti nereikia                 | Kiro, OpenCode Free, Pollinations | $0                          |
| **API raktas**            | Reikia API rakto                | OpenAI, Anthropic, Google         | Mokama pagal naudojimą      |
| **OAuth**                 | Prisijungiama naudojant paskyrą | Claude Code, GitHub Copilot       | Prenumerata                 |
| **Žiniatinklio slapukas** | Naudojamas naršyklės seansas    | ChatGPT Web (Codex), Gemini Web   | $0 (naudojama jūsų paskyra) |

### Žiniatinklio slapukų teikėjai

Bendrąsias sąrankos instrukcijas, apribojimus, trikčių šalinimo informaciją ir konkretiems teikėjams skirtas autentifikavimo gaires rasite faile **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**.

## Greitoji pradžia: prijunkite pirmąjį teikėją

### Pasirenkama nemokamų teikėjų sąranka pirmojo paleidimo metu

Pirmojo paleidimo vediklyje pateikiama aiški kortelė **Nustatyti nemokamus teikėjus**. Dabartinis
tinkamų teikėjų sąrašas sudaromas pagal OmniRoute teikėjų, kuriems nereikia autentifikavimo, registrą, o tada galite peržiūrėti kiekvieną
teikėją ir panaikinti jo pasirinkimą prieš patvirtindami. OmniRoute parodo teikėjo įspėjamąjį pranešimą ir nuorodą į jo svetainę,
kad pirmiausia galėtumėte peržiūrėti trečiosios šalies sąlygas, privatumo nuostatas, pasiekiamumą ir užklausų dažnio apribojimus.

Šis veiksmas neprivalomas: užbaigus vediklį, nemokamų teikėjų ryšiai niekada nesukuriami nepastebimai.
Sukuriami tik dar nepridėti teikėjai, esami tinkinti ryšiai
nekeičiami, o apie sukurtus, jau sukonfigūruotus ir nepavykusius pridėti teikėjus pranešama atskirai. Gavę dalinį rezultatą galite
saugiai iš naujo bandyti pridėti tik tuos teikėjus, kurių pridėti nepavyko.

### A parinktis: nemokamas teikėjas (nereikia kredito kortelės)

1. Atidarykite valdymo skydą adresu `http://localhost:20128`
2. Eikite į **Teikėjai** → **Pridėti teikėją**
3. Pasirinkite vieną iš šių nemokamų teikėjų:
   - **Kiro AI** — Nemokami Claude modeliai (autentifikavimas nereikalingas)
   - **OpenCode Free** — Nemokami GPT modeliai (autentifikavimas nereikalingas)
   - **Pollinations** — Nemokami GPT-5, Claude, Gemini (rakto nereikia)
   - **LongCat** — 10M nemokamų žetonų (vienkartinė dotacija, reikia paskyros ir KYC)
   - **Cloudflare AI** — Daugiau nei 50 modelių, 10K neuronų per dieną
   - **MLX Gemma 26B** — Vietinis Apple Silicon modelis (~38.5 žet./s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — Vietinis Apple Silicon modelis (~9.1 žet./s, ~13.1GB RAM)
4. Spustelėkite **Prisijungti**
5. Atlikta! Dabar turite nemokamą prieigą prie DI.

### B parinktis: API rakto teikėjas (mokamas)

1. Gaukite API raktą teikėjo svetainėje:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Atidarykite valdymo skydą adresu `http://localhost:20128`
3. Eikite į **Teikėjai** → **Pridėti teikėją**
4. Pasirinkite savo teikėją
5. Įklijuokite API raktą
6. Spustelėkite **Prisijungti**
7. Atlikta! Dabar turite prieigą prie to teikėjo modelių.

### C parinktis: OAuth teikėjas (prenumerata)

1. Atidarykite valdymo skydą adresu `http://localhost:20128`
2. Eikite į **Teikėjai** → **Pridėti teikėją**
3. Pasirinkite savo teikėją (pvz., Claude Code arba GitHub Copilot)
4. Spustelėkite **Prisijungti naudojant OAuth**
5. Prisijunkite naudodami savo paskyrą
6. Atlikta! Dabar turite prieigą prie prenumeratos modelių.

### D parinktis: vietiniai MLX modeliai (Apple Silicon)

Apple Silicon Mac kompiuteriuose su bendrąja atmintimi OmniRoute leidžia prijungti vietinius MLX modelius, veikiančius per `mlx-lm.server`, kaip įprastus su OpenAI suderinamus vietinius teikėjus.

#### Būtinosios sąlygos

- **Apple Silicon Mac** (M1/M2/M3/M4) su rekomenduojama 24GB ar didesne bendrąja atmintimi
- **uv** paketų tvarkytuvė: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Greitoji pradžia

1. **Įdiekite priklausomybes**:

   ```bash
   # Įdiekite uv, jei jis dar neįdiegtas
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Įdiekite mlx-lm
   uv pip install mlx-lm
   ```

2. **Paleiskite MLX serverius rankiniu būdu** (atskiruose terminaluose):

   ```bash
   # 1 terminalas: Gemma 4 26B A4B IT-QAT (prievadas 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # 2 terminalas: Qwen 3.8 27B MLX Mixed (prievadas 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Prisijunkite OmniRoute valdymo skyde**:
   - Eikite į **Teikėjai** → **Pridėti teikėją**
   - Pasirinkite **MLX Gemma 26B** arba **MLX Qwen 3.8 27B**
   - Spustelėkite **Prisijungti** (API rakto nereikia)

4. **Naudokite su OpenCode**:
   ```bash
   # Sukonfigūruokite OpenCode, kad naudotų OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Naudokite MLX modelius
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Atminties valdymas

**Svarbu**: turint 24GB bendrosios atminties, vienu metu gali veikti tik **vienas didelis MLX modelis**.

- Gemma 26B: ~15.9GB didžiausias atminties naudojimas
- Qwen 3.8 27B: ~13.1GB didžiausias atminties naudojimas

Tai turite valdyti rankiniu būdu:

- Vienu metu paleiskite tik vieną MLX serverį arba
- Paleiskite abu skirtinguose kompiuteriuose, arba
- Sustabdykite vieną prieš paleisdami kitą

OmniRoute automatiškai nevaldo MLX serverio procesų — jis tik nukreipia užklausas į jūsų sukonfigūruotus su OpenAI suderinamus galinius taškus.

#### Įrankių iškvietimo palaikymas

Abu modeliai palaiko su OpenAI suderinamą įrankių iškvietimą. Išbandykite naudodami:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Trikčių šalinimas

| Problema                     | Sprendimas                                                                                               |
| ---------------------------- | -------------------------------------------------------------------------------------------------------- |
| Serveris nepasileidžia       | Patikrinkite `uv run mlx_lm.server --help` ir modelių ID                                                 |
| Nepakanka atminties          | Įsitikinkite, kad veikia tik vienas modelis; uždarykite kitas programas; patikrinkite „Activity Monitor“ |
| Ryšys atmestas               | Patikrinkite, ar serveris veikia tinkamame prievade (11435/11436)                                        |
| Lėti atsakymai               | Pirmoji užklausa įkelia modelį į atmintį (~30–60 s); paskesnės užklausos vykdomos greitai                |
| Nepavyksta iškviesti įrankių | Įsitikinkite, kad modelis palaiko įrankius; patikrinkite „OmniRoute“ žurnalus dėl vertimo klaidų         |

## Kaip prijungti paslaugų teikėją (žingsnis po žingsnio)

### 1 žingsnis: atidarykite valdymo skydą

Naršyklėje atidarykite `http://localhost:20128`.

### 2 žingsnis: eikite į paslaugų teikėjų skiltį

Šoninėje juostoje spustelėkite **Paslaugų teikėjai**.

### 3 žingsnis: spustelėkite „Pridėti paslaugų teikėją“

Spustelėkite mygtuką **+ Pridėti paslaugų teikėją**.

### 4 žingsnis: pasirinkite paslaugų teikėją

Peržiūrėkite sąrašą arba raskite savo paslaugų teikėją naudodami paiešką. Spustelėkite jį.

### 5 žingsnis: įveskite prisijungimo duomenis

- **Nemokami paslaugų teikėjai**: prisijungimo duomenų nereikia — tiesiog spustelėkite **Prisijungti**
- **API raktą naudojantys paslaugų teikėjai**: įklijuokite savo API raktą
- **OAuth paslaugų teikėjai**: spustelėkite **Prisijungti naudojant OAuth** ir prisijunkite

### 6 žingsnis: patikrinkite ryšį

Spustelėkite **Patikrinti ryšį**, kad įsitikintumėte, jog jis veikia.

### 7 žingsnis: atlikta!

Jūsų paslaugų teikėjas prijungtas. Galite jį naudoti su `model: "auto"` arba tiesiogiai nurodyti paslaugų teikėją.

## Kelių paslaugų teikėjų naudojimas

OmniRoute geriausiai veikia su **keliais paslaugų teikėjais**. Tai suteikia:

- **Automatinį atsarginį perjungimą** — jei vienas paslaugų teikėjas neveikia, OmniRoute išbando kitą
- **Išlaidų optimizavimą** — OmniRoute kiekvienai užklausai parenka pigiausią paslaugų teikėją
- **Spartos optimizavimą** — OmniRoute kiekvienai užklausai parenka greičiausią paslaugų teikėją
- **Kokybės optimizavimą** — OmniRoute kiekvienai užduočiai parenka geriausią paslaugų teikėją

### Rekomenduojama konfigūracija

Kad naudojimo patirtis būtų geriausia, prijunkite bent **3 paslaugų teikėjus**:

1. **Vieną nemokamą paslaugų teikėją** (Kiro, OpenCode Free arba Pollinations) — visada pasiekiamą
2. **Vieną spartų paslaugų teikėją** (Groq, Cerebras) — greitiems atsakymams
3. **Vieną aukštos kokybės paslaugų teikėją** (OpenAI, Anthropic, Google) — sudėtingoms užduotims

Tada naudokite `model: "auto"`, o OmniRoute automatiškai parinks geriausią paslaugų teikėją kiekvienai užklausai.

## Dažniausiai užduodami klausimai

### „Ar turiu mokėti už naudojimąsi OmniRoute?“

**Ne!** OmniRoute yra nemokama atvirojo kodo programa. Galite nemokamai naudotis nemokamais paslaugų teikėjais (Kiro, OpenCode Free, Pollinations). Mokėsite tik tuo atveju, jei nuspręsite naudotis mokamais paslaugų teikėjais.

### „Nuo kurio paslaugų teikėjo turėčiau pradėti?“

Pradėkite nuo **Kiro AI** — jis yra nemokamas, jam nereikia API rakto ir jis suteikia prieigą prie Claude modelių. Tada pagal poreikį pridėkite daugiau paslaugų teikėjų.

### „Ar galiu vienu metu naudotis keliais paslaugų teikėjais?“

**Taip!** Būtent tam ir skirta OmniRoute. Prijunkite kelis paslaugų teikėjus ir naudokite `model: "auto"`, kad OmniRoute kiekvienai užklausai parinktų geriausią.

### „Ką daryti, jei paslaugų teikėjas nustoja veikti?“

OmniRoute automatiškai praleidžia neveikiančius paslaugų teikėjus ir išbando kitą. Jums nereikia nieko daryti.

### „Kaip atjungti paslaugų teikėją?“

Eikite į „Paslaugų teikėjai“ → spustelėkite paslaugų teikėją → spustelėkite **Atjungti**.

### „Ar galiu naudoti turimus API raktus?“

**Taip!** Jei jau turite OpenAI, Anthropic, Google ar kitų paslaugų API raktus, galite juos naudoti OmniRoute. Prisijungdami prie paslaugų teikėjo tiesiog juos įklijuokite.
