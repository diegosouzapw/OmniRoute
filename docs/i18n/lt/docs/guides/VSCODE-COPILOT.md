**OmniCopilot** įtraukia kiekvieną modelį, kurį aptarnauja jūsų OmniRoute, į _savosios_ GitHub Copilot Chat
modelių parinkiklį. Jokios antros šoninės juostos, jokios atskiros pokalbių sąsajos — Copilot agento režimas, įrankių iškvietimas,
MCP serveriai ir pasirinktinės instrukcijos veikia kaip anksčiau, tik naudojamas jūsų pasirinktas modelis.

## Sąranka

1. **Paleiskite OmniRoute** — `npm install -g omniroute && omniroute` (valdymo skydas pasiekiamas adresu `http://localhost:20128`).
2. **Įdiekite plėtinį** — plėtinių rodinyje ieškokite „OmniRoute“.
3. **Pasirinkite modelį** — Copilot Chat → modelių parinkiklis → **Valdyti modelius…** → **OmniRoute**, tada pažymėkite
   norimus modelius.

Kai OmniRoute veikia numatytuoju prievadu, nieko konfigūruoti nereikia. Jei naudojate nuotolinį egzempliorių, atverkite
**OmniRoute piktogramą veiklos juostoje** (arba paleiskite `OmniRoute: Manage Connection`) ir nustatykite:

- **Serverio URL** — serverio šakninis adresas, pvz., `http://192.168.0.15:20128`. Plėtinys
  prideda `/v1` priesagą; jos neįtraukite.
- **API raktas** — tik kai serveryje nustatytas `REQUIRE_API_KEY`. Jis saugomas OS raktinėje naudojant VS
  Code SecretStorage, niekada — `settings.json`.

## Kas bus rodoma parinkiklyje

Plėtinys nerodo neapdoroto `GET /v1/models` atsako turinio — jis jį suformuoja, todėl matomas skaičius
yra mažesnis už katalogo dydį dėl dviejų sąmoningų priežasčių.

### Kiekvienam modeliui prašoma po vieną ID

Numatytoji `MODELS_CATALOG_PREFIX_MODE` reikšmė yra **`dual`**, todėl kiekvienas modelis pateikiamas du kartus — vieną kartą
su trumpojo alternatyvaus pavadinimo prefiksu ir vieną kartą su kanoniniu teikėjo prefiksu — kad senesnės klientų
konfigūracijos ir toliau galėtų atpažinti abi formas:

```
cc/claude-sonnet-4-6        ← alternatyvaus pavadinimo prefiksas
claude/claude-sonnet-4-6    ← kanoninis prefiksas, tas pats modelis
```

Plėtinys siunčia užklausą **`GET /v1/models?prefix=alias`**, todėl kiekvienam modeliui gaunamas vienas ID,
nekeičiant viso serverio nustatymo kitiems jūsų klientams. Etaloniniame egzemplioriuje taip
**2345 įrašai buvo sumažinti iki 1396 — 949 dublikatai, neprarastas nė vienas modelis.**

Jei norite tai ištaisyti viso serverio mastu _kiekvienam_ klientui, valdymo skydelyje nustatykite
`MODELS_CATALOG_PREFIX_MODE` funkcijos vėliavėlės reikšmę į `alias`. Užklausos parametro ir kiekvieno režimo lentelės ieškokite
[API_REFERENCE → prefiksas](../reference/API_REFERENCE.md#model-id-prefixes-prefix).

### Paslepiami modeliai, kurie negali dalyvauti pokalbiuose

Kataloge taip pat pateikiami vaizdų, vaizdo įrašų, garso, perrikiavimo, įterpinių ir moderavimo modeliai. Vis tiek
būtų atmestos pokalbių užklausos jiems:

```
HTTP 400 — Model '<id>' is an image-generation model and cannot be used on
/v1/chat/completions. Use POST /v1/images/generations instead.
```

todėl, prieš jiems pasiekiant parinkiklį, jie išfiltruojami pagal `type` lauką. **Responses API
modeliai paliekami** — kiekviename Codex / GPT-5.x įraše nurodyta `supported_endpoints: ["responses"]`,
o OmniRoute juos konvertuoja į `/v1/chat/completions`, todėl juos galima visavertiškai naudoti.

### Teikėjai, kurių niekada nekonfigūravote

Kataloge pateikiami modeliai iš teikėjų, turinčių **aktyvų ryšį**, _ir_ visi **noAuth**
teikėjai — rakto nereikalaujantys teikėjai, sudarantys didelę nemokamos pakopos dalį. Taip numatyta. Norėdami
juos paslėpti, valdymo skydo nustatymuose pridėkite juos prie `blockedProviders`; plėtinyje
niekas nesikeičia.

## Valdymo skydelis VS Code skirtuke

`omnicopilot.dashboardOpen: "editor"` atvaizduoja OmniRoute valdymo skydelį redaktoriaus skirtuke per
Simple Browser, o ne išorinėje naršyklėje. Įterpimas yra **pasirenkamas serverio pusėje** naudojant
`DASHBOARD_ALLOW_EMBED=vscode`, todėl HTML puslapiai pateikiami su
`frame-ancestors 'self' vscode-webview:`, o ne su numatytaisiais `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. API sąsajos (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) abiem atvejais
išlaiko griežtas antraštes.

> ⚠️ **Tai yra kompiliavimo, o ne vykdymo laiko vėliavėlė.** Next.js sukompiliuoja `headers()` į maršrutų
> manifestą, todėl `next.config.mjs` nuskaito kintamąjį paketo kompiliavimo metu
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Jo eksportavimas prieš paleidžiant jau sukompiliuotą serverį nieko nekeičia — antraštės jau yra įkompiliuotos.

```bash
# kintamasis turi būti nustatytas VYKDOMO KOMPILIAVIMO komandoje
DASHBOARD_ALLOW_EMBED=vscode npm run build        # arba npm run build:release
npm start
```

| Kaip įdiegėte              | Ar galite įjungti įterpimą?                                                                                                                     |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Iš pirminio kodo           | ✅ nustatykite kintamąjį kompiliavimo komandoje, kaip parodyta pirmiau                                                                          |
| `npm install -g omniroute` | ❌ paskelbtame pakete pateikiamas iš anksto sukompiliuotas paketas — vietoje jo kompiliuokite iš pirminio kodo                                  |
| Docker atvaizdas           | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — iš anksto paruoštame Docker Hub atvaizde įterpimas neįjungtas |

Jei paketas nesukompiliuotas su įjungtu įterpimu, puslapis atsisako būti rodomas rėmelyje, plėtinys tai aptinka pagal
atsako antraštes ir grįžta prie išorinės naršyklės — niekas nesugenda, o apie tai vieną kartą pranešama.
Žr. [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) ir problemą
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Kitų įrankių konfigūravimas iš VS Code

**`OmniRoute: Configure Coding CLI`** naudoja `omniroute` CLI, kad įrašytų paruoštus naudoti profilius,
skirtus Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo ir Roo — tas pačias konfigūracijas, kurios aprašytos
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). API raktas CLI perduodamas per
`OMNIROUTE_API_KEY` aplinkos kintamąjį, niekada ne komandų eilutėje.
