„OmniRoute“ suskirsto 352 palaikomus teikėjus į 3 ekonomines pakopas. Kiekviena
užklausa siunčiama per jas eilės tvarka, kol gaunamas sėkmingas atsakymas —
taip gaunate pigiausią tinkamą atsakymą ir jums niekada nereikia rašyti atsarginės logikos.

## 1 pakopa — prenumerata

**Teikėjai, už kuriuos jau mokate.** „OmniRoute“ išnaudoja visą kvotą prieš
jai baigiant galioti.

| Teikėjas                           | Kodėl 1 pakopa                                                |
| ---------------------------------- | ------------------------------------------------------------- |
| Claude Code OAuth                  | Anthropic Pro/Team — fiksuotas mokestis, dažnai neišnaudojama |
| OpenAI Codex (ChatGPT prenumerata) | Plus/Team apima Codex kvotą                                   |
| GitHub Copilot                     | Mokestis už naudotoją — kvota atnaujinama kas mėnesį          |
| Cursor IDE                         | Pro plano kvota                                               |
| Antigravity / Devin Desktop        | Integruotos kvotos                                            |

**Strategija**: pirmiausia čia nukreipkite kiekvieną užklausą, atitinkančią modelio
stipriąsias puses. Kvotų stebėjimo priemonė seka artėjantį kvotų atnaujinimą, o
kombinuotoji strategija `reset-aware` atitinkamai nustato prioritetus. Norėdami pirmiausia
nukreipti į 1 pakopą ir pereiti prie mokamų pakopų tik išnaudojus kvotą, naudokite
identifikatorių `auto/thrifty` — arba `auto/subscription`, jei norite naudoti tik į planą
įtrauktus pajėgumus ir jų nepasiekus nutraukti vykdymą. Žr.
[Maršruto parinkimas pirmiausia pagal prenumeratą](../routing/SUBSCRIPTION_LADDER.md).

## 2 pakopa — nebrangūs teikėjai

**Teikėjai, kurių mokestis už žetonus nesiekia $1 už 1 mln. žetonų.** Skirta didelės apimties darbams
arba naudoti pasiekus 1 pakopos kvotų ribas.

| Teikėjas                              | Kaina (įvestis / išvestis) | Stipriosios pusės          |
| ------------------------------------- | -------------------------- | -------------------------- |
| DeepSeek V4 Pro                       | $0.27 / $1.10 už 1 mln.    | Kodas, samprotavimas       |
| GLM-4.5                               | $0.60 / $2.20 už 1 mln.    | Ilgas kontekstas           |
| MiniMax M1                            | $0.20 / $1.10 už 1 mln.    | Greitis                    |
| Qwen Coder                            | $0.30 / $1.20 už 1 mln.    | Kodas                      |
| OpenRouter (optimizuotas pagal kainą) | skiriasi                   | 100+ modelių, dinamiškumas |

**Strategija**: kombinacija `cost-optimized` parenka modelį su mažiausia $/žetoną kaina, kuris atitinka
užduoties galimybių filtrą (vaizdai, JSON režimas, įrankiai, maksimalus kontekstas).

## 3 pakopa — nemokami teikėjai

**Nekainuojantys teikėjai** — nemokami planai, kreditų programos, dienos OAuth kvotos.

| Teikėjas         | Nemokama kvota / kreditai                             |
| ---------------- | ----------------------------------------------------- |
| Kiro AI          | Nemokamas Claude planas (dosnaus sąžiningo naudojimo) |
| OpenCode Free    | Nereikia autentifikuotis, dosnūs dažnio apribojimai   |
| Qoder            | Nemokamas OAuth                                       |
| Google Vertex AI | $300 kreditų naujai paskyrai                          |
| Amazon Q         | Nemokamas planas AWS naudotojams                      |
| Pollinations     | Atvira viešoji API                                    |
| Cloudflare AI    | Nemokamas Workers AI planas                           |

**Strategija**: kombinacija `auto` su biudžeto riba nukreipia čia, kai 1 ir 2 pakopos neveikia
arba kai nustatyta `useFreeOnly=true`. Nemokamiems teikėjams dažnai taikomi griežtesni
dažnio apribojimai — grandinės pertraukiklis juos atkuria po laukimo intervalo.

## Pakopų konfigūravimas

Valdymo skydas → **Pakopos** → priskirkite savo teikėjus. Numatytosios nuostatos (iš `tierDefaults.json`) yra
tinkamos; redaguokite jas, kai norite teikti pirmenybę konkrečioms prenumeratoms arba neįtraukti tam tikrų teikėjų.

„Auto-Combo“ 16 veiksnių vertinimo sistema taip pat atsižvelgia į pakopą. Žr.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetrija

Valdymo skydas → **Naudojimas** rodo per dieną kiekvienoje pakopoje sunaudotus žetonus. Naudokite tai norėdami:

- Patvirtinti, kad 1 pakopa visiškai išnaudojama (kitaip švaistote prenumeratos vertę)
- Nustatyti, kurie 2 pakopos modeliai pasirenkami dažniausiai (sumažinkite jų skaičių iki 1–2)
- Patikrinti, ar 3 pakopa padeda sutaupyti atliekant testavimo ir tyrinėjimo darbus

## Dažniausi naudojimo modeliai

### Visiškai nemokamas darbo krūvis

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Ryškiai teikia pirmenybę 3 pakopai; 2 pakopa naudojama tik tada, kai 3 pakopa nepasiekiama.

### Pirmiausia prenumerata, su nebrangia atsargine parinktimi

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Aiškiai nurodytas sąrašas, kurio tvarka atitinka 1 pakopa → 2 pakopa → 3 pakopa.
