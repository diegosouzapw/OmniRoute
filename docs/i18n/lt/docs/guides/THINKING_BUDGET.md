> **Valdymo skydelis:** Nustatymai → **DI** → Mąstymo biudžetas  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **Šaltinis:** `open-sse/services/thinkingBudget.ts`

Mąstymo biudžetas nustato, ar OmniRoute, perduodama užklausas paslaugų teikėjams, **perrašo kliento mąstymo / samprotavimo parametrus**. Jis **neįjungia ir neišjungia** glaudinimo, maršruto parinkimo ar užklausų podėlio.

## Režimai

| Režimas                         | Ką daro OmniRoute                                                                                                         | Kada naudoti                                                                                                                                                                           |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (numatytasis) | Palieka kliento laukus nepakeistus (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config` ir kt.). | **Codex / Desktop / bet kuriam klientui, kuris turi valdyti pastangų lygį ir samprotavimo suvestines.** Būtina matomiems mąstymo skydeliams, kai klientas prašo `reasoning.summary`.   |
| **`auto`**                      | Prieš perduodant aukštesnio lygio paslaugai, iš užklausos turinio **pašalina visus** mąstymo / samprotavimo laukus.       | Tik kai sąmoningai norite, kad **paslaugos teikėjas** pats nustatytų numatytąsias reikšmes, ir jums nereikia kliento valdomo mąstymo. Tai **nereiškia** „automatiškai rodyti mąstymą“. |
| **`custom`**                    | Perrašo kiekvieną užklausą, nustatydama fiksuotą mąstymo žetonų biudžetą.                                                 | Griežtam viso srauto mąstymo žetonų limitui.                                                                                                                                           |
| **`adaptive`**                  | Keičia biudžetą pagal bazinį pastangų lygį, atsižvelgdama į pranešimų skaičių, įrankius ir užklausos ilgį.                | Lanksčiam žetonų valdymui, visiškai nepašalinant kliento nustatymų.                                                                                                                    |

### Ką pašalina `auto`

Kai pasirinktas režimas `auto`, `stripThinkingConfig()` pašalina (be kita ko):

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking` ir, jei yra, `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

Jei klientas (pvz., Codex Desktop) atsiuntė `reasoning: { effort: "ultra", summary: "detailed" }`, režimas **auto pašalina šį objektą**. Aukštesnio lygio paslaugos teikėjas vis tiek gali apmokestinti kai kuriuos samprotavimo žetonus, tačiau dažnai grąžina **tuščius arba tik užšifruotus** samprotavimo elementus, todėl naudotojo sąsajoje nerodomas naudingas mąstymo srautas.

## Kas tai **nėra**

| Funkcija                                                    | Sąsaja                                                                                                                                                             |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Glaudinimas** (Caveman, RTK, stacked, …)                  | Atskiras konvejeris. Veikia su kiekvienu mąstymo biudžeto režimu.                                                                                                  |
| **Užklausų / semantinis podėlis**                           | Atskiras. Mąstymo biudžeto režimas jam įtakos neturi.                                                                                                              |
| **Kombinuotas maršruto parinkimas / atsarginiai variantai** | Atskira. Įtakos neturi.                                                                                                                                            |
| **API rakto žetonų limitai / išlaidų biudžetai**            | Atskira. Įtakos neturi.                                                                                                                                            |
| **Samprotavimo atkūrimo podėlis**                           | Pakartotinis įterpimas kelių žinučių dialoguose griežtiems paslaugų teikėjams (DeepSeek, Kimi, Qwen-thinking, …). Tai nėra tas pats, kas Desktop „rodyti mąstymą“. |
| **`encrypted_content` iššifravimas**                        | **Neįmanomas.** Privatūs OpenAI/Codex samprotavimo objektai yra neskaidrūs. OmniRoute niekada jų neiššifruoja (#7095 / #7176 / #7304).                             |

## Matomas mąstymo procesas (Codex / Responses klientai)

Kad klientas rodytų mąstymo proceso tekstą, būtinos **visos** šios sąlygos:

1. Mąstymo biudžeto režimas = **`passthrough`** (arba pasirinktinis / adaptyvusis režimas, kuris jūsų naudojamam keliui pakankamai išsaugo santraukos užklausas).
2. Klientas prašo santraukos, pvz., Codex `model_reasoning_summary = "detailed"` / `auto` (ne `none`).
3. Pirminis paslaugos teikėjas iš tiesų srautiniu būdu perduoda `response.reasoning_summary_text.*` (arba elemente pateikia netuščią `reasoning.summary`).

Jei gaunate tik „užšifruotą privatų mąstymo procesą“, vadinasi:

- buvo naudojamas **`auto`** režimas (kliento užklausa buvo pašalinta), arba
- pirminis paslaugos teikėjas grąžino `encrypted_content` be santraukos teksto (paslaugos teikėjo apribojimas; OmniRoute gali pateikti tik vietaženklį, o ne atvirąjį tekstą).

## API pavyzdžiai

```bash
# Nuskaitymas
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Rekomenduojama Codex / Desktop mąstymo proceso matomumui
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Schema (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; neprivalomi `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### Išsaugojimas / paleidimas iš naujo

Reikšmė saugoma nustatymų rakte `thinkingBudget` ir įkeliama paleidžiant procesą (`hydrateThinkingBudgetConfig`). Pakeitę ją duomenų bazėje arba kitais, ne API, būdais, **paleiskite OmniRoute procesą iš naujo**, kad atmintyje esantis vienintelis egzempliorius atitiktų diske saugomą būseną.

## Operatoriaus kontrolinis sąrašas

- [ ] Codex / Desktop naudotojams: režimas = **passthrough**
- [ ] Jei norite taupyti **pranešimų** prieigos raktus, palikite glaudinimą įjungtą, užuot pašalinę mąstymo procesą
- [ ] Nesitikėkite, kad `auto` „parodys daugiau mąstymo proceso“
- [ ] Tik užšifruotos santraukos yra **paslaugos teikėjo** elgsena; passthrough negali jų iššifruoti
