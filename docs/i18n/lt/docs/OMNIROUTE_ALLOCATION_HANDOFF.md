Paskirstymas nėra teikėjo kvota.

Kvotų telkiniai apibrėžia, kurie API raktai gali naudoti teikėjo telkinį ir kaip taikomos griežtosios, lanksčiosios ar trumpalaikio viršijimo strategijos. Teikėjo kvota yra išorinis pajėgumas, apie kurį praneša teikėjas arba aiškiai sukonfigūruotas šaltinis. „Ghostlight“ vidiniai biudžetai yra administratoriaus nustatyti valdymo apribojimai.

Operacija `ensurePool` yra idempotentinė: identiškas telkinys nekeičiamas, pasikeitęs paskirstymas atnaujinamas, o nesamas telkinys sukuriamas. Tai skirta automatizavimui ir ribotas teises turintiems API klientams.

Tik skaitymui skirtas būsenos galinis taškas yra `GET /api/omniroute/status`. Patikros komanda yra `npm run omniroute:verify`; ji nesiunčia jokios realios modelio užklausos.
