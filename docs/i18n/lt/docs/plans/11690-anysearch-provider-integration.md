## 1. Faktinė paslaugos informacija (oficiali dokumentacija, patikrinta pagal kelis šaltinius)

- Bazinis URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` – parametrai: `query` (privalomas), `max_results` (1–10, numatytoji reikšmė – 10), `tag` (`{domain}.{sub_domain}` vertikalusis maršruto parinkimas), `zone` (cn/intl), `language`, `params` (struktūrizuoti vertikalės laukai), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` – galimybių katalogas, NĖRA įskaičiuojamas į kvotą.
- `POST /v1/extract` – gauna / išskiria `{url, title, content}`; griežtai apibrėžtas JSON turinys, 16 KiB riba.
- `POST /v1/auth/email/register` – registracija vienu iškvietimu, grąžina vienkartinį atvirojo teksto raktą `as_sk_...`.
- Autentifikavimas: pasirinktinis `Authorization: Bearer <as_sk_...>`; anoniminė prieiga apribojama vienam IP adresui taikomais limitais, naudojančiais nemokamą dienos kvotą; netinkamas raktas grąžina 401/403 ir NĖRA nepastebimai pereinama prie anoniminės prieigos.
- Nemokamas planas: 1000 užklausų per dieną, 20 QPS vienam raktui. Mokamas planas: kaina nenurodyta (Netrukus).
- Atsakymo apvalkalas: sėkmės atveju `{code: 0, message: "success", request_id, data}`; nesėkmės atveju `{code: -1, message}`. Autentifikavimo / kvotos klaidose nėra struktūrizuoto `error_code` (signalas yra pranešimo tekstas); tik išskyrimo operacijai būdingose klaidose yra `error_code` (`invalid_extract_url`, `extract_failed`). 429 atsakyme nėra `Retry-After` antraštės.

## 3. Sprendimai (visi priimti 2026-08-26)

1. **Maršruto parinkimo nuostata: `fallbackOnly`.** Pagrindimas: 0 kainos nemokamas teikėjas niekada neturi dominuoti automatinio maršruto parinkimo pagal kainą; aiškus pasirinkimas ir grįžimas po perjungimo į atsarginį teikėją lieka nepakitę. Precedentas: sujungtas xquik įrašas.
2. **Aprėptis: webSearch + webFetch per `POST /v1/extract` v1 versijoje.** Suderinta su tavily/exa dviejų galimybių koncepciniu modeliu. Vertikaliosios sąsajos (`tag`, `sub-domains`, `batch_search`) nepatenka į aprėptį — šiuo metu nėra vertikaliųjų parametrų IR.
3. **Kvotos rodymas: `freeMonthlyQuota: 0`** (konservatyvus xquik tipo rodymas). Faktinis limitas (1000 užklausų per dieną, kasdienis nustatymas iš naujo) vietoje to nurodomas UI katalogo `authHint` tekste. Pagrindimas: kvotos rodymas turi atitikti jos nustatymo iš naujo semantiką; dienos limito konvertavimas į mėnesio ekvivalentą (30000) yra klaidingas pažadas, kurio UI negali užtikrinti.
4. **searchTypes: tik `["web"]`.** Nėra viešų įrodymų, kad AnySearch API turi news/images vertikaliąją paiešką; tinklų sietuvai, integruojantys API be dokumentuotos vertikaliosios paieškos (pvz., Google Custom Search), pateikia tik web, užuot nepastebimai susieję news -> web.
5. **Rakto naudojimo nuostata:** galima veikti be rakto; dėl netinkamo rakto grąžinama 401/403 klaida ir niekada nepastebimai nepereinama prie anoniminės prieigos (atitinka pirminės paslaugos sutartį).
6. **Sąmoningai neįtraukta:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (pokalbių perėmimui ir toliau naudojami firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (anoniminiai nuotoliniai galiniai taškai dalijasi vienu pagal IP ribojamu telkiniu kiekvienam išeinančio ryšio IP adresui, todėl extract be rakto yra pasirenkama galimybė, o ne automatinio maršruto parinkimo kandidatas); `QUOTA_STATUS_PROVIDERS` (AnySearch apie kvotą praneša naudodama 429/atsako apvalkalą, o ne 402/403 būseną).
