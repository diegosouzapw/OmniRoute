`agentrouter` išorinis šliuzas taiko raktažodžiais pagrįstą turinio filtrą
`messages[].content` laukui. Filtras yra iš dalies deterministinis (visada blokuoja
tam tikras frazes) ir iš dalies tikimybinis (jautrus užklausų pliūpsniams — po
greitai siunčiamų užklausų tampa agresyvesnis, o po atvėsimo laikotarpio
atsistato).

Kai WAF užblokuoja užklausą, jis grąžina:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Filtro taikymo sritis

WAF tikrina tik `messages[].content`. Jis **netikrina**:

- `system` raginimo
- Struktūrizuoto turinio blokų (`tool_result`, `tool_use`, `thinking`, `image`)
- Įrankio laukų `description` ir `input_schema`
- Užklausos metaduomenų, antraščių ar modelio ID

## Visada blokuojami šablonai (neatsižvelgiant į raidžių dydį)

| Šablonas                          | Pastabos                                                    |
| --------------------------------- | ----------------------------------------------------------- |
| Bet kuris `Lorem ipsum` variantas | Blokuojamas visas lotyniškas „lorem“ žodynas                |
| `language model` (viena frazė)    | „the language model“ ir „large language model“ praleidžiami |
| `virtual assistant`               | „AI assistant“ praleidžiama                                 |
| `I'm here to help`                | Vien „here to help“ taip pat blokuojama                     |
| `Claude, made by Anthropic`       | Tik visa frazė                                              |

## Beveik visada blokuojami šablonai

| Šablonas                                                         | Pastabos                                                        |
| ---------------------------------------------------------------- | --------------------------------------------------------------- |
| `placeholder`                                                    | Kai vartojamas atskirai (ne kaip parametro pavadinimas ir pan.) |
| `dummy data`                                                     | Dažna pradinių fikstūrų duomenų frazė                           |
| `foo bar baz`                                                    | Kanoninė vietos rezervavimo frazė                               |
| Pasikartojantys trumpi žetonai (`AAA BBB CCC`, `test test test`) | Raktažodžių prikimšimo aptikimo priemonė                        |

## Veikimas esant apkrovai

Per trumpą laiką greitai išsiuntus maždaug 5 užklausas, WAF pradeda blokuoti turinį,
kuris įprastai būtų praleistas. Po maždaug 5–10 sekundžių neveiklos laikotarpio
ribojimas sušvelnėja. Tai yra tas pats pagal IP adresą ir raktą taikomas užklausų
dažnio ribotuvas, dėl kurio protarpiais kyla `400 content-blocked` klaidos, kai
Claude Code arba Codex CLI greitai viena po kitos atlieka kelias įrankių naudojimo /
žinučių siuntimo užklausas.

## „OmniRoute“ jau pritaikytos priemonės

1. **`open-sse/services/wafRateLimit.ts`** — pliūpsnių ribotuvas, užtikrinantis
   mažiausiai 500 ms tarpą tarp siunčiamų užklausų į bet kurį `agentrouter:*`
   URL. Šis tarpas yra gerokai trumpesnis, nei žmogus galėtų pastebėti kaip delsą,
   ir neleidžia WAF suaktyvėti esant įprastam srautui.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — kai išorinė sistema grąžina
   `400 content-blocked`, vykdyklė pakartotinai siunčia užklausą tuo pačiu URL,
   taikydama eksponentinį delsos didinimą (1,5 s, 3,0 s, daugiausia 2 bandymai).
   Po šios delsos WAF paprastai sušvelnėja ir pakartotinė užklausa pavyksta.

3. **`tests/unit/compression/harness.test.ts`** — bandomosios fikstūros
   `longInput` reikšmė buvo pakeista iš `"lorem ipsum dolor sit amet ".repeat(40)`
   į `"example content for testing purposes ".repeat(40)`, kad Claude Code
   perskaičius šį failą naudojant įrankį `Read`, failo turinys nebūtų grąžintas
   per `tool_result` bloką ir nesuaktyvintų WAF.

## Rekomendacijos raginimams ir įrankių išvesčiai

Jei Claude Code arba Codex CLI seansas pakartotinai susiduria su
`400 content-blocked`, patikrinkite naujausią naudotojo žinutę ir naujausią
įrankio rezultatą, ar juose nėra kurio nors iš pirmiau nurodytų šablonų, ir
perfrazuokite. Dažniausi sprendimo būdai:

- Pakeiskite `Lorem ipsum …` į `example text …` arba faktinį turinį,
  kurį bandoma modeliuoti testu ar fikstūra.
- Pakeiskite atskirai vartojamą `placeholder` į `example value`,
  `sample value` arba tikrąją reikšmę.
- Pakeiskite `language model` į `large language model` arba `the model`.
- Pakeiskite `dummy data` į `sample data` arba tikroviškas pradines reikšmes.
- Pakeiskite `I'm here to help` / `here to help` konkretesne
  pradine fraze (pvz., „I'll review the file you mentioned“).

## Pranešimas apie klaidingus teigiamus rezultatus išorinei sistemai

Dabartinis filtras yra pernelyg agresyvus — jis blokuoja „Lorem ipsum“
`tool_result` blokuose, nors operatorius akivaizdžiai neketino įterpti
raginimo. Operatoriai, norintys, kad tai būtų ištaisyta pačiame šaltinyje,
turėtų susisiekti su `agentrouter.org` ir pranešti apie klaidingus teigiamus
rezultatus. Pirmiau pateiktas blokuojamų frazių sąrašas yra empirinis išorinės
sistemos tyrimo rezultatas, gautas 2026-08-03.
