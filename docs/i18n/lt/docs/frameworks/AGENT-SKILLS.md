> **Tiesos šaltinis:** `src/lib/agentSkills/` (katalogas, generatorius, analizatoriai) + `skills/` katalogas (SKILL.md failai)
> **Paskutinį kartą atnaujinta:** 2026-08-02 — v3.8.50

Agentų įgūdžiai yra struktūrizuoti SKILL.md failai, mokantys išorinius agentus, MCP klientus ir A2A orkestratorius naudotis OmniRoute REST API ir CLI. Skirtingai nei [Omni įgūdžiai](./SKILLS.md) (tai yra LLM įrankių apibrėžimai, vykdomi OmniRoute viduje), agentų įgūdžiai yra _dokumentacijos katalogas_ — statinis markdown turinys, kurį galima tiesiogiai pateikti agento kontekste.

---

## Apžvalga

Kataloge yra **45 agentų įgūdžiai** (23 REST API + 21 CLI + 1 konfigūravimo darbo eiga). Kiekvienas įgūdis turi:

- **Kanoninį ID** (`omni-auth`, `cli-serve` ir t. t.)
- **SKILL.md** failą, esantį `skills/{id}/SKILL.md`, su YAML metaduomenimis (`name`, `description`) ir išsamiu markdown turiniu
- **REST galinius taškus** (API įgūdžiai) arba **CLI subkomandas** (CLI įgūdžiai), gautus iš OpenAPI specifikacijos ir CLI registro
- **GitHub neapdoroto turinio URL**, skirtą tiesioginiam gavimui: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Architektūra

```
src/shared/constants/agentSkills.ts    — kuruojamas 45 įrašų sąrašas (pavadinimas / aprašas / kategorija / sritis / piktograma)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() įrašo SKILL.md į skills/{id}/
  openapiParser.ts                     — ištraukia REST galinius taškus iš docs/openapi.yaml
  cliRegistryParser.ts                 — ištraukia CLI subkomandas iš bin/cli-registry.ts
  schemas.ts                           — Zod schemos: AgentSkillSchema, SkillCoverageSchema ir kt.
  types.ts                             — TypeScript sąsajos: AgentSkill, SkillCoverage ir kt.

skills/{id}/SKILL.md                   — sugeneruoti ir kuruojami markdown failai (iš viso 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (reikalingas autentifikavimas)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 MCP įrankiai (sąrašas, gavimas, aprėptis)
src/lib/a2a/skills/listCapabilities.ts        — A2A įgūdis: list-capabilities
```

## SKILL.md formatas

```markdown
---
name: omni-providers
description: "Valdykite teikėjų ryšius: pridėkite, testuokite, keiskite ir pašalinkite prisijungimo duomenis."
---

<!-- sugeneruota naudojant src/lib/agentSkills/generator.ts; rankiniai pakeitimai bus perrašyti -->

## Apžvalga

...

## Autentifikavimas

...

## Galiniai taškai

...

<!-- skill:custom-start -->

## Pasirinktinė skiltis (išsaugoma pakartotinai generuojant)

...

<!-- skill:custom-end -->
```

Pakartotinai generuodamas generatorius išsaugo turinį tarp `<!-- skill:custom-start -->` ir `<!-- skill:custom-end -->`. Dešimt įgūdžių turi kuruojamus pasirinktinius blokus:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## REST API aptikimas

| Galinis taškas               | Metodas | Aprašas                                                                   | Autentifikavimas |
| :--------------------------- | :------ | :------------------------------------------------------------------------ | :--------------- |
| `/api/agent-skills`          | GET     | Katalogo sąrašas (pasirinktinai `?category=api\|cli\|config&area=<area>`) | nereikalingas    |
| `/api/agent-skills/{id}`     | GET     | Gauti vieno įgūdžio metaduomenis                                          | nereikalingas    |
| `/api/agent-skills/{id}/raw` | GET     | Gauti SKILL.md kaip `text/markdown`                                       | nereikalingas    |
| `/api/agent-skills/coverage` | GET     | Aprėpties statistika (kiek yra SKILL.md failų)                            | nereikalingas    |
| `/api/agent-skills/generate` | POST    | Paleisti generatorių (dryRun/prune/onlyIds)                               | valdymo          |

Pavyzdys — pateikti visų API įgūdžių sąrašą:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Pavyzdys — gauti vieną SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

```json
{
  "jsonrpc": "2.0",

  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

## Kaip išoriniai agentai naudoja įgūdžius

### 1. Aptikimas per REST

```bash
# Gauti visą katalogą
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Gauti SKILL.md kontekstui įterpti
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Aptikimas per MCP

```typescript
// Claude Desktop / Cursor MCP kliente:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → AgentSkill masyvas, kuriame kiekvienas elementas turi rawUrl
```

### 3. Aptikimas per A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table yra markdown lentelė su visų 45 įgūdžių ID ir rawUrl stulpeliais
```

### 4. Tiesioginis neapdoroto failo gavimas iš GitHub (serveris nereikalingas)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generatorius

Generatorius nuskaito kuruojamą katalogą, OpenAPI specifikaciją bei CLI registrą ir kiekvienam įrašui sukuria `skills/{id}/SKILL.md`:

```bash
# Peržiūra (bandomasis vykdymas, nieko neįrašant)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Visiškas sugeneravimas iš naujo
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Konkrečių ID sugeneravimas iš naujo
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Generatoriaus atsakymas yra `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
