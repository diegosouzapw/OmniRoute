## Kas tai yra

„Local Corpus“ leidžia operatoriui suteikti „OmniRoute“ MCP serveriui prieigą prie vieno aiškiai patvirtinto tekstinių failų katalogo. Failai lieka savo pradiniame kataloge: „OmniRoute“ SQLite duomenų bazėje saugo tik kanoninį šakninį kelią ir atmintyje palaiko paieškos indeksą. Korpuso turinys nekopijuojamas į saugyklą ar duomenų bazę.

Indeksas atnaujinamas laipsniškai. Nepakeisti failai pakartotinai naudojami pagal jų dydį ir modifikavimo laiką, pakeisti failai perskaitomi iš naujo ir maišos reikšmė apskaičiuojama naudojant SHA-256, o ištrinti failai pašalinami. Atliekant paiešką atnaujinamas senesnis nei 30 sekundžių indeksas; iškvietėjai taip pat gali paprašyti jį atnaujinti nedelsiant.

## Šaltinio konfigūravimas

Nustatymų maršrutui reikalingas toks pats valdymo autentifikavimas kaip ir kitoms nustatymų API. Pateiktas kelias jau turi egzistuoti ir turi būti absoliutus katalogo kelias.

```bash
# Prijungti patvirtintą katalogą
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Patikrinti konfigūraciją ir indekso būseną
curl http://localhost:20128/api/settings/local-corpus

# Atjungti nekeičiant šaltinio failų
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP įrankiai

Visiems trims įrankiams reikalinga `read:local-corpus` teisė. Įrankių atsakymuose pateikiami santykiniai keliai ir šakninio katalogo bazinis pavadinimas, bet niekada nepateikiamas jo absoliutus kelias.

| Įrankis               | Aprašymas                                                                                                  |
| :-------------------- | :--------------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Pateikti konfigūracijos būseną, indekso dydį, ribas ir paskutinio atnaujinimo laiką                        |
| `local_corpus_search` | Ieškoti indeksuotame tekste ir grąžinti apribotas, pagal eilutes suskirstytas ištraukas (iki 20 rezultatų) |
| `local_corpus_read`   | Perskaityti apribotą eilučių intervalą iš vieno leidžiamo korpuso santykinio failo                         |

MCP įvesčių pavyzdžiai:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Saugumo ribos

- Leidžiamų failų sąrašas orientuotas į tekstą: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` ir `.yml`.
- Simbolinės nuorodos praleidžiamos. Skaitymo keliai kanonizuojami ir turi likti sukonfigūruoto šakninio katalogo viduje; absoliutūs keliai ir bandymai pereiti į kitus katalogus atmetami.
- Jautrių duomenų ir sugeneruotų katalogų pavadinimai neįtraukiami: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` ir
  `secrets`.
- Numatytosios ribos: 5 000 failų, 1 MiB vienam failui, 64 MiB viso indeksuoto turinio, maždaug 4 000 simbolių viename paieškos fragmente ir 400 eilučių vienam skaitymui.
- Failai, kuriuose yra NUL simbolių, laikomi netekstiniais ir praleidžiami arba atmetami.

Dvejetainiai dokumentai, pvz., PDF, DOCX, vaizdai ir archyvai, sąmoningai nepalaikomi. Prieš indeksuodami konvertuokite juos į patvirtintą tekstinį formatą sukonfigūruotame kataloge.

## Eksploatavimo pastabos

- Pakeitus arba ištrynus sukonfigūruotą šakninį katalogą, bendrinamas atmintyje laikomas indeksas išvalomas.
- Paleidus procesą iš naujo, indeksas prarandamas; atliekant kitą paiešką jis iš naujo sukuriamas iš sukonfigūruoto šaltinio.
- `local_corpus_status` nepriverčia atlikti nuskaitymo. Kai reikia nedelsiant nuskaityti iš naujo, naudokite `local_corpus_search` su `refresh: true`.
- Nuskaitymo ir skaitymo klaidos suskaičiuojamos arba grąžinamos kaip išvalyti klaidų pranešimai; šaltinio failai niekada nekeičiami.
