> **Patikimas šaltinis:** `src/lib/obsidian/api.ts` (REST ir sinchronizavimo klientas),
> `src/lib/db/obsidian.ts` (prieigos rakto / bazinio URL / WebDAV išsaugojimas),
> `src/lib/obsidianSync.ts` (WebDAV saugyklos sinchronizavimas), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP įrankiai), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (nustatymų API). Įrankių registravimas
> ir aprėpčių susiejimas atliekamas faile `open-sse/mcp-server/server.ts`.

## Kas tai yra

OmniRoute prisijungia prie **Obsidian** saugyklos kaip prie **konteksto šaltinio** — vietinės Markdown
žinių bazės, kurią agentai skaito ir keičia naudodami integruotą MCP serverį.
Integracija komunikuoja su **Obsidian Local REST API** bendruomenės papildiniu, veikiančiu
darbalaukio programoje, todėl agentai gali ieškoti užrašų, skaityti / rašyti / dalinai keisti failus, peržiūrėti
saugyklos turinį, dirbti su kasdieniais / kassavaitiniais periodiniais užrašais, tvarkyti žymas, vykdyti Obsidian komandas
ir (pasirinktinai) koordinuoti dvikryptį darbalaukio↔mobiliojo įrenginio saugyklos sinchronizavimą.

Klientas (`src/lib/obsidian/api.ts`) papildo Local REST API šiomis funkcijomis:

- **Pakartotiniais bandymais su didėjančia delsa**, kai gaunamos laikinos `5xx` klaidos, ir **30 sekundžių skirtuoju laiku**, įgyvendintu per `AbortController`.
- **Tipizuotu klaidų klasifikavimu** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Aiškia užuomina „nepavyksta pasiekti Obsidian“**, kurioje nurodoma dažna prievado klaida
  (HTTP naudoja `27123`, o **ne** MCP galinį punktą `27124`) ir Tailscale formatas.
- Saugyklos atžvilgiu santykinių **kelių kodavimu**, kad užrašų keliai su tarpais ir pasviraisiais brūkšniais būtų saugūs.

## Sąranka

Obsidian prieigos raktui ar baziniam URL **nėra aplinkos kintamojo** — abu saugomi
SQLite lentelėje `key_value` (vardų sritis `obsidian`) naudojant
`src/lib/db/obsidian.ts`. Prieigos raktas yra **šifruojamas saugojimo vietoje** (AES-256-GCM, išlaikant
atgalinio suderinamumo atsarginį paprastojo teksto variantą). Konfigūruokite galinio punkto valdymo skydelio
skirtuke **Konteksto šaltiniai** (`ObsidianSourceCard`) arba naudodami nustatymų REST API.

> [!IMPORTANT]
> **Obsidian Local REST API** papildinys turi būti įdiegtas ir paleistas. Jo REST
> sąsaja klausosi adresu **HTTP `127.0.0.1:27123`** (numatytasis bazinis URL). Prievadas `27124`
> yra _atskiras_ MCP/HTTPS galinis punktas, kurį nustatymų maršrutas aiškiai atmeta.
> Jungdamiesi iš kito įrenginio naudokite `http://<tailscale-ip>:27123`.

### Konfigūracijos raktai (SQLite `key_value`, vardų sritis `obsidian`)

| Raktas            | Paskirtis                                                         | Šifruojama |
| ----------------- | ----------------------------------------------------------------- | ---------- |
| `api_key`         | Local REST API prieigos raktas                                    | taip       |
| `base_url`        | REST bazinis URL (numatytasis `http://127.0.0.1:27123`)           | ne         |
| `vault_path`      | Absoliutus kelias į saugyklos katalogą (sinchronizavimui)         | ne         |
| `webdav_username` | Sugeneruotas WebDAV naudotojo vardas (saugyklos sinchronizavimui) | ne         |
| `webdav_password` | Sugeneruotas WebDAV slaptažodis (saugyklos sinchronizavimui)      | taip       |
| `webdav_enabled`  | Ar įjungtas WebDAV saugyklos sinchronizavimas                     | ne         |

### Konfigūravimas per REST

```bash
# Išsaugomas ir patikrinamas Local REST API prieigos raktas (POST patikrina atlikdamas būsenos užklausą)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Patikrinama ryšio būsena (grąžinami connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Atsijungiama (pašalinamas išsaugotas prieigos raktas)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Visiems metodams reikalingas autentifikavimas valdymo skydelyje. `POST` atmeta bet kokį URL, naudojantį prievadą `27124`,
ir prieš išsaugodamas patikrina prieigos raktą, iškviesdamas Local REST API būsenos galinį punktą.

### WebDAV saugyklos sinchronizavimas

`src/app/api/settings/obsidian/webdav/route.ts` valdo pasirinktinį WebDAV pagrįstą
saugyklos sinchronizavimą (vykdomą naudojant `src/lib/obsidianSync.ts`). Jį įjungus, OmniRoute nurodomas
vietinis saugyklos katalogas ir sugeneruojama atsitiktinė WebDAV naudotojo vardo bei slaptažodžio pora:

```bash
# Įjungiamas WebDAV sinchronizavimas saugyklos katalogui (sugeneruojamas naudotojo vardas ir slaptažodis)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Gaunama WebDAV sinchronizavimo būsena (prisijungimo duomenys grąžinami tik tada, kai sinchronizavimas įjungtas)
curl http://localhost:20128/api/settings/obsidian/webdav

# Išjungiamas WebDAV sinchronizavimas (pašalinami prisijungimo duomenys ir valdomas .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Atskiro API rakto konteksto šaltinis (pasirinktinis)

Obsidian konfigūraciją galima apriboti **atskiru API raktu** naudojant lentelę `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Kai MCP iškvietime perduodamas autentifikuoto API
rakto ID, `getObsidianConfigForApiKey()` teikia pirmenybę to rakto nuosavam prieigos raktui / baziniam URL / saugyklos keliui
(`source: "api_key"`), o jei jų nėra, naudoja visuotinę konfigūraciją (`source: "global"`).

## MCP įrankiai (22)

Apibrėžti faile `open-sse/mcp-server/tools/obsidianTools.ts`. Prieigos raktas / bazinis URL nustatomi
kiekvienam iškvietimui (pirmiausia pagal API raktą, tada visuotiniai). Įrankiams, kurie kreipiasi į OmniRoute **sinchronizavimo serverį**
(keturiems `obsidian_sync_*` įrankiams), papildomai reikalingas sinchronizavimo autentifikavimo prieigos raktas, sukonfigūruotas
OmniRoute nustatymuose.

### Skaitymo įrankiai (`read:obsidian`)

| Įrankis                      | Aprašymas                                                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Patikrinti, ar vietinė REST API yra pasiekiama ir autentifikuota.                                                                    |
| `obsidian_search_simple`     | Viso teksto paieška užrašų turinyje; grąžina fragmentus su failų keliais.                                                            |
| `obsidian_search_structured` | Paieška naudojant JSON Logic išraišką (and/or/regex/path filtrus).                                                                   |
| `obsidian_read_note`         | Skaityti užrašą pagal saugyklos atžvilgiu nurodytą kelią; pasirinktinai konkrečią antraštę / bloką / metaduomenis.                   |
| `obsidian_list_vault`        | Išvardyti saugyklos failus ir katalogus (įrašų medį).                                                                                |
| `obsidian_get_document_map`  | Gauti užrašo antraščių struktūrą kaip antraščių → eilučių numerių žemėlapį.                                                          |
| `obsidian_get_note_metadata` | Gauti metaduomenis, žymas, nuorodas ir simbolių / žodžių skaičių be viso turinio.                                                    |
| `obsidian_get_active_file`   | Gauti šiuo metu aktyvaus Obsidian failo kelią ir turinį.                                                                             |
| `obsidian_get_periodic_note` | Gauti nurodytos datos dienos / savaitės / mėnesio periodinį užrašą (jei praleista – šiandienos).                                     |
| `obsidian_get_tags`          | Išvardyti visas saugyklos žymas ir jų dažnius.                                                                                       |
| `obsidian_list_commands`     | Išvardyti galimus Obsidian komandų ID (naudoti su `obsidian_execute_command`).                                                       |
| `obsidian_sync_status`       | OmniRoute sinchronizavimo serverio būsena: ar veikia, saugyklos pavadinimas, prievadas, veikimo trukmė, paskutinis sinchronizavimas. |
| `obsidian_sync_conflicts`    | Išvardyti neišspręstus sinchronizavimo konfliktus (kelias, konflikto kelias, aptikimo laikas).                                       |

### Rašymo įrankiai (`write:obsidian`)

| Įrankis                          | Aprašymas                                                                                                            |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Sukurti arba perrašyti užrašą pateiktu Markdown turiniu.                                                             |
| `obsidian_append_note`           | Pridėti turinį prie užrašo; pasirinktinai prie konkrečios antraštės / bloko.                                         |
| `obsidian_patch_note`            | Tiksliai pridėti po / prieš arba pakeisti antraštės, bloko ar metaduomenų lauko turinį.                              |
| `obsidian_delete_note`           | Visam laikui ištrinti užrašą iš saugyklos.                                                                           |
| `obsidian_move_note`             | Perkelti arba pervardyti užrašą saugykloje.                                                                          |
| `obsidian_execute_command`       | Vykdyti Obsidian komandą pagal jos komandos ID.                                                                      |
| `obsidian_open_file`             | Atidaryti failą Obsidian programoje (sukuria jį, jei jis neegzistuoja).                                              |
| `obsidian_sync_trigger`          | Nedelsiant paleisti dvikryptį darbalaukio ↔ mobiliojo įrenginio saugyklos sinchronizavimą.                           |
| `obsidian_sync_resolve_conflict` | Išspręsti sinchronizavimo konfliktą: palikti `local` (mobiliojo įrenginio), `remote` (darbalaukio) arba `keep-both`. |

> [!NOTE]
> `obsidian_patch_note` paskirties vietos priima `targetType` reikšmes `heading | block | frontmatter`
> ir `operation` reikšmes `append | prepend | replace`, taip pat pasirinktinį
> `createTargetIfMissing`. Keturi `obsidian_sync_*` įrankiai susisiekia su vietiniu sinchronizavimo
> serveriu (pagal numatytuosius nustatymus `http://127.0.0.1:27781`) ir reikalauja sinchronizavimo prieigos rakto.

### Aprėptys

Skaitymo įrankiams reikalinga `read:obsidian`, o rašymo įrankiams – `write:obsidian`. Priverstinis taikymas
yra toks pat kaip Notion — jį apdoroja `withScopeEnforcement()`, esanti
`open-sse/mcp-server/server.ts`, ir jis įjungiamas, kai `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, o
leidžiamos aprėptys gaunamos iš `OMNIROUTE_MCP_SCOPES` arba API rakto aprėpties konteksto. Žr.
[MCP-SERVER.md](./MCP-SERVER.md).

## Galiniai taškai

| Metodas  | Kelias                          | Paskirtis                                                             |
| -------- | ------------------------------- | --------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Grąžina `{ connected, hasToken, baseUrl, vaultPath }`.                |
| `POST`   | `/api/settings/obsidian`        | Išsaugo ir patikrina prieigos raktą (atmeta prievadą `27124`).        |
| `DELETE` | `/api/settings/obsidian`        | Atjungia (išvalo išsaugotą prieigos raktą).                           |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV sinchronizavimo būsena ir prisijungimo duomenys (kai įjungta). |
| `POST`   | `/api/settings/obsidian/webdav` | Įjungia WebDAV sinchronizavimą saugyklos katalogui.                   |
| `DELETE` | `/api/settings/obsidian/webdav` | Išjungia WebDAV sinchronizavimą.                                      |

> Tai yra valdymo skydelio nustatymų maršrutai. Pati saugykla pasiekiama per Obsidian
> Local REST API (sukonfigūruotą `base_url`) ir anksčiau nurodytus MCP įrankius —
> viešojo Obsidian tarpinio serverio galinio taško `/v1` nėra.

## Naudojimo atvejai

- **Saugykla pagrįsti atsakymai** — `obsidian_search_simple` / `obsidian_search_structured`,
  tada `obsidian_read_note`, kad agentas atsakytų remdamasis tikraisiais jūsų užrašais.
- **Užrašų kūrimas / dienoraščio rašymas** — `obsidian_write_note`, `obsidian_append_note`
  arba tikslinis `obsidian_patch_note`, skirtas agento išvesčiai, santraukoms ar kasdieniams
  užrašams (`obsidian_get_periodic_note`) įrašyti į saugyklą.
- **Naršymas saugykloje** — `obsidian_list_vault`, `obsidian_get_document_map` ir
  `obsidian_get_tags`, skirti struktūrai išnagrinėti prieš skaitant ar rašant.
- **Obsidian automatizavimas** — `obsidian_list_commands` + `obsidian_execute_command`,
  skirti papildiniams ar komandoms valdyti per agentą; `obsidian_open_file`, skirtas
  užrašui parodyti naudotojo sąsajoje.
- **Sinchronizavimas su mobiliaisiais įrenginiais** — įjunkite WebDAV sinchronizavimą,
  tada naudokite `obsidian_sync_trigger` / `obsidian_sync_status` /
  `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`, kad koordinuotumėte
  sinchronizavimą tarp darbalaukio ir mobiliojo įrenginio bei išspręstumėte konfliktus.
