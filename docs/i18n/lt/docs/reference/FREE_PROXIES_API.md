„OmniRoute“ pateikiamas su atrinktu nemokamų tarpinių serverių rinkiniu lentelėje `free_proxies`,
sinchronizuojamu iš išorinių teikėjų (1proxy, proxifly, iplocate, webshare).
Valdymo skydelyje jie pateikiami skiltyje **Nustatymai → Nemokami tarpiniai serveriai**. Šiame dokumente
aprašomas serverio pusės filtravimas, rikiavimas, skaičiavimas ir sinchronizavimo klaidų pateikimas,
kurį užtikrina sąrašo maršrutas.

## Sąrašo maršrutas — `GET /api/settings/free-proxies`

Grąžina filtruotą, surikiuotą ir puslapiais suskirstytą ištrauką bei bendrą įrašų skaičių. Filtravimas ir
skaičiavimas atliekami SQL, todėl naudotojo sąsajoje galima rodyti tikrąjį bendrą skaičių (pvz., `Iš viso: 0`)
neįkeliant visų eilučių į atmintį.

### Užklausos parametrai

| Parametras        | Tipas                              | Numatytoji reikšmė | Reikšmė                                                                                                                            |
| ----------------- | ---------------------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | eilutė                             | `""`               | Didžiosioms ir mažosioms raidėms jautrus `LIKE`, taikomas pagrindinio kompiuterio (ir šaltinio) stulpeliui.                        |
| `protocol`        | eilutė                             | `""`               | `type` filtras: `http` / `https` / `socks4` / `socks5`. Tuščia reikšmė = visi.                                                     |
| `country`         | eilutė                             | `""`               | `countryCode` filtras (ISO-2). Tuščia reikšmė = visos šalys.                                                                       |
| `minQuality`      | skaičius                           | `0`                | Tik eilutės, kurių `qualityScore >= minQuality`. `0` = nėra apatinės ribos.                                                        |
| `disabledSources` | eilutė                             | `""`               | Kableliais atskirti neįtrauktinų šaltinių ID (pvz., `proxifly,webshare`).                                                          |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`          | `quality` = balas mažėjančiai; `latency` = delsa didėjančiai (nulinės reikšmės pabaigoje); `recent` = `lastValidated` mažėjančiai. |
| `offset`          | skaičius                           | `0`                | Puslapiavimo pradžia.                                                                                                              |
| `limit`           | skaičius                           | `50`               | Puslapio dydis (ribojamas serverio pusėje).                                                                                        |

### Atsakas

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 iš išorinio šaltinio"],
    "webshare": ["tinklo skirtasis laikas baigėsi"]
  }
}
```

`total` nurodo bendrą filtruotų įrašų skaičių **prieš** puslapiavimą, todėl naudotojo sąsaja gali
nepriklausomai atvaizduoti `Iš viso: N` ir `hasMore`. `syncErrors` raktai yra šaltinių ID, o
reikšmės pateikiamos tik tiems šaltiniams, kurių paskutinė sinchronizacija nepavyko — rezultatas
`Iš viso: 0` niekada nepateikiamas be paaiškinimo.

## Įtraukimas į rinkinį — `POST /api/settings/free-proxies/[id]/add-to-pool`

Perkelia nemokamą tarpinį serverį į valdomą `proxy_registry` rinkinį. Pirmiausia patikrina
išorinį serverį; jei patikra sėkminga, grąžina naujo rinkinio tarpinio serverio ID ir išmatuotą delsą.

## Sinchronizavimas — `POST /api/settings/free-proxies/sync`

Iš naujo gauna duomenis iš visų įjungtų šaltinių (arba poaibio, nurodyto `{ "sources": [...] }`).
Kiekvienas šaltinis sinchronizuojamas atskirai; nepavykusio šaltinio klaida įrašoma į `syncErrors`,
o kitų šaltinių sinchronizavimas vis tiek užbaigiamas, todėl dalinis sinchronizavimas niekada
neištrina anksčiau gautų tinkamų duomenų.

## Statistika — `GET /api/settings/free-proxies/stats`

Grąžina `total / inPool / avgQuality / bySource / lastSyncAt` suvestinę
be eilučių duomenų — ji naudojama valdymo skydelio antraštės valdikliuose.
