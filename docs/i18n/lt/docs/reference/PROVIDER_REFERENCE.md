## Kategorijos

- **Nemokama** — nemokamas planas su API raktu (konfigūruojamas valdymo skydelyje)
- **Be autentifikavimo** — viešieji galiniai taškai, kuriems visiškai nereikia rakto ar prisijungimo
- **OAuth** — prisijungimo procesą tvarko „OmniRoute“, API rakto nereikia
- **Žiniatinklio slapukas** — suteikia prieigą prie teikėjo žiniatinklio programos naudojant autentifikavimo slapuką
- **API raktas** — mokamas teikėjas, konfigūruojamas naudojant API raktą (gali būti suteikiami nemokami kreditai)
- **Vietinis** — veikia naudotojo kompiuteryje („Ollama“, „LM Studio“, „vLLM“ ir kt.)
- **Paieška** — žiniatinklio paieškos teikėjai
- **Garsas** — tik garso teikėjai (TTS / STT)
- **Aukštesnio lygmens tarpinis serveris** — teikėjai, nukreipiantys užklausas kitiems teikėjams
- **Debesijos agentas** — ilgai veikiantys programavimo agentai („Codex Cloud“, „Devin“, „Jules“)
- **Sisteminė** — vidiniai „OmniRoute“ teikėjai (grįžtamasis ryšys ir kt.)

Papildomos žymos: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Įrankių iškvietimas` (kai nurodyta): `native` — tikra funkcijų iškvietimo API; `emulated` — `tools` masyvas emuliuojamas užklausoje naudojant `webTools.ts` (reguliariosiomis išraiškomis analizuojami `<tool>{...}</tool>` blokai); `none` — šiuo metu `tools` tyliai atmetamas. Žr. #7286.

Norėdami įjungti, sukonfigūruoti ir išbandyti kiekvieną teikėją, naudokite valdymo skydelį adresu `/dashboard/providers`.
