> Vykdymo metu keičiami jungikliai, keičiantys „OmniRoute“ veikimą **be pakartotinio diegimo**.
> Kiekviena čia nurodyta žyma apibrėžta faile
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — vieninteliame tiesos šaltinyje. Ir valdymo skydelis, ir REST API skaito duomenis iš
> šio failo, todėl toliau pateikta lentelė sugeneruota taip, kad jį tiksliai atitiktų santykiu 1:1.

---

## Kas yra funkcijų žymos

Funkcijos žyma yra pavadintas jungiklis (loginė arba išvardijimo reikšmė), kurio reikšmę galima keisti
vykdymo metu ir išsaugoti duomenų bazėje neperdiegiant proceso. Kiekvieną
žymą aprašo `FeatureFlagDefinition`, turintis `key`, `label`,
`description`, `category`, `defaultValue`, `type` ir `requiresRestart` nuorodą.

### Nustatymo tvarka

Žymos **galutinę reikšmę** nustato
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts), vadovaudamasi šia
pirmenybės tvarka (laimi aukščiausias prioritetas):

1. **DB perrašymas** — `key_value` lentelėje, `feature_flags` vardų srityje,
   saugoma reikšmė (nustatyta valdymo skydelyje arba per REST API).
2. **Aplinkos kintamasis** — `process.env[<KEY>]`, jei jis nustatytas ir nėra tuščias.
3. **Numatytoji apibrėžimo reikšmė** — `defaultValue` iš `featureFlagDefinitions.ts`.

Loginė žyma laikoma **įjungta**, kai jos galutinė reikšmė yra `"true"`,
`"1"` arba `"yes"` (žr. `isFeatureFlagEnabled()`).

> [!NOTE]
> Dauguma žymų taip pat turi atitinkamą **tokio paties pavadinimo** aplinkos kintamąjį,
> aprašytą faile [`ENVIRONMENT.md`](./ENVIRONMENT.md). Žymos DB perrašymas
> turi pirmenybę prieš šį aplinkos kintamąjį. Žyma su
> `requiresRestart: true` išsaugoma iš karto, tačiau iš naujo nuskaitoma tik paleidžiant
> procesą — ją perjungus, valdymo skydelyje parodoma **„Paleisti serverį iš naujo“** juosta.

## Požymių perjungimas

### Valdymo skydelis

Eikite į **Valdymo skydelis → Nustatymai → Funkcijų požymiai**
(`/dashboard/settings/feature-flags`). Tinklelis
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
leidžia:

- Atlikti **paiešką** pagal raktą ar aprašą ir **filtruoti** pagal kategoriją (taip pat yra sintetinė
  **Reikia paleisti iš naujo** rodinio parinktis).
- Naudoti **jungiklį** loginiams požymiams ir **išskleidžiamąjį sąrašą** išvardijimo požymiams
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Matyti kiekvieno požymio **šaltinio ženklelį** — `DB`, `ENV` arba `DEF`, — nurodantį, iš kur
  gauta galiojanti reikšmė.
- Naudoti mygtuką **Atkurti** (rodomą tik požymiams, kurių šaltinis yra `DB`), kad būtų pašalytas perrašymas,
  ir apačioje esantį mygtuką **Atkurti visus perrašymus**.
- Matyti reklamjuostę **Paleisti serverį iš naujo**, kai pakeičiamas požymis su `requiresRestart`.

### REST API

Visos operacijos atliekamos per vieną maršrutą:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Kiekvienam metodui reikalingas autentifikuotas valdymo skydelio seansas (kitu atveju grąžinama `401`).

#### `GET /api/settings/feature-flags`

Grąžina kiekvieną požymį su jo galiojančia reikšme, šaltiniu ir suvestine.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... visi 75 požymiai
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Nustato arba pašalina vieną perrašymą. Turinys: `{ key: string; value?: string }`.
Praleidus `value`, perrašymas pašalinamas (atkuriama aplinkos / numatytoji reikšmė).

```bash
# Nustatyti DB perrašymą
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Pašalinti perrašymą (be "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Atsakyme pakartojamos naujos `effectiveValue`/`source`, ankstesnės `previousValue`/
`previousSource` ir `requiresRestart` reikšmės. Nežinomi raktai ir leistino diapazono neatitinkančios išvardijimo
reikšmės atmetamos pateikiant `400`.

#### `DELETE /api/settings/feature-flags`

Vienu metu pašalina **visus** DB perrašymus ir atkuria kiekvieno požymio aplinkos / numatytąją
reikšmę. Grąžina `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Požymiai su `requiresRestart: true` įsigalioja tik iš naujo paleidus procesą.
> Valdymo skydelio paleidimo iš naujo procesas iškviečia `POST /api/restart`, o tada periodiškai siunčia užklausas į
> `GET /api/health/ping`, kol serveris vėl pradeda veikti.

---

## Avarinis biudžeto atsarginis variantas

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, numatytoji reikšmė `true`) valdo
avarinį nemokamą atsarginį kelią faile
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Kai jis įjungtas, biudžetą išnaudojusios užklausos nukreipiamos nemokamam atsarginiam
teikėjui / modeliui, užuot iš karto patyrusios nesėkmę. Nustatykite `false` (arba `0`) — naudodami
valdymo skydelio jungiklį, DB perrašymą arba aplinkos kintamąjį `OMNIROUTE_EMERGENCY_FALLBACK`
— kad išjungtumėte šią elgseną ir leistumėte biudžetą išnaudojusioms užklausoms
patirti nesėkmę. (Valdymo skydelio jungiklis pridėtas PR #3741 / #3752.)
