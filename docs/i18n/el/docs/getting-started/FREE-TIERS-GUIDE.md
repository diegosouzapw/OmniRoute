> **Εν ολίγοις**: Χρησιμοποιήστε τους δικούς σας επιλέξιμους λογαριασμούς παρόχων. Το OmniRoute συνδυάζει τις συνδέσεις που διαμορφώνετε· δεν παρέχει το διαφημιζόμενο συνολικό όριο token. Η δωρεάν πρόσβαση ενδέχεται να απαιτεί εγγραφή, κλειδί API, έγκριση ή μέθοδο πληρωμής. Εξακολουθούν να ισχύουν τα όρια, οι πολιτικές απορρήτου και οι όροι των παρόχων.

## Τι είναι τα δωρεάν επίπεδα;

Πολλοί πάροχοι τεχνητής νοημοσύνης προσφέρουν κάποια μορφή **δωρεάν πρόσβασης**. Ανάλογα με τον πάροχο, αυτό μπορεί να σημαίνει ένα τελικό σημείο χωρίς έλεγχο ταυτότητας, επαναλαμβανόμενο όριο χρήσης, απεριόριστη πρόσβαση με περιορισμό ρυθμού, πίστωση κατά την εγγραφή, μη αυτόματη έγκριση ή μια προσωρινή προωθητική ενέργεια. Ορισμένες επιλογές απαιτούν λογαριασμό, κλειδί API, πιστωτική κάρτα, KYC ή αποδοχή όρων που αφορούν συγκεκριμένα τον πάροχο.

Το OmniRoute **συγκεντρώνει** τις διαμορφωμένες συνδέσεις σε ένα τελικό σημείο. Εξακολουθείτε να εγγράφεστε ξεχωριστά σε κάθε πάροχο που απαιτεί λογαριασμό. Συνδέστε αυτούς τους λογαριασμούς και χρησιμοποιήστε το `model: "auto"` για δρομολόγηση μεταξύ των κατάλληλων προορισμών. Μια νέα εγκατάσταση ενδέχεται να μην έχει κανέναν κατάλληλο προορισμό χωρίς κλειδί· η εγκατάσταση του OmniRoute από μόνη της δεν εγγυάται επιτυχή απόκριση συνομιλίας.

## Πώς να συνδυάσετε δωρεάν βαθμίδες

Η μαγεία του OmniRoute είναι ο **συνδυασμός δωρεάν βαθμίδων**. Αντί να βασίζεστε σε έναν πάροχο, συνδέετε πολλούς δωρεάν παρόχους και αφήνετε το OmniRoute να επιλέγει αυτόματα τον καλύτερο για κάθε αίτημα.

### Παράδειγμα: Ευρύτερη κάλυψη δωρεάν βαθμίδων

Συνδέστε αρκετούς παρόχους για να μειώσετε την εξάρτηση από οποιοδήποτε μεμονωμένο όριο χρήσης:

1. **Gemini** — επαναλαμβανόμενο όριο χρήσης κλειδιού API
2. **Groq** — επαναλαμβανόμενο όριο χρήσης κλειδιού API
3. **Pollinations** — πρόσβαση χωρίς κλειδί, με περιορισμό ρυθμού
4. **LongCat** — εφάπαξ πίστωση εγγραφής (απαιτεί KYC)

Στη συνέχεια, χρησιμοποιήστε `model: "auto"` και το OmniRoute θα:

- Δοκιμάσει πρώτα την επιλέξιμη σύνδεση με την υψηλότερη κατάταξη
- Αν αποτύχει το όριο χρήσης ή ο έλεγχος εύρυθμης λειτουργίας της → θα δοκιμάσει τον επόμενο διαμορφωμένο πάροχο
- Αν ο πάροχος χωρίς κλειδί δεν είναι διαθέσιμος → θα συνεχίσει με τους υπόλοιπους στόχους
- Αν καμία επιλέξιμη σύνδεση δεν επιτύχει → θα επιστρέψει σφάλμα· οι πιστώσεις εγγραφής μπορούν να χρησιμοποιηθούν μόνο όσο είναι έγκυρες και διαθέσιμες

**Αποτέλεσμα**: ευρύτερη κάλυψη δωρεάν βαθμίδων με αυτόματη εναλλακτική δρομολόγηση — όχι εγγύηση απεριόριστης χωρητικότητας.

## Πώς να συνδέσετε δωρεάν παρόχους

### Βήμα 1: Ανοίξτε τον Πίνακα ελέγχου

Μεταβείτε στη διεύθυνση `http://localhost:20128` στο πρόγραμμα περιήγησής σας.

### Βήμα 2: Μεταβείτε στους Παρόχους

Κάντε κλικ στην επιλογή **Πάροχοι** στην πλαϊνή γραμμή.

### Βήμα 3: Κάντε κλικ στην Προσθήκη παρόχου

Κάντε κλικ στο κουμπί **+ Προσθήκη παρόχου**.

### Βήμα 4: Επιλέξτε έναν δωρεάν πάροχο

Περιηγηθείτε στον κατάλογο και εξετάστε τα τρέχοντα μεταδεδομένα `hasFree`, ελέγχου ταυτότητας, ορίων χρήσης, απορρήτου
και Όρων Παροχής Υπηρεσιών κάθε παρόχου. Η κάρτα του παρόχου και η
[Αναφορά δωρεάν βαθμίδων](../reference/FREE_TIERS.md) διακρίνουν τα επαναλαμβανόμενα διαθέσιμα όρια,
την απεριόριστη πρόσβαση/πρόσβαση χωρίς κλειδί, τις μονάδες εγγραφής, τις καταργημένες καταχωρίσεις και τις πηγές υψηλότερου κινδύνου.

### Βήμα 5: Κάντε κλικ στη Σύνδεση

Για έναν πάροχο `NOAUTH`, το OmniRoute δεν ζητά διαπιστευτήριο για την υπηρεσία ανωτέρου επιπέδου. Αυτό δεν εγγυάται ότι η υπηρεσία ανωτέρου επιπέδου αποδέχεται προγράμματα-πελάτες τρίτων ή διαθέτει επαρκή χωρητικότητα. Οι πάροχοι OAuth και κλειδιών API πρέπει να συνδέονται μέσω της τεκμηριωμένης ροής λογαριασμού τους. Το πρόγραμμα-πελάτης σας εξακολουθεί να χρησιμοποιεί το κλειδί API του OmniRoute που εμφανίζεται στην ενότητα **Πίνακας ελέγχου → Τελικά σημεία** όταν είναι ενεργοποιημένος ο έλεγχος ταυτότητας του δρομολογητή.

### Βήμα 6: Επαναλάβετε

Συνδέστε αρκετούς παρόχους των οποίων οι όροι και το μοντέλο απορρήτου ταιριάζουν στην περίπτωση χρήσης σας.

## Σωστή ανάγνωση του καταλόγου

- Το `NOAUTH` σημαίνει ότι το OmniRoute δεν σας ζητά διαπιστευτήριο παρόχου· αυτό δεν
  εγγυάται διαθεσιμότητα, ιδιωτικότητα ή απεριόριστη χωρητικότητα.
- Το `hasFree` αποτελεί μεταδεδομένο εντοπισμού. Μπορεί να αντιπροσωπεύει ένα επαναλαμβανόμενο όριο χρήσης, πρόσβαση χωρίς κλειδί,
  πίστωση εγγραφής, πρόγραμμα έγκρισης ή προωθητική ενέργεια.
- Το `recurring-uncapped` σημαίνει ότι δεν υπήρχε διαθέσιμο δημοσιευμένο ανώτατο όριο token· εξακολουθούν να ισχύουν τα όρια ρυθμού
  και ταυτόχρονων αιτημάτων.
- Το `one-time-initial` δεν επαναλαμβάνεται μετά την εξάντληση της παροχής εγγραφής.
- Οι πάροχοι με επισήμανση `tos: avoid` εξαιρούνται από προεπιλογή από την αυτόματη δρομολόγηση (`excludeTosAvoid`). Η σύνδεση ενός λογαριασμού δεν παρακάμπτει αυτό το φίλτρο. Κάθε παράκαμψη από τον διαχειριστή θα πρέπει να γίνεται κατόπιν εξέτασης των όρων του παρόχου και του κινδύνου για τον λογαριασμό.
- Οι καταχωρίσεις με επισήμανση `discontinued` παραμένουν ως ιστορικά τεκμήρια και δεν πρέπει να παρουσιάζονται ως
  δωρεάν επί του παρόντος.

## Πώς το OmniRoute Βελτιώνει τα Δωρεάν Πακέτα

### 1. Αυτόματη Μετάπτωση

Αν ένας δωρεάν πάροχος είναι απασχολημένος ή εκτός λειτουργίας, το OmniRoute δοκιμάζει αυτόματα τον επόμενο. Δεν χρειάζεται να κάνετε τίποτα.

### 2. Έξυπνη Δρομολόγηση

Το OmniRoute επιλέγει τον **καλύτερο δωρεάν πάροχο** για κάθε αίτημα με βάση:

- Ταχύτητα — Ποιος πάροχος είναι ο ταχύτερος αυτήν τη στιγμή;
- Ποιότητα — Ποιος πάροχος είναι ο καλύτερος για αυτήν την εργασία;
- Χωρητικότητα — Ποιος πάροχος έχει υπόλοιπο διαθέσιμου ορίου χρήσης;

### 3. Εξοικονόμηση Token

Η διοχέτευση συμπίεσης του OmniRoute μπορεί να μειώσει τα επιλέξιμα token της προτροπής και της εξόδου εργαλείων. Η
πραγματική εξοικονόμηση εξαρτάται από το περιεχόμενο, τις επιλεγμένες μηχανές, τη λογιστική καταμέτρηση του παρόχου και τις ρυθμίσεις
πιστότητας· η συμπίεση δεν πολλαπλασιάζει κάθε όριο χρήσης παρόχου κατά έναν σταθερό συντελεστή.

### 4. Υποστήριξη Πολλαπλών Λογαριασμών

Αν οι όροι του παρόχου επιτρέπουν πολλαπλούς λογαριασμούς ή διαπιστευτήρια, το OmniRoute μπορεί να αντιμετωπίζει κάθε
σύνδεση ως ξεχωριστό υποψήφιο προορισμό δρομολόγησης. Μη δημιουργείτε επιπλέον λογαριασμούς για να παρακάμπτετε το
όριο χρήσης ή την πολιτική πρόσβασης ενός παρόχου.

## Υπολογισμός δωρεάν βαθμίδας

Ο ενεργός κατάλογος, με εξάλειψη διπλοτύπων ανά κοινόχρηστο απόθεμα, αναφέρει επί του παρόντος:

| Μέτρηση                                  | Τρέχουσα ελεγμένη τιμή | Ερμηνεία                                                                                                   |
| ---------------------------------------- | ---------------------: | ---------------------------------------------------------------------------------------------------------- |
| Επαναλαμβανόμενη ποσοτικοποιημένη παροχή | **~1.62B tokens/μήνα** | Τα κοινόχρηστα αποθέματα υπολογίζονται μία φορά· εξαιρούνται από το άθροισμα οι πάροχοι χωρίς ανώτατο όριο |
| Πρώτος μήνας με παροχές εγγραφής         |      **~2.22B tokens** | Επαναλαμβανόμενο σύνολο συν εφάπαξ και επαναλαμβανόμενες πιστώσεις                                         |

Αυτές είναι εκτιμήσεις για ολόκληρο τον κατάλογο, σε ξεχωριστούς επιλέξιμους λογαριασμούς, και όχι όριο χρήσης που παρέχεται από το OmniRoute ή πρόβλεψη για μια νέα εγκατάσταση. Η αξιοποιήσιμη χωρητικότητά σας εξαρτάται από τους παρόχους που συνδέετε και τους ισχύοντες όρους τους. Οι τιμές υπολογίζονται από το `open-sse/config/freeModelCatalog.ts`· ανατρέξτε στην
[Αναφορά δωρεάν βαθμίδων](../reference/FREE_TIERS.md) για την εξάλειψη διπλοτύπων κοινόχρηστων αποθεμάτων, τις σημάνσεις ToS,
τις καταργημένες καταχωρίσεις και τη μεθοδολογία πιστώσεων εγγραφής.

## Συνήθεις ερωτήσεις

### "Είναι πράγματι δωρεάν;"

Ο κατάλογος καταγράφει τους όρους που δημοσιεύουν οι πάροχοι και την έρευνα του έργου, αλλά οι προσφορές ενδέχεται να αλλάξουν.
Επαληθεύστε την τρέχουσα τιμολόγηση, την ποσόστωση, την πολιτική απορρήτου και τα κριτήρια επιλεξιμότητας του παρόχου πριν από τη χρήση.

### "Θα εξαντληθεί η δωρεάν βαθμίδα;"

Κάθε πάροχος μπορεί να επιβάλει περιορισμό ρυθμού, να αλλάξει μοντέλα, να αναστείλει την πρόσβαση ή να τεθεί εκτός σύνδεσης. Οι πολλαπλές
συνδέσεις βελτιώνουν την κάλυψη εναλλακτικής δρομολόγησης, αλλά δεν εγγυώνται τη διαθεσιμότητα μιας δωρεάν διαδρομής.

### "Μπορώ να χρησιμοποιώ δωρεάν παρόχους σε περιβάλλον παραγωγής;"

Μόνο εάν το SLA, ο χειρισμός δεδομένων, τα όρια και οι όροι του παρόχου καλύπτουν τις απαιτήσεις
παραγωγής σας. Οι κρίσιμοι φόρτοι εργασίας θα πρέπει να διαθέτουν παρακολουθούμενη και συμβατικά κατάλληλη εναλλακτική λύση.

### "Πού είναι η παγίδα;"

Οι συμβιβασμοί ενδέχεται να περιλαμβάνουν αυστηρά όρια, λίστες αναμονής, KYC, επαλήθευση πιστωτικής κάρτας, εκπαίδευση με βάση τα
prompts, ασθενέστερη προστασία απορρήτου, απουσία SLA, συχνές αλλαγές μοντέλων, γεωγραφικούς περιορισμούς, χρέωση υπέρβασης ή
κινδύνους που σχετίζονται με την πολιτική λογαριασμών. Το OmniRoute προβάλλει τα διαθέσιμα μεταδεδομένα· εσείς επιλέγετε τι θα ενεργοποιήσετε.

### "Πώς μπορώ να αποκτήσω μεγαλύτερη δωρεάν ποσόστωση;"

1. Συνδέστε περισσότερους δωρεάν παρόχους
2. Ενεργοποιήστε τις κατάλληλες μηχανές συμπίεσης και μετρήστε την εξοικονόμηση για τον φόρτο εργασίας σας
3. Χρησιμοποιήστε το `auto/cheap` για να δώσετε προτεραιότητα σε δωρεάν/φθηνούς παρόχους
4. Προσθέστε επιπλέον επιτρεπόμενους παρόχους ή διαπιστευτήρια χωρίς να παραβιάζετε τους όρους των παρόχων

### "Οι δωρεάν πάροχοι προσφέρουν χειρότερη ποιότητα;"

Όχι απαραίτητα. Ορισμένοι πάροχοι διαθέτουν τις ίδιες οικογένειες μοντέλων που είναι διαθέσιμες μέσω επί πληρωμή
διαδρομών, αλλά τα όρια, η καθυστέρηση, το απόρρητο, η αξιοπιστία και οι εκδόσεις μοντέλων ενδέχεται να διαφέρουν. Χρησιμοποιήστε τη
σελίδα κατάταξης δωρεάν παρόχων ως ένδειξη ποιότητας και επαληθεύστε το μοντέλο που παρέχεται στην πράξη.
