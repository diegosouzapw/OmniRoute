Οι πάροχοι Web Cookie επιτρέπουν στο OmniRoute να χρησιμοποιεί μια υπηρεσία AI μέσω της υπάρχουσας περιόδου σύνδεσης του προγράμματος περιήγησής σας αντί για ένα κλειδί API. Είναι χρήσιμοι όταν έχετε ήδη πρόσβαση σε μια υπηρεσία μέσω του ιστοτόπου της και θέλετε το OmniRoute να χρησιμοποιεί την ίδια πιστοποιημένη περίοδο σύνδεσης.

Σε αντίθεση με τους παρόχους που χρησιμοποιούν κλειδί API, οι πάροχοι Web Cookie πραγματοποιούν έλεγχο ταυτότητας χρησιμοποιώντας τα διαπιστευτήρια που αποστέλλει το πρόγραμμα περιήγησής σας στον ιστότοπο.

---

# Πριν ξεκινήσετε

> **Σημαντικό:** Αντιγράφετε πάντα τα διαπιστευτήρια από ένα **ενεργό αίτημα δικτύου** και **όχι** από τον χώρο αποθήκευσης cookie του προγράμματος περιήγησής σας.

Πολλά προβλήματα ελέγχου ταυτότητας προκαλούνται από την αντιγραφή cookie από λάθος σημείο.

## ΜΗΝ αντιγράφετε από τον χώρο αποθήκευσης cookie

Τα περισσότερα προγράμματα περιήγησης εμφανίζουν τα αποθηκευμένα cookie μέσω των εξής επιλογών:

```
DevTools
→ Application (ή Storage)
→ Cookies
```

Παρόλο που αυτά τα cookie φαίνονται σωστά, ενδέχεται να είναι:

- παρωχημένα
- ελλιπή
- χωρίς cookie που αποστέλλονται μόνο σε πιστοποιημένα αιτήματα

Η χρήση αυτών των τιμών μπορεί να προκαλέσει αποτυχίες ελέγχου ταυτότητας, ακόμη και αν φαίνονται έγκυρες.

## Αντιγραφή από ενεργό αίτημα

Αντί γι' αυτό, χρησιμοποιήστε τα cookie από ένα επιτυχημένο αίτημα:

```
DevTools
→ Network
→ Ανανεώστε τη σελίδα
→ Ανοίξτε ένα αίτημα συνομιλίας
→ Request Headers
→ Cookie
```

Η κεφαλίδα αιτήματος `Cookie` περιέχει τις ακριβείς πληροφορίες ελέγχου ταυτότητας που χρησιμοποίησε επιτυχώς το πρόγραμμα περιήγησής σας.

Για τους περισσότερους παρόχους Web Cookie, αυτή είναι η τιμή που πρέπει να επικολληθεί στο OmniRoute.

# Γενική ρύθμιση

Η διαδικασία ρύθμισης είναι ίδια για τους περισσότερους παρόχους Web Cookie.

1. Συνδεθείτε στον ιστότοπο του παρόχου.
2. Ανοίξτε τα Εργαλεία προγραμματιστή του προγράμματος περιήγησης.
3. Ανοίξτε την καρτέλα **Network**.
4. Ανανεώστε τη σελίδα.
5. Ανοίξτε ένα πιστοποιημένο αίτημα συνομιλίας.
6. Αντιγράψτε τα απαιτούμενα διαπιστευτήρια ελέγχου ταυτότητας.
7. Ανοίξτε το OmniRoute.
8. Μεταβείτε στην επιλογή **Providers → Add Provider**.
9. Επιλέξτε τον πάροχο Web Cookie.
10. Επικολλήστε τα διαπιστευτήρια.
11. Κάντε κλικ στην επιλογή **Test Connection**.
12. Αποθηκεύστε τον πάροχο.

Τα ακριβή διαπιστευτήρια που απαιτούνται εξαρτώνται από τον πάροχο.

# Τι μπορούν και τι δεν μπορούν να κάνουν οι πάροχοι Web Cookie

Οι πάροχοι Web Cookie επαναχρησιμοποιούν το περιβάλλον συνομιλίας ενός ιστοτόπου. **Δεν** παρέχουν τις ίδιες δυνατότητες με τα επίσημα API.

## Υποστηρίζονται

- Έλεγχος ταυτότητας μέσω της υπάρχουσας περιόδου σύνδεσης του προγράμματος περιήγησής σας
- Πρόσβαση στα μοντέλα που είναι διαθέσιμα μέσω του λογαριασμού σας
- Συνεχής ροή απαντήσεων συνομιλίας
- Δεν απαιτείται κλειδί API

## Δεν υποστηρίζονται

- Κλήση συναρτήσεων
- Κλήση εργαλείων
- Αυτόματη επεξεργασία αρχείων
- Ροές εργασίας IDE με πράκτορες
- Δυνατότητες διαθέσιμες μόνο μέσω API

Αυτή είναι αναμενόμενη συμπεριφορά και **δεν** αποτελεί σφάλμα.

Εάν χρειάζεστε εκτέλεση εργαλείων, αυτόματη επεξεργασία αρχείων ή άλλες ροές εργασίας με πράκτορες, χρησιμοποιήστε έναν **πάροχο με κλειδί API** αντί για έναν πάροχο Web Cookie.

# Περιορισμός επικύρωσης

Μια επιτυχημένη ενέργεια **Test Connection** ή επικύρωση cookie επαληθεύει μόνο ότι τα παρεχόμενα διαπιστευτήρια φαίνεται να έχουν την αναμενόμενη μορφή.

Μέχρι να επιλυθεί το ζήτημα #7857, η επιτυχημένη επικύρωση **δεν εγγυάται** ότι ο πάροχος θα πραγματοποιήσει επιτυχώς έλεγχο ταυτότητας.

Εάν ο έλεγχος ταυτότητας εξακολουθεί να αποτυγχάνει, επαληθεύστε ότι αντιγράψατε τα διαπιστευτήρια από ένα ενεργό αίτημα δικτύου και όχι από τον χώρο αποθήκευσης cookie του προγράμματος περιήγησης.

---

# Αντιμετώπιση προβλημάτων

## Ο έλεγχος ταυτότητας αποτυγχάνει

Επαληθεύστε ότι τα διαπιστευτήρια αντιγράφηκαν από:

```
Network
→ Request Headers
→ Cookie
```

και **όχι** από:

```
Application
→ Cookies
```

---

## Το cookie λειτουργεί στο πρόγραμμα περιήγησης αλλά όχι στο OmniRoute

Ορισμένοι πάροχοι περιλαμβάνουν cookie που αποστέλλονται μόνο κατά τη διάρκεια πιστοποιημένων αιτημάτων.

Αντιγράψτε ξανά τα διαπιστευτήρια από ένα νέο αίτημα δικτύου, αφού πρώτα ανοίξετε επιτυχώς μια συνομιλία.

---

## Η περίοδος σύνδεσης έληξε

Οι πάροχοι Web Cookie χρησιμοποιούν την υπάρχουσα περίοδο σύνδεσης του προγράμματος περιήγησής σας.

Εάν η περίοδος σύνδεσης του προγράμματος περιήγησης λήξει ή αποσυνδεθείτε, πρέπει να αντιγράψετε ένα νέο σύνολο διαπιστευτηρίων.

---

## Η δοκιμή σύνδεσης είναι επιτυχής αλλά τα αιτήματα αποτυγχάνουν

Μέχρι να επιλυθεί το ζήτημα #7857, η επιτυχής επικύρωση δεν εγγυάται ότι το αίτημα ελέγχου ταυτότητας θα ολοκληρωθεί επιτυχώς.

Αντιγράψτε ξανά τα διαπιστευτήριά σας από ένα νέο πιστοποιημένο αίτημα πριν συνεχίσετε την αντιμετώπιση προβλημάτων.

---

# Παράδειγμα παρόχου

Για μια πλήρη διαδικασία ρύθμισης ειδικά για έναν πάροχο, ανατρέξτε στο εξής:

- **Claude Web** — `docs/providers/CLAUDE_WEB.md`

Ο οδηγός Claude Web παρουσιάζει την πλήρη διαδικασία ρύθμισης για έναν πάροχο Web Cookie και λειτουργεί ως υλοποίηση αναφοράς.

---

# Βέλτιστες πρακτικές

- Αντιγράφετε τα διαπιστευτήρια από ένα νέο πιστοποιημένο αίτημα.
- Αποφεύγετε την επαναχρησιμοποίηση παλιών cookie.
- Διατηρείτε ενεργή την περίοδο σύνδεσης του προγράμματος περιήγησής σας ενώ χρησιμοποιείτε παρόχους Web Cookie.
- Αντιμετωπίζετε τα αντιγραμμένα cookie ως ευαίσθητα διαπιστευτήρια.
- Χρησιμοποιείτε παρόχους με κλειδί API όταν χρειάζεστε κλήση συναρτήσεων ή ροές εργασίας με πράκτορες.
