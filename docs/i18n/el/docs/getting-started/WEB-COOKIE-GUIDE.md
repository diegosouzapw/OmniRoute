Οι πάροχοι Web Cookie επιτρέπουν στο OmniRoute να χρησιμοποιεί μια υπηρεσία AI μέσω της υπάρχουσας περιόδου σύνδεσης του προγράμματος περιήγησής σας αντί για ένα κλειδί API. Είναι χρήσιμοι όταν έχετε ήδη πρόσβαση σε μια υπηρεσία μέσω του ιστοτόπου της και θέλετε το OmniRoute να χρησιμοποιεί την ίδια πιστοποιημένη περίοδο σύνδεσης.

Σε αντίθεση με τους παρόχους που χρησιμοποιούν κλειδί API, οι πάροχοι Web Cookie πραγματοποιούν έλεγχο ταυτότητας χρησιμοποιώντας τα διαπιστευτήρια που στέλνει το πρόγραμμα περιήγησής σας στον ιστότοπο.

---

# Πριν ξεκινήσετε

> **Σημαντικό:** Αντιγράφετε πάντα τα διαπιστευτήρια από ένα **ενεργό αίτημα δικτύου** και **όχι** από τον χώρο αποθήκευσης cookie του προγράμματος περιήγησής σας.

Πολλά προβλήματα ελέγχου ταυτότητας προκαλούνται από την αντιγραφή cookie από λάθος σημείο.

## ΜΗΝ αντιγράφετε από τον χώρο αποθήκευσης cookie

Τα περισσότερα προγράμματα περιήγησης εμφανίζουν τα αποθηκευμένα cookie μέσω της διαδρομής:

```
DevTools
→ Application (ή Storage)
→ Cookies
```

Παρόλο που αυτά τα cookie φαίνονται σωστά, ενδέχεται να είναι:

- παρωχημένα
- ελλιπή
- χωρίς cookie που αποστέλλονται μόνο σε πιστοποιημένα αιτήματα

Η χρήση αυτών των τιμών ενδέχεται να προκαλέσει αποτυχίες ελέγχου ταυτότητας, ακόμη και αν φαίνονται έγκυρες.

## Αντιγραφή από ενεργό αίτημα

Αντί γι' αυτό, χρησιμοποιήστε τα cookie από ένα επιτυχημένο αίτημα:

```
DevTools
→ Network
→ Ανανεώστε τη σελίδα
→ Ανοίξτε ένα αίτημα συνομιλίας
→ Request Headers
→ Cookie
```

Η κεφαλίδα αιτήματος `Cookie` περιέχει τις ακριβείς πληροφορίες ελέγχου ταυτότητας που χρησιμοποίησε επιτυχώς το πρόγραμμα περιήγησής σας.

Για τους περισσότερους παρόχους Web Cookie, αυτή είναι η τιμή που πρέπει να επικολληθεί στο OmniRoute.

# Γενική ρύθμιση

Η διαδικασία ρύθμισης είναι ίδια για τους περισσότερους παρόχους Web Cookie.

1. Συνδεθείτε στον ιστότοπο του παρόχου.
2. Ανοίξτε τα Εργαλεία προγραμματιστή του προγράμματος περιήγησης.
3. Ανοίξτε την καρτέλα **Network**.
4. Ανανεώστε τη σελίδα.
5. Ανοίξτε ένα πιστοποιημένο αίτημα συνομιλίας.
6. Αντιγράψτε τα απαιτούμενα διαπιστευτήρια ελέγχου ταυτότητας.
7. Ανοίξτε το OmniRoute.
8. Μεταβείτε στην επιλογή **Providers → Add Provider**.
9. Επιλέξτε τον πάροχο Web Cookie.
10. Επικολλήστε τα διαπιστευτήρια.
11. Κάντε κλικ στην επιλογή **Test Connection**.
12. Αποθηκεύστε τον πάροχο.

Τα ακριβή διαπιστευτήρια που απαιτούνται εξαρτώνται από τον πάροχο.

## NoTrack (notrack-web)

Το NoTrack ([notrack.ai](https://notrack.ai)) είναι μια δωρεάν πλατφόρμα συνομιλίας για καταναλωτές, χωρίς να απαιτείται εγγραφή — η συνεδρία δημιουργείται ανώνυμα κατά την πρώτη επίσκεψη και διατηρείται μέσω τριών cookies: `uid`, `si_usr_id` και `si_ses_id`. Το OmniRoute προωθεί μέσω διακομιστή μεσολάβησης το ίδιο τελικό σημείο `/api/dispatch`, χρησιμοποιώντας ένα μοναδικό αναγνωριστικό μοντέλου (`notrack-c`, ψευδώνυμο `ntw`).

### Βήματα σύνδεσης

1. Ανοίξτε το [notrack.ai](https://notrack.ai) στο πρόγραμμα περιήγησής σας και αφήστε να οριστεί το cookie της ανώνυμης συνεδρίας.
2. Ανοίξτε τα **Εργαλεία προγραμματιστή → Δίκτυο**, ανανεώστε τη σελίδα και κάντε κλικ σε οποιοδήποτε αίτημα `/api`.
3. Στις **Κεφαλίδες αιτήματος**, αντιγράψτε ολόκληρη την τιμή της κεφαλίδας `Cookie`.
4. Στο OmniRoute, μεταβείτε στην ενότητα **Πάροχοι → Προσθήκη παρόχου → NoTrack Web (Δωρεάν)**.
5. Επικολλήστε τη συμβολοσειρά του cookie στο πεδίο `apiKey` και επιλέξτε **Αποθήκευση**.

Το OmniRoute εξάγει τα `uid`, `si_usr_id` και `si_ses_id` από τη συμβολοσειρά που επικολλήθηκε και δημιουργεί εκ νέου μια καθαρή κεφαλίδα `Cookie` μόνο με αυτά τα ζεύγη — καθώς και το `nt_session` (το διακριτικό `ntk_…` που ορίζεται για συνδεδεμένους λογαριασμούς), όταν υπάρχει. Αν λείπει οποιοδήποτε από τα τρία, η ακατέργαστη συμβολοσειρά που επικολλήθηκε προωθείται χωρίς αλλαγές, ώστε οι διαχειριστές να μπορούν να πειραματιστούν με εναλλακτικές μορφές.

### Αναγνωριστικά μοντέλων

| Αναγνωριστικό μοντέλου | Εμφανιζόμενο όνομα | Σημειώσεις                                                             |
| ---------------------- | ------------------ | ---------------------------------------------------------------------- |
| `notrack-c`            | NoTrack C          | Προεπιλογή — το μοντέλο διεκπεραίωσης ανάντη `C`.                      |
| `C`                    | NoTrack C          | Ψευδώνυμο του `notrack-c` (ακατέργαστος κωδικός διεκπεραίωσης ανάντη). |
| `notrack`              | NoTrack C          | Ψευδώνυμο του `notrack-c`.                                             |
| `ntw`                  | NoTrack C          | Σύντομο ψευδώνυμο του `notrack-c`.                                     |

Και τα τέσσερα αναγνωριστικά μοντέλων αντιστοιχούν στο ίδιο μοντέλο διεκπεραίωσης ανάντη (`C`).

### Επιλογές αιτήματος

Ο εκτελεστής δέχεται τα ακόλουθα προαιρετικά πεδία στο σώμα του αιτήματος:

| Πεδίο σώματος         | Προεπιλογή | Σκοπός                                                                                         |
| --------------------- | ---------- | ---------------------------------------------------------------------------------------------- |
| `notrack_mode`        | `usual`    | Λειτουργία διεκπεραίωσης (συμβολοσειρά ελεύθερης μορφής· η υπηρεσία ανάντη δέχεται `usual`, …) |
| `notrack_max_turns`   | `6`        | Αριθμός εσωτερικών γύρων που μπορεί να εκτελέσει η υπηρεσία ανάντη πριν απαντήσει.             |
| `notrack_chat_id`     | `null`     | Συνέχιση μιας υπάρχουσας συνομιλίας ανάντη (παραλείψτε το για νέα συνομιλία).                  |
| `notrack_attachments` | `[]`       | Πίνακας περιγραφέων συνημμένων ανάντη που μεταβιβάζεται αυτούσιος.                             |
| `notrack_regenerate`  | `false`    | Ορίστε το σε `true` για να ζητήσετε μια αναδημιουργημένη απάντηση για τον προηγούμενο γύρο.    |

### Δυνατότητες

- **Ροή και μη ροή** ολοκληρώσεων συνομιλίας.
- **Κλήση εργαλείων** — ορίστε `tools: [...]` στο αίτημα· ο εκτελεστής τα σειριοποιεί σε μια σύμβαση φακέλου κλήσης εργαλείων και αναλύει τις απαντήσεις του μοντέλου ξανά σε `tool_calls` του OpenAI.
- **`response_format`** — υποστηρίζονται τα `json_object` και `json_schema`. Ο εκτελεστής εξάγει το πρώτο αντικείμενο JSON από την απάντηση του μοντέλου και το μετατρέπει σε συμβολοσειρά πριν το επιστρέψει.
- **Ένδειξη συλλογισμού** — ο εκτελεστής εκπέμπει μια διαφορά `reasoning` όταν η υπηρεσία ανάντη στέλνει ένα συμβάν `thinking`.

### Περιορισμοί

- Η υπηρεσία ανάντη επιβάλλει ποσοστώσεις ανώνυμης χρήσης — όταν γίνεται υπέρβασή τους, ο εκτελεστής εμφανίζει ένα σφάλμα 429 με ένα φιλικό μήνυμα.
- Όλα τα αναγνωριστικά μοντέλων επιλύονται στο ίδιο μοντέλο διεκπεραίωσης ανάντη· δεν υπάρχει δυνατότητα εναλλαγής ανά μοντέλο.
- Ο εκτελεστής δεν καλεί το τελικό σημείο `/api/chats` της υπηρεσίας ανάντη, επομένως το ιστορικό συνομιλιών / οι συνεδρίες δεν διαχειρίζονται αυτόματα. Χρησιμοποιήστε το `notrack_chat_id` για να συνεχίσετε μια υπάρχουσα συνομιλία ανάντη.

# Τι μπορούν και τι δεν μπορούν να κάνουν οι πάροχοι Web Cookie

Οι πάροχοι Web Cookie επαναχρησιμοποιούν τη διεπαφή συνομιλίας ενός ιστοτόπου. **Δεν** παρέχουν τις ίδιες δυνατότητες με τα επίσημα API.

## Υποστηρίζεται

- Έλεγχος ταυτότητας με χρήση της υπάρχουσας συνεδρίας του προγράμματος περιήγησής σας
- Πρόσβαση στα μοντέλα που είναι διαθέσιμα μέσω του λογαριασμού σας
- Ροή απαντήσεων συνομιλίας
- Δεν απαιτείται κλειδί API

## Δεν υποστηρίζεται

- Κλήση συναρτήσεων
- Κλήση εργαλείων
- Αυτόματη επεξεργασία αρχείων
- Ροές εργασίας IDE με πράκτορες
- Λειτουργίες διαθέσιμες μόνο μέσω API

Αυτή είναι αναμενόμενη συμπεριφορά και **δεν** αποτελεί σφάλμα.

Εάν χρειάζεστε εκτέλεση εργαλείων, αυτόματη επεξεργασία αρχείων ή άλλες ροές εργασίας με πράκτορες, χρησιμοποιήστε έναν **πάροχο με κλειδί API** αντί για έναν πάροχο Web Cookie.

# Επιφύλαξη σχετικά με την επικύρωση

Μια επιτυχής **Δοκιμή σύνδεσης** ή επικύρωση cookie επαληθεύει μόνο ότι τα παρεχόμενα διαπιστευτήρια φαίνεται να έχουν την αναμενόμενη μορφή.

Μέχρι να επιλυθεί το Issue #7857, μια επιτυχής επικύρωση **δεν εγγυάται** ότι ο πάροχος θα ολοκληρώσει επιτυχώς τον έλεγχο ταυτότητας.

Εάν ο έλεγχος ταυτότητας εξακολουθεί να αποτυγχάνει, βεβαιωθείτε ότι αντιγράψατε τα διαπιστευτήρια από ένα ενεργό αίτημα δικτύου και όχι από τον χώρο αποθήκευσης cookie του προγράμματος περιήγησης.

---

# Αντιμετώπιση προβλημάτων

## Ο έλεγχος ταυτότητας αποτυγχάνει

Βεβαιωθείτε ότι τα διαπιστευτήρια αντιγράφηκαν από:

```
Δίκτυο
→ Κεφαλίδες αιτήματος
→ Cookie
```

και **όχι** από:

```
Εφαρμογή
→ Cookies
```

---

## Το cookie λειτουργεί στο πρόγραμμα περιήγησης αλλά όχι στο OmniRoute

Ορισμένοι πάροχοι περιλαμβάνουν cookie που αποστέλλονται μόνο κατά τη διάρκεια αιτημάτων με έλεγχο ταυτότητας.

Αντιγράψτε ξανά τα διαπιστευτήρια από ένα νέο αίτημα δικτύου αφού ανοίξετε επιτυχώς μια συνομιλία.

---

## Η συνεδρία έληξε

Οι πάροχοι Web Cookie χρησιμοποιούν την υπάρχουσα συνεδρία του προγράμματος περιήγησής σας.

Εάν λήξει η συνεδρία του προγράμματος περιήγησής σας ή αποσυνδεθείτε, πρέπει να αντιγράψετε ένα νέο σύνολο διαπιστευτηρίων. Για να αυτοματοποιήσετε την ανανέωση cookie για υποστηριζόμενους παρόχους ιστού, ανατρέξτε στο συνοδευτικό εργαλείο [Επέκταση συγχρονισμού συνεδρίας προγράμματος περιήγησης](../guides/SESSION-SYNC-EXTENSION.md).

---

## Η δοκιμή σύνδεσης ολοκληρώνεται επιτυχώς αλλά τα αιτήματα αποτυγχάνουν

Μέχρι να επιλυθεί το Issue #7857, η επιτυχής επικύρωση δεν εγγυάται ότι το αίτημα ελέγχου ταυτότητας θα ολοκληρωθεί επιτυχώς.

Αντιγράψτε ξανά τα διαπιστευτήριά σας από ένα νέο αίτημα με έλεγχο ταυτότητας πριν προχωρήσετε σε περαιτέρω αντιμετώπιση προβλημάτων.

# Βέλτιστες πρακτικές

- Αντιγράφετε τα διαπιστευτήρια από ένα νέο αίτημα με έλεγχο ταυτότητας.
- Αποφεύγετε την επαναχρησιμοποίηση παλιών cookie.
- Διατηρείτε ενεργή τη συνεδρία του προγράμματος περιήγησής σας κατά τη χρήση παρόχων Web Cookie.
- Αντιμετωπίζετε τα αντιγραμμένα cookie ως ευαίσθητα διαπιστευτήρια.
- Χρησιμοποιείτε παρόχους με κλειδί API όταν χρειάζεστε κλήση συναρτήσεων ή ροές εργασίας με πράκτορες.
