> **Συνοπτικά**: Ένας πάροχος είναι μια σύνδεση με μια υπηρεσία ΤΝ (όπως OpenAI, Anthropic, Google). Χρειάζεστε τουλάχιστον έναν πάροχο για να χρησιμοποιήσετε το OmniRoute.

---

## Τι είναι ένας πάροχος;

Σκεφτείτε έναν πάροχο σαν μια **εταιρεία κινητής τηλεφωνίας**. Όπως χρειάζεστε μια εταιρεία κινητής τηλεφωνίας για να πραγματοποιείτε κλήσεις, έτσι χρειάζεστε έναν πάροχο ΤΝ για να χρησιμοποιείτε μοντέλα ΤΝ. Το OmniRoute είναι σαν ένα τηλέφωνο που λειτουργεί με **όλους τους παρόχους** — μπορείτε να εναλλάσσεστε αυτόματα μεταξύ τους.

### Τύποι παρόχων

| Τύπος            | Τι είναι                                                 | Παραδείγματα                      | Κόστος                               |
| ---------------- | -------------------------------------------------------- | --------------------------------- | ------------------------------------ |
| **Δωρεάν**       | Δεν απαιτείται πληρωμή                                   | Kiro, OpenCode Free, Pollinations | $0                                   |
| **Κλειδί API**   | Χρειάζεστε ένα κλειδί API                                | OpenAI, Anthropic, Google         | Χρέωση ανά χρήση                     |
| **OAuth**        | Σύνδεση με τον λογαριασμό σας                            | Claude Code, GitHub Copilot       | Συνδρομή                             |
| **Cookie ιστού** | Χρησιμοποιεί τη συνεδρία του προγράμματος περιήγησής σας | ChatGPT Web (Codex), Gemini Web   | $0 (χρησιμοποιεί τον λογαριασμό σας) |

### Πάροχοι με cookie ιστού

Ανατρέξτε στο **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** για γενικές οδηγίες ρύθμισης, περιορισμούς, αντιμετώπιση προβλημάτων και καθοδήγηση ελέγχου ταυτότητας ειδικά για κάθε πάροχο.

## Γρήγορη εκκίνηση: Συνδέστε τον πρώτο σας πάροχο

### Προαιρετική ρύθμιση δωρεάν παρόχων κατά την πρώτη εκτέλεση

Ο οδηγός πρώτης εκτέλεσης προσφέρει μια ξεχωριστή κάρτα **Ρύθμιση δωρεάν παρόχων**. Αντλεί την τρέχουσα
λίστα των επιλέξιμων παρόχων από το μητρώο παρόχων χωρίς έλεγχο ταυτότητας του OmniRoute και, στη συνέχεια, σας επιτρέπει να εξετάσετε και να αποεπιλέξετε κάθε
πάροχο πριν από την επιβεβαίωση. Το OmniRoute εμφανίζει την προειδοποιητική ειδοποίηση του παρόχου και έναν σύνδεσμο προς τον ιστότοπό του,
ώστε να μπορείτε πρώτα να εξετάσετε τους όρους τρίτων, το απόρρητο, τη διαθεσιμότητα και τα όρια ρυθμού χρήσης.

Αυτή η ενέργεια είναι προαιρετική: η ολοκλήρωση του οδηγού δεν δημιουργεί ποτέ σιωπηρά συνδέσεις με δωρεάν παρόχους.
Δημιουργεί μόνο παρόχους που εξακολουθούν να λείπουν, αφήνει ανέπαφες τις υπάρχουσες προσαρμοσμένες συνδέσεις
και αναφέρει ξεχωριστά τους παρόχους που δημιουργήθηκαν, που είχαν ήδη ρυθμιστεί και που απέτυχαν. Μπορείτε
να επαναλάβετε με ασφάλεια μόνο τις αποτυχημένες προσπάθειες μετά από ένα μερικό αποτέλεσμα.

### Επιλογή A: Δωρεάν πάροχος (χωρίς πιστωτική κάρτα)

1. Ανοίξτε τον πίνακα ελέγχου στη διεύθυνση `http://localhost:20128`
2. Μεταβείτε στην ενότητα **Πάροχοι** → **Προσθήκη παρόχου**
3. Επιλέξτε έναν από αυτούς τους δωρεάν παρόχους:
   - **Kiro AI** — Δωρεάν μοντέλα Claude (δεν απαιτείται έλεγχος ταυτότητας)
   - **OpenCode Free** — Δωρεάν μοντέλα GPT (δεν απαιτείται έλεγχος ταυτότητας)
   - **Pollinations** — Δωρεάν GPT-5, Claude, Gemini (δεν απαιτείται κλειδί)
   - **LongCat** — 10 εκατ. δωρεάν token (εφάπαξ παροχή, απαιτεί λογαριασμό + KYC)
   - **Cloudflare AI** — 50+ μοντέλα, 10 χιλ. νευρώνες/ημέρα
   - **MLX Gemma 26B** — Τοπικό μοντέλο Apple Silicon (~38.5 token/δευτ., ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — Τοπικό μοντέλο Apple Silicon (~9.1 token/δευτ., ~13.1GB RAM)
4. Κάντε κλικ στο **Σύνδεση**
5. Έτοιμο! Τώρα έχετε δωρεάν πρόσβαση σε ΤΝ.

### Επιλογή B: Πάροχος με κλειδί API (επί πληρωμή)

1. Αποκτήστε ένα κλειδί API από τον ιστότοπο του παρόχου:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Ανοίξτε τον πίνακα ελέγχου στη διεύθυνση `http://localhost:20128`
3. Μεταβείτε στην ενότητα **Πάροχοι** → **Προσθήκη παρόχου**
4. Επιλέξτε τον πάροχό σας
5. Επικολλήστε το κλειδί API σας
6. Κάντε κλικ στο **Σύνδεση**
7. Έτοιμο! Τώρα έχετε πρόσβαση στα μοντέλα αυτού του παρόχου.

### Επιλογή C: Πάροχος OAuth (συνδρομή)

1. Ανοίξτε τον πίνακα ελέγχου στη διεύθυνση `http://localhost:20128`
2. Μεταβείτε στην ενότητα **Πάροχοι** → **Προσθήκη παρόχου**
3. Επιλέξτε τον πάροχό σας (π.χ. Claude Code, GitHub Copilot)
4. Κάντε κλικ στο **Σύνδεση με OAuth**
5. Συνδεθείτε με τον λογαριασμό σας
6. Έτοιμο! Τώρα έχετε πρόσβαση στα μοντέλα της συνδρομής σας.

### Επιλογή D: Τοπικά μοντέλα MLX (Apple Silicon)

Για Mac με Apple Silicon και ενοποιημένη μνήμη, το OmniRoute υποστηρίζει τη σύνδεση με τοπικά μοντέλα MLX που εκτελούνται μέσω του `mlx-lm.server` ως κανονικοί τοπικοί πάροχοι συμβατοί με το OpenAI.

#### Προαπαιτούμενα

- **Mac με Apple Silicon** (M1/M2/M3/M4) με συνιστώμενη ενοποιημένη μνήμη 24GB+
- Διαχειριστής πακέτων **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Γρήγορη εκκίνηση

1. **Εγκαταστήστε τις εξαρτήσεις**:

   ```bash
   # Εγκαταστήστε το uv, εάν δεν είναι ήδη εγκατεστημένο
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Εγκαταστήστε το mlx-lm
   uv pip install mlx-lm
   ```

2. **Εκκινήστε χειροκίνητα τους διακομιστές MLX** (σε ξεχωριστά τερματικά):

   ```bash
   # Τερματικό 1: Gemma 4 26B A4B IT-QAT (θύρα 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Τερματικό 2: Qwen 3.8 27B MLX Mixed (θύρα 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Συνδεθείτε στον πίνακα ελέγχου του OmniRoute**:
   - Μεταβείτε στην ενότητα **Πάροχοι** → **Προσθήκη παρόχου**
   - Επιλέξτε **MLX Gemma 26B** ή **MLX Qwen 3.8 27B**
   - Κάντε κλικ στο **Σύνδεση** (δεν απαιτείται κλειδί API)

4. **Χρήση με το OpenCode**:
   ```bash
   # Ρυθμίστε το OpenCode ώστε να χρησιμοποιεί το OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Χρησιμοποιήστε μοντέλα MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Διαχείριση μνήμης

**Σημαντικό**: Με 24GB ενοποιημένης μνήμης, μπορεί να εκτελείται μόνο **ένα μεγάλο μοντέλο MLX κάθε φορά**.

- Gemma 26B: ~15.9GB μέγιστη χρήση μνήμης
- Qwen 3.8 27B: ~13.1GB μέγιστη χρήση μνήμης

Πρέπει να το διαχειρίζεστε χειροκίνητα:

- Εκτελείτε μόνο έναν διακομιστή MLX κάθε φορά ή
- Εκτελείτε τους δύο σε ξεχωριστά μηχανήματα ή
- Διακόπτετε τον έναν πριν εκκινήσετε τον άλλο

Το OmniRoute δεν διαχειρίζεται αυτόματα τις διεργασίες των διακομιστών MLX — δρομολογεί μόνο αιτήματα προς τα συμβατά με το OpenAI τελικά σημεία που ρυθμίζετε.

#### Υποστήριξη κλήσης εργαλείων

Και τα δύο μοντέλα υποστηρίζουν κλήσεις εργαλείων συμβατές με το OpenAI. Δοκιμάστε με:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "Πόσο κάνει 2+2; Χρησιμοποίησε το εργαλείο αριθμομηχανής."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Υπολογισμός", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Αντιμετώπιση προβλημάτων

| Πρόβλημα                      | Λύση                                                                                                                |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Ο διακομιστής δεν εκκινείται  | Ελέγξτε το `uv run mlx_lm.server --help` και επαληθεύστε τα αναγνωριστικά μοντέλων                                  |
| Ανεπαρκής μνήμη               | Βεβαιωθείτε ότι εκτελείται μόνο ένα μοντέλο, κλείστε άλλες εφαρμογές και ελέγξτε το Activity Monitor                |
| Απόρριψη σύνδεσης             | Επαληθεύστε ότι ο διακομιστής εκτελείται στη σωστή θύρα (11435/11436)                                               |
| Αργές αποκρίσεις              | Το πρώτο αίτημα φορτώνει το μοντέλο στη μνήμη (~30-60s)· τα επόμενα αιτήματα είναι γρήγορα                          |
| Η κλήση εργαλείων αποτυγχάνει | Βεβαιωθείτε ότι το μοντέλο υποστηρίζει εργαλεία· ελέγξτε τα αρχεία καταγραφής του OmniRoute για σφάλματα μετάφρασης |

## Πώς να συνδέσετε έναν πάροχο (βήμα προς βήμα)

### Βήμα 1: Ανοίξτε τον πίνακα ελέγχου

Μεταβείτε στη διεύθυνση `http://localhost:20128` στο πρόγραμμα περιήγησής σας.

### Βήμα 2: Μεταβείτε στους παρόχους

Κάντε κλικ στην επιλογή **Πάροχοι** στην πλαϊνή γραμμή.

### Βήμα 3: Κάντε κλικ στην προσθήκη παρόχου

Κάντε κλικ στο κουμπί **+ Προσθήκη παρόχου**.

### Βήμα 4: Επιλέξτε τον πάροχό σας

Περιηγηθείτε στη λίστα ή αναζητήστε τον πάροχό σας. Κάντε κλικ επάνω του.

### Βήμα 5: Εισαγάγετε τα διαπιστευτήρια

- **Δωρεάν πάροχοι**: Δεν απαιτούνται διαπιστευτήρια — απλώς κάντε κλικ στην επιλογή **Σύνδεση**
- **Πάροχοι με κλειδί API**: Επικολλήστε το κλειδί API σας
- **Πάροχοι OAuth**: Κάντε κλικ στην επιλογή **Σύνδεση με OAuth** και συνδεθείτε

### Βήμα 6: Δοκιμάστε τη σύνδεση

Κάντε κλικ στην επιλογή **Δοκιμή σύνδεσης** για να επαληθεύσετε ότι λειτουργεί.

### Βήμα 7: Έτοιμο!

Ο πάροχός σας είναι πλέον συνδεδεμένος. Μπορείτε να τον χρησιμοποιήσετε με `model: "auto"` ή να καθορίσετε απευθείας τον πάροχο.

## Χρήση πολλών παρόχων

Το OmniRoute λειτουργεί καλύτερα με **πολλούς παρόχους**. Αυτό σας προσφέρει:

- **Αυτόματη εναλλαγή σε εφεδρικό πάροχο** — Αν ένας πάροχος αποτύχει, το OmniRoute δοκιμάζει τον επόμενο
- **Βελτιστοποίηση κόστους** — Το OmniRoute επιλέγει τον οικονομικότερο πάροχο για κάθε αίτημα
- **Βελτιστοποίηση ταχύτητας** — Το OmniRoute επιλέγει τον ταχύτερο πάροχο για κάθε αίτημα
- **Βελτιστοποίηση ποιότητας** — Το OmniRoute επιλέγει τον καλύτερο πάροχο για κάθε εργασία

### Προτεινόμενη διαμόρφωση

Συνδέστε τουλάχιστον **3 παρόχους** για την καλύτερη δυνατή εμπειρία:

1. **Έναν δωρεάν πάροχο** (Kiro, OpenCode Free ή Pollinations) — Πάντα διαθέσιμος
2. **Έναν γρήγορο πάροχο** (Groq, Cerebras) — Για γρήγορες απαντήσεις
3. **Έναν πάροχο υψηλής ποιότητας** (OpenAI, Anthropic, Google) — Για σύνθετες εργασίες

Στη συνέχεια, χρησιμοποιήστε `model: "auto"` και το OmniRoute θα επιλέγει αυτόματα τον καλύτερο πάροχο για κάθε αίτημα.

## Συνήθεις ερωτήσεις

### "Χρειάζεται να πληρώσω για να χρησιμοποιήσω το OmniRoute;"

**Όχι!** Το OmniRoute είναι δωρεάν και ανοικτού κώδικα. Μπορείτε να χρησιμοποιείτε δωρεάν παρόχους (Kiro, OpenCode Free, Pollinations) χωρίς καμία χρέωση. Πληρώνετε μόνο αν επιλέξετε να χρησιμοποιήσετε παρόχους επί πληρωμή.

### "Με ποιον πάροχο θα πρέπει να ξεκινήσω;"

Ξεκινήστε με το **Kiro AI** — είναι δωρεάν, δεν απαιτεί κλειδί API και σας παρέχει πρόσβαση στα μοντέλα Claude. Στη συνέχεια, προσθέστε περισσότερους παρόχους ανάλογα με τις ανάγκες σας.

### "Μπορώ να χρησιμοποιώ πολλούς παρόχους ταυτόχρονα;"

**Ναι!** Αυτός είναι ο βασικός σκοπός του OmniRoute. Συνδέστε πολλούς παρόχους και χρησιμοποιήστε το `model: "auto"` ώστε το OmniRoute να επιλέγει τον καλύτερο για κάθε αίτημα.

### "Τι γίνεται αν ένας πάροχος τεθεί εκτός λειτουργίας;"

Το OmniRoute παρακάμπτει αυτόματα τους παρόχους που αποτυγχάνουν και δοκιμάζει τον επόμενο. Δεν χρειάζεται να κάνετε τίποτα.

### "Πώς αποσυνδέω έναν πάροχο;"

Μεταβείτε στους Παρόχους → κάντε κλικ στον πάροχο → κάντε κλικ στην επιλογή **Αποσύνδεση**.

### "Μπορώ να χρησιμοποιήσω τα υπάρχοντα κλειδιά API μου;"

**Ναι!** Αν διαθέτετε ήδη κλειδιά API για OpenAI, Anthropic, Google κ.λπ., μπορείτε να τα χρησιμοποιήσετε στο OmniRoute. Απλώς επικολλήστε τα όταν συνδέετε τον πάροχο.
