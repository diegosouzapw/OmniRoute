## Βήμα 1: Εγκατάσταση του OmniRoute

Επιλέξτε τη μέθοδο που προτιμάτε:

### Επιλογή A: npm (Συνιστάται)

```bash
npm install -g omniroute
```

### Επιλογή B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

Το `:latest` είναι η υψηλότερη **δημοσιευμένη** σταθερή έκδοση SemVer. **Δεν** ακολουθεί το git `main`. Καρφιτσώστε την έκδοση ως `diegosouzapw/omniroute:X.Y.Z` για GitOps. Δείτε την ενότητα [Ετικέτες εικόνων / Κανάλια εκδόσεων](../guides/DOCKER_GUIDE.md#release-channels).

### Επιλογή C: Από τον πηγαίο κώδικα

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Βήμα 2: Εκκίνηση του OmniRoute

```bash
omniroute
```

Το OmniRoute ξεκινά στη διεύθυνση `http://localhost:20128`. Ο πίνακας ελέγχου ανοίγει αυτόματα.

---

## Βήμα 3: Σύνδεση δωρεάν παρόχου

Μπορείτε να χρησιμοποιήσετε το OmniRoute **χωρίς να πληρώσετε τίποτα**, συνδέοντας έναν δωρεάν πάροχο.

### Επιλογή A: Kiro (Δωρεάν Claude — Χωρίς πιστωτική κάρτα)

1. Ανοίξτε τον πίνακα ελέγχου στη διεύθυνση `http://localhost:20128`
2. Μεταβείτε στο **Πάροχοι** → **Προσθήκη παρόχου**
3. Επιλέξτε **Kiro AI**
4. Κάντε κλικ στο **Σύνδεση** (δεν απαιτείται κλειδί API!)
5. Έτοιμο! Έχετε πλέον δωρεάν πρόσβαση στα μοντέλα Claude.

### Επιλογή B: OpenCode Free (Χωρίς έλεγχο ταυτότητας)

1. Ανοίξτε τον πίνακα ελέγχου στη διεύθυνση `http://localhost:20128`
2. Μεταβείτε στο **Πάροχοι** → **Προσθήκη παρόχου**
3. Επιλέξτε **OpenCode Free**
4. Κάντε κλικ στο **Σύνδεση** (δεν απαιτείται κλειδί API!)
5. Έτοιμο! Έχετε πλέον δωρεάν πρόσβαση σε πολλά μοντέλα.

### Επιλογή C: Pollinations (Δεν απαιτείται κλειδί)

1. Ανοίξτε τον πίνακα ελέγχου στη διεύθυνση `http://localhost:20128`
2. Μεταβείτε στο **Πάροχοι** → **Προσθήκη παρόχου**
3. Επιλέξτε **Pollinations**
4. Κάντε κλικ στο **Σύνδεση** (δεν απαιτείται κλειδί API!)
5. Έτοιμο! Έχετε πλέον δωρεάν πρόσβαση στα GPT-5, Claude, Gemini και άλλα.

## Βήμα 4: Επαλήθευση λειτουργίας

Από τη σελίδα [Κλειδιά API](http://localhost:20128/dashboard/api-manager), δημιουργήστε ένα νέο κλειδί. Αποθηκεύστε αυτό το κλειδί, καθώς δεν θα εμφανιστεί ξανά. Λάβετε υπόψη ότι αυτό το κλειδί προορίζεται για την πρόσβαση εργαλείων στο OmniRoute και όχι για την πρόσβαση σε εξωτερικούς παρόχους.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Θα πρέπει να δείτε τα συνδεδεμένα μοντέλα σας στη λίστα.

## Βήμα 5: Ρύθμιση του IDE ή του CLI σας ώστε να χρησιμοποιεί το OmniRoute

Στο εργαλείο IDE ή CLI σας, ορίστε:

```
Βασικό URL: http://localhost:20128/v1
Κλειδί API: [αντιγράψτε από τον Πίνακα ελέγχου → Τελικά σημεία]
Μοντέλο:    auto
```

Αυτό ήταν! Το IDE σας χρησιμοποιεί πλέον το OmniRoute με αυτόματη επιλογή παρόχου.

### Παράδειγμα IDE: VSCode/Continue.dev

1. Στο VSCode, εγκαταστήστε την επέκταση [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Ενημερώστε το `~/.continue/config.yaml` προσθέτοντας τις ακόλουθες γραμμές:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Στο παράθυρο συνομιλίας του Continue.dev, επιλέξτε `OmniRoute - Auto` και θα στέλνετε αιτήματα στο OmniRoute.
4. (Προαιρετικό) Άσκηση για τον αναγνώστη — ζητήστε από το IDE σας να ενημερώσει το `config.yaml` με όλες τις άλλες προκατασκευασμένες ρυθμίσεις 😊

### Παράδειγμα CLI: Codex CLI

1. Στο λειτουργικό σας σύστημα, ορίστε μόνιμα τη μεταβλητή περιβάλλοντος.
   Για macOS/Linux (προσθέστε τη στο `~/.bashrc` ή στο `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Για Windows (Γραμμή εντολών):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Τώρα ας εκκινήσουμε το Codex, αλλά ρυθμισμένο για το OmniRoute. Εκτελέστε:

```
omniroute launch-codex --model auto
```

Μπορείτε να το κάνετε χειροκίνητα μέσω του `codex` και παραμέτρων γραμμής εντολών για να καθορίσετε το τελικό σημείο και το κλειδί API, αλλά με την παραπάνω εντολή το OmniRoute αναλαμβάνει τα πάντα για εσάς.

Η ίδια εκκίνηση με μία εντολή λειτουργεί και για άλλα CLI μέσω του γενικού προγράμματος εκκίνησης — το `omniroute run <target>` υποστηρίζει τα `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` και `gemini` (δείτε τις [Ενσωματώσεις CLI](../guides/CLI-INTEGRATIONS.md)).

3. Το CLI θα πρέπει πλέον να στέλνει αιτήματα στο OmniRoute.

### Επιβεβαιώστε ότι το εργαλείο σας δρομολογεί αιτήματα στο OmniRoute

Μπορείτε να δείτε τις λεπτομέρειες του αιτήματος κάνοντας κλικ στο [Παρακολούθηση/Αρχεία καταγραφής](http://localhost:20128/dashboard/logs) από την αριστερή πλευρική γραμμή. Κάνοντας κλικ στις σχετικές καταχωρίσεις, μπορείτε να δείτε περισσότερες λεπτομέρειες. Επιπλέον, μπορείτε να δείτε ποιες πληροφορίες αποστέλλονται από το αγαπημένο σας περιβάλλον εκτέλεσης. Αυτό είναι χρήσιμο για εκπαιδευτικούς σκοπούς και για τον εντοπισμό σφαλμάτων.

## Συχνές ερωτήσεις

### «Χρειάζομαι κλειδί API;»

**Όχι!** Μπορείτε να χρησιμοποιήσετε δωρεάν παρόχους (Kiro, OpenCode Free, Pollinations) χωρίς κανένα κλειδί API. Απλώς συνδέστε τους στον πίνακα ελέγχου.

### «Τι είναι το `auto`;»

Το `auto` δίνει εντολή στο OmniRoute να επιλέγει αυτόματα τον καλύτερο πάροχο για κάθε αίτημα. Λαμβάνει υπόψη την ταχύτητα, το κόστος, την ποιότητα και τη διαθεσιμότητα. Δείτε τον [Οδηγό Auto-Combo](./AUTO-COMBO-GUIDE.md) για λεπτομέρειες.

### «Πόσο κοστίζει;»

Το ίδιο το OmniRoute είναι **δωρεάν και ανοιχτού κώδικα**. Πληρώνετε μόνο για τους παρόχους που χρησιμοποιείτε. Πολλοί πάροχοι διαθέτουν δωρεάν προγράμματα — δείτε τον [Οδηγό δωρεάν προγραμμάτων](./FREE-TIERS-GUIDE.md).

### «Μπορώ να το χρησιμοποιήσω με Claude Code / Cursor / Copilot;»

**Ναι!** Το OmniRoute λειτουργεί με οποιοδήποτε εργαλείο υποστηρίζει τη μορφή OpenAI. Απλώς ορίστε το βασικό URL σε `http://localhost:20128/v1`. Δείτε τον [Οδηγό εργαλείων CLI](../reference/CLI-TOOLS.md) για συγκεκριμένες οδηγίες ρύθμισης.

### «Τι γίνεται αν ένας πάροχος τεθεί εκτός λειτουργίας;»

Το OmniRoute παρακάμπτει αυτόματα τους παρόχους που αποτυγχάνουν και δοκιμάζει τον επόμενο. Δεν χρειάζεται να κάνετε τίποτα. Δείτε τον [Οδηγό Auto-Combo](./AUTO-COMBO-GUIDE.md) για λεπτομέρειες.
