Το παρόν έγγραφο καταγράφει την απόφαση υλοποίησης για το
[Issue #7854](https://github.com/diegosouzapw/OmniRoute/issues/7854). Τα δημόσια προϊόντα
αναπαρίστανται ως τέσσερις οικογένειες παρόχων. Η περιοχή αποτελεί δεδομένο σύνδεσης και όχι ξεχωριστό προϊόν.

## Απόφαση

| Οικογένεια παρόχου                            | OmniRoute ID            | Καθολική περιοχή | Περιοχή Κίνας |
| --------------------------------------------- | ----------------------- | ---------------- | ------------- |
| Alibaba Cloud Model Studio (χρέωση ανά χρήση) | `alibaba`               | Σιγκαπούρη       | Πεκίνο        |
| Alibaba Cloud Token Plan                      | `bailian-coding-plan`   | Σιγκαπούρη       | Πεκίνο        |
| Qwen Cloud (χρέωση ανά χρήση)                 | `qwen-cloud`            | Καθολική         | Πεκίνο        |
| Qwen Cloud Token Plan                         | `qwen-cloud-token-plan` | Σιγκαπούρη       | Πεκίνο        |

Το υπάρχον ID `alibaba-cn` παραμένει ως ψευδώνυμο συμβατότητας κατά την εκτέλεση για αποθηκευμένες συνδέσεις, διαδρομές
μοντέλων, συνδυασμούς και ιστορική χρήση. Η κάρτα του στον πίνακα ελέγχου ενσωματώνεται στην `alibaba`· δεν απαιτείται
επανεγγραφή της βάσης δεδομένων.

Το Qwen Cloud με χρέωση ανά χρήση και το Alibaba Cloud Model Studio χρησιμοποιούν επί του παρόντος από κοινού τους συμβατούς με το DashScope
κεντρικούς υπολογιστές εκτέλεσης, αλλά παραμένουν ξεχωριστές ταυτότητες παρόχων, επειδή οι χρήστες αποκτούν κλειδιά και διαχειρίζονται
λογαριασμούς μέσω διαφορετικών διεπαφών προϊόντων. Τα προϊόντα Alibaba και Qwen Cloud Token Plan χρησιμοποιούν
διαφορετικές οικογένειες τελικών σημείων, επομένως και τα τέσσερα προϊόντα παραμένουν ξεχωριστά ID παρόχων.

## Πίνακας τελικών σημείων

| Οικογένεια παρόχου      | `global-sg`                                                              | `china-beijing`                                                      | Μορφή πρωτοκόλλου |
| ----------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------- | ----------------- |
| `alibaba`               | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI            |
| `bailian-coding-plan`   | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/apps/anthropic/v1`  | `https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic/v1`  | Anthropic         |
| `qwen-cloud`            | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI            |
| `qwen-cloud-token-plan` | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` | `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | OpenAI            |

Το κλειδί API και το τελικό σημείο πρέπει να ανήκουν στο ίδιο προϊόν και στην ίδια περιοχή. Η επιλογή μιας περιοχής αλλάζει
το προκαθορισμένο τελικό σημείο που χρησιμοποιείται από την επικύρωση και τα κανονικά αιτήματα.

## Σύμβαση σύνδεσης

Οι νέες συνδέσεις αποθηκεύουν το σταθερό κλειδί περιοχής στο `providerSpecificData`:

```json
{
  "region": "global-sg"
}
```

Οι επιτρεπόμενες τιμές είναι `global-sg` και `china-beijing`. Το τελικό σημείο προκύπτει κεντρικά από το
ID παρόχου και την περιοχή. Ένα μη προκαθορισμένο `providerSpecificData.baseUrl` παραμένει ρητή
παράκαμψη από τον διαχειριστή και έχει προτεραιότητα, ενώ τα παλιά αποθηκευμένα προκαθορισμένα URL κανονικοποιούνται ξανά σύμφωνα με τον περιφερειακό
πίνακα.

Έτσι, το σχήμα σύνδεσης παραμένει επεκτάσιμο: μια άλλη περιοχή μπορεί να προστεθεί στον επιλυτή χωρίς
να δημιουργηθεί άλλη κάρτα παρόχου ή να αλλάξουν τα αποθηκευμένα ID παρόχων.

## Συμβατότητα και διάθεση

1. Προσθέστε τον μηχανισμό επίλυσης περιφερειακών endpoint και διατηρήστε τις τρέχουσες καθολικές προεπιλογές.
2. Χρησιμοποιήστε τη ζωντανή περιφερειακή ανακάλυψη `/models` του DashScope για το `alibaba`, το συμβατό
   ID `alibaba-cn` και το `qwen-cloud`. Οι αποκρίσεις τους περνούν πρώτα από ένα φίλτρο δημιουργίας κειμένου,
   επειδή το γενικό endpoint επιστρέφει επίσης μοντέλα εικόνας, βίντεο, ήχου, embedding και άλλα μοντέλα που
   δεν προορίζονται για συνομιλία. Στη συνέχεια, το `qwen-cloud` εφαρμόζει τη συντηρούμενη λίστα επιτρεπόμενων
   που δηλώνεται στο μητρώο παρόχου του. Το Alibaba Model Studio και το Qwen Cloud διατηρούν ξεχωριστούς
   επιμελημένους καταλόγους, παρόλο που επί του παρόντος χρησιμοποιούν από κοινού τους ίδιους runtime hosts.
3. Καταχωρίστε το `qwen-cloud-token-plan` με την τρέχουσα λίστα επιτρεπόμενων μοντέλων κειμένου του Token Plan.
4. Προσθέστε έναν επιλογέα περιοχής με τύπους στους διαλόγους προσθήκης/επεξεργασίας σύνδεσης.
5. Αποκρύψτε τη διπλότυπη κάρτα `alibaba-cn` και συμπεριλάβετε τις υπάρχουσες συνδέσεις της στη σελίδα παρόχου
   `alibaba`.
6. Διατηρήστε διαθέσιμες τις προσαρμοσμένες παρακάμψεις endpoint για προηγμένες υλοποιήσεις και υλοποιήσεις
   ειδικές για κάθε χώρο εργασίας.

Τα μοντέλα πολυμέσων του Token Plan παραμένουν εκτός του καταλόγου συνομιλίας, επειδή χρησιμοποιούν αποκλειστικά endpoint.
Τα `wan2.7-image` και `wan2.7-image-pro` είναι καταχωρισμένα στο `open-sse/config/imageRegistry.ts`·
τα `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v` και `happyhorse-1.1-r2v` είναι καταχωρισμένα στο
`open-sse/config/videoRegistry.ts`. Και τα δύο μητρώα επαναχρησιμοποιούν την ταυτότητα σύνδεσης
`qwen-cloud-token-plan` και τα διαπιστευτήριά της που είναι ειδικά για κάθε περιοχή.

Το κανονικό Qwen Cloud διαθέτει ξεχωριστούς καταλόγους εικόνας και βίντεο με χρέωση ανά χρήση υπό την ταυτότητα
`qwen-cloud`. Τα μοντέλα εικόνας του είναι τα `wan2.7-image-pro`, `wan2.7-image`, `qwen-image-3.0-pro`,
`qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0-2026-03-03` και `z-image-turbo`. Τα μοντέλα βίντεο
είναι τα `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`,
`happyhorse-1.0-video-edit`, `wan2.7-t2v`, `wan2.7-i2v`, `wan2.7-r2v-2026-06-12` και
`wan2.7-videoedit`. Αυτά τα μοντέλα επαναχρησιμοποιούν μόνο την κανονική σύνδεση `qwen-cloud` και το
περιφερειακό endpoint πολυμέσων του DashScope. Τα μητρώα του Token Plan και της χρέωσης ανά χρήση δεν
κληρονομούν ούτε συγχωνεύουν τις λίστες μοντέλων μεταξύ τους.

Η ταυτότητα `bailian-coding-plan` διαθέτει επίσης τις δικές της λίστες επιτρεπόμενων πολυμέσων:
`wan2.7-image`, `wan2.7-image-pro`, `qwen-image-2.0` και `qwen-image-2.0-pro` για δημιουργία
εικόνων, καθώς και
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v` και `happyhorse-1.1-r2v` για δημιουργία
βίντεο. Χρησιμοποιεί μόνο τη σύνδεση Bailian Coding Plan και το περιφερειακό endpoint του Coding Plan.
Τα μητρώα εικόνας και βίντεο της δεν κληρονομούν ούτε συγχωνεύονται με κανέναν από τους δύο παρόχους Qwen Cloud.

Η κανονική ταυτότητα `alibaba` διαθέτει ξεχωριστές λίστες επιτρεπόμενων για εικόνες και βίντεο. Τα μοντέλα
εικόνας της είναι τα `qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0`,
`z-image-turbo` και `wan2.6-t2i`. Τα πρόσθετα μοντέλα βίντεο είναι τα `happyhorse-1.1-i2v`,
`happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`,
`wan2.7-i2v-2026-04-25`, `wan2.6-i2v-flash`, `wan2.7-t2v-2026-06-12`,
`wan2.7-r2v-2026-06-12` και `wan2.7-videoedit`. Αυτά τα μοντέλα χρησιμοποιούν μόνο τη σύνδεση
Alibaba Model Studio και το επιλεγμένο περιφερειακό endpoint πολυμέσων της· δεν προστίθενται σε κανένα μητρώο
Coding Plan ή Qwen Cloud.

Ο κατάλογος συνομιλίας του Qwen Cloud Token Plan ακολουθεί τη λίστα επιτρεπόμενων κειμένου με ακριβή αντιστοίχιση
συμβολοσειράς του Individual plan:
`qwen3.8-max-preview`, `qwen3.7-max`, `qwen3.7-plus`, `qwen3.6-flash`, `glm-5.2` και
`deepseek-v4-pro`. Οι καταχωρίσεις Wan και HappyHorse ανήκουν στα ξεχωριστά API δημιουργίας εικόνων/βίντεο.

Το Alibaba Token Plan εκθέτει τα ίδια έξι τρέχοντα ID μοντέλων δημιουργίας κειμένου μέσω του
endpoint του που είναι συμβατό με το Anthropic. Η επιλογή Singapore αποθηκεύει το υπάρχον κλειδί περιοχής
`global-sg`· μόνο η ετικέτα που εμφανίζεται στον χρήστη διαφέρει από τις οικογένειες παρόχων που αποκαλούν
την περιοχή Global.

Ο κανονικός κατάλογος συνομιλίας του Qwen Cloud είναι σκόπιμα πιο περιορισμένος από την πλήρη ζωντανή απόκριση
κειμένου. Η συντηρούμενη λίστα επιτρεπόμενων βρίσκεται στο
`open-sse/config/providers/registry/qwen-cloud/index.ts`· η ζωντανή ανακάλυψη επιστρέφει μόνο ID που
υπάρχουν τόσο στην απόκριση του upstream όσο και σε εκείνη τη λίστα μητρώου.

Το Alibaba Model Studio ακολουθεί τον ίδιο κανόνα ζωντανής τομής με την ανεξάρτητα συντηρούμενη λίστα
επιτρεπόμενων στο `open-sse/config/providers/registry/alibaba/index.ts`. Ο πάροχος συμβατότητας
`alibaba-cn` επαναχρησιμοποιεί αυτόν τον κατάλογο, ενώ εκτελεί την ανακάλυψη μέσω του endpoint του Πεκίνου.
