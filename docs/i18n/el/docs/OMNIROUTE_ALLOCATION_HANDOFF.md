Η κατανομή δεν αποτελεί ποσόστωση παρόχου.

Οι δεξαμενές ποσόστωσης καθορίζουν ποια κλειδιά API μπορούν να καταναλώνουν πόρους από μια δεξαμενή παρόχου και πώς εφαρμόζονται οι πολιτικές αυστηρού, ελαστικού ή στιγμιαία αυξημένου ορίου. Η ποσόστωση παρόχου είναι εξωτερική χωρητικότητα που αναφέρεται από έναν πάροχο ή από μια ρητά διαμορφωμένη πηγή. Οι εσωτερικοί προϋπολογισμοί του Ghostlight είναι όρια διακυβέρνησης που καθορίζονται από τον διαχειριστή.

Η λειτουργία `ensurePool` είναι ιδιοδύναμη: μια πανομοιότυπη δεξαμενή παραμένει αμετάβλητη, μια τροποποιημένη κατανομή ενημερώνεται και μια δεξαμενή που λείπει δημιουργείται. Αυτό προορίζεται για αυτοματοποίηση και για καλούντες το API με καθορισμένα όρια.

Το τελικό σημείο κατάστασης μόνο για ανάγνωση είναι `GET /api/omniroute/status`. Η εντολή επαλήθευσης είναι `npm run omniroute:verify`· δεν πραγματοποιεί κανένα ενεργό αίτημα προς μοντέλο.
