**OmniCopilot** τοποθετεί κάθε μοντέλο που παρέχει το OmniRoute στον _εγγενή_ επιλογέα μοντέλων του GitHub Copilot Chat.
Χωρίς δεύτερη πλευρική γραμμή, χωρίς ξεχωριστό περιβάλλον συνομιλίας — η λειτουργία agent του Copilot, η κλήση εργαλείων,
οι διακομιστές MCP και οι προσαρμοσμένες οδηγίες συνεχίζουν να λειτουργούν κανονικά, απλώς εκτελούνται στο μοντέλο που επιλέγετε.

|                                |                                                                                                                                                 |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Εγκατάσταση (VS Code)**      | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Εγκατάσταση (forks)**        | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Πηγαίος κώδικας / ζητήματα** | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Απαιτεί**                    | VS Code 1.104+                                                                                                                                  |

> **Δεν απαιτείται συνδρομή Copilot.** Από το VS Code 1.122 και μετά, ένας πάροχος γλωσσικών μοντέλων λειτουργεί
> χωρίς σύνδεση στο GitHub και χωρίς οποιοδήποτε πρόγραμμα Copilot. Οι ενσωματωμένες συμπληρώσεις και
> οι λειτουργίες που βασίζονται σε embeddings παραμένουν εκτός του API παρόχου και εξακολουθούν να απαιτούν Copilot.

## Ρύθμιση

1. **Εκτελέστε το OmniRoute** — `npm install -g omniroute && omniroute` (πίνακας ελέγχου στη διεύθυνση `http://localhost:20128`).
2. **Εγκαταστήστε την επέκταση** — αναζητήστε "OmniRoute" στην προβολή Extensions.
3. **Επιλέξτε ένα μοντέλο** — Copilot Chat → επιλογέας μοντέλου → **Manage Models…** → **OmniRoute** και, στη συνέχεια, επιλέξτε
   όσα θέλετε.

Δεν χρειάζεται καμία ρύθμιση όταν το OmniRoute εκτελείται στην προεπιλεγμένη θύρα. Για μια απομακρυσμένη παρουσία, ανοίξτε το
**εικονίδιο OmniRoute στη γραμμή δραστηριοτήτων** (ή εκτελέστε `OmniRoute: Manage Connection`) και ορίστε:

- **URL διακομιστή** — τη ριζική διεύθυνση του διακομιστή, π.χ. `http://192.168.0.15:20128`. Το επίθημα `/v1`
  προστίθεται από την επέκταση· μην το συμπεριλάβετε.
- **Κλειδί API** — μόνο όταν ο διακομιστής ορίζει το `REQUIRE_API_KEY`. Αποθηκεύεται στην κλειδοθήκη του λειτουργικού συστήματος μέσω του VS
  Code SecretStorage, ποτέ στο `settings.json`.

## Τι θα εμφανίζει ο επιλογέας

Η επέκταση δεν εμφανίζει το ανεπεξέργαστο ωφέλιμο φορτίο του `GET /v1/models` — το διαμορφώνει και ο αριθμός που
βλέπετε είναι μικρότερος από το μέγεθος του καταλόγου για δύο σκόπιμους λόγους.

### Ζητά ένα id ανά μοντέλο

Το `MODELS_CATALOG_PREFIX_MODE` έχει ως προεπιλογή το **`dual`**, το οποίο δημοσιεύει κάθε μοντέλο δύο φορές — μία φορά
με το σύντομο πρόθεμα ψευδωνύμου και μία φορά με το κανονικό πρόθεμα παρόχου — ώστε οι παλαιότερες ρυθμίσεις
πελατών να συνεχίζουν να επιλύουν και τις δύο μορφές:

```
cc/claude-sonnet-4-6        ← πρόθεμα ψευδωνύμου
claude/claude-sonnet-4-6    ← κανονικό πρόθεμα, ίδιο μοντέλο
```

Η επέκταση ζητά **`GET /v1/models?prefix=alias`**, ώστε να λαμβάνεται ένα id ανά μοντέλο, χωρίς
να αλλάζει η ρύθμιση σε επίπεδο διακομιστή για τους άλλους πελάτες σας. Σε μια παρουσία αναφοράς, αυτό μείωσε
**2345 καταχωρίσεις σε 1396 — 949 διπλότυπα, κανένα μοντέλο δεν χάθηκε.**

Αν προτιμάτε να το διορθώσετε σε επίπεδο διακομιστή για _κάθε_ πελάτη, ορίστε τη σημαία λειτουργίας
`MODELS_CATALOG_PREFIX_MODE` σε `alias` στον πίνακα ελέγχου. Ανατρέξτε στο
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) για την
παράμετρο ερωτήματος και τον πίνακα ανά λειτουργία.

### Αποκρύπτει μοντέλα που δεν υποστηρίζουν συνομιλία

Ο κατάλογος περιλαμβάνει επίσης μοντέλα εικόνας, βίντεο, ήχου, ανακατάταξης, embeddings και εποπτείας. Αυτά
απορρίπτονται ούτως ή άλλως σε ένα αίτημα συνομιλίας:

```
HTTP 400 — Το μοντέλο '<id>' είναι μοντέλο δημιουργίας εικόνων και δεν μπορεί να χρησιμοποιηθεί στο
/v1/chat/completions. Χρησιμοποιήστε POST /v1/images/generations αντ' αυτού.
```

οπότε φιλτράρονται βάσει του πεδίου `type` πριν φτάσουν στον επιλογέα. **Τα μοντέλα Responses-API
διατηρούνται** — κάθε καταχώριση Codex / GPT-5.x δηλώνει `supported_endpoints: ["responses"]`
και το OmniRoute τις μεταφράζει για το `/v1/chat/completions`, επομένως μπορούν να χρησιμοποιηθούν κανονικά.

### Πάροχοι που δεν έχετε ρυθμίσει ποτέ

Ο κατάλογος παραθέτει μοντέλα από παρόχους με **ενεργή σύνδεση** _συν_ κάθε πάροχο **noAuth**
— εκείνους χωρίς κλειδί που αποτελούν μεγάλο μέρος της δωρεάν βαθμίδας. Αυτό είναι σκόπιμο. Για να
τους αποκρύψετε, προσθέστε τους στο `blockedProviders` στις ρυθμίσεις του πίνακα ελέγχου· δεν αλλάζει τίποτα στην
επέκταση.

## Πίνακας ελέγχου μέσα σε καρτέλα του VS Code

Η ρύθμιση `omnicopilot.dashboardOpen: "editor"` εμφανίζει τον πίνακα ελέγχου του OmniRoute σε μια καρτέλα επεξεργαστή μέσω του
Simple Browser αντί για εξωτερικό πρόγραμμα περιήγησης. Η ενσωμάτωση είναι **προαιρετική στον διακομιστή** μέσω της
`DASHBOARD_ALLOW_EMBED=vscode`, η οποία παρέχει τις σελίδες HTML με
`frame-ancestors 'self' vscode-webview:` αντί για τα προεπιλεγμένα `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Η επιφάνεια API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) διατηρεί τις
αυστηρές κεφαλίδες και στις δύο περιπτώσεις.

> ⚠️ **Πρόκειται για σημαία χρόνου μεταγλώττισης και όχι χρόνου εκτέλεσης.** Το Next.js μεταγλωττίζει τη `headers()` στο μανιφέστο
> των διαδρομών, επομένως το `next.config.mjs` διαβάζει τη μεταβλητή κατά τη δημιουργία του πακέτου
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Η εξαγωγή της πριν από την εκκίνηση ενός ήδη μεταγλωττισμένου διακομιστή δεν αλλάζει τίποτα — οι κεφαλίδες είναι ενσωματωμένες.

```bash
# η μεταβλητή πρέπει να υπάρχει στην εντολή BUILD
DASHBOARD_ALLOW_EMBED=vscode npm run build        # ή npm run build:release
npm start
```

| Τρόπος εγκατάστασης        | Μπορείτε να ενεργοποιήσετε την ενσωμάτωση;                                                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Από τον πηγαίο κώδικα      | ✅ ορίστε τη μεταβλητή στην εντολή μεταγλώττισης, όπως παραπάνω                                                                                         |
| `npm install -g omniroute` | ❌ το δημοσιευμένο πακέτο περιλαμβάνει ένα προμεταγλωττισμένο bundle — πραγματοποιήστε μεταγλώττιση από τον πηγαίο κώδικα αντ’ αυτού                    |
| Εικόνα Docker              | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — η προμεταγλωττισμένη εικόνα στο Docker Hub δεν υποστηρίζει ενσωμάτωση |

Χωρίς έκδοση με ενεργοποιημένη την ενσωμάτωση, η σελίδα αρνείται να εμφανιστεί σε πλαίσιο, η επέκταση το ανιχνεύει από τις
κεφαλίδες απόκρισης και επιστρέφει στο εξωτερικό πρόγραμμα περιήγησης — τίποτα δεν χαλάει και εμφανίζεται μία σχετική ενημέρωση.
Δείτε το [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) και το ζήτημα
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Ρύθμιση των άλλων εργαλείων σας μέσα από το VS Code

Η εντολή **`OmniRoute: Configure Coding CLI`** χρησιμοποιεί το CLI `omniroute` για να δημιουργήσει έτοιμα προς χρήση προφίλ
για τα Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo και Roo — τις ίδιες ρυθμίσεις παραμέτρων που περιγράφονται στο
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). Το κλειδί API μεταβιβάζεται στο CLI μέσω της
μεταβλητής περιβάλλοντος `OMNIROUTE_API_KEY`, ποτέ μέσω της γραμμής εντολών.

## Αντιμετώπιση προβλημάτων

| Σύμπτωμα                                                                       | Αιτία / λύση                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Δεν υπάρχουν μοντέλα OmniRoute στον επιλογέα                                   | Ο διακομιστής δεν είναι προσβάσιμος. Η κουκκίδα στη γραμμή κατάστασης γίνεται γκρι· εκτελέστε την εντολή `OmniRoute: Check Connection`. Η ανακάλυψη είναι σκόπιμα αθόρυβη και δεν προσθέτει μοντέλα αντί να εμφανίζει προτροπή.                                                                                                 |
| Κάθε μοντέλο εμφανίζεται δύο φορές                                             | Χρησιμοποιείτε έκδοση του OmniCopilot παλαιότερη από την 1.0.1 — αναβαθμίστε. Η επέκταση πλέον υποβάλλει αίτημα με `?prefix=alias`.                                                                                                                                                                                             |
| Ένα μοντέλο εικόνας/ήχου εμφανιζόταν παλαιότερα αλλά τώρα λείπει               | Αυτό είναι σκόπιμο από την έκδοση 1.0.1 — δεν μπορούσε ποτέ να απαντήσει σε αίτημα συνομιλίας.                                                                                                                                                                                                                                  |
| Ο πίνακας λείπει από τη Γραμμή δραστηριότητας                                  | Το VS Code μετακινεί τα επιπλέον κοντέινερ προβολών στο μενού υπερχείλισης **"…"** στο κάτω μέρος της Γραμμής δραστηριότητας, ενώ ένα κοντέινερ που αποκρύφτηκε μέσω δεξιού κλικ παραμένει κρυφό. Κάντε δεξί κλικ στη Γραμμή δραστηριότητας → επιλέξτε **OmniRoute** ή ανοίξτε το με την εντολή `OmniRoute: Manage Connection`. |
| Ο πίνακας ελέγχου ανοίγει στο πρόγραμμα περιήγησης παρά τη λειτουργία `editor` | Ο διακομιστής δεν **μεταγλωττίστηκε** με `DASHBOARD_ALLOW_EMBED=vscode` (δείτε παραπάνω) — ο ορισμός της κατά την εκκίνηση μιας προμεταγλωττισμένης εγκατάστασης δεν έχει κανένα αποτέλεσμα. Η εναλλακτική συμπεριφορά είναι σκόπιμη.                                                                                           |
| Η λίστα μοντέλων είναι παρωχημένη μετά την αλλαγή παρόχων                      | Εκτελέστε την εντολή `OmniRoute: Refresh Models` ή χρησιμοποιήστε τον σύνδεσμο ↻ στον πίνακα.                                                                                                                                                                                                                                   |
