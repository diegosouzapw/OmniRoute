Το `@omniroute/opencode-plugin-v2` προσθέτει ολόκληρο τον κατάλογο OmniRoute — μοντέλα, combos και
auto-combos — στον επιλογέα μοντέλων του OpenCode v2, μαζί με εμφανιζόμενα ονόματα, τιμολόγηση και όρια
δωρεάν χρήσης.

Είναι ξεχωριστό πακέτο από το `@omniroute/opencode-plugin`, επειδή τα OpenCode v1 και v2 φορτώνουν
τα plugins μέσω διαφορετικών συμβάσεων. Επιλέξτε αυτό που αντιστοιχεί στην κύρια έκδοση του OpenCode που χρησιμοποιείτε· τίποτα δεν
είναι κοινό μεταξύ τους, επομένως η αναβάθμιση του ενός δεν επιβάλλει ποτέ την αναβάθμιση του άλλου.

## Απαιτήσεις

- OpenCode v2.
- Μια προσβάσιμη πύλη OmniRoute (`http://localhost:20128` από προεπιλογή).
- Node.js 22 ή 24.

## Εγκατάσταση

Προσθέστε το plugin στο `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Στη συνέχεια, τα μοντέλα εμφανίζονται ως `omniroute/<provider>/<model>`· το `providerId` καθορίζει αυτό το πρόθεμα και
το αναγνωριστικό της ενσωμάτωσης κάτω από το οποίο το OpenCode αποθηκεύει το διαπιστευτήριο.

## Διαπιστευτήρια

Το plugin αναζητά ένα κλειδί πύλης σε τρία σημεία, με την ακόλουθη σειρά:

1. **Το διαπιστευτήριο που συνδέσατε στο OpenCode.** Το plugin καταχωρίζει μια ενσωμάτωση, ώστε
   η ροή ελέγχου ταυτότητας του OpenCode να μπορεί να αποθηκεύσει το κλειδί. Τίποτα δεν καταλήγει στο `opencode.json` — προτιμήστε αυτήν την επιλογή.
2. Το `apiKey` στις επιλογές του plugin, για παράκαμψη ανά έργο. Αυτό τοποθετεί το κλειδί σε ένα αρχείο που
   ενδέχεται να καταχωρείτε στο αποθετήριο.
3. Το `OMNIROUTE_API_KEY` στο περιβάλλον.

Αν δεν υπάρχει κανένα από τα τρία, ο κατάλογος είναι κενός και το plugin το αναφέρει μία φορά κατά την εκκίνηση, αντί
να σας αφήσει με έναν σιωπηρά κενό επιλογέα.

### Το διακριτικό διαχείρισης είναι διαφορετικό κλειδί

Τα combos, η κατάσταση των παρόχων και ο εμπλουτισμός (εμφανιζόμενα ονόματα, τιμολόγηση, όρια δωρεάν χρήσης) προέρχονται από
τα endpoints `/api/*` της πύλης, τα οποία οι περισσότερες εγκαταστάσεις προστατεύουν με ένα διακριτικό **διαχείρισης**
και όχι με το κλειδί inference:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Αν δεν οριστεί, το `managementReadToken` χρησιμοποιεί ως εφεδρικό το `apiKey`. Όταν μια πύλη απορρίπτει αυτήν την εφεδρική επιλογή,
ο κατάλογος εξακολουθεί να δημοσιεύεται, αλλά με τα ακατέργαστα αναγνωριστικά μοντέλων αντί για εμφανιζόμενα ονόματα, χωρίς απαλοιφή διπλοτύπων
κανονικών ψευδωνύμων, χωρίς τιμολόγηση και χωρίς combos. Το plugin προειδοποιεί μία φορά ανά endpoint όταν συμβαίνει αυτό,
κατονομάζοντας το endpoint και ό,τι χάθηκε — έτσι ένας υποβαθμισμένος επιλογέας δεν αποτελεί ποτέ μυστήριο.

## Επιλογές

| Κλειδί                           | Προεπιλογή                                             | Σημειώσεις                                                                                                                                |
| -------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                          | Αναγνωριστικό παρόχου, αναγνωριστικό ενσωμάτωσης και πρόθεμα κάτω από το οποίο εμφανίζονται τα μοντέλα                                    |
| `baseURL`                        | απαιτείται                                             | Ρίζα πύλης, μόνο `http(s)`· το επίθημα `/v1` προστίθεται όπου χρειάζεται                                                                  |
| `apiKey`                         | συνδεδεμένο διαπιστευτήριο, έπειτα `OMNIROUTE_API_KEY` | Κλειδί συνομιλίας για `/v1/*`                                                                                                             |
| `managementReadToken`            | χρησιμοποιεί ως εφεδρικό το `apiKey`                   | Κλειδί για `/api/*` — συνήθως **δεν** είναι το ίδιο                                                                                       |
| `displayName`                    | `"OmniRoute"`                                          | Όνομα παρόχου στον επιλογέα                                                                                                               |
| `timeoutMs`                      | `10000`                                                | Χρονικό όριο ανά endpoint για ανάκτηση (τα auto-combos χρησιμοποιούν 5 δευτ.)                                                             |
| `modelCacheTtlMs`                | `300000`                                               | TTL cache καταλόγου· ένα στιγμιότυπο στον δίσκο επιταχύνει τις ψυχρές εκκινήσεις                                                          |
| `timeouts`                       | χρησιμοποιεί ως εφεδρικό το `timeoutMs`                | Χρονικά όρια ανά endpoint σε ms: `models`, `combos`, `autoCombos`, `enrichment`                                                           |
| `enrichment`                     | `true`                                                 | Ανάκτηση ονομάτων, τιμολόγησης και ορίων δωρεάν χρήσης                                                                                    |
| `providerTag`                    | `true`                                                 | Προσθήκη ως προθέματος σε ένα εμφανιζόμενο όνομα του upstream παρόχου προς τον οποίο δρομολογεί                                           |
| `usableOnly`                     | `false`                                                | Διατήρηση μόνο των παρόχων που η πύλη αναφέρει ως διαμορφωμένους                                                                          |
| `visibleModels` / `hiddenModels` | `[]`                                                   | Λίστες αποδοχής με ακριβή αντιστοίχιση ή αντιστοίχιση επιθήματος· η απόρριψη υπερισχύει                                                   |
| `geminiSanitization`             | `true`                                                 | Αφαίρεση των λέξεων-κλειδιών JSON-Schema που απορρίπτει το Gemini από τα σχήματα εργαλείων (τα εργαλεία `$ref` προωθούνται χωρίς αλλαγές) |
| `apiFormat.allowAnthropic`       | `false`                                                | Δρομολόγηση των αναγνωριστικών της λίστας αποδοχής μέσω του μπλοκ API του Anthropic                                                       |
| `apiFormat.anthropicModels`      | `[]`                                                   | Πλήρη αναγνωριστικά μοντέλων που δρομολογούνται στο Anthropic                                                                             |
| `logLevel` / `startupDebug`      | `warn` / `false`                                       | Αναλυτικότητα καταγραφής                                                                                                                  |

## Πώς ο κατάλογος παραμένει ενημερωμένος

Ο κατάλογος ανακτάται κατ’ απαίτηση και αποθηκεύεται προσωρινά για `modelCacheTtlMs`, ενώ ένα στιγμιότυπο στον δίσκο διατηρεί διαθέσιμο τον
τελευταίο γνωστό κατάλογο όταν η πύλη δεν είναι προσβάσιμη — μια διακοπή λειτουργίας σάς κοστίζει μόνο
σε επικαιρότητα. Τα μοντέλα και οι συνδυασμοί δημοσιεύονται μόλις φτάσουν· οι αυτόματοι συνδυασμοί, η λίστα
παρόχων και η επικάλυψη εμπλουτισμού ενσωματώνονται όταν γίνουν διαθέσιμα, ώστε ένα αργό τελικό σημείο να μην μπορεί να κρατήσει
όλο το εργαλείο επιλογής σε ομηρία.

Τα ονόματα περιλαμβάνουν όσα γνωρίζει η πύλη: τον ανάντη πάροχο στον οποίο δρομολογείται ένα μοντέλο, μια ένδειξη `[Free]`
και τον προϋπολογισμό που τη συνοδεύει — έτσι, δύο συνδέσεις που διαθέτουν το ίδιο μοντέλο παραμένουν
διακριτές. Απενεργοποιήστε το πρόθεμα με `"providerTag": false`.

Δεν υπάρχει εντολή μη αυτόματης ανανέωσης: οι εντολές του OpenCode v2 είναι πρότυπα προτροπών και όχι συναρτήσεις επανάκλησης,
επομένως ένα πρόσθετο δεν μπορεί να παρέχει μια τέτοια εντολή. Οι ανανεώσεις ακολουθούν το TTL· ο κεντρικός υπολογιστής καλείται να επαναφορτώσει μόνο όταν
ο κατάλογος ή η επικάλυψη έχει πράγματι αλλάξει, και ποτέ μία φορά ανά ανανέωση.

## Κλήση εργαλείων στο Gemini

Το Gemini απορρίπτει ολόκληρο το αίτημα όταν οι δηλώσεις εργαλείων του περιέχουν `$schema` ή
`additionalProperties`, απαντώντας με `400 INVALID_ARGUMENT`. Το πρόσθετο αφαιρεί αυτές τις λέξεις-κλειδιά από
τα σχήματα εργαλείων που προορίζονται για ένα μοντέλο Gemini αυτού του παρόχου και αφήνει κάθε άλλο αίτημα ανέπαφο.
Ένα εργαλείο που περιέχει `$ref` προωθείται ανέπαφο αντί να αφαιρεθούν στοιχεία του, καθώς η αφαίρεση της
αναφοράς θα διεύρυνε το σχήμα ώστε να «δέχεται οτιδήποτε».
Ορίστε `"geminiSanitization": false` για να το απενεργοποιήσετε.

## Αντιμετώπιση προβλημάτων

| Σύμπτωμα                                                           | Αιτία                                                                                                                     |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| Το εργαλείο επιλογής δεν εμφανίζει μοντέλο OmniRoute               | Δεν επιλύθηκε κανένα κλειδί (ελέγξτε την προειδοποίηση κατά την εκκίνηση) ή η πύλη δεν είναι προσβάσιμη                   |
| Ακατέργαστα αναγνωριστικά μοντέλων, χωρίς συνδυασμούς ή τιμολόγηση | Τα τελικά σημεία διαχείρισης απέρριψαν το διακριτικό — ορίστε το `managementReadToken`                                    |
| Μια συνεδρία είναι καρφιτσωμένη στο `opencode-<id>/…`              | Το πρόσθετο v1 δημοσίευε το `opencode-<id>`· το v2 δημοσιεύει μόνο το `<id>`, οπότε επιλέξτε ξανά το μοντέλο στο `<id>/…` |
