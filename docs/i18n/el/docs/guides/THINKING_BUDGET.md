> **Πίνακας ελέγχου:** Ρυθμίσεις → **AI** → Προϋπολογισμός συλλογισμού  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **Πηγαίος κώδικας:** `open-sse/services/thinkingBudget.ts`

Ο Προϋπολογισμός συλλογισμού ελέγχει αν το OmniRoute **επανεγγράφει τις παραμέτρους σκέψης/συλλογισμού του προγράμματος-πελάτη** κατά τη διαδρομή προς τους παρόχους. **Δεν** ενεργοποιεί ή απενεργοποιεί τη συμπίεση, τη δρομολόγηση ή την κρυφή μνήμη προτροπών.

## Λειτουργίες

| Λειτουργία                     | Τι κάνει το OmniRoute                                                                                                                         | Πότε χρησιμοποιείται                                                                                                                                                                                       |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (προεπιλογή) | Αφήνει αμετάβλητα τα πεδία του προγράμματος-πελάτη (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config` κ.λπ.).      | **Codex / Desktop / οποιοδήποτε πρόγραμμα-πελάτης πρέπει να ελέγχει την προσπάθεια + τις περιλήψεις συλλογισμού.** Απαιτείται για ορατά πλαίσια σκέψης όταν το πρόγραμμα-πελάτης ζητά `reasoning.summary`. |
| **`auto`**                     | **Αφαιρεί όλα** τα πεδία σκέψης/συλλογισμού από το σώμα του αιτήματος πριν από την αποστολή στον πάροχο.                                      | Μόνο όταν θέλετε σκόπιμα ο **πάροχος** να καθορίζει προεπιλογές και **δεν** χρειάζεστε σκέψη ελεγχόμενη από το πρόγραμμα-πελάτη. **Δεν** σημαίνει «αυτόματη εμφάνιση σκέψης».                              |
| **`custom`**                   | Αντικαθιστά κάθε αίτημα με έναν σταθερό προϋπολογισμό token σκέψης.                                                                           | Αυστηρό ανώτατο όριο στα token σκέψης για όλη την κίνηση.                                                                                                                                                  |
| **`adaptive`**                 | Κλιμακώνει τον προϋπολογισμό από ένα βασικό επίπεδο προσπάθειας, χρησιμοποιώντας το πλήθος μηνυμάτων, τα εργαλεία και το μήκος της προτροπής. | Ευέλικτος έλεγχος των token χωρίς πλήρη αφαίρεση της πρόθεσης του προγράμματος-πελάτη.                                                                                                                     |

### Τι αφαιρεί το `auto`

Όταν η λειτουργία είναι `auto`, η `stripThinkingConfig()` διαγράφει (μεταξύ άλλων):

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking` και, όταν υπάρχει, `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

Αν ένα πρόγραμμα-πελάτης (π.χ. το Codex Desktop) έστειλε `reasoning: { effort: "ultra", summary: "detailed" }`, το **auto απορρίπτει αυτό το αντικείμενο**. Ο πάροχος μπορεί να συνεχίσει να χρεώνει ορισμένα token συλλογισμού, αλλά συχνά επιστρέφει στοιχεία συλλογισμού που είναι **κενά ή μόνο κρυπτογραφημένα** — επομένως το περιβάλλον χρήστη δεν εμφανίζει χρήσιμη ροή σκέψης.

## Τι **δεν** είναι αυτό

| Δυνατότητα                                            | Σχέση                                                                                                                                                            |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Συμπίεση** (Caveman, RTK, stacked, …)               | Ξεχωριστή διοχέτευση. Λειτουργεί σε κάθε λειτουργία προϋπολογισμού συλλογισμού.                                                                                  |
| **Κρυφή μνήμη προτροπών / σημασιολογική κρυφή μνήμη** | Ξεχωριστή. Δεν επηρεάζεται από τη λειτουργία προϋπολογισμού συλλογισμού.                                                                                         |
| **Συνδυαστική δρομολόγηση / εναλλακτικές διαδρομές**  | Ξεχωριστά. Δεν επηρεάζονται.                                                                                                                                     |
| **Όρια token κλειδιού API / προϋπολογισμοί κόστους**  | Ξεχωριστά. Δεν επηρεάζονται.                                                                                                                                     |
| **Κρυφή μνήμη επανάληψης συλλογισμού**                | Επανεισαγωγή σε πολλαπλούς γύρους για αυστηρούς παρόχους (DeepSeek, Kimi, Qwen-thinking, …). Δεν ταυτίζεται με την επιλογή «εμφάνιση σκέψης» του Desktop.        |
| **Αποκρυπτογράφηση του `encrypted_content`**          | **Αδύνατη.** Τα ιδιωτικά κρυπτογραφημένα δεδομένα συλλογισμού των OpenAI/Codex είναι αδιαφανή. Το OmniRoute δεν τα αποκρυπτογραφεί ποτέ (#7095 / #7176 / #7304). |

## Ορατή συλλογιστική (πελάτες Codex / Responses)

Για να εμφανίζει ένας πελάτης το κείμενο συλλογιστικής, χρειάζονται **όλα** τα παρακάτω:

1. Λειτουργία Thinking Budget = **`passthrough`** (ή custom/adaptive που εξακολουθεί να διατηρεί τα αιτήματα σύνοψης επαρκώς ανέπαφα για τη διαδρομή που χρησιμοποιείτε).
2. Ο πελάτης ζητά σύνοψη, π.χ. στο Codex `model_reasoning_summary = "detailed"` / `auto` (όχι `none`).
3. Η ανάντη υπηρεσία μεταδίδει πράγματι σε ροή `response.reasoning_summary_text.*` (ή ένα μη κενό `reasoning.summary` στο στοιχείο).

Αν λαμβάνετε μόνο «κρυπτογραφημένη ιδιωτική συλλογιστική», τότε είτε:

- η λειτουργία ήταν **`auto`** (το αίτημα του πελάτη αφαιρέθηκε), είτε
- η ανάντη υπηρεσία επέστρεψε `encrypted_content` χωρίς κείμενο σύνοψης (περιορισμός του παρόχου· το OmniRoute μπορεί να εμφανίσει μόνο ένα σύμβολο κράτησης θέσης, όχι απλό κείμενο).

## Παραδείγματα API

```bash
# Ανάγνωση
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Συνιστάται για την ορατότητα της συλλογιστικής στο Codex / Desktop
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Σχήμα (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`· προαιρετικά `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### Διατήρηση / επανεκκίνηση

Η τιμή αποθηκεύεται με το κλειδί ρυθμίσεων `thinkingBudget` και φορτώνεται κατά την εκκίνηση της διεργασίας (`hydrateThinkingBudgetConfig`). Μετά από αλλαγή μέσω της βάσης δεδομένων ή ορισμένων διαδρομών εκτός API, **επανεκκινήστε τη διεργασία OmniRoute**, ώστε το singleton στη μνήμη να συμφωνεί με τα δεδομένα στον δίσκο.

## Λίστα ελέγχου διαχειριστή

- [ ] Χρήστες Codex / Desktop: λειτουργία = **passthrough**
- [ ] Διατηρήστε τη συμπίεση ενεργοποιημένη αν θέλετε εξοικονόμηση token στα **μηνύματα**, όχι μέσω αφαίρεσης της συλλογιστικής
- [ ] Μην περιμένετε ότι το `auto` θα «εμφανίσει περισσότερη συλλογιστική»
- [ ] Οι συνόψεις μόνο σε κρυπτογραφημένη μορφή αποτελούν συμπεριφορά του **παρόχου**· το passthrough δεν μπορεί να τις αποκρυπτογραφήσει
