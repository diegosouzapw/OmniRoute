Το OmniRoute οργανώνει τους 352 υποστηριζόμενους παρόχους σε 3 οικονομικές βαθμίδες. Κάθε
αίτημα διέρχεται από αυτές με τη σειρά, έως ότου μία επιστρέψει επιτυχώς — έτσι
λαμβάνετε τη φθηνότερη βιώσιμη απόκριση χωρίς να χρειάζεται ποτέ να γράψετε κώδικα εναλλακτικής δρομολόγησης.

## Βαθμίδα 1 — Συνδρομή

**Πάροχοι για τους οποίους ήδη πληρώνετε.** Το OmniRoute αξιοποιεί πλήρως το όριο χρήσης προτού
λήξει.

| Πάροχος                         | Γιατί ανήκει στη Βαθμίδα 1                              |
| ------------------------------- | ------------------------------------------------------- |
| Claude Code OAuth               | Anthropic Pro/Team — σταθερή χρέωση, συχνά αναξιοποίητο |
| OpenAI Codex (συνδρομή ChatGPT) | Τα Plus/Team περιλαμβάνουν όριο χρήσης Codex            |
| GitHub Copilot                  | Ανά θέση χρήστη — το όριο μηδενίζεται κάθε μήνα         |
| Cursor IDE                      | Όριο χρήσης προγράμματος Pro                            |
| Antigravity / Devin Desktop     | Ενσωματωμένα όρια χρήσης                                |

**Στρατηγική**: δρομολογήστε πρώτα εδώ κάθε αίτημα που ταιριάζει στα
δυνατά σημεία του μοντέλου. Ο μηχανισμός παρακολούθησης ορίων εντοπίζει τους επικείμενους μηδενισμούς και η
συνδυαστική στρατηγική `reset-aware` καθορίζει ανάλογα τις προτεραιότητες. Για να δρομολογείτε πρώτα στη Βαθμίδα 1 και να μεταβαίνετε
στις βαθμίδες επί πληρωμή μόνο όταν εξαντλείται το όριο χρήσης, χρησιμοποιήστε το αναγνωριστικό `auto/thrifty` — ή το `auto/subscription`
για να παραμένετε στη χωρητικότητα που περιλαμβάνεται στο πρόγραμμα και να διακόπτετε τη λειτουργία σε περίπτωση αποτυχίας. Δείτε τη
[Δρομολόγηση με προτεραιότητα στις συνδρομές](../routing/SUBSCRIPTION_LADDER.md).

## Βαθμίδα 2 — Οικονομική

**Πάροχοι με χρέωση ανά token κάτω από $1/1M tokens.** Προορίζονται για εργασίες μεγάλου όγκου
ή για χρήση όταν τα όρια της Βαθμίδας 1 εξαντληθούν.

| Πάροχος                                        | Τιμή (είσοδος/έξοδος) | Δυνατά σημεία                  |
| ---------------------------------------------- | --------------------- | ------------------------------ |
| DeepSeek V4 Pro                                | $0.27 / $1.10 ανά 1M  | Κώδικας, συλλογισμός           |
| GLM-4.5                                        | $0.60 / $2.20 ανά 1M  | Εκτεταμένο context             |
| MiniMax M1                                     | $0.20 / $1.10 ανά 1M  | Ταχύτητα                       |
| Qwen Coder                                     | $0.30 / $1.20 ανά 1M  | Κώδικας                        |
| OpenRouter (βελτιστοποιημένο ως προς την τιμή) | ποικίλλει             | 100+ μοντέλα, δυναμική επιλογή |

**Στρατηγική**: ο συνδυασμός `cost-optimized` επιλέγει το μοντέλο με το χαμηλότερο κόστος $/token που ικανοποιεί
το φίλτρο δυνατοτήτων της εργασίας (όραση, λειτουργία JSON, εργαλεία, μέγιστο context).

## Βαθμίδα 3 — Δωρεάν

**Πάροχοι μηδενικού κόστους** — δωρεάν προγράμματα, προγράμματα πιστώσεων, ημερήσια όρια χρήσης OAuth.

| Πάροχος          | Δωρεάν όριο χρήσης / πιστώσεις                   |
| ---------------- | ------------------------------------------------ |
| Kiro AI          | Δωρεάν βαθμίδα Claude (γενναιόδωρη εύλογη χρήση) |
| OpenCode Free    | Χωρίς έλεγχο ταυτότητας, γενναιόδωρα όρια ρυθμού |
| Qoder            | Δωρεάν OAuth                                     |
| Google Vertex AI | Πιστώσεις $300 για νέους λογαριασμούς            |
| Amazon Q         | Δωρεάν βαθμίδα για χρήστες AWS                   |
| Pollinations     | Ανοιχτό δημόσιο API                              |
| Cloudflare AI    | Δωρεάν βαθμίδα Workers AI                        |

**Στρατηγική**: ο συνδυασμός `auto` με ανώτατο όριο προϋπολογισμού δρομολογεί εδώ όταν αποτυγχάνουν οι Βαθμίδες 1+2
ή όταν έχει οριστεί `useFreeOnly=true`. Οι δωρεάν πάροχοι συχνά έχουν πιο αυστηρά
όρια ρυθμού — ο αυτόματος διακόπτης κυκλώματος τους επαναφέρει μετά την περίοδο αναμονής.

## Διαμόρφωση βαθμίδων

Πίνακας ελέγχου → **Βαθμίδες** → αντιστοιχίστε τους παρόχους σας. Οι προεπιλογές (από το `tierDefaults.json`) είναι
εύλογες· επεξεργαστείτε τις όταν έχετε συγκεκριμένες συνδρομές στις οποίες θέλετε να δώσετε προτεραιότητα ή παρόχους που θέλετε να εξαιρέσετε.

Η βαθμολόγηση 16 παραγόντων του Auto-Combo λαμβάνει επίσης υπόψη τη βαθμίδα. Δείτε το
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Τηλεμετρία

Πίνακας ελέγχου → **Χρήση** εμφανίζει τα tokens που καταναλώνονται ανά βαθμίδα και ανά ημέρα. Χρησιμοποιήστε το για να:

- Επιβεβαιώσετε ότι η Βαθμίδα 1 αξιοποιείται πλήρως (διαφορετικά σπαταλάτε την αξία της συνδρομής)
- Εντοπίσετε ποια μοντέλα της Βαθμίδας 2 επιλέγονται συχνότερα (περιορίστε τα σε 1-2)
- Επαληθεύσετε ότι η Βαθμίδα 3 εξοικονομεί χρήματα σε φόρτους εργασίας δοκιμών/πειραματισμού

## Συνήθη μοτίβα

### Αποκλειστικά δωρεάν φόρτος εργασίας

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Κατευθύνει έντονα προς τη Βαθμίδα 3· χρησιμοποιεί τη Βαθμίδα 2 μόνο εάν η Βαθμίδα 3 δεν είναι διαθέσιμη.

### Προτεραιότητα στη συνδρομή με οικονομική εναλλακτική

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Ρητή ταξινομημένη λίστα που αντιστοιχεί σε Βαθμίδα 1 → Βαθμίδα 2 → Βαθμίδα 3.
