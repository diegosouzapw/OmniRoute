## 1. Antigravity έναντι Antigravity CLI (agy)

Και οι δύο πάροχοι χρησιμοποιούν το **ίδιο σύστημα υποστήριξης της Google** — πανομοιότυπο πρόγραμμα-πελάτη OAuth, ανανέωση διακριτικών, τελικά σημεία και λογαριασμούς Google. Η διαφορά έγκειται στα μοντέλα που εμφανίζονται.

> Δείτε την [ανακοίνωση του Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli) για την επίσημη σύγκριση της Google.

| Πτυχή                   | `antigravity` (IDE)                                                | `agy` (CLI)                                                    |
| ----------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------- |
| **Προϊόν Google**       | Antigravity 2.0 / Antigravity IDE                                  | Antigravity CLI                                                |
| **Σύστημα υποστήριξης** | Ίδιο Google Cloud Code API                                         | Ίδιο Google Cloud Code API                                     |
| **OAuth / Διακριτικό**  | Ίδιο πρόγραμμα-πελάτης, ίδια ανανέωση                              | Ίδιο πρόγραμμα-πελάτης, ίδια ανανέωση                          |
| **Κατάλογος μοντέλων**  | Στατική επιμελημένη λίστα (ενσωματωμένη στον κώδικα του OmniRoute) | Δυναμική ανίχνευση από την Google μέσω `:fetchAvailableModels` |
| **Μοντέλα Claude**      | Sonnet 4.6, Opus 4.6 (4 παραλλαγές το καθένα)                      | Sonnet 4.6, Opus 4.6 (4 παραλλαγές το καθένα)                  |
| **Ονομασία Gemini**     | Καθαρή σήμανση (Low/Medium/High)                                   | Αναγνωριστικά ανάντη συστήματος (extra-low/low/agent)          |
| **Επιπλέον μοντέλα**    | `gpt-oss-120b-medium`                                              | Ενδέχεται να περιλαμβάνει επιπλέον μοντέλα από την Google      |
| **Προεπιλεγμένη χρήση** | Ενσωμάτωση σε IDE (VS Code, JetBrains)                             | Πρόσβαση μέσω CLI / API                                        |
| **Όριο χρήσης**         | Κοινό με το agy (ίδιος λογαριασμός Google)                         | Κοινό με το antigravity (ίδιος λογαριασμός Google)             |

**Διαθέσιμα μοντέλα (επαληθευμένα μέσω πειράματος, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (διάφορα επίπεδα συλλογισμού)
- Claude: Sonnet 4.6, Opus 4.6 (το καθένα με παραλλαγές default/low/medium/high)
- Άλλα: GPT-OSS 120B Medium
- **Το Claude Sonnet 5 ΔΕΝ είναι διαθέσιμο** — υποστηρίζονται μόνο οι παραλλαγές 4.6

**Γιατί διαφέρει ο κατάλογος μοντέλων**: Το CLI της Google είναι «βελτιστοποιημένο για ταχύτητα και χαμηλή επιβάρυνση» και «συν-βελτιστοποιημένο με τα μοντέλα Gemini» (σύμφωνα με το επίσημο ιστολόγιο της Google). Το προϊόν Web/IDE είναι «βελτιστοποιημένο για πληρότητα». Το CLI χρησιμοποιεί το `:fetchAvailableModels` για τη δυναμική ανακάλυψη μοντέλων, ενώ το IDE χρησιμοποιεί μια στατική επιμελημένη λίστα.

**Στην πράξη**: Χρησιμοποιήστε το πρόθεμα `agy/` για τα μοντέλα Gemini (π.χ. `agy/gemini-3.7-flash-high`). Χρησιμοποιήστε το `antigravity/` για τη στατική επιμελημένη λίστα. Και τα δύο χρησιμοποιούν το ίδιο σύστημα υποστήριξης της Google, αλλά διαθέτουν διαφορετική ονομασία μοντέλων. Το όριο χρήσης είναι κοινό — η χρήση οποιουδήποτε από τους δύο παρόχους προσμετράται στα ίδια όρια του λογαριασμού Google.

## 2. Google One AI Pro: Σύστημα ποσοστώσεων

> Ανατρέξτε στην [Τεκμηρίωση του Antigravity: Προγράμματα](https://antigravity.google/docs/plans) για τις επίσημες λεπτομέρειες των ποσοστώσεων και στο [Αλλαγές στα προγράμματα του Antigravity](https://antigravity.google/blog/changes-to-antigravity-plans) για τις πιο πρόσφατες ενημερώσεις τιμών.

Το Google Antigravity χρησιμοποιεί μια **ποσόστωση δύο επιπέδων** που βασίζεται στην «Εργασία που εκτελέστηκε» (υπολογιστικό βάρος) και όχι στον αριθμό μηνυμάτων.

### Τα δύο επίπεδα

| Επίπεδο                  | Τι είναι                                        | Κύκλος ανανέωσης                                                                               |
| ------------------------ | ----------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Κύκλος 5 ωρών**        | Άμεσα διαθέσιμο απόθεμα «εκτελεσμένης εργασίας» | Μηδενίζεται 5 ώρες μετά το πρώτο αίτημα σε μια περίοδο λειτουργίας                             |
| **Βασικό όριο 7 ημερών** | Εβδομαδιαίο απόλυτο όριο                        | Υπερισχύει της ανανέωσης των 5 ωρών εάν εξαντληθεί· κλειδώνει έως την επόμενη περίοδο 7 ημερών |

**Πώς υπολογίζεται η «Εργασία που εκτελέστηκε»**: Οι εργασίες με έντονη χρήση agent (π.χ. «Αναδιαμόρφωσε ολόκληρο αυτό το αποθετήριο») εξαντλούν την ποσόστωση πολύ πιο γρήγορα από τις απλές εργασίες (π.χ. «Διόρθωσε αυτήν τη συνάρτηση»). Δεν υπάρχει πίνακας ελέγχου σε πραγματικό χρόνο που να εμφανίζει την κατανάλωση.

### Επίπεδα προγραμμάτων

| Πρόγραμμα    | Τιμή       | Ποσόστωση                                      | Εβδομαδιαίο όριο                                     |
| ------------ | ---------- | ---------------------------------------------- | ---------------------------------------------------- |
| Free         | $0         | Ουσιαστική ποσόστωση, ανανεώνεται εβδομαδιαίως | Ναι                                                  |
| AI Pro       | $19.99/mo  | Υψηλή ποσόστωση, κυλιόμενη ανανέωση 5 ωρών     | Ναι (υπερισχύει της ανανέωσης 5 ωρών εάν εξαντληθεί) |
| AI Ultra 5x  | $99.99/mo  | 5x την ποσόστωση του Pro                       | Χωρίς εβδομαδιαίο όριο                               |
| AI Ultra 20x | $199.99/mo | 20x την ποσόστωση του Pro                      | Χωρίς εβδομαδιαίο όριο                               |

### Μοντέλα Gemini έναντι μοντέλων εκτός Gemini

- **Μοντέλα Gemini** (Flash + Pro): Μοιράζονται ένα ενιαίο όριο ρυθμού, το οποίο καταναλώνεται βάσει της τιμολόγησης του API. Εάν το Flash είναι 8x φθηνότερο από το Pro, λαμβάνετε 8x περισσότερα token του Flash.
- **Μοντέλα εκτός Gemini** (Claude, GPT-OSS): Διαθέτουν **ξεχωριστά** όρια ρυθμού. Ενδέχεται να παραμένουν διαθέσιμα ακόμα και όταν το Gemini είναι κλειδωμένο.

### Πιστώσεις AI (Υπέρβαση ορίου)

> Ανατρέξτε στις [πιστώσεις AI του Google One](https://support.google.com/googleone/answer/14534406) για να δείτε πώς λειτουργούν οι πιστώσεις.

Όταν εξαντληθεί η βασική ποσόστωση:

- **Ποτέ**: Αναμονή μέχρι να ανανεωθεί η ποσόστωση· εμφανίζει «Εξαντλήθηκε η βασική ποσόστωση μοντέλου»
- **Πάντα**: Αυτόματη χρήση πιστώσεων AI· επιστρέφει στη βασική ποσόστωση όταν αυτή ανανεωθεί

Οι πιστώσεις αγοράζονται ξεχωριστά και αφαιρούνται σύμφωνα με την τυπική τιμολόγηση του API.

### Βασικές λεπτομέρειες

- Η ποσόστωση είναι **κοινόχρηστη σε επίπεδο λογαριασμού** — ο ίδιος λογαριασμός Google στο Antigravity IDE, στο CLI και στο OmniRoute μοιράζεται ένα κοινό απόθεμα ποσόστωσης
- Κάθε λογαριασμός Google έχει τη δική του ανεξάρτητη ποσόστωση — πολλοί λογαριασμοί = πολλά αποθέματα ποσόστωσης
- Χρήστες του AI Pro έχουν αναφέρει **κλειδώματα 7 ημερών** αντί για επαναφορές ανά 5 ώρες όταν εξαντλείται το εβδομαδιαίο βασικό όριο (η Google επιβεβαίωσε ότι αυτό είναι σκόπιμο για περιόδους υψηλής ζήτησης)

**Όταν εξαντλείται η ποσόστωση του λογαριασμού σας**: Το OmniRoute επαναλαμβάνει αυτόματα την προσπάθεια με τον επόμενο διαθέσιμο λογαριασμό στη συνδυαστική διαδρομή. Δεν απαιτείται μη αυτόματη παρέμβαση.

## 3. Πώς να αποκτήσετε ένα projectId

Κάθε σύνδεση antigravity/agy χρειάζεται ένα `projectId` του Google Cloud Code. Χωρίς αυτό, το endpoint `/v1internal:models` επιστρέφει 404.

### Μέθοδος A: Αυτόματα (Συνιστάται)

Το OmniRoute το διαχειρίζεται αυτόματα. Όταν προσθέτετε έναν νέο λογαριασμό Google μέσω OAuth στον Πίνακα ελέγχου:

1. Το OmniRoute ανανεώνει το token
2. Καλεί το `loadCodeAssist` για να εντοπίσει το projectId
3. Εάν δεν υπάρχει έργο, καλεί το `onboardUser` για να δημιουργήσει ένα
4. Επαναλαμβάνει την κλήση του `loadCodeAssist` για να λάβει το projectId που μόλις δημιουργήθηκε
5. Το αποθηκεύει στη βάση δεδομένων

**Αυτό λειτουργεί για τους περισσότερους λογαριασμούς** — δεν απαιτούνται μη αυτόματα βήματα.

### Μέθοδος B: Μη αυτόματα μέσω του agy CLI

Εάν ο αυτόματος εντοπισμός αποτύχει (ανατρέξτε στην Ενότητα 5 για το πότε συμβαίνει αυτό):

```bash
# Εγκαταστήστε το agy CLI (εάν δεν είναι ήδη εγκατεστημένο)
npm install -g @anthropic-ai/agy

# Συνδεθείτε με τον λογαριασμό σας Google
agy login

# Επιλέξτε τον λογαριασμό που χρειάζεται αρχική ρύθμιση
# Αυτό ενεργοποιεί την εγγραφή στο Cloud Code και εκχωρεί ένα projectId
```

Αφού ολοκληρωθεί επιτυχώς το `agy login`, ανανεώστε το token στον Πίνακα ελέγχου του OmniRoute. Το projectId θα εντοπιστεί αυτόματα.

### Πώς να το επαληθεύσετε

Ελέγξτε τη βάση δεδομένων:

```bash
# Μέσα στο container του OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Εναλλακτικά, ελέγξτε τα αρχεία καταγραφής:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. URI ανακατεύθυνσης OAuth

### Το πρόβλημα

Το Google OAuth απαιτεί ένα έγκυρο URI ανακατεύθυνσης. Η προεπιλεγμένη ρύθμιση του OmniRoute χρησιμοποιεί το `http://127.0.0.1:20128/callback` (loopback). Αυτό λειτουργεί για τοπικά builds, αλλά **αποτυγχάνει σε απομακρυσμένες αναπτύξεις** (π.χ. σε έναν διακομιστή στον οποίο αποκτάτε πρόσβαση μέσω IP LAN).

Η Google απορρίπτει URI ανακατεύθυνσης που:

- Χρησιμοποιούν διευθύνσεις IP (πρέπει να είναι domain που τελειώνει σε `.com`, `.org` κ.λπ.)
- Δεν αντιστοιχούν στα καταχωρισμένα URI ανακατεύθυνσης στη διαμόρφωση του πελάτη OAuth

### Η λύση

**Επιλογή A: Χρήση της ενσωματωμένης ροής OAuth (προεπιλογή)**

- Λειτουργεί όταν αποκτάτε πρόσβαση στο OmniRoute από `localhost` ή `127.0.0.1`
- Δεν απαιτείται διαμόρφωση

**Επιλογή B: Προσαρμοσμένα διαπιστευτήρια OAuth**

- Ορίστε το `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` στο περιβάλλον σας
- Παρέχετε τα δικά σας διαπιστευτήρια Google OAuth:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Καταχωρίστε το `https://your-domain.com/callback` ως εξουσιοδοτημένο URI ανακατεύθυνσης στο Google Cloud Console

**Επιλογή C: Χρήση του agy CLI για την αρχική σύνδεση**

- Εκτελέστε το `agy login` στο μηχάνημα που θα αποκτά πρόσβαση στο OmniRoute
- Η ροή OAuth ολοκληρώνεται τοπικά και τα token αποθηκεύονται
- Εισαγάγετε τη σύνδεση στο OmniRoute μέσω του Dashboard

### Περιορισμοί

- Τα προσαρμοσμένα διαπιστευτήρια OAuth απαιτούν όνομα domain (η Google δεν αποδέχεται διευθύνσεις IP ως URI ανακατεύθυνσης)
- Αν δεν διαθέτετε domain, χρησιμοποιήστε αντ' αυτού την Επιλογή A ή C

## 5. Αντιμετώπιση προβλημάτων: Όταν η αυτόματη ρύθμιση αποτυγχάνει

Το OmniRoute χειρίζεται αυτόματα τον εντοπισμό του projectId και την αρχική ρύθμιση για τους περισσότερους λογαριασμούς. Όταν αποτυγχάνει, η βασική αιτία είναι συνήθως μία από τις ακόλουθες:

### Η περιοχή του λογαριασμού είναι αποκλεισμένη

**Σύμπτωμα**: Το `agy login` επιστρέφει «Ο έλεγχος καταλληλότητας απέτυχε: Ο τρέχων λογαριασμός σας δεν είναι κατάλληλος για το Antigravity, επειδή δεν είναι διαθέσιμο αυτήν τη στιγμή στην τοποθεσία σας.»

**Βασική αιτία**: Οι λογαριασμοί Google διαθέτουν ένα πεδίο «Country Association» στο backend, το οποίο ορίζεται κατά την εγγραφή. Το agy CLI και το Cloud Code API ελέγχουν αυστηρά αυτό το πεδίο — σε αντίθεση με το web Gemini, το οποίο ελέγχει μόνο την τρέχουσα IP σας.

> Για να ελέγξετε ή να αλλάξετε τη συσχετισμένη περιοχή του λογαριασμού σας, επισκεφθείτε τη [Φόρμα συσχέτισης χώρας της Google](https://policies.google.com/country-association-form).

**Γιατί το web Gemini λειτουργεί, αλλά το agy όχι**:

- Web Gemini / Google One: ελέγχει μόνο την τρέχουσα IP (ο proxy επαρκεί)
- agy CLI / Cloud Code API: διαβάζει το πεδίο Country Association του backend (ο proxy δεν βοηθά)

**Διόρθωση**:

1. Επισκεφθείτε τη [Φόρμα συσχέτισης χώρας της Google](https://policies.google.com/country-association-form) ενώ χρησιμοποιείτε IP των ΗΠΑ
2. Υποβάλετε αίτημα αλλαγής περιοχής (επιλέξτε «Ζω σε διαφορετική χώρα»)
3. Περιμένετε 1-24 ώρες για την επεξεργασία από την Google και την ειδοποίηση μέσω email
4. Στη συνέχεια, το `agy login` θα πρέπει να ολοκληρωθεί με επιτυχία

### Ο λογαριασμός δεν διαθέτει έργο Cloud Code

**Σύμπτωμα**: Τα αρχεία καταγραφής εμφανίζουν `loadCodeAssist returned no project id` και `onboardUser failed (400)`.

**Βασική αιτία**: Ο λογαριασμός δεν έχει καταχωριστεί ποτέ στο Google Cloud Code και η αυτόματη αρχική ρύθμιση απέτυχε.

**Διόρθωση**: Εκτελέστε χειροκίνητα το `agy login` για να ενεργοποιήσετε την εγγραφή στο Cloud Code και, στη συνέχεια, ανανεώστε το token στο Dashboard του OmniRoute.

### Το token έχει λήξει ή ανακληθεί

**Σύμπτωμα**: Σφάλματα 401 στα αρχεία καταγραφής ή μηνύματα «Το token έχει λήξει».

**Διόρθωση**: Ανανεώστε το token από Dashboard → Providers → agy → Κάντε κλικ στο εικονίδιο ανανέωσης. Αν έχει ανακληθεί το ίδιο το refresh token, θα χρειαστεί να πραγματοποιήσετε εκ νέου έλεγχο ταυτότητας μέσω OAuth.

```
│  ├─ ΝΑΙ → Αλλάξτε περιοχή στη Φόρμα συσχέτισης χώρας της Google
│  │         (https://policies.google.com/country-association-form)
│  │         Περιμένετε 1-24 ώρες και, στη συνέχεια, δοκιμάστε ξανά
│  └─ ΟΧΙ ↓

│  ├─ ΟΧΙ → Εγγραφείτε πρώτα στο one.google.com
│  └─ ΝΑΙ ↓
│
├─ Δοκιμάστε την αυτόματη ανακάλυψη (ανανεώστε το token στον Πίνακα ελέγχου)

│  └─ Εξακολουθεί να αποτυγχάνει ↓

   ├─ Λειτουργεί → Ανανεώστε το token στον Πίνακα ελέγχου, το projectId εντοπίστηκε
   └─ Αποτυγχάνει → Ελέγξτε το μήνυμα σφάλματος· πιθανότατα πρόκειται για ζήτημα περιοχής ή συνδρομής
```
