Συνδέστε το CLI του **Claude Code** (`claude`) με το OmniRoute — τοπικά ή σε ένα απομακρυσμένο VPS —
με προφίλ ανά μοντέλο, ακολουθώντας τη διαμόρφωση του Codex.

---

## Γρήγορη εκκίνηση

```bash
# Εκκίνηση του Claude Code με ένα τοπικό OmniRoute (εντοπίζει αυτόματα το ενεργό context)
omniroute launch

# Με ένα απομακρυσμένο OmniRoute (μετά το `omniroute connect <host>`, αυτό γίνεται αυτόματα)
omniroute launch --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Δημιουργία προφίλ ανά μοντέλο και, στη συνέχεια, εκκίνηση ενός από αυτά
omniroute setup-claude            # γράφει στο ~/.claude/profiles/<name>/settings.json
omniroute launch --profile glm52  # Claude Code που χρησιμοποιεί το glm/glm-5.2 μέσω OmniRoute
```

## Πώς συνδέεται το Claude Code με μια πύλη

Το Claude Code επικοινωνεί μέσω του **Anthropic Messages API** και κατευθύνεται σε ένα προσαρμοσμένο
endpoint με μεταβλητές περιβάλλοντος (δεν διαθέτει σημαία `--base-url`):

| Μεταβλητή                                    | Σκοπός                                                                                                      |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `ANTHROPIC_BASE_URL`                         | Ριζικό URL της πύλης (το Claude Code προσθέτει `/v1/messages`). **Χωρίς επίθημα `/v1`.**                    |
| `ANTHROPIC_AUTH_TOKEN`                       | Αποστέλλεται ως `Authorization: Bearer …` — χρησιμοποιήστε το access token / API key του OmniRoute          |
| `ANTHROPIC_API_KEY`                          | Εναλλακτικά: αποστέλλεται ως `x-api-key`. Αν έχουν οριστεί και τα δύο, υπερισχύει το `ANTHROPIC_AUTH_TOKEN` |
| `ANTHROPIC_MODEL`                            | Επιβάλλει ένα συγκεκριμένο μοντέλο (παρακάμπτει την προεπιλογή του επιλογέα `/model`)                       |
| `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY` | `1` → ο εγγενής επιλογέας `/model` εμφανίζει μοντέλα `claude*`/`anthropic*` από το `/v1/models`             |
| `CLAUDE_CODE_MAX_OUTPUT_TOKENS`              | Περιορίζει τα token εξόδου ανά απόκριση (π.χ. `65536`)                                                      |
| `CLAUDE_CODE_AUTO_COMPACT_WINDOW`            | Όριο token για αυτόματη συμπύκνωση                                                                          |

> Οι μεταβλητές περιβάλλοντος διαβάζονται **μία φορά κατά την εκκίνηση** — επανεκκινήστε το Claude Code αφού τις αλλάξετε.

Το `omniroute launch` ορίζει όλα τα παραπάνω για εσάς: επιλύει το βασικό URL + token
από το ενεργό context (επομένως, μετά τα `omniroute connect <vps>` και `omniroute launch`
όλα λειτουργούν άμεσα), ελέγχει την κατάσταση του διακομιστή και εκτελεί το `claude`.

## Ψευδώνυμα εντοπισμού — εμφάνιση μοντέλων που δεν είναι Claude στον επιλογέα `/model`

Ο εντοπισμός μοντέλων πύλης του Claude Code εμφανίζει μόνο id που αρχίζουν με `claude`
ή `anthropic`, επομένως με `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` ο εγγενής
επιλογέας `/model` συνήθως εμφανίζει **μόνο** τα μοντέλα Claude/Anthropic του OmniRoute — ένα
`kimi/kimi-k2.6` ή `glm/glm-5.2` δεν εμφανίζεται ποτέ, παρότι δρομολογείται κανονικά.

Το OmniRoute μπορεί να κατοπτρίσει οποιοδήποτε ενεργοποιημένο μοντέλο (και combo) κάτω από ένα id `claude/…`, ώστε να
περνά αυτό το φίλτρο και να εμφανίζεται στον επιλογέα:

```
kimi/kimi-k2.6            →  claude/kimi/kimi-k2.6      "Kimi K2.6 (OmniRoute)"
glm/glm-5.2              →  claude/glm/glm-5.2         "GLM 5.2 (OmniRoute)"
<combo "custo-otimizado"> →  claude/combo/custo-otimizado
```

Όταν επιλέγετε ένα από αυτά στο Claude Code, το OmniRoute αφαιρεί το περίβλημα `claude/`
και επαναφέρει το πραγματικό id πριν από τη δρομολόγηση — ένα γνήσιο id `claude/<real-claude-model>`
(από τον πραγματικό πάροχο Claude OAuth) παραμένει πάντοτε ανέπαφο.

**Αυτό είναι απενεργοποιημένο από προεπιλογή** και ελέγχεται από μια πύλη τριών επιπέδων (υπερισχύει
το πιο συγκεκριμένο), ώστε ένα απλό OmniRoute να μην διπλασιάζει ποτέ τον κατάλογό του για πελάτες που δεν χρησιμοποιούν
το Claude Code:

| Επίπεδο  | Πού                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------- |
| Μοντέλο  | Σελίδα λεπτομερειών παρόχου → διακόπτης "Έκθεση στο Claude Code" ανά μοντέλο                      |
| Πάροχος  | Σελίδα λεπτομερειών παρόχου → διακόπτης επιπέδου παρόχου (καλύπτει όλα τα μοντέλα του)            |
| Καθολικό | Ρυθμίσεις → Σημαίες λειτουργιών → `EXPOSE_CC_DISCOVERY_ALIASES` (απενεργοποιημένο από προεπιλογή) |

Η μεταβλητή περιβάλλοντος `EXPOSE_CC_DISCOVERY_ALIASES` επιβάλλει την ενεργοποίηση του καθολικού επιπέδου
και υπερισχύει της παράκαμψης του πίνακα ελέγχου (η οθόνη Σημαιών λειτουργιών εμφανίζει
μια σημείωση "ενεργό μέσω μεταβλητής περιβάλλοντος" όταν συμβαίνει αυτό). Οι διακόπτες ανά πάροχο και
ανά μοντέλο εξειδικεύουν περαιτέρω τη ρύθμιση — π.χ. καθολική απενεργοποίηση + ενεργοποίηση του παρόχου Kimi εκθέτει
μόνο τα μοντέλα του Kimi.

> ⚠️ **Αναντιστοιχία παραθύρου σε μοντέλα που δεν είναι Claude.** Το Claude Code υποθέτει ένα παράθυρο context 200K
> για οποιοδήποτε id δεν αναγνωρίζει (δεν μπορεί να διαβάσει το πραγματικό παράθυρο από το
> `/v1/models`). Για ένα μοντέλο με μεγαλύτερο παράθυρο (π.χ. 256K του Kimi K2), ορίστε το
> `CLAUDE_CODE_AUTO_COMPACT_WINDOW` σε μια τιμή χαμηλότερη από το πραγματικό παράθυρο του μοντέλου, ώστε
> η αυτόματη συμπύκνωση να μην ενεργοποιείται πρόωρα. Τα προφίλ που δημιουργούνται παραπάνω το κάνουν ήδη
> αυτό ανά μοντέλο.

## Ενότητα αρχικής ρύθμισης στον πίνακα ελέγχου

Η κάρτα εργαλείου Claude (**Πίνακας ελέγχου → Κώδικας CLI**) εμφανίζει το ακριβές τμήμα του `settings.json`
για αυτή την εγκατάσταση, δίπλα στο κουμπί πληροφοριών για το ψευδώνυμο εντοπισμού, μαζί με ένα κουμπί αντιγραφής:

```jsonc
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://<your OmniRoute>:20128",
    "ANTHROPIC_AUTH_TOKEN": "<your OmniRoute API key>",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
  },
}
```

Η βασική διεύθυνση URL είναι αυτή που προσδιορίζει η κάρτα (συμπεριλαμβανομένης μιας προσαρμοσμένης παράκαμψης που πληκτρολογήσατε), ήδη
κανονικοποιημένη — χωρίς επίθημα `/v1` και χωρίς τελική κάθετο. **Το κλειδί δεν εμφανίζεται ποτέ**: η ενότητα περιλαμβάνει ένα
σύμβολο κράτησης θέσης, ώστε ένα στιγμιότυπο οθόνης ή ένα επικολλημένο απόσπασμα να μην μπορεί να το διαρρεύσει. Επικολλήστε το κλειδί σας στη θέση του.

Προσθέστε το `CLAUDE_CODE_AUTO_COMPACT_WINDOW` κάτω από την ίδια ενότητα `env` για κάθε μοντέλο του οποίου το πραγματικό
παράθυρο περιβάλλοντος δεν είναι 200K — το Claude Code θεωρεί ότι είναι 200K για κάθε id που δεν αναγνωρίζει, επομένως
διαφορετικά η αυτόματη συμπύκνωση ενεργοποιείται σε λάθος σημείο (δείτε την προειδοποίηση στην προηγούμενη ενότητα).
Το εργαλείο δημιουργίας αποσπάσματος δέχεται επίσης αυτή την τιμή, ώστε ένας καλών που γνωρίζει το παράθυρο του μοντέλου-στόχου
να μπορεί να τη συμπεριλάβει απευθείας.

Πηγή: `src/shared/services/claudeCliConfig.ts::buildClaudeDiscoverySettingsSnippet` (αμιγές
εργαλείο δημιουργίας, ελεγμένο με δοκιμές μονάδας), το οποίο αποδίδεται από το `ClaudeGatewayOnboardingBlock`.

## Προφίλ (`CLAUDE_CONFIG_DIR`)

Το Claude Code **δεν διαθέτει εγγενή αρχεία προφίλ** (σε αντίθεση με το `~/.codex/<name>.config.toml` του Codex).
Ο καθιερωμένος μηχανισμός είναι το `CLAUDE_CONFIG_DIR` — ένας ξεχωριστός κατάλογος ρυθμίσεων για κάθε
προφίλ, καθένας με το δικό του `settings.json`, διαπιστευτήρια, ιστορικό και προσωρινή μνήμη.

Το `omniroute setup-claude` ανακτά τον ενεργό κατάλογο `/v1/models` και δημιουργεί ένα
προφίλ ανά μοντέλο στη διαδρομή `~/.claude/profiles/<name>/settings.json`, επαναχρησιμοποιώντας τα
**ίδια ονόματα με το `setup-codex`** (`glm52`, `kimi-k27`, `deepseek-pro`, …):

```jsonc
// ~/.claude/profiles/glm52/settings.json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "model": "glm/glm-5.2",
  "effortLevel": "xhigh",
  "env": {
    "ANTHROPIC_BASE_URL": "http://192.168.0.15:20128",
    "ANTHROPIC_MODEL": "glm/glm-5.2",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "190000",
  },
}
```

> **Το διακριτικό ελέγχου ταυτότητας δεν εγγράφεται ποτέ στο προφίλ.** Εκκινήστε με
> `omniroute launch --profile <name>` (εισάγει το `ANTHROPIC_AUTH_TOKEN` από το
> ενεργό περιβάλλον) ή εξαγάγετε μόνοι σας το `ANTHROPIC_AUTH_TOKEN` και εκτελέστε
> `CLAUDE_CONFIG_DIR=~/.claude/profiles/<name> claude`.

**Αυτόματος συγχρονισμός μετά τον εντοπισμό μοντέλων (προαιρετικός).** Το OmniRoute μπορεί να αναδημιουργεί αυτόματα τα ίδια
αρχεία `~/.claude/profiles/<name>/settings.json` κάθε φορά που ένας συγχρονισμός μοντέλων παρόχου
αλλάζει τον ενεργό κατάλογο — έτσι τα νέα ή μετονομασμένα μοντέλα αποκτούν προφίλ χωρίς να απαιτείται εκ νέου εκτέλεση της
εντολής. Είναι **απενεργοποιημένος από προεπιλογή**: ενεργοποιήστε τον από τον **πίνακα ελέγχου Κώδικα CLI** ("Αυτόματος συγχρονισμός
προφίλ CLI" → Claude Code) ή ορίστε `OMNIROUTE_AUTO_SYNC_CLAUDE_PROFILES=true` (λαμβάνει επίσης υπόψη το
`CLI_ALLOW_CONFIG_WRITES`, το οποίο είναι ενεργοποιημένο από προεπιλογή). Όταν είναι ενεργοποιημένος, δημιουργεί μόνο αρχεία προφίλ· δεν
αλλάζει ποτέ την ενεργή/προεπιλεγμένη ρύθμιση του Claude, τον έλεγχο ταυτότητας ή το `~/.claude/settings.json`.

### Δημιουργία + χρήση προφίλ

```bash
# Τοπικό OmniRoute
omniroute setup-claude

# Απομακρυσμένο VPS (ενσωματώνει τη διεύθυνση URL του VPS σε κάθε προφίλ)
omniroute setup-claude --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Μόνο ορισμένοι πάροχοι
omniroute setup-claude --only glm,kimi

# Προεπισκόπηση χωρίς εγγραφή
omniroute setup-claude --dry-run

# Εκκίνηση ενός προφίλ
omniroute launch --profile kimi-k27
```

## Επίπεδα μοντέλων (προαιρετικά)

Το Claude Code δρομολογεί σε επίπεδα δυνατοτήτων. Αντιστοιχίστε κάθε επίπεδο σε ένα μοντέλο OmniRoute μέσω μεταβλητών περιβάλλοντος /
ρυθμίσεων, αν θέλετε διαφορετικούς παρόχους ανά επίπεδο:

```bash
export ANTHROPIC_DEFAULT_OPUS_MODEL="glm/glm-5.2"
export ANTHROPIC_DEFAULT_SONNET_MODEL="kmc/kimi-k2.6"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="glm/glm-4.7-flash"
```

Διαφορετικά, χρησιμοποιείται για όλα ένα μόνο `ANTHROPIC_MODEL` (αυτό που ορίζουν τα προφίλ).

## Απομακρυσμένη λειτουργία

Αφού εκτελέσετε `omniroute connect <host>` (δείτε την
[Απομακρυσμένη λειτουργία](./REMOTE-MODE.md)), τα `omniroute launch` και `omniroute setup-claude`
στοχεύουν αυτόματα εκείνον τον απομακρυσμένο διακομιστή και χρησιμοποιούν το διακριτικό πρόσβασης περιορισμένης εμβέλειάς του — δεν
απαιτούνται πρόσθετες σημαίες. Παρακάμψτε τη ρύθμιση ανά εκτέλεση με `--remote` / `--api-key`.

## Αντιμετώπιση προβλημάτων

**Το Claude Code αγνοεί την πύλη** — επιβεβαιώστε ότι το `ANTHROPIC_BASE_URL` **δεν
περιέχει `/v1`** και επανεκκινήστε το `claude` (οι μεταβλητές περιβάλλοντος διαβάζονται μία φορά κατά την εκκίνηση). Το `omniroute launch`
το χειρίζεται αυτό για εσάς.

**Ο επιλογέας `/model` είναι κενός / λείπουν μοντέλα της πύλης** — απαιτείται Claude Code
v2.1.219+ και `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`. Μόνο αναγνωριστικά μοντέλων `claude*` /
`anthropic*` εμφανίζονται στον επιλογέα· επιβάλετε οποιοδήποτε άλλο μοντέλο με
`ANTHROPIC_MODEL=<id>` (αυτό κάνουν τα προφίλ).

**`400 Ambiguous model 'claude-…'`** — το Claude Code στέλνει πάντα **χωρίς πρόθεμα**
αναγνωριστικά μοντέλων (π.χ. `claude-opus-4-8`), επομένως, όταν είναι συνδεδεμένοι τόσο ο πάροχος Claude Code (`cc/…`) όσο και ο
πάροχος Claude (`claude/…`), το αναγνωριστικό χωρίς πρόθεμα αντιστοιχεί σε δύο διαδρομές και το
OmniRoute αρνείται να μαντέψει. Διορθώστε το με έναν από τους εξής τρόπους: καθορίστε ένα αναγνωριστικό με πρόθεμα μέσω
`ANTHROPIC_MODEL=cc/claude-opus-4-8` ή ενεργοποιήστε την επιλογή **Προτίμηση του Claude Code για
μοντέλα Claude χωρίς πρόθεμα** — τον διακόπτη στη σελίδα του παρόχου Claude ή
`OMNIROUTE_PREFER_CLAUDE_CODE_FOR_UNPREFIXED_CLAUDE_MODELS=true` (απενεργοποιημένο από προεπιλογή·
δείτε το [Περιβάλλον](../reference/ENVIRONMENT.md)) — η οποία δρομολογεί τα αναγνωριστικά `claude-*` χωρίς πρόθεμα
στο Claude Code. Τα ρητά προθέματα παρόχων υπερισχύουν πάντα.

**Σφάλματα ελέγχου ταυτότητας** — το προφίλ δεν περιέχει διακριτικό. Χρησιμοποιήστε `omniroute launch --profile`
(το εισάγει) ή εξαγάγετε το `ANTHROPIC_AUTH_TOKEN`.

**Τα προφίλ δεν απομονώνονται** — κάθε προφίλ είναι ένας ξεχωριστός `CLAUDE_CONFIG_DIR`·
επαληθεύστε ότι το `echo $CLAUDE_CONFIG_DIR` μέσα στη συνεδρία παραπέμπει στο
`~/.claude/profiles/<name>`.
