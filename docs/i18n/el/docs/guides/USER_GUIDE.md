## 🎯 Περιπτώσεις Χρήσης

### Περίπτωση 1: «Έχω συνδρομή Claude Pro»

**Πρόβλημα:** Το όριο λήγει αναξιοποίητο, περιορισμοί ρυθμού κατά την έντονη κωδικοποίηση

```
Combo: "maximize-claude"
  1. cc/claude-opus-4-7        # (πλήρης αξιοποίηση συνδρομής)
  2. glm/glm-4.7               # (φθηνό εφεδρικό όταν εξαντληθεί το όριο)
  3. if/qwen3.8-max-preview       # (δωρεάν εφεδρικό έκτακτης ανάγκης)

Μηνιαίο κόστος: $20 (συνδρομή) + ~$5 (εφεδρικό) = $25 συνολικά
αντί για: $20 + χτύπημα ορίων = απογοήτευση
```

### Περίπτωση 2: «Θέλω μηδενικό κόστος»

**Πρόβλημα:** Δεν μπορώ να αντέξω συνδρομές, χρειάζομαι αξιόπιστη AI κωδικοποίηση

```
Combo: "zero-cost"
  1. if/kimi-k2.7-code          # (καταχωρημένη δωρεάν πρόσβαση· ενδέχεται να ισχύουν όρια ρυθμού)
  2. kr/qwen3-coder-next        # (δωρεάν εφεδρικό Kiro)

Μηνιαίο κόστος: $0
Ποιότητα: επαληθεύστε το μοντέλο, τα όρια, την ιδιωτικότητα και το SLA για τον φόρτο εργασίας σας
```

### Περίπτωση 3: «Χρειάζομαι κωδικοποίηση 24/7, χωρίς διακοπές»

**Πρόβλημα:** Προθεσμίες, δεν αντέχω διακοπή λειτουργίας

```
Combo: "always-on"
  1. cc/claude-opus-4-7        # (καλύτερη ποιότητα)
  2. cx/gpt-5.5                # (δεύτερη συνδρομή)
  3. glm/glm-4.7               # (φθηνό, επαναφορά καθημερινά)
  4. minimax/MiniMax-M2.1      # (φθηνότατο, επαναφορά 5ω)
  5. if/deepseek-v4-flash       # (καταχωρημένη δωρεάν πρόσβαση· ενδέχεται να ισχύουν όρια ρυθμού)

Αποτέλεσμα: 5 επίπεδα εφεδρικών διευρύνουν την ανθεκτικότητα· η διαθεσιμότητα upstream δεν εγγυάται
Μηνιαίο κόστος: $20-200 (συνδρομές) + $10-20 (εφεδρικό)
```

### Περίπτωση 4: «Θέλω ΔΩΡΕΑΝ AI στο OpenClaw»

**Πρόβλημα:** Χρειάζομαι AI βοηθό σε εφαρμογές μηνυμάτων, εντελώς δωρεάν

```
Combo: "openclaw-free"
  1. if/qwen3.8-max-preview     # (καταχωρημένη δωρεάν πρόσβαση· ενδέχεται να ισχύουν όρια ρυθμού)
  2. if/deepseek-v4-flash       # (καταχωρημένη δωρεάν πρόσβαση· ενδέχεται να ισχύουν όρια ρυθμού)
  3. if/kimi-k2.7-code          # (καταχωρημένη δωρεάν πρόσβαση· ενδέχεται να ισχύουν όρια ρυθμού)

Μηνιαίο κόστος: $0
Πρόσβαση μέσω: WhatsApp, Telegram, Slack, Discord, iMessage, Signal...
```

## 📖 Ρύθμιση παρόχων

Για μαζική προσθήκη συνδέσεων κλειδιών API από αρχείο CSV ή JSON, χρησιμοποιήστε τη διαδρομή **Πίνακας ελέγχου → Πάροχοι → Εισαγωγή από αρχείο**. Οι στήλες είναι ταξινομημένες κατά θέση (`provider,name,apiKey,baseUrl,priority`)· το `provider` πρέπει να υπάρχει ήδη ως διαχειριζόμενος πάροχος ή συμβατός κόμβος. Δείτε την ενότητα [Εισαγωγή παρόχων από αρχείο CSV ή JSON](../providers/CSV-IMPORT.md).

### 🔐 Συνδρομητικοί πάροχοι

#### Claude Code (Pro/Max)

```bash
Πίνακας ελέγχου → Πάροχοι → Σύνδεση Claude Code
→ Σύνδεση μέσω OAuth → Αυτόματη ανανέωση token
→ Παρακολούθηση ορίου 5 ωρών + εβδομαδιαίου ορίου

Μοντέλα:
  cc/claude-opus-4-7
  cc/claude-sonnet-4-6
  cc/claude-haiku-4-5-20251001
```

**Επαγγελματική συμβουλή:** Χρησιμοποιήστε το Opus για σύνθετες εργασίες και το Sonnet για ταχύτητα. Το OmniRoute παρακολουθεί το όριο ανά μοντέλο!

Δεν υπάρχει πρόγραμμα περιήγησης στον κεντρικό υπολογιστή του OmniRoute; Εκτελέστε το `claude setup-token` οπουδήποτε είναι συνδεδεμένο το Claude Code και επικολλήστε το token διάρκειας ενός έτους στην καρτέλα **Setup Token**. Δείτε την ενότητα [Claude Code με setup token](../providers/CLAUDE_CODE_SETUP_TOKEN.md).

Οι διαδρομές που είναι συμβατές με Claude και Claude Code διατηρούν την προσπάθεια συλλογισμού `max` για τα μοντέλα Opus και Sonnet. Τα μοντέλα Haiku δεν αποδέχονται το επίπεδο προσπάθειας `max`, επομένως το OmniRoute υποβαθμίζει αυτό το αίτημα σε υψηλό προϋπολογισμό συλλογισμού πριν το στείλει στον upstream πάροχο.

### 💰 Οικονομικοί πάροχοι

#### GLM-4.7 (Καθημερινή επαναφορά, $0.6/1M)

1. Εγγραφείτε: [Zhipu AI](https://open.bigmodel.cn)
2. Αποκτήστε κλειδί API από το Coding Plan
3. Πίνακας ελέγχου → Προσθήκη κλειδιού API: Πάροχος: `glm`, Κλειδί API: `your-key`

**Χρήση:** `glm/glm-4.7` — **Επαγγελματική συμβουλή:** Το Coding Plan προσφέρει 3× μεγαλύτερο όριο με το 1/7 του κόστους! Καθημερινή επαναφορά στις 10:00 π.μ.

#### MiniMax M2.1 (Επαναφορά ανά 5 ώρες, $0.20/1M)

1. Εγγραφείτε: [MiniMax](https://www.minimax.io)
2. Αποκτήστε κλειδί API → Πίνακας ελέγχου → Προσθήκη κλειδιού API

**Χρήση:** `minimax/MiniMax-M2.1` — **Επαγγελματική συμβουλή:** Η φθηνότερη επιλογή για μεγάλο context (1M tokens)!

#### Kimi K2 ($9/μήνα σταθερά)

1. Εγγραφείτε σε συνδρομή: [Moonshot AI](https://platform.kimi.ai?aff=omniroute)
2. Αποκτήστε κλειδί API → Πίνακας ελέγχου → Προσθήκη κλειδιού API

**Χρήση:** `kimi/kimi-k2.5` — **Επαγγελματική συμβουλή:** Σταθερό κόστος $9/μήνα για 10M tokens = πραγματικό κόστος $0.90/1M!

#### Baidu Qianfan / ERNIE

## 🚀 Ανάπτυξη

### Καθολική εγκατάσταση npm (Προτεινόμενη)

```bash
npm install -g omniroute

# Δημιουργία καταλόγου ρυθμίσεων
mkdir -p ~/.omniroute

# Δημιουργία αρχείου .env (δείτε .env.example)
cp .env.example ~/.omniroute/.env

# Εκκίνηση διακομιστή
omniroute
# Ή με προσαρμοσμένη θύρα:
omniroute --port 3000
```

Το CLI φορτώνει αυτόματα το `.env` από `~/.omniroute/.env` ή `./.env`.

### Λειτουργία δίσκου συστήματος (Tray)

Εκκινήστε το OmniRoute στο δίσκο συστήματος:

```bash
omniroute serve --tray
```

Η εντολή επιστρέφει μετά την ετοιμότητα του διακομιστή και του δίσκου.

Ο διακομιστής συνεχίζει χωρίς το τερματικό.

Η λειτουργία δίσκου υποστηρίζει macOS, Windows και γραφικές συνεδρίες Linux. Η λειτουργία δίσκου δεν ανοίγει αυτόματα το dashboard.

Χρησιμοποιήστε το μενού δίσκου για αυτές τις ενέργειες:

- Άνοιγμα του dashboard.
- Άνοιγμα του `/dashboard/logs`.
- Αλλαγή αυτόματης εκκίνησης.
- Διακοπή του OmniRoute.

Μη συνδυάζετε το `--tray` με αυτές τις επιλογές:

- `--daemon`
- `--log`
- `--no-recovery`

Αυτές οι λειτουργίες απαιτούν διαφορετική ιδιοκτησία διεργασίας.

Ενεργοποιήστε την εκκίνηση κατά την επόμενη σύνδεση στο μηχάνημα:

```bash
omniroute autostart enable
```

Η αυτόματη εκκίνηση χρησιμοποιεί λειτουργία δίσκου σε macOS, Windows και γραφικές συνεδρίες Linux. Το headless Linux χρησιμοποιεί την υπάρχουσα υπηρεσία χρήστη systemd.

Απενεργοποιήστε την εκκίνηση κατά τη σύνδεση:

```bash
omniroute autostart disable
```

Όταν δεν χρειάζεστε πλέον το OmniRoute, παρέχουμε δύο γρήγορα σενάρια για καθαρή αφαίρεση:

| `npm run uninstall`      | Αφαιρεί την εφαρμογή συστήματος αλλά **διατηρεί τη βάση δεδομένων και τις ρυθμίσεις σας** στο `~/.omniroute`. |
| `npm run uninstall:full` | Αφαιρεί την εφαρμογή ΚΑΙ **διαγράφει μόνιμα όλες τις ρυθμίσεις, τα κλειδιά και τις βάσεις δεδομένων**.        |

> Σημείωση: Για να εκτελέσετε αυτές τις εντολές, μεταβείτε στον φάκελο του έργου OmniRoute (εάν το κλωνοποιήσατε) και εκτελέστε τες. Εναλλακτικά, εάν είναι εγκατεστημένο καθολικά, μπορείτε απλώς να εκτελέσετε `npm uninstall -g omniroute`.

		aarch64*) _gyp_arch=arm64 ;;
		armv7*|armv6*) _gyp_arch=arm ;;
		i686*) _gyp_arch=ia32 ;;
		*) _gyp_arch=x64 ;;
	esac

	NODE_ENV=development npm ci --ignore-scripts

	# 2) Κατασκευή του μεμονωμένου bundle Next.js
	npm run build

	# 3) Αντιγραφή στατικών στοιχείων στο standalone
	cp -r .next/static .next/standalone/.next/static
	[ -d public ] && cp -r public .next/standalone/public || true

	local _node_gyp=/usr/lib/node_modules/npm/node_modules/node-gyp/bin/node-gyp.js
	(cd node_modules/better-sqlite3 && node "$_node_gyp" rebuild --arch="$_gyp_arch")

	mkdir -p "$_bs3_release"
	cp node_modules/better-sqlite3/build/Release/better_sqlite3.node "$_bs3_release/"

	# 6) Αφαίρεση πακέτων sharp ειδικών αρχιτεκτονικής
	rm -rf .next/standalone/node_modules/@img

	for _mod in pino-abstract-transport split2 process-warning; do
		cp -r "node_modules/$_mod" .next/standalone/node_modules/
	done
}

do_check() {
	npm run test:unit
}

do_install() {
	vmkdir usr/lib/omniroute/.next
	vcopy .next/standalone/. usr/lib/omniroute/.next/standalone

	# Αποτροπή αφαίρεσης κενών καταλόγων δρομολογητή Next.js app από το hook μετά την εγκατάσταση
	for _d in \
		.next/standalone/.next/server/app/dashboard \
		.next/standalone/.next/server/app/dashboard/settings \
		.next/standalone/.next/server/app/dashboard/providers; do

#!/bin/sh
export PORT="${PORT:-20128}"
export DATA_DIR="${DATA_DIR:-${XDG_DATA_HOME:-${HOME}/.local/share}/omniroute}"
export APP_LOG_TO_FILE="${APP_LOG_TO_FILE:-false}"

exec node /usr/lib/omniroute/.next/standalone/server.js "$@"
EOF
	vbin "${WRKDIR}/omniroute"
}

post_install() {
	vlicense LICENSE
}

### Προσαρμοσμένα μοντέλα

Προσθέστε οποιοδήποτε αναγνωριστικό μοντέλου σε οποιονδήποτε πάροχο χωρίς να περιμένετε ενημέρωση της εφαρμογής:

```bash
# Μέσω API
curl -X POST http://localhost:20128/api/provider-models \
  -H "Content-Type: application/json" \
  -d '{"provider": "openai", "modelId": "gpt-5.2", "modelName": "GPT-5.2"}'

# Λίστα: curl http://localhost:20128/api/provider-models?provider=openai
# Αφαίρεση: curl -X DELETE "http://localhost:20128/api/provider-models?provider=openai&model=gpt-5.2"
```

Ή χρησιμοποιήστε τον Πίνακα ελέγχου: **Πάροχοι → [Πάροχος] → Προσαρμοσμένα μοντέλα**.

Σημειώσεις:

- Η διαχείριση των παρόχων που είναι συμβατοί με OpenRouter και OpenAI/Anthropic γίνεται μόνο από τα **Διαθέσιμα μοντέλα**. Η μη αυτόματη προσθήκη, η εισαγωγή και ο αυτόματος συγχρονισμός καταλήγουν όλα στην ίδια λίστα διαθέσιμων μοντέλων, επομένως δεν υπάρχει ξεχωριστή ενότητα Προσαρμοσμένων μοντέλων για αυτούς τους παρόχους.
- Η ενότητα **Προσαρμοσμένα μοντέλα** προορίζεται για παρόχους που δεν προσφέρουν διαχειριζόμενες εισαγωγές διαθέσιμων μοντέλων.

### Προσαρμοσμένοι πάροχοι συμβατοί με OpenAI

Οποιαδήποτε πύλη υποστηρίζει το OpenAI API (ένας αυτοφιλοξενούμενος διακομιστής μεσολάβησης, το vLLM ή ένας συσσωρευτής τρίτου μέρους)
μπορεί να προστεθεί ως δικός της κόμβος παρόχου:

1. **Πάροχοι → Προσθήκη συμβατού με OpenAI**.
2. **Όνομα**: μια εμφανιζόμενη ετικέτα για τον κόμβο.
3. **Πρόθεμα**: το όνομα δρομολόγησης. Οι πελάτες καλούν τα μοντέλα ως `<prefix>/<model>`, επομένως ένας κόμβος με
   πρόθεμα `mygw` εξυπηρετεί το `mygw/gpt-4o-mini`. Απαιτείται· δεν υπάρχει περιορισμός χαρακτήρων.
4. **Τύπος API**: η οικογένεια τελικών σημείων που εξυπηρετεί η πύλη (ολοκληρώσεις συνομιλίας, αποκρίσεις,
   ενσωματώσεις, ήχος, εικόνες).
5. **Βασικό URL**: η ρίζα του API, έως και το `/v1` (για παράδειγμα
   `https://gateway.example.com/v1`), όχι η πλήρης διαδρομή `/chat/completions`. Οι πύλες με
   μη τυπικές διαδρομές τις ορίζουν στις **Προηγμένες ρυθμίσεις** (διαδρομή συνομιλίας, διαδρομή μοντέλων).
6. Το πεδίο **Κλειδί API (για έλεγχο)** ελέγχει μόνο τη σύνδεση. Αφού δημιουργήσετε τον κόμβο,
   ανοίξτε τον και χρησιμοποιήστε την επιλογή **Προσθήκη σύνδεσης** για να αποθηκεύσετε το κλειδί που θα χρησιμοποιούν τα αιτήματα.

Ο κόμβος λαμβάνει ένα εσωτερικό αναγνωριστικό της μορφής `openai-compatible-<apiType>-<uuid>`· δεν χρειάζεται ποτέ
να το πληκτρολογήσετε, καθώς το πρόθεμα είναι το δημόσιο όνομα.

#### Δεσμευμένα προθέματα

Ένα πρόθεμα δεν μπορεί να είναι το αναγνωριστικό ή το ψευδώνυμο ενός ενσωματωμένου παρόχου (για παράδειγμα `openai`, `cf`), ούτε
το αναγνωριστικό ενός παρόχου που έχει αποσυρθεί. Ο μηχανισμός επίλυσης μοντέλων ελέγχει τα ενσωματωμένα αναγνωριστικά και ψευδώνυμα πριν από
τους προσαρμοσμένους κόμβους, επομένως ένας κόμβος που χρησιμοποιεί ένα από αυτά τα προθέματα δεν θα λάμβανε ποτέ κίνηση:
το `<prefix>/model` θα κατευθυνόταν στον ενσωματωμένο πάροχο ή θα αποτύγχανε με ασφαλή τρόπο αν ο συγκεκριμένος πάροχος
είχε αποσυρθεί. Η δημιουργία ή η επεξεργασία ενός κόμβου με τέτοιο πρόθεμα απορρίπτεται με το μήνυμα:

```text
prefix: Το "<prefix>" είναι δεσμευμένο πρόθεμα παρόχου — επιλέξτε διαφορετικό πρόθεμα (τα δεσμευμένα αναγνωριστικά/ψευδώνυμα δεν μπορούν να χρησιμοποιηθούν για προσαρμοσμένους κόμβους, επειδή αιτήματα όπως το <prefix>/model δρομολογούνται σε έναν ενσωματωμένο πάροχο ή αποτυγχάνουν με ασφαλή τρόπο όταν αυτός έχει αποσυρθεί)
```

Επιλέξτε ένα διακριτό πρόθεμα (`mygw`, `acme-proxy`). Αν τα αιτήματα προς έναν προσαρμοσμένο κόμβο αποτυγχάνουν με
σφάλμα που αναφέρει έναν ενσωματωμένο πάροχο ή τα διαπιστευτήριά του, ελέγξτε αν το πρόθεμα του κόμβου είναι
δεσμευμένο: οι κόμβοι που αποθηκεύτηκαν πριν από την ύπαρξη αυτού του κανόνα εξακολουθούν να είναι αποθηκευμένοι, αλλά το πρόθεμά τους δρομολογεί
στον ενσωματωμένο πάροχο. Επεξεργαστείτε τον κόμβο και δώστε του ένα νέο πρόθεμα.

### Αλυσιδωτή σύνδεση ομότιμων κόμβων OmniRoute

Μια άλλη πύλη OmniRoute μπορεί να προστεθεί ως **προσαρμοσμένος πάροχος συμβατός με OpenAI**. Χρησιμοποιήστε το
βασικό URL `/v1` του ομότιμου κόμβου και ένα αποκλειστικό κλειδί API ελάχιστων προνομίων, το οποίο έχει εκδοθεί από αυτόν τον κόμβο.

Για αμφίδρομες ή πολλαπλών αλμάτων αλυσίδες, ενεργοποιήστε την προαιρετική προστασία από βρόχους σε κάθε πύλη:

```bash
# gateway-a
OMNIROUTE_INSTANCE_ID=gateway-a
OMNIROUTE_PEER_URLS=http://gateway-b:20128/v1
OMNIROUTE_PEER_MAX_HOPS=4
```

```bash
# gateway-b
OMNIROUTE_INSTANCE_ID=gateway-b
OMNIROUTE_PEER_URLS=http://gateway-a:20128/v1
OMNIROUTE_PEER_MAX_HOPS=4
```

Μόνο τα αιτήματα που αποστέλλονται σε ένα ρητά επιτρεπόμενο URL ομότιμου κόμβου λαμβάνουν την κεφαλίδα
`X-OmniRoute-Peer-Trace`. Μια πύλη απορρίπτει ένα επαναλαμβανόμενο αναγνωριστικό παρουσίας ή ένα εξαντλημένο όριο αλμάτων
με HTTP `508 Loop Detected`· οι συνηθισμένοι ανάντη πάροχοι δεν λαμβάνουν μεταδεδομένα ομότιμων κόμβων.

Η αλυσιδωτή σύνδεση ομότιμων κόμβων δεν αποτελεί αναπαραγωγή βάσης δεδομένων ή ανακατεύθυνση σε εφεδρικό κεντρικό υπολογιστή. Κάθε πύλη διατηρεί ανεξάρτητη
κατάσταση SQLite, κρυφές μνήμες, μετρητές ορίων και συνεδρίες. Χρησιμοποιήστε έναν αντίστροφο διακομιστή μεσολάβησης με ελέγχους εύρυθμης λειτουργίας ή εναλλακτική δρομολόγηση πελάτη
για ενεργή/παθητική ή ενεργή/ενεργή διαθεσιμότητα και μην προσαρτάτε ποτέ μία βάση δεδομένων SQLite
σε πολλές εκτελούμενες παρουσίες OmniRoute.

### Γρήγορη διοχέτευση Cloudflare

- Διαθέσιμο στο **Dashboard → Endpoints** για Docker και άλλες αυτοφιλοξενούμενες εγκαταστάσεις
- Δημιουργεί ένα προσωρινό URL `https://*.trycloudflare.com` που προωθεί στο τρέχον συμβατό με OpenAI endpoint `/v1`
- Η πρώτη ενεργοποίηση εγκαθιστά το `cloudflared` μόνο όταν χρειάζεται· οι επόμενες επανεκκινήσεις επαναχρησιμοποιούν το ίδιο διαχειριζόμενο εκτελέσιμο αρχείο
- Τα Quick Tunnels δεν επαναφέρονται αυτόματα μετά από επανεκκίνηση του OmniRoute ή του container· ενεργοποιήστε τα ξανά από το dashboard όταν χρειάζεται
- Τα URL των tunnel είναι προσωρινά και αλλάζουν κάθε φορά που διακόπτετε/εκκινείτε το tunnel
- Τα διαχειριζόμενα Quick Tunnels χρησιμοποιούν από προεπιλογή μεταφορά HTTP/2, ώστε να αποφεύγονται οι θορυβώδεις προειδοποιήσεις για το buffer UDP του QUIC σε containers με περιορισμένους πόρους
- Ορίστε `CLOUDFLARED_PROTOCOL=quic` ή `auto` εάν θέλετε να παρακάμψετε την επιλογή διαχειριζόμενης μεταφοράς
- Ορίστε `CLOUDFLARED_BIN` εάν προτιμάτε να χρησιμοποιήσετε ένα προεγκατεστημένο εκτελέσιμο αρχείο `cloudflared` αντί για τη διαχειριζόμενη λήψη
- Τα πάνελ Cloudflare Quick Tunnel, Tailscale Funnel και ngrok Tunnel μπορούν να εμφανίζονται ή να αποκρύπτονται στο **Settings → Appearance**. Η απόκρυψη ενός πάνελ δεν διακόπτει ένα tunnel που εκτελείται.

### Ευφυΐα πύλης LLM (Φάση 9)

- **Σημασιολογική κρυφή μνήμη** — Αποθηκεύει αυτόματα στην κρυφή μνήμη αποκρίσεις χωρίς streaming και με temperature=0 (παράκαμψη με `X-OmniRoute-No-Cache: true`)

- **Παρακολούθηση προόδου** — Προαιρετικά συμβάντα SSE `event: progress` μέσω της κεφαλίδας `X-OmniRoute-Progress: true`

| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Συμπλήρωση πρώτου**         | Χρησιμοποιεί τους λογαριασμούς κατά σειρά προτεραιότητας — ο κύριος λογαριασμός χειρίζεται όλα τα αιτήματα μέχρι να μην είναι διαθέσιμος |
| **Κυκλική εναλλαγή**          | Εναλλάσσεται κυκλικά μεταξύ όλων των λογαριασμών, με διαμορφώσιμο όριο διατήρησης (προεπιλογή: 3 κλήσεις ανά λογαριασμό)                 |
| **P2C (Ισχύς δύο επιλογών)**  | Επιλέγει 2 τυχαίους λογαριασμούς και δρομολογεί στον πιο υγιή — εξισορροπεί το φορτίο λαμβάνοντας υπόψη την κατάσταση λειτουργίας        |
| **Τυχαία**                    | Επιλέγει τυχαία έναν λογαριασμό για κάθε αίτημα χρησιμοποιώντας ανακάτεμα Fisher-Yates                                                   |
| **Λιγότερο χρησιμοποιημένος** | Δρομολογεί στον λογαριασμό με την παλαιότερη χρονοσήμανση `lastUsedAt`, κατανέμοντας ομοιόμορφα την κίνηση                               |
| **Βελτιστοποίηση κόστους**    | Δρομολογεί στον λογαριασμό με τη χαμηλότερη τιμή προτεραιότητας, βελτιστοποιώντας για παρόχους με το χαμηλότερο κόστος                   |

**Προηγμένοι συνδυασμοί και αυτόματες στρατηγικές** (διαμορφώνονται ανά συνδυασμό ή μέσω προθεμάτων `auto/*` — δείτε το [AUTO-COMBO.md](../routing/AUTO-COMBO.md)):

- `priority` — αυστηρή σειρά, χωρίς ποτέ κυκλική εναλλαγή
- `weighted` — αναλογικός επιμερισμός κίνησης βάσει βαρών ανά μοντέλο
- `fill-first` — εξάντληση του πρώτου μοντέλου μέχρι να επιτευχθούν τα όρια
- `round-robin` / `strict-random` / `random`
- `p2c` (Ισχύς δύο επιλογών)
- `least-used` και `cost-optimized`
- `auto` — βάσει βαθμολογίας σε όλους τους υποψηφίους
- `lkgp` (Τελευταίος γνωστός καλός πάροχος) — παραμένει στον τελευταίο επιτυχημένο πάροχο και, στη συνέχεια, μεταπίπτει στους κανόνες
- `context-optimized` — επιλέγει το μοντέλο με το μεγαλύτερο ελεύθερο παράθυρο context
- `context-relay` — συνδέει αλυσιδωτά μοντέλα μεγάλου context για επόμενους γύρους

#### Εξωτερική κεφαλίδα διατήρησης συνεδρίας

Για εξωτερική συνάφεια συνεδρίας (για παράδειγμα, agents Claude Code/Codex πίσω από reverse proxies), στείλτε:

```http
X-Session-Id: your-session-key
```

Το OmniRoute δέχεται επίσης `x_session_id` και επιστρέφει το ενεργό κλειδί συνεδρίας στο `X-OmniRoute-Session-Id`.

Εάν χρησιμοποιείτε Nginx και στέλνετε κεφαλίδες με κάτω παύλες, ενεργοποιήστε:

```nginx
underscores_in_headers on;
```

#### Ψευδώνυμα μοντέλων με χαρακτήρες μπαλαντέρ

Δημιουργήστε μοτίβα με χαρακτήρες μπαλαντέρ για να αντιστοιχίσετε εκ νέου ονόματα μοντέλων:

```
Μοτίβο: claude-sonnet-*     →  Προορισμός: cc/claude-sonnet-4-6
Μοτίβο: gpt-*               →  Προορισμός: gh/gpt-5.3-codex
```

Οι χαρακτήρες μπαλαντέρ υποστηρίζουν `*` (οποιοιδήποτε χαρακτήρες) και `?` (ένας χαρακτήρας).

#### Αλυσίδες εφεδρικής μετάπτωσης

Ορίστε καθολικές αλυσίδες εφεδρικής μετάπτωσης που εφαρμόζονται σε όλα τα αιτήματα:

```
Αλυσίδα: production-fallback
  1. cc/claude-opus-4-7
  2. gh/gpt-5.3-codex
  3. glm/glm-4.7
```

### Ανθεκτικότητα και διακόπτες κυκλώματος

Διαμορφώστε τα μέσω **Dashboard → Settings → Resilience**.

Το OmniRoute υλοποιεί ανθεκτικότητα σε επίπεδο παρόχου με πέντε στοιχεία:

1. **Ουρά και ρυθμός αιτημάτων** — Διαμόρφωση αιτημάτων σε επίπεδο συστήματος:
   - **Αιτήματα ανά λεπτό (RPM)** — Μέγιστος αριθμός αιτημάτων ανά λεπτό και ανά λογαριασμό
   - **Ελάχιστος χρόνος μεταξύ αιτημάτων** — Ελάχιστο διάστημα σε χιλιοστά του δευτερολέπτου μεταξύ αιτημάτων
   - **Μέγιστος αριθμός ταυτόχρονων αιτημάτων** — Μέγιστος αριθμός ταυτόχρονων αιτημάτων ανά λογαριασμό
2. **Χρόνος Αναμονής Σύνδεσης** — Διαμόρφωση ανά τύπο ελέγχου ταυτότητας για μία μεμονωμένη σύνδεση μετά από αποτυχίες που επιδέχονται επανάληψη:
   - **Βασικός Χρόνος Αναμονής** — Προεπιλεγμένο χρονικό διάστημα αναμονής για αποτυχίες ανάντη υπηρεσιών που επιδέχονται επανάληψη
   - **Χρήση Υποδείξεων Επανάληψης Ανάντη Υπηρεσίας** — Τηρεί τις έγκυρες υποδείξεις `Retry-After` ή επαναφοράς, όταν παρέχονται
   - **Μέγιστα Βήματα Οπισθοχώρησης** — Μέγιστο επίπεδο εκθετικής οπισθοχώρησης για επαναλαμβανόμενες αποτυχίες

3. **Διακόπτης Κυκλώματος Παρόχου** — Παρακολουθεί τις διατερματικές αποτυχίες του παρόχου, επισημαίνει έναν πάροχο ως υποβαθμισμένο στο διαμορφωμένο όριο προειδοποίησης και ανοίγει τον διακόπτη όταν συμπληρωθεί το διαμορφωμένο όριο αποτυχιών:
   - **Όριο Υποβάθμισης** — Διαδοχικές αποτυχίες παρόχου πριν από τη μετάβαση σε `DEGRADED`
   - **Όριο Αποτυχιών** — Διαδοχικές αποτυχίες παρόχου πριν από τη μετάβαση σε `OPEN`
   - **Χρονικό Όριο Επαναφοράς** — Χρονικό διάστημα πριν από την εκ νέου δοκιμή του παρόχου
   - **CLOSED** (Υγιής) — Τα αιτήματα διεκπεραιώνονται κανονικά
   - **DEGRADED** — Τα αιτήματα εξακολουθούν να διεκπεραιώνονται ενώ παρακολουθείται ο αυξημένος αριθμός αποτυχιών
   - **OPEN** — Ο πάροχος αποκλείεται προσωρινά μετά από επαναλαμβανόμενες αποτυχίες
   - **HALF_OPEN** — Ελέγχεται αν ο πάροχος έχει ανακάμψει

   Τα όρια ρυθμού `429` που αφορούν συγκεκριμένη σύνδεση παραμένουν στον **Χρόνο Αναμονής Σύνδεσης** και δεν προσμετρώνται στον διακόπτη κυκλώματος του παρόχου.

   Η κατάσταση εκτέλεσης του διακόπτη κυκλώματος παρόχου εμφανίζεται μόνο στο **Πίνακας Ελέγχου → Υγεία**.

4. **Αναμονή για τη Λήξη του Χρόνου Αναμονής** — Αν κάθε υποψήφια σύνδεση βρίσκεται ήδη σε χρόνο αναμονής, το OmniRoute μπορεί να περιμένει έως τη λήξη του συντομότερου χρόνου αναμονής και να επαναλάβει αυτόματα το ίδιο αίτημα πελάτη.

5. **Αυτόματος Εντοπισμός Ορίου Ρυθμού** — Όταν οι ανάντη πάροχοι επιστρέφουν ρητά χρονικά διαστήματα αναμονής, αυτές οι υποδείξεις υπερισχύουν του τοπικού χρόνου αναμονής σύνδεσης, εφόσον η ρύθμιση είναι ενεργοποιημένη.

**Επαγγελματική συμβουλή:** Χρησιμοποιήστε τη σελίδα **Υγεία** για να επιθεωρείτε και να επαναφέρετε ενεργούς διακόπτες κυκλώματος παρόχων μετά από μια διακοπή λειτουργίας. Η σελίδα Ανθεκτικότητα αλλάζει μόνο τη διαμόρφωση.

### Εξαγωγή / Εισαγωγή Βάσης Δεδομένων

Διαχειριστείτε τα αντίγραφα ασφαλείας της βάσης δεδομένων από το **Πίνακας Ελέγχου → Ρυθμίσεις → Σύστημα και Αποθήκευση**.

| Ενέργεια                     | Περιγραφή                                                                                                                                                                                                        |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Εξαγωγή Βάσης Δεδομένων**  | Πραγματοποιεί λήψη της τρέχουσας βάσης δεδομένων SQLite ως αρχείο `.sqlite`                                                                                                                                      |
| **Εξαγωγή Όλων (.tar.gz)**   | Πραγματοποιεί λήψη ενός πλήρους αρχείου αντιγράφου ασφαλείας που περιλαμβάνει: βάση δεδομένων, ρυθμίσεις, συνδυασμούς, συνδέσεις παρόχων (χωρίς διαπιστευτήρια), μεταδεδομένα κλειδιών API                       |
| **Εισαγωγή Βάσης Δεδομένων** | Μεταφορτώνει ένα αρχείο `.sqlite` για την αντικατάσταση της τρέχουσας βάσης δεδομένων. Δημιουργείται αυτόματα αντίγραφο ασφαλείας πριν από την εισαγωγή, εκτός αν έχει οριστεί `DISABLE_SQLITE_AUTO_BACKUP=true` |

```bash
# API: Εξαγωγή βάσης δεδομένων
curl -o backup.sqlite http://localhost:20128/api/db-backups/export

# API: Εξαγωγή όλων (πλήρες αρχείο)
curl -o backup.tar.gz http://localhost:20128/api/db-backups/exportAll

# API: Εισαγωγή βάσης δεδομένων
curl -X POST http://localhost:20128/api/db-backups/import \
  -F "file=@backup.sqlite"
```

**Επικύρωση Εισαγωγής:** Το εισαγόμενο αρχείο επικυρώνεται ως προς την ακεραιότητα (έλεγχος pragma του SQLite), τους απαιτούμενους πίνακες (`provider_connections`, `provider_nodes`, `combos`, `api_keys`) και το μέγεθος (μέγιστο 100MB).

**Περιπτώσεις Χρήσης:**

- Μετεγκατάσταση του OmniRoute μεταξύ υπολογιστών
- Δημιουργία εξωτερικών αντιγράφων ασφαλείας για αποκατάσταση από καταστροφές
- Κοινή χρήση διαμορφώσεων μεταξύ μελών της ομάδας (εξαγωγή όλων → κοινοποίηση αρχείου)

### Στρατηγικές εξισορρόπησης συνδυασμών

Διαμορφώστε την εξισορρόπηση ανά συνδυασμό στο **Πίνακας ελέγχου → Συνδυασμοί → Δημιουργία/Επεξεργασία → Στρατηγική**.

| Στρατηγική                   | Περιγραφή                                                                                      |
| ---------------------------- | ---------------------------------------------------------------------------------------------- |
| **Κυκλική εναλλαγή**         | Εναλλάσσεται διαδοχικά μεταξύ των μοντέλων                                                     |
| **Προτεραιότητα**            | Δοκιμάζει πάντα πρώτα το πρώτο μοντέλο· μεταβαίνει σε εφεδρικό μόνο σε περίπτωση σφάλματος     |
| **Τυχαία επιλογή**           | Επιλέγει ένα τυχαίο μοντέλο από τον συνδυασμό για κάθε αίτημα                                  |
| **Σταθμισμένη επιλογή**      | Δρομολογεί αναλογικά βάσει των βαρών που έχουν εκχωρηθεί ανά μοντέλο                           |
| **Λιγότερο χρησιμοποιημένο** | Δρομολογεί στο μοντέλο με τα λιγότερα πρόσφατα αιτήματα (χρησιμοποιεί μετρικές του συνδυασμού) |
| **Βελτιστοποίηση κόστους**   | Δρομολογεί στο φθηνότερο διαθέσιμο μοντέλο (χρησιμοποιεί τον πίνακα τιμολόγησης)               |

Οι καθολικές προεπιλογές συνδυασμών μπορούν να οριστούν στο **Πίνακας ελέγχου → Ρυθμίσεις → Δρομολόγηση → Προεπιλογές συνδυασμών**.
Τα χρονικά όρια των προορισμών ενός συνδυασμού κληρονομούν από προεπιλογή το τρέχον χρονικό όριο του αιτήματος. Χρησιμοποιήστε το **Χρονικό όριο προορισμού
(δευτερόλεπτα)** στις προεπιλογές συνδυασμών ή σε έναν μεμονωμένο συνδυασμό μόνο όταν ένα μικρότερο όριο ανά προορισμό πρέπει
να ενεργοποιεί ταχύτερα την εφεδρική μετάβαση.

Οι βελτιστοποιήσεις συνδυασμών μηδενικής καθυστέρησης ενεργοποιούνται προαιρετικά. Αφήστε τις **Βελτιστοποιήσεις μηδενικής καθυστέρησης** απενεργοποιημένες για να
αποτρέψετε αυτές τις λειτουργίες καθυστέρησης από το να ανταγωνίζονται εφεδρικούς προορισμούς, να παραλείπουν προορισμούς βάσει του ιστορικού
TTFT ή να συμπιέζουν εφεδρικά αιτήματα· η ενεργοποίησή τους επιτρέπει τη διαμορφωμένη αντιστάθμιση, τις προγνωστικές παραλείψεις βάσει TTFT
και την προληπτική συμπίεση εφεδρικών αιτημάτων, ανταλλάσσοντας την πιστότητα δρομολόγησης/αιτημάτων με χαμηλότερη ακραία
καθυστέρηση.

Απενεργοποιήστε το **Απόθεμα token συλλογισμού** όταν οι upstream πάροχοι απαιτούν αυστηρά όρια
`max_tokens` / `maxOutputTokens`. Όταν είναι ενεργοποιημένο, η δρομολόγηση συνδυασμών προσθέτει επιπλέον περιθώριο για μοντέλα συλλογισμού
μόνο σε μοντέλα με γνωστό όριο εξόδου και αφήνει αμετάβλητο το όριο token του πελάτη όταν η ασφαλής τιμή με το πρόσθετο απόθεμα θα υπερέβαινε αυτό το όριο.
Εάν το όριο του πελάτη υπερβαίνει ήδη ένα γνωστό ανώτατο όριο,
το OmniRoute το περιορίζει σε αυτό το ανώτατο όριο πριν στείλει το αίτημα στον upstream πάροχο.

### Πίνακας ελέγχου εύρυθμης λειτουργίας

Αποκτήστε πρόσβαση μέσω του **Πίνακας ελέγχου → Εύρυθμη λειτουργία**. Επισκόπηση της εύρυθμης λειτουργίας του συστήματος σε πραγματικό χρόνο με 6 κάρτες:

| Κάρτα                          | Τι εμφανίζει                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------- |
| **Κατάσταση συστήματος**       | Χρόνο λειτουργίας, έκδοση, χρήση μνήμης, κατάλογο δεδομένων                  |
| **Εύρυθμη λειτουργία παρόχων** | Καθολική κατάσταση εκτέλεσης του circuit breaker των παρόχων                 |
| **Όρια ρυθμού**                | Ενεργούς χρόνους αναμονής συνδέσεων ανά λογαριασμό με τον χρόνο που απομένει |
| **Ενεργοί αποκλεισμοί**        | Ενεργούς αποκλεισμούς ανά μοντέλο και προσωρινές εξαιρέσεις                  |
| **Cache υπογραφών**            | Στατιστικά cache αποδιπλοποίησης (ενεργά κλειδιά, ποσοστό επιτυχιών)         |
| **Τηλεμετρία καθυστέρησης**    | Συγκεντρωτικές καθυστερήσεις p50/p95/p99 ανά πάροχο                          |

**Επαγγελματική συμβουλή:** Η σελίδα εύρυθμης λειτουργίας ανανεώνεται αυτόματα κάθε 10 δευτερόλεπτα. Χρησιμοποιήστε την κάρτα circuit breaker για να εντοπίσετε ποιοι πάροχοι αντιμετωπίζουν προβλήματα.

## 🤖 Αυτόματη Δρομολόγηση (Χωρίς Ρύθμιση)

Το OmniRoute διαθέτει έναν **αυτόματο δρομολογητή βαθμολογίας** που επιλέγει το καλύτερο μοντέλο για κάθε αίτημα από όλους τους συνδεδεμένους παρόχους — χωρίς συνδυασμό προς συντήρηση. Απλώς στείλτε το αίτημα με ένα από τα προθέματα `auto/*` και το OmniRoute θα συναρμολογήσει έναν εικονικό συνδυασμό εν κινήσει, βαθμολογώντας τους υποψηφίους βάσει καθυστέρησης, κόστους, ποσοστού επιτυχίας, καταλληλότητας πλαισίου, καταλληλότητας μοντέλου για την εργασία, πρόσφατων αποτυχιών, ορίου χρήσης και κατάστασης διακόπτη κυκλώματος.

| Πρόθεμα        | Βελτιστοποιεί για                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------ |
| `auto`         | Ισορροπημένη προεπιλογή (καθυστέρηση × κόστος × ποσοστό επιτυχίας)                                                 |
| `auto/coding`  | Εργασίες κώδικα: προτιμά Claude, GPT-5, GLM, Kimi, Qwen Coder, DeepSeek coders                                     |
| `auto/cheap`   | Χαμηλότερο $/token, αποδέχεται υψηλότερη καθυστέρηση                                                               |
| `auto/fast`    | Χαμηλότερη καθυστέρηση, αγνοεί το κόστος                                                                           |
| `auto/offline` | Τοπικοί πάροχοι μόνο (Ollama, vLLM, llama.cpp) — χρήσιμο για απομονωμένες εγκαταστάσεις                            |
| `auto/smart`   | Ποιότητα συλλογισμού πρώτα (Opus, GPT-5 xhigh, R1, GLM 5.1 reasoning)                                              |
| `auto/lkgp`    | "Τελευταίος Γνωστός Καλός Πάροχος" — καρφιτσώνει στον τελευταίο επιτυχή πάροχο, έπειτα εφαρμόζει κανόνες εφεδρείας |

Παράδειγμα:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer $OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto/coding",
    "messages": [{ "role": "user", "content": "Refactor this Python function" }],
    "stream": true
  }'
```

Ο αυτόματος δρομολογητής περιγράφεται πλήρως στο [AUTO-COMBO.md](../routing/AUTO-COMBO.md) — συμπεριλαμβανομένου του τρόπου ρύθμισης βαρών βαθμολόγησης, αποκλεισμού παρόχων και επιθεώρησης αποφάσεων δρομολόγησης στο **Dashboard → Auto Combo**.

## 🔌 Ενσωμάτωση MCP & A2A

Το OmniRoute είναι ταυτόχρονα **διακομιστής MCP** (Model Context Protocol) και **διακομιστής A2A** (Agent-to-Agent JSON-RPC 2.0). Οποιοδήποτε IDE ή περιβάλλον εκτέλεσης πράκτορα που είναι συμβατό με MCP μπορεί να καλεί εργαλεία του OmniRoute απευθείας — χωρίς επιπλέον περιτύλιγμα.

### Μεταφορές MCP

- **SSE**: `http://localhost:20128/api/mcp/sse`
- **Streamable HTTP**: `http://localhost:20128/api/mcp/stream`
- **stdio**: `omniroute --mcp` (για πρόσθετα IDE που προτιμούν stdio)

### Σύνδεση του Claude Desktop

Επεξεργαστείτε το `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) ή το αντίστοιχο αρχείο σε Windows/Linux:

```json
{
  "mcpServers": {
    "omniroute": {
      "command": "omniroute",
      "args": ["--mcp"]
    }
  }
}
```

### Σύνδεση Cursor / Continue / VS Code MCP

Χρησιμοποιήστε τη διεύθυνση SSE `http://localhost:20128/api/mcp/sse` και ένα κλειδί API Bearer που δημιουργήθηκε στο **Dashboard → API Keys**.

### Εμβέλειες

Το MCP ορίζει αυτήν τη στιγμή 32 ονομαστικές εμβέλειες. Κάθε κλειδί Bearer μπορεί να περιοριστεί σε συγκεκριμένες εμβέλειες — δείτε το [MCP-SERVER.md](../frameworks/MCP-SERVER.md) για το αυθεντικό ευρετήριο εμβελειών και εργαλείων, και το [A2A-SERVER.md](../frameworks/A2A-SERVER.md) για το σχήμα JSON-RPC.

## 💾 Σύστημα Μνήμης

Το OmniRoute διατηρεί **μακροπρόθεσμη συνομιλιακή μνήμη** με υβριδική ανάκτηση:

- **SQLite FTS5** για αναζήτηση με λέξεις-κλειδιά σε προηγούμενες συνομιλίες
- **Qdrant vector store** (προαιρετικό) για σημασιολογική ανάκληση
- **Αυτόματη εξαγωγή γεγονότων** — οντότητες, προτιμήσεις και αποφάσεις συνοψίζονται μετά από κάθε συνεδρία και αποθηκεύονται στον πίνακα `memory_facts`
- Οι μνήμες εντοπίζονται ανά κλειδί API και ανά συνεδρία

Διαχειριστείτε τις μνήμες στο **Dashboard → Memory** (αναζήτηση, επεξεργασία, εξαγωγή, εκκαθάριση). Η επιφάνεια HTTP (`/api/memory/*`) επιτρέπει στους agents να ωθούν και να αναζητούν γεγονότα μέσω προγράμματος — δείτε [MEMORY.md](../frameworks/MEMORY.md).

## 🔔 Webhooks

Εγγραφείτε σε συμβάντα του OmniRoute για παρακολούθηση και αυτοματισμό σε πραγματικό χρόνο.

- Δημιουργήστε ένα webhook στο **Dashboard → Webhooks** με URL προορισμού και μυστικό υπογραφής HMAC
- Διαθέσιμα συμβάντα: `request.completed`, `request.failed`, `provider.unavailable`, `budget.exceeded`, `combo.switched`, `circuit_breaker.opened`, `circuit_breaker.closed`
- Κάθε payload περιλαμβάνει `X-OmniRoute-Signature` (HMAC-SHA256) για επαλήθευση
- Επαναλήψεις: 3 προσπάθειες με εκθετική καθυστέρηση, έπειτα ουρά νεκρών γραμμάτων

Πλήρες σχήμα στο [WEBHOOKS.md](../frameworks/WEBHOOKS.md).

## 🛠️ Προγραμματιστική Διαχείριση

Μπορείτε να διαχειριστείτε κάθε πόρο του OmniRoute (παρόχους, combos, κλειδιά, ρυθμίσεις) μέσω HTTP χρησιμοποιώντας ένα **Bearer κλειδί με την εμβέλεια `manage`**.

Δημιουργήστε το κλειδί στο **Dashboard → API Keys → New Key → Scope: manage**, και στη συνέχεια:

```bash
# Λίστα παρόχων
curl http://localhost:20128/api/providers \
  -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY"

# Προσθήκη σύνδεσης παρόχου
curl -X POST http://localhost:20128/api/providers \
  -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "provider": "openai", "apiKey": "sk-...", "name": "main" }'

# Δημιουργία combo
curl -X POST http://localhost:20128/api/combos \
  -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "premium", "strategy": "priority", "models": [{ "model": "cc/claude-opus-4-7" }, { "model": "glm/glm-5.1" }] }'

# Λίστα/δημιουργία κλειδιών API
curl http://localhost:20128/api/keys -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY"
curl -X POST http://localhost:20128/api/keys -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY" \
  -d '{ "name": "ci-bot", "scopes": ["chat"] }'
```

Δείτε το [API_REFERENCE.md](../reference/API_REFERENCE.md) για τον πλήρη κατάλογο endpoints και τα σχήματα αιτημάτων/αποκρίσεων.

## 💻 Εσωτερικό CLI

Το OmniRoute διαθέτει ένα εσωτερικό CLI (`omniroute …`) για εγκατάσταση, διαγνωστικά και έλεγχο χρόνου εκτέλεσης. Αυτό είναι **ξεχωριστό από τη σελίδα "CLI Tools" στον πίνακα ελέγχου**, η οποία διαμορφώνει CLIs τρίτων (Claude Code, Cursor, Codex, Cline, …) ώστε να επικοινωνούν με το OmniRoute.

```bash
omniroute setup                    # Διαδραστικός οδηγός (κωδικός πρόσβασης, πάροχοι, combos)
omniroute setup --non-interactive  # Κατάλληλο για CI
omniroute doctor                   # Διαγνωστικά υγείας (data dir, DB, πάροχοι, θύρες)
omniroute providers available      # Λίστα υποστηριζόμενων παρόχων
omniroute providers list           # Λίστα διαμορφωμένων συνδέσεων
omniroute providers test <id>      # Δοκιμή σύνδεσης παρόχου σε πραγματικό χρόνο
omniroute combos list              # Λίστα combos
omniroute combos switch <name>     # Ορισμός προεπιλεγμένου combo
omniroute models                   # Λίστα διαθέσιμων μοντέλων (--json, --search)
omniroute keys add | list | remove # Διαχείριση κλειδιών API από το τερματικό
omniroute backup                   # Στιγμιότυπο διαμόρφωσης + DB
omniroute restore [<timestamp>]    # Επαναφορά από στιγμιότυπο
omniroute health                   # Λεπτομερής υγεία (breakers, cache, μνήμη)
omniroute quota                    # Χρήση ορίου παρόχου
omniroute mcp status               # Κατάσταση διακομιστή MCP
omniroute a2a status               # Κατάσταση διακομιστή A2A
omniroute tunnel list|create|stop  # Tunnels Cloudflare/Tailscale/ngrok
omniroute reset-password           # Επαναφορά κωδικού πρόσβασης διαχειριστή
omniroute --mcp                    # Εκκίνηση διακομιστή MCP μέσω stdio
omniroute --port 3000              # Εκκίνηση διακομιστή σε προσαρμοσμένη θύρα
```

Συμβουλή: συνδυάστε το `omniroute doctor --json` με το εργαλείο παρακολούθησής σας για ειδοποιήσεις σε μη υγιείς συνδέσεις παρόχων.

## 🖥️ Εφαρμογή Desktop (Electron)

Το OmniRoute διατίθεται ως εγγενής εφαρμογή desktop για Windows, macOS και Linux.

### Εγκατάσταση

```bash
# Από τον κατάλογο electron:
cd electron
npm install

# Λειτουργία ανάπτυξης (σύνδεση σε εκτελούμενο διακομιστή Next.js dev):
npm run dev

# Λειτουργία παραγωγής (χρησιμοποιεί standalone build):
npm start
```

### Δημιουργία Εγκαταστατών

```bash
cd electron
npm run build          # Τρέχουσα πλατφόρμα
npm run build:win      # Windows (.exe NSIS)
npm run build:mac      # macOS (.dmg universal)
npm run build:linux    # Linux (.AppImage)
```

Έξοδος → `electron/dist-electron/`
