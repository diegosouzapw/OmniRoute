Η εκχωρημένη **Επεξεργασία Περιβάλλοντος** είναι μια λειτουργία διαχείρισης περιβάλλοντος αποκλειστικά για το Claude. Σε αντίθεση με τις τοπικές μηχανές συμπίεσης του OmniRoute (Caveman, RTK, LLMLingua, στοιβαγμένες διοχετεύσεις) — οι οποίες επανεγγράφουν το σώμα του αιτήματος _πριν_ αυτό φύγει από τον proxy — η Επεξεργασία Περιβάλλοντος ζητά από τον **πάροχο** να αφαιρέσει παρωχημένα μπλοκ χρήσης εργαλείων / αποτελεσμάτων εργαλείων από το δικό του ενεργό παράθυρο περιβάλλοντος. Το OmniRoute επισυνάπτει μόνο μία παράμετρο σώματος (`context_management.edits[]`)· το Claude εκτελεί την πραγματική εκκαθάριση βάσει του δικού του tokenizer.

Αυτή είναι από τη φύση της μια εκχωρημένη δυνατότητα: οι άλλοι πάροχοι απορρίπτουν την παράμετρο, επομένως το OmniRoute την περιορίζει αυστηρά στο Claude και σε αναμεταδότες συμβατούς με το Claude Code.

Πηγή αναφοράς: `open-sse/config/contextEditing.ts` (αναγνωριστικά στρατηγικών, εισαγωγή στο σώμα, εξαγωγή τηλεμετρίας), `open-sse/executors/base.ts` (πύλη εισαγωγής + εφεδρική συμπεριφορά για 400) και `open-sse/services/compression/types.ts` (σχήμα ρυθμίσεων + προεπιλογή).

## Τι κάνει το `clear_tool_uses`

Το OmniRoute εισάγει μία μοναδική επεξεργασία στο εξερχόμενο σώμα Anthropic Messages:

```json
{
  "context_management": {
    "edits": [
      {
        "type": "clear_tool_uses_20250919",
        "trigger": { "type": "input_tokens", "value": 100000 },
        "keep": { "type": "tool_uses", "value": 3 }
      }
    ]
  }
}
```

- `type: "clear_tool_uses_20250919"` — το αναγνωριστικό στρατηγικής με ημερομηνία της Anthropic (`CLEAR_TOOL_USES_STRATEGY`).
- `trigger.value: 100000` — μόλις τα token εισόδου του αιτήματος υπερβούν αυτό το όριο, το Claude αρχίζει να εκκαθαρίζει παλιά ζεύγη χρήσης/αποτελέσματος εργαλείων (`CONTEXT_EDITING_DEFAULT_TRIGGER_TOKENS`, η προεπιλογή της Anthropic).
- `keep.value: 3` — τα N πιο πρόσφατα ζεύγη χρήσης/αποτελέσματος εργαλείων διατηρούνται ανέπαφα (`CONTEXT_EDITING_DEFAULT_KEEP_TOOL_USES`).

Η έκδοση beta δηλώνεται μέσω της κεφαλίδας `anthropic-beta: context-management-2025-06-27`, την οποία το OmniRoute εκπέμπει ήδη στα αιτήματα Claude.

Η εισαγωγή πραγματοποιείται από το `applyContextEditingToBody()` και είναι **ιδιοδύναμη**: αν υπάρχει ήδη στο σώμα μια επεξεργασία `clear_tool_uses` (η οποία προστέθηκε από προηγούμενη κλήση ή παρασχέθηκε από τον πελάτη), το σώμα παραμένει ως έχει. Αν υπάρχει επίσης μια επεξεργασία `clear_thinking_20251015`, το OmniRoute ταξινομεί σταθερά την επεξεργασία `clear_thinking` ώστε να τοποθετείται στην αρχή, επειδή η Anthropic απαιτεί το `clear_thinking` να προηγείται του `clear_tool_uses` στον πίνακα `edits[]`.

## Ο διακόπτης ενεργοποίησης ανά συνδυασμό

Η Επεξεργασία Περιβάλλοντος είναι **απενεργοποιημένη από προεπιλογή** και απαιτεί ρητή ενεργοποίηση. Ο διακόπτης είναι μία μεμονωμένη λογική τιμή που μεταφέρεται στις ρυθμίσεις συμπίεσης:

- Κλειδί ρύθμισης: `contextEditing.enabled` (camelCase — **όχι** `context_editing` / `context-editing`).
- Τύπος: `ContextEditingConfig { enabled: boolean }` στο
  `open-sse/services/compression/types.ts`.
- Προεπιλογή: `DEFAULT_CONTEXT_EDITING_CONFIG = { enabled: false }`.
- Σχήμα Zod: `contextEditingConfigSchema` στο `src/shared/validation/compressionConfigSchemas.ts`.
- Αποθήκευση: διατηρείται μαζί με τις υπόλοιπες ρυθμίσεις συμπίεσης (κανονικοποιείται στο
  `src/lib/db/compression.ts`).

Στον πίνακα ελέγχου, ο διακόπτης βρίσκεται στον κόμβο συμπίεσης (`src/app/(dashboard)/dashboard/context/combos/CompressionHub.tsx`) και εγγράφει το `{ contextEditing: { enabled: … } }` μέσω του `saveSettings()`. Επειδή μεταφέρεται μέσα στο αντικείμενο ρυθμίσεων συμπίεσης, συνδυάζεται με το προφίλ συμπίεσης ανά συνδυασμό αντί να αποτελεί μια πλήρως ανεξάρτητη επιφάνεια ρυθμίσεων — η διαμόρφωση περιέχει μόνο τη σημαία ενεργοποίησης/απενεργοποίησης· όλα τα όρια (`trigger`, `keep`) είναι οι σταθερές που τεκμηριώνονται παραπάνω.

## Περιορισμός μόνο για Claude

Η έγχυση πραγματοποιείται μόνο για γνήσια Claude ή για αναμεταδότες συμβατούς με Claude Code. Η συνθήκη ελέγχου στο
`open-sse/executors/base.ts` είναι:

```ts
if (
  (this.provider === "claude" || isClaudeCodeCompatible(this.provider)) &&
  contextEditing?.enabled &&
  !contextEditingDisabled
) {
  applyContextEditingToBody(transformedBody, { enabled: true });
}
```

- `this.provider === "claude"` — πραγματικό κλειδί Anthropic/OAuth.
- `isClaudeCodeCompatible(this.provider)` — αναμεταδότες των οποίων το αναγνωριστικό παρόχου ξεκινά με το
  πρόθεμα `anthropic-compatible-cc-` (δηλώνουν συμβατότητα με Claude Code, επομένως είναι οι αναμεταδότες
  που είναι πιθανότερο να αποδέχονται τη λειτουργία beta). Βλ. `open-sse/services/provider.ts`.

Εξαιρούνται **σκόπιμα**:

- `claude-web` — ένας αναμεταδότης προγράμματος περιήγησης με μορφή αιτήματος `create_conversation_params`, ο οποίος δεν λαμβάνει ποτέ
  το `context_management`.
- Γενικοί αναμεταδότες `anthropic-compatible-*` (χωρίς το πρόθεμα `-cc-`) — τελικά σημεία τρίτων με
  αβέβαιη υποστήριξη της λειτουργίας beta.

Οι πάροχοι που δεν είναι Claude δεν λαμβάνουν ποτέ την παράμετρο `context_management`, ακόμη και όταν η εναλλαγή είναι ενεργοποιημένη.

## Η εναλλακτική διαδρομή για 400 / κάλυψη αναμεταδοτών

Ένας αναμεταδότης συμβατός με Claude μπορεί να δηλώνει τη λειτουργία beta, αλλά παρ' όλα αυτά να απορρίπτει την παράμετρο `context_management`
με HTTP 400. Για ομαλή υποβάθμιση αντί για αποτυχία του αιτήματος, ο εκτελεστής αφαιρεί την
παράμετρο και επαναλαμβάνει το αίτημα προς το ίδιο URL **μία φορά**:

```ts
if (
  response.status === HTTP_STATUS.BAD_REQUEST &&
  contextEditing?.enabled &&
  !contextEditingDisabled &&
  transformedBody?.context_management !== undefined
) {
  const errText = await response
    .clone()
    .text()
    .catch(() => "");
  if (/context[_-]management|context editing/i.test(errText)) {
    contextEditingDisabled = true;
    delete transformedBody.context_management;
    let retryBody = JSON.stringify(transformedBody);
    if (isClaudeCodeCompatible(this.provider) || this.provider === "claude") {
      retryBody = await signRequestBody(retryBody);
    }
    response = await fetch(url, { ...fetchOptions, body: retryBody });
  }
}
```

Συμπεριφορά:

1. Ενεργοποιείται μόνο σε `400` όταν η επεξεργασία περιβάλλοντος είναι ενεργοποιημένη και το σώμα περιέχει πράγματι
   `context_management`.
2. Το σώμα της απόκρισης 400 διαβάζεται μέσω ενός `clone()`, ώστε η αρχική απόκριση να παραμένει ανέπαφη για τη διαδρομή
   που δεν αντιστοιχεί.
3. Το κείμενο σφάλματος πρέπει να αντιστοιχεί στο `/context[_-]management|context editing/i` — ένα άσχετο 400 (π.χ.
   `max_tokens must be >= 1`) **δεν** ενεργοποιεί την εναλλακτική διαδρομή· το αρχικό σφάλμα διαδίδεται.
4. Σε περίπτωση αντιστοίχισης, θέτει `contextEditingDisabled = true` (κάτι που αποτρέπει την εκ νέου έγχυση εάν αργότερα
   δημιουργηθεί νέο `transformedBody` για επανάληψη/εναλλακτικό URL), διαγράφει το `context_management`,
   υπογράφει εκ νέου το σώμα για Claude / αναμεταδότες συμβατούς με Claude Code (`signRequestBody`) και επαναλαμβάνει το αίτημα προς το
   ίδιο URL μία φορά.

Το γνήσιο Claude μεταφέρει τη λειτουργία beta στο `ANTHROPIC_BETA_BASE` και δεν ακολουθεί αυτή την εναλλακτική διαδρομή.

## Τηλεμετρία `applied_edits`

Μετά από μια απόκριση Claude, το OmniRoute καταγράφει πόσο περιβάλλον εκκαθάρισε πραγματικά ο πάροχος. Αυτό
**δεν** μεταδίδεται μέσω ροής — εξάγεται από το σώμα της απόκρισης χωρίς ροή, με τη μέγιστη δυνατή προσπάθεια, και δεν
επηρεάζει ποτέ την απόκριση (οι αποτυχίες τηλεμετρίας αγνοούνται).

- Εξαγωγή: `extractContextEditingTelemetry(responseBody)` στο `open-sse/config/contextEditing.ts`.
  Ελέγχει το `applied_edits` σε τρεις θέσεις (αμυντικά, λόγω της μορφής της απόκρισης):
  - `context_management.applied_edits`
  - `usage.context_management.applied_edits`
  - `usage.applied_edits`
- Πεδία ανά επεξεργασία που διαβάζονται από κάθε καταχώριση: `cleared_input_tokens` και `cleared_tool_uses`
  (snake_case, εγγενή στην Anthropic), με εναλλακτική χρήση των `clearedInputTokens` / `clearedToolUses` σε camelCase.
- Επιστρέφει `null` όταν δεν βρεθεί πίνακας `applied_edits` ή όταν δεν εκκαθαρίστηκε τίποτα.

Η μορφή της απόδειξης είναι `ContextEditingTelemetry { editCount, clearedInputTokens, clearedToolUses }`.
Η καταγραφή πραγματοποιείται στο `open-sse/handlers/chatCore.ts` (περιορίζεται σε `provider === "claude"`) μέσω του
`recordContextEditingTelemetry()` (`src/lib/db/compressionAnalytics.ts`), το οποίο γράφει μια εγγραφή αναλυτικών στοιχείων
συμπίεσης με τις ετικέτες:

- `mode: "context-editing"`
- `engine: "context-editing"`
- `tokens_saved` / `original_tokens` = το πλήθος των εκκαθαρισμένων διακριτικών εισόδου
- `request_id` με το επίθημα `::context-editing`

Έτσι, η εκχωρημένη εκκαθάριση εμφανίζεται στα αναλυτικά στοιχεία συμπίεσης μαζί με τις τοπικές μηχανές, κάτω από την
ετικέτα μηχανής `context-editing`, και μπορεί να διακριθεί από την εξοικονόμηση των RTK/Caveman/LLMLingua.

## Σχέση με τις τοπικές μηχανές συμπίεσης

| Πτυχή                    | Τοπικές μηχανές (Caveman / RTK / LLMLingua / stacked)    | Εκχωρημένη Επεξεργασία Περιβάλλοντος                             |
| ------------------------ | -------------------------------------------------------- | ---------------------------------------------------------------- |
| Πού εκτελείται           | Στο OmniRoute, πριν το αίτημα εξέλθει από τον proxy      | Στον πάροχο (Claude), στην πλευρά του server                     |
| Τι επεξεργάζεται         | Κείμενο prompt / περιβάλλοντος / αποτελέσματος εργαλείου | Παλιά μπλοκ χρήσης εργαλείου / αποτελέσματος εργαλείου           |
| Εμβέλεια παρόχων         | Όλοι οι πάροχοι                                          | Μόνο `claude` + `anthropic-compatible-cc-*`                      |
| Εναλλαγή                 | Ρυθμίσεις λειτουργίας συμπίεσης                          | `contextEditing.enabled`                                         |
| Τρόπος αποτυχίας         | Fail-open (αρχικό κείμενο)                               | Εναλλακτική σε περίπτωση 400: αφαίρεση παραμέτρου, μία επανάληψη |
| Τηλεμετρία εξοικονόμησης | `engine: <engine id>`                                    | `engine: "context-editing"`                                      |

Οι δύο προσεγγίσεις είναι συμπληρωματικές: οι τοπικές μηχανές συμπιέζουν τα byte που στέλνει το OmniRoute· η Επεξεργασία Περιβάλλοντος επιτρέπει στο
Claude να περικόπτει το τρέχον περιβάλλον μεταξύ διαδοχικών αλληλεπιδράσεων. Μπορούν να ενεργοποιηθούν ταυτόχρονα.
