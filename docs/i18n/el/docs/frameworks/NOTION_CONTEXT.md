> **Πηγή αλήθειας:** `src/lib/notion/api.ts` (REST client), `src/lib/db/notion.ts`
> (αποθήκευση token), `open-sse/mcp-server/tools/notionTools.ts` (6 εργαλεία MCP),
> `src/app/api/settings/notion/route.ts` (API ρυθμίσεων). Η καταχώριση εργαλείων και η
> διασύνδεση των scopes βρίσκονται στο `open-sse/mcp-server/server.ts`.

## Τι είναι

Το OmniRoute μπορεί να συνδεθεί σε έναν χώρο εργασίας **Notion** ως **πηγή context** — μια
βάση γνώσεων ανάγνωσης/εγγραφής στην οποία έχουν πρόσβαση οι agents μέσω του ενσωματωμένου
MCP server. Μόλις ρυθμιστεί ένα integration token του Notion, τα εργαλεία MCP επιτρέπουν
σε ένα LLM να αναζητά σελίδες και βάσεις δεδομένων, να διαβάζει περιεχόμενο σελίδων και
δέντρα blocks, να υποβάλλει ερωτήματα σε βάσεις δεδομένων με φίλτρα/ταξινομήσεις και να
προσθέτει νέα blocks — όλα μέσω proxy από το OmniRoute (με επανάληψη, χρονικό όριο και
ταξινόμηση σφαλμάτων), ώστε το μοντέλο να μην επικοινωνεί ποτέ απευθείας με το Notion API.

Η ενσωμάτωση είναι ένα λεπτό, ενισχυμένο wrapper γύρω από το επίσημο Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`). Ο client
(`src/lib/notion/api.ts`) προσθέτει:

- **Επανάληψη με εκθετική καθυστέρηση** (έως 3 προσπάθειες) για `429` και `5xx`.
- **Χρονικό όριο αιτήματος 55 δευτερολέπτων** μέσω `AbortController`.
- **Ταξινόμηση σφαλμάτων με τύπους** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, λαμβάνει υπόψη τις
  υποδείξεις `retry after`), `NotionValidationError` (400/409), `NotionServerError`
  (5xx), `NotionTimeoutError`.
- **Εξυγίανση μηνυμάτων** που αφαιρεί τμήματα παρόμοια με stack traces πριν από την
  εμφάνισή τους.

## Ρύθμιση

Δεν υπάρχει **καμία μεταβλητή περιβάλλοντος** για το token του Notion — αποθηκεύεται στον
πίνακα `key_value` της SQLite (namespace `notion`, key `integration_token`) μέσω του
`src/lib/db/notion.ts`. Ρυθμίστε το από την καρτέλα **Context Sources** του dashboard του
Endpoint (`NotionSourceCard`, αδελφό στοιχείο του `ObsidianSourceCard`) ή μέσω του REST API
ρυθμίσεων.

> [!NOTE]
> Το token είναι ένα **Notion internal integration token**. Δημιουργήστε μια integration
> στο <https://www.notion.com/my-integrations> και, στη συνέχεια, κοινοποιήστε στην
> integration τις σελίδες/βάσεις δεδομένων στις οποίες θέλετε να έχει πρόσβαση το
> OmniRoute (το μοντέλο δικαιωμάτων του Notion βασίζεται στην κοινοποίηση και δεν
> εφαρμόζεται σε ολόκληρο τον χώρο εργασίας).

### Ρύθμιση μέσω REST

```bash
# Αποθήκευση + επικύρωση του integration token (το POST εκτελεί μια δοκιμαστική αναζήτηση για επικύρωση)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# Έλεγχος της κατάστασης σύνδεσης
curl http://localhost:20128/api/settings/notion

# Αποσύνδεση (διαγράφει το αποθηκευμένο token)
curl -X DELETE http://localhost:20128/api/settings/notion
```

Και οι τρεις μέθοδοι απαιτούν έλεγχο ταυτότητας στο dashboard (`isAuthenticated`). Στο
`POST`, το OmniRoute αποθηκεύει το token και εκτελεί αμέσως μια δοκιμαστική αναζήτηση με
1 αποτέλεσμα· αν το Notion επιστρέψει αντικείμενο σφάλματος, το token διαγράφεται και η
κλήση αποτυγχάνει με `400`.

## Εργαλεία MCP (6)

Ορίζονται στο `open-sse/mcp-server/tools/notionTools.ts`. Το token ανακτάται κατά την
κλήση μέσω του `getNotionToken()`· αν δεν έχει ρυθμιστεί, το εργαλείο εμφανίζει το σφάλμα
`"Το integration token του Notion δεν έχει ρυθμιστεί. Ορίστε το στις Settings > Context Sources."`

| Εργαλείο                     | Scope          | Περιγραφή                                                                                                         |
| ---------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | Αναζήτηση σελίδων και βάσεων δεδομένων μέσω ερωτήματος κειμένου (επιστρέφει τίτλους, IDs, URLs). Με σελιδοποίηση. |
| `notion_get_page`            | `read:notion`  | Λήψη του περιεχομένου και των μεταδεδομένων μιας σελίδας βάσει του ID της.                                        |
| `notion_list_block_children` | `read:notion`  | Παράθεση όλων των θυγατρικών blocks ενός block ή μιας σελίδας (το δέντρο blocks). Με σελιδοποίηση.                |
| `notion_query_database`      | `read:notion`  | Υποβολή ερωτήματος σε βάση δεδομένων με προαιρετικά `filter` + `sorts` (μορφή Notion API). Με σελιδοποίηση.       |
| `notion_get_database`        | `read:notion`  | Λήψη του σχήματος/των μεταδεδομένων μιας βάσης δεδομένων βάσει ID.                                                |
| `notion_append_blocks`       | `write:notion` | Προσθήκη θυγατρικών blocks σε υπάρχον block ή σελίδα (έως 100 blocks ανά αίτημα).                                 |

### Παράμετροι εισόδου

- `notion_search` — `query` (1–500 χαρακτήρες), `pageSize` (1–100, προεπιλογή 20),
  `startCursor` (προαιρετικό).
- `notion_get_page` — `pageId` (δεκαεξαδική συμβολοσειρά 32 χαρακτήρων ή UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, προεπιλογή 50),
  `startCursor` (προαιρετικό).
- `notion_query_database` — `databaseId`, `filter` (προαιρετικό, μορφή φίλτρου Notion),
  `sorts` (προαιρετικός πίνακας), `pageSize` (1–100, προεπιλογή 50), `startCursor`
  (προαιρετικό).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (πίνακας αντικειμένων block),
  `after` (προαιρετική θέση).

### Scopes

Τα εργαλεία ανάγνωσης απαιτούν `read:notion` και το εργαλείο εγγραφής απαιτεί
`write:notion`. Τα scopes επιβάλλονται από το `withScopeEnforcement()` στο
`open-sse/mcp-server/server.ts` μόνο όταν `OMNIROUTE_MCP_ENFORCE_SCOPES=true`· τα
επιτρεπόμενα scopes του καλούντος προέρχονται από το `OMNIROUTE_MCP_SCOPES`
(διαχωρισμένα με κόμματα) ή από το context των scopes του πιστοποιημένου API key. Δείτε
το [MCP-SERVER.md](./MCP-SERVER.md) για το πλήρες μοντέλο scopes.

## Τελικά σημεία

| Μέθοδος  | Διαδρομή               | Σκοπός                                             |
| -------- | ---------------------- | -------------------------------------------------- |
| `GET`    | `/api/settings/notion` | Επιστρέφει `{ connected, hasToken }`.              |
| `POST`   | `/api/settings/notion` | Αποθηκεύει + επικυρώνει το διακριτικό ενσωμάτωσης. |
| `DELETE` | `/api/settings/notion` | Αποσυνδέει (διαγράφει το αποθηκευμένο διακριτικό). |

> Αυτές είναι διαδρομές ρυθμίσεων του πίνακα ελέγχου. **Δεν υπάρχει δημόσιο τελικό σημείο
> διαμεσολάβησης `/v1` για το Notion** — η πρόσβαση στο Notion πραγματοποιείται αποκλειστικά μέσω των παραπάνω εργαλείων MCP.

## Περιπτώσεις χρήσης

- **Απαντήσεις βασισμένες σε γνώση** — επιτρέψτε σε έναν πράκτορα να εκτελέσει `notion_search` στον χώρο εργασίας και
  `notion_get_page` για το κορυφαίο αποτέλεσμα πριν απαντήσει, ώστε οι απαντήσεις να παραπέμπουν σε πραγματική εσωτερική τεκμηρίωση.
- **Ροές εργασίας υποστηριζόμενες από βάση δεδομένων** — εκτελέστε `notion_query_database` σε μια βάση δεδομένων εργασιών/CRM με
  φίλτρα + ταξινομήσεις και, στη συνέχεια, συνοψίστε ή ιεραρχήστε τις γραμμές.
- **Εγγραφή / καταγραφή** — χρησιμοποιήστε το `notion_append_blocks` για να προσαρτήσετε σημειώσεις συναντήσεων, συνόψεις
  εκτελέσεων ή έξοδο πράκτορα σε μια υπάρχουσα σελίδα (μόνο προσάρτηση, χωρίς καταστροφικές επεξεργασίες).
- **Εξερεύνηση δομής** — χρησιμοποιήστε το `notion_list_block_children` για να διατρέξετε το δέντρο μπλοκ μιας σελίδας
  ή το `notion_get_database` για να ανακαλύψετε το σχήμα ιδιοτήτων μιας βάσης δεδομένων πριν την υποβολή ερωτήματος.
