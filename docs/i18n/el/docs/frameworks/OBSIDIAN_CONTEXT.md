> **Πηγή αλήθειας:** `src/lib/obsidian/api.ts` (πελάτης REST + συγχρονισμού),
> `src/lib/db/obsidian.ts` (αποθήκευση token / βασικού URL / WebDAV),
> `src/lib/obsidianSync.ts` (συγχρονισμός vault μέσω WebDAV), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 εργαλεία MCP), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API ρυθμίσεων). Η καταχώριση εργαλείων
> και η σύνδεση εμβελειών βρίσκονται στο `open-sse/mcp-server/server.ts`.

## Τι είναι

Το OmniRoute συνδέεται σε ένα vault του **Obsidian** ως **πηγή περιβάλλοντος** — μια τοπική
βάση γνώσεων Markdown την οποία οι agents διαβάζουν και επεξεργάζονται μέσω του ενσωματωμένου
διακομιστή MCP. Η ενσωμάτωση επικοινωνεί με το πρόσθετο κοινότητας **Obsidian Local REST API**
που εκτελείται μέσα στην εφαρμογή για υπολογιστές, ώστε οι agents να μπορούν να αναζητούν
σημειώσεις, να διαβάζουν/γράφουν/τροποποιούν αρχεία, να εμφανίζουν τα περιεχόμενα του vault,
να εργάζονται με ημερήσιες/εβδομαδιαίες περιοδικές σημειώσεις, να διαχειρίζονται ετικέτες,
να εκτελούν εντολές του Obsidian και (προαιρετικά) να συντονίζουν έναν αμφίδρομο συγχρονισμό
vault μεταξύ υπολογιστή↔κινητού.

Ο πελάτης (`src/lib/obsidian/api.ts`) περιβάλλει το Local REST API με:

- **Επανάληψη με σταδιακή καθυστέρηση** για προσωρινά σφάλματα `5xx`, **χρονικό όριο 30 δευτερολέπτων** μέσω `AbortController`.
- **Τυποποιημένη ταξινόμηση σφαλμάτων** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- Μια **φιλική υπόδειξη «δεν είναι δυνατή η σύνδεση με το Obsidian»**, η οποία επισημαίνει
  το συνηθισμένο λάθος θύρας (HTTP στη `27123`, **όχι** το endpoint MCP στη `27124`) και τη μορφή Tailscale.
- **Κωδικοποίηση διαδρομών** σχετικών με το vault, ώστε οι διαδρομές σημειώσεων με κενά/καθέτους να είναι ασφαλείς.

## Ρύθμιση

Δεν υπάρχει **καμία μεταβλητή περιβάλλοντος** για το token ή το βασικό URL του Obsidian — και τα δύο
αποθηκεύονται στον πίνακα SQLite `key_value` (namespace `obsidian`) μέσω του
`src/lib/db/obsidian.ts`. Το token είναι **κρυπτογραφημένο κατά την αποθήκευση** (AES-256-GCM, με
εφεδρική συμβατότητα προς τα πίσω για απλό κείμενο). Ρυθμίστε το από την καρτέλα **Πηγές περιβάλλοντος**
του πίνακα ελέγχου Endpoint (`ObsidianSourceCard`) ή μέσω του REST API ρυθμίσεων.

> [!IMPORTANT]
> Το πρόσθετο **Obsidian Local REST API** πρέπει να είναι εγκατεστημένο και να εκτελείται. Η διεπαφή
> REST του ακούει μέσω **HTTP στη `127.0.0.1:27123`** (το προεπιλεγμένο βασικό URL). Η θύρα `27124`
> είναι ένα _ξεχωριστό_ endpoint MCP/HTTPS και απορρίπτεται ρητά από τη διαδρομή ρυθμίσεων.
> Αν συνδέεστε από άλλη συσκευή, χρησιμοποιήστε `http://<tailscale-ip>:27123`.

### Κλειδιά διαμόρφωσης (SQLite `key_value`, namespace `obsidian`)

| Κλειδί            | Σκοπός                                                       | Κρυπτογραφημένο |
| ----------------- | ------------------------------------------------------------ | --------------- |
| `api_key`         | Bearer token του Local REST API                              | ναι             |
| `base_url`        | Βασικό URL REST (προεπιλογή `http://127.0.0.1:27123`)        | όχι             |
| `vault_path`      | Απόλυτη διαδρομή προς τον κατάλογο vault (για συγχρονισμό)   | όχι             |
| `webdav_username` | Δημιουργημένο όνομα χρήστη WebDAV (συγχρονισμός vault)       | όχι             |
| `webdav_password` | Δημιουργημένος κωδικός πρόσβασης WebDAV (συγχρονισμός vault) | ναι             |
| `webdav_enabled`  | Αν είναι ενεργοποιημένος ο συγχρονισμός vault μέσω WebDAV    | όχι             |

### Διαμόρφωση μέσω REST

```bash
# Αποθήκευση + επικύρωση του token του Local REST API (το POST το επικυρώνει μέσω ελέγχου κατάστασης)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Έλεγχος κατάστασης σύνδεσης (επιστρέφει connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Αποσύνδεση (διαγράφει το αποθηκευμένο token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Όλες οι μέθοδοι απαιτούν έλεγχο ταυτότητας στον πίνακα ελέγχου. Το `POST` απορρίπτει οποιοδήποτε URL
στη θύρα `27124` και επικυρώνει το token καλώντας το endpoint κατάστασης του Local REST API πριν από
την αποθήκευση.

### Συγχρονισμός vault μέσω WebDAV

Το `src/app/api/settings/obsidian/webdav/route.ts` διαχειρίζεται έναν προαιρετικό συγχρονισμό
vault που υποστηρίζεται από WebDAV (μέσω του `src/lib/obsidianSync.ts`). Η ενεργοποίησή του κατευθύνει
το OmniRoute σε έναν τοπικό κατάλογο vault και δημιουργεί ένα τυχαίο ζεύγος ονόματος χρήστη/κωδικού
πρόσβασης WebDAV:

```bash
# Ενεργοποίηση συγχρονισμού WebDAV για έναν κατάλογο vault (δημιουργεί όνομα χρήστη/κωδικό πρόσβασης)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Λήψη κατάστασης συγχρονισμού WebDAV (τα διαπιστευτήρια επιστρέφονται μόνο όταν είναι ενεργοποιημένος)
curl http://localhost:20128/api/settings/obsidian/webdav

# Απενεργοποίηση συγχρονισμού WebDAV (διαγράφει τα διαπιστευτήρια + το διαχειριζόμενο .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Πηγή περιβάλλοντος ανά κλειδί API (προαιρετικό)

Η διαμόρφωση του Obsidian μπορεί να έχει εμβέλεια **ανά κλειδί API** μέσω του πίνακα
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Όταν μια κλήση MCP περιλαμβάνει
ένα αναγνωριστικό αυθεντικοποιημένου κλειδιού API, η `getObsidianConfigForApiKey()` προτιμά το
token/βασικό URL/διαδρομή vault του συγκεκριμένου κλειδιού (`source: "api_key"`) και, διαφορετικά,
επιστρέφει στην καθολική διαμόρφωση (`source: "global"`).

## Εργαλεία MCP (22)

Ορίζονται στο `open-sse/mcp-server/tools/obsidianTools.ts`. Το token/base-URL επιλύεται
ανά κλήση (πρώτα ανά κλειδί API και έπειτα καθολικά). Τα εργαλεία που επικοινωνούν με τον **διακομιστή συγχρονισμού**
του OmniRoute (τα τέσσερα εργαλεία `obsidian_sync_*`) απαιτούν επιπλέον το token ελέγχου ταυτότητας συγχρονισμού που έχει διαμορφωθεί
στις ρυθμίσεις του OmniRoute.

### Εργαλεία ανάγνωσης (`read:obsidian`)

| Εργαλείο                     | Περιγραφή                                                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Ελέγχει αν το Local REST API είναι προσβάσιμο και έχει πραγματοποιηθεί έλεγχος ταυτότητας.                                |
| `obsidian_search_simple`     | Αναζήτηση πλήρους κειμένου στο περιεχόμενο σημειώσεων· επιστρέφει αποσπάσματα με διαδρομές αρχείων.                       |
| `obsidian_search_structured` | Αναζήτηση με χρήση έκφρασης JSON Logic (φίλτρα and/or/regex/path).                                                        |
| `obsidian_read_note`         | Διαβάζει μια σημείωση βάσει διαδρομής σχετικής προς το vault· προαιρετικά μια συγκεκριμένη επικεφαλίδα/μπλοκ/frontmatter. |
| `obsidian_list_vault`        | Παραθέτει αρχεία και καταλόγους στο vault (δέντρο καταχωρίσεων).                                                          |
| `obsidian_get_document_map`  | Λαμβάνει τη δομή επικεφαλίδων της σημείωσης ως αντιστοίχιση επικεφαλίδων → αριθμών γραμμών.                               |
| `obsidian_get_note_metadata` | Λαμβάνει frontmatter, ετικέτες, συνδέσμους και πλήθος χαρακτήρων/λέξεων χωρίς το πλήρες περιεχόμενο.                      |
| `obsidian_get_active_file`   | Λαμβάνει τη διαδρομή και το περιεχόμενο του τρέχοντος ενεργού αρχείου στο Obsidian.                                       |
| `obsidian_get_periodic_note` | Λαμβάνει την ημερήσια/εβδομαδιαία/μηνιαία περιοδική σημείωση για μια ημερομηνία (τη σημερινή, αν παραλειφθεί).            |
| `obsidian_get_tags`          | Παραθέτει όλες τις ετικέτες του vault μαζί με τη συχνότητά τους.                                                          |
| `obsidian_list_commands`     | Παραθέτει τα διαθέσιμα αναγνωριστικά εντολών του Obsidian (για χρήση με το `obsidian_execute_command`).                   |
| `obsidian_sync_status`       | Κατάσταση διακομιστή συγχρονισμού OmniRoute: εκτέλεση, όνομα vault, θύρα, χρόνος λειτουργίας, τελευταίος συγχρονισμός.    |
| `obsidian_sync_conflicts`    | Παραθέτει τις ανεπίλυτες διενέξεις συγχρονισμού (διαδρομή, διαδρομή διένεξης, χρόνος εντοπισμού).                         |

### Εργαλεία εγγραφής (`write:obsidian`)

| Εργαλείο                         | Περιγραφή                                                                                           |
| -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Δημιουργεί ή αντικαθιστά μια σημείωση με το δοθέν περιεχόμενο Markdown.                             |
| `obsidian_append_note`           | Προσαρτά περιεχόμενο σε μια σημείωση· προαιρετικά σε συγκεκριμένη επικεφαλίδα/μπλοκ.                |
| `obsidian_patch_note`            | Προσαρτά/προτάσσει/αντικαθιστά στοχευμένα σε επικεφαλίδα, μπλοκ ή πεδίο frontmatter.                |
| `obsidian_delete_note`           | Διαγράφει οριστικά μια σημείωση από το vault.                                                       |
| `obsidian_move_note`             | Μετακινεί ή μετονομάζει μια σημείωση μέσα στο vault.                                                |
| `obsidian_execute_command`       | Εκτελεί μια εντολή του Obsidian βάσει του αναγνωριστικού εντολής της.                               |
| `obsidian_open_file`             | Ανοίγει ένα αρχείο στο Obsidian (το δημιουργεί αν δεν υπάρχει).                                     |
| `obsidian_sync_trigger`          | Ενεργοποιεί άμεσο αμφίδρομο συγχρονισμό του vault μεταξύ υπολογιστή↔κινητού.                        |
| `obsidian_sync_resolve_conflict` | Επιλύει μια διένεξη συγχρονισμού: διατήρηση `local` (κινητό), `remote` (υπολογιστής) ή `keep-both`. |

> [!NOTE]
> Οι στόχοι του `obsidian_patch_note` δέχονται `targetType` με τιμή `heading | block | frontmatter`
> και `operation` με τιμή `append | prepend | replace`, με προαιρετικό
> `createTargetIfMissing`. Τα τέσσερα εργαλεία `obsidian_sync_*` επικοινωνούν με τον τοπικό διακομιστή συγχρονισμού
> (`http://127.0.0.1:27781` από προεπιλογή) και απαιτούν το token συγχρονισμού.

### Εμβέλειες

Τα εργαλεία ανάγνωσης απαιτούν `read:obsidian`· τα εργαλεία εγγραφής απαιτούν `write:obsidian`. Η επιβολή
είναι ίδια με του Notion — διεκπεραιώνεται από το `withScopeEnforcement()` στο
`open-sse/mcp-server/server.ts`, ενεργοποιείται όταν `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, με
τις επιτρεπόμενες εμβέλειες να προέρχονται από το `OMNIROUTE_MCP_SCOPES` ή από το πλαίσιο εμβέλειας του κλειδιού API. Δείτε το
[MCP-SERVER.md](./MCP-SERVER.md).

## Τελικά σημεία

| Μέθοδος  | Διαδρομή                        | Σκοπός                                                                        |
| -------- | ------------------------------- | ----------------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Επιστρέφει `{ connected, hasToken, baseUrl, vaultPath }`.                     |
| `POST`   | `/api/settings/obsidian`        | Αποθηκεύει και επικυρώνει το token (απορρίπτει τη θύρα `27124`).              |
| `DELETE` | `/api/settings/obsidian`        | Αποσυνδέει (διαγράφει το αποθηκευμένο token).                                 |
| `GET`    | `/api/settings/obsidian/webdav` | Κατάσταση συγχρονισμού WebDAV και διαπιστευτήρια (όσο είναι ενεργοποιημένος). |
| `POST`   | `/api/settings/obsidian/webdav` | Ενεργοποιεί τον συγχρονισμό WebDAV για έναν κατάλογο vault.                   |
| `DELETE` | `/api/settings/obsidian/webdav` | Απενεργοποιεί τον συγχρονισμό WebDAV.                                         |

> Αυτές είναι διαδρομές ρυθμίσεων του πίνακα ελέγχου. Η πρόσβαση στο ίδιο το vault γίνεται μέσω του Obsidian
> Local REST API (του διαμορφωμένου `base_url`) και μέσω των παραπάνω εργαλείων MCP — δεν υπάρχει
> δημόσιο τελικό σημείο διαμεσολάβησης `/v1` για το Obsidian.

## Περιπτώσεις χρήσης

- **Απαντήσεις βασισμένες στο vault** — `obsidian_search_simple` / `obsidian_search_structured`
  και έπειτα `obsidian_read_note`, ώστε ένας agent να απαντά με βάση τις πραγματικές σας σημειώσεις.
- **Σύνταξη σημειώσεων / τήρηση ημερολογίου** — `obsidian_write_note`, `obsidian_append_note` ή
  το χειρουργικά ακριβές `obsidian_patch_note`, για την καταγραφή εξόδου του agent, συνόψεων ή ημερήσιων σημειώσεων
  (`obsidian_get_periodic_note`) στο vault.
- **Πλοήγηση στο vault** — `obsidian_list_vault`, `obsidian_get_document_map` και
  `obsidian_get_tags` για εξερεύνηση της δομής πριν από την ανάγνωση/εγγραφή.
- **Αυτοματοποίηση του Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` για
  τον χειρισμό προσθέτων/εντολών από έναν agent· `obsidian_open_file` για την εμφάνιση μιας σημείωσης στο περιβάλλον χρήστη.
- **Συγχρονισμός με κινητές συσκευές** — ενεργοποιήστε τον συγχρονισμό WebDAV και έπειτα χρησιμοποιήστε τα `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  για τον συντονισμό υπολογιστή↔κινητού και την επίλυση διενέξεων.
