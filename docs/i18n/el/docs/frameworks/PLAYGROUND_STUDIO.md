## Επισκόπηση

Το Playground Studio μετατρέπει το `/dashboard/playground` από έναν απλό επεξεργαστή βασισμένο στο Monaco σε
έναν πλήρως εξοπλισμένο χώρο εργασίας δοκιμών. Αντικαθιστά το παλαιό `page.tsx` με ένα κέλυφος `PlaygroundStudio`
που εμφανίζει τέσσερις καρτέλες και ένα κοινό τμήμα παραμέτρων.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Συνομιλία] [⚖ Σύγκριση] [{} API] [🔧 Δημιουργία] 142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {περιεχόμενο ενεργής καρτέλας}          │ ─ Παράμετροι              │
│                                          │ Τελικό σημείο [chat ∨]    │
│                                          │ Μοντέλο       [gpt-5.4 ∨] │
│                                          │ Σύστημα       [textarea]  │
│                                          │ Θερμοκρασία   ▕▕▔▔ 0.7    │
│                                          │ Προεπιλογές [▾ φόρτωση][αποθήκευση]│
│                                          │ [✨ Βελτίωση προτροπής]    │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Καρτέλες

### Καρτέλα συνομιλίας

Εξελίσσει το `ChatPlayground.tsx` σε έναν χώρο εργασίας πολλαπλών γύρων με ροή δεδομένων:

- Πλήρης απόδοση markdown μέσω του `MarkdownMessage.tsx` (μπλοκ κώδικα, πίνακες, λίστες, σύνδεσμοι).
- Η προτροπή συστήματος προέρχεται από το κοινό τμήμα παραμέτρων.
- Token/κόστος ανά μήνυμα (token προτροπής + token ολοκλήρωσης).
- Επαναδημιουργία της τελευταίας απάντησης.
- Αποστολή στο `POST /v1/chat/completions` με ροή SSE.

### Καρτέλα σύγκρισης

Το βασικό χαρακτηριστικό διαφοροποίησης για έναν proxy: εκτέλεση 1 προτροπής σε έως και **4 μοντέλα παράλληλα**.

- Έως 4 στήλες, καθεμία με ανεξάρτητη ροή από το `/v1/chat/completions`.
- Κουμπί `+ Προσθήκη μοντέλου` (συντόμευση Cmd+K) για την προσθήκη στηλών.
- Το `Εκτέλεση όλων ▶` ενεργοποιεί όλες τις ροές ταυτόχρονα μέσω `Promise.all` + ξεχωριστού `AbortController` ανά στήλη.
- Η καθολική επιλογή **Ακύρωση όλων** διακόπτει κάθε ροή που βρίσκεται σε εξέλιξη.
- Το `ProviderMetrics` ανά στήλη εμφανίζει σε πραγματικό χρόνο TTFT, TPS, token και εκτιμώμενο κόστος.
- Οι μετρήσεις επισημαίνονται ως **«εκτίμηση στην πλευρά του πελάτη»** (D12) — μετρούνται από το πρώτο τμήμα SSE.

### Καρτέλα API

Διατηρεί το 100% του αρχικού επεξεργαστή Monaco για προχωρημένους χρήστες (D14):

- 10 τελικά σημεία: ολοκληρώσεις συνομιλίας, ολοκληρώσεις, ενσωματώσεις, εικόνες, ήχος, ομιλία, μεταγραφές, εποπτεία περιεχομένου, ανακατάταξη, αναζήτηση.
- Μεταφόρτωση πολυτροπικών αρχείων.
- Ροή SSE με έξοδο σε πραγματικό χρόνο.
- Ενσωματωμένο ως `ApiTab.tsx` (με οκνηρή φόρτωση, `ssr: false`).

### Καρτέλα δημιουργίας

Διεπαφή χρήστη για εργαλεία/κλήση συναρτήσεων και δομημένη έξοδο:

- `ToolsBuilder.tsx` — προσθήκη/επεξεργασία/κατάργηση `tools[]` με επεξεργαστή σχήματος JSON ανά εργαλείο.
  Επικυρώνει τις παραμέτρους μέσω του `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — εναλλαγή λειτουργίας JSON + επεξεργαστής σχήματος JSON.
  Επικυρώνει την απόκριση βάσει του σχήματος μέσω του `StructuredOutputSchema` (Zod).
- Στέλνει το αίτημα στο `/v1/chat/completions` με `tools[]` ή/και `response_format`.

## Παράθυρο ρυθμίσεων (Κοινόχρηστο)

`StudioConfigPane.tsx` — πάντα ορατό, με δυνατότητα σύμπτυξης.

| Πεδίο                     | Στοιχείο              | Σημειώσεις                                                                              |
| ------------------------- | --------------------- | --------------------------------------------------------------------------------------- |
| Τελικό σημείο             | `<select>`            | 10 επιλογές που αντιστοιχούν στο `PlaygroundEndpoint`                                   |
| Μοντέλο                   | `<input>`             | ελεύθερο κείμενο, π.χ. `openai/gpt-4o`                                                  |
| Προτροπή συστήματος       | `<textarea>`          | παρέχεται σε όλες τις καρτέλες                                                          |
| Παράμετροι                | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop                  |
| Προκαθορισμένες ρυθμίσεις | `PresetPicker`        | φόρτωση/αποθήκευση επώνυμων στιγμιότυπων ρυθμίσεων (διατηρούνται στη ΒΔ)                |
| Βελτίωση προτροπής        | `ImprovePromptButton` | ανοίγει παράθυρο προειδοποίησης ορίου χρήσης, καλεί το `/api/playground/improve-prompt` |

Η κατάσταση ανυψώνεται στο `PlaygroundStudio.tsx` και μεταβιβάζεται σε όλες τις καρτέλες. Η εναλλαγή καρτελών
διατηρεί την κατάσταση των ρυθμίσεων.

## Βελτιωτής προτροπών

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Το παράθυρο προειδοποιεί ότι «θα καταναλωθεί το όριο χρήσης».
2. Μετά την επιβεβαίωση, στέλνει `{ system, prompt, model, tone }` στη διαδρομή.
3. Η διαδρομή καλεί εσωτερικά το `/v1/chat/completions` με το `promptImprover.META_SYSTEM_PROMPT`.
4. Επιστρέφει `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. Το περιβάλλον χρήστη ενημερώνει την προτροπή συστήματος στο παράθυρο ρυθμίσεων και την προτροπή χρήστη στην καρτέλα συνομιλίας.

## Προκαθορισμένες ρυθμίσεις

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Αποθηκεύονται στον πίνακα SQLite `playground_presets` (μετεγκατάσταση `084_playground_presets.sql`).
- Κάθε προκαθορισμένη ρύθμιση αποθηκεύει: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: λίστα μέσω `GET`, δημιουργία μέσω `POST`, `GET /:id`, `PUT /:id`, `DELETE /:id`.

## Μετρικές ροής

`useStreamMetrics.ts` + `streamMetrics.ts` (καθαρή συνάρτηση):

- `start()` — καταγράφει την ώρα έναρξης του αιτήματος.
- `onFirstChunk()` — καταγράφει το TTFT.
- `onChunk(n)` — συγκεντρώνει τον αριθμό διακριτικών ολοκλήρωσης.
- `finish(usage?)` — υπολογίζει τις τελικές μετρικές: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Τιμολόγηση από τον στατικό πίνακα στο `src/lib/playground/types.ts` (με την ένδειξη «εκτιμώμενη» — D13).

## Διαδρομές backend

| Μέθοδος  | Διαδρομή                         | Χειριστής                                                                                           |
| -------- | -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | Επικυρώνει με Zod το `ImprovePromptRequestSchema`· καλεί το `/v1/chat/completions` με μετα-προτροπή |
| `GET`    | `/api/playground/presets`        | Επιστρέφει `{ presets: PlaygroundPresetListItem[] }`                                                |
| `POST`   | `/api/playground/presets`        | Δημιουργεί προκαθορισμένη ρύθμιση· επικυρώνει το `PlaygroundPresetCreateSchema`                     |
| `GET`    | `/api/playground/presets/:id`    | Επιστρέφει μία προκαθορισμένη ρύθμιση ή 404                                                         |
| `PUT`    | `/api/playground/presets/:id`    | Μερική ενημέρωση                                                                                    |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                 |

Έλεγχος ταυτότητας: προαιρετικός (`REQUIRE_API_KEY`). Σφάλματα μέσω `buildErrorBody()` (Αυστηρός κανόνας #12).

## Αντιμετώπιση προβλημάτων

| Σύμπτωμα                                              | Αιτία                                                | Διόρθωση                                                                                                               |
| ----------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Ο επεξεργαστής Monaco δεν αποδίδεται στην καρτέλα API | Το SSR φόρτωσε το Monaco                             | Επαληθεύστε ότι το `ApiTab` χρησιμοποιεί `dynamic(..., { ssr: false })`                                                |
| Οι ροές σύγκρισης ξεκινούν διαδοχικά                  | Εσφαλμένη χρήση του `Promise.all`                    | Όλες οι εκκινήσεις ροών πρέπει να αποστέλλονται σε μία κλήση `Promise.all`                                             |
| Οι μετρικές εμφανίζουν `null` για το TTFT             | Δεν έχει συνδεθεί ο χειριστής του πρώτου τμήματος    | Ελέγξτε ότι το `useStreamMetrics.onFirstChunk()` καλείται στον βρόχο ανάγνωσης SSE                                     |
| Η προεπιλογή δεν διατηρείται                          | Δεν εκτελέστηκε η μετεγκατάσταση της βάσης δεδομένων | Εκτελέστε `npm run db:migrate` ή επανεκκινήστε τον διακομιστή (η μετεγκατάσταση εκτελείται αυτόματα κατά την εκκίνηση) |
| Η βελτίωση της προτροπής επιστρέφει 502               | Δεν έχει οριστεί μοντέλο στις Ρυθμίσεις              | Ο χρήστης πρέπει να εισαγάγει ένα όνομα μοντέλου στο παράθυρο Ρυθμίσεων πριν από τη βελτίωση                           |
| Ο εξαγόμενος κώδικας εμφανίζει `MISSING_API_KEY`      | Δεν εισήχθη το σύμβολο κράτησης θέσης                | Το `codeExport.ts` χρησιμοποιεί πάντα `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"`                                     |
