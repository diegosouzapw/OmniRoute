> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 εργαλεία MCP μόνο για ανάγνωση) και
> `src/app/api/settings/local-corpus/route.ts` (API ρυθμίσεων).

## Τι είναι

Το Local Corpus επιτρέπει σε έναν διαχειριστή να διαθέσει έναν ρητά εγκεκριμένο κατάλογο αρχείων κειμένου στον
διακομιστή MCP του OmniRoute. Τα αρχεία παραμένουν στον αρχικό τους κατάλογο: το OmniRoute αποθηκεύει μόνο
την κανονικοποιημένη διαδρομή ρίζας στο SQLite και διατηρεί ένα ευρετήριο αναζήτησης στη μνήμη. Δεν
αντιγράφει το περιεχόμενο του corpus στο αποθετήριο ή στη βάση δεδομένων.

Η ανανέωση του ευρετηρίου είναι επαυξητική. Τα αρχεία που δεν έχουν αλλάξει επαναχρησιμοποιούνται βάσει του μεγέθους και του χρόνου
τροποποίησης, ενώ τα αρχεία που έχουν αλλάξει διαβάζονται εκ νέου και κατακερματίζονται με SHA-256 και τα διαγραμμένα αρχεία αφαιρούνται.
Η αναζήτηση ανανεώνει ένα ευρετήριο παλαιότερο των 30 δευτερολέπτων· οι καλούντες μπορούν επίσης να ζητήσουν άμεση
ανανέωση.

## Διαμόρφωση της πηγής

Η διαδρομή ρυθμίσεων απαιτεί τον ίδιο έλεγχο ταυτότητας διαχείρισης με τα άλλα API ρυθμίσεων.
Η υποβαλλόμενη διαδρομή πρέπει να υπάρχει ήδη και να είναι απόλυτη διαδρομή καταλόγου.

```bash
# Σύνδεση ενός εγκεκριμένου καταλόγου
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Έλεγχος της διαμόρφωσης και της κατάστασης του ευρετηρίου
curl http://localhost:20128/api/settings/local-corpus

# Αποσύνδεση χωρίς αλλαγή των αρχείων προέλευσης
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Εργαλεία MCP

Και τα τρία εργαλεία απαιτούν `read:local-corpus`. Οι αποκρίσεις των εργαλείων εμφανίζουν σχετικές διαδρομές και
το βασικό όνομα του καταλόγου ρίζας, ποτέ την απόλυτη διαδρομή του.

| Εργαλείο              | Περιγραφή                                                                                                     |
| :-------------------- | :------------------------------------------------------------------------------------------------------------ |
| `local_corpus_status` | Αναφέρει την κατάσταση διαμόρφωσης, το μέγεθος του ευρετηρίου, τα όρια και τον χρόνο της τελευταίας ανανέωσης |
| `local_corpus_search` | Αναζητά στο ευρετηριασμένο κείμενο και επιστρέφει περιορισμένα αποσπάσματα ανά γραμμή (έως 20 αποτελέσματα)   |
| `local_corpus_read`   | Διαβάζει ένα περιορισμένο εύρος γραμμών από ένα επιτρεπόμενο αρχείο με διαδρομή σχετική προς το corpus        |

Παραδείγματα εισόδων MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Όρια ασφαλείας

- Η λίστα επιτρεπόμενων τύπων είναι προσανατολισμένη σε αρχεία κειμένου: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` και `.yml`.
- Οι συμβολικοί σύνδεσμοι παραλείπονται. Οι διαδρομές ανάγνωσης κανονικοποιούνται και πρέπει να παραμένουν εντός της
  διαμορφωμένης ρίζας· οι απόλυτες διαδρομές και οι απόπειρες διάσχισης καταλόγων απορρίπτονται.
- Εξαιρούνται ονόματα ευαίσθητων και παραγόμενων καταλόγων: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` και
  `secrets`.
- Τα προεπιλεγμένα όρια είναι 5.000 αρχεία, 1 MiB ανά αρχείο, 64 MiB συνολικού ευρετηριασμένου περιεχομένου,
  περίπου 4.000 χαρακτήρες ανά τμήμα αναζήτησης και 400 γραμμές ανά ανάγνωση.
- Τα αρχεία που περιέχουν NUL αντιμετωπίζονται ως μη κειμενικά και παραλείπονται ή απορρίπτονται.

Δυαδικά έγγραφα όπως PDF, DOCX, εικόνες και αρχεία αρχειοθέτησης δεν υποστηρίζονται σκόπιμα.
Μετατρέψτε τα σε εγκεκριμένη μορφή κειμένου στον διαμορφωμένο κατάλογο πριν από την ευρετηρίαση.

## Σημειώσεις λειτουργίας

- Η αλλαγή ή η διαγραφή της διαμορφωμένης ρίζας εκκαθαρίζει το κοινόχρηστο ευρετήριο στη μνήμη.
- Η επανεκκίνηση της διεργασίας απορρίπτει το ευρετήριο· η επόμενη αναζήτηση το ανακατασκευάζει από τη διαμορφωμένη
  πηγή.
- Το `local_corpus_status` δεν επιβάλλει σάρωση. Χρησιμοποιήστε το `local_corpus_search` με
  `refresh: true` όταν απαιτείται άμεση επανασάρωση.
- Οι αποτυχίες σάρωσης και ανάγνωσης καταμετρώνται ή επιστρέφονται ως αποκαθαρμένα σφάλματα· τα αρχεία προέλευσης
  δεν τροποποιούνται ποτέ.
