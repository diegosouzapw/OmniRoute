Το `devin-cli-agentic` επιτρέπει στο πραγματικό περιβάλλον εκτέλεσης Claude Code να χρησιμοποιεί το τοπικό endpoint Anthropic
Messages του OmniRoute, ενώ το επίσημο Devin CLI παρέχει αποκρίσεις μοντέλου μέσω ACP stdio. Δεν
τροποποιεί τους υπάρχοντες παρόχους Anthropic, Claude OAuth, Claude Web ή `devin-cli`.

> **Τρέχουσα κατάσταση: καρφιτσωμένο Claude Code `2.1.258`· η τελευταία καταγεγραμμένη επικύρωση
> εκτός σύνδεσης και σε πραγματικό περιβάλλον έγινε στην έκδοση `2.1.220`.** Η καρφιτσωμένη έκδοση `2.1.220` ολοκλήρωσε τρία απομονωμένα σενάρια μέσω του Devin CLI
> `3000.2.17` και του μοντέλου `swe-1-7-lightning`· εκείνη η τελική εκτέλεση σε πραγματικό περιβάλλον επιβεβαίωσε γύρους `Read`,
> `Edit` και `Bash` υπό τον έλεγχο του πελάτη, επιτυχή αποτελέσματα `npm test`, εντοπισμό εντολών και δεξιοτήτων
> έργου, δρομολόγηση αποκλειστικά μέσω Devin και μηδενική εξερχόμενη κίνηση προς το Claude. Στη συνέχεια, η καρφιτσωμένη έκδοση αναβαθμίστηκε στην `2.1.258`
> (τη γενιά CLI την οποία μιμείται η ταυτότητα Claude του OmniRoute και την πρώτη σειρά που διαθέτει
> εγγενώς το επίπεδο Fable 5.1). Στη νέα καρφιτσωμένη έκδοση, το επίπεδο εγκατάστασης και η εντολή `claude --version`
> επαληθεύτηκαν στην καρφιτσωμένη βασική εικόνα, ενώ η σουίτα δοκιμών μονάδας της γέφυρας, το `compose config` και η
> στατική απόδειξη απομόνωσης ολοκληρώνονται επιτυχώς — όμως το σενάριο προσομοίωσης εκτός σύνδεσης και η σουίτα τριών σεναρίων
> σε πραγματικό περιβάλλον δεν έχουν εκτελεστεί ξανά ακόμη. Εκτελέστε τα ξανά (δείτε «Ενημέρωση καρφιτσωμένων εργαλείων») προτού βασιστείτε
> στη γέφυρα με αυτή την καρφιτσωμένη έκδοση.

## Αρχιτεκτονική

```text
Claude Code 2.1.258 (απομονωμένο κοντέινερ Linux χωρίς δικαιώματα root)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (πάροχος μορφής Claude, χωρίς έλεγχο ταυτότητας)
  -> devin acp --agent-type summarizer (επίσημο ACP stdio, χωρίς εργαλεία Devin)
  -> λογαριασμός Devin στον αποκλειστικό τόμο devin-auth
```

Ο προεπιλεγμένος πράκτορας ACP του επίσημου CLI μπορεί να εκτελεί τα δικά του εργαλεία, επομένως αυτή η γέφυρα δεν τον
χρησιμοποιεί. Εκκινεί τον σταθερό πράκτορα ACP `summarizer`, του οποίου η επίσημη λειτουργία CLI δεν διαθέτει εργαλεία, και
πλαισιώνει το σειριοποιημένο αίτημα Anthropic ως ίχνος εκτέλεσης. Όταν απαιτείται άλλη ενέργεια υπό τον έλεγχο του Claude,
η απόκριση πρέπει να περιέχει ακριβώς έναν φάκελο εργαλείου πελάτη. Οποιοδήποτε ACP
`tool_call` ή `tool_call_update` απορρίπτεται πριν μια απόκριση μπορέσει να αναφερθεί ως
επιτυχής.

Ο σειριοποιητής στο `open-sse/executors/devin-agentic/serializer.ts` διατηρεί τα `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` και τα
εργαλεία που παρέχονται από το Claude Code. Οι εικόνες και τα άγνωστα μπλοκ αποτυγχάνουν ρητά. Τα μεγάλα αποτελέσματα εργαλείων
χρησιμοποιούν έναν ορατό δείκτη περικοπής.

Ο αναλυτής δέχεται έναν αυτόνομο φάκελο `<tool>{...}</tool>` ανά γύρο του μοντέλου. Ελέγχει
το όνομα σε σχέση με τη λίστα εργαλείων του αιτήματος, επικυρώνει τα ορίσματα βάσει του JSON
Schema αυτού του εργαλείου, απορρίπτει τον συνδυασμό αφήγησης και ενεργειών και επιτρέπει μία περιορισμένη προσπάθεια διόρθωσης. Στη συνέχεια, το Claude Code
εκτελεί το `tool_use` του Anthropic που προκύπτει τοπικά και στέλνει το `tool_result` πίσω μέσω
του OmniRoute.

## Απομόνωση και μοντέλο απειλών

Η εγκατάσταση, ο λογαριασμός και η διαμόρφωση Claude του κεντρικού συστήματος βρίσκονται εκτός πεδίου εφαρμογής και θεωρούνται
απαγορευμένα. Οι υπηρεσίες Compose:

- εκτελούνται ως UID/GID `10001:10001`, με σύστημα αρχείων ρίζας μόνο για ανάγνωση, καταργημένες δυνατότητες και
  `no-new-privileges`·
- χρησιμοποιούν ιδιωτικό `/home/bridge`, αποκλειστικό τόμο διαμόρφωσης Claude, απομονωμένα δεδομένα OmniRoute
  και ξεχωριστό τόμο `devin-auth`·
- προσαρτούν μόνο αναλώσιμους χώρους εργασίας/τεκμήρια `.sandbox`·
- δεν προσαρτούν τον προσωπικό κατάλογο του κεντρικού συστήματος, το Keychain, τα SSH, τα διαπιστευτήρια cloud ή την υποδοχή Docker·
- κατασκευάζουν ρητά περιβάλλοντα και αφαιρούν μεταβλητές API/OAuth/δρομολόγησης του Anthropic·
- κατευθύνουν τη συμπερασματολογία του Claude Code μόνο στο `http://omniroute:20128` με κλειδί αποκλειστικά τοπικής χρήσης.

Το προφίλ εκτός σύνδεσης χρησιμοποιεί εσωτερικό δίκτυο. Στο προφίλ πραγματικού περιβάλλοντος, το OmniRoute αποκτά πρόσβαση στα
επίσημα endpoint του Devin μόνο μέσω του `network-guard`· μη σχετικοί προορισμοί απορρίπτονται.
Το Claude Code διαθέτει ξεχωριστό μηχανισμό προστασίας που απαγορεύει όλη την εξερχόμενη κίνηση και μπορεί να προσπελάσει μόνο την τοπική υπηρεσία OmniRoute
μέσω του `NO_PROXY`. Τα αρχεία ελέγχου των μηχανισμών προστασίας προσαρτώνται μόνο από τη δική τους διεργασία προστασίας. Τα
σενάρια επαληθεύουν την κυριότητα αρχείων, τη λειτουργία, τον αριθμό συνδέσμων και κάθε απόφαση πριν εξαγάγουν
τεκμήρια χωρίς token.

Εκτελέστε ανεξάρτητα την απόδειξη απομόνωσης:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Επικυρώνει την τοπολογία, τις επώνυμες προσαρτήσεις, τις ρυθμίσεις εκτέλεσης χωρίς root/μόνο για ανάγνωση, τη ρητή τοπική δρομολόγηση,
την απουσία ευαίσθητων μεταβλητών περιβάλλοντος, την απουσία της υποδοχής Docker, την αποκλεισμένη πρόσβαση στα
`api.anthropic.com` και `claude.ai`, την επιλογή παρόχου αποκλειστικά μέσω Devin και τη ρητή αποτυχία όταν
το backend ACP δεν είναι διαθέσιμο.

## Αρχική ρύθμιση και κανονική χρήση

Δημιουργήστε το image με τις καρφιτσωμένες εκδόσεις:

```bash
./scripts/devin-bridge/build
```

Πραγματοποιήστε έλεγχο ταυτότητας μόνο στον απομονωμένο τόμο του Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Η εντολή σύνδεσης χρησιμοποιεί την επίσημη ροή μη αυτόματου token, η οποία προορίζεται για απομακρυσμένα περιβάλλοντα/περιβάλλοντα container. Η τιμή εισάγεται απευθείας στην προτροπή του CLI· δεν μεταβιβάζεται ως όρισμα διεργασίας, δεν εγγράφεται στο Git και δεν αντιγράφεται από τον host.

Εκκινήστε το απομονωμένο περιβάλλον εκτέλεσης του Claude Code:

```bash
./scripts/devin-bridge/launch
```

Το `launch` επανελέγχει την απομόνωση, τον έλεγχο ταυτότητας του Devin και τον εντοπισμό μοντέλων πριν εκκινήσει το Claude Code στο container. Δεν εκτελεί ποτέ το εκτελέσιμο αρχείο Claude του host. Τα ψευδώνυμα μοντέλων μπορούν να οριστούν στο `.env.devin-bridge`· κάθε διαμορφωμένη τιμή πρέπει να διατηρεί το πρόθεμα `devin-cli-agentic/`.

## Εντολές επικύρωσης

Η αναπαραγώγιμη διαδρομή εκτός σύνδεσης δεν απαιτεί λογαριασμό Devin και δεν έχει πρόσβαση στο Internet κατά την εκτέλεση:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Η προαιρετική διαδρομή ζωντανής εκτέλεσης με έλεγχο ταυτότητας είναι:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Ο εκτελεστής ζωντανών δοκιμών περιμένει μεταξύ των σεναρίων, ώστε να αποφεύγεται το ταυτόχρονο άνοιγμα πολλών συνεδριών ACP, και επικυρώνει δομημένα συμβάντα ροής του Claude αντί να εμπιστεύεται ισχυρισμούς σε μορφή κειμένου. Τα τρία σενάριά του αποδεικνύουν:

1. απευθείας αναγνώσεις του έργου και ανάλυση ελαττωμάτων,
2. μια πραγματική ενέργεια `Edit`, μια εντολή `Bash` `npm test` υπό τον έλεγχο του client και ένα τελικό αποτέλεσμα,
3. εντοπισμό των `/bridge-check` και `bridge-proof`, αναγνώσεις του έργου, μία ακόμη επιτυχή εκτέλεση `npm test` υπό τον έλεγχο του client και ολοκλήρωση χωρίς εκκρεμείς εργασίες.

Η τελική πύλη ελέγχει επίσης τον έλεγχο δικτύου του Devin και απαιτεί ο έλεγχος εξερχόμενης κίνησης του Claude να παραμένει κενός.

## Ενημέρωση εργαλείων με καρφιτσωμένες εκδόσεις

Το image καρφιτσώνει τις εκδόσεις των Node, Claude Code και Devin CLI στο `docker/devin-bridge/Dockerfile`. Για ενημέρωση:

1. αλλάξτε τις ρητά καθορισμένες εκδόσεις,
2. αντικαταστήστε τα checksum των αρχείων Devin και για τις δύο αρχιτεκτονικές με τιμές που αντιστοιχούν στο επίσημο artifact,
3. δημιουργήστε ξανά το image και εκτελέστε κάθε εντολή επικύρωσης εκτός σύνδεσης,
4. επιβεβαιώστε τις εκδόσεις μέσα στο image,
5. εκτελέστε ξανά τη ζωντανή σουίτα τριών σεναρίων με έλεγχο ταυτότητας.

Μην εγκαθιστάτε κανένα από τα δύο CLI καθολικά στον host και μην αντικαθιστάτε την επαλήθευση checksum με μη επαληθευμένη λήψη.

## Διάγνωση και εκκαθάριση

- Το `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  εμφανίζει την τοπική δρομολόγηση και τα εξυγιασμένα σφάλματα του executor.
- Το `.sandbox/evidence/mock-acp.jsonl` καταγράφει ντετερμινιστικές εικονικές ενέργειες ACP.
- Το `.sandbox/evidence/claude-stream.jsonl` καταγράφει την πραγματική εκτέλεση του Claude Code εκτός σύνδεσης.
- Το `.sandbox/evidence/live-*.jsonl` καταγράφει τις τρεις επικυρωμένες ζωντανές ροές.
- Τα `.sandbox/evidence/egress.jsonl` και `.sandbox/evidence/claude-egress.jsonl` είναι επικυρωμένα αντίγραφα των ελέγχων προστασίας, χωρίς token.

Διακόψτε τα container και τα δίκτυα που ανήκουν στο σύστημα, διατηρώντας παράλληλα τους τόμους σύνδεσης/διαμόρφωσης:

```bash
./scripts/devin-bridge/clean
```

Καταργήστε ολόκληρο το περιβάλλον που ανήκει στο bridge, συμπεριλαμβανομένων των ονομαστικών τόμων:

```bash
./scripts/devin-bridge/clean --all
```

## Περιορισμοί

- Η γέφυρα βασίζεται στον σταθερό ρόλο `summarizer` χωρίς εργαλεία, επειδή το Devin CLI `3000.2.17`
  δεν παρέχει έναν ουδέτερο ACP agent χωρίς εργαλεία. Ο προσαρμογέας αντισταθμίζει τις ενδιάμεσες
  αποκρίσεις που έχουν μορφή σύνοψης, αλλά μία περιορισμένη προσπάθεια διόρθωσης μπορεί και πάλι να αποτύχει ρητά.
- Οι ζωντανές κλήσεις ACP μπορούν να επιστρέψουν παροδικές αποκρίσεις `502`/`504`. Το harness κατανέμει χρονικά τα σενάρια·
  η επίμονη αποτυχία παραμένει fail-closed και δεν επιλέγει ποτέ άλλον πάροχο.
- Το περιβάλλον ACP ανακατασκευάζεται από κάθε αίτημα Anthropic· δεν υπάρχει συσχέτιση
  διεργασίας/συνεδρίας.
- Υποστηρίζεται μία κλήση εργαλείου ανά απόκριση μοντέλου· οι παράλληλες κλήσεις απορρίπτονται.
- Οι εικόνες δεν υποστηρίζονται ρητά. Η όραση, η έξοδος συλλογισμού, τα στοιχεία ελέγχου προσπάθειας και ένα παράθυρο
  περιβάλλοντος 1M δεν διαφημίζονται.
- Το SSE χρησιμοποιεί έγκυρα συμβάντα κύκλου ζωής Anthropic, αλλά εκπέμπεται αφού συλλεχθεί η περιορισμένη
  αλληλεπίδραση ACP· τα τμήματα ACP δεν προωθούνται σταδιακά.
