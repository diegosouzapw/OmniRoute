Το OmniRoute περιλαμβάνει μια επιμελημένη συλλογή δωρεάν διακομιστών μεσολάβησης στον πίνακα `free_proxies`,
η οποία συγχρονίζεται από εξωτερικούς παρόχους (1proxy, proxifly, iplocate, webshare). Ο
πίνακας ελέγχου τους εμφανίζει στην ενότητα **Ρυθμίσεις → Δωρεάν διακομιστές μεσολάβησης**. Αυτό το έγγραφο
καλύπτει το φιλτράρισμα, την ταξινόμηση, την καταμέτρηση και την αναφορά σφαλμάτων συγχρονισμού
στην πλευρά του διακομιστή, τα οποία παρέχονται από τη διαδρομή λίστας.

## Διαδρομή λίστας — `GET /api/settings/free-proxies`

Επιστρέφει ένα φιλτραρισμένο, ταξινομημένο και σελιδοποιημένο τμήμα, μαζί με το συνολικό πλήθος. Το φιλτράρισμα και
η καταμέτρηση πραγματοποιούνται σε SQL, ώστε το περιβάλλον χρήστη να μπορεί να εμφανίζει το πραγματικό σύνολο (π.χ. `Σύνολο: 0`)
χωρίς να φορτώνει κάθε γραμμή στη μνήμη.

### Παράμετροι ερωτήματος

| Παράμετρος        | Τύπος                              | Προεπιλογή | Σημασία                                                                                                                           |
| ----------------- | ---------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | συμβολοσειρά                       | `""`       | `LIKE` με διάκριση πεζών-κεφαλαίων στη στήλη κεντρικού υπολογιστή (και προέλευσης).                                               |
| `protocol`        | συμβολοσειρά                       | `""`       | Φίλτρο `type`: `http` / `https` / `socks4` / `socks5`. Κενό = όλα.                                                                |
| `country`         | συμβολοσειρά                       | `""`       | Φίλτρο `countryCode` (ISO-2). Κενό = όλα.                                                                                         |
| `minQuality`      | αριθμός                            | `0`        | Μόνο γραμμές με `qualityScore >= minQuality`. `0` = χωρίς ελάχιστο όριο.                                                          |
| `disabledSources` | συμβολοσειρά                       | `""`       | Αναγνωριστικά προελεύσεων προς εξαίρεση, διαχωρισμένα με κόμματα (π.χ. `proxifly,webshare`).                                      |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`  | `quality` = βαθμολογία φθίνουσα· `latency` = καθυστέρηση αύξουσα (οι null τιμές τελευταίες)· `recent` = `lastValidated` φθίνουσα. |
| `offset`          | αριθμός                            | `0`        | Αρχή σελιδοποίησης.                                                                                                               |
| `limit`           | αριθμός                            | `50`       | Μέγεθος σελίδας (με ανώτατο όριο στην πλευρά του διακομιστή).                                                                     |

### Απόκριση

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 από την ανάντη υπηρεσία"],
    "webshare": ["λήξη χρονικού ορίου δικτύου"]
  }
}
```

Το `total` αντικατοπτρίζει το φιλτραρισμένο σύνολο **πριν** από τη σελιδοποίηση, ώστε το περιβάλλον χρήστη να μπορεί να αποδίδει
τα `Σύνολο: N` και `hasMore` ανεξάρτητα. Το `syncErrors` χρησιμοποιεί ως κλειδιά τα αναγνωριστικά προέλευσης και
συμπληρώνεται μόνο για προελεύσεις των οποίων ο τελευταίος συγχρονισμός απέτυχε — ένα αποτέλεσμα `Σύνολο: 0`
δεν εμφανίζεται ποτέ χωρίς σχετική ένδειξη.

## Προσθήκη στη συλλογή — `POST /api/settings/free-proxies/[id]/add-to-pool`

Προάγει έναν δωρεάν διακομιστή μεσολάβησης στην υπό διαχείριση συλλογή `proxy_registry`. Επικυρώνει πρώτα την
ανάντη υπηρεσία· σε περίπτωση επιτυχίας, επιστρέφει το αναγνωριστικό του νέου διακομιστή μεσολάβησης στη συλλογή και τη μετρημένη καθυστέρηση.

## Συγχρονισμός — `POST /api/settings/free-proxies/sync`

Ανακτά ξανά όλες τις ενεργοποιημένες προελεύσεις (ή το υποσύνολο στο `{ "sources": [...] }`). Κάθε
προέλευση συγχρονίζεται ανεξάρτητα· μια προέλευση που αποτυγχάνει καταγράφεται στο `syncErrors`, ενώ οι
υπόλοιπες συνεχίζουν μέχρι την ολοκλήρωση, ώστε οι μερικοί συγχρονισμοί να μην διαγράφουν ποτέ προηγούμενα έγκυρα δεδομένα.

## Στατιστικά — `GET /api/settings/free-proxies/stats`

Επιστρέφει το συγκεντρωτικό αποτέλεσμα `total / inPool / avgQuality / bySource / lastSyncAt`
χωρίς το ωφέλιμο φορτίο των γραμμών — χρησιμοποιείται από τα γραφικά στοιχεία κεφαλίδας του πίνακα ελέγχου.
