Ορισμένες υπηρεσίες ενσωματώθηκαν στο OmniRoute και αργότερα αφαιρέθηκαν επειδή τα άτομα που τις
διαχειρίζονται το ζήτησαν. Αυτή η σελίδα αποτελεί το μόνιμο αρχείο αυτών των αφαιρέσεων. Ο μοναδικός
σκοπός της είναι να αποτρέψει την επαναφορά τους κατά λάθος: ένας συνεισφέρων που βρίσκει ένα παλιό fork,
ένα αποθηκευμένο στην κρυφή μνήμη πακέτο npm, ένα αρχειοθετημένο issue ή ένα αίτημα «επαναφοράς του
παρόχου X» χρειάζεται ένα σημείο που να δηλώνει **να μην επανεισαχθεί**.

Αυτή η σελίδα **δεν** είναι κατάλογος ανενεργών ή καταργημένων υπηρεσιών. Αυτές παρακολουθούνται στο
[`FREE_TIERS.md`](FREE_TIERS.md) («Αφαιρέθηκαν / χωρίς δωρεάν βαθμίδα») και μπορούν να επιστρέψουν εάν
επιστρέψει και η υπηρεσία. Οι παρακάτω καταχωρίσεις μπορούν να επιστρέψουν μόνο με γραπτή άδεια από τον
διαχειριστή που κατονομάζεται στο αίτημα, και η άδεια αυτή πρέπει να συνδέεται από την καταχώριση.

## Πολιτική

1. **Ένα αίτημα αφαίρεσης από τον διαχειριστή μιας υπηρεσίας γίνεται δεκτό, δεν αποτελεί αντικείμενο διαπραγμάτευσης.** Το OmniRoute
   δεν συνδέεται με καμία υπηρεσία ανάντη. Όταν ο διαχειριστής μιας υπηρεσίας ζητά να αφαιρεθεί η
   ενσωμάτωση, αυτή αφαιρείται, ανεξάρτητα από το αν χρησιμοποιούσε επίσημο API ή όχι.
2. **«Αφαιρέθηκε» σημαίνει από κάθε επιφάνεια που ελέγχει το OmniRoute.** Εκτελεστής, καταχώριση μητρώου, αναγνωριστικό
   και ψευδώνυμο παρόχου, λίστα μοντέλων, endpoints, μεταβλητές περιβάλλοντος, εικονίδιο, κάρτες πίνακα ελέγχου, η
   παραγόμενη αναφορά παρόχου, `FREE_TIERS.md`, η αναφορά περιβάλλοντος, μετρήσεις στο README,
   αντίγραφα του `llm.txt`, ειδικές δοκιμές και golden snapshots, σχόλια κώδικα, κουκκίδες του CHANGELOG
   (με καταγεγραμμένη συμφωνία, βλ. `config/release/changelog-reconciliations.json`),
   σημειώσεις GitHub Releases, το wiki, καθώς και τα GitHub issues, discussions και pull requests των οποίων
   το θέμα ήταν ο συγκεκριμένος πάροχος (τα issues και discussions διαγράφονται· τα pull requests μετονομάζονται, η
   περιγραφή τους αντικαθίσταται και το νήμα κλειδώνεται, επειδή το GitHub δεν μπορεί να διαγράψει pull requests).
3. **Μην επανεισαγάγετε ποτέ μια καταχώριση αυτής της σελίδας χωρίς γραπτή άδεια.** Αυτό περιλαμβάνει
   την εκ νέου προσθήκη του αναγνωριστικού ή του ψευδωνύμου σε οποιονδήποτε κατάλογο παρόχων, την προσθήκη των domain σε έναν εκτελεστή,
   την αποδοχή ενός PR συνεισφέροντος που την «επαναφέρει», την προσθήκη της στον κατάλογο δωρεάν μοντέλων ή
   την τεκμηρίωση ενός χειροκίνητου τρόπου πρόσβασης σε αυτή μέσω του OmniRoute. Κλείστε τέτοια PR και issues με έναν
   σύνδεσμο προς αυτή τη σελίδα.
4. **Διατηρήστε την καταχώριση λιτή.** Καταγράψτε μόνο όσα χρειάζεται ένας ελεγκτής για να αναγνωρίσει μια
   επανεισαγωγή: αναγνωριστικά, domain, ημερομηνίες και το pull request που πραγματοποίησε την αφαίρεση.
   Μην περιγράφετε τον τρόπο λειτουργίας της ενσωμάτωσης.
5. **Ο έλεγχος παλινδρόμησης είναι το `tests/unit/removed-providers-blocklist.test.ts`.** Αποτυγχάνει όταν
   οποιοδήποτε από τα παρακάτω αναγνωριστικά ή domain εμφανιστεί ξανά στους καταλόγους παρόχων, στον χάρτη εκτελεστών ή
   στον πηγαίο κώδικα του μητρώου παρόχων. Προσθέστε τα νέα αναγνωριστικά σε αυτήν τη δοκιμή στο ίδιο PR που
   προσθέτει μια γραμμή εδώ.

## Προσθήκη καταχώρισης

Όταν λαμβάνεται ένα νέο αίτημα αφαίρεσης:

1. Επιβεβαιώστε ότι το αίτημα προέρχεται από τον διαχειριστή της υπηρεσίας (τη διεύθυνση υποστήριξής του ή ένα
   domain που ελέγχει) και διατηρήστε το μήνυμα ιδιωτικό.
2. Αφαιρέστε την ενσωμάτωση ακολουθώντας τη λίστα ελέγχου στο στοιχείο 2 της πολιτικής. Χρησιμοποιήστε το
   [#12440](https://github.com/diegosouzapw/OmniRoute/pull/12440) ως σημείο αναφοράς για έναν
   πάροχο χωρίς κλειδί και το [#10210](https://github.com/diegosouzapw/OmniRoute/pull/10210) για έναν
   πάροχο με κλειδί API και αποθηκευμένες συνδέσεις (προσθέστε μια μετεγκατάσταση).
3. Προσθέστε μία γραμμή στον παραπάνω πίνακα και τα αναγνωριστικά στο
   `tests/unit/removed-providers-blocklist.test.ts`, στο ίδιο PR.
4. Απαντήστε στον διαχειριστή μόλις συγχωνευτεί το PR, αναφέροντας τι αφαιρέθηκε και τι δεν μπορεί να αλλάξει το OmniRoute
   (ήδη δημοσιευμένες εκδόσεις npm και Docker, ιστορικό git, fork τρίτων).
