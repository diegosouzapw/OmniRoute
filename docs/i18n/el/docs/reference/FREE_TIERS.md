> **Τελευταία έρευνα:** 2026-06-17 — διαδικτυακή έρευνα ανά πάροχο (επίσημη τεκμηρίωση + ειδήσεις των τελευταίων 7 ημερών, έλεγχος από 50 agents με αντιπαραθετική επαλήθευση), με επικαιροποίηση κάθε ορίου δωρεάν βαθμίδας + ToS. **Μερικός επανέλεγχος 2026-09-02** (`gemini`, `ollama-cloud`, `groq`, `nara`, `mistral` — δείτε τη χρονολογημένη σημείωση παρακάτω).
> **Πηγή αλήθειας (κατάλογος):** `open-sse/config/freeModelCatalog.ts` (προϋπολογισμοί ανά ΜΟΝΤΕΛΟ, με απαλοιφή διπλοεγγραφών ανά pool). Οι αριθμοί προϋπολογισμού tokens παρακάτω προέρχονται από ζωντανή διαδικτυακή έρευνα και αποτελούν **προσέγγιση** — δείτε [Μεθοδολογία και επιφυλάξεις](#methodology--caveats).

## TL;DR — πόση δωρεάν δυνατότητα inference συγκεντρώνει πραγματικά το OmniRoute;

| Μετρική                                            | Tokens / μήνα         | Σημασία                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Τεκμηριωμένη επαναλαμβανόμενη παροχή (σταθερή)** | **~1.62B**            | **Δεξαμενές** δωρεάν βαθμίδας (ανά κατάλογο μοντέλου), με κάθε κοινόχρηστη δεξαμενή να υπολογίζεται **μία φορά**. Η ζωντανή πηγή πίσω από το `/api/free-tier/summary` και τη σελίδα Free-Tier Budget του dashboard. **Χρησιμοποιήστε αυτόν τον αριθμό.**                                                                                                                  |
| **+ πρώτος μήνας με πιστώσεις εγγραφής**           | **~2.22B**            | Σταθερή παροχή + εφάπαξ πιστώσεις εγγραφής (Z.AI 20M, DeepSeek 5M, …), χωρίς διπλοεγγραφές ανά λογαριασμό. **Μόνο για τον πρώτο μήνα** — δεν επαναλαμβάνεται.                                                                                                                                                                                                             |
| **+ μόνιμα δωρεάν, χωρίς δημοσιευμένο όριο**       | _μη ποσοτικοποιήσιμο_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — πραγματική επαναλαμβανόμενη πρόσβαση, με περιορισμούς ρυθμού/ταυτόχρονης χρήσης, **χωρίς όριο tokens που να μπορεί να προσμετρηθεί**. Παρατίθενται, αλλά δεν αθροίζονται ποτέ (ο υπολογισμός τους ως `RPM×24/7` είναι η διόγκωση που απορρίπτουμε). |
| **+ ενίσχυση με ξεκλείδωμα μέσω κατάθεσης**        | **+~24M**             | Μία εφάπαξ ανανέωση υπολοίπου **$10** στο OpenRouter αυξάνει τη δωρεάν δεξαμενή του από 50 → 1000 αιτήματα/ημέρα. Αναφέρεται ξεχωριστά, ώστε να μη διογκώνει ποτέ τον σταθερό αριθμό.                                                                                                                                                                                     |
| **+ πίσω από περιφερειακό έλεγχο ταυτότητας**      | **+~6M**              | `modelscope` (σύνδεση Alibaba Cloud + επαλήθευση πραγματικού ονόματος στην ηπειρωτική Κίνα). Πραγματικό επαναλαμβανόμενο όριο χρήσης, διαθέσιμο ως `gatedRecurringTokens` / `gatedProviders` και στο dashboard. Δεν προστίθεται ποτέ στον κύριο αριθμό: +~6M πίσω από περιφερειακή επαλήθευση ταυτότητας.                                                                 |
| Θεωρητικό ανώτατο όριο (όλα τα όρια ρυθμού, 24/7)  | ~10B                  | Άθροισμα όλων των ορίων ρυθμού των παρόχων, με αναγωγή σε αδιάκοπη χρήση. **Δεν αποτελεί εγγύηση** — μην το χρησιμοποιείτε ως κύριο τίτλο.                                                                                                                                                                                                                                |

**Ειλικρινής κύριος τίτλος:** _Το OmniRoute συγκεντρώνει **~1.62B τεκμηριωμένα δωρεάν tokens ανά μήνα** (έως ~2.22B τον πρώτο σας μήνα με πιστώσεις εγγραφής) σε 35 δεξαμενές δωρεάν βαθμίδας — συν μια μακρά σειρά μόνιμα δωρεάν παρόχων χωρίς όριο — ενώ η συμπίεση RTK + Caveman (εξοικονόμηση tokens 15–95%) επεκτείνει ακόμη περισσότερο αυτήν τη δυνατότητα._

> **Γιατί αυτό μειώθηκε από το προηγούμενο ~1.94B.** Η ανανέωση της 2026-06-17 είναι διόρθωση ακρίβειας, όχι απώλεια: το `gemini` πλέον αποφεύγει τις διπλοεγγραφές σε επίπεδο δεξαμενής (προηγουμένως ο αριθμός ήταν διογκωμένος επειδή κάθε παραλλαγή Flash υπολογιζόταν ξεχωριστά, 462M → 60M), το `cloudflare-ai` διορθώθηκε στο πραγματικό του όριο των 10k-Neurons/ημέρα (122M → 30M), το `doubao` επαναταξινομήθηκε ως εφάπαξ πίστωση εγγραφής (όχι επαναλαμβανόμενη) και αφαιρέθηκαν βαθμίδες που έχουν τερματιστεί (`chutes`/`phind`/`kluster` διακόπηκαν). Αυτό αντισταθμίστηκε εν μέρει από το `llm7` (σωστό όριο 5M/ημέρα → 150M) και νέους δωρεάν παρόχους (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Περαιτέρω διόρθωση σε ~1.37B στην v3.8.42:** το `longcat` επαναταξινομήθηκε από επαναλαμβανόμενη παροχή 150M/μήνα σε εφάπαξ πίστωση εγγραφής 10M μετά τη λήξη της δωρεάν δοκιμαστικής περιόδου του. Ισχύει ο ίδιος κανόνας ακρίβειας — κανένας πάροχος δεν αφαιρέθηκε κατά λάθος.
>
> **Ενημερώθηκε στις 2026-08-26 μετά την απόσυρση του Felo Web:** το Felo Web εξαιρείται όσο η προέλευση/αδειοδότησή του που απορρέει από την GPL παραμένει σε HOLD· η πηγή ανέφερε 38 κλειδιά δεξαμενών εκείνη τη στιγμή. Το πλήθος των δεξαμενών ενημερώνεται ζωντανά και ελέγχεται από το CI (το `check:docs-counts` αποτυγχάνει το build αν οι παραπάνω αριθμοί αποκλίνουν από το `computeFreeModelTotals()`).
>
> **Επανελέγχθηκε στις 2026-09-02 με βάση τις σελίδες των ίδιων των παρόχων** (πηγές: τα σχόλια `// evidence:` δίπλα σε κάθε επανελεγμένη καταχώριση στο `open-sse/config/freeModelCatalog.data.ts`): τα `gemini` και `ollama-cloud` δεν δημοσιεύουν πλέον αριθμό tokens (η Google αφαίρεσε τον δωρεάν πίνακα ανά μοντέλο στις 2025-12-23· το δωρεάν πρόγραμμα της Ollama είναι «πιστώσεις αρχικής χρήσης») και πλέον παρατίθενται ως **χωρίς όριο**, χωρίς να αθροίζονται ποτέ (−80M)· το `groq` διαθέτει πέντε όρια **ανά μοντέλο** των 200K-TPD (6M το καθένα, +15M), ενώ αφαιρέθηκαν τρία αποσυρμένα IDs· το `nara` διαθέτει μία δεξαμενή 7M/ημέρα (+60M, 210M). Το 1B του `mistral` είναι ορατό μόνο στην κονσόλα λογαριασμού — δείτε την ενότητα _Κατηγορίες αποδεικτικών στοιχείων_ στη Μεθοδολογία.
>
> **Διορθώθηκε στις 2026-09-03 (#11773):** το `cerebras` επαναταξινομήθηκε από επαναλαμβανόμενη παροχή 30M/μήνα (παλιά δοκιμαστική περίοδος χωρίς κάρτα με 1M tokens/ημέρα) σε εφάπαξ πίστωση εγγραφής $5 που απαιτεί μέθοδο πληρωμής. Ισχύει ο ίδιος κανόνας ακρίβειας όπως και για το LongCat.
>
> **Συν το xKiro (2026-09-03):** η νέα δεξαμενή `xkiro-free` (150M/μήνα) προσθέτει ένα 35ο επαναλαμβανόμενο κλειδί δεξαμενής. Το Felo Web παραμένει εξαιρούμενο όσο η προέλευση/αδειοδότησή του που απορρέει από την GPL παραμένει σε HOLD. Η πηγή αναφέρει πλέον **35 επαναλαμβανόμενα κλειδιά δεξαμενών** και **~1.62B σταθερά** — τον ζωντανό αριθμό που ελέγχεται από το CI (το `check:docs-counts` αποτυγχάνει το build αν αυτός αποκλίνει από το `computeFreeModelTotals()`).

Μεγαλύτεροι **τεκμηριωμένοι** συνεισφέροντες: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (πέντε όρια ανά μοντέλο), `cloudflare-ai` 30M, `api-airforce` 24M. (Το `longcat` εξαιρείται — η παροχή 10M για το LongCat-2.0 είναι εφάπαξ πίστωση εγγραφής που απαιτεί KYC, όχι επαναλαμβανόμενος μηνιαίος προϋπολογισμός.)

> ⚠️ Το θεωρητικό ανώτατο όριο (~10B) είναι διογκωμένο από παρόχους που επιβάλλουν μόνο περιορισμούς ρυθμού και **δεν έχουν δημοσιευμένο όριο token** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), των οποίων οι τιμές θα ήταν `RPM/TPM × 24/7 × 30d` — ένα θεωρητικό μέγιστο που κανένας μεμονωμένος λογαριασμός δεν μπορεί να διατηρήσει. **Εξαιρούνται** από τον τεκμηριωμένο αριθμό (και εμφανίζονται αντ’ αυτού στη γραμμή «μόνιμα δωρεάν, χωρίς όριο»). Πρόκειται για την ίδια διόγκωση που καθιστά αναξιόπιστους τους ισχυρισμούς των ανταγωνιστών περί πολλών δισεκατομμυρίων.

## Ανανέωση 2026-06-17 — τι άλλαξε από τις 2026-06-05

Ένας γύρος διαδικτυακής έρευνας από 50 agents (επίσημη τεκμηρίωση + ειδήσεις των τελευταίων 7 ημερών, με ανταγωνιστική επαλήθευση) ανανέωσε ολόκληρο τον κατάλογο. Κύρια σημεία:

- **Καταργήθηκαν / χωρίς δωρεάν βαθμίδα (2026):** `chutes` (η δωρεάν βαθμίδα έληξε τον 2026-03), `phind` (η εταιρεία έκλεισε τον 2026-01), `kluster` (τερματισμός στις 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (η δωρεάν πρόσβαση στο MiMo ανακλήθηκε στις 2026-05-24, η προωθητική ενέργεια Nemotron έληξε τον 2026-06 — επαληθεύτηκε εκ νέου στις 2026-06-18), `aimlapi` (η δωρεάν βαθμίδα τέθηκε σε παύση — επαληθεύτηκε εκ νέου στις 2026-06-18), `yi` (το Yi-Light αποσύρθηκε, χρέωση ανάλογα με τη χρήση — επαληθεύτηκε εκ νέου στις 2026-06-18), `featherless-ai` (δεν διαθέτει επί του παρόντος δωρεάν βαθμίδα), `chipotle` (το "Pepper AI" της Chipotle — το widget συνομιλίας Amelia στο `amelia.chipotle.com`, το οποίο είχε προσεγγιστεί μέσω αντίστροφης μηχανικής από τον πάροχο, πλέον επιστρέφει 404 σε κάθε διαδρομή, συμπεριλαμβανομένης της ρίζας· το backend παροπλίστηκε/μετακινήθηκε, επιβεβαιώθηκε στις 2026-09-15 — αφαιρέθηκε πλήρως από τον κατάλογο, #13131/#4037). Τα `iflytek` / `sparkdesk` παραμένουν καταχωρισμένα, αλλά συνοδεύονται από σημείωση προσοχής σχετικά με τους Όρους Χρήσης (το Spark Lite είναι δωρεάν· οι Όροι Χρήσης περιορίζουν τη χρήση proxy/relay).
- **Gemini** — τα `2.0 Flash` / `2.0 Flash-Lite` τερματίστηκαν στις 2026-06-01 και το `2.5 Pro` αποχώρησε από τη δωρεάν βαθμίδα (2026-04)· η δωρεάν βαθμίδα περιλαμβάνει πλέον **μόνο την οικογένεια Flash** (2.5/3/3.1/3.5 Flash + Gemma). Ο κατάλογος πλέον **ομαδοποιεί** την οικογένεια Flash (προηγουμένως το σύνολο ήταν διογκωμένο επειδή κάθε παραλλαγή υπολογιζόταν ξεχωριστά: 462M → 60M).
- **Διορθωμένοι αριθμοί:** `cloudflare-ai` 122M → **30M** (πραγματικό όριο 10k Neurons/ημέρα), το `doubao` επαναταξινομήθηκε ως εφάπαξ πίστωση εγγραφής (όχι επαναλαμβανόμενη), `llm7` 4M → **150M** (τεκμηριωμένα 5M tokens/ημέρα), τα endpoints "-Free" του `together` καταργήθηκαν → αφαιρέθηκε επίσης η πίστωση εγγραφής $25 (απαιτείται ελάχιστη αγορά $5, χωρίς δωρεάν δοκιμή), η Preview του `longcat` έληξε + τα μοντέλα Flash αποσύρθηκαν → μόνο **LongCat-2.0**, επαναταξινομήθηκε ως εφάπαξ πίστωση εγγραφής **10M** tokens (απαιτεί KYC, δεν είναι επαναλαμβανόμενη).
- **Νέοι δωρεάν πάροχοι που ανακαλύφθηκαν:** ⭐ **Kilo Code** (`kilo-gateway` — εναλλασσόμενο σύνολο "Auto Free": οικογένεια NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 εναλλασσόμενα δωρεάν μοντέλα προγραμματισμού), ⭐ **Z.AI / Zhipu** (`glm-cn` — τα GLM-4-Flash / 4.5-Flash / 4.7-Flash είναι μόνιμα δωρεάν + μπόνους εγγραφής 20M) και `arcee-ai` Trinity Large Preview.
- **Νέες ειλικρινείς βαθμίδες** (βλ. Μεθοδολογία): μια κατηγορία _μόνιμα δωρεάν αλλά χωρίς ανώτατο όριο_ (πραγματική επαναλαμβανόμενη πρόσβαση, χωρίς όριο tokens προς καταμέτρηση) και μια _ενίσχυση με ξεκλείδωμα μέσω κατάθεσης_ (OpenRouter $10 → +24M/μήνα), οι οποίες εμφανίζονται **ξεχωριστά**, ώστε να μη διογκώνουν ποτέ τον κύριο αριθμό.

> Ο λεπτομερής πίνακας ανά πάροχο παρακάτω αποτελεί το **στιγμιότυπο της 2026-06-05**· οι παραπάνω μεταβολές υπερισχύουν. Η ενεργή, κανονική πηγή είναι ο κατάλογος ανά μοντέλο `open-sse/config/freeModelCatalog.ts`.

## Δύο καθεστώτα — καταμέτρηση έναντι λήψης αποφάσεων

Το OmniRoute απαντά στο ερώτημα «είναι δωρεάν;» μέσω δύο καθεστώτων που σκοπίμως διαβάζουν
διαφορετικές πηγές:

| Καθεστώς                   | Πηγή αλήθειας                                                                                                                                                                                       | Σημεία εμφάνισης                                                                                                                                              |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Καταμέτρηση / εμφάνιση** | Επιλυμένος κατάλογος — η διανεμόμενη γραμμή βάσης με επικάλυψη από τη ροή Radar (`getRadarCatalog`)                                                                                                 | Σύνολα δωρεάν βαθμίδας, κάρτα προϋπολογισμού, πίνακες ελέγχου                                                                                                 |
| **Λήψη αποφάσεων**         | Μόνο ο διανεμόμενος κατάλογος (`FREE_MODEL_BUDGETS` στο `open-sse/config/freeModelCatalog.data.ts`) μαζί με τα τοπικά ευρετικά κριτήρια (κατάληξη `:free`, μηδενική τιμολόγηση, `grantsFreeAccess`) | Κάθε καταναλωτής του `src/shared/utils/freeModels.ts`: εισαγωγή μοντέλων, δρομολόγηση `auto/*`, `GET /v1/models` και προεπισκοπήσεις στο πρόγραμμα περιήγησης |

Η καταμέτρηση μπορεί να βελτιώνεται κάθε φορά που είναι διαθέσιμη μια ροή. Η λήψη αποφάσεων παραμένει στο
τεχνούργημα της έκδοσης, ώστε η απάντηση να είναι πανομοιότυπη στο πρόγραμμα περιήγησης και στον διακομιστή,
να μπορεί να αναπαραχθεί εκτός σύνδεσης και να ελέγχεται χωρίς βάση δεδομένων. Αν επιτρεπόταν στην προεπισκόπηση του προγράμματος περιήγησης
να διαβάζει μία πηγή ενώ η εισαγωγή του διακομιστή διαβάζει άλλη, θα προέκυπτε μια
προεπισκόπηση που θα διαφωνούσε με ό,τι συμβαίνει κατά το κλικ — ο διαχωρισμός διατηρείται
σκόπιμα.

## Μεθοδολογία & επιφυλάξεις

- Οι αριθμοί είναι **εκτιμήσεις ανώτατου ορίου** βάσει των τεκμηριωμένων ορίων δωρεάν βαθμίδας κάθε παρόχου στις **2026-06-17**, οι οποίες συγκεντρώθηκαν μέσω διαδικτυακής έρευνας. Οι δωρεάν βαθμίδες αλλάζουν συνεχώς — επαληθεύστε ξανά τα στοιχεία προτού βασιστείτε σε αυτά.
- **Τι ακριβώς εγγυάται μια καταχώριση.** Καμία καταχώριση δεν διαθέτει αξιολόγηση αξιοπιστίας ανά γραμμή και το API δεν παρέχει καμία — αντιμετωπίστε κάθε παραπάνω τιμή ως εκτίμηση της ίδιας, μη δηλωμένης ποιότητας. Δύο στοιχεία διαφέρουν, επειδή επιμελούνται χειροκίνητα αντί να συνάγονται: 44 καταχωρίσεις διαθέτουν ανεξάρτητα τεκμηριωμένο αυστηρό όριο διακοπής (39 από αυτές είναι οι γραμμές xKiro, οι οποίες μοιράζονται όλες το ίδιο ημερήσιο όριο) και 13 καταχωρίσεις διαθέτουν γνωστοποίηση σχετικά με τη χρήση προτροπών για εκπαίδευση. Το `hardStopGuaranteed` ορίζεται μόνο όταν οι όροι του ίδιου του παρόχου αναφέρουν ότι η υπέρβαση του δωρεάν ορίου απορρίπτει το αίτημα αντί να αρχίζει σιωπηρά να σας χρεώνει, με την πηγή σε σχόλιο δίπλα στην καταχώριση· δεν λαμβάνει ποτέ ως προεπιλεγμένη τιμή το `true` και παραμένει μη ορισμένο σε μια καταχώριση που δεν έχει επαληθευτεί από κανέναν. Επομένως, η απουσία της σημαίας αυστηρής διακοπής σημαίνει «δεν έχει τεκμηριωθεί» και όχι «είναι γνωστό ότι θα σας χρεώσει». Η **λειτουργία STRICT** (ο προαιρετικός μηχανισμός προστασίας δρομολόγησης `freeAccessPolicy=strict`) εμπιστεύεται μόνο τις καταχωρίσεις που φέρουν τη σημαία· κάθε άλλη δωρεάν βαθμίδα αποκλείεται ως `no-hard-stop` (βλ. `open-sse/services/autoCombo/strictZeroCostFilter.ts`).
- `estMonthlyFreeTokens` = μόνο τα επαναλαμβανόμενα μηνιαία token. **Οι εφάπαξ πιστώσεις εγγραφής δεν επαναλαμβάνονται** και υπολογίζονται ως 0. Οι βαθμίδες που έχουν καταργηθεί υπολογίζονται επίσης ως 0.
- Ημερήσιο όριο token → `monthly = daily × 30`. Αν τεκμηριώνεται μόνο το RPD → `RPD × ~800 output tokens × 30`. Αν τεκμηριώνονται μόνο τα RPM/TPM (χωρίς ημερήσιο όριο) → **χωρίς ανώτατο όριο** (βλ. παρακάτω).
- **Μόνιμα δωρεάν, αλλά χωρίς δημοσιευμένο όριο token** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): πρόκειται για πραγματική, επαναλαμβανόμενη δωρεάν πρόσβαση, με περιορισμούς ρυθμού/ταυτόχρονης χρήσης. Τις ταξινομούμε ως `recurring-uncapped` και **δεν τις αθροίζουμε ποτέ** — ο πολλαπλασιασμός `RPM × 24/7 × 30d` θα παρήγαγε ένα πλασματικό ανώτατο όριο (τη διόγκωση που απορρίπτουμε). Παρατίθενται ώστε να γνωρίζετε ότι υπάρχουν.
- **Ενίσχυση μέσω ξεκλειδώματος με κατάθεση:** μια μικρή, εφάπαξ ανανέωση υπολοίπου που αυξάνει μόνιμα ένα δωρεάν όριο (OpenRouter: $10 → 1000 αιτήματα/ημέρα ≈ +24M/μήνα). Αναφέρεται ως ξεχωριστή τιμή και δεν περιλαμβάνεται στο σταθερό κύριο σύνολο.
- **Όρια που εξαρτώνται από κριτήρια επιλεξιμότητας** (`eligibilityGate: "regional-identity"`): ένα πραγματικό επαναλαμβανόμενο όριο που ενεργοποιείται μόνο μετά από έλεγχο ταυτότητας συνδεδεμένο με συγκεκριμένη περιοχή (επί του παρόντος, επαλήθευση πραγματικού ονόματος στην ηπειρωτική Κίνα). Υπολογίζεται με τον ίδιο κανόνα αποφυγής διπλομέτρησης κοινών δεξαμενών σε ξεχωριστή τιμή (`gatedRecurringTokens`) και ποτέ στο σταθερό κύριο σύνολο. Το καθεστώς (`freeType`) παραμένει αμετάβλητο, επομένως η δρομολόγηση παραμένει αμετάβλητη.
- **Κατηγορίες τεκμηρίωσης.** Ο κανόνας: ένας αριθμός στον κατάλογο παραθέτει την πηγή του σε σχόλιο `// evidence:` δίπλα στην καταχώριση — `public-page` (σελίδα παρόχου που μπορεί να διαβάσει οποιοσδήποτε), `api-public` (τελικό σημείο του παρόχου χωρίς απαίτηση ελέγχου ταυτότητας, π.χ. το δημόσιο τελικό σημείο προγραμμάτων του NaraRouter στη διεύθυνση router.bynara.id) ή `console-verified <date> por <who>` (η τιμή είναι ορατή μόνο μέσα στην κονσόλα ενός λογαριασμού· το σχόλιο καταγράφει ποιος την είδε και πότε, καθώς και τη δημόσια σελίδα που αναφέρει ότι το όριο υπάρχει). Η τρέχουσα κατάσταση: τα πέντε τμήματα που επανελέγχθηκαν στις 2026-09-02 το περιλαμβάνουν (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`)· οι καταχωρίσεις που προηγούνται του επανελέγχου της 2026-09-02 κληρονομούν την παλαιότερη έρευνα μέχρι να τροποποιηθούν· οποιοσδήποτε **νέος ή τροποποιημένος** αριθμός χωρίς σχόλιο τεκμηρίωσης αποτελεί σφάλμα. Επί του παρόντος, μόνο το `mistral` είναι επαληθευμένο μέσω κονσόλας.

## Γιατί ο αριθμός μας είναι μικρότερος από εκείνον άλλων aggregators

Τα περισσότερα στοιχεία για «δωρεάν tokens ανά μήνα» σε αυτόν τον χώρο είναι αθροίσματα επισημάνσεων ανά μοντέλο. Το δικό μας δεν είναι, εσκεμμένα:

- **Κάθε κοινόχρηστο pool υπολογίζεται μία φορά.** Το δωρεάν πλάνο της Mistral παρέχει ένα όριο 1B/μήνα ανά οργανισμό· η καταχώρισή του κάτω από πέντε μοντέλα δεν το μετατρέπει σε 5B. Αν αθροιζόταν ανά μοντέλο, ο δικός μας κατάλογος θα εμφάνιζε **~7.4B** (επανυπολογίστηκε στις 2026-09-03· αυτό το στοιχείο δεν ελέγχεται από το CI — υπολογίστε το ξανά κάθε φορά που αλλάζει ο κατάλογος) — ο τίτλος αναφέρει **~1.47B**, επειδή αυτό είναι το ποσό που μπορεί πράγματι να καταναλώσει ένας λογαριασμός από κάθε πάροχο.
- **Τα ημερήσια όρια μετατρέπονται, οι ρυθμοί όχι.** Ένα τεκμηριωμένο όριο tokens/ημέρα μετατρέπεται σε `× 30`· ένα τεκμηριωμένο όριο αιτημάτων/ημέρα μετατρέπεται σε `RPD × ~800 tokens × 30`· ένας πάροχος που δημοσιεύει μόνο αιτήματα ανά λεπτό **δεν** έχει μηνιαίο αριθμό και καταχωρίζεται ως _χωρίς όριο_, χωρίς ποτέ να προστίθεται στο άθροισμα. Ο πολλαπλασιασμός ενός ορίου ρυθμού επί 24/7 είναι η διόγκωση που αρνούμαστε να κάνουμε.
- **Τα όρια χρήσης που απαιτούν περιφερειακό έλεγχο ταυτότητας εμφανίζονται ξεχωριστά** (`+~6M behind regional identity verification`), επειδή οι περισσότεροι αναγνώστες δεν μπορούν να τα χρησιμοποιήσουν.
- **Οι πιστώσεις εγγραφής ισχύουν μόνο για τον πρώτο μήνα** και αναφέρονται ως δεύτερο στοιχείο, χωρίς ποτέ να συγχωνεύονται με τον σταθερό αριθμό.
- **Το στοιχείο επιβάλλεται από το CI.** Το `npm run check:docs-counts` υπολογίζει εκ νέου τα σύνολα από τον κατάλογο και αποτυγχάνει το build όταν αυτό το αρχείο, το README ή η κάρτα προϋπολογισμού αποκλίνουν από αυτά.

## Πίνακας επισήμανσης Όρων Χρήσης

> **Η επισήμανση ToS είναι συμβουλευτική και δεν αποτελεί περιορισμό δρομολόγησης.** Οι πάροχοι με επισήμανση `tos` εξακολουθούν να περιλαμβάνονται από προεπιλογή στη δρομολόγηση και στους συνδυασμούς/εφεδρικές επιλογές· η επισήμανση εμφανίζεται μόνο στα `/dashboard/free-tiers` και `/api/free-tier/summary`. Η παράμετρος ερωτήματος `excludeTosAvoid` επηρεάζει μόνο την προβολή σύνοψης και όχι την καθολική δρομολόγηση. Η αξιολόγηση βρίσκεται στο `open-sse/config/freeTierCatalog.ts` (είναι ενημερωτική και δεν διαβάζεται από τις μηχανές δρομολόγησης).

> Μια σύντομη επισκόπηση των όρων κάθε παρόχου για έναν αυτοφιλοξενούμενο, προσωπικό διακομιστή μεσολάβησης ενός χρήστη. `caution` = όρος περί προσωπικής χρήσης ή διακομιστή μεσολάβησης που αξίζει να ελεγχθεί· `ambiguous` = ασαφές· `ok` = επιτρέπεται ρητά. Ενημερωτικό υλικό, όχι νομική συμβουλή — εσείς αποφασίζετε.

## Γλωσσάρι

| Όρος                       | Σημασία                                                                                  |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**        | Αιτήματα ανά λεπτό / ημέρα / ώρα                                                         |
| **TPM / TPD**              | Token ανά λεπτό / ημέρα                                                                  |
| **Τεκμηριωμένη παροχή**    | Ο πάροχος δημοσιεύει ένα ρητό ημερήσιο/μηνιαίο όριο token (τεκμηριώσιμος προϋπολογισμός) |
| **Θεωρητικό ανώτατο όριο** | `όριο-ρυθμού × 24/7 × 30ημ.` — ένα μέγιστο όριο, όχι ένας εγκεκριμένος προϋπολογισμός    |
| **Νευρώνας**               | Υπολογιστική μονάδα Cloudflare (~1 token εξόδου)                                         |
