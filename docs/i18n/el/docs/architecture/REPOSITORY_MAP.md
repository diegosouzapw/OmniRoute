## `src/` — Εφαρμογή Next.js

```
src/
├── app/                 # App Router (σελίδες + διαδρομές API + σελίδες κατάστασης + σελίδα προορισμού)
├── lib/                 # Βασικές βιβλιοθήκες / μονάδες τομέα (80 υποκατάλογοι + ~70 αρχεία ανώτατου επιπέδου)
├── domain/              # Αμιγής λογική τομέα (μηχανή πολιτικών, εφεδρική λειτουργία, κόστος, αποκλεισμός, comboResolver, αξιολόγηση)
├── server/              # Μονάδες αποκλειστικά για διακομιστή (διοχέτευση authz, cors, ενδιάμεσο λογισμικό ελέγχου ταυτότητας) — δεν μπορούν να εισαχθούν από τον πελάτη
├── shared/              # Κοινόχρηστα μεταξύ διακομιστή και πελάτη όπου είναι ασφαλές (σταθερές, τύποι, επικύρωση, συμβάσεις, βοηθητικά εργαλεία)
├── i18n/                # Ρύθμιση παραμέτρων next-intl + JSON μηνυμάτων ανά τοπικές ρυθμίσεις (42 τοπικές ρυθμίσεις)
├── middleware/          # Ενδιάμεσο λογισμικό Next.js (εμπλουτισμός αιτήματος, ανίχνευση τοπικών ρυθμίσεων)
├── mitm/                # Πυρήνας διακομιστή μεσολάβησης MITM: δημιουργία/εγκατάσταση πιστοποιητικών, χειριστές, προορισμοί, επιθεωρητής, μάσκες, άμεση διέλευση
│   ├── handlers/        # 9 κλάσεις χειριστών πρακτόρων IDE που επεκτείνουν το MitmHandlerBase (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # Επίπεδο καταγραφής κίνησης: ενδιάμεση μνήμη (δακτύλιος στη μνήμη), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # Συνδετικός κώδικας προσαρμογέα μοντέλων (παλαιού τύπου shim)
├── scripts/             # Ενσωματωμένα σενάρια συντήρησης (π.χ., backfillAggregation)
├── sse/                 # Παλαιού τύπου χειριστές/υπηρεσίες SSE (chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # Παλαιού τύπου χώρος αποθήκευσης στη μνήμη (καταργείται σταδιακά υπέρ του src/lib/db)
├── types/               # Κοινόχρηστα αρχεία τύπων TS
├── instrumentation.ts   # Άγκιστρο τηλεμετρίας Next.js (πρόγραμμα περιήγησης + edge)
├── instrumentation-node.ts  # Instrumentation αποκλειστικά για Node
└── proxy.ts             # Shim σημείου εισόδου HTTP-proxy
```

## `open-sse/` — Χώρος εργασίας μηχανής ροής

Ξεχωριστός χώρος εργασίας npm (`@omniroute/open-sse`). Διαχειρίζεται την επεξεργασία αιτημάτων + την εκτέλεση παρόχων.

```
open-sse/
├── handlers/            # 16 αρχεία (12 χειριστές + 4 βοηθητικά): chatCore, responsesHandler, embeddings, audio, image, video, music, rerank, moderations, search, κ.λπ.
├── executors/           # 67 εκτελεστές ειδικοί ανά πάροχο (επεκτείνουν το BaseExecutor)
├── translator/          # Μετατροπείς μορφής (9 αιτημάτων, 9 αποκρίσεων, 9 βοηθητικά)
├── transformer/         # Responses API ↔ Chat Completions (TransformStream)
├── services/            # ~80+ λειτουργικές μονάδες υπηρεσιών (combo, accountFallback, autoCombo, reasoningCache, claude code/chatgpt stealth, modelDeprecation, taskAwareRouter, workflowFSM, κ.λπ.)
├── mcp-server/          # Διακομιστής MCP (110 εργαλεία, 3 μεταφορές, 33 πεδία πρόσβασης)
├── config/              # Μητρώα παρόχων/μοντέλων, ρυθμίσεις κεφαλίδων, ψευδώνυμα μοντέλων
├── utils/               # Πελάτης TLS, ανάκτηση/διεκπεραιωτής μέσω διαμεσολαβητή, βοηθητικά δικτύου
├── index.ts             # Σημείο εισόδου χώρου εργασίας
├── package.json         # Μανιφέστο χώρου εργασίας
├── tsconfig.json        # Ρυθμίσεις TS χώρου εργασίας
└── types.d.ts           # Δηλώσεις τύπων χώρου εργασίας
```
