## Πλοήγηση υψηλού επιπέδου

Η πλαϊνή γραμμή του πίνακα ελέγχου (μετά την Ομάδα B) έχει τις ακόλουθες ενότητες ανώτατου επιπέδου, με αυτή τη σειρά:

```
Αρχική
Πάροχοι
Συνδυασμοί
Κλειδιά API
Ρυθμίσεις
Αναλυτικά στοιχεία
Κόστη          ← ΝΕΟ (Ομάδα B, σχέδιο 16)
Παρακολούθηση  ← ΑΝΑΔΙΟΡΓΑΝΩΘΗΚΕ (Ομάδα B, σχέδιο 16)
...
```

## Ενότητα Κόστη (νέα, επίπεδο 1)

Πρόθεμα διαδρομής: `/dashboard/costs/`

| Στοιχείο          | URL                                  | Περιγραφή                                                              |
| ----------------- | ------------------------------------ | ---------------------------------------------------------------------- |
| Επισκόπηση        | `/dashboard/costs`                   | Συγκεντρωτικός πίνακας κόστους (μεταφέρθηκε από τα Αναλυτικά στοιχεία) |
| Τιμολόγηση        | `/dashboard/costs/pricing`           | Πίνακας τιμολόγησης ανά μοντέλο                                        |
| Προϋπολογισμός    | `/dashboard/costs/budget`            | Όρια προϋπολογισμού + ειδοποιήσεις                                     |
| Κοινή χρήση ορίου | `/dashboard/costs/quota-share`       | Ομάδες Κοινής χρήσης ορίου + χρήση                                     |
| Ρύθμιση πλάνου    | `/dashboard/costs/quota-share/plans` | Παρακάμψεις πλάνου ανά πάροχο                                          |

**Αιτιολόγηση**: Η Τιμολόγηση, ο Προϋπολογισμός και η Κοινή χρήση ορίου βρίσκονταν προηγουμένως στην ενότητα
`Παρακολούθηση > Παράμετροι κόστους`. Η μεταφορά τους σε μια αποκλειστική ενότητα ανώτατου επιπέδου
τα καθιστά ευκολότερα ανιχνεύσιμα, χωρίς να απαιτείται πλοήγηση στα εργαλεία παρατηρησιμότητας.

## Ενότητα Παρακολούθηση (αναδιοργανωμένη)

Η ενότητα Παρακολούθηση έχει πλέον τη **Δραστηριότητα στην κορυφή**, ακολουθούμενη από **3 υποομάδες**:

```
Παρακολούθηση
├── Δραστηριότητα         ← Ροή χρονολογίου (στοιχείο ανώτατου επιπέδου)
├── Ομάδα αρχείων καταγραφής
│   ├── Αρχεία καταγραφής (όλα)
│   ├── Αρχεία καταγραφής διακομιστή μεσολάβησης
│   └── Αρχεία καταγραφής κονσόλας
├── Ομάδα ελέγχου
│   ├── Αρχείο καταγραφής ελέγχου
│   ├── Έλεγχος MCP
│   └── Έλεγχος A2A
└── Ομάδα συστήματος
    ├── Εύρυθμη λειτουργία
    └── Χρόνος εκτέλεσης
```

### Τι άλλαξε σε σχέση με την παλιά δομή

| Πριν                                                                                                                                                 | Μετά                                                     |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Δραστηριότητα = καρτέλα μέσα στα Αρχεία καταγραφής που εμφάνιζε το Αρχείο καταγραφής ελέγχου                                                         | Δραστηριότητα = αποκλειστική ροή (`/dashboard/activity`) |
| Ομάδα Παράμετροι κόστους στην Παρακολούθηση                                                                                                          | Μεταφέρθηκε στην ενότητα Κόστη                           |
| Επίπεδη λίστα: Αρχεία καταγραφής, Δραστηριότητα (αρχεία καταγραφής), Έλεγχος, Εύρυθμη λειτουργία, Χρόνος εκτέλεσης, Τιμολόγηση, Προϋπολογισμός, Όριο | Δομημένες 3 ομάδες + αποκλειστική ενότητα Κόστη          |

## Δραστηριότητα έναντι Αρχείου καταγραφής ελέγχου

Αυτά τα δύο είναι πλέον διακριτά:

| Διάσταση                  | Δραστηριότητα (`/dashboard/activity`)                                  | Αρχείο καταγραφής ελέγχου (`/dashboard/audit`)      |
| ------------------------- | ---------------------------------------------------------------------- | --------------------------------------------------- |
| **Σκοπός**                | Ροή συμβάντων για τον χρήστη ("τι συνέβη πρόσφατα")                    | Αρχείο καταγραφής συμμόρφωσης / ασφάλειας           |
| **Προέλευση δεδομένων**   | `GET /api/compliance/audit-log?level=high`                             | `GET /api/compliance/audit-log?level=all`           |
| **Μορφή**                 | Χρονολόγιο, ομαδοποιημένο ανά ημέρα, με ευανάγνωστα ρήματα + εικονίδια | Πυκνός σελιδοποιημένος πίνακας, 50/σελίδα           |
| **Φίλτρα**                | Κατηγορία τύπου συμβάντος                                              | Ενέργεια, σοβαρότητα, εκτελεστής, εύρος ημερομηνιών |
| **Εξαγωγή**               | Δεν είναι διαθέσιμη                                                    | Εξαγωγή JSON                                        |
| **Φίλτρο εκτελεστή**      | Δεν εφαρμόζεται                                                        | Δυνατότητα φιλτραρίσματος ανά εκτελεστή             |
| **Εμφανιζόμενα συμβάντα** | Μόνο ενέργειες υψηλού επιπέδου (λίστα επιτρεπόμενων)                   | Όλα τα συμβάντα ελέγχου                             |

### Λίστα επιτρεπόμενων ενεργειών υψηλού επιπέδου

Ορίζεται στο `src/lib/audit/highLevelActions.ts`. Ελέγχει ποια συμβάντα εμφανίζονται στη
ροή Δραστηριότητας. Η λίστα επιτρεπόμενων περιλαμβάνει:

- Συμβάντα προσθήκης/αφαίρεσης/δοκιμής παρόχου
- Δημιουργία/ενημέρωση/διαγραφή συνδυασμού
- Κύκλος ζωής κλειδιού API (δημιουργία, ανάκληση, εναλλαγή)
- Επίτευξη ορίου προϋπολογισμού
- Σύνδεση/αποσύνδεση ελέγχου ταυτότητας
- Δημιουργία συνεδρίας πράκτορα cloud
- Καταχώριση εργαλείου MCP
- Δημιουργία/διαγραφή webhook
- Αλλαγές ομάδων/πλάνων ορίων (`quota.*` ενέργειες, Ομάδα B)
- Συμβάντα πλατφόρμας (ενημέρωση, ανάπτυξη)
- Εγκατάσταση/αφαίρεση δεξιότητας

Τα συμβάντα που δεν περιλαμβάνονται σε αυτή τη λίστα εμφανίζονται μόνο στο Αρχείο καταγραφής ελέγχου.

### Προσθήκη νέας ενέργειας υψηλού επιπέδου

Επεξεργαστείτε το `src/lib/audit/highLevelActions.ts` και προσθέστε τη συμβολοσειρά ενέργειας στο
`HIGH_LEVEL_ACTIONS`. Αυτό απαιτεί ένα PR (η λίστα βρίσκεται στον κώδικα και δεν μπορεί να ρυθμιστεί μέσω της βάσης δεδομένων).
Το αντίστοιχο εικονίδιο μπορεί να προστεθεί στο `src/lib/audit/activityIcons.ts`.

## Ανακατεύθυνση: `/dashboard/logs/activity`

Η παλιά διαδρομή `/dashboard/logs/activity` ανακατευθύνεται μόνιμα (HTTP 308) στη
`/dashboard/activity` μέσω της `permanentRedirect()` στο
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

Το παλαιό αναγνωριστικό πλαϊνής γραμμής `logs-activity` διατηρείται στο `HIDEABLE_SIDEBAR_ITEM_IDS`
(αλλά αφαιρέθηκε από το `SIDEBAR_DEFINITIONS`), ώστε να μην πάψουν να λειτουργούν οι προεπιλογές χρηστών που
αναφέρονται στο παλιό αναγνωριστικό.

## i18n

Χώροι ονομάτων που προστέθηκαν από την Ομάδα B:

| Κλειδί χώρου ονομάτων   | Καλύπτει                                                                                 |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| `sidebar.costsSection`  | Ετικέτα ενότητας Κόστη                                                                   |
| `sidebar.activity`      | Στοιχείο Δραστηριότητα της πλαϊνής γραμμής                                               |
| `sidebar.logsGroup`     | Ετικέτα υποομάδας αρχείων καταγραφής                                                     |
| `sidebar.systemGroup`   | Ετικέτα υποομάδας συστήματος                                                             |
| `sidebar.costsOverview` | Στοιχείο επισκόπησης κόστους                                                             |
| `activity.*`            | Όλες οι συμβολοσειρές της σελίδας Δραστηριότητα (τίτλος, ρήματα, φίλτρα, κενή κατάσταση) |

Οι τοπικές ρυθμίσεις που αποτελούν την πηγή αλήθειας είναι οι `pt-BR` και `en`. Και οι υπόλοιπες 40 τοπικές ρυθμίσεις χρησιμοποιούν ως εφεδρική
την αγγλική γλώσσα μέσω του μηχανισμού εφεδρείας του `next-intl` (ρυθμισμένου στο `src/i18n/config.ts`).
