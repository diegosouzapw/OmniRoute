## Snabbstart

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "my-plugin",
  priority: 50,
  onRequest: async (ctx) => {
    console.log(`Request ${ctx.requestId} for ${ctx.model}`);
  },
  onResponse: async (ctx, response) => {
    console.log(`Response for ${ctx.requestId}`);
    return response;
  },
  onError: async (ctx, error) => {
    console.error(`Error: ${error.message}`);
  },
});
```

## API-referens

### `definePlugin(def: PluginDefinition): Plugin`

Fabriksfunktion som skapar ett Plugin-objekt med standardvärden.

**Parametrar:**

- `name` (string, obligatorisk) — Plugin-namn i kebab-case
- `priority` (number, valfri, standardvärde: 100) — Lägre värde körs först
- `enabled` (boolean, valfri, standardvärde: true) — Ska pluginet vara aktiverat från början?
- `onRequest` (function, valfri) — Körs före chatthanteraren
- `onResponse` (function, valfri) — Körs efter chatthanteraren
- `onError` (function, valfri) — Körs vid hanteringsfel

### `blockRequest(response?): BlockingHookResult`

Blockera begäran och returnera valfritt ett anpassat svar.

```ts
onRequest: (ctx) => {
  if (!ctx.headers["authorization"]) {
    return blockRequest({ error: "Unauthorized", status: 401 });
  }
};
```

### `modifyBody(body): PluginResult`

Ändra begärans innehåll innan det når leverantören.

```ts
onRequest: (ctx) => {
  return modifyBody({ ...ctx.body, temperature: 0.7 });
};
```

### `addMetadata(metadata): PluginResult`

Bifoga metadata till begärans kontext.

```ts
onRequest: (ctx) => {
  return addMetadata({ source: "my-plugin", version: "1.0.0" });
};
```

## Plugin-kontext (`PluginContext`)

| Fält        | Typ                       | Beskrivning                    |
| ----------- | ------------------------- | ------------------------------ |
| `requestId` | `string`                  | Unik identifierare för begäran |
| `model`     | `string`                  | Namnet på den begärda modellen |
| `provider`  | `string`                  | Mål-id för leverantören        |
| `body`      | `Record<string, unknown>` | Begärans innehåll              |
| `headers`   | `Record<string, string>`  | Begärans rubriker              |
| `metadata`  | `Record<string, unknown>` | Ändringsbara metadata          |
| `timestamp` | `number`                  | Begärans tidsstämpel           |

## Manifest (`plugin.json`)

```json
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "A sample plugin",
  "author": "your-name",
  "main": "index.js",
  "hooks": {
    "onRequest": { "enabled": true, "priority": 50 },
    "onResponse": true,
    "onError": false
  },
  "requires": {
    "permissions": ["network", "file-read"]
  },
  "enabledByDefault": false,
  "configSchema": {
    "apiKey": {
      "type": "string",
      "description": "API key for external service"
    },
    "maxRetries": { "type": "number", "min": 1, "max": 10, "default": 3 },
    "debug": { "type": "boolean", "default": false },
    "mode": { "type": "string", "enum": ["fast", "slow"], "default": "fast" }
  }
}
```

### Hook-prioritet

Hooks kan konfigureras med prioritet (lägre = körs först):

```json
{
  "hooks": {
    "onRequest": { "enabled": true, "priority": 10 },
    "onResponse": { "enabled": true, "priority": 100 }
  }
}
```

Eller som enkla booleska värden (standardprioritet 100):

```json
{
  "hooks": {
    "onRequest": true,
    "onResponse": true
  }
}
```

## Behörighetssystem

Plugins körs i en sandlådeskyddad VM-kontext. Åtkomst till externa resurser kräver uttryckliga behörigheter:

| Behörighet   | Ger åtkomst till                                             |
| ------------ | ------------------------------------------------------------ |
| `network`    | `fetch`, `AbortController`, `Headers`, `Request`, `Response` |
| `file-read`  | `fs.readFile`, `fs.readdir`, `fs.stat`                       |
| `file-write` | `fs.writeFile`, `fs.mkdir`, `fs.rm`                          |
| `env`        | Skrivskyddad proxy för `process.env`                         |
| `exec`       | `child_process.exec`, `child_process.execSync`               |

Utan en behörighet är motsvarande globala objekt helt enkelt inte tillgängliga i sandlådan.

## Konfigurationsschema

Definiera konfigurerbara inställningar i `configSchema`:

```json
{
  "configSchema": {
    "apiKey": { "type": "string", "description": "External API key" },
    "maxRetries": { "type": "number", "min": 1, "max": 10, "default": 3 },
    "debug": { "type": "boolean", "default": false },
    "mode": { "type": "string", "enum": ["fast", "slow"], "default": "fast" }
  }
}
```

Fälttyper: `string`, `number`, `boolean`, `select`

Fältalternativ: `default`, `min`, `max`, `enum`, `description`

Konfigurationsvärden sparas i databasen och är tillgängliga via konfigurationssidan i instrumentpanelen.

## Inbyggda händelser

| Händelse          | När                                        | Nyttolast                     |
| ----------------- | ------------------------------------------ | ----------------------------- |
| `onRequest`       | Före chatthanteraren                       | Begärankontext                |
| `onResponse`      | Efter chatthanteraren                      | Svarsdata                     |
| `onError`         | Vid hanteringsfel                          | Felobjekt                     |
| `onModelSelect`   | Modell vald för dirigering                 | Modellinformation             |
| `onComboResolve`  | Kombinationsdirigering löst                | Kombinationsmål               |
| `onRateLimit`     | Hastighetsgräns uppnådd                    | Gränsinformation              |
| `onQuotaExhaust`  | Kvot förbrukad                             | Kvotinformation               |
| `onProviderError` | Leverantören returnerade ett fel           | Felinformation                |
| `onStreamStart`   | SSE-ström startad                          | Ströminformation              |
| `onStreamEnd`     | SSE-ström avslutad                         | Strömstatistik                |
| `onInstall`       | Plugin installerad                         | `{ name, version, manifest }` |
| `onActivate`      | Plugin aktiverad                           | `{ name, version, manifest }` |
| `onDeactivate`    | Plugin inaktiverad                         | `{ name, version, manifest }` |
| `onUninstall`     | Plugin avinstallerad (innan filer raderas) | `{ name, version, manifest }` |

## Exempel

### Begärandeloggare

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "request-logger",
  onRequest: async (ctx) => {
    console.log(`[${new Date().toISOString()}] ${ctx.method} ${ctx.model} -> ${ctx.provider}`);
  },
});
```

### Hastighetsbegränsare

```ts
import { definePlugin, blockRequest } from "omniroute/plugins/sdk";

const requests = new Map<string, number[]>();

export default definePlugin({
  name: "rate-limiter",
  priority: 10,
  onRequest: async (ctx) => {
    const key = ctx.headers["x-api-key"] || "anonymous";
    const now = Date.now();
    const window = 60000; // 1 minut
    const maxRequests = 100;

    const timestamps = (requests.get(key) || []).filter((t) => t > now - window);
    timestamps.push(now);
    requests.set(key, timestamps);

    if (timestamps.length > maxRequests) {
      return blockRequest({ error: "Rate limit exceeded", status: 429 });
    }
  },
});
```

### Svarstransformerare

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "response-transformer",
  onResponse: async (ctx, response) => {
    if (response.choices) {
      response.choices = response.choices.map((c: any) => ({
        ...c,
        message: { ...c.message, content: c.message.content.trim() },
      }));
    }
    return response;
  },
});
```
