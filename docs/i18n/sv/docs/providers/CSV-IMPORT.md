Kontrollpanel → Leverantörer → **Importera från fil** skapar API-nyckelanslutningar från en CSV- eller JSON-lista. Varje rad kan avse en annan leverantör. Partiella fel är en del av kontraktet: giltiga rader importeras även när andra misslyckas, och dialogrutan visar varför de misslyckade raderna avvisades.

Den här importen skapar **inte** nya OpenAI/Anthropic-kompatibla slutpunktsnoder. Skapa dem först (Kontrollpanel → Leverantörer → Lägg till OpenAI-kompatibel, eller `omniroute nodes add`) och importera sedan rader där kolumnen `provider` innehåller nodens id. Ett `baseUrl` per rad kan fortfarande åsidosätta nodens URL.

## CSV (positionell)

Kolumnnamnen är endast kosmetiska. Parsern delar upp varje rad och destrukturerar efter index:

| Index | Fält       | Obligatoriskt | Anmärkningar                                                                                                                                    |
| ----- | ---------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 0     | `provider` | ja            | Befintligt id för en hanterad leverantör (`openai`, `anthropic`, …) **eller** id:t för en redan registrerad OpenAI/Anthropic-kompatibel **nod** |
| 1     | `name`     | ja            | Anslutningens visningsnamn                                                                                                                      |
| 2     | `apiKey`   | ja            | API-nyckel                                                                                                                                      |
| 3     | `baseUrl`  | nej           | URL-åsidosättning per rad                                                                                                                       |
| 4     | `priority` | nej           | Heltal 1–100                                                                                                                                    |

En första rad vars första kolumn är det exakta ordet `provider` (oavsett skiftläge) hoppas över som rubrikrad. Tomma rader och `#`-kommentarer hoppas över.

Hämta en startfil från importdialogrutan (**Hämta CSV-mall**). Exempel:

```csv
# Import av OmniRoute-leverantörer (positionella kolumner)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Ett påhittat id som `openai-compatible-chat-001` är inte en nod. API:et returnerar `Okänd leverantör eller leverantör som inte stöds` för den raden; dialogrutan visar meddelandet bredvid radens namn.

## JSON

En JSON-array med objekt som har samma fält (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Till skillnad från CSV har JSON namngivna nycklar.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
