OmniRoute levereras med en utvald uppsättning kostnadsfria proxyservrar i tabellen `free_proxies`,
synkroniserade från externa leverantörer (1proxy, proxifly, iplocate, webshare).
Instrumentpanelen visar dessa under **Inställningar → Kostnadsfria proxyservrar**. Det här dokumentet
beskriver filtrering, sortering, räkning och rapportering av synkroniseringsfel på serversidan
som listrutten tillhandahåller.

## Listrutt — `GET /api/settings/free-proxies`

Returnerar ett filtrerat, sorterat och sidindelat urval samt ett totalt antal. Filtrering och
räkning sker i SQL, så att användargränssnittet kan visa det verkliga totalantalet (t.ex. `Totalt: 0`)
utan att läsa in varje rad i minnet.

### Frågeparametrar

| Parameter         | Typ                                | Standardvärde | Betydelse                                                                                                        |
| ----------------- | ---------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------- |
| `search`          | sträng                             | `""`          | Skiftlägeskänslig `LIKE` på kolumnen för värd (och källa).                                                       |
| `protocol`        | sträng                             | `""`          | `type`-filter: `http` / `https` / `socks4` / `socks5`. Tomt = alla.                                              |
| `country`         | sträng                             | `""`          | `countryCode`-filter (ISO-2). Tomt = alla.                                                                       |
| `minQuality`      | tal                                | `0`           | Endast rader där `qualityScore >= minQuality`. `0` = ingen minimigräns.                                          |
| `disabledSources` | sträng                             | `""`          | Kommaseparerade käll-id:n som ska exkluderas (t.ex. `proxifly,webshare`).                                        |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`     | `quality` = poäng fallande; `latency` = latens stigande (null-värden sist); `recent` = `lastValidated` fallande. |
| `offset`          | tal                                | `0`           | Startpunkt för sidindelning.                                                                                     |
| `limit`           | tal                                | `50`          | Sidstorlek (begränsas på serversidan).                                                                           |

### Svar

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 från uppströmsservern"],
    "webshare": ["tidsgränsen för nätverket överskreds"]
  }
}
```

`total` återspeglar det filtrerade totalantalet **före** sidindelning, så att användargränssnittet kan visa
`Totalt: N` och `hasMore` oberoende av varandra. `syncErrors` använder käll-id som nycklar och
fylls endast i för källor vars senaste synkronisering misslyckades — ett resultat med `Totalt: 0`
är aldrig tyst.

## Lägg till i poolen — `POST /api/settings/free-proxies/[id]/add-to-pool`

Flyttar en kostnadsfri proxyserver till den hanterade `proxy_registry`-poolen. Validerar
uppströmsservern först och returnerar vid lyckat resultat den nya poolproxyns id och uppmätta latens.

## Synkronisering — `POST /api/settings/free-proxies/sync`

Hämtar alla aktiverade källor på nytt (eller delmängden i `{ "sources": [...] }`). Varje
källa synkroniseras oberoende; en källa som misslyckas registreras i `syncErrors` medan de
övriga ändå slutförs, så partiella synkroniseringar raderar aldrig tidigare giltiga data.

## Statistik — `GET /api/settings/free-proxies/stats`

Returnerar aggregatet `total / inPool / avgQuality / bySource / lastSyncAt`
utan radinnehållet — används av instrumentpanelens rubrikwidgetar.
