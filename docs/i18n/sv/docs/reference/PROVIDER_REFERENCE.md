## Kategorier

- **Gratis** — kostnadsfri nivå med API-nyckel (konfigureras via kontrollpanelen)
- **Ingen autentisering** — offentliga slutpunkter som inte kräver någon nyckel eller inloggning
- **OAuth** — inloggningsflödet hanteras av OmniRoute, ingen API-nyckel behövs
- **Webbkaka** — kapslar in leverantörens webbapp via kakbaserad autentisering
- **API-nyckel** — betald leverantör som konfigureras via API-nyckel (kostnadsfria krediter kan förekomma)
- **Lokal** — körs på användarens dator (Ollama, LM Studio, vLLM osv.)
- **Sökning** — leverantörer av webbsökning
- **Ljud** — leverantörer endast för ljud (TTS/STT)
- **Uppströmsproxy** — leverantörer som fungerar som proxy till andra leverantörer
- **Molnagent** — långkörande kodningsagenter (Codex Cloud, Devin, Jules)
- **System** — interna OmniRoute-leverantörer (loopback osv.)

Ytterligare taggar: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (där det visas): `native` — riktigt API för funktionsanrop; `emulated` — matrisen `tools` emuleras via promptar med hjälp av `webTools.ts` (regex-tolkade `<tool>{...}</tool>`-block); `none` — `tools` ignoreras för närvarande utan någon varning. Se #7286.

Använd kontrollpanelen på `/dashboard/providers` för att aktivera, konfigurera och testa varje leverantör.
