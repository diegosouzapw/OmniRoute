> **Kort sagt**: OmniRoute rankar sina **kostnadsfria** leverantörer efter modellkvalitet med hjälp av **ELO-poäng från
> Arena AI (i LMArena-stil)**. Öppna sidan **Rankning av kostnadsfria leverantörer** i
> kontrollpanelen för att se vilka kostnadsfria leverantörer som erbjuder de starkaste modellerna för din uppgift —
> totalt sett eller filtrerat efter kategori (kodning, granskning, dokumentation, felsökning).

---

## Vad det är

OmniRoute registrerar 329 leverantörer, inklusive 155 katalogposter som är markerade som **kostnadsfria/utan autentisering**
(utan autentisering,
kostnadsfri OAuth-nivå eller kostnadsfri API-nyckel — se
[Guiden till kostnadsfria nivåer](../getting-started/FREE-TIERS-GUIDE.md) och den fullständiga
[katalogen över kostnadsfria nivåer](../reference/FREE_TIERS.md)). Haken är att kostnadsfria leverantörer varierar
kraftigt i modellkvalitet. En leverantör utan autentisering som erbjuder en spjutspetsmodell är betydligt mer användbar
än en som erbjuder en liten äldre modell.

**Rankning av kostnadsfria leverantörer** besvarar frågan ”**vilken kostnadsfri leverantör ger mig den bästa modellen?**” genom att
sammanföra varje kostnadsfri leverantörs katalog med **kollektivt insamlade kvalitetspoäng** från
**Arena AI:s topplista** (ELO baserad på mänskliga preferenser, samma idé som ligger bakom LMArena-
chatbotarenan). Leverantörerna rankas sedan efter styrkan hos deras **bästa kostnadsfria modell**.

Rankningen beräknas från tre verkliga källor:

1. Listorna över kostnadsfria leverantörer — `NOAUTH_PROVIDERS` samt poster i `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` som är flaggade med `hasFree`
   (`src/shared/constants/providers.ts`).
2. Varje leverantörs modellkatalog från leverantörsregistret
   (`open-sse/config/providerRegistry.ts`).
3. ELO-härledda poäng för uppgiftslämplighet som lagras i DB-tabellen `model_intelligence` av
   synkroniseringsmotorn för Arena ELO (`src/lib/arenaEloSync.ts`).

Sammanfogningslogiken finns i `src/lib/freeProviderRankings.ts`.

## Så får du åtkomst

### Kontrollpanelssida

Öppna kontrollpanelen och gå till **Kostnader → Rankning av kostnadsfria leverantörer**, eller navigera direkt till:

```
/dashboard/free-provider-rankings
```

Sidan (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) visar:

- Ett **prispodium för de tre främsta** (🥇 🥈 🥉) bland de högst rankade kostnadsfria leverantörerna.
- En fullständig **rankningstabell** med kolumnerna: **Placering**, **Leverantör**, **Toppmodell**,
  **Poäng**, **Genomsnittlig poäng**, **Modeller**, **Typ**.
- **Kategorifilterknappar**: _Alla kategorier_, _Standard_, _Kodning_, _Granskning_,
  _Dokumentation_, _Felsökning_.

Varje leverantörs **Typ**-märke visar på vilket sätt den är kostnadsfri:

| Märke    | Betydelse                                                |
| -------- | -------------------------------------------------------- |
| `NOAUTH` | Alltid kostnadsfri, inga autentiseringsuppgifter krävs   |
| `OAUTH`  | OAuth-leverantör med en kostnadsfri nivå (`hasFree`)     |
| `APIKEY` | API-nyckelleverantör med en kostnadsfri nivå (`hasFree`) |

Poängen visas som lättlästa etiketter (t.ex. _Elit_, _Utmärkt_, _Mycket bra_,
_Bra_, _Genomsnittlig_) i stället för råa tal, eftersom det underliggande värdet är ett relativt
mått på rankningskvalitet, inte en procentsats.

### API-slutpunkt

Sidan använder en offentlig slutpunkt för läsning
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Frågeparametrar (validerade med Zod):

| Parameter  | Typ    | Standardvärde | Anmärkningar                                                                                                |
| ---------- | ------ | ------------- | ----------------------------------------------------------------------------------------------------------- |
| `category` | sträng | (inget)       | En av `default`, `coding`, `review`, `documentation`, `debugging`. Utelämna för den kombinerade rankningen. |
| `limit`    | tal    | `50`          | Begränsas till intervallet `1–100`.                                                                         |

Svarsformat:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` är det ursprungliga Arena ELO-värdet; `score` är det normaliserade värdet för uppgiftslämplighet
(se nedan). Leverantörer utan poängsatta modeller utelämnas från svaret.

## Så fungerar poängen

### Källa: Arena AI:s topplista

Arena ELO-synkroniseringsmotorn (`src/lib/arenaEloSync.ts`) hämtar två topplistor — `text`
och `code` — från Arena AI:s API för topplistor
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Varje post i topplistan
innehåller ett modellnamn, en leverantör, ELO-`score`, ett konfidensintervall och antal röster.

Topplistans kategorier mappas till OmniRoutes uppgiftskategorier:

| Arena-topplista | OmniRoutes uppgiftskategorier                     |
| --------------- | ------------------------------------------------- |
| `text`          | `default`, `review`, `documentation`, `debugging` |
| `code`          | `coding`                                          |

### Normalisering (poäng för uppgiftslämplighet)

Råa ELO-poäng normaliseras per topplista till ett **värde för uppgiftslämplighet inom `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Poängen når aldrig `0` eller `1`, vilket lämnar utrymme för användaråsidosättningar. Detta är
fältet `score` som visas i API-svaret och etiketten som visas på instrumentpanelen.

### Konfidens

Varje post får en konfidensnivå baserat på antalet röster i Arena:

| Konfidens | Röster  |
| --------- | ------- |
| `high`    | ≥ 5 000 |
| `medium`  | ≥ 1 000 |
| `low`     | < 1 000 |

### Lagring och aktualitet

Normaliserade poster skrivs till DB-tabellen `model_intelligence` med
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Poster **upphör att gälla efter
7 dagar**, så en leverantör som slutar synkronisera försvinner så småningom i stället för att
visa inaktuella data.

Synkroniseringen körs **som standard**:

- Den körs en gång vid serverstart och därefter med ett periodiskt tidsintervall
  (`src/lib/arenaEloSync.ts`, inkopplad från `src/instrumentation-node.ts`).
- Den är **icke-blockerande och aldrig fatal** — om hämtningen från den externa källan misslyckas fortsätter OmniRoute
  att köras, och rankningarna visar helt enkelt de senast fungerande uppgifterna (eller ett tomt tillstånd).

Två miljövariabler styr den (dokumenterade i
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Variabel                  | Standard       | Syfte                                                    |
| ------------------------- | -------------- | -------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`         | Ange `false` för att välja bort utgående synkronisering. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24 h) | Synkroniseringsintervall i sekunder.                     |

### Manuell synkronisering/status/rensning

För operatörer tillhandahåller en autentiserad hanteringsslutpunkt manuell styrning
(`src/app/api/intelligence/sync/route.ts` — kräver hanteringsautentisering):

```
GET    /api/intelligence/sync          # aktuell synkroniseringsstatus (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # utlös en manuell synkronisering; body: { "dryRun": true } för att förhandsgranska utan att skriva
DELETE /api/intelligence/sync          # rensa alla synkroniserade arena_elo-intelligensposter
```

Om rankningssidan är tom fylls den på igen genom en manuell `POST /api/intelligence/sync` (eller helt enkelt
genom att servern startas om).

### Matchning av modeller mot topplistan

Modell-ID:n i registret och modellnamn i Arena matchar inte alltid exakt. Rankningen använder
flexibel matchning (`findMatchingIntelligence` i `src/lib/freeProviderRankings.ts`):

1. Exakt matchning mot det normaliserade modell-ID:t.
2. Matchning efter borttagning av ett avslutande versionssuffix (t.ex. `kimi-k2.6` → `kimi-k2`).
3. Prefixmatchning (ett modellnamn i topplistan är ett prefix till registrets ID).

På synkroniseringssidan tas kända leverantörsprefix (`anthropic/`, `openai/`, `google/`, …)
bort, och en liten aliasmappning utökar kanoniska namn till de varianter som OmniRoute använder
internt, så att modeller kan hittas oavsett namn.

### Så rankas en leverantör

För varje kostnadsfri leverantör poängsätter motorn varje modell i dess katalog och därefter gäller följande:

- **Bästa modell** = leverantörens modell med högst poäng.
- **Genomsnittlig poäng** = medelvärdet för alla leverantörens poängsatta modeller.
- **Modeller** = hur många av leverantörens modeller som hade en Arena-poäng.

Leverantörer sorteras först efter **den bästa modellens poäng** och därefter efter genomsnittlig poäng. Detta gynnar en
leverantör som erbjuder minst en stark kostnadsfri modell.

## Använda den för att välja kostnadsfria leverantörer

1. **Välj rätt kategori.** Använd filtret **Coding** för agentbaserade arbetsflöden/kodarbetsflöden, eller
   behåll **All Categories** / **Default** för allmän chatt. Samma leverantör kan
   rankas olika mellan kategorier eftersom dess bästa modell skiljer sig åt per topplista.
2. **Föredra pallplatserna för engångskonfigurationer.** Om du bara vill ansluta en eller två kostnadsfria
   leverantörer bör du börja med de högst rankade i din kategori.
3. **Kontrollera typetiketten.** `NOAUTH`-leverantörer är snabbast att ansluta (inga
   autentiseringsuppgifter). Kostnadsfria nivåer med `OAUTH` / `APIKEY` kräver en snabb registrering men ger ofta tillgång till
   kraftfullare modeller. Se [Guide till kostnadsfria nivåer](../getting-started/FREE-TIERS-GUIDE.md) för
   anslutningssteg.
4. **Anslut flera och låt Auto-Combo avgöra.** Samma Arena ELO-data som driver
   den här sidan används även för **uppgiftslämplighetsfaktorn** i Auto-Combos poängmotor
   (`open-sse/services/autoCombo/taskFitness.ts`, prioritetsordning:
   `user_override → arena_elo → models_dev_tier → static table`). När du har anslutit
   de främsta kostnadsfria leverantörerna kommer dirigering med `model: "auto"` (t.ex. `auto/coding`)
   därför automatiskt att föredra kostnadsfria modeller av högre kvalitet för varje begäran. Se
   [Auto-Combo](../routing/AUTO-COMBO.md) för den fullständiga poängsättningen med 16 faktorer.
