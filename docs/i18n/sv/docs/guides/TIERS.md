OmniRoute organiserar de 352 leverantörer som stöds i 3 ekonomiska nivåer. Varje
begäran går igenom dem i tur och ordning tills en av dem returnerar ett lyckat
svar — du får det billigaste fungerande svaret utan att behöva skriva reservkod.

## Nivå 1 — Abonnemang

**Leverantörer som du redan betalar för.** OmniRoute använder all tillgänglig
kvot innan den löper ut.

| Leverantör                        | Varför nivå 1                                   |
| --------------------------------- | ----------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — fast pris, ofta outnyttjat |
| OpenAI Codex (ChatGPT-abonnemang) | Plus/Team inkluderar Codex-kvot                 |
| GitHub Copilot                    | Per användare — kvoten återställs varje månad   |
| Cursor IDE                        | Kvot i Pro-planen                               |
| Antigravity / Devin Desktop       | Inbyggda kvoter                                 |

**Strategi**: dirigera hit först för varje begäran som passar modellens
styrkor. Kvotspåraren övervakar kommande återställningar och kombinationsstrategin
`reset-aware` prioriterar därefter. Om du vill dirigera till nivå 1 först och
endast gå vidare till betalda nivåer när kvoten tar slut använder du id:t
`auto/thrifty` — eller `auto/subscription` för att stanna på kapacitet som
ingår i planen och annars misslyckas utan att gå vidare. Se
[Abonnemangsförst-dirigering](../routing/SUBSCRIPTION_LADDER.md).

## Nivå 2 — Billigt

**Leverantörer med betalning per token under $1/1M tokens.** Reserverade för
arbeten med hög volym eller när kvoterna på nivå 1 har nått sina gränser.

| Leverantör                 | Pris (indata/utdata) | Styrkor                  |
| -------------------------- | -------------------- | ------------------------ |
| DeepSeek V4 Pro            | $0.27 / $1.10 per 1M | Kod, resonemang          |
| GLM-4.5                    | $0.60 / $2.20 per 1M | Lång kontext             |
| MiniMax M1                 | $0.20 / $1.10 per 1M | Hastighet                |
| Qwen Coder                 | $0.30 / $1.20 per 1M | Kod                      |
| OpenRouter (prisoptimerad) | varierar             | 100+ modeller, dynamiskt |

**Strategi**: kombinationen `cost-optimized` väljer den modell med lägst
$/token som uppfyller uppgiftens kapabilitetsfilter (bild, JSON-läge, verktyg,
maximal kontext).

## Nivå 3 — Gratis

**Kostnadsfria leverantörer** — kostnadsfria nivåer, kreditprogram och dagliga
OAuth-kvoter.

| Leverantör       | Kostnadsfri kvot/krediter                           |
| ---------------- | --------------------------------------------------- |
| Kiro AI          | Kostnadsfri Claude-nivå (generös skälig användning) |
| OpenCode Free    | Ingen autentisering, generösa hastighetsgränser     |
| Qoder            | Kostnadsfri OAuth                                   |
| Google Vertex AI | $300 i krediter för nya konton                      |
| Amazon Q         | Kostnadsfri nivå för AWS-användare                  |
| Pollinations     | Öppet publikt API                                   |
| Cloudflare AI    | Kostnadsfri Workers AI-nivå                         |

**Strategi**: kombinationen `auto` med budgettak dirigerar hit när nivå 1+2
misslyckas eller när `useFreeOnly=true` har angetts. Kostnadsfria leverantörer
har ofta striktare hastighetsgränser — kretsbrytaren återställer dem efter
backoff.

## Konfigurera nivåer

Kontrollpanelen → **Nivåer** → tilldela dina leverantörer. Standardvärdena
(från `tierDefaults.json`) är rimliga; redigera dem när du har specifika
abonnemang att prioritera eller leverantörer att utesluta.

Auto-Combos poängsättning med 16 faktorer tar också hänsyn till nivån. Se
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetri

Kontrollpanelen → **Användning** visar förbrukade tokens per nivå och dag.
Använd detta för att:

- Bekräfta att nivå 1 utnyttjas fullt ut (annars slösar du bort abonnemangets värde)
- Identifiera vilka modeller på nivå 2 som väljs oftast (konsolidera till 1–2)
- Verifiera att nivå 3 sparar pengar vid test- och utforskningsarbete

## Vanliga mönster

### Helt kostnadsfri arbetsbelastning

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Styr kraftigt mot nivå 3; använder endast nivå 2 om nivå 3 inte är tillgänglig.

### Abonnemang först med billig reservlösning

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Explicit ordnad lista som motsvarar nivå 1 → nivå 2 → nivå 3.
