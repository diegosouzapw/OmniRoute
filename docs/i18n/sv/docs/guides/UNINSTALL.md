## Snabb avinstallation (v3.6.2+)

OmniRoute tillhandahåller två inbyggda skript för fullständig avinstallation:

### Behåll dina data

```bash
npm run uninstall
```

Detta tar bort OmniRoute-applikationen men **bevarar** din databas, dina konfigurationer, API-nycklar och leverantörsinställningar i `~/.omniroute/`. Använd detta om du planerar att installera om senare och vill behålla din konfiguration.

### Fullständig borttagning

```bash
npm run uninstall:full
```

Detta tar bort applikationen **och raderar permanent** alla data:

- Databas (`storage.sqlite`)
- Leverantörskonfigurationer och API-nycklar
- Säkerhetskopior
- Loggfiler
- Alla filer i katalogen `~/.omniroute/`

> ⚠️ **Varning:** `npm run uninstall:full` går inte att ångra. Alla dina leverantörsanslutningar, kombinationer, API-nycklar och din användningshistorik kommer att raderas permanent.

## Manuell avinstallation

### Global NPM-installation

```bash
# Ta bort det globala paketet
npm uninstall -g omniroute

# (Valfritt) Ta bort datakatalogen
rm -rf ~/.omniroute
```

### Global pnpm-installation

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Stoppa och ta bort containern
docker stop omniroute
docker rm omniroute

# Ta bort volymen (raderar alla data)
docker volume rm omniroute-data

# (Valfritt) Ta bort avbildningen
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Stoppa och ta bort containrar
docker compose down

# Ta även bort volymer (raderar alla data)
docker compose down -v
```

### Electron-skrivbordsapp

**Windows:**

- Öppna `Inställningar → Appar → OmniRoute → Avinstallera`
- Eller kör NSIS-avinstalleraren från installationskatalogen

**macOS:**

- Dra `OmniRoute.app` från `/Applications` till papperskorgen
- Ta bort data: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Ta bort AppImage-filen
- Ta bort data: `rm -rf ~/.omniroute`

### Installation från källkod (git clone)

```bash
# Ta bort den klonade katalogen
rm -rf /path/to/omniroute

# (Valfritt) Ta bort datakatalogen
rm -rf ~/.omniroute
```

## Datakataloger

OmniRoute lagrar som standard data på följande platser:

| Plattform      | Standardsökväg                | Åsidosättning                    |
| -------------- | ----------------------------- | -------------------------------- |
| Linux          | `~/.omniroute/`               | Miljövariabeln `DATA_DIR`        |
| macOS          | `~/.omniroute/`               | Miljövariabeln `DATA_DIR`        |
| Windows        | `%APPDATA%/omniroute/`        | Miljövariabeln `DATA_DIR`        |
| Docker         | `/app/data/` (monterad volym) | Miljövariabeln `DATA_DIR`        |
| XDG-kompatibel | `$XDG_CONFIG_HOME/omniroute/` | Miljövariabeln `XDG_CONFIG_HOME` |

### Filer i datakatalogen

| Fil/katalog          | Beskrivning                                                        |
| -------------------- | ------------------------------------------------------------------ |
| `storage.sqlite`     | Huvuddatabas (leverantörer, kombinationer, inställningar, nycklar) |
| `storage.sqlite-wal` | SQLite-logg för förhandsskrivning (tillfällig)                     |
| `storage.sqlite-shm` | Delat SQLite-minne (tillfälligt)                                   |
| `call_logs/`         | Arkiv med begärandenas nyttolaster                                 |
| `backups/`           | Automatiska säkerhetskopior av databasen                           |
| `log.txt`            | Äldre begärandelogg (valfri)                                       |

## Verifiera fullständig borttagning

Efter avinstallationen kontrollerar du att inga filer finns kvar:

```bash
# Kontrollera globalt npm-paket
npm list -g omniroute 2>/dev/null

# Kontrollera datakatalogen
ls -la ~/.omniroute/ 2>/dev/null

# Kontrollera processer som körs
pgrep -f omniroute
```

Om någon process fortfarande körs stoppar du den:

```bash
pkill -f omniroute
```
