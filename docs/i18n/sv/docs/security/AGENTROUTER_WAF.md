`agentrouter`-uppströmsgatewayen kör ett nyckelordsbaserat innehållsfilter på
`messages[].content`. Filtret är delvis deterministiskt (blockerar alltid
vissa fraser) och delvis probabilistiskt (känsligt för anropsskurar — blir
mer aggressivt efter snabba förfrågningar och återhämtar sig efter en nedkylningsperiod).

När WAF:en blockerar en förfrågan returnerar den:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Filtrets omfattning

WAF:en granskar endast `messages[].content`. Den granskar **inte**:

- `system`-prompten
- Strukturerade innehållsblock (`tool_result`, `tool_use`, `thinking`, `image`)
- Verktygens fält `description` och `input_schema`
- Metadata för förfrågningar, headers eller modell-id

## Mönster som alltid blockeras (skiftlägesokänsligt)

| Mönster                         | Anmärkningar                                            |
| ------------------------------- | ------------------------------------------------------- |
| Alla varianter av `Lorem ipsum` | Hela det latinska lorem-ordförrådet blockeras           |
| `language model` (ensamt)       | "the language model" och "large language model" tillåts |
| `virtual assistant`             | "AI assistant" tillåts                                  |
| `I'm here to help`              | Även enbart "here to help" blockeras                    |
| `Claude, made by Anthropic`     | Endast hela frasen                                      |

## Mönster som nästan alltid blockeras

| Mönster                                                  | Anmärkningar                                          |
| -------------------------------------------------------- | ----------------------------------------------------- |
| `placeholder`                                            | När det står ensamt (inte som ett parameternamn osv.) |
| `dummy data`                                             | Vanlig seed-fras för fixtures                         |
| `foo bar baz`                                            | Kanonisk platshållarfras                              |
| Upprepade korta tokens (`AAA BBB CCC`, `test test test`) | Detektor för överdriven nyckelordsanvändning          |

## Beteende under belastning

Efter cirka 5 snabba förfrågningar inom ett kort tidsfönster börjar WAF:en
blockera innehåll som normalt skulle tillåtas. Begränsningsbucketen återhämtar
sig efter cirka 5–10 sekunders inaktivitet. Detta är samma IP- och nyckelbundna
hastighetsbegränsare som orsakar sporadiska `400 content-blocked`-fel när
Claude Code eller Codex CLI gör flera anrop för verktygsanvändning eller
meddelandesändning i snabb följd.

## Begränsningsåtgärder som redan har införts i OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — skurskydd som säkerställer ett
   minsta intervall på 500 ms mellan utgående förfrågningar till en
   `agentrouter:*`-URL. Intervallet är långt under människans uppfattningsgräns
   för latens och förhindrar att WAF:en aktiveras vid normal trafik.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — när en uppströmsserver returnerar
   `400 content-blocked` försöker exekveraren samma URL igen med
   exponentiell backoff (1,5 s, 3,0 s, högst 2 försök). Efter väntetiden
   har WAF:en vanligtvis återhämtat sig och det nya försöket lyckas.

3. **`tests/unit/compression/harness.test.ts`** — test-fixturen
   `longInput` ändrades från `"lorem ipsum dolor sit amet ".repeat(40)`
   till `"example content for testing purposes ".repeat(40)` så att
   filinnehållet, när Claude Code läser filen via verktyget `Read`,
   inte skickas tillbaka genom ett `tool_result`-block och utlöser WAF:en.

## Riktlinjer för prompter och verktygsutdata

Om en Claude Code- eller Codex CLI-session upprepade gånger stöter på
`400 content-blocked`, kontrollera det senaste användarmeddelandet och det
senaste verktygsresultatet efter något av mönstren ovan och formulera om.
Vanliga lösningar:

- Ersätt `Lorem ipsum …` med `example text …` eller det faktiska innehåll
  som testet eller fixturen försöker modellera.
- Ersätt `placeholder` (när det står ensamt) med `example value`,
  `sample value` eller det verkliga värdet.
- Ersätt `language model` med `large language model` eller `the model`.
- Ersätt `dummy data` med `sample data` eller realistiska seed-värden.
- Ersätt `I'm here to help` / `here to help` med en mer specifik
  inledning (t.ex. "I'll review the file you mentioned").

## Rapportering av falska positiva resultat till uppströmsleverantören

Det nuvarande filtret är alltför aggressivt — det blockerar "Lorem ipsum" i
`tool_result`-block trots att operatören uppenbarligen inte avsåg att
injicera en prompt. Operatörer som vill att detta åtgärdas vid källan bör
kontakta `agentrouter.org` för att rapportera de falska positiva resultaten.
Blockeringslistan ovan är det empiriska resultatet av tester mot
uppströmstjänsten per 2026-08-03.
