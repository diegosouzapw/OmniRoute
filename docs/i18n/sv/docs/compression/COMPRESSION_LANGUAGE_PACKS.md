Caveman-komprimering kan läsa in språkspecifika regelpaket utöver de inbyggda engelska reglerna.
Detta håller kärnmotorn stabil samtidigt som språkpaket för portugisiska, spanska, tyska, franska, italienska, japanska och
framtida språk kan utvecklas oberoende av varandra.

## Plats

Språkpaketen finns under:

```txt
open-sse/services/compression/rules/<language>/
```

Aktuella medföljande paket (verifierade mot innehållet i katalogen `rules/`):

| Språk                    | Katalog        | Tillgängliga regelkategorier                        |
| ------------------------ | -------------- | --------------------------------------------------- |
| Engelska                 | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spanska                  | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugisiska (Brasilien) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonesiska              | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italienska               | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Tyska                    | `rules/de/`    | `context`, `filler`, `structural`                   |
| Franska                  | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japanska                 | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Anmärkning om likvärdighet:** Paketen `en`, `es`, `pt-BR`, `id` och `it` har alla fem kategorierna. `de`, `fr` och `ja` levereras med tre kategorier. För de saknade kategorierna `dedup` och `ultra` används automatiskt de inbyggda engelska reglerna som reserv. Bidrag för att lägga till `dedup.json` och `ultra.json` i de mindre paketen är välkomna.
>
> Paketet `pt-BR` är baserat på **[Troglodita](https://github.com/leninejunior/troglodita)** av Lenine Júnior – ett komprimeringssystem som utformats från grunden för brasiliansk portugisisk grammatik (minskning av pleonasmer, borttagning av utfyllnadsord på PT-BR och tekniska förkortningar för den brasilianska utvecklargemenskapen).
>
> Den kanoniska kategorilistan och schemat för varje kategori finns i [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema-utkast 2020-12).

## Språkidentifiering

`languageDetector.ts` använder enkla heuristiker för att härleda språket från prompttexten. Det
konfigurerade standardspråket respekteras fortfarande, och identifieringen kan inaktiveras via konfigurationen när exakt
kontroll krävs.

Resultatet från identifieringen används endast för att välja regelpaket. Det ändrar inte leverantörsroutning, val av
språkinställning eller gränssnittsspråk.

## Konfigurationsstruktur

Komprimeringsinställningarna kan innehålla:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` styr standardinställningarna för instrumentpanelen och förhandsgranskningen. `cavemanConfig` är konfigurationen för körningsmotorn
som används när Caveman komprimerar meddelandetext.

## Lägga till ett språkpaket

1. Skapa `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Använd Caveman-regelformatet från `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Håll ersättningarna försiktiga och undvik att ändra kod, identifierare, URL:er eller JSON.
4. Lägg till eller uppdatera tester för språkval och ersättningsbeteende.
5. Exponera nya etiketter för instrumentpanelen/i18n om språket visas i gränssnittets väljare.

## API

Tillgängliga paket kan hämtas med:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Förhandsgranskningsslutpunkten accepterar åsidosättningar av språkkonfigurationen:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Alla 6 språkpaket fick en `SHARED_BOUNDARIES`-klausul i v3.8.0 som tillämpas vid varje
Caveman-intensitet (LITE, FULL, ULTRA). Den instruerar motorn att bevara dessa mönster ordagrant,
oavsett omgivande borttagning av utfyllnad:

| Mönstertyp                        | Exempel                                |
| --------------------------------- | -------------------------------------- |
| Inhägnade kodblock                | ` ```python\n...\n``` `                |
| Infogad kod                       | `` `my_var` ``                         |
| URL:er                            | `https://example.com/path`             |
| Filsökvägar (absoluta + relativa) | `/etc/hosts`, `./src/index.ts`         |
| Felrubriker                       | `Error:`, `TypeError:`, `SyntaxError:` |
| Stackspårningsrader               | `  at functionName (file.ts:12:3)`     |

Dessa mönster anges i `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (tidigare `[]`). Konstanten
finns i `open-sse/services/compression/types.ts`.

### Varför detta är viktigt

Utan SHARED_BOUNDARIES kunde aggressiva Caveman-lägen ta bort innehåll som såg ut som repetitiv
prosa men som i själva verket var ett kodavsnitt, en filsökväg eller en felstack. SHARED_BOUNDARIES fungerar som ett
språkoberoende skyddsnät som tillämpas innan reglerna för utfyllnad körs.

### Anpassa preservePatterns

Ytterligare mönster kan läggas till vid körning via komprimeringsinställningarna:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Anpassade mönster utökar (ersätter inte) de 6 standardmönstren.

## Driftsinformation

- De inbyggda engelska reglerna används fortfarande som reserv när ett språkpaket saknas.
- Ogiltiga inbyggda JSON-paket underkänns vid valideringen så att versionsartefakter inte försämras obemärkt.
- Regelpaket innehåller endast data och ska inte importera kod eller köra godtycklig logik.
- Analyslagret för komprimering registrerar det valda läget och motorn, inte hela prompttexten.
