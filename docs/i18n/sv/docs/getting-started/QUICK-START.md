> **Kort sagt**: Installera → Anslut en kostnadsfri leverantör → Konfigurera din IDE att använda OmniRoute. Klart.

---

## Steg 1: Installera OmniRoute

Välj den metod du föredrar:

### Alternativ A: npm (rekommenderas)

```bash
npm install -g omniroute
```

### Alternativ B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` är den högsta **publicerade** stabila SemVer-versionen. Den följer **inte** git `main`. Fäst `diegosouzapw/omniroute:X.Y.Z` för GitOps. Se [avbildningstaggar/utgivningskanaler](../guides/DOCKER_GUIDE.md#release-channels).

### Alternativ C: Från källkod

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Steg 2: Starta OmniRoute

```bash
omniroute
```

OmniRoute startar på `http://localhost:20128`. Kontrollpanelen öppnas automatiskt.

---

## Steg 3: Anslut en kostnadsfri leverantör

Du kan använda OmniRoute **helt kostnadsfritt** genom att ansluta en kostnadsfri leverantör.

### Alternativ A: Kiro (kostnadsfri Claude — inget kreditkort)

1. Öppna kontrollpanelen på `http://localhost:20128`
2. Gå till **Leverantörer** → **Lägg till leverantör**
3. Välj **Kiro AI**
4. Klicka på **Anslut** (ingen API-nyckel krävs!)
5. Klart! Du har nu kostnadsfri åtkomst till Claude-modeller.

### Alternativ B: OpenCode Free (ingen autentisering)

1. Öppna kontrollpanelen på `http://localhost:20128`
2. Gå till **Leverantörer** → **Lägg till leverantör**
3. Välj **OpenCode Free**
4. Klicka på **Anslut** (ingen API-nyckel krävs!)
5. Klart! Du har nu kostnadsfri åtkomst till flera modeller.

### Alternativ C: Pollinations (ingen nyckel krävs)

1. Öppna kontrollpanelen på `http://localhost:20128`
2. Gå till **Leverantörer** → **Lägg till leverantör**
3. Välj **Pollinations**
4. Klicka på **Anslut** (ingen API-nyckel krävs!)
5. Klart! Du har nu kostnadsfri åtkomst till GPT-5, Claude, Gemini med flera.

---

## Steg 4: Kontrollera att det fungerar

Skapa en ny nyckel under [API-nycklar](http://localhost:20128/dashboard/api-manager). Spara nyckeln eftersom den inte visas igen. Observera att nyckeln är till för verktyg som ska få åtkomst till OmniRoute, inte för åtkomst till externa leverantörer.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Dina anslutna modeller bör visas i listan.

---

## Steg 5: Konfigurera din IDE eller CLI att använda OmniRoute

Ange följande i din IDE eller ditt CLI-verktyg:

```
Bas-URL:   http://localhost:20128/v1
API-nyckel: [kopiera från Kontrollpanelen → Slutpunkter]
Modell:    auto
```

Det var allt! Din IDE använder nu OmniRoute med automatiskt val av leverantör.

### IDE-exempel: VSCode/Continue.dev

1. Installera tillägget [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) i VSCode.
2. Uppdatera `~/.continue/config.yaml` genom att lägga till följande rader:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Välj `OmniRoute - Auto` i chattpanelen för Continue.dev för att skicka förfrågningar till OmniRoute.
4. (Valfritt) Övning för läsaren – låt din IDE uppdatera `config.yaml` med alla andra färdiga konfigurationer 😊

### CLI-exempel: Codex CLI

1. Ange miljövariabeln permanent i operativsystemet.
   För macOS/Linux (lägg till i `~/.bashrc` eller `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

För Windows (Kommandotolken):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Nu startar vi Codex, men konfigurerat för OmniRoute. Kör:

```
omniroute launch-codex --model auto
```

Du kan göra detta manuellt via `codex` och kommandoradsparametrar för att ange slutpunkt och API-nyckel, men med kommandot ovan sköter OmniRoute allt åt dig.

Samma start med ett enda kommando fungerar för andra CLI-verktyg via den generiska startfunktionen – `omniroute run <target>` stöder `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` och `gemini` (se [CLI-integrationer](../guides/CLI-INTEGRATIONS.md)).

3. CLI-verktyget bör nu skicka förfrågningar till OmniRoute.

### Bekräfta att ditt verktyg dirigerar till OmniRoute

Du kan se information om förfrågan genom att klicka på [Övervakning/loggar](http://localhost:20128/dashboard/logs) i det vänstra sidofältet. Genom att klicka vidare kan du se mer information. Du kan även se vilken information som skickas från ditt favoritverktyg. Detta är användbart både i utbildnings- och felsökningssyfte.

## Vanliga frågor

### ”Behöver jag en API-nyckel?”

**Nej!** Du kan använda kostnadsfria leverantörer (Kiro, OpenCode Free, Pollinations) utan någon API-nyckel. Anslut dem bara i kontrollpanelen.

### ”Vad är `auto`?”

`auto` instruerar OmniRoute att automatiskt välja den bästa leverantören för varje förfrågan. Hänsyn tas till hastighet, kostnad, kvalitet och tillgänglighet. Mer information finns i [guiden till Auto-Combo](./AUTO-COMBO-GUIDE.md).

### ”Hur mycket kostar det?”

OmniRoute är **kostnadsfritt och har öppen källkod**. Du betalar endast för de leverantörer du använder. Många leverantörer har kostnadsfria nivåer – se [guiden till kostnadsfria nivåer](./FREE-TIERS-GUIDE.md).

### ”Kan jag använda det med Claude Code/Cursor/Copilot?”

**Ja!** OmniRoute fungerar med alla verktyg som stöder OpenAI-formatet. Ange bara bas-URL:en som `http://localhost:20128/v1`. Specifika konfigurationsanvisningar finns i [guiden till CLI-verktyg](../reference/CLI-TOOLS.md).

### ”Vad händer om en leverantör slutar fungera?”

OmniRoute hoppar automatiskt över leverantörer som inte fungerar och provar nästa. Du behöver inte göra något. Mer information finns i [guiden till Auto-Combo](./AUTO-COMBO-GUIDE.md).
