Komplett guide för att installera och konfigurera OmniRoute på en virtuell maskin (VPS) med en domän som hanteras via Cloudflare.

---

## Förutsättningar

| Komponent  | Minimum                    | Rekommenderat    |
| ---------- | -------------------------- | ---------------- |
| **CPU**    | 1 vCPU                     | 2 vCPU           |
| **RAM**    | 1 GB                       | 2 GB             |
| **Disk**   | 10 GB SSD                  | 25 GB SSD        |
| **OS**     | Ubuntu 22.04 LTS           | Ubuntu 24.04 LTS |
| **Domän**  | Registrerad hos Cloudflare | —                |
| **Docker** | Docker Engine 24+          | Docker 27+       |

**Testade leverantörer**: Akamai (Linode), DigitalOcean, Vultr, Hetzner, AWS Lightsail.

## 1. Konfigurera den virtuella maskinen

### 1.1 Skapa instansen

Hos den VPS-leverantör du föredrar:

- Välj Ubuntu 24.04 LTS
- Välj minimiplanen (1 vCPU / 1 GB RAM)
- Ange ett starkt root-lösenord eller konfigurera en SSH-nyckel
- Notera den **offentliga IP-adressen** (t.ex. `203.0.113.10`)

### 1.2 Anslut via SSH

```bash
ssh root@203.0.113.10
```

### 1.3 Uppdatera systemet

```bash
apt update && apt upgrade -y
```

### 1.4 Installera Docker

```bash
# Installera beroenden
apt install -y ca-certificates curl gnupg

# Lägg till Dockers officiella paketförråd
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $ (. /etc/os-release && echo "$VERSION_CODENAME") stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

### 1.5 Installera nginx

```bash
apt install -y nginx
```

### 1.6 Konfigurera brandväggen (UFW)

```bash
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp    # SSH
ufw allow 80/tcp    # HTTP (omdirigering)
ufw allow 443/tcp   # HTTPS
ufw enable
```

> **Tips**: Begränsa portarna 80 och 443 till enbart Cloudflares IP-adresser för maximal säkerhet. Se avsnittet [Avancerad säkerhet](#advanced-security).

## 2. Installera OmniRoute

### 2.1 Skapa konfigurationskatalogen

```bash
mkdir -p /opt/omniroute
```

### 2.2 Skapa filen med miljövariabler

```bash
cat > /opt/omniroute/.env << 'EOF'
# === Säkerhet ===
JWT_SECRET=CHANGE-TO-A-UNIQUE-64-CHAR-SECRET-KEY
INITIAL_PASSWORD=YourSecurePassword123!
API_KEY_SECRET=REPLACE-WITH-ANOTHER-SECRET-KEY
STORAGE_ENCRYPTION_KEY=REPLACE-WITH-THIRD-SECRET-KEY
STORAGE_ENCRYPTION_KEY_VERSION=v1
MACHINE_ID_SALT=CHANGE-TO-A-UNIQUE-SALT
OMNIROUTE_WS_BRIDGE_SECRET=REPLACE-WITH-WS-BRIDGE-SECRET  # KRÄVS i produktion: används av Codex Responses WS-bryggan

# === App ===
PORT=20128
NODE_ENV=production
HOSTNAME=0.0.0.0
DATA_DIR=/app/data
APP_LOG_TO_FILE=true
AUTH_COOKIE_SECURE=true
REQUIRE_API_KEY=false

# === URL:er (ändra till din domän) ===
# Intern bas-URL mellan servrar för schemalagda jobb/självanrop.
BASE_URL=http://127.0.0.1:20128
# Webbläsarvänd URL som används för OAuth-callbackar, länkar till kontrollpanelen och genererade offentliga URL:er.
NEXT_PUBLIC_BASE_URL=https://llms.seudominio.com
# Valfri explicit åsidosättning av offentligt ursprung för genererade offentliga resurs-URL:er.
# OMNIROUTE_PUBLIC_BASE_URL=https://llms.seudominio.com

# === Molnsynkronisering (valfritt) ===
# CLOUD_URL=https://cloud.omniroute.online
# NEXT_PUBLIC_CLOUD_URL=https://cloud.omniroute.online
EOF
```

> ⚠️ **VIKTIGT**: Generera unika hemliga nycklar! Använd `openssl rand -hex 32` för varje nyckel.

### 2.3 Starta containern

```bash
docker pull diegosouzapw/omniroute:latest

docker run -d \
  --name omniroute \
  --restart unless-stopped \
  --env-file /opt/omniroute/.env \
  -p 20128:20128 \
  -v omniroute-data:/app/data \
  diegosouzapw/omniroute:latest
```

### 2.4 Kontrollera att den körs

```bash
docker ps | grep omniroute
docker logs omniroute --tail 20
```

Följande bör visas: `[DB] SQLite database ready` och `listening on port 20128`.

## 3. Konfigurera nginx (omvänd proxy)

### 3.1 Generera SSL-certifikat (Cloudflare Origin)

I Cloudflare-kontrollpanelen:

1. Gå till **SSL/TLS → Origin Server**
2. Klicka på **Create Certificate**
3. Behåll standardinställningarna (15 år, \*.yourdomain.com)
4. Kopiera **Origin Certificate** och **Private Key**

```bash
mkdir -p /etc/nginx/ssl

# Klistra in certifikatet
nano /etc/nginx/ssl/origin.crt

# Klistra in den privata nyckeln
nano /etc/nginx/ssl/origin.key

chmod 600 /etc/nginx/ssl/origin.key
```

### 3.2 Nginx-konfiguration

```bash
cat > /etc/nginx/sites-available/omniroute << 'NGINX'
# Standardserver — blockerar direktåtkomst via IP
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    listen 443 ssl default_server;
    listen [::]:443 ssl default_server;
    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    server_name _;
    return 444;
}

# OmniRoute — HTTPS
server {
    listen 443 ssl;
    listen [::]:443 ssl;
    server_name llms.yourdomain.com;  # Ändra till din domän

    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    client_max_body_size 100M;

    location / {
        proxy_pass http://127.0.0.1:20128;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket-stöd
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # SSE (Server-Sent Events) — strömmande AI-svar
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }
}

# Omdirigering från HTTP till HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name llms.yourdomain.com;
    return 301 https://$server_name$request_uri;
}
NGINX
```

Se till att tidsgränserna för omvänd proxy-strömning är synkroniserade med OmniRoutes miljövariabler för tidsgränser. Om du höjer
`FETCH_TIMEOUT_MS` / `STREAM_IDLE_TIMEOUT_MS` ska du höja `proxy_read_timeout` / `proxy_send_timeout`
över samma tröskelvärde.

OmniRoute använder `NEXT_PUBLIC_BASE_URL` som det kanoniska webbläsarsynliga ursprunget för OAuth-
återanrop och genererade publika länkar. Autentiserade skrivningar i kontrollpanelen använder förfrågningar med samma ursprung
samt sessionsbunden CSRF-säkerhet, så de kräver inte en statisk publik bas-URL. Ovanstående
`X-Forwarded-*`-huvuden är fortfarande användbara metadata för dirigering, men de ersätter inte
inställningen av den uttryckliga publika URL:en när OAuth eller genererade webbläsarlänkar behöver en sådan. Aktivera endast
`OMNIROUTE_TRUST_PROXY` om OmniRoute inte kan nås direkt av klienter och din proxy
tar bort/återskapar inkommande vidarebefordringshuvuden.

### 3.3 Aktivera och testa

```bash
# Ta bort standardkonfigurationen
rm -f /etc/nginx/sites-enabled/default

# Aktivera OmniRoute
ln -sf /etc/nginx/sites-available/omniroute /etc/nginx/sites-enabled/omniroute

# Testa och ladda om
nginx -t && systemctl reload nginx
```

## 4. Konfigurera Cloudflare DNS

### 4.1 Lägg till DNS-post

I Cloudflare-instrumentpanelen → DNS:

| Typ | Namn   | Innehåll               | Proxy        |
| --- | ------ | ---------------------- | ------------ |
| A   | `llms` | `203.0.113.10` (VM-IP) | ✅ Via proxy |

### 4.2 Konfigurera SSL

Under **SSL/TLS → Översikt**:

- Läge: **Fullständig (strikt)**

Under **SSL/TLS → Edge-certifikat**:

- Använd alltid HTTPS: ✅ På
- Lägsta TLS-version: TLS 1.2
- Automatiska HTTPS-omskrivningar: ✅ På

### 4.3 Testning

```bash
curl -sI https://llms.seudominio.com/health
# Bör returnera HTTP/2 200
```

## 5. Drift och underhåll

### Uppgradera till en ny version

```bash
docker pull diegosouzapw/omniroute:latest
docker stop omniroute && docker rm omniroute
docker run -d --name omniroute --restart unless-stopped \
  --env-file /opt/omniroute/.env \
  -p 20128:20128 \
  -v omniroute-data:/app/data \
  diegosouzapw/omniroute:latest
```

### Visa loggar

```bash
docker logs -f omniroute          # Realtidsström
docker logs omniroute --tail 50   # De senaste 50 raderna
```

### Manuell säkerhetskopiering av databasen

```bash
# Kopiera data från volymen till värden
docker cp omniroute:/app/data ./backup-$(date +%F)

# Eller komprimera hela volymen
docker run --rm -v omniroute-data:/data -v $(pwd):/backup \
  alpine tar czf /backup/omniroute-data-$(date +%F).tar.gz /data
```

### Återställ från en säkerhetskopia

```bash
docker stop omniroute
docker run --rm -v omniroute-data:/data -v $(pwd):/backup \
  alpine sh -c "rm -rf /data/* && tar xzf /backup/omniroute-data-YYYY-MM-DD.tar.gz -C /"
docker start omniroute
```

## 6. Avancerad säkerhet

### Begränsa nginx till Cloudflares IP-adresser

```bash
cat > /etc/nginx/cloudflare-ips.conf << 'CF'
# Cloudflares IPv4-intervall — uppdatera regelbundet
# https://www.cloudflare.com/ips-v4/
set_real_ip_from 173.245.48.0/20;
set_real_ip_from 103.21.244.0/22;
set_real_ip_from 103.22.200.0/22;
set_real_ip_from 103.31.4.0/22;
set_real_ip_from 141.101.64.0/18;
set_real_ip_from 108.162.192.0/18;
set_real_ip_from 190.93.240.0/20;
set_real_ip_from 188.114.96.0/20;
set_real_ip_from 197.234.240.0/22;
set_real_ip_from 198.41.128.0/17;
set_real_ip_from 162.158.0.0/15;
set_real_ip_from 104.16.0.0/13;
set_real_ip_from 104.24.0.0/14;
set_real_ip_from 172.64.0.0/13;
set_real_ip_from 131.0.72.0/22;
real_ip_header CF-Connecting-IP;
CF
```

Lägg till följande i `nginx.conf` inuti blocket `http {}`:

```nginx
include /etc/nginx/cloudflare-ips.conf;
```

### Installera fail2ban

```bash
apt install -y fail2ban
systemctl enable fail2ban
systemctl start fail2ban

# Kontrollera status
fail2ban-client status sshd
```

### Blockera direktåtkomst till Docker-porten

```bash
# Förhindra direkt extern åtkomst till port 20128
iptables -I DOCKER-USER -p tcp --dport 20128 -j DROP
iptables -I DOCKER-USER -i lo -p tcp --dport 20128 -j ACCEPT

# Spara reglerna permanent
apt install -y iptables-persistent
netfilter-persistent save
```

## Optimering för lite minne/små VPS-instanser

För distributioner på små VPS-instanser (1 GB RAM eller mindre):

- **Inaktivera bakgrundstjänster** — ange `OMNIROUTE_DISABLE_BACKGROUND_SERVICES=1` för att hoppa över schemaläggaren, MCP-servern och periodiska underhållsuppgifter. Se `docs/reference/ENVIRONMENT.md`.
- **Använd SQLite WAL-läge** — aktiverat som standard och minskar den maximala minnesanvändningen vid samtidiga läsningar.
- **Begränsa V8-heapen** — ange `OMNIROUTE_MEMORY_MB` (t.ex. `512`) så att exekveringsmiljön inte kalibrerar en gräns som är större än den virtuella maskinen. Se `docs/reference/ENVIRONMENT.md`.
- **Antagningskontrollen för resurskrävande förfrågningar skalas automatiskt med heapgränsen** -- när `OMNIROUTE_MEMORY_MB` har angetts enligt ovan härleds bytebudgeten för inläsning (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) från samma gräns. En minnesbegränsad virtuell maskin får därför automatiskt en mindre budget för samtidiga förfrågningar utan ytterligare finjustering. Överskjutande förfrågningar får ett `503`-svar som kan försökas igen, med `Retry-After`, i stället för att konkurrera om minnet. Ange endast den äldre antalsgränsen för förfrågningar, `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`, om du behöver en absolut övre gräns utöver detta.
- **Undvik `next build` på VPS-instansen** — bygg lokalt och distribuera det fristående resultatet (`.next/standalone/`).
- **Övervaka med `top` / `free -m`** — OmniRoute använder vanligtvis 200–400 MB RSS i viloläge på en virtuell maskin med 1 GB minne.
