> **Fonte autorevole:** `src/lib/agentSkills/` (catalogo, generatore, parser) + directory `skills/` (file SKILL.md)
> **Ultimo aggiornamento:** 2026-08-02 — v3.8.50

Le Agent Skills sono file SKILL.md strutturati che insegnano agli agenti esterni, ai client MCP e agli orchestratori A2A come utilizzare l'API REST e la CLI di OmniRoute. A differenza delle [Omni Skills](./SKILLS.md) (che sono definizioni di strumenti LLM eseguite all'interno di OmniRoute), le Agent Skills costituiscono un _catalogo di documentazione_: markdown statico che può essere inserito direttamente nel contesto dell'agente.

---

## Panoramica

Il catalogo contiene **45 Agent Skills** (23 per l'API REST + 21 per la CLI + 1 flusso di lavoro di configurazione). Ogni skill dispone di:

- Un **ID canonico** (`omni-auth`, `cli-serve`, ecc.)
- Un file **SKILL.md** in `skills/{id}/SKILL.md` con frontmatter YAML (`name`, `description`) + un corpo markdown dettagliato
- **Endpoint REST** (skill API) o **sottocomandi CLI** (skill CLI) derivati dalla specifica OpenAPI e dal registro CLI
- Un **URL raw di GitHub** per il recupero in tempo reale: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

```

  [id]/route.ts                        — GET /api/agent-skills/{id}
```

## Formato SKILL.md

```markdown
---
name: omni-providers
description: "Gestisci le connessioni ai provider: aggiungi, verifica, ruota e rimuovi le credenziali."
---

<!-- generato da src/lib/agentSkills/generator.ts; le modifiche manuali verranno sovrascritte -->

## Panoramica

...

## Autenticazione

...

## Endpoint

...

<!-- skill:custom-start -->

## Sezione personalizzata (mantenuta durante la rigenerazione)

...

<!-- skill:custom-end -->
```

Durante la rigenerazione, il generatore mantiene il contenuto compreso tra `<!-- skill:custom-start -->` e `<!-- skill:custom-end -->`. Dieci skill dispongono di blocchi personalizzati curati:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Individuazione delle API REST

| Endpoint                     | Metodo | Descrizione                                                               | Autenticazione |
| :--------------------------- | :----- | :------------------------------------------------------------------------ | :------------- |
| `/api/agent-skills`          | GET    | Elenca il catalogo (`?category=api\|cli\|config&area=<area>` facoltativo) | nessuna        |
| `/api/agent-skills/{id}`     | GET    | Ottiene i metadati di una singola skill                                   | nessuna        |
| `/api/agent-skills/{id}/raw` | GET    | Recupera SKILL.md come `text/markdown`                                    | nessuna        |
| `/api/agent-skills/coverage` | GET    | Statistiche di copertura (quanti file SKILL.md esistono)                  | nessuna        |
| `/api/agent-skills/generate` | POST   | Avvia il generatore (dryRun/prune/onlyIds)                                | gestione       |

Esempio — elencare tutte le skill API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Esempio — recuperare un singolo SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Individuazione MCP

Tre strumenti MCP sono registrati nell'ambito `read:catalog`:

| Strumento                         | Descrizione                                              |
| :-------------------------------- | :------------------------------------------------------- |
| `omniroute_agent_skills_list`     | Elenca le skill (filtri `category` / `area` facoltativi) |
| `omniroute_agent_skills_get`      | Ottiene i metadati + SKILL.md di una skill tramite `id`  |
| `omniroute_agent_skills_coverage` | Statistiche di copertura (API/CLI presenti/totali)       |

Consultare [MCP-SERVER.md](./MCP-SERVER.md) per la configurazione degli ambiti e l'autenticazione.

## Individuazione A2A

La skill A2A `list-capabilities` restituisce il catalogo completo di 45 skill come artefatto sotto forma di tabella markdown. Gli orchestratori esterni possono richiamarla tramite:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "Elenca tutte le funzionalità" }]
  }
}
```

Consultare [A2A-SERVER.md](./A2A-SERVER.md) per i dettagli del protocollo.

## Come gli agenti esterni utilizzano le skill

### 1. Individuazione tramite REST

```bash
# Ottieni il catalogo completo
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Ottieni SKILL.md per l'iniezione del contesto
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Individuazione tramite MCP

```typescript
// In un client MCP Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → array di AgentSkill con rawUrl per ciascuna
```

### 3. Individuazione tramite A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table è una tabella markdown con tutti i 45 ID delle skill e le colonne rawUrl
```

### 4. Recupero diretto dei dati grezzi da GitHub (nessun server richiesto)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generatore

Il generatore legge il catalogo curato, la specifica OpenAPI e il registro CLI, quindi scrive `skills/{id}/SKILL.md` per ogni voce:

```bash
# Anteprima (esecuzione di prova, nessuna scrittura)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Rigenerazione completa
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Rigenera ID specifici
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

La risposta del generatore è un `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
