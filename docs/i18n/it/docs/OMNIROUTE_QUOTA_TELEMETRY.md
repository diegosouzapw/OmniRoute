OmniRoute separa la telemetria delle quote del provider dalla contabilizzazione di Ghostlight.

## Stati veritieri

- `healthy` indica che una fonte ha segnalato una capacità residua utilizzabile.
- `approaching_limit` indica che una fonte ha segnalato una capacità residua pari o inferiore alla soglia configurata.
- `exhausted` viene emesso solo quando una fonte segnala capacità pari a zero o un utilizzo che ha raggiunto il limite.
- `unavailable` indica che una fonte supportata non è riuscita a restituire dati.
- `unknown` indica che non esiste alcuna fonte supportata o che non è noto alcun limite del provider.

Lo stato Unknown non equivale a exhausted e non disabilita un provider.

Le fonti sono preferite nel seguente ordine: API ufficiale del provider, API di utilizzo autenticata, header di risposta mappati esplicitamente, configurazione dell’amministratore, stime locali, unknown. Le stime locali non vengono mai presentate come dati di fatturazione del provider.

Gli header di risposta vengono analizzati esclusivamente tramite una mappatura esplicita del provider. Non si presume che i nomi generici degli header siano validi globalmente.
