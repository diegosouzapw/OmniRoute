L'allocazione non è la quota del provider.

I pool di quota definiscono quali chiavi API possono utilizzare un pool del provider e come si applicano i criteri rigidi, flessibili o di picco. La quota del provider è la capacità esterna comunicata da un provider o da una fonte configurata esplicitamente. I budget interni di Ghostlight sono limiti di governance definiti dall'amministratore.

L'operazione `ensurePool` è idempotente: un pool identico rimane invariato, un'allocazione modificata viene aggiornata e un pool mancante viene creato. È pensata per l'automazione e per i chiamanti API con limiti definiti.

L'endpoint di stato in sola lettura è `GET /api/omniroute/status`. Il comando di verifica è `npm run omniroute:verify`; non effettua alcuna richiesta reale al modello.
