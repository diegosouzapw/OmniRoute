## Quando scegliere OmniRoute

- Utilizzi il self-hosting e desideri la **massima copertura di provider** (329 provider, 155 voci del catalogo gratuite/senza autenticazione)
- Hai bisogno di un **server MCP integrato** (strumenti LLM, memoria e competenze esposti come strumenti)
- Hai bisogno del **protocollo A2A** per flussi di lavoro tra agent
- Vuoi l'**occultamento del fingerprint** (JA3/JA4) per evitare il rilevamento da parte dei CAPTCHA upstream
- Hai bisogno di **funzionalità enterprise** (guardrail, valutazioni, audit trail) senza i costi di un servizio SaaS

## Quando scegliere LiteLLM

- Lavori **principalmente con Python** e hai bisogno di una stretta integrazione con `litellm.completion()`
- Hai bisogno di **procedure mature per il deployment in produzione** (k8s, chart Helm)
- Il tuo team utilizza già microservizi Python

## Quando scegliere OpenRouter (SaaS)

- Non vuoi occuparti del self-hosting
- Accetti di pagare per token con la maggiorazione SaaS
- Hai bisogno di un **unico metodo di pagamento** per tutti i provider

## Quando scegliere Portkey

- Hai bisogno di uno **SLA commerciale** con garanzie di disponibilità
- Preferisci una **dashboard gestita** senza oneri operativi
- Hai bisogno di **funzionalità di conformità enterprise** pronte all'uso
