Dashboard → Providers → **Importa da file** crea connessioni tramite chiave API da un elenco CSV o JSON. Ogni riga può fare riferimento a un provider diverso. Gli errori parziali sono previsti: le righe valide vengono comunque importate quando altre non riescono e la finestra modale indica il motivo per cui le righe non riuscite sono state rifiutate.

Questa importazione **non** crea nuovi nodi endpoint compatibili con OpenAI/Anthropic. Creali prima (Dashboard → Providers → Aggiungi compatibile con OpenAI oppure `omniroute nodes add`), quindi importa le righe la cui colonna `provider` corrisponde all'id del nodo. Un valore `baseUrl` specifico per riga può comunque sovrascrivere l'URL del nodo.

## CSV (posizionale)

I nomi delle colonne sono puramente descrittivi. Il parser suddivide ogni riga e ne destruttura i valori in base all'indice:

| Indice | Campo      | Obbligatorio | Note                                                                                                                                        |
| ------ | ---------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 0      | `provider` | sì           | Id di un provider gestito esistente (`openai`, `anthropic`, …) **oppure** id di un **nodo** compatibile con OpenAI/Anthropic già registrato |
| 1      | `name`     | sì           | Nome visualizzato della connessione                                                                                                         |
| 2      | `apiKey`   | sì           | Chiave API                                                                                                                                  |
| 3      | `baseUrl`  | no           | URL sostitutivo specifico per riga                                                                                                          |
| 4      | `priority` | no           | Numero intero da 1 a 100                                                                                                                    |

Una prima riga la cui prima colonna contiene la parola letterale `provider` (senza distinzione tra maiuscole e minuscole) viene ignorata come intestazione. Le righe vuote e i commenti che iniziano con `#` vengono ignorati.

Scarica un file iniziale dalla finestra modale di importazione (**Scarica modello CSV**). Esempio:

```csv
# Importazione dei provider OmniRoute (colonne posizionali)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Un id inventato come `openai-compatible-chat-001` non è un nodo. Per tale riga, l'API restituisce `Unknown or unsupported provider`; la finestra modale lo mostra accanto al nome della riga.

## JSON

Un array JSON di oggetti con gli stessi campi (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). A differenza del CSV, le chiavi JSON hanno un nome.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
