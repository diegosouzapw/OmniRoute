Questa guida illustra come rimuovere OmniRoute dal sistema in modo pulito.

---

## Disinstallazione rapida (v3.6.2+)

OmniRoute fornisce due script integrati per una rimozione pulita:

### Conservare i dati

```bash
npm run uninstall
```

Questo comando rimuove l'applicazione OmniRoute ma **conserva** il database, le configurazioni, le chiavi API e le impostazioni dei provider in `~/.omniroute/`. Usalo se prevedi di reinstallare l'applicazione in seguito e desideri mantenere la configurazione.

### Rimozione completa

```bash
npm run uninstall:full
```

Questo comando rimuove l'applicazione **e cancella definitivamente** tutti i dati:

- Database (`storage.sqlite`)
- Configurazioni dei provider e chiavi API
- File di backup
- File di log
- Tutti i file nella directory `~/.omniroute/`

> ⚠️ **Avviso:** `npm run uninstall:full` è irreversibile. Tutte le connessioni ai provider, le combinazioni, le chiavi API e la cronologia di utilizzo verranno eliminate definitivamente.

## Disinstallazione manuale

### Installazione globale con NPM

```bash
# Rimuove il pacchetto globale
npm uninstall -g omniroute

# (Facoltativo) Rimuove la directory dei dati
rm -rf ~/.omniroute
```

### Installazione globale con pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Arresta e rimuove il container
docker stop omniroute
docker rm omniroute

# Rimuove il volume (elimina tutti i dati)
docker volume rm omniroute-data

# (Facoltativo) Rimuove l'immagine
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Arresta e rimuove i container
docker compose down

# Rimuove anche i volumi (elimina tutti i dati)
docker compose down -v
```

### Applicazione desktop Electron

**Windows:**

- Apri `Impostazioni → App → OmniRoute → Disinstalla`
- In alternativa, esegui il programma di disinstallazione NSIS dalla directory di installazione

**macOS:**

- Trascina `OmniRoute.app` da `/Applications` al Cestino
- Rimuovi i dati: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Rimuovi il file AppImage
- Rimuovi i dati: `rm -rf ~/.omniroute`

### Installazione dal codice sorgente (git clone)

```bash
# Rimuove la directory clonata
rm -rf /path/to/omniroute

# (Facoltativo) Rimuove la directory dei dati
rm -rf ~/.omniroute
```

## Directory dei dati

Per impostazione predefinita, OmniRoute archivia i dati nelle seguenti posizioni:

| Piattaforma    | Percorso predefinito          | Variabile di override                  |
| -------------- | ----------------------------- | -------------------------------------- |
| Linux          | `~/.omniroute/`               | Variabile d'ambiente `DATA_DIR`        |
| macOS          | `~/.omniroute/`               | Variabile d'ambiente `DATA_DIR`        |
| Windows        | `%APPDATA%/omniroute/`        | Variabile d'ambiente `DATA_DIR`        |
| Docker         | `/app/data/` (volume montato) | Variabile d'ambiente `DATA_DIR`        |
| Conforme a XDG | `$XDG_CONFIG_HOME/omniroute/` | Variabile d'ambiente `XDG_CONFIG_HOME` |

### File nella directory dei dati

| File/Directory       | Descrizione                                                        |
| -------------------- | ------------------------------------------------------------------ |
| `storage.sqlite`     | Database principale (provider, combinazioni, impostazioni, chiavi) |
| `storage.sqlite-wal` | Log write-ahead di SQLite (temporaneo)                             |
| `storage.sqlite-shm` | Memoria condivisa di SQLite (temporanea)                           |
| `call_logs/`         | Archivi dei payload delle richieste                                |
| `backups/`           | Backup automatici del database                                     |
| `log.txt`            | Log delle richieste legacy (facoltativo)                           |

## Verificare la rimozione completa

Dopo la disinstallazione, verificare che non siano rimasti file:

```bash
# Verifica la presenza del pacchetto npm globale
npm list -g omniroute 2>/dev/null

# Verifica la presenza della directory dei dati
ls -la ~/.omniroute/ 2>/dev/null

# Verifica la presenza di processi in esecuzione
pgrep -f omniroute
```

Se un processo è ancora in esecuzione, arrestarlo:

```bash
pkill -f omniroute
```
