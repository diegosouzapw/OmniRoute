OmniRoute include un insieme curato di proxy gratuiti nella tabella `free_proxies`,
sincronizzati da provider esterni (1proxy, proxifly, iplocate, webshare). La
dashboard li mostra in **Impostazioni → Proxy gratuiti**. Questo documento
descrive il filtraggio, l'ordinamento, il conteggio e la segnalazione degli errori
di sincronizzazione lato server esposti dalla route dell'elenco.

## Route dell'elenco — `GET /api/settings/free-proxies`

Restituisce un sottoinsieme filtrato, ordinato e paginato, insieme al conteggio
totale. Il filtraggio e il conteggio avvengono in SQL, così l'interfaccia utente
può mostrare il totale effettivo (ad es. `Totale: 0`) senza caricare ogni riga
in memoria.

### Parametri di query

| Param             | Tipo                               | Predefinito | Significato                                                                                                                |
| ----------------- | ---------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`        | `LIKE` con distinzione tra maiuscole e minuscole sulla colonna host (e source).                                            |
| `protocol`        | string                             | `""`        | Filtro `type`: `http` / `https` / `socks4` / `socks5`. Vuoto = tutti.                                                      |
| `country`         | string                             | `""`        | Filtro `countryCode` (ISO-2). Vuoto = tutti.                                                                               |
| `minQuality`      | number                             | `0`         | Solo righe con `qualityScore >= minQuality`. `0` = nessuna soglia minima.                                                  |
| `disabledSources` | string                             | `""`        | ID delle sorgenti da escludere, separati da virgole (ad es. `proxifly,webshare`).                                          |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`   | `quality` = punteggio decrescente; `latency` = latenza crescente (null alla fine); `recent` = `lastValidated` decrescente. |
| `offset`          | number                             | `0`         | Inizio della paginazione.                                                                                                  |
| `limit`           | number                             | `50`        | Dimensione della pagina (limitata lato server).                                                                            |

### Risposta

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 dal servizio upstream"],
    "webshare": ["timeout di rete"]
  }
}
```

`total` riflette il totale filtrato **prima** della paginazione, così
l'interfaccia utente può visualizzare `Totale: N` e `hasMore` in modo
indipendente. `syncErrors` utilizza l'ID della sorgente come chiave e viene
popolato solo per le sorgenti la cui ultima sincronizzazione non è riuscita:
un risultato `Totale: 0` non è mai privo di spiegazioni.

## Aggiunta al pool — `POST /api/settings/free-proxies/[id]/add-to-pool`

Promuove un proxy gratuito nel pool gestito `proxy_registry`. Prima convalida
il servizio upstream; in caso di esito positivo, restituisce l'ID del nuovo
proxy del pool e la latenza misurata.

## Sincronizzazione — `POST /api/settings/free-proxies/sync`

Recupera nuovamente tutte le sorgenti abilitate (o il sottoinsieme specificato
in `{ "sources": [...] }`). Ogni sorgente viene sincronizzata in modo
indipendente; una sorgente non riuscita viene registrata in `syncErrors`, mentre
le altre vengono comunque completate, quindi le sincronizzazioni parziali non
eliminano mai i dati validi precedenti.

## Statistiche — `GET /api/settings/free-proxies/stats`

Restituisce l'aggregato `total / inPool / avgQuality / bySource / lastSyncAt`
senza il payload delle righe, utilizzato dai widget dell'intestazione della
dashboard.
