**OmniCopilot** นำทุกโมเดลที่ OmniRoute ของคุณให้บริการมาไว้ในตัวเลือกโมเดลแบบ _เนทีฟ_ ของ GitHub Copilot Chat
โดยไม่ต้องมีแถบด้านข้างที่สองหรือ UI แชตแยกต่างหาก — โหมดเอเจนต์ของ Copilot, การเรียกใช้เครื่องมือ,
เซิร์ฟเวอร์ MCP และคำสั่งแบบกำหนดเองทั้งหมดยังคงทำงานได้ เพียงแต่ทำงานบนโมเดลที่คุณเลือก

> โดยไม่ต้องลงชื่อเข้าใช้ GitHub และไม่ต้องมีแผน Copilot ใดๆ ส่วนการเติมโค้ดแบบอินไลน์และ
> ฟีเจอร์ที่ใช้ embeddings ยังคงอยู่นอก provider API และยังต้องใช้ Copilot

## การตั้งค่า

1. **เรียกใช้ OmniRoute** — `npm install -g omniroute && omniroute` (แดชบอร์ดอยู่ที่ `http://localhost:20128`)
2. **ติดตั้งส่วนขยาย** — ค้นหา "OmniRoute" ในมุมมอง Extensions
3. **เลือกโมเดล** — Copilot Chat → ตัวเลือกโมเดล → **Manage Models…** → **OmniRoute** จากนั้นทำเครื่องหมาย
   โมเดลที่คุณต้องการ

ไม่ต้องกำหนดค่าใดๆ เมื่อ OmniRoute ทำงานบนพอร์ตเริ่มต้น สำหรับอินสแตนซ์ระยะไกล ให้เปิด
**ไอคอน OmniRoute ใน Activity Bar** (หรือเรียกใช้ `OmniRoute: Manage Connection`) แล้วตั้งค่า:

- **URL ของเซิร์ฟเวอร์** — รากของเซิร์ฟเวอร์ เช่น `http://192.168.0.15:20128` ส่วนขยายจะเติมส่วนต่อท้าย `/v1`
  ให้เอง อย่ารวมส่วนนี้ไว้
- **คีย์ API** — ใช้เฉพาะเมื่อเซิร์ฟเวอร์ตั้งค่า `REQUIRE_API_KEY` โดยจะจัดเก็บในพวงกุญแจของระบบปฏิบัติการผ่าน VS
  Code SecretStorage และจะไม่เก็บไว้ใน `settings.json`

## สิ่งที่จะแสดงในตัวเลือก

ส่วนขยายจะไม่แสดงเพย์โหลดดิบจาก `GET /v1/models` — แต่จะปรับโครงสร้างข้อมูล และจำนวนที่คุณ
เห็นจะน้อยกว่าขนาดแค็ตตาล็อกด้วยเหตุผลสองประการที่ตั้งใจไว้

### ขอหนึ่ง id ต่อหนึ่งโมเดล

ค่าเริ่มต้นของ `MODELS_CATALOG_PREFIX_MODE` คือ **`dual`** ซึ่งประกาศแต่ละโมเดลสองครั้ง — ครั้งหนึ่ง
ภายใต้คำนำหน้าแบบนามแฝง และอีกครั้งภายใต้คำนำหน้าแบบมาตรฐานของผู้ให้บริการ — เพื่อให้การกำหนดค่าไคลเอนต์
รุ่นเก่ายังคงจับคู่ได้ทั้งสองรูปแบบ:

```
cc/claude-sonnet-4-6        ← คำนำหน้าแบบนามแฝง
claude/claude-sonnet-4-6    ← คำนำหน้าแบบมาตรฐาน โมเดลเดียวกัน
```

ส่วนขยายจะส่งคำขอ **`GET /v1/models?prefix=alias`** เพื่อให้ได้รับหนึ่ง id ต่อหนึ่งโมเดล โดยไม่
เปลี่ยนการตั้งค่าทั่วทั้งเซิร์ฟเวอร์สำหรับไคลเอนต์อื่นๆ ของคุณ ในอินสแตนซ์อ้างอิง วิธีนี้ลดจำนวน
**2345 รายการเหลือ 1396 รายการ — รายการซ้ำ 949 รายการ โดยไม่มีโมเดลสูญหายเลย**

หากคุณต้องการแก้ไขที่ระดับเซิร์ฟเวอร์สำหรับไคลเอนต์ _ทุกตัว_ ให้ตั้งค่า feature flag
`MODELS_CATALOG_PREFIX_MODE` เป็น `alias` ในแดชบอร์ด ดูพารามิเตอร์คิวรีและตารางของแต่ละโหมดได้ที่
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix)

### ซ่อนโมเดลที่ใช้แชตไม่ได้

แค็ตตาล็อกยังแสดงโมเดลสำหรับรูปภาพ วิดีโอ เสียง การจัดอันดับใหม่ embeddings และการกลั่นกรองเนื้อหา โมเดลเหล่านี้
จะถูกปฏิเสธเมื่อส่งคำขอแชตอยู่แล้ว:

```
HTTP 400 — โมเดล '<id>' เป็นโมเดลสร้างรูปภาพและไม่สามารถใช้กับ
/v1/chat/completions ได้ ให้ใช้ POST /v1/images/generations แทน
```

ดังนั้นโมเดลเหล่านี้จึงถูกกรองออกตามฟิลด์ `type` ก่อนจะไปถึงตัวเลือก **โมเดล Responses-API
จะยังคงอยู่** — รายการ Codex / GPT-5.x ทุกรายการประกาศ `supported_endpoints: ["responses"]`
และ OmniRoute จะแปลรายการเหล่านั้นสำหรับ `/v1/chat/completions` จึงสามารถใช้งานได้อย่างสมบูรณ์

### ผู้ให้บริการที่คุณไม่เคยกำหนดค่า

แค็ตตาล็อกแสดงโมเดลจากผู้ให้บริการที่มี **การเชื่อมต่อที่ใช้งานอยู่** รวมถึงผู้ให้บริการแบบ **noAuth**
ทุกตัว — ซึ่งเป็นผู้ให้บริการที่ไม่ต้องใช้คีย์และประกอบกันเป็นส่วนใหญ่ของระดับฟรี ลักษณะนี้เป็นไปโดยตั้งใจ หากต้องการซ่อน
ผู้ให้บริการเหล่านี้ ให้เพิ่มลงใน `blockedProviders` ในการตั้งค่าแดชบอร์ด โดยไม่ต้องเปลี่ยนแปลงสิ่งใดใน
ส่วนขยาย

## แดชบอร์ดภายในแท็บ VS Code

`omnicopilot.dashboardOpen: "editor"` แสดงแดชบอร์ด OmniRoute ในแท็บตัวแก้ไขผ่าน
Simple Browser แทนเบราว์เซอร์ภายนอก การฝังต้อง **เปิดใช้งานโดยสมัครใจบนเซิร์ฟเวอร์** ผ่าน
`DASHBOARD_ALLOW_EMBED=vscode` ซึ่งจะให้บริการหน้า HTML พร้อม
`frame-ancestors 'self' vscode-webview:` แทนค่าเริ่มต้น `frame-ancestors 'none'` +
`X-Frame-Options: DENY` ส่วน API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) จะยังคงใช้
ส่วนหัวที่เข้มงวดไม่ว่าจะตั้งค่าแบบใดก็ตาม

> ⚠️ **นี่เป็นแฟล็กในเวลาบิลด์ ไม่ใช่ในเวลารันไทม์** Next.js จะคอมไพล์ `headers()` ลงในรายการเส้นทาง
> ดังนั้น `next.config.mjs` จึงอ่านตัวแปรในขณะที่กำลังบิลด์บันเดิล
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`)
> การส่งออกตัวแปรนี้ก่อนเริ่มเซิร์ฟเวอร์ที่บิลด์ไว้แล้วจะไม่ทำให้เกิดการเปลี่ยนแปลงใด ๆ — ส่วนหัวถูกฝังไว้แล้ว

```bash
# ต้องกำหนดตัวแปรนี้ในคำสั่ง BUILD
DASHBOARD_ALLOW_EMBED=vscode npm run build        # หรือ npm run build:release
npm start
```

| วิธีที่คุณติดตั้ง          | สามารถเปิดใช้งานการฝังได้หรือไม่?                                                                                                               |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| จากซอร์สโค้ด               | ✅ กำหนดตัวแปรในคำสั่งบิลด์ดังตัวอย่างข้างต้น                                                                                                   |
| `npm install -g omniroute` | ❌ แพ็กเกจที่เผยแพร่มาพร้อมบันเดิลที่บิลด์ไว้ล่วงหน้า — ให้บิลด์จากซอร์สโค้ดแทน                                                                 |
| อิมเมจ Docker              | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — อิมเมจที่บิลด์ไว้ล่วงหน้าบน Docker Hub ไม่ได้เปิดใช้งานการฝัง |

หากไม่ได้ใช้บิลด์ที่เปิดใช้งานการฝัง หน้าดังกล่าวจะปฏิเสธการแสดงผลในเฟรม ส่วนขยายจะตรวจพบสิ่งนี้จาก
ส่วนหัวการตอบกลับและย้อนกลับไปใช้เบราว์เซอร์ภายนอก — ไม่มีสิ่งใดเสียหาย และจะแจ้งให้ทราบหนึ่งครั้ง
ดู [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) และ issue
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273)

## การกำหนดค่าเครื่องมืออื่น ๆ จากภายใน VS Code

**`OmniRoute: Configure Coding CLI`** ใช้ `omniroute` CLI เพื่อเขียนโปรไฟล์ที่พร้อมใช้งาน
สำหรับ Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo และ Roo — ซึ่งเป็นการกำหนดค่าเดียวกับที่อธิบายไว้ใน
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md) คีย์ API จะถูกส่งให้ CLI ผ่านตัวแปรสภาพแวดล้อม
`OMNIROUTE_API_KEY` และจะไม่ถูกส่งผ่านบรรทัดคำสั่ง

| แดชบอร์ดเปิดในเบราว์เซอร์แม้ใช้โหมด `editor`         | เซิร์ฟเวอร์ไม่ได้ถูก **บิลด์** ด้วย `DASHBOARD_ALLOW_EMBED=vscode` (ดูด้านบน) — การกำหนดค่านี้ตอนเริ่มระบบบนการติดตั้งที่บิลด์ไว้ล่วงหน้าไม่มีผล การย้อนกลับไปใช้เบราว์เซอร์เป็นพฤติกรรมที่ตั้งใจไว้                                      |
| รายการโมเดลไม่เป็นปัจจุบันหลังจากเปลี่ยนผู้ให้บริการ | `OmniRoute: Refresh Models` หรือลิงก์ ↻ ในแผง                                                                                                                                                                                             |
