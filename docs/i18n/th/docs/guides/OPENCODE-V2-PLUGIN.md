`@omniroute/opencode-plugin-v2` นำแค็ตตาล็อก OmniRoute ทั้งหมดของคุณ — ทั้งโมเดล คอมโบ และ
คอมโบอัตโนมัติ — เข้าสู่ตัวเลือกโมเดลของ OpenCode v2 พร้อมชื่อที่แสดง ราคา และโควตา
ระดับฟรี

แพ็กเกจนี้แยกจาก `@omniroute/opencode-plugin` เนื่องจาก OpenCode v1 และ v2 โหลด
ปลั๊กอินผ่านสัญญาคนละแบบ เลือกแพ็กเกจให้ตรงกับเวอร์ชันหลักของ OpenCode ที่คุณใช้ โดยทั้งสองแพ็กเกจ
ไม่ได้ใช้สิ่งใดร่วมกัน ดังนั้นการอัปเกรดแพ็กเกจหนึ่งจะไม่บังคับให้อีกแพ็กเกจต้องอัปเกรดตาม

## ข้อกำหนด

- OpenCode v2
- เกตเวย์ OmniRoute ที่เข้าถึงได้ (`http://localhost:20128` โดยค่าเริ่มต้น)
- Node.js 22 หรือ 24

## การติดตั้ง

เพิ่มปลั๊กอินลงใน `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

จากนั้นโมเดลจะปรากฏในรูปแบบ `omniroute/<provider>/<model>` โดย `providerId` จะกำหนดคำนำหน้านี้และ
รหัสของการผสานรวมที่ OpenCode ใช้จัดเก็บข้อมูลประจำตัว

## ข้อมูลประจำตัว

ปลั๊กอินจะค้นหาคีย์เกตเวย์จากสามตำแหน่งตามลำดับดังนี้:

1. **ข้อมูลประจำตัวที่คุณเชื่อมต่อใน OpenCode** ปลั๊กอินจะลงทะเบียนการผสานรวม เพื่อให้
   ขั้นตอนการยืนยันตัวตนของ OpenCode สามารถจัดเก็บคีย์ได้ โดยจะไม่มีข้อมูลใดถูกบันทึกลงใน `opencode.json` — แนะนำให้ใช้วิธีนี้
2. `apiKey` ในตัวเลือกของปลั๊กอิน สำหรับการเขียนทับค่ารายโปรเจกต์ วิธีนี้จะบันทึกคีย์ไว้ในไฟล์ที่คุณ
   อาจกำลังคอมมิตอยู่
3. `OMNIROUTE_API_KEY` ในสภาพแวดล้อม

หากไม่มีทั้งสามรายการ แค็ตตาล็อกจะว่างเปล่า และปลั๊กอินจะแจ้งให้ทราบหนึ่งครั้งเมื่อเริ่มต้นระบบ แทนที่จะ
ปล่อยให้ตัวเลือกโมเดลว่างเปล่าโดยไม่มีคำอธิบาย

### โทเค็นการจัดการเป็นคีย์คนละตัว

คอมโบ สถานะของผู้ให้บริการ และข้อมูลเสริม (ชื่อที่แสดง ราคา และโควตาระดับฟรี) มาจาก
เอนด์พอยต์ `/api/*` ของเกตเวย์ ซึ่งในการติดตั้งใช้งานส่วนใหญ่จะป้องกันด้วยโทเค็น **การจัดการ**
แทนที่จะเป็นคีย์สำหรับการอนุมาน:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<โทเค็นการอ่านสำหรับการจัดการ>"
}
```

หากไม่ได้กำหนดค่า `managementReadToken` ระบบจะใช้ `apiKey` เป็นค่าทดแทน เมื่อเกตเวย์ปฏิเสธค่าทดแทนดังกล่าว
แค็ตตาล็อกจะยังคงเผยแพร่ได้ แต่จะใช้รหัสดิบของโมเดลแทนชื่อที่แสดง ไม่มีการขจัดนามแฝงมาตรฐานที่ซ้ำกัน
ไม่มีข้อมูลราคา และไม่มีคอมโบ เมื่อเกิดกรณีนี้ ปลั๊กอินจะแจ้งเตือนหนึ่งครั้งต่อเอนด์พอยต์
โดยระบุชื่อเอนด์พอยต์และข้อมูลที่หายไป เพื่อให้ทราบสาเหตุของตัวเลือกโมเดลที่ทำงานได้ไม่เต็มรูปแบบเสมอ

## ตัวเลือก

| คีย์                             | ค่าเริ่มต้น                                                | หมายเหตุ                                                                                                                    |
| -------------------------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                              | รหัสผู้ให้บริการ รหัสการผสานรวม และคำนำหน้าที่โมเดลจะแสดงอยู่ภายใต้ค่านี้                                                   |
| `baseURL`                        | จำเป็น                                                     | รากของเกตเวย์ รองรับเฉพาะ `http(s)` โดยจะเพิ่มส่วนต่อท้าย `/v1` เมื่อจำเป็น                                                 |
| `apiKey`                         | ข้อมูลประจำตัวที่เชื่อมต่อ แล้วตามด้วย `OMNIROUTE_API_KEY` | คีย์แชตสำหรับ `/v1/*`                                                                                                       |
| `managementReadToken`            | ใช้ `apiKey` เป็นค่าทดแทน                                  | คีย์สำหรับ `/api/*` — โดยทั่วไป **ไม่ใช่** คีย์เดียวกัน                                                                     |
| `displayName`                    | `"OmniRoute"`                                              | ชื่อผู้ให้บริการในตัวเลือกโมเดล                                                                                             |
| `timeoutMs`                      | `10000`                                                    | ระยะหมดเวลาการดึงข้อมูลต่อเอนด์พอยต์ (คอมโบอัตโนมัติใช้ 5 วินาที)                                                           |
| `modelCacheTtlMs`                | `300000`                                                   | TTL ของแค็ตตาล็อกในแคช โดยสแนปช็อตบนดิสก์ช่วยเตรียมข้อมูลสำหรับการเริ่มต้นแบบเย็น                                           |
| `timeouts`                       | ใช้ `timeoutMs` เป็นค่าทดแทน                               | งบเวลาต่อเอนด์พอยต์ในหน่วยมิลลิวินาที: `models`, `combos`, `autoCombos`, `enrichment`                                       |
| `enrichment`                     | `true`                                                     | ดึงข้อมูลชื่อ ราคา และโควตาระดับฟรี                                                                                         |
| `providerTag`                    | `true`                                                     | เติมชื่อผู้ให้บริการต้นทางที่โมเดลส่งคำขอไปเป็นคำนำหน้าชื่อที่แสดง                                                          |
| `usableOnly`                     | `false`                                                    | เก็บไว้เฉพาะผู้ให้บริการที่เกตเวย์รายงานว่าพร้อมใช้งาน                                                                      |
| `visibleModels` / `hiddenModels` | `[]`                                                       | รายการอนุญาตแบบตรงทั้งหมดหรือตรงส่วนท้าย โดยรายการปฏิเสธมีสิทธิ์เหนือกว่า                                                   |
| `geminiSanitization`             | `true`                                                     | ตัดคีย์เวิร์ด JSON-Schema ที่ Gemini ปฏิเสธออกจากสคีมาของเครื่องมือ (เครื่องมือที่ใช้ `$ref` จะถูกส่งต่อตามเดิมโดยไม่แก้ไข) |
| `apiFormat.allowAnthropic`       | `false`                                                    | กำหนดเส้นทางให้รหัสที่อยู่ในรายการอนุญาตผ่านบล็อก Anthropic API                                                             |
| `apiFormat.anthropicModels`      | `[]`                                                       | รหัสโมเดลแบบเต็มที่จะกำหนดเส้นทางไปยัง Anthropic                                                                            |
| `logLevel` / `startupDebug`      | `warn` / `false`                                           | ระดับรายละเอียดของตัวบันทึกล็อก                                                                                             |

## วิธีที่แค็ตตาล็อกคงความสดใหม่

แค็ตตาล็อกจะถูกดึงแบบ lazy และแคชไว้ตามระยะเวลา `modelCacheTtlMs` อีกทั้งสแนปช็อตบนดิสก์ยังช่วยให้
แค็ตตาล็อกล่าสุดที่ทราบยังคงพร้อมใช้งานเมื่อไม่สามารถเชื่อมต่อเกตเวย์ได้ — การหยุดให้บริการจึงทำให้คุณเสียเพียง
ความสดใหม่ของข้อมูลเท่านั้น โมเดลและคอมโบจะถูกเผยแพร่ทันทีที่มาถึง ส่วนคอมโบอัตโนมัติ รายการผู้ให้บริการ
และโอเวอร์เลย์การเพิ่มข้อมูลจะถูกรวมเข้ามาเมื่อพร้อมใช้งาน ดังนั้นเอนด์พอยต์ที่ทำงานช้าเพียงแห่งเดียวจึงไม่อาจทำให้
ตัวเลือกทั้งหมดต้องหยุดรอได้

ชื่อจะระบุข้อมูลที่เกตเวย์ทราบ ได้แก่ ผู้ให้บริการต้นทางที่โมเดลกำหนดเส้นทางไป เครื่องหมาย `[Free]`
และงบประมาณที่มาพร้อมกัน — เพื่อให้การเชื่อมต่อสองรายการที่จำหน่ายโมเดลเดียวกันยังคง
แยกแยะออกจากกันได้ ปิดคำนำหน้าได้ด้วย `"providerTag": false`

ไม่มีคำสั่งรีเฟรชด้วยตนเอง เนื่องจากคำสั่งของ OpenCode v2 เป็นเทมเพลตพรอมต์ ไม่ใช่ callback
ดังนั้นปลั๊กอินจึงไม่สามารถเปิดให้ใช้คำสั่งดังกล่าวได้ การรีเฟรชจะเป็นไปตาม TTL โดยจะขอให้โฮสต์โหลดใหม่เฉพาะเมื่อ
แค็ตตาล็อกหรือโอเวอร์เลย์มีการเปลี่ยนแปลงจริงเท่านั้น ไม่ใช่ทุกครั้งที่รีเฟรช

## การเรียกใช้เครื่องมือบน Gemini

Gemini จะปฏิเสธคำขอทั้งหมดหากการประกาศเครื่องมือมี `$schema` หรือ
`additionalProperties` และตอบกลับด้วย `400 INVALID_ARGUMENT` ปลั๊กอินจะลบคีย์เวิร์ดเหล่านั้นออกจาก
สคีมาของเครื่องมือที่ส่งไปยังโมเดล Gemini ของผู้ให้บริการรายนี้ โดยไม่แก้ไขคำขออื่นใด
เครื่องมือที่มี `$ref` จะถูกส่งต่อโดยไม่แก้ไขแทนที่จะถูกลบออก เนื่องจากการลบ
การอ้างอิงจะทำให้สคีมาครอบคลุมกว้างขึ้นจนกลายเป็น "ยอมรับทุกอย่าง"
ตั้งค่า `"geminiSanitization": false` เพื่อปิดการทำงานนี้

## การแก้ไขปัญหา

| อาการ                                    | สาเหตุ                                                                                                        |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| ตัวเลือกไม่แสดงโมเดล OmniRoute           | ไม่พบคีย์ (ตรวจสอบคำเตือนเมื่อเริ่มต้นระบบ) หรือไม่สามารถเชื่อมต่อเกตเวย์ได้                                  |
| มีเฉพาะ ID โมเดลดิบ ไม่มีคอมโบ ไม่มีราคา | เอนด์พอยต์การจัดการปฏิเสธโทเค็น — ให้ตั้งค่า `managementReadToken`                                            |
| เซสชันถูกตรึงไว้กับ `opencode-<id>/…`    | ปลั๊กอิน v1 เผยแพร่ `opencode-<id>` ส่วน v2 เผยแพร่ `<id>` โดยตรง ดังนั้นให้เลือกโมเดลอีกครั้งภายใต้ `<id>/…` |
