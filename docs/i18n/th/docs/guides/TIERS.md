OmniRoute จัดกลุ่มผู้ให้บริการที่รองรับ 352 รายออกเป็น 3 ระดับตามต้นทุน คำขอแต่ละรายการ
จะถูกส่งผ่านผู้ให้บริการเหล่านี้ตามลำดับจนกว่าจะมีรายหนึ่งตอบกลับสำเร็จ — คุณจึง
ได้รับการตอบกลับที่ใช้งานได้และมีราคาถูกที่สุด โดยไม่ต้องเขียนโค้ดสำรองเลย

## ระดับ 1 — การสมัครสมาชิก

**ผู้ให้บริการที่คุณชำระเงินอยู่แล้ว** OmniRoute ใช้โควตาทุกส่วนให้คุ้มค่าก่อน
หมดอายุ

| ผู้ให้บริการ                          | เหตุผลที่อยู่ในระดับ 1                            |
| ------------------------------------- | ------------------------------------------------- |
| Claude Code OAuth                     | Anthropic Pro/Team — อัตราคงที่และมักไม่ได้ใช้งาน |
| OpenAI Codex (การสมัครสมาชิก ChatGPT) | Plus/Team มีโควตา Codex รวมอยู่ด้วย               |
| GitHub Copilot                        | คิดค่าบริการต่อผู้ใช้ — โควตารีเซ็ตทุกเดือน       |
| Cursor IDE                            | โควตาของแผน Pro                                   |
| Antigravity / Devin Desktop           | โควตาในตัว                                        |

**กลยุทธ์**: ส่งทุกคำขอที่เหมาะกับจุดแข็งของโมเดลมาที่ระดับนี้ก่อน
ตัวติดตามโควตาจะตรวจสอบช่วงเวลาที่ใกล้ถึงการรีเซ็ต และกลยุทธ์แบบผสม `reset-aware`
จะจัดลำดับความสำคัญให้สอดคล้องกัน หากต้องการส่งไปยังระดับ 1 ก่อน และขยับ
ไปยังระดับที่มีค่าใช้จ่ายเมื่อโควตาหมดเท่านั้น ให้ใช้รหัส `auto/thrifty` — หรือ `auto/subscription`
เพื่อใช้เฉพาะความจุที่รวมอยู่ในแผน และปิดการทำงานเมื่อไม่สำเร็จแทน โปรดดู
[การกำหนดเส้นทางโดยให้การสมัครสมาชิกมาก่อน](../routing/SUBSCRIPTION_LADDER.md)

## ระดับ 2 — ราคาประหยัด

**ผู้ให้บริการแบบชำระตามจำนวนโทเค็นที่มีราคาต่ำกว่า $1/1M โทเค็น** สงวนไว้สำหรับงานปริมาณมาก
หรือใช้หลังจากโควตาระดับ 1 ถึงขีดจำกัดแล้ว

| ผู้ให้บริการ                    | ราคา (อินพุต/เอาต์พุต) | จุดแข็ง                       |
| ------------------------------- | ---------------------- | ----------------------------- |
| DeepSeek V4 Pro                 | $0.27 / $1.10 ต่อ 1M   | โค้ด, การใช้เหตุผล            |
| GLM-4.5                         | $0.60 / $2.20 ต่อ 1M   | บริบทยาว                      |
| MiniMax M1                      | $0.20 / $1.10 ต่อ 1M   | ความเร็ว                      |
| Qwen Coder                      | $0.30 / $1.20 ต่อ 1M   | โค้ด                          |
| OpenRouter (ปรับราคาให้เหมาะสม) | แตกต่างกัน             | มากกว่า 100 โมเดล, แบบไดนามิก |

**กลยุทธ์**: กลยุทธ์แบบผสม `cost-optimized` จะเลือกโมเดลที่มีค่า $/token ต่ำที่สุดซึ่งผ่าน
ตัวกรองความสามารถของงาน (การมองเห็น, โหมด JSON, เครื่องมือ, บริบทสูงสุด)

## ระดับ 3 — ฟรี

**ผู้ให้บริการที่ไม่มีค่าใช้จ่าย** — ระดับใช้งานฟรี, โปรแกรมเครดิต, โควตา OAuth รายวัน

| ผู้ให้บริการ     | โควตา / เครดิตฟรี                                         |
| ---------------- | --------------------------------------------------------- |
| Kiro AI          | ระดับ Claude ฟรี (นโยบายใช้งานอย่างเป็นธรรมที่เอื้อเฟื้อ) |
| OpenCode Free    | ไม่ต้องยืนยันตัวตน, ขีดจำกัดอัตราการใช้งานสูง             |
| Qoder            | OAuth ฟรี                                                 |
| Google Vertex AI | เครดิต $300 สำหรับบัญชีใหม่                               |
| Amazon Q         | ระดับฟรีสำหรับผู้ใช้ AWS                                  |
| Pollinations     | API สาธารณะแบบเปิด                                        |
| Cloudflare AI    | ระดับฟรีของ Workers AI                                    |

**กลยุทธ์**: กลยุทธ์แบบผสม `auto` ที่มีเพดานงบประมาณจะส่งคำขอมาที่ระดับนี้เมื่อระดับ 1+2 ล้มเหลว
หรือเมื่อตั้งค่า `useFreeOnly=true` ผู้ให้บริการฟรีมักมี
ขีดจำกัดอัตราการใช้งานที่เข้มงวดกว่า — ตัวตัดวงจรจะนำผู้ให้บริการเหล่านี้กลับมาใช้งานหลังช่วงหน่วงเวลา

## การกำหนดค่าระดับ

แดชบอร์ด → **ระดับ** → กำหนดผู้ให้บริการของคุณ ค่าเริ่มต้น (จาก `tierDefaults.json`) มีความเหมาะสม
อยู่แล้ว; แก้ไขเมื่อคุณมีการสมัครสมาชิกเฉพาะที่ต้องการให้มีลำดับความสำคัญ หรือมีผู้ให้บริการที่ต้องการยกเว้น

การให้คะแนนด้วยปัจจัย 16 ประการของ Auto-Combo จะพิจารณาระดับด้วย โปรดดู
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md)

## ข้อมูลการใช้งาน

แดชบอร์ด → **การใช้งาน** แสดงจำนวนโทเค็นที่ใช้ต่อระดับในแต่ละวัน ใช้ข้อมูลนี้เพื่อ:

- ยืนยันว่าระดับ 1 ถูกใช้งานเต็มที่ (มิฉะนั้นคุณกำลังสูญเสียความคุ้มค่าจากการสมัครสมาชิก)
- ระบุว่าโมเดลระดับ 2 ใดถูกเลือกมากที่สุด (รวมให้เหลือ 1-2 โมเดล)
- ตรวจสอบว่าระดับ 3 ช่วยประหยัดค่าใช้จ่ายสำหรับภาระงานทดสอบ/สำรวจ

## รูปแบบทั่วไป

### ภาระงานแบบฟรีล้วน

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

ให้น้ำหนักไปทางระดับ 3 อย่างมาก; ใช้ระดับ 2 เฉพาะเมื่อระดับ 3 ไม่พร้อมใช้งานเท่านั้น

### ให้การสมัครสมาชิกมาก่อน พร้อมตัวสำรองราคาประหยัด

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

รายการที่เรียงลำดับไว้อย่างชัดเจน ซึ่งตรงกับระดับ 1 → ระดับ 2 → ระดับ 3
