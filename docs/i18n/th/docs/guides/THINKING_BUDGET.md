> **แดชบอร์ด:** Settings → **AI** → Thinking Budget  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **ซอร์ส:** `open-sse/services/thinkingBudget.ts`

Thinking Budget ควบคุมว่า OmniRoute จะ **เขียนทับพารามิเตอร์การคิด/การให้เหตุผลของไคลเอนต์** ระหว่างส่งไปยังผู้ให้บริการหรือไม่ โดย **ไม่ได้** เปิดหรือปิดการบีบอัด การกำหนดเส้นทาง หรือแคชพรอมต์

## โหมด

| โหมด                            | สิ่งที่ OmniRoute ทำ                                                                                                       | ควรใช้เมื่อ                                                                                                                                                |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (ค่าเริ่มต้น) | ปล่อยฟิลด์ของไคลเอนต์ไว้ตามเดิม (`reasoning`, `reasoning_effort`, `thinking` ของ Claude, `thinking_config` ของ Gemini ฯลฯ) | **Codex / Desktop / ไคลเอนต์ใด ๆ ที่ควรควบคุมระดับความพยายามและสรุปการให้เหตุผล** จำเป็นสำหรับการแสดงแผงการคิดเมื่อไคลเอนต์ร้องขอ `reasoning.summary`      |
| **`auto`**                      | **ลบฟิลด์ทั้งหมด** ที่เกี่ยวข้องกับการคิด/การให้เหตุผลออกจากเนื้อความคำขอก่อนส่งไปยังระบบต้นทาง                            | ใช้เฉพาะเมื่อตั้งใจให้ **ผู้ให้บริการ** กำหนดค่าเริ่มต้นเอง และคุณ **ไม่** ต้องการให้ไคลเอนต์ควบคุมการคิด ซึ่ง **ไม่ได้** หมายถึง “แสดงการคิดโดยอัตโนมัติ” |
| **`custom`**                    | เขียนทับทุกคำขอด้วยงบประมาณโทเค็นการคิดแบบคงที่                                                                            | ใช้กำหนดเพดานโทเค็นการคิดแบบตายตัวสำหรับทราฟฟิกทั้งหมด                                                                                                     |
| **`adaptive`**                  | ปรับขนาดงบประมาณจากระดับความพยายามพื้นฐาน โดยใช้จำนวนข้อความ เครื่องมือ และความยาวพรอมต์                                   | ควบคุมโทเค็นแบบยืดหยุ่นโดยไม่ลบเจตนาของไคลเอนต์ทั้งหมด                                                                                                     |

### สิ่งที่ `auto` ลบออก

เมื่อโหมดเป็น `auto` ฟังก์ชัน `stripThinkingConfig()` จะลบรายการต่อไปนี้ (รวมถึงรายการอื่น ๆ):

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking` และ `output_config.effort` หากมี
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

หากไคลเอนต์ (เช่น Codex Desktop) ส่ง `reasoning: { effort: "ultra", summary: "detailed" }` มา **`auto` จะลบออบเจ็กต์ดังกล่าวทิ้ง** ระบบต้นทางอาจยังเรียกเก็บค่าโทเค็นการให้เหตุผลบางส่วน แต่บ่อยครั้งจะส่งคืนรายการการให้เหตุผลที่ **ว่างเปล่าหรือมีเฉพาะข้อมูลเข้ารหัส** ทำให้ UI ไม่แสดงสตรีมการคิดที่มีประโยชน์

## สิ่งที่ฟีเจอร์นี้ **ไม่ใช่**

| ฟีเจอร์                                            | ความสัมพันธ์                                                                                                                            |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **การบีบอัด** (Caveman, RTK, stacked, …)           | เป็นไปป์ไลน์แยกต่างหาก ทำงานได้ภายใต้ทุกโหมดของ Thinking Budget                                                                         |
| **แคชพรอมต์ / แคชเชิงความหมาย**                    | แยกต่างหาก ไม่ได้รับผลกระทบจากโหมด Thinking Budget                                                                                      |
| **การกำหนดเส้นทางแบบ Combo / ระบบสำรอง**           | แยกต่างหาก ไม่ได้รับผลกระทบ                                                                                                             |
| **ขีดจำกัดโทเค็นของคีย์ API / งบประมาณค่าใช้จ่าย** | แยกต่างหาก ไม่ได้รับผลกระทบ                                                                                                             |
| **แคชการเล่นซ้ำการให้เหตุผล**                      | แทรกข้อมูลกลับเข้าไปใหม่แบบหลายรอบสำหรับผู้ให้บริการที่เข้มงวด (DeepSeek, Kimi, Qwen-thinking, …) ไม่เหมือนกับ “แสดงการคิด” ของ Desktop |
| **การถอดรหัส `encrypted_content`**                 | **เป็นไปไม่ได้** บล็อบการให้เหตุผลส่วนตัวของ OpenAI/Codex เป็นข้อมูลทึบแสง OmniRoute จะไม่ถอดรหัสข้อมูลเหล่านี้ (#7095 / #7176 / #7304) |

## การแสดงข้อความกระบวนการคิด (ไคลเอนต์ Codex / Responses)

หากต้องการให้ไคลเอนต์แสดงข้อความกระบวนการคิด คุณจำเป็นต้องมี **ทุกข้อ** ดังต่อไปนี้:

1. โหมด Thinking Budget = **`passthrough`** (หรือ custom/adaptive ที่ยังคงคำขอสรุปไว้อย่างเพียงพอสำหรับเส้นทางที่คุณใช้งาน)
2. ไคลเอนต์ร้องขอสรุป เช่น Codex `model_reasoning_summary = "detailed"` / `auto` (ไม่ใช่ `none`)
3. ต้นทางสตรีม `response.reasoning_summary_text.*` จริง (หรือมี `reasoning.summary` ที่ไม่ว่างเปล่าในรายการ)

หากคุณได้รับเพียง “กระบวนการคิดส่วนตัวที่เข้ารหัส” สาเหตุอาจเป็นข้อใดข้อหนึ่งต่อไปนี้:

- โหมดเป็น **`auto`** (คำขอของไคลเอนต์ถูกตัดออก) หรือ
- ต้นทางส่งคืน `encrypted_content` โดยไม่มีข้อความสรุป (ข้อจำกัดของผู้ให้บริการ; OmniRoute แสดงได้เพียงข้อความตัวแทน ไม่ใช่ข้อความธรรมดา)

## ตัวอย่าง API

```bash
# อ่าน
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# แนะนำสำหรับการแสดงกระบวนการคิดใน Codex / Desktop
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

สคีมา (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; ตัวเลือกเพิ่มเติม ได้แก่ `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`

### การคงอยู่ของค่า / การรีสตาร์ต

ค่าจะถูกจัดเก็บภายใต้คีย์การตั้งค่า `thinkingBudget` และโหลดเมื่อเริ่มต้นโปรเซส (`hydrateThinkingBudgetConfig`) หลังจากเปลี่ยนค่าผ่านฐานข้อมูลหรือช่องทางอื่นที่ไม่ใช่ API ให้ **รีสตาร์ตโปรเซส OmniRoute** เพื่อให้ซิงเกิลตันในหน่วยความจำตรงกับค่าบนดิสก์

## รายการตรวจสอบสำหรับผู้ดูแลระบบ

- [ ] ผู้ใช้ Codex / Desktop: โหมด = **passthrough**
- [ ] ยังคงเปิดใช้การบีบอัด หากคุณต้องการประหยัดโทเค็นใน **ข้อความ** ไม่ใช่ด้วยการตัดกระบวนการคิดออก
- [ ] อย่าคาดหวังว่า `auto` จะ “แสดงกระบวนการคิดมากขึ้น”
- [ ] สรุปที่มีเฉพาะข้อมูลเข้ารหัสเป็นพฤติกรรมของ **ผู้ให้บริการ**; passthrough ไม่สามารถถอดรหัสได้
