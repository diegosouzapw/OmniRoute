- เป้าหมายความครอบคลุมใช้กับไฟล์ซอร์ส ไม่ใช่ `tests/**`
- `open-sse/**` เป็นส่วนหนึ่งของผลิตภัณฑ์และต้องคงอยู่ในขอบเขต
- โค้ดใหม่ไม่ควรลดความครอบคลุมในส่วนที่มีการแก้ไข

- `npm run test:coverage`

  - สร้าง `text-summary`, `html`, `json-summary` และ `lcov`
- `npm run coverage:report`
  - รายงานโดยละเอียดแยกตามไฟล์จากการรันล่าสุด
- `npm run test:coverage:legacy`
  - ใช้สำหรับการเปรียบเทียบย้อนหลังเท่านั้น

คำสั่งวัดความครอบคลุมปัจจุบันวัดชุด unit test หลักของ Node และรวมซอร์สที่ถูกเรียกใช้จากชุดดังกล่าว ซึ่งรวมถึง `open-sse` แต่ยังไม่ได้รวมความครอบคลุมของ Vitest เข้าเป็นรายงานเดียวแบบครบวงจร การรวมดังกล่าวควรทำในภายหลัง แต่ไม่ใช่อุปสรรคต่อการเริ่มเพิ่มความครอบคลุมจาก 60% -> 80%
