> **สรุปสั้นๆ**: ติดตั้ง → เชื่อมต่อผู้ให้บริการฟรี → ตั้งค่า IDE ให้ชี้ไปที่ OmniRoute เท่านี้ก็เสร็จแล้ว

---

## ขั้นตอนที่ 1: ติดตั้ง OmniRoute

เลือกวิธีที่คุณต้องการ:

### ตัวเลือก A: npm (แนะนำ)

```bash
npm install -g omniroute
```

### ตัวเลือก B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` คือ SemVer เวอร์ชันเสถียรที่ **เผยแพร่แล้ว** และมีหมายเลขสูงสุด โดยจะ **ไม่** ติดตาม git `main` สำหรับ GitOps ให้ตรึงเวอร์ชันเป็น `diegosouzapw/omniroute:X.Y.Z` ดูข้อมูลเพิ่มเติมที่ [แท็กอิมเมจ / ช่องทางการเผยแพร่](../guides/DOCKER_GUIDE.md#release-channels)

### ตัวเลือก C: จากซอร์สโค้ด

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## ขั้นตอนที่ 2: เริ่มใช้งาน OmniRoute

```bash
omniroute
```

OmniRoute จะเริ่มทำงานที่ `http://localhost:20128` และแดชบอร์ดจะเปิดขึ้นโดยอัตโนมัติ

---

## ขั้นตอนที่ 3: เชื่อมต่อผู้ให้บริการฟรี

คุณสามารถใช้ OmniRoute **โดยไม่ต้องเสียค่าใช้จ่ายใดๆ** ด้วยการเชื่อมต่อผู้ให้บริการฟรี

### ตัวเลือก A: Kiro (Claude ฟรี — ไม่ต้องใช้บัตรเครดิต)

1. เปิดแดชบอร์ดที่ `http://localhost:20128`
2. ไปที่ **ผู้ให้บริการ** → **เพิ่มผู้ให้บริการ**
3. เลือก **Kiro AI**
4. คลิก **เชื่อมต่อ** (ไม่ต้องใช้ API key!)
5. เสร็จแล้ว! ตอนนี้คุณสามารถเข้าถึงโมเดล Claude ได้ฟรี

### ตัวเลือก B: OpenCode Free (ไม่ต้องยืนยันตัวตน)

1. เปิดแดชบอร์ดที่ `http://localhost:20128`
2. ไปที่ **ผู้ให้บริการ** → **เพิ่มผู้ให้บริการ**
3. เลือก **OpenCode Free**
4. คลิก **เชื่อมต่อ** (ไม่ต้องใช้ API key!)
5. เสร็จแล้ว! ตอนนี้คุณสามารถเข้าถึงโมเดลหลายรายการได้ฟรี

### ตัวเลือก C: Pollinations (ไม่ต้องใช้คีย์)

1. เปิดแดชบอร์ดที่ `http://localhost:20128`
2. ไปที่ **ผู้ให้บริการ** → **เพิ่มผู้ให้บริการ**
3. เลือก **Pollinations**
4. คลิก **เชื่อมต่อ** (ไม่ต้องใช้ API key!)
5. เสร็จแล้ว! ตอนนี้คุณสามารถเข้าถึง GPT-5, Claude, Gemini และโมเดลอื่นๆ ได้ฟรี

## ขั้นตอนที่ 4: ตรวจสอบว่าทำงานได้

จาก [API Keys](http://localhost:20128/dashboard/api-manager) ให้สร้างคีย์ใหม่และบันทึกคีย์นี้ไว้ เนื่องจากคีย์จะไม่แสดงอีก โปรดทราบว่าคีย์นี้มีไว้เพื่อให้เครื่องมือเข้าถึง OmniRoute ไม่ใช่เพื่อเข้าถึงผู้ให้บริการต้นทาง

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

คุณควรเห็นรายการโมเดลที่เชื่อมต่อไว้

## ขั้นตอนที่ 5: ตั้งค่า IDE หรือ CLI ให้ชี้ไปที่ OmniRoute

ตั้งค่าต่อไปนี้ใน IDE หรือเครื่องมือ CLI ของคุณ:

```
URL พื้นฐาน: http://localhost:20128/v1
API Key:     [คัดลอกจากแดชบอร์ด → เอนด์พอยต์]
โมเดล:       auto
```

เท่านี้ก็เรียบร้อย! ตอนนี้ IDE ของคุณจะใช้ OmniRoute พร้อมการเลือกผู้ให้บริการโดยอัตโนมัติ

### ตัวอย่าง IDE: VSCode/Continue.dev

1. ติดตั้งส่วนขยาย [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ใน VSCode
2. อัปเดต `~/.continue/config.yaml` โดยเพิ่มบรรทัดต่อไปนี้:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. ในหน้าต่างแชตของ Continue.dev ให้เลือก `OmniRoute - Auto` แล้วคำขอของคุณจะถูกส่งไปยัง OmniRoute
4. (ไม่บังคับ) แบบฝึกหัดสำหรับผู้อ่าน — ให้ IDE ของคุณอัปเดต `config.yaml` ด้วยการกำหนดค่าสำเร็จรูปอื่นๆ ทั้งหมด 😊

### ตัวอย่าง CLI: Codex CLI

1. ตั้งค่าตัวแปรสภาพแวดล้อมแบบถาวรในระบบปฏิบัติการของคุณ
   สำหรับ macOS/Linux (เพิ่มลงใน `~/.bashrc` หรือ `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

สำหรับ Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. ตอนนี้มาเปิดใช้งาน Codex โดยกำหนดค่าให้ใช้ OmniRoute กัน เรียกใช้:

```
omniroute launch-codex --model auto
```

คุณสามารถทำสิ่งนี้ด้วยตนเองผ่าน `codex` และพารามิเตอร์บรรทัดคำสั่งเพื่อระบุเอนด์พอยต์และ API key ได้ แต่เมื่อใช้คำสั่งข้างต้น OmniRoute จะจัดการทุกอย่างให้คุณ

การเปิดใช้งานด้วยคำสั่งเดียวแบบเดียวกันนี้รองรับ CLI อื่นๆ ผ่านตัวเรียกใช้งานทั่วไปด้วย — `omniroute run <target>` รองรับ `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` และ `gemini` (ดู [การผสานรวม CLI](../guides/CLI-INTEGRATIONS.md))

3. ตอนนี้ CLI ควรส่งคำขอไปยัง OmniRoute แล้ว

### ยืนยันว่าเครื่องมือของคุณกำลังกำหนดเส้นทางไปยัง OmniRoute

คุณสามารถดูรายละเอียดคำขอได้โดยคลิก [การตรวจสอบ/บันทึก](http://localhost:20128/dashboard/logs) จากแถบด้านซ้าย เมื่อคลิกเข้าไปแล้ว คุณจะเห็นรายละเอียดเพิ่มเติม นอกจากนี้ คุณยังสามารถดูได้ว่าเครื่องมือที่คุณชื่นชอบส่งข้อมูลใดออกไปบ้าง ซึ่งมีประโยชน์ทั้งในด้านการเรียนรู้และการแก้ไขข้อบกพร่อง

## คำถามที่พบบ่อย

### "ฉันจำเป็นต้องมี API key หรือไม่?"

**ไม่จำเป็น!** คุณสามารถใช้ผู้ให้บริการฟรี (Kiro, OpenCode Free, Pollinations) ได้โดยไม่ต้องมี API key เพียงเชื่อมต่อผู้ให้บริการเหล่านั้นในแดชบอร์ด

### "`auto` คืออะไร?"

`auto` จะสั่งให้ OmniRoute เลือกผู้ให้บริการที่ดีที่สุดสำหรับแต่ละคำขอโดยอัตโนมัติ โดยพิจารณาจากความเร็ว ค่าใช้จ่าย คุณภาพ และความพร้อมใช้งาน ดูรายละเอียดเพิ่มเติมได้ที่ [คู่มือ Auto-Combo](./AUTO-COMBO-GUIDE.md)

### "มีค่าใช้จ่ายเท่าไร?"

ตัว OmniRoute เองนั้น **ฟรีและเป็นโอเพนซอร์ส** คุณจะจ่ายเฉพาะค่าบริการของผู้ให้บริการที่คุณใช้เท่านั้น ผู้ให้บริการหลายรายมีแพ็กเกจฟรี — ดู [คู่มือแพ็กเกจฟรี](./FREE-TIERS-GUIDE.md)

### "ฉันสามารถใช้กับ Claude Code / Cursor / Copilot ได้หรือไม่?"

**ได้!** OmniRoute ทำงานร่วมกับเครื่องมือใดๆ ที่รองรับรูปแบบ OpenAI เพียงตั้งค่า URL พื้นฐานเป็น `http://localhost:20128/v1` ดูคำแนะนำในการตั้งค่าเฉพาะได้ที่ [คู่มือเครื่องมือ CLI](../reference/CLI-TOOLS.md)

### "จะเกิดอะไรขึ้นหากผู้ให้บริการหยุดทำงาน?"

OmniRoute จะข้ามผู้ให้บริการที่ล้มเหลวและลองใช้รายถัดไปโดยอัตโนมัติ คุณไม่จำเป็นต้องดำเนินการใดๆ ดูรายละเอียดเพิ่มเติมได้ที่ [คู่มือ Auto-Combo](./AUTO-COMBO-GUIDE.md)
