> **สรุปสั้น ๆ**: ใช้บัญชีผู้ให้บริการที่มีสิทธิ์ของคุณเอง OmniRoute จะรวมการเชื่อมต่อที่คุณกำหนดค่าไว้เข้าด้วยกัน แต่ไม่ได้เป็นผู้ออกโควตาโทเค็นรวมตามที่โฆษณาไว้ การเข้าถึงฟรีอาจต้องสมัครบัญชี ใช้ API key ได้รับการอนุมัติ หรือระบุวิธีการชำระเงิน ทั้งนี้ ขีดจำกัด นโยบายความเป็นส่วนตัว และข้อกำหนดของผู้ให้บริการยังคงมีผลบังคับใช้

## ระดับฟรีคืออะไร?

ผู้ให้บริการ AI หลายรายเสนอ **การเข้าถึงฟรี** ในรูปแบบใดรูปแบบหนึ่ง โดยอาจหมายถึงเอนด์พอยต์ที่ไม่ต้องยืนยันตัวตน โควตาที่ได้รับเป็นประจำ การเข้าถึงแบบไม่จำกัดปริมาณแต่จำกัดอัตราการใช้งาน เครดิตที่ได้รับเมื่อลงทะเบียน การอนุมัติด้วยตนเอง หรือโปรโมชันชั่วคราว ทั้งนี้ขึ้นอยู่กับผู้ให้บริการ ตัวเลือกบางอย่างจำเป็นต้องมีบัญชี คีย์ API บัตรเครดิต การยืนยันตัวตน (KYC) หรือการยอมรับข้อกำหนดเฉพาะของผู้ให้บริการ

OmniRoute **รวบรวม** การเชื่อมต่อที่กำหนดค่าไว้ให้เป็นเอนด์พอยต์เดียว คุณยังคงต้องลงทะเบียนกับผู้ให้บริการแต่ละรายที่กำหนดให้มีบัญชีแยกกัน เชื่อมต่อบัญชีเหล่านั้นแล้วใช้ `model: "auto"` เพื่อกำหนดเส้นทางไปยังเป้าหมายที่มีสิทธิ์ การติดตั้งใหม่อาจไม่มีเป้าหมายที่ไม่ต้องใช้คีย์และมีสิทธิ์ใช้งาน การติดตั้ง OmniRoute เพียงอย่างเดียวไม่ได้รับประกันว่าจะได้รับการตอบกลับจากแชตสำเร็จ

## วิธีรวมโควตาฟรีหลายระดับเข้าด้วยกัน

ความสามารถที่โดดเด่นของ OmniRoute คือ **การรวมโควตาฟรีหลายระดับเข้าด้วยกัน** แทนที่จะพึ่งพาผู้ให้บริการเพียงรายเดียว คุณสามารถเชื่อมต่อผู้ให้บริการฟรีหลายราย และให้ OmniRoute เลือกผู้ให้บริการที่ดีที่สุดสำหรับแต่ละคำขอโดยอัตโนมัติ

### ตัวอย่าง: เพิ่มความครอบคลุมของโควตาฟรี

เชื่อมต่อผู้ให้บริการหลายรายเพื่อลดการพึ่งพาโควตาของผู้ให้บริการรายใดรายหนึ่ง:

1. **Gemini** — โควตาคีย์ API แบบต่ออายุเป็นระยะ
2. **Groq** — โควตาคีย์ API แบบต่ออายุเป็นระยะ
3. **Pollinations** — เข้าถึงได้โดยไม่ต้องใช้คีย์ แต่มีการจำกัดอัตราการใช้งาน
4. **LongCat** — เครดิตที่ได้รับครั้งเดียวเมื่อลงทะเบียน (ต้องผ่าน KYC)

จากนั้นใช้ `model: "auto"` แล้ว OmniRoute จะ:

- ลองใช้การเชื่อมต่อที่มีสิทธิ์และมีอันดับสูงสุดก่อน
- หากโควตาหรือการตรวจสอบสถานะของการเชื่อมต่อนั้นล้มเหลว → ลองผู้ให้บริการรายถัดไปที่กำหนดค่าไว้
- หากผู้ให้บริการที่ไม่ต้องใช้คีย์ไม่พร้อมใช้งาน → ดำเนินการต่อโดยลองเป้าหมายที่เหลือ
- หากไม่มีการเชื่อมต่อที่มีสิทธิ์ใดสำเร็จ → ส่งคืนข้อผิดพลาด โดยเครดิตจากการลงทะเบียนจะใช้ได้เฉพาะขณะที่ยังมีผลและยังมีเครดิตคงเหลือ

**ผลลัพธ์**: ความครอบคลุมของโควตาฟรีที่กว้างขึ้น พร้อมระบบสำรองอัตโนมัติ — ไม่ใช่การรับประกันว่าจะมีความจุไม่จำกัด

## วิธีเชื่อมต่อผู้ให้บริการฟรี

### ขั้นตอนที่ 1: เปิดแดชบอร์ด

ไปที่ `http://localhost:20128` ในเบราว์เซอร์ของคุณ

### ขั้นตอนที่ 2: ไปที่ผู้ให้บริการ

คลิก **ผู้ให้บริการ** ในแถบด้านข้าง

### ขั้นตอนที่ 3: คลิกเพิ่มผู้ให้บริการ

คลิกปุ่ม **+ เพิ่มผู้ให้บริการ**

### ขั้นตอนที่ 4: เลือกผู้ให้บริการฟรี

เรียกดูแค็ตตาล็อกและตรวจสอบข้อมูลเมตาปัจจุบันของผู้ให้บริการแต่ละราย ได้แก่ `hasFree` การยืนยันตัวตน โควตา ความเป็นส่วนตัว
และข้อกำหนดในการให้บริการ การ์ดผู้ให้บริการและ
[ข้อมูลอ้างอิงระดับบริการฟรี](../reference/FREE_TIERS.md) จะแยกความแตกต่างระหว่างโควตาที่ได้รับเป็นรอบ
การเข้าถึงแบบไม่จำกัดหรือไม่ต้องใช้คีย์ เครดิตสำหรับการสมัครใช้งาน รายการที่ยุติให้บริการแล้ว และแหล่งบริการที่มีความเสี่ยงสูงกว่า

### ขั้นตอนที่ 5: คลิกเชื่อมต่อ

สำหรับผู้ให้บริการแบบ `NOAUTH` OmniRoute จะไม่ขอข้อมูลประจำตัวสำหรับบริการต้นทาง ทั้งนี้ไม่ได้รับประกันว่าบริการต้นทางจะยอมรับไคลเอนต์ของบุคคลที่สามหรือมีความจุพร้อมให้บริการ ผู้ให้บริการที่ใช้ OAuth และคีย์ API ต้องเชื่อมต่อผ่านขั้นตอนบัญชีตามที่ระบุไว้ในเอกสาร ไคลเอนต์ของคุณยังคงใช้คีย์ API ของ OmniRoute ที่แสดงใน **แดชบอร์ด → เอ็นด์พอยต์** เมื่อเปิดใช้งานการยืนยันตัวตนของเราเตอร์

### ขั้นตอนที่ 6: ทำซ้ำ

เชื่อมต่อผู้ให้บริการหลายรายที่มีข้อกำหนดและรูปแบบความเป็นส่วนตัวเหมาะกับกรณีการใช้งานของคุณ

## การอ่านแค็ตตาล็อกอย่างถูกต้อง

- `NOAUTH` หมายความว่า OmniRoute จะไม่ขอข้อมูลรับรองของผู้ให้บริการจากคุณ แต่ไม่ได้
  รับประกันเวลาพร้อมใช้งาน ความเป็นส่วนตัว หรือความจุแบบไม่จำกัด
- `hasFree` เป็นเมทาดาทาสำหรับการค้นหา ซึ่งอาจหมายถึงโควตาที่ได้รับเป็นประจำ การเข้าถึงโดยไม่ใช้คีย์
  เครดิตสำหรับการสมัคร โปรแกรมที่ต้องผ่านการอนุมัติ หรือโปรโมชัน
- `recurring-uncapped` หมายความว่าไม่มีการเผยแพร่เพดานโทเค็น แต่ข้อจำกัดด้านอัตราและ
  จำนวนการทำงานพร้อมกันยังคงมีผล
- `one-time-initial` จะไม่มีการมอบให้อีกหลังจากใช้สิทธิ์ที่ได้รับเมื่อลงทะเบียนจนหมดแล้ว
- ผู้ให้บริการที่มีเครื่องหมาย `tos: avoid` จะถูกยกเว้นจากการกำหนดเส้นทางอัตโนมัติโดยค่าเริ่มต้น (`excludeTosAvoid`) การเชื่อมต่อบัญชีไม่ได้เป็นการข้ามตัวกรองนี้ การแทนที่โดยผู้ดำเนินการควรทำหลังจากตรวจสอบข้อกำหนดของผู้ให้บริการและความเสี่ยงของบัญชีแล้ว
- รายการที่มีเครื่องหมาย `discontinued` ยังคงเก็บไว้เป็นหลักฐานทางประวัติศาสตร์ และต้องไม่นำเสนอว่า
  ยังคงให้บริการฟรีอยู่ในปัจจุบัน

## วิธีที่ OmniRoute ช่วยให้แพ็กเกจฟรีมีประสิทธิภาพยิ่งขึ้น

### 1. ระบบสำรองอัตโนมัติ

หากผู้ให้บริการฟรีรายหนึ่งมีผู้ใช้งานหนาแน่นหรือไม่พร้อมใช้งาน OmniRoute จะลองรายถัดไปโดยอัตโนมัติ คุณไม่จำเป็นต้องดำเนินการใดๆ

### 2. การกำหนดเส้นทางอัจฉริยะ

OmniRoute เลือก **ผู้ให้บริการฟรีที่ดีที่สุด** สำหรับคำขอแต่ละรายการโดยพิจารณาจาก:

- ความเร็ว — ผู้ให้บริการรายใดเร็วที่สุดในขณะนี้?
- คุณภาพ — ผู้ให้บริการรายใดเหมาะกับงานนี้ที่สุด?
- ความจุ — ผู้ให้บริการรายใดยังมีโควตาเหลืออยู่?

### 3. การประหยัดโทเค็น

ไปป์ไลน์การบีบอัดของ OmniRoute สามารถลดจำนวนโทเค็นของพรอมต์และผลลัพธ์จากเครื่องมือที่เข้าเกณฑ์ได้
การประหยัดจริงขึ้นอยู่กับเนื้อหา เอนจินที่เลือก วิธีคำนวณของผู้ให้บริการ และการตั้งค่า
ความเที่ยงตรง การบีบอัดไม่ได้เพิ่มโควตาของผู้ให้บริการทุกรายเป็นจำนวนเท่าที่ตายตัว

### 4. การรองรับหลายบัญชี

หากข้อกำหนดของผู้ให้บริการอนุญาตให้ใช้หลายบัญชีหรือข้อมูลรับรองหลายชุด OmniRoute สามารถถือว่าแต่ละ
การเชื่อมต่อเป็นตัวเลือกสำหรับการกำหนดเส้นทางแยกกันได้ อย่าสร้างบัญชีเพิ่มเติมเพื่อหลีกเลี่ยง
โควตาหรือนโยบายการเข้าถึงของผู้ให้บริการ

## การคำนวณโควตาฟรี

แค็ตตาล็อกแบบใช้งานจริงที่หักรายการซ้ำในพูลแล้วรายงานค่าปัจจุบันดังนี้:

| เมตริก                         | ค่าปัจจุบันที่ตรวจสอบแล้ว | คำอธิบาย                                                                           |
| ------------------------------ | ------------------------: | ---------------------------------------------------------------------------------- |
| โควตาประจำที่ระบุปริมาณได้     |   **~1.62B โทเค็น/เดือน** | นับพูลที่ใช้ร่วมกันเพียงครั้งเดียว และไม่รวมผู้ให้บริการที่ไม่จำกัดเพดานไว้ในผลรวม |
| เดือนแรกพร้อมเครดิตสมัครใช้งาน |         **~2.22B โทเค็น** | ยอดรวมโควตาประจำ บวกเครดิตแบบครั้งเดียวและแบบประจำ                                 |

ตัวเลขเหล่านี้เป็นค่าประมาณทั่วทั้งแค็ตตาล็อกสำหรับบัญชีที่มีสิทธิ์แยกกัน ไม่ใช่โควตาที่ OmniRoute มอบให้หรือการคาดการณ์สำหรับการติดตั้งใหม่ ความจุที่คุณใช้งานได้ขึ้นอยู่กับผู้ให้บริการที่คุณเชื่อมต่อและเงื่อนไขปัจจุบันของผู้ให้บริการเหล่านั้น ค่าต่างๆ คำนวณจาก `open-sse/config/freeModelCatalog.ts`; โปรดดู
[ข้อมูลอ้างอิงระดับบริการฟรี](../reference/FREE_TIERS.md) สำหรับรายละเอียดเกี่ยวกับการหักรายการซ้ำในพูล แฟล็ก ToS
รายการที่ยกเลิกให้บริการ และวิธีคำนวณเครดิตสมัครใช้งาน

## คำถามที่พบบ่อย

### "นี่ฟรีจริงหรือ?"

แค็ตตาล็อกบันทึกข้อกำหนดที่ผู้ให้บริการเผยแพร่และข้อมูลจากการค้นคว้าของโครงการ แต่ข้อเสนออาจเปลี่ยนแปลงได้
โปรดตรวจสอบราคา โควตา นโยบายความเป็นส่วนตัว และเงื่อนไขสิทธิ์ล่าสุดของผู้ให้บริการก่อนใช้งาน

### "Free Tier จะหมดหรือไม่?"

ผู้ให้บริการทุกรายอาจจำกัดอัตราการใช้งาน เปลี่ยนโมเดล ระงับการเข้าถึง หรือออฟไลน์ได้ การเชื่อมต่อ
หลายรายการช่วยเพิ่มความครอบคลุมของเส้นทางสำรอง แต่ไม่รับประกันว่าจะมีเส้นทางฟรีพร้อมใช้งาน

### "ฉันสามารถใช้ผู้ให้บริการฟรีกับระบบจริงได้หรือไม่?"

ได้เฉพาะเมื่อ SLA การจัดการข้อมูล ขีดจำกัด และข้อกำหนดของผู้ให้บริการตรงตาม
ข้อกำหนดของระบบจริงของคุณ เวิร์กโหลดที่สำคัญควรมีระบบสำรองที่ได้รับการตรวจสอบและเหมาะสมตามสัญญา

### "มีข้อแลกเปลี่ยนอะไรบ้าง?"

ข้อแลกเปลี่ยนอาจรวมถึงขีดจำกัดที่เข้มงวด รายชื่อรอ KYC การยืนยันบัตรเครดิต การนำพรอมต์ไปใช้ฝึก
ความเป็นส่วนตัวที่ด้อยกว่า การไม่มี SLA การเปลี่ยนโมเดลบ่อย ข้อจำกัดทางภูมิศาสตร์ ค่าใช้จ่ายเมื่อใช้เกินโควตา หรือ
ความเสี่ยงจากนโยบายบัญชี OmniRoute แสดงเมทาดาทาที่มีอยู่ ส่วนคุณเป็นผู้เลือกว่าจะเปิดใช้งานสิ่งใด

### "ฉันจะรับโควตาฟรีเพิ่มขึ้นได้อย่างไร?"

1. เชื่อมต่อผู้ให้บริการฟรีเพิ่มเติม
2. เปิดใช้เอนจินบีบอัดที่เหมาะสมและวัดปริมาณที่ประหยัดได้สำหรับเวิร์กโหลดของคุณ
3. ใช้ `auto/cheap` เพื่อให้ความสำคัญกับผู้ให้บริการฟรี/ราคาถูก
4. เพิ่มผู้ให้บริการหรือข้อมูลประจำตัวอื่นที่ได้รับอนุญาต โดยไม่ละเมิดข้อกำหนดของผู้ให้บริการ

### "ผู้ให้บริการฟรีมีคุณภาพแย่กว่าหรือไม่?"

ไม่จำเป็นเสมอไป ผู้ให้บริการบางรายเปิดให้ใช้ตระกูลโมเดลเดียวกับที่มีให้บริการผ่าน
เส้นทางแบบชำระเงิน แต่ขีดจำกัด เวลาแฝง ความเป็นส่วนตัว ความน่าเชื่อถือ และเวอร์ชันโมเดลอาจแตกต่างกัน ใช้หน้า
การจัดอันดับผู้ให้บริการฟรีเป็นตัวบ่งชี้คุณภาพ และตรวจสอบโมเดลที่ให้บริการจริง
