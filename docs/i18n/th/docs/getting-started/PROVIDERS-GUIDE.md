> **สรุปสั้นๆ**: ผู้ให้บริการคือการเชื่อมต่อกับบริการ AI (เช่น OpenAI, Anthropic, Google) คุณต้องมีผู้ให้บริการอย่างน้อยหนึ่งรายเพื่อใช้งาน OmniRoute

---

## ผู้ให้บริการคืออะไร?

ให้นึกถึงผู้ให้บริการว่าเป็นเหมือน **ผู้ให้บริการเครือข่ายโทรศัพท์** เช่นเดียวกับที่คุณต้องมีผู้ให้บริการเครือข่ายโทรศัพท์เพื่อโทรออก คุณก็ต้องมีผู้ให้บริการ AI เพื่อใช้งานโมเดล AI เช่นกัน OmniRoute เปรียบเสมือนโทรศัพท์ที่ใช้งานได้กับ **ทุกเครือข่าย** — คุณสามารถสลับระหว่างผู้ให้บริการเหล่านั้นได้โดยอัตโนมัติ

### ประเภทของผู้ให้บริการ

| ประเภท         | คืออะไร                    | ตัวอย่าง                          | ค่าใช้จ่าย          |
| -------------- | -------------------------- | --------------------------------- | ------------------- |
| **ฟรี**        | ไม่ต้องชำระเงิน            | Kiro, OpenCode Free, Pollinations | $0                  |
| **API Key**    | คุณต้องมี API key          | OpenAI, Anthropic, Google         | จ่ายตามการใช้งาน    |
| **OAuth**      | เข้าสู่ระบบด้วยบัญชีของคุณ | Claude Code, GitHub Copilot       | การสมัครสมาชิก      |
| **Web Cookie** | ใช้เซสชันของเบราว์เซอร์คุณ | ChatGPT Web (Codex), Gemini Web   | $0 (ใช้บัญชีของคุณ) |

### ผู้ให้บริการแบบ Web Cookie

ดูคำแนะนำทั่วไปเกี่ยวกับการตั้งค่า ข้อจำกัด การแก้ไขปัญหา และแนวทางการยืนยันตัวตนเฉพาะสำหรับผู้ให้บริการได้ที่ **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**

## เริ่มต้นอย่างรวดเร็ว: เชื่อมต่อผู้ให้บริการรายแรกของคุณ

### การตั้งค่าผู้ให้บริการฟรีในการใช้งานครั้งแรก (ไม่บังคับ)

ตัวช่วยสร้างสำหรับการใช้งานครั้งแรกมีการ์ด **ตั้งค่าผู้ให้บริการฟรี** โดยเฉพาะ ระบบจะสร้างรายการ
ผู้ให้บริการที่ใช้ได้ในปัจจุบันจากรีจิสทรีผู้ให้บริการที่ไม่ต้องยืนยันตัวตนของ OmniRoute จากนั้นเปิดโอกาสให้คุณตรวจสอบและยกเลิกการเลือก
ผู้ให้บริการแต่ละรายก่อนยืนยัน OmniRoute จะแสดงข้อความเตือนของผู้ให้บริการและลิงก์ไปยังเว็บไซต์
เพื่อให้คุณตรวจสอบข้อกำหนด ความเป็นส่วนตัว ความพร้อมให้บริการ และขีดจำกัดอัตราการใช้งานของบุคคลที่สามก่อน

การดำเนินการนี้ไม่บังคับ: การทำตัวช่วยสร้างจนเสร็จจะไม่สร้างการเชื่อมต่อกับผู้ให้บริการฟรีโดยไม่แจ้งให้ทราบ
ระบบจะสร้างเฉพาะผู้ให้บริการที่ยังไม่มี ปล่อยการเชื่อมต่อเดิมที่ปรับแต่งไว้
โดยไม่เปลี่ยนแปลง และรายงานผู้ให้บริการที่สร้างแล้ว กำหนดค่าไว้แล้ว และล้มเหลวแยกกัน คุณสามารถ
ลองใหม่เฉพาะรายการที่ล้มเหลวได้อย่างปลอดภัยหลังจากได้ผลลัพธ์บางส่วน

### ตัวเลือก A: ผู้ให้บริการฟรี (ไม่ต้องใช้บัตรเครดิต)

1. เปิดแดชบอร์ดที่ `http://localhost:20128`
2. ไปที่ **ผู้ให้บริการ** → **เพิ่มผู้ให้บริการ**
3. เลือกผู้ให้บริการฟรีรายใดรายหนึ่งต่อไปนี้:
   - **Kiro AI** — โมเดล Claude ฟรี (ไม่ต้องยืนยันตัวตน)
   - **OpenCode Free** — โมเดล GPT ฟรี (ไม่ต้องยืนยันตัวตน)
   - **Pollinations** — GPT-5, Claude, Gemini ฟรี (ไม่ต้องใช้คีย์)
   - **LongCat** — โทเค็นฟรี 10M (ให้สิทธิ์ครั้งเดียว ต้องมีบัญชี + KYC)
   - **Cloudflare AI** — มากกว่า 50 โมเดล, 10K นิวรอน/วัน
   - **MLX Gemma 26B** — โมเดล Apple Silicon ภายในเครื่อง (~38.5 โทเค็น/วินาที, RAM ~15.9GB)
   - **MLX Qwen 3.8 27B** — โมเดล Apple Silicon ภายในเครื่อง (~9.1 โทเค็น/วินาที, RAM ~13.1GB)
4. คลิก **เชื่อมต่อ**
5. เรียบร้อย! ตอนนี้คุณสามารถใช้งาน AI ได้ฟรีแล้ว

### ตัวเลือก B: ผู้ให้บริการแบบ API Key (มีค่าใช้จ่าย)

1. รับ API key จากเว็บไซต์ของผู้ให้บริการ:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. เปิดแดชบอร์ดที่ `http://localhost:20128`
3. ไปที่ **ผู้ให้บริการ** → **เพิ่มผู้ให้บริการ**
4. เลือกผู้ให้บริการของคุณ
5. วาง API key ของคุณ
6. คลิก **เชื่อมต่อ**
7. เรียบร้อย! ตอนนี้คุณสามารถเข้าถึงโมเดลของผู้ให้บริการรายนั้นได้แล้ว

### ตัวเลือก C: ผู้ให้บริการแบบ OAuth (การสมัครสมาชิก)

1. เปิดแดชบอร์ดที่ `http://localhost:20128`
2. ไปที่ **ผู้ให้บริการ** → **เพิ่มผู้ให้บริการ**
3. เลือกผู้ให้บริการของคุณ (เช่น Claude Code, GitHub Copilot)
4. คลิก **เชื่อมต่อด้วย OAuth**
5. เข้าสู่ระบบด้วยบัญชีของคุณ
6. เรียบร้อย! ตอนนี้คุณสามารถเข้าถึงโมเดลที่รวมอยู่ในการสมัครสมาชิกของคุณได้แล้ว

### ตัวเลือก D: โมเดล MLX ภายในเครื่อง (Apple Silicon)

สำหรับ Mac ที่ใช้ Apple Silicon พร้อมหน่วยความจำแบบรวม OmniRoute รองรับการเชื่อมต่อกับโมเดล MLX ภายในเครื่องที่ทำงานผ่าน `mlx-lm.server` ในฐานะผู้ให้บริการภายในเครื่องที่เข้ากันได้กับ OpenAI ตามปกติ

#### ข้อกำหนดเบื้องต้น

- **Mac ที่ใช้ Apple Silicon** (M1/M2/M3/M4) แนะนำให้มีหน่วยความจำแบบรวม 24GB ขึ้นไป
- ตัวจัดการแพ็กเกจ **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### เริ่มต้นอย่างรวดเร็ว

1. **ติดตั้งการขึ้นต่อกัน**:

   ```bash
   # ติดตั้ง uv หากยังไม่ได้ติดตั้ง
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # ติดตั้ง mlx-lm
   uv pip install mlx-lm
   ```

2. **เริ่มเซิร์ฟเวอร์ MLX ด้วยตนเอง** (ในเทอร์มินัลแยกกัน):

   ```bash
   # เทอร์มินัล 1: Gemma 4 26B A4B IT-QAT (พอร์ต 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # เทอร์มินัล 2: Qwen 3.8 27B MLX Mixed (พอร์ต 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **เชื่อมต่อในแดชบอร์ด OmniRoute**:
   - ไปที่ **ผู้ให้บริการ** → **เพิ่มผู้ให้บริการ**
   - เลือก **MLX Gemma 26B** หรือ **MLX Qwen 3.8 27B**
   - คลิก **เชื่อมต่อ** (ไม่ต้องใช้ API key)

4. **ใช้งานร่วมกับ OpenCode**:
   ```bash
   # กำหนดค่า OpenCode ให้ใช้ OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # ใช้โมเดล MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### การจัดการหน่วยความจำ

**สำคัญ**: เมื่อมีหน่วยความจำแบบรวม 24GB จะสามารถเรียกใช้ **โมเดล MLX ขนาดใหญ่ได้ครั้งละหนึ่งโมเดลเท่านั้น**

- Gemma 26B: ใช้หน่วยความจำสูงสุด ~15.9GB
- Qwen 3.8 27B: ใช้หน่วยความจำสูงสุด ~13.1GB

คุณต้องจัดการเรื่องนี้ด้วยตนเอง:

- เรียกใช้เซิร์ฟเวอร์ MLX เพียงหนึ่งเซิร์ฟเวอร์ต่อครั้ง หรือ
- เรียกใช้ทั้งสองเซิร์ฟเวอร์บนเครื่องที่แยกจากกัน หรือ
- หยุดเซิร์ฟเวอร์หนึ่งก่อนเริ่มอีกเซิร์ฟเวอร์หนึ่ง

OmniRoute ไม่ได้จัดการโปรเซสของเซิร์ฟเวอร์ MLX โดยอัตโนมัติ — ระบบเพียงกำหนดเส้นทางคำขอไปยังปลายทางที่เข้ากันได้กับ OpenAI ซึ่งคุณกำหนดค่าไว้เท่านั้น

#### การรองรับการเรียกใช้เครื่องมือ

ทั้งสองโมเดลรองรับการเรียกใช้เครื่องมือที่เข้ากันได้กับ OpenAI ทดสอบด้วย:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### การแก้ไขปัญหา

| ปัญหา                        | วิธีแก้ไข                                                                                |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| เซิร์ฟเวอร์ไม่เริ่มทำงาน     | ตรวจสอบ `uv run mlx_lm.server --help` และยืนยัน ID ของโมเดล                              |
| หน่วยความจำไม่เพียงพอ        | ตรวจสอบให้แน่ใจว่ามีเพียงโมเดลเดียวที่ทำงานอยู่ ปิดแอปอื่น ๆ และตรวจสอบ Activity Monitor |
| การเชื่อมต่อถูกปฏิเสธ        | ตรวจสอบว่าเซิร์ฟเวอร์กำลังทำงานบนพอร์ตที่ถูกต้อง (11435/11436)                           |
| ตอบสนองช้า                   | คำขอแรกจะโหลดโมเดลเข้าสู่หน่วยความจำ (~30-60 วินาที) คำขอถัดไปจะทำงานได้รวดเร็ว          |
| การเรียกใช้เครื่องมือล้มเหลว | ตรวจสอบว่าโมเดลรองรับเครื่องมือ และตรวจสอบบันทึกของ OmniRoute เพื่อหาข้อผิดพลาดในการแปล  |

## ผู้ให้บริการฟรีที่ดีที่สุด

ผู้ให้บริการเหล่านี้มอบ **การเข้าถึงฟรี** โดยไม่ต้องใช้บัตรเครดิต:

## วิธีเชื่อมต่อผู้ให้บริการ (ทีละขั้นตอน)

### ขั้นตอนที่ 1: เปิดแดชบอร์ด

ไปที่ `http://localhost:20128` ในเบราว์เซอร์ของคุณ

### ขั้นตอนที่ 2: ไปที่ผู้ให้บริการ

คลิก **ผู้ให้บริการ** ในแถบด้านข้าง

### ขั้นตอนที่ 3: คลิกเพิ่มผู้ให้บริการ

คลิกปุ่ม **+ เพิ่มผู้ให้บริการ**

### ขั้นตอนที่ 4: เลือกผู้ให้บริการของคุณ

เรียกดูรายการหรือค้นหาผู้ให้บริการของคุณ จากนั้นคลิกที่ผู้ให้บริการนั้น

### ขั้นตอนที่ 5: ป้อนข้อมูลประจำตัว

- **ผู้ให้บริการฟรี**: ไม่ต้องใช้ข้อมูลประจำตัว — เพียงคลิก **เชื่อมต่อ**
- **ผู้ให้บริการที่ใช้ API key**: วาง API key ของคุณ
- **ผู้ให้บริการ OAuth**: คลิก **เชื่อมต่อด้วย OAuth** และเข้าสู่ระบบ

### ขั้นตอนที่ 6: ทดสอบการเชื่อมต่อ

คลิก **ทดสอบการเชื่อมต่อ** เพื่อตรวจสอบว่าทำงานได้

### ขั้นตอนที่ 7: เสร็จสิ้น!

ตอนนี้ผู้ให้บริการของคุณเชื่อมต่อแล้ว คุณสามารถใช้งานด้วย `model: "auto"` หรือระบุผู้ให้บริการโดยตรง

## การใช้ผู้ให้บริการหลายราย

OmniRoute ทำงานได้ดีที่สุดเมื่อใช้ **ผู้ให้บริการหลายราย** ซึ่งช่วยให้คุณได้รับ:

- **การสลับไปใช้ผู้ให้บริการสำรองโดยอัตโนมัติ** — หากผู้ให้บริการรายหนึ่งล้มเหลว OmniRoute จะลองใช้รายถัดไป
- **การปรับค่าใช้จ่ายให้เหมาะสม** — OmniRoute เลือกผู้ให้บริการที่มีราคาถูกที่สุดสำหรับแต่ละคำขอ
- **การปรับความเร็วให้เหมาะสม** — OmniRoute เลือกผู้ให้บริการที่เร็วที่สุดสำหรับแต่ละคำขอ
- **การปรับคุณภาพให้เหมาะสม** — OmniRoute เลือกผู้ให้บริการที่ดีที่สุดสำหรับแต่ละงาน

### การตั้งค่าที่แนะนำ

เชื่อมต่อผู้ให้บริการอย่างน้อย **3 ราย** เพื่อประสบการณ์การใช้งานที่ดีที่สุด:

1. **ผู้ให้บริการฟรีหนึ่งราย** (Kiro, OpenCode Free หรือ Pollinations) — พร้อมใช้งานเสมอ
2. **ผู้ให้บริการที่รวดเร็วหนึ่งราย** (Groq, Cerebras) — สำหรับการตอบกลับอย่างรวดเร็ว
3. **ผู้ให้บริการคุณภาพสูงหนึ่งราย** (OpenAI, Anthropic, Google) — สำหรับงานที่ซับซ้อน

จากนั้นใช้ `model: "auto"` แล้ว OmniRoute จะเลือกผู้ให้บริการที่ดีที่สุดสำหรับแต่ละคำขอโดยอัตโนมัติ

## คำถามที่พบบ่อย

### "ฉันต้องจ่ายเงินเพื่อใช้ OmniRoute หรือไม่?"

**ไม่ต้อง!** OmniRoute ใช้งานได้ฟรีและเป็นโอเพนซอร์ส คุณสามารถใช้ผู้ให้บริการฟรี (Kiro, OpenCode Free, Pollinations) ได้โดยไม่ต้องเสียค่าใช้จ่ายใดๆ คุณจะจ่ายเงินเฉพาะเมื่อเลือกใช้ผู้ให้บริการแบบเสียค่าใช้จ่ายเท่านั้น

### "ฉันควรเริ่มต้นกับผู้ให้บริการรายใด?"

เริ่มต้นด้วย **Kiro AI** — ใช้งานได้ฟรี ไม่ต้องใช้คีย์ API และช่วยให้คุณเข้าถึงโมเดล Claude ได้ จากนั้นจึงเพิ่มผู้ให้บริการอื่นๆ ตามต้องการ

### "ฉันสามารถใช้ผู้ให้บริการหลายรายพร้อมกันได้หรือไม่?"

**ได้!** นั่นคือจุดประสงค์หลักของ OmniRoute เชื่อมต่อผู้ให้บริการหลายรายและใช้ `model: "auto"` เพื่อให้ OmniRoute เลือกผู้ให้บริการที่ดีที่สุดสำหรับแต่ละคำขอ

### "จะเกิดอะไรขึ้นหากผู้ให้บริการหยุดให้บริการ?"

OmniRoute จะข้ามผู้ให้บริการที่ล้มเหลวโดยอัตโนมัติและลองใช้รายถัดไป คุณไม่จำเป็นต้องดำเนินการใดๆ

### "ฉันจะยกเลิกการเชื่อมต่อผู้ให้บริการได้อย่างไร?"

ไปที่ผู้ให้บริการ → คลิกผู้ให้บริการ → คลิก **ยกเลิกการเชื่อมต่อ**

### "ฉันสามารถใช้คีย์ API ที่มีอยู่แล้วได้หรือไม่?"

**ได้!** หากคุณมีคีย์ API สำหรับ OpenAI, Anthropic, Google และอื่นๆ อยู่แล้ว คุณสามารถใช้คีย์เหล่านั้นใน OmniRoute ได้ เพียงวางคีย์เมื่อเชื่อมต่อผู้ให้บริการ
