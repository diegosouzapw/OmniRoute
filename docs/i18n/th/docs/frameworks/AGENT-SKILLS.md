> **แหล่งข้อมูลหลัก:** `src/lib/agentSkills/` (แค็ตตาล็อก ตัวสร้าง และตัวแยกวิเคราะห์) + ไดเรกทอรี `skills/` (ไฟล์ SKILL.md)
> **อัปเดตล่าสุด:** 2026-08-02 — v3.8.50

Agent Skills คือไฟล์ SKILL.md ที่มีโครงสร้าง ซึ่งสอนเอเจนต์ภายนอก ไคลเอนต์ MCP และตัวประสานงาน A2A ให้ใช้งาน REST API และ CLI ของ OmniRoute แตกต่างจาก [Omni Skills](./SKILLS.md) (ซึ่งเป็นข้อกำหนดเครื่องมือ LLM ที่ทำงานภายใน OmniRoute) โดย Agent Skills เป็น _แค็ตตาล็อกเอกสาร_ — markdown แบบคงที่ที่สามารถป้อนเข้าสู่บริบทของเอเจนต์ได้โดยตรง

---

## ภาพรวม

แค็ตตาล็อกประกอบด้วย **Agent Skills 45 รายการ** (REST API 23 รายการ + CLI 21 รายการ + เวิร์กโฟลว์การกำหนดค่า 1 รายการ) แต่ละสกิลประกอบด้วย:

- **ID มาตรฐาน** (`omni-auth`, `cli-serve` ฯลฯ)
- ไฟล์ **SKILL.md** ใน `skills/{id}/SKILL.md` พร้อม YAML frontmatter (`name`, `description`) + เนื้อหา markdown โดยละเอียด
- **REST endpoints** (สกิล API) หรือ **CLI subcommands** (สกิล CLI) ที่ได้มาจากข้อกำหนด OpenAPI และรีจิสทรี CLI
- **GitHub raw URL** สำหรับดึงข้อมูลสด: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

```

  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() เขียน SKILL.md ไปยัง skills/{id}/
  openapiParser.ts                     — แยก REST endpoints จาก docs/openapi.yaml
  cliRegistryParser.ts                 — แยก CLI subcommands จาก bin/cli-registry.ts
  schemas.ts                           — สคีมา Zod: AgentSkillSchema, SkillCoverageSchema ฯลฯ
  types.ts                             — อินเทอร์เฟซ TypeScript: AgentSkill, SkillCoverage ฯลฯ

skills/{id}/SKILL.md                   — ไฟล์ markdown ที่สร้างขึ้น + คัดสรรแล้ว (รวม 45 ไฟล์)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}

src/lib/a2a/skills/listCapabilities.ts        — สกิล A2A: list-capabilities
```

## การค้นหา REST API

| Endpoint                     | Method | Description                                                              | Auth      |
| :--------------------------- | :----- | :----------------------------------------------------------------------- | :-------- |
| `/api/agent-skills`          | GET    | แสดงรายการแค็ตตาล็อก (ระบุ `?category=api\|cli\|config&area=<area>` ได้) | ไม่มี     |
| `/api/agent-skills/{id}`     | GET    | รับข้อมูลเมตาของสกิลรายการเดียว                                          | ไม่มี     |
| `/api/agent-skills/{id}/raw` | GET    | ดึงข้อมูล SKILL.md ในรูปแบบ `text/markdown`                              | ไม่มี     |
| `/api/agent-skills/coverage` | GET    | สถิติความครอบคลุม (จำนวนไฟล์ SKILL.md ที่มีอยู่)                         | ไม่มี     |
| `/api/agent-skills/generate` | POST   | เรียกใช้ตัวสร้าง (dryRun/prune/onlyIds)                                  | การจัดการ |

ตัวอย่าง — แสดงรายการสกิล API ทั้งหมด:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ตัวอย่าง — ดึงข้อมูล SKILL.md รายการเดียว:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## การค้นหา A2A

สกิล A2A `list-capabilities` จะส่งคืนแค็ตตาล็อกสกิลทั้ง 45 รายการในรูปแบบอาร์ติแฟกต์ตาราง markdown ตัวประสานงานภายนอกสามารถเรียกใช้ได้ผ่าน:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

ดูรายละเอียดโปรโตคอลได้ที่ [A2A-SERVER.md](./A2A-SERVER.md)

## วิธีที่เอเจนต์ภายนอกใช้ Skills

### 1. การค้นหาผ่าน REST

```bash
# รับแค็ตตาล็อกทั้งหมด
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# รับ SKILL.md สำหรับแทรกบริบท
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. การค้นหาผ่าน MCP

```typescript
// ในไคลเอนต์ MCP ของ Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → อาร์เรย์ของ AgentSkill ซึ่งแต่ละรายการมี rawUrl
```

### 3. การค้นหาผ่าน A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table คือตารางมาร์กดาวน์ที่มี ID ของ skill ทั้ง 45 รายการ พร้อมคอลัมน์ rawUrl
```

### 4. การดึงข้อมูลดิบจาก GitHub โดยตรง (ไม่จำเป็นต้องมีเซิร์ฟเวอร์)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## ตัวสร้าง

ตัวสร้างจะอ่านแค็ตตาล็อกที่คัดสรรแล้ว + ข้อกำหนด OpenAPI + รีจิสทรี CLI และเขียน `skills/{id}/SKILL.md` สำหรับแต่ละรายการ:

```bash
# แสดงตัวอย่าง (ทดลองทำงานโดยไม่มีการเขียนไฟล์)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# สร้างใหม่ทั้งหมด
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# สร้างใหม่เฉพาะ ID ที่ระบุ
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

การตอบกลับจากตัวสร้างเป็น `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
