## ภาพรวม

Playground Studio ยกระดับ `/dashboard/playground` จากเอดิเตอร์พื้นฐานที่ใช้ Monaco ให้เป็น
พื้นที่ทำงานสำหรับการทดสอบที่มีฟีเจอร์ครบครัน โดยแทนที่ `page.tsx` แบบเดิมด้วยเชลล์ `PlaygroundStudio`
ที่แสดงผลสี่แท็บและแผงการกำหนดค่าที่ใช้ร่วมกัน

## แท็บ

### แท็บแชต

พัฒนา `ChatPlayground.tsx` ให้เป็นพื้นที่ทำงานแบบสตรีมที่รองรับการสนทนาหลายรอบ:

- แสดงผล Markdown อย่างสมบูรณ์ผ่าน `MarkdownMessage.tsx` (บล็อกโค้ด ตาราง รายการ และลิงก์)
- ใช้พรอมต์ระบบจากแผงการกำหนดค่าที่ใช้ร่วมกัน
- แสดงจำนวนโทเค็น/ค่าใช้จ่ายต่อข้อความ (โทเค็นพรอมต์ + โทเค็นคำตอบ)
- สร้างคำตอบล่าสุดใหม่
- ส่งไปยัง `POST /v1/chat/completions` พร้อมการสตรีมแบบ SSE

### แท็บเปรียบเทียบ

จุดเด่นสำคัญสำหรับพร็อกซี: เรียกใช้ 1 พรอมต์กับโมเดลสูงสุด **4 โมเดลพร้อมกัน**

- รองรับสูงสุด 4 คอลัมน์ โดยแต่ละคอลัมน์สตรีมจาก `/v1/chat/completions` อย่างเป็นอิสระ
- ปุ่ม `+ เพิ่มโมเดล` (ปุ่มลัด Cmd+K) สำหรับเพิ่มคอลัมน์
- `เรียกใช้ทั้งหมด ▶` เริ่มต้นสตรีมทั้งหมดพร้อมกันผ่าน `Promise.all` + `AbortController` แยกต่อคอลัมน์
- **ยกเลิกทั้งหมด** แบบส่วนกลางจะยกเลิกทุกสตรีมที่กำลังดำเนินการ
- `ProviderMetrics` ประจำแต่ละคอลัมน์แสดง TTFT, TPS, จำนวนโทเค็น และค่าใช้จ่ายโดยประมาณแบบเรียลไทม์
- เมตริกมีป้ายกำกับว่า **"ค่าประมาณจากฝั่งไคลเอนต์"** (D12) — วัดจาก SSE chunk แรก

### แท็บ API

คงเอดิเตอร์ Monaco เดิมไว้ครบ 100% สำหรับผู้ใช้ระดับสูง (D14):

- 10 ปลายทาง: การเติมข้อความแชต การเติมข้อความ embeddings รูปภาพ เสียง เสียงพูด การถอดเสียง การกลั่นกรอง การจัดอันดับใหม่ และการค้นหา
- อัปโหลดไฟล์แบบมัลติโมดัล
- การสตรีมแบบ SSE พร้อมเอาต์พุตแบบเรียลไทม์
- ห่อหุ้มเป็น `ApiTab.tsx` (โหลดแบบ lazy, `ssr: false`)

### แท็บสร้าง

UI สำหรับเครื่องมือ/การเรียกใช้ฟังก์ชันและเอาต์พุตแบบมีโครงสร้าง:

- `ToolsBuilder.tsx` — เพิ่ม/แก้ไข/ลบ `tools[]` พร้อมเอดิเตอร์ JSON schema สำหรับแต่ละเครื่องมือ
  ตรวจสอบความถูกต้องของพารามิเตอร์ผ่าน `ToolDefinitionSchema` (Zod)
- `StructuredOutputEditor.tsx` — สลับเปิด-ปิดโหมด JSON + เอดิเตอร์ JSON schema
  ตรวจสอบความถูกต้องของการตอบกลับเทียบกับ schema ผ่าน `StructuredOutputSchema` (Zod)
- ส่งคำขอไปยัง `/v1/chat/completions` พร้อม `tools[]` และ/หรือ `response_format`

## แผงการกำหนดค่า (ใช้ร่วมกัน)

`StudioConfigPane.tsx` — แสดงอยู่เสมอและสามารถยุบได้

| ฟิลด์            | คอมโพเนนต์            | หมายเหตุ                                                               |
| ---------------- | --------------------- | ---------------------------------------------------------------------- |
| เอนด์พอยต์       | `<select>`            | ตัวเลือก 10 รายการที่ตรงกับ `PlaygroundEndpoint`                       |
| โมเดล            | `<input>`             | ข้อความอิสระ เช่น `openai/gpt-4o`                                      |
| พรอมป์ต์ระบบ     | `<textarea>`          | ส่งไปยังแท็บทั้งหมด                                                    |
| พารามิเตอร์      | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop |
| พรีเซ็ต          | `PresetPicker`        | โหลด/บันทึกสแนปช็อตการกำหนดค่าที่มีชื่อ (จัดเก็บถาวรใน DB)             |
| ปรับปรุงพรอมป์ต์ | `ImprovePromptButton` | เปิดโมดัลเตือนเกี่ยวกับโควตา และเรียก `/api/playground/improve-prompt` |

จะคงสถานะการกำหนดค่าไว้

## เครื่องมือปรับปรุงพรอมป์ต์

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. โมดัลเตือนว่า "จะใช้โควตา"
2. เมื่อยืนยัน จะส่ง `{ system, prompt, model, tone }` ไปยังเส้นทาง
3. เส้นทางเรียก `/v1/chat/completions` ภายในโดยใช้ `promptImprover.META_SYSTEM_PROMPT`
4. ส่งคืน `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`
5. UI อัปเดตพรอมป์ต์ระบบในแผงการกำหนดค่าและพรอมป์ต์ผู้ใช้ในแท็บแชต

## พรีเซ็ต

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- จัดเก็บในตาราง SQLite `playground_presets` (การย้ายข้อมูล `084_playground_presets.sql`)
- แต่ละพรีเซ็ตจัดเก็บ: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`
- CRUD: รายการ `GET`, สร้าง `POST`, `GET /:id`, `PUT /:id`, `DELETE /:id`

---

## เมตริกสตรีม

`useStreamMetrics.ts` + `streamMetrics.ts` (ฟังก์ชันบริสุทธิ์):

- `start()` — บันทึกเวลาเริ่มต้นของคำขอ
- `onFirstChunk()` — บันทึก TTFT
- `onChunk(n)` — สะสมจำนวนโทเค็นการตอบกลับ
- `finish(usage?)` — คำนวณเมตริกสุดท้าย: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`
- ราคามาจากตารางแบบคงที่ใน `src/lib/playground/types.ts` (ระบุว่า "โดยประมาณ" — D13)

## เส้นทางแบ็กเอนด์

| เมธอด    | พาธ                              | ตัวจัดการ                                                                                                      |
| -------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | ตรวจสอบความถูกต้องด้วย Zod โดยใช้ `ImprovePromptRequestSchema`; เรียก `/v1/chat/completions` พร้อมเมตาพรอมป์ต์ |
| `GET`    | `/api/playground/presets`        | ส่งคืน `{ presets: PlaygroundPresetListItem[] }`                                                               |
| `POST`   | `/api/playground/presets`        | สร้างพรีเซ็ต; ตรวจสอบความถูกต้องด้วย `PlaygroundPresetCreateSchema`                                            |
| `GET`    | `/api/playground/presets/:id`    | ส่งคืนพรีเซ็ตหนึ่งรายการหรือ 404                                                                               |
| `PUT`    | `/api/playground/presets/:id`    | อัปเดตบางส่วน                                                                                                  |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                            |

การยืนยันตัวตน: ไม่บังคับ (`REQUIRE_API_KEY`) ข้อผิดพลาดผ่าน `buildErrorBody()` (กฎตายตัว #12)
