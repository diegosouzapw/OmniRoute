## คืออะไร

Local Corpus ช่วยให้ผู้ดูแลระบบสามารถเปิดเผยไดเรกทอรีไฟล์ข้อความหนึ่งรายการที่ได้รับการอนุมัติอย่างชัดเจนให้กับเซิร์ฟเวอร์ MCP ของ OmniRoute ได้ ไฟล์ต่าง ๆ ยังคงอยู่ในไดเรกทอรีเดิม โดย OmniRoute จะจัดเก็บเฉพาะพาธรากแบบมาตรฐานใน SQLite และดูแลดัชนีการค้นหาในหน่วยความจำเท่านั้น ระบบจะไม่คัดลอกเนื้อหาคลังข้อมูลเข้าไปในรีโพซิทอรีหรือฐานข้อมูล

การรีเฟรชดัชนีเป็นแบบเพิ่มส่วน เฉพาะไฟล์ที่ไม่มีการเปลี่ยนแปลงจะถูกนำกลับมาใช้ใหม่โดยพิจารณาจากขนาดและเวลาแก้ไข ส่วนไฟล์ที่มีการเปลี่ยนแปลงจะถูกอ่านใหม่และแฮชด้วย SHA-256 ขณะที่ไฟล์ที่ถูกลบจะถูกนำออก การค้นหาจะรีเฟรชดัชนีที่มีอายุเกิน 30 วินาที และผู้เรียกยังสามารถร้องขอให้รีเฟรชทันทีได้อีกด้วย

## กำหนดค่าแหล่งข้อมูล

เส้นทางการตั้งค่าต้องใช้การยืนยันตัวตนระดับการจัดการแบบเดียวกับ API การตั้งค่าอื่น ๆ พาธที่ส่งเข้ามาต้องมีอยู่แล้วและต้องเป็นพาธไดเรกทอรีแบบสัมบูรณ์

```bash
# เชื่อมต่อไดเรกทอรีที่ได้รับอนุมัติ
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# ตรวจสอบการกำหนดค่าและสถานะดัชนี
curl http://localhost:20128/api/settings/local-corpus

# ยกเลิกการเชื่อมต่อโดยไม่แก้ไขไฟล์ต้นทาง
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## เครื่องมือ MCP

เครื่องมือทั้งสามรายการต้องใช้ `read:local-corpus` การตอบกลับของเครื่องมือจะแสดงพาธสัมพัทธ์และชื่อฐานของไดเรกทอรีราก โดยจะไม่แสดงพาธสัมบูรณ์

| เครื่องมือ            | คำอธิบาย                                                                                        |
| :-------------------- | :---------------------------------------------------------------------------------------------- |
| `local_corpus_status` | รายงานสถานะการกำหนดค่า ขนาดดัชนี ขีดจำกัด และเวลารีเฟรชล่าสุด                                   |
| `local_corpus_search` | ค้นหาข้อความที่จัดทำดัชนีไว้และส่งคืนข้อความตัวอย่างแบบจำกัดขอบเขตตามบรรทัด (สูงสุด 20 ผลลัพธ์) |
| `local_corpus_read`   | อ่านช่วงบรรทัดที่จำกัดจากไฟล์หนึ่งรายการที่ได้รับอนุญาตซึ่งใช้พาธสัมพัทธ์กับคลังข้อมูล          |

ตัวอย่างอินพุต MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## ขอบเขตด้านความปลอดภัย

- รายการที่อนุญาตเน้นไฟล์ข้อความ ได้แก่ `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` และ `.yml`
- ลิงก์สัญลักษณ์จะถูกข้าม พาธสำหรับอ่านจะถูกแปลงเป็นรูปแบบมาตรฐานและต้องยังคงอยู่ภายใน
  รากที่กำหนดค่าไว้ ส่วนพาธสัมบูรณ์และความพยายามเข้าถึงพาธนอกขอบเขตจะถูกปฏิเสธ
- ชื่อไดเรกทอรีที่มีข้อมูลละเอียดอ่อนและไดเรกทอรีที่สร้างขึ้นโดยระบบจะถูกยกเว้น ได้แก่ `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` และ
  `secrets`
- ขีดจำกัดเริ่มต้นคือ 5,000 ไฟล์, 1 MiB ต่อไฟล์, เนื้อหาที่จัดทำดัชนีรวม 64 MiB,
  ประมาณ 4,000 อักขระต่อส่วนการค้นหา และ 400 บรรทัดต่อการอ่าน
- ไฟล์ที่มีอักขระ NUL จะถือว่าไม่ใช่ข้อความและจะถูกข้ามหรือปฏิเสธ

ระบบตั้งใจไม่รองรับเอกสารไบนารี เช่น PDF, DOCX, รูปภาพ และไฟล์บีบอัด โปรดแปลงไฟล์เหล่านี้เป็นรูปแบบข้อความที่ได้รับอนุมัติภายในไดเรกทอรีที่กำหนดค่าไว้ก่อนจัดทำดัชนี

## หมายเหตุด้านการปฏิบัติงาน

- การเปลี่ยนหรือลบรากที่กำหนดค่าไว้จะล้างดัชนีในหน่วยความจำที่ใช้ร่วมกัน
- การเริ่มกระบวนการใหม่จะทิ้งดัชนีเดิม และการค้นหาครั้งถัดไปจะสร้างดัชนีใหม่จากแหล่งข้อมูลที่กำหนดค่าไว้
- `local_corpus_status` จะไม่บังคับให้สแกน ใช้ `local_corpus_search` พร้อม
  `refresh: true` เมื่อต้องการสแกนใหม่ทันที
- ความล้มเหลวในการสแกนและการอ่านจะถูกนับหรือส่งคืนเป็นข้อผิดพลาดที่ผ่านการกรองข้อมูลละเอียดอ่อนแล้ว โดยไฟล์ต้นทาง
  จะไม่ถูกแก้ไขเด็ดขาด
