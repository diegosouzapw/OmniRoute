> อยู่ใน `open-sse/mcp-server/server.ts`

## คืออะไร

OmniRoute สามารถเชื่อมต่อกับเวิร์กสเปซ **Notion** ในฐานะ **แหล่งบริบท** — ฐานความรู้
แบบอ่าน/เขียนที่เอเจนต์เข้าถึงผ่านเซิร์ฟเวอร์ MCP ในตัว เมื่อกำหนดค่าโทเค็นการผสานรวม
Notion แล้ว เครื่องมือ MCP จะช่วยให้ LLM ค้นหาเพจและฐานข้อมูล อ่านเนื้อหาเพจและ
โครงสร้างบล็อก สืบค้นฐานข้อมูลด้วยตัวกรอง/การจัดเรียง และเพิ่มบล็อกใหม่ต่อท้ายได้ —
ทั้งหมดนี้ดำเนินการผ่านพร็อกซีของ OmniRoute (พร้อมการลองใหม่ การหมดเวลา และการจำแนกข้อผิดพลาด)
เพื่อให้โมเดลไม่ต้องเข้าถึง Notion API โดยตรง

การผสานรวมนี้เป็นตัวห่อหุ้มที่บางและเสริมความแข็งแกร่งให้กับ Notion REST API อย่างเป็นทางการ
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) โดยไคลเอนต์
(`src/lib/notion/api.ts`) เพิ่มความสามารถดังต่อไปนี้:

- **การลองใหม่พร้อมการหน่วงเวลาแบบเอ็กซ์โพเนนเชียล** (สูงสุด 3 ครั้ง) สำหรับ `429` และ `5xx`
- **หมดเวลาคำขอใน 55 วินาที** ผ่าน `AbortController`
- **การจำแนกข้อผิดพลาดแบบมีชนิดข้อมูล** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, ปฏิบัติตามคำแนะนำ `retry after`),
  `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`
- **การกรองข้อความ** ซึ่งลบส่วนที่มีลักษณะคล้ายสแต็กเทรซก่อนแสดงผล

## การตั้งค่า

ไม่มี **ตัวแปรสภาพแวดล้อม** สำหรับโทเค็น Notion — โทเค็นจะถูกจัดเก็บไว้ใน
ตาราง SQLite `key_value` (เนมสเปซ `notion`, คีย์ `integration_token`) ผ่าน
`src/lib/db/notion.ts` กำหนดค่าได้จากแท็บ **Context Sources** ของแดชบอร์ด Endpoint
(`NotionSourceCard` ซึ่งเป็นคอมโพเนนต์ระดับเดียวกับ `ObsidianSourceCard`) หรือผ่าน REST API การตั้งค่า

> [!NOTE]
> โทเค็นนี้คือ **โทเค็นการผสานรวมภายในของ Notion** สร้างการผสานรวมได้ที่
> <https://www.notion.com/my-integrations> จากนั้นแชร์เพจ/ฐานข้อมูลที่คุณต้องการให้
> OmniRoute เข้าถึงกับการผสานรวมนั้น (โมเดลสิทธิ์ของ Notion อิงตามการแชร์
> ไม่ใช่การให้สิทธิ์ทั่วทั้งเวิร์กสเปซ)

### กำหนดค่าผ่าน REST

```bash
# บันทึกและตรวจสอบโทเค็นการผสานรวม (POST จะตรวจสอบโดยส่งคำขอค้นหาทดสอบ)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# ตรวจสอบสถานะการเชื่อมต่อ
curl http://localhost:20128/api/settings/notion

# ยกเลิกการเชื่อมต่อ (ล้างโทเค็นที่จัดเก็บไว้)
curl -X DELETE http://localhost:20128/api/settings/notion
```

ทั้งสามเมธอดต้องผ่านการยืนยันตัวตนของแดชบอร์ด (`isAuthenticated`) สำหรับ `POST`
OmniRoute จะบันทึกโทเค็นและเรียกใช้การค้นหาทดสอบที่จำกัดผลลัพธ์ไว้ 1 รายการทันที หาก Notion
ส่งอ็อบเจ็กต์ข้อผิดพลาดกลับมา โทเค็นจะถูกล้างและการเรียกจะล้มเหลวด้วย `400`

## เครื่องมือ MCP (6)

กำหนดไว้ใน `open-sse/mcp-server/tools/notionTools.ts` โทเค็นจะถูกดึงมาในขณะเรียกใช้
ผ่าน `getNotionToken()` หากยังไม่ได้กำหนดค่าโทเค็น เครื่องมือจะส่งข้อผิดพลาด
`"Notion integration token not configured. Set it in Settings > Context Sources."`

| เครื่องมือ                   | ขอบเขต         | คำอธิบาย                                                                                            |
| ---------------------------- | -------------- | --------------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | ค้นหาเพจและฐานข้อมูลด้วยข้อความค้นหา (ส่งคืนชื่อ, ID และ URL) รองรับการแบ่งหน้า                     |
| `notion_get_page`            | `read:notion`  | รับเนื้อหาและข้อมูลเมตาของเพจตาม ID                                                                 |
| `notion_list_block_children` | `read:notion`  | แสดงบล็อกลูกทั้งหมดของบล็อกหรือเพจ (โครงสร้างบล็อก) รองรับการแบ่งหน้า                               |
| `notion_query_database`      | `read:notion`  | สืบค้นฐานข้อมูลโดยใช้ `filter` + `sorts` ซึ่งระบุหรือไม่ก็ได้ (รูปแบบ Notion API) รองรับการแบ่งหน้า |
| `notion_get_database`        | `read:notion`  | รับสคีมา/ข้อมูลเมตาของฐานข้อมูลตาม ID                                                               |
| `notion_append_blocks`       | `write:notion` | เพิ่มบล็อกลูกต่อท้ายบล็อกหรือเพจที่มีอยู่ (สูงสุด 100 บล็อกต่อคำขอ)                                 |

### พารามิเตอร์อินพุต

- `notion_search` — `query` (1–500 อักขระ), `pageSize` (1–100, ค่าเริ่มต้น 20),
  `startCursor` (ไม่บังคับ)
- `notion_get_page` — `pageId` (เลขฐานสิบหก 32 อักขระหรือ UUID)
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, ค่าเริ่มต้น 50),
  `startCursor` (ไม่บังคับ)
- `notion_query_database` — `databaseId`, `filter` (ไม่บังคับ, รูปแบบตัวกรองของ Notion),
  `sorts` (อาร์เรย์ที่ไม่บังคับ), `pageSize` (1–100, ค่าเริ่มต้น 50), `startCursor` (ไม่บังคับ)
- `notion_get_database` — `databaseId`
- `notion_append_blocks` — `blockId`, `children` (อาร์เรย์ของอ็อบเจ็กต์บล็อก),
  `after` (ตำแหน่งที่ไม่บังคับ)

### ขอบเขต

เครื่องมืออ่านต้องใช้ `read:notion` และเครื่องมือเขียนต้องใช้ `write:notion`
ขอบเขตจะถูกบังคับใช้โดย `withScopeEnforcement()` ใน
`open-sse/mcp-server/server.ts` เฉพาะเมื่อ `OMNIROUTE_MCP_ENFORCE_SCOPES=true` เท่านั้น
ขอบเขตที่ผู้เรียกได้รับอนุญาตมาจาก `OMNIROUTE_MCP_SCOPES` (คั่นด้วยเครื่องหมายจุลภาค) หรือ
บริบทขอบเขตของคีย์ API ที่ผ่านการยืนยันตัวตนแล้ว ดูโมเดลขอบเขตฉบับเต็มได้ที่
[MCP-SERVER.md](./MCP-SERVER.md)

> `/v1` แบบสาธารณะ** — ระบบจะเข้าถึง Notion ผ่านเครื่องมือ MCP ข้างต้นเท่านั้น

## กรณีการใช้งาน

- **คำตอบที่อิงฐานความรู้** — ให้เอเจนต์ใช้ `notion_search` ค้นหาในเวิร์กสเปซ และ
  ใช้ `notion_get_page` กับผลลัพธ์อันดับแรกก่อนตอบ เพื่อให้คำตอบอ้างอิงเอกสารภายในจริง
- **เวิร์กโฟลว์ที่ใช้ฐานข้อมูลรองรับ** — ใช้ `notion_query_database` กับฐานข้อมูลงาน/CRM
  พร้อมตัวกรองและการจัดเรียง จากนั้นสรุปหรือคัดแยกแถวข้อมูล
- **การเขียนข้อมูลกลับ / การบันทึกล็อก** — ใช้ `notion_append_blocks` เพื่อเพิ่มบันทึกการประชุม
  สรุปการทำงาน หรือเอาต์พุตของเอเจนต์ลงในเพจที่มีอยู่ (เพิ่มต่อท้ายเท่านั้น ไม่มีการแก้ไขแบบทำลายข้อมูล)
- **การสำรวจโครงสร้าง** — ใช้ `notion_list_block_children` เพื่อสำรวจโครงสร้างแบบต้นไม้ของบล็อกในเพจ
  หรือใช้ `notion_get_database` เพื่อค้นหาสคีมาคุณสมบัติของฐานข้อมูลก่อนสืบค้น
