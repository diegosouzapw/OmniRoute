OmniRoute แยกข้อมูลเทเลเมทรีโควตาของผู้ให้บริการออกจากการคำนวณบัญชีของ Ghostlight

## สถานะที่ตรงตามความเป็นจริง

- `healthy` หมายถึงแหล่งข้อมูลรายงานว่ามีความจุคงเหลือที่พร้อมใช้งาน
- `approaching_limit` หมายถึงแหล่งข้อมูลรายงานว่าความจุคงเหลือเท่ากับหรือต่ำกว่าเกณฑ์ที่กำหนดค่าไว้
- `exhausted` จะถูกส่งออกเฉพาะเมื่อแหล่งข้อมูลรายงานว่าความจุเป็นศูนย์หรือการใช้งานถึงขีดจำกัดแล้ว
- `unavailable` หมายถึงแหล่งข้อมูลที่รองรับไม่สามารถส่งคืนข้อมูลได้
- `unknown` หมายถึงไม่มีแหล่งข้อมูลที่รองรับ หรือไม่ทราบขีดจำกัดของผู้ให้บริการ

สถานะ Unknown ไม่ใช่สถานะ exhausted และจะไม่ปิดใช้งานผู้ให้บริการ

ระบบจะเลือกใช้แหล่งข้อมูลตามลำดับต่อไปนี้: API อย่างเป็นทางการของผู้ให้บริการ, API การใช้งานที่ผ่านการยืนยันตัวตน, เฮดเดอร์การตอบกลับที่มีการแมปไว้อย่างชัดเจน, การกำหนดค่าโดยผู้ดูแลระบบ, ค่าประมาณภายในระบบ และ unknown ค่าประมาณภายในระบบจะไม่ถูกนำเสนอเป็นข้อมูลการเรียกเก็บเงินของผู้ให้บริการ

เฮดเดอร์การตอบกลับจะได้รับการแยกวิเคราะห์ผ่านการแมปกับผู้ให้บริการที่กำหนดไว้อย่างชัดเจนเท่านั้น ระบบจะไม่อนุมานว่าชื่อเฮดเดอร์ทั่วไปมีผลใช้ได้ทั่วทั้งระบบ
