การบีบอัดแบบ Caveman สามารถโหลดแพ็กกฎเฉพาะภาษาเพิ่มเติมจากกฎภาษาอังกฤษที่มีมาให้ในตัวได้
วิธีนี้ช่วยให้เอนจินหลักมีความเสถียร ขณะเดียวกันก็ช่วยให้แพ็กภาษาโปรตุเกส สเปน เยอรมัน ฝรั่งเศส อิตาลี ญี่ปุ่น และ
แพ็กภาษาอื่นๆ ในอนาคตสามารถพัฒนาแยกจากกันได้อย่างอิสระ

## ตำแหน่งที่ตั้ง

แพ็กภาษาจะอยู่ภายใต้:

```txt
open-sse/services/compression/rules/<language>/
```

แพ็กที่จัดส่งในปัจจุบัน (ตรวจสอบเทียบกับเนื้อหาภายในไดเรกทอรี `rules/` แล้ว):

| ภาษา              | ไดเรกทอรี      | หมวดหมู่กฎที่มีอยู่                                 |
| ----------------- | -------------- | --------------------------------------------------- |
| อังกฤษ            | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| สเปน              | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| โปรตุเกส (บราซิล) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| อินโดนีเซีย       | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| อิตาลี            | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| เยอรมัน           | `rules/de/`    | `context`, `filler`, `structural`                   |
| ฝรั่งเศส          | `rules/fr/`    | `context`, `filler`, `structural`                   |
| ญี่ปุ่น           | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **หมายเหตุเกี่ยวกับความเท่าเทียม:** แพ็ก `en`, `es`, `pt-BR`, `id` และ `it` มีครบทั้ง 5 หมวดหมู่ ส่วน `de`, `fr` และ `ja` จัดส่งมาพร้อม 3 หมวดหมู่ หมวดหมู่ `dedup` และ `ultra` ที่ขาดหายไปจะย้อนกลับไปใช้กฎภาษาอังกฤษที่มีมาให้ในตัวโดยไม่มีการแจ้งเตือน ยินดีรับการมีส่วนร่วมเพื่อเพิ่ม `dedup.json` และ `ultra.json` ให้กับแพ็กที่มีขนาดเล็กกว่า
>
> แพ็ก `pt-BR` พัฒนาขึ้นโดยอ้างอิงจาก **[Troglodita](https://github.com/leninejunior/troglodita)** โดย Lenine Júnior ซึ่งเป็นระบบบีบอัดที่ออกแบบขึ้นใหม่ทั้งหมดสำหรับไวยากรณ์ภาษาโปรตุเกสแบบบราซิล (การลดถ้อยคำซ้ำซ้อน การลบคำฟุ่มเฟือยในภาษาโปรตุเกสแบบบราซิล และตัวย่อทางเทคนิคสำหรับชุมชนนักพัฒนาชาวบราซิล)
>
> รายการหมวดหมู่มาตรฐานและสคีมาของแต่ละหมวดหมู่อยู่ใน [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12)

## การตรวจหาภาษา

`languageDetector.ts` ใช้การวิเคราะห์เชิงฮิวริสติกแบบน้ำหนักเบาเพื่ออนุมานภาษาจากข้อความพรอมต์ ระบบยังคงใช้ภาษาเริ่มต้นที่กำหนดค่าไว้ และสามารถปิดใช้งานการตรวจหาได้ผ่านการกำหนดค่าเมื่อต้องการควบคุมอย่างแม่นยำ

ผลลัพธ์จากการตรวจหาจะใช้เพื่อเลือกแพ็กกฎเท่านั้น โดยจะไม่เปลี่ยนแปลงการกำหนดเส้นทางของผู้ให้บริการ การเลือกโลเคล หรือภาษาของ UI

## โครงสร้างการกำหนดค่า

การตั้งค่าการบีบอัดสามารถประกอบด้วย:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` ควบคุมค่าเริ่มต้นของแดชบอร์ด/การแสดงตัวอย่าง ส่วน `cavemanConfig` คือการกำหนดค่าของเอนจินขณะรันไทม์
ที่ใช้เมื่อ Caveman บีบอัดข้อความของข้อความสนทนา

## การเพิ่มแพ็กภาษา

1. สร้าง `open-sse/services/compression/rules/<language>/<pack>.json`
2. ใช้รูปแบบกฎ Caveman จาก `docs/compression/COMPRESSION_RULES_FORMAT.md`
3. กำหนดการแทนที่อย่างระมัดระวัง และหลีกเลี่ยงการเปลี่ยนแปลงโค้ด ตัวระบุ URL หรือ JSON
4. เพิ่มหรืออัปเดตการทดสอบสำหรับการเลือกภาษาและลักษณะการทำงานของการแทนที่
5. เพิ่มป้ายกำกับใหม่สำหรับแดชบอร์ด/i18n หากภาษานั้นปรากฏในตัวเลือกบน UI

## API

สามารถเรียกดูแพ็กภาษาที่พร้อมใช้งานได้ด้วย:

```bash
curl http://localhost:20128/api/compression/language-packs
```

เอนด์พอยต์สำหรับดูตัวอย่างรองรับการแทนที่การกำหนดค่าภาษา:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

แพ็กภาษาทั้ง 6 รายการได้รับส่วนคำสั่ง `SHARED_BOUNDARIES` ใน v3.8.0 ซึ่งจะถูกนำไปใช้กับทุกระดับความเข้มของ
Caveman (LITE, FULL, ULTRA) ส่วนคำสั่งนี้กำหนดให้เอนจินคงรูปแบบเหล่านี้ไว้ตามต้นฉบับ
โดยไม่คำนึงถึงการลบข้อความส่วนเกินที่อยู่รอบข้าง:

| ประเภทรูปแบบ                        | ตัวอย่าง                               |
| ----------------------------------- | -------------------------------------- |
| บล็อกโค้ดแบบมีรั้ว                  | ` ```python\n...\n``` `                |
| โค้ดแบบอินไลน์                      | `` `my_var` ``                         |
| URL                                 | `https://example.com/path`             |
| พาธไฟล์ (แบบสัมบูรณ์ + แบบสัมพัทธ์) | `/etc/hosts`, `./src/index.ts`         |
| ส่วนหัวข้อผิดพลาด                   | `Error:`, `TypeError:`, `SyntaxError:` |
| บรรทัดสแต็กเทรซ                     | `  at functionName (file.ts:12:3)`     |

รูปแบบเหล่านี้ถูกกำหนดไว้ใน `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (ก่อนหน้านี้คือ `[]`)
โดยค่าคงที่นี้อยู่ใน `open-sse/services/compression/types.ts`

### เหตุผลที่สิ่งนี้สำคัญ

หากไม่มี SHARED_BOUNDARIES โหมด Caveman ที่เข้มงวดอาจลบเนื้อหาที่ดูเหมือนข้อความร้อยแก้วซ้ำซ้อน
แต่จริง ๆ แล้วเป็นข้อมูลโค้ด พาธไฟล์ หรือสแต็กข้อผิดพลาด SHARED_BOUNDARIES ทำหน้าที่เป็น
กลไกความปลอดภัยที่ไม่ขึ้นกับภาษา ซึ่งจะถูกนำไปใช้ก่อนกฎการลบข้อความส่วนเกิน

### การปรับแต่ง preservePatterns

สามารถเพิ่มรูปแบบอื่น ๆ ขณะรันไทม์ได้ผ่านการตั้งค่าการบีบอัด:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

รูปแบบที่กำหนดเองจะขยายเพิ่มเติม (ไม่ใช่แทนที่) ค่าเริ่มต้นทั้ง 6 รายการ

## หมายเหตุด้านการปฏิบัติงาน

- กฎภาษาอังกฤษในตัวจะยังคงใช้เป็นทางเลือกสำรองเมื่อไม่มีแพ็กภาษา
- แพ็ก JSON ในตัวที่ไม่ถูกต้องจะไม่ผ่านการตรวจสอบ เพื่อป้องกันไม่ให้แอสเซ็ตของรีลีสลดคุณภาพลงโดยไม่มีการแจ้งเตือน
- แพ็กกฎมีเฉพาะข้อมูลเท่านั้น และไม่ควรนำเข้าโค้ดหรือเรียกใช้ตรรกะใด ๆ โดยพลการ
- ชั้นการวิเคราะห์การบีบอัดจะบันทึกโหมดและเอนจินที่เลือก ไม่ใช่ข้อความพรอมต์ฉบับเต็ม
