## หมวดหมู่

- **ฟรี** — แพ็กเกจฟรีที่ใช้คีย์ API (กำหนดค่าผ่านแดชบอร์ด)
- **ไม่ต้องยืนยันตัวตน** — เอ็นด์พอยต์สาธารณะที่ไม่ต้องใช้คีย์หรือเข้าสู่ระบบ
- **OAuth** — OmniRoute จัดการขั้นตอนการเข้าสู่ระบบให้โดยไม่ต้องใช้คีย์ API
- **คุกกี้เว็บ** — ครอบเว็บแอปของผู้ให้บริการโดยใช้การยืนยันตัวตนผ่านคุกกี้
- **คีย์ API** — ผู้ให้บริการแบบชำระเงินที่กำหนดค่าผ่านคีย์ API (อาจมีเครดิตฟรี)
- **ภายในเครื่อง** — ทำงานบนเครื่องของผู้ใช้ (Ollama, LM Studio, vLLM เป็นต้น)
- **ค้นหา** — ผู้ให้บริการค้นหาเว็บ
- **เสียง** — ผู้ให้บริการเฉพาะเสียง (TTS/STT)
- **พร็อกซีต้นทาง** — ผู้ให้บริการที่ทำหน้าที่เป็นพร็อกซีไปยังผู้ให้บริการรายอื่น
- **เอเจนต์คลาวด์** — เอเจนต์เขียนโค้ดที่ทำงานระยะยาว (Codex Cloud, Devin, Jules)
- **ระบบ** — ผู้ให้บริการภายในของ OmniRoute (loopback เป็นต้น)

แท็กเพิ่มเติม: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`

`การเรียกใช้เครื่องมือ` (เมื่อแสดง): `native` — API เรียกใช้ฟังก์ชันจริง; `emulated` — อาร์เรย์ `tools` ถูกจำลองผ่านพรอมต์โดยใช้ `webTools.ts` (บล็อก `<tool>{...}</tool>` ที่แยกวิเคราะห์ด้วย regex); `none` — ขณะนี้ `tools` ถูกละทิ้งโดยไม่มีการแจ้งเตือน ดู #7286

ใช้แดชบอร์ดที่ `/dashboard/providers` เพื่อเปิดใช้งาน กำหนดค่า และทดสอบผู้ให้บริการแต่ละราย
