> **แหล่งข้อมูลหลัก (แค็ตตาล็อก):** `open-sse/config/freeModelCatalog.ts` (งบประมาณแยกตามโมเดล โดยขจัดการนับซ้ำของพูล) ตัวเลขงบประมาณโทเค็นด้านล่างมาจากการค้นคว้าบนเว็บแบบสดและเป็นเพียง **ค่าประมาณ** — ดู[ระเบียบวิธีและข้อควรระวัง](#methodology--caveats)

## TL;DR — OmniRoute รวบรวมการอนุมานฟรีได้มากแค่ไหนกันแน่?

| เมตริก                                         | โทเค็น / เดือน           | ความหมาย                                                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **โควตาประจำที่มีเอกสารยืนยัน (คงที่)**        | **~1.62B**               | **พูล** ของระดับฟรี (แค็ตตาล็อกแยกตามโมเดล) โดยนับพูลที่ใช้ร่วมกันแต่ละพูลเพียง **ครั้งเดียว** นี่คือแหล่งข้อมูลสดเบื้องหลัง `/api/free-tier/summary` และหน้า Free-Tier Budget ของแดชบอร์ด **ให้ใช้ตัวเลขนี้**                                                                                                               |
| **+ เดือนแรกพร้อมเครดิตสมัครใช้งาน**           | **~2.22B**               | โควตาคงที่ + เครดิตสมัครใช้งานครั้งเดียว (Z.AI 20M, DeepSeek 5M, …) โดยตัดรายการซ้ำต่อบัญชี **เฉพาะเดือนแรกเท่านั้น** — ไม่มีการให้ซ้ำ                                                                                                                                                                                       |
| **+ ฟรีถาวรโดยไม่มีเพดานที่เผยแพร่**           | _ไม่สามารถระบุปริมาณได้_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — เข้าถึงได้ฟรีอย่างต่อเนื่องจริง โดยจำกัดอัตรา/จำนวนคำขอพร้อมกัน แต่ **ไม่มีเพดานโทเค็นให้นับ** แสดงไว้ในรายการแต่ไม่นำมารวมยอด (การนับโดยใช้ `RPM×24/7` คือการทำให้ตัวเลขสูงเกินจริง ซึ่งเราไม่ยอมรับ) |
| **+ การเพิ่มโควตาที่ปลดล็อกด้วยการฝากเงิน**    | **+~24M**                | การเติมเงิน OpenRouter **$10** แบบครั้งเดียวจะเพิ่มพูลฟรีจาก 50 → 1000 คำขอ/วัน รายงานแยกต่างหากเพื่อไม่ให้ตัวเลขคงที่สูงเกินจริง                                                                                                                                                                                            |
| **+ อยู่หลังการตรวจสอบตัวตนตามภูมิภาค**        | **+~6M**                 | `modelscope` (การผูกบัญชี Alibaba Cloud + การยืนยันชื่อจริงในจีนแผ่นดินใหญ่) เป็นโควตาประจำจริง โดยเปิดเผยเป็น `gatedRecurringTokens` / `gatedProviders` และบนแดชบอร์ด ไม่นำไปรวมในตัวเลขพาดหัว: +~6M ที่ต้องผ่านการยืนยันตัวตนตามภูมิภาค                                                                                    |
| เพดานตามทฤษฎี (ใช้อัตราสูงสุดทั้งหมดตลอด 24/7) | ~10B                     | ผลรวมของขีดจำกัดอัตราจากผู้ให้บริการทุกรายเมื่อประมาณการจากการใช้งานอย่างต่อเนื่อง **ไม่ใช่การรับประกัน** — อย่าใช้ตัวเลขนี้เป็นพาดหัว                                                                                                                                                                                       |

**พาดหัวที่ตรงไปตรงมา:** _OmniRoute รวบรวมโทเค็นฟรีที่มีเอกสารยืนยันได้ **~1.62B ต่อเดือน** (สูงสุด ~2.22B ในเดือนแรกเมื่อรวมเครดิตสมัครใช้งาน) จากพูลระดับฟรี 35 พูล — พร้อมผู้ให้บริการฟรีถาวรแบบไม่มีเพดานอีกจำนวนมาก — และการบีบอัดด้วย RTK + Caveman (ประหยัดโทเค็น 15–95%) ช่วยให้ใช้งานได้นานยิ่งขึ้น_

> **เหตุใดตัวเลขนี้จึงลดลงจาก ~1.94B ก่อนหน้านี้** การรีเฟรชเมื่อ 2026-06-17 เป็นการแก้ไขให้ตรงไปตรงมา ไม่ใช่การสูญเสียโควตา: ขณะนี้ `gemini` ถูกตัดรายการซ้ำในระดับพูลแล้ว (ก่อนหน้านี้ตัวเลขสูงเกินจริงเพราะนับ Flash แต่ละรุ่นแยกกัน จาก 462M → 60M), แก้ไข `cloudflare-ai` ให้ตรงกับโควตาจริง 10k-Neurons/วัน (122M → 30M), จัดประเภท `doubao` ใหม่เป็นเครดิตสมัครใช้งานครั้งเดียว (ไม่ใช่โควตาประจำ) และนำระดับบริการที่ปิดตัวแล้วออก (`chutes`/`phind`/`kluster` ยุติให้บริการ) การลดลงนี้ได้รับการชดเชยบางส่วนจาก `llm7` (แก้ไขเป็น 5M/วันที่ถูกต้อง → 150M) และผู้ให้บริการฟรีรายใหม่ (Kilo, OpenCode Zen, Z.AI GLM-Flash)
>
> **แก้ไขเพิ่มเติมเป็น ~1.37B ใน v3.8.42:** `longcat` ถูกจัดประเภทใหม่จากโควตาประจำ 150M/เดือนเป็นเครดิตสมัครใช้งานครั้งเดียว 10M หลังช่วงทดลองใช้ฟรีสิ้นสุดลง ใช้หลักความตรงไปตรงมาเดียวกัน — ไม่มีผู้ให้บริการรายใดถูกนำออกโดยไม่ได้ตั้งใจ
>
> **อัปเดตเมื่อ 2026-08-26 หลังยุติ Felo Web:** ไม่นับรวม Felo Web ระหว่างที่แหล่งที่มา/การให้สิทธิ์ใช้งานซึ่งสืบเนื่องจาก GPL ยังมีสถานะ HOLD โดยซอร์สรายงานคีย์พูล 38 รายการ ณ เวลานั้น จำนวนพูลเป็นข้อมูลสดและมี CI คอยตรวจสอบ (`check:docs-counts` จะทำให้บิลด์ล้มเหลวหากตัวเลขข้างต้นคลาดเคลื่อนจาก `computeFreeModelTotals()`)
>
> **ตรวจสอบซ้ำเมื่อ 2026-09-02 โดยเทียบกับหน้าของผู้ให้บริการเอง** (แหล่งข้อมูล: ความคิดเห็น `// evidence:` ถัดจากแต่ละรายการที่ตรวจสอบซ้ำใน `open-sse/config/freeModelCatalog.data.ts`): `gemini` และ `ollama-cloud` ไม่เผยแพร่ตัวเลขโทเค็นอีกต่อไป (Google นำตารางระดับฟรีแยกตามโมเดลออกเมื่อ 2025-12-23; แผน Free ของ Ollama คือ "เครดิตการใช้งานเริ่มต้น") และขณะนี้แสดงเป็น **ไม่มีเพดาน** โดยไม่นำมารวมยอด (−80M); `groq` มีเพดาน 200K-TPD ห้ารายการแบบ **แยกตามโมเดล** (รายการละ 6M, +15M) โดยนำ ID ที่ยุติแล้วสามรายการออก; `nara` เป็นบักเก็ตเดียวขนาด 7M/วัน (+60M, 210M) ส่วน 1B ของ `mistral` มองเห็นได้เฉพาะในคอนโซลบัญชี — ดู _ประเภทหลักฐาน_ ภายใต้ระเบียบวิธี
>
> **แก้ไขเมื่อ 2026-09-03 (#11773):** `cerebras` ถูกจัดประเภทใหม่จากโควตาประจำ 30M/เดือน (การทดลองแบบเก่าที่ไม่ต้องใช้บัตร ให้ 1M โทเค็น/วัน) เป็นเครดิตสมัครใช้งานครั้งเดียว $5 ซึ่งต้องระบุวิธีการชำระเงิน ใช้หลักความตรงไปตรงมาเดียวกับ LongCat
>
> **พร้อมเพิ่ม xKiro (2026-09-03):** พูลใหม่ `xkiro-free` (150M/เดือน) เพิ่มคีย์พูลประจำเป็นรายการที่ 35 Felo Web ยังคงถูกไม่นับรวมระหว่างที่แหล่งที่มา/การให้สิทธิ์ใช้งานซึ่งสืบเนื่องจาก GPL ยังมีสถานะ HOLD ขณะนี้ซอร์สรายงาน **คีย์พูลประจำ 35 รายการ** และ **โควตาคงที่ ~1.62B** — ตัวเลขสดที่มี CI คอยตรวจสอบ (`check:docs-counts` จะทำให้บิลด์ล้มเหลวหากตัวเลขนี้คลาดเคลื่อนจาก `computeFreeModelTotals()`)

ผู้สนับสนุนรายใหญ่ที่สุดที่**มีเอกสารยืนยัน**: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (เพดานแยกตามโมเดลห้ารายการ), `cloudflare-ai` 30M, `api-airforce` 24M (`longcat` ไม่ถูกนับรวม — โควตา LongCat-2.0 ขนาด 10M เป็นเครดิตสมัครใช้งานครั้งเดียวที่ต้องผ่าน KYC ไม่ใช่งบประมาณรายเดือนแบบประจำ)

> ⚠️ เพดานตามทฤษฎี (~10B) ถูกทำให้สูงเกินจริงโดยผู้ให้บริการที่จำกัดเฉพาะอัตราการใช้งานและ **ไม่ได้เผยแพร่เพดานโทเค็น** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`) ซึ่งตัวเลขจะคำนวณเป็น `RPM/TPM × 24/7 × 30d` — ค่าสูงสุดตามทฤษฎีที่ไม่มีบัญชีใดบัญชีหนึ่งสามารถใช้งานได้อย่างต่อเนื่อง ผู้ให้บริการเหล่านี้จึง **ไม่ถูกรวม** ในตัวเลขที่มีหลักฐานรองรับ (แต่จะแสดงอยู่ในแถว "ฟรีถาวร ไม่มีเพดาน") นี่คือการทำให้ตัวเลขสูงเกินจริงในลักษณะเดียวกันกับที่ทำให้คำกล่าวอ้างระดับหลายพันล้านของคู่แข่งไม่น่าเชื่อถือ

## การอัปเดต 2026-06-17 — สิ่งที่เปลี่ยนแปลงนับตั้งแต่ 2026-06-05

มีการใช้เอเจนต์ 50 ตัวทำวิจัยเว็บ (เอกสารอย่างเป็นทางการ + ข่าวในช่วง 7 วันที่ผ่านมา พร้อมตรวจสอบแบบเจาะหาจุดผิดพลาด) เพื่อปรับปรุงแค็ตตาล็อกทั้งหมด ไฮไลต์มีดังนี้:

## สองระบอบ — การนับเทียบกับการตัดสินใจ

OmniRoute ตอบคำถามว่า "ใช้งานฟรีหรือไม่?" ผ่านสองระบอบที่ตั้งใจให้อ่าน
จากแหล่งข้อมูลต่างกัน:

| ระบอบ                  | แหล่งข้อมูลที่ถือเป็นข้อยุติ                                                                                                                                                                  | ส่วนที่นำไปใช้                                                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **การนับ / การแสดงผล** | แค็ตตาล็อกที่ประมวลผลแล้ว — ข้อมูลพื้นฐานที่มาพร้อมกับรุ่นเผยแพร่ซึ่งซ้อนทับด้วยฟีด Radar (`getRadarCatalog`)                                                                                 | ยอดรวมแพ็กเกจฟรี, การ์ดงบประมาณ, แดชบอร์ด                                                                                           |
| **การตัดสินใจ**        | เฉพาะแค็ตตาล็อกที่มาพร้อมกับรุ่นเผยแพร่ (`FREE_MODEL_BUDGETS` ใน `open-sse/config/freeModelCatalog.data.ts`) รวมถึงฮิวริสติกภายใน (`:free` suffix, การกำหนดราคาเป็นศูนย์, `grantsFreeAccess`) | ทุกส่วนที่ใช้ `src/shared/utils/freeModels.ts`: การนำเข้าโมเดล, การกำหนดเส้นทาง `auto/*`, `GET /v1/models` และตัวอย่างในเบราว์เซอร์ |

การนับสามารถได้รับการปรับปรุงเมื่อใดก็ตามที่มีฟีดพร้อมใช้งาน ส่วนการตัดสินใจยังคงอิงกับ
อาร์ติแฟกต์ของรุ่นเผยแพร่ ดังนั้นคำตอบจึงเหมือนกันทั้งในเบราว์เซอร์และบนเซิร์ฟเวอร์
สามารถทำซ้ำแบบออฟไลน์ได้ และทดสอบได้โดยไม่ต้องใช้ฐานข้อมูล หากปล่อยให้ตัวอย่าง
ในเบราว์เซอร์อ่านจากแหล่งหนึ่ง ขณะที่การนำเข้าบนเซิร์ฟเวอร์อ่านจากอีกแหล่งหนึ่ง จะทำให้
ตัวอย่างไม่ตรงกับสิ่งที่เกิดขึ้นเมื่อคลิก — จึงจงใจคงการแยกนี้ไว้

## ระเบียบวิธีและข้อควรระวัง

- ตัวเลขเป็น **ค่าประมาณขีดจำกัดสูงสุด** จากข้อจำกัดของแพ็กเกจฟรีที่ผู้ให้บริการแต่ละรายจัดทำเป็นเอกสารไว้ ณ วันที่ **2026-06-17** ซึ่งรวบรวมจากการค้นคว้าทางเว็บ แพ็กเกจฟรีเปลี่ยนแปลงอยู่ตลอดเวลา — โปรดตรวจสอบอีกครั้งก่อนนำตัวเลขไปใช้
- **ข้อมูลแต่ละรายการรับรองอะไรจริง ๆ** ไม่มีรายการใดมีระดับความเชื่อมั่นเฉพาะแถว และ API ก็ไม่ได้ให้ข้อมูลดังกล่าว — ให้ถือว่าตัวเลขทั้งหมดข้างต้นเป็นค่าประมาณที่มีคุณภาพระดับเดียวกันซึ่งไม่ได้ระบุไว้ อย่างไรก็ตาม มีข้อเท็จจริงสองประเภทที่แตกต่างออกไป เพราะได้รับการคัดสรรด้วยตนเองแทนที่จะอนุมานขึ้นมา ได้แก่ 44 รายการที่มีการหยุดใช้งานเมื่อถึงขีดจำกัดซึ่งมีเอกสารยืนยันอย่างเป็นอิสระ (39 รายการในนั้นคือแถวของ xKiro ซึ่งทั้งหมดใช้โควตารายวันเดียวกัน) และ 13 รายการที่มีการเปิดเผยเรื่องการนำพรอมต์ไปใช้ฝึกโมเดล `hardStopGuaranteed` จะถูกตั้งค่าก็ต่อเมื่อข้อกำหนดของผู้ให้บริการเองระบุว่า เมื่อใช้เกินโควตาฟรี ระบบจะปฏิเสธคำขอแทนที่จะเริ่มเรียกเก็บเงินโดยไม่แจ้งให้ทราบ โดยมีแหล่งอ้างอิงอยู่ในความคิดเห็นถัดจากรายการนั้น ค่านี้จะไม่ถูกตั้งเป็น `true` โดยปริยาย และรายการที่ยังไม่มีใครตรวจสอบจะยังไม่ถูกตั้งค่า ดังนั้น การไม่มีแฟล็กการหยุดเมื่อถึงขีดจำกัดจึงหมายถึง "ยังไม่ได้รับการยืนยัน" ไม่ใช่ "เป็นที่ทราบว่าจะเรียกเก็บเงินจากคุณ" **โหมด STRICT** (ตัวป้องกันการกำหนดเส้นทาง `freeAccessPolicy=strict` ที่ต้องเลือกเปิดใช้) จะเชื่อถือเฉพาะรายการที่มีแฟล็กนี้เท่านั้น แพ็กเกจฟรีอื่นทั้งหมดจะถูกตัดออกในฐานะ `no-hard-stop` (ดู `open-sse/services/autoCombo/strictZeroCostFilter.ts`)
- `estMonthlyFreeTokens` = เฉพาะโทเค็นรายเดือนที่ได้รับซ้ำเป็นประจำเท่านั้น **เครดิตฟรีแบบครั้งเดียวเมื่อลงทะเบียนจะไม่ได้รับซ้ำ** และนับเป็น 0 แพ็กเกจที่ยกเลิกให้บริการแล้วก็นับเป็น 0 เช่นกัน
- ขีดจำกัดโทเค็นรายวัน → `monthly = daily × 30` หากมีเอกสารเฉพาะ RPD → `RPD × ~800 โทเค็นเอาต์พุต × 30` หากมีเฉพาะ RPM/TPM (ไม่มีขีดจำกัดรายวัน) → **ไม่จำกัดเพดาน** (ดูด้านล่าง)
- **ใช้ฟรีถาวร แต่ไม่มีการเผยแพร่ขีดจำกัดโทเค็น** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): บริการเหล่านี้ให้สิทธิ์ใช้ฟรีซ้ำเป็นประจำจริง โดยมีข้อจำกัดด้านอัตราการใช้งาน/จำนวนงานพร้อมกัน เราจัดประเภทเป็น `recurring-uncapped` และ **ไม่นำมารวมยอดเด็ดขาด** — การคูณ `RPM × 24/7 × 30d` จะสร้างเพดานลวงตา (เป็นการขยายตัวเลขเกินจริงที่เราไม่ยอมรับ) รายการเหล่านี้แสดงไว้เพื่อให้คุณทราบว่ามีบริการดังกล่าวอยู่
- **โควตาที่เพิ่มขึ้นหลังฝากเงินเพื่อปลดล็อก:** การเติมเงินจำนวนเล็กน้อยแบบครั้งเดียวซึ่งเพิ่มโควตาฟรีอย่างถาวร (OpenRouter: $10 → 1000 คำขอ/วัน ≈ เพิ่มขึ้น 24M/เดือน) รายงานเป็นตัวเลขแยกต่างหากและไม่นำไปรวมในตัวเลขหลักสำหรับโควตาคงที่
- **โควตาที่มีเงื่อนไขด้านคุณสมบัติ** (`eligibilityGate: "regional-identity"`): โควตาที่ได้รับซ้ำเป็นประจำจริง ซึ่งจะเปิดใช้งานต่อเมื่อผ่านการตรวจสอบตัวตนที่ผูกกับภูมิภาคแล้วเท่านั้น (ปัจจุบันคือการยืนยันชื่อจริงในจีนแผ่นดินใหญ่) คำนวณโดยใช้กฎการตัดรายการซ้ำในพูลแบบเดียวกันเป็นตัวเลขแยกต่างหาก (`gatedRecurringTokens`) และไม่นำไปรวมในตัวเลขหลักสำหรับโควตาคงที่ ประเภท (`freeType`) ยังคงเดิม ดังนั้นการกำหนดเส้นทางจึงไม่เปลี่ยนแปลง
- **ประเภทของหลักฐาน** กฎคือ ตัวเลขในแค็ตตาล็อกต้องอ้างอิงแหล่งที่มาไว้ในความคิดเห็น `// evidence:` ถัดจากรายการนั้น — `public-page` (หน้าของผู้ให้บริการที่ทุกคนอ่านได้), `api-public` (เอนด์พอยต์ของผู้ให้บริการที่ไม่ต้องยืนยันตัวตน เช่น เอนด์พอยต์แผนบริการสาธารณะของ NaraRouter ที่ router.bynara.id) หรือ `console-verified <date> por <who>` (ตัวเลขมองเห็นได้เฉพาะภายในคอนโซลของบัญชี ความคิดเห็นจะบันทึกว่าใครเป็นผู้เห็นและเห็นเมื่อใด พร้อมระบุหน้าสาธารณะที่ยืนยันว่ามีขีดจำกัดดังกล่าว) สถานะปัจจุบันคือ บล็อกทั้งห้าที่ได้รับการตรวจสอบซ้ำเมื่อ 2026-09-02 มีข้อมูลนี้ (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`) ส่วนรายการที่มีอยู่ก่อนการตรวจสอบซ้ำเมื่อ 2026-09-02 จะสืบทอดงานวิจัยเดิมจนกว่าจะได้รับการแก้ไข ตัวเลขใดก็ตามที่ **เพิ่มใหม่หรือมีการเปลี่ยนแปลง** โดยไม่มีความคิดเห็นระบุหลักฐานถือเป็นบั๊ก ปัจจุบันมีเพียง `mistral` เท่านั้นที่ได้รับการตรวจสอบผ่านคอนโซล

## เหตุใดตัวเลขของเราจึงน้อยกว่าของผู้รวบรวมรายอื่น

ตัวเลข "โทเค็นฟรีต่อเดือน" ส่วนใหญ่ในแวดวงนี้เกิดจากการนำตัวเลขที่ระบุแยกตามโมเดลมารวมกัน แต่ของเราจงใจไม่ทำเช่นนั้น:

- **แต่ละพูลที่ใช้ร่วมกันจะถูกนับเพียงครั้งเดียว** แผนฟรีของ Mistral ให้โควตา 1B/เดือนต่อองค์กรหนึ่งแห่ง การนำโควตานี้ไปแสดงใต้โมเดลห้าโมเดลไม่ได้ทำให้กลายเป็น 5B หากรวมแยกตามโมเดล แค็ตตาล็อกของเราเองจะมีตัวเลข **~7.4B** (คำนวณใหม่เมื่อ 2026-09-03; ตัวเลขนี้ไม่ได้ถูกตรวจสอบโดย CI — ให้วัดใหม่ทุกครั้งที่แค็ตตาล็อกเปลี่ยนแปลง) — แต่ตัวเลขพาดหัวระบุ **~1.47B** เพราะนั่นคือจำนวนที่บัญชีหนึ่งบัญชีของผู้ให้บริการแต่ละรายสามารถใช้ได้จริง
- **เพดานรายวันจะถูกแปลง แต่อัตราจะไม่ถูกแปลง** เพดาน tokens/day ที่มีการระบุไว้จะกลายเป็น `× 30`; เพดาน requests/day ที่มีการระบุไว้จะกลายเป็น `RPD × ~800 tokens × 30`; ผู้ให้บริการที่เผยแพร่เพียงจำนวนคำขอต่อนาทีจะ **ไม่มี** ตัวเลขรายเดือนและจะแสดงเป็น _ไม่มีเพดาน_ โดยจะไม่นำมารวม การคูณขีดจำกัดอัตราด้วย 24/7 คือการปั่นตัวเลขให้สูงเกินจริงซึ่งเราปฏิเสธที่จะทำ
- **โควตาที่ต้องผ่านการตรวจสอบตัวตนตามภูมิภาคจะแสดงแยกต่างหาก** (`+~6M behind regional identity verification`) เนื่องจากผู้อ่านส่วนใหญ่ไม่สามารถใช้งานได้
- **เครดิตสำหรับการสมัครใช้ได้เฉพาะเดือนแรก** และจะรายงานเป็นตัวเลขที่สอง โดยจะไม่นำไปรวมกับตัวเลขการใช้งานต่อเนื่อง
- **ตัวเลขนี้บังคับใช้โดย CI** `npm run check:docs-counts` จะคำนวณยอดรวมใหม่จากแค็ตตาล็อก และทำให้บิลด์ล้มเหลวเมื่อไฟล์นี้ README หรือการ์ดงบประมาณมีตัวเลขคลาดเคลื่อนจากยอดรวมดังกล่าว

## ตารางข้อควรระวังเกี่ยวกับ ToS

> **ธง ToS เป็นเพียงคำแนะนำ ไม่ใช่เงื่อนไขควบคุมการกำหนดเส้นทาง** ผู้ให้บริการที่ทำเครื่องหมาย `tos` ยังคงถูกรวมไว้ในการกำหนดเส้นทางและ combo/fallback ตามค่าเริ่มต้น โดยธงนี้จะแสดงเฉพาะบน `/dashboard/free-tiers` และ `/api/free-tier/summary` เท่านั้น พารามิเตอร์คิวรี `excludeTosAvoid` มีผลเฉพาะกับมุมมองสรุป ไม่ใช่การกำหนดเส้นทางโดยรวม คำวินิจฉัยอยู่ใน `open-sse/config/freeTierCatalog.ts` (ใช้เป็นข้อมูลเท่านั้น และกลไกการกำหนดเส้นทางไม่ได้อ่านค่านี้)

> สรุปข้อกำหนดของผู้ให้บริการแต่ละรายแบบรวดเร็ว สำหรับพร็อกซีส่วนบุคคลแบบโฮสต์เองที่มีผู้ใช้คนเดียว `caution` = มีข้อกำหนดเกี่ยวกับการใช้งานส่วนบุคคลหรือพร็อกซีที่ควรตรวจสอบ; `ambiguous` = ไม่ชัดเจน; `ok` = อนุญาตไว้อย่างชัดเจน ข้อมูลนี้มีไว้เพื่อให้ข้อมูล ไม่ใช่คำแนะนำทางกฎหมาย — คุณเป็นผู้ตัดสินใจ

## อภิธานศัพท์

| คำศัพท์                 | ความหมาย                                                                            |
| ----------------------- | ----------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**     | จำนวนคำขอต่อนาที / วัน / ชั่วโมง                                                    |
| **TPM / TPD**           | จำนวนโทเค็นต่อนาที / วัน                                                            |
| **Documented grant**    | ผู้ให้บริการเผยแพร่ขีดจำกัดโทเค็นรายวัน/รายเดือนอย่างชัดเจน (งบประมาณที่อ้างอิงได้) |
| **Theoretical ceiling** | `rate-limit × 24/7 × 30d` — ค่าสูงสุดตามทฤษฎี ไม่ใช่งบประมาณที่ได้รับ               |
| **Neuron**              | หน่วยประมวลผลของ Cloudflare (~1 โทเค็นเอาต์พุต)                                     |
