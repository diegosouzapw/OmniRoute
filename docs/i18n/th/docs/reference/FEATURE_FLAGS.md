## Feature Flags คืออะไร

Feature flag คือตัวสลับที่มีชื่อ (ชนิด boolean หรือ enum) ซึ่งสามารถเปลี่ยนค่าได้ใน
ขณะรันไทม์และบันทึกถาวรไว้ในฐานข้อมูล โดยไม่จำเป็นต้องปรับใช้โปรเซสใหม่ แต่ละ
แฟล็กอธิบายด้วย `FeatureFlagDefinition` ซึ่งประกอบด้วย `key`, `label`,
`description`, `category`, `defaultValue`, `type` และคำใบ้ `requiresRestart`

### ลำดับการกำหนดค่า

**ค่าที่มีผลจริง** ของแฟล็กจะถูกกำหนดโดย
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ตามลำดับ
ความสำคัญต่อไปนี้ (ลำดับที่สูงกว่าจะมีผล):

1. **ค่าที่กำหนดทับใน DB** — ค่าที่จัดเก็บไว้ในตาราง `key_value` ภายใต้
   namespace `feature_flags` (ตั้งค่าผ่านแดชบอร์ดหรือ REST API)
2. **ตัวแปรสภาพแวดล้อม** — `process.env[<KEY>]` หากมีการตั้งค่าและค่าไม่ว่างเปล่า
3. **ค่าเริ่มต้นจากข้อกำหนด** — `defaultValue` จาก `featureFlagDefinitions.ts`

แฟล็กชนิด boolean จะถือว่า **เปิดใช้งาน** เมื่อค่าที่มีผลจริงคือ `"true"`,
`"1"` หรือ `"yes"` (ดู `isFeatureFlagEnabled()`)

> [!NOTE]
> แฟล็กส่วนใหญ่ยังมีตัวแปรสภาพแวดล้อมที่ตรงกันและใช้ **ชื่อเดียวกัน**
> ซึ่งจัดทำเอกสารไว้ใน [`ENVIRONMENT.md`](./ENVIRONMENT.md) ค่าที่กำหนดทับใน DB
> ของแฟล็กจะมีลำดับความสำคัญเหนือกว่าตัวแปรสภาพแวดล้อมดังกล่าว แฟล็กที่มี
> `requiresRestart: true` จะถูกบันทึกถาวรทันที แต่จะถูกอ่านใหม่เฉพาะตอนเริ่มต้น
> โปรเซสเท่านั้น การสลับแฟล็กดังกล่าวจะแสดงแบนเนอร์ **"รีสตาร์ตเซิร์ฟเวอร์"** ในแดชบอร์ด

## แค็ตตาล็อกแฟล็ก

มีแฟล็ก 72 รายการใน 6 หมวดหมู่ **ค่าเริ่มต้น** คือค่าเริ่มต้นจากข้อกำหนด ซึ่งเป็นค่า
ที่ใช้เมื่อไม่มีทั้งค่าที่กำหนดทับใน DB และตัวแปรสภาพแวดล้อม

### ความปลอดภัย (10)

| คีย์                                    | ชนิด    | ค่าเริ่มต้น | คำอธิบาย                                                                                                                                                                                                                                              |
| --------------------------------------- | ------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `REQUIRE_API_KEY`                       | boolean | `false`     | กำหนดให้คำขอขาเข้าทั้งหมดต้องมี API key                                                                                                                                                                                                               |
| `INPUT_SANITIZER_ENABLED`               | boolean | `true`      | เปิดใช้งานการกรองอินพุตสำหรับคำขอทั้งหมด                                                                                                                                                                                                              |
| `INJECTION_GUARD_MODE`                  | enum    | `off`       | โหมดป้องกัน prompt injection ค่า: `off`, `warn`, `block`, `redact`                                                                                                                                                                                    |
| `PII_REDACTION_ENABLED`                 | boolean | `false`     | ปกปิด PII จากคำขอ (ทำงานเป็นอิสระจาก `INPUT_SANITIZER_MODE`)                                                                                                                                                                                          |
| `PII_RESPONSE_SANITIZATION`             | boolean | `false`     | กรอง PII ออกจากการตอบกลับของผู้ให้บริการ                                                                                                                                                                                                              |
| `PII_RESPONSE_SANITIZATION_MODE`        | enum    | `redact`    | โหมดสำหรับการกรอง PII จากการตอบกลับ ค่า: `redact`, `warn`, `block`, `off`                                                                                                                                                                             |
| `OUTBOUND_SSRF_GUARD_ENABLED`           | boolean | `true`      | บล็อกคำขอขาออกไปยังช่วง IP ส่วนตัว/ภายใน                                                                                                                                                                                                              |
| `ALLOW_API_KEY_REVEAL`                  | boolean | `false`     | อนุญาตให้ผู้ใช้แดชบอร์ดที่ผ่านการยืนยันตัวตนเปิดเผย API key ที่จัดเก็บไว้ แทนที่จะเห็นเฉพาะค่าที่ถูกปกปิด                                                                                                                                             |
| `AUTH_LOG_INCLUDE_ACCOUNT_ID`           | boolean | `false`     | รวมคำนำหน้าบัญชีไว้ในบรรทัดบันทึก AUTH (เช่น "กำลังใช้บัญชี <provider>: abc12345...") ปิดใช้งานโดยค่าเริ่มต้นเพื่อให้ตัวระบุบัญชีถูกปกปิดจากบันทึกของโปรเซสแบบใช้ร่วมกัน/หลายผู้เช่า ทำงานเป็นอิสระจากโหมดดีบัก การสลับโหมดดีบักจะไม่เปิดเผยข้อมูลนี้ |
| `OMNIROUTE_OIDC_DISABLE_PASSWORD_LOGIN` | boolean | `false`     | เมื่อเปิดใช้งาน OIDC ให้ปิดใช้งานการเข้าสู่ระบบด้วยรหัสผ่าน เพื่อให้ผู้ใช้ยืนยันตัวตนได้ผ่าน OIDC Single Sign-On เท่านั้น เมื่อปิดใช้งาน (ค่าเริ่มต้น) จะสามารถใช้ได้ทั้งการเข้าสู่ระบบด้วยรหัสผ่านและ OIDC                                           |

### เครือข่าย (15)

| คีย์                                            | ชนิด    | ค่าเริ่มต้น | รีสตาร์ต | คำอธิบาย                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------------- | ------- | ----------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ENABLE_TLS_FINGERPRINT`                        | boolean | `false`     | ✓        | เปิดใช้งานโหมดซ่อนร่องรอยลายนิ้วมือ TLS                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `AUDIO_REMOTE_PROVIDER_NODES`                   | boolean | `false`     |          | อนุญาตให้เส้นทาง /v1/audio/* ใช้โหนดผู้ให้บริการที่เข้ากันได้กับ OpenAI ซึ่งโฮสต์อยู่นอก localhost ค่าเริ่มต้นคือปิด — การกำหนดเส้นทางเสียงไปยังโฮสต์ระยะไกลจะเปลี่ยนอัตลักษณ์ขาออก และต้องเป็นการตัดสินใจโดยชัดแจ้งของผู้ดำเนินระบบ โหนด loopback ได้รับอนุญาตเสมอและไม่ได้รับผลกระทบ                                                                                                                                                                                     |
| `PROXY_AUTO_SELECT_ENABLED`                     | boolean | `false`     |          | เมื่อไม่มีพร็อกซีถูกกำหนดให้กับการเชื่อมต่อ ให้เลือกพร็อกซีตัวแรกที่ใช้งานได้จากรีจิสทรีโดยอัตโนมัติ ค่าเริ่มต้นคือปิด (มิฉะนั้นพร็อกซีใด ๆ ในรีจิสทรีจะกลายเป็นตัวสำรองส่วนกลาง — #3332)                                                                                                                                                                                                                                                                                  |
| `OMNIROUTE_CONTROL_PLANE_PROXY_DIRECT_FALLBACK` | boolean | `false`     |          | อนุญาตให้โฟลว์ OAuth และการตรวจสอบผู้ให้บริการข้ามพร็อกซีที่ตรึงไว้ และเชื่อมต่อโดยตรงเมื่อการตรวจสอบล่วงหน้าด้านการเข้าถึงพร็อกซีล้มเหลว ค่าเริ่มต้นคือปิด เนื่องจากการดำเนินการนี้อาจเปลี่ยน IP ขาออก                                                                                                                                                                                                                                                                    |
| `NETWORK_ROTATION_SHARED_EGRESS_GUARD`          | boolean | `true`      |          | เมื่อเกิดข้อยกเว้นด้านเครือข่าย (หมดเวลา การเชื่อมต่อถูกปฏิเสธ/รีเซ็ต) สำหรับตัวดำเนินการหมุนเวียนหลายบัญชี หากบัญชีที่ล้มเหลวไม่มีพร็อกซีเฉพาะ ให้ใช้ช่วงพักสั้น ๆ และข้ามบัญชีอื่นที่ไม่มีพร็อกซีตลอดคำขอที่เหลือ แทนที่จะลองแต่ละบัญชีใหม่ เปิดใช้งานเป็นค่าเริ่มต้น (ปลอดภัย: ไม่มีการเปลี่ยน IP ขาออก เพียงลดความหน่วง/ความเสี่ยงจากช่วงพักสำหรับบัญชีที่ใช้ทางออกร่วมกัน) ปิดใช้งานเพื่อคืนค่าการส่งต่อทันทีเมื่อบัญชีที่ไม่มีพร็อกซีตัวแรกส่งข้อยกเว้น              |
| `PROXY_SKIP_RECENTLY_FAILED`                    | boolean | `false`     |          | พูลพร็อกซีและการหมุนเวียน opencode รายบัญชีจะหยุดนำพร็อกซีที่เพิ่งล้มเหลวกลับมาให้บริการ (การตรวจสอบ TCP ถูกปฏิเสธ หรือได้รับ 429 ผ่านพร็อกซีนั้น) เป็นระยะเวลาต่อโปรเซสซึ่งเพิ่มเป็นสองเท่าเมื่อเกิดซ้ำแต่ละครั้งจนถึงค่าสูงสุด ไม่มีการเขียนสถานะพร็อกซี หากผู้สมัครทุกตัวถูกพักไว้ การเลือกจะไม่เปลี่ยนแปลง ค่าเริ่มต้นคือปิด                                                                                                                                           |
| `PROXY_POOL_EGRESS_OBSERVATION`                 | boolean | `false`     |          | แสดงใต้พูลพร็อกซีในแดชบอร์ดว่า ในช่วง 24 h ที่ผ่านมา มี IP ขาออกที่สังเกตพบจำนวนเท่าใดให้บริการสมาชิกของพูล และมีการเชื่อมต่อจำนวนเท่าใดที่ใช้ IP เหล่านั้น เป็นข้อมูลแบบอ่านอย่างเดียว คำนวณจากบันทึกพร็อกซี และไม่เคยใช้สำหรับการกำหนดเส้นทาง ค่าเริ่มต้นคือปิด                                                                                                                                                                                                          |

## การสลับสถานะแฟล็ก

### แดชบอร์ด

ไปที่ **แดชบอร์ด → การตั้งค่า → ฟีเจอร์แฟล็ก**
(`/dashboard/settings/feature-flags`) กริด
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
รองรับ:

- **การค้นหา** ตามคีย์หรือคำอธิบาย และ **การกรอง** ตามหมวดหมู่ (รวมถึงมุมมอง
  **ต้องรีสตาร์ต** ที่สร้างขึ้นเพิ่มเติม)
- **สวิตช์** สำหรับแฟล็กแบบบูลีน และ **เมนูดรอปดาวน์** สำหรับแฟล็กแบบ enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`)
- **ป้ายแหล่งที่มา** สำหรับแต่ละแฟล็ก — `DB`, `ENV` หรือ `DEF` — เพื่อแสดงว่า
  ค่าที่มีผลใช้งานมาจากที่ใด
- ปุ่ม **รีเซ็ต** (แสดงเฉพาะแฟล็กที่มาจาก `DB`) เพื่อลบค่าที่เขียนทับ
  และปุ่ม **รีเซ็ตค่าที่เขียนทับทั้งหมด** ที่ด้านล่าง
- แบนเนอร์ **รีสตาร์ตเซิร์ฟเวอร์** เมื่อมีการเปลี่ยนแฟล็ก `requiresRestart`

### REST API

การดำเนินการทั้งหมดผ่านเส้นทางเดียว:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts)
ทุกเมธอดจำเป็นต้องมีเซสชันแดชบอร์ดที่ผ่านการตรวจสอบสิทธิ์แล้ว (มิฉะนั้นจะได้รับ `401`)

#### `GET /api/settings/feature-flags`

ส่งคืนแฟล็กทั้งหมดพร้อมค่าที่มีผลใช้งาน แหล่งที่มา และข้อมูลสรุป

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... แฟล็กทั้งหมด 72 รายการ
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

กำหนดหรือลบค่าที่เขียนทับหนึ่งรายการ เนื้อหาคำขอ: `{ key: string; value?: string }`
การไม่ระบุ `value` จะลบค่าที่เขียนทับ (โดยคืนค่า env / ค่าเริ่มต้น)

```bash
# กำหนดค่าที่เขียนทับใน DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# ลบค่าที่เขียนทับ (ไม่มี "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

การตอบกลับจะส่งคืน `effectiveValue`/`source` ใหม่, `previousValue`/
`previousSource` และ `requiresRestart` คีย์ที่ไม่รู้จักและค่า enum ที่อยู่นอกช่วง
จะถูกปฏิเสธด้วย `400`

#### `DELETE /api/settings/feature-flags`

ล้างค่าที่เขียนทับใน DB **ทั้งหมด** พร้อมกัน โดยคืนค่าแฟล็กทั้งหมดเป็นค่า env /
ค่าเริ่มต้น ส่งคืน `{ cleared: <count>, message: "..." }`

> [!NOTE]
> แฟล็กที่มี `requiresRestart: true` จะมีผลหลังจากรีโหลดโปรเซสแล้วเท่านั้น
> ขั้นตอนการรีสตาร์ตของแดชบอร์ดจะเรียก `POST /api/restart` แล้วสำรวจสถานะ
> `GET /api/health/ping` เป็นระยะจนกว่าเซิร์ฟเวอร์จะกลับมาออนไลน์

## การใช้เส้นทางสำรองฉุกเฉินเมื่องบประมาณหมด

`OMNIROUTE_EMERGENCY_FALLBACK` (หมวดหมู่ `runtime`, ค่าเริ่มต้น `true`) ควบคุม
เส้นทางสำรองฟรีฉุกเฉินใน
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)
เมื่อเปิดใช้งาน คำขอที่ใช้งบประมาณจนหมดจะถูกส่งไปยังผู้ให้บริการ/โมเดลสำรองฟรี
แทนที่จะล้มเหลวทันที ตั้งค่าเป็น `false` (หรือ `0`) — ผ่านสวิตช์บนแดชบอร์ด
ค่าที่เขียนทับใน DB หรือตัวแปรสภาพแวดล้อม `OMNIROUTE_EMERGENCY_FALLBACK` —
เพื่อปิดใช้งานลักษณะการทำงานนี้ และปล่อยให้คำขอที่ใช้งบประมาณหมดล้มเหลว
(แสดงเป็นสวิตช์บนแดชบอร์ดใน PR #3741 / #3752)
