## Feature Flags คืออะไร

Feature flag คือตัวสลับที่มีชื่อ (ชนิด boolean หรือ enum) ซึ่งสามารถเปลี่ยนค่าได้ใน
ขณะรันไทม์และบันทึกถาวรไว้ในฐานข้อมูล โดยไม่จำเป็นต้องปรับใช้โปรเซสใหม่ แต่ละ
แฟล็กอธิบายด้วย `FeatureFlagDefinition` ซึ่งประกอบด้วย `key`, `label`,
`description`, `category`, `defaultValue`, `type` และคำใบ้ `requiresRestart`

### ลำดับการกำหนดค่า

**ค่าที่มีผลจริง** ของแฟล็กจะถูกกำหนดโดย
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ตามลำดับ
ความสำคัญต่อไปนี้ (ลำดับที่สูงกว่าจะมีผล):

1. **ค่าที่กำหนดทับใน DB** — ค่าที่จัดเก็บไว้ในตาราง `key_value` ภายใต้
   namespace `feature_flags` (ตั้งค่าผ่านแดชบอร์ดหรือ REST API)
2. **ตัวแปรสภาพแวดล้อม** — `process.env[<KEY>]` หากมีการตั้งค่าและค่าไม่ว่างเปล่า
3. **ค่าเริ่มต้นจากข้อกำหนด** — `defaultValue` จาก `featureFlagDefinitions.ts`

แฟล็กชนิด boolean จะถือว่า **เปิดใช้งาน** เมื่อค่าที่มีผลจริงคือ `"true"`,
`"1"` หรือ `"yes"` (ดู `isFeatureFlagEnabled()`)

> [!NOTE]
> แฟล็กส่วนใหญ่ยังมีตัวแปรสภาพแวดล้อมที่ตรงกันและใช้ **ชื่อเดียวกัน**
> ซึ่งจัดทำเอกสารไว้ใน [`ENVIRONMENT.md`](./ENVIRONMENT.md) ค่าที่กำหนดทับใน DB
> ของแฟล็กจะมีลำดับความสำคัญเหนือกว่าตัวแปรสภาพแวดล้อมดังกล่าว แฟล็กที่มี
> `requiresRestart: true` จะถูกบันทึกถาวรทันที แต่จะถูกอ่านใหม่เฉพาะตอนเริ่มต้น
> โปรเซสเท่านั้น การสลับแฟล็กดังกล่าวจะแสดงแบนเนอร์ **"รีสตาร์ตเซิร์ฟเวอร์"** ในแดชบอร์ด

## แค็ตตาล็อกแฟล็ก

แฟล็ก 74 รายการใน 6 หมวดหมู่ **ค่าเริ่มต้น** คือค่าเริ่มต้นที่กำหนดไว้ในนิยาม ซึ่งเป็นค่าที่ใช้เมื่อไม่มีทั้งค่าที่กำหนดทับใน DB และตัวแปรสภาพแวดล้อม

### ความปลอดภัย (10)

| คีย์                                    | ชนิดข้อมูล | ค่าเริ่มต้น | คำอธิบาย                                                                                                                                                                                                                                                  |
| --------------------------------------- | ---------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `REQUIRE_API_KEY`                       | boolean    | `false`     | กำหนดให้คำขอขาเข้าทั้งหมดต้องมี API key                                                                                                                                                                                                                   |
| `INPUT_SANITIZER_ENABLED`               | boolean    | `true`      | เปิดใช้งานการทำความสะอาดอินพุตสำหรับคำขอทั้งหมด                                                                                                                                                                                                           |
| `INJECTION_GUARD_MODE`                  | enum       | `off`       | โหมดป้องกันการแทรกแซงพรอมต์ ค่า: `off`, `warn`, `block`, `redact`                                                                                                                                                                                         |
| `PII_REDACTION_ENABLED`                 | boolean    | `false`     | ปกปิด PII จากคำขอ (ทำงานเป็นอิสระจาก `INPUT_SANITIZER_MODE`)                                                                                                                                                                                              |
| `PII_RESPONSE_SANITIZATION`             | boolean    | `false`     | ทำความสะอาด PII จากการตอบกลับของผู้ให้บริการ                                                                                                                                                                                                              |
| `PII_RESPONSE_SANITIZATION_MODE`        | enum       | `redact`    | โหมดสำหรับการทำความสะอาด PII ในการตอบกลับ ค่า: `redact`, `warn`, `block`, `off`                                                                                                                                                                           |
| `OUTBOUND_SSRF_GUARD_ENABLED`           | boolean    | `true`      | บล็อกคำขอขาออกไปยังช่วง IP ส่วนตัว/ภายใน                                                                                                                                                                                                                  |
| `ALLOW_API_KEY_REVEAL`                  | boolean    | `false`     | อนุญาตให้ผู้ใช้แดชบอร์ดที่ผ่านการยืนยันตัวตนเปิดเผย API key ที่จัดเก็บไว้ แทนที่จะเห็นเฉพาะค่าที่ถูกปิดบัง                                                                                                                                                |

| `OMNIROUTE_OIDC_DISABLE_PASSWORD_LOGIN` | boolean    | `false`     | เมื่อเปิดใช้งาน OIDC ให้ปิดใช้งานการเข้าสู่ระบบด้วยรหัสผ่าน เพื่อให้ผู้ใช้สามารถยืนยันตัวตนผ่าน OIDC Single Sign-On ได้เท่านั้น เมื่อปิดใช้งาน (ค่าเริ่มต้น) จะสามารถใช้ได้ทั้งการเข้าสู่ระบบด้วยรหัสผ่านและ OIDC                                         |

| `PROXY_AUTO_SELECT_ENABLED`                     | boolean | `false`     |          | เมื่อไม่มีพร็อกซีถูกกำหนดให้กับการเชื่อมต่อ ให้เลือกพร็อกซีตัวแรกที่ใช้งานได้จากรีจิสทรีโดยอัตโนมัติ ปิดไว้โดยค่าเริ่มต้น (มิฉะนั้นพร็อกซีใด ๆ ในรีจิสทรีจะกลายเป็นตัวสำรองส่วนกลาง — #3332)                                                                                                                                                                                                                                                                                           |

> ไม่ใช่แฟล็กฟีเจอร์: ไม่มีการแทนที่ค่าจาก DB และไม่มีสวิตช์บนแดชบอร์ด ดู
> [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication)

> [!NOTE]
> คอลัมน์ `Restart` ระบุแฟล็กที่มี `requiresRestart: true` — ค่าจะถูกบันทึกถาวร
> ทันที แต่จะมีผลหลังจากโหลดกระบวนการใหม่เท่านั้น แฟล็กแบบ Enum
> จะปฏิเสธค่าที่อยู่นอกชุดค่าที่อนุญาต (ตรวจสอบความถูกต้องที่ฝั่งเซิร์ฟเวอร์
> ทั้งใน `setFeatureFlagOverride()` และตัวจัดการ REST `PUT`)

## การสลับค่าของแฟล็ก

### แดชบอร์ด

ไปที่ **แดชบอร์ด → การตั้งค่า → แฟล็กฟีเจอร์**
(`/dashboard/settings/feature-flags`) กริด
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
รองรับ:

- **การค้นหา** ตามคีย์หรือคำอธิบาย และ **การกรอง** ตามหมวดหมู่ (รวมถึงมุมมองสังเคราะห์
  **ต้องรีสตาร์ต**)
- **สวิตช์** สำหรับแฟล็กแบบบูลีน และ **เมนูแบบเลื่อนลง** สำหรับแฟล็กแบบ enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`)
- **ป้ายกำกับแหล่งที่มา** สำหรับแต่ละแฟล็ก — `DB`, `ENV` หรือ `DEF` — ซึ่งแสดงว่าค่าที่มีผล
  มาจากที่ใด
- ปุ่ม **รีเซ็ต** (แสดงเฉพาะแฟล็กที่มีแหล่งที่มาเป็น `DB`) สำหรับลบค่าที่เขียนทับ
  และปุ่ม **รีเซ็ตค่าที่เขียนทับทั้งหมด** ที่ด้านล่าง
- แบนเนอร์ **รีสตาร์ตเซิร์ฟเวอร์** เมื่อมีการเปลี่ยนแปลงแฟล็ก `requiresRestart`

### REST API

การดำเนินการทั้งหมดจะผ่านเส้นทางเดียว:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts)
ทุกเมธอดจำเป็นต้องมีเซสชันแดชบอร์ดที่ผ่านการตรวจสอบสิทธิ์ (มิฉะนั้นจะได้รับ `401`)

#### `GET /api/settings/feature-flags`

ส่งคืนแฟล็กทั้งหมดพร้อมค่าที่มีผล แหล่งที่มา และข้อมูลสรุป

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... แฟล็กทั้งหมด 74 รายการ
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

กำหนดหรือลบค่าที่เขียนทับรายการเดียว เนื้อหา: `{ key: string; value?: string }`
การไม่ระบุ `value` จะลบค่าที่เขียนทับ (คืนค่า env / ค่าเริ่มต้น)

```bash
# กำหนดค่าที่เขียนทับใน DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# ลบค่าที่เขียนทับ (ไม่มี "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

การตอบกลับจะส่งคืน `effectiveValue`/`source` ใหม่, `previousValue`/
`previousSource` และ `requiresRestart` คีย์ที่ไม่รู้จักและค่า enum ที่อยู่นอกช่วง
จะถูกปฏิเสธด้วย `400`

#### `DELETE /api/settings/feature-flags`

ล้างค่าที่เขียนทับใน DB **ทั้งหมด** ในครั้งเดียว โดยคืนค่าแฟล็กทั้งหมดเป็นค่า env / ค่าเริ่มต้น
ส่งคืน `{ cleared: <count>, message: "..." }`

> [!NOTE]
> แฟล็กที่มี `requiresRestart: true` จะมีผลหลังจากรีโหลดโปรเซสแล้วเท่านั้น
> ขั้นตอนการรีสตาร์ตของแดชบอร์ดจะเรียก `POST /api/restart` แล้วทำการสำรวจ
> `GET /api/health/ping` จนกว่าเซิร์ฟเวอร์จะกลับมาทำงาน

## การใช้เส้นทางสำรองฉุกเฉินเมื่องบประมาณหมด

`OMNIROUTE_EMERGENCY_FALLBACK` (หมวดหมู่ `runtime`, ค่าเริ่มต้น `true`) ควบคุม
เส้นทางสำรองฟรีฉุกเฉินใน
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)
เมื่อเปิดใช้งาน คำขอที่ใช้งบประมาณจนหมดจะถูกส่งไปยังผู้ให้บริการ/โมเดลสำรองฟรี
แทนที่จะล้มเหลวทันที ตั้งค่าเป็น `false` (หรือ `0`) — ผ่านสวิตช์บนแดชบอร์ด
ค่าที่เขียนทับใน DB หรือตัวแปรสภาพแวดล้อม `OMNIROUTE_EMERGENCY_FALLBACK` —
เพื่อปิดใช้งานลักษณะการทำงานนี้ และปล่อยให้คำขอที่ใช้งบประมาณหมดล้มเหลว
(แสดงเป็นสวิตช์บนแดชบอร์ดใน PR #3741 / #3752)
