## Feature Flags คืออะไร

Feature flag คือตัวสลับที่มีชื่อ (ชนิด boolean หรือ enum) ซึ่งสามารถเปลี่ยนค่าได้ใน
ขณะรันไทม์และบันทึกถาวรไว้ในฐานข้อมูล โดยไม่จำเป็นต้องปรับใช้โปรเซสใหม่ แต่ละ
แฟล็กอธิบายด้วย `FeatureFlagDefinition` ซึ่งประกอบด้วย `key`, `label`,
`description`, `category`, `defaultValue`, `type` และคำใบ้ `requiresRestart`

### ลำดับการกำหนดค่า

**ค่าที่มีผลจริง** ของแฟล็กจะถูกกำหนดโดย
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ตามลำดับ
ความสำคัญต่อไปนี้ (ลำดับที่สูงกว่าจะมีผล):

1. **ค่าที่กำหนดทับใน DB** — ค่าที่จัดเก็บไว้ในตาราง `key_value` ภายใต้
   namespace `feature_flags` (ตั้งค่าผ่านแดชบอร์ดหรือ REST API)
2. **ตัวแปรสภาพแวดล้อม** — `process.env[<KEY>]` หากมีการตั้งค่าและค่าไม่ว่างเปล่า
3. **ค่าเริ่มต้นจากข้อกำหนด** — `defaultValue` จาก `featureFlagDefinitions.ts`

แฟล็กชนิด boolean จะถือว่า **เปิดใช้งาน** เมื่อค่าที่มีผลจริงคือ `"true"`,
`"1"` หรือ `"yes"` (ดู `isFeatureFlagEnabled()`)

> [!NOTE]
> แฟล็กส่วนใหญ่ยังมีตัวแปรสภาพแวดล้อมที่ตรงกันและใช้ **ชื่อเดียวกัน**
> ซึ่งจัดทำเอกสารไว้ใน [`ENVIRONMENT.md`](./ENVIRONMENT.md) ค่าที่กำหนดทับใน DB
> ของแฟล็กจะมีลำดับความสำคัญเหนือกว่าตัวแปรสภาพแวดล้อมดังกล่าว แฟล็กที่มี
> `requiresRestart: true` จะถูกบันทึกถาวรทันที แต่จะถูกอ่านใหม่เฉพาะตอนเริ่มต้น
> โปรเซสเท่านั้น การสลับแฟล็กดังกล่าวจะแสดงแบนเนอร์ **"รีสตาร์ตเซิร์ฟเวอร์"** ในแดชบอร์ด

## แค็ตตาล็อกแฟล็ก

แฟล็ก 80 รายการใน 6 หมวดหมู่ **ค่าเริ่มต้น** คือค่าเริ่มต้นตามที่กำหนดไว้ ซึ่งเป็นค่าที่ใช้เมื่อไม่มีทั้งค่าที่เขียนทับจาก DB และตัวแปรสภาพแวดล้อม

### ความปลอดภัย (10)

| คีย์                                    | ชนิดข้อมูล | ค่าเริ่มต้น | คำอธิบาย                                                                                                                                                                                                                                                |
| --------------------------------------- | ---------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `REQUIRE_API_KEY`                       | boolean    | `false`     | กำหนดให้ทุกคำขอขาเข้าต้องมีคีย์ API                                                                                                                                                                                                                     |
| `INPUT_SANITIZER_ENABLED`               | boolean    | `true`      | เปิดใช้งานการทำความสะอาดอินพุตสำหรับทุกคำขอ                                                                                                                                                                                                             |
| `INJECTION_GUARD_MODE`                  | enum       | `off`       | โหมดป้องกันการแทรกพรอมป์ ค่า: `off`, `warn`, `block`, `redact`                                                                                                                                                                                          |
| `PII_REDACTION_ENABLED`                 | boolean    | `false`     | ปกปิด PII จากคำขอ (ทำงานโดยไม่ขึ้นกับ `INPUT_SANITIZER_MODE`)                                                                                                                                                                                           |
| `PII_RESPONSE_SANITIZATION`             | boolean    | `false`     | ทำความสะอาด PII จากการตอบกลับของผู้ให้บริการ                                                                                                                                                                                                            |
| `PII_RESPONSE_SANITIZATION_MODE`        | enum       | `redact`    | โหมดสำหรับการทำความสะอาด PII ในการตอบกลับ ค่า: `redact`, `warn`, `block`, `off`                                                                                                                                                                         |
| `OUTBOUND_SSRF_GUARD_ENABLED`           | boolean    | `true`      | บล็อกคำขอขาออกไปยังช่วง IP ส่วนตัว/ภายใน                                                                                                                                                                                                                |
| `ALLOW_API_KEY_REVEAL`                  | boolean    | `false`     | อนุญาตให้ผู้ใช้แดชบอร์ดที่ผ่านการยืนยันตัวตนเปิดเผยคีย์ API ที่จัดเก็บไว้ แทนที่จะเห็นเฉพาะค่าที่ถูกปิดบัง                                                                                                                                              |
| `AUTH_LOG_INCLUDE_ACCOUNT_ID`           | boolean    | `false`     | รวมคำนำหน้าบัญชีไว้ในบรรทัดบันทึก AUTH (เช่น "กำลังใช้บัญชี <provider>: abc12345...") ปิดใช้งานโดยค่าเริ่มต้น เพื่อให้ตัวระบุบัญชีถูกปกปิดจากบันทึกกระบวนการแบบใช้ร่วมกัน/หลายผู้เช่า ทำงานโดยไม่ขึ้นกับโหมดดีบัก การสลับโหมดดีบักจะไม่เปิดเผยข้อมูลนี้ |
| `OMNIROUTE_OIDC_DISABLE_PASSWORD_LOGIN` | boolean    | `false`     | เมื่อเปิดใช้งาน OIDC ให้ปิดใช้งานการเข้าสู่ระบบด้วยรหัสผ่าน เพื่อให้ผู้ใช้ยืนยันตัวตนได้ผ่าน OIDC Single Sign-On เท่านั้น เมื่อปิดใช้งาน (ค่าเริ่มต้น) จะสามารถใช้ทั้งการเข้าสู่ระบบด้วยรหัสผ่านและ OIDC ได้                                            |

| `PROXY_AUTO_SELECT_ENABLED`                     | boolean | `false`     |          | เมื่อไม่มีพร็อกซีถูกกำหนดให้กับการเชื่อมต่อ ให้เลือกพร็อกซีตัวแรกที่ใช้งานได้จากรีจิสทรีโดยอัตโนมัติ โดยค่าเริ่มต้นจะปิดไว้ (มิฉะนั้นพร็อกซีใดๆ ในรีจิสทรีจะกลายเป็นตัวสำรองส่วนกลาง — #3332)                                                                                                                                                                                                                                                                         |

## การสลับแฟล็ก

### แดชบอร์ด

ไปที่ **แดชบอร์ด → การตั้งค่า → แฟล็กคุณสมบัติ**
(`/dashboard/settings/feature-flags`) ตาราง
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
รองรับ:

- **ค้นหา** ด้วยคีย์หรือคำอธิบาย และ **กรอง** ตามหมวดหมู่ (รวมถึงมุมมองสังเคราะห์ **ต้องรีสตาร์ท**)
- **ปุ่มสลับ** สำหรับแฟล็กแบบบูลีน และ **เมนูแบบเลื่อนลง** สำหรับแฟล็กแบบ enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`)
- **ป้ายแหล่งที่มา** สำหรับแต่ละแฟล็ก — `DB`, `ENV`, หรือ `DEF` — แสดงว่าค่าที่ใช้งานอยู่มาจากที่ใด
- ปุ่ม **รีเซ็ต** (แสดงเฉพาะแฟล็กที่มีแหล่งที่มาจาก `DB`) เพื่อยกเลิกการตั้งค่าทับ และปุ่ม **รีเซ็ตการตั้งค่าทับทั้งหมด** ที่ด้านล่าง
- แบนเนอร์ **รีสตาร์ทเซิร์ฟเวอร์** เมื่อแฟล็ก `requiresRestart` ถูกเปลี่ยนแปลง

### REST API

การดำเนินการทั้งหมดจะผ่านเส้นทางเดียว:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts)
ทุกเมธอดต้องใช้เซสชันแดชบอร์ดที่ผ่านการรับรองความถูกต้อง (`401` หากไม่เป็นเช่นนั้น)

#### `GET /api/settings/feature-flags`

ส่งคืนแฟล็กทุกรายการพร้อมค่าที่ใช้งานอยู่ แหล่งที่มา และสรุป

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... แฟล็กทั้งหมด 77 รายการ
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

ตั้งค่าหรือลบการตั้งค่าทับรายการเดียว เนื้อหา: `{ key: string; value?: string }`
การละเว้น `value` จะลบการตั้งค่าทับ (คืนค่า env / default)

```bash
# ตั้งค่าการตั้งค่าทับ DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# ลบการตั้งค่าทับ (ไม่มี "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

การตอบกลับจะสะท้อน `effectiveValue`/`source` ใหม่, `previousValue`/
`previousSource` และ `requiresRestart` คีย์ที่ไม่รู้จักและค่า enum ที่อยู่นอกช่วงจะถูกปฏิเสธด้วย `400`

#### `DELETE /api/settings/feature-flags`

ล้างการตั้งค่าทับ DB **ทั้งหมด** ในคราวเดียว คืนค่าแฟล็กทุกรายการเป็นค่า env / default
ส่งคืน `{ cleared: <count>, message: "..." }`

> [!NOTE]
> แฟล็กที่มี `requiresRestart: true` จะมีผลหลังจากรีโหลดกระบวนการเท่านั้น
> ขั้นตอนการรีสตาร์ทของแดชบอร์ดจะเรียก `POST /api/restart` จากนั้นจะตรวจสอบ
> `GET /api/health/ping` จนกว่าเซิร์ฟเวอร์จะกลับมาทำงาน

## ทางเลือกสำรองฉุกเฉินเมื่องบประมาณหมด

`OMNIROUTE_EMERGENCY_FALLBACK` (หมวดหมู่ `runtime`, ค่าเริ่มต้น `true`) ใช้ควบคุม
เส้นทางทางเลือกสำรองแบบไม่มีค่าใช้จ่ายในกรณีฉุกเฉินใน
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)
เมื่อเปิดใช้งาน คำขอที่ใช้งบประมาณจนหมดจะถูกส่งต่อไปยังผู้ให้บริการ/โมเดลทางเลือกสำรอง
แบบไม่มีค่าใช้จ่าย แทนที่จะล้มเหลวทันที ให้ตั้งค่าเป็น `false` (หรือ `0`) — ผ่านสวิตช์
บนแดชบอร์ด การแทนที่ค่าใน DB หรือตัวแปรสภาพแวดล้อม
`OMNIROUTE_EMERGENCY_FALLBACK` — เพื่อปิดใช้งานลักษณะการทำงานนี้ และปล่อยให้คำขอ
ที่ใช้งบประมาณจนหมดล้มเหลว (แสดงเป็นสวิตช์บนแดชบอร์ดใน PR #3741 / #3752)

การตอบกลับที่ให้บริการผ่านทางเลือกสำรองนี้จะมี
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>` เพื่อให้
ไคลเอนต์ทราบได้ว่าคำขอถูกเปลี่ยนเส้นทาง โดยไม่ต้องเปรียบเทียบความแตกต่างระหว่าง
`X-OmniRoute-Provider` กับคำขอของตน ส่วนการตอบกลับอื่นทั้งหมดจะไม่มีส่วนหัวนี้
