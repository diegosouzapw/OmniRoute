OmniRoute มาพร้อมกับพร็อกซีฟรีที่คัดสรรไว้ในตาราง `free_proxies`
โดยซิงค์จากผู้ให้บริการภายนอก (1proxy, proxifly, iplocate, webshare)
แดชบอร์ดแสดงรายการเหล่านี้ภายใต้ **Settings → Free Proxies** เอกสารนี้
ครอบคลุมการกรอง การเรียงลำดับ การนับ และการรายงานข้อผิดพลาดในการซิงค์
ฝั่งเซิร์ฟเวอร์ที่เส้นทางรายการเปิดให้ใช้งาน

## เส้นทางรายการ — `GET /api/settings/free-proxies`

ส่งคืนรายการบางส่วนที่ผ่านการกรอง เรียงลำดับ และแบ่งหน้า พร้อมจำนวนทั้งหมด
การกรองและการนับเกิดขึ้นใน SQL ดังนั้น UI จึงสามารถแสดงจำนวนรวมจริง
(เช่น `Total: 0`) โดยไม่ต้องโหลดทุกแถวเข้าสู่หน่วยความจำ

### พารามิเตอร์คิวรี

| พารามิเตอร์       | ชนิดข้อมูล                         | ค่าเริ่มต้น | ความหมาย                                                                                                                        |
| ----------------- | ---------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | สตริง                              | `""`        | `LIKE` แบบคำนึงถึงตัวพิมพ์เล็ก-ใหญ่ในคอลัมน์โฮสต์ (และแหล่งที่มา)                                                               |
| `protocol`        | สตริง                              | `""`        | ตัวกรอง `type`: `http` / `https` / `socks4` / `socks5` ค่าว่าง = ทั้งหมด                                                        |
| `country`         | สตริง                              | `""`        | ตัวกรอง `countryCode` (ISO-2) ค่าว่าง = ทั้งหมด                                                                                 |
| `minQuality`      | ตัวเลข                             | `0`         | เฉพาะแถวที่มี `qualityScore >= minQuality` โดย `0` = ไม่มีค่าขั้นต่ำ                                                            |
| `disabledSources` | สตริง                              | `""`        | รหัสแหล่งที่มาที่คั่นด้วยจุลภาคเพื่อยกเว้น (เช่น `proxifly,webshare`)                                                           |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`   | `quality` = คะแนนจากมากไปน้อย; `latency` = เวลาแฝงจากน้อยไปมาก (ค่า null อยู่ท้ายสุด); `recent` = `lastValidated` จากใหม่ไปเก่า |
| `offset`          | ตัวเลข                             | `0`         | ตำแหน่งเริ่มต้นของการแบ่งหน้า                                                                                                   |
| `limit`           | ตัวเลข                             | `50`        | ขนาดหน้า (จำกัดค่าสูงสุดที่ฝั่งเซิร์ฟเวอร์)                                                                                     |

### การตอบกลับ

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 จากต้นทาง"],
    "webshare": ["หมดเวลาการเชื่อมต่อเครือข่าย"]
  }
}
```

`total` แสดงจำนวนรวมที่ผ่านการกรอง **ก่อน** การแบ่งหน้า ดังนั้น UI จึงสามารถแสดง
`Total: N` และ `hasMore` แยกจากกันได้ `syncErrors` ใช้รหัสแหล่งที่มาเป็นคีย์ และ
จะมีข้อมูลเฉพาะแหล่งที่มาที่ซิงค์ครั้งล่าสุดล้มเหลวเท่านั้น — ผลลัพธ์ `Total: 0`
จะไม่เกิดขึ้นโดยไม่มีการแจ้งสาเหตุ

## เพิ่มไปยังพูล — `POST /api/settings/free-proxies/[id]/add-to-pool`

เลื่อนสถานะพร็อกซีฟรีเข้าสู่พูล `proxy_registry` ที่มีการจัดการ โดยตรวจสอบ
ต้นทางก่อน เมื่อสำเร็จจะส่งคืนรหัสพร็อกซีใหม่ในพูลและเวลาแฝงที่วัดได้

## ซิงค์ — `POST /api/settings/free-proxies/sync`

ดึงข้อมูลใหม่จากแหล่งที่มาที่เปิดใช้งานทั้งหมด (หรือเฉพาะชุดย่อยใน `{ "sources": [...] }`)
แต่ละแหล่งจะซิงค์อย่างอิสระ หากแหล่งใดล้มเหลว ระบบจะบันทึกไว้ใน `syncErrors`
ขณะที่แหล่งอื่นยังคงดำเนินการจนเสร็จ ดังนั้นการซิงค์เพียงบางส่วนจะไม่ลบ
ข้อมูลเดิมที่ใช้งานได้

## สถิติ — `GET /api/settings/free-proxies/stats`

ส่งคืนข้อมูลสรุป `total / inPool / avgQuality / bySource / lastSyncAt`
โดยไม่มีเพย์โหลดของแถว — ใช้โดยวิดเจ็ตส่วนหัวของแดชบอร์ด
