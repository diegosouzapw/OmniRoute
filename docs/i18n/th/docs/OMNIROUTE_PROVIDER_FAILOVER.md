ความล้มเหลวจะถูกจำแนกประเภทก่อนตัดสินใจลองใหม่

ความล้มเหลวชั่วคราว เช่น การหมดเวลา ข้อผิดพลาดของเครือข่าย การจำกัดอัตรา และการตอบกลับ 5xx จากผู้ให้บริการ อาจสลับไปใช้ผู้ให้บริการสำรอง ส่วนข้อผิดพลาดด้านการยืนยันตัวตน ข้อผิดพลาดด้านสิทธิ์ คำขอที่ไม่ถูกต้อง โมเดลที่ไม่พร้อมใช้งาน และความล้มเหลวที่ไม่ทราบสาเหตุ จะไม่ถูกลองใหม่โดยไม่มีการพิจารณา

นโยบายข้ามผู้ให้บริการเริ่มต้นอนุญาตให้ลองกับผู้ให้บริการได้สูงสุดสามครั้ง โดยจะลองใหม่เมื่อพบการจำกัดอัตราหรือการหมดเวลา และแยกการปิดใช้งานโดยผู้ดูแลระบบออกจากสถานะวงจรชั่วคราว

สถานะวงจร ได้แก่ `closed`, `open` และ `half_open` ช่วงพักรอจะกำหนดเวลาสำหรับการทดสอบที่มีขอบเขตจำกัด หากการทดสอบสำเร็จ วงจรจะปิด และหากการทดสอบล้มเหลว วงจรจะเปิดอีกครั้ง
