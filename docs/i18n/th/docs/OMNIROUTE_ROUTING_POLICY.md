การกำหนดเส้นทางจะคงตรรกะการเลือกความสามารถและคอมโบที่มีอยู่ไว้ จากนั้นจึงนำปัจจัยด้านการจัดสรร ความพร้อมใช้งาน วงจร โควตา เวลาแฝง ความน่าเชื่อถือ ค่ากำหนดโมเดล และค่ากำหนดต้นทุนมาพิจารณา

คะแนนแบบปรับตัวสามารถอธิบายได้ และส่งคืนทั้งตัวเลือกที่ได้รับเลือกและตัวเลือกทั้งหมดที่จัดอันดับแล้ว ตัวเลือกที่โควตาหมด ไม่ได้รับอนุญาตให้จัดสรร หรือมีวงจรเปิดอยู่จะไม่มีสิทธิ์ได้รับเลือก ส่วนตัวเลือกที่ไม่ทราบสถานะโควตาจะยังคงมีสิทธิ์ โดยใช้ปัจจัยโควตาแบบเป็นกลาง

การแสดงตัวอย่างเส้นทางให้ผลลัพธ์ที่กำหนดแน่นอนและไม่มีการส่งคำขอไปยังโมเดลต้นทาง:

`POST /api/omniroute/route/preview`

การตอบกลับประกอบด้วยคะแนน ปัจจัย และเหตุผลของตัวเลือกแต่ละรายการ ผู้ให้บริการที่ได้รับเลือก และ `liveRequestExecuted: false`
