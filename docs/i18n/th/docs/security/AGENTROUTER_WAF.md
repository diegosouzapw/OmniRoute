เกตเวย์ต้นทาง `agentrouter` ใช้ตัวกรองเนื้อหาแบบอิงคีย์เวิร์ดกับ
`messages[].content` ตัวกรองนี้ทำงานแบบกำหนดแน่นอนบางส่วน (บล็อกวลี
บางรายการเสมอ) และแบบความน่าจะเป็นบางส่วน (ไวต่อคำขอแบบถี่เป็นชุด —
จะเข้มงวดมากขึ้นหลังจากมีคำขออย่างรวดเร็ว และกลับสู่ปกติหลังจากช่วงพัก)

เมื่อ WAF บล็อกคำขอ ระบบจะส่งคืน:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## ขอบเขตของตัวกรอง

WAF ตรวจสอบเฉพาะ `messages[].content` โดย **ไม่** ตรวจสอบ:

- พรอมต์ `system`
- บล็อกเนื้อหาแบบมีโครงสร้าง (`tool_result`, `tool_use`, `thinking`, `image`)
- ฟิลด์ `description` และ `input_schema` ของเครื่องมือ
- เมทาดาทาของคำขอ ส่วนหัว หรือรหัสโมเดล

## รูปแบบที่ถูกบล็อกเสมอ (ไม่คำนึงถึงตัวพิมพ์เล็ก-ใหญ่)

| รูปแบบ                         | หมายเหตุ                                                |
| ------------------------------ | ------------------------------------------------------- |
| รูปแบบใดๆ ของ `Lorem ipsum`    | คำศัพท์ Lorem ภาษาละตินทั้งหมดถูกบล็อก                  |
| `language model` (อยู่เดี่ยวๆ) | "the language model" และ "large language model" ผ่านได้ |
| `virtual assistant`            | "AI assistant" ผ่านได้                                  |
| `I'm here to help`             | "here to help" เพียงอย่างเดียวก็ถูกบล็อกเช่นกัน         |
| `Claude, made by Anthropic`    | เฉพาะวลีเต็มเท่านั้น                                    |

## รูปแบบที่แทบจะถูกบล็อกเสมอ

| รูปแบบ                                                | หมายเหตุ                                         |
| ----------------------------------------------------- | ------------------------------------------------ |
| `placeholder`                                         | เมื่ออยู่เดี่ยวๆ (ไม่ใช่ชื่อพารามิเตอร์ เป็นต้น) |
| `dummy data`                                          | วลีตั้งต้นที่ใช้กันทั่วไปสำหรับฟิกซ์เจอร์        |
| `foo bar baz`                                         | วลีข้อความตัวแทนมาตรฐาน                          |
| โทเค็นสั้นที่ซ้ำกัน (`AAA BBB CCC`, `test test test`) | ตัวตรวจจับการยัดคีย์เวิร์ด                       |

## พฤติกรรมภายใต้โหลด

หลังจากมีคำขออย่างรวดเร็วประมาณ 5 รายการภายในช่วงเวลาสั้นๆ WAF จะเริ่มบล็อกเนื้อหา
ที่ตามปกติควรผ่านได้ บักเก็ตจะผ่อนคลายลงหลังจากไม่มีการใช้งานประมาณ 5–10 วินาที
นี่คือตัวจำกัดอัตราเดียวกันที่ผูกกับ IP และคีย์ ซึ่งเป็นสาเหตุของข้อผิดพลาด
`400 content-blocked` แบบเป็นครั้งคราว เมื่อ Claude Code หรือ Codex CLI
เรียกใช้เครื่องมือหรือส่งข้อความหลายครั้งต่อเนื่องกันอย่างรวดเร็ว

## การบรรเทาปัญหาที่นำไปใช้ใน OmniRoute แล้ว

1. **`open-sse/services/wafRateLimit.ts`** — ตัวป้องกันคำขอแบบถี่เป็นชุดที่บังคับให้มี
   ระยะห่างขั้นต่ำ 500 ms ระหว่างคำขอขาออกไปยัง URL `agentrouter:*`
   ใดๆ ระยะห่างนี้ต่ำกว่าระดับความหน่วงที่มนุษย์รับรู้ได้อย่างมาก และช่วยป้องกัน
   ไม่ให้ WAF เริ่มทำงานกับทราฟฟิกปกติ

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — เมื่อต้นทางส่งคืน
   `400 content-blocked` ตัวดำเนินการจะลอง URL เดิมอีกครั้งโดยใช้
   exponential backoff (1.5 s, 3.0 s, สูงสุด 2 ครั้ง) หลังจากช่วงหน่วง
   WAF มักจะผ่อนคลายลงและการลองใหม่จะสำเร็จ

3. **`tests/unit/compression/harness.test.ts`** — ฟิกซ์เจอร์ทดสอบ
   `longInput` ถูกเปลี่ยนจาก `"lorem ipsum dolor sit amet ".repeat(40)`
   เป็น `"example content for testing purposes ".repeat(40)` เพื่อให้เมื่อ
   Claude Code อ่านไฟล์นี้ผ่านเครื่องมือ `Read` เนื้อหาของไฟล์
   จะไม่ถูกส่งย้อนกลับผ่านบล็อก `tool_result` และกระตุ้น WAF

## คำแนะนำสำหรับพรอมต์และเอาต์พุตของเครื่องมือ

หากเซสชัน Claude Code หรือ Codex CLI พบ
`400 content-blocked` ซ้ำๆ ให้ตรวจสอบข้อความล่าสุดของผู้ใช้และผลลัพธ์ล่าสุด
ของเครื่องมือว่ามีรูปแบบใดๆ ข้างต้นหรือไม่ แล้วเรียบเรียงข้อความใหม่ วิธีแก้ปัญหาชั่วคราว
ที่ใช้กันทั่วไป:

- แทนที่ `Lorem ipsum …` ด้วย `example text …` หรือเนื้อหาจริง
  ที่การทดสอบหรือฟิกซ์เจอร์กำลังพยายามจำลอง
- แทนที่ `placeholder` (เมื่ออยู่เดี่ยวๆ) ด้วย `example value`,
  `sample value` หรือค่าจริง
- แทนที่ `language model` ด้วย `large language model` หรือ `the model`
- แทนที่ `dummy data` ด้วย `sample data` หรือค่าตั้งต้นที่สมจริง
- แทนที่ `I'm here to help` / `here to help` ด้วยประโยคเปิดที่เฉพาะเจาะจงกว่า
  (เช่น "ฉันจะตรวจสอบไฟล์ที่คุณกล่าวถึง")

## การรายงานผลบวกลวงไปยังต้นทาง

ตัวกรองปัจจุบันเข้มงวดเกินไป — โดยบล็อก "Lorem ipsum" ในบล็อก
`tool_result` แม้ว่าจะเห็นได้ชัดว่าผู้ปฏิบัติงานไม่ได้ตั้งใจแทรกพรอมต์
ผู้ปฏิบัติงานที่ต้องการให้แก้ไขปัญหานี้จากต้นทางควรติดต่อ
`agentrouter.org` เพื่อรายงานผลบวกลวง รายการบล็อกข้างต้นเป็นผลเชิงประจักษ์
