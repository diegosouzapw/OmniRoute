## `claude-web`

`claude-web`-ը OpenAI ձևաչափով զրույցի հարցումներ է ուղարկում վավերացված `claude.ai`
դիտարկչային աշխատաշրջանի միջոցով։ Կատարողը նորմալացնում է տրամադրված cookie-ն, որոշում է մեկ վավերացված
կազմակերպություն, նախապատրաստում է զրույցի վիճակը, ընտրում է ուղիղ կամ դիտարկչային փոխադրամիջոց և
խստորեն փոխակերպում է վերին հոսքի SSE պատասխանը։ Համակարգումը կատարվում է
`open-sse/executors/claude-web.ts:320`-ում։

> **Առաջին անգա՞մ եք օգտագործում Web Cookie մատակարարներ։**
>
> Նախքան մատակարարին հատուկ այս ուղեցույցին հետևելը կարդացեք **`docs/getting-started/WEB-COOKIE-GUIDE.md`**-ը՝ ընդհանուր կարգավորման գործընթացի, վավերացման ուղեցույցների, սահմանափակումների և խնդիրների լուծման մասին։

### Մոդելների կատալոգ

Մատակարարների ռեեստրն այժմ տրամադրում է հենց այս յոթ ստատիկ մոդելի ID-ները
(`open-sse/config/providers/registry/claude/web/index.ts:11`)։

| Մոդելի ID                   | Ցուցադրվող անուն        |
| --------------------------- | ----------------------- |
| `claude-fable-5`            | Claude Fable 5 (վեբ)    |
| `claude-opus-4-8`           | Claude Opus 4.8 (վեբ)   |
| `claude-sonnet-5`           | Claude Sonnet 5 (վեբ)   |
| `claude-haiku-4-5-20251001` | Claude Haiku 4.5 (վեբ)  |
| `claude-opus-4-7`           | Claude Opus 4.7 (վեբ)   |
| `claude-opus-4-6`           | Claude Opus 4.6 (վեբ)   |
| `claude-sonnet-4-6`         | Claude Sonnet 4.6 (վեբ) |

Այս մատակարարի համար մոդելների դինամիկ հայտնաբերում ներդրված չէ։ Վերևի ցանկը
կատարման ժամանակ օգտագործվող կատալոգն է։

### Հավատարմագրերի և կազմակերպության որոշում

Տրամադրեք կամ `claude.ai`-ի Cookie վերնագիրն ամբողջությամբ, կամ աշխատաշրջանի առանձին արժեքը։ Առանձին արժեքները
նորմալացվում են որպես `sessionKey`, իսկ մյուս cookie-ները տրամադրված լինելու դեպքում պահպանվում են։ Կատարողը
cookie-ն ընդունում է `cookie`-ի կամ `apiKey`-ի միջոցով և
միացման տվյալներից կարդում է ընտրովի `deviceId` ու `orgId` արժեքները
(`open-sse/executors/claude-web.ts:72`)։

Եթե `orgId`-ը բացակայում է, կատարողը կանչում է `GET https://claude.ai/api/organizations` և օգտագործում է վավերացված Claude Web աշխատաշրջանի
վերադարձած առաջին կազմակերպությունը
(`open-sse/executors/claude-web.ts:141`)։ Եթե վավեր կազմակերպություն չի
վերադարձվում, այն ապահով կերպով ձախողվում է, մերժված աշխատաշրջանի լիազորումը հաղորդում է որպես 401 և տարբերակում է Cloudflare-ի
ստուգումը վավերացման ձախողումից։

### Զրույցի գործողություններ

Վերին մակարդակի ընտրովի `claude_web` օբյեկտը խիստ է։ Անհայտ դաշտերը մերժվում են։ Դրա
ընդունելի դաշտերը սահմանված են `open-sse/executors/claude-web/session.ts:50`-ում։

| Դաշտ                  | Նշանակություն                                                         |
| --------------------- | --------------------------------------------------------------------- |
| `operation`           | Լռելյայն՝ `completion`, կրկնվող փորձի քայլի համար օգտագործեք `retry`  |
| `conversation_id`     | Գոյություն ունեցող զրույցի բացահայտ UUID                              |
| `parent_message_uuid` | Ծնող օգնականի հաղորդագրության բացահայտ UUID                           |
| `timezone`            | Վավեր IANA ժամային գոտու անուն                                        |
| `locale`              | Կառուցվածքային առումով վավեր տեղայնացուցիչ                            |
| `tool_states`         | Հաշվի գործիքների վիճակների ընտրովի զանգված՝ առավելագույնը 128 գրառում |

Նախապատրաստված հարցումներն օգտագործում են վերին հոսքի երկու վերջնակետերից մեկը
(`open-sse/executors/claude-web.ts:203`)։

- Նոր կամ շարունակական քայլը ուղարկվում է
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/completion`։
- Կրկնվող փորձն ուղարկվում է
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion`։

Նոր քայլը ներառում է `create_conversation_params`։ Քեշավորված կամ բացահայտորեն կապակցված շարունակությունը
ներառում է `parent_message_uuid` և բաց է թողնում `create_conversation_params`։ Կրկնվող փորձը պահանջում է և՛
զրույցի, և՛ ծնող հաղորդագրության վիճակը և հուշում չի ուղարկում
(`open-sse/executors/claude-web/session.ts:254`)։ Նոր զրույցները վավերացված
օգտագործողի միջերեսը բացում են `/new`-ում, իսկ քեշավորված կամ բացահայտորեն կապակցված շարունակությունները բացում են զրույցի ճշգրիտ էջը
(`open-sse/executors/claude-web/session.ts:324`)։

Զրույցի վիճակն օպերատիվ հիշողության քեշ է, որի բանալին SHA-256 հաշվի տիրույթն ու կանոնական
կանչողի տրանսկրիպտն են։ Գրառումների ժամկետը լրանում է 30 րոպեից, իսկ քեշը սահմանափակված է 5,000 գրառումով
(`open-sse/executors/claude-web/session.ts:12`)։ Վիճակը ամրագրվում է միայն այն բանից հետո, երբ խիստ
հոսքի վերլուծիչը հայտնաբերում է `message_stop`-ը։ Գործընթացի վերագործարկման դեպքում այն կորչում է։ Քեշում չգտնվելու դեպքում
բազմահաղորդագրությամբ հարցումը սերիականացվում է մեկ վերականգնման հուշման մեջ՝ ավելի վաղ
հաղորդագրությունները լուռ անտեսելու փոխարեն։

Տեղայնացուցիչն ու ժամային գոտին օգտագործում են հետևյալ առաջնահերթությունը՝ հարցման `claude_web` արժեք, միացման արժեք,
կատարման միջավայրի արժեք, այնուհետև՝ `en-US` տեղայնացուցիչի կամ `UTC` ժամային գոտու համար
(`open-sse/executors/claude-web/session.ts:218`)։

### Գործիքներ և հարցման օգտակար բեռներ

Ուղիղ հարցումները փոխակերպում են միայն կանչողի տրամադրած, կառուցվածքային առումով վավեր OpenAI ֆունկցիոնալ գործիքները։
Արհեստականորեն ստեղծված ստատիկ լռելյայն գործիքների ցանկ չկա
(`open-sse/executors/claude-web/payload.ts:102`)։

Դրա փոխարեն դիտարկչային հարցումները որսում են վավերացված օգտագործողի միջերեսի հարցումը և պահպանում դրա հաշվի գործիքները,
գործիքների վիճակներն ու անհատականացված ոճերը։ Նախապատրաստված զրույցի, մոդելի, դատողության, հուշման և
հաղորդագրության UUID դաշտերը, այնուամենայնիվ, գերակայում են որսված հարցման նկատմամբ
(`open-sse/executors/claude-web/browserTransport.ts:175`)։ Դիտարկչային ձևանմուշների տիրույթը որոշվում է
հաշվի, կազմակերպության, cookie-ի, տեղայնացուցիչի և ժամային գոտու հեշով, իսկ դրանց ժամկետը լրանում է 30 րոպեից
(`open-sse/executors/claude-web/browserTransport.ts:11`,
`open-sse/executors/claude-web/browserTransport.ts:158`)։ Երբ ուղիղ հարցումը կանչողի գործիքներ չունի,
այն կարող է վերաօգտագործել այդ տիրույթային ձևանմուշը, իսկ կանչողի բացահայտ գործիքները գերակայում են
(`open-sse/executors/claude-web/browserTransport.ts:214`)։

### Փոխադրամիջոցի ընտրություն

Լռելյայն ուղին `sendClaudeWebDirect()`-ն է, որը կանչում է `tlsFetchClaude()`-ը՝ կազմաձևված
Chrome 146 պրոֆիլով և տրամադրված cookie-ով (`open-sse/services/claudeTlsClient.ts:23`)։ Այն
չի գործարկում լուծիչ և չի ստեղծում փոխարինող cookie։

Սահմանեք `WEB_COOKIE_USE_BROWSER`-ը որպես `1`, `true` կամ `on`, որպեսզի հաշվի շրջանակով սահմանափակված դիտարկիչի
ադապտերը դառնա հիմնական փոխանցման միջոցը։ Սահմանեք `OMNIROUTE_BROWSER_POOL`-ը նույն արժեքներից որևէ մեկով՝
թույլ տալու, որ ճանաչված Cloudflare 403 ստուգման դեպքում ուղղակի փոխանցումից անցում կատարվի դեպի
դիտարկիչի ադապտեր (`open-sse/executors/claude-web.ts:195`)։ HTTP-ի այլ սխալները չեն գործարկում
այդ պահուստային անցումը։

Դիտարկիչի ադապտերը cookie-ները պահում է նույն համատեղ օգտագործվող Playwright համատեքստում, օգտագործում է վերևում նկարագրված՝ տվյալ շրջանակի համար
հեշավորված բանալին և պատասխանի ամբողջացումն ուղարկում է այդ համատեքստից
(`open-sse/executors/claude-web/browserTransport.ts:444`)։ Այն երբեք դիտարկիչի միջոցով ստացված
cookie-ն չի արտահանում ուղղակի TLS հաճախորդ։ Դիտարկիչով կրկնակի փորձերը պահանջում են ժամկետանց չլինող UI ձևանմուշ, որը կապված է
նույն փաստացի Playwright համատեքստին (`open-sse/executors/claude-web/browserTransport.ts:467`)։
Դիտարկիչում պատասխանների ընթերցումն իրականացվում է աստիճանաբար՝ վավերացված էջում, հաշվի է առնում հարցման չեղարկումը
և չեղարկում է վերին հոսքի մարմինը հենց որ դրա չափը գերազանցում է 16 MiB-ը
(`open-sse/executors/claude-web/browserTransport.ts:259`)։

Կատարիչը ընդհանուր հարցումների գրանցիչին վերադարձնում է զգայուն տվյալներից մաքրված աուդիտի ներկայացում․ կազմակերպության,
զրույցի և հաղորդագրությունների UUID-ները, հուշման տեքստը, գործիքների սահմանումները, cookie-ները և սարքերի նույնացուցիչները
բացառված են (`open-sse/executors/claude-web.ts:237`,
`open-sse/executors/claude-web.ts:252`)։ Փոխանցման բացառությունները նույնպես նետված հաղորդագրության փոխարեն վերադարձնում են
միացման ընդհանուր սխալ։

### SSE-ի վարքագիծը

`createClaudeWebResponse()`-ը մշակում է LF կամ CRLF շրջանակավորումը և բազմատող `data:` դաշտերը։ Այն
տեքստային տարբերությունները համապատասխանեցնում է `content`-ին, մտածողության տարբերությունները՝ `reasoning_content`-ին, իսկ հայտնի մետատվյալների իրադարձությունները՝
պատասխանի `claude_web` ընդլայնմանը։ Մետատվյալների յուրաքանչյուր իրադարձություն ներկայացվում է իր դաշտերի
թույլատրելի ցանկի միջոցով (`open-sse/executors/claude-web/stream.ts:37`)։ Զրույցի,
ծնող հաղորդագրության, օգնականի հաղորդագրության և գործողության մետատվյալները նաև վերադարձվում են
`X-OmniRoute-Claude-Web-*` վերնագրերում (`open-sse/executors/claude-web/stream.ts:364`)։

Վերլուծիչը խափանվում է անվտանգ ռեժիմով՝ սխալ կառուցվածքով JSON-ի, վերին հոսքի `error` իրադարձությունների, անհայտ իրադարձությունների տեսակների,
անվավեր հերթականության, բովանդակության բլոկների անհամապատասխանության կամ մինչև `message_stop`-ը EOF-ի հասնելու դեպքում։ Հոսքային ելքը
արձակում է ավարտի մեկ հատված և մեկ `[DONE]`, իսկ բուֆերացված ելքն օգտագործում է նույն վերլուծիչը։ Վերլուծիչը
`message_stop`-ն անմիջապես համարում է ավարտական, չեղարկում է վերին հոսքի հաջորդող տվյալները և
ստորին հոսքի չեղարկումը փոխանցում է վերին հոսքի ընթերցիչին (`open-sse/executors/claude-web/stream.ts:461`,
`open-sse/executors/claude-web/stream.ts:563`)։ Չավարտված SSE տողերի և կուտակված իրադարձությունների
սահմանաչափը 1 MiB է (`open-sse/executors/claude-web/stream.ts:17`,
`open-sse/executors/claude-web/stream.ts:62`)։

### Թեստավորում

Գործարկեք Claude Web-ի դետերմինիստական թեստերի հավաքածուն՝ առանց իրական հավատարմագրերի․

```powershell
node --import tsx/esm --test tests/unit/claude-web-auto-refresh.test.ts tests/unit/claude-web-browser-transport.test.ts tests/unit/claude-web-executor-split.test.ts tests/unit/claude-web-live-alignment.test.ts tests/unit/claude-web-payload-runtime.test.ts tests/unit/claude-web-session.test.ts tests/unit/claude-web-sonnet5-registry-6209.test.ts tests/unit/claude-web-stream.test.ts tests/unit/claude-web-transport.test.ts tests/unit/claude-web.test.ts tests/unit/issue-6662-repro.test.ts
```

`tests/unit/claude-web-auto-refresh.test.ts`-ում Playwright-ից կախված դեպքերը բացահայտորեն
բաց են թողնված։ Այս պահոցում ներկայումս սահմանված չէ հավատարմագրեր պահանջող Claude Web-ի իրական միջավայրի թեստի
սկրիպտ, ուստի բաց թողնված այդ դեպքերը աշխատանքի իրական ապացույց չեն։

### Կարգավորում

1. Գործարկեք OmniRoute-ը `npm run dev`-ի կամ հավաքված տեղադրման միջոցով։
2. Բացեք Վահանակ → Մատակարարներ → Ավելացնել մատակարար։
3. Ընտրեք Web Cookie կատեգորիան և Claude Web-ը։
4. Տեղադրեք վավերացված `claude.ai` հարցումից պատճենված Cookie ամբողջական վերնագիրը։
