OmniRoute-ը մատակարարի քվոտայի հեռաչափությունը տարանջատում է Ghostlight-ի հաշվառումից։

## Իրականությանը համապատասխան վիճակներ

- `healthy` նշանակում է, որ աղբյուրը հայտնել է օգտագործման համար հասանելի մնացորդային հզորության մասին։
- `approaching_limit` նշանակում է, որ աղբյուրը հայտնել է կազմաձևված շեմին հավասար կամ դրանից ցածր մնացորդային հզորության մասին։
- `exhausted` վիճակը տրվում է միայն այն դեպքում, երբ աղբյուրը հայտնում է զրոյական հզորության կամ սահմանաչափին հասած օգտագործման մասին։
- `unavailable` նշանակում է, որ աջակցվող աղբյուրին չի հաջողվել տվյալներ վերադարձնել։
- `unknown` նշանակում է, որ աջակցվող աղբյուր գոյություն չունի կամ մատակարարի սահմանաչափը հայտնի չէ։

Անհայտ վիճակը չի նշանակում սպառված վիճակ և չի ապաակտիվացնում մատակարարին։

Աղբյուրները նախընտրելի են հետևյալ հերթականությամբ՝ մատակարարի պաշտոնական API, իսկորոշված օգտագործման API, բացահայտ կերպով համապատասխանեցված պատասխանի վերնագրեր, ադմինիստրատորի կազմաձևում, տեղային գնահատումներ, անհայտ։ Տեղային գնահատումները երբեք չեն ներկայացվում որպես մատակարարի վճարումների հաշվարկման տվյալներ։

Պատասխանի վերնագրերը վերլուծվում են միայն մատակարարի բացահայտ համապատասխանեցման միջոցով։ Ընդհանուր վերնագրերի անունները համընդհանուր կիրառելի չեն համարվում։
