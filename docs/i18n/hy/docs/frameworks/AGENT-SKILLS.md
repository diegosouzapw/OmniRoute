## Ընդհանուր նկարագրություն

Կատալոգը պարունակում է **45 Agent Skills** (23 REST API + 21 CLI + 1 կազմաձևման աշխատանքային հոսք)։ Յուրաքանչյուր skill ունի՝

- **Կանոնական ID** (`omni-auth`, `cli-serve` և այլն)
- **SKILL.md** ֆայլ՝ `skills/{id}/SKILL.md`-ում, YAML frontmatter-ով (`name`, `description`) + բովանդակությամբ հարուստ markdown մարմին
- OpenAPI սպեցիֆիկացիայից և CLI ռեեստրից ստացված **REST վերջնակետեր** (API skills) կամ **CLI ենթահրամաններ** (CLI skills)
- Ուղիղ ներբեռնման համար նախատեսված **GitHub raw URL**՝ `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API-ի հայտնաբերում

| Վերջնակետ                    | Մեթոդ | Նկարագրություն                                                           | Նույնականացում |
| :--------------------------- | :---- | :----------------------------------------------------------------------- | :------------- |
| `/api/agent-skills`          | GET   | Կատալոգի ցանկ (ըստ ցանկության՝ `?category=api\|cli\|config&area=<area>`) | չկա            |
| `/api/agent-skills/{id}`     | GET   | Ստանալ առանձին հմտության մետատվյալները                                   | չկա            |
| `/api/agent-skills/{id}/raw` | GET   | Ստանալ SKILL.md-ը որպես `text/markdown`                                  | չկա            |
| `/api/agent-skills/coverage` | GET   | Ծածկույթի վիճակագրություն (քանի SKILL.md ֆայլ կա)                        | չկա            |
| `/api/agent-skills/generate` | POST  | Գործարկել գեներատորը (dryRun/prune/onlyIds)                              | կառավարում     |

Օրինակ՝ ցուցադրել API-ի բոլոր հմտությունները.

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Օրինակ՝ ստանալ մեկ SKILL.md.

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP-ի հայտնաբերում

`read:catalog` տիրույթում գրանցված է երեք MCP գործիք.

| Գործիք                            | Նկարագրություն                                                      |
| :-------------------------------- | :------------------------------------------------------------------ |
| `omniroute_agent_skills_list`     | Հմտությունների ցանկ (ըստ ցանկության՝ `category` / `area` զտիչներով) |
| `omniroute_agent_skills_get`      | Ստանալ մեկ հմտության մետատվյալները + SKILL.md-ը՝ ըստ `id`-ի         |
| `omniroute_agent_skills_coverage` | Ծածկույթի վիճակագրություն (API/CLI առկա/ընդհանուր)                  |

Տիրույթի կապակցման և նույնականացման մասին տե՛ս [MCP-SERVER.md](./MCP-SERVER.md)։

## A2A-ի հայտնաբերում

A2A-ի `list-capabilities` հմտությունը վերադարձնում է 45 հմտությունից բաղկացած ամբողջական կատալոգը՝ որպես markdown աղյուսակի արտեֆակտ։ Արտաքին նվագավարները կարող են կանչել այն հետևյալ կերպ.

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

Արձանագրության մանրամասների համար տե՛ս [A2A-SERVER.md](./A2A-SERVER.md)։

### 1. Հայտնաբերում REST-ի միջոցով

```bash

curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Հայտնաբերում MCP-ի միջոցով

```typescript
// Claude Desktop / Cursor MCP հաճախորդում՝
const result = await client.callTool("omniroute_agent_skills_list", {

```

### 3. Հայտնաբերում A2A-ի միջոցով

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={

```

## Գեներատոր

Գեներատորը կարդում է մշակված կատալոգը + OpenAPI բնութագիրը + CLI ռեեստրը և յուրաքանչյուր գրառման համար ստեղծում է `skills/{id}/SKILL.md`՝

```bash
# Նախադիտում (փորձնական գործարկում՝ առանց գրանցումների)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Ամբողջական վերագեներացում
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Վերագեներացնել որոշակի ID-ներ
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Գեներատորի պատասխանը `GeneratorReport` է՝

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
