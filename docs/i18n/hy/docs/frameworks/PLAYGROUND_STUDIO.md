## Ներդիրներ

### Զրույցի ներդիր

`ChatPlayground.tsx`-ը վերածում է բազմափուլ հոսքային աշխատանքային միջավայրի․

- Markdown-ի ամբողջական արտապատկերում `MarkdownMessage.tsx`-ի միջոցով (կոդի բլոկներ, աղյուսակներ, ցանկեր, հղումներ)։
- Համակարգային հուշումը վերցվում է ընդհանուր Կարգավորումների վահանակից։
- Յուրաքանչյուր հաղորդագրության թոքենների քանակը և արժեքը (հուշման + լրացման թոքեններ)։
- Վերջին պատասխանի վերաստեղծում։
- Ուղարկում է `POST /v1/chat/completions` հարցում՝ SSE հոսքային փոխանցմամբ։

### Համեմատման ներդիր

Պրոքսիի հիմնական տարբերակիչ հնարավորությունը․ մեկ հուշումը զուգահեռ գործարկել մինչև **4 մոդելի համար**։

- Մինչև 4 սյունակ, որոնցից յուրաքանչյուրն անկախ հոսք է ստանում `/v1/chat/completions`-ից։
- Սյունակներ ավելացնելու համար՝ `+ Ավելացնել մոդել` կոճակ (Cmd+K ստեղնաշարային դյուրանցում)։
- `Գործարկել բոլորը ▶`-ը միաժամանակ մեկնարկում է բոլոր հոսքերը՝ `Promise.all`-ի և յուրաքանչյուր սյունակի համար առանձին `AbortController`-ի միջոցով։
- Ընդհանուր **Չեղարկել բոլորը** կոճակը դադարեցնում է ընթացքի մեջ գտնվող բոլոր հոսքերը։
- Յուրաքանչյուր սյունակի `ProviderMetrics`-ը իրական ժամանակում ցուցադրում է TTFT-ը, TPS-ը, թոքենները և գնահատված արժեքը։
- Չափիչները պիտակավորված են որպես **«հաճախորդի կողմից հաշվարկված գնահատական»** (D12)՝ չափված առաջին SSE հատվածից։

### API ներդիր

Պահպանում է սկզբնական Monaco խմբագրիչի հնարավորությունների 100%-ը փորձառու օգտատերերի համար (D14)․

- 10 վերջնակետ՝ զրույցի լրացումներ, լրացումներ, ներդրումներ, պատկերներ, աուդիո, խոսք, տառադարձումներ, մոդերացիաներ, վերադասակարգում, որոնում։
- Բազմամոդալ ֆայլերի վերբեռնում։
- SSE հոսքային փոխանցում՝ իրական ժամանակի ելքով։
- Փաթեթավորված է որպես `ApiTab.tsx` (ծույլ բեռնում, `ssr: false`)։

### Կառուցման ներդիր

Գործիքների/ֆունկցիաների կանչման և կառուցվածքային ելքի միջերես․

- `ToolsBuilder.tsx` — ավելացնել/խմբագրել/հեռացնել `tools[]`՝ յուրաքանչյուր գործիքի համար JSON սխեմայի խմբագրիչով։
  Վավերացնում է պարամետրերը `ToolDefinitionSchema`-ի (Zod) միջոցով։
- `StructuredOutputEditor.tsx` — միացնել կամ անջատել JSON ռեժիմը + JSON սխեմայի խմբագրիչ։
  Վավերացնում է պատասխանը սխեմայի նկատմամբ՝ `StructuredOutputSchema`-ի (Zod) միջոցով։
- Հարցումն ուղարկում է `/v1/chat/completions`՝ `tools[]`-ով և/կամ `response_format`-ով։

## Կազմաձևման վահանակ (ընդհանուր)

`StudioConfigPane.tsx` — միշտ տեսանելի է, ծալվող։

| Դաշտ                 | Բաղադրիչ              | Նշումներ                                                                                         |
| -------------------- | --------------------- | ------------------------------------------------------------------------------------------------ |
| Վերջնակետ            | `<select>`            | `PlaygroundEndpoint`-ին համապատասխանող 10 տարբերակ                                               |
| Մոդել                | `<input>`             | ազատ տեքստ, օրինակ՝ `openai/gpt-4o`                                                              |
| Համակարգային հուշում | `<textarea>`          | փոխանցվում է բոլոր ներդիրներին                                                                   |
| Պարամետրեր           | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop                           |

անցնելիս կազմաձևման վիճակը պահպանվում է։

## Հուշման բարելավիչ

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Մոդալ պատուհանը նախազգուշացնում է՝ «կսպառի քվոտան»։
2. Հաստատումից հետո ուղարկում է `{ system, prompt, model, tone }` դեպի երթուղին։
3. Երթուղին ներքին կերպով կանչում է `/v1/chat/completions`՝ օգտագործելով `promptImprover.META_SYSTEM_PROMPT`։
4. Վերադարձնում է `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`։
5. UI-ը թարմացնում է Կազմաձևման վահանակի համակարգային հուշումը և Զրույցի ներդիրի օգտատիրոջ հուշումը։

- CRUD՝ `GET` ցուցակ, `POST` ստեղծում, `GET /:id`, `PUT /:id`, `DELETE /:id`։

## Հոսքի չափումներ

`useStreamMetrics.ts` + `streamMetrics.ts` (մաքուր ֆունկցիա)։

- `start()` — գրանցում է հարցման մեկնարկի ժամանակը։
- `onFirstChunk()` — գրանցում է TTFT-ն։
- `onChunk(n)` — կուտակում է լրացման տոկենների քանակը։
- `finish(usage?)` — հաշվարկում է վերջնական չափումները՝ `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`։
- Գնագոյացումը վերցվում է `src/lib/playground/types.ts`-ի ստատիկ աղյուսակից (նշված է որպես «գնահատված» — D13)։

| `POST`   | `/api/playground/presets`        | Ստեղծում է նախադրվածք, վավերացնում է `PlaygroundPresetCreateSchema`-ն                                |

| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                  |

Նույնականացում՝ կամընտիր (`REQUIRE_API_KEY`)։ Սխալները՝ `buildErrorBody()`-ի միջոցով (Խիստ կանոն #12)։
