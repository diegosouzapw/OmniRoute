> **Կարճ ասած**․ Օգտագործեք ձեր սեփական՝ համապատասխան պահանջներին բավարարող մատակարարների հաշիվները։ OmniRoute-ը միավորում է ձեր կազմաձևած կապերը․ այն չի տրամադրում գովազդվող համախառն թոքենների բյուջեն։ Անվճար հասանելիության համար կարող են պահանջվել գրանցում, API բանալի, հաստատում կամ վճարման եղանակ։ Մատակարարների սահմանափակումները, գաղտնիության քաղաքականությունները և պայմանները շարունակում են գործել։

## Ի՞նչ են անվճար մակարդակները։

AI ծառայությունների շատ մատակարարներ առաջարկում են **անվճար հասանելիության** որևէ ձև։ Կախված մատակարարից՝ դա կարող է նշանակել նույնականացում չպահանջող վերջնակետ, պարբերաբար թարմացվող քվոտա, հարցումների հաճախականությամբ սահմանափակված, բայց ընդհանուր ծավալով անսահմանափակ հասանելիություն, գրանցման ժամանակ տրամադրվող չափաբաժին, ձեռքով հաստատում կամ ժամանակավոր ակցիա։ Որոշ տարբերակներ պահանջում են հաշիվ, API բանալի, վարկային քարտ, KYC կամ մատակարարին հատուկ պայմանների ընդունում։

OmniRoute-ը **միավորում է** կարգավորված կապերը մեկ վերջնակետում։ Հաշիվ պահանջող յուրաքանչյուր մատակարարի մոտ, միևնույն է, պետք է առանձին գրանցվեք։ Միացրեք այդ հաշիվները և օգտագործեք `model: "auto"`՝ համապատասխան թիրախների միջև հարցումներն ուղղորդելու համար։ Նոր տեղադրումը կարող է չունենալ առանց բանալիի հասանելի որևէ համապատասխան թիրախ․ միայն OmniRoute-ի տեղադրումը չի երաշխավորում զրույցի հարցմանը հաջող պատասխան ստանալը։

| **OpenRouter-ի անվճար մոդելներ** | Հարցումների սահմանափակումով ընդհանուր պաշար․ կամընտիր մեկանգամյա համալրումը մեծացնում է կրկնվող թույլատրելի ծավալը | Փոխարինող մոդելների լայն կատալոգ          |
| **AI Horde**                     | Առանց բանալու համայնքային հզորություն․ հասանելիությունը տատանվում է                                                | Ըստ հնարավորության բաշխված ինֆերենս       |

## Ինչպես համատեղել անվճար մակարդակները

OmniRoute-ի առավելությունը **անվճար մակարդակների համատեղումն** է։ Մեկ մատակարարից կախված լինելու փոխարեն դուք միացնում եք մի քանի անվճար մատակարար և թույլ տալիս OmniRoute-ին ավտոմատ ընտրել լավագույնը յուրաքանչյուր հարցման համար։

### Օրինակ՝ անվճար մակարդակների ավելի լայն ծածկույթ

Միացրեք մի քանի մատակարար՝ որևէ առանձին քվոտայից կախվածությունը նվազեցնելու համար.

1. **Gemini** — API բանալիով պարբերաբար թարմացվող քվոտա
2. **Groq** — API բանալիով պարբերաբար թարմացվող քվոտա
3. **Pollinations** — առանց բանալու, հարցումների հաճախականության սահմանափակմամբ հասանելիություն
4. **LongCat** — գրանցման ժամանակ տրամադրվող միանվագ չափաբաժին (պահանջվում է KYC)

Այնուհետև օգտագործեք `model: "auto"`, և OmniRoute-ը՝

- Նախ կփորձի ամենաբարձր վարկանիշ ունեցող համապատասխան կապը
- Եթե դրա քվոտայի կամ աշխատանքային վիճակի ստուգումը ձախողվի → կփորձի հաջորդ կազմաձևված մատակարարին
- Եթե առանց բանալու մատակարարն անհասանելի լինի → կշարունակի փորձել մնացած թիրախները
- Եթե համապատասխան կապերից ոչ մեկը չհաջողվի → կվերադարձնի սխալ. գրանցման վարկերը կիրառելի են միայն քանի դեռ վավեր և հասանելի են

**Արդյունք**՝ անվճար մակարդակների ավելի լայն ծածկույթ՝ ավտոմատ պահուստային անցմամբ, այլ ոչ թե անսահմանափակ հզորության երաշխիք։

## Ինչպես միացնել անվճար մատակարարներին

### Քայլ 1․ Բացեք կառավարման վահանակը

Ձեր դիտարկիչում անցեք `http://localhost:20128` հասցեով։

### Քայլ 2․ Անցեք մատակարարների բաժին

Կողագոտում սեղմեք **Մատակարարներ**։

### Քայլ 3․ Սեղմեք «Ավելացնել մատակարար»

Սեղմեք **+ Ավելացնել մատակարար** կոճակը։

### Քայլ 4․ Ընտրեք անվճար մատակարար

Դիտեք կատալոգը և ուսումնասիրեք յուրաքանչյուր մատակարարի ընթացիկ `hasFree`, նույնականացման, քվոտայի, գաղտնիության
և օգտագործման պայմանների մետատվյալները։ Մատակարարի քարտը և
[Անվճար մակարդակների տեղեկատուն](../reference/FREE_TIERS.md) տարբերակում են պարբերաբար թարմացվող պաշարները,
առանց սահմանաչափի/բանալու հասանելիությունը, գրանցման վարկերը, դադարեցված առաջարկները և ավելի բարձր ռիսկով աղբյուրները։

### Քայլ 5․ Սեղմեք «Միացնել»

`NOAUTH` մատակարարի դեպքում OmniRoute-ը վերին մակարդակի ծառայության մուտքանունային տվյալներ չի պահանջում։ Սա չի երաշխավորում, որ վերին մակարդակի ծառայությունն ընդունում է երրորդ կողմի հաճախորդներ կամ ունի հասանելի հզորություն։ OAuth և API բանալի օգտագործող մատակարարները պետք է միացվեն իրենց փաստաթղթավորված հաշվի ընթացակարգի միջոցով։ Երբ երթուղիչի նույնականացումը միացված է, ձեր հաճախորդը շարունակում է օգտագործել **Կառավարման վահանակ → Վերջնակետեր** բաժնում ցուցադրված OmniRoute API բանալին։

### Քայլ 6․ Կրկնեք

Միացրեք մի քանի մատակարարների, որոնց պայմաններն ու գաղտնիության մոդելը համապատասխանում են ձեր օգտագործման դեպքին։

---

## Կատալոգը ճիշտ ընթերցելը

- `NOAUTH` նշանակում է, որ OmniRoute-ը ձեզանից չի պահանջում մատակարարի մուտքային տվյալներ․ դա չի
  երաշխավորում անխափան աշխատանք, գաղտնիություն կամ անսահմանափակ հզորություն։
- `hasFree`-ը հայտնաբերման մետատվյալ է։ Այն կարող է ներկայացնել պարբերական քվոտա, առանց բանալու հասանելիություն,
  գրանցման բոնուս, հաստատման ծրագիր կամ ակցիա։
- `recurring-uncapped` նշանակում է, որ հրապարակված թոքենների առավելագույն սահմանաչափ հասանելի չի եղել․ արագության և
  միաժամանակյա հարցումների սահմանափակումները շարունակում են գործել։
- `one-time-initial`-ը չի կրկնվում գրանցման ժամանակ տրամադրված բոնուսն սպառելուց հետո։
- `tos: avoid` նշումով մատակարարները լռելյայն բացառվում են ավտոմատ երթուղավորումից (`excludeTosAvoid`)։ Հաշիվ միացնելը չի շրջանցում այս զտիչը։ Օպերատորի կողմից ցանկացած վերասահմանում պետք է կատարվի մատակարարի պայմանների և հաշվի ռիսկերի ուսումնասիրությունից հետո։
- `discontinued` նշումով գրառումները պահպանվում են որպես պատմական վկայություն և չպետք է ներկայացվեն որպես
  ներկայում անվճար։

## Ինչպես է OmniRoute-ը բարելավում անվճար մակարդակների օգտագործումը

### 1. Ավտոմատ պահուստային անցում

Եթե անվճար մատակարարներից մեկը զբաղված կամ անհասանելի է, OmniRoute-ն ավտոմատ կերպով փորձում է հաջորդը։ Ձեզանից որևէ գործողություն չի պահանջվում։

### 2. Խելացի երթուղավորում

OmniRoute-ը յուրաքանչյուր հարցման համար ընտրում է **լավագույն անվճար մատակարարին**՝ հիմնվելով հետևյալի վրա․

- Արագություն — ո՞ր մատակարարն է տվյալ պահին ամենաարագը։
- Որակ — ո՞ր մատակարարն է լավագույնն այս առաջադրանքի համար։
- Հզորություն — ո՞ր մատակարարն ունի մնացած քվոտա։

### 3. Նշանների խնայողություն

OmniRoute-ի սեղմման շղթան կարող է նվազեցնել համապատասխան հուշումների և գործիքների ելքային տվյալների նշանների քանակը։ Իրական
խնայողությունը կախված է բովանդակությունից, ընտրված շարժիչներից, մատակարարի հաշվարկման եղանակից և ճշգրտության
կարգավորումներից․ սեղմումը յուրաքանչյուր մատակարարի քվոտան հաստատուն գործակցով չի բազմապատկում։

### 4. Բազմահաշիվ աջակցություն

Եթե մատակարարի պայմանները թույլ են տալիս օգտագործել մի քանի հաշիվ կամ նույնականացման տվյալներ, OmniRoute-ը կարող է յուրաքանչյուր
կապ դիտարկել որպես երթուղավորման առանձին թեկնածու։ Մի ստեղծեք լրացուցիչ հաշիվներ՝ մատակարարի
քվոտան կամ հասանելիության քաղաքականությունը շրջանցելու համար։

| Չափանիշ                         | Ընթացիկ աուդիտավորված արժեք | Մեկնաբանություն                                                                               |
| ------------------------------- | --------------------------: | --------------------------------------------------------------------------------------------- |
| Պարբերական քանակական քվոտա      |       **~1.62B թոքեն/ամիս** | Ընդհանուր պուլերը հաշվվում են մեկ անգամ․ գումարի մեջ չեն ներառվում անսահմանափակ մատակարարները |
| Գրանցման քվոտաներով առաջին ամիս |            **~2.22B թոքեն** | Պարբերական ընդհանուր քանակը՝ գումարած միանվագ և պարբերական կրեդիտները                         |

Սրանք կատալոգի ամբողջ ծավալով գնահատականներ են՝ տարբեր իրավասու հաշիվների համար, այլ ոչ թե OmniRoute-ի տրամադրած քվոտա կամ նոր տեղադրման համար կանխատեսում։ Ձեր օգտագործելի հզորությունը կախված է ձեր միացրած մատակարարներից և նրանց ընթացիկ պայմաններից։ Արժեքները հաշվարկվում են `open-sse/config/freeModelCatalog.ts`-ից․ ընդհանուր պուլերի կրկնությունների վերացման, ToS նշումների, այլևս չգործող գրառումների և գրանցման կրեդիտների մեթոդաբանության համար տե՛ս
[Անվճար մակարդակների տեղեկատուն](../reference/FREE_TIERS.md)։

### «Սա իրո՞ք անվճար է»

Կատալոգում գրանցվում են մատակարարների հրապարակած պայմանները և նախագծի հետազոտության արդյունքները, սակայն առաջարկները կարող են փոխվել։
Օգտագործելուց առաջ ստուգեք մատակարարի ընթացիկ գնագոյացումը, քվոտան, գաղտնիության քաղաքականությունը և իրավասության պայմանները։

### «Անվճար մակարդակի քվոտան կսպառվի՞»

Յուրաքանչյուր մատակարար կարող է սահմանափակել հարցումների հաճախականությունը, փոխել մոդելները, կասեցնել հասանելիությունը կամ անցանց դառնալ։ Բազմաթիվ
միացումները բարելավում են պահուստային տարբերակների ծածկույթը, սակայն չեն երաշխավորում հասանելի անվճար երթուղի։

### «Կարո՞ղ եմ անվճար մատակարարներն օգտագործել աշխատանքային միջավայրում»

Միայն այն դեպքում, եթե մատակարարի SLA-ն, տվյալների մշակումը, սահմանաչափերը և պայմանները համապատասխանում են ձեր աշխատանքային միջավայրի
պահանջներին։ Կարևոր աշխատանքային բեռնվածությունները պետք է ունենան վերահսկվող և պայմանագրային առումով համապատասխան պահուստային տարբերակ։

### «Ի՞նչն է թաքնված սրա հետևում»

Փոխզիջումները կարող են ներառել խիստ սահմանաչափեր, սպասման ցուցակներ, KYC, վարկային քարտի ստուգում, հարցումների օգտագործում ուսուցման համար,
ավելի թույլ գաղտնիություն, SLA-ի բացակայություն, մոդելների հաճախակի փոփոխություն, աշխարհագրական սահմանափակումներ, սահմանաչափի գերազանցման դիմաց վճար կամ
հաշվի քաղաքականության հետ կապված ռիսկ։ OmniRoute-ը ցուցադրում է հասանելի մետատվյալները, իսկ դուք ընտրում եք, թե ինչն ակտիվացնել։

### «Ինչպե՞ս կարող եմ ավելի շատ անվճար քվոտա ստանալ»

1. Միացրեք ավելի շատ անվճար մատակարարներ
2. Ակտիվացրեք համապատասխան սեղմման շարժիչները և չափեք ձեր աշխատանքային բեռնվածության համար ստացված խնայողությունը
3. Անվճար/էժան մատակարարներին առաջնահերթություն տալու համար օգտագործեք `auto/cheap`
4. Ավելացրեք այլ թույլատրելի մատակարարներ կամ հավատարմագրեր՝ չխախտելով մատակարարների պայմանները

### «Անվճար մատակարարների որակն ավելի վա՞տ է»

Պարտադիր չէ։ Որոշ մատակարարներ հասանելի են դարձնում նույն մոդելային ընտանիքները, որոնք հասանելի են վճարովի
երթուղիներով, սակայն սահմանաչափերը, ուշացումը, գաղտնիությունը, հուսալիությունը և մոդելների տարբերակները կարող են տարբերվել։ Օգտագործեք
Անվճար մատակարարների վարկանիշների էջը՝ որպես որակի ցուցիչ, և ստուգեք փաստացի տրամադրվող մոդելը։
