## Ի՞նչ են անվճար մակարդակները։

AI-ի շատ մատակարարներ առաջարկում են **անվճար հասանելիության** որևէ ձև։ Կախված մատակարարից՝ դա կարող է
լինել նույնականացում չպահանջող վերջնակետ, պարբերաբար թարմացվող քվոտա, հարցումների արագությամբ սահմանափակված, բայց ընդհանուր ծավալով անսահմանափակ հասանելիություն, գրանցման ժամանակ տրվող բոնուս,
ձեռքով հաստատում կամ ժամանակավոր ակցիա։ Որոշ տարբերակների համար պահանջվում են հաշիվ, API բանալի,
վարկային քարտ, KYC կամ մատակարարին հատուկ պայմանների ընդունում։

OmniRoute-ը **միավորում է** այս անվճար մակարդակները մեկ վերջնակետում։ 10 տարբեր ծառայությունում գրանցվելու փոխարեն՝ դրանք բոլորը միացնում եք OmniRoute-ին և օգտագործում `model: "auto"`՝ յուրաքանչյուր հարցման համար լավագույն անվճար տարբերակն ավտոմատ ընտրելու նպատակով։

## Ինչպես համատեղել անվճար մակարդակները

OmniRoute-ի առավելությունը **անվճար մակարդակների համատեղումն** է։ Մեկ մատակարարից կախված լինելու փոխարեն դուք միացնում եք մի քանի անվճար մատակարարներ և թույլ տալիս OmniRoute-ին յուրաքանչյուր հարցման համար ավտոմատ կերպով ընտրել լավագույնը։

### Օրինակ․ անվճար մակարդակների ավելի լայն ծածկույթ

Միացրեք մի քանի մատակարար՝ որևէ առանձին քվոտայից կախվածությունը նվազեցնելու համար․

1. **Gemini** — պարբերաբար թարմացվող API բանալու քվոտա
2. **Groq** — պարբերաբար թարմացվող API բանալու քվոտա
3. **Pollinations** — առանց բանալու, հաճախականությամբ սահմանափակված հասանելիություն
4. **LongCat** — գրանցման ժամանակ տրամադրվող միանվագ քվոտա (պահանջվում է KYC)

Այնուհետև օգտագործեք `model: "auto"`, և OmniRoute-ը՝

- Նախ կփորձի ամենաբարձր վարկանիշ ունեցող համապատասխան կապը
- Եթե դրա քվոտան սպառված է կամ աշխատունակության ստուգումը ձախողվում է → կփորձի հաջորդ կարգավորված մատակարարին
- Եթե առանց բանալու մատակարարն անհասանելի է → կշարունակի փորձել մնացած նպատակակետերը
- Եթե բոլորը ձախողվեն → որպես պահուստային տարբերակ կօգտագործի LongCat-ը

**Արդյունք**․ անվճար մակարդակների ավելի լայն ծածկույթ՝ ավտոմատ պահուստային անցումով, սակայն առանց անսահմանափակ հզորության երաշխիքի։

## Ինչպես միացնել անվճար մատակարարներ

### Քայլ 1․ բացեք կառավարման վահանակը

Ձեր դիտարկիչում անցեք `http://localhost:20128` հասցեով։

### Քայլ 2․ անցեք մատակարարների բաժին

Կողային վահանակում սեղմեք **Մատակարարներ**։

### Քայլ 3․ սեղմեք «Ավելացնել մատակարար»

Սեղմեք **+ Ավելացնել մատակարար** կոճակը։

### Քայլ 4․ ընտրեք անվճար մատակարար

Դիտեք կատալոգը և ուսումնասիրեք յուրաքանչյուր մատակարարի ընթացիկ `hasFree`, նույնականացման, քվոտայի, գաղտնիության և ToS մետատվյալները։ Մատակարարի քարտը և
[Անվճար մակարդակների տեղեկատուն](../reference/FREE_TIERS.md) տարբերակում են պարբերաբար թարմացվող պաշարները,
առանց սահմանաչափի/բանալու հասանելիությունը, գրանցման բոնուսները, դադարեցված առաջարկները և ավելի բարձր ռիսկով աղբյուրները։

### Քայլ 5․ սեղմեք «Միացնել»

`NOAUTH` մատակարարի համար նույնականացման տվյալներ չեն պահանջվում։ OAuth և API բանալի օգտագործող մատակարարները պետք է
միացվեն նրանց փաստաթղթավորված հաշվի կարգավորման ընթացակարգով։

### Քայլ 6․ կրկնեք

Միացրեք մի քանի մատակարար, որոնց պայմաններն ու գաղտնիության մոդելը համապատասխանում են ձեր օգտագործման սցենարին։

## Ինչպես ճիշտ կարդալ կատալոգը

- `NOAUTH` նշանակում է, որ OmniRoute-ը ձեզանից չի պահանջում մատակարարի նույնականացման տվյալներ․ դա չի
  երաշխավորում անխափան աշխատանք, գաղտնիություն կամ անսահմանափակ հզորություն։
- `hasFree`-ը հայտնաբերման մետատվյալ է։ Այն կարող է նշանակել պարբերաբար թարմացվող քվոտա, առանց բանալու հասանելիություն,
  գրանցման բոնուս, հաստատմամբ հասանելի ծրագիր կամ ժամանակավոր առաջարկ։
- `recurring-uncapped` նշանակում է, որ հրապարակված նշանների առավելագույն սահմանաչափ հասանելի չի եղել․ հարցումների հաճախականության և
  զուգահեռության սահմանափակումները շարունակում են գործել։
- `one-time-initial`-ը չի թարմացվում գրանցման ժամանակ տրամադրված պաշարը սպառելուց հետո։
- `tos: avoid`-ը նախազգուշացում է՝ օգտագործելուց առաջ ուսումնասիրելու մատակարարի պայմաններն ու հաշվի հետ կապված ռիսկերը։
- `discontinued` նշումով գրառումները պահպանվում են որպես պատմական վկայություն և չպետք է ներկայացվեն որպես
  ներկայում անվճար։

## Ինչպես է OmniRoute-ը բարելավում անվճար մակարդակների օգտագործումը

### 1. Ավտոմատ պահուստային անցում

Եթե անվճար մատակարարներից մեկը զբաղված կամ անհասանելի է, OmniRoute-ն ավտոմատ կերպով փորձում է հաջորդը։ Ձեզանից որևէ գործողություն չի պահանջվում։

### 2. Խելացի երթուղավորում

OmniRoute-ը յուրաքանչյուր հարցման համար ընտրում է **լավագույն անվճար մատակարարին**՝ հիմնվելով հետևյալի վրա․

- Արագություն — ո՞ր մատակարարն է տվյալ պահին ամենաարագը։
- Որակ — ո՞ր մատակարարն է լավագույնն այս առաջադրանքի համար։
- Հզորություն — ո՞ր մատակարարն ունի մնացած քվոտա։

### 3. Նշանների խնայողություն

OmniRoute-ի սեղմման շղթան կարող է նվազեցնել համապատասխան հուշումների և գործիքների ելքային տվյալների նշանների քանակը։ Իրական
խնայողությունը կախված է բովանդակությունից, ընտրված շարժիչներից, մատակարարի հաշվարկման եղանակից և ճշգրտության
կարգավորումներից․ սեղմումը յուրաքանչյուր մատակարարի քվոտան հաստատուն գործակցով չի բազմապատկում։

### 4. Բազմահաշիվ աջակցություն

Եթե մատակարարի պայմանները թույլ են տալիս օգտագործել մի քանի հաշիվ կամ նույնականացման տվյալներ, OmniRoute-ը կարող է յուրաքանչյուր
կապ դիտարկել որպես երթուղավորման առանձին թեկնածու։ Մի ստեղծեք լրացուցիչ հաշիվներ՝ մատակարարի
քվոտան կամ հասանելիության քաղաքականությունը շրջանցելու համար։

## Հաճախ տրվող հարցեր

### «Սա իրո՞ք անվճար է»

Կատալոգում գրանցվում են մատակարարների հրապարակած պայմանները և նախագծի հետազոտության արդյունքները, սակայն առաջարկները կարող են փոխվել։
Օգտագործելուց առաջ ստուգեք մատակարարի ընթացիկ գնագոյացումը, քվոտան, գաղտնիության քաղաքականությունը և իրավասության պայմանները։

### «Անվճար մակարդակի քվոտան կսպառվի՞»

Յուրաքանչյուր մատակարար կարող է սահմանափակել հարցումների հաճախականությունը, փոխել մոդելները, կասեցնել հասանելիությունը կամ անցանց դառնալ։ Բազմաթիվ
միացումները բարելավում են պահուստային տարբերակների ծածկույթը, սակայն չեն երաշխավորում հասանելի անվճար երթուղի։

### «Կարո՞ղ եմ անվճար մատակարարներն օգտագործել աշխատանքային միջավայրում»

Միայն այն դեպքում, եթե մատակարարի SLA-ն, տվյալների մշակումը, սահմանաչափերը և պայմանները համապատասխանում են ձեր աշխատանքային միջավայրի
պահանջներին։ Կարևոր աշխատանքային բեռնվածությունները պետք է ունենան վերահսկվող և պայմանագրային առումով համապատասխան պահուստային տարբերակ։

### «Ի՞նչն է թաքնված սրա հետևում»

Փոխզիջումները կարող են ներառել խիստ սահմանաչափեր, սպասման ցուցակներ, KYC, վարկային քարտի ստուգում, հարցումների օգտագործում ուսուցման համար,
ավելի թույլ գաղտնիություն, SLA-ի բացակայություն, մոդելների հաճախակի փոփոխություն, աշխարհագրական սահմանափակումներ, սահմանաչափի գերազանցման դիմաց վճար կամ
հաշվի քաղաքականության հետ կապված ռիսկ։ OmniRoute-ը ցուցադրում է հասանելի մետատվյալները, իսկ դուք ընտրում եք, թե ինչն ակտիվացնել։

### «Ինչպե՞ս կարող եմ ավելի շատ անվճար քվոտա ստանալ»

1. Միացրեք ավելի շատ անվճար մատակարարներ
2. Ակտիվացրեք համապատասխան սեղմման շարժիչները և չափեք ձեր աշխատանքային բեռնվածության համար ստացված խնայողությունը
3. Անվճար/էժան մատակարարներին առաջնահերթություն տալու համար օգտագործեք `auto/cheap`
4. Ավելացրեք այլ թույլատրելի մատակարարներ կամ հավատարմագրեր՝ չխախտելով մատակարարների պայմանները

### «Անվճար մատակարարների որակն ավելի վա՞տ է»

Պարտադիր չէ։ Որոշ մատակարարներ հասանելի են դարձնում նույն մոդելային ընտանիքները, որոնք հասանելի են վճարովի
երթուղիներով, սակայն սահմանաչափերը, ուշացումը, գաղտնիությունը, հուսալիությունը և մոդելների տարբերակները կարող են տարբերվել։ Օգտագործեք
Անվճար մատակարարների վարկանիշների էջը՝ որպես որակի ցուցիչ, և ստուգեք փաստացի տրամադրվող մոդելը։
