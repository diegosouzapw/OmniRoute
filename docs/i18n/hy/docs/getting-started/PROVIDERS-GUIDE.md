## Ի՞նչ է պրովայդերը

Պրովայդերը պատկերացրեք որպես **բջջային օպերատոր**։ Ինչպես զանգեր կատարելու համար անհրաժեշտ է բջջային օպերատոր, այնպես էլ AI մոդելներ օգտագործելու համար անհրաժեշտ է AI պրովայդեր։ OmniRoute-ը նման է հեռախոսի, որն աշխատում է **բոլոր օպերատորների հետ**. դուք կարող եք ավտոմատ կերպով անցնել մեկից մյուսին։

### Պրովայդերների տեսակները

| Տեսակ          | Ի՞նչ է դա                           | Օրինակներ                         | Արժեք                         |
| -------------- | ----------------------------------- | --------------------------------- | ----------------------------- |
| **Անվճար**     | Վճարում չի պահանջվում               | Kiro, OpenCode Free, Pollinations | $0                            |
| **API բանալի** | Ձեզ անհրաժեշտ է API բանալի          | OpenAI, Anthropic, Google         | Վճարում՝ ըստ օգտագործման      |
| **OAuth**      | Մուտք՝ ձեր հաշվի միջոցով            | Claude Code, GitHub Copilot       | Բաժանորդագրություն            |
| **Վեբ cookie** | Օգտագործում է դիտարկչի աշխատաշրջանը | ChatGPT Web (Codex), Gemini Web   | $0 (օգտագործում է ձեր հաշիվը) |

### Վեբ cookie-ով պրովայդերներ

Կարգավորման ընդհանուր հրահանգների, սահմանափակումների, խնդիրների լուծման և յուրաքանչյուր պրովայդերին հատուկ նույնականացման ուղեցույցների համար տե՛ս **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**։

## Արագ մեկնարկ. միացրեք ձեր առաջին պրովայդերը

### Առաջին գործարկման ժամանակ անվճար պրովայդերների կամընտիր կարգավորում

Առաջին գործարկման օգնականն առաջարկում է հստակ **Կարգավորել անվճար պրովայդերները** քարտ։ Այն OmniRoute-ի նույնականացում չպահանջող պրովայդերների ռեեստրից կազմում է տվյալ պահին համապատասխանող ցանկը, ապա հաստատելուց առաջ թույլ է տալիս վերանայել և ապաընտրել յուրաքանչյուր պրովայդեր։ OmniRoute-ը ցուցադրում է պրովայդերի նախազգուշացումը և նրա կայքի հղումը, որպեսզի նախ կարողանաք ծանոթանալ երրորդ կողմի պայմաններին, գաղտնիության քաղաքականությանը, հասանելիությանը և հարցումների հաճախականության սահմանափակումներին։

Այս գործողությունը կամընտիր է. օգնականի աշխատանքն ավարտելիս անվճար պրովայդերների կապեր երբեք գաղտնի չեն ստեղծվում։ Այն ստեղծում է միայն դեռևս բացակայող պրովայդերները, անփոփոխ է թողնում արդեն իսկ անհատականացված կապերը և առանձին հայտնում ստեղծված, արդեն կարգավորված և ձախողված պրովայդերների մասին։ Մասնակի արդյունքից հետո կարող եք անվտանգ կրկին փորձել միայն ձախողվածների համար։

### Տարբերակ A. անվճար պրովայդեր (առանց վարկային քարտի)

1. Բացեք կառավարման վահանակը՝ `http://localhost:20128`
2. Անցեք **Պրովայդերներ** → **Ավելացնել պրովայդեր**
3. Ընտրեք այս անվճար պրովայդերներից մեկը.
   - **Kiro AI** — անվճար Claude մոդելներ (նույնականացում չի պահանջվում)
   - **OpenCode Free** — անվճար GPT մոդելներ (նույնականացում չի պահանջվում)
   - **Pollinations** — անվճար GPT-5, Claude, Gemini (բանալի չի պահանջվում)
   - **LongCat** — 10M թոքեն անվճար (մեկանգամյա հատկացում, պահանջվում են հաշիվ և KYC)
   - **Cloudflare AI** — 50+ մոդել, օրական 10K նեյրոն
   - **MLX Gemma 26B** — տեղային Apple Silicon մոդել (~38.5 թոքեն/վրկ, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — տեղային Apple Silicon մոդել (~9.1 թոքեն/վրկ, ~13.1GB RAM)
4. Սեղմեք **Միացնել**
5. Պատրաստ է։ Այժմ ունեք անվճար հասանելիություն AI-ին։

### Տարբերակ B. API բանալիով պրովայդեր (վճարովի)

1. Ստացեք API բանալի պրովայդերի կայքից.
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Բացեք կառավարման վահանակը՝ `http://localhost:20128`
3. Անցեք **Պրովայդերներ** → **Ավելացնել պրովայդեր**
4. Ընտրեք ձեր պրովայդերը
5. Տեղադրեք ձեր API բանալին
6. Սեղմեք **Միացնել**
7. Պատրաստ է։ Այժմ հասանելի են այդ պրովայդերի մոդելները։

### Տարբերակ C. OAuth պրովայդեր (բաժանորդագրություն)

1. Բացեք կառավարման վահանակը՝ `http://localhost:20128`
2. Անցեք **Պրովայդերներ** → **Ավելացնել պրովայդեր**
3. Ընտրեք ձեր պրովայդերը (օրինակ՝ Claude Code, GitHub Copilot)
4. Սեղմեք **Միանալ OAuth-ով**
5. Մուտք գործեք ձեր հաշիվ
6. Պատրաստ է։ Այժմ հասանելի են ձեր բաժանորդագրության մոդելները։

### Տարբերակ D. տեղային MLX մոդելներ (Apple Silicon)

Միասնական հիշողությամբ Apple Silicon Mac համակարգիչների համար OmniRoute-ն աջակցում է `mlx-lm.server`-ի միջոցով աշխատող տեղային MLX մոդելներին՝ որպես OpenAI-ի հետ համատեղելի սովորական տեղային պրովայդերներ միանալուն։

#### Նախապայմաններ

- **Apple Silicon Mac** (M1/M2/M3/M4). խորհուրդ է տրվում 24GB+ միասնական հիշողություն
- **uv** փաթեթների կառավարիչ՝ `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**՝ `uv pip install mlx-lm`

#### Արագ մեկնարկ

1. **Տեղադրեք կախվածությունները**.

   ```bash
   # Տեղադրեք uv-ը, եթե այն դեռ տեղադրված չէ
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Տեղադրեք mlx-lm-ը
   uv pip install mlx-lm
   ```

2. **Ձեռքով գործարկեք MLX սերվերները** (առանձին տերմինալներում).

   ```bash
   # Տերմինալ 1. Gemma 4 26B A4B IT-QAT (պորտ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Տերմինալ 2. Qwen 3.8 27B MLX Mixed (պորտ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Միացեք OmniRoute-ի կառավարման վահանակում**.
   - Անցեք **Պրովայդերներ** → **Ավելացնել պրովայդեր**
   - Ընտրեք **MLX Gemma 26B** կամ **MLX Qwen 3.8 27B**
   - Սեղմեք **Միացնել** (API բանալի չի պահանջվում)

4. **Օգտագործեք OpenCode-ի հետ**.
   ```bash
   # Կարգավորեք OpenCode-ը՝ OmniRoute-ն օգտագործելու համար
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Օգտագործեք MLX մոդելները
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Հիշողության կառավարում

**Կարևոր է**. 24GB միասնական հիշողության դեպքում միաժամանակ կարող է աշխատել միայն **մեկ խոշոր MLX մոդել**։

- Gemma 26B՝ ~15.9GB առավելագույն հիշողություն
- Qwen 3.8 27B՝ ~13.1GB առավելագույն հիշողություն

Սա պետք է կառավարեք ձեռքով.

- Միաժամանակ գործարկեք միայն մեկ MLX սերվեր, կամ
- Երկուսն էլ գործարկեք առանձին համակարգիչների վրա, կամ
- Մեկը կանգնեցրեք՝ նախքան մյուսը գործարկելը

OmniRoute-ն ավտոմատ կերպով չի կառավարում MLX սերվերի գործընթացները. այն միայն հարցումներն ուղղորդում է դեպի ձեր կարգավորած OpenAI-ի հետ համատեղելի վերջնակետերը։

#### Գործիքների կանչման աջակցություն

Երկու մոդելներն էլ աջակցում են OpenAI-ի հետ համատեղելի գործիքների կանչմանը։ Փորձարկեք հետևյալով.

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

## Ինչպես միացնել մատակարար (քայլ առ քայլ)

### Քայլ 1. Բացեք կառավարման վահանակը

Ձեր դիտարկիչում բացեք `http://localhost:20128` հասցեն։

### Քայլ 2. Անցեք մատակարարների բաժին

Կողային վահանակում սեղմեք **Մատակարարներ**։

### Քայլ 3. Սեղմեք «Ավելացնել մատակարար»

Սեղմեք **+ Ավելացնել մատակարար** կոճակը։

### Քայլ 4. Ընտրեք ձեր մատակարարին

Դիտեք ցանկը կամ որոնեք ձեր մատակարարին։ Սեղմեք դրա վրա։

### Քայլ 5. Մուտքագրեք մուտքային տվյալները

- **Անվճար մատակարարներ**. մուտքային տվյալներ պետք չեն. պարզապես սեղմեք **Միացնել**
- **API բանալի պահանջող մատակարարներ**. տեղադրեք ձեր API բանալին
- **OAuth մատակարարներ**. սեղմեք **Միանալ OAuth-ով** և մուտք գործեք

### Քայլ 6. Փորձարկեք կապը

Սեղմեք **Փորձարկել կապը**՝ համոզվելու համար, որ այն աշխատում է։

### Քայլ 7. Պատրաստ է։

Ձեր մատակարարն այժմ միացված է։ Այն կարող եք օգտագործել `model: "auto"` տարբերակով կամ ուղղակիորեն նշել մատակարարին։

## Մի քանի մատակարարների օգտագործում

OmniRoute-ը լավագույնս աշխատում է **մի քանի մատակարարների** հետ։ Սա ձեզ տալիս է՝

- **Ավտոմատ պահուստային անցում** — եթե մի մատակարարը ձախողվի, OmniRoute-ը փորձում է հաջորդը
- **Ծախսերի օպտիմալացում** — OmniRoute-ը յուրաքանչյուր հարցման համար ընտրում է ամենաէժան մատակարարին
- **Արագության օպտիմալացում** — OmniRoute-ը յուրաքանչյուր հարցման համար ընտրում է ամենաարագ մատակարարին
- **Որակի օպտիմալացում** — OmniRoute-ը յուրաքանչյուր առաջադրանքի համար ընտրում է լավագույն մատակարարին

### Առաջարկվող կարգավորում

Լավագույն փորձառության համար միացրեք առնվազն **3 մատակարար**.

1. **Մեկ անվճար մատակարար** (Kiro, OpenCode Free կամ Pollinations) — միշտ հասանելի
2. **Մեկ արագ մատակարար** (Groq, Cerebras) — արագ պատասխանների համար
3. **Մեկ բարձրորակ մատակարար** (OpenAI, Anthropic, Google) — բարդ առաջադրանքների համար

Այնուհետև օգտագործեք `model: "auto"`, և OmniRoute-ն ավտոմատ կերպով յուրաքանչյուր հարցման համար կընտրի լավագույն տարբերակը։

## Հաճախակի տրվող հարցեր

### «OmniRoute-ն օգտագործելու համար պե՞տք է վճարեմ»

**Ո՛չ։** OmniRoute-ն անվճար է և բաց կոդով։ Կարող եք օգտվել անվճար մատակարարներից (Kiro, OpenCode Free, Pollinations)՝ ոչինչ չվճարելով։ Վճարում եք միայն այն դեպքում, եթե որոշեք օգտվել վճարովի մատակարարներից։

### «Ո՞ր մատակարարից պետք է սկսեմ»

Սկսեք **Kiro AI**-ից. այն անվճար է, API բանալի չի պահանջում և տրամադրում է Claude մոդելներից օգտվելու հնարավորություն։ Այնուհետև ըստ անհրաժեշտության ավելացրեք այլ մատակարարներ։

### «Կարո՞ղ եմ միաժամանակ օգտվել մի քանի մատակարարից»

**Այո՛։** Դա հենց OmniRoute-ի հիմնական նպատակն է։ Միացրեք մի քանի մատակարար և օգտագործեք `model: "auto"`, որպեսզի OmniRoute-ը յուրաքանչյուր հարցման համար ընտրի լավագույնը։

### «Ի՞նչ կլինի, եթե մատակարարը դադարի աշխատել»

OmniRoute-ն ավտոմատ կերպով բաց է թողնում չաշխատող մատակարարներին և փորձում հաջորդը։ Ձեզանից որևէ գործողություն չի պահանջվում։

### «Ինչպե՞ս անջատեմ մատակարարին»

Անցեք Մատակարարներ բաժին → սեղմեք մատակարարի վրա → սեղմեք **Անջատել**։

### «Կարո՞ղ եմ օգտագործել իմ առկա API բանալիները»

**Այո՛։** Եթե արդեն ունեք OpenAI-ի, Anthropic-ի, Google-ի և այլ մատակարարների API բանալիներ, կարող եք դրանք օգտագործել OmniRoute-ում։ Մատակարարին միանալիս պարզապես տեղադրեք դրանք։
