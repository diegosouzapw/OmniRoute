> **Կարճ ասած**․ Տեղադրեք → Միացրեք անվճար մատակարար → Ձեր IDE-ն ուղղեք դեպի OmniRoute։ Պատրաստ է։

---

## Քայլ 1․ Տեղադրեք OmniRoute-ը

Ընտրեք ձեր նախընտրած եղանակը․

### Տարբերակ A․ npm (Խորհուրդ է տրվում)

```bash
npm install -g omniroute
```

### Տարբերակ B․ Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest`-ը ամենաբարձր **հրապարակված** կայուն SemVer-ն է։ Այն **չի** հետևում git-ի `main` ճյուղին։ GitOps-ի համար ամրագրեք `diegosouzapw/omniroute:X.Y.Z` տարբերակը։ Տե՛ս [Պատկերների պիտակներ / Թողարկման ալիքներ](../guides/DOCKER_GUIDE.md#release-channels)։

### Տարբերակ C․ Սկզբնական կոդից

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Քայլ 2․ Գործարկեք OmniRoute-ը

```bash
omniroute
```

OmniRoute-ը գործարկվում է `http://localhost:20128` հասցեում։ Կառավարման վահանակը բացվում է ինքնաբերաբար։

---

## Քայլ 3․ Միացրեք անվճար մատակարար

Կարող եք օգտագործել OmniRoute-ը՝ **ոչինչ չվճարելով**, եթե միացնեք անվճար մատակարար։

### Տարբերակ A․ Kiro (Անվճար Claude՝ առանց վարկային քարտի)

1. Բացեք կառավարման վահանակը `http://localhost:20128` հասցեում
2. Անցեք **Մատակարարներ** → **Ավելացնել մատակարար**
3. Ընտրեք **Kiro AI**
4. Սեղմեք **Միացնել** (API բանալի անհրաժեշտ չէ՛)
5. Պատրաստ է։ Այժմ Claude-ի մոդելներին անվճար հասանելիություն ունեք։

### Տարբերակ B․ OpenCode Free (Առանց նույնականացման)

1. Բացեք կառավարման վահանակը `http://localhost:20128` հասցեում
2. Անցեք **Մատակարարներ** → **Ավելացնել մատակարար**
3. Ընտրեք **OpenCode Free**
4. Սեղմեք **Միացնել** (API բանալի անհրաժեշտ չէ՛)
5. Պատրաստ է։ Այժմ բազմաթիվ մոդելների անվճար հասանելիություն ունեք։

### Տարբերակ C․ Pollinations (Բանալի անհրաժեշտ չէ)

1. Բացեք կառավարման վահանակը `http://localhost:20128` հասցեում
2. Անցեք **Մատակարարներ** → **Ավելացնել մատակարար**
3. Ընտրեք **Pollinations**
4. Սեղմեք **Միացնել** (API բանալի անհրաժեշտ չէ՛)
5. Պատրաստ է։ Այժմ GPT-5-ի, Claude-ի, Gemini-ի և այլ մոդելների անվճար հասանելիություն ունեք։

## Քայլ 4․ Ստուգեք, որ այն աշխատում է

[API բանալիներ](http://localhost:20128/dashboard/api-manager) բաժնից ստեղծեք նոր բանալի։ Պահպանեք այն, քանի որ այլևս չի ցուցադրվելու։ Նկատի ունեցեք, որ այս բանալին գործիքների կողմից OmniRoute-ին հասանելիություն ստանալու համար է, այլ ոչ թե վերին մակարդակի մատակարարներին հասանելիություն ստանալու։

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Պետք է տեսնեք ձեր միացված մոդելների ցանկը։

## Քայլ 5․ Ձեր IDE-ն կամ CLI-ն ուղղեք դեպի OmniRoute

Ձեր IDE-ում կամ CLI գործիքում սահմանեք․

```
Հիմնական URL․ http://localhost:20128/v1
API բանալի․   [պատճենեք Կառավարման վահանակ → Վերջնակետեր բաժնից]
Մոդել․        auto
```

Ահա և վերջ։ Ձեր IDE-ն այժմ օգտագործում է OmniRoute-ը՝ մատակարարի ավտոմատ ընտրությամբ։

### IDE-ի օրինակ․ VSCode/Continue.dev

1. VSCode-ում տեղադրեք [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ընդլայնումը։
2. Թարմացրեք ձեր `~/.continue/config.yaml` ֆայլը՝ ավելացնելով հետևյալ տողերը․

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev-ի զրույցի վահանակում ընտրեք `OmniRoute - Auto`, և հարցումները կուղարկվեն OmniRoute-ին։
4. (Ընտրովի) Առաջադրանք ընթերցողին․ հանձնարարեք ձեր IDE-ին թարմացնել `config.yaml` ֆայլը՝ ավելացնելով նախապես պատրաստված մյուս բոլոր կազմաձևերը 😊

### CLI-ի օրինակ․ Codex CLI

1. Ձեր օպերացիոն համակարգում մշտապես սահմանեք միջավայրի փոփոխականը։
   macOS/Linux-ի համար (ավելացրեք ձեր `~/.bashrc` կամ `~/.zshrc` ֆայլում)․

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows-ի համար (Command Prompt)․

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Այժմ գործարկենք Codex-ը, սակայն OmniRoute-ի համար կազմաձևված։ Գործարկեք․

```
omniroute launch-codex --model auto
```

Դա կարող եք անել նաև ձեռքով՝ `codex`-ի և հրամանի տողի պարամետրերի միջոցով նշելով վերջնակետն ու API բանալին, սակայն վերոնշյալ հրամանի դեպքում OmniRoute-ն ամեն ինչ կատարում է ձեր փոխարեն։

Նույն մեկ հրամանով գործարկումն աշխատում է նաև այլ CLI-ների համար՝ ընդհանուր գործարկիչի միջոցով․ `omniroute run <target>`-ն աջակցում է `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` և `gemini` տարբերակները (տե՛ս [CLI ինտեգրումներ](../guides/CLI-INTEGRATIONS.md))։

3. Այժմ CLI-ն պետք է հարցումներն ուղարկի OmniRoute-ին։

### Հաստատեք, որ ձեր գործիքը հարցումներն ուղղորդում է դեպի OmniRoute

Հարցման մանրամասները կարող եք տեսնել՝ ձախ կողագոտուց սեղմելով [Մշտադիտարկում/Մատյաններ](http://localhost:20128/dashboard/logs)։ Բացված բաժիններով անցնելիս կտեսնեք լրացուցիչ մանրամասներ։ Բացի այդ, կարող եք տեսնել, թե ձեր նախընտրած գործիքակազմից ինչ տեղեկություններ են ուղարկվում վերին մակարդակի մատակարարին։ Սա օգտակար է ուսուցման և վրիպազերծման տեսանկյունից։

## Հաճախակի հարցեր

### «Ինձ API բանալի անհրաժե՞շտ է»

**Ո՛չ։** Կարող եք օգտագործել անվճար մատակարարներ (Kiro, OpenCode Free, Pollinations)՝ առանց որևէ API բանալու։ Պարզապես միացրեք դրանք կառավարման վահանակում։

### «Ի՞նչ է `auto`-ն»

`auto`-ն OmniRoute-ին հրահանգում է յուրաքանչյուր հարցման համար ավտոմատ ընտրել լավագույն մատակարարին։ Այն հաշվի է առնում արագությունը, արժեքը, որակը և հասանելիությունը։ Մանրամասների համար տե՛ս [Auto-Combo ուղեցույցը](./AUTO-COMBO-GUIDE.md)։

### «Որքա՞ն արժե այն»

OmniRoute-ն ինքնին **անվճար է և բաց կոդով**։ Դուք վճարում եք միայն ձեր օգտագործած մատակարարների համար։ Շատ մատակարարներ ունեն անվճար մակարդակներ․ տե՛ս [Անվճար մակարդակների ուղեցույցը](./FREE-TIERS-GUIDE.md)։

### «Կարո՞ղ եմ այն օգտագործել Claude Code-ի / Cursor-ի / Copilot-ի հետ»

**Այո՛։** OmniRoute-ն աշխատում է OpenAI ձևաչափն աջակցող ցանկացած գործիքի հետ։ Պարզապես հիմնական URL-ը սահմանեք որպես `http://localhost:20128/v1`։ Կազմաձևման հատուկ հրահանգների համար տե՛ս [CLI գործիքների ուղեցույցը](../reference/CLI-TOOLS.md)։

### «Ի՞նչ կլինի, եթե որևէ մատակարար դադարի աշխատել»

OmniRoute-ն ինքնաբերաբար բաց է թողնում խափանված մատակարարներին և փորձում հաջորդը։ Ձեզանից որևէ գործողություն չի պահանջվում։ Մանրամասների համար տե՛ս [Auto-Combo ուղեցույցը](./AUTO-COMBO-GUIDE.md)։
