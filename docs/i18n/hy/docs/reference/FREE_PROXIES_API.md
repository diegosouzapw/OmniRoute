OmniRoute-ը տրամադրում է անվճար պրոքսիների ընտրված հավաքածու `free_proxies` աղյուսակում,
որը համաժամացվում է արտաքին մատակարարներից (1proxy, proxifly, iplocate, webshare)։ Վահանակում
դրանք հասանելի են **Կարգավորումներ → Անվճար պրոքսիներ** բաժնում։ Այս փաստաթուղթը
նկարագրում է սերվերային զտումը, դասակարգումը, հաշվարկը և համաժամացման սխալների
ցուցադրումը, որոնք հասանելի են ցանկի երթուղու միջոցով։

## Ցանկի երթուղի — `GET /api/settings/free-proxies`

Վերադարձնում է զտված, դասակարգված և էջավորված հատված՝ ընդհանուր քանակի հետ միասին։ Զտումն ու
հաշվարկը կատարվում են SQL-ում, որպեսզի միջերեսը կարողանա ցուցադրել իրական ընդհանուր քանակը (օրինակ՝ `Ընդամենը՝ 0`)
առանց բոլոր տողերը հիշողության մեջ բեռնելու։

### Հարցման պարամետրեր

| Պարամետր          | Տեսակ                              | Լռելյայն  | Նշանակություն                                                                                                                                  |
| ----------------- | ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | տող                                | `""`      | Մեծատառերն ու փոքրատառերը տարբերակող `LIKE`՝ հոսթի (և աղբյուրի) սյան համար։                                                                    |
| `protocol`        | տող                                | `""`      | `type` զտիչ՝ `http` / `https` / `socks4` / `socks5`։ Դատարկ = բոլորը։                                                                          |
| `country`         | տող                                | `""`      | `countryCode` զտիչ (ISO-2)։ Դատարկ = բոլորը։                                                                                                   |
| `minQuality`      | թիվ                                | `0`       | Միայն այն տողերը, որոնց համար `qualityScore >= minQuality`։ `0` = նվազագույն շեմ չկա։                                                          |
| `disabledSources` | տող                                | `""`      | Բացառվող աղբյուրների՝ ստորակետերով բաժանված id-ներ (օրինակ՝ `proxifly,webshare`)։                                                              |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = գնահատականը՝ նվազման կարգով, `latency` = ուշացումը՝ աճման կարգով (`null`-երը վերջում), `recent` = `lastValidated`՝ նվազման կարգով։ |
| `offset`          | թիվ                                | `0`       | Էջավորման սկիզբը։                                                                                                                              |
| `limit`           | թիվ                                | `50`      | Էջի չափը (սահմանափակվում է սերվերի կողմից)։                                                                                                    |

### Պատասխան

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["Վերին աղբյուրից ստացվել է HTTP 429"],
    "webshare": ["ցանցային սպասման ժամանակը սպառվել է"]
  }
}
```

`total`-ն արտացոլում է զտված ընդհանուր քանակը՝ էջավորումից **առաջ**, որպեսզի միջերեսը կարողանա
միմյանցից անկախ ցուցադրել `Ընդամենը՝ N`-ը և `hasMore`-ը։ `syncErrors`-ի բանալին աղբյուրի id-ն է, և
այն լրացվում է միայն այն աղբյուրների համար, որոնց վերջին համաժամացումը ձախողվել է․ `Ընդամենը՝ 0`
արդյունքը երբեք չի ցուցադրվում առանց բացատրության։

## Հավաքածուի մեջ ավելացում — `POST /api/settings/free-proxies/[id]/add-to-pool`

Անվճար պրոքսին տեղափոխում է կառավարվող `proxy_registry` հավաքածու։ Նախ ստուգում է
վերին աղբյուրը, իսկ հաջողության դեպքում վերադարձնում է հավաքածուի նոր պրոքսիի id-ն և չափված ուշացումը։

## Համաժամացում — `POST /api/settings/free-proxies/sync`

Կրկին ներբեռնում է բոլոր միացված աղբյուրները (կամ `{ "sources": [...] }`-ում նշված ենթաբազմությունը)։ Յուրաքանչյուր
աղբյուր համաժամացվում է անկախ․ ձախողված աղբյուրը գրանցվում է `syncErrors`-ում, իսկ
մյուսների համաժամացումը շարունակվում է, ուստի մասնակի համաժամացումները երբեք չեն ջնջում նախկինում ստացված վավեր տվյալները։

## Վիճակագրություն — `GET /api/settings/free-proxies/stats`

Վերադարձնում է `total / inPool / avgQuality / bySource / lastSyncAt` ամփոփ տվյալները՝
առանց տողերի բովանդակության․ օգտագործվում է վահանակի վերնագրային վիջեթների կողմից։
