Վերջին թարմացումը՝ 2026-06-28

> Կարգավիճակը չափվել է 2026-05-13-ին՝ տողեր՝ 82.58%, հրահանգներ՝ 82.58%, ֆունկցիաներ՝ 84.23%, ճյուղեր՝ 75.22%։ 1-5 փուլերն ավարտված են։ Ներկայիս առաջնահերթությունը 6-րդ (>=85%) և 7-րդ (>=90%) փուլերն են։

## Ելակետային ցուցանիշներ

Առաջարկվող ելակետային ցուցանիշն այն թիվն է, որի նկատմամբ պետք է կատարել օպտիմալացումը։

## Կանոններ

- Ծածկույթի թիրախները վերաբերում են սկզբնաղբյուր ֆայլերին, ոչ թե `tests/**`-ին։
- `open-sse/**`-ն արտադրանքի մաս է և պետք է մնա ընդգրկված։
- Նոր կոդը չպետք է նվազեցնի ծածկույթը փոփոխված հատվածներում։
- Նախընտրեք թեստավորել վարքագիծը և ճյուղերի արդյունքները, այլ ոչ թե իրականացման մանրամասները։
- `src/lib/db/**`-ի համար լայնածավալ նմանակումների փոխարեն նախընտրեք ժամանակավոր SQLite տվյալների բազաներ և փոքր ֆիքստուրաներ։

## Հրամանների ընթացիկ հավաքածու

- `npm run test:coverage`
  - Միավորային թեստերի հավաքածուի սկզբնաղբյուրային ծածկույթի հիմնական շեմը
  - Ստեղծում է `text-summary`, `html`, `json-summary` և `lcov`
- `npm run coverage:report`
  - Վերջին գործարկման մանրամասն՝ ֆայլ առ ֆայլ հաշվետվությունը
- `npm run test:coverage:legacy`
  - Միայն պատմական համեմատության համար

## Շեմերի աստիճանական բարձրացման քաղաքականություն

Թարմացրեք `npm run test:coverage`-ի շեմերը միայն այն բանից հետո, երբ նախագիծն իրականում հարմարավետ պաշարով գերազանցի հաջորդ նշաձողը։

**Ընթացիկ սահմանաչափը՝** `npm run test:coverage`-ը պարտադրում է **60 հրահանգ / 60 տող / 60 ֆունկցիա / 60 ճյուղ** (չափանիշը վերահաշվարկվել է Quality-Gates փուլի 6A.1-ում․ նախկին 82.58% ելակետային ցուցանիշն արհեստականորեն բարձր էր, քանի որ այն հաշվում էր թեստային ֆայլերը և բացառում `open-sse`-ն)։ `test:coverage:legacy` հրամանը պահպանում է հին 50/50/50 չափանիշը՝ պատմական համեմատության համար։

## Հայտնի բացը

Ծածկույթի ընթացիկ հրամանը չափում է Node-ի հիմնական մոդուլային թեստերի հավաքածուն և ներառում է դրանից հասանելի սկզբնաղբյուրային կոդը, այդ թվում՝ `open-sse`-ն։ Այն դեռևս չի միավորում Vitest-ի ծածկույթը մեկ միասնական հաշվետվության մեջ։ Արժե այդ միավորումն ավելի ուշ իրականացնել, սակայն այն խոչընդոտ չէ 60%-ից դեպի 80% աճը սկսելու համար։
