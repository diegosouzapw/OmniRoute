> **Կարճ ասած**․ OmniRoute-ը դասակարգում է իր **անվճար** մատակարարներին ըստ մոդելների որակի՝ օգտագործելով **Arena AI-ի
> (LMArena-ի ոճով) ELO միավորները**։ Վահանակում բացեք **Անվճար մատակարարների դասակարգում** էջը՝ տեսնելու, թե որ անվճար մատակարարներն են առաջարկում ձեր առաջադրանքի համար ամենաուժեղ մոդելները՝
> ընդհանուր առմամբ կամ ըստ կատեգորիայի զտված (կոդավորում, վերանայում, փաստաթղթավորում, վրիպազերծում)։

## Ինչ է սա

OmniRoute-ը գրանցում է 329 մատակարար, այդ թվում՝ կատալոգի 155 գրառում, որոնք նշված են որպես **անվճար/առանց նույնականացման**
(առանց նույնականացման,
անվճար մակարդակի OAuth կամ անվճար մակարդակի API բանալի․ տե՛ս
[Անվճար մակարդակների ուղեցույցը](../getting-started/FREE-TIERS-GUIDE.md) և ամբողջական
[Անվճար մակարդակների ցանկը](../reference/FREE_TIERS.md))։ Սակայն կա մի խնդիր․ անվճար մատակարարների մոդելների որակը
խիստ տարբերվում է։ Առաջատար մոդել տրամադրող՝ նույնականացում չպահանջող մատակարարը շատ ավելի օգտակար է,
քան փոքր, հնացած մոդել տրամադրողը։

**Անվճար մատակարարների դասակարգումը** պատասխանում է «**ո՞ր անվճար մատակարարն է ինձ տալիս լավագույն մոդելը**» հարցին՝
յուրաքանչյուր անվճար մատակարարի կատալոգը համադրելով **օգտատերերի հավաքական գնահատականների** հետ՝ վերցված
**Arena AI առաջատարների աղյուսակից** (մարդկային նախապատվությունների վրա հիմնված ELO, նույն գաղափարը, որն ընկած է LMArena-ի
չաթ-բոտերի մրցադաշտի հիմքում)։ Այնուհետև մատակարարները դասակարգվում են ըստ իրենց **լավագույն անվճար մոդելի** հզորության։

Դասակարգումը հաշվարկվում է երեք իրական աղբյուրից՝

1. Անվճար մատակարարների ցանկերը՝ `NOAUTH_PROVIDERS`, ինչպես նաև `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` գրառումները, որոնք նշված են `hasFree` դրոշակով
   (`src/shared/constants/providers.ts`)։
2. Յուրաքանչյուր մատակարարի մոդելների կատալոգը՝ մատակարարների գրանցամատյանից
   (`open-sse/config/providerRegistry.ts`)։
3. ELO-ից ստացված՝ առաջադրանքին համապատասխանության միավորները, որոնք Arena ELO համաժամացման շարժիչի կողմից պահվում են
   `model_intelligence` ՏԲ աղյուսակում (`src/lib/arenaEloSync.ts`)։

Համադրման տրամաբանությունը գտնվում է `src/lib/freeProviderRankings.ts` ֆայլում։

## Ինչպես մուտք գործել

### Վահանակի էջը

Բացեք վահանակը և անցեք **Ծախսեր → Անվճար մատակարարների դասակարգում** բաժին կամ անմիջապես անցեք հետևյալ հասցեով՝

```
/dashboard/free-provider-rankings
```

Էջը (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) ցուցադրում է՝

- Լավագույն դասակարգված անվճար մատակարարների **առաջին եռյակի պատվանդանը** (🥇 🥈 🥉)։
- Ամբողջական **դասակարգման աղյուսակ**՝ հետևյալ սյունակներով․ **Դիրք**, **Մատակարար**, **Լավագույն մոդել**,
  **Միավոր**, **Միջին միավոր**, **Մոդելներ**, **Տեսակ**։
- **Կատեգորիաների զտիչ կոճակներ**՝ _Բոլոր կատեգորիաները_, _Լռելյայն_, _Կոդավորում_, _Վերանայում_,
  _Փաստաթղթավորում_, _Վրիպազերծում_։

Յուրաքանչյուր մատակարարի **Տեսակ** նշանը ցույց է տալիս, թե ինչ եղանակով է այն անվճար՝

| Նշան     | Նշանակություն                                                 |
| -------- | ------------------------------------------------------------- |
| `NOAUTH` | Միշտ անվճար է, հավատարմագրեր չեն պահանջվում                   |
| `OAUTH`  | Անվճար մակարդակով OAuth մատակարար (`hasFree`)                 |
| `APIKEY` | Անվճար մակարդակով API բանալի օգտագործող մատակարար (`hasFree`) |

Միավորները ցուցադրվում են մարդկանց համար ընթեռնելի պիտակներով (օրինակ՝ _Էլիտար_, _Գերազանց_, _Շատ լավ_,
_Լավ_, _Միջին_), այլ ոչ թե չմշակված թվերով, քանի որ հիմքում ընկած արժեքը հարաբերական
որակական դասակարգում է, ոչ թե տոկոսային ցուցանիշ։

### API վերջնակետ

Էջը հիմնված է հրապարակային ընթերցման վերջնակետի վրա
(`src/app/api/free-provider-rankings/route.ts`)՝

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Հարցման պարամետրերը (վավերացվում են Zod-ի միջոցով)՝

| Պարամետր   | Տեսակ  | Լռելյայն | Նշումներ                                                                                                                          |
| ---------- | ------ | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `category` | string | (չկա)    | `default`, `coding`, `review`, `documentation`, `debugging` տարբերակներից մեկը։ Բաց թողեք՝ համակցված դասակարգումն ստանալու համար։ |
| `limit`    | number | `50`     | Սահմանափակվում է `1–100` միջակայքով։                                                                                              |

Պատասխանի կառուցվածքը՝

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw`-ը Arena ELO-ի սկզբնական արժեքն է, իսկ `score`-ը՝ առաջադրանքին համապատասխանության նորմալացված արժեքը
(տե՛ս ստորև)։ Գնահատված մոդելներ չունեցող մատակարարները չեն ներառվում պատասխանում։

## Ինչպես են աշխատում գնահատականները

### Աղբյուր՝ Arena AI առաջատարների աղյուսակ

Arena ELO համաժամացման շարժիչը (`src/lib/arenaEloSync.ts`) Arena AI առաջատարների աղյուսակի API-ից
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`) ստանում է երկու առաջատարների աղյուսակ՝ `text`
և `code`։ Առաջատարների աղյուսակի յուրաքանչյուր գրառում պարունակում է մոդելի անունը, մատակարարին, ELO `score`-ը, վստահության միջակայքը և ձայների քանակը։

Առաջատարների աղյուսակի կատեգորիաները համապատասխանեցվում են OmniRoute-ի առաջադրանքների կատեգորիաներին․

| Arena-ի առաջատարների աղյուսակ | OmniRoute-ի առաջադրանքների կատեգորիաներ           |
| ----------------------------- | ------------------------------------------------- |
| `text`                        | `default`, `review`, `documentation`, `debugging` |
| `code`                        | `coding`                                          |

### Նորմալացում (առաջադրանքին համապատասխանության գնահատական)

Սկզբնական ELO գնահատականները յուրաքանչյուր առաջատարների աղյուսակի համար նորմալացվում են՝ ստանալով **առաջադրանքին համապատասխանության արժեք `[0.4, 0.98]` միջակայքում**․

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Գնահատականը երբեք չի հասնում `0`-ի կամ `1`-ի՝ օգտատիրոջ վերասահմանումների համար պահուստ թողնելով։ Սա API-ի պատասխանում տեսանելի `score` դաշտն է և կառավարման վահանակում ցուցադրվող պիտակը։

### Վստահություն

Յուրաքանչյուր գրառում ստանում է վստահության մակարդակ՝ հիմնված Arena-ի ձայների քանակի վրա․

| Վստահություն | Ձայներ  |
| ------------ | ------- |
| `high`       | ≥ 5,000 |
| `medium`     | ≥ 1,000 |
| `low`        | < 1,000 |

### Պահպանում և արդիականություն

Նորմալացված գրառումները պահվում են ՏԲ-ի `model_intelligence` աղյուսակում՝
`source = "arena_elo"` արժեքով (`src/lib/db/modelIntelligence.ts`)։ Գրառումների ժամկետը **լրանում է
7 օր անց**, այնպես որ համաժամացումը դադարեցրած մատակարարն ի վերջո հեռացվում է՝ հնացած տվյալներ մատուցելու փոխարեն։

Համաժամացումը **լռելյայն միացված է**․

- Այն գործարկվում է մեկ անգամ սերվերի մեկնարկի ժամանակ, ապա՝ պարբերական ժամանակաչափով
  (`src/lib/arenaEloSync.ts`, միացված է `src/instrumentation-node.ts`-ից)։
- Այն **չարգելափակող է և երբեք չի հանգեցնում ճակատագրական սխալի**․ եթե վերին աղբյուրից տվյալների ստացումը ձախողվում է, OmniRoute-ը շարունակում է
  աշխատել, իսկ վարկանիշները պարզապես ցուցադրում են վերջին հաջողությամբ ստացված տվյալները (կամ դատարկ վիճակ)։

Այն կառավարվում է միջավայրի երկու փոփոխականով (փաստաթղթավորված են
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)-ում)․

| Փոփոխական                 | Լռելյայն արժեք | Նպատակ                                                     |
| ------------------------- | -------------- | ---------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`         | Արտաքին համաժամացումից հրաժարվելու համար սահմանեք `false`։ |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24ժ)  | Համաժամացման միջակայքը՝ վայրկյաններով։                     |

### Ձեռքով համաժամացում / կարգավիճակ / մաքրում

Օպերատորների համար նույնականացում պահանջող կառավարման վերջնակետը տրամադրում է ձեռքով կառավարում
(`src/app/api/intelligence/sync/route.ts` — պահանջում է կառավարման նույնականացում)․

```
GET    /api/intelligence/sync          # համաժամացման ընթացիկ կարգավիճակը (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # գործարկել ձեռքով համաժամացում․ body: { "dryRun": true }՝ առանց գրանցման նախադիտելու համար
DELETE /api/intelligence/sync          # մաքրել բոլոր համաժամացված arena_elo բանականության գրառումները
```

Եթե վարկանիշների էջը դատարկ է, ձեռքով կատարված `POST /api/intelligence/sync` հարցումը (կամ պարզապես
սերվերի վերագործարկումը) կրկին լրացնում է այն։

### Մոդելների համապատասխանեցումն առաջատարների աղյուսակին

Ռեեստրի մոդելների ID-ները և Arena-ի մոդելների անունները միշտ չէ, որ ճշգրտորեն համընկնում են։ Վարկանիշավորման ժամանակ օգտագործվում է
ճկուն համապատասխանեցում (`findMatchingIntelligence`՝ `src/lib/freeProviderRankings.ts`-ում)․

1. Նորմալացված մոդելի ID-ի ճշգրիտ համընկնում։
2. Համընկնում վերջում գտնվող տարբերակի վերջածանցը հեռացնելուց հետո (օրինակ՝ `kimi-k2.6` → `kimi-k2`)։
3. Նախածանցով համընկնում (առաջատարների աղյուսակի մոդելի անունը ռեեստրի ID-ի նախածանցն է)։

Համաժամացման կողմում հայտնի մատակարարների նախածանցները (`anthropic/`, `openai/`, `google/`, …)
հեռացվում են, իսկ կեղծանունների փոքր քարտեզը կանոնական անունները ընդլայնում է OmniRoute-ի ներսում օգտագործվող տարբերակների,
որպեսզի մոդելները հնարավոր լինի գտնել ցանկացած անունով։

### Ինչպես է վարկանիշավորվում մատակարարը

Յուրաքանչյուր անվճար մատակարարի համար շարժիչը գնահատում է նրա կատալոգի բոլոր մոդելները, ապա՝

- **Լավագույն մոդել** = մատակարարի ամենաբարձր գնահատական ունեցող մոդելը։
- **Միջին գնահատական** = տվյալ մատակարարի գնահատված բոլոր մոդելների գնահատականների միջինը։
- **Մոդելներ** = մատակարարի այն մոդելների քանակը, որոնք ունեին Arena-ի գնահատական։

Մատակարարները նախ դասավորվում են ըստ **լավագույն մոդելի գնահատականի**, ապա՝ ըստ միջին գնահատականի։ Այս մոտեցումը առավելություն է տալիս այն
մատակարարին, որն առաջարկում է առնվազն մեկ ուժեղ անվճար մոդել։

## Դրա օգտագործումը՝ անվճար մատակարարներ ընտրելու համար

1. **Ընտրեք ճիշտ կատեգորիան։** Գործակալային/կոդային աշխատանքային ծանրաբեռնվածությունների համար օգտագործեք **Coding** զտիչը, իսկ
   ընդհանուր զրույցի համար թողեք **All Categories** / **Default** տարբերակը։ Նույն մատակարարը կարող է
   տարբեր կատեգորիաներում տարբեր դիրք զբաղեցնել, քանի որ դրա լավագույն մոդելը տարբերվում է ըստ վարկանիշային աղյուսակի։
2. **Մեկանգամյա կարգավորումների համար նախապատվությունը տվեք առաջատար եռյակին։** Եթե ցանկանում եք միացնել ընդամենը մեկ կամ երկու անվճար
   մատակարար, սկսեք ձեր կատեգորիայում ամենաբարձր վարկանիշ ունեցողներից։
3. **Ստուգեք Type նշանը։** `NOAUTH` մատակարարներն ամենաարագն են միացվում (առանց
   նույնականացման տվյալների)։ `OAUTH` / `APIKEY` անվճար մակարդակները պահանջում են արագ գրանցում, սակայն հաճախ հասանելի են դարձնում
   ավելի հզոր մոդելներ։ Միացման քայլերի համար տե՛ս [Անվճար մակարդակների ուղեցույցը](../getting-started/FREE-TIERS-GUIDE.md)։
4. **Միացրեք մի քանիսը և թույլ տվեք, որ Auto-Combo-ն որոշի։** Arena ELO-ի նույն տվյալները, որոնցով աշխատում է
   այս էջը, նաև տրամադրվում են Auto-Combo գնահատման շարժիչի **առաջադրանքին համապատասխանության գործոնին**
   (`open-sse/services/autoCombo/taskFitness.ts`, որոշման հերթականությունը՝
   `user_override → arena_elo → models_dev_tier → static table`)։ Այսպիսով, լավագույն անվճար մատակարարները միացնելուց
   հետո `model: "auto"`-ով երթուղավորումը (օրինակ՝ `auto/coding`) յուրաքանչյուր հարցման համար
   ինքնաբերաբար նախապատվություն կտա ավելի բարձր որակի անվճար մոդելներին։ 16 գործոնով ամբողջական գնահատման մասին տե՛ս
   [Auto-Combo](../routing/AUTO-COMBO.md) բաժինը։
