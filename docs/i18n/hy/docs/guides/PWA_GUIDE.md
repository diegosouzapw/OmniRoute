OmniRoute-ը տրամադրվում է որպես ամբողջությամբ տեղադրվող պրոգրեսիվ վեբ հավելված։ Երբ ցանկացած բջջային դիտարկիչից՝ Android-ում (Chrome) կամ iOS-ում (Safari), մուտք եք գործում կառավարման վահանակ, կարող եք ընտրել «Ավելացնել գլխավոր էկրանին» և ստանալ բնիկ հավելվածին նման փորձառություն՝ առանց հավելվածների խանութի անհրաժեշտության։

## Ի՞նչ է PWA-ն

Պրոգրեսիվ վեբ հավելվածը OmniRoute-ի վեբ կառավարման վահանակը վերածում է մի բանի, որն ունի բնիկ բջջային հավելվածի տեսք և վարքագիծ։ Տեղադրումից հետո այն՝

- Գործարկվում է ձեր գլխավոր էկրանից՝ իր սեփական պատկերակով
- Բացվում է ամբողջ էկրանով՝ առանց դիտարկիչի հասցեագոտու կամ ներդիրների միջերեսի
- Աշխատում է անցանց՝ կապակցման համար նախատեսված առանձին էջով
- Քեշավորում է ստատիկ ռեսուրսները՝ ավելի արագ բեռնման համար
- Աջակցում է ինչպես ուղղաձիգ, այնպես էլ հորիզոնական դիրքորոշումներին

## Տեղադրում

### Android (Chrome)

1. Բացեք OmniRoute-ի կառավարման վահանակը Chrome-ում՝ `http://YOUR_IP:20128`
2. Chrome-ն ինքնաշխատ կերպով կցուցադրի **«Ավելացնել OmniRoute-ը գլխավոր էկրանին»** վահանակը, կամ՝
   - Հպեք **⋮** ընտրացանկին (երեք կետ) → **«Ավելացնել գլխավոր էկրանին»** կամ **«Տեղադրել հավելվածը»**
3. Հաստատեք հուշումը
4. OmniRoute-ը կհայտնվի ձեր գլխավոր էկրանին՝ որպես ինքնուրույն հավելված

### iOS (Safari)

1. Բացեք OmniRoute-ի կառավարման վահանակը Safari-ում՝ `http://YOUR_IP:20128`
2. Հպեք **Կիսվել** կոճակին (սլաքով քառակուսի)
3. Ոլորեք ներքև և հպեք **«Ավելացնել գլխավոր էկրանին»**
4. Անվանեք այն (լռելյայն՝ «OmniRoute») և հպեք **Ավելացնել**
5. OmniRoute-ը հավելվածի պատկերակով կհայտնվի ձեր գլխավոր էկրանին

### Համակարգիչ (Chrome / Edge)

1. Բացեք OmniRoute-ի կառավարման վահանակը
2. Հասցեագոտում սեղմեք **տեղադրման պատկերակը** (կամ ⋮ → «Տեղադրել OmniRoute-ը...»)
3. Հաստատեք հուշումը
4. OmniRoute-ը կբացվի որպես ինքնուրույն պատուհան՝ առանց ներդիրների և հասցեագոտու

## Հնարավորություններ

### Ամբողջ էկրանով աշխատանք

Մանիֆեստը կազմաձևված է `display: "fullscreen"` պարամետրով, ինչը նշանակում է, որ տեղադրված հավելվածն օգտագործում է ամբողջ էկրանը՝ առանց դիտարկիչի միջերեսի և կարգավիճակի գոտու հետ վերադրման։ Դրա շնորհիվ կառավարման վահանակն իսկապես բնիկ հավելվածի տպավորություն է թողնում։

### Անցանց աջակցություն

OmniRoute-ը ներառում է ծառայողական աշխատիչ (`sw.js`), որն ապահովում է խելացի քեշավորում՝

| Ռեսուրսի տեսակ                                                           | Ռազմավարություն                  | Վարքագիծ                                                                                                   |
| ------------------------------------------------------------------------ | -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Հավելվածի հիմք**                                                       | Նախ՝ քեշից                       | `/`, `/offline`, մանիֆեստը և պատկերակները տեղադրման ընթացքում նախապես քեշավորվում են                       |
| **Ստատիկ ռեսուրսներ** (CSS, JS, պատկերներ, տառատեսակներ)                 | Նախ՝ ցանցից, ապա՝ քեշից          | Թարմ տարբերակը ստացվում է ցանցից, իսկ անցանց լինելու դեպքում օգտագործվում է քեշը                           |
| **Next.js փաթեթներ** (`/_next/`)                                         | Նախ՝ ցանցից՝ քեշի թարմացմամբ     | Ստացվում են ցանցից և թարմացնում քեշը, իսկ անցանց լինելու դեպքում տրամադրվում է քեշավորված տարբերակը        |
| **Նավարկման հարցումներ**                                                 | Շրջանցում (երբեք չի միջամտվում)  | HTTP/3→HTTP/2 հետանցումը վերահսկում է դիտարկիչը. չաշխատող QUIC սոկետը չպետք է վերածվի `Response.error()`-ի |
| **API / կառավարման վահանակի երթուղիներ** (`/api/`, `/a2a`, `/dashboard`) | Շրջանցում (երբեք չի քեշավորվում) | Միշտ ուղիղ փոխանցվում է սերվերին և ծառայողական աշխատիչի կողմից երբեք չի միջամտվում                         |

### Անցանց էջ

Երբ ցանցն անհասանելի է, և օգտատերը փորձում է անցնել նոր էջ, ծառայողական աշխատիչը ցուցադրում է հատուկ `/offline` էջ, որը՝

- Ցուցադրում է հստակ **«Կապակցման խնդիր»** հաղորդագրություն
- Ցուցադրում է **առցանց/անցանց վիճակի ցուցիչ**, որը թարմացվում է իրական ժամանակում
- Տրամադրում է **«Կրկին փորձել միանալ»** կոճակ՝ կապի վերականգնումից հետո էջը վերաբեռնելու համար
- Ախտորոշման համար հղում է տալիս դեպի **Կարգավիճակի էջը**

### Հավելվածի պատկերակներ

OmniRoute-ը տրամադրում է յուրաքանչյուր հարթակի համար օպտիմալացված պատկերակներ՝

| Ֆայլ                   | Չափ                  | Որտեղ է օգտագործվում                           |
| ---------------------- | -------------------- | ---------------------------------------------- |
| `icon-512.png`         | 512×512              | Android-ի տեղադրման հուշում, մեկնարկային էկրան |
| `apple-touch-icon.png` | 180×180              | iOS-ի գլխավոր էկրանի պատկերակ                  |
| `icon-192.svg`         | 192×192 (վեկտորային) | Android-ի հարմարվողական պատկերակ               |
| `apple-touch-icon.svg` | 180×180 (վեկտորային) | Apple-ի պահուստային տարբերակ                   |
| `favicon.svg`          | Վեկտորային           | Դիտարկիչի ներդիրներ                            |
| `favicon.ico`          | Բազմաչափ             | Հին դիտարկիչներ                                |

### Ինքնաշխատ գրանցում

Ծառայողական աշխատիչն ինքնաշխատ գրանցվում է արմատային դասավորության `<PwaRegister />` բաղադրիչի միջոցով։ Օգտատիրոջից որևէ գործողություն չի պահանջվում. հավելվածը հնարավոր է դառնում տեղադրել հենց որ դիտարկիչը հայտնաբերում է վավեր մանիֆեստը և ծառայողական աշխատիչը։

## Տեխնիկական ճարտարապետություն

### Վեբ հավելվածի մանիֆեստ (`manifest.webmanifest`)

Ստեղծվում է Next.js-ի կողմից՝ `src/app/manifest.ts`-ի միջոցով.

```json
{
  "name": "OmniRoute",
  "short_name": "OmniRoute",
  "description": "OmniRoute is an AI gateway for multi-provider LLMs. One endpoint for all your AI providers.",
  "start_url": "/",
  "scope": "/",
  "display": "fullscreen",
  "orientation": "any",
  "background_color": "#0b0f1a",
  "theme_color": "#0b0f1a",
  "icons": [
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    },
    { "src": "/apple-touch-icon.png", "sizes": "180x180", "type": "image/png" }
  ]
}
```

### Սպասարկման աշխատող (`public/sw.js`)

Սովորական սպասարկման աշխատող՝ առանց ֆրեյմվորքից կախվածությունների, որն ունի հետևյալ հնարավորությունները.

- **Տեղադրման փուլ**. Նախապես քեշավորում է հավելվածի շելլը (արմատային էջը, անցանց էջը, մանիֆեստը և պատկերակները)
- **Ակտիվացման փուլ**. Մաքրում է քեշի հին տարբերակները և ստանձնում է բոլոր կլիենտների կառավարումը
- **Հարցումների մշակման փուլ**. Կատարում է խելացի երթուղավորում՝ հարցման տեսակի հիման վրա (նավիգացիա, ստատիկ ռեսուրս, API)
- **Քեշի տարբերակավորում**. `omniroute-pwa-v3` — ավելացրեք այս տարբերակը՝ թարմացման ժամանակ ամբողջովին նոր քեշ հարկադրելու համար

### Դասավորության մետատվյալներ (`src/app/layout.tsx`)

Արմատային դասավորությունը տրամադրում է PWA-ի պահանջներին համապատասխանելու համար անհրաժեշտ բոլոր մետաթեգերը.

- `manifest` հղում դեպի `/manifest.webmanifest`
- `apple-web-app-capable: true`՝ iOS-ի ինքնուրույն ռեժիմի համար
- `apple-web-app-status-bar-style: black-translucent`
- `mobile-web-app-capable: yes`՝ Android Chrome-ի համար
- `theme-color: #0b0f1a`
- `viewport-fit: cover`՝ եզրից եզր արտապատկերման համար

### Բաղադրիչ՝ `PwaRegister`

Գտնվում է `src/shared/components/PwaRegister.tsx` հասցեում։ Այս կլիենտային բաղադրիչը.

1. Գործարկվում է մոնտաժման ժամանակ (միայն կլիենտային կողմում)
2. Ստուգում է բրաուզերում `serviceWorker`-ի աջակցությունը
3. Աննկատ գրանցում է `/sw.js`-ը (սխալներն անտեսվում են՝ հավելվածի աշխատանքը չարգելափակելու համար)
4. Ոչինչ չի արտապատկերում (`return null`)՝ այն միայն կողմնակի ազդեցություն առաջացնող բաղադրիչ է

## Օգտագործում Termux-ի հետ (Android)

Android-ում OmniRoute-ը Termux-ի միջոցով գործարկելիս PWA-ն աշխատում է անխափան.

1. Գործարկեք OmniRoute-ը Termux-ում՝ `npx omniroute`
2. Նույն հեռախոսում բացեք Chrome-ը՝ `http://localhost:20128`
3. Տեղադրեք PWA-ն «Ավելացնել գլխավոր էկրանին» տարբերակի միջոցով
4. PWA-ն միանում է տեղական Termux սերվերին. ամեն ինչ աշխատում է հենց սարքի վրա

Այս համադրությունը նշանակում է, որ ձեր Android հեռախոսը միաժամանակ և՛ **սերվեր** է (Termux), և՛ **կլիենտ** (PWA)՝ ամբողջական ինքնաբավ AI դարպաս։

## Օգտագործում այլ սարքերից

Տեղադրեք PWA-ն ցանկացած սարքում, որի բրաուզերից հասանելի է ձեր OmniRoute սերվերը.

- **Մեկ այլ հեռախոս/պլանշետ**. Անցեք `http://PHONE_IP:20128` հասցեով և տեղադրեք PWA-ն
- **Նոթբուք**. Բացեք Chrome/Edge-ը և տեղադրեք այն որպես աշխատասեղանի PWA
- **Բրաուզեր ունեցող խելացի հեռուստացույց**. Բացեք կառավարման վահանակն ամբողջ էկրանով

## Անհատականացում

### Օրինակի անվանում

PWA-ի վերնագիրը հաշվի է առնում `Dashboard → Settings` բաժնում նշված **Instance Name** կարգավորումը։ Եթե ձեր օրինակը վերանվանեք «My AI Gateway», տեղադրված PWA-ն կցուցադրի այդ անունը։

### Հատուկ favicon

Եթե `Dashboard → Settings` բաժնի միջոցով վերբեռնեք հատուկ favicon, աշխատասեղանի PWA պատկերակը կարտացոլի այդ հատուկ պատկերակը։ Բջջային սարքի գլխավոր էկրանի պատկերակներն օգտագործում են նախապես ստեղծված `icon-512.png` և `apple-touch-icon.png` ֆայլերը։

## Սահմանափակումներ

- **Push ծանուցումներ չկան** — Service worker-ը չի իրականացնում Push API-ն։ Փոխարենը ծանուցումները մշակվում են Electron հավելվածի կողմից։
- **Ֆոնային համաժամացում չկա** — Անցանց գործողությունները չեն հերթագրվում հետագա վերարտադրման համար։ PWA-ն հիմնականում կառավարման վահանակի դիտիչ է։
- **iOS-ի սահմանափակումներ** — iOS-ի Safari-ն չի աջակցում PWA-ի բոլոր հնարավորությունները (օրինակ՝ տեղադրման հուշումները ձեռքով են կատարվում, իսկ ֆոնային service worker-ները սահմանափակված են)։
- **Քեշի չափը** — Service worker-ը քեշավորում է միայն ստատիկ ռեսուրսները։ `/api/` երթուղիներից ստացվող մեծ պատասխանների բովանդակությունը երբեք չի քեշավորվում։
- **Հատուկ պատկերակներ բջջային սարքերում** — Կարգավորումներում favicon-ը փոխելը չի թարմացնում բջջային սարքի գլխավոր էկրանի պատկերակը (դրա համար անհրաժեշտ է վերաստեղծել PWA պատկերակները)։
