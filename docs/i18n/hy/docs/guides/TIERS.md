OmniRoute-ը աջակցվող 352 մատակարարներին բաժանում է տնտեսական 3 մակարդակի։ Յուրաքանչյուր հարցում հերթականությամբ անցնում է դրանցով, մինչև դրանցից մեկը հաջող պատասխան վերադարձնի․ դուք ստանում եք ամենաէժան կենսունակ պատասխանը՝ առանց պահուստային անցումների կոդ գրելու։

## Մակարդակ 1 — Բաժանորդագրություն

**Մատակարարներ, որոնց համար արդեն վճարում եք։** OmniRoute-ն օգտագործում է քվոտայի ամբողջ մնացորդը՝ նախքան դրա ժամկետի ավարտը։

| Մատակարար                                 | Ինչու է Մակարդակ 1-ում                                      |
| ----------------------------------------- | ----------------------------------------------------------- |
| Claude Code OAuth                         | Anthropic Pro/Team — ֆիքսված սակագին, հաճախ չի օգտագործվում |
| OpenAI Codex (ChatGPT բաժանորդագրություն) | Plus/Team-ը ներառում է Codex-ի քվոտա                        |
| GitHub Copilot                            | Յուրաքանչյուր օգտահաշվի համար․ քվոտան թարմացվում է ամսական  |
| Cursor IDE                                | Pro պլանի քվոտա                                             |
| Antigravity / Devin Desktop               | Ներկառուցված քվոտաներ                                       |

**Ռազմավարություն**․ յուրաքանչյուր հարցում, որը համապատասխանում է մոդելի ուժեղ կողմերին, նախ ուղղորդեք այստեղ։ Քվոտայի վերահսկիչը հետևում է մոտեցող վերականգնումներին, իսկ `reset-aware` համակցված ռազմավարությունը համապատասխանաբար սահմանում է առաջնահերթությունները։ Մակարդակ 1-ն առաջինը օգտագործելու և միայն քվոտայի սպառումից հետո վճարովի մակարդակներին անցնելու համար օգտագործեք `auto/thrifty` id-ն, իսկ միայն պլանում ներառված հզորությունների սահմաններում մնալու և դրանց անհասանելիության դեպքում հարցումը ձախողելու համար՝ `auto/subscription`-ը։ Տե՛ս [Բաժանորդագրությունն առաջնահերթ օգտագործող ուղղորդում](../routing/SUBSCRIPTION_LADDER.md)։

## Մակարդակ 2 — Էժան

**Ըստ թոքենների վճարվող մատակարարներ՝ 1 մլն թոքենի համար $1-ից պակաս արժեքով։** Նախատեսված են մեծ ծավալի աշխատանքների համար կամ այն դեպքերի, երբ Մակարդակ 1-ի քվոտաները հասնում են սահմանաչափին։

| Մատակարար                         | Գին (մուտք/ելք)              | Ուժեղ կողմեր                     |
| --------------------------------- | ---------------------------- | -------------------------------- |
| DeepSeek V4 Pro                   | $0.27 / $1.10՝ 1 մլն-ի համար | Կոդ, տրամաբանական վերլուծություն |
| GLM-4.5                           | $0.60 / $2.20՝ 1 մլն-ի համար | Երկար համատեքստ                  |
| MiniMax M1                        | $0.20 / $1.10՝ 1 մլն-ի համար | Արագություն                      |
| Qwen Coder                        | $0.30 / $1.20՝ 1 մլն-ի համար | Կոդ                              |
| OpenRouter (ըստ գնի օպտիմալացված) | փոփոխական                    | 100+ մոդել, դինամիկ              |

**Ռազմավարություն**․ `cost-optimized` համակցությունը ընտրում է թոքենի ամենացածր արժեքն ունեցող մոդելը, որը բավարարում է առաջադրանքի հնարավորությունների զտիչին (տեսողություն, JSON ռեժիմ, գործիքներ, առավելագույն համատեքստ)։

## Մակարդակ 3 — Անվճար

**Զրոյական արժեքով մատակարարներ**՝ անվճար մակարդակներ, վարկային ծրագրեր, OAuth-ի օրական քվոտաներ։

| Մատակարար        | Անվճար քվոտա / վարկեր                                            |
| ---------------- | ---------------------------------------------------------------- |
| Kiro AI          | Claude-ի անվճար մակարդակ (առատաձեռն արդար օգտագործման պայմաններ) |
| OpenCode Free    | Առանց նույնականացման, առատաձեռն հաճախականության սահմանաչափեր     |
| Qoder            | Անվճար OAuth                                                     |
| Google Vertex AI | $300 վարկ՝ նոր հաշիվների համար                                   |
| Amazon Q         | Անվճար մակարդակ AWS-ի օգտատերերի համար                           |
| Pollinations     | Բաց հանրային API                                                 |
| Cloudflare AI    | Workers AI-ի անվճար մակարդակ                                     |

**Ռազմավարություն**․ բյուջեի սահմանաչափով `auto` համակցությունը հարցումներն ուղղորդում է այստեղ, երբ Մակարդակ 1+2-ը ձախողվում են կամ երբ սահմանված է `useFreeOnly=true`։ Անվճար մատակարարները հաճախ ունեն հարցումների հաճախականության ավելի խիստ սահմանաչափեր․ ավտոմատ անջատիչը դադարից հետո վերականգնում է դրանց հասանելիությունը։

## Մակարդակների կարգավորում

Կառավարման վահանակ → **Մակարդակներ** → նշանակեք ձեր մատակարարներին։ Լռելյայն կարգավորումները (`tierDefaults.json`-ից) ողջամիտ են․ խմբագրեք դրանք, երբ ունեք որոշակի բաժանորդագրություններ, որոնց պետք է առաջնահերթություն տալ, կամ մատակարարներ, որոնց պետք է բացառել։

Auto-Combo-ի՝ 16 գործոնից բաղկացած գնահատումը նույնպես հաշվի է առնում մակարդակը։ Տե՛ս [`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md)։

## Հեռաչափություն

Կառավարման վահանակ → **Օգտագործում** բաժինը ցույց է տալիս յուրաքանչյուր մակարդակում օրական ծախսված թոքենները։ Օգտագործեք սա՝

- Հաստատելու, որ Մակարդակ 1-ն ամբողջությամբ օգտագործվում է (հակառակ դեպքում դուք վատնում եք բաժանորդագրության արժեքը)
- Պարզելու, թե Մակարդակ 2-ի որ մոդելներն են առավել հաճախ ընտրվում (կրճատեք մինչև 1-2 մոդել)
- Ստուգելու, որ Մակարդակ 3-ը գումար է խնայում թեստավորման/ուսումնասիրության աշխատանքներում

## Տարածված ձևաչափեր

### Միայն անվճար ռեսուրսներ օգտագործող աշխատանքային բեռնվածություն

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Խիստ առաջնահերթություն է տալիս Մակարդակ 3-ին և Մակարդակ 2-ն օգտագործում է միայն այն դեպքում, երբ Մակարդակ 3-ն անհասանելի է։

### Բաժանորդագրությունն առաջնահերթ՝ էժան պահուստային տարբերակով

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Հստակ հերթականացված ցանկ՝ Մակարդակ 1 → Մակարդակ 2 → Մակարդակ 3 դասավորությամբ։
