## Արագ ապատեղադրում (v3.6.2+)

OmniRoute-ը տրամադրում է մաքուր հեռացման երկու ներկառուցված սկրիպտ.

### Պահպանեք ձեր տվյալները

```bash
npm run uninstall
```

Սա հեռացնում է OmniRoute հավելվածը, սակայն **պահպանում է** ձեր տվյալների բազան, կազմաձևումները, API բանալիները և մատակարարների կարգավորումները `~/.omniroute/`-ում։ Օգտագործեք սա, եթե նախատեսում եք հետագայում վերատեղադրել և ցանկանում եք պահպանել ձեր կարգավորումները։

### Ամբողջական հեռացում

```bash
npm run uninstall:full
```

Սա հեռացնում է հավելվածը և **ընդմիշտ ջնջում** բոլոր տվյալները.

- Տվյալների բազան (`storage.sqlite`)
- Մատակարարների կազմաձևումները և API բանալիները
- Պահուստային պատճենների ֆայլերը
- Մատյանների ֆայլերը
- `~/.omniroute/` գրացուցակի բոլոր ֆայլերը

> ⚠️ **Զգուշացում.** `npm run uninstall:full` գործողությունն անշրջելի է։ Մատակարարների հետ ձեր բոլոր կապերը, համակցությունները, API բանալիները և օգտագործման պատմությունը ընդմիշտ կջնջվեն։

## Ձեռքով ապատեղադրում

### NPM-ի գլոբալ տեղադրում

```bash
# Հեռացնել գլոբալ փաթեթը
npm uninstall -g omniroute

# (Ըստ ցանկության) հեռացնել տվյալների գրացուցակը
rm -rf ~/.omniroute
```

### pnpm-ի գլոբալ տեղադրում

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Կանգնեցնել և հեռացնել կոնտեյները
docker stop omniroute
docker rm omniroute

# Հեռացնել հատորը (ջնջում է բոլոր տվյալները)
docker volume rm omniroute-data

# (Ըստ ցանկության) հեռացնել պատկերը
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Կանգնեցնել և հեռացնել կոնտեյներները
docker compose down

# Հեռացնել նաև հատորները (ջնջում է բոլոր տվյալները)
docker compose down -v
```

### Electron-ի աշխատասեղանի հավելված

**Windows.**

- Բացեք `Settings → Apps → OmniRoute → Uninstall`
- Կամ տեղադրման գրացուցակից գործարկեք NSIS ապատեղադրիչը

**macOS.**

- `/Applications`-ից `OmniRoute.app`-ը քաշեք Աղբարկղ
- Հեռացրեք տվյալները՝ `rm -rf ~/Library/Application Support/omniroute`

**Linux.**

- Հեռացրեք AppImage ֆայլը
- Հեռացրեք տվյալները՝ `rm -rf ~/.omniroute`

### Աղբյուրային կոդից տեղադրում (git clone)

```bash
# Հեռացնել կլոնավորված գրացուցակը
rm -rf /path/to/omniroute

# (Ըստ ցանկության) հեռացնել տվյալների գրացուցակը
rm -rf ~/.omniroute
```

## Տվյալների գրացուցակներ

Լռելյայն OmniRoute-ը տվյալները պահում է հետևյալ վայրերում.

| Հարթակ         | Լռելյայն ուղի                 | Վերասահմանում                         |
| -------------- | ----------------------------- | ------------------------------------- |
| Linux          | `~/.omniroute/`               | `DATA_DIR` միջավայրի փոփոխական        |
| macOS          | `~/.omniroute/`               | `DATA_DIR` միջավայրի փոփոխական        |
| Windows        | `%APPDATA%/omniroute/`        | `DATA_DIR` միջավայրի փոփոխական        |
| Docker         | `/app/data/` (միացված հատոր)  | `DATA_DIR` միջավայրի փոփոխական        |
| XDG-համատեղելի | `$XDG_CONFIG_HOME/omniroute/` | `XDG_CONFIG_HOME` միջավայրի փոփոխական |

### Տվյալների գրացուցակի ֆայլերը

| Ֆայլ/գրացուցակ       | Նկարագրություն                                                                      |
| -------------------- | ----------------------------------------------------------------------------------- |
| `storage.sqlite`     | Հիմնական տվյալների բազա (մատակարարներ, համակցություններ, կարգավորումներ, բանալիներ) |
| `storage.sqlite-wal` | SQLite-ի նախնական գրանցման մատյան (ժամանակավոր)                                     |
| `storage.sqlite-shm` | SQLite-ի համօգտագործվող հիշողություն (ժամանակավոր)                                  |
| `call_logs/`         | Հարցումների օգտակար բեռների արխիվներ                                                |
| `backups/`           | Տվյալների բազայի ավտոմատ պահուստային պատճեններ                                      |
| `log.txt`            | Հարցումների հին ձևաչափի մատյան (ըստ ցանկության)                                     |

## Ստուգեք ամբողջական հեռացումը

Տեղահանումից հետո համոզվեք, որ մնացած ֆայլեր չկան.

```bash
# Ստուգել գլոբալ npm փաթեթի առկայությունը
npm list -g omniroute 2>/dev/null

# Ստուգել տվյալների գրացուցակի առկայությունը
ls -la ~/.omniroute/ 2>/dev/null

# Ստուգել գործող պրոցեսների առկայությունը
pgrep -f omniroute
```

Եթե որևէ պրոցես դեռ գործում է, դադարեցրեք այն.

```bash
pkill -f omniroute
```
