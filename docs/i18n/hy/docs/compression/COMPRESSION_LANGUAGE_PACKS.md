Caveman սեղմումը կարող է ներկառուցված անգլերեն կանոններից բացի բեռնել նաև լեզվին հատուկ կանոնների փաթեթներ։
Սա պահպանում է հիմնական շարժիչի կայունությունը՝ միաժամանակ թույլ տալով պորտուգալերենի, իսպաներենի, գերմաներենի, ֆրանսերենի, իտալերենի, ճապոներենի և
ապագա լեզուների փաթեթներին զարգանալ անկախորեն։

## Տեղադրություն

Լեզվական փաթեթները գտնվում են հետևյալ ուղու ներքո․

```txt
open-sse/services/compression/rules/<language>/
```

Ներկայումս տրամադրվող փաթեթները (ստուգված՝ ըստ `rules/` պանակի պարունակության)․

| Լեզու                    | Պանակ          | Առկա կանոնների կատեգորիաներ                         |
| ------------------------ | -------------- | --------------------------------------------------- |
| Անգլերեն                 | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Իսպաներեն                | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Պորտուգալերեն (Բրազիլիա) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Ինդոնեզերեն              | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Իտալերեն                 | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Գերմաներեն               | `rules/de/`    | `context`, `filler`, `structural`                   |
| Ֆրանսերեն                | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Ճապոներեն                | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Համարժեքության նշում․** `en`, `es`, `pt-BR`, `id` և `it` փաթեթներն ունեն բոլոր 5 կատեգորիաները, իսկ `de`, `fr`, `ja` փաթեթները տրամադրվում են 3 կատեգորիայով։ Բացակայող `dedup` և `ultra` կատեգորիաների փոխարեն առանց ծանուցման օգտագործվում են անգլերենի ներկառուցված կանոնները։ Ողջունելի են ներդրումները՝ փոքր փաթեթներում `dedup.json` և `ultra.json` ավելացնելու համար։
>
> `pt-BR` փաթեթը հիմնված է Լենինե Ժունիորի **[Troglodita](https://github.com/leninejunior/troglodita)** նախագծի վրա՝ սեղմման համակարգ, որը զրոյից նախագծվել է բրազիլական պորտուգալերենի քերականության համար (ավելորդաբանությունների կրճատում, PT-BR լցոնիչների հեռացում, տեխնիկական հապավումներ բրազիլական ծրագրավորողների համայնքի համար)։
>
> Կատեգորիաների կանոնական ցանկը և յուրաքանչյուր կատեգորիայի սխեման գտնվում են [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json)-ում (JSON Schema-ի 2020-12 սևագիր)։

## Լեզվի հայտնաբերում

`languageDetector.ts`-ը կիրառում է պարզեցված էվրիստիկաներ՝ հուշման տեքստից լեզուն որոշելու համար։
Կարգավորված լռելյայն լեզուն շարունակում է հաշվի առնվել, իսկ երբ անհրաժեշտ է ճշգրիտ
կառավարում, հայտնաբերումը կարող է անջատվել կարգավորման միջոցով։

Հայտնաբերման արդյունքն օգտագործվում է միայն կանոնների փաթեթներն ընտրելու համար։ Այն չի փոխում մատակարարի ուղղորդումը, տեղայնացման
ընտրությունը կամ միջերեսի լեզուն։

## Կարգավորման կառուցվածք

Սեղմման կարգավորումները կարող են ներառել․

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig`-ը կառավարում է կառավարման վահանակի/նախադիտման լռելյայն արժեքները։ `cavemanConfig`-ը գործարկման ժամանակ օգտագործվող շարժիչի կարգավորումն է,
որն օգտագործվում է, երբ Caveman-ը սեղմում է հաղորդագրության տեքստը։

## Լեզվային փաթեթի ավելացում

1. Ստեղծեք `open-sse/services/compression/rules/<language>/<pack>.json` ֆայլը։
2. Օգտագործեք `docs/compression/COMPRESSION_RULES_FORMAT.md`-ում նկարագրված Caveman կանոնների ձևաչափը։
3. Փոխարինումները պահեք չափավոր և խուսափեք կոդը, նույնացուցիչները, URL-ները կամ JSON-ը փոփոխելուց։
4. Ավելացրեք կամ թարմացրեք լեզվի ընտրության և փոխարինումների վարքագծի թեստերը։
5. Ավելացրեք վահանակի/i18n-ի նոր պիտակները, եթե լեզուն ցուցադրվում է միջերեսի ընտրիչներում։

## API

Հասանելի փաթեթները կարելի է ստանալ հետևյալ հարցմամբ․

```bash
curl http://localhost:20128/api/compression/language-packs
```

Նախադիտման վերջնակետն ընդունում է լեզվի կազմաձևման վերագրումներ․

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Բոլոր 6 լեզվային փաթեթները v3.8.0-ում ստացել են `SHARED_BOUNDARIES` դրույթ, որը կիրառվում է
Caveman-ի ինտենսիվության յուրաքանչյուր մակարդակում (LITE, FULL, ULTRA)։ Այն շարժիչին հրահանգում է այս ձևանմուշները պահպանել անփոփոխ՝
անկախ շրջակա ավելորդ տեքստի հեռացումից․

| Ձևանմուշի տեսակը                         | Օրինակ                                 |
| ---------------------------------------- | -------------------------------------- |
| Սահմանազատված կոդի բլոկներ               | ` ```python\n...\n``` `                |
| Ներտողային կոդ                           | `` `my_var` ``                         |
| URL-ներ                                  | `https://example.com/path`             |
| Ֆայլերի ուղիներ (բացարձակ + հարաբերական) | `/etc/hosts`, `./src/index.ts`         |
| Սխալների վերնագրեր                       | `Error:`, `TypeError:`, `SyntaxError:` |
| Կանչերի շղթայի տողեր                     | `  at functionName (file.ts:12:3)`     |

Այս ձևանմուշները լրացվում են `DEFAULT_CAVEMAN_CONFIG.preservePatterns`-ում (նախկինում՝ `[]`)։ Այս
հաստատունը գտնվում է `open-sse/services/compression/types.ts`-ում։

### Ինչու է սա կարևոր

Առանց SHARED_BOUNDARIES-ի՝ Caveman-ի ագրեսիվ ռեժիմները կարող էին հեռացնել այնպիսի բովանդակություն, որը նման էր կրկնվող
արձակ տեքստի, բայց իրականում կոդի հատված, ֆայլի ուղի կամ սխալի կանչերի շղթա էր։ SHARED_BOUNDARIES-ը գործում է որպես
լեզվից անկախ պաշտպանիչ շերտ, որը կիրառվում է նախքան ավելորդ տեքստի կանոնների գործարկումը։

### preservePatterns-ի հարմարեցում

Լրացուցիչ ձևանմուշներ կարելի է ավելացնել կատարման պահին՝ սեղմման կարգավորումների միջոցով․

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Հատուկ ձևանմուշները ընդլայնում են 6 լռելյայն ձևանմուշները (և չեն փոխարինում դրանք)։

## Շահագործման նշումներ

- Ներկառուցված անգլերեն կանոնները շարունակում են օգտագործվել որպես պահուստային տարբերակ, երբ լեզվային փաթեթը բացակայում է։
- Անվավեր ներկառուցված JSON փաթեթները չեն անցնում վավերացումը, որպեսզի թողարկման ռեսուրսների որակն աննկատ չվատանա։
