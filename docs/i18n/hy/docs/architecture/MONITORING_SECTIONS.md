## Բարձր մակարդակի նավարկում

Կառավարման վահանակի կողագոտին (Group B-ից հետո) ունի հետևյալ վերին մակարդակի բաժինները՝ նշված հերթականությամբ․

```

Կարգավորումներ
Վերլուծություն
Ծախսեր          ← ՆՈՐ (Group B, պլան 16)
Մոնիթորինգ       ← ՎԵՐԱԿԱԶՄԱԿԵՐՊՎԱԾ (Group B, պլան 16)
...
```

## Ծախսեր բաժին (նոր, մակարդակ 1)

Ուղու նախածանց՝ `/dashboard/costs/`

| Տարր                   | URL                                  | Նկարագրություն                                             |
| ---------------------- | ------------------------------------ | ---------------------------------------------------------- |
| Ընդհանուր պատկեր       | `/dashboard/costs`                   | Ծախսերի համախմբված վահանակ (տեղափոխվել է Վերլուծությունից) |
| Գնագոյացում            | `/dashboard/costs/pricing`           | Յուրաքանչյուր մոդելի գնագոյացման աղյուսակ                  |
| Բյուջե                 | `/dashboard/costs/budget`            | Բյուջեի շեմեր + ծանուցումներ                               |
| Քվոտայի համօգտագործում | `/dashboard/costs/quota-share`       | Quota Share խմբեր + օգտագործում                            |
| Պլանի կարգավորում      | `/dashboard/costs/quota-share/plans` | Յուրաքանչյուր մատակարարի պլանի վերասահմանումներ            |

**Հիմնավորում**․ Գնագոյացումը, Բյուջեն և Քվոտայի համօգտագործումը նախկինում գտնվում էին
`Մոնիթորինգ > Ծախսերի պարամետրեր` բաժնում։ Դրանք վերին մակարդակի առանձին բաժին
տեղափոխելը հնարավորություն է տալիս գտնել դրանք՝ առանց դիտարկելիության գործիքների միջով անցնելու։

## Մոնիթորինգ բաժին (վերակազմակերպված)

Մոնիթորինգ բաժնի **վերևում այժմ Գործունեությունն է**, որին հաջորդում են **3 ենթախմբեր**․

```
Մոնիթորինգ
├── Գործունեություն             ← Ժամանակագրական հոսք (վերին մակարդակի տարր)
├── Մատյանների խումբ
│   ├── Մատյաններ (բոլորը)
│   ├── Proxy մատյաններ
│   └── Console մատյաններ
├── Աուդիտի խումբ
│   ├── Աուդիտի մատյան
│   ├── MCP աուդիտ
│   └── A2A աուդիտ
└── Համակարգի խումբ
    ├── Առողջական վիճակ
    └── Կատարման միջավայր
```

### Ինչ է փոխվել հին կառուցվածքի համեմատ

| Նախկինում                                                                                                                   | Այժմ                                                   |
| --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| Գործունեություն = ներդիր Մատյանների ներսում, որը ցուցադրում էր Աուդիտի մատյանը                                              | Գործունեություն = առանձին հոսք (`/dashboard/activity`) |
| Ծախսերի պարամետրերի խումբը՝ Մոնիթորինգում                                                                                   | Տեղափոխվել է Ծախսեր բաժին                              |
| Հարթ ցուցակ՝ Մատյաններ, Գործունեություն (մատյաններ), Աուդիտ, Առողջական վիճակ, Կատարման միջավայր, Գնագոյացում, Բյուջե, Քվոտա | Կառուցվածքային 3 խումբ + առանձին Ծախսեր բաժին          |

## Գործունեություն և Աուդիտի մատյան

Այժմ դրանք առանձին են․

| Չափանիշ                          | Գործունեություն (`/dashboard/activity`)                                           | Աուդիտի մատյան (`/dashboard/audit`)                       |
| -------------------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------- |
| **Նպատակ**                       | Օգտատիրոջ համար նախատեսված իրադարձությունների հոսք («ինչ է վերջերս տեղի ունեցել») | Համապատասխանության / անվտանգության մատյան                 |
| **Տվյալների աղբյուր**            | `GET /api/compliance/audit-log?level=high`                                        | `GET /api/compliance/audit-log?level=all`                 |
| **Ձևաչափ**                       | Ժամանակագրություն՝ խմբավորված ըստ օրվա, ընթեռնելի բայերով + պատկերակներով         | Խիտ, էջավորված աղյուսակ՝ 50 գրառում/էջ                    |
| **Զտիչներ**                      | Իրադարձության տեսակի կատեգորիա                                                    | Գործողություն, կարևորություն, կատարող, ամսաթվերի միջակայք |
| **Արտահանում**                   | Հասանելի չէ                                                                       | JSON արտահանում                                           |
| **Կատարողի զտիչ**                | Կիրառելի չէ                                                                       | Կարելի է զտել ըստ կատարողի                                |
| **Ցուցադրվող իրադարձություններ** | Միայն բարձր մակարդակի գործողություններ (թույլատրացուցակ)                          | Աուդիտի բոլոր իրադարձությունները                          |

### Բարձր մակարդակի գործողությունների թույլատրացուցակ

Սահմանված է `src/lib/audit/highLevelActions.ts`-ում։ Վերահսկում է, թե որ իրադարձություններն են
հայտնվում Գործունեության հոսքում։ Թույլատրացուցակը ներառում է․

- Մատակարարի ավելացման/հեռացման/փորձարկման իրադարձություններ
- Կոմբինացիայի ստեղծում/թարմացում/ջնջում
- API բանալու կենսացիկլ (ստեղծում, չեղարկում, փոխարինում)
- Բյուջեի շեմի հասնում
- Նույնականացման մուտք/ելք
- Ամպային գործակալի աշխատաշրջանի ստեղծում
- MCP գործիքի գրանցում
- Webhook-ի ստեղծում/ջնջում
- Քվոտայի խմբի/պլանի փոփոխություններ (`quota.*` գործողություններ, Group B)
- Հարթակի իրադարձություններ (թարմացում, տեղակայում)
- Հմտության տեղադրում/հեռացում

Այս ցուցակում չներառված իրադարձությունները հայտնվում են միայն Աուդիտի մատյանում։

### Նոր բարձր մակարդակի գործողության ավելացում

Խմբագրեք `src/lib/audit/highLevelActions.ts`-ը և գործողության տողն ավելացրեք
`HIGH_LEVEL_ACTIONS`-ում։ Դրա համար անհրաժեշտ է PR (ցուցակը կոդ է և չի կարգավորվում DB-ից)։
Համապատասխան պատկերակը կարելի է ավելացնել `src/lib/audit/activityIcons.ts`-ում։

## Վերահղում՝ `/dashboard/logs/activity`

Հին `/dashboard/logs/activity` ուղին մշտապես վերահղվում է (HTTP 308) դեպի
`/dashboard/activity`՝ `src/app/(dashboard)/dashboard/logs/activity/page.tsx`-ում
գտնվող `permanentRedirect()`-ի միջոցով։

Կողագոտու հին `logs-activity` ID-ն պահպանվել է `HIDEABLE_SIDEBAR_ITEM_IDS`-ում
(սակայն հեռացվել է `SIDEBAR_DEFINITIONS`-ից), որպեսզի չխափանվեն հին ID-ին
հղում կատարող օգտատիրոջ նախակարգավորումները։
