## အဆင့်မြင့် လမ်းညွှန်မီနူး

Dashboard ဘေးဘက်မီနူးတွင် (Group B ပြီးနောက်) အောက်ပါ ထိပ်တန်းကဏ္ဍများကို အစဉ်လိုက် ထည့်သွင်းထားသည်-

```
ပင်မ
ဝန်ဆောင်မှုပေးသူများ
ပေါင်းစပ်မှုများ
API ကီးများ
ဆက်တင်များ
ခွဲခြမ်းစိတ်ဖြာမှု
ကုန်ကျစရိတ်များ          ← အသစ် (Group B၊ အစီအစဉ် 16)
စောင့်ကြည့်မှု             ← ပြန်လည်ဖွဲ့စည်းထားသည် (Group B၊ အစီအစဉ် 16)
...
```

## ကုန်ကျစရိတ်များကဏ္ဍ (အသစ်၊ အဆင့် 1)

လမ်းကြောင်းရှေ့ဆက်: `/dashboard/costs/`

| အကြောင်းအရာ               | URL                                  | ဖော်ပြချက်                                                            |
| ------------------------- | ------------------------------------ | --------------------------------------------------------------------- |
| ခြုံငုံသုံးသပ်ချက်        | `/dashboard/costs`                   | စုစည်းထားသော ကုန်ကျစရိတ် dashboard (ခွဲခြမ်းစိတ်ဖြာမှုမှ ရွှေ့ထားသည်) |
| ဈေးနှုန်း                 | `/dashboard/costs/pricing`           | မော်ဒယ်တစ်ခုချင်းအလိုက် ဈေးနှုန်းဇယား                                 |
| ဘတ်ဂျက်                   | `/dashboard/costs/budget`            | ဘတ်ဂျက်သတ်မှတ်ချက်များ + သတိပေးချက်များ                               |
| ခွဲတမ်းမျှဝေမှု           | `/dashboard/costs/quota-share`       | ခွဲတမ်းမျှဝေမှု pool များ + အသုံးပြုမှု                               |
| အစီအစဉ် ပြင်ဆင်သတ်မှတ်မှု | `/dashboard/costs/quota-share/plans` | ဝန်ဆောင်မှုပေးသူတစ်ခုချင်းအလိုက် အစီအစဉ် ထပ်ဆင့်သတ်မှတ်ချက်များ       |

**အကြောင်းရင်း**: ဈေးနှုန်း၊ ဘတ်ဂျက်နှင့် ခွဲတမ်းမျှဝေမှုတို့သည် ယခင်က
`စောင့်ကြည့်မှု > ကုန်ကျစရိတ် ကန့်သတ်ချက်များ` အောက်တွင် ရှိခဲ့သည်။ ၎င်းတို့ကို သီးခြား ထိပ်တန်းကဏ္ဍတစ်ခုသို့
ရွှေ့လိုက်ခြင်းကြောင့် observability ကိရိယာများမှတစ်ဆင့် သွားလာစရာမလိုဘဲ
အလွယ်တကူ ရှာဖွေတွေ့ရှိနိုင်သည်။

## စောင့်ကြည့်မှုကဏ္ဍ (ပြန်လည်ဖွဲ့စည်းထားသည်)

ယခု စောင့်ကြည့်မှုကဏ္ဍတွင် **လုပ်ဆောင်ချက်ကို ထိပ်ဆုံး၌** ထားပြီးနောက် **အုပ်စုခွဲ 3 ခု** ပါရှိသည်-

```
စောင့်ကြည့်မှု
├── လုပ်ဆောင်ချက်             ← အချိန်လိုက် feed (ထိပ်တန်းအကြောင်းအရာ)
├── မှတ်တမ်းများအုပ်စု
│   ├── မှတ်တမ်းများ (အားလုံး)
│   ├── Proxy မှတ်တမ်းများ
│   └── Console မှတ်တမ်းများ
├── စစ်ဆေးမှုအုပ်စု
│   ├── စစ်ဆေးမှုမှတ်တမ်း
│   ├── MCP စစ်ဆေးမှု
│   └── A2A စစ်ဆေးမှု
└── စနစ်အုပ်စု
    ├── အခြေအနေ
    └── Runtime
```

### ဖွဲ့စည်းပုံအဟောင်းမှ ပြောင်းလဲထားသည့်အရာများ

| ယခင်                                                                                                             | ယခု                                                      |
| ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| လုပ်ဆောင်ချက် = စစ်ဆေးမှုမှတ်တမ်းကို ဖော်ပြပေးသည့် မှတ်တမ်းများအတွင်းရှိ tab                                     | လုပ်ဆောင်ချက် = သီးခြား feed (`/dashboard/activity`)     |
| စောင့်ကြည့်မှုအတွင်းရှိ ကုန်ကျစရိတ် ကန့်သတ်ချက်များအုပ်စု                                                        | ကုန်ကျစရိတ်များကဏ္ဍသို့ ရွှေ့ထားသည်                      |
| စာရင်းပြား- မှတ်တမ်းများ၊ လုပ်ဆောင်ချက် (မှတ်တမ်းများ)၊ စစ်ဆေးမှု၊ အခြေအနေ၊ Runtime၊ ဈေးနှုန်း၊ ဘတ်ဂျက်၊ ခွဲတမ်း | ဖွဲ့စည်းထားသော အုပ်စု 3 ခု + သီးခြား ကုန်ကျစရိတ်များကဏ္ဍ |

## လုပ်ဆောင်ချက်နှင့် စစ်ဆေးမှုမှတ်တမ်း

ယခု ၎င်းတို့နှစ်ခုသည် သီးခြားဖြစ်သည်-

| အတိုင်းအတာ                 | လုပ်ဆောင်ချက် (`/dashboard/activity`)                                                 | စစ်ဆေးမှုမှတ်တမ်း (`/dashboard/audit`)                        |
| -------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| **ရည်ရွယ်ချက်**            | အသုံးပြုသူအတွက် ဖြစ်ရပ် feed ("မကြာသေးမီက ဘာဖြစ်ခဲ့သလဲ")                              | စည်းမျဉ်းလိုက်နာမှု / လုံခြုံရေးမှတ်တမ်း                      |
| **ဒေတာရင်းမြစ်**           | `GET /api/compliance/audit-log?level=high`                                            | `GET /api/compliance/audit-log?level=all`                     |
| **ပုံစံ**                  | ရက်အလိုက် အုပ်စုဖွဲ့ထားသော အချိန်လိုက်ပြကွက်၊ လူဖတ်ရှုနိုင်သည့် ကြိယာများ + icon များ | အချက်အလက်ထူထပ်သော စာမျက်နှာခွဲဇယား၊ စာမျက်နှာတစ်ခုလျှင် 50 ခု |
| **စစ်ထုတ်မှုများ**         | ဖြစ်ရပ်အမျိုးအစား အုပ်စု                                                              | လုပ်ဆောင်ချက်၊ ပြင်းထန်မှု၊ လုပ်ဆောင်သူ၊ ရက်စွဲအပိုင်းအခြား   |
| **ထုတ်ယူမှု**              | မရရှိနိုင်                                                                            | JSON ထုတ်ယူမှု                                                |
| **လုပ်ဆောင်သူ စစ်ထုတ်မှု** | အသုံးမဝင်                                                                             | လုပ်ဆောင်သူအလိုက် စစ်ထုတ်နိုင်သည်                             |
| **ပြသထားသော ဖြစ်ရပ်များ**  | အဆင့်မြင့်လုပ်ဆောင်ချက်များသာ (ခွင့်ပြုစာရင်း)                                        | စစ်ဆေးမှုဖြစ်ရပ်အားလုံး                                       |

### အဆင့်မြင့်လုပ်ဆောင်ချက်များ ခွင့်ပြုစာရင်း

`src/lib/audit/highLevelActions.ts` တွင် သတ်မှတ်ထားသည်။ လုပ်ဆောင်ချက် feed တွင် မည်သည့်ဖြစ်ရပ်များ
ပေါ်လာမည်ကို ထိန်းချုပ်သည်။ ခွင့်ပြုစာရင်းတွင် အောက်ပါတို့ ပါဝင်သည်-

- ဝန်ဆောင်မှုပေးသူ ထည့်သွင်းခြင်း/ဖယ်ရှားခြင်း/စမ်းသပ်ခြင်း ဖြစ်ရပ်များ
- ပေါင်းစပ်မှု ဖန်တီးခြင်း/အပ်ဒိတ်လုပ်ခြင်း/ဖျက်ခြင်း
- API ကီး သက်တမ်းစက်ဝန်း (ဖန်တီးခြင်း၊ ပြန်လည်ရုပ်သိမ်းခြင်း၊ လှည့်လည်ပြောင်းလဲခြင်း)
- ဘတ်ဂျက်သတ်မှတ်ချက်သို့ ရောက်ရှိခြင်း
- အထောက်အထားစိစစ်မှု အကောင့်ဝင်ခြင်း/ထွက်ခြင်း
- Cloud agent session ဖန်တီးခြင်း
- MCP ကိရိယာ မှတ်ပုံတင်ခြင်း
- Webhook ဖန်တီးခြင်း/ဖျက်ခြင်း
- ခွဲတမ်း pool/အစီအစဉ် အပြောင်းအလဲများ (`quota.*` လုပ်ဆောင်ချက်များ၊ Group B)
- ပလက်ဖောင်းဖြစ်ရပ်များ (အပ်ဒိတ်၊ ဖြန့်ချိမှု)
- Skill ထည့်သွင်းခြင်း/ဖယ်ရှားခြင်း

ဤစာရင်းတွင် မပါဝင်သော ဖြစ်ရပ်များသည် စစ်ဆေးမှုမှတ်တမ်းတွင်သာ ပေါ်လာသည်။

### အဆင့်မြင့်လုပ်ဆောင်ချက်အသစ်တစ်ခု ထည့်သွင်းခြင်း

`src/lib/audit/highLevelActions.ts` ကို ပြင်ဆင်ပြီး လုပ်ဆောင်ချက် string ကို
`HIGH_LEVEL_ACTIONS` ထဲသို့ ထည့်ပါ။ ၎င်းအတွက် PR တစ်ခု လိုအပ်သည် (စာရင်းသည် code ဖြစ်ပြီး DB မှ ပြင်ဆင်သတ်မှတ်၍ မရပါ)။
သက်ဆိုင်ရာ icon ကို `src/lib/audit/activityIcons.ts` တွင် ထည့်သွင်းနိုင်သည်။

## ပြန်ညွှန်းခြင်း- `/dashboard/logs/activity`

လမ်းကြောင်းအဟောင်း `/dashboard/logs/activity` ကို
`src/app/(dashboard)/dashboard/logs/activity/page.tsx` ရှိ `permanentRedirect()` မှတစ်ဆင့်
`/dashboard/activity` သို့ အမြဲတမ်း ပြန်ညွှန်းထားသည် (HTTP 308)။

အဟောင်း sidebar ID `logs-activity` ကို `HIDEABLE_SIDEBAR_ITEM_IDS` တွင် ဆက်လက်ထိန်းသိမ်းထားပြီး
(သို့သော် `SIDEBAR_DEFINITIONS` မှ ဖယ်ရှားထားသည်) ID အဟောင်းကို

## i18n

Group B မှ ထည့်သွင်းထားသော namespace များ-

| Namespace ကီး           | အကျုံးဝင်သည့်အရာ                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------------- |
| `sidebar.costsSection`  | ကုန်ကျစရိတ်များကဏ္ဍ အညွှန်း                                                                 |
| `sidebar.activity`      | လုပ်ဆောင်ချက် sidebar အကြောင်းအရာ                                                           |
| `sidebar.logsGroup`     | မှတ်တမ်းများအုပ်စုခွဲ အညွှန်း                                                               |
| `sidebar.systemGroup`   | စနစ်အုပ်စုခွဲ အညွှန်း                                                                       |
| `sidebar.costsOverview` | ကုန်ကျစရိတ် ခြုံငုံသုံးသပ်ချက်အကြောင်းအရာ                                                   |
| `activity.*`            | လုပ်ဆောင်ချက်စာမျက်နှာရှိ စာသားအားလုံး (ခေါင်းစဉ်၊ ကြိယာများ၊ စစ်ထုတ်မှုများ၊ အလွတ်အခြေအနေ) |

မူရင်းအဖြစ် သတ်မှတ်ထားသော locale များမှာ `pt-BR` နှင့် `en` ဖြစ်သည်။ အခြား locale 40 ခုစလုံးသည်
`next-intl` fallback လုပ်ငန်းစဉ်မှတစ်ဆင့် အင်္ဂလိပ်ဘာသာသို့ fallback ပြုလုပ်သည် (`src/i18n/config.ts` တွင် ပြင်ဆင်သတ်မှတ်ထားသည်)။
