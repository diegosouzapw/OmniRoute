ခွဲဝေသတ်မှတ်မှုသည် provider quota မဟုတ်ပါ။

Quota pool များသည် မည်သည့် API key များက provider pool တစ်ခုကို အသုံးပြုနိုင်ကြောင်းနှင့် hard၊ soft သို့မဟုတ် burst policy များကို မည်သို့ အသုံးချမည်ဖြစ်ကြောင်း သတ်မှတ်သည်။ Provider quota သည် provider တစ်ခုက အစီရင်ခံသော သို့မဟုတ် အတိအလင်း ပြင်ဆင်သတ်မှတ်ထားသော ရင်းမြစ်တစ်ခုမှ ရရှိသည့် ပြင်ပစွမ်းဆောင်ရည်ပမာဏဖြစ်သည်။ Ghostlight ၏ internal budget များသည် စီမံခန့်ခွဲသူက သတ်မှတ်ထားသော အုပ်ချုပ်မှုဆိုင်ရာ ကန့်သတ်ချက်များဖြစ်သည်။

`ensurePool` လုပ်ဆောင်ချက်သည် idempotent ဖြစ်သည်။ တူညီသော pool ကို မပြောင်းလဲဘဲ ထားမည်၊ ပြောင်းလဲထားသော ခွဲဝေသတ်မှတ်မှုကို အပ်ဒိတ်လုပ်မည်၊ ပျောက်ဆုံးနေသော pool ကို ဖန်တီးမည်ဖြစ်သည်။ ၎င်းကို အလိုအလျောက်လုပ်ဆောင်မှုနှင့် ကန့်သတ်ထားသော API ခေါ်ယူသူများအတွက် ရည်ရွယ်ထားသည်။

ဖတ်ရှုရန်သီးသန့် status endpoint သည် `GET /api/omniroute/status` ဖြစ်သည်။ စစ်ဆေးအတည်ပြုရန် command သည် `npm run omniroute:verify` ဖြစ်ပြီး၊ ၎င်းသည် တိုက်ရိုက် model request ပြုလုပ်ခြင်းမရှိပါ။
