## ခြုံငုံသုံးသပ်ချက်

Playground Studio သည် `/dashboard/playground` ကို ရိုးရှင်းသော Monaco အခြေပြု editor တစ်ခုမှ
လုပ်ဆောင်ချက်စုံလင်သည့် စမ်းသပ်ရေး workspace တစ်ခုအဖြစ် ပြောင်းလဲပေးသည်။ ၎င်းသည် ယခင် `page.tsx` ကို tab လေးခုနှင့် မျှဝေသုံးစွဲသည့် config pane တစ်ခုကို ဖော်ပြပေးသော `PlaygroundStudio`
shell ဖြင့် အစားထိုးထားသည်။

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Chat] [⚖ နှိုင်းယှဉ်] [{} API] [🔧 တည်ဆောက်] 142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {လက်ရှိ tab အကြောင်းအရာ}               │ ─ Config                  │
│                                          │ Endpoint  [chat ∨]        │
│                                          │ Model     [gpt-5.4 ∨]     │
│                                          │ System    [စာသားဧရိယာ]    │
│                                          │ Temp      ▕▕▔▔ 0.7        │
│                                          │ ကြိုတင်သတ်မှတ်ချက်များ [▾ ဖွင့်][သိမ်း]│
│                                          │ [✨ prompt ကို ပိုကောင်းအောင်လုပ်ရန်]│
└──────────────────────────────────────────┴───────────────────────────┘
```

## Tab များ

### Chat Tab

`ChatPlayground.tsx` ကို အပြန်အလှန်စကားပြောမှုများစွာ ပြုလုပ်နိုင်သော streaming workbench အဖြစ် အဆင့်မြှင့်တင်ထားသည်-

- `MarkdownMessage.tsx` မှတစ်ဆင့် markdown အပြည့်အစုံကို ဖော်ပြပေးခြင်း (code block များ၊ ဇယားများ၊ စာရင်းများ၊ လင့်ခ်များ)။
- မျှဝေသုံးစွဲသည့် Config pane မှ system prompt ကို ရယူခြင်း။
- မက်ဆေ့ချ်တစ်ခုချင်းစီအတွက် token/ကုန်ကျစရိတ် (prompt + completion token များ)။
- နောက်ဆုံးတုံ့ပြန်ချက်ကို ပြန်လည်ထုတ်ပေးခြင်း။
- SSE streaming ဖြင့် `POST /v1/chat/completions` သို့ ပေးပို့ခြင်း။

### Compare Tab

Proxy တစ်ခုအတွက် အဓိကကွဲပြားချက်- prompt ၁ ခုကို model **၄ ခုအထိ တစ်ပြိုင်နက်** လုပ်ဆောင်နိုင်သည်။

- Column ၄ ခုအထိ ထည့်နိုင်ပြီး တစ်ခုစီသည် `/v1/chat/completions` မှ သီးခြား streaming ပြုလုပ်သည်။
- Column များထည့်ရန် `+ Model ထည့်ရန်` ခလုတ် (Cmd+K shortcut)။
- `အားလုံးလုပ်ဆောင်ရန် ▶` သည် `Promise.all` နှင့် column တစ်ခုစီအတွက် `AbortController` ကို အသုံးပြု၍ stream အားလုံးကို တစ်ပြိုင်နက် စတင်စေသည်။
- Global **အားလုံးကို ပယ်ဖျက်ရန်** သည် လုပ်ဆောင်နေဆဲ stream အားလုံးကို ရပ်တန့်စေသည်။
- Column တစ်ခုစီရှိ `ProviderMetrics` သည် TTFT၊ TPS၊ token များနှင့် ခန့်မှန်းကုန်ကျစရိတ်ကို အချိန်နှင့်တစ်ပြေးညီ ဖော်ပြပေးသည်။
- Metric များကို **"client-side ခန့်မှန်းချက်"** (D12) ဟု အညွှန်းတပ်ထားသည် — ပထမဆုံး SSE chunk မှစ၍ တိုင်းတာသည်။

### API Tab

အဆင့်မြင့်အသုံးပြုသူများအတွက် မူလ Monaco editor ကို ၁၀၀% ထိန်းသိမ်းထားသည် (D14)-

- Endpoint ၁၀ ခု- chat completions၊ completions၊ embeddings၊ images၊ audio၊ speech၊ transcriptions၊ moderations၊ rerank၊ search။
- Multimodal ဖိုင် upload။
- အချိန်နှင့်တစ်ပြေးညီ output ပါသော SSE streaming။
- `ApiTab.tsx` အဖြစ် ထုပ်ပိုးထားသည် (လိုအပ်မှ load လုပ်ပြီး `ssr: false`)။

### Build Tab

Tool/function calling နှင့် structured output UI-

- `ToolsBuilder.tsx` — tool တစ်ခုစီအတွက် JSON schema editor ဖြင့် `tools[]` ကို ထည့်ခြင်း/ပြင်ဆင်ခြင်း/ဖယ်ရှားခြင်း။
  Parameter များကို `ToolDefinitionSchema` (Zod) မှတစ်ဆင့် အတည်ပြုစစ်ဆေးသည်။
- `StructuredOutputEditor.tsx` — JSON mode ဖွင့်/ပိတ်ခလုတ် + JSON schema editor။
  Response ကို schema နှင့် ကိုက်ညီမှုရှိမရှိ `StructuredOutputSchema` (Zod) မှတစ်ဆင့် အတည်ပြုစစ်ဆေးသည်။
- Request ကို `tools[]` နှင့်/သို့မဟုတ် `response_format` ဖြင့် `/v1/chat/completions` သို့ ပေးပို့သည်။

## Config Pane (မျှဝေသုံးစွဲမှု)

| အကွက်          | Component             | မှတ်ချက်                                                                             |

## Prompt မြှင့်တင်ကိရိယာ

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Modal က "quota ကို အသုံးပြုမည်" ဟု သတိပေးသည်။
2. အတည်ပြုသောအခါ `{ system, prompt, model, tone }` ကို route သို့ ပို့သည်။
3. Route သည် `promptImprover.META_SYSTEM_PROMPT` ဖြင့် `/v1/chat/completions` ကို အတွင်းပိုင်းမှ ခေါ်သည်။
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` ကို ပြန်ပေးသည်။
5. UI သည် Config pane ၏ system prompt နှင့် Chat tab ၏ user prompt ကို patch ပြုလုပ်သည်။

## Stream တိုင်းတာချက်များ

`useStreamMetrics.ts` + `streamMetrics.ts` (pure function):

- `start()` — request စတင်ချိန်ကို မှတ်တမ်းတင်သည်။
- `onFirstChunk()` — TTFT ကို မှတ်တမ်းတင်သည်။
- `onChunk(n)` — completion token အရေအတွက်ကို စုစည်းသည်။
- `finish(usage?)` — နောက်ဆုံးတိုင်းတာချက်များဖြစ်သော `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd` ကို တွက်ချက်သည်။
- ဈေးနှုန်းများကို `src/lib/playground/types.ts` ရှိ static table မှ ရယူသည် ("ခန့်မှန်းခြေ" ဟု label တပ်ထားသည် — D13)။

## Backend Route များ

| Method   | Path                             | Handler                                                                                                            |
| -------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `POST`   | `/api/playground/improve-prompt` | `ImprovePromptRequestSchema` ဖြင့် Zod validation ပြုလုပ်ပြီး meta-prompt ဖြင့် `/v1/chat/completions` ကို ခေါ်သည် |
| `GET`    | `/api/playground/presets`        | `{ presets: PlaygroundPresetListItem[] }` ကို ပြန်ပေးသည်                                                           |
| `POST`   | `/api/playground/presets`        | Preset ဖန်တီးပြီး `PlaygroundPresetCreateSchema` ဖြင့် validation ပြုလုပ်သည်                                       |
| `GET`    | `/api/playground/presets/:id`    | Preset တစ်ခုကို ပြန်ပေးသည်၊ သို့မဟုတ် 404 ပြန်ပေးသည်                                                               |
| `PUT`    | `/api/playground/presets/:id`    | တစ်စိတ်တစ်ပိုင်း update ပြုလုပ်သည်                                                                                 |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                                |

Auth: ရွေးချယ်နိုင်သည် (`REQUIRE_API_KEY`)။ Error များကို `buildErrorBody()` မှတစ်ဆင့် ပေးပို့သည် (Hard Rule #12)။

| လက္ခဏာ                                               | အကြောင်းရင်း                           | ဖြေရှင်းနည်း                                                                                                      |
| ---------------------------------------------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
