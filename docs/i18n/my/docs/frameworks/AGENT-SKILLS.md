> **အမှန်တကယ် ကိုးကားရမည့် ရင်းမြစ်:** `src/lib/agentSkills/` (ကတ်တလောက်၊ ဂျင်နရေတာ၊ ပါဆာများ) + `skills/` လမ်းညွှန် (`SKILL.md` ဖိုင်များ)
> **နောက်ဆုံး အပ်ဒိတ်လုပ်ထားသည့်ရက်:** 2026-08-02 — v3.8.50

Agent Skills များသည် ပြင်ပ agent များ၊ MCP client များနှင့် A2A orchestrator များအား OmniRoute ၏ REST API နှင့် CLI ကို မည်သို့အသုံးပြုရမည်ကို သင်ကြားပေးသည့် ဖွဲ့စည်းပုံကျသော SKILL.md ဖိုင်များဖြစ်သည်။ [Omni Skills](./SKILLS.md) (OmniRoute အတွင်း လုပ်ဆောင်သည့် LLM ကိရိယာ သတ်မှတ်ချက်များ) နှင့်မတူဘဲ Agent Skills သည် _စာရွက်စာတမ်း ကတ်တလောက်_ တစ်ခုဖြစ်ပြီး agent context ထဲသို့ တိုက်ရိုက်ထည့်သွင်းအသုံးပြုနိုင်သည့် တည်ငြိမ်သော markdown ဖြစ်သည်။

## ခြုံငုံသုံးသပ်ချက်

ကတ်တလောက်တွင် **Agent Skills 45 ခု** (REST API 23 ခု + CLI 21 ခု + configuration workflow 1 ခု) ပါဝင်သည်။ Skill တစ်ခုစီတွင် အောက်ပါတို့ပါဝင်သည်-

- **တရားဝင် ID** တစ်ခု (`omni-auth`, `cli-serve` စသည်)
- YAML frontmatter (`name`, `description`) နှင့် အကြောင်းအရာပြည့်စုံသော markdown body ပါဝင်သည့် `skills/{id}/SKILL.md` ရှိ **SKILL.md** ဖိုင်တစ်ခု
- OpenAPI spec နှင့် CLI registry တို့မှ ရယူထားသော **REST endpoint များ** (API skill များ) သို့မဟုတ် **CLI subcommand များ** (CLI skill များ)
- တိုက်ရိုက်ရယူနိုင်ရန် **GitHub raw URL** တစ်ခု- `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API ရှာဖွေခြင်း

| Endpoint                     | နည်းလမ်း | ဖော်ပြချက်                                                                               | စစ်မှန်ကြောင်းအတည်ပြုမှု |
| :--------------------------- | :------- | :--------------------------------------------------------------------------------------- | :----------------------- |
| `/api/agent-skills`          | GET      | ကတ်တလောက်စာရင်း (`?category=api\|cli\|config&area=<area>` ကို ရွေးချယ်ထည့်သွင်းနိုင်သည်) | မလိုအပ်ပါ                |
| `/api/agent-skills/{id}`     | GET      | Skill တစ်ခု၏ metadata ကို ရယူရန်                                                         | မလိုအပ်ပါ                |
| `/api/agent-skills/{id}/raw` | GET      | SKILL.md ကို `text/markdown` အဖြစ် ရယူရန်                                                | မလိုအပ်ပါ                |
| `/api/agent-skills/coverage` | GET      | လွှမ်းခြုံမှုဆိုင်ရာ ကိန်းဂဏန်းများ (SKILL.md ဖိုင် မည်မျှရှိသည်)                        | မလိုအပ်ပါ                |
| `/api/agent-skills/generate` | POST     | Generator ကို အစပျိုးရန် (dryRun/prune/onlyIds)                                          | စီမံခန့်ခွဲမှု           |

ဥပမာ — API skill အားလုံးကို စာရင်းပြုစုရန်:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ဥပမာ — SKILL.md တစ်ခုကို ရယူရန်:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP ရှာဖွေခြင်း

MCP tool သုံးခုကို `read:catalog` scope အောက်တွင် မှတ်ပုံတင်ထားသည်:

| Tool                              | ဖော်ပြချက်                                                                                 |
| :-------------------------------- | :----------------------------------------------------------------------------------------- |
| `omniroute_agent_skills_list`     | Skill များကို စာရင်းပြုစုရန် (`category` / `area` filter များကို ရွေးချယ်အသုံးပြုနိုင်သည်) |
| `omniroute_agent_skills_get`      | `id` ဖြင့် skill တစ်ခု၏ metadata + SKILL.md ကို ရယူရန်                                     |
| `omniroute_agent_skills_coverage` | လွှမ်းခြုံမှုဆိုင်ရာ ကိန်းဂဏန်းများ (API/CLI ရှိသည့်အရေအတွက်/စုစုပေါင်း)                   |

Scope ချိတ်ဆက်ပုံနှင့် စစ်မှန်ကြောင်းအတည်ပြုမှုအတွက် [MCP-SERVER.md](./MCP-SERVER.md) ကို ကြည့်ပါ။

## A2A ရှာဖွေခြင်း

A2A skill `list-capabilities` သည် skill 45 ခုလုံးပါဝင်သော ကတ်တလောက်ကို markdown table artifact အဖြစ် ပြန်ပေးသည်။ ပြင်ပ orchestrator များက အောက်ပါအတိုင်း ခေါ်ယူအသုံးပြုနိုင်သည်:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

Protocol အသေးစိတ်အချက်အလက်များအတွက် [A2A-SERVER.md](./A2A-SERVER.md) ကို ကြည့်ပါ။

### 1. REST မှတစ်ဆင့် ရှာဖွေခြင်း

```bash
# ကတ်တလောက်အပြည့်အစုံကို ရယူရန်
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# context ထည့်သွင်းရန် SKILL.md ကို ရယူရန်
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP မှတစ်ဆင့် ရှာဖွေခြင်း

```typescript
// Claude Desktop / Cursor MCP client တစ်ခုအတွင်းတွင်:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",

// result.skills → တစ်ခုစီတွင် rawUrl ပါဝင်သည့် AgentSkill array
```

### 3. A2A မှတစ်ဆင့် ရှာဖွေခြင်း

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
```

## Generator

Generator သည် စီစဉ်ပြင်ဆင်ထားသော catalog + OpenAPI spec + CLI registry တို့ကို ဖတ်ရှုပြီး entry တစ်ခုစီအတွက် `skills/{id}/SKILL.md` ကို ရေးသားပေးသည်-

```bash
# အစမ်းကြည့်ရန် (dry run၊ ဖိုင်များ မရေးပါ)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# အပြည့်အစုံ ပြန်လည်ထုတ်လုပ်ရန်
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# သတ်မှတ်ထားသော ID များကို ပြန်လည်ထုတ်လုပ်ရန်
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Generator ၏ response သည် `GeneratorReport` တစ်ခုဖြစ်သည်-

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
