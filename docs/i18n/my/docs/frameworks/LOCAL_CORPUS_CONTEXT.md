## ၎င်းသည် ဘာလဲ

Local Corpus သည် operator တစ်ဦးအား အတိအလင်း အတည်ပြုထားသော စာသားဖိုင် directory တစ်ခုကို
OmniRoute ၏ MCP server တွင် အသုံးပြုနိုင်ရန် လုပ်ဆောင်ပေးသည်။ ဖိုင်များသည် မူလ directory ထဲတွင်သာ ရှိနေသည်။ OmniRoute သည်
canonical root path ကိုသာ SQLite ထဲတွင် သိမ်းဆည်းပြီး memory အတွင်း search index တစ်ခုကို ထိန်းသိမ်းထားသည်။ Corpus အကြောင်းအရာကို
repository သို့မဟုတ် database ထဲသို့ ကူးယူခြင်း မပြုပါ။

အညွှန်းကို incremental နည်းဖြင့် refresh လုပ်သည်။ မပြောင်းလဲထားသော ဖိုင်များကို အရွယ်အစားနှင့် ပြင်ဆင်ခဲ့သည့်
အချိန်ပေါ် အခြေခံ၍ ပြန်လည်အသုံးပြုပြီး၊ ပြောင်းလဲထားသော ဖိုင်များကို ပြန်လည်ဖတ်ရှုကာ SHA-256 ဖြင့် hash လုပ်ပြီး ဖျက်ထားသော ဖိုင်များကို ဖယ်ရှားသည်။
Search လုပ်သည့်အခါ စက္ကန့် 30 ထက် ပိုဟောင်းသော အညွှန်းကို refresh လုပ်သည်။ ခေါ်ယူသူများသည် ချက်ချင်း
refresh လုပ်ရန်လည်း တောင်းဆိုနိုင်သည်။

## ရင်းမြစ်ကို ပြင်ဆင်သတ်မှတ်ခြင်း

Settings route သည် အခြား settings API များနှင့် တူညီသော management authentication ကို လိုအပ်သည်။
ပေးပို့သော path သည် ရှိပြီးသားဖြစ်ရမည်ဖြစ်ပြီး absolute directory path ဖြစ်ရမည်။

```bash
# အတည်ပြုထားသော directory တစ်ခုကို ချိတ်ဆက်ရန်
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# ပြင်ဆင်သတ်မှတ်မှုနှင့် အညွှန်းအခြေအနေကို စစ်ဆေးရန်
curl http://localhost:20128/api/settings/local-corpus

# ရင်းမြစ်ဖိုင်များကို မပြောင်းလဲဘဲ ချိတ်ဆက်မှုဖြုတ်ရန်
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP tool များ

Tool သုံးခုစလုံးသည် `read:local-corpus` ကို လိုအပ်သည်။ Tool response များတွင် relative path များနှင့်
root directory ၏ basename ကိုသာ ဖော်ပြပြီး ၎င်း၏ absolute path ကို မည်သည့်အခါမျှ မဖော်ပြပါ။

| Tool                  | ဖော်ပြချက်                                                                                                        |
| :-------------------- | :---------------------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | ပြင်ဆင်သတ်မှတ်မှုအခြေအနေ၊ အညွှန်းအရွယ်အစား၊ ကန့်သတ်ချက်များနှင့် နောက်ဆုံး refresh အချိန်ကို အစီရင်ခံသည်          |
| `local_corpus_search` | အညွှန်းတင်ထားသော စာသားကို ရှာဖွေပြီး လိုင်းအလိုက် အကန့်အသတ်ရှိသည့် စာသားအပိုင်းများကို ပြန်ပေးသည် (ရလဒ် 20 ခုအထိ) |
| `local_corpus_read`   | ခွင့်ပြုထားသော corpus-relative ဖိုင်တစ်ခုမှ အကန့်အသတ်ရှိသည့် လိုင်းအပိုင်းအခြားကို ဖတ်သည်                         |

MCP input နမူနာများ-

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## ဘေးကင်းရေး နယ်နိမိတ်များ

- Allowlist သည် စာသားကို ဦးစားပေးထားသည်- `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` နှင့် `.yml`။
- Symlink များကို ကျော်သွားသည်။ ဖတ်ရှုမည့် path များကို canonicalize လုပ်ပြီး ပြင်ဆင်သတ်မှတ်ထားသော
  root အတွင်း၌သာ ရှိနေရမည်။ absolute path များနှင့် directory traversal ကြိုးပမ်းမှုများကို ငြင်းပယ်သည်။
- အရေးကြီးဒေတာပါဝင်နိုင်သော directory အမည်များနှင့် ထုတ်လုပ်ထားသော directory အမည်များကို ဖယ်ထုတ်ထားသည်- `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` နှင့်
  `secrets`။
- မူလကန့်သတ်ချက်များမှာ ဖိုင် 5,000 ခု၊ ဖိုင်တစ်ခုလျှင် 1 MiB၊ အညွှန်းတင်ထားသော အကြောင်းအရာစုစုပေါင်း 64 MiB၊
  search chunk တစ်ခုလျှင် စာလုံးရေ ခန့်မှန်းခြေ 4,000 နှင့် ဖတ်ရှုမှုတစ်ခုလျှင် လိုင်း 400 ဖြစ်သည်။
- NUL ပါဝင်သော ဖိုင်များကို စာသားမဟုတ်သော ဖိုင်များအဖြစ် သတ်မှတ်ပြီး ကျော်သွားခြင်း သို့မဟုတ် ငြင်းပယ်ခြင်း ပြုသည်။

PDF၊ DOCX၊ image နှင့် archive ကဲ့သို့သော binary document များကို ရည်ရွယ်ချက်ရှိရှိ မပံ့ပိုးထားပါ။
အညွှန်းမတင်မီ ၎င်းတို့ကို ပြင်ဆင်သတ်မှတ်ထားသော directory အတွင်း အတည်ပြုထားသည့် စာသား format တစ်ခုသို့ ပြောင်းပါ။

## လည်ပတ်မှုဆိုင်ရာ မှတ်ချက်များ

- ပြင်ဆင်သတ်မှတ်ထားသော root ကို ပြောင်းလဲခြင်း သို့မဟုတ် ဖျက်ခြင်းသည် မျှဝေအသုံးပြုထားသော memory အတွင်းရှိ အညွှန်းကို ရှင်းလင်းသည်။
- Process ကို restart လုပ်ပါက အညွှန်းကို စွန့်ပစ်မည်။ နောက်တစ်ကြိမ် search လုပ်သည့်အခါ ပြင်ဆင်သတ်မှတ်ထားသော
  ရင်းမြစ်မှ ပြန်လည်တည်ဆောက်မည်။
- `local_corpus_status` သည် scan လုပ်ရန် အတင်းအကျပ် မလုပ်ဆောင်ပါ။ ချက်ချင်း ပြန်လည် scan လုပ်ရန် လိုအပ်သည့်အခါ
  `refresh: true` ဖြင့် `local_corpus_search` ကို အသုံးပြုပါ။
- Scan နှင့် read လုပ်ရာတွင် ဖြစ်ပေါ်သော မအောင်မြင်မှုများကို ရေတွက်ခြင်း သို့မဟုတ် ထိခိုက်စေနိုင်သော အချက်အလက်များ ဖယ်ရှားထားသည့် error များအဖြစ် ပြန်ပေးခြင်း ပြုသည်။ ရင်းမြစ်ဖိုင်များကို
  မည်သည့်အခါမျှ မပြင်ဆင်ပါ။
