## အမျိုးအစားများ

- **အခမဲ့** — API key ဖြင့် အခမဲ့အသုံးပြုနိုင်သည့်အဆင့် (dashboard မှတစ်ဆင့် စီစဉ်သတ်မှတ်သည်)
- **အထောက်အထားစိစစ်မှု မလို** — key သို့မဟုတ် အကောင့်ဝင်ခြင်း လုံးဝမလိုအပ်သည့် အများသုံး endpoint များ
- **OAuth** — OmniRoute က ကိုင်တွယ်ပေးသည့် အကောင့်ဝင်ခြင်းလုပ်ငန်းစဉ်ဖြစ်ပြီး API key မလိုအပ်ပါ
- **ဝဘ် cookie** — cookie အထောက်အထားစိစစ်မှုဖြင့် ဝန်ဆောင်မှုပေးသူ၏ ဝဘ်အက်ပ်ကို ထုပ်ပိုးအသုံးပြုသည်
- **API key** — API key ဖြင့် စီစဉ်သတ်မှတ်သည့် အခပေးဝန်ဆောင်မှုပေးသူ (အခမဲ့ credit များ ရရှိနိုင်သည်)
- **စက်တွင်း** — အသုံးပြုသူ၏ စက်ပေါ်တွင် လည်ပတ်သည် (Ollama, LM Studio, vLLM စသည်)
- **ရှာဖွေမှု** — ဝဘ်ရှာဖွေရေး ဝန်ဆောင်မှုပေးသူများ
- **အသံ** — အသံအတွက်သာဖြစ်သော ဝန်ဆောင်မှုပေးသူများ (TTS/STT)
- **အထက်ရင်းမြစ် proxy** — အခြားဝန်ဆောင်မှုပေးသူများထံ proxy လုပ်ပေးသည့် ဝန်ဆောင်မှုပေးသူများ
- **Cloud agent** — အချိန်ကြာမြင့်စွာ လည်ပတ်သည့် coding agent များ (Codex Cloud, Devin, Jules)
- **စနစ်** — OmniRoute အတွင်းပိုင်း ဝန်ဆောင်မှုပေးသူများ (loopback စသည်)

ထပ်ဆောင်း tag များ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`။

`Tool calling` (ဖော်ပြထားသည့်နေရာများတွင်): `native` — တကယ့် function-calling API; `emulated` — `tools` array ကို `webTools.ts` မှတစ်ဆင့် prompt ပုံစံဖြင့် အတုယူဆောင်ရွက်သည် (regex ဖြင့် ခွဲခြမ်းစိတ်ဖြာသော `<tool>{...}</tool>` block များ); `none` — လက်ရှိတွင် `tools` ကို အသိပေးခြင်းမရှိဘဲ ဖယ်ရှားထားသည်။ #7286 ကို ကြည့်ပါ။

ဝန်ဆောင်မှုပေးသူတစ်ခုစီကို ဖွင့်ရန်၊ စီစဉ်သတ်မှတ်ရန်နှင့် စမ်းသပ်ရန် `/dashboard/providers` ရှိ dashboard ကို အသုံးပြုပါ။
