OmniRoute သည် ပြင်ပပံ့ပိုးသူများ (1proxy, proxifly, iplocate, webshare) ထံမှ စင့်ခ်လုပ်ထားသော အခမဲ့ ပရောက်စီများ၏ ရွေးချယ်စီစဉ်ထားသည့် အစုကို `free_proxies` ဇယားတွင် ထည့်သွင်းပေးထားသည်။
ဒက်ရှ်ဘုတ်တွင် ၎င်းတို့ကို **Settings → Free Proxies** အောက်၌ ဖော်ပြထားသည်။ ဤစာတမ်းတွင် စာရင်း route က ပံ့ပိုးပေးသည့် ဆာဗာဘက်ခြမ်း စစ်ထုတ်ခြင်း၊ အစီအစဉ်တကျ စီခြင်း၊ အရေအတွက်တွက်ချက်ခြင်းနှင့် စင့်ခ်အမှားအစီရင်ခံခြင်းတို့ကို ဖော်ပြထားသည်။

## စာရင်း route — `GET /api/settings/free-proxies`

စစ်ထုတ်ပြီး အစီအစဉ်တကျ စီထားသည့် စာမျက်နှာခွဲ အပိုင်းတစ်ခုနှင့် စုစုပေါင်းအရေအတွက်ကို ပြန်ပေးသည်။ စစ်ထုတ်ခြင်းနှင့် အရေအတွက်တွက်ချက်ခြင်းတို့ကို SQL တွင် လုပ်ဆောင်သောကြောင့် UI သည် row အားလုံးကို memory ထဲသို့ ထည့်သွင်းစရာမလိုဘဲ အမှန်တကယ် စုစုပေါင်း (ဥပမာ `Total: 0`) ကို ပြသနိုင်သည်။

### Query ပါရာမီတာများ

| ပါရာမီတာ          | အမျိုးအစား                         | မူလတန်ဖိုး | အဓိပ္ပာယ်                                                                                                                                          |
| ----------------- | ---------------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`       | host (နှင့် source) ကော်လံပေါ်တွင် စာလုံးအကြီးအသေး ခွဲခြားသည့် `LIKE`။                                                                             |
| `protocol`        | string                             | `""`       | `type` စစ်ထုတ်မှု− `http` / `https` / `socks4` / `socks5`။ အလွတ်ဖြစ်ပါက အားလုံး။                                                                   |
| `country`         | string                             | `""`       | `countryCode` စစ်ထုတ်မှု (ISO-2)။ အလွတ်ဖြစ်ပါက အားလုံး။                                                                                            |
| `minQuality`      | number                             | `0`        | `qualityScore >= minQuality` ဖြစ်သည့် row များသာ။ `0` = အနည်းဆုံးသတ်မှတ်ချက် မရှိ။                                                                 |
| `disabledSources` | string                             | `""`       | ဖယ်ထုတ်ရန် ကော်မာဖြင့်ခွဲထားသည့် source id များ (ဥပမာ `proxifly,webshare`)။                                                                        |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`  | `quality` = score ကြီးစဉ်ငယ်လိုက်၊ `latency` = latency ငယ်စဉ်ကြီးလိုက် (null များကို နောက်ဆုံးထားသည်)၊ `recent` = `lastValidated` ကြီးစဉ်ငယ်လိုက်။ |
| `offset`          | number                             | `0`        | စာမျက်နှာခွဲခြင်း စတင်သည့်နေရာ။                                                                                                                    |
| `limit`           | number                             | `50`       | စာမျက်နှာအရွယ်အစား (ဆာဗာဘက်ခြမ်းတွင် အများဆုံးကန့်သတ်ထားသည်)။                                                                                      |

### တုံ့ပြန်ချက်

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` သည် စာမျက်နှာမခွဲမီ စစ်ထုတ်ထားသော စုစုပေါင်းကို ကိုယ်စားပြုသောကြောင့် UI သည် `Total: N` နှင့် `hasMore` ကို သီးခြားစီ ဖော်ပြနိုင်သည်။ `syncErrors` ကို source id အလိုက် key သတ်မှတ်ထားပြီး နောက်ဆုံးစင့်ခ် မအောင်မြင်ခဲ့သည့် source များအတွက်သာ ဖြည့်သွင်းထားသည် — `Total: 0` ရလဒ်တစ်ခုသည် မည်သည့်အခါမျှ အကြောင်းကြားချက်မရှိဘဲ ဖြစ်ပေါ်မည်မဟုတ်ပါ။

## Pool ထဲသို့ ထည့်ခြင်း — `POST /api/settings/free-proxies/[id]/add-to-pool`

အခမဲ့ ပရောက်စီတစ်ခုကို စီမံခန့်ခွဲထားသည့် `proxy_registry` pool ထဲသို့ မြှင့်တင်ထည့်သွင်းသည်။ Upstream ကို ဦးစွာ စစ်ဆေးအတည်ပြုပြီး အောင်မြင်ပါက pool proxy id အသစ်နှင့် တိုင်းတာထားသော latency ကို ပြန်ပေးသည်။

## စင့်ခ် — `POST /api/settings/free-proxies/sync`

ဖွင့်ထားသည့် source အားလုံး (သို့မဟုတ် `{ "sources": [...] }` ထဲရှိ အစုခွဲ) ကို ပြန်လည်ရယူသည်။ Source တစ်ခုစီကို သီးခြားစင့်ခ်လုပ်သည်။ မအောင်မြင်သည့် source ကို `syncErrors` တွင် မှတ်တမ်းတင်ပြီး အခြား source များက ဆက်လက်ပြီးစီးမည်ဖြစ်သောကြောင့် တစ်စိတ်တစ်ပိုင်း စင့်ခ်လုပ်ခြင်းသည် ယခင်က ရရှိထားသော မှန်ကန်သည့်ဒေတာကို မည်သည့်အခါမျှ ဖျက်ပစ်မည်မဟုတ်ပါ။

## စာရင်းအင်း — `GET /api/settings/free-proxies/stats`

Row payload မပါဘဲ `total / inPool / avgQuality / bySource / lastSyncAt` စုစည်းတန်ဖိုးကို ပြန်ပေးသည် — ဒက်ရှ်ဘုတ် header widget များက အသုံးပြုသည်။
