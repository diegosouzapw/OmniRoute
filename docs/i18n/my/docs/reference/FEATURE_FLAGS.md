## Feature Flag ဆိုသည်မှာ အဘယ်နည်း

Feature flag ဆိုသည်မှာ အမည်သတ်မှတ်ထားသော toggle (boolean သို့မဟုတ် enum) တစ်ခုဖြစ်ပြီး ၎င်း၏တန်ဖိုးကို
runtime တွင် ပြောင်းလဲ၍ database ထဲတွင် အမြဲတမ်းသိမ်းဆည်းထားနိုင်ကာ process ကို ပြန်လည် deploy လုပ်ရန် မလိုအပ်ပါ။ Flag တစ်ခုချင်းစီကို
`key`, `label`, `description`, `category`, `defaultValue`, `type` နှင့် `requiresRestart` အရိပ်အမြွက်တို့ ပါဝင်သော `FeatureFlagDefinition` ဖြင့် ဖော်ပြထားသည်။

### တန်ဖိုးဖြေရှင်းမှု အစီအစဉ်

Flag တစ်ခု၏ **အကျိုးသက်ရောက်နေသောတန်ဖိုး** ကို
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) က အောက်ပါ ဦးစားပေးအစီအစဉ်အတိုင်း ဖြေရှင်းသည် (အမြင့်ဆုံးက အနိုင်ရသည်) -

1. **DB override** — `feature_flags` namespace အောက်ရှိ `key_value` ဇယားတွင် သိမ်းဆည်းထားသော
   တန်ဖိုးတစ်ခု (dashboard သို့မဟုတ် REST API မှတစ်ဆင့် သတ်မှတ်ထားသည်)။
2. **Environment variable** — သတ်မှတ်ထားပြီး အလွတ်မဟုတ်ပါက `process.env[<KEY>]`။
3. **သတ်မှတ်ချက်၏ မူလတန်ဖိုး** — `featureFlagDefinitions.ts` မှ `defaultValue`။

Boolean flag တစ်ခု၏ အကျိုးသက်ရောက်နေသောတန်ဖိုးသည် `"true"`,
`"1"` သို့မဟုတ် `"yes"` ဖြစ်ပါက **ဖွင့်ထားသည်** ဟု သတ်မှတ်သည်
(`isFeatureFlagEnabled()` ကို ကြည့်ပါ)။

> [!NOTE]
> Flag အများစုတွင် [`ENVIRONMENT.md`](./ENVIRONMENT.md) ၌ မှတ်တမ်းတင်ထားသော **အမည်တူ**
> environment variable တစ်ခုလည်း ရှိသည်။ Flag ၏ DB override သည်
> ထို environment variable ထက် ဦးစားပေးသည်။ `requiresRestart: true` ပါသော flag ကို
> ချက်ချင်း အမြဲတမ်းသိမ်းဆည်းသော်လည်း process စတင်ချိန်တွင်သာ ပြန်လည်ဖတ်ရှုသည် —
> ၎င်းကို toggle လုပ်ပါက dashboard တွင် **"Server ကို ပြန်လည်စတင်ပါ"** banner တစ်ခု ပေါ်လာသည်။

(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
သည် အောက်ပါတို့ကို ပံ့ပိုးပေးသည်-

- key သို့မဟုတ် ဖော်ပြချက်ဖြင့် **ရှာဖွေခြင်း** နှင့် အမျိုးအစားအလိုက် **စစ်ထုတ်ခြင်း** (ထို့အပြင် ဖန်တီးထားသော
  **Requires Restart** မြင်ကွင်း)။
- boolean အလံများအတွက် **အဖွင့်အပိတ်ခလုတ်** နှင့် enum အလံများအတွက် **ရွေးချယ်စရာစာရင်း**
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`)။
- အလံတစ်ခုစီအတွက် အကျိုးသက်ရောက်နေသော တန်ဖိုးသည် မည်သည့်နေရာမှ ရရှိလာသည်ကို ပြသသည့်
  **ရင်းမြစ်တံဆိပ်** — `DB`, `ENV` သို့မဟုတ် `DEF`။
- override ကို ဖယ်ရှားရန် **Reset** ခလုတ် (`DB` မှ ရင်းမြစ်ရရှိသော အလံများအတွက်သာ ပြသသည်)
  နှင့် အောက်ခြေရှိ **Reset All Overrides** ခလုတ်။
- `requiresRestart` အလံတစ်ခုကို ပြောင်းလဲသည့်အခါ **Restart Server** နဖူးစည်းစာတန်း။

### REST API

လုပ်ဆောင်ချက်အားလုံးသည် လမ်းကြောင်းတစ်ခုတည်းမှတစ်ဆင့် ဆောင်ရွက်သည်-
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts)။
method တစ်ခုစီအတွက် အထောက်အထားစိစစ်ပြီးသော ဒက်ရှ်ဘုတ် session တစ်ခု လိုအပ်သည် (မရှိပါက `401`)။

#### `GET /api/settings/feature-flags`

အလံတိုင်း၏ အကျိုးသက်ရောက်နေသော တန်ဖိုး၊ ရင်းမြစ်နှင့် အကျဉ်းချုပ်ကို ပြန်ပေးသည်။

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "API Key လိုအပ်သည်",
      "description": "ဝင်ရောက်လာသော တောင်းဆိုမှုအားလုံးအတွက် API key တစ်ခု လိုအပ်သည်",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... အလံ 74 ခုလုံး
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

override တစ်ခုတည်းကို သတ်မှတ်ပါ သို့မဟုတ် ဖယ်ရှားပါ။ Body: `{ key: string; value?: string }`။
`value` ကို ချန်လှပ်ထားပါက override ကို ဖယ်ရှားပေးသည် (env / default ကို ပြန်လည်အသုံးပြုသည်)။

```bash
# DB override တစ်ခု သတ်မှတ်ပါ
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# override ကို ဖယ်ရှားပါ ("value" မပါ)
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

တုံ့ပြန်ချက်သည် `effectiveValue`/`source` အသစ်၊ `previousValue`/
`previousSource` နှင့် `requiresRestart` တို့ကို ပြန်လည်ဖော်ပြသည်။ မသိသော key များနှင့် သတ်မှတ်အပိုင်းအခြားပြင်ပရှိ enum
တန်ဖိုးများကို `400` ဖြင့် ငြင်းပယ်သည်။

#### `DELETE /api/settings/feature-flags`

DB override **အားလုံး** ကို တစ်ပြိုင်နက် ရှင်းလင်းပြီး အလံတိုင်းကို ၎င်း၏ env / default
တန်ဖိုးသို့ ပြန်လည်ထားရှိသည်။ `{ cleared: <count>, message: "..." }` ကို ပြန်ပေးသည်။

> [!NOTE]
> `requiresRestart: true` ပါသော အလံများသည် process ကို ပြန်လည်စတင်ပြီးနောက်မှသာ အကျိုးသက်ရောက်သည်။
> ဒက်ရှ်ဘုတ်၏ ပြန်လည်စတင်ခြင်း လုပ်ငန်းစဉ်သည် `POST /api/restart` ကို ခေါ်ဆိုပြီးနောက် ဆာဗာ ပြန်လည်အလုပ်လုပ်လာသည်အထိ
> `GET /api/health/ping` ကို အကြိမ်ကြိမ် စစ်ဆေးသည်။

## အရေးပေါ် Budget Fallback

`OMNIROUTE_EMERGENCY_FALLBACK` (category `runtime`၊ default `true`) သည်
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts) ရှိ
အရေးပေါ် အခမဲ့ fallback လမ်းကြောင်းကို ထိန်းချုပ်သည်။
ဖွင့်ထားသောအခါ budget ကုန်ဆုံးသွားသည့် request များကို ချက်ချင်း မအောင်မြင်စေဘဲ အခမဲ့ fallback
provider/model တစ်ခုသို့ လမ်းကြောင်းပြောင်းပေးသည်။ ထိုလုပ်ဆောင်ချက်ကို ပိတ်ပြီး budget ကုန်ဆုံးသွားသည့် request များကို
မအောင်မြင်စေရန် dashboard toggle၊ DB override သို့မဟုတ် `OMNIROUTE_EMERGENCY_FALLBACK`
environment variable မှတစ်ဆင့် ၎င်းကို `false` (သို့မဟုတ် `0`) ဟု သတ်မှတ်ပါ။
(PR များ #3741 / #3752 တွင် dashboard toggle အဖြစ် ဖော်ပြထားသည်။)
