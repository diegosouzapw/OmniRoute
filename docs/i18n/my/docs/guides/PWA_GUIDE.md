OmniRoute ကို အပြည့်အဝ ထည့်သွင်းအသုံးပြုနိုင်သော Progressive Web App အဖြစ် ဖြန့်ချိထားပါသည်။ Android (Chrome) သို့မဟုတ် iOS (Safari) မည်သည့် မိုဘိုင်းဘရောက်ဆာမှမဆို dashboard ကို ဝင်ရောက်သည့်အခါ **"ပင်မစခရင်သို့ ထည့်ရန်"** ကို ရွေးချယ်နိုင်ပြီး app store မလိုအပ်ဘဲ native app ကဲ့သို့ အသုံးပြုနိုင်ပါသည်။

## PWA ဆိုသည်မှာ အဘယ်နည်း?

Progressive Web App သည် OmniRoute web dashboard ကို native မိုဘိုင်း app တစ်ခုကဲ့သို့ မြင်ရပြီး အသုံးပြုခံစားနိုင်သည့် ပုံစံသို့ ပြောင်းလဲပေးပါသည်။ ထည့်သွင်းပြီးသည်နှင့် ၎င်းသည်-

- ၎င်း၏ ကိုယ်ပိုင် icon ဖြင့် သင့်ပင်မစခရင်မှ စတင်အသုံးပြုနိုင်သည်
- မျက်နှာပြင်အပြည့်ဖြင့် ဖွင့်ပေးသည် — ဘရောက်ဆာလိပ်စာဘား သို့မဟုတ် tab UI မရှိပါ
- သီးသန့် ချိတ်ဆက်မှုစာမျက်နှာဖြင့် အင်တာနက်မရှိသည့်အချိန်တွင်လည်း အလုပ်လုပ်သည်
- ပိုမိုမြန်ဆန်စွာ ဖွင့်နိုင်ရန် static asset များကို cache ပြုလုပ်သည်
- ဒေါင်လိုက်နှင့် အလျားလိုက် orientation နှစ်မျိုးစလုံးကို ပံ့ပိုးသည်

## ထည့်သွင်းခြင်း

### Android (Chrome)

1. Chrome တွင် OmniRoute dashboard ကို ဖွင့်ပါ- `http://YOUR_IP:20128`
2. Chrome က **"OmniRoute ကို ပင်မစခရင်သို့ ထည့်ရန်"** banner ကို အလိုအလျောက် ပြသမည်၊ သို့မဟုတ်-
   - **⋮** menu (အစက်သုံးစက်) ကို နှိပ်ပါ → **"ပင်မစခရင်သို့ ထည့်ရန်"** သို့မဟုတ် **"App ထည့်သွင်းရန်"**
3. ပေါ်လာသည့် အတည်ပြုချက်ကို အတည်ပြုပါ
4. OmniRoute သည် သင့်ပင်မစခရင်ပေါ်တွင် သီးခြား app တစ်ခုအဖြစ် ပေါ်လာမည်

### iOS (Safari)

1. Safari တွင် OmniRoute dashboard ကို ဖွင့်ပါ- `http://YOUR_IP:20128`
2. **မျှဝေရန်** ခလုတ် (မြားပါသော လေးထောင့်ကွက်) ကို နှိပ်ပါ
3. အောက်သို့ ရွှေ့ပြီး **"ပင်မစခရင်သို့ ထည့်ရန်"** ကို နှိပ်ပါ
4. အမည်ပေးပြီး (ပုံသေအမည်မှာ "OmniRoute" ဖြစ်သည်) **ထည့်ရန်** ကို နှိပ်ပါ
5. OmniRoute သည် app icon နှင့်အတူ သင့်ပင်မစခရင်ပေါ်တွင် ပေါ်လာမည်

### Desktop (Chrome / Edge)

1. OmniRoute dashboard ကို ဖွင့်ပါ
2. လိပ်စာဘားရှိ **ထည့်သွင်းရန် icon** ကို နှိပ်ပါ (သို့မဟုတ် ⋮ → "OmniRoute ကို ထည့်သွင်းရန်...")
3. ပေါ်လာသည့် အတည်ပြုချက်ကို အတည်ပြုပါ
4. OmniRoute သည် သီးခြား window တစ်ခုအဖြစ် ဖွင့်မည် — tab များနှင့် လိပ်စာဘား မရှိပါ

## လုပ်ဆောင်ချက်များ

### မျက်နှာပြင်အပြည့် အသုံးပြုမှု

Manifest ကို `display: "fullscreen"` ဖြင့် သတ်မှတ်ထားသောကြောင့် ထည့်သွင်းထားသည့် app သည် မျက်နှာပြင်တစ်ခုလုံးကို အသုံးပြုသည် — ဘရောက်ဆာ UI မရှိသည့်အပြင် status bar နှင့်လည်း ထပ်မနေပါ။ ထို့ကြောင့် dashboard ကို native app တစ်ခုကဲ့သို့ အမှန်တကယ် ခံစားရစေပါသည်။

### အင်တာနက်မရှိချိန် ပံ့ပိုးမှု

OmniRoute တွင် အသိဉာဏ်ရှိသော caching ကို ပံ့ပိုးပေးသည့် service worker (`sw.js`) ပါဝင်သည်-

| Asset အမျိုးအစား                                               | မဟာဗျူဟာ                                     | လုပ်ဆောင်ပုံ                                                                                                         |
| -------------------------------------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **App Shell**                                                  | Cache ကို ဦးစားပေးခြင်း                      | ထည့်သွင်းချိန်တွင် `/`, `/offline`, manifest နှင့် icon များကို ကြိုတင် cache ပြုလုပ်သည်                             |
| **Static asset များ** (CSS, JS, ပုံများ၊ font များ)            | Cache အရန်ဖြင့် network ကို ဦးစားပေးခြင်း    | Network မှ အသစ်ကို ရယူပြီး အင်တာနက်မရှိပါက cache မှ ပြန်လည်ရယူသည်                                                    |
| **Next.js bundle များ** (`/_next/`)                            | Cache update ဖြင့် network ကို ဦးစားပေးခြင်း | Network မှ ရယူကာ cache ကို update လုပ်ပြီး အင်တာနက်မရှိပါက cache ထားသော version ကို ပေးပို့သည်                       |
| **Navigation request များ**                                    | ကျော်သွားခြင်း (လုံးဝ ကြားဖြတ်မယူပါ)         | HTTP/3→HTTP/2 fallback ကို ဘရောက်ဆာက စီမံသည်၊ အလုပ်မလုပ်တော့သည့် QUIC socket တစ်ခုသည် `Response.error()` မဖြစ်သင့်ပါ |
| **API / dashboard route များ** (`/api/`, `/a2a`, `/dashboard`) | ကျော်သွားခြင်း (လုံးဝ cache မပြုလုပ်ပါ)      | Server သို့ အမြဲတမ်း တိုက်ရိုက်သွားပြီး service worker က လုံးဝ ကြားဖြတ်မယူပါ                                         |

### အင်တာနက်မရှိချိန် စာမျက်နှာ

Network မရရှိနိုင်ချိန်တွင် အသုံးပြုသူက စာမျက်နှာအသစ်တစ်ခုသို့ သွားပါက service worker သည် အောက်ပါလုပ်ဆောင်ချက်များပါဝင်သော သီးသန့် `/offline` စာမျက်နှာကို ပြသပေးသည်-

- ရှင်းလင်းသော **"ချိတ်ဆက်မှု ပြဿနာ"** မက်ဆေ့ချ်ကို ပြသသည်
- အချိန်နှင့်တစ်ပြေးညီ update ဖြစ်သည့် **online/offline အခြေအနေပြ indicator** ကို ပြသသည်
- ချိတ်ဆက်မှု ပြန်လည်ရရှိချိန်တွင် reload လုပ်ရန် **"ချိတ်ဆက်မှုကို ပြန်လည်ကြိုးစားရန်"** ခလုတ်ကို ပံ့ပိုးသည်
- ပြဿနာရှာဖွေစစ်ဆေးရန် **အခြေအနေစာမျက်နှာ** သို့ link ပေးထားသည်

### App Icon များ

OmniRoute သည် platform တစ်ခုချင်းစီအတွက် အကောင်းဆုံးဖြစ်အောင် ပြုလုပ်ထားသော icon များကို ပံ့ပိုးပေးသည်-

| File                   | အရွယ်အစား         | အသုံးပြုသည့်နေရာ                               |
| ---------------------- | ----------------- | ---------------------------------------------- |
| `icon-512.png`         | 512×512           | Android ထည့်သွင်းမှုအတည်ပြုချက်၊ splash screen |
| `apple-touch-icon.png` | 180×180           | iOS ပင်မစခရင် icon                             |
| `icon-192.svg`         | 192×192 (vector)  | Android adaptive icon                          |
| `apple-touch-icon.svg` | 180×180 (vector)  | Apple အရန်အသုံးပြုမှု                          |
| `favicon.svg`          | Vector            | ဘရောက်ဆာ tab များ                              |
| `favicon.ico`          | အရွယ်အစားမျိုးစုံ | ဘရောက်ဆာအဟောင်းများ                            |

### အလိုအလျောက် မှတ်ပုံတင်ခြင်း

Service worker ကို root layout ရှိ `<PwaRegister />` component မှတစ်ဆင့် အလိုအလျောက် မှတ်ပုံတင်ပေးသည်။ အသုံးပြုသူဘက်မှ မည်သည့်လုပ်ဆောင်ချက်မျှ မလိုအပ်ပါ — ဘရောက်ဆာက မှန်ကန်သော manifest နှင့် service worker ကို တွေ့ရှိသည်နှင့် app ကို ထည့်သွင်းနိုင်မည် ဖြစ်သည်။

## နည်းပညာဆိုင်ရာ ဗိသုကာဖွဲ့စည်းပုံ

### ဝဘ်အက်ပ် မန်နီဖက်စ် (`manifest.webmanifest`)

Next.js က `src/app/manifest.ts` မှတစ်ဆင့် ထုတ်ပေးသည်-

```json
{
  "name": "OmniRoute",
  "short_name": "OmniRoute",
  "description": "OmniRoute is an AI gateway for multi-provider LLMs. One endpoint for all your AI providers.",
  "start_url": "/",
  "scope": "/",
  "display": "fullscreen",
  "orientation": "any",
  "background_color": "#0b0f1a",
  "theme_color": "#0b0f1a",
  "icons": [
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    },
    { "src": "/apple-touch-icon.png", "sizes": "180x180", "type": "image/png" }
  ]
}
```

### Service Worker (`public/sw.js`)

Framework dependency များမပါဝင်သော ရိုးရိုး service worker တစ်ခုဖြစ်ပြီး အောက်ပါတို့ပါဝင်သည်-

- **ထည့်သွင်းခြင်းအဆင့်**: အက်ပ် shell (root၊ offline စာမျက်နှာ၊ manifest နှင့် icon များ) ကို ကြိုတင် cache လုပ်သည်
- **အသက်သွင်းခြင်းအဆင့်**: cache ဗားရှင်းအဟောင်းများကို ရှင်းလင်းပြီး client အားလုံးကို ရယူထိန်းချုပ်သည်
- **ရယူခြင်းအဆင့်**: request အမျိုးအစား (navigation၊ static asset၊ API) အပေါ်အခြေခံ၍ အသိဉာဏ်ရှိစွာ လမ်းကြောင်းခွဲပေးသည်
- **Cache ဗားရှင်းသတ်မှတ်ခြင်း**: `omniroute-pwa-v3` — အပ်ဒိတ်လုပ်သည့်အခါ cache အသစ်ကို အတင်းအကျပ်အသုံးပြုစေရန် ဤတန်ဖိုးကို မြှင့်တင်ပါ

### Layout Metadata (`src/app/layout.tsx`)

Root layout သည် PWA စံနှုန်းနှင့်ကိုက်ညီရန် လိုအပ်သော meta tag အားလုံးကို ပံ့ပိုးပေးသည်-

- `/manifest.webmanifest` သို့ညွှန်သော `manifest` လင့်ခ်
- iOS standalone mode အတွက် `apple-web-app-capable: true`
- `apple-web-app-status-bar-style: black-translucent`
- Android Chrome အတွက် `mobile-web-app-capable: yes`
- `theme-color: #0b0f1a`
- မျက်နှာပြင်အစွန်းတစ်ဖက်မှ အခြားအစွန်းတစ်ဖက်အထိ ဖော်ပြရန် `viewport-fit: cover`

### Component: `PwaRegister`

`src/shared/components/PwaRegister.tsx` တွင်တည်ရှိပြီး ဤ client component သည်-

1. Mount လုပ်ချိန်တွင် အလုပ်လုပ်သည် (client-side တွင်သာ)
2. Browser တွင် `serviceWorker` ပံ့ပိုးမှုရှိ၊ မရှိ စစ်ဆေးသည်
3. `/sw.js` ကို အသံတိတ် register လုပ်သည် (အက်ပ်ကို မပိတ်ဆို့စေရန် error များကို လျစ်လျူရှုသည်)
4. မည်သည့်အရာမျှ render မလုပ်ပါ (`return null`) — side effect အတွက်သာ အသုံးပြုသော component ဖြစ်သည်

## Termux (Android) နှင့် အသုံးပြုခြင်း

Android တွင် Termux မှတစ်ဆင့် OmniRoute ကို အသုံးပြုသည့်အခါ PWA သည် ချောမွေ့စွာ အလုပ်လုပ်သည်-

1. Termux တွင် OmniRoute ကို စတင်ပါ- `npx omniroute`
2. ဖုန်းတစ်လုံးတည်းရှိ Chrome ကို ဖွင့်ပါ- `http://localhost:20128`
3. "ပင်မစာမျက်နှာသို့ ထည့်ရန်" မှတစ်ဆင့် PWA ကို ထည့်သွင်းပါ
4. PWA သည် စက်တွင်းရှိ Termux server သို့ ချိတ်ဆက်သည် — အရာအားလုံးကို စက်ပေါ်တွင်ပင် လုပ်ဆောင်သည်

ဤပေါင်းစပ်အသုံးပြုမှုကြောင့် သင့် Android ဖုန်းသည် **server** (Termux) နှင့် **client** (PWA) နှစ်မျိုးလုံးအဖြစ် လုပ်ဆောင်သည် — မိမိဘာသာ အပြည့်အဝလည်ပတ်နိုင်သော AI gateway တစ်ခုဖြစ်သည်။

## အခြားစက်များမှ အသုံးပြုခြင်း

သင်၏ OmniRoute server ကို browser မှတစ်ဆင့် ဝင်ရောက်နိုင်သော မည်သည့်စက်တွင်မဆို PWA ကို ထည့်သွင်းပါ-

- **အခြားဖုန်း/တက်ဘလက်**: `http://PHONE_IP:20128` သို့သွားပြီး PWA ကို ထည့်သွင်းပါ
- **လက်ပ်တော့**: Chrome/Edge ကို ဖွင့်ပြီး desktop PWA အဖြစ် ထည့်သွင်းပါ
- **Browser ပါသော Smart TV**: Dashboard ကို မျက်နှာပြင်အပြည့်ဖြင့် ဝင်ရောက်အသုံးပြုပါ

## စိတ်ကြိုက်ပြင်ဆင်ခြင်း

### Instance အမည်

PWA ခေါင်းစဉ်သည် `Dashboard → Settings` ရှိ **Instance Name** သတ်မှတ်ချက်ကို လိုက်နာသည်။ သင်၏ instance ကို "My AI Gateway" ဟု အမည်ပြောင်းပါက ထည့်သွင်းထားသော PWA တွင် ထိုအမည်ကို ပြသမည်ဖြစ်သည်။

### စိတ်ကြိုက် Favicon

`Dashboard → Settings` မှတစ်ဆင့် စိတ်ကြိုက် favicon တစ်ခုကို upload လုပ်ပါက desktop ပေါ်ရှိ PWA icon တွင် ထိုစိတ်ကြိုက် icon ကို အသုံးပြုမည်ဖြစ်သည်။ မိုဘိုင်းပင်မမျက်နှာပြင် icon များအတွက် ကြိုတင်တည်ဆောက်ထားသော `icon-512.png` နှင့် `apple-touch-icon.png` ဖိုင်များကို အသုံးပြုသည်။

## ကန့်သတ်ချက်များ

- **Push အသိပေးချက်များ မရှိပါ** — Service worker သည် Push API ကို အကောင်အထည်ဖော်ထားခြင်း မရှိပါ။ ထိုအစား အသိပေးချက်များကို Electron အက်ပ်က ကိုင်တွယ်ပေးသည်။
- **နောက်ခံစင့်ခ်လုပ်ခြင်း မရှိပါ** — အော့ဖ်လိုင်းလုပ်ဆောင်ချက်များကို နောက်မှ ပြန်လည်လုပ်ဆောင်ရန် တန်းစီသိမ်းဆည်းထားခြင်း မရှိပါ။ PWA သည် အဓိကအားဖြင့် dashboard ကြည့်ရှုရေးအတွက် ဖြစ်သည်။
- **iOS ကန့်သတ်ချက်များ** — iOS ရှိ Safari သည် PWA အင်္ဂါရပ်အားလုံးကို ပံ့ပိုးမထားပါ (ဥပမာ၊ ထည့်သွင်းရန် အသိပေးချက်များကို ကိုယ်တိုင်လုပ်ဆောင်ရပြီး နောက်ခံ service worker များကို ကန့်သတ်ထားသည်)။
- **Cache အရွယ်အစား** — Service worker သည် static asset များကိုသာ cache လုပ်သည်။ `/api/` route များမှ ကြီးမားသော response payload များကို မည်သည့်အခါမျှ cache မလုပ်ပါ။
- **မိုဘိုင်းရှိ စိတ်ကြိုက် icon များ** — ဆက်တင်များတွင် favicon ကို ပြောင်းလဲခြင်းသည် မိုဘိုင်း၏ ပင်မစာမျက်နှာရှိ icon ကို အပ်ဒိတ်မလုပ်ပေးပါ (၎င်းအတွက် PWA icon များကို ပြန်လည်ဖန်တီးရန် လိုအပ်သည်)။
