ဤလမ်းညွှန်တွင် သင့်စနစ်မှ OmniRoute ကို အကြွင်းအကျန်မရှိ သန့်ရှင်းစွာ ဖယ်ရှားနည်းကို ဖော်ပြထားသည်။

## အမြန် Uninstall ပြုလုပ်ခြင်း (v3.6.2+)

OmniRoute တွင် အပြီးသတ်ရှင်းလင်းဖယ်ရှားရန် အသင့်ပါဝင်သော script နှစ်ခုကို ပံ့ပိုးထားသည်-

### သင့်ဒေတာကို ထိန်းသိမ်းထားခြင်း

```bash
npm run uninstall
```

ဤ command သည် OmniRoute application ကို ဖယ်ရှားပေးသော်လည်း `~/.omniroute/` ရှိ သင့် database၊ configuration များ၊ API key များနှင့် provider setting များကို **ထိန်းသိမ်းထားသည်**။ နောက်ပိုင်းတွင် ပြန်လည် install လုပ်ရန် စီစဉ်ထားပြီး လက်ရှိ setup ကို ဆက်လက်ထိန်းသိမ်းလိုပါက ဤနည်းလမ်းကို အသုံးပြုပါ။

### အပြည့်အစုံ ဖယ်ရှားခြင်း

```bash
npm run uninstall:full
```

ဤ command သည် application ကို ဖယ်ရှားပေးသည့်အပြင် ဒေတာအားလုံးကိုပါ **အပြီးအပိုင် ဖျက်ပစ်သည်**-

- Database (`storage.sqlite`)
- Provider configuration များနှင့် API key များ
- Backup file များ
- Log file များ
- `~/.omniroute/` directory အတွင်းရှိ file အားလုံး

> ⚠️ **သတိပေးချက်:** `npm run uninstall:full` ကို ပြန်ပြင်၍မရပါ။ သင့် provider connection များ၊ combo များ၊ API key များနှင့် အသုံးပြုမှုမှတ်တမ်းအားလုံးကို အပြီးအပိုင် ဖျက်ပစ်မည်ဖြစ်သည်။

## ကိုယ်တိုင် Uninstall ပြုလုပ်ခြင်း

### NPM Global Install

```bash
# Global package ကို ဖယ်ရှားပါ
npm uninstall -g omniroute

# (ရွေးချယ်နိုင်သည်) ဒေတာ directory ကို ဖယ်ရှားပါ
rm -rf ~/.omniroute
```

### pnpm Global Install

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Container ကို ရပ်တန့်ပြီး ဖယ်ရှားပါ
docker stop omniroute
docker rm omniroute

# Volume ကို ဖယ်ရှားပါ (ဒေတာအားလုံးကို ဖျက်ပစ်သည်)
docker volume rm omniroute-data

# (ရွေးချယ်နိုင်သည်) Image ကို ဖယ်ရှားပါ
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Container များကို ရပ်တန့်ပြီး ဖယ်ရှားပါ
docker compose down

# Volume များကိုလည်း ဖယ်ရှားပါ (ဒေတာအားလုံးကို ဖျက်ပစ်သည်)
docker compose down -v
```

### Electron Desktop App

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` ကို ဖွင့်ပါ
- သို့မဟုတ် install directory မှ NSIS uninstaller ကို run ပါ

**macOS:**

- `/Applications` ရှိ `OmniRoute.app` ကို အမှိုက်ပုံးသို့ ဆွဲထည့်ပါ
- ဒေတာကို ဖယ်ရှားရန်- `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage file ကို ဖယ်ရှားပါ
- ဒေတာကို ဖယ်ရှားရန်- `rm -rf ~/.omniroute`

### Source မှ Install ပြုလုပ်ထားခြင်း (git clone)

```bash
# Clone လုပ်ထားသော directory ကို ဖယ်ရှားပါ
rm -rf /path/to/omniroute

# (ရွေးချယ်နိုင်သည်) ဒေတာ directory ကို ဖယ်ရှားပါ
rm -rf ~/.omniroute
```

## ဒေတာ Directory များ

ပုံမှန်အားဖြင့် OmniRoute သည် ဒေတာကို အောက်ပါနေရာများတွင် သိမ်းဆည်းသည်-

| Platform                 | ပုံမှန် Path                         | အစားထိုးသတ်မှတ်မှု        |
| ------------------------ | ------------------------------------ | ------------------------- |
| Linux                    | `~/.omniroute/`                      | `DATA_DIR` env var        |
| macOS                    | `~/.omniroute/`                      | `DATA_DIR` env var        |
| Windows                  | `%APPDATA%/omniroute/`               | `DATA_DIR` env var        |
| Docker                   | `/app/data/` (ချိတ်ဆက်ထားသော volume) | `DATA_DIR` env var        |
| XDG နှင့် ကိုက်ညီသောစနစ် | `$XDG_CONFIG_HOME/omniroute/`        | `XDG_CONFIG_HOME` env var |

### ဒေတာ directory အတွင်းရှိ File များ

| File/Directory       | ဖော်ပြချက်                                                        |
| -------------------- | ----------------------------------------------------------------- |
| `storage.sqlite`     | ပင်မ database (provider များ၊ combo များ၊ setting များ၊ key များ) |
| `storage.sqlite-wal` | SQLite write-ahead log (ယာယီ)                                     |
| `storage.sqlite-shm` | SQLite shared memory (ယာယီ)                                       |
| `call_logs/`         | Request payload archive များ                                      |
| `backups/`           | အလိုအလျောက် database backup များ                                  |
| `log.txt`            | အဟောင်း request log (ရွေးချယ်နိုင်သည်)                            |

## အပြီးအပိုင် ဖယ်ရှားပြီးကြောင်း အတည်ပြုခြင်း

Uninstall လုပ်ပြီးနောက် ကျန်ရှိနေသော ဖိုင်များ မရှိကြောင်း အတည်ပြုပါ:

```bash
# Global npm package ရှိမရှိ စစ်ဆေးပါ
npm list -g omniroute 2>/dev/null

# Data directory ရှိမရှိ စစ်ဆေးပါ
ls -la ~/.omniroute/ 2>/dev/null

# လုပ်ဆောင်နေသော process များ ရှိမရှိ စစ်ဆေးပါ
pgrep -f omniroute
```

Process တစ်ခုခု လုပ်ဆောင်နေဆဲဖြစ်ပါက ၎င်းကို ရပ်တန့်ပါ:

```bash
pkill -f omniroute
```
