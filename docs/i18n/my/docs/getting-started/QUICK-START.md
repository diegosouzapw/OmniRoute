---

## အဆင့် 1: OmniRoute ကို ထည့်သွင်းပါ

သင်နှစ်သက်ရာ နည်းလမ်းကို ရွေးချယ်ပါ:

### ရွေးချယ်မှု A: npm (အကြံပြုထားသည်)

```bash
npm install -g omniroute
```

### ရွေးချယ်မှု B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` သည် **ထုတ်ဝေထားသော** stable SemVer များအနက် အမြင့်ဆုံးဖြစ်သည်။ ၎င်းသည် git `main` ကို လိုက်လံညှိပေးခြင်း **မရှိပါ**။ GitOps အတွက် `diegosouzapw/omniroute:X.Y.Z` ကို သတ်မှတ်အသုံးပြုပါ။ [Image Tags / Release Channels](../guides/DOCKER_GUIDE.md#release-channels) ကို ကြည့်ပါ။

### ရွေးချယ်မှု C: Source မှ

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## အဆင့် 2: OmniRoute ကို စတင်ပါ

```bash
omniroute
```

OmniRoute သည် `http://localhost:20128` တွင် စတင်ပါမည်။ dashboard သည် အလိုအလျောက် ပွင့်လာပါမည်။

---

## အဆင့် 3: အခမဲ့ Provider တစ်ခုကို ချိတ်ဆက်ပါ

အခမဲ့ provider တစ်ခုကို ချိတ်ဆက်ခြင်းဖြင့် OmniRoute ကို **ငွေတစ်ပြားမျှ ပေးစရာမလိုဘဲ** အသုံးပြုနိုင်ပါသည်။

### ရွေးချယ်မှု A: Kiro (အခမဲ့ Claude — Credit Card မလိုပါ)

1. `http://localhost:20128` တွင် dashboard ကို ဖွင့်ပါ
2. **Providers** → **Add Provider** သို့ သွားပါ
3. **Kiro AI** ကို ရွေးချယ်ပါ
4. **Connect** ကို နှိပ်ပါ (API key မလိုပါ!)
5. ပြီးပါပြီ! ယခု Claude model များကို အခမဲ့ အသုံးပြုနိုင်ပါပြီ။

### ရွေးချယ်မှု B: OpenCode Free (Authentication မလိုပါ)

1. `http://localhost:20128` တွင် dashboard ကို ဖွင့်ပါ
2. **Providers** → **Add Provider** သို့ သွားပါ
3. **OpenCode Free** ကို ရွေးချယ်ပါ
4. **Connect** ကို နှိပ်ပါ (API key မလိုပါ!)
5. ပြီးပါပြီ! ယခု model အများအပြားကို အခမဲ့ အသုံးပြုနိုင်ပါပြီ။

### ရွေးချယ်မှု C: Pollinations (Key မလိုပါ)

1. `http://localhost:20128` တွင် dashboard ကို ဖွင့်ပါ
2. **Providers** → **Add Provider** သို့ သွားပါ
3. **Pollinations** ကို ရွေးချယ်ပါ
4. **Connect** ကို နှိပ်ပါ (API key မလိုပါ!)
5. ပြီးပါပြီ! ယခု GPT-5၊ Claude၊ Gemini နှင့် အခြား model များကို အခမဲ့ အသုံးပြုနိုင်ပါပြီ။

---

## အဆင့် 4: အလုပ်လုပ်ကြောင်း စစ်ဆေးပါ

[API Keys](http://localhost:20128/dashboard/api-manager) မှ key အသစ်တစ်ခု ဖန်တီးပါ။ ဤ key ကို နောက်တစ်ကြိမ် ပြန်လည်ပြသမည် မဟုတ်သောကြောင့် သိမ်းဆည်းထားပါ။ ဤ key သည် tool များက OmniRoute ကို အသုံးပြုနိုင်ရန်ဖြစ်ပြီး upstream provider များကို အသုံးပြုရန် မဟုတ်ကြောင်း သတိပြုပါ။

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

သင်ချိတ်ဆက်ထားသော model များကို စာရင်းအဖြစ် မြင်ရပါမည်။

---

## အဆင့် 5: သင့် IDE သို့မဟုတ် CLI ကို OmniRoute သို့ ညွှန်ပေးပါ

သင့် IDE သို့မဟုတ် CLI tool တွင် အောက်ပါအတိုင်း သတ်မှတ်ပါ:

```
Base URL: http://localhost:20128/v1
API Key:  [Dashboard → Endpoints မှ ကူးယူပါ]
Model:    auto
```

ဒါပါပဲ! သင့် IDE သည် ယခုအခါ provider ကို အလိုအလျောက် ရွေးချယ်ပေးသော OmniRoute ကို အသုံးပြုနေပါပြီ။

### IDE ဥပမာ: VSCode/Continue.dev

1. VSCode တွင် [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) extension ကို ထည့်သွင်းပါ။
2. အောက်ပါ စာကြောင်းများကို ထည့်ရန် သင့် `~/.continue/config.yaml` ကို ပြင်ဆင်ပါ:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev chat pane တွင် `OmniRoute - Auto` ကို ရွေးချယ်ပါ၊ ထို့နောက် OmniRoute သို့ request များ ပေးပို့နိုင်ပါမည်။
4. (ချန်လှပ်နိုင်သည်) စာဖတ်သူအတွက် လေ့ကျင့်ခန်း — သင့် IDE ကို အသုံးပြုပြီး အခြား ကြိုတင်တည်ဆောက်ထားသော configuration အားလုံးဖြင့် `config.yaml` ကို update လုပ်ကြည့်ပါ 😊

### CLI ဥပမာ: Codex CLI

1. သင့် operating system တွင် environment variable ကို အမြဲတမ်း အသုံးပြုနိုင်အောင် သတ်မှတ်ပါ။
   macOS/Linux အတွက် (သင့် `~/.bashrc` သို့မဟုတ် `~/.zshrc` ထဲသို့ ထည့်ပါ):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows (Command Prompt) အတွက်:

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. ယခု OmniRoute အတွက် configure လုပ်ထားသော Codex ကို စတင်ကြပါစို့။ အောက်ပါ command ကို run ပါ:

```
omniroute launch-codex --model auto
```

Endpoint နှင့် API key ကို သတ်မှတ်ရန် `codex` နှင့် command line parameter များမှတစ်ဆင့် ကိုယ်တိုင် လုပ်ဆောင်နိုင်သော်လည်း အထက်ပါ command ကို အသုံးပြုပါက OmniRoute က သင့်အတွက် အရာအားလုံးကို တာဝန်ယူ လုပ်ဆောင်ပေးပါသည်။

အလားတူ command တစ်ခုတည်းဖြင့် စတင်ခြင်းသည် generic launcher မှတစ်ဆင့် အခြား CLI များအတွက်လည်း အလုပ်လုပ်ပါသည် — `omniroute run <target>` သည် `claude`၊ `codex`၊ `aider`၊ `goose`၊ `opencode`၊ `qwen` နှင့် `gemini` တို့ကို ပံ့ပိုးပေးပါသည် ([CLI Integrations](../guides/CLI-INTEGRATIONS.md) ကို ကြည့်ပါ)။

3. ယခု CLI သည် request များကို OmniRoute သို့ ပေးပို့နေသင့်ပါသည်။

### သင့် tool သည် OmniRoute သို့ route လုပ်နေကြောင်း အတည်ပြုပါ

ဘယ်ဘက် sidebar ရှိ [Monitoring/Logs](http://localhost:20128/dashboard/logs) ကို နှိပ်ခြင်းဖြင့် request အသေးစိတ်ကို ကြည့်နိုင်ပါသည်။ ထပ်မံနှိပ်ဝင်ကြည့်ပါက အသေးစိတ်အချက်အလက်များကို ပိုမိုမြင်တွေ့နိုင်ပါသည်။ ထို့အပြင် သင်နှစ်သက်သော harness မှ မည်သည့်အချက်အလက်များ ပေးပို့သည်ကိုလည်း မြင်နိုင်ပါသည်။ ၎င်းသည် လေ့လာရေးနှင့် debugging ရှုထောင့်မှ အထောက်အကူပြုပါသည်။

## အမေးများသော မေးခွန်းများ

### "API key လိုအပ်ပါသလား?"

**မလိုပါ!** API key မပါဘဲ အခမဲ့ provider များ (Kiro၊ OpenCode Free၊ Pollinations) ကို အသုံးပြုနိုင်ပါသည်။ ၎င်းတို့ကို dashboard တွင် ချိတ်ဆက်လိုက်ရုံသာ ဖြစ်သည်။

### "`auto` ဆိုတာ ဘာလဲ?"

`auto` သည် request တစ်ခုစီအတွက် အကောင်းဆုံး provider ကို အလိုအလျောက် ရွေးချယ်ရန် OmniRoute ကို ညွှန်ကြားပါသည်။ ၎င်းသည် မြန်နှုန်း၊ ကုန်ကျစရိတ်၊ အရည်အသွေးနှင့် အသုံးပြုနိုင်မှုတို့ကို ထည့်သွင်းစဉ်းစားပါသည်။ အသေးစိတ်အတွက် [Auto-Combo လမ်းညွှန်](./AUTO-COMBO-GUIDE.md) ကို ကြည့်ပါ။

### "ကုန်ကျစရိတ် ဘယ်လောက်ရှိပါသလဲ?"

OmniRoute ကိုယ်တိုင်က **အခမဲ့ဖြစ်ပြီး open-source ဖြစ်ပါသည်**။ သင်အသုံးပြုသော provider များအတွက်သာ ငွေပေးချေရပါမည်။ Provider အများအပြားတွင် free tier များရှိပါသည် — [Free Tiers လမ်းညွှန်](./FREE-TIERS-GUIDE.md) ကို ကြည့်ပါ။

### "Claude Code / Cursor / Copilot တို့နှင့် အသုံးပြုနိုင်ပါသလား?"

**အသုံးပြုနိုင်ပါသည်!** OmniRoute သည် OpenAI format ကို ပံ့ပိုးသော မည်သည့် tool နှင့်မဆို အလုပ်လုပ်ပါသည်။ Base URL ကို `http://localhost:20128/v1` ဟု သတ်မှတ်လိုက်ရုံသာ ဖြစ်သည်။ သီးခြား setup လုပ်ရန် လမ်းညွှန်ချက်များအတွက် [CLI Tools လမ်းညွှန်](../reference/CLI-TOOLS.md) ကို ကြည့်ပါ။

### "Provider တစ်ခု အလုပ်မလုပ်တော့လျှင် ဘာဖြစ်မလဲ?"

OmniRoute သည် အလုပ်မလုပ်သော provider များကို အလိုအလျောက် ကျော်ပြီး နောက်တစ်ခုကို စမ်းသုံးပါသည်။ သင် ဘာမှလုပ်ရန် မလိုပါ။ အသေးစိတ်အတွက် [Auto-Combo လမ်းညွှန်](./AUTO-COMBO-GUIDE.md) ကို ကြည့်ပါ။
