> **အတိုချုပ်**: ဝန်ဆောင်မှုပေးသူဆိုသည်မှာ AI ဝန်ဆောင်မှုတစ်ခုနှင့် ချိတ်ဆက်မှုဖြစ်သည် (ဥပမာ OpenAI, Anthropic, Google)။ OmniRoute ကို အသုံးပြုရန် အနည်းဆုံး ဝန်ဆောင်မှုပေးသူတစ်ခု လိုအပ်သည်။

---

## ဝန်ဆောင်မှုပေးသူဆိုသည်မှာ အဘယ်နည်း?

ဝန်ဆောင်မှုပေးသူကို **ဖုန်းလိုင်းအော်ပရေတာ** တစ်ခုကဲ့သို့ စဉ်းစားနိုင်သည်။ ဖုန်းခေါ်ဆိုရန် ဖုန်းလိုင်းအော်ပရေတာတစ်ခု လိုအပ်သကဲ့သို့ AI မော်ဒယ်များကို အသုံးပြုရန် AI ဝန်ဆောင်မှုပေးသူတစ်ခု လိုအပ်သည်။ OmniRoute သည် **အော်ပရေတာအားလုံး** နှင့် အလုပ်လုပ်နိုင်သော ဖုန်းတစ်လုံးကဲ့သို့ဖြစ်ပြီး ၎င်းတို့အကြား အလိုအလျောက် ပြောင်းလဲအသုံးပြုနိုင်သည်။

### ဝန်ဆောင်မှုပေးသူ အမျိုးအစားများ

| အမျိုးအစား     | အဓိပ္ပာယ်                            | ဥပမာများ                          | ကုန်ကျစရိတ်                     |
| -------------- | ------------------------------------ | --------------------------------- | ------------------------------- |
| **အခမဲ့**      | ငွေပေးချေရန် မလိုအပ်ပါ               | Kiro, OpenCode Free, Pollinations | $0                              |
| **API Key**    | API key တစ်ခု လိုအပ်သည်              | OpenAI, Anthropic, Google         | အသုံးပြုမှုပမာဏအလိုက် ပေးချေရန် |
| **OAuth**      | သင့်အကောင့်ဖြင့် လော့ဂ်အင်ဝင်ရန်     | Claude Code, GitHub Copilot       | စာရင်းသွင်းခ                    |
| **Web Cookie** | သင့်ဘရောက်ဇာ session ကို အသုံးပြုသည် | ChatGPT Web (Codex), Gemini Web   | $0 (သင့်အကောင့်ကို အသုံးပြုသည်) |

### Web Cookie ဝန်ဆောင်မှုပေးသူများ

ယေဘုယျ ပြင်ဆင်သတ်မှတ်မှု လမ်းညွှန်ချက်များ၊ ကန့်သတ်ချက်များ၊ ပြဿနာဖြေရှင်းနည်းများနှင့် ဝန်ဆောင်မှုပေးသူအလိုက် authentication လမ်းညွှန်ချက်များအတွက် **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** ကို ကြည့်ပါ။

## အမြန်စတင်ခြင်း- သင့်ပထမဆုံး ဝန်ဆောင်မှုပေးသူကို ချိတ်ဆက်ပါ

### ပထမဆုံးအသုံးပြုချိန်အတွက် ရွေးချယ်နိုင်သော အခမဲ့ဝန်ဆောင်မှုပေးသူ ပြင်ဆင်သတ်မှတ်မှု

ပထမဆုံးအသုံးပြုချိန် wizard တွင် သီးခြား **အခမဲ့ဝန်ဆောင်မှုပေးသူများကို ပြင်ဆင်သတ်မှတ်ရန်** ကတ်တစ်ခု ပါဝင်သည်။ ၎င်းသည် လက်ရှိ
အသုံးပြုခွင့်ရှိသည့် စာရင်းကို OmniRoute ၏ authentication မလိုအပ်သော ဝန်ဆောင်မှုပေးသူ registry မှ ရယူပြီး အတည်မပြုမီ ဝန်ဆောင်မှုပေးသူ
တစ်ခုချင်းစီကို ပြန်လည်စစ်ဆေးကာ ရွေးချယ်မှုဖြုတ်နိုင်စေသည်။ ပြင်ပအဖွဲ့အစည်း၏ စည်းမျဉ်းများ၊ ကိုယ်ရေးလုံခြုံမှု၊ ရရှိနိုင်မှုနှင့် အသုံးပြုနှုန်းကန့်သတ်ချက်များကို
ဦးစွာ စစ်ဆေးနိုင်ရန် OmniRoute က ဝန်ဆောင်မှုပေးသူ၏ သတိပေးချက်နှင့် ၎င်း၏ဆိုက်သို့ လင့်ခ်တစ်ခုကို ပြသသည်။

ဤလုပ်ဆောင်ချက်သည် ရွေးချယ်နိုင်သည်- wizard ကို အပြီးသတ်ခြင်းသည် အခမဲ့ဝန်ဆောင်မှုပေးသူ ချိတ်ဆက်မှုများကို အသိပေးခြင်းမရှိဘဲ မည်သည့်အခါမျှ မဖန်တီးပါ။
၎င်းသည် မရှိသေးသော ဝန်ဆောင်မှုပေးသူများကိုသာ ဖန်တီးပြီး ရှိနှင့်ပြီးသား စိတ်ကြိုက်ပြင်ဆင်ထားသော ချိတ်ဆက်မှုများကို
မပြောင်းလဲဘဲ ထားကာ ဖန်တီးပြီး၊ ပြင်ဆင်သတ်မှတ်ပြီးသားနှင့် မအောင်မြင်သော ဝန်ဆောင်မှုပေးသူများကို တစ်ခုချင်းစီ အစီရင်ခံသည်။ ရလဒ်အချို့သာ အောင်မြင်ခဲ့ပါက
မအောင်မြင်သည့်အရာများကိုသာ ဘေးကင်းစွာ ပြန်လည်ကြိုးစားနိုင်သည်။

### ရွေးချယ်မှု A- အခမဲ့ဝန်ဆောင်မှုပေးသူ (ခရက်ဒစ်ကတ် မလိုအပ်ပါ)

1. `http://localhost:20128` ရှိ dashboard ကို ဖွင့်ပါ
2. **ဝန်ဆောင်မှုပေးသူများ** → **ဝန်ဆောင်မှုပေးသူ ထည့်ရန်** သို့ သွားပါ
3. အောက်ပါ အခမဲ့ဝန်ဆောင်မှုပေးသူများထဲမှ တစ်ခုကို ရွေးချယ်ပါ-
   - **Kiro AI** — အခမဲ့ Claude မော်ဒယ်များ (authentication မလိုအပ်ပါ)
   - **OpenCode Free** — အခမဲ့ GPT မော်ဒယ်များ (authentication မလိုအပ်ပါ)
   - **Pollinations** — အခမဲ့ GPT-5, Claude, Gemini (key မလိုအပ်ပါ)
   - **LongCat** — အခမဲ့ token 10M (တစ်ကြိမ်သာပေးအပ်ပြီး အကောင့် + KYC လိုအပ်သည်)
   - **Cloudflare AI** — မော်ဒယ် 50 ကျော်၊ တစ်ရက်လျှင် neuron 10K
   - **MLX Gemma 26B** — စက်တွင်း Apple Silicon မော်ဒယ် (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — စက်တွင်း Apple Silicon မော်ဒယ် (~9.1 tok/s, ~13.1GB RAM)
4. **ချိတ်ဆက်ရန်** ကို နှိပ်ပါ
5. ပြီးပါပြီ! ယခု အခမဲ့ AI အသုံးပြုခွင့် ရရှိပါပြီ။

### ရွေးချယ်မှု B- API Key ဝန်ဆောင်မှုပေးသူ (အခပေး)

1. ဝန်ဆောင်မှုပေးသူ၏ ဝဘ်ဆိုက်မှ API key တစ်ခု ရယူပါ-
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` ရှိ dashboard ကို ဖွင့်ပါ
3. **ဝန်ဆောင်မှုပေးသူများ** → **ဝန်ဆောင်မှုပေးသူ ထည့်ရန်** သို့ သွားပါ
4. သင့်ဝန်ဆောင်မှုပေးသူကို ရွေးချယ်ပါ
5. သင့် API key ကို ကူးထည့်ပါ
6. **ချိတ်ဆက်ရန်** ကို နှိပ်ပါ
7. ပြီးပါပြီ! ယခု အဆိုပါဝန်ဆောင်မှုပေးသူ၏ မော်ဒယ်များကို အသုံးပြုနိုင်ပါပြီ။

### ရွေးချယ်မှု C- OAuth ဝန်ဆောင်မှုပေးသူ (စာရင်းသွင်းမှု)

1. `http://localhost:20128` ရှိ dashboard ကို ဖွင့်ပါ
2. **ဝန်ဆောင်မှုပေးသူများ** → **ဝန်ဆောင်မှုပေးသူ ထည့်ရန်** သို့ သွားပါ
3. သင့်ဝန်ဆောင်မှုပေးသူကို ရွေးချယ်ပါ (ဥပမာ Claude Code, GitHub Copilot)
4. **OAuth ဖြင့် ချိတ်ဆက်ရန်** ကို နှိပ်ပါ
5. သင့်အကောင့်ဖြင့် လော့ဂ်အင်ဝင်ပါ
6. ပြီးပါပြီ! ယခု သင့်စာရင်းသွင်းမှုတွင် ပါဝင်သော မော်ဒယ်များကို အသုံးပြုနိုင်ပါပြီ။

### ရွေးချယ်မှု D- စက်တွင်း MLX မော်ဒယ်များ (Apple Silicon)

ပေါင်းစည်းမှတ်ဉာဏ်ပါသော Apple Silicon Mac များအတွက် OmniRoute သည် `mlx-lm.server` မှတစ်ဆင့် လည်ပတ်နေသည့် စက်တွင်း MLX မော်ဒယ်များကို ပုံမှန် OpenAI-compatible စက်တွင်းဝန်ဆောင်မှုပေးသူများအဖြစ် ချိတ်ဆက်နိုင်စေရန် ပံ့ပိုးပေးသည်။

#### ကြိုတင်လိုအပ်ချက်များ

- ပေါင်းစည်းမှတ်ဉာဏ် 24GB+ ပါရှိသော **Apple Silicon Mac** (M1/M2/M3/M4) ကို အကြံပြုသည်
- **uv** package manager: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### အမြန်စတင်ခြင်း

1. **လိုအပ်သော dependency များကို ထည့်သွင်းပါ**-

   ```bash
   # uv ကို မထည့်သွင်းရသေးပါက ထည့်သွင်းပါ
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm ကို ထည့်သွင်းပါ
   uv pip install mlx-lm
   ```

2. **MLX server များကို ကိုယ်တိုင် စတင်ပါ** (terminal သီးခြားစီတွင်)-

   ```bash
   # Terminal 1- Gemma 4 26B A4B IT-QAT (port 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Terminal 2- Qwen 3.8 27B MLX Mixed (port 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute Dashboard တွင် ချိတ်ဆက်ပါ**-
   - **ဝန်ဆောင်မှုပေးသူများ** → **ဝန်ဆောင်မှုပေးသူ ထည့်ရန်** သို့ သွားပါ
   - **MLX Gemma 26B** သို့မဟုတ် **MLX Qwen 3.8 27B** ကို ရွေးချယ်ပါ
   - **ချိတ်ဆက်ရန်** ကို နှိပ်ပါ (API key မလိုအပ်ပါ)

4. **OpenCode ဖြင့် အသုံးပြုပါ**-
   ```bash
   # OmniRoute ကို အသုံးပြုရန် OpenCode ကို ပြင်ဆင်သတ်မှတ်ပါ
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX မော်ဒယ်များကို အသုံးပြုပါ
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### မှတ်ဉာဏ် စီမံခန့်ခွဲမှု

**အရေးကြီးသည်**: ပေါင်းစည်းမှတ်ဉာဏ် 24GB ရှိပါက **ကြီးမားသော MLX မော်ဒယ်တစ်ခုသာ တစ်ချိန်တည်းတွင် လည်ပတ်နိုင်သည်**။

- Gemma 26B: အမြင့်ဆုံးမှတ်ဉာဏ် ~15.9GB
- Qwen 3.8 27B: အမြင့်ဆုံးမှတ်ဉာဏ် ~13.1GB

၎င်းကို ကိုယ်တိုင် စီမံခန့်ခွဲရမည်-

- တစ်ချိန်တည်းတွင် MLX server တစ်ခုသာ လည်ပတ်ပါ၊ သို့မဟုတ်
- နှစ်ခုလုံးကို စက်သီးခြားစီတွင် လည်ပတ်ပါ၊ သို့မဟုတ်
- နောက်တစ်ခုကို မစတင်မီ တစ်ခုကို ရပ်တန့်ပါ

OmniRoute သည် MLX server process များကို အလိုအလျောက် စီမံခန့်ခွဲခြင်းမပြုပါ — သင်ပြင်ဆင်သတ်မှတ်ထားသော OpenAI-compatible endpoint များသို့ request များကို လမ်းကြောင်းပေးရုံသာ လုပ်ဆောင်သည်။

#### Tool Calling ပံ့ပိုးမှု

မော်ဒယ်နှစ်ခုလုံးသည် OpenAI-compatible tool calling ကို ပံ့ပိုးသည်။ အောက်ပါအတိုင်း စမ်းသပ်ပါ-

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

## Provider အများအပြားကို အသုံးပြုခြင်း

OmniRoute သည် **provider အများအပြား** ဖြင့် အကောင်းဆုံး အလုပ်လုပ်ပါသည်။ ၎င်းက သင့်အား အောက်ပါတို့ကို ရရှိစေပါသည်-

- **အလိုအလျောက် အရန်ပြောင်းလဲအသုံးပြုမှု** — provider တစ်ခု အလုပ်မလုပ်ပါက OmniRoute သည် နောက်တစ်ခုကို စမ်းသပ်ပါမည်
- **ကုန်ကျစရိတ် အကောင်းဆုံးဖြစ်အောင် ပြုလုပ်ခြင်း** — request တစ်ခုစီအတွက် ကုန်ကျစရိတ်အသက်သာဆုံး provider ကို OmniRoute က ရွေးချယ်ပါသည်
- **မြန်နှုန်း အကောင်းဆုံးဖြစ်အောင် ပြုလုပ်ခြင်း** — request တစ်ခုစီအတွက် အမြန်ဆုံး provider ကို OmniRoute က ရွေးချယ်ပါသည်
- **အရည်အသွေး အကောင်းဆုံးဖြစ်အောင် ပြုလုပ်ခြင်း** — လုပ်ဆောင်ချက်တစ်ခုစီအတွက် အကောင်းဆုံး provider ကို OmniRoute က ရွေးချယ်ပါသည်

### အကြံပြုထားသော စီစဉ်မှု

အကောင်းဆုံး အသုံးပြုမှုအတွေ့အကြုံအတွက် အနည်းဆုံး **provider 3 ခု** ကို ချိတ်ဆက်ပါ-

1. **အခမဲ့ provider တစ်ခု** (Kiro, OpenCode Free သို့မဟုတ် Pollinations) — အမြဲအသုံးပြုနိုင်သည်
2. **မြန်ဆန်သော provider တစ်ခု** (Groq, Cerebras) — လျင်မြန်သော တုံ့ပြန်မှုများအတွက်
3. **အရည်အသွေးမြင့် provider တစ်ခု** (OpenAI, Anthropic, Google) — ရှုပ်ထွေးသော လုပ်ဆောင်ချက်များအတွက်

ထို့နောက် `model: "auto"` ကို အသုံးပြုပါ။ OmniRoute သည် request တစ်ခုစီအတွက် အကောင်းဆုံးတစ်ခုကို အလိုအလျောက် ရွေးချယ်ပေးပါမည်။

**Kiro AI** ဖြင့် စတင်ပါ — ၎င်းသည် အခမဲ့ဖြစ်ပြီး API key မလိုအပ်သည့်အပြင် Claude model များကို အသုံးပြုခွင့်ပေးသည်။ ထို့နောက် လိုအပ်သလို အခြား provider များကို ထပ်ထည့်ပါ။

### "Provider များစွာကို တစ်ပြိုင်နက် အသုံးပြုနိုင်ပါသလား?"

**အသုံးပြုနိုင်ပါသည်!** ဒါဟာ OmniRoute ရဲ့ အဓိကရည်ရွယ်ချက်ပါပဲ။ Provider များစွာကို ချိတ်ဆက်ပြီး request တစ်ခုချင်းစီအတွက် အကောင်းဆုံးတစ်ခုကို OmniRoute က ရွေးချယ်စေရန် `model: "auto"` ကို အသုံးပြုပါ။

### "Provider တစ်ခု အလုပ်မလုပ်တော့ရင် ဘာဖြစ်မလဲ?"

OmniRoute သည် မအောင်မြင်သော provider များကို အလိုအလျောက် ကျော်သွားပြီး နောက်တစ်ခုကို စမ်းသပ်ပါသည်။ သင် ဘာမှလုပ်ရန် မလိုအပ်ပါ။

### "Provider တစ်ခုကို ဘယ်လို ချိတ်ဆက်ဖြုတ်ရမလဲ?"

Providers သို့သွားပါ → provider ကို နှိပ်ပါ → **Disconnect** ကို နှိပ်ပါ။

### "ရှိပြီးသား API key တွေကို အသုံးပြုနိုင်ပါသလား?"

**အသုံးပြုနိုင်ပါသည်!** OpenAI, Anthropic, Google စသည်တို့အတွက် API key များ သင့်တွင် ရှိပြီးသားဖြစ်ပါက OmniRoute တွင် အသုံးပြုနိုင်သည်။ Provider ကို ချိတ်ဆက်သည့်အခါ ၎င်းတို့ကို ကူးထည့်ရုံသာ ဖြစ်သည်။
