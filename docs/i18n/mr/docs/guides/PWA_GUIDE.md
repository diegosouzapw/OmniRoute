OmniRoute हे पूर्णपणे इंस्टॉल करता येणारे Progressive Web App म्हणून उपलब्ध आहे. तुम्ही कोणत्याही मोबाइल ब्राउझरमधून — Android (Chrome) किंवा iOS (Safari) — डॅशबोर्डमध्ये प्रवेश करता तेव्हा, तुम्ही "होम स्क्रीनवर जोडा" हा पर्याय वापरून कोणत्याही अॅप स्टोअरशिवाय नेटिव्ह अॅपसारखा अनुभव मिळवू शकता.

## PWA म्हणजे काय?

Progressive Web App हे OmniRoute वेब डॅशबोर्डला नेटिव्ह मोबाइल अॅपसारखे दिसणाऱ्या आणि वाटणाऱ्या स्वरूपात रूपांतरित करते. इंस्टॉल केल्यानंतर ते:

- स्वतःच्या आयकॉनसह तुमच्या होम स्क्रीनवरून सुरू होते
- पूर्णस्क्रीनमध्ये उघडते — ब्राउझरची अॅड्रेस बार किंवा टॅब UI नसते
- समर्पित कनेक्टिव्हिटी पृष्ठासह ऑफलाइन कार्य करते
- अधिक जलद लोडिंगसाठी स्टॅटिक अॅसेट्स कॅश करते
- पोर्ट्रेट आणि लँडस्केप अशा दोन्ही अभिमुखतांना समर्थन देते

## इंस्टॉलेशन

### Android (Chrome)

1. Chrome मध्ये OmniRoute डॅशबोर्ड उघडा: `http://YOUR_IP:20128`
2. Chrome आपोआप **"OmniRoute होम स्क्रीनवर जोडा"** बॅनर दाखवेल, किंवा:
   - **⋮** मेनूवर (तीन ठिपके) टॅप करा → **"होम स्क्रीनवर जोडा"** किंवा **"अॅप इंस्टॉल करा"**
3. सूचनेची पुष्टी करा
4. OmniRoute तुमच्या होम स्क्रीनवर स्वतंत्र अॅप म्हणून दिसेल

### iOS (Safari)

1. Safari मध्ये OmniRoute डॅशबोर्ड उघडा: `http://YOUR_IP:20128`
2. **शेअर** बटणावर (बाण असलेला चौकोन) टॅप करा
3. खाली स्क्रोल करा आणि **"होम स्क्रीनवर जोडा"** यावर टॅप करा
4. त्याला नाव द्या (डीफॉल्ट नाव "OmniRoute" आहे) आणि **जोडा** यावर टॅप करा
5. OmniRoute अॅप आयकॉनसह तुमच्या होम स्क्रीनवर दिसेल

### डेस्कटॉप (Chrome / Edge)

1. OmniRoute डॅशबोर्ड उघडा
2. अॅड्रेस बारमधील **इंस्टॉल आयकॉन**वर क्लिक करा (किंवा ⋮ → "OmniRoute इंस्टॉल करा...")
3. सूचनेची पुष्टी करा
4. OmniRoute स्वतंत्र विंडोमध्ये उघडेल — टॅब नाहीत, अॅड्रेस बार नाही

## वैशिष्ट्ये

### पूर्णस्क्रीन अनुभव

मॅनिफेस्ट `display: "fullscreen"` सह कॉन्फिगर केलेले आहे, याचा अर्थ इंस्टॉल केलेले अॅप संपूर्ण स्क्रीन वापरते — ब्राउझर क्रोम नसते आणि स्टेटस बारशी ओव्हरलॅप होत नाही. यामुळे डॅशबोर्ड खऱ्या अर्थाने नेटिव्ह वाटतो.

### ऑफलाइन समर्थन

OmniRoute मध्ये एक service worker (`sw.js`) समाविष्ट आहे, जो बुद्धिमान कॅशिंग प्रदान करतो:

| अॅसेट प्रकार                                             | धोरण                               | वर्तन                                                                                                       |
| -------------------------------------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **अॅप शेल**                                              | प्रथम कॅश                          | `/`, `/offline`, मॅनिफेस्ट आणि आयकॉन्स इंस्टॉलेशनच्या वेळी पूर्व-कॅश केले जातात                             |
| **स्टॅटिक अॅसेट्स** (CSS, JS, प्रतिमा, फॉन्ट्स)          | कॅश फॉलबॅकसह प्रथम नेटवर्क         | नेटवर्कवरून अद्ययावत सामग्री आणते; ऑफलाइन असल्यास कॅश वापरते                                                |
| **Next.js बंडल्स** (`/_next/`)                           | कॅश अपडेटसह प्रथम नेटवर्क          | नेटवर्कवरून सामग्री आणून कॅश अपडेट करते; ऑफलाइन असल्यास कॅश केलेली आवृत्ती देते                             |
| **नेव्हिगेशन विनंत्या**                                  | बायपास (कधीही इंटरसेप्ट होत नाहीत) | HTTP/3→HTTP/2 फॉलबॅक ब्राउझर हाताळतो; निष्क्रिय QUIC सॉकेटचे `Response.error()` मध्ये रूपांतर होता कामा नये |
| **API / डॅशबोर्ड रूट्स** (`/api/`, `/a2a`, `/dashboard`) | बायपास (कधीही कॅश होत नाहीत)       | नेहमी थेट सर्व्हरकडे जातात — service worker कधीही त्यांना इंटरसेप्ट करत नाही                                |

### ऑफलाइन पृष्ठ

नेटवर्क उपलब्ध नसताना आणि वापरकर्ता नवीन पृष्ठावर नेव्हिगेट करतो तेव्हा, service worker एक समर्पित `/offline` पृष्ठ दाखवतो, जे:

- स्पष्ट **"कनेक्टिव्हिटी समस्या"** संदेश दाखवते
- रिअल टाइममध्ये अपडेट होणारा थेट **ऑनलाइन/ऑफलाइन स्थिती निर्देशक** दाखवते
- कनेक्टिव्हिटी परत आल्यावर पृष्ठ रीलोड करण्यासाठी **"कनेक्शनचा पुन्हा प्रयत्न करा"** बटण प्रदान करते
- निदानासाठी **स्थिती पृष्ठा**ची लिंक देते

### अॅप आयकॉन्स

OmniRoute प्रत्येक प्लॅटफॉर्मसाठी ऑप्टिमाइझ केलेले आयकॉन्स प्रदान करते:

| फाइल                   | आकार               | यासाठी वापरले जाते                     |
| ---------------------- | ------------------ | -------------------------------------- |
| `icon-512.png`         | 512×512            | Android इंस्टॉल सूचना, स्प्लॅश स्क्रीन |
| `apple-touch-icon.png` | 180×180            | iOS होम स्क्रीन आयकॉन                  |
| `icon-192.svg`         | 192×192 (व्हेक्टर) | Android अॅडॅप्टिव्ह आयकॉन              |
| `apple-touch-icon.svg` | 180×180 (व्हेक्टर) | Apple फॉलबॅक                           |
| `favicon.svg`          | व्हेक्टर           | ब्राउझर टॅब्स                          |
| `favicon.ico`          | अनेक आकार          | लेगसी ब्राउझर्स                        |

### स्वयंचलित नोंदणी

service worker ची नोंदणी रूट लेआउटमधील `<PwaRegister />` कॉम्पोनंटद्वारे आपोआप केली जाते. वापरकर्त्याला कोणतीही कृती करण्याची आवश्यकता नाही — ब्राउझरला वैध मॅनिफेस्ट आणि service worker आढळताच अॅप इंस्टॉल करण्यायोग्य बनते.

## तांत्रिक आर्किटेक्चर

### वेब अॅप मॅनिफेस्ट (`manifest.webmanifest`)

Next.js द्वारे `src/app/manifest.ts` मधून व्युत्पन्न केले जाते:

```json
{
  "name": "OmniRoute",
  "short_name": "OmniRoute",
  "description": "OmniRoute is an AI gateway for multi-provider LLMs. One endpoint for all your AI providers.",
  "start_url": "/",
  "scope": "/",
  "display": "fullscreen",
  "orientation": "any",
  "background_color": "#0b0f1a",
  "theme_color": "#0b0f1a",
  "icons": [
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    },
    { "src": "/apple-touch-icon.png", "sizes": "180x180", "type": "image/png" }
  ]
}
```

### सर्व्हिस वर्कर (`public/sw.js`)

कोणत्याही फ्रेमवर्क अवलंबित्वांशिवाय असलेला साधा सर्व्हिस वर्कर, ज्यामध्ये:

- **इन्स्टॉल टप्पा**: अॅप शेल (रूट, ऑफलाइन पृष्ठ, मॅनिफेस्ट, आयकॉन) पूर्व-कॅश करतो
- **सक्रियकरण टप्पा**: जुन्या कॅशे आवृत्त्या साफ करतो आणि सर्व क्लायंटवर नियंत्रण मिळवतो
- **फेच टप्पा**: विनंतीच्या प्रकारावर आधारित (नेव्हिगेशन, स्थिर अॅसेट, API) बुद्धिमान राउटिंग करतो
- **कॅशे आवृत्तीकरण**: `omniroute-pwa-v3` — अपडेट करताना पूर्णपणे नवीन कॅशे सक्तीने तयार करण्यासाठी हे मूल्य वाढवा

### लेआउट मेटाडेटा (`src/app/layout.tsx`)

रूट लेआउट PWA अनुपालनासाठी आवश्यक असलेले सर्व मेटा टॅग प्रदान करते:

- `/manifest.webmanifest` साठी `manifest` लिंक
- iOS स्टँडअलोन मोडसाठी `apple-web-app-capable: true`
- `apple-web-app-status-bar-style: black-translucent`
- Android Chrome साठी `mobile-web-app-capable: yes`
- `theme-color: #0b0f1a`
- कडेकडून-कडेपर्यंत रेंडरिंगसाठी `viewport-fit: cover`

### घटक: `PwaRegister`

`src/shared/components/PwaRegister.tsx` येथे असलेला हा क्लायंट घटक:

1. माउंट झाल्यावर चालतो (केवळ क्लायंट-साइड)
2. ब्राउझरमध्ये `serviceWorker` समर्थन आहे का ते तपासतो
3. `/sw.js` ची शांतपणे नोंदणी करतो (अॅप ब्लॉक होऊ नये म्हणून त्रुटी दुर्लक्षित केल्या जातात)
4. काहीही रेंडर करत नाही (`return null`) — हा केवळ साइड-इफेक्टसाठी असलेला घटक आहे

## Termux (Android) सह वापर

Android वर Termux द्वारे OmniRoute चालवताना, PWA अखंडपणे कार्य करते:

1. Termux मध्ये OmniRoute सुरू करा: `npx omniroute`
2. त्याच फोनवर Chrome उघडा: `http://localhost:20128`
3. "होम स्क्रीनवर जोडा" वापरून PWA इन्स्टॉल करा
4. PWA स्थानिक Termux सर्व्हरशी कनेक्ट होते — सर्व काही डिव्हाइसवरच चालते

या संयोजनामुळे तुमचा Android फोन **सर्व्हर** (Termux) आणि **क्लायंट** (PWA) अशा दोन्ही भूमिका पार पाडतो — एक पूर्णपणे स्वयंपूर्ण AI गेटवे.

## इतर डिव्हाइसवरून वापर

तुमच्या OmniRoute सर्व्हरचा ब्राउझरद्वारे अॅक्सेस असलेल्या कोणत्याही डिव्हाइसवर PWA इन्स्टॉल करा:

- **दुसरा फोन/टॅबलेट**: `http://PHONE_IP:20128` वर जा आणि PWA इन्स्टॉल करा
- **लॅपटॉप**: Chrome/Edge उघडा आणि ते डेस्कटॉप PWA म्हणून इन्स्टॉल करा
- **ब्राउझर असलेला स्मार्ट टीव्ही**: डॅशबोर्ड पूर्णस्क्रीनमध्ये वापरा

## सानुकूलन

### इन्स्टन्सचे नाव

PWA चे शीर्षक `Dashboard → Settings` मधील **Instance Name** सेटिंगनुसार असते. तुम्ही तुमच्या इन्स्टन्सचे नाव "My AI Gateway" असे बदलल्यास, इन्स्टॉल केलेले PWA तेच नाव दर्शवेल.

### सानुकूल फेव्हिकॉन

तुम्ही `Dashboard → Settings` द्वारे सानुकूल फेव्हिकॉन अपलोड केल्यास, डेस्कटॉपवरील PWA आयकॉनमध्ये तो सानुकूल आयकॉन दिसेल. मोबाइल होम स्क्रीनवरील आयकॉनसाठी पूर्वनिर्मित `icon-512.png` आणि `apple-touch-icon.png` फाइल्स वापरल्या जातात.

## मर्यादा

- **पुश सूचना नाहीत** — सर्व्हिस वर्कर Push API अंमलात आणत नाही. त्याऐवजी सूचना Electron अॅपद्वारे हाताळल्या जातात.
- **पार्श्वभूमी समक्रमण नाही** — ऑफलाइन क्रिया नंतर पुन्हा अंमलात आणण्यासाठी रांगेत ठेवल्या जात नाहीत. PWA मुख्यतः डॅशबोर्ड पाहण्यासाठी आहे.
- **iOS वरील निर्बंध** — iOS वरील Safari सर्व PWA वैशिष्ट्यांना समर्थन देत नाही (उदा., इंस्टॉलेशन प्रॉम्प्ट मॅन्युअल असतात आणि पार्श्वभूमीतील सर्व्हिस वर्कर्स मर्यादित असतात).
- **कॅश आकार** — सर्व्हिस वर्कर केवळ स्थिर अॅसेट्स कॅश करतो. `/api/` मार्गांवरील मोठे प्रतिसाद पेलोड्स कधीही कॅश केले जात नाहीत.
- **मोबाइलवरील सानुकूल आयकॉन्स** — सेटिंग्जमध्ये फेविकॉन बदलल्याने मोबाइलवरील होम स्क्रीन आयकॉन अपडेट होत नाही (यासाठी PWA आयकॉन्स पुन्हा निर्माण करावे लागतात).
