OmniRoute समर्थित 352 प्रदात्यांना 3 आर्थिक स्तरांमध्ये आयोजित करते. प्रत्येक
विनंती यशस्वी प्रतिसाद मिळेपर्यंत या स्तरांमधून क्रमाने जाते — त्यामुळे कोणताही
फॉलबॅक कोड न लिहिता तुम्हाला सर्वांत स्वस्त व्यवहार्य प्रतिसाद मिळतो.

## स्तर 1 — सदस्यता

**ज्या प्रदात्यांसाठी तुम्ही आधीच पैसे देता.** कोटा कालबाह्य होण्यापूर्वी
OmniRoute त्याचा प्रत्येक अंश वापरते.

| प्रदाता                        | स्तर 1 मध्ये असण्याचे कारण                         |
| ------------------------------ | -------------------------------------------------- |
| Claude Code OAuth              | Anthropic Pro/Team — निश्चित दर, अनेकदा न वापरलेला |
| OpenAI Codex (ChatGPT सदस्यता) | Plus/Team मध्ये Codex कोटा समाविष्ट आहे            |
| GitHub Copilot                 | प्रति-सीट — कोटा दर महिन्याला रीसेट होतो           |
| Cursor IDE                     | Pro प्लॅनचा कोटा                                   |
| Antigravity / Devin Desktop    | अंगभूत कोटे                                        |

**धोरण**: मॉडेलच्या क्षमतांना अनुरूप असलेल्या प्रत्येक विनंतीसाठी प्रथम येथे रूट करा.
कोटा ट्रॅकर जवळ येणाऱ्या रीसेटचे निरीक्षण करतो आणि `reset-aware`
कॉम्बो धोरण त्यानुसार प्राधान्य देते. प्रथम स्तर 1 कडे रूट करण्यासाठी आणि कोटा
संपत असतानाच सशुल्क स्तरांकडे जाण्यासाठी `auto/thrifty` id वापरा — किंवा
प्लॅनमध्ये समाविष्ट क्षमतेवरच राहण्यासाठी आणि ती उपलब्ध नसल्यास विनंती अयशस्वी
करण्यासाठी `auto/subscription` वापरा. [सदस्यता-प्रथम रूटिंग](../routing/SUBSCRIPTION_LADDER.md)
पहा.

## स्तर 2 — स्वस्त

**1M टोकनमागे $1 पेक्षा कमी किंमत असलेले प्रति-टोकन शुल्क आकारणारे प्रदाते.**
मोठ्या प्रमाणातील कामासाठी किंवा स्तर 1 चे कोटे मर्यादेपर्यंत पोहोचल्यानंतर
वापरण्यासाठी राखीव.

| प्रदाता                     | किंमत (इनपुट/आउटपुट)  | बलस्थाने               |
| --------------------------- | --------------------- | ---------------------- |
| DeepSeek V4 Pro             | 1M मागे $0.27 / $1.10 | कोड, तर्कशक्ती         |
| GLM-4.5                     | 1M मागे $0.60 / $2.20 | दीर्घ कॉन्टेक्स्ट      |
| MiniMax M1                  | 1M मागे $0.20 / $1.10 | वेग                    |
| Qwen Coder                  | 1M मागे $0.30 / $1.20 | कोड                    |
| OpenRouter (किंमत-अनुकूलित) | बदलते                 | 100+ मॉडेल्स, डायनॅमिक |

**धोरण**: कॉम्बो `cost-optimized` कार्याच्या क्षमता फिल्टरची (व्हिजन, JSON मोड,
टूल्स, कमाल-कॉन्टेक्स्ट) पूर्तता करणारे सर्वांत कमी $/टोकन असलेले मॉडेल निवडते.

## स्तर 3 — मोफत

**शून्य-खर्चाचे प्रदाते** — मोफत स्तर, क्रेडिट कार्यक्रम, OAuth दैनिक कोटे.

| प्रदाता          | मोफत कोटा / क्रेडिट्स              |
| ---------------- | ---------------------------------- |
| Kiro AI          | मोफत Claude स्तर (उदार वाजवी-वापर) |
| OpenCode Free    | प्रमाणीकरण नाही, उदार दर मर्यादा   |
| Qoder            | मोफत OAuth                         |
| Google Vertex AI | नवीन खात्यासाठी $300 क्रेडिट्स     |
| Amazon Q         | AWS वापरकर्त्यांसाठी मोफत स्तर     |
| Pollinations     | खुला सार्वजनिक API                 |
| Cloudflare AI    | Workers AI मोफत स्तर               |

**धोरण**: स्तर 1+2 अयशस्वी झाल्यास किंवा `useFreeOnly=true` सेट केलेले असल्यास,
बजेट मर्यादेसह कॉम्बो `auto` येथे रूट करते. मोफत प्रदात्यांच्या दर मर्यादा अनेकदा
कमी असतात — सर्किट ब्रेकर बॅकऑफनंतर त्यांना पुन्हा उपलब्ध करते.

## स्तर कॉन्फिगर करणे

डॅशबोर्ड → **स्तर** → तुमचे प्रदाते नियुक्त करा. डीफॉल्ट्स (`tierDefaults.json` मधील)
व्यवहार्य आहेत; विशिष्ट सदस्यतांना प्राधान्य द्यायचे असल्यास किंवा काही प्रदाते
वगळायचे असल्यास ते संपादित करा.

Auto-Combo चे 16-घटक स्कोअरिंग स्तराचाही विचार करते.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) पहा.

## टेलिमेट्री

डॅशबोर्ड → **वापर** प्रत्येक स्तरावर दररोज खर्च झालेले टोकन दाखवते. याचा वापर
पुढील गोष्टींसाठी करा:

- स्तर 1 पूर्णपणे वापरला जात असल्याची खात्री करा (अन्यथा तुम्ही सदस्यतेचे मूल्य वाया घालवत आहात)
- स्तर 2 मधील कोणती मॉडेल्स सर्वाधिक निवडली जातात ते ओळखा (त्यांची संख्या 1-2 पर्यंत मर्यादित करा)
- चाचणी/अन्वेषण वर्कलोडवर स्तर 3 पैसे वाचवत असल्याची पडताळणी करा

## सामान्य पॅटर्न्स

### पूर्णपणे मोफत वर्कलोड

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

स्तर 3 कडे ठामपणे वळवते; स्तर 3 अनुपलब्ध असेल तरच स्तर 2 वापरते.

### स्वस्त फॉलबॅकसह सदस्यता-प्रथम

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

स्तर 1 → स्तर 2 → स्तर 3 शी जुळणारी स्पष्ट क्रमबद्ध सूची.
