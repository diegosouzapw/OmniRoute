> **डॅशबोर्ड:** Settings → **AI** → Thinking Budget  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **स्रोत:** `open-sse/services/thinkingBudget.ts`

Thinking Budget हे प्रदात्यांकडे पाठवताना OmniRoute ने **क्लायंटचे thinking/reasoning पॅरामीटर्स पुन्हा लिहावेत की नाही** हे नियंत्रित करते. हे compression, routing किंवा prompt cache चालू अथवा बंद करत **नाही**.

## मोड

| मोड                         | OmniRoute काय करते                                                                                                  | कधी वापरावे                                                                                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (डीफॉल्ट) | क्लायंट फील्डमध्ये बदल करत नाही (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config`, इ.). | **Codex / Desktop / effort + reasoning summaries नियंत्रित करणारा कोणताही क्लायंट.** क्लायंटने `reasoning.summary` ची विनंती केल्यावर thinking पॅनेल दृश्यमान होण्यासाठी आवश्यक. |
| **`auto`**                  | upstream कडे पाठवण्यापूर्वी विनंतीच्या body मधून thinking/reasoning संबंधित **सर्व फील्ड काढून टाकते**.             | केवळ जेव्हा तुम्हाला **प्रदात्याने** स्वतः डीफॉल्ट ठरवावेत असे जाणीवपूर्वक वाटते आणि क्लायंट-नियंत्रित thinking ची आवश्यकता नसते. याचा अर्थ “thinking आपोआप दाखवा” असा **नाही**. |
| **`custom`**                | प्रत्येक विनंतीमध्ये निश्चित thinking token budget वापरते.                                                          | सर्व ट्रॅफिकमधील thinking tokens वर कठोर मर्यादा घालण्यासाठी.                                                                                                                    |
| **`adaptive`**              | संदेशांची संख्या, tools आणि prompt ची लांबी वापरून मूलभूत effort पासून budget चे प्रमाण ठरवते.                      | क्लायंटचा हेतू पूर्णपणे काढून न टाकता tokens चे लवचिक नियंत्रण करण्यासाठी.                                                                                                       |

### `auto` काय काढून टाकते

मोड `auto` असताना, `stripThinkingConfig()` खालील फील्ड्ससह इतर फील्ड्स हटवते:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking` आणि उपलब्ध असल्यास `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

एखाद्या क्लायंटने (उदा. Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` पाठवले असल्यास, **auto तो object वगळते**. upstream कडून तरीही काही reasoning tokens चे बिल आकारले जाऊ शकते, परंतु बहुतेकदा **रिकामे किंवा केवळ encrypted असलेले** reasoning items परत येतात — त्यामुळे UI मध्ये उपयुक्त thinking stream दिसत नाही.

## हे काय **नाही**

| वैशिष्ट्य                                  | संबंध                                                                                                                                     |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Compression** (Caveman, RTK, stacked, …) | स्वतंत्र pipeline. प्रत्येक thinking-budget मोडमध्ये कार्य करते.                                                                          |
| **Prompt / semantic cache**                | स्वतंत्र. thinking-budget मोडचा परिणाम होत नाही.                                                                                          |
| **Combo routing / fallbacks**              | स्वतंत्र. कोणताही परिणाम होत नाही.                                                                                                        |
| **API-key token limits / cost budgets**    | स्वतंत्र. कोणताही परिणाम होत नाही.                                                                                                        |
| **Reasoning replay cache**                 | कठोर नियम असलेल्या प्रदात्यांसाठी multi-turn re-inject (DeepSeek, Kimi, Qwen-thinking, …). हे Desktop मधील “thinking दाखवा” यासारखे नाही. |
| **`encrypted_content` चे decryption**      | **अशक्य.** OpenAI/Codex चे खाजगी reasoning blobs अपारदर्शक असतात. OmniRoute त्यांचे कधीही decryption करत नाही (#7095 / #7176 / #7304).    |

## दृश्यमान विचारप्रक्रिया (Codex / Responses क्लायंट)

क्लायंटने विचारप्रक्रियेचा मजकूर दाखवण्यासाठी तुम्हाला पुढील **सर्व** गोष्टी आवश्यक आहेत:

1. Thinking Budget मोड = **`passthrough`** (किंवा तुम्ही वापरत असलेल्या मार्गासाठी सारांश विनंत्या पुरेशा प्रमाणात अबाधित ठेवणारा custom/adaptive मोड).
2. क्लायंट सारांशाची विनंती करतो, उदा. Codex `model_reasoning_summary = "detailed"` / `auto` (`none` नाही).
3. अपस्ट्रीम प्रत्यक्षात `response.reasoning_summary_text.*` स्ट्रीम करते (किंवा आयटमवर रिक्त नसलेले `reasoning.summary` असते).

जर तुम्हाला फक्त “एनक्रिप्ट केलेली खाजगी विचारप्रक्रिया” मिळत असेल, तर यापैकी एक कारण असू शकते:

- मोड **`auto`** होता (क्लायंटची विनंती काढून टाकली गेली), किंवा
- अपस्ट्रीमने सारांश मजकुराशिवाय `encrypted_content` परत केले (प्रदात्याची मर्यादा; OmniRoute केवळ प्लेसहोल्डर दाखवू शकते, साधा मजकूर नाही).

## API उदाहरणे

```bash
# वाचा
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Codex / Desktop मध्ये विचारप्रक्रिया दृश्यमान ठेवण्यासाठी शिफारस केलेले
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

स्कीमा (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; पर्यायी `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### सातत्यपूर्ण संचयन / रीस्टार्ट

मूल्य `thinkingBudget` सेटिंग्ज की अंतर्गत साठवले जाते आणि प्रक्रिया सुरू होताना (`hydrateThinkingBudgetConfig`) लोड केले जाते. DB किंवा काही non-API मार्गांद्वारे बदल केल्यानंतर, इन-मेमरी सिंगलटन डिस्कशी जुळण्यासाठी **OmniRoute प्रक्रिया रीस्टार्ट करा**.

## ऑपरेटर तपासणीसूची

- [ ] Codex / Desktop वापरकर्ते: मोड = **passthrough**
- [ ] तुम्हाला विचारप्रक्रिया काढून न टाकता **संदेशांवरील** टोकनची बचत हवी असल्यास कॉम्प्रेशन सक्षम ठेवा
- [ ] `auto` मुळे “अधिक विचारप्रक्रिया दिसेल” अशी अपेक्षा ठेवू नका
- [ ] केवळ एनक्रिप्ट केलेले सारांश हे **प्रदात्याचे** वर्तन आहे; passthrough त्यांना डिक्रिप्ट करू शकत नाही
