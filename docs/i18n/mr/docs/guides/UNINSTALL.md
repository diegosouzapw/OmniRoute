## जलद विस्थापना (v3.6.2+)

OmniRoute स्वच्छपणे काढून टाकण्यासाठी दोन अंगभूत स्क्रिप्ट पुरवते:

### तुमचा डेटा जतन करा

```bash
npm run uninstall
```

हे OmniRoute अनुप्रयोग काढून टाकते, परंतु `~/.omniroute/` मधील तुमचा डेटाबेस, कॉन्फिगरेशन्स, API कीज आणि प्रदाता सेटिंग्ज **जतन करते**. तुम्ही नंतर पुन्हा इंस्टॉल करण्याचा विचार करत असाल आणि तुमची विद्यमान संरचना कायम ठेवू इच्छित असाल, तर हा पर्याय वापरा.

### संपूर्णपणे काढून टाका

```bash
npm run uninstall:full
```

हे अनुप्रयोग काढून टाकते **आणि सर्व डेटा कायमचा मिटवते**:

- डेटाबेस (`storage.sqlite`)
- प्रदाता कॉन्फिगरेशन्स आणि API कीज
- बॅकअप फाइल्स
- लॉग फाइल्स
- `~/.omniroute/` डिरेक्टरीमधील सर्व फाइल्स

> ⚠️ **चेतावणी:** `npm run uninstall:full` ही क्रिया पूर्ववत करता येत नाही. तुमची सर्व प्रदाता कनेक्शन्स, कॉम्बोज, API कीज आणि वापराचा इतिहास कायमचा हटवला जाईल.

## मॅन्युअल विस्थापना

### NPM ग्लोबल इंस्टॉल

```bash
# ग्लोबल पॅकेज काढून टाका
npm uninstall -g omniroute

# (पर्यायी) डेटा डिरेक्टरी काढून टाका
rm -rf ~/.omniroute
```

### pnpm ग्लोबल इंस्टॉल

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# कंटेनर थांबवा आणि काढून टाका
docker stop omniroute
docker rm omniroute

# व्हॉल्यूम काढून टाका (सर्व डेटा हटवते)
docker volume rm omniroute-data

# (पर्यायी) इमेज काढून टाका
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# कंटेनर्स थांबवा आणि काढून टाका
docker compose down

# व्हॉल्यूम्सही काढून टाका (सर्व डेटा हटवते)
docker compose down -v
```

### Electron डेस्कटॉप ॲप

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` उघडा
- किंवा इंस्टॉल डिरेक्टरीमधून NSIS अनइंस्टॉलर चालवा

**macOS:**

- `/Applications` मधील `OmniRoute.app` कचरापेटीत ड्रॅग करा
- डेटा काढून टाका: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage फाइल काढून टाका
- डेटा काढून टाका: `rm -rf ~/.omniroute`

### स्रोताद्वारे इंस्टॉल (git clone)

```bash
# क्लोन केलेली डिरेक्टरी काढून टाका
rm -rf /path/to/omniroute

# (पर्यायी) डेटा डिरेक्टरी काढून टाका
rm -rf ~/.omniroute
```

## डेटा डिरेक्टरीज

OmniRoute डीफॉल्टनुसार खालील ठिकाणी डेटा संग्रहित करते:

| प्लॅटफॉर्म | डीफॉल्ट पाथ                           | ओव्हरराइड                     |
| ---------- | ------------------------------------- | ----------------------------- |
| Linux      | `~/.omniroute/`                       | `DATA_DIR` पर्यावरण चल        |
| macOS      | `~/.omniroute/`                       | `DATA_DIR` पर्यावरण चल        |
| Windows    | `%APPDATA%/omniroute/`                | `DATA_DIR` पर्यावरण चल        |
| Docker     | `/app/data/` (माउंट केलेला व्हॉल्यूम) | `DATA_DIR` पर्यावरण चल        |
| XDG-सुसंगत | `$XDG_CONFIG_HOME/omniroute/`         | `XDG_CONFIG_HOME` पर्यावरण चल |

### डेटा डिरेक्टरीमधील फाइल्स

| फाइल/डिरेक्टरी       | वर्णन                                           |
| -------------------- | ----------------------------------------------- |
| `storage.sqlite`     | मुख्य डेटाबेस (प्रदाते, कॉम्बोज, सेटिंग्ज, कीज) |
| `storage.sqlite-wal` | SQLite राइट-अहेड लॉग (तात्पुरता)                |
| `storage.sqlite-shm` | SQLite सामायिक मेमरी (तात्पुरती)                |
| `call_logs/`         | विनंती पेलोड संग्रह                             |
| `backups/`           | स्वयंचलित डेटाबेस बॅकअप्स                       |
| `log.txt`            | लेगसी विनंती लॉग (पर्यायी)                      |

## पूर्णपणे काढून टाकल्याची पडताळणी करा

अनइंस्टॉल केल्यानंतर, कोणत्याही फाइल्स शिल्लक नसल्याची पडताळणी करा:

```bash
# जागतिक npm पॅकेज तपासा
npm list -g omniroute 2>/dev/null

# डेटा डिरेक्टरी तपासा
ls -la ~/.omniroute/ 2>/dev/null

# सुरू असलेल्या प्रक्रिया तपासा
pgrep -f omniroute
```

कोणतीही प्रक्रिया अजूनही सुरू असल्यास, ती थांबवा:

```bash
pkill -f omniroute
```
