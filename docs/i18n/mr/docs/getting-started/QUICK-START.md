---

## पायरी 1: OmniRoute इन्स्टॉल करा

तुमची पसंतीची पद्धत निवडा:

### पर्याय A: npm (शिफारस केलेले)

```bash
npm install -g omniroute
```

### पर्याय B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` ही सर्वाधिक आवृत्तीची **प्रकाशित** स्थिर SemVer आहे. ती git `main` चा मागोवा घेत **नाही**. GitOps साठी `diegosouzapw/omniroute:X.Y.Z` निश्चित करा. [इमेज टॅग्ज / रिलीज चॅनेल्स](../guides/DOCKER_GUIDE.md#release-channels) पहा.

### पर्याय C: सोर्समधून

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## पायरी 2: OmniRoute सुरू करा

```bash
omniroute
```

OmniRoute `http://localhost:20128` येथे सुरू होते. डॅशबोर्ड आपोआप उघडतो.

---

## पायरी 3: मोफत प्रोव्हायडर कनेक्ट करा

मोफत प्रोव्हायडर कनेक्ट करून तुम्ही OmniRoute **कोणतेही पैसे न देता** वापरू शकता.

### पर्याय A: Kiro (मोफत Claude — क्रेडिट कार्डची आवश्यकता नाही)

1. `http://localhost:20128` येथे डॅशबोर्ड उघडा
2. **Providers** → **Add Provider** येथे जा
3. **Kiro AI** निवडा
4. **Connect** वर क्लिक करा (API key आवश्यक नाही!)
5. झाले! आता तुम्हाला Claude मॉडेल्सचा मोफत ॲक्सेस मिळाला आहे.

### पर्याय B: OpenCode Free (ऑथेंटिकेशन नाही)

1. `http://localhost:20128` येथे डॅशबोर्ड उघडा
2. **Providers** → **Add Provider** येथे जा
3. **OpenCode Free** निवडा
4. **Connect** वर क्लिक करा (API key आवश्यक नाही!)
5. झाले! आता तुम्हाला अनेक मॉडेल्सचा मोफत ॲक्सेस मिळाला आहे.

### पर्याय C: Pollinations (की आवश्यक नाही)

1. `http://localhost:20128` येथे डॅशबोर्ड उघडा
2. **Providers** → **Add Provider** येथे जा
3. **Pollinations** निवडा
4. **Connect** वर क्लिक करा (API key आवश्यक नाही!)
5. झाले! आता तुम्हाला GPT-5, Claude, Gemini आणि इतर मॉडेल्सचा मोफत ॲक्सेस मिळाला आहे.

---

## पायरी 4: ते कार्यरत असल्याची खात्री करा

[API Keys](http://localhost:20128/dashboard/api-manager) मधून नवीन की तयार करा. ही की पुन्हा दिसणार नसल्यामुळे ती सुरक्षितपणे साठवा. लक्षात ठेवा की ही की टूल्सना OmniRoute चा ॲक्सेस देण्यासाठी आहे, अपस्ट्रीम प्रोव्हायडर्सचा ॲक्सेस देण्यासाठी नाही.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

तुम्हाला कनेक्ट केलेल्या मॉडेल्सची सूची दिसली पाहिजे.

## पायरी 5: तुमचा IDE किंवा CLI OmniRoute कडे निर्देशित करा

तुमच्या IDE किंवा CLI टूलमध्ये पुढील सेटिंग्ज करा:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

इतकेच! आता तुमचा IDE स्वयंचलित प्रोव्हायडर निवडीसह OmniRoute वापरतो.

### IDE उदाहरण: VSCode/Continue.dev

1. VSCode मध्ये [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) एक्स्टेंशन इन्स्टॉल करा.
2. पुढील ओळी जोडण्यासाठी तुमची `~/.continue/config.yaml` फाइल अपडेट करा:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev चॅट पेनमध्ये `OmniRoute - Auto` निवडा आणि त्यानंतर तुम्ही OmniRoute ला विनंत्या पाठवाल.
4. (पर्यायी) वाचकांसाठी सराव — इतर सर्व पूर्वनिर्मित कॉन्फिगरेशन्ससह `config.yaml` अपडेट करण्यास तुमच्या IDE ला सांगा 😊

### CLI उदाहरण: Codex CLI

1. तुमच्या ऑपरेटिंग सिस्टीममध्ये एन्व्हायर्नमेंट व्हेरिएबल कायमस्वरूपी सेट करा.
   macOS/Linux साठी (तुमच्या `~/.bashrc` किंवा `~/.zshrc` मध्ये जोडा):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows साठी (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. आता OmniRoute साठी कॉन्फिगर केलेले Codex सुरू करूया. हे चालवा:

```
omniroute launch-codex --model auto
```

एंडपॉइंट आणि API key निर्दिष्ट करण्यासाठी तुम्ही `codex` व कमांड-लाइन पॅरामीटर्सद्वारे हे मॅन्युअली करू शकता; मात्र वरील कमांड वापरल्यास OmniRoute तुमच्यासाठी सर्व गोष्टींची काळजी घेते.

जेनेरिक लाँचरद्वारे इतर CLI साठीही हीच एक-कमांड लाँच पद्धत कार्य करते — `omniroute run <target>` हे `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, आणि `gemini` यांना सपोर्ट करते ([CLI इंटिग्रेशन्स](../guides/CLI-INTEGRATIONS.md) पहा).

3. आता CLI ने OmniRoute कडे विनंत्या पाठवल्या पाहिजेत.

### तुमचे टूल OmniRoute कडे रूट करत असल्याची खात्री करा

डाव्या साइडबारमधील [Monitoring/Logs](http://localhost:20128/dashboard/logs) वर क्लिक करून तुम्ही विनंतीचे तपशील पाहू शकता. पुढे क्लिक केल्यावर तुम्हाला अधिक तपशील दिसतील. यासोबतच, तुमच्या आवडत्या हार्नेसमधून कोणती माहिती पाठवली जाते हेही तुम्ही पाहू शकता. शैक्षणिक आणि डीबगिंगच्या दृष्टीने हे उपयुक्त आहे.

## सामान्य प्रश्न

### "मला API key ची आवश्यकता आहे का?"

**नाही!** तुम्ही कोणत्याही API key शिवाय मोफत प्रोव्हायडर्स (Kiro, OpenCode Free, Pollinations) वापरू शकता. त्यांना फक्त डॅशबोर्डमध्ये कनेक्ट करा.

### "`auto` म्हणजे काय?"

`auto` हे OmniRoute ला प्रत्येक विनंतीसाठी सर्वोत्तम प्रोव्हायडर आपोआप निवडण्यास सांगते. ते वेग, खर्च, गुणवत्ता आणि उपलब्धता विचारात घेते. तपशीलांसाठी [Auto-Combo मार्गदर्शक](./AUTO-COMBO-GUIDE.md) पहा.

### "यासाठी किती खर्च येतो?"

OmniRoute स्वतः **मोफत आणि ओपन-सोर्स** आहे. तुम्ही फक्त वापरत असलेल्या प्रोव्हायडर्ससाठी पैसे देता. अनेक प्रोव्हायडर्सकडे मोफत टियर्स आहेत — [मोफत टियर्स मार्गदर्शक](./FREE-TIERS-GUIDE.md) पहा.

### "मी हे Claude Code / Cursor / Copilot सोबत वापरू शकतो का?"

**होय!** OpenAI फॉरमॅटला सपोर्ट करणाऱ्या कोणत्याही टूलसोबत OmniRoute कार्य करते. फक्त बेस URL `http://localhost:20128/v1` वर सेट करा. विशिष्ट सेटअप सूचनांसाठी [CLI टूल्स मार्गदर्शक](../reference/CLI-TOOLS.md) पहा.

### "एखादा प्रोव्हायडर बंद पडला तर काय होईल?"

OmniRoute अयशस्वी प्रोव्हायडर्सना आपोआप वगळते आणि पुढील प्रोव्हायडर वापरून पाहते. तुम्हाला काहीही करण्याची आवश्यकता नाही. तपशीलांसाठी [Auto-Combo मार्गदर्शक](./AUTO-COMBO-GUIDE.md) पहा.
