## प्रदाता म्हणजे काय?

प्रदात्याचा विचार **मोबाइल सेवा प्रदात्यासारखा** करा. जसे कॉल करण्यासाठी तुम्हाला मोबाइल सेवा प्रदात्याची आवश्यकता असते, तसेच AI मॉडेल वापरण्यासाठी तुम्हाला AI प्रदात्याची आवश्यकता असते. OmniRoute हा **सर्व सेवा प्रदात्यांसोबत** चालणाऱ्या फोनसारखा आहे — तुम्ही त्यांच्यात स्वयंचलितपणे अदलाबदल करू शकता.

### प्रदात्यांचे प्रकार

| प्रकार        | हे काय आहे                  | उदाहरणे                           | खर्च                   |
| ------------- | --------------------------- | --------------------------------- | ---------------------- |
| **विनामूल्य** | कोणतेही शुल्क आवश्यक नाही   | Kiro, OpenCode Free, Pollinations | $0                     |
| **API की**    | तुम्हाला API की आवश्यक आहे  | OpenAI, Anthropic, Google         | वापरानुसार शुल्क       |
| **OAuth**     | तुमच्या खात्याने लॉग इन करा | Claude Code, GitHub Copilot       | सदस्यता                |
| **वेब कुकी**  | तुमचे ब्राउझर सत्र वापरते   | ChatGPT Web (Codex), Gemini Web   | $0 (तुमचे खाते वापरते) |

### वेब कुकी प्रदाते

सामान्य सेटअप सूचना, मर्यादा, समस्यांचे निवारण आणि प्रदात्यानुसार प्रमाणीकरण मार्गदर्शनासाठी **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** पहा.

## झटपट सुरुवात: तुमचा पहिला प्रदाता जोडा

### प्रथम वापरावेळी विनामूल्य प्रदाते सेट करण्याचा पर्यायी मार्ग

प्रथम वापराच्या विझार्डमध्ये स्पष्ट **विनामूल्य प्रदाते सेट करा** कार्ड उपलब्ध असते. ते OmniRoute च्या प्रमाणीकरणाची आवश्यकता नसलेल्या प्रदाता रजिस्ट्रीमधून सध्या पात्र असलेली यादी तयार करते आणि पुष्टी करण्यापूर्वी तुम्हाला प्रत्येक प्रदात्याचे पुनरावलोकन करून त्याची निवड रद्द करण्याची सुविधा देते. OmniRoute प्रदात्याची सावधगिरीची सूचना आणि त्याच्या साइटची लिंक दाखवते, जेणेकरून तुम्ही प्रथम तृतीय-पक्ष अटी, गोपनीयता, उपलब्धता आणि दर मर्यादांचे पुनरावलोकन करू शकता.

ही कृती पर्यायी आहे: विझार्ड पूर्ण केल्याने विनामूल्य प्रदात्यांच्या जोडण्या कधीही तुमच्या नकळत तयार होत नाहीत. ते केवळ अद्याप नसलेले प्रदाते तयार करते, विद्यमान सानुकूलित जोडण्या तशाच ठेवते आणि तयार झालेले, आधीच कॉन्फिगर केलेले व अयशस्वी झालेले प्रदाते स्वतंत्रपणे कळवते. अंशतः निकाल मिळाल्यानंतर तुम्ही केवळ अयशस्वी प्रदात्यांसाठी सुरक्षितपणे पुन्हा प्रयत्न करू शकता.

### पर्याय A: विनामूल्य प्रदाता (क्रेडिट कार्डची आवश्यकता नाही)

1. `http://localhost:20128` येथे डॅशबोर्ड उघडा
2. **प्रदाते** → **प्रदाता जोडा** येथे जा
3. यापैकी एक विनामूल्य प्रदाता निवडा:
   - **Kiro AI** — विनामूल्य Claude मॉडेल (प्रमाणीकरणाची आवश्यकता नाही)
   - **OpenCode Free** — विनामूल्य GPT मॉडेल (प्रमाणीकरणाची आवश्यकता नाही)
   - **Pollinations** — विनामूल्य GPT-5, Claude, Gemini (कीची आवश्यकता नाही)
   - **LongCat** — 10M टोकन विनामूल्य (एकदाच मिळणारे अनुदान, खाते + KYC आवश्यक)
   - **Cloudflare AI** — 50+ मॉडेल, 10K न्यूरॉन्स/दिवस
   - **MLX Gemma 26B** — स्थानिक Apple Silicon मॉडेल (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — स्थानिक Apple Silicon मॉडेल (~9.1 tok/s, ~13.1GB RAM)
4. **जोडा** वर क्लिक करा
5. झाले! आता तुम्हाला विनामूल्य AI प्रवेश मिळाला आहे.

### पर्याय B: API की प्रदाता (सशुल्क)

1. प्रदात्याच्या वेबसाइटवरून API की मिळवा:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` येथे डॅशबोर्ड उघडा
3. **प्रदाते** → **प्रदाता जोडा** येथे जा
4. तुमचा प्रदाता निवडा
5. तुमची API की पेस्ट करा
6. **जोडा** वर क्लिक करा
7. झाले! आता तुम्हाला त्या प्रदात्याच्या मॉडेलचा प्रवेश मिळाला आहे.

### पर्याय C: OAuth प्रदाता (सदस्यता)

1. `http://localhost:20128` येथे डॅशबोर्ड उघडा
2. **प्रदाते** → **प्रदाता जोडा** येथे जा
3. तुमचा प्रदाता निवडा (उदा. Claude Code, GitHub Copilot)
4. **OAuth सह जोडा** वर क्लिक करा
5. तुमच्या खात्याने लॉग इन करा
6. झाले! आता तुम्हाला तुमच्या सदस्यतेमधील मॉडेलचा प्रवेश मिळाला आहे.

### पर्याय D: स्थानिक MLX मॉडेल (Apple Silicon)

एकत्रित मेमरी असलेल्या Apple Silicon Mac साठी, OmniRoute नियमित OpenAI-सुसंगत स्थानिक प्रदाते म्हणून `mlx-lm.server` द्वारे चालणाऱ्या स्थानिक MLX मॉडेलशी जोडणी करण्यास समर्थन देते.

#### पूर्वावश्यकता

- **Apple Silicon Mac** (M1/M2/M3/M4), 24GB+ एकत्रित मेमरीची शिफारस
- **uv** पॅकेज मॅनेजर: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### झटपट सुरुवात

1. **अवलंबित्वे इंस्टॉल करा**:

   ```bash
   # uv आधीच इंस्टॉल केलेले नसल्यास ते इंस्टॉल करा
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm इंस्टॉल करा
   uv pip install mlx-lm
   ```

2. **MLX सर्व्हर स्वहस्ते सुरू करा** (वेगवेगळ्या टर्मिनलमध्ये):

   ```bash
   # टर्मिनल 1: Gemma 4 26B A4B IT-QAT (पोर्ट 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # टर्मिनल 2: Qwen 3.8 27B MLX Mixed (पोर्ट 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute डॅशबोर्डमध्ये जोडा**:
   - **प्रदाते** → **प्रदाता जोडा** येथे जा
   - **MLX Gemma 26B** किंवा **MLX Qwen 3.8 27B** निवडा
   - **जोडा** वर क्लिक करा (API कीची आवश्यकता नाही)

4. **OpenCode सह वापरा**:
   ```bash
   # OmniRoute वापरण्यासाठी OpenCode कॉन्फिगर करा
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX मॉडेल वापरा
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### मेमरी व्यवस्थापन

**महत्त्वाचे**: 24GB एकत्रित मेमरीसह एका वेळी केवळ **एक मोठे MLX मॉडेल चालू शकते**.

- Gemma 26B: कमाल ~15.9GB मेमरी
- Qwen 3.8 27B: कमाल ~13.1GB मेमरी

तुम्हाला हे स्वहस्ते व्यवस्थापित करावे लागेल:

- एका वेळी फक्त एक MLX सर्व्हर चालवा, किंवा
- दोन्ही वेगवेगळ्या मशीनवर चालवा, किंवा
- दुसरा सुरू करण्यापूर्वी एक थांबवा

OmniRoute MLX सर्व्हर प्रक्रिया स्वयंचलितपणे व्यवस्थापित करत नाही — ते फक्त तुम्ही कॉन्फिगर केलेल्या OpenAI-सुसंगत एंडपॉइंटकडे विनंत्या पाठवते.

#### टूल कॉलिंग समर्थन

दोन्ही मॉडेल OpenAI-सुसंगत टूल कॉलिंगला समर्थन देतात. यासह चाचणी करा:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "2+2 किती होतात? calculator साधन वापरा."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "गणना करा", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### समस्या निवारण

| समस्या                     | उपाय                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------ |

| मेमरी अपुरी पडते           | फक्त एकच मॉडेल चालत असल्याची खात्री करा; इतर ॲप्स बंद करा; Activity Monitor तपासा          |
| कनेक्शन नाकारले गेले       | सर्व्हर योग्य पोर्टवर (11435/11436) चालू असल्याचे सत्यापित करा                             |
| प्रतिसाद धीमे आहेत         | पहिल्या विनंतीवेळी मॉडेल मेमरीमध्ये लोड होते (~30-60s); त्यानंतरच्या विनंत्या जलद असतात    |

## प्रदाता कसा कनेक्ट करावा (टप्प्याटप्प्याने)

### टप्पा 1: डॅशबोर्ड उघडा

तुमच्या ब्राउझरमध्ये `http://localhost:20128` वर जा.

### टप्पा 2: प्रदाते विभागात जा

साइडबारमधील **प्रदाते** वर क्लिक करा.

### टप्पा 3: प्रदाता जोडा वर क्लिक करा

**+ प्रदाता जोडा** बटणावर क्लिक करा.

### टप्पा 4: तुमचा प्रदाता निवडा

सूची ब्राउझ करा किंवा तुमचा प्रदाता शोधा. त्यावर क्लिक करा.

### टप्पा 5: क्रेडेन्शियल्स प्रविष्ट करा

- **मोफत प्रदाते**: क्रेडेन्शियल्सची आवश्यकता नाही — फक्त **कनेक्ट करा** वर क्लिक करा
- **API की प्रदाते**: तुमची API की पेस्ट करा
- **OAuth प्रदाते**: **OAuth सह कनेक्ट करा** वर क्लिक करून लॉग इन करा

### टप्पा 6: कनेक्शनची चाचणी करा

ते कार्यरत असल्याची खात्री करण्यासाठी **कनेक्शनची चाचणी करा** वर क्लिक करा.

### टप्पा 7: पूर्ण झाले!

तुमचा प्रदाता आता कनेक्ट झाला आहे. तुम्ही तो `model: "auto"` सह वापरू शकता किंवा थेट प्रदाता निर्दिष्ट करू शकता.

## अनेक प्रदाते वापरणे

OmniRoute **अनेक प्रदात्यांसह** सर्वाधिक प्रभावीपणे कार्य करते. यामुळे तुम्हाला पुढील फायदे मिळतात:

- **स्वयंचलित फॉलबॅक** — एक प्रदाता अयशस्वी झाल्यास, OmniRoute पुढील प्रदात्याचा प्रयत्न करते
- **खर्च ऑप्टिमायझेशन** — OmniRoute प्रत्येक विनंतीसाठी सर्वात स्वस्त प्रदाता निवडते
- **वेग ऑप्टिमायझेशन** — OmniRoute प्रत्येक विनंतीसाठी सर्वात वेगवान प्रदाता निवडते
- **गुणवत्ता ऑप्टिमायझेशन** — OmniRoute प्रत्येक कार्यासाठी सर्वोत्तम प्रदाता निवडते

### शिफारस केलेले सेटअप

सर्वोत्तम अनुभवासाठी किमान **3 प्रदाते** कनेक्ट करा:

1. **एक मोफत प्रदाता** (Kiro, OpenCode Free किंवा Pollinations) — नेहमी उपलब्ध
2. **एक वेगवान प्रदाता** (Groq, Cerebras) — जलद प्रतिसादांसाठी
3. **एक उच्च-गुणवत्तेचा प्रदाता** (OpenAI, Anthropic, Google) — जटिल कार्यांसाठी

त्यानंतर `model: "auto"` वापरा आणि OmniRoute प्रत्येक विनंतीसाठी सर्वोत्तम प्रदाता आपोआप निवडेल.

## सामान्य प्रश्न

### "OmniRoute वापरण्यासाठी मला पैसे द्यावे लागतील का?"

**नाही!** OmniRoute विनामूल्य आणि मुक्त-स्रोत आहे. तुम्ही कोणतेही पैसे न देता विनामूल्य प्रदाते (Kiro, OpenCode Free, Pollinations) वापरू शकता. तुम्ही सशुल्क प्रदाते वापरण्याचा निर्णय घेतल्यासच तुम्हाला पैसे द्यावे लागतील.

### "मी कोणत्या प्रदात्यापासून सुरुवात करावी?"

**Kiro AI** पासून सुरुवात करा — ते विनामूल्य आहे, त्यासाठी API की आवश्यक नाही आणि ते तुम्हाला Claude मॉडेल्सचा ॲक्सेस देते. त्यानंतर गरजेनुसार आणखी प्रदाते जोडा.

### "मी एकाच वेळी अनेक प्रदाते वापरू शकतो का?"

**होय!** हाच OmniRoute चा मुख्य उद्देश आहे. अनेक प्रदाते कनेक्ट करा आणि प्रत्येक विनंतीसाठी OmniRoute ला सर्वोत्तम प्रदाता निवडू देण्यासाठी `model: "auto"` वापरा.

### "एखादा प्रदाता बंद पडल्यास काय होईल?"

OmniRoute अयशस्वी प्रदात्यांना आपोआप वगळते आणि पुढील प्रदात्याचा प्रयत्न करते. तुम्हाला काहीही करण्याची आवश्यकता नाही.

### "मी प्रदात्याचे कनेक्शन कसे तोडू?"

प्रदाते येथे जा → प्रदात्यावर क्लिक करा → **कनेक्शन तोडा** वर क्लिक करा.

### "मी माझ्या विद्यमान API की वापरू शकतो का?"

**होय!** तुमच्याकडे OpenAI, Anthropic, Google इत्यादींसाठी आधीपासून API की असल्यास, तुम्ही त्या OmniRoute मध्ये वापरू शकता. प्रदाता कनेक्ट करताना त्या फक्त पेस्ट करा.
