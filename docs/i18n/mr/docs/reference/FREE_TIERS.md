> ⚠️ सैद्धांतिक कमाल मर्यादा (~10B) ही **कोणतीही प्रकाशित टोकन मर्यादा नसलेल्या** केवळ दर-मर्यादा असलेल्या प्रदात्यांमुळे (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`) फुगलेली आहे; त्यांचे आकडे `RPM/TPM × 24/7 × 30d` असे असतील — ही अशी सैद्धांतिक कमाल आहे जी कोणतेही एक खाते सातत्याने गाठू शकणार नाही. विश्वासार्ह आकड्यातून त्यांना **वगळले आहे** (त्याऐवजी "कायमस्वरूपी मोफत, कोणतीही मर्यादा नाही" या पंक्तीत दाखवले आहे). याच प्रकारच्या अतिशयोक्तीमुळे स्पर्धकांचे अब्जावधींचे दावे अविश्वसनीय ठरतात.

## 2026-06-17 अद्यतन — 2026-06-05 पासून काय बदलले

- **दैनिक मर्यादा रूपांतरित केल्या जातात, दर नाहीत.** दस्तऐवजीकृत tokens/day मर्यादेचे `× 30` केले जाते; दस्तऐवजीकृत requests/day मर्यादेचे `RPD × ~800 tokens × 30` केले जाते; केवळ requests-per-minute प्रकाशित करणाऱ्या प्रदात्यासाठी कोणताही मासिक आकडा दिला जात नाही आणि त्याला _मर्यादाविरहित_ म्हणून सूचीबद्ध केले जाते, त्याची बेरीज कधीही केली जात नाही. दरमर्यादेला 24/7 ने गुणून आकडा फुगवण्यास आम्ही नकार देतो.
- **प्रादेशिक ओळख पडताळणीमागील कोटे स्वतंत्रपणे दाखवले आहेत** (`+~6M behind regional identity verification`), कारण बहुतेक वाचक ते वापरू शकत नाहीत.
- **साइनअप क्रेडिट्स केवळ पहिल्या महिन्यासाठी असतात** आणि स्थिर आकड्यात मिसळण्याऐवजी दुसरा आकडा म्हणून नोंदवले जातात.
- **हा आकडा CI द्वारे लागू केला जातो.** `npm run check:docs-counts` कॅटलॉगमधून एकूण आकड्यांची पुन्हा गणना करते आणि ही फाइल, README किंवा बजेट कार्डमधील आकडे त्यांच्यापासून विचलित झाल्यास बिल्ड अयशस्वी करते.
