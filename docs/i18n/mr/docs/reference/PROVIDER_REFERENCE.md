## श्रेण्या

- **विनामूल्य** — API कीसह विनामूल्य स्तर (डॅशबोर्डद्वारे कॉन्फिगर केलेला)
- **प्रमाणीकरणाविना** — कोणतीही की किंवा साइन-इन अजिबात आवश्यक नसलेले सार्वजनिक एंडपॉइंट
- **OAuth** — OmniRoute द्वारे हाताळली जाणारी साइन-इन प्रक्रिया, API कीची आवश्यकता नाही
- **वेब कुकी** — कुकी प्रमाणीकरणाद्वारे प्रदात्याच्या वेब अॅपला रॅप करते
- **API की** — API कीद्वारे कॉन्फिगर केलेला सशुल्क प्रदाता (विनामूल्य क्रेडिट लागू होऊ शकते)
- **स्थानिक** — वापरकर्त्याच्या मशीनवर चालतो (Ollama, LM Studio, vLLM इ.)
- **शोध** — वेब शोध प्रदाते
- **ऑडिओ** — केवळ-ऑडिओ प्रदाते (TTS/STT)
- **अपस्ट्रीम प्रॉक्सी** — इतर प्रदात्यांकडे प्रॉक्सी करणारे प्रदाते
- **क्लाउड एजंट** — दीर्घकाळ चालणारे कोडिंग एजंट (Codex Cloud, Devin, Jules)
- **सिस्टम** — OmniRoute-अंतर्गत प्रदाते (लूपबॅक इ.)

अतिरिक्त टॅग: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (जिथे दाखवले आहे): `native` — वास्तविक फंक्शन-कॉलिंग API; `emulated` — `tools` अॅरेचे `webTools.ts` द्वारे प्रॉम्प्ट-अनुकरण केले जाते (regex द्वारे पार्स केलेले `<tool>{...}</tool>` ब्लॉक); `none` — `tools` सध्या कोणतीही सूचना न देता वगळले जाते. #7286 पाहा.

प्रत्येक प्रदाता सक्षम, कॉन्फिगर आणि तपासण्यासाठी `/dashboard/providers` येथील डॅशबोर्ड वापरा.
