OmniRoute हे `free_proxies` तक्त्यामध्ये विनामूल्य प्रॉक्सींचा काळजीपूर्वक निवडलेला संच उपलब्ध करून देते,
जो बाह्य प्रदात्यांकडून (1proxy, proxifly, iplocate, webshare) समक्रमित केला जातो.
डॅशबोर्डवर हे **Settings → Free Proxies** अंतर्गत दिसतात. या दस्तऐवजात
सूची रूटद्वारे उपलब्ध करून दिलेले सर्व्हर-साइड फिल्टरिंग, क्रमवारी, मोजणी आणि समक्रमण-त्रुटी अहवाल
समाविष्ट आहेत.

## सूची रूट — `GET /api/settings/free-proxies`

फिल्टर केलेला, क्रमवारी लावलेला आणि पृष्ठांकन केलेला भाग तसेच एकूण संख्या परत करते. फिल्टरिंग आणि
मोजणी SQL मध्ये केली जाते, त्यामुळे प्रत्येक पंक्ती मेमरीमध्ये लोड न करता UI वास्तविक एकूण संख्या (उदा. `Total: 0`)
दाखवू शकते.

### क्वेरी पॅरामीटर्स

| पॅरामीटर          | प्रकार                             | डीफॉल्ट   | अर्थ                                                                                                                        |
| ----------------- | ---------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------- |
| `search`          | स्ट्रिंग                           | `""`      | होस्ट (आणि स्रोत) स्तंभावर केस-संवेदी `LIKE`.                                                                               |
| `protocol`        | स्ट्रिंग                           | `""`      | `type` फिल्टर: `http` / `https` / `socks4` / `socks5`. रिक्त = सर्व.                                                        |
| `country`         | स्ट्रिंग                           | `""`      | `countryCode` फिल्टर (ISO-2). रिक्त = सर्व.                                                                                 |
| `minQuality`      | संख्या                             | `0`       | केवळ `qualityScore >= minQuality` असलेल्या पंक्ती. `0` = किमान मर्यादा नाही.                                                |
| `disabledSources` | स्ट्रिंग                           | `""`      | वगळण्यासाठी स्वल्पविरामाने विभक्त केलेले स्रोत id (उदा. `proxifly,webshare`).                                               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = गुण उतरत्या क्रमाने; `latency` = विलंब चढत्या क्रमाने (null शेवटी); `recent` = `lastValidated` उतरत्या क्रमाने. |
| `offset`          | संख्या                             | `0`       | पृष्ठांकनाची सुरुवात.                                                                                                       |
| `limit`           | संख्या                             | `50`      | पृष्ठाचा आकार (सर्व्हर-साइड मर्यादित).                                                                                      |

### प्रतिसाद

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["अपस्ट्रीमकडून HTTP 429"],
    "webshare": ["नेटवर्क टाइमआउट"]
  }
}
```

`total` हे पृष्ठांकनाच्या **आधीची** फिल्टर केलेली एकूण संख्या दर्शवते, त्यामुळे UI
`Total: N` आणि `hasMore` स्वतंत्रपणे रेंडर करू शकते. `syncErrors` मध्ये स्रोत id नुसार की असतात आणि
केवळ ज्यांचे शेवटचे समक्रमण अयशस्वी झाले अशा स्रोतांसाठी ते भरले जाते — `Total: 0` परिणाम
कधीही कोणत्याही स्पष्टीकरणाशिवाय नसतो.

## पूलमध्ये जोडणे — `POST /api/settings/free-proxies/[id]/add-to-pool`

विनामूल्य प्रॉक्सीला व्यवस्थापित `proxy_registry` पूलमध्ये समाविष्ट करते. प्रथम
अपस्ट्रीमचे प्रमाणीकरण करते; यशस्वी झाल्यास नवीन पूल प्रॉक्सी id आणि मोजलेला विलंब परत करते.

## समक्रमण — `POST /api/settings/free-proxies/sync`

सर्व सक्षम स्रोतांकडून (किंवा `{ "sources": [...] }` मधील उपसंचाकडून) डेटा पुन्हा प्राप्त करते. प्रत्येक
स्रोत स्वतंत्रपणे समक्रमित होतो; अयशस्वी स्रोताची नोंद `syncErrors` मध्ये केली जाते आणि
इतर स्रोतांचे समक्रमण तरीही पूर्ण होते, त्यामुळे अंशतः समक्रमणामुळे पूर्वीचा योग्य डेटा कधीही पुसला जात नाही.

## आकडेवारी — `GET /api/settings/free-proxies/stats`

पंक्तींच्या पेलोडशिवाय `total / inPool / avgQuality / bySource / lastSyncAt` एकत्रित आकडेवारी
परत करते — डॅशबोर्डच्या शीर्षलेखातील विजेट्सद्वारे वापरली जाते.
