## खर्च विभाग (नवीन, स्तर 1)

पाथ उपसर्ग: `/dashboard/costs/`

| घटक               | URL                                  | वर्णन                                        |
| ----------------- | ------------------------------------ | -------------------------------------------- |
| आढावा             | `/dashboard/costs`                   | एकत्रित खर्च डॅशबोर्ड (विश्लेषणातून हलवलेला) |
| किंमत निर्धारण    | `/dashboard/costs/pricing`           | प्रत्येक मॉडेलसाठी किंमत तक्ता               |
| बजेट              | `/dashboard/costs/budget`            | बजेट मर्यादा + सूचना                         |
| कोटा शेअरिंग      | `/dashboard/costs/quota-share`       | कोटा शेअर पूल + वापर                         |
| योजना कॉन्फिगरेशन | `/dashboard/costs/quota-share/plans` | प्रत्येक प्रदात्यासाठी योजना ओव्हरराइड       |

**कारण**: किंमत निर्धारण, बजेट आणि कोटा शेअरिंग हे यापूर्वी
`निरीक्षण > खर्च पॅरामीटर्स` अंतर्गत होते. त्यांना स्वतंत्र उच्च-स्तरीय विभागात
हलवल्यामुळे निरीक्षणक्षमतेच्या साधनांमधून नेव्हिगेट न करता ते सहज शोधता येतात.

## निरीक्षण विभाग (पुनर्रचित)

निरीक्षण विभागात आता सर्वांत वर **क्रियाकलाप** आणि त्यानंतर **3 उपगट** आहेत:

```
निरीक्षण
├── क्रियाकलाप             ← टाइमलाइन फीड (उच्च-स्तरीय घटक)
├── लॉग गट
│   ├── लॉग (सर्व)
│   ├── प्रॉक्सी लॉग
│   └── कन्सोल लॉग
├── ऑडिट गट
│   ├── ऑडिट लॉग
│   ├── MCP ऑडिट
│   └── A2A ऑडिट
└── सिस्टम गट
    ├── स्थिती
    └── रनटाइम
```

### जुन्या संरचनेपासून काय बदलले

| पूर्वी                                                                             | आता                                               |
| ---------------------------------------------------------------------------------- | ------------------------------------------------- |
| क्रियाकलाप = ऑडिट लॉग रेंडर करणारा लॉगमधील टॅब                                     | क्रियाकलाप = स्वतंत्र फीड (`/dashboard/activity`) |
| निरीक्षणामधील खर्च पॅरामीटर्स गट                                                   | खर्च विभागात हलवला                                |
| सपाट सूची: लॉग, क्रियाकलाप (लॉग), ऑडिट, स्थिती, रनटाइम, किंमत निर्धारण, बजेट, कोटा | संरचित 3-गट + स्वतंत्र खर्च विभाग                 |

## क्रियाकलाप विरुद्ध ऑडिट लॉग

हे दोन्ही आता वेगळे आहेत:

| परिमाण               | क्रियाकलाप (`/dashboard/activity`)                                           | ऑडिट लॉग (`/dashboard/audit`)                   |
| -------------------- | ---------------------------------------------------------------------------- | ----------------------------------------------- |
| **उद्देश**           | वापरकर्त्यांसाठी इव्हेंट फीड ("अलीकडे काय घडले")                             | अनुपालन / सुरक्षा लॉग                           |
| **डेटा स्रोत**       | `GET /api/compliance/audit-log?level=high`                                   | `GET /api/compliance/audit-log?level=all`       |
| **स्वरूप**           | दिवसानुसार गटबद्ध केलेली टाइमलाइन, माणसाला वाचता येतील अशी क्रियापदे + आयकॉन | तपशीलवार पृष्ठांकित तक्ता, प्रत्येक पृष्ठावर 50 |
| **फिल्टर**           | इव्हेंट प्रकार श्रेणी                                                        | कृती, तीव्रता, कर्ता, दिनांक श्रेणी             |
| **निर्यात**          | उपलब्ध नाही                                                                  | JSON निर्यात                                    |
| **कर्ता फिल्टर**     | लागू नाही                                                                    | कर्त्यानुसार फिल्टर करता येते                   |
| **दाखवलेले इव्हेंट** | केवळ उच्च-स्तरीय कृती (अनुमतीसूची)                                           | सर्व ऑडिट इव्हेंट                               |

### उच्च-स्तरीय कृतींची अनुमतीसूची

`src/lib/audit/highLevelActions.ts` मध्ये परिभाषित केलेली आहे. क्रियाकलाप
फीडमध्ये कोणते इव्हेंट दिसतील हे ती नियंत्रित करते. अनुमतीसूचीमध्ये पुढील गोष्टी समाविष्ट आहेत:

- प्रदाता जोडणे/काढणे/चाचणी इव्हेंट
- कॉम्बो तयार करणे/अपडेट करणे/हटवणे
- API की जीवनचक्र (तयार करणे, रद्द करणे, रोटेट करणे)
- बजेट मर्यादा गाठली
- प्रमाणीकरण लॉगिन/लॉगआउट
- क्लाउड एजंट सत्र निर्मिती
- MCP साधन नोंदणी
- वेबहुक तयार करणे/हटवणे
- कोटा पूल/योजना बदल (`quota.*` कृती, गट B)
- प्लॅटफॉर्म इव्हेंट (अपडेट, डिप्लॉय)
- कौशल्य स्थापित करणे/काढणे

या सूचीमध्ये नसलेले इव्हेंट केवळ ऑडिट लॉगमध्ये दिसतात.

### नवीन उच्च-स्तरीय कृती जोडणे

`src/lib/audit/highLevelActions.ts` संपादित करा आणि कृतीची स्ट्रिंग
`HIGH_LEVEL_ACTIONS` मध्ये जोडा. यासाठी PR आवश्यक आहे (ही सूची कोडमध्ये आहे, DB मधून कॉन्फिगर करता येत नाही).
संबंधित आयकॉन `src/lib/audit/activityIcons.ts` मध्ये जोडता येतो.

## पुनर्निर्देशन: `/dashboard/logs/activity`

जुना पाथ `/dashboard/logs/activity`,
`src/app/(dashboard)/dashboard/logs/activity/page.tsx` मधील `permanentRedirect()` द्वारे
`/dashboard/activity` कडे कायमस्वरूपी पुनर्निर्देशित (HTTP 308) केला जातो.

जुन्या ID चा संदर्भ देणारी वापरकर्ता प्रीसेट्स बिघडू नयेत म्हणून जुना साइडबार ID `logs-activity`,
`HIDEABLE_SIDEBAR_ITEM_IDS` मध्ये जतन केला आहे
(परंतु `SIDEBAR_DEFINITIONS` मधून काढला आहे).
