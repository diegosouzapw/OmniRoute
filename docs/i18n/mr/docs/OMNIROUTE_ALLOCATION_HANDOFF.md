वाटप म्हणजे प्रदात्याचा कोटा नव्हे.

कोटा पूल कोणत्या API कीज प्रदाता पूल वापरू शकतात आणि कठोर, मृदू किंवा बर्स्ट धोरणे कशी लागू होतात हे परिभाषित करतात. प्रदाता कोटा म्हणजे प्रदात्याने नोंदवलेली बाह्य क्षमता किंवा स्पष्टपणे कॉन्फिगर केलेल्या स्रोताची क्षमता. Ghostlight ची अंतर्गत बजेट ही प्रशासकाने परिभाषित केलेली प्रशासनविषयक मर्यादा आहेत.

`ensurePool` ऑपरेशन आयडेम्पोटंट आहे: समान पूल अपरिवर्तित राहतो, बदललेले वाटप अद्ययावत केले जाते आणि अस्तित्वात नसलेला पूल तयार केला जातो. हे ऑटोमेशन आणि मर्यादित API कॉलर्ससाठी अभिप्रेत आहे.

केवळ-वाचन स्थिती एंडपॉइंट `GET /api/omniroute/status` आहे. पडताळणी कमांड `npm run omniroute:verify` आहे; ती कोणतीही प्रत्यक्ष मॉडेल विनंती करत नाही.
