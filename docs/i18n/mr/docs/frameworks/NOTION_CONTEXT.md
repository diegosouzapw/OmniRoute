> **अधिकृत स्रोत:** `src/lib/notion/api.ts` (REST क्लायंट), `src/lib/db/notion.ts`
> (टोकन टिकवून ठेवणे), `open-sse/mcp-server/tools/notionTools.ts` (6 MCP साधने),
> `src/app/api/settings/notion/route.ts` (सेटिंग्ज API). साधन नोंदणी आणि स्कोप
> वायरिंग `open-sse/mcp-server/server.ts` मध्ये आहे.

## हे काय आहे

OmniRoute **Notion** कार्यक्षेत्राशी **संदर्भ स्रोत** म्हणून कनेक्ट होऊ शकते — हा एक वाचन/लेखन
ज्ञानसंग्रह आहे, ज्याला एजंट अंगभूत MCP सर्व्हरद्वारे वापरतात. Notion
इंटिग्रेशन टोकन कॉन्फिगर केल्यानंतर, MCP साधने LLM ला पृष्ठे आणि डेटाबेस शोधणे,
पृष्ठावरील सामग्री आणि ब्लॉक ट्री वाचणे, फिल्टर्स/सॉर्ट्ससह डेटाबेस क्वेरी करणे आणि नवीन
ब्लॉक्स जोडणे शक्य करतात — हे सर्व OmniRoute मार्फत प्रॉक्सी केले जाते (पुनर्प्रयत्न, कालबाह्यता आणि त्रुटी वर्गीकरणासह),
त्यामुळे मॉडेल कधीही थेट Notion API वापरत नाही.

हे इंटिग्रेशन अधिकृत Notion REST API वरील एक हलके, अधिक सुरक्षित रॅपर आहे
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`). क्लायंट
(`src/lib/notion/api.ts`) पुढील सुविधा जोडतो:

- `429` आणि `5xx` साठी **एक्स्पोनेन्शियल बॅकऑफसह पुनर्प्रयत्न** (कमाल 3 प्रयत्न).
- `AbortController` द्वारे **55-सेकंदांची विनंती कालबाह्यता**.
- **टाइपयुक्त त्रुटी वर्गीकरण** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  सूचनांचा आदर करते), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- त्रुटी प्रदर्शित करण्यापूर्वी स्टॅक-ट्रेससदृश तुकडे काढून टाकणारे **संदेश निर्जंतुकीकरण**.

## सेटअप

Notion टोकनसाठी **कोणतेही पर्यावरण चल नाही** — ते
`src/lib/db/notion.ts` द्वारे SQLite `key_value` टेबलमध्ये (नेमस्पेस `notion`, की `integration_token`)
संग्रहित केले जाते. Endpoint डॅशबोर्डच्या **Context Sources** टॅबमधून
(`ObsidianSourceCard` च्या शेजारील `NotionSourceCard`) किंवा सेटिंग्ज REST API द्वारे ते कॉन्फिगर करा.

> [!NOTE]
> हे टोकन एक **Notion अंतर्गत इंटिग्रेशन टोकन** आहे. येथे इंटिग्रेशन तयार करा:
> <https://www.notion.com/my-integrations>, त्यानंतर OmniRoute ने वापरावीत अशी पृष्ठे/डेटाबेस
> त्या इंटिग्रेशनसोबत शेअर करा (Notion चे परवानगी मॉडेल शेअरिंगवर आधारित आहे,
> संपूर्ण कार्यक्षेत्रावर नाही).

### REST द्वारे कॉन्फिगर करा

```bash
# इंटिग्रेशन टोकन जतन करा आणि वैधता तपासा (POST चाचणी शोध करून वैधता तपासते)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# कनेक्शनची स्थिती तपासा
curl http://localhost:20128/api/settings/notion

# डिस्कनेक्ट करा (संग्रहित टोकन काढून टाकते)
curl -X DELETE http://localhost:20128/api/settings/notion
```

या तिन्ही पद्धतींसाठी डॅशबोर्ड प्रमाणीकरण (`isAuthenticated`) आवश्यक आहे. `POST` वर,
OmniRoute टोकन जतन करते आणि लगेच 1 परिणामाचा चाचणी शोध चालवते; Notion ने
त्रुटी ऑब्जेक्ट परत केल्यास, टोकन काढून टाकले जाते आणि कॉल `400` सह अयशस्वी होतो.

## MCP साधने (6)

`open-sse/mcp-server/tools/notionTools.ts` मध्ये परिभाषित. कॉलच्या
वेळी `getNotionToken()` द्वारे टोकन मिळवले जाते; कोणतेही टोकन कॉन्फिगर केलेले नसल्यास साधन
`"Notion integration token not configured. Set it in Settings > Context Sources."`
ही त्रुटी दर्शवते.

| साधन                         | स्कोप          | वर्णन                                                                                  |
| ---------------------------- | -------------- | -------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | मजकूर क्वेरीद्वारे पृष्ठे आणि डेटाबेस शोधते (शीर्षके, IDs, URLs परत करते). पृष्ठांकित. |
| `notion_get_page`            | `read:notion`  | पृष्ठाच्या ID द्वारे त्याची सामग्री आणि मेटाडेटा मिळवते.                               |
| `notion_list_block_children` | `read:notion`  | ब्लॉक किंवा पृष्ठाचे सर्व चाइल्ड ब्लॉक्स (ब्लॉक ट्री) सूचीबद्ध करते. पृष्ठांकित.       |
| `notion_query_database`      | `read:notion`  | पर्यायी `filter` + `sorts` सह डेटाबेस क्वेरी करते (Notion API स्वरूप). पृष्ठांकित.     |
| `notion_get_database`        | `read:notion`  | ID द्वारे डेटाबेसची स्कीमा/मेटाडेटा मिळवते.                                            |
| `notion_append_blocks`       | `write:notion` | विद्यमान ब्लॉक किंवा पृष्ठामध्ये चाइल्ड ब्लॉक्स जोडते (प्रति विनंती कमाल 100 ब्लॉक्स). |

### इनपुट पॅरामीटर्स

- `notion_search` — `query` (1–500 अक्षरे), `pageSize` (1–100, डीफॉल्ट 20),
  `startCursor` (पर्यायी).
- `notion_get_page` — `pageId` (32-अक्षरी हेक्स किंवा UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, डीफॉल्ट 50),
  `startCursor` (पर्यायी).
- `notion_query_database` — `databaseId`, `filter` (पर्यायी, Notion फिल्टर स्वरूप),
  `sorts` (पर्यायी अॅरे), `pageSize` (1–100, डीफॉल्ट 50), `startCursor` (पर्यायी).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (ब्लॉक ऑब्जेक्ट्सचा अॅरे),
  `after` (पर्यायी स्थान).

### स्कोप्स

वाचन साधनांसाठी `read:notion` आणि लेखन साधनासाठी `write:notion` आवश्यक आहे.
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` असतानाच
`open-sse/mcp-server/server.ts` मधील `withScopeEnforcement()` द्वारे स्कोप्सची अंमलबजावणी केली जाते;
कॉलरला अनुमत असलेले स्कोप्स `OMNIROUTE_MCP_SCOPES` (स्वल्पविरामाने विभक्त) किंवा
प्रमाणीकृत API कीच्या स्कोप संदर्भातून येतात. संपूर्ण स्कोप मॉडेलसाठी
[MCP-SERVER.md](./MCP-SERVER.md) पहा.

## एंडपॉइंट्स

| पद्धत    | पथ                     | उद्देश                                  |
| -------- | ---------------------- | --------------------------------------- |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` परत करा.      |
| `POST`   | `/api/settings/notion` | इंटिग्रेशन टोकन जतन करा + सत्यापित करा. |
| `DELETE` | `/api/settings/notion` | डिस्कनेक्ट करा (संग्रहित टोकन हटवा).    |

> हे डॅशबोर्ड सेटिंग्जचे रूट्स आहेत. कोणताही सार्वजनिक `/v1` Notion प्रॉक्सी
> एंडपॉइंट **नाही** — Notion मध्ये केवळ वरील MCP टूल्सद्वारे प्रवेश केला जातो.

## वापराची प्रकरणे

- **ज्ञानावर आधारित उत्तरे** — उत्तर देण्यापूर्वी एजंटला वर्कस्पेसमध्ये `notion_search` करू द्या आणि
  सर्वोत्तम परिणामावर `notion_get_page` वापरू द्या, जेणेकरून प्रतिसादांमध्ये वास्तविक अंतर्गत दस्तऐवजांचे संदर्भ दिले जातील.
- **डेटाबेस-आधारित कार्यप्रवाह** — फिल्टर्स + सॉर्ट्ससह कार्ये/CRM डेटाबेसवर
  `notion_query_database` वापरा, त्यानंतर पंक्तींचा सारांश द्या किंवा त्यांचे प्राधान्यक्रम ठरवा.
- **परत लेखन / लॉगिंग** — मीटिंगच्या नोंदी, रनचे सारांश किंवा एजंटचे आउटपुट
  विद्यमान पृष्ठावर जोडण्यासाठी `notion_append_blocks` वापरा (केवळ जोडणे; कोणतीही विनाशकारी संपादने नाहीत).
- **संरचनेचा शोध** — पृष्ठाच्या ब्लॉक ट्रीमधून जाण्यासाठी `notion_list_block_children`
  किंवा डेटाबेसची चौकशी करण्यापूर्वी त्याचा प्रॉपर्टी स्कीमा शोधण्यासाठी `notion_get_database` वापरा.
