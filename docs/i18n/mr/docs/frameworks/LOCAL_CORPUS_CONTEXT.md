> `src/app/api/settings/local-corpus/route.ts` (सेटिंग्ज API).

## हे काय आहे

Local Corpus ऑपरेटरला मजकूर फाइल्सची स्पष्टपणे मंजूर केलेली एक निर्देशिका
OmniRoute च्या MCP सर्व्हरसाठी उपलब्ध करून देण्याची सुविधा देते. फाइल्स त्यांच्या मूळ निर्देशिकेतच राहतात: OmniRoute फक्त
कॅनॉनिकल रूट पाथ SQLite मध्ये संग्रहित करते आणि इन-मेमरी शोध अनुक्रमणिका राखते. ते
कॉर्पसची सामग्री रिपॉझिटरी किंवा डेटाबेसमध्ये कॉपी करत नाही.

अनुक्रमणिका रीफ्रेश क्रमवर्धित पद्धतीने होते. न बदललेल्या फाइल्सचा आकार आणि सुधारित
वेळ यांच्या आधारे पुनर्वापर केला जातो, बदललेल्या फाइल्स पुन्हा वाचून SHA-256 ने हॅश केल्या जातात आणि हटवलेल्या फाइल्स काढून टाकल्या जातात.
30 सेकंदांपेक्षा जुनी अनुक्रमणिका शोधादरम्यान रीफ्रेश केली जाते; कॉलर तत्काळ
रीफ्रेशची विनंतीही करू शकतात.

## स्रोत कॉन्फिगर करा

सेटिंग्ज रूटसाठी इतर सेटिंग्ज API प्रमाणेच व्यवस्थापन प्रमाणीकरण आवश्यक आहे.
सबमिट केलेला पाथ आधीपासून अस्तित्वात असला पाहिजे आणि तो निरपेक्ष निर्देशिका पाथ असला पाहिजे.

```bash
# मंजूर निर्देशिका कनेक्ट करा
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# कॉन्फिगरेशन आणि अनुक्रमणिका स्थिती तपासा
curl http://localhost:20128/api/settings/local-corpus

# स्रोत फाइल्स न बदलता डिस्कनेक्ट करा
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP साधने

तिन्ही साधनांसाठी `read:local-corpus` आवश्यक आहे. साधनांचे प्रतिसाद सापेक्ष पाथ आणि
रूट निर्देशिकेचे बेसनेम उघड करतात, तिचा निरपेक्ष पाथ कधीही उघड करत नाहीत.

| साधन                  | वर्णन                                                                              |
| :-------------------- | :--------------------------------------------------------------------------------- |
| `local_corpus_status` | कॉन्फिगरेशन स्थिती, अनुक्रमणिकेचा आकार, मर्यादा आणि शेवटच्या रीफ्रेशची वेळ नोंदवते |
| `local_corpus_search` | अनुक्रमित मजकूर शोधते आणि मर्यादित, ओळ-व्याप्तीतील उतारे परत करते (कमाल 20 परिणाम) |
| `local_corpus_read`   | परवानगी असलेल्या एका कॉर्पस-सापेक्ष फाइलमधून मर्यादित ओळ-व्याप्ती वाचते            |

MCP इनपुटची उदाहरणे:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## सुरक्षिततेच्या सीमा

- अनुमतीसूची मजकूर-केंद्रित आहे: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, आणि `.yml`.
- सिमलिंक्स वगळल्या जातात. वाचन पाथ कॅनॉनिकल केले जातात आणि कॉन्फिगर केलेल्या
  रूटमध्येच राहिले पाहिजेत; निरपेक्ष पाथ आणि ट्रॅव्हर्सल प्रयत्न नाकारले जातात.
- संवेदनशील आणि व्युत्पन्न निर्देशिका नावे वगळली जातात: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, आणि
  `secrets`.
- डीफॉल्ट मर्यादा 5,000 फाइल्स, प्रति फाइल 1 MiB, एकूण अनुक्रमित सामग्री 64 MiB,
  प्रति शोध खंड अंदाजे 4,000 वर्ण आणि प्रति वाचन 400 ओळी आहेत.
- NUL असलेल्या फाइल्सना गैर-मजकूर मानले जाते आणि त्या वगळल्या किंवा नाकारल्या जातात.

PDF, DOCX, प्रतिमा आणि संग्रहणांसारखे बायनरी दस्तऐवज हेतुपुरस्सर समर्थित नाहीत.
अनुक्रमित करण्यापूर्वी त्यांना कॉन्फिगर केलेल्या निर्देशिकेतील मंजूर मजकूर स्वरूपात रूपांतरित करा.

## कार्यान्वयनविषयक नोंदी

- कॉन्फिगर केलेला रूट बदलल्यास किंवा हटवल्यास सामायिक इन-मेमरी अनुक्रमणिका साफ होते.
- प्रक्रिया रीस्टार्ट केल्यावर अनुक्रमणिका नष्ट होते; पुढील शोध ती कॉन्फिगर केलेल्या
  स्रोतापासून पुन्हा तयार करतो.
- `local_corpus_status` सक्तीने स्कॅन करत नाही. तत्काळ पुनर्स्कॅन आवश्यक असल्यास
  `refresh: true` सह `local_corpus_search` वापरा.
- स्कॅन आणि वाचनातील अपयशांची मोजणी केली जाते किंवा ती निर्जंतुक केलेल्या त्रुटींच्या स्वरूपात परत केली जातात; स्रोत फाइल्स
  कधीही बदलल्या जात नाहीत.
