> **सत्याचा अधिकृत स्रोत:** `src/lib/agentSkills/` (कॅटलॉग, जनरेटर, पार्सर्स) + `skills/` डिरेक्टरी (SKILL.md फाइल्स)
> **शेवटचे अद्यतन:** 2026-08-02 — v3.8.50

Agent Skills या संरचित SKILL.md फाइल्स आहेत, ज्या बाह्य एजंट्स, MCP क्लायंट्स आणि A2A ऑर्केस्ट्रेटर्सना OmniRoute चे REST API आणि CLI कसे वापरायचे हे शिकवतात. [Omni Skills](./SKILLS.md) (ज्या OmniRoute मध्ये कार्यान्वित केल्या जाणाऱ्या LLM साधनांच्या व्याख्या आहेत) यांच्या विपरीत, Agent Skills हा एक _दस्तऐवजीकरण कॅटलॉग_ आहे — स्थिर markdown जो थेट एजंटच्या संदर्भात पुरवता येतो.

---

## आढावा

कॅटलॉगमध्ये **45 Agent Skills** आहेत (23 REST API + 21 CLI + 1 कॉन्फिगरेशन कार्यप्रवाह). प्रत्येक कौशल्यामध्ये पुढील गोष्टी असतात:

- एक **अधिकृत ID** (`omni-auth`, `cli-serve`, इ.)
- `skills/{id}/SKILL.md` मधील YAML फ्रंटमॅटर (`name`, `description`) + समृद्ध markdown मजकूर असलेली एक **SKILL.md** फाइल
- OpenAPI स्पेसिफिकेशन आणि CLI रजिस्ट्रीमधून व्युत्पन्न केलेले **REST एंडपॉइंट्स** (API कौशल्ये) किंवा **CLI सबकमांड्स** (CLI कौशल्ये)
- थेट प्राप्तीसाठी एक **GitHub रॉ URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API शोध

| एंडपॉइंट                     | पद्धत | वर्णन                                                            | प्रमाणीकरण |
| :--------------------------- | :---- | :--------------------------------------------------------------- | :--------- |
| `/api/agent-skills`          | GET   | कॅटलॉगची सूची (`?category=api\|cli\|config&area=<area>` पर्यायी) | नाही       |
| `/api/agent-skills/{id}`     | GET   | एका कौशल्याचा मेटाडेटा मिळवा                                     | नाही       |
| `/api/agent-skills/{id}/raw` | GET   | SKILL.md हे `text/markdown` म्हणून मिळवा                         | नाही       |
| `/api/agent-skills/coverage` | GET   | व्याप्तीची आकडेवारी (किती SKILL.md फाइल्स अस्तित्वात आहेत)       | नाही       |
| `/api/agent-skills/generate` | POST  | जनरेटर ट्रिगर करा (dryRun/prune/onlyIds)                         | व्यवस्थापन |

उदाहरण — सर्व API कौशल्यांची सूची:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

उदाहरण — एक SKILL.md मिळवा:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## A2A शोध

A2A कौशल्य `list-capabilities` संपूर्ण 45-कौशल्यांचा कॅटलॉग मार्कडाउन तक्ता आर्टिफॅक्ट म्हणून परत करते. बाह्य ऑर्केस्ट्रेटर्स ते याद्वारे कार्यान्वित करू शकतात:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "सर्व क्षमता सूचीबद्ध करा" }]
  }
}
```

प्रोटोकॉलच्या तपशीलांसाठी [A2A-SERVER.md](./A2A-SERVER.md) पहा.

## बाह्य एजंट्स कौशल्ये कशी वापरतात

### 1. REST द्वारे शोध

```bash
# संपूर्ण कॅटलॉग मिळवा
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# संदर्भ अंतर्भूत करण्यासाठी SKILL.md मिळवा
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP द्वारे शोध

```typescript
// Claude Desktop / Cursor MCP क्लायंटमध्ये:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → प्रत्येकासाठी rawUrl असलेला AgentSkill चा अॅरे
```

### 3. A2A द्वारे शोध

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table ही सर्व 45 कौशल्य ID आणि rawUrl स्तंभ असलेली markdown सारणी आहे
```

### 4. थेट GitHub raw प्राप्ती (सर्व्हरची आवश्यकता नाही)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## जनरेटर

जनरेटर व्यवस्थापित कॅटलॉग + OpenAPI तपशील + CLI रजिस्ट्री वाचतो आणि प्रत्येक नोंदीसाठी `skills/{id}/SKILL.md` लिहितो:

```bash
# पूर्वावलोकन (dry run, काहीही लिहिले जात नाही)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# संपूर्ण पुनर्निर्मिती
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# विशिष्ट ID पुन्हा निर्माण करा
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

जनरेटरचा प्रतिसाद हा `GeneratorReport` असतो:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
