> `src/lib/obsidianSync.ts` (WebDAV व्हॉल्ट सिंक), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP साधने), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (सेटिंग्ज API). साधन नोंदणी
> आणि स्कोप वायरिंग `open-sse/mcp-server/server.ts` मध्ये आहे.

## हे काय आहे

OmniRoute **Obsidian** व्हॉल्टशी **संदर्भ स्रोत** म्हणून जोडले जाते — हा एक स्थानिक Markdown
ज्ञानसंग्रह आहे, जो एजंट अंगभूत MCP सर्व्हरद्वारे वाचतात आणि त्यात लिहितात. हे
एकत्रीकरण डेस्कटॉप ॲपमध्ये चालणाऱ्या समुदायाच्या **Obsidian Local REST API** प्लगइनशी
संवाद साधते, ज्यामुळे एजंट नोट्स शोधू शकतात, फायली वाचू/लिहू/पॅच करू शकतात, व्हॉल्टची
सूची पाहू शकतात, दैनिक/साप्ताहिक नियतकालिक नोट्ससह काम करू शकतात, टॅग व्यवस्थापित
करू शकतात, Obsidian कमांड चालवू शकतात आणि (पर्यायाने) द्विदिशात्मक डेस्कटॉप↔मोबाइल
व्हॉल्ट सिंकचे समन्वयन करू शकतात.

क्लायंट (`src/lib/obsidian/api.ts`) Local REST API भोवती पुढील सुविधा प्रदान करतो:

- तात्पुरत्या `5xx` त्रुटींसाठी **बॅकऑफसह पुनर्प्रयत्न**, `AbortController` द्वारे **30-सेकंदांची कालमर्यादा**.
- **टाइप केलेले त्रुटी वर्गीकरण** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **"Obsidian शी संपर्क साधता येत नाही" अशी सोपी सूचना**, जी पोर्टशी संबंधित सामान्य
  चूक स्पष्ट करते (HTTP `27123` वर, `27124` वरील MCP एंडपॉइंटवर **नाही**) आणि Tailscale स्वरूप सांगते.
- नोट पाथमधील स्पेसेस/स्लॅश सुरक्षित राहण्यासाठी व्हॉल्ट-सापेक्ष **पाथ एन्कोडिंग**.

## सेटअप

Obsidian टोकन किंवा बेस URL साठी **कोणतेही एन्व्हायर्नमेंट व्हेरिएबल नाही** — दोन्ही
`src/lib/db/obsidian.ts` द्वारे SQLite `key_value` टेबलमध्ये (`obsidian` नेमस्पेस)
साठवले जातात. टोकन **संचयित स्थितीत एन्क्रिप्ट केलेले** असते (AES-256-GCM, प्लेनटेक्स्ट
बॅकवर्ड-कंपॅटिबिलिटी फॉलबॅकसह). Endpoint डॅशबोर्डच्या **Context Sources** टॅबमधून
(`ObsidianSourceCard`) किंवा सेटिंग्ज REST API द्वारे कॉन्फिगर करा.

> [!IMPORTANT]
> **Obsidian Local REST API** प्लगइन स्थापित आणि चालू असणे आवश्यक आहे. त्याचा REST
> इंटरफेस **HTTP `127.0.0.1:27123`** वर ऐकतो (डीफॉल्ट बेस URL). पोर्ट `27124`
> हा एक _स्वतंत्र_ MCP/HTTPS एंडपॉइंट आहे आणि सेटिंग्ज रूटद्वारे तो स्पष्टपणे नाकारला जातो.
> दुसऱ्या डिव्हाइसवरून जोडत असल्यास, `http://<tailscale-ip>:27123` वापरा.

### कॉन्फिगरेशन की (SQLite `key_value`, नेमस्पेस `obsidian`)

| की                | उद्देश                                               | एन्क्रिप्ट केलेले |
| ----------------- | ---------------------------------------------------- | ----------------- |
| `api_key`         | Local REST API बेअरर टोकन                            | हो                |
| `base_url`        | REST बेस URL (डीफॉल्ट `http://127.0.0.1:27123`)      | नाही              |
| `vault_path`      | व्हॉल्ट डायरेक्टरीचा अॅब्सोल्यूट पाथ (सिंकसाठी)      | नाही              |
| `webdav_username` | व्युत्पन्न केलेले WebDAV वापरकर्तानाव (व्हॉल्ट सिंक) | नाही              |
| `webdav_password` | व्युत्पन्न केलेला WebDAV पासवर्ड (व्हॉल्ट सिंक)      | हो                |
| `webdav_enabled`  | WebDAV व्हॉल्ट सिंक सक्षम आहे की नाही                | नाही              |

### REST द्वारे कॉन्फिगर करा

```bash
# Local REST API टोकन जतन करा + प्रमाणित करा (POST स्थिती तपासणीद्वारे प्रमाणित करते)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# कनेक्शनची स्थिती तपासा (connected, hasToken, baseUrl, vaultPath परत करते)
curl http://localhost:20128/api/settings/obsidian

# डिस्कनेक्ट करा (साठवलेले टोकन काढून टाकते)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

सर्व पद्धतींसाठी डॅशबोर्ड प्रमाणीकरण आवश्यक आहे. `POST` पोर्ट `27124` वरील कोणताही URL
नाकारते आणि माहिती साठवण्यापूर्वी Local REST API स्थिती एंडपॉइंटला कॉल करून टोकन प्रमाणित करते.

### WebDAV व्हॉल्ट सिंक

`src/app/api/settings/obsidian/webdav/route.ts`, `src/lib/obsidianSync.ts` द्वारे
चालवल्या जाणाऱ्या पर्यायी WebDAV-आधारित व्हॉल्ट सिंकचे व्यवस्थापन करते. ते सक्षम
केल्यावर OmniRoute स्थानिक व्हॉल्ट डायरेक्टरीकडे निर्देशित होते आणि यादृच्छिक WebDAV
वापरकर्तानाव/पासवर्ड जोडी तयार करते:

```bash
# व्हॉल्ट डायरेक्टरीसाठी WebDAV सिंक सक्षम करा (वापरकर्तानाव/पासवर्ड तयार करते)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV सिंकची स्थिती मिळवा (क्रेडेन्शियल्स फक्त सक्षम असतानाच परत केली जातात)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV सिंक अक्षम करा (क्रेडेन्शियल्स + व्यवस्थापित .stignore काढून टाकते)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### प्रत्येक API कीसाठी संदर्भ स्रोत (पर्यायी)

Obsidian कॉन्फिग `api_key_context_sources` टेबलद्वारे **प्रत्येक API कीनुसार**
स्कोप केले जाऊ शकते (`src/lib/db/apiKeyContextSources.ts`). MCP कॉलमध्ये प्रमाणित API
की आयडी असल्यास, `getObsidianConfigForApiKey()` त्या कीचे स्वतःचे टोकन/बेस-URL/व्हॉल्ट-पाथ
(`source: "api_key"`) प्राधान्याने वापरते; अन्यथा ग्लोबल कॉन्फिगवर (`source: "global"`)
फॉलबॅक करते.

## MCP साधने (22)

`open-sse/mcp-server/tools/obsidianTools.ts` मध्ये परिभाषित केली आहेत. token/base-URL प्रत्येक कॉलसाठी निर्धारित केले जातात (प्रथम प्रति-API-key, त्यानंतर जागतिक). OmniRoute **sync server** वापरणाऱ्या साधनांना (चार `obsidian_sync_*` साधने) OmniRoute सेटिंग्जमध्ये कॉन्फिगर केलेले sync auth token देखील आवश्यक आहे.

### वाचन साधने (`read:obsidian`)

| साधन                         | वर्णन                                                                                |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Local REST API पोहोचण्यायोग्य आणि प्रमाणीकृत आहे का ते तपासा.                        |
| `obsidian_search_simple`     | टिपांच्या मजकुराचा पूर्ण-मजकूर शोध; फाइल पथांसह उतारे परत करते.                      |
| `obsidian_search_structured` | JSON Logic expression (and/or/regex/path filters) वापरून शोधा.                       |
| `obsidian_read_note`         | vault-सापेक्ष पथाद्वारे टिपण वाचा; पर्यायाने विशिष्ट heading/block/frontmatter वाचा. |
| `obsidian_list_vault`        | vault मधील फाइल्स आणि निर्देशिका सूचीबद्ध करा (नोंदींचे tree).                       |
| `obsidian_get_document_map`  | टिपणाची heading संरचना headings → line numbers या नकाशाच्या स्वरूपात मिळवा.          |
| `obsidian_get_note_metadata` | संपूर्ण मजकुराशिवाय frontmatter, tags, links, char/word count मिळवा.                 |
| `obsidian_get_active_file`   | Obsidian मध्ये सध्या सक्रिय असलेल्या फाइलचा path + content मिळवा.                    |
| `obsidian_get_periodic_note` | एखाद्या तारखेसाठी daily/weekly/monthly periodic note मिळवा (वगळल्यास आजची तारीख).    |
| `obsidian_get_tags`          | vault मधील सर्व tags त्यांच्या वारंवारतेसह सूचीबद्ध करा.                             |
| `obsidian_list_commands`     | उपलब्ध Obsidian command IDs सूचीबद्ध करा (`obsidian_execute_command` सोबत वापरा).    |
| `obsidian_sync_status`       | OmniRoute sync server स्थिती: चालू आहे का, vault चे नाव, port, uptime, शेवटचा sync.  |
| `obsidian_sync_conflicts`    | निराकरण न झालेले sync conflicts सूचीबद्ध करा (path, conflict path, detected-at).     |

### लेखन साधने (`write:obsidian`)

| साधन                             | वर्णन                                                                                      |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| `obsidian_write_note`            | दिलेल्या Markdown मजकुरासह टिपण तयार करा किंवा त्यावर अधिलेखन करा.                         |
| `obsidian_append_note`           | टिपणात मजकूर जोडा; पर्यायाने विशिष्ट heading/block मध्ये.                                  |
| `obsidian_patch_note`            | heading, block किंवा frontmatter field येथे नेमकेपणाने मजकूर जोडा/आधी जोडा/बदला.           |
| `obsidian_delete_note`           | vault मधून टिपण कायमचे हटवा.                                                               |
| `obsidian_move_note`             | vault मध्ये टिपण हलवा किंवा त्याचे नाव बदला.                                               |
| `obsidian_execute_command`       | Obsidian command त्याच्या command ID द्वारे कार्यान्वित करा.                               |
| `obsidian_open_file`             | Obsidian मध्ये फाइल उघडा (ती अस्तित्वात नसल्यास तयार करते).                                |
| `obsidian_sync_trigger`          | तत्काळ द्विदिशात्मक desktop↔mobile vault sync सुरू करा.                                    |
| `obsidian_sync_resolve_conflict` | sync conflict चे निराकरण करा: `local` (mobile), `remote` (desktop) किंवा `keep-both` ठेवा. |

> [!NOTE]
> `obsidian_patch_note` targets मध्ये `targetType` म्हणून `heading | block | frontmatter`
> आणि `operation` म्हणून `append | prepend | replace` स्वीकारले जातात, तसेच पर्यायी
> `createTargetIfMissing` असते. चार `obsidian_sync_*` साधने स्थानिक sync
> server शी संवाद साधतात (डीफॉल्टनुसार `http://127.0.0.1:27781`) आणि त्यांना sync token आवश्यक आहे.

### Scopes

वाचन साधनांना `read:obsidian` आवश्यक आहे; लेखन साधनांना `write:obsidian` आवश्यक आहे. अंमलबजावणी
Notion प्रमाणेच आहे — ती `open-sse/mcp-server/server.ts` मधील `withScopeEnforcement()` द्वारे
हाताळली जाते, `OMNIROUTE_MCP_ENFORCE_SCOPES=true` वर नियंत्रित केली जाते आणि अनुमत scopes
`OMNIROUTE_MCP_SCOPES` किंवा API key च्या scope context मधून घेतले जातात. पहा
[MCP-SERVER.md](./MCP-SERVER.md).

| `GET`    | `/api/settings/obsidian`        | `{ connected, hasToken, baseUrl, vaultPath }` परत करणे.    |
| `POST`   | `/api/settings/obsidian`        | टोकन जतन करणे + वैधता तपासणे (`27124` पोर्ट नाकारला जातो). |
| `DELETE` | `/api/settings/obsidian`        | डिस्कनेक्ट करणे (संग्रहित टोकन साफ करणे).                  |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV समक्रमणाची स्थिती + क्रेडेन्शियल्स (सक्षम असताना).  |
| `POST`   | `/api/settings/obsidian/webdav` | व्हॉल्ट डायरेक्टरीसाठी WebDAV समक्रमण सक्षम करणे.          |
| `DELETE` | `/api/settings/obsidian/webdav` | WebDAV समक्रमण अक्षम करणे.                                 |

> हे डॅशबोर्ड सेटिंग्जचे रूट्स आहेत. व्हॉल्टमध्ये प्रवेश Obsidian
> Local REST API (कॉन्फिगर केलेले `base_url`) आणि वरील MCP साधनांद्वारे केला जातो —
> कोणताही सार्वजनिक `/v1` Obsidian प्रॉक्सी एंडपॉइंट नाही.

## उपयोगाची उदाहरणे

- **व्हॉल्ट-आधारित उत्तरे** — `obsidian_search_simple` / `obsidian_search_structured`
  आणि त्यानंतर `obsidian_read_note`, जेणेकरून एजंट तुमच्या वास्तविक नोट्सच्या आधारे उत्तर देईल.
- **नोट लेखन / दैनंदिनी लेखन** — एजंटचे आउटपुट, सारांश किंवा दैनिक नोट्स
  (`obsidian_get_periodic_note`) व्हॉल्टमध्ये नोंदवण्यासाठी `obsidian_write_note`, `obsidian_append_note` किंवा
  अचूक बदलांसाठी `obsidian_patch_note`.
- **व्हॉल्ट नेव्हिगेशन** — वाचन/लेखनापूर्वी संरचना एक्सप्लोर करण्यासाठी
  `obsidian_list_vault`, `obsidian_get_document_map` आणि `obsidian_get_tags`.
- **Obsidian ऑटोमेशन** — एजंटद्वारे प्लगइन/कमांड्स चालवण्यासाठी
  `obsidian_list_commands` + `obsidian_execute_command`; UI मध्ये नोट उघडण्यासाठी `obsidian_open_file`.
- **मोबाइल समक्रमण** — WebDAV समक्रमण सक्षम करा, त्यानंतर डेस्कटॉप↔मोबाइल समन्वयित करण्यासाठी आणि संघर्ष सोडवण्यासाठी
  `obsidian_sync_trigger` / `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`.
