## आढावा

Playground Studio हे `/dashboard/playground` चे रूपांतर साध्या Monaco-आधारित एडिटरमधून
सर्वसमावेशक चाचणी कार्यक्षेत्रात करते. हे जुन्या `page.tsx` च्या जागी चार टॅब आणि एक सामायिक कॉन्फिगरेशन पेन रेंडर करणारे `PlaygroundStudio`
शेल वापरते.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 चॅट] [⚖ तुलना] [{} API] [🔧 बिल्ड]       142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {सक्रिय टॅबची सामग्री}                 │ ─ कॉन्फिगरेशन            │
│                                          │ एंडपॉइंट  [chat ∨]        │
│                                          │ मॉडेल     [gpt-5.4 ∨]     │
│                                          │ सिस्टम    [मजकूर क्षेत्र] │
│                                          │ तापमान    ▕▕▔▔ 0.7        │
│                                          │ प्रीसेट [▾ लोड][जतन]      │
│                                          │ [✨ प्रॉम्प्ट सुधारा]      │
└──────────────────────────────────────────┴───────────────────────────┘
```

## टॅब

### चॅट टॅब

`ChatPlayground.tsx` ला मल्टी-टर्न स्ट्रीमिंग कार्यपीठात विकसित करते:

- `MarkdownMessage.tsx` द्वारे संपूर्ण markdown रेंडरिंग (कोड ब्लॉक, तक्ते, याद्या, दुवे).
- सामायिक कॉन्फिगरेशन पेनमधून घेतलेला सिस्टम प्रॉम्प्ट.
- प्रत्येक संदेशासाठी टोकन/खर्च (प्रॉम्प्ट + पूर्णता टोकन).
- शेवटचा प्रतिसाद पुन्हा निर्माण करण्याची सुविधा.
- SSE स्ट्रीमिंगसह `POST /v1/chat/completions` कडे पाठवते.

### तुलना टॅब

प्रॉक्सीसाठी मुख्य वैशिष्ट्य: एक प्रॉम्प्ट एकाच वेळी जास्तीत जास्त **4 मॉडेलवर समांतरपणे** चालवा.

- जास्तीत जास्त 4 स्तंभ, प्रत्येक स्तंभ `/v1/chat/completions` मधून स्वतंत्रपणे स्ट्रीम करतो.
- स्तंभ जोडण्यासाठी `+ मॉडेल जोडा` बटण (Cmd+K शॉर्टकट).
- `सर्व चालवा ▶` हे `Promise.all` + प्रत्येक स्तंभासाठी स्वतंत्र `AbortController` वापरून सर्व स्ट्रीम एकाच वेळी सुरू करते.
- जागतिक **सर्व रद्द करा** क्रिया प्रगतीपथावर असलेले प्रत्येक स्ट्रीम रद्द करते.
- प्रत्येक स्तंभातील `ProviderMetrics` हे TTFT, TPS, टोकन आणि अंदाजित खर्च रिअल टाइममध्ये दाखवते.
- मेट्रिक्सना **"क्लायंट-साइड अंदाज"** (D12) असे लेबल दिलेले आहे — पहिल्या SSE चंकपासून मोजले जाते.

### API टॅब

प्रगत वापरकर्त्यांसाठी मूळ Monaco एडिटरची 100% कार्यक्षमता जतन करते (D14):

- 10 एंडपॉइंट: चॅट पूर्णता, पूर्णता, एम्बेडिंग्ज, प्रतिमा, ऑडिओ, स्पीच, ट्रान्सक्रिप्शन, मॉडरेशन, रीरँक, शोध.
- मल्टिमोडल फाइल अपलोड.
- रिअल-टाइम आउटपुटसह SSE स्ट्रीमिंग.
- `ApiTab.tsx` म्हणून रॅप केलेले (लेझी-लोडेड, `ssr: false`).

### बिल्ड टॅब

टूल्स/फंक्शन कॉलिंग आणि संरचित आउटपुट UI:

- `ToolsBuilder.tsx` — प्रत्येक टूलसाठी JSON स्कीमा एडिटरसह `tools[]` जोडा/संपादित करा/काढून टाका.
  `ToolDefinitionSchema` (Zod) द्वारे पॅरामीटर्सचे प्रमाणीकरण करते.
- `StructuredOutputEditor.tsx` — JSON मोड टॉगल + JSON स्कीमा एडिटर.
  `StructuredOutputSchema` (Zod) द्वारे स्कीमाशी प्रतिसादाचे प्रमाणीकरण करते.
- `tools[]` आणि/किंवा `response_format` सह विनंती `/v1/chat/completions` कडे पाठवते.

## प्रॉम्प्ट सुधारक

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. मोडल "कोटा वापरला जाईल" असा इशारा देते.
2. पुष्टी केल्यावर, रूटकडे `{ system, prompt, model, tone }` पाठवते.
3. रूट अंतर्गतरीत्या `promptImprover.META_SYSTEM_PROMPT` सह `/v1/chat/completions` ला कॉल करतो.
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` परत करतो.
5. UI, कॉन्फिग पेनमधील सिस्टम प्रॉम्प्ट आणि Chat टॅबमधील वापरकर्ता प्रॉम्प्ट पॅच करते.

## प्रीसेट्स

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- `playground_presets` SQLite तक्त्यात साठवले जातात (मायग्रेशन `084_playground_presets.sql`).
- प्रत्येक प्रीसेटमध्ये हे साठवले जाते: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: `GET` यादी, `POST` तयार करणे, `GET /:id`, `PUT /:id`, `DELETE /:id`.

## स्ट्रीम मेट्रिक्स

`useStreamMetrics.ts` + `streamMetrics.ts` (शुद्ध फंक्शन):

- `start()` — विनंती सुरू होण्याची वेळ नोंदवते.
- `onFirstChunk()` — TTFT नोंदवते.
- `onChunk(n)` — पूर्णत्व टोकनची संख्या एकत्रित करते.
- `finish(usage?)` — अंतिम मेट्रिक्स मोजते: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- किंमत `src/lib/playground/types.ts` मधील स्थिर तक्त्यातून घेतली जाते ("अंदाजित" असे लेबल केलेले — D13).
