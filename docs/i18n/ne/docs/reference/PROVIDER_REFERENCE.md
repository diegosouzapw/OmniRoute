## श्रेणीहरू

- **निःशुल्क** — API key सहितको निःशुल्क तह (dashboard मार्फत कन्फिगर गरिने)
- **प्रमाणीकरणरहित** — कुनै key वा sign-in नै आवश्यक नपर्ने सार्वजनिक endpoints
- **OAuth** — OmniRoute द्वारा व्यवस्थापन गरिने sign-in प्रक्रिया, API key आवश्यक पर्दैन
- **वेब cookie** — cookie auth मार्फत प्रदायकको web app लाई आवरण गर्छ
- **API key** — API key मार्फत कन्फिगर गरिने सशुल्क प्रदायक (निःशुल्क credits लागू हुन सक्छन्)
- **स्थानीय** — प्रयोगकर्ताको machine मा चल्छ (Ollama, LM Studio, vLLM, आदि)
- **खोज** — वेब खोज प्रदायकहरू
- **अडियो** — अडियो-मात्र प्रदायकहरू (TTS/STT)
- **Upstream proxy** — अन्य प्रदायकहरूमा proxy गर्ने प्रदायकहरू
- **Cloud agent** — लामो समयसम्म चल्ने coding agents (Codex Cloud, Devin, Jules)
- **प्रणाली** — OmniRoute-का आन्तरिक प्रदायकहरू (loopback, आदि)

अतिरिक्त tags: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`।

`Tool calling` (देखाइएको ठाउँमा): `native` — वास्तविक function-calling API; `emulated` — `tools` array लाई `webTools.ts` मार्फत prompt-emulate गरिन्छ (regex द्वारा parse गरिएका `<tool>{...}</tool>` blocks); `none` — हाल `tools` लाई कुनै सूचना नदिई हटाइन्छ। #7286 हेर्नुहोस्।

प्रत्येक प्रदायकलाई सक्षम, कन्फिगर र परीक्षण गर्न `/dashboard/providers` मा रहेको dashboard प्रयोग गर्नुहोस्।
