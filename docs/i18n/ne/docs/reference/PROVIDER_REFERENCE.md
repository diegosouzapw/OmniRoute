## श्रेणीहरू

- **नि:शुल्क** — API कुञ्जी सहितको नि:शुल्क टियर (ड्यासबोर्ड मार्फत कन्फिगर गरिएको)
- **प्रमाणीकरण-रहित** — सार्वजनिक एन्डपोइन्टहरू जसलाई कुनै कुञ्जी वा साइन-इन आवश्यक पर्दैन
- **OAuth** — OmniRoute द्वारा ह्यान्डल गरिएको साइन-इन प्रवाह, कुनै API कुञ्जी आवश्यक पर्दैन
- **वेब कुकी** — कुकी प्रमाणीकरण मार्फत प्रदायकको वेब एपलाई समेट्छ
- **API कुञ्जी** — API कुञ्जी मार्फत कन्फिगर गरिएको सशुल्क प्रदायक (नि:शुल्क क्रेडिटहरू लागू हुन सक्छन्)
- **स्थानीय** — प्रयोगकर्ताको मेसिनमा चल्छ (Ollama, LM Studio, vLLM, आदि)
- **खोज** — वेब खोज प्रदायकहरू
- **अडियो** — अडियो-मात्र प्रदायकहरू (TTS/STT)
- **अपस्ट्रिम प्रोक्सी** — अन्य प्रदायकहरूमा प्रोक्सी गर्ने प्रदायकहरू
- **क्लाउड एजेन्ट** — लामो समयसम्म चल्ने कोडिङ एजेन्टहरू (Codex Cloud, Devin, Jules)
- **प्रणाली** — OmniRoute-आन्तरिक प्रदायकहरू (लूपब्याक, आदि)

थप ट्यागहरू: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`।

`टूल कलिङ` (जहाँ देखाइएको छ): `native` — वास्तविक प्रकार्य-कलिङ API; `emulated` — `tools` एरे `webTools.ts` मार्फत प्रम्प्ट-इम्युलेट गरिएको छ (रेगेक्स-पार्स गरिएको `<tool>{...}</tool>` ब्लकहरू); `none` — `tools` हाल चुपचाप हटाइएको छ। #7286 हेर्नुहोस्।

प्रत्येक प्रदायकलाई सक्षम पार्न, कन्फिगर गर्न र परीक्षण गर्न `/dashboard/providers` मा रहेको ड्यासबोर्ड प्रयोग गर्नुहोस्।
