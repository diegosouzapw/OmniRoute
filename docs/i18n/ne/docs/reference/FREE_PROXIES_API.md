OmniRoute ले `free_proxies` तालिकामा निःशुल्क प्रोक्सीहरूको चयनित समूह उपलब्ध गराउँछ,
जुन बाह्य प्रदायकहरू (1proxy, proxifly, iplocate, webshare) बाट समक्रमण गरिन्छ। ड्यासबोर्डले
यी प्रोक्सीहरूलाई **सेटिङहरू → निःशुल्क प्रोक्सीहरू** अन्तर्गत देखाउँछ। यस दस्तावेजले सूची रुटले
उपलब्ध गराउने सर्भर-साइड फिल्टरिङ, क्रमबद्धता, गणना र समक्रमण-त्रुटि रिपोर्टिङलाई समेट्छ।

## सूची रुट — `GET /api/settings/free-proxies`

फिल्टर गरिएको, क्रमबद्ध र पृष्ठाङ्कित अंशका साथै कुल सङ्ख्या फर्काउँछ। फिल्टरिङ र
गणना SQL मै गरिन्छ, त्यसैले UI ले प्रत्येक पङ्क्तिलाई मेमोरीमा लोड नगरी वास्तविक कुल सङ्ख्या (जस्तै `कुल: 0`)
देखाउन सक्छ।

### क्वेरी प्यारामिटरहरू

| प्यारामिटर        | प्रकार                             | पूर्वनिर्धारित | अर्थ                                                                                                                          |
| ----------------- | ---------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `search`          | स्ट्रिङ                            | `""`           | होस्ट (र स्रोत) स्तम्भमा केस-संवेदनशील `LIKE`।                                                                                |
| `protocol`        | स्ट्रिङ                            | `""`           | `type` फिल्टर: `http` / `https` / `socks4` / `socks5`। खाली = सबै।                                                            |
| `country`         | स्ट्रिङ                            | `""`           | `countryCode` फिल्टर (ISO-2)। खाली = सबै।                                                                                     |
| `minQuality`      | सङ्ख्या                            | `0`            | `qualityScore >= minQuality` भएका पङ्क्तिहरू मात्र। `0` = न्यूनतम सीमा छैन।                                                   |
| `disabledSources` | स्ट्रिङ                            | `""`           | हटाउनुपर्ने अल्पविरामद्वारा छुट्याइएका स्रोत id हरू (जस्तै `proxifly,webshare`)।                                              |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`      | `quality` = स्कोर घट्दो क्रममा; `latency` = विलम्ब बढ्दो क्रममा (null हरू अन्त्यमा); `recent` = `lastValidated` घट्दो क्रममा। |
| `offset`          | सङ्ख्या                            | `0`            | पृष्ठाङ्कनको सुरुवात।                                                                                                         |
| `limit`           | सङ्ख्या                            | `50`           | पृष्ठको आकार (सर्भर-साइडमा सीमित गरिएको)।                                                                                     |

### प्रतिक्रिया

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["अपस्ट्रिमबाट HTTP 429"],
    "webshare": ["नेटवर्क टाइमआउट"]
  }
}
```

`total` ले पृष्ठाङ्कन **अघि** फिल्टर गरिएको कुल सङ्ख्या जनाउँछ, त्यसैले UI ले
`कुल: N` र `hasMore` लाई स्वतन्त्र रूपमा रेन्डर गर्न सक्छ। `syncErrors` स्रोत id अनुसार कुञ्जीकृत हुन्छ र
पछिल्लो समक्रमण असफल भएका स्रोतहरूका लागि मात्र भरिन्छ — `कुल: 0` नतिजा
कहिल्यै मौन हुँदैन।

## पूलमा थप्नुहोस् — `POST /api/settings/free-proxies/[id]/add-to-pool`

निःशुल्क प्रोक्सीलाई व्यवस्थित `proxy_registry` पूलमा प्रवर्द्धन गर्छ। पहिले
अपस्ट्रिमलाई प्रमाणीकरण गर्छ; सफल भएमा नयाँ पूल प्रोक्सी id र मापन गरिएको विलम्ब फर्काउँछ।

## समक्रमण — `POST /api/settings/free-proxies/sync`

सक्षम गरिएका सबै स्रोतहरू (वा `{ "sources": [...] }` मा भएको उपसमूह) पुनः प्राप्त गर्छ। प्रत्येक
स्रोत स्वतन्त्र रूपमा समक्रमण हुन्छ; असफल स्रोतलाई `syncErrors` मा अभिलेख गरिन्छ र
अन्य स्रोतहरू पूरा भइरहन्छन्, त्यसैले आंशिक समक्रमणले पहिलेको सही डेटा कहिल्यै मेटाउँदैन।

## तथ्याङ्क — `GET /api/settings/free-proxies/stats`

पङ्क्तिको पेलोडबिना `total / inPool / avgQuality / bySource / lastSyncAt` समग्र
फर्काउँछ — ड्यासबोर्ड हेडरका विजेटहरूले यसलाई प्रयोग गर्छन्।
