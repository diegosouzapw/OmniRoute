OmniRoute ले बाह्य प्रदायकहरू (1proxy, proxifly, iplocate, webshare) बाट समक्रमण गरिएको निःशुल्क प्रोक्सीहरूको छनोट गरिएको समूह `free_proxies` तालिकामा उपलब्ध गराउँछ।
ड्यासबोर्डले यी प्रोक्सीहरूलाई **सेटिङहरू → निःशुल्क प्रोक्सीहरू** अन्तर्गत देखाउँछ। यस दस्तावेजमा सूची रुटले उपलब्ध गराउने सर्भर-साइड फिल्टरिङ, क्रमबद्धता, गणना र समक्रमण-त्रुटि रिपोर्टिङ समेटिएको छ।

## सूची रुट — `GET /api/settings/free-proxies`

कुल सङ्ख्यासहित फिल्टर गरिएको, क्रमबद्ध र पृष्ठाङ्कन गरिएको अंश फर्काउँछ। फिल्टरिङ र गणना SQL मा हुन्छन्, त्यसैले UI ले प्रत्येक पङ्क्ति मेमोरीमा लोड नगरी वास्तविक कुल सङ्ख्या (जस्तै `कुल: 0`) देखाउन सक्छ।

### क्वेरी प्यारामिटरहरू

| प्यारामिटर        | प्रकार                             | पूर्वनिर्धारित | अर्थ                                                                                                                        |
| ----------------- | ---------------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`           | host (र source) स्तम्भमा केस-संवेदनशील `LIKE`।                                                                              |
| `protocol`        | string                             | `""`           | `type` फिल्टर: `http` / `https` / `socks4` / `socks5`। खाली = सबै।                                                          |
| `country`         | string                             | `""`           | `countryCode` फिल्टर (ISO-2)। खाली = सबै।                                                                                   |
| `minQuality`      | number                             | `0`            | `qualityScore >= minQuality` भएका पङ्क्तिहरू मात्र। `0` = न्यूनतम सीमा छैन।                                                 |
| `disabledSources` | string                             | `""`           | हटाइने अल्पविरामद्वारा छुट्याइएका source id हरू (जस्तै `proxifly,webshare`)।                                                |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`      | `quality` = स्कोर घट्दो क्रममा; `latency` = विलम्बता बढ्दो क्रममा (null अन्त्यमा); `recent` = `lastValidated` घट्दो क्रममा। |
| `offset`          | number                             | `0`            | पृष्ठाङ्कनको सुरुवात।                                                                                                       |
| `limit`           | number                             | `50`           | पृष्ठको आकार (सर्भर-साइडमा सीमित)।                                                                                          |

### प्रतिक्रिया

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` ले पृष्ठाङ्कनभन्दा **अघिको** फिल्टर गरिएको कुल सङ्ख्या जनाउँछ, त्यसैले UI ले `कुल: N` र `hasMore` लाई स्वतन्त्र रूपमा रेन्डर गर्न सक्छ। `syncErrors` लाई source id अनुसार कुञ्जीकृत गरिन्छ र अन्तिम समक्रमण असफल भएका स्रोतहरूका लागि मात्र भरिन्छ—`कुल: 0` परिणाम कहिल्यै जानकारीविहीन हुँदैन।

## पूलमा थप्नुहोस् — `POST /api/settings/free-proxies/[id]/add-to-pool`

निःशुल्क प्रोक्सीलाई व्यवस्थित `proxy_registry` पूलमा बढुवा गर्छ। पहिले upstream लाई प्रमाणीकरण गर्छ; सफल भएमा नयाँ पूल प्रोक्सी id र मापन गरिएको विलम्बता फर्काउँछ।

## समक्रमण — `POST /api/settings/free-proxies/sync`

सक्षम गरिएका सबै स्रोतहरू (वा `{ "sources": [...] }` मा दिइएको उपसमूह) पुनः प्राप्त गर्छ। प्रत्येक स्रोत स्वतन्त्र रूपमा समक्रमण हुन्छ; असफल स्रोत `syncErrors` मा अभिलेख गरिन्छ र अन्य स्रोतहरू अझै पूरा हुन्छन्, त्यसैले आंशिक समक्रमणले पहिलेको राम्रो डेटा कहिल्यै मेटाउँदैन।

## तथ्याङ्क — `GET /api/settings/free-proxies/stats`

पङ्क्ति payload बिना `total / inPool / avgQuality / bySource / lastSyncAt` समग्र परिणाम फर्काउँछ—यो ड्यासबोर्डको हेडर विजेटहरूद्वारा प्रयोग गरिन्छ।
