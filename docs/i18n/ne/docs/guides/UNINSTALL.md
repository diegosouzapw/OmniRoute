## द्रुत अनइन्स्टल (v3.6.2+)

OmniRoute ले सफा रूपमा हटाउन दुईवटा अन्तर्निर्मित स्क्रिप्ट उपलब्ध गराउँछ:

### आफ्नो डेटा सुरक्षित राख्नुहोस्

```bash
npm run uninstall
```

यसले OmniRoute अनुप्रयोग हटाउँछ तर `~/.omniroute/` मा रहेका तपाईंको डेटाबेस, कन्फिगरेसनहरू, API कुञ्जीहरू र प्रदायक सेटिङहरू **सुरक्षित राख्छ**। तपाईं पछि पुनः इन्स्टल गर्ने योजना बनाउँदै हुनुहुन्छ र आफ्नो सेटअप कायम राख्न चाहनुहुन्छ भने यो प्रयोग गर्नुहोस्।

### पूर्ण रूपमा हटाउनुहोस्

```bash
npm run uninstall:full
```

यसले अनुप्रयोग हटाउनुका साथै सम्पूर्ण डेटा **स्थायी रूपमा मेटाउँछ**:

- डेटाबेस (`storage.sqlite`)
- प्रदायक कन्फिगरेसनहरू र API कुञ्जीहरू
- ब्याकअप फाइलहरू
- लग फाइलहरू
- `~/.omniroute/` डाइरेक्टरीभित्रका सबै फाइलहरू

> ⚠️ **चेतावनी:** `npm run uninstall:full` लाई उल्टाउन सकिँदैन। तपाईंका सबै प्रदायक जडानहरू, कम्बोहरू, API कुञ्जीहरू र प्रयोग इतिहास स्थायी रूपमा मेटिनेछन्।

## म्यानुअल अनइन्स्टल

### NPM ग्लोबल इन्स्टल

```bash
# ग्लोबल प्याकेज हटाउनुहोस्
npm uninstall -g omniroute

# (वैकल्पिक) डेटा डाइरेक्टरी हटाउनुहोस्
rm -rf ~/.omniroute
```

### pnpm ग्लोबल इन्स्टल

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# कन्टेनर रोक्नुहोस् र हटाउनुहोस्
docker stop omniroute
docker rm omniroute

# भोल्युम हटाउनुहोस् (सम्पूर्ण डेटा मेटाउँछ)
docker volume rm omniroute-data

# (वैकल्पिक) इमेज हटाउनुहोस्
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# कन्टेनरहरू रोक्नुहोस् र हटाउनुहोस्
docker compose down

# भोल्युमहरू पनि हटाउनुहोस् (सम्पूर्ण डेटा मेटाउँछ)
docker compose down -v
```

### Electron डेस्कटप एप

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` खोल्नुहोस्
- वा इन्स्टल डाइरेक्टरीबाट NSIS अनइन्स्टलर चलाउनुहोस्

**macOS:**

- `/Applications` बाट `OmniRoute.app` लाई रद्दीटोकरीमा तान्नुहोस्
- डेटा हटाउनुहोस्: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage फाइल हटाउनुहोस्
- डेटा हटाउनुहोस्: `rm -rf ~/.omniroute`

### स्रोतबाट गरिएको इन्स्टल (git clone)

```bash
# क्लोन गरिएको डाइरेक्टरी हटाउनुहोस्
rm -rf /path/to/omniroute

# (वैकल्पिक) डेटा डाइरेक्टरी हटाउनुहोस्
rm -rf ~/.omniroute
```

## डेटा डाइरेक्टरीहरू

पूर्वनिर्धारित रूपमा OmniRoute ले निम्न स्थानहरूमा डेटा भण्डारण गर्छ:

| प्लेटफर्म  | पूर्वनिर्धारित पथ                    | ओभरराइड                      |
| ---------- | ------------------------------------ | ---------------------------- |
| Linux      | `~/.omniroute/`                      | `DATA_DIR` वातावरण चर        |
| macOS      | `~/.omniroute/`                      | `DATA_DIR` वातावरण चर        |
| Windows    | `%APPDATA%/omniroute/`               | `DATA_DIR` वातावरण चर        |
| Docker     | `/app/data/` (माउन्ट गरिएको भोल्युम) | `DATA_DIR` वातावरण चर        |
| XDG-अनुरूप | `$XDG_CONFIG_HOME/omniroute/`        | `XDG_CONFIG_HOME` वातावरण चर |

### डेटा डाइरेक्टरीभित्रका फाइलहरू

| फाइल/डाइरेक्टरी      | विवरण                                                     |
| -------------------- | --------------------------------------------------------- |
| `storage.sqlite`     | मुख्य डेटाबेस (प्रदायकहरू, कम्बोहरू, सेटिङहरू, कुञ्जीहरू) |
| `storage.sqlite-wal` | SQLite राइट-अहेड लग (अस्थायी)                             |
| `storage.sqlite-shm` | SQLite साझा मेमोरी (अस्थायी)                              |
| `call_logs/`         | अनुरोध पेलोड अभिलेखहरू                                    |
| `backups/`           | स्वचालित डेटाबेस ब्याकअपहरू                               |
| `log.txt`            | पुरानो अनुरोध लग (वैकल्पिक)                               |

## पूर्ण रूपमा हटाइएको पुष्टि गर्नुहोस्

अनइन्स्टल गरेपछि, कुनै पनि फाइल बाँकी नरहेको पुष्टि गर्नुहोस्:

```bash
# ग्लोबल npm प्याकेज जाँच गर्नुहोस्
npm list -g omniroute 2>/dev/null

# डेटा डाइरेक्टरी जाँच गर्नुहोस्
ls -la ~/.omniroute/ 2>/dev/null

# चलिरहेका प्रोसेसहरू जाँच गर्नुहोस्
pgrep -f omniroute
```

यदि कुनै प्रोसेस अझै चलिरहेको छ भने, त्यसलाई रोक्नुहोस्:

```bash
pkill -f omniroute
```
