OmniRoute ले समर्थित 352 प्रदायकहरूलाई 3 आर्थिक टियरमा व्यवस्थित गर्छ। प्रत्येक
अनुरोध सफलतापूर्वक प्रतिक्रिया नफर्काएसम्म क्रमशः तिनीहरूमार्फत जान्छ — यसरी
तपाईंले fallback कोड कहिल्यै नलेखी सबैभन्दा सस्तो व्यवहार्य प्रतिक्रिया पाउनुहुन्छ।

## टियर 1 — सदस्यता

**तपाईंले पहिले नै भुक्तानी गरिरहेका प्रदायकहरू।** OmniRoute ले कोटा समाप्त हुनुअघि
त्यसको प्रत्येक अंश प्रयोग गर्छ।

| प्रदायक                        | टियर 1 हुनुको कारण                                 |
| ------------------------------ | -------------------------------------------------- |
| Claude Code OAuth              | Anthropic Pro/Team — स्थिर-दर, प्रायः प्रयोग नभएको |
| OpenAI Codex (ChatGPT सदस्यता) | Plus/Team मा Codex कोटा समावेश छ                   |
| GitHub Copilot                 | प्रति-सिट — कोटा मासिक रूपमा रिसेट हुन्छ           |
| Cursor IDE                     | Pro योजनाको कोटा                                   |
| Antigravity / Devin Desktop    | अन्तर्निर्मित कोटाहरू                              |

**रणनीति**: मोडेलको क्षमतासँग मेल खाने प्रत्येक अनुरोधलाई पहिले यहाँ रुट गर्नुहोस्।
कोटा ट्र्याकरले नजिकिँदै गरेका रिसेटहरू निगरानी गर्छ, र `reset-aware`
कम्बो रणनीतिले सोहीअनुसार प्राथमिकता दिन्छ। टियर 1 मा पहिले रुट गर्न र कोटा सकिँदै
जाँदा मात्र सशुल्क टियरहरूमा जान `auto/thrifty` आईडी प्रयोग गर्नुहोस् — वा योजनामा
समावेश क्षमतामै रहन र त्यसो हुन नसके बन्द हुन `auto/subscription` प्रयोग गर्नुहोस्।
[सदस्यता-पहिलो रुटिङ](../routing/SUBSCRIPTION_LADDER.md) हेर्नुहोस्।

## टियर 2 — सस्तो

**प्रति 1M टोकन $1 भन्दा कम पर्ने प्रति-टोकन भुक्तानी प्रदायकहरू।** उच्च-परिमाणको
कामका लागि वा टियर 1 कोटाहरू सीमा पुगेपछि प्रयोग गर्न आरक्षित।

| प्रदायक                     | मूल्य (इनपुट/आउटपुट)   | विशेषताहरू         |
| --------------------------- | ---------------------- | ------------------ |
| DeepSeek V4 Pro             | $0.27 / $1.10 प्रति 1M | कोड, तर्कशक्ति     |
| GLM-4.5                     | $0.60 / $2.20 प्रति 1M | लामो सन्दर्भ       |
| MiniMax M1                  | $0.20 / $1.10 प्रति 1M | गति                |
| Qwen Coder                  | $0.30 / $1.20 प्रति 1M | कोड                |
| OpenRouter (मूल्य-अनुकूलित) | फरक-फरक                | 100+ मोडेल, गतिशील |

**रणनीति**: `cost-optimized` कम्बोले कार्यको क्षमता फिल्टर (भिजन, JSON मोड,
उपकरणहरू, अधिकतम-सन्दर्भ) पूरा गर्ने सबैभन्दा कम $/token भएको मोडेल छान्छ।

## टियर 3 — निःशुल्क

**शून्य-लागत प्रदायकहरू** — निःशुल्क टियरहरू, क्रेडिट कार्यक्रमहरू, OAuth का दैनिक कोटाहरू।

| प्रदायक          | निःशुल्क कोटा / क्रेडिटहरू              |
| ---------------- | --------------------------------------- |
| Kiro AI          | निःशुल्क Claude टियर (उदार उचित-प्रयोग) |
| OpenCode Free    | प्रमाणीकरण आवश्यक छैन, उदार दर सीमाहरू  |
| Qoder            | निःशुल्क OAuth                          |
| Google Vertex AI | नयाँ खाताका लागि $300 क्रेडिट           |
| Amazon Q         | AWS प्रयोगकर्ताहरूका लागि निःशुल्क टियर |
| Pollinations     | खुला सार्वजनिक API                      |
| Cloudflare AI    | Workers AI निःशुल्क टियर                |

**रणनीति**: बजेट सीमासहितको `auto` कम्बोले टियर 1+2 असफल हुँदा
वा `useFreeOnly=true` सेट गरिएको हुँदा यहाँ रुट गर्छ। निःशुल्क प्रदायकहरूमा प्रायः
कमजोर दर सीमाहरू हुन्छन् — circuit breaker ले backoff पछि तिनीहरूलाई पुनःस्थापित गर्छ।

## टियरहरू कन्फिगर गर्ने

Dashboard → **Tiers** → आफ्ना प्रदायकहरू तोक्नुहोस्। पूर्वनिर्धारित मानहरू (`tierDefaults.json` बाट)
उपयुक्त छन्; प्राथमिकता दिनुपर्ने विशिष्ट सदस्यताहरू वा हटाउनुपर्ने प्रदायकहरू भए सम्पादन गर्नुहोस्।

Auto-Combo को 16-कारक स्कोरिङले टियरलाई पनि विचार गर्छ। हेर्नुहोस्
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md)।

## टेलिमेट्री

Dashboard → **Usage** ले प्रत्येक टियरमा प्रतिदिन खर्च भएका टोकनहरू देखाउँछ। यसलाई निम्नका लागि प्रयोग गर्नुहोस्:

- टियर 1 पूर्ण रूपमा प्रयोग भएको पुष्टि गर्नुहोस् (अन्यथा तपाईंले सदस्यताको मूल्य खेर फालिरहनुभएको छ)
- सबैभन्दा धेरै छनोट हुने टियर 2 मोडेलहरू पहिचान गर्नुहोस् (1-2 मा एकीकृत गर्नुहोस्)
- टियर 3 ले परीक्षण/अन्वेषण कार्यभारमा पैसा बचाएको प्रमाणित गर्नुहोस्

## सामान्य ढाँचाहरू

### पूर्णतः निःशुल्क कार्यभार

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

टियर 3 तर्फ दृढतापूर्वक निर्देशित गर्छ; टियर 3 अनुपलब्ध भए मात्र टियर 2 प्रयोग गर्छ।

### सस्तो fallback सहित सदस्यता-पहिलो

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

टियर 1 → टियर 2 → टियर 3 सँग मेल खाने स्पष्ट क्रमबद्ध सूची।
