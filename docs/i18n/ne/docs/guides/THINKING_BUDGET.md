> **ड्यासबोर्ड:** Settings → **AI** → Thinking Budget  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **स्रोत:** `open-sse/services/thinkingBudget.ts`

Thinking Budget ले प्रदायकहरूतर्फ पठाउँदा OmniRoute ले **क्लाइन्टका सोच/तर्कसम्बन्धी प्यारामिटरहरू पुनर्लेखन गर्ने कि नगर्ने** भन्ने नियन्त्रण गर्छ। यसले कम्प्रेसन, राउटिङ वा प्रम्प्ट क्यासलाई सक्रिय वा निष्क्रिय **गर्दैन**।

## मोडहरू

| मोड                                | OmniRoute ले के गर्छ                                                                                                            | कहिले प्रयोग गर्ने                                                                                                                                                              |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (पूर्वनिर्धारित) | क्लाइन्टका फिल्डहरूलाई जस्ताको तस्तै छोड्छ (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config`, आदि)। | **Codex / Desktop / प्रयासको स्तर + तर्कका सारांशहरू नियन्त्रण गर्नुपर्ने कुनै पनि क्लाइन्ट।** क्लाइन्टले `reasoning.summary` अनुरोध गर्दा सोच देखाउने प्यानलहरूका लागि आवश्यक। |
| **`auto`**                         | अपस्ट्रिममा पठाउनुअघि अनुरोध बडीबाट सोच/तर्कसम्बन्धी **सबै फिल्डहरू हटाउँछ**।                                                   | तपाईंले जानाजानी **प्रदायकलाई** पूर्वनिर्धारित मानहरू तय गर्न दिन चाहनुहुन्छ र क्लाइन्टद्वारा नियन्त्रित सोच आवश्यक छैन भने मात्र। यसको अर्थ “सोच स्वतः देखाउनु” **होइन**।      |
| **`custom`**                       | प्रत्येक अनुरोधलाई निश्चित सोच टोकन बजेटले अधिलेखन गर्छ।                                                                        | सबै ट्राफिकका सोच टोकनहरूमा कडा सीमा लगाउन।                                                                                                                                     |
| **`adaptive`**                     | सन्देश सङ्ख्या, टुलहरू र प्रम्प्टको लम्बाइ प्रयोग गरी आधारभूत प्रयासबाट बजेट समायोजन गर्छ।                                      | क्लाइन्टको अभिप्राय पूर्ण रूपमा नहटाई टोकनमाथि लचिलो नियन्त्रण गर्न।                                                                                                            |

### `auto` ले के हटाउँछ

मोड `auto` हुँदा, `stripThinkingConfig()` ले (अन्यका साथै) निम्न हटाउँछ:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, र उपस्थित हुँदा `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

यदि कुनै क्लाइन्टले (जस्तै Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` पठाएको थियो भने, **auto ले त्यो वस्तु हटाउँछ**। अपस्ट्रिमले अझै केही तर्क टोकनहरूको शुल्क लिन सक्छ, तर प्रायः **खाली वा इन्क्रिप्टेड-मात्र** तर्क आइटमहरू फर्काउँछ — त्यसैले UI मा उपयोगी सोच स्ट्रिम देखिँदैन।

## यो के **होइन**

| सुविधा                                   | सम्बन्ध                                                                                                                                |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **कम्प्रेसन** (Caveman, RTK, stacked, …) | छुट्टै पाइपलाइन। प्रत्येक thinking-budget मोडअन्तर्गत काम गर्छ।                                                                        |
| **प्रम्प्ट / सिमान्टिक क्यास**           | छुट्टै। thinking-budget मोडबाट अप्रभावित।                                                                                              |
| **कम्बो राउटिङ / फलब्याकहरू**            | छुट्टै। अप्रभावित।                                                                                                                     |
| **API-key टोकन सीमा / लागत बजेटहरू**     | छुट्टै। अप्रभावित।                                                                                                                     |
| **तर्क रिप्ले क्यास**                    | कडा प्रदायकहरूका लागि बहु-टर्न पुनः-इन्जेक्सन (DeepSeek, Kimi, Qwen-thinking, …)। Desktop को “सोच देखाउनुहोस्” सँग समान होइन।          |
| **`encrypted_content` डिक्रिप्ट गर्ने**  | **असम्भव।** OpenAI/Codex का निजी तर्क ब्लबहरू अपारदर्शी हुन्छन्। OmniRoute ले तिनलाई कहिल्यै डिक्रिप्ट गर्दैन (#7095 / #7176 / #7304)। |

## देखिने सोचाइ (Codex / Responses क्लाइन्टहरू)

कुनै क्लाइन्टले सोचाइको पाठ देखाउनका लागि तपाईंलाई यी **सबै** आवश्यक पर्छन्:

1. Thinking Budget मोड = **`passthrough`** (वा तपाईंले प्रयोग गर्ने पथका लागि सारांश अनुरोधहरूलाई पर्याप्त रूपमा यथावत् राख्ने custom/adaptive)।
2. क्लाइन्टले सारांश माग्छ, जस्तै Codex `model_reasoning_summary = "detailed"` / `auto` (`none` होइन)।
3. अपस्ट्रिमले वास्तवमै `response.reasoning_summary_text.*` स्ट्रिम गर्छ (वा आइटममा खाली नभएको `reasoning.summary` हुन्छ)।

यदि तपाईंले “encrypted private reasoning” मात्र प्राप्त गर्नुभयो भने, निम्नमध्ये कुनै कारण हुन सक्छ:

- मोड **`auto`** थियो (क्लाइन्ट अनुरोध हटाइएको थियो), वा
- अपस्ट्रिमले सारांश पाठबिना `encrypted_content` फर्कायो (प्रदायकको सीमा; OmniRoute ले प्लेसहोल्डर मात्र देखाउन सक्छ, प्लेनटेक्स्ट होइन)।

## API उदाहरणहरू

```bash
# पढ्नुहोस्
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Codex / Desktop मा सोचाइ देखाउनका लागि सिफारिस गरिएको
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

स्किमा (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; वैकल्पिक `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`।

### स्थायित्व / पुनः सुरु

मान सेटिङ्स कुञ्जी `thinkingBudget` अन्तर्गत भण्डारण गरिन्छ र प्रक्रिया सुरु हुँदा (`hydrateThinkingBudgetConfig`) हाइड्रेट गरिन्छ। DB वा केही गैर-API पथहरूमार्फत परिवर्तन गरेपछि, इन-मेमोरी सिङ्गलटन डिस्कसँग मेल खाने बनाउन **OmniRoute प्रक्रिया पुनः सुरु गर्नुहोस्**।

## सञ्चालकको जाँचसूची

- [ ] Codex / Desktop प्रयोगकर्ताहरू: मोड = **passthrough**
- [ ] यदि तपाईं **messages** मा टोकन बचत चाहनुहुन्छ भने कम्प्रेसन अझै सक्षम राख्नुहोस्, सोचाइ हटाएर होइन
- [ ] `auto` ले “थप सोचाइ देखाउँछ” भन्ने अपेक्षा नगर्नुहोस्
- [ ] इन्क्रिप्टेड-मात्र सारांशहरू **प्रदायक** को व्यवहार हुन्; passthrough ले तिनलाई डिक्रिप्ट गर्न सक्दैन
