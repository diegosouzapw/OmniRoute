## सिंहावलोकन

Playground Studio ले `/dashboard/playground` लाई साधारण Monaco-आधारित सम्पादकबाट
पूर्ण-सुविधायुक्त परीक्षण कार्यक्षेत्रमा रूपान्तरण गर्छ। यसले पुरानो `page.tsx` लाई चारवटा ट्याब र साझा कन्फिग प्यान देखाउने `PlaygroundStudio`
शेलद्वारा प्रतिस्थापन गर्छ।

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 च्याट] [⚖ तुलना] [{} API] [🔧 निर्माण]     142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {सक्रिय ट्याबको सामग्री}                │ ─ कन्फिग                  │
│                                          │ एन्डपोइन्ट [chat ∨]       │
│                                          │ मोडेल     [gpt-5.4 ∨]     │
│                                          │ प्रणाली   [पाठ क्षेत्र]    │
│                                          │ तापक्रम   ▕▕▔▔ 0.7         │
│                                          │ प्रिसेटहरू [▾ लोड][सुरक्षित]│
│                                          │ [✨ प्रम्प्ट सुधार गर्नुहोस्]│
└──────────────────────────────────────────┴───────────────────────────┘
```

## ट्याबहरू

### च्याट ट्याब

`ChatPlayground.tsx` लाई बहु-चरणीय स्ट्रिमिङ कार्यस्थलमा विकसित गर्छ:

- `MarkdownMessage.tsx` मार्फत पूर्ण markdown रेन्डरिङ (कोड ब्लकहरू, तालिकाहरू, सूचीहरू, लिङ्कहरू)।
- साझा कन्फिग प्यानबाट लिइएको प्रणाली प्रम्प्ट।
- प्रत्येक सन्देशको टोकन/लागत (प्रम्प्ट + कम्प्लिसन टोकनहरू)।
- अन्तिम प्रतिक्रिया पुनः उत्पन्न गर्ने।
- SSE स्ट्रिमिङसहित `POST /v1/chat/completions` मा पठाउँछ।

### तुलना ट्याब

प्रोक्सीको प्रमुख भिन्नता: एउटा प्रम्प्टलाई अधिकतम **4 वटा मोडेलमा समानान्तर रूपमा** चलाउनुहोस्।

- अधिकतम 4 वटा स्तम्भ, प्रत्येकले `/v1/chat/completions` बाट स्वतन्त्र रूपमा स्ट्रिम गर्छ।
- स्तम्भहरू थप्न `+ मोडेल थप्नुहोस्` बटन (Cmd+K सर्टकट)।
- `सबै चलाउनुहोस् ▶` ले `Promise.all` + प्रत्येक स्तम्भको `AbortController` मार्फत सबै स्ट्रिमहरू एकैसाथ सुरु गर्छ।
- विश्वव्यापी **सबै रद्द गर्नुहोस्** ले चलिरहेका सबै स्ट्रिमहरू रोक्छ।
- प्रत्येक स्तम्भको `ProviderMetrics` ले TTFT, TPS, टोकनहरू र अनुमानित लागत वास्तविक समयमा देखाउँछ।
- मेट्रिक्सलाई **"क्लाइन्ट-साइड अनुमान"** (D12) लेबल गरिएको छ — पहिलो SSE चङ्कबाट मापन गरिन्छ।

### API ट्याब

उन्नत प्रयोगकर्ताहरूका लागि मूल Monaco सम्पादकलाई 100% जोगाउँछ (D14):

- 10 वटा एन्डपोइन्ट: च्याट कम्प्लिसन, कम्प्लिसन, एम्बेडिङ, छविहरू, अडियो, स्पिच, ट्रान्सक्रिप्सन, मोडरेसन, रिर्याङ्क, खोज।
- बहुमाध्यम फाइल अपलोड।
- वास्तविक-समय आउटपुटसहित SSE स्ट्रिमिङ।
- `ApiTab.tsx` को रूपमा र्याप गरिएको (लेजी-लोड गरिएको, `ssr: false`)।

### निर्माण ट्याब

उपकरण/फङ्सन कलिङ र संरचित आउटपुट UI:

- `ToolsBuilder.tsx` — प्रत्येक उपकरणका लागि JSON स्किमा सम्पादकसहित `tools[]` थप्ने/सम्पादन गर्ने/हटाउने।
  `ToolDefinitionSchema` (Zod) मार्फत प्यारामिटरहरू प्रमाणीकरण गर्छ।
- `StructuredOutputEditor.tsx` — JSON मोड टगल + JSON स्किमा सम्पादक।
  `StructuredOutputSchema` (Zod) मार्फत स्किमाविरुद्ध प्रतिक्रिया प्रमाणीकरण गर्छ।
- `tools[]` र/वा `response_format` सहित अनुरोधलाई `/v1/chat/completions` मा पठाउँछ।

## कन्फिग पेन (साझा)

`StudioConfigPane.tsx` — सधैं देखिने, संकुचित गर्न मिल्ने।

| फिल्ड                 | कम्पोनेन्ट            | टिप्पणी                                                                         |
| --------------------- | --------------------- | ------------------------------------------------------------------------------- |
| एन्डपोइन्ट            | `<select>`            | `PlaygroundEndpoint` सँग मिल्ने 10 विकल्प                                       |
| मोडेल                 | `<input>`             | स्वतन्त्र पाठ, जस्तै `openai/gpt-4o`                                            |
| सिस्टम प्रम्प्ट       | `<textarea>`          | सबै ट्याबहरूमा पठाइने                                                           |
| प्यारामिटरहरू         | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop          |
| प्रिसेटहरू            | `PresetPicker`        | नाम दिइएका कन्फिग स्न्यापसटहरू लोड/सेभ गर्छ (DB मा स्थायी रूपमा भण्डारण गरिएका) |
| प्रम्प्ट सुधार्नुहोस् | `ImprovePromptButton` | कोटा-चेतावनी मोडल खोल्छ, `/api/playground/improve-prompt` कल गर्छ               |

स्टेटलाई `PlaygroundStudio.tsx` मा माथि सारिएको छ र सबै ट्याबहरूमा पठाइन्छ। ट्याबहरू
बदल्दा कन्फिग स्टेट सुरक्षित रहन्छ।

## कोड निर्यात मोडल

`ExportCodeModal.tsx` ले हालको `PlaygroundState` बाट curl / Python / TypeScript स्निपेटहरू
उत्पन्न गर्न `codeExport.ts` प्रयोग गर्छ। API कुञ्जी प्लेसहोल्डर सधैं `$OMNIROUTE_API_KEY` (D11) हुन्छ।

---

## प्रम्प्ट सुधारक

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. मोडलले "कोटा खपत हुनेछ" भनेर चेतावनी दिन्छ।
2. पुष्टि गरेपछि, यसले `{ system, prompt, model, tone }` रुटमा पठाउँछ।
3. रुटले आन्तरिक रूपमा `promptImprover.META_SYSTEM_PROMPT` सहित `/v1/chat/completions` कल गर्छ।
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` फर्काउँछ।
5. UI ले कन्फिग पेनको सिस्टम प्रम्प्ट र च्याट ट्याबको प्रयोगकर्ता प्रम्प्ट प्याच गर्छ।

---

## प्रिसेटहरू

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- `playground_presets` SQLite तालिकामा भण्डारण गरिन्छ (माइग्रेसन `084_playground_presets.sql`)।
- प्रत्येक प्रिसेटले यी भण्डारण गर्छ: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`।
- CRUD: `GET` सूची, `POST` सिर्जना, `GET /:id`, `PUT /:id`, `DELETE /:id`।

---

## स्ट्रिम मेट्रिक्स

`useStreamMetrics.ts` + `streamMetrics.ts` (शुद्ध फङ्सन):

- `start()` — अनुरोध सुरु भएको समय रेकर्ड गर्छ।
- `onFirstChunk()` — TTFT रेकर्ड गर्छ।
- `onChunk(n)` — कम्प्लिसन टोकन सङ्ख्या सञ्चित गर्छ।
- `finish(usage?)` — अन्तिम मेट्रिक्स गणना गर्छ: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`।
- `src/lib/playground/types.ts` को स्थिर तालिकाबाट मूल्य निर्धारण (`"estimated"` लेबल गरिएको — D13)।

## ब्याकएन्ड रुटहरू

| विधि     | पाथ                              | ह्यान्डलर                                                                                                 |
| -------- | -------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | `ImprovePromptRequestSchema` मार्फत Zod-प्रमाणीकरण गर्छ; मेटा-प्रम्प्टसहित `/v1/chat/completions` कल गर्छ |

| `GET`    | `/api/playground/presets/:id`    | एउटा प्रिसेट वा 404 फर्काउँछ                                                                              |
| `PUT`    | `/api/playground/presets/:id`    | आंशिक अद्यावधिक                                                                                           |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                       |

प्रमाणीकरण: वैकल्पिक (`REQUIRE_API_KEY`)। त्रुटिहरू `buildErrorBody()` मार्फत (कडा नियम #12)।
