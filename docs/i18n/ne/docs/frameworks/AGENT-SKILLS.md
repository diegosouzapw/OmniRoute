## अवलोकन

क्याटलगमा **45 वटा एजेन्ट स्किलहरू** (23 REST API + 21 CLI + 1 कन्फिगरेसन कार्यप्रवाह) छन्। प्रत्येक स्किलमा निम्न हुन्छन्:

- एउटा **आधिकारिक ID** (`omni-auth`, `cli-serve`, आदि)
- `skills/{id}/SKILL.md` मा YAML frontmatter (`name`, `description`) + समृद्ध markdown सामग्रीसहितको एउटा **SKILL.md** फाइल
- OpenAPI स्पेसिफिकेसन र CLI रजिस्ट्रीबाट प्राप्त **REST एन्डपोइन्टहरू** (API स्किलहरू) वा **CLI सबकमाण्डहरू** (CLI स्किलहरू)
- प्रत्यक्ष रूपमा प्राप्त गर्नका लागि एउटा **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API अन्वेषण

| एन्डपोइन्ट                   | विधि | विवरण                                                                          | प्रमाणीकरण    |
| :--------------------------- | :--- | :----------------------------------------------------------------------------- | :------------ |
| `/api/agent-skills`          | GET  | क्याटलग सूचीबद्ध गर्नुहोस् (वैकल्पिक `?category=api\|cli\|config&area=<area>`) | कुनै पनि होइन |
| `/api/agent-skills/{id}`     | GET  | एउटा सिपको मेटाडेटा प्राप्त गर्नुहोस्                                          | कुनै पनि होइन |
| `/api/agent-skills/{id}/raw` | GET  | SKILL.md लाई `text/markdown` का रूपमा प्राप्त गर्नुहोस्                        | कुनै पनि होइन |
| `/api/agent-skills/coverage` | GET  | कभरेज तथ्याङ्क (कति वटा SKILL.md फाइलहरू अवस्थित छन्)                          | कुनै पनि होइन |
| `/api/agent-skills/generate` | POST | जेनेरेटर ट्रिगर गर्नुहोस् (dryRun/prune/onlyIds)                               | व्यवस्थापन    |

उदाहरण — सबै API सिपहरू सूचीबद्ध गर्नुहोस्:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

उदाहरण — एउटा SKILL.md प्राप्त गर्नुहोस्:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## बाह्य एजेन्टहरूले स्किलहरू कसरी प्रयोग गर्छन्

### 1. REST मार्फत खोज

```bash
# पूर्ण क्याटलग प्राप्त गर्नुहोस्
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# सन्दर्भ इन्जेक्सनका लागि SKILL.md प्राप्त गर्नुहोस्
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP मार्फत खोज

```typescript
// Claude Desktop / Cursor MCP क्लाइन्टमा:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → प्रत्येकका लागि rawUrl सहितको AgentSkill एरे
```

### 3. A2A मार्फत खोज

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table सबै 45 स्किल ID + rawUrl स्तम्भहरू भएको markdown तालिका हो
```

### 4. प्रत्यक्ष GitHub raw प्राप्ति (सर्भर आवश्यक पर्दैन)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## जेनेरेटर

जेनेरेटरले व्यवस्थित क्याटलग + OpenAPI स्पेसिफिकेसन + CLI रजिस्ट्री पढ्छ र प्रत्येक प्रविष्टिका लागि `skills/{id}/SKILL.md` लेख्छ:

```bash
# पूर्वावलोकन (ड्राइ रन, केही पनि लेखिँदैन)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# पूर्ण पुनःउत्पादन
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# निर्दिष्ट ID हरू पुनःउत्पादन गर्नुहोस्
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```
