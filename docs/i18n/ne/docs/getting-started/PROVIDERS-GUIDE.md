## प्रदायक भनेको के हो?

प्रदायकलाई **फोन सेवा प्रदायक** जस्तै सम्झनुहोस्। जसरी कल गर्न तपाईंलाई फोन सेवा प्रदायक चाहिन्छ, त्यसरी नै AI मोडेलहरू प्रयोग गर्न AI प्रदायक चाहिन्छ। OmniRoute **सबै सेवा प्रदायकसँग** काम गर्ने फोनजस्तै हो — तपाईं तिनीहरूबीच स्वचालित रूपमा परिवर्तन गर्न सक्नुहुन्छ।

### प्रदायकका प्रकारहरू

| प्रकार         | यो के हो                         | उदाहरणहरू                         | लागत                          |
| -------------- | -------------------------------- | --------------------------------- | ----------------------------- |
| **निःशुल्क**   | कुनै भुक्तानी आवश्यक पर्दैन      | Kiro, OpenCode Free, Pollinations | $0                            |
| **API कुञ्जी** | तपाईंलाई API कुञ्जी चाहिन्छ      | OpenAI, Anthropic, Google         | प्रयोगअनुसार भुक्तानी         |
| **OAuth**      | आफ्नो खाताबाट लगइन गर्नुहोस्     | Claude Code, GitHub Copilot       | सदस्यता                       |
| **वेब कुकी**   | तपाईंको ब्राउजर सत्र प्रयोग गर्छ | ChatGPT Web (Codex), Gemini Web   | $0 (तपाईंको खाता प्रयोग गर्छ) |

### वेब कुकी प्रदायकहरू

सामान्य सेटअप निर्देशनहरू, सीमितताहरू, समस्या समाधान र प्रदायक-विशिष्ट प्रमाणीकरण मार्गदर्शनका लागि **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** हेर्नुहोस्।

## द्रुत सुरुवात: आफ्नो पहिलो प्रदायक जडान गर्नुहोस्

### पहिलो पटक चलाउँदा निःशुल्क प्रदायक सेटअप गर्ने वैकल्पिक सुविधा

पहिलो पटक चल्ने विजार्डले स्पष्ट **निःशुल्क प्रदायकहरू सेटअप गर्नुहोस्** कार्ड उपलब्ध गराउँछ। यसले OmniRoute को प्रमाणीकरण नचाहिने प्रदायक रजिस्ट्रीबाट हाल योग्य सूची निकाल्छ, त्यसपछि पुष्टि गर्नुअघि प्रत्येक प्रदायकको समीक्षा गर्न र चयन हटाउन दिन्छ। OmniRoute ले प्रदायकको सावधानी सूचना र त्यसको साइटको लिङ्क देखाउँछ, ताकि तपाईंले पहिले तेस्रो-पक्षका सर्तहरू, गोपनीयता, उपलब्धता र दर सीमाहरू समीक्षा गर्न सक्नुहोस्।

यो कार्य वैकल्पिक हो: विजार्ड पूरा गर्दा कहिल्यै पनि निःशुल्क प्रदायकका जडानहरू गोप्य रूपमा सिर्जना हुँदैनन्। यसले अझै नभएका प्रदायकहरू मात्र सिर्जना गर्छ, पहिलेबाट अनुकूलित जडानहरूलाई नछोई यथावत् राख्छ र सिर्जना भएका, पहिले नै कन्फिगर गरिएका तथा असफल भएका प्रदायकहरूबारे छुट्टाछुट्टै जानकारी दिन्छ। आंशिक नतिजापछि तपाईंले असफल भएकाहरूलाई मात्र सुरक्षित रूपमा पुनः प्रयास गर्न सक्नुहुन्छ।

### विकल्प A: निःशुल्क प्रदायक (क्रेडिट कार्ड आवश्यक छैन)

1. `http://localhost:20128` मा ड्यासबोर्ड खोल्नुहोस्
2. **प्रदायकहरू** → **प्रदायक थप्नुहोस्** मा जानुहोस्
3. यी निःशुल्क प्रदायकहरूमध्ये एउटा चयन गर्नुहोस्:
   - **Kiro AI** — निःशुल्क Claude मोडेलहरू (प्रमाणीकरण आवश्यक छैन)
   - **OpenCode Free** — निःशुल्क GPT मोडेलहरू (प्रमाणीकरण आवश्यक छैन)
   - **Pollinations** — निःशुल्क GPT-5, Claude, Gemini (कुञ्जी आवश्यक छैन)
   - **LongCat** — 10M टोकन निःशुल्क (एकपटक दिइने अनुदान, खाता + KYC आवश्यक)
   - **Cloudflare AI** — 50+ मोडेलहरू, 10K न्युरोन/दिन
   - **MLX Gemma 26B** — स्थानीय Apple Silicon मोडेल (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — स्थानीय Apple Silicon मोडेल (~9.1 tok/s, ~13.1GB RAM)
4. **जडान गर्नुहोस्** मा क्लिक गर्नुहोस्
5. सकियो! अब तपाईंसँग निःशुल्क AI पहुँच छ।

### विकल्प B: API कुञ्जी प्रदायक (सशुल्क)

1. प्रदायकको वेबसाइटबाट API कुञ्जी प्राप्त गर्नुहोस्:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` मा ड्यासबोर्ड खोल्नुहोस्
3. **प्रदायकहरू** → **प्रदायक थप्नुहोस्** मा जानुहोस्
4. आफ्नो प्रदायक चयन गर्नुहोस्
5. आफ्नो API कुञ्जी टाँस्नुहोस्
6. **जडान गर्नुहोस्** मा क्लिक गर्नुहोस्
7. सकियो! अब तपाईंसँग त्यस प्रदायकका मोडेलहरूमा पहुँच छ।

### विकल्प C: OAuth प्रदायक (सदस्यता)

1. `http://localhost:20128` मा ड्यासबोर्ड खोल्नुहोस्
2. **प्रदायकहरू** → **प्रदायक थप्नुहोस्** मा जानुहोस्
3. आफ्नो प्रदायक चयन गर्नुहोस् (जस्तै, Claude Code, GitHub Copilot)
4. **OAuth मार्फत जडान गर्नुहोस्** मा क्लिक गर्नुहोस्
5. आफ्नो खाताबाट लगइन गर्नुहोस्
6. सकियो! अब तपाईंसँग आफ्नो सदस्यताका मोडेलहरूमा पहुँच छ।

### विकल्प D: स्थानीय MLX मोडेलहरू (Apple Silicon)

एकीकृत मेमोरी भएका Apple Silicon Mac हरूका लागि, OmniRoute ले `mlx-lm.server` मार्फत चलिरहेका स्थानीय MLX मोडेलहरूलाई नियमित OpenAI-सङ्गत स्थानीय प्रदायकका रूपमा जडान गर्न समर्थन गर्छ।

#### पूर्वापेक्षाहरू

- 24GB+ एकीकृत मेमोरी भएको **Apple Silicon Mac** (M1/M2/M3/M4) सिफारिस गरिन्छ
- **uv** प्याकेज व्यवस्थापक: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### द्रुत सुरुवात

1. **निर्भरताहरू स्थापना गर्नुहोस्**:

   ```bash
   # पहिले नै स्थापना गरिएको छैन भने uv स्थापना गर्नुहोस्
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm स्थापना गर्नुहोस्
   uv pip install mlx-lm
   ```

2. **MLX सर्भरहरू म्यानुअल रूपमा सुरु गर्नुहोस्** (छुट्टाछुट्टै टर्मिनलमा):

   ```bash
   # टर्मिनल 1: Gemma 4 26B A4B IT-QAT (पोर्ट 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # टर्मिनल 2: Qwen 3.8 27B MLX Mixed (पोर्ट 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ड्यासबोर्डमा जडान गर्नुहोस्**:
   - **प्रदायकहरू** → **प्रदायक थप्नुहोस्** मा जानुहोस्
   - **MLX Gemma 26B** वा **MLX Qwen 3.8 27B** चयन गर्नुहोस्
   - **जडान गर्नुहोस्** मा क्लिक गर्नुहोस् (API कुञ्जी आवश्यक छैन)

4. **OpenCode सँग प्रयोग गर्नुहोस्**:
   ```bash
   # OmniRoute प्रयोग गर्न OpenCode कन्फिगर गर्नुहोस्
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX मोडेलहरू प्रयोग गर्नुहोस्
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### मेमोरी व्यवस्थापन

**महत्त्वपूर्ण**: 24GB एकीकृत मेमोरी हुँदा, एकपटकमा **एउटा ठूलो MLX मोडेल मात्र चल्न सक्छ**।

- Gemma 26B: ~15.9GB अधिकतम मेमोरी
- Qwen 3.8 27B: ~13.1GB अधिकतम मेमोरी

तपाईंले यसलाई म्यानुअल रूपमा व्यवस्थापन गर्नुपर्छ:

- एकपटकमा एउटा MLX सर्भर मात्र चलाउनुहोस्, वा
- दुवैलाई छुट्टाछुट्टै मेसिनमा चलाउनुहोस्, वा
- अर्को सुरु गर्नुअघि एउटालाई रोक्नुहोस्

OmniRoute ले MLX सर्भर प्रक्रियाहरू स्वचालित रूपमा व्यवस्थापन गर्दैन — यसले तपाईंले कन्फिगर गरेका OpenAI-सङ्गत एन्डपोइन्टहरूमा अनुरोधहरू रुट मात्र गर्छ।

#### उपकरण कलिङ समर्थन

दुवै मोडेलले OpenAI-सङ्गत उपकरण कलिङ समर्थन गर्छन्। यसबाट परीक्षण गर्नुहोस्:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### समस्या निवारण

| समस्या                 | समाधान                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------- |
| सर्भर सुरु हुँदैन      | `uv run mlx_lm.server --help` जाँच गर्नुहोस् र मोडेल ID हरू प्रमाणित गर्नुहोस्                             |
| मेमोरी अपर्याप्त हुन्छ | एउटा मात्र मोडेल चलिरहेको सुनिश्चित गर्नुहोस्; अन्य एपहरू बन्द गर्नुहोस्; Activity Monitor जाँच गर्नुहोस्  |
| जडान अस्वीकृत भयो      | सर्भर सही पोर्ट (11435/11436) मा चलिरहेको छ भनी प्रमाणित गर्नुहोस्                                         |
| ढिलो प्रतिक्रियाहरू    | पहिलो अनुरोधले मोडेललाई मेमोरीमा लोड गर्छ (~30-60s); त्यसपछिका अनुरोधहरू छिटो हुन्छन्                      |

## उत्कृष्ट निःशुल्क प्रदायकहरू

यी प्रदायकहरूले क्रेडिट कार्डबिना **निःशुल्क पहुँच** प्रदान गर्छन्:

| प्रदायक           | निःशुल्क कोटा       | मोडेलहरू                                 | कसरी जडान गर्ने       |

### चरण 3: प्रदायक थप्नुहोस् मा क्लिक गर्नुहोस्

**+ प्रदायक थप्नुहोस्** बटनमा क्लिक गर्नुहोस्।

### चरण 4: आफ्नो प्रदायक चयन गर्नुहोस्

सूची हेर्नुहोस् वा आफ्नो प्रदायक खोज्नुहोस्। त्यसमा क्लिक गर्नुहोस्।

### चरण 5: प्रमाणहरू प्रविष्ट गर्नुहोस्

- **निःशुल्क प्रदायकहरू**: कुनै प्रमाण आवश्यक छैन — केवल **जडान गर्नुहोस्** मा क्लिक गर्नुहोस्
- **API कुञ्जी प्रदायकहरू**: आफ्नो API कुञ्जी टाँस्नुहोस्
- **OAuth प्रदायकहरू**: **OAuth मार्फत जडान गर्नुहोस्** मा क्लिक गरी लगइन गर्नुहोस्

### चरण 6: जडान परीक्षण गर्नुहोस्

यसले काम गर्छ कि गर्दैन भनी पुष्टि गर्न **जडान परीक्षण गर्नुहोस्** मा क्लिक गर्नुहोस्।

### चरण 7: सम्पन्न!

तपाईंको प्रदायक अब जडान भएको छ। तपाईं यसलाई `model: "auto"` सँग प्रयोग गर्न वा प्रदायकलाई सिधै निर्दिष्ट गर्न सक्नुहुन्छ।

OmniRoute ले **धेरै प्रदायकहरू** सँग उत्कृष्ट रूपमा काम गर्छ। यसबाट तपाईंले निम्न सुविधाहरू पाउनुहुन्छ:

- **स्वचालित फलब्याक** — एउटा प्रदायक असफल भएमा OmniRoute ले अर्कोलाई प्रयास गर्छ
- **लागत अनुकूलन** — OmniRoute ले प्रत्येक अनुरोधका लागि सबैभन्दा सस्तो प्रदायक रोज्छ
- **गति अनुकूलन** — OmniRoute ले प्रत्येक अनुरोधका लागि सबैभन्दा छिटो प्रदायक रोज्छ
- **गुणस्तर अनुकूलन** — OmniRoute ले प्रत्येक कार्यका लागि उत्कृष्ट प्रदायक रोज्छ

### सिफारिस गरिएको सेटअप

उत्कृष्ट अनुभवका लागि कम्तीमा **3 प्रदायकहरू** जडान गर्नुहोस्:

1. **एउटा निःशुल्क प्रदायक** (Kiro, OpenCode Free, वा Pollinations) — सधैं उपलब्ध
2. **एउटा छिटो प्रदायक** (Groq, Cerebras) — द्रुत प्रतिक्रियाका लागि
3. **एउटा गुणस्तरीय प्रदायक** (OpenAI, Anthropic, Google) — जटिल कार्यहरूका लागि

त्यसपछि `model: "auto"` प्रयोग गर्नुहोस् र OmniRoute ले प्रत्येक अनुरोधका लागि उत्कृष्ट प्रदायक स्वतः रोज्नेछ।

## सामान्य प्रश्नहरू

### "के मैले OmniRoute प्रयोग गर्न पैसा तिर्नुपर्छ?"

**पर्दैन!** OmniRoute निःशुल्क र खुला-स्रोत हो। तपाईंले कुनै शुल्क नतिरी निःशुल्क प्रदायकहरू (Kiro, OpenCode Free, Pollinations) प्रयोग गर्न सक्नुहुन्छ। तपाईंले सशुल्क प्रदायकहरू प्रयोग गर्ने छनोट गरेमा मात्र पैसा तिर्नुहुन्छ।

### "मैले कुन प्रदायकबाट सुरु गर्नुपर्छ?"

**Kiro AI** बाट सुरु गर्नुहोस् — यो निःशुल्क छ, कुनै API कुञ्जी आवश्यक पर्दैन, र यसले तपाईंलाई Claude मोडेलहरूमा पहुँच दिन्छ। त्यसपछि आवश्यकताअनुसार थप प्रदायकहरू थप्नुहोस्।

### "के म एकैपटक धेरै प्रदायकहरू प्रयोग गर्न सक्छु?"

**सक्नुहुन्छ!** OmniRoute को मुख्य उद्देश्य नै यही हो। धेरै प्रदायकहरू जडान गर्नुहोस् र प्रत्येक अनुरोधका लागि OmniRoute लाई उत्कृष्ट प्रदायक छनोट गर्न दिन `model: "auto"` प्रयोग गर्नुहोस्।

### "कुनै प्रदायकको सेवा बन्द भयो भने के हुन्छ?"

OmniRoute ले असफल भएका प्रदायकहरूलाई स्वतः छोडेर अर्कोलाई प्रयास गर्छ। तपाईंले केही पनि गर्नुपर्दैन।

### "मैले प्रदायकको जडान कसरी विच्छेद गर्ने?"

प्रदायकहरूमा जानुहोस् → प्रदायकमा क्लिक गर्नुहोस् → **जडान विच्छेद गर्नुहोस्** मा क्लिक गर्नुहोस्।

### "के मसँग भएका API कुञ्जीहरू प्रयोग गर्न सक्छु?"

**सक्नुहुन्छ!** यदि तपाईंसँग OpenAI, Anthropic, Google आदि सेवाका API कुञ्जीहरू पहिल्यै छन् भने, तपाईंले तिनलाई OmniRoute मा प्रयोग गर्न सक्नुहुन्छ। प्रदायक जडान गर्दा तिनलाई टाँस्नुहोस्।
