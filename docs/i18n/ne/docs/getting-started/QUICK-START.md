> **संक्षेपमा**: स्थापना गर्नुहोस् → निःशुल्क प्रदायक जडान गर्नुहोस् → आफ्नो IDE लाई OmniRoute तर्फ निर्देशित गर्नुहोस्। सकियो।

---

## चरण 1: OmniRoute स्थापना गर्नुहोस्

आफूलाई मनपर्ने विधि छान्नुहोस्:

### विकल्प A: npm (सिफारिस गरिएको)

```bash
npm install -g omniroute
```

### विकल्प B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` सबैभन्दा उच्च **प्रकाशित** स्थिर SemVer हो। यसले git `main` लाई पछ्याउँदैन। GitOps का लागि `diegosouzapw/omniroute:X.Y.Z` पिन गर्नुहोस्। [इमेज ट्यागहरू / रिलीज च्यानलहरू](../guides/DOCKER_GUIDE.md#release-channels) हेर्नुहोस्।

### विकल्प C: स्रोतबाट

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## चरण 2: OmniRoute सुरु गर्नुहोस्

```bash
omniroute
```

OmniRoute `http://localhost:20128` मा सुरु हुन्छ। ड्यासबोर्ड स्वतः खुल्छ।

---

## चरण 3: निःशुल्क प्रदायक जडान गर्नुहोस्

तपाईंले निःशुल्क प्रदायक जडान गरेर **कुनै पनि शुल्क नतिरी** OmniRoute प्रयोग गर्न सक्नुहुन्छ।

### विकल्प A: Kiro (निःशुल्क Claude — क्रेडिट कार्ड आवश्यक छैन)

1. `http://localhost:20128` मा ड्यासबोर्ड खोल्नुहोस्
2. **प्रदायकहरू** → **प्रदायक थप्नुहोस्** मा जानुहोस्
3. **Kiro AI** चयन गर्नुहोस्
4. **जडान गर्नुहोस्** मा क्लिक गर्नुहोस् (API key आवश्यक छैन!)
5. सकियो! अब तपाईंले Claude मोडेलहरूमा निःशुल्क पहुँच पाउनुभएको छ।

### विकल्प B: OpenCode Free (प्रमाणीकरण आवश्यक छैन)

1. `http://localhost:20128` मा ड्यासबोर्ड खोल्नुहोस्
2. **प्रदायकहरू** → **प्रदायक थप्नुहोस्** मा जानुहोस्
3. **OpenCode Free** चयन गर्नुहोस्
4. **जडान गर्नुहोस्** मा क्लिक गर्नुहोस् (API key आवश्यक छैन!)
5. सकियो! अब तपाईंले धेरै मोडेलहरूमा निःशुल्क पहुँच पाउनुभएको छ।

### विकल्प C: Pollinations (कुञ्जी आवश्यक छैन)

1. `http://localhost:20128` मा ड्यासबोर्ड खोल्नुहोस्
2. **प्रदायकहरू** → **प्रदायक थप्नुहोस्** मा जानुहोस्
3. **Pollinations** चयन गर्नुहोस्
4. **जडान गर्नुहोस्** मा क्लिक गर्नुहोस् (API key आवश्यक छैन!)
5. सकियो! अब तपाईंले GPT-5, Claude, Gemini र अन्य मोडेलहरूमा निःशुल्क पहुँच पाउनुभएको छ।

---

## चरण 4: यसले काम गरिरहेको छ भनी प्रमाणित गर्नुहोस्

[API Keys](http://localhost:20128/dashboard/api-manager) बाट नयाँ कुञ्जी सिर्जना गर्नुहोस्। यो कुञ्जी फेरि देखाइने छैन, त्यसैले सुरक्षित राख्नुहोस्। ध्यान दिनुहोस्, यो कुञ्जी उपकरणहरूले OmniRoute पहुँच गर्नका लागि हो, अपस्ट्रिम प्रदायकहरू पहुँच गर्नका लागि होइन।

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

तपाईंले जडान गर्नुभएका मोडेलहरूको सूची देख्नुपर्छ।

## चरण 5: आफ्नो IDE वा CLI लाई OmniRoute तर्फ निर्देशित गर्नुहोस्

आफ्नो IDE वा CLI उपकरणमा निम्न सेट गर्नुहोस्:

```
आधारभूत URL: http://localhost:20128/v1
API कुञ्जी:   [Dashboard → Endpoints बाट प्रतिलिपि गर्नुहोस्]
मोडेल:       auto
```

यति हो! अब तपाईंको IDE ले स्वचालित प्रदायक चयनसहित OmniRoute प्रयोग गर्छ।

### IDE उदाहरण: VSCode/Continue.dev

1. VSCode मा [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) एक्सटेन्सन स्थापना गर्नुहोस्।
2. निम्न लाइनहरू थप्न आफ्नो `~/.continue/config.yaml` अद्यावधिक गर्नुहोस्:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev को च्याट प्यानमा `OmniRoute - Auto` चयन गर्नुहोस्, त्यसपछि तपाईंले OmniRoute मा अनुरोधहरू पठाउनुहुनेछ।
4. (वैकल्पिक) पाठकका लागि अभ्यास — आफ्नो IDE लाई अन्य सबै पूर्वनिर्मित कन्फिगरेसनहरूसहित `config.yaml` अद्यावधिक गर्न लगाउनुहोस् 😊

### CLI उदाहरण: Codex CLI

1. आफ्नो अपरेटिङ सिस्टममा वातावरण चर स्थायी रूपमा सेट गर्नुहोस्।
   macOS/Linux का लागि (आफ्नो `~/.bashrc` वा `~/.zshrc` मा थप्नुहोस्):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows (Command Prompt) का लागि:

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. अब OmniRoute का लागि कन्फिगर गरिएको Codex सुरु गरौँ। चलाउनुहोस्:

```
omniroute launch-codex --model auto
```

एन्डपोइन्ट र API key निर्दिष्ट गर्न तपाईंले `codex` र कमान्ड लाइन प्यारामिटरहरू प्रयोग गरेर यो काम म्यानुअल रूपमा गर्न सक्नुहुन्छ, तर माथिको कमान्ड प्रयोग गर्दा OmniRoute ले तपाईंका लागि सबै कुरा सम्हाल्छ।

अन्य CLI हरूका लागि पनि जेनेरिक लन्चरमार्फत यही एक-कमान्ड लन्चले काम गर्छ — `omniroute run <target>` ले `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, र `gemini` समर्थन गर्छ ([CLI एकीकरणहरू](../guides/CLI-INTEGRATIONS.md) हेर्नुहोस्)।

3. अब CLI ले OmniRoute मा अनुरोधहरू पठाइरहेको हुनुपर्छ।

### तपाईंको उपकरण OmniRoute मार्फत राउट भइरहेको छ भनी पुष्टि गर्नुहोस्

बायाँ साइडबारबाट [अनुगमन/लगहरू](http://localhost:20128/dashboard/logs) मा क्लिक गरेर तपाईंले अनुरोधका विवरणहरू हेर्न सक्नुहुन्छ। त्यसभित्र क्लिक गर्दै जाँदा थप विवरणहरू देखिन्छन्। थप जानकारीका रूपमा, तपाईंको मनपर्ने हार्नेसबाट कुन जानकारी पठाइन्छ भन्ने पनि हेर्न सक्नुहुन्छ। यो सिकाइ र डिबगिङ दुवै दृष्टिकोणबाट उपयोगी हुन्छ।

## सामान्य प्रश्नहरू

### "के मलाई API key चाहिन्छ?"

**चाहिँदैन!** तपाईंले कुनै पनि API key विना निःशुल्क प्रदायकहरू (Kiro, OpenCode Free, Pollinations) प्रयोग गर्न सक्नुहुन्छ। तिनीहरूलाई ड्यासबोर्डमा जडान मात्र गर्नुहोस्।

### "`auto` भनेको के हो?"

`auto` ले OmniRoute लाई प्रत्येक अनुरोधका लागि उत्कृष्ट प्रदायक स्वतः छनोट गर्न निर्देशन दिन्छ। यसले गति, लागत, गुणस्तर र उपलब्धतालाई विचार गर्छ। विवरणका लागि [Auto-Combo मार्गदर्शिका](./AUTO-COMBO-GUIDE.md) हेर्नुहोस्।

### "यसको लागत कति पर्छ?"

OmniRoute आफैँ **निःशुल्क र खुला-स्रोत** हो। तपाईंले आफूले प्रयोग गर्ने प्रदायकहरूका लागि मात्र भुक्तानी गर्नुहुन्छ। धेरै प्रदायकहरूसँग निःशुल्क टियरहरू छन् — [निःशुल्क टियर मार्गदर्शिका](./FREE-TIERS-GUIDE.md) हेर्नुहोस्।

### "के म यसलाई Claude Code / Cursor / Copilot सँग प्रयोग गर्न सक्छु?"

**सक्नुहुन्छ!** OmniRoute ले OpenAI ढाँचा समर्थन गर्ने कुनै पनि उपकरणसँग काम गर्छ। आधारभूत URL लाई `http://localhost:20128/v1` मा सेट गर्नुहोस्। निश्चित सेटअप निर्देशनहरूका लागि [CLI उपकरण मार्गदर्शिका](../reference/CLI-TOOLS.md) हेर्नुहोस्।

### "कुनै प्रदायक बन्द भयो भने के हुन्छ?"

OmniRoute ले असफल भएका प्रदायकहरूलाई स्वतः छोडेर अर्को प्रदायक प्रयास गर्छ। तपाईंले केही गर्नुपर्दैन। विवरणका लागि [Auto-Combo मार्गदर्शिका](./AUTO-COMBO-GUIDE.md) हेर्नुहोस्।
