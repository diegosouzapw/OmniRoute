## 1. सेवाको आधिकारिक तथ्य (आधिकारिक कागजातहरूबाट, परस्पर जाँच गरिएको)

- आधार URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0)।
- `POST /v1/search` - प्यारामिटरहरू: `query` (आवश्यक), `max_results` (1-10, पूर्वनिर्धारित 10), `tag` (`{domain}.{sub_domain}` ठाडो राउटिङ), `zone` (cn/intl), `language`, `params` (संरचित ठाडो फिल्डहरू), `format` (json/markdown)।
- `GET /v1/sub-domains?domain=...` - क्षमताहरूको सूची, कोटामा गणना हुँदैन।
- `POST /v1/extract` - `{url, title, content}` ल्याउने/निकाल्ने; कडा JSON बडी, 16 KiB सीमा।
- `POST /v1/auth/email/register` - एकल-कल दर्ता, एकपटक मात्र देखाइने प्लेनटेक्स्ट कुञ्जी `as_sk_...` फर्काउँछ।
- प्रमाणीकरण: वैकल्पिक `Authorization: Bearer <as_sk_...>`; बेनामी पहुँच प्रति-IP सीमामा घट्छ र दैनिक निःशुल्क कोटा खपत गर्छ; अमान्य कुञ्जीले कुनै मौन बेनामी फलब्याकबिना 401/403 फर्काउँछ।
- निःशुल्क तह: प्रति दिन 1000 अनुरोध, प्रति कुञ्जी 20 QPS। सशुल्क तह: मूल्य निर्धारण नगरिएको (चाँडै आउँदै छ)।
- प्रतिक्रिया आवरण: सफलता `{code: 0, message: "success", request_id, data}`; असफलता `{code: -1, message}`। प्रमाणीकरण/कोटा त्रुटिहरूमा संरचित `error_code` हुँदैन (`message` को पाठ नै सङ्केत हो); एक्स्ट्र्याक्ट-विशिष्ट त्रुटिहरूमा भने `error_code` (`invalid_extract_url`, `extract_failed`) हुन्छ। 429 मा `Retry-After` हेडर हुँदैन।

## 3. निर्णयहरू (सबै 2026-08-26 मा गरिएका)

1. **राउटिङ नीति: `fallbackOnly`।** तर्क: लागत-0 भएको निःशुल्क प्रदायकले स्वचालित लागत राउटिङमा कहिल्यै प्रभुत्व जमाउनु हुँदैन; स्पष्ट छनोट र फेलओभर रिटर्नमा कुनै असर पर्दैन। नजिर: मर्ज गरिएको xquik प्रविष्टि।
2. **दायरा: v1 मा `POST /v1/extract` मार्फत webSearch + webFetch।** tavily/exa को दोहोरो-क्षमता मानसिक मोडेलसँग मिल्दो। भर्टिकल सतहहरू (`tag`, `sub-domains`, `batch_search`) दायराबाहिरै रहन्छन् — हाल भर्टिकल प्यारामिटरहरूका लागि कुनै IR छैन।
3. **कोटा प्रदर्शन: `freeMonthlyQuota: 0`** (xquik-शैलीको सतर्क प्रदर्शन)। वास्तविक उपलब्धता (1000 req/day, दैनिक रिसेट) यसको सट्टा UI क्याटलगको `authHint` प्रतिलिपिमा राखिन्छ। तर्क: कोटा प्रदर्शन रिसेटको अर्थगत व्यवहारसँग मेल खानुपर्छ; दैनिक सीमालाई मासिक-समकक्ष (30000) मा रूपान्तरण गर्नु UI ले पूरा गर्न नसक्ने झुटो प्रतिबद्धता हो।
4. **searchTypes: `["web"]` मात्र।** AnySearch API मा समाचार/तस्बिर भर्टिकल भएको कुनै सार्वजनिक प्रमाण छैन; दस्तावेजीकृत भर्टिकल नभएका API हरू एकीकृत गर्ने गेटवेहरू (जस्तै Google Custom Search) ले news -> web लाई मौन रूपमा म्याप गर्नुको सट्टा web मात्र उपलब्ध गराउँछन्।
5. **की नीति:** कीबिना काम गर्छ; अमान्य कीले 401/403 फर्काउँछ र यसलाई कहिल्यै मौन रूपमा बेनाम पहुँचमा डाउनग्रेड गरिँदैन (अपस्ट्रिम सम्झौतालाई प्रतिबिम्बित गर्छ)।
6. **जानीजानी गरिएका बहिष्करणहरू:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (च्याट इन्टरसेप्सन firecrawl/jina/tavily मै रहन्छ); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (बेनाम रिमोट एन्डपोइन्टहरूले प्रत्येक इग्रेस IP का लागि एउटै IP-सीमित पूल साझा गर्छन्, त्यसैले कीबिनाको extract अप्ट-इन हो, स्वतः-राउटिङ उम्मेदवार होइन); `QUOTA_STATUS_PROVIDERS` (AnySearch ले कोटाको सङ्केत 402/403 स्टाटसबाट होइन, 429/इनभेलपमार्फत दिन्छ)।
