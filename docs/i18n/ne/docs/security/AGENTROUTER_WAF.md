`agentrouter` अपस्ट्रिम गेटवेले `messages[].content` मा कीवर्ड-आधारित सामग्री फिल्टर चलाउँछ। फिल्टर आंशिक रूपमा निर्धारणात्मक छ (केही वाक्यांशहरू सधैं रोक्छ) र आंशिक रूपमा सम्भाव्यतामा आधारित छ (बर्स्ट-संवेदनशील — द्रुत अनुरोधहरूपछि अझ आक्रामक बन्छ र कूलडाउनपछि पुनः सामान्य हुन्छ)।

WAF ले अनुरोध रोक्दा यसले निम्न प्रतिक्रिया फर्काउँछ:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## फिल्टरको दायरा

WAF ले `messages[].content` मात्र निरीक्षण गर्छ। यसले निम्नलाई निरीक्षण **गर्दैन**:

- `system` प्रम्प्ट
- संरचित सामग्री ब्लकहरू (`tool_result`, `tool_use`, `thinking`, `image`)
- टुलका `description` र `input_schema` फिल्डहरू
- अनुरोध मेटाडेटा, हेडरहरू वा मोडेल id

## सधैं रोकिएका ढाँचाहरू (ठूला-साना अक्षरप्रति असंवेदनशील)

| ढाँचा                           | टिप्पणी                                                   |
| ------------------------------- | --------------------------------------------------------- |
| कुनै पनि `Lorem ipsum` भेरियन्ट | पूर्ण ल्याटिन lorem शब्दावली रोकिएको छ                    |
| `language model` (एक्लै)        | "the language model" र "large language model" पार हुन्छन् |
| `virtual assistant`             | "AI assistant" पार हुन्छ                                  |
| `I'm here to help`              | "here to help" मात्रले पनि रोक्छ                          |
| `Claude, made by Anthropic`     | पूर्ण वाक्यांश मात्र                                      |

## लगभग सधैं रोकिएका ढाँचाहरू

| ढाँचा                                                    | टिप्पणी                                                 |
| -------------------------------------------------------- | ------------------------------------------------------- |
| `placeholder`                                            | यो एक्लै प्रयोग हुँदा (प्यारामिटर नाम आदिका रूपमा होइन) |
| `dummy data`                                             | फिक्स्चरहरूका लागि सामान्य seed वाक्यांश                |
| `foo bar baz`                                            | प्रचलित placeholder वाक्यांश                            |
| दोहोरिएका छोटा टोकनहरू (`AAA BBB CCC`, `test test test`) | कीवर्ड स्टफिङ पत्ता लगाउने डिटेक्टर                     |

## लोडअन्तर्गतको व्यवहार

छोटो अवधिमा करिब ५ वटा द्रुत अनुरोधपछि WAF ले सामान्यतया पार हुने सामग्रीलाई पनि रोक्न थाल्छ। करिब ५–१० सेकेन्ड निष्क्रिय रहेपछि बकेट खुकुलो हुन्छ। यो त्यही IP-र-key-बाउन्ड रेट लिमिटर हो, जसले Claude Code वा Codex CLI ले छोटो समयभित्र धेरैवटा टुल-प्रयोग / सन्देश-पठाउने कल गर्दा बीच-बीचमा `400 content-blocked` त्रुटिहरू निम्त्याउँछ।

## OmniRoute मा पहिले नै लागू गरिएका न्यूनीकरणहरू

1. **`open-sse/services/wafRateLimit.ts`** — कुनै पनि `agentrouter:*` URL तर्फ पठाइने आउटबाउन्ड अनुरोधहरूबीच न्यूनतम 500 ms अन्तर लागू गर्ने बर्स्ट गार्ड। यो अन्तर मानिसले महसुस गर्न सक्ने विलम्बभन्दा निकै कम छ र सामान्य ट्राफिकमा WAF सक्रिय हुनबाट रोक्छ।

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — अपस्ट्रिमले `400 content-blocked` फर्काउँदा executor ले exponential backoff (1.5 s, 3.0 s, अधिकतम 2 प्रयास) सहित त्यही URL पुनः प्रयास गर्छ। backoff पछि WAF सामान्यतया खुकुलो हुन्छ र पुनः प्रयास सफल हुन्छ।

3. **`tests/unit/compression/harness.test.ts`** — परीक्षण फिक्स्चर `longInput` लाई `"lorem ipsum dolor sit amet ".repeat(40)` बाट `"example content for testing purposes ".repeat(40)` मा परिवर्तन गरिएको थियो, ताकि Claude Code ले `Read` टुलमार्फत यो फाइल पढ्दा फाइलको सामग्री `tool_result` ब्लकमार्फत पुनः प्रवाहित भएर WAF सक्रिय नगरोस्।

## प्रम्प्ट र टुल आउटपुटका लागि मार्गदर्शन

यदि Claude Code वा Codex CLI सत्रले बारम्बार `400 content-blocked` सामना गर्छ भने, माथिका कुनै ढाँचा छन् कि भनेर सबैभन्दा हालको प्रयोगकर्ता सन्देश र सबैभन्दा हालको टुल परिणाम जाँच्नुहोस् र वाक्य पुनर्लेखन गर्नुहोस्। सामान्य समाधानहरू:

- `Lorem ipsum …` लाई `example text …` वा परीक्षण अथवा फिक्स्चरले मोडल गर्न खोजेको वास्तविक सामग्रीले बदल्नुहोस्।
- एक्लै प्रयोग भएको `placeholder` लाई `example value`, `sample value` वा वास्तविक मानले बदल्नुहोस्।
- `language model` लाई `large language model` वा `the model` ले बदल्नुहोस्।
- `dummy data` लाई `sample data` वा यथार्थपरक seed मानहरूले बदल्नुहोस्।
- `I'm here to help` / `here to help` लाई अझ विशिष्ट सुरुवाती वाक्यले बदल्नुहोस् (जस्तै, "I'll review the file you mentioned")।

## अपस्ट्रिममा false positives रिपोर्ट गर्ने

हालको फिल्टर अत्यधिक आक्रामक छ — अपरेटरले स्पष्ट रूपमा प्रम्प्ट इन्जेक्ट गर्न नखोजेको अवस्थामा पनि यसले `tool_result` ब्लकहरूमा रहेको "Lorem ipsum" रोक्छ। यसलाई मूल स्रोतमै समाधान गराउन चाहने अपरेटरहरूले false positives रिपोर्ट गर्न `agentrouter.org` लाई सम्पर्क गर्नुपर्छ। माथिको blocklist 2026-08-03 सम्म अपस्ट्रिममा गरिएको परीक्षणको अनुभवजन्य परिणाम हो।
