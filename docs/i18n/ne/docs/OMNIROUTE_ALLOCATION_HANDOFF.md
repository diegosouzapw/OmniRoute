आवंटन प्रदायक कोटा होइन।

कोटा पूलहरूले कुन API कुञ्जीहरूले प्रदायक पूल उपभोग गर्न सक्छन् र कडा, नरम वा बर्स्ट नीतिहरू कसरी लागू हुन्छन् भन्ने परिभाषित गर्छन्। प्रदायक कोटा भनेको प्रदायकद्वारा रिपोर्ट गरिएको वा स्पष्ट रूपमा कन्फिगर गरिएको स्रोतबाट प्राप्त बाह्य क्षमता हो। Ghostlight का आन्तरिक बजेटहरू प्रशासकद्वारा परिभाषित सुशासन सीमाहरू हुन्।

`ensurePool` सञ्चालन आइडेम्पोटेन्ट छ: उस्तै पूल अपरिवर्तित रहन्छ, परिवर्तन भएको आवंटन अद्यावधिक हुन्छ, र नभएको पूल सिर्जना हुन्छ। यो स्वचालन र सीमाबद्ध API कलकर्ताहरूका लागि लक्षित छ।

पढ्न-मात्र मिल्ने स्थिति एन्डपोइन्ट `GET /api/omniroute/status` हो। प्रमाणीकरण आदेश `npm run omniroute:verify` हो; यसले कुनै लाइभ मोडेल अनुरोध गर्दैन।
