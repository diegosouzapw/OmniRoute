## 1. 服务事实基准（官方文档，已交叉核验）

- 基础 URL：`https://api.anysearch.com`（REST）+ `POST /mcp`（MCP，JSON-RPC 2.0）。
- `POST /v1/search` - 参数：`query`（必填）、`max_results`（1-10，默认 10）、`tag`（用于垂直路由的 `{domain}.{sub_domain}`）、`zone`（cn/intl）、`language`、`params`（结构化垂直领域字段）、`format`（json/markdown）。
- `GET /v1/sub-domains?domain=...` - 能力目录，不计入配额。
- `POST /v1/extract` - 获取/提取 `{url, title, content}`；严格 JSON 请求体，上限 16 KiB。
- `POST /v1/auth/email/register` - 单次调用注册，返回一次性明文密钥 `as_sk_...`。
- 身份验证：可选的 `Authorization: Bearer <as_sk_...>`；匿名访问会降级为按 IP 限制，并消耗每日免费配额；无效密钥返回 401/403，且不会静默回退到匿名访问。
- 免费层级：每个密钥每天 1000 个请求，20 QPS。付费层级：尚未定价（即将推出）。
- 响应封装：成功时为 `{code: 0, message: "success", request_id, data}`；失败时为 `{code: -1, message}`。身份验证/配额错误不包含结构化的 `error_code`（以消息文本作为信号）；提取专用错误则包含 `error_code`（`invalid_extract_url`、`extract_failed`）。429 响应中没有 `Retry-After` 标头。

## 3. ਫ਼ੈਸਲੇ (ਸਾਰੇ 2026-08-26 ਨੂੰ ਕੀਤੇ ਗਏ)

1. **ਰਾਊਟਿੰਗ ਰੁਖ: `fallbackOnly`।** ਤਰਕ: ਲਾਗਤ-0 ਵਾਲੇ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਨੂੰ ਕਦੇ ਵੀ ਸਵੈਚਾਲਿਤ ਲਾਗਤ ਰਾਊਟਿੰਗ ਉੱਤੇ ਹਾਵੀ ਨਹੀਂ ਹੋਣਾ ਚਾਹੀਦਾ; ਸਪਸ਼ਟ ਚੋਣ ਅਤੇ ਫੇਲਓਵਰ ਵਾਪਸੀ ਪ੍ਰਭਾਵਿਤ ਨਹੀਂ ਹੁੰਦੇ। ਮਿਸਾਲ: ਮਰਜ ਕੀਤੀ xquik ਐਂਟਰੀ।
2. **ਦਾਇਰਾ: v1 ਵਿੱਚ `POST /v1/extract` ਰਾਹੀਂ webSearch + webFetch।** tavily/exa ਦੇ ਦੋਹਰੀ-ਸਮਰੱਥਾ ਮਾਨਸਿਕ ਮਾਡਲ ਨਾਲ ਇਕਸਾਰ। ਵਰਟੀਕਲ ਸਰਫੇਸ (`tag`, `sub-domains`, `batch_search`) ਦਾਇਰੇ ਤੋਂ ਬਾਹਰ ਰਹਿੰਦੇ ਹਨ — ਅੱਜ ਵਰਟੀਕਲ ਪੈਰਾਮੀਟਰਾਂ ਲਈ ਕੋਈ IR ਨਹੀਂ ਹੈ।
3. **ਕੋਟਾ ਡਿਸਪਲੇ: `freeMonthlyQuota: 0`** (xquik-ਸ਼ੈਲੀ ਦਾ ਸਾਵਧਾਨ ਡਿਸਪਲੇ)। ਅਸਲ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਸੀਮਾ (1000 ਬੇਨਤੀਆਂ/ਦਿਨ, ਰੋਜ਼ਾਨਾ ਰੀਸੈੱਟ) ਇਸ ਦੀ ਬਜਾਏ UI ਕੈਟਾਲਾਗ ਦੀ `authHint` ਕਾਪੀ ਵਿੱਚ ਦਿੱਤੀ ਜਾਂਦੀ ਹੈ। ਤਰਕ: ਕੋਟਾ ਡਿਸਪਲੇ ਦਾ ਰੀਸੈੱਟ ਅਰਥ-ਵਿਗਿਆਨ ਨਾਲ ਮੇਲ ਖਾਣਾ ਲਾਜ਼ਮੀ ਹੈ; ਰੋਜ਼ਾਨਾ ਸੀਮਾ ਨੂੰ ਮਹੀਨਾਵਾਰ-ਸਮਤੁੱਲ (30000) ਵਿੱਚ ਬਦਲਣਾ ਇੱਕ ਝੂਠਾ ਵਾਅਦਾ ਹੈ, ਜਿਸ ਨੂੰ UI ਪੂਰਾ ਨਹੀਂ ਕਰ ਸਕਦਾ।
4. **searchTypes: ਸਿਰਫ਼ `["web"]`।** AnySearch API ਵਿੱਚ ਖ਼ਬਰਾਂ/ਚਿੱਤਰਾਂ ਦੇ ਵਰਟੀਕਲ ਦਾ ਕੋਈ ਜਨਤਕ ਸਬੂਤ ਨਹੀਂ ਹੈ; ਬਿਨਾਂ ਦਸਤਾਵੇਜ਼ਬੱਧ ਵਰਟੀਕਲ ਵਾਲੀਆਂ APIs ਨੂੰ ਏਕੀਕ੍ਰਿਤ ਕਰਨ ਵਾਲੇ ਗੇਟਵੇ (ਉਦਾਹਰਨ ਲਈ Google Custom Search) ਖ਼ਬਰਾਂ -> ਵੈੱਬ ਨੂੰ ਚੁੱਪਚਾਪ ਮੈਪ ਕਰਨ ਦੀ ਬਜਾਏ ਸਿਰਫ਼ ਵੈੱਬ ਹੀ ਉਪਲਬਧ ਕਰਵਾਉਂਦੇ ਹਨ।
5. **ਕੁੰਜੀ ਰੁਖ:** ਕੁੰਜੀ ਤੋਂ ਬਿਨਾਂ ਕੰਮ ਕਰਦਾ ਹੈ; ਇੱਕ ਅਵੈਧ ਕੁੰਜੀ 401/403 ਵਾਪਸ ਕਰਦੀ ਹੈ ਅਤੇ ਇਸ ਨੂੰ ਕਦੇ ਵੀ ਚੁੱਪਚਾਪ ਅਗਿਆਤ ਪਹੁੰਚ ਵਿੱਚ ਡਾਊਨਗ੍ਰੇਡ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ (ਅੱਪਸਟ੍ਰੀਮ ਇਕਰਾਰਨਾਮੇ ਦੇ ਅਨੁਰੂਪ)।
6. **ਜਾਣਬੁੱਝ ਕੇ ਕੀਤੇ ਅਪਵਰਜਨ:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (ਚੈਟ ਇੰਟਰਸੈਪਸ਼ਨ firecrawl/jina/tavily ਤੱਕ ਹੀ ਸੀਮਿਤ ਰਹਿੰਦੀ ਹੈ); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (ਅਗਿਆਤ ਰਿਮੋਟ ਐਂਡਪੁਆਇੰਟ ਹਰ egress IP ਲਈ ਇੱਕ IP-ਸੀਮਿਤ ਪੂਲ ਸਾਂਝਾ ਕਰਦੇ ਹਨ, ਇਸ ਲਈ ਕੁੰਜੀ-ਰਹਿਤ extract ਆਪਟ-ਇਨ ਹੈ, ਸਵੈਚਾਲਿਤ ਰਾਊਟਿੰਗ ਉਮੀਦਵਾਰ ਨਹੀਂ); `QUOTA_STATUS_PROVIDERS` (AnySearch ਕੋਟੇ ਨੂੰ 402/403 ਸਥਿਤੀ ਦੀ ਬਜਾਏ 429/envelope ਰਾਹੀਂ ਸੰਕੇਤ ਕਰਦਾ ਹੈ)।
