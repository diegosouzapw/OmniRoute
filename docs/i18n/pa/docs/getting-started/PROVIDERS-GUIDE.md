## ਪ੍ਰਦਾਤਾ ਕੀ ਹੁੰਦਾ ਹੈ?

ਪ੍ਰਦਾਤਾ ਨੂੰ ਇੱਕ **ਫ਼ੋਨ ਕੈਰੀਅਰ** ਵਾਂਗ ਸਮਝੋ। ਜਿਵੇਂ ਕਾਲਾਂ ਕਰਨ ਲਈ ਤੁਹਾਨੂੰ ਫ਼ੋਨ ਕੈਰੀਅਰ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ, ਉਸੇ ਤਰ੍ਹਾਂ AI ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰਨ ਲਈ ਤੁਹਾਨੂੰ AI ਪ੍ਰਦਾਤਾ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ। OmniRoute ਇੱਕ ਅਜਿਹੇ ਫ਼ੋਨ ਵਰਗਾ ਹੈ ਜੋ **ਸਾਰੇ ਕੈਰੀਅਰਾਂ** ਨਾਲ ਕੰਮ ਕਰਦਾ ਹੈ — ਤੁਸੀਂ ਆਪਣੇ-ਆਪ ਉਨ੍ਹਾਂ ਵਿਚਕਾਰ ਸਵਿੱਚ ਕਰ ਸਕਦੇ ਹੋ।

## ਤੁਰੰਤ ਸ਼ੁਰੂਆਤ: ਆਪਣਾ ਪਹਿਲਾ ਪ੍ਰਦਾਤਾ ਕਨੈਕਟ ਕਰੋ

### ਪਹਿਲੀ ਵਾਰ ਚਲਾਉਣ ਸਮੇਂ ਮੁਫ਼ਤ-ਪ੍ਰਦਾਤਾ ਦਾ ਵਿਕਲਪਿਕ ਸੈੱਟਅੱਪ

ਪਹਿਲੀ ਵਾਰ ਚੱਲਣ ਵਾਲਾ ਵਿਜ਼ਾਰਡ ਇੱਕ ਸਪਸ਼ਟ **ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਸੈੱਟ ਅੱਪ ਕਰੋ** ਕਾਰਡ ਪੇਸ਼ ਕਰਦਾ ਹੈ। ਇਹ OmniRoute ਦੀ ਬਿਨਾਂ-ਪ੍ਰਮਾਣੀਕਰਨ ਵਾਲੀ ਪ੍ਰਦਾਤਾ ਰਜਿਸਟਰੀ ਤੋਂ ਮੌਜੂਦਾ
ਯੋਗ ਸੂਚੀ ਤਿਆਰ ਕਰਦਾ ਹੈ, ਫਿਰ ਪੁਸ਼ਟੀ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਤੁਹਾਨੂੰ ਹਰੇਕ
ਪ੍ਰਦਾਤਾ ਦੀ ਸਮੀਖਿਆ ਕਰਨ ਅਤੇ ਉਸਦੀ ਚੋਣ ਹਟਾਉਣ ਦਿੰਦਾ ਹੈ। OmniRoute ਪ੍ਰਦਾਤਾ ਦਾ ਸਾਵਧਾਨੀ ਨੋਟਿਸ ਅਤੇ ਉਸਦੀ ਸਾਈਟ ਦਾ ਲਿੰਕ ਦਿਖਾਉਂਦਾ ਹੈ
ਤਾਂ ਜੋ ਤੁਸੀਂ ਪਹਿਲਾਂ ਤੀਜੀ-ਧਿਰ ਦੀਆਂ ਸ਼ਰਤਾਂ, ਪਰਦੇਦਾਰੀ, ਉਪਲਬਧਤਾ ਅਤੇ ਦਰ ਸੀਮਾਵਾਂ ਦੀ ਸਮੀਖਿਆ ਕਰ ਸਕੋ।

ਇਹ ਕਾਰਵਾਈ ਵਿਕਲਪਿਕ ਹੈ: ਵਿਜ਼ਾਰਡ ਪੂਰਾ ਕਰਨ ਨਾਲ ਕਦੇ ਵੀ ਚੁੱਪਚਾਪ ਮੁਫ਼ਤ-ਪ੍ਰਦਾਤਾ ਕਨੈਕਸ਼ਨ ਨਹੀਂ ਬਣਦੇ।
ਇਹ ਸਿਰਫ਼ ਉਹੀ ਪ੍ਰਦਾਤਾ ਬਣਾਉਂਦਾ ਹੈ ਜੋ ਹਾਲੇ ਮੌਜੂਦ ਨਹੀਂ ਹਨ, ਪਹਿਲਾਂ ਤੋਂ ਮੌਜੂਦ ਅਨੁਕੂਲਿਤ ਕਨੈਕਸ਼ਨਾਂ ਨੂੰ
ਬਿਨਾਂ ਬਦਲੇ ਛੱਡਦਾ ਹੈ, ਅਤੇ ਬਣਾਏ ਗਏ, ਪਹਿਲਾਂ ਤੋਂ ਸੰਰਚਿਤ ਅਤੇ ਅਸਫਲ ਪ੍ਰਦਾਤਾਵਾਂ ਬਾਰੇ ਵੱਖ-ਵੱਖ ਰਿਪੋਰਟ ਕਰਦਾ ਹੈ। ਅੰਸ਼ਕ ਨਤੀਜੇ ਤੋਂ ਬਾਅਦ ਤੁਸੀਂ
ਸੁਰੱਖਿਅਤ ਢੰਗ ਨਾਲ ਸਿਰਫ਼ ਅਸਫਲਤਾਵਾਂ ਲਈ ਮੁੜ ਕੋਸ਼ਿਸ਼ ਕਰ ਸਕਦੇ ਹੋ।

### ਵਿਕਲਪ A: ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ (ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ)

1. `http://localhost:20128` ਉੱਤੇ ਡੈਸ਼ਬੋਰਡ ਖੋਲ੍ਹੋ
2. **ਪ੍ਰਦਾਤਾ** → **ਪ੍ਰਦਾਤਾ ਸ਼ਾਮਲ ਕਰੋ** 'ਤੇ ਜਾਓ
3. ਇਨ੍ਹਾਂ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾਵਾਂ ਵਿੱਚੋਂ ਇੱਕ ਚੁਣੋ:
   - **Kiro AI** — ਮੁਫ਼ਤ Claude ਮਾਡਲ (ਪ੍ਰਮਾਣੀਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ)
   - **OpenCode Free** — ਮੁਫ਼ਤ GPT ਮਾਡਲ (ਪ੍ਰਮਾਣੀਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ)
   - **Pollinations** — ਮੁਫ਼ਤ GPT-5, Claude, Gemini (ਕੁੰਜੀ ਦੀ ਲੋੜ ਨਹੀਂ)
   - **LongCat** — 10M ਟੋਕਨ ਮੁਫ਼ਤ (ਇੱਕ ਵਾਰ ਦੀ ਗ੍ਰਾਂਟ, ਖਾਤਾ + KYC ਲੋੜੀਂਦਾ ਹੈ)
   - **Cloudflare AI** — 50+ ਮਾਡਲ, 10K ਨਿਊਰੋਨ/ਦਿਨ
   - **MLX Gemma 26B** — ਸਥਾਨਕ Apple Silicon ਮਾਡਲ (~38.5 ਟੋਕਨ/ਸਕਿੰਟ, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — ਸਥਾਨਕ Apple Silicon ਮਾਡਲ (~9.1 ਟੋਕਨ/ਸਕਿੰਟ, ~13.1GB RAM)
4. **ਕਨੈਕਟ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ
5. ਹੋ ਗਿਆ! ਹੁਣ ਤੁਹਾਡੇ ਕੋਲ ਮੁਫ਼ਤ AI ਪਹੁੰਚ ਹੈ।

### ਵਿਕਲਪ B: API ਕੁੰਜੀ ਪ੍ਰਦਾਤਾ (ਭੁਗਤਾਨਯੋਗ)

1. ਪ੍ਰਦਾਤਾ ਦੀ ਵੈੱਬਸਾਈਟ ਤੋਂ API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰੋ:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` ਉੱਤੇ ਡੈਸ਼ਬੋਰਡ ਖੋਲ੍ਹੋ
3. **ਪ੍ਰਦਾਤਾ** → **ਪ੍ਰਦਾਤਾ ਸ਼ਾਮਲ ਕਰੋ** 'ਤੇ ਜਾਓ
4. ਆਪਣਾ ਪ੍ਰਦਾਤਾ ਚੁਣੋ
5. ਆਪਣੀ API ਕੁੰਜੀ ਪੇਸਟ ਕਰੋ
6. **ਕਨੈਕਟ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ
7. ਹੋ ਗਿਆ! ਹੁਣ ਤੁਹਾਡੇ ਕੋਲ ਉਸ ਪ੍ਰਦਾਤਾ ਦੇ ਮਾਡਲਾਂ ਤੱਕ ਪਹੁੰਚ ਹੈ।

### ਵਿਕਲਪ C: OAuth ਪ੍ਰਦਾਤਾ (ਸਬਸਕ੍ਰਿਪਸ਼ਨ)

1. `http://localhost:20128` ਉੱਤੇ ਡੈਸ਼ਬੋਰਡ ਖੋਲ੍ਹੋ
2. **ਪ੍ਰਦਾਤਾ** → **ਪ੍ਰਦਾਤਾ ਸ਼ਾਮਲ ਕਰੋ** 'ਤੇ ਜਾਓ
3. ਆਪਣਾ ਪ੍ਰਦਾਤਾ ਚੁਣੋ (ਉਦਾਹਰਨ ਲਈ, Claude Code, GitHub Copilot)

5. ਆਪਣੇ ਖਾਤੇ ਨਾਲ ਲੌਗਇਨ ਕਰੋ
6. ਹੋ ਗਿਆ! ਹੁਣ ਤੁਹਾਡੇ ਕੋਲ ਆਪਣੇ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਮਾਡਲਾਂ ਤੱਕ ਪਹੁੰਚ ਹੈ।

### ਵਿਕਲਪ D: ਸਥਾਨਕ MLX ਮਾਡਲ (Apple Silicon)

ਇਕਸਾਰ ਮੈਮੋਰੀ ਵਾਲੇ Apple Silicon Mac ਲਈ, OmniRoute ਆਮ OpenAI-ਅਨੁਕੂਲ ਸਥਾਨਕ ਪ੍ਰਦਾਤਾਵਾਂ ਵਜੋਂ `mlx-lm.server` ਰਾਹੀਂ ਚੱਲ ਰਹੇ ਸਥਾਨਕ MLX ਮਾਡਲਾਂ ਨਾਲ ਕਨੈਕਟ ਕਰਨ ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ।

#### ਪੂਰਵ-ਲੋੜਾਂ

- **Apple Silicon Mac** (M1/M2/M3/M4), 24GB+ ਇਕਸਾਰ ਮੈਮੋਰੀ ਦੀ ਸਿਫ਼ਾਰਸ਼ ਕੀਤੀ ਜਾਂਦੀ ਹੈ
- **uv** ਪੈਕੇਜ ਮੈਨੇਜਰ: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### ਤੁਰੰਤ ਸ਼ੁਰੂਆਤ

1. **ਨਿਰਭਰਤਾਵਾਂ ਇੰਸਟਾਲ ਕਰੋ**:

   ```bash
   # ਜੇ uv ਪਹਿਲਾਂ ਤੋਂ ਇੰਸਟਾਲ ਨਹੀਂ ਹੈ ਤਾਂ ਇਸਨੂੰ ਇੰਸਟਾਲ ਕਰੋ
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm ਇੰਸਟਾਲ ਕਰੋ
   uv pip install mlx-lm
   ```

2. **MLX ਸਰਵਰ ਹੱਥੀਂ ਸ਼ੁਰੂ ਕਰੋ** (ਵੱਖਰੇ ਟਰਮੀਨਲਾਂ ਵਿੱਚ):

   ```bash
   # ਟਰਮੀਨਲ 1: Gemma 4 26B A4B IT-QAT (ਪੋਰਟ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ਟਰਮੀਨਲ 2: Qwen 3.8 27B MLX Mixed (ਪੋਰਟ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ ਕਨੈਕਟ ਕਰੋ**:
   - **ਪ੍ਰਦਾਤਾ** → **ਪ੍ਰਦਾਤਾ ਸ਼ਾਮਲ ਕਰੋ** 'ਤੇ ਜਾਓ
   - **MLX Gemma 26B** ਜਾਂ **MLX Qwen 3.8 27B** ਚੁਣੋ
   - **ਕਨੈਕਟ ਕਰੋ** 'ਤੇ ਕਲਿੱਕ ਕਰੋ (API ਕੁੰਜੀ ਦੀ ਲੋੜ ਨਹੀਂ)

4. **OpenCode ਨਾਲ ਵਰਤੋਂ ਕਰੋ**:
   ```bash

   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਕਰੋ
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

### "ਕੀ ਮੈਂ ਇੱਕੋ ਸਮੇਂ ਕਈ ਪ੍ਰਦਾਤਾਵਾਂ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦਾ ਹਾਂ?"

### "ਜੇ ਕੋਈ ਪ੍ਰਦਾਤਾ ਬੰਦ ਹੋ ਜਾਵੇ ਤਾਂ ਕੀ ਹੋਵੇਗਾ?"

OmniRoute ਅਸਫਲ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਆਪਣੇ-ਆਪ ਛੱਡ ਦਿੰਦਾ ਹੈ ਅਤੇ ਅਗਲੇ ਨੂੰ ਅਜ਼ਮਾਉਂਦਾ ਹੈ। ਤੁਹਾਨੂੰ ਕੁਝ ਵੀ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ।

### "ਮੈਂ ਕਿਸੇ ਪ੍ਰਦਾਤਾ ਨੂੰ ਡਿਸਕਨੈਕਟ ਕਿਵੇਂ ਕਰਾਂ?"

### "ਕੀ ਮੈਂ ਆਪਣੀਆਂ ਮੌਜੂਦਾ API ਕੁੰਜੀਆਂ ਵਰਤ ਸਕਦਾ ਹਾਂ?"
