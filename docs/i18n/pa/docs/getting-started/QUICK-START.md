> **TL;DR**: ਇੰਸਟਾਲ ਕਰੋ → ਇੱਕ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਕਨੈਕਟ ਕਰੋ → ਆਪਣੇ IDE ਨੂੰ OmniRoute ਵੱਲ ਪੁਆਇੰਟ ਕਰੋ। ਬੱਸ ਹੋ ਗਿਆ।

---

## ਕਦਮ 1: OmniRoute ਇੰਸਟਾਲ ਕਰੋ

ਆਪਣਾ ਪਸੰਦੀਦਾ ਤਰੀਕਾ ਚੁਣੋ:

### ਵਿਕਲਪ A: npm (ਸਿਫ਼ਾਰਸ਼ੀ)

```bash
npm install -g omniroute
```

### ਵਿਕਲਪ B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` ਸਭ ਤੋਂ ਉੱਚਾ **ਪ੍ਰਕਾਸ਼ਿਤ** ਸਥਿਰ SemVer ਹੈ। ਇਹ git `main` ਨੂੰ ਟਰੈਕ **ਨਹੀਂ** ਕਰਦਾ। GitOps ਲਈ `diegosouzapw/omniroute:X.Y.Z` ਨੂੰ ਪਿੰਨ ਕਰੋ। [ਇਮੇਜ ਟੈਗ / ਰਿਲੀਜ਼ ਚੈਨਲ](../guides/DOCKER_GUIDE.md#release-channels) ਵੇਖੋ।

### ਵਿਕਲਪ C: ਸਰੋਤ ਤੋਂ

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## ਕਦਮ 2: OmniRoute ਸ਼ੁਰੂ ਕਰੋ

```bash
omniroute
```

OmniRoute `http://localhost:20128` ਉੱਤੇ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ। ਡੈਸ਼ਬੋਰਡ ਆਪਣੇ-ਆਪ ਖੁੱਲ੍ਹ ਜਾਂਦਾ ਹੈ।

---

## ਕਦਮ 3: ਇੱਕ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਕਨੈਕਟ ਕਰੋ

ਤੁਸੀਂ ਇੱਕ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਕਨੈਕਟ ਕਰਕੇ **ਬਿਨਾਂ ਕੁਝ ਭੁਗਤਾਨ ਕੀਤੇ** OmniRoute ਵਰਤ ਸਕਦੇ ਹੋ।

### ਵਿਕਲਪ A: Kiro (ਮੁਫ਼ਤ Claude — ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਦੀ ਲੋੜ ਨਹੀਂ)

1. `http://localhost:20128` ਉੱਤੇ ਡੈਸ਼ਬੋਰਡ ਖੋਲ੍ਹੋ
2. **ਪ੍ਰਦਾਤਾ** → **ਪ੍ਰਦਾਤਾ ਸ਼ਾਮਲ ਕਰੋ** ਉੱਤੇ ਜਾਓ
3. **Kiro AI** ਚੁਣੋ
4. **ਕਨੈਕਟ ਕਰੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ (API key ਦੀ ਲੋੜ ਨਹੀਂ!)
5. ਹੋ ਗਿਆ! ਹੁਣ ਤੁਹਾਡੇ ਕੋਲ Claude ਮਾਡਲਾਂ ਦੀ ਮੁਫ਼ਤ ਪਹੁੰਚ ਹੈ।

### ਵਿਕਲਪ B: OpenCode Free (ਪ੍ਰਮਾਣੀਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ)

1. `http://localhost:20128` ਉੱਤੇ ਡੈਸ਼ਬੋਰਡ ਖੋਲ੍ਹੋ
2. **ਪ੍ਰਦਾਤਾ** → **ਪ੍ਰਦਾਤਾ ਸ਼ਾਮਲ ਕਰੋ** ਉੱਤੇ ਜਾਓ
3. **OpenCode Free** ਚੁਣੋ
4. **ਕਨੈਕਟ ਕਰੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ (API key ਦੀ ਲੋੜ ਨਹੀਂ!)
5. ਹੋ ਗਿਆ! ਹੁਣ ਤੁਹਾਡੇ ਕੋਲ ਕਈ ਮਾਡਲਾਂ ਦੀ ਮੁਫ਼ਤ ਪਹੁੰਚ ਹੈ।

### ਵਿਕਲਪ C: Pollinations (ਕੁੰਜੀ ਦੀ ਲੋੜ ਨਹੀਂ)

1. `http://localhost:20128` ਉੱਤੇ ਡੈਸ਼ਬੋਰਡ ਖੋਲ੍ਹੋ
2. **ਪ੍ਰਦਾਤਾ** → **ਪ੍ਰਦਾਤਾ ਸ਼ਾਮਲ ਕਰੋ** ਉੱਤੇ ਜਾਓ
3. **Pollinations** ਚੁਣੋ
4. **ਕਨੈਕਟ ਕਰੋ** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ (API key ਦੀ ਲੋੜ ਨਹੀਂ!)
5. ਹੋ ਗਿਆ! ਹੁਣ ਤੁਹਾਡੇ ਕੋਲ GPT-5, Claude, Gemini ਅਤੇ ਹੋਰ ਮਾਡਲਾਂ ਦੀ ਮੁਫ਼ਤ ਪਹੁੰਚ ਹੈ।

---

## ਕਦਮ 4: ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਇਹ ਕੰਮ ਕਰਦਾ ਹੈ

[API Keys](http://localhost:20128/dashboard/api-manager) ਤੋਂ ਇੱਕ ਨਵੀਂ ਕੁੰਜੀ ਬਣਾਓ। ਇਸ ਕੁੰਜੀ ਨੂੰ ਸੰਭਾਲ ਕੇ ਰੱਖੋ, ਕਿਉਂਕਿ ਇਹ ਦੁਬਾਰਾ ਦਿਖਾਈ ਨਹੀਂ ਦੇਵੇਗੀ। ਧਿਆਨ ਰਹੇ ਕਿ ਇਹ ਕੁੰਜੀ ਟੂਲਾਂ ਵੱਲੋਂ OmniRoute ਤੱਕ ਪਹੁੰਚ ਲਈ ਹੈ, ਅੱਪਸਟ੍ਰੀਮ ਪ੍ਰਦਾਤਾਵਾਂ ਤੱਕ ਪਹੁੰਚ ਲਈ ਨਹੀਂ।

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

ਤੁਹਾਨੂੰ ਆਪਣੇ ਕਨੈਕਟ ਕੀਤੇ ਮਾਡਲ ਸੂਚੀਬੱਧ ਦਿਖਾਈ ਦੇਣੇ ਚਾਹੀਦੇ ਹਨ।

## ਕਦਮ 5: ਆਪਣੇ IDE ਜਾਂ CLI ਨੂੰ OmniRoute ਵੱਲ ਪੁਆਇੰਟ ਕਰੋ

ਆਪਣੇ IDE ਜਾਂ CLI ਟੂਲ ਵਿੱਚ ਇਹ ਸੈੱਟ ਕਰੋ:

```
ਬੇਸ URL: http://localhost:20128/v1
API ਕੁੰਜੀ:  [ਡੈਸ਼ਬੋਰਡ → ਐਂਡਪੌਇੰਟਸ ਤੋਂ ਕਾਪੀ ਕਰੋ]
ਮਾਡਲ:    auto
```

ਬੱਸ ਇੰਨਾ ਹੀ! ਹੁਣ ਤੁਹਾਡਾ IDE ਸਵੈਚਾਲਿਤ ਪ੍ਰਦਾਤਾ ਚੋਣ ਨਾਲ OmniRoute ਵਰਤਦਾ ਹੈ।

### IDE ਉਦਾਹਰਨ: VSCode/Continue.dev

1. VSCode ਵਿੱਚ [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ਐਕਸਟੈਂਸ਼ਨ ਇੰਸਟਾਲ ਕਰੋ।
2. ਹੇਠ ਲਿਖੀਆਂ ਲਾਈਨਾਂ ਸ਼ਾਮਲ ਕਰਨ ਲਈ ਆਪਣੀ `~/.continue/config.yaml` ਨੂੰ ਅੱਪਡੇਟ ਕਰੋ:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev ਚੈਟ ਪੈਨ ਵਿੱਚ `OmniRoute - Auto` ਚੁਣੋ, ਅਤੇ ਤੁਸੀਂ OmniRoute ਨੂੰ ਬੇਨਤੀਆਂ ਭੇਜੋਗੇ।
4. (ਵਿਕਲਪਿਕ) ਪਾਠਕ ਲਈ ਅਭਿਆਸ — ਆਪਣੇ IDE ਤੋਂ `config.yaml` ਨੂੰ ਹੋਰ ਸਾਰੀਆਂ ਪਹਿਲਾਂ ਤੋਂ ਬਣੀਆਂ ਸੰਰਚਨਾਵਾਂ ਨਾਲ ਅੱਪਡੇਟ ਕਰਵਾਓ 😊

### CLI ਉਦਾਹਰਨ: Codex CLI

1. ਆਪਣੇ ਓਪਰੇਟਿੰਗ ਸਿਸਟਮ ਵਿੱਚ environment variable ਨੂੰ ਸਥਾਈ ਤੌਰ ਉੱਤੇ ਸੈੱਟ ਕਰੋ।
   macOS/Linux ਲਈ (ਆਪਣੀ `~/.bashrc` ਜਾਂ `~/.zshrc` ਵਿੱਚ ਸ਼ਾਮਲ ਕਰੋ):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows ਲਈ (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. ਹੁਣ Codex ਨੂੰ OmniRoute ਲਈ ਸੰਰਚਿਤ ਕਰਕੇ ਚਲਾਈਏ। ਇਹ ਚਲਾਓ:

```
omniroute launch-codex --model auto
```

ਐਂਡਪੌਇੰਟ ਅਤੇ API ਕੁੰਜੀ ਨਿਰਧਾਰਤ ਕਰਨ ਲਈ ਤੁਸੀਂ `codex` ਅਤੇ ਕਮਾਂਡ-ਲਾਈਨ ਪੈਰਾਮੀਟਰਾਂ ਰਾਹੀਂ ਇਹ ਹੱਥੀਂ ਕਰ ਸਕਦੇ ਹੋ, ਪਰ ਉੱਪਰ ਦਿੱਤੀ ਕਮਾਂਡ ਨਾਲ OmniRoute ਤੁਹਾਡੇ ਲਈ ਹਰ ਚੀਜ਼ ਦਾ ਧਿਆਨ ਰੱਖਦਾ ਹੈ।

ਇਹੋ ਇੱਕ-ਕਮਾਂਡ ਲਾਂਚ ਆਮ ਲਾਂਚਰ ਰਾਹੀਂ ਹੋਰ CLIs ਲਈ ਵੀ ਕੰਮ ਕਰਦਾ ਹੈ — `omniroute run <target>` `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, ਅਤੇ `gemini` ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ ([CLI ਇੰਟੀਗ੍ਰੇਸ਼ਨ](../guides/CLI-INTEGRATIONS.md) ਵੇਖੋ)।

3. ਹੁਣ CLI ਨੂੰ OmniRoute ਵੱਲ ਬੇਨਤੀਆਂ ਭੇਜਣੀਆਂ ਚਾਹੀਦੀਆਂ ਹਨ।

### ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਤੁਹਾਡਾ ਟੂਲ OmniRoute ਵੱਲ ਰੂਟ ਕਰ ਰਿਹਾ ਹੈ

ਤੁਸੀਂ ਖੱਬੀ ਸਾਈਡਬਾਰ ਤੋਂ [ਨਿਗਰਾਨੀ/ਲੌਗ](http://localhost:20128/dashboard/logs) ਉੱਤੇ ਕਲਿੱਕ ਕਰਕੇ ਬੇਨਤੀ ਦੇ ਵੇਰਵੇ ਵੇਖ ਸਕਦੇ ਹੋ। ਅੱਗੇ ਕਲਿੱਕ ਕਰਨ ਨਾਲ ਤੁਹਾਨੂੰ ਹੋਰ ਵੇਰਵੇ ਦਿਖਾਈ ਦੇਣਗੇ। ਵਾਧੂ ਜਾਣਕਾਰੀ ਵਜੋਂ, ਤੁਸੀਂ ਦੇਖ ਸਕਦੇ ਹੋ ਕਿ ਤੁਹਾਡੇ ਮਨਪਸੰਦ ਹਾਰਨੈੱਸ ਤੋਂ ਕਿਹੜੀ ਜਾਣਕਾਰੀ ਭੇਜੀ ਜਾਂਦੀ ਹੈ। ਇਹ ਸਿੱਖਿਆ ਅਤੇ ਡੀਬੱਗਿੰਗ ਦੇ ਨਜ਼ਰੀਏ ਤੋਂ ਮਦਦਗਾਰ ਹੈ।

## ਆਮ ਸਵਾਲ

### "ਕੀ ਮੈਨੂੰ API key ਦੀ ਲੋੜ ਹੈ?"

**ਨਹੀਂ!** ਤੁਸੀਂ ਬਿਨਾਂ ਕਿਸੇ API key ਦੇ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ (Kiro, OpenCode Free, Pollinations) ਵਰਤ ਸਕਦੇ ਹੋ। ਬੱਸ ਉਨ੍ਹਾਂ ਨੂੰ ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ ਕਨੈਕਟ ਕਰੋ।

### "`auto` ਕੀ ਹੈ?"

`auto` OmniRoute ਨੂੰ ਹਰ ਬੇਨਤੀ ਲਈ ਆਪਣੇ-ਆਪ ਸਭ ਤੋਂ ਵਧੀਆ ਪ੍ਰਦਾਤਾ ਚੁਣਨ ਲਈ ਕਹਿੰਦਾ ਹੈ। ਇਹ ਗਤੀ, ਲਾਗਤ, ਗੁਣਵੱਤਾ ਅਤੇ ਉਪਲਬਧਤਾ ਨੂੰ ਧਿਆਨ ਵਿੱਚ ਰੱਖਦਾ ਹੈ। ਵੇਰਵਿਆਂ ਲਈ [Auto-Combo ਗਾਈਡ](./AUTO-COMBO-GUIDE.md) ਵੇਖੋ।

### "ਇਸਦੀ ਕੀਮਤ ਕਿੰਨੀ ਹੈ?"

OmniRoute ਖੁਦ **ਮੁਫ਼ਤ ਅਤੇ ਓਪਨ-ਸੋਰਸ** ਹੈ। ਤੁਸੀਂ ਸਿਰਫ਼ ਉਹਨਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਲਈ ਭੁਗਤਾਨ ਕਰਦੇ ਹੋ ਜਿਨ੍ਹਾਂ ਨੂੰ ਤੁਸੀਂ ਵਰਤਦੇ ਹੋ। ਕਈ ਪ੍ਰਦਾਤਾਵਾਂ ਕੋਲ ਮੁਫ਼ਤ ਟੀਅਰ ਹਨ — [ਮੁਫ਼ਤ ਟੀਅਰ ਗਾਈਡ](./FREE-TIERS-GUIDE.md) ਵੇਖੋ।

### "ਕੀ ਮੈਂ ਇਸਨੂੰ Claude Code / Cursor / Copilot ਨਾਲ ਵਰਤ ਸਕਦਾ ਹਾਂ?"

**ਹਾਂ!** OmniRoute OpenAI ਫਾਰਮੈਟ ਦਾ ਸਮਰਥਨ ਕਰਨ ਵਾਲੇ ਕਿਸੇ ਵੀ ਟੂਲ ਨਾਲ ਕੰਮ ਕਰਦਾ ਹੈ। ਬੱਸ ਬੇਸ URL ਨੂੰ `http://localhost:20128/v1` ਉੱਤੇ ਸੈੱਟ ਕਰੋ। ਖਾਸ ਸੈੱਟਅੱਪ ਹਦਾਇਤਾਂ ਲਈ [CLI ਟੂਲ ਗਾਈਡ](../reference/CLI-TOOLS.md) ਵੇਖੋ।

### "ਜੇ ਕੋਈ ਪ੍ਰਦਾਤਾ ਬੰਦ ਹੋ ਜਾਵੇ ਤਾਂ ਕੀ ਹੋਵੇਗਾ?"

OmniRoute ਅਸਫਲ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਆਪਣੇ-ਆਪ ਛੱਡ ਦਿੰਦਾ ਹੈ ਅਤੇ ਅਗਲੇ ਨੂੰ ਅਜ਼ਮਾਉਂਦਾ ਹੈ। ਤੁਹਾਨੂੰ ਕੁਝ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ। ਵੇਰਵਿਆਂ ਲਈ [Auto-Combo ਗਾਈਡ](./AUTO-COMBO-GUIDE.md) ਵੇਖੋ।
