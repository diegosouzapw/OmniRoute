## ਇਹ ਕੀ ਹੈ

Local Corpus ਕਿਸੇ ਓਪਰੇਟਰ ਨੂੰ ਟੈਕਸਟ ਫ਼ਾਈਲਾਂ ਦੀ ਇੱਕ ਸਪਸ਼ਟ ਤੌਰ 'ਤੇ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਡਾਇਰੈਕਟਰੀ
OmniRoute ਦੇ MCP ਸਰਵਰ ਲਈ ਉਪਲਬਧ ਕਰਵਾਉਣ ਦਿੰਦਾ ਹੈ। ਫ਼ਾਈਲਾਂ ਆਪਣੀ ਮੂਲ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ ਹੀ ਰਹਿੰਦੀਆਂ ਹਨ:
OmniRoute SQLite ਵਿੱਚ ਸਿਰਫ਼ ਕੈਨੋਨਿਕਲ ਰੂਟ ਪਾਥ ਸਟੋਰ ਕਰਦਾ ਹੈ ਅਤੇ ਮੈਮੋਰੀ ਵਿੱਚ ਖੋਜ ਇੰਡੈਕਸ ਬਣਾਈ ਰੱਖਦਾ ਹੈ।
ਇਹ ਕਾਰਪਸ ਸਮੱਗਰੀ ਨੂੰ ਰਿਪੋਜ਼ਟਰੀ ਜਾਂ ਡਾਟਾਬੇਸ ਵਿੱਚ ਕਾਪੀ ਨਹੀਂ ਕਰਦਾ।

ਇੰਡੈਕਸ ਰਿਫ੍ਰੈਸ਼ ਕ੍ਰਮਵਾਰ ਹੁੰਦਾ ਹੈ। ਨਾ ਬਦਲੀਆਂ ਫ਼ਾਈਲਾਂ ਨੂੰ ਆਕਾਰ ਅਤੇ ਸੋਧ ਦੇ ਸਮੇਂ ਦੇ ਆਧਾਰ 'ਤੇ
ਮੁੜ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ, ਬਦਲੀਆਂ ਫ਼ਾਈਲਾਂ ਨੂੰ ਦੁਬਾਰਾ ਪੜ੍ਹ ਕੇ SHA-256 ਨਾਲ ਹੈਸ਼ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਅਤੇ ਮਿਟਾਈਆਂ
ਫ਼ਾਈਲਾਂ ਨੂੰ ਹਟਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ। ਖੋਜ 30 ਸਕਿੰਟ ਤੋਂ ਪੁਰਾਣੇ ਇੰਡੈਕਸ ਨੂੰ ਰਿਫ੍ਰੈਸ਼ ਕਰਦੀ ਹੈ; ਕਾਲਰ ਤੁਰੰਤ
ਰਿਫ੍ਰੈਸ਼ ਦੀ ਬੇਨਤੀ ਵੀ ਕਰ ਸਕਦੇ ਹਨ।

## ਸਰੋਤ ਨੂੰ ਕਨਫਿਗਰ ਕਰੋ

ਸੈਟਿੰਗਾਂ ਰੂਟ ਲਈ ਉਹੀ ਪ੍ਰਬੰਧਕੀ ਪ੍ਰਮਾਣੀਕਰਨ ਲੋੜੀਂਦਾ ਹੈ ਜੋ ਹੋਰ ਸੈਟਿੰਗਾਂ APIs ਲਈ ਹੈ।
ਭੇਜਿਆ ਗਿਆ ਪਾਥ ਪਹਿਲਾਂ ਤੋਂ ਮੌਜੂਦ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ ਅਤੇ ਇੱਕ ਐਬਸੋਲਿਊਟ ਡਾਇਰੈਕਟਰੀ ਪਾਥ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ।

```bash
# ਇੱਕ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਡਾਇਰੈਕਟਰੀ ਕਨੈਕਟ ਕਰੋ
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# ਕਨਫਿਗਰੇਸ਼ਨ ਅਤੇ ਇੰਡੈਕਸ ਦੀ ਸਥਿਤੀ ਜਾਂਚੋ
curl http://localhost:20128/api/settings/local-corpus

# ਸਰੋਤ ਫ਼ਾਈਲਾਂ ਨੂੰ ਬਦਲੇ ਬਿਨਾਂ ਡਿਸਕਨੈਕਟ ਕਰੋ
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP ਟੂਲ

ਤਿੰਨਾਂ ਟੂਲਾਂ ਲਈ `read:local-corpus` ਲੋੜੀਂਦਾ ਹੈ। ਟੂਲ ਦੇ ਜਵਾਬ ਰਿਲੇਟਿਵ ਪਾਥ ਅਤੇ
ਰੂਟ ਡਾਇਰੈਕਟਰੀ ਦਾ ਬੇਸਨੇਮ ਦਿਖਾਉਂਦੇ ਹਨ, ਪਰ ਇਸਦਾ ਐਬਸੋਲਿਊਟ ਪਾਥ ਕਦੇ ਨਹੀਂ ਦਿਖਾਉਂਦੇ।

| ਟੂਲ                   | ਵਰਣਨ                                                                                                  |
| :-------------------- | :---------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | ਕਨਫਿਗਰੇਸ਼ਨ ਸਥਿਤੀ, ਇੰਡੈਕਸ ਆਕਾਰ, ਸੀਮਾਵਾਂ ਅਤੇ ਆਖਰੀ ਰਿਫ੍ਰੈਸ਼ ਦਾ ਸਮਾਂ ਰਿਪੋਰਟ ਕਰਦਾ ਹੈ                       |
| `local_corpus_search` | ਇੰਡੈਕਸ ਕੀਤੇ ਟੈਕਸਟ ਵਿੱਚ ਖੋਜ ਕਰਦਾ ਹੈ ਅਤੇ ਸੀਮਿਤ, ਲਾਈਨ-ਕੇਂਦਰਿਤ ਸਨਿੱਪਟ ਵਾਪਸ ਕਰਦਾ ਹੈ (ਵੱਧ ਤੋਂ ਵੱਧ 20 ਨਤੀਜੇ) |
| `local_corpus_read`   | ਇੱਕ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਕਾਰਪਸ-ਰਿਲੇਟਿਵ ਫ਼ਾਈਲ ਵਿੱਚੋਂ ਸੀਮਿਤ ਲਾਈਨ ਰੇਂਜ ਪੜ੍ਹਦਾ ਹੈ                                  |

MCP ਇਨਪੁੱਟਾਂ ਦੀਆਂ ਉਦਾਹਰਨਾਂ:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## ਸੁਰੱਖਿਆ ਸੀਮਾਵਾਂ

- ਅਲਾਉਲਿਸਟ ਟੈਕਸਟ-ਕੇਂਦਰਿਤ ਹੈ: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, ਅਤੇ `.yml`।
- ਸਿਮਲਿੰਕ ਛੱਡ ਦਿੱਤੇ ਜਾਂਦੇ ਹਨ। ਪੜ੍ਹਨ ਵਾਲੇ ਪਾਥ ਕੈਨੋਨਿਕਲ ਬਣਾਏ ਜਾਂਦੇ ਹਨ ਅਤੇ ਉਨ੍ਹਾਂ ਦਾ
  ਕਨਫਿਗਰ ਕੀਤੇ ਰੂਟ ਦੇ ਅੰਦਰ ਰਹਿਣਾ ਲਾਜ਼ਮੀ ਹੈ; ਐਬਸੋਲਿਊਟ ਪਾਥ ਅਤੇ ਟ੍ਰੈਵਰਸਲ ਕੋਸ਼ਿਸ਼ਾਂ ਰੱਦ ਕਰ ਦਿੱਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- ਸੰਵੇਦਨਸ਼ੀਲ ਅਤੇ ਜਨਰੇਟ ਕੀਤੀਆਂ ਡਾਇਰੈਕਟਰੀਆਂ ਦੇ ਨਾਮ ਬਾਹਰ ਰੱਖੇ ਜਾਂਦੇ ਹਨ: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, ਅਤੇ
  `secrets`।
- ਡਿਫੌਲਟ ਸੀਮਾਵਾਂ 5,000 ਫ਼ਾਈਲਾਂ, ਪ੍ਰਤੀ ਫ਼ਾਈਲ 1 MiB, ਕੁੱਲ ਇੰਡੈਕਸ ਕੀਤੀ ਸਮੱਗਰੀ 64 MiB,
  ਪ੍ਰਤੀ ਖੋਜ ਚੰਕ ਲਗਭਗ 4,000 ਅੱਖਰ ਅਤੇ ਪ੍ਰਤੀ ਰੀਡ 400 ਲਾਈਨਾਂ ਹਨ।
- NUL ਵਾਲੀਆਂ ਫ਼ਾਈਲਾਂ ਨੂੰ ਗੈਰ-ਟੈਕਸਟ ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ ਅਤੇ ਛੱਡ ਦਿੱਤਾ ਜਾਂ ਰੱਦ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।

PDF, DOCX, ਚਿੱਤਰਾਂ ਅਤੇ ਆਰਕਾਈਵਾਂ ਵਰਗੇ ਬਾਈਨਰੀ ਦਸਤਾਵੇਜ਼ ਜਾਣਬੁੱਝ ਕੇ ਸਮਰਥਿਤ ਨਹੀਂ ਹਨ।
ਇੰਡੈਕਸਿੰਗ ਤੋਂ ਪਹਿਲਾਂ ਉਨ੍ਹਾਂ ਨੂੰ ਕਨਫਿਗਰ ਕੀਤੀ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ ਕਿਸੇ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਟੈਕਸਟ ਫਾਰਮੈਟ ਵਿੱਚ ਬਦਲੋ।

## ਕਾਰਜਕਾਰੀ ਨੋਟਸ

- ਕਨਫਿਗਰ ਕੀਤੇ ਰੂਟ ਨੂੰ ਬਦਲਣ ਜਾਂ ਮਿਟਾਉਣ ਨਾਲ ਸਾਂਝਾ ਇਨ-ਮੈਮੋਰੀ ਇੰਡੈਕਸ ਸਾਫ਼ ਹੋ ਜਾਂਦਾ ਹੈ।
- ਪ੍ਰਕਿਰਿਆ ਮੁੜ ਚਾਲੂ ਹੋਣ ਨਾਲ ਇੰਡੈਕਸ ਮਿਟ ਜਾਂਦਾ ਹੈ; ਅਗਲੀ ਖੋਜ ਇਸਨੂੰ ਕਨਫਿਗਰ ਕੀਤੇ
  ਸਰੋਤ ਤੋਂ ਦੁਬਾਰਾ ਬਣਾਉਂਦੀ ਹੈ।
- `local_corpus_status` ਸਕੈਨ ਨੂੰ ਲਾਜ਼ਮੀ ਤੌਰ 'ਤੇ ਚਾਲੂ ਨਹੀਂ ਕਰਦਾ। ਜਦੋਂ ਤੁਰੰਤ ਮੁੜ-ਸਕੈਨ ਦੀ ਲੋੜ ਹੋਵੇ ਤਾਂ
  `refresh: true` ਨਾਲ `local_corpus_search` ਵਰਤੋ।
- ਸਕੈਨ ਅਤੇ ਰੀਡ ਅਸਫਲਤਾਵਾਂ ਨੂੰ ਗਿਣਿਆ ਜਾਂ ਸਾਫ਼ ਕੀਤੀਆਂ ਗਲਤੀਆਂ ਵਜੋਂ ਵਾਪਸ ਕੀਤਾ ਜਾਂਦਾ ਹੈ; ਸਰੋਤ ਫ਼ਾਈਲਾਂ ਨੂੰ
  ਕਦੇ ਵੀ ਸੋਧਿਆ ਨਹੀਂ ਜਾਂਦਾ।
