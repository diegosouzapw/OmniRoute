## 1. A2A — ਏਜੰਟ-ਤੋਂ-ਏਜੰਟ

**ਨਿਰਧਾਰਨ:** [A2A v0.3](https://a2a-protocol.org)
**OmniRoute ਐਂਡਪੌਇੰਟ:** `POST /a2a` (JSON-RPC 2.0)
**ਏਜੰਟ ਕਾਰਡ:** `GET /.well-known/agent.json`

### ਕਦੋਂ ਵਰਤਣਾ ਹੈ

- ਅਜਿਹਾ ਬਹੁ-ਏਜੰਟ ਸਿਸਟਮ ਬਣਾਉਂਦੇ ਸਮੇਂ ਜਿਸ ਵਿੱਚ OmniRoute ਪੀਅਰਾਂ ਵਿੱਚੋਂ ਇੱਕ ਹੋਵੇ
- Google ADK ਵਰਗੇ ਫਰੇਮਵਰਕਾਂ ਜਾਂ ਸਧਾਰਨ ਏਜੰਟ ਮੇਸ਼ਾਂ ਵਿੱਚ ਏਜੰਟਾਂ ਲਈ OmniRoute ਦੀ ਰੂਟਿੰਗ ਸਮਰੱਥਾ (ਸਮਾਰਟ ਰੂਟਿੰਗ, ਕੋਟਾ ਪ੍ਰਬੰਧਨ, ਆਦਿ) ਉਪਲਬਧ ਕਰਵਾਉਣ ਲਈ
- OmniRoute ਨੂੰ ਇੱਕ ਮਿਆਰੀ ਖੋਜ + ਸੱਦਾ ਇੰਟਰਫੇਸ ਦੇ ਪਿੱਛੇ ਰੈਪ ਕਰਨ ਲਈ

### ਢੰਗ

- `message/send` — ਸੁਨੇਹਾ ਭੇਜੋ, ਸਮਕਾਲੀ ਜਵਾਬ ਪ੍ਰਾਪਤ ਕਰੋ
- `message/stream` — ਸੁਨੇਹਾ ਭੇਜੋ + SSE ਰਾਹੀਂ ਸਟ੍ਰੀਮ ਕੀਤੇ ਪ੍ਰਗਤੀ ਇਵੈਂਟ ਪ੍ਰਾਪਤ ਕਰੋ
- `tasks/get` — ID ਰਾਹੀਂ ਕਾਰਜ ਪੜ੍ਹੋ
- `tasks/cancel` — ਚੱਲ ਰਿਹਾ ਕਾਰਜ ਰੱਦ ਕਰੋ

### ਬਿਲਟ-ਇਨ ਹੁਨਰ (6)

- `smart-routing` — ਪ੍ਰੌਂਪਟ ਨੂੰ ਸਭ ਤੋਂ ਢੁਕਵੇਂ ਕੌਂਬੋ ਰਾਹੀਂ ਰੂਟ ਕਰੋ
- `quota-management` — ਹਰ ਪ੍ਰਦਾਤਾ ਦੀ ਕੋਟਾ ਸਥਿਤੀ ਦੀ ਰਿਪੋਰਟ ਕਰੋ
- `provider-discovery` — ਸਮਰੱਥਾਵਾਂ ਸਮੇਤ ਇੰਸਟਾਲ ਕੀਤੇ ਪ੍ਰਦਾਤਾਵਾਂ ਦੀ ਸੂਚੀ ਦਿਓ
- `cost-analysis` — ਕਿਸੇ ਬੇਨਤੀ/ਗੱਲਬਾਤ ਦੀ ਲਾਗਤ ਦਾ ਅਨੁਮਾਨ ਲਗਾਓ
- `health-report` — ਹਰ ਪ੍ਰਦਾਤਾ ਦੀ ਬ੍ਰੇਕਰ/ਕੂਲਡਾਊਨ/ਲਾਕਆਊਟ ਸਥਿਤੀ ਨੂੰ ਇਕੱਤਰ ਕਰੋ
- `list-capabilities` — ਏਜੰਟ ਦੇ ਉਪਲਬਧ ਹੁਨਰਾਂ ਅਤੇ ਮੈਟਾਡੇਟਾ ਦੀ ਸੂਚੀ ਦਿਓ

### ਵਿਸਤ੍ਰਿਤ ਜਾਣਕਾਰੀ

ਟ੍ਰਾਂਸਪੋਰਟ ਵੇਰਵਿਆਂ, ਏਜੰਟ ਕਾਰਡ ਦੀ ਬਣਤਰ, ਕਾਰਜ TTL ਕੌਂਫਿਗਰੇਸ਼ਨ ਅਤੇ ਨਵੇਂ ਹੁਨਰ ਜੋੜਨ ਲਈ ਟੈਂਪਲੇਟ ਵਾਸਤੇ [A2A-SERVER.md](./A2A-SERVER.md) ਵੇਖੋ।

## 2. ACP — CLI ਏਜੰਟ ਰਜਿਸਟਰੀ

**OmniRoute ਐਂਡਪੌਇੰਟ:** `GET /api/acp/agents`
**ਸਰੋਤ:** `src/lib/acp/{index,manager,registry}.ts`

### ਇਹ ਕੀ ਹੈ

ACP OmniRoute ਦੀ **ਸਥਾਨਕ CLI ਏਜੰਟ ਸੂਚੀ** ਹੈ। ਇਹ ਪਤਾ ਲਗਾਉਂਦੀ ਹੈ ਕਿ ਹੋਸਟ ਉੱਤੇ ਕਿਹੜੀਆਂ ਕੋਡਿੰਗ CLI ਇੰਸਟਾਲ ਹਨ (Cursor, Cline, Claude Code, Codex CLI, Continue ਆਦਿ), ਉਨ੍ਹਾਂ ਦੇ ਵਰਜਨ ਨਿਰਧਾਰਤ ਕਰਦੀ ਹੈ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ ਡੈਸ਼ਬੋਰਡ ਉੱਤੇ ਦਿਖਾਉਂਦੀ ਹੈ, ਤਾਂ ਜੋ ਵਰਤੋਂਕਾਰ ਹਰ CLI ਨੂੰ OmniRoute ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਨ ਲਈ ਜੋੜ ਸਕੇ।

ਇਹ ਕੋਈ ਬਾਹਰੀ ਪ੍ਰੋਟੋਕੋਲ ਨਹੀਂ ਹੈ — ਇਹ ਇੱਕ ਅੰਦਰੂਨੀ ਰਜਿਸਟਰੀ ਹੈ ਜੋ "CLI Tools" UI ਅਤੇ CLI ਫਿੰਗਰਪ੍ਰਿੰਟ ਟ੍ਰੈਕਿੰਗ ਨੂੰ ਚਲਾਉਂਦੀ ਹੈ ([CLI-TOOLS.md](../reference/CLI-TOOLS.md) ਵੇਖੋ)।

### ਇਹ ਕੀ ਕਰਦੀ ਹੈ

- ਇੰਸਟਾਲ ਕੀਤੀਆਂ CLI ਬਾਈਨਰੀਆਂ ਲਈ ਹੋਸਟ ਦੀ ਜਾਂਚ ਕਰਦੀ ਹੈ (ਹਰੇਕ OS ਮੁਤਾਬਕ `which` / `where` ਵਰਤਦੀ ਹੈ)
- ਹਰੇਕ CLI ਦਾ ਵਰਜਨ ਪੜ੍ਹਦੀ ਹੈ (`<bin> --version` ਨੂੰ ਕਾਲ ਕਰਦੀ ਹੈ)
- ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ ਵਰਤੋਂਕਾਰ ਵੱਲੋਂ ਪਰਿਭਾਸ਼ਿਤ ਕਸਟਮ ਏਜੰਟ ਸਵੀਕਾਰ ਕਰਦੀ ਹੈ (ਬਾਈਨਰੀ ਪਾਥ + ਵਰਜਨ ਜਾਂਚ + ਸਪੌਨ ਆਰਗੂਮੈਂਟ)
- ਕਸਟਮ ਏਜੰਟਾਂ ਨੂੰ ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸੰਭਾਲਦੀ ਹੈ
- ਡੈਸ਼ਬੋਰਡ ਨੂੰ ਇਕਸਾਰ ਸੂਚੀ ਵਾਪਸ ਕਰਦੀ ਹੈ

### REST API

| ਐਂਡਪੌਇੰਟ          | ਵਿਧੀ | ਵੇਰਵਾ                                                      | ਪ੍ਰਮਾਣੀਕਰਨ |
| ----------------- | ---- | ---------------------------------------------------------- | ---------- |
| `/api/acp/agents` | GET  | ਖੋਜੇ ਗਏ + ਕਸਟਮ ਏਜੰਟਾਂ ਦੀ ਸੂਚੀ (ਇੰਸਟਾਲ/ਕੁੱਲ ਗਿਣਤੀ)          | API ਕੁੰਜੀ  |
| `/api/acp/agents` | POST | ਕਸਟਮ ਏਜੰਟ ਜੋੜੋ/ਅੱਪਡੇਟ ਕਰੋ/ਹਟਾਓ (ਬਾਡੀ ਵਿੱਚ ਕਾਰਵਾਈ ਪਛਾਣਕਰਤਾ) | API ਕੁੰਜੀ  |

POST ਲਈ ਬਾਡੀ ਦਾ ਰੂਪ (`src/app/api/acp/agents/route.ts` ਵਿੱਚ `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ

- ਡੈਸ਼ਬੋਰਡ ਦਾ "CLI Tools" ਪੰਨਾ ਇੰਸਟਾਲ ਕੀਤੇ ਟੂਲਾਂ ਦੀ ਸੂਚੀ ਦਿਖਾਉਂਦਾ ਹੈ ਅਤੇ ਹਰ ਇੱਕ ਨੂੰ OmniRoute ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਨ ਵਿੱਚ ਤੁਹਾਡੀ ਮਦਦ ਕਰਦਾ ਹੈ
- ਕਸਟਮ ਏਜੰਟ ਉੱਨਤ ਵਰਤੋਂਕਾਰਾਂ ਨੂੰ ਉਹ ਅੰਦਰੂਨੀ/ਮਲਕੀਅਤ ਵਾਲੀਆਂ CLI ਰਜਿਸਟਰ ਕਰਨ ਦਿੰਦੇ ਹਨ ਜਿਨ੍ਹਾਂ ਬਾਰੇ OmniRoute ਨੂੰ ਮੂਲ ਰੂਪ ਵਿੱਚ ਜਾਣਕਾਰੀ ਨਹੀਂ ਹੁੰਦੀ
- ਖੋਜ ਦਾ ਨਤੀਜਾ `cli-tools` ਫਿੰਗਰਪ੍ਰਿੰਟ ਮੈਟ੍ਰਿਕਸ ਨੂੰ ਡਾਟਾ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ

### ACP ਕਦੋਂ ਨਾ ਵਰਤਿਆ ਜਾਵੇ

- ACP ਟਾਸਕਾਂ ਨੂੰ _ਚਲਾਉਂਦੀ_ ਨਹੀਂ ਹੈ। ਇਹ ਸਿਰਫ਼ CLI ਨੂੰ ਖੋਜਦੀ + ਕੌਂਫਿਗਰ ਕਰਦੀ ਹੈ। ਕਿਸੇ CLI ਨੂੰ ਅਸਲ ਵਿੱਚ ਚਲਾਉਣ ਲਈ, ਤੁਸੀਂ OmniRoute ਵੱਲੋਂ ਦਿੱਤੇ env vars (`OPENAI_BASE_URL`, `OPENAI_API_KEY` ਆਦਿ) ਨਾਲ ਇਸਨੂੰ ਖੁਦ ਲਾਂਚ ਕਰਦੇ ਹੋ।

## 3. ਕਲਾਉਡ ਏਜੰਟ

**OmniRoute ਐਂਡਪੌਇੰਟ:** `/api/v1/agents/tasks/*` (ਜੀਵਨ-ਚੱਕਰ) + `/api/cloud/*` (ਅੰਦਰੂਨੀ ਜੋੜਤੋੜ)
**ਸਰੋਤ:** `src/lib/cloudAgent/`

### ਇਹ ਕੀ ਹੈ

ਤੀਜੀ-ਧਿਰ ਦੇ ਕਲਾਉਡ ਕੋਡਿੰਗ ਏਜੰਟਾਂ ਲਈ ਇੱਕ ਇਕਸਾਰ ਇੰਟਰਫੇਸ। ਤੁਸੀਂ ਇੱਕ ਪ੍ਰੌਂਪਟ + ਰਿਪੋ URL ਸਪੁਰਦ ਕਰਦੇ ਹੋ, OmniRoute ਇਸਨੂੰ ਸਹੀ ਕਲਾਉਡ ਏਜੰਟ ਕੋਲ ਭੇਜਦਾ ਹੈ, ਸਥਿਤੀ ਦੀ ਵਾਰ-ਵਾਰ ਜਾਂਚ ਕਰਦਾ ਹੈ ਅਤੇ ਨਤੀਜੇ ਵਾਪਸ ਕਰਦਾ ਹੈ।

### ਸਮਰਥਿਤ ਏਜੰਟ (`src/lib/cloudAgent/agents/` ਵਿੱਚ ਸਾਰੇ 4 ਦੀ ਪੁਸ਼ਟੀ ਕੀਤੀ ਗਈ ਹੈ)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### ਜੀਵਨ-ਚੱਕਰ

```
POST /api/v1/agents/tasks
  → ਹਰੇਕ ਏਜੰਟ ਕਲਾਸ ਲਈ BaseAgent.createTask()
  → ਬਾਹਰੀ ਸੇਵਾ ਕੰਮ ਸ਼ੁਰੂ ਕਰਦੀ ਹੈ
  → DB ਵਿੱਚ ਟਾਸਕ ਕਤਾਰ ਬਣਾਈ ਜਾਂਦੀ ਹੈ (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → ਪ੍ਰਦਾਤਾ ਤੋਂ ਲੋੜ ਅਨੁਸਾਰ ਸਥਿਤੀ ਸਿੰਕ
  → ਮੌਜੂਦਾ ਸਥਿਤੀ + ਯੋਜਨਾ + ਸਰਗਰਮੀ ਲੌਗ ਵਾਪਸ ਕਰਦਾ ਹੈ
  ↓
POST /api/v1/agents/tasks/[id]   (ਕਾਰਵਾਈ: "approve" | "message" | "cancel")
  → ਪ੍ਰਦਾਤਾ ਨੂੰ ਅੱਗੇ ਭੇਜਦਾ ਹੈ (ਜਾਂ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਰੱਦ ਕੀਤਾ ਚਿੰਨ੍ਹਿਤ ਕਰਦਾ ਹੈ)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → ਸਥਾਨਕ ਰੱਦਗੀ
```

### ਪ੍ਰਮਾਣੀਕਰਨ

⚠️ **ਸਾਰੇ `/api/v1/agents/tasks/*` ਐਂਡਪੌਇੰਟਾਂ ਲਈ ਪ੍ਰਬੰਧਨ ਪ੍ਰਮਾਣੀਕਰਨ ਲਾਜ਼ਮੀ ਹੈ** (ਕਮਿਟ `588a0333`)। v3.8.0 ਤੋਂ ਸਿਰਫ਼ Bearer ਵਰਤਣ ਵਾਲੇ ਕਾਲਰਾਂ ਨੂੰ 401 ਜਵਾਬ ਮਿਲਦਾ ਹੈ।

### ਵਿਸਤ੍ਰਿਤ ਜਾਣਕਾਰੀ

`CloudAgentBase` ਇਕਰਾਰਨਾਮੇ, ਹਰੇਕ ਏਜੰਟ ਦੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ, ਸਕੀਮਾ ਵੇਰਵਿਆਂ ਅਤੇ ਕ੍ਰੈਡੈਂਸ਼ਲ ਜੋੜਤੋੜ ਐਂਡਪੌਇੰਟਾਂ ਲਈ [CLOUD_AGENT.md](./CLOUD_AGENT.md) ਵੇਖੋ।

## ਤੁਲਨਾ: A2A ਬਨਾਮ Cloud Agents

ਦੋਵਾਂ ਵਿੱਚ "ਲੰਬੇ ਸਮੇਂ ਤੱਕ ਚੱਲਣ ਵਾਲੇ ਕਾਰਜ" ਹਨ, ਪਰ ਵੱਖ-ਵੱਖ ਪਰਤਾਂ 'ਤੇ:

| ਪਹਿਲੂ                 | A2A                                                                         | Cloud Agents                         |
| --------------------- | --------------------------------------------------------------------------- | ------------------------------------ |
| ਮਿਆਰ                  | Open A2A v0.3                                                               | OmniRoute-ਵਿਸ਼ੇਸ਼                    |
| ਕੰਪਿਊਟ ਕਿੱਥੇ ਚੱਲਦਾ ਹੈ | OmniRoute ਦੇ ਅੰਦਰ (ਕੌਂਫਿਗਰ ਕੀਤੇ ਕੰਬੋ ਵਰਤਦਾ ਹੈ)                              | ਬਾਹਰੀ (Codex / Devin / Jules ਸਰਵਰ)   |
| ਕਾਰਜ ਦੀ ਮਿਆਦ          | ਡਿਫੌਲਟ TTL 5 ਮਿੰਟ (`TaskManager` ਵਿੱਚ ਕੌਂਫਿਗਰ ਕਰਨ ਯੋਗ)                      | ਮਿੰਟਾਂ ਤੋਂ ਘੰਟਿਆਂ ਤੱਕ                |
| ਰਿਪੋ-ਜਾਗਰੂਕ           | ਨਹੀਂ (ਸਿਰਫ਼ ਪ੍ਰੌਂਪਟ ਪਾਸ ਕਰਦਾ ਹੈ)                                            | ਹਾਂ (ਰਿਪੋ URL + ਬ੍ਰਾਂਚ)              |

| ਪ੍ਰਮਾਣੀਕਰਨ            | `/a2a` ਲਈ ਵਿਕਲਪਿਕ `OMNIROUTE_API_KEY`; `/api/a2a/*` REST ਸਹਾਇਕਾਂ ਲਈ ਪ੍ਰਬੰਧਨ | ਹਮੇਸ਼ਾ ਪ੍ਰਬੰਧਨ                       |

## ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਉਦਾਹਰਨਾਂ

### OmniRoute ਦੀਆਂ A2A ਸਮਰੱਥਾਵਾਂ ਖੋਜੋ

```bash
curl http://localhost:20128/.well-known/agent.json
```

ਸਾਰੇ 6 ਹੁਨਰਾਂ, ਟ੍ਰਾਂਸਪੋਰਟਾਂ ਅਤੇ ਵਰਜਨ ਸਮੇਤ Agent Card ਵਾਪਸ ਕਰਦਾ ਹੈ।

### OmniRoute ਨੂੰ ਇੱਕ A2A ਏਜੰਟ ਵਜੋਂ ਕਾਲ ਕਰੋ

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### ACP ਰਾਹੀਂ ਇੰਸਟਾਲ ਕੀਤੇ CLI ਏਜੰਟਾਂ ਦੀ ਸੂਚੀ ਪ੍ਰਾਪਤ ਕਰੋ

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### ਇੱਕ ਕਸਟਮ CLI ਏਜੰਟ ਸ਼ਾਮਲ ਕਰੋ

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

### ਇੱਕ Cloud Agent ਕਾਰਜ ਸਪੁਰਦ ਕਰੋ

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Implement feature X in repo Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### ਕਲਾਉਡ ਕਾਰਜ ਦੀ ਸਥਿਤੀ ਲਈ ਪੋਲ ਕਰੋ

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```
