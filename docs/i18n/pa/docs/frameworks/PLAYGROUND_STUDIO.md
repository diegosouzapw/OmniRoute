## ਸੰਖੇਪ ਜਾਣਕਾਰੀ

Playground Studio `/dashboard/playground` ਨੂੰ ਇੱਕ ਸਧਾਰਨ Monaco-ਅਧਾਰਿਤ ਐਡੀਟਰ ਤੋਂ
ਇੱਕ ਪੂਰੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਵਾਲੇ ਟੈਸਟਿੰਗ ਵਰਕਸਪੇਸ ਵਿੱਚ ਬਦਲਦਾ ਹੈ। ਇਹ ਪੁਰਾਣੇ `page.tsx` ਨੂੰ ਇੱਕ `PlaygroundStudio`
ਸ਼ੈੱਲ ਨਾਲ ਬਦਲਦਾ ਹੈ, ਜੋ ਚਾਰ ਟੈਬਾਂ ਅਤੇ ਇੱਕ ਸਾਂਝਾ ਕੌਂਫਿਗ ਪੈਨ ਦਿਖਾਉਂਦਾ ਹੈ।


## ਟੈਬਾਂ

### ਚੈਟ ਟੈਬ

`ChatPlayground.tsx` ਨੂੰ ਇੱਕ ਮਲਟੀ-ਟਰਨ ਸਟ੍ਰੀਮਿੰਗ ਵਰਕਬੈਂਚ ਵਜੋਂ ਵਿਕਸਿਤ ਕਰਦੀ ਹੈ:

- `MarkdownMessage.tsx` ਰਾਹੀਂ ਪੂਰੀ markdown ਰੈਂਡਰਿੰਗ (ਕੋਡ ਬਲਾਕ, ਟੇਬਲਾਂ, ਸੂਚੀਆਂ, ਲਿੰਕ)।
- ਸਿਸਟਮ ਪ੍ਰੌਂਪਟ ਸਾਂਝੇ ਕੌਂਫਿਗ ਪੈਨ ਤੋਂ ਲਿਆ ਜਾਂਦਾ ਹੈ।
- ਪ੍ਰਤੀ ਸੁਨੇਹਾ ਟੋਕਨ/ਲਾਗਤ (ਪ੍ਰੌਂਪਟ + ਕੰਪਲੀਸ਼ਨ ਟੋਕਨ)।
- ਆਖਰੀ ਜਵਾਬ ਦੁਬਾਰਾ ਤਿਆਰ ਕਰੋ।
- SSE ਸਟ੍ਰੀਮਿੰਗ ਨਾਲ `POST /v1/chat/completions` ਨੂੰ ਭੇਜਦੀ ਹੈ।

### ਤੁਲਨਾ ਟੈਬ

ਇੱਕ ਪ੍ਰੌਕਸੀ ਲਈ ਮੁੱਖ ਵਿਸ਼ੇਸ਼ਤਾ: 1 ਪ੍ਰੌਂਪਟ ਨੂੰ ਵੱਧ ਤੋਂ ਵੱਧ **4 ਮਾਡਲਾਂ 'ਤੇ ਸਮਾਂਤਰ ਤੌਰ 'ਤੇ** ਚਲਾਓ।

- ਵੱਧ ਤੋਂ ਵੱਧ 4 ਕਾਲਮ, ਹਰੇਕ `/v1/chat/completions` ਤੋਂ ਸੁਤੰਤਰ ਤੌਰ 'ਤੇ ਸਟ੍ਰੀਮ ਕਰਦਾ ਹੈ।
- ਕਾਲਮ ਜੋੜਨ ਲਈ `+ ਮਾਡਲ ਜੋੜੋ` ਬਟਨ (Cmd+K ਸ਼ਾਰਟਕੱਟ)।
- `ਸਾਰੇ ਚਲਾਓ ▶`, `Promise.all` + ਪ੍ਰਤੀ-ਕਾਲਮ `AbortController` ਰਾਹੀਂ ਸਾਰੀਆਂ ਸਟ੍ਰੀਮਾਂ ਨੂੰ ਇੱਕੋ ਸਮੇਂ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ।
- ਗਲੋਬਲ **ਸਾਰੇ ਰੱਦ ਕਰੋ** ਹਰ ਚੱਲ ਰਹੀ ਸਟ੍ਰੀਮ ਨੂੰ ਰੋਕਦਾ ਹੈ।
- ਪ੍ਰਤੀ-ਕਾਲਮ `ProviderMetrics`, TTFT, TPS, ਟੋਕਨ ਅਤੇ ਅਨੁਮਾਨਿਤ ਲਾਗਤ ਨੂੰ ਰੀਅਲ ਟਾਈਮ ਵਿੱਚ ਦਿਖਾਉਂਦਾ ਹੈ।
- ਮੈਟ੍ਰਿਕਸ ਨੂੰ **"ਕਲਾਇੰਟ-ਸਾਈਡ ਅਨੁਮਾਨ"** (D12) ਲੇਬਲ ਕੀਤਾ ਗਿਆ ਹੈ — ਪਹਿਲੇ SSE ਚੰਕ ਤੋਂ ਮਾਪਿਆ ਜਾਂਦਾ ਹੈ।

### API ਟੈਬ

ਉੱਨਤ ਵਰਤੋਂਕਾਰਾਂ ਲਈ ਮੂਲ Monaco ਐਡੀਟਰ ਦਾ 100% ਹਿੱਸਾ ਸੁਰੱਖਿਅਤ ਰੱਖਦੀ ਹੈ (D14):

- 10 ਐਂਡਪੌਇੰਟ: ਚੈਟ ਕੰਪਲੀਸ਼ਨ, ਕੰਪਲੀਸ਼ਨ, ਐਮਬੈਡਿੰਗ, ਚਿੱਤਰ, ਆਡੀਓ, ਸਪੀਚ, ਟ੍ਰਾਂਸਕ੍ਰਿਪਸ਼ਨ, ਮੋਡਰੇਸ਼ਨ, ਰੀਰੈਂਕ, ਖੋਜ।
- ਮਲਟੀਮੋਡਲ ਫ਼ਾਈਲ ਅੱਪਲੋਡ।
- ਰੀਅਲ-ਟਾਈਮ ਆਉਟਪੁੱਟ ਨਾਲ SSE ਸਟ੍ਰੀਮਿੰਗ।
- `ApiTab.tsx` ਵਜੋਂ ਰੈਪ ਕੀਤਾ ਗਿਆ ਹੈ (ਲੇਜ਼ੀ-ਲੋਡ ਕੀਤਾ, `ssr: false`)।

### ਬਿਲਡ ਟੈਬ

ਟੂਲ/ਫੰਕਸ਼ਨ ਕਾਲਿੰਗ ਅਤੇ ਸਟ੍ਰਕਚਰਡ ਆਉਟਪੁੱਟ UI:

- `ToolsBuilder.tsx` — ਪ੍ਰਤੀ ਟੂਲ JSON ਸਕੀਮਾ ਐਡੀਟਰ ਨਾਲ `tools[]` ਨੂੰ ਜੋੜੋ/ਸੋਧੋ/ਹਟਾਓ।
  `ToolDefinitionSchema` (Zod) ਰਾਹੀਂ ਪੈਰਾਮੀਟਰਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰਦਾ ਹੈ।
- `StructuredOutputEditor.tsx` — JSON ਮੋਡ ਟੌਗਲ + JSON ਸਕੀਮਾ ਐਡੀਟਰ।
  `StructuredOutputSchema` (Zod) ਰਾਹੀਂ ਸਕੀਮਾ ਦੇ ਮੁਕਾਬਲੇ ਜਵਾਬ ਦੀ ਪੁਸ਼ਟੀ ਕਰਦਾ ਹੈ।
- `tools[]` ਅਤੇ/ਜਾਂ `response_format` ਨਾਲ ਬੇਨਤੀ ਨੂੰ `/v1/chat/completions` 'ਤੇ ਭੇਜਦੀ ਹੈ।

## ਪ੍ਰੌਂਪਟ ਸੁਧਾਰਕ

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. ਮੋਡਲ ਚੇਤਾਵਨੀ ਦਿੰਦਾ ਹੈ ਕਿ "ਕੋਟਾ ਵਰਤਿਆ ਜਾਵੇਗਾ"।
2. ਪੁਸ਼ਟੀ ਹੋਣ 'ਤੇ, ਰੂਟ ਨੂੰ `{ system, prompt, model, tone }` ਭੇਜਦਾ ਹੈ।
3. ਰੂਟ ਅੰਦਰੂਨੀ ਤੌਰ 'ਤੇ `promptImprover.META_SYSTEM_PROMPT` ਨਾਲ `/v1/chat/completions` ਨੂੰ ਕਾਲ ਕਰਦਾ ਹੈ।
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` ਵਾਪਸ ਕਰਦਾ ਹੈ।
5. UI, ਕੌਂਫਿਗ ਪੇਨ ਦੇ ਸਿਸਟਮ ਪ੍ਰੌਂਪਟ ਅਤੇ ਚੈਟ ਟੈਬ ਦੇ ਯੂਜ਼ਰ ਪ੍ਰੌਂਪਟ ਨੂੰ ਪੈਚ ਕਰਦਾ ਹੈ।

- ਹਰ ਪ੍ਰੀਸੈੱਟ ਇਹ ਸਟੋਰ ਕਰਦਾ ਹੈ: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`।

## ਸਟ੍ਰੀਮ ਮੈਟ੍ਰਿਕਸ

`useStreamMetrics.ts` + `streamMetrics.ts` (ਸ਼ੁੱਧ ਫੰਕਸ਼ਨ):

- `start()` — ਬੇਨਤੀ ਦਾ ਸ਼ੁਰੂਆਤੀ ਸਮਾਂ ਰਿਕਾਰਡ ਕਰਦਾ ਹੈ।
- `onFirstChunk()` — TTFT ਰਿਕਾਰਡ ਕਰਦਾ ਹੈ।
- `onChunk(n)` — ਪੂਰਨਤਾ ਟੋਕਨਾਂ ਦੀ ਗਿਣਤੀ ਇਕੱਠੀ ਕਰਦਾ ਹੈ।
- `finish(usage?)` — ਅੰਤਿਮ ਮੈਟ੍ਰਿਕਸ ਦੀ ਗਣਨਾ ਕਰਦਾ ਹੈ: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`।
- ਕੀਮਤਾਂ `src/lib/playground/types.ts` ਵਿੱਚ ਸਥਿਰ ਟੇਬਲ ਤੋਂ ਹਨ ("ਅਨੁਮਾਨਿਤ" ਵਜੋਂ ਲੇਬਲ ਕੀਤੀਆਂ — D13)।
