Agent Skills ਸੰਰਚਿਤ SKILL.md ਫ਼ਾਈਲਾਂ ਹਨ ਜੋ ਬਾਹਰੀ ਏਜੰਟਾਂ, MCP ਕਲਾਇੰਟਾਂ ਅਤੇ A2A ਆਰਕੈਸਟਰੇਟਰਾਂ ਨੂੰ OmniRoute ਦੀ REST API ਅਤੇ CLI ਵਰਤਣ ਦਾ ਤਰੀਕਾ ਸਿਖਾਉਂਦੀਆਂ ਹਨ। [Omni Skills](./SKILLS.md) (ਜੋ OmniRoute ਦੇ ਅੰਦਰ ਚਲਾਈਆਂ ਜਾਣ ਵਾਲੀਆਂ LLM ਟੂਲ ਪਰਿਭਾਸ਼ਾਵਾਂ ਹਨ) ਤੋਂ ਉਲਟ, Agent Skills ਇੱਕ _ਦਸਤਾਵੇਜ਼ੀ ਕੈਟਾਲਾਗ_ ਹਨ — ਸਥਿਰ ਮਾਰਕਡਾਊਨ ਜਿਸਨੂੰ ਸਿੱਧੇ ਏਜੰਟ ਸੰਦਰਭ ਵਿੱਚ ਦਿੱਤਾ ਜਾ ਸਕਦਾ ਹੈ।

---

## ਸੰਖੇਪ ਜਾਣਕਾਰੀ

ਕੈਟਾਲਾਗ ਵਿੱਚ **45 Agent Skills** (23 REST API + 21 CLI + 1 ਸੰਰਚਨਾ ਵਰਕਫ਼ਲੋ) ਸ਼ਾਮਲ ਹਨ। ਹਰ ਸਕਿੱਲ ਵਿੱਚ ਇਹ ਹੁੰਦਾ ਹੈ:

- ਇੱਕ **ਮਿਆਰੀ ID** (`omni-auth`, `cli-serve`, ਆਦਿ)
- `skills/{id}/SKILL.md` ਵਿੱਚ ਇੱਕ **SKILL.md** ਫ਼ਾਈਲ, ਜਿਸ ਵਿੱਚ YAML ਫਰੰਟਮੈਟਰ (`name`, `description`) + ਵਿਸਤ੍ਰਿਤ ਮਾਰਕਡਾਊਨ ਬਾਡੀ ਹੁੰਦੀ ਹੈ
- OpenAPI ਵਿਸ਼ੇਸ਼ਤਾ ਅਤੇ CLI ਰਜਿਸਟਰੀ ਤੋਂ ਪ੍ਰਾਪਤ **REST ਐਂਡਪੌਇੰਟ** (API ਸਕਿੱਲਾਂ) ਜਾਂ **CLI ਸਬਕਮਾਂਡਾਂ** (CLI ਸਕਿੱਲਾਂ)
- ਲਾਈਵ ਪ੍ਰਾਪਤੀ ਲਈ ਇੱਕ **GitHub ਰੌ URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API ਖੋਜ

| ਐਂਡਪੌਇੰਟ                     | ਢੰਗ  | ਵੇਰਵਾ                                                                  | ਪ੍ਰਮਾਣੀਕਰਨ |
| :--------------------------- | :--- | :--------------------------------------------------------------------- | :--------- |
| `/api/agent-skills`          | GET  | ਕੈਟਾਲਾਗ ਸੂਚੀਬੱਧ ਕਰੋ (ਵਿਕਲਪਿਕ `?category=api\|cli\|config&area=<area>`) | ਕੋਈ ਨਹੀਂ   |
| `/api/agent-skills/{id}`     | GET  | ਇੱਕ ਸਕਿੱਲ ਦਾ ਮੈਟਾਡਾਟਾ ਪ੍ਰਾਪਤ ਕਰੋ                                       | ਕੋਈ ਨਹੀਂ   |
| `/api/agent-skills/{id}/raw` | GET  | SKILL.md ਨੂੰ `text/markdown` ਵਜੋਂ ਪ੍ਰਾਪਤ ਕਰੋ                           | ਕੋਈ ਨਹੀਂ   |
| `/api/agent-skills/coverage` | GET  | ਕਵਰੇਜ ਅੰਕੜੇ (ਕਿੰਨੀਆਂ SKILL.md ਫ਼ਾਈਲਾਂ ਮੌਜੂਦ ਹਨ)                        | ਕੋਈ ਨਹੀਂ   |
| `/api/agent-skills/generate` | POST | ਜਨਰੇਟਰ ਚਲਾਓ (dryRun/prune/onlyIds)                                     | ਪ੍ਰਬੰਧਨ    |

ਉਦਾਹਰਨ — ਸਾਰੀਆਂ API ਸਕਿੱਲਾਂ ਸੂਚੀਬੱਧ ਕਰੋ:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ਉਦਾਹਰਨ — ਇੱਕ SKILL.md ਪ੍ਰਾਪਤ ਕਰੋ:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP ਖੋਜ

`read:catalog` ਸਕੋਪ ਹੇਠ ਤਿੰਨ MCP ਟੂਲ ਰਜਿਸਟਰ ਕੀਤੇ ਗਏ ਹਨ:

| ਟੂਲ                               | ਵੇਰਵਾ                                                   |
| :-------------------------------- | :------------------------------------------------------ |
| `omniroute_agent_skills_list`     | ਸਕਿੱਲਾਂ ਸੂਚੀਬੱਧ ਕਰੋ (ਵਿਕਲਪਿਕ `category` / `area` ਫਿਲਟਰ) |
| `omniroute_agent_skills_get`      | `id` ਰਾਹੀਂ ਇੱਕ ਸਕਿੱਲ ਲਈ ਮੈਟਾਡਾਟਾ + SKILL.md ਪ੍ਰਾਪਤ ਕਰੋ  |
| `omniroute_agent_skills_coverage` | ਕਵਰੇਜ ਅੰਕੜੇ (API/CLI ਮੌਜੂਦ/ਕੁੱਲ)                        |

ਸਕੋਪ ਵਾਇਰਿੰਗ ਅਤੇ ਪ੍ਰਮਾਣੀਕਰਨ ਲਈ [MCP-SERVER.md](./MCP-SERVER.md) ਵੇਖੋ।

## A2A ਖੋਜ

A2A ਸਕਿੱਲ `list-capabilities` ਪੂਰਾ 45-ਸਕਿੱਲ ਕੈਟਾਲਾਗ ਇੱਕ ਮਾਰਕਡਾਊਨ ਟੇਬਲ ਆਰਟੀਫੈਕਟ ਵਜੋਂ ਵਾਪਸ ਕਰਦੀ ਹੈ। ਬਾਹਰੀ ਆਰਕੈਸਟ੍ਰੇਟਰ ਇਸਨੂੰ ਇਸ ਤਰ੍ਹਾਂ ਸੱਦ ਸਕਦੇ ਹਨ:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "ਸਾਰੀਆਂ ਸਮਰੱਥਾਵਾਂ ਸੂਚੀਬੱਧ ਕਰੋ" }]
  }
}
```

ਪ੍ਰੋਟੋਕੋਲ ਵੇਰਵਿਆਂ ਲਈ [A2A-SERVER.md](./A2A-SERVER.md) ਵੇਖੋ।

## ਬਾਹਰੀ ਏਜੰਟ Skills ਦੀ ਵਰਤੋਂ ਕਿਵੇਂ ਕਰਦੇ ਹਨ

### 1. REST ਰਾਹੀਂ ਖੋਜ

```bash
# ਪੂਰਾ ਕੈਟਾਲਾਗ ਪ੍ਰਾਪਤ ਕਰੋ
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# ਸੰਦਰਭ ਇੰਜੈਕਸ਼ਨ ਲਈ SKILL.md ਪ੍ਰਾਪਤ ਕਰੋ
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP ਰਾਹੀਂ ਖੋਜ

```typescript
// Claude Desktop / Cursor MCP ਕਲਾਇੰਟ ਵਿੱਚ:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → AgentSkill ਦੀ ਐਰੇ, ਹਰੇਕ ਲਈ rawUrl ਸਮੇਤ
```

### 3. A2A ਰਾਹੀਂ ਖੋਜ

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table ਸਾਰੀਆਂ 45 skill IDs + rawUrl ਕਾਲਮਾਂ ਵਾਲੀ ਇੱਕ markdown ਸਾਰਣੀ ਹੈ
```

### 4. ਸਿੱਧਾ GitHub raw ਫੈਚ (ਕਿਸੇ ਸਰਵਰ ਦੀ ਲੋੜ ਨਹੀਂ)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## ਜਨਰੇਟਰ

ਜਨਰੇਟਰ ਸੰਭਾਲ ਕੇ ਤਿਆਰ ਕੀਤਾ ਕੈਟਾਲਾਗ + OpenAPI ਸਪੈੱਕ + CLI ਰਜਿਸਟਰੀ ਪੜ੍ਹਦਾ ਹੈ ਅਤੇ ਹਰੇਕ ਐਂਟਰੀ ਲਈ `skills/{id}/SKILL.md` ਲਿਖਦਾ ਹੈ:

```bash
# ਪੂਰਵ-ਝਲਕ (ਡ੍ਰਾਈ ਰਨ, ਕੁਝ ਵੀ ਨਹੀਂ ਲਿਖਿਆ ਜਾਵੇਗਾ)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# ਪੂਰੀ ਮੁੜ-ਜਨਰੇਸ਼ਨ
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# ਖਾਸ IDs ਨੂੰ ਮੁੜ ਜਨਰੇਟ ਕਰੋ
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

ਜਨਰੇਟਰ ਦਾ ਜਵਾਬ ਇੱਕ `GeneratorReport` ਹੈ:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
