## ਇਹ ਕੀ ਹੈ

OmniRoute ਇੱਕ **Obsidian** ਵਾਲਟ ਨਾਲ **ਕੰਟੈਕਸਟ ਸਰੋਤ** ਵਜੋਂ ਜੁੜਦਾ ਹੈ — ਇੱਕ ਸਥਾਨਕ Markdown
ਗਿਆਨ-ਅਧਾਰ, ਜਿਸਨੂੰ ਏਜੰਟ ਬਿਲਟ-ਇਨ MCP ਸਰਵਰ ਰਾਹੀਂ ਪੜ੍ਹਦੇ ਅਤੇ ਲਿਖਦੇ ਹਨ। ਇਹ
ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਡੈਸਕਟਾਪ ਐਪ ਦੇ ਅੰਦਰ ਚੱਲ ਰਹੇ **Obsidian Local REST API** ਕਮਿਊਨਿਟੀ ਪਲੱਗਇਨ
ਨਾਲ ਸੰਚਾਰ ਕਰਦੀ ਹੈ, ਤਾਂ ਜੋ ਏਜੰਟ ਨੋਟ ਖੋਜ ਸਕਣ, ਫਾਇਲਾਂ ਪੜ੍ਹ/ਲਿਖ/ਪੈਚ ਕਰ ਸਕਣ, ਵਾਲਟ ਦੀ ਸੂਚੀ
ਵੇਖ ਸਕਣ, ਰੋਜ਼ਾਨਾ/ਹਫ਼ਤਾਵਾਰੀ ਆਵਰਤੀ ਨੋਟਾਂ ਨਾਲ ਕੰਮ ਕਰ ਸਕਣ, ਟੈਗਾਂ ਦਾ ਪ੍ਰਬੰਧ ਕਰ ਸਕਣ,
Obsidian ਕਮਾਂਡਾਂ ਚਲਾ ਸਕਣ ਅਤੇ (ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ) ਦੋ-ਦਿਸ਼ਾਵੀ ਡੈਸਕਟਾਪ↔ਮੋਬਾਈਲ ਵਾਲਟ
ਸਿੰਕ ਦਾ ਤਾਲਮੇਲ ਕਰ ਸਕਣ।

ਕਲਾਇੰਟ (`src/lib/obsidian/api.ts`) Local REST API ਨੂੰ ਹੇਠ ਲਿਖੀਆਂ ਸਮਰੱਥਾਵਾਂ ਨਾਲ ਰੈਪ ਕਰਦਾ ਹੈ:

- ਅਸਥਾਈ `5xx` ਲਈ **ਬੈਕਆਫ਼ ਸਮੇਤ ਮੁੜ ਕੋਸ਼ਿਸ਼**, `AbortController` ਰਾਹੀਂ **30-ਸਕਿੰਟ ਦੀ ਸਮਾਂ-ਸੀਮਾ**।
- **ਟਾਈਪ ਕੀਤੀ ਗਲਤੀ ਵਰਗੀਕਰਨ** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`।
- ਇੱਕ **ਸੁਗਮ "Obsidian ਤੱਕ ਨਹੀਂ ਪਹੁੰਚਿਆ ਜਾ ਸਕਦਾ" ਸੰਕੇਤ**, ਜੋ ਆਮ ਪੋਰਟ ਗਲਤੀ
  (`27123` ਉੱਤੇ HTTP, `27124` ਉੱਤੇ MCP ਐਂਡਪੌਇੰਟ **ਨਹੀਂ**) ਅਤੇ Tailscale ਰੂਪ ਬਾਰੇ ਦੱਸਦਾ ਹੈ।
- ਵਾਲਟ-ਸਾਪੇਖ **ਪਾਥ ਐਨਕੋਡਿੰਗ**, ਤਾਂ ਜੋ ਖਾਲੀ ਥਾਵਾਂ/ਸਲੈਸ਼ਾਂ ਵਾਲੇ ਨੋਟ ਪਾਥ ਸੁਰੱਖਿਅਤ ਰਹਿਣ।

## ਸੈਟਅੱਪ

Obsidian ਟੋਕਨ ਜਾਂ ਬੇਸ URL ਲਈ **ਕੋਈ environment variable ਨਹੀਂ ਹੈ** — ਦੋਵੇਂ
`src/lib/db/obsidian.ts` ਰਾਹੀਂ SQLite ਦੀ `key_value` ਟੇਬਲ (`obsidian` namespace) ਵਿੱਚ
ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ। ਟੋਕਨ **ਸਟੋਰੇਜ ਵਿੱਚ ਇਨਕ੍ਰਿਪਟ ਕੀਤਾ ਹੁੰਦਾ ਹੈ** (AES-256-GCM, plaintext
ਪਿਛੋਕੜ-ਅਨੁਕੂਲਤਾ fallback ਸਮੇਤ)। Endpoint ਡੈਸ਼ਬੋਰਡ ਦੀ **Context Sources** ਟੈਬ
(`ObsidianSourceCard`) ਤੋਂ, ਜਾਂ ਸੈਟਿੰਗਾਂ ਦੀ REST API ਰਾਹੀਂ ਸੰਰਚਨਾ ਕਰੋ।

> [!IMPORTANT]
> **Obsidian Local REST API** ਪਲੱਗਇਨ ਇੰਸਟਾਲ ਅਤੇ ਚੱਲ ਰਿਹਾ ਹੋਣਾ ਲਾਜ਼ਮੀ ਹੈ। ਇਸਦਾ REST
> ਇੰਟਰਫੇਸ **HTTP `127.0.0.1:27123`** (ਡਿਫਾਲਟ ਬੇਸ URL) ਉੱਤੇ ਸੁਣਦਾ ਹੈ। ਪੋਰਟ `27124`
> ਇੱਕ _ਵੱਖਰਾ_ MCP/HTTPS ਐਂਡਪੌਇੰਟ ਹੈ ਅਤੇ ਸੈਟਿੰਗਾਂ ਵਾਲੇ ਰੂਟ ਦੁਆਰਾ ਸਪਸ਼ਟ ਤੌਰ 'ਤੇ ਰੱਦ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।
> ਕਿਸੇ ਹੋਰ ਡਿਵਾਈਸ ਤੋਂ ਕਨੈਕਟ ਕਰਦੇ ਸਮੇਂ, `http://<tailscale-ip>:27123` ਵਰਤੋ।

### ਸੰਰਚਨਾ ਕੁੰਜੀਆਂ (SQLite `key_value`, namespace `obsidian`)

| ਕੁੰਜੀ             | ਉਦੇਸ਼                                          | ਇਨਕ੍ਰਿਪਟ ਕੀਤਾ |
| ----------------- | ---------------------------------------------- | ------------- |
| `api_key`         | Local REST API ਬੇਅਰਰ ਟੋਕਨ                      | ਹਾਂ           |
| `base_url`        | REST ਬੇਸ URL (ਡਿਫਾਲਟ `http://127.0.0.1:27123`) | ਨਹੀਂ          |
| `vault_path`      | ਵਾਲਟ ਡਾਇਰੈਕਟਰੀ ਦਾ ਪੂਰਨ ਪਾਥ (ਸਿੰਕ ਲਈ)           | ਨਹੀਂ          |
| `webdav_username` | ਬਣਾਇਆ ਗਿਆ WebDAV ਯੂਜ਼ਰਨੇਮ (ਵਾਲਟ ਸਿੰਕ)          | ਨਹੀਂ          |
| `webdav_password` | ਬਣਾਇਆ ਗਿਆ WebDAV ਪਾਸਵਰਡ (ਵਾਲਟ ਸਿੰਕ)            | ਹਾਂ           |
| `webdav_enabled`  | ਕੀ WebDAV ਵਾਲਟ ਸਿੰਕ ਸਮਰੱਥ ਹੈ                   | ਨਹੀਂ          |

### REST ਰਾਹੀਂ ਸੰਰਚਨਾ ਕਰੋ

```bash
# Local REST API ਟੋਕਨ ਸੰਭਾਲੋ + ਪ੍ਰਮਾਣਿਤ ਕਰੋ (POST ਇੱਕ ਸਥਿਤੀ ਜਾਂਚ ਰਾਹੀਂ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# ਕਨੈਕਸ਼ਨ ਸਥਿਤੀ ਜਾਂਚੋ (connected, hasToken, baseUrl, vaultPath ਵਾਪਸ ਕਰਦਾ ਹੈ)
curl http://localhost:20128/api/settings/obsidian

# ਡਿਸਕਨੈਕਟ ਕਰੋ (ਸੰਭਾਲਿਆ ਟੋਕਨ ਮਿਟਾਉਂਦਾ ਹੈ)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

ਸਾਰੀਆਂ ਵਿਧੀਆਂ ਲਈ ਡੈਸ਼ਬੋਰਡ ਪ੍ਰਮਾਣੀਕਰਨ ਲੋੜੀਂਦਾ ਹੈ। `POST`, ਪੋਰਟ `27124` ਉੱਤੇ ਕਿਸੇ ਵੀ URL
ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ ਅਤੇ ਸਥਿਰ ਤੌਰ 'ਤੇ ਸੰਭਾਲਣ ਤੋਂ ਪਹਿਲਾਂ Local REST API ਸਥਿਤੀ ਐਂਡਪੌਇੰਟ ਨੂੰ
ਕਾਲ ਕਰਕੇ ਟੋਕਨ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ।

### WebDAV ਵਾਲਟ ਸਿੰਕ

`src/app/api/settings/obsidian/webdav/route.ts`, ਇੱਕ ਵਿਕਲਪਿਕ WebDAV-ਸਮਰਥਿਤ
ਵਾਲਟ ਸਿੰਕ (`src/lib/obsidianSync.ts` ਦੁਆਰਾ ਚਲਾਇਆ ਜਾਂਦਾ) ਦਾ ਪ੍ਰਬੰਧ ਕਰਦਾ ਹੈ। ਇਸਨੂੰ ਸਮਰੱਥ
ਕਰਨ ਨਾਲ OmniRoute ਇੱਕ ਸਥਾਨਕ ਵਾਲਟ ਡਾਇਰੈਕਟਰੀ ਵੱਲ ਨਿਰਦੇਸ਼ਿਤ ਹੁੰਦਾ ਹੈ ਅਤੇ ਇੱਕ ਬੇਤਰਤੀਬ
WebDAV ਯੂਜ਼ਰਨੇਮ/ਪਾਸਵਰਡ ਜੋੜਾ ਤਿਆਰ ਕਰਦਾ ਹੈ:

```bash
# ਕਿਸੇ ਵਾਲਟ ਡਾਇਰੈਕਟਰੀ ਲਈ WebDAV ਸਿੰਕ ਸਮਰੱਥ ਕਰੋ (ਯੂਜ਼ਰਨੇਮ/ਪਾਸਵਰਡ ਬਣਾਉਂਦਾ ਹੈ)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV ਸਿੰਕ ਸਥਿਤੀ ਪ੍ਰਾਪਤ ਕਰੋ (ਕ੍ਰੀਡੈਂਸ਼ੀਅਲ ਕੇਵਲ ਸਮਰੱਥ ਹੋਣ ਦੌਰਾਨ ਵਾਪਸ ਕੀਤੇ ਜਾਂਦੇ ਹਨ)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV ਸਿੰਕ ਅਸਮਰੱਥ ਕਰੋ (ਕ੍ਰੀਡੈਂਸ਼ੀਅਲ + ਪ੍ਰਬੰਧਿਤ .stignore ਮਿਟਾਉਂਦਾ ਹੈ)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### ਪ੍ਰਤੀ-API-ਕੁੰਜੀ ਕੰਟੈਕਸਟ ਸਰੋਤ (ਵਿਕਲਪਿਕ)

Obsidian ਸੰਰਚਨਾ ਨੂੰ `api_key_context_sources` ਟੇਬਲ
(`src/lib/db/apiKeyContextSources.ts`) ਰਾਹੀਂ **ਪ੍ਰਤੀ API ਕੁੰਜੀ** ਸਕੋਪ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ।
ਜਦੋਂ ਕੋਈ MCP ਕਾਲ ਇੱਕ ਪ੍ਰਮਾਣਿਤ API ਕੁੰਜੀ id ਨਾਲ ਆਉਂਦੀ ਹੈ, ਤਾਂ `getObsidianConfigForApiKey()`
ਉਸ ਕੁੰਜੀ ਦੇ ਆਪਣੇ ਟੋਕਨ/ਬੇਸ-URL/ਵਾਲਟ-ਪਾਥ (`source: "api_key"`) ਨੂੰ ਤਰਜੀਹ ਦਿੰਦਾ ਹੈ ਅਤੇ
ਨਹੀਂ ਤਾਂ ਗਲੋਬਲ ਸੰਰਚਨਾ (`source: "global"`) 'ਤੇ fallback ਕਰਦਾ ਹੈ।

## MCP ਟੂਲ (22)

`open-sse/mcp-server/tools/obsidianTools.ts` ਵਿੱਚ ਪਰਿਭਾਸ਼ਿਤ ਹਨ। ਟੋਕਨ/base-URL ਨੂੰ
ਹਰੇਕ ਕਾਲ ਲਈ ਹੱਲ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (ਪਹਿਲਾਂ ਪ੍ਰਤੀ-API-key, ਫਿਰ ਗਲੋਬਲ)। OmniRoute **ਸਿੰਕ ਸਰਵਰ**
ਨੂੰ ਵਰਤਣ ਵਾਲੇ ਟੂਲਾਂ (ਚਾਰ `obsidian_sync_*` ਟੂਲ) ਲਈ OmniRoute ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਸੰਰਚਿਤ
ਸਿੰਕ ਪ੍ਰਮਾਣੀਕਰਨ ਟੋਕਨ ਦੀ ਵੀ ਲੋੜ ਹੁੰਦੀ ਹੈ।

| `obsidian_search_simple`     | ਨੋਟ ਸਮੱਗਰੀ ਦੀ ਪੂਰੇ-ਟੈਕਸਟ ਵਾਲੀ ਖੋਜ; ਫ਼ਾਈਲ ਪਾਥਾਂ ਸਮੇਤ ਸਨਿੱਪਟ ਵਾਪਸ ਕਰਦੀ ਹੈ।                  |
| `obsidian_search_structured` | JSON Logic ਐਕਸਪ੍ਰੈਸ਼ਨ (and/or/regex/path ਫਿਲਟਰ) ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਖੋਜ ਕਰੋ।                    |
| `obsidian_read_note`         | vault-relative ਪਾਥ ਰਾਹੀਂ ਨੋਟ ਪੜ੍ਹੋ; ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ ਕੋਈ ਖਾਸ ਹੈਡਿੰਗ/block/frontmatter।     |
| `obsidian_list_vault`        | ਵਾਲਟ ਵਿੱਚ ਫ਼ਾਈਲਾਂ ਅਤੇ ਡਾਇਰੈਕਟਰੀਆਂ ਦੀ ਸੂਚੀ ਦਿਓ (ਐਂਟਰੀਆਂ ਦਾ ਟ੍ਰੀ)।                          |
| `obsidian_get_document_map`  | ਨੋਟ ਦੀ ਹੈਡਿੰਗ ਬਣਤਰ ਨੂੰ ਹੈਡਿੰਗਾਂ → ਲਾਈਨ ਨੰਬਰਾਂ ਦੇ ਮੈਪ ਵਜੋਂ ਪ੍ਰਾਪਤ ਕਰੋ।                     |
| `obsidian_get_note_metadata` | ਪੂਰੀ ਸਮੱਗਰੀ ਤੋਂ ਬਿਨਾਂ frontmatter, ਟੈਗ, ਲਿੰਕ, ਅੱਖਰ/ਸ਼ਬਦ ਗਿਣਤੀ ਪ੍ਰਾਪਤ ਕਰੋ।                 |
| `obsidian_get_active_file`   | Obsidian ਵਿੱਚ ਇਸ ਵੇਲੇ ਸਰਗਰਮ ਫ਼ਾਈਲ ਦਾ ਪਾਥ + ਸਮੱਗਰੀ ਪ੍ਰਾਪਤ ਕਰੋ।                             |
| `obsidian_get_periodic_note` | ਕਿਸੇ ਤਾਰੀਖ ਲਈ ਰੋਜ਼ਾਨਾ/ਹਫ਼ਤਾਵਾਰੀ/ਮਹੀਨਾਵਾਰੀ ਆਵਰਤੀ ਨੋਟ ਪ੍ਰਾਪਤ ਕਰੋ (ਨਾ ਦਿੱਤੇ ਜਾਣ 'ਤੇ ਅੱਜ ਦਾ)। |
| `obsidian_get_tags`          | ਸਾਰੇ ਵਾਲਟ ਟੈਗਾਂ ਨੂੰ ਉਨ੍ਹਾਂ ਦੀਆਂ ਆਵ੍ਰਿੱਤੀਆਂ ਸਮੇਤ ਸੂਚੀਬੱਧ ਕਰੋ।                              |
| `obsidian_list_commands`     | ਉਪਲਬਧ Obsidian ਕਮਾਂਡ ID ਸੂਚੀਬੱਧ ਕਰੋ (`obsidian_execute_command` ਨਾਲ ਵਰਤੋ)।                |
| `obsidian_sync_status`       | OmniRoute ਸਿੰਕ ਸਰਵਰ ਦੀ ਸਥਿਤੀ: ਚੱਲ ਰਿਹਾ ਹੈ ਜਾਂ ਨਹੀਂ, ਵਾਲਟ ਨਾਮ, ਪੋਰਟ, ਅਪਟਾਈਮ, ਆਖਰੀ ਸਿੰਕ।    |
| `obsidian_sync_conflicts`    | ਅਣਸੁਲਝੇ ਸਿੰਕ ਟਕਰਾਵਾਂ ਦੀ ਸੂਚੀ ਦਿਓ (ਪਾਥ, ਟਕਰਾਅ ਪਾਥ, ਪਤਾ ਲੱਗਣ ਦਾ ਸਮਾਂ)।                      |

### ਰਾਈਟ ਟੂਲ (`write:obsidian`)

| ਟੂਲ                              | ਵੇਰਵਾ                                                                               |
| -------------------------------- | ----------------------------------------------------------------------------------- |
| `obsidian_write_note`            | ਦਿੱਤੀ Markdown ਸਮੱਗਰੀ ਨਾਲ ਨੋਟ ਬਣਾਓ ਜਾਂ ਓਵਰਰਾਈਟ ਕਰੋ।                                 |
| `obsidian_append_note`           | ਨੋਟ ਵਿੱਚ ਸਮੱਗਰੀ ਜੋੜੋ; ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ ਕਿਸੇ ਖਾਸ ਹੈਡਿੰਗ/block ਵਿੱਚ।                   |
| `obsidian_patch_note`            | ਹੈਡਿੰਗ, block ਜਾਂ frontmatter ਫ਼ੀਲਡ ਉੱਤੇ ਸਟੀਕ ਤਰੀਕੇ ਨਾਲ append/prepend/replace ਕਰੋ। |
| `obsidian_delete_note`           | ਵਾਲਟ ਵਿੱਚੋਂ ਨੋਟ ਨੂੰ ਸਥਾਈ ਤੌਰ 'ਤੇ ਮਿਟਾਓ।                                             |
| `obsidian_move_note`             | ਵਾਲਟ ਦੇ ਅੰਦਰ ਨੋਟ ਨੂੰ ਮੂਵ ਕਰੋ ਜਾਂ ਉਸਦਾ ਨਾਮ ਬਦਲੋ।                                     |
| `obsidian_execute_command`       | Obsidian ਕਮਾਂਡ ਨੂੰ ਉਸਦੀ ਕਮਾਂਡ ID ਰਾਹੀਂ ਚਲਾਓ।                                        |
| `obsidian_open_file`             | Obsidian ਵਿੱਚ ਫ਼ਾਈਲ ਖੋਲ੍ਹੋ (ਜੇ ਮੌਜੂਦ ਨਹੀਂ ਹੈ ਤਾਂ ਇਸਨੂੰ ਬਣਾਉਂਦਾ ਹੈ)।                 |
| `obsidian_sync_trigger`          | ਤੁਰੰਤ ਦੋ-ਦਿਸ਼ਾਵੀ desktop↔mobile ਵਾਲਟ ਸਿੰਕ ਟ੍ਰਿਗਰ ਕਰੋ।                               |
| `obsidian_sync_resolve_conflict` | ਸਿੰਕ ਟਕਰਾਅ ਹੱਲ ਕਰੋ: `local` (mobile), `remote` (desktop), ਜਾਂ `keep-both` ਰੱਖੋ।     |

> [!NOTE]
> `obsidian_patch_note` ਟਾਰਗੇਟ `heading | block | frontmatter` ਵਿੱਚੋਂ `targetType`
> ਅਤੇ `append | prepend | replace` ਵਿੱਚੋਂ `operation` ਸਵੀਕਾਰ ਕਰਦੇ ਹਨ, ਨਾਲ ਹੀ ਵਿਕਲਪਿਕ
> `createTargetIfMissing`। ਚਾਰ `obsidian_sync_*` ਟੂਲ ਸਥਾਨਕ ਸਿੰਕ
> ਸਰਵਰ (ਮੂਲ ਰੂਪ ਵਿੱਚ `http://127.0.0.1:27781`) ਨਾਲ ਸੰਚਾਰ ਕਰਦੇ ਹਨ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ ਸਿੰਕ ਟੋਕਨ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ।

### ਸਕੋਪ

ਰੀਡ ਟੂਲਾਂ ਲਈ `read:obsidian` ਦੀ ਲੋੜ ਹੈ; ਰਾਈਟ ਟੂਲਾਂ ਲਈ `write:obsidian` ਦੀ। ਲਾਗੂਕਰਨ
Notion ਦੇ ਸਮਾਨ ਹੈ — `open-sse/mcp-server/server.ts` ਵਿੱਚ `withScopeEnforcement()` ਦੁਆਰਾ
ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ, `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ਉੱਤੇ ਗੇਟ ਕੀਤਾ ਗਿਆ ਹੈ, ਅਤੇ
ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਸਕੋਪ `OMNIROUTE_MCP_SCOPES` ਜਾਂ API key ਦੇ ਸਕੋਪ ਸੰਦਰਭ ਤੋਂ ਲਏ ਜਾਂਦੇ ਹਨ। ਵੇਖੋ
[MCP-SERVER.md](./MCP-SERVER.md)।

## ਐਂਡਪੌਇੰਟ

| ਵਿਧੀ     | ਪਾਥ                             | ਉਦੇਸ਼                                                                     |
| -------- | ------------------------------- | ------------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | `{ connected, hasToken, baseUrl, vaultPath }` ਵਾਪਸ ਕਰਦਾ ਹੈ।               |
| `POST`   | `/api/settings/obsidian`        | ਟੋਕਨ ਨੂੰ ਸੰਭਾਲਦਾ ਅਤੇ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ (ਪੋਰਟ `27124` ਨੂੰ ਅਸਵੀਕਾਰ ਕਰਦਾ ਹੈ)। |
| `DELETE` | `/api/settings/obsidian`        | ਡਿਸਕਨੈਕਟ ਕਰਦਾ ਹੈ (ਸੰਭਾਲਿਆ ਟੋਕਨ ਸਾਫ਼ ਕਰਦਾ ਹੈ)।                             |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV ਸਿੰਕ ਸਥਿਤੀ + ਪ੍ਰਮਾਣ-ਪੱਤਰ (ਸਮਰੱਥ ਹੋਣ ਦੌਰਾਨ)।                        |
| `POST`   | `/api/settings/obsidian/webdav` | ਕਿਸੇ ਵਾਲਟ ਡਾਇਰੈਕਟਰੀ ਲਈ WebDAV ਸਿੰਕ ਸਮਰੱਥ ਕਰਦਾ ਹੈ।                         |
| `DELETE` | `/api/settings/obsidian/webdav` | WebDAV ਸਿੰਕ ਅਸਮਰੱਥ ਕਰਦਾ ਹੈ।                                               |

> ਇਹ ਡੈਸ਼ਬੋਰਡ ਸੈਟਿੰਗਾਂ ਦੇ ਰੂਟ ਹਨ। ਵਾਲਟ ਤੱਕ ਖੁਦ Obsidian
> Local REST API (ਕੌਂਫਿਗਰ ਕੀਤਾ `base_url`) ਅਤੇ ਉੱਪਰ ਦਿੱਤੇ MCP ਟੂਲਾਂ ਰਾਹੀਂ ਪਹੁੰਚ ਕੀਤੀ ਜਾਂਦੀ ਹੈ — ਕੋਈ
> ਜਨਤਕ `/v1` Obsidian ਪ੍ਰੌਕਸੀ ਐਂਡਪੌਇੰਟ ਨਹੀਂ ਹੈ।

## ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ

- **ਵਾਲਟ-ਆਧਾਰਿਤ ਜਵਾਬ** — `obsidian_search_simple` / `obsidian_search_structured`
  ਫਿਰ `obsidian_read_note`, ਤਾਂ ਜੋ ਏਜੰਟ ਤੁਹਾਡੇ ਅਸਲ ਨੋਟਾਂ ਤੋਂ ਜਵਾਬ ਦੇਵੇ।
- **ਨੋਟ ਲਿਖਣਾ / ਜਰਨਲਿੰਗ** — ਏਜੰਟ ਆਉਟਪੁੱਟ, ਸਾਰਾਂ ਜਾਂ ਰੋਜ਼ਾਨਾ ਨੋਟਾਂ
  (`obsidian_get_periodic_note`) ਨੂੰ ਵਾਲਟ ਵਿੱਚ ਦਰਜ ਕਰਨ ਲਈ `obsidian_write_note`, `obsidian_append_note`, ਜਾਂ
  ਸਟੀਕ `obsidian_patch_note`।
- **ਵਾਲਟ ਨੈਵੀਗੇਸ਼ਨ** — ਪੜ੍ਹਨ/ਲਿਖਣ ਤੋਂ ਪਹਿਲਾਂ ਬਣਤਰ ਦੀ ਪੜਚੋਲ ਕਰਨ ਲਈ `obsidian_list_vault`, `obsidian_get_document_map`, ਅਤੇ
  `obsidian_get_tags`।
- **Obsidian ਆਟੋਮੇਸ਼ਨ** — ਏਜੰਟ ਰਾਹੀਂ ਪਲੱਗਇਨ/ਕਮਾਂਡਾਂ ਚਲਾਉਣ ਲਈ `obsidian_list_commands` + `obsidian_execute_command`;
  UI ਵਿੱਚ ਨੋਟ ਦਿਖਾਉਣ ਲਈ `obsidian_open_file`।
- **ਮੋਬਾਈਲ ਸਿੰਕ** — WebDAV ਸਿੰਕ ਸਮਰੱਥ ਕਰੋ, ਫਿਰ ਡੈਸਕਟਾਪ↔ਮੋਬਾਈਲ ਤਾਲਮੇਲ ਅਤੇ ਟਕਰਾਵਾਂ ਨੂੰ ਹੱਲ ਕਰਨ ਲਈ `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`।
