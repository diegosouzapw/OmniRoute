## ਇਹ ਕੀ ਹੈ

OmniRoute ਇੱਕ **Notion** ਵਰਕਸਪੇਸ ਨਾਲ **ਸੰਦਰਭ ਸਰੋਤ** ਵਜੋਂ ਕਨੈਕਟ ਕਰ ਸਕਦਾ ਹੈ — ਇੱਕ ਪੜ੍ਹਨ/ਲਿਖਣਯੋਗ
ਗਿਆਨ-ਭੰਡਾਰ ਜਿਸ ਤੱਕ ਏਜੰਟ ਬਿਲਟ-ਇਨ MCP ਸਰਵਰ ਰਾਹੀਂ ਪਹੁੰਚਦੇ ਹਨ। Notion
ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਟੋਕਨ ਕੌਂਫਿਗਰ ਹੋਣ ਤੋਂ ਬਾਅਦ, MCP ਟੂਲ ਕਿਸੇ LLM ਨੂੰ ਪੇਜਾਂ ਅਤੇ ਡੇਟਾਬੇਸਾਂ ਵਿੱਚ ਖੋਜ ਕਰਨ,
ਪੇਜ ਸਮੱਗਰੀ ਅਤੇ ਬਲਾਕ ਟ੍ਰੀਆਂ ਪੜ੍ਹਨ, ਫਿਲਟਰਾਂ/ਸੌਰਟਾਂ ਨਾਲ ਡੇਟਾਬੇਸਾਂ ਨੂੰ ਕਵੇਰੀ ਕਰਨ ਅਤੇ ਨਵੇਂ
ਬਲਾਕ ਜੋੜਨ ਦਿੰਦੇ ਹਨ — ਇਹ ਸਭ OmniRoute ਰਾਹੀਂ ਪ੍ਰੌਕਸੀ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (ਮੁੜ-ਕੋਸ਼ਿਸ਼, ਟਾਈਮਆਊਟ ਅਤੇ ਗਲਤੀ ਵਰਗੀਕਰਨ ਸਮੇਤ)
ਤਾਂ ਜੋ ਮਾਡਲ ਕਦੇ ਵੀ Notion API ਨੂੰ ਸਿੱਧੇ ਤੌਰ 'ਤੇ ਐਕਸੈਸ ਨਾ ਕਰੇ।

ਇਹ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਅਧਿਕਾਰਤ Notion REST API ਉੱਤੇ ਇੱਕ ਪਤਲਾ, ਮਜ਼ਬੂਤ ਰੈਪਰ ਹੈ
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`)। ਕਲਾਇੰਟ
(`src/lib/notion/api.ts`) ਇਹ ਜੋੜਦਾ ਹੈ:

- `429` ਅਤੇ `5xx` ਲਈ **ਐਕਸਪੋਨੇਨਸ਼ੀਅਲ ਬੈਕਆਫ਼ ਨਾਲ ਮੁੜ-ਕੋਸ਼ਿਸ਼** (ਵੱਧ ਤੋਂ ਵੱਧ 3 ਕੋਸ਼ਿਸ਼ਾਂ)।
- `AbortController` ਰਾਹੀਂ **55-ਸਕਿੰਟ ਦੀ ਬੇਨਤੀ ਟਾਈਮਆਊਟ**।
- **ਟਾਈਪ ਕੀਤਾ ਗਲਤੀ ਵਰਗੀਕਰਨ** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  ਸੰਕੇਤਾਂ ਦਾ ਸਨਮਾਨ ਕਰਦਾ ਹੈ), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`।
- **ਸੁਨੇਹਾ ਸੈਨੀਟਾਈਜ਼ੇਸ਼ਨ**, ਜੋ ਸਾਹਮਣੇ ਲਿਆਉਣ ਤੋਂ ਪਹਿਲਾਂ ਸਟੈਕ-ਟ੍ਰੇਸ ਵਰਗੇ ਹਿੱਸਿਆਂ ਨੂੰ ਹਟਾਉਂਦੀ ਹੈ।

## ਸੈਟਅੱਪ

Notion ਟੋਕਨ ਲਈ **ਕੋਈ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਨਹੀਂ ਹੈ** — ਇਸਨੂੰ
`src/lib/db/notion.ts` ਰਾਹੀਂ SQLite `key_value` ਟੇਬਲ (ਨੇਮਸਪੇਸ `notion`, ਕੁੰਜੀ `integration_token`) ਵਿੱਚ
ਸਟੋਰ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ਇਸਨੂੰ Endpoint ਡੈਸ਼ਬੋਰਡ ਦੀ **Context Sources** ਟੈਬ
(`ObsidianSourceCard` ਦੇ ਨਾਲ ਵਾਲੇ `NotionSourceCard`) ਤੋਂ ਜਾਂ ਸੈਟਿੰਗਾਂ REST API ਰਾਹੀਂ ਕੌਂਫਿਗਰ ਕਰੋ।

> [!NOTE]
> ਇਹ ਟੋਕਨ ਇੱਕ **Notion ਅੰਦਰੂਨੀ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਟੋਕਨ** ਹੈ। ਇੱਥੇ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਬਣਾਓ:
> <https://www.notion.com/my-integrations>, ਫਿਰ ਉਹ ਪੇਜ/ਡੇਟਾਬੇਸ, ਜਿਨ੍ਹਾਂ ਤੱਕ ਤੁਸੀਂ
> OmniRoute ਨੂੰ ਪਹੁੰਚ ਦੇਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਉਸ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਨਾਲ ਸਾਂਝੇ ਕਰੋ (Notion ਦਾ ਅਨੁਮਤੀ ਮਾਡਲ ਸਾਂਝਾ ਕਰਨ 'ਤੇ ਆਧਾਰਿਤ ਹੈ,
> ਪੂਰੇ ਵਰਕਸਪੇਸ 'ਤੇ ਨਹੀਂ)।

### REST ਰਾਹੀਂ ਕੌਂਫਿਗਰ ਕਰੋ

```bash
# ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਟੋਕਨ ਸੰਭਾਲੋ + ਪ੍ਰਮਾਣਿਤ ਕਰੋ (POST ਇੱਕ ਟੈਸਟ ਖੋਜ ਜਾਰੀ ਕਰਕੇ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# ਕਨੈਕਸ਼ਨ ਸਥਿਤੀ ਦੀ ਜਾਂਚ ਕਰੋ
curl http://localhost:20128/api/settings/notion

# ਡਿਸਕਨੈਕਟ ਕਰੋ (ਸਟੋਰ ਕੀਤਾ ਟੋਕਨ ਸਾਫ਼ ਕਰਦਾ ਹੈ)
curl -X DELETE http://localhost:20128/api/settings/notion
```

ਸਾਰੇ ਤਿੰਨ ਢੰਗਾਂ ਲਈ ਡੈਸ਼ਬੋਰਡ ਪ੍ਰਮਾਣਿਕਤਾ (`isAuthenticated`) ਲੋੜੀਂਦੀ ਹੈ। `POST` ਉੱਤੇ,
OmniRoute ਟੋਕਨ ਸੰਭਾਲਦਾ ਹੈ ਅਤੇ ਤੁਰੰਤ 1-ਨਤੀਜੇ ਵਾਲੀ ਟੈਸਟ ਖੋਜ ਚਲਾਉਂਦਾ ਹੈ; ਜੇ Notion
ਕੋਈ ਗਲਤੀ ਆਬਜੈਕਟ ਵਾਪਸ ਕਰਦਾ ਹੈ, ਤਾਂ ਟੋਕਨ ਸਾਫ਼ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ ਅਤੇ ਕਾਲ `400` ਨਾਲ ਅਸਫਲ ਹੋ ਜਾਂਦੀ ਹੈ।

## MCP ਟੂਲ (6)

`open-sse/mcp-server/tools/notionTools.ts` ਵਿੱਚ ਪਰਿਭਾਸ਼ਿਤ ਹਨ। ਟੋਕਨ ਨੂੰ ਕਾਲ ਦੇ
ਸਮੇਂ `getNotionToken()` ਰਾਹੀਂ ਰਿਜ਼ਾਲਵ ਕੀਤਾ ਜਾਂਦਾ ਹੈ; ਜੇ ਕੋਈ ਟੋਕਨ ਕੌਂਫਿਗਰ ਨਹੀਂ ਹੈ, ਤਾਂ ਟੂਲ
`"Notion integration token not configured. Set it in Settings > Context Sources."` ਗਲਤੀ ਸੁੱਟਦਾ ਹੈ।

| ਟੂਲ                          | ਸਕੋਪ           | ਵੇਰਵਾ                                                                                                 |
| ---------------------------- | -------------- | ----------------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | ਟੈਕਸਟ ਕਵੇਰੀ ਰਾਹੀਂ ਪੇਜਾਂ ਅਤੇ ਡੇਟਾਬੇਸਾਂ ਦੀ ਖੋਜ ਕਰੋ (ਸਿਰਲੇਖ, IDs, URLs ਵਾਪਸ ਕਰਦਾ ਹੈ)। ਪੇਜੀਨੇਟ ਕੀਤਾ ਹੋਇਆ। |
| `notion_get_page`            | `read:notion`  | ਕਿਸੇ ਪੇਜ ਦੀ ID ਰਾਹੀਂ ਉਸਦੀ ਸਮੱਗਰੀ ਅਤੇ ਮੈਟਾਡਾਟਾ ਪ੍ਰਾਪਤ ਕਰੋ।                                             |
| `notion_list_block_children` | `read:notion`  | ਕਿਸੇ ਬਲਾਕ ਜਾਂ ਪੇਜ ਦੇ ਸਾਰੇ ਚਾਈਲਡ ਬਲਾਕਾਂ ਦੀ ਸੂਚੀ ਪ੍ਰਾਪਤ ਕਰੋ (ਬਲਾਕ ਟ੍ਰੀ)। ਪੇਜੀਨੇਟ ਕੀਤਾ ਹੋਇਆ।             |
| `notion_query_database`      | `read:notion`  | ਵਿਕਲਪਿਕ `filter` + `sorts` (Notion API ਫਾਰਮੈਟ) ਨਾਲ ਡੇਟਾਬੇਸ ਨੂੰ ਕਵੇਰੀ ਕਰੋ। ਪੇਜੀਨੇਟ ਕੀਤਾ ਹੋਇਆ।          |
| `notion_get_database`        | `read:notion`  | ID ਰਾਹੀਂ ਡੇਟਾਬੇਸ ਦਾ ਸਕੀਮਾ/ਮੈਟਾਡਾਟਾ ਪ੍ਰਾਪਤ ਕਰੋ।                                                        |
| `notion_append_blocks`       | `write:notion` | ਕਿਸੇ ਮੌਜੂਦਾ ਬਲਾਕ ਜਾਂ ਪੇਜ ਵਿੱਚ ਚਾਈਲਡ ਬਲਾਕ ਜੋੜੋ (ਪ੍ਰਤੀ ਬੇਨਤੀ ਵੱਧ ਤੋਂ ਵੱਧ 100 ਬਲਾਕ)।                     |

### ਇਨਪੁੱਟ ਪੈਰਾਮੀਟਰ

- `notion_search` — `query` (1–500 ਅੱਖਰ), `pageSize` (1–100, ਡਿਫਾਲਟ 20),
  `startCursor` (ਵਿਕਲਪਿਕ)।
- `notion_get_page` — `pageId` (32-ਅੱਖਰੀ ਹੈਕਸ ਜਾਂ UUID)।
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, ਡਿਫਾਲਟ 50),
  `startCursor` (ਵਿਕਲਪਿਕ)।
- `notion_query_database` — `databaseId`, `filter` (ਵਿਕਲਪਿਕ, Notion ਫਿਲਟਰ ਫਾਰਮੈਟ),
  `sorts` (ਵਿਕਲਪਿਕ ਐਰੇ), `pageSize` (1–100, ਡਿਫਾਲਟ 50), `startCursor` (ਵਿਕਲਪਿਕ)।
- `notion_get_database` — `databaseId`।
- `notion_append_blocks` — `blockId`, `children` (ਬਲਾਕ ਆਬਜੈਕਟਾਂ ਦੀ ਐਰੇ),
  `after` (ਵਿਕਲਪਿਕ ਸਥਿਤੀ)।

### ਸਕੋਪ

ਪੜ੍ਹਨ ਵਾਲੇ ਟੂਲਾਂ ਲਈ `read:notion` ਅਤੇ ਲਿਖਣ ਵਾਲੇ ਟੂਲ ਲਈ `write:notion` ਲੋੜੀਂਦਾ ਹੈ।
ਸਕੋਪਾਂ ਨੂੰ `open-sse/mcp-server/server.ts` ਵਿੱਚ `withScopeEnforcement()` ਵੱਲੋਂ
ਕੇਵਲ ਉਦੋਂ ਲਾਗੂ ਕੀਤਾ ਜਾਂਦਾ ਹੈ ਜਦੋਂ `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ਹੋਵੇ; ਕਾਲਰ ਦੇ ਮਨਜ਼ੂਰਸ਼ੁਦਾ
ਸਕੋਪ `OMNIROUTE_MCP_SCOPES` (ਕੌਮਿਆਂ ਨਾਲ ਵੱਖ ਕੀਤੇ) ਜਾਂ ਪ੍ਰਮਾਣਿਤ API ਕੁੰਜੀ ਦੇ ਸਕੋਪ
ਸੰਦਰਭ ਤੋਂ ਆਉਂਦੇ ਹਨ। ਪੂਰੇ ਸਕੋਪ ਮਾਡਲ ਲਈ [MCP-SERVER.md](./MCP-SERVER.md) ਵੇਖੋ।

## ਐਂਡਪੌਇੰਟ

| ਵਿਧੀ     | ਪਾਥ                    | ਉਦੇਸ਼                                   |
| -------- | ---------------------- | --------------------------------------- |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` ਵਾਪਸ ਕਰੋ।     |
| `POST`   | `/api/settings/notion` | ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਟੋਕਨ ਸੰਭਾਲੋ + ਪ੍ਰਮਾਣਿਤ ਕਰੋ। |
| `DELETE` | `/api/settings/notion` | ਡਿਸਕਨੈਕਟ ਕਰੋ (ਸੰਭਾਲਿਆ ਟੋਕਨ ਮਿਟਾਓ)।      |

> ਇਹ ਡੈਸ਼ਬੋਰਡ ਸੈਟਿੰਗਾਂ ਦੇ ਰੂਟ ਹਨ। ਕੋਈ ਜਨਤਕ `/v1` Notion ਪ੍ਰੌਕਸੀ
> ਐਂਡਪੌਇੰਟ **ਨਹੀਂ ਹੈ** — Notion ਤੱਕ ਪਹੁੰਚ ਸਿਰਫ਼ ਉੱਪਰ ਦਿੱਤੇ MCP ਟੂਲਾਂ ਰਾਹੀਂ ਹੁੰਦੀ ਹੈ।

## ਵਰਤੋਂ ਦੇ ਮਾਮਲੇ

- **ਗਿਆਨ-ਅਧਾਰਿਤ ਜਵਾਬ** — ਜਵਾਬ ਦੇਣ ਤੋਂ ਪਹਿਲਾਂ ਕਿਸੇ ਏਜੰਟ ਨੂੰ ਵਰਕਸਪੇਸ ਵਿੱਚ `notion_search` ਕਰਨ ਅਤੇ
  ਸਭ ਤੋਂ ਉੱਚੇ ਨਤੀਜੇ ਉੱਤੇ `notion_get_page` ਵਰਤਣ ਦਿਓ, ਤਾਂ ਜੋ ਜਵਾਬ ਅਸਲ ਅੰਦਰੂਨੀ ਦਸਤਾਵੇਜ਼ਾਂ ਦਾ ਹਵਾਲਾ ਦੇਣ।
- **ਡੇਟਾਬੇਸ-ਅਧਾਰਿਤ ਵਰਕਫ਼ਲੋ** — ਫਿਲਟਰਾਂ + ਛਾਂਟਣ ਨਾਲ ਕਿਸੇ ਟਾਸਕ/CRM ਡੇਟਾਬੇਸ ਉੱਤੇ
  `notion_query_database` ਵਰਤੋ, ਫਿਰ ਕਤਾਰਾਂ ਦਾ ਸਾਰ ਦਿਓ ਜਾਂ ਉਨ੍ਹਾਂ ਦੀ ਤਰਜੀਹ ਨਿਰਧਾਰਤ ਕਰੋ।
- **ਵਾਪਸ ਲਿਖਣਾ / ਲੌਗਿੰਗ** — ਮੀਟਿੰਗ ਨੋਟਸ, ਰਨ ਦੇ ਸਾਰ, ਜਾਂ ਏਜੰਟ ਆਉਟਪੁੱਟ ਨੂੰ ਕਿਸੇ ਮੌਜੂਦਾ ਪੰਨੇ ਵਿੱਚ ਜੋੜਨ ਲਈ
  `notion_append_blocks` ਵਰਤੋ (ਸਿਰਫ਼ ਜੋੜਨਾ; ਕੋਈ ਵਿਨਾਸ਼ਕਾਰੀ ਸੋਧ ਨਹੀਂ)।
- **ਢਾਂਚੇ ਦੀ ਪੜਚੋਲ** — ਕਿਸੇ ਪੰਨੇ ਦੇ ਬਲਾਕ ਟ੍ਰੀ ਵਿੱਚੋਂ ਲੰਘਣ ਲਈ `notion_list_block_children`,
  ਜਾਂ ਕਿਸੇ ਡੇਟਾਬੇਸ ਨੂੰ ਕਵੇਰੀ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਉਸ ਦੀ ਪ੍ਰਾਪਰਟੀ ਸਕੀਮਾ ਖੋਜਣ ਲਈ `notion_get_database` ਵਰਤੋ।
