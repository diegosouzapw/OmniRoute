## ਉੱਚ-ਪੱਧਰੀ ਨੈਵੀਗੇਸ਼ਨ

ਡੈਸ਼ਬੋਰਡ ਸਾਈਡਬਾਰ (Group B ਤੋਂ ਬਾਅਦ) ਵਿੱਚ ਕ੍ਰਮਵਾਰ ਇਹ ਉੱਚ-ਪੱਧਰੀ ਭਾਗ ਹਨ:

```
ਮੁੱਖ ਪੰਨਾ
ਪ੍ਰਦਾਤਾ
ਕੌਂਬੋ
API ਕੁੰਜੀਆਂ
ਸੈਟਿੰਗਾਂ
ਵਿਸ਼ਲੇਸ਼ਣ
ਲਾਗਤਾਂ          ← ਨਵਾਂ (Group B, plan 16)
ਨਿਗਰਾਨੀ         ← ਮੁੜ-ਵਿਵਸਥਿਤ (Group B, plan 16)
...
```

## ਨਿਗਰਾਨੀ ਭਾਗ (ਮੁੜ-ਵਿਵਸਥਿਤ)

ਨਿਗਰਾਨੀ ਭਾਗ ਵਿੱਚ ਹੁਣ **ਸਭ ਤੋਂ ਉੱਪਰ ਸਰਗਰਮੀ** ਹੈ, ਜਿਸ ਤੋਂ ਬਾਅਦ **3 ਉਪ-ਸਮੂਹ** ਹਨ:

```
ਨਿਗਰਾਨੀ
├── ਸਰਗਰਮੀ             ← ਟਾਈਮਲਾਈਨ ਫੀਡ (ਉੱਚ-ਪੱਧਰੀ ਆਈਟਮ)
├── ਲੌਗ ਸਮੂਹ
│   ├── ਲੌਗ (ਸਾਰੇ)
│   ├── ਪ੍ਰੌਕਸੀ ਲੌਗ
│   └── ਕੰਸੋਲ ਲੌਗ
├── ਆਡਿਟ ਸਮੂਹ
│   ├── ਆਡਿਟ ਲੌਗ
│   ├── MCP ਆਡਿਟ
│   └── A2A ਆਡਿਟ
└── ਸਿਸਟਮ ਸਮੂਹ
    ├── ਸਿਹਤ
    └── ਰਨਟਾਈਮ
```

### ਪੁਰਾਣੀ ਬਣਤਰ ਤੋਂ ਕੀ ਬਦਲਿਆ

| ਪਹਿਲਾਂ                                                              | ਬਾਅਦ                                        |
| ------------------------------------------------------------------- | ------------------------------------------- |
| ਸਰਗਰਮੀ = ਲੌਗਾਂ ਦੇ ਅੰਦਰ ਇੱਕ ਟੈਬ, ਜੋ ਆਡਿਟ ਲੌਗ ਦਿਖਾਉਂਦੀ ਸੀ             | ਸਰਗਰਮੀ = ਸਮਰਪਿਤ ਫੀਡ (`/dashboard/activity`) |
| ਨਿਗਰਾਨੀ ਵਿੱਚ ਲਾਗਤ ਪੈਰਾਮੀਟਰ ਸਮੂਹ                                     | ਲਾਗਤਾਂ ਭਾਗ ਵਿੱਚ ਤਬਦੀਲ ਕੀਤਾ ਗਿਆ              |
| ਸਮਤਲ ਸੂਚੀ: ਲੌਗ, ਸਰਗਰਮੀ (ਲੌਗ), ਆਡਿਟ, ਸਿਹਤ, ਰਨਟਾਈਮ, ਕੀਮਤਾਂ, ਬਜਟ, ਕੋਟਾ | ਸੰਰਚਿਤ 3-ਸਮੂਹ + ਸਮਰਪਿਤ ਲਾਗਤਾਂ ਭਾਗ           |

ਇਹ ਦੋਵੇਂ ਹੁਣ ਵੱਖਰੇ ਹਨ:

| ਪੱਖ                | ਸਰਗਰਮੀ (`/dashboard/activity`)                              | ਆਡਿਟ ਲੌਗ (`/dashboard/audit`)             |
| ------------------ | ----------------------------------------------------------- | ----------------------------------------- |
| **ਉਦੇਸ਼**          | ਵਰਤੋਂਕਾਰ ਲਈ ਇਵੈਂਟ ਫੀਡ ("ਹਾਲ ਹੀ ਵਿੱਚ ਕੀ ਹੋਇਆ")               | ਪਾਲਣਾ / ਸੁਰੱਖਿਆ ਲੌਗ                       |
| **ਡਾਟਾ ਸਰੋਤ**      | `GET /api/compliance/audit-log?level=high`                  | `GET /api/compliance/audit-log?level=all` |
| **ਫਾਰਮੈਟ**         | ਟਾਈਮਲਾਈਨ, ਦਿਨ ਅਨੁਸਾਰ ਸਮੂਹਬੱਧ, ਮਨੁੱਖੀ-ਪਾਠਯੋਗ ਕਿਰਿਆਵਾਂ + ਆਈਕਨ | ਸੰਘਣੀ ਪੰਨਾ-ਵੰਡੀ ਸਾਰਣੀ, 50/ਪੰਨਾ            |
| **ਫਿਲਟਰ**          | ਇਵੈਂਟ ਕਿਸਮ ਦੀ ਸ਼੍ਰੇਣੀ                                       | ਕਾਰਵਾਈ, ਗੰਭੀਰਤਾ, ਕਰਤਾ, ਮਿਤੀ ਦੀ ਰੇਂਜ       |
| **ਨਿਰਯਾਤ**         | ਉਪਲਬਧ ਨਹੀਂ                                                  | JSON ਨਿਰਯਾਤ                               |
| **ਕਰਤਾ ਫਿਲਟਰ**     | ਲਾਗੂ ਨਹੀਂ                                                   | ਕਰਤਾ ਅਨੁਸਾਰ ਫਿਲਟਰ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ         |
| **ਦਿਖਾਏ ਗਏ ਇਵੈਂਟ** | ਕੇਵਲ ਉੱਚ-ਪੱਧਰੀ ਕਾਰਵਾਈਆਂ (ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਸੂਚੀ)                  | ਸਾਰੇ ਆਡਿਟ ਇਵੈਂਟ                           |

### ਉੱਚ-ਪੱਧਰੀ ਕਾਰਵਾਈਆਂ ਦੀ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਸੂਚੀ

`src/lib/audit/highLevelActions.ts` ਵਿੱਚ ਪਰਿਭਾਸ਼ਿਤ। ਇਹ ਨਿਯੰਤਰਿਤ ਕਰਦੀ ਹੈ ਕਿ ਕਿਹੜੇ ਇਵੈਂਟ
ਸਰਗਰਮੀ ਫੀਡ ਵਿੱਚ ਦਿਖਾਈ ਦੇਣਗੇ। ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਸੂਚੀ ਵਿੱਚ ਇਹ ਸ਼ਾਮਲ ਹਨ:

- ਪ੍ਰਦਾਤਾ ਨੂੰ ਜੋੜਨ/ਹਟਾਉਣ/ਟੈਸਟ ਕਰਨ ਦੇ ਇਵੈਂਟ
- ਕੌਂਬੋ ਬਣਾਉਣਾ/ਅੱਪਡੇਟ ਕਰਨਾ/ਮਿਟਾਉਣਾ
- API ਕੁੰਜੀ ਜੀਵਨ-ਚੱਕਰ (ਬਣਾਉਣਾ, ਰੱਦ ਕਰਨਾ, ਰੋਟੇਟ ਕਰਨਾ)
- ਬਜਟ ਸੀਮਾ ਤੱਕ ਪਹੁੰਚਣਾ
- ਪ੍ਰਮਾਣੀਕਰਨ ਲੌਗਇਨ/ਲੌਗਆਉਟ
- ਕਲਾਉਡ ਏਜੰਟ ਸੈਸ਼ਨ ਦੀ ਰਚਨਾ
- MCP ਟੂਲ ਰਜਿਸਟ੍ਰੇਸ਼ਨ
- ਵੈੱਬਹੁੱਕ ਬਣਾਉਣਾ/ਮਿਟਾਉਣਾ
- ਕੋਟਾ ਪੂਲ/ਯੋਜਨਾ ਤਬਦੀਲੀਆਂ (`quota.*` ਕਾਰਵਾਈਆਂ, Group B)
- ਪਲੇਟਫਾਰਮ ਇਵੈਂਟ (ਅੱਪਡੇਟ, ਡਿਪਲੌਇ)
- ਹੁਨਰ ਇੰਸਟਾਲ ਕਰਨਾ/ਹਟਾਉਣਾ

ਜਿਹੜੇ ਇਵੈਂਟ ਇਸ ਸੂਚੀ ਵਿੱਚ ਨਹੀਂ ਹਨ, ਉਹ ਕੇਵਲ ਆਡਿਟ ਲੌਗ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ।

### ਨਵੀਂ ਉੱਚ-ਪੱਧਰੀ ਕਾਰਵਾਈ ਜੋੜਨਾ

`src/lib/audit/highLevelActions.ts` ਨੂੰ ਸੰਪਾਦਿਤ ਕਰੋ ਅਤੇ ਕਾਰਵਾਈ ਸਟ੍ਰਿੰਗ ਨੂੰ
`HIGH_LEVEL_ACTIONS` ਵਿੱਚ ਜੋੜੋ। ਇਸ ਲਈ ਇੱਕ PR ਦੀ ਲੋੜ ਹੈ (ਇਹ ਸੂਚੀ ਕੋਡ ਹੈ, DB ਰਾਹੀਂ ਸੰਰਚਿਤ ਨਹੀਂ ਕੀਤੀ ਜਾ ਸਕਦੀ)।
ਸੰਬੰਧਿਤ ਆਈਕਨ ਨੂੰ `src/lib/audit/activityIcons.ts` ਵਿੱਚ ਜੋੜਿਆ ਜਾ ਸਕਦਾ ਹੈ।

## ਰੀਡਾਇਰੈਕਟ: `/dashboard/logs/activity`

ਪੁਰਾਣਾ ਪਾਥ `/dashboard/logs/activity`,
`src/app/(dashboard)/dashboard/logs/activity/page.tsx` ਵਿੱਚ `permanentRedirect()` ਰਾਹੀਂ
ਸਥਾਈ ਤੌਰ 'ਤੇ (HTTP 308) `/dashboard/activity` ਵੱਲ ਰੀਡਾਇਰੈਕਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

ਪੁਰਾਣੀ ID ਦਾ ਹਵਾਲਾ ਦੇਣ ਵਾਲੀਆਂ ਵਰਤੋਂਕਾਰ ਪ੍ਰੀਸੈਟਾਂ ਨੂੰ ਟੁੱਟਣ ਤੋਂ ਬਚਾਉਣ ਲਈ ਪੁਰਾਣੀ ਸਾਈਡਬਾਰ ID `logs-activity` ਨੂੰ
`HIDEABLE_SIDEBAR_ITEM_IDS` ਵਿੱਚ ਸੁਰੱਖਿਅਤ ਰੱਖਿਆ ਗਿਆ ਹੈ
(ਪਰ `SIDEBAR_DEFINITIONS` ਵਿੱਚੋਂ ਹਟਾ ਦਿੱਤਾ ਗਿਆ ਹੈ)।
