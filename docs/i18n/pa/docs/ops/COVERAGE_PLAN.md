## ਨਿਯਮ

- ਕਵਰੇਜ ਟੀਚੇ ਸਰੋਤ ਫਾਈਲਾਂ ਉੱਤੇ ਲਾਗੂ ਹੁੰਦੇ ਹਨ, `tests/**` ਉੱਤੇ ਨਹੀਂ।
- `open-sse/**` ਉਤਪਾਦ ਦਾ ਹਿੱਸਾ ਹੈ ਅਤੇ ਇਸ ਨੂੰ ਦਾਇਰੇ ਵਿੱਚ ਰੱਖਣਾ ਲਾਜ਼ਮੀ ਹੈ।
- ਨਵੇਂ ਕੋਡ ਨਾਲ ਛੋਹੇ ਗਏ ਖੇਤਰਾਂ ਵਿੱਚ ਕਵਰੇਜ ਘਟਣੀ ਨਹੀਂ ਚਾਹੀਦੀ।
- ਲਾਗੂਕਰਨ ਦੇ ਵੇਰਵਿਆਂ ਦੀ ਬਜਾਏ ਵਿਹਾਰ ਅਤੇ ਬ੍ਰਾਂਚ ਨਤੀਜਿਆਂ ਦੀ ਜਾਂਚ ਨੂੰ ਤਰਜੀਹ ਦਿਓ।
- `src/lib/db/**` ਲਈ ਵਿਆਪਕ ਮੌਕਾਂ ਦੀ ਬਜਾਏ ਅਸਥਾਈ SQLite ਡੇਟਾਬੇਸਾਂ ਅਤੇ ਛੋਟੇ ਫਿਕਸਚਰਾਂ ਨੂੰ ਤਰਜੀਹ ਦਿਓ।

### ਪੜਾਅ 5: 75% -> 80%

- [ ] ਇਨ੍ਹਾਂ ਲਈ ਹੈਂਡਲਰ-ਪੱਧਰੀ ਟੈਸਟ ਜੋੜੋ:

### ਪੜਾਅ 6: 80% -> 85%

- [ ] ਮੁੱਖ ਕਵਰੇਜ ਪਾਥ ਵਿੱਚ ਹੋਰ ਐਜ-ਕੇਸ ਸੂਟ ਮਿਲਾਓ
- [ ] ਕਮਜ਼ੋਰ ਕੰਸਟਰਕਟਰ/ਹੈਲਪਰ ਕਵਰੇਜ ਵਾਲੇ DB ਮੌਡਿਊਲਾਂ ਲਈ ਫੰਕਸ਼ਨ ਕਵਰੇਜ ਵਧਾਓ
- [ ] `settings.ts`, `registeredKeys.ts`, `validation.ts`, ਅਤੇ ਅਨੁਵਾਦਕ ਹੈਲਪਰਾਂ ਵਿੱਚ ਬ੍ਰਾਂਚ ਅੰਤਰ ਬੰਦ ਕਰੋ

### ਪੜਾਅ 7: 85% -> 90%

- [ ] ਬਾਕੀ ਰਹਿ ਗਈਆਂ ਘੱਟ-ਕਵਰੇਜ ਫ਼ਾਈਲਾਂ ਨੂੰ ਰੁਕਾਵਟਾਂ ਵਜੋਂ ਲਓ
- [ ] 90% ਤੱਕ ਪਹੁੰਚਣ ਦੇ ਯਤਨ ਦੌਰਾਨ ਠੀਕ ਕੀਤੇ ਹਰੇਕ ਅਣਕਵਰ ਉਤਪਾਦਨ ਬੱਗ ਲਈ ਰਿਗ੍ਰੈਸ਼ਨ ਟੈਸਟ ਜੋੜੋ
- [ ] CI ਵਿੱਚ ਕਵਰੇਜ ਗੇਟ ਕੇਵਲ ਉਦੋਂ ਵਧਾਓ ਜਦੋਂ ਸਥਾਨਕ ਬੇਸਲਾਈਨ ਘੱਟੋ-ਘੱਟ ਲਗਾਤਾਰ ਦੋ ਰਨਾਂ ਲਈ ਸਥਿਰ ਹੋਵੇ

## ਰੈਚਟ ਨੀਤੀ

`npm run test:coverage` ਦੀਆਂ ਥ੍ਰੈਸ਼ਹੋਲਡਾਂ ਨੂੰ ਸਿਰਫ਼ ਉਦੋਂ ਅੱਪਡੇਟ ਕਰੋ ਜਦੋਂ ਪ੍ਰੋਜੈਕਟ ਅਸਲ ਵਿੱਚ ਅਗਲੇ ਮੀਲ-ਪੱਥਰ ਨੂੰ ਇੱਕ ਆਰਾਮਦਾਇਕ ਅੰਤਰ ਨਾਲ ਪਾਰ ਕਰ ਲਵੇ।

**ਮੌਜੂਦਾ ਗੇਟ:** `npm run test:coverage` **60 ਸਟੇਟਮੈਂਟਾਂ / 60 ਲਾਈਨਾਂ / 60 ਫੰਕਸ਼ਨਾਂ / 60 ਬ੍ਰਾਂਚਾਂ** ਨੂੰ ਲਾਗੂ ਕਰਦਾ ਹੈ (ਮੈਟ੍ਰਿਕ ਨੂੰ Quality-Gates Fase 6A.1 ਵਿੱਚ ਮੁੜ ਬੇਸ ਕੀਤਾ ਗਿਆ ਸੀ — ਪਹਿਲਾਂ ਵਾਲੀ 82.58% ਬੇਸਲਾਈਨ ਵਧੀ ਹੋਈ ਸੀ ਕਿਉਂਕਿ ਉਸ ਵਿੱਚ ਟੈਸਟ ਫਾਈਲਾਂ ਗਿਣੀਆਂ ਜਾਂਦੀਆਂ ਸਨ ਅਤੇ `open-sse` ਨੂੰ ਸ਼ਾਮਲ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ ਸੀ)। `test:coverage:legacy` ਕਮਾਂਡ ਇਤਿਹਾਸਕ ਤੁਲਨਾ ਲਈ ਪੁਰਾਣੇ 50/50/50 ਮੈਟ੍ਰਿਕ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਦੀ ਹੈ।

ਨਵੀਨਤਮ ਰਿਪੋਰਟ ਦੇ ਆਧਾਰ 'ਤੇ ਤੁਰੰਤ ਥ੍ਰੈਸ਼ਹੋਲਡ ਜਾਂਚਾਂ ਲਈ ਇਹ ਵਰਤੋ:

```bash
node scripts/check/test-report-summary.mjs --threshold 75
```

ਜਦੋਂ ਬ੍ਰਾਂਚ ਕਵਰੇਜ ਲਗਾਤਾਰ ਦੋ ਰਨਾਂ ਲਈ 78% ਤੋਂ ਉੱਪਰ ਬਣੀ ਰਹੇ, ਤਾਂ ਅਗਲਾ ਰੈਚਟ ਟੀਚਾ `80/75/78` ਹੈ।

## ਜਾਣਿਆ-ਪਛਾਣਿਆ ਅੰਤਰ

ਮੌਜੂਦਾ ਕਵਰੇਜ ਕਮਾਂਡ ਮੁੱਖ Node ਯੂਨਿਟ ਸੂਟ ਨੂੰ ਮਾਪਦੀ ਹੈ ਅਤੇ ਇਸ ਰਾਹੀਂ ਪਹੁੰਚੇ ਸਰੋਤ ਨੂੰ ਸ਼ਾਮਲ ਕਰਦੀ ਹੈ, ਜਿਸ ਵਿੱਚ `open-sse` ਵੀ ਸ਼ਾਮਲ ਹੈ। ਇਹ ਹਾਲੇ Vitest ਕਵਰੇਜ ਨੂੰ ਇੱਕੋ ਇਕਸਾਰ ਰਿਪੋਰਟ ਵਿੱਚ ਮਰਜ ਨਹੀਂ ਕਰਦੀ। ਇਹ ਮਰਜ ਬਾਅਦ ਵਿੱਚ ਕਰਨਾ ਲਾਭਦਾਇਕ ਹੈ, ਪਰ ਇਹ 60% -> 80% ਦੀ ਚੜ੍ਹਾਈ ਸ਼ੁਰੂ ਕਰਨ ਵਿੱਚ ਰੁਕਾਵਟ ਨਹੀਂ ਹੈ।
