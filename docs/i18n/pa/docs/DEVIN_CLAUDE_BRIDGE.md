`devin-cli-agentic` ਅਸਲ Claude Code ਰਨਟਾਈਮ ਨੂੰ OmniRoute ਦੇ ਸਥਾਨਕ Anthropic
Messages ਐਂਡਪੌਇੰਟ ਦੀ ਵਰਤੋਂ ਕਰਨ ਦਿੰਦਾ ਹੈ, ਜਦਕਿ ਅਧਿਕਾਰਤ Devin CLI ACP stdio ਰਾਹੀਂ ਮਾਡਲ ਜਵਾਬ ਮੁਹੱਈਆ ਕਰਦਾ ਹੈ। ਇਹ
ਮੌਜੂਦਾ Anthropic, Claude OAuth, Claude Web, ਜਾਂ `devin-cli` ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸੋਧਦਾ ਨਹੀਂ ਹੈ।

> **ਮੌਜੂਦਾ ਸਥਿਤੀ: ਪਿੰਨ ਕੀਤਾ Claude Code `2.1.258`; ਆਫ਼ਲਾਈਨ ਅਤੇ ਲਾਈਵ ਪ੍ਰਮਾਣਿਕਤਾ ਆਖਰੀ ਵਾਰ
> `2.1.220` ਉੱਤੇ ਦਰਜ ਕੀਤੀ ਗਈ ਸੀ।** `2.1.220` ਪਿੰਨ ਨੇ Devin CLI
> `3000.2.17` ਅਤੇ ਮਾਡਲ `swe-1-7-lightning` ਰਾਹੀਂ ਤਿੰਨ ਅਲੱਗ-ਥਲੱਗ ਦ੍ਰਿਸ਼ ਪੂਰੇ ਕੀਤੇ; ਉਸ ਅੰਤਿਮ ਲਾਈਵ ਰਨ ਨੇ ਕਲਾਇੰਟ-ਮਲਕੀਅਤ ਵਾਲੇ `Read`,
> `Edit`, ਅਤੇ `Bash` ਟਰਨ, ਸਫਲ `npm test` ਨਤੀਜੇ, ਪ੍ਰੋਜੈਕਟ ਕਮਾਂਡ ਅਤੇ ਸਕਿੱਲ
> ਖੋਜ, ਕੇਵਲ-Devin ਰੂਟਿੰਗ, ਅਤੇ ਸਿਫ਼ਰ Claude ਆਉਟਗੋਇੰਗ ਟ੍ਰੈਫਿਕ ਸਾਬਤ ਕੀਤਾ। ਫਿਰ ਪਿੰਨ ਨੂੰ ਵਧਾ ਕੇ `2.1.258`
> ਕਰ ਦਿੱਤਾ ਗਿਆ (ਉਹ CLI ਪੀੜ੍ਹੀ ਜਿਸਦੀ ਪਛਾਣ OmniRoute ਦਾ Claude ਧਾਰਨ ਕਰਦਾ ਹੈ, ਅਤੇ ਪਹਿਲੀ ਲਾਈਨ ਜੋ
> Fable 5.1 ਟੀਅਰ ਨੂੰ ਮੂਲ ਰੂਪ ਵਿੱਚ ਸ਼ਾਮਲ ਕਰਦੀ ਹੈ)। ਨਵੇਂ ਪਿੰਨ ਉੱਤੇ ਪਿੰਨ ਕੀਤੀ ਬੇਸ ਇਮੇਜ ਵਿੱਚ ਇੰਸਟਾਲੇਸ਼ਨ ਲੇਅਰ ਅਤੇ `claude --version`
> ਦੀ ਪੁਸ਼ਟੀ ਕੀਤੀ ਗਈ, ਅਤੇ ਬ੍ਰਿਜ ਯੂਨਿਟ ਸੂਟ, `compose config` ਅਤੇ
> ਸਥਿਰ ਆਈਸੋਲੇਸ਼ਨ ਸਬੂਤ ਪਾਸ ਹੁੰਦੇ ਹਨ — ਪਰ ਆਫ਼ਲਾਈਨ ਮੌਕ ਦ੍ਰਿਸ਼ ਅਤੇ ਲਾਈਵ ਤਿੰਨ-ਦ੍ਰਿਸ਼
> ਸੂਟ ਨੂੰ ਹਾਲੇ ਮੁੜ ਨਹੀਂ ਚਲਾਇਆ ਗਿਆ। ਇਸ ਪਿੰਨ ਨਾਲ ਬ੍ਰਿਜ ਉੱਤੇ ਨਿਰਭਰ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਉਨ੍ਹਾਂ ਨੂੰ ਮੁੜ ਚਲਾਓ
> ("ਪਿੰਨ ਕੀਤੇ ਟੂਲ ਅੱਪਡੇਟ ਕਰਨਾ" ਵੇਖੋ)।

## ਆਰਕੀਟੈਕਚਰ

```text
Claude Code 2.1.258 (ਅਲੱਗ-ਥਲੱਗ ਗੈਰ-ਰੂਟ Linux ਕੰਟੇਨਰ)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ਫਾਰਮੈਟ, ਬਿਨਾਂ-ਪ੍ਰਮਾਣੀਕਰਨ ਵਾਲਾ ਪ੍ਰਦਾਤਾ)
  -> devin acp --agent-type summarizer (ਅਧਿਕਾਰਤ ACP stdio, ਕੋਈ Devin ਟੂਲ ਨਹੀਂ)
  -> ਸਮਰਪਿਤ devin-auth ਵਾਲਿਊਮ ਵਿੱਚ Devin ਖਾਤਾ
```

ਅਧਿਕਾਰਤ CLI ਦਾ ਡਿਫਾਲਟ ACP ਏਜੰਟ ਆਪਣੇ ਟੂਲ ਚਲਾ ਸਕਦਾ ਹੈ, ਇਸ ਲਈ ਇਹ ਬ੍ਰਿਜ ਉਸਦੀ ਵਰਤੋਂ ਨਹੀਂ ਕਰਦਾ।
ਇਹ ਨਿਰਧਾਰਤ `summarizer` ACP ਏਜੰਟ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ, ਜਿਸਦੇ ਅਧਿਕਾਰਤ CLI ਮੋਡ ਵਿੱਚ ਕੋਈ ਟੂਲ ਨਹੀਂ ਹਨ, ਅਤੇ
ਸੀਰੀਅਲਾਈਜ਼ ਕੀਤੀ Anthropic ਬੇਨਤੀ ਨੂੰ ਐਗਜ਼ਿਕਿਊਸ਼ਨ ਟਰੇਸ ਵਜੋਂ ਫ੍ਰੇਮ ਕਰਦਾ ਹੈ। ਜਦੋਂ ਕਿਸੇ ਹੋਰ Claude-ਮਲਕੀਅਤ ਵਾਲੀ
ਕਾਰਵਾਈ ਦੀ ਲੋੜ ਹੋਵੇ, ਤਾਂ ਜਵਾਬ ਵਿੱਚ ਬਿਲਕੁਲ ਇੱਕ ਕਲਾਇੰਟ ਟੂਲ ਐਨਵਲਪ ਹੋਣਾ ਲਾਜ਼ਮੀ ਹੈ। ਕਿਸੇ ਵੀ ACP
`tool_call` ਜਾਂ `tool_call_update` ਨੂੰ ਜਵਾਬ ਸਫਲ ਵਜੋਂ ਰਿਪੋਰਟ ਕੀਤੇ ਜਾਣ ਤੋਂ ਪਹਿਲਾਂ ਹੀ ਰੱਦ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।

`open-sse/executors/devin-agentic/serializer.ts` ਵਿੱਚਲਾ ਸੀਰੀਅਲਾਈਜ਼ਰ `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, ਅਤੇ
Claude Code ਵੱਲੋਂ ਦਿੱਤੇ ਟੂਲਾਂ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਦਾ ਹੈ। ਇਮੇਜਾਂ ਅਤੇ ਅਣਜਾਣ ਬਲਾਕਾਂ ਉੱਤੇ ਸਪਸ਼ਟ ਤੌਰ 'ਤੇ ਅਸਫਲਤਾ ਹੁੰਦੀ ਹੈ। ਵੱਡੇ ਟੂਲ ਨਤੀਜੇ
ਇੱਕ ਦਿਸਣਯੋਗ ਟਰੰਕੇਸ਼ਨ ਮਾਰਕਰ ਵਰਤਦੇ ਹਨ।

ਪਾਰਸਰ ਹਰ ਮਾਡਲ ਟਰਨ ਲਈ ਇੱਕ ਵੱਖਰਾ `<tool>{...}</tool>` ਐਨਵਲਪ ਸਵੀਕਾਰਦਾ ਹੈ। ਇਹ
ਨਾਮ ਨੂੰ ਬੇਨਤੀ ਦੀ ਟੂਲ ਸੂਚੀ ਨਾਲ ਜਾਂਚਦਾ ਹੈ, ਉਸ ਟੂਲ ਦੇ JSON
Schema ਅਨੁਸਾਰ ਆਰਗੂਮੈਂਟਾਂ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ, ਮਿਲੀ-ਜੁਲੀ ਵਿਆਖਿਆ/ਕਾਰਵਾਈਆਂ ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ, ਅਤੇ ਇੱਕ ਸੀਮਿਤ ਮੁਰੰਮਤ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਫਿਰ Claude Code
ਨਤੀਜੇ ਵਜੋਂ ਮਿਲੇ Anthropic `tool_use` ਨੂੰ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਚਲਾਉਂਦਾ ਹੈ ਅਤੇ `tool_result` ਨੂੰ OmniRoute ਰਾਹੀਂ
ਵਾਪਸ ਭੇਜਦਾ ਹੈ।

## ਆਈਸੋਲੇਸ਼ਨ ਅਤੇ ਖ਼ਤਰਾ ਮਾਡਲ

ਹੋਸਟ ਦੀ Claude ਇੰਸਟਾਲੇਸ਼ਨ, ਖਾਤਾ, ਅਤੇ ਸੰਰਚਨਾ ਦਾਇਰੇ ਤੋਂ ਬਾਹਰ ਹਨ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ
ਵਰਜਿਤ ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ। Compose ਸੇਵਾਵਾਂ:

- UID/GID `10001:10001` ਵਜੋਂ, ਸਿਰਫ਼-ਪੜ੍ਹਨਯੋਗ ਰੂਟ ਫ਼ਾਈਲ ਸਿਸਟਮ, ਹਟਾਈਆਂ ਹੋਈਆਂ ਸਮਰੱਥਾਵਾਂ, ਅਤੇ
  `no-new-privileges` ਨਾਲ ਚੱਲਦੀਆਂ ਹਨ;
- ਇੱਕ ਨਿੱਜੀ `/home/bridge`, ਇੱਕ ਸਮਰਪਿਤ Claude ਕਾਨਫ਼ਿਗ ਵਾਲਿਊਮ, ਅਲੱਗ-ਥਲੱਗ OmniRoute ਡੇਟਾ,
  ਅਤੇ ਇੱਕ ਵੱਖਰਾ `devin-auth` ਵਾਲਿਊਮ ਵਰਤਦੀਆਂ ਹਨ;
- ਸਿਰਫ਼ ਅਸਥਾਈ `.sandbox` ਵਰਕਸਪੇਸ/ਸਬੂਤ ਮਾਊਂਟ ਕਰਦੀਆਂ ਹਨ;
- ਹੋਸਟ ਹੋਮ, Keychain, SSH, ਕਲਾਉਡ ਪ੍ਰਮਾਣ-ਪੱਤਰ, ਜਾਂ Docker ਸਾਕਟ ਨੂੰ ਮਾਊਂਟ ਨਹੀਂ ਕਰਦੀਆਂ;
- ਸਪਸ਼ਟ ਵਾਤਾਵਰਣ ਬਣਾਉਂਦੀਆਂ ਹਨ ਅਤੇ Anthropic API/OAuth/ਰੂਟਿੰਗ ਵੇਰੀਏਬਲ ਹਟਾਉਂਦੀਆਂ ਹਨ;
- ਕੇਵਲ-ਸਥਾਨਕ ਕੁੰਜੀ ਨਾਲ Claude Code ਇਨਫ਼ਰੈਂਸ ਨੂੰ ਸਿਰਫ਼ `http://omniroute:20128` ਵੱਲ ਭੇਜਦੀਆਂ ਹਨ।

ਆਫ਼ਲਾਈਨ ਪ੍ਰੋਫ਼ਾਈਲ ਇੱਕ ਅੰਦਰੂਨੀ ਨੈੱਟਵਰਕ ਵਰਤਦਾ ਹੈ। ਲਾਈਵ ਪ੍ਰੋਫ਼ਾਈਲ ਵਿੱਚ, OmniRoute
ਅਧਿਕਾਰਤ Devin ਐਂਡਪੌਇੰਟਾਂ ਤੱਕ ਸਿਰਫ਼ `network-guard` ਰਾਹੀਂ ਪਹੁੰਚਦਾ ਹੈ; ਗੈਰ-ਸੰਬੰਧਿਤ ਟਿਕਾਣੇ ਅਸਵੀਕਾਰ ਕੀਤੇ ਜਾਂਦੇ ਹਨ।
Claude Code ਕੋਲ ਇੱਕ ਵੱਖਰਾ ਸਾਰੇ ਆਉਟਗੋਇੰਗ ਟ੍ਰੈਫਿਕ ਨੂੰ ਅਸਵੀਕਾਰ ਕਰਨ ਵਾਲਾ ਗਾਰਡ ਹੈ ਅਤੇ ਉਹ `NO_PROXY` ਰਾਹੀਂ ਸਿਰਫ਼ ਸਥਾਨਕ OmniRoute
ਸੇਵਾ ਤੱਕ ਪਹੁੰਚ ਸਕਦਾ ਹੈ। ਗਾਰਡ ਆਡਿਟ ਫ਼ਾਈਲਾਂ ਸਿਰਫ਼ ਉਨ੍ਹਾਂ ਦੀ ਗਾਰਡ ਪ੍ਰਕਿਰਿਆ ਵੱਲੋਂ ਮਾਊਂਟ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
ਸਕ੍ਰਿਪਟਾਂ ਟੋਕਨ-ਰਹਿਤ ਸਬੂਤ ਐਕਸਪੋਰਟ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਫ਼ਾਈਲ ਦੀ ਮਲਕੀਅਤ, ਮੋਡ, ਲਿੰਕ ਗਿਣਤੀ, ਅਤੇ ਹਰ ਫ਼ੈਸਲੇ ਦੀ ਪੁਸ਼ਟੀ ਕਰਦੀਆਂ ਹਨ।

ਆਈਸੋਲੇਸ਼ਨ ਸਬੂਤ ਨੂੰ ਸੁਤੰਤਰ ਤੌਰ 'ਤੇ ਚਲਾਓ:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

ਇਹ ਟੋਪੋਲੋਜੀ, ਨਾਮਿਤ ਮਾਊਂਟਾਂ, ਗੈਰ-ਰੂਟ/ਸਿਰਫ਼-ਪੜ੍ਹਨਯੋਗ ਸੈਟਿੰਗਾਂ, ਸਪਸ਼ਟ ਸਥਾਨਕ ਰੂਟਿੰਗ,
ਸੰਵੇਦਨਸ਼ੀਲ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲਾਂ ਦੀ ਗੈਰਹਾਜ਼ਰੀ, Docker ਸਾਕਟ ਦੀ ਗੈਰਹਾਜ਼ਰੀ, `api.anthropic.com` ਅਤੇ `claude.ai` ਤੱਕ
ਰੋਕੀ ਹੋਈ ਪਹੁੰਚ, ਕੇਵਲ-Devin ਪ੍ਰਦਾਤਾ ਚੋਣ, ਅਤੇ ACP ਬੈਕਐਂਡ ਉਪਲਬਧ ਨਾ ਹੋਣ 'ਤੇ ਸਪਸ਼ਟ ਅਸਫਲਤਾ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ।

## ਪਹਿਲੀ ਵਾਰ ਸੈਟਅੱਪ ਅਤੇ ਆਮ ਵਰਤੋਂ

ਪਿੰਨ ਕੀਤੀ ਇਮੇਜ ਬਿਲਡ ਕਰੋ:

```bash
./scripts/devin-bridge/build
```

ਸਿਰਫ਼ ਅਲੱਗ-ਥਲੱਗ Devin ਵਾਲਿਊਮ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰੋ:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

ਲਾਗਇਨ ਕਮਾਂਡ ਰਿਮੋਟ/ਕੰਟੇਨਰ ਵਾਤਾਵਰਣਾਂ ਲਈ ਬਣਾਏ ਗਏ ਅਧਿਕਾਰਤ ਮੈਨੁਅਲ-ਟੋਕਨ ਪ੍ਰਵਾਹ ਦੀ ਵਰਤੋਂ ਕਰਦੀ ਹੈ। ਮੁੱਲ ਸਿੱਧਾ CLI ਪ੍ਰੌਂਪਟ ਵਿੱਚ ਦਰਜ ਕੀਤਾ ਜਾਂਦਾ ਹੈ; ਇਸਨੂੰ ਪ੍ਰੋਸੈਸ ਆਰਗੂਮੈਂਟ ਵਜੋਂ ਪਾਸ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ, Git ਵਿੱਚ ਨਹੀਂ ਲਿਖਿਆ ਜਾਂਦਾ ਅਤੇ ਨਾ ਹੀ ਹੋਸਟ ਤੋਂ ਕਾਪੀ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

ਅਲੱਗ-ਥਲੱਗ Claude Code ਰਨਟਾਈਮ ਲਾਂਚ ਕਰੋ:

```bash
./scripts/devin-bridge/launch
```

ਕੰਟੇਨਰਾਈਜ਼ਡ Claude Code ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ `launch` ਆਈਸੋਲੇਸ਼ਨ, Devin ਪ੍ਰਮਾਣੀਕਰਨ ਅਤੇ ਮਾਡਲ ਖੋਜ ਦੀ ਮੁੜ ਜਾਂਚ ਕਰਦਾ ਹੈ। ਇਹ ਕਦੇ ਵੀ ਹੋਸਟ ਦੀ Claude ਐਗਜ਼ਿਕਿਊਟੇਬਲ ਨਹੀਂ ਚਲਾਉਂਦਾ। ਮਾਡਲ ਉਪਨਾਮ `.env.devin-bridge` ਵਿੱਚ ਸੈੱਟ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ; ਹਰੇਕ ਕੌਂਫਿਗਰ ਕੀਤਾ ਮੁੱਲ `devin-cli-agentic/` ਪ੍ਰੀਫਿਕਸ ਨੂੰ ਕਾਇਮ ਰੱਖਣਾ ਲਾਜ਼ਮੀ ਹੈ।

## ਪ੍ਰਮਾਣੀਕਰਨ ਕਮਾਂਡਾਂ

ਦੁਹਰਾਏ ਜਾ ਸਕਣ ਵਾਲੇ ਆਫ਼ਲਾਈਨ ਪਾਥ ਲਈ ਕਿਸੇ Devin ਖਾਤੇ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ ਅਤੇ ਇਸ ਵਿੱਚ ਰਨਟਾਈਮ ਇੰਟਰਨੈੱਟ ਨਹੀਂ ਹੁੰਦਾ:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

ਪ੍ਰਮਾਣਿਤ, ਆਪਟ-ਇਨ ਲਾਈਵ ਪਾਥ ਇਹ ਹੈ:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

ਲਾਈਵ ਰਨਰ ACP ਸੈਸ਼ਨਾਂ ਨੂੰ ਇੱਕੋ ਵਾਰ ਵੱਡੀ ਗਿਣਤੀ ਵਿੱਚ ਖੋਲ੍ਹਣ ਤੋਂ ਬਚਣ ਲਈ ਦ੍ਰਿਸ਼ਾਂ ਦੇ ਵਿਚਕਾਰ ਉਡੀਕ ਕਰਦਾ ਹੈ ਅਤੇ ਲਿਖਤੀ ਦਾਅਵਿਆਂ 'ਤੇ ਭਰੋਸਾ ਕਰਨ ਦੀ ਬਜਾਏ ਸੰਰਚਿਤ Claude ਸਟ੍ਰੀਮ ਇਵੈਂਟਾਂ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ। ਇਸਦੇ ਤਿੰਨ ਦ੍ਰਿਸ਼ ਇਹ ਸਾਬਤ ਕਰਦੇ ਹਨ:

1. ਸਿੱਧੀ ਪ੍ਰੋਜੈਕਟ ਰੀਡਿੰਗ ਅਤੇ ਖਾਮੀ ਵਿਸ਼ਲੇਸ਼ਣ;
2. ਇੱਕ ਅਸਲ `Edit`, ਕਲਾਇੰਟ ਦੀ ਮਲਕੀਅਤ ਵਾਲਾ `Bash` `npm test`, ਅਤੇ ਇੱਕ ਟਰਮੀਨਲ ਨਤੀਜਾ;
3. `/bridge-check` ਦੇ ਨਾਲ `bridge-proof` ਖੋਜ, ਪ੍ਰੋਜੈਕਟ ਰੀਡਿੰਗ, ਕਲਾਇੰਟ ਦੀ ਮਲਕੀਅਤ ਵਾਲਾ ਇੱਕ ਹੋਰ ਸਫਲ `npm test`, ਅਤੇ ਕੋਈ ਕੰਮ ਬਕਾਇਆ ਰਹੇ ਬਿਨਾਂ ਪੂਰਾ ਹੋਣਾ।

ਅੰਤਿਮ ਗੇਟ Devin ਨੈੱਟਵਰਕ ਆਡਿਟ ਦੀ ਵੀ ਜਾਂਚ ਕਰਦਾ ਹੈ ਅਤੇ Claude ਈਗ੍ਰੈੱਸ ਆਡਿਟ ਦਾ ਖਾਲੀ ਰਹਿਣਾ ਲਾਜ਼ਮੀ ਕਰਦਾ ਹੈ।

## ਪਿੰਨ ਕੀਤੇ ਟੂਲ ਅੱਪਡੇਟ ਕਰਨਾ

ਇਮੇਜ ਵਿੱਚ Node, Claude Code ਅਤੇ Devin CLI ਨੂੰ `docker/devin-bridge/Dockerfile` ਵਿੱਚ ਪਿੰਨ ਕੀਤਾ ਗਿਆ ਹੈ। ਅੱਪਡੇਟ ਕਰਨ ਲਈ:

1. ਸਪਸ਼ਟ ਵਰਜਨ ਬਦਲੋ;
2. ਦੋਵੇਂ ਆਰਕੀਟੈਕਚਰ-ਵਿਸ਼ੇਸ਼ Devin ਆਰਕਾਈਵ ਚੈਕਸਮਾਂ ਨੂੰ ਅਧਿਕਾਰਤ ਆਰਟੀਫੈਕਟ ਦੇ ਮੁੱਲਾਂ ਨਾਲ ਬਦਲੋ;
3. ਮੁੜ ਬਿਲਡ ਕਰੋ ਅਤੇ ਹਰੇਕ ਆਫ਼ਲਾਈਨ ਪ੍ਰਮਾਣੀਕਰਨ ਕਮਾਂਡ ਚਲਾਓ;
4. ਇਮੇਜ ਦੇ ਅੰਦਰਲੇ ਵਰਜਨਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ;
5. ਪ੍ਰਮਾਣਿਤ ਤਿੰਨ-ਦ੍ਰਿਸ਼ਾਂ ਵਾਲਾ ਲਾਈਵ ਸੂਟ ਮੁੜ ਚਲਾਓ।

ਕਿਸੇ ਵੀ CLI ਨੂੰ ਹੋਸਟ ਉੱਤੇ ਗਲੋਬਲ ਤੌਰ 'ਤੇ ਇੰਸਟਾਲ ਨਾ ਕਰੋ ਅਤੇ ਚੈਕਸਮ ਪ੍ਰਮਾਣੀਕਰਨ ਨੂੰ ਕਿਸੇ ਗੈਰ-ਪ੍ਰਮਾਣਿਤ ਡਾਊਨਲੋਡ ਨਾਲ ਨਾ ਬਦਲੋ।

## ਨਿਦਾਨ ਅਤੇ ਸਫ਼ਾਈ

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  ਸਥਾਨਕ ਰੂਟਿੰਗ ਅਤੇ ਸਾਫ਼ ਕੀਤੀਆਂ ਐਗਜ਼ਿਕਿਊਟਰ ਗਲਤੀਆਂ ਦਿਖਾਉਂਦਾ ਹੈ।
- `.sandbox/evidence/mock-acp.jsonl` ਨਿਰਧਾਰਤ ਮੌਕ ACP ਕਾਰਵਾਈਆਂ ਰਿਕਾਰਡ ਕਰਦੀ ਹੈ।
- `.sandbox/evidence/claude-stream.jsonl` ਅਸਲ Claude Code ਆਫ਼ਲਾਈਨ ਰਨ ਨੂੰ ਰਿਕਾਰਡ ਕਰਦੀ ਹੈ।
- `.sandbox/evidence/live-*.jsonl` ਤਿੰਨ ਪ੍ਰਮਾਣਿਤ ਲਾਈਵ ਸਟ੍ਰੀਮਾਂ ਨੂੰ ਰਿਕਾਰਡ ਕਰਦੀ ਹੈ।
- `.sandbox/evidence/egress.jsonl` ਅਤੇ `.sandbox/evidence/claude-egress.jsonl` ਗਾਰਡ ਆਡਿਟਾਂ ਦੀਆਂ ਪ੍ਰਮਾਣਿਤ, ਟੋਕਨ-ਰਹਿਤ ਕਾਪੀਆਂ ਹਨ।

ਲਾਗਇਨ/ਕੌਂਫਿਗ ਵਾਲਿਊਮਾਂ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਦੇ ਹੋਏ ਮਲਕੀਅਤ ਵਾਲੇ ਕੰਟੇਨਰ ਅਤੇ ਨੈੱਟਵਰਕ ਬੰਦ ਕਰੋ:

```bash
./scripts/devin-bridge/clean
```

ਨਾਮਿਤ ਵਾਲਿਊਮਾਂ ਸਮੇਤ, ਬ੍ਰਿਜ ਦੀ ਮਲਕੀਅਤ ਵਾਲਾ ਪੂਰਾ ਵਾਤਾਵਰਣ ਹਟਾਓ:

```bash
./scripts/devin-bridge/clean --all
```

## ਸੀਮਾਵਾਂ

- ਬ੍ਰਿਜ ਸਥਿਰ no-tools `summarizer` ਭੂਮਿਕਾ 'ਤੇ ਨਿਰਭਰ ਕਰਦਾ ਹੈ ਕਿਉਂਕਿ Devin CLI `3000.2.17`
  ਕੋਈ ਨਿਰਪੱਖ no-tools ACP ਏਜੰਟ ਉਪਲਬਧ ਨਹੀਂ ਕਰਵਾਉਂਦਾ। ਐਡਾਪਟਰ ਸੰਖੇਪ-ਰੂਪੀ
  ਦਰਮਿਆਨੇ ਜਵਾਬਾਂ ਦੀ ਭਰਪਾਈ ਕਰਦਾ ਹੈ, ਪਰ ਇੱਕ ਸੀਮਿਤ ਮੁਰੰਮਤ ਫਿਰ ਵੀ ਸਪਸ਼ਟ ਤੌਰ 'ਤੇ ਅਸਫਲ ਹੋ ਸਕਦੀ ਹੈ।
- ਲਾਈਵ ACP ਕਾਲਾਂ ਅਸਥਾਈ `502`/`504` ਜਵਾਬ ਵਾਪਸ ਕਰ ਸਕਦੀਆਂ ਹਨ। ਹਾਰਨੈੱਸ ਦ੍ਰਿਸ਼ਾਂ ਵਿਚਕਾਰ ਅੰਤਰ ਰੱਖਦਾ ਹੈ;
  ਲਗਾਤਾਰ ਅਸਫਲਤਾ ਦੀ ਸਥਿਤੀ ਵਿੱਚ ਇਹ ਬੰਦ ਹੀ ਰਹਿੰਦਾ ਹੈ ਅਤੇ ਕਦੇ ਵੀ ਕੋਈ ਹੋਰ ਪ੍ਰਦਾਤਾ ਨਹੀਂ ਚੁਣਦਾ।
- ACP ਸੰਦਰਭ ਹਰ Anthropic ਬੇਨਤੀ ਤੋਂ ਮੁੜ ਬਣਾਇਆ ਜਾਂਦਾ ਹੈ; ਕੋਈ ਪ੍ਰਕਿਰਿਆ/ਸੈਸ਼ਨ
  ਸੰਬੰਧਤਾ ਨਹੀਂ ਹੈ।
- ਹਰ ਮਾਡਲ ਜਵਾਬ ਲਈ ਇੱਕ ਟੂਲ ਕਾਲ ਸਮਰਥਿਤ ਹੈ; ਸਮਾਂਤਰ ਕਾਲਾਂ ਨੂੰ ਰੱਦ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।
- ਚਿੱਤਰ ਸਪਸ਼ਟ ਤੌਰ 'ਤੇ ਅਸਮਰਥਿਤ ਹਨ। ਵਿਜ਼ਨ, ਸੋਚ ਆਉਟਪੁੱਟ, ਕੋਸ਼ਿਸ਼ ਨਿਯੰਤਰਣ ਅਤੇ 1M
  ਸੰਦਰਭ ਵਿੰਡੋ ਦਾ ਪ੍ਰਚਾਰ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ।
- SSE ਵੈਧ Anthropic ਜੀਵਨ-ਚੱਕਰ ਇਵੈਂਟ ਵਰਤਦਾ ਹੈ, ਪਰ ਸੀਮਿਤ ACP ਟਰਨ ਇਕੱਤਰ ਕੀਤੇ ਜਾਣ ਤੋਂ ਬਾਅਦ ਹੀ ਨਿਕਾਸ ਕਰਦਾ ਹੈ;
  ACP ਚੰਕਾਂ ਨੂੰ ਕ੍ਰਮਵਾਰ ਢੰਗ ਨਾਲ ਅੱਗੇ ਨਹੀਂ ਭੇਜਿਆ ਜਾਂਦਾ।
