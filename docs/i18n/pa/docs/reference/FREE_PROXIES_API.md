OmniRoute `free_proxies` ਟੇਬਲ ਵਿੱਚ ਮੁਫ਼ਤ ਪ੍ਰਾਕਸੀਆਂ ਦਾ ਚੁਣਿਆ ਹੋਇਆ ਪੂਲ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ,
ਜਿਸਨੂੰ ਬਾਹਰੀ ਪ੍ਰਦਾਤਾਵਾਂ (1proxy, proxifly, iplocate, webshare) ਤੋਂ ਸਿੰਕ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ਡੈਸ਼ਬੋਰਡ
ਇਨ੍ਹਾਂ ਨੂੰ **Settings → Free Proxies** ਹੇਠ ਦਿਖਾਉਂਦਾ ਹੈ। ਇਹ ਦਸਤਾਵੇਜ਼
ਲਿਸਟ ਰੂਟ ਵੱਲੋਂ ਉਪਲਬਧ ਕਰਵਾਈ ਸਰਵਰ-ਸਾਈਡ ਫਿਲਟਰਿੰਗ, ਸੋਰਟਿੰਗ, ਗਿਣਤੀ ਅਤੇ ਸਿੰਕ-ਗਲਤੀ ਰਿਪੋਰਟਿੰਗ
ਨੂੰ ਕਵਰ ਕਰਦਾ ਹੈ।

## ਲਿਸਟ ਰੂਟ — `GET /api/settings/free-proxies`

ਕੁੱਲ ਗਿਣਤੀ ਦੇ ਨਾਲ ਫਿਲਟਰ ਕੀਤਾ, ਸੋਰਟ ਕੀਤਾ ਅਤੇ ਪੰਨਿਆਂ ਵਿੱਚ ਵੰਡਿਆ ਹਿੱਸਾ ਵਾਪਸ ਕਰਦਾ ਹੈ। ਫਿਲਟਰਿੰਗ ਅਤੇ
ਗਿਣਤੀ SQL ਵਿੱਚ ਹੁੰਦੀ ਹੈ, ਤਾਂ ਜੋ UI ਹਰ ਕਤਾਰ ਨੂੰ ਮੈਮੋਰੀ ਵਿੱਚ ਲੋਡ ਕੀਤੇ ਬਿਨਾਂ
ਅਸਲ ਕੁੱਲ ਗਿਣਤੀ (ਉਦਾਹਰਨ ਲਈ `Total: 0`) ਦਿਖਾ ਸਕੇ।

### ਕਵੇਰੀ ਪੈਰਾਮੀਟਰ

| ਪੈਰਾਮੀਟਰ          | ਕਿਸਮ                               | ਡਿਫਾਲਟ    | ਅਰਥ                                                                                                                             |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | ਸਤਰ                                | `""`      | ਹੋਸਟ (ਅਤੇ ਸਰੋਤ) ਕਾਲਮ ਉੱਤੇ ਕੇਸ-ਸੰਵੇਦਨਸ਼ੀਲ `LIKE`।                                                                                |
| `protocol`        | ਸਤਰ                                | `""`      | `type` ਫਿਲਟਰ: `http` / `https` / `socks4` / `socks5`। ਖਾਲੀ = ਸਾਰੇ।                                                              |
| `country`         | ਸਤਰ                                | `""`      | `countryCode` ਫਿਲਟਰ (ISO-2)। ਖਾਲੀ = ਸਾਰੇ।                                                                                       |
| `minQuality`      | ਸੰਖਿਆ                              | `0`       | ਸਿਰਫ਼ `qualityScore >= minQuality` ਵਾਲੀਆਂ ਕਤਾਰਾਂ। `0` = ਕੋਈ ਘੱਟੋ-ਘੱਟ ਸੀਮਾ ਨਹੀਂ।                                                 |
| `disabledSources` | ਸਤਰ                                | `""`      | ਬਾਹਰ ਰੱਖਣ ਲਈ ਕੌਮੇ ਨਾਲ ਵੱਖ ਕੀਤੀਆਂ ਸਰੋਤ id (ਉਦਾਹਰਨ ਲਈ `proxifly,webshare`)।                                                       |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = ਸਕੋਰ ਘਟਦੇ ਕ੍ਰਮ ਵਿੱਚ; `latency` = ਲੇਟੈਂਸੀ ਵਧਦੇ ਕ੍ਰਮ ਵਿੱਚ (null ਅੰਤ ਵਿੱਚ); `recent` = `lastValidated` ਘਟਦੇ ਕ੍ਰਮ ਵਿੱਚ। |
| `offset`          | ਸੰਖਿਆ                              | `0`       | ਪੰਨਾ-ਵੰਡ ਦੀ ਸ਼ੁਰੂਆਤ।                                                                                                            |
| `limit`           | ਸੰਖਿਆ                              | `50`      | ਪੰਨੇ ਦਾ ਆਕਾਰ (ਸਰਵਰ-ਸਾਈਡ ਸੀਮਿਤ)।                                                                                                 |

### ਜਵਾਬ

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` ਪੰਨਾ-ਵੰਡ ਤੋਂ **ਪਹਿਲਾਂ** ਫਿਲਟਰ ਕੀਤੀ ਕੁੱਲ ਗਿਣਤੀ ਦਰਸਾਉਂਦਾ ਹੈ, ਤਾਂ ਜੋ UI
`Total: N` ਅਤੇ `hasMore` ਨੂੰ ਇੱਕ-ਦੂਜੇ ਤੋਂ ਸੁਤੰਤਰ ਤੌਰ 'ਤੇ ਰੈਂਡਰ ਕਰ ਸਕੇ। `syncErrors` ਨੂੰ ਸਰੋਤ id
ਮੁਤਾਬਕ ਕੁੰਜੀਬੱਧ ਕੀਤਾ ਜਾਂਦਾ ਹੈ ਅਤੇ ਇਹ ਸਿਰਫ਼ ਉਨ੍ਹਾਂ ਸਰੋਤਾਂ ਲਈ ਭਰਿਆ ਜਾਂਦਾ ਹੈ ਜਿਨ੍ਹਾਂ ਦਾ ਪਿਛਲਾ ਸਿੰਕ ਅਸਫਲ ਰਿਹਾ ਸੀ — ਇੱਕ
`Total: 0` ਨਤੀਜਾ ਕਦੇ ਵੀ ਬਿਨਾਂ ਜਾਣਕਾਰੀ ਦੇ ਨਹੀਂ ਹੁੰਦਾ।

## ਪੂਲ ਵਿੱਚ ਸ਼ਾਮਲ ਕਰਨਾ — `POST /api/settings/free-proxies/[id]/add-to-pool`

ਇੱਕ ਮੁਫ਼ਤ ਪ੍ਰਾਕਸੀ ਨੂੰ ਪ੍ਰਬੰਧਿਤ `proxy_registry` ਪੂਲ ਵਿੱਚ ਤਰੱਕੀ ਦਿੰਦਾ ਹੈ। ਪਹਿਲਾਂ
ਅੱਪਸਟ੍ਰੀਮ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ; ਸਫਲਤਾ ਉੱਤੇ ਨਵੀਂ ਪੂਲ ਪ੍ਰਾਕਸੀ id ਅਤੇ ਮਾਪੀ ਗਈ ਲੇਟੈਂਸੀ ਵਾਪਸ ਕਰਦਾ ਹੈ।

## ਸਿੰਕ — `POST /api/settings/free-proxies/sync`

ਸਾਰੇ ਸਮਰੱਥ ਸਰੋਤਾਂ (ਜਾਂ `{ "sources": [...] }` ਵਿੱਚ ਦਿੱਤੇ ਉਪ-ਸਮੂਹ) ਨੂੰ ਮੁੜ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ। ਹਰੇਕ
ਸਰੋਤ ਸੁਤੰਤਰ ਤੌਰ 'ਤੇ ਸਿੰਕ ਹੁੰਦਾ ਹੈ; ਅਸਫਲ ਸਰੋਤ ਨੂੰ `syncErrors` ਵਿੱਚ ਦਰਜ ਕੀਤਾ ਜਾਂਦਾ ਹੈ ਅਤੇ
ਬਾਕੀ ਫਿਰ ਵੀ ਪੂਰੇ ਹੋ ਜਾਂਦੇ ਹਨ, ਇਸ ਲਈ ਅੰਸ਼ਕ ਸਿੰਕ ਪਹਿਲਾਂ ਦੇ ਸਹੀ ਡਾਟੇ ਨੂੰ ਕਦੇ ਨਹੀਂ ਮਿਟਾਉਂਦੇ।

## ਅੰਕੜੇ — `GET /api/settings/free-proxies/stats`

ਕਤਾਰ ਪੇਲੋਡ ਤੋਂ ਬਿਨਾਂ `total / inPool / avgQuality / bySource / lastSyncAt` ਸਮੂਹਿਕ ਅੰਕੜੇ
ਵਾਪਸ ਕਰਦਾ ਹੈ — ਇਸਦੀ ਵਰਤੋਂ ਡੈਸ਼ਬੋਰਡ ਹੈਡਰ ਵਿਜਟਾਂ ਵੱਲੋਂ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।
