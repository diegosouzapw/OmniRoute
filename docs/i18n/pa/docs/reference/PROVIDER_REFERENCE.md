ਕੁੱਲ ਪ੍ਰਦਾਤਾ: **360**। ਹੇਠਾਂ ਸ਼੍ਰੇਣੀ ਅਨੁਸਾਰ ਵੰਡ ਦੇਖੋ।

## ਸ਼੍ਰੇਣੀਆਂ

- **ਮੁਫ਼ਤ** — API ਕੁੰਜੀ ਨਾਲ ਮੁਫ਼ਤ ਟੀਅਰ (ਡੈਸ਼ਬੋਰਡ ਰਾਹੀਂ ਸੰਰਚਿਤ)
- **ਬਿਨਾਂ-ਪ੍ਰਮਾਣੀਕਰਨ** — ਜਨਤਕ ਐਂਡਪੌਇੰਟ ਜਿਨ੍ਹਾਂ ਲਈ ਕਿਸੇ ਕੁੰਜੀ ਜਾਂ ਸਾਈਨ-ਇਨ ਦੀ ਬਿਲਕੁਲ ਲੋੜ ਨਹੀਂ
- **OAuth** — ਸਾਈਨ-ਇਨ ਪ੍ਰਵਾਹ OmniRoute ਦੁਆਰਾ ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ, API ਕੁੰਜੀ ਦੀ ਲੋੜ ਨਹੀਂ
- **ਵੈੱਬ ਕੁਕੀ** — ਕੁਕੀ ਪ੍ਰਮਾਣੀਕਰਨ ਰਾਹੀਂ ਪ੍ਰਦਾਤਾ ਦੀ ਵੈੱਬ ਐਪ ਨੂੰ ਰੈਪ ਕਰਦਾ ਹੈ
- **API ਕੁੰਜੀ** — API ਕੁੰਜੀ ਰਾਹੀਂ ਸੰਰਚਿਤ ਭੁਗਤਾਨਯੋਗ ਪ੍ਰਦਾਤਾ (ਮੁਫ਼ਤ ਕ੍ਰੈਡਿਟ ਲਾਗੂ ਹੋ ਸਕਦੇ ਹਨ)
- **ਸਥਾਨਕ** — ਵਰਤੋਂਕਾਰ ਦੀ ਮਸ਼ੀਨ ਉੱਤੇ ਚੱਲਦਾ ਹੈ (Ollama, LM Studio, vLLM ਆਦਿ)
- **ਖੋਜ** — ਵੈੱਬ ਖੋਜ ਪ੍ਰਦਾਤਾ
- **ਆਡੀਓ** — ਸਿਰਫ਼-ਆਡੀਓ ਪ੍ਰਦਾਤਾ (TTS/STT)
- **ਅੱਪਸਟ੍ਰੀਮ ਪ੍ਰੌਕਸੀ** — ਉਹ ਪ੍ਰਦਾਤਾ ਜੋ ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ ਵੱਲ ਪ੍ਰੌਕਸੀ ਕਰਦੇ ਹਨ
- **ਕਲਾਉਡ ਏਜੰਟ** — ਲੰਮੇ ਸਮੇਂ ਤੱਕ ਚੱਲਣ ਵਾਲੇ ਕੋਡਿੰਗ ਏਜੰਟ (Codex Cloud, Devin, Jules)
- **ਸਿਸਟਮ** — OmniRoute ਦੇ ਅੰਦਰੂਨੀ ਪ੍ਰਦਾਤਾ (ਲੂਪਬੈਕ ਆਦਿ)

ਵਾਧੂ ਟੈਗ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`।

`ਟੂਲ ਕਾਲਿੰਗ` (ਜਿੱਥੇ ਦਿਖਾਈ ਗਈ ਹੈ): `native` — ਅਸਲ ਫੰਕਸ਼ਨ-ਕਾਲਿੰਗ API; `emulated` — `tools` ਐਰੇ ਨੂੰ `webTools.ts` ਰਾਹੀਂ ਪ੍ਰੌਂਪਟ ਵਿੱਚ ਅਨੁਕਰਿਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (regex ਨਾਲ ਪਾਰਸ ਕੀਤੇ `<tool>{...}</tool>` ਬਲਾਕ); `none` — ਇਸ ਵੇਲੇ `tools` ਨੂੰ ਬਿਨਾਂ ਕਿਸੇ ਸੂਚਨਾ ਦੇ ਹਟਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ। #7286 ਦੇਖੋ।

ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਨੂੰ ਸਮਰੱਥ, ਸੰਰਚਿਤ ਅਤੇ ਟੈਸਟ ਕਰਨ ਲਈ `/dashboard/providers` ਉੱਤੇ ਡੈਸ਼ਬੋਰਡ ਦੀ ਵਰਤੋਂ ਕਰੋ।
