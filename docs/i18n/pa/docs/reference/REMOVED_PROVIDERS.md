ਕੁਝ ਸੇਵਾਵਾਂ ਨੂੰ OmniRoute ਵਿੱਚ ਏਕੀਕ੍ਰਿਤ ਕੀਤਾ ਗਿਆ ਸੀ ਅਤੇ ਬਾਅਦ ਵਿੱਚ ਹਟਾ ਦਿੱਤਾ ਗਿਆ, ਕਿਉਂਕਿ ਉਹਨਾਂ ਨੂੰ ਚਲਾਉਣ ਵਾਲੇ
ਲੋਕਾਂ ਨੇ ਅਜਿਹਾ ਕਰਨ ਲਈ ਕਿਹਾ ਸੀ। ਇਹ ਪੰਨਾ ਉਹਨਾਂ ਹਟਾਉਣਾਂ ਦਾ ਸਥਾਈ ਰਿਕਾਰਡ ਹੈ। ਇਸਦਾ ਇੱਕੋ-ਇੱਕ ਉਦੇਸ਼
ਉਹਨਾਂ ਨੂੰ ਗਲਤੀ ਨਾਲ ਮੁੜ ਸ਼ਾਮਲ ਹੋਣ ਤੋਂ ਰੋਕਣਾ ਹੈ: ਕਿਸੇ ਪੁਰਾਣੇ ਫੋਰਕ, ਕੈਸ਼ ਕੀਤੀ npm
ਟਾਰਬਾਲ, ਆਰਕਾਈਵ ਕੀਤੇ ਮੁੱਦੇ ਜਾਂ "ਪ੍ਰਦਾਤਾ X ਨੂੰ ਬਹਾਲ ਕਰੋ" ਬੇਨਤੀ ਲੱਭਣ ਵਾਲੇ ਯੋਗਦਾਨਕਰਤਾ ਨੂੰ ਇੱਕ ਅਜਿਹੀ ਥਾਂ ਚਾਹੀਦੀ ਹੈ ਜੋ ਕਹੇ **ਮੁੜ
ਸ਼ਾਮਲ ਨਾ ਕਰੋ**।

ਇਹ ਪੰਨਾ ਬੰਦ ਹੋ ਚੁੱਕੀਆਂ ਜਾਂ ਰੱਦ ਕੀਤੀਆਂ ਸੇਵਾਵਾਂ ਦੀ ਸੂਚੀ **ਨਹੀਂ** ਹੈ। ਉਹਨਾਂ ਨੂੰ
[`FREE_TIERS.md`](FREE_TIERS.md) ("ਹਟਾਈਆਂ ਗਈਆਂ / ਕੋਈ ਮੁਫ਼ਤ ਟੀਅਰ ਨਹੀਂ") ਵਿੱਚ ਟਰੈਕ ਕੀਤਾ ਜਾਂਦਾ ਹੈ ਅਤੇ ਜੇ ਸੇਵਾ
ਵਾਪਸ ਆਉਂਦੀ ਹੈ ਤਾਂ ਉਹ ਵੀ ਵਾਪਸ ਆ ਸਕਦੀਆਂ ਹਨ। ਹੇਠਾਂ ਦਿੱਤੀਆਂ ਐਂਟਰੀਆਂ ਸਿਰਫ਼ ਬੇਨਤੀ ਵਿੱਚ ਦਰਜ ਓਪਰੇਟਰ ਦੀ ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਨਾਲ ਹੀ
ਵਾਪਸ ਆ ਸਕਦੀਆਂ ਹਨ, ਅਤੇ ਉਸ ਇਜਾਜ਼ਤ ਦਾ ਲਿੰਕ ਐਂਟਰੀ ਵਿੱਚ ਦਿੱਤਾ ਜਾਣਾ ਲਾਜ਼ਮੀ ਹੈ।

## ਨੀਤੀ

1. **ਸੇਵਾ ਓਪਰੇਟਰ ਵੱਲੋਂ ਹਟਾਉਣ ਦੀ ਬੇਨਤੀ ਦਾ ਸਨਮਾਨ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਉਸ ਬਾਰੇ ਗੱਲਬਾਤ ਨਹੀਂ ਕੀਤੀ ਜਾਂਦੀ।** OmniRoute ਦਾ
   ਕਿਸੇ ਵੀ ਅੱਪਸਟ੍ਰੀਮ ਸੇਵਾ ਨਾਲ ਕੋਈ ਸਬੰਧ ਨਹੀਂ ਹੈ। ਜਦੋਂ ਕਿਸੇ ਸੇਵਾ ਦਾ ਓਪਰੇਟਰ
   ਏਕੀਕਰਨ ਨੂੰ ਹਟਾਉਣ ਲਈ ਕਹਿੰਦਾ ਹੈ, ਤਾਂ ਉਹ ਹਟਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ, ਭਾਵੇਂ ਏਕੀਕਰਨ ਨੇ ਅਧਿਕਾਰਤ API ਵਰਤੀ ਹੋਵੇ ਜਾਂ ਨਾ।
2. **"ਹਟਾਇਆ ਗਿਆ" ਦਾ ਅਰਥ OmniRoute ਦੇ ਨਿਯੰਤਰਣ ਹੇਠਲਾ ਹਰ ਹਿੱਸਾ ਹੈ।** ਐਗਜ਼ੀਕਿਊਟਰ, ਰਜਿਸਟਰੀ ਐਂਟਰੀ, ਪ੍ਰਦਾਤਾ
   id ਅਤੇ ਉਪਨਾਮ, ਮਾਡਲ ਸੂਚੀ, ਐਂਡਪੌਇੰਟ, ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ, ਆਈਕਨ, ਡੈਸ਼ਬੋਰਡ ਕਾਰਡ,
   ਤਿਆਰ ਕੀਤਾ ਪ੍ਰਦਾਤਾ ਹਵਾਲਾ, `FREE_TIERS.md`, ਵਾਤਾਵਰਣ ਹਵਾਲਾ, README ਗਿਣਤੀਆਂ,
   `llm.txt` ਮਿਰਰ, ਸਮਰਪਿਤ ਟੈਸਟ ਅਤੇ ਗੋਲਡਨ ਸਨੈਪਸ਼ਾਟ, ਕੋਡ ਟਿੱਪਣੀਆਂ, CHANGELOG ਬੁਲੇਟ
   (ਲੇਜਰ ਵਿੱਚ ਦਰਜ ਮਿਲਾਨ ਸਮੇਤ, `config/release/changelog-reconciliations.json` ਵੇਖੋ),
   GitHub Releases ਨੋਟਸ, ਵਿਕੀ, ਅਤੇ ਉਹ GitHub ਮੁੱਦੇ, ਚਰਚਾਵਾਂ ਅਤੇ ਪੁੱਲ ਬੇਨਤੀਆਂ ਜਿਨ੍ਹਾਂ ਦਾ
   ਵਿਸ਼ਾ ਉਹ ਪ੍ਰਦਾਤਾ ਸੀ (ਮੁੱਦੇ ਅਤੇ ਚਰਚਾਵਾਂ ਮਿਟਾਈਆਂ ਜਾਂਦੀਆਂ ਹਨ; ਪੁੱਲ ਬੇਨਤੀਆਂ ਦਾ ਸਿਰਲੇਖ ਬਦਲਿਆ ਜਾਂਦਾ ਹੈ, ਉਹਨਾਂ ਦਾ
   ਵੇਰਵਾ ਤਬਦੀਲ ਕੀਤਾ ਜਾਂਦਾ ਹੈ ਅਤੇ ਥ੍ਰੈੱਡ ਲੌਕ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਕਿਉਂਕਿ GitHub ਪੁੱਲ ਬੇਨਤੀਆਂ ਨੂੰ ਮਿਟਾ ਨਹੀਂ ਸਕਦਾ)।
3. **ਲਿਖਤੀ ਇਜਾਜ਼ਤ ਤੋਂ ਬਿਨਾਂ ਇਸ ਪੰਨੇ ਦੀ ਕਿਸੇ ਐਂਟਰੀ ਨੂੰ ਕਦੇ ਵੀ ਮੁੜ ਸ਼ਾਮਲ ਨਾ ਕਰੋ।** ਇਸ ਵਿੱਚ
   ਕਿਸੇ ਵੀ ਪ੍ਰਦਾਤਾ ਕੈਟਾਲਾਗ ਵਿੱਚ id ਜਾਂ ਉਪਨਾਮ ਨੂੰ ਮੁੜ ਸ਼ਾਮਲ ਕਰਨਾ, ਡੋਮੇਨਾਂ ਨੂੰ ਕਿਸੇ ਐਗਜ਼ੀਕਿਊਟਰ ਵਿੱਚ ਜੋੜਨਾ,
   ਉਸਨੂੰ "ਬਹਾਲ" ਕਰਨ ਵਾਲੀ ਯੋਗਦਾਨਕਰਤਾ PR ਨੂੰ ਸਵੀਕਾਰ ਕਰਨਾ, ਉਸਨੂੰ ਮੁਫ਼ਤ-ਮਾਡਲ ਕੈਟਾਲਾਗ ਵਿੱਚ ਸ਼ਾਮਲ ਕਰਨਾ, ਜਾਂ
   OmniRoute ਰਾਹੀਂ ਉਸ ਤੱਕ ਪਹੁੰਚਣ ਦਾ ਦਸਤੀ ਤਰੀਕਾ ਦਸਤਾਵੇਜ਼ਬੱਧ ਕਰਨਾ ਸ਼ਾਮਲ ਹੈ। ਅਜਿਹੀਆਂ PRs ਅਤੇ ਮੁੱਦਿਆਂ ਨੂੰ ਇਸ
   ਪੰਨੇ ਦੇ ਲਿੰਕ ਨਾਲ ਬੰਦ ਕਰੋ।
4. **ਐਂਟਰੀ ਨੂੰ ਘੱਟੋ-ਘੱਟ ਰੱਖੋ।** ਸਿਰਫ਼ ਉਹ ਜਾਣਕਾਰੀ ਦਰਜ ਕਰੋ ਜਿਸਦੀ ਸਮੀਖਿਅਕ ਨੂੰ ਮੁੜ
   ਸ਼ਾਮਲ ਕੀਤੀ ਐਂਟਰੀ ਪਛਾਣਨ ਲਈ ਲੋੜ ਹੈ: ਪਛਾਣਕਰਤਾ, ਡੋਮੇਨ, ਤਾਰੀਖਾਂ ਅਤੇ ਹਟਾਉਣ ਵਾਲੀ ਪੁੱਲ ਬੇਨਤੀ।
   ਏਕੀਕਰਨ ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਸੀ, ਇਸਦਾ ਵਰਣਨ ਨਾ ਕਰੋ।
5. **ਰਿਗ੍ਰੈਸ਼ਨ ਗਾਰਡ `tests/unit/removed-providers-blocklist.test.ts` ਹੈ।** ਜਦੋਂ
   ਹੇਠਾਂ ਦਿੱਤਾ ਕੋਈ ਪਛਾਣਕਰਤਾ ਜਾਂ ਡੋਮੇਨ ਪ੍ਰਦਾਤਾ ਕੈਟਾਲਾਗਾਂ, ਐਗਜ਼ੀਕਿਊਟਰ ਮੈਪ ਜਾਂ
   ਪ੍ਰਦਾਤਾ ਰਜਿਸਟਰੀ ਸਰੋਤਾਂ ਵਿੱਚ ਮੁੜ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ, ਤਾਂ ਇਹ ਅਸਫਲ ਹੋ ਜਾਂਦਾ ਹੈ। ਨਵੇਂ ਪਛਾਣਕਰਤਾਵਾਂ ਨੂੰ ਉਸੇ PR ਵਿੱਚ ਉਸ ਟੈਸਟ ਵਿੱਚ ਸ਼ਾਮਲ ਕਰੋ
   ਜਿਸ ਵਿੱਚ ਇੱਥੇ ਇੱਕ ਕਤਾਰ ਸ਼ਾਮਲ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

## ਐਂਟਰੀ ਸ਼ਾਮਲ ਕਰਨਾ

ਜਦੋਂ ਹਟਾਉਣ ਦੀ ਨਵੀਂ ਬੇਨਤੀ ਆਉਂਦੀ ਹੈ:

1. ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਬੇਨਤੀ ਸੇਵਾ ਦੇ ਓਪਰੇਟਰ ਵੱਲੋਂ ਆਈ ਹੈ (ਉਹਨਾਂ ਦਾ ਸਹਾਇਤਾ ਪਤਾ ਜਾਂ ਉਹਨਾਂ ਦੇ
   ਨਿਯੰਤਰਣ ਹੇਠਲਾ ਡੋਮੇਨ), ਅਤੇ ਸੁਨੇਹੇ ਨੂੰ ਨਿੱਜੀ ਤੌਰ 'ਤੇ ਸੰਭਾਲ ਕੇ ਰੱਖੋ।
2. ਨੀਤੀ ਦੀ ਮਦ 2 ਵਿੱਚ ਦਿੱਤੀ ਚੈੱਕਲਿਸਟ ਦੀ ਪਾਲਣਾ ਕਰਦੇ ਹੋਏ ਏਕੀਕਰਨ ਨੂੰ ਹਟਾਓ।
   ਕੁੰਜੀ-ਰਹਿਤ ਪ੍ਰਦਾਤਾ ਲਈ [#12440](https://github.com/diegosouzapw/OmniRoute/pull/12440) ਨੂੰ ਹਵਾਲੇ ਵਜੋਂ ਅਤੇ
   ਸੰਭਾਲੇ ਹੋਏ ਕਨੈਕਸ਼ਨਾਂ ਵਾਲੇ API-ਕੁੰਜੀ ਪ੍ਰਦਾਤਾ ਲਈ [#10210](https://github.com/diegosouzapw/OmniRoute/pull/10210) ਨੂੰ ਵਰਤੋ
   (ਇੱਕ ਮਾਈਗ੍ਰੇਸ਼ਨ ਸ਼ਾਮਲ ਕਰੋ)।
