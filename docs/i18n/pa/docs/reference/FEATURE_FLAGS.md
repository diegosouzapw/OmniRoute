> ਰਨਟਾਈਮ ਟੌਗਲ ਜੋ OmniRoute ਦੇ ਵਿਹਾਰ ਨੂੰ **ਮੁੜ ਡਿਪਲੌਇ ਕੀਤੇ ਬਿਨਾਂ** ਬਦਲਦੇ ਹਨ।
> ਇੱਥੇ ਸੂਚੀਬੱਧ ਹਰ ਫਲੈਗ ਨੂੰ
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> ਵਿੱਚ ਪਰਿਭਾਸ਼ਿਤ ਕੀਤਾ ਗਿਆ ਹੈ — ਇਹ ਸੱਚਾਈ ਦਾ ਇਕਮਾਤਰ ਸਰੋਤ ਹੈ। ਡੈਸ਼ਬੋਰਡ ਅਤੇ REST API ਦੋਵੇਂ
> ਉਸ ਫ਼ਾਈਲ ਤੋਂ ਪੜ੍ਹਦੇ ਹਨ, ਇਸ ਲਈ ਹੇਠਾਂ ਦਿੱਤੀ ਸਾਰਣੀ ਇਸ ਨਾਲ 1:1 ਮੇਲ ਖਾਣ ਲਈ ਤਿਆਰ ਕੀਤੀ ਗਈ ਹੈ।

## ਫੀਚਰ ਫਲੈਗ ਕੀ ਹਨ

ਫੀਚਰ ਫਲੈਗ ਇੱਕ ਨਾਮਿਤ ਟੌਗਲ (ਬੂਲੀਅਨ ਜਾਂ enum) ਹੁੰਦਾ ਹੈ, ਜਿਸਦਾ ਮੁੱਲ
ਰਨਟਾਈਮ ਦੌਰਾਨ ਬਦਲਿਆ ਅਤੇ ਡੇਟਾਬੇਸ ਵਿੱਚ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸੰਭਾਲਿਆ ਜਾ ਸਕਦਾ ਹੈ, ਅਤੇ ਇਸ ਲਈ ਪ੍ਰਕਿਰਿਆ ਨੂੰ ਮੁੜ ਡਿਪਲੌਇ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੁੰਦੀ। ਹਰੇਕ
ਫਲੈਗ ਨੂੰ ਇੱਕ `FeatureFlagDefinition` ਰਾਹੀਂ ਵਰਣਿਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਜਿਸ ਵਿੱਚ `key`, `label`,
`description`, `category`, `defaultValue`, `type`, ਅਤੇ `requiresRestart` ਸੰਕੇਤ ਹੁੰਦਾ ਹੈ।

### ਰਿਜ਼ੋਲਿਊਸ਼ਨ ਕ੍ਰਮ

ਕਿਸੇ ਫਲੈਗ ਦਾ **ਪ੍ਰਭਾਵੀ ਮੁੱਲ**
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ਰਾਹੀਂ ਹੇਠਾਂ ਦਿੱਤੀ
ਤਰਜੀਹ ਅਨੁਸਾਰ ਨਿਰਧਾਰਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ (ਸਭ ਤੋਂ ਉੱਚੀ ਤਰਜੀਹ ਜਿੱਤਦੀ ਹੈ):

1. **DB ਓਵਰਰਾਈਡ** — `feature_flags` ਨੇਮਸਪੇਸ ਅਧੀਨ `key_value` ਸਾਰਣੀ ਵਿੱਚ ਸੰਭਾਲਿਆ
   ਗਿਆ ਮੁੱਲ (ਡੈਸ਼ਬੋਰਡ ਜਾਂ REST API ਰਾਹੀਂ ਸੈੱਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ)।
2. **ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ** — `process.env[<KEY>]`, ਜੇ ਇਹ ਸੈੱਟ ਅਤੇ ਗੈਰ-ਖਾਲੀ ਹੋਵੇ।
3. **ਪਰਿਭਾਸ਼ਾ ਦਾ ਡਿਫਾਲਟ** — `featureFlagDefinitions.ts` ਵਿਚਲਾ `defaultValue`।

ਕਿਸੇ ਬੂਲੀਅਨ ਫਲੈਗ ਨੂੰ **ਸਮਰੱਥ** ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ ਜਦੋਂ ਇਸਦਾ ਪ੍ਰਭਾਵੀ ਮੁੱਲ `"true"`,
`"1"`, ਜਾਂ `"yes"` ਹੋਵੇ (`isFeatureFlagEnabled()` ਵੇਖੋ)।

> [!NOTE]
> ਜ਼ਿਆਦਾਤਰ ਫਲੈਗਾਂ ਦਾ **ਇਸੇ ਨਾਮ** ਵਾਲਾ ਇੱਕ ਸੰਬੰਧਿਤ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਵੀ ਹੁੰਦਾ ਹੈ,
> ਜਿਸਦਾ ਦਸਤਾਵੇਜ਼ੀਕਰਨ [`ENVIRONMENT.md`](./ENVIRONMENT.md) ਵਿੱਚ ਕੀਤਾ ਗਿਆ ਹੈ। ਫਲੈਗ ਦਾ DB ਓਵਰਰਾਈਡ
> ਉਸ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਨਾਲੋਂ ਤਰਜੀਹ ਲੈਂਦਾ ਹੈ। `requiresRestart: true` ਵਾਲਾ ਫਲੈਗ
> ਤੁਰੰਤ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ, ਪਰ ਇਸਨੂੰ ਪ੍ਰਕਿਰਿਆ ਸ਼ੁਰੂ ਹੋਣ ਸਮੇਂ ਹੀ ਦੁਬਾਰਾ ਪੜ੍ਹਿਆ ਜਾਂਦਾ ਹੈ —
> ਇਸਨੂੰ ਟੌਗਲ ਕਰਨ ਨਾਲ ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ **"ਸਰਵਰ ਮੁੜ ਚਾਲੂ ਕਰੋ"** ਬੈਨਰ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।

## ਫਲੈਗਾਂ ਨੂੰ ਟੌਗਲ ਕਰਨਾ

### ਡੈਸ਼ਬੋਰਡ

**Dashboard → Settings → Feature Flags**
(`/dashboard/settings/feature-flags`) 'ਤੇ ਜਾਓ। ਗ੍ਰਿੱਡ
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
ਇਨ੍ਹਾਂ ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ:

- ਕੁੰਜੀ ਜਾਂ ਵੇਰਵੇ ਅਨੁਸਾਰ **ਖੋਜ**, ਅਤੇ ਸ਼੍ਰੇਣੀ ਅਨੁਸਾਰ **ਫਿਲਟਰ** (ਇਸ ਤੋਂ ਇਲਾਵਾ ਇੱਕ ਸਿੰਥੈਟਿਕ
  **Requires Restart** ਦ੍ਰਿਸ਼)।
- ਬੂਲੀਅਨ ਫਲੈਗਾਂ ਲਈ ਇੱਕ **ਟੌਗਲ** ਅਤੇ enum ਫਲੈਗਾਂ ਲਈ ਇੱਕ **ਡ੍ਰੌਪਡਾਊਨ**
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`)।
- ਹਰ ਫਲੈਗ ਲਈ ਇੱਕ **ਸਰੋਤ ਬੈਜ** — `DB`, `ENV`, ਜਾਂ `DEF` — ਜੋ ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ
  ਪ੍ਰਭਾਵੀ ਮੁੱਲ ਕਿੱਥੋਂ ਆਇਆ ਹੈ।
- ਓਵਰਰਾਈਡ ਹਟਾਉਣ ਲਈ ਇੱਕ **Reset** ਬਟਨ (ਕੇਵਲ `DB`-ਸਰੋਤ ਵਾਲੇ ਫਲੈਗਾਂ ਲਈ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ),
  ਅਤੇ ਹੇਠਾਂ ਇੱਕ **Reset All Overrides** ਬਟਨ।
- ਜਦੋਂ ਕੋਈ `requiresRestart` ਫਲੈਗ ਬਦਲਿਆ ਜਾਂਦਾ ਹੈ ਤਾਂ ਇੱਕ **Restart Server** ਬੈਨਰ।

### REST API

ਸਾਰੀਆਂ ਕਾਰਵਾਈਆਂ ਇੱਕੋ ਰੂਟ ਰਾਹੀਂ ਹੁੰਦੀਆਂ ਹਨ:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts)।
ਹਰੇਕ ਵਿਧੀ ਲਈ ਪ੍ਰਮਾਣਿਤ ਡੈਸ਼ਬੋਰਡ ਸੈਸ਼ਨ ਲੋੜੀਂਦਾ ਹੈ (ਨਹੀਂ ਤਾਂ `401`)।

#### `GET /api/settings/feature-flags`

ਹਰੇਕ ਫਲੈਗ ਨੂੰ ਉਸਦੇ ਪ੍ਰਭਾਵੀ ਮੁੱਲ, ਸਰੋਤ ਅਤੇ ਸੰਖੇਪ ਸਮੇਤ ਵਾਪਸ ਕਰਦਾ ਹੈ।

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... ਸਾਰੇ 75 ਫਲੈਗ
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

ਇੱਕ ਓਵਰਰਾਈਡ ਸੈੱਟ ਕਰੋ ਜਾਂ ਹਟਾਓ। ਬੌਡੀ: `{ key: string; value?: string }`।
`value` ਨੂੰ ਛੱਡਣ ਨਾਲ ਓਵਰਰਾਈਡ ਹਟ ਜਾਂਦਾ ਹੈ (env / ਡਿਫੌਲਟ ਨੂੰ ਮੁੜ-ਬਹਾਲ ਕਰਦੇ ਹੋਏ)।

```bash
# ਇੱਕ DB ਓਵਰਰਾਈਡ ਸੈੱਟ ਕਰੋ
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# ਓਵਰਰਾਈਡ ਹਟਾਓ (ਕੋਈ "value" ਨਹੀਂ)
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

ਜਵਾਬ ਨਵੇਂ `effectiveValue`/`source`, `previousValue`/
`previousSource`, ਅਤੇ `requiresRestart` ਨੂੰ ਵਾਪਸ ਭੇਜਦਾ ਹੈ। ਅਣਜਾਣ ਕੁੰਜੀਆਂ ਅਤੇ ਸੀਮਾ ਤੋਂ ਬਾਹਰ ਦੇ enum
ਮੁੱਲ `400` ਨਾਲ ਰੱਦ ਕਰ ਦਿੱਤੇ ਜਾਂਦੇ ਹਨ।

#### `DELETE /api/settings/feature-flags`

ਸਾਰੇ DB ਓਵਰਰਾਈਡਾਂ ਨੂੰ ਇੱਕੋ ਵਾਰ ਸਾਫ਼ ਕਰਦਾ ਹੈ, ਅਤੇ ਹਰੇਕ ਫਲੈਗ ਨੂੰ ਉਸਦੇ env / ਡਿਫੌਲਟ
ਮੁੱਲ 'ਤੇ ਮੁੜ-ਬਹਾਲ ਕਰਦਾ ਹੈ। `{ cleared: <count>, message: "..." }` ਵਾਪਸ ਕਰਦਾ ਹੈ।

> [!NOTE]
> `requiresRestart: true` ਵਾਲੇ ਫਲੈਗ ਕੇਵਲ ਪ੍ਰਕਿਰਿਆ ਨੂੰ ਮੁੜ ਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ ਹੀ ਪ੍ਰਭਾਵੀ ਹੁੰਦੇ ਹਨ।
> ਡੈਸ਼ਬੋਰਡ ਦਾ ਰੀਸਟਾਰਟ ਫ਼ਲੋ `POST /api/restart` ਨੂੰ ਕਾਲ ਕਰਦਾ ਹੈ ਅਤੇ ਫਿਰ ਸਰਵਰ ਦੇ ਮੁੜ ਚਾਲੂ ਹੋਣ ਤੱਕ
> `GET /api/health/ping` ਨੂੰ ਪੋਲ ਕਰਦਾ ਹੈ।
