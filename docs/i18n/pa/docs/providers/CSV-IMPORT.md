Dashboard → Providers → **ਫ਼ਾਈਲ ਤੋਂ ਇੰਪੋਰਟ ਕਰੋ** CSV ਜਾਂ JSON ਸੂਚੀ ਤੋਂ API-key ਕਨੈਕਸ਼ਨ ਬਣਾਉਂਦਾ ਹੈ। ਹਰ ਕਤਾਰ ਕਿਸੇ ਵੱਖਰੇ ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਨਿਸ਼ਾਨਾ ਬਣਾ ਸਕਦੀ ਹੈ। ਅੰਸ਼ਕ ਅਸਫਲਤਾ ਇਸਦਾ ਨਿਰਧਾਰਤ ਵਿਹਾਰ ਹੈ: ਜਦੋਂ ਕੁਝ ਕਤਾਰਾਂ ਅਸਫਲ ਹੁੰਦੀਆਂ ਹਨ, ਤਾਂ ਵੀ ਵੈਧ ਕਤਾਰਾਂ ਇੰਪੋਰਟ ਹੋ ਜਾਂਦੀਆਂ ਹਨ, ਅਤੇ ਮੋਡਲ ਦੱਸਦਾ ਹੈ ਕਿ ਅਸਫਲ ਕਤਾਰਾਂ ਨੂੰ ਕਿਉਂ ਰੱਦ ਕੀਤਾ ਗਿਆ ਸੀ।

ਇਹ ਇੰਪੋਰਟ ਨਵੇਂ OpenAI/Anthropic-ਅਨੁਕੂਲ ਐਂਡਪੌਇੰਟ ਨੋਡ **ਨਹੀਂ** ਬਣਾਉਂਦਾ। ਪਹਿਲਾਂ ਉਹਨਾਂ ਨੂੰ ਬਣਾਓ (Dashboard → Providers → OpenAI-Compatible ਸ਼ਾਮਲ ਕਰੋ, ਜਾਂ `omniroute nodes add`), ਫਿਰ ਉਹ ਕਤਾਰਾਂ ਇੰਪੋਰਟ ਕਰੋ ਜਿਨ੍ਹਾਂ ਦਾ `provider` ਕਾਲਮ ਉਸ ਨੋਡ ਦੀ id ਹੈ। ਹਰ ਕਤਾਰ ਲਈ ਦਿੱਤਾ `baseUrl` ਫਿਰ ਵੀ ਨੋਡ ਦੇ URL ਨੂੰ ਓਵਰਰਾਈਡ ਕਰ ਸਕਦਾ ਹੈ।

## CSV (ਸਥਿਤੀ-ਆਧਾਰਿਤ)

ਕਾਲਮਾਂ ਦੇ ਨਾਮ ਸਿਰਫ਼ ਦਿਖਾਵੇ ਲਈ ਹਨ। ਪਾਰਸਰ ਹਰ ਕਤਾਰ ਨੂੰ ਵੰਡਦਾ ਹੈ ਅਤੇ ਇੰਡੈਕਸ ਦੇ ਅਧਾਰ 'ਤੇ ਉਸਦੀ ਡੀਸਟਰੱਕਚਰਿੰਗ ਕਰਦਾ ਹੈ:

| ਇੰਡੈਕਸ | ਫ਼ੀਲਡ      | ਲੋੜੀਂਦਾ | ਨੋਟ                                                                                                                          |
| ------ | ---------- | ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 0      | `provider` | ਹਾਂ     | ਮੌਜੂਦਾ ਪ੍ਰਬੰਧਿਤ ਪ੍ਰੋਵਾਈਡਰ id (`openai`, `anthropic`, …) **ਜਾਂ** ਪਹਿਲਾਂ ਤੋਂ ਰਜਿਸਟਰ ਕੀਤੇ OpenAI/Anthropic-ਅਨੁਕੂਲ **ਨੋਡ** ਦੀ id |
| 1      | `name`     | ਹਾਂ     | ਕਨੈਕਸ਼ਨ ਦਾ ਪ੍ਰਦਰਸ਼ਿਤ ਨਾਮ                                                                                                     |
| 2      | `apiKey`   | ਹਾਂ     | API key                                                                                                                      |
| 3      | `baseUrl`  | ਨਹੀਂ    | ਹਰ ਕਤਾਰ ਲਈ URL ਓਵਰਰਾਈਡ                                                                                                       |
| 4      | `priority` | ਨਹੀਂ    | 1–100 ਦੇ ਵਿਚਕਾਰ ਪੂਰਨ ਅੰਕ                                                                                                     |

ਜਿਸ ਪਹਿਲੀ ਲਾਈਨ ਦੇ ਪਹਿਲੇ ਕਾਲਮ ਵਿੱਚ ਅੱਖਰਾਂ ਦੇ ਕੇਸ ਦੀ ਪਰਵਾਹ ਕੀਤੇ ਬਿਨਾਂ ਸ਼ਾਬਦਿਕ ਸ਼ਬਦ `provider` ਹੋਵੇ, ਉਸਨੂੰ ਹੈਡਰ ਮੰਨ ਕੇ ਛੱਡ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ। ਖਾਲੀ ਲਾਈਨਾਂ ਅਤੇ `#` ਟਿੱਪਣੀਆਂ ਨੂੰ ਵੀ ਛੱਡ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।

ਇੰਪੋਰਟ ਮੋਡਲ ਤੋਂ ਇੱਕ ਸ਼ੁਰੂਆਤੀ ਫ਼ਾਈਲ ਡਾਊਨਲੋਡ ਕਰੋ (**CSV ਟੈਂਪਲੇਟ ਡਾਊਨਲੋਡ ਕਰੋ**)। ਉਦਾਹਰਨ:

```csv
# OmniRoute ਪ੍ਰੋਵਾਈਡਰ ਇੰਪੋਰਟ (ਸਥਿਤੀ-ਆਧਾਰਿਤ ਕਾਲਮ)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

`openai-compatible-chat-001` ਵਰਗੀ ਮਨਘੜਤ id ਕੋਈ ਨੋਡ ਨਹੀਂ ਹੈ। ਉਸ ਕਤਾਰ ਲਈ API `Unknown or unsupported provider` ਵਾਪਸ ਕਰਦਾ ਹੈ; ਮੋਡਲ ਇਸਨੂੰ ਕਤਾਰ ਦੇ ਨਾਮ ਦੇ ਨਾਲ ਦਿਖਾਉਂਦਾ ਹੈ।

## JSON

ਉਹੀ ਫ਼ੀਲਡਾਂ (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`) ਵਾਲੇ ਆਬਜੈਕਟਾਂ ਦੀ ਇੱਕ JSON ਐਰੇ। CSV ਦੇ ਉਲਟ, JSON keys ਨਾਮਿਤ ਹੁੰਦੀਆਂ ਹਨ।

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
