ਜਦੋਂ OmniRoute Docker ਦੇ ਅੰਦਰ ਚੱਲਦਾ ਹੈ, ਤਾਂ ਮਿਆਰੀ "Zed Keychain ਤੋਂ ਇੰਪੋਰਟ ਕਰੋ" ਪ੍ਰਕਿਰਿਆ ਅਸਫਲ ਹੋ ਜਾਂਦੀ ਹੈ
ਕਿਉਂਕਿ ਕੰਟੇਨਰ ਹੋਸਟ OS ਕੀਚੇਨ ਡੀਮਨ (Linux ਉੱਤੇ libsecret,
macOS ਉੱਤੇ Keychain, Windows ਉੱਤੇ Credential Manager) ਤੱਕ ਨਹੀਂ ਪਹੁੰਚ ਸਕਦਾ ਅਤੇ ਹੋਸਟ ਫ਼ਾਈਲਸਿਸਟਮ ਉੱਤੇ
Zed ਸੰਰਚਨਾ ਡਾਇਰੈਕਟਰੀਆਂ ਮੂਲ ਰੂਪ ਵਿੱਚ ਕੰਟੇਨਰ ਦੇ ਅੰਦਰ ਦਿਖਾਈ ਨਹੀਂ ਦਿੰਦੀਆਂ।

## Docker ਵਿੱਚ Keychain ਇੰਪੋਰਟ ਕਿਉਂ ਅਸਫਲ ਹੁੰਦਾ ਹੈ

ਕੰਟੇਨਰ ਦੇ ਅੰਦਰ ਦੋ ਰੁਕਾਵਟੀ ਸਮੱਸਿਆਵਾਂ ਆਉਂਦੀਆਂ ਹਨ:

1. **ਫ਼ਾਈਲਸਿਸਟਮ ਅਲੱਗਾਵ** — `isZedInstalled()` `~/.config/zed` (Linux),
   `~/Library/Application Support/Zed` (macOS), ਜਾਂ Windows ਦੇ ਸਮਾਨ ਪਾਥ ਨੂੰ ਲੱਭਦਾ ਹੈ। ਇਹ ਪਾਥ
   ਹੋਸਟ ਉੱਤੇ ਮੌਜੂਦ ਹੁੰਦੇ ਹਨ ਅਤੇ ਉਦੋਂ ਤੱਕ ਉਪਲਬਧ ਨਹੀਂ ਹੁੰਦੇ ਜਦੋਂ ਤੱਕ ਇਨ੍ਹਾਂ ਨੂੰ ਸਪਸ਼ਟ ਤੌਰ 'ਤੇ ਵਾਲਿਊਮ ਵਜੋਂ ਮਾਊਂਟ ਨਾ ਕੀਤਾ ਜਾਵੇ।
2. **IPC ਅਲੱਗਾਵ** — ਭਾਵੇਂ ਸੰਰਚਨਾ ਡਾਇਰੈਕਟਰੀ ਮਾਊਂਟ ਕੀਤੀ ਹੋਵੇ, `keytar` ਨੇਟਿਵ
   ਮੋਡੀਊਲ Unix ਸਾਕਟ ਜਾਂ D-Bus ਸੈਸ਼ਨ ਰਾਹੀਂ OS ਕੀਚੇਨ ਸੇਵਾ ਨਾਲ ਸੰਚਾਰ ਕਰਦਾ ਹੈ।
   ਮੂਲ ਰੂਪ ਵਿੱਚ ਇਨ੍ਹਾਂ ਵਿੱਚੋਂ ਕੋਈ ਵੀ ਕੰਟੇਨਰ ਨਾਲ ਬ੍ਰਿਜ ਨਹੀਂ ਹੁੰਦਾ, ਇਸ ਲਈ ਕ੍ਰਿਡੈਂਸ਼ਲ ਪੜ੍ਹਨਾ ਹਮੇਸ਼ਾ ਅਸਫਲ ਹੁੰਦਾ ਹੈ।

OmniRoute ਦੋ ਤਰੀਕਿਆਂ ਰਾਹੀਂ Docker ਵਾਤਾਵਰਨ ਦੀ ਪਛਾਣ ਕਰਦਾ ਹੈ:

- `/.dockerenv` ਦੀ ਮੌਜੂਦਗੀ (ਕੰਟੇਨਰ ਸ਼ੁਰੂ ਹੋਣ ਵੇਲੇ Docker ਡੀਮਨ ਵੱਲੋਂ ਲਿਖੀ ਜਾਂਦੀ ਹੈ)।
- `/proc/1/cgroup` ਵਿੱਚ `docker` ਸਤਰ ਦਾ ਮੌਜੂਦ ਹੋਣਾ (Linux cgroup v1)।

ਜਦੋਂ ਇਨ੍ਹਾਂ ਵਿੱਚੋਂ ਕੋਈ ਵੀ ਤਰੀਕਾ ਟ੍ਰਿਗਰ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਇੰਪੋਰਟ ਰੂਟ HTTP 422 ਦੇ ਨਾਲ
`zedDockerEnvironment: true` ਅਤੇ ਤੁਹਾਨੂੰ ਮੈਨੂਅਲ ਟੋਕਨ ਇੰਪੋਰਟ ਟੈਬ ਵੱਲ ਭੇਜਣ ਵਾਲਾ ਸੁਨੇਹਾ ਵਾਪਸ ਕਰਦਾ ਹੈ।

## ਮੈਨੂਅਲ ਟੋਕਨ ਇੰਪੋਰਟ ਟੈਬ ਦੀ ਵਰਤੋਂ ਕਰਨਾ

1. **Dashboard → Providers → Zed** ਖੋਲ੍ਹੋ।
2. **Manual Token Import** ਪੈਨਲ ਕੀਚੇਨ ਇੰਪੋਰਟ ਕਾਰਡ ਦੇ ਹੇਠਾਂ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ। ਜਦੋਂ
   OmniRoute Docker ਦੀ ਪਛਾਣ ਕਰਦਾ ਹੈ, ਤਾਂ ਕੀਚੇਨ ਇੰਪੋਰਟ ਦੀ ਪਹਿਲੀ ਅਸਫਲ ਕੋਸ਼ਿਸ਼ ਤੋਂ ਬਾਅਦ ਇਹ ਪੈਨਲ ਆਪਣੇ ਆਪ ਫੈਲ ਜਾਂਦਾ ਹੈ।
3. ਡ੍ਰੌਪਡਾਊਨ ਵਿੱਚੋਂ ਪ੍ਰਦਾਤਾ ਚੁਣੋ (OpenAI, Anthropic, Google, Mistral, xAI,
   OpenRouter, ਜਾਂ DeepSeek)।
4. ਪਾਸਵਰਡ ਖੇਤਰ ਵਿੱਚ API ਕੁੰਜੀ ਪੇਸਟ ਕਰੋ।
5. **Import** ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ।

ਕੁੰਜੀ ਨੂੰ ਇਸ ਨਾਮ ਨਾਲ ਇੱਕ ਨਵੇਂ ਪ੍ਰਦਾਤਾ ਕਨੈਕਸ਼ਨ ਵਜੋਂ ਸੰਭਾਲਿਆ ਜਾਂਦਾ ਹੈ:
`Zed Manual Import (<provider>)`।

## Zed ਹੋਸਟ ਉੱਤੇ API ਕੁੰਜੀਆਂ ਕਿੱਥੇ ਸੰਭਾਲਦਾ ਹੈ

Zed AI ਪ੍ਰਦਾਤਾ ਕੁੰਜੀਆਂ ਨੂੰ OS ਕੀਚੇਨ ਵਿੱਚ `zed-openai`, `ai.zed.openai`,
`zed-anthropic`, ਆਦਿ ਵਰਗੇ ਸੇਵਾ ਨਾਮਾਂ ਹੇਠ ਸੰਭਾਲਦਾ ਹੈ। ਮੈਨੂਅਲ ਇੰਪੋਰਟ ਲਈ ਇਨ੍ਹਾਂ ਨੂੰ ਪ੍ਰਾਪਤ ਕਰਨ ਵਾਸਤੇ,
ਇੱਥੇ ਵੇਖੋ:

**Linux**

```
~/.config/zed/settings.json
```

`language_models` ਭਾਗ ਵਿੱਚ ਪ੍ਰਦਾਤਾ ਸੰਰਚਨਾਵਾਂ ਹੁੰਦੀਆਂ ਹਨ। Zed UI ਰਾਹੀਂ ਕੀਚੇਨ ਵਿੱਚ
ਸੰਭਾਲੀਆਂ ਕੁੰਜੀਆਂ `settings.json` ਵਿੱਚ ਸਧਾਰਨ ਟੈਕਸਟ ਵਜੋਂ ਮੌਜੂਦ ਨਹੀਂ ਹੁੰਦੀਆਂ; ਉਨ੍ਹਾਂ ਨੂੰ GNOME Keyring / Seahorse
ਵਰਗੇ ਕੀਚੇਨ ਦਰਸ਼ਕ ਰਾਹੀਂ, ਜਾਂ ਇਹ ਚਲਾ ਕੇ ਪ੍ਰਾਪਤ ਕਰੋ:

```bash
secret-tool lookup service zed-openai account api-key
```

**macOS**

```
~/Library/Application Support/Zed/settings.json
```

`zed` ਦੀ ਖੋਜ ਕਰਕੇ **Keychain Access.app** ਵਿੱਚ ਕੀਚੇਨ ਐਂਟਰੀਆਂ ਲੱਭੀਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ।

## ਵਾਲਿਊਮ-ਮਾਊਂਟ ਵਿਕਲਪ (ਉੱਨਤ)

ਤੁਸੀਂ ਚੋਣਵੇਂ ਤੌਰ 'ਤੇ Zed ਸੰਰਚਨਾ ਡਾਇਰੈਕਟਰੀ ਨੂੰ ਸਿਰਫ਼-ਪੜ੍ਹਨਯੋਗ ਮੋਡ ਵਿੱਚ ਕੰਟੇਨਰ ਅੰਦਰ ਮਾਊਂਟ ਕਰ ਸਕਦੇ ਹੋ।
ਇਸ ਨਾਲ ਕੀਚੇਨ ਸਮੱਸਿਆ ਹੱਲ ਨਹੀਂ ਹੁੰਦੀ, ਪਰ ਇਹ ਭਵਿੱਖ ਦੀਆਂ ਉਨ੍ਹਾਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਲਈ ਲਾਭਦਾਇਕ ਹੋ ਸਕਦਾ ਹੈ ਜੋ
ਗੈਰ-ਗੁਪਤ Zed ਸੰਰਚਨਾ ਮੁੱਲਾਂ (ਉਦਾਹਰਨ ਲਈ, ਮਾਡਲ ਤਰਜੀਹਾਂ) ਨੂੰ ਪੜ੍ਹਦੀਆਂ ਹਨ।

```yaml
# docker-compose.yml ਦਾ ਅੰਸ਼
services:
  omniroute:
    image: omniroute:latest
    volumes:
      # Linux ਹੋਸਟ
      - "${HOME}/.config/zed:/host-zed-config:ro"
      # macOS ਹੋਸਟ (ਇਸ ਦੀ ਬਜਾਏ ਟਿੱਪਣੀ ਹਟਾਓ)
      # - "${HOME}/Library/Application Support/Zed:/host-zed-config:ro"
    environment:
      # ਭਵਿੱਖ ਵਿੱਚ: ZED_CONFIG_PATH=/host-zed-config
      PORT: "20128"
```

ਨੋਟ: `ZED_CONFIG_PATH` ਵਾਤਾਵਰਨ ਵੇਰੀਏਬਲ ਓਵਰਰਾਈਡ ਅਜੇ ਲਾਗੂ ਨਹੀਂ ਕੀਤਾ ਗਿਆ। ਇਹ
ਅੰਸ਼ ਉਸ ਵਿਸ਼ੇਸ਼ਤਾ ਦੇ ਸ਼ਾਮਲ ਹੋਣ ਸਮੇਂ ਹਵਾਲੇ ਵਜੋਂ ਦਿੱਤਾ ਗਿਆ ਹੈ।

## ਮੈਨੂਅਲ ਇੰਪੋਰਟ API

ਮੈਨੂਅਲ ਇੰਪੋਰਟ ਐਂਡਪੌਇੰਟ ਨੂੰ ਸਿੱਧੇ ਤੌਰ 'ਤੇ ਵੀ ਕਾਲ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ:

```
POST /api/providers/zed/manual-import
Content-Type: application/json
Authorization: Bearer <oma_live_or_manage_scoped_api_key>

{
  "provider": "openai",
  "token": "sk-...",
  "label": "My Zed OpenAI key"   // ਵਿਕਲਪਿਕ
}
```

ਸਫਲ ਹੋਣ 'ਤੇ ਇਹ ਵਾਪਸ ਕਰਦਾ ਹੈ:

```json
{ "success": true, "connectionId": "...", "provider": "openai" }
```

## ਸਮੱਸਿਆ-ਨਿਵਾਰਣ

| ਲੱਛਣ                               | ਕਾਰਨ                              | ਹੱਲ                                   |
| ---------------------------------- | --------------------------------- | ------------------------------------- |
| 422 + `zedDockerEnvironment: true` | Docker ਦੇ ਅੰਦਰ ਚੱਲ ਰਿਹਾ ਹੈ        | Manual Token Import ਟੈਬ ਵਰਤੋ          |
| 404 + `zedInstalled: false`        | ਹੋਸਟ ਉੱਤੇ Zed ਇੰਸਟਾਲ ਨਹੀਂ ਹੈ      | Zed ਇੰਸਟਾਲ ਕਰੋ ਜਾਂ ਮੈਨੂਅਲ ਇੰਪੋਰਟ ਵਰਤੋ |
| 403 + ਕੀਚੇਨ ਪਹੁੰਚ ਅਸਵੀਕਾਰ ਕੀਤੀ ਗਈ  | OS ਨੇ ਕੀਚੇਨ ਪਹੁੰਚ ਅਸਵੀਕਾਰ ਕੀਤੀ    | OS ਪ੍ਰੌਮਪਟ ਵਿੱਚ ਇਜਾਜ਼ਤ ਦਿਓ            |
| 404 + ਕੀਚੇਨ ਸੇਵਾ ਉਪਲਬਧ ਨਹੀਂ        | Linux ਉੱਤੇ `libsecret` ਮੌਜੂਦ ਨਹੀਂ | `libsecret-1-dev` ਇੰਸਟਾਲ ਕਰੋ          |
