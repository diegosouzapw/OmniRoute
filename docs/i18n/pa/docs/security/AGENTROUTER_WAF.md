`agentrouter` ਅੱਪਸਟ੍ਰੀਮ ਗੇਟਵੇ `messages[].content` ਉੱਤੇ ਕੀਵਰਡ-ਅਧਾਰਿਤ ਸਮੱਗਰੀ ਫ਼ਿਲਟਰ ਚਲਾਉਂਦਾ ਹੈ। ਫ਼ਿਲਟਰ ਅੰਸ਼ਕ ਤੌਰ 'ਤੇ ਨਿਰਧਾਰਤ ਹੈ (ਕੁਝ ਵਾਕਾਂਸ਼ਾਂ ਨੂੰ ਹਮੇਸ਼ਾ ਬਲੌਕ ਕਰਦਾ ਹੈ) ਅਤੇ ਅੰਸ਼ਕ ਤੌਰ 'ਤੇ ਸੰਭਾਵਨਾਤਮਕ ਹੈ (ਬਰਸਟ-ਸੰਵੇਦਨਸ਼ੀਲ — ਤੇਜ਼ੀ ਨਾਲ ਬੇਨਤੀਆਂ ਆਉਣ ਤੋਂ ਬਾਅਦ ਹੋਰ ਸਖ਼ਤ ਹੋ ਜਾਂਦਾ ਹੈ ਅਤੇ ਕੂਲਡਾਊਨ ਤੋਂ ਬਾਅਦ ਮੁੜ ਸਧਾਰਨ ਹੋ ਜਾਂਦਾ ਹੈ)।

ਜਦੋਂ WAF ਕਿਸੇ ਬੇਨਤੀ ਨੂੰ ਬਲੌਕ ਕਰਦਾ ਹੈ, ਤਾਂ ਇਹ ਹੇਠਾਂ ਦਿੱਤਾ ਜਵਾਬ ਵਾਪਸ ਕਰਦਾ ਹੈ:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## ਫ਼ਿਲਟਰ ਦਾ ਦਾਇਰਾ

WAF ਸਿਰਫ਼ `messages[].content` ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ। ਇਹ ਹੇਠਾਂ ਦਿੱਤੀਆਂ ਚੀਜ਼ਾਂ ਦੀ ਜਾਂਚ **ਨਹੀਂ** ਕਰਦਾ:

- `system` ਪ੍ਰੌਂਪਟ
- ਸੰਰਚਿਤ ਸਮੱਗਰੀ ਬਲੌਕ (`tool_result`, `tool_use`, `thinking`, `image`)
- ਟੂਲ ਦੇ `description` ਅਤੇ `input_schema` ਫ਼ੀਲਡ
- ਬੇਨਤੀ ਮੈਟਾਡਾਟਾ, ਹੈਡਰ ਜਾਂ ਮਾਡਲ id

## ਹਮੇਸ਼ਾ ਬਲੌਕ ਹੋਣ ਵਾਲੇ ਪੈਟਰਨ (ਅੱਖਰਾਂ ਦੇ ਕੇਸ ਤੋਂ ਸੁਤੰਤਰ)

| ਪੈਟਰਨ                       | ਟਿੱਪਣੀਆਂ                                                        |
| --------------------------- | --------------------------------------------------------------- |
| `Lorem ipsum` ਦਾ ਕੋਈ ਵੀ ਰੂਪ | ਪੂਰੀ ਲਾਤੀਨੀ lorem ਸ਼ਬਦਾਵਲੀ ਬਲੌਕ ਕੀਤੀ ਜਾਂਦੀ ਹੈ                   |
| `language model` (ਇਕੱਲਾ)    | "the language model" ਅਤੇ "large language model" ਪਾਸ ਹੋ ਜਾਂਦੇ ਹਨ |
| `virtual assistant`         | "AI assistant" ਪਾਸ ਹੋ ਜਾਂਦਾ ਹੈ                                  |
| `I'm here to help`          | ਇਕੱਲਾ "here to help" ਵੀ ਬਲੌਕ ਹੁੰਦਾ ਹੈ                           |
| `Claude, made by Anthropic` | ਸਿਰਫ਼ ਪੂਰਾ ਵਾਕਾਂਸ਼                                              |

## ਲਗਭਗ ਹਮੇਸ਼ਾ ਬਲੌਕ ਹੋਣ ਵਾਲੇ ਪੈਟਰਨ

| ਪੈਟਰਨ                                                 | ਟਿੱਪਣੀਆਂ                                              |
| ----------------------------------------------------- | ----------------------------------------------------- |
| `placeholder`                                         | ਜਦੋਂ ਇਹ ਇਕੱਲਾ ਵਰਤਿਆ ਜਾਵੇ (ਪੈਰਾਮੀਟਰ ਨਾਮ ਆਦਿ ਵਜੋਂ ਨਹੀਂ) |
| `dummy data`                                          | ਫਿਕਸਚਰਾਂ ਲਈ ਆਮ ਸੀਡ ਵਾਕਾਂਸ਼                            |
| `foo bar baz`                                         | ਮਿਆਰੀ ਪਲੇਸਹੋਲਡਰ ਵਾਕਾਂਸ਼                               |
| ਦੁਹਰਾਏ ਗਏ ਛੋਟੇ ਟੋਕਨ (`AAA BBB CCC`, `test test test`) | ਕੀਵਰਡ ਸਟਫ਼ਿੰਗ ਲਈ ਡਿਟੈਕਟਰ                              |

## ਲੋਡ ਅਧੀਨ ਵਿਹਾਰ

ਥੋੜ੍ਹੇ ਸਮੇਂ ਵਿੱਚ ਲਗਭਗ 5 ਤੇਜ਼ ਬੇਨਤੀਆਂ ਤੋਂ ਬਾਅਦ, WAF ਉਸ ਸਮੱਗਰੀ ਨੂੰ ਵੀ ਬਲੌਕ ਕਰਨਾ ਸ਼ੁਰੂ ਕਰ ਦਿੰਦਾ ਹੈ ਜੋ ਆਮ ਤੌਰ 'ਤੇ ਪਾਸ ਹੋ ਜਾਂਦੀ ਹੈ। ਲਗਭਗ 5–10 ਸਕਿੰਟ ਦੀ ਨਿਸ਼ਕਿਰਿਆ ਮਿਆਦ ਤੋਂ ਬਾਅਦ ਬਕਟ ਢਿੱਲਾ ਪੈ ਜਾਂਦਾ ਹੈ। ਇਹ ਉਹੀ IP-ਅਤੇ-ਕੀ-ਅਧਾਰਿਤ ਰੇਟ ਲਿਮਟਰ ਹੈ ਜੋ Claude Code ਜਾਂ Codex CLI ਵੱਲੋਂ ਤੇਜ਼ੀ ਨਾਲ ਲਗਾਤਾਰ ਕਈ ਟੂਲ-ਵਰਤੋਂ / ਸੁਨੇਹਾ-ਭੇਜਣ ਕਾਲਾਂ ਕਰਨ ਵੇਲੇ ਰੁਕ-ਰੁਕ ਕੇ ਆਉਣ ਵਾਲੀਆਂ `400 content-blocked` ਗਲਤੀਆਂ ਦਾ ਕਾਰਨ ਬਣਦਾ ਹੈ।

## OmniRoute ਵਿੱਚ ਪਹਿਲਾਂ ਹੀ ਲਾਗੂ ਕੀਤੇ ਗਏ ਉਪਾਅ

1. **`open-sse/services/wafRateLimit.ts`** — ਇੱਕ ਬਰਸਟ ਗਾਰਡ ਜੋ ਕਿਸੇ ਵੀ `agentrouter:*` URL ਵੱਲ ਜਾਣ ਵਾਲੀਆਂ ਬੇਨਤੀਆਂ ਵਿਚਕਾਰ ਘੱਟੋ-ਘੱਟ 500 ms ਦਾ ਅੰਤਰ ਲਾਗੂ ਕਰਦਾ ਹੈ। ਇਹ ਅੰਤਰ ਮਨੁੱਖੀ ਤੌਰ 'ਤੇ ਮਹਿਸੂਸ ਹੋਣ ਵਾਲੀ ਲੇਟੈਂਸੀ ਤੋਂ ਕਾਫ਼ੀ ਘੱਟ ਹੈ ਅਤੇ ਆਮ ਟ੍ਰੈਫ਼ਿਕ ਦੌਰਾਨ WAF ਨੂੰ ਸਰਗਰਮ ਹੋਣ ਤੋਂ ਰੋਕਦਾ ਹੈ।

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — ਜਦੋਂ ਕੋਈ ਅੱਪਸਟ੍ਰੀਮ `400 content-blocked` ਵਾਪਸ ਕਰਦਾ ਹੈ, ਤਾਂ ਐਗਜ਼ਿਕਿਊਟਰ ਐਕਸਪੋਨੇਨਸ਼ੀਅਲ ਬੈਕਆਫ਼ (1.5 s, 3.0 s, ਵੱਧ ਤੋਂ ਵੱਧ 2 ਕੋਸ਼ਿਸ਼ਾਂ) ਨਾਲ ਉਸੇ URL ਲਈ ਮੁੜ ਕੋਸ਼ਿਸ਼ ਕਰਦਾ ਹੈ। ਬੈਕਆਫ਼ ਤੋਂ ਬਾਅਦ WAF ਆਮ ਤੌਰ 'ਤੇ ਢਿੱਲਾ ਪੈ ਜਾਂਦਾ ਹੈ ਅਤੇ ਮੁੜ ਕੋਸ਼ਿਸ਼ ਸਫਲ ਹੋ ਜਾਂਦੀ ਹੈ।

3. **`tests/unit/compression/harness.test.ts`** — ਟੈਸਟ ਫਿਕਸਚਰ `longInput` ਨੂੰ `"lorem ipsum dolor sit amet ".repeat(40)` ਤੋਂ ਬਦਲ ਕੇ `"example content for testing purposes ".repeat(40)` ਕਰ ਦਿੱਤਾ ਗਿਆ ਸੀ, ਤਾਂ ਜੋ ਜਦੋਂ Claude Code ਇਸ ਫ਼ਾਈਲ ਨੂੰ `Read` ਟੂਲ ਰਾਹੀਂ ਪੜ੍ਹੇ, ਤਾਂ ਫ਼ਾਈਲ ਦੀ ਸਮੱਗਰੀ `tool_result` ਬਲੌਕ ਰਾਹੀਂ ਵਾਪਸ ਪ੍ਰਵਾਹਿਤ ਹੋ ਕੇ WAF ਨੂੰ ਟ੍ਰਿਗਰ ਨਾ ਕਰੇ।

## ਪ੍ਰੌਂਪਟਾਂ ਅਤੇ ਟੂਲ ਆਉਟਪੁੱਟ ਲਈ ਮਾਰਗਦਰਸ਼ਨ

ਜੇ ਕੋਈ Claude Code ਜਾਂ Codex CLI ਸੈਸ਼ਨ ਵਾਰ-ਵਾਰ `400 content-blocked` ਦਾ ਸਾਹਮਣਾ ਕਰਦਾ ਹੈ, ਤਾਂ ਸਭ ਤੋਂ ਹਾਲੀਆ ਯੂਜ਼ਰ ਸੁਨੇਹੇ ਅਤੇ ਸਭ ਤੋਂ ਹਾਲੀਆ ਟੂਲ ਨਤੀਜੇ ਵਿੱਚ ਉੱਪਰ ਦਿੱਤੇ ਕਿਸੇ ਪੈਟਰਨ ਦੀ ਜਾਂਚ ਕਰੋ ਅਤੇ ਉਸਨੂੰ ਹੋਰ ਸ਼ਬਦਾਂ ਵਿੱਚ ਲਿਖੋ। ਆਮ ਹੱਲ:

- `Lorem ipsum …` ਨੂੰ `example text …` ਜਾਂ ਉਸ ਅਸਲ ਸਮੱਗਰੀ ਨਾਲ ਬਦਲੋ ਜਿਸਨੂੰ ਟੈਸਟ ਜਾਂ ਫਿਕਸਚਰ ਮਾਡਲ ਕਰਨ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰ ਰਿਹਾ ਹੈ।
- `placeholder` (ਜਦੋਂ ਇਕੱਲਾ ਵਰਤਿਆ ਗਿਆ ਹੋਵੇ) ਨੂੰ `example value`, `sample value` ਜਾਂ ਅਸਲ ਮੁੱਲ ਨਾਲ ਬਦਲੋ।
- `language model` ਨੂੰ `large language model` ਜਾਂ `the model` ਨਾਲ ਬਦਲੋ।
- `dummy data` ਨੂੰ `sample data` ਜਾਂ ਹਕੀਕਤਨੁਮਾ ਸੀਡ ਮੁੱਲਾਂ ਨਾਲ ਬਦਲੋ।
- `I'm here to help` / `here to help` ਨੂੰ ਹੋਰ ਵਿਸ਼ੇਸ਼ ਸ਼ੁਰੂਆਤੀ ਵਾਕ ਨਾਲ ਬਦਲੋ (ਉਦਾਹਰਨ ਲਈ, "I'll review the file you mentioned")।

## ਗਲਤ ਪਾਜ਼ਿਟਿਵਾਂ ਬਾਰੇ ਅੱਪਸਟ੍ਰੀਮ ਨੂੰ ਰਿਪੋਰਟ ਕਰਨਾ

ਮੌਜੂਦਾ ਫ਼ਿਲਟਰ ਹੱਦ ਤੋਂ ਵੱਧ ਸਖ਼ਤ ਹੈ — ਇਹ `tool_result` ਬਲੌਕਾਂ ਵਿੱਚ "Lorem ipsum" ਨੂੰ ਵੀ ਬਲੌਕ ਕਰਦਾ ਹੈ, ਭਾਵੇਂ ਓਪਰੇਟਰ ਦਾ ਸਪਸ਼ਟ ਤੌਰ 'ਤੇ ਪ੍ਰੌਂਪਟ ਇੰਜੈਕਟ ਕਰਨ ਦਾ ਕੋਈ ਇਰਾਦਾ ਨਹੀਂ ਸੀ। ਜਿਹੜੇ ਓਪਰੇਟਰ ਇਸਨੂੰ ਮੂਲ ਸਰੋਤ 'ਤੇ ਠੀਕ ਕਰਵਾਉਣਾ ਚਾਹੁੰਦੇ ਹਨ, ਉਹ ਗਲਤ ਪਾਜ਼ਿਟਿਵਾਂ ਦੀ ਰਿਪੋਰਟ ਕਰਨ ਲਈ `agentrouter.org` ਨਾਲ ਸੰਪਰਕ ਕਰਨ। ਉੱਪਰ ਦਿੱਤੀ ਬਲੌਕਲਿਸਟ 2026-08-03 ਤੱਕ ਅੱਪਸਟ੍ਰੀਮ ਦੀ ਜਾਂਚ ਤੋਂ ਪ੍ਰਾਪਤ ਅਨੁਭਵ-ਅਧਾਰਿਤ ਨਤੀਜਾ ਹੈ।
