## 1. Antigravity ਬਨਾਮ Antigravity CLI (agy)

ਦੋਵੇਂ ਪ੍ਰਦਾਤਾ **ਇੱਕੋ Google ਬੈਕਐਂਡ** ਸਾਂਝਾ ਕਰਦੇ ਹਨ — ਇੱਕੋ OAuth ਕਲਾਇੰਟ, ਟੋਕਨ ਰਿਫ੍ਰੈਸ਼, ਐਂਡਪੌਇੰਟ ਅਤੇ Google ਖਾਤੇ। ਅੰਤਰ ਇਸ ਗੱਲ ਵਿੱਚ ਹੈ ਕਿ ਤੁਹਾਨੂੰ ਕਿਹੜੇ ਮਾਡਲ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ।

> Google ਦੀ ਅਧਿਕਾਰਤ ਤੁਲਨਾ ਲਈ [Antigravity CLI ਘੋਸ਼ਣਾ](https://antigravity.google/blog/introducing-google-antigravity-cli) ਵੇਖੋ।

| ਪੱਖ               | `antigravity` (IDE)                              | `agy` (CLI)                                              |
| ----------------- | ------------------------------------------------ | -------------------------------------------------------- |
| **Google ਉਤਪਾਦ**  | Antigravity 2.0 / Antigravity IDE                | Antigravity CLI                                          |
| **ਬੈਕਐਂਡ**        | ਉਹੀ Google Cloud Code API                        | ਉਹੀ Google Cloud Code API                                |
| **OAuth / ਟੋਕਨ**  | ਉਹੀ ਕਲਾਇੰਟ, ਉਹੀ ਰਿਫ੍ਰੈਸ਼                         | ਉਹੀ ਕਲਾਇੰਟ, ਉਹੀ ਰਿਫ੍ਰੈਸ਼                                 |
| **ਮਾਡਲ ਕੈਟਾਲਾਗ**  | ਸਥਿਰ ਚੁਣੀ ਹੋਈ ਸੂਚੀ (OmniRoute ਵਿੱਚ ਹਾਰਡਕੋਡ ਕੀਤੀ) | `:fetchAvailableModels` ਰਾਹੀਂ Google ਤੋਂ ਲਾਈਵ ਜਾਂਚਿਆ ਗਿਆ |
| **Claude ਮਾਡਲ**   | Sonnet 4.6, Opus 4.6 (ਹਰੇਕ ਦੇ 4 ਵੇਰੀਐਂਟ)         | Sonnet 4.6, Opus 4.6 (ਹਰੇਕ ਦੇ 4 ਵੇਰੀਐਂਟ)                 |
| **Gemini ਨਾਮਕਰਨ** | ਸਪਸ਼ਟ ਲੇਬਲ (Low/Medium/High)                     | ਅੱਪਸਟ੍ਰੀਮ IDs (extra-low/low/agent)                      |
| **ਵਾਧੂ ਮਾਡਲ**     | `gpt-oss-120b-medium`                            | Google ਤੋਂ ਵਾਧੂ ਮਾਡਲ ਸ਼ਾਮਲ ਹੋ ਸਕਦੇ ਹਨ                    |
| **ਡਿਫੌਲਟ ਵਰਤੋਂ**  | IDE ਏਕੀਕਰਨ (VS Code, JetBrains)                  | CLI / API ਪਹੁੰਚ                                          |

**ਉਪਲਬਧ ਮਾਡਲ (ਪ੍ਰਯੋਗ ਰਾਹੀਂ ਤਸਦੀਕ ਕੀਤੇ ਗਏ, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (ਸੋਚਣ ਦੇ ਵੱਖ-ਵੱਖ ਪੱਧਰ)
- Claude: Sonnet 4.6, Opus 4.6 (ਹਰੇਕ ਦੇ default/low/medium/high ਵੇਰੀਐਂਟ)
- ਹੋਰ: GPT-OSS 120B Medium
- **Claude Sonnet 5 ਉਪਲਬਧ ਨਹੀਂ ਹੈ** — ਕੇਵਲ 4.6 ਵੇਰੀਐਂਟ ਸਮਰਥਿਤ ਹਨ

**ਮਾਡਲ ਕੈਟਾਲਾਗ ਵੱਖਰਾ ਕਿਉਂ ਹੈ**: Google ਦਾ CLI "ਗਤੀ ਅਤੇ ਘੱਟ ਓਵਰਹੈੱਡ ਲਈ ਅਨੁਕੂਲਿਤ" ਅਤੇ "Gemini ਮਾਡਲਾਂ ਨਾਲ ਸਾਂਝੇ ਤੌਰ 'ਤੇ ਅਨੁਕੂਲਿਤ" ਹੈ (Google ਦੇ ਅਧਿਕਾਰਤ ਬਲੌਗ ਅਨੁਸਾਰ)। Web/IDE ਉਤਪਾਦ "ਵਿਆਪਕਤਾ ਲਈ ਅਨੁਕੂਲਿਤ" ਹੈ। CLI ਮਾਡਲਾਂ ਨੂੰ ਗਤੀਸ਼ੀਲ ਢੰਗ ਨਾਲ ਖੋਜਣ ਲਈ `:fetchAvailableModels` ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ, ਜਦਕਿ IDE ਇੱਕ ਸਥਿਰ ਚੁਣੀ ਹੋਈ ਸੂਚੀ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ।

**ਵਿਹਾਰਕ ਤੌਰ 'ਤੇ**: Gemini ਮਾਡਲਾਂ ਲਈ `agy/` ਪ੍ਰੀਫਿਕਸ ਵਰਤੋ (ਉਦਾਹਰਨ ਲਈ `agy/gemini-3.7-flash-high`)। ਸਥਿਰ ਚੁਣੀ ਹੋਈ ਸੂਚੀ ਲਈ `antigravity/` ਵਰਤੋ। ਦੋਵੇਂ ਇੱਕੋ Google ਬੈਕਐਂਡ ਨੂੰ ਵਰਤਦੇ ਹਨ, ਪਰ ਮਾਡਲਾਂ ਦੇ ਵੱਖਰੇ ਨਾਮ ਪ੍ਰਦਰਸ਼ਿਤ ਕਰਦੇ ਹਨ। ਕੋਟਾ ਸਾਂਝਾ ਹੈ — ਕਿਸੇ ਵੀ ਪ੍ਰਦਾਤਾ ਦੀ ਵਰਤੋਂ ਉਸੇ Google ਖਾਤੇ ਦੀਆਂ ਸੀਮਾਵਾਂ ਵਿੱਚ ਗਿਣੀ ਜਾਂਦੀ ਹੈ।

## 2. Google One AI Pro: ਕੋਟਾ ਸਿਸਟਮ

> ਅਧਿਕਾਰਤ ਕੋਟਾ ਵੇਰਵਿਆਂ ਲਈ [Antigravity Docs: Plans](https://antigravity.google/docs/plans) ਅਤੇ ਨਵੀਨਤਮ ਕੀਮਤ ਅੱਪਡੇਟਾਂ ਲਈ [Changes to Antigravity Plans](https://antigravity.google/blog/changes-to-antigravity-plans) ਵੇਖੋ।

Google Antigravity ਸੁਨੇਹਿਆਂ ਦੀ ਗਿਣਤੀ ਦੀ ਬਜਾਏ "ਕੀਤਾ ਗਿਆ ਕੰਮ" (ਕੰਪਿਊਟੇਸ਼ਨਲ ਭਾਰ) 'ਤੇ ਆਧਾਰਿਤ ਇੱਕ **ਦੋਹਰੀ-ਪਰਤ ਕੋਟਾ** ਵਰਤਦਾ ਹੈ।

### Gemini ਬਨਾਮ ਗ਼ੈਰ-Gemini ਮਾਡਲ

- **Gemini ਮਾਡਲ** (Flash + Pro): ਇੱਕੋ ਦਰ ਸੀਮਾ ਸਾਂਝੀ ਕਰਦੇ ਹਨ, ਜਿਸ ਦੀ ਖਪਤ API ਕੀਮਤ ਮੁਤਾਬਕ ਹੁੰਦੀ ਹੈ। ਜੇ Flash, Pro ਨਾਲੋਂ 8x ਸਸਤਾ ਹੈ, ਤਾਂ ਤੁਹਾਨੂੰ 8x ਵੱਧ Flash ਟੋਕਨ ਮਿਲਦੇ ਹਨ।
- **ਗ਼ੈਰ-Gemini ਮਾਡਲ** (Claude, GPT-OSS): ਇਨ੍ਹਾਂ ਦੀਆਂ **ਵੱਖਰੀਆਂ** ਦਰ ਸੀਮਾਵਾਂ ਹਨ। Gemini ਦੇ ਲਾਕ ਹੋਣ 'ਤੇ ਵੀ ਇਹ ਉਪਲਬਧ ਰਹਿ ਸਕਦੇ ਹਨ।

### AI ਕ੍ਰੈਡਿਟ (ਵਾਧੂ ਵਰਤੋਂ)

> ਕ੍ਰੈਡਿਟ ਕਿਵੇਂ ਕੰਮ ਕਰਦੇ ਹਨ, ਇਸ ਲਈ [Google One AI credits](https://support.google.com/googleone/answer/14534406) ਵੇਖੋ।

ਜਦੋਂ ਬੇਸਲਾਈਨ ਕੋਟਾ ਖ਼ਤਮ ਹੋ ਜਾਂਦਾ ਹੈ:

- **ਕਦੇ ਨਹੀਂ**: ਕੋਟਾ ਰਿਫ੍ਰੈਸ਼ ਹੋਣ ਦੀ ਉਡੀਕ ਕਰੋ; "Baseline model quota reached" ਦਿਖਾਉਂਦਾ ਹੈ
- **ਹਮੇਸ਼ਾ**: ਆਪਣੇ-ਆਪ AI ਕ੍ਰੈਡਿਟ ਵਰਤੋ; ਬੇਸਲਾਈਨ ਰਿਫ੍ਰੈਸ਼ ਹੋਣ 'ਤੇ ਵਾਪਸ ਉਸ 'ਤੇ ਸਵਿੱਚ ਕਰਦਾ ਹੈ

ਕ੍ਰੈਡਿਟ ਵੱਖਰੇ ਤੌਰ 'ਤੇ ਖਰੀਦੇ ਜਾਂਦੇ ਹਨ ਅਤੇ ਮਿਆਰੀ API ਕੀਮਤ ਅਨੁਸਾਰ ਕੱਟੇ ਜਾਂਦੇ ਹਨ।

### ਮੁੱਖ ਵੇਰਵੇ

- ਕੋਟਾ **ਖਾਤਾ-ਪੱਧਰ 'ਤੇ ਸਾਂਝਾ** ਹੁੰਦਾ ਹੈ — Antigravity IDE, CLI ਅਤੇ OmniRoute ਵਿੱਚ ਇੱਕੋ Google ਖਾਤਾ ਇੱਕੋ ਕੋਟਾ ਪੂਲ ਸਾਂਝਾ ਕਰਦਾ ਹੈ
- ਹਰ Google ਖਾਤੇ ਦਾ ਆਪਣਾ ਸੁਤੰਤਰ ਕੋਟਾ ਹੁੰਦਾ ਹੈ — ਕਈ ਖਾਤੇ = ਕਈ ਕੋਟਾ ਪੂਲ
- AI Pro ਵਰਤੋਂਕਾਰਾਂ ਨੇ ਹਫ਼ਤਾਵਾਰੀ ਬੇਸਲਾਈਨ ਪੂਰੀ ਹੋਣ 'ਤੇ 5-ਘੰਟੇ ਦੇ ਰੀਸੈੱਟਾਂ ਦੀ ਬਜਾਏ **7-ਦਿਨਾਂ ਦੇ ਲਾਕਆਉਟਾਂ** ਦੀ ਰਿਪੋਰਟ ਕੀਤੀ ਹੈ (Google ਨੇ ਪੁਸ਼ਟੀ ਕੀਤੀ ਹੈ ਕਿ ਉੱਚ ਮੰਗ ਲਈ ਇਹ ਡਿਜ਼ਾਈਨ ਅਨੁਸਾਰ ਹੈ)

**ਜਦੋਂ ਤੁਹਾਡੇ ਖਾਤੇ ਦਾ ਕੋਟਾ ਖ਼ਤਮ ਹੋ ਜਾਂਦਾ ਹੈ**: OmniRoute ਕੰਬੋ ਰੂਟ ਵਿੱਚ ਅਗਲੇ ਉਪਲਬਧ ਖਾਤੇ ਨਾਲ ਆਪਣੇ-ਆਪ ਮੁੜ ਕੋਸ਼ਿਸ਼ ਕਰਦਾ ਹੈ। ਕਿਸੇ ਹੱਥੀਂ ਦਖ਼ਲ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ।

## 3. projectId ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰੀਏ

ਹਰ antigravity/agy ਕਨੈਕਸ਼ਨ ਨੂੰ Google Cloud Code `projectId` ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ। ਇਸ ਤੋਂ ਬਿਨਾਂ, `/v1internal:models` ਐਂਡਪੌਇੰਟ 404 ਵਾਪਸ ਕਰਦਾ ਹੈ।

### ਢੰਗ A: ਆਟੋਮੈਟਿਕ (ਸਿਫ਼ਾਰਸ਼ੀ)

OmniRoute ਇਹ ਕੰਮ ਆਪਣੇ-ਆਪ ਸੰਭਾਲਦਾ ਹੈ। ਜਦੋਂ ਤੁਸੀਂ Dashboard OAuth ਰਾਹੀਂ ਇੱਕ ਨਵਾਂ Google ਖਾਤਾ ਜੋੜਦੇ ਹੋ:

1. OmniRoute ਟੋਕਨ ਨੂੰ ਰਿਫ੍ਰੈਸ਼ ਕਰਦਾ ਹੈ
2. projectId ਖੋਜਣ ਲਈ `loadCodeAssist` ਨੂੰ ਕਾਲ ਕਰਦਾ ਹੈ
3. ਜੇ ਕੋਈ ਪ੍ਰੋਜੈਕਟ ਮੌਜੂਦ ਨਹੀਂ ਹੈ, ਤਾਂ ਇੱਕ ਬਣਾਉਣ ਲਈ `onboardUser` ਨੂੰ ਕਾਲ ਕਰਦਾ ਹੈ
4. ਨਵਾਂ ਬਣਾਇਆ projectId ਪ੍ਰਾਪਤ ਕਰਨ ਲਈ `loadCodeAssist` ਨੂੰ ਮੁੜ ਅਜ਼ਮਾਉਂਦਾ ਹੈ
5. ਇਸ ਨੂੰ ਡੇਟਾਬੇਸ ਵਿੱਚ ਸੇਵ ਕਰਦਾ ਹੈ

**ਇਹ ਜ਼ਿਆਦਾਤਰ ਖਾਤਿਆਂ ਲਈ ਕੰਮ ਕਰਦਾ ਹੈ** — ਕਿਸੇ ਹੱਥੀਂ ਕਦਮ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ।

### ਢੰਗ B: agy CLI ਰਾਹੀਂ ਹੱਥੀਂ

ਜੇ ਆਟੋਮੈਟਿਕ ਖੋਜ ਅਸਫਲ ਹੋ ਜਾਂਦੀ ਹੈ (ਇਹ ਕਦੋਂ ਹੁੰਦਾ ਹੈ, ਇਸ ਲਈ ਭਾਗ 5 ਵੇਖੋ):

```bash
# agy CLI ਇੰਸਟਾਲ ਕਰੋ (ਜੇ ਪਹਿਲਾਂ ਤੋਂ ਨਹੀਂ ਹੈ)
npm install -g @anthropic-ai/agy

# ਆਪਣੇ Google ਖਾਤੇ ਨਾਲ ਲੌਗਇਨ ਕਰੋ
agy login

# ਉਹ ਖਾਤਾ ਚੁਣੋ ਜਿਸ ਨੂੰ ਆਨਬੋਰਡਿੰਗ ਦੀ ਲੋੜ ਹੈ
# ਇਹ Cloud Code ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਨੂੰ ਟ੍ਰਿਗਰ ਕਰਦਾ ਹੈ ਅਤੇ ਇੱਕ projectId ਨਿਰਧਾਰਤ ਕਰਦਾ ਹੈ

`agy login` ਸਫਲ ਹੋਣ ਤੋਂ ਬਾਅਦ, OmniRoute Dashboard ਵਿੱਚ ਟੋਕਨ ਨੂੰ ਰਿਫ੍ਰੈਸ਼ ਕਰੋ। projectId ਆਪਣੇ-ਆਪ ਖੋਜਿਆ ਜਾਵੇਗਾ।

## 4. OAuth ਰੀਡਾਇਰੈਕਟ URI

### ਸਮੱਸਿਆ

Google OAuth ਲਈ ਇੱਕ ਵੈਧ ਰੀਡਾਇਰੈਕਟ URI ਲੋੜੀਂਦਾ ਹੈ। OmniRoute ਦਾ ਡਿਫੌਲਟ `http://127.0.0.1:20128/callback` (ਲੂਪਬੈਕ) ਵਰਤਦਾ ਹੈ। ਇਹ ਲੋਕਲ ਬਿਲਡਾਂ ਲਈ ਕੰਮ ਕਰਦਾ ਹੈ, ਪਰ **ਰਿਮੋਟ ਡਿਪਲੌਇਮੈਂਟਾਂ ਲਈ ਅਸਫਲ ਹੁੰਦਾ ਹੈ** (ਉਦਾਹਰਨ ਲਈ, LAN IP ਰਾਹੀਂ ਐਕਸੈੱਸ ਕੀਤਾ ਗਿਆ ਸਰਵਰ)।

Google ਉਹਨਾਂ ਰੀਡਾਇਰੈਕਟ URI ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ ਜੋ:

- IP ਐਡਰੈੱਸ ਵਰਤਦੇ ਹਨ (ਡੋਮੇਨ ਦਾ ਅੰਤ `.com`, `.org` ਆਦਿ ਨਾਲ ਹੋਣਾ ਲਾਜ਼ਮੀ ਹੈ)
- OAuth ਕਲਾਇੰਟ ਕੌਂਫਿਗ ਵਿੱਚ ਰਜਿਸਟਰ ਕੀਤੇ ਰੀਡਾਇਰੈਕਟ URI ਨਾਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦੇ

### ਹੱਲ

**ਵਿਕਲਪ A: ਬਿਲਟ-ਇਨ OAuth ਫਲੋ ਵਰਤੋ (ਡਿਫੌਲਟ)**

- ਜਦੋਂ ਤੁਸੀਂ OmniRoute ਨੂੰ `localhost` ਜਾਂ `127.0.0.1` ਤੋਂ ਐਕਸੈੱਸ ਕਰਦੇ ਹੋ ਤਾਂ ਇਹ ਕੰਮ ਕਰਦਾ ਹੈ
- ਕਿਸੇ ਕੌਂਫਿਗਰੇਸ਼ਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ

**ਵਿਕਲਪ B: ਕਸਟਮ OAuth ਕ੍ਰੀਡੈਂਸ਼ਲ**

- ਆਪਣੇ ਇਨਵਾਇਰਨਮੈਂਟ ਵਿੱਚ `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` ਸੈੱਟ ਕਰੋ
- ਆਪਣੇ Google OAuth ਕ੍ਰੀਡੈਂਸ਼ਲ ਦਿਓ:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Google Cloud Console ਵਿੱਚ `https://your-domain.com/callback` ਨੂੰ ਇੱਕ ਅਧਿਕਾਰਤ ਰੀਡਾਇਰੈਕਟ URI ਵਜੋਂ ਰਜਿਸਟਰ ਕਰੋ

**ਵਿਕਲਪ C: ਸ਼ੁਰੂਆਤੀ ਲੌਗਇਨ ਲਈ agy CLI ਵਰਤੋ**

- ਉਸ ਮਸ਼ੀਨ ਉੱਤੇ `agy login` ਚਲਾਓ ਜੋ OmniRoute ਨੂੰ ਐਕਸੈੱਸ ਕਰੇਗੀ
- OAuth ਫਲੋ ਲੋਕਲ ਤੌਰ 'ਤੇ ਪੂਰਾ ਹੁੰਦਾ ਹੈ ਅਤੇ ਟੋਕਨ ਸਟੋਰ ਹੋ ਜਾਂਦੇ ਹਨ
- Dashboard ਰਾਹੀਂ ਕਨੈਕਸ਼ਨ ਨੂੰ OmniRoute ਵਿੱਚ ਇੰਪੋਰਟ ਕਰੋ

### ਸੀਮਾਵਾਂ

- ਕਸਟਮ OAuth ਕ੍ਰੀਡੈਂਸ਼ਲ ਲਈ ਡੋਮੇਨ ਨਾਮ ਲੋੜੀਂਦਾ ਹੈ (Google IP ਐਡਰੈੱਸਾਂ ਨੂੰ ਰੀਡਾਇਰੈਕਟ URI ਵਜੋਂ ਸਵੀਕਾਰ ਨਹੀਂ ਕਰਦਾ)
- ਜੇ ਤੁਹਾਡੇ ਕੋਲ ਡੋਮੇਨ ਨਹੀਂ ਹੈ, ਤਾਂ ਇਸ ਦੀ ਬਜਾਏ ਵਿਕਲਪ A ਜਾਂ C ਵਰਤੋ

## 5. ਸਮੱਸਿਆ-ਨਿਪਟਾਰਾ: ਜਦੋਂ ਆਟੋਮੈਟਿਕ ਸੈੱਟਅੱਪ ਅਸਫਲ ਹੁੰਦਾ ਹੈ

OmniRoute ਜ਼ਿਆਦਾਤਰ ਖਾਤਿਆਂ ਲਈ projectId ਦੀ ਖੋਜ ਅਤੇ ਆਨਬੋਰਡਿੰਗ ਨੂੰ ਆਪਣੇ-ਆਪ ਸੰਭਾਲਦਾ ਹੈ। ਜਦੋਂ ਇਹ ਅਸਫਲ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਮੂਲ ਕਾਰਨ ਆਮ ਤੌਰ 'ਤੇ ਇਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਹੁੰਦਾ ਹੈ:

### ਖਾਤੇ ਦਾ ਖੇਤਰ ਬਲੌਕ ਕੀਤਾ ਹੋਇਆ ਹੈ

**ਲੱਛਣ**: `agy login` ਇਹ ਸੁਨੇਹਾ ਵਾਪਸ ਕਰਦਾ ਹੈ: "ਯੋਗਤਾ ਜਾਂਚ ਅਸਫਲ ਰਹੀ: ਤੁਹਾਡਾ ਮੌਜੂਦਾ ਖਾਤਾ Antigravity ਲਈ ਯੋਗ ਨਹੀਂ ਹੈ, ਕਿਉਂਕਿ ਇਹ ਇਸ ਵੇਲੇ ਤੁਹਾਡੇ ਸਥਾਨ ਵਿੱਚ ਉਪਲਬਧ ਨਹੀਂ ਹੈ।"

**ਮੂਲ ਕਾਰਨ**: Google ਖਾਤਿਆਂ ਵਿੱਚ ਬੈਕਐਂਡ ਦਾ ਇੱਕ "ਦੇਸ਼ ਸੰਬੰਧ" ਫੀਲਡ ਹੁੰਦਾ ਹੈ, ਜੋ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਵੇਲੇ ਸੈੱਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। agy CLI ਅਤੇ Cloud Code API ਇਸ ਫੀਲਡ ਦੀ ਸਖ਼ਤੀ ਨਾਲ ਜਾਂਚ ਕਰਦੇ ਹਨ — ਵੈੱਬ Gemini ਦੇ ਉਲਟ, ਜੋ ਸਿਰਫ਼ ਤੁਹਾਡੇ ਮੌਜੂਦਾ IP ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ।

> ਆਪਣੇ ਖਾਤੇ ਨਾਲ ਸੰਬੰਧਿਤ ਖੇਤਰ ਦੀ ਜਾਂਚ ਕਰਨ ਜਾਂ ਉਸਨੂੰ ਬਦਲਣ ਲਈ, [Google Country Association Form](https://policies.google.com/country-association-form) 'ਤੇ ਜਾਓ।

**ਵੈੱਬ Gemini ਕੰਮ ਕਿਉਂ ਕਰਦਾ ਹੈ ਪਰ agy ਨਹੀਂ**:

- ਵੈੱਬ Gemini / Google One: ਸਿਰਫ਼ ਮੌਜੂਦਾ IP ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ (ਪ੍ਰੌਕਸੀ ਨਾਲ ਕੰਮ ਕਰ ਜਾਂਦਾ ਹੈ)
- agy CLI / Cloud Code API: ਬੈਕਐਂਡ ਦੇ Country Association ਫੀਲਡ ਨੂੰ ਪੜ੍ਹਦਾ ਹੈ (ਪ੍ਰੌਕਸੀ ਨਾਲ ਕੋਈ ਮਦਦ ਨਹੀਂ ਮਿਲਦੀ)

**ਹੱਲ**:

1. US IP ਵਰਤਦੇ ਹੋਏ [Google Country Association Form](https://policies.google.com/country-association-form) 'ਤੇ ਜਾਓ
2. ਖੇਤਰ ਬਦਲਣ ਦੀ ਬੇਨਤੀ ਸਬਮਿਟ ਕਰੋ ("ਮੈਂ ਕਿਸੇ ਹੋਰ ਦੇਸ਼ ਵਿੱਚ ਰਹਿੰਦਾ/ਰਹਿੰਦੀ ਹਾਂ" ਚੁਣੋ)
3. Google ਵੱਲੋਂ ਪ੍ਰਕਿਰਿਆ ਪੂਰੀ ਕਰਨ ਅਤੇ ਈਮੇਲ ਸੂਚਨਾ ਭੇਜਣ ਲਈ 1-24 ਘੰਟੇ ਉਡੀਕ ਕਰੋ
4. ਇਸ ਤੋਂ ਬਾਅਦ `agy login` ਸਫਲ ਹੋ ਜਾਣਾ ਚਾਹੀਦਾ ਹੈ

### ਖਾਤੇ ਵਿੱਚ ਕੋਈ Cloud Code ਪ੍ਰੋਜੈਕਟ ਨਹੀਂ ਹੈ

**ਲੱਛਣ**: ਲੌਗਾਂ ਵਿੱਚ `loadCodeAssist returned no project id` ਅਤੇ `onboardUser failed (400)` ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ।

**ਮੂਲ ਕਾਰਨ**: ਖਾਤਾ ਪਹਿਲਾਂ ਕਦੇ ਵੀ Google Cloud Code ਨਾਲ ਰਜਿਸਟਰ ਨਹੀਂ ਹੋਇਆ ਅਤੇ ਆਟੋਮੈਟਿਕ ਆਨਬੋਰਡਿੰਗ ਅਸਫਲ ਰਹੀ।

**ਹੱਲ**: Cloud Code ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਸ਼ੁਰੂ ਕਰਨ ਲਈ `agy login` ਨੂੰ ਮੈਨੁਅਲੀ ਚਲਾਓ, ਫਿਰ OmniRoute Dashboard ਵਿੱਚ ਟੋਕਨ ਰਿਫ੍ਰੈਸ਼ ਕਰੋ।

### ਟੋਕਨ ਦੀ ਮਿਆਦ ਖ਼ਤਮ ਹੋ ਗਈ ਹੈ ਜਾਂ ਉਸਨੂੰ ਰੱਦ ਕਰ ਦਿੱਤਾ ਗਿਆ ਹੈ

**ਲੱਛਣ**: ਲੌਗਾਂ ਵਿੱਚ 401 ਤਰੁੱਟੀਆਂ ਜਾਂ "ਟੋਕਨ ਦੀ ਮਿਆਦ ਖ਼ਤਮ ਹੋ ਗਈ ਹੈ" ਸੁਨੇਹੇ।

**ਹੱਲ**: Dashboard → Providers → agy → ਰਿਫ੍ਰੈਸ਼ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰਕੇ ਟੋਕਨ ਰਿਫ੍ਰੈਸ਼ ਕਰੋ। ਜੇ ਰਿਫ੍ਰੈਸ਼ ਟੋਕਨ ਖੁਦ ਰੱਦ ਹੋ ਗਿਆ ਹੈ, ਤਾਂ ਤੁਹਾਨੂੰ OAuth ਰਾਹੀਂ ਮੁੜ ਪ੍ਰਮਾਣੀਕਰਨ ਕਰਨਾ ਪਵੇਗਾ।

│  ├─ ਨਹੀਂ → ਪਹਿਲਾਂ one.google.com 'ਤੇ ਗਾਹਕੀ ਲਓ
│  └─ ਹਾਂ ↓
│
├─ ਸਵੈਚਾਲਿਤ ਖੋਜ ਦੀ ਕੋਸ਼ਿਸ਼ ਕਰੋ (ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ ਟੋਕਨ ਰਿਫ੍ਰੈਸ਼ ਕਰੋ)
│  ├─ ਕੰਮ ਕਰਦਾ ਹੈ → ਮੁਕੰਮਲ
│  └─ ਹਾਲੇ ਵੀ ਅਸਫਲ ↓
│
└─ ਦਸਤੀ: ਮਸ਼ੀਨ 'ਤੇ `agy login` ਚਲਾਓ
   ├─ ਕੰਮ ਕਰਦਾ ਹੈ → ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ ਟੋਕਨ ਰਿਫ੍ਰੈਸ਼ ਕਰੋ, projectId ਲੱਭ ਲਿਆ ਗਿਆ
   └─ ਅਸਫਲ → ਗਲਤੀ ਸੁਨੇਹਾ ਜਾਂਚੋ, ਸੰਭਾਵਤ ਤੌਰ 'ਤੇ ਖੇਤਰ ਜਾਂ ਗਾਹਕੀ ਦੀ ਸਮੱਸਿਆ ਹੈ
```
