## ਤੁਰੰਤ ਅਣਇੰਸਟਾਲ (v3.6.2+)

OmniRoute ਸਾਫ਼ ਤਰੀਕੇ ਨਾਲ ਹਟਾਉਣ ਲਈ ਦੋ ਬਿਲਟ-ਇਨ ਸਕ੍ਰਿਪਟਾਂ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ:

### ਆਪਣਾ ਡਾਟਾ ਰੱਖੋ

```bash
npm run uninstall
```

ਇਹ OmniRoute ਐਪਲੀਕੇਸ਼ਨ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ, ਪਰ `~/.omniroute/` ਵਿੱਚ ਮੌਜੂਦ ਤੁਹਾਡੇ ਡਾਟਾਬੇਸ, ਸੰਰਚਨਾਵਾਂ, API ਕੁੰਜੀਆਂ ਅਤੇ ਪ੍ਰਦਾਤਾ ਸੈਟਿੰਗਾਂ ਨੂੰ **ਸੁਰੱਖਿਅਤ ਰੱਖਦਾ ਹੈ**। ਜੇ ਤੁਸੀਂ ਬਾਅਦ ਵਿੱਚ ਮੁੜ ਇੰਸਟਾਲ ਕਰਨ ਦੀ ਯੋਜਨਾ ਬਣਾਉਂਦੇ ਹੋ ਅਤੇ ਆਪਣਾ ਸੈੱਟਅੱਪ ਰੱਖਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਇਸਦੀ ਵਰਤੋਂ ਕਰੋ।

### ਪੂਰੀ ਤਰ੍ਹਾਂ ਹਟਾਉਣਾ

```bash
npm run uninstall:full
```

ਇਹ ਐਪਲੀਕੇਸ਼ਨ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ **ਅਤੇ ਸਾਰਾ ਡਾਟਾ ਸਥਾਈ ਤੌਰ 'ਤੇ ਮਿਟਾ ਦਿੰਦਾ ਹੈ**:

- ਡਾਟਾਬੇਸ (`storage.sqlite`)
- ਪ੍ਰਦਾਤਾ ਸੰਰਚਨਾਵਾਂ ਅਤੇ API ਕੁੰਜੀਆਂ
- ਬੈਕਅੱਪ ਫ਼ਾਈਲਾਂ
- ਲੌਗ ਫ਼ਾਈਲਾਂ
- `~/.omniroute/` ਡਾਇਰੈਕਟਰੀ ਵਿਚਲੀਆਂ ਸਾਰੀਆਂ ਫ਼ਾਈਲਾਂ

> ⚠️ **ਚੇਤਾਵਨੀ:** `npm run uninstall:full` ਨੂੰ ਵਾਪਸ ਨਹੀਂ ਕੀਤਾ ਜਾ ਸਕਦਾ। ਤੁਹਾਡੇ ਸਾਰੇ ਪ੍ਰਦਾਤਾ ਕਨੈਕਸ਼ਨ, ਕੰਬੋਜ਼, API ਕੁੰਜੀਆਂ ਅਤੇ ਵਰਤੋਂ ਦਾ ਇਤਿਹਾਸ ਸਥਾਈ ਤੌਰ 'ਤੇ ਮਿਟਾ ਦਿੱਤਾ ਜਾਵੇਗਾ।

## ਹੱਥੀਂ ਅਣਇੰਸਟਾਲ ਕਰਨਾ

### NPM ਗਲੋਬਲ ਇੰਸਟਾਲ

```bash
# ਗਲੋਬਲ ਪੈਕੇਜ ਹਟਾਓ
npm uninstall -g omniroute

# (ਵਿਕਲਪਿਕ) ਡਾਟਾ ਡਾਇਰੈਕਟਰੀ ਹਟਾਓ
rm -rf ~/.omniroute
```

### pnpm ਗਲੋਬਲ ਇੰਸਟਾਲ

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# ਕੰਟੇਨਰ ਨੂੰ ਰੋਕੋ ਅਤੇ ਹਟਾਓ
docker stop omniroute
docker rm omniroute

# ਵਾਲਿਊਮ ਹਟਾਓ (ਸਾਰਾ ਡਾਟਾ ਮਿਟਾਉਂਦਾ ਹੈ)
docker volume rm omniroute-data

# (ਵਿਕਲਪਿਕ) ਇਮੇਜ ਹਟਾਓ
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# ਕੰਟੇਨਰਾਂ ਨੂੰ ਰੋਕੋ ਅਤੇ ਹਟਾਓ
docker compose down

# ਵਾਲਿਊਮ ਵੀ ਹਟਾਓ (ਸਾਰਾ ਡਾਟਾ ਮਿਟਾਉਂਦਾ ਹੈ)
docker compose down -v
```

### Electron ਡੈਸਕਟਾਪ ਐਪ

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` ਖੋਲ੍ਹੋ
- ਜਾਂ ਇੰਸਟਾਲ ਡਾਇਰੈਕਟਰੀ ਤੋਂ NSIS ਅਣਇੰਸਟਾਲਰ ਚਲਾਓ

**macOS:**

- `OmniRoute.app` ਨੂੰ `/Applications` ਤੋਂ Trash ਵਿੱਚ ਖਿੱਚੋ
- ਡਾਟਾ ਹਟਾਓ: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage ਫ਼ਾਈਲ ਹਟਾਓ
- ਡਾਟਾ ਹਟਾਓ: `rm -rf ~/.omniroute`

### ਸਰੋਤ ਤੋਂ ਇੰਸਟਾਲ (git clone)

```bash
# ਕਲੋਨ ਕੀਤੀ ਡਾਇਰੈਕਟਰੀ ਹਟਾਓ
rm -rf /path/to/omniroute

# (ਵਿਕਲਪਿਕ) ਡਾਟਾ ਡਾਇਰੈਕਟਰੀ ਹਟਾਓ
rm -rf ~/.omniroute
```

## ਡਾਟਾ ਡਾਇਰੈਕਟਰੀਆਂ

ਮੂਲ ਰੂਪ ਵਿੱਚ OmniRoute ਹੇਠਾਂ ਦਿੱਤੀਆਂ ਥਾਵਾਂ 'ਤੇ ਡਾਟਾ ਸਟੋਰ ਕਰਦਾ ਹੈ:

| ਪਲੇਟਫਾਰਮ   | ਮੂਲ ਪਾਥ                          | ਓਵਰਰਾਈਡ                           |
| ---------- | -------------------------------- | --------------------------------- |
| Linux      | `~/.omniroute/`                  | `DATA_DIR` ਵਾਤਾਵਰਨ ਵੇਰੀਏਬਲ        |
| macOS      | `~/.omniroute/`                  | `DATA_DIR` ਵਾਤਾਵਰਨ ਵੇਰੀਏਬਲ        |
| Windows    | `%APPDATA%/omniroute/`           | `DATA_DIR` ਵਾਤਾਵਰਨ ਵੇਰੀਏਬਲ        |
| Docker     | `/app/data/` (ਮਾਊਂਟ ਕੀਤਾ ਵਾਲਿਊਮ) | `DATA_DIR` ਵਾਤਾਵਰਨ ਵੇਰੀਏਬਲ        |
| XDG-ਅਨੁਕੂਲ | `$XDG_CONFIG_HOME/omniroute/`    | `XDG_CONFIG_HOME` ਵਾਤਾਵਰਨ ਵੇਰੀਏਬਲ |

### ਡਾਟਾ ਡਾਇਰੈਕਟਰੀ ਵਿਚਲੀਆਂ ਫ਼ਾਈਲਾਂ

| ਫ਼ਾਈਲ/ਡਾਇਰੈਕਟਰੀ      | ਵੇਰਵਾ                                             |
| -------------------- | ------------------------------------------------- |
| `storage.sqlite`     | ਮੁੱਖ ਡਾਟਾਬੇਸ (ਪ੍ਰਦਾਤਾ, ਕੰਬੋਜ਼, ਸੈਟਿੰਗਾਂ, ਕੁੰਜੀਆਂ) |
| `storage.sqlite-wal` | SQLite ਰਾਈਟ-ਅਹੈੱਡ ਲੌਗ (ਆਰਜ਼ੀ)                     |
| `storage.sqlite-shm` | SQLite ਸਾਂਝੀ ਮੈਮੋਰੀ (ਆਰਜ਼ੀ)                       |
| `call_logs/`         | ਬੇਨਤੀ ਪੇਲੋਡ ਆਰਕਾਈਵ                                |
| `backups/`           | ਆਟੋਮੈਟਿਕ ਡਾਟਾਬੇਸ ਬੈਕਅੱਪ                           |
| `log.txt`            | ਪੁਰਾਣਾ ਬੇਨਤੀ ਲੌਗ (ਵਿਕਲਪਿਕ)                        |

## ਪੂਰੀ ਤਰ੍ਹਾਂ ਹਟਾਏ ਜਾਣ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ

ਅਣਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਬਾਅਦ, ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਕੋਈ ਫ਼ਾਈਲ ਬਾਕੀ ਨਹੀਂ ਹੈ:

```bash
# ਗਲੋਬਲ npm ਪੈਕੇਜ ਦੀ ਜਾਂਚ ਕਰੋ
npm list -g omniroute 2>/dev/null

# ਡਾਟਾ ਡਾਇਰੈਕਟਰੀ ਦੀ ਜਾਂਚ ਕਰੋ
ls -la ~/.omniroute/ 2>/dev/null

# ਚੱਲ ਰਹੀਆਂ ਪ੍ਰਕਿਰਿਆਵਾਂ ਦੀ ਜਾਂਚ ਕਰੋ
pgrep -f omniroute
```

ਜੇ ਕੋਈ ਪ੍ਰਕਿਰਿਆ ਹਾਲੇ ਵੀ ਚੱਲ ਰਹੀ ਹੈ, ਤਾਂ ਉਸਨੂੰ ਰੋਕੋ:

```bash
pkill -f omniroute
```
