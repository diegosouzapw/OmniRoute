OmniRoute ਸਮਰਥਿਤ 352 ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ 3 ਆਰਥਿਕ ਟੀਅਰਾਂ ਵਿੱਚ ਵਿਵਸਥਿਤ ਕਰਦਾ ਹੈ। ਹਰ
ਬੇਨਤੀ ਕ੍ਰਮਵਾਰ ਇਨ੍ਹਾਂ ਵਿੱਚੋਂ ਲੰਘਦੀ ਹੈ, ਜਦੋਂ ਤੱਕ ਕੋਈ ਇੱਕ ਸਫਲ ਜਵਾਬ ਨਹੀਂ ਦਿੰਦਾ — ਤੁਹਾਨੂੰ
ਕਦੇ ਵੀ ਫਾਲਬੈਕ ਕੋਡ ਲਿਖੇ ਬਿਨਾਂ ਸਭ ਤੋਂ ਸਸਤਾ ਵਿਹਾਰਕ ਜਵਾਬ ਮਿਲਦਾ ਹੈ।

## ਟੀਅਰ 1 — ਸਬਸਕ੍ਰਿਪਸ਼ਨ

**ਉਹ ਪ੍ਰਦਾਤਾ ਜਿਨ੍ਹਾਂ ਲਈ ਤੁਸੀਂ ਪਹਿਲਾਂ ਹੀ ਭੁਗਤਾਨ ਕਰਦੇ ਹੋ।** OmniRoute ਕੋਟੇ ਦੀ ਮਿਆਦ
ਮੁੱਕਣ ਤੋਂ ਪਹਿਲਾਂ ਉਸਦੀ ਹਰ ਬੂੰਦ ਵਰਤਦਾ ਹੈ।

| ਪ੍ਰਦਾਤਾ                            | ਟੀਅਰ 1 ਕਿਉਂ ਹੈ                                 |
| ---------------------------------- | ---------------------------------------------- |
| Claude Code OAuth                  | Anthropic Pro/Team — ਨਿਸ਼ਚਿਤ ਦਰ, ਅਕਸਰ ਨਾ ਵਰਤਿਆ |
| OpenAI Codex (ChatGPT ਸਬਸਕ੍ਰਿਪਸ਼ਨ) | Plus/Team ਵਿੱਚ Codex ਕੋਟਾ ਸ਼ਾਮਲ ਹੈ             |
| GitHub Copilot                     | ਪ੍ਰਤੀ ਸੀਟ — ਕੋਟਾ ਹਰ ਮਹੀਨੇ ਰੀਸੈੱਟ ਹੁੰਦਾ ਹੈ      |
| Cursor IDE                         | Pro ਪਲਾਨ ਦਾ ਕੋਟਾ                               |
| Antigravity / Devin Desktop        | ਅੰਦਰੂਨੀ ਕੋਟੇ                                   |

**ਰਣਨੀਤੀ**: ਹਰ ਉਸ ਬੇਨਤੀ ਨੂੰ ਪਹਿਲਾਂ ਇੱਥੇ ਰੂਟ ਕਰੋ ਜੋ ਮਾਡਲ ਦੀਆਂ
ਖੂਬੀਆਂ ਨਾਲ ਮੇਲ ਖਾਂਦੀ ਹੈ। ਕੋਟਾ ਟ੍ਰੈਕਰ ਨੇੜੇ ਆ ਰਹੇ ਰੀਸੈੱਟਾਂ ਦੀ ਨਿਗਰਾਨੀ ਕਰਦਾ ਹੈ, ਅਤੇ `reset-aware`
ਕੌਂਬੋ ਰਣਨੀਤੀ ਉਸ ਅਨੁਸਾਰ ਤਰਜੀਹ ਦਿੰਦੀ ਹੈ। ਪਹਿਲਾਂ ਟੀਅਰ 1 ਵੱਲ ਰੂਟ ਕਰਨ ਅਤੇ ਕੋਟਾ
ਮੁੱਕਣ 'ਤੇ ਹੀ ਭੁਗਤਾਨਯੋਗ ਟੀਅਰਾਂ ਵੱਲ ਜਾਣ ਲਈ, `auto/thrifty` id ਵਰਤੋ — ਜਾਂ ਪਲਾਨ ਵਿੱਚ
ਸ਼ਾਮਲ ਸਮਰੱਥਾ ਤੱਕ ਸੀਮਿਤ ਰਹਿਣ ਅਤੇ ਉਸਦੀ ਗੈਰ-ਉਪਲਬਧਤਾ 'ਤੇ ਬੰਦ ਹੋਣ ਲਈ `auto/subscription`
ਵਰਤੋ। [ਸਬਸਕ੍ਰਿਪਸ਼ਨ-ਪਹਿਲਾਂ ਰੂਟਿੰਗ](../routing/SUBSCRIPTION_LADDER.md) ਵੇਖੋ।

## ਟੀਅਰ 2 — ਸਸਤਾ

**$1/1M ਟੋਕਨਾਂ ਤੋਂ ਘੱਟ ਲਾਗਤ ਵਾਲੇ ਪ੍ਰਤੀ-ਟੋਕਨ ਭੁਗਤਾਨ ਪ੍ਰਦਾਤਾ।** ਵੱਡੀ ਮਾਤਰਾ ਵਾਲੇ ਕੰਮ
ਲਈ ਜਾਂ ਟੀਅਰ 1 ਦੇ ਕੋਟਿਆਂ ਦੀ ਸੀਮਾ ਪੂਰੀ ਹੋਣ ਤੋਂ ਬਾਅਦ ਲਈ ਰਾਖਵੇਂ।

**ਰਣਨੀਤੀ**: ਕੌਂਬੋ `cost-optimized` ਸਭ ਤੋਂ ਘੱਟ $/ਟੋਕਨ ਵਾਲਾ ਉਹ ਮਾਡਲ ਚੁਣਦਾ ਹੈ ਜੋ
ਕੰਮ ਦੇ ਸਮਰੱਥਾ ਫਿਲਟਰ (ਵਿਜ਼ਨ, JSON ਮੋਡ, ਟੂਲ, ਅਧਿਕਤਮ-ਸੰਦਰਭ) ਨੂੰ ਪੂਰਾ ਕਰਦਾ ਹੈ।

## ਟੀਅਰ 3 — ਮੁਫ਼ਤ

**ਜ਼ੀਰੋ-ਲਾਗਤ ਪ੍ਰਦਾਤਾ** — ਮੁਫ਼ਤ ਟੀਅਰ, ਕ੍ਰੈਡਿਟ ਪ੍ਰੋਗਰਾਮ, OAuth ਰੋਜ਼ਾਨਾ ਕੋਟੇ।

| ---------------- | ----------------------------------------- |
| Kiro AI          | ਮੁਫ਼ਤ Claude ਟੀਅਰ (ਖੁੱਲ੍ਹੀ ਉਚਿਤ-ਵਰਤੋਂ)    |
| OpenCode Free    | ਕੋਈ ਪ੍ਰਮਾਣੀਕਰਨ ਨਹੀਂ, ਖੁੱਲ੍ਹੀਆਂ ਦਰ ਸੀਮਾਵਾਂ |
| Qoder            | ਮੁਫ਼ਤ OAuth                               |
| Google Vertex AI | ਨਵੇਂ ਖਾਤੇ ਲਈ $300 ਕ੍ਰੈਡਿਟ                 |

**ਰਣਨੀਤੀ**: ਬਜਟ ਸੀਮਾ ਵਾਲਾ ਕੌਂਬੋ `auto` ਉਸ ਵੇਲੇ ਇੱਥੇ ਰੂਟ ਕਰਦਾ ਹੈ ਜਦੋਂ ਟੀਅਰ 1+2
ਅਸਫਲ ਹੋਣ ਜਾਂ ਜਦੋਂ `useFreeOnly=true` ਸੈੱਟ ਹੋਵੇ। ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾਵਾਂ ਦੀਆਂ ਦਰ ਸੀਮਾਵਾਂ
ਅਕਸਰ ਕਮਜ਼ੋਰ ਹੁੰਦੀਆਂ ਹਨ — ਸਰਕਿਟ ਬ੍ਰੇਕਰ ਬੈਕਆਫ਼ ਦੌਰਾਨ ਉਨ੍ਹਾਂ ਨੂੰ ਮੁੜ ਉਪਲਬਧ ਕਰਦਾ ਹੈ।

## ਟੀਅਰਾਂ ਦੀ ਸੰਰਚਨਾ

ਡੈਸ਼ਬੋਰਡ → **ਟੀਅਰ** → ਆਪਣੇ ਪ੍ਰਦਾਤਾ ਨਿਰਧਾਰਤ ਕਰੋ। ਡਿਫਾਲਟ (`tierDefaults.json` ਤੋਂ)
ਉਚਿਤ ਹਨ; ਜਦੋਂ ਤੁਹਾਡੇ ਕੋਲ ਤਰਜੀਹ ਦੇਣ ਲਈ ਖਾਸ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਜਾਂ ਬਾਹਰ ਰੱਖਣ ਲਈ ਪ੍ਰਦਾਤਾ ਹੋਣ ਤਾਂ ਸੋਧੋ।

Auto-Combo ਦੀ 16-ਕਾਰਕ ਸਕੋਰਿੰਗ ਟੀਅਰ ਨੂੰ ਵੀ ਧਿਆਨ ਵਿੱਚ ਰੱਖਦੀ ਹੈ। ਵੇਖੋ
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md)।

## ਟੈਲੀਮੈਟਰੀ

ਡੈਸ਼ਬੋਰਡ → **ਵਰਤੋਂ** ਪ੍ਰਤੀ ਟੀਅਰ ਪ੍ਰਤੀ ਦਿਨ ਖਰਚੇ ਗਏ ਟੋਕਨ ਦਿਖਾਉਂਦਾ ਹੈ। ਇਸਦੀ ਵਰਤੋਂ ਇਨ੍ਹਾਂ ਲਈ ਕਰੋ:

- ਪੁਸ਼ਟੀ ਕਰੋ ਕਿ ਟੀਅਰ 1 ਦੀ ਪੂਰੀ ਵਰਤੋਂ ਹੋ ਰਹੀ ਹੈ (ਨਹੀਂ ਤਾਂ ਤੁਸੀਂ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਦਾ ਮੁੱਲ ਵਿਅਰਥ ਕਰ ਰਹੇ ਹੋ)
- ਪਛਾਣੋ ਕਿ ਟੀਅਰ 2 ਦੇ ਕਿਹੜੇ ਮਾਡਲ ਸਭ ਤੋਂ ਵੱਧ ਚੁਣੇ ਜਾਂਦੇ ਹਨ (1-2 ਤੱਕ ਇਕੱਠੇ ਕਰੋ)
- ਤਸਦੀਕ ਕਰੋ ਕਿ ਟੀਅਰ 3 ਟੈਸਟ/ਖੋਜ ਵਾਲੇ ਕੰਮਾਂ 'ਤੇ ਪੈਸੇ ਬਚਾਉਂਦਾ ਹੈ

## ਆਮ ਪੈਟਰਨ

### ਪੂਰੀ ਤਰ੍ਹਾਂ ਮੁਫ਼ਤ ਵਰਕਲੋਡ

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

ਟੀਅਰ 3 ਵੱਲ ਜ਼ੋਰਦਾਰ ਢੰਗ ਨਾਲ ਭੇਜਦਾ ਹੈ; ਟੀਅਰ 2 ਦੀ ਵਰਤੋਂ ਸਿਰਫ਼ ਉਦੋਂ ਕਰਦਾ ਹੈ ਜਦੋਂ ਟੀਅਰ 3 ਉਪਲਬਧ ਨਾ ਹੋਵੇ।

### ਸਸਤੇ ਫਾਲਬੈਕ ਨਾਲ ਸਬਸਕ੍ਰਿਪਸ਼ਨ-ਪਹਿਲਾਂ

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

ਟੀਅਰ 1 → ਟੀਅਰ 2 → ਟੀਅਰ 3 ਨਾਲ ਮੇਲ ਖਾਂਦੀ ਸਪਸ਼ਟ ਕ੍ਰਮਬੱਧ ਸੂਚੀ।
