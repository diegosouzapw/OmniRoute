## ਸੈੱਟਅੱਪ

1. **OmniRoute ਚਲਾਓ** — `npm install -g omniroute && omniroute` (`http://localhost:20128` ਉੱਤੇ ਡੈਸ਼ਬੋਰਡ)।
2. **ਐਕਸਟੈਂਸ਼ਨ ਇੰਸਟਾਲ ਕਰੋ** — Extensions ਦ੍ਰਿਸ਼ ਵਿੱਚ "OmniRoute" ਖੋਜੋ।
3. **ਕੋਈ ਮਾਡਲ ਚੁਣੋ** — Copilot Chat → ਮਾਡਲ ਚੋਣਕਾਰ → **Manage Models…** → **OmniRoute**, ਫਿਰ
   ਆਪਣੀਆਂ ਲੋੜੀਂਦੀਆਂ ਚੋਣਾਂ ਉੱਤੇ ਨਿਸ਼ਾਨ ਲਗਾਓ।

ਜਦੋਂ OmniRoute ਡਿਫਾਲਟ ਪੋਰਟ ਉੱਤੇ ਚੱਲਦਾ ਹੈ, ਤਾਂ ਕੁਝ ਵੀ ਸੰਰਚਿਤ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੁੰਦੀ। ਕਿਸੇ ਰਿਮੋਟ ਇੰਸਟੈਂਸ ਲਈ,
**Activity Bar ਵਿੱਚ OmniRoute ਆਈਕਨ** ਖੋਲ੍ਹੋ (ਜਾਂ `OmniRoute: Manage Connection` ਚਲਾਓ) ਅਤੇ ਇਹ ਸੈੱਟ ਕਰੋ:

- **ਸਰਵਰ URL** — ਸਰਵਰ ਰੂਟ, ਜਿਵੇਂ `http://192.168.0.15:20128`। `/v1` ਸਫ਼ਿਕਸ
  ਐਕਸਟੈਂਸ਼ਨ ਵੱਲੋਂ ਜੋੜਿਆ ਜਾਂਦਾ ਹੈ; ਇਸਨੂੰ ਸ਼ਾਮਲ ਨਾ ਕਰੋ।
- **API ਕੁੰਜੀ** — ਸਿਰਫ਼ ਉਦੋਂ ਜਦੋਂ ਸਰਵਰ `REQUIRE_API_KEY` ਸੈੱਟ ਕਰਦਾ ਹੈ। ਇਹ VS
  Code SecretStorage ਰਾਹੀਂ OS ਕੀਚੇਨ ਵਿੱਚ ਸਟੋਰ ਹੁੰਦੀ ਹੈ, `settings.json` ਵਿੱਚ ਕਦੇ ਨਹੀਂ।

## ਚੋਣਕਾਰ ਕੀ ਦਿਖਾਏਗਾ

ਐਕਸਟੈਂਸ਼ਨ ਕੱਚਾ `GET /v1/models` ਪੇਲੋਡ ਨਹੀਂ ਦਿਖਾਉਂਦਾ — ਇਹ ਉਸਨੂੰ ਢਾਲਦਾ ਹੈ, ਅਤੇ ਤੁਹਾਨੂੰ ਦਿਖਾਈ ਦੇਣ ਵਾਲੀ
ਗਿਣਤੀ ਦੋ ਜਾਣਬੁੱਝ ਕੇ ਰੱਖੇ ਕਾਰਨਾਂ ਕਰਕੇ ਕੈਟਾਲਾਗ ਦੇ ਆਕਾਰ ਨਾਲੋਂ ਘੱਟ ਹੁੰਦੀ ਹੈ।

### ਇਹ ਪ੍ਰਤੀ ਮਾਡਲ ਇੱਕ id ਦੀ ਮੰਗ ਕਰਦਾ ਹੈ

`MODELS_CATALOG_PREFIX_MODE` ਦਾ ਡਿਫਾਲਟ **`dual`** ਹੈ, ਜੋ ਹਰੇਕ ਮਾਡਲ ਨੂੰ ਦੋ ਵਾਰ ਪ੍ਰਦਰਸ਼ਿਤ ਕਰਦਾ ਹੈ — ਇੱਕ ਵਾਰ
ਛੋਟੇ alias ਪ੍ਰੀਫਿਕਸ ਹੇਠ ਅਤੇ ਇੱਕ ਵਾਰ ਮਿਆਰੀ ਪ੍ਰਦਾਤਾ ਪ੍ਰੀਫਿਕਸ ਹੇਠ — ਤਾਂ ਜੋ ਪੁਰਾਣੀਆਂ ਕਲਾਇੰਟ
ਸੰਰਚਨਾਵਾਂ ਦੋਵਾਂ ਰੂਪਾਂ ਵਿੱਚੋਂ ਕਿਸੇ ਨੂੰ ਵੀ ਹੱਲ ਕਰਦੀਆਂ ਰਹਿਣ:

```
cc/claude-sonnet-4-6        ← alias ਪ੍ਰੀਫਿਕਸ
claude/claude-sonnet-4-6    ← ਮਿਆਰੀ ਪ੍ਰੀਫਿਕਸ, ਉਹੀ ਮਾਡਲ
```

ਐਕਸਟੈਂਸ਼ਨ **`GET /v1/models?prefix=alias`** ਦੀ ਬੇਨਤੀ ਕਰਦਾ ਹੈ, ਤਾਂ ਜੋ ਤੁਹਾਡੇ ਹੋਰ ਕਲਾਇੰਟਾਂ ਲਈ ਸਰਵਰ-ਵਿਆਪੀ
ਸੈਟਿੰਗ ਨੂੰ ਬਦਲੇ ਬਿਨਾਂ, ਪ੍ਰਤੀ ਮਾਡਲ ਇੱਕ id ਪ੍ਰਾਪਤ ਹੋਵੇ। ਇੱਕ ਹਵਾਲਾ ਇੰਸਟੈਂਸ ਉੱਤੇ ਇਸ ਨਾਲ
**2345 ਐਂਟਰੀਆਂ ਘਟ ਕੇ 1396 ਰਹਿ ਗਈਆਂ — 949 ਡੁਪਲੀਕੇਟ, ਇੱਕ ਵੀ ਮਾਡਲ ਗੁਆਚਿਆ ਨਹੀਂ।**

ਜੇ ਤੁਸੀਂ ਇਸਨੂੰ _ਹਰੇਕ_ ਕਲਾਇੰਟ ਲਈ ਸਰਵਰ-ਵਿਆਪੀ ਤੌਰ ਉੱਤੇ ਠੀਕ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ
`MODELS_CATALOG_PREFIX_MODE` ਫੀਚਰ ਫਲੈਗ ਨੂੰ `alias` ਉੱਤੇ ਸੈੱਟ ਕਰੋ। ਕਵੇਰੀ ਪੈਰਾਮੀਟਰ ਅਤੇ
ਹਰੇਕ ਮੋਡ ਦੀ ਸਾਰਣੀ ਲਈ [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) ਵੇਖੋ।

### ਇਹ ਉਹ ਮਾਡਲ ਲੁਕਾਉਂਦਾ ਹੈ ਜੋ ਚੈਟ ਨਹੀਂ ਕਰ ਸਕਦੇ

ਕੈਟਾਲਾਗ ਵਿੱਚ ਚਿੱਤਰ, ਵੀਡੀਓ, ਆਡੀਓ, ਰੀਰੈਂਕ, embedding ਅਤੇ ਮੋਡਰੇਸ਼ਨ ਮਾਡਲ ਵੀ ਸੂਚੀਬੱਧ ਹੁੰਦੇ ਹਨ। ਚੈਟ ਬੇਨਤੀ
ਉੱਤੇ ਉਹ ਫਿਰ ਵੀ ਅਸਵੀਕਾਰ ਕਰ ਦਿੱਤੇ ਜਾਂਦੇ ਹਨ:

```
HTTP 400 — ਮਾਡਲ '<id>' ਇੱਕ ਚਿੱਤਰ-ਉਤਪਾਦਨ ਮਾਡਲ ਹੈ ਅਤੇ ਇਸਨੂੰ
/v1/chat/completions ਉੱਤੇ ਵਰਤਿਆ ਨਹੀਂ ਜਾ ਸਕਦਾ। ਇਸਦੀ ਬਜਾਏ POST /v1/images/generations ਵਰਤੋ।
```

ਇਸ ਲਈ ਚੋਣਕਾਰ ਤੱਕ ਪਹੁੰਚਣ ਤੋਂ ਪਹਿਲਾਂ ਉਨ੍ਹਾਂ ਨੂੰ ਉਨ੍ਹਾਂ ਦੇ `type` ਖੇਤਰ ਦੇ ਆਧਾਰ ਉੱਤੇ ਫਿਲਟਰ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ। **Responses-API
ਮਾਡਲ ਰੱਖੇ ਜਾਂਦੇ ਹਨ** — ਹਰੇਕ Codex / GPT-5.x ਐਂਟਰੀ `supported_endpoints: ["responses"]` ਪ੍ਰਦਰਸ਼ਿਤ ਕਰਦੀ ਹੈ,
ਅਤੇ OmniRoute ਉਨ੍ਹਾਂ ਨੂੰ `/v1/chat/completions` ਲਈ ਤਬਦੀਲ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਉਹ ਪੂਰੀ ਤਰ੍ਹਾਂ ਵਰਤੋਂਯੋਗ ਹਨ।

### ਉਹ ਪ੍ਰਦਾਤਾ ਜੋ ਤੁਸੀਂ ਕਦੇ ਸੰਰਚਿਤ ਨਹੀਂ ਕੀਤੇ

ਕੈਟਾਲਾਗ **ਸਰਗਰਮ ਕਨੈਕਸ਼ਨ** ਵਾਲੇ ਪ੍ਰਦਾਤਾਵਾਂ ਦੇ ਮਾਡਲਾਂ ਦੇ ਨਾਲ-ਨਾਲ ਹਰੇਕ **noAuth**
ਪ੍ਰਦਾਤਾ ਨੂੰ ਵੀ ਸੂਚੀਬੱਧ ਕਰਦਾ ਹੈ — ਇਹ ਉਹ ਕੁੰਜੀ-ਰਹਿਤ ਪ੍ਰਦਾਤਾ ਹਨ ਜੋ ਮੁਫ਼ਤ ਟੀਅਰ ਦਾ ਵੱਡਾ ਹਿੱਸਾ ਬਣਾਉਂਦੇ ਹਨ। ਇਹ ਜਾਣਬੁੱਝ ਕੇ ਕੀਤਾ ਗਿਆ ਹੈ। ਉਨ੍ਹਾਂ ਨੂੰ
ਲੁਕਾਉਣ ਲਈ, ਡੈਸ਼ਬੋਰਡ ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਉਨ੍ਹਾਂ ਨੂੰ `blockedProviders` ਵਿੱਚ ਸ਼ਾਮਲ ਕਰੋ; ਐਕਸਟੈਂਸ਼ਨ ਵਿੱਚ ਕੁਝ ਵੀ
ਨਹੀਂ ਬਦਲਦਾ।

## VS Code ਟੈਬ ਦੇ ਅੰਦਰ ਡੈਸ਼ਬੋਰਡ

`omnicopilot.dashboardOpen: "editor"` OmniRoute ਡੈਸ਼ਬੋਰਡ ਨੂੰ ਕਿਸੇ ਬਾਹਰੀ ਬ੍ਰਾਊਜ਼ਰ ਦੀ ਬਜਾਏ Simple Browser ਰਾਹੀਂ ਇੱਕ ਐਡੀਟਰ ਟੈਬ ਵਿੱਚ ਰੈਂਡਰ ਕਰਦਾ ਹੈ। ਐਂਬੈਡਿੰਗ ਨੂੰ **ਸਰਵਰ ਉੱਤੇ ਚੋਣਵਾਂ ਤੌਰ 'ਤੇ ਸਮਰੱਥ ਕਰਨਾ ਪੈਂਦਾ ਹੈ**, ਜਿਸ ਲਈ `DASHBOARD_ALLOW_EMBED=vscode` ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ। ਇਹ HTML ਪੰਨਿਆਂ ਨੂੰ ਡਿਫਾਲਟ `frame-ancestors 'none'` +
`X-Frame-Options: DENY` ਦੀ ਬਜਾਏ `frame-ancestors 'self' vscode-webview:` ਨਾਲ ਸਰਵ ਕਰਦਾ ਹੈ। API ਸਤ੍ਹਾ (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) ਦੋਵਾਂ ਹਾਲਤਾਂ ਵਿੱਚ ਸਖ਼ਤ ਹੈਡਰ ਬਰਕਰਾਰ ਰੱਖਦੀ ਹੈ।

> ⚠️ **ਇਹ ਬਿਲਡ-ਟਾਈਮ ਫਲੈਗ ਹੈ, ਰਨਟਾਈਮ ਫਲੈਗ ਨਹੀਂ।** Next.js `headers()` ਨੂੰ ਰੂਟ
> ਮੈਨੀਫੈਸਟ ਵਿੱਚ ਕੰਪਾਇਲ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ `next.config.mjs` ਵੇਰੀਏਬਲ ਨੂੰ ਬੰਡਲ ਬਿਲਡ ਹੋਣ ਵੇਲੇ ਪੜ੍ਹਦਾ ਹੈ
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`)।
> ਪਹਿਲਾਂ ਤੋਂ ਬਿਲਡ ਕੀਤੇ ਸਰਵਰ ਦੇ ਅੱਗੇ ਇਸਨੂੰ ਐਕਸਪੋਰਟ ਕਰਨ ਨਾਲ ਕੁਝ ਨਹੀਂ ਬਦਲਦਾ — ਹੈਡਰ ਪਹਿਲਾਂ ਹੀ ਸ਼ਾਮਲ ਕੀਤੇ ਜਾ ਚੁੱਕੇ ਹੁੰਦੇ ਹਨ।

```bash
# ਵੇਰੀਏਬਲ BUILD ਕਮਾਂਡ ਉੱਤੇ ਮੌਜੂਦ ਹੋਣਾ ਲਾਜ਼ਮੀ ਹੈ
DASHBOARD_ALLOW_EMBED=vscode npm run build        # ਜਾਂ npm run build:release
npm start
```
