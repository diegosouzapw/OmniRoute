Elekeza **Claude Code** CLI (`claude`) kwenye OmniRoute — ya ndani au VPS ya mbali —
kwa kutumia wasifu maalumu kwa kila modeli, kwa kuakisi usanidi wa Codex.

---

## Kuanza haraka

```bash
# Zindua Claude Code dhidi ya OmniRoute ya ndani (hutambua muktadha unaotumika kiotomatiki)
omniroute launch

# Dhidi ya OmniRoute ya mbali (baada ya `omniroute connect <host>`, hii hufanyika kiotomatiki)
omniroute launch --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Tengeneza wasifu wa kila modeli, kisha uzindue mmoja
omniroute setup-claude            # huandika ~/.claude/profiles/<name>/settings.json
omniroute launch --profile glm52  # Claude Code ikitumia glm/glm-5.2 kupitia OmniRoute
```

---

## Jinsi Claude Code inavyounganishwa na lango

Claude Code huwasiliana na **Anthropic Messages API** na huelekezwa kwenye endpoint maalumu
kupitia vigezo vya mazingira (haina chaguo la `--base-url`):

| Kigezo                                       | Madhumuni                                                                                            |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `ANTHROPIC_BASE_URL`                         | URL ya msingi ya lango (Claude Code huongeza `/v1/messages`). **Bila kiambishi `/v1`.**              |
| `ANTHROPIC_AUTH_TOKEN`                       | Hutumwa kama `Authorization: Bearer …` — tumia tokeni yako ya ufikiaji / ufunguo wa API wa OmniRoute |
| `ANTHROPIC_API_KEY`                          | Mbadala: hutumwa kama `x-api-key`. Vyote viwekwa, `ANTHROPIC_AUTH_TOKEN` hutangulia                  |
| `ANTHROPIC_MODEL`                            | Lazimisha modeli maalumu (hubatilisha chaguo-msingi la kiteuzi cha `/model`)                         |
| `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY` | `1` → kiteuzi asilia cha `/model` huorodhesha modeli za `claude*`/`anthropic*` kutoka `/v1/models`   |
| `CLAUDE_CODE_MAX_OUTPUT_TOKENS`              | Weka kikomo cha tokeni za matokeo kwa kila jibu (k.m. `65536`)                                       |
| `CLAUDE_CODE_AUTO_COMPACT_WINDOW`            | Kizingiti cha tokeni kwa ajili ya ubanaji wa kiotomatiki                                             |

> Vigezo vya mazingira husomwa **mara moja wakati wa kuanza** — anzisha upya Claude Code baada ya kuvibadilisha.

`omniroute launch` hukuwekea vyote hivi: hutatua URL ya msingi + tokeni
kutoka kwenye muktadha unaotumika (kwa hivyo `omniroute connect <vps>` kisha `omniroute launch`
hufanya kazi moja kwa moja), hukagua afya ya seva, na hutekeleza `claude`.

## Lakabu za ugunduzi — onyesha modeli zisizo za Claude kwenye kiteuzi cha `/model`

Ugunduzi wa modeli za lango wa Claude Code huorodhesha tu vitambulisho vinavyoanza na `claude`
au `anthropic`, kwa hivyo ukiwa na `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`, kiteuzi
asilia cha `/model` kwa kawaida huonyesha **tu** modeli za Claude/Anthropic za OmniRoute — modeli kama
`kimi/kimi-k2.6` au `glm/glm-5.2` haionekani kamwe, ingawa uelekezaji wake hufanya kazi vizuri.

OmniRoute inaweza kuakisi modeli yoyote iliyowezeshwa (na mchanganyiko) chini ya kitambulisho cha `claude/…` ili
ipite kichujio hicho na ionekane kwenye kiteuzi:

```
kimi/kimi-k2.6            →  claude/kimi/kimi-k2.6      "Kimi K2.6 (OmniRoute)"
glm/glm-5.2              →  claude/glm/glm-5.2         "GLM 5.2 (OmniRoute)"
<combo "custo-otimizado"> →  claude/combo/custo-otimizado
```

Unapochagua mojawapo ya hizi katika Claude Code, OmniRoute huondoa kifuniko cha `claude/`
na kurudisha kitambulisho halisi kabla ya kuelekeza — kitambulisho halisi cha `claude/<real-claude-model>`
(mtoa huduma halisi wa Claude OAuth) daima huachwa bila kubadilishwa.

**Hii imezimwa kwa chaguo-msingi** na inadhibitiwa na lango la ngazi tatu (lililo mahususi zaidi
hutangulia), kwa hivyo OmniRoute ya kawaida kamwe hairudufu katalogi yake kwa wateja wasiotumia
Claude Code:

| Ngazi       | Mahali                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------ |
| Modeli      | Ukurasa wa maelezo ya mtoa huduma → swichi ya kila modeli ya "Onyesha katika Claude Code"        |
| Mtoa huduma | Ukurasa wa maelezo ya mtoa huduma → swichi ya ngazi ya mtoa huduma (hujumuisha modeli zake zote) |
| Kimataifa   | Mipangilio → Alama za Vipengele → `EXPOSE_CC_DISCOVERY_ALIASES` (imezimwa kwa chaguo-msingi)     |

Kigezo cha mazingira cha `EXPOSE_CC_DISCOVERY_ALIASES` hulazimisha ngazi ya kimataifa kuwashwa
na hutangulia ubatilishaji wa dashibodi (skrini ya Alama za Vipengele huonyesha
dokezo la "inatumika kupitia kigezo cha mazingira" inapofanya hivyo). Swichi za kila mtoa huduma na
kila modeli huboresha uteuzi kuanzia hapo — k.m. hali ya kimataifa ikiwa imezimwa + mtoa huduma wa Kimi amewashwa huonyesha
modeli za Kimi pekee.

> ⚠️ **Kutolingana kwa dirisha kwenye modeli zisizo za Claude.** Claude Code huchukulia dirisha la muktadha kuwa
> 200K kwa kitambulisho chochote kisichokitambua (haiwezi kusoma ukubwa halisi wa dirisha kutoka
> `/v1/models`). Kwa modeli yenye dirisha kubwa zaidi (k.m. 256K ya Kimi K2), weka
> `CLAUDE_CODE_AUTO_COMPACT_WINDOW` kuwa thamani iliyo chini ya dirisha halisi la modeli ili
> ubanaji wa kiotomatiki usianze mapema. Wasifu uliotengenezwa hapo juu tayari
> hufanya hivi kwa kila modeli.

## Sehemu ya utambulisho kwenye dashibodi

Kadi ya zana ya Claude (**Dashibodi → Msimbo wa CLI**) huonyesha kipande halisi cha `settings.json`
cha instansi hii, karibu na kitufe cha maelezo ya lakabu ya ugunduzi, pamoja na kitufe cha kunakili:

```jsonc
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://<OmniRoute yako>:20128",
    "ANTHROPIC_AUTH_TOKEN": "<ufunguo wako wa API wa OmniRoute>",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
  },
}
```

URL ya msingi ndiyo iliyobainishwa na kadi (ikiwemo thamani maalum ya kubatilisha uliyoandika), na tayari
imesawazishwa — haina kiambishi tamati cha `/v1` wala mfuo wa mwisho. **Ufunguo hauonyeshwi kamwe**: sehemu hiyo hutolewa ikiwa na
kishikilia nafasi, kwa hivyo picha ya skrini au kipande kilichobandikwa hakiwezi kuuvujisha. Bandika ufunguo wako juu yake.

Ongeza `CLAUDE_CODE_AUTO_COMPACT_WINDOW` chini ya sehemu hiyo hiyo ya `env` kwa modeli yoyote ambayo dirisha lake halisi
la muktadha si 200K — Claude Code hudhani kuwa kila kitambulisho kisichotambuliwa kina 200K, kwa hivyo
ufupishaji wa kiotomatiki huanza katika sehemu isiyofaa (angalia onyo katika sehemu iliyotangulia).
Kiunda kipande kinakubali thamani hiyo pia, kwa hivyo mwitaji anayejua ukubwa wa dirisha la modeli lengwa
anaweza kuitoa moja kwa moja.

Chanzo: `src/shared/services/claudeCliConfig.ts::buildClaudeDiscoverySettingsSnippet` (kiunda safi
kilichofanyiwa majaribio ya vitengo) kinachoonyeshwa na `ClaudeGatewayOnboardingBlock`.

## Wasifu (`CLAUDE_CONFIG_DIR`)

Claude Code **haina faili asilia za wasifu** (tofauti na `~/.codex/<name>.config.toml` ya Codex).
Utaratibu unaopendekezwa ni `CLAUDE_CONFIG_DIR` — saraka tofauti ya usanidi kwa kila
wasifu, kila moja ikiwa na `settings.json`, vitambulisho, historia na akiba yake.

`omniroute setup-claude` huleta katalogi ya moja kwa moja ya `/v1/models` na kuandika
wasifu mmoja kwa kila modeli katika `~/.claude/profiles/<name>/settings.json`, huku ikitumia tena
**majina yaleyale kama `setup-codex`** (`glm52`, `kimi-k27`, `deepseek-pro`, …):

```jsonc
// ~/.claude/profiles/glm52/settings.json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "model": "glm/glm-5.2",
  "effortLevel": "xhigh",
  "env": {
    "ANTHROPIC_BASE_URL": "http://192.168.0.15:20128",
    "ANTHROPIC_MODEL": "glm/glm-5.2",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "190000",
  },
}
```

> **Tokeni ya uthibitishaji haiandikwi kamwe kwenye wasifu.** Zindua kwa
> `omniroute launch --profile <name>` (huingiza `ANTHROPIC_AUTH_TOKEN` kutoka kwenye
> muktadha unaotumika), au hamisha `ANTHROPIC_AUTH_TOKEN` mwenyewe na uendeshe
> `CLAUDE_CONFIG_DIR=~/.claude/profiles/<name> claude`.

**Usawazishaji wa kiotomatiki baada ya ugunduzi wa modeli (kwa hiari).** OmniRoute inaweza kuzalisha upya kiotomatiki faili hizi hizi za
`~/.claude/profiles/<name>/settings.json` kila usawazishaji wa modeli za mtoa huduma unapobadilisha katalogi ya moja kwa moja — ili modeli mpya/zilizobadilishwa majina zipate wasifu bila kuendesha tena
amri. Hali hii **imezimwa kwa chaguo-msingi**: iwashwe kutoka kwenye **dashibodi ya Msimbo wa CLI** ("Usawazishaji wa kiotomatiki wa wasifu wa CLI" → Claude Code), au weka `OMNIROUTE_AUTO_SYNC_CLAUDE_PROFILES=true` (pia huzingatia
`CLI_ALLOW_CONFIG_WRITES`, ambayo huwashwa kwa chaguo-msingi). Ikiwashwa, huandika faili za wasifu pekee; haibadilishi kamwe
usanidi unaotumika/chaguo-msingi wa Claude, uthibitishaji, wala `~/.claude/settings.json`.

### Kuzalisha + kutumia wasifu

```bash
# OmniRoute ya ndani
omniroute setup-claude

# VPS ya mbali (hupachika URL ya VPS katika kila wasifu)
omniroute setup-claude --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Baadhi tu ya watoa huduma
omniroute setup-claude --only glm,kimi

# Hakiki bila kuandika
omniroute setup-claude --dry-run

# Zindua wasifu
omniroute launch --profile kimi-k27
```

## Viwango vya modeli (si lazima)

Claude Code huelekeza maombi kwenye viwango vya uwezo. Oanisha kila kiwango na modeli ya OmniRoute kupitia env /
mipangilio ikiwa unataka watoa huduma tofauti kwa kila kiwango:

```bash
export ANTHROPIC_DEFAULT_OPUS_MODEL="glm/glm-5.2"
export ANTHROPIC_DEFAULT_SONNET_MODEL="kmc/kimi-k2.6"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="glm/glm-4.7-flash"
```

Vinginevyo, `ANTHROPIC_MODEL` moja (ambayo wasifu huweka) hutumika kwa kila kitu.

## Hali ya mbali

Baada ya kuendesha `omniroute connect <host>` (angalia
[Hali ya Mbali](./REMOTE-MODE.md)), `omniroute launch` na `omniroute setup-claude`
hulenga seva hiyo ya mbali kiotomatiki na kutumia tokeni yake ya ufikiaji yenye upeo maalum — hakuna
alama za ziada zinazohitajika. Badilisha kwa kila utekelezaji ukitumia `--remote` / `--api-key`.

## Utatuzi wa matatizo

**Claude Code inapuuza lango** — thibitisha kuwa `ANTHROPIC_BASE_URL` **haina
`/v1`** na uanzishe upya `claude` (env husomwa mara moja wakati wa kuanza). `omniroute launch`
hushughulikia hili kwa niaba yako.

**Kiteuzi cha `/model` ni tupu / hakina modeli za lango** — kinahitaji Claude Code
v2.1.219+ na `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`. Ni vitambulisho vya modeli vya `claude*` /
`anthropic*` pekee vinavyoonekana kwenye kiteuzi; lazimisha modeli nyingine yoyote kwa
`ANTHROPIC_MODEL=<id>` (hivi ndivyo wasifu hufanya).

**`400 Ambiguous model 'claude-…'`** — Claude Code daima hutuma vitambulisho vya modeli **visivyo na kiambishi awali**
(k.m. `claude-opus-4-8`), kwa hivyo wakati watoa huduma wa Claude Code (`cc/…`) na
Claude (`claude/…`) wote wameunganishwa, kitambulisho kisicho na kiambishi awali hulingana na njia mbili na
OmniRoute hukataa kukisia. Rekebisha kwa mojawapo ya njia hizi: bainisha kitambulisho chenye kiambishi awali kwa
`ANTHROPIC_MODEL=cc/claude-opus-4-8`, au washa **Pendelea Claude Code kwa
modeli za Claude zisizo na viambishi awali** — swichi kwenye ukurasa wa mtoa huduma wa Claude, au
`OMNIROUTE_PREFER_CLAUDE_CODE_FOR_UNPREFIXED_CLAUDE_MODELS=true` (imezimwa kwa chaguo-msingi;
angalia [Mazingira](../reference/ENVIRONMENT.md)) — ambayo huelekeza vitambulisho vya `claude-*`
visivyo na viambishi awali kwa Claude Code badala yake. Viambishi awali vilivyobainishwa vya watoa huduma hupewa kipaumbele kila wakati.

**Hitilafu za uthibitishaji** — wasifu hauna tokeni. Tumia `omniroute launch --profile`
(huiingiza) au hamisha `ANTHROPIC_AUTH_TOKEN`.

**Wasifu hautengani** — kila wasifu ni `CLAUDE_CONFIG_DIR` tofauti;
thibitisha kuwa `echo $CLAUDE_CONFIG_DIR` ndani ya kipindi inaelekeza kwenye
`~/.claude/profiles/<name>`.
