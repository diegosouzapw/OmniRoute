OmniRoute inapanga watoa huduma 352 wanaotumika katika viwango 3 vya kiuchumi. Kila
ombi hupitia viwango hivyo kwa mpangilio hadi mmoja afanikiwe kutoa jibu — unapata
jibu la gharama nafuu zaidi linalofaa bila kuandika kamwe msimbo wa urejeaji.

## Kiwango cha 1 — Usajili

**Watoa huduma ambao tayari unawalipia.** OmniRoute hutumia kila sehemu ya kiwango chako cha matumizi kabla
hakijaisha muda wake.

| Mtoa huduma                       | Kwa nini ni Kiwango cha 1                                     |
| --------------------------------- | ------------------------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — bei isiyobadilika, mara nyingi haitumiki |
| OpenAI Codex (usajili wa ChatGPT) | Plus/Team inajumuisha kiwango cha matumizi cha Codex          |
| GitHub Copilot                    | Kwa kila nafasi ya mtumiaji — kiwango huwekwa upya kila mwezi |
| Cursor IDE                        | Kiwango cha matumizi cha mpango wa Pro                        |
| Antigravity / Devin Desktop       | Viwango vya matumizi vilivyojumuishwa                         |

**Mkakati**: elekeza hapa kwanza kila ombi linalolingana na uwezo bora wa modeli.
Kifuatiliaji cha kiwango cha matumizi hufuatilia nyakati za uwekaji upya zinazokaribia, na mkakati mseto wa `reset-aware`
huweka vipaumbele ipasavyo. Ili kuelekeza kwenye Kiwango cha 1 kwanza na kuhamia tu
kwenye viwango vinavyolipiwa kiwango cha matumizi kinapoisha, tumia id ya `auto/thrifty` — au `auto/subscription`
ili kubaki kwenye uwezo uliojumuishwa katika mpango na kusitisha ombi ikiwa haupatikani. Angalia
[Uelekezaji unaotanguliza usajili](../routing/SUBSCRIPTION_LADDER.md).

## Kiwango cha 2 — Gharama nafuu

**Watoa huduma wanaolipishwa kwa tokeni chini ya $1/1M ya tokeni.** Huhifadhiwa kwa kazi za kiwango kikubwa
au baada ya viwango vya matumizi vya Kiwango cha 1 kufikia vikomo.

| Mtoa huduma                        | Bei (ingizo/tokeo)   | Uwezo bora                  |
| ---------------------------------- | -------------------- | --------------------------- |
| DeepSeek V4 Pro                    | $0.27 / $1.10 kwa 1M | Msimbo, uchanganuzi         |
| GLM-4.5                            | $0.60 / $2.20 kwa 1M | Muktadha mrefu              |
| MiniMax M1                         | $0.20 / $1.10 kwa 1M | Kasi                        |
| Qwen Coder                         | $0.30 / $1.20 kwa 1M | Msimbo                      |
| OpenRouter (iliyoboreshwa kwa bei) | hutofautiana         | Modeli 100+, zinazobadilika |

**Mkakati**: mkakati mseto wa `cost-optimized` huchagua modeli yenye gharama ya chini zaidi ya $/token inayokidhi
kichujio cha uwezo wa kazi (maono, hali ya JSON, zana, muktadha wa juu zaidi).

## Kiwango cha 3 — Bila malipo

**Watoa huduma wasio na gharama** — viwango vya bure, programu za salio, viwango vya matumizi vya kila siku vya OAuth.

| Mtoa huduma      | Kiwango cha bure / salio                                  |
| ---------------- | --------------------------------------------------------- |
| Kiro AI          | Kiwango cha bure cha Claude (matumizi ya haki ya ukarimu) |
| OpenCode Free    | Hakuna uthibitishaji, vikomo vikubwa vya kasi             |
| Qoder            | OAuth bila malipo                                         |
| Google Vertex AI | Salio la $300 kwa akaunti mpya                            |
| Amazon Q         | Kiwango cha bure kwa watumiaji wa AWS                     |
| Pollinations     | API ya umma iliyo wazi                                    |
| Cloudflare AI    | Kiwango cha bure cha Workers AI                           |

**Mkakati**: mkakati mseto wa `auto` wenye kikomo cha bajeti huelekeza hapa wakati Kiwango cha 1+2 kinaposhindwa
au wakati `useFreeOnly=true` imewekwa. Watoa huduma wa bure mara nyingi huwa na
vikomo vya kasi vilivyo dhaifu zaidi — kizuia hitilafu huwarejesha baada ya muda wa kusubiri.

## Kusanidi viwango

Dashibodi → **Viwango** → gawa watoa huduma wako. Chaguo-msingi (kutoka `tierDefaults.json`) yanafaa;
yahariri unapokuwa na usajili mahususi wa kutanguliza au watoa huduma wa kuondoa.

Mfumo wa ukadiriaji wa vipengele 16 wa Auto-Combo pia huzingatia kiwango. Angalia
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetria

Dashibodi → **Matumizi** huonyesha tokeni zilizotumika kwa kila kiwango kwa siku. Tumia hii ili:

- Kuthibitisha kuwa Kiwango cha 1 kinatumika kikamilifu (vinginevyo unapoteza thamani ya usajili)
- Kutambua modeli za Kiwango cha 2 zinazochaguliwa zaidi (ziunganishe ziwe 1-2)
- Kuthibitisha kuwa Kiwango cha 3 kinaokoa pesa kwenye kazi za majaribio/uchunguzi

## Mifumo ya kawaida

### Kazi ya bure kabisa

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Huelekeza kwa nguvu kwenye Kiwango cha 3; hutumia Kiwango cha 2 tu ikiwa Kiwango cha 3 hakipatikani.

### Usajili kwanza, kisha urejeaji wa gharama nafuu

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Orodha dhahiri iliyopangwa inayolingana na Kiwango cha 1 → Kiwango cha 2 → Kiwango cha 3.
