> **Dashibodi:** Mipangilio → **AI** → Bajeti ya Kufikiri  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **Chanzo:** `open-sse/services/thinkingBudget.ts`

Bajeti ya Kufikiri hudhibiti iwapo OmniRoute **huandika upya vigezo vya kufikiri/kutoa hoja vya mteja** vinapoelekea kwa watoa huduma. **Haiwashi wala kuzima** ufinyazaji, uelekezaji, au akiba ya prompt.

## Modi

| Modi                              | Kile OmniRoute hufanya                                                                                                                | Wakati wa kuitumia                                                                                                                                                                            |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (chaguo-msingi) | Huacha sehemu za mteja bila kuzibadilisha (`reasoning`, `reasoning_effort`, `thinking` ya Claude, `thinking_config` ya Gemini, n.k.). | **Codex / Desktop / mteja yeyote anayepaswa kudhibiti kiwango cha juhudi + mihtasari ya utoaji hoja.** Inahitajika ili paneli za kufikiri zionekane wakati mteja anaomba `reasoning.summary`. |
| **`auto`**                        | **Huondoa sehemu zote** za kufikiri/kutoa hoja kutoka kwenye kiini cha ombi kabla ya kutumwa kwa mtoa huduma.                         | Ni pale tu unapotaka kwa makusudi **mtoa huduma** aunde chaguo-msingi na **huhitaji** kufikiri kunakodhibitiwa na mteja. **Haimaanishi** “onyesha kufikiri kiotomatiki”.                      |
| **`custom`**                      | Hubatilisha kila ombi kwa bajeti isiyobadilika ya tokeni za kufikiri.                                                                 | Kikomo kisichoweza kuzidiwa cha tokeni za kufikiri kwa trafiki yote.                                                                                                                          |
| **`adaptive`**                    | Hurekebisha bajeti kutoka kiwango cha msingi cha juhudi kwa kutumia idadi ya ujumbe, zana, na urefu wa prompt.                        | Udhibiti laini wa tokeni bila kuondoa kabisa kusudio la mteja.                                                                                                                                |

### Kile ambacho `auto` huondoa

Modi ikiwa `auto`, `stripThinkingConfig()` hufuta (pamoja na vingine):

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, na `output_config.effort` inapokuwepo
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

Ikiwa mteja (k.m. Codex Desktop) alituma `reasoning: { effort: "ultra", summary: "detailed" }`, **auto huondoa kipengee hicho**. Mtoa huduma bado anaweza kutoza baadhi ya tokeni za utoaji hoja, lakini mara nyingi hurejesha vipengee vya utoaji hoja **visivyo na maudhui au vilivyosimbwa kwa njia fiche pekee** — hivyo UI haionyeshi mtiririko wowote muhimu wa kufikiri.

## Kile ambacho hii **si**

| Kipengele                                            | Uhusiano                                                                                                                                           |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ufinyazaji** (Caveman, RTK, stacked, …)            | Mchakato tofauti. Hufanya kazi chini ya kila modi ya bajeti ya kufikiri.                                                                           |
| **Akiba ya prompt / kisemantiki**                    | Ni tofauti. Haiathiriwi na modi ya bajeti ya kufikiri.                                                                                             |
| **Uelekezaji mseto / njia mbadala**                  | Ni tofauti. Haiathiriwi.                                                                                                                           |
| **Vikomo vya tokeni za API key / bajeti za gharama** | Ni tofauti. Haiathiriwi.                                                                                                                           |
| **Akiba ya kurudia utoaji hoja**                     | Uingizaji upya wa zamu nyingi kwa watoa huduma wenye masharti makali (DeepSeek, Kimi, Qwen-thinking, …). Si sawa na “onyesha kufikiri” ya Desktop. |
| **Kusimbua `encrypted_content`**                     | **Haiwezekani.** Vipande vya faragha vya utoaji hoja vya OpenAI/Codex havionyeshi yaliyomo. OmniRoute haivisimbui kamwe (#7095 / #7176 / #7304).   |

## Mawazo yanayoonekana (viteja vya Codex / Responses)

Ili kiteja kionyeshe maandishi ya mawazo, unahitaji **yote** yafuatayo:

1. Hali ya Thinking Budget = **`passthrough`** (au custom/adaptive ambayo bado huacha maombi ya muhtasari bila kubadilishwa kiasi cha kutosha kwa njia unayotumia).
2. Kiteja kiombe muhtasari, kwa mfano Codex `model_reasoning_summary = "detailed"` / `auto` (si `none`).
3. Mfumo wa upstream utiririshe `response.reasoning_summary_text.*` (au `reasoning.summary` isiyo tupu kwenye kipengee).

Ukipata tu “mawazo ya faragha yaliyosimbwa”, basi:

- hali ilikuwa **`auto`** (ombi la kiteja liliondolewa), au
- upstream ilirejesha `encrypted_content` bila maandishi ya muhtasari (kizuizi cha mtoa huduma; OmniRoute inaweza kuonyesha tu kishikilia nafasi, si maandishi wazi).

## Mifano ya API

```bash
# Soma
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Inapendekezwa kwa mwonekano wa mawazo katika Codex / Desktop
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Skima (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier` ni za hiari.

### Uhifadhi / kuwasha upya

Thamani huhifadhiwa chini ya ufunguo wa mipangilio `thinkingBudget` na kupakiwa wakati mchakato unapoanza (`hydrateThinkingBudgetConfig`). Baada ya kubadilisha kupitia DB au baadhi ya njia zisizo za API, **washa upya mchakato wa OmniRoute** ili singleton iliyo kwenye kumbukumbu ilingane na data iliyo kwenye diski.

## Orodha hakiki ya mwendeshaji

- [ ] Watumiaji wa Codex / Desktop: hali = **passthrough**
- [ ] Ubanaji uendelee kuwashwa ikiwa unataka kupunguza matumizi ya tokeni kwenye **ujumbe**, si kwa kuondoa mawazo
- [ ] Usitarajie `auto` “kuonyesha mawazo zaidi”
- [ ] Mihtasari iliyosimbwa pekee ni tabia ya **mtoa huduma**; passthrough haiwezi kuisimbua
