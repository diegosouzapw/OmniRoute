## Uondoaji wa Haraka (v3.6.2+)

OmniRoute hutoa hati mbili zilizojengewa ndani kwa ajili ya uondoaji safi:

### Hifadhi Data Yako

```bash
npm run uninstall
```

Hii huondoa programu ya OmniRoute lakini **huhifadhi** hifadhidata, usanidi, funguo za API na mipangilio ya watoa huduma katika `~/.omniroute/`. Tumia hii ikiwa unapanga kusakinisha tena baadaye na ungependa kuhifadhi usanidi wako.

### Uondoaji Kamili

```bash
npm run uninstall:full
```

Hii huondoa programu **na kufuta kabisa** data yote:

- Hifadhidata (`storage.sqlite`)
- Mipangilio ya watoa huduma na funguo za API
- Faili za nakala rudufu
- Faili za kumbukumbu
- Faili zote katika saraka ya `~/.omniroute/`

> ⚠️ **Onyo:** `npm run uninstall:full` haiwezi kutenduliwa. Miunganisho yako yote ya watoa huduma, mikusanyiko, funguo za API na historia ya matumizi vitafutwa kabisa.

## Uondoaji wa Mwongozo

### Usakinishaji wa NPM wa Kimataifa

```bash
# Ondoa kifurushi cha kimataifa
npm uninstall -g omniroute

# (Si lazima) Ondoa saraka ya data
rm -rf ~/.omniroute
```

### Usakinishaji wa pnpm wa Kimataifa

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Simamisha na uondoe kontena
docker stop omniroute
docker rm omniroute

# Ondoa ujazo (hufuta data yote)
docker volume rm omniroute-data

# (Si lazima) Ondoa taswira
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Simamisha na uondoe makontena
docker compose down

# Ondoa pia majazo (hufuta data yote)
docker compose down -v
```

### Programu ya Eneo-kazi ya Electron

**Windows:**

- Fungua `Settings → Apps → OmniRoute → Uninstall`
- Au endesha kiondoaji cha NSIS kutoka kwenye saraka ya usakinishaji

**macOS:**

- Buruta `OmniRoute.app` kutoka `/Applications` hadi kwenye Tupio
- Ondoa data: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Ondoa faili ya AppImage
- Ondoa data: `rm -rf ~/.omniroute`

### Usakinishaji kutoka Chanzo (git clone)

```bash
# Ondoa saraka iliyopachikwa
rm -rf /path/to/omniroute

# (Si lazima) Ondoa saraka ya data
rm -rf ~/.omniroute
```

## Saraka za Data

Kwa chaguomsingi, OmniRoute huhifadhi data katika maeneo yafuatayo:

| Mfumo        | Njia Chaguomsingi                 | Ubatilishaji                              |
| ------------ | --------------------------------- | ----------------------------------------- |
| Linux        | `~/.omniroute/`                   | Kigeu cha mazingira cha `DATA_DIR`        |
| macOS        | `~/.omniroute/`                   | Kigeu cha mazingira cha `DATA_DIR`        |
| Windows      | `%APPDATA%/omniroute/`            | Kigeu cha mazingira cha `DATA_DIR`        |
| Docker       | `/app/data/` (ujazo uliopachikwa) | Kigeu cha mazingira cha `DATA_DIR`        |
| Inayotii XDG | `$XDG_CONFIG_HOME/omniroute/`     | Kigeu cha mazingira cha `XDG_CONFIG_HOME` |

### Faili katika saraka ya data

| Faili/Saraka         | Maelezo                                                         |
| -------------------- | --------------------------------------------------------------- |
| `storage.sqlite`     | Hifadhidata kuu (watoa huduma, mikusanyiko, mipangilio, funguo) |
| `storage.sqlite-wal` | Kumbukumbu ya SQLite ya kuandika mapema (ya muda)               |
| `storage.sqlite-shm` | Kumbukumbu ya pamoja ya SQLite (ya muda)                        |
| `call_logs/`         | Kumbukumbu za maudhui ya maombi                                 |
| `backups/`           | Nakala rudufu za hifadhidata zinazotengenezwa kiotomatiki       |
| `log.txt`            | Kumbukumbu ya zamani ya maombi (si lazima)                      |

## Thibitisha Uondoaji Kamili

Baada ya kusanidua, thibitisha kuwa hakuna faili zozote zilizosalia:

```bash
# Angalia kifurushi cha kimataifa cha npm
npm list -g omniroute 2>/dev/null

# Angalia saraka ya data
ls -la ~/.omniroute/ 2>/dev/null

# Angalia michakato inayoendelea
pgrep -f omniroute
```

Ikiwa mchakato wowote bado unaendelea, usitishe:

```bash
pkill -f omniroute
```
