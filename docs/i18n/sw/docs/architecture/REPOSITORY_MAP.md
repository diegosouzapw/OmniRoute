## `src/` — Programu ya Next.js

```
src/
├── app/                 # App Router (kurasa + njia za API + kurasa za hali + ukurasa wa mwanzo)
├── lib/                 # Maktaba za msingi / moduli za kikoa (sarakasi ndogo 80 + faili ~70 za kiwango cha juu)
├── domain/              # Mantiki halisi ya kikoa (injini ya sera, mbadala, gharama, kufungiwa nje, comboResolver, tathmini)
├── server/              # Moduli za seva pekee (msururu wa authz, cors, middleware ya uthibitishaji) — haziwezi kuingizwa kutoka kwa kiteja
├── shared/              # Hushirikiwa kati ya seva na kiteja inapokuwa salama (thabiti, aina, uthibitishaji, mikataba, zana)
├── i18n/                # Usanidi wa next-intl + JSON ya ujumbe kwa kila lugha (lugha 42)
├── middleware/          # Middleware ya Next.js (uboreshaji wa ombi, utambuzi wa lugha)
├── mitm/                # Kiini cha proksi ya MITM: utengenezaji/usakinishaji wa cheti, vishughulikiaji, malengo, kikaguzi, vinyago, upitishaji wa moja kwa moja
│   ├── handlers/        # Madarasa 9 ya vishughulikiaji vya wakala wa IDE yanayopanua MitmHandlerBase (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # Tabaka la kunasa trafiki: bafa (pete ya ndani ya kumbukumbu), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # Kiunganishi cha adapta ya modeli (shimu ya urithi)
├── scripts/             # Hati za matengenezo ndani ya mti (kwa mfano, backfillAggregation)
├── sse/                 # Vishughulikiaji/huduma za urithi za SSE (chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # Hifadhi ya urithi ya ndani ya kumbukumbu (inaondolewa hatua kwa hatua kwa ajili ya src/lib/db)
├── types/               # Faili za aina za TS zinazoshirikiwa
├── instrumentation.ts   # Kiunganishi cha telemetria cha Next.js (kivinjari + edge)
├── instrumentation-node.ts  # Instrumentation ya Node pekee
└── proxy.ts             # Shimu ya ingizo la proksi ya HTTP
```
