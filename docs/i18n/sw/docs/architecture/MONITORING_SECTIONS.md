## Urambazaji wa Kiwango cha Juu

Upau wa pembeni wa dashibodi (baada ya Kikundi B) una sehemu hizi za kiwango cha juu kwa mpangilio:

```
Nyumbani
Watoa huduma
Mikusanyiko
Funguo za API
Mipangilio
Uchanganuzi
Gharama          ← MPYA (Kikundi B, mpango wa 16)
Ufuatiliaji       ← IMEPANGWA UPYA (Kikundi B, mpango wa 16)
...
```

## Sehemu ya Gharama (mpya, kiwango cha 1)

Kiambishi awali cha njia: `/dashboard/costs/`

| Kipengee          | URL                                  | Maelezo                                                               |
| ----------------- | ------------------------------------ | --------------------------------------------------------------------- |
| Muhtasari         | `/dashboard/costs`                   | Dashibodi ya gharama zilizojumlishwa (imehamishwa kutoka Uchanganuzi) |
| Bei               | `/dashboard/costs/pricing`           | Jedwali la bei kwa kila modeli                                        |
| Bajeti            | `/dashboard/costs/budget`            | Viwango vya bajeti + arifa                                            |
| Kushiriki Mgao    | `/dashboard/costs/quota-share`       | Makundi ya Kushiriki Mgao + matumizi                                  |
| Usanidi wa Mpango | `/dashboard/costs/quota-share/plans` | Mabadiliko ya mpango kwa kila mtoa huduma                             |

**Sababu**: Bei, Bajeti na Kushiriki Mgao hapo awali vilikuwa chini ya
`Ufuatiliaji > Vigezo vya Gharama`. Kuvihamisha hadi sehemu maalumu ya kiwango cha juu
kunafanya viwe rahisi kupatikana bila kupitia zana za uangalizi.

## Sehemu ya Ufuatiliaji (imepangwa upya)

Sehemu ya Ufuatiliaji sasa ina **Shughuli juu** ikifuatiwa na **vikundi vidogo 3**:

```
Ufuatiliaji
├── Shughuli             ← Mlisho wa ratiba ya matukio (kipengee cha kiwango cha juu)
├── Kikundi cha Kumbukumbu
│   ├── Kumbukumbu (zote)
│   ├── Kumbukumbu za Proksi
│   └── Kumbukumbu za Dashibodi
├── Kikundi cha Ukaguzi
│   ├── Kumbukumbu ya Ukaguzi
│   ├── Ukaguzi wa MCP
│   └── Ukaguzi wa A2A
└── Kikundi cha Mfumo
    ├── Afya
    └── Muda wa Utekelezaji
```

### Kilichobadilika kutoka muundo wa zamani

| Kabla                                                                                                 | Baada                                             |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Shughuli = kichupo ndani ya Kumbukumbu kilichoonyesha Kumbukumbu ya Ukaguzi                           | Shughuli = mlisho maalumu (`/dashboard/activity`) |
| Kikundi cha Vigezo vya Gharama katika Ufuatiliaji                                                     | Kimehamishwa hadi sehemu ya Gharama               |
| Orodha bapa: Kumbukumbu, Shughuli (kumbukumbu), Ukaguzi, Afya, Muda wa Utekelezaji, Bei, Bajeti, Mgao | Muundo wa vikundi 3 + sehemu maalumu ya Gharama   |

## Shughuli dhidi ya Kumbukumbu ya Ukaguzi

Hivi viwili sasa ni tofauti:

| Kipimo                     | Shughuli (`/dashboard/activity`)                                                     | Kumbukumbu ya Ukaguzi (`/dashboard/audit`)              |
| -------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| **Madhumuni**              | Mlisho wa matukio kwa watumiaji ("nini kilitokea hivi karibuni")                     | Kumbukumbu ya uzingatiaji / usalama                     |
| **Chanzo cha data**        | `GET /api/compliance/audit-log?level=high`                                           | `GET /api/compliance/audit-log?level=all`               |
| **Muundo**                 | Ratiba ya matukio, iliyopangwa kwa siku, vitenzi vinavyoeleweka na binadamu + aikoni | Jedwali lenye taarifa nyingi na kurasa, 50/ukurasa      |
| **Vichujio**               | Aina ya tukio                                                                        | Kitendo, kiwango cha ukali, mhusika, kipindi cha tarehe |
| **Hamisha**                | Haipatikani                                                                          | Uhamishaji wa JSON                                      |
| **Kichujio cha mhusika**   | Hakihusiki                                                                           | Inaweza kuchujwa kwa mhusika                            |
| **Matukio yanayoonyeshwa** | Vitendo vya kiwango cha juu pekee (orodha ya kuruhusu)                               | Matukio yote ya ukaguzi                                 |

### Orodha ya kuruhusu ya Vitendo vya Kiwango cha Juu

Imefafanuliwa katika `src/lib/audit/highLevelActions.ts`. Inadhibiti matukio
yanayoonekana katika mlisho wa Shughuli. Orodha ya kuruhusu inajumuisha:

- Matukio ya kuongeza/kuondoa/kujaribu mtoa huduma
- Kuunda/kusasisha/kufuta mkusanyiko
- Mzunguko wa maisha wa ufunguo wa API (kuunda, kubatilisha, kuzungusha)
- Kiwango cha bajeti kufikiwa
- Kuingia/kutoka kwenye uthibitishaji
- Uundaji wa kipindi cha wakala wa wingu
- Usajili wa zana ya MCP
- Kuunda/kufuta webhook
- Mabadiliko ya kundi/mpango wa mgao (vitendo vya `quota.*`, Kikundi B)
- Matukio ya jukwaa (kusasisha, kusambaza)
- Kusakinisha/kuondoa ujuzi

Matukio ambayo hayapo katika orodha hii huonekana katika Kumbukumbu ya Ukaguzi pekee.

### Kuongeza kitendo kipya cha kiwango cha juu

Hariri `src/lib/audit/highLevelActions.ts` na uongeze mfuatano wa kitendo kwenye
`HIGH_LEVEL_ACTIONS`. Hili linahitaji PR (orodha ni msimbo, haiwezi kusanidiwa kupitia DB).
Aikoni husika inaweza kuongezwa kwenye `src/lib/audit/activityIcons.ts`.

## Uelekezaji upya: `/dashboard/logs/activity`

Njia ya zamani `/dashboard/logs/activity` inaelekezwa upya kabisa (HTTP 308) kwenda
`/dashboard/activity` kupitia `permanentRedirect()` katika
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

Kitambulisho cha zamani cha upau wa pembeni `logs-activity` kimehifadhiwa katika `HIDEABLE_SIDEBAR_ITEM_IDS`
(lakini kimeondolewa kutoka `SIDEBAR_DEFINITIONS`) ili kuepuka kuvuruga mipangilio ya awali ya watumiaji
inayorejelea kitambulisho cha zamani.
