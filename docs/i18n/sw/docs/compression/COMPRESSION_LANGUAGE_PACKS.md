Mbanizo wa Caveman unaweza kupakia vifurushi vya kanuni mahususi kwa lugha pamoja na kanuni zilizojengewa ndani za Kiingereza.
Hii huweka injini kuu ikiwa thabiti huku ikiruhusu vifurushi vya lugha za Kireno, Kihispania, Kijerumani, Kifaransa, Kiitaliano, Kijapani, na
lugha za baadaye kubadilika kwa kujitegemea.

## Mahali

Vifurushi vya lugha hupatikana chini ya:

```txt
open-sse/services/compression/rules/<language>/
```

Vifurushi vinavyotolewa kwa sasa (vimethibitishwa dhidi ya yaliyomo kwenye saraka ya `rules/`):

| Lugha            | Saraka         | Kategoria za kanuni zilizopo                        |
| ---------------- | -------------- | --------------------------------------------------- |
| Kiingereza       | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Kihispania       | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Kireno (Brazili) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Kiindonesia      | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Kiitaliano       | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Kijerumani       | `rules/de/`    | `context`, `filler`, `structural`                   |
| Kifaransa        | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Kijapani         | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Dokezo la ulinganifu:** Vifurushi vya `en`, `es`, `pt-BR`, `id`, na `it` vina kategoria zote 5; `de`, `fr`, `ja` hutolewa na kategoria 3. Kategoria za `dedup` na `ultra` zinazokosekana hutumia kwa kimya kanuni zilizojengewa ndani za Kiingereza kama mbadala. Michango ya kuongeza `dedup.json` na `ultra.json` kwa vifurushi vidogo inakaribishwa.
>
> Kifurushi cha `pt-BR` kinatokana na **[Troglodita](https://github.com/leninejunior/troglodita)** cha Lenine Júnior — mfumo wa mbanizo uliobuniwa kuanzia mwanzo kwa ajili ya sarufi ya Kireno cha Brazili (upunguzaji wa pleonasimu, uondoaji wa maneno ya kujazia ya PT-BR, vifupisho vya kiufundi kwa jumuiya ya wasanidi programu wa Brazili).
>
> Orodha rasmi ya kategoria na skima ya kila kategoria zinapatikana katika [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (rasimu ya JSON Schema 2020-12).

## Utambuzi wa Lugha

`languageDetector.ts` hutumia mbinu nyepesi za ukadiriaji kutambua lugha kutoka kwenye maandishi ya kidokezo. Lugha chaguomsingi
iliyosanidiwa bado huheshimiwa, na utambuzi unaweza kuzimwa kupitia usanidi wakati udhibiti kamili
unahitajika.

Matokeo ya utambuzi hutumiwa tu kuchagua vifurushi vya kanuni. Hayabadilishi uelekezaji wa mtoa huduma, uteuzi
wa lugha na eneo, wala lugha ya kiolesura.

## Muundo wa Usanidi

Mipangilio ya mbanizo inaweza kujumuisha:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` hudhibiti chaguomsingi za dashibodi/mwonekano wa awali. `cavemanConfig` ni usanidi wa injini wakati wa utekelezaji
unaotumiwa Caveman inapobana maandishi ya ujumbe.

## Kuongeza Kifurushi cha Lugha

1. Unda `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Tumia muundo wa kanuni za Caveman kutoka `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Hakikisha vibadilisho ni vya tahadhari na uepuke kubadilisha msimbo, vitambulishi, URL, au JSON.
4. Ongeza au sasisha majaribio ya uteuzi wa lugha na tabia ya ubadilishaji.
5. Onyesha lebo mpya za dashibodi/i18n ikiwa lugha hiyo inaonekana katika viteuzi vya UI.

## API

Vifurushi vinavyopatikana vinaweza kuulizwa kwa:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Endpoint ya uhakiki wa awali inakubali ubatilishaji wa usanidi wa lugha:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Vifurushi vyote 6 vya lugha vilipokea kifungu cha `SHARED_BOUNDARIES` katika v3.8.0 ambacho hutumika katika kila
kiwango cha Caveman (LITE, FULL, ULTRA). Kinaelekeza injini kuhifadhi ruwaza hizi bila mabadiliko,
bila kujali uondoaji wa maneno ya kujazia yanayozizunguka:

| Aina ya ruwaza                  | Mfano                                  |
| ------------------------------- | -------------------------------------- |
| Vitalu vya msimbo vyenye uzio   | ` ```python\n...\n``` `                |
| Msimbo wa ndani ya mstari       | `` `my_var` ``                         |
| URL                             | `https://example.com/path`             |
| Njia za faili (kamili + jamaa)  | `/etc/hosts`, `./src/index.ts`         |
| Vichwa vya hitilafu             | `Error:`, `TypeError:`, `SyntaxError:` |
| Mistari ya ufuatiliaji wa staki | `  at functionName (file.ts:12:3)`     |

Ruwaza hizi hujazwa katika `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (hapo awali `[]`). Konstanti hiyo
inapatikana katika `open-sse/services/compression/types.ts`.

### Kwa nini hili ni muhimu

Bila SHARED_BOUNDARIES, hali kali za Caveman zingeweza kuondoa maudhui yaliyoonekana kama maandishi
yanayojirudia lakini kwa kweli yalikuwa kijisehemu cha msimbo, njia ya faili, au staki ya hitilafu. SHARED_BOUNDARIES hufanya kazi kama
wavu wa usalama usiotegemea lugha unaotumika kabla ya kanuni za maneno ya kujazia kuendeshwa.

### Kubinafsisha preservePatterns

Ruwaza za ziada zinaweza kuongezwa wakati wa utekelezaji kupitia mipangilio ya mgandamizo:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Ruwaza maalum hupanua (hazibadilishi) ruwaza 6 chaguomsingi.

## Maelezo ya Uendeshaji

- Kanuni zilizojengewa ndani za Kiingereza husalia kuwa chaguo mbadala wakati kifurushi cha lugha hakipo.
- Vifurushi batili vya JSON vilivyojengewa ndani hushindwa katika uthibitishaji ili rasilimali za toleo zisipunguze ubora kimyakimya.
- Vifurushi vya kanuni ni vya data pekee na havipaswi kuleta msimbo au kutekeleza mantiki yoyote kiholela.
- Safu ya uchanganuzi wa mgandamizo hurekodi hali na injini iliyochaguliwa, si maandishi kamili ya prompt.
