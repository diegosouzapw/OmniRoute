Watoa huduma wa Web Cookie huiwezesha OmniRoute kutumia huduma ya AI kupitia kipindi chako kilichopo cha kivinjari badala ya API key. Wanafaa unapotumia tayari huduma kupitia tovuti yake na unataka OmniRoute itumie kipindi hicho hicho kilichothibitishwa.

Tofauti na watoa huduma wanaotumia API key, watoa huduma wa Web Cookie huthibitisha utambulisho kwa kutumia vitambulisho ambavyo kivinjari chako hutuma kwenye tovuti.

---

# Kabla Hujaanza

> **Muhimu:** Nakili vitambulisho kila wakati kutoka kwenye **ombi la moja kwa moja la mtandao**, **si** kutoka kwenye hifadhi ya cookie ya kivinjari chako.

Matatizo mengi ya uthibitishaji husababishwa na kunakili cookie kutoka mahali pasipofaa.

## USINAKILI kutoka kwenye Hifadhi ya Cookie

Vivinjari vingi huonyesha cookie zilizohifadhiwa kupitia:

```
DevTools
→ Application (au Storage)
→ Cookies
```

Ingawa cookie hizi zinaweza kuonekana kuwa sahihi, huenda zikawa:

- zimepitwa na wakati
- hazijakamilika
- hazina cookie zinazotumwa tu katika maombi yaliyothibitishwa

Kutumia thamani hizi kunaweza kusababisha uthibitishaji ushindwe hata kama zinaonekana kuwa halali.

## Nakili kutoka kwenye Ombi la Moja kwa Moja

Badala yake, tumia cookie kutoka kwenye ombi lililofanikiwa:

```
DevTools
→ Network
→ Onyesha upya ukurasa
→ Fungua ombi la gumzo au mazungumzo
→ Request Headers
→ Cookie
```

Kichwa cha ombi cha `Cookie` kina taarifa kamili za uthibitishaji ambazo kivinjari chako kilitumia kwa mafanikio.

Kwa watoa huduma wengi wa Web Cookie, hii ndiyo thamani inayopaswa kubandikwa kwenye OmniRoute.

---

# Usanidi wa Jumla

Mchakato wa usanidi ni sawa kwa watoa huduma wengi wa Web Cookie.

1. Ingia kwenye tovuti ya mtoa huduma.
2. Fungua Zana za Wasanidi Programu za kivinjari.
3. Fungua kichupo cha **Network**.
4. Onyesha upya ukurasa.
5. Fungua ombi lililothibitishwa la gumzo au mazungumzo.
6. Nakili vitambulisho vinavyohitajika vya uthibitishaji.
7. Fungua OmniRoute.
8. Nenda kwenye **Providers → Add Provider**.
9. Chagua mtoa huduma wako wa Web Cookie.
10. Bandika vitambulisho.
11. Bofya **Test Connection**.
12. Hifadhi mtoa huduma.

Vitambulisho kamili vinavyohitajika hutegemea mtoa huduma.

# Mambo Ambayo Watoa Huduma wa Web Cookie Wanaweza na Hawawezi Kufanya

Watoa huduma wa Web Cookie hutumia tena kiolesura cha gumzo cha tovuti. **Hawatoi** uwezo sawa na API rasmi.

## Yanayotumika

- Kuthibitisha utambulisho kwa kutumia kipindi chako kilichopo cha kivinjari
- Kufikia modeli zinazopatikana kupitia akaunti yako
- Kutiririsha majibu ya gumzo
- Hakuna API key inayohitajika

## Yasiyotumika

- Uitaji wa vitendaji
- Uitaji wa zana
- Uhariri wa faili kiotomatiki
- Mitiririko ya kazi ya IDE inayoendeshwa na ajenti
- Vipengele vinavyopatikana kupitia API pekee

Hii ni tabia inayotarajiwa na **si** hitilafu.

Ikiwa unahitaji utekelezaji wa zana, uhariri wa faili kiotomatiki, au mitiririko mingine ya kazi ya ajenti, tumia **mtoa huduma wa API key** badala ya mtoa huduma wa Web Cookie.

---

# Tahadhari Kuhusu Uthibitishaji

**Test Connection** iliyofanikiwa au uthibitishaji wa cookie huthibitisha tu kwamba vitambulisho vilivyotolewa vinaonekana kuwa katika muundo unaotarajiwa.

Hadi Issue #7857 itakapotatuliwa, uthibitishaji uliofanikiwa **hauhakikishi** kwamba mtoa huduma atathibitisha utambulisho kwa mafanikio.

Ikiwa uthibitishaji bado unashindwa, hakikisha kuwa ulinakili vitambulisho kutoka kwenye ombi la moja kwa moja la mtandao badala ya hifadhi ya cookie ya kivinjari.

---

# Utatuzi wa Matatizo

## Uthibitishaji Unashindwa

Hakikisha kuwa vitambulisho vilinakiliwa kutoka:

```
Network
→ Request Headers
→ Cookie
```

na **si** kutoka:

```
Application
→ Cookies
```

---

## Cookie Inafanya Kazi Kwenye Kivinjari lakini Si Kwenye OmniRoute

Baadhi ya watoa huduma hujumuisha cookie ambazo hutumwa tu wakati wa maombi yaliyothibitishwa.

Nakili upya vitambulisho kutoka kwenye ombi jipya la mtandao baada ya kufungua mazungumzo kwa mafanikio.

---

## Kipindi Kimeisha

Watoa huduma wa Web Cookie hutumia kipindi chako kilichopo cha kivinjari.

Kipindi chako cha kivinjari kikiisha au ukitoka kwenye akaunti, lazima unakili seti mpya ya vitambulisho.

---

## Test Connection Inafaulu lakini Maombi Yanashindwa

Hadi Issue #7857 itakapotatuliwa, kufaulu uthibitishaji hakuhakikishi kwamba ombi la uthibitishaji litafanikiwa.

Nakili upya vitambulisho vyako kutoka kwenye ombi jipya lililothibitishwa kabla ya kuendelea na utatuzi wa matatizo.

# Mbinu Bora

- Nakili vitambulisho kutoka kwenye ombi jipya lililothibitishwa.
- Epuka kutumia tena cookie za zamani.
- Dumisha kipindi chako cha kivinjari kikiwa hai unapotumia watoa huduma wa Web Cookie.
- Chukulia cookie zilizonakiliwa kama vitambulisho nyeti.
- Tumia watoa huduma wa API key unapohitaji uitaji wa vitendaji au mitiririko ya kazi ya ajenti.
