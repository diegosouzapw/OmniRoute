## Hatua ya 1: Sakinisha OmniRoute

Chagua njia unayopendelea:

### Chaguo A: npm (Inapendekezwa)

```bash
npm install -g omniroute
```

### Chaguo B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` ndiyo SemVer thabiti ya juu zaidi **iliyochapishwa**. Haifuatilii git `main`. Bainisha `diegosouzapw/omniroute:X.Y.Z` kwa GitOps. Tazama [Lebo za Image / Vituo vya Matoleo](../guides/DOCKER_GUIDE.md#release-channels).

### Chaguo C: Kutoka kwenye Msimbo Chanzo

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Hatua ya 2: Anzisha OmniRoute

```bash
omniroute
```

OmniRoute huanza kwenye `http://localhost:20128`. Dashibodi hufunguka kiotomatiki.

---

## Hatua ya 3: Unganisha Mtoa Huduma wa Bure

Unaweza kutumia OmniRoute **bila kulipa chochote** kwa kuunganisha mtoa huduma wa bure.

### Chaguo A: Kiro (Claude ya Bure — Hakuna Kadi ya Malipo)

1. Fungua dashibodi kwenye `http://localhost:20128`
2. Nenda kwenye **Watoa Huduma** → **Ongeza Mtoa Huduma**
3. Chagua **Kiro AI**
4. Bofya **Unganisha** (ufunguo wa API hauhitajiki!)
5. Imekamilika! Sasa unaweza kutumia modeli za Claude bila malipo.

### Chaguo B: OpenCode Free (Hakuna Uthibitishaji)

1. Fungua dashibodi kwenye `http://localhost:20128`
2. Nenda kwenye **Watoa Huduma** → **Ongeza Mtoa Huduma**
3. Chagua **OpenCode Free**
4. Bofya **Unganisha** (ufunguo wa API hauhitajiki!)
5. Imekamilika! Sasa unaweza kutumia modeli nyingi bila malipo.

### Chaguo C: Pollinations (Ufunguo Hauhitajiki)

1. Fungua dashibodi kwenye `http://localhost:20128`
2. Nenda kwenye **Watoa Huduma** → **Ongeza Mtoa Huduma**
3. Chagua **Pollinations**
4. Bofya **Unganisha** (ufunguo wa API hauhitajiki!)
5. Imekamilika! Sasa unaweza kutumia GPT-5, Claude, Gemini na nyingine zaidi bila malipo.

---

## Hatua ya 4: Thibitisha Kuwa Inafanya Kazi

Kutoka kwenye [Funguo za API](http://localhost:20128/dashboard/api-manager), tengeneza ufunguo mpya. Hifadhi ufunguo huu kwa sababu hautaonekana tena. Kumbuka kwamba ufunguo huu ni wa kuruhusu zana kufikia OmniRoute, si kufikia watoa huduma wa ngazi ya juu.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Unapaswa kuona modeli ulizounganisha zikiwa zimeorodheshwa.

## Hatua ya 5: Elekeza IDE au CLI Yako kwa OmniRoute

Katika IDE au zana yako ya CLI, weka:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

Ni hayo tu! Sasa IDE yako inatumia OmniRoute pamoja na uteuzi wa kiotomatiki wa mtoa huduma.

### Mfano wa IDE: VSCode/Continue.dev

1. Katika VSCode, sakinisha kiendelezi cha [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Sasisha `~/.continue/config.yaml` yako ili kuongeza mistari ifuatayo:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Katika kidirisha cha gumzo cha Continue.dev, chagua `OmniRoute - Auto` na utatuma maombi kwa OmniRoute.
4. (Si lazima) Zoezi kwa msomaji—ruhusu IDE yako isasishe `config.yaml` kwa usanidi mwingine wote uliotayarishwa mapema 😊

### Mfano wa CLI: Codex CLI

1. Katika mfumo wako wa uendeshaji, weka kigeu cha mazingira kwa kudumu.
   Kwa macOS/Linux (ongeza kwenye `~/.bashrc` au `~/.zshrc` yako):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Kwa Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Sasa tuanzishe Codex, lakini ikiwa imesanidiwa kwa ajili ya OmniRoute. Tekeleza:

```
omniroute launch-codex --model auto
```

Unaweza kufanya hivi mwenyewe kupitia `codex` na vigezo vya mstari wa amri ili kubainisha endpoint na ufunguo wa API, lakini kwa amri iliyo hapo juu, OmniRoute hushughulikia kila kitu kwa niaba yako.

Uzinduzi huo huo wa amri moja hufanya kazi kwa CLI nyingine kupitia kizinduzi cha jumla—`omniroute run <target>` hutumia `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` na `gemini` (tazama [Miunganisho ya CLI](../guides/CLI-INTEGRATIONS.md)).

3. Sasa CLI inapaswa kuwa inatuma maombi kwa OmniRoute.

### Thibitisha kuwa zana yako inaelekeza maombi kwa OmniRoute

Unaweza kuona maelezo ya ombi kwa kubofya [Ufuatiliaji/Kumbukumbu](http://localhost:20128/dashboard/logs) kutoka kwenye utepe wa kushoto. Ukibofya zaidi utaona maelezo ya ziada. Pia, unaweza kuona taarifa zinazotumwa kutoka kwenye harness unayoipendelea. Hili ni muhimu kwa madhumuni ya kujifunza na utatuzi.

## Maswali ya Kawaida

### "Je, ninahitaji ufunguo wa API?"

**Hapana!** Unaweza kutumia watoa huduma wa bure (Kiro, OpenCode Free, Pollinations) bila ufunguo wowote wa API. Waunganishe tu kwenye dashibodi.

### "`auto` ni nini?"

`auto` huiambia OmniRoute ichague kiotomatiki mtoa huduma bora zaidi kwa kila ombi. Huzingatia kasi, gharama, ubora na upatikanaji. Tazama [Mwongozo wa Auto-Combo](./AUTO-COMBO-GUIDE.md) kwa maelezo.

### "Inagharimu kiasi gani?"

OmniRoute yenyewe ni **ya bure na ya chanzo huria**. Unalipia tu watoa huduma unaotumia. Watoa huduma wengi wana viwango vya bure—tazama [Mwongozo wa Viwango vya Bure](./FREE-TIERS-GUIDE.md).

### "Je, ninaweza kuitumia na Claude Code / Cursor / Copilot?"

**Ndiyo!** OmniRoute hufanya kazi na zana yoyote inayotumia muundo wa OpenAI. Weka tu URL ya msingi kuwa `http://localhost:20128/v1`. Tazama [Mwongozo wa Zana za CLI](../reference/CLI-TOOLS.md) kwa maelekezo mahususi ya usanidi.

### "Itakuwaje ikiwa mtoa huduma hatapatikana?"

OmniRoute huwaruka kiotomatiki watoa huduma walioshindwa na kujaribu anayefuata. Huhitaji kufanya chochote. Tazama [Mwongozo wa Auto-Combo](./AUTO-COMBO-GUIDE.md) kwa maelezo.
