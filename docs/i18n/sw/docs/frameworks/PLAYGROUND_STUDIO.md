## Muhtasari

Playground Studio inabadilisha `/dashboard/playground` kutoka kihariri rahisi kinachotumia Monaco kuwa
eneo kamili la kazi la majaribio. Inachukua nafasi ya `page.tsx` ya zamani kwa ganda la `PlaygroundStudio`
linaloonyesha vichupo vinne na kidirisha cha usanidi kinachoshirikiwa.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Gumzo] [⚖ Linganisha] [{} API] [🔧 Unda]  142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {maudhui ya kichupo kinachotumika}      │ ─ Usanidi                 │
│                                          │ Endpoint  [chat ∨]        │
│                                          │ Model     [gpt-5.4 ∨]     │
│                                          │ Mfumo     [textarea]      │
│                                          │ Temp      ▕▕▔▔ 0.7        │
│                                          │ Mipangilio [▾ pakia][hifadhi] │
│                                          │ [✨ Boresha prompt]        │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Vichupo

### Kichupo cha Gumzo

Kinaboresha `ChatPlayground.tsx` kuwa sehemu ya kazi ya utiririshaji wa mazungumzo yenye zamu nyingi:

- Uonyeshaji kamili wa markdown kupitia `MarkdownMessage.tsx` (vitalu vya msimbo, majedwali, orodha, viungo).
- Prompt ya mfumo inayotoka kwenye kidirisha cha Usanidi kinachoshirikiwa.
- Tokeni/gharama kwa kila ujumbe (tokeni za prompt + ukamilishaji).
- Tengeneza upya jibu la mwisho.
- Hutuma kwa `POST /v1/chat/completions` kwa utiririshaji wa SSE.

### Kichupo cha Kulinganisha

Kipengele kikuu kinachotofautisha proksi: endesha prompt 1 kwenye hadi **modeli 4 kwa wakati mmoja**.

- Hadi safu wima 4, kila moja ikitiririsha kivyake kutoka `/v1/chat/completions`.
- Kitufe cha `+ Ongeza modeli` (njia ya mkato ya Cmd+K) cha kuongeza safu wima.
- `Endesha zote ▶` huanzisha mitiririko yote kwa wakati mmoja kupitia `Promise.all` + `AbortController` kwa kila safu wima.
- Kitufe cha jumla cha **Ghairi zote** husitisha kila mtiririko unaoendelea.
- `ProviderMetrics` ya kila safu wima huonyesha TTFT, TPS, tokeni na makadirio ya gharama katika muda halisi.
- Vipimo vimewekewa lebo **"makadirio ya upande wa mteja"** (D12) — hupimwa kuanzia kipande cha kwanza cha SSE.

### Kichupo cha API

Kinahifadhi 100% ya kihariri asili cha Monaco kwa watumiaji mahiri (D14):

- Endpoint 10: ukamilishaji wa gumzo, ukamilishaji, embeddings, picha, sauti, matamshi, unukuzi, udhibiti wa maudhui, upangaji upya na utafutaji.
- Upakiaji wa faili za aina nyingi za media.
- Utiririshaji wa SSE wenye matokeo ya muda halisi.
- Kimefungwa kama `ApiTab.tsx` (hupakiwa inapohitajika, `ssr: false`).

### Kichupo cha Kuunda

UI ya tools/function calling na matokeo yenye muundo:

- `ToolsBuilder.tsx` — ongeza/hariri/ondoa `tools[]` kwa kutumia kihariri cha schema ya JSON kwa kila zana.
  Huthibitisha parameters kupitia `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — washa/zima hali ya JSON + kihariri cha schema ya JSON.
  Huthibitisha response dhidi ya schema kupitia `StructuredOutputSchema` (Zod).
- Hutuma ombi kwa `/v1/chat/completions` likiwa na `tools[]` na/au `response_format`.

## Paneli ya Usanidi (Inayoshirikiwa)

`StudioConfigPane.tsx` — huonekana kila wakati, inaweza kukunjwa.

| Sehemu             | Kijenzi               | Maelezo                                                                        |
| ------------------ | --------------------- | ------------------------------------------------------------------------------ |
| Endpoint           | `<select>`            | chaguo 10 zinazolingana na `PlaygroundEndpoint`                                |
| Modeli             | `<input>`             | maandishi huru, k.m. `openai/gpt-4o`                                           |
| Kidokezo cha mfumo | `<textarea>`          | huingizwa kwenye vichupo vyote                                                 |
| Vigezo             | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop         |
| Mipangilio awali   | `PresetPicker`        | pakia/hifadhi vijipicha vya usanidi vilivyopewa majina (huhifadhiwa katika DB) |
| Boresha kidokezo   | `ImprovePromptButton` | hufungua modali ya onyo la mgao, huita `/api/playground/improve-prompt`        |

Hali huinuliwa hadi `PlaygroundStudio.tsx` na kupitishwa kwa vichupo vyote. Kubadilisha vichupo
huhifadhi hali ya usanidi.

## Upau wa Juu

`StudioTopBar.tsx`:

- Kibadilisha vichupo (role="tablist").
- `TokenCostCounter` — onyesho la moja kwa moja la tokeni (↑/↓) na gharama iliyokadiriwa.
- Kitufe cha kuhamisha msimbo (`</>`) — hufungua `ExportCodeModal`.

## Modali ya Kuhamisha Msimbo

`ExportCodeModal.tsx` hutumia `codeExport.ts` kutengeneza vijisehemu vya curl / Python / TypeScript
kutoka kwenye `PlaygroundState` ya sasa. Kishikilia nafasi cha ufunguo wa API huwa `$OMNIROUTE_API_KEY` kila wakati (D11).

---

## Kiboresha Kidokezo

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Modali huonya kuwa "itatumia mgao".
2. Baada ya kuthibitisha, hutuma `{ system, prompt, model, tone }` kwa route.
3. Route huita `/v1/chat/completions` kwa ndani kwa kutumia `promptImprover.META_SYSTEM_PROMPT`.
4. Hurejesha `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. UI husasisha kidokezo cha mfumo cha paneli ya Usanidi na kidokezo cha mtumiaji cha kichupo cha Gumzo.

---

## Mipangilio Awali

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Huhifadhiwa katika jedwali la SQLite la `playground_presets` (uhamishaji `084_playground_presets.sql`).
- Kila mpangilio awali huhifadhi: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: orodha ya `GET`, uundaji wa `POST`, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Vipimo vya Utiririshaji

`useStreamMetrics.ts` + `streamMetrics.ts` (kitendakazi kisicho na athari):

- `start()` — hurekodi wakati ombi lilipoanza.
- `onFirstChunk()` — hurekodi TTFT.
- `onChunk(n)` — hukusanya idadi ya tokeni za ukamilishaji.
- `finish(usage?)` — hukokotoa vipimo vya mwisho: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Bei kutoka kwenye jedwali tuli katika `src/lib/playground/types.ts` (limewekewa lebo "imekadiriwa" — D13).

## Route za Backend

| Mbinu    | Njia                             | Kishughulikiaji                                                                                 |
| -------- | -------------------------------- | ----------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | Huthibitisha `ImprovePromptRequestSchema` kwa Zod; huita `/v1/chat/completions` kwa meta-prompt |
| `GET`    | `/api/playground/presets`        | Hurejesha `{ presets: PlaygroundPresetListItem[] }`                                             |
| `POST`   | `/api/playground/presets`        | Huunda mpangilio awali; huthibitisha `PlaygroundPresetCreateSchema`                             |
| `GET`    | `/api/playground/presets/:id`    | Hurejesha mpangilio mmoja awali au 404                                                          |
| `PUT`    | `/api/playground/presets/:id`    | Usasishaji wa sehemu                                                                            |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                             |

Uthibitishaji: wa hiari (`REQUIRE_API_KEY`). Hitilafu kupitia `buildErrorBody()` (Kanuni Kali #12).
