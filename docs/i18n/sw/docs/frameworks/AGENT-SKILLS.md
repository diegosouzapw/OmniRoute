> **Chanzo rasmi:** `src/lib/agentSkills/` (katalogi, jenereta, vichanganuzi) + saraka ya `skills/` (faili za SKILL.md)
> **Ilisasishwa mara ya mwisho:** 2026-08-02 — v3.8.50

Agent Skills ni faili za SKILL.md zilizopangwa ambazo hufundisha mawakala wa nje, wateja wa MCP, na waratibu wa A2A jinsi ya kutumia REST API na CLI ya OmniRoute. Tofauti na [Omni Skills](./SKILLS.md) (ambazo ni ufafanuzi wa zana za LLM unaotekelezwa ndani ya OmniRoute), Agent Skills ni _katalogi ya nyaraka_ — markdown tuli inayoweza kuingizwa moja kwa moja katika muktadha wa wakala.

---

## Muhtasari

Katalogi ina **Agent Skills 45** (23 za REST API + 21 za CLI + 1 ya mtiririko wa usanidi). Kila skill ina:

- **Kitambulisho rasmi** (`omni-auth`, `cli-serve`, n.k.)
- Faili ya **SKILL.md** katika `skills/{id}/SKILL.md` yenye YAML frontmatter (`name`, `description`) + maudhui ya kina ya markdown
- **Vituo vya REST** (skills za API) au **amri ndogo za CLI** (skills za CLI) vinavyotokana na vipimo vya OpenAPI na sajili ya CLI
- **URL ghafi ya GitHub** kwa uchukuaji wa moja kwa moja: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Ugunduzi wa REST API

| Endpoint                     | Mbinu | Maelezo                                                                | Uthibitishaji |
| :--------------------------- | :---- | :--------------------------------------------------------------------- | :------------ |
| `/api/agent-skills`          | GET   | Orodhesha katalogi (`?category=api\|cli\|config&area=<area>` ni hiari) | hakuna        |
| `/api/agent-skills/{id}`     | GET   | Pata metadata ya ujuzi mmoja                                           | hakuna        |
| `/api/agent-skills/{id}/raw` | GET   | Pakua SKILL.md kama `text/markdown`                                    | hakuna        |
| `/api/agent-skills/coverage` | GET   | Takwimu za ufunikaji (idadi ya faili za SKILL.md zilizopo)             | hakuna        |
| `/api/agent-skills/generate` | POST  | Anzisha jenereta (dryRun/prune/onlyIds)                                | usimamizi     |

Mfano — orodhesha ujuzi wote wa API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Mfano — pakua SKILL.md moja:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Jinsi Mawakala wa Nje Wanavyotumia Ujuzi

### 1. Ugunduzi kupitia REST

```bash
# Pata katalogi kamili
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Pata SKILL.md kwa ajili ya kuingiza muktadha
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Ugunduzi kupitia MCP

```typescript
// Katika kiteja cha Claude Desktop / Cursor MCP:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → safu ya AgentSkill yenye rawUrl kwa kila moja
```

### 3. Ugunduzi kupitia A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table ni jedwali la markdown lenye vitambulisho vyote 45 vya ujuzi pamoja na safu wima za rawUrl
```

### 4. Upakuaji wa moja kwa moja wa faili ghafi kutoka GitHub (seva haihitajiki)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Kizalishaji

Kizalishaji husoma katalogi iliyoratibiwa pamoja na vipimo vya OpenAPI na sajili ya CLI, kisha huandika `skills/{id}/SKILL.md` kwa kila ingizo:

```bash
# Hakiki (utekelezaji wa majaribio, hakuna kinachoandikwa)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Uzalishaji upya kamili
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Zalisha upya vitambulisho mahususi
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Jibu la kizalishaji ni `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
