> **Kwa ufupi**: ACP huiwezesha OmniRoute kuanzisha mawakala wa CLI (kama Claude Code, Codex) kama michakato-toto badala ya kutumia API za HTTP. Hii hukupa usafirishaji wa "CLI-kama-backend".

---

## ACP Ni Nini?

ACP (Agent Client Protocol) ni usafirishaji wa **"CLI-kama-backend"** kwa OmniRoute. Badala ya kunasa miito ya API ya HTTP kwenda kwa watoa huduma za AI, ACP **huanzisha mawakala wa CLI kama michakato-toto** na kupitisha maagizo kupitia kiolesura chao asilia.

### Kwa Nini Utumie ACP?

| Faida                        | Maelezo                                                   |
| ---------------------------- | --------------------------------------------------------- |
| **Hakuna funguo za API**     | Hutumia uthibitishaji wako uliopo wa CLI                  |
| **Itifaki asilia**           | Hutumia umbizo asilia la ingizo/tokeo la kila CLI         |
| **Ugunduzi wa kiotomatiki**  | Hugundua CLI zilizosakinishwa kwenye mfumo wako           |
| **Mawakala 15 waliojengewa** | Wamesanidiwa mapema kwa zana maarufu za CLI               |
| **Mawakala maalum**          | Ongeza zana zako za CLI kupitia mipangilio                |
| **Usimamizi wa michakato**   | Hushughulikia mzunguko wa maisha (anzisha, tuma, sitisha) |

## Jinsi ACP Inavyofanya Kazi

### Usanifu

```
┌─────────────────┐
│  OmniRoute      │
│  (Proksi ya HTTP)│
└────────┬────────┘
         │
         │ spawn()
         ▼
┌─────────────────┐
│  Mchakato-toto  │
│  (Wakala wa CLI)│
│                 │
│  stdin  ◄──────┤  Tuma maagizo
│  stdout ──────►│  Pokea jibu
│  stderr ──────►│  Pokea hitilafu
└─────────────────┘
```

### Mzunguko wa Maisha wa Mchakato

1. **Kuanzisha** — ACP huunda mchakato-toto kwa ajili ya wakala wa CLI
2. **Kutuma** — ACP huandika maagizo kwenye stdin ya mchakato
3. **Kupokea** — ACP husoma majibu kutoka stdout/stderr
4. **Ugunduzi wa Kutokuwa na Shughuli** — ACP husubiri sekunde 2 bila shughuli kabla ya kuzingatia jibu kuwa limekamilika
5. **Kusitisha** — ACP husitisha mchakato (SIGTERM, kisha SIGKILL baada ya sekunde 5)

### Itifaki ya Mawasiliano

ACP hutumia **stdio** (ingizo/tokeo la kawaida) kuwasiliana na mawakala wa CLI. Itifaki ni:

1. **Tuma maagizo** — Andika kwenye stdin pamoja na mstari mpya
2. **Subiri jibu** — Soma kutoka stdout hadi kutokuwa na shughuli (sekunde 2 bila tokeo)
3. **Muda wa kusubiri kuisha** — Chaguo-msingi ni sekunde 120 (inaweza kusanidiwa)

## Marejeleo ya API

### Vitendakazi vya Sajili

#### `detectInstalledAgents()`

Hutambua mawakala wote wa CLI waliosakinishwa kwenye mfumo. Matokeo huhifadhiwa kwenye akiba kwa sekunde 60.

```typescript
import { detectInstalledAgents } from "@/lib/acp";

const agents = detectInstalledAgents();
// Hurejesha: CliAgentInfo[]

interface CliAgentInfo {
  id: string; // k.m., "codex", "claude"
  name: string; // Jina la kuonyeshwa
  binary: string; // Jina la faili tekelezi litakaloanzishwa
  versionCommand: string; // Amri ya kutambua toleo
  version: string | null; // Toleo lililotambuliwa (null ikiwa haijasakinishwa)
  installed: boolean; // Ikiwa wakala amesakinishwa
  providerAlias: string; // Kitambulisho cha mtoa huduma katika OmniRoute
  spawnArgs: string[]; // Hoja za kupitisha wakati wa kuanzisha
  protocol: "stdio" | "http"; // Itifaki ya mawasiliano
  isCustom?: boolean; // Ikiwa huyu ni wakala maalum aliyefafanuliwa na mtumiaji
}
```

#### `getAvailableAgents()`

Hupata mawakala waliosakinishwa na wanaopatikana kwa ACP pekee.

```typescript
import { getAvailableAgents } from "@/lib/acp";

const available = getAvailableAgents();
// Hurejesha: CliAgentInfo[] (mawakala waliosakinishwa pekee)
```

#### `getAgentById(id)`

Hupata wakala maalum kwa kutumia kitambulisho.

```typescript
import { getAgentById } from "@/lib/acp";

const agent = getAgentById("claude");
// Hurejesha: CliAgentInfo | undefined
```

#### `setCustomAgents(agents)`

Huweka ufafanuzi wa mawakala maalum kutoka kwenye mipangilio.

```typescript
import { setCustomAgents } from "@/lib/acp";

setCustomAgents([
  {
    id: "my-custom-cli",
    name: "My Custom CLI",
    binary: "mycli",
    versionCommand: "mycli --version",
    providerAlias: "my-provider",
    spawnArgs: [],
    protocol: "stdio",
  },
]);
```

### Vitendakazi vya Kidhibiti

#### `acpManager.spawn(agentId, binary, args, env)`

Huanzisha mchakato mpya wa wakala wa CLI.

```typescript
import { acpManager } from "@/lib/acp";

const session = acpManager.spawn("claude", "claude", ["--print", "--output-format", "json"], {
  /* vigeu maalum vya mazingira */
});
// Hurejesha: AcpSession
```

**Vitambulisho vya mawakala vinavyoruhusiwa**: `["claude", "codex", "gemini", "qwen"]`

#### `acpManager.sendPrompt(sessionId, prompt, timeoutMs)`

Hutuma kidokezo kwa wakala wa CLI na kukusanya jibu.

```typescript
import { acpManager } from "@/lib/acp";

const response = await acpManager.sendPrompt(
  "acp-claude-1234567890-abc123",
  "What is 2+2?",
  120000 // muda wa kusubiri wa dakika 2
);
// Hurejesha: Promise<string>
```

#### `acpManager.kill(sessionId)`

Husitisha kipindi na kufanya usafishaji.

```typescript
import { acpManager } from "@/lib/acp";

const killed = acpManager.kill("acp-claude-1234567890-abc123");
// Hurejesha: boolean
```

#### `acpManager.getActiveSessions()`

Hupata vipindi vyote vinavyotumika.

```typescript
import { acpManager } from "@/lib/acp";

const sessions = acpManager.getActiveSessions();
// Hurejesha: AcpSession[]
```

#### `acpManager.killAll()`

Husitisha vipindi vyote.

```typescript
import { acpManager } from "@/lib/acp";

acpManager.killAll();
```

### Kiolesura cha Kipindi

```typescript
interface AcpSession {
  id: string; // Kitambulisho cha kipekee cha kipindi
  agentId: string; // Kitambulisho cha wakala (k.m., "claude")
  process: ChildProcess; // Kishikio cha mchakato mtoto
  alive: boolean; // Ikiwa mchakato bado unafanya kazi
  stdoutBuffer: string; // Akiba ya stdout iliyokusanywa
  stderrBuffer: string; // Akiba ya stderr iliyokusanywa
  createdAt: Date; // Muhuri wa muda wa kuundwa
}
```

### Matukio

`AcpManager` hupanua `EventEmitter` na hutoa matukio yafuatayo:

#### `stdout`

Hutolewa wakati wakala wa CLI anapoandika kwenye stdout.

```typescript
acpManager.on("stdout", ({ sessionId, data }) => {
  console.log(`[${sessionId}] stdout: ${data}`);
});
```

#### `stderr`

Hutolewa wakati wakala wa CLI anapoandika kwenye stderr.

```typescript
acpManager.on("stderr", ({ sessionId, data }) => {
  console.error(`[${sessionId}] stderr: ${data}`);
});
```

#### `exit`

Hutolewa wakati mchakato wa wakala wa CLI unapokoma.

```typescript
acpManager.on("exit", ({ sessionId, code, signal }) => {
  console.log(`[${sessionId}] exited with code ${code}, signal ${signal}`);
});
```

#### `error`

Hutolewa wakati mchakato wa wakala wa CLI unapokumbana na hitilafu.

```typescript
acpManager.on("error", ({ sessionId, error }) => {
  console.error(`[${sessionId}] error: ${error}`);
});
```

## Usanidi

### Vigeu vya Mazingira

ACP hurithi vigeu vyote vya mazingira kutoka kwa mchakato mzazi na inaweza kupanuliwa kwa vigeu maalum vya mazingira:

```typescript
acpManager.spawn("claude", "claude", [], {
  ANTHROPIC_API_KEY: "sk-...",
  DEBUG: "true",
});
```

### Hoja za Kuanzisha

Kila wakala ana hoja chaguo-msingi za kuanzisha zilizofafanuliwa katika sajili. Unaweza kuzibatilisha:

```typescript
acpManager.spawn("claude", "claude", ["--print", "--verbose"], {});
```

### Muda wa Kusubiri

Muda chaguo-msingi wa kusubiri kidokezo ni **sekunde 120** (dakika 2). Unaweza kuubatilisha:

```typescript
await acpManager.sendPrompt(sessionId, prompt, 300000); // Dakika 5
```

### Akiba ya Utambuzi

Utambuzi wa wakala huhifadhiwa kwenye akiba kwa **sekunde 60** ili kuepuka ukaguzi unaotumia rasilimali nyingi wa mfumo wa faili. Lazimisha kuonyesha upya:

```typescript
import { refreshAgentCache } from "@/lib/acp";

refreshAgentCache();
```

## Usalama

### Kuzuia Uingizaji wa Amri

ACP huthibitisha amri za toleo ili kuzuia mashambulizi ya uingizaji wa amri:

```typescript
const DISALLOWED_VERSION_COMMAND_CHARS = /[;&|<>`$\r\n]/;
```

Amri za toleo zilizo na vibambo hivi hukataliwa:

- `;` — Kitenganishi cha amri
- `&` — Mchakato wa usuli
- `|` — Bomba
- `<`, `>` — Uelekezaji upya
- `` ` `` — Ubadilishaji wa amri
- `$` — Upanuzi wa kigeu
- `\r`, `\n` — Migawanyiko ya mistari

### Uthibitishaji wa Jina la Faili Tekelezi

ACP huthibitisha kwamba faili tekelezi ya amri ya toleo inalingana na jina la faili tekelezi linalotarajiwa (isipokuwa ikiwa ni wakala maalum).

### Utengaji wa Mchakato

Kila kipindi cha ACP huendeshwa katika mchakato wake wa mtoto. Mchakato husitishwa kipindi kinapoisha au muda wake wa kusubiri unapokwisha.

## Utendaji

### Utendaji wa Utambuzi

- **Mwito wa kwanza**: ~50-200ms (huendesha amri ya `version` kwa kila wakala)
- **Miito iliyohifadhiwa kwenye akiba**: <1ms (hurejesha kutoka kwenye akiba)
- **TTL ya akiba**: Sekunde 60

### Utendaji wa Kidokezo

- **Kuanzisha**: ~50-100ms
- **Kutuma kidokezo**: ~10-50ms
- **Kusubiri jibu**: Hutegemea wakala wa CLI (kwa kawaida sekunde 1-30)
- **Kusitisha**: ~sekunde 5 (SIGTERM) + papo hapo (SIGKILL)

### Matumizi ya Rasilimali

- **Kumbukumbu kwa kila kipindi**: ~10-50MB (hutegemea wakala wa CLI)
- **CPU**: Kidogo sana (hutawaliwa na I/O)
- **Diski**: Hakuna

## Utatuzi wa Matatizo

### Hitilafu ya "Unknown agent"

**Tatizo**: `acpManager.spawn()` hutupa `Unknown agent: <id>`

**Suluhisho**: Ni mawakala hawa pekee wanaoruhusiwa katika `spawn()`:

- `claude`
- `codex`
- `gemini`
- `qwen`

Mawakala wengine lazima waanzishwe mwenyewe au kupitia ufafanuzi maalum wa wakala.

### Hitilafu ya "Session not alive"

**Tatizo**: `acpManager.sendPrompt()` hutupa `Session ${sessionId} is not alive`

**Suluhisho**: Huenda kipindi kimekoma au kimesitishwa. Angalia hali ya kipindi:

```typescript
const session = acpManager.getSession(sessionId);
if (!session?.alive) {
  // Anzisha kipindi upya
  acpManager.spawn("claude", "claude", [], {});
}
```

### Hitilafu ya "ACP timeout"

**Tatizo**: `acpManager.sendPrompt()` hutupa `ACP timeout after 120000ms`

**Suluhisho**: Ongeza muda wa kusubiri:

```typescript
await acpManager.sendPrompt(sessionId, prompt, 300000); // Dakika 5
```

### CLI Haijatambuliwa

**Tatizo**: `detectInstalledAgents()` haipati CLI yako

**Suluhisho**:

1. **Angalia PATH**: Hakikisha CLI ipo katika PATH ya mfumo wako
2. **Angalia amri ya toleo**: Endesha `claude --version` mwenyewe
3. **Angalia ruhusa**: Hakikisha CLI inaweza kutekelezwa
4. **Wakala maalum**: Ongeza ufafanuzi maalum wa wakala kwa CLI zisizo za kawaida

### Ruhusa Imekataliwa

**Tatizo**: ACP haiwezi kutekeleza CLI

**Suluhisho**:

1. **Angalia ruhusa za faili**: `chmod +x /usr/local/bin/claude`
2. **Angalia umiliki**: Hakikisha OmniRoute ina ruhusa za kusoma/kutekeleza
3. **Angalia SELinux/AppArmor**: Huenda ikazuia uanzishaji wa michakato

## Mifano

### Mfano wa 1: Anzisha na Utumie Claude Code

```typescript
import { acpManager, detectInstalledAgents } from "@/lib/acp";

// Tambua mawakala waliosakinishwa
const agents = detectInstalledAgents();
const claude = agents.find((a) => a.id === "claude");

if (claude?.installed) {
  // Anzisha kipindi kipya
  const session = acpManager.spawn("claude", claude.binary, ["--print", "--output-format", "json"]);

  // Tuma kidokezo
  const response = await acpManager.sendPrompt(
    session.id,
    "Explain quantum computing in 100 words"
  );

  console.log("Claude's response:", response);

  // Fanya usafishaji
  acpManager.kill(session.id);
}
```

### Mfano wa 2: Ugunduzi wa Kiotomatiki wenye Chaguo Mbadala

```typescript
import { acpManager, getAvailableAgents } from "@/lib/acp";

const available = getAvailableAgents();

// Jaribu Claude kwanza, tumia Codex kama chaguo mbadala
let agentId = "claude";
if (!available.find((a) => a.id === "claude")) {
  if (available.find((a) => a.id === "codex")) {
    agentId = "codex";
  } else {
    throw new Error("No ACP-compatible CLI agent found");
  }
}

const agent = available.find((a) => a.id === agentId)!;
const session = acpManager.spawn(agentId, agent.binary, agent.spawnArgs);

const response = await acpManager.sendPrompt(session.id, "Hello!");

acpManager.kill(session.id);
```

### Mfano wa 3: Wakala Maalum

```typescript
import { setCustomAgents, detectInstalledAgents } from "@/lib/acp";

// Sajili wakala maalum wa CLI
setCustomAgents([
  {
    id: "my-llm-cli",
    name: "My LLM CLI",
    binary: "myllm",
    versionCommand: "myllm --version",
    providerAlias: "my-llm-provider",
    spawnArgs: ["--format", "json"],
    protocol: "stdio",
  },
]);

// Sasa detectInstalledAgents() itajumuisha "my-llm-cli"
const agents = detectInstalledAgents();
```
