OmniRoute huja na mkusanyiko ulioratibiwa wa proksi za bure katika jedwali la `free_proxies`,
unaosawazishwa kutoka kwa watoa huduma wa nje (1proxy, proxifly, iplocate, webshare).
Dashibodi huzionyesha chini ya **Mipangilio → Proksi za Bure**. Hati hii
inaelezea uchujaji, upangaji, kuhesabu na kuripoti hitilafu za usawazishaji
kwa upande wa seva zinazotolewa na njia ya orodha.

## Njia ya orodha — `GET /api/settings/free-proxies`

Hurejesha sehemu iliyochujwa, iliyopangwa na kugawanywa katika kurasa pamoja na jumla ya idadi. Uchujaji na
uhesabuji hufanyika katika SQL, hivyo kiolesura kinaweza kuonyesha jumla halisi (k.m. `Jumla: 0`)
bila kupakia kila safu kwenye kumbukumbu.

### Vigezo vya hoja

| Kigezo            | Aina                               | Chaguo-msingi | Maana                                                                                                                                                              |
| ----------------- | ---------------------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `search`          | tungo                              | `""`          | `LIKE` inayozingatia ukubwa wa herufi kwenye safu ya host (na source).                                                                                             |
| `protocol`        | tungo                              | `""`          | Kichujio cha `type`: `http` / `https` / `socks4` / `socks5`. Tupu = zote.                                                                                          |
| `country`         | tungo                              | `""`          | Kichujio cha `countryCode` (ISO-2). Tupu = zote.                                                                                                                   |
| `minQuality`      | namba                              | `0`           | Safu zenye `qualityScore >= minQuality` pekee. `0` = hakuna kiwango cha chini.                                                                                     |
| `disabledSources` | tungo                              | `""`          | Vitambulisho vya vyanzo vya kuondoa vilivyotenganishwa kwa koma (k.m. `proxifly,webshare`).                                                                        |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`     | `quality` = alama kwa mpangilio wa kushuka; `latency` = ucheleweshaji kwa mpangilio wa kupanda (null mwisho); `recent` = `lastValidated` kwa mpangilio wa kushuka. |
| `offset`          | namba                              | `0`           | Mwanzo wa ugawaji katika kurasa.                                                                                                                                   |
| `limit`           | namba                              | `50`          | Ukubwa wa ukurasa (unawekewa kikomo upande wa seva).                                                                                                               |

### Jibu

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 kutoka kwa huduma ya chanzo"],
    "webshare": ["muda wa kusubiri mtandao umeisha"]
  }
}
```

`total` huonyesha jumla iliyochujwa **kabla** ya ugawaji katika kurasa, hivyo kiolesura kinaweza kuonyesha
`Jumla: N` na `hasMore` kwa kujitegemea. `syncErrors` hutumia kitambulisho cha chanzo kama ufunguo na
hujazwa kwa vyanzo vilivyoshindwa katika usawazishaji wao wa mwisho pekee — matokeo ya `Jumla: 0`
hayawi kimya kamwe.

## Kuongeza kwenye mkusanyiko — `POST /api/settings/free-proxies/[id]/add-to-pool`

Hupandisha proksi ya bure hadi kwenye mkusanyiko unaodhibitiwa wa `proxy_registry`. Huthibitisha
huduma ya chanzo kwanza; ikifaulu, hurejesha kitambulisho kipya cha proksi ya mkusanyiko na ucheleweshaji uliopimwa.

## Usawazishaji — `POST /api/settings/free-proxies/sync`

Huchota upya vyanzo vyote vilivyowezeshwa (au seti ndogo iliyo katika `{ "sources": [...] }`). Kila
chanzo husawazishwa kwa kujitegemea; chanzo kinachoshindwa hurekodiwa katika `syncErrors` na
vingine bado hukamilika, hivyo usawazishaji wa sehemu haufuti kamwe data nzuri ya awali.

## Takwimu — `GET /api/settings/free-proxies/stats`

Hurejesha mkusanyiko wa `total / inPool / avgQuality / bySource / lastSyncAt`
bila data ya safu — hutumiwa na wijeti za kichwa cha dashibodi.
