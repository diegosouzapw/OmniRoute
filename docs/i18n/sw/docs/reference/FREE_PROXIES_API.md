OmniRoute huja na mkusanyiko ulioratibiwa wa proksi zisizolipishwa katika jedwali la `free_proxies`,
unaosawazishwa kutoka kwa watoa huduma wa nje (1proxy, proxifly, iplocate, webshare).
Dashibodi huonyesha hizi chini ya **Mipangilio → Proksi Zisizolipishwa**. Hati hii
inaelezea uchujaji, upangaji, uhesabuji na uripoti wa hitilafu za usawazishaji
upande wa seva unaotolewa na njia ya orodha.

## Njia ya orodha — `GET /api/settings/free-proxies`

Hurejesha sehemu iliyochujwa, iliyopangwa na kugawanywa katika kurasa pamoja na jumla ya idadi. Uchujaji na
uhesabuji hufanyika katika SQL, ili UI iweze kuonyesha jumla halisi (k.m. `Jumla: 0`)
bila kupakia kila safu kwenye kumbukumbu.

### Vigezo vya hoja

| Kigezo            | Aina                               | Chaguomsingi | Maana                                                                                                                                                                   |
| ----------------- | ---------------------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | mfuatano                           | `""`         | `LIKE` inayozingatia ukubwa wa herufi kwenye safu ya seva pangishi (na chanzo).                                                                                         |
| `protocol`        | mfuatano                           | `""`         | Kichujio cha `type`: `http` / `https` / `socks4` / `socks5`. Tupu = zote.                                                                                               |
| `country`         | mfuatano                           | `""`         | Kichujio cha `countryCode` (ISO-2). Tupu = zote.                                                                                                                        |
| `minQuality`      | nambari                            | `0`          | Safu zenye `qualityScore >= minQuality` pekee. `0` = hakuna kiwango cha chini.                                                                                          |
| `disabledSources` | mfuatano                           | `""`         | Vitambulisho vya vyanzo vilivyotenganishwa kwa koma vya kuondoa (k.m. `proxifly,webshare`).                                                                             |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`    | `quality` = alama kwa mpangilio wa kushuka; `latency` = ukawiaji kwa mpangilio wa kupanda (thamani batili mwisho); `recent` = `lastValidated` kwa mpangilio wa kushuka. |
| `offset`          | nambari                            | `0`          | Mwanzo wa ugawaji katika kurasa.                                                                                                                                        |
| `limit`           | nambari                            | `50`         | Ukubwa wa ukurasa (unawekewa kikomo upande wa seva).                                                                                                                    |

### Jibu

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` huwakilisha jumla iliyochujwa **kabla ya** ugawaji katika kurasa, ili UI iweze kuonyesha
`Jumla: N` na `hasMore` kwa kujitegemea. `syncErrors` hupangwa kwa kitambulisho cha chanzo na
hujazwa tu kwa vyanzo ambavyo usawazishaji wake wa mwisho ulishindwa — matokeo ya `Jumla: 0`
kamwe hayakosi maelezo.

## Kuongeza kwenye mkusanyiko — `POST /api/settings/free-proxies/[id]/add-to-pool`

Huipandisha proksi isiyolipishwa hadi kwenye mkusanyiko unaosimamiwa wa `proxy_registry`. Huthibitisha
chanzo cha nje kwanza; ikifaulu hurejesha kitambulisho kipya cha proksi ya mkusanyiko na ukawiaji uliopimwa.

## Usawazishaji — `POST /api/settings/free-proxies/sync`

Huchota upya vyanzo vyote vilivyowezeshwa (au kikundi kidogo kilicho katika `{ "sources": [...] }`). Kila
chanzo husawazishwa kwa kujitegemea; chanzo kinachoshindwa hurekodiwa katika `syncErrors` na
vingine bado hukamilika, kwa hivyo usawazishaji usiokamilika kamwe haufuti data nzuri ya awali.

## Takwimu — `GET /api/settings/free-proxies/stats`

Hurejesha jumlisho la `total / inPool / avgQuality / bySource / lastSyncAt`
bila data ya safu — hutumiwa na wijeti za kichwa cha dashibodi.
