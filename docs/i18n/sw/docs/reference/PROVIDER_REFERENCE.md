> Tengeneza upya kwa: `npm run gen:provider-reference`
> **Ilitengenezwa mara ya mwisho:** 2026-09-20

Jumla ya watoa huduma: **360**. Tazama mgawanyo wa kategoria hapa chini.

## Kategoria

- **Bure** — kiwango cha bure chenye ufunguo wa API (husawidiwa kupitia dashibodi)
- **Bila uthibitishaji** — ncha za umma ambazo hazihitaji ufunguo wala kuingia katika akaunti
- **OAuth** — mchakato wa kuingia katika akaunti hushughulikiwa na OmniRoute, hakuna ufunguo wa API unaohitajika
- **Kuki ya wavuti** — hufunika programu ya wavuti ya mtoa huduma kupitia uthibitishaji wa kuki
- **Ufunguo wa API** — mtoa huduma anayelipiwa na kusanidiwa kupitia ufunguo wa API (salio la bure linaweza kutolewa)
- **Ndani ya kifaa** — huendeshwa kwenye mashine ya mtumiaji (Ollama, LM Studio, vLLM, n.k.)
- **Utafutaji** — watoa huduma za utafutaji wa wavuti
- **Sauti** — watoa huduma za sauti pekee (TTS/STT)
- **Proksi ya juu** — watoa huduma wanaowakilisha watoa huduma wengine
- **Wakala wa wingu** — mawakala wa uandishi wa msimbo wanaoendelea kufanya kazi kwa muda mrefu (Codex Cloud, Devin, Jules)
- **Mfumo** — watoa huduma wa ndani wa OmniRoute (loopback, n.k.)

Lebo za ziada: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (inapoonyeshwa): `native` — API halisi ya kuita vitendakazi; `emulated` — safu ya `tools` huigwa kupitia kidokezo kwa kutumia `webTools.ts` (vitalu vya `<tool>{...}</tool>` vinavyochanganuliwa kwa regex); `none` — `tools` kwa sasa huondolewa kimyakimya. Tazama #7286.

Tumia dashibodi katika `/dashboard/providers` ili kuwezesha, kusanidi, na kujaribu kila mtoa huduma.
