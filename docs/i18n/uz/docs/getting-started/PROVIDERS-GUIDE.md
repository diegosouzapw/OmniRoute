## Provayder nima?

Provayderni **mobil aloqa operatori** kabi tasavvur qiling. Qoʻngʻiroq qilish uchun mobil aloqa operatori kerak boʻlgani kabi, AI modellaridan foydalanish uchun ham AI provayderi kerak. OmniRoute **barcha operatorlar** bilan ishlaydigan telefonga oʻxshaydi — ular orasida avtomatik almashishingiz mumkin.

### Provayder turlari

| Tur            | Bu nima                           | Misollar                          | Narxi                          |
| -------------- | --------------------------------- | --------------------------------- | ------------------------------ |
| **Bepul**      | Toʻlov talab qilinmaydi           | Kiro, OpenCode Free, Pollinations | $0                             |
| **API kaliti** | Sizga API kaliti kerak            | OpenAI, Anthropic, Google         | Foydalanish boʻyicha toʻlov    |
| **OAuth**      | Hisobingiz bilan kirasiz          | Claude Code, GitHub Copilot       | Obuna                          |
| **Veb cookie** | Brauzer seansingizdan foydalanadi | ChatGPT Web (Codex), Gemini Web   | $0 (hisobingizdan foydalanadi) |

### Veb cookie provayderlari

Umumiy sozlash koʻrsatmalari, cheklovlar, muammolarni bartaraf etish va provayderga xos autentifikatsiya boʻyicha yoʻriqnomalar uchun **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** fayliga qarang.

## Tezkor boshlash: birinchi provayderingizni ulang

### Birinchi ishga tushirishda bepul provayderlarni ixtiyoriy sozlash

Birinchi ishga tushirish ustasi alohida **Bepul provayderlarni sozlash** kartasini taklif qiladi. U joriy
mos provayderlar roʻyxatini OmniRoute’ning autentifikatsiya talab qilmaydigan provayderlar reyestridan oladi, soʻng tasdiqlashdan oldin har bir
provayderni koʻrib chiqish va tanlovdan olib tashlash imkonini beradi. Avval uchinchi tomon shartlari, maxfiylik siyosati, mavjudlik va tezlik cheklovlarini
koʻrib chiqishingiz uchun OmniRoute provayderning ogohlantirishini hamda uning saytiga havolani
koʻrsatadi.

Bu amal ixtiyoriy: ustani yakunlash bepul provayder ulanishlarini hech qachon yashirin tarzda yaratmaydi.
U faqat hali mavjud boʻlmagan provayderlarni yaratadi, mavjud moslashtirilgan ulanishlarni
oʻzgartirmaydi hamda yaratilgan, avvaldan sozlangan va muvaffaqiyatsiz provayderlar haqida alohida hisobot beradi. Qisman natijadan soʻng faqat muvaffaqiyatsiz urinishlarni
xavfsiz tarzda qayta bajarishingiz mumkin.

### A varianti: bepul provayder (kredit karta talab qilinmaydi)

1. Boshqaruv panelini `http://localhost:20128` manzilida oching
2. **Provayderlar** → **Provayder qoʻshish** boʻlimiga oʻting
3. Quyidagi bepul provayderlardan birini tanlang:
   - **Kiro AI** — Bepul Claude modellari (autentifikatsiya talab qilinmaydi)
   - **OpenCode Free** — Bepul GPT modellari (autentifikatsiya talab qilinmaydi)
   - **Pollinations** — Bepul GPT-5, Claude, Gemini (kalit talab qilinmaydi)
   - **LongCat** — 10M token bepul (bir martalik grant, hisob + KYC talab qilinadi)
   - **Cloudflare AI** — 50+ model, kuniga 10K neyron
   - **MLX Gemma 26B** — Mahalliy Apple Silicon modeli (~38.5 token/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — Mahalliy Apple Silicon modeli (~9.1 token/s, ~13.1GB RAM)
4. **Ulanish** tugmasini bosing
5. Tayyor! Endi bepul AI xizmatidan foydalanishingiz mumkin.

### B varianti: API kaliti provayderi (pullik)

1. Provayder veb-saytidan API kalitini oling:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Boshqaruv panelini `http://localhost:20128` manzilida oching
3. **Provayderlar** → **Provayder qoʻshish** boʻlimiga oʻting
4. Provayderingizni tanlang
5. API kalitingizni joylashtiring
6. **Ulanish** tugmasini bosing
7. Tayyor! Endi ushbu provayderning modellaridan foydalanishingiz mumkin.

### C varianti: OAuth provayderi (obuna)

1. Boshqaruv panelini `http://localhost:20128` manzilida oching
2. **Provayderlar** → **Provayder qoʻshish** boʻlimiga oʻting
3. Provayderingizni tanlang (masalan, Claude Code, GitHub Copilot)
4. **OAuth orqali ulanish** tugmasini bosing
5. Hisobingiz bilan kiring
6. Tayyor! Endi obunangizdagi modellardan foydalanishingiz mumkin.

### D varianti: mahalliy MLX modellari (Apple Silicon)

Birlashtirilgan xotirali Apple Silicon Mac kompyuterlari uchun OmniRoute `mlx-lm.server` orqali ishlaydigan mahalliy MLX modellariga oddiy OpenAI-mos mahalliy provayderlar sifatida ulanishni qoʻllab-quvvatlaydi.

#### Talablar

- 24GB+ birlashtirilgan xotiraga ega **Apple Silicon Mac** (M1/M2/M3/M4) tavsiya etiladi
- **uv** paket menejeri: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Tezkor boshlash

1. **Bogʻliqliklarni oʻrnating**:

   ```bash
   # Agar uv hali oʻrnatilmagan boʻlsa, uni oʻrnating
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm paketini oʻrnating
   uv pip install mlx-lm
   ```

2. **MLX serverlarini qoʻlda ishga tushiring** (alohida terminallarda):

   ```bash
   # 1-terminal: Gemma 4 26B A4B IT-QAT (11435-port)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # 2-terminal: Qwen 3.8 27B MLX Mixed (11436-port)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute boshqaruv panelida ulang**:
   - **Provayderlar** → **Provayder qoʻshish** boʻlimiga oʻting
   - **MLX Gemma 26B** yoki **MLX Qwen 3.8 27B** variantini tanlang
   - **Ulanish** tugmasini bosing (API kaliti talab qilinmaydi)

4. **OpenCode bilan foydalaning**:
   ```bash
   # OpenCode’ni OmniRoute’dan foydalanish uchun sozlang
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX modellaridan foydalaning
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Xotirani boshqarish

**Muhim**: 24GB birlashtirilgan xotira bilan bir vaqtda faqat **bitta katta MLX modeli ishlashi mumkin**.

- Gemma 26B: maksimal ~15.9GB xotira
- Qwen 3.8 27B: maksimal ~13.1GB xotira

Buni qoʻlda boshqarishingiz kerak:

- Bir vaqtda faqat bitta MLX serverini ishga tushiring yoki
- Ikkalasini alohida kompyuterlarda ishga tushiring yoki
- Boshqasini ishga tushirishdan oldin bittasini toʻxtating

OmniRoute MLX server jarayonlarini avtomatik boshqarmaydi — u faqat soʻrovlarni siz sozlagan OpenAI-mos endpoint’larga yoʻnaltiradi.

#### Vositalarni chaqirishni qoʻllab-quvvatlash

Har ikkala model OpenAI-mos vosita chaqiruvini qoʻllab-quvvatlaydi. Quyidagicha sinab koʻring:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Muammolarni bartaraf etish

| Muammo                      | Yechim                                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Server ishga tushmaydi      | `uv run mlx_lm.server --help` buyrugʻini tekshiring va model identifikatorlari toʻgʻriligini tasdiqlang                |
| Xotira yetishmaydi          | Faqat bitta model ishlayotganiga ishonch hosil qiling; boshqa ilovalarni yoping; Activity Monitorʼni tekshiring        |
| Ulanish rad etildi          | Server toʻgʻri portda (11435/11436) ishlayotganini tekshiring                                                          |
| Javoblar sekin              | Birinchi soʻrov modelni xotiraga yuklaydi (~30-60s); keyingi soʻrovlar tez bajariladi                                  |
| Vosita chaqiruvi ishlamaydi | Model vositalarni qoʻllab-quvvatlashiga ishonch hosil qiling; tarjima xatolari uchun OmniRoute jurnallarini tekshiring |

## Provayderni ulash usuli (bosqichma-bosqich)

### 1-bosqich: Boshqaruv panelini oching

Brauzeringizda `http://localhost:20128` manziliga oʻting.

### 2-bosqich: Provayderlar boʻlimiga oʻting

Yon paneldagi **Provayderlar** tugmasini bosing.

### 3-bosqich: Provayder qoʻshish tugmasini bosing

**+ Provayder qoʻshish** tugmasini bosing.

### 4-bosqich: Provayderingizni tanlang

Roʻyxatni koʻrib chiqing yoki provayderingizni qidiring. Uning ustiga bosing.

### 5-bosqich: Hisob maʼlumotlarini kiriting

- **Bepul provayderlar**: Hisob maʼlumotlari talab qilinmaydi — shunchaki **Ulanish** tugmasini bosing
- **API kaliti talab qilinadigan provayderlar**: API kalitingizni kiriting
- **OAuth provayderlari**: **OAuth orqali ulanish** tugmasini bosing va tizimga kiring

### 6-bosqich: Ulanishni tekshiring

Ishlayotganini tekshirish uchun **Ulanishni tekshirish** tugmasini bosing.

### 7-bosqich: Tayyor!

Provayderingiz ulandi. Undan `model: "auto"` orqali foydalanishingiz yoki provayderni bevosita koʻrsatishingiz mumkin.

## Bir nechta provayderdan foydalanish

OmniRoute **bir nechta provayder** bilan eng yaxshi ishlaydi. Bu sizga quyidagi imkoniyatlarni beradi:

- **Avtomatik zaxira provayderiga oʻtish** — Agar bir provayder ishlamasa, OmniRoute keyingisini sinab koʻradi
- **Xarajatlarni optimallashtirish** — OmniRoute har bir soʻrov uchun eng arzon provayderni tanlaydi
- **Tezlikni optimallashtirish** — OmniRoute har bir soʻrov uchun eng tezkor provayderni tanlaydi
- **Sifatni optimallashtirish** — OmniRoute har bir vazifa uchun eng yaxshi provayderni tanlaydi

### Tavsiya etilgan sozlama

Eng yaxshi natija uchun kamida **3 ta provayderni** ulang:

1. **Bitta bepul provayder** (Kiro, OpenCode Free yoki Pollinations) — Har doim mavjud
2. **Bitta tezkor provayder** (Groq, Cerebras) — Tezkor javoblar uchun
3. **Bitta yuqori sifatli provayder** (OpenAI, Anthropic, Google) — Murakkab vazifalar uchun

Soʻng `model: "auto"` parametridan foydalaning va OmniRoute har bir soʻrov uchun eng yaxshi provayderni avtomatik ravishda tanlaydi.

## Koʻp soʻraladigan savollar

### "OmniRoute xizmatidan foydalanish uchun pul toʻlashim kerakmi?"

**Yoʻq!** OmniRoute bepul va ochiq manbali. Bepul provayderlardan (Kiro, OpenCode Free, Pollinations) hech qanday toʻlovsiz foydalanishingiz mumkin. Faqat pulli provayderlardan foydalanishni tanlasangizgina toʻlov qilasiz.

### "Qaysi provayderdan boshlashim kerak?"

**Kiro AI** bilan boshlang — u bepul, API kalitini talab qilmaydi va Claude modellaridan foydalanish imkonini beradi. Keyin zaruratga qarab boshqa provayderlarni qoʻshing.

### "Bir vaqtning oʻzida bir nechta provayderdan foydalana olamanmi?"

**Ha!** OmniRoute aynan shu maqsad uchun yaratilgan. Bir nechta provayderni ulang va OmniRoute har bir soʻrov uchun eng yaxshisini tanlashi uchun `model: "auto"` dan foydalaning.

### "Provayder ishlamay qolsa nima boʻladi?"

OmniRoute ishlamay qolgan provayderlarni avtomatik ravishda chetlab oʻtadi va keyingisini sinab koʻradi. Hech narsa qilishingiz shart emas.

### "Provayderni qanday uzaman?"

Provayderlar boʻlimiga oʻting → provayder ustiga bosing → **Uzish** tugmasini bosing.

### "Mavjud API kalitlarimdan foydalana olamanmi?"

**Ha!** Agar sizda OpenAI, Anthropic, Google va boshqalar uchun API kalitlari mavjud boʻlsa, ulardan OmniRoute ichida foydalanishingiz mumkin. Provayderni ulashda ularni shunchaki kiriting.
