## 1-qadam: OmniRoute’ni oʻrnatish

Oʻzingizga maʼqul usulni tanlang:

### A variant: npm (Tavsiya etiladi)

```bash
npm install -g omniroute
```

### B variant: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` — **eʼlon qilingan** eng yuqori barqaror SemVer versiyasi. U git’dagi `main` tarmogʻini kuzatmaydi. GitOps uchun `diegosouzapw/omniroute:X.Y.Z` versiyasini aniq belgilang. [Tasvir teglari / Reliz kanallari](../guides/DOCKER_GUIDE.md#release-channels) boʻlimiga qarang.

### C variant: Manba kodidan

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## 2-qadam: OmniRoute’ni ishga tushirish

```bash
omniroute
```

OmniRoute `http://localhost:20128` manzilida ishga tushadi. Boshqaruv paneli avtomatik ravishda ochiladi.

---

## 3-qadam: Bepul provayderni ulash

Bepul provayderni ulash orqali OmniRoute’dan **hech qanday toʻlovsiz** foydalanishingiz mumkin.

### A variant: Kiro (Bepul Claude — Kredit karta talab qilinmaydi)

1. `http://localhost:20128` manzilidagi boshqaruv panelini oching
2. **Provayderlar** → **Provayder qoʻshish** boʻlimiga oʻting
3. **Kiro AI**’ni tanlang
4. **Ulash** tugmasini bosing (API kaliti kerak emas!)
5. Tayyor! Endi Claude modellaridan bepul foydalanishingiz mumkin.

### B variant: OpenCode Free (Autentifikatsiyasiz)

1. `http://localhost:20128` manzilidagi boshqaruv panelini oching
2. **Provayderlar** → **Provayder qoʻshish** boʻlimiga oʻting
3. **OpenCode Free**’ni tanlang
4. **Ulash** tugmasini bosing (API kaliti kerak emas!)
5. Tayyor! Endi bir nechta modeldan bepul foydalanishingiz mumkin.

### C variant: Pollinations (Kalit talab qilinmaydi)

1. `http://localhost:20128` manzilidagi boshqaruv panelini oching
2. **Provayderlar** → **Provayder qoʻshish** boʻlimiga oʻting
3. **Pollinations**’ni tanlang
4. **Ulash** tugmasini bosing (API kaliti kerak emas!)
5. Tayyor! Endi GPT-5, Claude, Gemini va boshqa modellardan bepul foydalanishingiz mumkin.

## 4-qadam: Ishlashini tekshirish

[API kalitlari](http://localhost:20128/dashboard/api-manager) boʻlimida yangi kalit yarating. Bu kalit boshqa koʻrsatilmasligi sababli uni saqlab qoʻying. Eʼtibor bering, bu kalit yuqori oqim provayderlariga kirish uchun emas, balki vositalarning OmniRoute’ga kirishi uchun moʻljallangan.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Ulangan modellaringiz roʻyxatini koʻrishingiz kerak.

## 5-qadam: IDE yoki CLI vositangizni OmniRoute’ga yoʻnaltirish

IDE yoki CLI vositangizda quyidagilarni sozlang:

```
Asosiy URL: http://localhost:20128/v1
API kaliti: [Boshqaruv paneli → Endpointlar bo‘limidan nusxalang]
Model:      auto
```

Shu bilan tamom! Endi IDE’ingiz provayderni avtomatik tanlash imkoniyati bilan OmniRoute’dan foydalanadi.

### IDE misoli: VSCode/Continue.dev

1. VSCode’da [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) kengaytmasini oʻrnating.
2. Quyidagi qatorlarni qoʻshish uchun `~/.continue/config.yaml` faylini yangilang:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev chat panelida `OmniRoute - Auto` variantini tanlang, shundan soʻng soʻrovlaringiz OmniRoute’ga yuboriladi.
4. (Ixtiyoriy) Oʻquvchi uchun mashq — IDE’ingiz yordamida `config.yaml` fayliga boshqa barcha tayyor konfiguratsiyalarni ham qoʻshing 😊

### CLI misoli: Codex CLI

1. Operatsion tizimingizda muhit oʻzgaruvchisini doimiy qilib sozlang.
   macOS/Linux uchun (`~/.bashrc` yoki `~/.zshrc` fayliga qoʻshing):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows uchun (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Endi Codex’ni OmniRoute uchun sozlangan holda ishga tushiramiz. Quyidagini bajaring:

```
omniroute launch-codex --model auto
```

Endpoint va API kalitini koʻrsatish uchun buni `codex` hamda buyruq qatori parametrlari orqali qoʻlda bajarishingiz mumkin, ammo yuqoridagi buyruq yordamida OmniRoute hammasini siz uchun hal qiladi.

Xuddi shu bitta buyruqli ishga tushirish usuli umumiy ishga tushirgich orqali boshqa CLI vositalari uchun ham ishlaydi — `omniroute run <target>` buyrugʻi `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` va `gemini` vositalarini qoʻllab-quvvatlaydi ([CLI integratsiyalari](../guides/CLI-INTEGRATIONS.md) boʻlimiga qarang).

3. Endi CLI soʻrovlarni OmniRoute’ga yuborishi kerak.

### Vosita soʻrovlarni OmniRoute orqali yoʻnaltirayotganini tasdiqlash

Chap yon paneldagi [Monitoring/Jurnallar](http://localhost:20128/dashboard/logs) havolasini bosish orqali soʻrov tafsilotlarini koʻrishingiz mumkin. Keyingi boʻlimlarga oʻtib, qoʻshimcha tafsilotlarni koʻrishingiz mumkin. Qoʻshimcha sifatida, sevimli boshqaruv vositangizdan qanday maʼlumotlar yuborilayotganini ham koʻrishingiz mumkin. Bu oʻrganish va nosozliklarni tuzatish nuqtayi nazaridan foydalidir.

## Koʻp beriladigan savollar

### "Menga API kaliti kerakmi?"

**Yoʻq!** Bepul provayderlardan (Kiro, OpenCode Free, Pollinations) hech qanday API kalitisiz foydalanishingiz mumkin. Ularni shunchaki boshqaruv panelida ulang.

### "`auto` nima?"

`auto` OmniRoute’ga har bir soʻrov uchun eng yaxshi provayderni avtomatik ravishda tanlashni buyuradi. Bunda tezlik, narx, sifat va mavjudlik hisobga olinadi. Batafsil maʼlumot uchun [Auto-Combo qoʻllanmasi](./AUTO-COMBO-GUIDE.md)ga qarang.

### "Bu qancha turadi?"

OmniRoute’ning oʻzi **bepul va ochiq manbali**. Siz faqat foydalanadigan provayderlaringiz uchun haq toʻlaysiz. Koʻplab provayderlarda bepul tariflar mavjud — [Bepul tariflar qoʻllanmasi](./FREE-TIERS-GUIDE.md)ga qarang.

### "Undan Claude Code / Cursor / Copilot bilan foydalana olamanmi?"

**Ha!** OmniRoute OpenAI formatini qoʻllab-quvvatlaydigan har qanday vosita bilan ishlaydi. Asosiy URL’ni `http://localhost:20128/v1` qilib sozlang. Muayyan sozlash koʻrsatmalari uchun [CLI vositalari qoʻllanmasi](../reference/CLI-TOOLS.md)ga qarang.

### "Provayder ishlamay qolsa nima boʻladi?"

OmniRoute ishlamay qolgan provayderlarni avtomatik ravishda oʻtkazib yuboradi va keyingisini sinab koʻradi. Hech narsa qilishingiz shart emas. Batafsil maʼlumot uchun [Auto-Combo qoʻllanmasi](./AUTO-COMBO-GUIDE.md)ga qarang.
