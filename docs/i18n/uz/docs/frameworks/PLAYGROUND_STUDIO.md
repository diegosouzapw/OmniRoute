## Umumiy koʻrinish

Playground Studio `/dashboard/playground` sahifasini oddiy Monaco asosidagi muharrirdan
toʻliq funksional sinov ish maydoniga aylantiradi. U eski `page.tsx` faylini toʻrtta ichki oyna
va umumiy konfiguratsiya panelini koʻrsatuvchi `PlaygroundStudio` qobigʻi bilan almashtiradi.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Chat] [⚖ Taqqoslash] [{} API] [🔧 Yaratish] 142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {faol ichki oyna kontenti}              │ ─ Konfiguratsiya          │
│                                          │ Endpoint  [chat ∨]        │
│                                          │ Model     [gpt-5.4 ∨]     │
│                                          │ Tizim     [matn maydoni]  │
│                                          │ Harorat  ▕▕▔▔ 0.7         │
│                                          │ Presetlar [▾ yuklash][saqlash]│
│                                          │ [✨ Soʻrovni yaxshilash]   │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Ichki oynalar

### Chat ichki oynasi

`ChatPlayground.tsx` komponentini koʻp bosqichli oqimli ish muhitiga aylantiradi:

- `MarkdownMessage.tsx` orqali Markdown’ni toʻliq koʻrsatish (kod bloklari, jadvallar, roʻyxatlar, havolalar).
- Tizim soʻrovi umumiy Konfiguratsiya panelidan olinadi.
- Har bir xabar uchun tokenlar/xarajat (soʻrov + yakuniy javob tokenlari).
- Oxirgi javobni qayta yaratish.
- SSE oqimi orqali `POST /v1/chat/completions` manziliga yuboradi.

### Taqqoslash ichki oynasi

Proksi uchun asosiy farqlovchi imkoniyat: 1 ta soʻrovni **4 tagacha modelda parallel ravishda** ishga tushirish.

- 4 tagacha ustun, har biri `/v1/chat/completions` manzilidan mustaqil ravishda oqim uzatadi.
- Ustunlar qoʻshish uchun `+ Model qoʻshish` tugmasi (Cmd+K klaviatura yorligʻi).
- `Barchasini ishga tushirish ▶` barcha oqimlarni `Promise.all` va har bir ustun uchun alohida `AbortController` orqali bir vaqtda ishga tushiradi.
- Global **Barchasini bekor qilish** amali bajarilayotgan barcha oqimlarni toʻxtatadi.
- Har bir ustundagi `ProviderMetrics` TTFT, TPS, tokenlar va taxminiy xarajatni real vaqt rejimida koʻrsatadi.
- Koʻrsatkichlar **“mijoz tomonidagi hisob-kitob”** (D12) deb belgilangan — birinchi SSE fragmentidan boshlab oʻlchanadi.

### API ichki oynasi

Ilgʻor foydalanuvchilar uchun asl Monaco muharririni 100% saqlab qoladi (D14):

- 10 ta endpoint: chat yakunlashlari, yakunlashlar, embeddinglar, tasvirlar, audio, nutq, transkripsiyalar, moderatsiyalar, qayta saralash, qidiruv.
- Multimodal fayl yuklash.
- Real vaqt rejimidagi natija bilan SSE oqimi.
- `ApiTab.tsx` sifatida oʻralgan (kechiktirib yuklanadi, `ssr: false`).

### Yaratish ichki oynasi

Vositalar/funksiyalarni chaqirish va tuzilmaviy natija interfeysi:

- `ToolsBuilder.tsx` — har bir vosita uchun JSON sxema muharriri yordamida `tools[]` elementlarini qoʻshish/tahrirlash/oʻchirish.
  Parametrlarni `ToolDefinitionSchema` (Zod) orqali tekshiradi.
- `StructuredOutputEditor.tsx` — JSON rejimini yoqish/oʻchirish + JSON sxema muharriri.
  Javobni sxemaga muvofiqligini `StructuredOutputSchema` (Zod) orqali tekshiradi.
- Soʻrovni `tools[]` va/yoki `response_format` bilan `/v1/chat/completions` manziliga yuboradi.

## Konfiguratsiya paneli (Umumiy)

`StudioConfigPane.tsx` — doimo ko‘rinadi, yig‘ib qo‘yish mumkin.

| Maydon              | Komponent             | Izohlar                                                                                          |
| ------------------- | --------------------- | ------------------------------------------------------------------------------------------------ |
| Yakuniy nuqta       | `<select>`            | `PlaygroundEndpoint`ga mos keluvchi 10 ta variant                                                |
| Model               | `<input>`             | erkin matn, masalan, `openai/gpt-4o`                                                             |
| Tizim prompti       | `<textarea>`          | barcha varaqlarga uzatiladi                                                                      |
| Parametrlar         | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop                           |
| Andozalar           | `PresetPicker`        | nomlangan konfiguratsiya nusxalarini yuklash/saqlash (DBda saqlanadi)                            |
| Promptni yaxshilash | `ImprovePromptButton` | kvota haqidagi ogohlantirish modal oynasini ochadi, `/api/playground/improve-prompt`ni chaqiradi |

Holat `PlaygroundStudio.tsx`ga ko‘tariladi va barcha varaqlarga uzatiladi. Varaqlarni
almashtirish konfiguratsiya holatini saqlab qoladi.

## Yuqori panel

`StudioTopBar.tsx`:

- Varaqlarni almashtirgich (role="tablist").
- `TokenCostCounter` — tokenlarning (↑/↓) joriy soni va taxminiy xarajat ko‘rsatkichi.
- Kodni eksport qilish tugmasi (`</>`) — `ExportCodeModal`ni ochadi.

## Kodni eksport qilish modal oynasi

`ExportCodeModal.tsx` joriy `PlaygroundState`dan curl / Python / TypeScript kod parchalarini
yaratish uchun `codeExport.ts`dan foydalanadi. API kaliti o‘rnini bosuvchi qiymat doimo `$OMNIROUTE_API_KEY` (D11).

---

## Promptni yaxshilovchi vosita

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Modal oyna «kvota sarflanadi» deb ogohlantiradi.
2. Tasdiqlangach, marshrutga `{ system, prompt, model, tone }` yuboradi.
3. Marshrut ichki tarzda `promptImprover.META_SYSTEM_PROMPT` bilan `/v1/chat/completions`ni chaqiradi.
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`ni qaytaradi.
5. UI Konfiguratsiya panelidagi tizim prompti va Chat varag‘idagi foydalanuvchi promptini yangilaydi.

---

## Andozalar

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- `playground_presets` SQLite jadvalida saqlanadi (`084_playground_presets.sql` migratsiyasi).
- Har bir andoza quyidagilarni saqlaydi: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: `GET` ro‘yxat, `POST` yaratish, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Oqim metrikalari

`useStreamMetrics.ts` + `streamMetrics.ts` (sof funksiya):

- `start()` — so‘rov boshlangan vaqtni qayd etadi.
- `onFirstChunk()` — TTFTni qayd etadi.
- `onChunk(n)` — yakunlash tokenlari sonini jamlaydi.
- `finish(usage?)` — yakuniy metrikalarni hisoblaydi: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Narxlar `src/lib/playground/types.ts` ichidagi statik jadvaldan olinadi («taxminiy» deb belgilangan — D13).
