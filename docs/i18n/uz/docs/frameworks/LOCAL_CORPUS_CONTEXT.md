## Bu nima

Local Corpus operatorga matnli fayllardan iborat, aniq tasdiqlangan bitta katalogni
OmniRoute MCP serveriga taqdim etish imkonini beradi. Fayllar asl katalogida qoladi:
OmniRoute SQLite bazasida faqat kanonik ildiz yoʻlini saqlaydi va xotirada qidiruv
indeksini yuritadi. U korpus tarkibini repozitoriyga yoki maʼlumotlar bazasiga
koʻchirmaydi.

Indeks bosqichma-bosqich yangilanadi. Oʻzgarmagan fayllar hajmi va oʻzgartirilgan
vaqtiga asoslanib qayta ishlatiladi, oʻzgargan fayllar qayta oʻqiladi va SHA-256 bilan
xeshlanadi, oʻchirilgan fayllar esa olib tashlanadi. Qidiruv 30 soniyadan eski indeksni
yangilaydi; chaqiruvchilar darhol yangilashni ham soʻrashi mumkin.

## Manbani sozlash

Sozlamalar marshruti boshqa sozlamalar API laridagi kabi boshqaruv autentifikatsiyasini
talab qiladi. Yuborilgan yoʻl avvaldan mavjud boʻlishi va mutlaq katalog yoʻli boʻlishi
kerak.

```bash
# Tasdiqlangan katalogni ulang
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Konfiguratsiya va indeks holatini tekshiring
curl http://localhost:20128/api/settings/local-corpus

# Manba fayllarini oʻzgartirmasdan aloqani uzing
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP vositalari

Uchala vosita ham `read:local-corpus` ruxsatini talab qiladi. Vosita javoblari mutlaq
yoʻlni emas, nisbiy yoʻllarni va ildiz katalogining asosiy nomini koʻrsatadi.

| Vosita                | Tavsif                                                                                                     |
| :-------------------- | :--------------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Konfiguratsiya holati, indeks hajmi, cheklovlar va oxirgi yangilanish vaqtini bildiradi                    |
| `local_corpus_search` | Indekslangan matndan qidiradi va qatorlar doirasidagi cheklangan parchalarni qaytaradi (20 tagacha natija) |
| `local_corpus_read`   | Ruxsat etilgan, korpusga nisbiy bitta fayldan cheklangan qatorlar oraligʻini oʻqiydi                       |

MCP kirish maʼlumotlariga misollar:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Xavfsizlik chegaralari

- Ruxsat etilgan fayllar roʻyxati matnga yoʻnaltirilgan: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` va `.yml`.
- Ramziy havolalar oʻtkazib yuboriladi. Oʻqish yoʻllari kanoniklashtiriladi va sozlangan
  ildiz ichida qolishi shart; mutlaq yoʻllar va katalog boʻylab oʻtishga urinishlar rad etiladi.
- Maxfiy va yaratiladigan katalog nomlari chiqarib tashlanadi: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` va
  `secrets`.
- Standart cheklovlar: 5 000 ta fayl, har bir fayl uchun 1 MiB, jami 64 MiB indekslangan
  tarkib, har bir qidiruv boʻlagi uchun taxminan 4 000 ta belgi va har bir oʻqish uchun 400 ta qator.
- NUL belgisini oʻz ichiga olgan fayllar matnli boʻlmagan fayllar sifatida qaraladi va
  oʻtkazib yuboriladi yoki rad etiladi.

PDF, DOCX, tasvirlar va arxivlar kabi ikkilik hujjatlar ataylab qoʻllab-quvvatlanmaydi.
Indekslashdan oldin ularni sozlangan katalogda tasdiqlangan matn formatiga aylantiring.

## Ishlatishga oid eslatmalar

- Sozlangan ildizni oʻzgartirish yoki oʻchirish umumiy xotira indeksini tozalaydi.
- Jarayonni qayta ishga tushirish indeksni yoʻq qiladi; keyingi qidiruv uni sozlangan
  manbadan qayta yaratadi.
- `local_corpus_status` majburiy skanerlashni boshlamaydi. Darhol qayta skanerlash zarur
  boʻlsa, `local_corpus_search` vositasidan `refresh: true` bilan foydalaning.
- Skanerlash va oʻqishdagi xatolar hisobga olinadi yoki tozalangan xatolar sifatida
  qaytariladi; manba fayllari hech qachon oʻzgartirilmaydi.
