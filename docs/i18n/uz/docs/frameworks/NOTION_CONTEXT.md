> (tokenni saqlash), `open-sse/mcp-server/tools/notionTools.ts` (6 ta MCP vositasi),

> ulash `open-sse/mcp-server/server.ts` ichida joylashgan.

## Bu nima

OmniRoute **Notion** ish maydoniga **kontekst manbasi** sifatida ulanishi mumkin — bu agentlar ichki MCP serveri orqali foydalanadigan, oʻqish va yozish mumkin boʻlgan bilimlar bazasidir. Notion integratsiya tokeni sozlangach, MCP vositalari LLM modeliga sahifalar va maʼlumotlar bazalarini qidirish, sahifa tarkibi va bloklar daraxtlarini oʻqish, filtrlar/saralashlar yordamida maʼlumotlar bazalariga soʻrov yuborish hamda yangi bloklarni qoʻshish imkonini beradi — bularning barchasi OmniRoute orqali proksi qilinadi (qayta urinish, vaqt chegarasi va xatolarni tasniflash bilan), shuning uchun model hech qachon Notion API bilan bevosita ishlamaydi.

Integratsiya rasmiy Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) ustidagi ixcham va mustahkamlangan qobiqdir. Mijoz
(`src/lib/notion/api.ts`) quyidagilarni qoʻshadi:

- `429` va `5xx` holatlari uchun **eksponensial kechikish bilan qayta urinish** (3 tagacha urinish).
- `AbortController` orqali **55 soniyalik soʻrov vaqt chegarasi**.
- **Tiplashtirilgan xatolar tasnifi** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  koʻrsatmalariga amal qiladi), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- Koʻrsatishdan oldin stek-treysga oʻxshash qismlarni olib tashlaydigan **xabarlarni tozalash**.

## Sozlash

Notion tokeni uchun **muhit oʻzgaruvchisi mavjud emas** — u
`src/lib/db/notion.ts` orqali SQLiteʼdagi `key_value` jadvalida (`notion` nomlar fazosi, `integration_token` kaliti)
saqlanadi. Uni Endpoint boshqaruv panelidagi **Context Sources** yorligʻidan
(`ObsidianSourceCard` bilan bir darajadagi `NotionSourceCard`) yoki sozlamalar REST API-si orqali sozlang.

> [!NOTE]
> Token — bu **Notion ichki integratsiya tokeni**. Integratsiyani
> <https://www.notion.com/my-integrations> manzilida yarating, soʻng OmniRoute foydalanishi kerak boʻlgan
> sahifalar/maʼlumotlar bazalarini shu integratsiya bilan ulashing (Notion ruxsat modeli butun ish maydoni
> miqyosida emas, ulashishga asoslangan).

### REST orqali sozlash

```bash
# Integratsiya tokenini saqlash + tekshirish (POST sinov qidiruvini yuborish orqali tekshiradi)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# Ulanish holatini tekshirish
curl http://localhost:20128/api/settings/notion

# Ulanishni uzish (saqlangan tokenni tozalaydi)
curl -X DELETE http://localhost:20128/api/settings/notion
```

Har uchala metod ham boshqaruv paneli autentifikatsiyasini (`isAuthenticated`) talab qiladi. `POST` soʻrovida
OmniRoute tokenni saqlaydi va darhol 1 ta natijali sinov qidiruvini bajaradi; agar Notion
xato obyektini qaytarsa, token tozalanadi va chaqiruv `400` bilan muvaffaqiyatsiz tugaydi.

## MCP vositalari (6)

`open-sse/mcp-server/tools/notionTools.ts` ichida belgilangan. Token chaqiruv vaqtida
`getNotionToken()` orqali aniqlanadi; agar hech qanday token sozlanmagan boʻlsa, vosita
`"Notion integration token not configured. Set it in Settings > Context Sources."`
xatosini chiqaradi.

| Vosita                       | Qamrov         | Tavsif                                                                                                                          |
| ---------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | Sahifalar va maʼlumotlar bazalarini matnli soʻrov boʻyicha qidiradi (sarlavhalar, ID-lar va URL-larni qaytaradi). Sahifalangan. |
| `notion_get_page`            | `read:notion`  | Sahifaning ID-si orqali uning tarkibi va metamaʼlumotlarini oladi.                                                              |
| `notion_list_block_children` | `read:notion`  | Blok yoki sahifaning barcha ichki bloklarini (bloklar daraxtini) roʻyxatlaydi. Sahifalangan.                                    |
| `notion_query_database`      | `read:notion`  | Ixtiyoriy `filter` + `sorts` bilan maʼlumotlar bazasiga soʻrov yuboradi (Notion API formati). Sahifalangan.                     |
| `notion_get_database`        | `read:notion`  | Maʼlumotlar bazasining sxemasi/metamaʼlumotlarini ID orqali oladi.                                                              |
| `notion_append_blocks`       | `write:notion` | Mavjud blok yoki sahifaga ichki bloklarni qoʻshadi (har bir soʻrovda koʻpi bilan 100 ta blok).                                  |

### Kirish parametrlari

- `notion_search` — `query` (1–500 ta belgi), `pageSize` (1–100, standart qiymat 20),
  `startCursor` (ixtiyoriy).
- `notion_get_page` — `pageId` (32 belgili hex yoki UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, standart qiymat 50),
  `startCursor` (ixtiyoriy).
- `notion_query_database` — `databaseId`, `filter` (ixtiyoriy, Notion filtri formati),
  `sorts` (ixtiyoriy massiv), `pageSize` (1–100, standart qiymat 50), `startCursor` (ixtiyoriy).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (blok obyektlari massivi),
  `after` (ixtiyoriy joylashuv).

### Qamrovlar

Oʻqish vositalari `read:notion`, yozish vositasi esa `write:notion` qamrovini talab qiladi.
Qamrovlar `open-sse/mcp-server/server.ts` ichidagi `withScopeEnforcement()` tomonidan faqat
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` boʻlganda majburiy tekshiriladi; chaqiruvchiga ruxsat berilgan
qamrovlar `OMNIROUTE_MCP_SCOPES` (vergul bilan ajratilgan) yoki autentifikatsiya qilingan API
kalitining qamrov kontekstidan olinadi. Toʻliq qamrov modeli uchun
[MCP-SERVER.md](./MCP-SERVER.md) fayliga qarang.

## Endpointlar

| Metod    | Yoʻl                   | Maqsad                                         |
| -------- | ---------------------- | ---------------------------------------------- |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` ni qaytaradi.        |
| `POST`   | `/api/settings/notion` | Integratsiya tokenini saqlaydi va tekshiradi.  |
| `DELETE` | `/api/settings/notion` | Ulanishni uzadi (saqlangan tokenni tozalaydi). |

> Bular boshqaruv paneli sozlamalari marshrutlaridir. Ommaviy `/v1` Notion proksi
> endpointi **mavjud emas** — Notion bilan faqat yuqoridagi MCP vositalari orqali ishlanadi.

## Foydalanish holatlari

- **Bilimlarga asoslangan javoblar** — agentga javob berishdan oldin ish maydonida `notion_search`
  orqali qidirish va eng mos natijani `notion_get_page` orqali olish imkonini bering, shunda
  javoblarda haqiqiy ichki hujjatlarga havola qilinadi.
- **Maʼlumotlar bazasiga asoslangan ish jarayonlari** — vazifalar/CRM maʼlumotlar bazasini
  filtrlar va saralashlar bilan `notion_query_database` orqali soʻrang, soʻng qatorlarni
  umumlashtiring yoki ustuvorlik boʻyicha ajrating.
- **Qayta yozish / jurnallash** — uchrashuv qaydlari, bajarilish xulosalari yoki agent
  natijalarini mavjud sahifaga qoʻshish uchun `notion_append_blocks` dan foydalaning
  (faqat qoʻshish; buzuvchi tahrirlar yoʻq).
- **Tuzilmani oʻrganish** — sahifaning bloklar daraxtini kezish uchun
  `notion_list_block_children` dan yoki maʼlumotlar bazasini soʻrashdan oldin uning
  xususiyatlar sxemasini aniqlash uchun `notion_get_database` dan foydalaning.
