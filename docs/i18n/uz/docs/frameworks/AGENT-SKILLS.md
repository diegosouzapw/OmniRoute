> **Haqiqat manbasi:** `src/lib/agentSkills/` (katalog, generator, parserlar) + `skills/` katalogi (SKILL.md fayllari)
> **Soʻnggi yangilanish:** 2026-08-02 — v3.8.50

Agent Skills — tashqi agentlar, MCP mijozlari va A2A orkestratorlariga OmniRoute REST API va CLI’dan qanday foydalanishni oʻrgatuvchi tuzilmali SKILL.md fayllaridir. [Omni Skills](./SKILLS.md)dan (OmniRoute ichida bajariladigan LLM vosita taʼriflari) farqli ravishda, Agent Skills — _hujjatlar katalogi_, yaʼni agent kontekstiga bevosita uzatilishi mumkin boʻlgan statik markdown.

---

## Umumiy koʻrinish

Katalogda **45 ta Agent Skill** mavjud (23 ta REST API + 21 ta CLI + 1 ta konfiguratsiya ish jarayoni). Har bir skill quyidagilarga ega:

- **Kanonik ID** (`omni-auth`, `cli-serve` va hokazo)
- `skills/{id}/SKILL.md` ichidagi YAML frontmatter (`name`, `description`) + batafsil markdown mazmuniga ega **SKILL.md** fayli
- OpenAPI spetsifikatsiyasi va CLI reyestridan olingan **REST endpointlari** (API skill’lari) yoki **CLI quyi buyruqlari** (CLI skill’lari)
- Jonli yuklab olish uchun **GitHub raw URL manzili**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

```markdown
---
name: omni-providers
description: "Provayder ulanishlarini boshqaring: hisob maʼlumotlarini qoʻshing, sinab koʻring, almashtiring va olib tashlang."

<!-- src/lib/agentSkills/generator.ts tomonidan generatsiya qilingan; qoʻlda kiritilgan oʻzgartirishlar ustiga yoziladi -->

## Umumiy koʻrinish

...

## Autentifikatsiya

...

## Endpointlar

...

<!-- skill:custom-start -->

## Maxsus boʻlim (qayta generatsiya qilish jarayonida saqlanadi)

...

```

Generator qayta generatsiya qilish jarayonida `<!-- skill:custom-start -->` va `<!-- skill:custom-end -->` orasidagi kontentni saqlab qoladi. Oʻnta skill saralangan maxsus bloklarga ega:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## REST API orqali aniqlash

| Oxirgi nuqta                 | Metod | Tavsif                                                                | Autentifikatsiya |
| :--------------------------- | :---- | :-------------------------------------------------------------------- | :--------------- |
| `/api/agent-skills`          | GET   | Katalog roʻyxati (ixtiyoriy `?category=api\|cli\|config&area=<area>`) | yoʻq             |
| `/api/agent-skills/{id}`     | GET   | Bitta koʻnikma metamaʼlumotlarini olish                               | yoʻq             |
| `/api/agent-skills/{id}/raw` | GET   | SKILL.md faylini `text/markdown` sifatida olish                       | yoʻq             |
| `/api/agent-skills/coverage` | GET   | Qamrov statistikasi (qancha SKILL.md fayli mavjudligi)                | yoʻq             |
| `/api/agent-skills/generate` | POST  | Generatorni ishga tushirish (dryRun/prune/onlyIds)                    | boshqaruv        |

Misol — barcha API koʻnikmalarini roʻyxatlash:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Misol — bitta SKILL.md faylini olish:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Tashqi agentlar ko‘nikmalardan qanday foydalanadi

### 1. REST orqali aniqlash

```bash
# To‘liq katalogni olish
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Kontekstga kiritish uchun SKILL.md faylini olish
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP orqali aniqlash

```typescript
// Claude Desktop / Cursor MCP mijozida:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → har biri uchun rawUrl mavjud bo‘lgan AgentSkill massivi
```

### 3. A2A orqali aniqlash

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table — barcha 45 ta ko‘nikma identifikatori va rawUrl ustunlarini o‘z ichiga olgan markdown jadvali
```

### 4. GitHub’dan to‘g‘ridan-to‘g‘ri raw formatida olish (server talab qilinmaydi)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generator

Generator saralangan katalog, OpenAPI spetsifikatsiyasi va CLI reyestrini o‘qiydi hamda har bir yozuv uchun `skills/{id}/SKILL.md` faylini yaratadi:

```bash
# Oldindan ko‘rish (sinov tariqasida ishga tushirish, fayllarga yozilmaydi)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# To‘liq qayta yaratish
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Muayyan identifikatorlarni qayta yaratish
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Generator javobi `GeneratorReport` hisoblanadi:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
