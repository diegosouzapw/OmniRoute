`agentrouter` yuqori oqim shlyuzi `messages[].content` tarkibiga kalit soʻzlarga asoslangan kontent filtrini qoʻllaydi. Filtr qisman deterministik (muayyan iboralarni har doim bloklaydi) va qisman ehtimollik asosida ishlaydi (soʻrovlar oqimiga sezgir — tezkor soʻrovlardan keyin yanada tajovuzkor boʻladi va kutish davridan soʻng tiklanadi).

WAF soʻrovni bloklaganda quyidagini qaytaradi:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Filtrning qamrovi

WAF faqat `messages[].content` tarkibini tekshiradi. U quyidagilarni tekshirmaydi:

- `system` soʻrovi
- Tuzilgan kontent bloklari (`tool_result`, `tool_use`, `thinking`, `image`)
- Vositaning `description` va `input_schema` maydonlari
- Soʻrov metamaʼlumotlari, sarlavhalari yoki model identifikatori

## Har doim bloklanadigan namunalar (harf registriga bogʻliq emas)

| Namuna                            | Izohlar                                               |
| --------------------------------- | ----------------------------------------------------- |
| Har qanday `Lorem ipsum` varianti | Toʻliq lotincha lorem lugʻati bloklanadi              |
| `language model` (alohida)        | "the language model" va "large language model" oʻtadi |
| `virtual assistant`               | "AI assistant" oʻtadi                                 |
| `I'm here to help`                | "here to help" iborasining oʻzi ham bloklanadi        |
| `Claude, made by Anthropic`       | Faqat toʻliq ibora                                    |

## Deyarli har doim bloklanadigan namunalar

| Namuna                                                          | Izohlar                                                       |
| --------------------------------------------------------------- | ------------------------------------------------------------- |
| `placeholder`                                                   | Alohida kelganda (parametr nomi va shu kabilar sifatida emas) |
| `dummy data`                                                    | Fiksturalar uchun keng tarqalgan boshlangʻich ibora           |
| `foo bar baz`                                                   | Kanonik oʻrinbosar ibora                                      |
| Takrorlanuvchi qisqa tokenlar (`AAA BBB CCC`, `test test test`) | Kalit soʻzlarni sunʼiy koʻpaytirishni aniqlovchi vosita       |

## Yuklama ostidagi xatti-harakat

Qisqa vaqt oraligʻida taxminan 5 ta tezkor soʻrovdan keyin WAF odatda oʻtadigan kontentni ham bloklay boshlaydi. Taxminan 5–10 soniyalik faoliyatsizlikdan keyin cheklov yumshaydi. Bu Claude Code yoki Codex CLI ketma-ket bir nechta vositadan foydalanish / xabar yuborish chaqiruvlarini tez amalga oshirganda vaqti-vaqti bilan `400 content-blocked` xatolariga sabab boʻladigan, ayni IP va kalitga bogʻlangan tezlik cheklovchisidir.

## OmniRoute’da allaqachon qoʻllangan yumshatish choralari

1. **`open-sse/services/wafRateLimit.ts`** — istalgan `agentrouter:*` URL manziliga yuboriladigan tashqi soʻrovlar orasida kamida 500 ms tanaffusni taʼminlaydigan keskin oqimdan himoya vositasi. Bu tanaffus inson sezadigan kechikish chegarasidan ancha past va odatiy trafikda WAF faollashishining oldini oladi.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — yuqori oqim `400 content-blocked` javobini qaytarganda, ijrochi eksponensial kutish bilan ayni URL manziliga soʻrovni qayta yuboradi (1.5 s, 3.0 s, koʻpi bilan 2 ta urinish). Kutishdan keyin WAF odatda yumshaydi va takroriy urinish muvaffaqiyatli yakunlanadi.

3. **`tests/unit/compression/harness.test.ts`** — Claude Code ushbu faylni `Read` vositasi orqali oʻqiganda, fayl tarkibi `tool_result` bloki orqali qaytib oʻtib WAF’ni ishga tushirmasligi uchun `longInput` test fiksturasi `"lorem ipsum dolor sit amet ".repeat(40)` qiymatidan `"example content for testing purposes ".repeat(40)` qiymatiga oʻzgartirildi.

## Soʻrovlar va vosita chiqishi boʻyicha koʻrsatmalar

Agar Claude Code yoki Codex CLI sessiyasi qayta-qayta `400 content-blocked` xatosiga duch kelsa, eng soʻnggi foydalanuvchi xabari va eng soʻnggi vosita natijasida yuqoridagi namunalardan biri mavjudligini tekshiring va iborani boshqacha ifodalang. Keng tarqalgan aylanib oʻtish usullari:

- `Lorem ipsum …` oʻrniga `example text …` yoki test yoxud fikstura modellashtirmoqchi boʻlgan haqiqiy kontentdan foydalaning.
- `placeholder` alohida kelganda, uni `example value`, `sample value` yoki haqiqiy qiymat bilan almashtiring.
- `language model` oʻrniga `large language model` yoki `the model` dan foydalaning.
- `dummy data` oʻrniga `sample data` yoki realistik boshlangʻich qiymatlardan foydalaning.
- `I'm here to help` / `here to help` oʻrniga aniqroq kirish jumlasidan foydalaning (masalan, "I'll review the file you mentioned").

## Notoʻgʻri ijobiy natijalar haqida yuqori oqimga xabar berish

Joriy filtr haddan tashqari tajovuzkor — operator soʻrovni kiritishni maqsad qilmagani aniq boʻlsa ham, u `tool_result` bloklaridagi "Lorem ipsum" iborasini bloklaydi. Buni manbaning oʻzida tuzatishni istagan operatorlar notoʻgʻri ijobiy natijalar haqida xabar berish uchun `agentrouter.org` bilan bogʻlanishlari kerak. Yuqoridagi bloklash roʻyxati 2026-08-03 holatiga koʻra yuqori oqimni sinab koʻrish orqali olingan empirik natijadir.
