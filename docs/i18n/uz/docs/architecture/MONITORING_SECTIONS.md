## Yuqori darajali navigatsiya

B guruhidan keyin boshqaruv panelining yon panelida quyidagi yuqori darajali bo‘limlar shu tartibda joylashadi:

```
Bosh sahifa
Provayderlar
Kombolar
API kalitlari
Sozlamalar
Tahlil
Xarajatlar     ← YANGI (B guruhi, 16-reja)
Monitoring     ← QAYTA TASHKIL ETILGAN (B guruhi, 16-reja)
...
```

---

## Xarajatlar bo‘limi (yangi, 1-daraja)

Yo‘l prefiksi: `/dashboard/costs/`

| Element          | URL                                  | Tavsif                                               |
| ---------------- | ------------------------------------ | ---------------------------------------------------- |
| Umumiy ko‘rinish | `/dashboard/costs`                   | Jamlangan xarajatlar paneli (Tahlildan ko‘chirilgan) |
| Narxlash         | `/dashboard/costs/pricing`           | Har bir model uchun narxlar jadvali                  |
| Budjet           | `/dashboard/costs/budget`            | Budjet chegaralari + ogohlantirishlar                |
| Kvotani ulashish | `/dashboard/costs/quota-share`       | Quota Share hovuzlari + foydalanish                  |
| Reja sozlamalari | `/dashboard/costs/quota-share/plans` | Har bir provayder uchun reja o‘zgartirishlari        |

**Asos**: Narxlash, Budjet va Kvotani ulashish avval
`Monitoring > Xarajatlar parametrlari` ostida edi. Ularni alohida yuqori darajali bo‘limga
ko‘chirish kuzatuv vositalari bo‘ylab o‘tmasdan topish imkonini beradi.

## Monitoring bo‘limi (qayta tashkil etilgan)

Monitoring bo‘limida endi **Faollik yuqorida** joylashgan va undan keyin **3 ta quyi guruh** keladi:

```
Monitoring
├── Faollik              ← Vaqt jadvali tasmasi (yuqori darajali element)
├── Jurnallar guruhi
│   ├── Jurnallar (barchasi)
│   ├── Proksi jurnallari
│   └── Konsol jurnallari
├── Audit guruhi
│   ├── Audit jurnali
│   ├── MCP auditi
│   └── A2A auditi
└── Tizim guruhi
    ├── Holat
    └── Bajarilish muhiti
```

### Eski tuzilishga nisbatan o‘zgarishlar

| Oldin                                                                                                  | Keyin                                           |
| ------------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| Faollik = Jurnallar ichidagi Audit jurnalini ko‘rsatadigan ichki varaq                                 | Faollik = alohida tasma (`/dashboard/activity`) |
| Monitoring ichidagi Xarajatlar parametrlari guruhi                                                     | Xarajatlar bo‘limiga ko‘chirildi                |
| Yassi ro‘yxat: Jurnallar, Faollik (jurnallar), Audit, Holat, Bajarilish muhiti, Narxlar, Budjet, Kvota | 3 guruhli tuzilma + alohida Xarajatlar bo‘limi  |

## Faollik va Audit jurnali

Endi ular bir-biridan farq qiladi:

| O‘lchov                       | Faollik (`/dashboard/activity`)                                            | Audit jurnali (`/dashboard/audit`)                  |
| ----------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------- |
| **Maqsad**                    | Foydalanuvchiga mo‘ljallangan hodisalar tasmasi (“yaqinda nima yuz berdi”) | Muvofiqlik / xavfsizlik jurnali                     |
| **Ma’lumotlar manbai**        | `GET /api/compliance/audit-log?level=high`                                 | `GET /api/compliance/audit-log?level=all`           |
| **Format**                    | Kun bo‘yicha guruhlangan vaqt jadvali, tushunarli fe’llar + ikonalar       | Zich sahifalangan jadval, har sahifada 50 ta        |
| **Filtrlar**                  | Hodisa turi toifasi                                                        | Amal, jiddiylik darajasi, bajaruvchi, sana oralig‘i |
| **Eksport**                   | Mavjud emas                                                                | JSON eksporti                                       |
| **Bajaruvchi filtri**         | Qo‘llanilmaydi                                                             | Bajaruvchi bo‘yicha filtrlash mumkin                |
| **Ko‘rsatiladigan hodisalar** | Faqat yuqori darajali amallar (ruxsat etilganlar ro‘yxati)                 | Barcha audit hodisalari                             |

### Yuqori darajali amallarning ruxsat etilganlar ro‘yxati

`src/lib/audit/highLevelActions.ts` faylida belgilangan. Faollik tasmasida qaysi hodisalar
ko‘rsatilishini boshqaradi. Ruxsat etilganlar ro‘yxatiga quyidagilar kiradi:

- Provayderni qo‘shish/o‘chirish/sinash hodisalari
- Komboni yaratish/yangilash/o‘chirish
- API kalitining hayot sikli (yaratish, bekor qilish, almashtirish)
- Budjet chegarasiga yetish
- Autentifikatsiyaga kirish/chiqish
- Bulutli agent seansini yaratish
- MCP vositasini ro‘yxatdan o‘tkazish
- Webhukni yaratish/o‘chirish
- Kvota hovuzi/rejasi o‘zgarishlari (`quota.*` amallari, B guruhi)
- Platforma hodisalari (yangilash, joylashtirish)
- Ko‘nikmani o‘rnatish/o‘chirish

Bu ro‘yxatda bo‘lmagan hodisalar faqat Audit jurnalida ko‘rsatiladi.

### Yangi yuqori darajali amal qo‘shish

`src/lib/audit/highLevelActions.ts` faylini tahrirlang va amal satrini
`HIGH_LEVEL_ACTIONS` ro‘yxatiga qo‘shing. Buning uchun PR talab qilinadi (ro‘yxat kodda berilgan, uni DB orqali sozlab bo‘lmaydi).
Tegishli ikonani `src/lib/audit/activityIcons.ts` fayliga qo‘shish mumkin.

## Qayta yo‘naltirish: `/dashboard/logs/activity`

Eski `/dashboard/logs/activity` yo‘li
`src/app/(dashboard)/dashboard/logs/activity/page.tsx` faylidagi `permanentRedirect()` orqali
`/dashboard/activity` manziliga doimiy ravishda qayta yo‘naltiriladi (HTTP 308).

Eski yon panel IDsi `logs-activity` eski IDga havola qiluvchi foydalanuvchi
andozalarini buzmaslik uchun `HIDEABLE_SIDEBAR_ITEM_IDS` ichida saqlangan
(ammo `SIDEBAR_DEFINITIONS` ichidan olib tashlangan).
