> `src/shared/constants/providers.ts` faylidan **avtomatik yaratilgan** — qoʻlda tahrirlamang.
> Qayta yaratish uchun: `npm run gen:provider-reference`
> **Oxirgi marta yaratilgan:** 2026-10-10

Provayderlar jami: **372**. Quyida toifalar boʻyicha taqsimotni koʻring.

## Toifalar

- **Bepul** — API kaliti bilan bepul tarif (boshqaruv paneli orqali sozlanadi)
- **Autentifikatsiyasiz** — umuman kalit yoki tizimga kirishni talab qilmaydigan ommaviy soʻnggi nuqtalar
- **OAuth** — tizimga kirish jarayoni OmniRoute tomonidan boshqariladi, API kaliti talab qilinmaydi
- **Veb cookie** — cookie autentifikatsiyasi orqali provayderning veb-ilovasini oʻrab ishlatadi
- **API kaliti** — API kaliti orqali sozlanadigan pulli provayder (bepul kreditlar taqdim etilishi mumkin)
- **Mahalliy** — foydalanuvchining kompyuterida ishlaydi (Ollama, LM Studio, vLLM va boshqalar)
- **Qidiruv** — veb-qidiruv provayderlari
- **Audio** — faqat audio bilan ishlaydigan provayderlar (TTS/STT)
- **Yuqori oqim proksisi** — boshqa provayderlarga proksi qiluvchi provayderlar
- **Bulut agenti** — uzoq vaqt ishlaydigan kodlash agentlari (Codex Cloud, Devin, Jules)
- **Tizim** — OmniRoute ichki provayderlari (loopback va boshqalar)

Qoʻshimcha teglar: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Vositalarni chaqirish` (koʻrsatilgan joylarda): `native` — haqiqiy funksiyalarni chaqirish API-si; `emulated` — `tools` massivi `webTools.ts` orqali prompt yordamida emulyatsiya qilinadi (muntazam ifoda bilan tahlil qilinadigan `<tool>{...}</tool>` bloklari); `none` — hozirda `tools` hech qanday ogohlantirishsiz tashlab yuboriladi. #7286 ga qarang.

Har bir provayderni yoqish, sozlash va sinash uchun `/dashboard/providers` manzilidagi boshqaruv panelidan foydalaning.
