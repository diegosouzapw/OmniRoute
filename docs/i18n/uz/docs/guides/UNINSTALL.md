## Tezkor o‘chirish (v3.6.2+)

OmniRoute toza o‘chirish uchun ikkita ichki skriptni taqdim etadi:

### Ma’lumotlaringizni saqlab qolish

```bash
npm run uninstall
```

Bu OmniRoute ilovasini o‘chiradi, ammo `~/.omniroute/` ichidagi ma’lumotlar bazasi, konfiguratsiyalar, API kalitlari va provayder sozlamalarini **saqlab qoladi**. Keyinroq qayta o‘rnatishni rejalashtirsangiz va sozlamalaringizni saqlab qolmoqchi bo‘lsangiz, bundan foydalaning.

### To‘liq o‘chirish

```bash
npm run uninstall:full
```

Bu ilovani o‘chiradi va barcha ma’lumotlarni **butunlay yo‘q qiladi**:

- Ma’lumotlar bazasi (`storage.sqlite`)
- Provayder konfiguratsiyalari va API kalitlari
- Zaxira fayllari
- Jurnal fayllari
- `~/.omniroute/` katalogidagi barcha fayllar

> ⚠️ **Ogohlantirish:** `npm run uninstall:full` amalini ortga qaytarib bo‘lmaydi. Barcha provayder ulanishlaringiz, kombinatsiyalaringiz, API kalitlaringiz va foydalanish tarixingiz butunlay o‘chiriladi.

## Qo‘lda o‘chirish

### NPM global o‘rnatmasi

```bash
# Global paketni o‘chirish
npm uninstall -g omniroute

# (Ixtiyoriy) Ma’lumotlar katalogini o‘chirish
rm -rf ~/.omniroute
```

### pnpm global o‘rnatmasi

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Konteynerni to‘xtatish va o‘chirish
docker stop omniroute
docker rm omniroute

# Jildni o‘chirish (barcha ma’lumotlarni o‘chiradi)
docker volume rm omniroute-data

# (Ixtiyoriy) Tasvirni o‘chirish
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Konteynerlarni to‘xtatish va o‘chirish
docker compose down

# Jildlarni ham o‘chirish (barcha ma’lumotlarni o‘chiradi)
docker compose down -v
```

### Electron ish stoli ilovasi

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` bo‘limini oching
- Yoki o‘rnatish katalogidan NSIS o‘chirish dasturini ishga tushiring

**macOS:**

- `/Applications` ichidagi `OmniRoute.app` faylini chiqindilar qutisiga olib o‘ting
- Ma’lumotlarni o‘chirish: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage faylini o‘chiring
- Ma’lumotlarni o‘chirish: `rm -rf ~/.omniroute`

### Manba kodidan o‘rnatish (git clone)

```bash
# Klonlangan katalogni o‘chirish
rm -rf /path/to/omniroute

# (Ixtiyoriy) Ma’lumotlar katalogini o‘chirish
rm -rf ~/.omniroute
```

## Ma’lumotlar kataloglari

Odatiy holatda OmniRoute ma’lumotlarni quyidagi joylarda saqlaydi:

| Platforma     | Standart yo‘l                 | Qayta belgilash                       |
| ------------- | ----------------------------- | ------------------------------------- |
| Linux         | `~/.omniroute/`               | `DATA_DIR` muhit o‘zgaruvchisi        |
| macOS         | `~/.omniroute/`               | `DATA_DIR` muhit o‘zgaruvchisi        |
| Windows       | `%APPDATA%/omniroute/`        | `DATA_DIR` muhit o‘zgaruvchisi        |
| Docker        | `/app/data/` (ulangan jild)   | `DATA_DIR` muhit o‘zgaruvchisi        |
| XDG bilan mos | `$XDG_CONFIG_HOME/omniroute/` | `XDG_CONFIG_HOME` muhit o‘zgaruvchisi |

### Ma’lumotlar katalogidagi fayllar

| Fayl/katalog         | Tavsif                                                                          |
| -------------------- | ------------------------------------------------------------------------------- |
| `storage.sqlite`     | Asosiy ma’lumotlar bazasi (provayderlar, kombinatsiyalar, sozlamalar, kalitlar) |
| `storage.sqlite-wal` | SQLite yozishdan oldingi jurnali (vaqtinchalik)                                 |
| `storage.sqlite-shm` | SQLite umumiy xotirasi (vaqtinchalik)                                           |
| `call_logs/`         | So‘rov yuklamalari arxivlari                                                    |
| `backups/`           | Ma’lumotlar bazasining avtomatik zaxira nusxalari                               |
| `log.txt`            | Eski so‘rovlar jurnali (ixtiyoriy)                                              |

## Toʻliq olib tashlanganini tekshirish

Oʻchirib tashlaganingizdan soʻng, hech qanday fayl qolmaganini tekshiring:

```bash
# Global npm paketini tekshirish
npm list -g omniroute 2>/dev/null

# Maʼlumotlar katalogini tekshirish
ls -la ~/.omniroute/ 2>/dev/null

# Ishlayotgan jarayonlarni tekshirish
pgrep -f omniroute
```

Agar biror jarayon hali ham ishlayotgan boʻlsa, uni toʻxtating:

```bash
pkill -f omniroute
```
