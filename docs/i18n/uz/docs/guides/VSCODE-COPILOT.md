**OmniCopilot** OmniRoute taqdim etadigan barcha modellarni GitHub Copilot Chat’ning _mahalliy_
model tanlagichiga joylashtiradi. Ikkinchi yon panel ham, alohida chat interfeysi ham yoʻq — Copilot’ning agent rejimi, vositalarni chaqirish,
MCP serverlari va maxsus koʻrsatmalari ishlashda davom etadi, faqat siz tanlagan modelda ishlaydi.

## Sozlash

1. **OmniRoute’ni ishga tushiring** — `npm install -g omniroute && omniroute` (boshqaruv paneli `http://localhost:20128` manzilida).
2. **Kengaytmani oʻrnating** — Extensions koʻrinishida "OmniRoute" deb qidiring.
3. **Modelni tanlang** — Copilot Chat → model tanlagichi → **Manage Models…** → **OmniRoute**, soʻng
   kerakli modellarni belgilang.

OmniRoute standart portda ishlayotganida hech narsani sozlash shart emas. Masofaviy nusxa uchun
**Activity Bar’dagi OmniRoute belgisini** oching (yoki `OmniRoute: Manage Connection` buyrugʻini ishga tushiring) va quyidagilarni belgilang:

- **Server URL** — serverning asosiy manzili, masalan, `http://192.168.0.15:20128`. `/v1` suffiksi
  kengaytma tomonidan qoʻshiladi; uni kiritmang.
- **API kaliti** — faqat serverda `REQUIRE_API_KEY` oʻrnatilgan boʻlsa. VS Code SecretStorage orqali
  operatsion tizim kalitlar omborida saqlanadi, `settings.json` faylida hech qachon saqlanmaydi.

## Tanlagichda nimalar koʻrsatiladi

Kengaytma `GET /v1/models` soʻrovining xom natijasini koʻrsatmaydi — u natijani shakllantiradi va siz
koʻradigan son katalog hajmidan ataylab ikki sababga koʻra kichikroq boʻladi.

### Har bir model uchun bitta id soʻraydi

`MODELS_CATALOG_PREFIX_MODE` standart holatda **`dual`** qiymatiga ega boʻlib, har bir modelni ikki marta — bir marta
qisqa taxallus prefiksi bilan va bir marta kanonik provayder prefiksi bilan — eʼlon qiladi, shu sababli eski mijoz
konfiguratsiyalari har ikkala shaklni ham aniqlay oladi:

```
cc/claude-sonnet-4-6        ← taxallus prefiksi
claude/claude-sonnet-4-6    ← kanonik prefiks, ayni model
```

Kengaytma **`GET /v1/models?prefix=alias`** soʻrovini yuboradi, natijada boshqa mijozlaringiz uchun
umumserver sozlamasini oʻzgartirmasdan har bir modelga bittadan id olinadi. Namunaviy nusxada bu
**2345 ta yozuvni 1396 tagacha qisqartirdi — 949 ta dublikat, yoʻqotilgan modellar soni esa nol.**

Agar buni _har bir_ mijoz uchun server miqyosida tuzatishni istasangiz, boshqaruv panelida
`MODELS_CATALOG_PREFIX_MODE` funksiya bayrogʻini `alias` qiymatiga oʻrnating. Soʻrov
parametri va har bir rejim jadvali uchun
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) boʻlimiga qarang.

### Chat qila olmaydigan modellarni yashiradi

Katalogda tasvir, video, audio, qayta tartiblash, embedding va moderatsiya modellari ham keltirilgan. Ular
chat soʻrovida baribir rad etiladi:

```
HTTP 400 — '<id>' modeli tasvir yaratish modeli boʻlib, undan
/v1/chat/completions manzilida foydalanib boʻlmaydi. Buning oʻrniga POST /v1/images/generations dan foydalaning.
```

shu sababli ular tanlagichga yetib borishidan oldin `type` maydoni boʻyicha filtrlanadi. **Responses-API
modellari saqlab qolinadi** — har bir Codex / GPT-5.x yozuvi `supported_endpoints: ["responses"]` ni eʼlon qiladi
va OmniRoute ularni `/v1/chat/completions` uchun tarjima qiladi, shu bois ulardan bemalol foydalanish mumkin.

### Siz hech qachon sozlamagan provayderlar

Katalogda **faol ulanishga** ega provayderlar modellari hamda barcha **noAuth**
provayderlari — bepul darajaning katta qismini tashkil etuvchi kalitsiz provayderlar — keltiriladi. Bu ataylab qilingan. Ularni yashirish uchun
boshqaruv paneli sozlamalaridagi `blockedProviders` roʻyxatiga qoʻshing; kengaytmada hech narsa oʻzgarmaydi.

## VS Code ichidagi ichki oynada boshqaruv paneli

`omnicopilot.dashboardOpen: "editor"` sozlamasi OmniRoute boshqaruv panelini tashqi brauzer o‘rniga Simple Browser orqali muharrir ichki oynasida ko‘rsatadi. Ichki joylashtirish serverda **ixtiyoriy ravishda yoqiladi**: `DASHBOARD_ALLOW_EMBED=vscode` orqali HTML sahifalar standart `frame-ancestors 'none'` + `X-Frame-Options: DENY` o‘rniga `frame-ancestors 'self' vscode-webview:` bilan taqdim etiladi. API yuzasi (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) har qanday holatda ham qat’iy sarlavhalarni saqlab qoladi.

> ⚠️ **Bu bajarilish vaqtida emas, qurish vaqtida ishlatiladigan bayroq.** Next.js `headers()` funksiyasini marshrut manifestiga kompilyatsiya qiladi, shuning uchun `next.config.mjs` o‘zgaruvchini to‘plam qurilayotgan paytda o‘qiydi
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Uni allaqachon qurilgan serverni ishga tushirishdan oldin eksport qilish hech narsani o‘zgartirmaydi — sarlavhalar qurilmaga singdirilgan.

```bash
# o‘zgaruvchi BUILD buyrug‘ida mavjud bo‘lishi kerak
DASHBOARD_ALLOW_EMBED=vscode npm run build        # yoki npm run build:release
npm start
```

| Qanday o‘rnatgansiz        | Ichki joylashtirishni yoqa olasizmi?                                                                                                                        |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Manba kodidan              | ✅ yuqorida ko‘rsatilganidek, o‘zgaruvchini qurish buyrug‘ida belgilang                                                                                     |
| `npm install -g omniroute` | ❌ e’lon qilingan paket oldindan qurilgan to‘plam bilan yetkaziladi — buning o‘rniga manba kodidan quring                                                   |
| Docker tasviri             | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — Docker Hub’dagi oldindan qurilgan tasvirda ichki joylashtirish yoqilmagan |

Ichki joylashtirish yoqilgan qurilma bo‘lmasa, sahifa freym ichida ko‘rsatilishni rad etadi; kengaytma buni javob sarlavhalaridan aniqlaydi va tashqi brauzerga qaytadi — hech narsa buzilmaydi va bu haqda bir marta xabar beradi.
[`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) va
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273) muammosiga qarang.
