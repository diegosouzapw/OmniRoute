OmniRoute qoʻllab-quvvatlanadigan 352 ta provayderni 3 ta iqtisodiy darajaga ajratadi. Har bir
soʻrov muvaffaqiyatli javob qaytarilguncha ular orqali ketma-ket oʻtadi — siz
hech qanday zaxira kodini yozmasdan, eng arzon yaroqli javobni olasiz.

## 1-daraja — Obuna

**Siz allaqachon haq toʻlayotgan provayderlar.** OmniRoute kvota muddati
tugashidan oldin undan toʻliq foydalanadi.

| Provayder                      | Nega 1-daraja                                              |
| ------------------------------ | ---------------------------------------------------------- |
| Claude Code OAuth              | Anthropic Pro/Team — qatʼiy tarif, koʻpincha ishlatilmaydi |
| OpenAI Codex (ChatGPT obunasi) | Plus/Team Codex kvotasini oʻz ichiga oladi                 |
| GitHub Copilot                 | Har bir foydalanuvchi uchun — kvota har oy yangilanadi     |
| Cursor IDE                     | Pro tarif kvotasi                                          |
| Antigravity / Devin Desktop    | Ichki kvotalar                                             |

**Strategiya**: modelning kuchli jihatlariga mos keladigan har bir soʻrovni avval shu yerga yoʻnaltiring.
Kvota kuzatuvchisi yaqinlashayotgan yangilanishlarni nazorat qiladi va `reset-aware`
kombinatsion strategiyasi ustuvorliklarni shunga muvofiq belgilaydi. Avval 1-darajaga yoʻnaltirish va
faqat kvota tugaganda pullik darajalarga oʻtish uchun `auto/thrifty` identifikatoridan foydalaning — yoki
tarifga kiritilgan sigʻim doirasida qolish va aks holda xato bilan yopilish uchun `auto/subscription`
identifikatoridan foydalaning.
[Avval obunaga yoʻnaltirish](../routing/SUBSCRIPTION_LADDER.md) sahifasiga qarang.

## 2-daraja — Arzon

**1 mln token uchun $1 dan arzon, token boʻyicha haq olinadigan provayderlar.** Katta hajmdagi ishlar
uchun yoki 1-daraja kvotalari limitga yetganidan keyin foydalanish uchun ajratilgan.

| Provayder                                      | Narx (kiritish/chiqarish) | Kuchli jihatlari       |
| ---------------------------------------------- | ------------------------- | ---------------------- |
| DeepSeek V4 Pro                                | 1 mln uchun $0.27 / $1.10 | Kod, mulohaza yuritish |
| GLM-4.5                                        | 1 mln uchun $0.60 / $2.20 | Uzun kontekst          |
| MiniMax M1                                     | 1 mln uchun $0.20 / $1.10 | Tezlik                 |
| Qwen Coder                                     | 1 mln uchun $0.30 / $1.20 | Kod                    |
| OpenRouter (narx boʻyicha optimallashtirilgan) | turlicha                  | 100+ model, dinamik    |

**Strategiya**: `cost-optimized` kombinatsiyasi vazifaning imkoniyatlar filtriga
(tasvir, JSON rejimi, vositalar, maksimal kontekst) mos keladigan, token uchun narxi eng past modelni tanlaydi.

## 3-daraja — Bepul

**Nol xarajatli provayderlar** — bepul tariflar, kredit dasturlari, kunlik OAuth kvotalari.

| Provayder        | Bepul kvota / kreditlar                                   |
| ---------------- | --------------------------------------------------------- |
| Kiro AI          | Bepul Claude tarifi (saxiy adolatli foydalanish)          |
| OpenCode Free    | Autentifikatsiya talab qilinmaydi, saxiy tezlik limitlari |
| Qoder            | Bepul OAuth                                               |
| Google Vertex AI | Yangi hisob uchun $300 kredit                             |
| Amazon Q         | AWS foydalanuvchilari uchun bepul tarif                   |
| Pollinations     | Ochiq ommaviy API                                         |
| Cloudflare AI    | Workers AI bepul tarifi                                   |

**Strategiya**: budjet chekloviga ega `auto` kombinatsiyasi 1+2-darajalar ishlamaganda
yoki `useFreeOnly=true` oʻrnatilganda soʻrovlarni shu yerga yoʻnaltiradi. Bepul provayderlarda koʻpincha
tezlik limitlari qatʼiyroq boʻladi — avtomatik uzgich kutish muddatidan soʻng ularni qayta tiklaydi.

## Darajalarni sozlash

Boshqaruv paneli → **Darajalar** → provayderlaringizni belgilang. Standart sozlamalar (`tierDefaults.json` faylidan)
maqbul; muayyan obunalarga ustuvorlik berish yoki ayrim provayderlarni chiqarib tashlash kerak boʻlsa, ularni tahrirlang.

Auto-Combo’ning 16 omilli baholashi darajani ham hisobga oladi.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) sahifasiga qarang.

## Telemetriya

Boshqaruv paneli → **Foydalanish** har bir daraja boʻyicha kuniga sarflangan tokenlarni koʻrsatadi. Bundan quyidagilar uchun foydalaning:

- 1-darajadan toʻliq foydalanilayotganini tasdiqlash (aks holda obuna qiymatini behuda sarflayapsiz)
- Qaysi 2-daraja modellari eng koʻp tanlanayotganini aniqlash (ularni 1–2 taga birlashtirish)
- 3-daraja sinov/tadqiqot ish yuklarida mablagʻni tejayotganini tekshirish

## Keng tarqalgan usullar

### Toʻliq bepul ish yuki

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

3-darajaga yoʻnaltirishni kuchli ragʻbatlantiradi; faqat 3-daraja mavjud boʻlmaganda 2-darajadan foydalanadi.

### Arzon zaxira variantiga ega, avval obunadan foydalanish

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

1-daraja → 2-daraja → 3-darajaga mos keladigan aniq tartiblangan roʻyxat.
