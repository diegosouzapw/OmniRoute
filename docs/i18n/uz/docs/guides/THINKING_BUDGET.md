> **Boshqaruv paneli:** Sozlamalar → **AI** → Fikrlash budjeti  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **Manba:** `open-sse/services/thinkingBudget.ts`

Fikrlash budjeti OmniRoute provayderlarga yuborish jarayonida **mijozning fikrlash/mulohaza yuritish parametrlarini qayta yozishi yoki yozmasligini** boshqaradi. U siqish, yoʻnaltirish yoki prompt keshini yoqmaydi hamda oʻchirmaydi.

## Rejimlar

| Rejim                        | OmniRoute nima qiladi                                                                                                       | Qachon foydalanish kerak                                                                                                                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (standart) | Mijoz maydonlarini oʻzgartirmaydi (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config` va hokazo). | **Codex / Desktop / harakat darajasi va mulohaza xulosalarini mijoz boshqarishi kerak boʻlgan har qanday mijoz.** Mijoz `reasoning.summary` soʻraganda koʻrinadigan fikrlash panellari uchun zarur. |
| **`auto`**                   | Yuqori oqimga yuborishdan oldin soʻrov tanasidan **barcha** fikrlash/mulohaza yuritish maydonlarini olib tashlaydi.         | Faqat **provayder** standart qiymatlarni oʻzi belgilashini ataylab xohlasangiz va mijoz boshqaradigan fikrlash kerak boʻlmasa. Bu “fikrlashni avtomatik koʻrsatish” degani **emas**.                |
| **`custom`**                 | Har bir soʻrovni belgilangan fikrlash tokenlari budjeti bilan qayta yozadi.                                                 | Barcha trafik uchun fikrlash tokenlariga qatʼiy cheklov qoʻyish.                                                                                                                                    |
| **`adaptive`**               | Xabarlar soni, vositalar va prompt uzunligidan foydalanib, bazaviy harakat darajasi asosida budjetni masshtablaydi.         | Mijoz niyatini toʻliq olib tashlamasdan tokenlarni moslashuvchan boshqarish.                                                                                                                        |

### `auto` nimalarni olib tashlaydi

Rejim `auto` boʻlganda, `stripThinkingConfig()` quyidagilarni (boshqalar qatori) oʻchiradi:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking` va mavjud boʻlganda `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

Agar mijoz (masalan, Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` yuborgan boʻlsa, **auto ushbu obyektni olib tashlaydi**. Yuqori oqim hali ham ayrim mulohaza yuritish tokenlari uchun haq olishi mumkin, ammo koʻpincha **boʻsh yoki faqat shifrlangan** mulohaza elementlarini qaytaradi — natijada foydalanuvchi interfeysida foydali fikrlash oqimi koʻrinmaydi.

## Bu nima **emas**

| Funksiya                                                 | Bogʻliqlik                                                                                                                                           |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Siqish** (Caveman, RTK, stacked, …)                    | Alohida konveyer. Har bir fikrlash budjeti rejimida ishlaydi.                                                                                        |
| **Prompt / semantik kesh**                               | Alohida. Fikrlash budjeti rejimi taʼsir qilmaydi.                                                                                                    |
| **Kombinatsiyalangan yoʻnaltirish / zaxira variantlari** | Alohida. Taʼsir qilmaydi.                                                                                                                            |
| **API kaliti token cheklovlari / xarajat budjetlari**    | Alohida. Taʼsir qilmaydi.                                                                                                                            |
| **Mulohazani qayta ijro etish keshi**                    | Qatʼiy provayderlar (DeepSeek, Kimi, Qwen-thinking, …) uchun koʻp bosqichli qayta kiritish. Desktop’dagi “fikrlashni koʻrsatish” bilan bir xil emas. |
| **`encrypted_content` shifrini ochish**                  | **Imkonsiz.** OpenAI/Codex’ning maxfiy mulohaza bloblari yopiq. OmniRoute ularni hech qachon shifrdan chiqarmaydi (#7095 / #7176 / #7304).           |

## Koʻrinadigan fikrlash (Codex / Responses mijozlari)

Mijoz fikrlash matnini koʻrsatishi uchun quyidagilarning **barchasi** talab qilinadi:

1. Thinking Budget rejimi = **`passthrough`** (yoki siz foydalanadigan yoʻl uchun xulosa soʻrovlarini yetarli darajada oʻzgartirmay qoldiradigan custom/adaptive).
2. Mijoz xulosa soʻraydi, masalan, Codex `model_reasoning_summary = "detailed"` / `auto` (`none` emas).
3. Yuqori oqim haqiqatda `response.reasoning_summary_text.*` ni uzatadi (yoki elementda boʻsh boʻlmagan `reasoning.summary` mavjud).

Agar faqat “shifrlangan maxfiy fikrlash” olsangiz, buning sababi quyidagilardan biri:

- rejim **`auto`** boʻlgan (mijoz soʻrovi olib tashlangan), yoki
- yuqori oqim xulosa matnisiz `encrypted_content` qaytargan (provayder cheklovi; OmniRoute oddiy matnni emas, faqat oʻrinbosarni koʻrsata oladi).

## API misollari

```bash
# Oʻqish
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Codex / Desktopʼda fikrlashni koʻrsatish uchun tavsiya etiladi
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Sxema (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; ixtiyoriy `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### Saqlanish / qayta ishga tushirish

Qiymat sozlamalardagi `thinkingBudget` kaliti ostida saqlanadi va jarayon ishga tushganda yuklanadi (`hydrateThinkingBudgetConfig`). DB orqali yoki ayrim APIʼdan tashqari yoʻllar orqali oʻzgartirilgandan soʻng, xotiradagi singleton diskdagi qiymatga mos kelishi uchun **OmniRoute jarayonini qayta ishga tushiring**.

## Operator nazorat roʻyxati

- [ ] Codex / Desktop foydalanuvchilari: rejim = **passthrough**
- [ ] Fikrlashni olib tashlash orqali emas, **xabarlar** uchun tokenlarni tejashni istasangiz, siqishni yoqilgan holda qoldiring
- [ ] `auto` “koʻproq fikrlashni koʻrsatadi” deb kutmang
- [ ] Faqat shifrlangan xulosalar — **provayder** xatti-harakati; passthrough ularni shifrdan chiqara olmaydi
