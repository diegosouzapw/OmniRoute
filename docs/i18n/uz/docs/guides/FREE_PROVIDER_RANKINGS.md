> **Qisqacha**: OmniRoute o‘zining **bepul** provayderlarini model sifati bo‘yicha **Arena AI
> (LMArena uslubidagi) ELO ballari** yordamida saralaydi. Vazifangiz uchun eng kuchli
> modellarni taqdim etuvchi bepul provayderlarni ko‘rish uchun boshqaruv panelidagi
> **Bepul provayderlar reytingi** sahifasini oching — umumiy yoki toifa bo‘yicha
> filtrlangan holda (kodlash, tekshirish, hujjatlashtirish, nosozliklarni tuzatish).

---

## Bu nima

OmniRoute 329 ta provayderni ro‘yxatdan o‘tkazadi, jumladan **bepul/autentifikatsiyasiz**
deb belgilangan 155 ta katalog yozuvini (autentifikatsiyasiz,
bepul darajadagi OAuth yoki bepul darajadagi API kaliti —
[Bepul darajalar qo‘llanmasi](../getting-started/FREE-TIERS-GUIDE.md) va to‘liq
[Bepul darajalar katalogi](../reference/FREE_TIERS.md) bilan tanishing). Muammo shundaki,
bepul provayderlarning model sifati keskin farq qiladi. Eng ilg‘or modelni taqdim etuvchi
autentifikatsiyasiz provayder kichik, eskirgan modelni taqdim etuvchidan ancha foydaliroq.

**Bepul provayderlar reytingi** har bir bepul provayder katalogini **Arena AI reyting
jadvali**dagi **ommaviy baholash asosidagi sifat ballari** bilan birlashtirib
(LMArena chatbot arenasidagi kabi, inson afzalliklariga asoslangan ELO),
“**qaysi bepul provayder menga eng yaxshi modelni beradi?**” degan savolga javob beradi.
So‘ng provayderlar o‘zlarining **eng yaxshi bepul modeli** kuchiga ko‘ra saralanadi.

Reyting uchta haqiqiy manba asosida hisoblanadi:

1. Bepul provayderlar ro‘yxatlari — `NOAUTH_PROVIDERS`, shuningdek, `hasFree` bilan
   belgilangan `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` yozuvlari
   (`src/shared/constants/providers.ts`).
2. Provayder reyestridagi har bir provayderning modellar katalogi
   (`open-sse/config/providerRegistry.ts`).
3. Arena ELO sinxronlash mexanizmi (`src/lib/arenaEloSync.ts`) tomonidan
   `model_intelligence` DB jadvalida saqlanadigan ELO asosidagi vazifaga moslik ballari.

Birlashtirish mantiqi `src/lib/freeProviderRankings.ts` faylida joylashgan.

## Qanday kirish mumkin

### Boshqaruv paneli sahifasi

Boshqaruv panelini oching va **Xarajatlar → Bepul provayderlar reytingi** bo‘limiga
o‘ting yoki to‘g‘ridan-to‘g‘ri quyidagi manzilga kiring:

```
/dashboard/free-provider-rankings
```

Sahifada (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) quyidagilar
ko‘rsatiladi:

- Eng yuqori o‘rinlarni egallagan bepul provayderlardan iborat **eng yaxshi 3 talik
  shohsupasi** (🥇 🥈 🥉).
- Quyidagi ustunlarga ega to‘liq **reyting jadvali**: **O‘rin**, **Provayder**,
  **Eng yaxshi model**, **Ball**, **O‘rtacha ball**, **Modellar**, **Tur**.
- **Toifa filtri tugmalari**: _Barcha toifalar_, _Standart_, _Kodlash_, _Tekshirish_,
  _Hujjatlashtirish_, _Nosozliklarni tuzatish_.

Har bir provayderning **Tur** belgisi uning qanday qilib bepul ekanini ko‘rsatadi:

| Belgi    | Ma’nosi                                              |
| -------- | ---------------------------------------------------- |
| `NOAUTH` | Har doim bepul, hisob ma’lumotlari talab qilinmaydi  |
| `OAUTH`  | Bepul darajaga ega OAuth provayderi (`hasFree`)      |
| `APIKEY` | Bepul darajaga ega API kaliti provayderi (`hasFree`) |

Ballar xom raqamlar o‘rniga o‘qish uchun qulay yorliqlar (masalan, _Elita_,
_A’lo_, _Juda yaxshi_, _Yaxshi_, _O‘rtacha_) ko‘rinishida beriladi, chunki asosiy
qiymat foiz emas, balki nisbiy reyting sifatidir.

### API so‘nggi nuqtasi

Sahifa hammaga ochiq o‘qish so‘nggi nuqtasi
(`src/app/api/free-provider-rankings/route.ts`) tomonidan quvvatlanadi:

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

So‘rov parametrlari (Zod yordamida tekshiriladi):

| Parametr   | Tur    | Standart | Izohlar                                                                                                                    |
| ---------- | ------ | -------- | -------------------------------------------------------------------------------------------------------------------------- |
| `category` | string | (yo‘q)   | `default`, `coding`, `review`, `documentation`, `debugging` qiymatlaridan biri. Birlashtirilgan reyting uchun ko‘rsatmang. |
| `limit`    | number | `50`     | `1–100` oralig‘i bilan cheklanadi.                                                                                         |

Javob tuzilishi:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` — Arena ELO’ning dastlabki qiymati; `score` esa normallashtirilgan vazifaga
moslik qiymatidir (quyiga qarang). Baholangan modellari mavjud bo‘lmagan provayderlar
javobdan chiqarib tashlanadi.

## Ballar qanday ishlaydi

### Manba: Arena AI reyting jadvali

Arena ELO sinxronlash mexanizmi (`src/lib/arenaEloSync.ts`) Arena AI reyting jadvali API manzilidan
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`) ikkita reyting jadvalini — `text`
va `code` — oladi. Har bir reyting yozuvi model nomi, taʼminotchi, ELO `score`, ishonch oraligʻi
va ovozlar sonini oʻz ichiga oladi.

Reyting jadvali toifalari OmniRoute vazifa toifalariga quyidagicha mos keladi:

| Arena reyting jadvali | OmniRoute vazifa toifalari                        |
| --------------------- | ------------------------------------------------- |
| `text`                | `default`, `review`, `documentation`, `debugging` |
| `code`                | `coding`                                          |

### Normalizatsiya (vazifaga moslik bali)

Dastlabki ELO ballari har bir reyting jadvali uchun **`[0.4, 0.98]` oraligʻidagi vazifaga moslik qiymatiga** normalizatsiya qilinadi:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Ball hech qachon `0` yoki `1` ga yetmaydi, bu esa foydalanuvchi tomonidan qayta belgilash uchun
zaxira qoldiradi. Bu API javobida koʻrinadigan `score` maydoni va boshqaruv panelida
koʻrsatiladigan belgidir.

### Ishonchlilik

Har bir yozuv Arena ovozlari soniga qarab ishonchlilik darajasini oladi:

| Ishonchlilik | Ovozlar |
| ------------ | ------- |
| `high`       | ≥ 5,000 |
| `medium`     | ≥ 1,000 |
| `low`        | < 1,000 |

### Saqlash va maʼlumotlarning dolzarbligi

Normalizatsiya qilingan yozuvlar `source = "arena_elo"` bilan `model_intelligence`
maʼlumotlar bazasi jadvaliga yoziladi (`src/lib/db/modelIntelligence.ts`). Yozuvlarning amal
qilish muddati **7 kundan soʻng tugaydi**, shu sababli sinxronlashni toʻxtatgan taʼminotchi
eskirgan maʼlumotlarni taqdim etish oʻrniga, oxir-oqibat roʻyxatdan chiqib ketadi.

Sinxronlash **standart holatda yoqilgan**:

- U server ishga tushganda bir marta, keyin esa davriy taymer boʻyicha ishga tushadi
  (`src/lib/arenaEloSync.ts`, `src/instrumentation-node.ts` orqali ulangan).
- U **bloklamaydi va hech qachon jiddiy xatoga sabab boʻlmaydi** — agar yuqori oqimdan maʼlumot
  olish muvaffaqiyatsiz tugasa, OmniRoute ishlashda davom etadi va reytinglar shunchaki oxirgi
  muvaffaqiyatli maʼlumotlarni (yoki boʻsh holatni) koʻrsatadi.

Uni ikkita muhit oʻzgaruvchisi boshqaradi
([`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md) faylida hujjatlashtirilgan):

| Oʻzgaruvchi               | Standart      | Maqsad                                                  |
| ------------------------- | ------------- | ------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Tashqi sinxronlashdan voz kechish uchun `false` qiling. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | Sinxronlash oraligʻi, soniyalarda.                      |

### Qoʻlda sinxronlash / holat / tozalash

Operatorlar uchun autentifikatsiyalangan boshqaruv endpointi qoʻlda boshqarish imkonini beradi
(`src/app/api/intelligence/sync/route.ts` — boshqaruv autentifikatsiyasini talab qiladi):

```
GET    /api/intelligence/sync          # joriy sinxronlash holati (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # qoʻlda sinxronlashni ishga tushirish; yozmasdan koʻrib chiqish uchun tana: { "dryRun": true }
DELETE /api/intelligence/sync          # barcha sinxronlangan arena_elo tahliliy maʼlumot yozuvlarini tozalash
```

Agar reytinglar sahifasi boʻsh boʻlsa, qoʻlda `POST /api/intelligence/sync` soʻrovini yuborish
(yoki serverni shunchaki qayta ishga tushirish) uni qayta toʻldiradi.

### Modellarni reyting jadvaliga moslashtirish

Reyestrdagi model IDlari va Arenadagi model nomlari har doim ham aynan mos kelavermaydi.
Reyting moslashuvchan moslashtirishdan foydalanadi (`src/lib/freeProviderRankings.ts`
faylidagi `findMatchingIntelligence`):

1. Normalizatsiya qilingan model IDsi boʻyicha aniq moslik.
2. Oxirdagi versiya suffiksi olib tashlangandan keyingi moslik (masalan, `kimi-k2.6` → `kimi-k2`).
3. Prefiks boʻyicha moslik (reyting jadvalidagi model nomi reyestr IDsi uchun prefiks boʻlsa).

Sinxronlash tomonida maʼlum taʼminotchi prefikslari (`anthropic/`, `openai/`, `google/`, …)
olib tashlanadi va kichik taxalluslar xaritasi kanonik nomlarni OmniRoute ichkarida
foydalanadigan variantlarga kengaytiradi, shu sababli modellarni istalgan nom bilan topish
mumkin boʻlib qoladi.

### Taʼminotchi qanday reytinglanadi

Mexanizm har bir bepul taʼminotchi katalogidagi barcha modellarni baholaydi, soʻng:

- **Eng yaxshi model** = taʼminotchining eng yuqori ball olgan modeli.
- **Oʻrtacha ball** = taʼminotchining ball olgan barcha modellari boʻyicha oʻrtacha ball.
- **Modellar** = taʼminotchining Arena bali mavjud modellari soni.

Taʼminotchilar avval **eng yaxshi model bali**, soʻngra oʻrtacha ball boʻyicha saralanadi.
Bu kamida bitta kuchli bepul modelni taqdim etadigan taʼminotchini ragʻbatlantiradi.

## Undan bepul provayderlarni tanlash uchun foydalanish

1. **Toʻgʻri toifani tanlang.** Agentli/kod yozish ish yuklamalari uchun **Coding** filtridan foydalaning yoki
   umumiy chat uchun uni **All Categories** / **Default** holatida qoldiring. Bir xil provayder
   turli toifalarda turlicha oʻrin egallashi mumkin, chunki uning eng yaxshi modeli har bir reyting jadvalida farq qiladi.
2. **Bir martalik sozlamalar uchun yetakchilarni afzal koʻring.** Agar faqat bitta yoki ikkita bepul
   provayderni ulamoqchi boʻlsangiz, toifangizdagi eng yuqori oʻrinni egallaganlardan boshlang.
3. **Type nishonini tekshiring.** `NOAUTH` provayderlarini ulash eng tezkor (hisob maʼlumotlari
   talab qilinmaydi). `OAUTH` / `APIKEY` bepul tariflari tezkor roʻyxatdan oʻtishni talab qiladi, ammo koʻpincha
   kuchliroq modellarni taqdim etadi. Ulanish bosqichlari uchun [Bepul tariflar qoʻllanmasi](../getting-started/FREE-TIERS-GUIDE.md)ga
   qarang.
4. **Bir nechtasini ulang va Auto-Combo tanlovni amalga oshirsin.** Ushbu sahifa asosidagi Arena ELO maʼlumotlari
   Auto-Combo baholash mexanizmining **vazifaga moslik omili**ni ham taʼminlaydi
   (`open-sse/services/autoCombo/taskFitness.ts`, aniqlash tartibi:
   `user_override → arena_elo → models_dev_tier → static table`). Shunday qilib, eng yaxshi bepul provayderlarni
   ulaganingizdan soʻng, `model: "auto"` (masalan, `auto/coding`) orqali marshrutlash
   har bir soʻrov uchun yuqoriroq sifatli bepul modellarni avtomatik ravishda afzal koʻradi. Toʻliq 16 omilli baholash uchun
   [Auto-Combo](../routing/AUTO-COMBO.md)ga qarang.
