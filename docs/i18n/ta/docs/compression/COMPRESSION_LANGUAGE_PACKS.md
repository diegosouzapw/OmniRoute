Caveman சுருக்கம், உட்பொதிக்கப்பட்ட ஆங்கில விதிகளுடன் கூடுதலாக மொழி சார்ந்த விதித் தொகுப்புகளையும் ஏற்ற முடியும்.
இது மைய இயந்திரத்தை நிலையாக வைத்துக்கொண்டே, போர்த்துகீசியம், ஸ்பானியம், ஜெர்மன், பிரெஞ்சு, இத்தாலியம், ஜப்பானியம் மற்றும்
எதிர்கால மொழித் தொகுப்புகள் தனித்தனியாக மேம்பட அனுமதிக்கிறது.

## இருப்பிடம்

மொழித் தொகுப்புகள் பின்வரும் இடத்தில் உள்ளன:

```txt
open-sse/services/compression/rules/<language>/
```

தற்போது வழங்கப்படும் தொகுப்புகள் (`rules/` கோப்பகத்தின் உள்ளடக்கங்களுடன் சரிபார்க்கப்பட்டவை):

| மொழி                       | கோப்பகம்       | இடம்பெற்றுள்ள விதி வகைகள்                           |
| -------------------------- | -------------- | --------------------------------------------------- |
| ஆங்கிலம்                   | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ஸ்பானியம்                  | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| போர்த்துகீசியம் (பிரேசில்) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| இந்தோனேசியம்               | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| இத்தாலியம்                 | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ஜெர்மன்                    | `rules/de/`    | `context`, `filler`, `structural`                   |
| பிரெஞ்சு                   | `rules/fr/`    | `context`, `filler`, `structural`                   |
| ஜப்பானியம்                 | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **ஒத்திசைவு குறிப்பு:** `en`, `es`, `pt-BR`, `id` மற்றும் `it` தொகுப்புகள் முழுமையான 5 வகைகளையும் கொண்டுள்ளன; `de`, `fr`, `ja` ஆகியவை 3 வகைகளுடன் வழங்கப்படுகின்றன. விடுபட்டுள்ள `dedup` மற்றும் `ultra` வகைகள் எந்த அறிவிப்புமின்றி உட்பொதிக்கப்பட்ட ஆங்கில விதிகளுக்குத் தானாகப் பின்வாங்கும். சிறிய தொகுப்புகளுக்கு `dedup.json` மற்றும் `ultra.json` சேர்ப்பதற்கான பங்களிப்புகள் வரவேற்கப்படுகின்றன.
>
> `pt-BR` தொகுப்பு, Lenine Júnior உருவாக்கிய **[Troglodita](https://github.com/leninejunior/troglodita)**-ஐ அடிப்படையாகக் கொண்டது — இது பிரேசிலிய போர்த்துகீசிய இலக்கணத்திற்காகப் புதிதாக வடிவமைக்கப்பட்ட ஒரு சுருக்க அமைப்பு (மீளுரைத்தல் குறைப்பு, PT-BR நிரப்பு வார்த்தைகளை அகற்றுதல், பிரேசிலிய மென்பொருள் உருவாக்குநர் சமூகத்திற்கான தொழில்நுட்பச் சுருக்கங்கள்).
>
> அதிகாரப்பூர்வ வகைப் பட்டியலும் ஒவ்வொரு வகைக்குமான திட்டவரையறையும் [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json)-இல் உள்ளன (JSON Schema draft 2020-12).

## மொழி கண்டறிதல்

`languageDetector.ts`, பயனர் உள்ளீட்டு உரையிலிருந்து மொழியை அனுமானிக்க இலகுரக நுண்ணறிவு விதிகளைப் பயன்படுத்துகிறது.
உள்ளமைக்கப்பட்ட இயல்புநிலை மொழி தொடர்ந்து மதிக்கப்படும்; துல்லியமான கட்டுப்பாடு தேவைப்படும்போது உள்ளமைவின் மூலம்
கண்டறிதலை முடக்கலாம்.

கண்டறிதல் வெளியீடு விதித் தொகுப்புகளைத் தேர்ந்தெடுப்பதற்கு மட்டுமே பயன்படுத்தப்படுகிறது. இது வழங்குநர் வழிப்படுத்தல், பிராந்திய அமைப்புத்
தேர்வு அல்லது UI மொழியை மாற்றாது.

## உள்ளமைவு வடிவம்

சுருக்க அமைப்புகளில் பின்வருவன இடம்பெறலாம்:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig`, முகப்புப்பலகை/முன்னோட்டத்தின் இயல்புநிலை அமைப்புகளைக் கட்டுப்படுத்துகிறது. `cavemanConfig` என்பது
Caveman செய்தி உரையைச் சுருக்கும்போது பயன்படுத்தப்படும் இயக்கநேர இயந்திர உள்ளமைவாகும்.

## மொழித் தொகுப்பைச் சேர்த்தல்

1. `open-sse/services/compression/rules/<language>/<pack>.json`-ஐ உருவாக்கவும்.
2. `docs/compression/COMPRESSION_RULES_FORMAT.md`-இல் உள்ள Caveman விதி வடிவமைப்பைப் பயன்படுத்தவும்.
3. மாற்றீடுகளைப் பழமைவாதமாக வைத்திருந்து, குறியீடு, அடையாளங்காட்டிகள், URL-கள் அல்லது JSON-ஐ மாற்றுவதைத் தவிர்க்கவும்.
4. மொழித் தேர்வு மற்றும் மாற்றீட்டு நடத்தைக்கான சோதனைகளைச் சேர்க்கவும் அல்லது புதுப்பிக்கவும்.
5. UI தேர்விகளில் அந்த மொழி தோன்றினால், புதிய dashboard/i18n சிட்டைகளை வெளிப்படுத்தவும்.

## API

கிடைக்கும் தொகுப்புகளைப் பின்வருமாறு வினவலாம்:

```bash
curl http://localhost:20128/api/compression/language-packs
```

முன்னோட்ட முனைப்புள்ளி மொழி உள்ளமைவு மேலெழுதல்களை ஏற்கிறது:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

அனைத்து 6 மொழித் தொகுப்புகளும் v3.8.0-இல் ஒரு `SHARED_BOUNDARIES` உட்பிரிவைப் பெற்றன; இது ஒவ்வொரு
Caveman தீவிர நிலையிலும் (LITE, FULL, ULTRA) பயன்படுத்தப்படுகிறது. சுற்றியுள்ள நிரப்புச் சொற்கள் நீக்கப்பட்டாலும்,
இந்த வடிவங்களை அப்படியே பாதுகாக்குமாறு இது இயந்திரத்திற்கு அறிவுறுத்துகிறது:

| வடிவ வகை                                 | எடுத்துக்காட்டு                        |
| ---------------------------------------- | -------------------------------------- |
| வேலியிடப்பட்ட குறியீட்டுத் தொகுதிகள்     | ` ```python\n...\n``` `                |
| வரியகக் குறியீடு                         | `` `my_var` ``                         |
| URL-கள்                                  | `https://example.com/path`             |
| கோப்புப் பாதைகள் (முழுமையான + சார்புடைய) | `/etc/hosts`, `./src/index.ts`         |
| பிழைத் தலைப்புகள்                        | `Error:`, `TypeError:`, `SyntaxError:` |
| அடுக்குத் தட வரிகள்                      | `  at functionName (file.ts:12:3)`     |

இந்த வடிவங்கள் `DEFAULT_CAVEMAN_CONFIG.preservePatterns`-இல் (முன்பு `[]`) நிரப்பப்படுகின்றன. இந்த
மாறிலி `open-sse/services/compression/types.ts`-இல் உள்ளது.

### இது ஏன் முக்கியமானது

SHARED_BOUNDARIES இல்லாமல், தீவிரமான Caveman பயன்முறைகள், மீண்டும் மீண்டும் வரும்
உரைநடை போல் தோன்றினாலும் உண்மையில் குறியீட்டுத் துணுக்கு, கோப்புப் பாதை அல்லது பிழை அடுக்காக இருந்த உள்ளடக்கத்தை நீக்கக்கூடும். SHARED_BOUNDARIES என்பது
நிரப்புச் சொல் விதிகள் இயங்குவதற்கு முன் பயன்படுத்தப்படும், மொழி சார்பற்ற பாதுகாப்பு வலையாகச் செயல்படுகிறது.

### preservePatterns-ஐத் தனிப்பயனாக்குதல்

சுருக்க அமைப்புகள் வழியாக இயக்க நேரத்தில் கூடுதல் வடிவங்களைச் சேர்க்கலாம்:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

தனிப்பயன் வடிவங்கள் இயல்புநிலையிலுள்ள 6 வடிவங்களை நீட்டிக்கின்றன (மாற்றீடு செய்வதில்லை).

## செயல்பாட்டுக் குறிப்புகள்

- மொழித் தொகுப்பு இல்லாதபோது, உள்ளமைக்கப்பட்ட ஆங்கில விதிகளே மாற்று இயல்புநிலையாகத் தொடரும்.
- செல்லாத உள்ளமைக்கப்பட்ட JSON தொகுப்புகள் சரிபார்ப்பில் தோல்வியடையும்; எனவே வெளியீட்டுச் சொத்துகளின் தரம் கவனிக்கப்படாமல் குறையாது.
- விதித் தொகுப்புகள் தரவை மட்டுமே கொண்டிருக்க வேண்டும்; அவை குறியீட்டை இறக்குமதி செய்யவோ தன்னிச்சையான தர்க்கத்தை இயக்கவோ கூடாது.
- சுருக்கப் பகுப்பாய்வு அடுக்கு தேர்ந்தெடுக்கப்பட்ட பயன்முறையையும் இயந்திரத்தையும் பதிவுசெய்கிறது; முழுமையான தூண்டல் உரையை அல்ல.
