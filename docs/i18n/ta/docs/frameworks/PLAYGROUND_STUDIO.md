## தாவல்கள்

### அரட்டைத் தாவல்

`ChatPlayground.tsx`-ஐ பல சுற்று ஸ்ட்ரீமிங் பணிமேடையாக மேம்படுத்துகிறது:

- `MarkdownMessage.tsx` வழியாக முழுமையான markdown காட்சிப்படுத்தல் (குறியீட்டுத் தொகுதிகள், அட்டவணைகள், பட்டியல்கள், இணைப்புகள்).
- பகிரப்பட்ட கட்டமைப்புப் பலகத்திலிருந்து பெறப்படும் சிஸ்டம் தூண்டுதல்.
- ஒவ்வொரு செய்திக்குமான டோக்கன்/செலவு (தூண்டுதல் + நிறைவு டோக்கன்கள்).
- கடைசிப் பதிலை மீண்டும் உருவாக்குதல்.
- SSE ஸ்ட்ரீமிங்குடன் `POST /v1/chat/completions`-க்கு அனுப்புகிறது.

### ஒப்பீட்டுத் தாவல்

ஒரு ப்ராக்ஸியின் முக்கிய வேறுபடுத்தும் அம்சம்: 1 தூண்டுதலை அதிகபட்சம் **4 மாடல்களில் இணையாக** இயக்குதல்.

- அதிகபட்சம் 4 நெடுவரிசைகள்; ஒவ்வொன்றும் `/v1/chat/completions`-இலிருந்து தனித்தனியாக ஸ்ட்ரீம் செய்யும்.
- நெடுவரிசைகளைச் சேர்ப்பதற்கான `+ மாடலைச் சேர்` பொத்தான் (Cmd+K குறுக்குவழி).
- `அனைத்தையும் இயக்கு ▶`, `Promise.all` + ஒவ்வொரு நெடுவரிசைக்குமான `AbortController` மூலம் அனைத்து ஸ்ட்ரீம்களையும் ஒரே நேரத்தில் தொடங்குகிறது.
- உலகளாவிய **அனைத்தையும் ரத்துசெய்** விருப்பம், செயலில் உள்ள ஒவ்வொரு ஸ்ட்ரீமையும் நிறுத்துகிறது.
- ஒவ்வொரு நெடுவரிசையிலும் உள்ள `ProviderMetrics`, TTFT, TPS, டோக்கன்கள் மற்றும் மதிப்பிடப்பட்ட செலவை நிகழ்நேரத்தில் காட்டுகிறது.
- அளவீடுகள் **"கிளையன்ட்-பக்க மதிப்பீடு"** (D12) எனக் குறிக்கப்படுகின்றன — முதல் SSE துண்டிலிருந்து அளவிடப்படுகின்றன.

### API தாவல்

மேம்பட்ட பயனர்களுக்காக அசல் Monaco திருத்தியை 100% பாதுகாக்கிறது (D14):

- 10 முனைப்புள்ளிகள்: அரட்டை நிறைவுகள், நிறைவுகள், உட்பொதிவுகள், படங்கள், ஆடியோ, பேச்சு, ஒலிப்பதிவாக்கங்கள், உள்ளடக்கக் கட்டுப்பாடுகள், மறுதரவரிசைப்படுத்தல், தேடல்.
- பல்வகை ஊடகக் கோப்புப் பதிவேற்றம்.
- நிகழ்நேர வெளியீட்டுடன் SSE ஸ்ட்ரீமிங்.
- `ApiTab.tsx` ஆகச் சுற்றப்பட்டுள்ளது (சோம்பேறி ஏற்றம், `ssr: false`).

### உருவாக்கத் தாவல்

கருவிகள்/செயல்பாட்டு அழைப்பு மற்றும் கட்டமைக்கப்பட்ட வெளியீட்டிற்கான UI:

- `ToolsBuilder.tsx` — ஒவ்வொரு கருவிக்குமான JSON schema திருத்தியுடன் `tools[]`-ஐச் சேர்க்கலாம்/திருத்தலாம்/அகற்றலாம்.
  `ToolDefinitionSchema` (Zod) வழியாக அளவுருக்களைச் சரிபார்க்கிறது.
- `StructuredOutputEditor.tsx` — JSON பயன்முறையை மாற்றுவதற்கான நிலைமாற்றி + JSON schema திருத்தி.
  `StructuredOutputSchema` (Zod) வழியாக schema-க்கு எதிராகப் பதிலைச் சரிபார்க்கிறது.
- `tools[]` மற்றும்/அல்லது `response_format` உடன் கோரிக்கையை `/v1/chat/completions`-க்கு அனுப்புகிறது.

## அறிவுறுத்தல் மேம்படுத்தி

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. "ஒதுக்கீட்டைப் பயன்படுத்தும்" என்று மாதிரிச் சாளரம் எச்சரிக்கிறது.
2. உறுதிப்படுத்தியதும், வழித்தடத்திற்கு `{ system, prompt, model, tone }` அனுப்பப்படுகிறது.
3. வழித்தடம், `promptImprover.META_SYSTEM_PROMPT` உடன் உள்ளகமாக `/v1/chat/completions`-ஐ அழைக்கிறது.
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`-ஐத் திருப்பி அனுப்புகிறது.
5. UI, உள்ளமைவுப் பலகத்தின் கணினி அறிவுறுத்தலையும் அரட்டைத் தாவலின் பயனர் அறிவுறுத்தலையும் திருத்துகிறது.

## ஸ்ட்ரீம் அளவீடுகள்

`useStreamMetrics.ts` + `streamMetrics.ts` (தூய செயல்கூறு):

- `start()` — கோரிக்கை தொடங்கிய நேரத்தைப் பதிவுசெய்கிறது.
- `onFirstChunk()` — TTFT-ஐப் பதிவுசெய்கிறது.
- `onChunk(n)` — நிறைவு டோக்கன் எண்ணிக்கையைக் குவிக்கிறது.
- `finish(usage?)` — இறுதி அளவீடுகளைக் கணக்கிடுகிறது: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- `src/lib/playground/types.ts`-இல் உள்ள நிலையான அட்டவணையிலிருந்து விலை நிர்ணயம் பெறப்படுகிறது ("மதிப்பிடப்பட்டது" எனக் குறிக்கப்பட்டுள்ளது — D13).
