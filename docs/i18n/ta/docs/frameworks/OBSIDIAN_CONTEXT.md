## இது என்ன

OmniRoute ஒரு **Obsidian** வால்ட்டுடன் **சூழல் மூலமாக** இணைகிறது — உள்ளமைக்கப்பட்ட MCP
சர்வர் வழியாக ஏஜெண்டுகள் படித்து எழுதக்கூடிய ஓர் உள்ளூர் Markdown அறிவுத் தளம். இந்த
ஒருங்கிணைப்பு டெஸ்க்டாப் செயலிக்குள் இயங்கும் சமூகச் செருகுநிரலான **Obsidian Local REST API**
உடன் தொடர்புகொள்கிறது. இதனால் ஏஜெண்டுகள் குறிப்புகளைத் தேடவும், கோப்புகளைப்
படிக்கவும்/எழுதவும்/திருத்தவும், வால்ட்டைப் பட்டியலிடவும், தினசரி/வாராந்திர காலமுறை
குறிப்புகளுடன் பணிபுரியவும், குறிச்சொற்களை நிர்வகிக்கவும், Obsidian கட்டளைகளை
இயக்கவும், மேலும் (விருப்பத்திற்கேற்ப) இருதிசை டெஸ்க்டாப்↔மொபைல் வால்ட் ஒத்திசைவை
ஒருங்கிணைக்கவும் முடியும்.

கிளையன்ட் (`src/lib/obsidian/api.ts`) Local REST API-ஐப் பின்வரும் வசதிகளுடன்
உறையிடுகிறது:

- நிலையற்ற `5xx` பிழைகளுக்கு **பின்வாங்கலுடன் மறுமுயற்சி**, `AbortController` வழியாக
  **30-விநாடி காலக்கெடு**.
- **வகைப்படுத்தப்பட்ட பிழை வகைப்பாடு** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- பொதுவாக ஏற்படும் போர்ட் தவறைச் சுட்டிக்காட்டும் பயனுள்ள **"Obsidian-ஐ அணுக முடியவில்லை" குறிப்பு**
  (`27123`-இல் HTTP, `27124`-இல் உள்ள MCP முனைப்புள்ளி **அல்ல**) மற்றும் Tailscale வடிவம்.
- இடைவெளிகள்/சாய்வுக்கோடுகள் கொண்ட குறிப்புப் பாதைகள் பாதுகாப்பாக இருக்க, வால்ட்-சார்ந்த
  **பாதைக் குறியாக்கம்**.

## அமைத்தல்

Obsidian டோக்கன் அல்லது அடிப்படை URL-க்கு **சூழல் மாறி எதுவும் இல்லை** — இரண்டும்
`src/lib/db/obsidian.ts` வழியாக SQLite `key_value` அட்டவணையில் (`obsidian` பெயர்வெளி)
சேமிக்கப்படுகின்றன. டோக்கன் **சேமிப்பில் குறியாக்கப்படுகிறது** (AES-256-GCM, எளிய உரைக்கான
பின்னோக்கிய-இணக்க மாற்று முறையுடன்). முனைப்புள்ளி டாஷ்போர்டின் **Context Sources**
தாவலில் (`ObsidianSourceCard`) இருந்தோ அல்லது அமைப்புகள் REST API வழியாகவோ உள்ளமைக்கவும்.

> [!IMPORTANT]
> **Obsidian Local REST API** செருகுநிரல் நிறுவப்பட்டு இயங்கிக்கொண்டிருக்க வேண்டும். அதன் REST
> இடைமுகம் **HTTP `127.0.0.1:27123`**-இல் கேட்கிறது (இயல்புநிலை அடிப்படை URL). போர்ட் `27124`
> என்பது ஒரு _தனியான_ MCP/HTTPS முனைப்புள்ளி; அமைப்புகள் ரூட் அதை வெளிப்படையாக நிராகரிக்கிறது.
> மற்றொரு சாதனத்திலிருந்து இணைத்தால், `http://<tailscale-ip>:27123`-ஐப் பயன்படுத்தவும்.

### உள்ளமைவு விசைகள் (SQLite `key_value`, `obsidian` பெயர்வெளி)

| விசை              | நோக்கம்                                                 | குறியாக்கப்பட்டது |
| ----------------- | ------------------------------------------------------- | ----------------- |
| `api_key`         | Local REST API bearer டோக்கன்                           | ஆம்               |
| `base_url`        | REST அடிப்படை URL (இயல்புநிலை `http://127.0.0.1:27123`) | இல்லை             |
| `vault_path`      | வால்ட் கோப்பகத்திற்கான முழுமையான பாதை (ஒத்திசைவுக்காக)  | இல்லை             |
| `webdav_username` | உருவாக்கப்பட்ட WebDAV பயனர்பெயர் (வால்ட் ஒத்திசைவு)     | இல்லை             |
| `webdav_password` | உருவாக்கப்பட்ட WebDAV கடவுச்சொல் (வால்ட் ஒத்திசைவு)     | ஆம்               |
| `webdav_enabled`  | WebDAV வால்ட் ஒத்திசைவு இயக்கப்பட்டுள்ளதா               | இல்லை             |

### REST வழியாக உள்ளமைத்தல்

```bash
# Local REST API டோக்கனைச் சேமித்து + சரிபார்க்கவும் (POST நிலைச் சரிபார்ப்பு மூலம் உறுதிப்படுத்துகிறது)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# இணைப்பு நிலையைச் சரிபார்க்கவும் (connected, hasToken, baseUrl, vaultPath ஆகியவற்றை வழங்கும்)
curl http://localhost:20128/api/settings/obsidian

# இணைப்பைத் துண்டிக்கவும் (சேமிக்கப்பட்ட டோக்கனை அழிக்கும்)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

அனைத்து முறைகளுக்கும் டாஷ்போர்டு அங்கீகாரம் தேவை. `POST`, போர்ட் `27124`-இல் உள்ள எந்த
URL-ஐயும் நிராகரிக்கிறது; மேலும் சேமிப்பதற்கு முன் Local REST API நிலை முனைப்புள்ளியை
அழைத்து டோக்கனைச் சரிபார்க்கிறது.

### WebDAV வால்ட் ஒத்திசைவு

`src/app/api/settings/obsidian/webdav/route.ts`, விருப்பத்திற்குரிய WebDAV-ஆதரவு கொண்ட
வால்ட் ஒத்திசைவை நிர்வகிக்கிறது (`src/lib/obsidianSync.ts` மூலம் இயக்கப்படுகிறது). அதை
இயக்கும்போது OmniRoute ஓர் உள்ளூர் வால்ட் கோப்பகத்தைப் பயன்படுத்துமாறு அமைக்கப்பட்டு,
சீரற்ற WebDAV பயனர்பெயர்/கடவுச்சொல் இணை உருவாக்கப்படுகிறது:

```bash
# ஒரு வால்ட் கோப்பகத்திற்கு WebDAV ஒத்திசைவை இயக்கவும் (பயனர்பெயர்/கடவுச்சொல்லை உருவாக்கும்)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV ஒத்திசைவு நிலையைப் பெறவும் (இயக்கப்பட்டிருக்கும்போது மட்டுமே நற்சான்றுகள் வழங்கப்படும்)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV ஒத்திசைவை முடக்கவும் (நற்சான்றுகள் + நிர்வகிக்கப்படும் .stignore ஆகியவற்றை அழிக்கும்)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### ஒவ்வொரு API விசைக்குமான சூழல் மூலம் (விருப்பத்திற்குரியது)

Obsidian உள்ளமைவை `api_key_context_sources` அட்டவணை வழியாக **ஒவ்வொரு API விசைக்கும்**
தனித்தனியாக வரம்பிடலாம் (`src/lib/db/apiKeyContextSources.ts`). ஓர் MCP அழைப்பு
அங்கீகரிக்கப்பட்ட API விசை id-ஐக் கொண்டிருக்கும்போது, `getObsidianConfigForApiKey()`
அந்த விசைக்குச் சொந்தமான டோக்கன்/அடிப்படை-URL/வால்ட்-பாதையை (`source: "api_key"`)
முன்னுரிமையுடன் பயன்படுத்தும்; இல்லையெனில் உலகளாவிய உள்ளமைவுக்கு
(`source: "global"`) மாறும்.

## MCP கருவிகள் (22)

`open-sse/mcp-server/tools/obsidianTools.ts` இல் வரையறுக்கப்பட்டுள்ளன. token/base-URL ஒவ்வொரு அழைப்பிற்கும் தீர்மானிக்கப்படுகின்றன (முதலில் ஒவ்வொரு API key-க்குமானவை, பின்னர் global). OmniRoute **sync server**-ஐ அணுகும் கருவிகளுக்கு (நான்கு `obsidian_sync_*` கருவிகள்) கூடுதலாக OmniRoute அமைப்புகளில் உள்ளமைக்கப்பட்ட sync auth token தேவைப்படுகிறது.

| `obsidian_search_structured` | JSON Logic expression-ஐப் பயன்படுத்தித் தேடும் (and/or/regex/path filters).                                           |
| `obsidian_read_note`         | vault-relative path மூலம் ஒரு குறிப்பைப் படிக்கும்; விருப்பமாகக் குறிப்பிட்ட heading/block/frontmatter-ஐப் படிக்கும். |
| `obsidian_list_vault`        | vault-இல் உள்ள files மற்றும் directories-ஐப் பட்டியலிடும் (உள்ளீடுகளின் tree).                                        |
| `obsidian_get_document_map`  | குறிப்பின் heading கட்டமைப்பை headings → line numbers வரைபடமாகப் பெறும்.                                              |
| `obsidian_get_note_metadata` | முழு உள்ளடக்கம் இல்லாமல் frontmatter, tags, links, char/word count ஆகியவற்றைப் பெறும்.                                |
| `obsidian_get_active_file`   | Obsidian-இல் தற்போது செயலில் உள்ள file-இன் path + content-ஐப் பெறும்.                                                 |
| `obsidian_get_periodic_note` | ஒரு தேதிக்கான daily/weekly/monthly periodic note-ஐப் பெறும் (விடுபட்டால் இன்றைய தேதி).                                |
| `obsidian_get_tags`          | அனைத்து vault tags-ஐயும் அவற்றின் frequencies உடன் பட்டியலிடும்.                                                      |
| `obsidian_list_commands`     | கிடைக்கக்கூடிய Obsidian command IDs-ஐப் பட்டியலிடும் (`obsidian_execute_command` உடன் பயன்படுத்தவும்).                |
| `obsidian_sync_status`       | OmniRoute sync server நிலை: இயங்குகிறதா, vault பெயர், port, uptime, கடைசி sync.                                       |
| `obsidian_sync_conflicts`    | தீர்க்கப்படாத sync conflicts-ஐப் பட்டியலிடும் (path, conflict path, கண்டறியப்பட்ட நேரம்).                             |

### எழுதும் கருவிகள் (`write:obsidian`)

| கருவி                            | விளக்கம்                                                                                                     |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `obsidian_write_note`            | கொடுக்கப்பட்ட Markdown உள்ளடக்கத்துடன் ஒரு குறிப்பை உருவாக்கும் அல்லது மேலெழுதும்.                           |
| `obsidian_append_note`           | ஒரு குறிப்பில் உள்ளடக்கத்தைச் சேர்க்கும்; விருப்பமாகக் குறிப்பிட்ட heading/block-இல் சேர்க்கும்.             |
| `obsidian_patch_note`            | ஒரு heading, block அல்லது frontmatter field-இல் துல்லியமாக append/prepend/replace செய்யும்.                  |
| `obsidian_delete_note`           | vault-இலிருந்து ஒரு குறிப்பை நிரந்தரமாக நீக்கும்.                                                            |
| `obsidian_move_note`             | vault-க்குள் ஒரு குறிப்பை நகர்த்தும் அல்லது மறுபெயரிடும்.                                                    |
| `obsidian_execute_command`       | ஒரு Obsidian command-ஐ அதன் command ID மூலம் இயக்கும்.                                                       |
| `obsidian_open_file`             | Obsidian-இல் ஒரு file-ஐத் திறக்கும் (அது இல்லாவிட்டால் உருவாக்கும்).                                         |
| `obsidian_sync_trigger`          | உடனடி இருதிசை desktop↔mobile vault sync-ஐத் தூண்டும்.                                                        |
| `obsidian_sync_resolve_conflict` | sync conflict-ஐத் தீர்க்கும்: `local` (mobile), `remote` (desktop) அல்லது `keep-both` என்பதைத் தக்கவைக்கும். |

> [!NOTE]
> `obsidian_patch_note` இலக்குகள் `heading | block | frontmatter` என்ற `targetType`-ஐயும்
> `append | prepend | replace` என்ற `operation`-ஐயும் ஏற்கின்றன; விருப்பமாக
> `createTargetIfMissing`-ஐயும் ஏற்கின்றன. நான்கு `obsidian_sync_*` கருவிகள் உள்ளக sync
> server-உடன் (`http://127.0.0.1:27781` இயல்புநிலையாக) தொடர்புகொள்கின்றன; அவற்றுக்கு sync token தேவைப்படுகிறது.

### Scopes

வாசிப்புக் கருவிகளுக்கு `read:obsidian` தேவை; எழுதும் கருவிகளுக்கு `write:obsidian` தேவை. அமலாக்கம்
Notion-ஐப் போலவே உள்ளது — இது `open-sse/mcp-server/server.ts` இல் உள்ள
`withScopeEnforcement()` மூலம் கையாளப்படுகிறது; `OMNIROUTE_MCP_ENFORCE_SCOPES=true` என்பதைப் பொறுத்து செயல்படுத்தப்பட்டு,
அனுமதிக்கப்பட்ட scopes `OMNIROUTE_MCP_SCOPES` அல்லது API key-இன் scope context-இலிருந்து பெறப்படுகின்றன. பார்க்கவும்:
[MCP-SERVER.md](./MCP-SERVER.md).

## பயன்பாட்டு நிலைகள்

- **Vault-ஐ ஆதாரமாகக் கொண்ட பதில்கள்** — முதலில் `obsidian_search_simple` / `obsidian_search_structured`,
  பின்னர் `obsidian_read_note` ஆகியவற்றைப் பயன்படுத்துவதன் மூலம், ஒரு முகவர் உங்கள் உண்மையான குறிப்புகளிலிருந்து பதிலளிக்க முடியும்.
- **குறிப்பு உருவாக்கம் / நாளேடு எழுதுதல்** — முகவரின் வெளியீடு, சுருக்கங்கள் அல்லது தினசரிக் குறிப்புகளைப்
  பதிவு செய்ய `obsidian_write_note`, `obsidian_append_note` அல்லது துல்லியமான
  `obsidian_patch_note` (`obsidian_get_periodic_note`) ஆகியவற்றைப் பயன்படுத்தி vault-இல் எழுதலாம்.
- **Vault வழிசெலுத்தல்** — படிப்பதற்கு/எழுதுவதற்கு முன் கட்டமைப்பை ஆராய
  `obsidian_list_vault`, `obsidian_get_document_map` மற்றும்
  `obsidian_get_tags` ஆகியவற்றைப் பயன்படுத்தலாம்.
- **Obsidian தானியக்கம்** — ஒரு முகவரிடமிருந்து செருகுநிரல்கள்/கட்டளைகளை இயக்க
  `obsidian_list_commands` + `obsidian_execute_command`; UI-இல் ஒரு குறிப்பைக் காண்பிக்க
  `obsidian_open_file` ஆகியவற்றைப் பயன்படுத்தலாம்.
- **மொபைல் ஒத்திசைவு** — WebDAV ஒத்திசைவை இயக்கி, பின்னர் desktop↔mobile ஒத்திசைவை ஒருங்கிணைக்கவும்
  முரண்பாடுகளைத் தீர்க்கவும் `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  ஆகியவற்றைப் பயன்படுத்தலாம்.
