## இது என்ன

Local Corpus, வெளிப்படையாக அங்கீகரிக்கப்பட்ட ஒரு உரைக் கோப்புகள் கோப்பகத்தை
OmniRoute-இன் MCP சேவையகத்துக்கு ஒரு இயக்குநர் வெளிப்படுத்த அனுமதிக்கிறது. கோப்புகள் அவற்றின் அசல் கோப்பகத்திலேயே இருக்கும்: OmniRoute,
நியமப்படுத்தப்பட்ட மூலப் பாதையை மட்டும் SQLite-இல் சேமித்து, நினைவகத்திலுள்ள தேடல் குறியீட்டைப் பராமரிக்கிறது. இது
Corpus உள்ளடக்கத்தை களஞ்சியத்திற்கோ தரவுத்தளத்திற்கோ நகலெடுப்பதில்லை.

குறியீட்டுப் புதுப்பிப்பு படிப்படியாக நடைபெறுகிறது. அளவு மற்றும் மாற்றப்பட்ட
நேரத்தின் அடிப்படையில் மாற்றப்படாத கோப்புகள் மீண்டும் பயன்படுத்தப்படுகின்றன; மாற்றப்பட்ட கோப்புகள் மீண்டும் வாசிக்கப்பட்டு SHA-256 மூலம் ஹாஷ் செய்யப்படுகின்றன; நீக்கப்பட்ட கோப்புகள் அகற்றப்படுகின்றன.
30 வினாடிகளுக்கு மேல் பழையதாக இருக்கும் குறியீட்டைத் தேடல் புதுப்பிக்கிறது; அழைப்பாளர்கள் உடனடி
புதுப்பிப்பையும் கோரலாம்.

## மூலத்தை உள்ளமைத்தல்

அமைப்புகள் வழித்தடத்துக்கு மற்ற அமைப்புகள் API-களைப் போலவே மேலாண்மை அங்கீகாரம் தேவைப்படுகிறது.
சமர்ப்பிக்கப்படும் பாதை ஏற்கெனவே இருக்க வேண்டும் மற்றும் அது ஒரு முழுமையான கோப்பகப் பாதையாக இருக்க வேண்டும்.

```bash
# அங்கீகரிக்கப்பட்ட கோப்பகத்தை இணைக்கவும்
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# உள்ளமைவு மற்றும் குறியீட்டு நிலையைக் காணவும்
curl http://localhost:20128/api/settings/local-corpus

# மூலக் கோப்புகளை மாற்றாமல் இணைப்பைத் துண்டிக்கவும்
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP கருவிகள்

மூன்று கருவிகளுக்கும் `read:local-corpus` தேவைப்படுகிறது. கருவிகளின் பதில்கள் சார்புப் பாதைகளையும்
மூலக் கோப்பகத்தின் அடிப்படைப் பெயரையும் மட்டுமே வெளிப்படுத்தும்; அதன் முழுமையான பாதையை ஒருபோதும் வெளிப்படுத்தாது.

| கருவி                 | விளக்கம்                                                                                                      |
| :-------------------- | :------------------------------------------------------------------------------------------------------------ |
| `local_corpus_status` | உள்ளமைவு நிலை, குறியீட்டு அளவு, வரம்புகள் மற்றும் கடைசியாகப் புதுப்பிக்கப்பட்ட நேரத்தை அறிக்கையிடும்          |
| `local_corpus_search` | குறியிடப்பட்ட உரையில் தேடி, வரம்புக்குட்பட்ட வரி-அடிப்படையிலான துணுக்குகளை வழங்கும் (அதிகபட்சம் 20 முடிவுகள்) |
| `local_corpus_read`   | அனுமதிக்கப்பட்ட ஒரு Corpus-சார்புக் கோப்பிலிருந்து வரம்புக்குட்பட்ட வரி வரம்பை வாசிக்கும்                     |

MCP உள்ளீட்டு எடுத்துக்காட்டுகள்:

```json
{ "query": "ரெட் ரிவர் கண்காணிப்பு", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## பாதுகாப்பு எல்லைகள்

- அனுமதிப்புப் பட்டியல் உரை சார்ந்தது: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, மற்றும் `.yml`.
- குறியீட்டு இணைப்புகள் தவிர்க்கப்படுகின்றன. வாசிப்புப் பாதைகள் நியமப்படுத்தப்பட்டு, உள்ளமைக்கப்பட்ட
  மூலத்துக்குள்ளேயே இருக்க வேண்டும்; முழுமையான பாதைகளும் அடைவு-கடத்தல் முயற்சிகளும் நிராகரிக்கப்படுகின்றன.
- உணர்திறன் வாய்ந்த மற்றும் உருவாக்கப்பட்ட கோப்பகப் பெயர்கள் விலக்கப்படுகின்றன: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, மற்றும்
  `secrets`.
- இயல்புநிலை வரம்புகள்: 5,000 கோப்புகள், ஒரு கோப்புக்கு 1 MiB, குறியிடப்பட்ட மொத்த உள்ளடக்கத்துக்கு 64 MiB,
  ஒரு தேடல் துண்டுக்கு தோராயமாக 4,000 எழுத்துகள், மற்றும் ஒரு வாசிப்புக்கு 400 வரிகள்.
- NUL கொண்ட கோப்புகள் உரை அல்லாதவையாகக் கருதப்பட்டு தவிர்க்கப்படுகின்றன அல்லது நிராகரிக்கப்படுகின்றன.

PDF, DOCX, படங்கள் மற்றும் காப்பகங்கள் போன்ற இரும ஆவணங்கள் வேண்டுமென்றே ஆதரிக்கப்படவில்லை.
குறியிடுவதற்கு முன், உள்ளமைக்கப்பட்ட கோப்பகத்தில் அவற்றை அங்கீகரிக்கப்பட்ட உரை வடிவத்துக்கு மாற்றவும்.

## செயல்பாட்டுக் குறிப்புகள்

- உள்ளமைக்கப்பட்ட மூலத்தை மாற்றுவது அல்லது நீக்குவது பகிரப்பட்ட நினைவகக் குறியீட்டை அழிக்கும்.
- ஒரு செயல்முறை மறுதொடக்கம் குறியீட்டை நீக்கிவிடும்; அடுத்த தேடல் அதை உள்ளமைக்கப்பட்ட
  மூலத்திலிருந்து மீண்டும் உருவாக்கும்.
- `local_corpus_status` ஒரு ஸ்கேனை கட்டாயப்படுத்தாது. உடனடி மறுஸ்கேன் தேவைப்படும்போது
  `refresh: true` உடன் `local_corpus_search`-ஐப் பயன்படுத்தவும்.
- ஸ்கேன் மற்றும் வாசிப்புத் தோல்விகள் எண்ணப்படுகின்றன அல்லது தூய்மைப்படுத்தப்பட்ட பிழைகளாக வழங்கப்படுகின்றன; மூலக் கோப்புகள்
  ஒருபோதும் மாற்றப்படுவதில்லை.
