> **உண்மையின் ஆதாரம்:** `src/lib/agentSkills/` (பட்டியல், உருவாக்கி, பகுப்பாய்விகள்) + `skills/` கோப்பகம் (SKILL.md கோப்புகள்)
> **கடைசியாகப் புதுப்பிக்கப்பட்டது:** 2026-08-02 — v3.8.50

Agent Skills என்பவை வெளிப்புற முகவர்கள், MCP கிளையன்ட்கள் மற்றும் A2A ஒருங்கிணைப்பாளர்களுக்கு OmniRoute-இன் REST API மற்றும் CLI-ஐ எவ்வாறு பயன்படுத்துவது என்பதைக் கற்பிக்கும் கட்டமைக்கப்பட்ட SKILL.md கோப்புகள். [Omni Skills](./SKILLS.md) போலல்லாமல் (இவை OmniRoute-க்குள் செயல்படுத்தப்படும் LLM கருவி வரையறைகள்), Agent Skills என்பது ஒரு _ஆவணப் பட்டியல்_ — முகவரின் சூழலுக்குள் நேரடியாக வழங்கக்கூடிய நிலையான markdown.

---

## கண்ணோட்டம்

இந்தப் பட்டியலில் **45 Agent Skills** உள்ளன (23 REST API + 21 CLI + 1 உள்ளமைவுப் பணிப்பாய்வு). ஒவ்வொரு திறனிலும் பின்வருபவை உள்ளன:

- ஒரு **அதிகாரப்பூர்வ ID** (`omni-auth`, `cli-serve` போன்றவை)
- YAML முன்தகவல் (`name`, `description`) + செறிவான markdown உள்ளடக்கம் கொண்ட `skills/{id}/SKILL.md` என்ற **SKILL.md** கோப்பு
- OpenAPI விவரக்குறிப்பு மற்றும் CLI பதிவகத்திலிருந்து பெறப்பட்ட **REST முனைப்புள்ளிகள்** (API திறன்கள்) அல்லது **CLI துணைக் கட்டளைகள்** (CLI திறன்கள்)
- நேரடியாகப் பெறுவதற்கான ஒரு **GitHub மூல URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API கண்டறிதல்

| Endpoint                     | Method | Description                                                                    | Auth        |
| :--------------------------- | :----- | :----------------------------------------------------------------------------- | :---------- |
| `/api/agent-skills`          | GET    | பட்டியலைக் காட்டும் (விருப்பத்தேர்வு `?category=api\|cli\|config&area=<area>`) | எதுவுமில்லை |
| `/api/agent-skills/{id}`     | GET    | ஒரு திறனின் மெட்டாடேட்டாவைப் பெறும்                                            | எதுவுமில்லை |
| `/api/agent-skills/{id}/raw` | GET    | SKILL.md-ஐ `text/markdown` ஆகப் பெறும்                                         | எதுவுமில்லை |
| `/api/agent-skills/coverage` | GET    | கவரேஜ் புள்ளிவிவரங்கள் (எத்தனை SKILL.md கோப்புகள் உள்ளன)                       | எதுவுமில்லை |
| `/api/agent-skills/generate` | POST   | உருவாக்கியைத் தூண்டும் (dryRun/prune/onlyIds)                                  | மேலாண்மை    |

எடுத்துக்காட்டு — அனைத்து API திறன்களையும் பட்டியலிடுதல்:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

எடுத்துக்காட்டு — ஒரு SKILL.md-ஐப் பெறுதல்:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP கண்டறிதல்

`read:catalog` வரம்பின் கீழ் மூன்று MCP கருவிகள் பதிவுசெய்யப்பட்டுள்ளன:

| Tool                              | Description                                                                |
| :-------------------------------- | :------------------------------------------------------------------------- |
| `omniroute_agent_skills_list`     | திறன்களைப் பட்டியலிடும் (விருப்பத்தேர்வு `category` / `area` வடிப்பான்கள்) |
| `omniroute_agent_skills_get`      | `id` மூலம் ஒரு திறனுக்கான மெட்டாடேட்டா + SKILL.md-ஐப் பெறும்               |
| `omniroute_agent_skills_coverage` | கவரேஜ் புள்ளிவிவரங்கள் (API/CLI உள்ளவை/மொத்தம்)                            |

வரம்பு இணைப்பு மற்றும் அங்கீகாரத்திற்காக [MCP-SERVER.md](./MCP-SERVER.md)-ஐப் பார்க்கவும்.

## A2A கண்டறிதல்

A2A திறனான `list-capabilities`, 45 திறன்கள் கொண்ட முழுப் பட்டியலை markdown அட்டவணை கலைப்பொருளாக வழங்குகிறது. வெளிப்புற ஒருங்கிணைப்பாளர்கள் இதைப் பின்வருமாறு அழைக்கலாம்:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

நெறிமுறை விவரங்களுக்கு [A2A-SERVER.md](./A2A-SERVER.md)-ஐப் பார்க்கவும்.

```bash
# முழுப் பட்டியலைப் பெறவும்

```

resp = requests.post("http://your-omniroute/a2a", json={

## உருவாக்கி

உருவாக்கி, கவனமாகத் தொகுக்கப்பட்ட பட்டியல் + OpenAPI விவரக்குறிப்பு + CLI பதிவகத்தைப் படித்து, ஒவ்வொரு உள்ளீட்டிற்கும் `skills/{id}/SKILL.md`-ஐ எழுதுகிறது:

```bash
# முன்னோட்டம் (சோதனை இயக்கம், எழுதுதல் இல்லை)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# முழுமையான மறுஉருவாக்கம்
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# குறிப்பிட்ட ID-களை மறுஉருவாக்கவும்
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

உருவாக்கியின் பதில் ஒரு `GeneratorReport` ஆகும்:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
