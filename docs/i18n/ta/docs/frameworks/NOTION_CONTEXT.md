## இது என்ன

OmniRoute ஒரு **Notion** பணியிடத்தை **சூழல் மூலமாக** இணைக்க முடியும் — இது உள்ளமைக்கப்பட்ட MCP சேவையகம் வழியாக ஏஜெண்டுகள் அணுகும், படிக்க/எழுதக்கூடிய ஓர் அறிவுத் தளமாகும். ஒரு Notion
ஒருங்கிணைப்பு டோக்கன் உள்ளமைக்கப்பட்டதும், MCP கருவிகள் ஒரு LLM-ஐப் பக்கங்களையும் தரவுத்தளங்களையும் தேடவும்,
பக்க உள்ளடக்கம் மற்றும் block மரங்களைப் படிக்கவும், வடிப்பான்கள்/வரிசைப்படுத்தல்களுடன் தரவுத்தளங்களை வினவவும், புதிய
block-களைச் சேர்க்கவும் அனுமதிக்கின்றன — இவை அனைத்தும் OmniRoute வழியாக பதிலியாக்கப்படுகின்றன (மறுமுயற்சி, காலக்கெடு மற்றும் பிழை வகைப்படுத்தலுடன்);
எனவே மாடல் ஒருபோதும் Notion API-ஐ நேரடியாக அணுகாது.

இந்த ஒருங்கிணைப்பு அதிகாரப்பூர்வ Notion REST API-க்கு மேலான ஒரு மெல்லிய, வலுப்படுத்தப்பட்ட உறையாகும்
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`). கிளையன்ட்
(`src/lib/notion/api.ts`) பின்வருவனவற்றைச் சேர்க்கிறது:

- `429` மற்றும் `5xx`-க்கு **அடுக்குக்குறி பின்னடைவுடன் மறுமுயற்சி** (அதிகபட்சம் 3 முயற்சிகள்).
- `AbortController` வழியாக **55-வினாடி கோரிக்கை காலக்கெடு**.
- **வகையிடப்பட்ட பிழை வகைப்படுத்தல்** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  குறிப்புகளை மதிக்கிறது), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- பிழைகளை வெளிப்படுத்துவதற்கு முன் stack trace போன்ற துண்டுகளை அகற்றும் **செய்தித் தூய்மைப்படுத்தல்**.

## அமைவு

Notion டோக்கனுக்காக **சுற்றுச்சூழல் மாறி எதுவும் இல்லை** — அது
`src/lib/db/notion.ts` வழியாக SQLite `key_value` அட்டவணையில் (namespace `notion`, key `integration_token`)
சேமிக்கப்படுகிறது. Endpoint டாஷ்போர்டின் **Context Sources** தாவலில்
(`ObsidianSourceCard`-இன் உடன்பிறப்பு `NotionSourceCard`) அல்லது அமைப்புகள் REST API வழியாக அதை உள்ளமைக்கவும்.

> [!NOTE]
> இந்த டோக்கன் ஒரு **Notion உள் ஒருங்கிணைப்பு டோக்கன்** ஆகும். ஓர் ஒருங்கிணைப்பை
> <https://www.notion.com/my-integrations> இல் உருவாக்கி, பின்னர் OmniRoute அணுக வேண்டிய
> பக்கங்கள்/தரவுத்தளங்களை அந்த ஒருங்கிணைப்புடன் பகிரவும் (Notion-இன் அனுமதி மாதிரி பகிர்வு அடிப்படையிலானது;
> முழுப் பணியிடத்திற்குமானது அல்ல).

### REST வழியாக உள்ளமைத்தல்

```bash
# ஒருங்கிணைப்பு டோக்கனைச் சேமித்து + சரிபார்க்கவும் (POST ஒரு சோதனைத் தேடலை அனுப்பி சரிபார்க்கிறது)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# இணைப்பு நிலையைச் சரிபார்க்கவும்
curl http://localhost:20128/api/settings/notion

# இணைப்பைத் துண்டிக்கவும் (சேமிக்கப்பட்ட டோக்கனை அழிக்கிறது)
curl -X DELETE http://localhost:20128/api/settings/notion
```

இந்த மூன்று முறைகளுக்கும் டாஷ்போர்டு அங்கீகாரம் (`isAuthenticated`) தேவை. `POST` செய்யும்போது,
OmniRoute டோக்கனைச் சேமித்து உடனடியாக 1-முடிவு கொண்ட சோதனைத் தேடலை இயக்குகிறது; Notion
ஒரு பிழைப் பொருளைத் திருப்பினால், டோக்கன் அழிக்கப்பட்டு அழைப்பு `400` உடன் தோல்வியடையும்.

## MCP கருவிகள் (6)

`open-sse/mcp-server/tools/notionTools.ts`-இல் வரையறுக்கப்பட்டுள்ளன. அழைப்பு நேரத்தில்
`getNotionToken()` வழியாக டோக்கன் பெறப்படுகிறது; எதுவும் உள்ளமைக்கப்படவில்லை என்றால் கருவி
`"Notion integration token not configured. Set it in Settings > Context Sources."`
என்று பிழை எழுப்பும்.

| கருவி                        | Scope          | விளக்கம்                                                                                                                     |
| ---------------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | உரை வினவல் மூலம் பக்கங்களையும் தரவுத்தளங்களையும் தேடுகிறது (தலைப்புகள், ID-கள், URL-களைத் திருப்பும்). பக்கப் பிரிப்புடையது. |
| `notion_get_page`            | `read:notion`  | ஒரு பக்கத்தின் ID மூலம் அதன் உள்ளடக்கத்தையும் metadata-வையும் பெறுகிறது.                                                     |
| `notion_list_block_children` | `read:notion`  | ஒரு block அல்லது பக்கத்தின் அனைத்து துணை block-களையும் (block மரத்தை) பட்டியலிடுகிறது. பக்கப் பிரிப்புடையது.                 |
| `notion_query_database`      | `read:notion`  | விருப்பத்திற்குரிய `filter` + `sorts` உடன் (Notion API வடிவம்) தரவுத்தளத்தை வினவுகிறது. பக்கப் பிரிப்புடையது.                |
| `notion_get_database`        | `read:notion`  | ID மூலம் ஒரு தரவுத்தளத்தின் schema/metadata-வைப் பெறுகிறது.                                                                  |
| `notion_append_blocks`       | `write:notion` | ஏற்கனவே உள்ள block அல்லது பக்கத்தில் துணை block-களைச் சேர்க்கிறது (ஒரு கோரிக்கைக்கு அதிகபட்சம் 100 block-கள்).               |

### உள்ளீட்டு அளவுருக்கள்

- `notion_search` — `query` (1–500 எழுத்துகள்), `pageSize` (1–100, இயல்புநிலை 20),
  `startCursor` (விருப்பத்திற்குரியது).
- `notion_get_page` — `pageId` (32-எழுத்து hex அல்லது UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, இயல்புநிலை 50),
  `startCursor` (விருப்பத்திற்குரியது).
- `notion_query_database` — `databaseId`, `filter` (விருப்பத்திற்குரியது, Notion வடிப்பான் வடிவம்),
  `sorts` (விருப்பத்திற்குரிய array), `pageSize` (1–100, இயல்புநிலை 50), `startCursor` (விருப்பத்திற்குரியது).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (block பொருட்களின் array),
  `after` (விருப்பத்திற்குரிய நிலை).

### Scope-கள்

படிப்புக் கருவிகளுக்கு `read:notion` தேவை; எழுதும் கருவிக்கு `write:notion` தேவை.
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` ஆக இருக்கும்போது மட்டுமே
`open-sse/mcp-server/server.ts`-இல் உள்ள `withScopeEnforcement()` மூலம் scope-கள் அமல்படுத்தப்படுகின்றன;
அழைப்பவருக்கு அனுமதிக்கப்பட்ட scope-கள் `OMNIROUTE_MCP_SCOPES`-இலிருந்து (காற்புள்ளியால் பிரிக்கப்பட்டவை) அல்லது
அங்கீகரிக்கப்பட்ட API key-இன் scope சூழலிலிருந்து பெறப்படுகின்றன. முழுமையான scope மாதிரிக்கு
[MCP-SERVER.md](./MCP-SERVER.md)-ஐப் பார்க்கவும்.

| முறை     | பாதை                   | நோக்கம்                                                   |
| -------- | ---------------------- | --------------------------------------------------------- |

| `POST`   | `/api/settings/notion` | ஒருங்கிணைப்பு டோக்கனைச் சேமித்து + சரிபார்க்கும்.         |

> இவை டாஷ்போர்டு அமைப்புகளுக்கான வழித்தடங்கள். பொதுப் பயன்பாட்டிற்கான `/v1` Notion ப்ராக்ஸி
> **எதுவும் இல்லை** — மேலே உள்ள MCP கருவிகள் மூலமாக மட்டுமே Notion அணுகப்படுகிறது.

## பயன்பாட்டு நிலைகள்

- **அறிவு அடிப்படையிலான பதில்கள்** — பதிலளிப்பதற்கு முன், ஒரு முகவர் பணியிடத்தில் `notion_search` செய்து,
  முதன்மையான முடிவை `notion_get_page` மூலம் பெற அனுமதிக்கவும்; இதனால் பதில்களில் உண்மையான உள் ஆவணங்களை மேற்கோள் காட்ட முடியும்.
- **தரவுத்தள அடிப்படையிலான பணிப்பாய்வுகள்** — வடிப்பான்கள் + வரிசைப்படுத்தல்களுடன் பணிகள்/CRM தரவுத்தளத்தை
  `notion_query_database` மூலம் வினவி, பின்னர் வரிசைகளைச் சுருக்கமாகத் தொகுக்கவும் அல்லது முன்னுரிமைப்படுத்தவும்.
- **மீண்டும் எழுதுதல் / பதிவுசெய்தல்** — சந்திப்புக் குறிப்புகள், இயக்கச் சுருக்கங்கள் அல்லது முகவர் வெளியீட்டை ஏற்கனவே உள்ள பக்கத்தில் சேர்க்க
  `notion_append_blocks` பயன்படுத்தவும் (சேர்த்தல் மட்டும்; அழிவை ஏற்படுத்தும் திருத்தங்கள் இல்லை).
- **கட்டமைப்பு ஆய்வு** — ஒரு பக்கத்தின் தொகுதி மரத்தை ஆராய `notion_list_block_children` பயன்படுத்தவும்,
  அல்லது தரவுத்தளத்தை வினவுவதற்கு முன் அதன் பண்புக்கூறு திட்டவடிவத்தைக் கண்டறிய `notion_get_database` பயன்படுத்தவும்.
