`agentrouter` அப்ஸ்ட்ரீம் கேட்வே, `messages[].content` மீது திறவுச்சொல் அடிப்படையிலான உள்ளடக்க வடிகட்டியை இயக்குகிறது. இந்த வடிகட்டி பகுதியளவில் நிர்ணயிக்கப்பட்டது (சில சொற்றொடர்களை எப்போதும் தடுக்கும்), பகுதியளவில் நிகழ்தகவு சார்ந்தது (தொடர் கோரிக்கைகளுக்கு உணர்திறன் கொண்டது — குறுகிய நேரத்தில் விரைவான கோரிக்கைகள் வந்த பிறகு மேலும் கடுமையாகி, ஓய்வுக் காலத்திற்குப் பிறகு மீள்கிறது).

WAF ஒரு கோரிக்கையைத் தடுக்கும்போது, அது பின்வருமாறு பதிலளிக்கிறது:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## வடிகட்டியின் வரம்பு

WAF, `messages[].content`ஐ மட்டுமே பரிசோதிக்கிறது. இது பின்வருவனவற்றைப் பரிசோதிப்பதில்லை:

- `system` prompt
- கட்டமைக்கப்பட்ட உள்ளடக்கத் தொகுதிகள் (`tool_result`, `tool_use`, `thinking`, `image`)
- Tool `description` மற்றும் `input_schema` புலங்கள்
- கோரிக்கை மெட்டாடேட்டா, headers அல்லது model id

## எப்போதும் தடுக்கப்படும் வடிவங்கள் (எழுத்துப் பெட்டி வேறுபாட்டைப் பொருட்படுத்தாது)

| வடிவம்                         | குறிப்புகள்                                                              |
| ------------------------------ | ------------------------------------------------------------------------ |
| ஏதேனும் `Lorem ipsum` மாறுபாடு | முழுமையான Latin lorem சொற்களஞ்சியம் தடுக்கப்படுகிறது                     |
| `language model` (தனியாக)      | "the language model" மற்றும் "large language model" அனுமதிக்கப்படுகின்றன |
| `virtual assistant`            | "AI assistant" அனுமதிக்கப்படுகிறது                                       |
| `I'm here to help`             | "here to help" மட்டும் இருந்தாலும் தடுக்கப்படுகிறது                      |
| `Claude, made by Anthropic`    | முழுச் சொற்றொடர் மட்டும்                                                 |

## கிட்டத்தட்ட எப்போதும் தடுக்கப்படும் வடிவங்கள்

| வடிவம்                                                          | குறிப்புகள்                                                     |
| --------------------------------------------------------------- | --------------------------------------------------------------- |
| `placeholder`                                                   | இது தனியாக இடம்பெறும்போது (parameter பெயராக இல்லாதபோது போன்றவை) |
| `dummy data`                                                    | fixtures-க்கான பொதுவான seed சொற்றொடர்                           |
| `foo bar baz`                                                   | வழக்கமான placeholder சொற்றொடர்                                  |
| மீண்டும் வரும் குறுகிய tokens (`AAA BBB CCC`, `test test test`) | keyword stuffing-ஐக் கண்டறியும் detector                        |

## சுமையின் கீழ் நடத்தை

குறுகிய காலச் சாளரத்தில் சுமார் 5 விரைவான கோரிக்கைகளுக்குப் பிறகு, வழக்கமாக அனுமதிக்கப்படும் உள்ளடக்கத்தையும் WAF தடுக்கத் தொடங்குகிறது. சுமார் 5–10 வினாடிகள் செயலற்றிருந்த பிறகு bucket தளர்கிறது. Claude Code அல்லது Codex CLI பல tool-use / message-send அழைப்புகளை விரைவாக அடுத்தடுத்து மேற்கொள்ளும்போது இடையிடையே ஏற்படும் `400 content-blocked` பிழைகளுக்குக் காரணமான, IP மற்றும் key-உடன் பிணைக்கப்பட்ட அதே rate limiter இதுவாகும்.

## OmniRoute-இல் ஏற்கெனவே செயல்படுத்தப்பட்ட தணிப்பு நடவடிக்கைகள்

1. **`open-sse/services/wafRateLimit.ts`** — எந்தவொரு `agentrouter:*` URL-க்கும் அனுப்பப்படும் வெளியேறும் கோரிக்கைகளுக்கு இடையில் குறைந்தபட்சம் 500 ms இடைவெளியை அமல்படுத்தும் burst guard. இந்த இடைவெளி மனிதர்கள் உணரக்கூடிய தாமதத்தைவிட மிகவும் குறைவானது; மேலும் சாதாரண போக்குவரத்தில் WAF செயல்படுவதைத் தடுக்கிறது.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — ஒரு அப்ஸ்ட்ரீம் `400 content-blocked`ஐத் திருப்பி அனுப்பும்போது, executor அதே URL-ஐ exponential backoff-உடன் மீண்டும் முயற்சிக்கிறது (1.5 s, 3.0 s, அதிகபட்சம் 2 முயற்சிகள்). Backoff-க்குப் பிறகு WAF வழக்கமாகத் தளர்வதால், மறுமுயற்சி வெற்றியடைகிறது.

3. **`tests/unit/compression/harness.test.ts`** — test fixture `longInput`, `"lorem ipsum dolor sit amet ".repeat(40)` என்பதிலிருந்து `"example content for testing purposes ".repeat(40)` என மாற்றப்பட்டது. இதனால் Claude Code இந்தக் கோப்பை `Read` tool வழியாகப் படிக்கும்போது, கோப்பின் உள்ளடக்கங்கள் `tool_result` block வழியாக மீண்டும் சென்று WAF-ஐத் தூண்டாது.

## Prompts மற்றும் tool வெளியீட்டிற்கான வழிகாட்டுதல்

Claude Code அல்லது Codex CLI session தொடர்ந்து `400 content-blocked` பிழையைச் சந்தித்தால், மிகச் சமீபத்திய user message மற்றும் மிகச் சமீபத்திய tool result ஆகியவற்றில் மேலே குறிப்பிடப்பட்ட வடிவங்கள் ஏதேனும் உள்ளனவா எனச் சரிபார்த்து, வேறு விதமாக எழுதவும். பொதுவான மாற்று வழிகள்:

- `Lorem ipsum …` என்பதை `example text …` அல்லது test அல்லது fixture பிரதிநிதித்துவப்படுத்த முயலும் உண்மையான உள்ளடக்கத்தால் மாற்றவும்.
- `placeholder` (தனியாக இடம்பெறும்போது) என்பதை `example value`, `sample value` அல்லது உண்மையான மதிப்பால் மாற்றவும்.
- `language model` என்பதை `large language model` அல்லது `the model` என்பதால் மாற்றவும்.
- `dummy data` என்பதை `sample data` அல்லது யதார்த்தமான seed மதிப்புகளால் மாற்றவும்.
- `I'm here to help` / `here to help` என்பதை மேலும் குறிப்பிட்ட தொடக்கத்தால் மாற்றவும் (எ.கா. "I'll review the file you mentioned").

## தவறான நேர்மறைகளை அப்ஸ்ட்ரீமுக்குப் புகாரளித்தல்

தற்போதைய வடிகட்டி அளவுக்கு மீறிய கடுமையுடன் உள்ளது — operator ஒரு prompt-ஐ inject செய்ய நினைக்கவில்லை என்பது தெளிவாக இருந்தாலும், `tool_result` blocks-இல் உள்ள "Lorem ipsum"ஐ இது தடுக்கிறது. இதை மூலத்திலேயே சரிசெய்ய விரும்பும் operators, தவறான நேர்மறைகளைப் புகாரளிக்க `agentrouter.org`ஐத் தொடர்புகொள்ள வேண்டும். மேலே உள்ள blocklist, 2026-08-03 நிலவரப்படி அப்ஸ்ட்ரீமைச் சோதித்ததில் கிடைத்த அனுபவப்பூர்வ முடிவாகும்.
