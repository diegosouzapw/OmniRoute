## `claude-web`

`claude-web`, அங்கீகரிக்கப்பட்ட `claude.ai` உலாவி அமர்வு மூலம் OpenAI-வடிவ அரட்டை கோரிக்கைகளை அனுப்புகிறது. வழங்கப்பட்ட cookie-ஐ executor இயல்பாக்கி, அங்கீகரிக்கப்பட்ட ஓர் organization-ஐத் தீர்மானித்து, conversation state-ஐத் தயாரித்து, நேரடி அல்லது உலாவி transport-ஐத் தேர்ந்தெடுத்து, upstream SSE response-ஐக் கண்டிப்பாக மொழிபெயர்க்கிறது. Orchestration ஆனது `open-sse/executors/claude-web.ts:320`-இல் உள்ளது.

> **Web Cookie வழங்குநர்களுக்கு புதியவரா?**
>
> இந்த வழங்குநருக்குரிய வழிகாட்டியைப் பின்பற்றுவதற்கு முன், பொதுவான அமைவுச் செயல்முறை, அங்கீகார வழிகாட்டுதல், வரம்புகள் மற்றும் சிக்கல் தீர்வு ஆகியவற்றுக்கு **`docs/getting-started/WEB-COOKIE-GUIDE.md`**-ஐப் படிக்கவும்.

### மாடல் பட்டியல்

வழங்குநர் registry தற்போது இந்த ஏழு நிலையான model ID-களை மட்டும் வெளிப்படுத்துகிறது
(`open-sse/config/providers/registry/claude/web/index.ts:11`):

| Model ID                    | காட்சிப் பெயர்          |
| --------------------------- | ----------------------- |
| `claude-fable-5`            | Claude Fable 5 (வலை)    |
| `claude-opus-4-8`           | Claude Opus 4.8 (வலை)   |
| `claude-sonnet-5`           | Claude Sonnet 5 (வலை)   |
| `claude-haiku-4-5-20251001` | Claude Haiku 4.5 (வலை)  |
| `claude-opus-4-7`           | Claude Opus 4.7 (வலை)   |
| `claude-opus-4-6`           | Claude Opus 4.6 (வலை)   |
| `claude-sonnet-4-6`         | Claude Sonnet 4.6 (வலை) |

இந்த வழங்குநருக்காக dynamic model discovery செயல்படுத்தப்படவில்லை. மேலேயுள்ள பட்டியலே runtime catalog ஆகும்.

### நற்சான்றுகள் மற்றும் organization தீர்மானம்

முழுமையான `claude.ai` Cookie header அல்லது session value மட்டும் ஆகியவற்றில் ஏதேனும் ஒன்றை வழங்கவும். தனித்த value-கள் `sessionKey` ஆக இயல்பாக்கப்படுகின்றன; பிற cookie-கள் வழங்கப்பட்டிருந்தால் அவை பாதுகாக்கப்படும். Executor, `cookie` அல்லது `apiKey` மூலம் cookie-ஐ ஏற்றுக்கொண்டு, connection data-விலிருந்து விருப்பமான `deviceId` மற்றும் `orgId` value-களைப் படிக்கிறது
(`open-sse/executors/claude-web.ts:72`).

`orgId` இல்லாவிட்டால், executor `GET https://claude.ai/api/organizations`-ஐ அழைத்து, அங்கீகரிக்கப்பட்ட Claude Web session திருப்பியளிக்கும் முதல் organization-ஐப் பயன்படுத்துகிறது
(`open-sse/executors/claude-web.ts:141`). செல்லுபடியாகும் organization எதுவும் திருப்பியளிக்கப்படாதபோது இது பாதுகாப்பாகத் தோல்வியடைகிறது; நிராகரிக்கப்பட்ட session authorization-ஐ 401 என அறிவிக்கிறது; மேலும் Cloudflare challenge-ஐ authentication failure-இலிருந்து வேறுபடுத்துகிறது.

### Conversation செயல்பாடுகள்

விருப்பமான மேல்-நிலை `claude_web` object கண்டிப்பானது. அறியப்படாத field-கள் நிராகரிக்கப்படுகின்றன. அது ஏற்றுக்கொள்ளும் field-கள் `open-sse/executors/claude-web/session.ts:50`-இல் வரையறுக்கப்பட்டுள்ளன:

| Field                 | பொருள்                                                                        |
| --------------------- | ----------------------------------------------------------------------------- |
| `operation`           | இயல்புநிலையாக `completion`; மீண்டும் முயலும் turn-க்கு `retry` பயன்படுத்தவும் |
| `conversation_id`     | ஏற்கனவே உள்ள conversation-க்கான வெளிப்படையான UUID                             |
| `parent_message_uuid` | parent assistant message-க்கான வெளிப்படையான UUID                              |
| `timezone`            | செல்லுபடியாகும் IANA time-zone பெயர்                                          |
| `locale`              | கட்டமைப்புரீதியாகச் செல்லுபடியாகும் locale                                    |
| `tool_states`         | விருப்பமான account tool-state array; 128 entry-கள் வரை வரம்பிடப்பட்டது        |

தயாரிக்கப்பட்ட request-கள் இரண்டு upstream endpoint-களில் ஒன்றைப் பயன்படுத்துகின்றன
(`open-sse/executors/claude-web.ts:203`):

- புதிய அல்லது follow-up turn பின்வருமிடத்திற்கு post செய்யப்படுகிறது:
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/completion`.
- retry பின்வருமிடத்திற்கு post செய்யப்படுகிறது:
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion`.

ஒரு புதிய turn-இல் `create_conversation_params` சேர்க்கப்படும். Cache செய்யப்பட்ட அல்லது வெளிப்படையாக இணைக்கப்பட்ட follow-up-இல் `parent_message_uuid` சேர்க்கப்பட்டு, `create_conversation_params` விடுபடும். Retry-க்கு conversation மற்றும் parent-message state ஆகிய இரண்டும் தேவை; அது prompt எதையும் அனுப்பாது
(`open-sse/executors/claude-web/session.ts:254`). புதிய conversation-கள் அங்கீகரிக்கப்பட்ட UI-ஐ `/new`-இல் திறக்கும்; cache செய்யப்பட்ட அல்லது வெளிப்படையாக இணைக்கப்பட்ட follow-up-கள் துல்லியமான conversation page-ஐத் திறக்கும்
(`open-sse/executors/claude-web/session.ts:324`).

Conversation state என்பது SHA-256 account scope மற்றும் canonical caller transcript ஆகியவற்றால் key செய்யப்பட்ட in-memory cache ஆகும். Entry-கள் 30 நிமிடங்களுக்குப் பிறகு காலாவதியாகும்; cache அதிகபட்சம் 5,000 entry-களாக வரம்பிடப்பட்டுள்ளது
(`open-sse/executors/claude-web/session.ts:12`). கண்டிப்பான stream parser `message_stop`-ஐக் கண்ட பிறகே state commit செய்யப்படும்; process restart-கள் அதை நீக்கிவிடும். Cache miss ஏற்படும்போது, முந்தைய message-களை அமைதியாகக் கைவிடுவதற்குப் பதிலாக, multi-message request ஒற்றை recovery prompt ஆக serialize செய்யப்படும்.

Locale மற்றும் time zone பின்வரும் முன்னுரிமையைப் பயன்படுத்துகின்றன: request `claude_web` value, connection value, runtime value, பின்னர் locale-க்கு `en-US` அல்லது time zone-க்கு `UTC`
(`open-sse/executors/claude-web/session.ts:218`).

### Tool-களும் request payload-களும்

நேரடி request-கள் caller வழங்கிய கட்டமைப்புரீதியாகச் செல்லுபடியாகும் OpenAI function tool-களை மட்டுமே மாற்றுகின்றன. உருவாக்கிப் பொருத்தப்பட்ட நிலையான default tool list எதுவும் இல்லை
(`open-sse/executors/claude-web/payload.ts:102`).

அதற்கு மாறாக, browser request-கள் அங்கீகரிக்கப்பட்ட UI request-ஐப் பதிவு செய்து, அதன் account tool-கள், tool state-கள் மற்றும் தனிப்பயனாக்கப்பட்ட style-களைத் தக்கவைக்கின்றன. தயாரிக்கப்பட்ட conversation, model, reasoning, prompt மற்றும் message UUID field-கள், பதிவு செய்யப்பட்ட request-ஐ இன்னும் override செய்கின்றன
(`open-sse/executors/claude-web/browserTransport.ts:175`). Browser template-கள் account, organization, cookie, locale மற்றும் time zone ஆகியவற்றின் hash மூலம் scope செய்யப்பட்டு, 30 நிமிடங்களுக்குப் பிறகு காலாவதியாகின்றன
(`open-sse/executors/claude-web/browserTransport.ts:11`,
`open-sse/executors/claude-web/browserTransport.ts:158`). ஒரு நேரடி request-இல் caller tool-கள் இல்லாதபோது, அது அந்த scoped template-ஐ மீண்டும் பயன்படுத்தலாம்; வெளிப்படையாக வழங்கப்பட்ட caller tool-களுக்கு முன்னுரிமை அளிக்கப்படும்
(`open-sse/executors/claude-web/browserTransport.ts:214`).

### Transport தேர்வு

இயல்புநிலை பாதை `sendClaudeWebDirect()` ஆகும்; இது அமைக்கப்பட்ட Chrome 146 profile மற்றும் வழங்கப்பட்ட cookie உடன் `tlsFetchClaude()`-ஐ அழைக்கிறது (`open-sse/services/claudeTlsClient.ts:23`). இது solver-ஐத் தொடங்குவதோ மாற்று cookie-ஐ உருவாக்குவதோ இல்லை.

கணக்கு-வரம்பிற்குட்பட்ட உலாவி அடாப்டரை முதன்மைப் போக்குவரத்தாக மாற்ற, `WEB_COOKIE_USE_BROWSER` ஐ `1`, `true`, அல்லது `on` என அமைக்கவும். அங்கீகரிக்கப்பட்ட Cloudflare 403 சவால் ஏற்பட்டால், நேரடிப் போக்குவரத்திலிருந்து உலாவி அடாப்டருக்குப் பின்னடைய அனுமதிக்க `OMNIROUTE_BROWSER_POOL` ஐ அதே மதிப்புகளில் ஒன்றாக அமைக்கவும் (`open-sse/executors/claude-web.ts:195`). பிற HTTP தோல்விகள் அந்தப் பின்னடைவைத் தூண்டாது.

உலாவி அடாப்டர் குக்கீகளை அதே பகிரப்பட்ட Playwright சூழலுக்குள் வைத்திருக்கிறது, மேலே விவரிக்கப்பட்ட வரம்பிற்குட்பட்ட ஹாஷ் செய்யப்பட்ட விசையைப் பயன்படுத்துகிறது, மேலும் அந்தச் சூழலிலிருந்து நிறைவை அனுப்புகிறது (`open-sse/executors/claude-web/browserTransport.ts:444`). உலாவியால் தீர்க்கப்பட்ட குக்கீயை இது ஒருபோதும் நேரடி TLS கிளையண்டிற்கு ஏற்றுமதி செய்வதில்லை. உலாவி மறுமுயற்சிகளுக்கு, அதே உண்மையான Playwright சூழலுடன் பிணைக்கப்பட்ட, காலாவதியாகாத UI வார்ப்புரு தேவை (`open-sse/executors/claude-web/browserTransport.ts:467`). உலாவிப் பதிப்பு வாசிப்புகள் அங்கீகரிக்கப்பட்ட பக்கத்தில் படிப்படியாக நடைபெறுகின்றன, கோரிக்கை ரத்தாக்கத்தை மதிக்கின்றன, மேலும் அளவு 16 MiB ஐத் தாண்டியவுடன் மேல்நிலை body ஐ ரத்துசெய்கின்றன (`open-sse/executors/claude-web/browserTransport.ts:259`).

செயலாக்கி, பகிரப்பட்ட கோரிக்கைப் பதிவிக்கு மறைக்கப்பட்ட தணிக்கைப் பிரதிநிதித்துவத்தைத் திருப்பி அனுப்புகிறது: நிறுவனம், உரையாடல் மற்றும் செய்தி UUID-கள், prompt உரை, கருவி வரையறைகள், குக்கீகள் மற்றும் சாதன அடையாளங்காட்டிகள் ஆகியவை விலக்கப்படுகின்றன (`open-sse/executors/claude-web.ts:237`,
`open-sse/executors/claude-web.ts:252`). போக்குவரத்து விதிவிலக்குகளும் எறியப்பட்ட செய்திக்குப் பதிலாக பொதுவான இணைப்புப் பிழையையே திருப்பி அனுப்புகின்றன.

### SSE நடத்தை

`createClaudeWebResponse()` ஆனது LF அல்லது CRLF கட்டமைப்பையும், பல வரிகளைக் கொண்ட `data:` புலங்களையும் கையாளுகிறது. இது உரை வேறுபாடுகளை `content` க்கும், சிந்தனை வேறுபாடுகளை `reasoning_content` க்கும், அறியப்பட்ட மெட்டாடேட்டா நிகழ்வுகளை `claude_web` பதில் நீட்டிப்பிற்கும் பொருத்துகிறது. ஒவ்வொரு மெட்டாடேட்டா நிகழ்வும் அதற்குரிய தனிப் புல அனுமதிப்பட்டியல் வழியாக பிரதிநிதித்துவப்படுத்தப்படுகிறது (`open-sse/executors/claude-web/stream.ts:37`). உரையாடல், மூலச் செய்தி, உதவியாளர் செய்தி மற்றும் செயல்பாட்டு மெட்டாடேட்டாவும் `X-OmniRoute-Claude-Web-*` தலைப்புகளில் திருப்பி அனுப்பப்படுகின்றன (`open-sse/executors/claude-web/stream.ts:364`).

தவறான JSON, மேல்நிலை `error` நிகழ்வுகள், அறியப்படாத நிகழ்வு வகைகள், செல்லாத வரிசைப்படுத்தல், உள்ளடக்கத் தொகுதி பொருத்தமின்மைகள் அல்லது `message_stop` க்கு முன் ஏற்படும் EOF ஆகியவற்றில் பாகுபடுத்தி மூடிய நிலையில் தோல்வியடைகிறது. ஸ்ட்ரீமிங் வெளியீடு ஒரு நிறைவுத் துண்டையும் ஒரு `[DONE]` ஐயும் வெளியிடுகிறது; இடையகப்படுத்தப்பட்ட வெளியீடும் அதே பாகுபடுத்தியைப் பயன்படுத்துகிறது. பாகுபடுத்தி `message_stop` ஐ உடனடியாக இறுதி நிலையாகக் கருதி, பின்னால் வரும் மேல்நிலைத் தரவை ரத்துசெய்கிறது, மேலும் கீழ்நிலை ரத்தாக்கத்தை மேல்நிலை வாசிப்பானுக்குப் பரப்புகிறது (`open-sse/executors/claude-web/stream.ts:461`,
`open-sse/executors/claude-web/stream.ts:563`). முடிக்கப்படாத SSE வரிகளும் திரட்டப்பட்ட நிகழ்வுகளும் 1 MiB ஆக வரம்பிடப்பட்டுள்ளன (`open-sse/executors/claude-web/stream.ts:17`,
`open-sse/executors/claude-web/stream.ts:62`).

node --import tsx/esm --test tests/unit/claude-web-auto-refresh.test.ts tests/unit/claude-web-browser-transport.test.ts tests/unit/claude-web-executor-split.test.ts tests/unit/claude-web-live-alignment.test.ts tests/unit/claude-web-payload-runtime.test.ts tests/unit/claude-web-session.test.ts tests/unit/claude-web-sonnet5-registry-6209.test.ts tests/unit/claude-web-stream.test.ts tests/unit/claude-web-transport.test.ts tests/unit/claude-web.test.ts tests/unit/issue-6662-repro.test.ts

`tests/unit/claude-web-auto-refresh.test.ts` இல் உள்ள Playwright-சார்ந்த சோதனை நிகழ்வுகள் வெளிப்படையாகத் தவிர்க்கப்படுகின்றன. இந்தக் களஞ்சியம் தற்போது நற்சான்றுகள் தேவைப்படும் Claude Web நேரடிச் சோதனை ஸ்கிரிப்டை வரையறுக்கவில்லை; எனவே தவிர்க்கப்பட்ட அந்த நிகழ்வுகள் இயக்கநேரச் சான்றாகாது.

### அமைப்பு

1. `npm run dev` அல்லது உருவாக்கப்பட்ட நிறுவலைப் பயன்படுத்தி OmniRoute ஐத் தொடங்கவும்.
2. Dashboard → Providers → Add Provider என்பதைத் திறக்கவும்.
3. Web Cookie வகையையும் Claude Web ஐயும் தேர்ந்தெடுக்கவும்.
4. அங்கீகரிக்கப்பட்ட `claude.ai` கோரிக்கையிலிருந்து நகலெடுக்கப்பட்ட முழு Cookie தலைப்பை ஒட்டவும்.
