```

...
```

பாதை முன்னொட்டு: `/dashboard/costs/`

| உருப்படி              | URL                                  | விளக்கம்                                                                  |
| --------------------- | ------------------------------------ | ------------------------------------------------------------------------- |
| கண்ணோட்டம்            | `/dashboard/costs`                   | ஒருங்கிணைக்கப்பட்ட செலவு டாஷ்போர்டு (பகுப்பாய்விலிருந்து நகர்த்தப்பட்டது) |
| விலை நிர்ணயம்         | `/dashboard/costs/pricing`           | ஒவ்வொரு மாதிரிக்குமான விலைப் பட்டியல்                                     |

நகர்த்துவதால், கண்காணிப்புத் திறன் கருவிகள் வழியாகச் செல்லாமலேயே அவற்றைக் கண்டறிய முடியும்.

## கண்காணிப்புப் பிரிவு (மறுசீரமைக்கப்பட்டது)

கண்காணிப்புப் பிரிவில் இப்போது **மேலே செயல்பாடு** உள்ளது; அதைத் தொடர்ந்து **3 துணைக்குழுக்கள்** உள்ளன:

```
கண்காணிப்பு
├── செயல்பாடு             ← காலவரிசை ஊட்டம் (உயர்நிலை உருப்படி)
├── பதிவுகள் குழு
│   ├── பதிவுகள் (அனைத்தும்)
│   ├── ப்ராக்ஸி பதிவுகள்
│   └── கன்சோல் பதிவுகள்
├── தணிக்கைக் குழு
│   ├── தணிக்கைப் பதிவு
│   ├── MCP தணிக்கை
│   └── A2A தணிக்கை
└── கணினிக் குழு
    ├── ஆரோக்கியம்
    └── இயக்கநேரம்
```

### பழைய கட்டமைப்பிலிருந்து மாற்றப்பட்டவை

| முன்பு                                                                                                                | பிறகு                                                   |
| --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| செயல்பாடு = தணிக்கைப் பதிவைக் காட்டிய பதிவுகளுக்குள் இருந்த தாவல்                                                     | செயல்பாடு = தனிப்பட்ட ஊட்டம் (`/dashboard/activity`)    |
| கண்காணிப்பில் இருந்த செலவு அளவுருக்கள் குழு                                                                           | செலவுகள் பிரிவுக்கு நகர்த்தப்பட்டது                     |
| தட்டையான பட்டியல்: பதிவுகள், செயல்பாடு (பதிவுகள்), தணிக்கை, ஆரோக்கியம், இயக்கநேரம், விலை நிர்ணயம், பட்ஜெட், ஒதுக்கீடு | கட்டமைக்கப்பட்ட 3 குழுக்கள் + தனிப்பட்ட செலவுகள் பிரிவு |

## செயல்பாடு மற்றும் தணிக்கைப் பதிவு

இவை இரண்டும் இப்போது தனித்தனியானவை:

| பரிமாணம்                     | செயல்பாடு (`/dashboard/activity`)                                                                        | தணிக்கைப் பதிவு (`/dashboard/audit`)               |
| ---------------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **நோக்கம்**                  | பயனர் எதிர்கொள்ளும் நிகழ்வு ஊட்டம் ("சமீபத்தில் என்ன நடந்தது")                                           | இணக்கப்பாடு / பாதுகாப்புப் பதிவு                   |
| **தரவு மூலம்**               | `GET /api/compliance/audit-log?level=high`                                                               | `GET /api/compliance/audit-log?level=all`          |
| **வடிவம்**                   | நாள் வாரியாகத் தொகுக்கப்பட்ட காலவரிசை, மனிதர்கள் எளிதில் புரிந்துகொள்ளக்கூடிய வினைச்சொற்கள் + சின்னங்கள் | அடர்த்தியான பக்கமிடப்பட்ட அட்டவணை, பக்கத்திற்கு 50 |
| **வடிப்பான்கள்**             | நிகழ்வு வகைப் பிரிவு                                                                                     | செயல், தீவிரம், செயல்பாட்டாளர், தேதி வரம்பு        |
| **ஏற்றுமதி**                 | கிடைக்காது                                                                                               | JSON ஏற்றுமதி                                      |
| **செயல்பாட்டாளர் வடிப்பான்** | பொருந்தாது                                                                                               | செயல்பாட்டாளர் அடிப்படையில் வடிக்கலாம்             |
| **காட்டப்படும் நிகழ்வுகள்**  | உயர்நிலைச் செயல்கள் மட்டும் (அனுமதிப்பட்டியல்)                                                           | அனைத்து தணிக்கை நிகழ்வுகளும்                       |

### உயர்நிலைச் செயல்களின் அனுமதிப்பட்டியல்

`src/lib/audit/highLevelActions.ts`-இல் வரையறுக்கப்பட்டுள்ளது. செயல்பாட்டு ஊட்டத்தில் எந்த
நிகழ்வுகள் தோன்றும் என்பதை இது கட்டுப்படுத்துகிறது. அனுமதிப்பட்டியலில் பின்வருவன அடங்கும்:

- வழங்குநரைச் சேர்த்தல்/அகற்றல்/சோதித்தல் நிகழ்வுகள்
- காம்போவை உருவாக்குதல்/புதுப்பித்தல்/நீக்குதல்
- API விசையின் வாழ்க்கைச் சுழற்சி (உருவாக்குதல், திரும்பப் பெறுதல், சுழற்றுதல்)
- பட்ஜெட் வரம்பை அடைதல்
- அங்கீகார உள்நுழைவு/வெளியேற்றம்
- கிளவுட் முகவர் அமர்வை உருவாக்குதல்
- MCP கருவிப் பதிவு
- Webhook உருவாக்குதல்/நீக்குதல்
- ஒதுக்கீட்டுத் தொகுப்பு/திட்ட மாற்றங்கள் (`quota.*` செயல்கள், Group B)
- தள நிகழ்வுகள் (புதுப்பித்தல், பணியமர்த்தல்)
- திறனை நிறுவுதல்/அகற்றுதல்

இந்தப் பட்டியலில் இல்லாத நிகழ்வுகள் தணிக்கைப் பதிவில் மட்டுமே தோன்றும்.

### புதிய உயர்நிலைச் செயலைச் சேர்த்தல்

`src/lib/audit/highLevelActions.ts`-ஐத் திருத்தி, செயல் சரத்தை
`HIGH_LEVEL_ACTIONS`-இல் சேர்க்கவும். இதற்கு ஒரு PR தேவைப்படுகிறது (இந்தப் பட்டியல் குறிமுறையாகும்,
DB வழியாக உள்ளமைக்கக்கூடியது அல்ல). தொடர்புடைய சின்னத்தை `src/lib/audit/activityIcons.ts`-இல் சேர்க்கலாம்.
