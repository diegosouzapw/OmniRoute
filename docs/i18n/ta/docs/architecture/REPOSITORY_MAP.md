## மேல்நிலை மரம்

```
OmniRoute/
├── src/                  # Next.js 16 பயன்பாடு (UI + API வழித்தடங்கள் + நூலகங்கள் + களம் + சேவையகம்)
├── open-sse/             # ஸ்ட்ரீமிங் எஞ்சின் பணியிடம் (கையாளிகள், செயல்படுத்திகள், மொழிபெயர்ப்பி, MCP சேவையகம்)
├── electron/             # டெஸ்க்டாப் உறை (Electron 41 + electron-builder 26.10)
├── bin/                  # CLI நுழைவுப் புள்ளி மற்றும் கட்டளைக் கையாளிகள்
├── scripts/              # உருவாக்கம், சரிபார்ப்பு, ஒத்திசைவு மற்றும் ஒருமுறைப் பயன்பாட்டு ஸ்கிரிப்ட்கள்
├── docs/                 # பொது ஆவணங்கள் (நீங்கள் இங்கே உள்ளீர்கள்)
├── tests/                # அனைத்து சோதனைத் தொகுப்புகளும் (அலகு, ஒருங்கிணைப்பு, e2e, நெறிமுறை கிளையண்டுகள்)
├── public/               # Next.js நிலையான வளங்கள், PWA மேனிஃபெஸ்ட், சேவைப் பணியாளர், ஐகான்கள்
├── config/               # நிலையான உள்ளமைவு + தரக் கட்டுப்பாட்டு நிலை (i18n, payloadRules, quality/)
├── images/               # சந்தைப்படுத்தல் / README பட வளங்கள்
├── @omniroute/           # வெளியிடக்கூடிய துணைத் தொகுப்புகள் (opencode-plugin, opencode-provider)
├── skills/               # CLI/முகவர் திறன் தொகுப்புகள் (cli-* + omni-* + config-codex-cli)
├── examples/             # மாதிரி செருகுநிரல்கள் + omniroute-cmd-hello தொடக்க வார்ப்புரு
├── contrib/              # சமூகப் பங்களிப்புகள் (podman/)
├── .source/              # Fumadocs மூல உள்ளமைவு (source.config.mjs + server/browser/dynamic)
├── .github/              # GitHub Actions பணிப்பாய்வுகள் + சிக்கல் வார்ப்புருக்கள் + PR வார்ப்புரு
├── .husky/               # Git கொக்கிகள் (pre-commit, pre-push)
├── .claude/              # Claude Code சாய்வுக்கோட்டுக் கட்டளைகள் (திட்ட வரம்புடையவை)
├── .agents/              # Codex / பொதுவான முகவர் பணிப்பாய்வுகள் + திறன்கள் (.claude/ இன் பிரதிநகல்)
├── .vscode/              # VS Code பணியிட அமைப்புகள்
├── _ideia/               # திட்டமிடல் குறிப்புகள் (முறைசாராதவை; விநியோகிக்கப்படுவதில்லை)
├── _mono_repo/           # வரலாற்றுத் துணைத்திட்டங்கள் (cloud, site, vscode-extension)
├── _references/          # தொடர்புடைய OSS திட்டங்களிலிருந்து படிக்க மட்டும் இயலும் குறிப்புப் பிரதிகள்
├── _tasks/               # ஒவ்வொரு வெளியீட்டிற்குமான பணிக் கண்காணிப்புக் கோப்புகள் (முறைசாராதவை)
├── .build/ .worktrees/ dist/   # உள்ளூர் உருவாக்கம் / git-worktree / உருவாக்க வெளியீட்டுக்கான தற்காலிகப் பகுதி (gitignored)
├── .issues/              # உள்ளூர் சிக்கல் இடைமாற்றகம் (gitignored)
├── .playwright-mcp/      # Playwright MCP சோதனைக் கலைப்பொருட்கள்
├── coverage/             # c8 சோதனை உள்ளடக்க வெளியீடு (gitignored)
├── logs/                 # இயக்கநேரப் பதிவுகள் (gitignored)
├── node_modules/         # சார்புகள் (gitignored)
├── package/              # npm pack தயார்நிலைப் பகுதி (உருவாக்கக் கலைப்பொருள்)
├── .next/                # Next.js உருவாக்க வெளியீடு (gitignored)
└── (மூலக் கோப்புகள் — கீழே காண்க)
```

## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — பிரதான tree-க்கு வெளியே

underscore முன்னொட்டு கொண்ட இந்த அடைவுகளில் வெளியீட்டில் சேராத உள்ளடக்கம் உள்ளது:

- **`_ideia/`** — வடிவமைப்புக் குறிப்புகள் (defer / notfit / viable வகைகள்)
- **`_mono_repo/`** — வரலாற்று துணைத்திட்டங்கள் (omnirouteCloud, omnirouteSite, vscode-extension)
- **`_references/`** — உருவாக்கத்தின்போது குறுக்கு மேற்கோளுக்காகத் தொடர்புடைய OSS திட்டங்களின் (LiteLLM, 9router, ClawRouter, CLIProxyAPI, modelrelay, new-api, போன்றவை) படிக்க-மட்டுமான clones
- **`_tasks/`** — ஒவ்வொரு release-க்குமான task கண்காணிப்புக் கோப்புகள் (முறைசாராதவை)

`npm pack` வெளியீட்டில் சேர்க்கப்படவில்லை. `.npmignore`-ஐப் பார்க்கவும்.
