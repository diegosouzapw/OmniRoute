> மறுபயன்படுத்தல் **இல்லாமல் OmniRoute-இன் நடத்தையை மாற்றும்** இயக்கநேர நிலைமாற்றிகள்.
> இங்கே பட்டியலிடப்பட்டுள்ள ஒவ்வொரு கொடியும்
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> கோப்பில் வரையறுக்கப்பட்டுள்ளது — இதுவே ஒற்றை உண்மை ஆதாரம். டாஷ்போர்டும் REST API-யும்
> அந்தக் கோப்பிலிருந்தே படிப்பதால், கீழேயுள்ள அட்டவணை அதனுடன் 1:1 பொருந்துமாறு உருவாக்கப்பட்டுள்ளது.

## அம்சக் கொடிகள் என்றால் என்ன

அம்சக் கொடி என்பது பெயரிடப்பட்ட நிலைமாற்றி (boolean அல்லது enum) ஆகும்; அதன் மதிப்பை
இயக்கநேரத்தில் மாற்றி தரவுத்தளத்தில் நிலைநிறுத்த முடியும், மேலும் செயல்முறையை மறுபயன்படுத்த
வேண்டியதில்லை. ஒவ்வொரு கொடியும் `key`, `label`, `description`, `category`,
`defaultValue`, `type` மற்றும் `requiresRestart` குறிப்பைக் கொண்ட
`FeatureFlagDefinition` மூலம் விவரிக்கப்படுகிறது.

### தீர்மான வரிசை

ஒரு கொடியின் **செயல்பாட்டு மதிப்பு**
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) மூலம் பின்வரும்
முன்னுரிமை வரிசையில் தீர்மானிக்கப்படுகிறது (அதிக முன்னுரிமை வெல்லும்):

1. **DB மேலெழுதுதல்** — `feature_flags` பெயர்வெளியின் கீழ் `key_value`
   அட்டவணையில் சேமிக்கப்பட்ட மதிப்பு (டாஷ்போர்டு அல்லது REST API வழியாக அமைக்கப்பட்டது).
2. **சூழல் மாறி** — அமைக்கப்பட்டு காலியாக இல்லாவிட்டால் `process.env[<KEY>]`.
3. **வரையறை இயல்புநிலை** — `featureFlagDefinitions.ts`-இலுள்ள `defaultValue`.

ஒரு boolean கொடியின் செயல்பாட்டு மதிப்பு `"true"`, `"1"` அல்லது `"yes"` ஆக இருந்தால்,
அது **இயக்கப்பட்டதாகக்** கருதப்படும் (`isFeatureFlagEnabled()`-ஐப் பார்க்கவும்).

> [!NOTE]
> பெரும்பாலான கொடிகளுக்கு [`ENVIRONMENT.md`](./ENVIRONMENT.md)-இல் ஆவணப்படுத்தப்பட்ட,
> **அதே பெயரைக்** கொண்ட பொருந்தும் சூழல் மாறியும் உள்ளது. கொடியின் DB மேலெழுதுதல்
> அந்தச் சூழல் மாறியைவிட முன்னுரிமை பெறுகிறது. `requiresRestart: true` கொண்ட ஒரு கொடி
> உடனடியாக நிலைநிறுத்தப்படும், ஆனால் செயல்முறை தொடக்கத்தின்போது மட்டுமே மீண்டும்
> படிக்கப்படும் — அதை மாற்றுவது டாஷ்போர்டில் **"சேவையகத்தை மறுதொடக்கம் செய்க"**
> பதாகையைக் காண்பிக்கும்.

> [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts)
> மூலம் படிக்கப்படும் சாதாரண சூழல் மாறிகள் மட்டுமே, feature flag-கள் அல்ல: அவற்றுக்கு DB மேலெழுதலும் dashboard மாற்றியும் இல்லை. பார்க்க:
> [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication).

> [!NOTE]
> `Restart` நெடுவரிசை `requiresRestart: true` கொண்ட flag-களைக் குறிக்கிறது — மதிப்பு
> உடனடியாகச் சேமிக்கப்படும், ஆனால் process மீண்டும் ஏற்றப்பட்ட பின்னரே அது செயல்படும். Enum
> flag-கள் அவற்றின் அனுமதிக்கப்பட்ட தொகுப்பிற்கு வெளியிலுள்ள எந்த மதிப்பையும் நிராகரிக்கும் (`setFeatureFlagOverride()` மற்றும் REST `PUT` handler ஆகிய இரண்டிலும் server பக்கத்தில் சரிபார்க்கப்படும்).

## கொடிகளை மாற்றுதல்

### கட்டுப்பாட்டுப் பலகம்

**கட்டுப்பாட்டுப் பலகம் → அமைப்புகள் → அம்சக் கொடிகள்** என்பதற்குச் செல்லவும்
(`/dashboard/settings/feature-flags`). கட்டம்
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
பின்வருவனவற்றை ஆதரிக்கிறது:

- விசை அல்லது விளக்கத்தின் அடிப்படையில் **தேடுதல்**, மற்றும் வகையின் அடிப்படையில் **வடிகட்டுதல்** (கூடுதலாக, செயற்கையாக உருவாக்கப்பட்ட
  **மறுதொடக்கம் தேவை** காட்சி).
- boolean கொடிகளுக்கான **மாற்றி** மற்றும் enum கொடிகளுக்கான **கீழ்தோன்றும் பட்டியல்**
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- ஒவ்வொரு கொடிக்கும் அதன் நடைமுறை மதிப்பு எங்கிருந்து வந்தது என்பதைக் காட்டும் **மூல அடையாளம்** — `DB`, `ENV`, அல்லது `DEF`.
- மேலெழுதலை நீக்குவதற்கான **மீட்டமை** பொத்தான் (`DB` மூலத்தைக் கொண்ட கொடிகளுக்கு மட்டும் காட்டப்படும்), மேலும் கீழ்ப்பகுதியில் **அனைத்து மேலெழுதல்களையும் மீட்டமை** பொத்தான்.
- `requiresRestart` கொடி மாற்றப்படும்போது **சேவையகத்தை மறுதொடக்கம் செய்க** பதாகை.

### REST API

அனைத்து செயல்பாடுகளும் ஒரே வழித்தடத்தின் மூலம் நடைபெறுகின்றன:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
ஒவ்வொரு முறைக்கும் அங்கீகரிக்கப்பட்ட கட்டுப்பாட்டுப் பலக அமர்வு தேவை (இல்லையெனில் `401`).

#### `GET /api/settings/feature-flags`

ஒவ்வொரு கொடியையும் அதன் நடைமுறை மதிப்பு, மூலம் மற்றும் சுருக்கத்துடன் வழங்குகிறது.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... மொத்தம் 75 கொடிகள்
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

ஒற்றை மேலெழுதலை அமைக்கிறது அல்லது நீக்குகிறது. கோரிக்கை உடல்: `{ key: string; value?: string }`.
`value` விடுபட்டால் மேலெழுதல் நீக்கப்படும் (env / இயல்புநிலை மீட்டமைக்கப்படும்).

```bash
# DB மேலெழுதலை அமைக்கவும்
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# மேலெழுதலை நீக்கவும் ("value" இல்லை)
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

பதில் புதிய `effectiveValue`/`source`, முந்தைய `previousValue`/
`previousSource`, மற்றும் `requiresRestart` ஆகியவற்றைத் திருப்பி வழங்குகிறது. அறியப்படாத விசைகளும் வரம்பிற்கு வெளியே உள்ள enum
மதிப்புகளும் `400` உடன் நிராகரிக்கப்படுகின்றன.

#### `DELETE /api/settings/feature-flags`

அனைத்து DB மேலெழுதல்களையும் ஒரே நேரத்தில் அழித்து, ஒவ்வொரு கொடியையும் அதன் env / இயல்புநிலை
மதிப்பிற்கு மீட்டமைக்கிறது. `{ cleared: <count>, message: "..." }` என்பதை வழங்குகிறது.

> [!NOTE]
> `requiresRestart: true` கொண்ட கொடிகள் செயல்முறை மீண்டும் ஏற்றப்பட்ட பின்னரே நடைமுறைக்கு வரும்.
> கட்டுப்பாட்டுப் பலகத்தின் மறுதொடக்கச் செயல்முறை `POST /api/restart`-ஐ அழைத்து, பின்னர் சேவையகம் மீண்டும் இயங்கும் வரை
> `GET /api/health/ping`-ஐத் தொடர்ந்து வினவுகிறது.

## அவசர செலவுத்திட்ட மாற்றுவழி

`OMNIROUTE_EMERGENCY_FALLBACK` (`runtime` வகை, இயல்புநிலை `true`) என்பது
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)
இல் உள்ள அவசர இலவச மாற்றுவழியை நிர்வகிக்கிறது.
இது இயக்கப்பட்டிருக்கும்போது, தங்கள் செலவுத்திட்டத்தை முழுமையாகப் பயன்படுத்திவிட்ட கோரிக்கைகள் நேரடியாகத் தோல்வியடைவதற்குப் பதிலாக ஓர் இலவச மாற்று
வழங்குநர்/மாதிரிக்கு அனுப்பப்படுகின்றன. இந்த நடத்தையை முடக்கி, செலவுத்திட்டத்தை முழுமையாகப் பயன்படுத்திவிட்ட கோரிக்கைகள்
தோல்வியடைய அனுமதிக்க, இதை `false` (அல்லது `0`) என அமைக்கவும் — கட்டுப்பாட்டுப் பலக நிலைமாற்றி, DB மீறல், அல்லது
`OMNIROUTE_EMERGENCY_FALLBACK` சூழல் மாறி வழியாக இதைச் செய்யலாம்.
(PRகள் #3741 / #3752 இல் கட்டுப்பாட்டுப் பலக நிலைமாற்றியாக வெளிப்படுத்தப்பட்டது.)
