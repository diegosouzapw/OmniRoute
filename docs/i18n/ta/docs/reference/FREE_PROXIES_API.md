OmniRoute, வெளிப்புற வழங்குநர்களிலிருந்து (1proxy, proxifly, iplocate, webshare) ஒத்திசைக்கப்பட்ட,
தேர்ந்தெடுக்கப்பட்ட இலவச ப்ராக்ஸிகளின் தொகுப்பை `free_proxies` அட்டவணையில் வழங்குகிறது.
டாஷ்போர்டு இவற்றை **Settings → Free Proxies** என்பதன் கீழ் காட்டுகிறது. பட்டியல் வழித்தடம்
வழங்கும் சேவையகப் பக்க வடிகட்டல், வரிசைப்படுத்தல், எண்ணிக்கை கணக்கிடுதல் மற்றும் ஒத்திசைவுப் பிழை அறிக்கையிடல்
ஆகியவற்றை இந்த ஆவணம் விளக்குகிறது.

## பட்டியல் வழித்தடம் — `GET /api/settings/free-proxies`

வடிகட்டப்பட்ட, வரிசைப்படுத்தப்பட்ட, பக்கங்களாகப் பிரிக்கப்பட்ட ஒரு பகுதியையும் மொத்த எண்ணிக்கையையும் வழங்குகிறது. வடிகட்டலும்
எண்ணிக்கை கணக்கிடுதலும் SQL-இல் நடைபெறுவதால், ஒவ்வொரு வரியையும் நினைவகத்தில் ஏற்றாமல்
உண்மையான மொத்தத்தை (எ.கா. `Total: 0`) UI காட்ட முடியும்.

### வினவல் அளவுருக்கள்

| அளவுரு            | வகை                                | இயல்புநிலை | பொருள்                                                                                                                          |
| ----------------- | ---------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | சரம்                               | `""`       | ஹோஸ்ட் (மற்றும் source) நெடுவரிசையில் பேரெழுத்து-சிற்றெழுத்து உணர்திறனுள்ள `LIKE`.                                              |
| `protocol`        | சரம்                               | `""`       | `type` வடிகட்டி: `http` / `https` / `socks4` / `socks5`. காலியாக இருந்தால் = அனைத்தும்.                                         |
| `country`         | சரம்                               | `""`       | `countryCode` வடிகட்டி (ISO-2). காலியாக இருந்தால் = அனைத்தும்.                                                                  |
| `minQuality`      | எண்                                | `0`        | `qualityScore >= minQuality` உள்ள வரிகள் மட்டும். `0` = குறைந்தபட்ச வரம்பு இல்லை.                                               |
| `disabledSources` | சரம்                               | `""`       | விலக்க வேண்டிய காற்புள்ளியால் பிரிக்கப்பட்ட source id-கள் (எ.கா. `proxifly,webshare`).                                          |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`  | `quality` = மதிப்பெண் இறங்கு வரிசை; `latency` = தாமதம் ஏறு வரிசை (null-கள் இறுதியில்); `recent` = `lastValidated` இறங்கு வரிசை. |
| `offset`          | எண்                                | `0`        | பக்கமாக்கல் தொடக்கம்.                                                                                                           |
| `limit`           | எண்                                | `50`       | பக்க அளவு (சேவையகப் பக்கத்தில் வரம்பிடப்படும்).                                                                                 |

### பதில்

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["மேல்நிலைச் சேவையிலிருந்து HTTP 429"],
    "webshare": ["பிணைய நேர முடிவு"]
  }
}
```

`total` என்பது பக்கமாக்கலுக்கு **முன்னர்** வடிகட்டப்பட்ட மொத்தத்தைக் குறிக்கிறது; எனவே UI,
`Total: N` மற்றும் `hasMore` ஆகியவற்றைத் தனித்தனியாகக் காட்ட முடியும். `syncErrors` என்பது source id-ஐ
விசையாகக் கொண்டிருக்கும் மற்றும் கடைசி ஒத்திசைவு தோல்வியடைந்த source-களுக்கு மட்டுமே நிரப்பப்படும் — ஒரு `Total: 0` முடிவு
ஒருபோதும் விளக்கமின்றி இருக்காது.

## தொகுப்பில் சேர்த்தல் — `POST /api/settings/free-proxies/[id]/add-to-pool`

ஒரு இலவச ப்ராக்ஸியை நிர்வகிக்கப்படும் `proxy_registry` தொகுப்பிற்கு உயர்த்துகிறது. முதலில்
மேல்நிலைச் சேவையைச் சரிபார்க்கிறது; வெற்றியடைந்தால் புதிய தொகுப்பு ப்ராக்ஸியின் id மற்றும் அளவிடப்பட்ட தாமதத்தை வழங்குகிறது.

## ஒத்திசைவு — `POST /api/settings/free-proxies/sync`

செயல்படுத்தப்பட்ட அனைத்து source-களையும் (அல்லது `{ "sources": [...] }` என்பதில் உள்ள துணைத்தொகுப்பை) மீண்டும் பெறுகிறது. ஒவ்வொரு
source-ம் தனித்தனியாக ஒத்திசைக்கப்படுகிறது; தோல்வியடையும் source, `syncErrors`-இல் பதிவு செய்யப்படும், மேலும்
மற்றவை தொடர்ந்து நிறைவடையும். இதனால் பகுதியளவு ஒத்திசைவுகள் முன்பிருந்த சரியான தரவை ஒருபோதும் அழிக்காது.

## புள்ளிவிவரங்கள் — `GET /api/settings/free-proxies/stats`

வரி தரவுகள் இல்லாமல் `total / inPool / avgQuality / bySource / lastSyncAt` ஒருங்கிணைப்பை
வழங்குகிறது — இது டாஷ்போர்டு தலைப்புப் பகுதியிலுள்ள விட்ஜெட்களால் பயன்படுத்தப்படுகிறது.
