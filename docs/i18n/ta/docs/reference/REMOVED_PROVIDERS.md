சில சேவைகள் OmniRoute-இல் ஒருங்கிணைக்கப்பட்டு, பின்னர் அவற்றை இயக்கும் நபர்கள் கேட்டுக்கொண்டதால் அகற்றப்பட்டன. அந்த அகற்றல்களின் நிலையான பதிவே இந்தப் பக்கம். அவை தவறுதலாக மீண்டும் சேர்க்கப்படுவதைத் தடுப்பது மட்டுமே இதன் நோக்கம்: பழைய fork, cache செய்யப்பட்ட npm tarball, காப்பகப்படுத்தப்பட்ட issue அல்லது "provider X-ஐ மீட்டமை" என்ற கோரிக்கையைக் கண்டறியும் பங்களிப்பாளருக்கு **மீண்டும் அறிமுகப்படுத்த வேண்டாம்** என்று குறிப்பிடும் ஒரே இடம் தேவை.

இந்தப் பக்கம் செயலிழந்த அல்லது நிறுத்தப்பட்ட சேவைகளின் பட்டியல் **அல்ல**. அவை
[`FREE_TIERS.md`](FREE_TIERS.md) ("அகற்றப்பட்டது / இலவச அடுக்கு இல்லை") என்பதில் கண்காணிக்கப்படுகின்றன; சேவை மீண்டும் செயல்பட்டால் அவையும் மீண்டும் சேர்க்கப்படலாம். கீழேயுள்ள பதிவுகள், கோரிக்கையில் குறிப்பிடப்பட்டுள்ள சேவை இயக்குநரிடமிருந்து எழுத்துப்பூர்வ அனுமதி கிடைத்தால் மட்டுமே மீண்டும் சேர்க்கப்படலாம்; அந்த அனுமதிக்கான இணைப்பு பதிவில் சேர்க்கப்பட வேண்டும்.

## கொள்கை

1. **சேவை இயக்குநரிடமிருந்து வரும் அகற்றல் கோரிக்கை ஏற்றுக்கொள்ளப்படும்; பேரம் பேசப்படாது.** OmniRoute எந்த upstream சேவையுடனும் இணைக்கப்பட்டதல்ல. ஒரு சேவையின் இயக்குநர் அதன் ஒருங்கிணைப்பை அகற்றுமாறு கேட்டால், அந்த ஒருங்கிணைப்பு அதிகாரப்பூர்வ API-ஐப் பயன்படுத்தியிருந்தாலும் இல்லாவிட்டாலும், அது அகற்றப்படும்.
2. **"அகற்றப்பட்டது" என்பது OmniRoute கட்டுப்படுத்தும் ஒவ்வொரு பரப்பையும் குறிக்கும்.** Executor, registry பதிவு, provider id மற்றும் alias, model பட்டியல், endpoints, environment variables, icon, dashboard cards, உருவாக்கப்பட்ட provider reference, `FREE_TIERS.md`, environment reference, README எண்ணிக்கைகள், `llm.txt` பிரதிகள், பிரத்யேக tests மற்றும் golden snapshots, code comments, CHANGELOG bullets (பதிவுசெய்யப்பட்ட reconciliation உடன்; `config/release/changelog-reconciliations.json`-ஐப் பார்க்கவும்), GitHub Releases குறிப்புகள், wiki மற்றும் அந்த provider-ஐப் பொருளாகக் கொண்ட GitHub issues, discussions மற்றும் pull requests (issues மற்றும் discussions நீக்கப்படும்; GitHub-இல் pull requests-ஐ நீக்க முடியாததால், pull requests-இன் தலைப்பு மாற்றப்பட்டு, அவற்றின் விளக்கம் மாற்றீடு செய்யப்பட்டு, thread பூட்டப்படும்).
3. **எழுத்துப்பூர்வ அனுமதி இல்லாமல் இந்தப் பக்கத்திலுள்ள எந்தப் பதிவையும் ஒருபோதும் மீண்டும் அறிமுகப்படுத்த வேண்டாம்.** எந்த provider catalog-இலும் id அல்லது alias-ஐ மீண்டும் சேர்ப்பது, domains-ஐ executor-இல் சேர்ப்பது, அதை "மீட்டமைக்கும்" பங்களிப்பாளர் PR-ஐ ஏற்றுக்கொள்வது, free-model catalog-இல் சேர்ப்பது அல்லது OmniRoute வழியாக அதை அணுகுவதற்கான கைமுறை வழியை ஆவணப்படுத்துவது ஆகியவையும் இதில் அடங்கும். அத்தகைய PRs மற்றும் issues-ஐ இந்தப் பக்கத்திற்கான இணைப்புடன் மூடவும்.
4. **பதிவை குறைந்தபட்சமாக வைத்திருக்கவும்.** மீண்டும் அறிமுகப்படுத்தப்பட்டதை ஒரு மதிப்பாய்வாளர் அடையாளம் காணத் தேவையானவற்றை மட்டும் பதிவுசெய்யவும்: identifiers, domains, dates மற்றும் அகற்றலைச் செய்த pull request. ஒருங்கிணைப்பு எவ்வாறு செயல்பட்டது என்பதை விவரிக்க வேண்டாம்.
5. **Regression guard என்பது `tests/unit/removed-providers-blocklist.test.ts`.** கீழேயுள்ள identifier அல்லது domain ஏதேனும் provider catalogs, executor map அல்லது provider registry sources-இல் மீண்டும் தோன்றினால் இது தோல்வியடையும். இங்கே ஒரு row-ஐச் சேர்க்கும் அதே PR-இல் புதிய identifiers-ஐ அந்த test-இல் சேர்க்கவும்.

## பதிவைச் சேர்த்தல்

புதிய அகற்றல் கோரிக்கை வரும்போது:

1. கோரிக்கை அந்தச் சேவையின் இயக்குநரிடமிருந்து வந்ததா என்பதை உறுதிப்படுத்தவும் (அவர்களது support address அல்லது அவர்கள் கட்டுப்படுத்தும் domain மூலம்); மேலும் அந்தச் செய்தியைத் தனிப்பட்ட முறையில் பாதுகாத்து வைத்திருக்கவும்.
2. கொள்கையின் உருப்படி 2-இல் உள்ள checklist-ஐப் பின்பற்றி ஒருங்கிணைப்பை அகற்றவும். Keyless provider-க்கான எடுத்துக்காட்டாக [#12440](https://github.com/diegosouzapw/OmniRoute/pull/12440)-ஐயும், சேமிக்கப்பட்ட connections கொண்ட API-key provider-க்கான எடுத்துக்காட்டாக [#10210](https://github.com/diegosouzapw/OmniRoute/pull/10210)-ஐயும் பயன்படுத்தவும் (ஒரு migration-ஐச் சேர்க்கவும்).
3. அதே PR-இல் மேலேயுள்ள table-இல் ஒரு row-ஐயும், identifiers-ஐ
   `tests/unit/removed-providers-blocklist.test.ts`-இலும் சேர்க்கவும்.
4. PR merge செய்யப்பட்டதும் இயக்குநருக்குப் பதிலளித்து, அகற்றப்பட்டவற்றையும் OmniRoute-ஆல் மாற்ற முடியாதவற்றையும் பட்டியலிடவும் (ஏற்கனவே வெளியிடப்பட்ட npm மற்றும் Docker versions, git history, third-party forks).
