சில சேவைகள் OmniRoute இல் ஒருங்கிணைக்கப்பட்டு, பின்னர் அவற்றை இயக்கும் நபர்கள் கேட்டுக் கொண்டதால் அகற்றப்பட்டன. இந்த பக்கம் அந்த நீக்கங்களின் நீடித்த பதிவு. அதன் ஒரே நோக்கம், அவை தற்செயலாக மீண்டும் வருவதைத் தடுப்பதாகும்: ஒரு பழைய ஃபோர்க், ஒரு தற்காலிக npm டார்பால், ஒரு காப்பகப்படுத்தப்பட்ட சிக்கல் அல்லது " வழங்குநர் X ஐ மீட்டமை" கோரிக்கையை கண்டுபிடிக்கும் ஒரு பங்களிப்பாளருக்கு **மீண்டும் அறிமுகப்படுத்த வேண்டாம்** என்று கூறும் ஒரு இடம் தேவை.

இந்த பக்கம் இறந்த அல்லது நிறுத்தப்பட்ட சேவைகளின் பட்டியல் **அல்ல**. அவை [`FREE_TIERS.md`](FREE_TIERS.md) ("அகற்றப்பட்டது / இலவச அடுக்கு இல்லை") இல் கண்காணிக்கப்படுகின்றன, மேலும் சேவை இருந்தால் மீண்டும் வரலாம். கீழே உள்ள உள்ளீடுகள் கோரிக்கையில் குறிப்பிடப்பட்டுள்ள ஆபரேட்டரின் எழுத்துப்பூர்வ அனுமதியுடன் மட்டுமே மீண்டும் வர முடியும், மேலும் அந்த அனுமதி உள்ளீட்டிலிருந்து இணைக்கப்பட வேண்டும்.

## கொள்கை

1. **ஒரு சேவை ஆபரேட்டரிடமிருந்து ஒரு நீக்குதல் கோரிக்கை மதிக்கப்படுகிறது, பேச்சுவார்த்தை நடத்தப்படுவதில்லை.** OmniRoute எந்த மேல்நிலை சேவையுடனும் இணைக்கப்படவில்லை. ஒரு சேவையின் ஆபரேட்டர் ஒருங்கிணைப்பு செல்லும்படி கேட்டால், அது செல்கிறது, ஒருங்கிணைப்பு ஒரு அதிகாரப்பூர்வ API ஐப் பயன்படுத்தினாலும் இல்லாவிட்டாலும்.
2. **"அகற்றப்பட்டது" என்பது OmniRoute கட்டுப்படுத்தும் ஒவ்வொரு மேற்பரப்பையும் குறிக்கிறது.** எக்ஸிகியூட்டர், பதிவேட்டில் உள்ளீடு, வழங்குநர் ஐடி மற்றும் மாற்றுப்பெயர், மாதிரி பட்டியல், இறுதிப்புள்ளிகள், சுற்றுச்சூழல் மாறிகள், ஐகான், டாஷ்போர்டு கார்டுகள், உருவாக்கப்பட்ட வழங்குநர் குறிப்பு, `FREE_TIERS.md`, சுற்றுச்சூழல் குறிப்பு, README எண்ணிக்கைகள், `llm.txt` கண்ணாடிகள், பிரத்யேக சோதனைகள் மற்றும் கோல்டன் ஸ்னாப்ஷாட்கள், குறியீடு கருத்துகள், CHANGELOG புல்லட்டுகள் (ஒரு லெட்ஜர் செய்யப்பட்ட சமரசத்துடன், `config/release/changelog-reconciliations.json` ஐப் பார்க்கவும்), GitHub வெளியீட்டு குறிப்புகள், விக்கி, மற்றும் GitHub சிக்கல்கள், விவாதங்கள் மற்றும் புல் கோரிக்கைகள் அதன் பொருள் அந்த வழங்குநர் (சிக்கல்கள் மற்றும் விவாதங்கள் நீக்கப்பட்டன; புல் கோரிக்கைகள் மறுபெயரிடப்பட்டன, அவற்றின் விளக்கம் மாற்றப்பட்டு நூல் பூட்டப்பட்டது, ஏனெனில் GitHub புல் கோரிக்கைகளை நீக்க முடியாது).
3. **இந்த பக்கத்தில் உள்ள ஒரு உள்ளீட்டை எழுத்துப்பூர்வ அனுமதி இல்லாமல் ஒருபோதும் மீண்டும் அறிமுகப்படுத்த வேண்டாம்.** இதில் எந்த வழங்குநர் பட்டியலிலும் ஐடி அல்லது மாற்றுப்பெயரை மீண்டும் சேர்ப்பது, ஒரு எக்ஸிகியூட்டருக்கு டொமைன்களைச் சேர்ப்பது, அதை "மீட்டெடுக்கும்" ஒரு பங்களிப்பாளர் PR ஐ ஏற்றுக்கொள்வது, அதை இலவச மாதிரி பட்டியலில் சேர்ப்பது அல்லது OmniRoute வழியாக அதை அடைய ஒரு கையேடு வழியை ஆவணப்படுத்துவது ஆகியவை அடங்கும். அத்தகைய PRகள் மற்றும் சிக்கல்களை இந்த பக்கத்திற்கான இணைப்புடன் மூடவும்.
4. **உள்ளீட்டை குறைந்தபட்சமாக வைத்திருங்கள்.** ஒரு மறு அறிமுகத்தை அங்கீகரிக்க ஒரு மதிப்பாய்வாளருக்குத் தேவையானவற்றை மட்டுமே பதிவு செய்யவும்: அடையாளங்காட்டிகள், டொமைன்கள், தேதிகள் மற்றும் நீக்கத்தை செய்த புல் கோரிக்கை. ஒருங்கிணைப்பு எவ்வாறு செயல்பட்டது என்பதை விவரிக்க வேண்டாம்.
5. **பின்னடைவு பாதுகாப்பு `tests/unit/removed-providers-blocklist.test.ts` ஆகும்.** வழங்குநர் பட்டியல்கள், எக்ஸிகியூட்டர் வரைபடம் அல்லது வழங்குநர் பதிவேட்டில் உள்ள மூலங்களில் கீழே உள்ள எந்த அடையாளங்காட்டி அல்லது டொமைனும் மீண்டும் தோன்றும்போது அது தோல்வியடைகிறது. இங்கே ஒரு வரிசையைச் சேர்க்கும் அதே PR இல் அந்த சோதனைக்கு புதிய அடையாளங்காட்டிகளைச் சேர்க்கவும்.

## ஒரு பதிவைச் சேர்த்தல்

புதிய டேவ்டவுன் (takedown) கோரிக்கை வரும்போது:

1. கோரிக்கையானது சேவையின் இயக்குநரிடமிருந்து (அவர்களின் ஆதரவு முகவரி அல்லது அவர்கள் கட்டுப்படுத்தும் டொமைன்) வந்ததா என்பதை உறுதிசெய்து, செய்தியை தனிப்பட்ட முறையில் வைத்துக் கொள்ளவும்.
2. கொள்கை உருப்படி 2-ல் உள்ள சரிபார்ப்புப் பட்டியலின்படி ஒருங்கிணைப்பை அகற்றவும். கீலெஸ் (keyless) வழங்குநருக்குச் சான்றாக [#12440](https://github.com/diegosouzapw/OmniRoute/pull/12440)-ஐயும், சேமிக்கப்பட்ட இணைப்புகளைக் கொண்ட API-கீ வழங்குநருக்கு [#10210](https://github.com/diegosouzapw/OmniRoute/pull/10210)-ஐயும் பயன்படுத்தவும் (ஒரு மைக்ரேஷனைச் சேர்க்கவும்).
3. மேலே உள்ள அட்டவணையில் ஒரு வரிசையையும், அடையாளங்காட்டிகளை `tests/unit/removed-providers-blocklist.test.ts`-லும் ஒரே PR-ல் சேர்க்கவும்.
4. PR இணைக்கப்பட்டதும் இயக்குநருக்குப் பதிலளிக்கவும், அதில் என்ன அகற்றப்பட்டது மற்றும் OmniRoute-ஆல் எதை மாற்ற முடியாது (ஏற்கனவே வெளியிடப்பட்ட npm மற்றும் Docker பதிப்புகள், git வரலாறு, மூன்றாம் தரப்பு ஃபோர்க்குகள்) என்பதைப் பட்டியலிடவும்.
