## வகைகள்

- **இலவசம்** — API விசையுடன் கூடிய இலவச அடுக்கு (டாஷ்போர்டு வழியாக உள்ளமைக்கப்படுகிறது)
- **அங்கீகாரம் தேவையில்லை** — விசையோ உள்நுழைவோ தேவையில்லாத பொது இறுதிப்புள்ளிகள்
- **OAuth** — உள்நுழைவு செயல்முறை OmniRoute மூலம் கையாளப்படுகிறது; API விசை தேவையில்லை
- **வலை குக்கீ** — குக்கீ அங்கீகாரம் மூலம் வழங்குநரின் வலைச் செயலியைச் சுற்றுப்பொதிகிறது
- **API விசை** — API விசை மூலம் உள்ளமைக்கப்படும் கட்டண வழங்குநர் (இலவச கிரெடிட்கள் பொருந்தக்கூடும்)
- **உள்ளகம்** — பயனரின் கணினியில் இயங்குகிறது (Ollama, LM Studio, vLLM போன்றவை)
- **தேடல்** — இணையத் தேடல் வழங்குநர்கள்
- **ஆடியோ** — ஆடியோ மட்டும் வழங்கும் வழங்குநர்கள் (TTS/STT)
- **அப்ஸ்ட்ரீம் ப்ராக்ஸி** — பிற வழங்குநர்களுக்குப் ப்ராக்ஸியாகச் செயல்படும் வழங்குநர்கள்
- **கிளவுட் முகவர்** — நீண்ட நேரம் இயங்கும் குறியீட்டாக்க முகவர்கள் (Codex Cloud, Devin, Jules)
- **அமைப்பு** — OmniRoute-இன் உள் வழங்குநர்கள் (loopback போன்றவை)

கூடுதல் குறிச்சொற்கள்: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`கருவி அழைப்பு` (காட்டப்படும் இடங்களில்): `native` — உண்மையான செயல்பாடு-அழைப்பு API; `emulated` — `tools` வரிசை `webTools.ts` வழியாக ப்ராம்ப்ட் முறையில் பாவனை செய்யப்படுகிறது (regex மூலம் பகுக்கப்படும் `<tool>{...}</tool>` தொகுதிகள்); `none` — தற்போது `tools` எந்த அறிவிப்புமின்றி கைவிடப்படுகிறது. #7286-ஐப் பார்க்கவும்.

ஒவ்வொரு வழங்குநரையும் இயக்க, உள்ளமைக்க மற்றும் சோதிக்க `/dashboard/providers` இல் உள்ள டாஷ்போர்டைப் பயன்படுத்தவும்.
