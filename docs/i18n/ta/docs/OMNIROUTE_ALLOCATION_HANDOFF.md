ஒதுக்கீடு என்பது வழங்குநர் ஒதுக்கீட்டு வரம்பு அல்ல.

ஒதுக்கீட்டு வரம்புத் தொகுப்புகள் எந்த API விசைகள் ஒரு வழங்குநர் தொகுப்பைப் பயன்படுத்தலாம் என்பதையும், கடுமையான, மென்மையான அல்லது திடீர் அதிகரிப்பு கொள்கைகள் எவ்வாறு செயல்படுத்தப்படுகின்றன என்பதையும் வரையறுக்கின்றன. வழங்குநர் ஒதுக்கீட்டு வரம்பு என்பது ஒரு வழங்குநரால் தெரிவிக்கப்படும் வெளிப்புறத் திறன் அல்லது வெளிப்படையாக உள்ளமைக்கப்பட்ட மூலத்திலிருந்து பெறப்படும் திறன் ஆகும். Ghostlight-இன் உள் செலவுத்திட்டங்கள் நிர்வாகியால் வரையறுக்கப்பட்ட ஆளுகை வரம்புகள் ஆகும்.

`ensurePool` செயல்பாடு ஒரேவிளைவுடையது: ஒரே மாதிரியான தொகுப்பு மாற்றமின்றி இருக்கும், மாற்றப்பட்ட ஒதுக்கீடு புதுப்பிக்கப்படும், இல்லாத தொகுப்பு உருவாக்கப்படும். இது தானியக்கத்திற்கும் வரம்புக்குட்பட்ட API அழைப்பாளர்களுக்கும் வடிவமைக்கப்பட்டுள்ளது.

வாசிப்பதற்கு மட்டுமான நிலை இறுதிப்புள்ளி `GET /api/omniroute/status` ஆகும். சரிபார்ப்புக் கட்டளை `npm run omniroute:verify`; இது நேரடி மாதிரிக் கோரிக்கை எதையும் மேற்கொள்ளாது.
