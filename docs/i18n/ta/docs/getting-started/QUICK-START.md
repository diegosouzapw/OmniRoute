## படி 1: OmniRoute-ஐ நிறுவுதல்

நீங்கள் விரும்பும் முறையைத் தேர்ந்தெடுக்கவும்:

### விருப்பம் A: npm (பரிந்துரைக்கப்படுகிறது)

```bash
npm install -g omniroute
```

### விருப்பம் B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` என்பது **வெளியிடப்பட்டுள்ளவற்றில்** மிக உயர்ந்த நிலையான SemVer ஆகும். இது git `main`-ஐப் பின்தொடராது. GitOps-க்கு `diegosouzapw/omniroute:X.Y.Z` என்பதைப் பதிப்புடன் நிலைநிறுத்தவும். [படக் குறிச்சொற்கள் / வெளியீட்டுச் சேனல்கள்](../guides/DOCKER_GUIDE.md#release-channels) என்பதைப் பார்க்கவும்.

### விருப்பம் C: மூலக் குறியீட்டிலிருந்து

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

## படி 2: OmniRoute-ஐத் தொடங்குதல்

```bash
omniroute
```

OmniRoute `http://localhost:20128` முகவரியில் தொடங்கும். கட்டுப்பாட்டுப் பலகம் தானாகத் திறக்கும்.

## படி 3: இலவச வழங்குநரை இணைத்தல்

இலவச வழங்குநரை இணைப்பதன் மூலம் OmniRoute-ஐ **எந்தக் கட்டணமும் செலுத்தாமல்** பயன்படுத்தலாம்.

### விருப்பம் A: Kiro (இலவச Claude — கடன் அட்டை தேவையில்லை)

1. `http://localhost:20128` முகவரியில் கட்டுப்பாட்டுப் பலகத்தைத் திறக்கவும்
2. **வழங்குநர்கள்** → **வழங்குநரைச் சேர்** என்பதற்குச் செல்லவும்
3. **Kiro AI** என்பதைத் தேர்ந்தெடுக்கவும்
4. **இணை** என்பதைக் கிளிக் செய்யவும் (API விசை தேவையில்லை!)
5. முடிந்தது! இப்போது Claude மாதிரிகளை இலவசமாக அணுகலாம்.

### விருப்பம் B: OpenCode Free (அங்கீகாரம் தேவையில்லை)

1. `http://localhost:20128` முகவரியில் கட்டுப்பாட்டுப் பலகத்தைத் திறக்கவும்
2. **வழங்குநர்கள்** → **வழங்குநரைச் சேர்** என்பதற்குச் செல்லவும்
3. **OpenCode Free** என்பதைத் தேர்ந்தெடுக்கவும்
4. **இணை** என்பதைக் கிளிக் செய்யவும் (API விசை தேவையில்லை!)
5. முடிந்தது! இப்போது பல மாதிரிகளை இலவசமாக அணுகலாம்.

### விருப்பம் C: Pollinations (விசை தேவையில்லை)

1. `http://localhost:20128` முகவரியில் கட்டுப்பாட்டுப் பலகத்தைத் திறக்கவும்
2. **வழங்குநர்கள்** → **வழங்குநரைச் சேர்** என்பதற்குச் செல்லவும்
3. **Pollinations** என்பதைத் தேர்ந்தெடுக்கவும்
4. **இணை** என்பதைக் கிளிக் செய்யவும் (API விசை தேவையில்லை!)
5. முடிந்தது! இப்போது GPT-5, Claude, Gemini மற்றும் பலவற்றை இலவசமாக அணுகலாம்.

## படி 4: இது செயல்படுகிறதா என்பதைச் சரிபார்த்தல்

[API விசைகள்](http://localhost:20128/dashboard/api-manager) பக்கத்திலிருந்து புதிய விசை ஒன்றை உருவாக்கவும். இந்த விசை மீண்டும் காண்பிக்கப்படாது என்பதால் அதைப் பாதுகாப்பாகச் சேமிக்கவும். இந்த விசை கருவிகள் OmniRoute-ஐ அணுகுவதற்கானது; மேல்நிலை வழங்குநர்களை அணுகுவதற்கானது அல்ல என்பதை நினைவில் கொள்ளவும்.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

நீங்கள் இணைத்த மாதிரிகள் பட்டியலிடப்பட்டிருப்பதைக் காண வேண்டும்.

## படி 5: உங்கள் IDE அல்லது CLI-ஐ OmniRoute-க்குச் சுட்டிக்காட்டுதல்

உங்கள் IDE அல்லது CLI கருவியில் பின்வருவனவற்றை அமைக்கவும்:

```
அடிப்படை URL: http://localhost:20128/v1
API விசை:     [கட்டுப்பாட்டுப் பலகம் → இறுதிப்புள்ளிகளிலிருந்து நகலெடுக்கவும்]
மாதிரி:       auto
```

அவ்வளவுதான்! இப்போது உங்கள் IDE, வழங்குநரைத் தானாகத் தேர்ந்தெடுக்கும் வசதியுடன் OmniRoute-ஐப் பயன்படுத்துகிறது.

### IDE எடுத்துக்காட்டு: VSCode/Continue.dev

1. VSCode-இல் [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) நீட்சியை நிறுவவும்.
2. பின்வரும் வரிகளைச் சேர்க்க உங்கள் `~/.continue/config.yaml` கோப்பைப் புதுப்பிக்கவும்:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev அரட்டைப் பலகத்தில் `OmniRoute - Auto` என்பதைத் தேர்ந்தெடுக்கவும்; அதன் பிறகு கோரிக்கைகள் OmniRoute-க்கு அனுப்பப்படும்.
4. (விருப்பத்தேர்வு) வாசகருக்கான பயிற்சி — முன்பே உருவாக்கப்பட்டுள்ள மற்ற அனைத்து உள்ளமைவுகளுடனும் `config.yaml` கோப்பை உங்கள் IDE மூலம் புதுப்பிக்கச் செய்யுங்கள் 😊

### CLI எடுத்துக்காட்டு: Codex CLI

1. உங்கள் இயக்க முறைமையில் சூழல் மாறியை நிரந்தரமாக அமைக்கவும்.
   macOS/Linux-க்கு (உங்கள் `~/.bashrc` அல்லது `~/.zshrc` கோப்பில் சேர்க்கவும்):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows-க்கு (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. இப்போது OmniRoute-க்காக உள்ளமைக்கப்பட்ட Codex-ஐத் தொடங்குவோம். இதை இயக்கவும்:

```
omniroute launch-codex --model auto
```

இறுதிப்புள்ளி மற்றும் API விசையைக் குறிப்பிடும் கட்டளைவரி அளவுருக்களுடன் `codex` வழியாக இதைக் கைமுறையாகச் செய்யலாம்; ஆனால் மேலே உள்ள கட்டளையைப் பயன்படுத்தினால், OmniRoute உங்களுக்காக அனைத்தையும் கவனித்துக்கொள்ளும்.

இதே ஒற்றைக் கட்டளைத் தொடக்கம் பொதுவான தொடக்கியான `omniroute run <target>` வழியாக மற்ற CLI-களுக்கும் செயல்படும் — இது `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` மற்றும் `gemini` ஆகியவற்றை ஆதரிக்கிறது ([CLI ஒருங்கிணைப்புகள்](../guides/CLI-INTEGRATIONS.md) என்பதைப் பார்க்கவும்).

3. இப்போது CLI, OmniRoute-க்கு கோரிக்கைகளை அனுப்பிக்கொண்டிருக்க வேண்டும்.

### உங்கள் கருவி OmniRoute வழியாக கோரிக்கைகளை அனுப்புகிறதா என்பதை உறுதிப்படுத்துதல்

இடப்பக்கப் பக்கப்பட்டியிலிருந்து [கண்காணிப்பு/பதிவுகள்](http://localhost:20128/dashboard/logs) என்பதைக் கிளிக் செய்வதன் மூலம் கோரிக்கையின் விவரங்களைக் காணலாம். தொடர்ந்து கிளிக் செய்தால் மேலும் பல விவரங்களைக் காணலாம். கூடுதல் தகவலாக, உங்களுக்கு விருப்பமான இயக்கக் கட்டமைப்பிலிருந்து எந்தத் தகவல்கள் மேல்நிலைக்கு அனுப்பப்படுகின்றன என்பதையும் காணலாம். கற்றல் மற்றும் பிழைத்திருத்தக் கண்ணோட்டத்தில் இது பயனுள்ளதாக இருக்கும்.

## பொதுவான கேள்விகள்

### "எனக்கு API விசை தேவையா?"

**இல்லை!** எந்த API விசையும் இல்லாமல் இலவச வழங்குநர்களை (Kiro, OpenCode Free, Pollinations) பயன்படுத்தலாம். கட்டுப்பாட்டுப் பலகத்தில் அவற்றை இணைத்தால் போதும்.

### "`auto` என்றால் என்ன?"

ஒவ்வொரு கோரிக்கைக்கும் சிறந்த வழங்குநரைத் தானாகத் தேர்ந்தெடுக்குமாறு `auto`, OmniRoute-க்கு அறிவுறுத்துகிறது. இது வேகம், செலவு, தரம் மற்றும் கிடைக்கும் தன்மை ஆகியவற்றைக் கருத்தில் கொள்கிறது. விவரங்களுக்கு [Auto-Combo வழிகாட்டி](./AUTO-COMBO-GUIDE.md) என்பதைப் பார்க்கவும்.

### "இதற்கு எவ்வளவு செலவாகும்?"

OmniRoute தானாகவே **இலவசமானதும் திறந்த மூலமானதும்** ஆகும். நீங்கள் பயன்படுத்தும் வழங்குநர்களுக்கு மட்டுமே பணம் செலுத்த வேண்டும். பல வழங்குநர்களிடம் இலவச அடுக்குகள் உள்ளன — [இலவச அடுக்குகள் வழிகாட்டி](./FREE-TIERS-GUIDE.md) என்பதைப் பார்க்கவும்.

### "இதை Claude Code / Cursor / Copilot உடன் பயன்படுத்த முடியுமா?"

**ஆம்!** OpenAI வடிவமைப்பை ஆதரிக்கும் எந்தக் கருவியுடனும் OmniRoute செயல்படும். அடிப்படை URL-ஐ `http://localhost:20128/v1` என அமைத்தால் போதும். குறிப்பிட்ட அமைப்பு வழிமுறைகளுக்கு [CLI கருவிகள் வழிகாட்டி](../reference/CLI-TOOLS.md) என்பதைப் பார்க்கவும்.

### "ஒரு வழங்குநர் செயலிழந்தால் என்ன ஆகும்?"

தோல்வியடைந்த வழங்குநர்களை OmniRoute தானாகத் தவிர்த்துவிட்டு அடுத்த வழங்குநரை முயற்சிக்கும். நீங்கள் எதுவும் செய்ய வேண்டியதில்லை. விவரங்களுக்கு [Auto-Combo வழிகாட்டி](./AUTO-COMBO-GUIDE.md) என்பதைப் பார்க்கவும்.
