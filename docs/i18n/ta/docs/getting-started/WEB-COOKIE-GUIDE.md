Web Cookie வழங்குநர்கள், API key-க்குப் பதிலாக ஏற்கனவே உள்ள உங்கள் உலாவி அமர்வின் மூலம் AI சேவையைப் பயன்படுத்த OmniRoute-ஐ அனுமதிக்கின்றனர். ஒரு சேவையின் இணையதளம் மூலம் உங்களுக்கு ஏற்கனவே அணுகல் இருந்து, அதே அங்கீகரிக்கப்பட்ட அமர்வை OmniRoute பயன்படுத்த வேண்டும் என நீங்கள் விரும்பும்போது இவை பயனுள்ளதாக இருக்கும்.

API-key வழங்குநர்களைப் போலன்றி, Web Cookie வழங்குநர்கள் உங்கள் உலாவி இணையதளத்திற்கு அனுப்பும் நற்சான்றுகளைப் பயன்படுத்தி அங்கீகரிக்கின்றனர்.

# தொடங்குவதற்கு முன்

> **முக்கியம்:** நற்சான்றுகளை எப்போதும் **நேரடி பிணையக் கோரிக்கையிலிருந்து** நகலெடுக்கவும்; உங்கள் உலாவியின் cookie சேமிப்பகத்திலிருந்து **நகலெடுக்க வேண்டாம்**.

தவறான இடத்திலிருந்து cookies-ஐ நகலெடுப்பதால் பல அங்கீகாரச் சிக்கல்கள் ஏற்படுகின்றன.

## Cookie சேமிப்பகத்திலிருந்து நகலெடுக்க வேண்டாம்

பெரும்பாலான உலாவிகள் சேமிக்கப்பட்ட cookies-ஐப் பின்வரும் வழியாகக் காட்டுகின்றன:

```
DevTools
→ Application (அல்லது Storage)
→ Cookies
```

இந்த cookies சரியாகத் தோன்றினாலும், அவை பின்வருமாறு இருக்கலாம்:

- காலாவதியானவை
- முழுமையற்றவை
- அங்கீகரிக்கப்பட்ட கோரிக்கைகளில் மட்டுமே அனுப்பப்படும் cookies இல்லாதவை

இந்த மதிப்புகள் செல்லுபடியாகத் தோன்றினாலும், அவற்றைப் பயன்படுத்துவது அங்கீகாரத் தோல்விகளை ஏற்படுத்தலாம்.

## நேரடி கோரிக்கையிலிருந்து நகலெடுக்கவும்

அதற்குப் பதிலாக, வெற்றிகரமான கோரிக்கையில் உள்ள cookies-ஐப் பயன்படுத்தவும்:

```
DevTools
→ Network
→ பக்கத்தைப் புதுப்பிக்கவும்
→ chat அல்லது conversation கோரிக்கையைத் திறக்கவும்
→ Request Headers
→ Cookie
```

`Cookie` கோரிக்கைத் தலைப்பு, உங்கள் உலாவி வெற்றிகரமாகப் பயன்படுத்திய துல்லியமான அங்கீகாரத் தகவலைக் கொண்டுள்ளது.

பெரும்பாலான Web Cookie வழங்குநர்களுக்கு, OmniRoute-இல் ஒட்டப்பட வேண்டிய மதிப்பு இதுவாகும்.

# பொதுவான அமைப்பு

பெரும்பாலான Web Cookie வழங்குநர்களுக்கான அமைவுச் செயல்முறை ஒரே மாதிரியாகும்.

1. வழங்குநரின் இணையதளத்தில் உள்நுழையவும்.
2. உலாவியின் Developer Tools-ஐத் திறக்கவும்.
3. **Network** தாவலைத் திறக்கவும்.
4. பக்கத்தைப் புதுப்பிக்கவும்.
5. அங்கீகரிக்கப்பட்ட chat அல்லது conversation கோரிக்கையைத் திறக்கவும்.
6. தேவையான அங்கீகார நற்சான்றுகளை நகலெடுக்கவும்.
7. OmniRoute-ஐத் திறக்கவும்.
8. **Providers → Add Provider** என்பதற்குச் செல்லவும்.
9. உங்கள் Web Cookie வழங்குநரைத் தேர்ந்தெடுக்கவும்.
10. நற்சான்றுகளை ஒட்டவும்.
11. **Test Connection** என்பதைக் கிளிக் செய்யவும்.
12. வழங்குநரைச் சேமிக்கவும்.

தேவையான சரியான நற்சான்றுகள் வழங்குநரைப் பொறுத்து மாறுபடும்.

# Web Cookie வழங்குநர்களால் செய்யக்கூடியவை மற்றும் செய்ய முடியாதவை

Web Cookie வழங்குநர்கள் ஒரு இணையதளத்தின் chat இடைமுகத்தை மீண்டும் பயன்படுத்துகின்றனர். அதிகாரப்பூர்வ API-களுக்கு இணையான திறன்களை அவை வழங்குவதில்லை.

## ஆதரிக்கப்படுபவை

- ஏற்கனவே உள்ள உங்கள் உலாவி அமர்வைப் பயன்படுத்தி அங்கீகரித்தல்
- உங்கள் கணக்கு மூலம் கிடைக்கும் models-ஐ அணுகுதல்
- chat பதில்களை stream செய்தல்
- API key தேவையில்லை

## ஆதரிக்கப்படாதவை

- Function calling
- Tool calling
- தானியங்கிக் கோப்புத் திருத்தம்
- Agentic IDE பணிப்பாய்வுகள்
- API-க்கு மட்டும் உரிய அம்சங்கள்

இது எதிர்பார்க்கப்படும் நடத்தையாகும்; இது ஒரு bug **அல்ல**.

உங்களுக்கு tool செயலாக்கம், தானியங்கிக் கோப்புத் திருத்தம் அல்லது பிற agent பணிப்பாய்வுகள் தேவைப்பட்டால், Web Cookie வழங்குநருக்குப் பதிலாக **API-key வழங்குநரைப்** பயன்படுத்தவும்.

# சரிபார்ப்புத் தொடர்பான எச்சரிக்கை

வெற்றிகரமான **Test Connection** அல்லது cookie சரிபார்ப்பு, வழங்கப்பட்ட நற்சான்றுகள் எதிர்பார்க்கப்படும் வடிவத்தில் இருப்பதாகத் தோன்றுவதை மட்டுமே உறுதிப்படுத்துகிறது.

Issue #7857 தீர்க்கப்படும் வரை, வெற்றிகரமான சரிபார்ப்பு வழங்குநர் வெற்றிகரமாக அங்கீகரிப்பார் என்பதற்கு **உத்தரவாதமளிக்காது**.

அங்கீகாரம் தொடர்ந்து தோல்வியுற்றால், உலாவியின் cookie சேமிப்பகத்திலிருந்து அல்லாமல் நேரடி பிணையக் கோரிக்கையிலிருந்து நற்சான்றுகளை நகலெடுத்தீர்களா என்பதைச் சரிபார்க்கவும்.

# சிக்கல் தீர்த்தல்

## அங்கீகாரம் தோல்வியடைகிறது

நற்சான்றுகள் பின்வரும் இடத்திலிருந்து நகலெடுக்கப்பட்டதா என்பதைச் சரிபார்க்கவும்:

```
Network
→ Request Headers
→ Cookie
```

மேலும் பின்வரும் இடத்திலிருந்து நகலெடுக்கப்படவில்லை என்பதை உறுதிசெய்யவும்:

```
Application
→ Cookies
```

## Cookie உலாவியில் செயல்படுகிறது, ஆனால் OmniRoute-இல் செயல்படவில்லை

சில வழங்குநர்கள், அங்கீகரிக்கப்பட்ட கோரிக்கைகளின்போது மட்டுமே அனுப்பப்படும் cookies-ஐ உள்ளடக்குகின்றனர்.

ஒரு conversation-ஐ வெற்றிகரமாகத் திறந்த பிறகு, புதிய பிணையக் கோரிக்கையிலிருந்து நற்சான்றுகளை மீண்டும் நகலெடுக்கவும்.

## அமர்வு காலாவதியானது

Web Cookie வழங்குநர்கள் ஏற்கனவே உள்ள உங்கள் உலாவி அமர்வைப் பயன்படுத்துகின்றனர்.

உங்கள் உலாவி அமர்வு காலாவதியானாலோ அல்லது நீங்கள் வெளியேறினாலோ, புதிய நற்சான்றுத் தொகுப்பை நகலெடுக்க வேண்டும்.

# சிறந்த நடைமுறைகள்

- புதிய அங்கீகரிக்கப்பட்ட கோரிக்கையிலிருந்து நற்சான்றுகளை நகலெடுக்கவும்.
- பழைய cookies-ஐ மீண்டும் பயன்படுத்துவதைத் தவிர்க்கவும்.
- Web Cookie வழங்குநர்களைப் பயன்படுத்தும்போது உங்கள் உலாவி அமர்வைச் செயலில் வைத்திருக்கவும்.
- நகலெடுக்கப்பட்ட cookies-ஐ முக்கியமான நற்சான்றுகளாகக் கருதவும்.
- Function calling அல்லது agent பணிப்பாய்வுகள் தேவைப்படும்போது API-key வழங்குநர்களைப் பயன்படுத்தவும்.
