## Provider என்றால் என்ன?

Provider-ஐ ஒரு **தொலைபேசி சேவை நிறுவனம்** போலக் கருதுங்கள். அழைப்புகளை மேற்கொள்ள உங்களுக்கு ஒரு தொலைபேசி சேவை நிறுவனம் தேவைப்படுவது போலவே, AI மாதிரிகளைப் பயன்படுத்த ஓர் AI provider தேவை. OmniRoute என்பது **அனைத்து சேவை நிறுவனங்களுடனும்** இயங்கும் தொலைபேசி போன்றது — அவற்றுக்கு இடையே தானாக மாறிக்கொள்ளலாம்.

### Provider வகைகள்

| வகை            | அது என்ன                            | எடுத்துக்காட்டுகள்                | செலவு                              |
| -------------- | ----------------------------------- | --------------------------------- | ---------------------------------- |
| **இலவசம்**     | கட்டணம் தேவையில்லை                  | Kiro, OpenCode Free, Pollinations | $0                                 |
| **API Key**    | உங்களுக்கு API key தேவை             | OpenAI, Anthropic, Google         | பயன்பாட்டிற்கு ஏற்ப கட்டணம்        |
| **OAuth**      | உங்கள் கணக்கில் உள்நுழைதல்          | Claude Code, GitHub Copilot       | சந்தா                              |
| **Web Cookie** | உங்கள் உலாவி அமர்வைப் பயன்படுத்தும் | ChatGPT Web (Codex), Gemini Web   | $0 (உங்கள் கணக்கைப் பயன்படுத்தும்) |

### Web Cookie Provider-கள்

பொதுவான அமைவு வழிமுறைகள், வரம்புகள், சிக்கல் தீர்வு மற்றும் provider-க்கான பிரத்யேக அங்கீகார வழிகாட்டுதலுக்கு **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**-ஐப் பார்க்கவும்.

## விரைவான தொடக்கம்: உங்கள் முதல் Provider-ஐ இணைத்தல்

### விருப்பத்திற்குரிய முதல் இயக்க இலவச-provider அமைவு

முதல் இயக்க வழிகாட்டி வெளிப்படையான **இலவச provider-களை அமைக்கவும்** அட்டையை வழங்குகிறது. OmniRoute-இன் அங்கீகாரம் தேவையில்லாத provider பதிவகத்திலிருந்து தற்போது
தகுதியுள்ள பட்டியலைப் பெற்று, உறுதிப்படுத்துவதற்கு முன் ஒவ்வொரு
provider-ஐயும் மதிப்பாய்வு செய்து தேர்வுநீக்க உங்களை அனுமதிக்கிறது. முதலில் மூன்றாம் தரப்பு விதிமுறைகள், தனியுரிமை, கிடைக்கும் தன்மை மற்றும் பயன்பாட்டு வரம்புகளை நீங்கள் மதிப்பாய்வு செய்யும் வகையில், provider-இன் எச்சரிக்கை அறிவிப்பையும் அதன் தளத்திற்கான இணைப்பையும் OmniRoute காட்டுகிறது.

இந்தச் செயல் விருப்பத்திற்குரியது: வழிகாட்டியை நிறைவு செய்வதால் இலவச-provider இணைப்புகள் ஒருபோதும் மறைமுகமாக உருவாக்கப்படாது.
இன்னும் இல்லாத provider-களை மட்டுமே இது உருவாக்கும், ஏற்கெனவே தனிப்பயனாக்கப்பட்ட இணைப்புகளை
மாற்றாமல் வைத்திருக்கும், மேலும் உருவாக்கப்பட்ட, ஏற்கெனவே உள்ளமைக்கப்பட்ட மற்றும் தோல்வியடைந்த provider-களைத் தனித்தனியாகத் தெரிவிக்கும். பகுதியளவு முடிவு கிடைத்த பிறகு, தோல்வியடைந்தவற்றை மட்டும்
பாதுகாப்பாக மீண்டும் முயற்சிக்கலாம்.

### விருப்பம் A: இலவச Provider (கடன் அட்டை தேவையில்லை)

1. `http://localhost:20128`-இல் dashboard-ஐத் திறக்கவும்
2. **Providers** → **Provider-ஐச் சேர்க்கவும்** என்பதற்குச் செல்லவும்
3. இந்த இலவச provider-களில் ஒன்றைத் தேர்ந்தெடுக்கவும்:
   - **Kiro AI** — இலவச Claude மாதிரிகள் (அங்கீகாரம் தேவையில்லை)
   - **OpenCode Free** — இலவச GPT மாதிரிகள் (அங்கீகாரம் தேவையில்லை)
   - **Pollinations** — இலவச GPT-5, Claude, Gemini (key தேவையில்லை)
   - **LongCat** — 10M token-கள் இலவசம் (ஒருமுறை வழங்கப்படும், கணக்கு + KYC தேவை)
   - **Cloudflare AI** — 50+ மாதிரிகள், நாளொன்றுக்கு 10K neuron-கள்
   - **MLX Gemma 26B** — உள்ளமை Apple Silicon மாதிரி (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — உள்ளமை Apple Silicon மாதிரி (~9.1 tok/s, ~13.1GB RAM)
4. **இணைக்கவும்** என்பதைக் கிளிக் செய்யவும்
5. முடிந்தது! இப்போது உங்களுக்கு இலவச AI அணுகல் உள்ளது.

### விருப்பம் B: API Key Provider (கட்டணமுள்ளது)

1. Provider-இன் இணையதளத்திலிருந்து API key-ஐப் பெறவும்:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128`-இல் dashboard-ஐத் திறக்கவும்
3. **Providers** → **Provider-ஐச் சேர்க்கவும்** என்பதற்குச் செல்லவும்
4. உங்கள் provider-ஐத் தேர்ந்தெடுக்கவும்
5. உங்கள் API key-ஐ ஒட்டவும்
6. **இணைக்கவும்** என்பதைக் கிளிக் செய்யவும்
7. முடிந்தது! இப்போது அந்த provider-இன் மாதிரிகளுக்கான அணுகல் உங்களிடம் உள்ளது.

### விருப்பம் C: OAuth Provider (சந்தா)

1. `http://localhost:20128`-இல் dashboard-ஐத் திறக்கவும்
2. **Providers** → **Provider-ஐச் சேர்க்கவும்** என்பதற்குச் செல்லவும்
3. உங்கள் provider-ஐத் தேர்ந்தெடுக்கவும் (எ.கா., Claude Code, GitHub Copilot)
4. **OAuth மூலம் இணைக்கவும்** என்பதைக் கிளிக் செய்யவும்
5. உங்கள் கணக்கில் உள்நுழையவும்
6. முடிந்தது! இப்போது உங்கள் சந்தா மாதிரிகளுக்கான அணுகல் உங்களிடம் உள்ளது.

### விருப்பம் D: உள்ளமை MLX மாதிரிகள் (Apple Silicon)

ஒருங்கிணைந்த நினைவகத்தைக் கொண்ட Apple Silicon Mac-களுக்கு, `mlx-lm.server` வழியாக இயங்கும் உள்ளமை MLX மாதிரிகளை வழக்கமான OpenAI-இணக்கமான உள்ளமை provider-களாக இணைப்பதை OmniRoute ஆதரிக்கிறது.

#### முன்தேவைகள்

- 24GB+ ஒருங்கிணைந்த நினைவகம் பரிந்துரைக்கப்படும் **Apple Silicon Mac** (M1/M2/M3/M4)
- **uv** package manager: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### விரைவான தொடக்கம்

1. **சார்புகளை நிறுவவும்**:

   ```bash
   # ஏற்கெனவே நிறுவப்படவில்லை என்றால் uv-ஐ நிறுவவும்
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm-ஐ நிறுவவும்
   uv pip install mlx-lm
   ```

2. **MLX server-களை கைமுறையாகத் தொடங்கவும்** (தனித்தனி terminal-களில்):

   ```bash
   # Terminal 1: Gemma 4 26B A4B IT-QAT (port 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Terminal 2: Qwen 3.8 27B MLX Mixed (port 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute Dashboard-இல் இணைக்கவும்**:
   - **Providers** → **Provider-ஐச் சேர்க்கவும்** என்பதற்குச் செல்லவும்
   - **MLX Gemma 26B** அல்லது **MLX Qwen 3.8 27B** என்பதைத் தேர்ந்தெடுக்கவும்
   - **இணைக்கவும்** என்பதைக் கிளிக் செய்யவும் (API key தேவையில்லை)

4. **OpenCode உடன் பயன்படுத்தவும்**:
   ```bash
   # OmniRoute-ஐப் பயன்படுத்த OpenCode-ஐ உள்ளமைக்கவும்
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX மாதிரிகளைப் பயன்படுத்தவும்
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### நினைவக மேலாண்மை

**முக்கியம்**: 24GB ஒருங்கிணைந்த நினைவகத்துடன், ஒரே நேரத்தில் **ஒரு பெரிய MLX மாதிரி மட்டுமே இயங்க முடியும்**.

- Gemma 26B: ~15.9GB உச்ச நினைவகப் பயன்பாடு
- Qwen 3.8 27B: ~13.1GB உச்ச நினைவகப் பயன்பாடு

இதை நீங்கள் கைமுறையாக நிர்வகிக்க வேண்டும்:

- ஒரே நேரத்தில் ஒரு MLX server-ஐ மட்டும் இயக்கவும், அல்லது
- இரண்டையும் தனித்தனி கணினிகளில் இயக்கவும், அல்லது
- மற்றொன்றைத் தொடங்குவதற்கு முன் ஒன்றை நிறுத்தவும்

OmniRoute, MLX server செயல்முறைகளைத் தானாக நிர்வகிக்காது — நீங்கள் உள்ளமைக்கும் OpenAI-இணக்கமான endpoint-களுக்கு கோரிக்கைகளை வழிமாற்றுவது மட்டுமே அதன் பணி.

## ஒரு வழங்குநரை இணைப்பது எப்படி (படிப்படியாக)

### படி 1: டாஷ்போர்டைத் திறக்கவும்

உங்கள் உலாவியில் `http://localhost:20128` என்பதற்குச் செல்லவும்.

### படி 2: வழங்குநர்கள் பகுதிக்குச் செல்லவும்

பக்கப்பட்டியில் உள்ள **வழங்குநர்கள்** என்பதைக் கிளிக் செய்யவும்.

### படி 3: வழங்குநரைச் சேர் என்பதைக் கிளிக் செய்யவும்

**+ வழங்குநரைச் சேர்** பொத்தானைக் கிளிக் செய்யவும்.

### படி 4: உங்கள் வழங்குநரைத் தேர்ந்தெடுக்கவும்

பட்டியலை உலாவவும் அல்லது உங்கள் வழங்குநரைத் தேடவும். அதன் மீது கிளிக் செய்யவும்.

### படி 5: அணுகல் விவரங்களை உள்ளிடவும்

- **இலவச வழங்குநர்கள்**: அணுகல் விவரங்கள் தேவையில்லை — **இணை** என்பதைக் கிளிக் செய்தால் போதும்
- **API சாவி வழங்குநர்கள்**: உங்கள் API சாவியை ஒட்டவும்
- **OAuth வழங்குநர்கள்**: **OAuth மூலம் இணை** என்பதைக் கிளிக் செய்து உள்நுழையவும்

### படி 6: இணைப்பைச் சோதிக்கவும்

அது செயல்படுகிறதா என்பதைச் சரிபார்க்க **இணைப்பைச் சோதி** என்பதைக் கிளிக் செய்யவும்.

### படி 7: முடிந்தது!

உங்கள் வழங்குநர் இப்போது இணைக்கப்பட்டுள்ளார். அதை `model: "auto"` உடன் பயன்படுத்தலாம் அல்லது வழங்குநரை நேரடியாகக் குறிப்பிடலாம்.
