## விரைவான நிறுவல் நீக்கம் (v3.6.2+)

முழுமையாக அகற்றுவதற்கு OmniRoute இரண்டு உள்ளமைந்த ஸ்கிரிப்ட்களை வழங்குகிறது:

### உங்கள் தரவைத் தக்கவைத்தல்

```bash
npm run uninstall
```

இது OmniRoute செயலியை அகற்றும், ஆனால் `~/.omniroute/` இல் உள்ள உங்கள் தரவுத்தளம், உள்ளமைவுகள், API விசைகள் மற்றும் வழங்குநர் அமைப்புகளை **பாதுகாக்கும்**. பின்னர் மீண்டும் நிறுவத் திட்டமிட்டு, உங்கள் அமைப்பைத் தக்கவைக்க விரும்பினால் இதைப் பயன்படுத்தவும்.

### முழுமையாக அகற்றுதல்

```bash
npm run uninstall:full
```

இது செயலியையும் **அனைத்துத் தரவையும் நிரந்தரமாக அழித்தும்** விடும்:

- தரவுத்தளம் (`storage.sqlite`)
- வழங்குநர் உள்ளமைவுகள் மற்றும் API விசைகள்
- காப்புப் பிரதி கோப்புகள்
- பதிவுக் கோப்புகள்
- `~/.omniroute/` கோப்பகத்திலுள்ள அனைத்துக் கோப்புகளும்

> ⚠️ **எச்சரிக்கை:** `npm run uninstall:full` செயல்பாட்டை மாற்றியமைக்க முடியாது. உங்கள் அனைத்து வழங்குநர் இணைப்புகள், சேர்க்கைகள், API விசைகள் மற்றும் பயன்பாட்டு வரலாறு நிரந்தரமாக நீக்கப்படும்.

## கைமுறை நிறுவல் நீக்கம்

### NPM உலகளாவிய நிறுவல்

```bash
# உலகளாவிய தொகுப்பை அகற்றவும்
npm uninstall -g omniroute

# (விருப்பத்திற்குரியது) தரவுக் கோப்பகத்தை அகற்றவும்
rm -rf ~/.omniroute
```

### pnpm உலகளாவிய நிறுவல்

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# கொள்கலனை நிறுத்தி அகற்றவும்
docker stop omniroute
docker rm omniroute

# தொகுதியை அகற்றவும் (அனைத்துத் தரவையும் நீக்கும்)
docker volume rm omniroute-data

# (விருப்பத்திற்குரியது) படிமத்தை அகற்றவும்
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# கொள்கலன்களை நிறுத்தி அகற்றவும்
docker compose down

# தொகுதிகளையும் அகற்றவும் (அனைத்துத் தரவையும் நீக்கும்)
docker compose down -v
```

### Electron மேசைக்கணினிச் செயலி

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` என்பதைத் திறக்கவும்
- அல்லது நிறுவல் கோப்பகத்திலிருந்து NSIS நிறுவல் நீக்கியை இயக்கவும்

**macOS:**

- `/Applications` இலிருந்து `OmniRoute.app` ஐக் குப்பைத்தொட்டிக்கு இழுக்கவும்
- தரவை அகற்றவும்: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage கோப்பை அகற்றவும்
- தரவை அகற்றவும்: `rm -rf ~/.omniroute`

### மூலக்குறியீட்டு நிறுவல் (git clone)

```bash
# நகலெடுக்கப்பட்ட கோப்பகத்தை அகற்றவும்
rm -rf /path/to/omniroute

# (விருப்பத்திற்குரியது) தரவுக் கோப்பகத்தை அகற்றவும்
rm -rf ~/.omniroute
```

## தரவுக் கோப்பகங்கள்

இயல்புநிலையில் OmniRoute பின்வரும் இடங்களில் தரவைச் சேமிக்கிறது:

| இயங்குதளம்     | இயல்புநிலைப் பாதை                | மேலெழுதும் அமைப்பு           |
| -------------- | -------------------------------- | ---------------------------- |
| Linux          | `~/.omniroute/`                  | `DATA_DIR` சூழல் மாறி        |
| macOS          | `~/.omniroute/`                  | `DATA_DIR` சூழல் மாறி        |
| Windows        | `%APPDATA%/omniroute/`           | `DATA_DIR` சூழல் மாறி        |
| Docker         | `/app/data/` (ஏற்றப்பட்ட தொகுதி) | `DATA_DIR` சூழல் மாறி        |
| XDG-இணக்கமானது | `$XDG_CONFIG_HOME/omniroute/`    | `XDG_CONFIG_HOME` சூழல் மாறி |

### தரவுக் கோப்பகத்திலுள்ள கோப்புகள்

| கோப்பு/கோப்பகம்      | விளக்கம்                                                              |
| -------------------- | --------------------------------------------------------------------- |
| `storage.sqlite`     | முதன்மைத் தரவுத்தளம் (வழங்குநர்கள், சேர்க்கைகள், அமைப்புகள், விசைகள்) |
| `storage.sqlite-wal` | SQLite முன்னெழுதுப் பதிவு (தற்காலிகமானது)                             |
| `storage.sqlite-shm` | SQLite பகிரப்பட்ட நினைவகம் (தற்காலிகமானது)                            |
| `call_logs/`         | கோரிக்கை பேலோடு காப்பகங்கள்                                           |
| `backups/`           | தானியங்குத் தரவுத்தளக் காப்புப் பிரதிகள்                              |
| `log.txt`            | மரபுவழிக் கோரிக்கைப் பதிவு (விருப்பத்திற்குரியது)                     |

## முழுமையாக அகற்றப்பட்டதைச் சரிபார்த்தல்

நிறுவல் நீக்கப்பட்ட பிறகு, மீதமுள்ள கோப்புகள் எதுவும் இல்லை என்பதைச் சரிபார்க்கவும்:

```bash
# உலகளாவிய npm தொகுப்பைச் சரிபார்க்கவும்
npm list -g omniroute 2>/dev/null

# தரவுக் கோப்பகத்தைச் சரிபார்க்கவும்
ls -la ~/.omniroute/ 2>/dev/null

# இயங்கிக்கொண்டிருக்கும் செயல்முறைகளைச் சரிபார்க்கவும்
pgrep -f omniroute
```

ஏதேனும் செயல்முறை இன்னும் இயங்கிக்கொண்டிருந்தால், அதை நிறுத்தவும்:

```bash
pkill -f omniroute
```
