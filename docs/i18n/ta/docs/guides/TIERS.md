OmniRoute ஆதரிக்கப்படும் 352 வழங்குநர்களை 3 பொருளாதார அடுக்குகளாக ஒழுங்கமைக்கிறது. ஒவ்வொரு
கோரிக்கையும் அவற்றில் ஒன்று வெற்றிகரமாகப் பதிலளிக்கும் வரை வரிசையாக அவற்றின் வழியாகச்
செல்கிறது — fallback குறியீட்டை எழுதாமலேயே, செயல்படக்கூடிய மிகக் குறைந்த விலைப் பதிலைப்
பெறுவீர்கள்.

## அடுக்கு 1 — சந்தா

**நீங்கள் ஏற்கனவே பணம் செலுத்தும் வழங்குநர்கள்.** ஒதுக்கீடு காலாவதியாகும் முன் அதன்
ஒவ்வொரு துளியையும் OmniRoute பயன்படுத்துகிறது.

| வழங்குநர்                    | ஏன் அடுக்கு 1                                                           |
| ---------------------------- | ----------------------------------------------------------------------- |
| Claude Code OAuth            | Anthropic Pro/Team — நிலையான கட்டணம், பெரும்பாலும் பயன்படுத்தப்படாதது   |
| OpenAI Codex (ChatGPT சந்தா) | Plus/Team-இல் Codex ஒதுக்கீடு அடங்கும்                                  |
| GitHub Copilot               | பயனர் இருக்கை அடிப்படையிலானது — ஒதுக்கீடு மாதந்தோறும் மீட்டமைக்கப்படும் |
| Cursor IDE                   | Pro திட்ட ஒதுக்கீடு                                                     |
| Antigravity / Devin Desktop  | உள்ளமைந்த ஒதுக்கீடுகள்                                                  |

**உத்தி**: மாதிரியின் திறன்களுக்குப் பொருந்தும் ஒவ்வொரு கோரிக்கையையும் முதலில் இங்கே
வழிமாற்றுங்கள். ஒதுக்கீட்டு கண்காணிப்பான் நெருங்கிவரும் மீட்டமைப்புகளைக் கண்காணிக்கிறது,
மேலும் `reset-aware` சேர்க்கை உத்தி அதற்கேற்ப முன்னுரிமை அளிக்கிறது. அடுக்கு 1-க்கு முதலில்
வழிமாற்றி, ஒதுக்கீடு தீர்ந்த பின்னரே கட்டண அடுக்குகளுக்குச் செல்ல `auto/thrifty` id-ஐப்
பயன்படுத்துங்கள் — அல்லது திட்டத்தில் அடங்கிய திறனுக்குள் மட்டும் இருந்து, அது கிடைக்காதபோது
தோல்வியுடன் நிறுத்த `auto/subscription`-ஐப் பயன்படுத்துங்கள். [சந்தா-முதல் வழிமாற்றம்](../routing/SUBSCRIPTION_LADDER.md)
என்பதைப் பார்க்கவும்.

## அடுக்கு 2 — மலிவானது

**1M tokens-க்கு $1-க்கும் குறைவாக வசூலிக்கும், token அடிப்படையிலான கட்டண வழங்குநர்கள்.**
அதிக அளவிலான பணிகளுக்காக அல்லது அடுக்கு 1 ஒதுக்கீடுகள் வரம்பை எட்டிய பிறகு பயன்படுத்துவதற்காக
ஒதுக்கப்பட்டவை.

| வழங்குநர்                           | விலை (உள்ளீடு/வெளியீடு) | பலங்கள்                            |
| ----------------------------------- | ----------------------- | ---------------------------------- |
| DeepSeek V4 Pro                     | 1M-க்கு $0.27 / $1.10   | குறியீடு, தர்க்கவியல்              |
| GLM-4.5                             | 1M-க்கு $0.60 / $2.20   | நீண்ட சூழல்                        |
| MiniMax M1                          | 1M-க்கு $0.20 / $1.10   | வேகம்                              |
| Qwen Coder                          | 1M-க்கு $0.30 / $1.20   | குறியீடு                           |
| OpenRouter (விலை-உகப்பாக்கப்பட்டது) | மாறுபடும்               | 100+ மாதிரிகள், இயக்கநிலைத் தேர்வு |

**உத்தி**: பணியின் திறன் வடிகட்டியை (பார்வை, JSON பயன்முறை, கருவிகள், அதிகபட்ச சூழல்)
பூர்த்தி செய்யும் மாதிரிகளில், குறைந்த $/token விலையுள்ள மாதிரியை `cost-optimized`
சேர்க்கை தேர்ந்தெடுக்கிறது.

## அடுக்கு 3 — இலவசம்

**செலவில்லா வழங்குநர்கள்** — இலவச அடுக்குகள், credit திட்டங்கள், OAuth தினசரி ஒதுக்கீடுகள்.

| வழங்குநர்        | இலவச ஒதுக்கீடு / credits                        |
| ---------------- | ----------------------------------------------- |
| Kiro AI          | இலவச Claude அடுக்கு (தாராளமான நியாயப் பயன்பாடு) |
| OpenCode Free    | அங்கீகாரம் தேவையில்லை, தாராளமான விகித வரம்புகள் |
| Qoder            | இலவச OAuth                                      |
| Google Vertex AI | புதிய கணக்குகளுக்கு $300 credits                |
| Amazon Q         | AWS பயனர்களுக்கான இலவச அடுக்கு                  |
| Pollinations     | திறந்த பொது API                                 |
| Cloudflare AI    | Workers AI இலவச அடுக்கு                         |

**உத்தி**: அடுக்கு 1+2 தோல்வியடையும்போது அல்லது `useFreeOnly=true` அமைக்கப்பட்டிருக்கும்போது,
செலவு உச்சவரம்புடன் கூடிய `auto` சேர்க்கை இங்கே வழிமாற்றுகிறது. இலவச வழங்குநர்கள்
பெரும்பாலும் குறைவான விகித வரம்புகளைக் கொண்டிருப்பார்கள் — circuit breaker, backoff
காலத்திற்குப் பிறகு அவற்றை மீட்டெடுக்கிறது.

## அடுக்குகளை உள்ளமைத்தல்

Dashboard → **Tiers** → உங்கள் வழங்குநர்களை ஒதுக்குங்கள். இயல்புநிலைகள் (`tierDefaults.json`-இலிருந்து)
பொருத்தமானவை; முன்னுரிமை அளிக்க வேண்டிய குறிப்பிட்ட சந்தாக்கள் அல்லது விலக்க வேண்டிய வழங்குநர்கள்
உங்களிடம் இருந்தால் அவற்றைத் திருத்துங்கள்.

Auto-Combo-வின் 16-காரணி மதிப்பீடும் அடுக்கைக் கருத்தில் கொள்கிறது.  
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) என்பதைப் பார்க்கவும்.

## தொலைஅளவியல்

Dashboard → **Usage** என்பது ஒவ்வொரு நாளும் ஒவ்வொரு அடுக்கிலும் செலவிடப்பட்ட tokens-ஐக் காட்டுகிறது. இதைப் பயன்படுத்தி:

- அடுக்கு 1 முழுமையாகப் பயன்படுத்தப்படுவதை உறுதிப்படுத்துங்கள் (இல்லையெனில் சந்தாவின் மதிப்பை வீணாக்குகிறீர்கள்)
- எந்த அடுக்கு 2 மாதிரிகள் அதிகமாகத் தேர்ந்தெடுக்கப்படுகின்றன என்பதைக் கண்டறியுங்கள் (1-2 மாதிரிகளாக ஒருங்கிணைக்கவும்)
- சோதனை/ஆய்வுப் பணிச்சுமைகளில் அடுக்கு 3 பணத்தைச் சேமிக்கிறதா என்பதைச் சரிபாருங்கள்

## பொதுவான வடிவங்கள்

### முழுமையாக இலவசமான பணிச்சுமை

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

அடுக்கு 3-ஐ நோக்கி வலுவாக வழிமாற்றுகிறது; அடுக்கு 3 கிடைக்காதபோது மட்டுமே அடுக்கு 2-ஐப்
பயன்படுத்துகிறது.

### மலிவான fallback உடன் சந்தா-முதல்

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

அடுக்கு 1 → அடுக்கு 2 → அடுக்கு 3 என்பதற்குப் பொருந்தும் வெளிப்படையான வரிசைப்படுத்தப்பட்ட பட்டியல்.
