## 1. Antigravity மற்றும் Antigravity CLI (agy) இடையிலான ஒப்பீடு

இரண்டு வழங்குநர்களும் **ஒரே Google பின்தளத்தைப்** பகிர்கின்றனர் — ஒரே OAuth கிளையண்ட், டோக்கன் புதுப்பித்தல், முனைப்புள்ளிகள் மற்றும் Google கணக்குகள். நீங்கள் எந்த மாடல்களைப் பார்க்கிறீர்கள் என்பதே வேறுபாடு.

> Google-இன் அதிகாரப்பூர்வ ஒப்பீட்டிற்கு [Antigravity CLI அறிவிப்பைப்](https://antigravity.google/blog/introducing-google-antigravity-cli) பார்க்கவும்.

| அம்சம்                    | `antigravity` (IDE)                                                             | `agy` (CLI)                                                                  |
| ------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Google தயாரிப்பு**      | Antigravity 2.0 / Antigravity IDE                                               | Antigravity CLI                                                              |
| **பின்தளம்**              | அதே Google Cloud Code API                                                       | அதே Google Cloud Code API                                                    |
| **OAuth / டோக்கன்**       | அதே கிளையண்ட், அதே புதுப்பித்தல்                                                | அதே கிளையண்ட், அதே புதுப்பித்தல்                                             |
| **மாடல் பட்டியல்**        | நிலையான தேர்ந்தெடுக்கப்பட்ட பட்டியல் (OmniRoute-இல் நேரடியாகக் குறியிடப்பட்டது) | `:fetchAvailableModels` மூலம் Google-இலிருந்து நேரடியாகச் சோதித்தறியப்பட்டது |

| **Gemini பெயரிடல்**       | தெளிவான பெயர்கள் (Low/Medium/High)                                              | மேல்நிலை ID-கள் (extra-low/low/agent)                                        |
| **கூடுதல் மாடல்கள்**      | `gpt-oss-120b-medium`                                                           | Google வழங்கும் கூடுதல் மாடல்களும் இருக்கலாம்                                |

| **ஒதுக்கீடு**             | agy உடன் பகிரப்படுகிறது (அதே Google கணக்கு)                                     | antigravity உடன் பகிரப்படுகிறது (அதே Google கணக்கு)                          |

**கிடைக்கும் மாடல்கள் (பரிசோதனை மூலம் சரிபார்க்கப்பட்டது, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (பல்வேறு சிந்தனை நிலைகள்)
- Claude: Sonnet 4.6, Opus 4.6 (ஒவ்வொன்றிலும் default/low/medium/high வகைகள்)
- மற்றவை: GPT-OSS 120B Medium
- **Claude Sonnet 5 கிடைக்காது** — 4.6 வகைகள் மட்டுமே ஆதரிக்கப்படுகின்றன

**மாடல் பட்டியல் ஏன் வேறுபடுகிறது**: Google-இன் அதிகாரப்பூர்வ வலைப்பதிவின்படி, Google-இன் CLI ஆனது "வேகம் மற்றும் குறைந்த மேலதிகச் சுமைக்காக மேம்படுத்தப்பட்டுள்ளது" மற்றும் "Gemini மாடல்களுடன் இணைந்து மேம்படுத்தப்பட்டுள்ளது." Web/IDE தயாரிப்பு "விரிவான முழுமைக்காக மேம்படுத்தப்பட்டுள்ளது." CLI மாடல்களை மாறும் வகையில் கண்டறிய `:fetchAvailableModels`-ஐப் பயன்படுத்துகிறது; IDE நிலையான தேர்ந்தெடுக்கப்பட்ட பட்டியலைப் பயன்படுத்துகிறது.

**நடைமுறையில்**: Gemini மாடல்களுக்கு `agy/` முன்னொட்டைப் பயன்படுத்தவும் (எ.கா. `agy/gemini-3.7-flash-high`). நிலையான தேர்ந்தெடுக்கப்பட்ட பட்டியலுக்கு `antigravity/`-ஐப் பயன்படுத்தவும். இரண்டும் ஒரே Google பின்தளத்தை அணுகுகின்றன; ஆனால் மாடல்களுக்கான வெவ்வேறு பெயரிடலை வெளிப்படுத்துகின்றன. ஒதுக்கீடு பகிரப்படுகிறது — எந்த வழங்குநரைப் பயன்படுத்தினாலும் அது அதே Google கணக்கின் வரம்புகளில் கணக்கிடப்படும்.

## 2. Google One AI Pro: ஒதுக்கீட்டு அமைப்பு

> அதிகாரப்பூர்வ ஒதுக்கீட்டு விவரங்களுக்கு [Antigravity ஆவணங்கள்: திட்டங்கள்](https://antigravity.google/docs/plans) என்பதையும், சமீபத்திய விலை மாற்றங்களுக்கு [Antigravity திட்டங்களில் செய்யப்பட்ட மாற்றங்கள்](https://antigravity.google/blog/changes-to-antigravity-plans) என்பதையும் பார்க்கவும்.

Google Antigravity, செய்திகளின் எண்ணிக்கையை அடிப்படையாகக் கொள்ளாமல், "செய்யப்பட்ட பணி" (கணக்கீட்டு எடை) அடிப்படையிலான **இரட்டை-அடுக்கு ஒதுக்கீட்டை** பயன்படுத்துகிறது.

### இரண்டு அடுக்குகள்

| அடுக்கு                    | அது என்ன                                         | புதுப்பிப்புச் சுழற்சி                                                                        |
| -------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **5-மணிநேர விரைவு அமர்வு** | உடனடியாகக் கிடைக்கும் "செய்யப்பட்ட பணி" தொகுப்பு | ஓர் அமர்வின் முதல் கோரிக்கைக்குப் பிறகு 5 மணிநேரத்தில் மீட்டமைக்கப்படும்                      |
| **7-நாள் அடிப்படை வரம்பு** | வாராந்திர கடின வரம்பு                            | இது எட்டப்பட்டால் 5-மணிநேரப் புதுப்பிப்பை மீறும்; அடுத்த 7-நாள் காலம் வரை அணுகல் பூட்டப்படும் |

**"செய்யப்பட்ட பணி" எவ்வாறு கணக்கிடப்படுகிறது**: முகவர்-தீவிரப் பணிகள் (எ.கா. "இந்த முழுக் களஞ்சியத்தையும் மறுசீரமைக்கவும்") எளிய பணிகளைவிட (எ.கா. "இந்தச் செயல்பாட்டைச் சரிசெய்யவும்") ஒதுக்கீட்டை மிக வேகமாகப் பயன்படுத்தும். பயன்பாட்டைக் காட்டும் நிகழ்நேரக் கட்டுப்பாட்டுப் பலகம் எதுவும் இல்லை.

### Gemini மற்றும் Gemini அல்லாத மாதிரிகள்

- **Gemini மாதிரிகள்** (Flash + Pro): API விலை நிர்ணயத்தின்படி பயன்படுத்தப்படும் ஒரே வீத வரம்பைப் பகிர்கின்றன. Flash ஆனது Pro-ஐவிட 8x மலிவானதாக இருந்தால், உங்களுக்கு 8x அதிகமான Flash டோக்கன்கள் கிடைக்கும்.
- **Gemini அல்லாத மாதிரிகள்** (Claude, GPT-OSS): **தனித்தனி** வீத வரம்புகளைக் கொண்டுள்ளன. Gemini-க்கான அணுகல் பூட்டப்பட்டிருந்தாலும் இவை தொடர்ந்து கிடைக்கக்கூடும்.

### AI கிரெடிட்கள் (கூடுதல் பயன்பாடு)

> கிரெடிட்கள் எவ்வாறு செயல்படுகின்றன என்பதை அறிய [Google One AI கிரெடிட்கள்](https://support.google.com/googleone/answer/14534406) என்பதைப் பார்க்கவும்.

அடிப்படை ஒதுக்கீடு தீர்ந்துவிட்டால்:

- **ஒருபோதும் வேண்டாம்**: ஒதுக்கீடு புதுப்பிக்கப்படும் வரை காத்திருக்கும்; "அடிப்படை மாதிரி ஒதுக்கீடு எட்டப்பட்டது" எனக் காட்டும்
- **எப்போதும்**: AI கிரெடிட்களைத் தானாகப் பயன்படுத்தும்; அடிப்படை ஒதுக்கீடு புதுப்பிக்கப்பட்டதும் மீண்டும் அதற்கு மாறும்

கிரெடிட்கள் தனியாக வாங்கப்பட்டு, நிலையான API விலை நிர்ணயத்தின்படி கழிக்கப்படுகின்றன.

### முக்கிய விவரங்கள்

- ஒதுக்கீடு **கணக்கு அளவில் பகிரப்படுகிறது** — Antigravity IDE, CLI மற்றும் OmniRoute ஆகியவற்றில் பயன்படுத்தப்படும் ஒரே Google கணக்கு, ஒரே ஒதுக்கீட்டுத் தொகுப்பைப் பகிர்கிறது
- ஒவ்வொரு Google கணக்கிற்கும் தனித்த, சுயாதீனமான ஒதுக்கீடு உள்ளது — பல கணக்குகள் = பல ஒதுக்கீட்டுத் தொகுப்புகள்
- வாராந்திர அடிப்படை வரம்பு எட்டப்படும்போது, 5-மணிநேர மீட்டமைப்புகளுக்குப் பதிலாக **7-நாள் அணுகல் பூட்டல்களை** எதிர்கொண்டதாக AI Pro பயனர்கள் தெரிவித்துள்ளனர் (அதிகத் தேவையைச் சமாளிக்க இது திட்டமிட்ட வடிவமைப்பே என Google உறுதிப்படுத்தியுள்ளது)

**உங்கள் கணக்கின் ஒதுக்கீடு தீர்ந்துவிட்டால்**: சேர்க்கை வழித்தடத்தில் அடுத்துக் கிடைக்கும் கணக்கைப் பயன்படுத்தி OmniRoute தானாகவே மீண்டும் முயற்சிக்கும். கைமுறைத் தலையீடு தேவையில்லை.

## 3. projectId-ஐ எவ்வாறு பெறுவது

ஒவ்வொரு antigravity/agy இணைப்பிற்கும் ஒரு Google Cloud Code `projectId` தேவை. அது இல்லையெனில், `/v1internal:models` முனைப்புள்ளி 404-ஐ வழங்கும்.

### முறை A: தானியக்கம் (பரிந்துரைக்கப்படுகிறது)

OmniRoute இதைத் தானாகக் கையாளுகிறது. Dashboard OAuth வழியாகப் புதிய Google கணக்கைச் சேர்க்கும்போது:

1. OmniRoute டோக்கனைப் புதுப்பிக்கிறது
2. projectId-ஐக் கண்டறிய `loadCodeAssist`-ஐ அழைக்கிறது
3. எந்தத் திட்டமும் இல்லை என்றால், ஒன்றை உருவாக்க `onboardUser`-ஐ அழைக்கிறது
4. புதிதாக உருவாக்கப்பட்ட projectId-ஐப் பெற `loadCodeAssist`-ஐ மீண்டும் முயற்சிக்கிறது
5. அதைத் தரவுத்தளத்தில் சேமிக்கிறது

**இது பெரும்பாலான கணக்குகளுக்குச் செயல்படும்** — கைமுறைப் படிகள் தேவையில்லை.

### முறை B: agy CLI வழியாகக் கைமுறையாக

தானியக்கக் கண்டறிதல் தோல்வியடைந்தால் (இது எப்போது நிகழும் என்பதற்கு பிரிவு 5-ஐப் பார்க்கவும்):

```bash
# agy CLI-ஐ நிறுவவும் (ஏற்கெனவே நிறுவப்படவில்லை என்றால்)
npm install -g @anthropic-ai/agy

# உங்கள் Google கணக்கில் உள்நுழையவும்
agy login

# தொடக்கப் பதிவேற்றம் தேவைப்படும் கணக்கைத் தேர்ந்தெடுக்கவும்
# இது Cloud Code பதிவைத் தொடங்கி, ஒரு projectId-ஐ ஒதுக்கும்
```

`agy login` வெற்றிபெற்ற பிறகு, OmniRoute Dashboard-இல் டோக்கனைப் புதுப்பிக்கவும். projectId தானாகவே கண்டறியப்படும்.

### சரிபார்ப்பது எப்படி

தரவுத்தளத்தைச் சரிபார்க்கவும்:

```bash
# OmniRoute கொள்கலனுக்குள்
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

அல்லது பதிவுகளைச் சரிபார்க்கவும்:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuth திருப்பிவிடும் URI

### சிக்கல்

Google OAuth-க்கு செல்லுபடியாகும் திருப்பிவிடும் URI தேவை. OmniRoute-இன் இயல்புநிலை `http://127.0.0.1:20128/callback` (loopback) ஐப் பயன்படுத்துகிறது. இது உள்ளூர் builds-க்கு வேலை செய்யும், ஆனால் **தொலைநிலை deployments-ல் தோல்வியடையும்** (எ.கா., LAN IP வழியாக அணுகப்படும் ஒரு server).

பின்வரும் வகையான திருப்பிவிடும் URI-களை Google நிராகரிக்கும்:

- IP முகவரிகளைப் பயன்படுத்துபவை (`.com`, `.org` போன்றவற்றில் முடியும் ஒரு domain ஆக இருக்க வேண்டும்)
- OAuth client config-இல் பதிவுசெய்யப்பட்ட திருப்பிவிடும் URI-களுடன் பொருந்தாதவை

### தீர்வு

**விருப்பம் A: உள்ளமைக்கப்பட்ட OAuth flow-ஐப் பயன்படுத்தவும் (இயல்புநிலை)**

- `localhost` அல்லது `127.0.0.1` இலிருந்து OmniRoute-ஐ அணுகும்போது வேலை செய்யும்
- எந்த configuration-உம் தேவையில்லை

**விருப்பம் B: தனிப்பயன் OAuth credentials**

- உங்கள் environment-இல் `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` என்பதை அமைக்கவும்
- உங்கள் சொந்த Google OAuth credentials-ஐ வழங்கவும்:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Google Cloud Console-இல் `https://your-domain.com/callback` என்பதை அங்கீகரிக்கப்பட்ட திருப்பிவிடும் URI ஆகப் பதிவுசெய்யவும்

**விருப்பம் C: ஆரம்ப உள்நுழைவுக்கு agy CLI-ஐப் பயன்படுத்தவும்**

- OmniRoute-ஐ அணுகவிருக்கும் machine-இல் `agy login` ஐ இயக்கவும்
- OAuth flow உள்ளூரில் நிறைவடைந்து, tokens சேமிக்கப்படும்
- Dashboard வழியாக connection-ஐ OmniRoute-க்குள் இறக்குமதி செய்யவும்

### வரம்புகள்

- தனிப்பயன் OAuth credentials-க்கு ஒரு domain name தேவை (திருப்பிவிடும் URI-களாக IP முகவரிகளை Google ஏற்காது)
- உங்களிடம் domain இல்லையெனில், அதற்குப் பதிலாக விருப்பம் A அல்லது C-ஐப் பயன்படுத்தவும்

## 5. சிக்கல் தீர்த்தல்: தானியங்கிய அமைப்பு தோல்வியடையும்போது

பெரும்பாலான accounts-க்கு projectId கண்டறிதலையும் onboarding-ஐயும் OmniRoute தானாகவே கையாளுகிறது. அது தோல்வியடையும்போது, மூலக் காரணம் பொதுவாக பின்வருவனவற்றில் ஒன்றாக இருக்கும்:

### Account region தடுக்கப்பட்டுள்ளது

**அறிகுறி**: `agy login` ஆனது "தகுதிச் சரிபார்ப்பு தோல்வியடைந்தது: Antigravity தற்போது உங்கள் இருப்பிடத்தில் கிடைக்காததால், உங்கள் நடப்பு account அதற்குத் தகுதியற்றது." எனத் தெரிவிக்கிறது.

**மூலக் காரணம்**: Google accounts-இல் பதிவு செய்யும் நேரத்தில் அமைக்கப்படும் backend "Country Association" field உள்ளது. agy CLI மற்றும் Cloud Code API ஆகியவை இந்த field-ஐக் கண்டிப்பாகச் சரிபார்க்கின்றன — தற்போதைய IP-ஐ மட்டும் சரிபார்க்கும் web Gemini போலல்லாமல்.

> உங்கள் account-உடன் தொடர்புடைய region-ஐச் சரிபார்க்க அல்லது மாற்ற, [Google Country Association Form](https://policies.google.com/country-association-form) ஐப் பார்வையிடவும்.

**web Gemini வேலை செய்யும்போது agy ஏன் வேலை செய்வதில்லை**:

- Web Gemini / Google One: தற்போதைய IP-ஐ மட்டும் சரிபார்க்கும் (proxy மூலம் செயல்படும்)
- agy CLI / Cloud Code API: backend Country Association field-ஐப் படிக்கும் (proxy உதவாது)

**தீர்வு**:

1. US IP-ஐப் பயன்படுத்தும்போது [Google Country Association Form](https://policies.google.com/country-association-form) ஐப் பார்வையிடவும்
2. region மாற்றக் கோரிக்கையைச் சமர்ப்பிக்கவும் ("நான் வேறு நாட்டில் வசிக்கிறேன்" என்பதைத் தேர்ந்தெடுக்கவும்)
3. Google செயலாக்கி + email அறிவிப்பு அனுப்புவதற்கு 1-24 மணிநேரம் காத்திருக்கவும்
4. அதன் பிறகு `agy login` வெற்றிபெற வேண்டும்

### Account-இல் Cloud Code project இல்லை

**அறிகுறி**: Logs-இல் `loadCodeAssist returned no project id` மற்றும் `onboardUser failed (400)` என்று காட்டப்படும்.

**மூலக் காரணம்**: அந்த account இதற்கு முன் Google Cloud Code-இல் பதிவு செய்யப்படவில்லை, மேலும் தானியங்கி onboarding தோல்வியடைந்துள்ளது.

**தீர்வு**: Cloud Code பதிவைத் தூண்ட `agy login` ஐ கைமுறையாக இயக்கி, பின்னர் OmniRoute Dashboard-இல் token-ஐப் புதுப்பிக்கவும்.

### Token காலாவதியாகியுள்ளது அல்லது ரத்துசெய்யப்பட்டுள்ளது

**அறிகுறி**: Logs-இல் 401 errors அல்லது "Token காலாவதியாகிவிட்டது" என்ற செய்திகள்.

**தீர்வு**: Dashboard → Providers → agy → புதுப்பிப்பு icon-ஐக் கிளிக் செய்யவும் என்பதன் மூலம் token-ஐப் புதுப்பிக்கவும். Refresh token-உம் ரத்துசெய்யப்பட்டிருந்தால், OAuth வழியாக மீண்டும் அங்கீகரிக்க வேண்டும்.

```
   └─ தோல்வியடைகிறது → பிழைச் செய்தியைச் சரிபார்க்கவும்; பெரும்பாலும் பிராந்தியம் அல்லது சந்தா தொடர்பான சிக்கலாக இருக்கும்
```
