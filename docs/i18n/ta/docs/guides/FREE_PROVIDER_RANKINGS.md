## இது என்ன

OmniRoute 329 வழங்குநர்களைப் பதிவுசெய்கிறது; இதில் **இலவசம்/அங்கீகாரம் தேவையில்லை** எனக் குறிக்கப்பட்ட 155 பட்டியல் உள்ளீடுகள் அடங்கும்
(அங்கீகாரம் தேவையில்லை,
இலவச அடுக்கு OAuth அல்லது இலவச அடுக்கு API விசை —
[இலவச அடுக்குகள் வழிகாட்டி](../getting-started/FREE-TIERS-GUIDE.md) மற்றும் முழுமையான
[இலவச அடுக்குகள் கோப்பகம்](../reference/FREE_TIERS.md) ஆகியவற்றைப் பார்க்கவும்). இதில் உள்ள சிக்கல்: இலவச வழங்குநர்களின் மாதிரித் தரம்
பெருமளவில் வேறுபடுகிறது. முன்னணி மாதிரியை வழங்கும் அங்கீகாரம் தேவையற்ற வழங்குநர்,
சிறிய பழைய மாதிரியை வழங்கும் வழங்குநரைவிட மிகவும் பயனுள்ளதாக இருப்பார்.

**இலவச வழங்குநர் தரவரிசைகள்**, ஒவ்வொரு இலவச வழங்குநரின் பட்டியலையும்
**Arena AI முன்னிலைப் பட்டியலில்** உள்ள **கூட்டத்திடமிருந்து பெறப்பட்ட தர மதிப்பெண்களுடன்** இணைப்பதன் மூலம், "**எந்த இலவச வழங்குநர் எனக்குச் சிறந்த மாதிரியை வழங்குகிறார்?**" என்ற கேள்விக்குப் பதிலளிக்கிறது
(மனித விருப்பத்தேர்வு ELO; LMArena
சாட்பாட் அரங்கத்தின் பின்னணியில் உள்ள அதே கருத்து). பின்னர் வழங்குநர்கள், அவர்களின் **சிறந்த இலவச மாதிரியின்** வலிமையின் அடிப்படையில் தரவரிசைப்படுத்தப்படுகிறார்கள்.

இந்தத் தரவரிசை மூன்று உண்மையான மூலங்களிலிருந்து கணக்கிடப்படுகிறது:

1. இலவச வழங்குநர் பட்டியல்கள் — `NOAUTH_PROVIDERS`, மேலும் `hasFree` எனக் குறிக்கப்பட்ட
   `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` உள்ளீடுகள்
   (`src/shared/constants/providers.ts`).
2. வழங்குநர் பதிவகத்திலுள்ள ஒவ்வொரு வழங்குநரின் மாதிரிப் பட்டியல்
   (`open-sse/config/providerRegistry.ts`).
3. Arena ELO ஒத்திசைவு இயந்திரத்தால் `model_intelligence` தரவுத்தள அட்டவணையில் சேமிக்கப்படும்
   ELO-விலிருந்து பெறப்பட்ட பணிப் பொருத்த மதிப்பெண்கள் (`src/lib/arenaEloSync.ts`).

இணைப்புத் தர்க்கம் `src/lib/freeProviderRankings.ts`-இல் உள்ளது.

## அணுகுவது எப்படி

### டாஷ்போர்டு பக்கம்

டாஷ்போர்டைத் திறந்து **செலவுகள் → இலவச வழங்குநர் தரவரிசைகள்** என்பதற்குச் செல்லவும் அல்லது நேரடியாக இங்கு செல்லவும்:

```
/dashboard/free-provider-rankings
```

இந்தப் பக்கம் (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) பின்வருவனவற்றைக் காட்டுகிறது:

- சிறந்த தரவரிசை பெற்ற இலவச வழங்குநர்களின் **முதல் 3 மேடை** (🥇 🥈 🥉).
- **தரவரிசை**, **வழங்குநர்**, **சிறந்த மாதிரி**,
  **மதிப்பெண்**, **சராசரி மதிப்பெண்**, **மாதிரிகள்**, **வகை** ஆகிய நெடுவரிசைகளுடன் கூடிய முழுமையான **தரவரிசை அட்டவணை**.
- **வகை வடிகட்டல் பொத்தான்கள்**: _அனைத்து வகைகளும்_, _இயல்புநிலை_, _குறியீட்டாக்கம்_, _மதிப்பாய்வு_,
  _ஆவணப்படுத்தல்_, _பிழைத்திருத்தம்_.

ஒவ்வொரு வழங்குநரின் **வகை** அடையாளமும் அது எவ்வாறு இலவசமாக உள்ளது என்பதைக் காட்டுகிறது:

| அடையாளம் | பொருள்                                              |
| -------- | --------------------------------------------------- |
| `NOAUTH` | எப்போதும் இலவசம், சான்றுகள் தேவையில்லை              |
| `OAUTH`  | இலவச அடுக்கைக் கொண்ட OAuth வழங்குநர் (`hasFree`)    |
| `APIKEY` | இலவச அடுக்கைக் கொண்ட API-விசை வழங்குநர் (`hasFree`) |

மதிப்பெண்கள் மூல எண்களுக்குப் பதிலாக மனிதர்கள் எளிதில் புரிந்துகொள்ளக்கூடிய குறிச்சொற்களாக (எ.கா. _உயர்தரம்_, _மிகச் சிறப்பு_, _மிகவும் நன்று_,
_நன்று_, _சராசரி_) காட்டப்படுகின்றன; ஏனெனில் அடிப்படை மதிப்பு ஒரு சதவீதம் அல்ல,
ஒப்பீட்டுத் தரவரிசைத் தரமாகும்.

### API முனைப்புள்ளி

இந்தப் பக்கத்துக்கு ஒரு பொதுப் படிப்பு முனைப்புள்ளி
(`src/app/api/free-provider-rankings/route.ts`) ஆதரவளிக்கிறது:

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

வினவல் அளவுருக்கள் (Zod மூலம் சரிபார்க்கப்படுகின்றன):

| அளவுரு     | வகை    | இயல்புநிலை    | குறிப்புகள்                                                                                                                 |
| ---------- | ------ | ------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `category` | string | (எதுவுமில்லை) | `default`, `coding`, `review`, `documentation`, `debugging` ஆகியவற்றில் ஒன்று. ஒருங்கிணைந்த தரவரிசைக்கு இதைத் தவிர்க்கவும். |
| `limit`    | number | `50`          | `1–100` வரம்புக்குள் கட்டுப்படுத்தப்படுகிறது.                                                                               |

பதில் வடிவம்:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` என்பது அசல் Arena ELO மதிப்பு; `score` என்பது இயல்பாக்கப்பட்ட பணிப் பொருத்த மதிப்பு
(கீழே காண்க). மதிப்பெண் வழங்கப்பட்ட மாதிரிகள் இல்லாத வழங்குநர்கள் பதிலிலிருந்து தவிர்க்கப்படுகிறார்கள்.

## மதிப்பெண்கள் எவ்வாறு செயல்படுகின்றன

### மூலம்: Arena AI தரவரிசைப் பட்டியல்

Arena ELO ஒத்திசைவு இயந்திரம் (`src/lib/arenaEloSync.ts`), Arena AI தரவரிசைப் பட்டியல் API-யிலிருந்து
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`) `text`
மற்றும் `code` ஆகிய இரண்டு தரவரிசைப் பட்டியல்களைப் பெறுகிறது. ஒவ்வொரு தரவரிசைப் பட்டியல் பதிவும்
ஒரு மாதிரிப் பெயர், வழங்குநர், ELO `score`, நம்பக இடைவெளி மற்றும் வாக்கு எண்ணிக்கையைக் கொண்டுள்ளது.

தரவரிசைப் பட்டியல் வகைகள் OmniRoute பணி வகைகளுடன் பின்வருமாறு பொருத்தப்படுகின்றன:

| Arena தரவரிசைப் பட்டியல் | OmniRoute பணி வகைகள்                              |
| ------------------------ | ------------------------------------------------- |
| `text`                   | `default`, `review`, `documentation`, `debugging` |
| `code`                   | `coding`                                          |

### இயல்பாக்கம் (பணிப் பொருத்த மதிப்பெண்)

மூல ELO மதிப்பெண்கள் ஒவ்வொரு தரவரிசைப் பட்டியலிலும் **`[0.4, 0.98]` வரம்பிற்குள் உள்ள பணிப் பொருத்த மதிப்பாக** இயல்பாக்கப்படுகின்றன:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

இந்த மதிப்பெண் ஒருபோதும் `0` அல்லது `1`-ஐ எட்டாது; இதனால் பயனர் மேலெழுதல்களுக்கு இடம் விடப்படுகிறது. API பதிலில் நீங்கள் காணும் `score` புலமும், கட்டுப்பாட்டுப் பலகையில் காட்டப்படும் சிட்டையும் இதுவே.

### நம்பகத்தன்மை

Arena வாக்கு எண்ணிக்கையின் அடிப்படையில் ஒவ்வொரு பதிவுக்கும் ஒரு நம்பகத்தன்மை நிலை வழங்கப்படுகிறது:

| நம்பகத்தன்மை | வாக்குகள் |
| ------------ | --------- |
| `high`       | ≥ 5,000   |
| `medium`     | ≥ 1,000   |
| `low`        | < 1,000   |

### சேமிப்பும் தரவின் புதுமையும்

இயல்பாக்கப்பட்ட பதிவுகள் `source = "arena_elo"` உடன் `model_intelligence` DB அட்டவணையில் எழுதப்படுகின்றன (`src/lib/db/modelIntelligence.ts`). பதிவுகள் **7 நாட்களுக்குப் பிறகு காலாவதியாகும்**; எனவே, ஒத்திசைப்பதை நிறுத்தும் வழங்குநரின் பழைய தரவுகள் தொடர்ந்து வழங்கப்படாமல், இறுதியில் நீக்கப்படும்.

ஒத்திசைவு **இயல்பாகவே இயக்கப்பட்டிருக்கும்**:

- சேவையகம் தொடங்கும்போது இது ஒருமுறை இயங்கி, பின்னர் குறிப்பிட்ட கால இடைவெளியில் தொடர்ச்சியாக இயங்கும்
  (`src/lib/arenaEloSync.ts`, `src/instrumentation-node.ts`-இலிருந்து இணைக்கப்பட்டுள்ளது).
- இது **தடையற்றது மற்றும் ஒருபோதும் செயலிழப்பை ஏற்படுத்தாது** — மேல்நிலைத் தரவுப் பெறுதல் தோல்வியடைந்தால், OmniRoute தொடர்ந்து
  இயங்கும்; தரவரிசைகள் கடைசியாக வெற்றிகரமாகப் பெறப்பட்ட தரவை மட்டும் காட்டும் (அல்லது வெற்று நிலையைக் காட்டும்).

இரண்டு சூழல் மாறிகள் இதைக் கட்டுப்படுத்துகின்றன ([`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)-இல்
ஆவணப்படுத்தப்பட்டுள்ளன):

| மாறி                      | இயல்புநிலை    | நோக்கம்                                                      |
| ------------------------- | ------------- | ------------------------------------------------------------ |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | வெளிச்செல்லும் ஒத்திசைவிலிருந்து விலக `false` என அமைக்கவும். |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | ஒத்திசைவு இடைவெளி, விநாடிகளில்.                              |

### கைமுறை ஒத்திசைவு / நிலை / அழித்தல்

நிர்வாகிகளுக்காக, அங்கீகரிக்கப்பட்ட மேலாண்மை முனைப்புள்ளி கைமுறைக் கட்டுப்பாட்டை வழங்குகிறது
(`src/app/api/intelligence/sync/route.ts` — மேலாண்மை அங்கீகாரம் தேவை):

```
GET    /api/intelligence/sync          # தற்போதைய ஒத்திசைவு நிலை (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # கைமுறை ஒத்திசைவைத் தொடங்கும்; எழுதாமல் முன்னோட்டமிட body: { "dryRun": true }
DELETE /api/intelligence/sync          # ஒத்திசைக்கப்பட்ட அனைத்து arena_elo நுண்ணறிவுப் பதிவுகளையும் அழிக்கும்
```

தரவரிசைப் பக்கம் காலியாக இருந்தால், கைமுறை `POST /api/intelligence/sync` கோரிக்கை (அல்லது சேவையகத்தை மீண்டும் தொடங்குவது மட்டும்) அதை மீண்டும் நிரப்பும்.

### மாதிரிகளைத் தரவரிசைப் பட்டியலுடன் பொருத்துதல்

பதிவக மாதிரி ID-களும் Arena மாதிரிப் பெயர்களும் எப்போதும் துல்லியமாகப் பொருந்துவதில்லை. தரவரிசையிடல் நெகிழ்வான பொருத்தத்தைப் பயன்படுத்துகிறது (`src/lib/freeProviderRankings.ts`-இல் உள்ள `findMatchingIntelligence`):

1. இயல்பாக்கப்பட்ட மாதிரி ID-யுடன் துல்லியமான பொருத்தம்.
2. இறுதியில் உள்ள பதிப்புப் பின்னொட்டினை நீக்கிய பிறகான பொருத்தம் (எ.கா. `kimi-k2.6` → `kimi-k2`).
3. முன்னொட்டுப் பொருத்தம் (தரவரிசைப் பட்டியலிலுள்ள மாதிரிப் பெயர், பதிவக ID-யின் முன்னொட்டாக இருக்கும்).

ஒத்திசைவுப் பக்கத்தில், அறியப்பட்ட வழங்குநர் முன்னொட்டுகள் (`anthropic/`, `openai/`, `google/`, …) நீக்கப்படுகின்றன; மேலும், ஒரு சிறிய மாற்றுப்பெயர் வரைபடம், நியமப் பெயர்களை OmniRoute அகத்தில் பயன்படுத்தும் மாற்று வடிவங்களாக விரிவாக்குகிறது. இதனால் மாதிரிகள் எந்தப் பெயரிலும் கண்டறியக்கூடியவையாக இருக்கும்.

### ஒரு வழங்குநர் எவ்வாறு தரவரிசைப்படுத்தப்படுகிறார்

ஒவ்வொரு இலவச வழங்குநருக்கும், இயந்திரம் அதன் பட்டியலிலுள்ள ஒவ்வொரு மாதிரிக்கும் மதிப்பெண் கணக்கிட்டு, பின்னர்:

- **சிறந்த மாதிரி** = வழங்குநரின் அதிக மதிப்பெண் பெற்ற மாதிரி.
- **சராசரி மதிப்பெண்** = அந்த வழங்குநரின் மதிப்பிடப்பட்ட அனைத்து மாதிரிகளின் சராசரி மதிப்பெண்.
- **மாதிரிகள்** = வழங்குநரின் மாதிரிகளில் Arena மதிப்பெண் கொண்டிருந்தவற்றின் எண்ணிக்கை.

வழங்குநர்கள் முதலில் **சிறந்த மாதிரியின் மதிப்பெண்** அடிப்படையிலும், பின்னர் சராசரி மதிப்பெண் அடிப்படையிலும் வரிசைப்படுத்தப்படுகின்றனர். குறைந்தது ஒரு வலுவான இலவச மாதிரியையாவது வழங்கும் வழங்குநருக்கு இது முன்னுரிமை அளிக்கிறது.

## இலவச வழங்குநர்களைத் தேர்ந்தெடுக்க இதைப் பயன்படுத்துதல்

1. **சரியான வகையைத் தேர்ந்தெடுக்கவும்.** ஏஜென்ட் சார்ந்த/குறியீட்டு பணிச்சுமைகளுக்கு **Coding** வடிகட்டியைப் பயன்படுத்தவும் அல்லது பொதுவான அரட்டைக்கு **All Categories** / **Default** என்பதிலேயே விடவும். ஒவ்வொரு தரவரிசைப் பட்டியலிலும் வழங்குநரின் சிறந்த மாதிரி வேறுபடுவதால், ஒரே வழங்குநர் வகைகளுக்கு ஏற்ப வெவ்வேறு இடங்களைப் பெறலாம்.
2. **ஒரேமுறை அமைப்புகளுக்கு முதல் மூன்று இடங்களை விரும்பவும்.** ஒன்று அல்லது இரண்டு இலவச வழங்குநர்களை மட்டுமே இணைக்க விரும்பினால், உங்கள் வகையில் உயர்ந்த தரவரிசையில் உள்ளவற்றிலிருந்து தொடங்கவும்.
3. **Type அடையாளக் குறியைச் சரிபார்க்கவும்.** `NOAUTH` வழங்குநர்களை மிக விரைவாக இணைக்கலாம் (சான்றுகள் தேவையில்லை). `OAUTH` / `APIKEY` இலவச அடுக்குகளுக்கு விரைவான பதிவுசெய்தல் தேவைப்படும், ஆனால் அவை பெரும்பாலும் அதிகத் திறனுள்ள மாதிரிகளை வழங்குகின்றன. இணைப்பதற்கான படிகளுக்கு [இலவச அடுக்குகள் வழிகாட்டி](../getting-started/FREE-TIERS-GUIDE.md) என்பதைப் பார்க்கவும்.
4. **பலவற்றை இணைத்து, Auto-Combo முடிவெடுக்க அனுமதிக்கவும்.** இந்தப் பக்கத்தை இயக்கும் அதே Arena ELO தரவு, Auto-Combo மதிப்பீட்டு இயந்திரத்தின் **பணிப் பொருத்தக் காரணிக்கும்** தரவளிக்கிறது (`open-sse/services/autoCombo/taskFitness.ts`, தீர்மான வரிசை:
   `user_override → arena_elo → models_dev_tier → static table`). எனவே, சிறந்த இலவச வழங்குநர்களை இணைத்த பிறகு, `model: "auto"` (எ.கா. `auto/coding`) மூலம் வழிச்செலுத்துவது ஒவ்வொரு கோரிக்கைக்கும் உயர்தரமான இலவச மாதிரிகளைத் தானாகவே முன்னுரிமைப்படுத்தும். முழுமையான 16-காரணி மதிப்பீட்டிற்கு [Auto-Combo](../routing/AUTO-COMBO.md) என்பதைப் பார்க்கவும்.
