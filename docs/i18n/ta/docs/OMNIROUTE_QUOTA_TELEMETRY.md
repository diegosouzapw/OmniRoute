OmniRoute, வழங்குநரின் ஒதுக்கீட்டுத் தொலைஅளவீட்டை Ghostlight கணக்கீட்டிலிருந்து பிரிக்கிறது.

## உண்மையான நிலைகள்

- `healthy` என்பது ஒரு மூலம் பயன்படுத்தக்கூடிய மீதமுள்ள கொள்ளளவைப் புகாரளித்துள்ளது என்பதைக் குறிக்கிறது.
- `approaching_limit` என்பது ஒரு மூலம், கட்டமைக்கப்பட்ட வரம்பிற்குச் சமமான அல்லது அதற்குக் குறைவான மீதமுள்ள கொள்ளளவைப் புகாரளித்துள்ளது என்பதைக் குறிக்கிறது.
- ஒரு மூலம் பூஜ்ஜிய கொள்ளளவையோ அல்லது அதன் வரம்பை எட்டிய பயன்பாட்டையோ புகாரளிக்கும்போது மட்டுமே `exhausted` வெளியிடப்படும்.
- `unavailable` என்பது ஆதரிக்கப்படும் ஒரு மூலம் தரவை வழங்கத் தவறியுள்ளது என்பதைக் குறிக்கிறது.
- `unknown` என்பது ஆதரிக்கப்படும் மூலம் எதுவும் இல்லை அல்லது வழங்குநரின் வரம்பு எதுவும் அறியப்படவில்லை என்பதைக் குறிக்கிறது.

அறியப்படாத நிலை என்பது ஒதுக்கீடு தீர்ந்துவிட்டதைக் குறிக்காது; மேலும், அது ஒரு வழங்குநரை முடக்காது.

மூலங்கள் இந்த வரிசையில் முன்னுரிமை அளிக்கப்படுகின்றன: வழங்குநரின் அதிகாரப்பூர்வ API, அங்கீகரிக்கப்பட்ட பயன்பாட்டு API, வெளிப்படையாகப் பொருத்தப்பட்ட பதில் தலைப்புகள், நிர்வாகி உள்ளமைவு, உள்ளூர் மதிப்பீடுகள், அறியப்படாத நிலை. உள்ளூர் மதிப்பீடுகள் ஒருபோதும் வழங்குநரின் பில்லிங் தரவாகக் காட்டப்படுவதில்லை.

வெளிப்படையான வழங்குநர் பொருத்தத்தின் மூலம் மட்டுமே பதில் தலைப்புகள் பாகுபடுத்தப்படுகின்றன. பொதுவான தலைப்புப் பெயர்கள் உலகளவில் பொருந்தும் என்று கருதப்படுவதில்லை.
