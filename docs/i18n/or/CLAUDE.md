ପଥ, `cp -al` node_modules, ବିଲୋପ ନିୟମ) `AGENTS.md` → Git Workflow → "Worktree
isolation"-ରେ ରହିଛି। Claude-Code-ନିର୍ଦ୍ଦିଷ୍ଟ ବିଷୟଗୁଡ଼ିକ:

- ଅପରେଟର୍ ପୂର୍ବରୁ ଜଣାଇ ନଥିଲେ, `AskUserQuestion` ମାଧ୍ୟମରେ ତାଙ୍କ ସହିତ ମୂଳ branch ନିଶ୍ଚିତ କରନ୍ତୁ (କଠୋର ନିୟମ #19)।
- ମୂଳ `EnterWorktree` ଟୁଲ୍କୁ ପ୍ରାଥମିକତା ଦିଅନ୍ତୁ — ଏହା ପୂର୍ବରୁ
  `.claude/worktrees/` (ପ୍ରାମାଣିକ ପଥ) ଅଧୀନରେ worktree ସୃଷ୍ଟି କରେ। ଡକ୍ୟୁମେଣ୍ଟ କରାଯାଇଥିବା `git
worktree add` କମାଣ୍ଡ୍ରେ worktree ସୃଷ୍ଟି କରନ୍ତୁ, ତା’ପରେ ଏହାର `path` ସହିତ `EnterWorktree` କଲ୍ କରନ୍ତୁ।

## କ୍ରସ୍-ସେସନ୍ ସୁରକ୍ଷା — Claude Code-ନିର୍ଦ୍ଦିଷ୍ଟ ବିବରଣୀ

କଠୋର ନିୟମ #19/#21/#22 (`AGENTS.md`-ରେ) ସମାନ୍ତରାଳ ସେସନ୍ଗୁଡ଼ିକୁ ପରିଚାଳନା କରେ। ଏହି

## Superpowers / ଯୋଜନା କଳାକୃତି — ପଥ ଅଧିଲେଖନ

`_tasks/` ପ୍ରଥାଟି `AGENTS.md` → "Planning & Research Artifacts"-ରେ ପରିଭାଷିତ। superpowers
skill-ଗୁଡ଼ିକ ସହିତ ଆସୁଥିବା ଡିଫଲ୍ଟଗୁଡ଼ିକ `docs/…`-କୁ ସୂଚାଏ — ସେହି ଡିଫଲ୍ଟଗୁଡ଼ିକୁ ଏଠାରେ **ଅଧିଲେଖନ କରାଯାଇଛି**।
ଯେତେବେଳେ କୌଣସି superpowers skill "saved to `docs/superpowers/plans/…`" ପରି ଏକ ପଥ ଘୋଷଣା କରେ,
ଲେଖିବା ପୂର୍ବରୁ ତାହାକୁ ସମତୁଲ୍ୟ `_tasks/…` ପଥରେ ପୁନର୍ଲେଖନ କରନ୍ତୁ:

| କଳାକୃତି (skill)                             | ଡିଫଲ୍ଟ (ବ୍ୟବହାର କରନ୍ତୁ ନାହିଁ) | ଏହା ପରିବର୍ତ୍ତେ ଏଠାରେ ସଂରକ୍ଷଣ କରନ୍ତୁ                           |
| ------------------------------------------- | ----------------------------- | ------------------------------------------------------------- |
| ଯୋଜନାଗୁଡ଼ିକ (`writing-plans`)               | `docs/superpowers/plans/`     | `_tasks/superpowers/plans/YYYY-MM-DD-<feature>.md`            |
| ନିର୍ଦ୍ଦିଷ୍ଟୀକରଣ / ଡିଜାଇନ୍ (`brainstorming`) | `docs/superpowers/specs/`     | `_tasks/superpowers/specs/YYYY-MM-DD-<topic>-design.md`       |
| ଗବେଷଣା (`deep-research`, ତଦର୍ଥ)             | `docs/research/`              | `_tasks/research/…`                                           |
| ହସ୍ତାନ୍ତର (`/handoff`)                      | —                             | `_tasks/hands-off/<YYYY-MM-DD>_<branch>_v<versão>_sess-<id>/` |

ସେହି କଳାକୃତିଗୁଡ଼ିକୁ `_tasks/` repo ଭିତରେ commit କରନ୍ତୁ (`git -C _tasks …`), ମୁଖ୍ୟ repo-ରେ କେବେ ନୁହେଁ।

## Scratch / ଅସ୍ଥାୟୀ ଫାଇଲ୍ଗୁଡ଼ିକ — `/tmp` ନୁହେଁ, `_artifacts/` ବ୍ୟବହାର କରନ୍ତୁ

## PR ଖୋଲିବା ପୂର୍ବରୁ base-green

କୌଣସି branch କାଟିବା କିମ୍ବା PR ଖୋଲିବା ପୂର୍ବରୁ, base-green ଯାଞ୍ଚ ଚଲାନ୍ତୁ (`AGENTS.md` → Git Workflow →
"Base-green check"; ପ୍ରକଳ୍ପ skill-ଗୁଡ଼ିକ ଏହାକୁ `.agents/skills/_shared/base-green.md` ଭାବେ ସନ୍ଦର୍ଭ କରନ୍ତି)। base tip red ଥିବାବେଳେ
ଖୋଲାଯାଇଥିବା PR-ର body-ରେ `⚠️ base-red inherited: #<issue>` ରହିବା ଆବଶ୍ୟକ। ସଞ୍ଚିତ red ଅବସ୍ଥା (base tip + red PR-ଗୁଡ଼ିକ) ନିଷ୍କାସନ କରିବାକୁ,
/sweep-reds skill ବ୍ୟବହାର କରନ୍ତୁ।
