> **ସଂକ୍ଷେପରେ**: ପ୍ରଦାତା ହେଉଛି ଏକ AI ସେବା (ଯେପରି OpenAI, Anthropic, Google) ସହିତ ସଂଯୋଗ। OmniRoute ବ୍ୟବହାର କରିବାକୁ ଆପଣଙ୍କୁ ଅତିକମରେ ଗୋଟିଏ ପ୍ରଦାତା ଆବଶ୍ୟକ।

## ପ୍ରଦାତା କ’ଣ?

ଏକ ପ୍ରଦାତାକୁ ଏକ **ଫୋନ୍ ବାହକ** ଭାବରେ ଚିନ୍ତା କରନ୍ତୁ। କଲ୍ କରିବା ପାଇଁ ଯେପରି ଆପଣଙ୍କୁ ଏକ ଫୋନ୍ ବାହକ ଆବଶ୍ୟକ, AI ମଡେଲ୍ ବ୍ୟବହାର କରିବା ପାଇଁ ସେହିପରି ଏକ AI ପ୍ରଦାତା ଆବଶ୍ୟକ। OmniRoute ଏପରି ଏକ ଫୋନ୍ ଭଳି, ଯାହା **ସମସ୍ତ ବାହକଙ୍କ ସହିତ** କାମ କରେ — ଆପଣ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସେମାନଙ୍କ ମଧ୍ୟରେ ବଦଳ କରିପାରିବେ।

## ଶୀଘ୍ର ଆରମ୍ଭ: ଆପଣଙ୍କ ପ୍ରଥମ ପ୍ରଦାତାକୁ ସଂଯୋଗ କରନ୍ତୁ

### ଇଚ୍ଛାଧୀନ ପ୍ରଥମ-ଚାଳନା ମାଗଣା-ପ୍ରଦାତା ସେଟ୍ଅପ୍

ପ୍ରଥମ-ଚାଳନା ୱିଜାର୍ଡ୍ରେ ଏକ ସ୍ପଷ୍ଟ **ମାଗଣା ପ୍ରଦାତାଗୁଡ଼ିକୁ ସେଟ୍ଅପ୍ କରନ୍ତୁ** କାର୍ଡ ଦିଆଯାଏ। ଏହା OmniRouteର ପ୍ରମାଣୀକରଣ-ବିହୀନ ପ୍ରଦାତା ରେଜିଷ୍ଟ୍ରିରୁ ବର୍ତ୍ତମାନର
ଯୋଗ୍ୟ ତାଲିକା ପ୍ରସ୍ତୁତ କରେ, ତା’ପରେ ନିଶ୍ଚିତ କରିବା ପୂର୍ବରୁ ପ୍ରତ୍ୟେକ
ପ୍ରଦାତାକୁ ସମୀକ୍ଷା କରି ଚୟନମୁକ୍ତ କରିବାକୁ ଦିଏ। OmniRoute ପ୍ରଦାତାଙ୍କ ସତର୍କତା ସୂଚନା ଏବଂ ତାଙ୍କ ସାଇଟ୍ର ଏକ ଲିଙ୍କ୍ ଦେଖାଏ,
ଯାହାଦ୍ୱାରା ଆପଣ ପ୍ରଥମେ ତୃତୀୟ-ପକ୍ଷ ସର୍ତ୍ତାବଳୀ, ଗୋପନୀୟତା, ଉପଲବ୍ଧତା ଏବଂ ହାର ସୀମାଗୁଡ଼ିକ ସମୀକ୍ଷା କରିପାରିବେ।

ଏହି କାର୍ଯ୍ୟଟି ଇଚ୍ଛାଧୀନ: ୱିଜାର୍ଡ୍ ସମାପ୍ତ କରିବା ଦ୍ୱାରା କେବେହେଲେ ମଧ୍ୟ ନିରବରେ ମାଗଣା-ପ୍ରଦାତା ସଂଯୋଗ ସୃଷ୍ଟି ହୁଏ ନାହିଁ।
ଏହା କେବଳ ଏପର୍ଯ୍ୟନ୍ତ ଅନୁପସ୍ଥିତ ଥିବା ପ୍ରଦାତାଗୁଡ଼ିକୁ ସୃଷ୍ଟି କରେ, ପୂର୍ବରୁ ଥିବା କଷ୍ଟମାଇଜ୍ ସଂଯୋଗଗୁଡ଼ିକୁ
ଅପରିବର୍ତ୍ତିତ ରଖେ ଏବଂ ସୃଷ୍ଟି ହୋଇଥିବା, ପୂର୍ବରୁ ବିନ୍ୟାସିତ ଏବଂ ବିଫଳ ପ୍ରଦାତାଗୁଡ଼ିକୁ ପୃଥକ ଭାବରେ ଦର୍ଶାଏ। ଆଂଶିକ ଫଳାଫଳ ପରେ ଆପଣ
ନିରାପଦ ଭାବରେ କେବଳ ବିଫଳଗୁଡ଼ିକୁ ପୁଣି ଚେଷ୍ଟା କରିପାରିବେ।

### ବିକଳ୍ପ A: ମାଗଣା ପ୍ରଦାତା (କ୍ରେଡିଟ୍ କାର୍ଡ ଆବଶ୍ୟକ ନାହିଁ)

1. `http://localhost:20128`ରେ ଡ୍ୟାସ୍ବୋର୍ଡ୍ ଖୋଲନ୍ତୁ
2. **ପ୍ରଦାତା** → **ପ୍ରଦାତା ଯୋଡ଼ନ୍ତୁ**କୁ ଯାଆନ୍ତୁ
3. ଏହି ମାଗଣା ପ୍ରଦାତାଗୁଡ଼ିକ ମଧ୍ୟରୁ ଗୋଟିଏ ବାଛନ୍ତୁ:
   - **Kiro AI** — ମାଗଣା Claude ମଡେଲ୍ଗୁଡ଼ିକ (ପ୍ରମାଣୀକରଣ ଆବଶ୍ୟକ ନାହିଁ)
   - **OpenCode Free** — ମାଗଣା GPT ମଡେଲ୍ଗୁଡ଼ିକ (ପ୍ରମାଣୀକରଣ ଆବଶ୍ୟକ ନାହିଁ)
   - **Pollinations** — ମାଗଣା GPT-5, Claude, Gemini (କୌଣସି key ଆବଶ୍ୟକ ନାହିଁ)
   - **LongCat** — 10M tokens ମାଗଣା (ଏକକାଳୀନ ଅନୁଦାନ, ଆକାଉଣ୍ଟ୍ + KYC ଆବଶ୍ୟକ)
   - **Cloudflare AI** — 50+ ମଡେଲ୍, ଦିନକୁ 10K ନ୍ୟୁରନ୍
   - **MLX Gemma 26B** — ସ୍ଥାନୀୟ Apple Silicon ମଡେଲ୍ (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — ସ୍ଥାନୀୟ Apple Silicon ମଡେଲ୍ (~9.1 tok/s, ~13.1GB RAM)
4. **ସଂଯୋଗ କରନ୍ତୁ** କ୍ଲିକ୍ କରନ୍ତୁ
5. ହୋଇଗଲା! ଏବେ ଆପଣଙ୍କ ପାଖରେ ମାଗଣା AI ପ୍ରବେଶାଧିକାର ଅଛି।

### ବିକଳ୍ପ B: API Key ପ୍ରଦାତା (ଦେୟଯୁକ୍ତ)

1. ପ୍ରଦାତାଙ୍କ ୱେବସାଇଟ୍ରୁ ଏକ API key ପାଆନ୍ତୁ:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128`ରେ ଡ୍ୟାସ୍ବୋର୍ଡ୍ ଖୋଲନ୍ତୁ
3. **ପ୍ରଦାତା** → **ପ୍ରଦାତା ଯୋଡ଼ନ୍ତୁ**କୁ ଯାଆନ୍ତୁ
4. ଆପଣଙ୍କ ପ୍ରଦାତା ବାଛନ୍ତୁ
5. ଆପଣଙ୍କ API key ପେଷ୍ଟ୍ କରନ୍ତୁ
6. **ସଂଯୋଗ କରନ୍ତୁ** କ୍ଲିକ୍ କରନ୍ତୁ
7. ହୋଇଗଲା! ଏବେ ଆପଣଙ୍କ ପାଖରେ ସେହି ପ୍ରଦାତାଙ୍କ ମଡେଲ୍ଗୁଡ଼ିକର ପ୍ରବେଶାଧିକାର ଅଛି।

### ବିକଳ୍ପ C: OAuth ପ୍ରଦାତା (ସଦସ୍ୟତା)

1. `http://localhost:20128`ରେ ଡ୍ୟାସ୍ବୋର୍ଡ୍ ଖୋଲନ୍ତୁ
2. **ପ୍ରଦାତା** → **ପ୍ରଦାତା ଯୋଡ଼ନ୍ତୁ**କୁ ଯାଆନ୍ତୁ
3. ଆପଣଙ୍କ ପ୍ରଦାତା ବାଛନ୍ତୁ (ଯେପରି, Claude Code, GitHub Copilot)
4. **OAuth ସହିତ ସଂଯୋଗ କରନ୍ତୁ** କ୍ଲିକ୍ କରନ୍ତୁ
5. ଆପଣଙ୍କ ଆକାଉଣ୍ଟ୍ରେ ଲଗ୍ଇନ୍ କରନ୍ତୁ
6. ହୋଇଗଲା! ଏବେ ଆପଣଙ୍କ ପାଖରେ ଆପଣଙ୍କ ସଦସ୍ୟତା ମଡେଲ୍ଗୁଡ଼ିକର ପ୍ରବେଶାଧିକାର ଅଛି।

### ବିକଳ୍ପ D: ସ୍ଥାନୀୟ MLX ମଡେଲ୍ଗୁଡ଼ିକ (Apple Silicon)

ୟୁନିଫାଏଡ୍ ମେମୋରି ଥିବା Apple Silicon Macଗୁଡ଼ିକ ପାଇଁ, OmniRoute `mlx-lm.server` ମାଧ୍ୟମରେ ଚାଲୁଥିବା ସ୍ଥାନୀୟ MLX ମଡେଲ୍ଗୁଡ଼ିକୁ ସାଧାରଣ OpenAI-ସୁସଙ୍ଗତ ସ୍ଥାନୀୟ ପ୍ରଦାତା ଭାବରେ ସଂଯୋଗ କରିବାକୁ ସମର୍ଥନ କରେ।

#### ପୂର୍ବାବଶ୍ୟକତା

- **Apple Silicon Mac** (M1/M2/M3/M4), 24GB+ ୟୁନିଫାଏଡ୍ ମେମୋରି ସୁପାରିସ କରାଯାଏ
- **uv** ପ୍ୟାକେଜ୍ ମ୍ୟାନେଜର୍: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### ଶୀଘ୍ର ଆରମ୍ଭ

1. **ନିର୍ଭରତାଗୁଡ଼ିକ ଇନଷ୍ଟଲ୍ କରନ୍ତୁ**:

   ```bash
   # ପୂର୍ବରୁ ଇନଷ୍ଟଲ୍ ହୋଇନଥିଲେ uv ଇନଷ୍ଟଲ୍ କରନ୍ତୁ
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm ଇନଷ୍ଟଲ୍ କରନ୍ତୁ
   uv pip install mlx-lm
   ```

2. **MLX ସର୍ଭର୍ଗୁଡ଼ିକୁ ମାନୁଆଲ୍ ଭାବରେ ଆରମ୍ଭ କରନ୍ତୁ** (ପୃଥକ ଟର୍ମିନାଲ୍ରେ):

   ```bash
   # ଟର୍ମିନାଲ୍ 1: Gemma 4 26B A4B IT-QAT (ପୋର୍ଟ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ଟର୍ମିନାଲ୍ 2: Qwen 3.8 27B MLX Mixed (ପୋର୍ଟ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ଡ୍ୟାସ୍ବୋର୍ଡ୍ରେ ସଂଯୋଗ କରନ୍ତୁ**:
   - **ପ୍ରଦାତା** → **ପ୍ରଦାତା ଯୋଡ଼ନ୍ତୁ**କୁ ଯାଆନ୍ତୁ
   - **MLX Gemma 26B** କିମ୍ବା **MLX Qwen 3.8 27B** ବାଛନ୍ତୁ
   - **ସଂଯୋଗ କରନ୍ତୁ** କ୍ଲିକ୍ କରନ୍ତୁ (କୌଣସି API key ଆବଶ୍ୟକ ନାହିଁ)

4. **OpenCode ସହିତ ବ୍ୟବହାର କରନ୍ତୁ**:
   ```bash
   # OmniRoute ବ୍ୟବହାର କରିବା ପାଇଁ OpenCode ବିନ୍ୟାସ କରନ୍ତୁ
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX ମଡେଲ୍ଗୁଡ଼ିକ ବ୍ୟବହାର କରନ୍ତୁ
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### ମେମୋରି ପରିଚାଳନା

**ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ**: 24GB ୟୁନିଫାଏଡ୍ ମେମୋରି ସହିତ, ଏକ ସମୟରେ କେବଳ **ଗୋଟିଏ ବଡ଼ MLX ମଡେଲ୍ ଚାଲିପାରିବ**।

- Gemma 26B: ~15.9GB ସର୍ବାଧିକ ମେମୋରି
- Qwen 3.8 27B: ~13.1GB ସର୍ବାଧିକ ମେମୋରି

ଆପଣଙ୍କୁ ଏହାକୁ ମାନୁଆଲ୍ ଭାବରେ ପରିଚାଳନା କରିବାକୁ ପଡ଼ିବ:

- ଏକ ସମୟରେ କେବଳ ଗୋଟିଏ MLX ସର୍ଭର୍ ଚଲାନ୍ତୁ, କିମ୍ବା
- ଉଭୟକୁ ପୃଥକ ମେସିନ୍ରେ ଚଲାନ୍ତୁ, କିମ୍ବା
- ଅନ୍ୟଟିକୁ ଆରମ୍ଭ କରିବା ପୂର୍ବରୁ ଗୋଟିଏକୁ ବନ୍ଦ କରନ୍ତୁ

OmniRoute ସ୍ୱୟଂଚାଳିତ ଭାବରେ MLX ସର୍ଭର୍ ପ୍ରକ୍ରିୟାଗୁଡ଼ିକୁ ପରିଚାଳନା କରେ ନାହିଁ — ଏହା କେବଳ ଆପଣ ବିନ୍ୟାସ କରିଥିବା OpenAI-ସୁସଙ୍ଗତ ଏଣ୍ଡପଏଣ୍ଟ୍ଗୁଡ଼ିକୁ ଅନୁରୋଧ ରୁଟ୍ କରେ।

### ପଦକ୍ଷେପ 1: ଡ୍ୟାଶବୋର୍ଡ ଖୋଲନ୍ତୁ

ଆପଣଙ୍କ ବ୍ରାଉଜର୍ରେ `http://localhost:20128`କୁ ଯାଆନ୍ତୁ।

### ପଦକ୍ଷେପ 2: ପ୍ରଦାନକାରୀ ବିଭାଗକୁ ଯାଆନ୍ତୁ

ସାଇଡ୍ବାର୍ରେ **ପ୍ରଦାନକାରୀ** ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ।

### ପଦକ୍ଷେପ 3: ପ୍ରଦାନକାରୀ ଯୋଡ଼ନ୍ତୁ ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ

**+ ପ୍ରଦାନକାରୀ ଯୋଡ଼ନ୍ତୁ** ବଟନ୍ରେ କ୍ଲିକ୍ କରନ୍ତୁ।

### ପଦକ୍ଷେପ 4: ଆପଣଙ୍କ ପ୍ରଦାନକାରୀଙ୍କୁ ବାଛନ୍ତୁ

ତାଲିକା ଦେଖନ୍ତୁ କିମ୍ବା ଆପଣଙ୍କ ପ୍ରଦାନକାରୀଙ୍କୁ ଖୋଜନ୍ତୁ। ତାଙ୍କ ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ।

### ପଦକ୍ଷେପ 5: ପରିଚୟପତ୍ର ପ୍ରବେଶ କରନ୍ତୁ

- **ମାଗଣା ପ୍ରଦାନକାରୀ**: କୌଣସି ପରିଚୟପତ୍ର ଆବଶ୍ୟକ ନାହିଁ — କେବଳ **ସଂଯୋଗ କରନ୍ତୁ** ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ
- **API କୀ ପ୍ରଦାନକାରୀ**: ଆପଣଙ୍କ API କୀ ପେଷ୍ଟ କରନ୍ତୁ
- **OAuth ପ୍ରଦାନକାରୀ**: **OAuth ସହିତ ସଂଯୋଗ କରନ୍ତୁ** ଉପରେ କ୍ଲିକ୍ କରି ଲଗ୍ଇନ୍ କରନ୍ତୁ

### ପଦକ୍ଷେପ 6: ସଂଯୋଗ ପରୀକ୍ଷା କରନ୍ତୁ

ଏହା କାମ କରୁଛି କି ନାହିଁ ଯାଞ୍ଚ କରିବାକୁ **ସଂଯୋଗ ପରୀକ୍ଷା କରନ୍ତୁ** ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ।

### ପଦକ୍ଷେପ 7: ସମ୍ପୂର୍ଣ୍ଣ!

ଆପଣଙ୍କ ପ୍ରଦାନକାରୀ ବର୍ତ୍ତମାନ ସଂଯୁକ୍ତ ହୋଇଛନ୍ତି। ଆପଣ ଏହାକୁ `model: "auto"` ସହିତ ବ୍ୟବହାର କରିପାରିବେ କିମ୍ବା ପ୍ରଦାନକାରୀଙ୍କୁ ସିଧାସଳଖ ନିର୍ଦ୍ଦିଷ୍ଟ କରିପାରିବେ।

OmniRoute **ଏକାଧିକ ପ୍ରଦାନକାରୀ** ସହିତ ସର୍ବୋତ୍ତମ ଭାବେ କାମ କରେ। ଏହା ଆପଣଙ୍କୁ ନିମ୍ନଲିଖିତ ସୁବିଧା ଦିଏ:

- **ସ୍ୱୟଂଚାଳିତ ଫଲ୍ବ୍ୟାକ୍** — ଯଦି ଜଣେ ପ୍ରଦାନକାରୀ ବିଫଳ ହୁଅନ୍ତି, OmniRoute ପରବର୍ତ୍ତୀଙ୍କୁ ଚେଷ୍ଟା କରେ
- **ମୂଲ୍ୟ ଅନୁକୂଳନ** — OmniRoute ପ୍ରତ୍ୟେକ ଅନୁରୋଧ ପାଇଁ ସବୁଠାରୁ ଶସ୍ତା ପ୍ରଦାନକାରୀଙ୍କୁ ବାଛେ
- **ଗତି ଅନୁକୂଳନ** — OmniRoute ପ୍ରତ୍ୟେକ ଅନୁରୋଧ ପାଇଁ ସବୁଠାରୁ ଦ୍ରୁତ ପ୍ରଦାନକାରୀଙ୍କୁ ବାଛେ
- **ଗୁଣବତ୍ତା ଅନୁକୂଳନ** — OmniRoute ପ୍ରତ୍ୟେକ କାର୍ଯ୍ୟ ପାଇଁ ସର୍ବୋତ୍ତମ ପ୍ରଦାନକାରୀଙ୍କୁ ବାଛେ

### ସୁପାରିସକୃତ ସେଟ୍ଅପ୍

ସର୍ବୋତ୍ତମ ଅନୁଭୂତି ପାଇଁ ଅତିକମରେ **3 ଜଣ ପ୍ରଦାନକାରୀ**ଙ୍କୁ ସଂଯୋଗ କରନ୍ତୁ:

1. **ଜଣେ ମାଗଣା ପ୍ରଦାନକାରୀ** (Kiro, OpenCode Free, କିମ୍ବା Pollinations) — ସବୁବେଳେ ଉପଲବ୍ଧ
2. **ଜଣେ ଦ୍ରୁତ ପ୍ରଦାନକାରୀ** (Groq, Cerebras) — ଶୀଘ୍ର ପ୍ରତିକ୍ରିୟା ପାଇଁ
3. **ଜଣେ ଗୁଣବତ୍ତାସମ୍ପନ୍ନ ପ୍ରଦାନକାରୀ** (OpenAI, Anthropic, Google) — ଜଟିଳ କାର୍ଯ୍ୟ ପାଇଁ

ତା’ପରେ `model: "auto"` ବ୍ୟବହାର କରନ୍ତୁ ଏବଂ OmniRoute ପ୍ରତ୍ୟେକ ଅନୁରୋଧ ପାଇଁ ସ୍ୱୟଂଚାଳିତ ଭାବେ ସର୍ବୋତ୍ତମ ପ୍ରଦାନକାରୀଙ୍କୁ ବାଛିବ।

## ସାଧାରଣ ପ୍ରଶ୍ନ

### "OmniRoute ବ୍ୟବହାର କରିବା ପାଇଁ ମୋତେ ଦେୟ ଦେବାକୁ ପଡ଼ିବ କି?"

**ନା!** OmniRoute ମାଗଣା ଏବଂ ଓପନ୍-ସୋର୍ସ। ଆପଣ କୌଣସି ଦେୟ ନ ଦେଇ ମାଗଣା ପ୍ରଦାନକାରୀଗୁଡ଼ିକ (Kiro, OpenCode Free, Pollinations) ବ୍ୟବହାର କରିପାରିବେ। ଆପଣ କେବଳ ସଶୁଳ୍କ ପ୍ରଦାନକାରୀ ବ୍ୟବହାର କରିବାକୁ ବାଛିଲେ ଦେୟ ଦେବେ।

### "ମୁଁ କେଉଁ ପ୍ରଦାନକାରୀରୁ ଆରମ୍ଭ କରିବି?"

**Kiro AI** ରୁ ଆରମ୍ଭ କରନ୍ତୁ — ଏହା ମାଗଣା, ଏଥିପାଇଁ କୌଣସି API କୀ ଆବଶ୍ୟକ ନାହିଁ ଏବଂ ଏହା ଆପଣଙ୍କୁ Claude ମଡେଲଗୁଡ଼ିକର ଆକ୍ସେସ୍ ଦିଏ। ତା’ପରେ ଆବଶ୍ୟକତା ଅନୁସାରେ ଅଧିକ ପ୍ରଦାନକାରୀ ଯୋଡ଼ନ୍ତୁ।

### "ମୁଁ ଏକସଙ୍ଗେ ଏକାଧିକ ପ୍ରଦାନକାରୀ ବ୍ୟବହାର କରିପାରିବି କି?"

**ହଁ!** ଏହା ହିଁ OmniRoute ର ମୂଳ ଉଦ୍ଦେଶ୍ୟ। ଏକାଧିକ ପ୍ରଦାନକାରୀଙ୍କୁ ସଂଯୋଗ କରନ୍ତୁ ଏବଂ ପ୍ରତ୍ୟେକ ଅନୁରୋଧ ପାଇଁ OmniRoute କୁ ସର୍ବୋତ୍ତମଟି ବାଛିବାକୁ ଦେବା ପାଇଁ `model: "auto"` ବ୍ୟବହାର କରନ୍ତୁ।

### "କୌଣସି ପ୍ରଦାନକାରୀର ସେବା ବନ୍ଦ ହୋଇଗଲେ କ’ଣ ହେବ?"

OmniRoute ସ୍ୱୟଂଚାଳିତ ଭାବେ ବିଫଳ ପ୍ରଦାନକାରୀଙ୍କୁ ଏଡ଼ାଇ ପରବର୍ତ୍ତୀ ପ୍ରଦାନକାରୀଙ୍କୁ ଚେଷ୍ଟା କରେ। ଆପଣଙ୍କୁ କିଛି କରିବାକୁ ପଡ଼ିବ ନାହିଁ।

### "ମୁଁ ଜଣେ ପ୍ରଦାନକାରୀଙ୍କୁ କିପରି ବିଚ୍ଛିନ୍ନ କରିବି?"

ପ୍ରଦାନକାରୀକୁ ଯାଆନ୍ତୁ → ପ୍ରଦାନକାରୀଙ୍କ ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ → **ବିଚ୍ଛିନ୍ନ କରନ୍ତୁ** ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ।

### "ମୁଁ ମୋର ବର୍ତ୍ତମାନର API କୀଗୁଡ଼ିକ ବ୍ୟବହାର କରିପାରିବି କି?"

**ହଁ!** ଯଦି ଆପଣଙ୍କ ପାଖରେ ପୂର୍ବରୁ OpenAI, Anthropic, Google ଇତ୍ୟାଦି ପାଇଁ API କୀ ଅଛି, ତେବେ ଆପଣ ସେଗୁଡ଼ିକୁ OmniRoute ରେ ବ୍ୟବହାର କରିପାରିବେ। ପ୍ରଦାନକାରୀଙ୍କୁ ସଂଯୋଗ କରିବା ସମୟରେ କେବଳ ସେଗୁଡ଼ିକୁ ପେଷ୍ଟ କରନ୍ତୁ।
