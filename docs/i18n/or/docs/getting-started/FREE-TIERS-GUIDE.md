## ମାଗଣା ସ୍ତରଗୁଡ଼ିକ କ’ଣ?

ଅନେକ AI ପ୍ରଦାନକାରୀ କୌଣସି ନା କୌଣସି ରୂପରେ **ମାଗଣା ଆକ୍ସେସ୍** ପ୍ରଦାନ କରନ୍ତି। ପ୍ରଦାନକାରୀଙ୍କ ଉପରେ ନିର୍ଭର କରି, ଏହାର ଅର୍ଥ
ପ୍ରମାଣୀକରଣ-ବିହୀନ ଏଣ୍ଡପଏଣ୍ଟ, ପୁନରାବୃତ୍ତ କୋଟା, ହାର-ସୀମିତ କିନ୍ତୁ ସର୍ବାଧିକ ସୀମାହୀନ ଆକ୍ସେସ୍, ସାଇନ୍ଅପ୍ ଅନୁଦାନ,
ମାନୁଆଲ୍ ଅନୁମୋଦନ କିମ୍ବା ଏକ ଅସ୍ଥାୟୀ ପ୍ରଚାରମୂଳକ ଅଫର୍ ହୋଇପାରେ। କିଛି ବିକଳ୍ପ ପାଇଁ ଏକ ଆକାଉଣ୍ଟ, API କି,
କ୍ରେଡିଟ୍ କାର୍ଡ, KYC କିମ୍ବା ପ୍ରଦାନକାରୀ-ନିର୍ଦ୍ଦିଷ୍ଟ ସର୍ତ୍ତାବଳୀର ସ୍ୱୀକୃତି ଆବଶ୍ୟକ।

OmniRoute ଏହି ମାଗଣା ସ୍ତରଗୁଡ଼ିକୁ ଗୋଟିଏ ଏଣ୍ଡପଏଣ୍ଟରେ **ଏକତ୍ରିତ** କରେ। 10ଟି ଭିନ୍ନ ସେବାରେ ସାଇନ୍ଅପ୍ କରିବା ପରିବର୍ତ୍ତେ, ଆପଣ ସେଗୁଡ଼ିକୁ OmniRoute ସହିତ ସଂଯୋଗ କରନ୍ତି ଏବଂ ପ୍ରତ୍ୟେକ ଅନୁରୋଧ ପାଇଁ ସର୍ବୋତ୍ତମ ମାଗଣା ବିକଳ୍ପକୁ ସ୍ୱୟଂଚାଳିତ ଭାବେ ବାଛିବା ପାଇଁ `model: "auto"` ବ୍ୟବହାର କରନ୍ତି।

- ଗତି — ବର୍ତ୍ତମାନ କେଉଁ ପ୍ରଦାନକାରୀ ସବୁଠାରୁ ଦ୍ରୁତ?
- ଗୁଣବତ୍ତା — ଏହି କାର୍ଯ୍ୟ ପାଇଁ କେଉଁ ପ୍ରଦାନକାରୀ ସର୍ବୋତ୍ତମ?
- କ୍ଷମତା — କେଉଁ ପ୍ରଦାନକାରୀଙ୍କ ପାଖରେ କୋଟା ଅବଶିଷ୍ଟ ଅଛି?

### 3. ଟୋକେନ୍ ସଞ୍ଚୟ

OmniRouteର କମ୍ପ୍ରେସନ୍ ପାଇପ୍ଲାଇନ୍ ଯୋଗ୍ୟ ପ୍ରମ୍ପ୍ଟ ଏବଂ ଟୁଲ୍-ଆଉଟ୍ପୁଟ୍ ଟୋକେନ୍ଗୁଡ଼ିକୁ କମାଇପାରେ।
ପ୍ରକୃତ ସଞ୍ଚୟ ବିଷୟବସ୍ତୁ, ଚୟନିତ ଇଞ୍ଜିନ୍, ପ୍ରଦାନକାରୀଙ୍କ ହିସାବ ପଦ୍ଧତି ଏବଂ ବିଶ୍ୱସ୍ତତା
ସେଟିଂସ୍ ଉପରେ ନିର୍ଭର କରେ; କମ୍ପ୍ରେସନ୍ ପ୍ରତ୍ୟେକ ପ୍ରଦାନକାରୀଙ୍କ କୋଟାକୁ ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ ଗୁଣକରେ ବଢ଼ାଏ ନାହିଁ।

### 4. ଏକାଧିକ-ଆକାଉଣ୍ଟ ସମର୍ଥନ

ଯଦି ପ୍ରଦାନକାରୀଙ୍କ ସର୍ତ୍ତାବଳୀ ଏକାଧିକ ଆକାଉଣ୍ଟ କିମ୍ବା ପ୍ରମାଣପତ୍ରକୁ ଅନୁମତି ଦିଏ, OmniRoute ପ୍ରତ୍ୟେକ
ସଂଯୋଗକୁ ଏକ ପୃଥକ ରାଉଟିଂ ପ୍ରାର୍ଥୀ ଭାବେ ବିବେଚନା କରିପାରେ। ପ୍ରଦାନକାରୀଙ୍କ କୋଟା କିମ୍ବା ଆକ୍ସେସ୍ ନୀତିକୁ ଏଡ଼ାଇବା ପାଇଁ ଅତିରିକ୍ତ ଆକାଉଣ୍ଟ ସୃଷ୍ଟି କରନ୍ତୁ ନାହିଁ।

## ସାଧାରଣ ପ୍ରଶ୍ନ

### "ଏହା ପ୍ରକୃତରେ ମାଗଣା କି?"

କ୍ୟାଟାଲଗ୍ରେ ପ୍ରଦାନକାରୀଙ୍କ ଦ୍ୱାରା ପ୍ରକାଶିତ ସର୍ତ୍ତାବଳୀ ଏବଂ ପ୍ରକଳ୍ପ ଗବେଷଣା ରେକର୍ଡ କରାଯାଏ, କିନ୍ତୁ ଅଫର୍ଗୁଡ଼ିକ ପରିବର୍ତ୍ତିତ ହୋଇପାରେ।
ବ୍ୟବହାର ପୂର୍ବରୁ ପ୍ରଦାନକାରୀଙ୍କ ବର୍ତ୍ତମାନର ମୂଲ୍ୟ, କୋଟା, ଗୋପନୀୟତା ନୀତି ଏବଂ ଯୋଗ୍ୟତା ଯାଞ୍ଚ କରନ୍ତୁ।

### "ମାଗଣା ଟିୟର୍ ଶେଷ ହୋଇଯିବ କି?"

ପ୍ରତ୍ୟେକ ପ୍ରଦାନକାରୀ ହାର-ସୀମା ଲାଗୁ କରିପାରନ୍ତି, ମଡେଲ୍ ପରିବର୍ତ୍ତନ କରିପାରନ୍ତି, ଆକ୍ସେସ୍ ସ୍ଥଗିତ କରିପାରନ୍ତି କିମ୍ବା ଅଫ୍ଲାଇନ୍ ହୋଇପାରନ୍ତି। ଏକାଧିକ
ସଂଯୋଗ ଫଲ୍ବ୍ୟାକ୍ କଭରେଜ୍କୁ ଉନ୍ନତ କରେ, କିନ୍ତୁ ଏକ ଉପଲବ୍ଧ ମାଗଣା ରୁଟ୍ର ଗ୍ୟାରେଣ୍ଟି ଦିଏ ନାହିଁ।

### "ମୁଁ ଉତ୍ପାଦନ ପାଇଁ ମାଗଣା ପ୍ରଦାନକାରୀଙ୍କୁ ବ୍ୟବହାର କରିପାରିବି କି?"

କେବଳ ପ୍ରଦାନକାରୀଙ୍କ SLA, ଡାଟା ପରିଚାଳନା, ସୀମା ଏବଂ ସର୍ତ୍ତାବଳୀ ଆପଣଙ୍କ ଉତ୍ପାଦନ
ଆବଶ୍ୟକତା ପୂରଣ କରୁଥିଲେ। ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ୱର୍କଲୋଡ୍ ପାଇଁ ନିରୀକ୍ଷଣ କରାଯାଉଥିବା, ଚୁକ୍ତିଗତ ଭାବେ ଉପଯୁକ୍ତ ଫଲ୍ବ୍ୟାକ୍ ରହିବା ଉଚିତ।

### "ଏଥିରେ ଅସୁବିଧା କ’ଣ?"

ଏଥିରେ ଥିବା ବିନିମୟଗୁଡ଼ିକ ମଧ୍ୟରେ କଠୋର ସୀମା, ପ୍ରତୀକ୍ଷା ତାଲିକା, KYC, କ୍ରେଡିଟ୍-କାର୍ଡ ଯାଞ୍ଚ, ପ୍ରମ୍ପ୍ଟ ଉପରେ
ପ୍ରଶିକ୍ଷଣ, ଦୁର୍ବଳ ଗୋପନୀୟତା, SLAର ଅନୁପସ୍ଥିତି, ବାରମ୍ବାର ମଡେଲ୍ ପରିବର୍ତ୍ତନ, ଭୌଗୋଳିକ ପ୍ରତିବନ୍ଧକ, ଦେୟଯୁକ୍ତ ଅତିରିକ୍ତ ବ୍ୟବହାର କିମ୍ବା
ଆକାଉଣ୍ଟ-ନୀତି ସମ୍ବନ୍ଧୀୟ ବିପଦ ଅନ୍ତର୍ଭୁକ୍ତ ହୋଇପାରେ। OmniRoute ଉପଲବ୍ଧ ମେଟାଡାଟା ପ୍ରଦର୍ଶନ କରେ; କ’ଣ ସକ୍ଷମ କରିବେ ତାହା ଆପଣ ବାଛନ୍ତି।

### "ମୁଁ କିପରି ଅଧିକ ମାଗଣା କୋଟା ପାଇପାରିବି?"

1. ଅଧିକ ମାଗଣା ପ୍ରଦାନକାରୀଙ୍କୁ ସଂଯୋଗ କରନ୍ତୁ
2. ଉପଯୁକ୍ତ କମ୍ପ୍ରେସନ୍ ଇଞ୍ଜିନ୍ଗୁଡ଼ିକ ସକ୍ଷମ କରନ୍ତୁ ଏବଂ ଆପଣଙ୍କ ୱର୍କଲୋଡ୍ ପାଇଁ ସଞ୍ଚୟ ମାପନ୍ତୁ
3. ମାଗଣା/ଶସ୍ତା ପ୍ରଦାନକାରୀଙ୍କୁ ପ୍ରାଥମିକତା ଦେବା ପାଇଁ `auto/cheap` ବ୍ୟବହାର କରନ୍ତୁ
4. ପ୍ରଦାନକାରୀଙ୍କ ସର୍ତ୍ତାବଳୀ ଉଲ୍ଲଂଘନ ନ କରି ଅତିରିକ୍ତ ଅନୁମୋଦିତ ପ୍ରଦାନକାରୀ କିମ୍ବା ପରିଚୟପତ୍ର ଯୋଡ଼ନ୍ତୁ

### "ମାଗଣା ପ୍ରଦାନକାରୀଙ୍କ ଗୁଣବତ୍ତା ଖରାପ କି?"

ଅବଶ୍ୟ ନୁହେଁ। କିଛି ପ୍ରଦାନକାରୀ ଦେୟଯୁକ୍ତ ରୁଟ୍ଗୁଡ଼ିକ ମାଧ୍ୟମରେ ଉପଲବ୍ଧ ସମାନ ମଡେଲ୍ ପରିବାରଗୁଡ଼ିକୁ ପ୍ରଦାନ କରନ୍ତି,
କିନ୍ତୁ ସୀମା, ବିଳମ୍ବତା, ଗୋପନୀୟତା, ନିର୍ଭରଯୋଗ୍ୟତା ଏବଂ ମଡେଲ୍ ସଂସ୍କରଣ ଭିନ୍ନ ହୋଇପାରେ। ଗୁଣବତ୍ତାର ଏକ ସଙ୍କେତ ଭାବେ
ମାଗଣା ପ୍ରଦାନକାରୀ ରାଙ୍କିଙ୍ଗ୍ ପୃଷ୍ଠା ବ୍ୟବହାର କରନ୍ତୁ ଏବଂ ବାସ୍ତବରେ ପ୍ରଦାନ କରାଯାଉଥିବା ମଡେଲ୍ଟିକୁ ଯାଞ୍ଚ କରନ୍ତୁ।
