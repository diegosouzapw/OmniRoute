Web Cookie ପ୍ରଦାନକାରୀଗୁଡ଼ିକ OmniRouteକୁ API key ପରିବର୍ତ୍ତେ ଆପଣଙ୍କ ବର୍ତ୍ତମାନର ବ୍ରାଉଜର୍ ସେସନ୍ ମାଧ୍ୟମରେ ଏକ AI ସେବା ବ୍ୟବହାର କରିବାକୁ ଦିଅନ୍ତି। ଯେତେବେଳେ ଆପଣଙ୍କ ପାଖରେ କୌଣସି ସେବାର ୱେବସାଇଟ୍ ମାଧ୍ୟମରେ ପୂର୍ବରୁ ପ୍ରବେଶାଧିକାର ଥାଏ ଏବଂ OmniRoute ସେହି ପ୍ରମାଣୀକୃତ ସେସନ୍କୁ ବ୍ୟବହାର କରୁ ବୋଲି ଆପଣ ଚାହାନ୍ତି, ସେତେବେଳେ ଏଗୁଡ଼ିକ ଉପଯୋଗୀ ହୋଇଥାଏ।

API-key ପ୍ରଦାନକାରୀଙ୍କ ଠାରୁ ଭିନ୍ନ ଭାବରେ, Web Cookie ପ୍ରଦାନକାରୀମାନେ ଆପଣଙ୍କ ବ୍ରାଉଜର୍ ୱେବସାଇଟ୍କୁ ପଠାଉଥିବା ପରିଚୟପତ୍ର ବ୍ୟବହାର କରି ପ୍ରମାଣୀକରଣ କରନ୍ତି।

# ଆରମ୍ଭ କରିବା ପୂର୍ବରୁ

> **ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ:** ସବୁବେଳେ ଏକ **ସକ୍ରିୟ ନେଟୱର୍କ ଅନୁରୋଧ**ରୁ ପରିଚୟପତ୍ର କପି କରନ୍ତୁ, ଆପଣଙ୍କ ବ୍ରାଉଜର୍ର cookie ସଂରକ୍ଷଣରୁ **ନୁହେଁ**।

ଭୁଲ୍ ସ୍ଥାନରୁ cookies କପି କରିବା ଯୋଗୁଁ ଅନେକ ପ୍ରମାଣୀକରଣ ସମସ୍ୟା ସୃଷ୍ଟି ହୁଏ।

## Cookie Storageରୁ କପି କରନ୍ତୁ ନାହିଁ

ଅଧିକାଂଶ ବ୍ରାଉଜର୍ ନିମ୍ନଲିଖିତ ସ୍ଥାନରେ ସଂରକ୍ଷିତ cookies ଦେଖାନ୍ତି:

```
DevTools
→ Application (କିମ୍ବା Storage)
→ Cookies
```

ଏହି cookiesଗୁଡ଼ିକ ଠିକ୍ ଦେଖାଗଲେ ମଧ୍ୟ, ସେଗୁଡ଼ିକ:

- ପୁରୁଣା ହୋଇପାରେ
- ଅସମ୍ପୂର୍ଣ୍ଣ ହୋଇପାରେ
- କେବଳ ପ୍ରମାଣୀକୃତ ଅନୁରୋଧରେ ପଠାଯାଉଥିବା cookies ସେଥିରେ ନଥାଇପାରେ

ଏହି ମୂଲ୍ୟଗୁଡ଼ିକ ବୈଧ ଦେଖାଗଲେ ମଧ୍ୟ, ସେଗୁଡ଼ିକ ବ୍ୟବହାର କଲେ ପ୍ରମାଣୀକରଣ ବିଫଳ ହୋଇପାରେ।

## ଏକ ସକ୍ରିୟ ଅନୁରୋଧରୁ କପି କରନ୍ତୁ

ଏହା ପରିବର୍ତ୍ତେ, ଏକ ସଫଳ ଅନୁରୋଧରୁ cookies ବ୍ୟବହାର କରନ୍ତୁ:

```
DevTools
→ Network
→ ପୃଷ୍ଠାଟି Refresh କରନ୍ତୁ
→ ଏକ chat କିମ୍ବା conversation ଅନୁରୋଧ ଖୋଲନ୍ତୁ
→ Request Headers
→ Cookie
```

`Cookie` ଅନୁରୋଧ headerରେ ଆପଣଙ୍କ ବ୍ରାଉଜର୍ ସଫଳତାର ସହ ବ୍ୟବହାର କରିଥିବା ସଠିକ୍ ପ୍ରମାଣୀକରଣ ସୂଚନା ରହିଥାଏ।

ଅଧିକାଂଶ Web Cookie ପ୍ରଦାନକାରୀଙ୍କ ପାଇଁ, ଏହି ମୂଲ୍ୟକୁ OmniRouteରେ ପେଷ୍ଟ କରିବା ଉଚିତ।

# ସାଧାରଣ ସେଟଅପ୍

ଅଧିକାଂଶ Web Cookie ପ୍ରଦାନକାରୀଙ୍କ ପାଇଁ ସେଟଅପ୍ ପ୍ରକ୍ରିୟା ସମାନ ଅଟେ।

1. ପ୍ରଦାନକାରୀଙ୍କ ୱେବସାଇଟ୍ରେ ସାଇନ୍ ଇନ୍ କରନ୍ତୁ।
2. ବ୍ରାଉଜର୍ର Developer Tools ଖୋଲନ୍ତୁ।
3. **Network** ଟ୍ୟାବ୍ ଖୋଲନ୍ତୁ।
4. ପୃଷ୍ଠାଟି Refresh କରନ୍ତୁ।
5. ଏକ ପ୍ରମାଣୀକୃତ chat କିମ୍ବା conversation ଅନୁରୋଧ ଖୋଲନ୍ତୁ।
6. ଆବଶ୍ୟକ ପ୍ରମାଣୀକରଣ ପରିଚୟପତ୍ର କପି କରନ୍ତୁ।
7. OmniRoute ଖୋଲନ୍ତୁ।
8. **Providers → Add Provider**କୁ ଯାଆନ୍ତୁ।
9. ଆପଣଙ୍କ Web Cookie ପ୍ରଦାନକାରୀ ଚୟନ କରନ୍ତୁ।
10. ପରିଚୟପତ୍ରଗୁଡ଼ିକ ପେଷ୍ଟ କରନ୍ତୁ।
11. **Test Connection** କ୍ଲିକ୍ କରନ୍ତୁ।
12. ପ୍ରଦାନକାରୀଙ୍କୁ ସେଭ୍ କରନ୍ତୁ।

ଆବଶ୍ୟକ ସଠିକ୍ ପରିଚୟପତ୍ର ପ୍ରଦାନକାରୀଙ୍କ ଉପରେ ନିର୍ଭର କରେ।

# Web Cookie ପ୍ରଦାନକାରୀମାନେ କ’ଣ କରିପାରିବେ ଏବଂ କ’ଣ କରିପାରିବେ ନାହିଁ

Web Cookie ପ୍ରଦାନକାରୀମାନେ ଏକ ୱେବସାଇଟ୍ର chat ଇଣ୍ଟରଫେସ୍କୁ ପୁନଃବ୍ୟବହାର କରନ୍ତି। ସେମାନେ ଆଧିକାରିକ APIs ପରି ସମାନ କ୍ଷମତା ପ୍ରଦାନ କରନ୍ତି **ନାହିଁ**।

## ସମର୍ଥିତ

- ଆପଣଙ୍କ ବର୍ତ୍ତମାନର ବ୍ରାଉଜର୍ ସେସନ୍ ବ୍ୟବହାର କରି ପ୍ରମାଣୀକରଣ
- ଆପଣଙ୍କ ଆକାଉଣ୍ଟ୍ ମାଧ୍ୟମରେ ଉପଲବ୍ଧ modelsକୁ ପ୍ରବେଶ
- chat ପ୍ରତିକ୍ରିୟାଗୁଡ଼ିକୁ stream କରିବା
- କୌଣସି API key ଆବଶ୍ୟକ ନାହିଁ

## ସମର୍ଥିତ ନୁହେଁ

- Function calling
- Tool calling
- ସ୍ୱୟଂଚାଳିତ file editing
- Agentic IDE workflows
- କେବଳ APIରେ ଉପଲବ୍ଧ ବୈଶିଷ୍ଟ୍ୟ

ଏହା ଆଶା କରାଯାଉଥିବା ଆଚରଣ ଏବଂ ଏହା ଏକ bug **ନୁହେଁ**।

ଆପଣଙ୍କୁ tool execution, ସ୍ୱୟଂଚାଳିତ file editing କିମ୍ବା ଅନ୍ୟ agent workflows ଆବଶ୍ୟକ ହେଲେ, Web Cookie ପ୍ରଦାନକାରୀ ପରିବର୍ତ୍ତେ ଏକ **API-key ପ୍ରଦାନକାରୀ** ବ୍ୟବହାର କରନ୍ତୁ।

# ବୈଧତା ଯାଞ୍ଚ ସମ୍ବନ୍ଧୀୟ ସତର୍କତା

ଏକ ସଫଳ **Test Connection** କିମ୍ବା cookie ବୈଧତା ଯାଞ୍ଚ କେବଳ ଏତିକି ନିଶ୍ଚିତ କରେ ଯେ ପ୍ରଦାନ କରାଯାଇଥିବା ପରିଚୟପତ୍ରଗୁଡ଼ିକ ଆଶାକରାଯାଇଥିବା ଫର୍ମାଟ୍ରେ ଥିବା ପରି ଦେଖାଯାଉଛି।

Issue #7857 ସମାଧାନ ହେବା ପର୍ଯ୍ୟନ୍ତ, ଏକ ସଫଳ ବୈଧତା ଯାଞ୍ଚ ପ୍ରଦାନକାରୀ ସଫଳତାର ସହ ପ୍ରମାଣୀକରଣ କରିବେ ବୋଲି **ନିଶ୍ଚିତ କରେ ନାହିଁ**।

ପ୍ରମାଣୀକରଣ ଏବେ ମଧ୍ୟ ବିଫଳ ହେଲେ, ଆପଣ ବ୍ରାଉଜର୍ cookie ସଂରକ୍ଷଣ ପରିବର୍ତ୍ତେ ଏକ ସକ୍ରିୟ ନେଟୱର୍କ ଅନୁରୋଧରୁ ପରିଚୟପତ୍ର କପି କରିଥିଲେ କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ।

# ସମସ୍ୟା ସମାଧାନ

## ପ୍ରମାଣୀକରଣ ବିଫଳ ହୁଏ

ପରିଚୟପତ୍ରଗୁଡ଼ିକ ନିମ୍ନଲିଖିତ ସ୍ଥାନରୁ କପି କରାଯାଇଥିଲା କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ:

```
Network
→ Request Headers
→ Cookie
```

ଏବଂ ନିମ୍ନଲିଖିତ ସ୍ଥାନରୁ **ନୁହେଁ**:

```
Application
→ Cookies
```

## Cookie ବ୍ରାଉଜର୍ରେ କାମ କରେ କିନ୍ତୁ OmniRouteରେ କରେ ନାହିଁ

କେତେକ ପ୍ରଦାନକାରୀ ଏପରି cookies ସାମିଲ କରନ୍ତି ଯାହା କେବଳ ପ୍ରମାଣୀକୃତ ଅନୁରୋଧ ସମୟରେ ପଠାଯାଏ।

ଏକ conversation ସଫଳତାର ସହ ଖୋଲିବା ପରେ ଏକ ନୂତନ ନେଟୱର୍କ ଅନୁରୋଧରୁ ପରିଚୟପତ୍ରଗୁଡ଼ିକୁ ପୁନର୍ବାର କପି କରନ୍ତୁ।

---

## ସେସନ୍ର ଅବଧି ସମାପ୍ତ ହୋଇଛି

Web Cookie ପ୍ରଦାନକାରୀମାନେ ଆପଣଙ୍କ ବର୍ତ୍ତମାନର ବ୍ରାଉଜର୍ ସେସନ୍ ବ୍ୟବହାର କରନ୍ତି।

ଆପଣଙ୍କ ବ୍ରାଉଜର୍ ସେସନ୍ର ଅବଧି ସମାପ୍ତ ହେଲେ କିମ୍ବା ଆପଣ ସାଇନ୍ ଆଉଟ୍ କଲେ, ଆପଣଙ୍କୁ ଏକ ନୂତନ ପରିଚୟପତ୍ର ସେଟ୍ କପି କରିବାକୁ ପଡ଼ିବ।

Issue #7857 ସମାଧାନ ହେବା ପର୍ଯ୍ୟନ୍ତ, ବୈଧତା ଯାଞ୍ଚରେ ସଫଳ ହେବା ପ୍ରମାଣୀକରଣ ଅନୁରୋଧ ସଫଳ ହେବ ବୋଲି ନିଶ୍ଚିତ କରେ ନାହିଁ।

ଅଧିକ ସମସ୍ୟା ସମାଧାନ କରିବା ପୂର୍ବରୁ ଏକ ନୂତନ ପ୍ରମାଣୀକୃତ ଅନୁରୋଧରୁ ଆପଣଙ୍କ ପରିଚୟପତ୍ରଗୁଡ଼ିକୁ ପୁନର୍ବାର କପି କରନ୍ତୁ।

# ସର୍ବୋତ୍ତମ ଅଭ୍ୟାସ

- ଏକ ନୂତନ ପ୍ରମାଣୀକୃତ ଅନୁରୋଧରୁ ପରିଚୟପତ୍ର କପି କରନ୍ତୁ।
- ପୁରୁଣା cookies ପୁନଃବ୍ୟବହାର କରିବାରୁ ବିରତ ରୁହନ୍ତୁ।
- Web Cookie ପ୍ରଦାନକାରୀ ବ୍ୟବହାର କରୁଥିବା ସମୟରେ ଆପଣଙ୍କ ବ୍ରାଉଜର୍ ସେସନ୍କୁ ସକ୍ରିୟ ରଖନ୍ତୁ।
- କପି କରାଯାଇଥିବା cookiesକୁ ସମ୍ବେଦନଶୀଳ ପରିଚୟପତ୍ର ଭାବରେ ବିବେଚନା କରନ୍ତୁ।
- ଆପଣଙ୍କୁ function calling କିମ୍ବା agent workflows ଆବଶ୍ୟକ ହେଲେ API-key ପ୍ରଦାନକାରୀ ବ୍ୟବହାର କରନ୍ତୁ।
