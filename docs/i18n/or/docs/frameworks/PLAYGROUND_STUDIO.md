## ସାରାଂଶ

Playground Studio `/dashboard/playground`କୁ ଏକ ସରଳ Monaco-ଆଧାରିତ ଏଡିଟର୍ରୁ
ଏକ ସମ୍ପୂର୍ଣ୍ଣ ବୈଶିଷ୍ଟ୍ୟଯୁକ୍ତ ପରୀକ୍ଷଣ କାର୍ଯ୍ୟକ୍ଷେତ୍ରରେ ପରିଣତ କରେ। ଏହା ପୁରୁଣା `page.tsx`କୁ ଏକ `PlaygroundStudio`

## ଟ୍ୟାବ୍ଗୁଡ଼ିକ

### ଚାଟ୍ ଟ୍ୟାବ୍

`ChatPlayground.tsx`କୁ ଏକ ମଲ୍ଟି-ଟର୍ନ ଷ୍ଟ୍ରିମିଂ ୱର୍କବେଞ୍ଚ୍ରେ ବିକଶିତ କରେ:

- `MarkdownMessage.tsx` ମାଧ୍ୟମରେ ସମ୍ପୂର୍ଣ୍ଣ markdown ରେଣ୍ଡରିଂ (କୋଡ୍ ବ୍ଲକ୍, ଟେବୁଲ୍, ତାଲିକା, ଲିଙ୍କ୍)।
- ସହଭାଗୀ କନଫିଗ୍ ପେନ୍ରୁ ନିଆଯାଇଥିବା ସିଷ୍ଟମ୍ ପ୍ରମ୍ପ୍ଟ।
- ପ୍ରତି ବାର୍ତ୍ତା ପାଇଁ ଟୋକନ୍/ଖର୍ଚ୍ଚ (ପ୍ରମ୍ପ୍ଟ + କମ୍ପ୍ଲିସନ୍ ଟୋକନ୍)।
- ଶେଷ ପ୍ରତିକ୍ରିୟାକୁ ପୁନଃ ସୃଷ୍ଟି କରେ।
- SSE ଷ୍ଟ୍ରିମିଂ ସହିତ `POST /v1/chat/completions`କୁ ପଠାଏ।

### ତୁଳନା ଟ୍ୟାବ୍

ଏକ ପ୍ରକ୍ସି ପାଇଁ ମୁଖ୍ୟ ପାର୍ଥକ୍ୟକାରୀ ବୈଶିଷ୍ଟ୍ୟ: ସର୍ବାଧିକ **4ଟି ମଡେଲ୍ରେ ସମାନ୍ତରାଳ ଭାବେ** 1ଟି ପ୍ରମ୍ପ୍ଟ ଚଲାନ୍ତୁ।

- ସର୍ବାଧିକ 4ଟି କଲମ୍, ପ୍ରତ୍ୟେକଟି `/v1/chat/completions`ରୁ ସ୍ୱାଧୀନ ଭାବେ ଷ୍ଟ୍ରିମ୍ କରେ।
- କଲମ୍ ଯୋଡ଼ିବା ପାଇଁ `+ ମଡେଲ୍ ଯୋଡ଼ନ୍ତୁ` ବଟନ୍ (Cmd+K ସର୍ଟକଟ୍)।
- `ସବୁ ଚଲାନ୍ତୁ ▶` `Promise.all` + ପ୍ରତି-କଲମ୍ `AbortController` ମାଧ୍ୟମରେ ସମସ୍ତ ଷ୍ଟ୍ରିମ୍କୁ ଏକାସାଙ୍ଗରେ ଟ୍ରିଗର୍ କରେ।
- ଗ୍ଲୋବାଲ୍ **ସବୁ ବାତିଲ୍ କରନ୍ତୁ** ପ୍ରତ୍ୟେକ ଚାଲୁଥିବା ଷ୍ଟ୍ରିମ୍କୁ ବନ୍ଦ କରେ।
- ପ୍ରତି-କଲମ୍ `ProviderMetrics` ବାସ୍ତବ ସମୟରେ TTFT, TPS, ଟୋକନ୍ ଏବଂ ଆନୁମାନିକ ଖର୍ଚ୍ଚ ଦେଖାଏ।
- ମେଟ୍ରିକ୍ସକୁ **"କ୍ଲାଏଣ୍ଟ-ପାର୍ଶ୍ୱ ଆକଳନ"** (D12) ଭାବେ ଲେବଲ୍ କରାଯାଇଛି — ପ୍ରଥମ SSE ଚଙ୍କ୍ରୁ ମାପାଯାଏ।

### API ଟ୍ୟାବ୍

ଉନ୍ନତ ବ୍ୟବହାରକାରୀଙ୍କ ପାଇଁ ମୂଳ Monaco ଏଡିଟର୍ର 100% ସଂରକ୍ଷଣ କରେ (D14):

- 10ଟି ଏଣ୍ଡପଏଣ୍ଟ: ଚାଟ୍ କମ୍ପ୍ଲିସନ୍, କମ୍ପ୍ଲିସନ୍, ଏମ୍ବେଡିଂ, ଇମେଜ୍, ଅଡିଓ, ସ୍ପିଚ୍, ଟ୍ରାନ୍ସକ୍ରିପ୍ସନ୍, ମଡରେସନ୍, ରିର୍ୟାଙ୍କ୍, ସର୍ଚ୍ଚ।
- ମଲ୍ଟିମୋଡାଲ୍ ଫାଇଲ୍ ଅପଲୋଡ୍।
- ବାସ୍ତବ-ସମୟ ଆଉଟପୁଟ୍ ସହିତ SSE ଷ୍ଟ୍ରିମିଂ।
- `ApiTab.tsx` ଭାବେ ଆବୃତ (ଲେଜି-ଲୋଡ୍ କରାଯାଇଛି, `ssr: false`)।

### ନିର୍ମାଣ ଟ୍ୟାବ୍

ଟୁଲ୍/ଫଙ୍କସନ୍ କଲିଂ ଏବଂ ସଂରଚିତ ଆଉଟପୁଟ୍ UI:

- `ToolsBuilder.tsx` — ପ୍ରତି ଟୁଲ୍ ପାଇଁ JSON ସ୍କିମା ଏଡିଟର୍ ସହିତ `tools[]` ଯୋଡ଼ନ୍ତୁ/ସମ୍ପାଦନା କରନ୍ତୁ/ଅପସାରଣ କରନ୍ତୁ।
  `ToolDefinitionSchema` (Zod) ମାଧ୍ୟମରେ ପାରାମିଟର୍ଗୁଡ଼ିକୁ ବୈଧତା ଯାଞ୍ଚ କରେ।
- `StructuredOutputEditor.tsx` — JSON ମୋଡ୍ + JSON ସ୍କିମା ଏଡିଟର୍ ଟୋଗଲ୍ କରନ୍ତୁ।
  `StructuredOutputSchema` (Zod) ମାଧ୍ୟମରେ ସ୍କିମା ବିପକ୍ଷରେ ପ୍ରତିକ୍ରିୟାର ବୈଧତା ଯାଞ୍ଚ କରେ।
- `tools[]` ଏବଂ/କିମ୍ବା `response_format` ସହିତ `/v1/chat/completions`କୁ ଅନୁରୋଧ ପଠାଏ।

## ପ୍ରମ୍ପ୍ଟ ଉନ୍ନତକାରୀ

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. ମୋଡାଲ୍ "କୋଟା ବ୍ୟବହାର ହେବ" ବୋଲି ଚେତାବନୀ ଦିଏ।
2. ନିଶ୍ଚିତ କଲେ, ଏହା ରୁଟ୍କୁ `{ system, prompt, model, tone }` ପଠାଏ।
3. ରୁଟ୍ଟି `promptImprover.META_SYSTEM_PROMPT` ସହ ଆଭ୍ୟନ୍ତରୀଣ ଭାବେ `/v1/chat/completions`କୁ କଲ୍ କରେ।
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` ଫେରାଏ।

## ଷ୍ଟ୍ରିମ୍ ମେଟ୍ରିକ୍ସ

`useStreamMetrics.ts` + `streamMetrics.ts` (ବିଶୁଦ୍ଧ ଫଙ୍କସନ୍):

- `start()` — ଅନୁରୋଧ ଆରମ୍ଭ ସମୟ ରେକର୍ଡ କରେ।
- `onFirstChunk()` — TTFT ରେକର୍ଡ କରେ।
- `onChunk(n)` — କମ୍ପ୍ଲିସନ୍ ଟୋକନ୍ ସଂଖ୍ୟା ସଞ୍ଚୟ କରେ।
- `finish(usage?)` — ଅନ୍ତିମ ମେଟ୍ରିକ୍ସ ଗଣନା କରେ: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`।
- `src/lib/playground/types.ts`ରେ ଥିବା ସ୍ଥିର ଟେବୁଲ୍ରୁ ମୂଲ୍ୟ ନିର୍ଦ୍ଧାରଣ (`"ଆନୁମାନିକ"` ଭାବେ ଚିହ୍ନିତ — D13)।
