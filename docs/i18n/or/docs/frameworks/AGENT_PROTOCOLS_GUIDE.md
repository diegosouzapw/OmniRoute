## 1. A2A — ଏଜେଣ୍ଟରୁ ଏଜେଣ୍ଟ

**ସ୍ପେସିଫିକେସନ୍:** [A2A v0.3](https://a2a-protocol.org)
**OmniRoute ଏଣ୍ଡପଏଣ୍ଟ:** `POST /a2a` (JSON-RPC 2.0)
**ଏଜେଣ୍ଟ କାର୍ଡ:** `GET /.well-known/agent.json`

### କେତେବେଳେ ବ୍ୟବହାର କରିବେ

- OmniRoute ସମକକ୍ଷମାନଙ୍କ ମଧ୍ୟରୁ ଗୋଟିଏ ହୋଇଥିବା ଏକ ବହୁ-ଏଜେଣ୍ଟ ସିଷ୍ଟମ୍ ତିଆରି କରିବା ସମୟରେ
- Google ADK କିମ୍ବା ସାଧାରଣ ଏଜେଣ୍ଟ ମେଶ୍ ଭଳି ଫ୍ରେମ୍ୱାର୍କରେ ଥିବା ଏଜେଣ୍ଟମାନଙ୍କ ପାଇଁ OmniRouteର ରାଉଟିଂ ବୁଦ୍ଧିମତ୍ତା (`smart-routing`, `quota-management` ଇତ୍ୟାଦି) ଉନ୍ମୁକ୍ତ କରିବା ସମୟରେ
- ଏକ ମାନକ ଆବିଷ୍କାର + ଆହ୍ୱାନ ଇଣ୍ଟରଫେସ୍ ପଛରେ OmniRouteକୁ ଆବୃତ କରିବା ସମୟରେ

### ପଦ୍ଧତିଗୁଡ଼ିକ

- `message/send` — ଏକ ସନ୍ଦେଶ ଦାଖଲ କରନ୍ତୁ, ସମକାଳୀନ ପ୍ରତିକ୍ରିୟା ପାଆନ୍ତୁ
- `message/stream` — ଦାଖଲ କରନ୍ତୁ + SSE ମାଧ୍ୟମରେ ଷ୍ଟ୍ରିମ୍ ହୋଇଥିବା ପ୍ରଗତି ଇଭେଣ୍ଟଗୁଡ଼ିକ ପାଆନ୍ତୁ
- `tasks/get` — ID ଅନୁଯାୟୀ କାର୍ଯ୍ୟ ପଢ଼ନ୍ତୁ
- `tasks/cancel` — ଚାଲୁଥିବା କାର୍ଯ୍ୟ ବାତିଲ୍ କରନ୍ତୁ

### ଅନ୍ତର୍ନିର୍ମିତ ଦକ୍ଷତା (6)

- `smart-routing` — ସର୍ବୋତ୍ତମ ସଂଯୋଜନ ମାଧ୍ୟମରେ ଏକ ପ୍ରମ୍ପ୍ଟକୁ ରାଉଟ୍ କରନ୍ତୁ
- `quota-management` — ପ୍ରତ୍ୟେକ ପ୍ରଦାନକାରୀ ପାଇଁ କୋଟା ସ୍ଥିତି ରିପୋର୍ଟ କରନ୍ତୁ
- `provider-discovery` — କ୍ଷମତାଗୁଡ଼ିକ ସହିତ ଇନ୍ଷ୍ଟଲ୍ ହୋଇଥିବା ପ୍ରଦାନକାରୀମାନଙ୍କୁ ତାଲିକାଭୁକ୍ତ କରନ୍ତୁ
- `cost-analysis` — ଏକ ଅନୁରୋଧ/ବାର୍ତ୍ତାଳାପର ଖର୍ଚ୍ଚ ଆକଳନ କରନ୍ତୁ
- `health-report` — ପ୍ରତ୍ୟେକ ପ୍ରଦାନକାରୀ ପାଇଁ ବ୍ରେକର୍/କୁଲ୍ଡାଉନ୍/ଲକ୍ଆଉଟ୍ ସ୍ଥିତି ଏକତ୍ର କରନ୍ତୁ
- `list-capabilities` — ଏଜେଣ୍ଟର ଉପଲବ୍ଧ ଦକ୍ଷତା ଏବଂ ମେଟାଡାଟା ଗଣନା କରନ୍ତୁ

### ବିସ୍ତୃତ ବିବରଣୀ

ପରିବହନ ବିବରଣୀ, ଏଜେଣ୍ଟ କାର୍ଡର ଗଠନ, କାର୍ଯ୍ୟ TTL ବିନ୍ୟାସ ଏବଂ ନୂଆ ଦକ୍ଷତା ଯୋଡ଼ିବା ପାଇଁ ଟେମ୍ପ୍ଲେଟ୍ ବିଷୟରେ ଜାଣିବାକୁ [A2A-SERVER.md](./A2A-SERVER.md) ଦେଖନ୍ତୁ।

## 2. ACP — CLI ଏଜେଣ୍ଟ ରେଜିଷ୍ଟ୍ରି

**OmniRoute ଏଣ୍ଡପଏଣ୍ଟ:** `GET /api/acp/agents`
**ସୋର୍ସ:** `src/lib/acp/{index,manager,registry}.ts`

### ଏହା କ’ଣ

ACP ହେଉଛି OmniRouteର **ସ୍ଥାନୀୟ CLI ଏଜେଣ୍ଟ ତାଲିକା**। ଏହା ହୋଷ୍ଟରେ କେଉଁ କୋଡିଂ CLIଗୁଡ଼ିକ ଇନଷ୍ଟଲ୍ ହୋଇଛି (Cursor, Cline, Claude Code, Codex CLI, Continue ଇତ୍ୟାଦି) ତାହା ଚିହ୍ନଟ କରେ, ସେଗୁଡ଼ିକର ସଂସ୍କରଣ ନିର୍ଦ୍ଧାରଣ କରେ ଏବଂ ଡ୍ୟାସବୋର୍ଡରେ ପ୍ରଦର୍ଶନ କରେ, ଯାହାଦ୍ୱାରା ବ୍ୟବହାରକାରୀ ପ୍ରତ୍ୟେକ CLIକୁ OmniRoute ଆଡ଼କୁ ନିର୍ଦ୍ଦେଶିତ କରିପାରିବେ।

ଏହା କୌଣସି ବାହ୍ୟ ପ୍ରୋଟୋକଲ୍ ନୁହେଁ — ଏହା ଏକ ଆଭ୍ୟନ୍ତରୀଣ ରେଜିଷ୍ଟ୍ରି, ଯାହା "CLI Tools" UI ଏବଂ CLI ଫିଙ୍ଗରପ୍ରିଣ୍ଟ ଟ୍ରାକିଂକୁ ଶକ୍ତି ଯୋଗାଏ ([CLI-TOOLS.md](../reference/CLI-TOOLS.md) ଦେଖନ୍ତୁ)।

### ଏହା କ’ଣ କରେ

- ଇନଷ୍ଟଲ୍ ହୋଇଥିବା CLI ବାଇନେରୀଗୁଡ଼ିକ ପାଇଁ ହୋଷ୍ଟକୁ ଯାଞ୍ଚ କରେ (OS ଅନୁସାରେ `which` / `where` ବ୍ୟବହାର କରେ)
- ପ୍ରତ୍ୟେକ CLIର ସଂସ୍କରଣ ପଢ଼େ (`<bin> --version` କଲ୍ କରେ)
- ଇଚ୍ଛାନୁସାରେ ବ୍ୟବହାରକାରୀ-ପରିଭାଷିତ କଷ୍ଟମ୍ ଏଜେଣ୍ଟଗୁଡ଼ିକୁ ଗ୍ରହଣ କରେ (ବାଇନେରୀ ପଥ + ସଂସ୍କରଣ ଯାଞ୍ଚ + ସ୍ପନ୍ ଆର୍ଗୁମେଣ୍ଟ)
- କଷ୍ଟମ୍ ଏଜେଣ୍ଟଗୁଡ଼ିକୁ ସେଟିଂସ୍ରେ ସ୍ଥାୟୀ ଭାବେ ସଂରକ୍ଷଣ କରେ
- ଡ୍ୟାସବୋର୍ଡକୁ ଏକୀକୃତ ତାଲିକା ଫେରାଏ

### REST API

| ଏଣ୍ଡପଏଣ୍ଟ         | ପଦ୍ଧତି | ବର୍ଣ୍ଣନା                                                                          | ପ୍ରମାଣୀକରଣ |
| ----------------- | ------ | --------------------------------------------------------------------------------- | ---------- |
| `/api/acp/agents` | GET    | ଚିହ୍ନଟ ହୋଇଥିବା + କଷ୍ଟମ୍ ଏଜେଣ୍ଟଗୁଡ଼ିକର ତାଲିକା (ଇନଷ୍ଟଲ୍ ହୋଇଥିବା/ମୋଟ ସଂଖ୍ୟା)         | API କୀ     |
| `/api/acp/agents` | POST   | କଷ୍ଟମ୍ ଏଜେଣ୍ଟ ଯୋଡ଼ନ୍ତୁ/ଅପଡେଟ୍ କରନ୍ତୁ/ଅପସାରଣ କରନ୍ତୁ (ବଡିରେ ଆକ୍ସନ୍ ଡିସ୍କ୍ରିମିନେଟର୍) | API କୀ     |

POST ପାଇଁ ବଡିର ଗଠନ (`src/app/api/acp/agents/route.ts`ରେ `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### ବ୍ୟବହାର ପରିସ୍ଥିତି

- ଡ୍ୟାସବୋର୍ଡର "CLI Tools" ପୃଷ୍ଠା କ’ଣ ଇନଷ୍ଟଲ୍ ହୋଇଛି ତାହା ତାଲିକାଭୁକ୍ତ କରେ ଏବଂ ପ୍ରତ୍ୟେକକୁ OmniRoute ଆଡ଼କୁ ନିର୍ଦ୍ଦେଶିତ କରିବାରେ ଆପଣଙ୍କୁ ସାହାଯ୍ୟ କରେ
- କଷ୍ଟମ୍ ଏଜେଣ୍ଟଗୁଡ଼ିକ ଉନ୍ନତ ବ୍ୟବହାରକାରୀଙ୍କୁ ଏପରି ଆଭ୍ୟନ୍ତରୀଣ/ମାଲିକାନାଧୀନ CLI ପଞ୍ଜୀକରଣ କରିବାକୁ ଦିଅନ୍ତି, ଯାହା ବିଷୟରେ OmniRoute ଡିଫଲ୍ଟ ଭାବେ ଜାଣେ ନାହିଁ
- ଚିହ୍ନଟ ଫଳାଫଳ `cli-tools` ଫିଙ୍ଗରପ୍ରିଣ୍ଟ ମ୍ୟାଟ୍ରିକ୍ସକୁ ତଥ୍ୟ ଯୋଗାଏ

### କେତେବେଳେ ACP ବ୍ୟବହାର କରିବେ ନାହିଁ

- ACP କାର୍ଯ୍ୟଗୁଡ଼ିକୁ _ଚଲାଏ_ ନାହିଁ। ଏହା କେବଳ CLIଗୁଡ଼ିକୁ ଚିହ୍ନଟ + ବିନ୍ୟାସ କରେ। ପ୍ରକୃତରେ ଏକ CLI ଆହ୍ୱାନ କରିବାକୁ, OmniRoute ପ୍ରଦାନ କରୁଥିବା ପରିବେଶ ଭେରିଏବଲ୍ଗୁଡ଼ିକ (`OPENAI_BASE_URL`, `OPENAI_API_KEY` ଇତ୍ୟାଦି) ସହିତ ଆପଣ ନିଜେ ଏହାକୁ ଚାଲୁ କରନ୍ତୁ।

## 3. କ୍ଲାଉଡ୍ ଏଜେଣ୍ଟ

**OmniRoute ଏଣ୍ଡପଏଣ୍ଟଗୁଡ଼ିକ:** `/api/v1/agents/tasks/*` (ଜୀବନଚକ୍ର) + `/api/cloud/*` (ଆଭ୍ୟନ୍ତରୀଣ ସଂଯୋଜନ)
**ସୋର୍ସ:** `src/lib/cloudAgent/`

### ଏହା କ’ଣ

ତୃତୀୟ-ପକ୍ଷ କ୍ଲାଉଡ୍ କୋଡିଂ ଏଜେଣ୍ଟଗୁଡ଼ିକ ଉପରେ ଏକ ଏକୀକୃତ ଇଣ୍ଟରଫେସ୍। ଆପଣ ଏକ ପ୍ରମ୍ପ୍ଟ + ରିପୋ URL ଦାଖଲ କରନ୍ତି, OmniRoute ଏହାକୁ ଉପଯୁକ୍ତ କ୍ଲାଉଡ୍ ଏଜେଣ୍ଟକୁ ପଠାଏ, ସ୍ଥିତି ପୋଲ୍ କରେ ଏବଂ ଫଳାଫଳ ଫେରାଏ।

### ସମର୍ଥିତ ଏଜେଣ୍ଟଗୁଡ଼ିକ (4, ସମସ୍ତେ `src/lib/cloudAgent/agents/`ରେ ନିଶ୍ଚିତ ହୋଇଛନ୍ତି)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### ଜୀବନଚକ୍ର

```
POST /api/v1/agents/tasks
  → ପ୍ରତ୍ୟେକ ଏଜେଣ୍ଟ କ୍ଲାସ୍ ପାଇଁ BaseAgent.createTask()
  → ବାହ୍ୟ ସେବା କାର୍ଯ୍ୟ ଆରମ୍ଭ କରେ
  → DBରେ କାର୍ଯ୍ୟ ଧାଡ଼ି ସୃଷ୍ଟି ହୁଏ (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → ପ୍ରଦାନକାରୀଠାରୁ ବିଳମ୍ବିତ ସ୍ଥିତି ସିଙ୍କ୍
  → ବର୍ତ୍ତମାନର ସ୍ଥିତି + ଯୋଜନା + କାର୍ଯ୍ୟକଳାପ ଲଗ୍ ଫେରାଏ
  ↓
POST /api/v1/agents/tasks/[id]   (ଆକ୍ସନ୍: "approve" | "message" | "cancel")
  → ପ୍ରଦାନକାରୀଙ୍କୁ ଅଗ୍ରସର କରେ (କିମ୍ବା ସ୍ଥାନୀୟ ଭାବେ ବାତିଲ୍ ଚିହ୍ନିତ କରେ)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → ସ୍ଥାନୀୟ ବାତିଲ୍
```

### ପ୍ରମାଣୀକରଣ

⚠️ **ସମସ୍ତ `/api/v1/agents/tasks/*` ଏଣ୍ଡପଏଣ୍ଟ ପାଇଁ ପରିଚାଳନା ପ୍ରମାଣୀକରଣ ଆବଶ୍ୟକ** (କମିଟ୍ `588a0333`)। v3.8.0ଠାରୁ କେବଳ Bearer ବ୍ୟବହାର କରୁଥିବା କଲର୍ମାନେ 401 ପାଆନ୍ତି।

### ବିସ୍ତୃତ ବିଶ୍ଳେଷଣ

`CloudAgentBase` ଚୁକ୍ତି, ପ୍ରତ୍ୟେକ ଏଜେଣ୍ଟର ବିଶେଷତା, ସ୍କିମା ବିବରଣୀ ଏବଂ କ୍ରେଡେନ୍ସିଆଲ୍ ସଂଯୋଜନ ଏଣ୍ଡପଏଣ୍ଟଗୁଡ଼ିକ ପାଇଁ [CLOUD_AGENT.md](./CLOUD_AGENT.md) ଦେଖନ୍ତୁ।

## ଇଣ୍ଟିଗ୍ରେସନ୍ ଉଦାହରଣ

### OmniRouteର A2A କ୍ଷମତାଗୁଡ଼ିକ ଆବିଷ୍କାର କରନ୍ତୁ

```bash
curl http://localhost:20128/.well-known/agent.json
```

ସମସ୍ତ 6ଟି ସ୍କିଲ୍, ଟ୍ରାନ୍ସପୋର୍ଟ ଏବଂ ଭର୍ସନ୍ ସହିତ Agent Card ଫେରାଏ।

### OmniRouteକୁ ଏକ A2A ଏଜେଣ୍ଟ ଭାବରେ କଲ୍ କରନ୍ତୁ

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### ACP ମାଧ୍ୟମରେ ଇନ୍ଷ୍ଟଲ୍ ହୋଇଥିବା CLI ଏଜେଣ୍ଟଗୁଡ଼ିକର ତାଲିକା ଦେଖନ୍ତୁ

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### ଏକ କଷ୍ଟମ୍ CLI ଏଜେଣ୍ଟ ଯୋଡ଼ନ୍ତୁ

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

curl -X POST http://localhost:20128/api/v1/agents/tasks \
