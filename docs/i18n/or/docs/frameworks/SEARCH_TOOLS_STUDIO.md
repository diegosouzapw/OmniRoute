## ଟ୍ୟାବ୍ଗୁଡ଼ିକ

### ସର୍ଚ୍ଚ ଟ୍ୟାବ୍

ବିଦ୍ୟମାନ `SearchForm` + `ResultsPanel` + `RerankPanel`କୁ ଏକ ଟ୍ୟାବ୍ ଭାବେ ବିକଶିତ କରେ:

- କ୍ୱେରୀ → ଫଳାଫଳ (ଶୀର୍ଷକ, URL, ସଂକ୍ଷିପ୍ତ ବର୍ଣ୍ଣନା, ପ୍ରାସଙ୍ଗିକତା ସ୍କୋର୍)।
- ବିନ୍ୟାସ ପେନ୍ରେ ପ୍ରଦାନକାରୀ ମେଟାଡାଟା (ମୂଲ୍ୟ, କୋଟା, ସ୍ଥିତି)।
- ପୁନଃକ୍ରମାଙ୍କନ ବିଭାଗ: ଏକ ପୁନଃକ୍ରମାଙ୍କନ ମଡେଲ୍ ବାଛନ୍ତୁ, ଫଳାଫଳକୁ ପୁନଃକ୍ରମିତ କରନ୍ତୁ, `positionDelta` ଦେଖାନ୍ତୁ।
- କୌଣସି ସର୍ଚ୍ଚ ପ୍ରଦାନକାରୀ ବିନ୍ୟାସିତ ହୋଇନଥିଲେ CTA ସହିତ ଖାଲି ସ୍ଥିତି।
- `SearchHistory.tsx` ମାଧ୍ୟମରେ ସର୍ଚ୍ଚ ଇତିହାସ।
- `POST /v1/search`କୁ କଲ୍ କରେ (ବିଦ୍ୟମାନ ଏଣ୍ଡପଏଣ୍ଟ୍, କୌଣସି ପରିବର୍ତ୍ତନ ନାହିଁ)।

### ସ୍କ୍ରାପ୍ ଟ୍ୟାବ୍

`POST /v1/web/fetch` ମାଧ୍ୟମରେ ଏକ URLରୁ ବିଷୟବସ୍ତୁ ନିଷ୍କାସନ ପାଇଁ ନୂଆ ଟ୍ୟାବ୍ (ଯୋଜନା 05ରେ ସୃଷ୍ଟି ହୋଇଛି):

- ଇନ୍ପୁଟ୍: URL + ସମ୍ପୂର୍ଣ୍ଣ-ପୃଷ୍ଠା ଟଗଲ୍ + ଫର୍ମାଟ୍ ଚୟନକାରୀ (markdown / text / HTML)।
- ଦାଖଲ → ଆଣନ୍ତୁ → `ScrapeResult.tsx` ରେଣ୍ଡର୍ କରନ୍ତୁ।
- `ScrapeResult` markdown ପୂର୍ବାବଲୋକନ + raw ଟଗଲ୍ ରେଣ୍ଡର୍ କରେ।
- ସୀମା: ଯଦି ପ୍ରତିକ୍ରିୟା ବଡି **256 KB**ରୁ ବଡ଼ ହୁଏ, UI `(ସଂକ୍ଷିପ୍ତ କରାଯାଇଛି, raw ଦେଖନ୍ତୁ)` ଦେଖାଏ ଏବଂ ଏକ Monaco ମୋଡାଲ୍ରେ raw ଖୋଲେ (D21)।
- ମେଟାଡାଟା ପ୍ୟାନେଲ୍: ପ୍ରଦାନକାରୀ (firecrawl/jina-reader/tavily-search/tinyfish/nimble-search/anysearch-search), ବିଳମ୍ବତା, ମୂଲ୍ୟ, ପ୍ରତିକ୍ରିୟା ଆକାର, ଲିଙ୍କ୍ ସଂଖ୍ୟା।
- `useScrapeFetch.ts` ହୁକ୍ ବ୍ୟବହାର କରେ।

### ତୁଳନା ଟ୍ୟାବ୍

ସର୍ବାଧିକ **4 ପ୍ରଦାନକାରୀଙ୍କ** ମଧ୍ୟରେ ସମାନ କ୍ୱେରୀ/URLକୁ ସମାନ୍ତରାଳ ଭାବେ ଚଲାଏ (D22):

- ପ୍ରତ୍ୟେକ ପ୍ରଦାନକାରୀ ପାଇଁ ପାଖାପାଖି ସ୍ତମ୍ଭ।
- ମେଟ୍ରିକ୍ସ: ବିଳମ୍ବତା, ମୂଲ୍ୟ, ଫଳାଫଳ ସଂଖ୍ୟା, ପ୍ରତିକ୍ରିୟା ଆକାର।
- ସର୍ଚ୍ଚ ପାଇଁ URL ଓଭରଲାପ୍ ଗଣନା (ପ୍ରାରମ୍ଭିକ ଫଳାଫଳ ତୁଳନାରେ ସାଧାରଣ URLଗୁଡ଼ିକର ସଂଖ୍ୟା)।
- ପ୍ରତ୍ୟେକ ପ୍ରଦାନକାରୀ ପାଇଁ `POST /v1/search` (ସର୍ଚ୍ଚ) କିମ୍ବା `POST /v1/web/fetch` (ସ୍କ୍ରାପ୍)କୁ କଲ୍ କରେ।

## ପ୍ରଦାନକାରୀ କ୍ୟାଟାଲଗ୍

`ProviderCatalog.tsx`, `GET /api/search/providers` ରୁ ସମ୍ପୂର୍ଣ୍ଣ ପ୍ରଦାନକାରୀ ତାଲିକା ପ୍ରଦର୍ଶନ କରେ
(fetch ପ୍ରଦାନକାରୀଙ୍କୁ ସାମିଲ କରିବା ପାଇଁ F4-ରେ ବିସ୍ତାରିତ):

| `kind` | `"search"` (20ଟି ପ୍ରଦାନକାରୀ) କିମ୍ବା `"fetch"` (firecrawl, jina-reader, tavily-search, tinyfish, nimble-search, anysearch-search) |

ପ୍ରମାଣପତ୍ର ଉପଲବ୍ଧ ଅଛି କି ନାହିଁ ଏବଂ ସମସ୍ତ କୀ ବର୍ତ୍ତମାନ କୁଲ୍ଡାଉନ୍ରେ ଅଛି କି ନାହିଁ ଯାଞ୍ଚ କରି,
ଅନୁରୋଧ ସମୟରେ ସ୍ଥିତି **ନିର୍ଦ୍ଧାରଣ କରାଯାଏ**।

## କୋଡ୍ ରପ୍ତାନି

Playground Studio ରୁ ଆମଦାନି ହୋଇଥିବା `ExportCodeModal` + `codeExport.ts`, `/v1/search` ଏବଂ `/v1/web/fetch` ଉଭୟ
କଲ୍ ପାଇଁ curl / Python / TypeScript ସ୍ନିପେଟ୍ ସୃଷ୍ଟି କରେ।
API କୀ ପ୍ଲେସ୍ହୋଲ୍ଡର୍ ସର୍ବଦା `$OMNIROUTE_API_KEY` (D11, Playground Studio ସହିତ ସହଭାଗୀ)।

## ବ୍ୟାକଏଣ୍ଡ ପରିବର୍ତ୍ତନ

ଏହି ବୈଶିଷ୍ଟ୍ୟ ପାଇଁ କେବଳ ଗୋଟିଏ ବ୍ୟାକଏଣ୍ଡ ପରିବର୍ତ୍ତନ ଆବଶ୍ୟକ ଥିଲା:

### ବିସ୍ତାରିତ `GET /api/search/providers`

`src/app/api/search/providers/route.ts` କୁ ନିମ୍ନଲିଖିତ ପାଇଁ ବିସ୍ତାର କରାଯାଇଥିଲା:

- ସମସ୍ତ 6ଟି fetch ପ୍ରଦାନକାରୀ (`firecrawl`, `jina-reader`, `tavily-search`, `tinyfish`, `nimble-search`, `anysearch-search`)ଙ୍କୁ ଆରେରେ ସାମିଲ କରିବା।
- ପ୍ରତ୍ୟେକ ଆଇଟମ୍ରେ `kind: "search" | "fetch"` ଯୋଡ଼ିବା।
- ସକ୍ରିୟ ପ୍ରମାଣପତ୍ର ସ୍ଥିତିରୁ ନିର୍ଦ୍ଧାରିତ `status: "configured" | "missing" | "rate_limited"` ଯୋଡ଼ିବା।
- ପୂର୍ବବର୍ତ୍ତୀ ସୁସଙ୍ଗତତା ବଜାୟ ରଖିବା — ବିଦ୍ୟମାନ ଫିଲ୍ଡଗୁଡ଼ିକ (`id`, `name`, ଇତ୍ୟାଦି) ଅପରିବର୍ତ୍ତିତ।
