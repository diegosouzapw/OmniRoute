## ଏହା କ’ଣ

OmniRoute ଏକ **Notion** ୱର୍କସ୍ପେସ୍କୁ **ପ୍ରସଙ୍ଗ ଉତ୍ସ** ଭାବରେ ସଂଯୋଗ କରିପାରେ — ଏକ ପଠନ/ଲିଖନଯୋଗ୍ୟ
ଜ୍ଞାନଭଣ୍ଡାର, ଯେଉଁଥିରେ ଏଜେଣ୍ଟଗୁଡ଼ିକ ବିଲ୍ଟ-ଇନ୍ MCP ସର୍ଭର୍ ମାଧ୍ୟମରେ ପହଞ୍ଚନ୍ତି। ଏକ Notion
ଇଣ୍ଟିଗ୍ରେସନ୍ ଟୋକେନ୍ କନଫିଗର୍ ହେବା ପରେ, MCP ଟୁଲ୍ଗୁଡ଼ିକ ଏକ LLMକୁ ପୃଷ୍ଠା ଓ ଡାଟାବେସ୍ ସନ୍ଧାନ କରିବା,
ପୃଷ୍ଠା ବିଷୟବସ୍ତୁ ଓ ବ୍ଲକ୍ ଟ୍ରି ପଢ଼ିବା, ଫିଲ୍ଟର୍/ସର୍ଟ୍ ସହିତ ଡାଟାବେସ୍ କ୍ୱେରି କରିବା, ଏବଂ ନୂଆ
ବ୍ଲକ୍ ଯୋଡ଼ିବାକୁ ଦେଇଥାଏ — ସବୁକିଛି OmniRoute ମାଧ୍ୟମରେ ପ୍ରକ୍ସି ହୁଏ (ପୁନଃପ୍ରୟାସ, ସମୟସୀମା ଏବଂ ତ୍ରୁଟି ବର୍ଗୀକରଣ ସହିତ),
ଯାହାଦ୍ୱାରା ମଡେଲ୍ କେବେବି Notion APIକୁ ସିଧାସଳଖ ଆକ୍ସେସ୍ କରେନାହିଁ।

ଏହି ଇଣ୍ଟିଗ୍ରେସନ୍ ହେଉଛି ଅଧିକୃତ Notion REST APIର ଏକ ହାଲୁକା, ସୁଦୃଢ଼ ରାପର୍
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`)। କ୍ଲାଏଣ୍ଟ
(`src/lib/notion/api.ts`) ନିମ୍ନଲିଖିତ ସୁବିଧା ଯୋଡ଼େ:

- `429` ଏବଂ `5xx` ପାଇଁ **ଏକ୍ସପୋନେନ୍ସିଆଲ୍ ବ୍ୟାକଅଫ୍ ସହିତ ପୁନଃପ୍ରୟାସ** (ସର୍ବାଧିକ 3ଟି ପ୍ରୟାସ)।
- `AbortController` ମାଧ୍ୟମରେ **55-ସେକେଣ୍ଡର ଅନୁରୋଧ ସମୟସୀମା**।
- **ଟାଇପ୍ଯୁକ୍ତ ତ୍ରୁଟି ବର୍ଗୀକରଣ** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  ସୂଚନାକୁ ସମ୍ମାନ କରେ), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`।
- **ବାର୍ତ୍ତା ପରିଶୋଧନ**, ଯାହା ପ୍ରଦର୍ଶନ କରିବା ପୂର୍ବରୁ ଷ୍ଟାକ୍-ଟ୍ରେସ୍ ସଦୃଶ ଅଂଶଗୁଡ଼ିକୁ ହଟାଇଦିଏ।

## ସେଟଅପ୍

Notion ଟୋକେନ୍ ପାଇଁ **କୌଣସି ପରିବେଶ ଭେରିଏବଲ୍ ନାହିଁ** — ଏହାକୁ
`src/lib/db/notion.ts` ମାଧ୍ୟମରେ SQLite `key_value` ଟେବୁଲ୍ରେ (ନେମସ୍ପେସ୍ `notion`, କି `integration_token`)
ସଂରକ୍ଷଣ କରାଯାଏ। ଏହାକୁ Endpoint ଡ୍ୟାସ୍ବୋର୍ଡର **Context Sources** ଟ୍ୟାବ୍ରୁ
(`ObsidianSourceCard`ର ସହୋଦର `NotionSourceCard`), କିମ୍ବା ସେଟିଂସ୍ REST API ମାଧ୍ୟମରେ କନଫିଗର୍ କରନ୍ତୁ।

> [!NOTE]
> ଏହି ଟୋକେନ୍ ହେଉଛି ଏକ **Notion ଆଭ୍ୟନ୍ତରୀଣ ଇଣ୍ଟିଗ୍ରେସନ୍ ଟୋକେନ୍**। ଏଠାରେ ଏକ ଇଣ୍ଟିଗ୍ରେସନ୍ ସୃଷ୍ଟି କରନ୍ତୁ:
> <https://www.notion.com/my-integrations>, ତା’ପରେ OmniRoute ଯେଉଁ ପୃଷ୍ଠା/ଡାଟାବେସ୍ଗୁଡ଼ିକୁ
> ଆକ୍ସେସ୍ କରୁ ବୋଲି ଚାହୁଁଛନ୍ତି, ସେଗୁଡ଼ିକୁ ସେହି ଇଣ୍ଟିଗ୍ରେସନ୍ ସହିତ ସେୟାର୍ କରନ୍ତୁ (Notionର ଅନୁମତି ମଡେଲ୍ ସେୟାର୍-ଆଧାରିତ,
> ସମ୍ପୂର୍ଣ୍ଣ ୱର୍କସ୍ପେସ୍-ଆଧାରିତ ନୁହେଁ)।

### REST ମାଧ୍ୟମରେ କନଫିଗର୍ କରନ୍ତୁ

```bash
# ଇଣ୍ଟିଗ୍ରେସନ୍ ଟୋକେନ୍ ସଂରକ୍ଷଣ + ବୈଧତା ଯାଞ୍ଚ କରନ୍ତୁ (POST ଏକ ପରୀକ୍ଷଣ ସନ୍ଧାନ ଜାରି କରି ବୈଧତା ଯାଞ୍ଚ କରେ)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# ସଂଯୋଗ ସ୍ଥିତି ଯାଞ୍ଚ କରନ୍ତୁ
curl http://localhost:20128/api/settings/notion

# ସଂଯୋଗ ବିଚ୍ଛିନ୍ନ କରନ୍ତୁ (ସଂରକ୍ଷିତ ଟୋକେନ୍କୁ ସଫା କରେ)
curl -X DELETE http://localhost:20128/api/settings/notion
```

ତିନୋଟି ପଦ୍ଧତି ପାଇଁ ଡ୍ୟାସ୍ବୋର୍ଡ ପ୍ରମାଣୀକରଣ (`isAuthenticated`) ଆବଶ୍ୟକ। `POST` ସମୟରେ,
OmniRoute ଟୋକେନ୍କୁ ସଂରକ୍ଷଣ କରେ ଏବଂ ତୁରନ୍ତ 1ଟି ଫଳାଫଳ ପାଇଁ ଏକ ପରୀକ୍ଷଣ ସନ୍ଧାନ ଚଲାଏ; ଯଦି Notion
ଏକ ତ୍ରୁଟି ଅବଜେକ୍ଟ ଫେରାଏ, ତେବେ ଟୋକେନ୍କୁ ସଫା କରାଯାଏ ଏବଂ କଲ୍ଟି `400` ସହିତ ବିଫଳ ହୁଏ।

## MCP ଟୁଲ୍ଗୁଡ଼ିକ (6)

`open-sse/mcp-server/tools/notionTools.ts` ରେ ପରିଭାଷିତ। କଲ୍ ସମୟରେ
`getNotionToken()` ମାଧ୍ୟମରେ ଟୋକେନ୍ ନିର୍ଣ୍ଣୟ କରାଯାଏ; ଯଦି କୌଣସି ଟୋକେନ୍ କନଫିଗର୍ ହୋଇନାହିଁ, ତେବେ ଟୁଲ୍ଟି
`"Notion ଇଣ୍ଟିଗ୍ରେସନ୍ ଟୋକେନ୍ କନଫିଗର୍ ହୋଇନାହିଁ। ଏହାକୁ Settings > Context Sources ରେ ସେଟ୍ କରନ୍ତୁ।"` ତ୍ରୁଟି ଉତ୍ପନ୍ନ କରେ।

### ଇନ୍ପୁଟ୍ ପାରାମିଟର୍ଗୁଡ଼ିକ

- `notion_search` — `query` (1–500ଟି ଅକ୍ଷର), `pageSize` (1–100, ଡିଫଲ୍ଟ 20),
  `startCursor` (ଇଚ୍ଛାଧୀନ)।
- `notion_get_page` — `pageId` (32-ଅକ୍ଷରର ହେକ୍ସ କିମ୍ବା UUID)।
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, ଡିଫଲ୍ଟ 50),
  `startCursor` (ଇଚ୍ଛାଧୀନ)।
- `notion_query_database` — `databaseId`, `filter` (ଇଚ୍ଛାଧୀନ, Notion ଫିଲ୍ଟର୍ ଫର୍ମାଟ୍),
  `sorts` (ଇଚ୍ଛାଧୀନ ଆରେ), `pageSize` (1–100, ଡିଫଲ୍ଟ 50), `startCursor` (ଇଚ୍ଛାଧୀନ)।
- `notion_get_database` — `databaseId`।
- `notion_append_blocks` — `blockId`, `children` (ବ୍ଲକ୍ ଅବଜେକ୍ଟଗୁଡ଼ିକର ଆରେ),
  `after` (ଇଚ୍ଛାଧୀନ ସ୍ଥାନ)।

### ସ୍କୋପ୍ଗୁଡ଼ିକ

ପଠନ ଟୁଲ୍ଗୁଡ଼ିକ ପାଇଁ `read:notion` ଏବଂ ଲିଖନ ଟୁଲ୍ ପାଇଁ `write:notion` ଆବଶ୍ୟକ।
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` ଥିବା ସମୟରେ ମାତ୍ର
`open-sse/mcp-server/server.ts` ରେ ଥିବା `withScopeEnforcement()` ଦ୍ୱାରା ସ୍କୋପ୍ଗୁଡ଼ିକୁ ବାଧ୍ୟତାମୂଳକ କରାଯାଏ; କଲ୍କାରୀଙ୍କ
ଅନୁମୋଦିତ ସ୍କୋପ୍ଗୁଡ଼ିକ `OMNIROUTE_MCP_SCOPES` (କମା ଦ୍ୱାରା ପୃଥକ) କିମ୍ବା
ପ୍ରମାଣୀକୃତ API କି’ର ସ୍କୋପ୍ ପ୍ରସଙ୍ଗରୁ ଆସେ। ସମ୍ପୂର୍ଣ୍ଣ ସ୍କୋପ୍ ମଡେଲ୍ ପାଇଁ [MCP-SERVER.md](./MCP-SERVER.md) ଦେଖନ୍ତୁ।

## ଏଣ୍ଡପଏଣ୍ଟଗୁଡ଼ିକ

| ପଦ୍ଧତି   | ପଥ                     | ଉଦ୍ଦେଶ୍ୟ                                            |
| -------- | ---------------------- | --------------------------------------------------- |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` ଫେରାନ୍ତୁ।                 |
| `POST`   | `/api/settings/notion` | ଇଣ୍ଟିଗ୍ରେସନ୍ ଟୋକନ୍କୁ ସଞ୍ଚୟ + ବୈଧତା ଯାଞ୍ଚ କରନ୍ତୁ।    |
| `DELETE` | `/api/settings/notion` | ସଂଯୋଗ ବିଚ୍ଛିନ୍ନ କରନ୍ତୁ (ସଞ୍ଚିତ ଟୋକନ୍କୁ ସଫା କରନ୍ତୁ)। |

> ଏଗୁଡ଼ିକ ଡ୍ୟାସ୍ବୋର୍ଡ ସେଟିଂସ୍ ରୁଟ୍। କୌଣସି ସାର୍ବଜନୀନ `/v1` Notion ପ୍ରକ୍ସି
> ଏଣ୍ଡପଏଣ୍ଟ **ନାହିଁ** — Notionକୁ କେବଳ ଉପରୋକ୍ତ MCP ଟୁଲ୍ଗୁଡ଼ିକ ମାଧ୍ୟମରେ ଆକ୍ସେସ୍ କରାଯାଏ।

## ବ୍ୟବହାର କ୍ଷେତ୍ରଗୁଡ଼ିକ

- **ଜ୍ଞାନ-ଆଧାରିତ ଉତ୍ତର** — ଉତ୍ତର ଦେବା ପୂର୍ବରୁ ଜଣେ ଏଜେଣ୍ଟକୁ ୱର୍କସ୍ପେସ୍ରେ `notion_search` ଏବଂ
  ଶୀର୍ଷ ଫଳାଫଳ ପାଇଁ `notion_get_page` ବ୍ୟବହାର କରିବାକୁ ଦିଅନ୍ତୁ, ଯାହାଦ୍ୱାରା ଉତ୍ତରଗୁଡ଼ିକ ପ୍ରକୃତ ଆଭ୍ୟନ୍ତରୀଣ ଡକ୍ୟୁମେଣ୍ଟକୁ ଉଦ୍ଧୃତ କରିବ।
- **ଡାଟାବେସ୍-ସମର୍ଥିତ ୱର୍କଫ୍ଲୋ** — ଫିଲ୍ଟର୍ + ସର୍ଟ୍ ସହିତ ଏକ ଟାସ୍କ/CRM ଡାଟାବେସ୍ରେ
  `notion_query_database` ବ୍ୟବହାର କରନ୍ତୁ, ତା’ପରେ ଧାଡ଼ିଗୁଡ଼ିକର ସାରାଂଶ କିମ୍ବା ପ୍ରାଥମିକତା ନିର୍ଦ୍ଧାରଣ କରନ୍ତୁ।
- **ପୁନଃ-ଲିଖନ / ଲଗିଂ** — ଏକ ବିଦ୍ୟମାନ ପୃଷ୍ଠାରେ ମିଟିଂ ନୋଟ୍, ରନ୍
  ସାରାଂଶ କିମ୍ବା ଏଜେଣ୍ଟ ଆଉଟପୁଟ୍ ଯୋଡ଼ିବାକୁ `notion_append_blocks` ବ୍ୟବହାର କରନ୍ତୁ (କେବଳ ଯୋଡ଼ାଯାଇପାରିବ; କୌଣସି ବିନାଶକାରୀ ସମ୍ପାଦନା ନାହିଁ)।
- **ଗଠନ ଅନ୍ୱେଷଣ** — ଏକ ପୃଷ୍ଠାର ବ୍ଲକ୍ ଟ୍ରିକୁ ଅତିକ୍ରମ କରିବା ପାଇଁ `notion_list_block_children`,
  କିମ୍ବା କ୍ୱେରି କରିବା ପୂର୍ବରୁ ଏକ ଡାଟାବେସ୍ର ପ୍ରପର୍ଟି ସ୍କିମା ଜାଣିବା ପାଇଁ `notion_get_database` ବ୍ୟବହାର କରନ୍ତୁ।
