## ଏହା କ’ଣ

Local Corpus ଜଣେ ଅପରେଟର୍ଙ୍କୁ ସ୍ପଷ୍ଟ ଭାବରେ ଅନୁମୋଦିତ ଟେକ୍ସଟ୍ ଫାଇଲ୍ର ଗୋଟିଏ ଡିରେକ୍ଟୋରୀକୁ
OmniRouteର MCP ସର୍ଭର୍ରେ ଉପଲବ୍ଧ କରାଇବାକୁ ଦିଏ। ଫାଇଲ୍ଗୁଡ଼ିକ ସେମାନଙ୍କର ମୂଳ ଡିରେକ୍ଟୋରୀରେ ରହେ: OmniRoute କେବଳ
କ୍ୟାନୋନିକାଲ୍ ରୁଟ୍ ପାଥ୍କୁ SQLiteରେ ସଂରକ୍ଷଣ କରେ ଏବଂ ଏକ ଇନ୍-ମେମୋରୀ ସର୍ଚ୍ଚ ଇଣ୍ଡେକ୍ସ ରକ୍ଷଣାବେକ୍ଷଣ କରେ। ଏହା
କର୍ପସ୍ ବିଷୟବସ୍ତୁକୁ ରିପୋଜିଟୋରୀ କିମ୍ବା ଡାଟାବେସ୍କୁ କପି କରେ ନାହିଁ।

ଇଣ୍ଡେକ୍ସ ରିଫ୍ରେଶ୍ କ୍ରମବର୍ଦ୍ଧିଷ୍ଣୁ ଅଟେ। ଆକାର ଏବଂ ପରିବର୍ତ୍ତନ ସମୟ ଆଧାରରେ ଅପରିବର୍ତ୍ତିତ
ଫାଇଲ୍ଗୁଡ଼ିକୁ ପୁନଃବ୍ୟବହାର କରାଯାଏ, ପରିବର୍ତ୍ତିତ ଫାଇଲ୍ଗୁଡ଼ିକୁ ପୁଣି ପଢ଼ାଯାଏ ଏବଂ SHA-256 ଦ୍ୱାରା ହ୍ୟାଶ୍ କରାଯାଏ, ଏବଂ ଡିଲିଟ୍ ହୋଇଥିବା ଫାଇଲ୍ଗୁଡ଼ିକୁ ହଟାଯାଏ।
ସର୍ଚ୍ଚ 30 ସେକେଣ୍ଡରୁ ପୁରୁଣା ଇଣ୍ଡେକ୍ସକୁ ରିଫ୍ରେଶ୍ କରେ; କଲର୍ମାନେ ତତ୍କାଳ
ରିଫ୍ରେଶ୍ ପାଇଁ ମଧ୍ୟ ଅନୁରୋଧ କରିପାରିବେ।

## ଉତ୍ସ କନଫିଗର୍ କରନ୍ତୁ

ସେଟିଂସ୍ ରୁଟ୍ ପାଇଁ ଅନ୍ୟ ସେଟିଂସ୍ APIଗୁଡ଼ିକ ପରି ସମାନ ପରିଚାଳନା ପ୍ରମାଣୀକରଣ ଆବଶ୍ୟକ।
ଦାଖଲ କରାଯାଇଥିବା ପାଥ୍ ପୂର୍ବରୁ ଅବସ୍ଥିତ ଥିବା ଆବଶ୍ୟକ ଏବଂ ଏକ ଆବସୋଲ୍ୟୁଟ୍ ଡିରେକ୍ଟୋରୀ ପାଥ୍ ହେବା ଆବଶ୍ୟକ।

```bash
# ଏକ ଅନୁମୋଦିତ ଡିରେକ୍ଟୋରୀ ସଂଯୋଗ କରନ୍ତୁ
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# କନଫିଗରେସନ୍ ଏବଂ ଇଣ୍ଡେକ୍ସ ସ୍ଥିତି ଯାଞ୍ଚ କରନ୍ତୁ
curl http://localhost:20128/api/settings/local-corpus

# ଉତ୍ସ ଫାଇଲ୍ଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ ନକରି ବିଚ୍ଛିନ୍ନ କରନ୍ତୁ
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP ଟୁଲ୍ଗୁଡ଼ିକ

ତିନୋଟି ଟୁଲ୍ ପାଇଁ `read:local-corpus` ଆବଶ୍ୟକ। ଟୁଲ୍ ପ୍ରତିକ୍ରିୟାଗୁଡ଼ିକ ରିଲେଟିଭ୍ ପାଥ୍ ଏବଂ
ରୁଟ୍ ଡିରେକ୍ଟୋରୀର ମୂଳ ନାମ ପ୍ରକାଶ କରେ, କିନ୍ତୁ ଏହାର ଆବସୋଲ୍ୟୁଟ୍ ପାଥ୍ କେବେ ମଧ୍ୟ ପ୍ରକାଶ କରେ ନାହିଁ।

| ଟୁଲ୍                  | ବର୍ଣ୍ଣନା                                                                                          |
| :-------------------- | :------------------------------------------------------------------------------------------------ |
| `local_corpus_status` | କନଫିଗରେସନ୍ ସ୍ଥିତି, ଇଣ୍ଡେକ୍ସ ଆକାର, ସୀମାଗୁଡ଼ିକ ଏବଂ ଶେଷ ରିଫ୍ରେଶ୍ ସମୟ ରିପୋର୍ଟ କରେ                     |
| `local_corpus_search` | ଇଣ୍ଡେକ୍ସ ହୋଇଥିବା ଟେକ୍ସଟ୍ ସର୍ଚ୍ଚ କରେ ଏବଂ ସୀମିତ, ଲାଇନ୍-ସ୍କୋପ୍ଡ ସ୍ନିପେଟ୍ ଫେରାଏ (ସର୍ବାଧିକ 20ଟି ଫଳାଫଳ) |
| `local_corpus_read`   | ଗୋଟିଏ ଅନୁମୋଦିତ କର୍ପସ୍-ରିଲେଟିଭ୍ ଫାଇଲ୍ରୁ ଏକ ସୀମିତ ଲାଇନ୍ ପରିସର ପଢ଼େ                                  |

MCP ଇନ୍ପୁଟ୍ର ଉଦାହରଣ:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## ସୁରକ୍ଷା ସୀମାଗୁଡ଼ିକ

- ଅନୁମୋଦିତ ତାଲିକାଟି ଟେକ୍ସଟ୍-କେନ୍ଦ୍ରିତ: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, ଏବଂ `.yml`।
- ସିମ୍ଲିଙ୍କ୍ଗୁଡ଼ିକୁ ଏଡ଼ାଇ ଦିଆଯାଏ। ପଠନ ପାଥ୍ଗୁଡ଼ିକୁ କ୍ୟାନୋନିକାଲାଇଜ୍ କରାଯାଏ ଏବଂ ସେଗୁଡ଼ିକ
  କନଫିଗର୍ ହୋଇଥିବା ରୁଟ୍ ଭିତରେ ରହିବା ଆବଶ୍ୟକ; ଆବସୋଲ୍ୟୁଟ୍ ପାଥ୍ ଏବଂ ଟ୍ରାଭର୍ସାଲ୍ ପ୍ରୟାସଗୁଡ଼ିକୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ।
- ସମ୍ବେଦନଶୀଳ ଏବଂ ଜେନେରେଟ୍ ହୋଇଥିବା ଡିରେକ୍ଟୋରୀ ନାମଗୁଡ଼ିକୁ ବାଦ ଦିଆଯାଏ: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, ଏବଂ
  `secrets`।
- ଡିଫଲ୍ଟ ସୀମାଗୁଡ଼ିକ ହେଉଛି 5,000ଟି ଫାଇଲ୍, ପ୍ରତି ଫାଇଲ୍ରେ 1 MiB, ମୋଟ ଇଣ୍ଡେକ୍ସ ହୋଇଥିବା ବିଷୟବସ୍ତୁ 64 MiB,
  ପ୍ରତି ସର୍ଚ୍ଚ ଚଙ୍କ୍ରେ ପ୍ରାୟ 4,000ଟି ଅକ୍ଷର, ଏବଂ ପ୍ରତି ପଠନରେ 400ଟି ଲାଇନ୍।
- NUL ଥିବା ଫାଇଲ୍ଗୁଡ଼ିକୁ ଅଣ-ଟେକ୍ସଟ୍ ଭାବେ ଗ୍ରହଣ କରାଯାଏ ଏବଂ ଏଡ଼ାଇ ଦିଆଯାଏ କିମ୍ବା ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ।

PDF, DOCX, ଛବି ଏବଂ ଆର୍କାଇଭ୍ ପରି ବାଇନାରୀ ଡକ୍ୟୁମେଣ୍ଟଗୁଡ଼ିକ ଉଦ୍ଦେଶ୍ୟମୂଳକ ଭାବରେ ସମର୍ଥିତ ନୁହେଁ।
ଇଣ୍ଡେକ୍ସିଂ ପୂର୍ବରୁ ସେଗୁଡ଼ିକୁ କନଫିଗର୍ ହୋଇଥିବା ଡିରେକ୍ଟୋରୀରେ ଏକ ଅନୁମୋଦିତ ଟେକ୍ସଟ୍ ଫର୍ମାଟ୍କୁ ରୂପାନ୍ତର କରନ୍ତୁ।

## ପରିଚାଳନା ସମ୍ବନ୍ଧୀୟ ଟିପ୍ପଣୀ

- କନଫିଗର୍ ହୋଇଥିବା ରୁଟ୍ ପରିବର୍ତ୍ତନ କିମ୍ବା ଡିଲିଟ୍ କଲେ ସେୟାର୍ଡ ଇନ୍-ମେମୋରୀ ଇଣ୍ଡେକ୍ସ ସଫା ହୁଏ।
- ପ୍ରୋସେସ୍ ପୁନଃଚାଳନ ଇଣ୍ଡେକ୍ସକୁ ବର୍ଜନ କରେ; ପରବର୍ତ୍ତୀ ସର୍ଚ୍ଚ କନଫିଗର୍ ହୋଇଥିବା
  ଉତ୍ସରୁ ଏହାକୁ ପୁନଃନିର୍ମାଣ କରେ।
