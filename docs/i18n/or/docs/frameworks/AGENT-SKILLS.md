## ସାରାଂଶ

ଏହି କ୍ୟାଟାଲଗ୍ରେ **45ଟି Agent Skills** (23ଟି REST API + 21ଟି CLI + 1ଟି କନଫିଗରେସନ୍ ୱର୍କଫ୍ଲୋ) ରହିଛି। ପ୍ରତ୍ୟେକ ସ୍କିଲ୍ରେ ରହିଛି:

- ଏକ **କ୍ୟାନୋନିକାଲ୍ ID** (`omni-auth`, `cli-serve`, ଇତ୍ୟାଦି)
- `skills/{id}/SKILL.md`ରେ ଏକ **SKILL.md** ଫାଇଲ୍, ଯେଉଁଥିରେ YAML ଫ୍ରଣ୍ଟମ୍ୟାଟର୍ (`name`, `description`) + ସମୃଦ୍ଧ markdown ବଡି ରହିଛି
- OpenAPI ସ୍ପେକ୍ ଏବଂ CLI ରେଜିଷ୍ଟ୍ରିରୁ ବ୍ୟୁତ୍ପନ୍ନ **REST ଏଣ୍ଡପଏଣ୍ଟଗୁଡ଼ିକ** (API ସ୍କିଲ୍) କିମ୍ବା **CLI ସବ୍କମାଣ୍ଡଗୁଡ଼ିକ** (CLI ସ୍କିଲ୍)
- ଲାଇଭ୍ ଫେଚ୍ ପାଇଁ ଏକ **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API ଆବିଷ୍କାର

| ଏଣ୍ଡପଏଣ୍ଟ                    | ପଦ୍ଧତି | ବର୍ଣ୍ଣନା                                                             | ପ୍ରାମାଣିକରଣ |
| :--------------------------- | :----- | :------------------------------------------------------------------- | :---------- |
| `/api/agent-skills`          | GET    | କ୍ୟାଟାଲଗ୍ ତାଲିକା (ଇଚ୍ଛାଧୀନ `?category=api\|cli\|config&area=<area>`) | କିଛି ନାହିଁ  |
| `/api/agent-skills/{id}`     | GET    | ଗୋଟିଏ କୌଶଳର ମେଟାଡାଟା ପ୍ରାପ୍ତ କରନ୍ତୁ                                  | କିଛି ନାହିଁ  |
| `/api/agent-skills/{id}/raw` | GET    | SKILL.mdକୁ `text/markdown` ଭାବେ ଆଣନ୍ତୁ                               | କିଛି ନାହିଁ  |
| `/api/agent-skills/coverage` | GET    | କଭରେଜ୍ ପରିସଂଖ୍ୟାନ (କେତୋଟି SKILL.md ଫାଇଲ୍ ଅଛି)                        | କିଛି ନାହିଁ  |
| `/api/agent-skills/generate` | POST   | ଜେନେରେଟର୍ ଟ୍ରିଗର୍ କରନ୍ତୁ (dryRun/prune/onlyIds)                      | ପରିଚାଳନା    |

ଉଦାହରଣ — ସମସ୍ତ API କୌଶଳର ତାଲିକା:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ଉଦାହରଣ — ଗୋଟିଏ SKILL.md ଆଣନ୍ତୁ:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP ଆବିଷ୍କାର

`read:catalog` ସ୍କୋପ୍ ଅଧୀନରେ ତିନୋଟି MCP ଟୁଲ୍ ପଞ୍ଜୀକୃତ ହୋଇଛି:

| ଟୁଲ୍                              | ବର୍ଣ୍ଣନା                                                       |
| :-------------------------------- | :------------------------------------------------------------- |
| `omniroute_agent_skills_list`     | କୌଶଳଗୁଡ଼ିକର ତାଲିକା (ଇଚ୍ଛାଧୀନ `category` / `area` ଫିଲ୍ଟର୍)      |
| `omniroute_agent_skills_get`      | `id` ଦ୍ୱାରା ଗୋଟିଏ କୌଶଳ ପାଇଁ ମେଟାଡାଟା + SKILL.md ପ୍ରାପ୍ତ କରନ୍ତୁ |
| `omniroute_agent_skills_coverage` | କଭରେଜ୍ ପରିସଂଖ୍ୟାନ (API/CLI ଉପଲବ୍ଧ/ମୋଟ)                         |

ସ୍କୋପ୍ ୱାୟରିଂ ଏବଂ ପ୍ରାମାଣିକରଣ ପାଇଁ [MCP-SERVER.md](./MCP-SERVER.md) ଦେଖନ୍ତୁ।

## A2A ଆବିଷ୍କାର

A2A କୌଶଳ `list-capabilities`, ସମ୍ପୂର୍ଣ୍ଣ 45ଟି କୌଶଳର କ୍ୟାଟାଲଗ୍କୁ ଏକ markdown ଟେବୁଲ୍ ଆର୍ଟିଫ୍ୟାକ୍ଟ ଭାବେ ଫେରାଏ। ବାହ୍ୟ ଅର୍କେଷ୍ଟ୍ରେଟର୍ଗୁଡ଼ିକ ଏହାକୁ ନିମ୍ନପ୍ରକାରେ ଆହ୍ୱାନ କରିପାରିବେ:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

ପ୍ରୋଟୋକଲ୍ ବିବରଣୀ ପାଇଁ [A2A-SERVER.md](./A2A-SERVER.md) ଦେଖନ୍ତୁ।

## ଜେନେରେଟର୍

ଜେନେରେଟର୍ କ୍ୟୁରେଟ୍ କରାଯାଇଥିବା କ୍ୟାଟାଲଗ୍ + OpenAPI ସ୍ପେକ୍ + CLI ରେଜିଷ୍ଟ୍ରିକୁ ପଢ଼େ ଏବଂ ପ୍ରତ୍ୟେକ ଏଣ୍ଟ୍ରି ପାଇଁ `skills/{id}/SKILL.md` ଲେଖେ:

```bash
# ପୂର୍ବାବଲୋକନ (ଡ୍ରାଇ ରନ୍, କୌଣସି ଲେଖନ ନାହିଁ)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# ସମ୍ପୂର୍ଣ୍ଣ ପୁନଃଜେନେରେସନ୍
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# ନିର୍ଦ୍ଦିଷ୍ଟ ID-ଗୁଡ଼ିକୁ ପୁନଃଜେନେରେଟ୍ କରନ୍ତୁ

  -H "Authorization: Bearer <admin-key>" \
```
