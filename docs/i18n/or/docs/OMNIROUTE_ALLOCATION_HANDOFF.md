ବଣ୍ଟନ ପ୍ରଦାନକାରୀ କୋଟା ନୁହେଁ।

କେଉଁ API କୀଗୁଡ଼ିକ ଏକ ପ୍ରଦାନକାରୀ ପୁଲ୍ରୁ ବ୍ୟବହାର କରିପାରିବ ଏବଂ ହାର୍ଡ, ସଫ୍ଟ କିମ୍ବା ବର୍ଷ୍ଟ ନୀତିଗୁଡ଼ିକ କିପରି ପ୍ରୟୋଗ ହେବ, ତାହା କୋଟା ପୁଲ୍ଗୁଡ଼ିକ ନିର୍ଦ୍ଧାରଣ କରନ୍ତି। ପ୍ରଦାନକାରୀ କୋଟା ହେଉଛି ପ୍ରଦାନକାରୀଙ୍କ ଦ୍ୱାରା ରିପୋର୍ଟ କରାଯାଇଥିବା କିମ୍ବା ସ୍ପଷ୍ଟ ଭାବରେ ବିନ୍ୟାସିତ ଉତ୍ସରୁ ମିଳୁଥିବା ବାହ୍ୟ କ୍ଷମତା। Ghostlightର ଆଭ୍ୟନ୍ତରୀଣ ବଜେଟ୍ଗୁଡ଼ିକ ହେଉଛି ପ୍ରଶାସକଙ୍କ ଦ୍ୱାରା ନିର୍ଦ୍ଧାରିତ ପରିଚାଳନା ସୀମା।

`ensurePool` ଅପରେସନ୍ଟି ଇଡେମ୍ପୋଟେଣ୍ଟ: ଏକ ସମାନ ପୁଲ୍ ଅପରିବର୍ତ୍ତିତ ରହେ, ପରିବର୍ତ୍ତିତ ବଣ୍ଟନ ଅଦ୍ୟତନ ହୁଏ ଏବଂ ଅନୁପସ୍ଥିତ ପୁଲ୍ ସୃଷ୍ଟି ହୁଏ। ଏହା ସ୍ୱୟଂଚାଳନ ଏବଂ ସୀମିତ API କଲର୍ମାନଙ୍କ ପାଇଁ ଉଦ୍ଦିଷ୍ଟ।

କେବଳ ପଠନୀୟ ସ୍ଥିତି ଏଣ୍ଡପଏଣ୍ଟ ହେଉଛି `GET /api/omniroute/status`। ଯାଞ୍ଚ କମାଣ୍ଡ ହେଉଛି `npm run omniroute:verify`; ଏହା କୌଣସି ଲାଇଭ୍ ମଡେଲ୍ ଅନୁରୋଧ କରେ ନାହିଁ।
