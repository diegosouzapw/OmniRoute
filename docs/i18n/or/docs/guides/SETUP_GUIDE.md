## ଇନଷ୍ଟଲ୍ ପଦ୍ଧତିଗୁଡ଼ିକ

### npm (ସୁପାରିସକୃତ)

```bash
npm install -g omniroute
omniroute
```

ଡ୍ୟାସ୍ବୋର୍ଡ `http://localhost:20128`ରେ ଖୋଲିବ ଏବଂ APIର ମୂଳ URL ହେଉଛି `http://localhost:20128/v1`।

### pnpm

```bash
pnpm add -g omniroute@latest --allow-build=better-sqlite3 --allow-build=@swc/core
omniroute
```

> **pnpm ବ୍ୟବହାରକାରୀମାନେ:** `better-sqlite3` ଏବଂ `@swc/core` ପାଇଁ ନେଟିଭ୍ ବିଲ୍ଡ ସ୍କ୍ରିପ୍ଟଗୁଡ଼ିକୁ ସକ୍ଷମ କରିବାକୁ `--allow-build` ଫ୍ଲାଗ୍ ଆବଶ୍ୟକ। pnpm v11ରେ ଗ୍ଲୋବାଲ୍ ଇନଷ୍ଟଲ୍ ପାଇଁ `pnpm approve-builds -g` କମାଣ୍ଡ ସମର୍ଥିତ ନୁହେଁ।

### Arch Linux (AUR)

```bash
yay -S omniroute-bin
systemctl --user enable --now omniroute.service
```

[AUR ପ୍ୟାକେଜ୍](https://aur.archlinux.org/packages/omniroute-bin) OmniRoute ଇନଷ୍ଟଲ୍ କରେ ଏବଂ ଏକ systemd ବ୍ୟବହାରକାରୀ ସେବା ପ୍ରଦାନ କରେ।

### ସୋର୍ସରୁ

```bash
npm install
PORT=20128 DASHBOARD_PORT=20129 NEXT_PUBLIC_BASE_URL=http://localhost:20129 npm run dev
```

> **Windows ଟିପ୍ପଣୀ:** ଡିଫଲ୍ଟ ଭାବେ, ପୁରୁଣା `%USERPROFILE%\.omniroute` ଡିରେକ୍ଟୋରୀ ଉପସ୍ଥିତ ନଥିଲେ OmniRoute `%APPDATA%\omniroute` ବ୍ୟବହାର କରେ। ଏକ ଭିନ୍ନ ଡାଟା-ଡିରେକ୍ଟୋରୀ ଅବସ୍ଥାନ ବାଛିବାକୁ `DATA_DIR` ସେଟ୍ କରନ୍ତୁ।

> **ଟିପ୍ପଣୀ:** ପ୍ରଥମ ଥର ଚାଲିବାବେଳେ `npm install`, `.env.example`ରୁ ସ୍ୱୟଂଚାଳିତ ଭାବେ `.env` ସୃଷ୍ଟି କରେ। ପରବର୍ତ୍ତୀ ଇନଷ୍ଟଲ୍ଗୁଡ଼ିକ ବିଦ୍ୟମାନ `.env`କୁ ଓଭର୍ରାଇଟ୍ କରିବ ନାହିଁ, ତେଣୁ କଷ୍ଟମାଇଜେସନ୍ଗୁଡ଼ିକ ସଂରକ୍ଷିତ ରହିବ। ପୁନଃ ସୃଷ୍ଟି କରିବାକୁ, ପୁଣି ଚଲାଇବା ପୂର୍ବରୁ `.env` ଡିଲିଟ୍ କରନ୍ତୁ।

### Docker

Compose ପ୍ରୋଫାଇଲ୍ ଏବଂ Caddy HTTPS ସମେତ ସମ୍ପୂର୍ଣ୍ଣ Docker ସେଟଅପ୍ ପାଇଁ [Docker ମାର୍ଗଦର୍ଶିକା](./DOCKER_GUIDE.md) ଦେଖନ୍ତୁ।

### ଡେସ୍କଟପ୍ ଆପ୍ (Electron)

OmniRoute, Electron 41 + electron-builder 26.10 ଉପରେ ନିର୍ମିତ ଏକ ଡେସ୍କଟପ୍ ରାପର୍ ସହ ଆସେ। ଉପଲବ୍ଧ ସ୍କ୍ରିପ୍ଟଗୁଡ଼ିକ (ୱାର୍କସ୍ପେସ୍ ରୁଟ୍):

```bash
npm run electron:dev          # ହଟ୍-ରିଲୋଡ୍ ସହ ଡେସ୍କଟପ୍ ଚଲାନ୍ତୁ
npm run electron:build        # ବର୍ତ୍ତମାନର OS ପାଇଁ ବିଲ୍ଡ କରନ୍ତୁ (ସ୍ୱୟଂଚାଳିତ ଭାବେ ଚିହ୍ନଟ)
npm run electron:build:win    # Windows ଇନଷ୍ଟଲର୍ (NSIS + ପୋର୍ଟେବଲ୍)
npm run electron:build:mac    # macOS (dmg + zip, arm64+x64)
npm run electron:build:linux  # Linux (AppImage + deb + rpm)
npm run electron:smoke:packaged  # ପ୍ୟାକେଜ୍ ହୋଇଥିବା ବିଲ୍ଡର ସ୍ମୋକ୍-ଟେଷ୍ଟ କରନ୍ତୁ
```

ଡେସ୍କଟପ୍ ଇନଷ୍ଟଲର୍ଗୁଡ଼ିକର ରିଲିଜ୍ GitHub Releases ସହ ସଂଲଗ୍ନ ଅଛି। Electron ବିଷୟରେ ସମ୍ପୂର୍ଣ୍ଣ ଗଭୀର ବିବରଣୀ (ସାଇନିଂ, IPC ବ୍ରିଜ୍, ଡିଷ୍ଟ୍ରୋଗୁଡ଼ିକ) ପାଇଁ, [`ELECTRON_GUIDE.md`](./ELECTRON_GUIDE.md) ଦେଖନ୍ତୁ _(ପରବର୍ତ୍ତୀ ପର୍ଯ୍ୟାୟରେ ସୃଷ୍ଟି କରାଯାଇଛି)_।

### ହେଡ୍ଲେସ୍ ସର୍ଭର୍ (CI/ଅଟୋମେସନ୍)

ଅନୁପସ୍ଥିତ ସେଟଅପ୍ଗୁଡ଼ିକ (Docker, Kubernetes, CI) ପାଇଁ, ବ୍ୟବହାର କରନ୍ତୁ:

```bash
omniroute setup --non-interactive
omniroute providers test-batch
```

env ଭେରିଏବଲ୍ଗୁଡ଼ିକ (`INITIAL_PASSWORD`, `OMNIROUTE_WS_BRIDGE_SECRET`, ଇତ୍ୟାଦି) ସହ ମିଶାଇ, ଏହା ଆପଣଙ୍କୁ ସମ୍ପୂର୍ଣ୍ଣ ସ୍କ୍ରିପ୍ଟଯୋଗ୍ୟ ଭାବେ ଏକ OmniRoute ଇନଷ୍ଟାନ୍ସ ଚାଲୁ କରିବାକୁ ଦିଏ।

### CLI ବିକଳ୍ପଗୁଡ଼ିକ

| କମାଣ୍ଡ                  | ବର୍ଣ୍ଣନା                                                                           |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `omniroute`             | ସର୍ଭର୍ ଆରମ୍ଭ କରନ୍ତୁ (`PORT=20128`, API ଏବଂ ଡ୍ୟାସ୍ବୋର୍ଡ ସମାନ ପୋର୍ଟରେ)               |
| `omniroute setup`       | ପାସ୍ୱାର୍ଡ ଏବଂ ପ୍ରଥମ ପ୍ରଦାନକାରୀ ପାଇଁ ମାର୍ଗଦର୍ଶିତ CLI ଅନ୍ବୋର୍ଡିଂ                     |
| `omniroute doctor`      | ସର୍ଭର୍ ଆରମ୍ଭ ନକରି ସ୍ଥାନୀୟ ସ୍ୱାସ୍ଥ୍ୟ ଯାଞ୍ଚ ଚଲାନ୍ତୁ                                  |
| `omniroute providers`   | CLIରୁ ପ୍ରଦାନକାରୀମାନଙ୍କୁ ଖୋଜନ୍ତୁ, ତାଲିକାଭୁକ୍ତ କରନ୍ତୁ, ବୈଧ କରନ୍ତୁ ଏବଂ ପରୀକ୍ଷା କରନ୍ତୁ |
| `omniroute config`      | CLI ଟୁଲ୍ ବିନ୍ୟାସ — ବିନ୍ୟାସଗୁଡ଼ିକୁ ତାଲିକାଭୁକ୍ତ, ପ୍ରାପ୍ତ, ସେଟ୍ ଏବଂ ବୈଧ କରନ୍ତୁ        |
| `omniroute status`      | ଅଫ୍ଲାଇନ୍ ସ୍ଥିତି ଡ୍ୟାସ୍ବୋର୍ଡ — ସଂସ୍କରଣ, DB, ଟୁଲ୍ଗୁଡ଼ିକ, ବିନ୍ୟାସ                     |
| `omniroute logs`        | APIରୁ ବ୍ୟବହାର ଲଗ୍ଗୁଡ଼ିକୁ ଷ୍ଟ୍ରିମ୍ କରନ୍ତୁ (`--follow` ସମର୍ଥିତ)                      |
| `omniroute update`      | OmniRoute ଅପଡେଟ୍ଗୁଡ଼ିକ ଯାଞ୍ଚ କିମ୍ବା ପ୍ରୟୋଗ କରନ୍ତୁ                                  |
| `omniroute provider`    | ପ୍ରଦାନକାରୀ ସଂଯୋଗଗୁଡ଼ିକ ପରିଚାଳନା କରନ୍ତୁ — ଯୋଗ, ତାଲିକା, ଅପସାରଣ, ପରୀକ୍ଷା, ଡିଫଲ୍ଟ      |
| `omniroute --port 3000` | କ୍ୟାନୋନିକାଲ୍/API ପୋର୍ଟକୁ 3000ରେ ସେଟ୍ କରନ୍ତୁ                                        |
| `omniroute --mcp`       | MCP ସର୍ଭର୍ ଆରମ୍ଭ କରନ୍ତୁ (stdio ଟ୍ରାନ୍ସପୋର୍ଟ)                                       |
| `omniroute --no-open`   | ବ୍ରାଉଜର୍ ସ୍ୱୟଂଚାଳିତ ଭାବେ ଖୋଲନ୍ତୁ ନାହିଁ                                             |
| `omniroute --help`      | ସହାୟତା ଦେଖାନ୍ତୁ                                                                    |

ହେଡ୍ଲେସ୍ ସେଟଅପ୍କୁ ଫ୍ଲାଗ୍ କିମ୍ବା ଏନ୍ଭାଇରନ୍ମେଣ୍ଟ ଭେରିଏବଲ୍ଗୁଡ଼ିକ ସହ ସ୍କ୍ରିପ୍ଟ କରାଯାଇପାରେ:

```bash
omniroute setup --non-interactive --password "$OMNIROUTE_PASSWORD"
omniroute setup --non-interactive --add-provider --provider openai --api-key "$OPENAI_API_KEY"
omniroute setup --non-interactive --add-provider --provider openai --api-key "$OPENAI_API_KEY" --test-provider
```

ଡ୍ୟାସ୍ବୋର୍ଡ ନଖୋଲି ସ୍ଥାନୀୟ ଡାଇଗ୍ନୋଷ୍ଟିକ୍ସ ଚଲାନ୍ତୁ:

```bash
omniroute doctor
omniroute doctor --json
omniroute doctor --no-liveness
```

ଡ୍ୟାସ୍ବୋର୍ଡ ନଖୋଲି SSH କିମ୍ବା ସ୍କ୍ରିପ୍ଟରୁ ପ୍ରଦାନକାରୀମାନଙ୍କୁ ପରିଚାଳନା କରନ୍ତୁ:

```bash
omniroute providers available
omniroute providers available --search openai
omniroute providers available --category api-key
omniroute providers list
omniroute providers test <id-or-name>
omniroute providers test-all
omniroute providers validate
```

## CLI ଟୁଲ୍ ବିନ୍ୟାସ

### 1) ପ୍ରଦାନକାରୀମାନଙ୍କୁ ସଂଯୋଗ କରନ୍ତୁ ଏବଂ API କୀ ସୃଷ୍ଟି କରନ୍ତୁ

1. Dashboard → `Providers` ଖୋଲନ୍ତୁ ଏବଂ ଅତି କମରେ ଗୋଟିଏ ପ୍ରଦାନକାରୀଙ୍କୁ ସଂଯୋଗ କରନ୍ତୁ (OAuth କିମ୍ବା API କୀ)।
2. Dashboard → `Endpoints` ଖୋଲନ୍ତୁ ଏବଂ ଏକ API କୀ ସୃଷ୍ଟି କରନ୍ତୁ।
3. (ଇଚ୍ଛାଧୀନ) Dashboard → `Combos` ଖୋଲନ୍ତୁ ଏବଂ ଆପଣଙ୍କର ଫଲ୍ବ୍ୟାକ୍ ଶୃଙ୍ଖଳ ସେଟ୍ କରନ୍ତୁ।

### 2) ଆପଣଙ୍କ କୋଡିଂ ଟୁଲ୍କୁ ନିର୍ଦ୍ଦେଶ କରନ୍ତୁ

```txt
ମୂଳ URL: http://localhost:20128/v1
API କୀ:  [Endpoint ପୃଷ୍ଠାରୁ କପି କରନ୍ତୁ]
ମଡେଲ୍:    if/qwen3.8-max-preview (କିମ୍ବା ଯେକୌଣସି ପ୍ରଦାନକାରୀ/ମଡେଲ୍ ପ୍ରିଫିକ୍ସ)
```

ଯଦି ଆପଣଙ୍କ ଏଡିଟର୍ `Authorization: Bearer ...` ପଠାଇପାରେ ନାହିଁ, ତେବେ ଏହା ପରିବର୍ତ୍ତେ ଟୋକନ୍ଯୁକ୍ତ ସୁସଙ୍ଗତତା ମୂଳ ଠିକଣା ବ୍ୟବହାର କରନ୍ତୁ:

```txt
ମୂଳ URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/
ମଡେଲ୍ URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/models
ଚାଟ୍ URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/chat/completions
Ollama ଟ୍ୟାଗ୍ URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/api/tags
```

Claude Code, Codex CLI, Cursor, Cline, OpenClaw, OpenCode ଏବଂ OpenAI-ସୁସଙ୍ଗତ SDKଗୁଡ଼ିକ ସହିତ କାମ କରେ।

#### `setup-*` ସହିତ ସ୍ୱୟଂଚାଳିତ ବିନ୍ୟାସ

ମୂଳ URL ଏବଂ କୀକୁ ହାତରେ ପେଷ୍ଟ କରିବା ପରିବର୍ତ୍ତେ, ଲାଇଭ୍ ମଡେଲ୍ କ୍ୟାଟାଲଗ୍ରୁ OmniRouteକୁ ପ୍ରତ୍ୟେକ ଟୁଲ୍ର
ନିଜସ୍ୱ ବିନ୍ୟାସ ଲେଖିବାକୁ ଦିଅନ୍ତୁ। ପ୍ରତ୍ୟେକ ଟୁଲ୍ ପାଇଁ ଗୋଟିଏ କମାଣ୍ଡ:

```bash
omniroute setup-codex        # ~/.codex/<name>.config.toml ପ୍ରୋଫାଇଲ୍ଗୁଡ଼ିକ
omniroute setup-claude       # ~/.claude/profiles/<name>/settings.json
omniroute setup-opencode     # ~/.config/opencode/opencode.json (OpenAI-ସୁସଙ୍ଗତ)
omniroute setup-cline        # Cline CLI + VS Code ଏକ୍ସଟେନ୍ସନ୍ ସେଟିଂସ୍
omniroute setup-kilo         # Kilo Code
omniroute setup-continue     # ~/.continue/config.yaml (Continue / cn)
omniroute setup-cursor       # Cursorର ଆପ୍ ମଧ୍ୟରେ ଥିବା ପଦକ୍ଷେପଗୁଡ଼ିକ ପ୍ରିଣ୍ଟ କରେ
omniroute setup-roo          # Roo Code ଇମ୍ପୋର୍ଟ + autoImport ପଏଣ୍ଟର୍
omniroute setup-crush        # ~/.config/crush/crush.json
omniroute setup-goose        # ~/.config/goose/config.yaml
omniroute setup-aider        # ~/.aider.conf.yml
omniroute setup-qwen         # ~/.qwen/settings.json + ~/.qwen/.env
```

ଏକ **ରିମୋଟ୍** OmniRoute ବିପକ୍ଷରେ ସ୍ଥାନୀୟ ଟୁଲ୍ ବିନ୍ୟାସ କରିବା ପାଇଁ ପ୍ରତ୍ୟେକ କମାଣ୍ଡ `--remote <url> --api-key <key>` ଗ୍ରହଣ କରେ,
ଏବଂ ପୂର୍ବାବଲୋକନ ପାଇଁ `--dry-run` ମଧ୍ୟ ଗ୍ରହଣ କରେ। ସଠିକ୍ env ଇଞ୍ଜେକ୍ଟ କରି ଏବଂ ଆଦୌ କୌଣସି ବିନ୍ୟାସ ନ ଲେଖି ଏକ CLI ଆରମ୍ଭ କରିବାକୁ,
ସାଧାରଣ ଲଞ୍ଚର୍ `omniroute run <target>` (claude, codex, aider, goose, opencode, qwen, gemini) ବ୍ୟବହାର କରନ୍ତୁ;
ପୁରୁଣା ପ୍ରତି-ଟୁଲ୍ ଲଞ୍ଚର୍ଗୁଡ଼ିକ `omniroute launch` (Claude Code) ଏବଂ
`omniroute launch-codex` (Codex) ଏବେ ମଧ୍ୟ ଉପଲବ୍ଧ ଅଛି।

ସମ୍ପୂର୍ଣ୍ଣ ସାରଣୀ ପାଇଁ (ପ୍ରତ୍ୟେକ କମାଣ୍ଡ କ’ଣ ଲେଖେ, ପ୍ରତ୍ୟେକ ଫ୍ଲାଗ୍, ସ୍ଥାନୀୟ ବନାମ ରିମୋଟ୍, ମୂଳ-URL
`/v1` ପ୍ରଥା), **[CLI ଏକୀକରଣ](./CLI-INTEGRATIONS.md)** ଦେଖନ୍ତୁ।

ପ୍ରତ୍ୟେକ ଟୁଲ୍ର ବିସ୍ତୃତ ବିନ୍ୟାସ ପାଇଁ (Claude Code, Codex CLI, Cursor, Cline, OpenClaw, Kilo Code, Copilot ଏବଂ ଅନ୍ୟାନ୍ୟ), ଉତ୍ସର୍ଗୀକୃତ **[CLI ଟୁଲ୍ ଗାଇଡ୍](../reference/CLI-TOOLS.md)** ଦେଖନ୍ତୁ।

## ପ୍ରୋଟୋକଲ୍ ସେଟଅପ୍ (MCP + A2A)

### MCP ସେଟଅପ୍ (ମଡେଲ୍ କଣ୍ଟେକ୍ସ୍ଟ ପ୍ରୋଟୋକଲ୍)

stdio ମୋଡ୍ରେ MCP ଟ୍ରାନ୍ସପୋର୍ଟ ଆରମ୍ଭ କରନ୍ତୁ:

```bash
omniroute --mcp
```

ସୁପାରିସ୍ କରାଯାଇଥିବା ବୈଧତା ଯାଞ୍ଚ ପ୍ରବାହ:

```bash
# 1. MCP ସର୍ଭର୍ ଆରମ୍ଭ କରନ୍ତୁ
omniroute --mcp

# 2. ଆପଣଙ୍କ MCP କ୍ଲାଏଣ୍ଟରୁ ଏଗୁଡ଼ିକୁ କଲ୍ କରନ୍ତୁ:
omniroute_get_health        # ସିଷ୍ଟମ୍ର ସ୍ୱାସ୍ଥ୍ୟ ସ୍ଥିତି ଫେରାଇବା ଉଚିତ
omniroute_list_combos       # ସକ୍ରିୟ କମ୍ବୋଗୁଡ଼ିକ ଫେରାଇବା ଉଚିତ

# 3. କିମ୍ବା ସମ୍ପୂର୍ଣ୍ଣ E2E ସୁଇଟ୍ ଚଲାନ୍ତୁ:
npm run test:protocols:e2e
```

#### MCP କ୍ଲାଏଣ୍ଟ ବିନ୍ୟାସ

**Claude Code:**

```bash
claude mcp add-server omniroute --type http --url http://localhost:20128/api/mcp/stream
```

**Cursor / Cline:**

ଆପଣଙ୍କ MCP ସେଟିଂସ୍ରେ ଯୋଡ଼ନ୍ତୁ:

```json
{
  "mcpServers": {
    "omniroute": {
      "command": "omniroute",
      "args": ["--mcp"],
      "env": {}
    }
  }
}
```

**ସମ୍ପୂର୍ଣ୍ଣ MCP ଡକ୍ୟୁମେଣ୍ଟେସନ୍:** [MCP ସର୍ଭର୍ README](../../open-sse/mcp-server/README.md) — 110ଟି ଟୁଲ୍, IDE ବିନ୍ୟାସ, Python/TS/Go କ୍ଲାଏଣ୍ଟ।

### A2A ସେଟଅପ୍ (ଏଜେଣ୍ଟ-ଟୁ-ଏଜେଣ୍ଟ ପ୍ରୋଟୋକଲ୍)

Agent Card ଯାଞ୍ଚ କରନ୍ତୁ:

```bash
curl http://localhost:20128/.well-known/agent.json
```

ଗୋଟିଏ କାର୍ଯ୍ୟ ପଠାନ୍ତୁ:

```bash
curl -X POST http://localhost:20128/a2a \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":"quickstart","method":"message/send","params":{"skill":"quota-management","messages":[{"role":"user","content":"Give me a short quota summary."}]}}'
```

**ସମ୍ପୂର୍ଣ୍ଣ A2A ଡକ୍ୟୁମେଣ୍ଟେସନ୍:** [A2A ସର୍ଭର୍ README](../../src/lib/a2a/README.md) — JSON-RPC 2.0, କୌଶଳ, ଷ୍ଟ୍ରିମିଂ, କାର୍ଯ୍ୟ ଜୀବନଚକ୍ର।

## ଟାଇମ୍ଆଉଟ୍ ବିନ୍ୟାସ

### ମୌଳିକ ଟାଇମ୍ଆଉଟ୍ଗୁଡ଼ିକ

ଅଧିକାଂଶ ଡିପ୍ଲୟମେଣ୍ଟ ପାଇଁ, ଆପଣଙ୍କୁ କେବଳ ଏହି ଦୁଇଟି ଭେରିଏବଲ୍ ଆବଶ୍ୟକ:

| ଭେରିଏବଲ୍                 | ଡିଫଲ୍ଟ                                        | ଉଦ୍ଦେଶ୍ୟ                                                                                                                                                  |
| ------------------------ | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `REQUEST_TIMEOUT_MS`     | `600000`                                      | ଅପ୍ଷ୍ଟ୍ରିମ୍ ପ୍ରତିକ୍ରିୟା ଆରମ୍ଭ ଟାଇମ୍ଆଉଟ୍, ଲୁକ୍କାୟିତ Undici ଟାଇମ୍ଆଉଟ୍, TLS ଫିଙ୍ଗରପ୍ରିଣ୍ଟ ଅନୁରୋଧ ଏବଂ API ବ୍ରିଜ୍ ଅନୁରୋଧ/ପ୍ରକ୍ସି ଟାଇମ୍ଆଉଟ୍ ପାଇଁ ସହଭାଗୀ ଆଧାରମାନ |
| `STREAM_IDLE_TIMEOUT_MS` | `REQUEST_TIMEOUT_MS` ରୁ ଉତ୍ତରାଧିକାରରେ ପ୍ରାପ୍ତ | OmniRoute ଦ୍ୱାରା SSE ଷ୍ଟ୍ରିମ୍ ବନ୍ଦ କରାଯିବା ପୂର୍ବରୁ ଷ୍ଟ୍ରିମିଂ ଚଙ୍କ୍ଗୁଡ଼ିକ ମଧ୍ୟରେ ସର୍ବାଧିକ ବ୍ୟବଧାନ                                                          |

ପଛୁଆ ସୁସଙ୍ଗତତା ସଂରକ୍ଷିତ ରହିଛି: ବିଦ୍ୟମାନ `FETCH_TIMEOUT_MS`, `API_BRIDGE_PROXY_TIMEOUT_MS` ଏବଂ ଅନ୍ୟ ପ୍ରତି-ସ୍ତର ଟାଇମ୍ଆଉଟ୍ ଭେରିଏବଲ୍ଗୁଡ଼ିକ ଏବେ ମଧ୍ୟ କାମ କରନ୍ତି ଏବଂ ସହଭାଗୀ ଆଧାରମାନକୁ ଓଭର୍ରାଇଡ୍ କରନ୍ତି।

### ପ୍ରଦାନକାରୀ-ନିର୍ଦ୍ଦିଷ୍ଟ ଟିପ୍ପଣୀ

Claude Code-ସୁସଙ୍ଗତ ଅପ୍ଷ୍ଟ୍ରିମ୍ଗୁଡ଼ିକ (`anthropic-compatible-cc-*`) ପାଇଁ, OmniRoute ସମାଧାନ ହୋଇଥିବା ଫେଚ୍ ଟାଇମ୍ଆଉଟ୍ରୁ ଆଉଟ୍ବାଉଣ୍ଡ `X-Stainless-Timeout` ହେଡର୍ ନିର୍ଦ୍ଧାରଣ କରେ, ଯାହାଦ୍ୱାରା ପ୍ରଦାନକାରୀ-ପାର୍ଶ୍ୱ ରିଡ୍ ଟାଇମ୍ଆଉଟ୍ଗୁଡ଼ିକ ଆପଣଙ୍କ env ବିନ୍ୟାସ ସହ ସମନ୍ୱିତ ରହେ।

ତୃତୀୟ-ପକ୍ଷ Claude Code-ସୁସଙ୍ଗତ ରିଭର୍ସ ପ୍ରକ୍ସିଗୁଡ଼ିକ ପାଇଁ, OmniRoute ଡିଫଲ୍ଟ `anthropic-beta` ସେଟ୍କୁ ସଂଯମୀ ରଖେ ଏବଂ, `Client Cache Control`କୁ `Auto`ରେ ଛାଡ଼ିଦିଆଗଲେ, କେବଳ କ୍ଲାଏଣ୍ଟ ଦ୍ୱାରା ପ୍ରଦାନ କରାଯାଇଥିବା `cache_control` ମାର୍କର୍ଗୁଡ଼ିକୁ ଫର୍ୱାର୍ଡ କରେ। ଅପ୍ଷ୍ଟ୍ରିମ୍କୁ ବିଶେଷ ଭାବରେ ସଂଶୋଧିତ Claude ଚିନ୍ତନ ଷ୍ଟ୍ରିମ୍ ଆବଶ୍ୟକ ହେଲେ ମାତ୍ର ପ୍ରତି-ସଂଯୋଗ "Enable redact-thinking beta" ଟଗଲ୍ ସକ୍ଷମ କରନ୍ତୁ।

| `FETCH_CONNECT_TIMEOUT_MS`               | `30000`                                                       | Undici TCP ସଂଯୋଗ ଟାଇମ୍ଆଉଟ୍                                                                 |
| `FETCH_KEEPALIVE_TIMEOUT_MS`             | `4000`                                                        | Undici ନିଷ୍କ୍ରିୟ କିପ୍-ଅଲାଇଭ୍ ସକେଟ୍ ଟାଇମ୍ଆଉଟ୍                                               |
| `TLS_CLIENT_TIMEOUT_MS`                  | `FETCH_TIMEOUT_MS` ରୁ ଉତ୍ତରାଧିକାରରେ ପ୍ରାପ୍ତ                   | `wreq-js` ମାଧ୍ୟମରେ କରାଯାଇଥିବା TLS ଫିଙ୍ଗରପ୍ରିଣ୍ଟ ଅନୁରୋଧଗୁଡ଼ିକ ପାଇଁ ଟାଇମ୍ଆଉଟ୍                |
| `API_BRIDGE_PROXY_TIMEOUT_MS`            | `REQUEST_TIMEOUT_MS` କିମ୍ବା `600000` ରୁ ଉତ୍ତରାଧିକାରରେ ପ୍ରାପ୍ତ | API ପୋର୍ଟରୁ ଡ୍ୟାଶ୍ବୋର୍ଡ ପୋର୍ଟକୁ `/v1` ପ୍ରକ୍ସି ଫର୍ୱାର୍ଡିଂ ପାଇଁ ଟାଇମ୍ଆଉଟ୍                    |
| `API_BRIDGE_SERVER_REQUEST_TIMEOUT_MS`   | `max(API_BRIDGE_PROXY_TIMEOUT_MS, 300000)`                    | API ବ୍ରିଜ୍ ସର୍ଭର୍ରେ ଇନ୍କମିଂ ଅନୁରୋଧ ଟାଇମ୍ଆଉଟ୍                                               |
| `API_BRIDGE_SERVER_HEADERS_TIMEOUT_MS`   | `60000`                                                       | API ବ୍ରିଜ୍ ସର୍ଭର୍ରେ ଇନ୍କମିଂ ହେଡର୍ ଟାଇମ୍ଆଉଟ୍                                                |
| `API_BRIDGE_SERVER_KEEPALIVE_TIMEOUT_MS` | `5000`                                                        | API ବ୍ରିଜ୍ ସର୍ଭର୍ରେ କିପ୍-ଅଲାଇଭ୍ ଟାଇମ୍ଆଉଟ୍                                                  |
| `API_BRIDGE_SERVER_SOCKET_TIMEOUT_MS`    | `0`                                                           | API ବ୍ରିଜ୍ ସର୍ଭର୍ରେ ସକେଟ୍ ନିଷ୍କ୍ରିୟତା ଟାଇମ୍ଆଉଟ୍ (`0` ଏହାକୁ ଅକ୍ଷମ କରେ)                      |

> **ଟିପ୍ପଣୀ:** ଷ୍ଟ୍ରିମିଂ ଅନୁରୋଧଗୁଡ଼ିକ ପାଇଁ, `FETCH_TIMEOUT_MS` କେବଳ ସଂଯୋଗ ସେଟ୍ଅପ୍ / ପ୍ରଥମ ଅପ୍ଷ୍ଟ୍ରିମ୍ ପ୍ରତିକ୍ରିୟା ପାଇଁ ଅପେକ୍ଷା କରିବାକୁ ଅନ୍ତର୍ଭୁକ୍ତ କରେ। ଷ୍ଟ୍ରିମ୍ ସକ୍ରିୟ ହୋଇଗଲା ପରେ, OmniRoute କେବଳ ପ୍ରକୃତ ସ୍ଥଗିତତା (`STREAM_IDLE_TIMEOUT_MS`) କିମ୍ବା Undici ବଡି ନିଷ୍କ୍ରିୟତା (`FETCH_BODY_TIMEOUT_MS`) ହେଲେ ଏହାକୁ ବନ୍ଦ କରିବ।

### ରିଭର୍ସ ପ୍ରକ୍ସି ସୁସଙ୍ଗତତା

ଯଦି ଆପଣ OmniRouteକୁ Nginx, Caddy, Cloudflare କିମ୍ବା ଅନ୍ୟ କୌଣସି ରିଭର୍ସ ପ୍ରକ୍ସି ପଛରେ ଚଲାନ୍ତି, ତେବେ ପ୍ରକ୍ସି ଟାଇମ୍ଆଉଟ୍ଗୁଡ଼ିକ ମଧ୍ୟ ଆପଣଙ୍କ OmniRoute ଷ୍ଟ୍ରିମ୍/ଫେଚ୍ ଟାଇମ୍ଆଉଟ୍ଠାରୁ ଅଧିକ ଥିବା ନିଶ୍ଚିତ କରନ୍ତୁ।

## Void Linux (`xbps-src`) ଟେମ୍ପଲେଟ୍

Void Linux ବ୍ୟବହାରକାରୀମାନେ `xbps-src` ବ୍ୟବହାର କରି ଏକ ନେଟିଭ୍ ପ୍ୟାକେଜ୍ ବିଲ୍ଡ କରିପାରିବେ। ଏହି ବ୍ଲକ୍କୁ `srcpkgs/omniroute/template` ଭାବରେ ସଂରକ୍ଷଣ କରନ୍ତୁ:

```bash
# 'omniroute' ପାଇଁ ଟେମ୍ପଲେଟ୍ ଫାଇଲ୍
pkgname=omniroute
version=3.8.0
revision=1
hostmakedepends="nodejs python3 make"
depends="openssl"
short_desc="Universal AI gateway with smart routing for multiple LLM providers"
maintainer="zenobit <zenobit@disroot.org>"
license="MIT"
homepage="https://github.com/diegosouzapw/OmniRoute"
distfiles="https://github.com/diegosouzapw/OmniRoute/archive/refs/tags/v${version}.tar.gz"
# ପ୍ରତ୍ୟେକ ରିଲିଜ୍ ପାଇଁ ଏହା ବ୍ୟବହାର କରି checksum ପୁନଃ ସୃଷ୍ଟି କରନ୍ତୁ:
#   curl -L -o /tmp/omniroute.tar.gz "https://github.com/diegosouzapw/OmniRoute/archive/refs/tags/v${version}.tar.gz" && sha256sum /tmp/omniroute.tar.gz
checksum=PLACEHOLDER_REGENERATE_PER_RELEASE
system_accounts="_omniroute"
omniroute_homedir="/var/lib/omniroute"
export NODE_ENV=production
export npm_config_engine_strict=false
export npm_config_loglevel=error
export npm_config_fund=false
export npm_config_audit=false

do_build() {
	local _gyp_arch
	case "$XBPS_TARGET_MACHINE" in
		aarch64*) _gyp_arch=arm64 ;;
		armv7*|armv6*) _gyp_arch=arm ;;
		i686*) _gyp_arch=ia32 ;;
		*) _gyp_arch=x64 ;;
	esac

	NODE_ENV=development npm ci --ignore-scripts
	npm run build
	cp -r .next/static .next/standalone/.next/static
	[ -d public ] && cp -r public .next/standalone/public || true

	local _node_gyp=/usr/lib/node_modules/npm/node_modules/node-gyp/bin/node-gyp.js
	(cd node_modules/better-sqlite3 && node "$_node_gyp" rebuild --arch="$_gyp_arch")

	local _bs3_release=.next/standalone/node_modules/better-sqlite3/build/Release
	mkdir -p "$_bs3_release"
	cp node_modules/better-sqlite3/build/Release/better_sqlite3.node "$_bs3_release/"

	rm -rf .next/standalone/node_modules/@img

	for _mod in pino-abstract-transport split2 process-warning; do
		cp -r "node_modules/$_mod" .next/standalone/node_modules/
	done
}

do_check() {
	npm run test:unit
}

do_install() {
	vmkdir usr/lib/omniroute/.next
	vcopy .next/standalone/. usr/lib/omniroute/.next/standalone

	for _d in \
		.next/standalone/.next/server/app/dashboard \
		.next/standalone/.next/server/app/dashboard/settings \
		.next/standalone/.next/server/app/dashboard/providers; do
		touch "${DESTDIR}/usr/lib/omniroute/${_d}/.keep"
	done

	cat > "${WRKDIR}/omniroute" <<'EOF'
#!/bin/sh
export PORT="${PORT:-20128}"
export DATA_DIR="${DATA_DIR:-${XDG_DATA_HOME:-${HOME}/.local/share}/omniroute}"
export APP_LOG_TO_FILE="${APP_LOG_TO_FILE:-false}"
mkdir -p "${DATA_DIR}"
exec node /usr/lib/omniroute/.next/standalone/server.js "$@"
EOF
	vbin "${WRKDIR}/omniroute"
}

post_install() {
	vlicense LICENSE
}
```
