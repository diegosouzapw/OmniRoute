**OmniCopilot** ଆପଣଙ୍କ OmniRoute ଦ୍ୱାରା ପରିବେଷିତ ପ୍ରତ୍ୟେକ ମଡେଲ୍କୁ _ମୂଳ_ GitHub Copilot Chat
ମଡେଲ୍ ଚୟନକାରୀରେ ଉପଲବ୍ଧ କରାଏ। କୌଣସି ଦ୍ୱିତୀୟ ସାଇଡ୍ବାର୍ ନାହିଁ, କୌଣସି ପୃଥକ ଚାଟ୍ UI ନାହିଁ — Copilotର ଏଜେଣ୍ଟ ମୋଡ୍, ଟୁଲ୍ କଲିଂ,
MCP ସର୍ଭର୍ ଏବଂ କଷ୍ଟମ୍ ନିର୍ଦ୍ଦେଶାବଳୀ ସବୁ ପୂର୍ବବତ୍ କାମ କରେ, କେବଳ ଆପଣ ବାଛିଥିବା ମଡେଲ୍ରେ ଚାଲେ।

## ସେଟଅପ୍

1. **OmniRoute ଚଲାନ୍ତୁ** — `npm install -g omniroute && omniroute` (`http://localhost:20128`ରେ ଡ୍ୟାସ୍ବୋର୍ଡ)।
2. **ଏକ୍ସଟେନ୍ସନ୍ ଇନ୍ଷ୍ଟଲ୍ କରନ୍ତୁ** — Extensions ଭ୍ୟୁରେ "OmniRoute" ଖୋଜନ୍ତୁ।
3. **ଏକ ମଡେଲ୍ ବାଛନ୍ତୁ** — Copilot Chat → ମଡେଲ୍ ଚୟନକାରୀ → **Manage Models…** → **OmniRoute**, ତା’ପରେ
   ଆପଣ ଚାହୁଁଥିବାଗୁଡ଼ିକୁ ଟିକ୍ କରନ୍ତୁ।

OmniRoute ଡିଫଲ୍ଟ ପୋର୍ଟରେ ଚାଲୁଥିବାବେଳେ କିଛି ବିନ୍ୟାସ କରିବାକୁ ପଡ଼େ ନାହିଁ। ଏକ ରିମୋଟ୍ ଇନ୍ଷ୍ଟାନ୍ସ ପାଇଁ,
**Activity Barରେ ଥିବା OmniRoute ଆଇକନ୍** ଖୋଲନ୍ତୁ (କିମ୍ବା `OmniRoute: Manage Connection` ଚଲାନ୍ତୁ) ଏବଂ ନିମ୍ନଲିଖିତଗୁଡ଼ିକ ସେଟ୍ କରନ୍ତୁ:

- **ସର୍ଭର୍ URL** — ସର୍ଭର୍ର ରୁଟ୍, ଯେପରିକି `http://192.168.0.15:20128`। `/v1` ସଫିକ୍ସକୁ
  ଏକ୍ସଟେନ୍ସନ୍ ଯୋଡ଼େ; ଏହାକୁ ସାମିଲ କରନ୍ତୁ ନାହିଁ।
- **API କୀ** — ସର୍ଭର୍ `REQUIRE_API_KEY` ସେଟ୍ କରିଥିଲେ କେବଳ ଏହା ଆବଶ୍ୟକ। VS
  Code SecretStorage ମାଧ୍ୟମରେ OS କୀଚେନ୍ରେ ସଂରକ୍ଷିତ ହୁଏ, `settings.json`ରେ କେବେ ନୁହେଁ।

## ଚୟନକାରୀ କ’ଣ ଦେଖାଇବ

ଏକ୍ସଟେନ୍ସନ୍ଟି ଅପରିବର୍ତ୍ତିତ `GET /v1/models` ପେଲୋଡ୍ ଦେଖାଏ ନାହିଁ — ଏହା ତାହାକୁ ଆକାର ଦିଏ, ଏବଂ ଆପଣ
ଦେଖୁଥିବା ସଂଖ୍ୟାଟି ଦୁଇଟି ସୁଚିନ୍ତିତ କାରଣରୁ କ୍ୟାଟାଲଗ୍ ଆକାରଠାରୁ କମ୍ ଅଟେ।

### ଏହା ପ୍ରତ୍ୟେକ ମଡେଲ୍ ପାଇଁ ଗୋଟିଏ id ଅନୁରୋଧ କରେ

`MODELS_CATALOG_PREFIX_MODE`ର ଡିଫଲ୍ଟ ହେଉଛି **`dual`**, ଯାହା ପ୍ରତ୍ୟେକ ମଡେଲ୍କୁ ଦୁଇଥର ଘୋଷଣା କରେ — ଥରେ
ସଂକ୍ଷିପ୍ତ ଉପନାମ ପ୍ରିଫିକ୍ସ ଅଧୀନରେ ଏବଂ ଥରେ ମାନକ ପ୍ରଦାନକାରୀ ପ୍ରିଫିକ୍ସ ଅଧୀନରେ — ଯାହାଦ୍ୱାରା ପୁରୁଣା କ୍ଲାଏଣ୍ଟ
ବିନ୍ୟାସଗୁଡ଼ିକ ଉଭୟ ରୂପକୁ ରିଜଲ୍ଭ କରିପାରିବ:

```
cc/claude-sonnet-4-6        ← ଉପନାମ ପ୍ରିଫିକ୍ସ
claude/claude-sonnet-4-6    ← ମାନକ ପ୍ରିଫିକ୍ସ, ସମାନ ମଡେଲ୍
```

ଏକ୍ସଟେନ୍ସନ୍ **`GET /v1/models?prefix=alias`** ଅନୁରୋଧ କରେ, ଯାହାଦ୍ୱାରା ଆପଣଙ୍କ ଅନ୍ୟ କ୍ଲାଏଣ୍ଟଗୁଡ଼ିକ ପାଇଁ
ସର୍ଭର୍-ବ୍ୟାପୀ ସେଟିଂ ପରିବର୍ତ୍ତନ ନକରି ପ୍ରତ୍ୟେକ ମଡେଲ୍ ପାଇଁ ଗୋଟିଏ id ଆସେ। ଏକ ସନ୍ଦର୍ଭ ଇନ୍ଷ୍ଟାନ୍ସରେ ଏହା
**2345ଟି ଏଣ୍ଟ୍ରିକୁ 1396କୁ ହ୍ରାସ କରିଥିଲା — 949ଟି ନକଲ, କୌଣସି ମଡେଲ୍ ହଜିନଥିଲା।**

ଯଦି ଆପଣ _ପ୍ରତ୍ୟେକ_ କ୍ଲାଏଣ୍ଟ ପାଇଁ ସର୍ଭର୍-ବ୍ୟାପୀ ଭାବରେ ଏହାକୁ ଠିକ୍ କରିବାକୁ ଚାହାନ୍ତି, ତେବେ ଡ୍ୟାସ୍ବୋର୍ଡରେ
`MODELS_CATALOG_PREFIX_MODE` ଫିଚର୍ ଫ୍ଲାଗ୍କୁ `alias`ରେ ସେଟ୍ କରନ୍ତୁ। କ୍ୱେରି ପାରାମିଟର୍ ଏବଂ
ପ୍ରତ୍ୟେକ-ମୋଡ୍ ଟେବୁଲ୍ ପାଇଁ [API_REFERENCE → ପ୍ରିଫିକ୍ସ](../reference/API_REFERENCE.md#model-id-prefixes-prefix) ଦେଖନ୍ତୁ।

### ଏହା ଚାଟ୍ କରିପାରୁ ନଥିବା ମଡେଲ୍ଗୁଡ଼ିକୁ ଲୁଚାଏ

କ୍ୟାଟାଲଗ୍ରେ ଇମେଜ୍, ଭିଡିଓ, ଅଡିଓ, ରିର୍ୟାଙ୍କ, ଏମ୍ବେଡିଂ ଏବଂ ମଡରେସନ୍ ମଡେଲ୍ଗୁଡ଼ିକ ମଧ୍ୟ ତାଲିକାଭୁକ୍ତ ହୋଇଛି। ସେଗୁଡ଼ିକୁ
ଚାଟ୍ ଅନୁରୋଧରେ ଯାହାହେଉ ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ:

```
HTTP 400 — ମଡେଲ୍ '<id>' ଏକ ଇମେଜ୍-ଜେନେରେସନ୍ ମଡେଲ୍ ଏବଂ ଏହାକୁ
/v1/chat/completionsରେ ବ୍ୟବହାର କରାଯାଇପାରିବ ନାହିଁ। ଏହା ପରିବର୍ତ୍ତେ POST /v1/images/generations ବ୍ୟବହାର କରନ୍ତୁ।
```

ତେଣୁ ଚୟନକାରୀରେ ପହଞ୍ଚିବା ପୂର୍ବରୁ ସେଗୁଡ଼ିକୁ ସେମାନଙ୍କ `type` ଫିଲ୍ଡ ଆଧାରରେ ଫିଲ୍ଟର୍ କରାଯାଏ। **Responses-API
ମଡେଲ୍ଗୁଡ଼ିକ ରଖାଯାଏ** — ପ୍ରତ୍ୟେକ Codex / GPT-5.x ଏଣ୍ଟ୍ରି `supported_endpoints: ["responses"]` ଘୋଷଣା କରେ,
ଏବଂ OmniRoute `/v1/chat/completions` ପାଇଁ ସେଗୁଡ଼ିକୁ ଅନୁବାଦ କରେ, ତେଣୁ ସେଗୁଡ଼ିକ ସମ୍ପୂର୍ଣ୍ଣ ଭାବେ ବ୍ୟବହାରଯୋଗ୍ୟ।

### ଆପଣ କେବେ ବିନ୍ୟାସ କରିନଥିବା ପ୍ରଦାନକାରୀମାନେ

କ୍ୟାଟାଲଗ୍ରେ **ସକ୍ରିୟ କନେକ୍ସନ୍** ଥିବା ପ୍ରଦାନକାରୀମାନଙ୍କର ମଡେଲ୍ _ସହିତ_ ପ୍ରତ୍ୟେକ **noAuth**
ପ୍ରଦାନକାରୀ ତାଲିକାଭୁକ୍ତ ହୁଏ — ଅର୍ଥାତ୍ ମାଗଣା ସ୍ତରର ବଡ଼ ଅଂଶ ଗଠନ କରୁଥିବା କୀ-ବିହୀନ ପ୍ରଦାନକାରୀମାନେ। ଏହା ଉଦ୍ଦେଶ୍ୟମୂଳକ। ସେଗୁଡ଼ିକୁ ଲୁଚାଇବା ପାଇଁ,
ଡ୍ୟାସ୍ବୋର୍ଡ ସେଟିଂସ୍ରେ `blockedProviders`କୁ ସେଗୁଡ଼ିକୁ ଯୋଡ଼ନ୍ତୁ; ଏକ୍ସଟେନ୍ସନ୍ରେ କିଛି ପରିବର୍ତ୍ତନ ହୁଏ ନାହିଁ।

## VS Code ଟ୍ୟାବ୍ ଭିତରେ ଡ୍ୟାଶବୋର୍ଡ

`omnicopilot.dashboardOpen: "editor"` ବାହ୍ୟ ବ୍ରାଉଜର୍ ପରିବର୍ତ୍ତେ Simple Browser ମାଧ୍ୟମରେ ଏକ editor ଟ୍ୟାବ୍ରେ OmniRoute ଡ୍ୟାଶବୋର୍ଡକୁ ରେଣ୍ଡର୍ କରେ। ଏମ୍ବେଡିଂ ସର୍ଭର୍ରେ **ଅପ୍ଟ-ଇନ୍** ଅଟେ ଏବଂ ଏହା `DASHBOARD_ALLOW_EMBED=vscode` ମାଧ୍ୟମରେ ସକ୍ଷମ ହୁଏ, ଯାହା ଡିଫଲ୍ଟ `frame-ancestors 'none'` +
`X-Frame-Options: DENY` ପରିବର୍ତ୍ତେ
`frame-ancestors 'self' vscode-webview:` ସହିତ HTML ପୃଷ୍ଠାଗୁଡ଼ିକୁ ପରିବେଷଣ କରେ। API ପୃଷ୍ଠତଳ (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) ଉଭୟ ପରିସ୍ଥିତିରେ କଠୋର ହେଡର୍ଗୁଡ଼ିକୁ ଅପରିବର୍ତ୍ତିତ ରଖେ।

> ⚠️ **ଏହା ଏକ ବିଲ୍ଡ-ଟାଇମ୍ ଫ୍ଲାଗ୍, ରନ୍ଟାଇମ୍ ଫ୍ଲାଗ୍ ନୁହେଁ।** Next.js `headers()`କୁ ରୁଟ୍
> ମ୍ୟାନିଫେଷ୍ଟରେ କମ୍ପାଇଲ୍ କରେ, ତେଣୁ ବଣ୍ଡଲ୍ ବିଲ୍ଡ ହେଉଥିବା ସମୟରେ `next.config.mjs` ଭେରିଏବଲ୍ଟିକୁ ପଢ଼େ
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`)।
> ପୂର୍ବରୁ ବିଲ୍ଡ ହୋଇଥିବା ସର୍ଭର୍ର ସମ୍ମୁଖରେ ଏହାକୁ export କଲେ କିଛି ପରିବର୍ତ୍ତନ ହୁଏ ନାହିଁ — ହେଡର୍ଗୁଡ଼ିକ ବିଲ୍ଡରେ ସ୍ଥାୟୀ ଭାବେ ସାମିଲ ହୋଇଯାଇଥାଏ।

```bash
# ଭେରିଏବଲ୍ଟି BUILD କମାଣ୍ଡରେ ଉପସ୍ଥିତ ରହିବା ଆବଶ୍ୟକ
DASHBOARD_ALLOW_EMBED=vscode npm run build        # କିମ୍ବା npm run build:release
npm start
```
