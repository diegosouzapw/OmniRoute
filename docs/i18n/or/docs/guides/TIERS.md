OmniRoute ସମର୍ଥିତ 352ଟି ପ୍ରଦାନକାରୀଙ୍କୁ 3ଟି ଆର୍ଥିକ ସ୍ତରରେ ସଂଗଠିତ କରେ। ପ୍ରତ୍ୟେକ
ଅନୁରୋଧ କୌଣସି ଗୋଟିଏ ପ୍ରଦାନକାରୀ ସଫଳତାର ସହ ଉତ୍ତର ଦେବା ପର୍ଯ୍ୟନ୍ତ କ୍ରମାନୁସାରେ ସେମାନଙ୍କ ମାଧ୍ୟମରେ
ଯାଏ — କୌଣସି ଫଲ୍ବ୍ୟାକ୍ କୋଡ୍ ନ ଲେଖି ଆପଣ ସବୁଠାରୁ ଶସ୍ତା କାର୍ଯ୍ୟକ୍ଷମ ଉତ୍ତର
ପାଆନ୍ତି।

## ସ୍ତର 1 — ସବ୍ସ୍କ୍ରିପ୍ସନ୍

**ଯେଉଁ ପ୍ରଦାନକାରୀଙ୍କ ପାଇଁ ଆପଣ ପୂର୍ବରୁ ଦେୟ ପ୍ରଦାନ କରୁଛନ୍ତି।** କୋଟାର ସମୟସୀମା ଶେଷ ହେବା ପୂର୍ବରୁ
OmniRoute ତାହାର ପ୍ରତ୍ୟେକ ଅଂଶ ବ୍ୟବହାର କରେ।

| ପ୍ରଦାନକାରୀ                            | ସ୍ତର 1 ହେବାର କାରଣ                                     |
| ------------------------------------- | ----------------------------------------------------- |
| Claude Code OAuth                     | Anthropic Pro/Team — ନିର୍ଦ୍ଧାରିତ ଦର, ପ୍ରାୟତଃ ଅବ୍ୟବହୃତ |
| OpenAI Codex (ChatGPT ସବ୍ସ୍କ୍ରିପ୍ସନ୍) | Plus/Team ମଧ୍ୟରେ Codex କୋଟା ଅନ୍ତର୍ଭୁକ୍ତ               |
| GitHub Copilot                        | ପ୍ରତି-ସିଟ୍ — କୋଟା ପ୍ରତି ମାସରେ ରିସେଟ୍ ହୁଏ              |
| Cursor IDE                            | Pro ପ୍ଲାନ୍ କୋଟା                                       |
| Antigravity / Devin Desktop           | ଅନ୍ତର୍ନିର୍ମିତ କୋଟା                                    |

**କୌଶଳ**: ମଡେଲ୍ର ସାମର୍ଥ୍ୟ ସହ ମେଳ ଖାଉଥିବା ପ୍ରତ୍ୟେକ ଅନୁରୋଧକୁ ପ୍ରଥମେ ଏଠାକୁ
ରୁଟ୍ କରନ୍ତୁ। କୋଟା ଟ୍ରାକର୍ ନିକଟବର୍ତ୍ତୀ ରିସେଟ୍ଗୁଡ଼ିକୁ ନିରୀକ୍ଷଣ କରେ ଏବଂ `reset-aware`
କମ୍ବୋ କୌଶଳ ସେହି ଅନୁସାରେ ପ୍ରାଥମିକତା ଦିଏ। ପ୍ରଥମେ ସ୍ତର 1କୁ ରୁଟ୍ କରିବା ଏବଂ କୋଟା ଶେଷ ହେଲେ ମାତ୍ର
ଦେୟଯୁକ୍ତ ସ୍ତରକୁ ଯିବା ପାଇଁ `auto/thrifty` id ବ୍ୟବହାର କରନ୍ତୁ — କିମ୍ବା ପ୍ଲାନ୍ରେ
ଅନ୍ତର୍ଭୁକ୍ତ କ୍ଷମତା ମଧ୍ୟରେ ରହିବା ଏବଂ ତାହା ନ ମିଳିଲେ ବନ୍ଦ ହୋଇ ବିଫଳ ହେବା ପାଇଁ `auto/subscription`
ବ୍ୟବହାର କରନ୍ତୁ। [ସବ୍ସ୍କ୍ରିପ୍ସନ୍-ପ୍ରଥମ ରାଉଟିଂ](../routing/SUBSCRIPTION_LADDER.md) ଦେଖନ୍ତୁ।

| ପ୍ରଦାନକାରୀ       | ମାଗଣା କୋଟା / କ୍ରେଡିଟ୍                       |
| ---------------- | ------------------------------------------- |

| OpenCode Free    | କୌଣସି ପ୍ରମାଣୀକରଣ ନାହିଁ, ଉଦାର ହାର ସୀମା       |

ବଜେଟ୍ ସୀମା ସହିତ `auto` କମ୍ବୋ ଅନୁରୋଧକୁ ଏଠାକୁ ରୁଟ୍ କରେ। ମାଗଣା ପ୍ରଦାନକାରୀଙ୍କ ହାର
ସୀମା ପ୍ରାୟତଃ କମ୍ ଥାଏ — ବ୍ୟାକଅଫ୍ ସମୟରେ ସର୍କିଟ୍ ବ୍ରେକର୍ ସେମାନଙ୍କୁ ପୁନରୁଦ୍ଧାର କରେ।

## ସ୍ତରଗୁଡ଼ିକୁ ବିନ୍ୟାସ କରିବା

ଡ୍ୟାସ୍ବୋର୍ଡ → **ସ୍ତରଗୁଡ଼ିକ** → ଆପଣଙ୍କ ପ୍ରଦାନକାରୀଙ୍କୁ ନିର୍ଦ୍ଧାରଣ କରନ୍ତୁ। ଡିଫଲ୍ଟଗୁଡ଼ିକ (`tierDefaults.json`ରୁ)
ଯୁକ୍ତିସଙ୍ଗତ; ନିର୍ଦ୍ଦିଷ୍ଟ ସବ୍ସ୍କ୍ରିପ୍ସନ୍କୁ ପ୍ରାଥମିକତା ଦେବା କିମ୍ବା ପ୍ରଦାନକାରୀଙ୍କୁ ବାଦ ଦେବା ଆବଶ୍ୟକ ହେଲେ ସମ୍ପାଦନା କରନ୍ତୁ।

Auto-Comboର 16-ଉପାଦାନ ସ୍କୋରିଂ ମଧ୍ୟ ସ୍ତରକୁ ବିଚାର କରେ।
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) ଦେଖନ୍ତୁ।

## ଟେଲିମେଟ୍ରି

ଡ୍ୟାସ୍ବୋର୍ଡ → **ବ୍ୟବହାର** ପ୍ରତିଦିନ ପ୍ରତ୍ୟେକ ସ୍ତରରେ ବ୍ୟୟ ହୋଇଥିବା ଟୋକନ୍ ଦେଖାଏ। ଏହାକୁ ନିମ୍ନଲିଖିତ କାର୍ଯ୍ୟ ପାଇଁ ବ୍ୟବହାର କରନ୍ତୁ:

- ସ୍ତର 1 ସମ୍ପୂର୍ଣ୍ଣ ଭାବେ ବ୍ୟବହୃତ ହେଉଛି ବୋଲି ନିଶ୍ଚିତ କରନ୍ତୁ (ନଚେତ୍ ଆପଣ ସବ୍ସ୍କ୍ରିପ୍ସନ୍ ମୂଲ୍ୟ ଅପଚୟ କରୁଛନ୍ତି)
- କେଉଁ ସ୍ତର 2 ମଡେଲ୍ ସର୍ବାଧିକ ବଛାଯାଉଛି ଚିହ୍ନଟ କରନ୍ତୁ (1-2ଟିରେ ଏକତ୍ରୀକରଣ କରନ୍ତୁ)
- ସ୍ତର 3 ପରୀକ୍ଷଣ/ଅନ୍ୱେଷଣ କାର୍ଯ୍ୟଭାରରେ ଟଙ୍କା ସଞ୍ଚୟ କରୁଛି ବୋଲି ଯାଞ୍ଚ କରନ୍ତୁ

## ସାଧାରଣ ଢାଞ୍ଚା

### ସମ୍ପୂର୍ଣ୍ଣ ମାଗଣା କାର୍ଯ୍ୟଭାର

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

ସ୍ତର 3 ଆଡ଼କୁ ଦୃଢ଼ ଭାବରେ ନିର୍ଦ୍ଦେଶିତ କରେ; ସ୍ତର 3 ଉପଲବ୍ଧ ନଥିଲେ ମାତ୍ର ସ୍ତର 2 ବ୍ୟବହାର କରେ।

### ଶସ୍ତା ଫଲ୍ବ୍ୟାକ୍ ସହିତ ସବ୍ସ୍କ୍ରିପ୍ସନ୍-ପ୍ରଥମ

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

ସ୍ତର 1 → ସ୍ତର 2 → ସ୍ତର 3 ସହ ମେଳ ଖାଉଥିବା ସ୍ପଷ୍ଟ କ୍ରମବଦ୍ଧ ତାଲିକା।
