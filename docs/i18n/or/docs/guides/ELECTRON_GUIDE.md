> **ସତ୍ୟର ଉତ୍ସ:** `electron/` ୱର୍କସ୍ପେସ୍
> **ଶେଷ ଅଦ୍ୟତନ:** 2026-06-28 — v3.8.40

OmniRoute, **Electron 41** + **electron-builder 26.10** ଉପରେ ନିର୍ମିତ ଏକ କ୍ରସ୍-ପ୍ଲାଟଫର୍ମ ଡେସ୍କଟପ୍ ଆପ୍ (Windows / macOS / Linux) ପ୍ରଦାନ କରେ। ଡେସ୍କଟପ୍ ଆପ୍ଟି Next.js ଷ୍ଟାଣ୍ଡଅଲୋନ୍ ସର୍ଭର୍କୁ ଏକ ଚାଇଲ୍ଡ ପ୍ରୋସେସ୍ ଭାବେ ଆରମ୍ଭ କରେ, ଏକ `BrowserWindow`କୁ ଏହା ଆଡ଼କୁ ନିର୍ଦ୍ଦେଶ କରେ, ଏବଂ ଏକ ସିଷ୍ଟମ୍ ଟ୍ରେ, ସ୍ୱୟଂଚାଳିତ ଅପଡେଟର୍, IPC ବ୍ରିଜ୍ ଓ ଶୂନ୍ୟ-କନଫିଗରେସନ୍ ସିକ୍ରେଟ୍ ବୁଟ୍ଷ୍ଟ୍ରାପ୍ ଯୋଡ଼େ।

| `npm run electron:dev`            | `npm run dev` ଆରମ୍ଭ କରେ + `localhost:20128` ପାଇଁ ଅପେକ୍ଷା କରେ + Electron ଚାଲୁ କରେ        |

`electron/` ୱର୍କସ୍ପେସ୍ ନିମ୍ନଲିଖିତଗୁଡ଼ିକୁ ମଧ୍ୟ ଉପଲବ୍ଧ କରାଏ:

- `npm run prepare:bundle` — `scripts/build/prepare-electron-standalone.mjs` ଚଲାଏ
- `npm run build:mac-x64` / `build:mac-arm64` — ଏକକ-ଆର୍କିଟେକ୍ଚର୍ macOS ବିଲ୍ଡଗୁଡ଼ିକ
- `npm run pack` — ସ୍ଥାନୀୟ ପରୀକ୍ଷଣ ପାଇଁ କେବଳ-ଡିରେକ୍ଟୋରୀ ବିଲ୍ଡ (କୌଣସି ଇନ୍ଷ୍ଟଲର୍ ନାହିଁ)

## IPC ସେତୁ (`preload.js`)

ପ୍ରିଲୋଡ୍, `contextIsolation: true` ଏବଂ `nodeIntegration: false` ସହିତ `contextBridge`
ବ୍ୟବହାର କରି `window.electronAPI` ରେ ଏକ ଅନୁମୋଦିତ API ପ୍ରକାଶ କରେ।

```javascript
const VALID_CHANNELS = {
  invoke: [
    "get-app-info",
    "open-external",
    "get-data-dir",
    "restart-server",
    "check-for-updates",
    "download-update",
    "install-update",
    "get-app-version",
  ],
  send: ["window-minimize", "window-maximize", "window-close"],
  receive: ["server-status", "port-changed", "update-status"],
};
```

ପ୍ରକାଶିତ ପଦ୍ଧତିଗୁଡ଼ିକ:

| ରେଣ୍ଡରର୍ କଲ୍                                                      | ପ୍ରକାର                    |
| ----------------------------------------------------------------- | ------------------------- |
| `getAppInfo()` → `{ name, version, platform, isDev, port }`       | invoke                    |
| `openExternal(url)`                                               | invoke                    |
| `getDataDir()`                                                    | invoke                    |
| `restartServer()`                                                 | invoke                    |
| `getAppVersion()`                                                 | invoke                    |
| `checkForUpdates()` / `downloadUpdate()` / `installUpdate()`      | invoke                    |
| `minimizeWindow()` / `maximizeWindow()` / `closeWindow()`         | send                      |
| `onServerStatus(cb)` / `onPortChanged(cb)` / `onUpdateStatus(cb)` | receive (ଡିସ୍ପୋଜର୍ ଫେରାଏ) |

ରିସିଭ୍ ସହାୟକଗୁଡ଼ିକ `removeAllListeners` ଉପରେ ନିର୍ଭର କରିବା ପରିବର୍ତ୍ତେ ଏକ **ଡିସ୍ପୋଜର୍ ଫଙ୍କସନ୍**
ଫେରାନ୍ତି — React କମ୍ପୋନେଣ୍ଟଗୁଡ଼ିକ ପୁନଃ ମାଉଣ୍ଟ ହେବାବେଳେ ଏହା ଲିସନର୍ଗୁଡ଼ିକର
ସଞ୍ଚୟକୁ ପ୍ରତିରୋଧ କରେ।

## ସର୍ଭର୍ ଜୀବନଚକ୍ର

ସିଷ୍ଟମ୍ Node ସହିତ ନେଟିଭ୍-ମଡ୍ୟୁଲ୍ ABI ଅମେଳକୁ ଏଡ଼ାଇବା ପାଇଁ `main.js`, Electron Node
ରନ୍ଟାଇମ୍ରେ ସିଧାସଳଖ Next.js ଷ୍ଟାଣ୍ଡଅଲୋନ୍ ବଣ୍ଡଲ୍କୁ ଆରମ୍ଭ କରେ:

```js
spawn(process.execPath, [serverScript], {
  cwd: NEXT_SERVER_PATH,
  env: {
    ...serverEnv,
    PORT,
    NODE_ENV: "production",
    ELECTRON_RUN_AS_NODE: "1",
    NODE_PATH,
  },
  stdio: "pipe",
});
```

ମୁଖ୍ୟ ବିଶେଷତାଗୁଡ଼ିକ:

- ୱିଣ୍ଡୋ ଦେଖାଇବା ପୂର୍ବରୁ `waitForServer()` ସର୍ବାଧିକ 30 s ପର୍ଯ୍ୟନ୍ତ URL କୁ ପୋଲ୍ କରେ (କୋଲ୍ଡ ଷ୍ଟାର୍ଟ ସମୟରେ କୌଣସି ଖାଲି ସ୍କ୍ରିନ୍ ନାହିଁ)।
- `stdio: "pipe"` stdout/stderr କ୍ୟାପଚର୍ କରେ; ପ୍ରସ୍ତୁତି ସୂଚକ ବାକ୍ୟାଂଶଗୁଡ଼ିକ (`Ready` / `listening`) IPC ମାଧ୍ୟମରେ `server-status: running` ନିର୍ଗତ କରନ୍ତି।
- `before-quit`, ସୁଚାରୁ SIGTERM (WAL ଚେକ୍ପଏଣ୍ଟ) ପାଇଁ ସର୍ବାଧିକ 5 s ଅପେକ୍ଷା କରେ, ତା’ପରେ SIGKILL ପଠାଏ।
- ଟ୍ରେରେ ଥିବା ପୋର୍ଟ ସ୍ୱିଚର୍ (`20128`, `3000`, `8080`) ସର୍ଭର୍କୁ ବନ୍ଦ କରି ପୁନଃଚାଳୁ କରେ, ତା’ପରେ BrowserWindow କୁ ପୁନଃ ଲୋଡ୍ କରେ।

## ଶୂନ୍ୟ-ବିନ୍ୟାସ ଗୁପ୍ତତଥ୍ୟ ବୁଟ୍ଷ୍ଟ୍ରାପ୍

ପ୍ରଥମ ଲଞ୍ଚ୍ରେ, ମୁଖ୍ୟ ପ୍ରକ୍ରିୟା ଅନୁପସ୍ଥିତ ଗୁପ୍ତତଥ୍ୟଗୁଡ଼ିକୁ ସ୍ୱୟଂଚାଳିତ ଭାବେ ସୃଷ୍ଟି ଏବଂ ସ୍ଥାୟୀ ଭାବେ ସଂରକ୍ଷଣ କରେ:

| ଗୁପ୍ତତଥ୍ୟ                | ଉତ୍ସ                                                                                              |
| ------------------------ | ------------------------------------------------------------------------------------------------- |
| `JWT_SECRET`             | `crypto.randomBytes(64).toString("hex")`                                                          |
| `STORAGE_ENCRYPTION_KEY` | `crypto.randomBytes(32).toString("hex")` (ଏନ୍କ୍ରିପ୍ଟ ହୋଇଥିବା ପରିଚୟପତ୍ର ପୂର୍ବରୁ ଥିଲେ ଅସ୍ୱୀକାର କରେ) |
| `API_KEY_SECRET`         | `crypto.randomBytes(32).toString("hex")`                                                          |

`<DATA_DIR>/server.env`ରେ ସ୍ଥାୟୀ ଭାବେ ସଂରକ୍ଷିତ ହୁଏ। `DATA_DIR` ନିମ୍ନଲିଖିତ ଭାବେ ସମାଧାନ ହୁଏ:

- Windows: `%APPDATA%\omniroute`
- Linux: `$XDG_CONFIG_HOME/omniroute` କିମ୍ବା `~/.omniroute`
- macOS: `~/.omniroute`

## ୱିଣ୍ଡୋ ଏବଂ ଟ୍ରେ

- `BrowserWindow`: 1400×900 (ସର୍ବନିମ୍ନ 1024×700), `backgroundColor: "#0a0a0a"`.
- macOS: `titleBarStyle: "hiddenInset"`, `{ x: 16, y: 16 }`ରେ ଟ୍ରାଫିକ୍-ଲାଇଟ୍।
- Windows/Linux: ନେଟିଭ୍ ଟାଇଟଲ୍ ବାର୍।
- ବନ୍ଦ ବଟନ୍ ଟ୍ରେକୁ ମିନିମାଇଜ୍ କରେ; ଟ୍ରେ ମେନୁରେ **OmniRoute ଖୋଲନ୍ତୁ**, **ଡ୍ୟାସ୍ବୋର୍ଡ ଖୋଲନ୍ତୁ** (ବାହ୍ୟ ବ୍ରାଉଜର୍), **ସର୍ଭର୍ ପୋର୍ଟ** ସବ୍ମେନୁ, **ଅପଡେଟ୍ ଯାଞ୍ଚ କରନ୍ତୁ**, **ପ୍ରସ୍ଥାନ କରନ୍ତୁ** ରହିଛି।

## ବିଷୟବସ୍ତୁ ସୁରକ୍ଷା ନୀତି

`session.defaultSession.webRequest.onHeadersReceived` ମାଧ୍ୟମରେ ସେଟ୍ କରାଯାଏ। ଉଲ୍ଲେଖନୀୟ ନିର୍ଦ୍ଦେଶଗୁଡ଼ିକ:

- `frame-ancestors 'none'`, `object-src 'none'`, `child-src 'none'`
- `connect-src 'self' http://localhost:* http://127.0.0.1:* ws://localhost:* ws://127.0.0.1:* https://*.omniroute.online https://*.omniroute.dev`
- ଡେଭ୍ ମୋଡ୍ କେବଳ `script-src`ରେ `'unsafe-eval'` ଯୋଡ଼େ

## ସ୍ୱୟଂଚାଳିତ ଅପଡେଟ୍

GitHub ପ୍ରଦାନକାରୀ (`diegosouzapw/OmniRoute`) ସହିତ `electron-updater` ବ୍ୟବହାର କରେ।

- ଇଭେଣ୍ଟଗୁଡ଼ିକୁ `update-status` IPC ମାଧ୍ୟମରେ ରେଣ୍ଡରର୍କୁ ପଠାଯାଏ:
  `checking`, `available`, `not-available`, `downloading` (`percent` ସହିତ), `downloaded`, `error`
- `installUpdate()` ସର୍ଭର୍କୁ ବନ୍ଦ କରେ ଏବଂ ତା’ପରେ `autoUpdater.quitAndInstall()`କୁ କଲ୍ କରେ
- ଡେଭ୍ ମୋଡ୍ରେ (`!app.isPackaged`) ଏହାକୁ ଏଡ଼ାଇ ଦିଆଯାଏ

## ବିଲ୍ଡ ପାଇପ୍ଲାଇନ୍

1. `npm run build` → `.next/standalone`ରେ Next.js ସ୍ୱତନ୍ତ୍ର ବିଲ୍ଡ।
2. `prepare-electron-standalone.mjs` → `.next/electron-standalone`ରେ ପୁନଃ ଷ୍ଟେଜ୍ କରେ ଏବଂ `server.js` + `required-server-files.json` ଭିତରେ ଥିବା ଆବ୍ସୋଲ୍ୟୁଟ୍ ପଥଗୁଡ଼ିକୁ ପୁନର୍ଲିଖନ କରେ, ଯାହାଦ୍ୱାରା ବଣ୍ଡଲ୍କୁ ସ୍ଥାନାନ୍ତର କରାଯାଇପାରିବ।
3. `electron-builder`, `main.js`, `preload.js`, `node_modules`, ଏବଂ `extraResources: { ../.next/electron-standalone → app }`କୁ ପ୍ୟାକେଜ୍ କରେ।

## ପ୍ୟାକେଜ୍ ହୋଇଥିବା ବିଲ୍ଡର ସ୍ମୋକ୍ ପରୀକ୍ଷଣ

```bash
npm run electron:smoke:packaged
```

`scripts/dev/smoke-electron-packaged.mjs`:

- ବର୍ତ୍ତମାନର ପ୍ଲାଟଫର୍ମ ପାଇଁ `electron/dist-electron/`ରେ ପ୍ୟାକେଜ୍ ହୋଇଥିବା ବାଇନେରୀକୁ ସ୍ୱୟଂଚାଳିତ ଭାବେ ଖୋଜିଥାଏ।
- ପୃଥକ୍ `HOME`/`APPDATA`/`XDG_*` ଡିରେକ୍ଟୋରୀ ସହିତ ଲଞ୍ଚ୍ କରେ, ଯାହାଦ୍ୱାରା ଏହା ଡେଭଲପର୍ ଡାଟାକୁ ସ୍ପର୍ଶ କରେ ନାହିଁ।
- 45 s ମଧ୍ୟରେ HTTP 200 ପାଇଁ `http://127.0.0.1:20128/login`କୁ ପୋଲ୍ କରେ।
- ମାରାତ୍ମକ ପାଟର୍ନଗୁଡ଼ିକ (`Cannot find module`, `MODULE_NOT_FOUND`, `ERR_DLOPEN_FAILED`, `Failed to start server`, ଇତ୍ୟାଦି) ପାଇଁ stderr/stdoutକୁ ନିରୀକ୍ଷଣ କରେ।
- ପ୍ରସ୍ତୁତି ପରେ 2 s ସ୍ଥିର ରନ୍ଟାଇମ୍ ପାଇଁ ଅପେକ୍ଷା କରେ, ତା’ପରେ SIGTERM ଜାରି କରି ପୋର୍ଟ ମୁକ୍ତ ହେବା ପର୍ଯ୍ୟନ୍ତ ଅପେକ୍ଷା କରେ।
- CIରେ, ସ୍ୱୟଂଚାଳିତ ଭାବେ `--no-sandbox --disable-gpu` (ଏବଂ Linuxରେ `--disable-dev-shm-usage`) ପାସ୍ କରେ।

ପରିବେଶ ଓଭର୍ରାଇଡ୍ଗୁଡ଼ିକ: `ELECTRON_SMOKE_APP_EXECUTABLE`, `ELECTRON_SMOKE_URL`, `ELECTRON_SMOKE_TIMEOUT_MS`, `ELECTRON_SMOKE_SETTLE_MS`, `ELECTRON_SMOKE_DATA_DIR`, `ELECTRON_SMOKE_KEEP_DATA`, `ELECTRON_SMOKE_STREAM_LOGS`.

## କୋଡ୍ ସାଇନିଂ

`electron/package.json` ସାଇନିଂ ପ୍ରମାଣପତ୍ରଗୁଡ଼ିକୁ ସିଧାସଳଖ ବିନ୍ୟାସ କରେ **ନାହିଁ**। ସେଗୁଡ଼ିକୁ env vars ମାଧ୍ୟମରେ `electron-builder`କୁ ପ୍ରଦାନ କରନ୍ତୁ:

### macOS

```bash
export APPLE_ID=<email>
export APPLE_APP_SPECIFIC_PASSWORD=<password>
export APPLE_TEAM_ID=<id>
export CSC_LINK=path/to/cert.p12
export CSC_KEY_PASSWORD=<cert-password>
npm run electron:build:mac
```

### Windows

```bash
export CSC_LINK=path/to/cert.pfx
export CSC_KEY_PASSWORD=<cert-password>
npm run electron:build:win
```

### Linux

AppImage ସାଇନିଂ ଇଚ୍ଛାଧୀନ — ସାଇନିଂ କରିବାକୁ ହେଲେ `LINUX_GPG_KEY` ସେଟ୍ କରନ୍ତୁ।
