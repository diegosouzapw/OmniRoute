## ଦ୍ରୁତ ଅନିଷ୍ଟାଲ (v3.6.2+)

OmniRoute ସ୍ୱଚ୍ଛ ଅପସାରଣ ପାଇଁ ଦୁଇଟି ଅନ୍ତର୍ନିହିତ ସ୍କ୍ରିପ୍ଟ ପ୍ରଦାନ କରେ:

### ଆପଣଙ୍କ ତଥ୍ୟ ରଖନ୍ତୁ

```bash
npm run uninstall
```

ଏହା OmniRoute ଆପ୍ଲିକେସନକୁ ଅପସାରଣ କରେ କିନ୍ତୁ ଆପଣଙ୍କ ଡାଟାବେସ, କନଫିଗରେସନ, API କୀ ଏବଂ ପ୍ରଦାନକାରୀ ସେଟିଂସ୍ଗୁଡ଼ିକୁ `~/.omniroute/` ରେ **ସଂରକ୍ଷିତ** ରଖେ | ଯଦି ଆପଣ ପରବର୍ତ୍ତୀ ସମୟରେ ପୁନଃସ୍ଥାପନ କରିବାକୁ ଚାହାଁନ୍ତି ଏବଂ ଆପଣଙ୍କ ସେଟଅପ୍ ରଖିବାକୁ ଚାହାଁନ୍ତି ତେବେ ଏହା ବ୍ୟବହାର କରନ୍ତୁ |

### ସମ୍ପୂର୍ଣ୍ଣ ଅପସାରଣ

```bash
npm run uninstall:full
```

ଏହା ଆପ୍ଲିକେସନକୁ ଅପସାରଣ କରେ **ଏବଂ ସମସ୍ତ ତଥ୍ୟକୁ ସ୍ଥାୟୀ ଭାବେ ମୁଚିଦିଏ**:

- ଡାଟାବେସ (`storage.sqlite`)
- ପ୍ରଦାନକାରୀ କନଫିଗରେସନ ଏବଂ API କୀ
- ବ୍ୟାକଅପ୍ ଫାଇଲ୍
- ଲଗ୍ ଫାଇଲ୍
- `~/.omniroute/` ନିର୍ଦ୍ଦେଶିକାରେ ଥିବା ସମସ୍ତ ଫାଇଲ୍

> ⚠️ **ଚେତାବନୀ:** `npm run uninstall:full` ଅପରିବର୍ତ୍ତନୀୟ | ଆପଣଙ୍କ ସମସ୍ତ ପ୍ରଦାନକାରୀ ସଂଯୋଗ, କମ୍ବୋ, API କୀ ଏବଂ ବ୍ୟବହାର ଇତିହାସ ସ୍ଥାୟୀ ଭାବେ ଡିଲିଟ୍ ହୋଇଯିବ |

## ମାନୁଆଲ୍ ଅନିଷ୍ଟାଲ

### NPM ଗ୍ଲୋବାଲ୍ ଇନ୍ଷ୍ଟଲ

```bash
# ଗ୍ଲୋବାଲ୍ ପ୍ୟାକେଜ୍ ଅପସାରଣ କରନ୍ତୁ
npm uninstall -g omniroute

# (ବିକଳ୍ପ) ତଥ୍ୟ ନିର୍ଦ୍ଦେଶିକା ଅପସାରଣ କରନ୍ତୁ
rm -rf ~/.omniroute
```

### pnpm ଗ୍ଲୋବାଲ୍ ଇନ୍ଷ୍ଟଲ

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# କନ୍ଟେନର୍ ବନ୍ଦ ଏବଂ ଅପସାରଣ କରନ୍ତୁ
docker stop omniroute
docker rm omniroute

# ଭଲ୍ୟୁମ୍ ଅପସାରଣ କରନ୍ତୁ (ସମସ୍ତ ତଥ୍ୟ ଡିଲିଟ୍ କରେ)
docker volume rm omniroute-data

# (ବିକଳ୍ପ) ଇମେଜ୍ ଅପସାରଣ କରନ୍ତୁ
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# କନ୍ଟେନର୍ ବନ୍ଦ ଏବଂ ଅପସାରଣ କରନ୍ତୁ
docker compose down

# ଭଲ୍ୟୁମ୍ ମଧ୍ୟ ଅପସାରଣ କରନ୍ତୁ (ସମସ୍ତ ତଥ୍ୟ ଡିଲିଟ୍ କରେ)
docker compose down -v
```

### Electron ଡେସ୍କଟପ୍ ଆପ୍

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` ଖୋଲନ୍ତୁ
- ଅଥବା ଇନ୍ଷ୍ଟଲ ଡାଇରେକ୍ଟୋରୀରୁ NSIS ଅନିଷ୍ଟାଲର ଚଲାନ୍ତୁ

**macOS:**

- `/Applications` ରୁ `OmniRoute.app` କୁ ଟ୍ରାଶ୍କୁ ଡ୍ରାଗ୍ କରନ୍ତୁ
- ତଥ୍ୟ ଅପସାରଣ: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage ଫାଇଲ୍ ଅପସାରଣ କରନ୍ତୁ
- ତଥ୍ୟ ଅପସାରଣ: `rm -rf ~/.omniroute`

### ସୋର୍ସ ଇନ୍ଷ୍ଟଲ (git clone)

```bash
# କ୍ଲୋନ୍ କରାଯାଇଥିବା ନିର୍ଦ୍ଦେଶିକା ଅପସାରଣ କରନ୍ତୁ
rm -rf /path/to/omniroute

# (ବିକଳ୍ପ) ତଥ୍ୟ ନିର୍ଦ୍ଦେଶିକା ଅପସାରଣ କରନ୍ତୁ
rm -rf ~/.omniroute
```

## ତଥ୍ୟ ନିର୍ଦ୍ଦେଶିକା

OmniRoute ଡିଫଲ୍ଟ ଭାବେ ନିମ୍ନଲିଖିତ ସ୍ଥାନଗୁଡ଼ିକରେ ତଥ୍ୟ ସଂରକ୍ଷଣ କରେ:

| ପ୍ଲାଟଫର୍ମ  | ଡିଫଲ୍ଟ ପାଥ                       | ଓଭରାଇଡ୍                                   |
| ---------- | -------------------------------- | ----------------------------------------- |
| Linux      | `~/.omniroute/`                  | `DATA_DIR` ଏନଭିରୋନ୍ମେଣ୍ଟ ଭ୍ାରିଆବଲ୍        |
| macOS      | `~/.omniroute/`                  | `DATA_DIR` ଏନଭିରୋନ୍ମେଣ୍ଟ ଭ୍ାରିଆବଲ୍        |
| Windows    | `%APPDATA%/omniroute/`           | `DATA_DIR` ଏନଭିରୋନ୍ମେଣ୍ଟ ଭ୍ାରିଆବଲ୍        |
| Docker     | `/app/data/` (ମାଉଣ୍ଟେଡ୍ ଭଲ୍ୟୁମ୍) | `DATA_DIR` ଏନଭିରୋନ୍ମେଣ୍ଟ ଭ୍ାରିଆବଲ୍        |
| XDG-ଅନୁକୂଳ | `$XDG_CONFIG_HOME/omniroute/`    | `XDG_CONFIG_HOME` ଏନଭିରୋନ୍ମେଣ୍ଟ ଭ୍ାରିଆବଲ୍ |

### ତଥ୍ୟ ନିର୍ଦ୍ଦେଶିକାରେ ଥିବା ଫାଇଲ୍

| ଫାଇଲ୍/ନିର୍ଦ୍ଦେଶିକା   | ବିବରଣୀ                                         |
| -------------------- | ---------------------------------------------- |
| `storage.sqlite`     | ମୁଖ୍ୟ ଡାଟାବେସ (ପ୍ରଦାନକାରୀ, କମ୍ବୋ, ସେଟିଂସ୍, କୀ) |
| `storage.sqlite-wal` | SQLite ରାଇଟ୍-ହେଡ୍ ଲଗ୍ (ଅସ୍ଥାୟୀ)                |
| `storage.sqlite-shm` | SQLite ସେୟାର୍ଡ୍ ମେମୋରୀ (ଅସ୍ଥାୟୀ)               |
| `call_logs/`         | ଅନୁରୋଧ ପେଲୋଡ୍ ଆର୍କାଇଭ୍                         |
| `backups/`           | ସ୍ୱୟଂଚାଳିତ ଡାଟାବେସ୍ ବ୍ୟାକଅପ୍                   |
| `log.txt`            | ଲେଗାସି ଅନୁରୋଧ ଲଗ୍ (ବିକଳ୍ପ)                     |

## ସମ୍ପୂର୍ଣ୍ଣ ଅପସାରଣ ଯାଞ୍ଚ କରନ୍ତୁ

ଅନଇନ୍ଷ୍ଟଲ କରିବା ପରେ, କୌଣସି ଅବଶିଷ୍ଟ ଫାଇଲ୍ ନାହିଁ ବୋಲି ଯାଞ୍ଚ କରନ୍ତୁ:

```bash
# ଗ୍ଲୋବାଲ npm ପ୍ୟାକେଜ୍ ଯାଞ୍ଚ କରନ୍ତୁ
npm list -g omniroute 2>/dev/null

# ଡାଟା ନିର୍ଦ୍ଦେଶିକା ଯାଞ୍ଚ କରନ୍ତୁ
ls -la ~/.omniroute/ 2>/dev/null

# ଚାଲୁଥିବା ପ୍ରକ୍ରିୟାଗୁଡ଼ିକ ଯାଞ୍ଚ କରନ୍ତୁ
pgrep -f omniroute
```

ଯଦି କୌଣସି ପ୍ରକ୍ରିୟା ଏବେ ବି ଚାଲୁଛି, ତେବେ ଏହାକୁ ବନ୍ଦ କରନ୍ତୁ:

```bash
pkill -f omniroute
```
