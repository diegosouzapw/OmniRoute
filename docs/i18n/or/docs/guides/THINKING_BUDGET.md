> **ଡ୍ୟାଶବୋର୍ଡ:** Settings → **AI** → Thinking Budget  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **ଉତ୍ସ:** `open-sse/services/thinkingBudget.ts`

Thinking Budget ନିୟନ୍ତ୍ରଣ କରେ ଯେ ପ୍ରଦାତାଙ୍କ ପାଖକୁ ଯିବା ବେଳେ OmniRoute **କ୍ଲାଏଣ୍ଟର ଚିନ୍ତନ/ତର୍କ ପାରାମିଟରଗୁଡ଼ିକୁ ପୁନଃଲେଖନ କରିବ କି ନାହିଁ**। ଏହା କମ୍ପ୍ରେସନ୍, ରାଉଟିଂ କିମ୍ବା ପ୍ରମ୍ପ୍ଟ କ୍ୟାଶ୍କୁ ଚାଲୁ କିମ୍ବା ବନ୍ଦ କରେ **ନାହିଁ**।

| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (ଡିଫଲ୍ଟ) | କ୍ଲାଏଣ୍ଟ ଫିଲ୍ଡଗୁଡ଼ିକୁ ଅପରିବର୍ତ୍ତିତ ରଖେ (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config`, ଇତ୍ୟାଦି)। | **Codex / Desktop / ପ୍ରୟାସ + ତର୍କ ସାରାଂଶ ନିୟନ୍ତ୍ରଣ କରିବା ଉଚିତ ଏପରି ଯେକୌଣସି କ୍ଲାଏଣ୍ଟ।** କ୍ଲାଏଣ୍ଟ `reasoning.summary` ଅନୁରୋଧ କଲେ ଦୃଶ୍ୟମାନ ଚିନ୍ତନ ପ୍ୟାନେଲ୍ ପାଇଁ ଏହା ଆବଶ୍ୟକ।                                   |

| **`adaptive`**             | ସନ୍ଦେଶ ସଂଖ୍ୟା, ଟୁଲ୍ ଏବଂ ପ୍ରମ୍ପ୍ଟ ଦୈର୍ଘ୍ୟ ବ୍ୟବହାର କରି ଏକ ମୂଳ ପ୍ରୟାସରୁ ବଜେଟ୍କୁ ସ୍କେଲ୍ କରେ।                                        | କ୍ଲାଏଣ୍ଟର ଉଦ୍ଦେଶ୍ୟକୁ ସମ୍ପୂର୍ଣ୍ଣ ଭାବେ ହଟାଇ ନଦେଇ ନମନୀୟ ଟୋକନ୍ ନିୟନ୍ତ୍ରଣ।                                                                                                                                      |

### `auto` କ’ଣ ହଟାଏ

ମୋଡ୍ `auto` ଥିବାବେଳେ, `stripThinkingConfig()` ନିମ୍ନଲିଖିତଗୁଡ଼ିକୁ (ଅନ୍ୟାନ୍ୟ ସହିତ) ବିଲୋପ କରେ:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, ଏବଂ ଉପସ୍ଥିତ ଥିଲେ `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

ଯଦି କୌଣସି କ୍ଲାଏଣ୍ଟ (ଯେପରିକି Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` ପଠାଇଥାଏ, ତେବେ **auto ସେହି ଅବଜେକ୍ଟକୁ ହଟାଇ ଦିଏ**। ଅପ୍ଷ୍ଟ୍ରିମ୍ ତଥାପି କିଛି ତର୍କ ଟୋକନ୍ ପାଇଁ ବିଲ୍ କରିପାରେ, କିନ୍ତୁ ପ୍ରାୟତଃ **ଖାଲି କିମ୍ବା କେବଳ ଏନ୍କ୍ରିପ୍ଟ ହୋଇଥିବା** ତର୍କ ଆଇଟମ୍ ଫେରାଏ — ତେଣୁ UI କୌଣସି ଉପଯୋଗୀ ଚିନ୍ତନ ଷ୍ଟ୍ରିମ୍ ଦେଖାଏ ନାହିଁ।

## ଦୃଶ୍ୟମାନ ଚିନ୍ତନ (Codex / Responses କ୍ଲାଏଣ୍ଟଗୁଡ଼ିକ)

ଏକ କ୍ଲାଏଣ୍ଟ ଚିନ୍ତନ ପାଠ୍ୟ ଦେଖାଇବା ପାଇଁ ଆପଣଙ୍କୁ ନିମ୍ନୋକ୍ତ **ସମସ୍ତ** ବିଷୟ ଆବଶ୍ୟକ:

1. Thinking Budget ମୋଡ୍ = **`passthrough`** (କିମ୍ବା custom/adaptive, ଯାହା ଆପଣ ବ୍ୟବହାର କରୁଥିବା ପଥ ପାଇଁ ସାରାଂଶ ଅନୁରୋଧଗୁଡ଼ିକୁ ଯଥେଷ୍ଟ ଅକ୍ଷୁଣ୍ଣ ରଖେ)।
2. କ୍ଲାଏଣ୍ଟ ଏକ ସାରାଂଶ ଅନୁରୋଧ କରେ, ଯଥା Codex `model_reasoning_summary = "detailed"` / `auto` (`none` ନୁହେଁ)।
3. ଅପ୍ଷ୍ଟ୍ରିମ୍ ପ୍ରକୃତରେ `response.reasoning_summary_text.*` ଷ୍ଟ୍ରିମ୍ କରେ (କିମ୍ବା ଆଇଟମ୍ରେ ଏକ ଅଣ-ଖାଲି `reasoning.summary` ଥାଏ)।

ଯଦି ଆପଣ କେବଳ “ଏନ୍କ୍ରିପ୍ଟ କରାଯାଇଥିବା ବ୍ୟକ୍ତିଗତ ଚିନ୍ତନ” ପାଆନ୍ତି, ତେବେ:

- ମୋଡ୍ **`auto`** ଥିଲା (କ୍ଲାଏଣ୍ଟ ଅନୁରୋଧକୁ ହଟାଇ ଦିଆଯାଇଥିଲା), କିମ୍ବା
- ଅପ୍ଷ୍ଟ୍ରିମ୍ ସାରାଂଶ ପାଠ୍ୟ ବିନା `encrypted_content` ଫେରାଇଥିଲା (ପ୍ରଦାନକାରୀଙ୍କ ସୀମାବଦ୍ଧତା; OmniRoute କେବଳ ଏକ ପ୍ଲେସ୍ହୋଲ୍ଡର୍ ଦେଖାଇପାରେ, ସାଧାରଣ ପାଠ୍ୟ ନୁହେଁ)।

## API ଉଦାହରଣଗୁଡ଼ିକ

```bash
# ପଢ଼ନ୍ତୁ
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Codex / Desktopରେ ଚିନ୍ତନ ଦୃଶ୍ୟମାନତା ପାଇଁ ସୁପାରିସକୃତ
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

ସ୍କିମା (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; ଇଚ୍ଛାଧୀନ `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`।

### ସ୍ଥାୟୀତ୍ୱ / ପୁନଃଚାଳନ

ମୂଲ୍ୟଟି ସେଟିଂସ୍ କୀ `thinkingBudget` ଅଧୀନରେ ସଂରକ୍ଷିତ ହୁଏ ଏବଂ ପ୍ରକ୍ରିୟା ଆରମ୍ଭ ସମୟରେ ଲୋଡ୍ ହୁଏ (`hydrateThinkingBudgetConfig`)। DB କିମ୍ବା କେତେକ ଅଣ-API ପଥ ମାଧ୍ୟମରେ ପରିବର୍ତ୍ତନ କରିବା ପରେ, ଇନ୍-ମେମୋରି ସିଙ୍ଗଲ୍ଟନ୍ଟି ଡିସ୍କ ସହିତ ମେଳ ଖାଇବା ପାଇଁ **OmniRoute ପ୍ରକ୍ରିୟାକୁ ପୁନଃଚାଳନ କରନ୍ତୁ**।

## ଅପରେଟର୍ ଯାଞ୍ଚସୂଚୀ

- [ ] Codex / Desktop ବ୍ୟବହାରକାରୀ: ମୋଡ୍ = **passthrough**
- [ ] ଯଦି ଆପଣ **ସନ୍ଦେଶଗୁଡ଼ିକରେ** ଟୋକନ୍ ସଞ୍ଚୟ ଚାହାନ୍ତି, ତେବେ ଚିନ୍ତନକୁ ହଟାଇବା ପରିବର୍ତ୍ତେ କମ୍ପ୍ରେସନ୍ ସକ୍ଷମ ରଖନ୍ତୁ
- [ ] `auto` “ଅଧିକ ଚିନ୍ତନ ଦେଖାଇବ” ବୋଲି ଆଶା କରନ୍ତୁ ନାହିଁ
- [ ] କେବଳ ଏନ୍କ୍ରିପ୍ଟ କରାଯାଇଥିବା ସାରାଂଶଗୁଡ଼ିକ ଏକ **ପ୍ରଦାନକାରୀ** ଆଚରଣ; passthrough ସେଗୁଡ଼ିକୁ ଡିକ୍ରିପ୍ଟ କରିପାରିବ ନାହିଁ
