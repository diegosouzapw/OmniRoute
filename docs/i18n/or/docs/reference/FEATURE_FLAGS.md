> ସେହି ଫାଇଲ୍ରୁ ପଢ଼ନ୍ତି, ତେଣୁ ନିମ୍ନସ୍ଥ ସାରଣୀଟି ତାହା ସହିତ 1:1 ମେଳ ରଖିବା ପାଇଁ ସୃଷ୍ଟି କରାଯାଇଛି।

## ଫିଚର୍ ଫ୍ଲାଗ୍ କ’ଣ

ଏକ ଫିଚର୍ ଫ୍ଲାଗ୍ ହେଉଛି ଏକ ନାମିତ ଟଗଲ୍ (boolean କିମ୍ବା enum), ଯାହାର ମୂଲ୍ୟକୁ
ରନ୍ଟାଇମ୍ରେ ପରିବର୍ତ୍ତନ କରି ଡାଟାବେସ୍ରେ ସ୍ଥାୟୀ ଭାବେ ସଂରକ୍ଷଣ କରାଯାଇପାରେ ଏବଂ କୌଣସି ପ୍ରକ୍ରିୟା ପୁନଃ ଡିପ୍ଲୟମେଣ୍ଟ ଆବଶ୍ୟକ ହୁଏ ନାହିଁ। ପ୍ରତ୍ୟେକ
ଫ୍ଲାଗ୍କୁ `key`, `label`,
`description`, `category`, `defaultValue`, `type` ଏବଂ ଏକ `requiresRestart` ସୂଚନା ସହିତ `FeatureFlagDefinition` ଦ୍ୱାରା ବର୍ଣ୍ଣନା କରାଯାଏ।

### ସମାଧାନ କ୍ରମ

ଏକ ଫ୍ଲାଗ୍ର **କାର୍ଯ୍ୟକାରୀ ମୂଲ୍ୟ**
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ଦ୍ୱାରା ଏହି
ଅଗ୍ରାଧିକାର କ୍ରମରେ ନିର୍ଦ୍ଧାରିତ ହୁଏ (ସର୍ବୋଚ୍ଚଟି ପ୍ରାଧାନ୍ୟ ପାଏ):

1. **DB ଓଭର୍ରାଇଡ୍** — `feature_flags` ନେମ୍ସ୍ପେସ୍ ଅଧୀନରେ
   `key_value` ସାରଣୀରେ ସଂରକ୍ଷିତ ଏକ ମୂଲ୍ୟ (ଡ୍ୟାସ୍ବୋର୍ଡ କିମ୍ବା REST API ମାଧ୍ୟମରେ ସେଟ୍ କରାଯାଇଥାଏ)।
2. **ପରିବେଶ ଭେରିଏବଲ୍** — `process.env[<KEY>]`, ଯଦି ସେଟ୍ ହୋଇଥାଏ ଏବଂ ଖାଲି ନଥାଏ।
3. **ସଂଜ୍ଞାର ଡିଫଲ୍ଟ** — `featureFlagDefinitions.ts`ରୁ `defaultValue`।

ଏକ boolean ଫ୍ଲାଗ୍ର କାର୍ଯ୍ୟକାରୀ ମୂଲ୍ୟ `"true"`,
`"1"`, କିମ୍ବା `"yes"` ହେଲେ ତାହାକୁ **ସକ୍ଷମ** ବୋଲି ବିବେଚନା କରାଯାଏ
(`isFeatureFlagEnabled()` ଦେଖନ୍ତୁ)।

> [!NOTE]
> ଅଧିକାଂଶ ଫ୍ଲାଗ୍ରେ [`ENVIRONMENT.md`](./ENVIRONMENT.md)ରେ ଦଲିଲଭୁକ୍ତ **ସମାନ ନାମର**
> ଏକ ମେଳ ଖାଉଥିବା ପରିବେଶ ଭେରିଏବଲ୍ ମଧ୍ୟ ରହିଛି। ଫ୍ଲାଗ୍ର DB ଓଭର୍ରାଇଡ୍
> ସେହି ପରିବେଶ ଭେରିଏବଲ୍ଠାରୁ ଅଗ୍ରାଧିକାର ପାଏ। `requiresRestart: true` ଥିବା ଏକ ଫ୍ଲାଗ୍
> ତୁରନ୍ତ ସ୍ଥାୟୀ ଭାବେ ସଂରକ୍ଷିତ ହୁଏ, କିନ୍ତୁ ପ୍ରକ୍ରିୟା ଆରମ୍ଭ ସମୟରେ ମାତ୍ର ପୁନଃ ପଢ଼ାଯାଏ —
> ଏହାକୁ ଟଗଲ୍ କଲେ ଡ୍ୟାସ୍ବୋର୍ଡରେ ଏକ **"ସର୍ଭର୍ ପୁନଃଚାଳନ କରନ୍ତୁ"** ବ୍ୟାନର୍ ଦେଖାଯାଏ।

  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`)।
- ପ୍ରତ୍ୟେକ ଫ୍ଲାଗ୍ ପାଇଁ ଏକ **ଉତ୍ସ ବ୍ୟାଜ୍** — `DB`, `ENV`, କିମ୍ବା `DEF` — ଯାହା ପ୍ରଭାବୀ ମୂଲ୍ୟଟି
  କେଉଁଠାରୁ ଆସିଛି ଦର୍ଶାଏ।
- ଓଭର୍ରାଇଡ୍କୁ ହଟାଇବା ପାଇଁ ଏକ **ରିସେଟ୍** ବଟନ୍ (କେବଳ `DB`-ଉତ୍ସରୁ ଆସିଥିବା ଫ୍ଲାଗ୍ଗୁଡ଼ିକ ପାଇଁ ଦେଖାଯାଏ),
  ଏବଂ ତଳେ ଏକ **ସମସ୍ତ ଓଭର୍ରାଇଡ୍ ରିସେଟ୍ କରନ୍ତୁ** ବଟନ୍।
- ଏକ `requiresRestart` ଫ୍ଲାଗ୍ ପରିବର୍ତ୍ତିତ ହେଲେ ଏକ **ସର୍ଭର୍ ପୁନଃପ୍ରାରମ୍ଭ କରନ୍ତୁ** ବ୍ୟାନର୍।

### REST API

ସମସ୍ତ କାର୍ଯ୍ୟ ଗୋଟିଏ ରୁଟ୍ ମାଧ୍ୟମରେ ହୁଏ:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts)।
ପ୍ରତ୍ୟେକ ମେଥଡ୍ ପାଇଁ ଏକ ପ୍ରମାଣୀକୃତ ଡ୍ୟାଶବୋର୍ଡ ସେସନ୍ ଆବଶ୍ୟକ (ନଚେତ୍ `401`)।

#### `GET /api/settings/feature-flags`

ପ୍ରତ୍ୟେକ ଫ୍ଲାଗ୍କୁ ତାହାର ପ୍ରଭାବୀ ମୂଲ୍ୟ, ଉତ୍ସ ଏବଂ ଏକ ସାରାଂଶ ସହିତ ଫେରାଏ।

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... ସମସ୍ତ 75ଟି ଫ୍ଲାଗ୍
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

ଗୋଟିଏ ଓଭର୍ରାଇଡ୍ ସେଟ୍ କିମ୍ବା ଅପସାରଣ କରେ। ବଡି: `{ key: string; value?: string }`।
`value`କୁ ଛାଡ଼ିଦେଲେ ଓଭର୍ରାଇଡ୍ ଅପସାରିତ ହୁଏ (env / ଡିଫଲ୍ଟ ପୁନଃସ୍ଥାପିତ ହୁଏ)।

```bash
# ଏକ DB ଓଭର୍ରାଇଡ୍ ସେଟ୍ କରନ୍ତୁ
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# ଓଭର୍ରାଇଡ୍କୁ ଅପସାରଣ କରନ୍ତୁ ("value" ବିନା)
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

ପ୍ରତିକ୍ରିୟାଟି ନୂତନ `effectiveValue`/`source`, `previousValue`/
`previousSource`, ଏବଂ `requiresRestart`କୁ ପୁନଃ ଫେରାଏ। ଅଜଣା କୀ ଏବଂ ସୀମା ବାହାରର enum
ମୂଲ୍ୟଗୁଡ଼ିକୁ `400` ସହିତ ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ।

#### `DELETE /api/settings/feature-flags`

ଏକାଥରେ **ସମସ୍ତ** DB ଓଭର୍ରାଇଡ୍ ସଫା କରି, ପ୍ରତ୍ୟେକ ଫ୍ଲାଗ୍କୁ ତାହାର env / ଡିଫଲ୍ଟ
ମୂଲ୍ୟକୁ ପୁନଃସ୍ଥାପନ କରେ। `{ cleared: <count>, message: "..." }` ଫେରାଏ।

> [!NOTE]
> `requiresRestart: true` ଥିବା ଫ୍ଲାଗ୍ଗୁଡ଼ିକ କେବଳ ପ୍ରୋସେସ୍ ପୁନଃଲୋଡ୍ ପରେ ପ୍ରଭାବୀ ହୁଅନ୍ତି।
> ଡ୍ୟାଶବୋର୍ଡର ପୁନଃପ୍ରାରମ୍ଭ ପ୍ରବାହ `POST /api/restart`କୁ କଲ୍ କରେ ଏବଂ ତା’ପରେ ସର୍ଭର୍ ପୁଣି ଚାଲୁ ହେବା ପର୍ଯ୍ୟନ୍ତ
> `GET /api/health/ping`କୁ ପୋଲ୍ କରେ।

## ଜରୁରୀ ବଜେଟ୍ ଫଲ୍ବ୍ୟାକ୍

`OMNIROUTE_EMERGENCY_FALLBACK` (ବର୍ଗ `runtime`, ଡିଫଲ୍ଟ `true`)
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)ରେ ଥିବା
ଜରୁରୀ ମାଗଣା-ଫଲ୍ବ୍ୟାକ୍ ପଥକୁ ନିୟନ୍ତ୍ରଣ କରେ।
ସକ୍ଷମ ଥିବାବେଳେ, ନିଜ ବଜେଟ୍ ଶେଷ କରିଦେଇଥିବା ଅନୁରୋଧଗୁଡ଼ିକ ସମ୍ପୂର୍ଣ୍ଣ ଭାବେ ବିଫଳ ହେବା ପରିବର୍ତ୍ତେ
ଏକ ମାଗଣା ଫଲ୍ବ୍ୟାକ୍ ପ୍ରଦାନକାରୀ/ମଡେଲ୍କୁ ରୁଟ୍ କରାଯାଏ। ଏହି ଆଚରଣକୁ ଅକ୍ଷମ କରିବା ଏବଂ ବଜେଟ୍-ଶେଷ ହୋଇଥିବା ଅନୁରୋଧଗୁଡ଼ିକୁ
ବିଫଳ ହେବାକୁ ଦେବା ପାଇଁ — ଡ୍ୟାସ୍ବୋର୍ଡ ଟୋଗଲ୍, ଏକ DB ଓଭର୍ରାଇଡ୍ କିମ୍ବା
`OMNIROUTE_EMERGENCY_FALLBACK` ପରିବେଶ ଭେରିଏବଲ୍ ମାଧ୍ୟମରେ — ଏହାକୁ `false` (କିମ୍ବା `0`)ରେ ସେଟ୍ କରନ୍ତୁ।
(PR #3741 / #3752ରେ ଏକ ଡ୍ୟାସ୍ବୋର୍ଡ ଟୋଗଲ୍ ଭାବେ ଉପସ୍ଥାପିତ।)
