## ବର୍ଗଗୁଡ଼ିକ

- **ମାଗଣା** — API କୀ ସହିତ ମାଗଣା ସ୍ତର (ଡ୍ୟାଶବୋର୍ଡ ମାଧ୍ୟମରେ ବିନ୍ୟାସ କରାଯାଏ)
- **ପ୍ରମାଣୀକରଣ-ବିହୀନ** — ସାର୍ବଜନୀନ ଏଣ୍ଡପଏଣ୍ଟ, ଯେଉଁଥିପାଇଁ କୌଣସି କୀ କିମ୍ବା ସାଇନ୍-ଇନ୍ ଆଦୌ ଆବଶ୍ୟକ ନୁହେଁ
- **OAuth** — OmniRoute ଦ୍ୱାରା ପରିଚାଳିତ ସାଇନ୍-ଇନ୍ ପ୍ରବାହ, API କୀ ଆବଶ୍ୟକ ନୁହେଁ
- **ୱେବ୍ କୁକି** — କୁକି ପ୍ରମାଣୀକରଣ ମାଧ୍ୟମରେ ପ୍ରଦାନକାରୀଙ୍କ ୱେବ୍ ଆପ୍କୁ ଆବୃତ କରେ
- **API କୀ** — API କୀ ମାଧ୍ୟମରେ ବିନ୍ୟାସ କରାଯାଇଥିବା ଶୁଳ୍କଯୁକ୍ତ ପ୍ରଦାନକାରୀ (ମାଗଣା କ୍ରେଡିଟ୍ ପ୍ରଯୋଜ୍ୟ ହୋଇପାରେ)
- **ସ୍ଥାନୀୟ** — ବ୍ୟବହାରକାରୀଙ୍କ ମେସିନ୍ରେ ଚାଲେ (Ollama, LM Studio, vLLM ଇତ୍ୟାଦି)
- **ସନ୍ଧାନ** — ୱେବ୍ ସନ୍ଧାନ ପ୍ରଦାନକାରୀ
- **ଅଡିଓ** — କେବଳ-ଅଡିଓ ପ୍ରଦାନକାରୀ (TTS/STT)
- **ଅପ୍ଷ୍ଟ୍ରିମ୍ ପ୍ରକ୍ସି** — ଅନ୍ୟ ପ୍ରଦାନକାରୀଙ୍କୁ ପ୍ରକ୍ସି କରୁଥିବା ପ୍ରଦାନକାରୀ
- **କ୍ଲାଉଡ୍ ଏଜେଣ୍ଟ** — ଦୀର୍ଘ ସମୟ ଧରି ଚାଲୁଥିବା କୋଡିଂ ଏଜେଣ୍ଟ (Codex Cloud, Devin, Jules)
- **ସିଷ୍ଟମ୍** — OmniRouteର ଆଭ୍ୟନ୍ତରୀଣ ପ୍ରଦାନକାରୀ (ଲୁପ୍ବ୍ୟାକ୍ ଇତ୍ୟାଦି)

ଅତିରିକ୍ତ ଟ୍ୟାଗ୍ଗୁଡ଼ିକ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`।

`Tool calling` (ଯେଉଁଠାରେ ଦର୍ଶାଯାଇଛି): `native` — ପ୍ରକୃତ ଫଙ୍କସନ୍-କଲିଂ API; `emulated` — `tools` ଆରେକୁ `webTools.ts` ମାଧ୍ୟମରେ ପ୍ରମ୍ପ୍ଟ-ଅନୁକରଣ କରାଯାଏ (regex ଦ୍ୱାରା ପାର୍ସ କରାଯାଇଥିବା `<tool>{...}</tool>` ବ୍ଲକ୍ଗୁଡ଼ିକ); `none` — `tools`କୁ ବର୍ତ୍ତମାନ ନିରବରେ ବାଦ ଦିଆଯାଉଛି। #7286 ଦେଖନ୍ତୁ।

ପ୍ରତ୍ୟେକ ପ୍ରଦାନକାରୀକୁ ସକ୍ଷମ, ବିନ୍ୟାସ ଏବଂ ପରୀକ୍ଷା କରିବା ପାଇଁ `/dashboard/providers`ରେ ଥିବା ଡ୍ୟାଶବୋର୍ଡ ବ୍ୟବହାର କରନ୍ତୁ।
