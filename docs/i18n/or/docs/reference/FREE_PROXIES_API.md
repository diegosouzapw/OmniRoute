OmniRoute `free_proxies` ଟେବୁଲ୍ରେ ମାଗଣା ପ୍ରକ୍ସିଗୁଡ଼ିକର ଏକ ଚୟନିତ ପୁଲ୍ ପ୍ରଦାନ କରେ,
ଯାହା ବାହ୍ୟ ପ୍ରଦାନକାରୀମାନଙ୍କଠାରୁ (1proxy, proxifly, iplocate, webshare) ସିଙ୍କ୍ କରାଯାଏ। ଡ୍ୟାସ୍ବୋର୍ଡ
ଏଗୁଡ଼ିକୁ **ସେଟିଂସ୍ → ମାଗଣା ପ୍ରକ୍ସିଗୁଡ଼ିକ** ଅଧୀନରେ ଦେଖାଏ। ଏହି ଡକ୍ୟୁମେଣ୍ଟ
ତାଲିକା ରୁଟ୍ ପ୍ରଦାନ କରୁଥିବା ସର୍ଭର୍-ପାର୍ଶ୍ୱ ଫିଲ୍ଟରିଂ, ସର୍ଟିଂ, ଗଣନା ଏବଂ ସିଙ୍କ୍-ତ୍ରୁଟି ରିପୋର୍ଟିଂ
ବିଷୟରେ ବର୍ଣ୍ଣନା କରେ।

## ତାଲିକା ରୁଟ୍ — `GET /api/settings/free-proxies`

ଏକ ଫିଲ୍ଟର୍ ଓ ସର୍ଟ୍ କରାଯାଇଥିବା, ପୃଷ୍ଠାଙ୍କିତ ଅଂଶ ସହିତ ମୋଟ ଗଣନା ଫେରାଏ। ଫିଲ୍ଟରିଂ ଏବଂ
ଗଣନା SQLରେ ହୁଏ, ତେଣୁ ପ୍ରତ୍ୟେକ ଧାଡ଼ିକୁ ମେମୋରିରେ ଲୋଡ୍ ନକରି UI ପ୍ରକୃତ ମୋଟ ସଂଖ୍ୟା (ଯଥା `ମୋଟ: 0`)
ଦେଖାଇପାରେ।

### କ୍ୱେରୀ ପାରାମିଟର୍ଗୁଡ଼ିକ

| ପାରାମିଟର୍         | ପ୍ରକାର                             | ଡିଫଲ୍ଟ    | ଅର୍ଥ                                                                                                       |
| ----------------- | ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------- |
| `search`          | ଷ୍ଟ୍ରିଙ୍ଗ୍                         | `""`      | ହୋଷ୍ଟ୍ (ଏବଂ ଉତ୍ସ) କଲମ୍ରେ କେସ୍-ସେନ୍ସିଟିଭ୍ `LIKE`।                                                           |
| `protocol`        | ଷ୍ଟ୍ରିଙ୍ଗ୍                         | `""`      | `type` ଫିଲ୍ଟର୍: `http` / `https` / `socks4` / `socks5`। ଖାଲି = ସମସ୍ତ।                                      |
| `country`         | ଷ୍ଟ୍ରିଙ୍ଗ୍                         | `""`      | `countryCode` ଫିଲ୍ଟର୍ (ISO-2)। ଖାଲି = ସମସ୍ତ।                                                               |
| `minQuality`      | ସଂଖ୍ୟା                             | `0`       | କେବଳ `qualityScore >= minQuality` ଥିବା ଧାଡ଼ିଗୁଡ଼ିକ। `0` = କୌଣସି ନ୍ୟୂନତମ ସୀମା ନାହିଁ।                        |
| `disabledSources` | ଷ୍ଟ୍ରିଙ୍ଗ୍                         | `""`      | ବାଦ୍ ଦେବାକୁ ଥିବା କମା-ପୃଥକ ଉତ୍ସ idଗୁଡ଼ିକ (ଯଥା `proxifly,webshare`)।                                         |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = ସ୍କୋର୍ ଅବରୋହୀ; `latency` = ବିଳମ୍ବ ଆରୋହୀ (nullଗୁଡ଼ିକ ଶେଷରେ); `recent` = `lastValidated` ଅବରୋହୀ। |
| `offset`          | ସଂଖ୍ୟା                             | `0`       | ପୃଷ୍ଠାଙ୍କନର ଆରମ୍ଭ।                                                                                         |
| `limit`           | ସଂଖ୍ୟା                             | `50`      | ପୃଷ୍ଠା ଆକାର (ସର୍ଭର୍-ପାର୍ଶ୍ୱରେ ସୀମିତ)।                                                                      |

### ପ୍ରତିକ୍ରିୟା

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["ଅପ୍ଷ୍ଟ୍ରିମ୍ରୁ HTTP 429"],
    "webshare": ["ନେଟ୍ୱର୍କ ଟାଇମ୍ଆଉଟ୍"]
  }
}
```

`total` ପୃଷ୍ଠାଙ୍କନର **ପୂର୍ବରୁ** ଥିବା ଫିଲ୍ଟର୍ କରାଯାଇଥିବା ମୋଟ ସଂଖ୍ୟାକୁ ପ୍ରତିଫଳିତ କରେ, ଯାହାଦ୍ୱାରା UI
`ମୋଟ: N` ଏବଂ `hasMore`କୁ ସ୍ୱାଧୀନ ଭାବରେ ରେଣ୍ଡର୍ କରିପାରେ। `syncErrors` ଉତ୍ସ id ଅନୁସାରେ କୀ କରାଯାଇଥାଏ ଏବଂ
କେବଳ ଯେଉଁ ଉତ୍ସଗୁଡ଼ିକର ଶେଷ ସିଙ୍କ୍ ବିଫଳ ହୋଇଥିଲା ସେଗୁଡ଼ିକ ପାଇଁ ପୂରଣ ହୁଏ — ଏକ `ମୋଟ: 0` ଫଳାଫଳ
କେବେ ମଧ୍ୟ ନିରବ ରହେ ନାହିଁ।

## ପୁଲ୍ରେ ଯୋଡ଼ନ୍ତୁ — `POST /api/settings/free-proxies/[id]/add-to-pool`

ଏକ ମାଗଣା ପ୍ରକ୍ସିକୁ ପରିଚାଳିତ `proxy_registry` ପୁଲ୍କୁ ଉନ୍ନୀତ କରେ। ପ୍ରଥମେ
ଅପ୍ଷ୍ଟ୍ରିମ୍କୁ ବୈଧ କରେ; ସଫଳ ହେଲେ ନୂତନ ପୁଲ୍ ପ୍ରକ୍ସି id ଏବଂ ମାପ କରାଯାଇଥିବା ବିଳମ୍ବ ଫେରାଏ।

## ସିଙ୍କ୍ — `POST /api/settings/free-proxies/sync`

ସମସ୍ତ ସକ୍ଷମ ଉତ୍ସକୁ (କିମ୍ବା `{ "sources": [...] }`ରେ ଥିବା ଉପସେଟ୍କୁ) ପୁନଃ ଆଣେ। ପ୍ରତ୍ୟେକ
ଉତ୍ସ ସ୍ୱାଧୀନ ଭାବରେ ସିଙ୍କ୍ ହୁଏ; ଏକ ବିଫଳ ଉତ୍ସ `syncErrors`ରେ ରେକର୍ଡ୍ ହୁଏ ଏବଂ
ଅନ୍ୟଗୁଡ଼ିକ ତଥାପି ସମ୍ପୂର୍ଣ୍ଣ ହୁଅନ୍ତି, ତେଣୁ ଆଂଶିକ ସିଙ୍କ୍ କେବେ ମଧ୍ୟ ପୂର୍ବର ଭଲ ଡାଟାକୁ ମିଟାଏ ନାହିଁ।

## ପରିସଂଖ୍ୟାନ — `GET /api/settings/free-proxies/stats`

ଧାଡ଼ି ପେଲୋଡ୍ ବିନା `total / inPool / avgQuality / bySource / lastSyncAt` ସମଷ୍ଟି
ଫେରାଏ — ଏହା ଡ୍ୟାସ୍ବୋର୍ଡ ହେଡର୍ ୱିଜେଟ୍ଗୁଡ଼ିକ ଦ୍ୱାରା ବ୍ୟବହୃତ ହୁଏ।
