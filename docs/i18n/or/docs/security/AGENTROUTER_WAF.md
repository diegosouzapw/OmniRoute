`agentrouter` ଅପ୍ଷ୍ଟ୍ରିମ୍ ଗେଟୱେ `messages[].content` ଉପରେ ଏକ କୀୱାର୍ଡ-ଆଧାରିତ ବିଷୟବସ୍ତୁ ଫିଲ୍ଟର୍ ଚଲାଏ। ଫିଲ୍ଟର୍ଟି ଆଂଶିକ ଭାବେ ନିର୍ଦ୍ଧାରଣାତ୍ମକ (ନିର୍ଦ୍ଦିଷ୍ଟ ବାକ୍ୟାଂଶକୁ ସର୍ବଦା ବ୍ଲକ୍ କରେ) ଏବଂ ଆଂଶିକ ଭାବେ ସମ୍ଭାବନାଭିତ୍ତିକ (ବର୍ଷ୍ଟ-ସମ୍ବେଦନଶୀଳ — ଦ୍ରୁତ ଅନୁରୋଧ ପରେ ଅଧିକ ଆକ୍ରାମକ ହୁଏ ଏବଂ କୁଲ୍ଡାଉନ୍ ପରେ ସ୍ୱାଭାବିକ ଅବସ୍ଥାକୁ ଫେରେ)।

WAF କୌଣସି ଅନୁରୋଧକୁ ବ୍ଲକ୍ କଲେ ଏହା ନିମ୍ନଲିଖିତ ଫେରାଏ:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## ଫିଲ୍ଟର୍ର ପରିସର

WAF କେବଳ `messages[].content` ଯାଞ୍ଚ କରେ। ଏହା ନିମ୍ନଲିଖିତଗୁଡ଼ିକୁ ଯାଞ୍ଚ କରେ **ନାହିଁ**:

- `system` ପ୍ରମ୍ପ୍ଟ
- ସଂରଚିତ ବିଷୟବସ୍ତୁ ବ୍ଲକ୍ (`tool_result`, `tool_use`, `thinking`, `image`)
- ଟୁଲ୍ର `description` ଏବଂ `input_schema` ଫିଲ୍ଡ
- ଅନୁରୋଧ ମେଟାଡାଟା, ହେଡର୍, କିମ୍ବା ମଡେଲ୍ id

## ସର୍ବଦା ବ୍ଲକ୍ ହେଉଥିବା ପ୍ୟାଟର୍ନ (କେସ୍-ଅସମ୍ବେଦନଶୀଳ)

| ପ୍ୟାଟର୍ନ                       | ଟିପ୍ପଣୀ                                                  |
| ------------------------------ | -------------------------------------------------------- |
| ଯେକୌଣସି `Lorem ipsum` ରୂପାନ୍ତର | ସମ୍ପୂର୍ଣ୍ଣ Latin lorem ଶବ୍ଦାବଳୀ ବ୍ଲକ୍ ହୁଏ                |
| `language model` (ଏକାକୀ)       | "the language model" ଏବଂ "large language model" ପାସ୍ ହୁଏ |
| `virtual assistant`            | "AI assistant" ପାସ୍ ହୁଏ                                  |
| `I'm here to help`             | କେବଳ "here to help" ମଧ୍ୟ ବ୍ଲକ୍ ହୁଏ                       |
| `Claude, made by Anthropic`    | କେବଳ ସମ୍ପୂର୍ଣ୍ଣ ବାକ୍ୟାଂଶ                                 |

## ପ୍ରାୟ ସର୍ବଦା ବ୍ଲକ୍ ହେଉଥିବା ପ୍ୟାଟର୍ନ

| ପ୍ୟାଟର୍ନ                                                | ଟିପ୍ପଣୀ                                                   |
| ------------------------------------------------------- | --------------------------------------------------------- |
| `placeholder`                                           | ଯେତେବେଳେ ଏହା ଏକାକୀ ଥାଏ (ପାରାମିଟର୍ ନାମ ଇତ୍ୟାଦି ଭାବେ ନୁହେଁ) |
| `dummy data`                                            | ଫିକ୍ସଚର୍ଗୁଡ଼ିକ ପାଇଁ ସାଧାରଣ ସିଡ୍ ବାକ୍ୟାଂଶ                  |
| `foo bar baz`                                           | ପ୍ରଚଳିତ ପ୍ଲେସ୍ହୋଲ୍ଡର୍ ବାକ୍ୟାଂଶ                            |
| ପୁନରାବୃତ୍ତ ଛୋଟ ଟୋକେନ୍ (`AAA BBB CCC`, `test test test`) | କୀୱାର୍ଡ ଷ୍ଟଫିଙ୍ଗ ଚିହ୍ନଟକାରୀ                               |

## ଲୋଡ୍ ଅଧୀନରେ ଆଚରଣ

ଅଳ୍ପ ସମୟ ମଧ୍ୟରେ ପ୍ରାୟ 5ଟି ଦ୍ରୁତ ଅନୁରୋଧ ପରେ, WAF ସାଧାରଣତଃ ପାସ୍ ହେଉଥିବା ବିଷୟବସ୍ତୁକୁ ବ୍ଲକ୍ କରିବା ଆରମ୍ଭ କରେ। ପ୍ରାୟ 5–10 ସେକେଣ୍ଡ ନିଷ୍କ୍ରିୟ ରହିବା ପରେ ବକେଟ୍ଟି ଶିଥିଳ ହୁଏ। ଏହା ସେହି IP-ଏବଂ-key-ଆଧାରିତ ରେଟ୍ ଲିମିଟର୍, ଯାହା Claude Code କିମ୍ବା Codex CLI ଦ୍ରୁତ କ୍ରମରେ ଏକାଧିକ ଟୁଲ୍-ବ୍ୟବହାର / ବାର୍ତ୍ତା-ପ୍ରେରଣ କଲ୍ କଲେ ମଧ୍ୟବର୍ତ୍ତୀ `400 content-blocked` ତ୍ରୁଟି ସୃଷ୍ଟି କରେ।

## OmniRouteରେ ପୂର୍ବରୁ ପ୍ରୟୋଗ ହୋଇଥିବା ପ୍ରତିକାର

1. **`open-sse/services/wafRateLimit.ts`** — ଏକ ବର୍ଷ୍ଟ ଗାର୍ଡ, ଯାହା ଯେକୌଣସି `agentrouter:*` URLକୁ ପଠାଯାଉଥିବା ଆଉଟ୍ବାଉଣ୍ଡ ଅନୁରୋଧଗୁଡ଼ିକ ମଧ୍ୟରେ ସର୍ବନିମ୍ନ 500 ms ବ୍ୟବଧାନ ବାଧ୍ୟତାମୂଳକ କରେ। ଏହି ବ୍ୟବଧାନ ମାନବୀୟ ଲେଟେନ୍ସି ଅନୁଭୂତିଠାରୁ ଯଥେଷ୍ଟ କମ୍ ଏବଂ ସାଧାରଣ ଟ୍ରାଫିକ୍ରେ WAF ସକ୍ରିୟ ହେବାକୁ ରୋକେ।

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — ଯେତେବେଳେ ଏକ ଅପ୍ଷ୍ଟ୍ରିମ୍ `400 content-blocked` ଫେରାଏ, ଏକ୍ସିକ୍ୟୁଟର୍ ଏକ୍ସପୋନେନ୍ସିଆଲ୍ ବ୍ୟାକଅଫ୍ ସହିତ ସେହି URLକୁ ପୁନଃଚେଷ୍ଟା କରେ (1.5 s, 3.0 s, ସର୍ବାଧିକ 2ଟି ପ୍ରୟାସ)। ବ୍ୟାକଅଫ୍ ପରେ WAF ସାଧାରଣତଃ ଶିଥିଳ ହୁଏ ଏବଂ ପୁନଃଚେଷ୍ଟା ସଫଳ ହୁଏ।

3. **`tests/unit/compression/harness.test.ts`** — ପରୀକ୍ଷଣ ଫିକ୍ସଚର୍ `longInput`କୁ `"lorem ipsum dolor sit amet ".repeat(40)`ରୁ `"example content for testing purposes ".repeat(40)`କୁ ପରିବର୍ତ୍ତନ କରାଯାଇଥିଲା, ଯାହାଦ୍ୱାରା Claude Code `Read` ଟୁଲ୍ ମାଧ୍ୟମରେ ଏହି ଫାଇଲ୍ଟି ପଢ଼ିବାବେଳେ ଫାଇଲ୍ର ବିଷୟବସ୍ତୁ ଏକ `tool_result` ବ୍ଲକ୍ ଦେଇ ପୁନଃ ପ୍ରବାହିତ ହୋଇ WAFକୁ ସକ୍ରିୟ ନକରେ।

## ପ୍ରମ୍ପ୍ଟ ଏବଂ ଟୁଲ୍ ଆଉଟ୍ପୁଟ୍ ପାଇଁ ମାର୍ଗଦର୍ଶନ

ଯଦି କୌଣସି Claude Code କିମ୍ବା Codex CLI ସେସନ୍ରେ ବାରମ୍ବାର `400 content-blocked` ଘଟେ, ଉପରୋକ୍ତ ପ୍ୟାଟର୍ନଗୁଡ଼ିକ ମଧ୍ୟରୁ କୌଣସିଟି ସବୁଠାରୁ ସାମ୍ପ୍ରତିକ ବ୍ୟବହାରକାରୀ ବାର୍ତ୍ତା ଏବଂ ସବୁଠାରୁ ସାମ୍ପ୍ରତିକ ଟୁଲ୍ ଫଳାଫଳରେ ଅଛି କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ ଏବଂ ପୁନଃବାକ୍ୟବିନ୍ୟାସ କରନ୍ତୁ। ସାଧାରଣ ବିକଳ୍ପଗୁଡ଼ିକ:

- `Lorem ipsum …`କୁ `example text …` କିମ୍ବା ପରୀକ୍ଷଣ ବା ଫିକ୍ସଚର୍ ଯେଉଁ ପ୍ରକୃତ ବିଷୟବସ୍ତୁକୁ ମଡେଲ୍ କରିବାକୁ ଚେଷ୍ଟା କରୁଛି, ତାହା ସହିତ ବଦଳାନ୍ତୁ।
- `placeholder`କୁ (ଏକାକୀ ଥିବାବେଳେ) `example value`, `sample value`, କିମ୍ବା ପ୍ରକୃତ ମୂଲ୍ୟ ସହିତ ବଦଳାନ୍ତୁ।
- `language model`କୁ `large language model` କିମ୍ବା `the model` ସହିତ ବଦଳାନ୍ତୁ।
- `dummy data`କୁ `sample data` କିମ୍ବା ବାସ୍ତବସମ୍ମତ ସିଡ୍ ମୂଲ୍ୟଗୁଡ଼ିକ ସହିତ ବଦଳାନ୍ତୁ।
- `I'm here to help` / `here to help`କୁ ଅଧିକ ନିର୍ଦ୍ଦିଷ୍ଟ ପ୍ରାରମ୍ଭିକ ବାକ୍ୟ ସହିତ ବଦଳାନ୍ତୁ (ଯଥା, "I'll review the file you mentioned")।

## ଅପ୍ଷ୍ଟ୍ରିମ୍କୁ ଫଲ୍ସ ପଜିଟିଭ୍ ରିପୋର୍ଟ କରିବା

ବର୍ତ୍ତମାନର ଫିଲ୍ଟର୍ ଅତ୍ୟଧିକ ଆକ୍ରାମକ — ଏହା `tool_result` ବ୍ଲକ୍ରେ "Lorem ipsum"କୁ ବ୍ଲକ୍ କରେ, ଯଦିଓ ଅପରେଟର୍ଙ୍କର ଏକ ପ୍ରମ୍ପ୍ଟ ଇଞ୍ଜେକ୍ଟ କରିବାର ଉଦ୍ଦେଶ୍ୟ ନଥିବା ସ୍ପଷ୍ଟ। ଯେଉଁ ଅପରେଟର୍ମାନେ ମୂଳ ଉତ୍ସରେ ଏହାକୁ ସମାଧାନ କରାଇବାକୁ ଚାହାନ୍ତି, ସେମାନେ ଫଲ୍ସ ପଜିଟିଭ୍ଗୁଡ଼ିକ ରିପୋର୍ଟ କରିବା ପାଇଁ `agentrouter.org` ସହିତ ଯୋଗାଯୋଗ କରିବା ଉଚିତ। ଉପରୋକ୍ତ ବ୍ଲକ୍ଲିଷ୍ଟଟି 2026-08-03 ସୁଦ୍ଧା ଅପ୍ଷ୍ଟ୍ରିମ୍ର ପରୀକ୍ଷାମୂଳକ ଅନୁସନ୍ଧାନର ଫଳାଫଳ।
