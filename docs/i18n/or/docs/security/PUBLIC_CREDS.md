## ଏହା କାହିଁକି ରହିଛି

- [ନେଟିଭ୍ ଆପ୍ଗୁଡ଼ିକ ପାଇଁ OAuth 2.0 (PKCE)](https://developers.google.com/identity/protocols/oauth2/native-app) — ଇନ୍ଷ୍ଟଲ୍ ହୋଇଥିବା ଆପ୍ଗୁଡ଼ିକ ପାଇଁ OAuth client_id / client_secret ସାର୍ବଜନୀନ ଅଟେ; PKCE ପ୍ରକୃତ ସୁରକ୍ଷା ପ୍ରଦାନ କରେ।
- [Firebase API କୀଗୁଡ଼ିକ](https://firebase.google.com/docs/projects/api-keys) — Web କ୍ଲାଏଣ୍ଟ ପରିଚୟକଗୁଡ଼ିକ ଡିଜାଇନ୍ ଅନୁସାରେ ସାର୍ବଜନୀନ ଅଟେ।

OmniRoute-କୁ ଏହି ମୂଲ୍ୟଗୁଡ଼ିକ ଏମ୍ବେଡ୍ କରିବାକୁ ପଡ଼ିବ, ଯାହାଦ୍ୱାରା `.env` ବିନ୍ୟାସ କରୁନଥିବା ବ୍ୟବହାରକାରୀମାନେ ମଧ୍ୟ ବିନା ଅତିରିକ୍ତ ସେଟ୍ଅପ୍ରେ ଏକ କାର୍ଯ୍ୟକ୍ଷମ OAuth ପ୍ରବାହ ପାଇପାରିବେ। ଏକ ଏମ୍ବେଡେଡ୍ ଫଲ୍ବ୍ୟାକ୍ ବିନା, "କେବଳ କ୍ଲୋନ୍ କରନ୍ତୁ ଏବଂ ଚଲାନ୍ତୁ" ପଥ ଅନୁସରଣ କରୁଥିବା ଯେକୌଣସି ବ୍ୟବହାରକାରୀଙ୍କ ପାଇଁ Gemini / Antigravity ପ୍ରଦାତାଗୁଡ଼ିକ କାମ କରିବା ବନ୍ଦ କରିଦିଅନ୍ତି।

ତଥାପି, `AIzaSy…`, `GOCSPX-…`, `…apps.googleusercontent.com` ପରି ଲିଟେରାଲ୍ ମୂଲ୍ୟଗୁଡ଼ିକ **GitHub Secret Scanning**, **Semgrep**, ଏବଂ ସମାନ ପ୍ୟାଟର୍ନ ସ୍କାନର୍ଗୁଡ଼ିକ ଦ୍ୱାରା ମେଳ କରାଯାଏ। ପ୍ରତ୍ୟେକ ରିଲିଜ୍ ଭୁଲ୍ ପଜିଟିଭ୍ର ଏକ କୋଳାହଳପୂର୍ଣ୍ଣ ଧାରାରେ ପରିଣତ ହୁଏ, push protection ବୈଧ କମିଟ୍ଗୁଡ଼ିକୁ ବ୍ଲକ୍ କରେ, ଏବଂ ଅପରେଟର୍ମାନେ ସତର୍କତା ଫିଡ୍କୁ ବିଶ୍ୱାସ କରିବା ବନ୍ଦ କରିଦିଅନ୍ତି।

`open-sse/utils/publicCreds.ts` ସହାୟକ ଏକାସାଙ୍ଗରେ ଉଭୟ ସୀମାବଦ୍ଧତାର ସମାଧାନ କରେ:

- ସାର୍ବଜନୀନ ପରିଚୟକକୁ ଏକ **XOR-ମାସ୍କ୍ଡ୍ ବାଇଟ୍ କ୍ରମ** ଭାବରେ ଏମ୍ବେଡ୍ କରେ (ସୋର୍ସରେ କୌଣସି ସ୍କାନର୍ ପ୍ୟାଟର୍ନ ନଥାଏ)।
- ରନ୍ଟାଇମ୍ରେ `decodePublicCred` / `resolvePublicCred` ମାଧ୍ୟମରେ ଡିକୋଡ୍ କରେ।
- ପୂର୍ବରୁ ସୁପରିଚିତ ପ୍ରିଫିକ୍ସଗୁଡ଼ିକ (`AIza`, `GOCSPX-`, `<digits>-<32hex>.apps.googleusercontent.com`, `Iv1.<hex>`) ଅନୁସରଣ କରୁଥିବା କଞ୍ଚା ମୂଲ୍ୟଗୁଡ଼ିକୁ ଚିହ୍ନଟ କରେ ଏବଂ ସେଗୁଡ଼ିକୁ ଅପରିବର୍ତ୍ତିତ ଭାବେ ପଠାଇଦିଏ, ତେଣୁ ନିଜର ବର୍ତ୍ତମାନର `.env`-ରେ କଞ୍ଚା ମୂଲ୍ୟ ଥିବା ବ୍ୟବହାରକାରୀମାନଙ୍କ ପାଇଁ **ଶୂନ୍ୟ ମାଇଗ୍ରେସନ୍** ସହିତ କାମ ଚାଲୁ ରହେ।

ଏହା **ଅସ୍ପଷ୍ଟୀକରଣ, ଏନ୍କ୍ରିପ୍ସନ୍ ନୁହେଁ।** ସୋର୍ସ ପଢ଼ୁଥିବା ଯେକୌଣସି ବ୍ୟକ୍ତି ମୂଲ୍ୟଟି ପୁନରୁଦ୍ଧାର କରିପାରିବେ — ଯାହା ଠିକ୍, କାରଣ ମୂଲ୍ୟଟି ଡିଜାଇନ୍ ଅନୁସାରେ ସାର୍ବଜନୀନ। ଏକମାତ୍ର ଲକ୍ଷ୍ୟ ହେଉଛି ସ୍କାନର୍ regex ମେଳଗୁଡ଼ିକୁ ଏଡ଼ାଇବା।

## ବାଧ୍ୟତାମୂଳକ ପ୍ୟାଟର୍ନ

### 1. ଏକ ନୂତନ ସାର୍ବଜନୀନ କ୍ରେଡେନ୍ସିଆଲ୍ ଯୋଡ଼ିବା

ଯେତେବେଳେ ଆପଣଙ୍କୁ ଏକ ନୂତନ ଅପ୍ଷ୍ଟ୍ରିମ୍-ପ୍ରଦତ୍ତ ମୂଲ୍ୟ ଏମ୍ବେଡ୍ କରିବାକୁ ପଡ଼େ, ଯାହା:

- ଏକ ସାର୍ବଜନୀନ CLI / ଡେସ୍କଟପ୍ ଆପ୍ / ବ୍ରାଉଜର୍ ବଣ୍ଡଲ୍ରୁ ଆସେ, **ଏବଂ**
- ଅପ୍ଷ୍ଟ୍ରିମ୍ ପ୍ରଦାତା ଏହାକୁ ଏକ ସାର୍ବଜନୀନ କ୍ଲାଏଣ୍ଟ ପରିଚୟକ ଭାବରେ ଦଲିଲଭୁକ୍ତ କରେ (କିମ୍ବା ସେହିପରି ବ୍ୟବହାର କରେ), **ଏବଂ**
- ଅନ୍ୟଥା ଏକ ପ୍ୟାଟର୍ନ ସ୍କାନର୍ ଏହାକୁ ମେଳ କରିବ (`AIza…`, `GOCSPX-…`, `<digits>-…apps.googleusercontent.com`, ଇତ୍ୟାଦି),

…ଏହି ଯାଞ୍ଚତାଲିକା ଅନୁସରଣ କରନ୍ତୁ:

1. ମାସ୍କ୍ଡ୍ ବାଇଟ୍ କ୍ରମ ସୃଷ୍ଟି କରନ୍ତୁ:

   ```bash
   node --import tsx/esm -e \
     'import("./open-sse/utils/publicCreds.ts").then(m =>
        console.log(JSON.stringify(Array.from(
          Buffer.from(m.encodePublicCred("THE_PUBLIC_VALUE"), "base64")
        ))))'
   ```

2. `open-sse/utils/publicCreds.ts`-ରେ `EMBEDDED_DEFAULTS`କୁ ଏକ **ନିରପେକ୍ଷ କୀ ନାମ** (`<provider>_id`, `<provider>_alt`, `<provider>_fb`, ଇତ୍ୟାଦି) ସହିତ ଏକ ନୂତନ ଏଣ୍ଟ୍ରି ଯୋଡ଼ନ୍ତୁ। ସହାୟକରେ `client_secret` କିମ୍ବା `api_key` ପରି ନାମ **ବ୍ୟବହାର କରନ୍ତୁ ନାହିଁ** — ସେହି ଶବ୍ଦଗୁଡ଼ିକ Semgrep generic-secret ନିୟମଗୁଡ଼ିକୁ ଟ୍ରିଗର୍ କରେ।

3. ସାର୍ବଜନୀନ ଟାଇପ୍ ୟୁନିଅନ୍ରେ ଏକ `keyof typeof EMBEDDED_DEFAULTS` ଯୋଡ଼ନ୍ତୁ (ଏହା ସ୍ୱୟଂଚାଳିତ ଭାବେ ଅନୁମାନ କରାଯାଏ)।

4. କଞ୍ଜ୍ୟୁମର୍ କୋଡ୍ରେ, ହାର୍ଡକୋଡ୍ କରାଯାଇଥିବା ଲିଟେରାଲ୍କୁ ଏହା ସହିତ ବଦଳାନ୍ତୁ:

   ```ts
   // ଏକକ env ଓଭର୍ରାଇଡ୍
   clientSecret: resolvePublicCred("provider_alt", "PROVIDER_OAUTH_CLIENT_SECRET"),

   // ଏକାଧିକ env ଉପନାମ (ପ୍ରଥମ ଅଣ-ଖାଲି ମୂଲ୍ୟ ବିଜୟୀ ହୁଏ)
   clientId: resolvePublicCredMulti("provider_id", [
     "PROVIDER_CLI_OAUTH_CLIENT_ID",
     "PROVIDER_OAUTH_CLIENT_ID",
   ]),

   // କୌଣସି env ଓଭର୍ରାଇଡ୍ ନାହିଁ (ସର୍ବଦା ଏମ୍ବେଡେଡ୍ ଡିଫଲ୍ଟ)
   firebaseApiKey: resolvePublicCred("provider_fb"),
   ```

5. `.env.example`ରୁ ଲିଟେରାଲ୍ଟି ଅପସାରଣ କରନ୍ତୁ (ପାଠକମାନଙ୍କୁ ଏଠାକୁ ନିର୍ଦ୍ଦେଶ କରୁଥିବା କେବଳ-ମନ୍ତବ୍ୟ ଦଲିଲ ସହିତ ବଦଳାନ୍ତୁ):

   ```dotenv
   # ── ପ୍ରଦାତା (Google / Firebase / ଇତ୍ୟାଦି) ──
   # ସାର୍ବଜନୀନ OAuth କ୍ରେଡେନ୍ସିଆଲ୍ଗୁଡ଼ିକୁ
   # open-sse/utils/publicCreds.ts ମାଧ୍ୟମରେ କୋଡ୍ରେ ଏମ୍ବେଡ୍ କରାଯାଇଛି। କେବଳ ନିଜରଗୁଡ଼ିକ ବ୍ୟବହାର କରିବାକୁ ଏହି ଭେରିଏବଲ୍ଗୁଡ଼ିକ ସେଟ୍ କରନ୍ତୁ।
   # PROVIDER_OAUTH_CLIENT_ID=
   # PROVIDER_OAUTH_CLIENT_SECRET=
   ```

6. ନୂତନ କୀ ପାଇଁ ଏକ ଆକୃତି ଆସର୍ସନ୍ ଯୋଡ଼ିବାକୁ `tests/unit/publicCreds.test.ts` ଅଦ୍ୟତନ କରନ୍ତୁ (ଲିଟେରାଲ୍ ମୂଲ୍ୟ ନୁହେଁ, ଫର୍ମାଟ୍ ଯାଞ୍ଚ କରନ୍ତୁ — ପ୍ୟାଟର୍ନ ପାଇଁ ବର୍ତ୍ତମାନର ପରୀକ୍ଷାଗୁଡ଼ିକ ଦେଖନ୍ତୁ)।

7. ପରୀକ୍ଷା ଫାଇଲ୍ଗୁଡ଼ିକରେ `AIza…` / `GOCSPX-…` / `…apps.googleusercontent.com` ଲିଟେରାଲ୍ **କେବେବି** ଯୋଡ଼ନ୍ତୁ ନାହିଁ। `.join("")` ଖଣ୍ଡଗୁଡ଼ିକରୁ ନିର୍ମିତ `FAKE_*` କନ୍ଷ୍ଟାଣ୍ଟଗୁଡ଼ିକ ବ୍ୟବହାର କରନ୍ତୁ (ବର୍ତ୍ତମାନର ପରୀକ୍ଷାଗୁଡ଼ିକ ଦେଖନ୍ତୁ)।

### 2. କଞ୍ଜ୍ୟୁମର୍ଗୁଡ଼ିକ

- **କେବଳ `resolvePublicCred()` / `resolvePublicCredMulti()`ରୁ ପଢ଼ନ୍ତୁ** — ସହାୟକ ବାହାରେ କେବେବି ସିଧାସଳଖ `decodePublicCredBytes()` କଲ୍ କରନ୍ତୁ ନାହିଁ।
- ସହାୟକଟି ଉଦ୍ଦେଶ୍ୟମୂଳକ ଭାବେ ସ୍ୱଳ୍ପ ବ୍ୟୟବହୁଳ (ରୈଖିକ ବାଇଟ୍ XOR) ଏବଂ ମଡ୍ୟୁଲ୍-ଲୋଡ୍ ସମୟରେ କଲ୍ କରିବା ପାଇଁ ସୁରକ୍ଷିତ; ଡିଫଲ୍ଟଗୁଡ଼ିକ ଥରେ ମାତ୍ର ଗଣନା କରାଯାଏ।
- env ଓଭର୍ରାଇଡ୍ ସର୍ବଦା ପ୍ରାଧାନ୍ୟ ପାଏ। ଯଦି ଜଣେ ବ୍ୟବହାରକାରୀ `PROVIDER_OAUTH_CLIENT_SECRET=GOCSPX-myown` ସେଟ୍ କରନ୍ତି, ସହାୟକ ସେହି କଞ୍ଚା ମୂଲ୍ୟକୁ ଅପରିବର୍ତ୍ତିତ ଭାବେ ପଠାଇଦିଏ।

### 3. ନିଷିଦ୍ଧ ପ୍ୟାଟର୍ନଗୁଡ଼ିକ

❌ ପ୍ରଡକ୍ସନ୍ କୋଡ୍ରେ (`src/`, `open-sse/`, `electron/`, `bin/`) ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ କୌଣସିଟି **କେବେବି** କରନ୍ତୁ ନାହିଁ:

```ts
// ଖରାପ: ଲିଟେରାଲ୍ ମୂଲ୍ୟ Secret Scanning + Semgrepକୁ ଟ୍ରିଗର୍ କରେ
clientSecret: process.env.PROVIDER_OAUTH_CLIENT_SECRET || "GOCSPX-realvalue",

// ଖରାପ: ଲିଟେରାଲ୍ର base64 — Feb/2025 ଠାରୁ GitHub ଏବେ ମଧ୍ୟ ଏହାକୁ ଚିହ୍ନଟ କରେ
clientSecret: process.env.PROVIDER_OAUTH_CLIENT_SECRET ||
  Buffer.from("R09DU1BYLXJlYWx2YWx1ZQ==", "base64").toString(),

// ଖରାପ: ରନ୍ଟାଇମ୍ରେ ପ୍ୟାଟର୍ନକୁ ପୁଣି ଏକତ୍ର କରୁଥିବା ଷ୍ଟ୍ରିଙ୍ଗ୍ ସଂଯୋଜନ
clientSecret: "GO" + "CS" + "PX-" + "realvalue",

// ଖରାପ: hex/ROT13 ଏନ୍କୋଡିଂ — ଭିନ୍ନ ଅସ୍ପଷ୍ଟୀକରଣ, ଚିହ୍ନଟ ହେବାର ସମାନ ବିପଦ
clientSecret: hexDecode("474f4353..."),
```

ଏସବୁ ଶେଷରେ କୌଣସି ନା କୌଣସି ସ୍କାନର୍କୁ ଟ୍ରିଗର୍ କରେ। `resolvePublicCred()` ବ୍ୟବହାର କରନ୍ତୁ।

❌ `.env.example`ରେ ଲିଟେରାଲ୍ କ୍ରେଡେନ୍ସିଆଲ୍ଗୁଡ଼ିକ **କେବେବି** ଯୋଡ଼ନ୍ତୁ ନାହିଁ। ପ୍ରକୃତ ଅପ୍ଷ୍ଟ୍ରିମ୍ ମୂଲ୍ୟ ଆବଶ୍ୟକ କରୁଥିବା ବ୍ୟବହାରକାରୀମାନେ ସେଗୁଡ଼ିକୁ ନିଜେ ସାର୍ବଜନୀନ CLIରୁ ନିଷ୍କାସନ କରିପାରିବେ, କିମ୍ବା ନିଜର OAuth ପଞ୍ଜୀକରଣ ବ୍ୟବହାର କରିପାରିବେ।

❌ କ୍ରେଡେନ୍ସିଆଲ୍ଟିକୁ ଏହି ସହାୟକକୁ ସ୍ଥାନାନ୍ତର କରାଯିବା ଉଚିତ କି ନାହିଁ ପ୍ରଥମେ ଯାଞ୍ଚ ନକରି କୌଣସି ନୂତନ secret-scanning ସତର୍କତାକୁ **କେବେବି** ଖାରଜ କରନ୍ତୁ ନାହିଁ।

## ସମ୍ବନ୍ଧିତ ନିୟନ୍ତ୍ରଣଗୁଡ଼ିକ

- `publicCreds.ts` ରେ ଥିବା `RAW_VALUE_PATTERN`, ପାସ୍ଥ୍ରୁକୁ ସକ୍ରିୟ କରୁଥିବା ପ୍ରିଫିକ୍ସଗୁଡ଼ିକୁ ତାଲିକାଭୁକ୍ତ କରେ (ପୂର୍ବ ସଂସ୍କରଣ ସହ ସୁସଙ୍ଗତତା)। କେବଳ ଡକ୍ୟୁମେଣ୍ଟ କରାଯାଇଥିବା ସାର୍ବଜନୀନ କ୍ରେଡେନ୍ସିଆଲ୍ ଫର୍ମାଟ୍ଗୁଡ଼ିକ ପାଇଁ ଏହାକୁ ବିସ୍ତାର କରନ୍ତୁ, ମାଲିକାନାଧୀନ ଗୋପନୀୟ ତଥ୍ୟ ପାଇଁ କେବେ ନୁହେଁ।
- `.env.example`, CI ର `check-env-doc-sync` ସ୍କ୍ରିପ୍ଟରେ ରହିଛି — ଏଠାରୁ କୌଣସି ଭେରିଏବଲ୍ ଅପସାରଣ କଲେ, ଡକ୍ୟୁମେଣ୍ଟେସନ୍ ତାହା ସହ ମେଳ ଖାଉଛି ବୋଲି ନିଶ୍ଚିତ କରନ୍ତୁ।
- `npm run test:vitest` ଏବଂ `node --import tsx/esm --test tests/unit/publicCreds.test.ts` ଟେଷ୍ଟ ସୁଇଟ୍—ଉଭୟକୁ ସଫଳ ରଖିବା ଆବଶ୍ୟକ।

## ଏହି ହେଲ୍ପର୍କୁ କେବେ ବ୍ୟବହାର କରିବେ **ନାହିଁ**

ଏହି ହେଲ୍ପର୍ଟି **କେବଳ** ନିମ୍ନଲିଖିତ କ୍ରେଡେନ୍ସିଆଲ୍ଗୁଡ଼ିକ ପାଇଁ:

1. ଅପ୍ଷ୍ଟ୍ରିମ୍ ପ୍ରଦାନକାରୀଙ୍କ ଦ୍ୱାରା ସାର୍ବଜନୀନ ଭାବେ ବିତରଣ କରାଯାଇଥିବା (CLI ବାଇନେରୀ, ବ୍ରାଉଜର୍ ବଣ୍ଡଲ୍, ଅଧିକୃତ ଡକ୍ୟୁମେଣ୍ଟ)।
2. ଅଗୋପନୀୟ ବୋଲି ଡକ୍ୟୁମେଣ୍ଟ କରାଯାଇଥିବା କିମ୍ବା ଦୃଢ଼ ଭାବେ ସୂଚିତ (PKCE-ସୁରକ୍ଷିତ, Firebase Web କୀ, କିମ୍ବା ସମାନ)।

ଅନ୍ୟ ସମସ୍ତ କ୍ଷେତ୍ରରେ — ଅପରେଟର୍ ଜାରି କରିଥିବା ଟୋକନ୍, ପ୍ରତି-ଟେନାଣ୍ଟ ଗୋପନୀୟ ତଥ୍ୟ, ଆପଣଙ୍କ ନିଜ OAuth ଆପ୍ର client_secret, ଏନ୍କ୍ରିପ୍ସନ୍ କୀ, JWT ଗୋପନୀୟ ତଥ୍ୟ, ଡାଟାବେସ୍ ପାସ୍ୱାର୍ଡ — **କେବଳ env vars** (`process.env.FOO`, ଖାଲି ମୂଲ୍ୟ / ସ୍ପଷ୍ଟ ତ୍ରୁଟି ପାଇଁ `||` ଫଲ୍ବ୍ୟାକ୍) ବ୍ୟବହାର କରନ୍ତୁ। ଏଗୁଡ଼ିକ ସୋର୍ସରେ ନୁହେଁ, ବରଂ `.env` ଏବଂ [ଏନ୍କ୍ରିପ୍ଟ କରାଯାଇଥିବା କ୍ରେଡେନ୍ସିଆଲ୍ ଷ୍ଟୋର୍](./COMPLIANCE.md) ରେ ରହିବା ଉଚିତ।
