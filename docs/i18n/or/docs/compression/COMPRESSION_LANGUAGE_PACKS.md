Caveman କମ୍ପ୍ରେସନ୍ରେ ଅନ୍ତର୍ନିର୍ମିତ ଇଂରାଜୀ ନିୟମଗୁଡ଼ିକ ସହିତ ଭାଷା-ନିର୍ଦ୍ଦିଷ୍ଟ ନିୟମ ପ୍ୟାକ୍ଗୁଡ଼ିକୁ ମଧ୍ୟ ଲୋଡ୍ କରାଯାଇପାରେ।
ଏହା ମୂଳ ଇଞ୍ଜିନ୍କୁ ସ୍ଥିର ରଖିବା ସହିତ ପର୍ତ୍ତୁଗୀଜ୍, ସ୍ପାନିଶ୍, ଜର୍ମାନ୍, ଫ୍ରେଞ୍ଚ୍, ଇଟାଲୀୟ, ଜାପାନୀ ଏବଂ
ଭବିଷ୍ୟତର ଭାଷା ପ୍ୟାକ୍ଗୁଡ଼ିକୁ ସ୍ୱାଧୀନ ଭାବେ ବିକଶିତ ହେବାକୁ ସୁଯୋଗ ଦିଏ।

## ଅବସ୍ଥାନ

ଭାଷା ପ୍ୟାକ୍ଗୁଡ଼ିକ ଏଠାରେ ରହେ:

```txt
open-sse/services/compression/rules/<language>/
```

ବର୍ତ୍ତମାନ ପ୍ରଦାନ କରାଯାଉଥିବା ପ୍ୟାକ୍ଗୁଡ଼ିକ (`rules/` ଡିରେକ୍ଟୋରୀର ବିଷୟବସ୍ତୁ ସହିତ ଯାଞ୍ଚ କରାଯାଇଛି):

| ଭାଷା                   | ଡିରେକ୍ଟୋରୀ     | ଉପଲବ୍ଧ ନିୟମ ବର୍ଗଗୁଡ଼ିକ                              |
| ---------------------- | -------------- | --------------------------------------------------- |
| ଇଂରାଜୀ                 | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ସ୍ପାନିଶ୍               | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ପର୍ତ୍ତୁଗୀଜ୍ (ବ୍ରାଜିଲ୍) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ଇଣ୍ଡୋନେସୀୟ             | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ଇଟାଲୀୟ                 | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ଜର୍ମାନ୍                | `rules/de/`    | `context`, `filler`, `structural`                   |
| ଫ୍ରେଞ୍ଚ୍               | `rules/fr/`    | `context`, `filler`, `structural`                   |
| ଜାପାନୀ                 | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **ସମତୁଲ୍ୟତା ସୂଚନା:** `en`, `es`, `pt-BR`, `id`, ଏବଂ `it` ପ୍ୟାକ୍ଗୁଡ଼ିକରେ ସମସ୍ତ 5ଟି ବର୍ଗ ରହିଛି; `de`, `fr`, `ja`ରେ 3ଟି ବର୍ଗ ପ୍ରଦାନ କରାଯାଏ। ଅନୁପସ୍ଥିତ `dedup` ଏବଂ `ultra` ବର୍ଗଗୁଡ଼ିକ ନିରବରେ ଅନ୍ତର୍ନିର୍ମିତ ଇଂରାଜୀ ନିୟମକୁ ବ୍ୟବହାର କରନ୍ତି। ଛୋଟ ପ୍ୟାକ୍ଗୁଡ଼ିକ ପାଇଁ `dedup.json` ଏବଂ `ultra.json` ଯୋଡ଼ିବାକୁ ଅବଦାନ ସ୍ୱାଗତଯୋଗ୍ୟ।
>
> `pt-BR` ପ୍ୟାକ୍ଟି Lenine Júniorଙ୍କ **[Troglodita](https://github.com/leninejunior/troglodita)** ଉପରେ ଆଧାରିତ — ଏହା ବ୍ରାଜିଲୀୟ ପର୍ତ୍ତୁଗୀଜ୍ ବ୍ୟାକରଣ ପାଇଁ ଆରମ୍ଭରୁ ଡିଜାଇନ୍ କରାଯାଇଥିବା ଏକ କମ୍ପ୍ରେସନ୍ ସିଷ୍ଟମ୍ (ପୁନରୁକ୍ତି ହ୍ରାସ, PT-BR ଅନାବଶ୍ୟକ ଶବ୍ଦ ଅପସାରଣ, dev BR ସମୁଦାୟ ପାଇଁ ବୈଷୟିକ ସଂକ୍ଷିପ୍ତ ରୂପ)।
>
> ପ୍ରାମାଣିକ ବର୍ଗ ତାଲିକା ଏବଂ ପ୍ରତ୍ୟେକ ବର୍ଗର ସ୍କିମା [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json)ରେ ରହିଛି (JSON Schema draft 2020-12)।

## ଭାଷା ଚିହ୍ନଟ

`languageDetector.ts` ପ୍ରମ୍ପ୍ଟ ଟେକ୍ସଟ୍ରୁ ଭାଷା ଅନୁମାନ କରିବା ପାଇଁ ହାଲୁକା ହ୍ୟୁରିଷ୍ଟିକ୍ସ ବ୍ୟବହାର କରେ। ବିନ୍ୟାସିତ ଡିଫଲ୍ଟ ଭାଷାକୁ ତଥାପି ସମ୍ମାନ କରାଯାଏ, ଏବଂ ସଠିକ୍
ନିୟନ୍ତ୍ରଣ ଆବଶ୍ୟକ ହେଲେ କନଫିଗ୍ ମାଧ୍ୟମରେ ଚିହ୍ନଟକୁ ଅକ୍ଷମ କରାଯାଇପାରେ।

ଚିହ୍ନଟ ଆଉଟ୍ପୁଟ୍ କେବଳ ନିୟମ ପ୍ୟାକ୍ ବାଛିବା ପାଇଁ ବ୍ୟବହୃତ ହୁଏ। ଏହା ପ୍ରଦାନକାରୀ ରାଉଟିଂ, ଲୋକେଲ୍
ଚୟନ କିମ୍ବା UI ଭାଷାକୁ ପରିବର୍ତ୍ତନ କରେ ନାହିଁ।

## କନଫିଗ୍ର ଗଠନ

କମ୍ପ୍ରେସନ୍ ସେଟିଂସ୍ରେ ଏହା ଅନ୍ତର୍ଭୁକ୍ତ ହୋଇପାରେ:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` ଡ୍ୟାଶ୍ବୋର୍ଡ/ପୂର୍ବାବଲୋକନ ଡିଫଲ୍ଟଗୁଡ଼ିକୁ ନିୟନ୍ତ୍ରଣ କରେ। `cavemanConfig` ହେଉଛି ରନ୍ଟାଇମ୍ ଇଞ୍ଜିନ୍ କନଫିଗ୍,
ଯାହା Caveman ମେସେଜ୍ ଟେକ୍ସଟ୍କୁ କମ୍ପ୍ରେସ୍ କରିବା ସମୟରେ ବ୍ୟବହୃତ ହୁଏ।

## ଏକ ଭାଷା ପ୍ୟାକ୍ ଯୋଡ଼ିବା

1. `open-sse/services/compression/rules/<language>/<pack>.json` ସୃଷ୍ଟି କରନ୍ତୁ।
2. `docs/compression/COMPRESSION_RULES_FORMAT.md`ରେ ଥିବା Caveman ନିୟମ ଫର୍ମାଟ୍ ବ୍ୟବହାର କରନ୍ତୁ।
3. ପ୍ରତିସ୍ଥାପନଗୁଡ଼ିକୁ ସୀମିତ ରଖନ୍ତୁ ଏବଂ କୋଡ୍, ପରିଚୟକ, URL କିମ୍ବା JSON ପରିବର୍ତ୍ତନ କରିବାରୁ ବିରତ ରୁହନ୍ତୁ।
4. ଭାଷା ଚୟନ ଏବଂ ପ୍ରତିସ୍ଥାପନ ଆଚରଣ ପାଇଁ ପରୀକ୍ଷଣଗୁଡ଼ିକ ଯୋଡ଼ନ୍ତୁ କିମ୍ବା ଅଦ୍ୟତନ କରନ୍ତୁ।
5. ଭାଷାଟି UI ଚୟନକର୍ତ୍ତାଗୁଡ଼ିକରେ ଦେଖାଯାଉଥିଲେ, ନୂତନ ଡ୍ୟାଶବୋର୍ଡ/i18n ଲେବଲ୍ଗୁଡ଼ିକୁ ଉପଲବ୍ଧ କରାନ୍ତୁ।

## API

ଉପଲବ୍ଧ ପ୍ୟାକ୍ଗୁଡ଼ିକୁ ନିମ୍ନପ୍ରକାର କ୍ୱେରି କରାଯାଇପାରିବ:

```bash
curl http://localhost:20128/api/compression/language-packs
```

ପୂର୍ବାବଲୋକନ ଏଣ୍ଡପଏଣ୍ଟ୍ ଭାଷା ବିନ୍ୟାସ ଓଭର୍ରାଇଡ୍ଗୁଡ଼ିକୁ ଗ୍ରହଣ କରେ:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

v3.8.0ରେ ସମସ୍ତ 6ଟି ଭାଷା ପ୍ୟାକ୍ରେ ଏକ `SHARED_BOUNDARIES` ଧାରା ଯୋଡ଼ାଯାଇଛି, ଯାହା ପ୍ରତ୍ୟେକ
Caveman ତୀବ୍ରତାରେ (LITE, FULL, ULTRA) ପ୍ରୟୋଗ କରାଯାଏ। ଚାରିପାଖରେ ଥିବା ଅନାବଶ୍ୟକ ଶବ୍ଦଗୁଡ଼ିକୁ ଅପସାରଣ କରାଯାଉଥିଲେ ମଧ୍ୟ,
ଏହା ଇଞ୍ଜିନ୍କୁ ଏହି ପ୍ୟାଟର୍ନଗୁଡ଼ିକୁ ଅବିକଳ ଭାବରେ ସଂରକ୍ଷଣ କରିବାକୁ ନିର୍ଦ୍ଦେଶ ଦିଏ:

| ପ୍ୟାଟର୍ନ ପ୍ରକାର                  | ଉଦାହରଣ                                 |
| -------------------------------- | -------------------------------------- |
| ସୀମାବଦ୍ଧ କୋଡ୍ ବ୍ଲକ୍              | ` ```python\n...\n``` `                |
| ଇନ୍ଲାଇନ୍ କୋଡ୍                    | `` `my_var` ``                         |
| URLଗୁଡ଼ିକ                        | `https://example.com/path`             |
| ଫାଇଲ୍ ପଥ (ସମ୍ପୂର୍ଣ୍ଣ + ଆପେକ୍ଷିକ) | `/etc/hosts`, `./src/index.ts`         |
| ତ୍ରୁଟି ହେଡର୍ଗୁଡ଼ିକ               | `Error:`, `TypeError:`, `SyntaxError:` |
| ଷ୍ଟାକ୍ ଟ୍ରେସ୍ ଧାଡ଼ିଗୁଡ଼ିକ        | `  at functionName (file.ts:12:3)`     |

ଏହି ପ୍ୟାଟର୍ନଗୁଡ଼ିକ `DEFAULT_CAVEMAN_CONFIG.preservePatterns`ରେ ପୂରଣ କରାଯାଇଛି (ପୂର୍ବରୁ `[]` ଥିଲା)। ଏହି
ଧ୍ରୁବକଟି `open-sse/services/compression/types.ts`ରେ ଅବସ୍ଥିତ।

### ଏହା କାହିଁକି ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ

SHARED_BOUNDARIES ବିନା, ଆକ୍ରମଣାତ୍ମକ Caveman ମୋଡ୍ଗୁଡ଼ିକ ଏପରି ବିଷୟବସ୍ତୁକୁ ଅପସାରଣ କରିପାରନ୍ତି, ଯାହା ଦେଖିବାକୁ ପୁନରାବୃତ୍ତିମୂଳକ
ଗଦ୍ୟ ପରି ଲାଗୁଥିଲେ ମଧ୍ୟ ପ୍ରକୃତରେ ଏକ କୋଡ୍ ସ୍ନିପେଟ୍, ଫାଇଲ୍ ପଥ କିମ୍ବା ତ୍ରୁଟି ଷ୍ଟାକ୍ ଥିଲା। SHARED_BOUNDARIES ଏକ
ଭାଷା-ନିରପେକ୍ଷ ସୁରକ୍ଷା ଜାଲ ଭାବେ କାମ କରେ, ଯାହା ଅନାବଶ୍ୟକ ଶବ୍ଦ ନିୟମଗୁଡ଼ିକ ଚାଲିବା ପୂର୍ବରୁ ପ୍ରୟୋଗ କରାଯାଏ।

### preservePatterns କଷ୍ଟମାଇଜ୍ କରିବା

କମ୍ପ୍ରେସନ୍ ସେଟିଂସ୍ ମାଧ୍ୟମରେ ରନ୍ଟାଇମ୍ରେ ଅତିରିକ୍ତ ପ୍ୟାଟର୍ନ ଯୋଡ଼ାଯାଇପାରିବ:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

କଷ୍ଟମ୍ ପ୍ୟାଟର୍ନଗୁଡ଼ିକ 6ଟି ଡିଫଲ୍ଟକୁ ବିସ୍ତାର କରେ (ପ୍ରତିସ୍ଥାପନ କରେ ନାହିଁ)।

## ପରିଚାଳନାସମ୍ବନ୍ଧୀୟ ଟିପ୍ପଣୀ

- କୌଣସି ଭାଷା ପ୍ୟାକ୍ ନଥିଲେ, ଇଂରାଜୀର ଅନ୍ତର୍ନିର୍ମିତ ନିୟମଗୁଡ଼ିକ ଫଲ୍ବ୍ୟାକ୍ ଭାବେ ରହିଥାଏ।
- ଅବୈଧ ଅନ୍ତର୍ନିର୍ମିତ JSON ପ୍ୟାକ୍ଗୁଡ଼ିକ ବୈଧତା ଯାଞ୍ଚରେ ବିଫଳ ହୁଏ, ଯାହାଦ୍ୱାରା ରିଲିଜ୍ ଆସେଟ୍ଗୁଡ଼ିକର ଗୁଣବତ୍ତା ନିରବରେ ହ୍ରାସ ନ ପାଏ।
- ନିୟମ ପ୍ୟାକ୍ଗୁଡ଼ିକ କେବଳ ଡାଟା-ଆଧାରିତ ଏବଂ ସେଗୁଡ଼ିକ କୋଡ୍ ଇମ୍ପୋର୍ଟ କିମ୍ବା ଇଚ୍ଛାମତା ଲଜିକ୍ ଚାଳନା କରିବା ଉଚିତ୍ ନୁହେଁ।
- କମ୍ପ୍ରେସନ୍ ଆନାଲିଟିକ୍ସ ସ୍ତରଟି ସମ୍ପୂର୍ଣ୍ଣ ପ୍ରମ୍ପ୍ଟ ପାଠ୍ୟ ନୁହେଁ, ବରଂ ଚୟନିତ ମୋଡ୍ ଏବଂ ଇଞ୍ଜିନ୍କୁ ରେକର୍ଡ କରେ।
