`devin-cli-agentic`, ପ୍ରକୃତ Claude Code ରନ୍ଟାଇମ୍କୁ OmniRouteର ସ୍ଥାନୀୟ Anthropic
Messages ଏଣ୍ଡପଏଣ୍ଟ ବ୍ୟବହାର କରିବାକୁ ଦିଏ, ଯେତେବେଳେ ଆଧିକାରିକ Devin CLI, ACP stdio ମାଧ୍ୟମରେ ମଡେଲ୍ ପ୍ରତିକ୍ରିୟା ପ୍ରଦାନ କରେ। ଏହା
ବିଦ୍ୟମାନ Anthropic, Claude OAuth, Claude Web, କିମ୍ବା `devin-cli` ପ୍ରଦାତାଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ କରେ ନାହିଁ।

> **ବର୍ତ୍ତମାନ ସ୍ଥିତି: Claude Code `2.1.258`ରେ ପିନ୍ କରାଯାଇଛି; ଅଫ୍ଲାଇନ୍ ଏବଂ ଲାଇଭ୍ ବୈଧୀକରଣ ଶେଷଥର
> `2.1.220`ରେ ରେକର୍ଡ କରାଯାଇଥିଲା।** `2.1.220` ପିନ୍, Devin CLI
> `3000.2.17` ଏବଂ ମଡେଲ୍ `swe-1-7-lightning` ମାଧ୍ୟମରେ ତିନୋଟି ପୃଥକ ପରିଦୃଶ୍ୟ ସମ୍ପୂର୍ଣ୍ଣ କରିଥିଲା; ସେହି ଅନ୍ତିମ ଲାଇଭ୍ ରନ୍ କ୍ଲାଏଣ୍ଟ-ନିୟନ୍ତ୍ରିତ `Read`,
> `Edit`, ଏବଂ `Bash` ଟର୍ନ୍, ସଫଳ `npm test` ଫଳାଫଳ, ପ୍ରକଳ୍ପ କମାଣ୍ଡ ଏବଂ ସ୍କିଲ୍
> ଆବିଷ୍କାର, କେବଳ-Devin ରାଉଟିଂ, ଏବଂ ଶୂନ୍ୟ Claude ଇଗ୍ରେସ୍ ପ୍ରମାଣ କରିଥିଲା। ଏହାପରେ ପିନ୍କୁ `2.1.258`କୁ ବୃଦ୍ଧି କରାଯାଇଥିଲା
> (OmniRouteର Claude ପରିଚୟ ଯେଉଁ CLI ପିଢ଼ିର ଛଦ୍ମବେଶ ଧାରଣ କରେ, ଏବଂ ସ୍ୱାଭାବିକ ଭାବରେ
> Fable 5.1 ସ୍ତର ପ୍ରଦାନ କରୁଥିବା ପ୍ରଥମ ଲାଇନ୍)। ନୂଆ ପିନ୍ରେ, ପିନ୍ କରାଯାଇଥିବା ବେସ୍ ଇମେଜ୍ରେ ଇନ୍ଷ୍ଟଲ୍ ସ୍ତର ଏବଂ `claude --version`
> ଯାଞ୍ଚ କରାଯାଇଥିଲା, ଏବଂ ବ୍ରିଜ୍ ୟୁନିଟ୍ ସୁଇଟ୍, `compose config` ଓ
> ସ୍ଥିର ଆଇସୋଲେସନ୍ ପ୍ରମାଣ ସଫଳ ହୋଇଛି — କିନ୍ତୁ ଅଫ୍ଲାଇନ୍ ମକ୍ ପରିଦୃଶ୍ୟ ଏବଂ ଲାଇଭ୍ ତିନି-ପରିଦୃଶ୍ୟ
> ସୁଇଟ୍କୁ ଏପର୍ଯ୍ୟନ୍ତ ପୁନଃ ଚଲାଯାଇନାହିଁ। ଏହି ପିନ୍ ସହିତ ବ୍ରିଜ୍ଉପରେ ନିର୍ଭର କରିବା ପୂର୍ବରୁ ସେଗୁଡ଼ିକୁ ପୁନଃ ଚଲାନ୍ତୁ
> ("ପିନ୍ କରାଯାଇଥିବା ଟୁଲ୍ଗୁଡ଼ିକୁ ଅପଡେଟ୍ କରିବା" ଦେଖନ୍ତୁ)।

## ସ୍ଥାପତ୍ୟ

```text
Claude Code 2.1.258 (ପୃଥକ କରାଯାଇଥିବା ଅଣ-root Linux କଣ୍ଟେନର୍)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ଫର୍ମାଟ୍, ଅଣ-ପ୍ରମାଣୀକରଣ ପ୍ରଦାତା)
  -> devin acp --agent-type summarizer (ଆଧିକାରିକ ACP stdio, କୌଣସି Devin ଟୁଲ୍ ନାହିଁ)
  -> ଉତ୍ସର୍ଗୀକୃତ devin-auth ଭଲ୍ୟୁମ୍ରେ Devin ଆକାଉଣ୍ଟ
```

ଆଧିକାରିକ CLIର ଡିଫଲ୍ଟ ACP ଏଜେଣ୍ଟ ନିଜ ଟୁଲ୍ଗୁଡ଼ିକ ଚଲାଇପାରେ, ତେଣୁ ଏହି ବ୍ରିଜ୍ ତାହାକୁ ବ୍ୟବହାର
କରେ ନାହିଁ। ଏହା ନିର୍ଦ୍ଧାରିତ `summarizer` ACP ଏଜେଣ୍ଟକୁ ଆରମ୍ଭ କରେ, ଯାହାର ଆଧିକାରିକ CLI ମୋଡ୍ରେ କୌଣସି ଟୁଲ୍ ନାହିଁ, ଏବଂ
କ୍ରମିକୀକୃତ Anthropic ଅନୁରୋଧକୁ ଏକ ଏକ୍ସିକ୍ୟୁସନ୍ ଟ୍ରେସ୍ ଭାବରେ ଫ୍ରେମ୍ କରେ। ଅନ୍ୟ ଏକ Claude-ନିୟନ୍ତ୍ରିତ
କାର୍ଯ୍ୟ ଆବଶ୍ୟକ ହେଲେ, ପ୍ରତିକ୍ରିୟାରେ ଠିକ୍ ଗୋଟିଏ କ୍ଲାଏଣ୍ଟ ଟୁଲ୍ ଏନ୍ଭେଲପ୍ ରହିବା ଆବଶ୍ୟକ। କୌଣସି ACP
`tool_call` କିମ୍ବା `tool_call_update`କୁ ଏକ ପ୍ରତିକ୍ରିୟା ସଫଳ ବୋଲି ରିପୋର୍ଟ କରାଯିବା ପୂର୍ବରୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ।

`open-sse/executors/devin-agentic/serializer.ts`ରେ ଥିବା ସିରିଆଲାଇଜର୍ `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, ଏବଂ
Claude Code ଦ୍ୱାରା ଯୋଗାଇ ଦିଆଯାଇଥିବା ଟୁଲ୍ଗୁଡ଼ିକୁ ସଂରକ୍ଷଣ କରେ। ଇମେଜ୍ ଏବଂ ଅଜଣା ବ୍ଲକ୍ଗୁଡ଼ିକ ସ୍ପଷ୍ଟ ଭାବରେ ବିଫଳ ହୁଏ। ବଡ଼ ଟୁଲ୍ ଫଳାଫଳ
ଏକ ଦୃଶ୍ୟମାନ କାଟଛାଣ୍ଟ ସୂଚକ ବ୍ୟବହାର କରେ।

ପାର୍ସର୍ ପ୍ରତ୍ୟେକ ମଡେଲ୍ ଟର୍ନ୍ରେ ଗୋଟିଏ ସ୍ୱତନ୍ତ୍ର `<tool>{...}</tool>` ଏନ୍ଭେଲପ୍ ଗ୍ରହଣ କରେ। ଏହା
ଅନୁରୋଧର ଟୁଲ୍ ତାଲିକା ସହିତ ନାମ ଯାଞ୍ଚ କରେ, ସେହି ଟୁଲ୍ର JSON
Schema ଅନୁଯାୟୀ ଆର୍ଗୁମେଣ୍ଟଗୁଡ଼ିକୁ ବୈଧୀକରଣ କରେ, ମିଶ୍ରିତ ବର୍ଣ୍ଣନା/କାର୍ଯ୍ୟଗୁଡ଼ିକୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରେ, ଏବଂ ଗୋଟିଏ ସୀମିତ ମରାମତିକୁ ଅନୁମତି ଦିଏ। ତା’ପରେ Claude Code
ଫଳସ୍ୱରୂପ ମିଳୁଥିବା Anthropic `tool_use`କୁ ସ୍ଥାନୀୟ ଭାବରେ ନିଷ୍ପାଦନ କରେ ଏବଂ `tool_result`କୁ OmniRoute ମାଧ୍ୟମରେ ପଛକୁ
ପଠାଏ।

## ଆଇସୋଲେସନ୍ ଏବଂ ବିପଦ ମଡେଲ୍

ହୋଷ୍ଟର Claude ଇନ୍ଷ୍ଟଲେସନ୍, ଆକାଉଣ୍ଟ ଏବଂ ବିନ୍ୟାସ କାର୍ଯ୍ୟପରିସର ବାହାରେ ଅଛି ଏବଂ ସେଗୁଡ଼ିକୁ
ନିଷିଦ୍ଧ ଭାବରେ ଧରାଯାଏ। Compose ସର୍ଭିସ୍ଗୁଡ଼ିକ:

- UID/GID `10001:10001` ଭାବରେ, କେବଳ-ପଠନୀୟ ରୁଟ୍ ଫାଇଲ୍ ସିଷ୍ଟମ୍, ବାଦ ଦିଆଯାଇଥିବା କ୍ଷମତା, ଏବଂ
  `no-new-privileges` ସହିତ ଚାଲେ;
- ଏକ ବ୍ୟକ୍ତିଗତ `/home/bridge`, ଏକ ଉତ୍ସର୍ଗୀକୃତ Claude ବିନ୍ୟାସ ଭଲ୍ୟୁମ୍, ପୃଥକ OmniRoute ଡାଟା,
  ଏବଂ ଏକ ଅଲଗା `devin-auth` ଭଲ୍ୟୁମ୍ ବ୍ୟବହାର କରେ;
- କେବଳ ନିଷ୍କାସନଯୋଗ୍ୟ `.sandbox` ୱର୍କସ୍ପେସ୍/ପ୍ରମାଣ ମାଉଣ୍ଟ କରେ;
- ହୋଷ୍ଟ ହୋମ୍, Keychain, SSH, କ୍ଲାଉଡ୍ ପରିଚୟପତ୍ର, କିମ୍ବା Docker ସକେଟ୍ ମାଉଣ୍ଟ କରେ ନାହିଁ;
- ସ୍ପଷ୍ଟ ଏନ୍ଭାୟରନ୍ମେଣ୍ଟ ନିର୍ମାଣ କରେ ଏବଂ Anthropic API/OAuth/ରାଉଟିଂ ଭେରିଏବଲ୍ଗୁଡ଼ିକୁ ଅପସାରଣ କରେ;
- କେବଳ-ସ୍ଥାନୀୟ କୀ ସହିତ Claude Code ଇନ୍ଫରେନ୍ସକୁ କେବଳ `http://omniroute:20128`କୁ ନିର୍ଦ୍ଦେଶିତ କରେ।

ଅଫ୍ଲାଇନ୍ ପ୍ରୋଫାଇଲ୍ ଏକ ଆଭ୍ୟନ୍ତରୀଣ ନେଟୱର୍କ ବ୍ୟବହାର କରେ। ଲାଇଭ୍ ପ୍ରୋଫାଇଲ୍ରେ, OmniRoute
କେବଳ `network-guard` ମାଧ୍ୟମରେ ଆଧିକାରିକ Devin ଏଣ୍ଡପଏଣ୍ଟଗୁଡ଼ିକରେ ପହଞ୍ଚେ; ଅସମ୍ବନ୍ଧିତ ଗନ୍ତବ୍ୟସ୍ଥଳଗୁଡ଼ିକୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ।
Claude Codeର ଏକ ପୃଥକ ସମସ୍ତ-ଇଗ୍ରେସ୍-ପ୍ରତ୍ୟାଖ୍ୟାନ ଗାର୍ଡ ଅଛି ଏବଂ ଏହା କେବଳ ସ୍ଥାନୀୟ OmniRoute
ସର୍ଭିସ୍ରେ `NO_PROXY` ମାଧ୍ୟମରେ ପହଞ୍ଚିପାରେ। ଗାର୍ଡ ଅଡିଟ୍ ଫାଇଲ୍ଗୁଡ଼ିକ କେବଳ ସେମାନଙ୍କର ଗାର୍ଡ ପ୍ରକ୍ରିୟା ଦ୍ୱାରା ମାଉଣ୍ଟ କରାଯାଏ। ସ୍କ୍ରିପ୍ଟଗୁଡ଼ିକ
ଟୋକେନ୍-ମୁକ୍ତ ପ୍ରମାଣ ରପ୍ତାନି କରିବା ପୂର୍ବରୁ ଫାଇଲ୍ ମାଲିକାନା, ମୋଡ୍, ଲିଙ୍କ୍ ସଂଖ୍ୟା ଏବଂ ପ୍ରତ୍ୟେକ ନିଷ୍ପତ୍ତି ଯାଞ୍ଚ କରେ।

ଆଇସୋଲେସନ୍ ପ୍ରମାଣକୁ ସ୍ୱାଧୀନ ଭାବରେ ଚଲାନ୍ତୁ:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

ଏହା ଟୋପୋଲୋଜି, ନାମିତ ମାଉଣ୍ଟ, ଅଣ-root/କେବଳ-ପଠନୀୟ ସେଟିଂସ୍, ସ୍ପଷ୍ଟ ସ୍ଥାନୀୟ ରାଉଟିଂ,
ସମ୍ବେଦନଶୀଳ ଏନ୍ଭାୟରନ୍ମେଣ୍ଟ ଭେରିଏବଲ୍ଗୁଡ଼ିକର ଅନୁପସ୍ଥିତି, Docker ସକେଟ୍ର ଅନୁପସ୍ଥିତି, `api.anthropic.com`
ଏବଂ `claude.ai`କୁ ଅବରୋଧିତ ପ୍ରବେଶ, କେବଳ-Devin ପ୍ରଦାତା ଚୟନ, ଏବଂ ACP ବ୍ୟାକେଣ୍ଡ ଅନୁପଲବ୍ଧ ଥିବାବେଳେ
ସ୍ପଷ୍ଟ ବିଫଳତାକୁ ବୈଧୀକରଣ କରେ।

## ପ୍ରଥମ ଥର ସେଟଅପ୍ ଏବଂ ସାଧାରଣ ବ୍ୟବହାର

ପିନ୍ କରାଯାଇଥିବା ଇମେଜ୍ ବିଲ୍ଡ କରନ୍ତୁ:

```bash
./scripts/devin-bridge/build
```

କେବଳ ପୃଥକ Devin ଭଲ୍ୟୁମ୍କୁ ପ୍ରମାଣୀକୃତ କରନ୍ତୁ:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

ଲଗଇନ୍ କମାଣ୍ଡଟି ରିମୋଟ୍/କଣ୍ଟେନର୍ ପରିବେଶ ପାଇଁ ଉଦ୍ଦିଷ୍ଟ ଅଧିକୃତ ମାନୁଆଲ୍-ଟୋକନ୍ ପ୍ରବାହ ବ୍ୟବହାର କରେ। ମୂଲ୍ୟଟି ସିଧାସଳଖ CLI ପ୍ରମ୍ପ୍ଟରେ ପ୍ରବେଶ କରାଯାଏ; ଏହାକୁ ପ୍ରକ୍ରିୟା ଆର୍ଗୁମେଣ୍ଟ ଭାବେ ପଠାଯାଏ ନାହିଁ, Git ରେ ଲେଖାଯାଏ ନାହିଁ କିମ୍ବା ହୋଷ୍ଟରୁ କପି କରାଯାଏ ନାହିଁ।

ପୃଥକ Claude Code ରନ୍ଟାଇମ୍ ଆରମ୍ଭ କରନ୍ତୁ:

```bash
./scripts/devin-bridge/launch
```

କଣ୍ଟେନର୍ଭିତ୍ତିକ Claude Code ଆରମ୍ଭ କରିବା ପୂର୍ବରୁ `launch` ପୃଥକୀକରଣ, Devin ପ୍ରମାଣୀକରଣ ଏବଂ ମଡେଲ୍ ଆବିଷ୍କାରକୁ ପୁନଃ ଯାଞ୍ଚ କରେ। ଏହା କେବେବି ହୋଷ୍ଟର Claude ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ଚଲାଏ ନାହିଁ। ମଡେଲ୍ ଉପନାମଗୁଡ଼ିକୁ `.env.devin-bridge` ରେ ସେଟ୍ କରାଯାଇପାରେ; ବିନ୍ୟାସ କରାଯାଇଥିବା ପ୍ରତ୍ୟେକ ମୂଲ୍ୟରେ `devin-cli-agentic/` ପ୍ରିଫିକ୍ସ ରହିବା ଆବଶ୍ୟକ।

## ବୈଧତା ଯାଞ୍ଚ କମାଣ୍ଡଗୁଡ଼ିକ

ପୁନରୁତ୍ପାଦନଯୋଗ୍ୟ ଅଫ୍ଲାଇନ୍ ପଥ ପାଇଁ କୌଣସି Devin ଆକାଉଣ୍ଟ ଆବଶ୍ୟକ ନାହିଁ ଏବଂ ଏଥିରେ ରନ୍ଟାଇମ୍ ଇଣ୍ଟରନେଟ୍ ନାହିଁ:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

ପ୍ରମାଣୀକୃତ ଇଚ୍ଛାଧୀନ ଲାଇଭ୍ ପଥ ହେଉଛି:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

ଏକାଥରେ ବହୁ ACP ସେସନ୍ ଖୋଲିବାକୁ ଏଡ଼ାଇବା ପାଇଁ ଲାଇଭ୍ ରନର୍ ପରିଦୃଶ୍ୟଗୁଡ଼ିକ ମଧ୍ୟରେ ଅପେକ୍ଷା କରେ ଏବଂ ପାଠ୍ୟ ଦାବିଗୁଡ଼ିକୁ ବିଶ୍ୱାସ କରିବା ପରିବର୍ତ୍ତେ ଗଠିତ Claude ଷ୍ଟ୍ରିମ୍ ଇଭେଣ୍ଟଗୁଡ଼ିକୁ ବୈଧ କରେ। ଏହାର ତିନୋଟି ପରିଦୃଶ୍ୟ ନିମ୍ନଲିଖିତ ବିଷୟ ପ୍ରମାଣ କରେ:

1. ସିଧାସଳଖ ପ୍ରକଳ୍ପ ପଠନ ଏବଂ ତ୍ରୁଟି ବିଶ୍ଳେଷଣ;
2. ଏକ ପ୍ରକୃତ `Edit`, କ୍ଲାଏଣ୍ଟ-ମାଲିକାନାଧୀନ `Bash` `npm test`, ଏବଂ ଏକ ଟର୍ମିନାଲ୍ ଫଳାଫଳ;
3. `/bridge-check` ସହିତ `bridge-proof` ଆବିଷ୍କାର, ପ୍ରକଳ୍ପ ପଠନ, ଆଉ ଏକ ସଫଳ କ୍ଲାଏଣ୍ଟ-ମାଲିକାନାଧୀନ `npm test`, ଏବଂ କୌଣସି ବିଚାରାଧୀନ କାମ ବିନା ସମାପ୍ତି।

ଅନ୍ତିମ ଗେଟ୍ Devin ନେଟୱର୍କ ଅଡିଟ୍କୁ ମଧ୍ୟ ଯାଞ୍ଚ କରେ ଏବଂ Claude ଇଗ୍ରେସ୍ ଅଡିଟ୍ ଖାଲି ରହିବା ଆବଶ୍ୟକ କରେ।

## ପିନ୍ କରାଯାଇଥିବା ଟୁଲ୍ଗୁଡ଼ିକୁ ଅଦ୍ୟତନ କରିବା

ଇମେଜ୍ଟି `docker/devin-bridge/Dockerfile` ରେ Node, Claude Code ଏବଂ Devin CLI କୁ ପିନ୍ କରେ। ଅଦ୍ୟତନ କରିବା ପାଇଁ:

1. ସ୍ପଷ୍ଟ ଭାବେ ଉଲ୍ଲେଖିତ ସଂସ୍କରଣଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ କରନ୍ତୁ;
2. ଉଭୟ ଆର୍କିଟେକ୍ଚର୍-ନିର୍ଦ୍ଦିଷ୍ଟ Devin ଆର୍କାଇଭ୍ ଚେକ୍ସମ୍କୁ ଅଧିକୃତ ଆର୍ଟିଫ୍ୟାକ୍ଟର ମୂଲ୍ୟ ସହିତ ବଦଳାନ୍ତୁ;
3. ପୁନଃ ବିଲ୍ଡ କରନ୍ତୁ ଏବଂ ପ୍ରତ୍ୟେକ ଅଫ୍ଲାଇନ୍ ବୈଧତା ଯାଞ୍ଚ କମାଣ୍ଡ ଚଲାନ୍ତୁ;
4. ଇମେଜ୍ ଭିତରେ ସଂସ୍କରଣଗୁଡ଼ିକୁ ନିଶ୍ଚିତ କରନ୍ତୁ;
5. ପ୍ରମାଣୀକୃତ ତିନି-ପରିଦୃଶ୍ୟ ବିଶିଷ୍ଟ ଲାଇଭ୍ ସୁଇଟ୍କୁ ପୁନଃ ଚଲାନ୍ତୁ।

ହୋଷ୍ଟରେ କୌଣସି CLI କୁ ଗ୍ଲୋବାଲ୍ ଭାବେ ଇନ୍ଷ୍ଟଲ୍ କରନ୍ତୁ ନାହିଁ କିମ୍ବା ଚେକ୍ସମ୍ ଯାଞ୍ଚକୁ ଏକ ଅଯାଞ୍ଚିତ ଡାଉନଲୋଡ୍ ସହିତ ବଦଳାନ୍ତୁ ନାହିଁ।

- `.sandbox/evidence/egress.jsonl` ଏବଂ `.sandbox/evidence/claude-egress.jsonl` ହେଉଛି ଗାର୍ଡ ଅଡିଟ୍ର ବୈଧ କରାଯାଇଥିବା, ଟୋକନ୍-ମୁକ୍ତ କପି।

