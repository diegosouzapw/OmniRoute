## ଉଚ୍ଚ-ସ୍ତରୀୟ ନାଭିଗେସନ୍

ଗ୍ରୁପ୍ B ପରେ ଡ୍ୟାସ୍ବୋର୍ଡ ସାଇଡ୍ବାର୍ରେ ନିମ୍ନଲିଖିତ ଶୀର୍ଷ-ସ୍ତରୀୟ ବିଭାଗଗୁଡ଼ିକ ଏହି କ୍ରମରେ ରହିଛି:

```
ହୋମ୍
ପ୍ରଦାନକାରୀ
କମ୍ବୋ
API କୀ
ସେଟିଂସ୍
ଆନାଲିଟିକ୍ସ
ଖର୍ଚ୍ଚ          ← ନୂଆ (ଗ୍ରୁପ୍ B, ଯୋଜନା 16)
ମନିଟରିଂ        ← ପୁନଃସଂଗଠିତ (ଗ୍ରୁପ୍ B, ଯୋଜନା 16)
...
```

## ଖର୍ଚ୍ଚ ବିଭାଗ (ନୂଆ, ସ୍ତର 1)

ପଥ ଉପସର୍ଗ: `/dashboard/costs/`

| ଆଇଟମ୍            | URL                                  | ବର୍ଣ୍ଣନା                                               |
| ---------------- | ------------------------------------ | ------------------------------------------------------ |
| ସାରାଂଶ           | `/dashboard/costs`                   | ସମନ୍ୱିତ ଖର୍ଚ୍ଚ ଡ୍ୟାସ୍ବୋର୍ଡ (ଆନାଲିଟିକ୍ସରୁ ସ୍ଥାନାନ୍ତରିତ) |
| ମୂଲ୍ୟ ନିର୍ଦ୍ଧାରଣ | `/dashboard/costs/pricing`           | ପ୍ରତି-ମଡେଲ୍ ମୂଲ୍ୟ ନିର୍ଦ୍ଧାରଣ ସାରଣୀ                     |
| ବଜେଟ୍            | `/dashboard/costs/budget`            | ବଜେଟ୍ ସୀମା + ସତର୍କତା                                   |
| କୋଟା ସେୟାରିଂ     | `/dashboard/costs/quota-share`       | କୋଟା ସେୟାର୍ ପୁଲ୍ + ବ୍ୟବହାର                             |

**ଯୁକ୍ତି**: ମୂଲ୍ୟ ନିର୍ଦ୍ଧାରଣ, ବଜେଟ୍ ଏବଂ କୋଟା ସେୟାରିଂ ପୂର୍ବରୁ
`ମନିଟରିଂ > ଖର୍ଚ୍ଚ ପାରାମିଟର୍` ଅଧୀନରେ ଥିଲା। ସେଗୁଡ଼ିକୁ ଏକ ସ୍ୱତନ୍ତ୍ର ଶୀର୍ଷ-ସ୍ତରୀୟ ବିଭାଗକୁ
ସ୍ଥାନାନ୍ତର କରିବା ଫଳରେ ପର୍ଯ୍ୟବେକ୍ଷଣ ଟୁଲିଂ ମଧ୍ୟଦେଇ ନାଭିଗେଟ୍ ନ କରି ସେଗୁଡ଼ିକୁ ଖୋଜିହେବ।

## ମନିଟରିଂ ବିଭାଗ (ପୁନଃସଂଗଠିତ)

ମନିଟରିଂ ବିଭାଗରେ ଏବେ **ଶୀର୍ଷରେ କାର୍ଯ୍ୟକଳାପ** ଏବଂ ତାହା ପରେ **3ଟି ଉପଗୋଷ୍ଠୀ** ରହିଛି:

```
ମନିଟରିଂ
├── କାର୍ଯ୍ୟକଳାପ             ← ଟାଇମ୍ଲାଇନ୍ ଫିଡ୍ (ଶୀର୍ଷ-ସ୍ତରୀୟ ଆଇଟମ୍)
├── ଲଗ୍ ଗୋଷ୍ଠୀ
│   ├── ଲଗ୍ (ସମସ୍ତ)
│   ├── ପ୍ରକ୍ସି ଲଗ୍
│   └── କନ୍ସୋଲ୍ ଲଗ୍
├── ଅଡିଟ୍ ଗୋଷ୍ଠୀ
│   ├── ଅଡିଟ୍ ଲଗ୍
│   ├── MCP ଅଡିଟ୍
│   └── A2A ଅଡିଟ୍
└── ସିଷ୍ଟମ୍ ଗୋଷ୍ଠୀ
    ├── ସ୍ୱାସ୍ଥ୍ୟ
    └── ରନ୍ଟାଇମ୍
```

### ଉଚ୍ଚ-ସ୍ତରୀୟ କାର୍ଯ୍ୟଗୁଡ଼ିକର ଅନୁମୋଦିତ ତାଲିକା

`src/lib/audit/highLevelActions.ts`ରେ ପରିଭାଷିତ। କାର୍ଯ୍ୟକଳାପ ଫିଡ୍ରେ କେଉଁ ଇଭେଣ୍ଟଗୁଡ଼ିକ
ଦେଖାଯିବ, ତାହା ନିୟନ୍ତ୍ରଣ କରେ। ଅନୁମୋଦିତ ତାଲିକାରେ ଏଗୁଡ଼ିକ ଅନ୍ତର୍ଭୁକ୍ତ:

- ପ୍ରଦାନକାରୀ ଯୋଡ଼ିବା/ଅପସାରଣ/ପରୀକ୍ଷା ଇଭେଣ୍ଟ
- କମ୍ବୋ ସୃଷ୍ଟି/ଅଦ୍ୟତନ/ବିଲୋପ
- API କୀ ଜୀବନଚକ୍ର (ସୃଷ୍ଟି, ପ୍ରତ୍ୟାହାର, ରୋଟେଟ୍)
- ବଜେଟ୍ ସୀମାରେ ପହଞ୍ଚିବା
- ପ୍ରମାଣୀକରଣ ଲଗ୍ଇନ୍/ଲଗ୍ଆଉଟ୍
- କ୍ଲାଉଡ୍ ଏଜେଣ୍ଟ ସେସନ୍ ସୃଷ୍ଟି
- MCP ଟୁଲ୍ ପଞ୍ଜୀକରଣ
- ୱେବ୍ହୁକ୍ ସୃଷ୍ଟି/ବିଲୋପ
- କୋଟା ପୁଲ୍/ଯୋଜନା ପରିବର୍ତ୍ତନ (`quota.*` କାର୍ଯ୍ୟ, ଗ୍ରୁପ୍ B)
- ପ୍ଲାଟ୍ଫର୍ମ ଇଭେଣ୍ଟ (ଅଦ୍ୟତନ, ଡିପ୍ଲୟ)
- ଦକ୍ଷତା ଇନ୍ଷ୍ଟଲ୍/ଅପସାରଣ

ଏହି ତାଲିକାରେ ନଥିବା ଇଭେଣ୍ଟଗୁଡ଼ିକ କେବଳ ଅଡିଟ୍ ଲଗ୍ରେ ଦେଖାଯାଏ।

### ଏକ ନୂଆ ଉଚ୍ଚ-ସ୍ତରୀୟ କାର୍ଯ୍ୟ ଯୋଡ଼ିବା

`src/lib/audit/highLevelActions.ts` ସମ୍ପାଦନା କରନ୍ତୁ ଏବଂ କାର୍ଯ୍ୟ ଷ୍ଟ୍ରିଙ୍ଗ୍କୁ
`HIGH_LEVEL_ACTIONS`ରେ ଯୋଡ଼ନ୍ତୁ। ଏଥିପାଇଁ ଏକ PR ଆବଶ୍ୟକ (ତାଲିକାଟି କୋଡ୍, DB ମାଧ୍ୟମରେ ବିନ୍ୟାସଯୋଗ୍ୟ ନୁହେଁ)।
ସମ୍ପର୍କିତ ଆଇକନ୍କୁ `src/lib/audit/activityIcons.ts`ରେ ଯୋଡ଼ାଯାଇପାରିବ।
