## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — ଟ୍ରି ବାହାରେ

- **`_tasks/`** — ପ୍ରତି-ରିଲିଜ୍ କାର୍ଯ୍ୟ ଟ୍ରାକିଂ ଫାଇଲ୍ (ଅନୌପଚାରିକ)
