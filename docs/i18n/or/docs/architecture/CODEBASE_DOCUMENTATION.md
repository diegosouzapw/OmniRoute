### 3.1 `src/app/` — ଆପ୍ ରୁଟର

ଆପ୍ ରୁଟର ଡ୍ୟାସବୋର୍ଡ୍ UI ଏବଂ ସାର୍ବଜନୀନ/ପରିଚାଳନା HTTP API ଦୁଇଟି ଉପସ୍ଥାପିତ କରେ।
**କୌଣସି ଗ୍ଲୋବାଲ୍ ମିଡୱେୟାର୍ ନାହିଁ** — ଇଣ୍ଟରସେପସନ୍ ପ୍ରତ୍ୟେକ ରୁଟ୍ରେ କରାଯାଏ।

`src/app/` ଅଧୀନରେ ଥିବା ଟପ୍-ଲେଭଲ୍ ସେଗମେଣ୍ଟ୍:

| ପାଥ                                                                           | ଉଦ୍ଦେଶ୍ୟ                                             |
| ----------------------------------------------------------------------------- | ---------------------------------------------------- |
| `api/`                                                                        | ସମସ୍ତ HTTP API ରୁଟ୍ (ନିମ୍ନରେ ବିଭାଜନ ଦେଖନ୍ତୁ)         |

  ପସନ୍ଦ କରନ୍ତୁ।
- **ଡାଟାବେସ୍**: ରୁଟ ବା ହ୍ୟାଣ୍ଡଲରରେ କେବେ ହେଲେ କଞ୍ଚା SQL ଲେଖନ୍ତୁ ନାହିଁ — ସର୍ବଦା
  `src/lib/db/` ମଡ୍ୟୁଲ ମାଧ୍ୟମରେ ଯାଆନ୍ତୁ। କେବେ ହେଲେ ବ୍ୟାରେଲ-ଆମଦାନୀ ନ କରନ୍ତୁ — ସିଧାସଳଖ ନିର୍ଦ୍ଦିଷ୍ଟ `src/lib/db/*` ମଡ୍ୟୁଲ ବ୍ୟବହାର କରନ୍ତୁ।
- **DB-entity ପ୍ରକାର (#3512)**: ଏକ ଡାଟାବେସ୍ ଟେବୁଲର ଧାରା ଆକୃତି ଲେଖୁ ବା ପଢ଼ୁଥିବା ଫଙ୍କସନ
  ସେହି ଟେବୁଲର ସ୍ତମ୍ଭ 1:1 ପ୍ରତିବିମ୍ବିତ କରୁଥିବା ଏକ ନାମିତ TS ଇଣ୍ଟରଫେସ୍ ନେବା/ଫେରାଇବା ଉଚିତ୍, `any` ବା କଲ-ସାଇଟରେ ଏକ ଇନଲାଇନ ବେନାମୀ ପ୍ରକାର ନୁହେଁ।
  ଫଙ୍କସନ ପାଖରେ ଇଣ୍ଟରଫେସ୍ ଅବସ୍ଥାପିତ କରନ୍ତୁ (ଯେପରି `src/lib/usage/usageHistory.ts` ରେ `saveRequestUsage` ଉପରେ `export interface UsageEntry`), ବିଭିନ୍ନ ଲେଖକ ଧାରାକୁ କ୍ରମିକ ଭାବେ ପୂରଣ କଲେ ବ୍ୟକ୍ତିଗତ କ୍ଷେତ୍ରଗୁଡ଼ିକୁ ବିକଳ୍ପ/ଶୂନ୍ୟ ରଖନ୍ତୁ,
  ଏବଂ କଲରମାନଙ୍କ ମଧ୍ୟରେ ଆକୃତି ଭିନ୍ନ ଥିବା କ୍ଷେତ୍ର ପାଇଁ `unknown` କୁ `any` ଅପେକ୍ଷା ପସନ୍ଦ କରନ୍ତୁ (କ୍ଷେତ୍ର ଉପରେ ଡକୁମେଣ୍ଟ କରାଯାଇଛି, ଯେପରି `UsageEntry.tokens` ଉଭୟ କଞ୍ଚା ପ୍ରଦାତା-ଆକୃତି ବ୍ୟବହାର ଏବଂ ସାମାନ୍ୟୀକୃତ ଆକୃତି ଗ୍ରହଣ କରେ)। ଏକ ଫାଇଲର `any` ଗଣନା ଏହି ପ୍ରକାରେ ଶୂନ୍ୟ ସ୍ପର୍ଶ କଲେ,
  ଏହାକୁ `check:any-budget:t11` ଅନୁମତି ତାଲିକା (`scripts/check/check-t11-any-budget.mjs`,
  `maxAny: 0`) ରେ ଯୋଗ କରନ୍ତୁ ଯାହାଦ୍ୱାରା ଏହା ପଛକୁ ଯାଇ ନ ପାରେ। ଏହା ଏକ ପ୍ରଥମ-ଖଣ୍ଡ ସମ୍ମେଳନ —
  ବ୍ୟାପକ "ବେନାମୀ `any` ନାହିଁ" ସଫା ବାକି କୋଡ୍ବେସରେ ପୁନରାବୃତ୍ତି ଅଟେ।
- **ତ୍ରୁଟି**: ନିର୍ଦ୍ଦିଷ୍ଟ ତ୍ରୁଟି ପ୍ରକାର ସହିତ try/catch, piro ସାନ୍ଦର୍ଭ ସହିତ ଲଗ୍ କରନ୍ତୁ। କେବେ ହେଲେ
  SSE ଷ୍ଟ୍ରିମରେ ଚୁପ୍ ହୋଇ ତ୍ରୁଟି ନ ଗିଳନ୍ତୁ; ସଫା ପାଇଁ ଅବରଟ ସିଗ୍ନାଲ ବ୍ୟବହାର କରନ୍ତୁ।
- **ସୁରକ୍ଷା**: କେବେ ହେଲେ `eval()` / `new Function()` / ଅନୁବିନ୍ଧିତ eval ବ୍ୟବହାର ନ କରନ୍ତୁ। ସମସ୍ତ
  ଇନପୁଟ୍ Zod ସହିତ ଯାଞ୍ଚ କରନ୍ତୁ। ସ୍ଥିର ସମୟରେ ପ୍ରମାଣ ସାଖି (AES-256-GCM) ଏନ୍କ୍ରିପ୍ଟ କରନ୍ତୁ।
  `src/shared/constants/upstreamHeaders.ts` ଅସ୍ୱୀକୃତ ତାଲିକାକୁ ସେନିଟାଇଜ/ଯାଞ୍ଚ ସ୍ତର ସହିତ ସମାନ ରଖନ୍ତୁ।
- **କମିଟ**: Conventional Commits — `feat(scope): subject`। ଅନୁମୋଦିତ ପରିସର:
