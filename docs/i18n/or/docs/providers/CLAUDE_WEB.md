## `claude-web`

`claude-web` ଏକ ପ୍ରମାଣୀକୃତ `claude.ai` ବ୍ରାଉଜର ସେସନ୍ ମାଧ୍ୟମରେ OpenAI-ଫର୍ମାଟ୍ ଚାଟ୍ ଅନୁରୋଧ ପଠାଏ। ଏକ୍ସିକ୍ୟୁଟର୍ ଯୋଗାଇ ଦିଆଯାଇଥିବା କୁକିକୁ ସାମାନ୍ୟୀକୃତ କରେ, ଗୋଟିଏ ପ୍ରମାଣୀକୃତ ସଂଗଠନ ନିର୍ଦ୍ଧାରଣ କରେ, ବାର୍ତ୍ତାଳାପ ସ୍ଥିତି ପ୍ରସ୍ତୁତ କରେ, ଏକ ପ୍ରତ୍ୟକ୍ଷ କିମ୍ବା ବ୍ରାଉଜର ପରିବହନ ଚୟନ କରେ, ଏବଂ ଅପଷ୍ଟ୍ରିମ୍ SSE ପ୍ରତିକ୍ରିୟାକୁ କଠୋର ଭାବେ ରୂପାନ୍ତର କରେ। ଅର୍କେଷ୍ଟ୍ରେସନ୍ଟି `open-sse/executors/claude-web.ts:320`ରେ ଅଛି।

> **Web Cookie ପ୍ରଦାନକାରୀଙ୍କ ପାଇଁ ନୂଆ?**
>
> ଏହି ପ୍ରଦାନକାରୀ-ନିର୍ଦ୍ଦିଷ୍ଟ ଗାଇଡ୍ ଅନୁସରଣ କରିବା ପୂର୍ବରୁ ସାଧାରଣ ସେଟଅପ୍ ପ୍ରକ୍ରିୟା, ପ୍ରମାଣୀକରଣ ମାର୍ଗଦର୍ଶନ, ସୀମାବଦ୍ଧତା ଏବଂ ସମସ୍ୟା ସମାଧାନ ପାଇଁ **`docs/getting-started/WEB-COOKIE-GUIDE.md`** ପଢ଼ନ୍ତୁ।

ପ୍ରଦାନକାରୀ ରେଜିଷ୍ଟ୍ରି ବର୍ତ୍ତମାନ ଠିକ୍ ଏହି ସାତଟି ସ୍ଥିର ମଡେଲ୍ ID ପ୍ରକାଶ କରେ (`open-sse/config/providers/registry/claude/web/index.ts:11`):

ଏହି ପ୍ରଦାନକାରୀ ପାଇଁ ଡାଇନାମିକ୍ ମଡେଲ୍ ଆବିଷ୍କାର କାର୍ଯ୍ୟକାରୀ କରାଯାଇନାହିଁ। ଉପରୋକ୍ତ ତାଲିକାଟି ହେଉଛି ରନ୍ଟାଇମ୍ କ୍ୟାଟାଲଗ୍।

### ପରିଚୟପତ୍ର ଏବଂ ସଂଗଠନ ନିର୍ଦ୍ଧାରଣ

ସମ୍ପୂର୍ଣ୍ଣ `claude.ai` Cookie ହେଡର୍ କିମ୍ବା କେବଳ ଏକ ସେସନ୍ ମୂଲ୍ୟ ଯୋଗାନ୍ତୁ। କେବଳ ମୂଲ୍ୟ ଦିଆଗଲେ ତାହାକୁ `sessionKey`ରେ ସାମାନ୍ୟୀକୃତ କରାଯାଏ; ଯୋଗାଇ ଦିଆଯାଇଥିଲେ ଅନ୍ୟ କୁକିଗୁଡ଼ିକୁ ସଂରକ୍ଷିତ ରଖାଯାଏ। ଏକ୍ସିକ୍ୟୁଟର୍ `cookie` କିମ୍ବା `apiKey` ମାଧ୍ୟମରେ କୁକି ଗ୍ରହଣ କରେ ଏବଂ ସଂଯୋଗ ଡାଟାରୁ ଇଚ୍ଛାଧୀନ `deviceId` ଏବଂ `orgId` ମୂଲ୍ୟଗୁଡ଼ିକ ପଢ଼େ (`open-sse/executors/claude-web.ts:72`)।

ଯଦି `orgId` ଅନୁପସ୍ଥିତ ଥାଏ, ଏକ୍ସିକ୍ୟୁଟର୍ `GET https://claude.ai/api/organizations`କୁ କଲ୍ କରେ ଏବଂ ପ୍ରମାଣୀକୃତ Claude Web ସେସନ୍ ଦ୍ୱାରା ଫେରସ୍ତ ହୋଇଥିବା ପ୍ରଥମ ସଂଗଠନକୁ ବ୍ୟବହାର କରେ (`open-sse/executors/claude-web.ts:141`)। କୌଣସି ବୈଧ ସଂଗଠନ ଫେରସ୍ତ ନହେଲେ ଏହା ସୁରକ୍ଷିତ ଭାବେ ବିଫଳ ହୁଏ, ପ୍ରତ୍ୟାଖ୍ୟାତ ସେସନ୍ ପ୍ରାଧିକରଣକୁ 401 ଭାବେ ରିପୋର୍ଟ କରେ, ଏବଂ ଏକ Cloudflare ଚ୍ୟାଲେଞ୍ଜକୁ ପ୍ରମାଣୀକରଣ ବିଫଳତାରୁ ପୃଥକ କରେ।

### ବାର୍ତ୍ତାଳାପ କାର୍ଯ୍ୟଗୁଡ଼ିକ

ଇଚ୍ଛାଧୀନ ଶୀର୍ଷ-ସ୍ତରୀୟ `claude_web` ଅବଜେକ୍ଟ କଠୋର ଅଟେ। ଅଜଣା ଫିଲ୍ଡଗୁଡ଼ିକୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ। ଏହାର ଗ୍ରହଣୀୟ ଫିଲ୍ଡଗୁଡ଼ିକ `open-sse/executors/claude-web/session.ts:50`ରେ ପରିଭାଷିତ:

| ଫିଲ୍ଡ                 | ଅର୍ଥ                                                                   |
| --------------------- | ---------------------------------------------------------------------- |
| `operation`           | ଡିଫଲ୍ଟ ଭାବେ `completion`; ପୁନଃଚେଷ୍ଟା ଟର୍ନ୍ ପାଇଁ `retry` ବ୍ୟବହାର କରନ୍ତୁ |
| `conversation_id`     | ଏକ ବିଦ୍ୟମାନ ବାର୍ତ୍ତାଳାପ ପାଇଁ ସ୍ପଷ୍ଟ UUID                               |
| `parent_message_uuid` | ପ୍ୟାରେଣ୍ଟ ସହାୟକ ବାର୍ତ୍ତା ପାଇଁ ସ୍ପଷ୍ଟ UUID                              |
| `timezone`            | ବୈଧ IANA ସମୟ-ମଣ୍ଡଳ ନାମ                                                 |
| `locale`              | ଗଠନାତ୍ମକ ଭାବେ ବୈଧ ଲୋକେଲ୍                                               |
| `tool_states`         | ଇଚ୍ଛାଧୀନ ଆକାଉଣ୍ଟ ଟୁଲ୍-ସ୍ଥିତି ଆରେ, 128ଟି ଏଣ୍ଟ୍ରି ମଧ୍ୟରେ ସୀମିତ           |

ପ୍ରସ୍ତୁତ ଅନୁରୋଧଗୁଡ଼ିକ ଦୁଇଟି ଅପଷ୍ଟ୍ରିମ୍ ଏଣ୍ଡପଏଣ୍ଟ ମଧ୍ୟରୁ ଗୋଟିଏ ବ୍ୟବହାର କରେ (`open-sse/executors/claude-web.ts:203`):

- ଏକ ନୂଆ କିମ୍ବା ଫଲୋ-ଅପ୍ ଟର୍ନ୍
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/completion`କୁ ପୋଷ୍ଟ କରେ।
- ଏକ ପୁନଃଚେଷ୍ଟା
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion`କୁ ପୋଷ୍ଟ କରେ।

ଏକ ନୂଆ ଟର୍ନ୍ରେ `create_conversation_params` ଅନ୍ତର୍ଭୁକ୍ତ ଥାଏ। ଏକ କ୍ୟାଶ୍କୃତ କିମ୍ବା ସ୍ପଷ୍ଟ ଭାବେ ଲିଙ୍କ୍ ହୋଇଥିବା ଫଲୋ-ଅପ୍ରେ `parent_message_uuid` ଅନ୍ତର୍ଭୁକ୍ତ ହୁଏ ଏବଂ `create_conversation_params` ବାଦ୍ ଦିଆଯାଏ। ପୁନଃଚେଷ୍ଟା ପାଇଁ ବାର୍ତ୍ତାଳାପ ଏବଂ ପ୍ୟାରେଣ୍ଟ-ବାର୍ତ୍ତା ସ୍ଥିତି ଉଭୟ ଆବଶ୍ୟକ ଏବଂ ଏହା କୌଣସି ପ୍ରମ୍ପ୍ଟ ପଠାଏ ନାହିଁ (`open-sse/executors/claude-web/session.ts:254`)। ନୂଆ ବାର୍ତ୍ତାଳାପଗୁଡ଼ିକ ପ୍ରମାଣୀକୃତ UIକୁ `/new`ରେ ଖୋଲେ; କ୍ୟାଶ୍କୃତ କିମ୍ବା ସ୍ପଷ୍ଟ ଭାବେ ଲିଙ୍କ୍ ହୋଇଥିବା ଫଲୋ-ଅପ୍ଗୁଡ଼ିକ ସଠିକ୍ ବାର୍ତ୍ତାଳାପ ପୃଷ୍ଠା ଖୋଲେ (`open-sse/executors/claude-web/session.ts:324`)।

ବାର୍ତ୍ତାଳାପ ସ୍ଥିତି ହେଉଛି SHA-256 ଆକାଉଣ୍ଟ ସ୍କୋପ୍ ଏବଂ କ୍ୟାନୋନିକାଲ୍ କଲର୍ ଟ୍ରାନ୍ସକ୍ରିପ୍ଟ ଦ୍ୱାରା କୀକୃତ ଏକ ଇନ୍-ମେମୋରି କ୍ୟାଶ୍। ଏଣ୍ଟ୍ରିଗୁଡ଼ିକ 30 ମିନିଟ୍ ପରେ ମିଆଦ ଶେଷ ହୁଏ ଏବଂ କ୍ୟାଶ୍ଟି 5,000 ଏଣ୍ଟ୍ରିରେ ସୀମିତ (`open-sse/executors/claude-web/session.ts:12`)। କଠୋର ଷ୍ଟ୍ରିମ୍ ପାର୍ସର୍ `message_stop` ଦେଖିବା ପରେ ମାତ୍ର ସ୍ଥିତି କମିଟ୍ କରାଯାଏ; ପ୍ରୋସେସ୍ ପୁନରାରମ୍ଭ ହେଲେ ଏହା ବିଲୋପ ହୁଏ। କ୍ୟାଶ୍ ମିସ୍ ହେଲେ, ପୂର୍ବ ବାର୍ତ୍ତାଗୁଡ଼ିକୁ ନିରବରେ ବାଦ୍ ଦେବା ପରିବର୍ତ୍ତେ ଏକାଧିକ-ବାର୍ତ୍ତା ଅନୁରୋଧକୁ ଗୋଟିଏ ପୁନରୁଦ୍ଧାର ପ୍ରମ୍ପ୍ଟରେ ସିରିଆଲାଇଜ୍ କରାଯାଏ।

ଲୋକେଲ୍ ଏବଂ ସମୟ ମଣ୍ଡଳ ଏହି ପ୍ରାଥମିକତା ବ୍ୟବହାର କରେ: ଅନୁରୋଧର `claude_web` ମୂଲ୍ୟ, ସଂଯୋଗ ମୂଲ୍ୟ, ରନ୍ଟାଇମ୍ ମୂଲ୍ୟ, ତା'ପରେ ଲୋକେଲ୍ ପାଇଁ `en-US` କିମ୍ବା ସମୟ ମଣ୍ଡଳ ପାଇଁ `UTC` (`open-sse/executors/claude-web/session.ts:218`)।

### ଟୁଲ୍ ଏବଂ ଅନୁରୋଧ ପେଲୋଡ୍

ପ୍ରତ୍ୟକ୍ଷ ଅନୁରୋଧଗୁଡ଼ିକ କେବଳ କଲର୍ ଦ୍ୱାରା ଯୋଗାଇ ଦିଆଯାଇଥିବା ଗଠନାତ୍ମକ ଭାବେ ବୈଧ OpenAI ଫଙ୍କସନ୍ ଟୁଲ୍ଗୁଡ଼ିକୁ ରୂପାନ୍ତର କରେ। କୌଣସି କୃତ୍ରିମ ସ୍ଥିର ଡିଫଲ୍ଟ ଟୁଲ୍ ତାଲିକା ନାହିଁ (`open-sse/executors/claude-web/payload.ts:102`)।

ଏହା ପରିବର୍ତ୍ତେ ବ୍ରାଉଜର ଅନୁରୋଧଗୁଡ଼ିକ ପ୍ରମାଣୀକୃତ UI ଅନୁରୋଧକୁ କ୍ୟାପ୍ଚର୍ କରେ ଏବଂ ତାହାର ଆକାଉଣ୍ଟ ଟୁଲ୍, ଟୁଲ୍ ସ୍ଥିତି ଓ ବ୍ୟକ୍ତିଗତକୃତ ଶୈଳୀଗୁଡ଼ିକୁ ରଖେ। ପ୍ରସ୍ତୁତ ବାର୍ତ୍ତାଳାପ, ମଡେଲ୍, ରିଜନିଂ, ପ୍ରମ୍ପ୍ଟ ଏବଂ ବାର୍ତ୍ତା UUID ଫିଲ୍ଡଗୁଡ଼ିକ ତଥାପି କ୍ୟାପ୍ଚର୍ କରାଯାଇଥିବା ଅନୁରୋଧକୁ ଓଭର୍ରାଇଡ୍ କରେ (`open-sse/executors/claude-web/browserTransport.ts:175`)। ବ୍ରାଉଜର ଟେମ୍ପ୍ଲେଟ୍ଗୁଡ଼ିକ ଆକାଉଣ୍ଟ, ସଂଗଠନ, କୁକି, ଲୋକେଲ୍ ଏବଂ ସମୟ ମଣ୍ଡଳର ଏକ ହ୍ୟାଶ୍ ଦ୍ୱାରା ସ୍କୋପ୍ କରାଯାଏ ଏବଂ 30 ମିନିଟ୍ ପରେ ମିଆଦ ଶେଷ ହୁଏ (`open-sse/executors/claude-web/browserTransport.ts:11`,
`open-sse/executors/claude-web/browserTransport.ts:158`)। ଯେତେବେଳେ ଏକ ପ୍ରତ୍ୟକ୍ଷ ଅନୁରୋଧରେ କୌଣସି କଲର୍ ଟୁଲ୍ ନଥାଏ, ଏହା ସେହି ସ୍କୋପ୍କୃତ ଟେମ୍ପ୍ଲେଟ୍କୁ ପୁନଃବ୍ୟବହାର କରିପାରେ; ସ୍ପଷ୍ଟ କଲର୍ ଟୁଲ୍ଗୁଡ଼ିକୁ ପ୍ରାଥମିକତା ମିଳେ (`open-sse/executors/claude-web/browserTransport.ts:214`)।

### ପରିବହନ ଚୟନ

ଡିଫଲ୍ଟ ପଥ ହେଉଛି `sendClaudeWebDirect()`, ଯାହା ବିନ୍ୟାସିତ Chrome 146 ପ୍ରୋଫାଇଲ୍ ଏବଂ ଯୋଗାଇ ଦିଆଯାଇଥିବା କୁକି ସହିତ `tlsFetchClaude()`କୁ କଲ୍ କରେ (`open-sse/services/claudeTlsClient.ts:23`)। ଏହା କୌଣସି ସଲ୍ଭର୍ ଲଞ୍ଚ୍ କରେ ନାହିଁ କିମ୍ବା ବିକଳ୍ପ କୁକି ତିଆରି କରେ ନାହିଁ।

ଆକାଉଣ୍ଟ-ସ୍କୋପ୍ଡ୍ ବ୍ରାଉଜର ଆଡାପ୍ଟରକୁ ପ୍ରାଥମିକ ଟ୍ରାନ୍ସପୋର୍ଟ କରିବା ପାଇଁ `WEB_COOKIE_USE_BROWSER`କୁ `1`, `true`, କିମ୍ବା `on`ରେ ସେଟ୍ କରନ୍ତୁ। ଚିହ୍ନଟ ହୋଇଥିବା Cloudflare 403 ଚ୍ୟାଲେଞ୍ଜ ସମୟରେ ସିଧାସଳଖ ଟ୍ରାନ୍ସପୋର୍ଟରୁ ବ୍ରାଉଜର ଆଡାପ୍ଟରକୁ ଫଲ୍ବ୍ୟାକ୍ କରିବାକୁ ଅନୁମତି ଦେବା ପାଇଁ `OMNIROUTE_BROWSER_POOL`କୁ ମଧ୍ୟ ସେହି ମୂଲ୍ୟଗୁଡ଼ିକ ମଧ୍ୟରୁ ଗୋଟିଏରେ ସେଟ୍ କରନ୍ତୁ (`open-sse/executors/claude-web.ts:195`)। ଅନ୍ୟ HTTP ବିଫଳତାଗୁଡ଼ିକ ସେହି ଫଲ୍ବ୍ୟାକ୍କୁ ଟ୍ରିଗର କରନ୍ତି ନାହିଁ।

ବ୍ରାଉଜର ଆଡାପ୍ଟର ସମାନ ପୁଲ୍ଡ୍ Playwright କଣ୍ଟେକ୍ସ୍ଟ ମଧ୍ୟରେ କୁକିଗୁଡ଼ିକୁ ରଖେ, ଉପରେ ବର୍ଣ୍ଣିତ ସ୍କୋପ୍ଡ୍ ହ୍ୟାଶ୍ କୀ ବ୍ୟବହାର କରେ ଏବଂ ସେହି କଣ୍ଟେକ୍ସ୍ଟରୁ କମ୍ପ୍ଲିସନ୍ ପଠାଏ (`open-sse/executors/claude-web/browserTransport.ts:444`)। ଏହା କେବେ ମଧ୍ୟ ବ୍ରାଉଜର ଦ୍ୱାରା ସମାଧାନ ହୋଇଥିବା କୁକିକୁ ସିଧାସଳଖ TLS କ୍ଲାଏଣ୍ଟକୁ ଏକ୍ସପୋର୍ଟ କରେ ନାହିଁ। ବ୍ରାଉଜର ପୁନଃପ୍ରୟାସ ପାଇଁ ସମାନ ବାସ୍ତବ Playwright କଣ୍ଟେକ୍ସ୍ଟ ସହ ବନ୍ଧା ହୋଇଥିବା ଏକ ଅବଧି ସମାପ୍ତ ହୋଇନଥିବା UI ଟେମ୍ପଲେଟ୍ ଆବଶ୍ୟକ (`open-sse/executors/claude-web/browserTransport.ts:467`)। ବ୍ରାଉଜର ରେସ୍ପନ୍ସ ପଠନଗୁଡ଼ିକ ପ୍ରମାଣିତ ପୃଷ୍ଠାରେ କ୍ରମବର୍ଦ୍ଧିଷ୍ଣୁ ଭାବରେ ଚାଲେ, ରିକ୍ୱେଷ୍ଟ ବାତିଲକୁ ସମ୍ମାନ କରେ ଏବଂ ଅପ୍ଷ୍ଟ୍ରିମ୍ ବଡି 16 MiB ଅତିକ୍ରମ କରିବା ମାତ୍ରେ ତାହାକୁ ବାତିଲ କରେ (`open-sse/executors/claude-web/browserTransport.ts:259`)।

ଏକ୍ସିକ୍ୟୁଟର ସେୟାର୍ଡ୍ ରିକ୍ୱେଷ୍ଟ ଲଗର୍କୁ ଏକ ସମ୍ପାଦିତ ଅଡିଟ୍ ପ୍ରୋଜେକ୍ସନ୍ ଫେରାଏ: ସଂଗଠନ, କଥୋପକଥନ ଏବଂ ମେସେଜ୍ UUID, ପ୍ରମ୍ପ୍ଟ ଟେକ୍ସ୍ଟ, ଟୁଲ୍ ସଂଜ୍ଞା, କୁକି ଏବଂ ଡିଭାଇସ୍ ପରିଚୟକଗୁଡ଼ିକୁ ବାଦ ଦିଆଯାଏ (`open-sse/executors/claude-web.ts:237`,
`open-sse/executors/claude-web.ts:252`)। ଟ୍ରାନ୍ସପୋର୍ଟ ଏକ୍ସେପ୍ସନ୍ଗୁଡ଼ିକ ମଧ୍ୟ ଥ୍ରୋ ହୋଇଥିବା ମେସେଜ୍ ପରିବର୍ତ୍ତେ ଏକ ସାଧାରଣ କନେକ୍ସନ୍ ତ୍ରୁଟି ଫେରାନ୍ତି।

### SSE ଆଚରଣ

`createClaudeWebResponse()` LF କିମ୍ବା CRLF ଫ୍ରେମିଂ ଏବଂ ଏକାଧିକ ଲାଇନ୍ର `data:` ଫିଲ୍ଡଗୁଡ଼ିକୁ ପରିଚାଳନା କରେ। ଏହା ଟେକ୍ସ୍ଟ ଡେଲ୍ଟାଗୁଡ଼ିକୁ `content`କୁ, ଥିଙ୍କିଂ ଡେଲ୍ଟାଗୁଡ଼ିକୁ `reasoning_content`କୁ ଏବଂ ଜଣାଶୁଣା ମେଟାଡାଟା ଇଭେଣ୍ଟଗୁଡ଼ିକୁ `claude_web` ରେସ୍ପନ୍ସ ଏକ୍ସଟେନ୍ସନ୍କୁ ମ୍ୟାପ୍ କରେ। ପ୍ରତ୍ୟେକ ମେଟାଡାଟା ଇଭେଣ୍ଟକୁ ତାହାର ନିଜସ୍ୱ ଫିଲ୍ଡ ଅନୁମୋଦିତ-ତାଲିକା ମାଧ୍ୟମରେ ପ୍ରୋଜେକ୍ଟ କରାଯାଏ (`open-sse/executors/claude-web/stream.ts:37`)। କଥୋପକଥନ, ପ୍ୟାରେଣ୍ଟ-ମେସେଜ୍, ଆସିଷ୍ଟାଣ୍ଟ-ମେସେଜ୍ ଏବଂ ଅପରେସନ୍ ମେଟାଡାଟାକୁ ମଧ୍ୟ `X-OmniRoute-Claude-Web-*` ହେଡର୍ଗୁଡ଼ିକରେ ଫେରାଯାଏ (`open-sse/executors/claude-web/stream.ts:364`)।

ବିକୃତ JSON, ଅପ୍ଷ୍ଟ୍ରିମ୍ `error` ଇଭେଣ୍ଟ, ଅଜଣା ଇଭେଣ୍ଟ ପ୍ରକାର, ଅବୈଧ କ୍ରମ, କଣ୍ଟେଣ୍ଟ-ବ୍ଲକ୍ ଅମେଳ କିମ୍ବା `message_stop` ପୂର୍ବରୁ EOF ମିଳିଲେ ପାର୍ସର ବନ୍ଦ ହୋଇ ବିଫଳ ହୁଏ। ଷ୍ଟ୍ରିମିଂ ଆଉଟ୍ପୁଟ୍ ଗୋଟିଏ ଫିନିଶ୍ ଚଙ୍କ୍ ଏବଂ ଗୋଟିଏ `[DONE]` ନିର୍ଗତ କରେ; ବଫର୍ଡ୍ ଆଉଟ୍ପୁଟ୍ ସେହି ପାର୍ସରକୁ ବ୍ୟବହାର କରେ। ପାର୍ସର `message_stop`କୁ ତୁରନ୍ତ ଟର୍ମିନାଲ୍ ଭାବେ ବିବେଚନା କରେ, ପଛରେ ଥିବା ଅପ୍ଷ୍ଟ୍ରିମ୍ ଡାଟାକୁ ବାତିଲ କରେ ଏବଂ ଡାଉନ୍ଷ୍ଟ୍ରିମ୍ ବାତିଲକୁ ଅପ୍ଷ୍ଟ୍ରିମ୍ ରିଡର୍ ପର୍ଯ୍ୟନ୍ତ ପ୍ରସାରିତ କରେ (`open-sse/executors/claude-web/stream.ts:461`,
`open-sse/executors/claude-web/stream.ts:563`)। ଅସମାପ୍ତ SSE ଲାଇନ୍ ଏବଂ ସଞ୍ଚିତ ଇଭେଣ୍ଟଗୁଡ଼ିକୁ 1 MiBରେ ସୀମିତ କରାଯାଏ (`open-sse/executors/claude-web/stream.ts:17`,
`open-sse/executors/claude-web/stream.ts:62`)।
