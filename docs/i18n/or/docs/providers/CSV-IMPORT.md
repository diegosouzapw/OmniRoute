Dashboard → Providers → **ଫାଇଲ୍ରୁ ଆମଦାନୀ କରନ୍ତୁ** ଏକ CSV କିମ୍ବା JSON ତାଲିକାରୁ API-key ସଂଯୋଗଗୁଡ଼ିକ ସୃଷ୍ଟି କରେ। ପ୍ରତ୍ୟେକ ଧାଡ଼ି ଏକ ଭିନ୍ନ ପ୍ରଦାତାକୁ ଲକ୍ଷ୍ୟ କରିପାରେ। ଆଂଶିକ ବିଫଳତା ଏହି ଚୁକ୍ତିର ଏକ ଅଂଶ: କିଛି ଧାଡ଼ି ବିଫଳ ହେଲେ ମଧ୍ୟ ବୈଧ ଧାଡ଼ିଗୁଡ଼ିକ ଆମଦାନୀ ହୁଏ, ଏବଂ ବିଫଳ ଧାଡ଼ିଗୁଡ଼ିକ କାହିଁକି ପ୍ରତ୍ୟାଖ୍ୟାନ ହେଲା ତାହା ମୋଡାଲ୍ରେ ତାଲିକାଭୁକ୍ତ ହୁଏ।

ଏହି ଆମଦାନୀ ନୂଆ OpenAI/Anthropic-ସୁସଙ୍ଗତ endpoint node ସୃଷ୍ଟି କରେ **ନାହିଁ**। ପ୍ରଥମେ ସେଗୁଡ଼ିକ ସୃଷ୍ଟି କରନ୍ତୁ (Dashboard → Providers → OpenAI-Compatible ଯୋଡ଼ନ୍ତୁ, କିମ୍ବା `omniroute nodes add`), ତା’ପରେ ଏପରି ଧାଡ଼ିଗୁଡ଼ିକ ଆମଦାନୀ କରନ୍ତୁ ଯାହାର `provider` ସ୍ତମ୍ଭରେ ସେହି nodeର id ରହିଛି। ପ୍ରତି ଧାଡ଼ିର `baseUrl` ତଥାପି nodeର URLକୁ ଅଧିଲିଖନ କରିପାରିବ।

## CSV (ଅବସ୍ଥାନଭିତ୍ତିକ)

ସ୍ତମ୍ଭ ନାମଗୁଡ଼ିକ କେବଳ ପ୍ରଦର୍ଶନ ପାଇଁ। ପାର୍ସର୍ ପ୍ରତ୍ୟେକ ଧାଡ଼ିକୁ ବିଭକ୍ତ କରେ ଏବଂ index ଅନୁସାରେ ତାହାକୁ ବିଖଣ୍ଡିତ କରେ:

| Index | Field      | Required | Notes                                                                                                                     |
| ----- | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------- |
| 0     | `provider` | ହଁ       | ବିଦ୍ୟମାନ ପରିଚାଳିତ provider id (`openai`, `anthropic`, …) **କିମ୍ବା** ପୂର୍ବରୁ ପଞ୍ଜୀକୃତ OpenAI/Anthropic-ସୁସଙ୍ଗତ **node** id |
| 1     | `name`     | ହଁ       | ସଂଯୋଗର ପ୍ରଦର୍ଶନ ନାମ                                                                                                       |
| 2     | `apiKey`   | ହଁ       | API key                                                                                                                   |
| 3     | `baseUrl`  | ନା       | ପ୍ରତି ଧାଡ଼ି URL ଅଧିଲିଖନ                                                                                                   |
| 4     | `priority` | ନା       | ପୂର୍ଣ୍ଣସଂଖ୍ୟା 1–100                                                                                                       |

ଯେଉଁ ପ୍ରଥମ ଧାଡ଼ିର ପ୍ରଥମ ସ୍ତମ୍ଭରେ ଅକ୍ଷରର case ନିର୍ବିଶେଷରେ ଆକ୍ଷରିକ ଶବ୍ଦ `provider` ରହିଛି, ତାହାକୁ header ଭାବେ ଛାଡ଼ି ଦିଆଯାଏ। ଖାଲି ଧାଡ଼ି ଏବଂ `#` ଟିପ୍ପଣୀଗୁଡ଼ିକୁ ମଧ୍ୟ ଛାଡ଼ି ଦିଆଯାଏ।

ଆମଦାନୀ ମୋଡାଲ୍ରୁ ଏକ ପ୍ରାରମ୍ଭିକ ଫାଇଲ୍ ଡାଉନଲୋଡ୍ କରନ୍ତୁ (**CSV template ଡାଉନଲୋଡ୍ କରନ୍ତୁ**)। ଉଦାହରଣ:

```csv
# OmniRoute provider ଆମଦାନୀ (ଅବସ୍ଥାନଭିତ୍ତିକ ସ୍ତମ୍ଭଗୁଡ଼ିକ)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

`openai-compatible-chat-001` ପରି ଏକ କଳ୍ପିତ id କୌଣସି node ନୁହେଁ। ସେହି ଧାଡ଼ି ପାଇଁ API `Unknown or unsupported provider` ଫେରାଏ; ମୋଡାଲ୍ରେ ଏହା ଧାଡ଼ିର ନାମ ପାଖରେ ଦେଖାଯାଏ।

## JSON

ସମାନ field (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`) ଥିବା objectଗୁଡ଼ିକର ଏକ JSON array। CSV ଠାରୁ ଭିନ୍ନ ଭାବେ, JSON keyଗୁଡ଼ିକ ନାମିତ।

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
