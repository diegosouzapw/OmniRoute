OmniRoute xarici provayderlərdən (1proxy, proxifly, iplocate, webshare)
sinxronlaşdırılan, seçilmiş pulsuz proksi toplusunu `free_proxies` cədvəlində təqdim edir.
İdarəetmə panelində bunlar **Parametrlər → Pulsuz proksilər** bölməsində göstərilir. Bu sənəd
siyahı marşrutunun təqdim etdiyi server tərəfli filtrləmə, çeşidləmə, sayma və sinxronizasiya xətalarının
hesabatını əhatə edir.

## Siyahı marşrutu — `GET /api/settings/free-proxies`

Ümumi sayla birlikdə filtrlənmiş, çeşidlənmiş və səhifələnmiş hissəni qaytarır. Filtrləmə və
sayma SQL-də həyata keçirilir, buna görə istifadəçi interfeysi bütün sətirləri yaddaşa
yükləmədən həqiqi ümumi sayı (məsələn, `Total: 0`) göstərə bilər.

### Sorğu parametrləri

| Parametr          | Növ                                | Standart  | Mənası                                                                                                                                   |
| ----------------- | ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | sətir                              | `""`      | Host (və mənbə) sütununda registrə həssas `LIKE`.                                                                                        |
| `protocol`        | sətir                              | `""`      | `type` filtri: `http` / `https` / `socks4` / `socks5`. Boş = hamısı.                                                                     |
| `country`         | sətir                              | `""`      | `countryCode` filtri (ISO-2). Boş = hamısı.                                                                                              |
| `minQuality`      | ədəd                               | `0`       | Yalnız `qualityScore >= minQuality` olan sətirlər. `0` = minimum hədd yoxdur.                                                            |
| `disabledSources` | sətir                              | `""`      | İstisna ediləcək, vergüllə ayrılmış mənbə identifikatorları (məsələn, `proxifly,webshare`).                                              |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = bal azalan sıra ilə; `latency` = gecikmə artan sıra ilə (`null` dəyərlər sonda); `recent` = `lastValidated` azalan sıra ilə. |
| `offset`          | ədəd                               | `0`       | Səhifələmənin başlanğıcı.                                                                                                                |
| `limit`           | ədəd                               | `50`      | Səhifə ölçüsü (server tərəfində məhdudlaşdırılır).                                                                                       |

### Cavab

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` səhifələmədən **əvvəlki** filtrlənmiş ümumi sayı əks etdirir, beləliklə istifadəçi interfeysi
`Total: N` və `hasMore` dəyərlərini müstəqil şəkildə göstərə bilər. `syncErrors` mənbə identifikatoruna
görə açarlanır və yalnız son sinxronizasiyası uğursuz olmuş mənbələr üçün doldurulur — `Total: 0`
nəticəsi heç vaxt izahsız qalmır.

## Tərtib edilmiş topluya əlavə etmə — `POST /api/settings/free-proxies/[id]/add-to-pool`

Pulsuz proksini idarə olunan `proxy_registry` toplusuna keçirir. Əvvəlcə yuxarı axın
mənbəyini yoxlayır; uğurlu olduqda yeni toplu proksisinin identifikatorunu və ölçülmüş gecikməni qaytarır.

## Sinxronizasiya — `POST /api/settings/free-proxies/sync`

Bütün aktiv mənbələri (və ya `{ "sources": [...] }` daxilindəki alt çoxluğu) yenidən əldə edir. Hər
mənbə müstəqil şəkildə sinxronlaşdırılır; uğursuz mənbə `syncErrors` daxilində qeydə alınır,
digərləri isə tamamlanmağa davam edir, beləliklə qismən sinxronizasiyalar əvvəlki etibarlı məlumatları heç vaxt silmir.

## Statistika — `GET /api/settings/free-proxies/stats`

Sətir faydalı yükü olmadan `total / inPool / avgQuality / bySource / lastSyncAt` aqreqatını
qaytarır — idarəetmə panelinin başlıq vidcetləri tərəfindən istifadə olunur.
