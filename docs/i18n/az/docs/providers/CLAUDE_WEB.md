## `claude-web`

`claude-web` autentifikasiya edilmiş `claude.ai` brauzer sessiyası vasitəsilə OpenAI formatlı çat sorğuları göndərir. İcraçı təqdim edilmiş cookie-ni normallaşdırır, autentifikasiya edilmiş bir təşkilatı müəyyənləşdirir, söhbət vəziyyətini hazırlayır, birbaşa və ya brauzer nəqliyyatını seçir və yuxarı axındakı SSE cavabını ciddi şəkildə çevirir. Orkestrasiya `open-sse/executors/claude-web.ts:320` faylındadır.

> **Web Cookie provayderlərindən ilk dəfə istifadə edirsiniz?**
>
> Bu provayderə xas təlimatı izləməzdən əvvəl ümumi quraşdırma prosesi, autentifikasiya üzrə göstərişlər, məhdudiyyətlər və problemlərin aradan qaldırılması üçün **`docs/getting-started/WEB-COOKIE-GUIDE.md`** sənədini oxuyun.

### Etimadnamələr və təşkilatın müəyyənləşdirilməsi

Tam `claude.ai` Cookie başlığını və ya yalnız sessiya dəyərini təqdim edin. Yalnız sessiya dəyərləri `sessionKey` kimi normallaşdırılır; təqdim edildiyi halda digər cookie-lər qorunub saxlanılır. İcraçı cookie-ni `cookie` və ya `apiKey` vasitəsilə qəbul edir və bağlantı məlumatlarından qeyri-məcburi `deviceId` və `orgId` dəyərlərini oxuyur
(`open-sse/executors/claude-web.ts:72`).

`orgId` yoxdursa, icraçı `GET https://claude.ai/api/organizations` çağırışını edir və autentifikasiya edilmiş Claude Web sessiyasının qaytardığı ilk təşkilatdan istifadə edir
(`open-sse/executors/claude-web.ts:141`). Etibarlı təşkilat qaytarılmadıqda təhlükəsiz şəkildə imtina edir, sessiya avtorizasiyasının rədd edilməsini 401 kimi bildirir və Cloudflare yoxlamasını autentifikasiya xətasından fərqləndirir.

### Söhbət əməliyyatları

Qeyri-məcburi yuxarı səviyyəli `claude_web` obyekti sərtdir. Naməlum sahələr rədd edilir. Onun qəbul etdiyi sahələr `open-sse/executors/claude-web/session.ts:50` faylında müəyyən edilib:

| Sahə                  | Mənası                                                                      |
| --------------------- | --------------------------------------------------------------------------- |
| `operation`           | Defolt olaraq `completion`; təkrar cəhd növbəsi üçün `retry` istifadə edin  |
| `conversation_id`     | Mövcud söhbət üçün açıq şəkildə göstərilən UUID                             |
| `parent_message_uuid` | Əsas assistent mesajı üçün açıq şəkildə göstərilən UUID                     |
| `timezone`            | Etibarlı IANA saat qurşağı adı                                              |
| `locale`              | Struktur baxımından etibarlı lokal                                          |
| `tool_states`         | 128 qeydlə məhdudlaşdırılmış qeyri-məcburi hesab aləti vəziyyətləri massivi |

Hazırlanmış sorğular yuxarı axının iki son nöqtəsindən birini istifadə edir
(`open-sse/executors/claude-web.ts:203`):

- Yeni və ya davam edən növbə
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/completion` ünvanına göndərilir.
- Təkrar cəhd
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion` ünvanına göndərilir.

Yeni növbəyə `create_conversation_params` daxildir. Keşlənmiş və ya açıq şəkildə əlaqələndirilmiş davam sorğusuna `parent_message_uuid` daxildir və `create_conversation_params` buraxılır. Təkrar cəhd həm söhbət, həm də əsas mesaj vəziyyətini tələb edir və heç bir prompt göndərmir
(`open-sse/executors/claude-web/session.ts:254`). Yeni söhbətlər autentifikasiya edilmiş UI-ni `/new` ünvanında açır; keşlənmiş və ya açıq şəkildə əlaqələndirilmiş davam sorğuları isə dəqiq söhbət səhifəsini açır
(`open-sse/executors/claude-web/session.ts:324`).

Söhbət vəziyyəti SHA-256 hesab əhatə dairəsi və çağıran tərəfin kanonik transkripti ilə açarlandırılan yaddaşdaxili keşdir. Qeydlərin müddəti 30 dəqiqədən sonra bitir və keş 5.000 qeydlə məhdudlaşdırılıb
(`open-sse/executors/claude-web/session.ts:12`). Vəziyyət yalnız sərt axın təhlilçisi `message_stop` müşahidə etdikdən sonra təsdiqlənir; prosesin yenidən başladılması onu silir. Keş uyğunluğu olmadıqda, çoxmesajlı sorğudakı əvvəlki mesajlar səssizcə buraxılmaq əvəzinə bir bərpa promptuna seriyalaşdırılır.

Lokal və saat qurşağı üçün bu prioritet sırası istifadə olunur: sorğudakı `claude_web` dəyəri, bağlantı dəyəri, icra mühiti dəyəri, daha sonra lokal üçün `en-US` və ya saat qurşağı üçün `UTC`
(`open-sse/executors/claude-web/session.ts:218`).

### Alətlər və sorğu faydalı yükləri

Birbaşa sorğular yalnız çağıran tərəfin təqdim etdiyi struktur baxımından etibarlı OpenAI funksiya alətlərini çevirir. Süni şəkildə yaradılmış statik defolt alət siyahısı yoxdur
(`open-sse/executors/claude-web/payload.ts:102`).

Brauzer sorğuları isə autentifikasiya edilmiş UI sorğusunu tutur və onun hesab alətlərini, alət vəziyyətlərini və fərdiləşdirilmiş üslublarını saxlayır. Hazırlanmış söhbət, model, əsaslandırma, prompt və mesaj UUID sahələri yenə də tutulan sorğunu üstələyir
(`open-sse/executors/claude-web/browserTransport.ts:175`). Brauzer şablonları hesab, təşkilat, cookie, lokal və saat qurşağının heşinə görə əhatələndirilir və müddətləri 30 dəqiqədən sonra bitir
(`open-sse/executors/claude-web/browserTransport.ts:11`,
`open-sse/executors/claude-web/browserTransport.ts:158`). Birbaşa sorğuda çağıran tərəfin alətləri olmadıqda, həmin əhatələndirilmiş şablondan yenidən istifadə edilə bilər; çağıran tərəfin açıq şəkildə göstərdiyi alətlərə üstünlük verilir
(`open-sse/executors/claude-web/browserTransport.ts:214`).

### Nəqliyyatın seçilməsi

Defolt yol konfiqurasiya edilmiş Chrome 146 profili və təqdim edilmiş cookie ilə `tlsFetchClaude()` funksiyasını çağıran `sendClaudeWebDirect()` funksiyasıdır (`open-sse/services/claudeTlsClient.ts:23`). O, solver işə salmır və əvəzedici cookie yaratmır.

Hesab əhatəli brauzer adapterini əsas nəqliyyat etmək üçün `WEB_COOKIE_USE_BROWSER` dəyişənini `1`, `true` və ya `on` olaraq təyin edin. Tanınan Cloudflare 403 çağırışında birbaşa nəqliyyatdan brauzer adapterinə ehtiyat keçidə icazə vermək üçün `OMNIROUTE_BROWSER_POOL` dəyişənini də eyni dəyərlərdən birinə təyin edin (`open-sse/executors/claude-web.ts:195`). Digər HTTP xətaları bu ehtiyat keçidi işə salmır.

Brauzer adapteri kukiləri eyni paylaşılmış Playwright kontekstində saxlayır, yuxarıda təsvir edilən əhatəli heşlənmiş açardan istifadə edir və tamamlanmanı həmin kontekstdən göndərir (`open-sse/executors/claude-web/browserTransport.ts:444`). O, brauzerin həll etdiyi kukini heç vaxt birbaşa TLS müştərisinə ixrac etmir. Brauzerdə təkrar cəhdlər eyni faktiki Playwright kontekstinə bağlı olan, müddəti bitməmiş UI şablonu tələb edir (`open-sse/executors/claude-web/browserTransport.ts:467`). Brauzer cavablarının oxunması autentifikasiya edilmiş səhifədə artımlı şəkildə həyata keçirilir, sorğunun ləğv edilməsini nəzərə alır və ölçü 16 MiB həddini keçən kimi yuxarı axın gövdəsini ləğv edir (`open-sse/executors/claude-web/browserTransport.ts:259`).

İcraçı ortaq sorğu jurnalına redaktə edilmiş audit proyeksiyası qaytarır: təşkilat, söhbət və mesaj UUID-ləri, sorğu mətni, alət tərifləri, kukilər və cihaz identifikatorları istisna edilir (`open-sse/executors/claude-web.ts:237`,
`open-sse/executors/claude-web.ts:252`). Nəqliyyat istisnaları da atılmış xəta mesajı əvəzinə ümumi bağlantı xətası qaytarır.

### SSE davranışı

`createClaudeWebResponse()` LF və ya CRLF çərçivələnməsini, eləcə də çoxsətirli `data:` sahələrini emal edir. O, mətn deltalarını `content`, düşünmə deltalarını `reasoning_content`, məlum metadata hadisələrini isə cavabın `claude_web` genişləndirməsi ilə uyğunlaşdırır. Hər bir metadata hadisəsi öz sahə icazə siyahısından keçirilərək proyeksiya edilir (`open-sse/executors/claude-web/stream.ts:37`). Söhbət, əsas mesaj, assistent mesajı və əməliyyat metadatası həmçinin `X-OmniRoute-Claude-Web-*` başlıqlarında qaytarılır (`open-sse/executors/claude-web/stream.ts:364`).

Parser qüsurlu JSON, yuxarı axındakı `error` hadisələri, naməlum hadisə növləri, etibarsız ardıcıllıq, məzmun bloklarının uyğunsuzluğu və ya `message_stop` hadisəsindən əvvəl EOF baş verdikdə təhlükəsiz şəkildə xəta ilə dayanır. Axın çıxışı bir tamamlanma fraqmenti və bir `[DONE]` göndərir; buferlənmiş çıxış eyni parserdən istifadə edir. Parser `message_stop` hadisəsini dərhal terminal hadisə kimi qəbul edir, ardınca gələn yuxarı axın məlumatlarını ləğv edir və aşağı axındakı ləğvi yuxarı axın oxuyucusuna ötürür (`open-sse/executors/claude-web/stream.ts:461`,
`open-sse/executors/claude-web/stream.ts:563`). Sonlandırılmamış SSE sətirləri və toplanmış hadisələr üçün 1 MiB həddi tətbiq edilir (`open-sse/executors/claude-web/stream.ts:17`,
`open-sse/executors/claude-web/stream.ts:62`).

### Quraşdırma

1. OmniRoute-u `npm run dev` ilə və ya yığılmış quraşdırmadan başladın.
2. İdarəetmə paneli → Provayderlər → Provayder əlavə et bölməsini açın.
3. Web Cookie kateqoriyasını və Claude Web-i seçin.
4. Autentifikasiya edilmiş `claude.ai` sorğusundan kopyalanmış tam Cookie başlığını yapışdırın.
