`chatgpt-web-codex` (`cgpt-codex` aliası) autentifikasiya olunmuş ChatGPT brauzer sessiyası vasitəsilə Codex Responses sorğu dövrlərini əlaqələndirir. O, istifadədən çıxarılmış ümumi
`chatgpt-web` provayderindən müstəqildir və yuxarı axının v4.0.7 versiyasının
`b59d7dc51b84fb1f465ff1d00f5207f3b2b4a494` kommiti əsasında yenilənmiş,
`open-sse/vendor/codex-chatgpt-web/` daxilindəki MIT bildirişli tətbiqdən istifadə edir.

## Ümumi provayderin istifadədən çıxarılması

Əvvəlki ümumi provayder ID-ləri `chatgpt-web` və `cgpt-web` artıq təqdim edilmir, çünki
onların ilkin açar/iş sübutu tətbiqinin mənşəyini təsdiqləmək mümkün olmadı. Hər iki ID-yə
edilən açıq sorğular, o cümlədən slash ilə başlayan model ID-ləri və saxlanılmış aliaslar,
yuxarı axına hər hansı sorğu göndərilməzdən əvvəl HTTP `410` və **PROVIDER_RETIRED** kodu
ilə qapalı şəkildə rədd edilir.

`168_retire_chatgpt_web.sql` miqrasiyası uyğun provayder bağlantılarını silinmiş kimi
işarələyir və onların aktiv sessiya icarələrini etibarsız edir. O, bağlantı tarixçəsini və API açarı
icazə siyahılarını qoruyur; icazə siyahısına əvəzedici giriş əlavə etmir. Codex provayderi və
onun bağlantıları bu istifadədən çıxarma əməliyyatına uyğun gəlmir.

## İlkin şərtlər

- daxil olunmuş ChatGPT sessiyasından tam Cookie başlığı;
- npm, systemd və PM2 quraşdırmaları üçün Chrome və ya Chromium, həmçinin qrafik sessiya və ya Xvfb displeyi;
- Docker `web` profili ilə `docker-compose.yml` faylındakı daxili Chromium xidməti;
- yerli Codex alətləri üçün OpenAI `tunnel-client` v0.0.13 və ChatGPT fərdi konnektoru.

Tunel yalnız alət sorğu dövrləri üçün lazımdır. `pro` daxil olmaqla sadalanan bütün marşrutlar,
tunel və konnektor konfiqurasiya edildikdə sorğu dövrünə bağlı eyni yerli alət imkanından istifadə edə bilər.

## İdarə panelində quraşdırma

1. **ChatGPT Web (Codex)** provayderini açın və bağlantı əlavə edin.
2. Tam ChatGPT Cookie başlığını, tunel ID-sini, icra mühiti açarını və fərdi konnektorun
   adını daxil edin. Alət imkanına malik yeni quraşdırmalar adı dəqiq şəkildə
   `OmniRoute Codex v2` olan yeni yaradılmış konnektordan istifadə etməli, Authentication
   None, Permissions isə Allow all actions olaraq təyin edilməlidir.
3. Bağlantı yoxlamasını başladın. OmniRoute brauzer dəstəkli Temporary Chat açır və hesab
   üçün Sol və Pro-nun əlçatan olub-olmadığını müəyyən edir.
4. Bağlantını saxlayın. OmniRoute daxil edilmiş kukini yoxlanmış Playwright saxlama
   vəziyyəti ilə əvəz edir və onu şifrələnmiş etimadnamə abstraksiyası vasitəsilə icra mühiti açarı ilə saxlayır.

Uğurlu saxlamadan sonra ilkin kuki qorunub saxlanılmır. Sessiyanın müddəti bitdikdə
bağlantını açın, yeni tam Cookie başlığı daxil edin və yoxlamanı yenidən başladın. Redaktə
dialoqundakı diaqnostika statusu brauzer, saxlama vəziyyəti, giriş, Temporary Chat, tunel,
konnektor və alətin tam sorğu-cavab dövrü barədə ayrıca məlumat verir.

> Heç vaxt real kukini, icra mühiti açarını, saxlama vəziyyətini və ya imkan tokenini kommit etməyin. Test və
> sənədləşdirmə dəyərləri həmişə yer tutucular olmalıdır.

## Modellər və kombinasiyalar

Sabit model marşrutları bunlardır:

- `chatgpt-web-codex/luna` — GPT-5.6 Luna, aşağı səy səviyyəsi
- `chatgpt-web-codex/think` — GPT-5.6 Luna, orta səy səviyyəsi
- `chatgpt-web-codex/instant`
- `chatgpt-web-codex/medium`
- `chatgpt-web-codex/high`
- `chatgpt-web-codex/extra-high`
- `chatgpt-web-codex/pro`

Onlardan birini istənilən digər model kimi kombinasiyaya əlavə edin. Codex tətbiqi kombinasiya adını
`model` kimi adi Responses son nöqtəsinə, `/v1/responses` ünvanına göndərir; ayrıca Codex
son nöqtəsi və ya rejim dəyişdiricisi yoxdur.

Free/Go hesabları Luna marşrutlarını təqdim edir. Sol imkanlı hesablar Instant-dan
High-a qədər marşrutları, Pro imkanlı hesablar isə əlavə olaraq Extra High və Pro-nu təqdim edir. Hər marşrutun
sabit arxa sistem modeli və əsaslandırma səy səviyyəsi var; ziddiyyətli açıq Responses səy səviyyəsi
seçilmiş brauzer rejimini səssizcə dəyişdirmək əvəzinə qapalı şəkildə rədd edilir.

Köhnə `Codex Native` və ya `OmniRoute Codex` konnektorunun adını dəyişməyin və onu təkrar istifadə etməyin. ChatGPT
açıq MCP müqaviləsini konnektorun identikliyinə əsasən keşləyir, yenilənmiş körpü isə
yeni birbaşa sorğu dövrü tokeni müqaviləsindən istifadə edir. İcra mühiti bu köhnə identiklikləri rədd edir və
yeni `OmniRoute Codex v2` konnektorunu tələb edir.

## Təhlükəsizlik modeli

- Nativ yol Responses sorğusu, tanınmış Codex klienti, həmçinin uyğun axın və gediş identifikatorları tələb edir.
- İş sahəsi, sandbox, təsdiq siyasəti və alətlər kataloqu nativ Codex qabığından gəlir; sərbəst formalı sorğu mətni bunlar üçün səlahiyyət mənbəyi deyil.
- ChatGPT hər gediş üçün yalnız qısamüddətli imkan əldə edir. MCP brokeri yalnız Codex-in məhz həmin gedişdə təklif etdiyi alətləri qəbul edir.
- **Allow once** seçiminin avtomatik təsdiqlənməsi yalnız alət sorğusunu Codex-ə qaytarır. Təsdiq və icra barədə qərarı yalnız Codex verir.
- İlk çıxışdan əvvəl kombinasiya başqa uyğun hədəfə keçə bilər. Çıxış başladıqdan sonra isə provayder, model, bağlantı və brauzer gedişi tamamlanana qədər sabit qalır.
- Kukilər, icra mühiti açarları, saxlama vəziyyəti və imkan tokenləri provayder cavablarında və ya sorğu jurnallarında görünmür.

## Displeysiz VPS və Docker

npm, systemd və PM2 quraşdırmalarında OmniRoute geniş yayılmış Chrome və Chromium yollarını aşkarlayır.
Alternativ olaraq, `CHATGPT_WEB_CODEX_CHROME_PATH` təyin edin. İcra zamanı gedişlər məqsədli şəkildə qrafik interfeysli Chrome istifadə edir, çünki ChatGPT həqiqi başsız brauzer formasını rədd edir. Buna görə də displeysiz host OmniRoute-u özəl Xvfb displeyi ilə işlətməlidir; yalnız Chrome yolunu təyin etmək displey təmin etmir.

Docker `web` profili daxili Compose şəbəkəsində `chatgpt-web-codex-browser` xidmətini işə salır. Yardımçı konteyner Xvfb daxilində qrafik interfeysli Chrome-u işlədir, buna görə fiziki displey tələb olunmur. Onun CDP portu hostda yayımlanmır. Qorunan brauzer profili cildi OmniRoute məlumat cildindən ayrıdır və brauzer kifayət qədər paylaşılan yaddaş alır. Daxili CDP proksisi yalnız Compose şəbəkəsi daxilində `9223` portunu dinləyir; Chrome isə yardımçı konteynerdə geridönüş interfeysinə bağlı qalır.

`DATA_DIR` daxilindəki nəzarətçi icarəsi birdən çox OmniRoute prosesinin eyni tunel və broker vəziyyətinə sahib olmasının qarşısını alır. Ziddiyyət diaqnostika vasitəsi tərəfindən bildirilir.

## İnteraktiv bərpa

Avtomatlaşdırılmış Docker yolunda hostdan görünən pəncərə yoxdur, lakin Chrome özü özəl Xvfb displeyi daxilində qrafik interfeyslə işləyir. ChatGPT interaktiv giriş və ya yoxlama tələb etdikdə, bərpa üçün mövcud VNC brauzer infrastrukturundan istifadə edilə bilər. Brauzer UI-si və CDP yalnız geridönüş interfeysi, autentifikasiyalı idarəetmə bağlantısı və ya SSH tuneli vasitəsilə əlçatan qalmalıdır; normal iş zamanı noVNC deaktiv qalır.

## WebSocket ehtiyat mexanizmi

Kombinasiyaya ChatGPT Web (Codex) daxil olduqda, Responses WebSocket körpüsü yuxarı axına qoşulmazdan əvvəl HTTP/SSE ehtiyat mexanizmini tələb edir. Ötürmə daha sonra `/v1/responses` vasitəsilə həyata keçirilir.
