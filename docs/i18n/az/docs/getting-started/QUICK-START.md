## Addım 1: OmniRoute-u quraşdırın

Üstünlük verdiyiniz üsulu seçin:

### Seçim A: npm (Tövsiyə olunur)

```bash
npm install -g omniroute
```

### Seçim B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` dərc edilmiş ən yüksək stabil SemVer versiyasıdır. O, git `main` qolunu izləmir. GitOps üçün `diegosouzapw/omniroute:X.Y.Z` versiyasını sabitləyin. [İmaj teqləri / Buraxılış kanalları](../guides/DOCKER_GUIDE.md#release-channels) bölməsinə baxın.

### Seçim C: Mənbə kodundan

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Addım 2: OmniRoute-u başladın

```bash
omniroute
```

OmniRoute `http://localhost:20128` ünvanında işə düşür. İdarə paneli avtomatik açılır.

---

## Addım 3: Pulsuz provayder qoşun

Pulsuz provayder qoşaraq OmniRoute-dan **heç bir ödəniş etmədən** istifadə edə bilərsiniz.

### Seçim A: Kiro (Pulsuz Claude — Kredit kartı tələb olunmur)

1. `http://localhost:20128` ünvanında idarə panelini açın
2. **Providers** → **Add Provider** bölməsinə keçin
3. **Kiro AI** seçin
4. **Connect** düyməsinə klikləyin (API açarı tələb olunmur!)
5. Hazırdır! İndi Claude modellərinə pulsuz girişiniz var.

### Seçim B: OpenCode Free (Autentifikasiya tələb olunmur)

1. `http://localhost:20128` ünvanında idarə panelini açın
2. **Providers** → **Add Provider** bölməsinə keçin
3. **OpenCode Free** seçin
4. **Connect** düyməsinə klikləyin (API açarı tələb olunmur!)
5. Hazırdır! İndi bir neçə modelə pulsuz girişiniz var.

### Seçim C: Pollinations (Açar tələb olunmur)

1. `http://localhost:20128` ünvanında idarə panelini açın
2. **Providers** → **Add Provider** bölməsinə keçin
3. **Pollinations** seçin
4. **Connect** düyməsinə klikləyin (API açarı tələb olunmur!)
5. Hazırdır! İndi GPT-5, Claude, Gemini və digər modellərə pulsuz girişiniz var.

---

## Addım 4: İşlədiyini yoxlayın

[API Keys](http://localhost:20128/dashboard/api-manager) bölməsində yeni açar yaradın. Bu açar bir daha göstərilməyəcəyi üçün onu yadda saxlayın. Nəzərə alın ki, bu açar yuxarı axın provayderlərinə deyil, alətlərin OmniRoute-a giriş əldə etməsi üçündür.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Qoşulmuş modellərinizin siyahısını görməlisiniz.

## Addım 5: IDE və ya CLI alətinizi OmniRoute-a yönləndirin

IDE və ya CLI alətinizdə bunları təyin edin:

```
Baza URL-i: http://localhost:20128/v1
API açarı:  [İdarə paneli → Endpoints bölməsindən kopyalayın]
Model:      auto
```

Bu qədər! IDE-niz artıq avtomatik provayder seçimi ilə OmniRoute-dan istifadə edir.

### IDE nümunəsi: VSCode/Continue.dev

1. VSCode-da [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) genişləndirməsini quraşdırın.
2. Aşağıdakı sətirləri əlavə etmək üçün `~/.continue/config.yaml` faylınızı yeniləyin:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev söhbət panelində `OmniRoute - Auto` seçin və sorğularınız OmniRoute-a göndəriləcək.
4. (İstəyə bağlı) Oxucu üçün tapşırıq — IDE-nizə `config.yaml` faylını əvvəlcədən hazırlanmış bütün digər konfiqurasiyalarla yenilətmək 😊

### CLI nümunəsi: Codex CLI

1. Əməliyyat sisteminizdə mühit dəyişənini daimi olaraq təyin edin.
   macOS/Linux üçün (`~/.bashrc` və ya `~/.zshrc` faylınıza əlavə edin):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows üçün (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. İndi Codex-i OmniRoute üçün konfiqurasiya edilmiş şəkildə işə salaq. Aşağıdakı əmri icra edin:

```
omniroute launch-codex --model auto
```

Bunu `codex` vasitəsilə, son nöqtəni və API açarını göstərən əmr sətri parametrlərindən istifadə edərək əl ilə edə bilərsiniz, lakin yuxarıdakı əmrlə OmniRoute hər şeyi sizin üçün idarə edir.

Eyni tək əmrlə işə salma üsulu ümumi başladıcı vasitəsilə digər CLI-lər üçün də işləyir — `omniroute run <target>` əmri `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` və `gemini` alətlərini dəstəkləyir ([CLI inteqrasiyaları](../guides/CLI-INTEGRATIONS.md) bölməsinə baxın).

3. CLI indi sorğuları OmniRoute-a göndərməlidir.

### Alətinizin OmniRoute-a yönləndirildiyini təsdiqləyin

Sol yan paneldə [Monitoring/Logs](http://localhost:20128/dashboard/logs) bölməsinə klikləyərək sorğunun təfərrüatlarını görə bilərsiniz. Müvafiq qeydlərə kliklədikdə daha ətraflı məlumat göstərilir. Əlavə olaraq, sevimli alət mühitinizdən hansı məlumatların göndərildiyini də görə bilərsiniz. Bu, öyrənmə və sazlama baxımından faydalıdır.

## Tez-tez verilən suallar

### "API açarına ehtiyacım varmı?"

**Xeyr!** Pulsuz provayderlərdən (Kiro, OpenCode Free, Pollinations) heç bir API açarı olmadan istifadə edə bilərsiniz. Sadəcə onları idarə panelində qoşun.

### "`auto` nədir?"

`auto` OmniRoute-a hər sorğu üçün ən yaxşı provayderi avtomatik seçməyi bildirir. O, sürəti, xərci, keyfiyyəti və əlçatanlığı nəzərə alır. Ətraflı məlumat üçün [Auto-Combo təlimatına](./AUTO-COMBO-GUIDE.md) baxın.

### "Qiyməti nə qədərdir?"

OmniRoute özü **pulsuz və açıq mənbəlidir**. Yalnız istifadə etdiyiniz provayderlər üçün ödəniş edirsiniz. Bir çox provayderin pulsuz tarifləri var — [Pulsuz tariflər üzrə təlimata](./FREE-TIERS-GUIDE.md) baxın.

### "Onu Claude Code / Cursor / Copilot ilə istifadə edə bilərəm?"

**Bəli!** OmniRoute OpenAI formatını dəstəkləyən istənilən alətlə işləyir. Sadəcə baza URL-ni `http://localhost:20128/v1` olaraq təyin edin. Xüsusi quraşdırma təlimatları üçün [CLI alətləri üzrə təlimata](../reference/CLI-TOOLS.md) baxın.

### "Provayder fəaliyyətini dayandırsa nə baş verəcək?"

OmniRoute uğursuz olan provayderləri avtomatik ötürür və növbəti provayderi sınayır. Heç nə etməyinizə ehtiyac yoxdur. Ətraflı məlumat üçün [Auto-Combo təlimatına](./AUTO-COMBO-GUIDE.md) baxın.
