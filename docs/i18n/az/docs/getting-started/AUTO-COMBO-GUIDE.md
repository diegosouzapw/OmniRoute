> **Qısa xülasə**: Modelinizi `auto` olaraq təyin edin və OmniRoute hər sorğu üçün ən yaxşı süni intellekt provayderini avtomatik seçsin. Heç bir konfiqurasiya tələb olunmur.

---

## Nə edir

Konkret bir süni intellekt modeli (məsələn, GPT-4o və ya Claude) seçmək əvəzinə, OmniRoute-un hər sorğu üçün **ən yaxşı modeli avtomatik seçməsinə** icazə verə bilərsiniz. O, aşağıdakıları nəzərə alır:

- **Sağlamlıq** — Provayder hazırda işləyirmi?
- **Sürət** — Nə qədər sürətlidir?
- **Xərc** — Nə qədər xərc tələb edir?
- **Keyfiyyət** — Bu tapşırıq növü üçün uyğundurmu?
- **Tutum** — Qalan kvotası varmı?

OmniRoute qoşulmuş bütün provayderlərinizi qiymətləndirir və ən yaxşısını seçir. Seçilmiş provayder uğursuz olarsa, avtomatik olaraq növbətisini sınayır.

---

## Sürətli başlanğıc

**Addım 1**: IDE və ya CLI-də modelinizi `auto` olaraq təyin edin:

```
model: "auto"
```

**Addım 2**: Bu qədər! Qalan hər şeyi OmniRoute idarə edir.

**Addım 3** (istəyə bağlı): Konkret tapşırıqlar üçün variantdan istifadə edin:

```
model: "auto/coding"    # Kod üçün ən yaxşısı
model: "auto/fast"      # Ən sürətli cavab
model: "auto/cheap"     # Ən ucuz seçim
```

## Hansı "auto" variantından istifadə etməliyəm?

| Əgər istədiyiniz...     | Bundan istifadə edin | Ən uyğun olduğu hallar          | Necə işləyir                                         |
| ----------------------- | -------------------- | ------------------------------- | ---------------------------------------------------- |
| **Ümumilikdə ən yaxşı** | `auto`               | Ümumi suallar, söhbət           | Sürət, xərc və keyfiyyəti tarazlaşdırır              |
| **Kod üçün ən yaxşı**   | `auto/coding`        | Kod yazmaq, sazlama             | Kodlaşdırma tapşırıqlarında yaxşı modelləri seçir    |
| **Ən sürətli cavab**    | `auto/fast`          | Sürətli cavablar, aşağı gecikmə | Sürəti hər şeydən üstün tutur                        |
| **Ən ucuz seçim**       | `auto/cheap`         | Pul qənaət etmək                | Ən ucuz provayderi seçir                             |
| **Ən ağıllı model**     | `auto/smart`         | Mürəkkəb tapşırıqlar            | Keyfiyyətə üstünlük verir + yeni modelləri araşdırır |
| **Ən əlçatan**          | `auto/offline`       | Provayderlər məşğul olduqda     | Ən çox tutumu olan provayderləri seçir               |

## Necə işləyir (sadə versiya)

`model: "auto"` ilə sorğu göndərdiyiniz zaman OmniRoute:

1. **Qoşulmuş bütün provayderlərinizə baxır** — Əlavə etdiyiniz hər bir provayder (OpenAI, Anthropic, Google və s.)
2. **Hər birini qiymətləndirir** və digər amillərlə yanaşı bunları nəzərə alır:
   - İşləyirmi? (sağlamlıq)
   - Kifayət qədər tutumu varmı? (kvota)
   - Nə qədər xərc tələb edir? (qiymət)
   - Nə qədər sürətlidir? (sürət)
   - Bu tapşırıq üçün uyğundurmu? (keyfiyyət)
3. **Ən yaxşısını seçir** — Ən yüksək bal toplamış provayder sorğunuzu qəbul edir
4. **Avtomatik bərpa olunur** — Uğursuz olarsa, OmniRoute avtomatik olaraq növbətisini sınayır

### Qiymətləndirmə sistemi

Hər provayder 0-dan 1-ə qədər bal alır. Bal nə qədər yüksəkdirsə, uyğunluq bir o qədər yaxşıdır.

| Amil               | Çəki | Mənası                                                   |
| ------------------ | ---- | -------------------------------------------------------- |
| Sağlamlıq          | 20%  | Provayder işləyirmi? (circuit breaker vəziyyəti)         |
| Kvota              | 15%  | Qalan tutumu varmı?                                      |
| Xərc               | 15%  | Nə qədər bahadır? (daha ucuz = daha yüksək bal)          |
| Sürət              | 12%  | Nə qədər sürətlidir? (daha az gecikmə = daha yüksək bal) |
| Tapşırığa uyğunluq | 8%   | Bu tapşırıq növü üçün uyğundurmu?                        |
| Sabitlik           | 5%   | Ardıcıldırmı? (aşağı xəta səviyyəsi)                     |
| Səviyyə            | 5%   | Hesab səviyyəsi (Ultra > Pro > Free)                     |
| Digər              | 20%  | Kontekst uyğunluğu, bağlantı sıxlığı və s.               |

### Variantlar qiymətləndirməni necə dəyişir

Hər variant fərqli çəkilərdən istifadə edir:

| Variant        | Üstünlük verdiyi      | Əsas çəkilər                    |
| -------------- | --------------------- | ------------------------------- |
| `auto`         | Balans                | health=20%, quota=15%, cost=15% |
| `auto/coding`  | Keyfiyyət             | taskFit=37%, stability=15%      |
| `auto/fast`    | Sürət                 | latency=32%, health=28%         |
| `auto/cheap`   | Xərc                  | cost=37%                        |
| `auto/smart`   | Keyfiyyət + araşdırma | taskFit=37%, exploration=10%    |
| `auto/offline` | Tutum                 | quota=37%, health=28%           |

## Nasazlıqları Necə İdarə Edir

OmniRoute **üç qoruma qatına** malikdir:

### 1. Avtomatik Ehtiyat Keçidi

Ən yaxşı provayder uğursuz olarsa, OmniRoute avtomatik olaraq növbəti provayderi sınayır. Heç nə etməyinizə ehtiyac yoxdur.

### 2. Özünübərpa

Provayder davamlı olaraq uğursuz olarsa:

- **Bal < 0.2** → 5 dəqiqəlik kənarlaşdırılır
- **Dövrə açarı açıqdır** → Avtomatik kənarlaşdırılır
- **Provayderlərin 50%-dən çoxu işləmir** → İnsident rejimi (araşdırma yoxdur)

### 3. Fövqəladə Ehtiyat Keçidi

Bütün provayderlər uğursuz olarsa, OmniRoute son çıxış yolu kimi sorğuları stabil pulsuz provayderlərə (məsələn, Kiro və ya Qoder) yönləndirir.

---

## Çoxsaylı Hesab Dəstəyi

Eyni provayder üçün bir neçə hesabınız varsa (məsələn, iki OpenAI açarı), OmniRoute hər birinə **ayrıca namizəd** kimi yanaşır. Bu o deməkdir ki:

- A hesabında qalan kvota var → ondan istifadə et
- B hesabına sürət məhdudiyyəti tətbiq olunub → onu keç
- C hesabı daha ucuzdur → ona üstünlük ver

Hər bir hesab öz işləkliyinə, kvotasına və sürətinə əsasən müstəqil şəkildə qiymətləndirilir.

---

## Bandit Araşdırması

OmniRoute daha yaxşı seçimlər tapmaq üçün vaxtaşırı yeni provayderləri **araşdırır**:

- **Defolt**: Sorğuların 5%-i təsadüfi provayderlərə göndərilir
- **Auto/smart**: 10% araşdırma nisbəti
- Provayderlərin 50%-dən çoxu qeyri-sağlam olduqda **deaktiv edilir**

Bu, OmniRoute-a istifadə qaydalarınız üçün hansı provayderlərin daha yaxşı işlədiyini öyrənməyə kömək edir.

## Tez-Tez Verilən Suallar

### "Həmişə ən bahalı modeli seçəcək?"

**Xeyr.** Defolt olaraq xərc balın yalnız 15%-ni təşkil edir. Ucuz, sürətli və sağlam provayder bahalı provayderi üstələyə bilər. Xərci daha çox prioritetləşdirmək istəyirsinizsə, `auto/cheap` istifadə edin.

### "Provayder fəaliyyətini dayandırarsa nə baş verəcək?"

OmniRoute onu avtomatik keçir və növbəti provayderi sınayır. Provayder davamlı olaraq uğursuz olarsa, müvəqqəti olaraq (5-30 dəqiqəlik) kənarlaşdırılır. Heç nə etməyinizə ehtiyac yoxdur.

### "Hansı provayderin istifadə edildiyini görə bilərəm?"

Cavab başlıqlarını yoxlayın — OmniRoute hər cavabda istifadə olunan provayderi və modeli göstərir.

### "İstifadəmdən öyrənirmi?"

Bəli! Qiymətləndirmə sistemi zaman keçdikcə daha yaxşı qərarlar vermək üçün tarixi məlumatlardan (gecikmə, xəta nisbətləri, uğur nisbətləri) istifadə edir.

### "`auto` ilə `auto/smart` arasında hansı fərq var?"

- `auto` — Balanslaşdırılmış, 5% araşdırma
- `auto/smart` — Keyfiyyət prioritetlidir (`auto/coding` ilə eyni çəkilər), 10% araşdırma

Ən yaxşı keyfiyyəti istəyirsinizsə və vaxtaşırı araşdırmanın aparılması sizin üçün məqbuldursa, `auto/smart` istifadə edin.

### "Konkret provayderin istifadəsini məcbur edə bilərəm?"

Bəli! `auto` əvəzinə `priority` strategiyalı kombinasiyadan istifadə edin, sonra kombinasiyanın **dəqiq adını** `model` sahəsi kimi göndərin (məsələn, `model: "my-combo"` — `auto` deyil). Ətraflı məlumat üçün [Texniki İstinada](../routing/AUTO-COMBO.md) baxın.

### "Bu, növbəli seçimdən nə ilə fərqlənir?"

Növbəli seçim provayderlər arasında ardıcıllıqla keçid edir. Auto-combo **hər bir provayderi qiymətləndirir** və ən yaxşısını seçir. O, daha ağıllıdır — işləkliyi, sürəti, xərci və keyfiyyəti nəzərə alır.
