## Sürətli silinmə (v3.6.2+)

OmniRoute təmiz silinmə üçün iki daxili skript təqdim edir:

### Məlumatlarınızı saxlayın

```bash
npm run uninstall
```

Bu, OmniRoute tətbiqini silir, lakin `~/.omniroute/` daxilindəki verilənlər bazanızı, konfiqurasiyalarınızı, API açarlarınızı və provayder parametrlərinizi **qoruyub saxlayır**. Daha sonra yenidən quraşdırmağı planlaşdırırsınızsa və mövcud sazlamalarınızı saxlamaq istəyirsinizsə, bundan istifadə edin.

### Tam silinmə

```bash
npm run uninstall:full
```

Bu, tətbiqi silir **və bütün məlumatları həmişəlik pozur**:

- Verilənlər bazası (`storage.sqlite`)
- Provayder konfiqurasiyaları və API açarları
- Ehtiyat nüsxə faylları
- Jurnal faylları
- `~/.omniroute/` qovluğundakı bütün fayllar

> ⚠️ **Xəbərdarlıq:** `npm run uninstall:full` əməliyyatı geri qaytarıla bilməz. Bütün provayder bağlantılarınız, kombinasiyalarınız, API açarlarınız və istifadə tarixçəniz həmişəlik silinəcək.

## Əl ilə silinmə

### NPM qlobal quraşdırması

```bash
# Qlobal paketi silin
npm uninstall -g omniroute

# (İstəyə bağlı) Məlumat qovluğunu silin
rm -rf ~/.omniroute
```

### pnpm qlobal quraşdırması

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Konteyneri dayandırın və silin
docker stop omniroute
docker rm omniroute

# Həcmi silin (bütün məlumatları silir)
docker volume rm omniroute-data

# (İstəyə bağlı) Obrazı silin
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Konteynerləri dayandırın və silin
docker compose down

# Həmçinin həcmləri silin (bütün məlumatları silir)
docker compose down -v
```

### Electron masaüstü tətbiqi

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` bölməsini açın
- Və ya quraşdırma qovluğundan NSIS silmə proqramını işə salın

**macOS:**

- `OmniRoute.app` faylını `/Applications` qovluğundan zibil qutusuna sürükləyin
- Məlumatları silin: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage faylını silin
- Məlumatları silin: `rm -rf ~/.omniroute`

### Mənbə kodundan quraşdırma (git clone)

```bash
# Klonlanmış qovluğu silin
rm -rf /path/to/omniroute

# (İstəyə bağlı) Məlumat qovluğunu silin
rm -rf ~/.omniroute
```

## Məlumat qovluqları

OmniRoute standart olaraq məlumatları aşağıdakı yerlərdə saxlayır:

| Platforma | Standart yol                  | Əvəzləyici                       |
| --------- | ----------------------------- | -------------------------------- |
| Linux     | `~/.omniroute/`               | `DATA_DIR` mühit dəyişəni        |
| macOS     | `~/.omniroute/`               | `DATA_DIR` mühit dəyişəni        |
| Windows   | `%APPDATA%/omniroute/`        | `DATA_DIR` mühit dəyişəni        |
| Docker    | `/app/data/` (qoşulmuş həcm)  | `DATA_DIR` mühit dəyişəni        |
| XDG-uyğun | `$XDG_CONFIG_HOME/omniroute/` | `XDG_CONFIG_HOME` mühit dəyişəni |

### Məlumat qovluğundakı fayllar

| Fayl/Qovluq          | Təsvir                                                                      |
| -------------------- | --------------------------------------------------------------------------- |
| `storage.sqlite`     | Əsas verilənlər bazası (provayderlər, kombinasiyalar, parametrlər, açarlar) |
| `storage.sqlite-wal` | SQLite qabaqlayıcı yazma jurnalı (müvəqqəti)                                |
| `storage.sqlite-shm` | SQLite ortaq yaddaşı (müvəqqəti)                                            |
| `call_logs/`         | Sorğu faydalı yüklərinin arxivləri                                          |
| `backups/`           | Verilənlər bazasının avtomatik ehtiyat nüsxələri                            |
| `log.txt`            | Köhnə sorğu jurnalı (istəyə bağlı)                                          |

## Tam Silinməni Yoxlayın

Sildikdən sonra heç bir faylın qalmadığını yoxlayın:

```bash
# Qlobal npm paketini yoxlayın
npm list -g omniroute 2>/dev/null

# Məlumat qovluğunu yoxlayın
ls -la ~/.omniroute/ 2>/dev/null

# İşləyən prosesləri yoxlayın
pgrep -f omniroute
```

Hər hansı proses hələ də işləyirsə, onu dayandırın:

```bash
pkill -f omniroute
```
