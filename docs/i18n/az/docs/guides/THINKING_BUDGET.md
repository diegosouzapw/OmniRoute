> **İdarəetmə paneli:** Parametrlər → **AI** → Düşünmə büdcəsi  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **Mənbə:** `open-sse/services/thinkingBudget.ts`

Düşünmə büdcəsi OmniRoute-un provayderlərə göndərilən sorğularda **müştərinin düşünmə/mühakimə parametrlərini yenidən yazıb-yazmamasını** idarə edir. Bu parametr sıxılmanı, marşrutlaşdırmanı və ya sorğu keşini aktivləşdirmir və ya deaktivləşdirmir.

## Rejimlər

| Rejim                        | OmniRoute nə edir                                                                                                            | Nə zaman istifadə edilməlidir                                                                                                                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (standart) | Müştəri sahələrini dəyişmədən saxlayır (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config` və s.). | **Codex / Desktop / səy səviyyəsini və mühakimə xülasələrini idarə etməli olan istənilən müştəri.** Müştəri `reasoning.summary` tələb etdikdə görünən düşünmə panelləri üçün zəruridir.               |
| **`auto`**                   | Yuxarı axına göndərməzdən əvvəl sorğu gövdəsindən bütün düşünmə/mühakimə sahələrini **silir**.                               | Yalnız **provayderin** standart dəyərləri özü təyin etməsini qəsdən istədiyiniz və müştərinin idarə etdiyi düşünməyə ehtiyacınız olmadığı hallarda. Bu, “düşünməni avtomatik göstər” demək **deyil**. |
| **`custom`**                 | Hər sorğunu sabit düşünmə tokeni büdcəsi ilə əvəzləyir.                                                                      | Bütün trafik üçün düşünmə tokenlərinə sərt limit qoymaq məqsədilə.                                                                                                                                    |
| **`adaptive`**               | Mesajların sayına, alətlərə və sorğunun uzunluğuna əsasən baza səy səviyyəsindən büdcəni miqyaslandırır.                     | Müştərinin niyyətini tamamilə aradan qaldırmadan tokenlərə yumşaq nəzarət etmək məqsədilə.                                                                                                            |

### `auto` nəyi silir

Rejim `auto` olduqda, `stripThinkingConfig()` digərləri ilə yanaşı bunları silir:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking` və mövcud olduqda `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

Müştəri (məsələn, Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` göndəribsə, **auto həmin obyekti silir**. Yuxarı axındakı xidmət yenə də bəzi mühakimə tokenləri üçün ödəniş hesablaya bilər, lakin çox vaxt **boş və ya yalnız şifrələnmiş** mühakimə elementləri qaytarır — buna görə də istifadəçi interfeysi faydalı düşünmə axını göstərmir.

## Bu, **nə deyil**

| Funksiya                                               | Əlaqə                                                                                                                                                           |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Sıxılma** (Caveman, RTK, stacked, …)                 | Ayrı konveyerdir. Hər bir düşünmə büdcəsi rejimində işləyir.                                                                                                    |
| **Sorğu / semantik keş**                               | Ayrıdır. Düşünmə büdcəsi rejimindən təsirlənmir.                                                                                                                |
| **Kombinə edilmiş marşrutlaşdırma / ehtiyat keçidlər** | Ayrıdır. Təsirlənmir.                                                                                                                                           |
| **API açarı üzrə token limitləri / xərc büdcələri**    | Ayrıdır. Təsirlənmir.                                                                                                                                           |
| **Mühakimənin təkrar oxudulması keşi**                 | Sərt provayderlər (DeepSeek, Kimi, Qwen-thinking, …) üçün çoxgedişli yenidən əlavəetmə mexanizmidir. Desktop-dakı “düşünməni göstər” funksiyası ilə eyni deyil. |
| **`encrypted_content` şifrəsinin açılması**            | **Mümkün deyil.** OpenAI/Codex-in özəl mühakimə məlumat blokları qeyri-şəffafdır. OmniRoute onları heç vaxt deşifrə etmir (#7095 / #7176 / #7304).              |

## Görünən düşünmə mətni (Codex / Responses klientləri)

Klientin düşünmə mətnini göstərməsi üçün aşağıdakıların **hamısı** tələb olunur:

1. Thinking Budget rejimi = **`passthrough`** (və ya istifadə etdiyiniz yol üçün xülasə sorğularını kifayət qədər dəyişməz saxlayan custom/adaptive rejimi).
2. Klient xülasə tələb edir, məsələn, Codex `model_reasoning_summary = "detailed"` / `auto` (`none` deyil).
3. Yuxarı axın həqiqətən `response.reasoning_summary_text.*` yayımlayır (və ya elementdə boş olmayan `reasoning.summary` mövcuddur).

Yalnız “şifrələnmiş gizli düşünmə” əldə edirsinizsə, səbəb bunlardan biridir:

- rejim **`auto`** olub (klient sorğusu silinib) və ya
- yuxarı axın xülasə mətni olmadan `encrypted_content` qaytarıb (provayder məhdudiyyəti; OmniRoute yalnız yer tutucu göstərə bilər, açıq mətni deyil).

## API nümunələri

```bash
# Oxuma
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Codex / Desktop-da düşünmə mətninin görünməsi üçün tövsiyə olunur
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Sxem (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; istəyə bağlı `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### Saxlanma / yenidən başlatma

Dəyər parametrlərin `thinkingBudget` açarı altında saxlanılır və proses başladıqda yüklənir (`hydrateThinkingBudgetConfig`). DB və ya bəzi qeyri-API yolları vasitəsilə dəyişiklik etdikdən sonra yaddaşdakı singleton-un diskdəki dəyərlə uyğunlaşması üçün **OmniRoute prosesini yenidən başladın**.

## Operator üçün yoxlama siyahısı

- [ ] Codex / Desktop istifadəçiləri: rejim = **passthrough**
- [ ] Tokenlərə qənaət etmək istəyirsinizsə, düşünmə mətnini silmək əvəzinə **mesajlar** üçün sıxılmanı aktiv saxlayın
- [ ] `auto` rejiminin “daha çox düşünmə mətni göstərəcəyini” gözləməyin
- [ ] Yalnız şifrələnmiş xülasələr **provayder** davranışıdır; passthrough onları deşifrə edə bilməz
