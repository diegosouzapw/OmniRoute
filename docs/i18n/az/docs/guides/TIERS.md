OmniRoute dəstəklənən 352 provayderi 3 iqtisadi səviyyəyə ayırır. Hər
sorğu uğurlu cavab alınana qədər ardıcıllıqla bu səviyyələrdən keçir — beləliklə,
ehtiyat keçid kodu yazmadan mümkün olan ən ucuz cavabı əldə edirsiniz.

## Səviyyə 1 — Abunəlik

**Artıq ödəniş etdiyiniz provayderlər.** OmniRoute kvota müddəti bitməzdən əvvəl
ondan tam istifadə edir.

| Provayder                        | Niyə Səviyyə 1                                                |
| -------------------------------- | ------------------------------------------------------------- |
| Claude Code OAuth                | Anthropic Pro/Team — sabit tarifli, çox vaxt istifadə olunmur |
| OpenAI Codex (ChatGPT abunəliyi) | Plus/Team paketinə Codex kvotası daxildir                     |
| GitHub Copilot                   | İstifadəçi başına — kvota hər ay sıfırlanır                   |
| Cursor IDE                       | Pro plan kvotası                                              |
| Antigravity / Devin Desktop      | Daxili kvotalar                                               |

**Strategiya**: modelin güclü tərəflərinə uyğun gələn hər sorğunu əvvəlcə buraya
yönləndirin. Kvota izləyicisi yaxınlaşan sıfırlanmaları izləyir və `reset-aware`
kombinə strategiyası prioritetləri buna uyğun müəyyənləşdirir. Əvvəlcə Səviyyə 1-ə
yönləndirmək və yalnız kvota bitdikcə ödənişli səviyyələrə keçmək üçün `auto/thrifty`
id-sindən istifadə edin — yaxud plana daxil olan resurslarla məhdudlaşmaq və onlar
əlçatan olmadıqda sorğunu rədd etmək üçün `auto/subscription` istifadə edin.
[Abunəlik prioritetli yönləndirmə](../routing/SUBSCRIPTION_LADDER.md) bölməsinə baxın.

## Səviyyə 2 — Ucuz

**1 milyon token üçün qiyməti $1-dan aşağı olan, tokenə görə ödənişli provayderlər.**
Yüksək həcmli işlər və ya Səviyyə 1 kvotaları limitə çatdıqdan sonrakı istifadə
üçün nəzərdə tutulub.

| Provayder                                    | Qiymət (giriş/çıxış)  | Güclü tərəflər      |
| -------------------------------------------- | --------------------- | ------------------- |
| DeepSeek V4 Pro                              | 1M üçün $0.27 / $1.10 | Kod, mülahizə       |
| GLM-4.5                                      | 1M üçün $0.60 / $2.20 | Uzun kontekst       |
| MiniMax M1                                   | 1M üçün $0.20 / $1.10 | Sürət               |
| Qwen Coder                                   | 1M üçün $0.30 / $1.20 | Kod                 |
| OpenRouter (qiymətə görə optimallaşdırılmış) | dəyişir               | 100+ model, dinamik |

**Strategiya**: `cost-optimized` kombinasiyası tapşırığın imkan filtrinə
(görmə, JSON rejimi, alətlər, maksimum kontekst) uyğun gələn ən aşağı
$/token qiymətli modeli seçir.

## Səviyyə 3 — Pulsuz

**Sıfır xərcli provayderlər** — pulsuz səviyyələr, kredit proqramları, gündəlik OAuth kvotaları.

| Provayder        | Pulsuz kvota / kreditlər                                        |
| ---------------- | --------------------------------------------------------------- |
| Kiro AI          | Pulsuz Claude səviyyəsi (səxavətli ədalətli istifadə)           |
| OpenCode Free    | Autentifikasiya tələb olunmur, səxavətli sorğu sürəti limitləri |
| Qoder            | Pulsuz OAuth                                                    |
| Google Vertex AI | Yeni hesablar üçün $300 kredit                                  |
| Amazon Q         | AWS istifadəçiləri üçün pulsuz səviyyə                          |
| Pollinations     | Açıq ictimai API                                                |
| Cloudflare AI    | Workers AI pulsuz səviyyəsi                                     |

**Strategiya**: büdcə limiti olan `auto` kombinasiyası Səviyyə 1+2 uğursuz
olduqda və ya `useFreeOnly=true` təyin edildikdə sorğuları buraya yönləndirir.
Pulsuz provayderlərin sorğu sürəti limitləri çox vaxt daha sərt olur —
dövrə açarı gözləmə müddətindən sonra onları bərpa edir.

## Səviyyələrin konfiqurasiyası

İdarə paneli → **Səviyyələr** → provayderlərinizi təyin edin. Standart parametrlər
(`tierDefaults.json` faylından) məqsədəuyğundur; prioritetləşdirmək istədiyiniz
xüsusi abunəliklər və ya istisna etmək istədiyiniz provayderlər olduqda onları redaktə edin.

Auto-Combo-nun 16 amilli qiymətləndirməsi səviyyəni də nəzərə alır.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) sənədinə baxın.

## Telemetriya

İdarə paneli → **İstifadə** bölməsi hər səviyyə üzrə gündəlik sərf olunan tokenləri göstərir. Bundan aşağıdakılar üçün istifadə edin:

- Səviyyə 1-dən tam istifadə edildiyini təsdiqləyin (əks halda abunəliyin dəyərini boşa verirsiniz)
- Hansı Səviyyə 2 modellərinin daha çox seçildiyini müəyyənləşdirin (onları 1-2 modelə endirin)
- Səviyyə 3-ün sınaq/tədqiqat iş yüklərində pula qənaət etdiyini yoxlayın

## Ümumi istifadə nümunələri

### Tamamilə pulsuz iş yükü

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Yönləndirməni güclü şəkildə Səviyyə 3-ə istiqamətləndirir; Səviyyə 2-dən yalnız
Səviyyə 3 əlçatan olmadıqda istifadə edir.

### Ucuz ehtiyat keçidlə abunəlik prioriteti

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Səviyyə 1 → Səviyyə 2 → Səviyyə 3 ardıcıllığına uyğun açıq şəkildə müəyyənləşdirilmiş siyahı.
