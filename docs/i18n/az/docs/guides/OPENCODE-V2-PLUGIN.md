`@omniroute/opencode-plugin-v2` bütün OmniRoute kataloqunuzu — modelləri, kombinasiyaları və
avtomatik kombinasiyaları — görünən adlar, qiymətlər və pulsuz səviyyə
limitləri ilə birlikdə OpenCode v2-nin model seçicisinə əlavə edir.

Bu, `@omniroute/opencode-plugin` paketindən ayrı paketdir, çünki OpenCode v1 və v2
plaginləri fərqli müqavilələr vasitəsilə yükləyir. OpenCode-un əsas versiyasına uyğun olanı
seçin; onlar arasında heç nə paylaşılmadığı üçün birini yeniləmək heç vaxt digərini yeniləməyə
məcbur etmir.

## Tələblər

- OpenCode v2.
- Əlçatan OmniRoute şlüzü (standart olaraq `http://localhost:20128`).
- Node.js 22 və ya 24.

## Quraşdırma

Plagini `opencode.json` faylına əlavə edin:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Bundan sonra modellər `omniroute/<provider>/<model>` formasında görünür; `providerId` həmin
prefiksi və OpenCode-un giriş məlumatını saxladığı inteqrasiya identifikatorunu müəyyən edir.

## Giriş məlumatları

Plagin şlüz açarını aşağıdakı üç yerdə, bu ardıcıllıqla axtarır:

1. **OpenCode-da qoşduğunuz giriş məlumatı.** Plagin inteqrasiya qeydiyyatdan keçirdiyi üçün
   OpenCode-un öz autentifikasiya prosesi açarı saxlaya bilər. `opencode.json` faylına heç nə
   yazılmır — buna üstünlük verin.
2. Layihəyə məxsus əvəzləmə üçün plagin seçimlərindəki `apiKey`. Bu, açarı repozitoriyaya
   daxil edə biləcəyiniz bir faylda saxlayır.
3. Mühitdəki `OMNIROUTE_API_KEY`.

Bu üçündən heç biri olmadıqda kataloq boş olur və plagin sizi səssizcə boş seçici ilə
baş-başa qoymaq əvəzinə başlanğıcda bunu bir dəfə bildirir.

### İdarəetmə tokeni fərqli açardır

Kombinasiyalar, provayderin vəziyyəti və zənginləşdirmə (görünən adlar, qiymətlər və pulsuz
səviyyə limitləri) şlüzün `/api/*` son nöqtələrindən əldə edilir. Əksər yerləşdirmələr bu son
nöqtələri inferensiya açarı əvəzinə **idarəetmə** tokeni ilə qoruyur:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

`managementReadToken` təyin edilmədikdə `apiKey` istifadə olunur. Şlüz bu alternativi rədd
etdikdə kataloq yenə də yayımlanır, lakin görünən adların əvəzinə xam model identifikatorları
ilə, kanonik alias təkrarsızlaşdırması, qiymətlər və kombinasiyalar olmadan təqdim edilir.
Bu baş verdikdə plagin hər son nöqtə üçün bir dəfə xəbərdarlıq edir, son nöqtənin adını və
nələrin itirildiyini göstərir — beləliklə, məhdud işləyən seçicinin səbəbi heç vaxt müəmmalı
qalmır.

## Seçimlər

| Açar                             | Standart dəyər                                     | Qeydlər                                                                                                             |
| -------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                      | Provayder identifikatoru, inteqrasiya identifikatoru və modellərin göründüyü prefiks                                |
| `baseURL`                        | tələb olunur                                       | Şlüzün kök ünvanı, yalnız `http(s)`; lazım olan yerlərdə `/v1` suffiksi əlavə edilir                                |
| `apiKey`                         | qoşulmuş giriş məlumatı, sonra `OMNIROUTE_API_KEY` | `/v1/*` üçün çat açarı                                                                                              |
| `managementReadToken`            | `apiKey` istifadə olunur                           | `/api/*` üçün açar — adətən eyni açar **deyil**                                                                     |
| `displayName`                    | `"OmniRoute"`                                      | Seçicidəki provayder adı                                                                                            |
| `timeoutMs`                      | `10000`                                            | Hər son nöqtə üzrə sorğu vaxt limiti (avtomatik kombinasiyalar 5 san. istifadə edir)                                |
| `modelCacheTtlMs`                | `300000`                                           | Kataloq keşinin TTL müddəti; disk ani görüntüsü soyuq başlanğıcları sürətləndirir                                   |
| `timeouts`                       | `timeoutMs` istifadə olunur                        | Son nöqtələr üzrə millisaniyə ilə limitlər: `models`, `combos`, `autoCombos`, `enrichment`                          |
| `enrichment`                     | `true`                                             | Adları, qiymətləri və pulsuz səviyyə limitlərini əldə edir                                                          |
| `providerTag`                    | `true`                                             | Görünən adın əvvəlinə sorğunun yönləndirildiyi yuxarı axın provayderini əlavə edir                                  |
| `usableOnly`                     | `false`                                            | Yalnız şlüzün təmin edilmiş kimi bildirdiyi provayderləri saxlayır                                                  |
| `visibleModels` / `hiddenModels` | `[]`                                               | Dəqiq uyğunluq və ya suffiks üzrə icazə siyahıları; qadağa üstünlük təşkil edir                                     |
| `geminiSanitization`             | `true`                                             | Gemini-nin alət sxemlərində rədd etdiyi JSON-Schema açar sözlərini silir (`$ref` alətləri dəyişdirilmədən ötürülür) |
| `apiFormat.allowAnthropic`       | `false`                                            | İcazə siyahısındakı identifikatorları Anthropic API bloku vasitəsilə yönləndirir                                    |
| `apiFormat.anthropicModels`      | `[]`                                               | Anthropic-ə yönləndirilən tam model identifikatorları                                                               |
| `logLevel` / `startupDebug`      | `warn` / `false`                                   | Jurnalın təfərrüat səviyyəsi                                                                                        |

## Kataloq necə aktual saxlanılır

Kataloq tənbəl şəkildə əldə edilir və `modelCacheTtlMs` müddəti boyunca keşlənir; diskdəki ani görüntü isə şlüz əlçatmaz olduqda son məlum kataloqu əlçatan saxlayır — kəsinti sizə yalnız aktuallıq baxımından təsir edir. Modellər və kombinasiyalar daxil olan kimi dərc edilir; avtomatik kombinasiyalar, provayder siyahısı və zənginləşdirmə üst qatı hazır olduqca əlavə edilir, beləliklə, bir yavaş son nöqtə bütün seçim alətinin işini dayandıra bilməz.

Adlar şlüzün bildiyi məlumatları ehtiva edir: modelin yönləndirildiyi yuxarı axın provayderini, `[Free]` işarəsini və onunla birlikdə gələn büdcəni — beləliklə, eyni modeli satan iki bağlantını bir-birindən ayırmaq mümkün olur. Prefiksi söndürmək üçün `"providerTag": false` təyin edin.

Əl ilə yeniləmə əmri yoxdur: OpenCode v2 əmrləri geri çağırışlar deyil, sorğu şablonlarıdır, buna görə də plagin belə bir əmri təqdim edə bilməz. Yeniləmələr TTL əsasında aparılır; hostdan yalnız kataloq və ya üst qat həqiqətən dəyişdikdə yenidən yükləmə tələb olunur, hər yeniləmədə deyil.

## Gemini-də alət çağırışı

Gemini, alət bəyanlarında `$schema` və ya `additionalProperties` olan bütöv sorğunu rədd edərək `400 INVALID_ARGUMENT` cavabını verir. Plagin bu açar sözləri həmin provayderin Gemini modelinə göndərilən alət sxemlərindən çıxarır və bütün digər sorğulara toxunmur. `$ref` ehtiva edən alət dəyişdirilmədən ötürülür, çünki istinadın silinməsi sxemi «hər şeyi qəbul et» səviyyəsinə qədər genişləndirərdi.
Bunu söndürmək üçün `"geminiSanitization": false` təyin edin.

## Problemlərin aradan qaldırılması

| Əlamət                                                       | Səbəb                                                                                                                   |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| Seçim aləti heç bir OmniRoute modeli göstərmir               | Heç bir açar müəyyən edilməyib (başlanğıc xəbərdarlığını yoxlayın) və ya şlüz əlçatmazdır                               |
| Xam model identifikatorları, kombinasiya və qiymətlər yoxdur | İdarəetmə son nöqtələri tokeni rədd edib — `managementReadToken` təyin edin                                             |
| Sessiya `opencode-<id>/…` ünvanına bərkidilib                | v1 plagini `opencode-<id>` dərc edirdi; v2 isə çılpaq `<id>` dərc edir, buna görə modeli `<id>/…` altında yenidən seçin |
