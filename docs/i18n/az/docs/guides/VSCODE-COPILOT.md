**OmniCopilot** OmniRoute tərəfindən təqdim edilən bütün modelləri _birbaşa_ GitHub Copilot Chat-in
model seçicisinə əlavə edir. İkinci yan panel və ayrıca söhbət interfeysi yoxdur — Copilot-un agent rejimi, alət çağırışları,
MCP serverləri və fərdi təlimatları işləməyə davam edir, sadəcə seçdiyiniz modeldə çalışır.

## Quraşdırma

1. **OmniRoute-u işə salın** — `npm install -g omniroute && omniroute` (idarəetmə paneli `http://localhost:20128` ünvanındadır).
2. **Genişlənməni quraşdırın** — Extensions görünüşündə "OmniRoute" axtarın.
3. **Model seçin** — Copilot Chat → model seçicisi → **Manage Models…** → **OmniRoute**, sonra
   istədiklərinizi işarələyin.

OmniRoute standart portda işləyərkən heç nə konfiqurasiya etməyə ehtiyac yoxdur. Uzaq instansiya üçün
**Activity Bar-da OmniRoute ikonunu** açın (və ya `OmniRoute: Manage Connection` əmrini işlədin) və bunları təyin edin:

- **Server URL-i** — serverin kök ünvanı, məsələn, `http://192.168.0.15:20128`. `/v1` suffiksi
  genişlənmə tərəfindən əlavə edilir; onu daxil etməyin.
- **API açarı** — yalnız server `REQUIRE_API_KEY` təyin etdikdə. VS
  Code SecretStorage vasitəsilə əməliyyat sisteminin açarlar zəncirində saxlanılır, heç vaxt `settings.json` daxilində saxlanılmır.

## Seçicidə nələr göstəriləcək

Genişlənmə xam `GET /v1/models` cavabını göstərmir — onu formalaşdırır və gördüyünüz say
iki məqsədli səbəbə görə kataloqun ölçüsündən azdır.

### Hər model üçün bir id tələb edir

`MODELS_CATALOG_PREFIX_MODE` standart olaraq **`dual`** dəyərinə malikdir və bu, hər modeli iki dəfə — bir dəfə
qısa ləqəb prefiksi, bir dəfə isə kanonik provayder prefiksi ilə — təqdim edir ki, köhnə klient
konfiqurasiyaları hər iki formanı müəyyən edə bilsin:

```
cc/claude-sonnet-4-6        ← ləqəb prefiksi
claude/claude-sonnet-4-6    ← kanonik prefiks, eyni model
```

Genişlənmə **`GET /v1/models?prefix=alias`** sorğusunu göndərir ki, digər klientləriniz üçün
server üzrə ümumi parametri dəyişdirmədən hər modelə bir id əldə etsin. Nümunə instansiyada bu,
**2345 qeydi 1396-ya endirdi — 949 dublikat, itirilən model sayı sıfır.**

Bunu _hər_ klient üçün server üzrə düzəltmək istəyirsinizsə, idarəetmə panelində
`MODELS_CATALOG_PREFIX_MODE` funksiya bayrağını `alias` olaraq təyin edin. Sorğu parametri və
hər rejim üzrə cədvəl üçün [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) bölməsinə baxın.

### Söhbət edə bilməyən modelləri gizlədir

Kataloqda həmçinin şəkil, video, audio, yenidən sıralama, embedding və moderasiya modelləri sadalanır. Bunlar
onsuz da söhbət sorğusunda rədd edilir:

```
HTTP 400 — '<id>' modeli şəkil yaratma modelidir və
/v1/chat/completions ilə istifadə edilə bilməz. Əvəzində POST /v1/images/generations istifadə edin.
```

buna görə də onlar seçiciyə çatmazdan əvvəl `type` sahəsinə əsasən filtrlənir. **Responses-API
modelləri saxlanılır** — hər Codex / GPT-5.x qeydi `supported_endpoints: ["responses"]` təqdim edir
və OmniRoute onları `/v1/chat/completions` üçün çevirir, buna görə də onlar tam istifadə oluna bilir.

### Heç vaxt konfiqurasiya etmədiyiniz provayderlər

Kataloqda **aktiv bağlantısı** olan provayderlərin modelləri və bütün **noAuth**
provayderləri — pulsuz səviyyənin böyük hissəsini təşkil edən açarsız provayderlər — sadalanır. Bu, qəsdən belədir. Onları gizlətmək üçün
idarəetmə panelinin parametrlərində `blockedProviders` siyahısına əlavə edin; genişlənmədə heç nə dəyişmir.

## VS Code vərəqində idarə paneli

`omnicopilot.dashboardOpen: "editor"` OmniRoute idarə panelini xarici brauzer əvəzinə Simple Browser vasitəsilə redaktor vərəqində göstərir. Daxiletmə **serverdə könüllü aktivləşdirilir**:
`DASHBOARD_ALLOW_EMBED=vscode`. Bu parametr HTML səhifələrini standart `frame-ancestors 'none'` +
`X-Frame-Options: DENY` əvəzinə `frame-ancestors 'self' vscode-webview:` ilə təqdim edir. API səthi (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) hər iki halda sərt başlıqları saxlayır.

> ⚠️ **Bu, icra vaxtı deyil, yığma vaxtı parametridir.** Next.js `headers()` funksiyasını marşrut manifestinə kompilyasiya edir, buna görə də `next.config.mjs` dəyişəni paket yığılarkən oxuyur
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Dəyişəni artıq yığılmış serveri işə salmazdan əvvəl ixrac etmək heç nəyi dəyişmir — başlıqlar əvvəlcədən yığmaya daxil edilib.

```bash
# dəyişən BUILD əmrində mövcud olmalıdır
DASHBOARD_ALLOW_EMBED=vscode npm run build        # və ya npm run build:release
npm start
```

| Quraşdırma üsulu           | Daxiletməni aktivləşdirə bilərsiniz?                                                                                                                |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mənbə kodundan             | ✅ yuxarıda göstərildiyi kimi, dəyişəni yığma əmrində təyin edin                                                                                    |
| `npm install -g omniroute` | ❌ dərc edilmiş paket əvvəlcədən yığılmış paketlə gəlir — bunun əvəzinə mənbə kodundan yığın                                                        |
| Docker obrazı              | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — Docker Hub-dakı əvvəlcədən yığılmış obrazda daxiletmə aktiv deyil |

Daxiletmənin aktiv olduğu yığma olmadan səhifə çərçivədə göstərilməkdən imtina edir. Genişləndirmə bunu cavab başlıqlarından aşkarlayır və xarici brauzerə keçir — heç nə pozulmur və bu barədə bir dəfə məlumat verilir.
[`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) sənədinə və
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273) məsələsinə baxın.

## Problemlərin aradan qaldırılması

| Əlamət                                                     | Səbəb / həll                                                                                                                                                                                                                                                            |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Seçicidə OmniRoute modelləri yoxdur                        | Server əlçatan deyil. Status panelindəki nöqtə boz rəngə çevrilir; `OmniRoute: Check Connection` əmrini işə salın. Aşkarlama məqsədli şəkildə səssizdir və sorğu göstərmək əvəzinə heç bir model təqdim etmir.                                                          |
| Hər model iki dəfə görünür                                 | OmniCopilot versiyanız 1.0.1-dən köhnədir — yeniləyin. Genişləndirmə artıq `?prefix=alias` tələb edir.                                                                                                                                                                  |
| Əvvəllər siyahıda olan şəkil/audio modeli yoxa çıxıb       | Bu, 1.0.1 versiyasından etibarən qəsdən belədir — həmin model heç vaxt çat sorğusuna cavab verə bilmirdi.                                                                                                                                                               |
| Panel Activity Bar-da yoxdur                               | VS Code əlavə görünüş konteynerlərini Activity Bar-ın aşağısındakı **"…"** daşma menyusuna köçürür və sağ kliklə gizlədilmiş konteyner gizli qalır. Activity Bar-a sağ klikləyin → **OmniRoute** seçimini işarələyin və ya onu `OmniRoute: Manage Connection` ilə açın. |
| `editor` rejiminə baxmayaraq idarə paneli brauzerdə açılır | Server `DASHBOARD_ALLOW_EMBED=vscode` ilə **yığılmayıb** (yuxarıya baxın) — əvvəlcədən yığılmış quraşdırmada bunu işəsalma zamanı təyin etmək heç nəyi dəyişmir. Xarici brauzerə keçid məqsədlidir.                                                                     |
| Provayderləri dəyişdikdən sonra model siyahısı köhnə qalır | `OmniRoute: Refresh Models` əmrini və ya paneldəki ↻ keçidini istifadə edin.                                                                                                                                                                                            |
