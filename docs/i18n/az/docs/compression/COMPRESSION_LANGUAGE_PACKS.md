Caveman sıxışdırması daxili ingilis dili qaydalarına əlavə olaraq dilə xas qayda paketlərini yükləyə bilər.
Bu, əsas mühərriki sabit saxlayır, eyni zamanda portuqal, ispan, alman, fransız, italyan, yapon və
gələcək dil paketlərinin müstəqil şəkildə təkmilləşməsinə imkan verir.

## Yerləşmə

Dil paketləri aşağıdakı qovluqda yerləşir:

```txt
open-sse/services/compression/rules/<language>/
```

Hazırda təqdim olunan paketlər (`rules/` qovluğunun məzmunu ilə yoxlanılıb):

| Dil                       | Qovluq         | Mövcud qayda kateqoriyaları                         |
| ------------------------- | -------------- | --------------------------------------------------- |
| İngilis dili              | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| İspan dili                | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portuqal dili (Braziliya) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| İndoneziya dili           | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| İtalyan dili              | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Alman dili                | `rules/de/`    | `context`, `filler`, `structural`                   |
| Fransız dili              | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Yapon dili                | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Uyğunluq qeydi:** `en`, `es`, `pt-BR`, `id` və `it` paketləri tam 5 kateqoriyaya malikdir; `de`, `fr`, `ja` isə 3 kateqoriya ilə təqdim olunur. Çatışmayan `dedup` və `ultra` kateqoriyaları səssiz şəkildə daxili ingilis dili qaydalarına geri qayıdır. Daha kiçik paketlərə `dedup.json` və `ultra.json` əlavə etmək üçün töhfələr qəbul olunur.
>
> `pt-BR` paketi Lenine Júnior tərəfindən hazırlanmış **[Troglodita](https://github.com/leninejunior/troglodita)** layihəsinə əsaslanır — bu, Braziliya portuqal dilinin qrammatikası üçün sıfırdan hazırlanmış sıxışdırma sistemidir (pleonazmların azaldılması, PT-BR doldurucu ifadələrinin silinməsi, Braziliya proqramçı icması üçün texniki qısaltmalar).
>
> Kanonik kateqoriya siyahısı və hər kateqoriya üzrə sxem [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) faylında yerləşir (JSON Schema layihəsi 2020-12).

## Dilin Aşkarlanması

`languageDetector.ts` sorğu mətninin dilini müəyyən etmək üçün yüngül evristikalardan istifadə edir.
Konfiqurasiya edilmiş standart dilə yenə də riayət olunur və dəqiq idarəetmə tələb edildikdə aşkarlama
konfiqurasiya vasitəsilə deaktiv edilə bilər.

Aşkarlama nəticəsi yalnız qayda paketlərini seçmək üçün istifadə olunur. Bu, provayder marşrutlaşdırmasını,
lokal seçimini və ya istifadəçi interfeysinin dilini dəyişmir.

## Konfiqurasiya Strukturu

Sıxışdırma parametrlərinə aşağıdakılar daxil edilə bilər:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` idarəetmə paneli/önizləmə üçün standart dəyərləri idarə edir. `cavemanConfig` isə
Caveman mesaj mətnini sıxışdırarkən istifadə olunan icra zamanı mühərrik konfiqurasiyasıdır.

## Dil Paketinin Əlavə Edilməsi

1. `open-sse/services/compression/rules/<language>/<pack>.json` faylını yaradın.
2. `docs/compression/COMPRESSION_RULES_FORMAT.md` sənədindəki Caveman qayda formatından istifadə edin.
3. Əvəzləmələri ehtiyatla tətbiq edin və kodu, identifikatorları, URL-ləri və ya JSON-u dəyişdirməyin.
4. Dil seçimi və əvəzləmə davranışı üçün testlər əlavə edin və ya mövcud testləri yeniləyin.
5. Dil UI selektorlarında görünürsə, yeni dashboard/i18n etiketlərini əlçatan edin.

## API

Mövcud paketləri aşağıdakı sorğu ilə əldə etmək olar:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Önizləmə son nöqtəsi dil konfiqurasiyası əvəzləmələrini qəbul edir:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Bütün 6 dil paketi v3.8.0 versiyasında hər bir Caveman intensivliyində (LITE, FULL, ULTRA) tətbiq edilən `SHARED_BOUNDARIES` bəndini aldı. Bu bənd mühərrikə ətrafdakı doldurucu mətnin silinməsindən asılı olmayaraq, aşağıdakı nümunələri olduğu kimi qorumağı bildirir:

| Nümunə növü                   | Nümunə                                 |
| ----------------------------- | -------------------------------------- |
| Çərçivələnmiş kod blokları    | ` ```python\n...\n``` `                |
| Sətirdaxili kod               | `` `my_var` ``                         |
| URL-lər                       | `https://example.com/path`             |
| Fayl yolları (mütləq + nisbi) | `/etc/hosts`, `./src/index.ts`         |
| Xəta başlıqları               | `Error:`, `TypeError:`, `SyntaxError:` |
| Stek izi sətirləri            | `  at functionName (file.ts:12:3)`     |

Bu nümunələr `DEFAULT_CAVEMAN_CONFIG.preservePatterns` daxilində yerləşdirilir (əvvəllər `[]` idi). Sabit `open-sse/services/compression/types.ts` faylında yerləşir.

### Bu niyə vacibdir

SHARED_BOUNDARIES olmadan aqressiv Caveman rejimləri təkrarlanan mətn kimi görünən, lakin əslində kod fraqmenti, fayl yolu və ya xəta steki olan məzmunu silə bilərdi. SHARED_BOUNDARIES doldurucu qaydalar icra edilməzdən əvvəl tətbiq olunan, dildən asılı olmayan təhlükəsizlik mexanizmi kimi fəaliyyət göstərir.

### preservePatterns fərdiləşdirilməsi

Sıxışdırma parametrləri vasitəsilə icra zamanı əlavə nümunələr daxil edilə bilər:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Fərdi nümunələr 6 standart nümunəni əvəz etmir, onları genişləndirir.

## Əməliyyat Qeydləri

- Dil paketi olmadıqda daxili ingilis dili qaydaları ehtiyat variant kimi qalır.
- Etibarsız daxili JSON paketləri doğrulamadan keçmir ki, buraxılış resurslarının keyfiyyəti xəbərdarlıq edilmədən aşağı düşməsin.
- Qayda paketləri yalnız verilənlərdən ibarətdir və kod import etməməli və ya ixtiyari məntiq icra etməməlidir.
- Sıxışdırma analitikası qatı tam sorğu mətnini deyil, seçilmiş rejimi və mühərriki qeydə alır.
