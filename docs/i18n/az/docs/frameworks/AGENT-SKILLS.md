> **Əsas həqiqət mənbəyi:** `src/lib/agentSkills/` (kataloq, generator, parserlər) + `skills/` qovluğu (SKILL.md faylları)
> **Son yenilənmə:** 2026-08-02 — v3.8.50

Agent Skills xarici agentlərə, MCP klientlərinə və A2A orkestratorlarına OmniRoute-un REST API və CLI interfeysindən necə istifadə etməyi öyrədən strukturlaşdırılmış SKILL.md fayllarıdır. [Omni Skills](./SKILLS.md)-dən (OmniRoute daxilində icra edilən LLM alət tərifləri) fərqli olaraq, Agent Skills _sənədləşdirmə kataloqudur_ — birbaşa agent kontekstinə ötürülə bilən statik markdown məzmunudur.

---

## İcmal

Kataloqda **45 Agent Skill** (23 REST API + 21 CLI + 1 konfiqurasiya iş axını) mövcuddur. Hər skill aşağıdakılara malikdir:

- **Kanonik ID** (`omni-auth`, `cli-serve` və s.)
- `skills/{id}/SKILL.md` daxilində YAML ön məlumatı (`name`, `description`) + zəngin markdown məzmunu olan **SKILL.md** faylı
- OpenAPI spesifikasiyası və CLI reyestrindən əldə edilən **REST son nöqtələri** (API skill-ləri) və ya **CLI alt əmrləri** (CLI skill-ləri)
- Canlı yükləmə üçün **GitHub xam URL-i**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## SKILL.md Formatı

```markdown
---
name: omni-providers
description: "Provayder bağlantılarını idarə edin: etimadnamələri əlavə edin, sınaqdan keçirin, rotasiya edin və silin."
---

<!-- src/lib/agentSkills/generator.ts tərəfindən generasiya edilib; əl ilə edilən dəyişikliklərin üzərinə yazılacaq -->

## İcmal

...

## Autentifikasiya

...

## Son nöqtələr

...

<!-- skill:custom-start -->

## Fərdi Bölmə (təkrar generasiya zamanı qorunur)

...

<!-- skill:custom-end -->
```

Generator təkrar generasiya zamanı `<!-- skill:custom-start -->` və `<!-- skill:custom-end -->` arasındakı məzmunu qoruyur. On skill üçün seçilmiş fərdi bloklar mövcuddur:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## REST API aşkarlanması

| Son nöqtə                    | Metod | Təsvir                                                                       | Avtorizasiya |
| :--------------------------- | :---- | :--------------------------------------------------------------------------- | :----------- |
| `/api/agent-skills`          | GET   | Kataloqu siyahıya al (istəyə bağlı `?category=api\|cli\|config&area=<area>`) | yoxdur       |
| `/api/agent-skills/{id}`     | GET   | Tək bacarığın metadatasını əldə et                                           | yoxdur       |
| `/api/agent-skills/{id}/raw` | GET   | SKILL.md faylını `text/markdown` kimi əldə et                                | yoxdur       |
| `/api/agent-skills/coverage` | GET   | Əhatə statistikası (neçə SKILL.md faylının mövcud olduğu)                    | yoxdur       |
| `/api/agent-skills/generate` | POST  | Generatoru işə sal (dryRun/prune/onlyIds)                                    | idarəetmə    |

Nümunə — bütün API bacarıqlarını siyahıya almaq:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Nümunə — tək bir SKILL.md faylını əldə etmək:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## A2A aşkarlanması

A2A `list-capabilities` bacarığı 45 bacarıqdan ibarət tam kataloqu markdown cədvəli artefaktı kimi qaytarır. Xarici orkestratorlar onu aşağıdakı qaydada çağıra bilər:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "Bütün imkanları siyahıya al" }]
  }
}
```

Protokol təfərrüatları üçün [A2A-SERVER.md](./A2A-SERVER.md) sənədinə baxın.

## Xarici agentlər bacarıqlardan necə istifadə edir

### 1. REST vasitəsilə aşkarlama

```bash
# Tam kataloqu əldə edin
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Kontekst inyeksiyası üçün SKILL.md faylını əldə edin
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP vasitəsilə aşkarlama

```typescript
// Claude Desktop / Cursor MCP müştərisində:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → hər biri üçün rawUrl olan AgentSkill massivi
```

### 3. A2A vasitəsilə aşkarlama

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table bütün 45 bacarıq ID-si və rawUrl sütunları olan markdown cədvəlidir
```

### 4. Birbaşa GitHub xam məzmununun əldə edilməsi (server tələb olunmur)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generator

Generator xüsusi hazırlanmış kataloqu, OpenAPI spesifikasiyasını və CLI reyestrini oxuyur və hər bir qeyd üçün `skills/{id}/SKILL.md` faylını yaradır:

```bash
# Önizləmə (sınaq icrası, heç nə yazılmır)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Tam yenidən generasiya
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Xüsusi ID-ləri yenidən generasiya edin
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Generatorun cavabı `GeneratorReport` obyektidir:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
