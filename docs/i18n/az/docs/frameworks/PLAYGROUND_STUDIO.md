## Ümumi baxış

Playground Studio `/dashboard/playground` səhifəsini sadə Monaco əsaslı redaktordan
tam funksional sınaq iş məkanına çevirir. O, köhnə `page.tsx` faylını dörd tab və ortaq konfiqurasiya paneli göstərən `PlaygroundStudio`
örtüyü ilə əvəz edir.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Söhbət] [⚖ Müqayisə] [{} API] [🔧 Qur]    142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {aktiv tabın məzmunu}                   │ ─ Konfiqurasiya           │
│                                          │ Son nöqtə [chat ∨]        │
│                                          │ Model     [gpt-5.4 ∨]     │
│                                          │ Sistem    [mətn sahəsi]   │
│                                          │ Temp.     ▕▕▔▔ 0.7        │
│                                          │ Şablonlar [▾ yüklə][saxla]│
│                                          │ [✨ Sorğunu təkmilləşdir] │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Tablar

### Söhbət tabı

`ChatPlayground.tsx` faylını çoxgedişli axınlı iş mühitinə çevirir:

- `MarkdownMessage.tsx` vasitəsilə Markdown-un tam göstərilməsi (kod blokları, cədvəllər, siyahılar, keçidlər).
- Sistem sorğusu ortaq Konfiqurasiya panelindən əldə edilir.
- Hər mesaj üzrə token/xərc (sorğu + tamamlama tokenləri).
- Son cavabı yenidən yaratmaq.
- SSE axını ilə `POST /v1/chat/completions` ünvanına göndərir.

### Müqayisə tabı

Proksi üçün əsas fərqləndirici xüsusiyyət: 1 sorğunu paralel şəkildə **4 modelə qədər** icra etmək.

- Hər biri `/v1/chat/completions` ünvanından müstəqil şəkildə axın alan 4-ə qədər sütun.
- Sütun əlavə etmək üçün `+ Model əlavə et` düyməsi (Cmd+K qısayolu).
- `Hamısını işə sal ▶` bütün axınları `Promise.all` və hər sütun üçün ayrıca `AbortController` vasitəsilə eyni anda başladır.
- Ümumi **Hamısını ləğv et** əmri davam edən bütün axınları dayandırır.
- Hər sütundakı `ProviderMetrics` real vaxt rejimində TTFT, TPS, tokenləri və təxmini xərci göstərir.
- Metriklər **"müştəri tərəfində təxmin"** (D12) kimi işarələnir — ilk SSE fraqmentindən etibarən ölçülür.

### API tabı

Təcrübəli istifadəçilər üçün orijinal Monaco redaktorunu 100% qoruyur (D14):

- 10 son nöqtə: söhbət tamamlamaları, tamamlamalar, yerləşdirmələr, şəkillər, audio, nitq, transkripsiyalar, moderasiyalar, yenidən sıralama, axtarış.
- Multimodal fayl yükləmə.
- Real vaxt çıxışı ilə SSE axını.
- `ApiTab.tsx` kimi əhatələnib (tənbəl yüklənir, `ssr: false`).

### Qurma tabı

Alətlər/funksiya çağırışı və strukturlaşdırılmış çıxış interfeysi:

- `ToolsBuilder.tsx` — hər alət üçün JSON sxemi redaktoru ilə `tools[]` elementlərini əlavə etmək/redaktə etmək/silmək.
  Parametrləri `ToolDefinitionSchema` (Zod) vasitəsilə yoxlayır.
- `StructuredOutputEditor.tsx` — JSON rejimini aktivləşdirmək/deaktivləşdirmək + JSON sxemi redaktoru.
  Cavabı `StructuredOutputSchema` (Zod) vasitəsilə sxemə uyğun yoxlayır.
- Sorğunu `tools[]` və/və ya `response_format` ilə `/v1/chat/completions` ünvanına göndərir.

## Konfiqurasiya Paneli (Ortaq)

`StudioConfigPane.tsx` — həmişə görünür, yığıla bilir.

| Sahə                | Komponent             | Qeydlər                                                                               |
| ------------------- | --------------------- | ------------------------------------------------------------------------------------- |
| Son nöqtə           | `<select>`            | `PlaygroundEndpoint` ilə uyğun gələn 10 seçim                                         |
| Model               | `<input>`             | sərbəst mətn, məsələn, `openai/gpt-4o`                                                |
| Sistem promptu      | `<textarea>`          | bütün tablara ötürülür                                                                |
| Parametrlər         | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop                |
| Presetlər           | `PresetPicker`        | adlandırılmış konfiqurasiya görüntülərini yükləyir/saxlayır (DB-də qalıcı saxlanılır) |
| Promptu yaxşılaşdır | `ImprovePromptButton` | kvota xəbərdarlığı modalını açır, `/api/playground/improve-prompt` ünvanını çağırır   |

Vəziyyət `PlaygroundStudio.tsx` komponentinə qaldırılır və bütün tablara ötürülür. Tablar arasında keçid
konfiqurasiya vəziyyətini qoruyur.

## Üst Panel

`StudioTopBar.tsx`:

- Tab dəyişdiricisi (role="tablist").
- `TokenCostCounter` — canlı token (↑/↓) və təxmini xərc göstəricisi.
- Kodu ixrac etmə düyməsi (`</>`) — `ExportCodeModal` modalını açır.

## Kodu İxrac Etmə Modalı

`ExportCodeModal.tsx` cari `PlaygroundState` əsasında curl / Python / TypeScript fraqmentləri
yaratmaq üçün `codeExport.ts` faylından istifadə edir. API açarı yer tutucusu həmişə `$OMNIROUTE_API_KEY` olur (D11).

---

## Prompt Yaxşılaşdırıcısı

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Modal "kvota sərf olunacaq" xəbərdarlığını göstərir.
2. Təsdiqləndikdə, marşruta `{ system, prompt, model, tone }` göndərir.
3. Marşrut daxildə `promptImprover.META_SYSTEM_PROMPT` ilə `/v1/chat/completions` çağırır.
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` qaytarır.
5. UI Konfiqurasiya panelinin sistem promptunu və Söhbət tabının istifadəçi promptunu yeniləyir.

---

## Presetlər

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- `playground_presets` SQLite cədvəlində saxlanılır (miqrasiya: `084_playground_presets.sql`).
- Hər preset bunları saxlayır: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: `GET` siyahı, `POST` yaratma, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Axın Metrikaları

`useStreamMetrics.ts` + `streamMetrics.ts` (təmiz funksiya):

- `start()` — sorğunun başlama vaxtını qeydə alır.
- `onFirstChunk()` — TTFT-ni qeydə alır.
- `onChunk(n)` — tamamlama tokenlərinin sayını toplayır.
- `finish(usage?)` — yekun metrikaları hesablayır: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Qiymətlər `src/lib/playground/types.ts` daxilindəki statik cədvəldən götürülür ("təxmini" kimi işarələnib — D13).

## Backend Marşrutları

| Metod    | Yol                              | Emalçı                                                                                                   |
| -------- | -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | `ImprovePromptRequestSchema` ilə Zod validasiyası aparır; meta-prompt ilə `/v1/chat/completions` çağırır |
| `GET`    | `/api/playground/presets`        | `{ presets: PlaygroundPresetListItem[] }` qaytarır                                                       |
| `POST`   | `/api/playground/presets`        | Preset yaradır; `PlaygroundPresetCreateSchema` ilə validasiya edir                                       |
| `GET`    | `/api/playground/presets/:id`    | Bir preset və ya 404 qaytarır                                                                            |
| `PUT`    | `/api/playground/presets/:id`    | Qismən yeniləmə                                                                                          |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                      |

Autentifikasiya: istəyə bağlıdır (`REQUIRE_API_KEY`). Xətalar `buildErrorBody()` vasitəsilə qaytarılır (Sərt Qayda #12).

## Nasazlıqların aradan qaldırılması

| Əlamət                                      | Səbəb                                   | Həll yolu                                                                                                          |
| ------------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Monaco redaktoru API vərəqində görünmür     | SSR Monaco-nu yükləyib                  | `ApiTab` komponentinin `dynamic(..., { ssr: false })` istifadə etdiyini yoxlayın                                   |
| Müqayisə axınları ardıcıl işə düşür         | `Promise.all` yanlış istifadə olunur    | Bütün axın başladılmaları bir `Promise.all` çağırışında göndərilməlidir                                            |

| İxrac edilən kod `MISSING_API_KEY` göstərir | Doldurucu əlavə edilməyib               | `codeExport.ts` həmişə `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"` istifadə edir                                  |
