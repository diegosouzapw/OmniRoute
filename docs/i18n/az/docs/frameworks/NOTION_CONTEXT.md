> **Əsas mənbə:** `src/lib/notion/api.ts` (REST klienti), `src/lib/db/notion.ts`
> (tokenun saxlanması), `open-sse/mcp-server/tools/notionTools.ts` (6 MCP aləti),
> `src/app/api/settings/notion/route.ts` (parametrlər API-si). Alətlərin qeydiyyatı və əhatə dairələrinin
> əlaqələndirilməsi `open-sse/mcp-server/server.ts` faylında yerləşir.

## Bu nədir

OmniRoute **Notion** iş sahəsinə **kontekst mənbəyi** kimi — agentlərin daxili MCP serveri
vasitəsilə istifadə etdiyi oxuma/yazma imkanlı bilik bazası kimi qoşula bilər. Notion
inteqrasiya tokeni konfiqurasiya edildikdən sonra MCP alətləri LLM-ə səhifələrdə və verilənlər
bazalarında axtarış aparmağa, səhifə məzmununu və blok ağaclarını oxumağa, verilənlər bazalarını
filtrlər/çeşidləmələr ilə sorğulamağa və yeni bloklar əlavə etməyə imkan verir — bütün bunlar
OmniRoute üzərindən proksi edilir (təkrar cəhd, vaxt məhdudiyyəti və xətaların təsnifatı ilə),
beləliklə model heç vaxt birbaşa Notion API-yə müraciət etmir.

İnteqrasiya rəsmi Notion REST API-si
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) üzərində qurulmuş yığcam və
möhkəmləndirilmiş örtükdür. Klient (`src/lib/notion/api.ts`) aşağıdakıları əlavə edir:

- `429` və `5xx` üçün **eksponensial gecikmə ilə təkrar cəhd** (3 cəhdədək).
- `AbortController` vasitəsilə **55 saniyəlik sorğu vaxt məhdudiyyəti**.
- **Tipləşdirilmiş xəta təsnifatı** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  göstərişlərini nəzərə alır), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- İstifadəçiyə göstərilməzdən əvvəl stek izi tipli fraqmentləri silən **mesaj təmizlənməsi**.

## Quraşdırma

Notion tokeni üçün **mühit dəyişəni yoxdur** — o,
`src/lib/db/notion.ts` vasitəsilə SQLite `key_value` cədvəlində (ad sahəsi `notion`,
açar `integration_token`) saxlanılır. Onu Endpoint idarəetmə panelinin
**Kontekst Mənbələri** tabından (`ObsidianSourceCard` komponentinin qonşusu olan
`NotionSourceCard`) və ya parametrlər REST API-si vasitəsilə konfiqurasiya edin.

> [!NOTE]
> Token **Notion daxili inteqrasiya tokenidir**. <https://www.notion.com/my-integrations>
> ünvanında inteqrasiya yaradın, sonra OmniRoute-un giriş əldə etməsini istədiyiniz
> səhifələri/verilənlər bazalarını həmin inteqrasiya ilə paylaşın (Notion-un icazə modeli
> bütün iş sahəsini deyil, paylaşımı əsas götürür).

### REST vasitəsilə konfiqurasiya

```bash
# İnteqrasiya tokenini saxlayın və doğrulayın (POST sınaq axtarışı göndərərək doğrulayır)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# Bağlantı statusunu yoxlayın
curl http://localhost:20128/api/settings/notion

# Bağlantını kəsin (saxlanmış tokeni təmizləyir)
curl -X DELETE http://localhost:20128/api/settings/notion
```

Hər üç metod idarəetmə paneli autentifikasiyasını (`isAuthenticated`) tələb edir. `POST`
zamanı OmniRoute tokeni saxlayır və dərhal 1 nəticəli sınaq axtarışı başladır; Notion
xəta obyekti qaytararsa, token təmizlənir və çağırış `400` ilə uğursuz olur.

## MCP alətləri (6)

`open-sse/mcp-server/tools/notionTools.ts` faylında müəyyən edilib. Token çağırış
zamanı `getNotionToken()` vasitəsilə əldə edilir; heç biri konfiqurasiya edilməyibsə,
alət `"Notion integration token not configured. Set it in Settings > Context Sources."`
xətasını yaradır.

| Alət                         | Əhatə dairəsi  | Təsvir                                                                                                                         |
| ---------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `notion_search`              | `read:notion`  | Mətn sorğusu ilə səhifələrdə və verilənlər bazalarında axtarış aparır (başlıqları, ID-ləri və URL-ləri qaytarır). Səhifələnir. |
| `notion_get_page`            | `read:notion`  | Səhifənin məzmununu və metadatasını ID-si ilə əldə edir.                                                                       |
| `notion_list_block_children` | `read:notion`  | Blokun və ya səhifənin bütün alt bloklarını (blok ağacını) sadalayır. Səhifələnir.                                             |
| `notion_query_database`      | `read:notion`  | Verilənlər bazasını istəyə bağlı `filter` + `sorts` ilə sorğulayır (Notion API formatı). Səhifələnir.                          |
| `notion_get_database`        | `read:notion`  | Verilənlər bazasının sxemini/metadatasını ID ilə əldə edir.                                                                    |
| `notion_append_blocks`       | `write:notion` | Mövcud bloka və ya səhifəyə alt bloklar əlavə edir (hər sorğu üçün maksimum 100 blok).                                         |

### Giriş parametrləri

- `notion_search` — `query` (1–500 simvol), `pageSize` (1–100, standart 20),
  `startCursor` (istəyə bağlı).
- `notion_get_page` — `pageId` (32 simvolluq onaltılıq dəyər və ya UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, standart 50),
  `startCursor` (istəyə bağlı).
- `notion_query_database` — `databaseId`, `filter` (istəyə bağlı, Notion filtr formatı),
  `sorts` (istəyə bağlı massiv), `pageSize` (1–100, standart 50), `startCursor` (istəyə bağlı).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (blok obyektləri massivi),
  `after` (istəyə bağlı mövqe).

### Əhatə dairələri

Oxuma alətləri `read:notion`, yazma aləti isə `write:notion` tələb edir.
Əhatə dairələri `open-sse/mcp-server/server.ts` faylındakı `withScopeEnforcement()`
tərəfindən yalnız `OMNIROUTE_MCP_ENFORCE_SCOPES=true` olduqda tətbiq edilir;
çağıranın icazə verilmiş əhatə dairələri `OMNIROUTE_MCP_SCOPES` dəyişənindən
(vergüllə ayrılmış) və ya autentifikasiya edilmiş API açarının əhatə dairəsi
kontekstindən əldə edilir. Tam əhatə dairəsi modeli üçün
[MCP-SERVER.md](./MCP-SERVER.md) sənədinə baxın.

## Son nöqtələr

| Metod    | Yol                    | Məqsəd                                     |
| -------- | ---------------------- | ------------------------------------------ |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` qaytarır.        |
| `POST`   | `/api/settings/notion` | İnteqrasiya tokenini saxlayır və yoxlayır. |

## İstifadə halları

- **Biliklərə əsaslanan cavablar** — agentə cavab verməzdən əvvəl iş məkanında `notion_search`
  ilə axtarış etməyə və ən uyğun nəticəni `notion_get_page` ilə əldə etməyə imkan verin ki,
  cavablarda real daxili sənədlərə istinad edilsin.
- **Verilənlər bazasına əsaslanan iş axınları** — tapşırıqlar/CRM verilənlər bazasını filtrlər
  və çeşidləmə ilə `notion_query_database` vasitəsilə sorğulayın, sonra sətirləri ümumiləşdirin
  və ya prioritetləşdirin.
- **Geri yazma / jurnallaşdırma** — görüş qeydlərini, icra xülasələrini və ya agentin çıxışını
  mövcud səhifəyə əlavə etmək üçün `notion_append_blocks` istifadə edin (yalnız əlavəetmə;
  dağıdıcı redaktələr yoxdur).
- **Strukturun araşdırılması** — səhifənin blok ağacını nəzərdən keçirmək üçün
  `notion_list_block_children`, yaxud sorğulamadan əvvəl verilənlər bazasının xassələr sxemini
  öyrənmək üçün `notion_get_database` istifadə edin.
