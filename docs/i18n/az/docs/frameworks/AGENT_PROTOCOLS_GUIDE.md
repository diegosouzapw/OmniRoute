> **Mənbə:** `src/lib/{a2a,acp,cloudAgent}/`, `src/app/api/{a2a,acp,cloud}/`, `src/app/api/v1/agents/`
> **Son yenilənmə:** 2026-06-28 — v3.8.40

OmniRoute agentlərlə əlaqəli üç fərqli interfeys təqdim edir. İlk baxışda oxşar görünsələr də, fərqli problemləri həll edirlər. Uyğun olanı seçmək üçün bu səhifədən istifadə edin.

## Qısa xülasə

| İnterfeys                        | Ən uyğun istifadə sahəsi                                                                                                                                                   | Nəqliyyat                                               | Standart                      |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | ----------------------------- |
| **A2A — Agentdən agentə**        | A2A protokolundan istifadə edən həmkar agentlərlə agentlərarası əməkdaşlıq                                                                                                 | HTTP üzərindən JSON-RPC 2.0                             | A2A v0.3 (açıq spesifikasiya) |
| **ACP — CLI Agentləri Reyestri** | İstifadəçinin cihazında quraşdırılmış CLI proqramlaşdırma agentlərini (Cursor, Cline, Codex CLI, Claude Code, Aider və s.) aşkarlamaq / qeydiyyatdan keçirmək / işə salmaq | HTTP REST                                               | OmniRoute-a məxsus            |
| **Bulud Agentləri**              | Uzunmüddətli proqramlaşdırma tapşırıqlarını xarici bulud xidmətlərinə (Codex Cloud, Devin, Jules, Cursor Cloud) göndərmək                                                  | HTTP REST + verilənlər bazasında saxlanılan tapşırıqlar | OmniRoute-a məxsus            |

Bu üçü bir-birindən müstəqildir — istənilən alt çoxluğu seçə bilərsiniz.

## Qərar Ağacı

```
Bu cihazdan kənarda işi görmək üçün bulud xidmətinə (Codex Cloud / Cursor Cloud / Devin / Jules) ehtiyacınız var?
├─ BƏLİ → Bulud Agentləri (POST /api/v1/agents/tasks)
└─ XEYR → Davam edin
    │
    A2A protokolundan istifadə edən və əməkdaşlıq etmək istəyən həmkar agentiniz var?
    ├─ BƏLİ → A2A (POST /a2a)
    └─ XEYR → Davam edin
        │
        Lokal olaraq quraşdırılmış CLI proqramlaşdırma agentlərini siyahıya almaq / konfiqurasiya etmək istəyirsiniz?
        ├─ BƏLİ → ACP (GET /api/acp/agents)
        └─ XEYR → Adi /v1/chat/completions istifadə edin
```

## 1. A2A — Agentdən agentə

**Spesifikasiya:** [A2A v0.3](https://a2a-protocol.org)
**OmniRoute son nöqtəsi:** `POST /a2a` (JSON-RPC 2.0)
**Agent Kartı:** `GET /.well-known/agent.json`

### Nə zaman istifadə etməli

- OmniRoute-un həmkarlardan biri olduğu çoxagentli sistem qurarkən
- OmniRoute-un marşrutlaşdırma imkanlarını (ağıllı marşrutlaşdırma, kvota idarəetməsi və s.) Google ADK kimi freymvorklardakı agentlərə və ya ümumi agent şəbəkələrinə təqdim edərkən
- OmniRoute-u standart aşkarlama + çağırış interfeysi ilə əhatə edərkən

### Metodlar

- `message/send` — mesaj göndərin, sinxron cavab alın
- `message/stream` — mesaj göndərin + SSE vasitəsilə yayımlanan irəliləyiş hadisələrini alın
- `tasks/get` — tapşırığı ID üzrə oxuyun
- `tasks/cancel` — icra olunan tapşırığı ləğv edin

### Daxili bacarıqlar (6)

- `smart-routing` — sorğunu optimal kombinasiya vasitəsilə marşrutlaşdırır
- `quota-management` — hər provayder üzrə kvota vəziyyətini bildirir
- `provider-discovery` — quraşdırılmış provayderləri imkanları ilə birlikdə siyahıya alır
- `cost-analysis` — sorğunun/söhbətin dəyərini hesablayır
- `health-report` — hər provayder üzrə kəsici/soyuma/bloklanma vəziyyətini ümumiləşdirir
- `list-capabilities` — agentin mövcud bacarıqlarını və metadatasını sadalayır

### Ətraflı məlumat

Nəqliyyat təfərrüatları, agent kartının strukturu, tapşırıq TTL konfiqurasiyası və yeni bacarıqlar əlavə etmək üçün şablon barədə [A2A-SERVER.md](./A2A-SERVER.md) sənədinə baxın.

## 2. ACP — CLI Agentləri Reyestri

**OmniRoute son nöqtəsi:** `GET /api/acp/agents`
**Mənbə:** `src/lib/acp/{index,manager,registry}.ts`

### Bu nədir

ACP OmniRoute-un **lokal CLI agentləri inventarıdır**. O, host sistemdə hansı proqramlaşdırma CLI-lərinin quraşdırıldığını (Cursor, Cline, Claude Code, Codex CLI, Continue və s.) aşkar edir, onların versiyalarını müəyyənləşdirir və istifadəçinin hər bir CLI-ni OmniRoute-a yönləndirə bilməsi üçün onları idarə panelində göstərir.

Bu, xarici protokol DEYİL — "CLI Tools" istifadəçi interfeysini və CLI barmaq izi izləməsini təmin edən daxili reyestrdir (baxın: [CLI-TOOLS.md](../reference/CLI-TOOLS.md)).

### Nə edir

- Quraşdırılmış CLI icra fayllarını tapmaq üçün host sistemi yoxlayır (əməliyyat sistemindən asılı olaraq `which` / `where` istifadə edir)
- Hər bir CLI-nin versiyasını oxuyur (`<bin> --version` çağırır)
- İstəyə bağlı olaraq istifadəçi tərəfindən müəyyən edilmiş xüsusi agentləri qəbul edir (icra faylının yolu + versiya yoxlama əmri + işə salma arqumentləri)
- Xüsusi agentləri parametrlərdə daimi saxlayır
- Birləşdirilmiş siyahını idarə panelinə qaytarır

### REST API

| Son nöqtə         | Metod | Təsvir                                                                      | Autentifikasiya |
| ----------------- | ----- | --------------------------------------------------------------------------- | --------------- |
| `/api/acp/agents` | GET   | Aşkar edilmiş + xüsusi agentləri siyahıya alır (quraşdırılmış/ümumi saylar) | API açarı       |
| `/api/acp/agents` | POST  | Xüsusi agent əlavə edir/yeniləyir/silir (gövdədə əməliyyat diskriminatoru)  | API açarı       |

POST üçün gövdə strukturu (`src/app/api/acp/agents/route.ts` daxilində `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### İstifadə halları

- İdarə panelindəki "CLI Tools" səhifəsi quraşdırılmış alətləri siyahıya alır və hər birini OmniRoute-a yönləndirməyə kömək edir
- Xüsusi agentlər təcrübəli istifadəçilərə OmniRoute-un standart olaraq tanımadığı daxili/mülkiyyətli CLI-ləri qeydiyyatdan keçirməyə imkan verir
- Aşkarlama nəticəsi `cli-tools` barmaq izi matrisini məlumatla təmin edir

### ACP-dən nə zaman istifadə ETMƏMƏLİ

- ACP tapşırıqları _icra etmir_. O, yalnız CLI-ləri aşkar edir və konfiqurasiya edir. CLI-ni faktiki olaraq işə salmaq üçün onu OmniRoute-un təqdim etdiyi mühit dəyişənləri (`OPENAI_BASE_URL`, `OPENAI_API_KEY` və s.) ilə özünüz başladırsınız.

## 3. Bulud Agentləri

**OmniRoute son nöqtələri:** `/api/v1/agents/tasks/*` (həyat dövrü) + `/api/cloud/*` (infrastruktur)
**Mənbə:** `src/lib/cloudAgent/`

### Bu nədir

Üçüncü tərəf bulud proqramlaşdırma agentləri üzərində vahid interfeysdir. Siz sorğu mətni + repozitoriya URL-i göndərirsiniz, OmniRoute onu uyğun bulud agentinə yönləndirir, statusu mütəmadi yoxlayır və nəticələri qaytarır.

### Dəstəklənən agentlər (4, hamısı `src/lib/cloudAgent/agents/` daxilində təsdiqlənib)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### Həyat dövrü

```
POST /api/v1/agents/tasks
  → hər agent sinfi üçün BaseAgent.createTask()
  → xarici xidmət işi başladır
  → verilənlər bazasında tapşırıq sətri yaradılır (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → provayderdən tənbəl status sinxronizasiyası
  → cari statusu + planı + fəaliyyət jurnalını qaytarır
  ↓
POST /api/v1/agents/tasks/[id]   (əməliyyat: "approve" | "message" | "cancel")
  → provayderə yönləndirir (və ya lokal olaraq ləğv edilmiş kimi işarələyir)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → lokal ləğvetmə
```

### Autentifikasiya

⚠️ **Bütün `/api/v1/agents/tasks/*` son nöqtələri idarəetmə autentifikasiyası tələb edir** (`588a0333` kommiti). Yalnız Bearer istifadə edən çağırışçılar v3.8.0-dan etibarən 401 cavabı alırlar.

### Ətraflı məlumat

`CloudAgentBase` müqaviləsi, hər agentə aid xüsusiyyətlər, sxem təfərrüatları və autentifikasiya məlumatlarının ötürülməsi son nöqtələri üçün [CLOUD_AGENT.md](./CLOUD_AGENT.md) sənədinə baxın.

## Müqayisə: A2A və Bulud Agentləri

Hər ikisində "uzunmüddətli tapşırıqlar" var, lakin fərqli səviyyələrdə:

| Aspekt                   | A2A                                                                                        | Bulud Agentləri                                                  |
| ------------------------ | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| Standart                 | Açıq A2A v0.3                                                                              | OmniRoute-a xas                                                  |
| Hesablamanın icra yeri   | OmniRoute daxilində (konfiqurasiya edilmiş kombinasiyalardan istifadə edir)                | Xarici (Codex / Devin / Jules serverləri)                        |
| Tapşırığın müddəti       | Standart TTL 5 dəqiqə (`TaskManager` daxilində konfiqurasiya edilə bilər)                  | Dəqiqələrdən saatlara qədər                                      |
| Repozitoriyadan xəbərdar | Xeyr (yalnız sorğuları ötürür)                                                             | Bəli (repo URL-si + budaq)                                       |
| İstifadə ssenarisi       | Agentlərarası əməkdaşlıq, xidmət kimi ağıllı marşrutlaşdırma                               | "Y reposunda X funksiyasını reallaşdır" tapşırığını həvalə etmək |
| Autentifikasiya          | `/a2a` üçün istəyə bağlı `OMNIROUTE_API_KEY`; `/api/a2a/*` REST köməkçiləri üçün idarəetmə | Həmişə idarəetmə                                                 |

## İnteqrasiya Nümunələri

### OmniRoute-un A2A imkanlarını kəşf edin

```bash
curl http://localhost:20128/.well-known/agent.json
```

Bütün 6 bacarıq, nəqliyyat və versiya məlumatları ilə Agent Kartını qaytarır.

### OmniRoute-u A2A agenti kimi çağırın

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### ACP vasitəsilə quraşdırılmış CLI agentlərini siyahıya alın

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### Fərdi CLI agenti əlavə edin

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

### Bulud Agenti tapşırığını göndərin

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Implement feature X in repo Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### Bulud tapşırığının statusunu sorğulayın

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```

## Hansını Nə Zaman İstifadə Etməli

- **Çatbot / kopilot istifadəçi interfeysi** → `/v1/chat/completions` (OpenAI ilə uyğun — agent protokolu deyil)
- **Çoxagentli əməkdaşlıq** → A2A
- **İdarəetmə panelində lokal CLI-lərin siyahıya alınması** → ACP
- **Uzunmüddətli kodlaşdırma tapşırıqlarının bulud xidmətlərinə həvalə edilməsi** → Bulud Agentləri
