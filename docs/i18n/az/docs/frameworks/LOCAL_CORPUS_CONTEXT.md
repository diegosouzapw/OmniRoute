## Bu nədir

Local Corpus operatora mətn fayllarından ibarət, açıq şəkildə təsdiqlənmiş bir qovluğu
OmniRoute-un MCP serverinə təqdim etməyə imkan verir. Fayllar ilkin qovluqlarında qalır:
OmniRoute SQLite-da yalnız kanonik kök yolu saxlayır və yaddaşdaxili axtarış indeksini
idarə edir. O, korpus məzmununu repozitoriyaya və ya verilənlər bazasına köçürmür.

İndeks artımlı şəkildə yenilənir. Dəyişdirilməmiş fayllar ölçüsünə və dəyişdirilmə
vaxtına əsasən təkrar istifadə olunur, dəyişdirilmiş fayllar yenidən oxunur və SHA-256
ilə heşlənir, silinmiş fayllar isə indeksdən çıxarılır. Axtarış 30 saniyədən köhnə
indeksi yeniləyir; çağıran tərəflər dərhal yenilənmə də tələb edə bilər.

## Mənbəni konfiqurasiya edin

Parametrlər marşrutu digər parametrlər API-ləri ilə eyni idarəetmə autentifikasiyasını
tələb edir. Göndərilən yol əvvəlcədən mövcud olmalı və mütləq qovluq yolu olmalıdır.

```bash
# Təsdiqlənmiş qovluğu qoşun
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Konfiqurasiyanı və indeksin vəziyyətini yoxlayın
curl http://localhost:20128/api/settings/local-corpus

# Mənbə fayllarını dəyişdirmədən əlaqəni kəsin
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP alətləri

Hər üç alət `read:local-corpus` tələb edir. Alət cavabları mütləq yolu deyil, nisbi
yolları və kök qovluğun əsas adını göstərir.

| Alət                  | Təsvir                                                                                                    |
| :-------------------- | :-------------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Konfiqurasiya vəziyyətini, indeks ölçüsünü, limitləri və son yenilənmə vaxtını bildirir                   |
| `local_corpus_search` | İndekslənmiş mətndə axtarış aparır və sətirlərlə məhdudlaşdırılmış fraqmentləri qaytarır (20 nəticəyədək) |
| `local_corpus_read`   | İcazə verilmiş, korpusa nisbətən göstərilən bir fayldan məhdud sətir diapazonunu oxuyur                   |

MCP giriş nümunələri:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Təhlükəsizlik sərhədləri

- İcazə siyahısı mətn yönümlüdür: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` və `.yml`.
- Simvolik keçidlər ötürülür. Oxuma yolları kanonikləşdirilir və konfiqurasiya edilmiş
  kökün daxilində qalmalıdır; mütləq yollar və qovluq keçidi cəhdləri rədd edilir.
- Həssas və generasiya edilmiş qovluq adları istisna edilir: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` və
  `secrets`.
- Standart limitlər 5,000 fayl, hər fayl üçün 1 MiB, cəmi 64 MiB indekslənmiş məzmun,
  hər axtarış fraqmenti üçün təxminən 4,000 simvol və hər oxuma üçün 400 sətirdir.
- NUL ehtiva edən fayllar qeyri-mətn faylları hesab edilir və ötürülür və ya rədd edilir.

PDF, DOCX, şəkillər və arxivlər kimi binar sənədlər qəsdən dəstəklənmir.
İndeksləmədən əvvəl onları konfiqurasiya edilmiş qovluqda təsdiqlənmiş mətn formatına
çevirin.

## Əməliyyat qeydləri

- Konfiqurasiya edilmiş kökün dəyişdirilməsi və ya silinməsi paylaşılan yaddaşdaxili
  indeksi təmizləyir.
- Prosesin yenidən başladılması indeksi silir; növbəti axtarış onu konfiqurasiya edilmiş
  mənbədən yenidən qurur.
- `local_corpus_status` skan edilməsini məcburi etmir. Dərhal yenidən skan tələb
  olunduqda `refresh: true` ilə `local_corpus_search` istifadə edin.
- Skan və oxuma xətaları hesablanır və ya təmizlənmiş xətalar kimi qaytarılır; mənbə
  faylları heç vaxt dəyişdirilmir.
