`agentrouter` yuxarı axın şlüzü `messages[].content` üzərində açar söz əsaslı məzmun filtri işlədir. Filtr qismən deterministikdir (müəyyən ifadələri həmişə bloklayır), qismən isə ehtimala əsaslanır (sorğu sıxlığına həssasdır — sürətli sorğulardan sonra daha aqressiv olur və fasilədən sonra bərpa olunur).

WAF sorğunu blokladıqda aşağıdakı cavabı qaytarır:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Filtrin əhatə dairəsi

WAF yalnız `messages[].content` sahəsini yoxlayır. O, aşağıdakıları **yoxlamır**:

- `system` promptunu
- Strukturlaşdırılmış məzmun bloklarını (`tool_result`, `tool_use`, `thinking`, `image`)
- Alətlərin `description` və `input_schema` sahələrini
- Sorğu metadatasını, başlıqları və ya model id-sini

## Həmişə bloklanan nümunələr (böyük-kiçik hərfə həssas deyil)

| Nümunə                           | Qeydlər                                                  |
| -------------------------------- | -------------------------------------------------------- |
| İstənilən `Lorem ipsum` variantı | Tam latın lorem lüğəti bloklanır                         |
| `language model` (təkbaşına)     | "the language model" və "large language model" buraxılır |
| `virtual assistant`              | "AI assistant" buraxılır                                 |
| `I'm here to help`               | Təkcə "here to help" də bloklanır                        |
| `Claude, made by Anthropic`      | Yalnız tam ifadə                                         |

## Demək olar ki, həmişə bloklanan nümunələr

| Nümunə                                                      | Qeydlər                                                       |
| ----------------------------------------------------------- | ------------------------------------------------------------- |
| `placeholder`                                               | Təkbaşına istifadə edildikdə (parametr adı kimi deyil və s.)  |
| `dummy data`                                                | Fiksturlar üçün ümumi başlanğıc ifadəsi                       |
| `foo bar baz`                                               | Kanonik doldurucu ifadə                                       |
| Təkrarlanan qısa tokenlər (`AAA BBB CCC`, `test test test`) | Açar sözlərin süni şəkildə çoxaldılmasını aşkarlayan detektor |

## Yük altında davranış

Qısa müddət ərzində təxminən 5 sürətli sorğudan sonra WAF normalda buraxılacaq məzmunu bloklamağa başlayır. Təxminən 5–10 saniyəlik fəaliyyətsizlikdən sonra limit vedrəsi boşalır. Bu, Claude Code və ya Codex CLI ardıcıl olaraq bir neçə alət istifadəsi / mesaj göndərilməsi çağırışı etdikdə fasilələrlə yaranan `400 content-blocked` xətalarına səbəb olan, IP və açarla əlaqələndirilmiş eyni sorğu tezliyi məhdudlaşdırıcısıdır.

## OmniRoute-da artıq tətbiq edilmiş yumşaltma tədbirləri

1. **`open-sse/services/wafRateLimit.ts`** — istənilən `agentrouter:*` URL-inə göndərilən sorğular arasında minimum 500 ms intervalı məcburi edən sıçrayış qoruyucusu. Bu interval insanın gecikməni hiss etmə həddindən xeyli aşağıdır və normal trafik zamanı WAF-ın aktivləşməsinin qarşısını alır.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — yuxarı axın `400 content-blocked` qaytardıqda icraçı eksponensial gözləmə ilə (1.5 s, 3.0 s, maksimum 2 cəhd) eyni URL üzrə sorğunu təkrar edir. Gözləmədən sonra WAF adətən yumşalır və təkrar cəhd uğurlu olur.

3. **`tests/unit/compression/harness.test.ts`** — `longInput` test fiksturu `"lorem ipsum dolor sit amet ".repeat(40)` ifadəsindən `"example content for testing purposes ".repeat(40)` ifadəsinə dəyişdirildi ki, Claude Code bu faylı `Read` aləti vasitəsilə oxuduqda faylın məzmunu `tool_result` bloku vasitəsilə geri ötürülərək WAF-ı işə salmasın.

## Promptlar və alət çıxışı üçün tövsiyələr

Claude Code və ya Codex CLI sessiyası təkrarən `400 content-blocked` xətası ilə qarşılaşırsa, ən son istifadəçi mesajında və ən son alət nəticəsində yuxarıdakı nümunələrdən hər hansı birinin olub-olmadığını yoxlayın və ifadəni dəyişdirin. Ümumi həll yolları:

- `Lorem ipsum …` ifadəsini `example text …` ilə və ya testin, yaxud fiksturun modelləşdirməyə çalışdığı faktiki məzmunla əvəz edin.
- Təkbaşına işlənən `placeholder` ifadəsini `example value`, `sample value` və ya real dəyərlə əvəz edin.
- `language model` ifadəsini `large language model` və ya `the model` ilə əvəz edin.
- `dummy data` ifadəsini `sample data` və ya realistik başlanğıc dəyərlərlə əvəz edin.
- `I'm here to help` / `here to help` ifadəsini daha konkret girişlə əvəz edin (məsələn, "Qeyd etdiyiniz faylı nəzərdən keçirəcəyəm").

## Yanlış müsbət nəticələrin yuxarı axına bildirilməsi

Cari filtr həddindən artıq aqressivdir — operatorun prompt yeritməyə çalışmadığı aydın olsa belə, `tool_result` bloklarında "Lorem ipsum" ifadəsini bloklayır. Bunun mənbədə düzəldilməsini istəyən operatorlar yanlış müsbət nəticələri bildirmək üçün `agentrouter.org` ilə əlaqə saxlamalıdırlar. Yuxarıdakı bloklama siyahısı 2026-08-03 tarixində yuxarı axının sınaqdan keçirilməsi nəticəsində empirik olaraq əldə edilib.
