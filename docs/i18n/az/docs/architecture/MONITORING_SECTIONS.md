## Yüksək Səviyyəli Naviqasiya

İdarəetmə panelinin yan panelində (B Qrupundan sonra) aşağıdakı yuxarı səviyyəli bölmələr bu ardıcıllıqla yerləşir:

```
Ana səhifə
Provayderlər
Kombinasiyalar
API Açarları
Parametrlər
Analitika
Xərclər          ← YENİ (B Qrupu, plan 16)
Monitorinq       ← YENİDƏN TƏŞKİL EDİLİB (B Qrupu, plan 16)
...
```

## Xərclər bölməsi (yeni, səviyyə 1)

Yol prefiksi: `/dashboard/costs/`

| Element               | URL                                  | Təsvir                                        |
| --------------------- | ------------------------------------ | --------------------------------------------- |
| İcmal                 | `/dashboard/costs`                   | Ümumi xərclər paneli (Analitikadan köçürülüb) |
| Qiymətləndirmə        | `/dashboard/costs/pricing`           | Hər model üzrə qiymət cədvəli                 |
| Büdcə                 | `/dashboard/costs/budget`            | Büdcə hədləri + xəbərdarlıqlar                |
| Kvotanın paylaşılması | `/dashboard/costs/quota-share`       | Kvota paylaşma hovuzları + istifadə           |
| Plan konfiqurasiyası  | `/dashboard/costs/quota-share/plans` | Hər provayder üzrə planın fərdi parametrləri  |

**Əsaslandırma**: Qiymətləndirmə, Büdcə və Kvotanın paylaşılması əvvəllər
`Monitorinq > Xərc Parametrləri` altında yerləşirdi. Onların ayrıca yuxarı səviyyəli
bölməyə köçürülməsi müşahidə alətləri arasında naviqasiya etmədən tapılmalarını
asanlaşdırır.

## Monitorinq bölməsi (yenidən təşkil edilib)

Monitorinq bölməsində indi yuxarıda **Fəaliyyət**, onun ardınca isə **3 alt qrup** var:

```
Monitorinq
├── Fəaliyyət             ← Taymlayn axını (yuxarı səviyyəli element)
├── Jurnallar qrupu
│   ├── Jurnallar (hamısı)
│   ├── Proksi Jurnalları
│   └── Konsol Jurnalları
├── Audit qrupu
│   ├── Audit Jurnalı
│   ├── MCP Auditi
│   └── A2A Auditi
└── Sistem qrupu
    ├── Sağlamlıq
    └── İcra Mühiti
```

### Köhnə strukturla müqayisədə dəyişikliklər

| Əvvəl                                                                                                     | Sonra                                               |
| --------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Fəaliyyət = Jurnallar daxilində Audit Jurnalını göstərən tab                                              | Fəaliyyət = ayrıca axın (`/dashboard/activity`)     |
| Monitorinqdə Xərc Parametrləri qrupu                                                                      | Xərclər bölməsinə köçürülüb                         |
| Düz siyahı: Jurnallar, Fəaliyyət (jurnallar), Audit, Sağlamlıq, İcra Mühiti, Qiymətləndirmə, Büdcə, Kvota | Strukturlaşdırılmış 3 qrup + ayrıca Xərclər bölməsi |

## Fəaliyyət və Audit Jurnalı

Bunlar artıq bir-birindən fərqlənir:

| Ölçü                     | Fəaliyyət (`/dashboard/activity`)                                  | Audit Jurnalı (`/dashboard/audit`)            |
| ------------------------ | ------------------------------------------------------------------ | --------------------------------------------- |
| **Məqsəd**               | İstifadəçiyə yönəlmiş hadisələr axını ("son vaxtlar nə baş verdi") | Uyğunluq / təhlükəsizlik jurnalı              |
| **Məlumat mənbəyi**      | `GET /api/compliance/audit-log?level=high`                         | `GET /api/compliance/audit-log?level=all`     |
| **Format**               | Günlər üzrə qruplaşdırılmış taymlayn, anlaşılan fellər + ikonlar   | Sıx səhifələnmiş cədvəl, hər səhifədə 50 qeyd |
| **Filtrlər**             | Hadisə növünün kateqoriyası                                        | Əməl, ciddilik, icraçı, tarix aralığı         |
| **İxrac**                | Mövcud deyil                                                       | JSON ixracı                                   |
| **İcraçı filtri**        | Tətbiq edilmir                                                     | İcraçıya görə filtrlənə bilər                 |
| **Göstərilən hadisələr** | Yalnız yüksək səviyyəli əməllər (icazə siyahısı)                   | Bütün audit hadisələri                        |

### Yüksək Səviyyəli Əməllərin icazə siyahısı

`src/lib/audit/highLevelActions.ts` faylında müəyyən edilib. Fəaliyyət axınında
hansı hadisələrin görünəcəyini idarə edir. İcazə siyahısına bunlar daxildir:

- Provayder əlavə etmə/silmə/sınaq hadisələri
- Kombinasiyanın yaradılması/yenilənməsi/silinməsi
- API açarının həyat dövrü (yaratma, ləğv etmə, rotasiya)
- Büdcə həddinə çatılması
- Autentifikasiya zamanı giriş/çıxış
- Bulud agenti sessiyasının yaradılması
- MCP alətinin qeydiyyatı
- Webhook yaradılması/silinməsi
- Kvota hovuzu/planı dəyişiklikləri (`quota.*` əməlləri, B Qrupu)
- Platforma hadisələri (yeniləmə, yerləşdirmə)
- Bacarığın quraşdırılması/silinməsi

Bu siyahıda olmayan hadisələr yalnız Audit Jurnalında görünür.

### Yeni yüksək səviyyəli əməl əlavə etmək

`src/lib/audit/highLevelActions.ts` faylını redaktə edin və əməl sətrini
`HIGH_LEVEL_ACTIONS` dəyişəninə əlavə edin. Bunun üçün PR tələb olunur (siyahı
verilənlər bazası vasitəsilə konfiqurasiya edilmir, kodda saxlanılır).
Müvafiq ikonu `src/lib/audit/activityIcons.ts` faylına əlavə etmək olar.

## Yönləndirmə: `/dashboard/logs/activity`

Köhnə `/dashboard/logs/activity` yolu
`src/app/(dashboard)/dashboard/logs/activity/page.tsx` faylındakı
`permanentRedirect()` vasitəsilə daimi olaraq (HTTP 308)
`/dashboard/activity` yoluna yönləndirilir.

Köhnə ID-yə istinad edən istifadəçi ilkin parametrlərini pozmamaq üçün əvvəlki
yan panel ID-si `logs-activity`, `HIDEABLE_SIDEBAR_ITEM_IDS` daxilində saxlanılır
(lakin `SIDEBAR_DEFINITIONS` daxilindən silinib).
