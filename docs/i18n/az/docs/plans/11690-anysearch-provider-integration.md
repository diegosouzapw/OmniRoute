## 1. Xidmət üzrə faktiki məlumatlar (rəsmi sənədlər, çarpaz yoxlanılıb)

- Əsas URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - parametrlər: `query` (məcburi), `max_results` (1-10, standart olaraq 10), `tag` (`{domain}.{sub_domain}` üzrə şaquli yönləndirmə), `zone` (cn/intl), `language`, `params` (strukturlaşdırılmış şaquli sahələr), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - imkanlar kataloqudur, kvotaya daxil EDİLMİR.
- `POST /v1/extract` - `{url, title, content}` məlumatlarını əldə edir/çıxarır; sərt JSON gövdəsi, 16 KiB limiti.
- `POST /v1/auth/email/register` - bir çağırışla qeydiyyat; birdəfəlik açıq mətn açarı `as_sk_...` qaytarır.
- Autentifikasiya: `Authorization: Bearer <as_sk_...>` istəyə bağlıdır; anonim giriş gündəlik pulsuz kvotanı istifadə edən IP üzrə limitlərə endirilir; etibarsız açar səssiz anonim ehtiyat rejiminə keçid OLMADAN 401/403 qaytarır.
- Pulsuz tarif: gündə 1000 sorğu, hər açar üçün 20 QPS. Ödənişli tarif: qiymət müəyyən edilməyib (Tezliklə).
- Cavab zərfi: uğurlu `{code: 0, message: "success", request_id, data}`; uğursuz `{code: -1, message}`. Autentifikasiya/kvota xətalarında strukturlaşdırılmış `error_code` yoxdur (siqnal mesaj mətnidir); çıxarışa xas xətalarda isə `error_code` mövcuddur (`invalid_extract_url`, `extract_failed`). 429 cavabında `Retry-After` başlığı yoxdur.

## 3. Qərarlar (hamısı 2026-08-26 tarixində qəbul edilib)

1. **Marşrutlaşdırma yanaşması: `fallbackOnly`.** Əsaslandırma: qiyməti 0 olan pulsuz provayder avtomatik xərc əsaslı marşrutlaşdırmada heç vaxt üstünlük təşkil etməməlidir; birbaşa seçim və ehtiyat keçiddən geri qayıtma dəyişməz qalır. Presedent: birləşdirilmiş xquik qeydi.
2. **Əhatə dairəsi: v1-də `POST /v1/extract` vasitəsilə webSearch + webFetch.** tavily/exa-nın ikili imkan mental modelinə uyğundur. Şaquli funksiyalar (`tag`, `sub-domains`, `batch_search`) əhatə dairəsinə daxil deyil — hazırda şaquli parametrlər üçün IR mövcud deyil.
3. **Kvota göstəricisi: `freeMonthlyQuota: 0`** (xquik üslubunda konservativ göstərim). Faktiki limit (gündə 1000 sorğu, gündəlik sıfırlanma) əvəzinə UI kataloqundakı `authHint` mətnində göstərilir. Əsaslandırma: kvota göstəricisi sıfırlanma semantikasına uyğun olmalıdır; gündəlik limiti aylıq ekvivalentə (30000) çevirmək UI-nin təmin edə bilməyəcəyi yanlış vəddir.
4. **searchTypes: yalnız `["web"]`.** AnySearch API-də xəbərlər/şəkillər şaquli axtarışına dair açıq sübut yoxdur; sənədləşdirilmiş şaquli axtarışı olmayan API-ləri inteqrasiya edən şlüzlər (məsələn, Google Custom Search) xəbərləri səssizcə veb axtarışına uyğunlaşdırmaq əvəzinə yalnız veb axtarışını təqdim edir.
5. **Açar yanaşması:** açarsız işləyir; etibarsız açar 401/403 qaytarır və heç vaxt səssizcə anonim rejimə endirilmir (yuxarı axın müqaviləsini əks etdirir).
6. **Qəsdən istisna edilənlər:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (çat sorğularının tutulması firecrawl/jina/tavily ilə məhdud qalır); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (anonim uzaq son nöqtələr hər çıxış IP-si üçün IP ilə məhdudlaşdırılmış ortaq hovuzdan istifadə edir, buna görə də açarsız çıxarış avtomatik marşrutlaşdırma namizədi deyil, seçim əsasında aktivləşdirilən funksiyadır); `QUOTA_STATUS_PROVIDERS` (AnySearch kvotanı 402/403 statusu ilə deyil, 429/zərf vasitəsilə bildirir).
