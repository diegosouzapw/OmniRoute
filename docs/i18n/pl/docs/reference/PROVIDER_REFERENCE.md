## Kategorie

- **Bezpłatne** — bezpłatny plan z kluczem API (konfigurowanym w panelu)
- **Bez uwierzytelniania** — publiczne punkty końcowe, które nie wymagają klucza ani logowania
- **OAuth** — proces logowania obsługiwany przez OmniRoute, bez konieczności używania klucza API
- **Web cookie** — integracja z aplikacją internetową dostawcy za pomocą uwierzytelniania opartego na plikach cookie
- **Klucz API** — płatny dostawca konfigurowany za pomocą klucza API (mogą być dostępne bezpłatne środki)
- **Lokalne** — działa na komputerze użytkownika (Ollama, LM Studio, vLLM itp.)
- **Wyszukiwanie** — dostawcy wyszukiwania internetowego
- **Audio** — dostawcy obsługujący wyłącznie dźwięk (TTS/STT)
- **Nadrzędne proxy** — dostawcy pośredniczący w dostępie do innych dostawców
- **Agent chmurowy** — długotrwale działający agenci programistyczni (Codex Cloud, Devin, Jules)
- **Systemowe** — wewnętrzni dostawcy OmniRoute (loopback itp.)

Dodatkowe tagi: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Wywoływanie narzędzi` (jeśli podano): `native` — rzeczywisty interfejs API do wywoływania funkcji; `emulated` — tablica `tools` jest emulowana w prompcie za pośrednictwem `webTools.ts` (bloki `<tool>{...}</tool>` analizowane za pomocą wyrażeń regularnych); `none` — tablica `tools` jest obecnie po cichu pomijana. Zobacz #7286.

Użyj panelu pod adresem `/dashboard/providers`, aby włączyć, skonfigurować i przetestować każdego dostawcę.
