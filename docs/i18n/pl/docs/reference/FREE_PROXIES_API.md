OmniRoute dostarcza starannie dobraną pulę bezpłatnych serwerów proxy w tabeli `free_proxies`,
synchronizowaną z zewnętrznymi dostawcami (1proxy, proxifly, iplocate, webshare).
Panel wyświetla je w sekcji **Ustawienia → Bezpłatne proxy**. Ten dokument
opisuje filtrowanie, sortowanie, zliczanie i raportowanie błędów synchronizacji
po stronie serwera, udostępniane przez trasę listy.

## Trasa listy — `GET /api/settings/free-proxies`

Zwraca przefiltrowany, posortowany i podzielony na strony wycinek oraz łączną liczbę wyników. Filtrowanie
i zliczanie odbywa się w SQL, dzięki czemu interfejs użytkownika może wyświetlić rzeczywistą łączną liczbę (np. `Łącznie: 0`)
bez wczytywania każdego wiersza do pamięci.

### Parametry zapytania

| Parametr          | Typ                                | Domyślnie | Znaczenie                                                                                                                 |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------- |
| `search`          | ciąg znaków                        | `""`      | Rozróżniające wielkość liter dopasowanie `LIKE` w kolumnie hosta (oraz źródła).                                           |
| `protocol`        | ciąg znaków                        | `""`      | Filtr `type`: `http` / `https` / `socks4` / `socks5`. Pusta wartość = wszystkie.                                          |
| `country`         | ciąg znaków                        | `""`      | Filtr `countryCode` (ISO-2). Pusta wartość = wszystkie.                                                                   |
| `minQuality`      | liczba                             | `0`       | Tylko wiersze z `qualityScore >= minQuality`. `0` = brak dolnego progu.                                                   |
| `disabledSources` | ciąg znaków                        | `""`      | Rozdzielone przecinkami identyfikatory źródeł do wykluczenia (np. `proxifly,webshare`).                                   |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = wynik malejąco; `latency` = opóźnienie rosnąco (wartości null na końcu); `recent` = `lastValidated` malejąco. |
| `offset`          | liczba                             | `0`       | Początek paginacji.                                                                                                       |
| `limit`           | liczba                             | `50`      | Rozmiar strony (ograniczony po stronie serwera).                                                                          |

### Odpowiedź

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 od usługi nadrzędnej"],
    "webshare": ["przekroczono limit czasu sieci"]
  }
}
```

`total` odzwierciedla łączną liczbę przefiltrowanych wyników **przed** paginacją, dzięki czemu interfejs użytkownika może wyświetlać
`Łącznie: N` oraz `hasMore` niezależnie od siebie. Kluczami `syncErrors` są identyfikatory źródeł, a wartość
jest uzupełniana tylko dla źródeł, których ostatnia synchronizacja zakończyła się niepowodzeniem — wynik `Łącznie: 0`
nigdy nie jest pozostawiany bez wyjaśnienia.

## Dodawanie do puli — `POST /api/settings/free-proxies/[id]/add-to-pool`

Przenosi bezpłatny serwer proxy do zarządzanej puli `proxy_registry`. Najpierw weryfikuje
serwer nadrzędny; po powodzeniu zwraca identyfikator nowego serwera proxy w puli i zmierzone opóźnienie.

## Synchronizacja — `POST /api/settings/free-proxies/sync`

Ponownie pobiera dane ze wszystkich włączonych źródeł (lub ich podzbioru wskazanego w `{ "sources": [...] }`). Każde
źródło jest synchronizowane niezależnie; źródło, którego synchronizacja zakończyła się niepowodzeniem, jest rejestrowane w `syncErrors`, a
pozostałe nadal są przetwarzane, dzięki czemu częściowe synchronizacje nigdy nie usuwają wcześniej poprawnie pobranych danych.

## Statystyki — `GET /api/settings/free-proxies/stats`

Zwraca agregat `total / inPool / avgQuality / bySource / lastSyncAt`
bez danych wierszy — używany przez widżety nagłówka panelu.
