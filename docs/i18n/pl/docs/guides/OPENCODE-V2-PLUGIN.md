`@omniroute/opencode-plugin-v2` udostępnia cały katalog OmniRoute — modele, kombinacje i
automatyczne kombinacje — w selektorze modeli OpenCode v2 wraz z nazwami wyświetlanymi, cenami
i limitami bezpłatnych warstw.

Jest to pakiet odrębny od `@omniroute/opencode-plugin`, ponieważ OpenCode v1 i v2 ładują
wtyczki za pośrednictwem różnych kontraktów. Wybierz pakiet odpowiadający głównej wersji OpenCode;
nie współdzielą one żadnych elementów, więc aktualizacja jednego nigdy nie wymusza aktualizacji drugiego.

## Wymagania

- OpenCode v2.
- Osiągalna brama OmniRoute (domyślnie `http://localhost:20128`).
- Node.js 22 lub 24.

## Instalacja

Dodaj wtyczkę do `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modele pojawią się jako `omniroute/<provider>/<model>`; `providerId` określa ten prefiks oraz
identyfikator integracji, pod którym OpenCode przechowuje dane uwierzytelniające.

## Dane uwierzytelniające

Wtyczka szuka klucza bramy w trzech miejscach, w następującej kolejności:

1. **Dane uwierzytelniające połączone w OpenCode.** Wtyczka rejestruje integrację, dzięki czemu
   własny proces uwierzytelniania OpenCode może przechowywać klucz. Nic nie trafia do `opencode.json` — ta opcja jest zalecana.
2. `apiKey` w opcjach wtyczki jako nadpisanie dla konkretnego projektu. Powoduje to zapisanie klucza w pliku,
   który może być umieszczany w repozytorium.
3. `OMNIROUTE_API_KEY` w środowisku.

Jeśli nie podano żadnej z tych trzech wartości, katalog jest pusty, a wtyczka informuje o tym raz podczas uruchamiania,
zamiast pozostawiać pusty selektor bez żadnego komunikatu.

### Token zarządzania jest innym kluczem

Kombinacje, stan dostawców i wzbogacanie danych (nazwy wyświetlane, ceny, limity bezpłatnych warstw) pochodzą
z punktów końcowych `/api/*` bramy, które w większości wdrożeń są chronione **tokenem zarządzania**,
a nie kluczem wnioskowania:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Jeśli `managementReadToken` nie jest ustawiony, używana jest wartość `apiKey`. Gdy brama odrzuci tę wartość zastępczą,
katalog nadal zostanie opublikowany, ale z surowymi identyfikatorami modeli zamiast nazw wyświetlanych, bez
deduplikacji aliasów kanonicznych, cen i kombinacji. Wtyczka ostrzega o tym raz dla każdego punktu końcowego,
podając jego nazwę i wskazując utracone informacje — dzięki temu przyczyna ograniczonego selektora zawsze jest jasna.

## Opcje

| Klucz                            | Wartość domyślna                                                | Uwagi                                                                                                                            |
| -------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                                   | Identyfikator dostawcy i integracji oraz prefiks, pod którym pojawiają się modele                                                |
| `baseURL`                        | wymagane                                                        | Adres główny bramy, wyłącznie `http(s)`; sufiks `/v1` jest dodawany w razie potrzeby                                             |
| `apiKey`                         | połączone dane uwierzytelniające, następnie `OMNIROUTE_API_KEY` | Klucz czatu dla `/v1/*`                                                                                                          |
| `managementReadToken`            | domyślnie używa `apiKey`                                        | Klucz dla `/api/*` — zazwyczaj **nie** jest to ten sam klucz                                                                     |
| `displayName`                    | `"OmniRoute"`                                                   | Nazwa dostawcy w selektorze                                                                                                      |
| `timeoutMs`                      | `10000`                                                         | Limit czasu pobierania dla każdego punktu końcowego (automatyczne kombinacje używają 5 s)                                        |
| `modelCacheTtlMs`                | `300000`                                                        | TTL pamięci podręcznej katalogu; migawka na dysku przyspiesza zimne uruchomienia                                                 |
| `timeouts`                       | domyślnie używa `timeoutMs`                                     | Limity czasu poszczególnych punktów końcowych w ms: `models`, `combos`, `autoCombos`, `enrichment`                               |
| `enrichment`                     | `true`                                                          | Pobieranie nazw, cen i limitów bezpłatnych warstw                                                                                |
| `providerTag`                    | `true`                                                          | Poprzedzenie nazwy wyświetlanej nazwą dostawcy nadrzędnego, do którego kierowany jest ruch                                       |
| `usableOnly`                     | `false`                                                         | Zachowanie wyłącznie dostawców, których brama zgłasza jako skonfigurowanych                                                      |
| `visibleModels` / `hiddenModels` | `[]`                                                            | Listy dozwolonych wartości dopasowywanych dokładnie lub według sufiksu; odmowa ma pierwszeństwo                                  |
| `geminiSanitization`             | `true`                                                          | Usuwanie ze schematów narzędzi słów kluczowych JSON Schema odrzucanych przez Gemini (narzędzia `$ref` są przekazywane bez zmian) |
| `apiFormat.allowAnthropic`       | `false`                                                         | Kierowanie identyfikatorów z listy dozwolonych przez blok API Anthropic                                                          |
| `apiFormat.anthropicModels`      | `[]`                                                            | Pełne identyfikatory modeli kierowanych do Anthropic                                                                             |
| `logLevel` / `startupDebug`      | `warn` / `false`                                                | Szczegółowość rejestrowania                                                                                                      |

## Jak katalog pozostaje aktualny

Katalog jest pobierany leniwie i buforowany przez `modelCacheTtlMs`, a migawka na dysku zapewnia
dostępność ostatniego znanego katalogu, gdy brama jest nieosiągalna — awaria kosztuje jedynie
utratę aktualności. Modele i kombinacje są publikowane natychmiast po ich otrzymaniu; automatyczne kombinacje, lista
dostawców oraz nakładka wzbogacająca są dołączane, gdy tylko się pojawią, dzięki czemu jeden powolny punkt końcowy nie może zablokować
całego selektora.

Nazwy zawierają informacje znane bramie: dostawcę nadrzędnego, do którego kierowany jest model, znacznik `[Free]`
oraz powiązany z nim budżet — dzięki temu dwa połączenia oferujące ten sam model pozostają
rozróżnialne. Wyłącz prefiks za pomocą `"providerTag": false`.

Nie ma polecenia ręcznego odświeżania: polecenia OpenCode v2 są szablonami promptów, a nie funkcjami zwrotnymi,
więc wtyczka nie może udostępnić takiego polecenia. Odświeżanie odbywa się zgodnie z TTL; host otrzymuje żądanie ponownego wczytania tylko wtedy, gdy
katalog lub nakładka rzeczywiście się zmieniły, nigdy przy każdym odświeżeniu.

## Wywoływanie narzędzi w Gemini

Gemini odrzuca całe żądanie, jeśli deklaracje narzędzi zawierają `$schema` lub
`additionalProperties`, odpowiadając błędem `400 INVALID_ARGUMENT`. Wtyczka usuwa te słowa kluczowe ze
schematów narzędzi przeznaczonych dla modelu Gemini tego dostawcy i pozostawia wszystkie pozostałe żądania bez zmian.
Narzędzie zawierające `$ref` jest przekazywane bez zmian zamiast poddawania usuwaniu, ponieważ usunięcie
odwołania rozszerzyłoby schemat tak, by „akceptował wszystko”.
Ustaw `"geminiSanitization": false`, aby to wyłączyć.

## Rozwiązywanie problemów

| Objaw                                               | Przyczyna                                                                                                |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Selektor nie wyświetla żadnego modelu OmniRoute     | Nie znaleziono klucza (sprawdź ostrzeżenie podczas uruchamiania) albo brama jest nieosiągalna            |
| Surowe identyfikatory modeli, brak kombinacji i cen | Punkty końcowe zarządzania odrzuciły token — ustaw `managementReadToken`                                 |
| Sesja przypięta do `opencode-<id>/…`                | Wtyczka v1 publikowała `opencode-<id>`; v2 publikuje samo `<id>`, więc ponownie wybierz model w `<id>/…` |
