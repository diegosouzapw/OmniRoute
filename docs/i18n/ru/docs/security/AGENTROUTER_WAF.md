Вышестоящий шлюз `agentrouter` применяет к `messages[].content` фильтр содержимого на основе ключевых слов. Фильтр частично детерминирован (всегда блокирует определённые фразы), а частично вероятностный (чувствителен к всплескам — становится более агрессивным после быстрых последовательных запросов и восстанавливается после периода ожидания).

Когда WAF блокирует запрос, он возвращает:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Область действия фильтра

WAF проверяет только `messages[].content`. Он **не** проверяет:

- Промпт `system`
- Структурированные блоки содержимого (`tool_result`, `tool_use`, `thinking`, `image`)
- Поля `description` и `input_schema` инструментов
- Метаданные запроса, заголовки или идентификатор модели

## Всегда блокируемые шаблоны (без учёта регистра)

| Шаблон                      | Примечания                                             |
| --------------------------- | ------------------------------------------------------ |
| Любой вариант `Lorem ipsum` | Блокируется весь латинский словарь lorem               |
| `language model` (отдельно) | "the language model" и "large language model" проходят |
| `virtual assistant`         | "AI assistant" проходит                                |
| `I'm here to help`          | "here to help" отдельно также блокируется              |
| `Claude, made by Anthropic` | Только полная фраза                                    |

## Почти всегда блокируемые шаблоны

| Шаблон                                                          | Примечания                                                 |
| --------------------------------------------------------------- | ---------------------------------------------------------- |
| `placeholder`                                                   | Когда используется отдельно (не как имя параметра и т. п.) |
| `dummy data`                                                    | Распространённая начальная фраза для фикстур               |
| `foo bar baz`                                                   | Каноническая фраза-заполнитель                             |
| Повторяющиеся короткие токены (`AAA BBB CCC`, `test test test`) | Детектор переполнения ключевыми словами                    |

## Поведение под нагрузкой

Примерно после 5 быстрых запросов за короткий промежуток времени WAF начинает блокировать содержимое, которое обычно проходит. Ограничение ослабевает после примерно 5–10 секунд бездействия. Это тот же ограничитель частоты запросов, привязанный к IP-адресу и ключу, который вызывает периодические ошибки `400 content-blocked`, когда Claude Code или Codex CLI быстро выполняет несколько вызовов инструментов или отправок сообщений подряд.

## Меры, уже реализованные в OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — защита от всплесков, обеспечивающая минимальный интервал в 500 мс между исходящими запросами к любому URL `agentrouter:*`. Этот интервал значительно ниже порога восприятия задержки человеком и не позволяет WAF активироваться при обычном трафике.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — когда вышестоящий сервис возвращает `400 content-blocked`, исполнитель повторяет запрос к тому же URL с экспоненциальной задержкой (1,5 с, 3,0 с, максимум 2 попытки). После задержки WAF обычно ослабляет ограничения, и повторный запрос выполняется успешно.

3. **`tests/unit/compression/harness.test.ts`** — тестовая фикстура `longInput` была изменена с `"lorem ipsum dolor sit amet ".repeat(40)` на `"example content for testing purposes ".repeat(40)`, чтобы при чтении этого файла Claude Code с помощью инструмента `Read` содержимое файла не возвращалось через блок `tool_result` и не активировало WAF.

## Рекомендации для промптов и вывода инструментов

Если сеанс Claude Code или Codex CLI постоянно сталкивается с `400 content-blocked`, проверьте последнее сообщение пользователя и последний результат инструмента на наличие любого из указанных выше шаблонов и переформулируйте текст. Распространённые способы обхода:

- Замените `Lorem ipsum …` на `example text …` или на фактическое содержимое, которое должен моделировать тест или фикстура.
- Замените `placeholder` (когда используется отдельно) на `example value`, `sample value` или фактическое значение.
- Замените `language model` на `large language model` или `the model`.
- Замените `dummy data` на `sample data` или реалистичные начальные значения.
- Замените `I'm here to help` / `here to help` на более конкретную вступительную фразу (например, "I'll review the file you mentioned").

## Сообщение о ложных срабатываниях вышестоящему сервису

Текущий фильтр чрезмерно агрессивен — он блокирует "Lorem ipsum" в блоках `tool_result`, хотя оператор явно не намеревался внедрять промпт. Операторам, которые хотят устранить проблему в источнике, следует обратиться к `agentrouter.org` и сообщить о ложных срабатываниях. Приведённый выше список блокировки является эмпирическим результатом тестирования вышестоящего сервиса по состоянию на 2026-08-03.
