> **Источник истины:** `src/lib/agentSkills/` (каталог, генератор, парсеры) + каталог `skills/` (файлы SKILL.md)
> **Последнее обновление:** 2026-08-02 — v3.8.50

Agent Skills — это структурированные файлы SKILL.md, которые обучают внешних агентов, клиентов MCP и оркестраторов A2A работе с REST API и CLI OmniRoute. В отличие от [Omni Skills](./SKILLS.md) (которые представляют собой определения инструментов LLM, выполняемых внутри OmniRoute), Agent Skills являются _каталогом документации_ — статическим Markdown-содержимым, которое можно напрямую передавать в контекст агента.

---

## Обзор

Каталог содержит **45 Agent Skills** (23 для REST API + 21 для CLI + 1 рабочий процесс конфигурации). Каждый навык имеет:

- **Канонический ID** (`omni-auth`, `cli-serve` и т. д.)
- Файл **SKILL.md** в `skills/{id}/SKILL.md` с YAML frontmatter (`name`, `description`) и содержательным Markdown-текстом
- **Конечные точки REST** (навыки API) или **подкоманды CLI** (навыки CLI), полученные из спецификации OpenAPI и реестра CLI
- **Необработанный URL GitHub** для загрузки актуальной версии: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Архитектура

```
src/shared/constants/agentSkills.ts    — курируемый список из 45 записей (имя/описание/категория/область/значок)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() записывает SKILL.md в skills/{id}/
  openapiParser.ts                     — извлекает конечные точки REST из docs/openapi.yaml
  cliRegistryParser.ts                 — извлекает подкоманды CLI из bin/cli-registry.ts
  schemas.ts                           — схемы Zod: AgentSkillSchema, SkillCoverageSchema и т. д.
  types.ts                             — интерфейсы TypeScript: AgentSkill, SkillCoverage и т. д.

skills/{id}/SKILL.md                   — сгенерированные и курируемые Markdown-файлы (всего 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (требуется аутентификация)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 инструмента MCP (список, получение, покрытие)
src/lib/a2a/skills/listCapabilities.ts        — навык A2A: list-capabilities
```

## Формат SKILL.md

```markdown
---
name: omni-providers
description: "Управление подключениями поставщиков: добавление, тестирование, ротация и удаление учётных данных."
---

<!-- сгенерировано src/lib/agentSkills/generator.ts; изменения, внесённые вручную, будут перезаписаны -->

## Обзор

...

## Аутентификация

...

## Конечные точки

...

<!-- skill:custom-start -->

## Пользовательский раздел (сохраняется при повторной генерации)

...

<!-- skill:custom-end -->
```

При повторной генерации генератор сохраняет содержимое между `<!-- skill:custom-start -->` и `<!-- skill:custom-end -->`. Десять навыков содержат курируемые пользовательские блоки:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Обнаружение REST API

| Конечная точка               | Метод | Описание                                                                            | Авторизация  |
| :--------------------------- | :---- | :---------------------------------------------------------------------------------- | :----------- |
| `/api/agent-skills`          | GET   | Список каталога (необязательные параметры `?category=api\|cli\|config&area=<area>`) | не требуется |
| `/api/agent-skills/{id}`     | GET   | Получение метаданных отдельного навыка                                              | не требуется |
| `/api/agent-skills/{id}/raw` | GET   | Получение SKILL.md в формате `text/markdown`                                        | не требуется |
| `/api/agent-skills/coverage` | GET   | Статистика покрытия (количество существующих файлов SKILL.md)                       | не требуется |
| `/api/agent-skills/generate` | POST  | Запуск генератора (dryRun/prune/onlyIds)                                            | управление   |

Пример — вывести список всех навыков API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Пример — получить отдельный файл SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Обнаружение MCP

В области действия `read:catalog` зарегистрированы три инструмента MCP:

| Инструмент                        | Описание                                                    |
| :-------------------------------- | :---------------------------------------------------------- |
| `omniroute_agent_skills_list`     | Список навыков (необязательные фильтры `category` / `area`) |
| `omniroute_agent_skills_get`      | Получение метаданных и SKILL.md одного навыка по `id`       |
| `omniroute_agent_skills_coverage` | Статистика покрытия (имеется/всего для API/CLI)             |

Настройку областей действия и аутентификацию см. в [MCP-SERVER.md](./MCP-SERVER.md).

## Обнаружение A2A

Навык A2A `list-capabilities` возвращает полный каталог из 45 навыков в виде артефакта с таблицей Markdown. Внешние оркестраторы могут вызвать его следующим образом:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "Перечисли все возможности" }]
  }
}
```

Подробности протокола см. в [A2A-SERVER.md](./A2A-SERVER.md).

## Как внешние агенты используют навыки

### 1. Обнаружение через REST

```bash
# Получить полный каталог
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Получить SKILL.md для внедрения контекста
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Обнаружение через MCP

```typescript
// В клиенте MCP для Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → массив AgentSkill, каждый из которых содержит rawUrl
```

### 3. Обнаружение через A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table — это Markdown-таблица со всеми 45 идентификаторами навыков и столбцами rawUrl
```

### 4. Прямое получение необработанного файла с GitHub (сервер не требуется)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Генератор

Генератор считывает подготовленный каталог, спецификацию OpenAPI и реестр CLI, а затем записывает `skills/{id}/SKILL.md` для каждой записи:

```bash
# Предварительный просмотр (пробный запуск без записи)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Полная повторная генерация
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Повторно сгенерировать указанные идентификаторы
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Ответ генератора представляет собой `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
