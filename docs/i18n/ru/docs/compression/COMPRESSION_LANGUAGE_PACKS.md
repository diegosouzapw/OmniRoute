Сжатие Caveman может загружать наборы правил для конкретных языков в дополнение к встроенным правилам английского языка.
Это позволяет сохранять стабильность основного движка, одновременно давая наборам правил для португальского, испанского, немецкого, французского, итальянского, японского и
будущих языков возможность развиваться независимо.

## Расположение

Языковые наборы находятся в:

```txt
open-sse/services/compression/rules/<language>/
```

Поставляемые в настоящее время наборы (проверено по содержимому каталога `rules/`):

| Язык                     | Каталог        | Доступные категории правил                          |
| ------------------------ | -------------- | --------------------------------------------------- |
| Английский               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Испанский                | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Португальский (Бразилия) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Индонезийский            | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Итальянский              | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Немецкий                 | `rules/de/`    | `context`, `filler`, `structural`                   |
| Французский              | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Японский                 | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Примечание о паритете:** наборы `en`, `es`, `pt-BR`, `id` и `it` содержат полный комплект из 5 категорий; наборы `de`, `fr` и `ja` поставляются с 3 категориями. Для отсутствующих категорий `dedup` и `ultra` без уведомления используются встроенные правила английского языка. Мы приветствуем добавление `dedup.json` и `ultra.json` в меньшие наборы.
>
> Набор `pt-BR` основан на **[Troglodita](https://github.com/leninejunior/troglodita)**, созданной Ленине Жуниором, — системе сжатия, разработанной с нуля для грамматики бразильского португальского языка (сокращение плеоназмов, удаление слов-паразитов PT-BR, технические сокращения для бразильского сообщества разработчиков).
>
> Канонический список категорий и схема каждой категории находятся в [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12).

## Определение языка

`languageDetector.ts` использует легковесные эвристики для определения языка по тексту промпта. Настроенный
язык по умолчанию по-прежнему учитывается, а определение языка можно отключить в конфигурации, когда требуется
точный контроль.

Результат определения используется только для выбора наборов правил. Он не влияет на маршрутизацию провайдеров, выбор
локали или язык пользовательского интерфейса.

## Структура конфигурации

Настройки сжатия могут включать:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` управляет значениями по умолчанию для панели управления и предварительного просмотра. `cavemanConfig` — это конфигурация движка времени выполнения,
используемая Caveman при сжатии текста сообщений.

## Добавление языкового пакета

1. Создайте `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Используйте формат правил Caveman из `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Применяйте замены консервативно и не изменяйте код, идентификаторы, URL-адреса или JSON.
4. Добавьте или обновите тесты для выбора языка и поведения замен.
5. Добавьте новые метки панели управления/i18n, если язык отображается в селекторах пользовательского интерфейса.

## API

Доступные пакеты можно запросить с помощью:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Конечная точка предварительного просмотра принимает переопределения конфигурации языка:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Во все 6 языковых пакетов в v3.8.0 было добавлено условие `SHARED_BOUNDARIES`, которое применяется при каждом
уровне интенсивности Caveman (LITE, FULL, ULTRA). Оно предписывает движку сохранять следующие шаблоны без изменений
независимо от удаления окружающих слов-паразитов:

| Тип шаблона                                | Пример                                 |
| ------------------------------------------ | -------------------------------------- |
| Ограждённые блоки кода                     | ` ```python\n...\n``` `                |
| Встроенный код                             | `` `my_var` ``                         |
| URL-адреса                                 | `https://example.com/path`             |
| Пути к файлам (абсолютные и относительные) | `/etc/hosts`, `./src/index.ts`         |
| Заголовки ошибок                           | `Error:`, `TypeError:`, `SyntaxError:` |
| Строки трассировки стека                   | `  at functionName (file.ts:12:3)`     |

Эти шаблоны задаются в `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (ранее `[]`). Эта
константа находится в `open-sse/services/compression/types.ts`.

### Почему это важно

Без SHARED_BOUNDARIES агрессивные режимы Caveman могли удалить содержимое, которое выглядело как повторяющийся
прозаический текст, но на самом деле являлось фрагментом кода, путём к файлу или стеком ошибок. SHARED_BOUNDARIES служит
независимым от языка защитным механизмом, применяемым до выполнения правил удаления слов-паразитов.

### Настройка preservePatterns

Дополнительные шаблоны можно добавить во время выполнения через настройки сжатия:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Пользовательские шаблоны дополняют (а не заменяют) 6 шаблонов по умолчанию.

## Примечания по эксплуатации

- Встроенные правила для английского языка остаются резервным вариантом при отсутствии языкового пакета.
- Недопустимые встроенные JSON-пакеты не проходят проверку, чтобы качество ресурсов выпуска не ухудшалось незаметно.
- Пакеты правил должны содержать только данные и не должны импортировать код или выполнять произвольную логику.
- Уровень аналитики сжатия записывает выбранные режим и движок, но не полный текст запроса.
