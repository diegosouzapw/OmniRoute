## Шаг 1: Установите OmniRoute

Выберите предпочтительный способ:

### Вариант A: npm (рекомендуется)

```bash
npm install -g omniroute
```

### Вариант B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` — это самая новая **опубликованная** стабильная версия SemVer. Этот тег **не** отслеживает ветку git `main`. Для GitOps закрепите версию с помощью `diegosouzapw/omniroute:X.Y.Z`. См. [Теги образов / каналы выпусков](../guides/DOCKER_GUIDE.md#release-channels).

### Вариант C: из исходного кода

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Шаг 2: Запустите OmniRoute

```bash
omniroute
```

OmniRoute запускается по адресу `http://localhost:20128`. Панель управления откроется автоматически.

---

## Шаг 3: Подключите бесплатного провайдера

Вы можете использовать OmniRoute **совершенно бесплатно**, подключив бесплатного провайдера.

### Вариант A: Kiro (бесплатный Claude — банковская карта не требуется)

1. Откройте панель управления по адресу `http://localhost:20128`
2. Перейдите в раздел **Провайдеры** → **Добавить провайдера**
3. Выберите **Kiro AI**
4. Нажмите **Подключить** (API-ключ не требуется!)
5. Готово! Теперь у вас есть бесплатный доступ к моделям Claude.

### Вариант B: OpenCode Free (без аутентификации)

1. Откройте панель управления по адресу `http://localhost:20128`
2. Перейдите в раздел **Провайдеры** → **Добавить провайдера**
3. Выберите **OpenCode Free**
4. Нажмите **Подключить** (API-ключ не требуется!)
5. Готово! Теперь у вас есть бесплатный доступ к нескольким моделям.

### Вариант C: Pollinations (ключ не требуется)

1. Откройте панель управления по адресу `http://localhost:20128`
2. Перейдите в раздел **Провайдеры** → **Добавить провайдера**
3. Выберите **Pollinations**
4. Нажмите **Подключить** (API-ключ не требуется!)
5. Готово! Теперь у вас есть бесплатный доступ к GPT-5, Claude, Gemini и другим моделям.

## Шаг 4: Проверьте работу

На странице [API-ключи](http://localhost:20128/dashboard/api-manager) создайте новый ключ. Сохраните его, поскольку он больше не будет отображаться. Обратите внимание: этот ключ предназначен для доступа инструментов к OmniRoute, а не для доступа к вышестоящим провайдерам.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Вы должны увидеть список подключённых моделей.

## Шаг 5: Укажите OmniRoute в своей IDE или CLI

В своей IDE или CLI задайте:

```
Базовый URL: http://localhost:20128/v1
API-ключ:    [скопируйте из панели управления → Конечные точки]
Модель:      auto
```

Вот и всё! Теперь ваша IDE использует OmniRoute с автоматическим выбором провайдера.

### Пример для IDE: VSCode/Continue.dev

1. Установите в VSCode расширение [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Добавьте следующие строки в файл `~/.continue/config.yaml`:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. На панели чата Continue.dev выберите `OmniRoute - Auto`, после чего запросы будут отправляться в OmniRoute.
4. (Необязательно) Упражнение для читателя: попросите свою IDE добавить в `config.yaml` все остальные готовые конфигурации 😊

### Пример для CLI: Codex CLI

1. Создайте постоянную переменную среды в своей операционной системе.
   Для macOS/Linux (добавьте в `~/.bashrc` или `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Для Windows (командная строка):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Теперь запустим Codex, настроенный для OmniRoute. Выполните:

```
omniroute launch-codex --model auto
```

Это можно сделать вручную с помощью `codex` и параметров командной строки, указав конечную точку и API-ключ, однако при использовании приведённой выше команды OmniRoute настроит всё за вас.

Такой же запуск одной командой доступен и для других CLI через универсальное средство запуска: `omniroute run <target>` поддерживает `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` и `gemini` (см. [Интеграции с CLI](../guides/CLI-INTEGRATIONS.md)).

3. Теперь CLI должен отправлять запросы в OmniRoute.

### Убедитесь, что ваш инструмент направляет запросы в OmniRoute

Подробности запроса можно просмотреть, выбрав пункт [Мониторинг/Журналы](http://localhost:20128/dashboard/logs) на левой боковой панели. Переход к записи покажет более подробную информацию. Кроме того, вы сможете увидеть, какие данные отправляет ваш любимый инструмент. Это полезно как для обучения, так и для отладки.

## Часто задаваемые вопросы

### «Нужен ли мне API-ключ?»

**Нет!** Вы можете использовать бесплатных провайдеров (Kiro, OpenCode Free, Pollinations) без API-ключа. Просто подключите их в панели управления.

### «Что такое `auto`?»

`auto` указывает OmniRoute автоматически выбирать лучшего провайдера для каждого запроса. При этом учитываются скорость, стоимость, качество и доступность. Подробности см. в [руководстве по Auto-Combo](./AUTO-COMBO-GUIDE.md).

### «Сколько это стоит?»

Сам OmniRoute является **бесплатным проектом с открытым исходным кодом**. Вы платите только за используемых провайдеров. У многих провайдеров есть бесплатные тарифы — см. [руководство по бесплатным тарифам](./FREE-TIERS-GUIDE.md).

### «Можно ли использовать его с Claude Code / Cursor / Copilot?»

**Да!** OmniRoute работает с любым инструментом, поддерживающим формат OpenAI. Просто укажите базовый URL `http://localhost:20128/v1`. Конкретные инструкции по настройке см. в [руководстве по инструментам CLI](../reference/CLI-TOOLS.md).

### «Что произойдёт, если провайдер перестанет работать?»

OmniRoute автоматически пропускает недоступных провайдеров и пробует следующего. Вам не нужно ничего делать. Подробности см. в [руководстве по Auto-Combo](./AUTO-COMBO-GUIDE.md).
