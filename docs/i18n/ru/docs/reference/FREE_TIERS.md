## TL;DR — какой объём бесплатного инференса фактически агрегирует OmniRoute?

Эти показатели относятся к отдельным сторонним учётным записям и условиям участия в рамках каталога. OmniRoute не предоставляет этот бюджет: вы должны самостоятельно получить необходимые учётные записи или учётные данные, подключить подходящих провайдеров и соблюдать установленные ими ограничения. Фактически доступный объём может быть ниже, вплоть до нуля на новой установке без подходящего маршрута. Провайдеры с пометкой `tos: avoid` по умолчанию исключены из автоматической маршрутизации.

**Проверено 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) предлагает единоразовый промокредит в размере $5, для получения которого требуется указать способ оплаты; срок его действия истекает через 30 дней. [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) публикует лимиты частоты запросов по проектам, моделям и уровням; он по-прежнему не включён в заявленный количественный месячный объём.

| Метрика                                                | Токенов / месяц                    | Значение                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------------ | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Документированный регулярный лимит (стабильный)**    | **~1.62B**                         | **Пулы** бесплатных тарифов (каталог по моделям), каждый общий пул учитывается **один раз**. Актуальный источник данных для `/api/free-tier/summary` и страницы Free-Tier Budget на панели управления. **Используйте это число.**                                                                                                                                                              |
| **+ первый месяц с приветственными кредитами**         | **~2.22B**                         | Стабильный лимит + единоразовые приветственные кредиты (Z.AI 20M, DeepSeek 5M, …), без повторного учёта в рамках одной учётной записи. **Только первый месяц** — не возобновляются.                                                                                                                                                                                                            |
| **+ постоянно бесплатно, без опубликованного лимита**  | _невозможно оценить количественно_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — реальный регулярный доступ с ограничениями по частоте запросов и параллелизму, но **без лимита токенов, который можно было бы учесть**. Перечисляются, но никогда не суммируются (подсчёт по формуле `RPM×24/7` привёл бы к завышению, которое мы считаем недопустимым). |
| **+ увеличение после внесения депозита**               | **+~24M**                          | Единоразовое пополнение баланса OpenRouter на **$10** увеличивает его бесплатный пул с 50 до 1000 запросов в день. Указывается отдельно, чтобы не завышать стабильный показатель.                                                                                                                                                                                                              |
| **+ после региональной проверки личности**             | **+~6M**                           | `modelscope` (привязка Alibaba Cloud + проверка реального имени в материковом Китае). Реальная регулярная квота, представленная как `gatedRecurringTokens` / `gatedProviders` и отображаемая на панели управления. Никогда не включается в основной показатель: +~6M после региональной проверки личности.                                                                                     |
| Теоретический максимум (все ограничения частоты, 24/7) | ~10B                               | Сумма ограничений частоты запросов всех провайдеров, экстраполированная на непрерывное использование. **Не является гарантией** — не указывайте это в заголовке.                                                                                                                                                                                                                               |

**Честный заголовок:** _OmniRoute агрегирует **~1.62B документированных бесплатных токенов в месяц** (до ~2.22B в первый месяц с приветственными кредитами) в 35 пулах бесплатных тарифов, а также множество постоянно бесплатных провайдеров без фиксированного лимита; сжатие RTK + Caveman (экономия токенов на 15–95%) позволяет использовать этот объём ещё эффективнее._

> **Почему показатель снизился с прежних ~1,94 млрд.** Обновление от 2026-06-17 — это корректировка для достоверности, а не потеря: `gemini` теперь дедуплицируется на уровне пула (ранее показатель был завышен из-за отдельного учёта каждого варианта Flash, 462 млн → 60 млн), значение `cloudflare-ai` исправлено до фактических 10 тыс. нейронов в день (122 млн → 30 млн), `doubao` переклассифицирован как одноразовый бонус за регистрацию (а не возобновляемый), а закрытые уровни удалены (`chutes`/`phind`/`kluster` прекратили работу). Снижение частично компенсировано `llm7` (исправлено на 5 млн в день → 150 млн) и новыми бесплатными провайдерами (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Дополнительно скорректировано до ~1,37 млрд в v3.8.42:** `longcat` был переклассифицирован с возобновляемого лимита 150 млн в месяц на одноразовый бонус 10 млн за регистрацию после завершения бесплатного ознакомительного периода. Применяется то же правило достоверности — ни один провайдер не был исключён по ошибке.
>
> **Обновлено 2026-08-26 после вывода Felo Web из эксплуатации:** Felo Web исключён, пока происхождение и лицензирование его производного от GPL кода остаются в статусе HOLD; на тот момент источник сообщал о 38 ключах пулов. Количество пулов обновляется в реальном времени и контролируется CI (`check:docs-counts` завершает сборку с ошибкой, если приведённые выше числа расходятся с `computeFreeModelTotals()`).
>
> **Повторно проверено 2026-09-02 по собственным страницам провайдеров** (источники: комментарии `// evidence:` рядом с каждой повторно проверенной записью в `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` больше не публикуют значения количества токенов (Google удалил бесплатную таблицу по моделям 2025-12-23; бесплатный план Ollama предоставляет «стартовые кредиты на использование») и теперь указаны как **неограниченные**, без включения в сумму (−80 млн); у `groq` есть пять лимитов в 200 тыс. TPD **на каждую модель** (по 6 млн, +15 млн), при этом три выведенных из эксплуатации ID удалены; у `nara` один пул на 7 млн в день (+60 млн, 210 млн). Лимит `mistral` в 1 млрд виден только в консоли учётной записи — см. раздел _Классы доказательств_ в Методологии.
>
> **Исправлено 2026-09-03 (#11773):** `cerebras` был переклассифицирован с возобновляемого лимита 30 млн в месяц (прежний пробный план без карты на 1 млн токенов в день) на одноразовый бонус $5 за регистрацию, для которого требуется способ оплаты. Применяется то же правило достоверности, что и для LongCat.
>
> **А также xKiro (2026-09-03):** новый пул `xkiro-free` (150 млн в месяц) добавляет 35-й ключ возобновляемого пула. Felo Web остаётся исключённым, пока происхождение и лицензирование его производного от GPL кода сохраняют статус HOLD. Теперь источник сообщает о **35 ключах возобновляемых пулов** и **стабильном объёме ~1,62 млрд** — это актуальное число, контролируемое CI (`check:docs-counts` завершает сборку с ошибкой, если оно расходится с `computeFreeModelTotals()`).

Крупнейшие **документально подтверждённые** источники: `mistral` — 1,00 млрд, `nara` — 210 млн, `llm7` — 150 млн, `xkiro` — 150 млн, `groq` — 30 млн (пять лимитов на отдельные модели), `cloudflare-ai` — 30 млн, `api-airforce` — 24 млн. (`longcat` исключён: его лимит LongCat-2.0 в 10 млн — это одноразовый бонус за регистрацию, требующий прохождения KYC, а не возобновляемый ежемесячный бюджет.)

> ⚠️ Теоретический максимум (~10 млрд) завышен за счёт провайдеров, ограниченных только частотой запросов и **не публикующих лимит токенов** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), для которых показатели рассчитывались бы как `RPM/TPM × 24/7 × 30d` — это теоретический максимум, который не сможет стабильно поддерживать ни одна отдельная учётная запись. Они **исключены** из обоснованного показателя (вместо этого приведены в строке «бесплатно навсегда, без лимита»). Именно такое завышение делает заявления конкурентов о многомиллиардных объёмах ненадёжными.

## Обновление от 2026-06-17 — что изменилось с 2026-06-05

Весь каталог был обновлён по результатам веб-исследования с участием 50 агентов (официальная документация + новости за последние 7 дней, с критической перепроверкой). Основные изменения:

- **Удалены / бесплатного тарифа нет (2026):** `chutes` (бесплатный тариф закрыт в 2026-03), `phind` (компания прекратила работу в 2026-01), `kluster` (закрыт 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (бесплатный доступ к MiMo отозван 2026-05-24, промоакция Nemotron завершилась в 2026-06 — повторно проверено 2026-06-18), `aimlapi` (бесплатный тариф приостановлен — повторно проверено 2026-06-18), `yi` (Yi-Light выведен из эксплуатации, действует оплата по мере использования — повторно проверено 2026-06-18), `featherless-ai` (в настоящее время бесплатного тарифа нет), `chipotle` («Pepper AI» от Chipotle — обратно спроектированный виджет чата Amelia по адресу `amelia.chipotle.com`, к которому обращался провайдер, теперь возвращает 404 на всех маршрутах, включая корневой; бэкенд выведен из эксплуатации или перемещён, подтверждено 2026-09-15 — полностью удалён из каталога, #13131/#4037). `iflytek` / `sparkdesk` остаются в списке, но снабжены предупреждением об условиях использования (Spark Lite бесплатен; условия использования ограничивают применение в качестве прокси/ретранслятора).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` отключены 2026-06-01, а `2.5 Pro` исключён из бесплатного тарифа (2026-04); теперь бесплатный тариф включает **только семейство Flash** (2.5/3/3.1/3.5 Flash + Gemma). Теперь каталог **объединяет в один пул** семейство Flash (ранее показатель был завышен из-за отдельного учёта каждого варианта: 462M → 60M).
- **Исправленные значения:** `cloudflare-ai` 122M → **30M** (фактически 10 тыс. Neurons/день), `doubao` переклассифицирован как однократный бонус за регистрацию (не возобновляется), `llm7` 4M → **150M** (документально подтверждённые 5M токенов/день), эндпоинты `together` с суффиксом «-Free» отключены → бонус $25 за регистрацию также удалён (требуется покупка минимум на $5, бесплатного пробного периода нет), период Preview для `longcat` завершён + модели Flash выведены из эксплуатации → осталась только **LongCat-2.0**, переклассифицированная как однократный бонус за регистрацию в размере **10M** токенов (требуется KYC, бонус не возобновляется).
- **Обнаружены новые бесплатные провайдеры:** ⭐ **Kilo Code** (`kilo-gateway` — ротируемый набор «Auto Free»: семейство NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 ротируемых бесплатных моделей для программирования), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash бесплатны на постоянной основе + бонус 20M за регистрацию), а также `arcee-ai` Trinity Large Preview.
- **Новые прозрачные категории тарифов** (см. «Методология»): категория _постоянно бесплатных тарифов без установленного лимита_ (реальный возобновляемый доступ без лимита токенов, который можно было бы учесть) и _увеличение лимита после внесения депозита_ (OpenRouter $10 → +24M/мес.); обе показываются **отдельно**, чтобы они никогда не завышали основной показатель.

## Два режима — подсчёт и принятие решений

OmniRoute отвечает на вопрос «бесплатно ли это?» в двух режимах, которые намеренно используют
разные источники:

| Режим                     | Источник истины                                                                                                                                                                     | Где используется                                                                                                                     |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Подсчёт / отображение** | Разрешённый каталог — поставляемая базовая версия с наложенными данными из ленты Radar (`getRadarCatalog`)                                                                          | Итоговые показатели бесплатных тарифов, карточка бюджета, панели мониторинга                                                         |
| **Принятие решений**      | Только поставляемый каталог (`FREE_MODEL_BUDGETS` в `open-sse/config/freeModelCatalog.data.ts`) вместе с локальными эвристиками (суффикс `:free`, нулевая цена, `grantsFreeAccess`) | Все потребители `src/shared/utils/freeModels.ts`: импорт моделей, маршрутизация `auto/*`, `GET /v1/models` и предпросмотр в браузере |

Результаты подсчёта могут улучшаться при каждом появлении доступной ленты данных. Принятие решений по-прежнему основывается на
артефакте релиза, поэтому ответ идентичен в браузере и на сервере,
воспроизводим в автономном режиме и допускает тестирование без базы данных. Если позволить браузерному
предпросмотру обращаться к одному источнику, а серверному импорту — к другому, предпросмотр
будет расходиться с фактическим результатом после нажатия — поэтому такое разделение сохранено
намеренно.

## Методология и оговорки

- Числа — это **оценки верхней границы**, основанные на документированных лимитах бесплатного уровня каждого провайдера по состоянию на **2026-06-17** и собранные в ходе веб-исследования. Бесплатные уровни постоянно меняются — перепроверяйте данные, прежде чем полагаться на конкретное значение.
- **Что именно подтверждает каждая запись.** Ни одна запись не имеет построчной оценки достоверности, и API её не предоставляет — рассматривайте каждое приведённое выше значение как оценку одинакового, неуказанного качества. Два факта отличаются, поскольку они курируются вручную, а не выводятся автоматически: у 44 записей есть независимо задокументированная жёсткая остановка (39 из них — строки xKiro, использующие одну и ту же суточную квоту), а у 13 записей есть сведения об использовании промптов для обучения. `hardStopGuaranteed` устанавливается только в том случае, если собственные условия провайдера явно указывают, что при превышении бесплатной квоты запрос будет отклонён, а не начнёт без предупреждения тарифицироваться; источник приводится в комментарии рядом с записью. По умолчанию это значение никогда не устанавливается в `true`, а у записи, которую никто не проверил, оно остаётся незаданным. Поэтому отсутствие флага жёсткой остановки означает «не установлено», а не «известно, что начнётся тарификация». **Режим STRICT** (опциональный защитный механизм маршрутизации `freeAccessPolicy=strict`) доверяет только записям с этим флагом; все остальные бесплатные уровни исключаются как `no-hard-stop` (см. `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Когда защитный механизм фильтрует пул, видимый оператору журнал сообщает как количество исключений, так и долю `no-hard-stop` среди них.
- `estMonthlyFreeTokens` = только ежемесячно возобновляемые токены. **Одноразовые кредиты за регистрацию не возобновляются** и учитываются как 0. Прекращённые уровни также учитываются как 0.
- Суточный лимит токенов → `monthly = daily × 30`. Если документирован только RPD → `RPD × ~800 выходных токенов × 30`. Если указаны только RPM/TPM (без суточного лимита) → **без лимита** (см. ниже).
- **Постоянно бесплатно, но опубликованного лимита токенов нет** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): это реальный, регулярно возобновляемый бесплатный доступ, ограниченный частотой запросов или параллелизмом. Мы классифицируем такие предложения как `recurring-uncapped` и **никогда не суммируем их** — умножение `RPM × 24/7 × 30d` дало бы фантастический верхний предел (такое завышение мы отвергаем). Они перечислены, чтобы вы знали об их существовании.
- **Повышение лимита после пополнения:** небольшое одноразовое пополнение, которое навсегда увеличивает бесплатную квоту (OpenRouter: $10 → 1000 запросов/день ≈ +24M/мес.). Указывается как отдельное значение и не включается в основной показатель постоянной квоты.
- **Квоты с ограничением по критериям доступа** (`eligibilityGate: "regional-identity"`): реальная возобновляемая квота, которая становится доступна только после привязанной к региону проверки личности (в настоящее время — верификация настоящего имени в материковом Китае). Она учитывается по тому же правилу дедупликации пулов в отдельном показателе (`gatedRecurringTokens`) и никогда не включается в основной показатель постоянной квоты. Режим (`freeType`) не меняется, поэтому маршрутизация также остаётся неизменной.
- **Классы доказательств.** Правило: число в каталоге сопровождается ссылкой на источник в комментарии `// evidence:` рядом с записью — `public-page` (страница провайдера, доступная любому пользователю), `api-public` (не требующая аутентификации конечная точка провайдера, например публичная конечная точка тарифных планов NaraRouter по адресу router.bynara.id) или `console-verified <date> por <who>` (значение видно только в консоли учётной записи; в комментарии указывается, кто и когда его видел, а также публичная страница, подтверждающая существование лимита). Текущее состояние: соответствующее указание есть у пяти блоков, повторно проверенных 2026-09-02 (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); записи, созданные до повторной проверки 2026-09-02, наследуют результаты более раннего исследования до тех пор, пока их не затронут; любое **новое или изменённое** число без комментария с доказательством является ошибкой. На сегодняшний день только `mistral` имеет статус console-verified.

## Почему наше число меньше, чем у других агрегаторов

Большинство показателей «бесплатных токенов в месяц» в этой области представляют собой суммы лимитов отдельных моделей. Мы намеренно считаем иначе:

- **Каждый общий пул учитывается один раз.** Бесплатный план Mistral предоставляет один лимит в 1B/месяц на организацию; перечисление его для пяти моделей не превращает его в 5B. Если суммировать по моделям, наш собственный каталог показал бы **~7.4B** (пересчитано 2026-09-03; этот показатель не контролируется CI — пересчитывайте его при каждом изменении каталога), однако в заголовке указано **~1.47B**, поскольку именно столько фактически можно потратить с одной учётной записи у каждого провайдера.
- **Дневные ограничения пересчитываются, ограничения частоты запросов — нет.** Задокументированное ограничение токенов в день преобразуется как `× 30`; задокументированное ограничение запросов в день — как `RPD × ~800 токенов × 30`; если провайдер публикует только число запросов в минуту, для него **не указывается** месячный объём и он обозначается как _без ограничения_, не включаясь в сумму. Умножение ограничения частоты запросов на режим 24/7 — это завышение, от которого мы отказываемся.
- **Квоты, доступные только после региональной проверки личности, указаны отдельно** (`+~6M после региональной проверки личности`), поскольку большинство читателей не могут ими воспользоваться.
- **Стартовые кредиты действуют только в первый месяц** и указываются отдельным числом, никогда не смешиваясь с постоянным показателем.
- **Показатель контролируется CI.** `npm run check:docs-counts` пересчитывает итоговые значения на основе каталога и прерывает сборку, если данные в этом файле, README или карточке бюджета расходятся с ними.

## OpenCode Free: ограничение клиентского контракта (#14313)

Провайдер `opencode` без ключа (публичный `https://opencode.ai/zen/v1`) отклоняет любой запрос,
который не соответствует клиентскому контракту OpenCode, с ошибкой **403 `FreeTierError`** и
сообщением _«Бесплатный тариф OpenCode можно использовать только из OpenCode»_. Это
отказ на уровне запроса (одинаковый результат для каждой учётной записи при одинаковой структуре запроса), а не
блокировка модели или период ожидания соединения — OmniRoute классифицирует его как `project_route_error`, пропускает
блокировку модели / период ожидания и (на синтетическом пути `noauth`) приостанавливает повторный автоматический выбор комбинации
на короткий TTL. Отправляйте запросы с непустым списком инструментов, `stream: true` и
заголовками сессии/UA OpenCode (`opencodeFreeTierContract.ts`), иначе ожидайте ошибку 403.

## Глоссарий

| Термин                      | Значение                                                                                            |
| --------------------------- | --------------------------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**         | Запросы в минуту / день / час                                                                       |
| **TPM / TPD**               | Токены в минуту / день                                                                              |
| **Документированная квота** | Провайдер публикует явное суточное/месячное ограничение на количество токенов (обоснованный бюджет) |
| **Теоретический предел**    | `rate-limit × 24/7 × 30d` — максимум, а не гарантированный бюджет                                   |
| **Нейрон**                  | Единица вычислений Cloudflare (~1 выходной токен)                                                   |
