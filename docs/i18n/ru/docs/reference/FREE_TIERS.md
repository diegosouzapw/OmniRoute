## TL;DR — какой объём бесплатного инференса фактически агрегирует OmniRoute?

| Метрика                                              | Токенов / месяц         | Значение                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Документированный регулярный лимит**               | **~1.62B**              | **Пулы** бесплатных тарифов (по каталогу моделей), каждый общий пул учитывается **один раз**. Актуальный источник данных для `/api/free-tier/summary` и страницы Free-Tier Budget на панели управления. **Используйте это число.**                                                                                                                                              |
| **+ первый месяц с бонусами за регистрацию**         | **~2.22B**              | Регулярный лимит + одноразовые бонусы за регистрацию (Z.AI 20M, DeepSeek 5M, …), без повторного учёта в рамках одной учётной записи. **Только первый месяц** — эти бонусы не возобновляются.                                                                                                                                                                                    |
| **+ навсегда бесплатно, без опубликованного лимита** | _невозможно подсчитать_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — реальный регулярный доступ, ограниченный частотой запросов/параллелизмом, **без лимита токенов, который можно было бы учесть**. Они перечисляются, но никогда не суммируются (подсчёт по формуле `RPM×24/7` привёл бы к завышению, которое мы отвергаем). |
| **+ увеличение после пополнения**                    | **+~24M**               | Одноразовое пополнение OpenRouter на **$10** повышает его бесплатный пул с 50 до 1000 запросов в день. Указывается отдельно, чтобы никогда не завышать регулярный показатель.                                                                                                                                                                                                   |
| **+ после региональной проверки личности**           | **+~6M**                | `modelscope` (привязка Alibaba Cloud + подтверждение личности для материкового Китая). Реальная регулярная квота, представленная как `gatedRecurringTokens` / `gatedProviders` и отображаемая на панели управления. Никогда не включается в основной показатель: +~6M после региональной проверки личности.                                                                     |
| Теоретический максимум (все лимиты частоты, 24/7)    | ~10B                    | Сумма лимитов частоты всех провайдеров, экстраполированная на непрерывное использование. **Не гарантируется** — не выносите это число в заголовок.                                                                                                                                                                                                                              |

**Честный заголовок:** _OmniRoute агрегирует **~1.62B документированных бесплатных токенов в месяц** (до ~2.22B в первый месяц с учётом бонусов за регистрацию) в 35 пулах бесплатных тарифов — плюс длинный список навсегда бесплатных провайдеров без лимита, — а сжатие RTK + Caveman (экономия токенов на 15–95%) позволяет использовать их ещё эффективнее._

> **Почему показатель снизился с прежних ~1.94B.** Обновление от 2026-06-17 — это корректировка ради достоверности, а не потеря: для `gemini` теперь устранён повторный учёт общего пула (ранее показатель был завышен из-за отдельного учёта каждого варианта Flash, 462M → 60M), показатель `cloudflare-ai` исправлен до фактических 10k Neurons/день (122M → 30M), `doubao` переклассифицирован как одноразовый бонус за регистрацию (а не регулярный), а закрытые тарифы удалены (`chutes`/`phind`/`kluster` прекратили работу). Это частично компенсировано `llm7` (правильное значение 5M/день → 150M) и новыми бесплатными провайдерами (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Дополнительно скорректировано до ~1.37B в v3.8.42:** `longcat` был переклассифицирован с регулярного лимита 150M/мес. на одноразовый бонус за регистрацию в размере 10M после завершения бесплатного предварительного периода. Применено то же правило достоверности — ни один провайдер не был удалён по ошибке.
>
> **Обновлено 2026-08-26 после прекращения поддержки Felo Web:** Felo Web исключён, пока происхождение/лицензирование производного от GPL кода остаётся в статусе HOLD; на тот момент источник сообщал о 38 ключах пулов. Количество пулов рассчитывается динамически и контролируется CI (`check:docs-counts` завершает сборку с ошибкой, если приведённые выше числа расходятся с `computeFreeModelTotals()`).
>
> **Повторно проверено 2026-09-02 по собственным страницам провайдеров** (источники: комментарии `// evidence:` рядом с каждой повторно проверенной записью в `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` больше не публикуют количество токенов (Google удалил бесплатную таблицу по моделям 2025-12-23; бесплатный план Ollama предоставляет «начальные кредиты на использование») и теперь указаны как **безлимитные**, но никогда не включаются в сумму (−80M); у `groq` имеется пять **отдельных для каждой модели** лимитов по 200K TPD (по 6M каждый, +15M), а три выведенных из эксплуатации ID удалены; у `nara` один пул на 7M/день (+60M, 210M). Лимит `mistral` в 1B виден только в консоли учётной записи — см. раздел _Классы доказательств_ в Методологии.
>
> **Исправлено 2026-09-03 (#11773):** `cerebras` был переклассифицирован с регулярного лимита 30M/мес. (старый пробный тариф без карты на 1M токенов/день) на одноразовый бонус за регистрацию в размере $5, для которого требуется способ оплаты. Применено то же правило достоверности, что и для LongCat.
>
> **Плюс xKiro (2026-09-03):** новый пул `xkiro-free` (150M/мес.) добавляет 35-й ключ регулярного пула. Felo Web остаётся исключённым, пока происхождение/лицензирование производного от GPL кода находится в статусе HOLD. Теперь источник сообщает о **35 ключах регулярных пулов** и **~1.62B на постоянной основе** — это актуальный показатель, контролируемый CI (`check:docs-counts` завершает сборку с ошибкой, если он расходится с `computeFreeModelTotals()`).

Крупнейшие **документированные** источники: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (пять отдельных лимитов для моделей), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` исключён — его лимит LongCat-2.0 в размере 10M является одноразовым, требующим KYC бонусом за регистрацию, а не регулярным ежемесячным бюджетом.)

> ⚠️ Теоретический предел (~10 млрд) завышен из-за провайдеров, ограничивающих только частоту запросов и **не публикующих лимит токенов** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), чьи показатели рассчитывались бы как `RPM/TPM × 24/7 × 30 дней` — это теоретический максимум, который не сможет стабильно поддерживать ни одна учётная запись. Они **исключены** из обоснованного значения (вместо этого они указаны в строке «бесплатно навсегда, без лимита»). Именно такое завышение делает заявления конкурентов о многомиллиардных объёмах недостоверными.

## Два режима — подсчёт и принятие решений

OmniRoute отвечает на вопрос «бесплатно ли это?» с помощью двух режимов, которые намеренно используют
разные источники:

| Режим                     | Источник истины                                                                                                                                                              | Где используется                                                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Подсчёт / отображение** | Разрешённый каталог — поставляемая базовая версия с наложенными данными из ленты Radar (`getRadarCatalog`)                                                                   | Общие показатели бесплатного уровня, карточка бюджета, панели мониторинга                                                            |
| **Принятие решений**      | Только поставляемый каталог (`FREE_MODEL_BUDGETS` в `open-sse/config/freeModelCatalog.data.ts`) плюс локальные эвристики (суффикс `:free`, нулевая цена, `grantsFreeAccess`) | Все потребители `src/shared/utils/freeModels.ts`: импорт моделей, маршрутизация `auto/*`, `GET /v1/models` и предпросмотр в браузере |

Подсчёт может становиться точнее всякий раз, когда доступна лента данных. Принятие решений остаётся привязанным к
артефакту релиза, поэтому ответ одинаков в браузере и на сервере,
воспроизводим офлайн и тестируем без базы данных. Если бы предпросмотр в браузере
использовал один источник, а серверный импорт — другой, предпросмотр расходился бы
с тем, что происходит после нажатия, поэтому такое разделение сохранено
намеренно.

## Методология и оговорки

- Числа являются **оценками верхней границы**, основанными на документированных лимитах бесплатного уровня каждого провайдера по состоянию на **2026-06-17** и собранными в ходе веб-исследования. Бесплатные уровни постоянно меняются — перепроверьте данные, прежде чем полагаться на какое-либо значение.
- **Что именно подтверждает каждая запись.** Для отдельных строк не указывается уровень достоверности, и API его не предоставляет — считайте каждое приведённое выше значение оценкой одинакового, явно не указанного качества. Два факта отличаются, поскольку они проверяются вручную, а не выводятся автоматически: 44 записи имеют независимо документированный жёсткий предел (39 из них — строки xKiro, использующие один и тот же суточный лимит), а 13 записей содержат сведения об использовании запросов для обучения. `hardStopGuaranteed` устанавливается только тогда, когда в собственных условиях провайдера указано, что при превышении бесплатного лимита запрос будет отклонён, а не приведёт к незаметному началу списания средств; источник приводится в комментарии рядом с записью. Значение никогда не устанавливается в `true` по умолчанию, а у записи, которую никто не проверил, оно остаётся незаданным. Поэтому отсутствие флага жёсткого предела означает «не установлено», а не «известно, что начнётся списание средств». **Режим STRICT** (добровольно включаемое ограничение маршрутизации `freeAccessPolicy=strict`) доверяет только записям с этим флагом; любой другой бесплатный уровень исключается как `no-hard-stop` (см. `open-sse/services/autoCombo/strictZeroCostFilter.ts`).
- `estMonthlyFreeTokens` = только регулярно предоставляемые ежемесячные токены. **Разовые бонусы при регистрации не возобновляются** и учитываются как 0. Прекращённые уровни также учитываются как 0.
- Суточный лимит токенов → `monthly = daily × 30`. Если документирован только RPD → `RPD × ~800 выходных токенов × 30`. Если указаны только RPM/TPM (без суточного лимита) → **без верхнего предела** (см. ниже).
- **Постоянно бесплатные, но без опубликованного лимита токенов** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): это реально существующий регулярно предоставляемый бесплатный доступ, ограниченный частотой запросов или параллелизмом. Мы классифицируем такие варианты как `recurring-uncapped` и **никогда не суммируем их** — умножение `RPM × 24/7 × 30d` дало бы фантастический потолок (мы отвергаем подобное завышение). Они перечислены, чтобы вы знали об их существовании.
- **Повышение лимита после пополнения:** небольшое разовое пополнение, которое навсегда увеличивает бесплатную квоту (OpenRouter: $10 → 1000 запросов в день ≈ +24M в месяц). Указывается отдельным значением и не включается в основной показатель стабильной квоты.
- **Квоты с проверкой права на доступ** (`eligibilityGate: "regional-identity"`): реальная регулярно предоставляемая квота, которая становится доступна только после привязанной к региону проверки личности (на сегодняшний день — подтверждение настоящего имени в материковом Китае). С учётом того же правила устранения дубликатов пулов она включается в отдельный показатель (`gatedRecurringTokens`) и никогда не входит в основной показатель стабильной квоты. Режим (`freeType`) не меняется, поэтому маршрутизация также остаётся неизменной.
- **Классы доказательств.** Правило: число в каталоге сопровождается ссылкой на источник в комментарии `// evidence:` рядом с записью — `public-page` (страница провайдера, доступная любому пользователю), `api-public` (не требующая аутентификации конечная точка провайдера, например общедоступная конечная точка тарифов NaraRouter по адресу router.bynara.id) или `console-verified <date> por <who>` (значение видно только в консоли учётной записи; в комментарии указывается, кто и когда его видел, а также общедоступная страница, подтверждающая наличие лимита). Текущее состояние: пять блоков, повторно проверенных 2026-09-02, содержат такие комментарии (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); записи, появившиеся до повторной проверки 2026-09-02, наследуют результаты более раннего исследования, пока их не обновят; любое **новое или изменённое** число без комментария с доказательством является ошибкой. На сегодняшний день только `mistral` имеет статус `console-verified`.

## Почему наша цифра меньше, чем у других агрегаторов

Большинство показателей «бесплатных токенов в месяц» в этой сфере представляют собой суммы значений, указанных для каждой модели. Наша цифра намеренно рассчитывается иначе:

- **Каждый общий пул учитывается один раз.** Бесплатный план Mistral предоставляет один лимит в 1B токенов в месяц на организацию; перечисление его для пяти моделей не превращает этот лимит в 5B. При суммировании по моделям наш собственный каталог показывал бы **~7.4B** (пересчитано 2026-09-03; эта цифра не контролируется CI — пересчитывайте её при каждом изменении каталога), однако в заголовке указано **~1.47B**, поскольку именно столько фактически может использовать один аккаунт у каждого провайдера.
- **Суточные лимиты пересчитываются, ограничения скорости — нет.** Задокументированный лимит токенов в день преобразуется как `× 30`; задокументированный лимит запросов в день — как `RPD × ~800 токенов × 30`; если провайдер публикует только количество запросов в минуту, для него **не указывается** месячный объём и он помечается как _безлимитный_, но никогда не включается в сумму. Умножение ограничения скорости на режим 24/7 — это завышение, от которого мы отказываемся.
- **Квоты, доступные после региональной проверки личности, показываются отдельно** (`+~6M после региональной проверки личности`), поскольку большинство читателей не могут ими воспользоваться.
- **Кредиты за регистрацию действуют только в первый месяц** и указываются второй отдельной цифрой, никогда не объединяясь с постоянным объёмом.
- **Значение контролируется CI.** `npm run check:docs-counts` пересчитывает итоговые значения на основе каталога и завершает сборку с ошибкой, если данные в этом файле, README или карточке бюджета перестают им соответствовать.

## Глоссарий

| Термин                      | Значение                                                                                            |
| --------------------------- | --------------------------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**         | Запросы в минуту / день / час                                                                       |
| **TPM / TPD**               | Токены в минуту / день                                                                              |
| **Документированная квота** | Провайдер публикует явное суточное/месячное ограничение на количество токенов (обоснованный бюджет) |
| **Теоретический максимум**  | `rate-limit × 24/7 × 30d` — максимум, а не гарантированный бюджет                                   |
| **Нейрон**                  | Единица вычислений Cloudflare (~1 выходной токен)                                                   |
