OmniRoute поставляется с тщательно отобранным набором бесплатных прокси в таблице `free_proxies`,
синхронизируемым с внешними поставщиками (1proxy, proxifly, iplocate, webshare). На
панели управления они доступны в разделе **Настройки → Бесплатные прокси**. В этом документе
описаны серверная фильтрация, сортировка, подсчёт и отображение ошибок синхронизации,
предоставляемые маршрутом списка.

## Маршрут списка — `GET /api/settings/free-proxies`

Возвращает отфильтрованный, отсортированный и разбитый на страницы набор данных, а также общее количество записей. Фильтрация и
подсчёт выполняются в SQL, поэтому интерфейс может отображать фактическое общее количество (например, `Всего: 0`),
не загружая все строки в память.

### Параметры запроса

| Параметр          | Тип                                | По умолчанию | Значение                                                                                                                    |
| ----------------- | ---------------------------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `search`          | строка                             | `""`         | Регистрозависимый `LIKE` для столбца хоста (и источника).                                                                   |
| `protocol`        | строка                             | `""`         | Фильтр `type`: `http` / `https` / `socks4` / `socks5`. Пустое значение = все.                                               |
| `country`         | строка                             | `""`         | Фильтр `countryCode` (ISO-2). Пустое значение = все.                                                                        |
| `minQuality`      | число                              | `0`          | Только строки, где `qualityScore >= minQuality`. `0` = без нижней границы.                                                  |
| `disabledSources` | строка                             | `""`         | Разделённые запятыми идентификаторы исключаемых источников (например, `proxifly,webshare`).                                 |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`    | `quality` = оценка по убыванию; `latency` = задержка по возрастанию (null в конце); `recent` = `lastValidated` по убыванию. |
| `offset`          | число                              | `0`          | Начальная позиция пагинации.                                                                                                |
| `limit`           | число                              | `50`         | Размер страницы (ограничивается на стороне сервера).                                                                        |

### Ответ

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` отражает общее количество отфильтрованных записей **до** применения пагинации, поэтому интерфейс может отображать
`Всего: N` и `hasMore` независимо друг от друга. Объект `syncErrors` индексируется по идентификатору источника и
заполняется только для источников, последняя синхронизация которых завершилась ошибкой, — результат `Всего: 0`
никогда не отображается без пояснения.

## Добавление в пул — `POST /api/settings/free-proxies/[id]/add-to-pool`

Перемещает бесплатный прокси в управляемый пул `proxy_registry`. Сначала проверяет
внешний прокси; при успешной проверке возвращает идентификатор нового прокси в пуле и измеренную задержку.

## Синхронизация — `POST /api/settings/free-proxies/sync`

Повторно получает данные из всех включённых источников (или из подмножества, указанного в `{ "sources": [...] }`). Каждый
источник синхронизируется независимо; источник, завершившийся с ошибкой, записывается в `syncErrors`, а
остальные продолжают работу, поэтому частичная синхронизация никогда не удаляет ранее полученные корректные данные.

## Статистика — `GET /api/settings/free-proxies/stats`

Возвращает агрегированные данные `total / inPool / avgQuality / bySource / lastSyncAt`
без строк с данными — используется виджетами заголовка панели управления.
