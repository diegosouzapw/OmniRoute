1. Зафиксировать существующий контракт семафора с одним ключом и новый атомарный контракт с несколькими ключами с помощью целевых тестов: отсутствие частичных резервирований, очередь FIFO, прерывание, тайм-аут, переполнение очереди, идемпотентное освобождение, статистика и очистка.
2. Обобщить существующий семафор учётных записей без изменения его расположения. Сохранить `acquire()` как обёртку для обратной совместимости над `acquireMany()`; не добавлять второй планировщик или зависимость.
3. Заменить получение разрешения только для учётной записи в `chatCore` на единое совокупное получение разрешений для глобального уровня, провайдера и учётной записи непосредственно перед `withRateLimit`. Повторно получать весь набор всякий раз, когда ротация учётных записей изменяет подключение, и удерживать разрешения до завершения потоковой передачи.
4. Расширить существующий конвейер настроек отказоустойчивости (типы, значения по умолчанию, нормализация, схема, ответ API, UI и переводы), добавив глобальные ограничения и ограничения провайдера. Переименовать прежний параметр управления параллелизмом Bottleneck в параллелизм уровня подключения/квоты, чтобы явно отразить его фактическую область действия.
5. Запустить целевые тесты, линтер, проверку типов, статические проверки и полный набор тестов; задокументировать изменение поведения в журнале изменений.

Намеренно сохранённое поведение: нулевое значение/`null` для параллелизма обходит ограничитель, вызовы только для учётных записей продолжают использовать `acquire()`, средства управления заблокированными учётными записями сохраняют формат ключей и API, а поведение очереди ограничения частоты запросов провайдера остаётся неизменным.
