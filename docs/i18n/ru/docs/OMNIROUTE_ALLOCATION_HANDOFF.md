Распределение — это не квота провайдера.

Пулы квот определяют, какие API-ключи могут использовать пул провайдера и как применяются жёсткие, мягкие политики или политики кратковременного превышения. Квота провайдера — это внешняя доступная ёмкость, о которой сообщает провайдер или явно настроенный источник. Внутренние бюджеты Ghostlight — это административные ограничения, задаваемые администратором.

Операция `ensurePool` идемпотентна: идентичный пул не изменяется, изменённое распределение обновляется, а отсутствующий пул создаётся. Она предназначена для автоматизации и API-клиентов с ограниченными правами.

Эндпоинт состояния только для чтения: `GET /api/omniroute/status`. Команда проверки — `npm run omniroute:verify`; она не выполняет запросов к активной модели.
