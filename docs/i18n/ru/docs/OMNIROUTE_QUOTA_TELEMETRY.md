OmniRoute отделяет телеметрию квот провайдера от учёта Ghostlight.

## Достоверные состояния

- `healthy` означает, что источник сообщил о наличии доступного остатка ресурсов.
- `approaching_limit` означает, что источник сообщил об остатке ресурсов на уровне настроенного порогового значения или ниже него.
- `exhausted` выдаётся только в том случае, если источник сообщает о нулевом остатке ресурсов или о достижении лимита использования.
- `unavailable` означает, что поддерживаемому источнику не удалось вернуть данные.
- `unknown` означает, что поддерживаемый источник отсутствует или лимит провайдера неизвестен.

Неизвестное состояние не означает исчерпание ресурсов и не приводит к отключению провайдера.

Источники используются в следующем порядке предпочтения: официальный API провайдера, аутентифицированный API использования, явно сопоставленные заголовки ответа, конфигурация администратора, локальные оценки, неизвестное состояние. Локальные оценки никогда не представляются как данные провайдера для выставления счетов.

Заголовки ответа анализируются только на основе явного сопоставления для конкретного провайдера. Не предполагается, что универсальные имена заголовков применимы глобально.
