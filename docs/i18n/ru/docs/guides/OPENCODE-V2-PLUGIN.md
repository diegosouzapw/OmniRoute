`@omniroute/opencode-plugin-v2` добавляет весь ваш каталог OmniRoute — модели, комбо и
автокомбо — в средство выбора моделей OpenCode v2 вместе с отображаемыми именами, ценами и
лимитами бесплатного уровня.

Это отдельный пакет, не связанный с `@omniroute/opencode-plugin`, поскольку OpenCode v1 и v2 загружают
плагины через разные контракты. Выберите пакет, соответствующий основной версии OpenCode; между
ними нет общих компонентов, поэтому обновление одного никогда не требует обновления другого.

## Требования

- OpenCode v2.
- Доступный шлюз OmniRoute (`http://localhost:20128` по умолчанию).
- Node.js 22 или 24.

## Установка

Добавьте плагин в `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

После этого модели появятся в виде `omniroute/<provider>/<model>`; `providerId` определяет этот префикс и
идентификатор интеграции, под которым OpenCode хранит учётные данные.

## Учётные данные

Плагин ищет ключ шлюза в трёх местах в следующем порядке:

1. **Учётные данные, подключённые в OpenCode.** Плагин регистрирует интеграцию, поэтому
   собственный механизм аутентификации OpenCode может сохранить ключ. В `opencode.json` ничего не записывается — предпочитайте этот вариант.
2. `apiKey` в параметрах плагина для переопределения на уровне проекта. При этом ключ помещается в файл,
   который вы можете фиксировать в системе контроля версий.
3. `OMNIROUTE_API_KEY` в окружении.

Если ключ не найден ни в одном из этих мест, каталог будет пуст, и плагин один раз сообщит об этом при запуске,
вместо того чтобы молча оставить средство выбора пустым.

### Токен управления — это другой ключ

Комбо, состояние провайдеров и обогащение данных (отображаемые имена, цены, лимиты бесплатного уровня) поступают
из конечных точек шлюза `/api/*`, которые в большинстве развёртываний защищены **управляющим** токеном,
а не ключом для инференса:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Если `managementReadToken` не задан, вместо него используется `apiKey`. Если шлюз отклоняет такой резервный вариант,
каталог всё равно публикуется, но с исходными идентификаторами моделей вместо отображаемых имён, без устранения
дубликатов канонических псевдонимов, без цен и без комбо. Плагин выводит предупреждение по одному разу для каждой
конечной точки, когда это происходит, указывая конечную точку и какие данные были потеряны, — поэтому причина
ограниченной функциональности средства выбора всегда будет понятна.

## Параметры

| Ключ                             | По умолчанию                                           | Примечания                                                                                                                |
| -------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                          | Идентификатор провайдера, идентификатор интеграции и префикс, под которым отображаются модели                             |
| `baseURL`                        | обязателен                                             | Корневой адрес шлюза, только `http(s)`; суффикс `/v1` добавляется при необходимости                                       |
| `apiKey`                         | подключённые учётные данные, затем `OMNIROUTE_API_KEY` | Ключ чата для `/v1/*`                                                                                                     |
| `managementReadToken`            | резервно используется `apiKey`                         | Ключ для `/api/*` — обычно **не** тот же самый                                                                            |
| `displayName`                    | `"OmniRoute"`                                          | Имя провайдера в средстве выбора                                                                                          |
| `timeoutMs`                      | `10000`                                                | Тайм-аут запроса к каждой конечной точке (для автокомбо используется 5 с)                                                 |
| `modelCacheTtlMs`                | `300000`                                               | TTL кеша каталога; снимок на диске ускоряет холодный запуск                                                               |
| `timeouts`                       | резервно используется `timeoutMs`                      | Лимиты времени для конечных точек в мс: `models`, `combos`, `autoCombos`, `enrichment`                                    |
| `enrichment`                     | `true`                                                 | Получать имена, цены и лимиты бесплатного уровня                                                                          |
| `providerTag`                    | `true`                                                 | Добавлять к отображаемому имени префикс вышестоящего провайдера, к которому направляется запрос                           |
| `usableOnly`                     | `false`                                                | Оставлять только провайдеров, которые шлюз считает настроенными                                                           |
| `visibleModels` / `hiddenModels` | `[]`                                                   | Списки разрешений по точному совпадению или суффиксу; запрет имеет приоритет                                              |
| `geminiSanitization`             | `true`                                                 | Удалять из схем инструментов ключевые слова JSON Schema, отклоняемые Gemini (инструменты `$ref` передаются без изменений) |
| `apiFormat.allowAnthropic`       | `false`                                                | Направлять идентификаторы из списка разрешений через блок API Anthropic                                                   |
| `apiFormat.anthropicModels`      | `[]`                                                   | Полные идентификаторы моделей, направляемых в Anthropic                                                                   |
| `logLevel` / `startupDebug`      | `warn` / `false`                                       | Уровень подробности журналирования                                                                                        |

## Как каталог поддерживается в актуальном состоянии

Каталог загружается лениво и кешируется на время `modelCacheTtlMs`, а снимок на диске сохраняет
последнюю известную версию каталога доступной, когда шлюз недоступен — при сбое вы теряете только
актуальность данных. Модели и комбинации публикуются сразу после получения; автокомбинации, список
провайдеров и слой обогащения добавляются по мере поступления, поэтому одна медленная конечная точка
не может заблокировать весь интерфейс выбора.

Названия содержат известные шлюзу сведения: вышестоящего провайдера, к которому направляется модель,
маркер `[Free]` и соответствующий бюджет — поэтому два подключения, предлагающие одну и ту же модель,
остаются различимыми. Отключите префикс с помощью `"providerTag": false`.

Команды ручного обновления нет: команды OpenCode v2 являются шаблонами запросов, а не обратными
вызовами, поэтому плагин не может предоставить такую команду. Обновления выполняются в соответствии
с TTL; запрос на перезагрузку отправляется хосту, только когда каталог или слой обогащения
действительно изменился, а не при каждом обновлении.

## Вызов инструментов в Gemini

Gemini отклоняет весь запрос, если объявления инструментов содержат `$schema` или
`additionalProperties`, отвечая `400 INVALID_ARGUMENT`. Плагин удаляет эти ключевые слова из схем
инструментов, предназначенных для модели Gemini этого провайдера, и не изменяет остальные запросы.
Инструмент, содержащий `$ref`, пересылается без изменений, поскольку удаление ссылки расширило бы
схему до «принимать что угодно».
Установите `"geminiSanitization": false`, чтобы отключить эту функцию.

## Устранение неполадок

| Симптом                                                     | Причина                                                                                                       |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| В списке выбора нет модели OmniRoute                        | Ключ не найден (проверьте предупреждение при запуске) или шлюз недоступен                                     |
| Необработанные идентификаторы моделей, без комбинаций и цен | Конечные точки управления отклонили токен — задайте `managementReadToken`                                     |
| Сеанс закреплён за `opencode-<id>/…`                        | Плагин v1 публиковал `opencode-<id>`; v2 публикует просто `<id>`, поэтому повторно выберите модель в `<id>/…` |
