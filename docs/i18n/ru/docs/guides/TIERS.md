OmniRoute распределяет 352 поддерживаемых провайдера по 3 экономическим уровням. Каждый запрос последовательно проходит через них, пока один из провайдеров не вернёт успешный ответ — вы получаете самый дешёвый доступный ответ без необходимости писать код для резервного переключения.

## Уровень 1 — Подписка

**Провайдеры, за которых вы уже платите.** OmniRoute использует весь доступный объём квоты до истечения срока её действия.

| Провайдер                       | Почему уровень 1                                                          |
| ------------------------------- | ------------------------------------------------------------------------- |
| Claude Code OAuth               | Anthropic Pro/Team — фиксированная плата, часто не используется полностью |
| OpenAI Codex (подписка ChatGPT) | Plus/Team включает квоту Codex                                            |
| GitHub Copilot                  | Оплата за пользователя — квота сбрасывается ежемесячно                    |
| Cursor IDE                      | Квота плана Pro                                                           |
| Antigravity / Devin Desktop     | Встроенные квоты                                                          |

**Стратегия**: сначала направлять сюда каждый запрос, соответствующий сильным сторонам модели. Трекер квот отслеживает приближающиеся сбросы, а комбинированная стратегия `reset-aware` соответствующим образом расставляет приоритеты. Чтобы сначала направлять запросы на уровень 1 и переходить к платным уровням только по мере исчерпания квоты, используйте идентификатор `auto/thrifty` — либо `auto/subscription`, чтобы оставаться в пределах включённых в план ресурсов и завершать запрос ошибкой при их недоступности. См.
[Маршрутизация с приоритетом подписок](../routing/SUBSCRIPTION_LADDER.md).

## Уровень 2 — Недорогие

**Провайдеры с оплатой за токены стоимостью менее $1 за 1 млн токенов.** Зарезервированы для задач с высокой нагрузкой или случаев, когда квоты уровня 1 исчерпаны.

| Провайдер                        | Цена (ввод/вывод)      | Сильные стороны                       |
| -------------------------------- | ---------------------- | ------------------------------------- |
| DeepSeek V4 Pro                  | $0.27 / $1.10 за 1 млн | Код, рассуждения                      |
| GLM-4.5                          | $0.60 / $2.20 за 1 млн | Большой контекст                      |
| MiniMax M1                       | $0.20 / $1.10 за 1 млн | Скорость                              |
| Qwen Coder                       | $0.30 / $1.20 за 1 млн | Код                                   |
| OpenRouter (оптимизация по цене) | варьируется            | Более 100 моделей, динамический выбор |

**Стратегия**: комбинация `cost-optimized` выбирает модель с минимальной стоимостью токена, которая соответствует фильтру возможностей задачи (зрение, режим JSON, инструменты, максимальный контекст).

## Уровень 3 — Бесплатные

**Провайдеры с нулевой стоимостью** — бесплатные планы, кредитные программы, ежедневные квоты OAuth.

| Провайдер        | Бесплатная квота / кредиты                                                |
| ---------------- | ------------------------------------------------------------------------- |
| Kiro AI          | Бесплатный уровень Claude (щедрая политика добросовестного использования) |
| OpenCode Free    | Авторизация не требуется, щедрые ограничения частоты запросов             |
| Qoder            | Бесплатный OAuth                                                          |
| Google Vertex AI | $300 в виде кредитов для новых аккаунтов                                  |
| Amazon Q         | Бесплатный уровень для пользователей AWS                                  |
| Pollinations     | Открытый публичный API                                                    |
| Cloudflare AI    | Бесплатный уровень Workers AI                                             |

**Стратегия**: комбинация `auto` с ограничением бюджета направляет запросы сюда, когда уровни 1 и 2 недоступны или когда задано `useFreeOnly=true`. У бесплатных провайдеров часто действуют более строгие ограничения частоты запросов — автоматический предохранитель восстанавливает их доступность после периода ожидания.

## Настройка уровней

Панель управления → **Уровни** → назначьте своих провайдеров. Значения по умолчанию (из `tierDefaults.json`) подходят для большинства случаев; измените их, если необходимо приоритизировать определённые подписки или исключить отдельных провайдеров.

Система оценки Auto-Combo по 16 факторам также учитывает уровень. См.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Телеметрия

Панель управления → **Использование** показывает количество токенов, израсходованных на каждом уровне за день. Используйте эти данные, чтобы:

- Убедиться, что уровень 1 используется полностью (иначе ценность подписки расходуется впустую)
- Определить, какие модели уровня 2 выбираются чаще всего (сократить их количество до 1–2)
- Убедиться, что уровень 3 помогает экономить на тестовых и исследовательских задачах

## Распространённые сценарии

### Полностью бесплатная рабочая нагрузка

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Сильно смещает выбор в сторону уровня 3; уровень 2 используется только в том случае, если уровень 3 недоступен.

### Сначала подписка, затем недорогой резервный вариант

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Явный упорядоченный список, соответствующий последовательности: уровень 1 → уровень 2 → уровень 3.
