В этом руководстве описано, как полностью удалить OmniRoute из вашей системы.

---

## Быстрое удаление (v3.6.2+)

OmniRoute предоставляет два встроенных скрипта для полного удаления:

### Сохранение данных

```bash
npm run uninstall
```

Эта команда удаляет приложение OmniRoute, но **сохраняет** базу данных, конфигурации, API-ключи и настройки провайдеров в `~/.omniroute/`. Используйте её, если планируете переустановить приложение позже и хотите сохранить свои настройки.

### Полное удаление

```bash
npm run uninstall:full
```

Эта команда удаляет приложение **и безвозвратно стирает** все данные:

- Базу данных (`storage.sqlite`)
- Конфигурации провайдеров и API-ключи
- Файлы резервных копий
- Файлы журналов
- Все файлы в каталоге `~/.omniroute/`

> ⚠️ **Предупреждение:** действие `npm run uninstall:full` необратимо. Все подключения к провайдерам, комбинации, API-ключи и история использования будут безвозвратно удалены.

## Удаление вручную

### Глобальная установка через NPM

```bash
# Удаление глобального пакета
npm uninstall -g omniroute

# (Необязательно) Удаление каталога данных
rm -rf ~/.omniroute
```

### Глобальная установка через pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Остановка и удаление контейнера
docker stop omniroute
docker rm omniroute

# Удаление тома (удаляет все данные)
docker volume rm omniroute-data

# (Необязательно) Удаление образа
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Остановка и удаление контейнеров
docker compose down

# Также удаляет тома (удаляет все данные)
docker compose down -v
```

### Настольное приложение Electron

**Windows:**

- Откройте `Параметры → Приложения → OmniRoute → Удалить`
- Или запустите деинсталлятор NSIS из каталога установки

**macOS:**

- Перетащите `OmniRoute.app` из `/Applications` в Корзину
- Удалите данные: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Удалите файл AppImage
- Удалите данные: `rm -rf ~/.omniroute`

### Установка из исходного кода (git clone)

```bash
# Удаление клонированного каталога
rm -rf /path/to/omniroute

# (Необязательно) Удаление каталога данных
rm -rf ~/.omniroute
```

## Каталоги данных

По умолчанию OmniRoute хранит данные в следующих расположениях:

| Платформа         | Путь по умолчанию               | Переопределение                        |
| ----------------- | ------------------------------- | -------------------------------------- |
| Linux             | `~/.omniroute/`                 | Переменная окружения `DATA_DIR`        |
| macOS             | `~/.omniroute/`                 | Переменная окружения `DATA_DIR`        |
| Windows           | `%APPDATA%/omniroute/`          | Переменная окружения `DATA_DIR`        |
| Docker            | `/app/data/` (подключённый том) | Переменная окружения `DATA_DIR`        |
| Совместимые с XDG | `$XDG_CONFIG_HOME/omniroute/`   | Переменная окружения `XDG_CONFIG_HOME` |

### Файлы в каталоге данных

| Файл/каталог         | Описание                                                        |
| -------------------- | --------------------------------------------------------------- |
| `storage.sqlite`     | Основная база данных (провайдеры, комбинации, настройки, ключи) |
| `storage.sqlite-wal` | Журнал упреждающей записи SQLite (временный)                    |
| `storage.sqlite-shm` | Общая память SQLite (временная)                                 |
| `call_logs/`         | Архивы содержимого запросов                                     |
| `backups/`           | Автоматические резервные копии базы данных                      |
| `log.txt`            | Устаревший журнал запросов (необязательно)                      |

## Проверка полного удаления

После удаления убедитесь, что никаких файлов не осталось:

```bash
# Проверка глобального пакета npm
npm list -g omniroute 2>/dev/null

# Проверка каталога данных
ls -la ~/.omniroute/ 2>/dev/null

# Проверка запущенных процессов
pgrep -f omniroute
```

Если какой-либо процесс всё ещё запущен, остановите его:

```bash
pkill -f omniroute
```
