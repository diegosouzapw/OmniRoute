OmniRoute поставляется как полностью устанавливаемое прогрессивное веб-приложение. Когда вы открываете панель управления в любом мобильном браузере — Chrome на Android или Safari на iOS, — вы можете выбрать «Добавить на главный экран» и получить возможности, аналогичные нативному приложению, без использования магазина приложений.

## Что такое PWA?

Прогрессивное веб-приложение превращает веб-панель управления OmniRoute в приложение, которое выглядит и работает как нативное мобильное приложение. После установки оно:

- Запускается с главного экрана с помощью собственного значка
- Открывается в полноэкранном режиме — без адресной строки браузера и интерфейса вкладок
- Работает без подключения к сети благодаря отдельной странице состояния подключения
- Кэширует статические ресурсы для ускорения загрузки
- Поддерживает как книжную, так и альбомную ориентацию

## Установка

### Android (Chrome)

1. Откройте панель управления OmniRoute в Chrome: `http://YOUR_IP:20128`
2. Chrome автоматически отобразит баннер **«Добавить OmniRoute на главный экран»**, либо:
   - Нажмите меню **⋮** (три точки) → **«Добавить на главный экран»** или **«Установить приложение»**
3. Подтвердите действие
4. OmniRoute появится на главном экране как отдельное приложение

### iOS (Safari)

1. Откройте панель управления OmniRoute в Safari: `http://YOUR_IP:20128`
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой)
3. Прокрутите вниз и нажмите **«На экран „Домой“»**
4. Укажите название (по умолчанию — «OmniRoute») и нажмите **«Добавить»**
5. OmniRoute появится на главном экране со значком приложения

### Компьютер (Chrome / Edge)

1. Откройте панель управления OmniRoute
2. Нажмите **значок установки** в адресной строке (или ⋮ → «Установить OmniRoute...»)
3. Подтвердите действие
4. OmniRoute откроется в отдельном окне — без вкладок и адресной строки

## Возможности

### Полноэкранный режим

Манифест настроен с параметром `display: "fullscreen"`, поэтому установленное приложение использует весь экран — без элементов интерфейса браузера и наложения на строку состояния. Благодаря этому панель управления воспринимается как настоящее нативное приложение.

### Поддержка автономной работы

OmniRoute содержит сервис-воркер (`sw.js`), обеспечивающий интеллектуальное кэширование:

| Тип ресурса                                                          | Стратегия                          | Поведение                                                                                                           |
| -------------------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Оболочка приложения**                                              | Сначала кэш                        | `/`, `/offline`, манифест и значки предварительно кэшируются при установке                                          |
| **Статические ресурсы** (CSS, JS, изображения, шрифты)               | Сначала сеть, затем кэш            | Загружает актуальные данные из сети; при отсутствии подключения использует кэш                                      |
| **Пакеты Next.js** (`/_next/`)                                       | Сначала сеть с обновлением кэша    | Загружает данные из сети и обновляет кэш; при отсутствии подключения использует кэшированную версию                 |
| **Навигационные запросы**                                            | Обход (никогда не перехватываются) | Браузер управляет переходом с HTTP/3 на HTTP/2; неработающий сокет QUIC не должен превращаться в `Response.error()` |
| **Маршруты API / панели управления** (`/api/`, `/a2a`, `/dashboard`) | Обход (никогда не кэшируются)      | Всегда направляются непосредственно на сервер и никогда не перехватываются сервис-воркером                          |

### Страница автономного режима

Когда сеть недоступна и пользователь переходит на новую страницу, сервис-воркер отображает специальную страницу `/offline`, которая:

- Показывает понятное сообщение **«Проблема с подключением»**
- Отображает динамический **индикатор состояния сети**, который обновляется в реальном времени
- Предоставляет кнопку **«Повторить подключение»** для перезагрузки страницы после восстановления связи
- Содержит ссылку на **страницу состояния** для диагностики

### Значки приложения

OmniRoute предоставляет значки, оптимизированные для каждой платформы:

| Файл                   | Размер             | Используется для                       |
| ---------------------- | ------------------ | -------------------------------------- |
| `icon-512.png`         | 512×512            | Запрос установки и заставка на Android |
| `apple-touch-icon.png` | 180×180            | Значок на главном экране iOS           |
| `icon-192.svg`         | 192×192 (вектор)   | Адаптивный значок Android              |
| `apple-touch-icon.svg` | 180×180 (вектор)   | Резервный значок Apple                 |
| `favicon.svg`          | Векторный          | Вкладки браузера                       |
| `favicon.ico`          | Несколько размеров | Устаревшие браузеры                    |

### Автоматическая регистрация

Сервис-воркер автоматически регистрируется с помощью компонента `<PwaRegister />` в корневом макете. Пользователю не требуется выполнять никаких действий — приложение становится доступным для установки, как только браузер обнаруживает действительный манифест и сервис-воркер.

## Техническая архитектура

### Манифест веб-приложения (`manifest.webmanifest`)

Генерируется Next.js через `src/app/manifest.ts`:

```json
{
  "name": "OmniRoute",
  "short_name": "OmniRoute",
  "description": "OmniRoute is an AI gateway for multi-provider LLMs. One endpoint for all your AI providers.",
  "start_url": "/",
  "scope": "/",
  "display": "fullscreen",
  "orientation": "any",
  "background_color": "#0b0f1a",
  "theme_color": "#0b0f1a",
  "icons": [
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    },
    { "src": "/apple-touch-icon.png", "sizes": "180x180", "type": "image/png" }
  ]
}
```

### Service Worker (`public/sw.js`)

Нативный service worker (без зависимостей от фреймворков) со следующими возможностями:

- **Фаза установки**: Предварительно кэширует оболочку приложения (корневую страницу, офлайн-страницу, манифест и значки)
- **Фаза активации**: Удаляет старые версии кэша и получает контроль над всеми клиентами
- **Фаза обработки запросов**: Интеллектуальная маршрутизация в зависимости от типа запроса (навигация, статический ресурс, API)
- **Версионирование кэша**: `omniroute-pwa-v3` — увеличьте версию, чтобы принудительно обновить кэш при обновлении приложения

### Метаданные макета (`src/app/layout.tsx`)

Корневой макет предоставляет все метатеги, необходимые для соответствия требованиям PWA:

- Ссылка `manifest` на `/manifest.webmanifest`
- `apple-web-app-capable: true` для автономного режима на iOS
- `apple-web-app-status-bar-style: black-translucent`
- `mobile-web-app-capable: yes` для Chrome на Android
- `theme-color: #0b0f1a`
- `viewport-fit: cover` для отображения от края до края

### Компонент: `PwaRegister`

Этот клиентский компонент, расположенный в `src/shared/components/PwaRegister.tsx`:

1. Запускается при монтировании (только на стороне клиента)
2. Проверяет поддержку `serviceWorker` в браузере
3. Незаметно регистрирует `/sw.js` (ошибки подавляются, чтобы не блокировать приложение)
4. Ничего не отображает (`return null`) — этот компонент предназначен исключительно для выполнения побочного эффекта

## Использование с Termux (Android)

При запуске OmniRoute на Android через Termux PWA работает без дополнительной настройки:

1. Запустите OmniRoute в Termux: `npx omniroute`
2. Откройте Chrome на том же телефоне: `http://localhost:20128`
3. Установите PWA через «Добавить на главный экран»
4. PWA подключится к локальному серверу Termux — всё работает непосредственно на устройстве

При таком подходе ваш телефон Android одновременно является **сервером** (Termux) и **клиентом** (PWA), образуя полностью автономный ИИ-шлюз.

## Использование с других устройств

Установите PWA на любое устройство, браузер которого имеет доступ к вашему серверу OmniRoute:

- **Другой телефон или планшет**: Перейдите по адресу `http://PHONE_IP:20128` и установите PWA
- **Ноутбук**: Откройте Chrome/Edge и установите приложение как PWA для настольных компьютеров
- **Смарт-телевизор с браузером**: Откройте панель управления в полноэкранном режиме

## Настройка

### Имя экземпляра

Заголовок PWA учитывает параметр **Имя экземпляра** в разделе `Панель управления → Настройки`. Если переименовать экземпляр в «Мой ИИ-шлюз», установленное PWA будет отображать это имя.

### Пользовательский фавикон

Если загрузить пользовательский фавикон через `Панель управления → Настройки`, значок PWA на настольном компьютере будет заменён на пользовательский. Для значков на главном экране мобильных устройств используются готовые файлы `icon-512.png` и `apple-touch-icon.png`.

## Ограничения

- **Нет push-уведомлений** — Service worker не реализует Push API. Вместо этого уведомления обрабатываются приложением Electron.
- **Нет фоновой синхронизации** — Действия, выполненные офлайн, не ставятся в очередь для последующего выполнения. PWA предназначено главным образом для просмотра панели мониторинга.
- **Ограничения iOS** — Safari на iOS поддерживает не все функции PWA (например, запрос на установку необходимо вызывать вручную, а работа service worker в фоновом режиме ограничена).
- **Размер кеша** — Service worker кеширует только статические ресурсы. Большие полезные нагрузки ответов от маршрутов `/api/` никогда не кешируются.
- **Пользовательские значки на мобильных устройствах** — Изменение favicon в настройках не обновляет значок на главном экране мобильного устройства (для этого необходимо заново сгенерировать значки PWA).
