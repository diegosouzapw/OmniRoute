## Mi ez?

A Local Corpus lehetővé teszi, hogy egy üzemeltető egyetlen, kifejezetten jóváhagyott, szövegfájlokat tartalmazó könyvtárat tegyen elérhetővé az OmniRoute MCP-kiszolgálója számára. A fájlok az eredeti könyvtárukban maradnak: az OmniRoute csak a kanonikus gyökérútvonalat tárolja az SQLite-adatbázisban, és egy memóriában tartott keresési indexet kezel. A korpusz tartalmát nem másolja a tárolóba vagy az adatbázisba.

Az index frissítése inkrementális. A változatlan fájlokat a méretük és módosítási idejük alapján újra felhasználja, a módosított fájlokat újra beolvassa, és SHA-256 használatával kivonatolja, a törölt fájlokat pedig eltávolítja. A keresés frissíti a 30 másodpercnél régebbi indexet; a hívók azonnali frissítést is kérhetnek.

## A forrás konfigurálása

A beállítási útvonal ugyanazt a felügyeleti hitelesítést igényli, mint a többi beállítási API. A beküldött útvonalnak már léteznie kell, és abszolút könyvtárútvonalnak kell lennie.

```bash
# Jóváhagyott könyvtár csatlakoztatása
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# A konfiguráció és az index állapotának ellenőrzése
curl http://localhost:20128/api/settings/local-corpus

# Leválasztás a forrásfájlok módosítása nélkül
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP-eszközök

Mindhárom eszközhöz szükséges a `read:local-corpus` jogosultság. Az eszközök válaszai relatív útvonalakat és a gyökérkönyvtár alapnevét teszik közzé, az abszolút útvonalát soha.

| Eszköz                | Leírás                                                                                                                |
| :-------------------- | :-------------------------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Jelenti a konfiguráció állapotát, az index méretét, a korlátokat és az utolsó frissítés időpontját                    |
| `local_corpus_search` | Keres az indexelt szövegben, és korlátozott méretű, sorokra vonatkozó részleteket ad vissza (legfeljebb 20 találatot) |
| `local_corpus_read`   | Korlátozott sortartományt olvas be egy engedélyezett, korpuszhoz viszonyított fájlból                                 |

Példák MCP-bemenetekre:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Biztonsági korlátok

- Az engedélyezési lista szövegközpontú: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` és `.yml`.
- A szimbolikus hivatkozásokat kihagyja. Az olvasási útvonalakat kanonizálja, és azoknak a
  konfigurált gyökérkönyvtáron belül kell maradniuk; az abszolút útvonalakat és a könyvtárbejárási kísérleteket elutasítja.
- Az érzékeny és generált könyvtárneveket kizárja: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` és
  `secrets`.
- Az alapértelmezett korlátok: 5 000 fájl, fájlonként 1 MiB, összesen 64 MiB indexelt tartalom,
  keresési blokkonként körülbelül 4 000 karakter és olvasásonként 400 sor.
- A NUL-karaktert tartalmazó fájlokat nem szövegesként kezeli, ezért kihagyja vagy elutasítja őket.

A bináris dokumentumok, például a PDF- és DOCX-fájlok, képek és archívumok szándékosan nem támogatottak.
Az indexelés előtt alakítsa át őket egy engedélyezett szövegformátumba a konfigurált könyvtárban.

## Üzemeltetési megjegyzések

- A konfigurált gyökérkönyvtár módosítása vagy törlése kiüríti a megosztott, memóriában tartott indexet.
- A folyamat újraindítása eldobja az indexet; a következő keresés újra felépíti azt a konfigurált
  forrásból.
- A `local_corpus_status` nem kényszerít ki vizsgálatot. Ha azonnali újravizsgálat szükséges, használja a `local_corpus_search` eszközt
  `refresh: true` értékkel.
- A vizsgálati és olvasási hibákat megszámolja, vagy megtisztított hibákként adja vissza; a forrásfájlokat
  soha nem módosítja.
