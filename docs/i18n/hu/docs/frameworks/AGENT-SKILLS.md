> **Hiteles forrás:** `src/lib/agentSkills/` (katalógus, generátor, elemzők) + `skills/` könyvtár (SKILL.md fájlok)
> **Utolsó frissítés:** 2026-08-02 — v3.8.50

Az Agent Skills strukturált SKILL.md fájlok, amelyek megtanítják a külső ügynököknek, MCP-klienseknek és A2A-orkesztrátoroknak, hogyan használják az OmniRoute REST API-ját és CLI-jét. Az [Omni Skills](./SKILLS.md) funkciótól eltérően (amely az OmniRoute-on belül végrehajtott LLM-eszközdefiníciókat tartalmazza) az Agent Skills egy _dokumentációs katalógus_ — statikus markdown-tartalom, amely közvetlenül beilleszthető az ügynök kontextusába.

---

## Áttekintés

A katalógus **45 Agent Skillt** tartalmaz (23 REST API + 21 CLI + 1 konfigurációs munkafolyamat). Minden skill a következőkkel rendelkezik:

- Egy **kanonikus azonosító** (`omni-auth`, `cli-serve` stb.)
- Egy **SKILL.md** fájl a `skills/{id}/SKILL.md` helyen, YAML frontmatterrel (`name`, `description`) és részletes markdown-törzzsel
- Az OpenAPI-specifikációból és a CLI-nyilvántartásból származtatott **REST-végpontok** (API-skillek) vagy **CLI-alparancsok** (CLI-skillek)
- Egy **nyers GitHub-URL** az élő lekéréshez: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Architektúra

```
src/shared/constants/agentSkills.ts    — 45 elemből álló, gondosan összeállított lista (név/leírás/kategória/terület/ikon)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — a generateAgentSkills() SKILL.md fájlokat ír a skills/{id}/ könyvtárba
  openapiParser.ts                     — REST-végpontokat nyer ki a docs/openapi.yaml fájlból
  cliRegistryParser.ts                 — CLI-alparancsokat nyer ki a bin/cli-registry.ts fájlból
  schemas.ts                           — Zod-sémák: AgentSkillSchema, SkillCoverageSchema stb.
  types.ts                             — TypeScript-interfészek: AgentSkill, SkillCoverage stb.

skills/{id}/SKILL.md                   — Generált és gondozott markdown-fájlok (összesen 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (hitelesítés szükséges)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 MCP-eszköz (listázás, lekérés, lefedettség)
src/lib/a2a/skills/listCapabilities.ts        — A2A-skill: list-capabilities
```

## A SKILL.md formátuma

```markdown
---
name: omni-providers
description: "Szolgáltatói kapcsolatok kezelése: hitelesítő adatok hozzáadása, tesztelése, rotálása és eltávolítása."
---

<!-- a src/lib/agentSkills/generator.ts generálta; a kézi módosítások felül lesznek írva -->

## Áttekintés

...

## Hitelesítés

...

## Végpontok

...

<!-- skill:custom-start -->

## Egyéni szakasz (újrageneráláskor megmarad)

...

<!-- skill:custom-end -->
```

A generátor újrageneráláskor megőrzi a `<!-- skill:custom-start -->` és `<!-- skill:custom-end -->` közötti tartalmat. Tíz skill rendelkezik gondozott egyéni blokkokkal:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## REST API-felderítés

| Végpont                      | Metódus | Leírás                                                                     | Hitelesítés |
| :--------------------------- | :------ | :------------------------------------------------------------------------- | :---------- |
| `/api/agent-skills`          | GET     | Katalógus listázása (opcionális: `?category=api\|cli\|config&area=<area>`) | nincs       |
| `/api/agent-skills/{id}`     | GET     | Egy készség metaadatainak lekérése                                         | nincs       |
| `/api/agent-skills/{id}/raw` | GET     | A SKILL.md lekérése `text/markdown` formátumban                            | nincs       |
| `/api/agent-skills/coverage` | GET     | Lefedettségi statisztikák (hány SKILL.md fájl létezik)                     | nincs       |
| `/api/agent-skills/generate` | POST    | A generátor elindítása (dryRun/prune/onlyIds)                              | felügyeleti |

Példa — az összes API-készség listázása:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Példa — egyetlen SKILL.md lekérése:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## A2A-felderítés

A `list-capabilities` A2A-készség a teljes, 45 készséget tartalmazó katalógust Markdown-táblázatos műtermékként adja vissza. Külső vezénylők a következő módon hívhatják meg:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "Az összes képesség listázása" }]
  }
}
```

A protokoll részleteit lásd az [A2A-SERVER.md](./A2A-SERVER.md) dokumentumban.

## Hogyan használják a külső ügynökök a készségeket

### 1. Felderítés REST-en keresztül

```bash
# A teljes katalógus lekérése
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# A SKILL.md lekérése kontextusinjektáláshoz
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Felderítés MCP-n keresztül

```typescript
// Egy Claude Desktop / Cursor MCP-kliensben:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → AgentSkill-elemek tömbje, mindegyikhez tartozó rawUrl mezővel
```

### 3. Felderítés A2A-n keresztül

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# A table egy markdown-tábla mind a 45 készségazonosítóval és a rawUrl oszlopokkal
```

### 4. Közvetlen nyers GitHub-lekérés (nincs szükség szerverre)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generátor

A generátor beolvassa a gondozott katalógust, az OpenAPI-specifikációt és a CLI-nyilvántartást, majd minden bejegyzéshez létrehozza a `skills/{id}/SKILL.md` fájlt:

```bash
# Előnézet (próbafuttatás, írás nélkül)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Teljes újragenerálás
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Meghatározott azonosítók újragenerálása
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

A generátor válasza egy `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
