Az OmniRoute ingyenes proxyk gondosan összeválogatott készletét biztosítja a `free_proxies` táblában,
külső szolgáltatóktól (1proxy, proxifly, iplocate, webshare) szinkronizálva. Az
irányítópult ezeket a **Beállítások → Ingyenes proxyk** alatt jeleníti meg. Ez a dokumentum
a listázási útvonal által biztosított szerveroldali szűrést, rendezést, számlálást és
szinkronizálási hibajelentést ismerteti.

## Listázási útvonal — `GET /api/settings/free-proxies`

Egy szűrt, rendezett és lapozott részhalmazt, valamint egy teljes elemszámot ad vissza. A szűrés és
a számlálás SQL-ben történik, így a felhasználói felület a valós teljes elemszámot (például `Összesen: 0`)
anélkül jelenítheti meg, hogy minden sort betöltene a memóriába.

### Lekérdezési paraméterek

| Paraméter         | Típus                              | Alapértelmezett | Jelentés                                                                                                                            |
| ----------------- | ---------------------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | karakterlánc                       | `""`            | Kis- és nagybetűérzékeny `LIKE` a gazdagép (és a forrás) oszlopán.                                                                  |
| `protocol`        | karakterlánc                       | `""`            | `type` szűrő: `http` / `https` / `socks4` / `socks5`. Üres = mind.                                                                  |
| `country`         | karakterlánc                       | `""`            | `countryCode` szűrő (ISO-2). Üres = mind.                                                                                           |
| `minQuality`      | szám                               | `0`             | Csak azok a sorok, amelyeknél `qualityScore >= minQuality`. `0` = nincs alsó korlát.                                                |
| `disabledSources` | karakterlánc                       | `""`            | Kizárandó forrásazonosítók vesszővel elválasztva (például `proxifly,webshare`).                                                     |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`       | `quality` = pontszám csökkenően; `latency` = késleltetés növekvően (a null értékek a végén); `recent` = `lastValidated` csökkenően. |
| `offset`          | szám                               | `0`             | A lapozás kezdőpontja.                                                                                                              |
| `limit`           | szám                               | `50`            | Oldalméret (szerveroldalon korlátozva).                                                                                             |

### Válasz

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 a külső szolgáltatótól"],
    "webshare": ["hálózati időtúllépés"]
  }
}
```

A `total` a lapozás **előtti** szűrt teljes elemszámot tükrözi, így a felhasználói felület
egymástól függetlenül jelenítheti meg az `Összesen: N` értéket és a `hasMore` állapotot. A `syncErrors`
kulcsai forrásazonosítók, és csak azoknál a forrásoknál van kitöltve, amelyek legutóbbi szinkronizálása
sikertelen volt — egy `Összesen: 0` eredmény mögötti hiba soha nem marad jelzés nélkül.

## Hozzáadás a készlethez — `POST /api/settings/free-proxies/[id]/add-to-pool`

Egy ingyenes proxyt átemel a kezelt `proxy_registry` készletbe. Először ellenőrzi a
külső proxyt; siker esetén visszaadja az új készletproxy azonosítóját és a mért késleltetést.

## Szinkronizálás — `POST /api/settings/free-proxies/sync`

Újra lekéri az összes engedélyezett forrást (vagy a `{ "sources": [...] }` részhalmazban megadottakat). Minden
forrás egymástól függetlenül szinkronizálódik; a sikertelen forrás bekerül a `syncErrors` mezőbe, a
többi pedig továbbra is befejeződik, így a részleges szinkronizálások soha nem törlik a korábbi érvényes adatokat.

## Statisztikák — `GET /api/settings/free-proxies/stats`

Visszaadja a `total / inPool / avgQuality / bySource / lastSyncAt` összesített adatokat
a soradatok nélkül — ezt használják az irányítópult fejlécében lévő widgetek.
