## Kategóriák

- **Ingyenes** — ingyenes csomag API-kulccsal (az irányítópulton konfigurálható)
- **Hitelesítés nélküli** — nyilvános végpontok, amelyekhez egyáltalán nincs szükség kulcsra vagy bejelentkezésre
- **OAuth** — az OmniRoute által kezelt bejelentkezési folyamat, nincs szükség API-kulcsra
- **Webes süti** — a szolgáltató webalkalmazását csomagolja be sütialapú hitelesítéssel
- **API-kulcs** — API-kulccsal konfigurált fizetős szolgáltató (ingyenes kreditek elérhetők lehetnek)
- **Helyi** — a felhasználó gépén fut (Ollama, LM Studio, vLLM stb.)
- **Keresés** — webes keresési szolgáltatók
- **Hang** — kizárólag hangalapú szolgáltatók (TTS/STT)
- **Továbbító proxy** — más szolgáltatókhoz továbbító proxyszolgáltatók
- **Felhőügynök** — hosszú ideig futó kódoló ügynökök (Codex Cloud, Devin, Jules)
- **Rendszer** — az OmniRoute belső szolgáltatói (loopback stb.)

További címkék: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Eszközhívás` (ahol szerepel): `native` — valódi függvényhívási API; `emulated` — a `tools` tömb promptalapú emulációját a `webTools.ts` végzi (reguláris kifejezéssel feldolgozott `<tool>{...}</tool>` blokkok); `none` — a `tools` jelenleg figyelmeztetés nélkül eldobásra kerül. Lásd: #7286.

Az egyes szolgáltatók engedélyezéséhez, konfigurálásához és teszteléséhez használd a `/dashboard/providers` irányítópultot.
