## 1. lépés: Az OmniRoute telepítése

Válaszd ki az általad előnyben részesített módszert:

### A lehetőség: npm (ajánlott)

```bash
npm install -g omniroute
```

### B lehetőség: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

A `:latest` a legmagasabb **közzétett**, stabil SemVer-verzió. Nem követi a git `main` ágát. GitOps használata esetén rögzítsd a `diegosouzapw/omniroute:X.Y.Z` verziót. Lásd: [Képcímkék / Kiadási csatornák](../guides/DOCKER_GUIDE.md#release-channels).

### C lehetőség: Forráskódból

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## 2. lépés: Az OmniRoute elindítása

```bash
omniroute
```

Az OmniRoute a `http://localhost:20128` címen indul el. Az irányítópult automatikusan megnyílik.

---

## 3. lépés: Ingyenes szolgáltató csatlakoztatása

Az OmniRoute-ot **fizetés nélkül** is használhatod egy ingyenes szolgáltató csatlakoztatásával.

### A lehetőség: Kiro (ingyenes Claude — bankkártya nélkül)

1. Nyisd meg az irányítópultot a `http://localhost:20128` címen
2. Lépj a **Providers** → **Add Provider** menüpontra
3. Válaszd a **Kiro AI** lehetőséget
4. Kattints a **Connect** gombra (nincs szükség API-kulcsra!)
5. Kész! Mostantól ingyenesen hozzáférhetsz a Claude-modellekhez.

### B lehetőség: OpenCode Free (hitelesítés nélkül)

1. Nyisd meg az irányítópultot a `http://localhost:20128` címen
2. Lépj a **Providers** → **Add Provider** menüpontra
3. Válaszd az **OpenCode Free** lehetőséget
4. Kattints a **Connect** gombra (nincs szükség API-kulcsra!)
5. Kész! Mostantól ingyenesen hozzáférhetsz több modellhez.

### C lehetőség: Pollinations (nincs szükség kulcsra)

1. Nyisd meg az irányítópultot a `http://localhost:20128` címen
2. Lépj a **Providers** → **Add Provider** menüpontra
3. Válaszd a **Pollinations** lehetőséget
4. Kattints a **Connect** gombra (nincs szükség API-kulcsra!)
5. Kész! Mostantól ingyenesen hozzáférhetsz a GPT-5, Claude, Gemini és további modellekhez.

---

## 4. lépés: A működés ellenőrzése

Az [API Keys](http://localhost:20128/dashboard/api-manager) oldalon hozz létre egy új kulcsot. Mentsd el ezt a kulcsot, mert később nem jelenik meg újra. Fontos, hogy ez a kulcs az eszközök OmniRoute-hozzáférésére szolgál, nem pedig a háttérben használt szolgáltatók elérésére.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

A csatlakoztatott modellek listájának kell megjelennie.

## 5. lépés: Az IDE vagy a CLI beállítása az OmniRoute használatára

Az IDE-ben vagy a CLI-eszközben állítsd be a következőket:

```
Alap URL:  http://localhost:20128/v1
API-kulcs: [másold ki az irányítópult → Endpoints oldaláról]
Modell:    auto
```

Ennyi! Az IDE mostantól az OmniRoute-ot használja automatikus szolgáltatóválasztással.

### IDE-példa: VSCode/Continue.dev

1. Telepítsd a VSCode-ban a [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) bővítményt.
2. Add hozzá a következő sorokat a `~/.continue/config.yaml` fájlhoz:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. A Continue.dev csevegőpaneljén válaszd az `OmniRoute - Auto` lehetőséget, és a kéréseket az OmniRoute-nak fogod elküldeni.
4. (Nem kötelező) Gyakorlat az olvasónak: frissíttesd az IDE-vel a `config.yaml` fájlt az összes többi előre elkészített konfigurációval 😊

### CLI-példa: Codex CLI

1. Állítsd be tartósan a környezeti változót az operációs rendszeredben.
   macOS/Linux esetén (add hozzá a `~/.bashrc` vagy `~/.zshrc` fájlhoz):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows esetén (Parancssor):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Most indítsuk el a Codexet az OmniRoute használatára konfigurálva. Futtasd:

```
omniroute launch-codex --model auto
```

Ezt manuálisan is megteheted a `codex` és a végpontot, illetve az API-kulcsot megadó parancssori paraméterek használatával, de a fenti paranccsal az OmniRoute mindent elintéz helyetted.

Ugyanez az egyparancsos indítás más CLI-k esetén is működik az általános indítón keresztül — az `omniroute run <target>` támogatja a `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` és `gemini` célokat (lásd: [CLI-integrációk](../guides/CLI-INTEGRATIONS.md)).

3. A CLI-nek most már az OmniRoute részére kell küldenie a kéréseket.

### Ellenőrizd, hogy az eszközöd az OmniRoute-on keresztül irányítja-e a kéréseket

A kérés részleteit a bal oldali oldalsáv [Monitoring/Logs](http://localhost:20128/dashboard/logs) elemére kattintva tekintheted meg. Továbblépve további részleteket láthatsz. Emellett azt is megtekintheted, hogy a kedvenc klienskörnyezeted milyen adatokat küld tovább. Ez oktatási és hibakeresési szempontból is hasznos.

## Gyakori kérdések

### „Szükségem van API-kulcsra?”

**Nem!** Az ingyenes szolgáltatókat (Kiro, OpenCode Free, Pollinations) API-kulcs nélkül is használhatod. Egyszerűen csatlakoztasd őket az irányítópulton.

### „Mi az az `auto`?”

Az `auto` arra utasítja az OmniRoute-ot, hogy minden kéréshez automatikusan válassza ki a legjobb szolgáltatót. Figyelembe veszi a sebességet, a költséget, a minőséget és a rendelkezésre állást. A részletekért lásd az [Auto-Combo útmutatót](./AUTO-COMBO-GUIDE.md).

### „Mennyibe kerül?”

Maga az OmniRoute **ingyenes és nyílt forráskódú**. Csak az általad használt szolgáltatókért kell fizetned. Számos szolgáltató kínál ingyenes csomagot — lásd az [Ingyenes csomagok útmutatóját](./FREE-TIERS-GUIDE.md).

### „Használhatom a Claude Code / Cursor / Copilot eszközökkel?”

**Igen!** Az OmniRoute minden olyan eszközzel működik, amely támogatja az OpenAI-formátumot. Egyszerűen állítsd be alap URL-ként a `http://localhost:20128/v1` címet. A konkrét beállítási utasításokért lásd a [CLI-eszközök útmutatóját](../reference/CLI-TOOLS.md).

### „Mi történik, ha egy szolgáltató leáll?”

Az OmniRoute automatikusan kihagyja a hibás szolgáltatókat, és megpróbálja a következőt. Neked semmit sem kell tenned. A részletekért lásd az [Auto-Combo útmutatót](./AUTO-COMBO-GUIDE.md).
