Az OmniRoute a 352 támogatott szolgáltatót 3 gazdasági szintbe szervezi. Minden
kérés sorrendben halad végig rajtuk, amíg valamelyik sikeres választ nem ad —
így mindig a legolcsóbb működőképes választ kapja, anélkül, hogy tartalékkezelő
kódot kellene írnia.

## 1. szint — Előfizetés

**Szolgáltatók, amelyekért már fizet.** Az OmniRoute a kvóta minden részét
felhasználja annak lejárata előtt.

| Szolgáltató                       | Miért 1. szint                                            |
| --------------------------------- | --------------------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — átalánydíjas, gyakran kihasználatlan |
| OpenAI Codex (ChatGPT-előfizetés) | A Plus/Team Codex-kvótát tartalmaz                        |
| GitHub Copilot                    | Felhasználónkénti díjazás — a kvóta havonta megújul       |
| Cursor IDE                        | Pro csomag kvótája                                        |
| Antigravity / Devin Desktop       | Beépített kvóták                                          |

**Stratégia**: minden olyan kérést először ide irányítson, amely megfelel a modell
erősségeinek. A kvótakövető figyeli a közelgő megújulásokat, és a `reset-aware`
kombinációs stratégia ezek alapján állítja fel a prioritásokat. Ha először az

1. szintre szeretné irányítani a kéréseket, és csak a kvóta elfogyása után
   térne át a fizetős szintekre, használja az `auto/thrifty` azonosítót — vagy az
   `auto/subscription` azonosítót, ha kizárólag a csomagban foglalt kapacitást
   szeretné használni, és annak kimerülésekor hibával leállni. Lásd:
   [Előfizetés-első útválasztás](../routing/SUBSCRIPTION_LADDER.md).

## 2. szint — Olcsó

**Használatalapú, tokenenként fizetendő szolgáltatók 1 USD/1 millió token alatti áron.**
Nagy volumenű feladatokhoz, illetve az 1. szint kvótáinak kimerülése után használhatók.

| Szolgáltató                    | Ár (bemenet/kimenet) | Erősségek                       |
| ------------------------------ | -------------------- | ------------------------------- |
| DeepSeek V4 Pro                | $0.27 / $1.10 / 1M   | Kód, következtetés              |
| GLM-4.5                        | $0.60 / $2.20 / 1M   | Hosszú kontextus                |
| MiniMax M1                     | $0.20 / $1.10 / 1M   | Sebesség                        |
| Qwen Coder                     | $0.30 / $1.20 / 1M   | Kód                             |
| OpenRouter (árra optimalizált) | változó              | Több mint 100 modell, dinamikus |

**Stratégia**: a `cost-optimized` kombináció azt a legalacsonyabb
USD/token költségű modellt választja, amely megfelel a feladat képességszűrőjének
(képfeldolgozás, JSON-mód, eszközök, maximális kontextus).

## 3. szint — Ingyenes

**Nulla költségű szolgáltatók** — ingyenes csomagok, kreditprogramok,
napi OAuth-kvóták.

| Szolgáltató      | Ingyenes kvóta / kreditek                          |
| ---------------- | -------------------------------------------------- |
| Kiro AI          | Ingyenes Claude-szint (bőkezű méltányos használat) |
| OpenCode Free    | Nincs hitelesítés, bőkezű sebességkorlátok         |
| Qoder            | Ingyenes OAuth                                     |
| Google Vertex AI | $300 kredit új fiókokhoz                           |
| Amazon Q         | Ingyenes szint AWS-felhasználóknak                 |
| Pollinations     | Nyilvános, szabadon használható API                |
| Cloudflare AI    | Workers AI ingyenes szint                          |

**Stratégia**: a költségkerettel rendelkező `auto` kombináció ide irányítja
a kéréseket, amikor az 1. és 2. szint sikertelen, vagy ha a `useFreeOnly=true`
beállítás aktív. Az ingyenes szolgáltatók sebességkorlátai gyakran szigorúbbak —
a megszakító a várakozási idő letelte után ismét elérhetővé teszi őket.

## Szintek konfigurálása

Irányítópult → **Szintek** → rendelje hozzá a szolgáltatókat. Az alapértelmezések
(a `tierDefaults.json` fájlból) észszerűek; akkor módosítsa őket, ha bizonyos
előfizetéseket szeretne előnyben részesíteni, vagy egyes szolgáltatókat ki szeretne zárni.

Az Auto-Combo 16 tényezős pontozása a szintet is figyelembe veszi. Lásd:
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetria

Az Irányítópult → **Használat** megjeleníti az egyes szinteken naponta elköltött
tokeneket. Ezt a következőkre használhatja:

- Ellenőrizze, hogy az 1. szint teljesen ki van-e használva (ellenkező esetben elpazarolja az előfizetés értékét)
- Azonosítsa, mely 2. szintű modelleket választja ki leggyakrabban a rendszer (vonja össze őket 1–2 modellre)
- Ellenőrizze, hogy a 3. szint pénzt takarít-e meg a tesztelési/felderítési munkaterheléseken

## Gyakori minták

### Kizárólag ingyenes munkaterhelés

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Erősen a 3. szint felé tereli a kéréseket; csak akkor használja a 2. szintet,
ha a 3. szint nem érhető el.

### Előfizetés-első, olcsó tartalékmegoldással

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Az 1. szint → 2. szint → 3. szint sorrendnek megfelelő, explicit rendezett lista.
