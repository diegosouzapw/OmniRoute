A Caveman tömörítés a beépített angol szabályok mellett nyelvspecifikus szabálycsomagokat is képes betölteni.
Így az alapmotor stabil marad, miközben a portugál, spanyol, német, francia, olasz, japán és
jövőbeli nyelvi csomagok egymástól függetlenül fejlődhetnek.

## Hely

A nyelvi csomagok itt találhatók:

```txt
open-sse/services/compression/rules/<language>/
```

A jelenleg szállított csomagok (a `rules/` könyvtár tartalma alapján ellenőrizve):

| Nyelv               | Könyvtár       | Elérhető szabálykategóriák                          |
| ------------------- | -------------- | --------------------------------------------------- |
| Angol               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spanyol             | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugál (Brazília) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonéz             | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Olasz               | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Német               | `rules/de/`    | `context`, `filler`, `structural`                   |
| Francia             | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japán               | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Funkcionális egyezésre vonatkozó megjegyzés:** Az `en`, `es`, `pt-BR`, `id` és `it` csomag mind az 5 kategóriát tartalmazza; a `de`, `fr` és `ja` csomag 3 kategóriával érkezik. A hiányzó `dedup` és `ultra` kategóriák helyett a rendszer észrevétlenül a beépített angol szabályokat használja. Szívesen fogadunk hozzájárulásokat a `dedup.json` és `ultra.json` fájlok kisebb csomagokhoz történő hozzáadásához.
>
> A `pt-BR` csomag Lenine Júnior **[Troglodita](https://github.com/leninejunior/troglodita)** projektjén alapul — ez egy, a brazil portugál nyelvtanához az alapoktól megtervezett tömörítési rendszer (pleonazmusok csökkentése, portugál-brazil töltelékszavak eltávolítása, technikai rövidítések a brazil fejlesztői közösség számára).
>
> A kategóriák kanonikus listája és a kategóriánkénti séma az [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) fájlban található (JSON Schema, 2020-12-es tervezet).

## Nyelvfelismerés

A `languageDetector.ts` egyszerű heurisztikákkal következtet a nyelvre a prompt szövegéből. A rendszer
továbbra is figyelembe veszi a beállított alapértelmezett nyelvet, és a felismerés a konfigurációban
kikapcsolható, ha pontos vezérlésre van szükség.

A felismerés eredménye kizárólag a szabálycsomagok kiválasztására szolgál. Nem módosítja a szolgáltatói
útválasztást, a területi beállítás kiválasztását vagy a felhasználói felület nyelvét.

## A konfiguráció szerkezete

A tömörítési beállítások a következőket tartalmazhatják:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

A `languageConfig` az irányítópult és az előnézet alapértelmezett beállításait szabályozza. A `cavemanConfig`
a futásidejű motor konfigurációja, amelyet a Caveman az üzenetek szövegének tömörítésekor használ.

## Nyelvi csomag hozzáadása

1. Hozza létre az `open-sse/services/compression/rules/<language>/<pack>.json` fájlt.
2. Használja a `docs/compression/COMPRESSION_RULES_FORMAT.md` dokumentumban leírt Caveman-szabályformátumot.
3. A helyettesítéseket alkalmazza visszafogottan, és kerülje a kód, az azonosítók, az URL-ek vagy a JSON módosítását.
4. Adjon hozzá vagy frissítsen teszteket a nyelvkiválasztás és a helyettesítési viselkedés ellenőrzéséhez.
5. Tegye elérhetővé az új irányítópult-/i18n-címkéket, ha a nyelv megjelenik a felhasználói felület választóelemeiben.

## API

Az elérhető csomagok a következőképpen kérdezhetők le:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Az előnézeti végpont elfogadja a nyelvi konfiguráció felülírásait:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Mind a 6 nyelvi csomag megkapta a `SHARED_BOUNDARIES` záradékot a v3.8.0 verzióban, amely minden
Caveman-intenzitási szinten (LITE, FULL, ULTRA) alkalmazásra kerül. Arra utasítja a motort, hogy ezeket a mintákat
változatlanul őrizze meg, a környező töltelékszöveg eltávolításától függetlenül:

| Mintatípus                            | Példa                                  |
| ------------------------------------- | -------------------------------------- |
| Körülhatárolt kódblokkok              | ` ```python\n...\n``` `                |
| Sorközi kód                           | `` `my_var` ``                         |
| URL-ek                                | `https://example.com/path`             |
| Fájlelérési utak (abszolút + relatív) | `/etc/hosts`, `./src/index.ts`         |
| Hibafejlécek                          | `Error:`, `TypeError:`, `SyntaxError:` |
| Veremkiírás sorai                     | `  at functionName (file.ts:12:3)`     |

Ezek a minták a `DEFAULT_CAVEMAN_CONFIG.preservePatterns` mezőben találhatók (korábban `[]`). A
konstans az `open-sse/services/compression/types.ts` fájlban található.

### Miért fontos ez?

A SHARED_BOUNDARIES nélkül az agresszív Caveman-módok eltávolíthatták a tartalmat, amely ismétlődő
prózának tűnt, de valójában kódrészlet, fájlelérési út vagy hibaverem volt. A SHARED_BOUNDARIES egy
nyelvfüggetlen biztonsági hálóként működik, amelyet a rendszer a töltelékszövegre vonatkozó szabályok futtatása előtt alkalmaz.

### A preservePatterns testreszabása

További minták adhatók hozzá futásidőben a tömörítési beállításokon keresztül:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Az egyéni minták kibővítik (nem helyettesítik) a 6 alapértelmezett mintát.

## Üzemeltetési megjegyzések

- Ha egy nyelvi csomag hiányzik, továbbra is a beépített angol szabályok szolgálnak tartalékként.
- Az érvénytelen beépített JSON-csomagok nem mennek át az ellenőrzésen, így a kiadási összetevők minősége nem romlik észrevétlenül.
- A szabálycsomagok csak adatokat tartalmazhatnak, és nem importálhatnak kódot, illetve nem futtathatnak tetszőleges logikát.
- A tömörítési analitikai réteg a kiválasztott módot és motort rögzíti, nem pedig a teljes promptszöveget.
