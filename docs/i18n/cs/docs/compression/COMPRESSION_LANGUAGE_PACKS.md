Komprese Caveman může kromě vestavěných pravidel pro angličtinu načítat také jazykově specifické balíčky pravidel.
Díky tomu zůstává základní engine stabilní, zatímco balíčky pro portugalštinu, španělštinu, němčinu, francouzštinu, italštinu, japonštinu a
budoucí jazyky se mohou vyvíjet nezávisle.

## Umístění

Jazykové balíčky se nacházejí v:

```txt
open-sse/services/compression/rules/<language>/
```

Aktuálně dodávané balíčky (ověřeno podle obsahu adresáře `rules/`):

| Jazyk                    | Adresář        | Přítomné kategorie pravidel                         |
| ------------------------ | -------------- | --------------------------------------------------- |
| Angličtina               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Španělština              | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugalština (Brazílie) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonéština              | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italština                | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Němčina                  | `rules/de/`    | `context`, `filler`, `structural`                   |
| Francouzština            | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japonština               | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Poznámka k paritě:** Balíčky `en`, `es`, `pt-BR`, `id` a `it` obsahují všech 5 kategorií; `de`, `fr` a `ja` se dodávají se 3 kategoriemi. Chybějící kategorie `dedup` a `ultra` automaticky a bez upozornění používají vestavěná anglická pravidla. Příspěvky, které do menších balíčků přidají soubory `dedup.json` a `ultra.json`, jsou vítány.
>
> Balíček `pt-BR` je založen na systému **[Troglodita](https://github.com/leninejunior/troglodita)** od Lenina Júniora — kompresním systému navrženém od základů pro gramatiku brazilské portugalštiny (redukce pleonasmů, odstraňování výplňových výrazů v PT-BR, technické zkratky pro brazilskou vývojářskou komunitu).
>
> Kanonický seznam kategorií a schéma jednotlivých kategorií se nacházejí v souboru [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12).

## Detekce jazyka

`languageDetector.ts` používá jednoduché heuristiky k odvození jazyka z textu promptu. Nakonfigurovaný
výchozí jazyk je i nadále respektován a detekci lze v konfiguraci zakázat, pokud je vyžadována přesná
kontrola.

Výstup detekce slouží pouze k výběru balíčků pravidel. Nemění směrování k poskytovatelům, výběr locale
ani jazyk uživatelského rozhraní.

## Struktura konfigurace

Nastavení komprese může obsahovat:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` řídí výchozí nastavení dashboardu a náhledu. `cavemanConfig` je konfigurace enginu za běhu,
která se používá, když Caveman komprimuje text zprávy.

## Přidání jazykového balíčku

1. Vytvořte `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Použijte formát pravidel Caveman z dokumentu `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Náhrady nastavujte konzervativně a neměňte kód, identifikátory, adresy URL ani JSON.
4. Přidejte nebo aktualizujte testy pro výběr jazyka a chování náhrad.
5. Pokud se jazyk zobrazuje ve výběrech uživatelského rozhraní, zpřístupněte nové popisky pro řídicí panel/i18n.

## API

Dostupné balíčky lze zjistit pomocí:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Koncový bod pro náhled přijímá přepsání konfigurace jazyka:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Všech 6 jazykových balíčků obdrželo ve verzi v3.8.0 klauzuli `SHARED_BOUNDARIES`, která se používá při každé
intenzitě Caveman (LITE, FULL, ULTRA). Dává enginu pokyn zachovat následující vzory beze změny
bez ohledu na odstranění okolních výplňových výrazů:

| Typ vzoru                                | Příklad                                |
| ---------------------------------------- | -------------------------------------- |
| Ohraničené bloky kódu                    | ` ```python\n...\n``` `                |
| Kód v řádku                              | `` `my_var` ``                         |
| Adresy URL                               | `https://example.com/path`             |
| Cesty k souborům (absolutní + relativní) | `/etc/hosts`, `./src/index.ts`         |
| Záhlaví chyb                             | `Error:`, `TypeError:`, `SyntaxError:` |
| Řádky trasování zásobníku                | `  at functionName (file.ts:12:3)`     |

Tyto vzory jsou uvedeny v `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (dříve `[]`). Tato
konstanta se nachází v `open-sse/services/compression/types.ts`.

### Proč je to důležité

Bez SHARED_BOUNDARIES by agresivní režimy Caveman mohly odstranit obsah, který vypadal jako opakující se
próza, ale ve skutečnosti šlo o úryvek kódu, cestu k souboru nebo zásobník chyby. SHARED_BOUNDARIES funguje jako
bezpečnostní mechanismus nezávislý na jazyce, který se použije před spuštěním pravidel pro výplňové výrazy.

### Přizpůsobení preservePatterns

Další vzory lze přidat za běhu prostřednictvím nastavení komprese:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Vlastní vzory rozšiřují (nenahrazují) 6 výchozích vzorů.

## Provozní poznámky

- Pokud jazykový balíček chybí, jako záložní možnost se nadále používají vestavěná pravidla pro angličtinu.
- Neplatné vestavěné balíčky JSON neprojdou validací, aby nedocházelo k nepozorovanému zhoršení kvality artefaktů vydání.
- Balíčky pravidel obsahují pouze data a neměly by importovat kód ani spouštět libovolnou logiku.
- Analytická vrstva komprese zaznamenává vybraný režim a engine, nikoli celý text výzvy.
