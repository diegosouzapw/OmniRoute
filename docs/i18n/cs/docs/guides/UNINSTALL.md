---

## Rychlá odinstalace (v3.6.2+)

OmniRoute poskytuje dva vestavěné skripty pro čisté odebrání:

### Zachování dat

```bash
npm run uninstall
```

Tento příkaz odebere aplikaci OmniRoute, ale **zachová** vaši databázi, konfigurace, klíče API a nastavení poskytovatelů v adresáři `~/.omniroute/`. Použijte jej, pokud plánujete aplikaci později znovu nainstalovat a chcete zachovat své nastavení.

### Úplné odebrání

```bash
npm run uninstall:full
```

Tento příkaz odebere aplikaci **a trvale vymaže** všechna data:

- Databázi (`storage.sqlite`)
- Konfigurace poskytovatelů a klíče API
- Záložní soubory
- Soubory protokolů
- Všechny soubory v adresáři `~/.omniroute/`

> ⚠️ **Varování:** Příkaz `npm run uninstall:full` je nevratný. Všechna vaše připojení k poskytovatelům, kombinace, klíče API a historie využití budou trvale odstraněny.

## Ruční odinstalace

### Globální instalace pomocí NPM

```bash
# Odebrání globálního balíčku
npm uninstall -g omniroute

# (Volitelné) Odebrání datového adresáře
rm -rf ~/.omniroute
```

### Globální instalace pomocí pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Zastavení a odebrání kontejneru
docker stop omniroute
docker rm omniroute

# Odebrání svazku (odstraní všechna data)
docker volume rm omniroute-data

# (Volitelné) Odebrání obrazu
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Zastavení a odebrání kontejnerů
docker compose down

# Odebrání také svazků (odstraní všechna data)
docker compose down -v
```

### Desktopová aplikace Electron

**Windows:**

- Otevřete `Nastavení → Aplikace → OmniRoute → Odinstalovat`
- Nebo spusťte odinstalační program NSIS z instalačního adresáře

**macOS:**

- Přetáhněte `OmniRoute.app` z `/Applications` do koše
- Odeberte data: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Odeberte soubor AppImage
- Odeberte data: `rm -rf ~/.omniroute`

### Instalace ze zdrojového kódu (git clone)

```bash
# Odebrání naklonovaného adresáře
rm -rf /path/to/omniroute

# (Volitelné) Odebrání datového adresáře
rm -rf ~/.omniroute
```

## Datové adresáře

OmniRoute ve výchozím nastavení ukládá data do následujících umístění:

| Platforma          | Výchozí cesta                   | Přepsání                             |
| ------------------ | ------------------------------- | ------------------------------------ |
| Linux              | `~/.omniroute/`                 | proměnná prostředí `DATA_DIR`        |
| macOS              | `~/.omniroute/`                 | proměnná prostředí `DATA_DIR`        |
| Windows            | `%APPDATA%/omniroute/`          | proměnná prostředí `DATA_DIR`        |
| Docker             | `/app/data/` (připojený svazek) | proměnná prostředí `DATA_DIR`        |
| Kompatibilní s XDG | `$XDG_CONFIG_HOME/omniroute/`   | proměnná prostředí `XDG_CONFIG_HOME` |

### Soubory v datovém adresáři

| Soubor/adresář       | Popis                                                        |
| -------------------- | ------------------------------------------------------------ |
| `storage.sqlite`     | Hlavní databáze (poskytovatelé, kombinace, nastavení, klíče) |
| `storage.sqlite-wal` | Protokol SQLite pro dopředný zápis (dočasný)                 |
| `storage.sqlite-shm` | Sdílená paměť SQLite (dočasná)                               |
| `call_logs/`         | Archivy dat požadavků                                        |
| `backups/`           | Automatické zálohy databáze                                  |
| `log.txt`            | Starší protokol požadavků (volitelné)                        |

## Ověření úplného odstranění

Po odinstalaci ověřte, že nezůstaly žádné soubory:

```bash
# Kontrola globálního balíčku npm
npm list -g omniroute 2>/dev/null

# Kontrola datového adresáře
ls -la ~/.omniroute/ 2>/dev/null

# Kontrola spuštěných procesů
pgrep -f omniroute
```

Pokud je některý proces stále spuštěný, ukončete jej:

```bash
pkill -f omniroute
```
