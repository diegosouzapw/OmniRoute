`@omniroute/opencode-plugin-v2` zpřístupní celý váš katalog OmniRoute — modely, komba a
automatická komba — ve výběru modelů OpenCode v2, včetně zobrazovaných názvů, cen a
limitů bezplatné úrovně.

Jedná se o samostatný balíček od `@omniroute/opencode-plugin`, protože OpenCode v1 a v2 načítají
pluginy prostřednictvím odlišných rozhraní. Vyberte ten, který odpovídá vaší hlavní verzi OpenCode;
nic mezi nimi není sdíleno, takže aktualizace jednoho nikdy nevynutí aktualizaci druhého.

## Požadavky

- OpenCode v2.
- Dostupná brána OmniRoute (ve výchozím nastavení `http://localhost:20128`).
- Node.js 22 nebo 24.

## Instalace

Přidejte plugin do `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modely se poté zobrazí jako `omniroute/<provider>/<model>`; `providerId` určuje tuto předponu
a id integrace, pod kterým OpenCode ukládá přihlašovací údaj.

## Přihlašovací údaje

Plugin hledá klíč brány na třech místech, a to v tomto pořadí:

1. **Přihlašovací údaj, který jste připojili v OpenCode.** Plugin registruje integraci, takže
   vlastní ověřovací proces OpenCode může klíč uložit. Nic se nezapíše do `opencode.json` — tuto možnost upřednostněte.
2. `apiKey` v možnostech pluginu pro přepsání na úrovni projektu. Klíč se tak uloží do souboru,
   který můžete zahrnout do commitu.
3. `OMNIROUTE_API_KEY` v prostředí.

Pokud není k dispozici žádná z těchto tří možností, katalog zůstane prázdný a plugin to při spuštění
jednou oznámí, místo aby vám bez upozornění zobrazil prázdný výběr.

### Token pro správu je jiný klíč

Komba, stav poskytovatelů a obohacení (zobrazované názvy, ceny a limity bezplatné úrovně) pocházejí
z endpointů brány `/api/*`, které většina nasazení chrání **správcovským** tokenem,
nikoli klíčem pro inferenci:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<správcovský token pro čtení>"
}
```

Pokud `managementReadToken` není nastaven, použije se jako náhradní hodnota `apiKey`. Když brána tuto
náhradní hodnotu odmítne, katalog se přesto zveřejní, ale s nezpracovanými id modelů namísto zobrazovaných
názvů, bez deduplikace kanonických aliasů, cen a komb. Plugin při takové situaci jednou pro každý endpoint
zobrazí varování s názvem endpointu a informací o tom, co chybí — zhoršená podoba výběru tak nikdy není záhadou.

## Možnosti

| Klíč                             | Výchozí hodnota                                       | Poznámky                                                                                                               |
| -------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                         | Id poskytovatele, id integrace a předpona, pod kterou se modely zobrazují                                              |
| `baseURL`                        | povinné                                               | Kořenová adresa brány, pouze `http(s)`; přípona `/v1` se přidává tam, kde je potřeba                                   |
| `apiKey`                         | připojený přihlašovací údaj, poté `OMNIROUTE_API_KEY` | Klíč pro chat pro `/v1/*`                                                                                              |
| `managementReadToken`            | použije `apiKey` jako náhradní hodnotu                | Klíč pro `/api/*` — obvykle **nejde** o stejný klíč                                                                    |
| `displayName`                    | `"OmniRoute"`                                         | Název poskytovatele ve výběru                                                                                          |
| `timeoutMs`                      | `10000`                                               | Časový limit načítání pro každý endpoint (automatická komba používají 5 s)                                             |
| `modelCacheTtlMs`                | `300000`                                              | TTL mezipaměti katalogu; diskový snímek urychluje studené starty                                                       |
| `timeouts`                       | použije `timeoutMs` jako náhradní hodnotu             | Časové limity jednotlivých endpointů v ms: `models`, `combos`, `autoCombos`, `enrichment`                              |
| `enrichment`                     | `true`                                                | Načítat názvy, ceny a limity bezplatné úrovně                                                                          |
| `providerTag`                    | `true`                                                | Přidat před zobrazovaný název poskytovatele, ke kterému směrování vede                                                 |
| `usableOnly`                     | `false`                                               | Ponechat pouze poskytovatele, které brána uvádí jako zprovozněné                                                       |
| `visibleModels` / `hiddenModels` | `[]`                                                  | Seznamy povolených modelů podle přesné shody nebo přípony; zákaz má přednost                                           |
| `geminiSanitization`             | `true`                                                | Odebrat ze schémat nástrojů klíčová slova JSON Schema, která Gemini odmítá (nástroje s `$ref` se předávají beze změny) |
| `apiFormat.allowAnthropic`       | `false`                                               | Směrovat povolená id prostřednictvím bloku API Anthropic                                                               |
| `apiFormat.anthropicModels`      | `[]`                                                  | Úplná id modelů směrovaných do Anthropic                                                                               |
| `logLevel` / `startupDebug`      | `warn` / `false`                                      | Podrobnost protokolování                                                                                               |

## Jak katalog zůstává aktuální

Katalog se načítá až v případě potřeby a ukládá se do mezipaměti na dobu `modelCacheTtlMs`; snímek na disku navíc uchovává poslední známý katalog dostupný i tehdy, když je brána nedostupná — výpadek vás tedy nestojí nic kromě aktuálnosti. Modely a kombinace se zveřejní ihned po doručení; automatické kombinace, seznam poskytovatelů a překryvná obohacující data se začlení, jakmile dorazí, takže jeden pomalý koncový bod nemůže zablokovat celý výběr.

Názvy obsahují informace dostupné bráně: nadřazeného poskytovatele, ke kterému je model směrován, označení `[Free]` a související rozpočet — dvě připojení nabízející stejný model tak zůstávají rozlišitelná. Prefix lze vypnout pomocí `"providerTag": false`.

Příkaz pro ruční obnovení neexistuje: příkazy OpenCode v2 jsou šablony výzev, nikoli zpětná volání, takže jej plugin nemůže nabídnout. Obnovení se řídí hodnotou TTL; hostitel je vyzván k opětovnému načtení pouze tehdy, když se katalog nebo překryvná data skutečně změní, nikdy při každém obnovení.

## Volání nástrojů v Gemini

Gemini odmítne celý požadavek, pokud deklarace nástrojů obsahují `$schema` nebo `additionalProperties`, a odpoví chybou `400 INVALID_ARGUMENT`. Plugin tyto klíčové výrazy odstraní ze schémat nástrojů určených pro model Gemini tohoto poskytovatele a všechny ostatní požadavky ponechá beze změny. Nástroj obsahující `$ref` se předá beze změny namísto odstranění těchto výrazů, protože odstranění odkazu by rozšířilo schéma tak, že by „přijímalo cokoli“.
Tuto funkci lze vypnout nastavením `"geminiSanitization": false`.

## Řešení problémů

| Příznak                                          | Příčina                                                                                                   |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| Výběr nezobrazuje žádný model OmniRoute          | Nebyl nalezen žádný klíč (zkontrolujte upozornění při spuštění), nebo je brána nedostupná                 |
| Nezpracovaná ID modelů, žádné kombinace ani ceny | Koncové body pro správu odmítly token — nastavte `managementReadToken`                                    |
| Relace připnutá k `opencode-<id>/…`              | Plugin v1 zveřejňoval `opencode-<id>`; v2 zveřejňuje přímo `<id>`, proto model znovu vyberte pod `<id>/…` |
