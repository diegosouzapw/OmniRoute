## Kdy zvolit OmniRoute

- Provozujete vlastní hosting a chcete **maximální pokrytí poskytovatelů** (329 poskytovatelů, 155 bezplatných položek katalogu / bez ověření)
- Potřebujete **vestavěný server MCP** (nástroje LLM, paměť a dovednosti zpřístupněné jako nástroje)
- Potřebujete **protokol A2A** pro pracovní postupy mezi agenty
- Chcete **maskování fingerprintu** (JA3/JA4), abyste předešli detekci mechanismy CAPTCHA u upstream služeb
- Potřebujete **podnikové funkce** (ochranná opatření, evaluace, auditní stopu) bez účtu za SaaS

## Kdy zvolit LiteLLM

- Upřednostňujete **Python** a potřebujete těsnou integraci s `litellm.completion()`
- Potřebujete **vyzrálé postupy pro produkční nasazení** (k8s, Helm charts)
- Váš tým již provozuje mikroslužby v Pythonu

## Kdy zvolit OpenRouter (SaaS)

- Nechcete provozovat vlastní hosting
- Nevadí vám platit za token s přirážkou za SaaS
- Potřebujete **jedinou platební metodu** pro všechny poskytovatele

## Kdy zvolit Portkey

- Potřebujete **komerční SLA** se zárukami dostupnosti
- Preferujete **spravovaný dashboard** bez provozní režie
- Potřebujete **funkce pro dodržování podnikových předpisů** ihned po nasazení
