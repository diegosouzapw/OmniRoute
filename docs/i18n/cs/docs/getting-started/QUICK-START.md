## Krok 1: Nainstalujte OmniRoute

Vyberte si preferovaný způsob:

### Možnost A: npm (doporučeno)

```bash
npm install -g omniroute
```

### Možnost B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` označuje nejvyšší **publikovanou** stabilní verzi SemVer. Nesleduje větev `main` v gitu. Pro GitOps připněte `diegosouzapw/omniroute:X.Y.Z`. Viz [Tagy obrazů / kanály vydání](../guides/DOCKER_GUIDE.md#release-channels).

### Možnost C: Ze zdrojového kódu

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Krok 2: Spusťte OmniRoute

```bash
omniroute
```

OmniRoute se spustí na adrese `http://localhost:20128`. Ovládací panel se otevře automaticky.

---

## Krok 3: Připojte bezplatného poskytovatele

OmniRoute můžete používat **zcela zdarma**, pokud připojíte bezplatného poskytovatele.

### Možnost A: Kiro (Claude zdarma — bez platební karty)

1. Otevřete ovládací panel na adrese `http://localhost:20128`
2. Přejděte na **Poskytovatelé** → **Přidat poskytovatele**
3. Vyberte **Kiro AI**
4. Klikněte na **Připojit** (není potřeba žádný klíč API!)
5. Hotovo! Nyní máte bezplatný přístup k modelům Claude.

### Možnost B: OpenCode Free (bez ověření)

1. Otevřete ovládací panel na adrese `http://localhost:20128`
2. Přejděte na **Poskytovatelé** → **Přidat poskytovatele**
3. Vyberte **OpenCode Free**
4. Klikněte na **Připojit** (není potřeba žádný klíč API!)
5. Hotovo! Nyní máte bezplatný přístup k několika modelům.

### Možnost C: Pollinations (bez nutnosti klíče)

1. Otevřete ovládací panel na adrese `http://localhost:20128`
2. Přejděte na **Poskytovatelé** → **Přidat poskytovatele**
3. Vyberte **Pollinations**
4. Klikněte na **Připojit** (není potřeba žádný klíč API!)
5. Hotovo! Nyní máte bezplatný přístup k modelům GPT-5, Claude, Gemini a dalším.

---

## Krok 4: Ověřte funkčnost

Na stránce [Klíče API](http://localhost:20128/dashboard/api-manager) vytvořte nový klíč. Uložte si jej, protože se již znovu nezobrazí. Upozorňujeme, že tento klíč slouží nástrojům k přístupu k OmniRoute, nikoli k přístupu k nadřazeným poskytovatelům.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Měl by se zobrazit seznam připojených modelů.

## Krok 5: Nasměrujte své IDE nebo CLI na OmniRoute

Ve svém IDE nebo nástroji CLI nastavte:

```
Základní URL: http://localhost:20128/v1
Klíč API:     [zkopírujte z Ovládací panel → Koncové body]
Model:        auto
```

To je vše! Vaše IDE nyní používá OmniRoute s automatickým výběrem poskytovatele.

### Příklad IDE: VSCode/Continue.dev

1. Ve VSCode nainstalujte rozšíření [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Přidejte do souboru `~/.continue/config.yaml` následující řádky:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. V panelu chatu Continue.dev vyberte `OmniRoute - Auto` a vaše požadavky budou odesílány do OmniRoute.
4. (Volitelné) Cvičení pro čtenáře — nechte své IDE aktualizovat soubor `config.yaml` všemi ostatními předpřipravenými konfiguracemi 😊

### Příklad CLI: Codex CLI

1. Nastavte ve svém operačním systému proměnnou prostředí trvale.
   V systému macOS/Linux (přidejte do souboru `~/.bashrc` nebo `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

V systému Windows (Příkazový řádek):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Nyní spusťme Codex nakonfigurovaný pro OmniRoute. Spusťte:

```
omniroute launch-codex --model auto
```

Můžete to provést ručně pomocí příkazu `codex` a parametrů příkazového řádku určujících koncový bod a klíč API, ale s výše uvedeným příkazem se o vše postará OmniRoute.

Stejné spuštění jediným příkazem funguje i pro ostatní nástroje CLI prostřednictvím obecného spouštěče — `omniroute run <target>` podporuje `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` a `gemini` (viz [Integrace CLI](../guides/CLI-INTEGRATIONS.md)).

3. CLI by nyní mělo odesílat požadavky do OmniRoute.

### Ověřte, že váš nástroj směruje požadavky do OmniRoute

Podrobnosti požadavku zobrazíte kliknutím na [Monitorování/Protokoly](http://localhost:20128/dashboard/logs) v levém postranním panelu. Po rozkliknutí uvidíte další podrobnosti. Mimochodem zde můžete zjistit, jaké informace odesílá váš oblíbený nástroj. To je užitečné pro vzdělávání i ladění.

## Časté otázky

### „Potřebuji klíč API?“

**Ne!** Bezplatné poskytovatele (Kiro, OpenCode Free, Pollinations) můžete používat bez jakéhokoli klíče API. Stačí je připojit v ovládacím panelu.

### „Co je `auto`?“

`auto` říká OmniRoute, aby pro každý požadavek automaticky vybral nejlepšího poskytovatele. Bere v úvahu rychlost, cenu, kvalitu a dostupnost. Podrobnosti najdete v [Průvodci Auto-Combo](./AUTO-COMBO-GUIDE.md).

### „Kolik to stojí?“

Samotný OmniRoute je **zdarma a má otevřený zdrojový kód**. Platíte pouze za poskytovatele, které používáte. Mnoho poskytovatelů nabízí bezplatné tarify — viz [Průvodce bezplatnými tarify](./FREE-TIERS-GUIDE.md).

### „Mohu jej používat s Claude Code / Cursor / Copilot?“

**Ano!** OmniRoute funguje s libovolným nástrojem, který podporuje formát OpenAI. Stačí nastavit základní adresu URL na `http://localhost:20128/v1`. Konkrétní pokyny k nastavení najdete v [Průvodci nástroji CLI](../reference/CLI-TOOLS.md).

### „Co když dojde k výpadku poskytovatele?“

OmniRoute automaticky přeskočí nefunkční poskytovatele a zkusí dalšího. Nemusíte nic dělat. Podrobnosti najdete v [Průvodci Auto-Combo](./AUTO-COMBO-GUIDE.md).
