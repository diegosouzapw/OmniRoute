OmniRoute odděluje telemetrii kvót poskytovatele od účtování Ghostlight.

## Pravdivé stavy

- `healthy` znamená, že zdroj nahlásil dostupnou zbývající kapacitu.
- `approaching_limit` znamená, že zdroj nahlásil zbývající kapacitu na úrovni nakonfigurované prahové hodnoty nebo pod ní.
- `exhausted` je signalizován pouze tehdy, když zdroj nahlásí nulovou kapacitu nebo využití na úrovni limitu.
- `unavailable` znamená, že podporovaný zdroj nedokázal vrátit data.
- `unknown` znamená, že neexistuje žádný podporovaný zdroj nebo není znám žádný limit poskytovatele.

Neznámý stav neznamená vyčerpání a nezpůsobí deaktivaci poskytovatele.

Zdroje jsou upřednostňovány v tomto pořadí: oficiální API poskytovatele, ověřené API využití, explicitně mapované hlavičky odpovědi, konfigurace správce, místní odhady, neznámý stav. Místní odhady nejsou nikdy prezentovány jako fakturační údaje poskytovatele.

Hlavičky odpovědi jsou zpracovávány pouze prostřednictvím explicitního mapování poskytovatele. Nepředpokládá se, že obecné názvy hlaviček platí globálně.
