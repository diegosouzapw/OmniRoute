> **Zdroj pravdy:** `src/lib/obsidian/api.ts` (REST + synchronizační klient),
> `src/lib/db/obsidian.ts` (uchovávání tokenu / základní URL / WebDAV),
> `src/lib/obsidianSync.ts` (WebDAV synchronizace trezoru), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 nástrojů MCP), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API nastavení). Registrace nástrojů
> a propojení rozsahů oprávnění se nachází v `open-sse/mcp-server/server.ts`.

## Co to je

OmniRoute se připojuje k trezoru **Obsidian** jako ke **zdroji kontextu** — místní
znalostní bázi v Markdownu, kterou agenti čtou a zapisují prostřednictvím vestavěného
serveru MCP. Integrace komunikuje s komunitním pluginem **Obsidian Local REST API**
spuštěným v desktopové aplikaci, takže agenti mohou vyhledávat poznámky, číst/zapisovat/upravovat
soubory, procházet obsah trezoru, pracovat s denními/týdenními periodickými poznámkami,
spravovat značky, spouštět příkazy Obsidianu a (volitelně) koordinovat obousměrnou
synchronizaci trezoru mezi desktopem a mobilním zařízením.

Klient (`src/lib/obsidian/api.ts`) obaluje Local REST API a poskytuje:

- **Opakování s prodlevou** pro přechodné chyby `5xx`, **30sekundový časový limit** prostřednictvím `AbortController`.
- **Typovou klasifikaci chyb** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Srozumitelnou nápovědu „nelze se připojit k Obsidianu“**, která upozorňuje na častou
  chybu s portem (HTTP na `27123`, **nikoli** koncový bod MCP na `27124`) a na formát pro Tailscale.
- **Kódování cest** relativních vůči trezoru, aby byly cesty k poznámkám s mezerami/lomítky bezpečné.

## Nastavení

Pro token ani základní URL Obsidianu neexistuje **žádná proměnná prostředí** — obě
hodnoty se ukládají do tabulky SQLite `key_value` (jmenný prostor `obsidian`) prostřednictvím
`src/lib/db/obsidian.ts`. Token je **v úložišti šifrován** (AES-256-GCM se zpětně
kompatibilním záložním řešením pro prostý text). Konfiguraci proveďte na kartě
**Zdroje kontextu** v ovládacím panelu koncového bodu (`ObsidianSourceCard`) nebo
prostřednictvím REST API nastavení.

> [!IMPORTANT]
> Plugin **Obsidian Local REST API** musí být nainstalován a spuštěn. Jeho rozhraní REST
> naslouchá na **HTTP `127.0.0.1:27123`** (výchozí základní URL). Port `27124`
> je _samostatný_ koncový bod MCP/HTTPS a route nastavení jej explicitně odmítá.
> Při připojování z jiného zařízení použijte `http://<tailscale-ip>:27123`.

### Konfigurační klíče (SQLite `key_value`, jmenný prostor `obsidian`)

| Klíč              | Účel                                                          | Šifrováno |
| ----------------- | ------------------------------------------------------------- | --------- |
| `api_key`         | Nosný token Local REST API                                    | ano       |
| `base_url`        | Základní URL REST (výchozí `http://127.0.0.1:27123`)          | ne        |
| `vault_path`      | Absolutní cesta k adresáři trezoru (pro synchronizaci)        | ne        |
| `webdav_username` | Vygenerované uživatelské jméno WebDAV (synchronizace trezoru) | ne        |
| `webdav_password` | Vygenerované heslo WebDAV (synchronizace trezoru)             | ano       |
| `webdav_enabled`  | Zda je povolena synchronizace trezoru přes WebDAV             | ne        |

### Konfigurace prostřednictvím REST

```bash
# Uložení + ověření tokenu Local REST API (POST jej ověří kontrolou stavu)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Kontrola stavu připojení (vrací connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Odpojení (vymaže uložený token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Všechny metody vyžadují ověření v ovládacím panelu. `POST` odmítá všechny adresy URL
na portu `27124` a před uložením ověřuje token voláním stavového koncového bodu Local REST API.

### Synchronizace trezoru přes WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` spravuje volitelnou synchronizaci
trezoru založenou na WebDAV (zajišťovanou souborem `src/lib/obsidianSync.ts`). Jejím
povolením nasměrujete OmniRoute na místní adresář trezoru a vygenerujete náhodnou
dvojici uživatelského jména a hesla WebDAV:

```bash
# Povolení synchronizace přes WebDAV pro adresář trezoru (vygeneruje uživatelské jméno/heslo)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Získání stavu synchronizace přes WebDAV (přihlašovací údaje se vracejí pouze při jejím povolení)
curl http://localhost:20128/api/settings/obsidian/webdav

# Zakázání synchronizace přes WebDAV (vymaže přihlašovací údaje + spravovaný soubor .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Zdroj kontextu pro jednotlivé klíče API (volitelné)

Konfiguraci Obsidianu lze omezit **na jednotlivé klíče API** prostřednictvím tabulky
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Pokud volání MCP
obsahuje ID ověřeného klíče API, `getObsidianConfigForApiKey()` upřednostní vlastní
token/základní URL/cestu k trezoru daného klíče (`source: "api_key"`), jinak použije
globální konfiguraci (`source: "global"`).

## Nástroje MCP (22)

Definovány v `open-sse/mcp-server/tools/obsidianTools.ts`. Token a základní URL se určují
pro každé volání (nejprve podle API klíče, poté globálně). Nástroje, které komunikují se **synchronizačním serverem**
OmniRoute (čtyři nástroje `obsidian_sync_*`), navíc vyžadují ověřovací token synchronizace nakonfigurovaný
v nastavení OmniRoute.

### Nástroje pro čtení (`read:obsidian`)

| Nástroj                      | Popis                                                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Ověří, zda je místní REST API dostupné a ověřené.                                                            |
| `obsidian_search_simple`     | Fulltextové vyhledávání v obsahu poznámek; vrací úryvky s cestami k souborům.                                |
| `obsidian_search_structured` | Vyhledávání pomocí výrazu JSON Logic (filtry and/or/regex/path).                                             |
| `obsidian_read_note`         | Načte poznámku podle cesty relativní k trezoru; volitelně konkrétní nadpis/blok/frontmatter.                 |
| `obsidian_list_vault`        | Vypíše soubory a adresáře v trezoru (strom položek).                                                         |
| `obsidian_get_document_map`  | Získá strukturu nadpisů poznámky jako mapu nadpisů → čísel řádků.                                            |
| `obsidian_get_note_metadata` | Získá frontmatter, značky, odkazy a počet znaků/slov bez úplného obsahu.                                     |
| `obsidian_get_active_file`   | Získá cestu a obsah souboru, který je právě aktivní v Obsidianu.                                             |
| `obsidian_get_periodic_note` | Získá denní/týdenní/měsíční periodickou poznámku pro dané datum (při vynechání pro dnešek).                  |
| `obsidian_get_tags`          | Vypíše všechny značky v trezoru s četností jejich výskytu.                                                   |
| `obsidian_list_commands`     | Vypíše dostupná ID příkazů Obsidianu (pro použití s `obsidian_execute_command`).                             |
| `obsidian_sync_status`       | Stav synchronizačního serveru OmniRoute: spuštěn, název trezoru, port, doba provozu, poslední synchronizace. |
| `obsidian_sync_conflicts`    | Vypíše nevyřešené konflikty synchronizace (cesta, cesta ke konfliktu, čas zjištění).                         |

### Nástroje pro zápis (`write:obsidian`)

| Nástroj                          | Popis                                                                                         |
| -------------------------------- | --------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Vytvoří nebo přepíše poznámku zadaným obsahem Markdown.                                       |
| `obsidian_append_note`           | Připojí obsah k poznámce; volitelně ke konkrétnímu nadpisu/bloku.                             |
| `obsidian_patch_note`            | Přesně připojí, vloží před nebo nahradí obsah u nadpisu, bloku či pole frontmatteru.          |
| `obsidian_delete_note`           | Trvale odstraní poznámku z trezoru.                                                           |
| `obsidian_move_note`             | Přesune nebo přejmenuje poznámku v rámci trezoru.                                             |
| `obsidian_execute_command`       | Spustí příkaz Obsidianu podle jeho ID.                                                        |
| `obsidian_open_file`             | Otevře soubor v Obsidianu (pokud neexistuje, vytvoří jej).                                    |
| `obsidian_sync_trigger`          | Spustí okamžitou obousměrnou synchronizaci trezoru mezi počítačem a mobilním zařízením.       |
| `obsidian_sync_resolve_conflict` | Vyřeší konflikt synchronizace: zachovat `local` (mobil), `remote` (počítač) nebo `keep-both`. |

> [!NOTE]
> Cíle nástroje `obsidian_patch_note` přijímají `targetType` s hodnotou `heading | block | frontmatter`
> a `operation` s hodnotou `append | prepend | replace`, spolu s volitelným parametrem
> `createTargetIfMissing`. Čtyři nástroje `obsidian_sync_*` komunikují s místním synchronizačním
> serverem (ve výchozím nastavení `http://127.0.0.1:27781`) a vyžadují synchronizační token.

### Rozsahy oprávnění

Nástroje pro čtení vyžadují `read:obsidian`; nástroje pro zápis vyžadují `write:obsidian`. Vynucování
je stejné jako u Notionu — zajišťuje jej `withScopeEnforcement()` v souboru
`open-sse/mcp-server/server.ts`, je podmíněno hodnotou `OMNIROUTE_MCP_ENFORCE_SCOPES=true` a
povolené rozsahy se načítají z `OMNIROUTE_MCP_SCOPES` nebo z kontextu rozsahů API klíče. Viz
[MCP-SERVER.md](./MCP-SERVER.md).

## Koncové body

| Metoda   | Cesta                           | Účel                                                             |
| -------- | ------------------------------- | ---------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Vrátí `{ connected, hasToken, baseUrl, vaultPath }`.             |
| `POST`   | `/api/settings/obsidian`        | Uloží a ověří token (odmítne port `27124`).                      |
| `DELETE` | `/api/settings/obsidian`        | Odpojí integraci (vymaže uložený token).                         |
| `GET`    | `/api/settings/obsidian/webdav` | Stav synchronizace WebDAV + přihlašovací údaje (je-li povolena). |
| `POST`   | `/api/settings/obsidian/webdav` | Povolí synchronizaci WebDAV pro adresář trezoru.                 |
| `DELETE` | `/api/settings/obsidian/webdav` | Zakáže synchronizaci WebDAV.                                     |

> Toto jsou cesty nastavení ovládacího panelu. Samotný trezor je přístupný prostřednictvím
> Obsidian Local REST API (nakonfigurované `base_url`) a výše uvedených nástrojů MCP —
> žádný veřejný koncový bod proxy Obsidian `/v1` neexistuje.

## Případy použití

- **Odpovědi založené na obsahu trezoru** — `obsidian_search_simple` / `obsidian_search_structured`
  a následně `obsidian_read_note`, aby agent odpovídal na základě vašich skutečných poznámek.
- **Tvorba poznámek / vedení deníku** — `obsidian_write_note`, `obsidian_append_note` nebo
  přesný nástroj `obsidian_patch_note` pro zaznamenávání výstupů agenta, souhrnů či denních poznámek
  (`obsidian_get_periodic_note`) do trezoru.
- **Navigace v trezoru** — `obsidian_list_vault`, `obsidian_get_document_map` a
  `obsidian_get_tags` k prozkoumání struktury před čtením či zápisem.
- **Automatizace Obsidianu** — `obsidian_list_commands` + `obsidian_execute_command` pro
  ovládání pluginů/příkazů pomocí agenta; `obsidian_open_file` pro zobrazení poznámky v uživatelském rozhraní.
- **Mobilní synchronizace** — povolte synchronizaci WebDAV a poté pomocí `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  koordinujte synchronizaci mezi počítačem a mobilním zařízením a řešte konflikty.
