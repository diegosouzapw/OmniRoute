> **Zdroj pravdy:** `src/lib/localCorpus/index.ts` (omezený textový index),
> `src/lib/localCorpus/configured.ts` (nakonfigurované běhové prostředí),
> `src/lib/db/localCorpus.ts` (trvalé uložení kořenové cesty),
> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 nástroje MCP pouze pro čtení) a
> `src/app/api/settings/local-corpus/route.ts` (API nastavení).

## Co to je

Local Corpus umožňuje operátorovi zpřístupnit serveru MCP systému OmniRoute jeden výslovně schválený adresář textových souborů. Soubory zůstávají ve svém původním adresáři: OmniRoute ukládá do SQLite pouze kanonickou kořenovou cestu a udržuje vyhledávací index v paměti. Obsah korpusu nekopíruje do repozitáře ani databáze.

Aktualizace indexu probíhá přírůstkově. Nezměněné soubory se opětovně použijí na základě velikosti a času změny, změněné soubory se znovu načtou a vytvoří se pro ně otisk SHA-256 a odstraněné soubory se z indexu odeberou. Při vyhledávání se aktualizuje index starší než 30 sekund; volající mohou také požádat o okamžitou aktualizaci.

## Konfigurace zdroje

Trasa nastavení vyžaduje stejné ověření pro správu jako ostatní API nastavení. Odeslaná cesta již musí existovat a musí být absolutní cestou k adresáři.

```bash
# Připojení schváleného adresáře
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Kontrola konfigurace a stavu indexu
curl http://localhost:20128/api/settings/local-corpus

# Odpojení beze změny zdrojových souborů
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Nástroje MCP

Všechny tři nástroje vyžadují oprávnění `read:local-corpus`. Odpovědi nástrojů zpřístupňují relativní cesty a základní název kořenového adresáře, nikdy jeho absolutní cestu.

| Nástroj               | Popis                                                                                 |
| :-------------------- | :------------------------------------------------------------------------------------ |
| `local_corpus_status` | Ohlásí stav konfigurace, velikost indexu, limity a čas poslední aktualizace           |
| `local_corpus_search` | Prohledá indexovaný text a vrátí omezené úryvky vymezené řádky (až 20 výsledků)       |
| `local_corpus_read`   | Načte omezený rozsah řádků z jednoho povoleného souboru s cestou relativní ke korpusu |

Příklady vstupů MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Bezpečnostní hranice

- Seznam povolených přípon je zaměřen na textové soubory: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` a `.yml`.
- Symbolické odkazy se přeskakují. Cesty pro čtení se převádějí do kanonické podoby a musí zůstat uvnitř
  nakonfigurovaného kořenového adresáře; absolutní cesty a pokusy o průchod mimo něj jsou odmítnuty.
- Názvy citlivých a generovaných adresářů jsou vyloučeny: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` a
  `secrets`.
- Výchozí limity činí 5 000 souborů, 1 MiB na soubor, celkem 64 MiB indexovaného obsahu,
  přibližně 4 000 znaků na jeden vyhledávací blok a 400 řádků na jedno čtení.
- Soubory obsahující znak NUL se považují za netextové a jsou přeskočeny nebo odmítnuty.

Binární dokumenty, jako jsou PDF, DOCX, obrázky a archivy, záměrně nejsou podporovány.
Před indexováním je v nakonfigurovaném adresáři převeďte do schváleného textového formátu.

## Provozní poznámky

- Změna nebo odstranění nakonfigurovaného kořenového adresáře vymaže sdílený index v paměti.
- Restart procesu zahodí index; při příštím vyhledávání se znovu sestaví z nakonfigurovaného
  zdroje.
- `local_corpus_status` nevynucuje prohledání souborů. Pokud je vyžadováno okamžité opětovné prohledání, použijte `local_corpus_search` s
  `refresh: true`.
- Selhání při prohledávání a čtení se započítávají nebo vracejí jako očištěné chyby; zdrojové soubory se
  nikdy neupravují.
