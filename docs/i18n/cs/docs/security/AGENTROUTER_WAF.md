Upstream brána `agentrouter` používá na `messages[].content` filtr obsahu založený na klíčových slovech. Filtr je částečně deterministický (určité fráze blokuje vždy) a částečně pravděpodobnostní (je citlivý na dávky požadavků — po rychle odeslaných požadavcích je agresivnější a po době klidu se zotaví).

Když WAF zablokuje požadavek, vrátí:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Rozsah filtru

WAF kontroluje pouze `messages[].content`. **Nekontroluje**:

- Systémovou výzvu `system`
- Bloky strukturovaného obsahu (`tool_result`, `tool_use`, `thinking`, `image`)
- Pole nástrojů `description` a `input_schema`
- Metadata požadavku, hlavičky ani ID modelu

## Vzory blokované vždy (bez ohledu na velikost písmen)

| Vzor                            | Poznámky                                              |
| ------------------------------- | ----------------------------------------------------- |
| Jakákoli varianta `Lorem ipsum` | Blokována je celá latinská slovní zásoba lorem        |
| `language model` (samostatně)   | „the language model“ a „large language model“ projdou |
| `virtual assistant`             | „AI assistant“ projde                                 |
| `I'm here to help`              | Samotné „here to help“ se také blokuje                |
| `Claude, made by Anthropic`     | Pouze celá fráze                                      |

## Vzory blokované téměř vždy

| Vzor                                                      | Poznámky                                                      |
| --------------------------------------------------------- | ------------------------------------------------------------- |
| `placeholder`                                             | Když stojí samostatně (nikoli například jako název parametru) |
| `dummy data`                                              | Běžná počáteční fráze pro testovací data                      |
| `foo bar baz`                                             | Kanonická zástupná fráze                                      |
| Opakované krátké tokeny (`AAA BBB CCC`, `test test test`) | Detektor zahlcování klíčovými slovy                           |

## Chování při zatížení

Po přibližně 5 rychlých požadavcích v krátkém časovém úseku začne WAF blokovat obsah, který by za normálních okolností prošel. Bucket se uvolní přibližně po 5–10 sekundách nečinnosti. Jde o stejný omezovač rychlosti vázaný na IP adresu a klíč, který způsobuje občasné chyby `400 content-blocked`, když Claude Code nebo Codex CLI provede několik volání použití nástroje / odeslání zprávy v rychlém sledu.

## Opatření již použitá v OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — ochrana proti dávkám, která vynucuje minimální rozestup 500 ms mezi odchozími požadavky na libovolnou adresu URL odpovídající `agentrouter:*`. Tento rozestup je hluboko pod hranicí, kdy by člověk vnímal zpoždění, a zabraňuje aktivaci WAF při běžném provozu.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — když upstream vrátí `400 content-blocked`, executor zopakuje požadavek na stejnou adresu URL s exponenciálním prodlužováním prodlevy (1,5 s, 3,0 s, maximálně 2 pokusy). Po této prodlevě se WAF obvykle uvolní a opakovaný pokus uspěje.

3. **`tests/unit/compression/harness.test.ts`** — testovací fixture `longInput` byla změněna z `"lorem ipsum dolor sit amet ".repeat(40)` na `"example content for testing purposes ".repeat(40)`, aby při čtení tohoto souboru pomocí nástroje `Read` v Claude Code jeho obsah neprocházel zpět přes blok `tool_result` a neaktivoval WAF.

## Doporučení pro výzvy a výstup nástrojů

Pokud relace Claude Code nebo Codex CLI opakovaně naráží na `400 content-blocked`, zkontrolujte nejnovější zprávu uživatele a nejnovější výsledek nástroje, zda neobsahují některý z výše uvedených vzorů, a přeformulujte je. Běžná řešení:

- Nahraďte `Lorem ipsum …` výrazem `example text …` nebo skutečným obsahem, který má test či fixture modelovat.
- Nahraďte `placeholder` (pokud stojí samostatně) výrazem `example value`, `sample value` nebo skutečnou hodnotou.
- Nahraďte `language model` výrazem `large language model` nebo `the model`.
- Nahraďte `dummy data` výrazem `sample data` nebo realistickými počátečními hodnotami.
- Nahraďte `I'm here to help` / `here to help` konkrétnějším úvodem (např. „I'll review the file you mentioned“).

## Hlášení falešně pozitivních výsledků upstreamu

Současný filtr je příliš agresivní — blokuje „Lorem ipsum“ v blocích `tool_result`, přestože operátor zjevně neměl v úmyslu vložit výzvu. Provozovatelé, kteří chtějí, aby byla tato chyba opravena u zdroje, by měli kontaktovat `agentrouter.org` a falešně pozitivní výsledky nahlásit. Výše uvedený seznam blokovaných výrazů je empirickým výsledkem testování upstreamu k datu 2026-08-03.
