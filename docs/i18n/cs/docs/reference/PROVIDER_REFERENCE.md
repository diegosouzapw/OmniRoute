Celkem poskytovatelů: **360**. Rozpis kategorií viz níže.

## Kategorie

- **Zdarma** — bezplatná úroveň s klíčem API (konfiguruje se přes řídicí panel)
- **Bez ověření** — veřejné koncové body, které vůbec nevyžadují klíč ani přihlášení
- **OAuth** — přihlašovací proces zajišťuje OmniRoute, klíč API není potřeba
- **Webový soubor cookie** — zpřístupňuje webovou aplikaci poskytovatele prostřednictvím ověřování pomocí souborů cookie
- **Klíč API** — placený poskytovatel konfigurovaný pomocí klíče API (mohou být k dispozici bezplatné kredity)
- **Lokální** — běží na zařízení uživatele (Ollama, LM Studio, vLLM atd.)
- **Vyhledávání** — poskytovatelé webového vyhledávání
- **Audio** — poskytovatelé pouze zvukových služeb (TTS/STT)
- **Nadřazený proxy server** — poskytovatelé, kteří zprostředkovávají přístup k jiným poskytovatelům
- **Cloudový agent** — dlouhodobě běžící programovací agenti (Codex Cloud, Devin, Jules)
- **Systém** — interní poskytovatelé OmniRoute (loopback atd.)

Další značky: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Volání nástrojů` (je-li uvedeno): `native` — skutečné API pro volání funkcí; `emulated` — pole `tools` je emulováno v promptu prostřednictvím souboru `webTools.ts` (bloky `<tool>{...}</tool>` analyzované regulárními výrazy); `none` — pole `tools` je v současnosti bez upozornění zahozeno. Viz #7286.

Jednotlivé poskytovatele můžete povolit, nakonfigurovat a otestovat na řídicím panelu na adrese `/dashboard/providers`.
