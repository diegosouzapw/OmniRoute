OmniRoute obsahuje pečlivě vybranou sadu bezplatných proxy serverů v tabulce `free_proxies`,
synchronizovanou z externích poskytovatelů (1proxy, proxifly, iplocate, webshare).
Řídicí panel je zobrazuje v části **Nastavení → Bezplatné proxy servery**. Tento dokument
popisuje filtrování, řazení, počítání a hlášení chyb synchronizace na straně serveru,
které zpřístupňuje trasa seznamu.

## Trasa seznamu — `GET /api/settings/free-proxies`

Vrací filtrovanou, seřazenou a stránkovanou část dat společně s celkovým počtem. Filtrování
a počítání probíhá v SQL, takže uživatelské rozhraní může zobrazit skutečný celkový počet (např. `Celkem: 0`)
bez načítání všech řádků do paměti.

### Parametry dotazu

| Parametr          | Typ                                | Výchozí   | Význam                                                                                                                  |
| ----------------- | ---------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------- |
| `search`          | řetězec                            | `""`      | `LIKE` rozlišující velikost písmen ve sloupci hostitele (a zdroje).                                                     |
| `protocol`        | řetězec                            | `""`      | Filtr `type`: `http` / `https` / `socks4` / `socks5`. Prázdná hodnota = vše.                                            |
| `country`         | řetězec                            | `""`      | Filtr `countryCode` (ISO-2). Prázdná hodnota = vše.                                                                     |
| `minQuality`      | číslo                              | `0`       | Pouze řádky s `qualityScore >= minQuality`. `0` = bez minimální hranice.                                                |
| `disabledSources` | řetězec                            | `""`      | Čárkami oddělená ID zdrojů, která se mají vyloučit (např. `proxifly,webshare`).                                         |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = skóre sestupně; `latency` = latence vzestupně (hodnoty null poslední); `recent` = `lastValidated` sestupně. |
| `offset`          | číslo                              | `0`       | Začátek stránkování.                                                                                                    |
| `limit`           | číslo                              | `50`      | Velikost stránky (omezená na straně serveru).                                                                           |

### Odpověď

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 od nadřazeného serveru"],
    "webshare": ["časový limit sítě"]
  }
}
```

`total` představuje filtrovaný celkový počet **před** stránkováním, takže uživatelské rozhraní může vykreslit
`Celkem: N` a `hasMore` nezávisle na sobě. `syncErrors` používá jako klíče ID zdrojů a
je vyplněno pouze pro zdroje, jejichž poslední synchronizace selhala — výsledek `Celkem: 0`
proto nikdy není bez vysvětlení.

## Přidání do fondu — `POST /api/settings/free-proxies/[id]/add-to-pool`

Povýší bezplatný proxy server do spravovaného fondu `proxy_registry`. Nejprve ověří
nadřazený server; při úspěchu vrátí ID nového proxy serveru ve fondu a naměřenou latenci.

## Synchronizace — `POST /api/settings/free-proxies/sync`

Znovu načte všechny povolené zdroje (nebo podmnožinu uvedenou v `{ "sources": [...] }`). Každý
zdroj se synchronizuje nezávisle; selhání zdroje se zaznamená do `syncErrors` a ostatní
zdroje se přesto dokončí, takže částečné synchronizace nikdy nevymažou dříve získaná platná data.

## Statistiky — `GET /api/settings/free-proxies/stats`

Vrací agregované hodnoty `total / inPool / avgQuality / bySource / lastSyncAt`
bez dat jednotlivých řádků — používají je widgety v záhlaví řídicího panelu.
