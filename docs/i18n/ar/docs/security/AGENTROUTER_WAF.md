تُشغّل بوابة المنبع `agentrouter` مرشح محتوى قائمًا على الكلمات المفتاحية على
`messages[].content`. المرشح حتمي جزئيًا (يحظر دائمًا
عبارات معينة) واحتمالي جزئيًا (حساس للطلبات المتدفقة — يصبح
أكثر تشددًا بعد الطلبات السريعة، ثم يتعافى بعد فترة تهدئة).

عندما يحظر WAF طلبًا، فإنه يعيد:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## نطاق المرشح

يفحص WAF الحقل `messages[].content` فقط. وهو **لا** يفحص:

- موجه `system`
- كتل المحتوى المنظّمة (`tool_result`، و`tool_use`، و`thinking`، و`image`)
- حقلي `description` و`input_schema` الخاصين بالأداة
- بيانات الطلب الوصفية أو الترويسات أو معرّف النموذج

## الأنماط المحظورة دائمًا (بصرف النظر عن حالة الأحرف)

| النمط                       | ملاحظات                                                    |
| --------------------------- | ---------------------------------------------------------- |
| أي صيغة من `Lorem ipsum`    | تُحظر مفردات lorem اللاتينية كاملةً                        |
| `language model` (بمفردها)  | تمر العبارتان "the language model" و"large language model" |
| `virtual assistant`         | تمر العبارة "AI assistant"                                 |
| `I'm here to help`          | تُحظر أيضًا عبارة "here to help" بمفردها                   |
| `Claude, made by Anthropic` | العبارة الكاملة فقط                                        |

## الأنماط المحظورة في معظم الحالات

| النمط                                                      | ملاحظات                                           |
| ---------------------------------------------------------- | ------------------------------------------------- |
| `placeholder`                                              | عندما تأتي بمفردها (وليس كاسم معلمة، وما إلى ذلك) |
| `dummy data`                                               | عبارة أولية شائعة للتجهيزات الاختبارية            |
| `foo bar baz`                                              | عبارة عنصر نائب معيارية                           |
| الرموز القصيرة المتكررة (`AAA BBB CCC`، و`test test test`) | أداة كشف حشو الكلمات المفتاحية                    |

## السلوك تحت الحمل

بعد نحو 5 طلبات سريعة ضمن نافذة زمنية قصيرة، يبدأ WAF في حظر محتوى
كان سيمر عادةً. ويسترخي دلو التقييد بعد نحو 5–10 ثوانٍ من
الخمول. وهذا هو محدد المعدل نفسه المرتبط بعنوان IP والمفتاح، والذي يتسبب في
أخطاء `400 content-blocked` المتقطعة عندما يجري Claude Code أو Codex CLI
عدة استدعاءات لاستخدام الأدوات أو إرسال الرسائل بتتابع سريع.

## إجراءات التخفيف المطبقة بالفعل في OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — حارس تدفق يفرض
   حدًا أدنى قدره 500 ms بين الطلبات الصادرة إلى أي عنوان URL من نوع `agentrouter:*`.
   الفاصل أقل بكثير من أن يدركه الإنسان كتأخير، ويمنع
   تنشيط WAF في حركة البيانات العادية.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — عندما يعيد المنبع
   `400 content-blocked`، يعيد المنفّذ محاولة عنوان URL نفسه باستخدام
   تراجع أُسّي (1.5 s، ثم 3.0 s، وبحد أقصى محاولتان). بعد التراجع،
   يكون WAF قد استرخى عادةً وتنجح إعادة المحاولة.

3. **`tests/unit/compression/harness.test.ts`** — تغيّرت التجهيزة الاختبارية
   `longInput` من `"lorem ipsum dolor sit amet ".repeat(40)`
   إلى `"example content for testing purposes ".repeat(40)` بحيث عندما
   يقرأ Claude Code هذا الملف عبر أداة `Read`، لا تتدفق محتويات الملف
   مجددًا عبر كتلة `tool_result` وتتسبب في تشغيل WAF.

## إرشادات للموجهات ومخرجات الأدوات

إذا واجهت جلسة Claude Code أو Codex CLI الخطأ
`400 content-blocked` بشكل متكرر، فتحقق من أحدث رسالة للمستخدم ومن أحدث
نتيجة للأداة بحثًا عن أي من الأنماط المذكورة أعلاه، ثم أعد صياغتها. تشمل
الحلول البديلة الشائعة:

- استبدل `Lorem ipsum …` بـ`example text …` أو بالمحتوى الفعلي
  الذي يحاول الاختبار أو التجهيزة تمثيله.
- استبدل `placeholder` (عندما تأتي بمفردها) بـ`example value`،
  أو `sample value`، أو بالقيمة الحقيقية.
- استبدل `language model` بـ`large language model` أو `the model`.
- استبدل `dummy data` بـ`sample data` أو بقيم أولية واقعية.
- استبدل `I'm here to help` / `here to help` بافتتاحية أكثر تحديدًا
  (مثلًا: "سأراجع الملف الذي ذكرته").

## الإبلاغ عن النتائج الإيجابية الكاذبة إلى المنبع

المرشح الحالي شديد العدوانية — فهو يحظر "Lorem ipsum" داخل
كتل `tool_result` رغم أن المشغّل لم يقصد بوضوح
حقن موجه. ينبغي للمشغّلين الذين يريدون إصلاح ذلك من المصدر
التواصل مع `agentrouter.org` للإبلاغ عن النتائج الإيجابية الكاذبة. قائمة الحظر
أعلاه هي النتيجة التجريبية لفحص المنبع بتاريخ 2026-08-03.
