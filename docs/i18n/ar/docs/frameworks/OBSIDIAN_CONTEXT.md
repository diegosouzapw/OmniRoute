> **مصدر الحقيقة:** `src/lib/obsidian/api.ts` (عميل REST + المزامنة)،
> `src/lib/db/obsidian.ts` (استمرارية الرمز المميز / عنوان URL الأساسي / WebDAV)،
> `src/lib/obsidianSync.ts` (مزامنة خزنة WebDAV)، `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 أداة MCP)، `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (واجهات API للإعدادات). يوجد تسجيل الأدوات
> وربط النطاقات في `open-sse/mcp-server/server.ts`.

## ماهيته

يتصل OmniRoute بخزنة **Obsidian** بوصفها **مصدر سياق** — وهي قاعدة معرفة محلية بصيغة Markdown
تقرأ منها الوكلاء وتكتب إليها عبر خادم MCP المدمج. يتواصل التكامل مع إضافة المجتمع
**Obsidian Local REST API** التي تعمل داخل تطبيق سطح المكتب، ما يتيح للوكلاء البحث في الملاحظات،
وقراءة الملفات وكتابتها وتصحيحها، وسرد محتويات الخزنة، والعمل مع الملاحظات الدورية اليومية/الأسبوعية،
وإدارة الوسوم، وتشغيل أوامر Obsidian، و(اختياريًا) تنسيق مزامنة ثنائية الاتجاه للخزنة بين سطح المكتب↔الهاتف المحمول.

يغلف العميل (`src/lib/obsidian/api.ts`) واجهة Local REST API بالميزات التالية:

- **إعادة المحاولة مع تراجع تدريجي** لأخطاء `5xx` المؤقتة، و**مهلة 30 ثانية** عبر `AbortController`.
- **تصنيف محدد الأنواع للأخطاء** — `ObsidianAuthError` (401/403)،
  و`ObsidianNotFoundError` (404)، و`ObsidianServerError` (5xx)، و`ObsidianTimeoutError`.
- **تلميح سهل الفهم بشأن "تعذر الوصول إلى Obsidian"** يوضح خطأ المنفذ الشائع
  (HTTP على `27123`، **وليس** نقطة نهاية MCP على `27124`) وصيغة Tailscale.
- **ترميز المسارات** النسبية إلى الخزنة، بحيث تكون مسارات الملاحظات التي تحتوي على مسافات/شرطات مائلة آمنة.

## الإعداد

لا يوجد **متغير بيئة** لرمز Obsidian المميز أو عنوان URL الأساسي — فكلاهما
مخزّن في جدول SQLite المسمى `key_value` (ضمن نطاق الأسماء `obsidian`) عبر
`src/lib/db/obsidian.ts`. الرمز المميز **مشفّر أثناء التخزين** (AES-256-GCM، مع
احتياط للتوافق مع الإصدارات السابقة للنص العادي). اضبط الإعدادات من علامة تبويب **مصادر السياق** في
لوحة معلومات نقطة النهاية (`ObsidianSourceCard`)، أو عبر واجهة REST API للإعدادات.

> [!IMPORTANT]
> يجب تثبيت إضافة **Obsidian Local REST API** وتشغيلها. تستمع واجهة REST الخاصة بها
> على **HTTP `127.0.0.1:27123`** (عنوان URL الأساسي الافتراضي). المنفذ `27124`
> هو نقطة نهاية MCP/HTTPS _منفصلة_، ويرفضه مسار الإعدادات صراحةً.
> عند الاتصال من جهاز آخر، استخدم `http://<tailscale-ip>:27123`.

### مفاتيح الإعداد (جدول SQLite المسمى `key_value`، ضمن نطاق الأسماء `obsidian`)

| المفتاح           | الغرض                                                          | مشفّر |
| ----------------- | -------------------------------------------------------------- | ----- |
| `api_key`         | رمز حامل Local REST API المميز                                 | نعم   |
| `base_url`        | عنوان URL الأساسي لـ REST (الافتراضي `http://127.0.0.1:27123`) | لا    |
| `vault_path`      | المسار المطلق إلى دليل الخزنة (للمزامنة)                       | لا    |
| `webdav_username` | اسم مستخدم WebDAV المُنشأ (مزامنة الخزنة)                      | لا    |
| `webdav_password` | كلمة مرور WebDAV المُنشأة (مزامنة الخزنة)                      | نعم   |
| `webdav_enabled`  | ما إذا كانت مزامنة الخزنة عبر WebDAV مفعّلة                    | لا    |

### الضبط عبر REST

```bash
# حفظ رمز Local REST API المميز والتحقق منه (يتحقق POST عبر فحص الحالة)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# فحص حالة الاتصال (يعيد connected وhasToken وbaseUrl وvaultPath)
curl http://localhost:20128/api/settings/obsidian

# قطع الاتصال (يمسح الرمز المميز المخزّن)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

تتطلب جميع الأساليب مصادقة لوحة المعلومات. يرفض `POST` أي عنوان URL على المنفذ `27124`
ويتحقق من الرمز المميز عن طريق استدعاء نقطة نهاية الحالة في Local REST API قبل حفظه.

### مزامنة الخزنة عبر WebDAV

يدير `src/app/api/settings/obsidian/webdav/route.ts` مزامنة اختيارية للخزنة
مدعومة بـ WebDAV (ويشغّلها `src/lib/obsidianSync.ts`). يؤدي تمكينها إلى توجيه OmniRoute نحو
دليل خزنة محلي وإنشاء زوج عشوائي من اسم مستخدم/كلمة مرور WebDAV:

```bash
# تمكين مزامنة WebDAV لدليل خزنة (ينشئ اسم مستخدم/كلمة مرور)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# الحصول على حالة مزامنة WebDAV (تُعاد بيانات الاعتماد فقط أثناء التمكين)
curl http://localhost:20128/api/settings/obsidian/webdav

# تعطيل مزامنة WebDAV (يمسح بيانات الاعتماد وملف .stignore المُدار)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### مصدر سياق لكل مفتاح API (اختياري)

يمكن تحديد نطاق إعداد Obsidian **لكل مفتاح API** عبر جدول `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). عندما يتضمن استدعاء MCP معرّف مفتاح API مصادقًا عليه،
يفضّل `getObsidianConfigForApiKey()` الرمز المميز/عنوان URL الأساسي/مسار الخزنة الخاص بذلك المفتاح
(`source: "api_key"`)، وإلا فيعود إلى الإعداد العام (`source: "global"`).

## أدوات MCP ‏(22)

مُعرَّفة في `open-sse/mcp-server/tools/obsidianTools.ts`. يتم تحديد الرمز المميز/عنوان URL الأساسي
لكل استدعاء (مفتاح API أولًا، ثم الإعداد العام). تتطلب الأدوات التي تتصل بـ **خادم المزامنة**
الخاص بـ OmniRoute (أدوات `obsidian_sync_*` الأربع) أيضًا رمز مصادقة المزامنة المهيأ
في إعدادات OmniRoute.

### أدوات القراءة (`read:obsidian`)

| الأداة                       | الوصف                                                                                  |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | التحقق مما إذا كانت Local REST API قابلة للوصول ومصادقًا عليها.                        |
| `obsidian_search_simple`     | البحث بالنص الكامل في محتوى الملاحظات؛ يعيد مقتطفات مع مسارات الملفات.                 |
| `obsidian_search_structured` | البحث باستخدام تعبير JSON Logic (مرشحات and/or/regex/path).                            |
| `obsidian_read_note`         | قراءة ملاحظة حسب المسار النسبي للخزنة؛ مع إمكانية تحديد عنوان/كتلة/frontmatter بعينها. |
| `obsidian_list_vault`        | سرد الملفات والمجلدات في الخزنة (شجرة من الإدخالات).                                   |
| `obsidian_get_document_map`  | الحصول على بنية عناوين الملاحظة في صورة خريطة من العناوين ← أرقام الأسطر.              |
| `obsidian_get_note_metadata` | الحصول على frontmatter والوسوم والروابط وعدد الأحرف/الكلمات دون المحتوى الكامل.        |
| `obsidian_get_active_file`   | الحصول على المسار + محتوى الملف النشط حاليًا في Obsidian.                              |
| `obsidian_get_periodic_note` | الحصول على الملاحظة الدورية اليومية/الأسبوعية/الشهرية لتاريخ ما (اليوم إذا لم يُحدد).  |
| `obsidian_get_tags`          | سرد جميع وسوم الخزنة مع تكراراتها.                                                     |
| `obsidian_list_commands`     | سرد معرّفات أوامر Obsidian المتاحة (للاستخدام مع `obsidian_execute_command`).          |
| `obsidian_sync_status`       | حالة خادم مزامنة OmniRoute: التشغيل، واسم الخزنة، والمنفذ، ومدة التشغيل، وآخر مزامنة.  |
| `obsidian_sync_conflicts`    | سرد تعارضات المزامنة غير المحلولة (المسار، ومسار التعارض، ووقت الاكتشاف).              |

### أدوات الكتابة (`write:obsidian`)

| الأداة                           | الوصف                                                                                            |
| -------------------------------- | ------------------------------------------------------------------------------------------------ |
| `obsidian_write_note`            | إنشاء ملاحظة أو الكتابة فوقها بمحتوى Markdown المحدد.                                            |
| `obsidian_append_note`           | إلحاق محتوى بملاحظة؛ مع إمكانية إلحاقه بعنوان/كتلة محددة.                                        |
| `obsidian_patch_note`            | إلحاق/إضافة في البداية/استبدال بشكل دقيق عند عنوان أو كتلة أو حقل frontmatter.                   |
| `obsidian_delete_note`           | حذف ملاحظة نهائيًا من الخزنة.                                                                    |
| `obsidian_move_note`             | نقل ملاحظة أو إعادة تسميتها داخل الخزنة.                                                         |
| `obsidian_execute_command`       | تنفيذ أمر Obsidian باستخدام معرّف الأمر الخاص به.                                                |
| `obsidian_open_file`             | فتح ملف في Obsidian (ينشئه إذا لم يكن موجودًا).                                                  |
| `obsidian_sync_trigger`          | تشغيل مزامنة ثنائية الاتجاه وفورية للخزنة بين سطح المكتب↔الهاتف المحمول.                         |
| `obsidian_sync_resolve_conflict` | حل تعارض مزامنة: الاحتفاظ بـ `local` (الهاتف المحمول)، أو `remote` (سطح المكتب)، أو `keep-both`. |

> [!NOTE]
> تقبل أهداف `obsidian_patch_note` قيمة `targetType` من `heading | block | frontmatter`
> وقيمة `operation` من `append | prepend | replace`، مع
> `createTargetIfMissing` اختياري. تتصل أدوات `obsidian_sync_*` الأربع بخادم المزامنة المحلي
> (`http://127.0.0.1:27781` افتراضيًا) وتتطلب رمز المزامنة.

### النطاقات

تتطلب أدوات القراءة `read:obsidian`؛ وتتطلب أدوات الكتابة `write:obsidian`. ويكون الإنفاذ
مطابقًا لـ Notion — إذ تتولاه `withScopeEnforcement()` في
`open-sse/mcp-server/server.ts`، ويكون مشروطًا بأن تكون قيمة `OMNIROUTE_MCP_ENFORCE_SCOPES=true`، مع
استخلاص النطاقات المسموح بها من `OMNIROUTE_MCP_SCOPES` أو سياق نطاق مفتاح API. راجع
[MCP-SERVER.md](./MCP-SERVER.md).

## نقاط النهاية

| الطريقة  | المسار                          | الغرض                                                |
| -------- | ------------------------------- | ---------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | إرجاع `{ connected, hasToken, baseUrl, vaultPath }`. |
| `POST`   | `/api/settings/obsidian`        | حفظ الرمز المميز والتحقق منه (يرفض المنفذ `27124`).  |
| `DELETE` | `/api/settings/obsidian`        | قطع الاتصال (مسح الرمز المميز المخزّن).              |
| `GET`    | `/api/settings/obsidian/webdav` | حالة مزامنة WebDAV وبيانات الاعتماد (أثناء التمكين). |
| `POST`   | `/api/settings/obsidian/webdav` | تمكين مزامنة WebDAV لدليل خزنة.                      |
| `DELETE` | `/api/settings/obsidian/webdav` | تعطيل مزامنة WebDAV.                                 |

> هذه هي مسارات إعدادات لوحة المعلومات. يجري الوصول إلى الخزنة نفسها عبر واجهة Obsidian
> Local REST API (القيمة `base_url` المضبوطة) ومن خلال أدوات MCP أعلاه — ولا توجد
> نقطة نهاية وكيلة عامة لـ Obsidian على المسار `/v1`.

## حالات الاستخدام

- **إجابات مستندة إلى الخزنة** — استخدم `obsidian_search_simple` / `obsidian_search_structured`
  ثم `obsidian_read_note` لكي يجيب الوكيل استنادًا إلى ملاحظاتك الفعلية.
- **تأليف الملاحظات / تدوين اليوميات** — استخدم `obsidian_write_note` أو `obsidian_append_note` أو
  العملية الدقيقة `obsidian_patch_note` لتسجيل مخرجات الوكيل أو الملخصات أو الملاحظات اليومية
  (`obsidian_get_periodic_note`) في الخزنة.
- **التنقل في الخزنة** — استخدم `obsidian_list_vault` و`obsidian_get_document_map` و
  `obsidian_get_tags` لاستكشاف البنية قبل القراءة/الكتابة.
- **أتمتة Obsidian** — استخدم `obsidian_list_commands` مع `obsidian_execute_command`
  لتشغيل الإضافات/الأوامر من وكيل؛ واستخدم `obsidian_open_file` لإظهار ملاحظة في واجهة المستخدم.
- **المزامنة مع الأجهزة المحمولة** — مكّن مزامنة WebDAV، ثم استخدم `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  لتنسيق المزامنة بين سطح المكتب والهاتف المحمول وحل التعارضات.
