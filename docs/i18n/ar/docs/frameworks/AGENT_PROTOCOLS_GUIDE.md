> **المصدر:** `src/lib/{a2a,acp,cloudAgent}/`، `src/app/api/{a2a,acp,cloud}/`، `src/app/api/v1/agents/`
> **آخر تحديث:** 2026-06-28 — v3.8.40

يوفّر OmniRoute ثلاث واجهات مختلفة مرتبطة بالوكلاء. قد تبدو متشابهة للوهلة الأولى، لكنها تحل مشكلات مختلفة. استخدم هذه الصفحة لاختيار الواجهة المناسبة.

## الخلاصة

| الواجهة                    | الأنسب لـ                                                                                                                           | وسيلة النقل                           | المعيار                  |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- | ------------------------ |
| **A2A — من وكيل إلى وكيل** | التعاون بين الوكلاء مع وكلاء نظراء يدعمون بروتوكول A2A                                                                              | JSON-RPC 2.0 عبر HTTP                 | A2A v0.3 (مواصفة مفتوحة) |
| **ACP — سجل وكلاء CLI**    | اكتشاف / تسجيل / تشغيل وكلاء البرمجة عبر CLI المثبّتين على جهاز المستخدم (Cursor، وCline، وCodex CLI، وClaude Code، وAider، وغيرها) | HTTP REST                             | خاص بـ OmniRoute         |
| **الوكلاء السحابيون**      | إرسال مهام برمجية طويلة الأمد إلى خدمات سحابية خارجية (Codex Cloud، وDevin، وJules، وCursor Cloud)                                  | HTTP REST + مهام مدعومة بقاعدة بيانات | خاص بـ OmniRoute         |

هذه الواجهات الثلاث مستقلة — اختر أي مجموعة فرعية منها.

## شجرة القرار

```
هل تحتاج إلى خدمة سحابية لتنفيذ العمل خارج هذا الجهاز (Codex Cloud / Cursor Cloud / Devin / Jules)؟
├─ نعم → الوكلاء السحابيون (POST /api/v1/agents/tasks)
└─ لا → تابع
    │
    هل لديك وكيل نظير يدعم A2A ويريد التعاون؟
    ├─ نعم → A2A (POST /a2a)
    └─ لا → تابع
        │
        هل تحتاج إلى سرد / تهيئة وكلاء البرمجة عبر CLI المثبّتين محليًا؟
        ├─ نعم → ACP (GET /api/acp/agents)
        └─ لا → استخدم /v1/chat/completions مباشرةً
```

## 1. A2A — من وكيل إلى وكيل

**المواصفة:** [A2A v0.3](https://a2a-protocol.org)
**نقطة نهاية OmniRoute:** `POST /a2a` ‏(JSON-RPC 2.0)
**بطاقة الوكيل:** `GET /.well-known/agent.json`

### متى تستخدمها

- بناء نظام متعدد الوكلاء يكون فيه OmniRoute أحد النظراء
- إتاحة إمكانات التوجيه الذكية في OmniRoute (`smart-routing`، و`quota-management`، وغيرها) للوكلاء في أطر عمل مثل Google ADK أو شبكات الوكلاء العامة
- تغليف OmniRoute خلف واجهة قياسية للاكتشاف والاستدعاء

### الأساليب

- `message/send` — إرسال رسالة وتلقّي استجابة متزامنة
- `message/stream` — الإرسال وتلقّي أحداث التقدم المتدفقة عبر SSE
- `tasks/get` — قراءة المهمة حسب المعرّف
- `tasks/cancel` — إلغاء مهمة قيد التشغيل

### المهارات المضمّنة (6)

- `smart-routing` — توجيه مطالبة عبر التركيبة المثلى
- `quota-management` — الإبلاغ عن حالة الحصة لكل مزوّد
- `provider-discovery` — سرد المزوّدين المثبّتين مع إمكاناتهم
- `cost-analysis` — تقدير تكلفة طلب/محادثة
- `health-report` — تجميع حالة قاطع الدارة/فترة التهدئة/الحظر لكل مزوّد
- `list-capabilities` — تعداد مهارات الوكيل المتاحة وبياناتها الوصفية

### شرح متعمق

راجع [A2A-SERVER.md](./A2A-SERVER.md) للاطلاع على تفاصيل النقل، وبنية بطاقة الوكيل، وتهيئة مدة بقاء المهمة (TTL)، والقالب المستخدم لإضافة مهارات جديدة.

## 2. ACP — سجل وكلاء CLI

**نقطة نهاية OmniRoute:** `GET /api/acp/agents`
**المصدر:** `src/lib/acp/{index,manager,registry}.ts`

### ماهيته

يمثّل ACP **مخزون OmniRoute المحلي لوكلاء CLI**. يكتشف أدوات CLI البرمجية المثبّتة على المضيف (Cursor وCline وClaude Code وCodex CLI وContinue وغيرها)، ويحدّد إصداراتها، ويعرضها في لوحة المعلومات كي يتمكن المستخدم من توجيه كل أداة CLI إلى OmniRoute.

هذا ليس بروتوكولًا خارجيًا — بل سجل داخلي يدعم واجهة مستخدم "أدوات CLI" وتتبع بصمات CLI (راجع [CLI-TOOLS.md](../reference/CLI-TOOLS.md)).

### ما يفعله

- يفحص المضيف بحثًا عن ملفات CLI التنفيذية المثبّتة (يستخدم `which` / `where` وفقًا لنظام التشغيل)
- يقرأ إصدار كل أداة CLI (يستدعي `<bin> --version`)
- يقبل اختياريًا وكلاء مخصّصين يعرّفهم المستخدم (مسار الملف التنفيذي + فحص الإصدار + وسيطات التشغيل)
- يحفظ الوكلاء المخصّصين في الإعدادات
- يعيد القائمة الموحّدة إلى لوحة المعلومات

### واجهة REST API

| نقطة النهاية      | الطريقة | الوصف                                                        | المصادقة  |
| ----------------- | ------- | ------------------------------------------------------------ | --------- |
| `/api/acp/agents` | GET     | عرض الوكلاء المكتشفين والمخصّصين (أعداد المثبّت/الإجمالي)    | مفتاح API |
| `/api/acp/agents` | POST    | إضافة/تحديث/إزالة وكيل مخصّص (مميّز الإجراء في النص الأساسي) | مفتاح API |

بنية النص الأساسي لطلب POST (`customAgentBodySchema` في `src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### حالات الاستخدام

- تعرض صفحة "أدوات CLI" في لوحة المعلومات الأدوات المثبّتة وتساعدك على توجيه كل منها إلى OmniRoute
- تتيح الوكلاء المخصّصة للمستخدمين المتقدمين تسجيل أدوات CLI داخلية/احتكارية لا يعرفها OmniRoute افتراضيًا
- تغذّي نتيجة الاكتشاف مصفوفة بصمات `cli-tools`

### متى يجب عدم استخدام ACP

- لا يقوم ACP _بتشغيل_ المهام. فهو يكتشف أدوات CLI ويهيّئها فقط. لاستدعاء أداة CLI فعليًا، شغّلها بنفسك باستخدام متغيرات البيئة التي يوفرها OmniRoute (`OPENAI_BASE_URL` و`OPENAI_API_KEY` وغيرهما).

## 3. الوكلاء السحابيون

**نقاط نهاية OmniRoute:** `/api/v1/agents/tasks/*` (دورة الحياة) + `/api/cloud/*` (البنية التحتية)
**المصدر:** `src/lib/cloudAgent/`

### ماهيتها

واجهة موحّدة للوكلاء البرمجيين السحابيين التابعين لجهات خارجية. ترسل مطالبة + عنوان URL للمستودع، فيوجّه OmniRoute الطلب إلى الوكيل السحابي المناسب، ويستعلم دوريًا عن الحالة، ثم يعيد النتائج.

### الوكلاء المدعومون (4، جميعهم مؤكّدون في `src/lib/cloudAgent/agents/`)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### دورة الحياة

```
POST /api/v1/agents/tasks
  → BaseAgent.createTask() لكل فئة وكيل
  → تبدأ الخدمة الخارجية العمل
  → يُنشأ صف للمهمة في قاعدة البيانات (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → مزامنة مؤجّلة للحالة من المزوّد
  → يعيد الحالة الحالية + الخطة + سجل النشاط
  ↓
POST /api/v1/agents/tasks/[id]   (الإجراء: "approve" | "message" | "cancel")
  → يعيد التوجيه إلى المزوّد (أو يضع علامة الإلغاء محليًا)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → إلغاء محلي
```

### المصادقة

⚠️ **تتطلب جميع نقاط النهاية `/api/v1/agents/tasks/*` مصادقة إدارية** (الالتزام `588a0333`). تتلقى الجهات المستدعية التي تستخدم Bearer فقط استجابة 401 منذ v3.8.0.

### تفاصيل معمّقة

راجع [CLOUD_AGENT.md](./CLOUD_AGENT.md) للاطلاع على عقد `CloudAgentBase`، وتفاصيل كل وكيل، وتفاصيل المخطط، ونقاط نهاية البنية التحتية لبيانات الاعتماد.

## مقارنة: A2A مقابل الوكلاء السحابيين

كلاهما يدعم «المهام طويلة الأمد»، لكن على مستويات مختلفة:

| الجانب             | A2A                                                                                   | الوكلاء السحابيون                    |
| ------------------ | ------------------------------------------------------------------------------------- | ------------------------------------ |
| المعيار            | Open A2A v0.3                                                                         | خاص بـ OmniRoute                     |
| مكان تنفيذ الحوسبة | داخل OmniRoute (يستخدم التركيبات المُهيأة)                                            | خارجي (خوادم Codex / Devin / Jules)  |
| مدة المهمة         | مدة البقاء الافتراضية 5 دقائق (قابلة للتهيئة في `TaskManager`)                        | من دقائق إلى ساعات                   |
| الوعي بالمستودع    | لا (يمرر المطالبات فقط)                                                               | نعم (عنوان URL للمستودع + الفرع)     |
| حالة الاستخدام     | التعاون بين الوكلاء، والتوجيه الذكي كخدمة                                             | تفويض «تنفيذ الميزة X في المستودع Y» |
| المصادقة           | `OMNIROUTE_API_KEY` اختياري لـ `/a2a`؛ ومصادقة الإدارة لمساعدات REST ضمن `/api/a2a/*` | مصادقة الإدارة دائمًا                |

## أمثلة التكامل

### اكتشاف إمكانات A2A في OmniRoute

```bash
curl http://localhost:20128/.well-known/agent.json
```

يعيد بطاقة الوكيل متضمنةً جميع المهارات الست ووسائل النقل والإصدار.

### استدعاء OmniRoute بصفته وكيل A2A

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "وجّه هذه المطالبة"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### عرض وكلاء CLI المثبتين عبر ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### إضافة وكيل CLI مخصص

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

### إرسال مهمة إلى وكيل سحابي

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "نفّذ الميزة X في المستودع Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### استطلاع حالة المهمة السحابية

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```

## متى تستخدم كل خيار

- **واجهة روبوت محادثة / مساعد برمجي** → `/v1/chat/completions` (متوافق مع OpenAI — وليس بروتوكول وكلاء)
- **التعاون بين عدة وكلاء** → A2A
- **عرض أدوات CLI المحلية في لوحة المعلومات** → ACP
- **تفويض مهام البرمجة طويلة الأمد إلى الخدمات السحابية** → الوكلاء السحابيون

```
                ┌─────────────────────┐
                │    نواة OmniRoute   │
                └─────────────────────┘
                  ↑       ↑        ↑
        ┌─────────┘       │        └─────────┐
        │                 │                  │
    ┌───────┐        ┌─────────┐       ┌────────────┐
    │  A2A  │        │   ACP   │       │ الوكلاء    │
    │ (/a2a)│        │ (/acp)  │       │ السحابيون  │

                                        Devin، Jules
```
