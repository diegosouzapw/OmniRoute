> **مصدر الحقيقة:** `src/lib/agentSkills/` (الكتالوج، والمولّد، والمحلّلات) + دليل `skills/` (ملفات SKILL.md)
> **آخر تحديث:** 2026-08-02 — v3.8.50

مهارات الوكلاء هي ملفات SKILL.md منظّمة تعلّم الوكلاء الخارجيين، وعملاء MCP، ومنسّقات A2A كيفية استخدام REST API وCLI الخاصين بـ OmniRoute. وعلى خلاف [مهارات Omni](./SKILLS.md) (وهي تعريفات لأدوات LLM تُنفَّذ داخل OmniRoute)، فإن مهارات الوكلاء هي _كتالوج توثيق_ — أي ملفات markdown ثابتة يمكن إدراجها مباشرةً في سياق الوكيل.

---

## نظرة عامة

يحتوي الكتالوج على **45 مهارة وكيل** (23 لـ REST API + 21 لـ CLI + سير عمل واحد للتهيئة). تتضمن كل مهارة:

- **معرّفًا أساسيًا** (`omni-auth`، و`cli-serve`، وما إلى ذلك)
- ملف **SKILL.md** في `skills/{id}/SKILL.md` يتضمن ترويسة YAML (`name`، و`description`) + محتوى markdown غنيًا
- **نقاط نهاية REST** (لمهارات API) أو **أوامر CLI فرعية** (لمهارات CLI) مشتقة من مواصفات OpenAPI وسجل CLI
- **عنوان URL أوليًا على GitHub** للجلب المباشر: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## نظرة عامة

...

...

...

<!-- skill:custom-start -->

`omni-mcp`، `omni-compression`، `cli-providers`، `cli-eval`، `omni-agents-a2a`، `omni-combos-routing`، `omni-auth`، `omni-resilience`، `omni-inference`، `cli-serve`.

## استكشاف REST API

| نقطة النهاية                 | الطريقة | الوصف                                                           | المصادقة |
| :--------------------------- | :------ | :-------------------------------------------------------------- | :------- |
| `/api/agent-skills`          | GET     | عرض الكتالوج (`?category=api\|cli\|config&area=<area>` اختياري) | لا توجد  |
| `/api/agent-skills/{id}`     | GET     | الحصول على البيانات الوصفية لمهارة واحدة                        | لا توجد  |
| `/api/agent-skills/{id}/raw` | GET     | جلب SKILL.md بصيغة `text/markdown`                              | لا توجد  |
| `/api/agent-skills/coverage` | GET     | إحصاءات التغطية (عدد ملفات SKILL.md الموجودة)                   | لا توجد  |
| `/api/agent-skills/generate` | POST    | تشغيل المولّد (dryRun/prune/onlyIds)                            | إدارية   |

مثال — عرض جميع مهارات API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

مثال — جلب ملف SKILL.md واحد:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## استكشاف A2A

تعيد مهارة A2A المسماة `list-capabilities` الكتالوج الكامل المكوّن من 45 مهارة في صورة جدول markdown. يمكن للمنسّقات الخارجية استدعاؤها عبر:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

راجع [A2A-SERVER.md](./A2A-SERVER.md) لمعرفة تفاصيل البروتوكول.

## كيفية استهلاك الوكلاء الخارجيين للمهارات

### 1. الاكتشاف عبر REST

```bash
# الحصول على الكتالوج الكامل
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# الحصول على SKILL.md لحقن السياق
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. الاكتشاف عبر MCP

```typescript
// في عميل MCP ضمن Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → مصفوفة من AgentSkill تحتوي على rawUrl لكل عنصر
```

### 3. الاكتشاف عبر A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table هو جدول markdown يحتوي على جميع معرّفات المهارات الـ 45 مع أعمدة rawUrl
```

### 4. الجلب المباشر للبيانات الخام من GitHub (لا يتطلب خادمًا)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## المولّد

يقرأ المولّد الكتالوج المنسّق + مواصفات OpenAPI + سجل CLI، ثم يكتب `skills/{id}/SKILL.md` لكل إدخال:

```bash
# معاينة (تشغيل تجريبي، من دون كتابة)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# إعادة توليد كاملة
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# إعادة توليد معرّفات محددة
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

استجابة المولّد هي `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
