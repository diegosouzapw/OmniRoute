ينظّم OmniRoute مزوّدي الخدمة المدعومين البالغ عددهم 352 مزوّدًا ضمن 3 مستويات اقتصادية. ينتقل كل
طلب عبر هذه المستويات بالترتيب حتى يعيد أحدها استجابة ناجحة — لتحصل
على أرخص استجابة قابلة للاستخدام من دون الحاجة إلى كتابة أي شيفرة احتياطية.

## المستوى 1 — الاشتراك

**مزوّدو الخدمة الذين تدفع لهم بالفعل.** يستخدم OmniRoute كل جزء من الحصة قبل
انتهاء صلاحيتها.

| مزوّد الخدمة                  | سبب الإدراج في المستوى 1                          |
| ----------------------------- | ------------------------------------------------- |
| Claude Code OAuth             | Anthropic Pro/Team — سعر ثابت، وغالبًا غير مستخدم |
| OpenAI Codex (اشتراك ChatGPT) | تتضمن Plus/Team حصة Codex                         |
| GitHub Copilot                | لكل مستخدم — تُعاد تهيئة الحصة شهريًا             |
| Cursor IDE                    | حصة خطة Pro                                       |
| Antigravity / Devin Desktop   | حصص مضمّنة                                        |

**الاستراتيجية**: وجّه كل طلب مناسب لإمكانات النموذج إلى هنا أولًا.
يتتبّع مراقب الحصص مواعيد إعادة التهيئة القريبة، وتعطي استراتيجية الدمج `reset-aware`
الأولوية وفقًا لذلك. لتوجيه الطلبات إلى المستوى 1 أولًا وعدم الانتقال
إلى المستويات المدفوعة إلا عند نفاد الحصة، استخدم المعرّف `auto/thrifty` — أو `auto/subscription`
للبقاء ضمن السعة المشمولة بالخطة والتوقف عند تعذر ذلك بدلًا من الانتقال إلى مستوى آخر. راجع
[التوجيه بالاشتراك أولًا](../routing/SUBSCRIPTION_LADDER.md).

## المستوى 2 — منخفض التكلفة

**مزوّدو خدمة بنظام الدفع لكل رمز بأقل من $1 لكل 1M رمز.** مخصّصون لأحمال العمل كبيرة الحجم
أو للاستخدام بعد بلوغ حصص المستوى 1 حدودها.

| مزوّد الخدمة             | السعر (الإدخال/الإخراج) | نقاط القوة                  |
| ------------------------ | ----------------------- | --------------------------- |
| DeepSeek V4 Pro          | $0.27 / $1.10 لكل 1M    | البرمجة، والاستدلال         |
| GLM-4.5                  | $0.60 / $2.20 لكل 1M    | السياق الطويل               |
| MiniMax M1               | $0.20 / $1.10 لكل 1M    | السرعة                      |
| Qwen Coder               | $0.30 / $1.20 لكل 1M    | البرمجة                     |
| OpenRouter (محسّن للسعر) | متغيّر                  | أكثر من 100 نموذج، ديناميكي |

**الاستراتيجية**: يختار الدمج `cost-optimized` النموذج الأقل تكلفة من حيث $/token الذي يستوفي
مرشح الإمكانات الخاص بالمهمة (الرؤية، ووضع JSON، والأدوات، والحد الأقصى للسياق).

## المستوى 3 — مجاني

**مزوّدو خدمة دون تكلفة** — مستويات مجانية، وبرامج أرصدة، وحصص OAuth يومية.

| مزوّد الخدمة     | الحصة / الأرصدة المجانية               |
| ---------------- | -------------------------------------- |
| Kiro AI          | مستوى Claude مجاني (استخدام عادل وسخي) |
| OpenCode Free    | دون مصادقة، وحدود معدّل سخية           |
| Qoder            | OAuth مجاني                            |
| Google Vertex AI | أرصدة بقيمة $300 للحسابات الجديدة      |
| Amazon Q         | مستوى مجاني لمستخدمي AWS               |
| Pollinations     | API عام ومفتوح                         |
| Cloudflare AI    | المستوى المجاني من Workers AI          |

**الاستراتيجية**: يوجّه الدمج `auto` المزوّد بحد أقصى للميزانية الطلبات إلى هنا عند فشل المستويين 1 و2
أو عند ضبط `useFreeOnly=true`. غالبًا ما تكون حدود المعدّل لدى مزوّدي الخدمة المجانيين
أكثر تقييدًا — ويعيد قاطع الدائرة إتاحتهم بعد انتهاء فترة التراجع.

## إعداد المستويات

لوحة المعلومات ← **المستويات** ← عيّن مزوّدي الخدمة. الإعدادات الافتراضية (من `tierDefaults.json`)
معقولة؛ عدّلها عندما تكون لديك اشتراكات محددة تريد منحها الأولوية أو مزوّدو خدمة تريد استبعادهم.

يراعي نظام التقييم ذي العوامل الـ16 في Auto-Combo المستوى أيضًا. راجع
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## القياس عن بُعد

تعرض لوحة المعلومات ← **الاستخدام** الرموز المستهلكة يوميًا لكل مستوى. استخدم ذلك من أجل:

- التأكد من استخدام المستوى 1 بالكامل (وإلا فأنت تهدر قيمة الاشتراك)
- تحديد نماذج المستوى 2 الأكثر اختيارًا (وحصرها في 1-2)
- التحقق من أن المستوى 3 يوفّر المال في أحمال عمل الاختبار/الاستكشاف

## الأنماط الشائعة

### حمل عمل مجاني بالكامل

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

يوجّه الطلبات بقوة نحو المستوى 3؛ ولا يستخدم المستوى 2 إلا إذا كان المستوى 3 غير متاح.

### الاشتراك أولًا مع انتقال احتياطي منخفض التكلفة

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

قائمة مرتبة صراحةً تتوافق مع المستوى 1 ← المستوى 2 ← المستوى 3.
