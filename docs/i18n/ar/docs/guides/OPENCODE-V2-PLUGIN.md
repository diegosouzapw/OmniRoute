تضع الحزمة `@omniroute/opencode-plugin-v2` كتالوج OmniRoute بالكامل — النماذج، والتركيبات، والتركيبات التلقائية — في منتقي النماذج في OpenCode v2، مع أسماء العرض، والتسعير، وحصص الفئة المجانية.

وهي حزمة منفصلة عن `@omniroute/opencode-plugin` لأن OpenCode v1 وv2 يحمّلان المكونات الإضافية من خلال عقود مختلفة. اختر الحزمة المطابقة للإصدار الرئيسي من OpenCode لديك؛ فلا شيء مشترك بينهما، لذا لا تفرض ترقية إحداهما ترقية الأخرى مطلقًا.

## المتطلبات

- OpenCode v2.
- بوابة OmniRoute يمكن الوصول إليها (`http://localhost:20128` افتراضيًا).
- Node.js 22 أو 24.

## التثبيت

أضف المكون الإضافي إلى `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

ستظهر النماذج بعد ذلك بالصيغة `omniroute/<provider>/<model>`؛ وتحدد `providerId` هذه البادئة ومعرّف التكامل الذي يخزّن OpenCode بيانات الاعتماد تحته.

## بيانات الاعتماد

يبحث المكون الإضافي عن مفتاح البوابة في ثلاثة مواضع، بالترتيب التالي:

1. **بيانات الاعتماد التي ربطتها في OpenCode.** يسجّل المكون الإضافي تكاملًا، بحيث يمكن لمسار المصادقة الخاص بـ OpenCode تخزين المفتاح. لا يُكتب أي شيء في `opencode.json` — وهذا هو الخيار المفضّل.
2. `apiKey` ضمن خيارات المكون الإضافي، لتجاوز خاص بكل مشروع. يؤدي ذلك إلى وضع المفتاح في ملف قد تقوم بإيداعه في مستودعك.
3. `OMNIROUTE_API_KEY` في البيئة.

في حال عدم توفر أي من هذه الخيارات الثلاثة، يكون الكتالوج فارغًا ويُبلغ المكون الإضافي بذلك مرة واحدة عند بدء التشغيل، بدلًا من ترك منتقي فارغ دون أي تنبيه.

### رمز الإدارة هو مفتاح مختلف

تأتي التركيبات، وحالة المزوّد، والإثراء (أسماء العرض، والتسعير، وحصص الفئة المجانية) من نقاط النهاية `/api/*` الخاصة بالبوابة، والتي تحميها معظم عمليات النشر برمز **إدارة** بدلًا من مفتاح الاستدلال:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<رمز قراءة الإدارة>"
}
```

إذا لم تُضبط `managementReadToken`، فستعود إلى استخدام `apiKey`. عندما ترفض البوابة هذا الخيار الاحتياطي، يظل الكتالوج منشورًا، ولكن بمعرّفات النماذج الخام بدلًا من أسماء العرض، ومن دون إزالة التكرار للأسماء المستعارة القياسية، ومن دون تسعير أو تركيبات. يحذّر المكون الإضافي مرة واحدة لكل نقطة نهاية عند حدوث ذلك، مع ذكر نقطة النهاية وما فُقد — بحيث لا يكون سبب تراجع إمكانات المنتقي غامضًا أبدًا.

## الخيارات

| المفتاح                          | القيمة الافتراضية                                | ملاحظات                                                                                                |
| -------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| `providerId`                     | `"omniroute"`                                    | معرّف المزوّد، ومعرّف التكامل، والبادئة التي تظهر النماذج تحتها                                        |
| `baseURL`                        | مطلوب                                            | جذر البوابة، مع دعم `http(s)` فقط؛ وتُضاف اللاحقة `/v1` عند الحاجة                                     |
| `apiKey`                         | بيانات الاعتماد المرتبطة، ثم `OMNIROUTE_API_KEY` | مفتاح المحادثة لـ `/v1/*`                                                                              |
| `managementReadToken`            | يعود إلى `apiKey`                                | مفتاح `/api/*` — وعادةً **لا** يكون المفتاح نفسه                                                       |
| `displayName`                    | `"OmniRoute"`                                    | اسم المزوّد في المنتقي                                                                                 |
| `timeoutMs`                      | `10000`                                          | مهلة الجلب لكل نقطة نهاية (تستخدم التركيبات التلقائية 5 ثوانٍ)                                         |
| `modelCacheTtlMs`                | `300000`                                         | مدة صلاحية ذاكرة التخزين المؤقت للكتالوج؛ وتُسرّع لقطة محفوظة على القرص عمليات البدء البارد            |
| `timeouts`                       | يعود إلى `timeoutMs`                             | المهل لكل نقطة نهاية بالمللي ثانية: `models`، و`combos`، و`autoCombos`، و`enrichment`                  |
| `enrichment`                     | `true`                                           | جلب الأسماء، والتسعير، وحصص الفئة المجانية                                                             |
| `providerTag`                    | `true`                                           | إضافة اسم المزوّد الأصلي الذي يوجّه إليه كبادئة لاسم العرض                                             |
| `usableOnly`                     | `false`                                          | الاحتفاظ فقط بالمزوّدين الذين تفيد البوابة بأنه تم توفيرهم                                             |
| `visibleModels` / `hiddenModels` | `[]`                                             | قوائم سماح بالتطابق التام أو حسب اللاحقة؛ ويكون للمنع الأولوية                                         |
| `geminiSanitization`             | `true`                                           | إزالة كلمات JSON-Schema المفتاحية التي يرفضها Gemini من مخططات الأدوات (تُمرّر أدوات `$ref` دون تعديل) |
| `apiFormat.allowAnthropic`       | `false`                                          | توجيه المعرّفات المدرجة في قائمة السماح عبر كتلة Anthropic API                                         |
| `apiFormat.anthropicModels`      | `[]`                                             | معرّفات النماذج الكاملة الموجّهة إلى Anthropic                                                         |
| `logLevel` / `startupDebug`      | `warn` / `false`                                 | مستوى تفصيل السجل                                                                                      |

## كيف يظل الكتالوج محدَّثًا

يُجلب الكتالوج عند الحاجة ويُخزَّن مؤقتًا لمدة `modelCacheTtlMs`، كما تُبقي لقطة محفوظة على القرص
آخر كتالوج معروف متاحًا عندما يتعذر الوصول إلى البوابة — فلا يكلفك الانقطاع سوى
حداثة البيانات. تُنشر النماذج والتركيبات فور وصولها؛ وتُدمج التركيبات التلقائية وقائمة موفري الخدمة
وطبقة الإثراء عند وصولها، بحيث لا تستطيع نقطة نهاية بطيئة واحدة تعطيل
أداة الاختيار بأكملها.

تتضمن الأسماء ما تعرفه البوابة: موفر الخدمة الرئيسي الذي يُوجَّه إليه النموذج، وعلامة `[Free]`
والميزانية المصاحبة لها — وبذلك يظل اتصالان يبيعان النموذج نفسه
قابلين للتمييز. عطّل البادئة باستخدام `"providerTag": false`.

لا يوجد أمر تحديث يدوي: فأوامر OpenCode v2 هي قوالب مطالبات وليست استدعاءات رد،
لذلك لا يمكن لإضافة توفير أمر من هذا النوع. تتبع عمليات التحديث مدة TTL؛ ولا يُطلب من المضيف إعادة التحميل إلا عندما
يتغير الكتالوج أو طبقة التراكب فعليًا، وليس مرةً عند كل تحديث.

## استدعاء الأدوات على Gemini

يرفض Gemini الطلب بالكامل إذا كانت تعريفات أدواته تحتوي على `$schema` أو
`additionalProperties`، ويردّ بـ `400 INVALID_ARGUMENT`. تزيل الإضافة هاتين الكلمتين المفتاحيتين من
مخططات الأدوات المتجهة إلى نموذج Gemini لدى موفر الخدمة هذا، وتترك جميع الطلبات الأخرى دون تغيير.
تُمرَّر الأداة التي تحتوي على `$ref` دون تغيير بدلًا من إزالة هذه العناصر منها، لأن إزالة
المرجع ستوسّع المخطط ليصبح «قبول أي شيء».
اضبط `"geminiSanitization": false` لتعطيل ذلك.

## استكشاف الأخطاء وإصلاحها

| العَرَض                                     | السبب                                                                                                          |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| لا تعرض أداة الاختيار أي نموذج OmniRoute    | لم يتم العثور على أي مفتاح (تحقق من تحذير بدء التشغيل)، أو يتعذر الوصول إلى البوابة                            |
| معرّفات نماذج أولية، ولا تركيبات، ولا تسعير | رفضت نقاط نهاية الإدارة الرمز المميز — اضبط `managementReadToken`                                              |
| جلسة مثبّتة على `opencode-<id>/…`           | نشرت إضافة v1 المعرّف `opencode-<id>`؛ بينما تنشر v2 المعرّف `<id>` مجردًا، لذا أعد تحديد النموذج ضمن `<id>/…` |
