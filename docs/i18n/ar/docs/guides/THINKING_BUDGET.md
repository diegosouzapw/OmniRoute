> **لوحة التحكم:** الإعدادات → **الذكاء الاصطناعي** → ميزانية التفكير  
> **واجهة API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **المصدر:** `open-sse/services/thinkingBudget.ts`

تتحكم ميزانية التفكير فيما إذا كان OmniRoute **يعيد كتابة معاملات التفكير/الاستدلال الخاصة بالعميل** في أثناء تمرير الطلبات إلى المزوّدين. وهي **لا** تُفعّل أو تُعطّل الضغط أو التوجيه أو ذاكرة التخزين المؤقت للمطالبات.

## الأوضاع

| الوضع                         | ما يفعله OmniRoute                                                                                                                | متى يُستخدم                                                                                                                                      |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`passthrough`** (الافتراضي) | يترك حقول العميل كما هي (`reasoning` و`reasoning_effort` و`thinking` الخاص بـ Claude و`thinking_config` الخاص بـ Gemini، وغيرها). | **Codex / Desktop / أي عميل ينبغي أن يتحكم في مستوى الجهد وملخصات الاستدلال.** مطلوب لإظهار لوحات التفكير عندما يطلب العميل `reasoning.summary`. |
| **`auto`**                    | **يزيل جميع** حقول التفكير/الاستدلال من نص الطلب قبل إرساله إلى المنبع.                                                           | فقط عندما تريد عمدًا أن يحدد **المزوّد** القيم الافتراضية ولا تحتاج إلى تفكير يتحكم فيه العميل. لا يعني **«إظهار التفكير تلقائيًا»**.            |
| **`custom`**                  | يستبدل إعدادات كل طلب بميزانية ثابتة لرموز التفكير.                                                                               | لوضع حد أقصى صارم لرموز التفكير في جميع حركات المرور.                                                                                            |
| **`adaptive`**                | يضبط الميزانية انطلاقًا من مستوى جهد أساسي باستخدام عدد الرسائل والأدوات وطول المطالبة.                                           | للتحكم المرن في الرموز من دون تجاهل نية العميل بالكامل.                                                                                          |

### ما يزيله `auto`

عندما يكون الوضع `auto`، تحذف `stripThinkingConfig()`، من بين أمور أخرى:

- OpenAI / Responses: ‏`reasoning` و`reasoning_effort`
- Claude: ‏`thinking`، وكذلك `output_config.effort` عند وجوده
- Gemini: ‏`generationConfig.thinking_config` / `thinkingConfig`

إذا أرسل عميل (مثل Codex Desktop) القيمة `reasoning: { effort: "ultra", summary: "detailed" }`، فإن الوضع **`auto` يحذف هذا الكائن**. قد يستمر المنبع في احتساب بعض رموز الاستدلال، لكنه غالبًا ما يعيد عناصر استدلال **فارغة أو مشفّرة فقط**، ولذلك لا تعرض واجهة المستخدم تدفقًا مفيدًا للتفكير.

## ما **لا** تمثله هذه الميزة

| الميزة                                          | العلاقة                                                                                                                              |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **الضغط** (Caveman وRTK والمكدّس، …)            | مسار معالجة منفصل. يعمل في جميع أوضاع ميزانية التفكير.                                                                               |
| **ذاكرة التخزين المؤقت للمطالبات / الدلالات**   | منفصلة. لا تتأثر بوضع ميزانية التفكير.                                                                                               |
| **التوجيه المركّب / البدائل الاحتياطية**        | منفصلة. لا تتأثر.                                                                                                                    |
| **حدود رموز مفاتيح API / ميزانيات التكلفة**     | منفصلة. لا تتأثر.                                                                                                                    |
| **ذاكرة التخزين المؤقت لإعادة تشغيل الاستدلال** | تعيد الحقن عبر جولات متعددة للمزوّدين الصارمين (DeepSeek وKimi وQwen-thinking، …). وهي ليست مماثلة لميزة «إظهار التفكير» في Desktop. |
| **فك تشفير `encrypted_content`**                | **مستحيل.** كتل الاستدلال الخاصة في OpenAI/Codex مبهمة. لا يفك OmniRoute تشفيرها مطلقًا (#7095 / #7176 / #7304).                     |

## إظهار التفكير (عملاء Codex / Responses)

لكي يعرض العميل نص التفكير، تحتاج إلى **كل** ما يلي:

1. وضع ميزانية التفكير = **`passthrough`** (أو `custom`/`adaptive` مع إبقاء طلبات الملخص سليمة بما يكفي للمسار الذي تستخدمه).
2. أن يطلب العميل ملخصًا، مثل Codex ‏`model_reasoning_summary = "detailed"` / ‏`auto` (وليس `none`).
3. أن يبث موفّر الخدمة فعليًا `response.reasoning_summary_text.*` (أو أن يتضمن العنصر قيمة غير فارغة في `reasoning.summary`).

إذا لم تحصل إلا على «تفكير خاص مشفّر»، فهذا يعني أحد الأمرين:

- كان الوضع هو **`auto`** (تمت إزالة طلب العميل)، أو
- أعاد موفّر الخدمة `encrypted_content` من دون نص ملخص (قيد لدى الموفّر؛ لا يستطيع OmniRoute سوى عرض عنصر نائب، وليس النص الصريح).

## أمثلة API

```bash
# قراءة
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# الإعداد الموصى به لإظهار التفكير في Codex / Desktop
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

المخطط (`updateThinkingBudgetSchema`): ‏`mode` ∈ `passthrough|auto|custom|adaptive`؛ والحقول الاختيارية هي `customBudget` و`effortLevel` و`baseBudget` و`complexityMultiplier`.

### الاستمرارية / إعادة التشغيل

تُخزَّن القيمة تحت مفتاح الإعدادات `thinkingBudget` وتُحمَّل عند بدء العملية (`hydrateThinkingBudgetConfig`). بعد تغييرها عبر قاعدة البيانات أو بعض المسارات التي لا تستخدم API، **أعِد تشغيل عملية OmniRoute** حتى تتطابق النسخة المفردة في الذاكرة مع القرص.

## قائمة تحقق للمشغّل

- [ ] مستخدمو Codex / Desktop: الوضع = **passthrough**
- [ ] أبقِ الضغط مفعّلًا إذا كنت تريد توفير الرموز في **الرسائل**، وليس عبر حذف التفكير
- [ ] لا تتوقع من `auto` أن «يعرض مزيدًا من التفكير»
- [ ] الملخصات المشفّرة فقط هي سلوك خاص **بموفّر الخدمة**؛ ولا يستطيع `passthrough` فك تشفيرها
