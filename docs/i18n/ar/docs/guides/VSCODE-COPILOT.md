يضع **OmniCopilot** كل نموذج يقدّمه OmniRoute لديك ضمن منتقي النماذج _الأصلي_ في GitHub Copilot Chat.
لا يوجد شريط جانبي ثانٍ، ولا واجهة دردشة منفصلة — يظل وضع الوكيل في Copilot، واستدعاء الأدوات،
وخوادم MCP، والتعليمات المخصصة، جميعها قيد العمل، ولكن باستخدام النموذج الذي تختاره.

> **لا يلزم اشتراك Copilot.** منذ VS Code 1.122، يعمل موفّر نماذج اللغة
> من دون تسجيل الدخول إلى GitHub ومن دون أي خطة Copilot. تظل الإكمالات المضمنة
> والميزات المستندة إلى التضمينات خارج واجهة API الخاصة بالموفّر، ولا تزال تتطلب Copilot.

## الإعداد

1. **شغّل OmniRoute** — `npm install -g omniroute && omniroute` (لوحة المعلومات على `http://localhost:20128`).
2. **ثبّت الامتداد** — ابحث عن "OmniRoute" في عرض الامتدادات.
3. **اختر نموذجًا** — Copilot Chat ← منتقي النماذج ← **إدارة النماذج…** ← **OmniRoute**، ثم حدّد
   ما تريده.

لا حاجة إلى ضبط أي إعدادات عندما يعمل OmniRoute على المنفذ الافتراضي. بالنسبة إلى مثيل بعيد، افتح
**أيقونة OmniRoute في شريط النشاط** (أو شغّل `OmniRoute: Manage Connection`) واضبط:

- **عنوان URL للخادم** — جذر الخادم، مثل `http://192.168.0.15:20128`. تُلحَق اللاحقة `/v1`
  بواسطة الامتداد؛ لا تُدرجها.
- **مفتاح API** — فقط عندما يضبط الخادم `REQUIRE_API_KEY`. يُخزَّن في سلسلة مفاتيح نظام التشغيل عبر
  VS Code SecretStorage، وليس في `settings.json` أبدًا.

## ما سيعرضه المنتقي

لا يعرض الامتداد حمولة `GET /v1/models` الأولية — بل يعيد تشكيلها، ولذلك يكون العدد الذي
تراه أقل من حجم الكتالوج لسببين مقصودين.

### يطلب معرّفًا واحدًا لكل نموذج

الوضع الافتراضي لـ `MODELS_CATALOG_PREFIX_MODE` هو **`dual`**، ما يعلن عن كل نموذج مرتين — مرة
باستخدام بادئة الاسم المستعار المختصرة، ومرة باستخدام بادئة الموفّر القياسية — بحيث تظل إعدادات
العملاء الأقدم قادرة على تحليل الصيغتين:

```
cc/claude-sonnet-4-6        ← بادئة الاسم المستعار
claude/claude-sonnet-4-6    ← البادئة القياسية، النموذج نفسه
```

يطلب الامتداد **`GET /v1/models?prefix=alias`** بحيث يصل معرّف واحد لكل نموذج، من دون
تغيير الإعداد العام للخادم لدى عملائك الآخرين. في مثيل مرجعي، أدى ذلك إلى تقليص
**2345 إدخالًا إلى 1396 — أي 949 نسخة مكررة، من دون فقدان أي نموذج.**

إذا كنت تفضّل معالجة ذلك على مستوى الخادم _لكل_ عميل، فاضبط علامة الميزة
`MODELS_CATALOG_PREFIX_MODE` على `alias` في لوحة المعلومات. راجع
[API_REFERENCE ← البادئة](../reference/API_REFERENCE.md#model-id-prefixes-prefix) للاطلاع على
معامل الاستعلام والجدول الخاص بكل وضع.

### يخفي النماذج التي لا يمكنها إجراء الدردشة

يسرد الكتالوج أيضًا نماذج الصور والفيديو والصوت وإعادة الترتيب والتضمين والإشراف. وهذه
تُرفض على أي حال عند إرسال طلب دردشة:

```
HTTP 400 — النموذج '<id>' هو نموذج لتوليد الصور ولا يمكن استخدامه على
/v1/chat/completions. استخدم POST /v1/images/generations بدلًا منه.
```

ولذلك تُرشَّح استنادًا إلى حقل `type` الخاص بها قبل وصولها إلى المنتقي. **يتم الاحتفاظ بنماذج
Responses-API** — يعلن كل إدخال Codex / GPT-5.x عن `supported_endpoints: ["responses"]`،
ويحوّل OmniRoute هذه الطلبات لاستخدام `/v1/chat/completions`، لذا فهي قابلة للاستخدام بشكل كامل.

### الموفّرون الذين لم تضبطهم مطلقًا

يسرد الكتالوج نماذج الموفّرين الذين لديهم **اتصال نشط** _بالإضافة إلى_ كل موفّري **noAuth**
— وهم الموفّرون الذين لا يتطلبون مفتاحًا ويشكّلون جزءًا كبيرًا من الفئة المجانية. هذا مقصود. لإخفائهم،
أضفهم إلى `blockedProviders` في إعدادات لوحة المعلومات؛ لا يتغير أي شيء في
الامتداد.

## لوحة المعلومات داخل علامة تبويب في VS Code

يعرض `omnicopilot.dashboardOpen: "editor"` لوحة معلومات OmniRoute في علامة تبويب للمحرر عبر
Simple Browser بدلًا من متصفح خارجي. التضمين **يتطلب تفعيلًا صريحًا على الخادم** من خلال
`DASHBOARD_ALLOW_EMBED=vscode`، ما يؤدي إلى تقديم صفحات HTML باستخدام
`frame-ancestors 'self' vscode-webview:` بدلًا من الإعداد الافتراضي `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. وتحتفظ واجهات API (`/api`، و`/v1`، و`/v1beta`، و`/a2a`، و`/healthz`)
بالترويسات الصارمة في كلتا الحالتين.

> ⚠️ **هذه علامة خاصة بوقت البناء، وليست بوقت التشغيل.** يترجم Next.js الدالة `headers()` إلى بيان
> المسارات، لذا يقرأ `next.config.mjs` المتغير أثناء بناء الحزمة
> (`next.config.mjs` → `resolveDashboardEmbedMode`، و`scripts/build/dashboardEmbed.mjs`).
> لن يؤدي تصديره قبل تشغيل خادم مبني مسبقًا إلى تغيير أي شيء — فالترويسات مضمّنة في البناء.

```bash
# يجب أن يكون المتغير موجودًا في أمر البناء
DASHBOARD_ALLOW_EMBED=vscode npm run build        # أو npm run build:release
npm start
```

| كيفية التثبيت              | هل يمكنك تمكين التضمين؟                                                                                                            |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| من المصدر                  | ✅ اضبط المتغير في أمر البناء، كما هو موضح أعلاه                                                                                   |
| `npm install -g omniroute` | ❌ تتضمن الحزمة المنشورة حزمةً مبنية مسبقًا — ابنِ من المصدر بدلًا من ذلك                                                          |
| صورة Docker                | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — صورة Docker Hub المبنية مسبقًا غير مهيأة للتضمين |

من دون بناء مهيأ للتضمين، سترفض الصفحة العرض داخل إطار، وستكتشف الإضافة ذلك من
ترويسات الاستجابة وتعود إلى استخدام المتصفح الخارجي — لن يتعطل شيء، وستعرض إشعارًا بذلك مرة واحدة.
راجع [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) والمشكلة
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## تهيئة أدواتك الأخرى من داخل VS Code

يشغّل **`OmniRoute: Configure Coding CLI`** واجهة `omniroute` CLI لكتابة ملفات تعريف جاهزة للاستخدام
مع Codex CLI، وClaude Code، وCline، وContinue، وCursor، وAider، وOpenCode، وGoose، وCrush، وQwen Code،
وKilo، وRoo — وهي الإعدادات نفسها الموضحة في
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). يُمرَّر مفتاح API إلى CLI عبر متغير البيئة
`OMNIROUTE_API_KEY`، وليس عبر سطر الأوامر مطلقًا.

## استكشاف الأخطاء وإصلاحها

| العَرَض                                         | السبب / الحل                                                                                                                                                                                                                                        |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| لا توجد نماذج OmniRoute في أداة الاختيار        | يتعذر الوصول إلى الخادم. تتحول نقطة شريط الحالة إلى اللون الرمادي؛ شغّل `OmniRoute: Check Connection`. تتم عملية الاكتشاف بصمت حسب التصميم، ولا تضيف أي نماذج بدلًا من عرض مطالبة.                                                                  |
| يظهر كل نموذج مرتين                             | أنت تستخدم إصدارًا من OmniCopilot أقدم من 1.0.1 — حدّثه. تطلب الإضافة الآن `?prefix=alias`.                                                                                                                                                         |
| كان أحد نماذج الصور/الصوت مدرجًا ثم اختفى       | هذا مقصود منذ الإصدار 1.0.1 — إذ لم يكن بإمكانه مطلقًا الرد على طلب محادثة.                                                                                                                                                                         |
| اللوحة مفقودة من شريط النشاط                    | ينقل VS Code حاويات العرض الإضافية إلى قائمة التجاوز **"…"** أسفل شريط النشاط، وتظل الحاوية المخفية بالنقر بزر الماوس الأيمن مخفية. انقر بزر الماوس الأيمن على شريط النشاط → فعّل **OmniRoute**، أو افتحها باستخدام `OmniRoute: Manage Connection`. |
| تفتح لوحة المعلومات في المتصفح رغم وضع `editor` | لم يتم **بناء** الخادم باستخدام `DASHBOARD_ALLOW_EMBED=vscode` (راجع ما سبق) — ضبطه عند بدء تشغيل نسخة مبنية مسبقًا لا يغيّر شيئًا. والرجوع إلى المتصفح الخارجي سلوك مقصود.                                                                         |
| قائمة النماذج قديمة بعد تغيير المزوّدين         | استخدم `OmniRoute: Refresh Models`، أو رابط ↻ في اللوحة.                                                                                                                                                                                            |
