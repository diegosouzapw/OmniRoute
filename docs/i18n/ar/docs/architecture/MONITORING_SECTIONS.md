## التنقل عالي المستوى

يحتوي الشريط الجانبي للوحة المعلومات (بعد المجموعة B) على الأقسام ذات المستوى الأعلى التالية بالترتيب:

```
الرئيسية
المزوّدون
التركيبات
مفاتيح API
الإعدادات
التحليلات
التكاليف          ← جديد (المجموعة B، الخطة 16)
المراقبة           ← أُعيد تنظيمه (المجموعة B، الخطة 16)
...
```

## قسم التكاليف (جديد، المستوى 1)

بادئة المسار: `/dashboard/costs/`

| العنصر       | عنوان URL                            | الوصف                                             |
| ------------ | ------------------------------------ | ------------------------------------------------- |
| نظرة عامة    | `/dashboard/costs`                   | لوحة معلومات مجمّعة للتكاليف (نُقلت من التحليلات) |
| التسعير      | `/dashboard/costs/pricing`           | جدول تسعير لكل نموذج                              |
| الميزانية    | `/dashboard/costs/budget`            | حدود الميزانية + التنبيهات                        |
| مشاركة الحصة | `/dashboard/costs/quota-share`       | مجموعات مشاركة الحصص + الاستخدام                  |
| إعداد الخطة  | `/dashboard/costs/quota-share/plans` | تجاوزات الخطط لكل مزوّد                           |

**السبب**: كان التسعير والميزانية ومشاركة الحصص موجودة سابقًا ضمن
`المراقبة > معلمات التكاليف`. يؤدي نقلها إلى قسم مستقل ذي مستوى أعلى
إلى تسهيل العثور عليها دون الحاجة إلى التنقل عبر أدوات قابلية الملاحظة.

## قسم المراقبة (أُعيد تنظيمه)

يحتوي قسم المراقبة الآن على **النشاط في الأعلى** متبوعًا بـ **3 مجموعات فرعية**:

```
المراقبة
├── النشاط                ← موجز الخط الزمني (عنصر من المستوى الأعلى)
├── مجموعة السجلات
│   ├── السجلات (الكل)
│   ├── سجلات الوكيل
│   └── سجلات وحدة التحكم
├── مجموعة التدقيق
│   ├── سجل التدقيق
│   ├── تدقيق MCP
│   └── تدقيق A2A
└── مجموعة النظام
    ├── السلامة
    └── وقت التشغيل
```

### ما الذي تغيّر مقارنة بالبنية القديمة

| قبل                                                                                              | بعد                                         |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| النشاط = علامة تبويب داخل السجلات تعرض سجل التدقيق                                               | النشاط = موجز مستقل (`/dashboard/activity`) |
| مجموعة معلمات التكاليف ضمن المراقبة                                                              | نُقلت إلى قسم التكاليف                      |
| قائمة مسطحة: السجلات، النشاط (السجلات)، التدقيق، السلامة، وقت التشغيل، التسعير، الميزانية، الحصة | 3 مجموعات منظّمة + قسم مستقل للتكاليف       |

## النشاط مقابل سجل التدقيق

أصبح الاثنان متميزين الآن:

| البُعد                  | النشاط (`/dashboard/activity`)                          | سجل التدقيق (`/dashboard/audit`)               |
| ----------------------- | ------------------------------------------------------- | ---------------------------------------------- |
| **الغرض**               | موجز أحداث موجّه للمستخدم («ما الذي حدث مؤخرًا»)        | سجل الامتثال / الأمان                          |
| **مصدر البيانات**       | `GET /api/compliance/audit-log?level=high`              | `GET /api/compliance/audit-log?level=all`      |
| **التنسيق**             | خط زمني مجمّع حسب اليوم، مع أفعال وأيقونات سهلة القراءة | جدول كثيف مقسّم إلى صفحات، 50 عنصرًا/صفحة      |
| **عوامل التصفية**       | فئة نوع الحدث                                           | الإجراء، الخطورة، الجهة الفاعلة، النطاق الزمني |
| **التصدير**             | غير متاح                                                | تصدير JSON                                     |
| **تصفية الجهة الفاعلة** | لا ينطبق                                                | قابل للتصفية حسب الجهة الفاعلة                 |
| **الأحداث المعروضة**    | الإجراءات عالية المستوى فقط (قائمة سماح)                | جميع أحداث التدقيق                             |

### قائمة السماح للإجراءات عالية المستوى

مُعرّفة في `src/lib/audit/highLevelActions.ts`. وهي تتحكم في الأحداث التي تظهر في
موجز النشاط. تتضمن قائمة السماح ما يلي:

- أحداث إضافة المزوّد وإزالته واختباره
- إنشاء التركيبات وتحديثها وحذفها
- دورة حياة مفتاح API (الإنشاء، الإبطال، التدوير)
- بلوغ حد الميزانية
- تسجيل الدخول إلى المصادقة/تسجيل الخروج منها
- إنشاء جلسة وكيل سحابي
- تسجيل أداة MCP
- إنشاء خطاف ويب/حذفه
- تغييرات مجموعة/خطة الحصص (إجراءات `quota.*`، المجموعة B)
- أحداث المنصة (التحديث، النشر)
- تثبيت المهارة/إزالتها

لا تظهر الأحداث غير الموجودة في هذه القائمة إلا في سجل التدقيق.

### إضافة إجراء جديد عالي المستوى

حرّر `src/lib/audit/highLevelActions.ts` وأضف سلسلة الإجراء إلى
`HIGH_LEVEL_ACTIONS`. يتطلب هذا طلب دمج (PR) (القائمة عبارة عن كود، ولا يمكن إعدادها من خلال قاعدة البيانات).
يمكن إضافة الأيقونة المقابلة إلى `src/lib/audit/activityIcons.ts`.

## إعادة التوجيه: `/dashboard/logs/activity`

يُعاد توجيه المسار القديم `/dashboard/logs/activity` بشكل دائم (HTTP 308) إلى
`/dashboard/activity` عبر `permanentRedirect()` في
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

يُحتفظ بمعرّف الشريط الجانبي القديم `logs-activity` في `HIDEABLE_SIDEBAR_ITEM_IDS`
(لكنه أُزيل من `SIDEBAR_DEFINITIONS`) لتجنب تعطيل الإعدادات المسبقة للمستخدمين التي
تشير إلى المعرّف القديم.

## التدويل

مساحات الأسماء التي أضافتها المجموعة B:

| مفتاح مساحة الاسم       | ما يغطيه                                                                 |
| ----------------------- | ------------------------------------------------------------------------ |
| `sidebar.costsSection`  | تسمية قسم التكاليف                                                       |
| `sidebar.activity`      | عنصر النشاط في الشريط الجانبي                                            |
| `sidebar.logsGroup`     | تسمية مجموعة السجلات الفرعية                                             |
| `sidebar.systemGroup`   | تسمية مجموعة النظام الفرعية                                              |
| `sidebar.costsOverview` | عنصر نظرة عامة على التكاليف                                              |
| `activity.*`            | جميع سلاسل صفحة النشاط (العنوان، الأفعال، عوامل التصفية، الحالة الفارغة) |

اللغات المحلية المرجعية: `pt-BR` و`en`. تستخدم جميع اللغات المحلية الأربعين الأخرى
الإنجليزية كلغة احتياطية عبر آلية الرجوع في `next-intl` (المُعدّة في `src/i18n/config.ts`).
