يأتي OmniRoute مزودًا بمجموعة منتقاة من الوكلاء المجانيين في جدول `free_proxies`،
تتم مزامنتها من مزودين خارجيين (1proxy وproxifly وiplocate وwebshare). تعرض
لوحة المعلومات هؤلاء ضمن **الإعدادات ← الوكلاء المجانيون**. يتناول هذا المستند
التصفية والترتيب والعدّ من جانب الخادم، بالإضافة إلى الإبلاغ عن أخطاء المزامنة
التي يتيحها مسار القائمة.

## مسار القائمة — `GET /api/settings/free-proxies`

يعيد جزءًا مصفّى ومرتبًا ومقسّمًا إلى صفحات، بالإضافة إلى العدد الإجمالي. تتم
التصفية والعدّ في SQL، بحيث يمكن لواجهة المستخدم عرض الإجمالي الفعلي (مثل `الإجمالي: 0`)
من دون تحميل كل صف في الذاكرة.

### معلمات الاستعلام

| المعلمة           | النوع                              | القيمة الافتراضية | المعنى                                                                                                                       |
| ----------------- | ---------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `search`          | سلسلة نصية                         | `""`              | مطابقة `LIKE` حساسة لحالة الأحرف على عمود المضيف (والمصدر).                                                                  |
| `protocol`        | سلسلة نصية                         | `""`              | عامل تصفية `type`:‏ `http` / `https` / `socks4` / `socks5`. القيمة الفارغة = الكل.                                           |
| `country`         | سلسلة نصية                         | `""`              | عامل تصفية `countryCode` ‏(ISO-2). القيمة الفارغة = الكل.                                                                    |
| `minQuality`      | رقم                                | `0`               | الصفوف التي تحقق `qualityScore >= minQuality` فقط. `0` = بلا حد أدنى.                                                        |
| `disabledSources` | سلسلة نصية                         | `""`              | معرّفات المصادر المطلوب استبعادها، مفصولة بفواصل (مثل `proxifly,webshare`).                                                  |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`         | `quality` = الدرجة تنازليًا؛ `latency` = زمن الاستجابة تصاعديًا (القيم الفارغة أخيرًا)؛ `recent` = `lastValidated` تنازليًا. |
| `offset`          | رقم                                | `0`               | بداية التقسيم إلى صفحات.                                                                                                     |
| `limit`           | رقم                                | `50`              | حجم الصفحة (مقيّد بحد أقصى من جانب الخادم).                                                                                  |

### الاستجابة

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 من المصدر الرئيسي"],
    "webshare": ["انتهاء مهلة الشبكة"]
  }
}
```

تعكس `total` الإجمالي المصفّى **قبل** التقسيم إلى صفحات، بحيث يمكن لواجهة المستخدم عرض
`الإجمالي: N` و`hasMore` بصورة مستقلة. تُفهرس `syncErrors` حسب معرّف المصدر، ولا
تُملأ إلا للمصادر التي فشلت مزامنتها الأخيرة — ونتيجة `الإجمالي: 0`
لا تكون صامتة أبدًا.

## الإضافة إلى المجموعة — `POST /api/settings/free-proxies/[id]/add-to-pool`

يرقّي وكيلاً مجانيًا إلى مجموعة `proxy_registry` المُدارة. يتحقق من
المصدر الرئيسي أولًا؛ وعند النجاح، يعيد معرّف وكيل المجموعة الجديد وزمن الاستجابة المقاس.

## المزامنة — `POST /api/settings/free-proxies/sync`

يعيد جلب جميع المصادر المفعّلة (أو المجموعة الفرعية الموجودة في `{ "sources": [...] }`).
تتم مزامنة كل مصدر بصورة مستقلة؛ ويُسجّل المصدر الذي يفشل في `syncErrors` بينما
تستمر المصادر الأخرى حتى الاكتمال، ولذلك لا تمحو المزامنات الجزئية البيانات الصالحة السابقة أبدًا.

## الإحصاءات — `GET /api/settings/free-proxies/stats`

يعيد تجميع `total / inPool / avgQuality / bySource / lastSyncAt`
من دون حمولة الصفوف — وتستخدمه عناصر واجهة رأس لوحة المعلومات.
