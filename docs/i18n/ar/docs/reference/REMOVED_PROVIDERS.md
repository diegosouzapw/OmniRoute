دُمجت بعض الخدمات في OmniRoute ثم أُزيلت لاحقًا لأن الأشخاص الذين يديرونها طلبوا
ذلك. هذه الصفحة هي السجل الدائم لعمليات الإزالة تلك. والغرض الوحيد منها هو منع
عودتها عن طريق الخطأ: فأي مساهم يعثر على fork قديم، أو حزمة npm مخزنة مؤقتًا،
أو issue مؤرشفة، أو طلب "استعادة المزوّد X"، يحتاج إلى مكان واحد ينص على **عدم
إعادة تقديمه**.

هذه الصفحة **ليست** قائمة بالخدمات المتوقفة أو التي أُلغيت. تُتابَع تلك الخدمات في
[`FREE_TIERS.md`](FREE_TIERS.md) ("مُزالة / لا توجد فئة مجانية") ويمكن أن تعود إذا عادت
الخدمة. أما الإدخالات أدناه فلا يمكن أن تعود إلا بإذن كتابي من المشغّل المذكور في
الطلب، ويجب ربط ذلك الإذن من الإدخال.

## السياسة

1. **يُمتثل لطلب الإزالة المقدّم من مشغّل الخدمة، ولا يخضع للتفاوض.** لا يرتبط OmniRoute
   بأي خدمة خارجية. عندما يطلب مشغّل خدمة إزالة التكامل، يُزال، سواء استخدم التكامل
   API رسميًا أم لا.
2. **تعني "مُزال" كل واجهة يتحكم فيها OmniRoute.** المنفّذ، وإدخال السجل، ومعرّف المزوّد
   والاسم المستعار، وقائمة النماذج، ونقاط النهاية، ومتغيرات البيئة، والأيقونة، وبطاقات
   لوحة المعلومات، ومرجع المزوّد المُنشأ، و`FREE_TIERS.md`، ومرجع البيئة، والأعداد في README،
   ونُسخ `llm.txt`، والاختبارات المخصصة واللقطات المرجعية، وتعليقات الشيفرة، وبنود CHANGELOG
   (مع تسوية مسجّلة، راجع `config/release/changelog-reconciliations.json`)،
   وملاحظات GitHub Releases، والويكي، وissues وdiscussions وpull requests على GitHub التي
   كان موضوعها ذلك المزوّد (تُحذف issues وdiscussions؛ ويُعاد تعيين عناوين pull requests،
   وتُستبدل أوصافها وتُقفل سلاسلها، لأن GitHub لا يستطيع حذف pull requests).
3. **لا تُعِد أبدًا تقديم إدخال في هذه الصفحة من دون إذن كتابي.** يشمل ذلك
   إعادة إضافة المعرّف أو الاسم المستعار إلى أي كتالوج للمزوّدين، أو إضافة النطاقات إلى منفّذ،
   أو قبول PR من مساهم "يستعيده"، أو إضافته إلى كتالوج النماذج المجانية، أو
   توثيق طريقة يدوية للوصول إليه عبر OmniRoute. أغلِق مثل هذه الـPRs والـissues مع
   رابط إلى هذه الصفحة.
4. **أبقِ الإدخال في حده الأدنى.** سجّل فقط ما يحتاج إليه المراجع للتعرّف على
   إعادة تقديم: المعرّفات، والنطاقات، والتواريخ، وpull request الذي نفّذ الإزالة.
   لا تصف كيفية عمل التكامل.
5. **حاجز منع التراجع هو `tests/unit/removed-providers-blocklist.test.ts`.** يفشل عندما
   يظهر أي معرّف أو نطاق أدناه مرة أخرى في كتالوجات المزوّدين، أو خريطة المنفّذ، أو
   مصادر سجل المزوّدين. أضف المعرّفات الجديدة إلى ذلك الاختبار في الـPR نفسه الذي
   يضيف صفًا هنا.

## إضافة إدخال

عند وصول طلب إزالة جديد:

1. تأكد من أن الطلب يأتي من مشغّل الخدمة (عنوان الدعم الخاص به أو
   نطاق يتحكم فيه)، واحتفظ بالرسالة بصورة خاصة.
2. أزل التكامل باتباع قائمة التحقق الواردة في البند 2 من السياسة. استخدم
   [#12440](https://github.com/diegosouzapw/OmniRoute/pull/12440) كمرجع لمزوّد
   لا يحتاج إلى مفتاح، و[#10210](https://github.com/diegosouzapw/OmniRoute/pull/10210) لمزوّد
   يعتمد على مفتاح API ولديه اتصالات مخزنة (أضف ترحيلًا).
3. أضف صفًا واحدًا إلى الجدول أعلاه والمعرّفات إلى
   `tests/unit/removed-providers-blocklist.test.ts`، في الـPR نفسه.
4. رُدّ على المشغّل بعد دمج الـPR، مع سرد ما أُزيل وما لا يستطيع OmniRoute
   تغييره (إصدارات npm وDocker المنشورة مسبقًا، وسجل git، وforks التابعة لجهات خارجية).
