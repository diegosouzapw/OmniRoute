> مفاتيح تبديل وقت التشغيل التي تغيّر سلوك OmniRoute **من دون إعادة النشر**.
> كل علامة مدرجة هنا معرّفة في
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — وهو المصدر الوحيد للحقيقة. تقرأ كلٌّ من لوحة المعلومات وواجهة REST API من
> ذلك الملف، ولذلك يُنشأ الجدول أدناه ليطابقه بنسبة 1:1.

---

## ما هي علامات الميزات

علامة الميزة هي مفتاح تبديل مُسمّى (قيمة منطقية أو تعداد) يمكن تغيير قيمته في
وقت التشغيل وحفظها في قاعدة البيانات، من دون الحاجة إلى إعادة نشر العملية. تُوصَف كل
علامة بواسطة `FeatureFlagDefinition` يتضمن `key` و`label`
و`description` و`category` و`defaultValue` و`type` وتلميح `requiresRestart`.

### ترتيب تحديد القيمة

تُحدَّد **القيمة الفعلية** للعلامة بواسطة
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) وفق
ترتيب الأولوية التالي (تفوز الأولوية الأعلى):

1. **تجاوز قاعدة البيانات** — قيمة مخزنة في جدول `key_value` ضمن نطاق الأسماء
   `feature_flags` (تُعيَّن عبر لوحة المعلومات أو واجهة REST API).
2. **متغير البيئة** — `process.env[<KEY>]`، إذا كان معيّنًا وغير فارغ.
3. **القيمة الافتراضية للتعريف** — قيمة `defaultValue` من `featureFlagDefinitions.ts`.

تُعد العلامة المنطقية **مفعّلة** عندما تكون قيمتها الفعلية `"true"` أو
`"1"` أو `"yes"` (راجع `isFeatureFlagEnabled()`).

> [!NOTE]
> لمعظم العلامات أيضًا متغير بيئة مطابق يحمل **الاسم نفسه**
> وموثّق في [`ENVIRONMENT.md`](./ENVIRONMENT.md). تكون الأولوية لتجاوز قاعدة البيانات الخاص بالعلامة
> على متغير البيئة هذا. تُحفَظ العلامة التي تحتوي على
> `requiresRestart: true` فورًا، لكنها لا تُقرأ مجددًا إلا عند بدء تشغيل العملية
> — ويؤدي تبديلها إلى إظهار لافتة **"إعادة تشغيل الخادم"** في لوحة المعلومات.

## دليل العلامات

76 علامة موزعة على 6 فئات. **الافتراضي** هو القيمة الافتراضية في التعريف — أي القيمة
المستخدمة عند عدم وجود تجاوز في قاعدة البيانات أو متغير بيئة.

| `PROXY_HEALTH_BLOCKED_RESETS_STREAK`      | منطقي | `false`           | في عملية الفحص الشامل لسلامة الوكيل، يؤدي الاستقصاء الذي رفضه الهدف (401/403/429) إلى تصفير سلسلة الإخفاقات المتتالية للوكيل. يكون معطّلًا افتراضيًا: يظل الرفض محايدًا (#10654). وتظل استجابة 5xx غير حاسمة في كلتا الحالتين؛ ولا يؤدي الرفض مطلقًا إلى إزالة وكيل أو تعطيله أو إعادة تنشيطه. |
| `DB_HEALTHCHECK_STARTUP_DEFERRED_ENABLED` | منطقي | `false`           | تشغيل فحص تكامل/سلامة قاعدة البيانات عند بدء التشغيل بعد أن يبدأ الخادم في قبول الطلبات (عبر `setImmediate`) بدلًا من حظر بدء التشغيل حتى اكتماله (#13717). يكون معطّلًا افتراضيًا: يُحظر بدء التشغيل تمامًا كما كان قبل طلب السحب هذا.                                                        |

> [!NOTE]
> يضبط `INPUT_SANITIZER_BLOCK_THRESHOLD` والاسم البديل القديم له
> `INJECTION_GUARD_BLOCK_THRESHOLD` وضع `block` الخاص بـ
> `INJECTION_GUARD_MODE`، لكنهما متغيرا بيئة عاديان تتم قراءتهما بواسطة
> [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts)،
> وليسا علامتي ميزات: فلا يمكن تجاوز قيمتيهما في قاعدة البيانات، ولا يوجد مفتاح تبديل لهما في لوحة المعلومات. راجع
> [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication).

> [!NOTE]
> يشير عمود `إعادة التشغيل` إلى العلامات التي تحمل `requiresRestart: true` — تُحفظ القيمة
> فورًا، لكنها لا تصبح سارية إلا بعد إعادة تحميل العملية. وترفض علامات التعداد
> أي قيمة خارج المجموعة المسموح بها (يُتحقق منها على جانب الخادم في كل من
> `setFeatureFlagOverride()` ومعالج REST `PUT`).

## تبديل العلامات

### لوحة التحكم

انتقل إلى **لوحة التحكم → الإعدادات → علامات الميزات**
(`/dashboard/settings/feature-flags`). تدعم الشبكة
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
ما يلي:

- **البحث** حسب المفتاح أو الوصف، و**التصفية** حسب الفئة (بالإضافة إلى عرض اصطناعي
  باسم **يتطلب إعادة التشغيل**).
- **مفتاح تبديل** للعلامات المنطقية وقائمة **منسدلة** لعلامات التعداد
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **شارة مصدر** لكل علامة — `DB` أو `ENV` أو `DEF` — توضّح مصدر
  القيمة الفعلية.
- زر **إعادة التعيين** (يظهر فقط للعلامات التي مصدرها `DB`) لإزالة التجاوز،
  وزر **إعادة تعيين جميع التجاوزات** في الأسفل.
- لافتة **إعادة تشغيل الخادم** عند تغيير علامة من نوع `requiresRestart`.

### واجهة REST API

تمر جميع العمليات عبر مسار واحد:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
تتطلب كل طريقة جلسة لوحة تحكم مصادَقًا عليها (وإلا يُعاد `401`).

#### `GET /api/settings/feature-flags`

يعيد كل علامة مع قيمتها الفعلية ومصدرها وملخصًا.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "طلب مفتاح API",
      "description": "طلب مفتاح API لجميع الطلبات الواردة",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... جميع العلامات الـ 75
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

يعيّن تجاوزًا واحدًا أو يزيله. النص: `{ key: string; value?: string }`.
يؤدي حذف `value` إلى إزالة التجاوز (واستعادة قيمة البيئة / القيمة الافتراضية).

```bash
# تعيين تجاوز في DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# إزالة التجاوز (من دون "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

تكرر الاستجابة القيمة والمصدر الجديدين `effectiveValue`/`source`، والقيمة والمصدر السابقين `previousValue`/
`previousSource`، و`requiresRestart`. تُرفض المفاتيح غير المعروفة وقيم التعداد
الواقعة خارج النطاق باستخدام `400`.

#### `DELETE /api/settings/feature-flags`

يمسح **جميع** تجاوزات DB دفعة واحدة، ويعيد كل علامة إلى قيمة البيئة / القيمة الافتراضية
الخاصة بها. يعيد `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> لا تدخل العلامات التي تحمل `requiresRestart: true` حيز التنفيذ إلا بعد إعادة تحميل العملية.
> يستدعي مسار إعادة التشغيل في لوحة التحكم `POST /api/restart` ثم يستطلع
> `GET /api/health/ping` حتى يعود الخادم إلى العمل.

## المسار الاحتياطي الطارئ للميزانية

يتحكم `OMNIROUTE_EMERGENCY_FALLBACK` (الفئة `runtime`، والقيمة الافتراضية `true`) في
مسار الرجوع المجاني الطارئ ضمن
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
عند تمكينه، تُوجَّه الطلبات التي تستنفد ميزانيتها إلى موفّر/نموذج احتياطي مجاني
بدلًا من فشلها مباشرةً. اضبطه على `false` (أو `0`) — عبر مفتاح التبديل في
لوحة التحكم، أو تجاوز في DB، أو متغير البيئة `OMNIROUTE_EMERGENCY_FALLBACK`
— لتعطيل هذا السلوك والسماح بفشل الطلبات التي استنفدت ميزانيتها.
(ظهر كمفتاح تبديل في لوحة التحكم ضمن طلبي الدمج #3741 / #3752.)
