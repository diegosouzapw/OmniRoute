## ما المزوّد؟

فكّر في المزوّد كما لو كان **شركة اتصالات هاتفية**. فكما تحتاج إلى شركة اتصالات لإجراء المكالمات، تحتاج إلى مزوّد ذكاء اصطناعي لاستخدام نماذج الذكاء الاصطناعي. يشبه OmniRoute هاتفًا يعمل مع **جميع شركات الاتصالات** — ويمكنك التبديل بينها تلقائيًا.

### أنواع المزوّدين

| النوع                      | ماهيته                      | أمثلة                             | التكلفة             |
| -------------------------- | --------------------------- | --------------------------------- | ------------------- |
| **مجاني**                  | لا يتطلب دفعًا              | Kiro، OpenCode Free، Pollinations | $0                  |
| **مفتاح API**              | تحتاج إلى مفتاح API         | OpenAI، Anthropic، Google         | الدفع حسب الاستخدام |
| **OAuth**                  | تسجيل الدخول باستخدام حسابك | Claude Code، GitHub Copilot       | اشتراك              |
| **ملف تعريف ارتباط الويب** | يستخدم جلسة متصفحك          | ChatGPT Web (Codex)، Gemini Web   | $0 (يستخدم حسابك)   |

### مزوّدو ملفات تعريف ارتباط الويب

راجع **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** للحصول على إرشادات الإعداد العامة والقيود واستكشاف الأخطاء وإصلاحها وإرشادات المصادقة الخاصة بكل مزوّد.

## البدء السريع: وصّل مزوّدك الأول

### إعداد اختياري للمزوّدين المجانيين عند التشغيل الأول

يوفّر معالج التشغيل الأول بطاقة صريحة بعنوان **إعداد المزوّدين المجانيين**. ويستخرج القائمة الحالية
للمزوّدين المؤهلين من سجل مزوّدي OmniRoute الذين لا يتطلبون مصادقة، ثم يتيح لك مراجعة كل
مزوّد وإلغاء تحديده قبل التأكيد. يعرض OmniRoute تنبيه الاحتياط الخاص بالمزوّد ورابطًا إلى موقعه
كي تتمكن أولًا من مراجعة شروط الجهة الخارجية والخصوصية والتوفر وحدود معدل الاستخدام.

هذا الإجراء اختياري: لا يؤدي إنهاء المعالج أبدًا إلى إنشاء اتصالات بمزوّدين مجانيين دون إشعار.
فهو لا ينشئ إلا المزوّدين الذين ما زالوا غير موجودين، ويترك الاتصالات الحالية المخصّصة
دون تغيير، ويعرض كلًا من المزوّدين الذين أُنشئوا والمُهيّئين مسبقًا والذين فشلوا بصورة منفصلة. ويمكنك
بأمان إعادة محاولة حالات الفشل فقط بعد الحصول على نتيجة جزئية.

### الخيار A: مزوّد مجاني (من دون بطاقة ائتمان)

1. افتح لوحة المعلومات على `http://localhost:20128`
2. انتقل إلى **المزوّدون** → **إضافة مزوّد**
3. اختر أحد هؤلاء المزوّدين المجانيين:
   - **Kiro AI** — نماذج Claude مجانية (لا تتطلب مصادقة)
   - **OpenCode Free** — نماذج GPT مجانية (لا تتطلب مصادقة)
   - **Pollinations** — GPT-5 وClaude وGemini مجانًا (لا يتطلب مفتاحًا)
   - **LongCat** — 10M من الرموز المميزة مجانًا (منحة لمرة واحدة، تتطلب حسابًا + التحقق من الهوية)
   - **Cloudflare AI** — أكثر من 50 نموذجًا، و10K عصبون/يوم
   - **MLX Gemma 26B** — نموذج محلي لأجهزة Apple Silicon (حوالي 38.5 رمزًا مميزًا/ثانية، وحوالي 15.9GB من ذاكرة RAM)
   - **MLX Qwen 3.8 27B** — نموذج محلي لأجهزة Apple Silicon (حوالي 9.1 رمزًا مميزًا/ثانية، وحوالي 13.1GB من ذاكرة RAM)
4. انقر على **اتصال**
5. انتهيت! أصبح لديك الآن وصول مجاني إلى الذكاء الاصطناعي.

### الخيار B: مزوّد بمفتاح API (مدفوع)

1. احصل على مفتاح API من موقع المزوّد:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. افتح لوحة المعلومات على `http://localhost:20128`
3. انتقل إلى **المزوّدون** → **إضافة مزوّد**
4. اختر مزوّدك
5. ألصق مفتاح API الخاص بك
6. انقر على **اتصال**
7. انتهيت! أصبح لديك الآن وصول إلى نماذج ذلك المزوّد.

### الخيار C: مزوّد OAuth (اشتراك)

1. افتح لوحة المعلومات على `http://localhost:20128`
2. انتقل إلى **المزوّدون** → **إضافة مزوّد**
3. اختر مزوّدك (مثل Claude Code أو GitHub Copilot)
4. انقر على **الاتصال باستخدام OAuth**
5. سجّل الدخول باستخدام حسابك
6. انتهيت! أصبح لديك الآن وصول إلى نماذج اشتراكك.

### الخيار D: نماذج MLX المحلية (Apple Silicon)

بالنسبة إلى أجهزة Mac المزودة بمعالجات Apple Silicon وذاكرة موحّدة، يدعم OmniRoute الاتصال بنماذج MLX المحلية التي تعمل عبر `mlx-lm.server` بوصفها مزوّدين محليين عاديين متوافقين مع OpenAI.

#### المتطلبات الأساسية

- جهاز **Apple Silicon Mac** ‏(M1/M2/M3/M4) مع ذاكرة موحّدة بسعة 24GB أو أكثر حسب التوصية
- مدير الحزم **uv**: ‏`curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: ‏`uv pip install mlx-lm`

#### البدء السريع

1. **ثبّت التبعيات**:

   ```bash
   # ثبّت uv إذا لم يكن مثبّتًا بالفعل
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # ثبّت mlx-lm
   uv pip install mlx-lm
   ```

2. **شغّل خوادم MLX يدويًا** (في طرفيات منفصلة):

   ```bash
   # الطرفية 1: Gemma 4 26B A4B IT-QAT (المنفذ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # الطرفية 2: Qwen 3.8 27B MLX Mixed (المنفذ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **اتصل من لوحة معلومات OmniRoute**:
   - انتقل إلى **المزوّدون** → **إضافة مزوّد**
   - اختر **MLX Gemma 26B** أو **MLX Qwen 3.8 27B**
   - انقر على **اتصال** (لا يتطلب مفتاح API)

4. **استخدمه مع OpenCode**:
   ```bash
   # اضبط OpenCode لاستخدام OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # استخدم نماذج MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### إدارة الذاكرة

**مهم**: عند استخدام ذاكرة موحّدة بسعة 24GB، لا يمكن تشغيل سوى **نموذج MLX كبير واحد في كل مرة**.

- Gemma 26B: ذروة استخدام للذاكرة تبلغ حوالي 15.9GB
- Qwen 3.8 27B: ذروة استخدام للذاكرة تبلغ حوالي 13.1GB

يجب عليك إدارة ذلك يدويًا:

- شغّل خادم MLX واحدًا فقط في كل مرة، أو
- شغّل كليهما على جهازين منفصلين، أو
- أوقف أحدهما قبل تشغيل الآخر

لا يدير OmniRoute عمليات خادم MLX تلقائيًا — بل يوجّه الطلبات فقط إلى نقاط النهاية المتوافقة مع OpenAI التي تضبطها.

#### دعم استدعاء الأدوات

يدعم كلا النموذجين استدعاء الأدوات المتوافق مع OpenAI. اختبر ذلك باستخدام:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "ما ناتج 2+2؟ استخدم أداة الحاسبة."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "إجراء عملية حسابية", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### استكشاف الأخطاء وإصلاحها

| المشكلة                | الحل                                                                             |
| ---------------------- | -------------------------------------------------------------------------------- |
| الخادم لا يبدأ التشغيل | تحقّق من `uv run mlx_lm.server --help` وتأكد من معرّفات النماذج                  |
| نفاد الذاكرة           | تأكد من تشغيل نموذج واحد فقط؛ وأغلق التطبيقات الأخرى؛ وتحقق من مراقب النشاط      |
| رُفض الاتصال           | تأكد من أن الخادم يعمل على المنفذ الصحيح (11435/11436)                           |
| الاستجابات بطيئة       | يحمّل الطلب الأول النموذج إلى الذاكرة (~30-60 ثانية)؛ أما الطلبات اللاحقة فسريعة |
| فشل استدعاء الأداة     | تأكد من أن النموذج يدعم الأدوات؛ وراجع سجلات OmniRoute بحثًا عن أخطاء الترجمة    |

## كيفية ربط مزوّد (خطوة بخطوة)

### الخطوة 1: افتح لوحة التحكم

انتقل إلى `http://localhost:20128` في متصفحك.

### الخطوة 2: انتقل إلى المزوّدين

انقر على **المزوّدون** في الشريط الجانبي.

### الخطوة 3: انقر على إضافة مزوّد

انقر على زر **+ إضافة مزوّد**.

### الخطوة 4: اختر المزوّد

تصفّح القائمة أو ابحث عن المزوّد. انقر عليه.

### الخطوة 5: أدخل بيانات الاعتماد

- **المزوّدون المجانيون**: لا حاجة إلى بيانات اعتماد — ما عليك سوى النقر على **اتصال**
- **المزوّدون الذين يستخدمون مفتاح API**: الصق مفتاح API الخاص بك
- **مزوّدو OAuth**: انقر على **الاتصال باستخدام OAuth** وسجّل الدخول

### الخطوة 6: اختبر الاتصال

انقر على **اختبار الاتصال** للتحقق من أنه يعمل.

### الخطوة 7: تم!

أصبح المزوّد متصلًا الآن. يمكنك استخدامه مع `model: "auto"` أو تحديد المزوّد مباشرةً.

## استخدام عدة مزوّدين

يعمل OmniRoute بأفضل صورة مع **عدة مزوّدين**. ويمنحك ذلك:

- **الرجوع التلقائي إلى مزوّد بديل** — إذا تعذّر أحد المزوّدين، يجرّب OmniRoute المزوّد التالي
- **تحسين التكلفة** — يختار OmniRoute أرخص مزوّد لكل طلب
- **تحسين السرعة** — يختار OmniRoute أسرع مزوّد لكل طلب
- **تحسين الجودة** — يختار OmniRoute أفضل مزوّد لكل مهمة

### الإعداد الموصى به

اربط **3 مزوّدين** على الأقل للحصول على أفضل تجربة:

1. **مزوّد مجاني واحد** (Kiro أو OpenCode Free أو Pollinations) — متاح دائمًا
2. **مزوّد سريع واحد** (Groq أو Cerebras) — للحصول على استجابات سريعة
3. **مزوّد عالي الجودة واحد** (OpenAI أو Anthropic أو Google) — للمهام المعقّدة

بعد ذلك، استخدم `model: "auto"` وسيختار OmniRoute تلقائيًا أفضل مزوّد لكل طلب.

## الأسئلة الشائعة

### "هل أحتاج إلى الدفع لاستخدام OmniRoute؟"

**لا!** إن OmniRoute مجاني ومفتوح المصدر. يمكنك استخدام المزوّدين المجانيين (Kiro وOpenCode Free وPollinations) دون دفع أي شيء. ولا تدفع إلا إذا اخترت استخدام مزوّدين مدفوعي الأجر.

### "بأي مزوّد ينبغي أن أبدأ؟"

ابدأ باستخدام **Kiro AI** — فهو مجاني، ولا يتطلب مفتاح API، ويتيح لك الوصول إلى نماذج Claude. ثم أضف المزيد من المزوّدين حسب الحاجة.

### "هل يمكنني استخدام عدة مزوّدين في الوقت نفسه؟"

**نعم!** هذه هي الفكرة الأساسية من OmniRoute. اربط عدة مزوّدين واستخدم `model: "auto"` للسماح لـ OmniRoute باختيار الأنسب لكل طلب.

### "ماذا يحدث إذا تعطل أحد المزوّدين؟"

يتخطى OmniRoute تلقائيًا المزوّدين الذين فشلوا ويجرب المزوّد التالي. ولا يتعين عليك فعل أي شيء.

### "كيف أفصل أحد المزوّدين؟"

انتقل إلى المزوّدون → انقر على المزوّد → انقر على **قطع الاتصال**.

### "هل يمكنني استخدام مفاتيح API الحالية الخاصة بي؟"

**نعم!** إذا كانت لديك بالفعل مفاتيح API خاصة بـ OpenAI أو Anthropic أو Google أو غيرها، فيمكنك استخدامها في OmniRoute. ما عليك سوى لصقها عند ربط المزوّد.
