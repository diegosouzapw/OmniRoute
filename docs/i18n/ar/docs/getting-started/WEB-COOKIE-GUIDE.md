تتيح موفّرات Web Cookie لـ OmniRoute استخدام خدمة ذكاء اصطناعي من خلال جلسة المتصفح الحالية بدلًا من مفتاح API. وهي مفيدة عندما يكون لديك بالفعل وصول إلى خدمة عبر موقعها الإلكتروني وتريد أن يستخدم OmniRoute الجلسة الموثَّقة نفسها.

على عكس الموفّرات التي تستخدم مفاتيح API، تجري مصادقة موفّرات Web Cookie باستخدام بيانات الاعتماد التي يرسلها متصفحك إلى الموقع الإلكتروني.

---

# قبل البدء

> **مهم:** انسخ بيانات الاعتماد دائمًا من **طلب شبكة مباشر**، **وليس** من مخزن ملفات تعريف الارتباط في متصفحك.

تحدث العديد من مشكلات المصادقة بسبب نسخ ملفات تعريف الارتباط من المكان الخطأ.

## لا تنسخ من مخزن ملفات تعريف الارتباط

تعرض معظم المتصفحات ملفات تعريف الارتباط المخزنة من خلال:

```
DevTools
→ Application (أو Storage)
→ Cookies
```

على الرغم من أن ملفات تعريف الارتباط هذه قد تبدو صحيحة، فقد تكون:

- قديمة
- غير مكتملة
- تفتقد ملفات تعريف ارتباط لا تُرسل إلا مع الطلبات الموثَّقة

قد يؤدي استخدام هذه القيم إلى فشل المصادقة حتى لو بدت صالحة.

## انسخ من طلب مباشر

بدلًا من ذلك، استخدم ملفات تعريف الارتباط من طلب ناجح:

```
DevTools
→ Network
→ حدّث الصفحة
→ افتح طلب دردشة أو محادثة
→ Request Headers
→ Cookie
```

يحتوي ترويس طلب `Cookie` على معلومات المصادقة الدقيقة التي استخدمها متصفحك بنجاح.

بالنسبة إلى معظم موفّرات Web Cookie، هذه هي القيمة التي يجب لصقها في OmniRoute.

---

# الإعداد العام

عملية الإعداد متماثلة لمعظم موفّرات Web Cookie.

1. سجّل الدخول إلى الموقع الإلكتروني للموفّر.
2. افتح أدوات المطوّرين في المتصفح.
3. افتح علامة التبويب **Network**.
4. حدّث الصفحة.
5. افتح طلب دردشة أو محادثة موثَّقًا.
6. انسخ بيانات اعتماد المصادقة المطلوبة.
7. افتح OmniRoute.
8. انتقل إلى **Providers → Add Provider**.
9. حدّد موفّر Web Cookie الخاص بك.
10. الصق بيانات الاعتماد.
11. انقر على **Test Connection**.
12. احفظ الموفّر.

تعتمد بيانات الاعتماد المطلوبة تحديدًا على الموفّر.

# ما يمكن لموفّرات Web Cookie فعله وما لا يمكنها فعله

تعيد موفّرات Web Cookie استخدام واجهة الدردشة الخاصة بموقع إلكتروني. وهي **لا** توفّر الإمكانات نفسها التي توفّرها واجهات API الرسمية.

## مدعوم

- المصادقة باستخدام جلسة المتصفح الحالية
- الوصول إلى النماذج المتاحة من خلال حسابك
- بث استجابات الدردشة
- لا يلزم مفتاح API

## غير مدعوم

- استدعاء الدوال
- استدعاء الأدوات
- التحرير التلقائي للملفات
- تدفقات عمل بيئات التطوير المتكاملة القائمة على الوكلاء
- الميزات المتاحة عبر API فقط

هذا سلوك متوقع و**ليس** خطأً برمجيًا.

إذا كنت بحاجة إلى تنفيذ الأدوات أو التحرير التلقائي للملفات أو تدفقات عمل أخرى للوكلاء، فاستخدم **موفّرًا يعتمد على مفتاح API** بدلًا من موفّر Web Cookie.

---

# تنبيه بشأن التحقق

لا يؤكد نجاح **Test Connection** أو التحقق من ملفات تعريف الارتباط سوى أن بيانات الاعتماد المقدَّمة تبدو بالتنسيق المتوقع.

إلى أن تُحل المشكلة #7857، فإن نجاح التحقق **لا يضمن** نجاح مصادقة الموفّر.

إذا استمرت المصادقة في الفشل، فتحقّق من أنك نسخت بيانات الاعتماد من طلب شبكة مباشر بدلًا من مخزن ملفات تعريف الارتباط في المتصفح.

---

# استكشاف الأخطاء وإصلاحها

## فشل المصادقة

تحقّق من أن بيانات الاعتماد نُسخت من:

```
Network
→ Request Headers
→ Cookie
```

و**ليس** من:

```
Application
→ Cookies
```

---

## يعمل ملف تعريف الارتباط في المتصفح ولكن ليس في OmniRoute

تتضمن بعض الموفّرات ملفات تعريف ارتباط لا تُرسل إلا أثناء الطلبات الموثَّقة.

أعد نسخ بيانات الاعتماد من طلب شبكة جديد بعد فتح محادثة بنجاح.

---

## انتهت صلاحية الجلسة

تستخدم موفّرات Web Cookie جلسة المتصفح الحالية.

إذا انتهت صلاحية جلسة المتصفح أو سجّلت الخروج، فيجب عليك نسخ مجموعة جديدة من بيانات الاعتماد.

---

## ينجح اختبار الاتصال ولكن تفشل الطلبات

إلى أن تُحل المشكلة #7857، لا يعني اجتياز التحقق أن طلب المصادقة سينجح بالضرورة.

أعد نسخ بيانات اعتمادك من طلب موثَّق جديد قبل مواصلة استكشاف الأخطاء وإصلاحها.

---

للحصول على شرح إرشادي كامل خاص بموفّر معيّن، راجع:

- **Claude Web** — `docs/providers/CLAUDE_WEB.md`

يوضّح دليل Claude Web عملية الإعداد الكاملة لموفّر Web Cookie، ويُعدّ التطبيق المرجعي.

# أفضل الممارسات

- انسخ بيانات الاعتماد من طلب موثَّق جديد.
- تجنّب إعادة استخدام ملفات تعريف الارتباط القديمة.
- أبقِ جلسة متصفحك نشطة أثناء استخدام موفّرات Web Cookie.
- تعامل مع ملفات تعريف الارتباط المنسوخة باعتبارها بيانات اعتماد حساسة.
- استخدم الموفّرات التي تعتمد على مفاتيح API عندما تحتاج إلى استدعاء الدوال أو تدفقات عمل الوكلاء.
