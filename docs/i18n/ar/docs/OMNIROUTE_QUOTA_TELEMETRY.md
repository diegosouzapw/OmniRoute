يفصل OmniRoute بين بيانات قياس الحصص الخاصة بمزوّد الخدمة ومحاسبة Ghostlight.

## الحالات الدقيقة

- تعني `healthy` أن مصدرًا أبلغ عن سعة متبقية قابلة للاستخدام.
- تعني `approaching_limit` أن مصدرًا أبلغ عن سعة متبقية تساوي الحد المُهيأ أو تقل عنه.
- لا تُصدر الحالة `exhausted` إلا عندما يُبلغ مصدر عن سعة صفرية أو عن وصول الاستخدام إلى حده الأقصى.
- تعني `unavailable` أن مصدرًا مدعومًا أخفق في إرجاع البيانات.
- تعني `unknown` عدم وجود مصدر مدعوم أو عدم معرفة حد مزوّد الخدمة.

الحالة غير المعروفة لا تعني نفاد السعة، ولا تؤدي إلى تعطيل مزوّد الخدمة.

تُفضَّل المصادر بالترتيب التالي: واجهة API الرسمية لمزوّد الخدمة، وواجهة API الموثّقة للاستخدام، وترويسات الاستجابة المعيّنة صراحةً، وإعدادات المسؤول، والتقديرات المحلية، ثم الحالة غير المعروفة. ولا تُعرض التقديرات المحلية مطلقًا على أنها بيانات فوترة خاصة بمزوّد الخدمة.

لا تُحلَّل ترويسات الاستجابة إلا من خلال تعيين صريح خاص بمزوّد الخدمة. ولا يُفترض انطباق أسماء الترويسات العامة على جميع المزوّدين.
