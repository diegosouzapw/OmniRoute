## `src/` — Manhajar Next.js

```
src/
├── app/                 # App Router (shafuka + hanyoyin API + shafukan matsayi + shafin gabatarwa)
├── lib/                 # Muhimman ɗakunan karatu / sassan fanni (ƙananan kundin adireshi 80 + kusan fayilolin matakin sama 70)
├── domain/              # Tsantsar dabarun fanni (injin manufofi, fallback, kuɗi, lockout, comboResolver, assessment)
├── server/              # Sassan da ake amfani da su a sabar kawai (authz pipeline, cors, auth middleware) — ba za a iya shigo da su daga abokin ciniki ba
├── shared/              # Abubuwan da aka raba tsakanin saba da abokin ciniki inda hakan ba shi da haɗari (constants, types, validation, contracts, utils)
├── i18n/                # Tsarin next-intl + saƙonnin JSON na kowane locale (locales 42)
├── middleware/          # Next.js middleware (inganta buƙata, gano locale)
├── mitm/                # Jigon wakilin MITM: ƙirƙira/shigar da takardar shaida, handlers, targets, inspector, masks, passthrough
│   ├── handlers/        # Ajin handler na wakilin IDE guda 9 waɗanda suka faɗaɗa MitmHandlerBase (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # Matakin kama zirga-zirga: buffer (zoben ƙwaƙwalwar-ciki), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # Manne-haɗin adaftan samfuri (legacy shim)
├── scripts/             # Rubutun kula da tsarin da ke cikin bishiyar (misali, backfillAggregation)
├── sse/                 # Tsofaffin handlers/services na SSE (chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # Tsohon ma'ajin cikin ƙwaƙwalwa (ana daina amfani da shi a hankali don komawa src/lib/db)
├── types/               # Fayilolin nau'in TS da aka raba
├── instrumentation.ts   # Ƙugiyar telemetry ta Next.js (browser + edge)
├── instrumentation-node.ts  # Instrumentation na Node kawai
└── proxy.ts             # Shim ɗin mashigar HTTP-proxy
```
