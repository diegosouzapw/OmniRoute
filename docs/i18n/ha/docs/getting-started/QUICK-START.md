## Mataki na 1: Shigar da OmniRoute

Zaɓi hanyar da ka fi so:

### Zaɓi na A: npm (An Shawarta)

```bash
npm install -g omniroute
```

### Zaɓi na B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` shi ne ingantaccen SemVer mafi girma da aka **wallafa**. Ba ya bin git `main`. Ƙayyade `diegosouzapw/omniroute:X.Y.Z` don GitOps. Duba [Alamomin Image / Tashoshin Fitarwa](../guides/DOCKER_GUIDE.md#release-channels).

### Zaɓi na C: Daga Source

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Mataki na 2: Fara OmniRoute

```bash
omniroute
```

OmniRoute yana farawa a `http://localhost:20128`. Dashboard zai buɗe ta atomatik.

---

## Mataki na 3: Haɗa Mai Samarwa na Kyauta

Za ka iya amfani da OmniRoute **ba tare da biyan komai ba** ta hanyar haɗa mai samarwa na kyauta.

### Zaɓi na A: Kiro (Claude na Kyauta — Ba a Buƙatar Katin Kuɗi)

1. Buɗe dashboard a `http://localhost:20128`
2. Je zuwa **Masu Samarwa** → **Ƙara Mai Samarwa**
3. Zaɓi **Kiro AI**
4. Danna **Haɗa** (ba a buƙatar API key!)
5. An gama! Yanzu kana da damar amfani da models na Claude kyauta.

### Zaɓi na B: OpenCode Free (Ba a Buƙatar Tantancewa)

1. Buɗe dashboard a `http://localhost:20128`
2. Je zuwa **Masu Samarwa** → **Ƙara Mai Samarwa**
3. Zaɓi **OpenCode Free**
4. Danna **Haɗa** (ba a buƙatar API key!)
5. An gama! Yanzu kana da damar amfani da models da yawa kyauta.

### Zaɓi na C: Pollinations (Ba a Buƙatar Key)

1. Buɗe dashboard a `http://localhost:20128`
2. Je zuwa **Masu Samarwa** → **Ƙara Mai Samarwa**
3. Zaɓi **Pollinations**
4. Danna **Haɗa** (ba a buƙatar API key!)
5. An gama! Yanzu kana da damar amfani da GPT-5, Claude, Gemini, da sauransu kyauta.

---

## Mataki na 4: Tabbatar Yana Aiki

Daga [API Keys](http://localhost:20128/dashboard/api-manager), ƙirƙiri sabon key. Ajiye wannan key domin ba zai sake bayyana ba. Ka lura cewa wannan key ɗin na kayan aiki ne don samun damar shiga OmniRoute, ba don samun damar shiga masu samarwa na waje ba.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Ya kamata ka ga jerin models ɗin da ka haɗa.

## Mataki na 5: Nuna wa IDE ko CLI ɗinka OmniRoute

A cikin IDE ko kayan aikin CLI ɗinka, saita:

```
Base URL: http://localhost:20128/v1
API Key:  [kwafa daga Dashboard → Endpoints]
Model:    auto
```

Shi ke nan! Yanzu IDE ɗinka yana amfani da OmniRoute tare da zaɓen mai samarwa ta atomatik.

### Misalin IDE: VSCode/Continue.dev

1. A cikin VSCode, shigar da extension na [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Sabunta `~/.continue/config.yaml` ɗinka don ƙara layuka masu zuwa:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. A cikin sashen hira na Continue.dev, zaɓi `OmniRoute - Auto` kuma za ka aika buƙatu zuwa OmniRoute.
4. (Na zaɓi) Aikin gwaji ga mai karatu — sa IDE ɗinka ya sabunta `config.yaml` da duk sauran tsarukan da aka riga aka gina 😊

### Misalin CLI: Codex CLI

1. A cikin operating system ɗinka, saita environment variable ɗin dindindin.
   Don macOS/Linux (ƙara shi zuwa `~/.bashrc` ko `~/.zshrc` ɗinka):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Don Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Yanzu mu ƙaddamar da Codex, amma an tsara shi don OmniRoute. Gudanar da:

```
omniroute launch-codex --model auto
```

Za ka iya yin wannan da hannu ta hanyar `codex` da command line parameters don ƙayyade endpoint da api key, amma da umarnin da ke sama, OmniRoute zai kula da komai a madadinka.

Irin wannan ƙaddamarwa da umarni guda ɗaya yana aiki ga sauran CLIs ta hanyar generic launcher — `omniroute run <target>` yana goyon bayan `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, da `gemini` (duba [Haɗin CLI](../guides/CLI-INTEGRATIONS.md)).

3. Ya kamata CLI ya fara aika buƙatu zuwa OmniRoute yanzu.

### Tabbatar cewa kayan aikinka yana tura buƙatu zuwa OmniRoute

Za ka iya ganin bayanan buƙatar ta hanyar danna [Sa-ido/Logs](http://localhost:20128/dashboard/logs) daga sidebar na hagu. Danna cikinsa zai nuna maka ƙarin bayani. A matsayin ƙarin bayani, za ka iya ganin irin bayanan da harness ɗin da ka fi so yake aikawa. Wannan yana da amfani ta fuskar koyo da gyaran matsaloli.

## Tambayoyin da Aka Saba Yi

### "Ina buƙatar API key?"

**A'a!** Za ka iya amfani da masu samarwa na kyauta (Kiro, OpenCode Free, Pollinations) ba tare da wani API key ba. Kawai haɗa su a cikin dashboard.

### "Mene ne `auto`?"

`auto` yana gaya wa OmniRoute ya zaɓi mafi kyawun mai samarwa ga kowace buƙata ta atomatik. Yana la'akari da sauri, farashi, inganci, da samuwa. Duba [Jagorar Auto-Combo](./AUTO-COMBO-GUIDE.md) don cikakken bayani.

### "Nawa ne kuɗinsa?"

OmniRoute kansa **kyauta ne kuma open-source ne**. Kana biyan kuɗin masu samarwar da kake amfani da su ne kawai. Masu samarwa da yawa suna da matakan kyauta — duba [Jagorar Matakan Kyauta](./FREE-TIERS-GUIDE.md).

### "Zan iya amfani da shi tare da Claude Code / Cursor / Copilot?"

**E!** OmniRoute yana aiki da duk wani kayan aiki da ke goyon bayan tsarin OpenAI. Kawai saita base URL zuwa `http://localhost:20128/v1`. Duba [Jagorar Kayan Aikin CLI](../reference/CLI-TOOLS.md) don takamaiman umarnin saitawa.

### "Me zai faru idan wani mai samarwa ya daina aiki?"

OmniRoute yana tsallake masu samarwar da suka gaza ta atomatik sannan ya gwada na gaba. Ba ka buƙatar yin komai. Duba [Jagorar Auto-Combo](./AUTO-COMBO-GUIDE.md) don cikakken bayani.
