> **Madogarar gaskiya:** `src/lib/obsidian/api.ts` (REST + abokin ciniki na daidaitawa),
> `src/lib/db/obsidian.ts` (dorewar token / base-URL / WebDAV),
> `src/lib/obsidianSync.ts` (daidaita rumbun WebDAV), `open-sse/mcp-server/tools/obsidianTools.ts`
> (kayan aikin MCP guda 22), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API na saituna). Rijistar kayan aiki
> da haɗa iyakokin izini suna cikin `open-sse/mcp-server/server.ts`.

## Mene ne

OmniRoute yana haɗuwa da rumbun **Obsidian** a matsayin **tushen mahallin bayani** — ma'ajiyar
ilimin Markdown ta gida wadda wakilai ke karantawa da rubutawa ta hanyar sabar MCP da aka
gina a ciki. Haɗin yana sadarwa da plugin ɗin al'umma na **Obsidian Local REST API** wanda
ke gudana a cikin manhajar tebur, don haka wakilai za su iya bincika bayanan rubutu,
karanta/rubuta/gyara fayiloli, jera abubuwan rumbun, aiki da bayanan rubutu na yau da kullum
ko na mako-mako, sarrafa tags, gudanar da umarnin Obsidian, da kuma (idan ana so) daidaita
rumbun ta hanyoyi biyu tsakanin tebur↔wayar hannu.

Abokin cinikin (`src/lib/obsidian/api.ts`) yana lulluɓe Local REST API da:

- **Sake gwadawa tare da jinkiri mai ƙaruwa** don kurakuran wucin gadi na `5xx`, da **lokacin jira na daƙiƙa 30** ta hanyar `AbortController`.
- **Rarraba kurakurai bisa nau'i** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Shawara mai sauƙin fahimta ta "ba za a iya isa ga Obsidian ba"** wadda ke nuna kuskuren
  tashar sadarwa da ake yawan yi (HTTP a `27123`, **ba** ƙarshen MCP da ke `27124` ba) da tsarin Tailscale.
- **Tsarawa ta musamman ga hanyoyin fayil** masu dangantaka da rumbu, domin hanyoyin bayanan rubutu masu sarari/slashes su kasance amintattu.

## Saitawa

Babu **environment variable** don token ko base URL na Obsidian — dukansu ana adana su
a cikin teburin SQLite `key_value` (namespace `obsidian`) ta hanyar
`src/lib/db/obsidian.ts`. Ana **rufe token ɗin da ɓoyayyen tsaro lokacin da yake ajiye**
(AES-256-GCM, tare da koma-baya zuwa plaintext don dacewa da tsofaffin nau'ikan). Yi saitin
daga shafin **Context Sources** na dashboard ɗin Endpoint (`ObsidianSourceCard`), ko ta
hanyar REST API na saituna.

> [!IMPORTANT]
> Dole ne a girka plugin ɗin **Obsidian Local REST API** kuma yana gudana. REST
> interface ɗinsa yana sauraro a **HTTP `127.0.0.1:27123`** (base URL na asali). Tashar `27124`
> ƙarshen MCP/HTTPS ne _na daban_ kuma hanyar saituna tana ƙin karɓarsa kai tsaye.
> Idan ana haɗawa daga wata na'ura, yi amfani da `http://<tailscale-ip>:27123`.

### Maɓallan daidaitawa (SQLite `key_value`, namespace `obsidian`)

| Maɓalli           | Manufa                                                   | An ɓoye |
| ----------------- | -------------------------------------------------------- | ------- |
| `api_key`         | Local REST API bearer token                              | eh      |
| `base_url`        | REST base URL (na asali `http://127.0.0.1:27123`)        | a'a     |
| `vault_path`      | Cikakkiyar hanya zuwa kundin rumbun (don daidaitawa)     | a'a     |
| `webdav_username` | Sunan mai amfani na WebDAV da aka samar (daidaita rumbu) | a'a     |
| `webdav_password` | Kalmar sirrin WebDAV da aka samar (daidaita rumbu)       | eh      |
| `webdav_enabled`  | Ko an kunna daidaita rumbu ta WebDAV                     | a'a     |

### Daidaitawa ta REST

```bash
# Ajiye + tabbatar da token na Local REST API (POST yana tabbatarwa ta hanyar binciken matsayi)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Duba matsayin haɗi (yana dawo da connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Cire haɗi (yana share token ɗin da aka adana)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Dukkan hanyoyin suna buƙatar tantancewar dashboard. `POST` yana ƙin duk wani URL da ke kan
tashar `27124` kuma yana tabbatar da token ta hanyar kiran ƙarshen matsayi na Local REST API
kafin ya adana shi.

### Daidaita rumbu ta WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` yana sarrafa daidaita rumbu na zaɓi wanda
WebDAV ke tallafawa (wanda `src/lib/obsidianSync.ts` ke tafiyarwa). Kunna shi yana nuna
OmniRoute zuwa kundin rumbu na gida kuma yana samar da sunan mai amfani/kalmar sirri ta
WebDAV na bazuwar zaɓi:

```bash
# Kunna daidaita WebDAV don kundin rumbu (yana samar da sunan mai amfani/kalmar sirri)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Samo matsayin daidaita WebDAV (ana dawo da bayanan shiga ne kawai yayin da aka kunna)
curl http://localhost:20128/api/settings/obsidian/webdav

# Kashe daidaita WebDAV (yana share bayanan shiga + .stignore da ake sarrafawa)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Tushen mahallin bayani na kowane API key (na zaɓi)

Za a iya keɓance daidaitawar Obsidian **ga kowane API key** ta hanyar teburin
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Lokacin da kiran MCP
ya ɗauki ingantaccen id na API key, `getObsidianConfigForApiKey()` yana fifita token/base-URL/vault-path
na wannan maɓallin (`source: "api_key"`), in ba haka ba kuma ya koma ga daidaitawar gama-gari
(`source: "global"`).

## Kayan aikin MCP (22)

An ayyana su a cikin `open-sse/mcp-server/tools/obsidianTools.ts`. Ana tantance token/base-URL
ga kowane kira (na API key da farko, sannan na gama-gari). Kayan aikin da ke hulɗa da **sync server**
na OmniRoute (kayan aikin `obsidian_sync_*` guda huɗu) suna kuma buƙatar sync auth token da aka saita
a cikin saitunan OmniRoute.

### Kayan aikin karantawa (`read:obsidian`)

| Kayan aiki                   | Bayani                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Duba ko ana iya isa ga Local REST API kuma an tabbatar da izinin shiga.                          |
| `obsidian_search_simple`     | Binciken cikakken rubutu na bayanan rubutu; yana dawo da gutsattsarin rubutu tare da file paths. |
| `obsidian_search_structured` | Bincike ta amfani da JSON Logic expression (matatun and/or/regex/path).                          |
| `obsidian_read_note`         | Karanta bayanin rubutu ta vault-relative path; a zaɓe, takamaiman heading/block/frontmatter.     |
| `obsidian_list_vault`        | Jera files da directories da ke cikin vault (bishiyar entries).                                  |
| `obsidian_get_document_map`  | Sami tsarin headings na bayanin rubutu a matsayin taswirar headings → line numbers.              |
| `obsidian_get_note_metadata` | Sami frontmatter, tags, links, da ƙididdigar haruffa/kalmomi ba tare da cikakken abun ciki ba.   |
| `obsidian_get_active_file`   | Sami path + abun cikin file da ke aiki a halin yanzu a Obsidian.                                 |
| `obsidian_get_periodic_note` | Sami bayanin rubutu na kullum/mako-wata-wata/wata-wata na wata rana (yau idan ba a bayar ba).    |
| `obsidian_get_tags`          | Jera duk tags na vault tare da yawan bayyanarsu.                                                 |
| `obsidian_list_commands`     | Jera IDs na commands na Obsidian da ake da su (a yi amfani da `obsidian_execute_command`).       |
| `obsidian_sync_status`       | Matsayin sync server na OmniRoute: yana gudana, sunan vault, port, uptime, da sync na ƙarshe.    |
| `obsidian_sync_conflicts`    | Jera rikice-rikicen sync da ba a warware ba (path, conflict path, detected-at).                  |

### Kayan aikin rubutawa (`write:obsidian`)

| Kayan aiki                       | Bayani                                                                           |
| -------------------------------- | -------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Ƙirƙira ko sake rubuta bayanin rubutu da abun cikin Markdown da aka bayar.       |
| `obsidian_append_note`           | Ƙara abun ciki zuwa bayanin rubutu; a zaɓe, zuwa takamaiman heading/block.       |
| `obsidian_patch_note`            | Ƙara a ƙarshe/farko ko sauya daidai a heading, block, ko filin frontmatter.      |
| `obsidian_delete_note`           | Goge bayanin rubutu daga vault har abada.                                        |
| `obsidian_move_note`             | Matsar ko sake wa bayanin rubutu suna a cikin vault.                             |
| `obsidian_execute_command`       | Gudanar da command na Obsidian ta command ID ɗinsa.                              |
| `obsidian_open_file`             | Buɗe file a Obsidian (yana ƙirƙirarsa idan babu shi).                            |
| `obsidian_sync_trigger`          | Fara sync mai hanyoyi biyu na desktop↔mobile nan take.                           |
| `obsidian_sync_resolve_conflict` | Warware rikicin sync: riƙe `local` (mobile), `remote` (desktop), ko `keep-both`. |

> [!NOTE]
> Targets na `obsidian_patch_note` suna karɓar `targetType` na `heading | block | frontmatter`
> da `operation` na `append | prepend | replace`, tare da `createTargetIfMissing` na zaɓi.
> Kayan aikin `obsidian_sync_*` guda huɗu suna sadarwa da local sync
> server (`http://127.0.0.1:27781` ta tsohuwa) kuma suna buƙatar sync token.

### Scopes

Kayan aikin karantawa suna buƙatar `read:obsidian`; kayan aikin rubutawa suna buƙatar `write:obsidian`. Tilastawa
daidai yake da na Notion — `withScopeEnforcement()` ne ke sarrafa shi a cikin
`open-sse/mcp-server/server.ts`, ana kunna shi ta `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, tare da
scopes da aka yarda da su daga `OMNIROUTE_MCP_SCOPES` ko scope context na API key. Duba
[MCP-SERVER.md](./MCP-SERVER.md).

## Wuraren Ƙarshe

| Hanya    | Tafarki                         | Manufa                                                            |
| -------- | ------------------------------- | ----------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Mayar da `{ connected, hasToken, baseUrl, vaultPath }`.           |
| `POST`   | `/api/settings/obsidian`        | Ajiye + tabbatar da token (yana ƙin port `27124`).                |
| `DELETE` | `/api/settings/obsidian`        | Cire haɗin (goge token da aka adana).                             |
| `GET`    | `/api/settings/obsidian/webdav` | Matsayin daidaitawar WebDAV + bayanan shiga (yayin da aka kunna). |
| `POST`   | `/api/settings/obsidian/webdav` | Kunna daidaitawar WebDAV don kundin adireshin vault.              |
| `DELETE` | `/api/settings/obsidian/webdav` | Kashe daidaitawar WebDAV.                                         |

> Waɗannan su ne hanyoyin saitunan dashboard. Ana isa ga vault ɗin kansa ta Obsidian
> Local REST API (`base_url` da aka saita) da kuma ta kayan aikin MCP da ke sama — babu
> endpoint na wakilin Obsidian na `/v1` na jama'a.

## Yanayin amfani

- **Amsoshi masu tushe daga vault** — `obsidian_search_simple` / `obsidian_search_structured`
  sannan `obsidian_read_note` domin wakili ya amsa daga ainihin bayanan rubutunka.
- **Rubuta bayanai / kundin yau da kullum** — `obsidian_write_note`, `obsidian_append_note`, ko
  `obsidian_patch_note` mai yin gyara daidai domin rubuta sakamakon wakili, taƙaitawa, ko bayanan yau da kullum
  (`obsidian_get_periodic_note`) cikin vault.
- **Kewaya vault** — `obsidian_list_vault`, `obsidian_get_document_map`, da
  `obsidian_get_tags` don bincika tsari kafin karantawa/rubutawa.
- **Sarrafawar Obsidian ta atomatik** — `obsidian_list_commands` + `obsidian_execute_command` don
  sarrafa plugins/commands daga wakili; `obsidian_open_file` don nuna wani bayani a cikin UI.
- **Daidaitawar wayar hannu** — kunna daidaitawar WebDAV, sannan `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  don daidaita desktop↔mobile da warware rikice-rikice.
