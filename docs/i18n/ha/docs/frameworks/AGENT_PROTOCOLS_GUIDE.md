OmniRoute yana samar da ɓangarori uku daban-daban masu alaƙa da wakilai. Da farko suna iya kama da juna, amma suna magance matsaloli daban-daban. Yi amfani da wannan shafin don zaɓar wanda ya dace.

## A Taƙaice

| Ɓangare                        | Ya fi dacewa da                                                                                                                                           | Hanyar sadarwa                       | Ma'auni                       |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ | ----------------------------- |
| **A2A — Wakili-zuwa-Wakili**   | Haɗin gwiwa tsakanin wakilai da wakilan takwarorinsu waɗanda ke amfani da ƙa'idar A2A                                                                     | JSON-RPC 2.0 ta HTTP                 | A2A v0.3 (buɗaɗɗen ƙayyadewa) |
| **ACP — Rijistar Wakilan CLI** | Gano / yin rajista / ƙaddamar da wakilan shirye-shiryen CLI da aka girka a na'urar mai amfani (Cursor, Cline, Codex CLI, Claude Code, Aider, da sauransu) | HTTP REST                            | Na musamman ga OmniRoute      |
| **Wakilan Cloud**              | Miƙa ayyukan shirye-shirye masu ɗaukar lokaci zuwa sabis na cloud na waje (Codex Cloud, Devin, Jules, Cursor Cloud)                                       | HTTP REST + ayyuka masu amfani da DB | Na musamman ga OmniRoute      |

Dukkan ukun masu zaman kansu ne — zaɓi kowane haɗinsu da kake so.

## Bishiyar Yanke Shawara

```
Kana buƙatar sabis na cloud ya yi aiki a wajen wannan na'urar (Codex Cloud / Cursor Cloud / Devin / Jules)?
├─ EH → Wakilan Cloud (POST /api/v1/agents/tasks)
└─ A'A → Ci gaba
    │
    Kana da wakilin takwara da ke amfani da A2A kuma yake son haɗin gwiwa?
    ├─ EH → A2A (POST /a2a)
    └─ A'A → Ci gaba
        │
        Kana buƙatar jera / saita wakilan shirye-shiryen CLI da aka girka a gida?
        ├─ EH → ACP (GET /api/acp/agents)
        └─ A'A → Yi amfani da /v1/chat/completions kai tsaye
```

## 1. A2A — Wakili-zuwa-Wakili

**Ƙayyadewa:** [A2A v0.3](https://a2a-protocol.org)
**Endpoint na OmniRoute:** `POST /a2a` (JSON-RPC 2.0)
**Katin Wakili:** `GET /.well-known/agent.json`

### Lokacin amfani

- Gina tsarin wakilai da yawa inda OmniRoute yake ɗaya daga cikin takwarorin
- Bayar da basirar turawa ta OmniRoute (smart-routing, quota-management, da sauransu) ga wakilai a cikin frameworks kamar Google ADK ko hanyoyin haɗin wakilai na gama-gari
- Ƙunshe OmniRoute a bayan daidaitacciyar hanyar ganowa + kira

### Hanyoyin aiki

- `message/send` — miƙa saƙo, karɓi amsa ta sync
- `message/stream` — miƙa saƙo + karɓi al'amuran ci gaba da ake watsawa ta SSE
- `tasks/get` — karanta aiki ta ID
- `tasks/cancel` — soke aiki mai gudana

### Ƙwarewar da aka haɗa (6)

- `smart-routing` — tura prompt ta mafi kyawun combo
- `quota-management` — bayar da rahoton yanayin quota na kowane provider
- `provider-discovery` — jera providers da aka girka tare da iyawarsu
- `cost-analysis` — ƙiyasta kuɗin buƙata/tattaunawa
- `health-report` — tattara yanayin breaker/cooldown/lockout na kowane provider
- `list-capabilities` — jera ƙwarewar wakilin da ake da su da metadata

### Cikakken bayani

Duba [A2A-SERVER.md](./A2A-SERVER.md) don cikakkun bayanan hanyar sadarwa, tsarin katin wakili, saitin TTL na aiki, da template na ƙara sababbin ƙwarewa.

## 2. ACP — Rijistar Wakilan CLI

**Endpoint na OmniRoute:** `GET /api/acp/agents`
**Tushe:** `src/lib/acp/{index,manager,registry}.ts`

### Mene ne

ACP shi ne **kundin wakilan CLI na cikin gida** na OmniRoute. Yana gano waɗanne CLI na rubuta lamba aka shigar a kan na'urar mai masaukin baki (Cursor, Cline, Claude Code, Codex CLI, Continue, da sauransu), yana tantance sigoginsu, sannan yana nuna su a dashboard domin mai amfani ya iya saita kowanne CLI ya yi nuni zuwa OmniRoute.

Wannan BA wata ƙa'ida ta waje ba ce — rijista ce ta cikin gida wadda ke sarrafa UI na "CLI Tools" da kuma bin sawun tambarin CLI (duba [CLI-TOOLS.md](../reference/CLI-TOOLS.md)).

### Abin da yake yi

- Yana bincika na'urar mai masaukin baki don gano fayilolin binary na CLI da aka shigar (yana amfani da `which` / `where` gwargwadon OS)
- Yana karanta sigar kowane CLI (yana kiran `<bin> --version`)
- A zaɓe, yana karɓar wakilai na musamman da mai amfani ya ayyana (hanyar binary + binciken siga + hujjojin farawa)
- Yana adana wakilai na musamman a saituna
- Yana mayar da haɗaɗɗen jeri zuwa dashboard

### REST API

| Endpoint          | Hanya | Bayani                                                                  | Tantancewa  |
| ----------------- | ----- | ----------------------------------------------------------------------- | ----------- |
| `/api/acp/agents` | GET   | Jera wakilan da aka gano + na musamman (adadin waɗanda aka shigar/duka) | Mabuɗin API |
| `/api/acp/agents` | POST  | Ƙara/sabunta/cire wakili na musamman (mai bambance action a cikin body) | Mabuɗin API |

Tsarin body na POST (`customAgentBodySchema` a cikin `src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### Yanayin amfani

- Shafin "CLI Tools" na dashboard yana jera abin da aka shigar kuma yana taimaka maka ka sa kowanne ya yi nuni zuwa OmniRoute
- Wakilai na musamman suna ba ƙwararrun masu amfani damar yin rajistar CLI na ciki/na mallaka waɗanda OmniRoute bai san da su ta tsohuwa ba
- Sakamakon ganowa yana samar da bayanai ga matrix ɗin tambari na `cli-tools`

### Lokacin da bai kamata a yi amfani da ACP ba

- ACP ba ya _gudanar da_ ayyuka. Yana gano + saita CLI ne kawai. Don ainihin kiran CLI, kai da kanka ne za ka ƙaddamar da shi tare da env vars da OmniRoute ke bayarwa (`OPENAI_BASE_URL`, `OPENAI_API_KEY`, da sauransu).

## 3. Wakilan Cloud

**Endpoints na OmniRoute:** `/api/v1/agents/tasks/*` (zagayowar rayuwa) + `/api/cloud/*` (haɗin ginin ciki)
**Tushe:** `src/lib/cloudAgent/`

### Mene ne

Haɗaɗɗiyar mahaɗa ce ga wakilan rubuta lamba na cloud daga wasu kamfanoni. Kana aika prompt + URL na repo, OmniRoute ya tura zuwa wakilin cloud da ya dace, ya riƙa duba matsayi, sannan ya mayar da sakamako.

### Wakilan da ake tallafawa (4, duk an tabbatar da su a cikin `src/lib/cloudAgent/agents/`)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### Zagayowar rayuwa

```
POST /api/v1/agents/tasks
  → BaseAgent.createTask() ga kowane ajin wakili
  → sabis na waje ya fara aiki
  → an ƙirƙiri layin aiki a DB (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → daidaita matsayi daga mai bayarwa lokacin da ake buƙata
  → yana mayar da matsayin yanzu + tsari + kundin ayyuka
  ↓
POST /api/v1/agents/tasks/[id]   (action: "approve" | "message" | "cancel")
  → yana tura zuwa mai bayarwa (ko ya sanya alamar an soke a cikin gida)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → sokewa a cikin gida
```

### Tantancewa

⚠️ **Duk endpoints na `/api/v1/agents/tasks/*` suna buƙatar tantancewar gudanarwa** (commit `588a0333`). Masu kira masu amfani da Bearer kawai suna karɓar 401 tun daga v3.8.0.

### Cikakken bayani

Duba [CLOUD_AGENT.md](./CLOUD_AGENT.md) don yarjejeniyar `CloudAgentBase`, takamaiman bayanan kowane wakili, bayanan schema, da endpoints na haɗa bayanan shaida.

## Kwatantawa: A2A da Cloud Agents

Dukansu suna da “ayyuka masu ɗaukar dogon lokaci”, amma a matakai daban-daban:

| Fanni                    | A2A                                                                                  | Cloud Agents                            |
| ------------------------ | ------------------------------------------------------------------------------------ | --------------------------------------- |
| Ma'auni                  | Buɗaɗɗen A2A v0.3                                                                    | Na musamman ga OmniRoute                |
| Inda sarrafawa ke gudana | A cikin OmniRoute (yana amfani da haɗe-haɗen da aka saita)                           | Na waje (sabobin Codex / Devin / Jules) |
| Tsawon aikin             | Tsohon TTL na asali minti 5 (ana iya daidaita shi a cikin `TaskManager`)             | Daga mintuna zuwa awanni                |
| Fahimtar repo            | A'a (yana tura prompts kawai)                                                        | E (URL na repo + branch)                |
| Yanayin amfani           | Haɗin gwiwar agents, samar da smart routing a matsayin sabis                         | Wakilta “aiwatar da feature X a repo Y” |
| Tabbatar da izini        | `OMNIROUTE_API_KEY` na zaɓi ne ga `/a2a`; management ga REST helpers na `/api/a2a/*` | Koyaushe management                     |

## Misalan Haɗawa

### Gano damar A2A na OmniRoute

```bash
curl http://localhost:20128/.well-known/agent.json
```

Yana mayar da Agent Card tare da dukkan skills guda 6, transports, da version.

### Kiran OmniRoute a matsayin A2A agent

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### Jera CLI agents da aka girka ta hanyar ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### Ƙara CLI agent na musamman

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

### Miƙa aikin Cloud Agent

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Implement feature X in repo Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### Duba halin aikin cloud lokaci-lokaci

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```

## Lokacin Amfani da Kowanne

- **Frontend na chatbot / copilot** → `/v1/chat/completions` (mai dacewa da OpenAI — ba agent protocol ba ne)
- **Haɗin gwiwar agents da yawa** → A2A
- **Jera local CLIs a dashboard** → ACP
- **Wakilta ayyukan coding masu ɗaukar dogon lokaci zuwa cloud services** → Cloud Agents
