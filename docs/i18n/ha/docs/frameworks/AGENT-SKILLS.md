> **Tushen gaskiya:** `src/lib/agentSkills/` (kundin bayanai, janareta, masu fassara) + kundin adireshin `skills/` (fayilolin SKILL.md)
> **Sabuntawa ta ƙarshe:** 2026-08-02 — v3.8.50

Agent Skills fayilolin SKILL.md ne masu tsari waɗanda ke koya wa wakilai na waje, abokan cinikin MCP, da masu tsara A2A yadda ake amfani da REST API da CLI na OmniRoute. Ba kamar [Omni Skills](./SKILLS.md) (waɗanda suke ma’anonin kayan aikin LLM da ake aiwatarwa a cikin OmniRoute) ba, Agent Skills _kundin takardu_ ne — markdown tsayayye wanda za a iya shigar da shi kai tsaye cikin mahallin wakili.

---

## Bayanin Gabaɗaya

Kundin ya ƙunshi **Agent Skills 45** (REST API 23 + CLI 21 + tsarin aiki na daidaitawa 1). Kowace fasaha tana da:

- **ID na hukuma** (`omni-auth`, `cli-serve`, da sauransu)
- Fayil ɗin **SKILL.md** a cikin `skills/{id}/SKILL.md` mai YAML frontmatter (`name`, `description`) + cikakken jikin markdown
- **REST endpoints** (fasahohin API) ko **CLI subcommands** (fasahohin CLI) da aka samo daga ƙayyadaddun OpenAPI da rajistar CLI
- **GitHub raw URL** don ɗaukowa kai tsaye: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Gano REST API

| Endpoint                     | Method | Bayani                                                         | Auth      |
| :--------------------------- | :----- | :------------------------------------------------------------- | :-------- |
| `/api/agent-skills`          | GET    | Jera kundin (zaɓi na `?category=api\|cli\|config&area=<area>`) | babu      |
| `/api/agent-skills/{id}`     | GET    | Samo metadata na ƙwarewa guda                                  | babu      |
| `/api/agent-skills/{id}/raw` | GET    | Ɗauko SKILL.md a matsayin `text/markdown`                      | babu      |
| `/api/agent-skills/coverage` | GET    | Ƙididdigar ɗaukar hoto (fayilolin SKILL.md nawa ne suke akwai) | babu      |
| `/api/agent-skills/generate` | POST   | Ƙaddamar da janareta (dryRun/prune/onlyIds)                    | gudanarwa |

Misali — jera duk ƙwarewar API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Misali — ɗauko SKILL.md guda:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Yadda Wakilai na Waje ke Amfani da Skills

### 1. Ganowa ta REST

```bash
# Samo cikakken kundin
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Samo SKILL.md don saka mahalli
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Ganowa ta MCP

```typescript
// A cikin abokin cinikin Claude Desktop / Cursor MCP:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → jeri na AgentSkill tare da rawUrl na kowannensu
```

### 3. Ganowa ta A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table wani tebur ne na markdown mai dukkan ID na skills 45 + ginshiƙan rawUrl
```

### 4. Ɗauko raw kai tsaye daga GitHub (ba a buƙatar sabar)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Mai Ƙirƙirawa

Mai ƙirƙirawa yana karanta kundin da aka tsara + ƙayyadaddun OpenAPI + rajistar CLI sannan ya rubuta `skills/{id}/SKILL.md` ga kowace shigarwa:

```bash
# Samfoti (gwajin bushe, babu rubutawa)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Sake ƙirƙirawa gaba ɗaya
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Sake ƙirƙirar takamaiman ID
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Amsar mai ƙirƙirawa `GeneratorReport` ce:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
