## Cirewa Cikin Sauri (v3.6.2+)

OmniRoute yana samar da rubutattun umarni guda biyu da aka gina a ciki don cirewa cikin tsabta:

### Riƙe Bayananka

```bash
npm run uninstall
```

Wannan yana cire manhajar OmniRoute amma yana **adana** ma'ajiyar bayananka, saitunanka, mabuɗan API, da saitunan masu samarwa a cikin `~/.omniroute/`. Yi amfani da wannan idan kana shirin sake girkawa daga baya kuma kana son riƙe saitunanka.

### Cirewa Gaba Ɗaya

```bash
npm run uninstall:full
```

Wannan yana cire manhajar **kuma yana gogewa har abada** dukkan bayanai:

- Ma'ajiyar bayanai (`storage.sqlite`)
- Saitunan masu samarwa da mabuɗan API
- Fayilolin ajiyar wucin-gadi
- Fayilolin rajista
- Duk fayilolin da ke cikin kundin adireshin `~/.omniroute/`

> ⚠️ **Gargaɗi:** Ba za a iya mayar da abin da `npm run uninstall:full` ya yi ba. Za a goge duk haɗin masu samarwarka, combos, mabuɗan API, da tarihin amfani har abada.

## Cirewa da Hannu

### Girka ta NPM a Dukkan Tsarin

```bash
# Cire fakitin da aka girka a dukkan tsarin
npm uninstall -g omniroute

# (Na zaɓi) Cire kundin adireshin bayanai
rm -rf ~/.omniroute
```

### Girka ta pnpm a Dukkan Tsarin

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Tsayar da kuma cire container
docker stop omniroute
docker rm omniroute

# Cire volume (yana goge dukkan bayanai)
docker volume rm omniroute-data

# (Na zaɓi) Cire image
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Tsayar da kuma cire containers
docker compose down

# Haka kuma cire volumes (yana goge dukkan bayanai)
docker compose down -v
```

### Manhajar Teburin Aiki ta Electron

**Windows:**

- Buɗe `Settings → Apps → OmniRoute → Uninstall`
- Ko gudanar da mai cirewa na NSIS daga kundin adireshin girkawa

**macOS:**

- Ja `OmniRoute.app` daga `/Applications` zuwa Shara
- Cire bayanai: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Cire fayil ɗin AppImage
- Cire bayanai: `rm -rf ~/.omniroute`

### Girka daga Lambar Tushe (git clone)

```bash
# Cire kundin adireshin da aka clone
rm -rf /path/to/omniroute

# (Na zaɓi) Cire kundin adireshin bayanai
rm -rf ~/.omniroute
```

## Kundin Adireshin Bayanai

A tsoho, OmniRoute yana adana bayanai a wurare masu zuwa:

| Dandali     | Tsohuwar Hanya                    | Sauya                            |
| ----------- | --------------------------------- | -------------------------------- |
| Linux       | `~/.omniroute/`                   | canjin muhalli `DATA_DIR`        |
| macOS       | `~/.omniroute/`                   | canjin muhalli `DATA_DIR`        |
| Windows     | `%APPDATA%/omniroute/`            | canjin muhalli `DATA_DIR`        |
| Docker      | `/app/data/` (volume da aka haɗa) | canjin muhalli `DATA_DIR`        |
| Mai bin XDG | `$XDG_CONFIG_HOME/omniroute/`     | canjin muhalli `XDG_CONFIG_HOME` |

### Fayiloli a cikin kundin adireshin bayanai

| Fayil/Kundin Adireshi | Bayani                                                            |
| --------------------- | ----------------------------------------------------------------- |
| `storage.sqlite`      | Babban ma'ajiyar bayanai (masu samarwa, combos, saituna, mabuɗai) |
| `storage.sqlite-wal`  | Rajistar rubutu-gaba ta SQLite (ta wucin-gadi)                    |
| `storage.sqlite-shm`  | Ƙwaƙwalwar gama-gari ta SQLite (ta wucin-gadi)                    |
| `call_logs/`          | Ma'ajiyar payload na buƙatu                                       |
| `backups/`            | Ajiyar ma'ajiyar bayanai ta atomatik                              |
| `log.txt`             | Tsohuwar rajistar buƙatu (na zaɓi)                                |

## Tabbatar da Cikakken Cirewa

Bayan cire shirin, tabbatar cewa babu sauran fayiloli:

```bash
# Duba kunshin npm na global
npm list -g omniroute 2>/dev/null

# Duba kundin bayanai
ls -la ~/.omniroute/ 2>/dev/null

# Duba processes da ke gudana
pgrep -f omniroute
```

Idan har yanzu akwai wani process da ke gudana, dakatar da shi:

```bash
pkill -f omniroute
```
