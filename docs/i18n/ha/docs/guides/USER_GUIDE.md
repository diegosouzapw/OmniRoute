## 🎯 Yanayin Amfani

### Yanayi na 1: "Ina da rajistar Claude Pro"

**Matsala:** Ƙayyadar amfani tana ƙarewa ba tare da an yi amfani da ita ba, sannan ana fuskantar iyakokin sauri yayin yin coding sosai

```
Combo: "maximize-claude"
  1. cc/claude-opus-4-7        (yi amfani da rajistar gaba ɗaya)
  2. glm/glm-4.7               (madadin mai araha idan ƙayyadar ta ƙare)
  3. if/qwen3.8-max-preview       (madadin gaggawa na kyauta)

Kuɗin wata-wata: $20 (rajista) + ~$5 (madadin) = jimillar $25
maimakon $20 + cin karo da iyakoki = takaici
```

### Yanayi na 2: "Ina son babu kuɗi"

**Matsala:** Ba zan iya biyan rajista ba, ina buƙatar AI mai dogaro don yin coding

```
Combo: "zero-cost"
  1. if/kimi-k2.7-code          (an jera samun sa kyauta; ana iya sanya iyakokin sauri)
  2. kr/qwen3-coder-next        (madadin Kiro na kyauta)

Kuɗin wata-wata: $0
Inganci: tabbatar da samfurin, iyakoki, sirri, da SLA don aikin da kake yi
```

### Yanayi na 3: "Ina buƙatar yin coding 24/7, ba tare da tsaiko ba"

**Matsala:** Lokutan ƙarshe sun yi kusa, ba zan iya jure katsewar aiki ba

```
Combo: "always-on"
  1. cc/claude-opus-4-7        (mafi kyawun inganci)
  2. cx/gpt-5.5                (rajista ta biyu)
  3. glm/glm-4.7               (mai araha, yana sabuntawa kullum)
  4. minimax/MiniMax-M2.1      (mafi arha, sabuntawa bayan 5h)
  5. if/deepseek-v4-flash       (an jera samun sa kyauta; ana iya sanya iyakokin sauri)

Sakamako: Matakan madadin 5 suna ƙara juriya; ba a tabbatar da samuwar sabis na sama ba
Kuɗin wata-wata: $20-200 (rajista) + $10-20 (madadin)
```

### Yanayi na 4: "Ina son AI KYAUTA a OpenClaw"

**Matsala:** Ina buƙatar mataimakin AI a manhajojin aika saƙonni, kyauta gaba ɗaya

```
Combo: "openclaw-free"
  1. if/qwen3.8-max-preview     (an jera samun sa kyauta; ana iya sanya iyakokin sauri)
  2. if/deepseek-v4-flash       (an jera samun sa kyauta; ana iya sanya iyakokin sauri)
  3. if/kimi-k2.7-code          (an jera samun sa kyauta; ana iya sanya iyakokin sauri)

Kuɗin wata-wata: $0
Samun dama ta: WhatsApp, Telegram, Slack, Discord, iMessage, Signal...
```

## 📖 Saitin Mai Bayarwa

Don ƙara haɗin maɓallan API da yawa daga fayil ɗin CSV ko JSON, yi amfani da **Dashboard → Providers → Import from file**. Ginshiƙai suna bin matsayi (`provider,name,apiKey,baseUrl,priority`); dole ne `provider` ya riga ya kasance a matsayin mai bayarwa da ake sarrafawa ko kumburi mai jituwa. Duba [Shigo da masu bayarwa daga fayil ɗin CSV ko JSON](../providers/CSV-IMPORT.md).

### 🔐 Masu Bayarwa na Biyan Kuɗin Rajista

#### Claude Code (Pro/Max)

```bash
Dashboard → Providers → Haɗa Claude Code
→ Shiga ta OAuth → Sabunta token ta atomatik
→ Bibiyar ƙa'idar amfani ta awa 5 + mako-mako

Samfura:
  cc/claude-opus-4-7
  cc/claude-sonnet-4-6
  cc/claude-haiku-4-5-20251001
```

**Shawarar Kwararre:** Yi amfani da Opus don ayyuka masu rikitarwa, Sonnet kuma don sauri. OmniRoute yana bibiyar ƙa'idar amfani ga kowane samfuri!

Hanyoyin da suka dace da Claude da Claude Code suna kiyaye matakin ƙoƙarin tunani na `max` don samfuran Opus da Sonnet. Samfuran Haiku ba sa karɓar matakin ƙoƙarin `max`, saboda haka OmniRoute yana saukar da wannan buƙatar zuwa babban kasafin tunani kafin aika ta zuwa sabis na sama.

#### OpenAI Codex (Plus/Pro)

```bash
Dashboard → Providers → Haɗa Codex
→ Shiga ta OAuth (port 1455)
→ Sake saiti bayan awa 5 + mako-mako

Samfura:
  cx/gpt-5.5
  cx/gpt-5.4
  cx/gpt-5.3-codex
  cx/gpt-5.3-codex-spark
```

#### GitHub Copilot

```bash
Dashboard → Providers → Haɗa GitHub
→ OAuth ta GitHub
→ Sake saiti kowane wata (ranar 1 ga wata)

Samfura:
  gh/gpt-5.5
  gh/gpt-5.4
  gh/claude-sonnet-4.6
  gh/claude-opus-4.7
  gh/gemini-3.1-pro-preview
```

### 💰 Masu Bayarwa Masu Arha

#### GLM-4.7 (Sake saiti kullum, $0.6/1M)

1. Yi rajista: [Zhipu AI](https://open.bigmodel.cn)
2. Sami maɓallin API daga Coding Plan
3. Dashboard → Ƙara Maɓallin API: Mai Bayarwa: `glm`, Maɓallin API: `your-key`

**Amfani:** `glm/glm-4.7` — **Shawarar Kwararre:** Coding Plan yana bayar da ƙa'idar amfani sau 3 a farashi 1/7! Ana sake saiti kullum da ƙarfe 10:00 na safe.

1. Yi rajista: [MiniMax](https://www.minimax.io)
2. Sami maɓallin API → Dashboard → Ƙara Maɓallin API

**Amfani:** `minimax/MiniMax-M2.1` — **Shawarar Kwararre:** Zaɓi mafi arha don dogon mahalli (token miliyan 1)!

#### Kimi K2 ($9/wata tsayayye)

1. Yi rajistar biyan kuɗi: [Moonshot AI](https://platform.kimi.ai?aff=omniroute)
2. Sami maɓallin API → Dashboard → Ƙara Maɓallin API

**Amfani:** `kimi/kimi-k2.5` — **Shawarar Kwararre:** Tsayayyen $9/wata don token miliyan 10 = ainihin farashin $0.90/1M!

#### Baidu Qianfan / ERNIE

1. Yi rajista: [Baidu AI Cloud Qianfan](https://cloud.baidu.com/product/wenxinworkshop)
2. Ƙirƙiri maɓallin API na Qianfan → Dashboard → Ƙara Maɓallin API: Mai Bayarwa: `qianfan`

**Amfani:** `qianfan/ernie-5.1`, `qianfan/ernie-x1.1`, ko wani ID na samfurin Qianfan mai jituwa da OpenAI.


## 🔧 Haɗawar CLI

### Cursor IDE

**Amfani da Cursor a matsayin abokin cinikin OmniRoute** (bi da tattaunawar Cursor ta OmniRoute):

```
Settings → Models → Advanced:
  OpenAI API Base URL: http://localhost:20128/v1
  OpenAI API Key: [daga dashboard na omniroute]
  Model: cc/claude-opus-4-7
```

**Amfani da OmniRoute a matsayin mai samar da Cursor** (OmniRoute yana kiran Cursor na sama): fi son
**Dashboard → Providers → Cursor → Login with Cursor**. A Docker, duba
[`docs/providers/CURSOR-DOCKER.md`](../providers/CURSOR-DOCKER.md).

### Claude Code

Gyara `~/.claude/settings.json`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128",
    "ANTHROPIC_AUTH_TOKEN": "your-omniroute-api-key"
  }
```


abokin ciniki idan an gaza domin samuwar active/passive ko active/active, kuma kada a taɓa ɗora rumbun bayanan SQLite guda ɗaya

### Juriya & Circuit Breakers

Saita ta hanyar **Dashboard → Settings → Resilience**.

OmniRoute yana aiwatar da juriya a matakin provider ta amfani da sassa biyar:

1. **Jerin Jira na Buƙatu & Daidaita Sauri** — Tsara buƙatu a matakin tsarin:
   - **Buƙatu a Kowane Minti (RPM)** — Matsakaicin adadin buƙatu a kowane minti ga kowane asusu
   - **Mafi Ƙarancin Lokaci Tsakanin Buƙatu** — Mafi ƙarancin tazara a milliseconds tsakanin buƙatu
   - **Matsakaicin Buƙatun Lokaci Guda** — Matsakaicin buƙatun da za a iya gudanarwa lokaci guda ga kowane asusu

2. **Connection Cooldown** — Saiti na kowane nau'in auth ga connection guda bayan gazawar da za a iya sake gwadawa:
   - **Base Cooldown** — Tsohuwar cooldown window ga gazawar upstream da za a iya sake gwadawa
   - **Amfani da Upstream Retry Hints** — Yana bin sahihan `Retry-After` ko reset hints idan an samar da su
   - **Matsakaicin Matakan Backoff** — Matsakaicin matakin exponential backoff ga gazawar da ke maimaituwa

3. **Provider Circuit Breaker** — Yana bibiyar gazawar provider daga farko zuwa ƙarshe, yana sanya provider a matsayin degraded idan an kai warning threshold da aka saita, sannan ya buɗe breaker idan an kai failure threshold da aka saita:
   - **Degradation Threshold** — Yawan gazawar provider a jere kafin shiga `DEGRADED`
   - **Failure Threshold** — Yawan gazawar provider a jere kafin shiga `OPEN`
   - **Reset Timeout** — Tsawon lokacin jira kafin a sake gwada provider
   - **CLOSED** (Lafiya) — Buƙatu suna gudana yadda aka saba
   - **DEGRADED** — Buƙatu suna ci gaba da gudana yayin da ake bibiyar ƙaruwar gazawa
   - **OPEN** — An toshe provider na ɗan lokaci bayan gazawa mai maimaituwa
   - **HALF_OPEN** — Ana gwada ko provider ya farfaɗo

   Rate limits na `429` da suka shafi connection kawai suna kasancewa a cikin **Connection Cooldown** kuma ba a ƙirga su a cikin provider breaker.

   Ana nuna runtime state na provider breaker a **Dashboard → Health** kawai.

4. **Jiran Cooldown** — Idan duk candidate connections sun riga sun shiga cooldown, OmniRoute zai iya jira cooldown mafi kusa sannan ya sake gwada wannan client request kai tsaye.

5. **Gano Rate Limit Kai Tsaye** — Idan upstream providers sun dawo da takamaiman wait windows, waɗannan hints suna maye gurbin local connection cooldown idan an kunna wannan saitin.

**Shawarar Ƙwararru:** Yi amfani da shafin **Health** domin dubawa da reset na live provider breakers bayan outage. Shafin Resilience yana sauya saituna kawai.

### Dabarun Daidaita Combo

Saita daidaitawar kowane combo a **Dashboard → Combos → Ƙirƙira/Gyara → Dabara**.

| Dabara             | Bayani                                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **Round-Robin**    | Yana zagayawa ta cikin samfura bi-da-bi                                                                              |
| **Priority**       | Koyaushe yana fara gwada samfurin farko; yana komawa wani ne kawai idan an samu kuskure                              |
| **Random**         | Yana zaɓar samfur bazuwar daga combo don kowace buƙata                                                               |
| **Weighted**       | Yana karkatar da buƙatu gwargwadon nauyin da aka ware wa kowane samfur                                               |
| **Least-Used**     | Yana karkatar da buƙata zuwa samfurin da ke da mafi ƙarancin buƙatun baya-bayan nan (yana amfani da ma’aunin combo)  |
| **Cost-Optimized** | Yana karkatar da buƙata zuwa samfurin da ya fi araha daga cikin waɗanda ake da su (yana amfani da jadawalin farashi) |

Ana iya saita tsoffin ƙimomin combo na gaba ɗaya a **Dashboard → Settings → Routing → Combo Defaults**.
A tsoho, wa’adin ƙarewar lokacin maƙasudin combo yana gādo wa’adin ƙarewar lokacin buƙata na yanzu. Yi amfani da **Target timeout
(seconds)** a tsoffin ƙimomin combo ko a kan combo guda ɗaya kawai idan ya kamata gajeren iyakar lokaci ga kowane maƙasudi
ya jawo saurin komawa madadin.

Ingantawar combo mai rashin jinkiri sai an zaɓi amfani da ita. Bar **Zero-latency optimizations** a kashe don
hana waɗannan fasalolin jinkiri yin tsere da maƙasudan komawa madadin, tsallake maƙasudai bisa tarihin TTFT,
ko matse buƙatun komawa madadin; kunna ta yana ba da damar amfani da hedging da aka saita, tsallakewa bisa hasashen TTFT,
da matse komawa madadin tun da wuri, domin musanya daidaiton karkatarwa/buƙata da rage jinkirin ƙarshen lokaci.

Kashe **Reasoning token buffer** lokacin da masu samarwa na upstream ke buƙatar tsauraran iyakokin
`max_tokens` / `maxOutputTokens`. Idan an kunna, karkatarwar combo tana ƙara sararin token na samfurin tunani
kawai ga samfuran da ke da sananniyar iyakar fitarwa, kuma tana barin iyakar token ta abokin ciniki ba tare da canji ba idan
amintacciyar ƙimar da aka ƙara buffer za ta wuce wannan iyaka. Idan iyakar abokin ciniki ta riga ta fi sananniyar iyaka,
OmniRoute yana rage ta zuwa wannan iyakar kafin aika buƙatar upstream.

## 🤖 Zaɓin Hanya ta Atomatik (Ba tare da saiti ba)

OmniRoute yana zuwa da **mai zaɓin hanya ta atomatik bisa maki** wanda ke zaɓar mafi kyawun model ga kowace buƙata daga dukkan provider da aka haɗa — babu combo da za a riƙa kulawa da shi. Kawai aika buƙatar da ɗaya daga cikin prefix na `auto/*`, sannan OmniRoute zai haɗa virtual combo nan take, yana ba wa candidates maki bisa latency, cost, success rate, dacewar context, dacewar model da aikin, failures na baya-bayan nan, quota, da yanayin circuit-breaker.

| Prefix         | Abin da yake ingantawa                                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`         | Daidaitaccen tsohon zaɓi (latency × cost × success rate)                                                                              |
| `auto/coding`  | Ayyukan coding: yana fifita Claude, GPT-5, GLM, Kimi, Qwen Coder, DeepSeek coders                                                     |
| `auto/cheap`   | Mafi ƙarancin $/token, yana yarda da latency mafi girma                                                                               |
| `auto/fast`    | Mafi ƙarancin latency, yana yin watsi da cost                                                                                         |
| `auto/offline` | Provider na cikin gida kawai (Ollama, vLLM, llama.cpp) — yana da amfani ga saitunan air-gapped                                        |
| `auto/smart`   | Ingancin reasoning da farko (Opus, GPT-5 xhigh, R1, GLM 5.1 reasoning)                                                                |
| `auto/lkgp`    | "Provider na Ƙarshe da Aka San Yana Aiki" — yana manne wa provider na ƙarshe da ya yi nasara, sannan ya koma ga ƙa’idoji idan ya gaza |

Misali:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer $OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto/coding",
    "messages": [{ "role": "user", "content": "Sake tsara wannan Python function" }],
    "stream": true
  }'
```

An yi cikakken bayanin mai zaɓin hanya ta atomatik a cikin [AUTO-COMBO.md](../routing/AUTO-COMBO.md) — har da yadda ake daidaita scoring weights, saka provider cikin blacklist, da duba shawarwarin routing a **Dashboard → Auto Combo**.

## 🔌 Haɗin MCP & A2A

OmniRoute duka **MCP server** ne (Model Context Protocol) kuma **A2A server** ne (Agent-to-Agent JSON-RPC 2.0). Duk wani IDE ko agent host da ya dace da MCP zai iya kiran kayan aikin OmniRoute kai tsaye — ba a buƙatar ƙarin wrapper.

### MCP transports

- **SSE**: `http://localhost:20128/api/mcp/sse`
- **Streamable HTTP**: `http://localhost:20128/api/mcp/stream`
- **stdio**: `omniroute --mcp` (ga IDE plugins da suka fi son stdio)

### Haɗa Claude Desktop

Gyara `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) ko makamancinsa a Windows/Linux:

```json
{
  "mcpServers": {
    "omniroute": {
      "command": "omniroute",
      "args": ["--mcp"]
    }
  }
}
```

### Haɗa Cursor / Continue / VS Code MCP

Yi amfani da SSE URL `http://localhost:20128/api/mcp/sse` da Bearer API key da aka ƙirƙira a **Dashboard → API Keys**.

### Scopes

A halin yanzu MCP yana ayyana scopes 32 masu suna. Ana iya iyakance kowace Bearer key zuwa takamaiman scopes — duba [MCP-SERVER.md](../frameworks/MCP-SERVER.md) don tabbataccen jerin scope da tool, da kuma [A2A-SERVER.md](../frameworks/A2A-SERVER.md) don JSON-RPC schema.

## 🔔 Webhooks

Yi rajista ga abubuwan da ke faruwa a OmniRoute domin sa ido da sarrafa ayyuka ta atomatik a ainihin lokaci.

- Ƙirƙiri webhook a **Dashboard → Webhooks** tare da URL na manufa da sirrin sa hannun HMAC

- Sake gwadawa: yunƙuri 3 tare da ƙarin jinkiri a hankali, sannan a tura zuwa jerin saƙonnin da suka gaza

## 🛠️ Gudanarwa ta Shirye-shirye

Kuna iya sarrafa kowane albarkatun OmniRoute (providers, combos, keys, settings) ta HTTP ta amfani da **maɓallin Bearer mai scope na `manage`**.

Samar da maɓallin a **Dashboard → API Keys → New Key → Scope: manage**, sannan:

```bash
# Jera providers
curl http://localhost:20128/api/providers \
  -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY"

# Ƙara haɗin provider
curl -X POST http://localhost:20128/api/providers \
  -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "provider": "openai", "apiKey": "sk-...", "name": "main" }'

# Ƙirƙiri combo
curl -X POST http://localhost:20128/api/combos \
  -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "premium", "strategy": "priority", "models": [{ "model": "cc/claude-opus-4-7" }, { "model": "glm/glm-5.1" }] }'

# Jera/ƙirƙiri maɓallan API
curl http://localhost:20128/api/keys -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY"
curl -X POST http://localhost:20128/api/keys -H "Authorization: Bearer $OMNIROUTE_MANAGE_KEY" \
  -d '{ "name": "ci-bot", "scopes": ["chat"] }'
```

Duba [API_REFERENCE.md](../reference/API_REFERENCE.md) don cikakken kundin endpoints da schemas na request/response.

## 💻 CLI na Ciki

OmniRoute yana zuwa da CLI na ciki (`omniroute …`) don saiti, binciken matsaloli, da sarrafa lokacin aiki. Wannan **ya bambanta da shafin "CLI Tools" da ke cikin dashboard**, wanda yake saita CLI na wasu kamfanoni (Claude Code, Cursor, Codex, Cline, …) domin su iya sadarwa da OmniRoute.

```bash
omniroute setup                    # Jagorar saiti mai mu'amala (kalmar sirri, masu samarwa, haɗe-haɗe)
omniroute setup --non-interactive  # Ya dace da CI
omniroute doctor                   # Binciken lafiya (kundin bayanai, DB, masu samarwa, tashoshin jiragen ruwa)
omniroute providers available      # Nuna masu samarwa da ake tallafawa
omniroute providers list           # Nuna haɗin da aka saita
omniroute providers test <id>      # Gwada haɗin mai samarwa kai tsaye
omniroute combos list              # Nuna haɗe-haɗe
omniroute combos switch <name>     # Saita haɗin tsoho
omniroute models                   # Nuna samfuran da ake da su (--json, --search)
omniroute keys add | list | remove # Sarrafa maɓallan API daga terminal
omniroute backup                   # Ɗauki hoton config + DB
omniroute restore [<timestamp>]    # Mayar da bayanai daga hoton ajiya
omniroute health                   # Cikakken bayani kan lafiya (breakers, cache, memory)
omniroute quota                    # Amfani da ƙayyadadden kaso na mai samarwa
omniroute mcp status               # Matsayin uwar garken MCP
omniroute a2a status               # Matsayin uwar garken A2A
omniroute tunnel list|create|stop  # Tunnels na Cloudflare/Tailscale/ngrok
omniroute reset-password           # Sake saita kalmar sirrin mai gudanarwa
omniroute --mcp                    # Fara uwar garken MCP ta stdio
omniroute --port 3000              # Fara uwar garken a tashar jirgin ruwa ta musamman
```

Shawara: haɗa `omniroute doctor --json` da kayan aikinka na sa ido domin samun faɗakarwa idan haɗin masu samarwa ba su da lafiya.
