OmniRoute na zuwa da zaɓaɓɓun proxies na kyauta a cikin teburin `free_proxies`,
waɗanda ake daidaita su daga masu samarwa na waje (1proxy, proxifly, iplocate, webshare).
Dashboard yana nuna su a ƙarƙashin **Settings → Free Proxies**. Wannan takarda
tana bayani kan tacewa, jerewa, ƙirgawa, da bayar da rahoton kurakuran daidaitawa
a ɓangaren sabar waɗanda hanyar jeri ke samarwa.

## Hanyar jeri — `GET /api/settings/free-proxies`

Tana dawo da wani ɓangare da aka tace, aka jera, kuma aka raba zuwa shafuka tare da
jimillar adadi. Tacewa da ƙirgawa suna gudana a cikin SQL, don haka UI zai iya nuna
ainihin jimilla (misali `Total: 0`) ba tare da loda kowane layi zuwa ƙwaƙwalwa ba.

### Sigogin tambaya

| Param             | Type                               | Default   | Meaning                                                                                                                                           |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`      | `LIKE` mai kula da bambancin manyan da ƙananan haruffa a kan ginshiƙin host (da source).                                                          |
| `protocol`        | string                             | `""`      | Tacewar `type`: `http` / `https` / `socks4` / `socks5`. Babu ƙima = duka.                                                                         |
| `country`         | string                             | `""`      | Tacewar `countryCode` (ISO-2). Babu ƙima = duka.                                                                                                  |
| `minQuality`      | number                             | `0`       | Layukan da suke da `qualityScore >= minQuality` kawai. `0` = babu mafi ƙarancin iyaka.                                                            |
| `disabledSources` | string                             | `""`      | Ids na sources da aka raba da waƙafi waɗanda za a cire (misali `proxifly,webshare`).                                                              |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = maki daga babba zuwa ƙasa; `latency` = latency daga ƙasa zuwa sama (nulls a ƙarshe); `recent` = `lastValidated` daga sabo zuwa tsoho. |
| `offset`          | number                             | `0`       | Farkon rarrabawa zuwa shafuka.                                                                                                                    |
| `limit`           | number                             | `50`      | Girman shafi (ana sanya iyakar sa a ɓangaren sabar).                                                                                              |

### Amsa

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 daga upstream"],
    "webshare": ["lokacin jiran network ya ƙare"]
  }
}
```

`total` yana nuna jimillar da aka tace **kafin** rarrabawa zuwa shafuka, don haka UI
zai iya nuna `Total: N` da `hasMore` daban-daban. Ana tsara `syncErrors` ta source id,
kuma ana cika shi ne kawai ga sources da daidaitawarsu ta ƙarshe ta gaza — sakamakon
`Total: 0` ba ya taɓa kasancewa ba tare da bayani ba.

## Ƙarawa zuwa pool — `POST /api/settings/free-proxies/[id]/add-to-pool`

Yana ɗaukaka proxy na kyauta zuwa pool ɗin `proxy_registry` da ake gudanarwa. Da farko
yana tabbatar da ingancin upstream; idan an yi nasara, yana dawo da sabon pool proxy id
da latency da aka auna.

## Daidaitawa — `POST /api/settings/free-proxies/sync`

Yana sake ɗauko duk sources da aka kunna (ko kuma zaɓaɓɓun da ke cikin
`{ "sources": [...] }`). Kowane source yana daidaitawa da kansa; ana rubuta source
da ya gaza a cikin `syncErrors`, yayin da sauran suke ci gaba har su kammala, don haka
daidaitawa ta wani ɓangare ba ta taɓa goge ingantattun bayanan da ake da su.

## Ƙididdiga — `GET /api/settings/free-proxies/stats`

Yana dawo da jimillar `total / inPool / avgQuality / bySource / lastSyncAt`
ba tare da bayanan layuka ba — widget ɗin saman dashboard ne ke amfani da shi.
