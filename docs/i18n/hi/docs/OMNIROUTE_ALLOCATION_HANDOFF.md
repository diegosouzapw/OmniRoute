आवंटन प्रदाता कोटा नहीं है।

कोटा पूल निर्धारित करते हैं कि कौन-सी API कुंजियाँ किसी प्रदाता पूल का उपयोग कर सकती हैं और हार्ड, सॉफ्ट या बर्स्ट नीतियाँ कैसे लागू होती हैं। प्रदाता कोटा किसी प्रदाता द्वारा रिपोर्ट की गई बाहरी क्षमता या स्पष्ट रूप से कॉन्फ़िगर किए गए स्रोत से प्राप्त क्षमता है। Ghostlight के आंतरिक बजट व्यवस्थापक द्वारा निर्धारित गवर्नेंस सीमाएँ हैं।

`ensurePool` ऑपरेशन आइडेम्पोटेंट है: समान पूल अपरिवर्तित रहता है, बदला हुआ आवंटन अपडेट किया जाता है, और अनुपस्थित पूल बनाया जाता है। यह ऑटोमेशन और सीमित API कॉलर्स के लिए अभिप्रेत है।

केवल-पठन स्थिति एंडपॉइंट `GET /api/omniroute/status` है। सत्यापन कमांड `npm run omniroute:verify` है; यह कोई लाइव मॉडल अनुरोध नहीं करता।
