> **संक्षेप में**: इंस्टॉल करें → कोई मुफ़्त प्रदाता कनेक्ट करें → अपने IDE को OmniRoute की ओर निर्देशित करें। बस हो गया।

---

## चरण 1: OmniRoute इंस्टॉल करें

अपनी पसंदीदा विधि चुनें:

### विकल्प A: npm (अनुशंसित)

```bash
npm install -g omniroute
```

### विकल्प B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` उच्चतम **प्रकाशित** स्थिर SemVer है। यह git `main` को ट्रैक **नहीं** करता। GitOps के लिए `diegosouzapw/omniroute:X.Y.Z` को पिन करें। [इमेज टैग / रिलीज़ चैनल](../guides/DOCKER_GUIDE.md#release-channels) देखें।

### विकल्प C: स्रोत से

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## चरण 2: OmniRoute शुरू करें

```bash
omniroute
```

OmniRoute `http://localhost:20128` पर शुरू होता है। डैशबोर्ड अपने-आप खुल जाता है।

---

## चरण 3: कोई मुफ़्त प्रदाता कनेक्ट करें

आप किसी मुफ़्त प्रदाता को कनेक्ट करके OmniRoute का उपयोग **बिना कोई भुगतान किए** कर सकते हैं।

### विकल्प A: Kiro (मुफ़्त Claude — क्रेडिट कार्ड की आवश्यकता नहीं)

1. `http://localhost:20128` पर डैशबोर्ड खोलें
2. **Providers** → **Add Provider** पर जाएँ
3. **Kiro AI** चुनें
4. **Connect** पर क्लिक करें (API कुंजी की आवश्यकता नहीं!)
5. हो गया! अब आपके पास Claude मॉडल का मुफ़्त एक्सेस है।

### विकल्प B: OpenCode Free (प्रमाणीकरण की आवश्यकता नहीं)

1. `http://localhost:20128` पर डैशबोर्ड खोलें
2. **Providers** → **Add Provider** पर जाएँ
3. **OpenCode Free** चुनें
4. **Connect** पर क्लिक करें (API कुंजी की आवश्यकता नहीं!)
5. हो गया! अब आपके पास कई मॉडल का मुफ़्त एक्सेस है।

### विकल्प C: Pollinations (कुंजी की आवश्यकता नहीं)

1. `http://localhost:20128` पर डैशबोर्ड खोलें
2. **Providers** → **Add Provider** पर जाएँ
3. **Pollinations** चुनें
4. **Connect** पर क्लिक करें (API कुंजी की आवश्यकता नहीं!)
5. हो गया! अब आपके पास GPT-5, Claude, Gemini और अन्य मॉडल का मुफ़्त एक्सेस है।

## चरण 4: सत्यापित करें कि यह काम कर रहा है

[API Keys](http://localhost:20128/dashboard/api-manager) से एक नई कुंजी बनाएँ। इस कुंजी को सुरक्षित रखें, क्योंकि यह दोबारा दिखाई नहीं देगी। ध्यान दें कि यह कुंजी टूल द्वारा OmniRoute को एक्सेस करने के लिए है, अपस्ट्रीम प्रदाताओं को एक्सेस करने के लिए नहीं।

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

आपको कनेक्ट किए गए मॉडल सूचीबद्ध दिखाई देने चाहिए।

## चरण 5: अपने IDE या CLI को OmniRoute की ओर निर्देशित करें

अपने IDE या CLI टूल में यह सेट करें:

```
आधार URL: http://localhost:20128/v1
API कुंजी: [Dashboard → Endpoints से कॉपी करें]
मॉडल:      auto
```

बस हो गया! अब आपका IDE स्वचालित प्रदाता चयन के साथ OmniRoute का उपयोग करता है।

### IDE उदाहरण: VSCode/Continue.dev

1. VSCode में [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) एक्सटेंशन इंस्टॉल करें।
2. निम्नलिखित पंक्तियाँ जोड़ने के लिए अपनी `~/.continue/config.yaml` फ़ाइल अपडेट करें:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev चैट पेन में `OmniRoute - Auto` चुनें, जिसके बाद आपके अनुरोध OmniRoute को भेजे जाएँगे।
4. (वैकल्पिक) पाठक के लिए अभ्यास—अपने IDE से `config.yaml` को अन्य सभी पहले से तैयार कॉन्फ़िगरेशन के साथ अपडेट करवाएँ 😊

### CLI उदाहरण: Codex CLI

1. अपने ऑपरेटिंग सिस्टम में पर्यावरण चर को स्थायी रूप से सेट करें।
   macOS/Linux के लिए (अपनी `~/.bashrc` या `~/.zshrc` में जोड़ें):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows (Command Prompt) के लिए:

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. अब Codex शुरू करते हैं, लेकिन इसे OmniRoute के लिए कॉन्फ़िगर करके। चलाएँ:

```
omniroute launch-codex --model auto
```

एंडपॉइंट और API कुंजी निर्दिष्ट करने के लिए आप `codex` और कमांड-लाइन पैरामीटर के माध्यम से यह काम मैन्युअल रूप से कर सकते हैं, लेकिन ऊपर दिए गए कमांड से OmniRoute आपके लिए सब कुछ संभालता है।

यही एक-कमांड लॉन्च सामान्य लॉन्चर के माध्यम से अन्य CLI के लिए भी काम करता है—`omniroute run <target>` में `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, और `gemini` समर्थित हैं ([CLI एकीकरण](../guides/CLI-INTEGRATIONS.md) देखें)।

3. अब CLI को OmniRoute पर अनुरोध भेजने चाहिए।

### पुष्टि करें कि आपका टूल OmniRoute पर रूट कर रहा है

आप बाईं साइडबार से [Monitoring/Logs](http://localhost:20128/dashboard/logs) पर क्लिक करके अनुरोध का विवरण देख सकते हैं। आगे क्लिक करने पर आपको अधिक विवरण दिखाई देंगे। इसके अतिरिक्त, आप देख सकते हैं कि आपके पसंदीदा हार्नेस से कौन-सी जानकारी भेजी जाती है। यह सीखने और डीबगिंग के दृष्टिकोण से उपयोगी है।

## सामान्य प्रश्न

### "क्या मुझे API कुंजी की आवश्यकता है?"

**नहीं!** आप बिना किसी API कुंजी के मुफ़्त प्रदाताओं (Kiro, OpenCode Free, Pollinations) का उपयोग कर सकते हैं। बस उन्हें डैशबोर्ड में कनेक्ट करें।

### "`auto` क्या है?"

`auto` OmniRoute को प्रत्येक अनुरोध के लिए अपने-आप सर्वश्रेष्ठ प्रदाता चुनने का निर्देश देता है। यह गति, लागत, गुणवत्ता और उपलब्धता पर विचार करता है। विवरण के लिए [Auto-Combo मार्गदर्शिका](./AUTO-COMBO-GUIDE.md) देखें।

### "इसकी लागत कितनी है?"

OmniRoute स्वयं **मुफ़्त और ओपन-सोर्स** है। आपको केवल उपयोग किए जाने वाले प्रदाताओं के लिए भुगतान करना होता है। कई प्रदाताओं के मुफ़्त टियर उपलब्ध हैं—[मुफ़्त टियर मार्गदर्शिका](./FREE-TIERS-GUIDE.md) देखें।

### "क्या मैं इसे Claude Code / Cursor / Copilot के साथ उपयोग कर सकता हूँ?"

**हाँ!** OmniRoute OpenAI प्रारूप का समर्थन करने वाले किसी भी टूल के साथ काम करता है। बस आधार URL को `http://localhost:20128/v1` पर सेट करें। विशिष्ट सेटअप निर्देशों के लिए [CLI टूल मार्गदर्शिका](../reference/CLI-TOOLS.md) देखें।

### "अगर कोई प्रदाता बंद हो जाए तो क्या होगा?"

OmniRoute विफल प्रदाताओं को अपने-आप छोड़ देता है और अगले प्रदाता को आज़माता है। आपको कुछ भी करने की आवश्यकता नहीं है। विवरण के लिए [Auto-Combo मार्गदर्शिका](./AUTO-COMBO-GUIDE.md) देखें।
