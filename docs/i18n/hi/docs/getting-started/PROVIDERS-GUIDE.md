## प्रोवाइडर क्या है?

प्रोवाइडर को एक **फ़ोन कैरियर** की तरह समझें। जैसे कॉल करने के लिए आपको फ़ोन कैरियर की आवश्यकता होती है, वैसे ही AI मॉडल का उपयोग करने के लिए आपको AI प्रोवाइडर की आवश्यकता होती है। OmniRoute एक ऐसे फ़ोन की तरह है जो **सभी कैरियर** के साथ काम करता है — आप उनके बीच स्वचालित रूप से स्विच कर सकते हैं।

### प्रोवाइडर के प्रकार

| प्रकार        | यह क्या है                          | उदाहरण                            | लागत                            |
| ------------- | ----------------------------------- | --------------------------------- | ------------------------------- |
| **निःशुल्क**  | किसी भुगतान की आवश्यकता नहीं        | Kiro, OpenCode Free, Pollinations | $0                              |
| **API कुंजी** | आपको एक API कुंजी चाहिए             | OpenAI, Anthropic, Google         | उपयोग के अनुसार भुगतान          |
| **OAuth**     | अपने खाते से लॉगिन करें             | Claude Code, GitHub Copilot       | सदस्यता                         |
| **वेब कुकी**  | आपके ब्राउज़र सत्र का उपयोग करता है | ChatGPT Web (Codex), Gemini Web   | $0 (आपके खाते का उपयोग करता है) |

### वेब कुकी प्रोवाइडर

सामान्य सेटअप निर्देशों, सीमाओं, समस्या-निवारण और प्रोवाइडर-विशिष्ट प्रमाणीकरण मार्गदर्शन के लिए **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** देखें।

## त्वरित शुरुआत: अपना पहला प्रोवाइडर कनेक्ट करें

### पहली बार के लिए वैकल्पिक निःशुल्क-प्रोवाइडर सेटअप

पहली बार चलने वाला विज़ार्ड एक स्पष्ट **निःशुल्क प्रोवाइडर सेट अप करें** कार्ड प्रदान करता है। यह OmniRoute की बिना-प्रमाणीकरण वाली प्रोवाइडर रजिस्ट्री से वर्तमान
पात्र सूची प्राप्त करता है, फिर पुष्टि करने से पहले आपको प्रत्येक
प्रोवाइडर की समीक्षा करने और उसका चयन हटाने देता है। OmniRoute प्रोवाइडर की सावधानी संबंधी सूचना और उसकी साइट का लिंक दिखाता है,
ताकि आप पहले तृतीय-पक्ष की शर्तों, गोपनीयता, उपलब्धता और दर सीमाओं की समीक्षा कर सकें।

यह क्रिया वैकल्पिक है: विज़ार्ड पूरा करने पर निःशुल्क-प्रोवाइडर कनेक्शन कभी भी चुपचाप नहीं बनाए जाते।
यह केवल उन्हीं प्रोवाइडर को बनाता है जो अभी भी अनुपस्थित हैं, मौजूदा अनुकूलित कनेक्शन को
अपरिवर्तित छोड़ता है, और बनाए गए, पहले से कॉन्फ़िगर किए गए तथा विफल प्रोवाइडर की अलग-अलग रिपोर्ट देता है। आंशिक परिणाम के बाद आप
केवल विफल प्रोवाइडर के लिए सुरक्षित रूप से पुनः प्रयास कर सकते हैं।

### विकल्प A: निःशुल्क प्रोवाइडर (क्रेडिट कार्ड की आवश्यकता नहीं)

1. `http://localhost:20128` पर डैशबोर्ड खोलें
2. **प्रोवाइडर** → **प्रोवाइडर जोड़ें** पर जाएँ
3. इन निःशुल्क प्रोवाइडर में से किसी एक को चुनें:
   - **Kiro AI** — निःशुल्क Claude मॉडल (प्रमाणीकरण आवश्यक नहीं)
   - **OpenCode Free** — निःशुल्क GPT मॉडल (प्रमाणीकरण आवश्यक नहीं)
   - **Pollinations** — निःशुल्क GPT-5, Claude, Gemini (कुंजी आवश्यक नहीं)
   - **LongCat** — 10M टोकन निःशुल्क (एकमुश्त अनुदान, खाता + KYC आवश्यक)
   - **Cloudflare AI** — 50+ मॉडल, 10K न्यूरॉन/दिन
   - **MLX Gemma 26B** — स्थानीय Apple Silicon मॉडल (~38.5 टोकन/सेकंड, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — स्थानीय Apple Silicon मॉडल (~9.1 टोकन/सेकंड, ~13.1GB RAM)
4. **कनेक्ट करें** पर क्लिक करें
5. हो गया! अब आपके पास निःशुल्क AI एक्सेस है।

### विकल्प B: API कुंजी प्रोवाइडर (सशुल्क)

1. प्रोवाइडर की वेबसाइट से API कुंजी प्राप्त करें:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` पर डैशबोर्ड खोलें
3. **प्रोवाइडर** → **प्रोवाइडर जोड़ें** पर जाएँ
4. अपना प्रोवाइडर चुनें
5. अपनी API कुंजी पेस्ट करें
6. **कनेक्ट करें** पर क्लिक करें
7. हो गया! अब आपके पास उस प्रोवाइडर के मॉडल का एक्सेस है।

### विकल्प C: OAuth प्रोवाइडर (सदस्यता)

1. `http://localhost:20128` पर डैशबोर्ड खोलें
2. **प्रोवाइडर** → **प्रोवाइडर जोड़ें** पर जाएँ
3. अपना प्रोवाइडर चुनें (उदाहरण के लिए, Claude Code, GitHub Copilot)
4. **OAuth से कनेक्ट करें** पर क्लिक करें
5. अपने खाते से लॉगिन करें
6. हो गया! अब आपके पास अपने सदस्यता मॉडल का एक्सेस है।

### विकल्प D: स्थानीय MLX मॉडल (Apple Silicon)

एकीकृत मेमोरी वाले Apple Silicon Mac के लिए, OmniRoute `mlx-lm.server` के माध्यम से चलने वाले स्थानीय MLX मॉडल से नियमित OpenAI-संगत स्थानीय प्रोवाइडर के रूप में कनेक्ट होने का समर्थन करता है।

#### पूर्वापेक्षाएँ

- **Apple Silicon Mac** (M1/M2/M3/M4), 24GB+ एकीकृत मेमोरी की अनुशंसा की जाती है
- **uv** पैकेज मैनेजर: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### त्वरित शुरुआत

1. **निर्भरताएँ इंस्टॉल करें**:

   ```bash
   # यदि uv पहले से इंस्टॉल नहीं है, तो उसे इंस्टॉल करें
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm इंस्टॉल करें
   uv pip install mlx-lm
   ```

2. **MLX सर्वर मैन्युअल रूप से शुरू करें** (अलग-अलग टर्मिनल में):

   ```bash
   # टर्मिनल 1: Gemma 4 26B A4B IT-QAT (पोर्ट 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # टर्मिनल 2: Qwen 3.8 27B MLX Mixed (पोर्ट 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute डैशबोर्ड में कनेक्ट करें**:
   - **प्रोवाइडर** → **प्रोवाइडर जोड़ें** पर जाएँ
   - **MLX Gemma 26B** या **MLX Qwen 3.8 27B** चुनें
   - **कनेक्ट करें** पर क्लिक करें (API कुंजी आवश्यक नहीं)

4. **OpenCode के साथ उपयोग करें**:
   ```bash
   # OmniRoute का उपयोग करने के लिए OpenCode कॉन्फ़िगर करें
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX मॉडल का उपयोग करें
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### मेमोरी प्रबंधन

**महत्वपूर्ण**: 24GB एकीकृत मेमोरी के साथ, एक समय में केवल **एक बड़ा MLX मॉडल चल सकता है**।

- Gemma 26B: ~15.9GB अधिकतम मेमोरी
- Qwen 3.8 27B: ~13.1GB अधिकतम मेमोरी

आपको इसे मैन्युअल रूप से प्रबंधित करना होगा:

- एक समय में केवल एक MLX सर्वर चलाएँ, या
- दोनों को अलग-अलग मशीन पर चलाएँ, या
- दूसरे को शुरू करने से पहले एक को बंद करें

OmniRoute MLX सर्वर प्रक्रियाओं को स्वचालित रूप से प्रबंधित नहीं करता — यह केवल अनुरोधों को आपके द्वारा कॉन्फ़िगर किए गए OpenAI-संगत एंडपॉइंट तक रूट करता है।

#### टूल कॉलिंग समर्थन

दोनों मॉडल OpenAI-संगत टूल कॉलिंग का समर्थन करते हैं। इसके साथ परीक्षण करें:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "2+2 क्या है? कैलकुलेटर टूल का उपयोग करें।"}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "गणना करें", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### समस्या निवारण

| समस्या               | समाधान                                                                                       |
| -------------------- | -------------------------------------------------------------------------------------------- |
| सर्वर शुरू नहीं होता | `uv run mlx_lm.server --help` जाँचें और मॉडल IDs सत्यापित करें                               |
| मेमोरी कम पड़ना      | सुनिश्चित करें कि केवल एक मॉडल चल रहा हो; अन्य ऐप्स बंद करें; Activity Monitor जाँचें        |
| कनेक्शन अस्वीकृत     | सत्यापित करें कि सर्वर सही पोर्ट (11435/11436) पर चल रहा है                                  |
| धीमी प्रतिक्रियाएँ   | पहला अनुरोध मॉडल को मेमोरी में लोड करता है (~30-60s); बाद के अनुरोध तेज़ होते हैं            |
| टूल कॉलिंग विफल होना | सुनिश्चित करें कि मॉडल टूल्स का समर्थन करता है; अनुवाद त्रुटियों के लिए OmniRoute लॉग जाँचें |

## प्रदाता को कनेक्ट करने का तरीका (चरण-दर-चरण)

### चरण 1: डैशबोर्ड खोलें

अपने ब्राउज़र में `http://localhost:20128` पर जाएँ।

### चरण 2: प्रदाताओं पर जाएँ

साइडबार में **Providers** पर क्लिक करें।

### चरण 3: प्रदाता जोड़ें पर क्लिक करें

**+ Add Provider** बटन पर क्लिक करें।

### चरण 4: अपना प्रदाता चुनें

सूची ब्राउज़ करें या अपने प्रदाता को खोजें। उस पर क्लिक करें।

### चरण 5: क्रेडेंशियल दर्ज करें

- **मुफ़्त प्रदाता**: किसी क्रेडेंशियल की आवश्यकता नहीं — बस **Connect** पर क्लिक करें
- **API कुंजी प्रदाता**: अपनी API कुंजी पेस्ट करें
- **OAuth प्रदाता**: **Connect with OAuth** पर क्लिक करें और लॉग इन करें

### चरण 6: कनेक्शन का परीक्षण करें

यह सत्यापित करने के लिए कि कनेक्शन काम करता है, **Test Connection** पर क्लिक करें।

### चरण 7: हो गया!

आपका प्रदाता अब कनेक्ट हो गया है। आप इसे `model: "auto"` के साथ उपयोग कर सकते हैं या सीधे प्रदाता निर्दिष्ट कर सकते हैं।

## कई प्रदाताओं का उपयोग

OmniRoute **कई प्रदाताओं** के साथ सबसे अच्छा काम करता है। इससे आपको ये लाभ मिलते हैं:

- **स्वचालित फ़ॉलबैक** — यदि एक प्रदाता विफल हो जाता है, तो OmniRoute अगले प्रदाता को आज़माता है
- **लागत अनुकूलन** — OmniRoute प्रत्येक अनुरोध के लिए सबसे सस्ता प्रदाता चुनता है
- **गति अनुकूलन** — OmniRoute प्रत्येक अनुरोध के लिए सबसे तेज़ प्रदाता चुनता है
- **गुणवत्ता अनुकूलन** — OmniRoute प्रत्येक कार्य के लिए सर्वश्रेष्ठ प्रदाता चुनता है

### अनुशंसित सेटअप

सर्वोत्तम अनुभव के लिए कम-से-कम **3 प्रदाताओं** को कनेक्ट करें:

1. **एक मुफ़्त प्रदाता** (Kiro, OpenCode Free, या Pollinations) — हमेशा उपलब्ध
2. **एक तेज़ प्रदाता** (Groq, Cerebras) — त्वरित प्रतिक्रियाओं के लिए
3. **एक उच्च-गुणवत्ता वाला प्रदाता** (OpenAI, Anthropic, Google) — जटिल कार्यों के लिए

फिर `model: "auto"` का उपयोग करें और OmniRoute प्रत्येक अनुरोध के लिए स्वचालित रूप से सर्वश्रेष्ठ प्रदाता चुनेगा।

## सामान्य प्रश्न

### "क्या OmniRoute का उपयोग करने के लिए मुझे भुगतान करना होगा?"

**नहीं!** OmniRoute मुफ़्त और ओपन-सोर्स है। आप बिना कुछ भुगतान किए मुफ़्त प्रदाताओं (Kiro, OpenCode Free, Pollinations) का उपयोग कर सकते हैं। आपको केवल तभी भुगतान करना होगा, जब आप सशुल्क प्रदाताओं का उपयोग करना चुनते हैं।

### "मुझे किस प्रदाता से शुरुआत करनी चाहिए?"

**Kiro AI** से शुरुआत करें — यह मुफ़्त है, इसके लिए API कुंजी की आवश्यकता नहीं होती, और यह आपको Claude मॉडल तक पहुँच प्रदान करता है। फिर आवश्यकतानुसार और प्रदाता जोड़ें।

### "क्या मैं एक साथ कई प्रदाताओं का उपयोग कर सकता हूँ?"

**हाँ!** यही OmniRoute का मुख्य उद्देश्य है। कई प्रदाताओं को कनेक्ट करें और प्रत्येक अनुरोध के लिए OmniRoute को सर्वोत्तम प्रदाता चुनने देने हेतु `model: "auto"` का उपयोग करें।

### "यदि कोई प्रदाता बंद हो जाए तो क्या होगा?"

OmniRoute विफल प्रदाताओं को स्वचालित रूप से छोड़ देता है और अगले प्रदाता को आज़माता है। आपको कुछ भी करने की आवश्यकता नहीं है।

### "मैं किसी प्रदाता को डिस्कनेक्ट कैसे करूँ?"

प्रदाता पर जाएँ → प्रदाता पर क्लिक करें → **डिस्कनेक्ट करें** पर क्लिक करें।

### "क्या मैं अपनी मौजूदा API कुंजियों का उपयोग कर सकता हूँ?"

**हाँ!** यदि आपके पास OpenAI, Anthropic, Google आदि के लिए पहले से API कुंजियाँ हैं, तो आप OmniRoute में उनका उपयोग कर सकते हैं। प्रदाता को कनेक्ट करते समय बस उन्हें पेस्ट करें।
