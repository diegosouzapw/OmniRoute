```
├── .agents/              # Codex / सामान्य एजेंट वर्कफ़्लोज़ + कौशल (.claude/ का प्रतिबिंब)

├── _ideia/               # योजना संबंधी नोट्स (अनौपचारिक; वितरित नहीं किए जाते)
```

## `src/` — Next.js एप्लिकेशन

```
src/
├── app/                 # App Router (पेज + API रूट + स्टेटस पेज + लैंडिंग पेज)
├── lib/                 # मुख्य लाइब्रेरी / डोमेन मॉड्यूल (80 सबडायरेक्टरी + ~70 शीर्ष-स्तरीय फ़ाइलें)
├── domain/              # शुद्ध डोमेन लॉजिक (पॉलिसी इंजन, फ़ॉलबैक, लागत, लॉकआउट, comboResolver, असेसमेंट)
├── server/              # केवल-सर्वर मॉड्यूल (ऑथराइज़ेशन पाइपलाइन, cors, ऑथ मिडलवेयर) — क्लाइंट से इम्पोर्ट नहीं किए जा सकते
├── shared/              # जहाँ सुरक्षित हो, वहाँ सर्वर और क्लाइंट के बीच साझा (कॉन्स्टेंट, टाइप, वैलिडेशन, कॉन्ट्रैक्ट, यूटिलिटी)
├── i18n/                # next-intl कॉन्फ़िगरेशन + प्रत्येक लोकेल के लिए संदेश JSON (42 लोकेल)
├── middleware/          # Next.js मिडलवेयर (रिक्वेस्ट संवर्धन, लोकेल पहचान)
├── mitm/                # MITM प्रॉक्सी कोर: सर्टिफ़िकेट जनरेशन/इंस्टॉलेशन, हैंडलर, टार्गेट, इंस्पेक्टर, मास्क, पासथ्रू
│   ├── handlers/        # MitmHandlerBase को एक्सटेंड करने वाली 9 IDE-एजेंट हैंडलर क्लास (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
```

## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — मुख्य ट्री से बाहर

अंडरस्कोर से शुरू होने वाली इन डायरेक्टरियों में ऐसा कॉन्टेंट होता है जिसे शिप नहीं किया जाता:

- **`_ideia/`** — डिज़ाइन नोट्स (defer / notfit / viable श्रेणियाँ)
- **`_mono_repo/`** — ऐतिहासिक सबप्रोजेक्ट (omnirouteCloud, omnirouteSite, vscode-extension)
- **`_references/`** — संबंधित OSS प्रोजेक्ट्स (LiteLLM, 9router, ClawRouter, CLIProxyAPI, modelrelay, new-api, आदि) के केवल-पढ़ने योग्य क्लोन, जिन्हें विकास के दौरान क्रॉस-रेफ़रेंस के लिए उपयोग किया जाता है
- **`_tasks/`** — प्रत्येक रिलीज़ के कार्य-ट्रैकिंग की फ़ाइलें (अनौपचारिक)

`npm pack` आउटपुट में शामिल नहीं हैं। `.npmignore` देखें।

## नेविगेशन सुझाव

- **प्रोवाइडर जोड़ रहे हैं?** `docs/architecture/ARCHITECTURE.md § Adding a New Provider` का अनुसरण करें + `docs/reference/PROVIDER_REFERENCE.md` से क्रॉस-चेक करें।

- **MCP टूल जोड़ रहे हैं?** `docs/frameworks/MCP-SERVER.md § Adding a Tool`।
- **A2A स्किल जोड़ रहे हैं?** `docs/frameworks/A2A-SERVER.md § Adding a New Skill`।
- **स्थानीय रूप से चला रहे हैं?** `docs/guides/SETUP_GUIDE.md`।
- **डिप्लॉय कर रहे हैं?** `docs/guides/DOCKER_GUIDE.md` / `docs/ops/VM_DEPLOYMENT_GUIDE.md` / `docs/ops/FLY_IO_DEPLOYMENT_GUIDE.md`।
- **रिलीज़ कर रहे हैं?** `docs/ops/RELEASE_CHECKLIST.md` (और `/generate-release-cc` Claude Code स्किल)।
