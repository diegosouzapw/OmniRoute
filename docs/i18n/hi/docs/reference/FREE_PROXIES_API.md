OmniRoute `free_proxies` तालिका में मुफ़्त प्रॉक्सियों का एक चयनित पूल प्रदान करता है,
जिसे बाहरी प्रदाताओं (1proxy, proxifly, iplocate, webshare) से सिंक किया जाता है।
डैशबोर्ड इन्हें **Settings → Free Proxies** के अंतर्गत प्रदर्शित करता है। यह दस्तावेज़
लिस्ट रूट द्वारा उपलब्ध कराई जाने वाली सर्वर-साइड फ़िल्टरिंग, सॉर्टिंग, गणना और सिंक-त्रुटि रिपोर्टिंग
को कवर करता है।

## लिस्ट रूट — `GET /api/settings/free-proxies`

कुल संख्या के साथ फ़िल्टर किया हुआ, क्रमबद्ध और पृष्ठांकित हिस्सा लौटाता है। फ़िल्टरिंग और
गणना SQL में होती है, ताकि UI प्रत्येक पंक्ति को मेमोरी में लोड किए बिना वास्तविक कुल
(जैसे `Total: 0`) दिखा सके।

### क्वेरी पैरामीटर

| पैरामीटर          | प्रकार                             | डिफ़ॉल्ट  | अर्थ                                                                                                   |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------ |
| `search`          | स्ट्रिंग                           | `""`      | होस्ट (और स्रोत) कॉलम पर केस-सेंसिटिव `LIKE`।                                                          |
| `protocol`        | स्ट्रिंग                           | `""`      | `type` फ़िल्टर: `http` / `https` / `socks4` / `socks5`। खाली = सभी।                                    |
| `country`         | स्ट्रिंग                           | `""`      | `countryCode` फ़िल्टर (ISO-2)। खाली = सभी।                                                             |
| `minQuality`      | संख्या                             | `0`       | केवल वे पंक्तियाँ जिनमें `qualityScore >= minQuality` हो। `0` = कोई न्यूनतम सीमा नहीं।                 |
| `disabledSources` | स्ट्रिंग                           | `""`      | बाहर रखने के लिए कॉमा से अलग किए गए स्रोत आईडी (जैसे `proxifly,webshare`)।                             |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = स्कोर अवरोही; `latency` = लेटेंसी आरोही (null अंत में); `recent` = `lastValidated` अवरोही। |
| `offset`          | संख्या                             | `0`       | पृष्ठांकन का आरंभ।                                                                                     |
| `limit`           | संख्या                             | `50`      | पृष्ठ का आकार (सर्वर-साइड पर सीमित)।                                                                   |

### प्रतिक्रिया

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` पृष्ठांकन से **पहले** फ़िल्टर किए गए कुल को दर्शाता है, ताकि UI
`Total: N` और `hasMore` को स्वतंत्र रूप से रेंडर कर सके। `syncErrors` की कुंजियाँ स्रोत आईडी होती हैं और
इसे केवल उन स्रोतों के लिए भरा जाता है जिनका अंतिम सिंक विफल हुआ था — `Total: 0` परिणाम
कभी भी बिना सूचना के नहीं रहता।

## पूल में जोड़ना — `POST /api/settings/free-proxies/[id]/add-to-pool`

एक मुफ़्त प्रॉक्सी को प्रबंधित `proxy_registry` पूल में पदोन्नत करता है। पहले
अपस्ट्रीम को सत्यापित करता है; सफलता मिलने पर नए पूल प्रॉक्सी की आईडी और मापी गई लेटेंसी लौटाता है।

## सिंक — `POST /api/settings/free-proxies/sync`

सभी सक्षम स्रोतों (या `{ "sources": [...] }` में दिए गए उपसमूह) को फिर से प्राप्त करता है। प्रत्येक
स्रोत स्वतंत्र रूप से सिंक होता है; विफल स्रोत को `syncErrors` में दर्ज किया जाता है और
अन्य स्रोत फिर भी पूरे होते हैं, इसलिए आंशिक सिंक पहले से मौजूद सही डेटा को कभी नहीं मिटाते।

## आँकड़े — `GET /api/settings/free-proxies/stats`

पंक्ति पेलोड के बिना `total / inPool / avgQuality / bySource / lastSyncAt` समुच्चय
लौटाता है — इसका उपयोग डैशबोर्ड हेडर विजेट द्वारा किया जाता है।
