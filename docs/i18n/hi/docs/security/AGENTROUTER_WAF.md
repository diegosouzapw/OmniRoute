`agentrouter` अपस्ट्रीम गेटवे `messages[].content` पर कीवर्ड-आधारित सामग्री फ़िल्टर चलाता है। फ़िल्टर आंशिक रूप से नियतात्मक है (कुछ वाक्यांशों को हमेशा अवरुद्ध करता है) और आंशिक रूप से संभाव्य है (बर्स्ट-संवेदी — तीव्र अनुरोधों के बाद अधिक आक्रामक हो जाता है और कूलडाउन के बाद सामान्य हो जाता है)।

जब WAF किसी अनुरोध को अवरुद्ध करता है, तो वह यह लौटाता है:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## फ़िल्टर का दायरा

WAF केवल `messages[].content` का निरीक्षण करता है। यह इनका निरीक्षण **नहीं** करता:

- `system` प्रॉम्प्ट
- संरचित सामग्री ब्लॉक (`tool_result`, `tool_use`, `thinking`, `image`)
- टूल के `description` और `input_schema` फ़ील्ड
- अनुरोध मेटाडेटा, हेडर या मॉडल आईडी

## हमेशा अवरुद्ध होने वाले पैटर्न (केस-असंवेदी)

| पैटर्न                      | टिप्पणियाँ                                                          |
| --------------------------- | ------------------------------------------------------------------- |
| `Lorem ipsum` का कोई भी रूप | संपूर्ण लैटिन lorem शब्दावली अवरुद्ध है                             |
| `language model` (अकेला)    | "the language model" और "large language model" स्वीकार किए जाते हैं |
| `virtual assistant`         | "AI assistant" स्वीकार किया जाता है                                 |
| `I'm here to help`          | अकेला "here to help" भी अवरुद्ध होता है                             |
| `Claude, made by Anthropic` | केवल पूरा वाक्यांश                                                  |

## लगभग हमेशा अवरुद्ध होने वाले पैटर्न

| पैटर्न                                                | टिप्पणियाँ                                        |
| ----------------------------------------------------- | ------------------------------------------------- |
| `placeholder`                                         | जब यह अकेला हो (पैरामीटर नाम आदि के रूप में नहीं) |
| `dummy data`                                          | फ़िक्स्चर के लिए सामान्य सीड वाक्यांश             |
| `foo bar baz`                                         | मानक प्लेसहोल्डर वाक्यांश                         |
| दोहराए गए छोटे टोकन (`AAA BBB CCC`, `test test test`) | कीवर्ड स्टफ़िंग का डिटेक्टर                       |

## लोड के दौरान व्यवहार

कम समयावधि में लगभग 5 तीव्र अनुरोधों के बाद, WAF ऐसी सामग्री को अवरुद्ध करना शुरू कर देता है जो सामान्यतः स्वीकार हो जाती। लगभग 5–10 सेकंड निष्क्रिय रहने के बाद बकेट सामान्य हो जाता है। यह वही IP-और-कुंजी-बद्ध रेट लिमिटर है, जिसके कारण Claude Code या Codex CLI द्वारा एक के बाद एक कई टूल-उपयोग / संदेश-प्रेषण कॉल किए जाने पर रुक-रुककर `400 content-blocked` त्रुटियाँ आती हैं।

## OmniRoute में पहले से लागू शमन उपाय

1. **`open-sse/services/wafRateLimit.ts`** — एक बर्स्ट गार्ड, जो किसी भी `agentrouter:*` URL को भेजे जाने वाले आउटबाउंड अनुरोधों के बीच न्यूनतम 500 ms का अंतर लागू करता है। यह अंतर मानवीय विलंब-अनुभूति की सीमा से बहुत कम है और सामान्य ट्रैफ़िक पर WAF को सक्रिय होने से रोकता है।

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — जब कोई अपस्ट्रीम `400 content-blocked` लौटाता है, तो एक्ज़ीक्यूटर एक्सपोनेंशियल बैकऑफ़ (1.5 s, 3.0 s, अधिकतम 2 प्रयास) के साथ उसी URL का पुनः प्रयास करता है। बैकऑफ़ के बाद WAF आमतौर पर सामान्य हो जाता है और पुनः प्रयास सफल रहता है।

3. **`tests/unit/compression/harness.test.ts`** — टेस्ट फ़िक्स्चर `longInput` को `"lorem ipsum dolor sit amet ".repeat(40)` से बदलकर `"example content for testing purposes ".repeat(40)` किया गया, ताकि जब Claude Code इस फ़ाइल को `Read` टूल के माध्यम से पढ़े, तो फ़ाइल की सामग्री `tool_result` ब्लॉक के माध्यम से वापस प्रवाहित होकर WAF को सक्रिय न करे।

## प्रॉम्प्ट और टूल आउटपुट के लिए मार्गदर्शन

यदि कोई Claude Code या Codex CLI सत्र बार-बार `400 content-blocked` का सामना करता है, तो सबसे हालिया उपयोगकर्ता संदेश और सबसे हालिया टूल परिणाम में ऊपर दिए गए किसी पैटर्न की जाँच करें और उसे दूसरे शब्दों में लिखें। सामान्य समाधान:

- `Lorem ipsum …` को `example text …` या उस वास्तविक सामग्री से बदलें जिसे टेस्ट या फ़िक्स्चर मॉडल करने का प्रयास कर रहा है।
- अकेले प्रयुक्त `placeholder` को `example value`, `sample value` या वास्तविक मान से बदलें।
- `language model` को `large language model` या `the model` से बदलें।
- `dummy data` को `sample data` या यथार्थवादी सीड मानों से बदलें।
- `I'm here to help` / `here to help` को अधिक विशिष्ट आरंभिक वाक्य से बदलें (उदाहरण के लिए, "I'll review the file you mentioned")।

## अपस्ट्रीम को ग़लत सकारात्मक परिणामों की रिपोर्ट करना

वर्तमान फ़िल्टर अत्यधिक आक्रामक है — यह `tool_result` ब्लॉक में "Lorem ipsum" को तब भी अवरुद्ध करता है, जब ऑपरेटर का स्पष्ट रूप से कोई प्रॉम्प्ट इंजेक्ट करने का इरादा नहीं था। जो ऑपरेटर इसे स्रोत पर ठीक करवाना चाहते हैं, उन्हें ग़लत सकारात्मक परिणामों की रिपोर्ट करने के लिए `agentrouter.org` से संपर्क करना चाहिए। ऊपर दी गई ब्लॉकलिस्ट 2026-08-03 तक अपस्ट्रीम की जाँच से प्राप्त अनुभवजन्य परिणाम है।
