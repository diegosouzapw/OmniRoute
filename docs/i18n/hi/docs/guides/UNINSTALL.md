## त्वरित अनइंस्टॉल (v3.6.2+)

OmniRoute साफ़ तरीके से हटाने के लिए दो अंतर्निहित स्क्रिप्ट प्रदान करता है:

### अपना डेटा बनाए रखें

```bash
npm run uninstall
```

यह OmniRoute एप्लिकेशन को हटा देता है, लेकिन `~/.omniroute/` में मौजूद आपके डेटाबेस, कॉन्फ़िगरेशन, API कुंजियों और प्रदाता सेटिंग्स को **सुरक्षित रखता है**। यदि आप बाद में इसे दोबारा इंस्टॉल करने की योजना बना रहे हैं और अपना सेटअप बनाए रखना चाहते हैं, तो इसका उपयोग करें।

### पूर्ण निष्कासन

```bash
npm run uninstall:full
```

यह एप्लिकेशन को हटाता है **और सभी डेटा को स्थायी रूप से मिटा देता है**:

- डेटाबेस (`storage.sqlite`)
- प्रदाता कॉन्फ़िगरेशन और API कुंजियाँ
- बैकअप फ़ाइलें
- लॉग फ़ाइलें
- `~/.omniroute/` डायरेक्टरी की सभी फ़ाइलें

> ⚠️ **चेतावनी:** `npm run uninstall:full` को पूर्ववत नहीं किया जा सकता। आपके सभी प्रदाता कनेक्शन, कॉम्बो, API कुंजियाँ और उपयोग इतिहास स्थायी रूप से हटा दिए जाएँगे।

## मैन्युअल अनइंस्टॉल

### NPM ग्लोबल इंस्टॉल

```bash
# ग्लोबल पैकेज हटाएँ
npm uninstall -g omniroute

# (वैकल्पिक) डेटा डायरेक्टरी हटाएँ
rm -rf ~/.omniroute
```

### pnpm ग्लोबल इंस्टॉल

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# कंटेनर को रोकें और हटाएँ
docker stop omniroute
docker rm omniroute

# वॉल्यूम हटाएँ (सभी डेटा मिटा देता है)
docker volume rm omniroute-data

# (वैकल्पिक) इमेज हटाएँ
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# कंटेनरों को रोकें और हटाएँ
docker compose down

# वॉल्यूम भी हटाएँ (सभी डेटा मिटा देता है)
docker compose down -v
```

### Electron डेस्कटॉप ऐप

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` खोलें
- या इंस्टॉल डायरेक्टरी से NSIS अनइंस्टॉलर चलाएँ

**macOS:**

- `/Applications` से `OmniRoute.app` को ट्रैश में खींचें
- डेटा हटाएँ: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage फ़ाइल हटाएँ
- डेटा हटाएँ: `rm -rf ~/.omniroute`

### सोर्स इंस्टॉल (git clone)

```bash
# क्लोन की गई डायरेक्टरी हटाएँ
rm -rf /path/to/omniroute

# (वैकल्पिक) डेटा डायरेक्टरी हटाएँ
rm -rf ~/.omniroute
```

## डेटा डायरेक्टरियाँ

OmniRoute डिफ़ॉल्ट रूप से निम्न स्थानों पर डेटा संग्रहीत करता है:

| प्लेटफ़ॉर्म | डिफ़ॉल्ट पथ                           | ओवरराइड                               |
| ----------- | ------------------------------------- | ------------------------------------- |
| Linux       | `~/.omniroute/`                       | `DATA_DIR` एनवायरनमेंट वेरिएबल        |
| macOS       | `~/.omniroute/`                       | `DATA_DIR` एनवायरनमेंट वेरिएबल        |
| Windows     | `%APPDATA%/omniroute/`                | `DATA_DIR` एनवायरनमेंट वेरिएबल        |
| Docker      | `/app/data/` (माउंट किया गया वॉल्यूम) | `DATA_DIR` एनवायरनमेंट वेरिएबल        |
| XDG-अनुपालक | `$XDG_CONFIG_HOME/omniroute/`         | `XDG_CONFIG_HOME` एनवायरनमेंट वेरिएबल |

### डेटा डायरेक्टरी की फ़ाइलें

| फ़ाइल/डायरेक्टरी     | विवरण                                               |
| -------------------- | --------------------------------------------------- |
| `storage.sqlite`     | मुख्य डेटाबेस (प्रदाता, कॉम्बो, सेटिंग्स, कुंजियाँ) |
| `storage.sqlite-wal` | SQLite राइट-अहेड लॉग (अस्थायी)                      |
| `storage.sqlite-shm` | SQLite साझा मेमोरी (अस्थायी)                        |
| `call_logs/`         | अनुरोध पेलोड अभिलेखागार                             |
| `backups/`           | स्वचालित डेटाबेस बैकअप                              |
| `log.txt`            | लेगेसी अनुरोध लॉग (वैकल्पिक)                        |

## पूर्ण निष्कासन सत्यापित करें

अनइंस्टॉल करने के बाद, सत्यापित करें कि कोई फ़ाइल शेष नहीं है:

```bash
# वैश्विक npm पैकेज की जाँच करें
npm list -g omniroute 2>/dev/null

# डेटा डायरेक्टरी की जाँच करें
ls -la ~/.omniroute/ 2>/dev/null

# चल रही प्रक्रियाओं की जाँच करें
pgrep -f omniroute
```

यदि कोई प्रक्रिया अभी भी चल रही है, तो उसे रोकें:

```bash
pkill -f omniroute
```
