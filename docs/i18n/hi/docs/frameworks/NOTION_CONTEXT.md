## यह क्या है

OmniRoute किसी **Notion** वर्कस्पेस से **कॉन्टेक्स्ट स्रोत** के रूप में जुड़ सकता है — एक पढ़ने/लिखने योग्य
ज्ञान आधार, जिस तक एजेंट अंतर्निहित MCP सर्वर के माध्यम से पहुँचते हैं। Notion
इंटीग्रेशन टोकन कॉन्फ़िगर हो जाने के बाद, MCP टूल किसी LLM को पेज और डेटाबेस खोजने,
पेज सामग्री और ब्लॉक ट्री पढ़ने, फ़िल्टर/सॉर्ट के साथ डेटाबेस क्वेरी करने और नए
ब्लॉक जोड़ने देते हैं — यह सब OmniRoute के माध्यम से प्रॉक्सी किया जाता है (पुनः प्रयास, टाइमआउट और त्रुटि वर्गीकरण सहित),
ताकि मॉडल कभी भी Notion API को सीधे एक्सेस न करे।

यह इंटीग्रेशन आधिकारिक Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) पर बना एक हल्का और सुदृढ़ रैपर है। क्लाइंट
(`src/lib/notion/api.ts`) निम्नलिखित जोड़ता है:

- `429` और `5xx` के लिए **एक्सपोनेंशियल बैकऑफ़ के साथ पुनः प्रयास** (अधिकतम 3 प्रयास)।
- `AbortController` के माध्यम से **55-सेकंड का अनुरोध टाइमआउट**।
- **टाइपयुक्त त्रुटि वर्गीकरण** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  संकेतों का पालन करता है), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`।
- **संदेश स्वच्छीकरण**, जो प्रदर्शित करने से पहले स्टैक-ट्रेस-जैसे अंशों को हटा देता है।

## सेटअप

Notion टोकन के लिए **कोई एनवायरनमेंट वेरिएबल नहीं है** — इसे
`src/lib/db/notion.ts` के माध्यम से SQLite `key_value` तालिका (नेमस्पेस `notion`, कुंजी `integration_token`) में
संग्रहीत किया जाता है। इसे Endpoint डैशबोर्ड के **Context Sources** टैब
(`ObsidianSourceCard` के सहोदर `NotionSourceCard`) से या सेटिंग्स REST API के माध्यम से कॉन्फ़िगर करें।

> [!NOTE]
> यह टोकन एक **Notion आंतरिक इंटीग्रेशन टोकन** है। यहाँ इंटीग्रेशन बनाएँ:
> <https://www.notion.com/my-integrations>, फिर वे पेज/डेटाबेस उस इंटीग्रेशन के साथ साझा करें
> जिन्हें आप OmniRoute द्वारा एक्सेस करवाना चाहते हैं (Notion का अनुमति मॉडल साझा करने पर आधारित है,
> पूरे वर्कस्पेस पर नहीं)।

### REST के माध्यम से कॉन्फ़िगर करें

```bash
# इंटीग्रेशन टोकन सहेजें + सत्यापित करें (POST एक परीक्षण खोज जारी करके सत्यापन करता है)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# कनेक्शन की स्थिति जाँचें
curl http://localhost:20128/api/settings/notion

# डिस्कनेक्ट करें (संग्रहीत टोकन हटाता है)
curl -X DELETE http://localhost:20128/api/settings/notion
```

तीनों विधियों के लिए डैशबोर्ड प्रमाणीकरण (`isAuthenticated`) आवश्यक है। `POST` पर,
OmniRoute टोकन सहेजता है और तुरंत 1-परिणाम वाली परीक्षण खोज चलाता है; यदि Notion
कोई त्रुटि ऑब्जेक्ट लौटाता है, तो टोकन हटा दिया जाता है और कॉल `400` के साथ विफल हो जाती है।

## MCP टूल (6)

`open-sse/mcp-server/tools/notionTools.ts` में परिभाषित। कॉल के समय टोकन को
`getNotionToken()` के माध्यम से प्राप्त किया जाता है; यदि कोई टोकन कॉन्फ़िगर नहीं है, तो टूल यह त्रुटि देता है:
`"Notion integration token not configured. Set it in Settings > Context Sources."`

| टूल                          | स्कोप          | विवरण                                                                                    |
| ---------------------------- | -------------- | ---------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | टेक्स्ट क्वेरी द्वारा पेज और डेटाबेस खोजें (शीर्षक, ID और URL लौटाता है)। पृष्ठांकित।    |
| `notion_get_page`            | `read:notion`  | किसी पेज की ID द्वारा उसकी सामग्री और मेटाडेटा प्राप्त करें।                             |
| `notion_list_block_children` | `read:notion`  | किसी ब्लॉक या पेज के सभी चाइल्ड ब्लॉक (ब्लॉक ट्री) सूचीबद्ध करें। पृष्ठांकित।            |
| `notion_query_database`      | `read:notion`  | वैकल्पिक `filter` + `sorts` (Notion API प्रारूप) के साथ डेटाबेस क्वेरी करें। पृष्ठांकित। |
| `notion_get_database`        | `read:notion`  | ID द्वारा किसी डेटाबेस का स्कीमा/मेटाडेटा प्राप्त करें।                                  |
| `notion_append_blocks`       | `write:notion` | किसी मौजूदा ब्लॉक या पेज में चाइल्ड ब्लॉक जोड़ें (प्रति अनुरोध अधिकतम 100 ब्लॉक)।        |

### इनपुट पैरामीटर

- `notion_search` — `query` (1–500 वर्ण), `pageSize` (1–100, डिफ़ॉल्ट 20),
  `startCursor` (वैकल्पिक)।
- `notion_get_page` — `pageId` (32-वर्ण हेक्स या UUID)।
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, डिफ़ॉल्ट 50),
  `startCursor` (वैकल्पिक)।
- `notion_query_database` — `databaseId`, `filter` (वैकल्पिक, Notion फ़िल्टर प्रारूप),
  `sorts` (वैकल्पिक ऐरे), `pageSize` (1–100, डिफ़ॉल्ट 50), `startCursor` (वैकल्पिक)।
- `notion_get_database` — `databaseId`।
- `notion_append_blocks` — `blockId`, `children` (ब्लॉक ऑब्जेक्ट की ऐरे),
  `after` (वैकल्पिक स्थिति)।

### स्कोप

रीड टूल के लिए `read:notion` और राइट टूल के लिए `write:notion` आवश्यक है।
स्कोप को `open-sse/mcp-server/server.ts` में `withScopeEnforcement()` द्वारा केवल तभी लागू किया जाता है
जब `OMNIROUTE_MCP_ENFORCE_SCOPES=true` हो; कॉलर के अनुमत स्कोप
`OMNIROUTE_MCP_SCOPES` (अल्पविराम से अलग किए गए) या प्रमाणीकृत API कुंजी के स्कोप कॉन्टेक्स्ट से आते हैं।
पूर्ण स्कोप मॉडल के लिए [MCP-SERVER.md](./MCP-SERVER.md) देखें।

## एंडपॉइंट्स

| विधि     | पथ                     | उद्देश्य                                   |
| -------- | ---------------------- | ------------------------------------------ |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` लौटाएँ।          |
| `POST`   | `/api/settings/notion` | इंटीग्रेशन टोकन सहेजें + सत्यापित करें।    |
| `DELETE` | `/api/settings/notion` | डिस्कनेक्ट करें (संग्रहीत टोकन साफ़ करें)। |

> ये डैशबोर्ड सेटिंग्स रूट हैं। कोई सार्वजनिक `/v1` Notion प्रॉक्सी
> एंडपॉइंट **नहीं है** — Notion तक केवल ऊपर दिए गए MCP टूल्स के माध्यम से पहुँचा जाता है।

## उपयोग के मामले

- **ज्ञान-आधारित उत्तर** — उत्तर देने से पहले एजेंट को वर्कस्पेस में `notion_search` और
  शीर्ष परिणाम पर `notion_get_page` करने दें, ताकि उत्तर वास्तविक आंतरिक दस्तावेज़ों का संदर्भ दें।
- **डेटाबेस-समर्थित वर्कफ़्लो** — फ़िल्टर + सॉर्ट के साथ टास्क/CRM डेटाबेस पर
  `notion_query_database` चलाएँ, फिर पंक्तियों का सारांश दें या उन्हें प्राथमिकता के अनुसार छाँटें।
- **वापस लिखना / लॉगिंग** — मीटिंग नोट्स, रन सारांश या एजेंट आउटपुट को किसी मौजूदा पेज में
  जोड़ने के लिए `notion_append_blocks` का उपयोग करें (केवल जोड़ना; कोई विनाशकारी संपादन नहीं)।
- **संरचना का अन्वेषण** — किसी पेज के ब्लॉक ट्री में जाने के लिए `notion_list_block_children`
  या किसी डेटाबेस को क्वेरी करने से पहले उसकी प्रॉपर्टी स्कीमा जानने के लिए `notion_get_database` का उपयोग करें।
