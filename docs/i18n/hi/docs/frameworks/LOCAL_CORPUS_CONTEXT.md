## यह क्या है

Local Corpus किसी ऑपरेटर को टेक्स्ट फ़ाइलों वाली एक स्पष्ट रूप से स्वीकृत डायरेक्टरी को
OmniRoute के MCP सर्वर के लिए उपलब्ध कराने देता है। फ़ाइलें अपनी मूल डायरेक्टरी में ही रहती हैं: OmniRoute केवल
कैनोनिकल रूट पाथ को SQLite में संग्रहीत करता है और इन-मेमोरी सर्च इंडेक्स बनाए रखता है। यह
कॉर्पस सामग्री को रिपॉज़िटरी या डेटाबेस में कॉपी नहीं करता।

इंडेक्स रीफ़्रेश वृद्धिशील होता है। अपरिवर्तित फ़ाइलों का आकार और संशोधन
समय के आधार पर पुनः उपयोग किया जाता है, बदली हुई फ़ाइलों को दोबारा पढ़ा जाता है और SHA-256 से हैश किया जाता है, तथा हटाई गई फ़ाइलें निकाल दी जाती हैं।
खोज 30 सेकंड से अधिक पुराने इंडेक्स को रीफ़्रेश करती है; कॉलर तत्काल
रीफ़्रेश का अनुरोध भी कर सकते हैं।

## स्रोत कॉन्फ़िगर करें

सेटिंग्स रूट के लिए वही प्रबंधन प्रमाणीकरण आवश्यक है जो अन्य सेटिंग्स API के लिए होता है।
सबमिट किया गया पाथ पहले से मौजूद होना चाहिए और एक एब्सोल्यूट डायरेक्टरी पाथ होना चाहिए।

```bash
# किसी स्वीकृत डायरेक्टरी को कनेक्ट करें
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# कॉन्फ़िगरेशन और इंडेक्स की स्थिति जाँचें
curl http://localhost:20128/api/settings/local-corpus

# स्रोत फ़ाइलों को बदले बिना डिस्कनेक्ट करें
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP टूल

तीनों टूल के लिए `read:local-corpus` आवश्यक है। टूल की प्रतिक्रियाएँ रिलेटिव पाथ और
रूट डायरेक्टरी का बेसनेम दिखाती हैं, उसका एब्सोल्यूट पाथ कभी नहीं।

| टूल                   | विवरण                                                                                             |
| :-------------------- | :------------------------------------------------------------------------------------------------ |
| `local_corpus_status` | कॉन्फ़िगरेशन स्थिति, इंडेक्स आकार, सीमाएँ और अंतिम रीफ़्रेश समय रिपोर्ट करता है                   |
| `local_corpus_search` | इंडेक्स किए गए टेक्स्ट को खोजता है और सीमित, लाइन-स्कोप वाले स्निपेट लौटाता है (अधिकतम 20 परिणाम) |
| `local_corpus_read`   | किसी एक अनुमत कॉर्पस-रिलेटिव फ़ाइल से सीमित लाइन रेंज पढ़ता है                                    |

MCP इनपुट के उदाहरण:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## सुरक्षा सीमाएँ

- अनुमति-सूची टेक्स्ट-उन्मुख है: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, और `.yml`।
- सिमलिंक छोड़ दिए जाते हैं। रीड पाथ को कैनोनिकलाइज़ किया जाता है और उन्हें कॉन्फ़िगर किए गए
  रूट के अंदर ही रहना चाहिए; एब्सोल्यूट पाथ और ट्रैवर्सल प्रयास अस्वीकार कर दिए जाते हैं।
- संवेदनशील और जनरेट की गई डायरेक्टरी के नाम बाहर रखे जाते हैं: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, और
  `secrets`।
- डिफ़ॉल्ट सीमाएँ 5,000 फ़ाइलें, प्रति फ़ाइल 1 MiB, कुल इंडेक्स की गई सामग्री 64 MiB,
  प्रति सर्च चंक लगभग 4,000 कैरेक्टर और प्रति रीड 400 लाइनें हैं।
- NUL वाली फ़ाइलों को गैर-टेक्स्ट माना जाता है और छोड़ दिया जाता है या अस्वीकार कर दिया जाता है।

PDF, DOCX, इमेज और आर्काइव जैसे बाइनरी दस्तावेज़ जानबूझकर समर्थित नहीं हैं।
इंडेक्स करने से पहले उन्हें कॉन्फ़िगर की गई डायरेक्टरी में किसी स्वीकृत टेक्स्ट फ़ॉर्मेट में बदलें।

## परिचालन संबंधी टिप्पणियाँ

- कॉन्फ़िगर किए गए रूट को बदलने या हटाने पर साझा इन-मेमोरी इंडेक्स साफ़ हो जाता है।
- प्रोसेस पुनः प्रारंभ होने पर इंडेक्स हट जाता है; अगली खोज उसे कॉन्फ़िगर किए गए
  स्रोत से दोबारा बनाती है।
- `local_corpus_status` स्कैन को बाध्य नहीं करता। तत्काल रीस्कैन की आवश्यकता होने पर
  `refresh: true` के साथ `local_corpus_search` का उपयोग करें।
- स्कैन और रीड की विफलताओं को गिना जाता है या सैनिटाइज़ की गई त्रुटियों के रूप में लौटाया जाता है; स्रोत फ़ाइलों को
  कभी संशोधित नहीं किया जाता।
