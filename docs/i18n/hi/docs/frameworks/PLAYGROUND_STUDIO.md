## अवलोकन

Playground Studio `/dashboard/playground` को एक साधारण Monaco-आधारित एडिटर से
एक पूर्ण-सुविधायुक्त परीक्षण कार्यक्षेत्र में बदल देता है। यह पुराने `page.tsx` को एक `PlaygroundStudio`
शेल से बदलता है, जो चार टैब और एक साझा कॉन्फ़िगरेशन पेन रेंडर करता है।

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 चैट] [⚖ तुलना] [{} API] [🔧 बिल्ड]       142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {सक्रिय टैब की सामग्री}                 │ ─ कॉन्फ़िगरेशन            │
│                                          │ एंडपॉइंट  [chat ∨]        │
│                                          │ मॉडल      [gpt-5.4 ∨]     │
│                                          │ सिस्टम    [टेक्स्टएरिया]   │
│                                          │ तापमान    ▕▕▔▔ 0.7        │

│                                          │ [✨ प्रॉम्प्ट सुधारें]      │
└──────────────────────────────────────────┴───────────────────────────┘
```

## टैब

### चैट टैब

`ChatPlayground.tsx` को बहु-टर्न स्ट्रीमिंग कार्यक्षेत्र में विकसित करता है:

- `MarkdownMessage.tsx` के माध्यम से पूर्ण markdown रेंडरिंग (कोड ब्लॉक, तालिकाएँ, सूचियाँ, लिंक)।
- साझा कॉन्फ़िगरेशन पेन से प्राप्त सिस्टम प्रॉम्प्ट।
- प्रति संदेश टोकन/लागत (प्रॉम्प्ट + पूर्णता टोकन)।
- अंतिम प्रतिक्रिया पुनः जनरेट करें।
- SSE स्ट्रीमिंग के साथ `POST /v1/chat/completions` पर भेजता है।

### तुलना टैब

प्रॉक्सी के लिए प्रमुख विशेषता: 1 प्रॉम्प्ट को अधिकतम **4 मॉडलों पर समानांतर रूप से** चलाएँ।

- अधिकतम 4 कॉलम, जिनमें से प्रत्येक `/v1/chat/completions` से स्वतंत्र रूप से स्ट्रीम करता है।
- कॉलम जोड़ने के लिए `+ मॉडल जोड़ें` बटन (Cmd+K शॉर्टकट)।
- `सभी चलाएँ ▶`, `Promise.all` + प्रति-कॉलम `AbortController` के माध्यम से सभी स्ट्रीम एक साथ शुरू करता है।
- वैश्विक **सभी रद्द करें** प्रत्येक चालू स्ट्रीम को निरस्त करता है।
- प्रति-कॉलम `ProviderMetrics` वास्तविक समय में TTFT, TPS, टोकन और अनुमानित लागत दिखाता है।
- मेट्रिक्स को **"क्लाइंट-साइड अनुमान"** (D12) के रूप में लेबल किया गया है — पहले SSE चंक से मापा जाता है।

### API टैब

उन्नत उपयोगकर्ताओं के लिए मूल Monaco एडिटर का 100% हिस्सा सुरक्षित रखता है (D14):

- 10 एंडपॉइंट: चैट पूर्णताएँ, पूर्णताएँ, एम्बेडिंग, इमेज, ऑडियो, स्पीच, ट्रांसक्रिप्शन, मॉडरेशन, री-रैंक, खोज।
- मल्टीमॉडल फ़ाइल अपलोड।
- रीयल-टाइम आउटपुट के साथ SSE स्ट्रीमिंग।
- `ApiTab.tsx` के रूप में रैप किया गया है (लेज़ी-लोडेड, `ssr: false`)।

### बिल्ड टैब

टूल/फ़ंक्शन कॉलिंग और संरचित आउटपुट UI:

- `ToolsBuilder.tsx` — प्रत्येक टूल के लिए JSON स्कीमा एडिटर के साथ `tools[]` जोड़ें/संपादित करें/हटाएँ।
  `ToolDefinitionSchema` (Zod) के माध्यम से पैरामीटर सत्यापित करता है।
- `StructuredOutputEditor.tsx` — JSON मोड टॉगल + JSON स्कीमा एडिटर।
  `StructuredOutputSchema` (Zod) के माध्यम से स्कीमा के विरुद्ध प्रतिक्रिया सत्यापित करता है।
- `tools[]` और/या `response_format` के साथ `/v1/chat/completions` को अनुरोध भेजता है।

## कॉन्फ़िगरेशन पेन (साझा)

`StudioConfigPane.tsx` — हमेशा दृश्यमान, संक्षिप्त करने योग्य।

| फ़ील्ड            | कंपोनेंट              | टिप्पणियाँ                                                                  |
| ----------------- | --------------------- | --------------------------------------------------------------------------- |
| एंडपॉइंट          | `<select>`            | `PlaygroundEndpoint` से मेल खाने वाले 10 विकल्प                             |
| मॉडल              | `<input>`             | मुक्त टेक्स्ट, जैसे `openai/gpt-4o`                                         |
| सिस्टम प्रॉम्प्ट  | `<textarea>`          | सभी टैब में दिया जाता है                                                    |
| पैरामीटर          | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop      |
| प्रीसेट           | `PresetPicker`        | नामित कॉन्फ़िगरेशन स्नैपशॉट लोड/सहेजें (DB में स्थायी रूप से संग्रहीत)      |
| प्रॉम्प्ट सुधारें | `ImprovePromptButton` | कोटा-चेतावनी मोडल खोलता है, `/api/playground/improve-prompt` को कॉल करता है |

स्टेट को `PlaygroundStudio.tsx` में ऊपर उठाया जाता है और सभी टैब को पास किया जाता है। टैब बदलने पर
कॉन्फ़िगरेशन स्टेट संरक्षित रहता है।

`codeExport.ts` का उपयोग करता है। API कुंजी प्लेसहोल्डर हमेशा `$OMNIROUTE_API_KEY` होता है (D11)।

## प्रॉम्प्ट सुधारक

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. मोडल चेतावनी देता है कि "इससे कोटा खर्च होगा"।
2. पुष्टि करने पर, रूट को `{ system, prompt, model, tone }` भेजता है।
3. रूट आंतरिक रूप से `promptImprover.META_SYSTEM_PROMPT` के साथ `/v1/chat/completions` को कॉल करता है।
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` लौटाता है।
5. UI, कॉन्फ़िगरेशन पेन के सिस्टम प्रॉम्प्ट और चैट टैब के उपयोगकर्ता प्रॉम्प्ट को पैच करता है।

## प्रीसेट

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- `playground_presets` SQLite तालिका में संग्रहीत (माइग्रेशन `084_playground_presets.sql`)।
- प्रत्येक प्रीसेट में ये संग्रहीत होते हैं: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`।
- CRUD: `GET` सूची, `POST` बनाएँ, `GET /:id`, `PUT /:id`, `DELETE /:id`।

---

## स्ट्रीम मेट्रिक्स

`useStreamMetrics.ts` + `streamMetrics.ts` (शुद्ध फ़ंक्शन):

- `start()` — अनुरोध शुरू होने का समय रिकॉर्ड करता है।
- `onFirstChunk()` — TTFT रिकॉर्ड करता है।
- `onChunk(n)` — पूर्णता टोकन की संख्या संचित करता है।
- `finish(usage?)` — अंतिम मेट्रिक्स की गणना करता है: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`।
- मूल्य निर्धारण `src/lib/playground/types.ts` की स्थिर तालिका से लिया जाता है ("अनुमानित" के रूप में लेबल किया गया — D13)।

## समस्या निवारण

| लक्षण                                        | कारण                               | समाधान                                                                                          |
| -------------------------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------- |
| API टैब में Monaco एडिटर रेंडर नहीं हो रहा   | SSR ने Monaco लोड किया             | सत्यापित करें कि `ApiTab`, `dynamic(..., { ssr: false })` का उपयोग करता है                      |
| तुलना स्ट्रीम क्रमिक रूप से चलती हैं         | `Promise.all` का गलत उपयोग         | सभी स्ट्रीम प्रारंभ एक ही `Promise.all` कॉल में डिस्पैच होने चाहिए                              |
| मेट्रिक्स में TTFT `null` दिखता है           | पहला चंक हैंडलर कनेक्ट नहीं है     | जाँचें कि SSE रीडर लूप में `useStreamMetrics.onFirstChunk()` कॉल किया गया है                    |
| प्रीसेट बना नहीं रहता                        | DB माइग्रेशन नहीं चला              | `npm run db:migrate` चलाएँ या सर्वर को पुनः प्रारंभ करें (स्टार्टअप पर माइग्रेशन स्वतः चलता है) |
| प्रॉम्प्ट सुधारने पर 502 लौटता है            | Config में मॉडल सेट नहीं है        | सुधार करने से पहले उपयोगकर्ता को Config पेन में मॉडल का नाम दर्ज करना होगा                      |
| एक्सपोर्ट कोड में `MISSING_API_KEY` दिखता है | प्लेसहोल्डर सम्मिलित नहीं किया गया | `codeExport.ts` हमेशा `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"` का उपयोग करता है             |
