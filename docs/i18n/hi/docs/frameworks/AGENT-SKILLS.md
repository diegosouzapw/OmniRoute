> **प्रामाणिक स्रोत:** `src/lib/agentSkills/` (कैटलॉग, जनरेटर, पार्सर) + `skills/` डायरेक्टरी (SKILL.md फ़ाइलें)
> **अंतिम अपडेट:** 2026-08-02 — v3.8.50

Agent Skills संरचित SKILL.md फ़ाइलें हैं, जो बाहरी एजेंटों, MCP क्लाइंटों और A2A ऑर्केस्ट्रेटरों को OmniRoute के REST API और CLI का उपयोग करना सिखाती हैं। [Omni Skills](./SKILLS.md) (जो OmniRoute के भीतर निष्पादित होने वाली LLM टूल परिभाषाएँ हैं) के विपरीत, Agent Skills एक _दस्तावेज़ीकरण कैटलॉग_ हैं — स्थिर markdown जिसे सीधे एजेंट संदर्भ में दिया जा सकता है।

---

## अवलोकन

कैटलॉग में **45 Agent Skills** (23 REST API + 21 CLI + 1 कॉन्फ़िगरेशन वर्कफ़्लो) शामिल हैं। प्रत्येक स्किल में निम्नलिखित होते हैं:

- एक **कैनोनिकल ID** (`omni-auth`, `cli-serve`, आदि)
- `skills/{id}/SKILL.md` में एक **SKILL.md** फ़ाइल, जिसमें YAML frontmatter (`name`, `description`) + विस्तृत markdown बॉडी होती है
- OpenAPI स्पेसिफ़िकेशन और CLI रजिस्ट्री से प्राप्त **REST एंडपॉइंट** (API स्किल) या **CLI सबकमांड** (CLI स्किल)
- लाइव फ़ेच के लिए एक **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API खोज

| एंडपॉइंट                     | विधि | विवरण                                                                    | प्रमाणीकरण |
| :--------------------------- | :--- | :----------------------------------------------------------------------- | :--------- |
| `/api/agent-skills`          | GET  | कैटलॉग सूचीबद्ध करें (वैकल्पिक `?category=api\|cli\|config&area=<area>`) | कोई नहीं   |
| `/api/agent-skills/{id}`     | GET  | किसी एक स्किल का मेटाडेटा प्राप्त करें                                   | कोई नहीं   |
| `/api/agent-skills/{id}/raw` | GET  | SKILL.md को `text/markdown` के रूप में प्राप्त करें                      | कोई नहीं   |
| `/api/agent-skills/coverage` | GET  | कवरेज आँकड़े (कितनी SKILL.md फ़ाइलें मौजूद हैं)                          | कोई नहीं   |
| `/api/agent-skills/generate` | POST | जनरेटर ट्रिगर करें (dryRun/prune/onlyIds)                                | प्रबंधन    |

उदाहरण — सभी API स्किल सूचीबद्ध करें:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

उदाहरण — एक SKILL.md प्राप्त करें:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## A2A खोज

A2A स्किल `list-capabilities` संपूर्ण 45-स्किल कैटलॉग को मार्कडाउन तालिका आर्टिफ़ैक्ट के रूप में लौटाती है। बाहरी ऑर्केस्ट्रेटर इसे इस प्रकार इनवोक कर सकते हैं:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

प्रोटोकॉल विवरण के लिए [A2A-SERVER.md](./A2A-SERVER.md) देखें।

## बाहरी एजेंट Skills का उपयोग कैसे करते हैं

### 1. REST के माध्यम से खोज

```bash
# पूरा कैटलॉग प्राप्त करें
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# संदर्भ इंजेक्शन के लिए SKILL.md प्राप्त करें
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP के माध्यम से खोज

```typescript
// Claude Desktop / Cursor MCP क्लाइंट में:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → प्रत्येक के rawUrl सहित AgentSkill की सरणी
```

### 3. A2A के माध्यम से खोज

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table सभी 45 skill IDs + rawUrl कॉलम वाली एक markdown तालिका है
```

### 4. सीधे GitHub raw से प्राप्त करना (सर्वर आवश्यक नहीं)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## जेनरेटर

जेनरेटर क्यूरेट किए गए कैटलॉग + OpenAPI स्पेसिफिकेशन + CLI रजिस्ट्री को पढ़ता है और प्रत्येक प्रविष्टि के लिए `skills/{id}/SKILL.md` लिखता है:

```bash
# पूर्वावलोकन (ड्राई रन, कोई लेखन नहीं)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# पूर्ण पुनर्जनन
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# विशिष्ट IDs को पुनः जनरेट करें
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

जेनरेटर की प्रतिक्रिया एक `GeneratorReport` है:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
