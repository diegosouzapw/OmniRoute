## 1. Stvarno stanje servisa (zvanična dokumentacija, unakrsno provereno)

- Osnovni URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - parametri: `query` (obavezan), `max_results` (1-10, podrazumevano 10), `tag` (`{domain}.{sub_domain}` vertikalno usmeravanje), `zone` (cn/intl), `language`, `params` (strukturirana polja vertikale), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - katalog mogućnosti, NE uračunava se u kvotu.
- `POST /v1/extract` - preuzima/izdvaja `{url, title, content}`; strogo JSON telo, ograničenje od 16 KiB.
- `POST /v1/auth/email/register` - registracija jednim pozivom, vraća jednokratni ključ u obliku običnog teksta `as_sk_...`.
- Autentifikacija: opcioni `Authorization: Bearer <as_sk_...>`; anonimni pristup prelazi na ograničenja po IP adresi i troši dnevnu besplatnu kvotu; nevažeći ključ vraća 401/403 BEZ neprimetnog prelaska na anonimni pristup.
- Besplatni paket: 1000 zahteva dnevno, 20 QPS po ključu. Plaćeni paket: cena nije određena (uskoro).
- Omotač odgovora: uspeh `{code: 0, message: "success", request_id, data}`; neuspeh `{code: -1, message}`. Greške autentifikacije/kvote nemaju strukturirani `error_code` (tekst poruke je signal); greške specifične za izdvajanje imaju `error_code` (`invalid_extract_url`, `extract_failed`). Nema zaglavlja `Retry-After` za 429.

## 3. Одлуке (све донете 2026-08-26)

1. **Поставка рутирања: `fallbackOnly`.** Образложење: бесплатни добављач са трошком 0 никада не сме да преузме примат у аутоматском рутирању по трошку; експлицитни избор и повратак након отказа остају непромењени. Преседан: спојени xquik унос.
2. **Опсег: webSearch + webFetch путем `POST /v1/extract` у v1.** Усклађено са менталним моделом двоструких могућности tavily/exa. Вертикалне површине (`tag`, `sub-domains`, `batch_search`) остају ван опсега — тренутно не постоји IR за вертикалне параметре.
3. **Приказ квоте: `freeMonthlyQuota: 0`** (конзервативни приказ у стилу xquik). Стварно ограничење (1000 захтева дневно, дневно ресетовање) уместо тога је наведено у тексту `authHint` каталога корисничког интерфејса. Образложење: приказ квоте мора да одговара семантици ресетовања; претварање дневног ограничења у месечни еквивалент (30000) представља лажно обећање које кориснички интерфејс не може да испуни.
4. **searchTypes: само `["web"]`.** Не постоје јавно доступни докази о вертикали за вести/слике у AnySearch API-ју; мрежни пролази који интегришу API-је без документоване вертикале (нпр. Google Custom Search) излажу само веб, уместо да прећутно мапирају вести -> веб.
5. **Поставка кључа:** рад без кључа је подржан; неважећи кључ враћа 401/403 и никада се прећутно не деградира на анонимни приступ (одражава уговор узводног сервиса).
6. **Намерна изузимања:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (пресретање ћаскања остаје на firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (анонимне удаљене крајње тачке деле један скуп ограничен IP адресом за сваку излазну IP адресу, па је издвајање без кључа опционално, а не кандидат за аутоматско рутирање); `QUOTA_STATUS_PROVIDERS` (AnySearch сигнализира квоту путем статуса 429/омотача, а не статуса 402/403).

## 4. Референце

- xquik шаблон: commit a0ceccc, PR #11370 (у стаблу на release/v3.8.51).
- Званична документација за AnySearch: https://anysearch.com/docs, https://anysearch.com/pricing; MCP каталог mcpservers.org/servers/anysearch-ai/anysearch-mcp-server; репозиторијум вештине github.com/anysearch-ai/anysearch-skill.
