## 1. Antigravity у односу на Antigravity CLI (agy)

Оба добављача користе **исти Google позадински систем** — идентичан OAuth клијент, освежавање токена, крајње тачке и Google налоге. Разлика је у томе које моделе видите.

> Погледајте [најаву Antigravity CLI-ја](https://antigravity.google/blog/introducing-google-antigravity-cli) за званично Google-ово поређење.

| Аспект                   | `antigravity` (IDE)                            | `agy` (CLI)                                                 |
| ------------------------ | ---------------------------------------------- | ----------------------------------------------------------- |
| **Google производ**      | Antigravity 2.0 / Antigravity IDE              | Antigravity CLI                                             |
| **Позадински систем**    | Исти Google Cloud Code API                     | Исти Google Cloud Code API                                  |
| **OAuth / токен**        | Исти клијент, исто освежавање                  | Исти клијент, исто освежавање                               |
| **Каталог модела**       | Статичка одабрана листа (уграђена у OmniRoute) | Динамички преузет од Google-а преко `:fetchAvailableModels` |
| **Claude модели**        | Sonnet 4.6, Opus 4.6 (по 4 варијанте)          | Sonnet 4.6, Opus 4.6 (по 4 варијанте)                       |
| **Именовање Gemini-ја**  | Јасне ознаке (Low/Medium/High)                 | Изворни ID-ови (extra-low/low/agent)                        |
| **Додатни модели**       | `gpt-oss-120b-medium`                          | Може укључивати додатне Google-ове моделе                   |
| **Подразумевана намена** | Интеграција са IDE-ом (VS Code, JetBrains)     | Приступ преко CLI-ја / API-ја                               |
| **Квота**                | Дели се са agy-јем (исти Google налог)         | Дели се са antigravity-јем (исти Google налог)              |

**Доступни модели (потврђено експериментом, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (различити нивои размишљања)
- Claude: Sonnet 4.6, Opus 4.6 (сваки са варијантама default/low/medium/high)
- Остало: GPT-OSS 120B Medium
- **Claude Sonnet 5 НИЈЕ доступан** — подржане су само варијанте 4.6

**Зашто се каталог модела разликује**: Google-ов CLI је „оптимизован за брзину и мало додатно оптерећење“ и „заједнички оптимизован са Gemini моделима“ (према званичном Google-овом блогу). Веб/IDE производ је „оптимизован за свеобухватност“. CLI користи `:fetchAvailableModels` за динамичко откривање модела, док IDE користи статичку одабрану листу.

**У пракси**: Користите префикс `agy/` за Gemini моделе (нпр. `agy/gemini-3.7-flash-high`). Користите `antigravity/` за статичку одабрану листу. Оба користе исти Google позадински систем, али приказују различита имена модела. Квота се дели — коришћење било ког добављача урачунава се у ограничења истог Google налога.

## 2. Google One AI Pro: Систем квота

> Погледајте [Antigravity документацију: Планови](https://antigravity.google/docs/plans) за званичне детаље о квотама и [Измене Antigravity планова](https://antigravity.google/blog/changes-to-antigravity-plans) за најновије измене цена.

Google Antigravity користи **двослојну квоту** засновану на „обављеном раду“ (рачунарском оптерећењу), а не на броју порука.

### Два слоја

| Слој                 | Шта представља                              | Циклус освежавања                                                                                          |
| -------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **5-часовни спринт** | Тренутно доступна количина „обављеног рада“ | Ресетује се 5 сати након првог захтева у сесији                                                            |
| **7-дневна основа**  | Недељно строго ограничење                   | Има предност над 5-часовним освежавањем ако се достигне; приступ је блокиран до следећег 7-дневног периода |

**Како се израчунава „обављени рад“**: Задаци који интензивно користе агенте (нпр. „Рефакториши цело ово спремиште“) троше квоту много брже од једноставних задатака (нпр. „Исправи ову функцију“). Не постоји контролна табла која приказује потрошњу у реалном времену.

### Нивои планова

| План         | Цена            | Квота                                           | Недељно ограничење                                           |
| ------------ | --------------- | ----------------------------------------------- | ------------------------------------------------------------ |
| Бесплатни    | $0              | Значајна квота, освежава се недељно             | Да                                                           |
| AI Pro       | $19.99/месечно  | Висока квота, континуирано 5-часовно освежавање | Да (има предност над 5-часовним ограничењем ако се достигне) |
| AI Ultra 5x  | $99.99/месечно  | 5x већа квота од Pro плана                      | Без недељног ограничења                                      |
| AI Ultra 20x | $199.99/месечно | 20x већа квота од Pro плана                     | Без недељног ограничења                                      |

### Gemini и модели који нису Gemini

- **Gemini модели** (Flash + Pro): Деле једно ограничење учесталости, које се троши у складу са API ценама. Ако је Flash 8x јефтинији од Pro модела, добијате 8x више Flash токена.
- **Модели који нису Gemini** (Claude, GPT-OSS): Имају **засебна** ограничења учесталости. Могу остати доступни чак и када је Gemini блокиран.

### AI кредити (прекорачење)

> Погледајте [Google One AI кредити](https://support.google.com/googleone/answer/14534406) да бисте сазнали како кредити функционишу.

Када се основна квота исцрпи:

- **Никада**: Чека се да се квота освежи; приказује се „Достигнута је основна квота модела“
- **Увек**: Аутоматски се користе AI кредити; систем се враћа на основну квоту када се она освежи

Кредити се купују засебно и одузимају се по стандардним API ценама.

### Кључни детаљи

- Квота се **дели на нивоу налога** — исти Google налог у Antigravity IDE-у, CLI-ју и OmniRoute-у дели један скуп квоте
- Сваки Google налог има сопствену независну квоту — више налога = више скупова квота
- Корисници AI Pro плана пријавили су **7-дневне блокаде** уместо 5-часовних ресетовања када се достигне недељна основа (Google је потврдио да је ово намерно предвиђено за периоде велике потражње)

**Када се квота вашег налога исцрпи**: OmniRoute аутоматски поново покушава са следећим доступним налогом у комбинованој рути. Није потребна ручна интервенција.

## 3. Како добити projectId

Свакој antigravity/agy вези потребан је Google Cloud Code `projectId`. Без њега, крајња тачка `/v1internal:models` враћа 404.

### Метод A: Аутоматски (препоручено)

OmniRoute ово обавља аутоматски. Када додате нови Google налог путем OAuth-а на контролној табли:

1. OmniRoute освежава токен
2. Позива `loadCodeAssist` да би пронашао projectId
3. Ако пројекат не постоји, позива `onboardUser` да би га направио
4. Поново позива `loadCodeAssist` да би добио новонаправљени projectId
5. Чува га у бази података

**Ово функционише за већину налога** — нису потребни ручни кораци.

### Метод B: Ручно путем agy CLI-ја

Ако аутоматско откривање не успе (погледајте Одељак 5 да бисте сазнали када се то дешава):

```bash
# Инсталирајте agy CLI (ако већ није инсталиран)
npm install -g @anthropic-ai/agy

# Пријавите се помоћу свог Google налога
agy login

# Изаберите налог који треба активирати
# Ово покреће Cloud Code регистрацију и додељује projectId
```

Након што се `agy login` успешно заврши, освежите токен на OmniRoute контролној табли. projectId ће бити аутоматски откривен.

### Како проверити

Проверите базу података:

```bash
# Унутар OmniRoute контејнера
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Или проверите евиденцију:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuth URI za preusmeravanje

### Problem

Google OAuth zahteva važeći URI za preusmeravanje. OmniRoute podrazumevano koristi `http://127.0.0.1:20128/callback` (povratna petlja). Ovo funkcioniše za lokalne verzije, ali **ne funkcioniše kod udaljenih implementacija** (npr. servera kome se pristupa preko LAN IP adrese).

Google odbija URI-je za preusmeravanje koji:

- Koriste IP adrese (mora se koristiti domen koji se završava sa `.com`, `.org` itd.)
- Ne podudaraju se sa registrovanim URI-jima za preusmeravanje u konfiguraciji OAuth klijenta

### Rešenje

**Opcija A: Koristite ugrađeni OAuth tok (podrazumevano)**

- Funkcioniše kada OmniRoute-u pristupate preko `localhost` ili `127.0.0.1`
- Nije potrebna nikakva konfiguracija

**Opcija B: Prilagođeni OAuth akreditivi**

- Podesite `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` u svom okruženju
- Navedite sopstvene Google OAuth akreditive:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Registrujte `https://your-domain.com/callback` kao ovlašćeni URI za preusmeravanje u Google Cloud Console

**Opcija C: Koristite agy CLI za početno prijavljivanje**

- Pokrenite `agy login` na računaru koji će pristupati OmniRoute-u
- OAuth tok se završava lokalno, a tokeni se čuvaju
- Uvezite vezu u OmniRoute preko kontrolne table

### Ograničenja

- Prilagođeni OAuth akreditivi zahtevaju naziv domena (Google ne prihvata IP adrese kao URI-je za preusmeravanje)
- Ako nemate domen, umesto toga koristite opciju A ili C

## 5. Rešavanje problema: Kada automatsko podešavanje ne uspe

OmniRoute automatski obavlja otkrivanje projectId-a i uvođenje za većinu naloga. Kada to ne uspe, osnovni uzrok je obično jedan od sledećih:

### Region naloga je blokiran

**Simptom**: `agy login` vraća „Provera podobnosti nije uspela: Vaš trenutni nalog ne ispunjava uslove za Antigravity jer on trenutno nije dostupan na vašoj lokaciji.“

**Osnovni uzrok**: Google nalozi imaju pozadinsko polje „Country Association“ koje se podešava prilikom registracije. agy CLI i Cloud Code API strogo proveravaju ovo polje — za razliku od veb-verzije Gemini-ja, koja proverava samo vašu trenutnu IP adresu.

> Da biste proverili ili promenili region povezan sa svojim nalogom, posetite [Google obrazac za povezivanje zemlje](https://policies.google.com/country-association-form).

**Zašto veb-verzija Gemini-ja funkcioniše, ali agy ne funkcioniše**:

- Veb-verzija Gemini-ja / Google One: proverava samo trenutnu IP adresu (proxy funkcioniše)
- agy CLI / Cloud Code API: čita pozadinsko polje „Country Association“ (proxy ne pomaže)

**Rešenje**:

1. Posetite [Google obrazac za povezivanje zemlje](https://policies.google.com/country-association-form) dok koristite IP adresu iz SAD-a
2. Pošaljite zahtev za promenu regiona (izaberite „Živim u drugoj zemlji“)
3. Sačekajte 1–24 sata da Google obradi zahtev i pošalje obaveštenje e-poštom
4. Nakon toga bi `agy login` trebalo da uspe

### Nalog nema Cloud Code projekat

**Simptom**: Evidencije prikazuju `loadCodeAssist returned no project id` i `onboardUser failed (400)`.

**Osnovni uzrok**: Nalog nikada nije bio registrovan u Google Cloud Code-u, a automatsko uvođenje nije uspelo.

**Rešenje**: Ručno pokrenite `agy login` da biste aktivirali Cloud Code registraciju, a zatim osvežite token na OmniRoute kontrolnoj tabli.

### Token je istekao ili opozvan

**Simptom**: Greške 401 u evidencijama ili poruke „Token je istekao“.

**Rešenje**: Osvežite token putem Kontrolna tabla → Dobavljači → agy → Kliknite na ikonu za osvežavanje. Ako je sam token za osvežavanje opozvan, moraćete ponovo da se autentifikujete putem OAuth-a.

```
   └─ Не ради → Проверите поруку о грешци; вероватно је проблем у региону или претплати
```
