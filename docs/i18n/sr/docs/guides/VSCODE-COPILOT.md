**OmniCopilot** ставља сваки модел који ваш OmniRoute опслужује у _изворни_ бирач модела
за GitHub Copilot Chat. Нема друге бочне траке, нема засебног корисничког интерфејса за ћаскање — Copilot режим агента, позивање алата,
MCP сервери и прилагођена упутства настављају да раде, само на моделу који изаберете.

|                            |                                                                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Инсталација (VS Code)**  | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Инсталација (форкови)**  | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Изворни кôд / проблеми** | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Захтева**                | VS Code 1.104+                                                                                                                                  |

> **Copilot претплата није потребна.** Од верзије VS Code 1.122, добављач језичког модела ради
> без пријављивања на GitHub и без икаквог Copilot плана. Уметнуте допуне и
> функције засноване на угнежђивањима остају ван API-ја добављача и и даље захтевају Copilot.

## Подешавање

1. **Покрените OmniRoute** — `npm install -g omniroute && omniroute` (контролна табла на `http://localhost:20128`).
2. **Инсталирајте проширење** — потражите „OmniRoute“ у приказу Extensions.
3. **Изаберите модел** — Copilot Chat → бирач модела → **Manage Models…** → **OmniRoute**, а затим означите
   шта желите.

Није потребно ништа подешавати када OmniRoute ради на подразумеваном порту. За удаљену инстанцу отворите
**OmniRoute икону на траци активности** (или покрените `OmniRoute: Manage Connection`) и подесите:

- **URL сервера** — корен сервера, нпр. `http://192.168.0.15:20128`. Суфикс `/v1`
  додаје проширење; немојте га укључивати.
- **API кључ** — само када сервер поставља `REQUIRE_API_KEY`. Чува се у складишту кључева оперативног система преко VS
  Code SecretStorage, никада у `settings.json`.

## Шта ће бирач приказати

Проширење не приказује необрађени садржај одговора `GET /v1/models` — оно га обликује, а број који
видите мањи је од величине каталога из два намерна разлога.

### Захтева један идентификатор по моделу

`MODELS_CATALOG_PREFIX_MODE` подразумевано има вредност **`dual`**, која оглашава сваки модел два пута — једном
са кратким префиксом псеудонима и једном са канонским префиксом добављача — тако да старије конфигурације
клијената настављају да разрешавају оба облика:

```
cc/claude-sonnet-4-6        ← префикс псеудонима
claude/claude-sonnet-4-6    ← канонски префикс, исти модел
```

Проширење захтева **`GET /v1/models?prefix=alias`** како би за сваки модел стигао један идентификатор, без
промене подешавања на нивоу сервера за ваше друге клијенте. На референтној инстанци, тиме је број смањен са
**2345 ставки на 1396 — 949 дупликата, без изгубљених модела.**

Ако бисте радије то исправили на нивоу сервера за _сваког_ клијента, поставите функционалну заставицу
`MODELS_CATALOG_PREFIX_MODE` на `alias` у контролној табли. Погледајте
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) за
параметар упита и табелу по режимима.

### Скрива моделе који не могу да се користе за ћаскање

Каталог такође наводи моделе за слике, видео, звук, поновно рангирање, угнежђивање и модерацију. Они се
свакако одбијају при захтеву за ћаскање:

```
HTTP 400 — Модел '<id>' је модел за генерисање слика и не може да се користи на
/v1/chat/completions. Уместо тога користите POST /v1/images/generations.
```

па се филтрирају на основу свог поља `type` пре него што стигну до бирача. **Модели Responses API-ја
се задржавају** — свака Codex / GPT-5.x ставка оглашава `supported_endpoints: ["responses"]`,
а OmniRoute их преводи за `/v1/chat/completions`, тако да су потпуно употребљиви.

### Добављачи које никада нисте конфигурисали

Каталог наводи моделе добављача са **активном везом**, као и све **noAuth**
добављаче — оне без кључа који чине велики део бесплатног нивоа. То је намерно. Да бисте
их сакрили, додајте их у `blockedProviders` у подешавањима контролне табле; у
проширењу се ништа не мења.

## Контролна табла унутар VS Code картице

`omnicopilot.dashboardOpen: "editor"` приказује OmniRoute контролну таблу у картици уређивача путем
Simple Browser-а уместо у спољном прегледачу. Уграђивање се **изричито омогућава на серверу** путем
`DASHBOARD_ALLOW_EMBED=vscode`, чиме се HTML странице испоручују са
`frame-ancestors 'self' vscode-webview:` уместо подразумеваног `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Површина API-ја (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) у сваком
случају задржава строга заглавља.

> ⚠️ **Ово је опција у време изградње, а не током извршавања.** Next.js компилира `headers()` у манифест
> рута, па `next.config.mjs` чита променљиву током изградње пакета
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Њено постављање испред већ изграђеног сервера не мења ништа — заглавља су већ уграђена.

```bash
# променљива мора бити присутна у команди за ИЗГРАДЊУ
DASHBOARD_ALLOW_EMBED=vscode npm run build        # или npm run build:release
npm start
```

| Начин инсталације          | Да ли можете да омогућите уграђивање?                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Из изворног кода           | ✅ поставите променљиву у команди за изградњу, као што је приказано изнад                                                                        |
| `npm install -g omniroute` | ❌ објављени пакет садржи унапред изграђен пакет — уместо тога извршите изградњу из изворног кода                                                |
| Docker слика               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — унапред изграђена слика на Docker Hub-у не подржава уграђивање |

Без верзије изграђене са омогућеним уграђивањем, страница одбија приказивање у оквиру, екстензија то
открива из заглавља одговора и прелази на спољни прегледач — ништа се не квари, а обавештење о томе
приказује се једном. Погледајте [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) и проблем
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Конфигурисање других алата из VS Code-а

**`OmniRoute: Configure Coding CLI`** користи `omniroute` CLI за уписивање профила спремних за употребу
за Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo и Roo — истих конфигурација које су описане у
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). API кључ се CLI-ју прослеђује путем променљиве окружења
`OMNIROUTE_API_KEY`, никада преко командне линије.

## Решавање проблема

| Симптом                                                       | Узрок / решење                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Нема OmniRoute модела у бирачу                                | Сервер није доступан. Тачка на статусној траци постаје сива; покрените `OmniRoute: Check Connection`. Откривање је намерно неприметно и не додаје моделе уместо да приказује упит.                                                                                      |
| Сваки модел се приказује двапут                               | Користите OmniCopilot старији од 1.0.1 — ажурирајте га. Екстензија сада захтева `?prefix=alias`.                                                                                                                                                                        |
| Модел за слике/звук је раније био на листи, а сада га нема    | То је намерно од верзије 1.0.1 — такав модел никада није могао да одговори на захтев за ћаскање.                                                                                                                                                                        |
| Панел недостаје на траци активности                           | VS Code премешта додатне контејнере приказа у одељак **"…"** при дну траке активности, а контејнер сакривен десним кликом остаје сакривен. Кликните десним тастером на траку активности → означите **OmniRoute** или га отворите помоћу `OmniRoute: Manage Connection`. |
| Контролна табла се отвара у прегледачу упркос режиму `editor` | Сервер није **изграђен** са `DASHBOARD_ALLOW_EMBED=vscode` (погледајте изнад) — његово постављање при покретању унапред изграђене инсталације не мења ништа. Резервни прелаз је намеран.                                                                                |
| Листа модела је застарела након промене добављача             | `OmniRoute: Refresh Models` или веза ↻ у панелу.                                                                                                                                                                                                                        |
