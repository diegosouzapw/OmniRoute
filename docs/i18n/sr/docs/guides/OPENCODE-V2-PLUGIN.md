`@omniroute/opencode-plugin-v2` додаје цео ваш OmniRoute каталог — моделе, комбинације и
аутоматске комбинације — у OpenCode v2 бирач модела, заједно са називима за приказ, ценама и
ограничењима бесплатног нивоа.

То је засебан пакет у односу на `@omniroute/opencode-plugin` зато што OpenCode v1 и v2 учитавају
додатке преко различитих уговора. Изаберите онај који одговара главној верзији вашег OpenCode-а;
ништа се не дели између њих, тако да надоградња једног никада не захтева надоградњу другог.

## Захтеви

- OpenCode v2.
- Доступан OmniRoute мрежни пролаз (подразумевано `http://localhost:20128`).
- Node.js 22 или 24.

## Инсталација

Додајте додатак у `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Модели ће се затим појавити као `omniroute/<provider>/<model>`; `providerId` одређује тај префикс и
ID интеграције под којим OpenCode чува акредитив.

## Акредитиви

Додатак тражи кључ мрежног пролаза на три места, следећим редоследом:

1. **Акредитив који сте повезали у OpenCode-у.** Додатак региструје интеграцију, тако да
   OpenCode-ов сопствени ток аутентификације може да сачува кључ. Ништа се не уписује у `opencode.json` — ово је пожељна опција.
2. `apiKey` у опцијама додатка, за замену подешавања на нивоу пројекта. Тако се кључ смешта у датотеку
   коју можда шаљете у репозиторијум.
3. `OMNIROUTE_API_KEY` у окружењу.

Ако ниједна од ове три опције није доступна, каталог је празан и додатак то једном саопштава при покретању,
уместо да вам остави неприметно празан бирач.

### Токен за управљање је засебан кључ

Комбинације, стање добављача и обогаћивање података (називи за приказ, цене и ограничења бесплатног нивоа) долазе са
`/api/*` крајњих тачака мрежног пролаза, које већина инсталација штити **управљачким** токеном,
а не кључем за извршавање закључивања:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<токен за управљачки приступ за читање>"
}
```

Ако није подешен, `managementReadToken` се враћа на `apiKey`. Када мрежни пролаз одбије ту резервну
вредност, каталог се и даље објављује, али са сировим ID-овима модела уместо назива за приказ, без
уклањања дупликата канонских алијаса, цена и комбинација. Додатак упозорава једном по крајњој тачки када се то догоди,
наводећи крајњу тачку и шта је изгубљено — тако да разлог осиромашеног бирача никада није нејасан.

## Опције

| Кључ                             | Подразумевано                                 | Напомене                                                                                                    |
| -------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                 | ID добављача, ID интеграције и префикс под којим се модели приказују                                        |
| `baseURL`                        | обавезно                                      | Корен мрежног пролаза, само `http(s)`; суфикс `/v1` се додаје где је потребно                               |
| `apiKey`                         | повезани акредитив, затим `OMNIROUTE_API_KEY` | Кључ за ћаскање за `/v1/*`                                                                                  |
| `managementReadToken`            | враћа се на `apiKey`                          | Кључ за `/api/*` — обично **није** исти                                                                     |
| `displayName`                    | `"OmniRoute"`                                 | Назив добављача у бирачу                                                                                    |
| `timeoutMs`                      | `10000`                                       | Временско ограничење за преузимање по крајњој тачки (аутоматске комбинације користе 5s)                     |
| `modelCacheTtlMs`                | `300000`                                      | TTL кеша каталога; снимак на диску убрзава хладна покретања                                                 |
| `timeouts`                       | враћа се на `timeoutMs`                       | Временска ограничења по крајњој тачки у ms: `models`, `combos`, `autoCombos`, `enrichment`                  |
| `enrichment`                     | `true`                                        | Преузимање назива, цена и ограничења бесплатног нивоа                                                       |
| `providerTag`                    | `true`                                        | Додавање префикса називу за приказ са добављачем вишег нивоа ка којем се захтев усмерава                    |
| `usableOnly`                     | `false`                                       | Задржавање само добављача за које мрежни пролаз пријављује да су конфигурисани                              |
| `visibleModels` / `hiddenModels` | `[]`                                          | Листе дозвољених тачних вредности или суфикса; забрана има предност                                         |
| `geminiSanitization`             | `true`                                        | Уклањање JSON-Schema кључних речи које Gemini одбија из шема алата (`$ref` алати се прослеђују непромењени) |
| `apiFormat.allowAnthropic`       | `false`                                       | Усмеравање ID-ова са листе дозвољених кроз Anthropic API блок                                               |
| `apiFormat.anthropicModels`      | `[]`                                          | Пуни ID-ови модела који се усмеравају ка Anthropic-у                                                        |
| `logLevel` / `startupDebug`      | `warn` / `false`                              | Опширност евиденције                                                                                        |

## Како каталог остаје ажуран

Каталог се преузима по потреби и кешира током `modelCacheTtlMs`, а снимак на диску чува последњи
познати каталог доступним када мрежни пролаз није доступан — прекид рада вас не кошта ничега осим
ажурности. Модели и комбинације се објављују чим стигну; аутоматске комбинације, листа добављача
и слој обогаћивања укључују се када пристигну, тако да једна спора крајња тачка не може да блокира
цео бирач.

Називи садрже оно што мрежни пролаз зна: изворног добављача ка коме се модел усмерава, ознаку `[Free]`
и буџет који иде уз њу — тако да две везе које нуде исти модел остају
препознатљиве. Искључите префикс помоћу `"providerTag": false`.

Не постоји команда за ручно освежавање: OpenCode v2 команде су шаблони упита, а не повратни позиви,
па додатак не може да је изложи. Освежавања прате TTL; од хоста се тражи поновно учитавање само када
су се каталог или слој заиста променили, а никада при сваком освежавању.

## Позивање алата на Gemini-ју

Gemini одбацује цео захтев чије декларације алата садрже `$schema` или
`additionalProperties`, уз одговор `400 INVALID_ARGUMENT`. Додатак уклања те кључне речи из
шема алата намењених Gemini моделу овог добављача и не мења ниједан други захтев.
Алат који садржи `$ref` прослеђује се непромењен уместо да буде очишћен, јер би уклањање
референце проширило шему тако да „прихвата било шта“.
Подесите `"geminiSanitization": false` да бисте то искључили.

## Решавање проблема

| Симптом                                          | Узрок                                                                                                      |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Бирач не приказује ниједан OmniRoute модел       | Ниједан кључ није разрешен (проверите упозорење при покретању) или мрежни пролаз није доступан             |
| Необрађени ID-ови модела, без комбинација и цена | Крајње тачке за управљање одбиле су токен — подесите `managementReadToken`                                 |
| Сесија је фиксирана на `opencode-<id>/…`         | Додатак v1 је објављивао `opencode-<id>`; v2 објављује само `<id>`, па поново изаберите модел под `<id>/…` |
