OmniRoute организује 352 подржана провајдера у 3 економска нивоа. Сваки
захтев пролази кроз њих редом док један не врати успешан одговор — тако
добијате најјефтинији одговарајући одговор без писања резервног кода.

## Ниво 1 — Претплата

**Провајдери које већ плаћате.** OmniRoute користи целокупну квоту пре него
што она истекне.

| Провајдер                        | Зашто је у нивоу 1                                   |
| -------------------------------- | ---------------------------------------------------- |
| Claude Code OAuth                | Anthropic Pro/Team — фиксна цена, често неискоришћен |
| OpenAI Codex (ChatGPT претплата) | Plus/Team укључује Codex квоту                       |
| GitHub Copilot                   | По корисничком месту — квота се обнавља месечно      |
| Cursor IDE                       | Квота Pro плана                                      |
| Antigravity / Devin Desktop      | Уграђене квоте                                       |

**Стратегија**: прво усмерите овде сваки захтев који одговара предностима
модела. Праћење квоте надгледа предстојећа обнављања, а комбинована стратегија
`reset-aware` у складу с тим одређује приоритет. Да бисте прво користили ниво 1
и прешли на плаћене нивое тек када се квота потроши, користите ID `auto/thrifty`
— или `auto/subscription` да бисте остали на капацитету укљученом у план и
у супротном прекинули обраду. Погледајте
[Усмеравање са претплатом као приоритетом](../routing/SUBSCRIPTION_LADDER.md).

## Ниво 2 — Јефтино

**Провајдери са наплатом по токену испод $1/1M токена.** Резервисани су за
послове великог обима или за случај када квоте нивоа 1 достигну ограничења.

| Провајдер                        | Цена (улаз/излаз)   | Предности              |
| -------------------------------- | ------------------- | ---------------------- |
| DeepSeek V4 Pro                  | $0.27 / $1.10 по 1M | Код, резоновање        |
| GLM-4.5                          | $0.60 / $2.20 по 1M | Дуг контекст           |
| MiniMax M1                       | $0.20 / $1.10 по 1M | Брзина                 |
| Qwen Coder                       | $0.30 / $1.20 по 1M | Код                    |
| OpenRouter (оптимизован по цени) | варира              | 100+ модела, динамички |

**Стратегија**: комбинација `cost-optimized` бира модел са најнижом ценом
по токену који испуњава филтер могућности задатка (визуелни унос, JSON режим,
алати, максимални контекст).

## Ниво 3 — Бесплатно

**Провајдери без трошкова** — бесплатни нивои, програми кредита, дневне OAuth квоте.

| Провајдер        | Бесплатна квота / кредити                             |
| ---------------- | ----------------------------------------------------- |
| Kiro AI          | Бесплатни Claude ниво (великодушно поштено коришћење) |
| OpenCode Free    | Без аутентификације, великодушна ограничења брзине    |
| Qoder            | Бесплатан OAuth                                       |
| Google Vertex AI | $300 кредита за нови налог                            |
| Amazon Q         | Бесплатни ниво за AWS кориснике                       |
| Pollinations     | Отворени јавни API                                    |
| Cloudflare AI    | Бесплатни ниво Workers AI                             |

**Стратегија**: комбинација `auto` са ограничењем буџета усмерава овде када
нивои 1 и 2 не успеју или када је постављено `useFreeOnly=true`. Бесплатни
провајдери често имају строжа ограничења брзине — механизам заштитног прекидача
их опоравља након периода чекања.

## Конфигурисање нивоа

Контролна табла → **Нивои** → доделите своје провајдере. Подразумеване вредности
(из `tierDefaults.json`) су разумне; измените их када имате одређене претплате
којима желите да дате приоритет или провајдере које желите да искључите.

Auto-Combo бодовање на основу 16 фактора такође узима у обзир ниво. Погледајте
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Телеметрија

Контролна табла → **Коришћење** приказује токене потрошене по нивоу и дану. Користите ово да бисте:

- Потврдили да је ниво 1 у потпуности искоришћен (у супротном расипате вредност претплате)
- Утврдили који се модели нивоа 2 најчешће бирају (сведите их на 1–2)
- Проверили да ниво 3 штеди новац на тестним/истраживачким радним оптерећењима

## Уобичајени обрасци

### Потпуно бесплатно радно оптерећење

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Снажно усмерава ка нивоу 3; ниво 2 користи само ако ниво 3 није доступан.

### Претплата као приоритет, са јефтином резервном опцијом

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Изричито уређена листа која одговара редоследу ниво 1 → ниво 2 → ниво 3.
