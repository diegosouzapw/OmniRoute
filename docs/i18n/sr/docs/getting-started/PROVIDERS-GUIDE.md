## Шта је провајдер?

Замислите провајдера као **мобилног оператера**. Као што вам је потребан мобилни оператер да бисте телефонирали, потребан вам је AI провајдер да бисте користили AI моделе. OmniRoute је попут телефона који ради са **свим оператерима** — можете аутоматски да се пребацујете између њих.

### Типови провајдера

| Тип             | Шта представља                 | Примери                           | Цена                   |
| --------------- | ------------------------------ | --------------------------------- | ---------------------- |
| **Бесплатно**   | Плаћање није потребно          | Kiro, OpenCode Free, Pollinations | $0                     |
| **API кључ**    | Потребан вам је API кључ       | OpenAI, Anthropic, Google         | Плаћање по коришћењу   |
| **OAuth**       | Пријава помоћу вашег налога    | Claude Code, GitHub Copilot       | Претплата              |
| **Веб колачић** | Користи вашу сесију прегледача | ChatGPT Web (Codex), Gemini Web   | $0 (користи ваш налог) |

### Провајдери са веб колачићима

Погледајте **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** за општа упутства за подешавање, ограничења, решавање проблема и смернице за потврду идентитета специфичне за сваког провајдера.

## Брзи почетак: Повежите свог првог провајдера

### Опционо почетно подешавање бесплатних провајдера

Чаробњак при првом покретању нуди засебну картицу **Подеси бесплатне провајдере**. Он из регистра OmniRoute провајдера који не захтевају потврду идентитета изводи тренутну
листу доступних провајдера, а затим вам омогућава да пре потврде прегледате сваки
провајдер и поништите његов избор. OmniRoute приказује упозорење провајдера и везу ка његовом сајту
како бисте најпре могли да прегледате услове треће стране, приватност, доступност и ограничења броја захтева.

Ова радња је опциона: завршетак чаробњака никада не прави прећутно везе са бесплатним провајдерима.
Праве се само везе за провајдере који још увек недостају, док постојеће прилагођене везе остају
непромењене, а направљени, већ конфигурисани и неуспешни провајдери пријављују се појединачно. Након делимичног резултата можете
безбедно поновити поступак само за неуспешне провајдере.

### Опција A: Бесплатан провајдер (без кредитне картице)

1. Отворите контролну таблу на `http://localhost:20128`
2. Идите на **Провајдери** → **Додај провајдера**
3. Изаберите једног од ових бесплатних провајдера:
   - **Kiro AI** — Бесплатни Claude модели (потврда идентитета није потребна)
   - **OpenCode Free** — Бесплатни GPT модели (потврда идентитета није потребна)
   - **Pollinations** — Бесплатни GPT-5, Claude, Gemini (кључ није потребан)
   - **LongCat** — 10 милиона бесплатних токена (једнократна додела, потребни су налог и KYC)
   - **Cloudflare AI** — Више од 50 модела, 10 хиљада неурона дневно
   - **MLX Gemma 26B** — Локални модел за Apple Silicon (~38.5 токена/с, ~15.9GB RAM-а)
   - **MLX Qwen 3.8 27B** — Локални модел за Apple Silicon (~9.1 токена/с, ~13.1GB RAM-а)
4. Кликните на **Повежи**
5. Готово! Сада имате бесплатан приступ AI-ју.

### Опција B: Провајдер са API кључем (плаћа се)

1. Набавите API кључ са веб-сајта провајдера:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Отворите контролну таблу на `http://localhost:20128`
3. Идите на **Провајдери** → **Додај провајдера**
4. Изаберите свог провајдера
5. Налепите свој API кључ
6. Кликните на **Повежи**
7. Готово! Сада имате приступ моделима тог провајдера.

### Опција C: OAuth провајдер (претплата)

1. Отворите контролну таблу на `http://localhost:20128`
2. Идите на **Провајдери** → **Додај провајдера**
3. Изаберите свог провајдера (нпр. Claude Code, GitHub Copilot)
4. Кликните на **Повежи помоћу OAuth-а**
5. Пријавите се помоћу свог налога
6. Готово! Сада имате приступ моделима обухваћеним вашом претплатом.

### Опција D: Локални MLX модели (Apple Silicon)

За Mac рачунаре са Apple Silicon процесором и обједињеном меморијом, OmniRoute подржава повезивање са локалним MLX моделима који се покрећу преко `mlx-lm.server` као стандардни локални провајдери компатибилни са OpenAI-јем.

#### Предуслови

- **Mac са Apple Silicon процесором** (M1/M2/M3/M4), препоручује се 24GB или више обједињене меморије
- **uv** менаџер пакета: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Брзи почетак

1. **Инсталирајте зависности**:

   ```bash
   # Инсталирајте uv ако већ није инсталиран
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Инсталирајте mlx-lm
   uv pip install mlx-lm
   ```

2. **Ручно покрените MLX сервере** (у засебним терминалима):

   ```bash
   # Терминал 1: Gemma 4 26B A4B IT-QAT (порт 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Терминал 2: Qwen 3.8 27B MLX Mixed (порт 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Повежите се на OmniRoute контролној табли**:
   - Идите на **Провајдери** → **Додај провајдера**
   - Изаберите **MLX Gemma 26B** или **MLX Qwen 3.8 27B**
   - Кликните на **Повежи** (API кључ није потребан)

4. **Користите са OpenCode-ом**:
   ```bash
   # Конфигуришите OpenCode да користи OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Користите MLX моделе
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Управљање меморијом

**Важно**: Са 24GB обједињене меморије, истовремено може да ради само **један велики MLX модел**.

- Gemma 26B: ~15.9GB вршне потрошње меморије
- Qwen 3.8 27B: ~13.1GB вршне потрошње меморије

Овим морате управљати ручно:

- Покрећите само један MLX сервер истовремено или
- Покрените их на засебним рачунарима или
- Зауставите један пре покретања другог

OmniRoute не управља аутоматски процесима MLX сервера — он само усмерава захтеве ка крајњим тачкама компатибилним са OpenAI-јем које конфигуришете.

#### Подршка за позивање алата

Оба модела подржавају позивање алата компатибилно са OpenAI-јем. Тестирајте помоћу:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Решавање проблема

| Проблем                  | Решење                                                                                             |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| Сервер се не покреће     | Проверите `uv run mlx_lm.server --help` и потврдите ID-ове модела                                  |
| Недовољно меморије       | Уверите се да је покренут само један модел; затворите друге апликације; проверите Activity Monitor |
| Веза је одбијена         | Проверите да ли сервер ради на исправном порту (11435/11436)                                       |
| Спори одговори           | Први захтев учитава модел у меморију (~30-60s); наредни захтеви су брзи                            |
| Позивање алата не успева | Уверите се да модел подржава алате; проверите OmniRoute евиденције због грешака при превођењу      |

## Како повезати провајдера (корак по корак)

### Корак 1: Отворите контролну таблу

У прегледачу идите на `http://localhost:20128`.

### Корак 2: Идите на Провајдери

На бочној траци кликните на **Провајдери**.

### Корак 3: Кликните на Додај провајдера

Кликните на дугме **+ Додај провајдера**.

### Корак 4: Изаберите провајдера

Прегледајте листу или потражите свог провајдера. Кликните на њега.

### Корак 5: Унесите приступне податке

- **Бесплатни провајдери**: Приступни подаци нису потребни — само кликните на **Повежи**
- **Провајдери са API кључем**: Налепите свој API кључ
- **OAuth провајдери**: Кликните на **Повежи помоћу OAuth-а** и пријавите се

### Корак 6: Тестирајте везу

Кликните на **Тестирај везу** да бисте проверили да ли ради.

### Корак 7: Готово!

Ваш провајдер је сада повезан. Можете га користити са `model: "auto"` или директно навести провајдера.

## Коришћење више провајдера

OmniRoute најбоље функционише са **више провајдера**. То вам пружа:

- **Аутоматско пребацивање** — Ако један провајдер откаже, OmniRoute покушава са следећим
- **Оптимизацију трошкова** — OmniRoute бира најјефтинијег провајдера за сваки захтев
- **Оптимизацију брзине** — OmniRoute бира најбржег провајдера за сваки захтев
- **Оптимизацију квалитета** — OmniRoute бира најбољег провајдера за сваки задатак

### Препоручено подешавање

Повежите најмање **3 провајдера** за најбоље искуство:

1. **Један бесплатни провајдер** (Kiro, OpenCode Free или Pollinations) — Увек доступан
2. **Један брзи провајдер** (Groq, Cerebras) — За брзе одговоре
3. **Један квалитетан провајдер** (OpenAI, Anthropic, Google) — За сложене задатке

Затим користите `model: "auto"` и OmniRoute ће аутоматски изабрати најбољег провајдера за сваки захтев.

3. Налепите API кључ → Повежи

### Anthropic

1. Преузмите API кључ: https://console.anthropic.com/
2. У OmniRoute-у: Провајдери → Додај провајдера → Anthropic
3. Налепите API кључ → Повежи

### Google (Gemini)

## Честа питања

### „Да ли морам да платим да бих користио OmniRoute?“

**Не!** OmniRoute је бесплатан и отвореног кода. Можете да користите бесплатне провајдере (Kiro, OpenCode Free, Pollinations) без икаквог плаћања. Плаћате само ако одлучите да користите провајдере који се плаћају.

### „Са којим провајдером би требало да почнем?“

Почните са **Kiro AI** — бесплатан је, не захтева API кључ и омогућава вам приступ Claude моделима. Затим по потреби додајте још провајдера.

### „Могу ли да користим више провајдера истовремено?“

**Да!** То је и главна сврха OmniRoute-а. Повежите више провајдера и користите `model: "auto"` како бисте омогућили OmniRoute-у да изабере најбољег за сваки захтев.

### „Шта ако провајдер престане да ради?“

OmniRoute аутоматски прескаче провајдере код којих је дошло до грешке и покушава са следећим. Не морате ништа да радите.

### „Како да прекинем везу са провајдером?“

Идите на Провајдери → кликните на провајдера → кликните на **Прекини везу**.

### „Могу ли да користим постојеће API кључеве?“

**Да!** Ако већ имате API кључеве за OpenAI, Anthropic, Google итд., можете да их користите у OmniRoute-у. Само их налепите приликом повезивања провајдера.
