## Корак 1: Инсталирајте OmniRoute

Изаберите жељени метод:

### Опција A: npm (препоручено)

```bash
npm install -g omniroute
```

### Опција B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` је највиша **објављена** стабилна SemVer верзија. Она **не** прати git грану `main`. За GitOps фиксирајте `diegosouzapw/omniroute:X.Y.Z`. Погледајте [ознаке слика / канале издања](../guides/DOCKER_GUIDE.md#release-channels).

### Опција C: Из изворног кода

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Корак 2: Покрените OmniRoute

```bash
omniroute
```

OmniRoute се покреће на адреси `http://localhost:20128`. Контролна табла се аутоматски отвара.

---

## Корак 3: Повежите бесплатног добављача

OmniRoute можете користити **потпуно бесплатно** тако што ћете повезати бесплатног добављача.

### Опција A: Kiro (бесплатан Claude — без кредитне картице)

1. Отворите контролну таблу на адреси `http://localhost:20128`
2. Идите на **Добављачи** → **Додај добављача**
3. Изаберите **Kiro AI**
4. Кликните на **Повежи** (API кључ није потребан!)
5. Готово! Сада имате бесплатан приступ Claude моделима.

### Опција B: OpenCode Free (без аутентификације)

1. Отворите контролну таблу на адреси `http://localhost:20128`
2. Идите на **Добављачи** → **Додај добављача**
3. Изаберите **OpenCode Free**
4. Кликните на **Повежи** (API кључ није потребан!)
5. Готово! Сада имате бесплатан приступ већем броју модела.

### Опција C: Pollinations (кључ није потребан)

1. Отворите контролну таблу на адреси `http://localhost:20128`
2. Идите на **Добављачи** → **Додај добављача**
3. Изаберите **Pollinations**
4. Кликните на **Повежи** (API кључ није потребан!)
5. Готово! Сада имате бесплатан приступ моделима GPT-5, Claude, Gemini и другим.

---

## Корак 4: Проверите да ли ради

На страници [API кључеви](http://localhost:20128/dashboard/api-manager) направите нови кључ. Сачувајте га јер се неће поново приказати. Имајте у виду да је овај кључ намењен алатима за приступ систему OmniRoute, а не за приступ спољним добављачима.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Требало би да видите списак повезаних модела.

## Корак 5: Усмерите свој IDE или CLI на OmniRoute

У свом IDE или CLI алату подесите:

```
Основни URL: http://localhost:20128/v1
API кључ:    [копирајте са Контролна табла → Крајње тачке]
Модел:       auto
```

То је све! Ваш IDE сада користи OmniRoute са аутоматским избором добављача.

### Пример за IDE: VSCode/Continue.dev

1. У VSCode-у инсталирајте проширење [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Ажурирајте датотеку `~/.continue/config.yaml` додавањем следећих редова:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. У Continue.dev окну за ћаскање изаберите `OmniRoute - Auto` и слаћете захтеве систему OmniRoute.
4. (Опционално) Вежба за читаоца — нека ваш IDE ажурира `config.yaml` свим осталим унапред припремљеним конфигурацијама 😊

### Пример за CLI: Codex CLI

1. У оперативном систему трајно подесите променљиву окружења.
   За macOS/Linux (додајте у `~/.bashrc` или `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

За Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Сада покренимо Codex, али конфигурисан за OmniRoute. Покрените:

```
omniroute launch-codex --model auto
```

Ово можете урадити ручно преко команде `codex` и параметара командне линије којима се задају крајња тачка и API кључ, али уз горњу команду OmniRoute све обавља уместо вас.

Исто покретање једном командом функционише и за друге CLI алате преко генеричког покретача — `omniroute run <target>` подржава `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` и `gemini` (погледајте [CLI интеграције](../guides/CLI-INTEGRATIONS.md)).

3. CLI би сада требало да шаље захтеве систему OmniRoute.

### Потврдите да ваш алат усмерава саобраћај на OmniRoute

Детаље захтева можете видети тако што ћете на левој бочној траци кликнути на [Надзор/евиденције](http://localhost:20128/dashboard/logs). Даљим кликовима можете видети више детаља. Узгред, можете видети које се информације шаљу из вашег омиљеног окружења. Ово је корисно за учење и отклањање грешака.

## Честа питања

### „Да ли ми је потребан API кључ?“

**Не!** Бесплатне добављаче (Kiro, OpenCode Free, Pollinations) можете користити без API кључа. Само их повежите на контролној табли.

### „Шта је `auto`?“

`auto` налаже систему OmniRoute да аутоматски изабере најбољег добављача за сваки захтев. У обзир узима брзину, цену, квалитет и доступност. Детаље потражите у [водичу за Auto-Combo](./AUTO-COMBO-GUIDE.md).

### „Колико кошта?“

Сам OmniRoute је **бесплатан и отвореног кода**. Плаћате само добављаче које користите. Многи добављачи имају бесплатне пакете — погледајте [водич за бесплатне пакете](./FREE-TIERS-GUIDE.md).

### „Могу ли да га користим са Claude Code / Cursor / Copilot?“

**Да!** OmniRoute функционише са сваким алатом који подржава OpenAI формат. Само подесите основни URL на `http://localhost:20128/v1`. Конкретна упутства за подешавање потражите у [водичу за CLI алате](../reference/CLI-TOOLS.md).

### „Шта ако добављач престане да ради?“

OmniRoute аутоматски прескаче неуспешне добављаче и покушава са следећим. Не морате ништа да радите. Детаље потражите у [водичу за Auto-Combo](./AUTO-COMBO-GUIDE.md).
