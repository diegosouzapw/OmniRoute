> **Извор истине:** `src/lib/localCorpus/index.ts` (ограничени текстуални индекс),
> `src/lib/localCorpus/configured.ts` (конфигурисано извршно окружење),
> `src/lib/db/localCorpus.ts` (трајно чување путање кореног директоријума),
> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 MCP алата само за читање) и
> `src/app/api/settings/local-corpus/route.ts` (API за подешавања).

## Шта је то

Local Corpus омогућава оператеру да MCP серверу OmniRoute-а изложи један изричито одобрени директоријум текстуалних датотека. Датотеке остају у свом изворном директоријуму: OmniRoute у SQLite-у чува само канонску путању кореног директоријума и одржава индекс за претрагу у меморији. Садржај корпуса се не копира у репозиторијум или базу података.

Освежавање индекса је инкрементално. Непромењене датотеке се поново користе на основу величине и времена измене, измењене датотеке се поново читају и хеширају помоћу SHA-256, а обрисане датотеке се уклањају. Претрага освежава индекс старији од 30 секунди; позиваоци такође могу да затраже тренутно освежавање.

## Конфигурисање извора

Рута за подешавања захтева исту управљачку аутентификацију као и остали API-ји за подешавања. Прослеђена путања мора већ да постоји и мора бити апсолутна путања директоријума.

```bash
# Повезивање одобреног директоријума
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Провера конфигурације и статуса индекса
curl http://localhost:20128/api/settings/local-corpus

# Прекидање везе без измене изворних датотека
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP алати

Сва три алата захтевају `read:local-corpus`. Одговори алата приказују релативне путање и основни назив кореног директоријума, али никада његову апсолутну путању.

| Алат                  | Опис                                                                                              |
| :-------------------- | :------------------------------------------------------------------------------------------------ |
| `local_corpus_status` | Приказује стање конфигурације, величину индекса, ограничења и време последњег освежавања          |
| `local_corpus_search` | Претражује индексирани текст и враћа ограничене исечке по редовима (до 20 резултата)              |
| `local_corpus_read`   | Чита ограничени опсег редова из једне дозвољене датотеке са путањом релативном у односу на корпус |

Примери MCP улаза:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Безбедносне границе

- Листа дозвољених екстензија усмерена је на текстуалне датотеке: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` и `.yml`.
- Симболичке везе се прескачу. Путање за читање се канонизују и морају остати унутар конфигурисаног кореног директоријума; апсолутне путање и покушаји проласка кроз директоријуме се одбијају.
- Осетљиви и генерисани називи директоријума су искључени: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` и
  `secrets`.
- Подразумевана ограничења су 5.000 датотека, 1 MiB по датотеци, укупно 64 MiB индексираног садржаја, приближно 4.000 знакова по сегменту претраге и 400 редова по читању.
- Датотеке које садрже NUL сматрају се нетекстуалним и прескачу се или одбијају.

Бинарни документи као што су PDF, DOCX, слике и архиве намерно нису подржани. Пре индексирања их конвертујте у одобрени текстуални формат у конфигурисаном директоријуму.

## Напомене за рад

- Промена или брисање конфигурисаног кореног директоријума брише дељени индекс у меморији.
- Поновно покретање процеса одбацује индекс; следећа претрага га поново изграђује из конфигурисаног извора.
- `local_corpus_status` не покреће принудно скенирање. Користите `local_corpus_search` са
  `refresh: true` када је потребно тренутно поновно скенирање.
- Неуспела скенирања и читања се пребројавају или враћају као прочишћене грешке; изворне датотеке се никада не мењају.
