> **Извор истине:** `src/lib/obsidian/api.ts` (REST + клијент за синхронизацију),
> `src/lib/db/obsidian.ts` (чување токена / основног URL-а / WebDAV података),
> `src/lib/obsidianSync.ts` (WebDAV синхронизација трезора), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP алатке), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API-ји за подешавања). Регистрација алатки
> и повезивање опсега налазе се у `open-sse/mcp-server/server.ts`.

## Шта је ово

OmniRoute се повезује са **Obsidian** трезором као **извором контекста** — локалном Markdown
базом знања коју агенти читају и у коју уписују преко уграђеног MCP сервера.
Интеграција комуницира са додатком заједнице **Obsidian Local REST API** који се извршава у
десктоп апликацији, тако да агенти могу да претражују белешке, читају/пишу/мењају датотеке, излиставају трезор, раде
са дневним/недељним периодичним белешкама, управљају ознакама, покрећу Obsidian команде и (опционо)
координишу двосмерну синхронизацију трезора између десктопа и мобилног уређаја.

Клијент (`src/lib/obsidian/api.ts`) обавија Local REST API и пружа:

- **Поновне покушаје са одлагањем** за привремене `5xx` грешке, **временско ограничење од 30 секунди** преко `AbortController`.
- **Типизирану класификацију грешака** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Разумљив савет „није могуће приступити Obsidian-у“** који указује на честу грешку са портом
  (HTTP на `27123`, **не** MCP крајња тачка на `27124`) и Tailscale облик адресе.
- **Кодирање путања** релативних у односу на трезор, како би путање бележака са размацима/косим цртама биле безбедне.

## Подешавање

Не постоји **променљива окружења** за Obsidian токен или основни URL — оба се
чувају у SQLite табели `key_value` (именски простор `obsidian`) преко
`src/lib/db/obsidian.ts`. Токен је **шифрован при складиштењу** (AES-256-GCM, уз
резервну подршку за нешифровани текст ради уназадне компатибилности). Подесите га на картици **Извори контекста** на
контролној табли крајње тачке (`ObsidianSourceCard`) или преко REST API-ја за подешавања.

> [!IMPORTANT]
> Додатак **Obsidian Local REST API** мора бити инсталиран и покренут. Његов REST
> интерфејс ослушкује на **HTTP `127.0.0.1:27123`** (подразумевани основни URL). Порт `27124`
> је _засебна_ MCP/HTTPS крајња тачка и рута за подешавања га изричито одбија.
> Ако се повезујете са другог уређаја, користите `http://<tailscale-ip>:27123`.

### Конфигурациони кључеви (SQLite `key_value`, именски простор `obsidian`)

| Кључ              | Намена                                                        | Шифровано |
| ----------------- | ------------------------------------------------------------- | --------- |
| `api_key`         | Bearer токен за Local REST API                                | да        |
| `base_url`        | Основни REST URL (подразумевано `http://127.0.0.1:27123`)     | не        |
| `vault_path`      | Апсолутна путања до директоријума трезора (за синхронизацију) | не        |
| `webdav_username` | Генерисано WebDAV корисничко име (синхронизација трезора)     | не        |
| `webdav_password` | Генерисана WebDAV лозинка (синхронизација трезора)            | да        |
| `webdav_enabled`  | Да ли је WebDAV синхронизација трезора омогућена              | не        |

### Подешавање преко REST-а

```bash
# Сачувајте + потврдите Local REST API токен (POST га потврђује провером статуса)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Проверите статус везе (враћа connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Прекините везу (брише сачувани токен)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Све методе захтевају аутентификацију на контролној табли. `POST` одбија сваки URL на порту `27124`
и потврђује токен позивањем статусне крајње тачке Local REST API-ја пре чувања.

### WebDAV синхронизација трезора

`src/app/api/settings/obsidian/webdav/route.ts` управља опционом синхронизацијом
трезора заснованом на WebDAV-у (коју покреће `src/lib/obsidianSync.ts`). Њеним омогућавањем OmniRoute се усмерава на
локални директоријум трезора и генерише се насумични пар WebDAV корисничког имена и лозинке:

```bash
# Омогућите WebDAV синхронизацију за директоријум трезора (генерише корисничко име/лозинку)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Преузмите статус WebDAV синхронизације (акредитиви се враћају само док је омогућена)
curl http://localhost:20128/api/settings/obsidian/webdav

# Онемогућите WebDAV синхронизацију (брише акредитиве + управљану .stignore датотеку)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Извор контекста по API кључу (опционо)

Obsidian конфигурација може имати опсег **по API кључу** преко табеле `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Када MCP позив садржи идентификатор аутентификованог API
кључа, `getObsidianConfigForApiKey()` даје предност токену/основном URL-у/путањи трезора тог кључа
(`source: "api_key"`), а у супротном користи глобалну конфигурацију (`source: "global"`).

## MCP алати (22)

Дефинисани су у `open-sse/mcp-server/tools/obsidianTools.ts`. Токен/основни URL се одређују
за сваки позив (прво по API кључу, а затим глобално). Алати који приступају OmniRoute **серверу за синхронизацију**
(четири алата `obsidian_sync_*`) додатно захтевају токен за аутентификацију синхронизације конфигурисан
у OmniRoute подешавањима.

### Алати за читање (`read:obsidian`)

| Алат                         | Опис                                                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Проверава да ли је локални REST API доступан и аутентификован.                                                  |
| `obsidian_search_simple`     | Претрага целог текста садржаја бележака; враћа исечке са путањама датотека.                                     |
| `obsidian_search_structured` | Претрага помоћу JSON Logic израза (and/or/regex/path филтери).                                                  |
| `obsidian_read_note`         | Чита белешку по путањи релативној у односу на трезор; опционо одређено заглавље/блок/frontmatter.               |
| `obsidian_list_vault`        | Наводи датотеке и директоријуме у трезору (стабло ставки).                                                      |
| `obsidian_get_document_map`  | Преузима структуру заглавља белешке као мапу заглавља → бројеви редова.                                         |
| `obsidian_get_note_metadata` | Преузима frontmatter, ознаке, везе и број знакова/речи без целокупног садржаја.                                 |
| `obsidian_get_active_file`   | Преузима путању + садржај тренутно активне датотеке у Obsidian-у.                                               |
| `obsidian_get_periodic_note` | Преузима дневну/недељну/месечну периодичну белешку за датум (данашњи ако је изостављен).                        |
| `obsidian_get_tags`          | Наводи све ознаке у трезору са учесталошћу њиховог појављивања.                                                 |
| `obsidian_list_commands`     | Наводи доступне ID-ове Obsidian команди (користити са `obsidian_execute_command`).                              |
| `obsidian_sync_status`       | Статус OmniRoute сервера за синхронизацију: покренут, назив трезора, порт, време рада, последња синхронизација. |
| `obsidian_sync_conflicts`    | Наводи нерешене конфликте синхронизације (путања, путања конфликта, време откривања).                           |

### Алати за писање (`write:obsidian`)

| Алат                             | Опис                                                                                                            |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Креира или преписује белешку датим Markdown садржајем.                                                          |
| `obsidian_append_note`           | Додаје садржај у белешку; опционо у одређено заглавље/блок.                                                     |
| `obsidian_patch_note`            | Прецизно додаје после/пре или замењује садржај у заглављу, блоку или frontmatter пољу.                          |
| `obsidian_delete_note`           | Трајно брише белешку из трезора.                                                                                |
| `obsidian_move_note`             | Премешта или преименује белешку унутар трезора.                                                                 |
| `obsidian_execute_command`       | Извршава Obsidian команду према њеном ID-у команде.                                                             |
| `obsidian_open_file`             | Отвара датотеку у Obsidian-у (креира је ако не постоји).                                                        |
| `obsidian_sync_trigger`          | Покреће тренутну двосмерну синхронизацију трезора између десктоп и мобилног уређаја.                            |
| `obsidian_sync_resolve_conflict` | Решава конфликт синхронизације: задржава `local` (мобилна верзија), `remote` (десктоп верзија) или `keep-both`. |

> [!NOTE]
> Циљеви алата `obsidian_patch_note` прихватају `targetType` вредности `heading | block | frontmatter`
> и `operation` вредности `append | prepend | replace`, са опционим
> `createTargetIfMissing`. Четири алата `obsidian_sync_*` комуницирају са локалним сервером за синхронизацију
> (`http://127.0.0.1:27781` подразумевано) и захтевају токен за синхронизацију.

### Опсези

Алати за читање захтевају `read:obsidian`; алати за писање захтевају `write:obsidian`. Спровођење
је идентично као за Notion — њиме управља `withScopeEnforcement()` у
`open-sse/mcp-server/server.ts`, условљено са `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, при чему се
дозвољени опсези преузимају из `OMNIROUTE_MCP_SCOPES` или контекста опсега API кључа. Погледајте
[MCP-SERVER.md](./MCP-SERVER.md).

## Крајње тачке

| Метод    | Путања                          | Намена                                                        |
| -------- | ------------------------------- | ------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Враћа `{ connected, hasToken, baseUrl, vaultPath }`.          |
| `POST`   | `/api/settings/obsidian`        | Чува и проверава токен (одбија порт `27124`).                 |
| `DELETE` | `/api/settings/obsidian`        | Прекида везу (брише сачувани токен).                          |
| `GET`    | `/api/settings/obsidian/webdav` | Статус WebDAV синхронизације и акредитиви (док је омогућена). |
| `POST`   | `/api/settings/obsidian/webdav` | Омогућава WebDAV синхронизацију за директоријум трезора.      |
| `DELETE` | `/api/settings/obsidian/webdav` | Онемогућава WebDAV синхронизацију.                            |

> Ово су руте подешавања контролне табле. Самом трезору се приступа преко Obsidian
> Local REST API-ја (конфигурисаног `base_url`) и путем горенаведених MCP алата — не
> постоји јавна Obsidian прокси крајња тачка `/v1`.

## Случајеви употребе

- **Одговори засновани на трезору** — `obsidian_search_simple` / `obsidian_search_structured`,
  а затим `obsidian_read_note`, како би агент одговарао на основу ваших стварних белешки.
- **Писање белешки / вођење дневника** — `obsidian_write_note`, `obsidian_append_note` или
  прецизни `obsidian_patch_note` за уписивање излаза агента, сажетака или дневних белешки
  (`obsidian_get_periodic_note`) у трезор.
- **Навигација кроз трезор** — `obsidian_list_vault`, `obsidian_get_document_map` и
  `obsidian_get_tags` за истраживање структуре пре читања/писања.
- **Obsidian аутоматизација** — `obsidian_list_commands` + `obsidian_execute_command` за
  покретање додатака/команди преко агента; `obsidian_open_file` за приказ белешке у корисничком интерфејсу.
- **Мобилна синхронизација** — омогућите WebDAV синхронизацију, а затим користите `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  за координацију између десктоп и мобилног уређаја и решавање конфликата.
