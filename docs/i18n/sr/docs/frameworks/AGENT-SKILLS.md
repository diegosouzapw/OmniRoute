> **Извор истине:** `src/lib/agentSkills/` (каталог, генератор, парсери) + директоријум `skills/` (SKILL.md датотеке)
> **Последње ажурирање:** 2026-08-02 — v3.8.50

Agent Skills су структуриране SKILL.md датотеке које спољне агенте, MCP клијенте и A2A оркестраторе подучавају како да користе OmniRoute REST API и CLI. За разлику од [Omni Skills](./SKILLS.md) (које су дефиниције LLM алата извршаване унутар OmniRoute-а), Agent Skills представљају _каталог документације_ — статички markdown који се може директно проследити у контекст агента.

---

## Преглед

Каталог садржи **45 Agent Skills** (23 за REST API + 21 за CLI + 1 ток рада за конфигурацију). Свака вештина има:

- **Канонски ID** (`omni-auth`, `cli-serve` итд.)
- **SKILL.md** датотеку у `skills/{id}/SKILL.md` са YAML уводним метаподацима (`name`, `description`) + богатим markdown садржајем
- **REST крајње тачке** (API вештине) или **CLI поткоманде** (CLI вештине), изведене из OpenAPI спецификације и CLI регистра
- **GitHub raw URL** за преузимање уживо: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Архитектура

```
src/shared/constants/agentSkills.ts    — уређена листа од 45 ставки (назив/опис/категорија/област/икона)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() уписује SKILL.md у skills/{id}/
  openapiParser.ts                     — издваја REST крајње тачке из docs/openapi.yaml
  cliRegistryParser.ts                 — издваја CLI поткоманде из bin/cli-registry.ts
  schemas.ts                           — Zod шеме: AgentSkillSchema, SkillCoverageSchema итд.
  types.ts                             — TypeScript интерфејси: AgentSkill, SkillCoverage итд.

skills/{id}/SKILL.md                   — генерисане + ручно уређене markdown датотеке (укупно 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (захтева аутентификацију)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 MCP алата (листа, преузимање, покривеност)
src/lib/a2a/skills/listCapabilities.ts        — A2A вештина: list-capabilities
```

## Формат SKILL.md датотеке

```markdown
---
name: omni-providers
description: "Управљајте везама са добављачима: додајте, тестирајте, ротирајте и уклањајте акредитиве."
---

<!-- генерисано помоћу src/lib/agentSkills/generator.ts; ручне измене ће бити замењене -->

## Преглед

...

## Аутентификација

...

## Крајње тачке

...

<!-- skill:custom-start -->

## Прилагођени одељак (чува се приликом поновног генерисања)

...

<!-- skill:custom-end -->
```

Генератор приликом поновног генерисања чува садржај између `<!-- skill:custom-start -->` и `<!-- skill:custom-end -->`. Десет вештина има ручно уређене прилагођене блокове:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Откривање REST API-ја

| Крајња тачка                 | Метод | Опис                                                               | Ауторизација |
| :--------------------------- | :---- | :----------------------------------------------------------------- | :----------- |
| `/api/agent-skills`          | GET   | Приказ каталога (опционо `?category=api\|cli\|config&area=<area>`) | нема         |
| `/api/agent-skills/{id}`     | GET   | Преузимање метаподатака једне вештине                              | нема         |
| `/api/agent-skills/{id}/raw` | GET   | Преузимање SKILL.md као `text/markdown`                            | нема         |
| `/api/agent-skills/coverage` | GET   | Статистика покривености (колико SKILL.md датотека постоји)         | нема         |
| `/api/agent-skills/generate` | POST  | Покретање генератора (dryRun/prune/onlyIds)                        | управљачка   |

Пример — приказ свих API вештина:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Пример — преузимање једне SKILL.md датотеке:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Откривање MCP-а

Три MCP алатке су регистроване у оквиру опсега `read:catalog`:

| Алатка                            | Опис                                                        |
| :-------------------------------- | :---------------------------------------------------------- |
| `omniroute_agent_skills_list`     | Приказ вештина (опциони филтери `category` / `area`)        |
| `omniroute_agent_skills_get`      | Преузимање метаподатака + SKILL.md за једну вештину по `id` |
| `omniroute_agent_skills_coverage` | Статистика покривености (API/CLI доступно/укупно)           |

Погледајте [MCP-SERVER.md](./MCP-SERVER.md) за повезивање опсега и аутентификацију.

## Откривање A2A

A2A вештина `list-capabilities` враћа комплетан каталог од 45 вештина као артефакт у облику markdown табеле. Спољни оркестратори могу да је позову путем:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "Прикажи све могућности" }]
  }
}
```

Погледајте [A2A-SERVER.md](./A2A-SERVER.md) за детаље протокола.

## Како спољни агенти користе вештине

### 1. Откривање путем REST-а

```bash
# Преузмите цео каталог
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Преузмите SKILL.md за убризгавање контекста
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Откривање путем MCP-а

```typescript
// У Claude Desktop / Cursor MCP клијенту:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → низ објеката AgentSkill, сваки са rawUrl
```

### 3. Откривање путем A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table је markdown табела са свих 45 ID-јева вештина и колонама rawUrl
```

### 4. Директно преузимање необрађеног садржаја са GitHub-а (сервер није потребан)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Генератор

Генератор чита уређени каталог + OpenAPI спецификацију + CLI регистар и уписује `skills/{id}/SKILL.md` за сваку ставку:

```bash
# Преглед (пробно покретање, без уписивања)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Потпуно поновно генерисање
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Поновно генерисање одређених ID-јева
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Одговор генератора је `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
