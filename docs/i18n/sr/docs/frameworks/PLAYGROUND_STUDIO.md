## Преглед

Playground Studio претвара `/dashboard/playground` из једноставног уређивача заснованог на Monaco-у у
потпуно опремљено радно окружење за тестирање. Замењује застарели `page.tsx` омотачем `PlaygroundStudio`
који приказује четири картице и заједнички панел за конфигурацију.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Ћаскање] [⚖ Поређење] [{} API] [🔧 Израда] 142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {садржај активне картице}               │ ─ Конфигурација           │
│                                          │ Крајња тачка [chat ∨]     │
│                                          │ Модел        [gpt-5.4 ∨]  │
│                                          │ Систем       [поље текста]│
│                                          │ Температура  ▕▕▔▔ 0.7     │
│                                          │ Унапред подешено          │
│                                          │ [▾ учитај][сачувај]       │
│                                          │ [✨ Побољшај упит]         │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Картице

### Картица за ћаскање

Развија `ChatPlayground.tsx` у радно окружење за вишекружни стриминг:

- Потпуно приказивање Markdown-а путем `MarkdownMessage.tsx` (блокови кода, табеле, листе, везе).
- Системски упит преузет из заједничког панела за конфигурацију.
- Број токена/трошак по поруци (токени упита + токени одговора).
- Поновно генерисање последњег одговора.
- Шаље на `POST /v1/chat/completions` уз SSE стриминг.

### Картица за поређење

Кључна предност проксија: покретање једног упита паралелно на највише **4 модела**.

- Највише 4 колоне, од којих свака независно прима стрим са `/v1/chat/completions`.
- Дугме `+ Додај модел` (пречица Cmd+K) за додавање колона.
- `Покрени све ▶` истовремено покреће све стримове путем `Promise.all` и засебног `AbortController`-а за сваку колону.
- Глобално **Откажи све** прекида сваки активни стрим.
- `ProviderMetrics` по колони приказује TTFT, TPS, токене и процењени трошак у реалном времену.
- Метрике су означене као **„процена на страни клијента“** (D12) — мере се од првог SSE сегмента.

### Картица API-ја

Задржава 100% оригиналног Monaco уређивача за напредне кориснике (D14):

- 10 крајњих тачака: довршавања ћаскања, довршавања, угњежђивања, слике, звук, говор, транскрипције, модерације, поновно рангирање, претрага.
- Отпремање мултимодалних датотека.
- SSE стриминг са излазом у реалном времену.
- Обухваћено компонентом `ApiTab.tsx` (лењо учитавање, `ssr: false`).

### Картица за израду

Кориснички интерфејс за алате/позивање функција и структурирани излаз:

- `ToolsBuilder.tsx` — додавање/уређивање/уклањање `tools[]` са уређивачем JSON шеме за сваки алат.
  Валидира параметре путем `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — укључивање JSON режима и уређивач JSON шеме.
  Валидира одговор према шеми путем `StructuredOutputSchema` (Zod).
- Шаље захтев на `/v1/chat/completions` са `tools[]` и/или `response_format`.

## Панел за конфигурацију (заједнички)

`StudioConfigPane.tsx` — увек видљив, може се скупити.

| Поље             | Компонента            | Напомене                                                                |
| ---------------- | --------------------- | ----------------------------------------------------------------------- |
| Крајња тачка     | `<select>`            | 10 опција које одговарају типу `PlaygroundEndpoint`                     |
| Модел            | `<input>`             | слободан текст, нпр. `openai/gpt-4o`                                    |
| Системски упит   | `<textarea>`          | прослеђује се свим картицама                                            |
| Параметри        | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop  |
| Унапред подешено | `PresetPicker`        | учитавање/чување именованих снимака конфигурације (трајно у бази)       |
| Побољшај упит    | `ImprovePromptButton` | отвара модал упозорења о квоти, позива `/api/playground/improve-prompt` |

Стање је подигнуто у `PlaygroundStudio.tsx` и прослеђује се свим картицама. Пребацивање између картица
чува стање конфигурације.

## Горња трака

- Пребацивач картица (role="tablist").

## Модал за извоз кода

`ExportCodeModal.tsx` користи `codeExport.ts` за генерисање curl / Python / TypeScript исечака
из тренутног стања `PlaygroundState`. Место за API кључ увек је `$OMNIROUTE_API_KEY` (D11).

## Побољшавач упита

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Модал упозорава да ће „потрошити квоту“.
2. Након потврде, шаље `{ system, prompt, model, tone }` рути.
3. Рута интерно позива `/v1/chat/completions` са `promptImprover.META_SYSTEM_PROMPT`.
4. Враћа `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. Кориснички интерфејс ажурира системски упит у панелу за конфигурацију и кориснички упит на картици за ћаскање.

---

## Унапред подешене конфигурације

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Чувају се у SQLite табели `playground_presets` (миграција `084_playground_presets.sql`).
- Свака унапред подешена конфигурација чува: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: `GET` листа, `POST` креирање, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Метрике стримовања

`useStreamMetrics.ts` + `streamMetrics.ts` (чиста функција):

- `start()` — бележи време почетка захтева.
- `onFirstChunk()` — бележи TTFT.
- `onChunk(n)` — акумулира број токена довршавања.
- `finish(usage?)` — израчунава коначне метрике: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Цене из статичке табеле у `src/lib/playground/types.ts` (означене као „процењене“ — D13).

## Решавање проблема

| Симптом                                        | Узрок                                  | Решење                                                                                                     |
| ---------------------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Monaco уређивач се не приказује на API картици | SSR је учитао Monaco                   | Проверите да ли `ApiTab` користи `dynamic(..., { ssr: false })`                                            |
| Токови за поређење се покрећу секвенцијално    | Погрешна употреба `Promise.all`        | Сва покретања токова морају бити послата у једном позиву `Promise.all`                                     |
| Метрике приказују `null` за TTFT               | Обрађивач првог дела није повезан      | Проверите да ли се `useStreamMetrics.onFirstChunk()` позива у петљи SSE читача                             |
| Унапред подешена конфигурација се не чува      | Миграција базе података није покренута | Покрените `npm run db:migrate` или поново покрените сервер (миграција се аутоматски покреће при покретању) |
| Побољшавање упита враћа 502                    | Модел није подешен у конфигурацији     | Корисник мора да унесе назив модела у окну за конфигурацију пре побољшавања                                |
| Извезени кôд приказује `MISSING_API_KEY`       | Чувар места није уметнут               | `codeExport.ts` увек користи `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"`                                  |
