Узводни мрежни пролаз `agentrouter` примењује филтер садржаја заснован на кључним речима над
`messages[].content`. Филтер је делимично детерминистички (увек блокира
одређене фразе), а делимично вероватносан (осетљив је на нагле серије захтева — постаје
агресивнији након брзо узастопних захтева и опоравља се након периода мировања).

Када WAF блокира захтев, враћа:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Опсег филтера

WAF проверава само `messages[].content`. Он **не** проверава:

- `system` промпт
- Структуриране блокове садржаја (`tool_result`, `tool_use`, `thinking`, `image`)
- Поља `description` и `input_schema` алата
- Метаподатке захтева, заглавља или идентификатор модела

## Обрасци који се увек блокирају (без обзира на величину слова)

| Образац                           | Напомене                                              |
| --------------------------------- | ----------------------------------------------------- |
| Било која варијанта `Lorem ipsum` | Блокиран је целокупан латински lorem речник           |
| `language model` (самостално)     | „the language model“ и „large language model“ пролазе |
| `virtual assistant`               | „AI assistant“ пролази                                |
| `I'm here to help`                | И самостално „here to help“ такође се блокира         |
| `Claude, made by Anthropic`       | Само цела фраза                                       |

## Обрасци који се скоро увек блокирају

| Образац                                                   | Напомене                                            |
| --------------------------------------------------------- | --------------------------------------------------- |
| `placeholder`                                             | Када стоји самостално (не као назив параметра итд.) |
| `dummy data`                                              | Честа почетна фраза за тестне податке               |
| `foo bar baz`                                             | Канонска фраза за заменски текст                    |
| Поновљени кратки токени (`AAA BBB CCC`, `test test test`) | Детектор за претрпавање кључним речима              |

## Понашање под оптерећењем

Након приближно 5 брзо узастопних захтева у кратком временском периоду, WAF почиње да блокира садржај
који би иначе прошао. Ограничење се ублажава након приближно 5–10 секунди
неактивности. То је исти ограничавач учесталости везан за IP адресу и кључ који изазива
повремене грешке `400 content-blocked` када Claude Code или Codex CLI
упути више позива за употребу алата / слање порука у кратком временском периоду.

## Ублажавања која су већ примењена у OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — заштита од наглих серија захтева која намеће
   минимални размак од 500 ms између одлазних захтева ка било којем `agentrouter:*`
   URL-у. Размак је далеко испод прага људске перцепције кашњења и спречава
   активирање WAF-а при нормалном саобраћају.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — када узводни сервис врати
   `400 content-blocked`, извршилац поново покушава исти URL уз
   експоненцијално одлагање (1.5 s, 3.0 s, највише 2 покушаја). Након одлагања
   WAF обично ублажи ограничење и поновљени покушај успе.

3. **`tests/unit/compression/harness.test.ts`** — тестни податак
   `longInput` промењен је из `"lorem ipsum dolor sit amet ".repeat(40)`
   у `"example content for testing purposes ".repeat(40)` како садржај датотеке,
   када Claude Code прочита ову датотеку помоћу алата `Read`,
   не би био прослеђен назад кроз блок `tool_result` и активирао WAF.

## Смернице за промптове и излаз алата

Ако Claude Code или Codex CLI сесија више пута наиђе на
`400 content-blocked`, проверите најновију корисничку поруку и најновији
резултат алата да бисте пронашли неки од наведених образаца, па га преформулишите. Уобичајена
заобилазна решења:

- Замените `Lorem ipsum …` са `example text …` или стварним садржајем
  који тест или тестни податак треба да представља.
- Замените `placeholder` (када стоји самостално) са `example value`,
  `sample value` или стварном вредношћу.
- Замените `language model` са `large language model` или `the model`.
- Замените `dummy data` са `sample data` или реалистичним почетним вредностима.
- Замените `I'm here to help` / `here to help` конкретнијим
  уводом (нпр. „I'll review the file you mentioned“).

## Пријављивање лажно позитивних резултата узводном сервису

Тренутни филтер је претерано агресиван — блокира „Lorem ipsum“ у
блоковима `tool_result`, иако оператер очигледно није намеравао да
убризга промпт. Оператери који желе да се ово исправи на извору треба да
контактирају `agentrouter.org` и пријаве лажно позитивне резултате. Горња листа блокираних образаца
представља емпиријски резултат испитивања узводног сервиса на дан 2026-08-03.
