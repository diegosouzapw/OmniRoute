Caveman компресија може да учита пакете правила специфичне за језик поред уграђених правила за енглески.
Ово одржава стабилност основног механизма, док омогућава да се пакети за португалски, шпански, немачки, француски, италијански, јапански и
будуће језике развијају независно.

## Локација

Језички пакети се налазе у:

```txt
open-sse/services/compression/rules/<language>/
```

Пакети који се тренутно испоручују (проверено у односу на садржај директоријума `rules/`):

| Језик                | Директоријум   | Присутне категорије правила                         |
| -------------------- | -------------- | --------------------------------------------------- |
| Енглески             | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Шпански              | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Португалски (Бразил) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Индонежански         | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Италијански          | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Немачки              | `rules/de/`    | `context`, `filler`, `structural`                   |
| Француски            | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Јапански             | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Напомена о усклађености:** Пакети `en`, `es`, `pt-BR`, `id` и `it` имају свих 5 категорија; `de`, `fr` и `ja` се испоручују са 3 категорије. За недостајуће категорије `dedup` и `ultra` неприметно се користе уграђена правила за енглески. Доприноси за додавање датотека `dedup.json` и `ultra.json` мањим пакетима су добродошли.
>
> Пакет `pt-BR` је заснован на систему **[Troglodita](https://github.com/leninejunior/troglodita)** аутора Lenine Júnior — систему компресије осмишљеном од почетка за граматику бразилског португалског (смањење плеоназама, уклањање сувишних речи у PT-BR, техничке скраћенице за бразилску програмерску заједницу).
>
> Канонска листа категорија и шема за сваку категорију налазе се у [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema нацрт 2020-12).

## Откривање језика

`languageDetector.ts` користи једноставне хеуристике да би закључио језик на основу текста упита. Подразумевани језик подешен у конфигурацији се и даље поштује, а откривање се може онемогућити путем конфигурације када је потребна прецизна контрола.

Резултат откривања користи се искључиво за избор пакета правила. Он не мења усмеравање ка добављачима, избор локализације нити језик корисничког интерфејса.

## Структура конфигурације

Подешавања компресије могу да садрже:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` контролише подразумеване вредности контролне табле и прегледа. `cavemanConfig` је конфигурација механизма током извршавања
која се користи када Caveman компримује текст поруке.

## Додавање језичког пакета

1. Направите `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Користите формат Caveman правила из `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Нека замене буду конзервативне и избегавајте мењање кода, идентификатора, URL-ова или JSON-а.
4. Додајте или ажурирајте тестове за избор језика и понашање замена.
5. Омогућите нове ознаке контролне табле/i18n ако се језик појављује у селекторима корисничког интерфејса.

## API

Доступни пакети могу да се упитају помоћу:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Крајња тачка за преглед прихвата измене језичке конфигурације:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Свих 6 језичких пакета добило је клаузулу `SHARED_BOUNDARIES` у верзији v3.8.0, која се примењује при сваком
нивоу интензитета Caveman-а (LITE, FULL, ULTRA). Она налаже механизму да дословно сачува ове обрасце,
без обзира на уклањање околног сувишног садржаја:

| Тип обрасца                             | Пример                                 |
| --------------------------------------- | -------------------------------------- |
| Ограђени блокови кода                   | ` ```python\n...\n``` `                |
| Уметнути код                            | `` `my_var` ``                         |
| URL-ови                                 | `https://example.com/path`             |
| Путање датотека (апсолутне + релативне) | `/etc/hosts`, `./src/index.ts`         |
| Заглавља грешака                        | `Error:`, `TypeError:`, `SyntaxError:` |
| Редови стека позива                     | `  at functionName (file.ts:12:3)`     |

Ови обрасци се попуњавају у `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (раније `[]`). Ова
константа се налази у `open-sse/services/compression/types.ts`.

### Зашто је ово важно

Без SHARED_BOUNDARIES, агресивни Caveman режими могли би да уклоне садржај који изгледа као понављајућа
проза, али је заправо исечак кода, путања датотеке или стек грешке. SHARED_BOUNDARIES служи као
заштитна мрежа независна од језика, која се примењује пре правила за уклањање сувишног садржаја.

### Прилагођавање preservePatterns

Додатни обрасци могу да се додају током извршавања путем подешавања компресије:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Прилагођени обрасци проширују (не замењују) 6 подразумеваних образаца.

## Напомене о раду

- Уграђена правила за енглески остају резервна опција када језички пакет недостаје.
- Неважећи уграђени JSON пакети не пролазе валидацију, тако да се квалитет ресурса издања не нарушава неприметно.
- Пакети правила садрже само податке и не треба да увозе код нити да извршавају произвољну логику.
- Слој аналитике компресије бележи изабрани режим и механизам, а не цео текст упита.
