## Укратко — колико бесплатног закључивања OmniRoute заправо обједињује?

| Метрика                                           | Токени / месец               | Значење                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Документована периодична квота (стална)**       | **~1.62B**                   | **Скупови** бесплатних нивоа (каталог по моделу), при чему се сваки дељени скуп рачуна **једном**. Актуелни извор који користе `/api/free-tier/summary` и страница „Буџет бесплатног нивоа“ на контролној табли. **Користите овај број.**                                                                                                               |
| **+ први месец са кредитима за регистрацију**     | **~2.22B**                   | Стална квота + једнократни кредити за регистрацију (Z.AI 20M, DeepSeek 5M, …), дедуплицирани по налогу. **Само први месец** — не обнављају се.                                                                                                                                                                                                          |
| **+ трајно бесплатно, без објављеног ограничења** | _није могуће квантификовати_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — стваран периодични приступ, ограничен брзином/конкурентношћу, **без ограничења броја токена које би се могло урачунати**. Наведени су, али се никада не сабирају (рачунање као `RPM×24/7` представља надувавање које одбацујемо). |
| **+ повећање откључано депозитом**                | **+~24M**                    | Једнократна допуна OpenRouter налога од **$10** повећава његов бесплатни скуп са 50 → 1000 захтева дневно. Приказује се засебно како никада не би надувавала сталну вредност.                                                                                                                                                                           |
| **+ иза регионалне провере идентитета**           | **+~6M**                     | `modelscope` (повезивање са Alibaba Cloud налогом + верификација стварног имена у континенталној Кини). Стварна периодична квота, изложена као `gatedRecurringTokens` / `gatedProviders` и на контролној табли. Никада се не сабира са истакнутом вредношћу: +~6M иза регионалне провере идентитета.                                                    |
| Теоријски максимум (сва ограничења брзине, 24/7)  | ~10B                         | Збир свих ограничења брзине добављача, екстраполиран на непрекидно коришћење. **Није гаранција** — немојте ово истицати као главну вредност.                                                                                                                                                                                                            |

**Искрен главни податак:** _OmniRoute обједињује **~1.62B документованих бесплатних токена месечно** (до ~2.22B током првог месеца са кредитима за регистрацију) у оквиру 35 скупова бесплатних нивоа — уз дугачак низ трајно бесплатних добављача без ограничења — а RTK + Caveman компресија (уштеда токена од 15–95%) додатно проширује ту количину._

> **Зашто је овај број пао са претходних ~1.94B.** Освежавање од 2026-06-17 представља исправку ради тачности, а не губитак: `gemini` сада уклања дупликате на нивоу скупа (претходно је број био увећан јер је свака Flash варијанта рачуната засебно, 462M → 60M), `cloudflare-ai` је исправљен на стварних 10k Neurons дневно (122M → 30M), `doubao` је прекласификован као једнократни кредит при регистрацији (не обнавља се), а угашени нивои су уклоњени (`chutes`/`phind`/`kluster` су обустављени). То је делимично надокнађено са `llm7` (исправних 5M дневно → 150M) и новим бесплатним добављачима (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Додатно исправљено на ~1.37B у v3.8.42:** `longcat` је, након завршетка бесплатног пробног периода, прекласификован са понављајућег додатка од 150M месечно на једнократни кредит од 10M при регистрацији. Исто правило тачности — ниједан добављач није грешком изостављен.
>
> **Ажурирано 2026-08-26 након повлачења Felo Web-а:** Felo Web је изостављен док његово порекло/лиценцирање изведено из GPL-а остаје НА ЧЕКАЊУ; извор је у том тренутку пријављивао 38 кључева скупова. Број скупова се ажурира уживо и контролише кроз CI (`check:docs-counts` обара верзију ако горенаведени бројеви одступе од `computeFreeModelTotals()`).
>
> **Поново проверено 2026-09-02 према сопственим страницама добављача** (извори: коментари `// evidence:` поред сваке поново проверене ставке у `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` више не објављују број токена (Google је уклонио бесплатну табелу по моделу 2025-12-23; Ollama Free план нуди „почетне кредите за коришћење“) и сада су наведени као **без ограничења**, без укључивања у збир (−80M); `groq` има пет ограничења од 200K TPD **по моделу** (по 6M, +15M), уз уклањање три повучена ID-а; `nara` има један заједнички лимит од 7M дневно (+60M, 210M). `mistral`-ових 1B видљиво је само у конзоли налога — погледајте _Класе доказа_ у одељку Методологија.
>
> **Исправљено 2026-09-03 (#11773):** `cerebras` је прекласификован са понављајућег додатка од 30M месечно (стара пробна понуда без картице од 1M токена дневно) на једнократни кредит од $5 при регистрацији, који захтева начин плаћања. Исто правило тачности као за LongCat.
>
> **Уз xKiro (2026-09-03):** нови скуп `xkiro-free` (150M месечно) додаје 35. кључ понављајућег скупа. Felo Web остаје изостављен док његово порекло/лиценцирање изведено из GPL-а остаје НА ЧЕКАЊУ. Извор сада пријављује **35 кључева понављајућих скупова** и **~1.62B стабилно** — број који се ажурира уживо и контролише кроз CI (`check:docs-counts` обара верзију ако овај број одступи од `computeFreeModelTotals()`).

Највећи **документовани** доприноси: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (пет ограничења по моделу), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` је изостављен — његов LongCat-2.0 додатак од 10M представља једнократни кредит при регистрацији условљен KYC провером, а не понављајући месечни буџет.)

> ⚠️ Теоријски максимум (~10B) увећан је због добављача ограничених само брзином, **без објављеног ограничења токена** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), чије би вредности биле `RPM/TPM × 24/7 × 30d` — теоријски максимум који ниједан појединачни налог не може да одржи. Они су **изостављени** из одбрањивог броја (уместо тога су приказани у реду „трајно бесплатно, без ограничења“). То је исто увећавање због којег су тврдње конкурената о више милијарди непоуздане.

## Освежено 2026-06-17 — шта се променило од 2026-06-05

Преглед веб-извора који је спровело 50 агената (званична документација + вести из последњих 7 дана, уз критичку проверу) освежио је цео каталог. Најважније промене:

- **Уклоњено / нема бесплатног нивоа (2026):** `chutes` (бесплатни ниво укинут 2026-03), `phind` (компанија угашена 2026-01), `kluster` (угашен 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (бесплатан приступ за MiMo укинут 2026-05-24, промоција за Nemotron завршена 2026-06 — поново проверено 2026-06-18), `aimlapi` (бесплатни ниво паузиран — поново проверено 2026-06-18), `yi` (Yi-Light повучен, плаћање по потрошњи — поново проверено 2026-06-18), `featherless-ai` (тренутно нема бесплатног нивоа), `chipotle` (Chipotle-ов „Pepper AI“ — Amelia виџет за ћаскање на `amelia.chipotle.com`, добијен обрнутим инжењерингом и са којим је добављач комуницирао, сада враћа 404 на свакој путањи, укључујући корену; позадински систем је повучен из употребе/премештен, потврђено 2026-09-15 — потпуно уклоњен из каталога, #13131/#4037). `iflytek` / `sparkdesk` остају наведени, али уз напомену о опрезу у вези са условима коришћења (Spark Lite је бесплатан; услови коришћења ограничавају употребу проксија/релеја).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` угашени су 2026-06-01, а `2.5 Pro` је уклоњен из бесплатног нивоа (2026-04); бесплатни ниво сада обухвата **само породицу Flash** (2.5/3/3.1/3.5 Flash + Gemma). Каталог сада **обједињује** породицу Flash (раније је број био надуван засебним рачунањем сваке варијанте: 462M → 60M).
- **Исправљене вредности:** `cloudflare-ai` 122M → **30M** (стварних 10k неурона дневно), `doubao` је прекласификован као једнократни кредит при регистрацији (не обнавља се), `llm7` 4M → **150M** (документованих 5M токена дневно), укинуте су „-Free“ приступне тачке добављача `together` → уклоњен је и кредит од $25 при регистрацији (захтева куповину од најмање $5, нема бесплатног пробног периода), период Preview за `longcat` је завршен, а модели Flash су повучени → остаје само **LongCat-2.0**, прекласификован као једнократни кредит од **10M** токена при регистрацији (условљен KYC провером, не обнавља се).
- **Откривени нови бесплатни добављачи:** ⭐ **Kilo Code** (`kilo-gateway` — ротирајући скуп „Auto Free“: породица NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 ротирајућих бесплатних модела за програмирање), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash трајно бесплатни + бонус од 20M при регистрацији) и `arcee-ai` Trinity Large Preview.
- **Нови транспарентни нивои** (погледајте Методологију): категорија _трајно бесплатно, али без горње границе_ (стварни приступ који се обнавља, без ограничења броја токена које би се могло урачунати) и _увећање које се откључава депозитом_ (OpenRouter $10 → +24M месечно), оба приказана **засебно** како никада не би увећавала истакнути збир.

> Детаљна табела по добављачима у наставку представља **снимак стања од 2026-06-05**; горенаведене измене имају предност над њом. Актуелни, канонски извор је каталог по моделима `open-sse/config/freeModelCatalog.ts`.

## Два режима — рачунање наспрам одлучивања

OmniRoute одговара на питање „да ли је бесплатно?“ путем два режима који намерно користе
различите изворе:

| Режим                      | Извор истине                                                                                                                                                       | Места приказа                                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Рачунање / приказивање** | Разрешени каталог — испоручена основа преклопљена Radar фидом (`getRadarCatalog`)                                                                                  | Укупне вредности бесплатног нивоа, картица буџета, контролне табле                                                                 |
| **Одлучивање**             | Само испоручени каталог (`FREE_MODEL_BUDGETS` у `open-sse/config/freeModelCatalog.data.ts`) уз локалне хеуристике (суфикс `:free`, нулта цена, `grantsFreeAccess`) | Сваки корисник датотеке `src/shared/utils/freeModels.ts`: увоз модела, `auto/*` рутирање, `GET /v1/models` и прегледи у прегледачу |

Рачунање може да се побољша кад год је фид доступан. Одлучивање остаје засновано на
артефакту издања, па је одговор идентичан у прегледачу и на серверу,
поновљив ван мреже и може се тестирати без базе података. Ако би се прегледу у прегледачу
дозволило да чита један извор, док увоз на серверу чита други, добио би се
преглед који није у складу са оним што се дешава након клика — ова подела се задржава
намерно.

## Методологија и напомене

- Бројеви су **процене горње границе** засноване на документованим ограничењима бесплатног нивоа сваког добављача на дан **2026-06-17**, прикупљене веб-истраживањем. Бесплатни нивои се непрестано мењају — поново их проверите пре него што се ослоните на неки податак.
- **Шта нека ставка заправо потврђује.** Ниједна ставка нема оцену поузданости по реду, нити је API пружа — сваки горенаведени број сматрајте проценом истог, ненаведеног квалитета. Две чињенице се разликују зато што су ручно проверене, а не изведене: 44 ставке имају независно документовано строго ограничење (од тога су 39 редови за xKiro, који сви деле једно дневно ограничење), а 13 ставки има објављене информације о коришћењу упита за обуку. `hardStopGuaranteed` се поставља само када услови самог добављача наводе да прекорачење бесплатног ограничења доводи до одбијања захтева уместо до прећутног почетка наплате, при чему се извор налази у коментару поред ставке; вредност се никада подразумевано не поставља на `true`, а ставка коју нико није проверио остаје неподешена. Стога одсуство ознаке строгог ограничења значи „није утврђено“, а не „познато је да ће вам бити наплаћено“. **STRICT режим** (опциона заштита рутирања `freeAccessPolicy=strict`) верује само ставкама које имају ту ознаку; сваки други бесплатни ниво искључује се као `no-hard-stop` (погледајте `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Када заштита филтрира скуп, дневник видљив оператеру приказује и број искључених ставки и удео ставки са разлогом `no-hard-stop`.
- `estMonthlyFreeTokens` = само токени који се обнављају месечно. **Једнократни кредити при регистрацији не обнављају се** и рачунају се као 0. Укинути нивои се такође рачунају као 0.
- Дневно ограничење токена → `monthly = daily × 30`. Ако је документован само RPD → `RPD × ~800 излазних токена × 30`. Ако постоје само RPM/TPM (без дневног ограничења) → **без ограничења** (погледајте испод).
- **Трајно бесплатно, али без објављеног ограничења токена** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): ово су стварни, периодично обновљиви бесплатни приступи, ограничени брзином/истовременошћу. Класификујемо их као `recurring-uncapped` и **никада их не сабирамо** — множење `RPM × 24/7 × 30d` произвело би нереалну горњу границу (такво надувавање одбацујемо). Наведени су како бисте знали да постоје.
- **Повећање откључано уплатом:** мала једнократна допуна која трајно повећава бесплатну квоту (OpenRouter: $10 → 1000 захтева/дан ≈ +24M/месечно). Приказује се као засебан податак и не укључује се у главну вредност стално доступне квоте.
- **Квоте условљене испуњавањем критеријума** (`eligibilityGate: "regional-identity"`): стварна периодично обновљива квота која постаје доступна тек након провере идентитета везане за одређени регион (данас је то провера стварног имена у континенталној Кини). Рачуна се по истом правилу уклањања дупликата из скупа у засебну вредност (`gatedRecurringTokens`) и никада се не укључује у главну вредност стално доступне квоте. Режим (`freeType`) остаје непромењен, па се ни рутирање не мења.
- **Класе доказа.** Правило гласи: број у каталогу наводи свој извор у коментару `// evidence:` поред ставке — `public-page` (страница добављача коју свако може да прочита), `api-public` (неаутентификована крајња тачка добављача, нпр. NaraRouter-ова јавна крајња тачка за планове на router.bynara.id) или `console-verified <date> por <who>` (податак је видљив само у конзоли налога; коментар бележи ко га је видео и када, као и јавну страницу која наводи да ограничење постоји). Тренутно стање: пет блокова који су поново проверени 2026-09-02 имају такав коментар (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); ставке које претходе поновној провери од 2026-09-02 наслеђују раније истраживање док не буду измењене; сваки **нови или промењени** број без коментара о доказу представља грешку. Данас је само `mistral` верификован преко конзоле.

## Зашто је наш број мањи него код других агрегатора

Већина вредности за „бесплатне токене месечно“ у овој области представља збир ознака по моделу. Наша вредност то намерно није:

- **Сваки заједнички пул рачуна се једном.** Бесплатни план компаније Mistral представља једно ограничење од 1B месечно по организацији; навођење тог ограничења уз пет модела не чини га ограничењем од 5B. Када би се сабирало по моделу, наш сопствени каталог показивао би **~7.4B** (поново израчунато 2026-09-03; ова вредност није контролисана путем CI-ја — поново је измерите кад год се каталог промени) — у наслову стоји **~1.47B** јер је то оно што један налог код сваког добављача заиста може да потроши.
- **Дневна ограничења се претварају, а стопе не.** Документовано ограничење токена по дану постаје `× 30`; документовано ограничење захтева по дану постаје `RPD × ~800 токена × 30`; добављач који објављује само број захтева у минуту **нема** месечну вредност и наведен је као _без ограничења_, те се никада не сабира. Множење ограничења стопе коришћењем 24/7 представља надувавање вредности које одбијамо да радимо.
- **Квоте условљене регионалном провером идентитета приказане су засебно** (`+~6M након регионалне провере идентитета`), јер већина читалаца не може да их користи.
- **Кредити при регистрацији важе само током првог месеца** и приказују се као друга вредност, без укључивања у сталну вредност.
- **Вредност се проверава путем CI-ја.** `npm run check:docs-counts` поново израчунава укупне вредности из каталога и обара процес изградње када ова датотека, README или картица буџета одступају од њих.

## Табела напомена о условима коришћења

> **Ознака услова коришћења је саветодавна, а не препрека за усмеравање.** Добављачи означени са `tos` и даље су подразумевано укључени у усмеравање и комбиновање/резервне опције; ознака се приказује само на `/dashboard/free-tiers` и `/api/free-tier/summary`. Параметар упита `excludeTosAvoid` утиче само на приказ сажетка, а не на глобално усмеравање. Оцена се налази у `open-sse/config/freeTierCatalog.ts` (информативна је и механизми за усмеравање је не читају).

> Кратак преглед услова сваког добављача за лични прокси са сопственим хостингом и једним корисником. `caution` = одредба о личној употреби или проксију коју вреди проверити; `ambiguous` = нејасно; `ok` = изричито дозвољено. Информативно, није правни савет — ви одлучујете.

## Речник

| Термин                  | Значење                                                                       |
| ----------------------- | ----------------------------------------------------------------------------- |
| **RPM / RPD / RPH**     | Захтеви по минуту / дану / сату                                               |
| **TPM / TPD**           | Токени по минуту / дану                                                       |
| **Документована квота** | Добављач објављује изричито дневно/месечно ограничење токена (одбрањив буџет) |
| **Теоријски максимум**  | `ограничење брзине × 24/7 × 30 дана` — максимум, а не додељени буџет          |
| **Неурон**              | Cloudflare-ова рачунарска јединица (~1 излазни токен)                         |
