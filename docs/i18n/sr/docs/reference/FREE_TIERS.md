## Укратко — колико бесплатне инференције OmniRoute заправо обједињује?

| Метрика                                           | Токени / месец               | Значење                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Документована периодична квота (стална)**       | **~1.62B**                   | Бесплатни **скупови** (каталог по моделу), при чему се сваки дељени скуп рачуна **једном**. Активни извор који користе `/api/free-tier/summary` и страница Free-Tier Budget на контролној табли. **Користите овај број.**                                                                                                                      |
| **+ први месец са кредитима за регистрацију**     | **~2.22B**                   | Стална квота + једнократни кредити за регистрацију (Z.AI 20M, DeepSeek 5M, …), без дупликата по налогу. **Само први месец** — не обнавља се.                                                                                                                                                                                                   |
| **+ трајно бесплатно, без објављеног ограничења** | _није могуће квантификовати_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — стварни периодични приступ, ограничен брзином/истовременошћу, **без ограничења токена које би се могло рачунати**. Наводе се, али се никада не сабирају (рачунање као `RPM×24/7` представља надувавање које одбацујемо). |
| **+ повећање откључано депозитом**                | **+~24M**                    | Једнократна OpenRouter допуна од **$10** повећава његов бесплатни скуп са 50 → 1000 захтева/дан. Приказује се засебно како никада не би надувала стални број.                                                                                                                                                                                  |
| **+ иза регионалне провере идентитета**           | **+~6M**                     | `modelscope` (повезивање са Alibaba Cloud-ом + верификација правог имена у континенталној Кини). Стварна периодична квота, изложена као `gatedRecurringTokens` / `gatedProviders` и приказана на контролној табли. Никада се не сабира у главни број: +~6M иза регионалне верификације идентитета.                                             |
| Теоријски максимум (сва ограничења брзине, 24/7)  | ~10B                         | Збир свих ограничења брзине добављача, екстраполиран на непрекидно коришћење. **Није гаранција** — немојте ово истицати у наслову.                                                                                                                                                                                                             |

**Искрен наслов:** _OmniRoute обједињује **~1.62B документованих бесплатних токена месечно** (до ~2.22B током првог месеца са кредитима за регистрацију) у оквиру 35 бесплатних скупова — уз дугачак низ трајно бесплатних добављача без ограничења — а RTK + Caveman компресија (уштеда од 15–95% токена) то додатно продужава._

> **Зашто је овај број смањен са претходних ~1.94B.** Освежавање од 2026-06-17 представља исправку ради тачности, а не губитак: `gemini` сада уклања дупликате на нивоу скупа (раније је број био надуван јер се свака Flash варијанта рачунала засебно, 462M → 60M), `cloudflare-ai` је исправљен на стварних 10k Neurons/дан (122M → 30M), `doubao` је прекласификован као једнократни кредит за регистрацију (а не периодични), а угашени нивои су уклоњени (`chutes`/`phind`/`kluster` су укинути). То је делимично надокнађено преко `llm7` (исправних 5M/дан → 150M) и нових бесплатних добављача (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Додатно исправљено на ~1.37B у v3.8.42:** `longcat` је прекласификован са периодичне квоте од 150M/месечно на једнократни кредит за регистрацију од 10M након завршетка бесплатног пробног периода. Исто правило тачности — ниједан добављач није грешком изостављен.
>
> **Ажурирано 2026-08-26 након повлачења Felo Web-а:** Felo Web је изостављен док његово порекло/лиценцирање изведено из GPL-а остаје на ЧЕКАЊУ; извор је у том тренутку пријављивао 38 кључева скупова. Број скупова је актуелан и проверава га CI (`check:docs-counts` обара изградњу ако горенаведени бројеви одступају од `computeFreeModelTotals()`).
>
> **Поново проверено 2026-09-02 према сопственим страницама добављача** (извори: коментари `// evidence:` поред сваке поново проверене ставке у `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` више не објављују број токена (Google је уклонио бесплатну табелу по моделу 2025-12-23; Ollama Free план нуди „почетне кредите за коришћење“) и сада су наведени као **неограничени**, без сабирања (−80M); `groq` има пет ограничења од 200K TPD **по моделу** (по 6M, +15M), док су три повучена ID-а изостављена; `nara` има један скуп од 7M/дан (+60M, 210M). Квота од 1B за `mistral` видљива је само у конзоли налога — погледајте _Класе доказа_ у одељку Методологија.
>
> **Исправљено 2026-09-03 (#11773):** `cerebras` је прекласификован са периодичне квоте од 30M/месечно (стари пробни период без картице од 1M токена/дан) на једнократни кредит за регистрацију од $5 који захтева начин плаћања. Исто правило тачности као за LongCat.
>
> **Плус xKiro (2026-09-03):** нови скуп `xkiro-free` (150M/месечно) додаје 35. кључ периодичног скупа. Felo Web остаје изостављен док његово порекло/лиценцирање изведено из GPL-а остаје на ЧЕКАЊУ. Извор сада пријављује **35 кључева периодичних скупова** и **~1.62B сталне квоте** — актуелан број који проверава CI (`check:docs-counts` обара изградњу ако овај број одступа од `computeFreeModelTotals()`).

Највећи **документовани** доприноси: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (пет ограничења по моделу), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` је изостављен — његова квота од 10M за LongCat-2.0 представља једнократни кредит за регистрацију условљен KYC провером, а не периодични месечни буџет.)

> ⚠️ Теоријски максимум (~10B) увећан је због провајдера који имају само ограничење брзине, али **немају објављено ограничење броја токена** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), чије би вредности биле `RPM/TPM × 24/7 × 30d` — теоријски максимум који ниједан појединачни налог не може трајно да одржава. Они су **изузети** из одбрањиве процене (уместо тога су приказани у реду „трајно бесплатно, без ограничења“). То је исто увећавање због којег су тврдње конкурената о више милијарди непоуздане.

## Освежење од 2026-06-17 — шта се променило од 2026-06-05

Истраживање веба које је спровело 50 агената (званична документација + вести из последњих 7 дана, уз независну проверу спорних тврдњи) освежило је цео каталог. Најважније измене:

- **Уклоњено / нема бесплатног нивоа (2026):** `chutes` (бесплатни ниво укинут 2026-03), `phind` (компанија угашена 2026-01), `kluster` (повучен 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (укинут бесплатан приступ моделу MiMo 2026-05-24, промоција за Nemotron завршена 2026-06 — поново проверено 2026-06-18), `aimlapi` (бесплатни ниво паузиран — поново проверено 2026-06-18), `yi` (Yi-Light повучен, плаћање према потрошњи — поново проверено 2026-06-18), `featherless-ai` (тренутно нема бесплатни ниво), `chipotle` (Chipotle-ов „Pepper AI“ — Amelia виџет за ћаскање добијен обрнутим инжењерингом, на адреси `amelia.chipotle.com`, са којим је провајдер комуницирао, сада враћа 404 на свакој путањи, укључујући корену; позадински систем је искључен/премештен, потврђено 2026-09-15 — у потпуности уклоњено из каталога, #13131/#4037). `iflytek` / `sparkdesk` остају наведени, али уз напомену о опрезу у вези са условима коришћења (Spark Lite је бесплатан; услови коришћења ограничавају употребу проксија/релеја).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` угашени су 2026-06-01, а `2.5 Pro` је уклоњен са бесплатног нивоа (2026-04); бесплатни ниво сада обухвата **само породицу Flash** (2.5/3/3.1/3.5 Flash + Gemma). Каталог сада **обједињује** породицу Flash (раније је број био преувеличан јер се свака варијанта рачунала засебно: 462M → 60M).
- **Исправљене бројке:** `cloudflare-ai` 122M → **30M** (стварних 10k неурона дневно), `doubao` је рекласификован као једнократни кредит при регистрацији (не обнавља се), `llm7` 4M → **150M** (документованих 5M токена дневно), `together` крајње тачке „-Free“ су укинуте → уклоњен је и кредит од $25 при регистрацији (захтева се минимална куповина од $5, нема бесплатног пробног периода), `longcat` Preview је завршен + Flash модели су повучени → само **LongCat-2.0**, рекласификован као једнократни кредит од **10M** токена при регистрацији (условљен KYC провером, не обнавља се).
- **Откривени нови бесплатни провајдери:** ⭐ **Kilo Code** (`kilo-gateway` — ротирајући скуп „Auto Free“: породица NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 ротирајућих бесплатних модела за програмирање), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash трајно бесплатни + бонус од 20M при регистрацији) и `arcee-ai` Trinity Large Preview.
- **Нови транспарентни нивои** (погледајте Методологију): категорија _трајно бесплатно, али без ограничења_ (стварни приступ који се обнавља, без ограничења броја токена које би се могло рачунати) и _повећање лимита откључано депозитом_ (OpenRouter $10 → +24M месечно), оба приказана **засебно** како никада не би увећавала главну бројку.

> Детаљна табела по провајдерима у наставку представља **снимак стања од 2026-06-05**; горенаведене измене имају предност над њим. Актуелни, меродавни извор је каталог по моделима `open-sse/config/freeModelCatalog.ts`.

## Два режима — рачунање наспрам одлучивања

OmniRoute одговара на питање „да ли је бесплатно?“ кроз два режима који намерно читају
различите изворе:

| Режим                      | Извор истине                                                                                                                                                       | Места приказа                                                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Рачунање / приказивање** | Разрешени каталог — испоручена основа преко које се примењује Radar извор (`getRadarCatalog`)                                                                      | Укупне вредности бесплатног нивоа, картица буџета, контролне табле                                                                   |
| **Одлучивање**             | Само испоручени каталог (`FREE_MODEL_BUDGETS` у `open-sse/config/freeModelCatalog.data.ts`) уз локалне хеуристике (суфикс `:free`, нулта цена, `grantsFreeAccess`) | Сваки корисник датотеке `src/shared/utils/freeModels.ts`: увоз модела, усмеравање `auto/*`, `GET /v1/models` и прегледи у прегледачу |

Рачунање се може побољшати кад год је извор доступан. Одлучивање остаје засновано на
артефакту издања, тако да је одговор идентичан у прегледачу и на серверу,
поновљив без мрежне везе и проверљив без базе података. Ако би преглед у
прегледачу читао један извор, а увоз на серверу други, преглед се не би слагао
са оним што се дешава након клика — та подела је задржана
намерно.

## Методологија и ограничења

- Бројеви су **процене горње границе** засноване на документованим ограничењима бесплатног нивоа сваког добављача на дан **2026-06-17**, прикупљене веб-истраживањем. Бесплатни нивои се непрестано мењају — поново их проверите пре него што се ослоните на неки податак.
- **Шта свака ставка заправо потврђује.** Ниједна ставка нема оцену поузданости по реду, нити је API пружа — сваки горенаведени број сматрајте проценом истог, ненаведеног квалитета. Две чињенице су другачије јер се ручно уређују, а не изводе закључивањем: 44 ставке имају независно документовано чврсто ограничење (од тога су 39 xKiro редови, који сви деле исту дневну квоту), а 13 ставки садржи обавештење о коришћењу упита за обучавање. `hardStopGuaranteed` се поставља само када у условима самог добављача пише да ће прекорачење бесплатне квоте довести до одбијања захтева, уместо до прећутног почетка наплате, при чему је извор наведен у коментару поред ставке; никада се подразумевано не поставља на `true`, а ставка коју нико није проверио остаје неподешена. Зато одсуство ознаке чврстог ограничења значи „није утврђено“, а не „познато је да ће вам бити наплаћено“. **STRICT режим** (опциона заштита усмеравања `freeAccessPolicy=strict`) верује само ставкама које имају ту ознаку; сваки други бесплатни ниво искључује се као `no-hard-stop` (погледајте `open-sse/services/autoCombo/strictZeroCostFilter.ts`).
- `estMonthlyFreeTokens` = само месечни токени који се обнављају. **Једнократни кредити при регистрацији се не обнављају** и рачунају се као 0. Укинути нивои се такође рачунају као 0.
- Дневно ограничење токена → `monthly = daily × 30`. Ако је документован само RPD → `RPD × ~800 излазних токена × 30`. Ако постоји само RPM/TPM (без дневног ограничења) → **неограничено** (погледајте испод).
- **Трајно бесплатно, али без објављеног ограничења токена** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): ово су стварни облици бесплатног приступа који се обнавља, уз ограничење брзине/конкурентности. Класификујемо их као `recurring-uncapped` и **никада их не сабирамо** — множење `RPM × 24/7 × 30d` произвело би нереалну горњу границу (такво увећавање одбацујемо). Наведени су како бисте знали да постоје.
- **Повећање откључано депозитом:** једнократна мала доплата која трајно повећава бесплатну квоту (OpenRouter: $10 → 1000 захтева/дан ≈ +24M/месечно). Приказује се као посебан број и не укључује се у главни показатељ сталне квоте.
- **Квоте условљене испуњавањем критеријума** (`eligibilityGate: "regional-identity"`): стварна квота која се редовно обнавља, али се активира тек након провере идентитета везане за одређени регион (тренутно верификација стварног имена у континенталној Кини). Израчунава се по истом правилу уклањања дупликата у оквиру заједничког фонда и приказује као посебан број (`gatedRecurringTokens`), а никада се не укључује у главни показатељ сталне квоте. Режим (`freeType`) остаје непромењен, па се ни усмеравање не мења.
- **Класе доказа.** Правило гласи: број у каталогу наводи свој извор у коментару `// evidence:` поред ставке — `public-page` (страница добављача коју свако може да прочита), `api-public` (неаутентификована крајња тачка добављача, нпр. јавна крајња тачка за планове NaraRouter-а на router.bynara.id) или `console-verified <date> por <who>` (број је видљив само у конзоли налога; коментар бележи ко га је и када видео, као и јавну страницу на којој пише да ограничење постоји). Тренутно стање: пет блокова поново проверених 2026-09-02 садрже ту ознаку (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); ставке које претходе поновној провери од 2026-09-02 наслеђују раније истраживање док не буду измењене; сваки **нови или измењени** број без коментара о доказу представља грешку. Данас је само `mistral` верификован путем конзоле.

## Зашто је наш број мањи него код других агрегатора

Већина вредности „бесплатних токена месечно“ у овој области представља збир вредности наведених за сваки модел. Наша вредност то намерно није:

- **Сваки заједнички пул рачуна се једном.** Бесплатни Mistral план представља једно ограничење од 1B месечно по организацији; навођење тог ограничења под пет модела не чини га ограничењем од 5B. Када би се сабирало по моделу, наш каталог би показивао **~7.4B** (поново израчунато 2026-09-03; ова вредност није контролисана у CI-ју — поново је измерите при свакој промени каталога) — у наслову стоји **~1.47B** јер је то оно што један налог код сваког добављача заиста може да потроши.
- **Дневна ограничења се конвертују, стопе не.** Документовано ограничење токена по дану постаје `× 30`; документовано ограничење захтева по дану постаје `RPD × ~800 токена × 30`; добављач који објављује само број захтева у минуту **нема** месечну вредност и наведен је као _без ограничења_, те се никада не сабира. Множење ограничења стопе са 24/7 јесте надувавање које одбијамо да применимо.
- **Квоте доступне након регионалне провере идентитета приказане су засебно** (`+~6M након регионалне провере идентитета`), јер већина читалаца не може да их користи.
- **Кредити при регистрацији важе само током првог месеца** и приказују се као друга вредност, без спајања са сталном вредношћу.
- **Вредност се проверава путем CI-ја.** `npm run check:docs-counts` поново израчунава укупне вредности из каталога и обара изградњу када ова датотека, README или картица буџета одступе од њих.

## Табела упозорења за ToS

> **Ознака ToS је саветодавна, а не услов за усмеравање.** Провајдери означени са `tos` и даље су подразумевано укључени у усмеравање и combo/fallback механизме; ознака се приказује само на `/dashboard/free-tiers` и `/api/free-tier/summary`. Параметар упита `excludeTosAvoid` утиче само на приказ сажетка, а не на глобално усмеравање. Процена се налази у `open-sse/config/freeTierCatalog.ts` (информативна је и механизми за усмеравање је не читају).

> Кратак преглед услова сваког провајдера за лични прокси са сопственим хостингом и једним корисником. `caution` = одредба о личној употреби или проксију коју вреди проверити; `ambiguous` = нејасно; `ok` = изричито дозвољено. Информативног је карактера и не представља правни савет — ви одлучујете.

## Речник

| Термин                  | Значење                                                                                       |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**     | Захтеви у минути / дану / сату                                                                |
| **TPM / TPD**           | Токени у минути / дану                                                                        |
| **Документована квота** | Добављач објављује изричито дневно/месечно ограничење токена (буџет који се може образложити) |
| **Теоријски максимум**  | `ограничење стопе × 24/7 × 30d` — максимум, а не додељени буџет                               |
| **Неурон**              | Cloudflare рачунарска јединица (~1 излазни токен)                                             |
