OmniRoute се испоручује са одабраним скупом бесплатних проксија у табели `free_proxies`,
синхронизованим са спољним добављачима (1proxy, proxifly, iplocate, webshare). Контролна
табла их приказује у одељку **Подешавања → Бесплатни проксији**. Овај документ
описује филтрирање, сортирање, пребројавање и пријављивање грешака при синхронизацији
на страни сервера које рута за листу пружа.

## Рута за листу — `GET /api/settings/free-proxies`

Враћа филтрирани, сортирани и пагинирани подскуп, заједно са укупним бројем. Филтрирање и
пребројавање обављају се у SQL-у, тако да кориснички интерфејс може да прикаже стварни укупан број (нпр. `Укупно: 0`)
без учитавања сваког реда у меморију.

### Параметри упита

| Параметар         | Тип                                | Подразумевано | Значење                                                                                                                      |
| ----------------- | ---------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`          | `LIKE` осетљив на величину слова над колоном хоста (и извора).                                                               |
| `protocol`        | string                             | `""`          | Филтер за `type`: `http` / `https` / `socks4` / `socks5`. Празно = све.                                                      |
| `country`         | string                             | `""`          | Филтер за `countryCode` (ISO-2). Празно = све.                                                                               |
| `minQuality`      | number                             | `0`           | Само редови са `qualityScore >= minQuality`. `0` = без доње границе.                                                         |
| `disabledSources` | string                             | `""`          | Идентификатори извора раздвојени запетама које треба изузети (нпр. `proxifly,webshare`).                                     |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`     | `quality` = резултат опадајуће; `latency` = кашњење растуће (null вредности на крају); `recent` = `lastValidated` опадајуће. |
| `offset`          | number                             | `0`           | Почетак пагинације.                                                                                                          |
| `limit`           | number                             | `50`          | Величина странице (ограничена на страни сервера).                                                                            |

### Одговор

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 од узводног сервиса"],
    "webshare": ["истек времена мрежне везе"]
  }
}
```

`total` представља филтрирани укупан број **пре** пагинације, тако да кориснички интерфејс може независно да прикаже
`Укупно: N` и `hasMore`. `syncErrors` користи идентификатор извора као кључ и
попуњава се само за изворе чија је последња синхронизација била неуспешна — резултат `Укупно: 0`
никада се не приказује без објашњења.

## Додавање у скуп — `POST /api/settings/free-proxies/[id]/add-to-pool`

Премешта бесплатни прокси у управљани скуп `proxy_registry`. Прво проверава
узводни сервис; у случају успеха враћа идентификатор новог проксија у скупу и измерено кашњење.

## Синхронизација — `POST /api/settings/free-proxies/sync`

Поново преузима податке из свих омогућених извора (или подскупа наведеног у `{ "sources": [...] }`). Сваки
извор се синхронизује независно; неуспех једног извора бележи се у `syncErrors`, док се
остали и даље довршавају, тако да делимичне синхронизације никада не бришу претходно исправне податке.

## Статистика — `GET /api/settings/free-proxies/stats`

Враћа агрегиране вредности `total / inPool / avgQuality / bySource / lastSyncAt`
без садржаја редова — користе их виџети у заглављу контролне табле.
