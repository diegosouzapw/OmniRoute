Kontrolna tabla → Pružaoci usluga → **Uvezi iz datoteke** kreira veze sa API ključevima iz CSV ili JSON liste. Svaki red može da cilja drugog pružaoca usluga. Delimičan neuspeh je predviđeno ponašanje: važeći redovi se uvoze čak i kada drugi ne uspeju, a modalni prozor navodi zašto su neuspešni redovi odbijeni.

Ovaj uvoz **ne** kreira nove čvorove krajnjih tačaka kompatibilne sa OpenAI/Anthropic. Najpre ih kreirajte (Kontrolna tabla → Pružaoci usluga → Dodaj čvor kompatibilan sa OpenAI ili `omniroute nodes add`), a zatim uvezite redove čija kolona `provider` sadrži id tog čvora. Vrednost `baseUrl` za pojedinačni red i dalje može da zameni URL čvora.

## CSV (pozicioni)

Nazivi kolona su samo kozmetički. Parser deli svaki red i destrukturira ga prema indeksu:

| Indeks | Polje      | Obavezno | Napomene                                                                                                                                   |
| ------ | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 0      | `provider` | da       | Postojeći id podržanog pružaoca usluga (`openai`, `anthropic`, …) **ili** id već registrovanog **čvora** kompatibilnog sa OpenAI/Anthropic |
| 1      | `name`     | da       | Prikazni naziv veze                                                                                                                        |
| 2      | `apiKey`   | da       | API ključ                                                                                                                                  |
| 3      | `baseUrl`  | ne       | Zamenski URL za pojedinačni red                                                                                                            |
| 4      | `priority` | ne       | Ceo broj od 1 do 100                                                                                                                       |

Prvi red čija prva kolona sadrži doslovnu reč `provider` (bez obzira na veličinu slova) preskače se kao zaglavlje. Prazni redovi i komentari sa `#` se preskaču.

Preuzmite početnu datoteku iz modalnog prozora za uvoz (**Preuzmi CSV šablon**). Primer:

```csv
# Uvoz pružalaca usluga u OmniRoute (pozicione kolone)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Izmišljeni id, kao što je `openai-compatible-chat-001`, nije čvor. API za taj red vraća `Nepoznat ili nepodržan pružalac usluga`; modalni prozor ga prikazuje pored naziva reda.

## JSON

JSON niz objekata sa istim poljima (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Za razliku od CSV-a, JSON ključevi su imenovani.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
