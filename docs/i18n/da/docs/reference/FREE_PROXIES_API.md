OmniRoute leveres med en kurateret samling af gratis proxyer i tabellen `free_proxies`,
som synkroniseres fra eksterne udbydere (1proxy, proxifly, iplocate, webshare).
Dashboardet viser disse under **Indstillinger → Gratis proxyer**. Dette dokument
beskriver den serversidefiltrering, sortering, optælling og rapportering af
synkroniseringsfejl, som listeruten eksponerer.

## Listerute — `GET /api/settings/free-proxies`

Returnerer et filtreret, sorteret og sideinddelt udsnit samt et samlet antal.
Filtrering og optælling sker i SQL, så brugergrænsefladen kan vise det faktiske
samlede antal (f.eks. `I alt: 0`) uden at indlæse alle rækker i hukommelsen.

### Forespørgselsparametre

| Parameter         | Type                               | Standard  | Betydning                                                                                                             |
| ----------------- | ---------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`      | Forskel på store og små bogstaver ved `LIKE` på værtskolonnen (og kildekolonnen).                                     |
| `protocol`        | string                             | `""`      | `type`-filter: `http` / `https` / `socks4` / `socks5`. Tom = alle.                                                    |
| `country`         | string                             | `""`      | `countryCode`-filter (ISO-2). Tom = alle.                                                                             |
| `minQuality`      | number                             | `0`       | Kun rækker med `qualityScore >= minQuality`. `0` = ingen nedre grænse.                                                |
| `disabledSources` | string                             | `""`      | Kommaseparerede kilde-id'er, der skal udelukkes (f.eks. `proxifly,webshare`).                                         |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = score faldende; `latency` = latenstid stigende (null-værdier sidst); `recent` = `lastValidated` faldende. |
| `offset`          | number                             | `0`       | Startpunkt for sideinddeling.                                                                                         |
| `limit`           | number                             | `50`      | Sidestørrelse (begrænses på serversiden).                                                                             |

### Svar

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 fra upstream"],
    "webshare": ["netværkstimeout"]
  }
}
```

`total` afspejler det filtrerede samlede antal **før** sideinddeling, så
brugergrænsefladen kan gengive `I alt: N` og `hasMore` uafhængigt af hinanden.
`syncErrors` bruger kilde-id'et som nøgle og udfyldes kun for kilder, hvis seneste
synkronisering mislykkedes — et resultat med `I alt: 0` er aldrig uden forklaring.

## Føj til samling — `POST /api/settings/free-proxies/[id]/add-to-pool`

Overfører en gratis proxy til den administrerede `proxy_registry`-samling.
Validerer først upstream-kilden; ved succes returneres den nye proxy-id i
samlingen samt den målte latenstid.

## Synkronisering — `POST /api/settings/free-proxies/sync`

Henter alle aktiverede kilder igen (eller delmængden i `{ "sources": [...] }`).
Hver kilde synkroniseres uafhængigt; en kilde, der fejler, registreres i
`syncErrors`, mens de øvrige stadig gennemføres, så delvise synkroniseringer
aldrig sletter tidligere gyldige data.

## Statistik — `GET /api/settings/free-proxies/stats`

Returnerer aggregatet `total / inPool / avgQuality / bySource / lastSyncAt`
uden rækkedataene — bruges af dashboardets header-widgets.
