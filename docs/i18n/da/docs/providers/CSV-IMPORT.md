Dashboard → Providers → **Importér fra fil** opretter API-nøgleforbindelser fra en CSV- eller JSON-liste. Hver række kan målrettes mod en anden udbyder. Delvis fejl er en del af kontrakten: Gyldige rækker importeres stadig, når andre fejler, og dialogboksen viser, hvorfor de mislykkede rækker blev afvist.

Denne import opretter **ikke** nye OpenAI/Anthropic-kompatible slutpunktsnoder. Opret dem først (Dashboard → Providers → Add OpenAI-Compatible eller `omniroute nodes add`), og importér derefter rækker, hvor kolonnen `provider` er den pågældende nodes id. En `baseUrl` pr. række kan stadig tilsidesætte nodens URL.

## CSV (positionsbaseret)

Kolonnenavnene er kosmetiske. Parseren opdeler hver række og destrukturerer efter indeks:

| Indeks | Felt       | Påkrævet | Bemærkninger                                                                                                                                      |
| ------ | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0      | `provider` | ja       | Eksisterende administreret udbyder-id (`openai`, `anthropic`, …) **eller** id'et for en allerede registreret OpenAI/Anthropic-kompatibel **node** |
| 1      | `name`     | ja       | Forbindelsens viste navn                                                                                                                          |
| 2      | `apiKey`   | ja       | API-nøgle                                                                                                                                         |
| 3      | `baseUrl`  | nej      | URL-tilsidesættelse pr. række                                                                                                                     |
| 4      | `priority` | nej      | Heltal fra 1–100                                                                                                                                  |

En første linje, hvis første kolonne er det bogstavelige ord `provider` (uanset store og små bogstaver), springes over som en kolonneoverskrift. Tomme linjer og `#`-kommentarer springes over.

Download en startfil fra importdialogboksen (**Download CSV-skabelon**). Eksempel:

```csv
# OmniRoute-udbyderimport (positionsbaserede kolonner)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Et opdigtet id såsom `openai-compatible-chat-001` er ikke en node. API'et returnerer `Unknown or unsupported provider` for den pågældende række; dialogboksen viser det ud for rækkens navn.

## JSON

Et JSON-array af objekter med de samme felter (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). I modsætning til CSV er JSON-nøgler navngivne.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
