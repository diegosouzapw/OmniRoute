> **Kort fortalt**: Installer → Tilslut en gratis udbyder → Peg dit IDE på OmniRoute. Færdig.

---

## Trin 1: Installer OmniRoute

Vælg din foretrukne metode:

### Mulighed A: npm (anbefalet)

```bash
npm install -g omniroute
```

### Mulighed B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` er den højeste **udgivne** stabile SemVer-version. Den følger **ikke** git `main`. Fastlås `diegosouzapw/omniroute:X.Y.Z` til GitOps. Se [Image-tags/udgivelseskanaler](../guides/DOCKER_GUIDE.md#release-channels).

### Mulighed C: Fra kildekoden

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Trin 2: Start OmniRoute

```bash
omniroute
```

OmniRoute starter på `http://localhost:20128`. Dashboardet åbnes automatisk.

---

## Trin 3: Tilslut en gratis udbyder

Du kan bruge OmniRoute **helt gratis** ved at tilslutte en gratis udbyder.

### Mulighed A: Kiro (gratis Claude — intet kreditkort)

1. Åbn dashboardet på `http://localhost:20128`
2. Gå til **Udbydere** → **Tilføj udbyder**
3. Vælg **Kiro AI**
4. Klik på **Tilslut** (ingen API-nøgle nødvendig!)
5. Færdig! Du har nu gratis adgang til Claude-modeller.

### Mulighed B: OpenCode Free (ingen godkendelse)

1. Åbn dashboardet på `http://localhost:20128`
2. Gå til **Udbydere** → **Tilføj udbyder**
3. Vælg **OpenCode Free**
4. Klik på **Tilslut** (ingen API-nøgle nødvendig!)
5. Færdig! Du har nu gratis adgang til flere modeller.

### Mulighed C: Pollinations (ingen nøgle nødvendig)

1. Åbn dashboardet på `http://localhost:20128`
2. Gå til **Udbydere** → **Tilføj udbyder**
3. Vælg **Pollinations**
4. Klik på **Tilslut** (ingen API-nøgle nødvendig!)
5. Færdig! Du har nu gratis adgang til GPT-5, Claude, Gemini og flere andre.

---

## Trin 4: Kontrollér, at det virker

Opret en ny nøgle under [API-nøgler](http://localhost:20128/dashboard/api-manager). Gem denne nøgle, da den ikke vises igen. Bemærk, at denne nøgle bruges af værktøjer til at få adgang til OmniRoute, ikke til at få adgang til upstream-udbydere.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Du bør kunne se dine tilsluttede modeller på listen.

## Trin 5: Peg dit IDE eller CLI på OmniRoute

Angiv følgende i dit IDE eller CLI-værktøj:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

Det var det! Dit IDE bruger nu OmniRoute med automatisk valg af udbyder.

### IDE-eksempel: VSCode/Continue.dev

1. Installer udvidelsen [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) i VSCode.
2. Opdater din `~/.continue/config.yaml` ved at tilføje følgende linjer:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Vælg `OmniRoute - Auto` i Continue.dev-chatpanelet for at sende anmodninger til OmniRoute.
4. (Valgfrit) En øvelse til læseren – få dit IDE til at opdatere `config.yaml` med alle de øvrige færdigbyggede konfigurationer 😊

### CLI-eksempel: Codex CLI

1. Angiv miljøvariablen permanent i dit operativsystem.
   For macOS/Linux (tilføj den i din `~/.bashrc` eller `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

For Windows (Kommandoprompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Lad os nu starte Codex konfigureret til OmniRoute. Kør:

```
omniroute launch-codex --model auto
```

Du kan gøre dette manuelt via `codex` og kommandolinjeparametre for at angive slutpunktet og API-nøglen, men med ovenstående kommando klarer OmniRoute det hele for dig.

Den samme start med én kommando fungerer for andre CLI'er via den generiske launcher — `omniroute run <target>` understøtter `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` og `gemini` (se [CLI-integrationer](../guides/CLI-INTEGRATIONS.md)).

3. CLI'en bør nu sende anmodninger til OmniRoute.

### Bekræft, at dit værktøj sender trafik til OmniRoute

Du kan se oplysningerne om anmodningen ved at klikke på [Overvågning/logfiler](http://localhost:20128/dashboard/logs) i venstre sidepanel. Når du klikker dig videre, vises flere oplysninger. Som en sidebemærkning kan du se, hvilke oplysninger der sendes fra dit foretrukne værktøj. Det er nyttigt både til læring og fejlfinding.

## Ofte stillede spørgsmål

### "Har jeg brug for en API-nøgle?"

**Nej!** Du kan bruge gratis udbydere (Kiro, OpenCode Free, Pollinations) uden en API-nøgle. Du skal blot tilslutte dem i dashboardet.

### "Hvad er `auto`?"

`auto` fortæller OmniRoute, at den automatisk skal vælge den bedste udbyder til hver anmodning. Den tager højde for hastighed, pris, kvalitet og tilgængelighed. Se [guiden til Auto-Combo](./AUTO-COMBO-GUIDE.md) for nærmere oplysninger.

### "Hvad koster det?"

OmniRoute er i sig selv **gratis og open source**. Du betaler kun for de udbydere, du bruger. Mange udbydere har gratis niveauer — se [guiden til gratis niveauer](./FREE-TIERS-GUIDE.md).

### "Kan jeg bruge det med Claude Code / Cursor / Copilot?"

**Ja!** OmniRoute fungerer med alle værktøjer, der understøtter OpenAI-formatet. Du skal blot angive basis-URL'en som `http://localhost:20128/v1`. Se [guiden til CLI-værktøjer](../reference/CLI-TOOLS.md) for specifikke konfigurationsinstruktioner.

### "Hvad sker der, hvis en udbyder går ned?"

OmniRoute springer automatisk over udbydere, der fejler, og prøver den næste. Du behøver ikke at gøre noget. Se [guiden til Auto-Combo](./AUTO-COMBO-GUIDE.md) for nærmere oplysninger.
