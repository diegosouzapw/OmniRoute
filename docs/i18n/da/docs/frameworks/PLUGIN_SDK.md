## Hurtig start

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "my-plugin",
  priority: 50,
  onRequest: async (ctx) => {
    console.log(`Request ${ctx.requestId} for ${ctx.model}`);
  },
  onResponse: async (ctx, response) => {
    console.log(`Response for ${ctx.requestId}`);
    return response;
  },
  onError: async (ctx, error) => {
    console.error(`Error: ${error.message}`);
  },
});
```

## API-reference

### `definePlugin(def: PluginDefinition): Plugin`

Factoryfunktion, der opretter et Plugin-objekt med standardværdier.

**Parametre:**

- `name` (string, påkrævet) — Pluginnavn i kebab-case
- `priority` (number, valgfri, standard: 100) — Lavere værdier køres først
- `enabled` (boolean, valgfri, standard: true) — Skal pluginet være aktiveret fra starten?
- `onRequest` (function, valgfri) — Køres før chat-handleren
- `onResponse` (function, valgfri) — Køres efter chat-handleren
- `onError` (function, valgfri) — Køres ved fejl i handleren

### `blockRequest(response?): BlockingHookResult`

Bloker anmodningen, og returnér eventuelt et brugerdefineret svar.

```ts
onRequest: (ctx) => {
  if (!ctx.headers["authorization"]) {
    return blockRequest({ error: "Unauthorized", status: 401 });
  }
};
```

### `modifyBody(body): PluginResult`

Rediger anmodningsteksten, før den når udbyderen.

```ts
onRequest: (ctx) => {
  return modifyBody({ ...ctx.body, temperature: 0.7 });
};
```

### `addMetadata(metadata): PluginResult`

Knyt metadata til anmodningskonteksten.

```ts
onRequest: (ctx) => {
  return addMetadata({ source: "my-plugin", version: "1.0.0" });
};
```

## Pluginkontekst (`PluginContext`)

| Felt        | Type                      | Beskrivelse                     |
| ----------- | ------------------------- | ------------------------------- |
| `requestId` | `string`                  | Entydig anmodningsidentifikator |
| `model`     | `string`                  | Navn på den anmodede model      |
| `provider`  | `string`                  | Måludbyderens ID                |
| `body`      | `Record<string, unknown>` | Anmodningstekst                 |
| `headers`   | `Record<string, string>`  | Anmodningsheadere               |
| `metadata`  | `Record<string, unknown>` | Redigerbare metadata            |
| `timestamp` | `number`                  | Tidsstempel for anmodningen     |

## Manifest (`plugin.json`)

```json
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "A sample plugin",
  "author": "your-name",
  "main": "index.js",
  "hooks": {
    "onRequest": { "enabled": true, "priority": 50 },
    "onResponse": true,
    "onError": false
  },
  "requires": {
    "permissions": ["network", "file-read"]
  },
  "enabledByDefault": false,
  "configSchema": {
    "apiKey": {
      "type": "string",
      "description": "API key for external service"
    },
    "maxRetries": { "type": "number", "min": 1, "max": 10, "default": 3 },
    "debug": { "type": "boolean", "default": false },
    "mode": { "type": "string", "enum": ["fast", "slow"], "default": "fast" }
  }
}
```

### Hookprioritet

Hooks kan konfigureres med en prioritet (lavere = køres først):

```json
{
  "hooks": {
    "onRequest": { "enabled": true, "priority": 10 },
    "onResponse": { "enabled": true, "priority": 100 }
  }
}
```

Eller som simple booleske værdier (standardprioritet 100):

```json
{
  "hooks": {
    "onRequest": true,
    "onResponse": true
  }
}
```

## Tilladelsessystem

Plugins kører i en sandkassebaseret VM-kontekst. Adgang til eksterne ressourcer kræver udtrykkelige tilladelser:

| Tilladelse   | Giver adgang til                                             |
| ------------ | ------------------------------------------------------------ |
| `network`    | `fetch`, `AbortController`, `Headers`, `Request`, `Response` |
| `file-read`  | `fs.readFile`, `fs.readdir`, `fs.stat`                       |
| `file-write` | `fs.writeFile`, `fs.mkdir`, `fs.rm`                          |
| `env`        | Skrivebeskyttet `process.env`-proxy                          |
| `exec`       | `child_process.exec`, `child_process.execSync`               |

Uden en tilladelse er de tilsvarende globale objekter ganske enkelt ikke tilgængelige i sandkassen.

## Konfigurationsskema

Definer konfigurerbare indstillinger i `configSchema`:

```json
{
  "configSchema": {
    "apiKey": { "type": "string", "description": "External API key" },
    "maxRetries": { "type": "number", "min": 1, "max": 10, "default": 3 },
    "debug": { "type": "boolean", "default": false },
    "mode": { "type": "string", "enum": ["fast", "slow"], "default": "fast" }
  }
}
```

Felttyper: `string`, `number`, `boolean`, `select`

Feltindstillinger: `default`, `min`, `max`, `enum`, `description`

Konfigurationsværdier gemmes i databasen og er tilgængelige via dashboardets konfigurationsside.

## Indbyggede hændelser

| Hændelse          | Hvornår                                  | Data                          |
| ----------------- | ---------------------------------------- | ----------------------------- |
| `onRequest`       | Før chat-handleren                       | Forespørgselskontekst         |
| `onResponse`      | Efter chat-handleren                     | Svardata                      |
| `onError`         | Ved handlerfejl                          | Fejlobjekt                    |
| `onModelSelect`   | Model valgt til routing                  | Modeloplysninger              |
| `onComboResolve`  | Kombinationsrouting afklaret             | Kombinationsmål               |
| `onRateLimit`     | Hastighedsgrænse nået                    | Grænseoplysninger             |
| `onQuotaExhaust`  | Kvote opbrugt                            | Kvoteoplysninger              |
| `onProviderError` | Udbyderen returnerede en fejl            | Fejloplysninger               |
| `onStreamStart`   | SSE-stream startet                       | Streamoplysninger             |
| `onStreamEnd`     | SSE-stream afsluttet                     | Streamstatistik               |
| `onInstall`       | Plugin installeret                       | `{ name, version, manifest }` |
| `onActivate`      | Plugin aktiveret                         | `{ name, version, manifest }` |
| `onDeactivate`    | Plugin deaktiveret                       | `{ name, version, manifest }` |
| `onUninstall`     | Plugin afinstalleret (før filer slettes) | `{ name, version, manifest }` |

## Eksempler

### Logning af forespørgsler

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "request-logger",
  onRequest: async (ctx) => {
    console.log(`[${new Date().toISOString()}] ${ctx.method} ${ctx.model} -> ${ctx.provider}`);
  },
});
```

### Hastighedsbegrænser

```ts
import { definePlugin, blockRequest } from "omniroute/plugins/sdk";

const requests = new Map<string, number[]>();

export default definePlugin({
  name: "rate-limiter",
  priority: 10,
  onRequest: async (ctx) => {
    const key = ctx.headers["x-api-key"] || "anonymous";
    const now = Date.now();
    const window = 60000; // 1 minut
    const maxRequests = 100;

    const timestamps = (requests.get(key) || []).filter((t) => t > now - window);
    timestamps.push(now);
    requests.set(key, timestamps);

    if (timestamps.length > maxRequests) {
      return blockRequest({ error: "Rate limit exceeded", status: 429 });
    }
  },
});
```

### Svartransformator

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "response-transformer",
  onResponse: async (ctx, response) => {
    if (response.choices) {
      response.choices = response.choices.map((c: any) => ({
        ...c,
        message: { ...c.message, content: c.message.content.trim() },
      }));
    }
    return response;
  },
});
```
