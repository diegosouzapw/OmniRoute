## Hvad det er

Local Corpus giver en operatør mulighed for at gøre én udtrykkeligt godkendt mappe med tekstfiler tilgængelig for
OmniRoutes MCP-server. Filerne forbliver i deres oprindelige mappe: OmniRoute gemmer kun
den kanoniske rodsti i SQLite og vedligeholder et søgeindeks i hukommelsen. Korpusindholdet
kopieres ikke til repositoryet eller databasen.

Indekset opdateres trinvist. Uændrede filer genbruges baseret på størrelse og ændringstidspunkt,
ændrede filer genindlæses og hashes med SHA-256, og slettede filer fjernes.
Søgning opdaterer et indeks, der er ældre end 30 sekunder; kaldende klienter kan også anmode om en øjeblikkelig
opdatering.

## Konfigurer kilden

Indstillingsruten kræver den samme administrationsgodkendelse som andre indstillings-API'er.
Den indsendte sti skal allerede eksistere og skal være en absolut mappesti.

```bash
# Tilslut en godkendt mappe
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Kontrollér konfiguration og indeksstatus
curl http://localhost:20128/api/settings/local-corpus

# Afbryd forbindelsen uden at ændre kildefiler
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP-værktøjer

Alle tre værktøjer kræver `read:local-corpus`. Værktøjssvar viser relative stier og
rodmappens basisnavn, aldrig dens absolutte sti.

| Værktøj               | Beskrivelse                                                                                      |
| :-------------------- | :----------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Rapporter konfigurationstilstand, indeksstørrelse, grænser og tidspunktet for seneste opdatering |
| `local_corpus_search` | Søg i indekseret tekst, og returner afgrænsede uddrag pr. linje (op til 20 resultater)           |
| `local_corpus_read`   | Læs et afgrænset linjeinterval fra én tilladt korpusrelativ fil                                  |

Eksempler på MCP-input:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Sikkerhedsgrænser

- Tilladelseslisten er tekstorienteret: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` og `.yml`.
- Symbolske links springes over. Læsestier kanoniseres og skal forblive inden for den
  konfigurerede rod; absolutte stier og forsøg på stitraversering afvises.
- Følsomme og genererede mappenavne udelukkes: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` og
  `secrets`.
- Standardgrænserne er 5.000 filer, 1 MiB pr. fil, 64 MiB samlet indekseret indhold,
  cirka 4.000 tegn pr. søgeblok og 400 linjer pr. læsning.
- Filer, der indeholder NUL, behandles som ikke-tekst og springes over eller afvises.

Binære dokumenter såsom PDF, DOCX, billeder og arkiver understøttes bevidst ikke.
Konvertér dem til et godkendt tekstformat i den konfigurerede mappe før indeksering.

## Driftsbemærkninger

- Ændring eller sletning af den konfigurerede rod rydder det delte indeks i hukommelsen.
- En genstart af processen kasserer indekset; den næste søgning genopbygger det fra den konfigurerede
  kilde.
- `local_corpus_status` fremtvinger ikke en scanning. Brug `local_corpus_search` med
  `refresh: true`, når en øjeblikkelig genscanning er påkrævet.
- Scannings- og læsefejl tælles eller returneres som rensede fejl; kildefiler
  ændres aldrig.
