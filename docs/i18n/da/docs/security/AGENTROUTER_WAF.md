`agentrouter`-upstreamgatewayen kører et nøgleordsbaseret indholdsfilter på
`messages[].content`. Filteret er delvist deterministisk (blokerer altid
bestemte fraser) og delvist probabilistisk (følsomt over for trafikspidser — bliver
mere aggressivt efter hurtige forespørgsler og normaliseres efter en afkølingsperiode).

Når WAF'en blokerer en forespørgsel, returnerer den:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Filterets omfang

WAF'en inspicerer kun `messages[].content`. Den inspicerer **ikke**:

- `system`-prompten
- Strukturerede indholdsblokke (`tool_result`, `tool_use`, `thinking`, `image`)
- Værktøjernes `description`- og `input_schema`-felter
- Metadata for forespørgsler, headers eller model-id

## Mønstre, der altid blokeres (uafhængigt af store og små bogstaver)

| Mønster                         | Bemærkninger                                            |
| ------------------------------- | ------------------------------------------------------- |
| Enhver variant af `Lorem ipsum` | Hele det latinske lorem-ordforråd blokeres              |
| `language model` (alene)        | "the language model" og "large language model" tillades |
| `virtual assistant`             | "AI assistant" tillades                                 |
| `I'm here to help`              | "here to help" alene blokeres også                      |
| `Claude, made by Anthropic`     | Kun hele frasen                                         |

## Mønstre, der næsten altid blokeres

| Mønster                                                 | Bemærkninger                                        |
| ------------------------------------------------------- | --------------------------------------------------- |
| `placeholder`                                           | Når det står alene (ikke som et parameternavn osv.) |
| `dummy data`                                            | Almindelig seed-frase til fixtures                  |
| `foo bar baz`                                           | Kanonisk pladsholderfrase                           |
| Gentagne korte tokens (`AAA BBB CCC`, `test test test`) | Detektor til keyword stuffing                       |

## Adfærd under belastning

Efter ca. 5 hurtige forespørgsler inden for et kort tidsrum begynder WAF'en at blokere indhold,
som normalt ville blive tilladt. Begrænsningen lempes efter ca. 5–10 sekunders inaktivitet.
Det er den samme IP- og nøglebundne hastighedsbegrænser, der forårsager
periodiske `400 content-blocked`-fejl, når Claude Code eller Codex CLI
foretager flere værktøjsbrug-/beskedafsendelseskald hurtigt efter hinanden.

## Afhjælpninger, der allerede er implementeret i OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — beskyttelse mod trafikspidser, der håndhæver et
   minimumsinterval på 500 ms mellem udgående forespørgsler til enhver `agentrouter:*`-
   URL. Intervallet er langt under den forsinkelse, mennesker kan opfatte, og forhindrer
   WAF'en i at blive aktiveret ved normal trafik.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — når en upstream returnerer
   `400 content-blocked`, prøver eksekveringskomponenten den samme URL igen med
   eksponentiel backoff (1,5 s, 3,0 s, maks. 2 forsøg). Efter denne backoff
   er WAF'en normalt lempet, og det nye forsøg lykkes.

3. **`tests/unit/compression/harness.test.ts`** — test-fixturen
   `longInput` blev ændret fra `"lorem ipsum dolor sit amet ".repeat(40)`
   til `"example content for testing purposes ".repeat(40)`, så filens indhold,
   når Claude Code læser denne fil via værktøjet `Read`, ikke sendes
   tilbage gennem en `tool_result`-blok og udløser WAF'en.

## Vejledning til prompts og værktøjsoutput

Hvis en Claude Code- eller Codex CLI-session gentagne gange rammer
`400 content-blocked`, skal du kontrollere den seneste brugermeddelelse og det seneste
værktøjsresultat for nogle af ovenstående mønstre og omformulere dem. Almindelige
løsninger:

- Erstat `Lorem ipsum …` med `example text …` eller det faktiske indhold,
  som testen eller fixturen forsøger at modellere.
- Erstat `placeholder` (når det står alene) med `example value`,
  `sample value` eller den faktiske værdi.
- Erstat `language model` med `large language model` eller `the model`.
- Erstat `dummy data` med `sample data` eller realistiske seed-værdier.
- Erstat `I'm here to help` / `here to help` med en mere specifik
  indledning (f.eks. "I'll review the file you mentioned").

## Rapportering af falske positiver til upstream

Det aktuelle filter er for aggressivt — det blokerer "Lorem ipsum" i
`tool_result`-blokke, selvom operatøren tydeligvis ikke havde til hensigt at
injicere en prompt. Operatører, der ønsker dette rettet ved kilden, bør
kontakte `agentrouter.org` for at rapportere de falske positiver. Ovenstående blokeringsliste
er det empiriske resultat af test af upstream-tjenesten pr. 2026-08-03.
