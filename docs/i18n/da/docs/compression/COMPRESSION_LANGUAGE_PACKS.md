Caveman-komprimering kan indlæse sprogspecifikke regelpakker ud over de indbyggede engelske regler.
Dette holder kernemotoren stabil, samtidig med at portugisiske, spanske, tyske, franske, italienske, japanske og
fremtidige sprogpakker kan udvikles uafhængigt.

## Placering

Sprogpakker findes under:

```txt
open-sse/services/compression/rules/<language>/
```

Aktuelt leverede pakker (verificeret mod indholdet af mappen `rules/`):

| Sprog                   | Mappe          | Tilgængelige regelkategorier                        |
| ----------------------- | -------------- | --------------------------------------------------- |
| Engelsk                 | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spansk                  | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugisisk (Brasilien) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonesisk              | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italiensk               | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Tysk                    | `rules/de/`    | `context`, `filler`, `structural`                   |
| Fransk                  | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japansk                 | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Bemærkning om funktionsparitet:** Pakkerne `en`, `es`, `pt-BR`, `id` og `it` har alle 5 kategorier; `de`, `fr` og `ja` leveres med 3 kategorier. De manglende kategorier `dedup` og `ultra` falder automatisk tilbage til de indbyggede engelske regler. Bidrag til at føje `dedup.json` og `ultra.json` til de mindre pakker er velkomne.
>
> Pakken `pt-BR` er baseret på **[Troglodita](https://github.com/leninejunior/troglodita)** af Lenine Júnior — et komprimeringssystem, der er udviklet fra bunden til brasiliansk-portugisisk grammatik (reduktion af pleonasmer, fjernelse af fyldord på PT-BR og tekniske forkortelser til det brasilianske udviklerfællesskab).
>
> Den kanoniske kategoriliste og skemaet for hver kategori findes i [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema-udkast 2020-12).

## Sprogregistrering

`languageDetector.ts` bruger simple heuristikker til at udlede sproget fra promptteksten. Det
konfigurerede standardsprog respekteres stadig, og registrering kan deaktiveres via konfigurationen, når præcis
kontrol er påkrævet.

Registreringsresultatet bruges kun til at vælge regelpakker. Det ændrer ikke providerrouting, valg af landestandard
eller brugergrænsefladens sprog.

## Konfigurationsstruktur

Komprimeringsindstillinger kan indeholde:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` styrer standardindstillingerne for dashboardet og forhåndsvisningen. `cavemanConfig` er den konfiguration af kørselsmotoren,
der bruges, når Caveman komprimerer meddelelsestekst.

## Tilføjelse af en sprogpakke

1. Opret `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Brug Caveman-regelformatet fra `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Hold erstatningerne konservative, og undgå at ændre kode, identifikatorer, URL'er eller JSON.
4. Tilføj eller opdater tests for sprogvalg og erstatningsadfærd.
5. Tilføj nye dashboard-/i18n-etiketter, hvis sproget vises i UI-vælgere.

## API

Tilgængelige pakker kan forespørges med:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Endpointet til forhåndsvisning accepterer tilsidesættelser af sprogkonfigurationen:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Alle 6 sprogpakker fik tilføjet en `SHARED_BOUNDARIES`-klausul i v3.8.0, som anvendes ved hver
Caveman-intensitet (LITE, FULL, ULTRA). Den instruerer motoren i at bevare disse mønstre ordret,
uanset omgivende fjernelse af fyldord:

| Mønstertype                     | Eksempel                               |
| ------------------------------- | -------------------------------------- |
| Indhegnede kodeblokke           | ` ```python\n...\n``` `                |
| Indlejret kode                  | `` `my_var` ``                         |
| URL'er                          | `https://example.com/path`             |
| Filstier (absolutte + relative) | `/etc/hosts`, `./src/index.ts`         |
| Fejloverskrifter                | `Error:`, `TypeError:`, `SyntaxError:` |
| Staksporingslinjer              | `  at functionName (file.ts:12:3)`     |

Disse mønstre udfyldes i `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (tidligere `[]`). Konstanten
findes i `open-sse/services/compression/types.ts`.

### Hvorfor dette er vigtigt

Uden SHARED_BOUNDARIES kunne aggressive Caveman-tilstande fjerne indhold, der lignede gentagende
prosa, men som faktisk var et kodestykke, en filsti eller en fejlstak. SHARED_BOUNDARIES fungerer som
et sproguafhængigt sikkerhedsnet, der anvendes, før reglerne for fyldord køres.

### Tilpasning af preservePatterns

Yderligere mønstre kan tilføjes under kørsel via komprimeringsindstillingerne:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Brugerdefinerede mønstre udvider (og erstatter ikke) de 6 standardmønstre.

## Driftsbemærkninger

- De indbyggede engelske regler forbliver reserveløsningen, når en sprogpakke mangler.
- Ugyldige indbyggede JSON-pakker består ikke valideringen, så udgivelsesartefakter ikke forringes ubemærket.
- Regelpakker indeholder kun data og bør ikke importere kode eller køre vilkårlig logik.
- Analysekomponenten for komprimering registrerer den valgte tilstand og motor, ikke den fulde prompttekst.
