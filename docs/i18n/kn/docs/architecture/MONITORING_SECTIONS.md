## ಉನ್ನತ ಮಟ್ಟದ ನ್ಯಾವಿಗೇಶನ್

ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಸೈಡ್ಬಾರ್ನಲ್ಲಿ (ಗುಂಪು B ನಂತರ) ಈ ಉನ್ನತ ಮಟ್ಟದ ವಿಭಾಗಗಳು ಕ್ರಮವಾಗಿ ಇವೆ:

```
ಮುಖಪುಟ
ಪೂರೈಕೆದಾರರು
ಕಾಂಬೊಗಳು
API ಕೀಗಳು
ಸೆಟ್ಟಿಂಗ್ಗಳು
ವಿಶ್ಲೇಷಣೆ
ವೆಚ್ಚಗಳು          ← ಹೊಸದು (ಗುಂಪು B, ಯೋಜನೆ 16)
ಮೇಲ್ವಿಚಾರಣೆ       ← ಮರುಸಂಘಟಿಸಲಾಗಿದೆ (ಗುಂಪು B, ಯೋಜನೆ 16)
...
```

## ವೆಚ್ಚಗಳ ವಿಭಾಗ (ಹೊಸದು, ಹಂತ 1)

ಪಥದ ಪೂರ್ವಪ್ರತ್ಯಯ: `/dashboard/costs/`

| ಐಟಂ            | URL                                  | ವಿವರಣೆ                                                            |
| -------------- | ------------------------------------ | ----------------------------------------------------------------- |
| ಅವಲೋಕನ         | `/dashboard/costs`                   | ಒಟ್ಟುಗೂಡಿಸಿದ ವೆಚ್ಚದ ಡ್ಯಾಶ್ಬೋರ್ಡ್ (ವಿಶ್ಲೇಷಣೆಯಿಂದ ಸ್ಥಳಾಂತರಿಸಲಾಗಿದೆ) |
| ಬೆಲೆ ನಿಗದಿ     | `/dashboard/costs/pricing`           | ಪ್ರತಿ-ಮಾದರಿಯ ಬೆಲೆ ಪಟ್ಟಿ                                           |
| ಬಜೆಟ್          | `/dashboard/costs/budget`            | ಬಜೆಟ್ ಮಿತಿಗಳು + ಎಚ್ಚರಿಕೆಗಳು                                       |
| ಕೋಟಾ ಹಂಚಿಕೆ    | `/dashboard/costs/quota-share`       | ಕೋಟಾ ಹಂಚಿಕೆ ಪೂಲ್ಗಳು + ಬಳಕೆ                                        |
| ಯೋಜನೆ ಕಾನ್ಫಿಗ್ | `/dashboard/costs/quota-share/plans` | ಪ್ರತಿ-ಪೂರೈಕೆದಾರರ ಯೋಜನೆ ಓವರ್ರೈಡ್ಗಳು                                |

**ತಾರ್ಕಿಕ ಕಾರಣ**: ಬೆಲೆ ನಿಗದಿ, ಬಜೆಟ್ ಮತ್ತು ಕೋಟಾ ಹಂಚಿಕೆ ಈ ಮೊದಲು
`ಮೇಲ್ವಿಚಾರಣೆ > ವೆಚ್ಚಗಳ ನಿಯತಾಂಕಗಳು` ಅಡಿಯಲ್ಲಿದ್ದವು. ಅವುಗಳನ್ನು ಮೀಸಲಾದ ಉನ್ನತ ಮಟ್ಟದ ವಿಭಾಗಕ್ಕೆ
ಸ್ಥಳಾಂತರಿಸುವುದರಿಂದ ವೀಕ್ಷಣೀಯತಾ ಪರಿಕರಗಳ ಮೂಲಕ ನ್ಯಾವಿಗೇಟ್ ಮಾಡದೆಯೇ ಅವುಗಳನ್ನು ಸುಲಭವಾಗಿ ಕಂಡುಕೊಳ್ಳಬಹುದು.

## ಮೇಲ್ವಿಚಾರಣೆ ವಿಭಾಗ (ಮರುಸಂಘಟಿಸಲಾಗಿದೆ)

ಮೇಲ್ವಿಚಾರಣೆ ವಿಭಾಗದಲ್ಲಿ ಈಗ **ಮೇಲ್ಭಾಗದಲ್ಲಿ ಚಟುವಟಿಕೆ** ಇದ್ದು, ಅದರ ನಂತರ **3 ಉಪಗುಂಪುಗಳು** ಇವೆ:

```
ಮೇಲ್ವಿಚಾರಣೆ
├── ಚಟುವಟಿಕೆ             ← ಟೈಮ್ಲೈನ್ ಫೀಡ್ (ಉನ್ನತ ಮಟ್ಟದ ಐಟಂ)
├── ಲಾಗ್ಗಳ ಗುಂಪು
│   ├── ಲಾಗ್ಗಳು (ಎಲ್ಲಾ)
│   ├── ಪ್ರಾಕ್ಸಿ ಲಾಗ್ಗಳು
│   └── ಕನ್ಸೋಲ್ ಲಾಗ್ಗಳು
├── ಆಡಿಟ್ ಗುಂಪು
│   ├── ಆಡಿಟ್ ಲಾಗ್
│   ├── MCP ಆಡಿಟ್
│   └── A2A ಆಡಿಟ್
└── ಸಿಸ್ಟಮ್ ಗುಂಪು
    ├── ಆರೋಗ್ಯ
    └── ರನ್ಟೈಮ್
```

### ಹಳೆಯ ರಚನೆಯಿಂದ ಏನು ಬದಲಾಗಿದೆ

| ಮೊದಲು                                                                                        | ನಂತರ                                           |
| -------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| ಚಟುವಟಿಕೆ = ಆಡಿಟ್ ಲಾಗ್ ಅನ್ನು ಪ್ರದರ್ಶಿಸುತ್ತಿದ್ದ ಲಾಗ್ಗಳ ಒಳಗಿನ ಟ್ಯಾಬ್                            | ಚಟುವಟಿಕೆ = ಮೀಸಲಾದ ಫೀಡ್ (`/dashboard/activity`) |
| ಮೇಲ್ವಿಚಾರಣೆಯಲ್ಲಿನ ವೆಚ್ಚಗಳ ನಿಯತಾಂಕಗಳ ಗುಂಪು                                                    | ವೆಚ್ಚಗಳ ವಿಭಾಗಕ್ಕೆ ಸ್ಥಳಾಂತರಿಸಲಾಗಿದೆ             |
| ಸಮತಟ್ಟಾದ ಪಟ್ಟಿ: ಲಾಗ್ಗಳು, ಚಟುವಟಿಕೆ (ಲಾಗ್ಗಳು), ಆಡಿಟ್, ಆರೋಗ್ಯ, ರನ್ಟೈಮ್, ಬೆಲೆ ನಿಗದಿ, ಬಜೆಟ್, ಕೋಟಾ | ರಚನಾತ್ಮಕ 3-ಗುಂಪು + ಮೀಸಲಾದ ವೆಚ್ಚಗಳ ವಿಭಾಗ        |

### ಉನ್ನತ ಮಟ್ಟದ ಕ್ರಿಯೆಗಳ ಅನುಮತಿ ಪಟ್ಟಿ

`src/lib/audit/highLevelActions.ts` ನಲ್ಲಿ ವ್ಯಾಖ್ಯಾನಿಸಲಾಗಿದೆ. ಚಟುವಟಿಕೆ ಫೀಡ್ನಲ್ಲಿ ಯಾವ ಈವೆಂಟ್ಗಳು ಕಾಣಿಸಬೇಕು ಎಂಬುದನ್ನು
ಇದು ನಿಯಂತ್ರಿಸುತ್ತದೆ. ಅನುಮತಿ ಪಟ್ಟಿಯು ಇವುಗಳನ್ನು ಒಳಗೊಂಡಿದೆ:

- ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸುವ/ತೆಗೆದುಹಾಕುವ/ಪರೀಕ್ಷಿಸುವ ಈವೆಂಟ್ಗಳು
- ಕಾಂಬೊ ರಚನೆ/ನವೀಕರಣ/ಅಳಿಸುವಿಕೆ
- API ಕೀ ಜೀವನಚಕ್ರ (ರಚನೆ, ಹಿಂಪಡೆಯುವಿಕೆ, ರೊಟೇಟ್)
- ಬಜೆಟ್ ಮಿತಿಯನ್ನು ತಲುಪಿರುವುದು
- ದೃಢೀಕರಣ ಲಾಗಿನ್/ಲಾಗ್ಔಟ್
- ಕ್ಲೌಡ್ ಏಜೆಂಟ್ ಸೆಷನ್ ರಚನೆ
- MCP ಪರಿಕರ ನೋಂದಣಿ
- ವೆಬ್ಹುಕ್ ರಚನೆ/ಅಳಿಸುವಿಕೆ
- ಕೋಟಾ ಪೂಲ್/ಯೋಜನೆ ಬದಲಾವಣೆಗಳು (`quota.*` ಕ್ರಿಯೆಗಳು, ಗುಂಪು B)
- ಪ್ಲಾಟ್ಫಾರ್ಮ್ ಈವೆಂಟ್ಗಳು (ನವೀಕರಣ, ನಿಯೋಜನೆ)
- ಕೌಶಲ್ಯ ಸ್ಥಾಪನೆ/ತೆಗೆದುಹಾಕುವಿಕೆ

ಈ ಪಟ್ಟಿಯಲ್ಲಿ ಇಲ್ಲದ ಈವೆಂಟ್ಗಳು ಆಡಿಟ್ ಲಾಗ್ನಲ್ಲಿ ಮಾತ್ರ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತವೆ.

### ಹೊಸ ಉನ್ನತ ಮಟ್ಟದ ಕ್ರಿಯೆಯನ್ನು ಸೇರಿಸುವುದು

`src/lib/audit/highLevelActions.ts` ಅನ್ನು ಸಂಪಾದಿಸಿ ಮತ್ತು ಕ್ರಿಯೆಯ ಸ್ಟ್ರಿಂಗ್ ಅನ್ನು
`HIGH_LEVEL_ACTIONS` ಗೆ ಸೇರಿಸಿ. ಇದಕ್ಕೆ PR ಅಗತ್ಯವಿದೆ (ಈ ಪಟ್ಟಿ ಕೋಡ್ ಆಗಿದ್ದು, DB ಮೂಲಕ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾಗುವುದಿಲ್ಲ).
ಅದಕ್ಕೆ ಸಂಬಂಧಿಸಿದ ಐಕಾನ್ ಅನ್ನು `src/lib/audit/activityIcons.ts` ಗೆ ಸೇರಿಸಬಹುದು.

## ಮರುನಿರ್ದೇಶನ: `/dashboard/logs/activity`

ಹಳೆಯ ಪಥ `/dashboard/logs/activity` ಅನ್ನು
`src/app/(dashboard)/dashboard/logs/activity/page.tsx` ನಲ್ಲಿನ `permanentRedirect()` ಮೂಲಕ
`/dashboard/activity` ಗೆ ಶಾಶ್ವತವಾಗಿ ಮರುನಿರ್ದೇಶಿಸಲಾಗುತ್ತದೆ (HTTP 308).

(ಆದರೆ `SIDEBAR_DEFINITIONS` ನಿಂದ ತೆಗೆದುಹಾಕಲಾಗಿದೆ), ಇದರಿಂದ ಹಳೆಯ ID ಅನ್ನು ಉಲ್ಲೇಖಿಸುವ
ಬಳಕೆದಾರರ ಪೂರ್ವನಿಗದಿಗಳು ಮುರಿಯುವುದನ್ನು ತಪ್ಪಿಸಬಹುದು.
