ಹಂಚಿಕೆಯು ಪೂರೈಕೆದಾರರ ಕೋಟಾ ಅಲ್ಲ.

ಯಾವ API ಕೀಲಿಗಳು ಪೂರೈಕೆದಾರರ ಪೂಲ್ ಅನ್ನು ಬಳಸಬಹುದು ಮತ್ತು ಕಠಿಣ, ಮೃದು ಅಥವಾ ಬರ್ಸ್ಟ್ ನೀತಿಗಳು ಹೇಗೆ ಅನ್ವಯಿಸುತ್ತವೆ ಎಂಬುದನ್ನು ಕೋಟಾ ಪೂಲ್ಗಳು ವ್ಯಾಖ್ಯಾನಿಸುತ್ತವೆ. ಪೂರೈಕೆದಾರರ ಕೋಟಾ ಎಂದರೆ ಪೂರೈಕೆದಾರರು ವರದಿ ಮಾಡಿದ ಬಾಹ್ಯ ಸಾಮರ್ಥ್ಯ ಅಥವಾ ಸ್ಪಷ್ಟವಾಗಿ ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ಮೂಲ. Ghostlight ಆಂತರಿಕ ಬಜೆಟ್ಗಳು ನಿರ್ವಾಹಕರು ವ್ಯಾಖ್ಯಾನಿಸಿದ ಆಡಳಿತ ಮಿತಿಗಳಾಗಿವೆ.

`ensurePool` ಕಾರ್ಯಾಚರಣೆಯು ಐಡೆಂಪೋಟೆಂಟ್ ಆಗಿದೆ: ಒಂದೇ ರೀತಿಯ ಪೂಲ್ ಬದಲಾಗದೆ ಉಳಿಯುತ್ತದೆ, ಬದಲಾದ ಹಂಚಿಕೆಯನ್ನು ನವೀಕರಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಅಸ್ತಿತ್ವದಲ್ಲಿಲ್ಲದ ಪೂಲ್ ಅನ್ನು ರಚಿಸಲಾಗುತ್ತದೆ. ಇದು ಸ್ವಯಂಚಾಲನೆ ಮತ್ತು ಮಿತಿಗೊಳಿಸಿದ API ಕರೆಗಾರರಿಗಾಗಿ ಉದ್ದೇಶಿಸಲಾಗಿದೆ.

ಓದಲು-ಮಾತ್ರವಾದ ಸ್ಥಿತಿ ಎಂಡ್ಪಾಯಿಂಟ್ `GET /api/omniroute/status` ಆಗಿದೆ. ಪರಿಶೀಲನಾ ಕಮಾಂಡ್ `npm run omniroute:verify` ಆಗಿದೆ; ಇದು ಯಾವುದೇ ಲೈವ್ ಮಾದರಿ ವಿನಂತಿಯನ್ನು ಮಾಡುವುದಿಲ್ಲ.
