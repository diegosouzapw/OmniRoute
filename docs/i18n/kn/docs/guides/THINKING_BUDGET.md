> **ಡ್ಯಾಶ್ಬೋರ್ಡ್:** ಸೆಟ್ಟಿಂಗ್ಗಳು → **AI** → ಚಿಂತನಾ ಬಜೆಟ್  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **ಮೂಲ:** `open-sse/services/thinkingBudget.ts`

ಪೂರೈಕೆದಾರರ ಬಳಿಗೆ ಸಾಗುವಾಗ OmniRoute **ಕ್ಲೈಂಟ್ನ ಚಿಂತನೆ/ತಾರ್ಕಿಕತೆಯ ಪ್ಯಾರಾಮೀಟರ್ಗಳನ್ನು ಮರುಬರೆಯಬೇಕೇ** ಎಂಬುದನ್ನು ಚಿಂತನಾ ಬಜೆಟ್ ನಿಯಂತ್ರಿಸುತ್ತದೆ. ಇದು ಸಂಕುಚನ, ರೂಟಿಂಗ್ ಅಥವಾ ಪ್ರಾಂಪ್ಟ್ ಕ್ಯಾಶ್ ಅನ್ನು ಆನ್ ಅಥವಾ ಆಫ್ ಮಾಡುವುದಿಲ್ಲ.

## ಮೋಡ್ಗಳು

| ಮೋಡ್                         | OmniRoute ಏನು ಮಾಡುತ್ತದೆ                                                                                                        | ಯಾವಾಗ ಬಳಸಬೇಕು                                                                                                                                                                         |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (ಡೀಫಾಲ್ಟ್) | ಕ್ಲೈಂಟ್ ಫೀಲ್ಡ್ಗಳನ್ನು ಹಾಗೆಯೇ ಬಿಡುತ್ತದೆ (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config`, ಇತ್ಯಾದಿ). | **Codex / Desktop / ಶ್ರಮ + ತಾರ್ಕಿಕತೆಯ ಸಾರಾಂಶಗಳನ್ನು ನಿಯಂತ್ರಿಸಬೇಕಾದ ಯಾವುದೇ ಕ್ಲೈಂಟ್.** ಕ್ಲೈಂಟ್ `reasoning.summary` ಅನ್ನು ವಿನಂತಿಸಿದಾಗ ಗೋಚರಿಸುವ ಚಿಂತನಾ ಪ್ಯಾನೆಲ್ಗಳಿಗೆ ಇದು ಅಗತ್ಯ.            |
| **`auto`**                   | ಅಪ್ಸ್ಟ್ರೀಮ್ಗೆ ಕಳುಹಿಸುವ ಮೊದಲು ವಿನಂತಿಯ ಬಾಡಿಯಿಂದ ಎಲ್ಲಾ ಚಿಂತನೆ/ತಾರ್ಕಿಕತೆಯ ಫೀಲ್ಡ್ಗಳನ್ನು **ತೆಗೆದುಹಾಕುತ್ತದೆ**.                        | **ಪೂರೈಕೆದಾರನೇ** ಡೀಫಾಲ್ಟ್ಗಳನ್ನು ರೂಪಿಸಬೇಕೆಂದು ನೀವು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಬಯಸಿದಾಗ ಮತ್ತು ಕ್ಲೈಂಟ್-ನಿಯಂತ್ರಿತ ಚಿಂತನೆ ಅಗತ್ಯವಿಲ್ಲದಿದ್ದಾಗ ಮಾತ್ರ. ಇದು “ಚಿಂತನೆಯನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ತೋರಿಸು” ಎಂದರ್ಥವಲ್ಲ. |
| **`custom`**                 | ಪ್ರತಿ ವಿನಂತಿಯನ್ನೂ ಸ್ಥಿರ ಚಿಂತನಾ ಟೋಕನ್ ಬಜೆಟ್ನೊಂದಿಗೆ ಓವರ್ರೈಟ್ ಮಾಡುತ್ತದೆ.                                                          | ಎಲ್ಲಾ ಟ್ರಾಫಿಕ್ನ ಚಿಂತನಾ ಟೋಕನ್ಗಳಿಗೆ ಕಠಿಣ ಮಿತಿ.                                                                                                                                          |
| **`adaptive`**               | ಸಂದೇಶಗಳ ಸಂಖ್ಯೆ, ಟೂಲ್ಗಳು ಮತ್ತು ಪ್ರಾಂಪ್ಟ್ನ ಉದ್ದವನ್ನು ಆಧರಿಸಿ ಮೂಲ ಶ್ರಮದಿಂದ ಬಜೆಟ್ ಅನ್ನು ಸ್ಕೇಲ್ ಮಾಡುತ್ತದೆ.                           | ಕ್ಲೈಂಟ್ನ ಉದ್ದೇಶವನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ತೆಗೆದುಹಾಕದೆ ಮೃದುವಾದ ಟೋಕನ್ ನಿಯಂತ್ರಣ.                                                                                                                  |

### `auto` ಏನನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ

ಮೋಡ್ `auto` ಆಗಿರುವಾಗ, `stripThinkingConfig()` ಇವುಗಳನ್ನು (ಇತರವುಗಳ ಜೊತೆಗೆ) ಅಳಿಸುತ್ತದೆ:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, ಮತ್ತು ಇದ್ದಲ್ಲಿ `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

ಯಾವುದಾದರೂ ಕ್ಲೈಂಟ್ (ಉದಾ. Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` ಅನ್ನು ಕಳುಹಿಸಿದ್ದರೆ, **auto ಆ ಆಬ್ಜೆಕ್ಟ್ ಅನ್ನು ಕೈಬಿಡುತ್ತದೆ**. ಅಪ್ಸ್ಟ್ರೀಮ್ ಇನ್ನೂ ಕೆಲವು ತಾರ್ಕಿಕತೆಯ ಟೋಕನ್ಗಳಿಗೆ ಶುಲ್ಕ ವಿಧಿಸಬಹುದು, ಆದರೆ ಅನೇಕ ಬಾರಿ **ಖಾಲಿ ಅಥವಾ ಎನ್ಕ್ರಿಪ್ಟ್ ಮಾಡಿದವು ಮಾತ್ರ** ಇರುವ ತಾರ್ಕಿಕತೆಯ ಐಟಂಗಳನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ — ಆದ್ದರಿಂದ UI ಯಾವುದೇ ಉಪಯುಕ್ತ ಚಿಂತನಾ ಸ್ಟ್ರೀಮ್ ಅನ್ನು ತೋರಿಸುವುದಿಲ್ಲ.

## ಇದು **ಏನಲ್ಲ**

| ವೈಶಿಷ್ಟ್ಯ                                         | ಸಂಬಂಧ                                                                                                                                                |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ಸಂಕುಚನ** (Caveman, RTK, stacked, …)             | ಪ್ರತ್ಯೇಕ ಪೈಪ್ಲೈನ್. ಪ್ರತಿ ಚಿಂತನಾ-ಬಜೆಟ್ ಮೋಡ್ನ ಅಡಿಯಲ್ಲೂ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.                                                                            |
| **ಪ್ರಾಂಪ್ಟ್ / ಸೆಮ್ಯಾಂಟಿಕ್ ಕ್ಯಾಶ್**                | ಪ್ರತ್ಯೇಕ. ಚಿಂತನಾ-ಬಜೆಟ್ ಮೋಡ್ನಿಂದ ಯಾವುದೇ ಪರಿಣಾಮವಿಲ್ಲ.                                                                                                  |
| **ಕಾಂಬೊ ರೂಟಿಂಗ್ / ಫಾಲ್ಬ್ಯಾಕ್ಗಳು**                 | ಪ್ರತ್ಯೇಕ. ಯಾವುದೇ ಪರಿಣಾಮವಿಲ್ಲ.                                                                                                                        |
| **API-ಕೀ ಟೋಕನ್ ಮಿತಿಗಳು / ವೆಚ್ಚದ ಬಜೆಟ್ಗಳು**        | ಪ್ರತ್ಯೇಕ. ಯಾವುದೇ ಪರಿಣಾಮವಿಲ್ಲ.                                                                                                                        |
| **ತಾರ್ಕಿಕತೆ ರೀಪ್ಲೇ ಕ್ಯಾಶ್**                       | ಕಟ್ಟುನಿಟ್ಟಿನ ಪೂರೈಕೆದಾರರಿಗಾಗಿ ಬಹು-ಟರ್ನ್ ಮರು-ಸೇರಿಸುವಿಕೆ (DeepSeek, Kimi, Qwen-thinking, …). Desktopನ “ಚಿಂತನೆಯನ್ನು ತೋರಿಸು” ಎಂಬುದಕ್ಕೆ ಸಮಾನವಲ್ಲ.          |
| **`encrypted_content` ಅನ್ನು ಡೀಕ್ರಿಪ್ಟ್ ಮಾಡುವುದು** | **ಅಸಾಧ್ಯ.** OpenAI/Codex ಖಾಸಗಿ ತಾರ್ಕಿಕತೆಯ ಬ್ಲಾಬ್ಗಳು ಅಪಾರದರ್ಶಕವಾಗಿರುತ್ತವೆ. OmniRoute ಅವುಗಳನ್ನು ಎಂದಿಗೂ ಡೀಕ್ರಿಪ್ಟ್ ಮಾಡುವುದಿಲ್ಲ (#7095 / #7176 / #7304). |

## ಗೋಚರಿಸುವ ಚಿಂತನೆ (Codex / Responses ಕ್ಲೈಂಟ್ಗಳು)

ಕ್ಲೈಂಟ್ ಚಿಂತನೆಯ ಪಠ್ಯವನ್ನು ತೋರಿಸಲು ನಿಮಗೆ ಈ **ಎಲ್ಲವೂ** ಅಗತ್ಯ:

1. Thinking Budget ಮೋಡ್ = **`passthrough`** (ಅಥವಾ ನೀವು ಬಳಸುವ ಮಾರ್ಗಕ್ಕೆ ಸಾರಾಂಶ ವಿನಂತಿಗಳನ್ನು ಸಾಕಷ್ಟು ಅಚಲವಾಗಿ ಉಳಿಸುವ custom/adaptive).
2. ಕ್ಲೈಂಟ್ ಸಾರಾಂಶವನ್ನು ಕೇಳುತ್ತದೆ, ಉದಾ. Codex `model_reasoning_summary = "detailed"` / `auto` (`none` ಅಲ್ಲ).
3. ಅಪ್ಸ್ಟ್ರೀಮ್ ನಿಜವಾಗಿಯೂ `response.reasoning_summary_text.*` ಅನ್ನು ಸ್ಟ್ರೀಮ್ ಮಾಡುತ್ತದೆ (ಅಥವಾ ಐಟಂನಲ್ಲಿ ಖಾಲಿಯಲ್ಲದ `reasoning.summary` ಇರುತ್ತದೆ).

ನಿಮಗೆ “ಎನ್ಕ್ರಿಪ್ಟ್ ಮಾಡಿದ ಖಾಸಗಿ ತಾರ್ಕಿಕತೆ” ಮಾತ್ರ ದೊರೆತರೆ, ಇದರಲ್ಲಿ ಯಾವುದಾದರೂ ಕಾರಣವಾಗಿರಬಹುದು:

- ಮೋಡ್ **`auto`** ಆಗಿತ್ತು (ಕ್ಲೈಂಟ್ ವಿನಂತಿಯನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ), ಅಥವಾ
- ಅಪ್ಸ್ಟ್ರೀಮ್ ಸಾರಾಂಶ ಪಠ್ಯವಿಲ್ಲದೆ `encrypted_content` ಅನ್ನು ಹಿಂದಿರುಗಿಸಿದೆ (ಪೂರೈಕೆದಾರರ ಮಿತಿ; OmniRoute ಪ್ಲೇಸ್ಹೋಲ್ಡರ್ ಅನ್ನು ಮಾತ್ರ ತೋರಿಸಬಲ್ಲದು, ಸರಳ ಪಠ್ಯವನ್ನಲ್ಲ).

## API ಉದಾಹರಣೆಗಳು

```bash
# ಓದಿ
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Codex / Desktop ಚಿಂತನೆಯ ಗೋಚರತೆಗಾಗಿ ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

ಸ್ಕೀಮಾ (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; ಐಚ್ಛಿಕ `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### ಸ್ಥಿರತೆ / ಮರುಪ್ರಾರಂಭ

ಮೌಲ್ಯವನ್ನು `thinkingBudget` ಸೆಟ್ಟಿಂಗ್ಗಳ ಕೀ ಅಡಿಯಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಪ್ರಕ್ರಿಯೆ ಪ್ರಾರಂಭವಾಗುವಾಗ (`hydrateThinkingBudgetConfig`) ಹೈಡ್ರೇಟ್ ಮಾಡಲಾಗುತ್ತದೆ. DB ಅಥವಾ ಕೆಲವು API-ಅಲ್ಲದ ಮಾರ್ಗಗಳ ಮೂಲಕ ಬದಲಾಯಿಸಿದ ನಂತರ, ಇನ್-ಮೆಮೊರಿ ಸಿಂಗಲ್ಟನ್ ಡಿಸ್ಕ್ನಲ್ಲಿರುವುದಕ್ಕೆ ಹೊಂದಿಕೆಯಾಗುವಂತೆ **OmniRoute ಪ್ರಕ್ರಿಯೆಯನ್ನು ಮರುಪ್ರಾರಂಭಿಸಿ**.
