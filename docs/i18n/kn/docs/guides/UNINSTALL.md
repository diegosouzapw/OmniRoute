## ತ್ವರಿತ ಅಸ್ಥಾಪನೆ ರದ್ದತಿ (v3.6.2+)

ಸ್ವಚ್ಛವಾಗಿ ತೆಗೆದುಹಾಕಲು OmniRoute ಎರಡು ಅಂತರ್ನಿರ್ಮಿತ ಸ್ಕ್ರಿಪ್ಟ್ಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ:

### ನಿಮ್ಮ ಡೇಟಾವನ್ನು ಉಳಿಸಿಕೊಳ್ಳಿ

```bash
npm run uninstall
```

ಇದು OmniRoute ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ, ಆದರೆ `~/.omniroute/` ನಲ್ಲಿರುವ ನಿಮ್ಮ ಡೇಟಾಬೇಸ್, ಸಂರಚನೆಗಳು, API ಕೀಗಳು ಮತ್ತು ಪೂರೈಕೆದಾರರ ಸೆಟ್ಟಿಂಗ್ಗಳನ್ನು **ಉಳಿಸುತ್ತದೆ**. ನೀವು ನಂತರ ಮರುಸ್ಥಾಪಿಸಲು ಯೋಜಿಸುತ್ತಿದ್ದರೆ ಮತ್ತು ನಿಮ್ಮ ಸೆಟಪ್ ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳಲು ಬಯಸಿದರೆ ಇದನ್ನು ಬಳಸಿ.

### ಸಂಪೂರ್ಣ ತೆಗೆದುಹಾಕುವಿಕೆ

```bash
npm run uninstall:full
```

ಇದು ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ತೆಗೆದುಹಾಕುವುದರ ಜೊತೆಗೆ ಎಲ್ಲಾ ಡೇಟಾವನ್ನು **ಶಾಶ್ವತವಾಗಿ ಅಳಿಸುತ್ತದೆ**:

- ಡೇಟಾಬೇಸ್ (`storage.sqlite`)
- ಪೂರೈಕೆದಾರರ ಸಂರಚನೆಗಳು ಮತ್ತು API ಕೀಗಳು
- ಬ್ಯಾಕಪ್ ಫೈಲ್ಗಳು
- ಲಾಗ್ ಫೈಲ್ಗಳು
- `~/.omniroute/` ಡೈರೆಕ್ಟರಿಯಲ್ಲಿರುವ ಎಲ್ಲಾ ಫೈಲ್ಗಳು

> ⚠️ **ಎಚ್ಚರಿಕೆ:** `npm run uninstall:full` ಕ್ರಿಯೆಯನ್ನು ಹಿಂತಿರುಗಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ. ನಿಮ್ಮ ಎಲ್ಲಾ ಪೂರೈಕೆದಾರರ ಸಂಪರ್ಕಗಳು, ಕಾಂಬೊಗಳು, API ಕೀಗಳು ಮತ್ತು ಬಳಕೆಯ ಇತಿಹಾಸವನ್ನು ಶಾಶ್ವತವಾಗಿ ಅಳಿಸಲಾಗುತ್ತದೆ.

## ಕೈಯಾರೆ ಅನ್ಇನ್ಸ್ಟಾಲ್ ಮಾಡುವುದು

### NPM ಜಾಗತಿಕ ಸ್ಥಾಪನೆ

```bash
# ಜಾಗತಿಕ ಪ್ಯಾಕೇಜ್ ಅನ್ನು ತೆಗೆದುಹಾಕಿ
npm uninstall -g omniroute

# (ಐಚ್ಛಿಕ) ಡೇಟಾ ಡೈರೆಕ್ಟರಿಯನ್ನು ತೆಗೆದುಹಾಕಿ
rm -rf ~/.omniroute
```

### pnpm ಜಾಗತಿಕ ಸ್ಥಾಪನೆ

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# ಕಂಟೇನರ್ ಅನ್ನು ನಿಲ್ಲಿಸಿ ಮತ್ತು ತೆಗೆದುಹಾಕಿ
docker stop omniroute
docker rm omniroute

# ವಾಲ್ಯೂಮ್ ಅನ್ನು ತೆಗೆದುಹಾಕಿ (ಎಲ್ಲಾ ಡೇಟಾವನ್ನು ಅಳಿಸುತ್ತದೆ)
docker volume rm omniroute-data

# (ಐಚ್ಛಿಕ) ಇಮೇಜ್ ಅನ್ನು ತೆಗೆದುಹಾಕಿ
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# ಕಂಟೇನರ್ಗಳನ್ನು ನಿಲ್ಲಿಸಿ ಮತ್ತು ತೆಗೆದುಹಾಕಿ
docker compose down

# ವಾಲ್ಯೂಮ್ಗಳನ್ನೂ ತೆಗೆದುಹಾಕಿ (ಎಲ್ಲಾ ಡೇಟಾವನ್ನು ಅಳಿಸುತ್ತದೆ)
docker compose down -v
```

### Electron ಡೆಸ್ಕ್ಟಾಪ್ ಆ್ಯಪ್

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` ತೆರೆಯಿರಿ
- ಅಥವಾ ಸ್ಥಾಪನಾ ಡೈರೆಕ್ಟರಿಯಿಂದ NSIS ಅನ್ಇನ್ಸ್ಟಾಲರ್ ಅನ್ನು ಚಲಾಯಿಸಿ

**macOS:**

- `/Applications` ನಿಂದ `OmniRoute.app` ಅನ್ನು ಕಸದ ಬುಟ್ಟಿಗೆ ಎಳೆಯಿರಿ
- ಡೇಟಾವನ್ನು ತೆಗೆದುಹಾಕಿ: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage ಫೈಲ್ ಅನ್ನು ತೆಗೆದುಹಾಕಿ
- ಡೇಟಾವನ್ನು ತೆಗೆದುಹಾಕಿ: `rm -rf ~/.omniroute`

### ಮೂಲದಿಂದ ಸ್ಥಾಪನೆ (git clone)

```bash
# ಕ್ಲೋನ್ ಮಾಡಿದ ಡೈರೆಕ್ಟರಿಯನ್ನು ತೆಗೆದುಹಾಕಿ
rm -rf /path/to/omniroute

# (ಐಚ್ಛಿಕ) ಡೇಟಾ ಡೈರೆಕ್ಟರಿಯನ್ನು ತೆಗೆದುಹಾಕಿ
rm -rf ~/.omniroute
```

## ಡೇಟಾ ಡೈರೆಕ್ಟರಿಗಳು

OmniRoute ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಈ ಕೆಳಗಿನ ಸ್ಥಳಗಳಲ್ಲಿ ಡೇಟಾವನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ:

| ಪ್ಲಾಟ್ಫಾರ್ಮ್ | ಪೂರ್ವನಿಯೋಜಿತ ಪಥ                     | ಅತಿಕ್ರಮಣ                   |
| ------------ | ----------------------------------- | -------------------------- |
| Linux        | `~/.omniroute/`                     | `DATA_DIR` ಪರಿಸರ ಚರ        |
| macOS        | `~/.omniroute/`                     | `DATA_DIR` ಪರಿಸರ ಚರ        |
| Windows      | `%APPDATA%/omniroute/`              | `DATA_DIR` ಪರಿಸರ ಚರ        |
| Docker       | `/app/data/` (ಮೌಂಟ್ ಮಾಡಿದ ವಾಲ್ಯೂಮ್) | `DATA_DIR` ಪರಿಸರ ಚರ        |
| XDG-ಅನುಸರಣೆ  | `$XDG_CONFIG_HOME/omniroute/`       | `XDG_CONFIG_HOME` ಪರಿಸರ ಚರ |

### ಡೇಟಾ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿರುವ ಫೈಲ್ಗಳು

| ಫೈಲ್/ಡೈರೆಕ್ಟರಿ       | ವಿವರಣೆ                                                        |
| -------------------- | ------------------------------------------------------------- |
| `storage.sqlite`     | ಮುಖ್ಯ ಡೇಟಾಬೇಸ್ (ಪೂರೈಕೆದಾರರು, ಸಂಯೋಜನೆಗಳು, ಸೆಟ್ಟಿಂಗ್ಗಳು, ಕೀಗಳು) |
| `storage.sqlite-wal` | SQLite ರೈಟ್-ಅಹೆಡ್ ಲಾಗ್ (ತಾತ್ಕಾಲಿಕ)                            |
| `storage.sqlite-shm` | SQLite ಹಂಚಿಕೆಯ ಮೆಮೊರಿ (ತಾತ್ಕಾಲಿಕ)                             |
| `call_logs/`         | ವಿನಂತಿಯ ಪೇಲೋಡ್ ಆರ್ಕೈವ್ಗಳು                                     |
| `backups/`           | ಸ್ವಯಂಚಾಲಿತ ಡೇಟಾಬೇಸ್ ಬ್ಯಾಕಪ್ಗಳು                                |
| `log.txt`            | ಹಳೆಯ ವಿನಂತಿ ಲಾಗ್ (ಐಚ್ಛಿಕ)                                     |

## ಸಂಪೂರ್ಣ ತೆಗೆದುಹಾಕಿರುವುದನ್ನು ಪರಿಶೀಲಿಸಿ

ಅನ್ಇನ್ಸ್ಟಾಲ್ ಮಾಡಿದ ನಂತರ, ಯಾವುದೇ ಫೈಲ್ಗಳು ಉಳಿದಿಲ್ಲವೆಂದು ಪರಿಶೀಲಿಸಿ:

```bash
# ಜಾಗತಿಕ npm ಪ್ಯಾಕೇಜ್ಗಾಗಿ ಪರಿಶೀಲಿಸಿ
npm list -g omniroute 2>/dev/null

# ಡೇಟಾ ಡೈರೆಕ್ಟರಿಗಾಗಿ ಪರಿಶೀಲಿಸಿ
ls -la ~/.omniroute/ 2>/dev/null
```
