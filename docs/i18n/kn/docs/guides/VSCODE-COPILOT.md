ಮಾದರಿ ಆಯ್ಕೆಗಾರದಲ್ಲಿ ಇರಿಸುತ್ತದೆ. ಎರಡನೇ ಸೈಡ್ಬಾರ್ ಇಲ್ಲ, ಪ್ರತ್ಯೇಕ ಚಾಟ್ UI ಇಲ್ಲ — Copilotನ ಏಜೆಂಟ್ ಮೋಡ್, ಟೂಲ್ ಕಾಲಿಂಗ್,
MCP ಸರ್ವರ್ಗಳು ಮತ್ತು ಕಸ್ಟಮ್ ಸೂಚನೆಗಳು ಎಲ್ಲವೂ ಎಂದಿನಂತೆಯೇ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ, ಆದರೆ ನೀವು ಆಯ್ಕೆಮಾಡಿದ ಮಾದರಿಯಲ್ಲಿ ಚಲಿಸುತ್ತವೆ.

## ಸೆಟಪ್

1. **OmniRoute ಚಲಾಯಿಸಿ** — `npm install -g omniroute && omniroute` (`http://localhost:20128` ನಲ್ಲಿ ಡ್ಯಾಶ್ಬೋರ್ಡ್).
2. **ಎಕ್ಸ್ಟೆನ್ಶನ್ ಸ್ಥಾಪಿಸಿ** — Extensions ವೀಕ್ಷಣೆಯಲ್ಲಿ "OmniRoute" ಎಂದು ಹುಡುಕಿ.
3. **ಮಾದರಿಯನ್ನು ಆಯ್ಕೆಮಾಡಿ** — Copilot Chat → ಮಾದರಿ ಆಯ್ಕೆಗಾರ → **ಮಾದರಿಗಳನ್ನು ನಿರ್ವಹಿಸಿ…** → **OmniRoute**, ನಂತರ
   ನಿಮಗೆ ಬೇಕಾದವುಗಳಿಗೆ ಗುರುತು ಹಾಕಿ.

OmniRoute ಡೀಫಾಲ್ಟ್ ಪೋರ್ಟ್ನಲ್ಲಿ ಚಲಿಸುವಾಗ ಏನನ್ನೂ ಕಾನ್ಫಿಗರ್ ಮಾಡುವ ಅಗತ್ಯವಿಲ್ಲ. ರಿಮೋಟ್ ಇನ್ಸ್ಟಾನ್ಸ್ಗಾಗಿ,
**Activity Barನಲ್ಲಿರುವ OmniRoute ಐಕಾನ್** ತೆರೆಯಿರಿ (ಅಥವಾ `OmniRoute: Manage Connection` ಚಲಾಯಿಸಿ) ಮತ್ತು ಇವುಗಳನ್ನು ಹೊಂದಿಸಿ:

- **ಸರ್ವರ್ URL** — ಸರ್ವರ್ ರೂಟ್, ಉದಾ. `http://192.168.0.15:20128`. `/v1` ಪ್ರತ್ಯಯವನ್ನು
  ಎಕ್ಸ್ಟೆನ್ಶನ್ ಸೇರಿಸುತ್ತದೆ; ಅದನ್ನು ಸೇರಿಸಬೇಡಿ.
- **API ಕೀ** — ಸರ್ವರ್ `REQUIRE_API_KEY` ಹೊಂದಿಸಿದಾಗ ಮಾತ್ರ. VS
  Code SecretStorage ಮೂಲಕ OS ಕೀಚೈನ್ನಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ, `settings.json` ನಲ್ಲಿ ಎಂದಿಗೂ ಅಲ್ಲ.

## ಆಯ್ಕೆಗಾರವು ಏನನ್ನು ತೋರಿಸುತ್ತದೆ

ಎಕ್ಸ್ಟೆನ್ಶನ್ ಕಚ್ಚಾ `GET /v1/models` ಪೇಲೋಡ್ ಅನ್ನು ತೋರಿಸುವುದಿಲ್ಲ — ಅದು ಅದನ್ನು ಅಗತ್ಯ ರೂಪಕ್ಕೆ ತರುತ್ತದೆ ಮತ್ತು ನೀವು
ನೋಡುವ ಎಣಿಕೆಯು ಎರಡು ಉದ್ದೇಶಪೂರ್ವಕ ಕಾರಣಗಳಿಂದ ಕ್ಯಾಟಲಾಗ್ ಗಾತ್ರಕ್ಕಿಂತ ಕಡಿಮೆಯಾಗಿರುತ್ತದೆ.

### ಇದು ಪ್ರತಿ ಮಾದರಿಗೆ ಒಂದು id ಅನ್ನು ಕೇಳುತ್ತದೆ

`MODELS_CATALOG_PREFIX_MODE` ಡೀಫಾಲ್ಟ್ ಆಗಿ **`dual`** ಆಗಿರುತ್ತದೆ, ಇದು ಪ್ರತಿಯೊಂದು ಮಾದರಿಯನ್ನೂ ಎರಡು ಬಾರಿ ಪ್ರಕಟಿಸುತ್ತದೆ — ಒಮ್ಮೆ
ಸಂಕ್ಷಿಪ್ತ ಅಲಿಯಾಸ್ ಪೂರ್ವಪ್ರತ್ಯಯದ ಅಡಿಯಲ್ಲಿ ಮತ್ತು ಮತ್ತೊಮ್ಮೆ ಕ್ಯಾನಾನಿಕಲ್ ಪೂರೈಕೆದಾರ ಪೂರ್ವಪ್ರತ್ಯಯದ ಅಡಿಯಲ್ಲಿ — ಹೀಗಾಗಿ ಹಳೆಯ ಕ್ಲೈಂಟ್
ಕಾನ್ಫಿಗ್ಗಳು ಎರಡೂ ರೂಪಗಳನ್ನು ಪರಿಹರಿಸುವುದನ್ನು ಮುಂದುವರಿಸುತ್ತವೆ:

```
cc/claude-sonnet-4-6        ← ಅಲಿಯಾಸ್ ಪೂರ್ವಪ್ರತ್ಯಯ
claude/claude-sonnet-4-6    ← ಕ್ಯಾನಾನಿಕಲ್ ಪೂರ್ವಪ್ರತ್ಯಯ, ಅದೇ ಮಾದರಿ
```

ಎಕ್ಸ್ಟೆನ್ಶನ್ **`GET /v1/models?prefix=alias`** ಅನ್ನು ವಿನಂತಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ನಿಮ್ಮ ಇತರ ಕ್ಲೈಂಟ್ಗಳಿಗಾಗಿ
ಸರ್ವರ್-ವ್ಯಾಪಿ ಸೆಟ್ಟಿಂಗ್ ಬದಲಾಯಿಸದೆಯೇ ಪ್ರತಿ ಮಾದರಿಗೆ ಒಂದು id ಬರುತ್ತದೆ. ಉಲ್ಲೇಖ ಇನ್ಸ್ಟಾನ್ಸ್ನಲ್ಲಿ ಇದು
**2345 ನಮೂದುಗಳನ್ನು 1396ಕ್ಕೆ ಇಳಿಸಿತು — 949 ನಕಲುಗಳು, ಕಳೆದುಹೋದ ಮಾದರಿಗಳು ಶೂನ್ಯ.**

ನೀವು ಇದನ್ನು _ಪ್ರತಿಯೊಂದು_ ಕ್ಲೈಂಟ್ಗಾಗಿ ಸರ್ವರ್-ವ್ಯಾಪಿಯಾಗಿ ಸರಿಪಡಿಸಲು ಬಯಸಿದರೆ, ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ
`MODELS_CATALOG_PREFIX_MODE` ವೈಶಿಷ್ಟ್ಯ ಫ್ಲ್ಯಾಗ್ ಅನ್ನು `alias` ಗೆ ಹೊಂದಿಸಿ. ಕ್ವೆರಿ ಪ್ಯಾರಾಮೀಟರ್ ಮತ್ತು
ಪ್ರತಿ-ಮೋಡ್ ಟೇಬಲ್ಗಾಗಿ [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) ನೋಡಿ.

### ಚಾಟ್ ಮಾಡಲು ಸಾಧ್ಯವಿಲ್ಲದ ಮಾದರಿಗಳನ್ನು ಇದು ಮರೆಮಾಡುತ್ತದೆ

ಕ್ಯಾಟಲಾಗ್ ಚಿತ್ರ, ವೀಡಿಯೊ, ಆಡಿಯೊ, ರೀರ್ಯಾಂಕ್, ಎಂಬೆಡಿಂಗ್ ಮತ್ತು ಮಾಡರೇಷನ್ ಮಾದರಿಗಳನ್ನೂ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ. ಅವುಗಳನ್ನು
ಚಾಟ್ ವಿನಂತಿಯಲ್ಲಿ ಹೇಗಾದರೂ ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ:

```
HTTP 400 — ಮಾದರಿ '<id>' ಚಿತ್ರ-ರಚನಾ ಮಾದರಿಯಾಗಿದ್ದು, ಇದರಲ್ಲಿ ಬಳಸಲಾಗುವುದಿಲ್ಲ
/v1/chat/completions. ಬದಲಿಗೆ POST /v1/images/generations ಬಳಸಿ.
```

ಆದ್ದರಿಂದ ಆಯ್ಕೆಗಾರವನ್ನು ತಲುಪುವ ಮೊದಲು ಅವುಗಳ `type` ಫೀಲ್ಡ್ ಆಧರಿಸಿ ಅವುಗಳನ್ನು ಫಿಲ್ಟರ್ ಮಾಡಲಾಗುತ್ತದೆ. **Responses-API
ಮಾದರಿಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳಲಾಗುತ್ತದೆ** — ಪ್ರತಿಯೊಂದು Codex / GPT-5.x ನಮೂದು `supported_endpoints: ["responses"]` ಅನ್ನು ಪ್ರಕಟಿಸುತ್ತದೆ,
ಮತ್ತು OmniRoute ಅವುಗಳನ್ನು `/v1/chat/completions` ಗಾಗಿ ಅನುವಾದಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಅವುಗಳನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಬಳಸಬಹುದು.

### ನೀವು ಎಂದಿಗೂ ಕಾನ್ಫಿಗರ್ ಮಾಡದ ಪೂರೈಕೆದಾರರು

ಕ್ಯಾಟಲಾಗ್ **ಸಕ್ರಿಯ ಸಂಪರ್ಕ** ಹೊಂದಿರುವ ಪೂರೈಕೆದಾರರ ಮಾದರಿಗಳ ಜೊತೆಗೆ ಪ್ರತಿಯೊಂದು **noAuth**
ಪೂರೈಕೆದಾರವನ್ನೂ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ — ಉಚಿತ ಹಂತದ ಬಹುಭಾಗವನ್ನು ರೂಪಿಸುವ ಕೀ ಅಗತ್ಯವಿಲ್ಲದ ಪೂರೈಕೆದಾರರು. ಇದು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿದೆ. ಅವುಗಳನ್ನು ಮರೆಮಾಡಲು,
ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಸೆಟ್ಟಿಂಗ್ಗಳಲ್ಲಿರುವ `blockedProviders` ಗೆ ಅವುಗಳನ್ನು ಸೇರಿಸಿ; ಎಕ್ಸ್ಟೆನ್ಶನ್ನಲ್ಲಿ ಏನೂ ಬದಲಾಗುವುದಿಲ್ಲ.

## VS Code ಟ್ಯಾಬ್ನೊಳಗಿನ ಡ್ಯಾಶ್ಬೋರ್ಡ್

`omnicopilot.dashboardOpen: "editor"` ಬಾಹ್ಯ ಬ್ರೌಸರ್ನ ಬದಲಿಗೆ Simple Browser ಮೂಲಕ OmniRoute ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಅನ್ನು ಎಡಿಟರ್ ಟ್ಯಾಬ್ನಲ್ಲಿ ಪ್ರದರ್ಶಿಸುತ್ತದೆ. ಎಂಬೆಡ್ ಮಾಡುವುದನ್ನು ಸರ್ವರ್ನಲ್ಲಿ **ಆಯ್ಕೆ ಮಾಡಿಕೊಂಡು ಸಕ್ರಿಯಗೊಳಿಸಬೇಕು**; ಇದಕ್ಕಾಗಿ `DASHBOARD_ALLOW_EMBED=vscode` ಬಳಸಲಾಗುತ್ತದೆ. ಇದು ಡೀಫಾಲ್ಟ್ `frame-ancestors 'none'` +
`X-Frame-Options: DENY` ಬದಲಿಗೆ `frame-ancestors 'self' vscode-webview:` ಜೊತೆಗೆ HTML ಪುಟಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ. ಯಾವುದೇ ಸಂದರ್ಭದಲ್ಲಿಯೂ API ಮೇಲ್ಮೈ (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) ಕಟ್ಟುನಿಟ್ಟಾದ ಹೆಡರ್ಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ.

> ⚠️ **ಇದು ಬಿಲ್ಡ್-ಟೈಮ್ ಫ್ಲ್ಯಾಗ್, ರನ್ಟೈಮ್ ಫ್ಲ್ಯಾಗ್ ಅಲ್ಲ.** Next.js `headers()` ಅನ್ನು ರೂಟ್
> ಮ್ಯಾನಿಫೆಸ್ಟ್ನಲ್ಲಿ ಕಂಪೈಲ್ ಮಾಡುತ್ತದೆ; ಆದ್ದರಿಂದ ಬಂಡಲ್ ಬಿಲ್ಡ್ ಆಗುತ್ತಿರುವಾಗ `next.config.mjs` ವೇರಿಯೇಬಲ್ ಅನ್ನು ಓದುತ್ತದೆ
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> ಈಗಾಗಲೇ ಬಿಲ್ಡ್ ಮಾಡಿದ ಸರ್ವರ್ನ ಮುಂದೆ ಅದನ್ನು ಎಕ್ಸ್ಪೋರ್ಟ್ ಮಾಡುವುದರಿಂದ ಏನೂ ಬದಲಾಗುವುದಿಲ್ಲ — ಹೆಡರ್ಗಳು ಬಿಲ್ಡ್ನಲ್ಲೇ ಸ್ಥಿರವಾಗಿ ಸೇರಿಸಲ್ಪಟ್ಟಿರುತ್ತವೆ.

```bash
# ವೇರಿಯೇಬಲ್ BUILD ಕಮಾಂಡ್ನಲ್ಲಿ ಇರಲೇಬೇಕು
DASHBOARD_ALLOW_EMBED=vscode npm run build        # ಅಥವಾ npm run build:release
npm start
```
