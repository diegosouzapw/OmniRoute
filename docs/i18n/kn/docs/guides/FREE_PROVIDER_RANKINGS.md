## ಇದು ಏನು

OmniRoute 329 ಪೂರೈಕೆದಾರರನ್ನು ನೋಂದಾಯಿಸುತ್ತದೆ; ಇವುಗಳಲ್ಲಿ 155 ಕ್ಯಾಟಲಾಗ್ ನಮೂದುಗಳನ್ನು
**ಉಚಿತ/ದೃಢೀಕರಣ-ರಹಿತ** ಎಂದು ಗುರುತಿಸಲಾಗಿದೆ (ದೃಢೀಕರಣ-ರಹಿತ, ಉಚಿತ-ಹಂತದ OAuth ಅಥವಾ
ಉಚಿತ-ಹಂತದ API ಕೀ — [ಉಚಿತ ಹಂತಗಳ ಮಾರ್ಗದರ್ಶಿ](../getting-started/FREE-TIERS-GUIDE.md)
ಮತ್ತು ಸಂಪೂರ್ಣ [ಉಚಿತ ಹಂತಗಳ ಡೈರೆಕ್ಟರಿ](../reference/FREE_TIERS.md) ನೋಡಿ). ಆದರೆ ಒಂದು
ಸಮಸ್ಯೆಯಿದೆ: ಉಚಿತ ಪೂರೈಕೆದಾರರ ಮಾದರಿಯ ಗುಣಮಟ್ಟವು ಬಹಳಷ್ಟು ಬದಲಾಗುತ್ತದೆ. ಅತ್ಯಾಧುನಿಕ
ಮಾದರಿಯನ್ನು ಒದಗಿಸುವ ದೃಢೀಕರಣ-ರಹಿತ ಪೂರೈಕೆದಾರರು, ಸಣ್ಣ ಹಳೆಯ ಮಾದರಿಯನ್ನು ಒದಗಿಸುವವರಿಗಿಂತ
ಹೆಚ್ಚು ಉಪಯುಕ್ತರಾಗಿರುತ್ತಾರೆ.

**ಉಚಿತ ಪೂರೈಕೆದಾರರ ಶ್ರೇಯಾಂಕಗಳು**, ಪ್ರತಿ ಉಚಿತ ಪೂರೈಕೆದಾರರ ಕ್ಯಾಟಲಾಗ್ ಅನ್ನು **Arena AI
ಲೀಡರ್ಬೋರ್ಡ್ನ** **ಬಳಕೆದಾರ ಸಮುದಾಯದಿಂದ ಸಂಗ್ರಹಿಸಲಾದ ಗುಣಮಟ್ಟದ ಸ್ಕೋರ್ಗಳೊಂದಿಗೆ**
(LMArena ಚಾಟ್ಬಾಟ್ ಅರೆನಾದ ಹಿಂದಿರುವ ಅದೇ ಪರಿಕಲ್ಪನೆಯ ಮಾನವ-ಆದ್ಯತೆಯ ELO) ಜೋಡಿಸುವ ಮೂಲಕ,
"**ಯಾವ ಉಚಿತ ಪೂರೈಕೆದಾರರು ನನಗೆ ಅತ್ಯುತ್ತಮ ಮಾದರಿಯನ್ನು ನೀಡುತ್ತಾರೆ?**" ಎಂಬ ಪ್ರಶ್ನೆಗೆ ಉತ್ತರಿಸುತ್ತದೆ.
ನಂತರ ಪೂರೈಕೆದಾರರನ್ನು ಅವರ **ಅತ್ಯುತ್ತಮ ಉಚಿತ ಮಾದರಿಯ** ಸಾಮರ್ಥ್ಯದ ಆಧಾರದ ಮೇಲೆ
ಶ್ರೇಣೀಕರಿಸಲಾಗುತ್ತದೆ.

ಶ್ರೇಯಾಂಕವನ್ನು ಮೂರು ನೈಜ ಮೂಲಗಳಿಂದ ಲೆಕ್ಕಹಾಕಲಾಗುತ್ತದೆ:

1. ಉಚಿತ-ಪೂರೈಕೆದಾರರ ಪಟ್ಟಿಗಳು — `NOAUTH_PROVIDERS`, ಜೊತೆಗೆ `hasFree` ಎಂದು
   ಗುರುತಿಸಲಾದ `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` ನಮೂದುಗಳು
   (`src/shared/constants/providers.ts`).
2. ಪೂರೈಕೆದಾರರ ರಿಜಿಸ್ಟ್ರಿಯಿಂದ ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ಮಾದರಿ ಕ್ಯಾಟಲಾಗ್
   (`open-sse/config/providerRegistry.ts`).
3. Arena ELO ಸಿಂಕ್ ಎಂಜಿನ್ (`src/lib/arenaEloSync.ts`) ಮೂಲಕ `model_intelligence`
   DB ಕೋಷ್ಟಕದಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾದ ELO-ಆಧಾರಿತ ಕಾರ್ಯ-ಹೊಂದಾಣಿಕೆ ಸ್ಕೋರ್ಗಳು.

ಜೋಡಣೆ ತರ್ಕವು `src/lib/freeProviderRankings.ts` ನಲ್ಲಿದೆ.

## ಪ್ರವೇಶಿಸುವ ವಿಧಾನ

### ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಪುಟ

ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ ಮತ್ತು **ವೆಚ್ಚಗಳು → ಉಚಿತ ಪೂರೈಕೆದಾರರ ಶ್ರೇಯಾಂಕಗಳು** ಎಂಬುದಕ್ಕೆ
ಹೋಗಿ, ಅಥವಾ ನೇರವಾಗಿ ಇಲ್ಲಿಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ:

```
/dashboard/free-provider-rankings
```

ಈ ಪುಟವು (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) ಇವುಗಳನ್ನು
ತೋರಿಸುತ್ತದೆ:

- ಅತ್ಯುತ್ತಮ ಶ್ರೇಯಾಂಕ ಪಡೆದ ಉಚಿತ ಪೂರೈಕೆದಾರರ **ಅಗ್ರ-3 ವೇದಿಕೆ** (🥇 🥈 🥉).
- **ಶ್ರೇಣಿ**, **ಪೂರೈಕೆದಾರರು**, **ಅಗ್ರ ಮಾದರಿ**, **ಸ್ಕೋರ್**, **ಸರಾಸರಿ ಸ್ಕೋರ್**,
  **ಮಾದರಿಗಳು**, **ಪ್ರಕಾರ** ಎಂಬ ಕಾಲಮ್ಗಳಿರುವ ಸಂಪೂರ್ಣ **ಶ್ರೇಯಾಂಕ ಕೋಷ್ಟಕ**.
- **ವರ್ಗದ ಫಿಲ್ಟರ್ ಬಟನ್ಗಳು**: _ಎಲ್ಲಾ ವರ್ಗಗಳು_, _ಡೀಫಾಲ್ಟ್_, _ಕೋಡಿಂಗ್_,
  _ಪರಿಶೀಲನೆ_, _ದಸ್ತಾವೇಜೀಕರಣ_, _ಡೀಬಗ್ಗಿಂಗ್_.

ಪ್ರತಿ ಪೂರೈಕೆದಾರರ **ಪ್ರಕಾರ** ಬ್ಯಾಡ್ಜ್, ಅದು ಯಾವ ರೀತಿಯಲ್ಲಿ ಉಚಿತವಾಗಿದೆ ಎಂಬುದನ್ನು ತಿಳಿಸುತ್ತದೆ:

| ಬ್ಯಾಡ್ಜ್ | ಅರ್ಥ                                                  |
| -------- | ----------------------------------------------------- |
| `NOAUTH` | ಯಾವಾಗಲೂ ಉಚಿತ, ರುಜುವಾತುಗಳ ಅಗತ್ಯವಿಲ್ಲ                   |
| `OAUTH`  | ಉಚಿತ ಹಂತವನ್ನು ಹೊಂದಿರುವ OAuth ಪೂರೈಕೆದಾರರು (`hasFree`)  |
| `APIKEY` | ಉಚಿತ ಹಂತವನ್ನು ಹೊಂದಿರುವ API-ಕೀ ಪೂರೈಕೆದಾರರು (`hasFree`) |

ಸ್ಕೋರ್ಗಳನ್ನು ಕಚ್ಚಾ ಸಂಖ್ಯೆಗಳ ಬದಲಿಗೆ, ಮನುಷ್ಯರು ಸುಲಭವಾಗಿ ಅರ್ಥಮಾಡಿಕೊಳ್ಳಬಹುದಾದ ಲೇಬಲ್ಗಳಾಗಿ
(ಉದಾ. _ಅತ್ಯುನ್ನತ_, _ಅತ್ಯುತ್ತಮ_, _ಬಹಳ ಉತ್ತಮ_, _ಉತ್ತಮ_, _ಸರಾಸರಿ_) ತೋರಿಸಲಾಗುತ್ತದೆ,
ಏಕೆಂದರೆ ಆಧಾರವಾಗಿರುವ ಮೌಲ್ಯವು ಶೇಕಡಾವಾರು ಅಲ್ಲ, ಬದಲಿಗೆ ಸಾಪೇಕ್ಷ ಶ್ರೇಯಾಂಕ ಗುಣಮಟ್ಟವಾಗಿದೆ.

### API ಎಂಡ್ಪಾಯಿಂಟ್

ಈ ಪುಟವು ಸಾರ್ವಜನಿಕ ರೀಡ್ ಎಂಡ್ಪಾಯಿಂಟ್
(`src/app/api/free-provider-rankings/route.ts`) ಅನ್ನು ಆಧರಿಸಿದೆ:

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

ಕ್ವೆರಿ ಪ್ಯಾರಾಮೀಟರ್ಗಳು (Zod ಮೂಲಕ ಮೌಲ್ಯೀಕರಿಸಲಾಗಿದೆ):

| ಪ್ಯಾರಾಮೀಟರ್ | ಪ್ರಕಾರ | ಡೀಫಾಲ್ಟ್      | ಟಿಪ್ಪಣಿಗಳು                                                                                                            |
| ----------- | ------ | ------------- | --------------------------------------------------------------------------------------------------------------------- |
| `category`  | string | (ಯಾವುದೂ ಇಲ್ಲ) | `default`, `coding`, `review`, `documentation`, `debugging` ಇವುಗಳಲ್ಲಿ ಒಂದು. ಸಂಯೋಜಿತ ಶ್ರೇಯಾಂಕಕ್ಕಾಗಿ ಇದನ್ನು ಬಿಟ್ಟುಬಿಡಿ. |
| `limit`     | number | `50`          | `1–100` ವ್ಯಾಪ್ತಿಗೆ ಸೀಮಿತಗೊಳಿಸಲಾಗಿದೆ.                                                                                  |

ಪ್ರತಿಕ್ರಿಯೆಯ ಸ್ವರೂಪ:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` ಮೂಲ Arena ELO ಮೌಲ್ಯವಾಗಿದೆ; `score` ಸಾಮಾನ್ಯೀಕರಿಸಿದ ಕಾರ್ಯ-ಹೊಂದಾಣಿಕೆ
ಮೌಲ್ಯವಾಗಿದೆ (ಕೆಳಗೆ ನೋಡಿ). ಸ್ಕೋರ್ ಮಾಡಲಾದ ಯಾವುದೇ ಮಾದರಿಗಳನ್ನು ಹೊಂದಿರದ ಪೂರೈಕೆದಾರರನ್ನು
ಪ್ರತಿಕ್ರಿಯೆಯಿಂದ ಕೈಬಿಡಲಾಗುತ್ತದೆ.

## ಸ್ಕೋರ್ಗಳು ಹೇಗೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ

### ಮೂಲ: Arena AI ಲೀಡರ್ಬೋರ್ಡ್

Arena ELO ಸಿಂಕ್ ಎಂಜಿನ್ (`src/lib/arenaEloSync.ts`), Arena AI ಲೀಡರ್ಬೋರ್ಡ್ API
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`) ನಿಂದ `text`
ಮತ್ತು `code` ಎಂಬ ಎರಡು ಲೀಡರ್ಬೋರ್ಡ್ಗಳನ್ನು ಪಡೆಯುತ್ತದೆ. ಪ್ರತಿಯೊಂದು ಲೀಡರ್ಬೋರ್ಡ್ ನಮೂದು
ಮಾದರಿಯ ಹೆಸರು, ವಿತರಕರು, ELO `score`, ವಿಶ್ವಾಸಾರ್ಹತಾ ಮಧ್ಯಂತರ ಮತ್ತು ಮತಗಳ ಸಂಖ್ಯೆಯನ್ನು
ಒಳಗೊಂಡಿರುತ್ತದೆ.

ಲೀಡರ್ಬೋರ್ಡ್ ವರ್ಗಗಳು OmniRoute ಕಾರ್ಯ ವರ್ಗಗಳಿಗೆ ಈ ರೀತಿ ನಕ್ಷೆಗೊಳ್ಳುತ್ತವೆ:

| Arena ಲೀಡರ್ಬೋರ್ಡ್ | OmniRoute ಕಾರ್ಯ ವರ್ಗಗಳು                           |
| ----------------- | ------------------------------------------------- |
| `text`            | `default`, `review`, `documentation`, `debugging` |
| `code`            | `coding`                                          |

### ಸಾಮಾನ್ಯೀಕರಣ (ಕಾರ್ಯ-ಹೊಂದಾಣಿಕೆ ಸ್ಕೋರ್)

ಕಚ್ಚಾ ELO ಸ್ಕೋರ್ಗಳನ್ನು ಪ್ರತಿ ಲೀಡರ್ಬೋರ್ಡ್ಗೆ **`[0.4, 0.98]` ವ್ಯಾಪ್ತಿಯ ಕಾರ್ಯ-ಹೊಂದಾಣಿಕೆ ಮೌಲ್ಯವಾಗಿ** ಸಾಮಾನ್ಯೀಕರಿಸಲಾಗುತ್ತದೆ:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

ಸ್ಕೋರ್ ಎಂದಿಗೂ `0` ಅಥವಾ `1` ತಲುಪುವುದಿಲ್ಲ; ಇದರಿಂದ ಬಳಕೆದಾರರ ಅತಿಕ್ರಮಣಗಳಿಗೆ ಅವಕಾಶ
ಉಳಿಯುತ್ತದೆ. API ಪ್ರತಿಕ್ರಿಯೆಯಲ್ಲಿ ನೀವು ನೋಡುವ `score` ಕ್ಷೇತ್ರ ಮತ್ತು ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ
ತೋರಿಸಲಾಗುವ ಲೇಬಲ್ ಇದೇ ಆಗಿದೆ.

### ವಿಶ್ವಾಸಾರ್ಹತೆ

Arena ಮತಗಳ ಸಂಖ್ಯೆಯನ್ನು ಆಧರಿಸಿ ಪ್ರತಿ ನಮೂದಿಗೂ ವಿಶ್ವಾಸಾರ್ಹತೆಯ ಮಟ್ಟವನ್ನು ನೀಡಲಾಗುತ್ತದೆ:

| ವಿಶ್ವಾಸಾರ್ಹತೆ | ಮತಗಳು   |
| ------------- | ------- |
| `high`        | ≥ 5,000 |
| `medium`      | ≥ 1,000 |
| `low`         | < 1,000 |

### ಸಂಗ್ರಹಣೆ ಮತ್ತು ತಾಜಾತನ

ಸಾಮಾನ್ಯೀಕರಿಸಿದ ನಮೂದುಗಳನ್ನು `source = "arena_elo"` ಜೊತೆಗೆ `model_intelligence` DB
ಕೋಷ್ಟಕದಲ್ಲಿ ಬರೆಯಲಾಗುತ್ತದೆ (`src/lib/db/modelIntelligence.ts`). ನಮೂದುಗಳು **7 ದಿನಗಳ
ನಂತರ ಅವಧಿ ಮೀರುತ್ತವೆ**; ಆದ್ದರಿಂದ ಸಿಂಕ್ ಮಾಡುವುದನ್ನು ನಿಲ್ಲಿಸುವ ಪೂರೈಕೆದಾರರು ಹಳೆಯ
ಡೇಟಾವನ್ನು ಒದಗಿಸುವ ಬದಲು ಅಂತಿಮವಾಗಿ ಪಟ್ಟಿಯಿಂದ ಹೊರಬೀಳುತ್ತಾರೆ.

ಸಿಂಕ್ **ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಸಕ್ರಿಯವಾಗಿರುತ್ತದೆ**:

- ಇದು ಸರ್ವರ್ ಪ್ರಾರಂಭವಾಗುವಾಗ ಒಮ್ಮೆ ಮತ್ತು ನಂತರ ನಿಯತಕಾಲಿಕ ಟೈಮರ್ನಲ್ಲಿ ಚಲಿಸುತ್ತದೆ
  (`src/lib/arenaEloSync.ts`, `src/instrumentation-node.ts` ನಿಂದ ಸಂಪರ್ಕಿಸಲಾಗಿದೆ).
- ಇದು **ತಡೆಯೊಡ್ಡುವುದಿಲ್ಲ ಮತ್ತು ಎಂದಿಗೂ ಮಾರಕವಾಗುವುದಿಲ್ಲ** — ಅಪ್ಸ್ಟ್ರೀಮ್ ಪಡೆಯುವಿಕೆ
  ವಿಫಲವಾದರೆ, OmniRoute ಚಾಲನೆಯಲ್ಲೇ ಇರುತ್ತದೆ ಮತ್ತು ಶ್ರೇಯಾಂಕಗಳು ಕೊನೆಯ ಉತ್ತಮ ಡೇಟಾವನ್ನು
  (ಅಥವಾ ಖಾಲಿ ಸ್ಥಿತಿಯನ್ನು) ಸರಳವಾಗಿ ತೋರಿಸುತ್ತವೆ.

ಎರಡು ಪರಿಸರ ಚರಗಳು ಇದನ್ನು ನಿಯಂತ್ರಿಸುತ್ತವೆ
([`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md) ನಲ್ಲಿ ದಾಖಲಿಸಲಾಗಿದೆ):

| ಚರ                        | ಪೂರ್ವನಿಯೋಜಿತ  | ಉದ್ದೇಶ                                            |
| ------------------------- | ------------- | ------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | ಔಟ್ಬೌಂಡ್ ಸಿಂಕ್ನಿಂದ ಹೊರಗುಳಿಯಲು `false` ಗೆ ಹೊಂದಿಸಿ. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | ಸೆಕೆಂಡುಗಳಲ್ಲಿ ಸಿಂಕ್ ಮಧ್ಯಂತರ.                      |

### ಹಸ್ತಚಾಲಿತ ಸಿಂಕ್ / ಸ್ಥಿತಿ / ತೆರವುಗೊಳಿಸುವಿಕೆ

ನಿರ್ವಾಹಕರಿಗಾಗಿ, ದೃಢೀಕೃತ ನಿರ್ವಹಣಾ ಎಂಡ್ಪಾಯಿಂಟ್ ಹಸ್ತಚಾಲಿತ ನಿಯಂತ್ರಣವನ್ನು ಒದಗಿಸುತ್ತದೆ
(`src/app/api/intelligence/sync/route.ts` — ನಿರ್ವಹಣಾ ದೃಢೀಕರಣದ ಅಗತ್ಯವಿದೆ):

```
GET    /api/intelligence/sync          # ಪ್ರಸ್ತುತ ಸಿಂಕ್ ಸ್ಥಿತಿ (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # ಹಸ್ತಚಾಲಿತ ಸಿಂಕ್ ಪ್ರಚೋದಿಸಿ; ಬರೆಯದೆ ಮುನ್ನೋಟ ನೋಡಲು body: { "dryRun": true }
DELETE /api/intelligence/sync          # ಸಿಂಕ್ ಮಾಡಲಾದ ಎಲ್ಲ arena_elo ಬುದ್ಧಿಮತ್ತೆ ನಮೂದುಗಳನ್ನು ತೆರವುಗೊಳಿಸಿ
```

ಶ್ರೇಯಾಂಕಗಳ ಪುಟ ಖಾಲಿಯಾಗಿದ್ದರೆ, ಹಸ್ತಚಾಲಿತ `POST /api/intelligence/sync` (ಅಥವಾ
ಸರ್ವರ್ ಅನ್ನು ಸರಳವಾಗಿ ಮರುಪ್ರಾರಂಭಿಸುವುದು) ಅದನ್ನು ಮರುತುಂಬಿಸುತ್ತದೆ.

### ಮಾದರಿಗಳನ್ನು ಲೀಡರ್ಬೋರ್ಡ್ಗೆ ಹೊಂದಿಸುವುದು

ರಿಜಿಸ್ಟ್ರಿ ಮಾದರಿ IDಗಳು ಮತ್ತು Arena ಮಾದರಿ ಹೆಸರುಗಳು ಯಾವಾಗಲೂ ನಿಖರವಾಗಿ ಹೊಂದಿಕೆಯಾಗುವುದಿಲ್ಲ.
ಶ್ರೇಯಾಂಕವು ಹೊಂದಿಕೊಳ್ಳುವ ಹೊಂದಾಣಿಕೆಯನ್ನು ಬಳಸುತ್ತದೆ (`src/lib/freeProviderRankings.ts`
ನಲ್ಲಿನ `findMatchingIntelligence`):

1. ಸಾಮಾನ್ಯೀಕರಿಸಿದ ಮಾದರಿ IDಯೊಂದಿಗೆ ನಿಖರ ಹೊಂದಾಣಿಕೆ.
2. ಕೊನೆಯ ಆವೃತ್ತಿ ಪ್ರತ್ಯಯವನ್ನು ತೆಗೆದುಹಾಕಿದ ನಂತರದ ಹೊಂದಾಣಿಕೆ (ಉದಾ. `kimi-k2.6` → `kimi-k2`).
3. ಪೂರ್ವಪ್ರತ್ಯಯ ಹೊಂದಾಣಿಕೆ (ಲೀಡರ್ಬೋರ್ಡ್ ಮಾದರಿಯ ಹೆಸರು ರಿಜಿಸ್ಟ್ರಿ IDಯ ಪೂರ್ವಪ್ರತ್ಯಯವಾಗಿರುತ್ತದೆ).

ಸಿಂಕ್ ಭಾಗದಲ್ಲಿ, ತಿಳಿದಿರುವ ವಿತರಕರ ಪೂರ್ವಪ್ರತ್ಯಯಗಳನ್ನು (`anthropic/`, `openai/`,
`google/`, …) ತೆಗೆದುಹಾಕಲಾಗುತ್ತದೆ ಮತ್ತು ಒಂದು ಸಣ್ಣ ಅಲಿಯಾಸ್ ನಕ್ಷೆಯು ಪ್ರಮಾಣಿತ ಹೆಸರುಗಳನ್ನು
OmniRoute ಆಂತರಿಕವಾಗಿ ಬಳಸುವ ರೂಪಾಂತರಗಳಿಗೆ ವಿಸ್ತರಿಸುತ್ತದೆ; ಆದ್ದರಿಂದ ಮಾದರಿಗಳು ಯಾವುದೇ
ಹೆಸರಿನ ಅಡಿಯಲ್ಲೂ ಪತ್ತೆಯಾಗುವಂತಿರುತ್ತವೆ.

### ಪೂರೈಕೆದಾರರಿಗೆ ಹೇಗೆ ಶ್ರೇಯಾಂಕ ನೀಡಲಾಗುತ್ತದೆ

ಪ್ರತಿ ಉಚಿತ ಪೂರೈಕೆದಾರರಿಗಾಗಿ, ಎಂಜಿನ್ ಅದರ ಕ್ಯಾಟಲಾಗ್ನಲ್ಲಿರುವ ಪ್ರತಿಯೊಂದು ಮಾದರಿಗೂ ಸ್ಕೋರ್
ನೀಡುತ್ತದೆ, ನಂತರ:

- **ಅಗ್ರ ಮಾದರಿ** = ಪೂರೈಕೆದಾರರ ಅತ್ಯಧಿಕ ಸ್ಕೋರ್ ಪಡೆದ ಮಾದರಿ.
- **ಸರಾಸರಿ ಸ್ಕೋರ್** = ಆ ಪೂರೈಕೆದಾರರ ಸ್ಕೋರ್ ಪಡೆದ ಎಲ್ಲಾ ಮಾದರಿಗಳ ಸರಾಸರಿ ಸ್ಕೋರ್.
- **ಮಾದರಿಗಳು** = ಪೂರೈಕೆದಾರರ ಎಷ್ಟು ಮಾದರಿಗಳು Arena ಸ್ಕೋರ್ ಹೊಂದಿದ್ದವು ಎಂಬುದು.

ಪೂರೈಕೆದಾರರನ್ನು ಮೊದಲು **ಅಗ್ರ-ಮಾದರಿ ಸ್ಕೋರ್** ಮತ್ತು ನಂತರ ಸರಾಸರಿ ಸ್ಕೋರ್ ಆಧರಿಸಿ
ವಿಂಗಡಿಸಲಾಗುತ್ತದೆ. ಇದು ಕನಿಷ್ಠ ಒಂದು ಪ್ರಬಲ ಉಚಿತ ಮಾದರಿಯನ್ನು ಒದಗಿಸುವ ಪೂರೈಕೆದಾರರಿಗೆ
ಪ್ರತಿಫಲ ನೀಡುತ್ತದೆ.

## ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಆಯ್ಕೆ ಮಾಡಲು ಇದನ್ನು ಬಳಸುವುದು

1. **ಸರಿಯಾದ ವರ್ಗವನ್ನು ಆಯ್ಕೆಮಾಡಿ.** ಏಜೆಂಟ್-ಆಧಾರಿತ/ಕೋಡ್ ಕಾರ್ಯಭಾರಗಳಿಗಾಗಿ **ಕೋಡಿಂಗ್** ಫಿಲ್ಟರ್ ಬಳಸಿ, ಅಥವಾ
   ಸಾಮಾನ್ಯ ಚಾಟ್ಗಾಗಿ ಅದನ್ನು **ಎಲ್ಲಾ ವರ್ಗಗಳು** / **ಡೀಫಾಲ್ಟ್** ಆಯ್ಕೆಯಲ್ಲೇ ಬಿಡಿ. ಪ್ರತಿ ಲೀಡರ್ಬೋರ್ಡ್ನಲ್ಲಿ ಅದರ
   ಅಗ್ರ ಮಾಡೆಲ್ ಭಿನ್ನವಾಗಿರುವುದರಿಂದ, ಒಂದೇ ಪೂರೈಕೆದಾರನು ವಿವಿಧ ವರ್ಗಗಳಲ್ಲಿ ವಿಭಿನ್ನ ಶ್ರೇಣಿ
   ಪಡೆಯಬಹುದು.
2. **ಒಂದೇ ಬಾರಿ ಮಾಡುವ ಸೆಟಪ್ಗಳಿಗೆ ಅಗ್ರ ಮೂರು ಸ್ಥಾನಗಳಿಗೆ ಆದ್ಯತೆ ನೀಡಿ.** ನೀವು ಕೇವಲ ಒಂದು ಅಥವಾ ಎರಡು ಉಚಿತ
   ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಲು ಬಯಸಿದರೆ, ನಿಮ್ಮ ವರ್ಗದಲ್ಲಿ ಅಗ್ರ ಶ್ರೇಣಿ ಪಡೆದಿರುವವುಗಳಿಂದ ಪ್ರಾರಂಭಿಸಿ.
3. **ಪ್ರಕಾರದ ಬ್ಯಾಡ್ಜ್ ಪರಿಶೀಲಿಸಿ.** `NOAUTH` ಪೂರೈಕೆದಾರರನ್ನು ಅತ್ಯಂತ ವೇಗವಾಗಿ ಸಂಪರ್ಕಿಸಬಹುದು (ಯಾವುದೇ
   ರುಜುವಾತುಗಳ ಅಗತ್ಯವಿಲ್ಲ). `OAUTH` / `APIKEY` ಉಚಿತ ಹಂತಗಳಿಗೆ ತ್ವರಿತ ನೋಂದಣಿ ಅಗತ್ಯವಿದೆ, ಆದರೆ ಅವು ಸಾಮಾನ್ಯವಾಗಿ
   ಹೆಚ್ಚು ಸಾಮರ್ಥ್ಯವಿರುವ ಮಾಡೆಲ್ಗಳನ್ನು ಒದಗಿಸುತ್ತವೆ. ಸಂಪರ್ಕಿಸುವ ಹಂತಗಳಿಗಾಗಿ
   [ಉಚಿತ ಹಂತಗಳ ಮಾರ್ಗದರ್ಶಿ](../getting-started/FREE-TIERS-GUIDE.md) ನೋಡಿ.
4. **ಹಲವಾರು ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ ಮತ್ತು Auto-Combo ನಿರ್ಧರಿಸಲು ಬಿಡಿ.** ಈ ಪುಟವನ್ನು ಚಾಲಿತಗೊಳಿಸುವ ಅದೇ Arena ELO ಡೇಟಾವು
   Auto-Combo ಸ್ಕೋರಿಂಗ್ ಎಂಜಿನ್ನ **ಕಾರ್ಯ-ಸೂಕ್ತತೆ ಅಂಶ**ಕ್ಕೂ ಪೂರೈಕೆಯಾಗುತ್ತದೆ
   (`open-sse/services/autoCombo/taskFitness.ts`, ನಿರ್ಧಾರ ಕ್ರಮ
   `user_override → arena_elo → models_dev_tier → static table`). ಆದ್ದರಿಂದ ನೀವು ಅಗ್ರ ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿದ ನಂತರ,
   `model: "auto"` (ಉದಾ. `auto/coding`) ಬಳಸಿ ರೂಟಿಂಗ್ ಮಾಡಿದಾಗ, ಪ್ರತಿ ವಿನಂತಿಗೂ
   ಹೆಚ್ಚಿನ ಗುಣಮಟ್ಟದ ಉಚಿತ ಮಾಡೆಲ್ಗಳಿಗೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಆದ್ಯತೆ ನೀಡಲಾಗುತ್ತದೆ. ಸಂಪೂರ್ಣ 16-ಅಂಶಗಳ ಸ್ಕೋರಿಂಗ್ಗಾಗಿ
   [Auto-Combo](../routing/AUTO-COMBO.md) ನೋಡಿ.
