OmniRoute ಬೆಂಬಲಿತ 352 ಪೂರೈಕೆದಾರರನ್ನು 3 ಆರ್ಥಿಕ ಶ್ರೇಣಿಗಳಾಗಿ ಸಂಘಟಿಸುತ್ತದೆ. ಪ್ರತಿ
ವಿನಂತಿಯು ಯಶಸ್ವಿ ಪ್ರತಿಕ್ರಿಯೆ ದೊರೆಯುವವರೆಗೆ ಕ್ರಮವಾಗಿ ಅವುಗಳ ಮೂಲಕ ಸಾಗುತ್ತದೆ — ನೀವು
ಯಾವುದೇ fallback ಕೋಡ್ ಬರೆಯದೆಯೇ ಲಭ್ಯವಿರುವ ಅತ್ಯಂತ ಅಗ್ಗದ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಪಡೆಯುತ್ತೀರಿ.

## ಶ್ರೇಣಿ 1 — ಚಂದಾದಾರಿಕೆ

**ನೀವು ಈಗಾಗಲೇ ಹಣ ಪಾವತಿಸುತ್ತಿರುವ ಪೂರೈಕೆದಾರರು.** OmniRoute ಪ್ರತಿ ಹನಿ ಕೋಟಾವನ್ನೂ
ಅದರ ಅವಧಿ ಮುಗಿಯುವ ಮೊದಲು ಬಳಸುತ್ತದೆ.

| ಪೂರೈಕೆದಾರ                         | ಶ್ರೇಣಿ 1 ಆಗಿರುವುದೇಕೆ                                     |
| --------------------------------- | -------------------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — ನಿಗದಿತ ದರ, ಬಹುತೇಕ ಬಳಕೆಯಾಗುವುದಿಲ್ಲ   |
| OpenAI Codex (ChatGPT ಚಂದಾದಾರಿಕೆ) | Plus/Team ನಲ್ಲಿ Codex ಕೋಟಾ ಸೇರಿದೆ                        |
| GitHub Copilot                    | ಪ್ರತಿ ಬಳಕೆದಾರ ಸ್ಥಾನಕ್ಕೆ — ಕೋಟಾ ಮಾಸಿಕವಾಗಿ ಮರುಹೊಂದಿಸುತ್ತದೆ |
| Cursor IDE                        | Pro ಯೋಜನೆಯ ಕೋಟಾ                                          |
| Antigravity / Devin Desktop       | ಅಂತರ್ನಿರ್ಮಿತ ಕೋಟಾಗಳು                                     |

**ತಂತ್ರ**: ಮಾದರಿಯ ಸಾಮರ್ಥ್ಯಗಳಿಗೆ ಹೊಂದುವ ಪ್ರತಿಯೊಂದು ವಿನಂತಿಯನ್ನೂ ಮೊದಲು ಇಲ್ಲಿಗೆ ರೌಟ್ ಮಾಡಿ.
ಕೋಟಾ ಟ್ರ್ಯಾಕರ್ ಸಮೀಪಿಸುತ್ತಿರುವ ಮರುಹೊಂದಿಕೆಗಳನ್ನು ಮೇಲ್ವಿಚಾರಣೆ ಮಾಡುತ್ತದೆ ಮತ್ತು `reset-aware`
ಸಂಯೋಜಿತ ತಂತ್ರವು ಅದಕ್ಕೆ ಅನುಗುಣವಾಗಿ ಆದ್ಯತೆ ನೀಡುತ್ತದೆ. ಮೊದಲು ಶ್ರೇಣಿ 1ಕ್ಕೆ ರೌಟ್ ಮಾಡಿ,
ಕೋಟಾ ಖಾಲಿಯಾದಾಗ ಮಾತ್ರ ಪಾವತಿಸಬೇಕಾದ ಶ್ರೇಣಿಗಳಿಗೆ ಹೋಗಲು `auto/thrifty` id ಬಳಸಿ — ಅಥವಾ
ಯೋಜನೆಯಲ್ಲಿ ಒಳಗೊಂಡಿರುವ ಸಾಮರ್ಥ್ಯದಲ್ಲೇ ಉಳಿದು, ಅದು ಲಭ್ಯವಿಲ್ಲದಿದ್ದರೆ ವಿಫಲಗೊಳ್ಳಲು
`auto/subscription` ಬಳಸಿ. [ಚಂದಾದಾರಿಕೆ-ಮೊದಲ ರೌಟಿಂಗ್](../routing/SUBSCRIPTION_LADDER.md)
ನೋಡಿ.

## ಶ್ರೇಣಿ 2 — ಅಗ್ಗ

**1M ಟೋಕನ್ಗಳಿಗೆ $1ಗಿಂತ ಕಡಿಮೆ ದರದ ಪ್ರತಿ-ಟೋಕನ್ ಪೂರೈಕೆದಾರರು.** ಹೆಚ್ಚಿನ ಪ್ರಮಾಣದ
ಕೆಲಸಕ್ಕಾಗಿ ಅಥವಾ ಶ್ರೇಣಿ 1ರ ಕೋಟಾಗಳು ಮಿತಿಯನ್ನು ತಲುಪಿದ ನಂತರ ಬಳಸಲು ಕಾಯ್ದಿರಿಸಲಾಗಿದೆ.

| ಪೂರೈಕೆದಾರ                             | ಬೆಲೆ (ಇನ್ಪುಟ್/ಔಟ್ಪುಟ್) | ಸಾಮರ್ಥ್ಯಗಳು             |
| ------------------------------------- | ---------------------- | ----------------------- |
| DeepSeek V4 Pro                       | $0.27 / $1.10 ಪ್ರತಿ 1M | ಕೋಡ್, ತಾರ್ಕಿಕ ವಿಶ್ಲೇಷಣೆ |
| GLM-4.5                               | $0.60 / $2.20 ಪ್ರತಿ 1M | ದೀರ್ಘ ಸಂದರ್ಭ            |
| MiniMax M1                            | $0.20 / $1.10 ಪ್ರತಿ 1M | ವೇಗ                     |
| Qwen Coder                            | $0.30 / $1.20 ಪ್ರತಿ 1M | ಕೋಡ್                    |
| OpenRouter (ಬೆಲೆ-ಆಪ್ಟಿಮೈಸ್ ಮಾಡಲಾಗಿದೆ) | ಬದಲಾಗುತ್ತದೆ            | 100+ ಮಾದರಿಗಳು, ಡೈನಾಮಿಕ್ |

**ತಂತ್ರ**: ಕಾರ್ಯದ ಸಾಮರ್ಥ್ಯ ಫಿಲ್ಟರ್ಗೆ (ದೃಷ್ಟಿ, JSON ಮೋಡ್, ಪರಿಕರಗಳು, ಗರಿಷ್ಠ-ಸಂದರ್ಭ)
ಹೊಂದುವ, ಅತ್ಯಂತ ಕಡಿಮೆ $/ಟೋಕನ್ ಹೊಂದಿರುವ ಮಾದರಿಯನ್ನು `cost-optimized` ಸಂಯೋಜನೆ ಆಯ್ಕೆಮಾಡುತ್ತದೆ.

## ಶ್ರೇಣಿ 3 — ಉಚಿತ

**ಶೂನ್ಯ-ವೆಚ್ಚದ ಪೂರೈಕೆದಾರರು** — ಉಚಿತ ಶ್ರೇಣಿಗಳು, ಕ್ರೆಡಿಟ್ ಕಾರ್ಯಕ್ರಮಗಳು, OAuth ದೈನಂದಿನ ಕೋಟಾಗಳು.

| ಪೂರೈಕೆದಾರ        | ಉಚಿತ ಕೋಟಾ / ಕ್ರೆಡಿಟ್ಗಳು                     |
| ---------------- | ------------------------------------------- |
| Kiro AI          | ಉಚಿತ Claude ಶ್ರೇಣಿ (ಉದಾರವಾದ ನ್ಯಾಯೋಚಿತ ಬಳಕೆ) |
| OpenCode Free    | ದೃಢೀಕರಣ ಅಗತ್ಯವಿಲ್ಲ, ಉದಾರವಾದ ದರ ಮಿತಿಗಳು      |
| Qoder            | ಉಚಿತ OAuth                                  |
| Google Vertex AI | ಹೊಸ ಖಾತೆಗೆ $300 ಕ್ರೆಡಿಟ್ಗಳು                 |
| Amazon Q         | AWS ಬಳಕೆದಾರರಿಗೆ ಉಚಿತ ಶ್ರೇಣಿ                 |
| Pollinations     | ಮುಕ್ತ ಸಾರ್ವಜನಿಕ API                         |
| Cloudflare AI    | Workers AI ಉಚಿತ ಶ್ರೇಣಿ                      |

**ತಂತ್ರ**: ಶ್ರೇಣಿ 1+2 ವಿಫಲವಾದಾಗ ಅಥವಾ `useFreeOnly=true` ಹೊಂದಿಸಿದಾಗ,
ಬಜೆಟ್ ಮಿತಿಯೊಂದಿಗೆ `auto` ಸಂಯೋಜನೆಯು ಇಲ್ಲಿಗೆ ರೌಟ್ ಮಾಡುತ್ತದೆ. ಉಚಿತ ಪೂರೈಕೆದಾರರು
ಸಾಮಾನ್ಯವಾಗಿ ದುರ್ಬಲ ದರ ಮಿತಿಗಳನ್ನು ಹೊಂದಿರುತ್ತಾರೆ — circuit breaker ಅವುಗಳನ್ನು
backoff ನಂತರ ಮರುಸ್ಥಾಪಿಸುತ್ತದೆ.

## ಶ್ರೇಣಿಗಳನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡುವುದು

Dashboard → **Tiers** → ನಿಮ್ಮ ಪೂರೈಕೆದಾರರನ್ನು ನಿಯೋಜಿಸಿ. ಡೀಫಾಲ್ಟ್ಗಳು (`tierDefaults.json` ನಿಂದ)
ಸಮಂಜಸವಾಗಿವೆ; ಆದ್ಯತೆ ನೀಡಬೇಕಾದ ನಿರ್ದಿಷ್ಟ ಚಂದಾದಾರಿಕೆಗಳು ಅಥವಾ ಹೊರತುಪಡಿಸಬೇಕಾದ
ಪೂರೈಕೆದಾರರು ನಿಮ್ಮಲ್ಲಿದ್ದರೆ ಅವುಗಳನ್ನು ಸಂಪಾದಿಸಿ.

Auto-Comboದ 16-ಅಂಶಗಳ ಸ್ಕೋರಿಂಗ್ ಶ್ರೇಣಿಯನ್ನೂ ಪರಿಗಣಿಸುತ್ತದೆ.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) ನೋಡಿ.

## ಟೆಲಿಮೆಟ್ರಿ

Dashboard → **Usage** ಪ್ರತಿ ಶ್ರೇಣಿಯಲ್ಲಿ ಪ್ರತಿ ದಿನ ಬಳಸಿದ ಟೋಕನ್ಗಳನ್ನು ತೋರಿಸುತ್ತದೆ. ಇದನ್ನು ಹೀಗೆ ಬಳಸಿ:

- ಶ್ರೇಣಿ 1 ಅನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಬಳಸಲಾಗುತ್ತಿದೆ ಎಂಬುದನ್ನು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ (ಇಲ್ಲವಾದರೆ ನೀವು ಚಂದಾದಾರಿಕೆಯ ಮೌಲ್ಯವನ್ನು ವ್ಯರ್ಥ ಮಾಡುತ್ತಿದ್ದೀರಿ)
- ಯಾವ ಶ್ರೇಣಿ 2 ಮಾದರಿಗಳನ್ನು ಹೆಚ್ಚು ಆಯ್ಕೆ ಮಾಡಲಾಗುತ್ತಿದೆ ಎಂಬುದನ್ನು ಗುರುತಿಸಿ (1-2ಕ್ಕೆ ಏಕೀಕರಿಸಿ)
- ಪರೀಕ್ಷೆ/ಅನ್ವೇಷಣೆಯ ಕಾರ್ಯಭಾರಗಳಲ್ಲಿ ಶ್ರೇಣಿ 3 ಹಣ ಉಳಿಸುತ್ತದೆ ಎಂಬುದನ್ನು ಪರಿಶೀಲಿಸಿ

## ಸಾಮಾನ್ಯ ಮಾದರಿಗಳು

### ಸಂಪೂರ್ಣ ಉಚಿತ ಕಾರ್ಯಭಾರ

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

ಶ್ರೇಣಿ 3ರ ಕಡೆಗೆ ಬಲವಾಗಿ ನಿರ್ದೇಶಿಸುತ್ತದೆ; ಶ್ರೇಣಿ 3 ಲಭ್ಯವಿಲ್ಲದಿದ್ದರೆ ಮಾತ್ರ ಶ್ರೇಣಿ 2 ಅನ್ನು ಬಳಸುತ್ತದೆ.

### ಅಗ್ಗದ fallback ಹೊಂದಿರುವ ಚಂದಾದಾರಿಕೆ-ಮೊದಲ ವಿಧಾನ

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

ಶ್ರೇಣಿ 1 → ಶ್ರೇಣಿ 2 → ಶ್ರೇಣಿ 3ಕ್ಕೆ ಹೊಂದುವ ಸ್ಪಷ್ಟವಾದ ಕ್ರಮಬದ್ಧ ಪಟ್ಟಿ.
