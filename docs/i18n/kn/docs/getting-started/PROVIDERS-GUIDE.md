## ಪೂರೈಕೆದಾರ ಎಂದರೇನು?

ಪೂರೈಕೆದಾರರನ್ನು **ಮೊಬೈಲ್ ನೆಟ್ವರ್ಕ್ ಸೇವಾದಾರರಂತೆ** ಪರಿಗಣಿಸಿ. ಕರೆಗಳನ್ನು ಮಾಡಲು ನಿಮಗೆ ಮೊಬೈಲ್ ನೆಟ್ವರ್ಕ್ ಸೇವಾದಾರರು ಅಗತ್ಯವಿರುವಂತೆಯೇ, AI ಮಾದರಿಗಳನ್ನು ಬಳಸಲು AI ಪೂರೈಕೆದಾರರು ಅಗತ್ಯವಿರುತ್ತಾರೆ. OmniRoute **ಎಲ್ಲಾ ಸೇವಾದಾರರೊಂದಿಗೂ** ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಫೋನ್ನಂತಿದೆ — ನೀವು ಅವರ ನಡುವೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬದಲಾಯಿಸಬಹುದು.

### ಪೂರೈಕೆದಾರರ ವಿಧಗಳು

| ವಿಧ           | ಅದು ಏನು                       | ಉದಾಹರಣೆಗಳು                        | ವೆಚ್ಚ                          |
| ------------- | ----------------------------- | --------------------------------- | ------------------------------ |
| **ಉಚಿತ**      | ಪಾವತಿಯ ಅಗತ್ಯವಿಲ್ಲ             | Kiro, OpenCode Free, Pollinations | $0                             |
| **API ಕೀ**    | ನಿಮಗೆ API ಕೀ ಅಗತ್ಯವಿದೆ        | OpenAI, Anthropic, Google         | ಬಳಕೆಗೆ ಅನುಗುಣವಾಗಿ ಪಾವತಿ        |
| **OAuth**     | ನಿಮ್ಮ ಖಾತೆಯಿಂದ ಲಾಗಿನ್ ಮಾಡಿ    | Claude Code, GitHub Copilot       | ಚಂದಾದಾರಿಕೆ                     |
| **ವೆಬ್ ಕುಕಿ** | ನಿಮ್ಮ ಬ್ರೌಸರ್ ಸೆಷನ್ ಬಳಸುತ್ತದೆ | ChatGPT Web (Codex), Gemini Web   | $0 (ನಿಮ್ಮ ಖಾತೆಯನ್ನು ಬಳಸುತ್ತದೆ) |

### ವೆಬ್ ಕುಕಿ ಪೂರೈಕೆದಾರರು

ಸಾಮಾನ್ಯ ಸೆಟಪ್ ಸೂಚನೆಗಳು, ಮಿತಿಗಳು, ಸಮಸ್ಯೆ ನಿವಾರಣೆ ಮತ್ತು ಪೂರೈಕೆದಾರ-ನಿರ್ದಿಷ್ಟ ದೃಢೀಕರಣ ಮಾರ್ಗದರ್ಶನಕ್ಕಾಗಿ **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** ನೋಡಿ.

## ತ್ವರಿತ ಪ್ರಾರಂಭ: ನಿಮ್ಮ ಮೊದಲ ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ

### ಐಚ್ಛಿಕ ಮೊದಲ-ಬಳಕೆಯ ಉಚಿತ-ಪೂರೈಕೆದಾರ ಸೆಟಪ್

ಮೊದಲ-ಬಳಕೆಯ ವಿಝಾರ್ಡ್ ಸ್ಪಷ್ಟವಾದ **ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಸೆಟಪ್ ಮಾಡಿ** ಕಾರ್ಡ್ ಅನ್ನು ಒದಗಿಸುತ್ತದೆ. ಇದು OmniRouteನ ದೃಢೀಕರಣ-ಅಗತ್ಯವಿಲ್ಲದ ಪೂರೈಕೆದಾರರ ರಿಜಿಸ್ಟ್ರಿಯಿಂದ ಪ್ರಸ್ತುತ ಅರ್ಹ ಪಟ್ಟಿಯನ್ನು ಪಡೆದುಕೊಳ್ಳುತ್ತದೆ ಮತ್ತು ದೃಢೀಕರಿಸುವ ಮೊದಲು ಪ್ರತಿಯೊಂದು ಪೂರೈಕೆದಾರರನ್ನು ಪರಿಶೀಲಿಸಲು ಹಾಗೂ ಆಯ್ಕೆಯನ್ನು ರದ್ದುಮಾಡಲು ನಿಮಗೆ ಅವಕಾಶ ನೀಡುತ್ತದೆ. ತೃತೀಯ-ಪಕ್ಷದ ನಿಯಮಗಳು, ಗೌಪ್ಯತೆ, ಲಭ್ಯತೆ ಮತ್ತು ದರ ಮಿತಿಗಳನ್ನು ನೀವು ಮೊದಲು ಪರಿಶೀಲಿಸಲು ಸಾಧ್ಯವಾಗುವಂತೆ OmniRoute ಪೂರೈಕೆದಾರರ ಎಚ್ಚರಿಕೆ ಸೂಚನೆ ಮತ್ತು ಅವರ ಸೈಟ್ಗೆ ಲಿಂಕ್ ಅನ್ನು ತೋರಿಸುತ್ತದೆ.

ಈ ಕ್ರಿಯೆ ಐಚ್ಛಿಕವಾಗಿದೆ: ವಿಝಾರ್ಡ್ ಅನ್ನು ಪೂರ್ಣಗೊಳಿಸುವುದರಿಂದ ಉಚಿತ-ಪೂರೈಕೆದಾರ ಸಂಪರ್ಕಗಳು ಎಂದಿಗೂ ನಿಮಗೆ ತಿಳಿಯದೆ ರಚನೆಯಾಗುವುದಿಲ್ಲ. ಇದು ಇನ್ನೂ ಇಲ್ಲದಿರುವ ಪೂರೈಕೆದಾರರನ್ನು ಮಾತ್ರ ರಚಿಸುತ್ತದೆ, ಈಗಾಗಲೇ ಗ್ರಾಹಕೀಯಗೊಳಿಸಿದ ಸಂಪರ್ಕಗಳನ್ನು ಬದಲಾಯಿಸದೆ ಹಾಗೆಯೇ ಬಿಡುತ್ತದೆ ಮತ್ತು ರಚಿಸಲಾದ, ಈಗಾಗಲೇ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾದ ಹಾಗೂ ವಿಫಲವಾದ ಪೂರೈಕೆದಾರರನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ವರದಿ ಮಾಡುತ್ತದೆ. ಭಾಗಶಃ ಫಲಿತಾಂಶದ ನಂತರ ವಿಫಲವಾದವುಗಳನ್ನು ಮಾತ್ರ ನೀವು ಸುರಕ್ಷಿತವಾಗಿ ಮರುಪ್ರಯತ್ನಿಸಬಹುದು.

### ಆಯ್ಕೆ A: ಉಚಿತ ಪೂರೈಕೆದಾರರು (ಕ್ರೆಡಿಟ್ ಕಾರ್ಡ್ ಅಗತ್ಯವಿಲ್ಲ)

1. `http://localhost:20128` ನಲ್ಲಿ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ
2. **ಪೂರೈಕೆದಾರರು** → **ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ಎಂಬುದಕ್ಕೆ ಹೋಗಿ
3. ಈ ಉಚಿತ ಪೂರೈಕೆದಾರರಲ್ಲಿ ಒಬ್ಬರನ್ನು ಆಯ್ಕೆಮಾಡಿ:
   - **Kiro AI** — ಉಚಿತ Claude ಮಾದರಿಗಳು (ದೃಢೀಕರಣ ಅಗತ್ಯವಿಲ್ಲ)
   - **OpenCode Free** — ಉಚಿತ GPT ಮಾದರಿಗಳು (ದೃಢೀಕರಣ ಅಗತ್ಯವಿಲ್ಲ)
   - **Pollinations** — ಉಚಿತ GPT-5, Claude, Gemini (ಕೀ ಅಗತ್ಯವಿಲ್ಲ)
   - **LongCat** — 10M ಟೋಕನ್ಗಳು ಉಚಿತ (ಒಂದು-ಬಾರಿಯ ಅನುದಾನ, ಖಾತೆ + KYC ಅಗತ್ಯವಿದೆ)
   - **Cloudflare AI** — 50+ ಮಾದರಿಗಳು, ದಿನಕ್ಕೆ 10K ನ್ಯೂರಾನ್ಗಳು
   - **MLX Gemma 26B** — ಸ್ಥಳೀಯ Apple Silicon ಮಾದರಿ (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — ಸ್ಥಳೀಯ Apple Silicon ಮಾದರಿ (~9.1 tok/s, ~13.1GB RAM)
4. **ಸಂಪರ್ಕಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ
5. ಮುಗಿಯಿತು! ಈಗ ನೀವು ಉಚಿತ AI ಪ್ರವೇಶವನ್ನು ಹೊಂದಿದ್ದೀರಿ.

### ಆಯ್ಕೆ B: API ಕೀ ಪೂರೈಕೆದಾರರು (ಪಾವತಿಸಬೇಕಾದವು)

1. ಪೂರೈಕೆದಾರರ ವೆಬ್ಸೈಟ್ನಿಂದ API ಕೀ ಪಡೆಯಿರಿ:

7. ಮುಗಿಯಿತು! ಈಗ ಆ ಪೂರೈಕೆದಾರರ ಮಾದರಿಗಳಿಗೆ ನೀವು ಪ್ರವೇಶವನ್ನು ಹೊಂದಿದ್ದೀರಿ.

### ಆಯ್ಕೆ D: ಸ್ಥಳೀಯ MLX ಮಾದರಿಗಳು (Apple Silicon)

ಏಕೀಕೃತ ಮೆಮೊರಿಯನ್ನು ಹೊಂದಿರುವ Apple Silicon Macಗಳಲ್ಲಿ, ಸಾಮಾನ್ಯ OpenAI-ಹೊಂದಾಣಿಕೆಯ ಸ್ಥಳೀಯ ಪೂರೈಕೆದಾರರಂತೆ `mlx-lm.server` ಮೂಲಕ ಚಾಲನೆಯಲ್ಲಿರುವ ಸ್ಥಳೀಯ MLX ಮಾದರಿಗಳಿಗೆ ಸಂಪರ್ಕಿಸುವುದನ್ನು OmniRoute ಬೆಂಬಲಿಸುತ್ತದೆ.

#### ಪೂರ್ವಾಪೇಕ್ಷಿತಗಳು

- 24GB+ ಏಕೀಕೃತ ಮೆಮೊರಿಯನ್ನು ಹೊಂದಿರುವ **Apple Silicon Mac** (M1/M2/M3/M4) ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ
- **uv** ಪ್ಯಾಕೇಜ್ ಮ್ಯಾನೇಜರ್: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### ತ್ವರಿತ ಪ್ರಾರಂಭ

1. **ಅವಲಂಬನೆಗಳನ್ನು ಇನ್ಸ್ಟಾಲ್ ಮಾಡಿ**:

   ```bash
   # ಈಗಾಗಲೇ ಇನ್ಸ್ಟಾಲ್ ಮಾಡದಿದ್ದರೆ uv ಅನ್ನು ಇನ್ಸ್ಟಾಲ್ ಮಾಡಿ
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm ಅನ್ನು ಇನ್ಸ್ಟಾಲ್ ಮಾಡಿ
   uv pip install mlx-lm
   ```

2. **MLX ಸರ್ವರ್ಗಳನ್ನು ಹಸ್ತಚಾಲಿತವಾಗಿ ಪ್ರಾರಂಭಿಸಿ** (ಪ್ರತ್ಯೇಕ ಟರ್ಮಿನಲ್ಗಳಲ್ಲಿ):

   ```bash
   # ಟರ್ಮಿನಲ್ 1: Gemma 4 26B A4B IT-QAT (ಪೋರ್ಟ್ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ಟರ್ಮಿನಲ್ 2: Qwen 3.8 27B MLX Mixed (ಪೋರ್ಟ್ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ಸಂಪರ್ಕಿಸಿ**:
   - **ಪೂರೈಕೆದಾರರು** → **ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ಎಂಬುದಕ್ಕೆ ಹೋಗಿ
   - **MLX Gemma 26B** ಅಥವಾ **MLX Qwen 3.8 27B** ಆಯ್ಕೆಮಾಡಿ
   - **ಸಂಪರ್ಕಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ (API ಕೀ ಅಗತ್ಯವಿಲ್ಲ)

4. **OpenCode ಜೊತೆಗೆ ಬಳಸಿ**:
   ```bash
   # OmniRoute ಬಳಸುವಂತೆ OpenCode ಅನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿ
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX ಮಾದರಿಗಳನ್ನು ಬಳಸಿ
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### ಮೆಮೊರಿ ನಿರ್ವಹಣೆ

**ಪ್ರಮುಖ**: 24GB ಏಕೀಕೃತ ಮೆಮೊರಿಯೊಂದಿಗೆ, ಒಂದೇ ಸಮಯದಲ್ಲಿ **ಒಂದು ದೊಡ್ಡ MLX ಮಾದರಿಯನ್ನು ಮಾತ್ರ ಚಲಾಯಿಸಬಹುದು**.

- Qwen 3.8 27B: ~13.1GB ಗರಿಷ್ಠ ಮೆಮೊರಿ

## ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸುವ ವಿಧಾನ (ಹಂತ-ಹಂತವಾಗಿ)

### ಹಂತ 1: ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ

ನಿಮ್ಮ ಬ್ರೌಸರ್ನಲ್ಲಿ `http://localhost:20128` ಗೆ ಹೋಗಿ.

### ಹಂತ 2: ಪೂರೈಕೆದಾರರ ವಿಭಾಗಕ್ಕೆ ಹೋಗಿ

ಸೈಡ್ಬಾರ್ನಲ್ಲಿರುವ **ಪೂರೈಕೆದಾರರು** ಕ್ಲಿಕ್ ಮಾಡಿ.

### ಹಂತ 3: ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ ಕ್ಲಿಕ್ ಮಾಡಿ

**+ ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ.

### ಹಂತ 4: ನಿಮ್ಮ ಪೂರೈಕೆದಾರರನ್ನು ಆಯ್ಕೆಮಾಡಿ

ಪಟ್ಟಿಯನ್ನು ವೀಕ್ಷಿಸಿ ಅಥವಾ ನಿಮ್ಮ ಪೂರೈಕೆದಾರರನ್ನು ಹುಡುಕಿ. ಅದರ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ.

### ಹಂತ 5: ರುಜುವಾತುಗಳನ್ನು ನಮೂದಿಸಿ

- **ಉಚಿತ ಪೂರೈಕೆದಾರರು**: ಯಾವುದೇ ರುಜುವಾತುಗಳು ಅಗತ್ಯವಿಲ್ಲ — ಕೇವಲ **ಸಂಪರ್ಕಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ
- **API ಕೀ ಪೂರೈಕೆದಾರರು**: ನಿಮ್ಮ API ಕೀಯನ್ನು ಅಂಟಿಸಿ
- **OAuth ಪೂರೈಕೆದಾರರು**: **OAuth ಮೂಲಕ ಸಂಪರ್ಕಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಲಾಗಿನ್ ಮಾಡಿ

### ಹಂತ 6: ಸಂಪರ್ಕವನ್ನು ಪರೀಕ್ಷಿಸಿ

ಅದು ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಲು **ಸಂಪರ್ಕವನ್ನು ಪರೀಕ್ಷಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ.

### ಹಂತ 7: ಪೂರ್ಣಗೊಂಡಿದೆ!

ನಿಮ್ಮ ಪೂರೈಕೆದಾರರು ಈಗ ಸಂಪರ್ಕಗೊಂಡಿದ್ದಾರೆ. ನೀವು ಅದನ್ನು `model: "auto"` ಜೊತೆಗೆ ಬಳಸಬಹುದು ಅಥವಾ ಪೂರೈಕೆದಾರರನ್ನು ನೇರವಾಗಿ ನಿರ್ದಿಷ್ಟಪಡಿಸಬಹುದು.

- **ಗುಣಮಟ್ಟ ಆಪ್ಟಿಮೈಸೇಶನ್** — ಪ್ರತಿ ಕಾರ್ಯಕ್ಕೂ OmniRoute ಅತ್ಯುತ್ತಮ ಪೂರೈಕೆದಾರರನ್ನು ಆಯ್ಕೆಮಾಡುತ್ತದೆ

## ಸಾಮಾನ್ಯ ಪ್ರಶ್ನೆಗಳು

### "OmniRoute ಬಳಸಲು ನಾನು ಹಣ ಪಾವತಿಸಬೇಕೇ?"

**ಇಲ್ಲ!** OmniRoute ಉಚಿತ ಮತ್ತು ಮುಕ್ತ-ಮೂಲವಾಗಿದೆ. ನೀವು ಏನನ್ನೂ ಪಾವತಿಸದೆ ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು (Kiro, OpenCode Free, Pollinations) ಬಳಸಬಹುದು. ನೀವು ಪಾವತಿಸಬೇಕಾದ ಪೂರೈಕೆದಾರರನ್ನು ಬಳಸಲು ಆಯ್ಕೆ ಮಾಡಿದರೆ ಮಾತ್ರ ಹಣ ಪಾವತಿಸಬೇಕು.

### "ನಾನು ಯಾವ ಪೂರೈಕೆದಾರರೊಂದಿಗೆ ಪ್ರಾರಂಭಿಸಬೇಕು?"

**Kiro AI** ನೊಂದಿಗೆ ಪ್ರಾರಂಭಿಸಿ — ಇದು ಉಚಿತವಾಗಿದೆ, API ಕೀಲಿಯ ಅಗತ್ಯವಿಲ್ಲ ಮತ್ತು Claude ಮಾದರಿಗಳಿಗೆ ಪ್ರವೇಶವನ್ನು ನೀಡುತ್ತದೆ. ನಂತರ ಅಗತ್ಯಕ್ಕೆ ತಕ್ಕಂತೆ ಹೆಚ್ಚಿನ ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ.

### "ನಾನು ಒಂದೇ ಸಮಯದಲ್ಲಿ ಹಲವು ಪೂರೈಕೆದಾರರನ್ನು ಬಳಸಬಹುದೇ?"

**ಹೌದು!** OmniRoute ನ ಮುಖ್ಯ ಉದ್ದೇಶವೇ ಅದು. ಹಲವು ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ ಮತ್ತು ಪ್ರತಿ ವಿನಂತಿಗೆ ಅತ್ಯುತ್ತಮವಾದುದನ್ನು OmniRoute ಆಯ್ಕೆ ಮಾಡಲು `model: "auto"` ಬಳಸಿ.

### "ಪೂರೈಕೆದಾರರ ಸೇವೆ ಸ್ಥಗಿತಗೊಂಡರೆ ಏನಾಗುತ್ತದೆ?"

OmniRoute ವಿಫಲವಾದ ಪೂರೈಕೆದಾರರನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬಿಟ್ಟುಬಿಡುತ್ತದೆ ಮತ್ತು ಮುಂದಿನದನ್ನು ಪ್ರಯತ್ನಿಸುತ್ತದೆ. ನೀವು ಏನನ್ನೂ ಮಾಡಬೇಕಾಗಿಲ್ಲ.

### "ಪೂರೈಕೆದಾರರ ಸಂಪರ್ಕವನ್ನು ನಾನು ಹೇಗೆ ಕಡಿತಗೊಳಿಸಲಿ?"

ಪೂರೈಕೆದಾರರು → ಪೂರೈಕೆದಾರರ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ → **ಸಂಪರ್ಕ ಕಡಿತಗೊಳಿಸಿ** ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ.

### "ನನ್ನ ಈಗಿನ API ಕೀಲಿಗಳನ್ನು ನಾನು ಬಳಸಬಹುದೇ?"

**ಹೌದು!** ನೀವು ಈಗಾಗಲೇ OpenAI, Anthropic, Google ಮುಂತಾದವುಗಳ API ಕೀಲಿಗಳನ್ನು ಹೊಂದಿದ್ದರೆ, ಅವುಗಳನ್ನು OmniRoute ನಲ್ಲಿ ಬಳಸಬಹುದು. ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸುವಾಗ ಅವುಗಳನ್ನು ಅಂಟಿಸಿ.
