> **ಸಂಕ್ಷಿಪ್ತವಾಗಿ**: ಸ್ಥಾಪಿಸಿ → ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ → ನಿಮ್ಮ IDE ಅನ್ನು OmniRoute ಕಡೆಗೆ ನಿರ್ದೇಶಿಸಿ. ಅಷ್ಟೇ.

## ಹಂತ 1: OmniRoute ಅನ್ನು ಸ್ಥಾಪಿಸಿ

ನೀವು ಬಯಸುವ ವಿಧಾನವನ್ನು ಆಯ್ಕೆಮಾಡಿ:

### ಆಯ್ಕೆ A: npm (ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ)

```bash
npm install -g omniroute
```

### ಆಯ್ಕೆ B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` ಎಂಬುದು ಅತ್ಯುನ್ನತ **ಪ್ರಕಟಿತ** ಸ್ಥಿರ SemVer ಆಗಿದೆ. ಇದು git `main` ಅನ್ನು ಅನುಸರಿಸುವುದಿಲ್ಲ. GitOps ಗಾಗಿ `diegosouzapw/omniroute:X.Y.Z` ಅನ್ನು ನಿರ್ದಿಷ್ಟ ಆವೃತ್ತಿಗೆ ನಿಗದಿಪಡಿಸಿ. [ಇಮೇಜ್ ಟ್ಯಾಗ್ಗಳು / ಬಿಡುಗಡೆ ಚಾನಲ್ಗಳು](../guides/DOCKER_GUIDE.md#release-channels) ನೋಡಿ.

### ಆಯ್ಕೆ C: ಮೂಲದಿಂದ

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

## ಹಂತ 2: OmniRoute ಅನ್ನು ಪ್ರಾರಂಭಿಸಿ

```bash
omniroute
```

OmniRoute `http://localhost:20128` ನಲ್ಲಿ ಪ್ರಾರಂಭವಾಗುತ್ತದೆ. ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ತೆರೆಯುತ್ತದೆ.

---

## ಹಂತ 3: ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ

ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸುವ ಮೂಲಕ ನೀವು OmniRoute ಅನ್ನು **ಯಾವುದೇ ಹಣ ಪಾವತಿಸದೆ** ಬಳಸಬಹುದು.

### ಆಯ್ಕೆ A: Kiro (ಉಚಿತ Claude — ಕ್ರೆಡಿಟ್ ಕಾರ್ಡ್ ಅಗತ್ಯವಿಲ್ಲ)

1. `http://localhost:20128` ನಲ್ಲಿ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ
2. **ಪೂರೈಕೆದಾರರು** → **ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ಗೆ ಹೋಗಿ
3. **Kiro AI** ಆಯ್ಕೆಮಾಡಿ
4. **ಸಂಪರ್ಕಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ (API ಕೀ ಅಗತ್ಯವಿಲ್ಲ!)
5. ಮುಗಿಯಿತು! ಈಗ ನೀವು Claude ಮಾದರಿಗಳಿಗೆ ಉಚಿತ ಪ್ರವೇಶವನ್ನು ಹೊಂದಿದ್ದೀರಿ.

### ಆಯ್ಕೆ B: OpenCode Free (ದೃಢೀಕರಣ ಅಗತ್ಯವಿಲ್ಲ)

1. `http://localhost:20128` ನಲ್ಲಿ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ
2. **ಪೂರೈಕೆದಾರರು** → **ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ಗೆ ಹೋಗಿ
3. **OpenCode Free** ಆಯ್ಕೆಮಾಡಿ
4. **ಸಂಪರ್ಕಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ (API ಕೀ ಅಗತ್ಯವಿಲ್ಲ!)
5. ಮುಗಿಯಿತು! ಈಗ ನೀವು ಹಲವು ಮಾದರಿಗಳಿಗೆ ಉಚಿತ ಪ್ರವೇಶವನ್ನು ಹೊಂದಿದ್ದೀರಿ.

### ಆಯ್ಕೆ C: Pollinations (ಕೀ ಅಗತ್ಯವಿಲ್ಲ)

1. `http://localhost:20128` ನಲ್ಲಿ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ
2. **ಪೂರೈಕೆದಾರರು** → **ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ಗೆ ಹೋಗಿ
3. **Pollinations** ಆಯ್ಕೆಮಾಡಿ
4. **ಸಂಪರ್ಕಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ (API ಕೀ ಅಗತ್ಯವಿಲ್ಲ!)
5. ಮುಗಿಯಿತು! ಈಗ ನೀವು GPT-5, Claude, Gemini ಮತ್ತು ಇನ್ನೂ ಹೆಚ್ಚಿನವುಗಳಿಗೆ ಉಚಿತ ಪ್ರವೇಶವನ್ನು ಹೊಂದಿದ್ದೀರಿ.

## ಹಂತ 4: ಇದು ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ

[API ಕೀಗಳು](http://localhost:20128/dashboard/api-manager) ಪುಟದಿಂದ ಹೊಸ ಕೀಯನ್ನು ರಚಿಸಿ. ಈ ಕೀ ಮತ್ತೊಮ್ಮೆ ಕಾಣಿಸದಿರುವುದರಿಂದ ಅದನ್ನು ಸುರಕ್ಷಿತವಾಗಿ ಸಂಗ್ರಹಿಸಿ. ಈ ಕೀ ಪರಿಕರಗಳು OmniRoute ಅನ್ನು ಪ್ರವೇಶಿಸಲು ಬಳಸುವುದೇ ಹೊರತು, ಅಪ್ಸ್ಟ್ರೀಮ್ ಪೂರೈಕೆದಾರರನ್ನು ಪ್ರವೇಶಿಸಲು ಅಲ್ಲ ಎಂಬುದನ್ನು ಗಮನಿಸಿ.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

ನೀವು ಸಂಪರ್ಕಿಸಿದ ಮಾದರಿಗಳು ಪಟ್ಟಿಯಲ್ಲಿ ಕಾಣಿಸಬೇಕು.

## ಹಂತ 5: ನಿಮ್ಮ IDE ಅಥವಾ CLI ಅನ್ನು OmniRoute ಕಡೆಗೆ ನಿರ್ದೇಶಿಸಿ

ನಿಮ್ಮ IDE ಅಥವಾ CLI ಪರಿಕರದಲ್ಲಿ ಹೀಗೆ ಹೊಂದಿಸಿ:

```
ಮೂಲ URL: http://localhost:20128/v1
API ಕೀ:  [ಡ್ಯಾಶ್ಬೋರ್ಡ್ → ಎಂಡ್ಪಾಯಿಂಟ್ಗಳಿಂದ ನಕಲಿಸಿ]
ಮಾದರಿ:    auto
```

ಅಷ್ಟೇ! ಈಗ ನಿಮ್ಮ IDE ಸ್ವಯಂಚಾಲಿತ ಪೂರೈಕೆದಾರರ ಆಯ್ಕೆಯೊಂದಿಗೆ OmniRoute ಅನ್ನು ಬಳಸುತ್ತದೆ.

### IDE ಉದಾಹರಣೆ: VSCode/Continue.dev

1. VSCode ನಲ್ಲಿ [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ವಿಸ್ತರಣೆಯನ್ನು ಸ್ಥಾಪಿಸಿ.
2. ಕೆಳಗಿನ ಸಾಲುಗಳನ್ನು ಸೇರಿಸಲು ನಿಮ್ಮ `~/.continue/config.yaml` ಅನ್ನು ನವೀಕರಿಸಿ:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev ಚಾಟ್ ಫಲಕದಲ್ಲಿ `OmniRoute - Auto` ಆಯ್ಕೆಮಾಡಿ; ನಂತರ ನೀವು OmniRoute ಗೆ ವಿನಂತಿಗಳನ್ನು ಕಳುಹಿಸಬಹುದು.
4. (ಐಚ್ಛಿಕ) ಓದುಗರಿಗಾಗಿ ಅಭ್ಯಾಸ — ಉಳಿದ ಎಲ್ಲಾ ಪೂರ್ವನಿರ್ಮಿತ ಸಂರಚನೆಗಳೊಂದಿಗೆ `config.yaml` ಅನ್ನು ನಿಮ್ಮ IDE ಮೂಲಕ ನವೀಕರಿಸಿ 😊

### CLI ಉದಾಹರಣೆ: Codex CLI

1. ನಿಮ್ಮ ಕಾರ್ಯಾಚರಣಾ ವ್ಯವಸ್ಥೆಯಲ್ಲಿ ಪರಿಸರ ಚರಾಂಶವನ್ನು ಶಾಶ್ವತವಾಗಿ ಹೊಂದಿಸಿ.
   macOS/Linux ಗಾಗಿ (ನಿಮ್ಮ `~/.bashrc` ಅಥವಾ `~/.zshrc` ಗೆ ಸೇರಿಸಿ):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows ಗಾಗಿ (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. ಈಗ OmniRoute ಗಾಗಿ ಸಂರಚಿಸಿದ Codex ಅನ್ನು ಪ್ರಾರಂಭಿಸೋಣ. ಇದನ್ನು ಚಲಾಯಿಸಿ:

```
omniroute launch-codex --model auto
```

ಎಂಡ್ಪಾಯಿಂಟ್ ಮತ್ತು API ಕೀಯನ್ನು ನಿರ್ದಿಷ್ಟಪಡಿಸಲು `codex` ಹಾಗೂ ಕಮಾಂಡ್ ಲೈನ್ ಪ್ಯಾರಾಮೀಟರ್ಗಳನ್ನು ಬಳಸಿ ನೀವು ಇದನ್ನು ಹಸ್ತಚಾಲಿತವಾಗಿ ಮಾಡಬಹುದು; ಆದರೆ ಮೇಲಿನ ಕಮಾಂಡ್ ಬಳಸಿದಾಗ, OmniRoute ನಿಮಗಾಗಿ ಎಲ್ಲವನ್ನೂ ನಿರ್ವಹಿಸುತ್ತದೆ.

ಇದೇ ಏಕ-ಕಮಾಂಡ್ ಪ್ರಾರಂಭ ವಿಧಾನವು ಸಾಮಾನ್ಯ ಲಾಂಚರ್ ಮೂಲಕ ಇತರ CLI ಗಳಿಗೂ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ — `omniroute run <target>` ಎಂಬುದು `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` ಮತ್ತು `gemini` ಅನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ ([CLI ಏಕೀಕರಣಗಳು](../guides/CLI-INTEGRATIONS.md) ನೋಡಿ).

3. ಈಗ CLI ವಿನಂತಿಗಳನ್ನು OmniRoute ಗೆ ಕಳುಹಿಸುತ್ತಿರಬೇಕು.

### ನಿಮ್ಮ ಪರಿಕರವು OmniRoute ಗೆ ರೂಟಿಂಗ್ ಮಾಡುತ್ತಿದೆ ಎಂಬುದನ್ನು ದೃಢೀಕರಿಸಿ

ಎಡ ಪಾರ್ಶ್ವಪಟ್ಟಿಯಿಂದ [ಮೇಲ್ವಿಚಾರಣೆ/ಲಾಗ್ಗಳು](http://localhost:20128/dashboard/logs) ಕ್ಲಿಕ್ ಮಾಡುವ ಮೂಲಕ ವಿನಂತಿಯ ವಿವರಗಳನ್ನು ನೋಡಬಹುದು. ಒಳಗೆ ಕ್ಲಿಕ್ ಮಾಡಿದರೆ ಇನ್ನಷ್ಟು ವಿವರಗಳು ಕಾಣಿಸುತ್ತವೆ. ಹೆಚ್ಚುವರಿಯಾಗಿ, ನಿಮ್ಮ ಮೆಚ್ಚಿನ ಹಾರ್ನೆಸ್ನಿಂದ ಯಾವ ಮಾಹಿತಿ ಕಳುಹಿಸಲ್ಪಡುತ್ತದೆ ಎಂಬುದನ್ನೂ ನೀವು ನೋಡಬಹುದು. ಇದು ಕಲಿಕೆ ಮತ್ತು ಡೀಬಗಿಂಗ್ ದೃಷ್ಟಿಯಿಂದ ಉಪಯುಕ್ತವಾಗಿದೆ.

## ಸಾಮಾನ್ಯ ಪ್ರಶ್ನೆಗಳು

### "ನನಗೆ API ಕೀ ಅಗತ್ಯವಿದೆಯೇ?"

**ಇಲ್ಲ!** ನೀವು ಯಾವುದೇ API ಕೀ ಇಲ್ಲದೆ ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು (Kiro, OpenCode Free, Pollinations) ಬಳಸಬಹುದು. ಅವುಗಳನ್ನು ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ಸಂಪರ್ಕಿಸಿ.

### "`auto` ಎಂದರೇನು?"

ಪ್ರತಿ ವಿನಂತಿಗೂ ಅತ್ಯುತ್ತಮ ಪೂರೈಕೆದಾರರನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಆಯ್ಕೆಮಾಡುವಂತೆ `auto` OmniRoute ಗೆ ಸೂಚಿಸುತ್ತದೆ. ಇದು ವೇಗ, ವೆಚ್ಚ, ಗುಣಮಟ್ಟ ಮತ್ತು ಲಭ್ಯತೆಯನ್ನು ಪರಿಗಣಿಸುತ್ತದೆ. ವಿವರಗಳಿಗಾಗಿ [Auto-Combo ಮಾರ್ಗದರ್ಶಿ](./AUTO-COMBO-GUIDE.md) ನೋಡಿ.

### "ಇದರ ವೆಚ್ಚ ಎಷ್ಟು?"

OmniRoute ಸ್ವತಃ **ಉಚಿತ ಮತ್ತು ಮುಕ್ತ ಮೂಲದ** ಸಾಫ್ಟ್ವೇರ್ ಆಗಿದೆ. ನೀವು ಬಳಸುವ ಪೂರೈಕೆದಾರರಿಗೆ ಮಾತ್ರ ಪಾವತಿಸುತ್ತೀರಿ. ಅನೇಕ ಪೂರೈಕೆದಾರರು ಉಚಿತ ಶ್ರೇಣಿಗಳನ್ನು ಹೊಂದಿದ್ದಾರೆ — [ಉಚಿತ ಶ್ರೇಣಿಗಳ ಮಾರ್ಗದರ್ಶಿ](./FREE-TIERS-GUIDE.md) ನೋಡಿ.

### "ನಾನು ಇದನ್ನು Claude Code / Cursor / Copilot ಜೊತೆಗೆ ಬಳಸಬಹುದೇ?"

**ಹೌದು!** OpenAI ಸ್ವರೂಪವನ್ನು ಬೆಂಬಲಿಸುವ ಯಾವುದೇ ಪರಿಕರದೊಂದಿಗೆ OmniRoute ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ. ಮೂಲ URL ಅನ್ನು `http://localhost:20128/v1` ಗೆ ಹೊಂದಿಸಿ. ನಿರ್ದಿಷ್ಟ ಸೆಟಪ್ ಸೂಚನೆಗಳಿಗಾಗಿ [CLI ಪರಿಕರಗಳ ಮಾರ್ಗದರ್ಶಿ](../reference/CLI-TOOLS.md) ನೋಡಿ.

### "ಪೂರೈಕೆದಾರರ ಸೇವೆ ಸ್ಥಗಿತಗೊಂಡರೆ ಏನಾಗುತ್ತದೆ?"

OmniRoute ವಿಫಲವಾದ ಪೂರೈಕೆದಾರರನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬಿಟ್ಟು ಮುಂದಿನದನ್ನು ಪ್ರಯತ್ನಿಸುತ್ತದೆ. ನೀವು ಏನನ್ನೂ ಮಾಡಬೇಕಾಗಿಲ್ಲ. ವಿವರಗಳಿಗಾಗಿ [Auto-Combo ಮಾರ್ಗದರ್ಶಿ](./AUTO-COMBO-GUIDE.md) ನೋಡಿ.
