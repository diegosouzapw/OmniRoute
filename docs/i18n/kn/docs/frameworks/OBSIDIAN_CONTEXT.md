## ಇದು ಏನು

OmniRoute ಒಂದು **Obsidian** ವಾಲ್ಟ್ಗೆ **ಸಂದರ್ಭ ಮೂಲವಾಗಿ** ಸಂಪರ್ಕಿಸುತ್ತದೆ — ಇದು
ಅಂತರ್ನಿರ್ಮಿತ MCP ಸರ್ವರ್ ಮೂಲಕ ಏಜೆಂಟ್ಗಳು ಓದುವ ಮತ್ತು ಬರೆಯುವ ಸ್ಥಳೀಯ Markdown ಜ್ಞಾನ
ಭಂಡಾರವಾಗಿದೆ. ಈ ಏಕೀಕರಣವು ಡೆಸ್ಕ್ಟಾಪ್ ಆ್ಯಪ್ನಲ್ಲಿ ಚಾಲನೆಯಲ್ಲಿರುವ **Obsidian Local REST API**
ಸಮುದಾಯ ಪ್ಲಗಿನ್ನೊಂದಿಗೆ ಸಂವಹನ ನಡೆಸುತ್ತದೆ. ಆದ್ದರಿಂದ ಏಜೆಂಟ್ಗಳು ಟಿಪ್ಪಣಿಗಳನ್ನು ಹುಡುಕಬಹುದು,
ಫೈಲ್ಗಳನ್ನು ಓದಬಹುದು/ಬರೆಯಬಹುದು/ಪ್ಯಾಚ್ ಮಾಡಬಹುದು, ವಾಲ್ಟ್ ಅನ್ನು ಪಟ್ಟಿ ಮಾಡಬಹುದು, ದೈನಂದಿನ/ಸಾಪ್ತಾಹಿಕ
ಆವರ್ತಕ ಟಿಪ್ಪಣಿಗಳೊಂದಿಗೆ ಕೆಲಸ ಮಾಡಬಹುದು, ಟ್ಯಾಗ್ಗಳನ್ನು ನಿರ್ವಹಿಸಬಹುದು, Obsidian ಕಮಾಂಡ್ಗಳನ್ನು
ಚಲಾಯಿಸಬಹುದು ಮತ್ತು (ಐಚ್ಛಿಕವಾಗಿ) ದ್ವಿಮುಖ ಡೆಸ್ಕ್ಟಾಪ್↔ಮೊಬೈಲ್ ವಾಲ್ಟ್ ಸಿಂಕ್ ಅನ್ನು ಸಂಯೋಜಿಸಬಹುದು.

ಕ್ಲೈಂಟ್ (`src/lib/obsidian/api.ts`) Local REST APIಯನ್ನು ಈ ವೈಶಿಷ್ಟ್ಯಗಳೊಂದಿಗೆ ಆವರಿಸುತ್ತದೆ:

- ತಾತ್ಕಾಲಿಕ `5xx` ದೋಷಗಳಿಗೆ **ಹಿನ್ನಡೆ ಅವಧಿಯೊಂದಿಗೆ ಮರುಪ್ರಯತ್ನ**, `AbortController` ಮೂಲಕ **30-ಸೆಕೆಂಡ್ ಕಾಲಮಿತಿ**.
- **ಟೈಪ್ ಮಾಡಿದ ದೋಷ ವರ್ಗೀಕರಣ** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- ಸಾಮಾನ್ಯ ಪೋರ್ಟ್ ತಪ್ಪನ್ನು ಸೂಚಿಸುವ ಸ್ನೇಹಪರ **"Obsidian ಅನ್ನು ತಲುಪಲು ಸಾಧ್ಯವಿಲ್ಲ" ಸಲಹೆ**
  (HTTP `27123`ನಲ್ಲಿ, `27124`ನಲ್ಲಿರುವ MCP ಎಂಡ್ಪಾಯಿಂಟ್ನಲ್ಲಿ **ಅಲ್ಲ**) ಮತ್ತು Tailscale ಸ್ವರೂಪ.
- ಸ್ಪೇಸ್ಗಳು/ಸ್ಲ್ಯಾಶ್ಗಳನ್ನು ಹೊಂದಿರುವ ಟಿಪ್ಪಣಿ ಪಥಗಳು ಸುರಕ್ಷಿತವಾಗಿರುವಂತೆ ವಾಲ್ಟ್ಗೆ ಸಂಬಂಧಿತ
  **ಪಥ ಎನ್ಕೋಡಿಂಗ್**.

## ಸೆಟಪ್

Obsidian ಟೋಕನ್ ಅಥವಾ ಮೂಲ URLಗಾಗಿ **ಯಾವುದೇ ಎನ್ವಿರಾನ್ಮೆಂಟ್ ವೇರಿಯಬಲ್ ಇಲ್ಲ** — ಎರಡನ್ನೂ
`src/lib/db/obsidian.ts` ಮೂಲಕ SQLite `key_value` ಕೋಷ್ಟಕದಲ್ಲಿ (ನೇಮ್ಸ್ಪೇಸ್ `obsidian`)
ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ. ಟೋಕನ್ ಅನ್ನು **ನಿಶ್ಚಲ ಸ್ಥಿತಿಯಲ್ಲಿ ಎನ್ಕ್ರಿಪ್ಟ್ ಮಾಡಲಾಗಿದೆ** (AES-256-GCM,
ಪ್ಲೇನ್ಟೆಕ್ಸ್ಟ್ ಹಿಮ್ಮುಖ-ಹೊಂದಾಣಿಕೆ ಫಾಲ್ಬ್ಯಾಕ್ನೊಂದಿಗೆ). Endpoint ಡ್ಯಾಶ್ಬೋರ್ಡ್ನ
**Context Sources** ಟ್ಯಾಬ್ನಿಂದ (`ObsidianSourceCard`) ಅಥವಾ ಸೆಟ್ಟಿಂಗ್ಗಳ REST API ಮೂಲಕ
ಕಾನ್ಫಿಗರ್ ಮಾಡಿ.

> [!IMPORTANT]
> **Obsidian Local REST API** ಪ್ಲಗಿನ್ ಅನ್ನು ಸ್ಥಾಪಿಸಿ ಚಾಲನೆಯಲ್ಲಿರಿಸಬೇಕು. ಅದರ REST
> ಇಂಟರ್ಫೇಸ್ **HTTP `127.0.0.1:27123`**ನಲ್ಲಿ ಆಲಿಸುತ್ತದೆ (ಡೀಫಾಲ್ಟ್ ಮೂಲ URL). ಪೋರ್ಟ್ `27124`
> ಒಂದು _ಪ್ರತ್ಯೇಕ_ MCP/HTTPS ಎಂಡ್ಪಾಯಿಂಟ್ ಆಗಿದ್ದು, ಸೆಟ್ಟಿಂಗ್ಗಳ ರೂಟ್ ಅದನ್ನು ಸ್ಪಷ್ಟವಾಗಿ
> ತಿರಸ್ಕರಿಸುತ್ತದೆ. ಮತ್ತೊಂದು ಸಾಧನದಿಂದ ಸಂಪರ್ಕಿಸುವುದಾದರೆ, `http://<tailscale-ip>:27123` ಬಳಸಿ.

### ಕಾನ್ಫಿಗರೇಶನ್ ಕೀಗಳು (SQLite `key_value`, ನೇಮ್ಸ್ಪೇಸ್ `obsidian`)

| ಕೀ                | ಉದ್ದೇಶ                                           | ಎನ್ಕ್ರಿಪ್ಟ್ ಮಾಡಲಾಗಿದೆಯೇ |
| ----------------- | ------------------------------------------------ | ----------------------- |
| `api_key`         | Local REST API ಬೇರರ್ ಟೋಕನ್                       | ಹೌದು                    |
| `base_url`        | REST ಮೂಲ URL (ಡೀಫಾಲ್ಟ್ `http://127.0.0.1:27123`) | ಇಲ್ಲ                    |
| `vault_path`      | ವಾಲ್ಟ್ ಡೈರೆಕ್ಟರಿಯ ನಿರಪೇಕ್ಷ ಪಥ (ಸಿಂಕ್ಗಾಗಿ)        | ಇಲ್ಲ                    |
| `webdav_username` | ರಚಿಸಲಾದ WebDAV ಬಳಕೆದಾರಹೆಸರು (ವಾಲ್ಟ್ ಸಿಂಕ್)       | ಇಲ್ಲ                    |
| `webdav_password` | ರಚಿಸಲಾದ WebDAV ಪಾಸ್ವರ್ಡ್ (ವಾಲ್ಟ್ ಸಿಂಕ್)          | ಹೌದು                    |
| `webdav_enabled`  | WebDAV ವಾಲ್ಟ್ ಸಿಂಕ್ ಸಕ್ರಿಯವಾಗಿದೆಯೇ               | ಇಲ್ಲ                    |

### REST ಮೂಲಕ ಕಾನ್ಫಿಗರ್ ಮಾಡಿ

```bash
# Local REST API ಟೋಕನ್ ಅನ್ನು ಉಳಿಸಿ + ಮೌಲ್ಯೀಕರಿಸಿ (POST ಸ್ಥಿತಿ ಪರಿಶೀಲನೆಯ ಮೂಲಕ ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# ಸಂಪರ್ಕ ಸ್ಥಿತಿಯನ್ನು ಪರಿಶೀಲಿಸಿ (connected, hasToken, baseUrl, vaultPath ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ)
curl http://localhost:20128/api/settings/obsidian

# ಸಂಪರ್ಕ ಕಡಿತಗೊಳಿಸಿ (ಸಂಗ್ರಹಿಸಿದ ಟೋಕನ್ ಅನ್ನು ತೆರವುಗೊಳಿಸುತ್ತದೆ)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

ಎಲ್ಲಾ ವಿಧಾನಗಳಿಗೂ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ದೃಢೀಕರಣ ಅಗತ್ಯವಿದೆ. `POST` ಪೋರ್ಟ್ `27124`ನಲ್ಲಿರುವ ಯಾವುದೇ
URL ಅನ್ನು ತಿರಸ್ಕರಿಸುತ್ತದೆ ಮತ್ತು ಶಾಶ್ವತವಾಗಿ ಸಂಗ್ರಹಿಸುವ ಮೊದಲು Local REST API ಸ್ಥಿತಿ
ಎಂಡ್ಪಾಯಿಂಟ್ಗೆ ಕರೆ ಮಾಡುವ ಮೂಲಕ ಟೋಕನ್ ಅನ್ನು ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ.

### WebDAV ವಾಲ್ಟ್ ಸಿಂಕ್

`src/app/api/settings/obsidian/webdav/route.ts` ಐಚ್ಛಿಕ WebDAV-ಬೆಂಬಲಿತ ವಾಲ್ಟ್ ಸಿಂಕ್ ಅನ್ನು
ನಿರ್ವಹಿಸುತ್ತದೆ (`src/lib/obsidianSync.ts` ಮೂಲಕ ಚಾಲಿತ). ಅದನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿದಾಗ OmniRoute
ಅನ್ನು ಸ್ಥಳೀಯ ವಾಲ್ಟ್ ಡೈರೆಕ್ಟರಿಗೆ ನಿರ್ದೇಶಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಯಾದೃಚ್ಛಿಕ WebDAV
ಬಳಕೆದಾರಹೆಸರು/ಪಾಸ್ವರ್ಡ್ ಜೋಡಿಯನ್ನು ರಚಿಸಲಾಗುತ್ತದೆ:

```bash
# ವಾಲ್ಟ್ ಡೈರೆಕ್ಟರಿಗಾಗಿ WebDAV ಸಿಂಕ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿ (ಬಳಕೆದಾರಹೆಸರು/ಪಾಸ್ವರ್ಡ್ ರಚಿಸುತ್ತದೆ)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV ಸಿಂಕ್ ಸ್ಥಿತಿಯನ್ನು ಪಡೆಯಿರಿ (ಸಕ್ರಿಯವಾಗಿರುವಾಗ ಮಾತ್ರ ರುಜುವಾತುಗಳನ್ನು ಹಿಂತಿರುಗಿಸಲಾಗುತ್ತದೆ)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV ಸಿಂಕ್ ಅನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸಿ (ರುಜುವಾತುಗಳು + ನಿರ್ವಹಿಸಲಾದ .stignore ಅನ್ನು ತೆರವುಗೊಳಿಸುತ್ತದೆ)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### ಪ್ರತಿ-API-ಕೀ ಸಂದರ್ಭ ಮೂಲ (ಐಚ್ಛಿಕ)

Obsidian ಕಾನ್ಫಿಗರೇಶನ್ ಅನ್ನು `api_key_context_sources` ಕೋಷ್ಟಕದ ಮೂಲಕ **ಪ್ರತಿ API ಕೀಗೆ**
ವ್ಯಾಪ್ತಿಗೊಳಿಸಬಹುದು (`src/lib/db/apiKeyContextSources.ts`). MCP ಕರೆ ದೃಢೀಕರಿಸಲಾದ API ಕೀ
ಐಡಿಯನ್ನು ಹೊಂದಿರುವಾಗ, `getObsidianConfigForApiKey()` ಆ ಕೀಗೆ ಸೇರಿದ ಸ್ವಂತ
ಟೋಕನ್/ಮೂಲ-URL/ವಾಲ್ಟ್-ಪಥಕ್ಕೆ (`source: "api_key"`) ಆದ್ಯತೆ ನೀಡುತ್ತದೆ; ಇಲ್ಲದಿದ್ದರೆ ಜಾಗತಿಕ
ಕಾನ್ಫಿಗರೇಶನ್ಗೆ (`source: "global"`) ಫಾಲ್ಬ್ಯಾಕ್ ಆಗುತ್ತದೆ.

## MCP ಪರಿಕರಗಳು (22)

`open-sse/mcp-server/tools/obsidianTools.ts` ನಲ್ಲಿ ವ್ಯಾಖ್ಯಾನಿಸಲಾಗಿದೆ. ಟೋಕನ್/base-URL ಅನ್ನು ಪ್ರತಿ ಕರೆಗೆ ಪರಿಹರಿಸಲಾಗುತ್ತದೆ (ಮೊದಲು ಪ್ರತಿ-API-key, ನಂತರ ಜಾಗತಿಕ). OmniRoute **sync server** ಅನ್ನು ಸಂಪರ್ಕಿಸುವ ಪರಿಕರಗಳಿಗೆ (ನಾಲ್ಕು `obsidian_sync_*` ಪರಿಕರಗಳು) ಹೆಚ್ಚುವರಿಯಾಗಿ OmniRoute ಸೆಟ್ಟಿಂಗ್ಗಳಲ್ಲಿ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾದ ಸಿಂಕ್ ದೃಢೀಕರಣ ಟೋಕನ್ ಅಗತ್ಯವಿದೆ.

### ಓದುವ ಪರಿಕರಗಳು (`read:obsidian`)

| ಪರಿಕರ                        | ವಿವರಣೆ                                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Local REST API ಅನ್ನು ತಲುಪಬಹುದೇ ಮತ್ತು ದೃಢೀಕರಿಸಲಾಗಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸುತ್ತದೆ.                         |
| `obsidian_search_simple`     | ಟಿಪ್ಪಣಿ ವಿಷಯದ ಪೂರ್ಣ-ಪಠ್ಯ ಹುಡುಕಾಟ; ಫೈಲ್ ಪಥಗಳೊಂದಿಗೆ ತುಣುಕುಗಳನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ.                   |
| `obsidian_search_structured` | JSON Logic ಅಭಿವ್ಯಕ್ತಿಯನ್ನು ಬಳಸಿ ಹುಡುಕುತ್ತದೆ (and/or/regex/path ಫಿಲ್ಟರ್ಗಳು).                        |
| `obsidian_read_note`         | ವಾಲ್ಟ್ಗೆ-ಸಂಬಂಧಿತ ಪಥದ ಮೂಲಕ ಟಿಪ್ಪಣಿಯನ್ನು ಓದುತ್ತದೆ; ಐಚ್ಛಿಕವಾಗಿ ನಿರ್ದಿಷ್ಟ ಶೀರ್ಷಿಕೆ/ಬ್ಲಾಕ್/frontmatter. |
| `obsidian_list_vault`        | ವಾಲ್ಟ್ನಲ್ಲಿರುವ ಫೈಲ್ಗಳು ಮತ್ತು ಡೈರೆಕ್ಟರಿಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ (ನಮೂದುಗಳ ವೃಕ್ಷ).                      |
| `obsidian_get_document_map`  | ಟಿಪ್ಪಣಿಯ ಶೀರ್ಷಿಕೆ ರಚನೆಯನ್ನು ಶೀರ್ಷಿಕೆಗಳು → ಸಾಲು ಸಂಖ್ಯೆಗಳ ನಕ್ಷೆಯಾಗಿ ಪಡೆಯುತ್ತದೆ.                      |
| `obsidian_get_note_metadata` | ಪೂರ್ಣ ವಿಷಯವಿಲ್ಲದೆ frontmatter, ಟ್ಯಾಗ್ಗಳು, ಲಿಂಕ್ಗಳು, ಅಕ್ಷರ/ಪದಗಳ ಎಣಿಕೆಯನ್ನು ಪಡೆಯುತ್ತದೆ.              |
| `obsidian_get_active_file`   | Obsidian ನಲ್ಲಿ ಪ್ರಸ್ತುತ ಸಕ್ರಿಯವಾಗಿರುವ ಫೈಲ್ನ ಪಥ + ವಿಷಯವನ್ನು ಪಡೆಯುತ್ತದೆ.                             |
| `obsidian_get_periodic_note` | ದಿನಾಂಕಕ್ಕಾಗಿ ದೈನಂದಿನ/ಸಾಪ್ತಾಹಿಕ/ಮಾಸಿಕ ಆವರ್ತಕ ಟಿಪ್ಪಣಿಯನ್ನು ಪಡೆಯುತ್ತದೆ (ಬಿಟ್ಟುಬಿಟ್ಟರೆ ಇಂದು).          |
| `obsidian_get_tags`          | ಎಲ್ಲಾ ವಾಲ್ಟ್ ಟ್ಯಾಗ್ಗಳನ್ನು ಅವುಗಳ ಆವರ್ತನಗಳೊಂದಿಗೆ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ.                                    |
| `obsidian_list_commands`     | ಲಭ್ಯವಿರುವ Obsidian ಕಮಾಂಡ್ ID ಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ (`obsidian_execute_command` ಜೊತೆಗೆ ಬಳಸಿ).      |
| `obsidian_sync_status`       | OmniRoute sync server ಸ್ಥಿತಿ: ಚಾಲನೆಯಲ್ಲಿದೆಯೇ, ವಾಲ್ಟ್ ಹೆಸರು, ಪೋರ್ಟ್, ಕಾರ್ಯಾವಧಿ, ಕೊನೆಯ ಸಿಂಕ್.        |
| `obsidian_sync_conflicts`    | ಪರಿಹರಿಸದ ಸಿಂಕ್ ಸಂಘರ್ಷಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ (ಪಥ, ಸಂಘರ್ಷ ಪಥ, ಪತ್ತೆಯಾದ ಸಮಯ).                         |

### ಬರೆಯುವ ಪರಿಕರಗಳು (`write:obsidian`)

| ಪರಿಕರ                            | ವಿವರಣೆ                                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | ನೀಡಲಾದ Markdown ವಿಷಯದೊಂದಿಗೆ ಟಿಪ್ಪಣಿಯನ್ನು ರಚಿಸುತ್ತದೆ ಅಥವಾ ತಿದ್ದಿ ಬರೆಯುತ್ತದೆ.                                |
| `obsidian_append_note`           | ಟಿಪ್ಪಣಿಗೆ ವಿಷಯವನ್ನು ಸೇರಿಸುತ್ತದೆ; ಐಚ್ಛಿಕವಾಗಿ ನಿರ್ದಿಷ್ಟ ಶೀರ್ಷಿಕೆ/ಬ್ಲಾಕ್ಗೆ.                                   |
| `obsidian_patch_note`            | ಶೀರ್ಷಿಕೆ, ಬ್ಲಾಕ್ ಅಥವಾ frontmatter ಕ್ಷೇತ್ರದಲ್ಲಿ ನಿಖರವಾಗಿ ಸೇರಿಸುತ್ತದೆ/ಮುಂದೆ ಸೇರಿಸುತ್ತದೆ/ಬದಲಾಯಿಸುತ್ತದೆ.       |
| `obsidian_delete_note`           | ವಾಲ್ಟ್ನಿಂದ ಟಿಪ್ಪಣಿಯನ್ನು ಶಾಶ್ವತವಾಗಿ ಅಳಿಸುತ್ತದೆ.                                                             |
| `obsidian_move_note`             | ವಾಲ್ಟ್ನೊಳಗೆ ಟಿಪ್ಪಣಿಯನ್ನು ಸ್ಥಳಾಂತರಿಸುತ್ತದೆ ಅಥವಾ ಮರುಹೆಸರಿಸುತ್ತದೆ.                                            |
| `obsidian_execute_command`       | ಅದರ ಕಮಾಂಡ್ ID ಮೂಲಕ Obsidian ಕಮಾಂಡ್ ಅನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸುತ್ತದೆ.                                               |
| `obsidian_open_file`             | Obsidian ನಲ್ಲಿ ಫೈಲ್ ತೆರೆಯುತ್ತದೆ (ಅದು ಅಸ್ತಿತ್ವದಲ್ಲಿಲ್ಲದಿದ್ದರೆ ರಚಿಸುತ್ತದೆ).                                  |
| `obsidian_sync_trigger`          | ತಕ್ಷಣದ ದ್ವಿದಿಶ desktop↔mobile ವಾಲ್ಟ್ ಸಿಂಕ್ ಅನ್ನು ಪ್ರಚೋದಿಸುತ್ತದೆ.                                           |
| `obsidian_sync_resolve_conflict` | ಸಿಂಕ್ ಸಂಘರ್ಷವನ್ನು ಪರಿಹರಿಸುತ್ತದೆ: `local` (mobile), `remote` (desktop), ಅಥವಾ `keep-both` ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳಿ. |

> [!NOTE]
> `obsidian_patch_note` ಗುರಿಗಳು `heading | block | frontmatter` ಎಂಬ `targetType`
> ಮತ್ತು `append | prepend | replace` ಎಂಬ `operation` ಅನ್ನು, ಐಚ್ಛಿಕ
> `createTargetIfMissing` ಜೊತೆಗೆ ಸ್ವೀಕರಿಸುತ್ತವೆ. ನಾಲ್ಕು `obsidian_sync_*` ಪರಿಕರಗಳು ಸ್ಥಳೀಯ ಸಿಂಕ್
> ಸರ್ವರ್ನೊಂದಿಗೆ (`http://127.0.0.1:27781` ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ) ಸಂವಹನ ಮಾಡುತ್ತವೆ ಮತ್ತು ಸಿಂಕ್ ಟೋಕನ್ ಅಗತ್ಯವಿದೆ.

### ವ್ಯಾಪ್ತಿಗಳು

ಓದುವ ಪರಿಕರಗಳಿಗೆ `read:obsidian` ಅಗತ್ಯವಿದೆ; ಬರೆಯುವ ಪರಿಕರಗಳಿಗೆ `write:obsidian` ಅಗತ್ಯವಿದೆ. ಜಾರಿಗೊಳಿಸುವಿಕೆಯು Notion ನಂತೆಯೇ ಇದೆ — ಇದನ್ನು `open-sse/mcp-server/server.ts` ನಲ್ಲಿನ `withScopeEnforcement()` ನಿರ್ವಹಿಸುತ್ತದೆ, `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ಮೂಲಕ ನಿಯಂತ್ರಿಸಲಾಗುತ್ತದೆ, ಅನುಮತಿಸಲಾದ ವ್ಯಾಪ್ತಿಗಳನ್ನು `OMNIROUTE_MCP_SCOPES` ಅಥವಾ API key ಯ ವ್ಯಾಪ್ತಿ ಸಂದರ್ಭದಿಂದ ಪಡೆಯಲಾಗುತ್ತದೆ. [MCP-SERVER.md](./MCP-SERVER.md) ನೋಡಿ.

## ಎಂಡ್ಪಾಯಿಂಟ್ಗಳು

| ವಿಧಾನ    | ಪಥ                              | ಉದ್ದೇಶ                                                                       |

| `DELETE` | `/api/settings/obsidian/webdav` | WebDAV ಸಿಂಕ್ ಅನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ.                                     |

> Local REST API (ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ `base_url`) ಮೂಲಕ ಮತ್ತು ಮೇಲಿನ MCP ಪರಿಕರಗಳ ಮೂಲಕ ಪ್ರವೇಶಿಸಲಾಗುತ್ತದೆ —
> ಯಾವುದೇ ಸಾರ್ವಜನಿಕ `/v1` Obsidian ಪ್ರಾಕ್ಸಿ ಎಂಡ್ಪಾಯಿಂಟ್ ಇಲ್ಲ.

## ಬಳಕೆಯ ಸಂದರ್ಭಗಳು

- **ವಾಲ್ಟ್-ಆಧಾರಿತ ಉತ್ತರಗಳು** — `obsidian_search_simple` / `obsidian_search_structured`
  ನಂತರ `obsidian_read_note`, ಇದರಿಂದ ಏಜೆಂಟ್ ನಿಮ್ಮ ನೈಜ ಟಿಪ್ಪಣಿಗಳ ಆಧಾರದ ಮೇಲೆ ಉತ್ತರಿಸುತ್ತದೆ.
- **ಟಿಪ್ಪಣಿ ರಚನೆ / ದಿನಚರಿ ಬರವಣಿಗೆ** — ಏಜೆಂಟ್ ಔಟ್ಪುಟ್, ಸಾರಾಂಶಗಳು ಅಥವಾ ದೈನಂದಿನ ಟಿಪ್ಪಣಿಗಳನ್ನು
  (`obsidian_get_periodic_note`) ವಾಲ್ಟ್ಗೆ ದಾಖಲಿಸಲು `obsidian_write_note`, `obsidian_append_note`, ಅಥವಾ
  ನಿಖರವಾದ `obsidian_patch_note`.
- **ವಾಲ್ಟ್ ನ್ಯಾವಿಗೇಶನ್** — ಓದುವ/ಬರೆಯುವ ಮೊದಲು ರಚನೆಯನ್ನು ಅನ್ವೇಷಿಸಲು `obsidian_list_vault`, `obsidian_get_document_map`, ಮತ್ತು
  `obsidian_get_tags`.
- **Obsidian ಸ್ವಯಂಚಾಲನೆ** — ಏಜೆಂಟ್ನಿಂದ ಪ್ಲಗಿನ್ಗಳು/ಕಮಾಂಡ್ಗಳನ್ನು ಚಾಲನೆ ಮಾಡಲು `obsidian_list_commands` + `obsidian_execute_command`;
  UI ಯಲ್ಲಿ ಟಿಪ್ಪಣಿಯನ್ನು ಪ್ರದರ್ಶಿಸಲು `obsidian_open_file`.
- **ಮೊಬೈಲ್ ಸಿಂಕ್** — WebDAV ಸಿಂಕ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿ, ನಂತರ ಡೆಸ್ಕ್ಟಾಪ್↔ಮೊಬೈಲ್ ಅನ್ನು ಸಮನ್ವಯಗೊಳಿಸಲು ಮತ್ತು ಸಂಘರ್ಷಗಳನ್ನು ಪರಿಹರಿಸಲು
  `obsidian_sync_trigger` / `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`.
