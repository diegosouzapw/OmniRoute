## ಇದು ಏನು

OmniRoute ಒಂದು **Notion** ಕಾರ್ಯಸ್ಥಳಕ್ಕೆ **ಸಂದರ್ಭ ಮೂಲವಾಗಿ** ಸಂಪರ್ಕಿಸಬಹುದು — ಇದು ಏಜೆಂಟ್ಗಳು ಅಂತರ್ನಿರ್ಮಿತ MCP ಸರ್ವರ್ ಮೂಲಕ ಪ್ರವೇಶಿಸುವ ಓದಲು/ಬರೆಯಲು ಸಾಧ್ಯವಾದ ಜ್ಞಾನ ಭಂಡಾರವಾಗಿದೆ. Notion ಇಂಟಿಗ್ರೇಶನ್ ಟೋಕನ್ ಅನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ನಂತರ, MCP ಪರಿಕರಗಳು LLMಗೆ ಪುಟಗಳು ಮತ್ತು ಡೇಟಾಬೇಸ್ಗಳನ್ನು ಹುಡುಕಲು, ಪುಟದ ವಿಷಯ ಮತ್ತು ಬ್ಲಾಕ್ ಟ್ರೀಗಳನ್ನು ಓದಲು, ಫಿಲ್ಟರ್ಗಳು/ವಿಂಗಡಣೆಗಳೊಂದಿಗೆ ಡೇಟಾಬೇಸ್ಗಳನ್ನು ಕ್ವೆರಿ ಮಾಡಲು ಮತ್ತು ಹೊಸ ಬ್ಲಾಕ್ಗಳನ್ನು ಸೇರಿಸಲು ಅವಕಾಶ ನೀಡುತ್ತವೆ — ಇವೆಲ್ಲವನ್ನೂ OmniRoute ಮೂಲಕ ಪ್ರಾಕ್ಸಿ ಮಾಡಲಾಗುತ್ತದೆ (ಮರುಪ್ರಯತ್ನ, ಸಮಯ ಮಿತಿ ಮತ್ತು ದೋಷ ವರ್ಗೀಕರಣದೊಂದಿಗೆ), ಆದ್ದರಿಂದ ಮಾದರಿಯು ಎಂದಿಗೂ Notion API ಅನ್ನು ನೇರವಾಗಿ ಪ್ರವೇಶಿಸುವುದಿಲ್ಲ.

ಈ ಇಂಟಿಗ್ರೇಶನ್ ಅಧಿಕೃತ Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) ಮೇಲಿನ ತೆಳುವಾದ, ದೃಢಗೊಳಿಸಲಾದ ರ್ಯಾಪರ್ ಆಗಿದೆ. ಕ್ಲೈಂಟ್
(`src/lib/notion/api.ts`) ಈ ಕೆಳಗಿನವುಗಳನ್ನು ಸೇರಿಸುತ್ತದೆ:

- `429` ಮತ್ತು `5xx` ಗಾಗಿ **ಎಕ್ಸ್ಪೊನೆನ್ಶಿಯಲ್ ಬ್ಯಾಕ್ಆಫ್ನೊಂದಿಗೆ ಮರುಪ್ರಯತ್ನ** (ಗರಿಷ್ಠ 3 ಪ್ರಯತ್ನಗಳು).
- `AbortController` ಮೂಲಕ **55-ಸೆಕೆಂಡ್ ವಿನಂತಿ ಸಮಯ ಮಿತಿ**.
- **ಟೈಪ್ ಮಾಡಿದ ದೋಷ ವರ್ಗೀಕರಣ** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  ಸೂಚನೆಗಳನ್ನು ಪಾಲಿಸುತ್ತದೆ), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- ಹೊರತೋರಿಸುವ ಮೊದಲು ಸ್ಟ್ಯಾಕ್-ಟ್ರೇಸ್ನಂತಹ ತುಣುಕುಗಳನ್ನು ತೆಗೆದುಹಾಕುವ **ಸಂದೇಶ ಸ್ವಚ್ಛೀಕರಣ**.

## ಸೆಟಪ್

Notion ಟೋಕನ್ಗಾಗಿ **ಯಾವುದೇ ಪರಿಸರ ವೇರಿಯಬಲ್ ಇಲ್ಲ** — ಅದನ್ನು
`src/lib/db/notion.ts` ಮೂಲಕ SQLite `key_value` ಟೇಬಲ್ನಲ್ಲಿ (ನೇಮ್ಸ್ಪೇಸ್ `notion`, ಕೀ `integration_token`) ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ. ಅದನ್ನು Endpoint
ಡ್ಯಾಶ್ಬೋರ್ಡ್ನ **Context Sources** ಟ್ಯಾಬ್ನಿಂದ (`ObsidianSourceCard` ನ ಸಹೋದರ `NotionSourceCard`) ಅಥವಾ ಸೆಟ್ಟಿಂಗ್ಗಳ REST API ಮೂಲಕ ಕಾನ್ಫಿಗರ್ ಮಾಡಿ.

> [!NOTE]
> ಈ ಟೋಕನ್ ಒಂದು **Notion ಆಂತರಿಕ ಇಂಟಿಗ್ರೇಶನ್ ಟೋಕನ್** ಆಗಿದೆ.
> <https://www.notion.com/my-integrations> ನಲ್ಲಿ ಇಂಟಿಗ್ರೇಶನ್ ರಚಿಸಿ, ನಂತರ OmniRoute ಪ್ರವೇಶಿಸಬೇಕಾದ ಪುಟಗಳು/ಡೇಟಾಬೇಸ್ಗಳನ್ನು ಆ ಇಂಟಿಗ್ರೇಶನ್ನೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳಿ (Notion ನ ಅನುಮತಿ ಮಾದರಿಯು ಹಂಚಿಕೆ-ಆಧಾರಿತವಾಗಿದೆ,
> ಸಂಪೂರ್ಣ ಕಾರ್ಯಸ್ಥಳ-ವ್ಯಾಪ್ತಿಯದ್ದಲ್ಲ).

### REST ಮೂಲಕ ಕಾನ್ಫಿಗರ್ ಮಾಡಿ

```bash
# ಇಂಟಿಗ್ರೇಶನ್ ಟೋಕನ್ ಅನ್ನು ಉಳಿಸಿ + ಮೌಲ್ಯೀಕರಿಸಿ (POST ಪರೀಕ್ಷಾ ಹುಡುಕಾಟವನ್ನು ನಡೆಸುವ ಮೂಲಕ ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# ಸಂಪರ್ಕ ಸ್ಥಿತಿಯನ್ನು ಪರಿಶೀಲಿಸಿ
curl http://localhost:20128/api/settings/notion

# ಸಂಪರ್ಕ ಕಡಿತಗೊಳಿಸಿ (ಸಂಗ್ರಹಿಸಲಾದ ಟೋಕನ್ ಅನ್ನು ತೆರವುಗೊಳಿಸುತ್ತದೆ)
curl -X DELETE http://localhost:20128/api/settings/notion
```

ಎಲ್ಲಾ ಮೂರು ವಿಧಾನಗಳಿಗೆ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ದೃಢೀಕರಣ (`isAuthenticated`) ಅಗತ್ಯವಿದೆ. `POST` ನಲ್ಲಿ,
OmniRoute ಟೋಕನ್ ಅನ್ನು ಉಳಿಸಿ ತಕ್ಷಣವೇ 1-ಫಲಿತಾಂಶದ ಪರೀಕ್ಷಾ ಹುಡುಕಾಟವನ್ನು ನಡೆಸುತ್ತದೆ; Notion
ದೋಷ ಆಬ್ಜೆಕ್ಟ್ ಅನ್ನು ಹಿಂದಿರುಗಿಸಿದರೆ, ಟೋಕನ್ ಅನ್ನು ತೆರವುಗೊಳಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಕರೆ `400` ದೊಂದಿಗೆ ವಿಫಲಗೊಳ್ಳುತ್ತದೆ.

## MCP ಪರಿಕರಗಳು (6)

`open-sse/mcp-server/tools/notionTools.ts` ನಲ್ಲಿ ವ್ಯಾಖ್ಯಾನಿಸಲಾಗಿದೆ. ಕರೆ ಮಾಡುವ ಸಮಯದಲ್ಲಿ `getNotionToken()` ಮೂಲಕ ಟೋಕನ್ ಅನ್ನು ಪರಿಹರಿಸಲಾಗುತ್ತದೆ; ಯಾವುದನ್ನೂ ಕಾನ್ಫಿಗರ್ ಮಾಡದಿದ್ದರೆ ಪರಿಕರವು
`"Notion ಇಂಟಿಗ್ರೇಶನ್ ಟೋಕನ್ ಅನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿಲ್ಲ. ಅದನ್ನು Settings > Context Sources ನಲ್ಲಿ ಹೊಂದಿಸಿ."` ಎಂಬ ದೋಷವನ್ನು ಎಸೆಯುತ್ತದೆ.

| ಪರಿಕರ                        | ಸ್ಕೋಪ್         | ವಿವರಣೆ                                                                                                                     |
| ---------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | ಪಠ್ಯ ಕ್ವೆರಿ ಮೂಲಕ ಪುಟಗಳು ಮತ್ತು ಡೇಟಾಬೇಸ್ಗಳನ್ನು ಹುಡುಕುತ್ತದೆ (ಶೀರ್ಷಿಕೆಗಳು, IDಗಳು, URLಗಳನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತದೆ). ಪುಟೀಕರಿಸಲಾಗಿದೆ. |
| `notion_get_page`            | `read:notion`  | ಪುಟವೊಂದರ ID ಮೂಲಕ ಅದರ ವಿಷಯ ಮತ್ತು ಮೆಟಾಡೇಟಾವನ್ನು ಪಡೆಯುತ್ತದೆ.                                                                  |
| `notion_list_block_children` | `read:notion`  | ಬ್ಲಾಕ್ ಅಥವಾ ಪುಟದ ಎಲ್ಲಾ ಚೈಲ್ಡ್ ಬ್ಲಾಕ್ಗಳನ್ನು (ಬ್ಲಾಕ್ ಟ್ರೀ) ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ. ಪುಟೀಕರಿಸಲಾಗಿದೆ.                                  |
| `notion_query_database`      | `read:notion`  | ಐಚ್ಛಿಕ `filter` + `sorts` ನೊಂದಿಗೆ ಡೇಟಾಬೇಸ್ ಅನ್ನು ಕ್ವೆರಿ ಮಾಡುತ್ತದೆ (Notion API ಸ್ವರೂಪ). ಪುಟೀಕರಿಸಲಾಗಿದೆ.                     |
| `notion_get_database`        | `read:notion`  | ID ಮೂಲಕ ಡೇಟಾಬೇಸ್ನ ಸ್ಕೀಮಾ/ಮೆಟಾಡೇಟಾವನ್ನು ಪಡೆಯುತ್ತದೆ.                                                                         |
| `notion_append_blocks`       | `write:notion` | ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಬ್ಲಾಕ್ ಅಥವಾ ಪುಟಕ್ಕೆ ಚೈಲ್ಡ್ ಬ್ಲಾಕ್ಗಳನ್ನು ಸೇರಿಸುತ್ತದೆ (ಪ್ರತಿ ವಿನಂತಿಗೆ ಗರಿಷ್ಠ 100 ಬ್ಲಾಕ್ಗಳು).                |

### ಇನ್ಪುಟ್ ಪ್ಯಾರಾಮೀಟರ್ಗಳು

- `notion_search` — `query` (1–500 ಅಕ್ಷರಗಳು), `pageSize` (1–100, ಡೀಫಾಲ್ಟ್ 20),
  `startCursor` (ಐಚ್ಛಿಕ).
- `notion_get_page` — `pageId` (32-ಅಕ್ಷರದ ಹೆಕ್ಸ್ ಅಥವಾ UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, ಡೀಫಾಲ್ಟ್ 50),
  `startCursor` (ಐಚ್ಛಿಕ).
- `notion_query_database` — `databaseId`, `filter` (ಐಚ್ಛಿಕ, Notion ಫಿಲ್ಟರ್ ಸ್ವರೂಪ),
  `sorts` (ಐಚ್ಛಿಕ ಅರೆ), `pageSize` (1–100, ಡೀಫಾಲ್ಟ್ 50), `startCursor` (ಐಚ್ಛಿಕ).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (ಬ್ಲಾಕ್ ಆಬ್ಜೆಕ್ಟ್ಗಳ ಅರೆ),
  `after` (ಐಚ್ಛಿಕ ಸ್ಥಾನ).

### ಸ್ಕೋಪ್ಗಳು

ಓದುವ ಪರಿಕರಗಳಿಗೆ `read:notion` ಮತ್ತು ಬರೆಯುವ ಪರಿಕರಕ್ಕೆ `write:notion` ಅಗತ್ಯವಿದೆ.
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` ಆಗಿರುವಾಗ ಮಾತ್ರ
`open-sse/mcp-server/server.ts` ನಲ್ಲಿನ `withScopeEnforcement()` ಮೂಲಕ ಸ್ಕೋಪ್ಗಳನ್ನು ಜಾರಿಗೊಳಿಸಲಾಗುತ್ತದೆ; ಕರೆ ಮಾಡುವವರ ಅನುಮತಿಸಲಾದ ಸ್ಕೋಪ್ಗಳು `OMNIROUTE_MCP_SCOPES` (ಅಲ್ಪವಿರಾಮದಿಂದ ಪ್ರತ್ಯೇಕಿಸಿದ) ಅಥವಾ ದೃಢೀಕರಿಸಲಾದ API ಕೀಯ ಸ್ಕೋಪ್ ಸಂದರ್ಭದಿಂದ ಬರುತ್ತವೆ. ಸಂಪೂರ್ಣ ಸ್ಕೋಪ್ ಮಾದರಿಗಾಗಿ [MCP-SERVER.md](./MCP-SERVER.md) ನೋಡಿ.

| `POST`   | `/api/settings/notion` | ಏಕೀಕರಣ ಟೋಕನ್ ಅನ್ನು ಉಳಿಸಿ + ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ.                  |
| `DELETE` | `/api/settings/notion` | ಸಂಪರ್ಕ ಕಡಿತಗೊಳಿಸುತ್ತದೆ (ಉಳಿಸಿದ ಟೋಕನ್ ಅನ್ನು ತೆರವುಗೊಳಿಸುತ್ತದೆ). |

> ಇವು ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಸೆಟ್ಟಿಂಗ್ಗಳ ರೂಟ್ಗಳು. ಸಾರ್ವಜನಿಕ `/v1` Notion ಪ್ರಾಕ್ಸಿ
> ಎಂಡ್ಪಾಯಿಂಟ್ **ಇಲ್ಲ** — ಮೇಲಿನ MCP ಪರಿಕರಗಳ ಮೂಲಕ ಮಾತ್ರ Notion ಅನ್ನು ಪ್ರವೇಶಿಸಲಾಗುತ್ತದೆ.

## ಬಳಕೆಯ ಸಂದರ್ಭಗಳು

- **ಜ್ಞಾನ-ಆಧಾರಿತ ಉತ್ತರಗಳು** — ಉತ್ತರಿಸುವ ಮೊದಲು ಏಜೆಂಟ್ಗೆ ಕಾರ್ಯಸ್ಥಳದಲ್ಲಿ `notion_search` ಮಾಡಲು ಮತ್ತು
  ಅತ್ಯುತ್ತಮ ಫಲಿತಾಂಶವನ್ನು `notion_get_page` ಮಾಡಲು ಅವಕಾಶ ನೀಡಿ, ಇದರಿಂದ ಪ್ರತಿಕ್ರಿಯೆಗಳು ನೈಜ ಆಂತರಿಕ ದಾಖಲೆಗಳನ್ನು ಉಲ್ಲೇಖಿಸುತ್ತವೆ.
- **ಡೇಟಾಬೇಸ್-ಆಧಾರಿತ ಕಾರ್ಯವಿಧಾನಗಳು** — ಫಿಲ್ಟರ್ಗಳು + ವಿಂಗಡಣೆಗಳೊಂದಿಗೆ ಕಾರ್ಯಗಳು/CRM ಡೇಟಾಬೇಸ್ ಅನ್ನು
  `notion_query_database` ಮಾಡಿ, ನಂತರ ಸಾಲುಗಳನ್ನು ಸಾರಾಂಶಗೊಳಿಸಿ ಅಥವಾ ಆದ್ಯತೆಯಂತೆ ವರ್ಗೀಕರಿಸಿ.
- **ಮರಳಿ ಬರೆಯುವಿಕೆ / ಲಾಗಿಂಗ್** — ಸಭೆಯ ಟಿಪ್ಪಣಿಗಳು, ರನ್
  ಸಾರಾಂಶಗಳು ಅಥವಾ ಏಜೆಂಟ್ ಔಟ್ಪುಟ್ ಅನ್ನು ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಪುಟಕ್ಕೆ ಸೇರಿಸಲು `notion_append_blocks` ಬಳಸಿ (ಸೇರಿಸುವಿಕೆ ಮಾತ್ರ; ಯಾವುದೇ ವಿನಾಶಕಾರಿ ಸಂಪಾದನೆಗಳಿಲ್ಲ).
- **ರಚನೆ ಅನ್ವೇಷಣೆ** — ಪುಟದ ಬ್ಲಾಕ್ ವೃಕ್ಷವನ್ನು ಕ್ರಮಿಸಲು `notion_list_block_children` ಬಳಸಿ,
  ಅಥವಾ ಡೇಟಾಬೇಸ್ ಅನ್ನು ಪ್ರಶ್ನಿಸುವ ಮೊದಲು ಅದರ ಪ್ರಾಪರ್ಟಿ ಸ್ಕೀಮಾವನ್ನು ಕಂಡುಹಿಡಿಯಲು `notion_get_database` ಬಳಸಿ.
