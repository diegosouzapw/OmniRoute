## ಅವಲೋಕನ

Playground Studio, `/dashboard/playground` ಅನ್ನು ಸರಳ Monaco-ಆಧಾರಿತ ಎಡಿಟರ್ನಿಂದ
ಸಂಪೂರ್ಣ ವೈಶಿಷ್ಟ್ಯಗಳಿರುವ ಪರೀಕ್ಷಾ ಕಾರ್ಯಕ್ಷೇತ್ರವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ. ಇದು ಹಳೆಯ `page.tsx` ಅನ್ನು ನಾಲ್ಕು ಟ್ಯಾಬ್ಗಳು ಮತ್ತು ಹಂಚಿದ ಕಾನ್ಫಿಗ್ ಪೇನ್ ಅನ್ನು ರೆಂಡರ್ ಮಾಡುವ `PlaygroundStudio`
ಶೆಲ್ನೊಂದಿಗೆ ಬದಲಾಯಿಸುತ್ತದೆ.

## ಟ್ಯಾಬ್ಗಳು

### ಚಾಟ್ ಟ್ಯಾಬ್

`ChatPlayground.tsx` ಅನ್ನು ಬಹು-ಸುತ್ತಿನ ಸ್ಟ್ರೀಮಿಂಗ್ ಕಾರ್ಯಪೀಠವಾಗಿ ವಿಕಸಿಸುತ್ತದೆ:

- `MarkdownMessage.tsx` ಮೂಲಕ ಸಂಪೂರ್ಣ markdown ರೆಂಡರಿಂಗ್ (ಕೋಡ್ ಬ್ಲಾಕ್ಗಳು, ಕೋಷ್ಟಕಗಳು, ಪಟ್ಟಿಗಳು, ಲಿಂಕ್ಗಳು).
- ಹಂಚಿದ ಕಾನ್ಫಿಗ್ ಪೇನ್ನಿಂದ ಸಿಸ್ಟಮ್ ಪ್ರಾಂಪ್ಟ್ ಪಡೆಯಲಾಗುತ್ತದೆ.
- ಪ್ರತಿ ಸಂದೇಶದ ಟೋಕನ್/ವೆಚ್ಚ (ಪ್ರಾಂಪ್ಟ್ + ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ ಟೋಕನ್ಗಳು).
- ಕೊನೆಯ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಪುನರುತ್ಪಾದಿಸುವಿಕೆ.
- SSE ಸ್ಟ್ರೀಮಿಂಗ್ನೊಂದಿಗೆ `POST /v1/chat/completions` ಗೆ ಕಳುಹಿಸುತ್ತದೆ.

### ಹೋಲಿಕೆ ಟ್ಯಾಬ್

ಪ್ರಾಕ್ಸಿಯ ಪ್ರಮುಖ ವಿಭಿನ್ನಕಾರಿ: 1 ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಗರಿಷ್ಠ **4 ಮಾದರಿಗಳಲ್ಲಿ ಸಮಾನಾಂತರವಾಗಿ** ಚಲಾಯಿಸಿ.

- ಗರಿಷ್ಠ 4 ಕಾಲಮ್ಗಳು, ಪ್ರತಿಯೊಂದೂ `/v1/chat/completions` ನಿಂದ ಸ್ವತಂತ್ರವಾಗಿ ಸ್ಟ್ರೀಮ್ ಮಾಡುತ್ತದೆ.
- ಕಾಲಮ್ಗಳನ್ನು ಸೇರಿಸಲು `+ ಮಾದರಿ ಸೇರಿಸಿ` ಬಟನ್ (Cmd+K ಶಾರ್ಟ್ಕಟ್).
- `ಎಲ್ಲವನ್ನೂ ಚಲಾಯಿಸಿ ▶`, `Promise.all` + ಪ್ರತಿ ಕಾಲಮ್ಗೆ `AbortController` ಮೂಲಕ ಎಲ್ಲಾ ಸ್ಟ್ರೀಮ್ಗಳನ್ನು ಏಕಕಾಲದಲ್ಲಿ ಪ್ರಾರಂಭಿಸುತ್ತದೆ.
- ಜಾಗತಿಕ **ಎಲ್ಲವನ್ನೂ ರದ್ದುಗೊಳಿಸಿ** ಪ್ರಗತಿಯಲ್ಲಿರುವ ಪ್ರತಿಯೊಂದು ಸ್ಟ್ರೀಮ್ ಅನ್ನು ಸ್ಥಗಿತಗೊಳಿಸುತ್ತದೆ.
- ಪ್ರತಿ ಕಾಲಮ್ನ `ProviderMetrics`, TTFT, TPS, ಟೋಕನ್ಗಳು ಮತ್ತು ಅಂದಾಜು ವೆಚ್ಚವನ್ನು ನೈಜ ಸಮಯದಲ್ಲಿ ತೋರಿಸುತ್ತದೆ.
- ಮೆಟ್ರಿಕ್ಗಳಿಗೆ **"ಕ್ಲೈಂಟ್-ಸೈಡ್ ಅಂದಾಜು"** (D12) ಎಂಬ ಲೇಬಲ್ ಇದೆ — ಮೊದಲ SSE ಚಂಕ್ನಿಂದ ಅಳೆಯಲಾಗುತ್ತದೆ.

### API ಟ್ಯಾಬ್

ಮುನ್ನಡೆದ ಬಳಕೆದಾರರಿಗಾಗಿ ಮೂಲ Monaco ಎಡಿಟರ್ನ 100% ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ (D14):

- 10 ಎಂಡ್ಪಾಯಿಂಟ್ಗಳು: ಚಾಟ್ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆಗಳು, ಪೂರ್ಣಗೊಳಿಸುವಿಕೆಗಳು, ಎಂಬೆಡ್ಡಿಂಗ್ಗಳು, ಚಿತ್ರಗಳು, ಆಡಿಯೊ, ಸ್ಪೀಚ್, ಟ್ರಾನ್ಸ್ಕ್ರಿಪ್ಷನ್ಗಳು, ಮಾಡರೇಷನ್ಗಳು, ರೀರ್ಯಾಂಕ್, ಹುಡುಕಾಟ.
- ಮಲ್ಟಿಮೋಡಲ್ ಫೈಲ್ ಅಪ್ಲೋಡ್.
- ನೈಜ-ಸಮಯದ ಔಟ್ಪುಟ್ನೊಂದಿಗೆ SSE ಸ್ಟ್ರೀಮಿಂಗ್.
- `ApiTab.tsx` ಆಗಿ ಸುತ್ತುವರಿಯಲಾಗಿದೆ (ಲೇಜಿ-ಲೋಡ್ ಮಾಡಲಾಗಿದೆ, `ssr: false`).

### ನಿರ್ಮಾಣ ಟ್ಯಾಬ್

ಪರಿಕರಗಳು/ಫಂಕ್ಷನ್ ಕಾಲಿಂಗ್ ಮತ್ತು ರಚನಾತ್ಮಕ ಔಟ್ಪುಟ್ UI:

- `ToolsBuilder.tsx` — ಪ್ರತಿ ಪರಿಕರಕ್ಕೆ JSON ಸ್ಕೀಮಾ ಎಡಿಟರ್ನೊಂದಿಗೆ `tools[]` ಅನ್ನು ಸೇರಿಸಿ/ಸಂಪಾದಿಸಿ/ತೆಗೆದುಹಾಕಿ.
  `ToolDefinitionSchema` (Zod) ಮೂಲಕ ಪ್ಯಾರಾಮೀಟರ್ಗಳನ್ನು ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ.
- `StructuredOutputEditor.tsx` — JSON ಮೋಡ್ ಟಾಗಲ್ + JSON ಸ್ಕೀಮಾ ಎಡಿಟರ್.
  `StructuredOutputSchema` (Zod) ಮೂಲಕ ಸ್ಕೀಮಾದ ವಿರುದ್ಧ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ.
- `tools[]` ಮತ್ತು/ಅಥವಾ `response_format` ನೊಂದಿಗೆ ವಿನಂತಿಯನ್ನು `/v1/chat/completions` ಗೆ ಕಳುಹಿಸುತ್ತದೆ.

ಕಾನ್ಫಿಗ್ ಸ್ಥಿತಿ ಹಾಗೆಯೇ ಉಳಿಯುತ್ತದೆ.

## ಪ್ರಾಂಪ್ಟ್ ಸುಧಾರಕ

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. ಮೋಡಲ್ "ಕೋಟಾವನ್ನು ಬಳಸುತ್ತದೆ" ಎಂದು ಎಚ್ಚರಿಸುತ್ತದೆ.
2. ದೃಢೀಕರಿಸಿದಾಗ, ರೂಟ್ಗೆ `{ system, prompt, model, tone }` ಅನ್ನು ಕಳುಹಿಸುತ್ತದೆ.
3. ರೂಟ್ ಆಂತರಿಕವಾಗಿ `promptImprover.META_SYSTEM_PROMPT` ಜೊತೆಗೆ `/v1/chat/completions` ಅನ್ನು ಕರೆಮಾಡುತ್ತದೆ.
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ.
5. UI, ಕಾನ್ಫಿಗ್ ಫಲಕದ ಸಿಸ್ಟಮ್ ಪ್ರಾಂಪ್ಟ್ ಮತ್ತು ಚಾಟ್ ಟ್ಯಾಬ್ನ ಬಳಕೆದಾರ ಪ್ರಾಂಪ್ಟ್ಗೆ ಪ್ಯಾಚ್ ಅನ್ವಯಿಸುತ್ತದೆ.

## ಪೂರ್ವನಿಗದಿಗಳು

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- `playground_presets` SQLite ಕೋಷ್ಟಕದಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ (ವಲಸೆ `084_playground_presets.sql`).
- ಪ್ರತಿಯೊಂದು ಪೂರ್ವನಿಗದಿಯೂ ಇವುಗಳನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: `GET` ಪಟ್ಟಿ, `POST` ರಚನೆ, `GET /:id`, `PUT /:id`, `DELETE /:id`.

## ಸ್ಟ್ರೀಮ್ ಮೆಟ್ರಿಕ್ಗಳು

`useStreamMetrics.ts` + `streamMetrics.ts` (ಶುದ್ಧ ಫಂಕ್ಷನ್):

- `start()` — ವಿನಂತಿಯ ಪ್ರಾರಂಭ ಸಮಯವನ್ನು ದಾಖಲಿಸುತ್ತದೆ.
- `onFirstChunk()` — TTFT ಅನ್ನು ದಾಖಲಿಸುತ್ತದೆ.
- `onChunk(n)` — ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ ಟೋಕನ್ಗಳ ಸಂಖ್ಯೆಯನ್ನು ಸಂಚಯಿಸುತ್ತದೆ.
- `finish(usage?)` — ಅಂತಿಮ ಮೆಟ್ರಿಕ್ಗಳನ್ನು ಲೆಕ್ಕಾಚಾರ ಮಾಡುತ್ತದೆ: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- `src/lib/playground/types.ts`ನಲ್ಲಿರುವ ಸ್ಥಿರ ಕೋಷ್ಟಕದಿಂದ ಬೆಲೆ ನಿಗದಿ ("ಅಂದಾಜು" ಎಂದು ಲೇಬಲ್ ಮಾಡಲಾಗಿದೆ — D13).
