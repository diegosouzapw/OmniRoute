## ಇದು ಏನು

Local Corpus, ಸ್ಪಷ್ಟವಾಗಿ ಅನುಮೋದಿಸಲಾದ ಪಠ್ಯ ಫೈಲ್ಗಳ ಒಂದು ಡೈರೆಕ್ಟರಿಯನ್ನು OmniRoute ನ MCP ಸರ್ವರ್ಗೆ ಲಭ್ಯವಾಗುವಂತೆ ಮಾಡಲು ನಿರ್ವಾಹಕರಿಗೆ ಅನುಮತಿಸುತ್ತದೆ. ಫೈಲ್ಗಳು ಅವುಗಳ ಮೂಲ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿಯೇ ಉಳಿಯುತ್ತವೆ: OmniRoute ಕೇವಲ ಕ್ಯಾನಾನಿಕಲ್ ರೂಟ್ ಪಾತ್ ಅನ್ನು SQLite ನಲ್ಲಿ ಸಂಗ್ರಹಿಸುತ್ತದೆ ಮತ್ತು ಮೆಮೊರಿಯೊಳಗಿನ ಹುಡುಕಾಟ ಸೂಚ್ಯಂಕವನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ. ಇದು ಕಾರ್ಪಸ್ ವಿಷಯವನ್ನು ರೆಪೊಸಿಟರಿ ಅಥವಾ ಡೇಟಾಬೇಸ್ಗೆ ನಕಲಿಸುವುದಿಲ್ಲ.

ಸೂಚ್ಯಂಕದ ರಿಫ್ರೆಶ್ ಇನ್ಕ್ರಿಮೆಂಟಲ್ ಆಗಿರುತ್ತದೆ. ಬದಲಾಗದ ಫೈಲ್ಗಳನ್ನು ಗಾತ್ರ ಮತ್ತು ಮಾರ್ಪಡಿಸಿದ ಸಮಯದ ಆಧಾರದ ಮೇಲೆ ಮರುಬಳಕೆ ಮಾಡಲಾಗುತ್ತದೆ, ಬದಲಾದ ಫೈಲ್ಗಳನ್ನು ಮರುಓದಿ SHA-256 ಮೂಲಕ ಹ್ಯಾಶ್ ಮಾಡಲಾಗುತ್ತದೆ ಮತ್ತು ಅಳಿಸಲಾದ ಫೈಲ್ಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗುತ್ತದೆ. ಹುಡುಕಾಟವು 30 ಸೆಕೆಂಡುಗಳಿಗಿಂತ ಹಳೆಯದಾದ ಸೂಚ್ಯಂಕವನ್ನು ರಿಫ್ರೆಶ್ ಮಾಡುತ್ತದೆ; ಕರೆ ಮಾಡುವವರು ತಕ್ಷಣದ ರಿಫ್ರೆಶ್ಗೂ ವಿನಂತಿಸಬಹುದು.

## ಮೂಲವನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿ

ಸೆಟ್ಟಿಂಗ್ಗಳ ರೂಟ್ಗೆ ಇತರ ಸೆಟ್ಟಿಂಗ್ಗಳ API ಗಳಂತೆಯೇ ನಿರ್ವಹಣಾ ದೃಢೀಕರಣದ ಅಗತ್ಯವಿದೆ. ಸಲ್ಲಿಸಿದ ಪಾತ್ ಈಗಾಗಲೇ ಅಸ್ತಿತ್ವದಲ್ಲಿರಬೇಕು ಮತ್ತು ಅದು ಸಂಪೂರ್ಣ ಡೈರೆಕ್ಟರಿ ಪಾತ್ ಆಗಿರಬೇಕು.

```bash
# ಅನುಮೋದಿಸಲಾದ ಡೈರೆಕ್ಟರಿಯನ್ನು ಸಂಪರ್ಕಿಸಿ
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# ಕಾನ್ಫಿಗರೇಶನ್ ಮತ್ತು ಸೂಚ್ಯಂಕದ ಸ್ಥಿತಿಯನ್ನು ಪರಿಶೀಲಿಸಿ
curl http://localhost:20128/api/settings/local-corpus

# ಮೂಲ ಫೈಲ್ಗಳನ್ನು ಬದಲಾಯಿಸದೆ ಸಂಪರ್ಕ ಕಡಿತಗೊಳಿಸಿ
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP ಪರಿಕರಗಳು

ಎಲ್ಲಾ ಮೂರು ಪರಿಕರಗಳಿಗೂ `read:local-corpus` ಅಗತ್ಯವಿದೆ. ಪರಿಕರಗಳ ಪ್ರತಿಕ್ರಿಯೆಗಳು ಸಾಪೇಕ್ಷ ಪಾತ್ಗಳು ಮತ್ತು ರೂಟ್ ಡೈರೆಕ್ಟರಿಯ ಮೂಲ ಹೆಸರನ್ನು ಬಹಿರಂಗಪಡಿಸುತ್ತವೆ, ಅದರ ಸಂಪೂರ್ಣ ಪಾತ್ ಅನ್ನು ಎಂದಿಗೂ ಬಹಿರಂಗಪಡಿಸುವುದಿಲ್ಲ.

| ಪರಿಕರ                 | ವಿವರಣೆ                                                                                                   |
| :-------------------- | :------------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | ಕಾನ್ಫಿಗರೇಶನ್ ಸ್ಥಿತಿ, ಸೂಚ್ಯಂಕದ ಗಾತ್ರ, ಮಿತಿಗಳು ಮತ್ತು ಕೊನೆಯ ರಿಫ್ರೆಶ್ ಸಮಯವನ್ನು ವರದಿ ಮಾಡುತ್ತದೆ                |
| `local_corpus_search` | ಸೂಚ್ಯಂಕಿತ ಪಠ್ಯವನ್ನು ಹುಡುಕಿ, ಮಿತಿಗೊಳಿಸಿದ ಸಾಲು-ವ್ಯಾಪ್ತಿಯ ತುಣುಕುಗಳನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ (20 ಫಲಿತಾಂಶಗಳವರೆಗೆ) |
| `local_corpus_read`   | ಅನುಮತಿಸಲಾದ ಒಂದು ಕಾರ್ಪಸ್-ಸಾಪೇಕ್ಷ ಫೈಲ್ನಿಂದ ಮಿತಿಗೊಳಿಸಿದ ಸಾಲು ವ್ಯಾಪ್ತಿಯನ್ನು ಓದುತ್ತದೆ                         |

MCP ಇನ್ಪುಟ್ಗಳ ಉದಾಹರಣೆಗಳು:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## ಸುರಕ್ಷತಾ ಗಡಿಗಳು

- ಅನುಮತಿ ಪಟ್ಟಿಯು ಪಠ್ಯ-ಆಧಾರಿತವಾಗಿದೆ: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, ಮತ್ತು `.yml`.
- ಸಿಂಬಾಲಿಕ್ ಲಿಂಕ್ಗಳನ್ನು ಬಿಟ್ಟುಬಿಡಲಾಗುತ್ತದೆ. ಓದುವ ಪಾತ್ಗಳನ್ನು ಕ್ಯಾನಾನಿಕಲೈಸ್ ಮಾಡಲಾಗುತ್ತದೆ ಮತ್ತು ಅವು ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ರೂಟ್ನ ಒಳಗೇ ಉಳಿಯಬೇಕು; ಸಂಪೂರ್ಣ ಪಾತ್ಗಳು ಮತ್ತು ಡೈರೆಕ್ಟರಿ ಟ್ರಾವರ್ಸಲ್ ಪ್ರಯತ್ನಗಳನ್ನು ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ.
- ಸೂಕ್ಷ್ಮ ಮತ್ತು ರಚಿಸಲಾದ ಡೈರೆಕ್ಟರಿ ಹೆಸರುಗಳನ್ನು ಹೊರಗಿಡಲಾಗುತ್ತದೆ: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, ಮತ್ತು
  `secrets`.
- ಡೀಫಾಲ್ಟ್ ಮಿತಿಗಳು 5,000 ಫೈಲ್ಗಳು, ಪ್ರತಿ ಫೈಲ್ಗೆ 1 MiB, ಒಟ್ಟು ಸೂಚ್ಯಂಕಿತ ವಿಷಯಕ್ಕೆ 64 MiB, ಪ್ರತಿ ಹುಡುಕಾಟ ತುಣುಕಿಗೆ ಸರಿಸುಮಾರು 4,000 ಅಕ್ಷರಗಳು ಮತ್ತು ಪ್ರತಿ ಓದುವಿಕೆಗೆ 400 ಸಾಲುಗಳು.
- NUL ಹೊಂದಿರುವ ಫೈಲ್ಗಳನ್ನು ಪಠ್ಯೇತರವೆಂದು ಪರಿಗಣಿಸಿ ಬಿಟ್ಟುಬಿಡಲಾಗುತ್ತದೆ ಅಥವಾ ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ.

PDF, DOCX, ಚಿತ್ರಗಳು ಮತ್ತು ಆರ್ಕೈವ್ಗಳಂತಹ ಬೈನರಿ ಡಾಕ್ಯುಮೆಂಟ್ಗಳನ್ನು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಬೆಂಬಲಿಸಲಾಗುವುದಿಲ್ಲ. ಸೂಚ್ಯಂಕೀಕರಣದ ಮೊದಲು ಅವುಗಳನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ ಅನುಮೋದಿತ ಪಠ್ಯ ಸ್ವರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸಿ.

## ಕಾರ್ಯಾಚರಣೆಯ ಟಿಪ್ಪಣಿಗಳು

- ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ರೂಟ್ ಅನ್ನು ಬದಲಾಯಿಸುವುದು ಅಥವಾ ಅಳಿಸುವುದು ಹಂಚಿಕೊಂಡ ಮೆಮೊರಿಯೊಳಗಿನ ಸೂಚ್ಯಂಕವನ್ನು ತೆರವುಗೊಳಿಸುತ್ತದೆ.
- ಪ್ರಕ್ರಿಯೆಯ ಮರುಪ್ರಾರಂಭವು ಸೂಚ್ಯಂಕವನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ; ಮುಂದಿನ ಹುಡುಕಾಟವು ಅದನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ಮೂಲದಿಂದ ಮರುನಿರ್ಮಿಸುತ್ತದೆ.
- `local_corpus_status` ಸ್ಕ್ಯಾನ್ ಅನ್ನು ಬಲವಂತವಾಗಿ ಪ್ರಾರಂಭಿಸುವುದಿಲ್ಲ. ತಕ್ಷಣದ ಮರುಸ್ಕ್ಯಾನ್ ಅಗತ್ಯವಿದ್ದಾಗ `refresh: true` ಜೊತೆಗೆ `local_corpus_search` ಬಳಸಿ.
- ಸ್ಕ್ಯಾನ್ ಮತ್ತು ಓದುವಿಕೆ ವೈಫಲ್ಯಗಳನ್ನು ಎಣಿಸಲಾಗುತ್ತದೆ ಅಥವಾ ಶುದ್ಧೀಕರಿಸಿದ ದೋಷಗಳಾಗಿ ಹಿಂತಿರುಗಿಸಲಾಗುತ್ತದೆ; ಮೂಲ ಫೈಲ್ಗಳನ್ನು ಎಂದಿಗೂ ಮಾರ್ಪಡಿಸಲಾಗುವುದಿಲ್ಲ.
