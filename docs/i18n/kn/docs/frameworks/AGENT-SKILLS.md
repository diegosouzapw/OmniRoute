> **ಕೊನೆಯದಾಗಿ ನವೀಕರಿಸಲಾಗಿದೆ:** 2026-08-02 — v3.8.50

Agent Skills ಎನ್ನುವುದು ಬಾಹ್ಯ ಏಜೆಂಟ್ಗಳು, MCP ಕ್ಲೈಂಟ್ಗಳು ಮತ್ತು A2A ಆರ್ಕೆಸ್ಟ್ರೇಟರ್ಗಳಿಗೆ OmniRoute ನ REST API ಮತ್ತು CLI ಅನ್ನು ಹೇಗೆ ಬಳಸಬೇಕೆಂದು ಕಲಿಸುವ ರಚನಾತ್ಮಕ SKILL.md ಫೈಲ್ಗಳಾಗಿವೆ. [Omni Skills](./SKILLS.md) ಗಿಂತ ಭಿನ್ನವಾಗಿ (ಅವು OmniRoute ಒಳಗೆ ಕಾರ್ಯಗತಗೊಳ್ಳುವ LLM ಪರಿಕರ ವ್ಯಾಖ್ಯಾನಗಳಾಗಿವೆ), Agent Skills ಒಂದು _ದಸ್ತಾವೇಜೀಕರಣ ಕ್ಯಾಟಲಾಗ್_ ಆಗಿದೆ — ಏಜೆಂಟ್ ಸಂದರ್ಭಕ್ಕೆ ನೇರವಾಗಿ ಒದಗಿಸಬಹುದಾದ ಸ್ಥಿರ markdown.

## ಅವಲೋಕನ

ಕ್ಯಾಟಲಾಗ್ನಲ್ಲಿ **45 Agent Skills** ಇವೆ (23 REST API + 21 CLI + 1 ಸಂರಚನಾ ಕಾರ್ಯಪ್ರವಾಹ). ಪ್ರತಿಯೊಂದು ಕೌಶಲ್ಯವು ಇವುಗಳನ್ನು ಹೊಂದಿದೆ:

- ಒಂದು **ಅಧಿಕೃತ ID** (`omni-auth`, `cli-serve`, ಇತ್ಯಾದಿ)
- YAML frontmatter (`name`, `description`) + ಸಮೃದ್ಧ markdown ವಿಷಯವನ್ನು ಹೊಂದಿರುವ `skills/{id}/SKILL.md` ನಲ್ಲಿನ ಒಂದು **SKILL.md** ಫೈಲ್
- OpenAPI ನಿರ್ದಿಷ್ಟತೆ ಮತ್ತು CLI ರಿಜಿಸ್ಟ್ರಿಯಿಂದ ಪಡೆಯಲಾದ **REST ಎಂಡ್ಪಾಯಿಂಟ್ಗಳು** (API ಕೌಶಲ್ಯಗಳು) ಅಥವಾ **CLI ಉಪಕಮಾಂಡ್ಗಳು** (CLI ಕೌಶಲ್ಯಗಳು)
- ನೇರವಾಗಿ ಪಡೆದುಕೊಳ್ಳಲು ಒಂದು **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API ಅನ್ವೇಷಣೆ

| ಎಂಡ್ಪಾಯಿಂಟ್                  | ವಿಧಾನ | ವಿವರಣೆ                                                            | ದೃಢೀಕರಣ     |
| :--------------------------- | :---- | :---------------------------------------------------------------- | :---------- |
| `/api/agent-skills`          | GET   | ಕ್ಯಾಟಲಾಗ್ ಪಟ್ಟಿ (ಐಚ್ಛಿಕ `?category=api\|cli\|config&area=<area>`) | ಯಾವುದೂ ಇಲ್ಲ |
| `/api/agent-skills/{id}`     | GET   | ಒಂದು ಕೌಶಲ್ಯದ ಮೆಟಾಡೇಟಾವನ್ನು ಪಡೆಯಿರಿ                                | ಯಾವುದೂ ಇಲ್ಲ |
| `/api/agent-skills/{id}/raw` | GET   | SKILL.md ಅನ್ನು `text/markdown` ರೂಪದಲ್ಲಿ ಪಡೆಯಿರಿ                   | ಯಾವುದೂ ಇಲ್ಲ |
| `/api/agent-skills/coverage` | GET   | ವ್ಯಾಪ್ತಿ ಅಂಕಿಅಂಶಗಳು (ಎಷ್ಟು SKILL.md ಫೈಲ್ಗಳಿವೆ)                    | ಯಾವುದೂ ಇಲ್ಲ |
| `/api/agent-skills/generate` | POST  | ಜನರೇಟರ್ ಅನ್ನು ಪ್ರಚೋದಿಸಿ (dryRun/prune/onlyIds)                    | ನಿರ್ವಹಣೆ    |

ಉದಾಹರಣೆ — ಎಲ್ಲಾ API ಕೌಶಲ್ಯಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡಿ:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ಉದಾಹರಣೆ — ಒಂದೇ SKILL.md ಅನ್ನು ಪಡೆಯಿರಿ:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP ಅನ್ವೇಷಣೆ

`read:catalog` ವ್ಯಾಪ್ತಿಯ ಅಡಿಯಲ್ಲಿ ಮೂರು MCP ಪರಿಕರಗಳನ್ನು ನೋಂದಾಯಿಸಲಾಗಿದೆ:

| ಪರಿಕರ                             | ವಿವರಣೆ                                                          |
| :-------------------------------- | :-------------------------------------------------------------- |
| `omniroute_agent_skills_list`     | ಕೌಶಲ್ಯಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡಿ (ಐಚ್ಛಿಕ `category` / `area` ಫಿಲ್ಟರ್ಗಳು) |
| `omniroute_agent_skills_get`      | `id` ಮೂಲಕ ಒಂದು ಕೌಶಲ್ಯದ ಮೆಟಾಡೇಟಾ + SKILL.md ಪಡೆಯಿರಿ              |
| `omniroute_agent_skills_coverage` | ವ್ಯಾಪ್ತಿ ಅಂಕಿಅಂಶಗಳು (API/CLI ಲಭ್ಯ/ಒಟ್ಟು)                        |

ವ್ಯಾಪ್ತಿ ಜೋಡಣೆ ಮತ್ತು ದೃಢೀಕರಣಕ್ಕಾಗಿ [MCP-SERVER.md](./MCP-SERVER.md) ನೋಡಿ.

## A2A ಅನ್ವೇಷಣೆ

A2A ಕೌಶಲ್ಯ `list-capabilities` ಸಂಪೂರ್ಣ 45-ಕೌಶಲ್ಯಗಳ ಕ್ಯಾಟಲಾಗ್ ಅನ್ನು ಮಾರ್ಕ್ಡೌನ್ ಕೋಷ್ಟಕ ಆರ್ಟಿಫ್ಯಾಕ್ಟ್ ಆಗಿ ಹಿಂದಿರುಗಿಸುತ್ತದೆ. ಬಾಹ್ಯ ಆರ್ಕೆಸ್ಟ್ರೇಟರ್ಗಳು ಇದನ್ನು ಈ ಮೂಲಕ ಆಹ್ವಾನಿಸಬಹುದು:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

ಪ್ರೋಟೋಕಾಲ್ ವಿವರಗಳಿಗಾಗಿ [A2A-SERVER.md](./A2A-SERVER.md) ನೋಡಿ.

## ಜನರೇಟರ್

ಜನರೇಟರ್ ಸಂರಕ್ಷಿತ ಕ್ಯಾಟಲಾಗ್ + OpenAPI ನಿರ್ದಿಷ್ಟತೆ + CLI ರಿಜಿಸ್ಟ್ರಿಯನ್ನು ಓದಿ, ಪ್ರತಿ ನಮೂದಿಗಾಗಿ `skills/{id}/SKILL.md` ಅನ್ನು ಬರೆಯುತ್ತದೆ:

```bash
# ಪೂರ್ವವೀಕ್ಷಣೆ (ಡ್ರೈ ರನ್, ಯಾವುದೇ ಬರವಣಿಗೆಗಳಿಲ್ಲ)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# ಸಂಪೂರ್ಣ ಮರುಸೃಷ್ಟಿ
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# ನಿರ್ದಿಷ್ಟ IDಗಳನ್ನು ಮರುಸೃಷ್ಟಿಸಿ
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

ಜನರೇಟರ್ ಪ್ರತಿಕ್ರಿಯೆಯು `GeneratorReport` ಆಗಿರುತ್ತದೆ:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
