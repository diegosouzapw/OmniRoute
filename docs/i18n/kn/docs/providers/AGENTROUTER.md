[AgentRouter](https://agentrouter.org) ಎಂಬುದು Anthropic-ಹೊಂದಾಣಿಕೆಯ ರಿಲೇ ಆಗಿದ್ದು, Claude ಮತ್ತು ಇತರ ಮಾದರಿಗಳನ್ನು ಮರುಮಾರಾಟ ಮಾಡುತ್ತದೆ, ಅನೇಕ ಬಾರಿ ನೇರ Anthropic API ಗಿಂತ ಕಡಿಮೆ ಬೆಲೆಯಲ್ಲಿ. ಇದನ್ನು ಅಧಿಕೃತ Claude Code ಕ್ಲೈಂಟ್ಗೆ ಡ್ರಾಪ್-ಇನ್ `ANTHROPIC_BASE_URL` ಬದಲಿಯಾಗಿ ವಿನ್ಯಾಸಗೊಳಿಸಲಾಗಿದೆ, ಆದ್ದರಿಂದ ಇದು Claude Code ವೈರ್ ಇಮೇಜ್ಗೆ ಹೊಂದಿಕೆಯಾಗುವ ಟ್ರಾಫಿಕ್ ಅನ್ನು ಮಾತ್ರ ಸ್ವೀಕರಿಸುತ್ತದೆ (ನಿರ್ದಿಷ್ಟ User-Agent, `anthropic-beta` ಫ್ಲ್ಯಾಗ್ಗಳು, Stainless SDK ಹೆಡರ್ಗಳು ಇತ್ಯಾದಿ).

## ತ್ವರಿತ ಪ್ರಾರಂಭ — ಸ್ಥಳೀಯ `agentrouter` ಪೂರೈಕೆದಾರವನ್ನು ಬಳಸಿ (ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ)

ಹೆಚ್ಚಿನ ಬಳಕೆದಾರರಿಗೆ, **ಯಾವುದೇ ವಿಶೇಷ ಸೆಟಪ್ ಅಗತ್ಯವಿಲ್ಲ**. OmniRoute, ಸಂಪೂರ್ಣ Claude Code ವೈರ್ ಇಮೇಜ್ ಅನ್ನು ಈಗಾಗಲೇ ಅಂತರ್ನಿರ್ಮಿತವಾಗಿ ಹೊಂದಿರುವ `agentrouter` ಪೂರೈಕೆದಾರವನ್ನು ಒಳಗೊಂಡಿದೆ (`open-sse/config/providerRegistry.ts` → `agentrouter` ನೋಡಿ). ಅದನ್ನು ಬಳಸಲು:

1. **ಡ್ಯಾಶ್ಬೋರ್ಡ್ → ಪೂರೈಕೆದಾರರು → ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ತೆರೆಯಿರಿ.
2. ಪಟ್ಟಿಯಿಂದ **AgentRouter** ಆಯ್ಕೆಮಾಡಿ.
3. ನಿಮ್ಮ `sk-...` API ಕೀಲಿಯನ್ನು ಅಂಟಿಸಿ ಮತ್ತು ಉಳಿಸಿ.

ಅಷ್ಟೇ — ಯಾವುದೇ ಪರಿಸರ ವೇರಿಯಬಲ್ಗಳಾಗಲಿ, ಕಸ್ಟಮ್ ಪೂರೈಕೆದಾರ ಪ್ರಕಾರವಾಗಲಿ ಅಗತ್ಯವಿಲ್ಲ. ಅಂತರ್ನಿರ್ಮಿತ ಮಾದರಿಗಳಲ್ಲಿ `claude-opus-4-6`, `claude-haiku-4-5-20251001`, `glm-5.1`, ಮತ್ತು `deepseek-v3.2` ಸೇರಿವೆ.

ಈ ಮಾರ್ಗದರ್ಶಿಯ ಉಳಿದ ಭಾಗವು **ಸುಧಾರಿತ ಮಾರ್ಗವನ್ನು** ಒಳಗೊಂಡಿದೆ: `anthropic-compatible-cc-*` ಪೂರೈಕೆದಾರ ಪ್ರಕಾರವನ್ನು ಬಳಸುವುದು. ವೈರ್ ಇಮೇಜ್ ಮೇಲೆ ನಿಮಗೆ ಹೆಚ್ಚಿನ ನಿಯಂತ್ರಣ ಅಗತ್ಯವಿದ್ದಾಗ — ಉದಾಹರಣೆಗೆ, ಸ್ಥಳೀಯ ಪೂರೈಕೆದಾರ ರಿಜಿಸ್ಟ್ರಿಯಲ್ಲಿ ಇನ್ನೂ ಇಲ್ಲದ ಇತರ AgentRouter-ಶೈಲಿಯ ರಿಲೇಗಳಿಗೆ ಸಂಪರ್ಕಿಸುವಾಗ, ಅಥವಾ ಮೂಲ URL, ಚಾಟ್ ಪಥ, ಅಥವಾ ಹೆಡರ್ ಸಮೂಹವನ್ನು ಅತಿಕ್ರಮಿಸುವಾಗ — ಇದನ್ನು ಬಳಸಿ.

## ಸುಧಾರಿತ: Claude Code ಹೊಂದಾಣಿಕೆಯ ಪೂರೈಕೆದಾರ ಪ್ರಕಾರದ ಮೂಲಕ ಸಂಪರ್ಕಿಸುವುದು

OmniRoute, ಸರಿಯಾದ ವೈರ್ ಇಮೇಜ್ನೊಂದಿಗೆ Anthropic Messages API ಅನ್ನು ಬಳಸುವ **Claude Code ಹೊಂದಾಣಿಕೆಯ** ಪೂರೈಕೆದಾರ ಪ್ರಕಾರದ (`anthropic-compatible-cc-*`) ಮೂಲಕವೂ AgentRouter (ಮತ್ತು ಅದೇ ರೀತಿಯ ರಿಲೇಗಳು) ಅನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ. `https://agentrouter.org` ಅನ್ನು ಸೂಚಿಸುವ ಸಾಮಾನ್ಯ `openai-compatible-chat` ಪೂರೈಕೆದಾರವು **ಕೆಲಸ ಮಾಡುವುದಿಲ್ಲ** — Claude Code ನಂತೆ ಕಾಣದ ವಿನಂತಿಗಳನ್ನು ಅಪ್ಸ್ಟ್ರೀಮ್ WAF ತಿರಸ್ಕರಿಸುತ್ತದೆ.

## ಪೂರ್ವಾಪೇಕ್ಷಿತಗಳು

- AgentRouter ಖಾತೆ ಮತ್ತು API ಕೀಲಿ. ಹೊಸದಾಗಿ ನೋಂದಾಯಿಸುವವರು ಯೋಜನೆಯ [README](../README.md) ನಲ್ಲಿರುವ ಅಂಗಸಂಸ್ಥೆ ಲಿಂಕ್ ಮೂಲಕ ಉಚಿತ ಕ್ರೆಡಿಟ್ಗಳನ್ನು ಪಡೆಯುತ್ತಾರೆ.
- `ENABLE_CC_COMPATIBLE_PROVIDER` ವೈಶಿಷ್ಟ್ಯ ಫ್ಲ್ಯಾಗ್ ಸಕ್ರಿಯಗೊಳಿಸಿ ಚಾಲನೆಯಲ್ಲಿರುವ OmniRoute (ಕೆಳಗೆ ನೋಡಿ).

## 1. CC-ಹೊಂದಾಣಿಕೆಯ ಪೂರೈಕೆದಾರ ಪ್ರಕಾರವನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿ

Claude Code ಹೊಂದಾಣಿಕೆಯ ಪೂರೈಕೆದಾರ ಪ್ರಕಾರವು ಅಧಿಕೃತ Claude Code ಕ್ಲೈಂಟ್ ಅನ್ನು ನಿಕಟವಾಗಿ ಅನುಕರಿಸುವ ಟ್ರಾಫಿಕ್ ಅನ್ನು ಕಳುಹಿಸುವುದರಿಂದ, ಇದನ್ನು ವೈಶಿಷ್ಟ್ಯ ಫ್ಲ್ಯಾಗ್ನ ಹಿಂದೆ ಇರಿಸಲಾಗಿದೆ. OmniRoute ಅನ್ನು ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು ಪರಿಸರ ವೇರಿಯಬಲ್ ಅನ್ನು ಹೊಂದಿಸುವ ಮೂಲಕ ಇದನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿ:

```bash
ENABLE_CC_COMPATIBLE_PROVIDER=true
```

Docker ಉದಾಹರಣೆ:

```bash
docker run -d --name omniroute \
  --restart unless-stopped \
  -p 20128:20128 \
  -v omniroute-data:/app/data \
  -e ENABLE_CC_COMPATIBLE_PROVIDER=true \
  diegosouzapw/omniroute:latest
```

ಮರುಪ್ರಾರಂಭಿಸಿದ ನಂತರ, ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ OpenAI-ಹೊಂದಾಣಿಕೆಯ ಮತ್ತು Anthropic-ಹೊಂದಾಣಿಕೆಯ ಹರಿವುಗಳ ಜೊತೆಗೆ ಡ್ಯಾಶ್ಬೋರ್ಡ್ **Claude Code ಹೊಂದಾಣಿಕೆಯನ್ನು ಸೇರಿಸಿ** ಆಯ್ಕೆಯನ್ನು ಪ್ರದರ್ಶಿಸುತ್ತದೆ.

## 2. ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ಪೂರೈಕೆದಾರರನ್ನು ರಚಿಸಿ

1. **ಡ್ಯಾಶ್ಬೋರ್ಡ್ → ಪೂರೈಕೆದಾರರು → ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ತೆರೆಯಿರಿ.
2. **Claude Code ಹೊಂದಾಣಿಕೆಯನ್ನು ಸೇರಿಸಿ** ಆಯ್ಕೆಮಾಡಿ (ಮೇಲಿನ ಫ್ಲ್ಯಾಗ್ ಹೊಂದಿಸಿದಾಗ ಮಾತ್ರ ಗೋಚರಿಸುತ್ತದೆ).
3. ಕ್ಷೇತ್ರಗಳನ್ನು ಭರ್ತಿ ಮಾಡಿ:

| ಕ್ಷೇತ್ರ      | ಮೌಲ್ಯ                                                                                  |
| ------------ | -------------------------------------------------------------------------------------- |
| ಹೆಸರು        | `AgentRouter` (ಅಥವಾ ಯಾವುದೇ ಲೇಬಲ್)                                                      |
| ಪೂರ್ವಪ್ರತ್ಯಯ | `agentrouter` (ಲಾಗ್ಗಳು ಮತ್ತು ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ತೋರಿಸಲಾಗುವ ಬಳಕೆದಾರ-ಸ್ನೇಹಿ ಪರ್ಯಾಯ ಹೆಸರು) |
| ಮೂಲ URL      | `https://agentrouter.org`                                                              |
| ಚಾಟ್ ಪಥ      | `/v1/messages?beta=true` (ಡೀಫಾಲ್ಟ್ — ಹಾಗೆಯೇ ಬಿಡಿ)                                      |

> ಕ್ಯಾನಾನಿಕಲ್ ಮಾದರಿ ಗುರುತಿಸುವಿಕೆ ಇನ್ನೂ ಪೂರ್ಣ ಪೂರೈಕೆದಾರ ನೋಡ್ ID ಅನ್ನು ಬಳಸುತ್ತದೆ
> (`anthropic-compatible-cc-{uuid}/{model}`). **ಪೂರ್ವಪ್ರತ್ಯಯ** ಎನ್ನುವುದು ಹೆಚ್ಚು ಓದಲು ಅನುಕೂಲವಾದ ಲಾಗ್ ಔಟ್ಪುಟ್ಗಾಗಿ `src/lib/usage/callLogs.ts` ಮೂಲಕ ಪರಿಹರಿಸಲ್ಪಡುವ ಪ್ರದರ್ಶನ
> ಪರ್ಯಾಯ ಹೆಸರು ಮಾತ್ರ.

4. (ಐಚ್ಛಿಕ) ಉಳಿಸುವ ಮೊದಲು ಸಂಪರ್ಕವನ್ನು ಖಚಿತಪಡಿಸಲು ನಿಮ್ಮ API ಕೀಲಿಯನ್ನು **ಮೌಲ್ಯೀಕರಿಸಿ** ಕ್ಷೇತ್ರದಲ್ಲಿ ಅಂಟಿಸಿ ಮತ್ತು **ಪರಿಶೀಲಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ.
5. **ಸೇರಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ.

ರಚಿಸಿದ ನಂತರ, ಪೂರೈಕೆದಾರರನ್ನು ತೆರೆಯಿರಿ ಮತ್ತು ನಿಮ್ಮ AgentRouter API ಕೀಲಿಯೊಂದಿಗೆ (`sk-...`) **ಸಂಪರ್ಕ**ವನ್ನು ಸೇರಿಸಿ. ಸಂಪರ್ಕದ `test_status` `active` ಆಗಬೇಕು.

## 3. ಇದನ್ನು ಕಾಂಬೊ ಮೂಲಕ ಅಥವಾ ನೇರವಾಗಿ ಬಳಸಿ

ನಿಮ್ಮ ಪೂರೈಕೆದಾರರ ಪೂರ್ವಪ್ರತ್ಯಯವನ್ನು ನೇಮ್ಸ್ಪೇಸ್ ಆಗಿ ಬಳಸಿಕೊಂಡು ಮಾದರಿಯನ್ನು ಉಲ್ಲೇಖಿಸಿ:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "agentrouter/claude-opus-4-6",
    "messages": [{"role": "user", "content": "hello"}],
    "max_tokens": 100
  }'
```

ಅಧಿಕೃತ ಮಾದರಿ ID `anthropic-compatible-cc-{uuid}/claude-opus-4-6` ಕೂಡ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ
ಮತ್ತು ಡೇಟಾಬೇಸ್ ಹಾಗೂ ಕಾಂಬೊ ಸಂರಚನೆಯಲ್ಲಿ ಇದೇ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ.

ಅಥವಾ ಇತರ ಯಾವುದೇ ಪೂರೈಕೆದಾರರಂತೆಯೇ ರೂಟಿಂಗ್, ಫಾಲ್ಬ್ಯಾಕ್ ಮತ್ತು ಕೋಟಾ ನಿರ್ವಹಣೆಗಾಗಿ ಇದನ್ನು
ಕಾಂಬೊಗೆ ಸೇರಿಸಿ.

## ವೈರ್ ಇಮೇಜ್ ವಿವರಗಳು

ಉಲ್ಲೇಖಕ್ಕಾಗಿ, cc-compatible ಬ್ರಿಡ್ಜ್ ಪ್ರತಿ ಅಪ್ಸ್ಟ್ರೀಮ್ ವಿನಂತಿಯಲ್ಲೂ ಈ ಕೆಳಗಿನವುಗಳನ್ನು
ಕಳುಹಿಸುತ್ತದೆ (`open-sse/services/claudeCodeCompatible.ts` ನೋಡಿ):

| ಹೆಡರ್                                       | ಮೌಲ್ಯ                                                                                                                        |

## ದೋಷನಿವಾರಣೆ

**`{"error":{"message":"unauthorized client detected, ..."}}`** — ನಿಮ್ಮ ವಿನಂತಿಯು
Claude Code ವೈರ್ ಇಮೇಜ್ಗೆ ಹೊಂದಿಕೆಯಾಗಿಲ್ಲ. ಪೂರೈಕೆದಾರರನ್ನು
`anthropic-compatible-cc` ಬದಲಿಗೆ `openai-compatible-chat` ಆಗಿ ಸಂರಚಿಸಿದಾಗ ಅಥವಾ
ಪ್ರಾರಂಭಿಸುವಾಗ `ENABLE_CC_COMPATIBLE_PROVIDER=true` ಫ್ಲ್ಯಾಗ್ ಹೊಂದಿಸದಿದ್ದಾಗ ಇದು ಸಂಭವಿಸುತ್ತದೆ.

**`{"error":{"message":"无效的令牌","type":"new_api_error"}}` (HTTP 401)** —
"ಅಮಾನ್ಯ ಟೋಕನ್". ವೈರ್ ಇಮೇಜ್ ಸರಿಯಾಗಿದೆ, ಆದರೆ API ಕೀ ತಿರಸ್ಕರಿಸಲಾಗಿದೆ. AgentRouter
ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ಹೊಸ ಕೀ ರಚಿಸಿ ಮತ್ತು ಸಂಪರ್ಕವನ್ನು ನವೀಕರಿಸಿ.

**`{"error":{"code":"content-blocked","type":"agent_router_api_error"}}`
(HTTP 400)** — AgentRouter ನ ಮಾಡರೇಷನ್ ಹುಕ್ ವಿನಂತಿಯ ವಿಷಯವನ್ನು ತಿರಸ್ಕರಿಸಿದೆ ಅಥವಾ
ಕೀಗೆ ಸೇರಿದ ಪ್ಲ್ಯಾನ್ ವಿನಂತಿಸಿದ ಮಾದರಿಯನ್ನು ಅನುಮತಿಸುವುದಿಲ್ಲ. ಬೇರೆ ಪ್ರಾಂಪ್ಟ್ ಅಥವಾ ಮಾದರಿಯನ್ನು ಪ್ರಯತ್ನಿಸಿ;
ನಿರುಪದ್ರವಿ ಪ್ರಾಂಪ್ಟ್ ನಿರಂತರವಾಗಿ ನಿರ್ಬಂಧಿಸಲ್ಪಟ್ಟರೆ AgentRouter ಬೆಂಬಲವನ್ನು ಸಂಪರ್ಕಿಸಿ.

**ನಿರ್ದಿಷ್ಟ ಮಾದರಿಗಳಲ್ಲಿ ಮಾತ್ರ `[400]: content-blocked`** — ಹೆಚ್ಚಿನ AgentRouter ಪ್ಲ್ಯಾನ್ಗಳು
ಮಾದರಿಗಳ ಉಪಸಮೂಹವನ್ನು ಮಾತ್ರ ಅನುಮತಿಸುತ್ತವೆ (ಉದಾ. `claude-opus-4-6`). ಕೀ ಮಾನ್ಯವಾಗಿದ್ದರೂ
ಇತರ ಮಾದರಿ IDಗಳು `unauthorized_client_error` ಅನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತವೆ. ನಿಮ್ಮ ಪ್ಲ್ಯಾನ್ ಯಾವ
ಮಾದರಿಗಳನ್ನು ಒಳಗೊಂಡಿದೆ ಎಂಬುದನ್ನು AgentRouter ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.

**omniroute ಲಾಗ್ಗಳಿಂದ `Invalid JSON response from provider (reset after Ns)`** —
ಅಪ್ಸ್ಟ್ರೀಮ್ JSON ಅಲ್ಲದ ಬಾಡಿಯನ್ನು ಹಿಂದಿರುಗಿಸಿದೆ (ಸಾಮಾನ್ಯವಾಗಿ WAF ನಿಂದ ಬಂದ HTML ದೋಷ ಪುಟ).
ಇದರರ್ಥ ಸಾಮಾನ್ಯವಾಗಿ ವಿನಂತಿಯು AgentRouter ಬ್ಯಾಕೆಂಡ್ಗೆ ತಲುಪಲೇ ಇಲ್ಲ — ಪೂರೈಕೆದಾರ ID
`anthropic-compatible-cc-` ನಿಂದ ಪ್ರಾರಂಭವಾಗುತ್ತದೆ ಎಂಬುದನ್ನು ಮರುಪರಿಶೀಲಿಸಿ (ಕೊನೆಯ ಡ್ಯಾಶ್ ಅನ್ನು
ಗಮನಿಸಿ — `open-sse/services/claudeCodeCompatible.ts` ನಲ್ಲಿನ
`CLAUDE_CODE_COMPATIBLE_PREFIX` ನೋಡಿ) ಮತ್ತು ಫೀಚರ್ ಫ್ಲ್ಯಾಗ್ ಸಕ್ರಿಯವಾಗಿದೆ ಎಂಬುದನ್ನು ಖಚಿತಪಡಿಸಿ.

**AgentRouter ಪೂರೈಕೆದಾರ ಈಗಾಗಲೇ ಅಸ್ತಿತ್ವದಲ್ಲಿದ್ದರೂ `unauthorized client detected` /
HTML ದೋಷ ಪುಟ** — ನೀವು ಬಹುಶಃ **ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು** AgentRouter ಪೂರೈಕೆದಾರರನ್ನು ಹೊಂದಿದ್ದೀರಿ
ಮತ್ತು ನಿಮ್ಮ ವಿನಂತಿಯು ತಪ್ಪಾದ ಪೂರೈಕೆದಾರರನ್ನು ತಲುಪುತ್ತಿದೆ. ಉಳಿದುಕೊಂಡಿರುವ ಕೈಯಾರೆ ರಚಿಸಿದ
`anthropic-compatible-*` (`cc` ಅಲ್ಲದ) ಅಥವಾ `openai-compatible-chat-*` ಪೂರೈಕೆದಾರವನ್ನು
