`agentrouter` ಅಪ್ಸ್ಟ್ರೀಮ್ ಗೇಟ್ವೇ `messages[].content` ಮೇಲೆ ಕೀವರ್ಡ್-ಆಧಾರಿತ ವಿಷಯ ಫಿಲ್ಟರ್ ಅನ್ನು ಚಲಾಯಿಸುತ್ತದೆ. ಫಿಲ್ಟರ್ ಭಾಗಶಃ ನಿರ್ಣಾಯಕವಾಗಿದೆ (ಕೆಲವು ನುಡಿಗಟ್ಟುಗಳನ್ನು ಯಾವಾಗಲೂ ನಿರ್ಬಂಧಿಸುತ್ತದೆ) ಮತ್ತು ಭಾಗಶಃ ಸಂಭವನೀಯವಾಗಿದೆ (ಬರ್ಸ್ಟ್-ಸಂವೇದನಶೀಲ — ವೇಗವಾದ ವಿನಂತಿಗಳ ನಂತರ ಹೆಚ್ಚು ಆಕ್ರಮಣಕಾರಿಯಾಗುತ್ತದೆ ಮತ್ತು ವಿರಾಮದ ನಂತರ ಚೇತರಿಸಿಕೊಳ್ಳುತ್ತದೆ).

WAF ವಿನಂತಿಯನ್ನು ನಿರ್ಬಂಧಿಸಿದಾಗ ಅದು ಹೀಗೆ ಹಿಂತಿರುಗಿಸುತ್ತದೆ:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## ಫಿಲ್ಟರ್ನ ವ್ಯಾಪ್ತಿ

WAF ಕೇವಲ `messages[].content` ಅನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ. ಇದು ಕೆಳಗಿನವುಗಳನ್ನು ಪರಿಶೀಲಿಸುವುದಿಲ್ಲ:

- `system` ಪ್ರಾಂಪ್ಟ್
- ರಚನಾತ್ಮಕ ವಿಷಯ ಬ್ಲಾಕ್ಗಳು (`tool_result`, `tool_use`, `thinking`, `image`)
- ಟೂಲ್ನ `description` ಮತ್ತು `input_schema` ಕ್ಷೇತ್ರಗಳು
- ವಿನಂತಿಯ ಮೆಟಾಡೇಟಾ, ಹೆಡರ್ಗಳು ಅಥವಾ ಮಾಡೆಲ್ ಐಡಿ

## ಯಾವಾಗಲೂ ನಿರ್ಬಂಧಿಸಲಾಗುವ ಮಾದರಿಗಳು (ದೊಡ್ಡಕ್ಷರ-ಸಣ್ಣಕ್ಷರ ವ್ಯತ್ಯಾಸವಿಲ್ಲದೆ)

| ಮಾದರಿ                           | ಟಿಪ್ಪಣಿಗಳು                                                          |
| ------------------------------- | ------------------------------------------------------------------- |
| ಯಾವುದೇ `Lorem ipsum` ರೂಪಾಂತರ    | ಸಂಪೂರ್ಣ ಲ್ಯಾಟಿನ್ lorem ಪದಸಂಪತ್ತನ್ನು ನಿರ್ಬಂಧಿಸಲಾಗಿದೆ                 |
| `language model` (ಪ್ರತ್ಯೇಕವಾಗಿ) | "the language model" ಮತ್ತು "large language model" ಅನುಮತಿಸಲ್ಪಡುತ್ತವೆ |
| `virtual assistant`             | "AI assistant" ಅನುಮತಿಸಲ್ಪಡುತ್ತದೆ                                    |
| `I'm here to help`              | "here to help" ಮಾತ್ರ ಇದ್ದರೂ ನಿರ್ಬಂಧಿಸಲಾಗುತ್ತದೆ                      |
| `Claude, made by Anthropic`     | ಸಂಪೂರ್ಣ ನುಡಿಗಟ್ಟು ಮಾತ್ರ                                             |

## ಬಹುತೇಕ ಯಾವಾಗಲೂ ನಿರ್ಬಂಧಿಸಲಾಗುವ ಮಾದರಿಗಳು

| ಮಾದರಿ                                                        | ಟಿಪ್ಪಣಿಗಳು                                                        |
| ------------------------------------------------------------ | ----------------------------------------------------------------- |
| `placeholder`                                                | ಅದು ಪ್ರತ್ಯೇಕವಾಗಿ ಇದ್ದಾಗ (ಪ್ಯಾರಾಮೀಟರ್ ಹೆಸರಾಗಿ ಇತ್ಯಾದಿ ಅಲ್ಲದಿದ್ದಾಗ) |
| `dummy data`                                                 | ಫಿಕ್ಸ್ಚರ್ಗಳಿಗಾಗಿ ಸಾಮಾನ್ಯ ಸೀಡ್ ನುಡಿಗಟ್ಟು                           |
| `foo bar baz`                                                | ಪ್ರಮಾಣಿತ ಪ್ಲೇಸ್ಹೋಲ್ಡರ್ ನುಡಿಗಟ್ಟು                                  |
| ಪುನರಾವರ್ತಿತ ಚಿಕ್ಕ ಟೋಕನ್ಗಳು (`AAA BBB CCC`, `test test test`) | ಕೀವರ್ಡ್ ತುಂಬುವಿಕೆಯನ್ನು ಪತ್ತೆಹಚ್ಚುವ ಡಿಟೆಕ್ಟರ್                      |

## ಲೋಡ್ನಲ್ಲಿನ ವರ್ತನೆ

ಕಡಿಮೆ ಅವಧಿಯಲ್ಲಿ ಸುಮಾರು 5 ವೇಗವಾದ ವಿನಂತಿಗಳ ನಂತರ, ಸಾಮಾನ್ಯವಾಗಿ ಅನುಮತಿಸಲ್ಪಡುವ ವಿಷಯವನ್ನೂ WAF ನಿರ್ಬಂಧಿಸಲು ಪ್ರಾರಂಭಿಸುತ್ತದೆ. ಸುಮಾರು 5–10 ಸೆಕೆಂಡ್ಗಳ ನಿಷ್ಕ್ರಿಯ ಅವಧಿಯ ನಂತರ ಬಕೆಟ್ ಸಡಿಲಗೊಳ್ಳುತ್ತದೆ. Claude Code ಅಥವಾ Codex CLI ಹಲವು ಟೂಲ್-ಬಳಕೆ / ಸಂದೇಶ-ಕಳುಹಿಸುವ ಕರೆಗಳನ್ನು ತ್ವರಿತವಾಗಿ ಮಾಡಿದಾಗ ಮಧ್ಯಂತರವಾಗಿ `400 content-blocked` ದೋಷಗಳನ್ನು ಉಂಟುಮಾಡುವ ಅದೇ IP-ಮತ್ತು-ಕೀ-ಬೌಂಡ್ ದರ ಮಿತಿಗಾರಕ ಇದಾಗಿದೆ.

## OmniRoute ನಲ್ಲಿ ಈಗಾಗಲೇ ಅನ್ವಯಿಸಲಾದ ಪರಿಹಾರ ಕ್ರಮಗಳು

1. **`open-sse/services/wafRateLimit.ts`** — ಯಾವುದೇ `agentrouter:*` URL ಗೆ ಹೊರಹೋಗುವ ವಿನಂತಿಗಳ ನಡುವೆ ಕನಿಷ್ಠ 500 ms ಅಂತರವನ್ನು ಕಡ್ಡಾಯಗೊಳಿಸುವ ಬರ್ಸ್ಟ್ ಗಾರ್ಡ್. ಈ ಅಂತರವು ಮಾನವ ಗ್ರಹಿಕೆಗೆ ತಾಗದಷ್ಟು ಕಡಿಮೆ ವಿಳಂಬವಾಗಿದ್ದು, ಸಾಮಾನ್ಯ ಟ್ರಾಫಿಕ್ನಲ್ಲಿ WAF ಸಕ್ರಿಯಗೊಳ್ಳುವುದನ್ನು ತಡೆಯುತ್ತದೆ.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — ಅಪ್ಸ್ಟ್ರೀಮ್ `400 content-blocked` ಅನ್ನು ಹಿಂತಿರುಗಿಸಿದಾಗ, ಎಕ್ಸಿಕ್ಯೂಟರ್ ಅದೇ URL ಅನ್ನು ಎಕ್ಸ್ಪೊನೆನ್ಷಿಯಲ್ ಬ್ಯಾಕ್ಆಫ್ನೊಂದಿಗೆ (1.5 s, 3.0 s, ಗರಿಷ್ಠ 2 ಪ್ರಯತ್ನಗಳು) ಮರುಪ್ರಯತ್ನಿಸುತ್ತದೆ. ಬ್ಯಾಕ್ಆಫ್ ನಂತರ WAF ಸಾಮಾನ್ಯವಾಗಿ ಸಡಿಲಗೊಳ್ಳುತ್ತದೆ ಮತ್ತು ಮರುಪ್ರಯತ್ನ ಯಶಸ್ವಿಯಾಗುತ್ತದೆ.

3. **`tests/unit/compression/harness.test.ts`** — Claude Code ಈ ಫೈಲ್ ಅನ್ನು `Read` ಟೂಲ್ ಮೂಲಕ ಓದಿದಾಗ, ಫೈಲ್ನ ವಿಷಯಗಳು `tool_result` ಬ್ಲಾಕ್ ಮೂಲಕ ಹಿಂದಕ್ಕೆ ಹರಿದು WAF ಅನ್ನು ಪ್ರಚೋದಿಸದಂತೆ, ಪರೀಕ್ಷಾ ಫಿಕ್ಸ್ಚರ್ `longInput` ಅನ್ನು `"lorem ipsum dolor sit amet ".repeat(40)` ನಿಂದ `"example content for testing purposes ".repeat(40)` ಗೆ ಬದಲಾಯಿಸಲಾಗಿದೆ.

## ಪ್ರಾಂಪ್ಟ್ಗಳು ಮತ್ತು ಟೂಲ್ ಔಟ್ಪುಟ್ಗೆ ಮಾರ್ಗದರ್ಶನ

Claude Code ಅಥವಾ Codex CLI ಸೆಷನ್ ಪದೇಪದೇ `400 content-blocked` ಅನ್ನು ಎದುರಿಸಿದರೆ, ಮೇಲಿನ ಯಾವುದೇ ಮಾದರಿಗಳಿಗಾಗಿ ತೀರಾ ಇತ್ತೀಚಿನ ಬಳಕೆದಾರ ಸಂದೇಶ ಮತ್ತು ತೀರಾ ಇತ್ತೀಚಿನ ಟೂಲ್ ಫಲಿತಾಂಶವನ್ನು ಪರಿಶೀಲಿಸಿ, ನಂತರ ಅದನ್ನು ಬೇರೆ ರೀತಿಯಲ್ಲಿ ಬರೆಯಿರಿ. ಸಾಮಾನ್ಯ ಪರ್ಯಾಯ ವಿಧಾನಗಳು:

- `Lorem ipsum …` ಅನ್ನು `example text …` ಅಥವಾ ಪರೀಕ್ಷೆ ಅಥವಾ ಫಿಕ್ಸ್ಚರ್ ಮಾದರಿಯಾಗಿಸಲು ಪ್ರಯತ್ನಿಸುತ್ತಿರುವ ನೈಜ ವಿಷಯದಿಂದ ಬದಲಾಯಿಸಿ.
- `placeholder` ಅನ್ನು (ಅದು ಪ್ರತ್ಯೇಕವಾಗಿ ಇದ್ದಾಗ) `example value`, `sample value`, ಅಥವಾ ನೈಜ ಮೌಲ್ಯದಿಂದ ಬದಲಾಯಿಸಿ.
- `language model` ಅನ್ನು `large language model` ಅಥವಾ `the model` ನಿಂದ ಬದಲಾಯಿಸಿ.
- `dummy data` ಅನ್ನು `sample data` ಅಥವಾ ವಾಸ್ತವಿಕ ಸೀಡ್ ಮೌಲ್ಯಗಳಿಂದ ಬದಲಾಯಿಸಿ.
- `I'm here to help` / `here to help` ಅನ್ನು ಹೆಚ್ಚು ನಿರ್ದಿಷ್ಟವಾದ ಆರಂಭಿಕ ವಾಕ್ಯದಿಂದ ಬದಲಾಯಿಸಿ (ಉದಾ. "I'll review the file you mentioned").

## ತಪ್ಪಾದ ಧನಾತ್ಮಕ ಫಲಿತಾಂಶಗಳನ್ನು ಅಪ್ಸ್ಟ್ರೀಮ್ಗೆ ವರದಿ ಮಾಡುವುದು

ಪ್ರಸ್ತುತ ಫಿಲ್ಟರ್ ಅತಿಯಾಗಿ ಆಕ್ರಮಣಕಾರಿಯಾಗಿದೆ — ಆಪರೇಟರ್ ಸ್ಪಷ್ಟವಾಗಿ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಸೇರಿಸಲು ಉದ್ದೇಶಿಸದಿದ್ದರೂ, ಅದು `tool_result` ಬ್ಲಾಕ್ಗಳಲ್ಲಿನ "Lorem ipsum" ಅನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ. ಇದನ್ನು ಮೂಲದಲ್ಲೇ ಸರಿಪಡಿಸಲು ಬಯಸುವ ಆಪರೇಟರ್ಗಳು ತಪ್ಪಾದ ಧನಾತ್ಮಕ ಫಲಿತಾಂಶಗಳನ್ನು ವರದಿ ಮಾಡಲು `agentrouter.org` ಅನ್ನು ಸಂಪರ್ಕಿಸಬೇಕು. ಮೇಲಿನ ಬ್ಲಾಕ್ಲಿಸ್ಟ್ 2026-08-03 ರಂತೆ ಅಪ್ಸ್ಟ್ರೀಮ್ ಅನ್ನು ಪರೀಕ್ಷಿಸಿದಾಗ ದೊರೆತ ಪ್ರಾಯೋಗಿಕ ಫಲಿತಾಂಶವಾಗಿದೆ.
