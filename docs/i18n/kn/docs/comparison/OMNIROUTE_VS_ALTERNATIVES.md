## OmniRoute ಅನ್ನು ಯಾವಾಗ ಆಯ್ಕೆ ಮಾಡಬೇಕು

- ನೀವು ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಮಾಡುತ್ತೀರಿ ಮತ್ತು **ಗರಿಷ್ಠ ಪೂರೈಕೆದಾರ ವ್ಯಾಪ್ತಿ** ಬಯಸುತ್ತೀರಿ (329 ಪೂರೈಕೆದಾರರು, 155 ಉಚಿತ/ದೃಢೀಕರಣ-ರಹಿತ ಕ್ಯಾಟಲಾಗ್ ನಮೂದುಗಳು)
- ನಿಮಗೆ **ಅಂತರ್ನಿರ್ಮಿತ MCP ಸರ್ವರ್** ಅಗತ್ಯವಿದೆ (LLM ಪರಿಕರಗಳು, ಮೆಮೊರಿ ಮತ್ತು ಕೌಶಲ್ಯಗಳನ್ನು ಪರಿಕರಗಳಾಗಿ ಒದಗಿಸಲಾಗುತ್ತದೆ)
- ಏಜೆಂಟ್ನಿಂದ-ಏಜೆಂಟ್ಗೆ ವರ್ಕ್ಫ್ಲೋಗಳಿಗಾಗಿ ನಿಮಗೆ **A2A ಪ್ರೋಟೋಕಾಲ್** ಅಗತ್ಯವಿದೆ
- ಅಪ್ಸ್ಟ್ರೀಮ್ CAPTCHAಗಳಿಂದ ಪತ್ತೆಯಾಗುವುದನ್ನು ತಪ್ಪಿಸಲು ನಿಮಗೆ **ಫಿಂಗರ್ಪ್ರಿಂಟ್ ರಹಸ್ಯತೆ** (JA3/JA4) ಬೇಕು
- SaaS ಬಿಲ್ ಇಲ್ಲದೆ ನಿಮಗೆ **ಎಂಟರ್ಪ್ರೈಸ್ ವೈಶಿಷ್ಟ್ಯಗಳು** (ರಕ್ಷಣಾ ನಿಯಮಗಳು, ಮೌಲ್ಯಮಾಪನಗಳು, ಆಡಿಟ್ ಟ್ರೇಲ್) ಅಗತ್ಯವಿದೆ

## LiteLLM ಅನ್ನು ಯಾವಾಗ ಆಯ್ಕೆ ಮಾಡಬೇಕು

- ನೀವು **Python-ಪ್ರಥಮ** ವಿಧಾನ ಅನುಸರಿಸುತ್ತೀರಿ ಮತ್ತು `litellm.completion()` ಜೊತೆಗೆ ನಿಕಟ ಏಕೀಕರಣ ಬೇಕು
- ನಿಮಗೆ **ಪ್ರಬುದ್ಧ ಪ್ರೊಡಕ್ಷನ್ ನಿಯೋಜನಾ ವಿಧಾನಗಳು** (k8s, Helm ಚಾರ್ಟ್ಗಳು) ಅಗತ್ಯವಿವೆ
- ನಿಮ್ಮ ತಂಡ ಈಗಾಗಲೇ Python ಮೈಕ್ರೋಸರ್ವಿಸ್ಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತಿದೆ

## OpenRouter (SaaS) ಅನ್ನು ಯಾವಾಗ ಆಯ್ಕೆ ಮಾಡಬೇಕು

- ನೀವು ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಮಾಡಲು ಬಯಸುವುದಿಲ್ಲ
- SaaS ಮಾರ್ಕ್ಅಪ್ನೊಂದಿಗೆ ಪ್ರತಿ-ಟೋಕನ್ಗೆ ಪಾವತಿಸಲು ನಿಮಗೆ ತೊಂದರೆಯಿಲ್ಲ
- ಎಲ್ಲಾ ಪೂರೈಕೆದಾರರಿಗೆ ಒಂದೇ **ಪಾವತಿ ವಿಧಾನ** ನಿಮಗೆ ಅಗತ್ಯವಿದೆ

## Portkey ಅನ್ನು ಯಾವಾಗ ಆಯ್ಕೆ ಮಾಡಬೇಕು

- ಅಪ್ಟೈಮ್ ಖಾತರಿಗಳೊಂದಿಗೆ ನಿಮಗೆ **ವಾಣಿಜ್ಯ SLA** ಅಗತ್ಯವಿದೆ
- ಕಾರ್ಯಾಚರಣಾ ನಿರ್ವಹಣೆಯ ಹೆಚ್ಚುವರಿ ಹೊರೆ ಇಲ್ಲದ **ನಿರ್ವಹಿತ ಡ್ಯಾಶ್ಬೋರ್ಡ್** ಅನ್ನು ನೀವು ಬಯಸುತ್ತೀರಿ
- ಯಾವುದೇ ಹೆಚ್ಚುವರಿ ಸಂರಚನೆಯಿಲ್ಲದೆ ನಿಮಗೆ **ಎಂಟರ್ಪ್ರೈಸ್ ಅನುಸರಣೆ** ವೈಶಿಷ್ಟ್ಯಗಳು ಅಗತ್ಯವಿವೆ
