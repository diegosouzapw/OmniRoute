ಮರುಪ್ರಯತ್ನದ ನಿರ್ಧಾರಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳುವ ಮೊದಲು ವೈಫಲ್ಯಗಳನ್ನು ವರ್ಗೀಕರಿಸಲಾಗುತ್ತದೆ.

ಕಾಲಾವಧಿ ಮೀರುವಿಕೆಗಳು, ನೆಟ್ವರ್ಕ್ ದೋಷಗಳು, ದರ ಮಿತಿಗಳು ಮತ್ತು ಪೂರೈಕೆದಾರರ 5xx ಪ್ರತಿಕ್ರಿಯೆಗಳಂತಹ ತಾತ್ಕಾಲಿಕ ವೈಫಲ್ಯಗಳ ಸಂದರ್ಭದಲ್ಲಿ ಪರ್ಯಾಯ ಪೂರೈಕೆದಾರರಿಗೆ ಬದಲಾಯಿಸಬಹುದು. ದೃಢೀಕರಣ ದೋಷಗಳು, ಅನುಮತಿ ದೋಷಗಳು, ಅಮಾನ್ಯ ವಿನಂತಿಗಳು, ಲಭ್ಯವಿಲ್ಲದ ಮಾದರಿಗಳು ಮತ್ತು ಅಜ್ಞಾತ ವೈಫಲ್ಯಗಳನ್ನು ವಿವೇಚನೆಯಿಲ್ಲದೆ ಮರುಪ್ರಯತ್ನಿಸಲಾಗುವುದಿಲ್ಲ.

ಡೀಫಾಲ್ಟ್ ಅಂತರ-ಪೂರೈಕೆದಾರ ನೀತಿಯು ಗರಿಷ್ಠ ಮೂರು ಪೂರೈಕೆದಾರ ಪ್ರಯತ್ನಗಳಿಗೆ ಅವಕಾಶ ನೀಡುತ್ತದೆ, ದರ ಮಿತಿಗಳು ಮತ್ತು ಕಾಲಾವಧಿ ಮೀರುವಿಕೆಗಳ ಸಂದರ್ಭದಲ್ಲಿ ಮರುಪ್ರಯತ್ನಿಸುತ್ತದೆ ಮತ್ತು ಆಡಳಿತಾತ್ಮಕ ನಿಷ್ಕ್ರಿಯಗೊಳಿಸುವಿಕೆಯನ್ನು ತಾತ್ಕಾಲಿಕ ಸರ್ಕ್ಯೂಟ್ ಸ್ಥಿತಿಯಿಂದ ಪ್ರತ್ಯೇಕವಾಗಿರಿಸುತ್ತದೆ.

ಸರ್ಕ್ಯೂಟ್ ಸ್ಥಿತಿಗಳು `closed`, `open` ಮತ್ತು `half_open` ಆಗಿವೆ. ಶಮನ ಅವಧಿಯು ಮಿತಿಗೊಳಿಸಿದ ಪ್ರೋಬ್ ಅನ್ನು ನಿಗದಿಪಡಿಸುತ್ತದೆ; ಯಶಸ್ವಿ ಪ್ರೋಬ್ ಸರ್ಕ್ಯೂಟ್ ಅನ್ನು ಮುಚ್ಚುತ್ತದೆ ಮತ್ತು ವಿಫಲವಾದ ಪ್ರೋಬ್ ಅದನ್ನು ಮತ್ತೆ ತೆರೆಯುತ್ತದೆ.
