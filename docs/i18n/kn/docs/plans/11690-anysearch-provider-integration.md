ಟೆಂಪ್ಲೇಟ್: xquik #11370 (release/v3.8.51 ನಲ್ಲಿ ವಿಲೀನಗೊಳಿಸಲಾಗಿದೆ). ನಿಲುವು: `fallbackOnly`.
ಅಪ್ಸ್ಟ್ರೀಮ್ ಪ್ರಸ್ತಾವನೆ: issue diegosouzapw/OmniRoute#11637.

## 1. ಸೇವೆಯ ಅಧಿಕೃತ ವಾಸ್ತವಾಂಶಗಳು (ಅಧಿಕೃತ ದಸ್ತಾವೇಜುಗಳು, ಅಡ್ಡ-ಪರಿಶೀಲಿಸಲಾಗಿದೆ)

- ಮೂಲ URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - ಪ್ಯಾರಾಮೀಟರ್ಗಳು: `query` (ಅಗತ್ಯ), `max_results` (1-10, ಡೀಫಾಲ್ಟ್ 10), `tag` (`{domain}.{sub_domain}` ವರ್ಟಿಕಲ್ ರೂಟಿಂಗ್), `zone` (cn/intl), `language`, `params` (ರಚನಾತ್ಮಕ ವರ್ಟಿಕಲ್ ಕ್ಷೇತ್ರಗಳು), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - ಸಾಮರ್ಥ್ಯ ಕ್ಯಾಟಲಾಗ್, ಕೋಟಾದಲ್ಲಿ ಎಣಿಕೆಯಾಗುವುದಿಲ್ಲ.
- `POST /v1/extract` - `{url, title, content}` ಅನ್ನು ಪಡೆದು/ಹೊರತೆಗೆಯುತ್ತದೆ; ಕಟ್ಟುನಿಟ್ಟಾದ JSON ಬಾಡಿ, 16 KiB ಮಿತಿ.
- `POST /v1/auth/email/register` - ಒಂದೇ ಕರೆಯ ನೋಂದಣಿ, ಒಂದು ಬಾರಿ ಮಾತ್ರ ಬಳಸಬಹುದಾದ ಸರಳ ಪಠ್ಯ ಕೀ `as_sk_...` ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ.
- ದೃಢೀಕರಣ: ಐಚ್ಛಿಕ `Authorization: Bearer <as_sk_...>`; ಅನಾಮಧೇಯ ಬಳಕೆಯು ದೈನಂದಿನ ಉಚಿತ ಕೋಟಾವನ್ನು ಬಳಸುವ ಪ್ರತಿ-IP ಮಿತಿಗಳಿಗೆ ಇಳಿಯುತ್ತದೆ; ಅಮಾನ್ಯ ಕೀ ಯಾವುದೇ ಮೌನ ಅನಾಮಧೇಯ ಫಾಲ್ಬ್ಯಾಕ್ ಇಲ್ಲದೆ 401/403 ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ.
- ಉಚಿತ ಹಂತ: ದಿನಕ್ಕೆ 1000 ವಿನಂತಿಗಳು, ಪ್ರತಿ ಕೀಗೆ 20 QPS. ಪಾವತಿಸಿದ ಹಂತ: ಬೆಲೆ ನಿಗದಿಯಾಗಿಲ್ಲ (ಶೀಘ್ರದಲ್ಲೇ ಬರಲಿದೆ).
- ಪ್ರತಿಕ್ರಿಯೆ ಎನ್ವಲಪ್: ಯಶಸ್ಸು `{code: 0, message: "success", request_id, data}`; ವೈಫಲ್ಯ `{code: -1, message}`. ದೃಢೀಕರಣ/ಕೋಟಾ ದೋಷಗಳು ರಚನಾತ್ಮಕ `error_code` ಅನ್ನು ಹೊಂದಿರುವುದಿಲ್ಲ (ಸಂದೇಶದ ಪಠ್ಯವೇ ಸಂಕೇತ); extract-ನಿರ್ದಿಷ್ಟ ದೋಷಗಳು `error_code` ಅನ್ನು ಹೊಂದಿರುತ್ತವೆ (`invalid_extract_url`, `extract_failed`). 429 ನಲ್ಲಿ `Retry-After` ಹೆಡರ್ ಇರುವುದಿಲ್ಲ.

## 3. ನಿರ್ಧಾರಗಳು (ಎಲ್ಲವೂ 2026-08-26 ರಂದು ತೆಗೆದುಕೊಳ್ಳಲಾಗಿದೆ)

1. **ರೂಟಿಂಗ್ ನಿಲುವು: `fallbackOnly`.** ತಾರ್ಕಿಕ ಕಾರಣ: ವೆಚ್ಚ-0 ಉಚಿತ ಪೂರೈಕೆದಾರವು ಸ್ವಯಂಚಾಲಿತ ವೆಚ್ಚ ರೂಟಿಂಗ್ನಲ್ಲಿ ಎಂದಿಗೂ ಪ್ರಾಬಲ್ಯ ಸಾಧಿಸಬಾರದು; ಸ್ಪಷ್ಟ ಆಯ್ಕೆ ಮತ್ತು ವಿಫಲತೆಯ ನಂತರದ ವಾಪಸಾತಿಗೆ ಯಾವುದೇ ಪರಿಣಾಮವಿಲ್ಲ. ಪೂರ್ವನಿದರ್ಶನ: ವಿಲೀನಗೊಳಿಸಲಾದ xquik ನಮೂದು.
2. **ವ್ಯಾಪ್ತಿ: v1 ನಲ್ಲಿ `POST /v1/extract` ಮೂಲಕ webSearch + webFetch.** tavily/exa ದ್ವಿ-ಸಾಮರ್ಥ್ಯದ ಪರಿಕಲ್ಪನಾ ಮಾದರಿಯೊಂದಿಗೆ ಹೊಂದಿಕೆಯಾಗುತ್ತದೆ. ವರ್ಟಿಕಲ್ ಮೇಲ್ಮೈಗಳು (`tag`, `sub-domains`, `batch_search`) ವ್ಯಾಪ್ತಿಯಿಂದ ಹೊರಗಿರುತ್ತವೆ — ಪ್ರಸ್ತುತ ವರ್ಟಿಕಲ್ ಪ್ಯಾರಾಮೀಟರ್ಗಳಿಗೆ ಯಾವುದೇ IR ಇಲ್ಲ.
3. **ಕೋಟಾ ಪ್ರದರ್ಶನ: `freeMonthlyQuota: 0`** (xquik-ಶೈಲಿಯ ಸಂಪ್ರದಾಯಬದ್ಧ ಪ್ರದರ್ಶನ). ನೈಜ ಮಿತಿ (ದಿನಕ್ಕೆ 1000 ವಿನಂತಿಗಳು, ದೈನಂದಿನ ಮರುಹೊಂದಿಕೆ) ಬದಲಿಗೆ UI ಕ್ಯಾಟಲಾಗ್ನ `authHint` ಪಠ್ಯದಲ್ಲಿ ನೀಡಲಾಗುತ್ತದೆ. ತಾರ್ಕಿಕ ಕಾರಣ: ಕೋಟಾ ಪ್ರದರ್ಶನವು ಮರುಹೊಂದಿಕೆ ಅರ್ಥವ್ಯವಸ್ಥೆಗೆ ಹೊಂದಿಕೆಯಾಗಬೇಕು; ದೈನಂದಿನ ಮಿತಿಯನ್ನು ಮಾಸಿಕ-ಸಮಾನ ಪ್ರಮಾಣಕ್ಕೆ (30000) ಪರಿವರ್ತಿಸುವುದು UI ಪಾಲಿಸಲಾಗದ ಸುಳ್ಳು ಭರವಸೆಯಾಗಿದೆ.
4. **searchTypes: `["web"]` ಮಾತ್ರ.** AnySearch API ನಲ್ಲಿ ಸುದ್ದಿ/ಚಿತ್ರಗಳ ವರ್ಟಿಕಲ್ಗೆ ಯಾವುದೇ ಸಾರ್ವಜನಿಕ ಪುರಾವೆಯಿಲ್ಲ; ದಾಖಲಿತ ವರ್ಟಿಕಲ್ ಇಲ್ಲದ API ಗಳನ್ನು ಸಂಯೋಜಿಸುವ ಗೇಟ್ವೇಗಳು (ಉದಾ. Google Custom Search), news -> web ಅನ್ನು ಮೌನವಾಗಿ ಮ್ಯಾಪ್ ಮಾಡುವ ಬದಲು web ಅನ್ನು ಮಾತ್ರ ಬಹಿರಂಗಪಡಿಸುತ್ತವೆ.
5. **ಕೀ ನಿಲುವು:** ಕೀ ಇಲ್ಲದೆಯೂ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ; ಅಮಾನ್ಯ ಕೀ 401/403 ಅನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತದೆ ಮತ್ತು ಅದನ್ನು ಎಂದಿಗೂ ಮೌನವಾಗಿ ಅನಾಮಧೇಯ ಪ್ರವೇಶಕ್ಕೆ ಇಳಿಸಲಾಗುವುದಿಲ್ಲ (ಅಪ್ಸ್ಟ್ರೀಮ್ ಒಪ್ಪಂದವನ್ನು ಪ್ರತಿಬಿಂಬಿಸುತ್ತದೆ).
6. **ಉದ್ದೇಶಪೂರ್ವಕ ಹೊರಗಿಡುವಿಕೆಗಳು:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (ಚಾಟ್ ಇಂಟರ್ಸೆಪ್ಶನ್ firecrawl/jina/tavily ಆಗಿಯೇ ಉಳಿಯುತ್ತದೆ); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (ಅನಾಮಧೇಯ ರಿಮೋಟ್ ಎಂಡ್ಪಾಯಿಂಟ್ಗಳು ಪ್ರತಿ ಇಗ್ರೆಸ್ IPಗೆ ಒಂದೇ IP-ಮಿತಿಯ ಪೂಲ್ ಅನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತವೆ, ಆದ್ದರಿಂದ ಕೀ ಇಲ್ಲದ extract ಆಯ್ಕೆಯ ಮೂಲಕ ಬಳಸುವ ವೈಶಿಷ್ಟ್ಯವೇ ಹೊರತು ಸ್ವಯಂ-ರೂಟಿಂಗ್ ಅಭ್ಯರ್ಥಿಯಲ್ಲ); `QUOTA_STATUS_PROVIDERS` (AnySearch ಕೋಟಾವನ್ನು 402/403 ಸ್ಥಿತಿಯ ಮೂಲಕವಲ್ಲ, 429/ಎನ್ವಲಪ್ ಮೂಲಕ ಸೂಚಿಸುತ್ತದೆ).
