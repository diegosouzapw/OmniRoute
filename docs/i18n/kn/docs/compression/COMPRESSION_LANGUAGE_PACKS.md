Caveman ಸಂಕುಚನವು ಅಂತರ್ನಿರ್ಮಿತ ಇಂಗ್ಲಿಷ್ ನಿಯಮಗಳ ಜೊತೆಗೆ ಭಾಷೆ-ನಿರ್ದಿಷ್ಟ ನಿಯಮ ಪ್ಯಾಕ್ಗಳನ್ನು ಲೋಡ್ ಮಾಡಬಹುದು.
ಇದು ಮುಖ್ಯ ಎಂಜಿನ್ ಅನ್ನು ಸ್ಥಿರವಾಗಿರಿಸಿ, ಪೋರ್ಚುಗೀಸ್, ಸ್ಪ್ಯಾನಿಷ್, ಜರ್ಮನ್, ಫ್ರೆಂಚ್, ಇಟಾಲಿಯನ್, ಜಪಾನೀಸ್ ಮತ್ತು
ಭವಿಷ್ಯದ ಭಾಷಾ ಪ್ಯಾಕ್ಗಳು ಸ್ವತಂತ್ರವಾಗಿ ವಿಕಸಿಸಲು ಅವಕಾಶ ನೀಡುತ್ತದೆ.

## ಸ್ಥಳ

ಭಾಷಾ ಪ್ಯಾಕ್ಗಳು ಇಲ್ಲಿ ಇರುತ್ತವೆ:

```txt
open-sse/services/compression/rules/<language>/
```

ಪ್ರಸ್ತುತ ಒದಗಿಸಲಾದ ಪ್ಯಾಕ್ಗಳು (`rules/` ಡೈರೆಕ್ಟರಿಯ ವಿಷಯಗಳೊಂದಿಗೆ ಪರಿಶೀಲಿಸಲಾಗಿದೆ):

| ಭಾಷೆ                  | ಡೈರೆಕ್ಟರಿ      | ಲಭ್ಯವಿರುವ ನಿಯಮ ವರ್ಗಗಳು                              |
| --------------------- | -------------- | --------------------------------------------------- |
| ಇಂಗ್ಲಿಷ್              | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ಸ್ಪ್ಯಾನಿಷ್            | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ಪೋರ್ಚುಗೀಸ್ (ಬ್ರೆಜಿಲ್) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ಇಂಡೋನೇಷಿಯನ್           | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ಇಟಾಲಿಯನ್              | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ಜರ್ಮನ್                | `rules/de/`    | `context`, `filler`, `structural`                   |
| ಫ್ರೆಂಚ್               | `rules/fr/`    | `context`, `filler`, `structural`                   |
| ಜಪಾನೀಸ್               | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **ಸಮಾನತೆ ಕುರಿತ ಟಿಪ್ಪಣಿ:** `en`, `es`, `pt-BR`, `id`, ಮತ್ತು `it` ಪ್ಯಾಕ್ಗಳು ಎಲ್ಲಾ 5 ವರ್ಗಗಳನ್ನು ಹೊಂದಿವೆ; `de`, `fr`, `ja` ಪ್ಯಾಕ್ಗಳು 3 ವರ್ಗಗಳೊಂದಿಗೆ ಒದಗಿಸಲ್ಪಡುತ್ತವೆ. ಲಭ್ಯವಿಲ್ಲದ `dedup` ಮತ್ತು `ultra` ವರ್ಗಗಳು ಯಾವುದೇ ಸೂಚನೆಯಿಲ್ಲದೆ ಅಂತರ್ನಿರ್ಮಿತ ಇಂಗ್ಲಿಷ್ ನಿಯಮಗಳಿಗೆ ಹಿಂತಿರುಗುತ್ತವೆ. ಸಣ್ಣ ಪ್ಯಾಕ್ಗಳಿಗೆ `dedup.json` ಮತ್ತು `ultra.json` ಸೇರಿಸಲು ಕೊಡುಗೆಗಳನ್ನು ಸ್ವಾಗತಿಸುತ್ತೇವೆ.
>
> `pt-BR` ಪ್ಯಾಕ್ Lenine Júnior ಅವರ **[Troglodita](https://github.com/leninejunior/troglodita)** ಅನ್ನು ಆಧರಿಸಿದೆ — ಇದು ಬ್ರೆಜಿಲಿಯನ್ ಪೋರ್ಚುಗೀಸ್ ವ್ಯಾಕರಣಕ್ಕಾಗಿ ಆರಂಭದಿಂದಲೇ ವಿನ್ಯಾಸಗೊಳಿಸಲಾದ ಸಂಕುಚನ ವ್ಯವಸ್ಥೆಯಾಗಿದೆ (ಪುನರುಕ್ತಿ ಕಡಿತ, PT-BR ಪೂರಕ ಪದಗಳ ತೆಗೆದುಹಾಕುವಿಕೆ, dev BR ಸಮುದಾಯಕ್ಕಾಗಿ ತಾಂತ್ರಿಕ ಸಂಕ್ಷೇಪಣಗಳು).
>
> ಪ್ರಮಾಣಿತ ವರ್ಗ ಪಟ್ಟಿ ಮತ್ತು ಪ್ರತಿ-ವರ್ಗದ ಸ್ಕೀಮಾ [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) ನಲ್ಲಿ ಲಭ್ಯವಿವೆ (JSON Schema draft 2020-12).

## ಭಾಷೆ ಪತ್ತೆಹಚ್ಚುವಿಕೆ

`languageDetector.ts` ಪ್ರಾಂಪ್ಟ್ ಪಠ್ಯದಿಂದ ಭಾಷೆಯನ್ನು ಊಹಿಸಲು ಹಗುರವಾದ ಹ್ಯೂರಿಸ್ಟಿಕ್ಗಳನ್ನು ಬಳಸುತ್ತದೆ.
ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾದ ಡೀಫಾಲ್ಟ್ ಭಾಷೆಯನ್ನು ಇನ್ನೂ ಗೌರವಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ನಿಖರವಾದ ನಿಯಂತ್ರಣ ಅಗತ್ಯವಿದ್ದಾಗ
ಕಾನ್ಫಿಗ್ ಮೂಲಕ ಪತ್ತೆಹಚ್ಚುವಿಕೆಯನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸಬಹುದು.

ಪತ್ತೆಹಚ್ಚುವಿಕೆಯ ಔಟ್ಪುಟ್ ಅನ್ನು ನಿಯಮ ಪ್ಯಾಕ್ಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡಲು ಮಾತ್ರ ಬಳಸಲಾಗುತ್ತದೆ. ಇದು ಪ್ರೊವೈಡರ್ ರೂಟಿಂಗ್, ಲೊಕೇಲ್
ಆಯ್ಕೆ ಅಥವಾ UI ಭಾಷೆಯನ್ನು ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

## ಕಾನ್ಫಿಗ್ ರಚನೆ

ಸಂಕುಚನ ಸೆಟ್ಟಿಂಗ್ಗಳು ಇವುಗಳನ್ನು ಒಳಗೊಂಡಿರಬಹುದು:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` ಡ್ಯಾಶ್ಬೋರ್ಡ್/ಪೂರ್ವವೀಕ್ಷಣೆಯ ಡೀಫಾಲ್ಟ್ಗಳನ್ನು ನಿಯಂತ್ರಿಸುತ್ತದೆ. `cavemanConfig` ಎಂಬುದು Caveman ಸಂದೇಶದ ಪಠ್ಯವನ್ನು ಸಂಕುಚಿತಗೊಳಿಸುವಾಗ
ಬಳಸಲಾಗುವ ರನ್ಟೈಮ್ ಎಂಜಿನ್ ಕಾನ್ಫಿಗ್ ಆಗಿದೆ.

## ಭಾಷಾ ಪ್ಯಾಕ್ ಸೇರಿಸುವುದು

1. `open-sse/services/compression/rules/<language>/<pack>.json` ಅನ್ನು ರಚಿಸಿ.
2. `docs/compression/COMPRESSION_RULES_FORMAT.md` ನಲ್ಲಿರುವ Caveman ನಿಯಮದ ಸ್ವರೂಪವನ್ನು ಬಳಸಿ.
3. ಬದಲಾವಣೆಗಳನ್ನು ಮಿತವಾಗಿರಿಸಿ ಮತ್ತು ಕೋಡ್, ಗುರುತಿಸುವಿಕೆಗಳು, URLಗಳು ಅಥವಾ JSON ಅನ್ನು ಬದಲಾಯಿಸುವುದನ್ನು ತಪ್ಪಿಸಿ.
4. ಭಾಷೆಯ ಆಯ್ಕೆ ಮತ್ತು ಬದಲಿ ವರ್ತನೆಗಾಗಿ ಪರೀಕ್ಷೆಗಳನ್ನು ಸೇರಿಸಿ ಅಥವಾ ನವೀಕರಿಸಿ.
5. ಭಾಷೆಯು UI ಆಯ್ಕೆಪಟ್ಟಿಗಳಲ್ಲಿ ಕಾಣಿಸಿಕೊಂಡರೆ, ಹೊಸ ಡ್ಯಾಶ್ಬೋರ್ಡ್/i18n ಲೇಬಲ್ಗಳನ್ನು ಲಭ್ಯವಾಗುವಂತೆ ಮಾಡಿ.

## API

ಲಭ್ಯವಿರುವ ಪ್ಯಾಕ್ಗಳನ್ನು ಈ ಮೂಲಕ ಕ್ವೆರಿ ಮಾಡಬಹುದು:

```bash
curl http://localhost:20128/api/compression/language-packs
```

ಪೂರ್ವವೀಕ್ಷಣೆ ಎಂಡ್ಪಾಯಿಂಟ್ ಭಾಷಾ ಸಂರಚನೆಯ ಅತಿಕ್ರಮಣಗಳನ್ನು ಸ್ವೀಕರಿಸುತ್ತದೆ:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

ಎಲ್ಲಾ 6 ಭಾಷಾ ಪ್ಯಾಕ್ಗಳು v3.8.0 ನಲ್ಲಿ `SHARED_BOUNDARIES` ಷರತ್ತನ್ನು ಪಡೆದಿವೆ ಮತ್ತು ಅದನ್ನು ಪ್ರತಿಯೊಂದು
Caveman ತೀವ್ರತೆಯಲ್ಲೂ (LITE, FULL, ULTRA) ಅನ್ವಯಿಸಲಾಗುತ್ತದೆ. ಸುತ್ತಮುತ್ತಲಿನ ಅನಗತ್ಯ ಪಠ್ಯವನ್ನು ತೆಗೆದುಹಾಕಿದರೂ,
ಈ ಮಾದರಿಗಳನ್ನು ಯಥಾವತ್ತಾಗಿ ಉಳಿಸಿಕೊಳ್ಳುವಂತೆ ಅದು ಎಂಜಿನ್ಗೆ ಸೂಚಿಸುತ್ತದೆ:

| ಮಾದರಿಯ ಪ್ರಕಾರ                   | ಉದಾಹರಣೆ                                |
| ------------------------------- | -------------------------------------- |
| ಫೆನ್ಸ್ ಮಾಡಿದ ಕೋಡ್ ಬ್ಲಾಕ್ಗಳು     | ` ```python\n...\n``` `                |
| ಇನ್ಲೈನ್ ಕೋಡ್                    | `` `my_var` ``                         |
| URLಗಳು                          | `https://example.com/path`             |
| ಫೈಲ್ ಪಥಗಳು (ನಿರಪೇಕ್ಷ + ಸಾಪೇಕ್ಷ) | `/etc/hosts`, `./src/index.ts`         |
| ದೋಷ ಹೆಡರ್ಗಳು                    | `Error:`, `TypeError:`, `SyntaxError:` |
| ಸ್ಟ್ಯಾಕ್ ಟ್ರೇಸ್ ಸಾಲುಗಳು         | `  at functionName (file.ts:12:3)`     |

ಈ ಮಾದರಿಗಳನ್ನು `DEFAULT_CAVEMAN_CONFIG.preservePatterns` ನಲ್ಲಿ (ಈ ಹಿಂದೆ `[]`) ತುಂಬಲಾಗುತ್ತದೆ. ಈ
ಸ್ಥಿರಾಂಕವು `open-sse/services/compression/types.ts` ನಲ್ಲಿದೆ.

### ಇದು ಏಕೆ ಮುಖ್ಯ

SHARED_BOUNDARIES ಇಲ್ಲದೆ, ಆಕ್ರಮಣಕಾರಿ Caveman ಮೋಡ್ಗಳು ಪುನರಾವರ್ತಿತ ಗದ್ಯದಂತೆ ಕಾಣುವ, ಆದರೆ ವಾಸ್ತವವಾಗಿ
ಕೋಡ್ ತುಣುಕು, ಫೈಲ್ ಪಥ ಅಥವಾ ದೋಷ ಸ್ಟ್ಯಾಕ್ ಆಗಿರುವ ವಿಷಯವನ್ನು ತೆಗೆದುಹಾಕಬಹುದು. SHARED_BOUNDARIES ಅನಗತ್ಯ ಪಠ್ಯದ ನಿಯಮಗಳು
ಕಾರ್ಯಗತಗೊಳ್ಳುವ ಮೊದಲು ಅನ್ವಯಿಸುವ ಭಾಷಾ-ಸ್ವತಂತ್ರ ಸುರಕ್ಷತಾ ಜಾಲವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.

### preservePatterns ಅನ್ನು ಕಸ್ಟಮೈಸ್ ಮಾಡುವುದು

ಸಂಕುಚನ ಸೆಟ್ಟಿಂಗ್ಗಳ ಮೂಲಕ ರನ್ಟೈಮ್ನಲ್ಲಿ ಹೆಚ್ಚುವರಿ ಮಾದರಿಗಳನ್ನು ಸೇರಿಸಬಹುದು:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

ಕಸ್ಟಮ್ ಮಾದರಿಗಳು 6 ಡೀಫಾಲ್ಟ್ಗಳನ್ನು ವಿಸ್ತರಿಸುತ್ತವೆ (ಬದಲಿಸುವುದಿಲ್ಲ).

## ಕಾರ್ಯಾಚರಣೆಯ ಟಿಪ್ಪಣಿಗಳು

- ಭಾಷಾ ಪ್ಯಾಕ್ ಲಭ್ಯವಿಲ್ಲದಿದ್ದಾಗ, ಅಂತರ್ನಿರ್ಮಿತ ಇಂಗ್ಲಿಷ್ ನಿಯಮಗಳು ಫಾಲ್ಬ್ಯಾಕ್ ಆಗಿ ಉಳಿಯುತ್ತವೆ.
- ಅಮಾನ್ಯ ಅಂತರ್ನಿರ್ಮಿತ JSON ಪ್ಯಾಕ್ಗಳು ಮೌಲ್ಯಮಾಪನದಲ್ಲಿ ವಿಫಲವಾಗುತ್ತವೆ, ಇದರಿಂದ ಬಿಡುಗಡೆ ಸ್ವತ್ತುಗಳ ಗುಣಮಟ್ಟವು ಸದ್ದಿಲ್ಲದೆ ಕುಸಿಯುವುದಿಲ್ಲ.
- ನಿಯಮ ಪ್ಯಾಕ್ಗಳು ಡೇಟಾ-ಮಾತ್ರವಾಗಿದ್ದು, ಅವು ಕೋಡ್ ಅನ್ನು ಇಂಪೋರ್ಟ್ ಮಾಡಬಾರದು ಅಥವಾ ಅನಿಯಂತ್ರಿತ ತರ್ಕವನ್ನು ಚಲಾಯಿಸಬಾರದು.
- ಸಂಕುಚನ ವಿಶ್ಲೇಷಣಾ ಲೇಯರ್ ಆಯ್ಕೆಮಾಡಿದ ಮೋಡ್ ಮತ್ತು ಎಂಜಿನ್ ಅನ್ನು ದಾಖಲಿಸುತ್ತದೆ, ಸಂಪೂರ್ಣ ಪ್ರಾಂಪ್ಟ್ ಪಠ್ಯವನ್ನಲ್ಲ.
