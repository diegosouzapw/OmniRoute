## ವರ್ಗಗಳು

- **ಉಚಿತ** — API ಕೀಲಿಯೊಂದಿಗೆ ಉಚಿತ ಶ್ರೇಣಿ (ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಮೂಲಕ ಸಂರಚಿಸಲಾಗಿದೆ)
- **ದೃಢೀಕರಣವಿಲ್ಲ** — ಯಾವುದೇ ಕೀ ಅಥವಾ ಸೈನ್-ಇನ್ ಅಗತ್ಯವಿಲ್ಲದ ಸಾರ್ವಜನಿಕ ಎಂಡ್ಪಾಯಿಂಟ್ಗಳು
- **OAuth** — OmniRoute ನಿರ್ವಹಿಸುವ ಸೈನ್-ಇನ್ ಪ್ರಕ್ರಿಯೆ, API ಕೀ ಅಗತ್ಯವಿಲ್ಲ
- **ವೆಬ್ ಕುಕಿ** — ಕುಕಿ ದೃಢೀಕರಣದ ಮೂಲಕ ಪೂರೈಕೆದಾರರ ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಆವರಿಸುತ್ತದೆ
- **API ಕೀ** — API ಕೀಲಿಯ ಮೂಲಕ ಸಂರಚಿಸಲಾದ ಪಾವತಿಸಬೇಕಾದ ಪೂರೈಕೆದಾರ (ಉಚಿತ ಕ್ರೆಡಿಟ್ಗಳು ಅನ್ವಯಿಸಬಹುದು)
- **ಸ್ಥಳೀಯ** — ಬಳಕೆದಾರರ ಯಂತ್ರದಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ (Ollama, LM Studio, vLLM, ಇತ್ಯಾದಿ)
- **ಹುಡುಕಾಟ** — ವೆಬ್ ಹುಡುಕಾಟ ಪೂರೈಕೆದಾರರು
- **ಆಡಿಯೊ** — ಆಡಿಯೊ-ಮಾತ್ರ ಪೂರೈಕೆದಾರರು (TTS/STT)
- **ಅಪ್ಸ್ಟ್ರೀಮ್ ಪ್ರಾಕ್ಸಿ** — ಇತರ ಪೂರೈಕೆದಾರರಿಗೆ ಪ್ರಾಕ್ಸಿಯಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಪೂರೈಕೆದಾರರು
- **ಕ್ಲೌಡ್ ಏಜೆಂಟ್** — ದೀರ್ಘಕಾಲ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಕೋಡಿಂಗ್ ಏಜೆಂಟ್ಗಳು (Codex Cloud, Devin, Jules)
- **ಸಿಸ್ಟಮ್** — OmniRoute-ಆಂತರಿಕ ಪೂರೈಕೆದಾರರು (ಲೂಪ್ಬ್ಯಾಕ್, ಇತ್ಯಾದಿ)

ಹೆಚ್ಚುವರಿ ಟ್ಯಾಗ್ಗಳು: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (ತೋರಿಸಿದಲ್ಲಿ): `native` — ನೈಜ ಫಂಕ್ಷನ್-ಕಾಲಿಂಗ್ API; `emulated` — `tools` ಅರೇಯನ್ನು `webTools.ts` ಮೂಲಕ ಪ್ರಾಂಪ್ಟ್-ಅನುಕರಿಸಲಾಗುತ್ತದೆ (ರೆಜೆಕ್ಸ್ ಮೂಲಕ ಪಾರ್ಸ್ ಮಾಡಲಾದ `<tool>{...}</tool>` ಬ್ಲಾಕ್ಗಳು); `none` — ಪ್ರಸ್ತುತ `tools` ಅನ್ನು ಯಾವುದೇ ಸೂಚನೆಯಿಲ್ಲದೆ ಕೈಬಿಡಲಾಗುತ್ತದೆ. #7286 ನೋಡಿ.

ಪ್ರತಿ ಪೂರೈಕೆದಾರರನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಲು, ಸಂರಚಿಸಲು ಮತ್ತು ಪರೀಕ್ಷಿಸಲು `/dashboard/providers` ನಲ್ಲಿರುವ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಬಳಸಿ.
