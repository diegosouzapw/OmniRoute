OmniRoute ಆಯ್ದ ಉಚಿತ ಪ್ರಾಕ್ಸಿಗಳ ಸಂಗ್ರಹವನ್ನು `free_proxies` ಕೋಷ್ಟಕದಲ್ಲಿ ಒದಗಿಸುತ್ತದೆ,
ಇದನ್ನು ಬಾಹ್ಯ ಪೂರೈಕೆದಾರರಿಂದ (1proxy, proxifly, iplocate, webshare) ಸಿಂಕ್ ಮಾಡಲಾಗುತ್ತದೆ.
ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಇವುಗಳನ್ನು **Settings → Free Proxies** ಅಡಿಯಲ್ಲಿ ಪ್ರದರ್ಶಿಸುತ್ತದೆ. ಈ ದಸ್ತಾವೇಜು
ಪಟ್ಟಿ ರೂಟ್ ಒದಗಿಸುವ ಸರ್ವರ್-ಸೈಡ್ ಫಿಲ್ಟರಿಂಗ್, ವಿಂಗಡಣೆ, ಎಣಿಕೆ ಮತ್ತು ಸಿಂಕ್-ದೋಷ ವರದಿಯನ್ನು
ವಿವರಿಸುತ್ತದೆ.

## ಪಟ್ಟಿ ರೂಟ್ — `GET /api/settings/free-proxies`

ಫಿಲ್ಟರ್ ಮಾಡಿದ, ವಿಂಗಡಿಸಿದ, ಪುಟೀಕರಿಸಿದ ಭಾಗದ ಜೊತೆಗೆ ಒಟ್ಟು ಎಣಿಕೆಯನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ. ಫಿಲ್ಟರಿಂಗ್ ಮತ್ತು
ಎಣಿಕೆ SQL ನಲ್ಲಿ ನಡೆಯುವುದರಿಂದ, ಪ್ರತಿಯೊಂದು ಸಾಲನ್ನೂ ಮೆಮೊರಿಗೆ ಲೋಡ್ ಮಾಡದೆಯೇ UI ನೈಜ ಒಟ್ಟು ಸಂಖ್ಯೆಯನ್ನು
(ಉದಾ. `Total: 0`) ತೋರಿಸಬಹುದು.

### ಕ್ವೆರಿ ನಿಯತಾಂಕಗಳು

| ನಿಯತಾಂಕ           | ಪ್ರಕಾರ                             | ಡೀಫಾಲ್ಟ್  | ಅರ್ಥ                                                                                                                                               |
| ----------------- | ---------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | ಸ್ಟ್ರಿಂಗ್                          | `""`      | ಹೋಸ್ಟ್ (ಮತ್ತು ಮೂಲ) ಕಾಲಮ್ನಲ್ಲಿ ಕೇಸ್-ಸೆನ್ಸಿಟಿವ್ `LIKE`.                                                                                              |
| `protocol`        | ಸ್ಟ್ರಿಂಗ್                          | `""`      | `type` ಫಿಲ್ಟರ್: `http` / `https` / `socks4` / `socks5`. ಖಾಲಿ = ಎಲ್ಲವೂ.                                                                             |
| `country`         | ಸ್ಟ್ರಿಂಗ್                          | `""`      | `countryCode` ಫಿಲ್ಟರ್ (ISO-2). ಖಾಲಿ = ಎಲ್ಲವೂ.                                                                                                      |
| `minQuality`      | ಸಂಖ್ಯೆ                             | `0`       | `qualityScore >= minQuality` ಇರುವ ಸಾಲುಗಳು ಮಾತ್ರ. `0` = ಕನಿಷ್ಠ ಮಿತಿ ಇಲ್ಲ.                                                                           |
| `disabledSources` | ಸ್ಟ್ರಿಂಗ್                          | `""`      | ಹೊರಗಿಡಬೇಕಾದ, ಅಲ್ಪವಿರಾಮದಿಂದ ಬೇರ್ಪಡಿಸಿದ ಮೂಲ ಐಡಿಗಳು (ಉದಾ. `proxifly,webshare`).                                                                       |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = ಸ್ಕೋರ್ ಅವರೋಹಣ ಕ್ರಮದಲ್ಲಿ; `latency` = ಲೇಟೆನ್ಸಿ ಆರೋಹಣ ಕ್ರಮದಲ್ಲಿ (ಶೂನ್ಯ ಮೌಲ್ಯಗಳು ಕೊನೆಯಲ್ಲಿ); `recent` = `lastValidated` ಅವರೋಹಣ ಕ್ರಮದಲ್ಲಿ. |
| `offset`          | ಸಂಖ್ಯೆ                             | `0`       | ಪುಟೀಕರಣದ ಆರಂಭ.                                                                                                                                     |
| `limit`           | ಸಂಖ್ಯೆ                             | `50`      | ಪುಟದ ಗಾತ್ರ (ಸರ್ವರ್-ಸೈಡ್ನಲ್ಲಿ ಮಿತಿಗೊಳಿಸಲಾಗಿದೆ).                                                                                                     |

### ಪ್ರತಿಕ್ರಿಯೆ

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` ಪುಟೀಕರಣದ **ಮೊದಲು** ಫಿಲ್ಟರ್ ಮಾಡಿದ ಒಟ್ಟು ಸಂಖ್ಯೆಯನ್ನು ಪ್ರತಿಬಿಂಬಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ UI
`Total: N` ಮತ್ತು `hasMore` ಅನ್ನು ಸ್ವತಂತ್ರವಾಗಿ ರೆಂಡರ್ ಮಾಡಬಹುದು. `syncErrors` ಅನ್ನು ಮೂಲ ಐಡಿ ಆಧಾರವಾಗಿ
ಕೀ ಮಾಡಲಾಗುತ್ತದೆ ಮತ್ತು ಕೊನೆಯ ಸಿಂಕ್ ವಿಫಲವಾದ ಮೂಲಗಳಿಗೆ ಮಾತ್ರ ಭರ್ತಿ ಮಾಡಲಾಗುತ್ತದೆ — `Total: 0` ಫಲಿತಾಂಶವು
ಎಂದಿಗೂ ಮೌನವಾಗಿರುವುದಿಲ್ಲ.

## ಪೂಲ್ಗೆ ಸೇರಿಸುವುದು — `POST /api/settings/free-proxies/[id]/add-to-pool`

ಉಚಿತ ಪ್ರಾಕ್ಸಿಯನ್ನು ನಿರ್ವಹಿಸಲಾದ `proxy_registry` ಪೂಲ್ಗೆ ಬಡ್ತಿ ನೀಡುತ್ತದೆ. ಮೊದಲು
ಅಪ್ಸ್ಟ್ರೀಮ್ ಅನ್ನು ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ; ಯಶಸ್ವಿಯಾದರೆ ಹೊಸ ಪೂಲ್ ಪ್ರಾಕ್ಸಿ ಐಡಿ ಮತ್ತು ಅಳೆಯಲಾದ ಲೇಟೆನ್ಸಿಯನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ.

## ಸಿಂಕ್ — `POST /api/settings/free-proxies/sync`

ಸಕ್ರಿಯಗೊಳಿಸಲಾದ ಎಲ್ಲಾ ಮೂಲಗಳನ್ನು (ಅಥವಾ `{ "sources": [...] }` ನಲ್ಲಿರುವ ಉಪಸಮೂಹವನ್ನು) ಪುನಃ ಪಡೆಯುತ್ತದೆ. ಪ್ರತಿಯೊಂದು
ಮೂಲವು ಸ್ವತಂತ್ರವಾಗಿ ಸಿಂಕ್ ಆಗುತ್ತದೆ; ವಿಫಲವಾದ ಮೂಲವನ್ನು `syncErrors` ನಲ್ಲಿ ದಾಖಲಿಸಲಾಗುತ್ತದೆ ಮತ್ತು
ಉಳಿದವು ಇನ್ನೂ ಪೂರ್ಣಗೊಳ್ಳುತ್ತವೆ, ಆದ್ದರಿಂದ ಭಾಗಶಃ ಸಿಂಕ್ಗಳು ಹಿಂದಿನ ಉತ್ತಮ ಡೇಟಾವನ್ನು ಎಂದಿಗೂ ಅಳಿಸುವುದಿಲ್ಲ.

## ಅಂಕಿಅಂಶಗಳು — `GET /api/settings/free-proxies/stats`

ಸಾಲುಗಳ ಪೇಲೋಡ್ ಇಲ್ಲದೆ `total / inPool / avgQuality / bySource / lastSyncAt` ಒಟ್ಟುಗೂಡಿಸಿದ
ಮಾಹಿತಿಯನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ — ಇದನ್ನು ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಹೆಡರ್ ವಿಜೆಟ್ಗಳು ಬಳಸುತ್ತವೆ.
