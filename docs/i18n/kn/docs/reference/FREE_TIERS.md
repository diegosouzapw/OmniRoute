> **ಬಳಕೆದಾರರಿಗಾಗಿ**: ಸರಳ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ಹುಡುಕುತ್ತಿದ್ದೀರಾ? ಉಚಿತ AI ಪಡೆಯುವ ಹಂತ-ಹಂತದ ಸೂಚನೆಗಳಿಗಾಗಿ [ಉಚಿತ ಶ್ರೇಣಿಗಳ ಮಾರ್ಗದರ್ಶಿ](../getting-started/FREE-TIERS-GUIDE.md) ನೋಡಿ.

> **ಕೊನೆಯದಾಗಿ ಸಂಶೋಧಿಸಿದ್ದು:** 2026-06-17 — ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ವೆಬ್ ಸಂಶೋಧನೆ (ಅಧಿಕೃತ ದಾಖಲೆಗಳು + ಕಳೆದ 7 ದಿನಗಳ ಸುದ್ದಿಗಳು, ಪ್ರತಿಕೂಲ ಪರಿಶೀಲನೆಯೊಂದಿಗೆ 50-agent ಪರಿಶೀಲನೆ), ಪ್ರತಿಯೊಂದು ಉಚಿತ-ಶ್ರೇಣಿ ಕೋಟಾ + ToS ಅನ್ನು ನವೀಕರಿಸಲಾಗಿದೆ. **ಭಾಗಶಃ ಮರು-ಲೆಕ್ಕಪರಿಶೋಧನೆ 2026-09-02** (`gemini`, `ollama-cloud`, `groq`, `nara`, `mistral` — ಕೆಳಗಿನ ದಿನಾಂಕಿತ ಟಿಪ್ಪಣಿಯನ್ನು ನೋಡಿ).
> **ಸತ್ಯದ ಮೂಲ (ಕ್ಯಾಟಲಾಗ್):** `open-sse/config/freeModelCatalog.ts` (ಪ್ರತಿ-MODEL ಬಜೆಟ್ಗಳು, ಪೂಲ್-ನಕಲು ನಿವಾರಿಸಲಾಗಿದೆ). ಕೆಳಗಿನ ಟೋಕನ್-ಬಜೆಟ್ ಸಂಖ್ಯೆಗಳು ನೇರ ವೆಬ್ ಸಂಶೋಧನೆಯಿಂದ ಬಂದಿದ್ದು, ಅವು ಒಂದು **ಅಂದಾಜು** — [ವಿಧಾನ ಮತ್ತು ಮುನ್ನೆಚ್ಚರಿಕೆಗಳು](#methodology--caveats) ನೋಡಿ.

## TL;DR — OmniRoute ವಾಸ್ತವವಾಗಿ ಎಷ್ಟು ಉಚಿತ ಇನ್ಫರೆನ್ಸ್ ಅನ್ನು ಒಟ್ಟುಗೂಡಿಸುತ್ತದೆ?

| ಮೆಟ್ರಿಕ್                                        | ಟೋಕನ್ಗಳು / ತಿಂಗಳು  | ಅರ್ಥ                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ದಾಖಲಿತ ಪುನರಾವರ್ತಿತ ಅನುದಾನ (ಸ್ಥಿರ)**           | **~1.62B**         | ಉಚಿತ-ಶ್ರೇಣಿಯ **ಪೂಲ್ಗಳು** (ಪ್ರತಿ-ಮಾದರಿ ಕ್ಯಾಟಲಾಗ್), ಹಂಚಿಕೊಂಡಿರುವ ಪ್ರತಿಯೊಂದು ಪೂಲ್ ಅನ್ನು **ಒಮ್ಮೆ ಮಾತ್ರ** ಎಣಿಸಲಾಗಿದೆ. `/api/free-tier/summary` ಮತ್ತು ಡ್ಯಾಶ್ಬೋರ್ಡ್ನ Free-Tier Budget ಪುಟದ ಹಿಂದಿರುವ ಲೈವ್ ಮೂಲ. **ಈ ಸಂಖ್ಯೆಯನ್ನು ಬಳಸಿ.**                                                                                         |
| **+ ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗಳನ್ನು ಒಳಗೊಂಡ ಮೊದಲ ತಿಂಗಳು** | **~2.22B**         | ಸ್ಥಿರ ಮೊತ್ತ + ಒಂದು-ಬಾರಿಯ ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗಳು (Z.AI 20M, DeepSeek 5M, …), ಪ್ರತಿ ಖಾತೆಗೆ ನಕಲುಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ. **ಮೊದಲ ತಿಂಗಳಿಗೆ ಮಾತ್ರ** — ಪುನರಾವರ್ತಿಸುವುದಿಲ್ಲ.                                                                                                                                                       |
| **+ ಶಾಶ್ವತವಾಗಿ ಉಚಿತ, ಪ್ರಕಟಿತ ಮಿತಿಯಿಲ್ಲ**        | _ಪ್ರಮಾಣೀಕರಿಸಲಾಗದು_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — ನೈಜ ಪುನರಾವರ್ತಿತ ಪ್ರವೇಶ, ದರ/ಸಮಕಾಲೀನತೆ-ಮಿತಿಗೊಳಿಸಲಾಗಿದೆ, **ಎಣಿಸಲು ಟೋಕನ್ ಮಿತಿಯಿಲ್ಲ**. ಪಟ್ಟಿಮಾಡಲಾಗಿದೆ, ಎಂದಿಗೂ ಒಟ್ಟು ಮಾಡಲಾಗಿಲ್ಲ (`RPM×24/7` ದರದಲ್ಲಿ ಅವುಗಳನ್ನು ಎಣಿಸುವುದು ನಾವು ತಿರಸ್ಕರಿಸುವ ಉತ್ಪ್ರೇಕ್ಷೆ). |
| **+ ಠೇವಣಿ-ಅನ್ಲಾಕ್ ಹೆಚ್ಚಳ**                      | **+~24M**          | ಒಂದು-ಬಾರಿಯ **$10** OpenRouter ಟಾಪ್-ಅಪ್ ಅದರ ಉಚಿತ ಪೂಲ್ ಅನ್ನು ದಿನಕ್ಕೆ 50 → 1000 ವಿನಂತಿಗಳಿಗೆ ಹೆಚ್ಚಿಸುತ್ತದೆ. ಸ್ಥಿರ ಸಂಖ್ಯೆಯನ್ನು ಎಂದಿಗೂ ಉತ್ಪ್ರೇಕ್ಷಿಸದಂತೆ ಪ್ರತ್ಯೇಕವಾಗಿ ವರದಿ ಮಾಡಲಾಗಿದೆ.                                                                                                                                         |
| **+ ಪ್ರಾದೇಶಿಕ ಗುರುತು ಪರಿಶೀಲನೆಯ ಹಿಂದೆ**          | **+~6M**           | `modelscope` (Alibaba Cloud ಬಾಂಧವ್ಯ + ಚೀನಾ ಮುಖ್ಯಭೂಭಾಗದ ನೈಜ-ಹೆಸರು ಪರಿಶೀಲನೆ). ನೈಜ ಪುನರಾವರ್ತಿತ ಕೋಟಾ, `gatedRecurringTokens` / `gatedProviders` ಆಗಿ ಮತ್ತು ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ತೋರಿಸಲಾಗಿದೆ. ಮುಖ್ಯ ಸಂಖ್ಯೆಯಲ್ಲಿ ಎಂದಿಗೂ ಒಟ್ಟು ಮಾಡಲಾಗುವುದಿಲ್ಲ: ಪ್ರಾದೇಶಿಕ ಗುರುತು ಪರಿಶೀಲನೆಯ ಹಿಂದೆ +~6M.                                             |
| ಸೈದ್ಧಾಂತಿಕ ಗರಿಷ್ಠ ಮಿತಿ (ಎಲ್ಲ ದರ ಮಿತಿಗಳು, 24/7)  | ~10B               | ತಡೆರಹಿತ ಬಳಕೆಗೆ ವಿಸ್ತರಿಸಿದ ಪ್ರತಿಯೊಂದು ಪೂರೈಕೆದಾರರ ದರ ಮಿತಿಯ ಮೊತ್ತ. **ಖಾತರಿಯಲ್ಲ** — ಇದನ್ನು ಶೀರ್ಷಿಕೆಯಾಗಿ ಬಳಸಬೇಡಿ.                                                                                                                                                                                                           |

**ಪ್ರಾಮಾಣಿಕ ಶೀರ್ಷಿಕೆ:** _OmniRoute 35 ಉಚಿತ-ಶ್ರೇಣಿಯ ಪೂಲ್ಗಳಾದ್ಯಂತ **ತಿಂಗಳಿಗೆ ~1.62B ದಾಖಲಿತ ಉಚಿತ ಟೋಕನ್ಗಳನ್ನು** ಒಟ್ಟುಗೂಡಿಸುತ್ತದೆ (ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗಳೊಂದಿಗೆ ನಿಮ್ಮ ಮೊದಲ ತಿಂಗಳಲ್ಲಿ ~2.22B ವರೆಗೆ) — ಜೊತೆಗೆ ಶಾಶ್ವತವಾಗಿ ಉಚಿತವಾದ, ಮಿತಿಯಿಲ್ಲದ ಪೂರೈಕೆದಾರರ ದೀರ್ಘ ಪಟ್ಟಿಯೂ ಇದೆ — ಮತ್ತು RTK + Caveman ಕಂಪ್ರೆಷನ್ (15–95% ಟೋಕನ್ ಉಳಿತಾಯ) ಅದನ್ನು ಇನ್ನಷ್ಟು ವಿಸ್ತರಿಸುತ್ತದೆ._

> **ಇದು ಹಿಂದಿನ ~1.94B ಇಂದ ಏಕೆ ಕಡಿಮೆಯಾಯಿತು.** 2026-06-17 ರಿಫ್ರೆಶ್ ಪ್ರಾಮಾಣಿಕತೆಯ ತಿದ್ದುಪಡಿಯಾಗಿದೆ, ನಷ್ಟವಲ್ಲ: `gemini` ಅನ್ನು ಈಗ ಪೂಲ್ ಮಟ್ಟದಲ್ಲಿ ನಕಲು-ಮುಕ್ತಗೊಳಿಸಲಾಗಿದೆ (ಹಿಂದೆ ಪ್ರತಿಯೊಂದು Flash ರೂಪಾಂತರವನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ಎಣಿಸಿ ಉತ್ಪ್ರೇಕ್ಷಿಸಲಾಗಿತ್ತು, 462M → 60M), `cloudflare-ai` ಅನ್ನು ಅದರ ನೈಜ ದಿನಕ್ಕೆ 10k-Neurons ಗೆ ತಿದ್ದಲಾಗಿದೆ (122M → 30M), `doubao` ಅನ್ನು ಒಂದು-ಬಾರಿಯ ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ ಆಗಿ ಮರುವರ್ಗೀಕರಿಸಲಾಗಿದೆ (ಪುನರಾವರ್ತಿತವಲ್ಲ), ಮತ್ತು ಮುಚ್ಚಲ್ಪಟ್ಟ ಶ್ರೇಣಿಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ (`chutes`/`phind`/`kluster` ಸ್ಥಗಿತಗೊಂಡಿವೆ). ಇದನ್ನು `llm7` (ಸರಿಯಾದ ದಿನಕ್ಕೆ 5M → 150M) ಮತ್ತು ಹೊಸ ಉಚಿತ ಪೂರೈಕೆದಾರರು (Kilo, OpenCode Zen, Z.AI GLM-Flash) ಭಾಗಶಃ ಸರಿದೂಗಿಸಿದ್ದಾರೆ.
>
> **v3.8.42 ನಲ್ಲಿ ಮತ್ತಷ್ಟು ತಿದ್ದುಪಡಿ ಮಾಡಿ ~1.37B ಗೆ ಇಳಿಸಲಾಗಿದೆ:** `longcat` ನ ಉಚಿತ ಪೂರ್ವವೀಕ್ಷಣೆ ಕೊನೆಗೊಂಡ ನಂತರ, ಅದನ್ನು ತಿಂಗಳಿಗೆ 150M ಪುನರಾವರ್ತಿತ ಅನುದಾನದಿಂದ ಒಂದು-ಬಾರಿಯ 10M ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ ಆಗಿ ಮರುವರ್ಗೀಕರಿಸಲಾಗಿದೆ. ಅದೇ ಪ್ರಾಮಾಣಿಕತೆಯ ನಿಯಮ — ಯಾವುದೇ ಪೂರೈಕೆದಾರರನ್ನು ತಪ್ಪಾಗಿ ತೆಗೆದುಹಾಕಿಲ್ಲ.

> **Felo Web ಅನ್ನು ನಿವೃತ್ತಿಗೊಳಿಸಿದ ನಂತರ 2026-08-26 ರಂದು ನವೀಕರಿಸಲಾಗಿದೆ:** ಅದರ GPL-ಮೂಲದ ಉಗಮ/ಪರವಾನಗಿ HOLD ಸ್ಥಿತಿಯಲ್ಲಿರುವವರೆಗೆ Felo Web ಅನ್ನು ಹೊರಗಿಡಲಾಗಿದೆ; ಆ ಸಮಯದಲ್ಲಿ ಮೂಲವು 38 ಪೂಲ್ ಕೀಗಳನ್ನು ವರದಿ ಮಾಡಿತ್ತು. ಪೂಲ್ ಎಣಿಕೆ ಲೈವ್ ಆಗಿದ್ದು CI-ಗೇಟೆಡ್ ಆಗಿದೆ (`computeFreeModelTotals()` ನಿಂದ ಮೇಲಿನ ಸಂಖ್ಯೆಗಳು ಭಿನ್ನವಾದರೆ `check:docs-counts` ಬಿಲ್ಡ್ ಅನ್ನು ವಿಫಲಗೊಳಿಸುತ್ತದೆ).

> **2026-09-02 ರಂದು ಪೂರೈಕೆದಾರರ ಸ್ವಂತ ಪುಟಗಳ ಆಧಾರದ ಮೇಲೆ ಮರು-ಲೆಕ್ಕಪರಿಶೋಧಿಸಲಾಗಿದೆ** (ಮೂಲಗಳು: `open-sse/config/freeModelCatalog.data.ts` ನಲ್ಲಿ ಮರು-ಲೆಕ್ಕಪರಿಶೋಧಿಸಲಾದ ಪ್ರತಿ ನಮೂದಿನ ಪಕ್ಕದಲ್ಲಿರುವ `// evidence:` ಕಾಮೆಂಟ್ಗಳು): `gemini` ಮತ್ತು `ollama-cloud` ಇನ್ನು ಮುಂದೆ ಟೋಕನ್ ಸಂಖ್ಯೆಯನ್ನು ಪ್ರಕಟಿಸುವುದಿಲ್ಲ (Google 2025-12-23 ರಂದು ಪ್ರತಿ-ಮಾದರಿಯ ಉಚಿತ ಕೋಷ್ಟಕವನ್ನು ತೆಗೆದುಹಾಕಿತು; Ollama ನ Free ಯೋಜನೆ "starter usage credits" ಆಗಿದೆ) ಮತ್ತು ಈಗ ಅವುಗಳನ್ನು **ಮಿತಿಯಿಲ್ಲದವು** ಎಂದು ಪಟ್ಟಿಮಾಡಲಾಗಿದೆ, ಎಂದಿಗೂ ಒಟ್ಟು ಮಾಡಲಾಗುವುದಿಲ್ಲ (−80M); `groq` ಐದು **ಪ್ರತಿ-ಮಾದರಿಯ** 200K-TPD ಮಿತಿಗಳನ್ನು ಹೊಂದಿದೆ (ಪ್ರತಿಯೊಂದಕ್ಕೂ 6M, +15M), ಜೊತೆಗೆ ನಿವೃತ್ತಿಗೊಳಿಸಲಾದ ಮೂರು ID ಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ; `nara` ದಿನಕ್ಕೆ ಒಂದು 7M ಬಕೆಟ್ ಆಗಿದೆ (+60M, 210M). `mistral` ನ 1B ಖಾತೆಯ ಕನ್ಸೋಲ್ನಲ್ಲಿ ಮಾತ್ರ ಗೋಚರಿಸುತ್ತದೆ — ವಿಧಾನಶಾಸ್ತ್ರದ ಅಡಿಯಲ್ಲಿರುವ _ಸಾಕ್ಷ್ಯದ ವರ್ಗಗಳು_ ನೋಡಿ.
>
> **2026-09-03 ರಂದು ತಿದ್ದುಪಡಿ ಮಾಡಲಾಗಿದೆ (#11773):** `cerebras` ಅನ್ನು ತಿಂಗಳಿಗೆ 30M ಪುನರಾವರ್ತಿತ ಅನುದಾನದಿಂದ (ಹಳೆಯ, ಕಾರ್ಡ್ ಅಗತ್ಯವಿಲ್ಲದ ದಿನಕ್ಕೆ 1M ಟೋಕನ್ಗಳ ಪ್ರಯೋಗಾವಧಿ) ಪಾವತಿ ವಿಧಾನ ಅಗತ್ಯವಿರುವ ಒಂದು-ಬಾರಿಯ $5 ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ ಆಗಿ ಮರುವರ್ಗೀಕರಿಸಲಾಗಿದೆ. LongCat ಗೆ ಅನ್ವಯಿಸಿದ ಅದೇ ಪ್ರಾಮಾಣಿಕತೆಯ ನಿಯಮ.
>
> **ಜೊತೆಗೆ xKiro (2026-09-03):** ಹೊಸ `xkiro-free` ಪೂಲ್ (ತಿಂಗಳಿಗೆ 150M) 35ನೇ ಪುನರಾವರ್ತಿತ ಪೂಲ್ ಕೀಯನ್ನು ಸೇರಿಸುತ್ತದೆ. ಅದರ GPL-ಮೂಲದ ಉಗಮ/ಪರವಾನಗಿ HOLD ಸ್ಥಿತಿಯಲ್ಲಿರುವವರೆಗೆ Felo Web ಹೊರಗೇ ಉಳಿಯುತ್ತದೆ. ಮೂಲವು ಈಗ **35 ಪುನರಾವರ್ತಿತ ಪೂಲ್ ಕೀಗಳು** ಮತ್ತು **~1.62B ಸ್ಥಿರ ಮೊತ್ತ**ವನ್ನು ವರದಿ ಮಾಡುತ್ತದೆ — ಇದು ಲೈವ್, CI-ಗೇಟೆಡ್ ಸಂಖ್ಯೆ (`computeFreeModelTotals()` ನಿಂದ ಇದು ಭಿನ್ನವಾದರೆ `check:docs-counts` ಬಿಲ್ಡ್ ಅನ್ನು ವಿಫಲಗೊಳಿಸುತ್ತದೆ).

ಅತಿದೊಡ್ಡ **ದಾಖಲಿತ** ಕೊಡುಗೆದಾರರು: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (ಐದು ಪ್ರತಿ-ಮಾದರಿಯ ಮಿತಿಗಳು), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` ಅನ್ನು ಹೊರಗಿಡಲಾಗಿದೆ — ಅದರ 10M LongCat-2.0 ಅನುದಾನವು ಒಂದು-ಬಾರಿಯ, KYC-ಗೇಟೆಡ್ ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ ಆಗಿದೆ, ಪುನರಾವರ್ತಿತ ಮಾಸಿಕ ಬಜೆಟ್ ಅಲ್ಲ.)

> ⚠️ ಸೈದ್ಧಾಂತಿಕ ಗರಿಷ್ಠ ಮಿತಿ (~10B) **ಪ್ರಕಟಿತ ಟೋಕನ್ ಮಿತಿಯಿಲ್ಲದ**, ಕೇವಲ ದರ-ಮಿತಿಯನ್ನು ಹೊಂದಿರುವ ಪೂರೈಕೆದಾರರಿಂದ (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`) ಉತ್ಪ್ರೇಕ್ಷಿತವಾಗಿದೆ; ಅವರ ಅಂಕಿಅಂಶಗಳು `RPM/TPM × 24/7 × 30d` ಆಗಿರುತ್ತವೆ — ಇದು ಯಾವುದೇ ಒಂದು ಖಾತೆಯು ನಿರಂತರವಾಗಿ ಕಾಯ್ದುಕೊಳ್ಳಲಾಗದ ಸೈದ್ಧಾಂತಿಕ ಗರಿಷ್ಠವಾಗಿದೆ. ಸಮರ್ಥಿಸಬಹುದಾದ ಸಂಖ್ಯೆಯಿಂದ ಅವುಗಳನ್ನು **ಹೊರಗಿಡಲಾಗಿದೆ** (ಬದಲಿಗೆ "ಶಾಶ್ವತವಾಗಿ ಉಚಿತ, ಮಿತಿಯಿಲ್ಲ" ಸಾಲಿನಲ್ಲಿ ತೋರಿಸಲಾಗಿದೆ). ಇದೇ ಉತ್ಪ್ರೇಕ್ಷೆಯು ಸ್ಪರ್ಧಿಗಳ ಬಹು-ಬಿಲಿಯನ್ ದಾವೆಗಳನ್ನು ವಿಶ್ವಾಸಾರ್ಹವಲ್ಲದಂತೆ ಮಾಡುತ್ತದೆ.

## 2026-06-17 ನವೀಕರಣ — 2026-06-05 ರಿಂದ ಏನು ಬದಲಾಗಿದೆ

50-ಏಜೆಂಟ್ ವೆಬ್-ಸಂಶೋಧನಾ ಪರಿಶೀಲನೆಯು (ಅಧಿಕೃತ ಡಾಕ್ಯುಮೆಂಟ್ಗಳು + ಕಳೆದ 7 ದಿನಗಳ ಸುದ್ದಿಗಳು, ಪ್ರತಿಕೂಲ ವಿಧಾನದಲ್ಲಿ ಪರಿಶೀಲಿಸಲಾಗಿದೆ) ಸಂಪೂರ್ಣ ಕ್ಯಾಟಲಾಗ್ ಅನ್ನು ನವೀಕರಿಸಿದೆ. ಮುಖ್ಯಾಂಶಗಳು:

- **ಹೊಸದಾಗಿ ಪತ್ತೆಯಾದ ಉಚಿತ ಪೂರೈಕೆದಾರರು:** ⭐ **Kilo Code** (`kilo-gateway` — ಆವರ್ತಕ "Auto Free" ಸಂಗ್ರಹ: NVIDIA Nemotron 3 ಕುಟುಂಬ, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — ಆವರ್ತಕ 6 ಉಚಿತ ಕೋಡಿಂಗ್ ಮಾದರಿಗಳು), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash ಶಾಶ್ವತವಾಗಿ ಉಚಿತ + 20M ಸೈನ್ಅಪ್ ಬೋನಸ್), ಮತ್ತು `arcee-ai` Trinity Large Preview.
- **ಹೊಸ ಪ್ರಾಮಾಣಿಕ ಶ್ರೇಣಿಗಳು** (ವಿಧಾನಶಾಸ್ತ್ರವನ್ನು ನೋಡಿ): _ಶಾಶ್ವತವಾಗಿ-ಉಚಿತ-ಆದರೆ-ಮಿತಿಯಿಲ್ಲದ_ ವರ್ಗ (ನೈಜ ಮರುಕಳಿಸುವ ಪ್ರವೇಶ, ಎಣಿಸಲು ಯಾವುದೇ ಟೋಕನ್ ಮಿತಿ ಇಲ್ಲ) ಮತ್ತು _ಠೇವಣಿ-ಅನ್ಲಾಕ್ ಬೂಸ್ಟ್_ (OpenRouter $10 → +24M/ತಿಂಗಳು), ಇವೆರಡನ್ನೂ **ಪ್ರತ್ಯೇಕವಾಗಿ** ಪ್ರದರ್ಶಿಸಲಾಗಿದೆ, ಆದ್ದರಿಂದ ಅವು ಎಂದಿಗೂ ಮುಖ್ಯ ಸಂಖ್ಯೆಯನ್ನು ಹೆಚ್ಚಿಸುವುದಿಲ್ಲ.

> ಕೆಳಗೆ ಇನ್ನಷ್ಟು ವಿವರವಾಗಿ ನೀಡಿರುವ ಪ್ರತಿ-ಪೂರೈಕೆದಾರರ ಕೋಷ್ಟಕವು **2026-06-05 ಸ್ನ್ಯಾಪ್ಶಾಟ್** ಆಗಿದೆ; ಮೇಲಿನ ಬದಲಾವಣೆಗಳು ಅದನ್ನು ಮೀರಿ ಅನ್ವಯಿಸುತ್ತವೆ. ನೇರ, ಅಧಿಕೃತ ಮೂಲವೆಂದರೆ ಪ್ರತಿ-ಮಾದರಿ ಕ್ಯಾಟಲಾಗ್ `open-sse/config/freeModelCatalog.ts`.

## ವಿಧಾನಶಾಸ್ತ್ರ & ಎಚ್ಚರಿಕೆಗಳು

- ಸಂಖ್ಯೆಗಳು **2026-06-17**ರ ವೇಳೆಗೆ ಪ್ರತಿಯೊಂದು ಪೂರೈಕೆದಾರರು ದಾಖಲಿಸಿರುವ ಉಚಿತ-ಶ್ರೇಣಿಯ ಮಿತಿಗಳಿಂದ ವೆಬ್ ಸಂಶೋಧನೆಯ ಮೂಲಕ ಸಂಗ್ರಹಿಸಲಾದ **ಗರಿಷ್ಠ-ಮಿತಿಯ ಅಂದಾಜುಗಳು**. ಉಚಿತ ಶ್ರೇಣಿಗಳು ನಿರಂತರವಾಗಿ ಬದಲಾಗುತ್ತವೆ — ಯಾವುದೇ ಅಂಕಿಯನ್ನು ಅವಲಂಬಿಸುವ ಮೊದಲು ಮತ್ತೊಮ್ಮೆ ಪರಿಶೀಲಿಸಿ.
- **ಒಂದು ನಮೂದು ವಾಸ್ತವವಾಗಿ ಯಾವುದಕ್ಕೆ ಖಾತರಿ ನೀಡುತ್ತದೆ.** ಯಾವುದೇ ನಮೂದು ಪ್ರತಿ-ಸಾಲಿನ ವಿಶ್ವಾಸಾರ್ಹತಾ ರೇಟಿಂಗ್ ಹೊಂದಿಲ್ಲ ಮತ್ತು API ಕೂಡ ಯಾವುದನ್ನೂ ಒದಗಿಸುವುದಿಲ್ಲ — ಮೇಲಿನ ಪ್ರತಿಯೊಂದು ಅಂಕಿಯನ್ನೂ ಒಂದೇ ರೀತಿಯ, ಸ್ಪಷ್ಟಪಡಿಸದ ಗುಣಮಟ್ಟದ ಅಂದಾಜಾಗಿ ಪರಿಗಣಿಸಿ. ಎರಡು ಸಂಗತಿಗಳು ಮಾತ್ರ ವಿಭಿನ್ನವಾಗಿವೆ, ಏಕೆಂದರೆ ಅವುಗಳನ್ನು ಊಹಿಸುವ ಬದಲು ಕೈಯಾರೆ ಸಂಗ್ರಹಿಸಲಾಗಿದೆ: 44 ನಮೂದುಗಳು ಸ್ವತಂತ್ರವಾಗಿ ದಾಖಲಿಸಲಾದ ಕಟ್ಟುನಿಟ್ಟಿನ ತಡೆ ಮಿತಿಯನ್ನು ಹೊಂದಿವೆ (ಅವುಗಳಲ್ಲಿ 39 xKiro ಸಾಲುಗಳು ಮತ್ತು ಅವೆಲ್ಲವೂ ಒಂದೇ ದೈನಂದಿನ ಭತ್ಯೆಯನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತವೆ), ಹಾಗೂ 13 ನಮೂದುಗಳು ಪ್ರಾಂಪ್ಟ್-ತರಬೇತಿ ಬಹಿರಂಗಪಡಿಸುವಿಕೆಯನ್ನು ಹೊಂದಿವೆ. ಉಚಿತ ಭತ್ಯೆಯನ್ನು ಮೀರಿದಾಗ ನಿಮಗೆ ತಿಳಿಸದೆ ಬಿಲ್ಲಿಂಗ್ ಪ್ರಾರಂಭಿಸುವ ಬದಲು ವಿನಂತಿಯನ್ನು ನಿರಾಕರಿಸಲಾಗುತ್ತದೆ ಎಂದು ಪೂರೈಕೆದಾರರ ಸ್ವಂತ ನಿಯಮಗಳು ಹೇಳಿದಾಗ ಮಾತ್ರ `hardStopGuaranteed` ಅನ್ನು ಹೊಂದಿಸಲಾಗುತ್ತದೆ; ಅದರ ಮೂಲವನ್ನು ನಮೂದಿನ ಪಕ್ಕದ ಕಾಮೆಂಟ್ನಲ್ಲಿ ನೀಡಲಾಗುತ್ತದೆ. ಇದನ್ನು ಎಂದಿಗೂ ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ `true` ಎಂದು ಹೊಂದಿಸಲಾಗುವುದಿಲ್ಲ ಮತ್ತು ಯಾರೂ ಪರಿಶೀಲಿಸದ ನಮೂದು ಹೊಂದಿಸದೆ ಉಳಿಯುತ್ತದೆ. ಆದ್ದರಿಂದ ಕಟ್ಟುನಿಟ್ಟಿನ-ತಡೆ ಫ್ಲ್ಯಾಗ್ ಇಲ್ಲದಿರುವುದರ ಅರ್ಥ "ಸ್ಥಾಪಿತವಾಗಿಲ್ಲ" ಎಂಬುದೇ ಹೊರತು "ನಿಮಗೆ ಬಿಲ್ ಮಾಡುತ್ತದೆಂದು ತಿಳಿದಿದೆ" ಎಂದಲ್ಲ. **STRICT ಮೋಡ್** (ಆಯ್ಕೆಮಾಡಿ ಸಕ್ರಿಯಗೊಳಿಸುವ `freeAccessPolicy=strict` ರೂಟಿಂಗ್ ರಕ್ಷಣೆ) ಫ್ಲ್ಯಾಗ್ ಹೊಂದಿರುವ ನಮೂದುಗಳನ್ನು ಮಾತ್ರ ನಂಬುತ್ತದೆ; ಉಳಿದ ಪ್ರತಿಯೊಂದು ಉಚಿತ ಶ್ರೇಣಿಯನ್ನೂ `no-hard-stop` ಎಂದು ಹೊರಗಿಡಲಾಗುತ್ತದೆ (`open-sse/services/autoCombo/strictZeroCostFilter.ts` ನೋಡಿ).
- `estMonthlyFreeTokens` = ಪುನರಾವರ್ತಿತ ಮಾಸಿಕ ಟೋಕನ್ಗಳು ಮಾತ್ರ. **ಒಮ್ಮೆ ಮಾತ್ರ ದೊರೆಯುವ ನೋಂದಣಿ ಕ್ರೆಡಿಟ್ಗಳು ಪುನರಾವರ್ತಿಸುವುದಿಲ್ಲ** ಮತ್ತು ಅವುಗಳನ್ನು 0 ಎಂದು ಎಣಿಸಲಾಗುತ್ತದೆ. ಸ್ಥಗಿತಗೊಂಡ ಶ್ರೇಣಿಗಳನ್ನೂ 0 ಎಂದು ಪರಿಗಣಿಸಲಾಗುತ್ತದೆ.
- ದೈನಂದಿನ ಟೋಕನ್ ಮಿತಿ → `monthly = daily × 30`. RPD ಮಾತ್ರ ದಾಖಲಿಸಿದ್ದರೆ → `RPD × ~800 ಔಟ್ಪುಟ್ ಟೋಕನ್ಗಳು × 30`. RPM/TPM ಮಾತ್ರ ಇದ್ದರೆ (ದೈನಂದಿನ ಮಿತಿಯಿಲ್ಲದೆ) → **ಮಿತಿರಹಿತ** (ಕೆಳಗೆ ನೋಡಿ).
- **ಶಾಶ್ವತವಾಗಿ ಉಚಿತ, ಆದರೆ ಪ್ರಕಟಿತ ಟೋಕನ್ ಮಿತಿಯಿಲ್ಲ** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): ಇವು ದರ/ಸಮಕಾಲಿಕತೆಯಿಂದ ಮಿತಿಗೊಳಿಸಲಾದ ನೈಜ, ಪುನರಾವರ್ತಿತ ಉಚಿತ ಪ್ರವೇಶಗಳಾಗಿವೆ. ಇವುಗಳನ್ನು ನಾವು `recurring-uncapped` ಎಂದು ವರ್ಗೀಕರಿಸುತ್ತೇವೆ ಮತ್ತು **ಎಂದಿಗೂ ಒಟ್ಟುಗೂಡಿಸುವುದಿಲ್ಲ** — `RPM × 24/7 × 30d` ಎಂದು ಗುಣಿಸುವುದರಿಂದ ಕಾಲ್ಪನಿಕ ಗರಿಷ್ಠ ಮಿತಿ ಉಂಟಾಗುತ್ತದೆ (ನಾವು ತಿರಸ್ಕರಿಸುವ ಉತ್ಪ್ರೇಕ್ಷೆ). ಇವು ಅಸ್ತಿತ್ವದಲ್ಲಿವೆ ಎಂಬುದು ನಿಮಗೆ ತಿಳಿಯಲೆಂದು ಅವುಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡಲಾಗಿದೆ.
- **ಠೇವಣಿ-ಅನ್ಲಾಕ್ ಹೆಚ್ಚಳ:** ಉಚಿತ ಕೋಟಾವನ್ನು ಶಾಶ್ವತವಾಗಿ ಹೆಚ್ಚಿಸುವ, ಒಮ್ಮೆ ಮಾತ್ರ ಮಾಡುವ ಸಣ್ಣ ಟಾಪ್-ಅಪ್ (OpenRouter: $10 → 1000 req/day ≈ +24M/mo). ಇದನ್ನು ಪ್ರತ್ಯೇಕ ಅಂಕಿಯಾಗಿ ವರದಿ ಮಾಡಲಾಗುತ್ತದೆ ಮತ್ತು ಸ್ಥಿರ ಮುಖ್ಯಾಂಶದಿಂದ ಹೊರಗಿಡಲಾಗುತ್ತದೆ.
- **ಅರ್ಹತೆ-ನಿಯಂತ್ರಿತ ಕೋಟಾಗಳು** (`eligibilityGate: "regional-identity"`): ಪ್ರದೇಶಕ್ಕೆ ಬದ್ಧವಾದ ಗುರುತು ಪರಿಶೀಲನೆಯ ನಂತರ ಮಾತ್ರ ತೆರೆಯುವ ನೈಜ ಪುನರಾವರ್ತಿತ ಕೋಟಾ (ಪ್ರಸ್ತುತ ಚೀನಾದ ಮುಖ್ಯಭೂಭಾಗದ ನೈಜ-ಹೆಸರು ಪರಿಶೀಲನೆ). ಅದೇ ಪೂಲ್-ಡೀಡ್ಯೂಪ್ ನಿಯಮದೊಂದಿಗೆ ಇದನ್ನು ಪ್ರತ್ಯೇಕ ಅಂಕಿ (`gatedRecurringTokens`)ಯಲ್ಲಿ ಎಣಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಸ್ಥಿರ ಮುಖ್ಯಾಂಶದಲ್ಲಿ ಎಂದಿಗೂ ಸೇರಿಸಲಾಗುವುದಿಲ್ಲ. ವ್ಯವಸ್ಥೆ (`freeType`) ಬದಲಾಗುವುದಿಲ್ಲ, ಆದ್ದರಿಂದ ರೂಟಿಂಗ್ ಕೂಡ ಬದಲಾಗುವುದಿಲ್ಲ.
- **ಸಾಕ್ಷ್ಯದ ವರ್ಗಗಳು.** ನಿಯಮ: ಕ್ಯಾಟಲಾಗ್ನಲ್ಲಿರುವ ಸಂಖ್ಯೆಯು ನಮೂದಿನ ಪಕ್ಕದ `// evidence:` ಕಾಮೆಂಟ್ನಲ್ಲಿ ತನ್ನ ಮೂಲವನ್ನು ಉಲ್ಲೇಖಿಸುತ್ತದೆ — `public-page` (ಯಾರಾದರೂ ಓದಬಹುದಾದ ಪೂರೈಕೆದಾರರ ಪುಟ), `api-public` (ಪೂರೈಕೆದಾರರ ದೃಢೀಕರಣ ಅಗತ್ಯವಿಲ್ಲದ ಎಂಡ್ಪಾಯಿಂಟ್, ಉದಾ. router.bynara.idನಲ್ಲಿರುವ NaraRouterನ ಸಾರ್ವಜನಿಕ ಯೋಜನೆಗಳ ಎಂಡ್ಪಾಯಿಂಟ್), ಅಥವಾ `console-verified <date> por <who>` (ಅಂಕಿಯು ಖಾತೆಯ ಕನ್ಸೋಲ್ ಒಳಗೆ ಮಾತ್ರ ಗೋಚರಿಸುತ್ತದೆ; ಅದನ್ನು ಯಾರು ಮತ್ತು ಯಾವಾಗ ನೋಡಿದರು ಎಂಬುದನ್ನು ಹಾಗೂ ಮಿತಿ ಅಸ್ತಿತ್ವದಲ್ಲಿದೆ ಎಂದು ಹೇಳುವ ಸಾರ್ವಜನಿಕ ಪುಟವನ್ನು ಕಾಮೆಂಟ್ ದಾಖಲಿಸುತ್ತದೆ). ಪ್ರಸ್ತುತ ಸ್ಥಿತಿ: 2026-09-02ರಂದು ಮರು-ಲೆಕ್ಕಪರಿಶೋಧಿಸಲಾದ ಐದು ಬ್ಲಾಕ್ಗಳು ಇದನ್ನು ಹೊಂದಿವೆ (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); 2026-09-02ರ ಮರು-ಲೆಕ್ಕಪರಿಶೋಧನೆಗಿಂತ ಹಿಂದಿನ ನಮೂದುಗಳು ಪರಿಷ್ಕರಿಸುವವರೆಗೆ ಹಿಂದಿನ ಸಂಶೋಧನೆಯನ್ನು ಆನುವಂಶಿಕವಾಗಿ ಪಡೆಯುತ್ತವೆ; ಸಾಕ್ಷ್ಯದ ಕಾಮೆಂಟ್ ಇಲ್ಲದ ಯಾವುದೇ **ಹೊಸ ಅಥವಾ ಬದಲಾದ** ಸಂಖ್ಯೆಯು ದೋಷವಾಗಿದೆ. ಪ್ರಸ್ತುತ `mistral` ಮಾತ್ರ ಕನ್ಸೋಲ್ನಲ್ಲಿ ಪರಿಶೀಲಿಸಲಾಗಿದೆ.

## ನಮ್ಮ ಸಂಖ್ಯೆ ಇತರ ಅಗ್ರಿಗೇಟರ್ಗಳಿಗಿಂತ ಏಕೆ ಚಿಕ್ಕದಾಗಿದೆ

ಈ ಕ್ಷೇತ್ರದಲ್ಲಿನ ಹೆಚ್ಚಿನ "ತಿಂಗಳಿಗೆ ಉಚಿತ ಟೋಕನ್ಗಳು" ಅಂಕಿಅಂಶಗಳು ಪ್ರತಿ-ಮಾದರಿ ಲೇಬಲ್ಗಳ ಮೊತ್ತವಾಗಿವೆ. ನಮ್ಮದು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿಯೇ ಹಾಗಿಲ್ಲ:

- **ಪ್ರತಿಯೊಂದು ಹಂಚಿಕೆಯ ಪೂಲ್ ಅನ್ನು ಒಮ್ಮೆ ಮಾತ್ರ ಎಣಿಸಲಾಗುತ್ತದೆ.** Mistralನ ಉಚಿತ ಯೋಜನೆಯು ಪ್ರತಿ ಸಂಸ್ಥೆಗೆ ತಿಂಗಳಿಗೆ ಒಂದು 1B ಮಿತಿಯಾಗಿದೆ; ಅದನ್ನು ಐದು ಮಾದರಿಗಳ ಅಡಿಯಲ್ಲಿ ಪಟ್ಟಿ ಮಾಡುವುದರಿಂದ ಅದು 5B ಆಗುವುದಿಲ್ಲ. ಪ್ರತಿ ಮಾದರಿಯಂತೆ ಮೊತ್ತ ಮಾಡಿದರೆ, ನಮ್ಮದೇ ಕ್ಯಾಟಲಾಗ್ **~7.4B** ಎಂದು ತೋರಿಸುತ್ತದೆ (2026-09-03 ರಂದು ಮರುಲೆಕ್ಕ ಹಾಕಲಾಗಿದೆ; ಈ ಅಂಕಿ CI-ನಿಯಂತ್ರಿತವಲ್ಲ — ಕ್ಯಾಟಲಾಗ್ ಬದಲಾದಾಗಲೆಲ್ಲ ಅದನ್ನು ಮರು-ಅಳೆಯಿರಿ) — ಶೀರ್ಷಿಕೆಯು **~1.47B** ಎಂದು ಹೇಳುತ್ತದೆ, ಏಕೆಂದರೆ ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ಒಂದು ಖಾತೆಯು ವಾಸ್ತವವಾಗಿ ಖರ್ಚು ಮಾಡಬಹುದಾದ ಮೊತ್ತ ಅದೇ.
- **ದೈನಂದಿನ ಮಿತಿಗಳನ್ನು ಪರಿವರ್ತಿಸಲಾಗುತ್ತದೆ, ದರಗಳನ್ನು ಅಲ್ಲ.** ದಾಖಲಿತ tokens/day ಮಿತಿಯು `× 30` ಆಗುತ್ತದೆ; ದಾಖಲಿತ requests/day ಮಿತಿಯು `RPD × ~800 tokens × 30` ಆಗುತ್ತದೆ; ಕೇವಲ requests-per-minute ಅನ್ನು ಪ್ರಕಟಿಸುವ ಪೂರೈಕೆದಾರರಿಗೆ ಮಾಸಿಕ ಅಂಕಿ **ಇರುವುದಿಲ್ಲ** ಮತ್ತು ಅವರನ್ನು _ಮಿತಿಯಿಲ್ಲದ_ ಎಂದು ಪಟ್ಟಿ ಮಾಡಲಾಗುತ್ತದೆ, ಮೊತ್ತಕ್ಕೆ ಎಂದಿಗೂ ಸೇರಿಸಲಾಗುವುದಿಲ್ಲ. ದರ ಮಿತಿಯನ್ನು 24/7 ರಿಂದ ಗುಣಿಸುವುದು ನಾವು ನಿರಾಕರಿಸುವ ಅಂಕಿ ಉಬ್ಬಿಸುವಿಕೆಯಾಗಿದೆ.
- **ಪ್ರಾದೇಶಿಕ ಗುರುತು ಪರಿಶೀಲನೆಯ ಹಿಂದಿರುವ ಕೋಟಾಗಳನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ತೋರಿಸಲಾಗುತ್ತದೆ** (`+~6M ಪ್ರಾದೇಶಿಕ ಗುರುತು ಪರಿಶೀಲನೆಯ ಹಿಂದೆ`), ಏಕೆಂದರೆ ಹೆಚ್ಚಿನ ಓದುಗರು ಅವುಗಳನ್ನು ಬಳಸಲು ಸಾಧ್ಯವಿಲ್ಲ.
- **ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗಳು ಮೊದಲ ತಿಂಗಳಿಗೆ ಮಾತ್ರ** ಮತ್ತು ಅವುಗಳನ್ನು ಎರಡನೇ ಅಂಕಿಯಾಗಿ ವರದಿ ಮಾಡಲಾಗುತ್ತದೆ; ಸ್ಥಿರ ಅಂಕಿಯೊಂದಿಗೆ ಎಂದಿಗೂ ಬೆರೆಸಲಾಗುವುದಿಲ್ಲ.
- **ಈ ಅಂಕಿಯನ್ನು CI ಜಾರಿಗೊಳಿಸುತ್ತದೆ.** `npm run check:docs-counts` ಕ್ಯಾಟಲಾಗ್ನಿಂದ ಒಟ್ಟುಗಳನ್ನು ಮರುಲೆಕ್ಕ ಹಾಕುತ್ತದೆ ಮತ್ತು ಈ ಫೈಲ್, README ಅಥವಾ ಬಜೆಟ್ ಕಾರ್ಡ್ ಅವುಗಳಿಂದ ವ್ಯತ್ಯಾಸಗೊಂಡಾಗ ಬಿಲ್ಡ್ ಅನ್ನು ವಿಫಲಗೊಳಿಸುತ್ತದೆ.

## ToS ಗಮನಾರ್ಹ ಅಂಶಗಳ ಕೋಷ್ಟಕ

> **ToS ಗುರುತು ಸಲಹಾತ್ಮಕವಾಗಿದೆ, ರೂಟಿಂಗ್ ತಡೆಯಲ್ಲ.** `tos` ಎಂದು ಗುರುತಿಸಲಾದ ಪೂರೈಕೆದಾರರನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ರೂಟಿಂಗ್ ಮತ್ತು ಕಾಂಬೊ/ಫಾಲ್ಬ್ಯಾಕ್ನಲ್ಲಿ ಸೇರಿಸಲಾಗುತ್ತದೆ; ಗುರುತು `/dashboard/free-tiers` ಮತ್ತು `/api/free-tier/summary` ನಲ್ಲಿ ಮಾತ್ರ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ. `excludeTosAvoid` ಕ್ವೆರಿ ಪ್ಯಾರಾಮೀಟರ್ ಸಾರಾಂಶ ವೀಕ್ಷಣೆಯ ಮೇಲೆ ಮಾತ್ರ ಪರಿಣಾಮ ಬೀರುತ್ತದೆ, ಜಾಗತಿಕ ರೂಟಿಂಗ್ ಮೇಲಲ್ಲ. ತೀರ್ಪು `open-sse/config/freeTierCatalog.ts` ನಲ್ಲಿದೆ (ಮಾಹಿತಿಗಾಗಿ ಮಾತ್ರ, ರೂಟಿಂಗ್ ಎಂಜಿನ್ಗಳು ಇದನ್ನು ಓದುವುದಿಲ್ಲ).

> ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಮಾಡಿದ, ಏಕ-ಬಳಕೆದಾರರ ವೈಯಕ್ತಿಕ ಪ್ರಾಕ್ಸಿಗೆ ಸಂಬಂಧಿಸಿದಂತೆ ಪ್ರತಿಯೊಂದು ಪೂರೈಕೆದಾರರ ನಿಯಮಗಳ ತ್ವರಿತ ಅವಲೋಕನ. `caution` = ಪರಿಶೀಲಿಸಬೇಕಾದ ವೈಯಕ್ತಿಕ-ಬಳಕೆ ಅಥವಾ ಪ್ರಾಕ್ಸಿ ಷರತ್ತು; `ambiguous` = ಅಸ್ಪಷ್ಟ; `ok` = ಸ್ಪಷ್ಟವಾಗಿ ಅನುಮತಿಸಲಾಗಿದೆ. ಇದು ಮಾಹಿತಿಗಾಗಿ ಮಾತ್ರ, ಕಾನೂನು ಸಲಹೆಯಲ್ಲ — ನಿರ್ಧಾರ ನಿಮ್ಮದು.

> ಅವರ ಉಚಿತ ಪ್ರವೇಶ ನೈಜವಾಗಿದೆ ಮತ್ತು OmniRoute ಅವರಿಗೆ ರೂಟ್ ಮಾಡಬಹುದು; ಕೆಳಗಿನ ಷರತ್ತುಗಳನ್ನು ತಿಳಿದಿರುವುದು ಮಾತ್ರ ಸೂಕ್ತ. OAuth/ಕೀಲಿರಹಿತ ಆಯ್ಕೆಗಳನ್ನು ಟೋಕನ್ಗಳ ಆಧಾರದಲ್ಲಿ ಪ್ರಮಾಣೀಕರಿಸಲಾಗುವುದಿಲ್ಲ, ಆದ್ದರಿಂದ ಅವು ಮುಖ್ಯ ಸಂಖ್ಯೆಯಲ್ಲಿ ಸೇರಿಲ್ಲ (ಅವುಗಳನ್ನು ಬಳಸಲಾಗುವುದಿಲ್ಲ ಎಂಬ ಕಾರಣಕ್ಕಾಗಿ ಅಲ್ಲ).

- **`uncloseai`** — ಬಹುಮಟ್ಟಿಗೆ ಹೊಂದಿಕೆಯಾಗುತ್ತದೆ — ಸೈನ್ಅಪ್ ಇಲ್ಲದೆ ಇನ್ನೂ ಸದಾಕಾಲ ಉಚಿತವಾಗಿದೆ. ಆದರೆ, ToS (terms-of-use.html) ಅತಿಯಾದ ಬಳಕೆಗೆ IP-ಆಧಾರಿತ ಥ್ರಾಟ್ಲಿಂಗ್ ಅಸ್ತಿತ್ವದಲ್ಲಿದೆ ಎಂಬುದನ್ನು ಸ್ಪಷ್ಟಪಡಿಸುತ್ತದೆ ಮತ್ತು ಪ್ರತಿಸ್ಪರ್ಧಿ ML ಸೇವೆಗಳನ್ನು ನಿರ್ಮಿಸುವುದನ್ನು ನಿಷೇಧಿಸುತ್ತದೆ…
