> **ಬಳಕೆದಾರರಿಗಾಗಿ**: ಸರಳ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ಹುಡುಕುತ್ತಿದ್ದೀರಾ? ಉಚಿತ AI ಪಡೆಯಲು ಹಂತ-ಹಂತದ ಸೂಚನೆಗಳಿಗಾಗಿ [ಉಚಿತ ಹಂತಗಳ ಮಾರ್ಗದರ್ಶಿ](../getting-started/FREE-TIERS-GUIDE.md) ನೋಡಿ.

> **ಕೊನೆಯ ಸಂಶೋಧನೆ:** 2026-06-17 — ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ವೆಬ್ ಸಂಶೋಧನೆಯ ಮೂಲಕ (ಅಧಿಕೃತ ದಾಖಲೆಗಳು + ಕಳೆದ 7 ದಿನಗಳ ಸುದ್ದಿಗಳು, ಪ್ರತಿಕೂಲ ಪರಿಶೀಲನೆಯೊಂದಿಗೆ 50-ಏಜೆಂಟ್ ಪರಿಶೀಲನೆ) ಪ್ರತಿಯೊಂದು ಉಚಿತ-ಹಂತದ ಕೋಟಾ + ಸೇವಾ ನಿಯಮಗಳನ್ನು ನವೀಕರಿಸಲಾಗಿದೆ. **ಭಾಗಶಃ ಮರು-ಲೆಕ್ಕಪರಿಶೋಧನೆ 2026-09-02** (`gemini`, `ollama-cloud`, `groq`, `nara`, `mistral` — ಕೆಳಗಿನ ದಿನಾಂಕಿತ ಟಿಪ್ಪಣಿಯನ್ನು ನೋಡಿ).
> **ಅಧಿಕೃತ ಮೂಲ (ಕ್ಯಾಟಲಾಗ್):** `open-sse/config/freeModelCatalog.ts` (ಪ್ರತಿ-MODEL ಬಜೆಟ್ಗಳು, ಪೂಲ್ ಮಟ್ಟದಲ್ಲಿ ನಕಲುಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ). ಕೆಳಗಿನ ಟೋಕನ್-ಬಜೆಟ್ ಸಂಖ್ಯೆಗಳು ನೇರ ವೆಬ್ ಸಂಶೋಧನೆಯಿಂದ ಬಂದಿದ್ದು, ಅವು ಒಂದು **ಅಂದಾಜು** — [ವಿಧಾನ ಮತ್ತು ಎಚ್ಚರಿಕೆಗಳು](#methodology--caveats) ನೋಡಿ.

## ಸಂಕ್ಷಿಪ್ತವಾಗಿ — OmniRoute ವಾಸ್ತವವಾಗಿ ಎಷ್ಟು ಉಚಿತ ಇನ್ಫರೆನ್ಸ್ ಅನ್ನು ಒಟ್ಟುಗೂಡಿಸುತ್ತದೆ?

| ಮೆಟ್ರಿಕ್                                       | ಟೋಕನ್ಗಳು / ತಿಂಗಳು  | ಅರ್ಥ                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ದಾಖಲೀಕರಿಸಿದ ಪುನರಾವರ್ತಿತ ಅನುದಾನ (ಸ್ಥಿರ)**     | **~1.62B**         | ಉಚಿತ-ಹಂತದ **ಪೂಲ್ಗಳು** (ಪ್ರತಿ-ಮಾದರಿ ಕ್ಯಾಟಲಾಗ್), ಹಂಚಿಕೊಂಡಿರುವ ಪ್ರತಿಯೊಂದು ಪೂಲ್ ಅನ್ನು **ಒಮ್ಮೆ ಮಾತ್ರ** ಎಣಿಸಲಾಗಿದೆ. `/api/free-tier/summary` ಮತ್ತು ಡ್ಯಾಶ್ಬೋರ್ಡ್ನ ಉಚಿತ-ಹಂತದ ಬಜೆಟ್ ಪುಟದ ಹಿಂದಿರುವ ನೇರ ಮೂಲ. **ಈ ಸಂಖ್ಯೆಯನ್ನು ಬಳಸಿ.**                                                                                                                             |
| **+ ನೋಂದಣಿ ಕ್ರೆಡಿಟ್ಗಳಿರುವ ಮೊದಲ ತಿಂಗಳು**        | **~2.22B**         | ಸ್ಥಿರ ಪ್ರಮಾಣ + ಒಂದು-ಬಾರಿಯ ನೋಂದಣಿ ಕ್ರೆಡಿಟ್ಗಳು (Z.AI 20M, DeepSeek 5M, …), ಪ್ರತಿ ಖಾತೆಗೆ ನಕಲುಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ. **ಮೊದಲ ತಿಂಗಳಿಗೆ ಮಾತ್ರ** — ಇದು ಮರುಕಳಿಸುವುದಿಲ್ಲ.                                                                                                                                                                                      |
| **+ ಶಾಶ್ವತವಾಗಿ ಉಚಿತ, ಪ್ರಕಟಿತ ಮಿತಿ ಇಲ್ಲ**       | _ಪ್ರಮಾಣೀಕರಿಸಲಾಗದು_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — ನೈಜ ಪುನರಾವರ್ತಿತ ಪ್ರವೇಶ, ದರ/ಏಕಕಾಲೀನತೆ ಮಿತಿಗೆ ಒಳಪಟ್ಟಿದೆ, **ಎಣಿಸಲು ಯಾವುದೇ ಟೋಕನ್ ಮಿತಿ ಇಲ್ಲ**. ಪಟ್ಟಿಮಾಡಲಾಗಿದೆ, ಆದರೆ ಮೊತ್ತಕ್ಕೆ ಎಂದಿಗೂ ಸೇರಿಸಲಾಗುವುದಿಲ್ಲ (`RPM×24/7` ಆಧಾರದಲ್ಲಿ ಅವುಗಳನ್ನು ಎಣಿಸುವುದು ನಾವು ತಿರಸ್ಕರಿಸುವ ಉತ್ಪ್ರೇಕ್ಷೆಯಾಗಿದೆ). |
| **+ ಠೇವಣಿ-ಅನ್ಲಾಕ್ ಹೆಚ್ಚಳ**                     | **+~24M**          | ಒಂದು-ಬಾರಿಯ **$10** OpenRouter ಟಾಪ್-ಅಪ್ ಅದರ ಉಚಿತ ಪೂಲ್ ಅನ್ನು ದಿನಕ್ಕೆ 50 → 1000 ವಿನಂತಿಗಳಿಗೆ ಹೆಚ್ಚಿಸುತ್ತದೆ. ಇದು ಸ್ಥಿರ ಸಂಖ್ಯೆಯನ್ನು ಎಂದಿಗೂ ಉತ್ಪ್ರೇಕ್ಷಿಸದಂತೆ ಪ್ರತ್ಯೇಕವಾಗಿ ವರದಿ ಮಾಡಲಾಗಿದೆ.                                                                                                                                                                    |
| **+ ಪ್ರಾದೇಶಿಕ ಗುರುತು ಪರಿಶೀಲನೆಯ ಹಿಂದೆ**         | **+~6M**           | `modelscope` (Alibaba Cloud ಜೋಡಣೆ + ಚೀನಾದ ಮುಖ್ಯಭೂಭಾಗದ ನೈಜ-ಹೆಸರು ಪರಿಶೀಲನೆ). ನೈಜ ಪುನರಾವರ್ತಿತ ಕೋಟಾ, `gatedRecurringTokens` / `gatedProviders` ರೂಪದಲ್ಲಿ ಮತ್ತು ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ಪ್ರದರ್ಶಿಸಲಾಗಿದೆ. ಮುಖ್ಯ ಸಂಖ್ಯೆಗೆ ಎಂದಿಗೂ ಸೇರಿಸಲಾಗುವುದಿಲ್ಲ: ಪ್ರಾದೇಶಿಕ ಗುರುತು ಪರಿಶೀಲನೆಯ ಹಿಂದೆ +~6M.                                                                           |
| ಸೈದ್ಧಾಂತಿಕ ಗರಿಷ್ಠ ಮಿತಿ (ಎಲ್ಲ ದರ ಮಿತಿಗಳು, 24/7) | ~10B               | ನಿರಂತರ ಬಳಕೆಗೆ ವಿಸ್ತರಿಸಿ ಲೆಕ್ಕಹಾಕಿದ ಪ್ರತಿಯೊಂದು ಪೂರೈಕೆದಾರರ ದರ ಮಿತಿಯ ಮೊತ್ತ. **ಖಾತರಿಯಲ್ಲ** — ಇದನ್ನು ಶೀರ್ಷಿಕೆಯಾಗಿ ಬಳಸಬೇಡಿ.                                                                                                                                                                                                                                 |

**ಪ್ರಾಮಾಣಿಕ ಮುಖ್ಯಾಂಶ:** _OmniRoute 35 ಉಚಿತ-ಹಂತದ ಪೂಲ್ಗಳಾದ್ಯಂತ **ತಿಂಗಳಿಗೆ ~1.62B ದಾಖಲೀಕರಿಸಿದ ಉಚಿತ ಟೋಕನ್ಗಳನ್ನು** ಒಟ್ಟುಗೂಡಿಸುತ್ತದೆ (ನೋಂದಣಿ ಕ್ರೆಡಿಟ್ಗಳೊಂದಿಗೆ ನಿಮ್ಮ ಮೊದಲ ತಿಂಗಳಲ್ಲಿ ~2.22B ವರೆಗೆ) — ಜೊತೆಗೆ ಶಾಶ್ವತವಾಗಿ ಉಚಿತವಾಗಿರುವ, ಮಿತಿಯಿಲ್ಲದ ಪೂರೈಕೆದಾರರ ದೀರ್ಘ ಪಟ್ಟಿ ಇದೆ — ಮತ್ತು RTK + Caveman ಕಂಪ್ರೆಷನ್ (15–95% ಟೋಕನ್ ಉಳಿತಾಯ) ಅದನ್ನು ಇನ್ನಷ್ಟು ವಿಸ್ತರಿಸುತ್ತದೆ._

> **ಇದು ಹಿಂದಿನ ~1.94B ಇಂದ ಏಕೆ ಇಳಿದಿದೆ.** 2026-06-17 ರ ನವೀಕರಣವು ಪ್ರಾಮಾಣಿಕತೆಯ ತಿದ್ದುಪಡಿಯೇ ಹೊರತು ನಷ್ಟವಲ್ಲ: `gemini` ಅನ್ನು ಈಗ ಪೂಲ್ ಮಟ್ಟದಲ್ಲಿ ನಕಲು-ಮುಕ್ತಗೊಳಿಸಲಾಗಿದೆ (ಹಿಂದೆ ಪ್ರತಿಯೊಂದು Flash ರೂಪಾಂತರವನ್ನೂ ಪ್ರತ್ಯೇಕವಾಗಿ ಎಣಿಸಿದ್ದರಿಂದ ಹೆಚ್ಚಾಗಿ ತೋರಿಸಲಾಗಿತ್ತು, 462M → 60M), `cloudflare-ai` ಅನ್ನು ಅದರ ನಿಜವಾದ ದಿನಕ್ಕೆ 10k-Neurons ಗೆ ತಿದ್ದಲಾಗಿದೆ (122M → 30M), `doubao` ಅನ್ನು ಮರುಕಳಿಸುವ ಕ್ರೆಡಿಟ್ ಬದಲಿಗೆ ಒಂದು-ಬಾರಿಯ ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ ಎಂದು ಮರುವರ್ಗೀಕರಿಸಲಾಗಿದೆ ಮತ್ತು ಸ್ಥಗಿತಗೊಂಡ ಶ್ರೇಣಿಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ (`chutes`/`phind`/`kluster` ಸ್ಥಗಿತಗೊಂಡಿವೆ). ಇದನ್ನು `llm7` (ಸರಿಯಾದ ದಿನಕ್ಕೆ 5M → 150M) ಮತ್ತು ಹೊಸ ಉಚಿತ ಪೂರೈಕೆದಾರರು (Kilo, OpenCode Zen, Z.AI GLM-Flash) ಭಾಗಶಃ ಸರಿದೂಗಿಸುತ್ತಾರೆ.
>
> **v3.8.42 ನಲ್ಲಿ ಮತ್ತಷ್ಟು ತಿದ್ದುಪಡಿ ಮಾಡಿ ~1.37B ಗೆ ತರಲಾಗಿದೆ:** ಉಚಿತ ಪೂರ್ವವೀಕ್ಷಣೆ ಅಂತ್ಯಗೊಂಡ ನಂತರ `longcat` ಅನ್ನು ತಿಂಗಳಿಗೆ ಮರುಕಳಿಸುವ 150M ಅನುದಾನದಿಂದ ಒಂದು-ಬಾರಿಯ 10M ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗೆ ಮರುವರ್ಗೀಕರಿಸಲಾಗಿದೆ. ಅದೇ ಪ್ರಾಮಾಣಿಕತೆಯ ನಿಯಮ — ಯಾವುದೇ ಪೂರೈಕೆದಾರರನ್ನು ತಪ್ಪಾಗಿ ತೆಗೆದುಹಾಕಿಲ್ಲ.

> **Felo Web ಅನ್ನು ನಿವೃತ್ತಿಗೊಳಿಸಿದ ನಂತರ 2026-08-26 ರಂದು ನವೀಕರಿಸಲಾಗಿದೆ:** ಅದರ GPL-ಮೂಲದ ಉಗಮ/ಪರವಾನಗಿಯು HOLD ಸ್ಥಿತಿಯಲ್ಲಿರುವವರೆಗೆ Felo Web ಅನ್ನು ಹೊರಗಿಡಲಾಗಿದೆ; ಆ ಸಮಯದಲ್ಲಿ ಮೂಲವು 38 ಪೂಲ್ ಕೀಲಿಗಳನ್ನು ವರದಿ ಮಾಡಿತ್ತು. ಪೂಲ್ ಎಣಿಕೆಯು ಲೈವ್ ಆಗಿದ್ದು CI-ಗೇಟೆಡ್ ಆಗಿದೆ (`computeFreeModelTotals()` ನಿಂದ ಮೇಲಿನ ಸಂಖ್ಯೆಗಳು ವ್ಯತ್ಯಾಸಗೊಂಡರೆ `check:docs-counts` ಬಿಲ್ಡ್ ಅನ್ನು ವಿಫಲಗೊಳಿಸುತ್ತದೆ).

> **2026-09-02 ರಂದು ಪೂರೈಕೆದಾರರ ಸ್ವಂತ ಪುಟಗಳ ಆಧಾರದ ಮೇಲೆ ಮರು-ಲೆಕ್ಕಪರಿಶೋಧಿಸಲಾಗಿದೆ** (ಮೂಲಗಳು: `open-sse/config/freeModelCatalog.data.ts` ನಲ್ಲಿ ಮರು-ಲೆಕ್ಕಪರಿಶೋಧಿಸಲಾದ ಪ್ರತಿಯೊಂದು ನಮೂದಿನ ಪಕ್ಕದಲ್ಲಿರುವ `// evidence:` ಕಾಮೆಂಟ್ಗಳು): `gemini` ಮತ್ತು `ollama-cloud` ಇನ್ನು ಮುಂದೆ ಟೋಕನ್ ಸಂಖ್ಯೆಯನ್ನು ಪ್ರಕಟಿಸುವುದಿಲ್ಲ (Google 2025-12-23 ರಂದು ಪ್ರತಿ-ಮಾದರಿಯ ಉಚಿತ ಕೋಷ್ಟಕವನ್ನು ತೆಗೆದುಹಾಕಿತು; Ollama ದ Free ಯೋಜನೆಯು "starter usage credits" ಆಗಿದೆ) ಮತ್ತು ಈಗ ಅವುಗಳನ್ನು **ಮಿತಿರಹಿತ** ಎಂದು ಪಟ್ಟಿ ಮಾಡಲಾಗಿದೆ, ಅವುಗಳನ್ನು ಎಂದಿಗೂ ಮೊತ್ತಕ್ಕೆ ಸೇರಿಸಲಾಗುವುದಿಲ್ಲ (−80M); `groq` ಐದು **ಪ್ರತಿ-ಮಾದರಿಯ** 200K-TPD ಮಿತಿಗಳನ್ನು ಹೊಂದಿದೆ (ಪ್ರತಿಯೊಂದಕ್ಕೆ 6M, +15M), ಜೊತೆಗೆ ನಿವೃತ್ತಿಗೊಳಿಸಲಾದ ಮೂರು ID ಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ; `nara` ಒಂದೇ ದಿನಕ್ಕೆ 7M ಬಕೆಟ್ ಆಗಿದೆ (+60M, 210M). `mistral` ನ 1B ಖಾತೆಯ ಕನ್ಸೋಲ್ನಲ್ಲಿ ಮಾತ್ರ ಗೋಚರಿಸುತ್ತದೆ — ವಿಧಾನಶಾಸ್ತ್ರದ ಅಡಿಯಲ್ಲಿ ಇರುವ _ಸಾಕ್ಷ್ಯದ ವರ್ಗಗಳು_ ನೋಡಿ.
>
> **2026-09-03 ರಂದು ತಿದ್ದುಪಡಿ ಮಾಡಲಾಗಿದೆ (#11773):** `cerebras` ಅನ್ನು ತಿಂಗಳಿಗೆ ಮರುಕಳಿಸುವ 30M ಅನುದಾನದಿಂದ (ಕಾರ್ಡ್ ಅಗತ್ಯವಿಲ್ಲದ ಹಳೆಯ ದಿನಕ್ಕೆ 1M ಟೋಕನ್ಗಳ ಪ್ರಯೋಗಾವಧಿ) ಪಾವತಿ ವಿಧಾನ ಅಗತ್ಯವಿರುವ ಒಂದು-ಬಾರಿಯ $5 ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗೆ ಮರುವರ್ಗೀಕರಿಸಲಾಗಿದೆ. LongCat ಗೆ ಅನ್ವಯಿಸಿದ ಅದೇ ಪ್ರಾಮಾಣಿಕತೆಯ ನಿಯಮ.
>
> **ಜೊತೆಗೆ xKiro (2026-09-03):** ಹೊಸ `xkiro-free` ಪೂಲ್ (150M/mo) ಮರುಕಳಿಸುವ 35ನೇ ಪೂಲ್ ಕೀಲಿಯನ್ನು ಸೇರಿಸುತ್ತದೆ. ಅದರ GPL-ಮೂಲದ ಉಗಮ/ಪರವಾನಗಿಯು HOLD ಸ್ಥಿತಿಯಲ್ಲಿರುವವರೆಗೆ Felo Web ಅನ್ನು ಹೊರಗಿಡಲಾಗಿದೆ. ಮೂಲವು ಈಗ **ಮರುಕಳಿಸುವ 35 ಪೂಲ್ ಕೀಲಿಗಳು** ಮತ್ತು **ಸ್ಥಿರವಾಗಿ ~1.62B** ಎಂದು ವರದಿ ಮಾಡುತ್ತದೆ — ಇದು ಲೈವ್, CI-ಗೇಟೆಡ್ ಸಂಖ್ಯೆ (`computeFreeModelTotals()` ನಿಂದ ಇದು ವ್ಯತ್ಯಾಸಗೊಂಡರೆ `check:docs-counts` ಬಿಲ್ಡ್ ಅನ್ನು ವಿಫಲಗೊಳಿಸುತ್ತದೆ).

ಅತಿದೊಡ್ಡ **ದಾಖಲಿತ** ಕೊಡುಗೆದಾರರು: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (ಐದು ಪ್ರತಿ-ಮಾದರಿಯ ಮಿತಿಗಳು), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` ಅನ್ನು ಹೊರಗಿಡಲಾಗಿದೆ — ಅದರ 10M LongCat-2.0 ಅನುದಾನವು ಒಂದು-ಬಾರಿಯ, KYC-ಗೇಟೆಡ್ ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ ಆಗಿದ್ದು, ಮರುಕಳಿಸುವ ಮಾಸಿಕ ಬಜೆಟ್ ಅಲ್ಲ.)

> ⚠️ ಸೈದ್ಧಾಂತಿಕ ಗರಿಷ್ಠ ಮಿತಿ (~10B), **ಯಾವುದೇ ಪ್ರಕಟಿತ ಟೋಕನ್ ಮಿತಿಯಿಲ್ಲದ** ದರ-ಮಿತಿ-ಮಾತ್ರದ ಪೂರೈಕೆದಾರರಿಂದ (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`) ಅತಿಯಾಗಿ ಹೆಚ್ಚಾಗುತ್ತದೆ; ಅವರ ಅಂಕಿಅಂಶಗಳು `RPM/TPM × 24/7 × 30d` ಆಗಿರುತ್ತವೆ — ಇದು ಯಾವುದೇ ಒಂದು ಖಾತೆಯು ನಿರಂತರವಾಗಿ ಕಾಯ್ದುಕೊಳ್ಳಲಾಗದ ಸೈದ್ಧಾಂತಿಕ ಗರಿಷ್ಠ. ಸಮರ್ಥಿಸಬಹುದಾದ ಸಂಖ್ಯೆಯಿಂದ ಅವುಗಳನ್ನು **ಹೊರಗಿಡಲಾಗಿದೆ** (ಬದಲಿಗೆ "ಶಾಶ್ವತವಾಗಿ ಉಚಿತ, ಮಿತಿಯಿಲ್ಲ" ಸಾಲಿನಲ್ಲಿ ತೋರಿಸಲಾಗಿದೆ). ಇದೇ ಅತಿರೇಕವು ಸ್ಪರ್ಧಿಗಳ ಬಹು-ಬಿಲಿಯನ್ ದಾವೆಗಳನ್ನು ವಿಶ್ವಾಸಾರ್ಹವಲ್ಲದಂತೆ ಮಾಡುತ್ತದೆ.

## 2026-06-17 ನವೀಕರಣ — 2026-06-05 ರಿಂದ ಏನು ಬದಲಾಗಿದೆ

50-ಏಜೆಂಟ್ ವೆಬ್-ಸಂಶೋಧನಾ ಪರಿಶೀಲನೆಯು (ಅಧಿಕೃತ ದಸ್ತಾವೇಜುಗಳು + ಕಳೆದ-7-ದಿನಗಳ ಸುದ್ದಿಗಳು, ಪ್ರತಿಕೂಲವಾಗಿ ಪರಿಶೀಲಿಸಲಾಗಿದೆ) ಸಂಪೂರ್ಣ ಕ್ಯಾಟಲಾಗ್ ಅನ್ನು ನವೀಕರಿಸಿದೆ. ಮುಖ್ಯಾಂಶಗಳು:

> ಕೆಳಗಿರುವ ಪ್ರತಿ-ಪೂರೈಕೆದಾರರ ವಿವರವಾದ ಕೋಷ್ಟಕವು **2026-06-05 ಸ್ನ್ಯಾಪ್ಶಾಟ್** ಆಗಿದೆ; ಮೇಲಿನ ಬದಲಾವಣೆಗಳು ಅದನ್ನು ಅತಿಕ್ರಮಿಸುತ್ತವೆ. ಲೈವ್, ಅಧಿಕೃತ ಮೂಲವು ಪ್ರತಿ-ಮಾದರಿಯ ಕ್ಯಾಟಲಾಗ್ `open-sse/config/freeModelCatalog.ts` ಆಗಿದೆ.

ಆಫ್ಲೈನ್ನಲ್ಲಿಯೂ ಮರುಉತ್ಪಾದಿಸಬಹುದಾಗಿದೆ ಮತ್ತು ಡೇಟಾಬೇಸ್ ಇಲ್ಲದೆಯೇ ಪರೀಕ್ಷಿಸಬಹುದಾಗಿದೆ. ಸರ್ವರ್
ಆಮದು ಮತ್ತೊಂದು ಮೂಲವನ್ನು ಓದುತ್ತಿರುವಾಗ ಬ್ರೌಸರ್ ಪೂರ್ವವೀಕ್ಷಣೆಗೆ ಒಂದು ಮೂಲವನ್ನು ಓದಲು ಅವಕಾಶ ನೀಡಿದರೆ,
ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ನಿಜವಾಗಿ ಏನಾಗುತ್ತದೆ ಎಂಬುದಕ್ಕೆ ಹೊಂದಿಕೆಯಾಗದ ಪೂರ್ವವೀಕ್ಷಣೆ ಉಂಟಾಗುತ್ತದೆ — ಈ ವಿಭಜನೆಯನ್ನು
ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಉಳಿಸಲಾಗಿದೆ.

## ವಿಧಾನಶಾಸ್ತ್ರ ಮತ್ತು ಎಚ್ಚರಿಕೆಗಳು

- ಸಂಖ್ಯೆಗಳು **2026-06-17**ರ ವೇಳೆಗೆ ಪ್ರತಿಯೊಬ್ಬ ಪೂರೈಕೆದಾರರು ದಾಖಲಿಸಿರುವ ಉಚಿತ-ಹಂತದ ಮಿತಿಗಳಿಂದ ಪಡೆದ **ಗರಿಷ್ಠ-ಮಿತಿಯ ಅಂದಾಜುಗಳು**; ಇವುಗಳನ್ನು ವೆಬ್ ಸಂಶೋಧನೆಯ ಮೂಲಕ ಸಂಗ್ರಹಿಸಲಾಗಿದೆ. ಉಚಿತ ಹಂತಗಳು ನಿರಂತರವಾಗಿ ಬದಲಾಗುತ್ತವೆ — ಯಾವುದೇ ಸಂಖ್ಯೆಯನ್ನು ಅವಲಂಬಿಸುವ ಮೊದಲು ಅದನ್ನು ಮರುಪರಿಶೀಲಿಸಿ.
- **ಒಂದು ನಮೂದು ನಿಜವಾಗಿ ಯಾವುದನ್ನು ದೃಢೀಕರಿಸುತ್ತದೆ.** ಯಾವುದೇ ನಮೂದಿಗೂ ಪ್ರತಿ-ಸಾಲಿನ ವಿಶ್ವಾಸಾರ್ಹತಾ ರೇಟಿಂಗ್ ಇಲ್ಲ, ಮತ್ತು API ಕೂಡ ಅದನ್ನು ಒದಗಿಸುವುದಿಲ್ಲ — ಮೇಲಿನ ಪ್ರತಿಯೊಂದು ಸಂಖ್ಯೆಯನ್ನೂ ಒಂದೇ ರೀತಿಯ, ಸ್ಪಷ್ಟವಾಗಿ ಹೇಳದ ಗುಣಮಟ್ಟದ ಅಂದಾಜೆಂದು ಪರಿಗಣಿಸಿ. ಎರಡು ಸಂಗತಿಗಳು ವಿಭಿನ್ನವಾಗಿವೆ, ಏಕೆಂದರೆ ಅವುಗಳನ್ನು ಊಹಿಸುವ ಬದಲು ಕೈಯಾರೆ ಸಂಗ್ರಹಿಸಲಾಗಿದೆ: 44 ನಮೂದುಗಳಿಗೆ ಸ್ವತಂತ್ರವಾಗಿ ದಾಖಲಿಸಲಾದ ಕಠಿಣ ನಿಲುಗಡೆ ಇದೆ (ಅವುಗಳಲ್ಲಿ 39 xKiro ಸಾಲುಗಳು; ಅವೆಲ್ಲವೂ ಒಂದೇ ದೈನಂದಿನ ಭತ್ಯೆಯನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತವೆ), ಮತ್ತು 13 ನಮೂದುಗಳಿಗೆ ಪ್ರಾಂಪ್ಟ್-ತರಬೇತಿ ಬಹಿರಂಗಪಡಿಸುವಿಕೆ ಇದೆ. ಉಚಿತ ಭತ್ಯೆಯನ್ನು ಮೀರಿದಾಗ ಮೌನವಾಗಿ ಬಿಲ್ಲಿಂಗ್ ಪ್ರಾರಂಭಿಸುವ ಬದಲು ವಿನಂತಿಯನ್ನು ನಿರಾಕರಿಸಲಾಗುತ್ತದೆ ಎಂದು ಪೂರೈಕೆದಾರರ ಸ್ವಂತ ನಿಯಮಗಳು ಹೇಳಿದಾಗ ಮಾತ್ರ `hardStopGuaranteed` ಅನ್ನು ಹೊಂದಿಸಲಾಗುತ್ತದೆ; ನಮೂದಿನ ಪಕ್ಕದ ಕಾಮೆಂಟ್ನಲ್ಲಿ ಮೂಲವಿರುತ್ತದೆ. ಅದನ್ನು ಎಂದಿಗೂ ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ `true` ಎಂದು ಹೊಂದಿಸಲಾಗುವುದಿಲ್ಲ, ಮತ್ತು ಯಾರೂ ಪರಿಶೀಲಿಸದ ನಮೂದು ಹೊಂದಿಸದೇ ಉಳಿಯುತ್ತದೆ. ಆದ್ದರಿಂದ ಕಠಿಣ-ನಿಲುಗಡೆ ಫ್ಲ್ಯಾಗ್ ಇಲ್ಲದಿರುವುದು "ದೃಢಪಟ್ಟಿಲ್ಲ" ಎಂದರ್ಥವೇ ಹೊರತು "ನಿಮಗೆ ಬಿಲ್ ಮಾಡುತ್ತದೆ ಎಂದು ತಿಳಿದಿದೆ" ಎಂದಲ್ಲ. **STRICT ಮೋಡ್** (`freeAccessPolicy=strict` ಎಂಬ ಆಯ್ಕೆಯಾಧಾರಿತ ರೂಟಿಂಗ್ ರಕ್ಷಣಾ ವ್ಯವಸ್ಥೆ) ಫ್ಲ್ಯಾಗ್ ಹೊಂದಿರುವ ನಮೂದುಗಳನ್ನು ಮಾತ್ರ ನಂಬುತ್ತದೆ; ಇತರ ಪ್ರತಿಯೊಂದು ಉಚಿತ ಹಂತವನ್ನೂ `no-hard-stop` ಎಂದು ಹೊರಗಿಡಲಾಗುತ್ತದೆ (`open-sse/services/autoCombo/strictZeroCostFilter.ts` ನೋಡಿ). ಈ ರಕ್ಷಣಾ ವ್ಯವಸ್ಥೆಯು ಪೂಲ್ ಅನ್ನು ಫಿಲ್ಟರ್ ಮಾಡಿದಾಗ, ಆಪರೇಟರ್ಗೆ ಕಾಣುವ ಲಾಗ್ ಹೊರಗಿಡಲಾದ ನಮೂದುಗಳ ಸಂಖ್ಯೆ ಮತ್ತು ಅವುಗಳಲ್ಲಿ `no-hard-stop` ಪಾಲು—ಎರಡನ್ನೂ ವರದಿ ಮಾಡುತ್ತದೆ.
- `estMonthlyFreeTokens` = ಮರುಕಳಿಸುವ ಮಾಸಿಕ ಟೋಕನ್ಗಳು ಮಾತ್ರ. **ಒಂದು-ಬಾರಿಯ ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗಳು ಮರುಕಳಿಸುವುದಿಲ್ಲ** ಮತ್ತು ಅವುಗಳನ್ನು 0 ಎಂದು ಎಣಿಸಲಾಗುತ್ತದೆ. ಸ್ಥಗಿತಗೊಂಡ ಹಂತಗಳನ್ನೂ 0 ಎಂದು ಎಣಿಸಲಾಗುತ್ತದೆ.
- ದೈನಂದಿನ ಟೋಕನ್ ಮಿತಿ → `monthly = daily × 30`. RPD ಮಾತ್ರ ದಾಖಲಿಸಲಾಗಿದ್ದರೆ → `RPD × ~800 output tokens × 30`. RPM/TPM ಮಾತ್ರ ಇದ್ದರೆ (ದೈನಂದಿನ ಮಿತಿ ಇಲ್ಲದಿದ್ದರೆ) → **ಮಿತಿಯಿಲ್ಲದ್ದು** (ಕೆಳಗೆ ನೋಡಿ).
- **ಶಾಶ್ವತವಾಗಿ ಉಚಿತ, ಆದರೆ ಪ್ರಕಟಿತ ಟೋಕನ್ ಮಿತಿ ಇಲ್ಲ** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): ಇವು ದರ/ಸಮಕಾಲೀನತೆಯ ಮಿತಿಗೆ ಒಳಪಟ್ಟ ನೈಜ, ಮರುಕಳಿಸುವ ಉಚಿತ ಪ್ರವೇಶಗಳಾಗಿವೆ. ನಾವು ಅವುಗಳನ್ನು `recurring-uncapped` ಎಂದು ವರ್ಗೀಕರಿಸುತ್ತೇವೆ ಮತ್ತು **ಎಂದಿಗೂ ಅವುಗಳ ಮೊತ್ತವನ್ನು ಲೆಕ್ಕಿಸುವುದಿಲ್ಲ** — `RPM × 24/7 × 30d` ಅನ್ನು ಗುಣಿಸುವುದರಿಂದ ಕಾಲ್ಪನಿಕ ಗರಿಷ್ಠ ಮಿತಿ ಸೃಷ್ಟಿಯಾಗುತ್ತದೆ (ನಾವು ತಿರಸ್ಕರಿಸುವ ಅತಿರೇಕ ಇದೇ). ಅವು ಅಸ್ತಿತ್ವದಲ್ಲಿವೆ ಎಂಬುದನ್ನು ನಿಮಗೆ ತಿಳಿಸಲು ಅವುಗಳನ್ನು ಪಟ್ಟಿಮಾಡಲಾಗಿದೆ.
- **ಠೇವಣಿ-ಅನ್ಲಾಕ್ ಹೆಚ್ಚಳ:** ಉಚಿತ ಕೋಟಾವನ್ನು ಶಾಶ್ವತವಾಗಿ ಹೆಚ್ಚಿಸುವ ಒಂದು-ಬಾರಿಯ ಸಣ್ಣ ಟಾಪ್-ಅಪ್ (OpenRouter: $10 → 1000 ವಿನಂತಿಗಳು/ದಿನ ≈ +24M/ತಿಂಗಳು). ಇದನ್ನು ಪ್ರತ್ಯೇಕ ಸಂಖ್ಯೆಯಾಗಿ ವರದಿ ಮಾಡಲಾಗುತ್ತದೆ ಮತ್ತು ಸ್ಥಿರ ಮುಖ್ಯ ಸಂಖ್ಯೆಯಿಂದ ಹೊರಗಿಡಲಾಗುತ್ತದೆ.
- **ಅರ್ಹತೆ-ನಿಯಂತ್ರಿತ ಕೋಟಾಗಳು** (`eligibilityGate: "regional-identity"`): ಪ್ರದೇಶಕ್ಕೆ ಬದ್ಧವಾದ ಗುರುತಿನ ಪರಿಶೀಲನೆಯ ನಂತರ ಮಾತ್ರ ಲಭ್ಯವಾಗುವ ನೈಜ ಮರುಕಳಿಸುವ ಕೋಟಾ (ಪ್ರಸ್ತುತ ಚೀನಾದ ಮುಖ್ಯಭೂಮಿಯ ನೈಜ-ಹೆಸರು ಪರಿಶೀಲನೆ). ಅದೇ ಪೂಲ್-ನಕಲು-ನಿವಾರಣಾ ನಿಯಮವನ್ನು ಬಳಸಿ ಇದನ್ನು ಪ್ರತ್ಯೇಕ ಸಂಖ್ಯೆಯಲ್ಲಿ (`gatedRecurringTokens`) ಎಣಿಸಲಾಗುತ್ತದೆ; ಸ್ಥಿರ ಮುಖ್ಯ ಸಂಖ್ಯೆಯಲ್ಲಿ ಎಂದಿಗೂ ಸೇರಿಸಲಾಗುವುದಿಲ್ಲ. ವ್ಯವಸ್ಥೆ (`freeType`) ಬದಲಾಗದೆ ಇರುವುದರಿಂದ ರೂಟಿಂಗ್ ಕೂಡ ಬದಲಾಗುವುದಿಲ್ಲ.
- **ಸಾಕ್ಷ್ಯದ ವರ್ಗಗಳು.** ನಿಯಮ: ಕ್ಯಾಟಲಾಗ್ನಲ್ಲಿರುವ ಸಂಖ್ಯೆಯು ನಮೂದಿನ ಪಕ್ಕದ `// evidence:` ಕಾಮೆಂಟ್ನಲ್ಲಿ ತನ್ನ ಮೂಲವನ್ನು ಉಲ್ಲೇಖಿಸುತ್ತದೆ — `public-page` (ಯಾರಾದರೂ ಓದಬಹುದಾದ ಪೂರೈಕೆದಾರರ ಪುಟ), `api-public` (ಪೂರೈಕೆದಾರರ ದೃಢೀಕರಣ-ಅಗತ್ಯವಿಲ್ಲದ ಎಂಡ್ಪಾಯಿಂಟ್, ಉದಾಹರಣೆಗೆ router.bynara.id ನಲ್ಲಿರುವ NaraRouterನ ಸಾರ್ವಜನಿಕ ಪ್ಲಾನ್ಗಳ ಎಂಡ್ಪಾಯಿಂಟ್), ಅಥವಾ `console-verified <date> por <who>` (ಸಂಖ್ಯೆಯು ಖಾತೆಯ ಕನ್ಸೋಲ್ನೊಳಗೆ ಮಾತ್ರ ಗೋಚರಿಸುತ್ತದೆ; ಅದನ್ನು ಯಾರು ಮತ್ತು ಯಾವಾಗ ನೋಡಿದರು ಎಂಬುದನ್ನೂ, ಮಿತಿ ಅಸ್ತಿತ್ವದಲ್ಲಿದೆ ಎಂದು ಹೇಳುವ ಸಾರ್ವಜನಿಕ ಪುಟವನ್ನೂ ಕಾಮೆಂಟ್ ದಾಖಲಿಸುತ್ತದೆ). ಪ್ರಸ್ತುತ ಸ್ಥಿತಿ: 2026-09-02ರಂದು ಮರು-ಲೆಕ್ಕಪರಿಶೋಧನೆಗೊಳಗಾದ ಐದು ಬ್ಲಾಕ್ಗಳು ಇದನ್ನು ಹೊಂದಿವೆ (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); 2026-09-02ರ ಮರು-ಲೆಕ್ಕಪರಿಶೋಧನೆಗಿಂತ ಹಿಂದಿನ ನಮೂದುಗಳನ್ನು ಪರಿಷ್ಕರಿಸುವವರೆಗೆ ಅವು ಹಿಂದಿನ ಸಂಶೋಧನೆಯನ್ನು ಆಧಾರವಾಗಿ ಪಡೆಯುತ್ತವೆ; ಸಾಕ್ಷ್ಯದ ಕಾಮೆಂಟ್ ಇಲ್ಲದ ಯಾವುದೇ **ಹೊಸ ಅಥವಾ ಬದಲಾದ** ಸಂಖ್ಯೆ ಒಂದು ದೋಷವಾಗಿದೆ. ಪ್ರಸ್ತುತ `mistral` ಮಾತ್ರ ಕನ್ಸೋಲ್ನಲ್ಲಿ ಪರಿಶೀಲಿತವಾಗಿದೆ.

## ನಮ್ಮ ಸಂಖ್ಯೆ ಇತರ ಅಗ್ರಿಗೇಟರ್ಗಳಿಗಿಂತ ಏಕೆ ಚಿಕ್ಕದಾಗಿದೆ

ಈ ಕ್ಷೇತ್ರದಲ್ಲಿನ ಬಹುತೇಕ "ತಿಂಗಳಿಗೆ ಉಚಿತ ಟೋಕನ್ಗಳು" ಅಂಕಿಅಂಶಗಳು ಪ್ರತಿ-ಮಾದರಿ ಲೇಬಲ್ಗಳ ಮೊತ್ತಗಳಾಗಿವೆ. ನಮ್ಮದು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಹಾಗಿಲ್ಲ:

- **ಪ್ರತಿ ಹಂಚಿಕೆಯ ಪೂಲ್ ಅನ್ನು ಒಮ್ಮೆ ಮಾತ್ರ ಎಣಿಸಲಾಗುತ್ತದೆ.** Mistral ನ ಉಚಿತ ಯೋಜನೆಯು ಪ್ರತಿ ಸಂಸ್ಥೆಗೆ ತಿಂಗಳಿಗೆ ಒಂದೇ 1B ಭತ್ಯೆಯಾಗಿದೆ; ಅದನ್ನು ಐದು ಮಾದರಿಗಳ ಅಡಿಯಲ್ಲಿ ಪಟ್ಟಿ ಮಾಡುವುದರಿಂದ ಅದು 5B ಆಗುವುದಿಲ್ಲ. ಪ್ರತಿ ಮಾದರಿಯಂತೆ ಮೊತ್ತ ಮಾಡಿದರೆ, ನಮ್ಮದೇ ಕ್ಯಾಟಲಾಗ್ನಲ್ಲಿ **~7.4B** ಎಂದು ಕಾಣುತ್ತದೆ (2026-09-03 ರಂದು ಮರುಲೆಕ್ಕಿಸಲಾಗಿದೆ; ಈ ಅಂಕಿಅಂಶವು CI-ಗೇಟೆಡ್ ಅಲ್ಲ — ಕ್ಯಾಟಲಾಗ್ ಬದಲಾದಾಗಲೆಲ್ಲ ಅದನ್ನು ಮರುಅಳೆಯಿರಿ) — ಶೀರ್ಷಿಕೆಯಲ್ಲಿ **~1.47B** ಎಂದು ಹೇಳಲಾಗಿದೆ, ಏಕೆಂದರೆ ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ಒಂದೊಂದು ಖಾತೆಯು ವಾಸ್ತವವಾಗಿ ಖರ್ಚು ಮಾಡಬಹುದಾದ ಮೊತ್ತ ಅದೇ.
- **ದೈನಂದಿನ ಮಿತಿಗಳನ್ನು ಪರಿವರ್ತಿಸಲಾಗುತ್ತದೆ, ದರಗಳನ್ನು ಅಲ್ಲ.** ದಾಖಲಿತ tokens/day ಮಿತಿಯು `× 30` ಆಗುತ್ತದೆ; ದಾಖಲಿತ requests/day ಮಿತಿಯು `RPD × ~800 ಟೋಕನ್ಗಳು × 30` ಆಗುತ್ತದೆ; requests-per-minute ಅನ್ನು ಮಾತ್ರ ಪ್ರಕಟಿಸುವ ಪೂರೈಕೆದಾರರಿಗೆ ಮಾಸಿಕ ಅಂಕಿಅಂಶ **ಇರುವುದಿಲ್ಲ** ಮತ್ತು ಅವರನ್ನು _ಮಿತಿಯಿಲ್ಲದ್ದು_ ಎಂದು ಪಟ್ಟಿ ಮಾಡಲಾಗುತ್ತದೆ, ಎಂದಿಗೂ ಮೊತ್ತಕ್ಕೆ ಸೇರಿಸಲಾಗುವುದಿಲ್ಲ. ದರ ಮಿತಿಯನ್ನು 24/7 ರಿಂದ ಗುಣಿಸುವುದು ನಾವು ನಿರಾಕರಿಸುವ ಅತಿಶಯೋಕ್ತಿಯಾಗಿದೆ.
- **ಪ್ರಾದೇಶಿಕ ಗುರುತು ಪರಿಶೀಲನೆಯ ಹಿಂದಿರುವ ಕೋಟಾಗಳನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ತೋರಿಸಲಾಗುತ್ತದೆ** (`+~6M ಪ್ರಾದೇಶಿಕ ಗುರುತು ಪರಿಶೀಲನೆಯ ಹಿಂದೆ`), ಏಕೆಂದರೆ ಹೆಚ್ಚಿನ ಓದುಗರು ಅವುಗಳನ್ನು ಬಳಸಲಾಗುವುದಿಲ್ಲ.
- **ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗಳು ಮೊದಲ ತಿಂಗಳಿಗೆ ಮಾತ್ರ** ಮತ್ತು ಅವುಗಳನ್ನು ಎರಡನೇ ಅಂಕಿಅಂಶವಾಗಿ ವರದಿ ಮಾಡಲಾಗುತ್ತದೆ; ಸ್ಥಿರ ಅಂಕಿಅಂಶದೊಂದಿಗೆ ಎಂದಿಗೂ ಬೆರೆಸಲಾಗುವುದಿಲ್ಲ.
- **ಈ ಅಂಕಿಅಂಶವನ್ನು CI ಜಾರಿಗೊಳಿಸುತ್ತದೆ.** `npm run check:docs-counts` ಕ್ಯಾಟಲಾಗ್ನಿಂದ ಒಟ್ಟುಗಳನ್ನು ಮರುಲೆಕ್ಕಿಸುತ್ತದೆ ಮತ್ತು ಈ ಫೈಲ್, README ಅಥವಾ ಬಜೆಟ್ ಕಾರ್ಡ್ ಅವುಗಳಿಂದ ವ್ಯತ್ಯಾಸಗೊಂಡಾಗ ಬಿಲ್ಡ್ ಅನ್ನು ವಿಫಲಗೊಳಿಸುತ್ತದೆ.

## ToS ಗಮನ ಕೋಷ್ಟಕ

> **ToS ಫ್ಲ್ಯಾಗ್ ಸಲಹಾತ್ಮಕವಾಗಿದೆ, ರೂಟಿಂಗ್ ಗೇಟ್ ಅಲ್ಲ.** `tos` ಎಂದು ಗುರುತಿಸಲಾದ ಪೂರೈಕೆದಾರರನ್ನು ಡೀಫಾಲ್ಟ್ ಆಗಿ ರೂಟಿಂಗ್ ಮತ್ತು ಕಾಂಬೊ/ಫಾಲ್ಬ್ಯಾಕ್ನಲ್ಲಿ ಇನ್ನೂ ಸೇರಿಸಲಾಗುತ್ತದೆ; ಫ್ಲ್ಯಾಗ್ ಕೇವಲ `/dashboard/free-tiers` ಮತ್ತು `/api/free-tier/summary` ನಲ್ಲಿ ಮಾತ್ರ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ. `excludeTosAvoid` ಕ್ವೆರಿ ಪ್ಯಾರಾಮೀಟರ್ ಸಾರಾಂಶ ವೀಕ್ಷಣೆಯ ಮೇಲೆ ಮಾತ್ರ ಪರಿಣಾಮ ಬೀರುತ್ತದೆ, ಜಾಗತಿಕ ರೂಟಿಂಗ್ ಮೇಲೆ ಅಲ್ಲ. ತೀರ್ಪು `open-sse/config/freeTierCatalog.ts` ನಲ್ಲಿ ಇದೆ (ಮಾಹಿತಿಗಾಗಿ ಮಾತ್ರ, ರೂಟಿಂಗ್ ಎಂಜಿನ್ಗಳು ಅದನ್ನು ಓದುವುದಿಲ್ಲ).

> ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಮಾಡಿದ, ಏಕ-ಬಳಕೆದಾರ ವೈಯಕ್ತಿಕ ಪ್ರಾಕ್ಸಿಗೆ ಸಂಬಂಧಿಸಿದಂತೆ ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ನಿಯಮಗಳ ತ್ವರಿತ ಅವಲೋಕನ. `caution` = ಪರಿಶೀಲಿಸಲು ಯೋಗ್ಯವಾದ ವೈಯಕ್ತಿಕ-ಬಳಕೆ ಅಥವಾ ಪ್ರಾಕ್ಸಿ ಷರತ್ತು; `ambiguous` = ಅಸ್ಪಷ್ಟ; `ok` = ಸ್ಪಷ್ಟವಾಗಿ ಅನುಮತಿಸಲಾಗಿದೆ. ಇದು ಮಾಹಿತಿಗಾಗಿ ಮಾತ್ರ, ಕಾನೂನು ಸಲಹೆಯಲ್ಲ — ನಿರ್ಧಾರ ನಿಮ್ಮದು.

### ⚠️ ಎಚ್ಚರಿಕೆ — ಪರಿಶೀಲಿಸಲು ಯೋಗ್ಯವಾದ ವೈಯಕ್ತಿಕ-ಬಳಕೆ / ಪ್ರಾಕ್ಸಿ ಷರತ್ತುಗಳು (16)

> ಅವರ ಉಚಿತ ಪ್ರವೇಶವು ನಿಜವಾಗಿದೆ ಮತ್ತು OmniRoute ಅವರಿಗೆ ರೂಟ್ ಮಾಡಬಹುದು; ಕೆಳಗಿನ ಷರತ್ತುಗಳನ್ನು ತಿಳಿದುಕೊಳ್ಳುವುದು ಮಾತ್ರ ಉಪಯುಕ್ತ. OAuth/ಕೀಲಿರಹಿತವಾದವುಗಳನ್ನು ಟೋಕನ್ಗಳ ಮೂಲಕ ಪ್ರಮಾಣೀಕರಿಸಲಾಗುವುದಿಲ್ಲ, ಆದ್ದರಿಂದ ಅವು ಶೀರ್ಷಿಕೆಯ ಅಂಕಿಅಂಶದಲ್ಲಿಲ್ಲ (ಅವು ಬಳಸಲಾಗುವುದಿಲ್ಲ ಎಂಬ ಕಾರಣಕ್ಕೆ ಅಲ್ಲ).
