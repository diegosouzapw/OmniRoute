`agentrouter` augšupstraumes vārteja izmanto uz atslēgvārdiem balstītu satura filtru laukam
`messages[].content`. Filtrs ir daļēji deterministisks (vienmēr bloķē
noteiktas frāzes) un daļēji varbūtisks (jutīgs pret pieprasījumu uzplūdiem — kļūst
agresīvāks pēc straujas pieprasījumu virknes un atjaunojas pēc nogaidīšanas perioda).

Kad WAF bloķē pieprasījumu, tas atgriež:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Filtra tvērums

WAF pārbauda tikai `messages[].content`. Tas **nepārbauda**:

- `system` uzvedni
- Strukturēta satura blokus (`tool_result`, `tool_use`, `thinking`, `image`)
- Rīku laukus `description` un `input_schema`
- Pieprasījuma metadatus, galvenes vai modeļa ID

## Vienmēr bloķētie raksti (reģistrnejutīgi)

| Raksts                         | Piezīmes                                                  |
| ------------------------------ | --------------------------------------------------------- |
| Jebkurš `Lorem ipsum` variants | Tiek bloķēts viss latīņu lorem vārdu krājums              |
| `language model` (atsevišķi)   | "the language model" un "large language model" tiek cauri |
| `virtual assistant`            | "AI assistant" tiek cauri                                 |
| `I'm here to help`             | Arī "here to help" atsevišķi tiek bloķēts                 |
| `Claude, made by Anthropic`    | Tikai pilnā frāze                                         |

## Gandrīz vienmēr bloķētie raksti

| Raksts                                                   | Piezīmes                                                           |
| -------------------------------------------------------- | ------------------------------------------------------------------ |
| `placeholder`                                            | Ja tas ir norādīts atsevišķi (nevis kā parametra nosaukums u.tml.) |
| `dummy data`                                             | Izplatīta sākotnējo datu frāze testa objektiem                     |
| `foo bar baz`                                            | Kanoniska viettura frāze                                           |
| Atkārtoti īsi marķieri (`AAA BBB CCC`, `test test test`) | Atslēgvārdu pārblīvēšanas detektors                                |

## Darbība slodzes apstākļos

Pēc aptuveni 5 straujiem pieprasījumiem īsā laika periodā WAF sāk bloķēt saturu,
kas parasti tiktu izlaists. Ierobežojums atslābst pēc aptuveni 5–10 sekunžu
dīkstāves. Tas ir tas pats ar IP adresi un atslēgu saistītais ātruma ierobežotājs, kas izraisa
periodiskas `400 content-blocked` kļūdas, kad Claude Code vai Codex CLI
ātrā secībā veic vairākus rīku izmantošanas / ziņojumu nosūtīšanas izsaukumus.

## OmniRoute jau ieviestie mazināšanas pasākumi

1. **`open-sse/services/wafRateLimit.ts`** — pieprasījumu uzplūdu ierobežotājs, kas nodrošina
   vismaz 500 ms intervālu starp izejošajiem pieprasījumiem uz jebkuru `agentrouter:*`
   URL. Šis intervāls ir daudz īsāks par cilvēkam uztveramu aizkavi un neļauj
   WAF aktivizēties normālas datplūsmas laikā.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — kad augšupstraumes pakalpojums atgriež
   `400 content-blocked`, izpildītājs atkārtoti mēģina izmantot to pašu URL ar
   eksponenciālu aizturi (1,5 s, 3,0 s, ne vairāk kā 2 mēģinājumi). Pēc aiztures
   WAF parasti atslābst, un atkārtotais mēģinājums izdodas.

3. **`tests/unit/compression/harness.test.ts`** — testa objekts
   `longInput` tika mainīts no `"lorem ipsum dolor sit amet ".repeat(40)`
   uz `"example content for testing purposes ".repeat(40)`, lai tad, kad
   Claude Code nolasa šo failu, izmantojot rīku `Read`, faila saturs
   netiktu nodots atpakaļ caur `tool_result` bloku un neaktivizētu WAF.

## Norādījumi uzvednēm un rīku izvadei

Ja Claude Code vai Codex CLI sesija atkārtoti sastopas ar
`400 content-blocked`, pārbaudiet jaunāko lietotāja ziņojumu un jaunāko
rīka rezultātu, meklējot kādu no iepriekš minētajiem rakstiem, un pārfrāzējiet to. Izplatīti
apiešanas risinājumi:

- Aizstājiet `Lorem ipsum …` ar `example text …` vai faktisko saturu,
  kuru tests vai testa objekts mēģina modelēt.
- Aizstājiet `placeholder` (ja tas ir norādīts atsevišķi) ar `example value`,
  `sample value` vai faktisko vērtību.
- Aizstājiet `language model` ar `large language model` vai `the model`.
- Aizstājiet `dummy data` ar `sample data` vai reālistiskām sākotnējām vērtībām.
- Aizstājiet `I'm here to help` / `here to help` ar konkrētāku
  ievadfrāzi (piemēram, "I'll review the file you mentioned").

## Kļūdaini pozitīvo rezultātu ziņošana augšupstraumes pakalpojuma uzturētājiem

Pašreizējais filtrs ir pārmērīgi agresīvs — tas bloķē "Lorem ipsum"
`tool_result` blokos, lai gan operators acīmredzami nebija paredzējis
ievadīt uzvedni. Operatoriem, kuri vēlas, lai šī problēma tiktu novērsta tās avotā,
jāsazinās ar `agentrouter.org`, lai ziņotu par kļūdaini pozitīvajiem rezultātiem. Iepriekš norādītais bloķēšanas saraksts
ir empīrisks rezultāts, kas iegūts, pārbaudot augšupstraumes pakalpojumu 2026-08-03.
