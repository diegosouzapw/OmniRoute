> **Īsumā**: Instalējiet → Pievienojiet bezmaksas pakalpojumu sniedzēju → Norādiet savai IDE izmantot OmniRoute. Gatavs.

---

## 1. darbība: instalējiet OmniRoute

Izvēlieties vēlamo metodi:

### A variants: npm (ieteicams)

```bash
npm install -g omniroute
```

### B variants: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` ir jaunākā **publicētā** stabilā SemVer versija. Tā **neseko** git `main` zaram. GitOps vajadzībām piesaistiet konkrētu `diegosouzapw/omniroute:X.Y.Z` versiju. Skatiet sadaļu [Attēlu tagi / laidienu kanāli](../guides/DOCKER_GUIDE.md#release-channels).

### C variants: no pirmkoda

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## 2. darbība: palaidiet OmniRoute

```bash
omniroute
```

OmniRoute tiek palaists adresē `http://localhost:20128`. Informācijas panelis tiek atvērts automātiski.

---

## 3. darbība: pievienojiet bezmaksas pakalpojumu sniedzēju

Varat izmantot OmniRoute, **neko nemaksājot**, ja pievienojat bezmaksas pakalpojumu sniedzēju.

### A variants: Kiro (bezmaksas Claude — nav nepieciešama kredītkarte)

1. Atveriet informācijas paneli adresē `http://localhost:20128`
2. Dodieties uz **Pakalpojumu sniedzēji** → **Pievienot pakalpojumu sniedzēju**
3. Atlasiet **Kiro AI**
4. Noklikšķiniet uz **Savienot** (API atslēga nav nepieciešama!)
5. Gatavs! Tagad jums ir bezmaksas piekļuve Claude modeļiem.

### B variants: OpenCode Free (bez autentifikācijas)

1. Atveriet informācijas paneli adresē `http://localhost:20128`
2. Dodieties uz **Pakalpojumu sniedzēji** → **Pievienot pakalpojumu sniedzēju**
3. Atlasiet **OpenCode Free**
4. Noklikšķiniet uz **Savienot** (API atslēga nav nepieciešama!)
5. Gatavs! Tagad jums ir bezmaksas piekļuve vairākiem modeļiem.

### C variants: Pollinations (atslēga nav nepieciešama)

1. Atveriet informācijas paneli adresē `http://localhost:20128`
2. Dodieties uz **Pakalpojumu sniedzēji** → **Pievienot pakalpojumu sniedzēju**
3. Atlasiet **Pollinations**
4. Noklikšķiniet uz **Savienot** (API atslēga nav nepieciešama!)
5. Gatavs! Tagad jums ir bezmaksas piekļuve GPT-5, Claude, Gemini un citiem modeļiem.

---

## 4. darbība: pārbaudiet, vai viss darbojas

Sadaļā [API atslēgas](http://localhost:20128/dashboard/api-manager) izveidojiet jaunu atslēgu. Saglabājiet šo atslēgu, jo tā vairs netiks parādīta. Ņemiet vērā, ka šī atslēga ir paredzēta rīku piekļuvei OmniRoute, nevis augšupējo pakalpojumu sniedzēju piekļuvei.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Jums vajadzētu redzēt pievienoto modeļu sarakstu.

---

## 5. darbība: norādiet savai IDE vai CLI izmantot OmniRoute

Savā IDE vai CLI rīkā iestatiet:

```
Bāzes URL: http://localhost:20128/v1
API atslēga:  [kopējiet no Informācijas panelis → Galapunkti]
Modelis:    auto
```

Tas arī viss! Tagad jūsu IDE izmanto OmniRoute ar automātisku pakalpojumu sniedzēja atlasi.

### IDE piemērs: VSCode/Continue.dev

1. Programmā VSCode instalējiet paplašinājumu [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Atjauniniet `~/.continue/config.yaml`, pievienojot tālāk norādītās rindas:

```
  - name: OmniRoute - Automātiski
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev tērzēšanas rūtī atlasiet `OmniRoute - Automātiski`, un pieprasījumi tiks nosūtīti uz OmniRoute.
4. (Neobligāti) Uzdevums lasītājam — lieciet savai IDE atjaunināt `config.yaml` ar visām pārējām iepriekš sagatavotajām konfigurācijām 😊

### CLI piemērs: Codex CLI

1. Savā operētājsistēmā iestatiet vides mainīgo pastāvīgai lietošanai.
   Operētājsistēmā macOS/Linux (pievienojiet failam `~/.bashrc` vai `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Operētājsistēmā Windows (komandu uzvednē):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Tagad palaidīsim Codex, konfigurējot to darbam ar OmniRoute. Izpildiet:

```
omniroute launch-codex --model auto
```

Varat to paveikt manuāli, izmantojot `codex` un komandrindas parametrus, lai norādītu galapunktu un API atslēgu, taču ar iepriekš norādīto komandu OmniRoute par visu parūpējas jūsu vietā.

Tāda pati palaišana ar vienu komandu darbojas arī citiem CLI, izmantojot universālo palaidēju — `omniroute run <target>` atbalsta `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` un `gemini` (skatiet [CLI integrācijas](../guides/CLI-INTEGRATIONS.md)).

3. Tagad CLI vajadzētu sūtīt pieprasījumus uz OmniRoute.

### Pārliecinieties, ka jūsu rīks maršrutē pieprasījumus uz OmniRoute

Pieprasījuma informāciju varat apskatīt, kreisajā sānjoslā noklikšķinot uz [Uzraudzība/žurnāli](http://localhost:20128/dashboard/logs). Atverot ierakstus, varat skatīt detalizētāku informāciju. Turklāt varat redzēt, kādu informāciju nosūta jūsu iecienītais rīks. Tas ir noderīgi mācību un atkļūdošanas nolūkos.

## Bieži uzdotie jautājumi

### „Vai man ir nepieciešama API atslēga?”

**Nē!** Varat izmantot bezmaksas pakalpojumu sniedzējus (Kiro, OpenCode Free, Pollinations) bez API atslēgas. Vienkārši pievienojiet tos informācijas panelī.

### „Kas ir `auto`?”

`auto` norāda OmniRoute automātiski izvēlēties piemērotāko pakalpojumu sniedzēju katram pieprasījumam. Tas ņem vērā ātrumu, izmaksas, kvalitāti un pieejamību. Plašāku informāciju skatiet [Auto-Combo ceļvedī](./AUTO-COMBO-GUIDE.md).

### „Cik tas maksā?”

Pats OmniRoute ir **bezmaksas un atvērtā pirmkoda** risinājums. Jūs maksājat tikai par izmantotajiem pakalpojumu sniedzējiem. Daudziem pakalpojumu sniedzējiem ir bezmaksas līmeņi — skatiet [Bezmaksas līmeņu ceļvedi](./FREE-TIERS-GUIDE.md).

### „Vai varu to izmantot ar Claude Code / Cursor / Copilot?”

**Jā!** OmniRoute darbojas ar jebkuru rīku, kas atbalsta OpenAI formātu. Vienkārši iestatiet bāzes URL uz `http://localhost:20128/v1`. Konkrētas iestatīšanas instrukcijas skatiet [CLI rīku ceļvedī](../reference/CLI-TOOLS.md).

### „Kas notiek, ja pakalpojumu sniedzējs pārtrauc darboties?”

OmniRoute automātiski izlaiž nestrādājošos pakalpojumu sniedzējus un izmēģina nākamo. Jums nekas nav jādara. Plašāku informāciju skatiet [Auto-Combo ceļvedī](./AUTO-COMBO-GUIDE.md).
