## 1. Pakalpojuma faktiskā darbība (oficiālā dokumentācija, savstarpēji pārbaudīta)

- Bāzes URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` — parametri: `query` (obligāts), `max_results` (1–10, noklusējums 10), `tag` (`{domain}.{sub_domain}` vertikālā maršrutēšana), `zone` (cn/intl), `language`, `params` (strukturēti vertikāles lauki), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` — iespēju katalogs; NETIEK ieskaitīts kvotā.
- `POST /v1/extract` — iegūst/izvelk `{url, title, content}`; stingri noteikts JSON pamatteksts, 16 KiB ierobežojums.
- `POST /v1/auth/email/register` — reģistrācija ar vienu izsaukumu; atgriež vienreiz parādītu nešifrēta teksta atslēgu `as_sk_...`.
- Autentifikācija: neobligāts `Authorization: Bearer <as_sk_...>`; anonīmā piekļuve tiek ierobežota atbilstoši IP adresei, patērējot bezmaksas dienas kvotu; nederīga atslēga atgriež 401/403 BEZ nemanāmas pārslēgšanās uz anonīmo režīmu.
- Bezmaksas līmenis: 1000 pieprasījumu dienā, 20 QPS katrai atslēgai. Maksas līmenis: cena nav noteikta (drīzumā).
- Atbildes aploksne: veiksmīga atbilde `{code: 0, message: "success", request_id, data}`; neveiksmīga atbilde `{code: -1, message}`. Autentifikācijas/kvotas kļūdām nav strukturēta `error_code` (signāls ir ziņojuma teksts); izvilkšanai raksturīgajām kļūdām ir `error_code` (`invalid_extract_url`, `extract_failed`). 429 atbildei nav `Retry-After` galvenes.

## 3. Lēmumi (visi pieņemti 2026-08-26)

1. **Maršrutēšanas nostāja: `fallbackOnly`.** Pamatojums: bezmaksas nodrošinātājs ar izmaksām 0 nedrīkst dominēt automātiskajā maršrutēšanā pēc izmaksām; tieša atlase un atgriešanās kļūmjpārlēces gadījumā netiek ietekmēta. Precedents: sapludinātais xquik ieraksts.
2. **Tvērums: webSearch + webFetch, izmantojot `POST /v1/extract` versijā v1.** Saskaņots ar tavily/exa divu iespēju mentālo modeli. Vertikālās saskarnes (`tag`, `sub-domains`, `batch_search`) neietilpst tvērumā — pašlaik vertikālajiem parametriem nav IR.
3. **Kvotas attēlojums: `freeMonthlyQuota: 0`** (xquik stila konservatīvs attēlojums). Faktiskais limits (1000 pieprasījumu dienā, atiestatīšana katru dienu) tā vietā ir norādīts UI kataloga `authHint` tekstā. Pamatojums: kvotas attēlojumam jāatbilst atiestatīšanas semantikai; dienas limita pārvēršana mēneša ekvivalentā (30000) ir nepatiess solījums, kuru UI nevar izpildīt.
4. **searchTypes: tikai `["web"]`.** Nav publisku pierādījumu par ziņu/attēlu vertikāli AnySearch API; vārtejas, kas integrē API bez dokumentētas vertikāles (piemēram, Google Custom Search), piedāvā tikai tīmekļa meklēšanu, nevis nemanāmi kartē news -> web.
5. **Atslēgas nostāja:** darbība bez atslēgas ir iespējama; nederīga atslēga atgriež 401/403, un pieprasījums nekad netiek nemanāmi pazemināts uz anonīmu režīmu (atspoguļo augšupstraumes līgumu).
6. **Apzināti izņēmumi:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (tērzēšanas pārtveršanai joprojām tiek izmantoti firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (anonīmie attālie galapunkti koplieto vienu pēc IP ierobežotu kopu katrai izejošajai IP adresei, tāpēc izvilkšana bez atslēgas ir izvēles iespēja, nevis automātiskās maršrutēšanas kandidāts); `QUOTA_STATUS_PROVIDERS` (AnySearch signalizē par kvotu, izmantojot 429/aploksni, nevis 402/403 statusu).

- xquik veidne: komits a0ceccc, PR #11370 (iekļauts kokā laidienā release/v3.8.51).
- AnySearch oficiālā dokumentācija: https://anysearch.com/docs, https://anysearch.com/pricing; MCP katalogs mcpservers.org/servers/anysearch-ai/anysearch-mcp-server; prasmju repozitorijs github.com/anysearch-ai/anysearch-skill.
