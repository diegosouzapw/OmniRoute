> **Patiesais avots:** `src/lib/agentSkills/` (katalogs, ģenerators, parsētāji) + direktorijs `skills/` (SKILL.md faili)
> **Pēdējoreiz atjaunināts:** 2026-08-02 — v3.8.50

Agentu prasmes ir strukturēti SKILL.md faili, kas ārējiem aģentiem, MCP klientiem un A2A orķestratoriem māca izmantot OmniRoute REST API un CLI. Atšķirībā no [Omni prasmēm](./SKILLS.md) (kas ir LLM rīku definīcijas, kuras tiek izpildītas OmniRoute iekšienē), Agentu prasmes ir _dokumentācijas katalogs_ — statisks markdown saturs, ko var tieši ievadīt aģenta kontekstā.

---

## Pārskats

Katalogā ir **45 Agentu prasmes** (23 REST API + 21 CLI + 1 konfigurācijas darbplūsma). Katrai prasmei ir:

- **Kanoniskais ID** (`omni-auth`, `cli-serve` utt.)
- **SKILL.md** fails direktorijā `skills/{id}/SKILL.md` ar YAML priekšdaļu (`name`, `description`) + bagātīgi formatētu markdown pamatdaļu
- **REST galapunkti** (API prasmēm) vai **CLI apakškomandas** (CLI prasmēm), kas iegūtas no OpenAPI specifikācijas un CLI reģistra
- **GitHub neapstrādātā satura URL** tiešai ielādei: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Arhitektūra

```
src/shared/constants/agentSkills.ts    — pārvaldīts saraksts ar 45 ierakstiem (nosaukums/apraksts/kategorija/joma/ikona)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() ieraksta SKILL.md direktorijā skills/{id}/
  openapiParser.ts                     — izgūst REST galapunktus no docs/openapi.yaml
  cliRegistryParser.ts                 — izgūst CLI apakškomandas no bin/cli-registry.ts
  schemas.ts                           — Zod shēmas: AgentSkillSchema, SkillCoverageSchema utt.
  types.ts                             — TypeScript saskarnes: AgentSkill, SkillCoverage utt.

skills/{id}/SKILL.md                   — ģenerēti un manuāli papildināti markdown faili (kopā 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (nepieciešama autentifikācija)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 MCP rīki (saraksts, iegūšana, pārklājums)
src/lib/a2a/skills/listCapabilities.ts        — A2A prasme: list-capabilities
```

## SKILL.md formāts

```markdown
---
name: omni-providers
description: "Pārvaldiet pakalpojumu sniedzēju savienojumus: pievienojiet, pārbaudiet, rotējiet un noņemiet akreditācijas datus."
---

<!-- ģenerēts ar src/lib/agentSkills/generator.ts; manuālās izmaiņas tiks pārrakstītas -->

## Pārskats

...

## Autentifikācija

...

## Galapunkti

...

<!-- skill:custom-start -->

## Pielāgota sadaļa (tiek saglabāta atkārtotas ģenerēšanas laikā)

...

<!-- skill:custom-end -->
```

Atkārtotas ģenerēšanas laikā ģenerators saglabā saturu starp `<!-- skill:custom-start -->` un `<!-- skill:custom-end -->`. Desmit prasmēm ir manuāli papildināti pielāgoti bloki:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## REST API atklāšana

| Galapunkts                   | Metode | Apraksts                                                                | Autorizācija |
| :--------------------------- | :----- | :---------------------------------------------------------------------- | :----------- |
| `/api/agent-skills`          | GET    | Kataloga saraksts (neobligāti `?category=api\|cli\|config&area=<area>`) | nav          |
| `/api/agent-skills/{id}`     | GET    | Iegūt vienas prasmes metadatus                                          | nav          |
| `/api/agent-skills/{id}/raw` | GET    | Iegūt SKILL.md formātā `text/markdown`                                  | nav          |
| `/api/agent-skills/coverage` | GET    | Pārklājuma statistika (cik SKILL.md failu pastāv)                       | nav          |
| `/api/agent-skills/generate` | POST   | Aktivizēt ģeneratoru (dryRun/prune/onlyIds)                             | pārvaldība   |

Piemērs — uzskaitīt visas API prasmes:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Piemērs — iegūt vienu SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Kā ārējie aģenti izmanto prasmes

### 1. Atklāšana, izmantojot REST

```bash
# Iegūt pilno katalogu
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Iegūt SKILL.md konteksta ievietošanai
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Atklāšana, izmantojot MCP

```typescript
// Claude Desktop / Cursor MCP klientā:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → AgentSkill masīvs, kurā katram elementam ir rawUrl
```

### 3. Atklāšana, izmantojot A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table ir markdown tabula ar visu 45 prasmju ID un rawUrl kolonnām
```

### 4. Tieša neapstrādātā satura iegūšana no GitHub (serveris nav nepieciešams)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Ģenerators

Ģenerators nolasa pārvaldīto katalogu, OpenAPI specifikāciju un CLI reģistru un katram ierakstam izveido `skills/{id}/SKILL.md`:

```bash
# Priekšskatījums (izmēģinājuma izpilde bez ierakstīšanas)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Pilna atkārtota ģenerēšana
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Atkārtoti ģenerēt noteiktus ID
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Ģeneratora atbilde ir `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
