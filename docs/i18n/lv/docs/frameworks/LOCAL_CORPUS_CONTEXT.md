> **Patiesais avots:** `src/lib/localCorpus/index.ts` (ierobežots teksta indekss),
> `src/lib/localCorpus/configured.ts` (konfigurēta izpildlaika vide),
> `src/lib/db/localCorpus.ts` (saknes ceļa saglabāšana),
> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 tikai lasāmi MCP rīki) un
> `src/app/api/settings/local-corpus/route.ts` (iestatījumu API).

## Kas tas ir

Local Corpus ļauj operatoram OmniRoute MCP serverim darīt pieejamu vienu skaidri apstiprinātu teksta failu direktoriju. Faili paliek to sākotnējā direktorijā: OmniRoute saglabā SQLite datubāzē tikai kanonisko saknes ceļu un uztur meklēšanas indeksu atmiņā. Korpusa saturs netiek kopēts repozitorijā vai datubāzē.

Indeksa atsvaidzināšana notiek inkrementāli. Nemainīti faili tiek izmantoti atkārtoti, pamatojoties uz to lielumu un modificēšanas laiku, savukārt mainītie faili tiek nolasīti atkārtoti, un tiem tiek aprēķināta SHA-256 jaukšanas vērtība; izdzēstie faili tiek noņemti. Meklēšana atsvaidzina indeksu, kas ir vecāks par 30 sekundēm; izsaucēji var arī pieprasīt tūlītēju atsvaidzināšanu.

## Avota konfigurēšana

Iestatījumu maršrutam ir nepieciešama tā pati pārvaldības autentifikācija, kas citām iestatījumu API. Iesniegtajam ceļam jau ir jāpastāv, un tam jābūt absolūtam direktorijas ceļam.

```bash
# Pievienot apstiprinātu direktoriju
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Pārbaudīt konfigurācijas un indeksa statusu
curl http://localhost:20128/api/settings/local-corpus

# Atvienot, nemainot avota failus
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP rīki

Visiem trim rīkiem ir nepieciešama atļauja `read:local-corpus`. Rīku atbildēs tiek norādīti relatīvie ceļi un saknes direktorijas pamatnosaukums, bet nekad tās absolūtais ceļš.

| Rīks                  | Apraksts                                                                                            |
| :-------------------- | :-------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Ziņo par konfigurācijas stāvokli, indeksa lielumu, ierobežojumiem un pēdējās atsvaidzināšanas laiku |
| `local_corpus_search` | Meklē indeksētajā tekstā un atgriež ierobežotus, pa rindām tvērtus fragmentus (līdz 20 rezultātiem) |
| `local_corpus_read`   | Nolasa ierobežotu rindu diapazonu no viena atļauta korpusam relatīva faila                          |

MCP ievades piemēri:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Drošības robežas

- Atļauto failu saraksts ir orientēts uz tekstu: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` un `.yml`.
- Simboliskās saites tiek izlaistas. Lasīšanas ceļi tiek kanonizēti, un tiem jāpaliek
  konfigurētajā saknes direktorijā; absolūti ceļi un mēģinājumi pārvietoties ārpus tās tiek noraidīti.
- Sensitīvu un ģenerētu direktoriju nosaukumi tiek izslēgti: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` un
  `secrets`.
- Noklusējuma ierobežojumi ir 5 000 failu, 1 MiB vienam failam, 64 MiB kopējā indeksētā satura,
  aptuveni 4 000 rakstzīmju vienā meklēšanas fragmentā un 400 rindu vienā lasīšanas reizē.
- Faili, kas satur NUL rakstzīmes, tiek uzskatīti par neteksta failiem un tiek izlaisti vai noraidīti.

Bināri dokumenti, piemēram, PDF, DOCX, attēli un arhīvi, ar nolūku netiek atbalstīti.
Pirms indeksēšanas pārveidojiet tos apstiprinātā teksta formātā konfigurētajā direktorijā.

## Ekspluatācijas piezīmes

- Konfigurētās saknes mainīšana vai dzēšana notīra koplietoto atmiņā esošo indeksu.
- Procesa restartēšana izmet indeksu; nākamā meklēšana to atjauno no konfigurētā
  avota.
- `local_corpus_status` neveic piespiedu skenēšanu. Izmantojiet `local_corpus_search` ar
  `refresh: true`, ja nepieciešama tūlītēja atkārtota skenēšana.
- Skenēšanas un lasīšanas kļūmes tiek saskaitītas vai atgrieztas kā sanitizētas kļūdas; avota faili
  nekad netiek modificēti.
