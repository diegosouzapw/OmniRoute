> **Patiesības avots:** `src/lib/obsidian/api.ts` (REST + sinhronizācijas klients),
> `src/lib/db/obsidian.ts` (pilnvaras / bāzes URL / WebDAV pastāvīgā glabāšana),
> `src/lib/obsidianSync.ts` (WebDAV krātuves sinhronizācija), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP rīki), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (iestatījumu API). Rīku reģistrācija
> un tvērumu sasaiste atrodas `open-sse/mcp-server/server.ts`.

## Kas tas ir

OmniRoute izveido savienojumu ar **Obsidian** krātuvi kā **konteksta avotu** — lokālu Markdown
zināšanu bāzi, kuru aģenti lasa un raksta, izmantojot iebūvēto MCP serveri. Integrācija
sazinās ar kopienas spraudni **Obsidian Local REST API**, kas darbojas darbvirsmas
lietotnē, tādēļ aģenti var meklēt piezīmes, lasīt/rakstīt/labot failus, uzskaitīt krātuves
saturu, strādāt ar dienas/nedēļas periodiskajām piezīmēm, pārvaldīt tagus, izpildīt
Obsidian komandas un (pēc izvēles) koordinēt divvirzienu darbvirsmas↔mobilās ierīces
krātuves sinhronizāciju.

Klients (`src/lib/obsidian/api.ts`) ietver Local REST API ar:

- **Atkārtotiem mēģinājumiem ar pieaugošu aizkavi** pārejošām `5xx` kļūdām un **30 sekunžu taimautu**, izmantojot `AbortController`.
- **Tipizētu kļūdu klasifikāciju** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Saprotamu norādi “nevar sasniegt Obsidian”**, kas izceļ bieži sastopamo porta kļūdu
  (HTTP portā `27123`, **nevis** MCP galapunktā portā `27124`) un Tailscale formātu.
- Krātuvei relatīvu **ceļu kodēšanu**, lai piezīmju ceļus ar atstarpēm/slīpsvītrām varētu droši izmantot.

## Iestatīšana

Obsidian pilnvarai vai bāzes URL **nav vides mainīgā** — abi tiek
glabāti SQLite tabulā `key_value` (nosaukumtelpā `obsidian`), izmantojot
`src/lib/db/obsidian.ts`. Pilnvara ir **šifrēta glabāšanas laikā** (AES-256-GCM ar
atpakaļsaderības atkāpšanās mehānismu nešifrētam tekstam). Konfigurējiet to galapunkta
informācijas paneļa cilnē **Konteksta avoti** (`ObsidianSourceCard`) vai izmantojot
iestatījumu REST API.

> [!IMPORTANT]
> Spraudnim **Obsidian Local REST API** jābūt instalētam un palaistam. Tā REST
> saskarne klausās adresē **HTTP `127.0.0.1:27123`** (noklusējuma bāzes URL). Ports `27124`
> ir _atsevišķs_ MCP/HTTPS galapunkts, un iestatījumu maršruts to nepārprotami noraida.
> Veidojot savienojumu no citas ierīces, izmantojiet `http://<tailscale-ip>:27123`.

### Konfigurācijas atslēgas (SQLite `key_value`, nosaukumtelpa `obsidian`)

| Atslēga           | Nolūks                                                    | Šifrēts |
| ----------------- | --------------------------------------------------------- | ------- |
| `api_key`         | Local REST API nesējpilnvara                              | jā      |
| `base_url`        | REST bāzes URL (noklusējums `http://127.0.0.1:27123`)     | nē      |
| `vault_path`      | Absolūtais ceļš uz krātuves direktoriju (sinhronizācijai) | nē      |
| `webdav_username` | Ģenerētais WebDAV lietotājvārds (krātuves sinhronizācija) | nē      |
| `webdav_password` | Ģenerētā WebDAV parole (krātuves sinhronizācija)          | jā      |
| `webdav_enabled`  | Vai WebDAV krātuves sinhronizācija ir iespējota           | nē      |

### Konfigurēšana, izmantojot REST

```bash
# Saglabāt un validēt Local REST API pilnvaru (POST veic validāciju ar statusa pārbaudi)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Pārbaudīt savienojuma statusu (atgriež connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Atvienot (notīra saglabāto pilnvaru)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Visām metodēm ir nepieciešama informācijas paneļa autentifikācija. `POST` noraida jebkuru
URL ar portu `27124` un pirms saglabāšanas validē pilnvaru, izsaucot Local REST API
statusa galapunktu.

### WebDAV krātuves sinhronizācija

`src/app/api/settings/obsidian/webdav/route.ts` pārvalda izvēles WebDAV nodrošinātu
krātuves sinhronizāciju (ko darbina `src/lib/obsidianSync.ts`). Tās iespējošana norāda
OmniRoute lokālas krātuves direktoriju un izveido nejaušu WebDAV lietotājvārda/paroles
pāri:

```bash
# Iespējot WebDAV sinhronizāciju krātuves direktorijam (izveido lietotājvārdu/paroli)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Iegūt WebDAV sinhronizācijas statusu (akreditācijas dati tiek atgriezti tikai tad, kad tā ir iespējota)
curl http://localhost:20128/api/settings/obsidian/webdav

# Atspējot WebDAV sinhronizāciju (notīra akreditācijas datus un pārvaldīto .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Katras API atslēgas konteksta avots (neobligāts)

Obsidian konfigurāciju var ierobežot **katrai API atslēgai atsevišķi**, izmantojot tabulu
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Ja MCP izsaukumā ir
autentificēts API atslēgas ID, `getObsidianConfigForApiKey()` dod priekšroku šīs atslēgas
pilnvarai/bāzes URL/krātuves ceļam (`source: "api_key"`), bet pretējā gadījumā izmanto
globālo konfigurāciju (`source: "global"`).

## MCP rīki (22)

Definēti failā `open-sse/mcp-server/tools/obsidianTools.ts`. Pilnvara/pamata URL tiek noteikti
katram izsaukumam (vispirms katrai API atslēgai, pēc tam globāli). Rīkiem, kas piekļūst OmniRoute **sinhronizācijas serverim**
(četriem `obsidian_sync_*` rīkiem), papildus ir nepieciešama OmniRoute iestatījumos konfigurētā
sinhronizācijas autentifikācijas pilnvara.

### Lasīšanas rīki (`read:obsidian`)

| Rīks                         | Apraksts                                                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Pārbaudīt, vai lokālā REST API ir sasniedzama un autentificēta.                                                          |
| `obsidian_search_simple`     | Pilnteksta meklēšana piezīmju saturā; atgriež fragmentus ar failu ceļiem.                                                |
| `obsidian_search_structured` | Meklēšana, izmantojot JSON Logic izteiksmi (and/or/regex/path filtrus).                                                  |
| `obsidian_read_note`         | Lasīt piezīmi pēc ceļa attiecībā pret glabātuvi; pēc izvēles — konkrētu virsrakstu/bloku/priekšmetadatus.                |
| `obsidian_list_vault`        | Uzskaitīt glabātuvē esošos failus un direktorijus (ierakstu koku).                                                       |
| `obsidian_get_document_map`  | Iegūt piezīmes virsrakstu struktūru kā virsrakstu → rindu numuru karti.                                                  |
| `obsidian_get_note_metadata` | Iegūt priekšmetadatus, tagus, saites un rakstzīmju/vārdu skaitu bez pilna satura.                                        |
| `obsidian_get_active_file`   | Iegūt Obsidian pašlaik aktīvā faila ceļu un saturu.                                                                      |
| `obsidian_get_periodic_note` | Iegūt dienas/nedēļas/mēneša periodisko piezīmi konkrētam datumam (ja nav norādīts — šodienai).                           |
| `obsidian_get_tags`          | Uzskaitīt visus glabātuves tagus un to biežumu.                                                                          |
| `obsidian_list_commands`     | Uzskaitīt pieejamos Obsidian komandu ID (izmantošanai ar `obsidian_execute_command`).                                    |
| `obsidian_sync_status`       | OmniRoute sinhronizācijas servera statuss: darbība, glabātuves nosaukums, ports, darbības ilgums, pēdējā sinhronizācija. |
| `obsidian_sync_conflicts`    | Uzskaitīt neatrisinātos sinhronizācijas konfliktus (ceļš, konflikta ceļš, noteikšanas laiks).                            |

### Rakstīšanas rīki (`write:obsidian`)

| Rīks                             | Apraksts                                                                                                     |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `obsidian_write_note`            | Izveidot vai pārrakstīt piezīmi ar norādīto Markdown saturu.                                                 |
| `obsidian_append_note`           | Pievienot saturu piezīmei; pēc izvēles — konkrētam virsrakstam/blokam.                                       |
| `obsidian_patch_note`            | Precīzi pievienot beigās/sākumā vai aizstāt saturu pie virsraksta, bloka vai priekšmetadatu lauka.           |
| `obsidian_delete_note`           | Neatgriezeniski dzēst piezīmi no glabātuves.                                                                 |
| `obsidian_move_note`             | Pārvietot vai pārdēvēt piezīmi glabātuvē.                                                                    |
| `obsidian_execute_command`       | Izpildīt Obsidian komandu pēc tās komandas ID.                                                               |
| `obsidian_open_file`             | Atvērt failu Obsidian (izveido to, ja tas nepastāv).                                                         |
| `obsidian_sync_trigger`          | Aktivizēt tūlītēju divvirzienu darbvirsmas↔mobilās ierīces glabātuves sinhronizāciju.                        |
| `obsidian_sync_resolve_conflict` | Atrisināt sinhronizācijas konfliktu: paturēt `local` (mobilā ierīce), `remote` (darbvirsma) vai `keep-both`. |

> [!NOTE]
> `obsidian_patch_note` mērķi pieņem `targetType` vērtību `heading | block | frontmatter`
> un `operation` vērtību `append | prepend | replace` ar neobligātu
> `createTargetIfMissing`. Četri `obsidian_sync_*` rīki sazinās ar lokālo sinhronizācijas
> serveri (pēc noklusējuma `http://127.0.0.1:27781`), un tiem ir nepieciešama sinhronizācijas pilnvara.

### Tvērumi

Lasīšanas rīkiem ir nepieciešams `read:obsidian`; rakstīšanas rīkiem ir nepieciešams `write:obsidian`. Piemērošana
ir identiska Notion — to apstrādā `withScopeEnforcement()` failā
`open-sse/mcp-server/server.ts`, un tā tiek aktivizēta ar `OMNIROUTE_MCP_ENFORCE_SCOPES=true`; atļautie
tvērumi tiek iegūti no `OMNIROUTE_MCP_SCOPES` vai API atslēgas tvēruma konteksta. Skatiet
[MCP-SERVER.md](./MCP-SERVER.md).

## Galapunkti

| Metode   | Ceļš                            | Mērķis                                                                  |
| -------- | ------------------------------- | ----------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Atgriež `{ connected, hasToken, baseUrl, vaultPath }`.                  |
| `POST`   | `/api/settings/obsidian`        | Saglabā un pārbauda pilnvaru (noraida portu `27124`).                   |
| `DELETE` | `/api/settings/obsidian`        | Atvieno (notīra saglabāto pilnvaru).                                    |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV sinhronizācijas statuss un akreditācijas dati (kamēr iespējota). |
| `POST`   | `/api/settings/obsidian/webdav` | Iespējo WebDAV sinhronizāciju glabātuves direktorijam.                  |
| `DELETE` | `/api/settings/obsidian/webdav` | Atspējo WebDAV sinhronizāciju.                                          |

> Šie ir informācijas paneļa iestatījumu maršruti. Pašai glabātuvei var piekļūt, izmantojot Obsidian
> Local REST API (konfigurēto `base_url`) un iepriekš minētos MCP rīkus — publiska
> Obsidian `/v1` starpniekservera galapunkta nav.

## Lietošanas gadījumi

- **Atbildes, kas balstītas glabātuvē** — `obsidian_search_simple` / `obsidian_search_structured`,
  pēc tam `obsidian_read_note`, lai aģents atbildētu, izmantojot jūsu faktiskās piezīmes.
- **Piezīmju veidošana / dienasgrāmatas rakstīšana** — `obsidian_write_note`, `obsidian_append_note` vai
  precīzais `obsidian_patch_note`, lai glabātuvē ierakstītu aģenta izvadi, kopsavilkumus vai dienas piezīmes
  (`obsidian_get_periodic_note`).
- **Glabātuves navigācija** — `obsidian_list_vault`, `obsidian_get_document_map` un
  `obsidian_get_tags`, lai pirms lasīšanas/rakstīšanas izpētītu struktūru.
- **Obsidian automatizācija** — `obsidian_list_commands` + `obsidian_execute_command`, lai
  aģents varētu darbināt spraudņus/komandas; `obsidian_open_file`, lai lietotāja saskarnē parādītu piezīmi.
- **Mobilā sinhronizācija** — iespējojiet WebDAV sinhronizāciju, pēc tam izmantojiet `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`,
  lai koordinētu sinhronizāciju starp datoru un mobilo ierīci un atrisinātu konfliktus.
