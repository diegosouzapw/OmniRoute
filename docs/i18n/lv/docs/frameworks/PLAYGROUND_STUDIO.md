## Pārskats

Playground Studio pārveido `/dashboard/playground` no vienkārša Monaco redaktora par
pilnvērtīgu testēšanas darbvietu. Tas aizstāj mantoto `page.tsx` ar `PlaygroundStudio`
ietvaru, kas attēlo četras cilnes un koplietojamu konfigurācijas paneli.

```

├──────────────────────────────────────────┬───────────────────────────┤
```

## Cilnes

### Tērzēšanas cilne

Pārveido `ChatPlayground.tsx` par vairāku sarunas kārtu straumēšanas darbstaciju:

- Pilnvērtīga Markdown attēlošana, izmantojot `MarkdownMessage.tsx` (koda bloki, tabulas, saraksti, saites).
- Sistēmas uzvedne tiek iegūta no koplietojamā konfigurācijas paneļa.
- Žetonu skaits un izmaksas katram ziņojumam (uzvednes un pabeigšanas žetoni).
- Iespēja atkārtoti ģenerēt pēdējo atbildi.
- Nosūta pieprasījumus uz `POST /v1/chat/completions`, izmantojot SSE straumēšanu.

### Salīdzināšanas cilne

Galvenā priekšrocība starpniekserverim: vienlaikus izpildīt 1 uzvedni līdz pat **4 modeļos**.

- Līdz 4 kolonnām, un katra neatkarīgi straumē datus no `/v1/chat/completions`.
- Poga `+ Pievienot modeli` (Cmd+K saīsne) kolonnu pievienošanai.
- `Izpildīt visu ▶` vienlaikus palaiž visas straumes, izmantojot `Promise.all` un katrai kolonnai atsevišķu `AbortController`.
- Globālā darbība **Atcelt visu** pārtrauc visas aktīvās straumes.
- Katras kolonnas `ProviderMetrics` reāllaikā rāda TTFT, TPS, žetonus un aptuvenās izmaksas.
- Metrika ir apzīmēta kā **"klienta puses aplēse"** (D12) — mērījums tiek veikts no pirmā SSE fragmenta saņemšanas brīža.

### API cilne

Pieredzējušiem lietotājiem pilnībā saglabā sākotnējo Monaco redaktoru (D14):

- 10 galapunkti: tērzēšanas pabeigšana, pabeigšana, iegultnes, attēli, audio, runa, transkripcijas, moderēšana, pārkārtošana pēc atbilstības un meklēšana.
- Multimodālu failu augšupielāde.
- SSE straumēšana ar izvadi reāllaikā.
- Ietverts kā `ApiTab.tsx` (ielādēts atlikti, `ssr: false`).

### Veidošanas cilne

Rīku/funkciju izsaukšanas un strukturētas izvades lietotāja saskarne:

- `ToolsBuilder.tsx` — iespēja pievienot/rediģēt/noņemt `tools[]`, katram rīkam izmantojot JSON shēmas redaktoru.
  Validē parametrus, izmantojot `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — JSON režīma pārslēgšana un JSON shēmas redaktors.
  Validē atbildi atbilstoši shēmai, izmantojot `StructuredOutputSchema` (Zod).
- Nosūta pieprasījumu uz `/v1/chat/completions` ar `tools[]` un/vai `response_format`.

## Konfigurācijas panelis (koplietots)

`StudioConfigPane.tsx` — vienmēr redzams, sakļaujams.

| Lauks                  | Komponents            | Piezīmes                                                                      |
| ---------------------- | --------------------- | ----------------------------------------------------------------------------- |
| Galapunkts             | `<select>`            | 10 opcijas, kas atbilst `PlaygroundEndpoint`                                  |
| Modelis                | `<input>`             | brīvs teksts, piem., `openai/gpt-4o`                                          |
| Sistēmas uzvedne       | `<textarea>`          | tiek izmantota visās cilnēs                                                   |
| Parametri              | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop        |
| Sākotnējie iestatījumi | `PresetPicker`        | nosauktu konfigurācijas momentuzņēmumu ielāde/saglabāšana (glabājas DB)       |
| Uzlabot uzvedni        | `ImprovePromptButton` | atver kvotas brīdinājuma modālo logu, izsauc `/api/playground/improve-prompt` |

Stāvoklis tiek pārcelts uz `PlaygroundStudio.tsx` un nodots visām cilnēm. Pārslēdzot cilnes,
konfigurācijas stāvoklis tiek saglabāts.

## Koda eksportēšanas modālais logs

`ExportCodeModal.tsx` izmanto `codeExport.ts`, lai no pašreizējā `PlaygroundState` ģenerētu curl / Python / TypeScript fragmentus.
API atslēgas vietturis vienmēr ir `$OMNIROUTE_API_KEY` (D11).

---

## Uzvedņu uzlabotājs

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Modālais logs brīdina, ka darbība „patērēs kvotu”.
2. Pēc apstiprināšanas maršrutam nosūta `{ system, prompt, model, tone }`.
3. Maršruts iekšēji izsauc `/v1/chat/completions` ar `promptImprover.META_SYSTEM_PROMPT`.
4. Atgriež `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. Lietotāja saskarne atjaunina konfigurācijas paneļa sistēmas uzvedni un tērzēšanas cilnes lietotāja uzvedni.

---

## Sākotnējie iestatījumi

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Tiek glabāti SQLite tabulā `playground_presets` (migrācija `084_playground_presets.sql`).
- Katrā sākotnējā iestatījumā tiek glabāti: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: `GET` saraksts, `POST` izveide, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Straumes metrika

`useStreamMetrics.ts` + `streamMetrics.ts` (tīra funkcija):

- `start()` — reģistrē pieprasījuma sākuma laiku.
- `onFirstChunk()` — reģistrē TTFT.
- `onChunk(n)` — uzkrāj pabeigšanas marķieru skaitu.
- `finish(usage?)` — aprēķina galīgo metriku: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Cenas tiek iegūtas no statiskas tabulas failā `src/lib/playground/types.ts` (atzīmētas kā „paredzamās” — D13).

## Aizmugursistēmas maršruti

| Metode   | Ceļš                             | Apstrādātājs                                                                                       |
| -------- | -------------------------------- | -------------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | Veic Zod validāciju ar `ImprovePromptRequestSchema`; izsauc `/v1/chat/completions` ar meta-uzvedni |
| `GET`    | `/api/playground/presets`        | Atgriež `{ presets: PlaygroundPresetListItem[] }`                                                  |
| `POST`   | `/api/playground/presets`        | Izveido sākotnējo iestatījumu; validē `PlaygroundPresetCreateSchema`                               |
| `GET`    | `/api/playground/presets/:id`    | Atgriež vienu sākotnējo iestatījumu vai 404                                                        |

| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                |

Autentifikācija: neobligāta (`REQUIRE_API_KEY`). Kļūdas tiek apstrādātas ar `buildErrorBody()` (stingrais noteikums Nr. 12).

## Problēmu novēršana

| Simptoms                                      | Cēlonis                                      | Risinājums                                                                                                      |
| --------------------------------------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Monaco redaktors netiek attēlots API cilnē    | SSR ielādēja Monaco                          | Pārbaudiet, vai `ApiTab` izmanto `dynamic(..., { ssr: false })`                                                 |
| Salīdzināšanas straumes tiek palaistas secīgi | Nepareizs `Promise.all` lietojums            | Visas straumju palaišanas jāizsauc vienā `Promise.all` izsaukumā                                                |
| Metrikās TTFT tiek rādīts kā `null`           | Nav piesaistīts pirmā fragmenta apstrādātājs | Pārbaudiet, vai SSE lasītāja ciklā tiek izsaukts `useStreamMetrics.onFirstChunk()`                              |
| Priekšiestatījums netiek saglabāts            | Nav izpildīta DB migrācija                   | Palaidiet `npm run db:migrate` vai restartējiet serveri (migrācija tiek automātiski izpildīta palaišanas laikā) |
| Uzvednes uzlabošana atgriež 502               | Konfigurācijā nav iestatīts modelis          | Pirms uzlabošanas lietotājam konfigurācijas rūtī jāievada modeļa nosaukums                                      |
| Eksportētajā kodā redzams `MISSING_API_KEY`   | Nav ievietots vietturis                      | `codeExport.ts` vienmēr izmanto `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"`                                    |
