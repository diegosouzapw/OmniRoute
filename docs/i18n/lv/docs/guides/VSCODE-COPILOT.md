**OmniCopilot** pievieno visus OmniRoute apkalpotos modeļus _iebūvētajai_ GitHub Copilot Chat
modeļu izvēlnei. Nekādas otras sānjoslas vai atsevišķas tērzēšanas saskarnes — Copilot aģenta režīms, rīku izsaukšana,
MCP serveri un pielāgotās instrukcijas turpina darboties, tikai izmantojot jūsu izvēlēto modeli.

> **Copilot abonements nav nepieciešams.** Kopš VS Code 1.122 valodas modeļu nodrošinātājs darbojas
> bez pierakstīšanās GitHub kontā un bez jebkāda Copilot plāna. Iekļautā koda pabeigšana un
> uz ieguldījumiem balstītās funkcijas neietilpst nodrošinātāja API un joprojām pieprasa Copilot.

## Iestatīšana

1. **Palaidiet OmniRoute** — `npm install -g omniroute && omniroute` (vadības panelis pieejams adresē `http://localhost:20128`).
2. **Instalējiet paplašinājumu** — paplašinājumu skatā meklējiet „OmniRoute”.
3. **Izvēlieties modeli** — Copilot Chat → modeļu izvēlne → **Manage Models…** → **OmniRoute**, pēc tam atzīmējiet
   vajadzīgos modeļus.

Ja OmniRoute darbojas noklusējuma portā, nekas nav jākonfigurē. Attālai instancei atveriet
**OmniRoute ikonu darbību joslā** (vai palaidiet `OmniRoute: Manage Connection`) un iestatiet:

- **Servera URL** — servera saknes adrese, piemēram, `http://192.168.0.15:20128`. Sufiksu `/v1`
  pievieno paplašinājums; neiekļaujiet to.
- **API atslēga** — tikai tad, ja serverī ir iestatīts `REQUIRE_API_KEY`. Tā tiek glabāta operētājsistēmas atslēgu saišķī, izmantojot VS
  Code SecretStorage, un nekad netiek glabāta failā `settings.json`.

## Kas tiks parādīts izvēlnē

Paplašinājums nerāda neapstrādāto `GET /v1/models` atbildi — tas to pielāgo, un parādītais
skaits ir mazāks par kataloga lielumu divu apzinātu iemeslu dēļ.

### Katram modelim tiek pieprasīts viens id

`MODELS_CATALOG_PREFIX_MODE` noklusējuma vērtība ir **`dual`**, kas katru modeli publicē divreiz — vienreiz
ar īso aizstājvārda prefiksu un vienreiz ar kanonisko nodrošinātāja prefiksu —, lai vecāku klientu
konfigurācijas turpinātu atpazīt abas formas:

```
cc/claude-sonnet-4-6        ← aizstājvārda prefikss
claude/claude-sonnet-4-6    ← kanoniskais prefikss, tas pats modelis
```

Paplašinājums pieprasa **`GET /v1/models?prefix=alias`**, tāpēc katram modelim tiek saņemts viens id,
nemainot servera mēroga iestatījumu citiem klientiem. Atsauces instancē tas samazināja
**2345 ierakstus līdz 1396 — 949 dublikāti, nezaudējot nevienu modeli.**

Ja vēlaties to novērst servera mērogā _visiem_ klientiem, vadības panelī iestatiet
`MODELS_CATALOG_PREFIX_MODE` funkcijas karoga vērtību uz `alias`. Informāciju par
vaicājuma parametru un katra režīma tabulu skatiet sadaļā
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix).

### Tiek paslēpti modeļi, kuri nevar tērzēt

Katalogā ir uzskaitīti arī attēlu, video, audio, pārkārtošanas, ieguldījumu un moderēšanas modeļi. Tērzēšanas
pieprasījumā tie tik un tā tiek noraidīti:

```
HTTP 400 — Model '<id>' is an image-generation model and cannot be used on
/v1/chat/completions. Use POST /v1/images/generations instead.
```

tāpēc tie pēc lauka `type` tiek filtrēti, pirms nonāk izvēlnē. **Responses API
modeļi tiek saglabāti** — katrs Codex / GPT-5.x ieraksts publicē `supported_endpoints: ["responses"]`,
un OmniRoute tos pārveido izmantošanai ar `/v1/chat/completions`, tāpēc tie ir pilnībā izmantojami.

### Nodrošinātāji, kurus nekad neesat konfigurējis

Katalogā ir uzskaitīti modeļi no nodrošinātājiem ar **aktīvu savienojumu**, kā arī no visiem **noAuth**
nodrošinātājiem — tiem, kuriem nav vajadzīga atslēga un kuri veido lielu daļu bezmaksas līmeņa. Tas ir apzināti. Lai
tos paslēptu, pievienojiet tos vadības paneļa iestatījumu sarakstam `blockedProviders`; paplašinājumā
nekas nav jāmaina.

## Informācijas panelis VS Code cilnē

`omnicopilot.dashboardOpen: "editor"` atveido OmniRoute informācijas paneli redaktora cilnē, izmantojot
Simple Browser, nevis ārēju pārlūkprogrammu. Iegulšana serverī ir **jāiespējo atsevišķi**, izmantojot
`DASHBOARD_ALLOW_EMBED=vscode`, kas nodrošina HTML lapas ar
`frame-ancestors 'self' vscode-webview:`, nevis noklusējuma `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. API saskarne (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) jebkurā
gadījumā saglabā stingrās galvenes.

> ⚠️ **Tas ir būvēšanas laika, nevis izpildlaika karogs.** Next.js kompilē `headers()` maršrutu
> manifestā, tāpēc `next.config.mjs` nolasa mainīgo pakotnes būvēšanas laikā
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Tā eksportēšana pirms jau uzbūvēta servera palaišanas neko nemaina — galvenes jau ir iekļautas būvējumā.

```bash
# mainīgajam jābūt norādītam BŪVĒŠANAS komandā
DASHBOARD_ALLOW_EMBED=vscode npm run build        # vai npm run build:release
npm start
```

| Instalēšanas veids         | Vai varat iespējot iegulšanu?                                                                                                                              |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No pirmkoda                | ✅ iestatiet mainīgo būvēšanas komandā, kā parādīts iepriekš                                                                                               |
| `npm install -g omniroute` | ❌ publicētajā pakotnē ir iepriekš uzbūvēta pakotne — tā vietā būvējiet no pirmkoda                                                                        |
| Docker attēls              | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — Docker Hub pieejamajā iepriekš uzbūvētajā attēlā iegulšana nav iespējota |

Bez būvējuma, kurā iespējota iegulšana, lapa atsakās tikt parādīta rāmī; paplašinājums to konstatē pēc
atbildes galvenēm un pārslēdzas uz ārējo pārlūkprogrammu — nekas netiek sabojāts, un par to vienreiz tiek paziņots.
Skatiet [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) un problēmu
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Citu rīku konfigurēšana no VS Code

**`OmniRoute: Configure Coding CLI`** izmanto `omniroute` CLI, lai izveidotu lietošanai gatavus profilus
Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo un Roo — tās pašas konfigurācijas, kas aprakstītas
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). API atslēga CLI tiek nodota, izmantojot
vides mainīgo `OMNIROUTE_API_KEY`, un nekad netiek norādīta komandrindā.

## Problēmu novēršana

| Pazīme                                                                            | Cēlonis/risinājums                                                                                                                                                                                                                                                                         |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Atlasītājā nav OmniRoute modeļu                                                   | Serveris nav sasniedzams. Statusa joslas punkts kļūst pelēks; palaidiet `OmniRoute: Check Connection`. Atklāšana pēc nolūka notiek bez paziņojumiem un nepievieno nevienu modeli, nevis parāda uzvedni.                                                                                    |
| Katrs modelis tiek parādīts divreiz                                               | Jūs izmantojat OmniCopilot versiju, kas vecāka par 1.0.1 — atjauniniet to. Tagad paplašinājums pieprasa `?prefix=alias`.                                                                                                                                                                   |
| Iepriekš sarakstā redzamais attēlu/audio modelis ir pazudis                       | Tas ir apzināti kopš versijas 1.0.1 — tas nekad nevarēja atbildēt uz tērzēšanas pieprasījumu.                                                                                                                                                                                              |
| Darbību joslā nav paneļa                                                          | VS Code pārvieto papildu skatu konteinerus uz **"…"** pārpildes izvēlni darbību joslas apakšdaļā, un ar labo klikšķi paslēpts konteiners paliek paslēpts. Ar peles labo pogu noklikšķiniet uz darbību joslas → atzīmējiet **OmniRoute** vai atveriet to ar `OmniRoute: Manage Connection`. |
| Informācijas panelis tiek atvērts pārlūkprogrammā, neraugoties uz `editor` režīmu | Serveris netika **uzbūvēts** ar `DASHBOARD_ALLOW_EMBED=vscode` (skatiet iepriekš) — tā iestatīšana palaišanas laikā iepriekš uzbūvētā instalācijā neko nemaina. Pārslēgšanās ir apzināta.                                                                                                  |
| Pēc pakalpojumu sniedzēju maiņas modeļu saraksts ir novecojis                     | `OmniRoute: Refresh Models` vai ↻ saite panelī.                                                                                                                                                                                                                                            |
