## 1. Antigravity un Antigravity CLI (agy) salīdzinājums

Abi nodrošinātāji izmanto **vienu un to pašu Google aizmugursistēmu** — identisku OAuth klientu, marķieru atsvaidzināšanu, galapunktus un Google kontus. Atšķiras pieejamie modeļi.

> Google oficiālo salīdzinājumu skatiet [Antigravity CLI paziņojumā](https://antigravity.google/blog/introducing-google-antigravity-cli).

| Aspekts                   | `antigravity` (IDE)                              | `agy` (CLI)                                                        |
| ------------------------- | ------------------------------------------------ | ------------------------------------------------------------------ |
| **Google produkts**       | Antigravity 2.0 / Antigravity IDE                | Antigravity CLI                                                    |
| **Aizmugursistēma**       | Tā pati Google Cloud Code API                    | Tā pati Google Cloud Code API                                      |
| **OAuth / marķieris**     | Tas pats klients, tā pati atsvaidzināšana        | Tas pats klients, tā pati atsvaidzināšana                          |
| **Modeļu katalogs**       | Statisks, atlasīts saraksts (iekodēts OmniRoute) | Dinamiski pārbaudīts no Google, izmantojot `:fetchAvailableModels` |
| **Claude modeļi**         | Sonnet 4.6, Opus 4.6 (katram 4 varianti)         | Sonnet 4.6, Opus 4.6 (katram 4 varianti)                           |
| **Gemini nosaukumi**      | Vienkāršoti apzīmējumi (zems/vidējs/augsts)      | Sākotnējie ID (extra-low/low/agent)                                |
| **Papildu modeļi**        | `gpt-oss-120b-medium`                            | Var ietvert papildu Google modeļus                                 |
| **Noklusējuma lietojums** | IDE integrācija (VS Code, JetBrains)             | CLI / API piekļuve                                                 |
| **Kvota**                 | Koplietota ar agy (tas pats Google konts)        | Koplietota ar antigravity (tas pats Google konts)                  |

**Pieejamie modeļi (eksperimentāli pārbaudīti 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (dažādi domāšanas līmeņi)
- Claude: Sonnet 4.6, Opus 4.6 (katram default/low/medium/high varianti)
- Citi: GPT-OSS 120B Medium
- **Claude Sonnet 5 NAV pieejams** — tiek atbalstīti tikai 4.6 varianti

**Kāpēc modeļu katalogi atšķiras**: Google CLI ir „optimizēts ātrumam un zemam resursu patēriņam” un „kopīgi optimizēts darbam ar Gemini modeļiem” (saskaņā ar Google oficiālo emuāru). Tīmekļa/IDE produkts ir „optimizēts visaptverošai funkcionalitātei”. CLI izmanto `:fetchAvailableModels`, lai dinamiski atrastu modeļus, savukārt IDE izmanto statisku, atlasītu sarakstu.

**Praksē**: Gemini modeļiem izmantojiet prefiksu `agy/` (piemēram, `agy/gemini-3.7-flash-high`). Statiskajam, atlasītajam sarakstam izmantojiet `antigravity/`. Abi izmanto vienu un to pašu Google aizmugursistēmu, taču piedāvā atšķirīgus modeļu nosaukumus. Kvota ir koplietota — jebkura nodrošinātāja izmantošana tiek ieskaitīta tā paša Google konta limitos.

## 2. Google One AI Pro: kvotu sistēma

> Oficiālo informāciju par kvotām skatiet [Antigravity dokumentācijā: plāni](https://antigravity.google/docs/plans), savukārt jaunākos cenu atjauninājumus — sadaļā [Izmaiņas Antigravity plānos](https://antigravity.google/blog/changes-to-antigravity-plans).

Google Antigravity izmanto **divu līmeņu kvotu**, kuras pamatā ir „paveiktais darbs” (skaitļošanas slodze), nevis ziņojumu skaits.

### Divi līmeņi

| Līmenis                | Kas tas ir                                  | Atjaunošanas cikls                                                                                               |
| ---------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **5 stundu posms**     | Tūlītēji pieejamais „paveiktā darba” apjoms | Tiek atiestatīts 5 stundas pēc pirmā pieprasījuma sesijā                                                         |
| **7 dienu pamatkvota** | Nedēļas stingrais ierobežojums              | Ja tas tiek sasniegts, 5 stundu atjaunošana tiek ignorēta; piekļuve tiek bloķēta līdz nākamajam 7 dienu periodam |

**Kā tiek aprēķināts „paveiktais darbs”**: uzdevumi, kas intensīvi izmanto aģentus (piemēram, „Pārstrukturē visu šo repozitoriju”), iztērē kvotu daudz ātrāk nekā vienkārši uzdevumi (piemēram, „Izlabo šo funkciju”). Nav reāllaika informācijas paneļa, kas rādītu patēriņu.

### Plānu līmeņi

| Plāns        | Cena         | Kvota                                             | Nedēļas ierobežojums                                          |
| ------------ | ------------ | ------------------------------------------------- | ------------------------------------------------------------- |
| Free         | $0           | Ievērojama kvota, kas tiek atjaunota katru nedēļu | Jā                                                            |
| AI Pro       | $19.99/mēn.  | Liela kvota, slīdoša atjaunošana ik pēc 5 stundām | Jā (ja sasniegts, tam ir prioritāte pār 5 stundu atjaunošanu) |
| AI Ultra 5x  | $99.99/mēn.  | 5x Pro kvota                                      | Nav nedēļas ierobežojuma                                      |
| AI Ultra 20x | $199.99/mēn. | 20x Pro kvota                                     | Nav nedēļas ierobežojuma                                      |

### Gemini un modeļi, kas nav Gemini

- **Gemini modeļi** (Flash + Pro): tiem ir viens kopīgs ātruma ierobežojums, kas tiek patērēts atbilstoši API cenām. Ja Flash ir 8x lētāks nekā Pro, varat izmantot 8x vairāk Flash tokenu.
- **Modeļi, kas nav Gemini** (Claude, GPT-OSS): tiem ir **atsevišķi** ātruma ierobežojumi. Tie var palikt pieejami pat tad, ja Gemini piekļuve ir bloķēta.

### AI kredīti (pārtēriņš)

> Informāciju par kredītu darbību skatiet sadaļā [Google One AI kredīti](https://support.google.com/googleone/answer/14534406).

Kad pamatkvota ir iztērēta:

- **Nekad**: gaidīt, līdz kvota tiek atjaunota; tiek parādīts „Sasniegta modeļa pamatkvota”
- **Vienmēr**: automātiski izmantot AI kredītus; pēc pamatkvotas atjaunošanas sistēma pārslēdzas atpakaļ uz to

Kredīti tiek iegādāti atsevišķi un ieturēti atbilstoši standarta API cenām.

### Būtiska informācija

- Kvota tiek **koplietota konta līmenī** — viens un tas pats Google konts Antigravity IDE, CLI un OmniRoute vidē izmanto vienu kopīgu kvotu
- Katram Google kontam ir sava neatkarīga kvota — vairāki konti nozīmē vairākas kvotas
- AI Pro lietotāji ir ziņojuši par **7 dienu bloķēšanu**, nevis atiestatīšanu pēc 5 stundām, ja ir sasniegta nedēļas pamatkvota (Google ir apstiprinājis, ka liela pieprasījuma gadījumā tā darbojas pēc ieceres)

**Kad jūsu konta kvota ir iztērēta**: OmniRoute automātiski atkārto pieprasījumu, izmantojot nākamo pieejamo kontu kombinētajā maršrutā. Manuāla iejaukšanās nav nepieciešama.

## 3. Kā iegūt projectId

Katram antigravity/agy savienojumam ir nepieciešams Google Cloud Code `projectId`. Bez tā galapunkts `/v1internal:models` atgriež 404.

### A metode: automātiski (ieteicams)

OmniRoute to veic automātiski. Kad pievienojat jaunu Google kontu, izmantojot informācijas paneļa OAuth:

1. OmniRoute atjaunina tokenu
2. Izsauc `loadCodeAssist`, lai atrastu projectId
3. Ja projekts nepastāv, izsauc `onboardUser`, lai to izveidotu
4. Atkārtoti izsauc `loadCodeAssist`, lai iegūtu jaunizveidoto projectId
5. Saglabā to datubāzē

**Tas darbojas lielākajai daļai kontu** — manuālas darbības nav nepieciešamas.

### B metode: manuāli, izmantojot agy CLI

Ja automātiskā atrašana neizdodas (informāciju par gadījumiem, kad tas notiek, skatiet 5. sadaļā):

```bash
# Instalējiet agy CLI (ja tas vēl nav instalēts)
npm install -g @anthropic-ai/agy

# Piesakieties ar savu Google kontu
agy login

# Atlasiet kontu, kuram jāveic sākotnējā iestatīšana
# Tas aktivizē Cloud Code reģistrāciju un piešķir projectId
```

Kad `agy login` ir veiksmīgi pabeigts, atjauniniet tokenu OmniRoute informācijas panelī. projectId tiks atrasts automātiski.

### Kā pārbaudīt

Pārbaudiet datubāzi:

```bash
# OmniRoute konteinera iekšienē
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Vai pārbaudiet žurnālus:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuth novirzīšanas URI

### Problēma

Google OAuth pieprasa derīgu novirzīšanas URI. OmniRoute pēc noklusējuma izmanto `http://127.0.0.1:20128/callback` (atgriezeniskās cilpas adresi). Tas darbojas lokālām būvēm, bet **nedarbojas attālinātās izvietošanās vidēs** (piemēram, serverī, kuram piekļūst, izmantojot LAN IP adresi).

Google noraida novirzīšanas URI, kas:

- Izmanto IP adreses (jāizmanto domēns, kas beidzas ar `.com`, `.org` u. c.)
- Neatbilst OAuth klienta konfigurācijā reģistrētajiem novirzīšanas URI

### Risinājums

**A variants: izmantojiet iebūvēto OAuth plūsmu (noklusējums)**

- Darbojas, ja piekļūstat OmniRoute no `localhost` vai `127.0.0.1`
- Konfigurēšana nav nepieciešama

**B variants: pielāgoti OAuth akreditācijas dati**

- Savā vidē iestatiet `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web`
- Norādiet savus Google OAuth akreditācijas datus:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Google Cloud Console reģistrējiet `https://your-domain.com/callback` kā autorizētu novirzīšanas URI

**C variants: sākotnējai pieteikšanai izmantojiet agy CLI**

- Iekārtā, kas piekļūs OmniRoute, palaidiet `agy login`
- OAuth plūsma tiek pabeigta lokāli, un pilnvaras tiek saglabātas
- Importējiet savienojumu OmniRoute, izmantojot Dashboard

### Ierobežojumi

- Pielāgotiem OAuth akreditācijas datiem ir nepieciešams domēna nosaukums (Google nepieņem IP adreses kā novirzīšanas URI)
- Ja jums nav domēna, izmantojiet A vai C variantu

## 5. Problēmu novēršana: ja automātiskā iestatīšana neizdodas

OmniRoute vairumam kontu automātiski veic projectId noteikšanu un sākotnējo iestatīšanu. Ja tas neizdodas, pamatcēlonis parasti ir kāds no tālāk minētajiem:

### Konta reģions ir bloķēts

**Simptoms**: `agy login` atgriež ziņojumu „Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location.”

**Pamatcēlonis**: Google kontiem ir aizmugursistēmas lauks „Country Association”, kas tiek iestatīts reģistrācijas laikā. agy CLI un Cloud Code API šo lauku pārbauda stingri — atšķirībā no Gemini tīmekļa versijas, kas pārbauda tikai jūsu pašreizējo IP adresi.

> Lai pārbaudītu vai mainītu ar kontu saistīto reģionu, apmeklējiet [Google valsts piesaistes veidlapu](https://policies.google.com/country-association-form).

**Kāpēc Gemini tīmekļa versija darbojas, bet agy nedarbojas**:

- Gemini tīmekļa versija / Google One: pārbauda tikai pašreizējo IP adresi (starpniekserveris ļauj pārbaudi izturēt)
- agy CLI / Cloud Code API: nolasa aizmugursistēmas lauku „Country Association” (starpniekserveris nepalīdz)

**Risinājums**:

1. Izmantojot ASV IP adresi, apmeklējiet [Google valsts piesaistes veidlapu](https://policies.google.com/country-association-form)
2. Iesniedziet reģiona maiņas pieprasījumu (atlasiet „I live in a different country”)
3. Gaidiet 1–24 stundas, līdz Google apstrādās pieprasījumu un nosūtīs e-pasta paziņojumu
4. Pēc tam komandai `agy login` vajadzētu darboties

### Kontam nav Cloud Code projekta

**Simptoms**: žurnālos tiek rādīts `loadCodeAssist returned no project id` un `onboardUser failed (400)`.

**Pamatcēlonis**: konts nekad nav reģistrēts pakalpojumā Google Cloud Code, un automātiskā sākotnējā iestatīšana neizdevās.

**Risinājums**: manuāli palaidiet `agy login`, lai aktivizētu Cloud Code reģistrāciju, un pēc tam atsvaidziniet pilnvaru OmniRoute Dashboard.

### Pilnvara ir beigusies vai atsaukta

**Simptoms**: žurnālos ir 401 kļūdas vai ziņojumi „Token has expired”.

**Risinājums**: atsvaidziniet pilnvaru sadaļā Dashboard → Providers → agy → noklikšķiniet uz atsvaidzināšanas ikonas. Ja ir atsaukta pati atsvaidzināšanas pilnvara, jums būs atkārtoti jāautentificējas, izmantojot OAuth.
