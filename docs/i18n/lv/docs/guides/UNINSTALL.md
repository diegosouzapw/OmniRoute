## Ātrā atinstalēšana (v3.6.2+)

OmniRoute nodrošina divus iebūvētus skriptus pilnīgai noņemšanai:

### Datu saglabāšana

```bash
npm run uninstall
```

Tādējādi tiek noņemta OmniRoute lietotne, bet **tiek saglabāta** datubāze, konfigurācijas, API atslēgas un pakalpojumu sniedzēju iestatījumi mapē `~/.omniroute/`. Izmantojiet šo opciju, ja plānojat lietotni instalēt atkārtoti un vēlaties saglabāt savu konfigurāciju.

### Pilnīga noņemšana

```bash
npm run uninstall:full
```

Tādējādi tiek noņemta lietotne un **neatgriezeniski dzēsti** visi dati:

- Datubāze (`storage.sqlite`)
- Pakalpojumu sniedzēju konfigurācijas un API atslēgas
- Dublējumu faili
- Žurnālfaili
- Visi faili direktorijā `~/.omniroute/`

> ⚠️ **Brīdinājums:** `npm run uninstall:full` darbību nav iespējams atsaukt. Visi jūsu pakalpojumu sniedzēju savienojumi, kombinācijas, API atslēgas un lietojuma vēsture tiks neatgriezeniski dzēsti.

## Manuāla noņemšana

### Globālā instalēšana ar NPM

```bash
# Noņemt globālo pakotni
npm uninstall -g omniroute

# (Pēc izvēles) Noņemt datu mapi
rm -rf ~/.omniroute
```

### Globālā instalēšana ar pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Apturēt un noņemt konteineru
docker stop omniroute
docker rm omniroute

# Noņemt tilpumu (tiks dzēsti visi dati)
docker volume rm omniroute-data

# (Pēc izvēles) Noņemt attēlu
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Apturēt un noņemt konteinerus
docker compose down

# Turklāt noņemt tilpumus (tiks dzēsti visi dati)
docker compose down -v
```

### Electron darbvirsmas lietotne

**Windows:**

- Atvērt `Iestatījumi → Lietojumprogrammas → OmniRoute → Deinstalēt`
- Vai palaist NSIS deinstalatoru no instalācijas mapes

**macOS:**

- Novietojiet `OmniRoute.app` no `/Applications` mapes uz Kubelu
- Noņemt datus: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Noņemt AppImage failu
- Noņemt datus: `rm -rf ~/.omniroute`

### Instalēšana no pirmavota (git clone)

```bash
# Noņemt klonēto mapi
rm -rf /path/to/omniroute

# (Pēc izvēles) Noņemt datu mapi
rm -rf ~/.omniroute
```

## Datu mapes

Pēc noklusējuma OmniRoute saglabā datus šādās vietās:

| Platforma      | Noklusējuma ceļš                  | Aizstāšana                        |
| -------------- | --------------------------------- | --------------------------------- |
| Linux          | `~/.omniroute/`                   | `DATA_DIR` vides mainīgais        |
| macOS          | `~/.omniroute/`                   | `DATA_DIR` vides mainīgais        |
| Windows        | `%APPDATA%/omniroute/`            | `DATA_DIR` vides mainīgais        |
| Docker         | `/app/data/` (pievienots tilpums) | `DATA_DIR` vides mainīgais        |
| XDG-atbilstoša | `$XDG_CONFIG_HOME/omniroute/`     | `XDG_CONFIG_HOME` vides mainīgais |

### Faili datu mapē

| Fails/Mapes          | Apraksts                                                          |
| -------------------- | ----------------------------------------------------------------- |
| `storage.sqlite`     | Galvenā datubāze (sniedzēji, kombinācijas, iestatījumi, atslēgas) |
| `storage.sqlite-wal` | SQLite rakstīšanas žurnāls (pagaidu)                              |
| `storage.sqlite-shm` | SQLite koplietojamā atmiņa (pagaidu)                              |
| `call_logs/`         | Pieprasījumu slodzes arhīvi                                       |
| `backups/`           | Automātiskas datubāzes dublkopijas                                |
| `log.txt`            | Vecākais pieprasījumu žurnāls (pēc izvēles)                       |

## Pilnīgas noņemšanas pārbaude

Pēc deinstalācijas pārliecinieties, ka nav palikušu failu:

```bash
# Pārbaudīt globālo npm pakotni
npm list -g omniroute 2>/dev/null

# Pārbaudīt datu mapi
ls -la ~/.omniroute/ 2>/dev/null

# Pārbaudīt aktīvos procesus
pgrep -f omniroute
```

Ja kāds processes joprojām darbojas, apturiet to:

```bash
pkill -f omniroute
```
