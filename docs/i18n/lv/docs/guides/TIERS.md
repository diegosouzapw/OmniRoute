OmniRoute organizē 352 atbalstītos pakalpojumu sniedzējus 3 ekonomiskajos līmeņos. Katrs
pieprasījums tiek secīgi novirzīts caur šiem līmeņiem, līdz kāds no tiem tiek sekmīgi izpildīts —
jūs saņemat lētāko derīgo atbildi, nerakstot atkāpšanās loģikas kodu.

## 1. līmenis — Abonementi

**Pakalpojumu sniedzēji, par kuriem jūs jau maksājat.** OmniRoute izmanto visu kvotu, pirms
beidzas tās derīguma termiņš.

| Pakalpojumu sniedzējs             | Kāpēc 1. līmenis                                          |
| --------------------------------- | --------------------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — fiksēta maksa, bieži neizmantots     |
| OpenAI Codex (ChatGPT abonements) | Plus/Team ietver Codex kvotu                              |
| GitHub Copilot                    | Maksa par lietotāju — kvota tiek atiestatīta katru mēnesi |
| Cursor IDE                        | Pro plāna kvota                                           |
| Antigravity / Devin Desktop       | Iebūvētas kvotas                                          |

**Stratēģija**: vispirms novirziet šeit katru pieprasījumu, kas atbilst modeļa
stiprajām pusēm. Kvotu uzskaites rīks pārrauga gaidāmo atiestatīšanu, un `reset-aware`
kombinētā stratēģija atbilstoši nosaka prioritātes. Lai vispirms izmantotu 1. līmeni un pārietu
uz maksas līmeņiem tikai tad, kad kvota ir izsmelta, izmantojiet identifikatoru `auto/thrifty` — vai `auto/subscription`,
lai izmantotu tikai plānā iekļauto kapacitāti un pretējā gadījumā pārtrauktu izpildi. Skatiet
[Maršrutēšanu, vispirms izmantojot abonementus](../routing/SUBSCRIPTION_LADDER.md).

## 2. līmenis — Lēti

**Pakalpojumu sniedzēji ar maksu par marķieriem, kas ir mazāka par $1 par 1M marķieru.** Paredzēti liela apjoma darbiem
vai izmantošanai pēc 1. līmeņa kvotu ierobežojumu sasniegšanas.

| Pakalpojumu sniedzējs         | Cena (ievade/izvade) | Stiprās puses          |
| ----------------------------- | -------------------- | ---------------------- |
| DeepSeek V4 Pro               | $0.27 / $1.10 par 1M | Kods, spriešana        |
| GLM-4.5                       | $0.60 / $2.20 par 1M | Garš konteksts         |
| MiniMax M1                    | $0.20 / $1.10 par 1M | Ātrums                 |
| Qwen Coder                    | $0.30 / $1.20 par 1M | Kods                   |
| OpenRouter (cenas optimizēts) | mainās               | 100+ modeļu, dinamisks |

**Stratēģija**: kombinācija `cost-optimized` izvēlas modeli ar zemāko cenu par marķieri, kas atbilst
uzdevuma spēju filtram (attēlu apstrāde, JSON režīms, rīki, maksimālais konteksts).

## 3. līmenis — Bezmaksas

**Bezmaksas pakalpojumu sniedzēji** — bezmaksas līmeņi, kredītu programmas, OAuth dienas kvotas.

| Pakalpojumu sniedzējs | Bezmaksas kvota/kredīti                                      |
| --------------------- | ------------------------------------------------------------ |
| Kiro AI               | Bezmaksas Claude līmenis (dāsna godīgas lietošanas politika) |
| OpenCode Free         | Nav nepieciešama autentifikācija, augsti ātruma ierobežojumi |
| Qoder                 | Bezmaksas OAuth                                              |
| Google Vertex AI      | $300 kredīti jauniem kontiem                                 |
| Amazon Q              | Bezmaksas līmenis AWS lietotājiem                            |
| Pollinations          | Atvērta publiska API                                         |
| Cloudflare AI         | Workers AI bezmaksas līmenis                                 |

**Stratēģija**: kombinācija `auto` ar budžeta ierobežojumu novirza pieprasījumus šeit, ja 1. un 2. līmenis nav pieejams
vai ja ir iestatīts `useFreeOnly=true`. Bezmaksas pakalpojumu sniedzējiem bieži ir stingrāki
ātruma ierobežojumi — ķēdes pārtraucējs pēc nogaidīšanas perioda atjauno to izmantošanu.

## Līmeņu konfigurēšana

Informācijas panelis → **Līmeņi** → piešķiriet savus pakalpojumu sniedzējus. Noklusējuma iestatījumi (no `tierDefaults.json`) ir
saprātīgi; rediģējiet tos, ja vēlaties piešķirt prioritāti konkrētiem abonementiem vai izslēgt noteiktus pakalpojumu sniedzējus.

Auto-Combo 16 faktoru vērtējumā tiek ņemts vērā arī līmenis. Skatiet
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetrija

Informācijas panelis → **Lietojums** parāda dienā iztērēto marķieru skaitu katrā līmenī. Izmantojiet to, lai:

- Pārliecinātos, ka 1. līmenis tiek pilnībā izmantots (pretējā gadījumā jūs izšķērdējat abonementa vērtību)
- Noteiktu, kuri 2. līmeņa modeļi tiek izvēlēti visbiežāk (apvienojiet līdz 1–2)
- Pārbaudītu, vai 3. līmenis ietaupa naudu testēšanas un izpētes darba slodzēm

## Bieži lietoti modeļi

### Pilnībā bezmaksas darba slodze

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Izteikti dod priekšroku 3. līmenim; 2. līmeni izmanto tikai tad, ja 3. līmenis nav pieejams.

### Vispirms abonements, ar lētu atkāpšanās variantu

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Skaidri norādīts sakārtots saraksts, kas atbilst 1. līmenim → 2. līmenim → 3. līmenim.
