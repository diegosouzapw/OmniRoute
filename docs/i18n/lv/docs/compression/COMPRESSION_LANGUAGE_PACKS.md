Caveman saspiešana papildus iebūvētajiem angļu valodas noteikumiem var ielādēt konkrētām valodām paredzētas noteikumu pakotnes.
Tas nodrošina pamatdzinēja stabilitāti, vienlaikus ļaujot portugāļu, spāņu, vācu, franču, itāļu, japāņu un
nākotnē izveidotām valodu pakotnēm attīstīties neatkarīgi.

## Atrašanās vieta

Valodu pakotnes atrodas šeit:

```txt
open-sse/services/compression/rules/<language>/
```

Pašlaik piegādātās pakotnes (pārbaudītas, salīdzinot ar direktorija `rules/` saturu):

| Valoda                | Direktorijs    | Pieejamās noteikumu kategorijas                     |
| --------------------- | -------------- | --------------------------------------------------- |
| Angļu                 | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spāņu                 | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugāļu (Brazīlija) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonēziešu           | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Itāļu                 | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Vācu                  | `rules/de/`    | `context`, `filler`, `structural`                   |
| Franču                | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japāņu                | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Paritātes piezīme:** `en`, `es`, `pt-BR`, `id` un `it` pakotnēs ir visas 5 kategorijas; `de`, `fr` un `ja` tiek piegādātas ar 3 kategorijām. Ja trūkst `dedup` un `ultra` kategoriju, nemanāmi tiek izmantoti iebūvētie angļu valodas noteikumi. Gaidām ieguldījumus, lai mazākajām pakotnēm pievienotu `dedup.json` un `ultra.json`.
>
> Pakotnes `pt-BR` pamatā ir Lenine Júnior izstrādātais **[Troglodita](https://github.com/leninejunior/troglodita)** — no nulles izveidota saspiešanas sistēma Brazīlijas portugāļu valodas gramatikai (pleonasmu samazināšana, PT-BR liekvārdu noņemšana, tehniskie saīsinājumi Brazīlijas izstrādātāju kopienai).
>
> Kanoniskais kategoriju saraksts un katras kategorijas shēma atrodas failā [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema projekts 2020-12).

## Valodas noteikšana

`languageDetector.ts` izmanto vienkāršas heiristikas, lai pēc uzvednes teksta noteiktu valodu. Konfigurētā
noklusējuma valoda joprojām tiek ievērota, un, ja nepieciešama precīza kontrole, noteikšanu var atspējot
konfigurācijā.

Noteikšanas rezultāts tiek izmantots tikai noteikumu pakotņu izvēlei. Tas nemaina pakalpojumu sniedzēja maršrutēšanu, lokalizācijas
izvēli vai lietotāja saskarnes valodu.

## Konfigurācijas struktūra

Saspiešanas iestatījumos var iekļaut:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` kontrolē informācijas paneļa/priekšskatījuma noklusējuma iestatījumus. `cavemanConfig` ir izpildlaika dzinēja konfigurācija,
kas tiek izmantota, kad Caveman saspiež ziņojuma tekstu.

## Valodas pakotnes pievienošana

1. Izveidojiet `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Izmantojiet Caveman kārtulu formātu no `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Veiciet aizstāšanu piesardzīgi un nemainiet kodu, identifikatorus, URL vai JSON.
4. Pievienojiet vai atjauniniet testus valodas izvēlei un aizstāšanas darbībai.
5. Pievienojiet jaunus informācijas paneļa/i18n apzīmējumus, ja valoda tiek parādīta lietotāja saskarnes atlasītājos.

## API

Pieejamās pakotnes var pieprasīt ar:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Priekšskatījuma galapunkts pieņem valodas konfigurācijas pārrakstīšanas vērtības:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Visas 6 valodu pakotnes versijā v3.8.0 saņēma klauzulu `SHARED_BOUNDARIES`, kas tiek lietota katrā
Caveman intensitātes līmenī (LITE, FULL, ULTRA). Tā norāda dzinējam saglabāt šos šablonus burtiski
neatkarīgi no apkārt esošā liekvārdīgā satura noņemšanas:

| Šablona veids                     | Piemērs                                |
| --------------------------------- | -------------------------------------- |
| Norobežoti koda bloki             | ` ```python\n...\n``` `                |
| Iekļauts kods                     | `` `my_var` ``                         |
| URL                               | `https://example.com/path`             |
| Failu ceļi (absolūti un relatīvi) | `/etc/hosts`, `./src/index.ts`         |
| Kļūdu galvenes                    | `Error:`, `TypeError:`, `SyntaxError:` |
| Steka izsekošanas rindas          | `  at functionName (file.ts:12:3)`     |

Šie šabloni tiek ievietoti `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (iepriekš `[]`). Konstante
atrodas failā `open-sse/services/compression/types.ts`.

### Kāpēc tas ir svarīgi

Bez SHARED_BOUNDARIES agresīvie Caveman režīmi varētu noņemt saturu, kas izskatās pēc atkārtotas
prozas, bet patiesībā ir koda fragments, faila ceļš vai kļūdas steka izsekojums. SHARED_BOUNDARIES darbojas kā
no valodas neatkarīgs drošības tīkls, kas tiek lietots pirms liekvārdīgā satura kārtulu izpildes.

### preservePatterns pielāgošana

Izpildlaikā var pievienot papildu šablonus, izmantojot saspiešanas iestatījumus:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Pielāgotie šabloni papildina (nevis aizstāj) 6 noklusējuma šablonus.

## Ekspluatācijas piezīmes

- Iebūvētās angļu valodas kārtulas paliek kā rezerves variants, ja valodas pakotnes trūkst.
- Nederīgām iebūvētajām JSON pakotnēm validācija neizdodas, lai laidiena resursu kvalitāte nemanāmi nepasliktinātos.
- Kārtulu pakotnes satur tikai datus, un tās nedrīkst importēt kodu vai izpildīt patvaļīgu loģiku.
- Saspiešanas analītikas slānis reģistrē atlasīto režīmu un dzinēju, nevis pilnu uzvednes tekstu.
