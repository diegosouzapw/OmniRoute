Toplam sağlayıcı sayısı: **360**. Kategori dökümünü aşağıda görebilirsiniz.

## Kategoriler

- **Ücretsiz** — API anahtarıyla ücretsiz katman (kontrol paneli üzerinden yapılandırılır)
- **Kimlik doğrulamasız** — hiçbir anahtar veya oturum açma gerektirmeyen herkese açık uç noktalar
- **OAuth** — oturum açma akışı OmniRoute tarafından yönetilir, API anahtarı gerekmez
- **Web çerezi** — sağlayıcının web uygulamasını çerez tabanlı kimlik doğrulamasıyla sarmalar
- **API anahtarı** — API anahtarıyla yapılandırılan ücretli sağlayıcı (ücretsiz krediler sunulabilir)
- **Yerel** — kullanıcının makinesinde çalışır (Ollama, LM Studio, vLLM vb.)
- **Arama** — web arama sağlayıcıları
- **Ses** — yalnızca ses sağlayan sağlayıcılar (TTS/STT)
- **Üst akış proxy'si** — diğer sağlayıcılara proxy görevi gören sağlayıcılar
- **Bulut aracısı** — uzun süre çalışan kodlama aracıları (Codex Cloud, Devin, Jules)
- **Sistem** — OmniRoute'un dahili sağlayıcıları (loopback vb.)

Ek etiketler: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Araç çağırma` (gösterildiği yerlerde): `native` — gerçek işlev çağırma API'si; `emulated` — `tools` dizisi, `webTools.ts` aracılığıyla istem tabanlı olarak taklit edilir (regex ile ayrıştırılan `<tool>{...}</tool>` blokları); `none` — `tools` şu anda herhangi bir uyarı verilmeden yok sayılır. Bkz. #7286.

Her sağlayıcıyı etkinleştirmek, yapılandırmak ve test etmek için `/dashboard/providers` adresindeki kontrol panelini kullanın.
