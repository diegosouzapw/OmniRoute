> **Doğruluk kaynağı:** `src/lib/obsidian/api.ts` (REST + senkronizasyon istemcisi),
> `src/lib/db/obsidian.ts` (token / temel URL / WebDAV kalıcılığı),
> `src/lib/obsidianSync.ts` (WebDAV kasa senkronizasyonu), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP aracı), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (ayar API'leri). Araç kaydı
> ve kapsam bağlantıları `open-sse/mcp-server/server.ts` içinde bulunur.

## Nedir?

OmniRoute, yerleşik MCP sunucusu aracılığıyla ajanların okuyup yazdığı yerel bir Markdown
bilgi tabanı olan **Obsidian** kasasına bir **bağlam kaynağı** olarak bağlanır.
Entegrasyon, masaüstü uygulamasında çalışan **Obsidian Local REST API** topluluk eklentisiyle
iletişim kurar; böylece ajanlar notlarda arama yapabilir, dosyaları okuyabilir/yazabilir/yamalayabilir,
kasayı listeleyebilir, günlük/haftalık periyodik notlarla çalışabilir, etiketleri yönetebilir,
Obsidian komutlarını çalıştırabilir ve (isteğe bağlı olarak) çift yönlü bir masaüstü↔mobil
kasa senkronizasyonunu koordine edebilir.

İstemci (`src/lib/obsidian/api.ts`), Local REST API'yi şu özelliklerle sarmalar:

- Geçici `5xx` hataları için **geri çekilmeli yeniden deneme**, `AbortController` aracılığıyla **30 saniyelik zaman aşımı**.
- **Türü belirlenmiş hata sınıflandırması** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- Yaygın port hatasını (MCP uç noktası olan `27124` **değil**, `27123` üzerinde HTTP)
  ve Tailscale biçimini belirten, kullanıcı dostu bir **"Obsidian'a ulaşılamıyor" ipucu**.
- Boşluk/eğik çizgi içeren not yollarının güvenli olması için kasaya göreli **yol kodlama**.

## Kurulum

Obsidian token'ı veya temel URL'si için **ortam değişkeni yoktur** — her ikisi de
`src/lib/db/obsidian.ts` aracılığıyla SQLite `key_value` tablosunda (`obsidian` ad alanı)
saklanır. Token **bekleme durumunda şifrelenir** (AES-256-GCM; düz metinle geriye dönük
uyumluluk için yedek mekanizmayla). Endpoint panosundaki **Context Sources** sekmesinden
(`ObsidianSourceCard`) veya ayarlar REST API'si üzerinden yapılandırın.

> [!IMPORTANT]
> **Obsidian Local REST API** eklentisi kurulmuş ve çalışıyor olmalıdır. REST
> arayüzü **HTTP `127.0.0.1:27123`** adresini dinler (varsayılan temel URL). `27124`
> portu _ayrı_ bir MCP/HTTPS uç noktasıdır ve ayarlar yönlendirmesi tarafından açıkça reddedilir.
> Başka bir cihazdan bağlanıyorsanız `http://<tailscale-ip>:27123` kullanın.

### Yapılandırma anahtarları (SQLite `key_value`, `obsidian` ad alanı)

| Anahtar           | Amaç                                                    | Şifreli |
| ----------------- | ------------------------------------------------------- | ------- |
| `api_key`         | Local REST API bearer token'ı                           | evet    |
| `base_url`        | REST temel URL'si (varsayılan `http://127.0.0.1:27123`) | hayır   |
| `vault_path`      | Kasa dizininin mutlak yolu (senkronizasyon için)        | hayır   |
| `webdav_username` | Oluşturulan WebDAV kullanıcı adı (kasa senkronizasyonu) | hayır   |
| `webdav_password` | Oluşturulan WebDAV parolası (kasa senkronizasyonu)      | evet    |
| `webdav_enabled`  | WebDAV kasa senkronizasyonunun etkin olup olmadığı      | hayır   |

### REST üzerinden yapılandırma

```bash
# Local REST API token'ını kaydedin + doğrulayın (POST, bir durum kontrolü aracılığıyla doğrular)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Bağlantı durumunu kontrol edin (connected, hasToken, baseUrl, vaultPath döndürür)
curl http://localhost:20128/api/settings/obsidian

# Bağlantıyı kesin (saklanan token'ı temizler)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Tüm yöntemler pano kimlik doğrulaması gerektirir. `POST`, `27124` portundaki tüm URL'leri
reddeder ve kalıcı olarak saklamadan önce Local REST API durum uç noktasını çağırarak token'ı doğrular.

### WebDAV kasa senkronizasyonu

`src/app/api/settings/obsidian/webdav/route.ts`, isteğe bağlı WebDAV destekli bir
kasa senkronizasyonunu yönetir (`src/lib/obsidianSync.ts` tarafından yürütülür).
Bu özelliğin etkinleştirilmesi, OmniRoute'u yerel bir kasa dizinine yönlendirir ve rastgele
bir WebDAV kullanıcı adı/parola çifti oluşturur:

```bash
# Bir kasa dizini için WebDAV senkronizasyonunu etkinleştirin (kullanıcı adı/parola oluşturur)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV senkronizasyon durumunu alın (kimlik bilgileri yalnızca etkinken döndürülür)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV senkronizasyonunu devre dışı bırakın (kimlik bilgilerini + yönetilen .stignore dosyasını temizler)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### API anahtarı başına bağlam kaynağı (isteğe bağlı)

Obsidian yapılandırması, `api_key_context_sources` tablosu
(`src/lib/db/apiKeyContextSources.ts`) aracılığıyla **API anahtarı başına** kapsamlandırılabilir.
Bir MCP çağrısı kimliği doğrulanmış bir API anahtarı kimliği taşıdığında,
`getObsidianConfigForApiKey()` bu anahtarın kendi token/temel URL/kasa yolunu
(`source: "api_key"`) tercih eder; aksi durumda global yapılandırmaya
(`source: "global"`) geri döner.

## MCP araçları (22)

`open-sse/mcp-server/tools/obsidianTools.ts` dosyasında tanımlanmıştır. Token/base-URL her çağrı için çözümlenir (önce API anahtarına özel olan, ardından genel olan). OmniRoute **senkronizasyon sunucusuna** erişen araçlar (dört `obsidian_sync_*` aracı) ayrıca OmniRoute ayarlarında yapılandırılmış senkronizasyon kimlik doğrulama token'ını gerektirir.

### Okuma araçları (`read:obsidian`)

| Araç                         | Açıklama                                                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Local REST API'nin erişilebilir ve kimliği doğrulanmış olup olmadığını kontrol eder.                                 |
| `obsidian_search_simple`     | Not içeriğinde tam metin araması yapar; dosya yollarıyla birlikte metin parçacıkları döndürür.                       |
| `obsidian_search_structured` | Bir JSON Logic ifadesi (and/or/regex/path filtreleri) kullanarak arama yapar.                                        |
| `obsidian_read_note`         | Bir notu kasa köküne göreli yoluyla okur; isteğe bağlı olarak belirli bir başlığı/bloğu/frontmatter alanını okur.    |
| `obsidian_list_vault`        | Kasadaki dosya ve dizinleri listeler (girdi ağacı).                                                                  |
| `obsidian_get_document_map`  | Notun başlık yapısını, başlıklar → satır numaraları eşlemesi olarak alır.                                            |
| `obsidian_get_note_metadata` | Tam içerik olmadan frontmatter, etiketler, bağlantılar ve karakter/kelime sayısını alır.                             |
| `obsidian_get_active_file`   | Obsidian'da o anda etkin olan dosyanın yolunu ve içeriğini alır.                                                     |
| `obsidian_get_periodic_note` | Bir tarih için günlük/haftalık/aylık dönemsel notu alır (belirtilmezse bugün).                                       |
| `obsidian_get_tags`          | Tüm kasa etiketlerini kullanım sıklıklarıyla birlikte listeler.                                                      |
| `obsidian_list_commands`     | Kullanılabilir Obsidian komut kimliklerini listeler (`obsidian_execute_command` ile kullanılır).                     |
| `obsidian_sync_status`       | OmniRoute senkronizasyon sunucusu durumu: çalışıyor olma durumu, kasa adı, port, çalışma süresi, son senkronizasyon. |
| `obsidian_sync_conflicts`    | Çözülmemiş senkronizasyon çakışmalarını listeler (yol, çakışma yolu, algılanma zamanı).                              |

### Yazma araçları (`write:obsidian`)

| Araç                             | Açıklama                                                                                                       |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Belirtilen Markdown içeriğiyle bir not oluşturur veya üzerine yazar.                                           |
| `obsidian_append_note`           | Bir nota içerik ekler; isteğe bağlı olarak belirli bir başlığa/bloğa ekler.                                    |
| `obsidian_patch_note`            | Bir başlıkta, blokta veya frontmatter alanında hassas biçimde sona ekleme/başa ekleme/değiştirme işlemi yapar. |
| `obsidian_delete_note`           | Bir notu kasadan kalıcı olarak siler.                                                                          |
| `obsidian_move_note`             | Bir notu kasa içinde taşır veya yeniden adlandırır.                                                            |
| `obsidian_execute_command`       | Komut kimliğiyle bir Obsidian komutunu yürütür.                                                                |
| `obsidian_open_file`             | Obsidian'da bir dosya açar (mevcut değilse oluşturur).                                                         |
| `obsidian_sync_trigger`          | Anında çift yönlü masaüstü↔mobil kasa senkronizasyonu tetikler.                                                |
| `obsidian_sync_resolve_conflict` | Bir senkronizasyon çakışmasını çözer: `local` (mobil), `remote` (masaüstü) veya `keep-both` seçeneğini korur.  |

> [!NOTE]
> `obsidian_patch_note` hedefleri, `heading | block | frontmatter` biçimindeki `targetType`
> ve `append | prepend | replace` biçimindeki `operation` değerlerini, isteğe bağlı bir
> `createTargetIfMissing` ile kabul eder. Dört `obsidian_sync_*` aracı yerel senkronizasyon
> sunucusuyla (varsayılan olarak `http://127.0.0.1:27781`) iletişim kurar ve senkronizasyon token'ını gerektirir.

### Kapsamlar

Okuma araçları `read:obsidian`; yazma araçları ise `write:obsidian` kapsamını gerektirir. Uygulama
Notion ile aynıdır — `open-sse/mcp-server/server.ts` içindeki `withScopeEnforcement()`
tarafından gerçekleştirilir, `OMNIROUTE_MCP_ENFORCE_SCOPES=true` olduğunda etkinleştirilir ve
izin verilen kapsamlar `OMNIROUTE_MCP_SCOPES` değişkeninden veya API anahtarının kapsam bağlamından alınır. Bkz.
[MCP-SERVER.md](./MCP-SERVER.md).

## Uç Noktalar

| Yöntem   | Yol                             | Amaç                                                         |
| -------- | ------------------------------- | ------------------------------------------------------------ |
| `GET`    | `/api/settings/obsidian`        | `{ connected, hasToken, baseUrl, vaultPath }` döndürür.      |
| `POST`   | `/api/settings/obsidian`        | Tokenı kaydeder ve doğrular (`27124` portunu reddeder).      |
| `DELETE` | `/api/settings/obsidian`        | Bağlantıyı keser (saklanan tokenı temizler).                 |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV senkronizasyon durumu + kimlik bilgileri (etkinken).  |
| `POST`   | `/api/settings/obsidian/webdav` | Bir kasa dizini için WebDAV senkronizasyonunu etkinleştirir. |
| `DELETE` | `/api/settings/obsidian/webdav` | WebDAV senkronizasyonunu devre dışı bırakır.                 |

> Bunlar kontrol paneli ayar rotalarıdır. Kasanın kendisine Obsidian
> Local REST API (yapılandırılmış `base_url`) ve yukarıdaki MCP araçları üzerinden erişilir —
> herkese açık bir `/v1` Obsidian proxy uç noktası yoktur.

## Kullanım alanları

- **Kasayı temel alan yanıtlar** — Bir aracının gerçek notlarınızdan yararlanarak yanıt vermesi için
  `obsidian_search_simple` / `obsidian_search_structured` ve ardından `obsidian_read_note`.
- **Not yazımı / günlük tutma** — Aracı çıktısını, özetleri veya günlük notları
  (`obsidian_get_periodic_note`) kasaya kaydetmek için `obsidian_write_note`, `obsidian_append_note`
  ya da hassas düzenleme sağlayan `obsidian_patch_note`.
- **Kasada gezinme** — Okuma/yazma işleminden önce yapıyı keşfetmek için
  `obsidian_list_vault`, `obsidian_get_document_map` ve `obsidian_get_tags`.
- **Obsidian otomasyonu** — Eklentileri/komutları bir aracı üzerinden yönetmek için
  `obsidian_list_commands` + `obsidian_execute_command`; bir notu kullanıcı arayüzünde görüntülemek
  için `obsidian_open_file`.
- **Mobil senkronizasyon** — WebDAV senkronizasyonunu etkinleştirin, ardından masaüstü↔mobil
  senkronizasyonunu koordine etmek ve çakışmaları çözmek için `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`.
