**Claude Code** CLI'ını (`claude`) OmniRoute'a — yerel veya uzak bir VPS'e —
model bazlı profillerle, Codex kurulumunu yansıtacak şekilde yönlendirin.

---

## Hızlı başlangıç

```bash
# Claude Code'u yerel bir OmniRoute ile başlatır (etkin bağlamı otomatik algılar)
omniroute launch

# Uzak bir OmniRoute ile başlatır (`omniroute connect <host>` sonrasında bu işlem otomatiktir)
omniroute launch --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Model bazlı profiller oluşturur, ardından birini başlatır
omniroute setup-claude            # ~/.claude/profiles/<name>/settings.json dosyasına yazar
omniroute launch --profile glm52  # OmniRoute üzerinden glm/glm-5.2 kullanan Claude Code
```

## Claude Code bir ağ geçidine nasıl bağlanır?

Claude Code, **Anthropic Messages API** ile iletişim kurar ve ortam değişkenleri
aracılığıyla özel bir uç noktaya yönlendirilir (`--base-url` bayrağı yoktur):

| Değişken                                     | Amaç                                                                                                     |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `ANTHROPIC_BASE_URL`                         | Ağ geçidi kök URL'si (Claude Code sonuna `/v1/messages` ekler). **`/v1` son eki olmamalıdır.**           |
| `ANTHROPIC_AUTH_TOKEN`                       | `Authorization: Bearer …` olarak gönderilir — OmniRoute erişim belirtecinizi / API anahtarınızı kullanın |
| `ANTHROPIC_API_KEY`                          | Alternatif: `x-api-key` olarak gönderilir. İkisi de ayarlanmışsa `ANTHROPIC_AUTH_TOKEN` önceliklidir     |
| `ANTHROPIC_MODEL`                            | Belirli bir modeli zorunlu kılar (`/model` seçicisinin varsayılanını geçersiz kılar)                     |
| `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY` | `1` → yerel `/model` seçicisi, `/v1/models` içindeki `claude*`/`anthropic*` modellerini listeler         |
| `CLAUDE_CODE_MAX_OUTPUT_TOKENS`              | Yanıt başına çıktı belirteçlerini sınırlar (ör. `65536`)                                                 |
| `CLAUDE_CODE_AUTO_COMPACT_WINDOW`            | Otomatik sıkıştırma için belirteç eşiği                                                                  |

> Ortam değişkenleri **başlangıçta yalnızca bir kez** okunur — bunları değiştirdikten sonra Claude Code'u yeniden başlatın.

`omniroute launch` bunların tümünü sizin için ayarlar: temel URL'yi ve belirteci
etkin bağlamdan çözümler (böylece `omniroute connect <vps>` ve ardından
`omniroute launch` doğrudan çalışır), sunucunun sistem durumunu denetler ve
`claude` komutunu çalıştırır.

## Keşif takma adları — Claude dışı modelleri `/model` seçicisinde gösterin

Claude Code'un ağ geçidi model keşfi yalnızca kimlikleri `claude` veya
`anthropic` ile başlayan modelleri listeler; bu nedenle
`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` olduğunda yerel `/model` seçicisi
normalde **yalnızca** OmniRoute'un Claude/Anthropic modellerini gösterir —
`kimi/kimi-k2.6` veya `glm/glm-5.2`, sorunsuz yönlendirilse bile hiçbir zaman
görünmez.

OmniRoute, etkinleştirilmiş herhangi bir modeli (ve kombinasyonu), bu filtreden
geçip seçicide görünmesi için bir `claude/…` kimliği altında yansıtabilir:

```
kimi/kimi-k2.6            →  claude/kimi/kimi-k2.6      "Kimi K2.6 (OmniRoute)"
glm/glm-5.2              →  claude/glm/glm-5.2         "GLM 5.2 (OmniRoute)"
<combo "custo-otimizado"> →  claude/combo/custo-otimizado
```

Claude Code'da bunlardan birini seçtiğinizde OmniRoute, yönlendirmeden önce
`claude/` sarmalayıcısını kaldırarak gerçek kimliğe döner — gerçek bir
`claude/<real-claude-model>` kimliğine (asıl Claude OAuth sağlayıcısı) ise her
zaman dokunulmaz.

**Bu özellik varsayılan olarak kapalıdır** ve üç seviyeli bir geçit tarafından
denetlenir (en özel olan önceliklidir); böylece standart bir OmniRoute,
Claude Code kullanmayan istemciler için kataloğunu ikiye katlamaz:

| Seviye    | Konum                                                                                   |
| --------- | --------------------------------------------------------------------------------------- |
| Model     | Sağlayıcı ayrıntı sayfası → model bazlı "Claude Code'da göster" anahtarı                |
| Sağlayıcı | Sağlayıcı ayrıntı sayfası → sağlayıcı düzeyindeki anahtar (tüm modellerini kapsar)      |
| Genel     | Ayarlar → Özellik Bayrakları → `EXPOSE_CC_DISCOVERY_ALIASES` (varsayılan olarak kapalı) |

`EXPOSE_CC_DISCOVERY_ALIASES` ortam değişkeni, genel seviyeyi zorunlu olarak
etkinleştirir ve kontrol panelindeki geçersiz kılma ayarına göre önceliklidir
(Özellik Bayrakları ekranı, bu durumda "ortam değişkeni aracılığıyla etkin"
notunu gösterir). Sağlayıcı ve model bazlı anahtarlar buradan itibaren ayarı
daha da özelleştirir — örneğin genel ayar kapalı + Kimi sağlayıcısı açık
olduğunda yalnızca Kimi'nin modelleri gösterilir.

> ⚠️ **Claude dışı modellerde pencere uyuşmazlığı.** Claude Code, tanımadığı tüm
> kimlikler için 200K bağlam penceresi varsayar (`/v1/models` üzerinden gerçek
> pencereyi okuyamaz). Daha büyük pencereye sahip bir modelde (ör. Kimi K2'nin
> 256K penceresi), otomatik sıkıştırmanın zamanından önce devreye girmemesi için
> `CLAUDE_CODE_AUTO_COMPACT_WINDOW` değerini modelin gerçek penceresinden daha
> düşük bir değere ayarlayın. Yukarıda oluşturulan profiller bunu zaten her
> model için ayrı ayrı yapar.

## Kontrol panelindeki ilk kullanım bloğu

Claude araç kartı (**Kontrol Paneli → CLI Code**), kopyalama düğmesiyle birlikte keşif takma adı bilgi düğmesinin yanında bu örneğe ait tam `settings.json` parçasını görüntüler:

```jsonc
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://<your OmniRoute>:20128",
    "ANTHROPIC_AUTH_TOKEN": "<your OmniRoute API key>",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
  },
}
```

Temel URL, kart tarafından çözümlenen URL'dir (yazdığınız özel geçersiz kılma değeri dahil) ve önceden normalleştirilmiştir — `/v1` son eki veya sonda eğik çizgi içermez. **Anahtar hiçbir zaman görüntülenmez**: blok bir yer tutucuyla sunulur; dolayısıyla ekran görüntüsü veya yapıştırılmış bir kod parçası anahtarı sızdıramaz. Kendi anahtarınızı bunun üzerine yapıştırın.

Gerçek bağlam penceresi 200K olmayan tüm modeller için aynı `env` bloğunun altına `CLAUDE_CODE_AUTO_COMPACT_WINDOW` ekleyin — Claude Code, tanımadığı her kimlik için 200K varsayar; bu nedenle otomatik sıkıştırma aksi takdirde yanlış noktada devreye girer (önceki bölümdeki uyarıya bakın). Kod parçası oluşturucu da bu değeri kabul eder; böylece hedef modelin pencere boyutunu bilen bir çağıran, değeri doğrudan oluşturabilir.

Kaynak: `ClaudeGatewayOnboardingBlock` tarafından görüntülenen `src/shared/services/claudeCliConfig.ts::buildClaudeDiscoverySettingsSnippet` (saf oluşturucu, birim testli).

## Profiller (`CLAUDE_CONFIG_DIR`)

Claude Code'un **yerleşik profil dosyaları yoktur** (Codex'in `~/.codex/<name>.config.toml` dosyasından farklı olarak). Standart mekanizma `CLAUDE_CONFIG_DIR`'dır — her profil için ayrı bir yapılandırma dizini bulunur ve her birinin kendi `settings.json` dosyası, kimlik bilgileri, geçmişi ve önbelleği vardır.

`omniroute setup-claude`, canlı `/v1/models` kataloğunu getirir ve `~/.claude/profiles/<name>/settings.json` konumuna model başına bir profil yazar; **`setup-codex` ile aynı adları** (`glm52`, `kimi-k27`, `deepseek-pro`, …) yeniden kullanır:

```jsonc
// ~/.claude/profiles/glm52/settings.json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "model": "glm/glm-5.2",
  "effortLevel": "xhigh",
  "env": {
    "ANTHROPIC_BASE_URL": "http://192.168.0.15:20128",
    "ANTHROPIC_MODEL": "glm/glm-5.2",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "190000",
  },
}
```

> **Kimlik doğrulama belirteci hiçbir zaman profile yazılmaz.** `omniroute launch --profile <name>` ile başlatın (etkin bağlamdaki `ANTHROPIC_AUTH_TOKEN` değerini enjekte eder) veya `ANTHROPIC_AUTH_TOKEN` değişkenini kendiniz dışa aktararak `CLAUDE_CONFIG_DIR=~/.claude/profiles/<name> claude` komutunu çalıştırın.

**Model keşfinden sonra otomatik eşitleme (isteğe bağlı).** OmniRoute, sağlayıcı modeli eşitlemesi canlı kataloğu değiştirdiğinde aynı `~/.claude/profiles/<name>/settings.json` dosyalarını otomatik olarak yeniden oluşturabilir; böylece yeni veya yeniden adlandırılmış modeller, komutu yeniden çalıştırmadan profil edinir. Bu özellik **varsayılan olarak kapalıdır**: **CLI Code kontrol panelinden** etkinleştirin ("CLI profilini otomatik eşitle" → Claude Code) veya `OMNIROUTE_AUTO_SYNC_CLAUDE_PROFILES=true` olarak ayarlayın (`CLI_ALLOW_CONFIG_WRITES` ayarını da dikkate alır; bu ayar varsayılan olarak açıktır). Etkinleştirildiğinde yalnızca profil dosyalarını yazar; etkin/varsayılan Claude yapılandırmanızı, kimlik doğrulamanızı veya `~/.claude/settings.json` dosyasını hiçbir zaman değiştirmez.

### Profil oluşturma ve kullanma

```bash
# Yerel OmniRoute
omniroute setup-claude

# Uzak VPS (VPS URL'sini her profile yerleştirir)
omniroute setup-claude --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Yalnızca bazı sağlayıcılar
omniroute setup-claude --only glm,kimi

# Yazmadan önizleme
omniroute setup-claude --dry-run

# Bir profil başlatın
omniroute launch --profile kimi-k27
```

## Model katmanları (isteğe bağlı)

Claude Code, istekleri yetenek katmanlarına yönlendirir. Her katman için farklı sağlayıcılar kullanmak istiyorsanız env /
ayarlar aracılığıyla her birini bir OmniRoute modeliyle eşleyin:

```bash
export ANTHROPIC_DEFAULT_OPUS_MODEL="glm/glm-5.2"
export ANTHROPIC_DEFAULT_SONNET_MODEL="kmc/kimi-k2.6"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="glm/glm-4.7-flash"
```

Aksi takdirde her şey için tek bir `ANTHROPIC_MODEL` (profillerin ayarladığı) kullanılır.

## Uzak mod

`omniroute connect <host>` komutunu çalıştırdıktan sonra (bkz.
[Uzak Mod](./REMOTE-MODE.md)), `omniroute launch` ve `omniroute setup-claude`
otomatik olarak bu uzak sunucuyu hedefler ve sunucuya özel erişim belirtecini kullanır — ek
bayrak gerekmez. Her çağrı için `--remote` / `--api-key` ile geçersiz kılabilirsiniz.

## Sorun giderme

**Claude Code ağ geçidini yok sayıyor** — `ANTHROPIC_BASE_URL` değerinin
`/v1` **içermediğini** doğrulayın ve `claude` uygulamasını yeniden başlatın (env yalnızca başlangıçta bir kez okunur). `omniroute launch`
bunu sizin için halleder.

**`/model` seçicisi boş / ağ geçidi modelleri eksik** — Claude Code
v2.1.219+ ve `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` gerekir. Seçicide yalnızca `claude*` /
`anthropic*` model kimlikleri görünür; diğer modelleri
`ANTHROPIC_MODEL=<id>` ile zorlayın (profiller bunu yapar).

**`400 Ambiguous model 'claude-…'`** — Claude Code her zaman **ön eksiz**
model kimlikleri (ör. `claude-opus-4-8`) gönderir; bu nedenle hem Claude Code (`cc/…`) hem de
Claude (`claude/…`) sağlayıcıları bağlı olduğunda yalın kimlik iki rotayla eşleşir ve
OmniRoute tahminde bulunmayı reddeder. Bunu iki şekilde düzeltebilirsiniz: ön ekli bir kimliği
`ANTHROPIC_MODEL=cc/claude-opus-4-8` ile sabitleyin veya **Ön eksiz Claude modelleri için Claude Code'u tercih et**
seçeneğini etkinleştirin — Claude sağlayıcı sayfasındaki anahtar ya da
`OMNIROUTE_PREFER_CLAUDE_CODE_FOR_UNPREFIXED_CLAUDE_MODELS=true` (varsayılan olarak kapalıdır;
bkz. [Ortam](../reference/ENVIRONMENT.md)) — bu seçenek yalın `claude-*`
kimliklerini bunun yerine Claude Code'a yönlendirir. Açık sağlayıcı ön ekleri her zaman önceliklidir.

**Kimlik doğrulama hataları** — profil herhangi bir belirteç içermez. `omniroute launch --profile`
kullanın (belirteci ekler) veya `ANTHROPIC_AUTH_TOKEN` değişkenini dışa aktarın.

**Profiller birbirinden yalıtılmıyor** — her profil farklı bir `CLAUDE_CONFIG_DIR` kullanır;
oturum içinde `echo $CLAUDE_CONFIG_DIR` çıktısının
`~/.claude/profiles/<name>` konumunu gösterdiğini doğrulayın.
