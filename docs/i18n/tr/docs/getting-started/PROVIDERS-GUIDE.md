## Sağlayıcı Nedir?

Sağlayıcıyı bir **telefon operatörü** gibi düşünün. Arama yapmak için bir telefon operatörüne ihtiyaç duyduğunuz gibi, yapay zekâ modellerini kullanmak için de bir yapay zekâ sağlayıcısına ihtiyacınız vardır. OmniRoute, **tüm operatörlerle** çalışan bir telefon gibidir; sağlayıcılar arasında otomatik olarak geçiş yapabilirsiniz.

### Sağlayıcı Türleri

| Tür              | Nedir                                 | Örnekler                          | Maliyet                  |
| ---------------- | ------------------------------------- | --------------------------------- | ------------------------ |
| **Ücretsiz**     | Ödeme gerekmez                        | Kiro, OpenCode Free, Pollinations | $0                       |
| **API Anahtarı** | Bir API anahtarına ihtiyacınız vardır | OpenAI, Anthropic, Google         | Kullanım başına ödeme    |
| **OAuth**        | Hesabınızla oturum açarsınız          | Claude Code, GitHub Copilot       | Abonelik                 |
| **Web Çerezi**   | Tarayıcı oturumunuzu kullanır         | ChatGPT Web (Codex), Gemini Web   | $0 (hesabınızı kullanır) |

### Web Çerezi Sağlayıcıları

## Hızlı Başlangıç: İlk Sağlayıcınızı Bağlayın

### İsteğe bağlı ilk çalıştırma ücretsiz sağlayıcı kurulumu

İlk çalıştırma sihirbazı, açıkça belirtilmiş bir **Ücretsiz sağlayıcıları ayarla** kartı sunar. Mevcut
uygun listeyi OmniRoute'un kimlik doğrulaması gerektirmeyen sağlayıcı kayıt defterinden oluşturur ve ardından onaylamadan önce her
sağlayıcıyı gözden geçirip seçimini kaldırmanıza olanak tanır. OmniRoute, sağlayıcının uyarı bildirimini ve sitesine yönlendiren bir bağlantıyı
gösterir; böylece önce üçüncü taraf koşullarını, gizlilik politikasını, kullanılabilirliği ve hız sınırlarını inceleyebilirsiniz.

Bu işlem isteğe bağlıdır: sihirbazı tamamlamak hiçbir zaman sessizce ücretsiz sağlayıcı bağlantıları oluşturmaz.
Yalnızca hâlâ eksik olan sağlayıcıları oluşturur, mevcut özelleştirilmiş bağlantılara
dokunmaz ve oluşturulan, zaten yapılandırılmış ve başarısız olan sağlayıcıları ayrı ayrı bildirir. Kısmi bir sonuçtan sonra
yalnızca başarısız olanları güvenle yeniden deneyebilirsiniz.

### Seçenek A: Ücretsiz Sağlayıcı (Kredi Kartı Gerekmez)

1. `http://localhost:20128` adresindeki panoyu açın
2. **Sağlayıcılar** → **Sağlayıcı Ekle** bölümüne gidin
3. Şu ücretsiz sağlayıcılardan birini seçin:
   - **Kiro AI** — Ücretsiz Claude modelleri (kimlik doğrulaması gerekmez)
   - **OpenCode Free** — Ücretsiz GPT modelleri (kimlik doğrulaması gerekmez)
   - **Pollinations** — Ücretsiz GPT-5, Claude, Gemini (anahtar gerekmez)
   - **LongCat** — 10M ücretsiz token (tek seferlik tahsis; hesap + KYC gerektirir)
   - **Cloudflare AI** — 50'den fazla model, günde 10K nöron
   - **MLX Gemma 26B** — Yerel Apple Silicon modeli (~38.5 token/sn, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — Yerel Apple Silicon modeli (~9.1 token/sn, ~13.1GB RAM)
4. **Bağlan** seçeneğine tıklayın
5. Tamamlandı! Artık ücretsiz yapay zekâ erişiminiz var.

### Seçenek B: API Anahtarı Sağlayıcısı (Ücretli)

1. Sağlayıcının web sitesinden bir API anahtarı alın:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` adresindeki panoyu açın
3. **Sağlayıcılar** → **Sağlayıcı Ekle** bölümüne gidin
4. Sağlayıcınızı seçin
5. API anahtarınızı yapıştırın
6. **Bağlan** seçeneğine tıklayın
7. Tamamlandı! Artık bu sağlayıcının modellerine erişiminiz var.

### Seçenek C: OAuth Sağlayıcısı (Abonelik)

1. `http://localhost:20128` adresindeki panoyu açın
2. **Sağlayıcılar** → **Sağlayıcı Ekle** bölümüne gidin
3. Sağlayıcınızı seçin (ör. Claude Code, GitHub Copilot)
4. **OAuth ile Bağlan** seçeneğine tıklayın
5. Hesabınızla oturum açın
6. Tamamlandı! Artık aboneliğinize dahil modellere erişiminiz var.

### Seçenek D: Yerel MLX Modelleri (Apple Silicon)

Birleşik belleğe sahip Apple Silicon Mac'lerde OmniRoute, `mlx-lm.server` aracılığıyla çalışan yerel MLX modellerine standart OpenAI uyumlu yerel sağlayıcılar olarak bağlanmayı destekler.

#### Ön Koşullar

- 24GB veya daha fazla birleşik belleğe sahip bir **Apple Silicon Mac** (M1/M2/M3/M4) önerilir
- **uv** paket yöneticisi: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Hızlı Başlangıç

1. **Bağımlılıkları yükleyin**:

   ```bash
   # Henüz yüklü değilse uv'yi yükleyin
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm'yi yükleyin
   uv pip install mlx-lm
   ```

2. **MLX sunucularını manuel olarak başlatın** (ayrı terminallerde):

   ```bash
   # Terminal 1: Gemma 4 26B A4B IT-QAT (port 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Terminal 2: Qwen 3.8 27B MLX Mixed (port 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute Panosu'nda bağlanın**:
   - **Sağlayıcılar** → **Sağlayıcı Ekle** bölümüne gidin
   - **MLX Gemma 26B** veya **MLX Qwen 3.8 27B** seçeneğini belirleyin
   - **Bağlan** seçeneğine tıklayın (API anahtarı gerekmez)

4. **OpenCode ile kullanın**:
   ```bash
   # OpenCode'u OmniRoute'u kullanacak şekilde yapılandırın
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <omniroute-api-anahtarınız>

   # MLX modellerini kullanın
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Bellek Yönetimi

**Önemli**: 24GB birleşik bellekle aynı anda yalnızca **bir büyük MLX modeli çalışabilir**.

- Gemma 26B: ~15.9GB en yüksek bellek kullanımı
- Qwen 3.8 27B: ~13.1GB en yüksek bellek kullanımı

Bunu manuel olarak yönetmeniz gerekir:

- Aynı anda yalnızca bir MLX sunucusu çalıştırın veya
- Her ikisini ayrı makinelerde çalıştırın ya da
- Diğerini başlatmadan önce birini durdurun

OmniRoute, MLX sunucu süreçlerini otomatik olarak yönetmez; yalnızca istekleri yapılandırdığınız OpenAI uyumlu uç noktalara yönlendirir.

#### Araç Çağırma Desteği

Her iki model de OpenAI uyumlu araç çağırmayı destekler. Şununla test edin:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Sorun giderme

| Sorun                  | Çözüm                                                                                                       |
| ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| Sunucu başlamıyor      | `uv run mlx_lm.server --help` komutunu kontrol edin ve model kimliklerini doğrulayın                        |
| Bellek yetersiz        | Yalnızca bir modelin çalıştığından emin olun; diğer uygulamaları kapatın; Etkinlik Monitörü'nü kontrol edin |
| Bağlantı reddedildi    | Sunucunun doğru portta (11435/11436) çalıştığını doğrulayın                                                 |
| Yanıtlar yavaş         | İlk istek modeli belleğe yükler (~30-60 sn.); sonraki istekler hızlıdır                                     |
| Araç çağırma başarısız | Modelin araçları desteklediğinden emin olun; çeviri hataları için OmniRoute günlüklerini kontrol edin       |

## Bir Sağlayıcı Nasıl Bağlanır? (Adım Adım)

### 1. Adım: Kontrol Panelini Açın

Tarayıcınızda `http://localhost:20128` adresine gidin.

### 2. Adım: Sağlayıcılara Gidin

Kenar çubuğundaki **Sağlayıcılar** seçeneğine tıklayın.

### 3. Adım: Sağlayıcı Ekle'ye Tıklayın

**+ Sağlayıcı Ekle** düğmesine tıklayın.

### 4. Adım: Sağlayıcınızı Seçin

Listede gezinin veya sağlayıcınızı arayın. Üzerine tıklayın.

### 5. Adım: Kimlik Bilgilerini Girin

- **Ücretsiz sağlayıcılar**: Kimlik bilgileri gerekmez — yalnızca **Bağlan** seçeneğine tıklayın
- **API anahtarı kullanan sağlayıcılar**: API anahtarınızı yapıştırın
- **OAuth sağlayıcıları**: **OAuth ile Bağlan** seçeneğine tıklayın ve oturum açın

### 6. Adım: Bağlantıyı Test Edin

Çalıştığını doğrulamak için **Bağlantıyı Test Et** seçeneğine tıklayın.

### 7. Adım: Tamamlandı!

Sağlayıcınız artık bağlıdır. `model: "auto"` ile kullanabilir veya sağlayıcıyı doğrudan belirtebilirsiniz.

## Birden Fazla Sağlayıcı Kullanma

OmniRoute, **birden fazla sağlayıcıyla** en iyi şekilde çalışır. Bu size şunları sağlar:

- **Otomatik yedekleme** — Bir sağlayıcı başarısız olursa OmniRoute sıradakini dener
- **Maliyet optimizasyonu** — OmniRoute her istek için en ucuz sağlayıcıyı seçer
- **Hız optimizasyonu** — OmniRoute her istek için en hızlı sağlayıcıyı seçer
- **Kalite optimizasyonu** — OmniRoute her görev için en iyi sağlayıcıyı seçer

### Önerilen Kurulum

En iyi deneyim için en az **3 sağlayıcı** bağlayın:

1. **Bir ücretsiz sağlayıcı** (Kiro, OpenCode Free veya Pollinations) — Her zaman kullanılabilir
2. **Bir hızlı sağlayıcı** (Groq, Cerebras) — Hızlı yanıtlar için
3. **Bir yüksek kaliteli sağlayıcı** (OpenAI, Anthropic, Google) — Karmaşık görevler için

Ardından `model: "auto"` kullanın; OmniRoute her istek için en uygun sağlayıcıyı otomatik olarak seçer.

## Sık Sorulan Sorular

### "OmniRoute'u kullanmak için ödeme yapmam gerekiyor mu?"

**Hayır!** OmniRoute ücretsiz ve açık kaynaklıdır. Hiçbir ödeme yapmadan ücretsiz sağlayıcıları (Kiro, OpenCode Free, Pollinations) kullanabilirsiniz. Yalnızca ücretli sağlayıcıları kullanmayı tercih ederseniz ödeme yaparsınız.

### "Hangi sağlayıcıyla başlamalıyım?"

**Kiro AI** ile başlayın — ücretsizdir, API anahtarı gerektirmez ve Claude modellerine erişmenizi sağlar. Ardından ihtiyaç duydukça daha fazla sağlayıcı ekleyin.

### "Aynı anda birden fazla sağlayıcı kullanabilir miyim?"

**Evet!** OmniRoute'un temel amacı tam olarak budur. Birden fazla sağlayıcı bağlayın ve OmniRoute'un her istek için en iyisini seçmesini sağlamak üzere `model: "auto"` kullanın.

### "Bir sağlayıcı devre dışı kalırsa ne olur?"

OmniRoute, başarısız olan sağlayıcıları otomatik olarak atlar ve bir sonrakini dener. Hiçbir şey yapmanız gerekmez.

### "Bir sağlayıcının bağlantısını nasıl keserim?"

Sağlayıcılar'a gidin → sağlayıcıya tıklayın → **Bağlantıyı Kes** seçeneğine tıklayın.

### "Mevcut API anahtarlarımı kullanabilir miyim?"

**Evet!** OpenAI, Anthropic, Google vb. için zaten API anahtarlarınız varsa bunları OmniRoute'ta kullanabilirsiniz. Sağlayıcıya bağlanırken anahtarları yapıştırmanız yeterlidir.
