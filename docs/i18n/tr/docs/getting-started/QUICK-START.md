## 1. Adım: OmniRoute'u Kurun

Tercih ettiğiniz yöntemi seçin:

### Seçenek A: npm (Önerilen)

```bash
npm install -g omniroute
```

### Seçenek B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest`, **yayımlanmış** en yüksek kararlı SemVer sürümüdür. git `main` dalını takip **etmez**. GitOps için `diegosouzapw/omniroute:X.Y.Z` sürümünü sabitleyin. Bkz. [İmaj Etiketleri / Sürüm Kanalları](../guides/DOCKER_GUIDE.md#release-channels).

### Seçenek C: Kaynak Koddan

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## 2. Adım: OmniRoute'u Başlatın

```bash
omniroute
```

OmniRoute, `http://localhost:20128` adresinde başlatılır. Kontrol paneli otomatik olarak açılır.

---

## 3. Adım: Ücretsiz Bir Sağlayıcı Bağlayın

Ücretsiz bir sağlayıcı bağlayarak OmniRoute'u **hiçbir ücret ödemeden** kullanabilirsiniz.

### Seçenek A: Kiro (Ücretsiz Claude — Kredi Kartı Gerektirmez)

1. `http://localhost:20128` adresindeki kontrol panelini açın
2. **Providers** → **Add Provider** bölümüne gidin
3. **Kiro AI** seçeneğini belirleyin
4. **Connect** düğmesine tıklayın (API anahtarı gerekmez!)
5. Tamamdır! Artık Claude modellerine ücretsiz erişiminiz var.

### Seçenek B: OpenCode Free (Kimlik Doğrulama Gerektirmez)

1. `http://localhost:20128` adresindeki kontrol panelini açın
2. **Providers** → **Add Provider** bölümüne gidin
3. **OpenCode Free** seçeneğini belirleyin
4. **Connect** düğmesine tıklayın (API anahtarı gerekmez!)
5. Tamamdır! Artık birden fazla modele ücretsiz erişiminiz var.

### Seçenek C: Pollinations (Anahtar Gerektirmez)

1. `http://localhost:20128` adresindeki kontrol panelini açın
2. **Providers** → **Add Provider** bölümüne gidin
3. **Pollinations** seçeneğini belirleyin
4. **Connect** düğmesine tıklayın (API anahtarı gerekmez!)
5. Tamamdır! Artık GPT-5, Claude, Gemini ve daha fazlasına ücretsiz erişiminiz var.

---

## 4. Adım: Çalıştığını Doğrulayın

[API Keys](http://localhost:20128/dashboard/api-manager) bölümünden yeni bir anahtar oluşturun. Bu anahtar tekrar görüntülenmeyeceği için güvenli bir yerde saklayın. Bu anahtarın üst sağlayıcılara erişmek için değil, araçların OmniRoute'a erişmesi için kullanıldığını unutmayın.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Bağlı modellerinizin listelendiğini görmelisiniz.

---

## 5. Adım: IDE'nizi veya CLI Aracınızı OmniRoute'a Yönlendirin

IDE'nizde veya CLI aracınızda şunları ayarlayın:

```
Temel URL:  http://localhost:20128/v1
API Anahtarı:  [Kontrol Paneli → Endpoints bölümünden kopyalayın]
Model:      auto
```

Hepsi bu! IDE'niz artık otomatik sağlayıcı seçimiyle OmniRoute'u kullanıyor.

### IDE Örneği: VSCode/Continue.dev

1. VSCode'a [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) uzantısını yükleyin.
2. Aşağıdaki satırları eklemek için `~/.continue/config.yaml` dosyanızı güncelleyin:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev sohbet panelinde `OmniRoute - Auto` seçeneğini belirlediğinizde istekleriniz OmniRoute'a gönderilir.
4. (İsteğe bağlı) Okuyucu için alıştırma: IDE'nizin `config.yaml` dosyasını diğer tüm önceden oluşturulmuş yapılandırmalarla güncellemesini sağlayın 😊

### CLI Örneği: Codex CLI

1. İşletim sisteminizde ortam değişkenini kalıcı olarak ayarlayın.
   macOS/Linux için (`~/.bashrc` veya `~/.zshrc` dosyanıza ekleyin):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows için (Komut İstemi):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Şimdi Codex'i OmniRoute için yapılandırılmış şekilde başlatalım. Şunu çalıştırın:

```
omniroute launch-codex --model auto
```

Uç noktayı ve API anahtarını belirtmek için bunu `codex` ve komut satırı parametreleri aracılığıyla manuel olarak yapabilirsiniz; ancak yukarıdaki komutla OmniRoute sizin için her şeyi halleder.

Aynı tek komutla başlatma yöntemi, genel başlatıcı üzerinden diğer CLI'lar için de çalışır: `omniroute run <target>`; `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` ve `gemini` seçeneklerini destekler (bkz. [CLI Entegrasyonları](../guides/CLI-INTEGRATIONS.md)).

3. CLI artık istekleri OmniRoute'a gönderiyor olmalıdır.

### Aracınızın OmniRoute'a yönlendirme yaptığını doğrulayın

Sol kenar çubuğundaki [Monitoring/Logs](http://localhost:20128/dashboard/logs) seçeneğine tıklayarak isteğin ayrıntılarını görebilirsiniz. İsteğe tıklayarak daha fazla ayrıntı görüntüleyebilirsiniz. Ayrıca, kullandığınız istemci aracından hangi bilgilerin gönderildiğini de görebilirsiniz. Bu, öğrenme ve hata ayıklama açısından faydalıdır.

## Sık Sorulan Sorular

### "Bir API anahtarına ihtiyacım var mı?"

**Hayır!** Ücretsiz sağlayıcıları (Kiro, OpenCode Free, Pollinations) herhangi bir API anahtarı olmadan kullanabilirsiniz. Bunları kontrol panelinden bağlamanız yeterlidir.

### "`auto` nedir?"

`auto`, OmniRoute'a her istek için en iyi sağlayıcıyı otomatik olarak seçmesini söyler. Hız, maliyet, kalite ve kullanılabilirlik dikkate alınır. Ayrıntılar için [Auto-Combo Kılavuzu](./AUTO-COMBO-GUIDE.md) bölümüne bakın.

### "Maliyeti ne kadar?"

OmniRoute'un kendisi **ücretsiz ve açık kaynaklıdır**. Yalnızca kullandığınız sağlayıcılar için ödeme yaparsınız. Birçok sağlayıcının ücretsiz katmanı vardır — [Ücretsiz Katmanlar Kılavuzu](./FREE-TIERS-GUIDE.md) bölümüne bakın.

### "Claude Code / Cursor / Copilot ile kullanabilir miyim?"

**Evet!** OmniRoute, OpenAI biçimini destekleyen tüm araçlarla çalışır. Temel URL'yi `http://localhost:20128/v1` olarak ayarlamanız yeterlidir. Belirli kurulum talimatları için [CLI Araçları Kılavuzu](../reference/CLI-TOOLS.md) bölümüne bakın.

### "Bir sağlayıcı devre dışı kalırsa ne olur?"

OmniRoute, başarısız olan sağlayıcıları otomatik olarak atlar ve sıradakini dener. Herhangi bir işlem yapmanız gerekmez. Ayrıntılar için [Auto-Combo Kılavuzu](./AUTO-COMBO-GUIDE.md) bölümüne bakın.
