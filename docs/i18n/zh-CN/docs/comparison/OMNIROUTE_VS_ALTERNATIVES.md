## 何时选择 OmniRoute

- 你需要自行托管，并希望获得**最广泛的提供者覆盖**（329 个提供者，155 个免费/无需认证的目录条目）
- 你需要**内置 MCP 服务器**（将 LLM 工具、记忆和技能作为工具公开）
- 你需要用于智能体间工作流的 **A2A 协议**
- 你希望通过**指纹隐匿**（JA3/JA4）避免被上游 CAPTCHA 检测
- 你需要**企业级功能**（防护机制、评估、审计跟踪），但不希望支付 SaaS 费用

## 何时选择 LiteLLM

- 你**以 Python 为主**，并需要与 `litellm.completion()` 紧密集成
- 你需要**成熟的生产部署方案**（k8s、Helm charts）
- 你的团队已经在运行 Python 微服务

## 何时选择 OpenRouter (SaaS)

- 你不想自行托管
- 你可以接受按 Token 付费以及 SaaS 加价
- 你需要使用**单一支付方式**向所有提供者付款

## 何时选择 Portkey

- 你需要具有可用性保证的**商业 SLA**
- 你更喜欢无需承担运维开销的**托管式仪表板**
- 你需要开箱即用的**企业合规**功能
