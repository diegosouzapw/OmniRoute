在决定是否重试之前，会先对故障进行分类。

超时、网络错误、速率限制和提供者 5xx 响应等瞬时故障可能会触发故障转移。对于身份验证错误、权限错误、无效请求、不可用模型和未知故障，不会盲目重试。

默认的跨提供者策略最多允许尝试三个提供者，会重试因速率限制和超时导致的失败，并将管理性禁用与临时熔断状态分开处理。

熔断状态包括 `closed`、`open` 和 `half_open`。冷却期结束后会安排一次受限探测；探测成功会关闭熔断器，探测失败则会重新打开熔断器。
