分配并非提供者配额。

配额池定义哪些 API 密钥可以使用提供者资源池，以及如何应用硬性、软性或突发策略。提供者配额是由提供者报告的外部容量，或由显式配置的来源提供的容量。Ghostlight 内部预算是由管理员定义的治理限制。

`ensurePool` 操作具有幂等性：相同的资源池保持不变，发生变化的分配会被更新，缺失的资源池会被创建。此操作适用于自动化场景和调用次数受限的 API 调用方。

只读状态端点为 `GET /api/omniroute/status`。验证命令为 `npm run omniroute:verify`；该命令不会发起实时模型请求。
