## 类别

- **免费** — 提供免费套餐，需要 API 密钥（通过控制面板配置）
- **无需认证** — 完全不需要密钥或登录的公共端点
- **OAuth** — 登录流程由 OmniRoute 处理，无需 API 密钥
- **Web Cookie** — 通过 Cookie 认证封装提供者的 Web 应用
- **API 密钥** — 通过 API 密钥配置的付费提供者（可能提供免费额度）
- **本地** — 在用户的计算机上运行（Ollama、LM Studio、vLLM 等）
- **搜索** — Web 搜索提供者
- **音频** — 仅提供音频功能的提供者（TTS/STT）
- **上游代理** — 代理到其他提供者的提供者
- **云端代理** — 长时间运行的编码代理（Codex Cloud、Devin、Jules）
- **系统** — OmniRoute 内部提供者（回环等）

附加标签：`image`、`video`、`aggregator`、`enterprise`、`embed/rerank`、`self-hosted`。

`工具调用`（若显示）：`native` — 真正的函数调用 API；`emulated` — 通过 `webTools.ts` 对 `tools` 数组进行提示词模拟（使用正则表达式解析 `<tool>{...}</tool>` 块）；`none` — 当前会静默丢弃 `tools`。参见 #7286。

使用 `/dashboard/providers` 中的控制面板启用、配置和测试各个提供者。
