> **简而言之**：请使用您自己的符合条件的提供者账户。OmniRoute 会整合您配置的连接；它本身并不提供宣传中所述的聚合 token 额度。免费访问可能需要注册、API 密钥、审批或付款方式。提供者的限制、隐私政策和条款仍然适用。

---

## 什么是免费套餐？

许多 AI 提供者都提供某种形式的**免费访问**。具体形式因提供者而异，可能是无需身份验证的端点、周期性配额、受速率限制但无总量上限的访问、注册赠额、人工审批或限时促销。某些选项需要账户、API 密钥、信用卡、KYC，或接受提供者的特定条款。

OmniRoute 将已配置的连接**聚合**到一个端点中。对于每个要求账户的提供者，你仍需分别注册。连接这些账户后，使用 `model: "auto"` 在符合条件的目标之间进行路由。全新安装后可能没有任何符合条件的免密钥目标；仅安装 OmniRoute 并不能保证成功获得聊天响应。

## 如何叠加免费套餐

OmniRoute 的妙处在于**叠加免费套餐**。你无需依赖单一提供者，而是可以连接多个提供免费套餐的提供者，让 OmniRoute 自动为每个请求选择最佳提供者。

### 示例：扩大免费套餐覆盖范围

连接多个提供者，以减少对任何单一配额的依赖：

1. **Gemini** — 定期重置的 API 密钥配额
2. **Groq** — 定期重置的 API 密钥配额
3. **Pollinations** — 无需密钥、受速率限制的访问
4. **LongCat** — 一次性注册赠金（需要 KYC）

然后使用 `model: "auto"`，OmniRoute 将：

- 首先尝试排名最高且符合条件的连接
- 如果其配额不足或健康检查失败 → 尝试下一个已配置的提供者
- 如果无需密钥的提供者不可用 → 继续尝试其余目标
- 如果没有符合条件的连接成功 → 返回错误；注册赠金仅在有效且尚有余额时可用

**结果**：通过自动回退扩大免费套餐覆盖范围，但不保证容量无限。

## 如何连接免费提供者

### 第 1 步：打开仪表板

在浏览器中访问 `http://localhost:20128`。

### 第 2 步：前往提供者页面

点击侧边栏中的 **提供者**。

### 第 3 步：点击添加提供者

点击 **+ 添加提供者** 按钮。

### 第 4 步：选择免费提供者

浏览目录，并查看每个提供者当前的 `hasFree`、身份验证、配额、隐私和 ToS 元数据。提供者卡片和
[免费套餐参考](../reference/FREE_TIERS.md)对周期性额度池、无上限/无密钥访问、注册赠送额度、已停止服务的条目以及较高风险的来源进行了区分。

### 第 5 步：点击连接

对于 `NOAUTH` 提供者，OmniRoute 不会请求上游凭据。但这并不保证上游接受第三方客户端或拥有可用容量。OAuth 和 API 密钥提供者必须通过其文档中说明的账户流程进行连接。启用路由器身份验证后，您的客户端仍需使用 **仪表板 → 端点** 中显示的 OmniRoute API 密钥。

### 第 6 步：重复操作

连接多个条款和隐私模式符合您使用场景的提供者。

## 正确阅读目录

- `NOAUTH` 表示 OmniRoute 不会要求您提供服务商凭证；但这并不保证正常运行时间、隐私或无限容量。
- `hasFree` 是用于发现的元数据。它可能表示周期性配额、无密钥访问、注册赠金、审批计划或促销活动。
- `recurring-uncapped` 表示没有可用的已公布 token 上限；速率限制和并发限制仍然适用。
- `one-time-initial` 在注册赠额用完后不会再次发放。
- 默认情况下，标记为 `tos: avoid` 的服务商会被排除在自动路由之外（`excludeTosAvoid`）。连接账户不会绕过此筛选。操作人员进行任何覆盖操作前，都应审查服务商条款和账户风险。
- 标记为 `discontinued` 的条目仅作为历史记录保留，不得描述为当前免费。

## OmniRoute 如何更好地利用免费额度

### 1. 自动回退

如果某个免费提供者繁忙或宕机，OmniRoute 会自动尝试下一个提供者。你无需执行任何操作。

### 2. 智能路由

OmniRoute 会根据以下因素，为每个请求选择**最佳免费提供者**：

- 速度 — 哪个提供者当前速度最快？
- 质量 — 哪个提供者最适合此任务？
- 容量 — 哪个提供者仍有剩余配额？

### 3. 节省令牌

OmniRoute 的压缩管道可以减少符合条件的提示词和工具输出所使用的令牌数。实际节省量取决于内容、所选引擎、提供者的计费方式和保真度设置；压缩不会按固定倍数增加每个提供者的配额。

### 4. 多账户支持

如果提供者条款允许使用多个账户或凭据，OmniRoute 可以将每个连接视为独立的路由候选项。请勿通过创建额外账户来规避提供者的配额或访问政策。

## 常见问题

### “这真的是免费的吗？”

目录记录了提供者公布的条款和项目研究结果，但优惠可能发生变化。
使用前，请核实提供者当前的定价、配额、隐私政策和资格要求。

### “免费套餐会用完吗？”

任何提供者都可能实施速率限制、更换模型、暂停访问或停止服务。建立多个
连接可以增强回退覆盖范围，但不能保证始终有可用的免费路由。

### “我可以在生产环境中使用免费提供者吗？”

只有当提供者的 SLA、数据处理方式、限制和条款满足您的生产要求时才可以。
关键工作负载应配备受监控且合同条件适当的回退方案。

### “有什么附加条件？”

可能的权衡包括严格限制、候补名单、KYC、信用卡验证、使用提示词进行训练、
隐私保护较弱、无 SLA、模型频繁变更、地域限制、超额付费或账户政策风险。
OmniRoute 会展示可用的元数据；由您决定启用哪些选项。

### “如何获得更多免费配额？”

1. 连接更多免费提供者
2. 启用适当的压缩引擎，并衡量其对您的工作负载所节省的用量
3. 使用 `auto/cheap` 优先选择免费/低价提供者
4. 在不违反提供者条款的前提下，添加其他获准使用的提供者或凭据

### “免费提供者的质量更差吗？”

不一定。某些提供者提供的模型系列与付费路由所提供的相同，但其限制、
延迟、隐私、可靠性和模型版本可能不同。请将免费提供者排名页面作为质量参考，
并核实实际提供服务的模型。
