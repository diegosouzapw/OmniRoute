## 什么是免费层级？

许多 AI 提供者都会提供某种形式的**免费访问**。具体取决于提供者，这可能意味着无需身份验证的端点、周期性配额、受速率限制但不设总量上限的访问、注册赠额、人工审批或限时促销。某些选项要求提供账户、API 密钥、信用卡、KYC，或接受提供者的特定条款。

OmniRoute 将这些免费层级**聚合**到一个端点中。你无需分别注册 10 个不同的服务，只需将它们全部连接到 OmniRoute，并使用 `model: "auto"`，即可为每个请求自动选择最佳免费选项。

## 如何叠加免费额度

OmniRoute 的妙处在于**叠加免费额度**。你无需依赖单一提供者，而是可以连接多个免费提供者，让 OmniRoute 自动为每个请求选择最佳提供者。

### 示例：扩大免费额度覆盖范围

连接多个提供者，以降低对任何单一配额的依赖：

1. **Gemini** — 周期性 API 密钥配额
2. **Groq** — 周期性 API 密钥配额
3. **Pollinations** — 无需密钥、有速率限制的访问
4. **LongCat** — 一次性注册赠送额度（需要 KYC）

然后使用 `model: "auto"`，OmniRoute 将：

- 首先尝试排名最高且符合条件的连接
- 如果其配额不足或健康检查失败 → 尝试下一个已配置的提供者
- 如果无密钥提供者不可用 → 继续尝试其余目标
- 如果全部失败 → 使用 LongCat 作为备用

**结果**：通过自动回退获得更广泛的免费额度覆盖，但不保证拥有无限容量。

## 如何连接免费提供者

### 第 1 步：打开仪表板

在浏览器中访问 `http://localhost:20128`。

### 第 2 步：前往提供者页面

点击侧边栏中的 **提供者**。

### 第 3 步：点击添加提供者

点击 **+ 添加提供者** 按钮。

### 第 4 步：选择免费提供者

浏览目录，并查看每个提供者当前的 `hasFree`、身份验证、配额、隐私和 ToS 元数据。提供者卡片和
[免费额度参考](../reference/FREE_TIERS.md)会区分周期性额度池、无上限/无密钥访问、注册赠送额度、已停止的条目以及风险较高的来源。

### 第 5 步：点击连接

对于 `NOAUTH` 提供者，无需凭据。OAuth 和 API 密钥提供者必须通过其文档中说明的账户流程进行连接。

### 第 6 步：重复操作

连接多个条款和隐私模式符合你使用场景的提供者。

## 正确理解目录信息

- `NOAUTH` 表示 OmniRoute 不会要求你提供该提供者的凭据；这并不保证可用时间、隐私或无限容量。
- `hasFree` 是用于发现的元数据。它可以表示周期性配额、无密钥访问、注册赠送额度、审批计划或促销活动。
- `recurring-uncapped` 表示没有可用的已公布令牌上限；速率和并发限制仍然适用。
- `one-time-initial` 表示注册赠送额度用完后不会再次发放。
- `tos: avoid` 是一项警告，提醒你在使用前审查提供者条款和账户风险。
- 标记为 `discontinued` 的条目仅作为历史记录保留，不得将其描述为当前仍然免费。

## OmniRoute 如何更好地利用免费额度

### 1. 自动回退

如果某个免费提供者繁忙或宕机，OmniRoute 会自动尝试下一个提供者。你无需执行任何操作。

### 2. 智能路由

OmniRoute 会根据以下因素，为每个请求选择**最佳免费提供者**：

- 速度 — 哪个提供者当前速度最快？
- 质量 — 哪个提供者最适合此任务？
- 容量 — 哪个提供者仍有剩余配额？

### 3. 节省令牌

OmniRoute 的压缩管道可以减少符合条件的提示词和工具输出所使用的令牌数。实际节省量取决于内容、所选引擎、提供者的计费方式和保真度设置；压缩不会按固定倍数增加每个提供者的配额。

### 4. 多账户支持

如果提供者条款允许使用多个账户或凭据，OmniRoute 可以将每个连接视为独立的路由候选项。请勿通过创建额外账户来规避提供者的配额或访问政策。

## 常见问题

### “这真的是免费的吗？”

目录记录了提供者公布的条款和项目研究结果，但优惠可能发生变化。
使用前，请核实提供者当前的定价、配额、隐私政策和资格要求。

### “免费套餐会用完吗？”

任何提供者都可能实施速率限制、更换模型、暂停访问或停止服务。建立多个
连接可以增强回退覆盖范围，但不能保证始终有可用的免费路由。

### “我可以在生产环境中使用免费提供者吗？”

只有当提供者的 SLA、数据处理方式、限制和条款满足您的生产要求时才可以。
关键工作负载应配备受监控且合同条件适当的回退方案。

### “有什么附加条件？”

可能的权衡包括严格限制、候补名单、KYC、信用卡验证、使用提示词进行训练、
隐私保护较弱、无 SLA、模型频繁变更、地域限制、超额付费或账户政策风险。
OmniRoute 会展示可用的元数据；由您决定启用哪些选项。

### “如何获得更多免费配额？”

1. 连接更多免费提供者
2. 启用适当的压缩引擎，并衡量其对您的工作负载所节省的用量
3. 使用 `auto/cheap` 优先选择免费/低价提供者
4. 在不违反提供者条款的前提下，添加其他获准使用的提供者或凭据

### “免费提供者的质量更差吗？”

不一定。某些提供者提供的模型系列与付费路由所提供的相同，但其限制、
延迟、隐私、可靠性和模型版本可能不同。请将免费提供者排名页面作为质量参考，
并核实实际提供服务的模型。
