## Tổng quan

Playground Studio chuyển đổi `/dashboard/playground` từ một trình soạn thảo đơn giản dựa trên Monaco thành
một không gian làm việc kiểm thử đầy đủ tính năng. Nó thay thế `page.tsx` cũ bằng một shell `PlaygroundStudio`
hiển thị bốn tab và một ngăn cấu hình dùng chung.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Trò chuyện] [⚖ So sánh] [{} API] [🔧 Xây dựng] 142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {nội dung tab đang hoạt động}           │ ─ Cấu hình                │
│                                          │ Điểm cuối [chat ∨]        │
│                                          │ Mô hình   [gpt-5.4 ∨]     │
│                                          │ Hệ thống  [vùng văn bản]  │
│                                          │ Nhiệt độ  ▕▕▔▔ 0.7        │
│                                          │ Cấu hình sẵn [▾ tải][lưu] │
│                                          │ [✨ Cải thiện prompt]      │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Các tab

### Tab Trò chuyện

Phát triển `ChatPlayground.tsx` thành một bàn làm việc phát trực tuyến đa lượt:

- Kết xuất Markdown đầy đủ thông qua `MarkdownMessage.tsx` (khối mã, bảng, danh sách, liên kết).
- Prompt hệ thống được lấy từ ngăn Cấu hình dùng chung.
- Token/chi phí cho mỗi thông điệp (token prompt + token hoàn thành).
- Tạo lại phản hồi gần nhất.
- Gửi đến `POST /v1/chat/completions` bằng phương thức phát trực tuyến SSE.

### Tab So sánh

Điểm khác biệt chính của một proxy: chạy 1 prompt trên tối đa **4 mô hình song song**.

- Tối đa 4 cột, mỗi cột phát trực tuyến độc lập từ `/v1/chat/completions`.
- Nút `+ Thêm mô hình` (phím tắt Cmd+K) để thêm cột.
- `Chạy tất cả ▶` kích hoạt đồng thời tất cả luồng bằng `Promise.all` + `AbortController` riêng cho từng cột.
- **Hủy tất cả** trên toàn cục sẽ hủy mọi luồng đang chạy.
- `ProviderMetrics` của từng cột hiển thị TTFT, TPS, số token và chi phí ước tính theo thời gian thực.
- Chỉ số được gắn nhãn **"ước tính phía máy khách"** (D12) — được đo từ đoạn SSE đầu tiên.

### Tab API

Giữ nguyên 100% trình soạn thảo Monaco ban đầu dành cho người dùng chuyên sâu (D14):

- 10 điểm cuối: hoàn thành trò chuyện, hoàn thành, embedding, hình ảnh, âm thanh, giọng nói, phiên âm, kiểm duyệt, xếp hạng lại, tìm kiếm.
- Tải lên tệp đa phương thức.
- Phát trực tuyến SSE với đầu ra theo thời gian thực.
- Được đóng gói dưới dạng `ApiTab.tsx` (tải trì hoãn, `ssr: false`).

### Tab Xây dựng

Giao diện gọi công cụ/hàm và đầu ra có cấu trúc:

- `ToolsBuilder.tsx` — thêm/chỉnh sửa/xóa `tools[]` bằng trình soạn thảo schema JSON cho từng công cụ.
  Xác thực tham số thông qua `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — bật/tắt chế độ JSON + trình soạn thảo schema JSON.
  Xác thực phản hồi dựa trên schema thông qua `StructuredOutputSchema` (Zod).
- Gửi yêu cầu đến `/v1/chat/completions` với `tools[]` và/hoặc `response_format`.

## Ngăn cấu hình (Dùng chung)

`StudioConfigPane.tsx` — luôn hiển thị, có thể thu gọn.

| Trường           | Thành phần            | Ghi chú                                                                   |
| ---------------- | --------------------- | ------------------------------------------------------------------------- |
| Điểm cuối        | `<select>`            | 10 tùy chọn tương ứng với `PlaygroundEndpoint`                            |
| Mô hình          | `<input>`             | văn bản tự do, ví dụ: `openai/gpt-4o`                                     |
| Prompt hệ thống  | `<textarea>`          | được truyền vào tất cả các tab                                            |
| Tham số          | `ParamSliders`        | temperature, max_tokens, top_p, hệ số phạt presence/frequency, seed, stop |
| Cấu hình đặt sẵn | `PresetPicker`        | tải/lưu các ảnh chụp nhanh cấu hình có tên (được lưu trong CSDL)          |
| Cải thiện prompt | `ImprovePromptButton` | mở hộp thoại cảnh báo hạn ngạch, gọi `/api/playground/improve-prompt`     |

Trạng thái được đưa lên `PlaygroundStudio.tsx` và truyền xuống tất cả các tab. Việc chuyển đổi tab
vẫn giữ nguyên trạng thái cấu hình.

## Thanh trên cùng

`StudioTopBar.tsx`:

- Bộ chuyển đổi tab (role="tablist").
- `TokenCostCounter` — hiển thị trực tiếp số token (↑/↓) và chi phí ước tính.
- Nút xuất mã (`</>`) — mở `ExportCodeModal`.

---

## Hộp thoại xuất mã

`ExportCodeModal.tsx` sử dụng `codeExport.ts` để tạo các đoạn mã curl / Python / TypeScript
từ `PlaygroundState` hiện tại. Phần giữ chỗ cho khóa API luôn là `$OMNIROUTE_API_KEY` (D11).

---

## Trình cải thiện prompt

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Hộp thoại cảnh báo "sẽ tiêu tốn hạn ngạch".
2. Khi xác nhận, gửi `{ system, prompt, model, tone }` đến route.
3. Route gọi nội bộ `/v1/chat/completions` với `promptImprover.META_SYSTEM_PROMPT`.
4. Trả về `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. Giao diện người dùng cập nhật prompt hệ thống trong ngăn Cấu hình và prompt người dùng trong tab Trò chuyện.

---

## Cấu hình đặt sẵn

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Được lưu trong bảng SQLite `playground_presets` (migration `084_playground_presets.sql`).
- Mỗi cấu hình đặt sẵn lưu trữ: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: danh sách `GET`, tạo `POST`, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Chỉ số luồng

`useStreamMetrics.ts` + `streamMetrics.ts` (hàm thuần):

- `start()` — ghi lại thời điểm bắt đầu yêu cầu.
- `onFirstChunk()` — ghi lại TTFT.
- `onChunk(n)` — cộng dồn số lượng token hoàn thành.
- `finish(usage?)` — tính toán các chỉ số cuối cùng: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Mức giá lấy từ bảng tĩnh trong `src/lib/playground/types.ts` (được gắn nhãn "ước tính" — D13).

## Các route backend

| Phương thức | Đường dẫn                        | Trình xử lý                                                                                |
| ----------- | -------------------------------- | ------------------------------------------------------------------------------------------ |
| `POST`      | `/api/playground/improve-prompt` | Xác thực `ImprovePromptRequestSchema` bằng Zod; gọi `/v1/chat/completions` với meta-prompt |
| `GET`       | `/api/playground/presets`        | Trả về `{ presets: PlaygroundPresetListItem[] }`                                           |
| `POST`      | `/api/playground/presets`        | Tạo cấu hình đặt sẵn; xác thực `PlaygroundPresetCreateSchema`                              |
| `GET`       | `/api/playground/presets/:id`    | Trả về một cấu hình đặt sẵn hoặc 404                                                       |
| `PUT`       | `/api/playground/presets/:id`    | Cập nhật một phần                                                                          |
| `DELETE`    | `/api/playground/presets/:id`    | 204                                                                                        |

Xác thực: tùy chọn (`REQUIRE_API_KEY`). Lỗi được xử lý qua `buildErrorBody()` (Quy tắc cứng #12).

## Khắc phục sự cố

| Triệu chứng                                         | Nguyên nhân                                  | Cách khắc phục                                                                                        |
| --------------------------------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Trình soạn thảo Monaco không hiển thị trong tab API | SSR đã tải Monaco                            | Xác minh `ApiTab` sử dụng `dynamic(..., { ssr: false })`                                              |
| Các luồng so sánh chạy tuần tự                      | Sử dụng `Promise.all` không đúng             | Mọi thao tác khởi chạy luồng phải được gửi trong một lệnh gọi `Promise.all`                           |
| Chỉ số hiển thị TTFT là `null`                      | Trình xử lý chunk đầu tiên chưa được kết nối | Kiểm tra `useStreamMetrics.onFirstChunk()` được gọi trong vòng lặp đọc SSE                            |
| Preset không được duy trì                           | Chưa chạy quá trình di chuyển DB             | Chạy `npm run db:migrate` hoặc khởi động lại máy chủ (quá trình di chuyển tự động chạy khi khởi động) |
| Tính năng cải thiện prompt trả về 502               | Chưa đặt model trong Config                  | Người dùng phải nhập tên model trong ngăn Config trước khi cải thiện                                  |
| Mã xuất hiển thị `MISSING_API_KEY`                  | Chưa chèn phần giữ chỗ                       | `codeExport.ts` luôn sử dụng `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"`                             |
