## Gỡ cài đặt nhanh (v3.6.2+)

OmniRoute cung cấp hai tập lệnh tích hợp để gỡ cài đặt sạch:

### Giữ lại dữ liệu của bạn

```bash
npm run uninstall
```

Lệnh này gỡ bỏ ứng dụng OmniRoute nhưng **giữ lại** cơ sở dữ liệu, cấu hình, khóa API và cài đặt nhà cung cấp trong `~/.omniroute/`. Sử dụng tùy chọn này nếu bạn dự định cài đặt lại sau này và muốn giữ nguyên thiết lập hiện tại.

### Gỡ bỏ hoàn toàn

```bash
npm run uninstall:full
```

Lệnh này gỡ bỏ ứng dụng **và xóa vĩnh viễn** toàn bộ dữ liệu:

- Cơ sở dữ liệu (`storage.sqlite`)
- Cấu hình nhà cung cấp và khóa API
- Tệp sao lưu
- Tệp nhật ký
- Tất cả tệp trong thư mục `~/.omniroute/`

> ⚠️ **Cảnh báo:** Không thể hoàn tác `npm run uninstall:full`. Tất cả kết nối nhà cung cấp, tổ hợp, khóa API và lịch sử sử dụng của bạn sẽ bị xóa vĩnh viễn.

## Gỡ cài đặt thủ công

### Cài đặt NPM toàn cục

```bash
# Gỡ bỏ gói toàn cục
npm uninstall -g omniroute

# (Tùy chọn) Xóa thư mục dữ liệu
rm -rf ~/.omniroute
```

### Cài đặt pnpm toàn cục

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Dừng và xóa vùng chứa
docker stop omniroute
docker rm omniroute

# Xóa ổ đĩa lưu trữ (xóa toàn bộ dữ liệu)
docker volume rm omniroute-data

# (Tùy chọn) Xóa ảnh
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Dừng và xóa các vùng chứa
docker compose down

# Đồng thời xóa các ổ đĩa lưu trữ (xóa toàn bộ dữ liệu)
docker compose down -v
```

### Ứng dụng máy tính Electron

**Windows:**

- Mở `Settings → Apps → OmniRoute → Uninstall`
- Hoặc chạy trình gỡ cài đặt NSIS từ thư mục cài đặt

**macOS:**

- Kéo `OmniRoute.app` từ `/Applications` vào Thùng rác
- Xóa dữ liệu: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Xóa tệp AppImage
- Xóa dữ liệu: `rm -rf ~/.omniroute`

### Cài đặt từ mã nguồn (git clone)

```bash
# Xóa thư mục đã sao chép
rm -rf /path/to/omniroute

# (Tùy chọn) Xóa thư mục dữ liệu
rm -rf ~/.omniroute
```

## Thư mục dữ liệu

Theo mặc định, OmniRoute lưu trữ dữ liệu tại các vị trí sau:

| Nền tảng     | Đường dẫn mặc định            | Ghi đè                            |
| ------------ | ----------------------------- | --------------------------------- |
| Linux        | `~/.omniroute/`               | Biến môi trường `DATA_DIR`        |
| macOS        | `~/.omniroute/`               | Biến môi trường `DATA_DIR`        |
| Windows      | `%APPDATA%/omniroute/`        | Biến môi trường `DATA_DIR`        |
| Docker       | `/app/data/` (ổ đĩa được gắn) | Biến môi trường `DATA_DIR`        |
| Tuân thủ XDG | `$XDG_CONFIG_HOME/omniroute/` | Biến môi trường `XDG_CONFIG_HOME` |

### Các tệp trong thư mục dữ liệu

| Tệp/Thư mục          | Mô tả                                                     |
| -------------------- | --------------------------------------------------------- |
| `storage.sqlite`     | Cơ sở dữ liệu chính (nhà cung cấp, tổ hợp, cài đặt, khóa) |
| `storage.sqlite-wal` | Nhật ký ghi trước SQLite (tạm thời)                       |
| `storage.sqlite-shm` | Bộ nhớ dùng chung SQLite (tạm thời)                       |
| `call_logs/`         | Kho lưu trữ tải trọng yêu cầu                             |
| `backups/`           | Bản sao lưu cơ sở dữ liệu tự động                         |
| `log.txt`            | Nhật ký yêu cầu cũ (tùy chọn)                             |

## Xác minh đã xóa hoàn toàn

Sau khi gỡ cài đặt, hãy xác minh rằng không còn tệp nào:

```bash
# Kiểm tra gói npm toàn cục
npm list -g omniroute 2>/dev/null

# Kiểm tra thư mục dữ liệu
ls -la ~/.omniroute/ 2>/dev/null

# Kiểm tra các tiến trình đang chạy
pgrep -f omniroute
```

Nếu vẫn còn tiến trình đang chạy, hãy dừng tiến trình đó:

```bash
pkill -f omniroute
```
