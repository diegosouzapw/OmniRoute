## Danh mục

- **Miễn phí** — gói miễn phí với khóa API (được cấu hình qua bảng điều khiển)
- **Không cần xác thực** — các endpoint công khai hoàn toàn không yêu cầu khóa hoặc đăng nhập
- **OAuth** — quy trình đăng nhập do OmniRoute xử lý, không cần khóa API
- **Cookie web** — bao bọc ứng dụng web của nhà cung cấp thông qua xác thực bằng cookie
- **Khóa API** — nhà cung cấp trả phí được cấu hình qua khóa API (có thể có tín dụng miễn phí)
- **Cục bộ** — chạy trên máy của người dùng (Ollama, LM Studio, vLLM, v.v.)
- **Tìm kiếm** — các nhà cung cấp dịch vụ tìm kiếm web
- **Âm thanh** — các nhà cung cấp chỉ hỗ trợ âm thanh (TTS/STT)
- **Proxy thượng nguồn** — các nhà cung cấp làm proxy cho những nhà cung cấp khác
- **Tác nhân đám mây** — các tác nhân lập trình chạy dài hạn (Codex Cloud, Devin, Jules)
- **Hệ thống** — các nhà cung cấp nội bộ của OmniRoute (loopback, v.v.)

Các thẻ bổ sung: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Gọi công cụ` (nếu được hiển thị): `native` — API gọi hàm thực; `emulated` — mảng `tools` được mô phỏng qua prompt bằng `webTools.ts` (các khối `<tool>{...}</tool>` được phân tích bằng biểu thức chính quy); `none` — `tools` hiện bị âm thầm loại bỏ. Xem #7286.

Sử dụng bảng điều khiển tại `/dashboard/providers` để bật, cấu hình và kiểm thử từng nhà cung cấp.
