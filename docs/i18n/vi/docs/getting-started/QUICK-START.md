## Bước 1: Cài đặt OmniRoute

Chọn phương thức bạn muốn:

### Tùy chọn A: npm (Khuyến nghị)

```bash
npm install -g omniroute
```

### Tùy chọn B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` là phiên bản SemVer ổn định **đã phát hành** cao nhất. Thẻ này **không** theo dõi nhánh git `main`. Hãy ghim `diegosouzapw/omniroute:X.Y.Z` khi sử dụng GitOps. Xem [Thẻ Image / Kênh phát hành](../guides/DOCKER_GUIDE.md#release-channels).

### Tùy chọn C: Từ mã nguồn

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Bước 2: Khởi động OmniRoute

```bash
omniroute
```

OmniRoute khởi động tại `http://localhost:20128`. Bảng điều khiển sẽ tự động mở.

---

## Bước 3: Kết nối một nhà cung cấp miễn phí

Bạn có thể sử dụng OmniRoute **mà không phải trả bất kỳ khoản phí nào** bằng cách kết nối một nhà cung cấp miễn phí.

### Tùy chọn A: Kiro (Claude miễn phí — Không cần thẻ tín dụng)

1. Mở bảng điều khiển tại `http://localhost:20128`
2. Đi tới **Nhà cung cấp** → **Thêm nhà cung cấp**
3. Chọn **Kiro AI**
4. Nhấp vào **Kết nối** (không cần API key!)
5. Xong! Giờ đây bạn có quyền truy cập miễn phí vào các mô hình Claude.

### Tùy chọn B: OpenCode Free (Không cần xác thực)

1. Mở bảng điều khiển tại `http://localhost:20128`
2. Đi tới **Nhà cung cấp** → **Thêm nhà cung cấp**
3. Chọn **OpenCode Free**
4. Nhấp vào **Kết nối** (không cần API key!)
5. Xong! Giờ đây bạn có quyền truy cập miễn phí vào nhiều mô hình.

### Tùy chọn C: Pollinations (Không cần khóa)

1. Mở bảng điều khiển tại `http://localhost:20128`
2. Đi tới **Nhà cung cấp** → **Thêm nhà cung cấp**
3. Chọn **Pollinations**
4. Nhấp vào **Kết nối** (không cần API key!)
5. Xong! Giờ đây bạn có quyền truy cập miễn phí vào GPT-5, Claude, Gemini và nhiều mô hình khác.

---

## Bước 4: Xác minh hoạt động

Từ trang [API Keys](http://localhost:20128/dashboard/api-manager), hãy tạo một khóa mới. Hãy lưu khóa này vì nó sẽ không xuất hiện lại. Lưu ý rằng khóa này dành cho các công cụ truy cập OmniRoute, không phải để truy cập các nhà cung cấp thượng nguồn.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Bạn sẽ thấy danh sách các mô hình đã kết nối.

## Bước 5: Trỏ IDE hoặc CLI của bạn tới OmniRoute

Trong IDE hoặc công cụ CLI của bạn, hãy thiết lập:

```
URL cơ sở: http://localhost:20128/v1
API Key:    [sao chép từ Bảng điều khiển → Điểm cuối]
Mô hình:    auto
```

Vậy là xong! Giờ đây IDE của bạn sử dụng OmniRoute với khả năng tự động lựa chọn nhà cung cấp.

### Ví dụ về IDE: VSCode/Continue.dev

1. Trong VSCode, hãy cài đặt tiện ích mở rộng [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Cập nhật `~/.continue/config.yaml` để thêm các dòng sau:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Trong khung trò chuyện Continue.dev, chọn `OmniRoute - Auto` và các yêu cầu của bạn sẽ được gửi tới OmniRoute.
4. (Không bắt buộc) Bài tập dành cho người đọc — hãy yêu cầu IDE cập nhật `config.yaml` với tất cả các cấu hình dựng sẵn khác 😊

### Ví dụ về CLI: Codex CLI

1. Trong hệ điều hành của bạn, hãy thiết lập biến môi trường theo cách cố định.
   Đối với macOS/Linux (thêm vào `~/.bashrc` hoặc `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Đối với Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Bây giờ, hãy khởi chạy Codex với cấu hình dành cho OmniRoute. Chạy:

```
omniroute launch-codex --model auto
```

Bạn có thể thực hiện việc này theo cách thủ công thông qua `codex` và các tham số dòng lệnh để chỉ định endpoint và API key, nhưng với lệnh trên, OmniRoute sẽ xử lý mọi thứ cho bạn.

Cách khởi chạy bằng một lệnh tương tự cũng hoạt động với các CLI khác thông qua trình khởi chạy chung — `omniroute run <target>` hỗ trợ `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` và `gemini` (xem [Tích hợp CLI](../guides/CLI-INTEGRATIONS.md)).

3. Giờ đây CLI sẽ gửi các yêu cầu tới OmniRoute.

### Xác nhận công cụ của bạn đang định tuyến tới OmniRoute

Bạn có thể xem chi tiết yêu cầu bằng cách nhấp vào [Giám sát/Nhật ký](http://localhost:20128/dashboard/logs) từ thanh bên trái. Nhấp vào từng mục để xem thêm chi tiết. Ngoài ra, bạn cũng có thể xem thông tin nào được gửi từ môi trường công cụ yêu thích của mình. Điều này hữu ích cho mục đích học tập và gỡ lỗi.

## Câu hỏi thường gặp

### "Tôi có cần API key không?"

**Không!** Bạn có thể sử dụng các nhà cung cấp miễn phí (Kiro, OpenCode Free, Pollinations) mà không cần API key. Chỉ cần kết nối chúng trong bảng điều khiển.

### "`auto` là gì?"

`auto` yêu cầu OmniRoute tự động chọn nhà cung cấp phù hợp nhất cho mỗi yêu cầu. Tính năng này cân nhắc tốc độ, chi phí, chất lượng và tính khả dụng. Xem [Hướng dẫn Auto-Combo](./AUTO-COMBO-GUIDE.md) để biết chi tiết.

### "Chi phí là bao nhiêu?"

Bản thân OmniRoute là phần mềm **miễn phí và mã nguồn mở**. Bạn chỉ phải trả phí cho các nhà cung cấp mà mình sử dụng. Nhiều nhà cung cấp có gói miễn phí — xem [Hướng dẫn về các gói miễn phí](./FREE-TIERS-GUIDE.md).

### "Tôi có thể sử dụng OmniRoute với Claude Code / Cursor / Copilot không?"

**Có!** OmniRoute hoạt động với mọi công cụ hỗ trợ định dạng OpenAI. Chỉ cần đặt URL cơ sở thành `http://localhost:20128/v1`. Xem [Hướng dẫn công cụ CLI](../reference/CLI-TOOLS.md) để biết hướng dẫn thiết lập cụ thể.

### "Nếu một nhà cung cấp ngừng hoạt động thì sao?"

OmniRoute tự động bỏ qua các nhà cung cấp gặp lỗi và thử nhà cung cấp tiếp theo. Bạn không cần làm gì cả. Xem [Hướng dẫn Auto-Combo](./AUTO-COMBO-GUIDE.md) để biết chi tiết.
