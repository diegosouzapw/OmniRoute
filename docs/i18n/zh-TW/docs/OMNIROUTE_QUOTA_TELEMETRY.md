OmniRoute 將提供者配額遙測與 Ghostlight 計量分開處理。

## 如實反映的狀態

- `healthy` 表示資料來源回報仍有可用的剩餘容量。
- `approaching_limit` 表示資料來源回報的剩餘容量等於或低於設定的閾值。
- `exhausted` 僅在資料來源回報容量為零或使用量已達上限時才會發出。
- `unavailable` 表示支援的資料來源無法傳回資料。
- `unknown` 表示不存在支援的資料來源，或沒有已知的提供者限制。

未知並不代表已耗盡，也不會停用提供者。

資料來源的優先順序如下：官方提供者 API、經過驗證的用量 API、明確對應的回應標頭、管理員設定、本機估算、未知。本機估算絕不會呈現為提供者的計費資料。

回應標頭僅會透過明確的提供者對應關係進行剖析。不會假設通用標頭名稱可全域適用。
