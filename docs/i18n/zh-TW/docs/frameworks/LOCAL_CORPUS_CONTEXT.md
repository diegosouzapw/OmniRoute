> **真實來源：** `src/lib/localCorpus/index.ts`（有界文字索引）、
> `src/lib/localCorpus/configured.ts`（已設定的執行階段）、
> `src/lib/db/localCorpus.ts`（根路徑持久化）、
> `open-sse/mcp-server/tools/localCorpusTools.ts`（3 個唯讀 MCP 工具），以及
> `src/app/api/settings/local-corpus/route.ts`（設定 API）。

## 功能簡介

Local Corpus 可讓操作人員將一個經明確核准的文字檔案目錄提供給
OmniRoute 的 MCP 伺服器。檔案會保留在原始目錄中：OmniRoute 僅將
標準化根路徑儲存在 SQLite，並維護記憶體內搜尋索引。它不會將
語料庫內容複製到儲存庫或資料庫中。

索引會以增量方式重新整理。系統會根據檔案大小和修改時間重複使用
未變更的檔案；重新讀取已變更的檔案並使用 SHA-256 進行雜湊；並移除
已刪除的檔案。搜尋時會重新整理超過 30 秒的索引；呼叫端也可以要求
立即重新整理。

## 設定來源

此設定路由所需的管理驗證與其他設定 API 相同。提交的路徑必須已存在，
且必須是絕對目錄路徑。

```bash
# 連接經核准的目錄
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# 檢查設定和索引狀態
curl http://localhost:20128/api/settings/local-corpus

# 中斷連接，但不變更來源檔案
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP 工具

這三個工具都需要 `read:local-corpus`。工具回應只會公開相對路徑和
根目錄的基底名稱，絕不會公開其絕對路徑。

| 工具                  | 說明                                                                 |
| :-------------------- | :------------------------------------------------------------------- |
| `local_corpus_status` | 回報設定狀態、索引大小、限制及上次重新整理時間                       |
| `local_corpus_search` | 搜尋已建立索引的文字，並傳回有界且限定行範圍的片段（最多 20 筆結果） |
| `local_corpus_read`   | 從一個允許的語料庫相對檔案中讀取有界行範圍                           |

MCP 輸入範例：

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## 安全界限

- 允許清單以文字格式為主：`.cfg`、`.csv`、`.geojson`、`.htm`、`.html`、`.ini`、
  `.js`、`.json`、`.jsonl`、`.jsx`、`.log`、`.md`、`.mjs`、`.ps1`、`.py`、`.sh`、
  `.sql`、`.toml`、`.ts`、`.tsx`、`.txt`、`.xml`、`.yaml` 和 `.yml`。
- 符號連結會被略過。讀取路徑會經過標準化，且必須保持在已設定的
  根目錄內；絕對路徑和路徑遍歷嘗試會遭到拒絕。
- 系統會排除敏感及產生的目錄名稱：`.build`、`.codex`、`.env`、
  `.git`、`.next`、`.omniroute`、`.ssh`、`coverage`、`dist`、`node_modules` 和
  `secrets`。
- 預設限制為 5,000 個檔案、每個檔案 1 MiB、索引內容總計 64 MiB、
  每個搜尋區塊約 4,000 個字元，以及每次讀取 400 行。
- 含有 NUL 的檔案會被視為非文字檔案，並遭到略過或拒絕。

系統刻意不支援 PDF、DOCX、圖片和封存檔等二進位文件。請先在已設定的
目錄中將它們轉換成核准的文字格式，再建立索引。

## 操作注意事項

- 變更或刪除已設定的根目錄會清除共用的記憶體內索引。
- 程序重新啟動時會捨棄索引；下次搜尋會從已設定的來源重建索引。
- `local_corpus_status` 不會強制執行掃描。需要立即重新掃描時，請使用
  `local_corpus_search` 並設定 `refresh: true`。
- 掃描和讀取失敗會納入計數，或以經過清理的錯誤形式傳回；來源檔案
  絕不會遭到修改。
