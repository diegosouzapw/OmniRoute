`agentrouter` 上游閘道會對 `messages[].content` 執行以關鍵字為基礎的內容篩選。此篩選器具有部分確定性（總是封鎖特定片語）及部分機率性（對突發流量敏感——在快速連續請求後會變得更嚴格，並在冷卻後恢復）。

當 WAF 封鎖請求時，會回傳：

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## 篩選範圍

WAF 僅檢查 `messages[].content`。它**不會**檢查：

- `system` 提示
- 結構化內容區塊（`tool_result`、`tool_use`、`thinking`、`image`）
- 工具的 `description` 與 `input_schema` 欄位
- 請求中繼資料、標頭或模型 ID

## 一律封鎖的模式（不區分大小寫）

| 模式                        | 備註                                                      |
| --------------------------- | --------------------------------------------------------- |
| 任何 `Lorem ipsum` 變體     | 完整的拉丁文 lorem 詞彙都會被封鎖                         |
| 單獨出現的 `language model` | `"the language model"` 與 `"large language model"` 可通過 |
| `virtual assistant`         | `"AI assistant"` 可通過                                   |
| `I'm here to help`          | 單獨的 `"here to help"` 也會被封鎖                        |
| `Claude, made by Anthropic` | 僅封鎖完整片語                                            |

## 幾乎總是封鎖的模式

| 模式                                            | 備註                             |
| ----------------------------------------------- | -------------------------------- |
| `placeholder`                                   | 單獨出現時（而非作為參數名稱等） |
| `dummy data`                                    | 測試資料常用的種子片語           |
| `foo bar baz`                                   | 典型的佔位片語                   |
| 重複的短權杖（`AAA BBB CCC`、`test test test`） | 用於偵測關鍵字堆砌的偵測器       |

## 負載下的行為

在短時間內快速發出約 5 個請求後，WAF 會開始封鎖通常可以通過的內容。閒置約 5–10 秒後，配額桶會放寬。這與依 IP 和金鑰綁定的速率限制器相同；當 Claude Code 或 Codex CLI 快速連續進行多次工具使用／訊息傳送呼叫時，該限制器會造成間歇性的 `400 content-blocked` 錯誤。

## OmniRoute 中已套用的緩解措施

1. **`open-sse/services/wafRateLimit.ts`** — 突發流量防護，強制對任何 `agentrouter:*` URL 的連續外送請求保持至少 500 ms 的間隔。此間隔遠低於人類可感知的延遲，並可防止 WAF 在正常流量下啟動。

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — 當上游回傳 `400 content-blocked` 時，執行器會以指數退避方式重試相同 URL（1.5 s、3.0 s，最多嘗試 2 次）。退避後，WAF 通常會放寬限制，重試便能成功。

3. **`tests/unit/compression/harness.test.ts`** — 測試固定資料 `longInput` 已從 `"lorem ipsum dolor sit amet ".repeat(40)` 變更為 `"example content for testing purposes ".repeat(40)`，因此當 Claude Code 透過 `Read` 工具讀取此檔案時，檔案內容不會經由 `tool_result` 區塊回流並觸發 WAF。

## 提示與工具輸出的指引

如果 Claude Code 或 Codex CLI 工作階段反覆遇到 `400 content-blocked`，請檢查最新的使用者訊息與最新的工具結果是否包含上述任何模式，並重新措辭。常見的因應方式包括：

- 將 `Lorem ipsum …` 替換為 `example text …`，或使用測試或固定資料實際嘗試模擬的內容。
- 將單獨出現的 `placeholder` 替換為 `example value`、`sample value` 或真實值。
- 將 `language model` 替換為 `large language model` 或 `the model`。
- 將 `dummy data` 替換為 `sample data` 或實際的種子值。
- 將 `I'm here to help`／`here to help` 替換為更具體的開場白（例如 `"I'll review the file you mentioned"`）。

## 向上游回報誤判

目前的篩選器過於嚴格——即使操作者顯然無意注入提示，它仍會封鎖 `tool_result` 區塊中的 `"Lorem ipsum"`。希望從源頭修正此問題的營運人員，應聯絡 `agentrouter.org` 以回報這些誤判。上述封鎖清單是截至 2026-08-03 對上游進行探測所得的實證結果。
