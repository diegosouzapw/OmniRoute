配額分配（Allocation）不是提供者配額。

配額集區定義哪些 API 金鑰可以使用提供者集區，以及如何套用硬性、軟性或突發政策。提供者配額是由提供者回報，或由明確設定的來源提供的外部容量。Ghostlight 內部預算則是由管理員定義的治理限制。

`ensurePool` 操作具備冪等性：相同的集區不會變更；配額分配有變更時會予以更新；集區不存在時則會建立。此操作專為自動化與受限的 API 呼叫端而設計。

唯讀狀態端點為 `GET /api/omniroute/status`。驗證命令為 `npm run omniroute:verify`；此命令不會發出即時模型請求。
