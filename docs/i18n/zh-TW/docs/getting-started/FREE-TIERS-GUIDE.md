> **重點摘要**：請自備符合資格的提供者帳戶。OmniRoute 會整合您設定的連線；它不會自行提供所宣稱的彙總權杖額度。免費存取可能需要註冊、API 金鑰、審核核准或付款方式。提供者的限制、隱私權政策與條款仍然適用。

## 什麼是免費方案？

許多 AI 提供者都提供某種形式的**免費存取**。依提供者而異，這可能表示無須驗證的端點、定期重置的額度、受速率限制但無總量上限的存取、註冊贈送額度、人工核准，或限時優惠。部分選項需要帳戶、API 金鑰、信用卡、KYC，或接受提供者特定的條款。

OmniRoute 會將已設定的連線**彙整**至單一端點。對於每個要求帳戶的提供者，您仍需分別註冊。連接這些帳戶，並使用 `model: "auto"` 在符合條件的目標之間進行路由。全新安裝可能沒有任何符合條件且無須金鑰的目標；僅安裝 OmniRoute 並不保證能成功取得聊天回應。

## 如何疊加免費方案

OmniRoute 的精髓在於**疊加免費方案**。您不必依賴單一提供者，而是可以連接多個免費提供者，並讓 OmniRoute 自動為每個請求選擇最佳提供者。

### 範例：更廣泛的免費方案涵蓋範圍

連接多個提供者，以降低對任何單一配額的依賴：

1. **Gemini** — 週期性 API 金鑰配額
2. **Groq** — 週期性 API 金鑰配額
3. **Pollinations** — 無需金鑰、具有速率限制的存取
4. **LongCat** — 一次性註冊額度（需要 KYC）

接著使用 `model: "auto"`，OmniRoute 將會：

- 優先嘗試排名最高且符合條件的連線
- 如果其配額用盡或健康檢查失敗 → 嘗試下一個已設定的提供者
- 如果無需金鑰的提供者無法使用 → 繼續嘗試其餘目標
- 如果沒有符合條件的連線成功 → 傳回錯誤；註冊額度僅能在有效且仍有可用額度時使用

**結果**：透過自動備援獲得更廣泛的免費方案涵蓋範圍，而非保證擁有無限容量。

## 如何連線免費提供者

### 步驟 1：開啟儀表板

在瀏覽器中前往 `http://localhost:20128`。

### 步驟 2：前往提供者頁面

按一下側邊欄中的 **提供者**。

### 步驟 3：按一下新增提供者

按一下 **+ 新增提供者** 按鈕。

### 步驟 4：選擇免費提供者

瀏覽目錄，並查看每個提供者目前的 `hasFree`、驗證方式、配額、隱私權及服務條款中繼資料。提供者資訊卡與
[免費方案參考](../reference/FREE_TIERS.md)會區分定期重設的資源池、無上限／無需金鑰的存取方式、註冊贈送額度、已停止提供的項目，以及風險較高的來源。

### 步驟 5：按一下連線

對於 `NOAUTH` 提供者，OmniRoute 不會要求上游憑證。這不保證上游會接受第三方用戶端或有可用容量。OAuth 與 API 金鑰提供者必須透過其文件記載的帳戶流程進行連線。啟用路由器驗證時，您的用戶端仍會使用 **儀表板 → 端點** 中顯示的 OmniRoute API 金鑰。

### 步驟 6：重複操作

連線數個條款與隱私權模式符合您使用情境的提供者。

## 正確閱讀目錄

- `NOAUTH` 表示 OmniRoute 不會要求您提供提供者憑證；這並不
  保證正常運作時間、隱私或無限容量。
- `hasFree` 是探索中繼資料。它可能表示定期配額、無金鑰存取、
  註冊點數、審核方案或促銷活動。
- `recurring-uncapped` 表示沒有已公布的 token 上限；速率與
  並行限制仍然適用。
- `one-time-initial` 在註冊贈額用完後不會再次提供。
- `tos: avoid` 提供者預設會排除在自動路由之外（`excludeTosAvoid`）。連結帳戶並不會繞過此篩選器。任何操作員覆寫都應在審查提供者條款與帳戶風險後進行。
- 標記為 `discontinued` 的項目會保留作為歷史記錄，且不得宣稱為
  目前免費。

## OmniRoute 如何讓免費方案更好用

### 1. 自動備援

如果某個免費提供者忙碌或服務中斷，OmniRoute 會自動嘗試下一個提供者。您無須進行任何操作。

### 2. 智慧路由

OmniRoute 會根據以下條件，為每個請求選擇**最佳免費提供者**：

- 速度 — 哪個提供者目前速度最快？
- 品質 — 哪個提供者最適合此任務？
- 容量 — 哪個提供者仍有剩餘配額？

### 3. 節省權杖

OmniRoute 的壓縮管線可以減少符合條件的提示詞與工具輸出權杖。
實際節省量取決於內容、所選引擎、提供者計費方式及保真度
設定；壓縮不會以固定倍數增加每個提供者的配額。

### 4. 多帳戶支援

如果提供者條款允許使用多個帳戶或憑證，OmniRoute 可以將每個
連線視為獨立的路由候選項目。請勿建立額外帳戶以規避提供者的
配額或存取政策。

## 常見問題

### 「這真的是免費的嗎？」

目錄記錄提供者公開的條款與專案研究結果，但方案可能隨時變更。
使用前請確認提供者目前的定價、配額、隱私權政策及資格條件。

### 「免費方案的額度會用完嗎？」

任何提供者都可能實施速率限制、變更模型、暫停存取或停止服務。連接多個
提供者可改善備援涵蓋範圍，但無法保證始終有可用的免費路由。

### 「我可以在正式環境中使用免費提供者嗎？」

只有在提供者的 SLA、資料處理方式、限制及條款符合您的正式環境
需求時才可以。關鍵工作負載應具備受監控且在合約上適用的備援方案。

### 「有什麼代價？」

取捨可能包括嚴格限制、候補名單、KYC、信用卡驗證、使用提示詞進行訓練、
較弱的隱私保障、無 SLA、模型頻繁更替、地理限制、超額付費，或帳戶政策風險。
OmniRoute 會呈現可用的中繼資料；您可自行選擇要啟用的項目。

### 「如何獲得更多免費配額？」

1. 連接更多免費提供者
2. 啟用適當的壓縮引擎，並衡量其對您的工作負載所節省的用量
3. 使用 `auto/cheap`，優先選擇免費／低價提供者
4. 在不違反提供者條款的前提下，新增其他獲准使用的提供者或憑證

### 「免費提供者的品質比較差嗎？」

不一定。部分提供者提供的模型系列與付費路由相同，
但限制、延遲、隱私、可靠性及模型版本可能有所不同。請將
「免費提供者排名」頁面作為品質參考指標，並確認實際提供服務的模型。
