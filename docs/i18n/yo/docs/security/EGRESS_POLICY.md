> **So ìṣàn jáde mọ́ ẹbí IP kan ṣoṣo — `auto`, `ipv4`, tàbí `ipv6` — fún proxy kọ̀ọ̀kan, kí egress IPv6-nìkan má bàa yọ́ padà sí IPv4 ní ìkọ̀kọ̀.**

> **Orísun òtítọ́:** `open-sse/utils/proxyFamily.ts`, `open-sse/utils/proxyDispatcher.ts`, `open-sse/utils/proxyFetch.ts`, `open-sse/utils/socksConnectorWithFamily.ts`, `open-sse/utils/proxyFamilyResolve.ts`, `src/shared/validation/schemas.ts`, `src/lib/db/proxies.ts`, `src/lib/db/upstreamProxy.ts`, `src/lib/db/migrations/099_proxy_family.sql`

OmniRoute ń jẹ́ kí proxy kọ̀ọ̀kan ní **àṣẹ egress ẹbí àdírẹ́sì**. Ní àìyípadà, OS ló máa yan IPv4 tàbí IPv6 (dual-stack, "Happy Eyeballs"). Nígbà tí o bá ṣètò àṣẹ náà sí `ipv4` tàbí `ipv6`, OmniRoute máa so gbogbo ìsopọ̀ tó gba inú proxy yẹn kọjá mọ́ ẹbí tí a yàn, yóò sì **kọ̀ láìlọ sí ọ̀nà mìíràn** dípò kó padà sí ẹbí kejì.

Ojú-ìwé yìí ṣàkọsílẹ̀ ohun tí àṣẹ náà jẹ́, ìdí tí ó fi wà, ibi tí o ti lè ṣètò rẹ̀, àti bí runtime ṣe ń yanjú rẹ̀.

## Ohun Tí Ó Jẹ́

Gbogbo proxy inú registry ní field `family` kan pẹ̀lú iye mẹ́ta tó ṣeé lò, tí Zod enum sì ń ṣe ìfọwọ́sí rẹ̀:

```ts
// src/shared/validation/schemas.ts
family: z.enum(["auto", "ipv4", "ipv6"]).optional().default("auto"),
```

Iye àìyípadà field náà ni `"auto"`, èyí tó ń pa ìhùwàsí dual-stack tẹ́lẹ̀ mọ́. Ṣíṣètò rẹ̀ sí `ipv4` tàbí `ipv6` máa so ẹbí ìsopọ̀ fún proxy yẹn mọ́ iye tí a yàn.

A máa ń ṣe àtúnṣe àṣẹ náà ní gbogbo ibi nípasẹ̀ olùrànlọ́wọ́ kan ṣoṣo, kí iye àìmọ̀ èyíkéyìí lè padà sí `auto`:

```ts
// open-sse/utils/proxyFamily.ts
export type ProxyFamily = "auto" | "ipv4" | "ipv6";

export function parseProxyFamily(value: unknown): ProxyFamily {
  return value === "ipv4" || value === "ipv6" ? value : "auto";
}
```

## Ìdí Tí Ó Fi Wà

A ṣe àgbékalẹ̀ rẹ̀ nínú PR [#3777](https://github.com/diegosouzapw/OmniRoute/pull/3777). Àwọn ìṣòro tó mú kí a ṣe é:

| Ìṣòro                                         | Ohun tí àṣẹ náà ń ṣàtúnṣe                                                                                                                                                                                                                                                                                                                         |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Egress IPv6-nìkan tó ń yọ́ sí IPv4**         | Nígbà tí host proxy kan bá ní àwọn record A àti AAAA méjèèjì (tàbí tí OS bá fẹ́ràn IPv4), Happy Eyeballs lè pe ìsopọ̀ jáde lórí IPv4 bó tilẹ̀ jẹ́ pé ọ̀nà IPv6-nìkan ni o fẹ́. Síso mọ́ `ipv6` máa ń mú ìyọ́sí yẹn kúrò.                                                                                                                                  |
| **Fífagilé nítorí àìṣedéédé egress tí a pín** | Àwọn olùpèsè tó ń yípadà (codex/openai) máa ń fagilé àwọn token nígbà tí ọ̀pọ̀ account bá ń jáde nípasẹ̀ IP **kan náà** lọ́pọ̀lọpọ̀. Ṣíṣàkóso ẹbí egress jẹ́ apá kan ti fífi àwọn account sí orí àwọn ọ̀nà egress ọ̀tọ̀ọ̀tọ̀ tó sì ṣeé sọ àsọtẹ́lẹ̀ (wo [`src/lib/proxyEgress.ts`](../../src/lib/proxyEgress.ts) fún ìwádìí-àìsàn IP egress tó bá èyí ṣiṣẹ́ pọ̀). |
| **Egress tó dájú fún ìbámu/ìdánwò**           | Nígbà tí o gbọ́dọ̀ ṣe ìdánilójú pé ìṣàn jáde lórí ẹbí kan pàtó, `auto` kò tó.                                                                                                                                                                                                                                                                       |

A mọ̀ọ́mọ̀ ṣe àṣẹ náà fún **proxy kọ̀ọ̀kan**, kì í ṣe gbogbo ètò — àwọn proxy ọ̀tọ̀ọ̀tọ̀ nínú pool rẹ lè ní àwọn ìlànà tó yàtọ̀ síra.

`ProxyRegistryManager.tsx` ló ń render control náà (tí a mount sínú `proxy/ProxyPoolTab.tsx`).

### API

Field `family` jẹ́ apá kan àwọn payload ìṣẹ̀dá/ìṣàtúnṣe registry proxy, tí `createProxyRegistrySchema` / `updateProxyRegistrySchema` (`src/shared/validation/schemas.ts`) ń validate, tí `POST` / `PATCH /api/v1/management/proxies` sì ń bójú tó:

```bash
# Ṣẹ̀dá proxy IPv6-nìkan
curl -X POST http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{
    "name": "IPv6 egress",
    "type": "socks5",
    "host": "proxy.example.com",
    "port": 1080,
    "family": "ipv6"
  }'

# Yí proxy tó ti wà padà sí IPv4-nìkan
curl -X PATCH http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{ "id": "proxy-uuid-here", "family": "ipv4" }'
```

Object config proxy inline tí a ń lò fún àwọn entry upstream-proxy náà tún gba field kan náà (`upstream_proxy_config.family`, wo [Àwòṣe Dátà](#data-model)).

Fún ìyókù API CRUD/assignment proxy, wo [PROXY_GUIDE.md](../ops/PROXY_GUIDE.md).

## Bí `auto` Ṣe Ń Yanjú

Nígbà tí `family` bá jẹ́ `auto`, OmniRoute **kì í** fi directive kankan kún un — URL proxy náà ni a máa lò bí ó ṣe rí, family ìsopọ̀ náà sì ni a máa pinnu lọ́nà àbínibí.

Ní àkókò ṣíṣe URL (`proxyConfigToUrl` / `normalizeProxyUrl` nínú `open-sse/utils/proxyDispatcher.ts`), proxy `auto` máa ń mú URL lasan jáde láìsí marker:

```ts
// open-sse/utils/proxyDispatcher.ts
const fam = parseProxyFamily(config.family);
const normalized = normalizeProxyUrl(proxyUrlStr, "context proxy", {
  allowSocks5,
});
return fam === "auto" ? normalized : `${normalized}?family=${fam}`;
```

Ní àkókò dispatch (`resolveDispatcherFamily`), `auto` máa ń yanjú sí family àbínibí ti host IP-literal, tàbí `null` (kí OS pinnu) fún hostname:

```ts
// open-sse/utils/proxyDispatcher.ts
function resolveDispatcherFamily(parsed: URL): 4 | 6 | null {
  const directive = parseProxyFamily(parsed.searchParams.get("family") ?? undefined);
  const literal = detectIpLiteralFamily(parsed.hostname);
  if (directive === "auto") return literal; // null fún hostname → OS ló yan
  // ...
}
```

Nítorí náà:

- `auto` + host IP-literal (`192.0.2.1` / `[2001:db8::1]`) → family ti literal náà.
- `auto` + hostname → `null` → ìyanjú dual-stack boṣewa ti OS.

## Bí A Ṣe N Fipá Mú `ipv4` / `ipv6` Ṣiṣẹ́

Ìtọ́sọ́nà tí kì í ṣe `auto` máa ń rìn gẹ́gẹ́ bí àmì ìbéèrè àtọwọ́dá kan ṣoṣo — `?family=ipv4` tàbí `?family=ipv6` — tí a ṣàfikún lẹ́ẹ̀kan ṣoṣo sí URL aṣojú tí a ti mú wà ní ìlànà kan náà. `normalizeProxyUrl` máa ń ṣọ́ra láti yọ àmì yìí kúrò kí ó sì tún un ṣàfikún lẹ́ẹ̀kan ṣoṣo gan-an, kí ó má bàa ba ìtúpalẹ̀ port jẹ́ láéláé.

Nígbà tí a bá ń kọ́ dispatcher náà, a máa ka àmì náà, a sì máa yí i padà sí family ìsopọ̀ pàtó kan. Bí host náà bá jẹ́ IP literal ti family **òdì kejì**, OmniRoute yóò ju àṣìṣe jáde (ìtakora máa ń fa ìkọ̀sílẹ̀ láìsí ààyè fún ìpadà-sẹ́yìn):

```ts
// open-sse/utils/proxyDispatcher.ts
const want = directive === "ipv6" ? 6 : 4;
if (literal !== null && literal !== want) {
  throw new Error(
    `[ProxyDispatcher] Proxy family directive ${directive} contradicts ${literal === 6 ? "IPv6" : "IPv4"} literal host`
  );
}
```

Lẹ́yìn náà, a máa so family pàtó náà mọ́ connector:

- **Àwọn aṣojú HTTP/HTTPS** (`ProxyAgent`): `proxyTls: { family, autoSelectFamily: false }` — èyí mú Happy Eyeballs má ṣiṣẹ́, kí family tí a yàn nìkan ni a lè pe ìsopọ̀ sí.
- **Àwọn aṣojú SOCKS5**: connector àkànṣe kan máa ń fi `socket_options: { family, autoSelectFamily: false }` ránṣẹ́ sínú client SOCKS (wo [Ìbámu SOCKS5](#socks5-compatibility)).

## Ìbámu SOCKS5

Ìsopọ̀ family náà ń ṣiṣẹ́ pẹ̀lú àwọn aṣojú SOCKS5, ṣùgbọ́n `fetch-socks` àkójọpọ̀ kò ṣí àwọn àṣàyàn socket tí a nílò láti so family ti ìgbésẹ̀ aṣojú náà mọ́. OmniRoute ní connector tirẹ̀ fún ìdí yìí:

```ts
// open-sse/utils/socksConnectorWithFamily.ts
export function buildSocksFamilySocketOptions(family: 4 | 6 | null): Record<string, unknown> {
  if (family === 6) return { family: 6, autoSelectFamily: false };
  if (family === 4) return { family: 4, autoSelectFamily: false };
  return {};
}
```

Gbogbo ìfiránṣẹ́ SOCKS5 máa ń gba inú `createSocksDispatcherWithFamily` kọjá láìka iye `family` sí (pẹ̀lú `null` / `auto` lórí hostname): `buildSocksFamilySocketOptions(null)` máa ń dá `{}` padà, a sì máa lo ipa-ọ̀nà `SocksClient.createConnection` + TLS `buildConnector` kan náà pẹ̀lú fífi `socket_options` so mọ́ ọn, kí Happy Eyeballs má bàa lè yan IPv4 fún ìlànà egress tí IPv6 nìkan.

Àtìlẹ́yìn SOCKS5 fúnra rẹ̀ wà ní títàn ní àkọ́kọ́ (o lè jáde kúrò nípasẹ̀ `ENABLE_SOCKS5_PROXY=false`); wo [PROXY_GUIDE.md → Àwọn Àyípadà Àyíká](../ops/PROXY_GUIDE.md#environment-variables).

## Ìhùwàsí Ìkọ̀sílẹ̀ Láìsí Ààyè Fún Ìpadà-sẹ́yìn

Ète pàtàkì ti ìtọ́sọ́nà náà ni láti **kọ̀** dípò kí ó padà lọ sí family tí kò tọ́ ní ìdákẹ́jẹ́. Àwọn olùṣọ́ méjì ló ń fipá mú èyí ṣẹlẹ̀:

1. **Ìtakora literal** — ìtọ́sọ́nà tí ó tako host IP-literal máa ń ju àṣìṣe jáde ní àkókò tí a ń kọ́ dispatcher (`resolveDispatcherFamily`, tí a fihàn lókè).

2. **Àyẹ̀wò DNS ṣáájú ìjáde fún hostname** — fún aṣojú hostname tí a so mọ́ family kan, `proxyFetch.ts` máa ń ṣàyẹ̀wò pé hostname náà ní record kan nínú family tí a nílò **ṣáájú** egress, nípasẹ̀ `assertHostnameSupportsFamily`:

   ```ts
   // open-sse/utils/proxyFamilyResolve.ts
   const hasFamily = records.some((r) => r.family === family);
   if (!hasFamily) {
     throw new Error(
       `[ProxyFamily] Proxy host ${host} has no ${family === 6 ? "IPv6 (AAAA)" : "IPv4 (A)"} record; ` +
         `refusing ${family === 6 ? "IPv6" : "IPv4"}-only egress (fail-closed)`
     );
   }
   ```

   Nígbà ìkùnà, `proxyFetch.ts` máa ń fi `code = "PROXY_FAMILY_UNAVAILABLE"` àti `statusCode = 503` ṣe àmì sí àṣìṣe náà. Bákan náà, a ka ìkùnà ìtúpalẹ̀ DNS sí ìkọ̀sílẹ̀ láìsí ààyè fún ìpadà-sẹ́yìn (a kọ̀ láti ṣe egress).

Àwọn host IP-literal kò nílò ohunkóhun fún àyẹ̀wò DNS ṣáájú ìjáde — family wọn jẹ́ apá àbínibí wọn, kò sì nílò ìwádìí kankan.

## Àwòṣe Dátà

A fi ọ̀wọ̀n `family` kún tábìlì **méjì** nípasẹ̀ ìṣíkiri `099_proxy_family.sql`:

```sql
-- src/lib/db/migrations/099_proxy_family.sql
ALTER TABLE proxy_registry ADD COLUMN family TEXT NOT NULL DEFAULT 'auto';
ALTER TABLE upstream_proxy_config ADD COLUMN family TEXT NOT NULL DEFAULT 'auto';
```

- `proxy_registry.family` — ìtọ́sọ́nà fún proxy kọ̀ọ̀kan nínú àwọn àkọsílẹ̀ registry (`src/lib/db/proxies.ts`). Àwọn ìbéèrè ìyanjú máa ń yan `family` pẹ̀lú àwọn ọ̀wọ̀n proxy yòókù, a sì máa ń yí iye tí kò sí tàbí tí kì í ṣe string padà sí `"auto"`.
- `upstream_proxy_config.family` — ìtọ́sọ́nà fún àwọn àkọsílẹ̀ upstream-proxy (`src/lib/db/upstreamProxy.ts`), pẹ̀lú iye àìyípadà `"auto"` kan náà.

Nígbà tí ohun proxy tí a ti yanjú bá ní `family` tí kì í ṣe `auto`, `proxyConfigToUrl` máa ń fi àmì `?family=` kún un kí ìdìmọ́ náà lè wà títí dé dispatcher.
