Ìtúòdù aláfarahàn TPROXY jẹ́ **ìpo ìmúwọlé karùn-ún** ti OmniRoute fún akopọ MITM
[Traffic Inspector](../frameworks/TRAFFIC_INSPECTOR.md) / [AgentBridge](../frameworks/AGENTBRIDGE.md).
Ó ń dáwọ́ dúró, ó sì ń **túòdù** ìrìnàjò HTTPS àbájáde agbègbè lórí Linux
nípa lílo TPROXY ekuro + ìdarí ipa-ọ̀nà gẹ́gẹ́ bí ìlànà — **láì ṣe** àfarawé `/etc/hosts` àti
**láì ṣe** àtúnṣe àwọn ìṣètò aṣojú-ètò káàkiri OS. Ó bójú mu fún lílò láìsí ìbójútó
(kò sí àwọn àtúnṣe DNS láti sọ di mímọ́), àwọn òfin ogiri-ààbò sì máa ń parẹ́ fúnra wọn nígbà àtúnítàn.

Láìdàbí àwọn ìpo ìmúwọlé yòókù, TPROXY kò nílò ìṣètò ọ̀tọ̀ fún olùgbàlejò kọ̀ọ̀kan: ó ń
dáwọ́ dúró lọ́nà aláfarahàn fún àwọn olùgbàlejò ibi-àfojúsùn **èyíkéyìí** lórí pórì ibi-àfojúsùn kan, ó ń parí TLS pẹ̀lú
ìwé-ẹ̀rí ewé tí ó ń ṣe jáde lẹ́sẹ̀kẹsẹ̀ fún orúkọ olùgbàlejò SNI kọ̀ọ̀kan, ó ń gba
ìpàṣípààrọ̀ tí a ti túòdù, ó sì tún ń fi ìbéèrè náà sí odù sí ibi-àfojúsùn ìpilẹ̀ṣẹ̀.

> **Linux nìkan, root nìkan, àti nípa yíyàn láti mú ṣiṣẹ́.** Ìpo yìí nílò Linux, àfikún abinibi kan
> tí a kọ́ pẹ̀lú irinṣẹ́ C, àti agbára **CAP_NET_ADMIN** (ní ọ̀pọ̀ ìgbà root). Ó wà lẹ́yìn
> API AgentBridge tí a fi mọ́ loopback nìkan, a sì pa á nípa àìyẹsẹ̀. CA MITM tí a fọkàn tán
> tí ó lè fọwọ́ sí olùgbàlejò èyíkéyìí jẹ́ agbára ńlá — wo [§6 Ààbò](#6-security).

**Orísun:** `src/mitm/tproxy/`
**Ipa-ọ̀nà API:** `GET / POST / DELETE /api/tools/agent-bridge/tproxy`
**Yíyàn dásíbọ́ọ̀du:** Traffic Inspector → pẹpẹ irinṣẹ́ àwọn ìpo ìmúwọlé → **"Ìtúòdù TPROXY"** ⚠

## §1 Ohun tí ó jẹ́ àti ìgbà tí ó yẹ kí o lò ó

Ọ̀kọ̀ọ̀kan àwọn ìpo ìmúwọlé mẹ́rin yòókù ní ààlà tirẹ̀:

| Ìpo                    | Bí a ṣe ń darí ìrìnàjò                                       | Ààlà                                                       |
| ---------------------- | ------------------------------------------------------------ | ---------------------------------------------------------- |
| AgentBridge            | Àfarawé DNS `/etc/hosts` fún àkójọpọ̀ olùgbàlejò tí kò yípadà | àwọn olùgbàlejò aṣojú IDE tí a forúkọsílẹ̀ nìkan            |
| Àwọn Olùgbàlejò Àkànṣe | Àfarawé DNS `/etc/hosts` fún olùgbàlejò kọ̀ọ̀kan               | àkọsílẹ̀ kan fún olùgbàlejò kọ̀ọ̀kan; sudo láti ṣàtúnṣe hosts |
| HTTP_PROXY             | àyíká `HTTP_PROXY`/`HTTPS_PROXY`                             | àwọn ìṣàfilọ́lẹ̀ tí ó ń tẹ̀lé oníyípadà àyíká náà nìkan       |
| Aṣojú káàkiri ètò      | Àwọn ìṣètò aṣojú OS                                          | ń ṣàtúnṣe ipò àgbáyé; ó nílò ìmúpadàbọ̀                     |

Dípò èyí, ìtúòdù aláfarahàn TPROXY ń darí ìrìnàjò ní ipele **ekuro**. Ó
ń fi àmì sí àwọn ìsopọ̀ TCP àbájáde agbègbè tuntun sí pórì ibi-àfojúsùn kan (àìyẹsẹ̀ `443`) nínú
ẹ̀wọ̀n `mangle OUTPUT`, `ip rule` kan ń tún àwọn packet tí a sàmì sí darí sí ìfijiṣẹ́ agbègbè,
àti nígbà tí wọ́n bá tún wọlé, ibi-àfojúsùn `TPROXY` ti `mangle PREROUTING` ń fi wọ́n lé
olùgbọ́ **IP_TRANSPARENT** lọ́wọ́ — èyí tí yóò parí TLS, tí yóò sì gba ọ̀rọ̀ tí kò sí nínú odù.

Lò ó nígbà tí o bá fẹ́ gba àti túòdù ìrìnàjò láti inú iṣẹ́ kan tí:

- ń bá olùgbàlejò kan tí AgentBridge kò forúkọsílẹ̀ sọ̀rọ̀, àti
- kò tẹ̀lé `HTTP_PROXY`, àti
- tí o kò fẹ́ dá láàmú pẹ̀lú àyípadà aṣojú káàkiri ètò.

Nítorí pé ìdádúró náà ń ṣẹlẹ̀ nínú ekuro, iṣẹ́ tó dá ìrìnàjò náà sílẹ̀ kò nílò **ìyípadà
ìṣètò kankan** — ṣùgbọ́n iṣẹ́ náà gbọ́dọ̀ fọkàn tán CA aláyípadà tí OmniRoute
fi sílẹ̀ (wo [§4](#4-the-per-sni-dynamic-ca-and-trust-store-installer)).

## §2 Àwọn ohun tí a nílò

| Ohun tí a nílò         | Àlàyé                                                                                                                                                 |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OS**                 | Linux nìkan — **IP_TRANSPARENT** jẹ́ àṣàyàn socket tí Linux nìkan ní. Loader náà máa ń dá "unavailable" padà lórí gbogbo platform mìíràn.              |
| **Àṣẹ**                | Agbára **CAP_NET_ADMIN** láti ṣẹ̀dá socket transparent náà àti láti lo àwọn òfin `iptables`/`ip` — ní ìlò gidi, ṣiṣẹ́ gẹ́gẹ́ bí root.                     |
| **Addon abinibi**      | A gbọ́dọ̀ kọ addon N-API kékeré kan (`src/mitm/tproxy/native/transparent.c`) tàbí pèsè é gẹ́gẹ́ bí prebuild. Wo [§3](#3-the-native-ip_transparent-addon). |
| **Àwọn module kernel** | `iptables` pẹ̀lú àtìlẹ́yìn ìbámu `TPROXY`, `mangle`, àti `mark` (a ti fìdí rẹ̀ múlẹ̀ pẹ̀lú kernel 6.8.0).                                                  |

**Ìdínkù iṣẹ́ láìfa ìṣòro:** bí èyíkéyìí nínú àwọn ohun tí a nílò kò bá sí (tí kì í ṣe Linux, kò sí toolchain,
a kò kọ addon náà), loader addon náà (`src/mitm/tproxy/transparentSocket.ts::loadTransparentAddon`)
yóò dá `null` padà dípò jíju àṣìṣe. Ipò capture-mode yóò sì fi
`available: false` hàn, toggle dashboard náà yóò jẹ́ **aláìṣiṣẹ́** pẹ̀lú tooltip
"TPROXY decrypt nílò Linux + root + addon abinibi náà", apá tó kù nínú
OmniRoute yóò sì máa ṣiṣẹ́.

## §3 Addon IP_TRANSPARENT abinibi náà

Module `net` ti Node kò lè ṣe `setsockopt(IP_TRANSPARENT)` _ṣáájú_ `bind()`, èyí tí
TPROXY nílò (bí bẹ́ẹ̀ kọ́, kernel yóò sọ àwọn packet tí a darí padà nù). Addon náà
(`src/mitm/tproxy/native/transparent.c`, tí a kọ nípasẹ̀ `binding.gyp`) jẹ́ module N-API
kékeré kan tó ń ṣí àwọn function mẹ́ta sílẹ̀, tí a ń lò nípasẹ̀ `transparentSocket.ts`:

| Function addon                        | Iṣẹ́ socket                                                                                   | Ohun tí a fi ń lò ó fún                                                           |
| ------------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `createTransparentListener(ip, port)` | `socket()` + **SO_REUSEADDR** + **IP_TRANSPARENT** + `bind()` + `listen()`, ó dá raw fd padà | listener capture transparent náà (Node gba fd náà nípasẹ̀ `server.listen({ fd })`) |
| `setSocketMark(fd, mark)`             | `setsockopt` **SO_MARK** lórí fd tó ti wà                                                    | ìdènà loop (fí àmì sí àwọn socket proxy náà fúnra rẹ̀)                             |
| `connectMarked(ip, port, mark)`       | `socket()` + **SO_MARK** **ṣáájú** `connect()` tí kì í dí iṣẹ́ dúró, ó dá fd padà             | ìfiránṣẹ́ upstream tí a tún encrypt (SYN náà gbé àmì náà)                          |

A máa ń ka destination àkọ́kọ́ láti inú `socket.localAddress`/`localPort` — TPROXY
tọ́jú rẹ̀, nítorí náà kò sí ìṣàwárí **SO_ORIGINAL_DST**/NAT.

### Kíkọ addon náà

```bash
npm run build:native:tproxy      # wọ src/mitm/tproxy/native kí o sì ṣe node-gyp rebuild
                                 # -> native/build/Release/transparent.node
```

- Nígbà `npm run build`, `scripts/build/build-tproxy-native.mjs` máa ń ṣiṣẹ́ `node-gyp
rebuild`. Ó jẹ́ **fún Linux nìkan, kò sì ṣeéwu** — àìsí toolchain kan kàn máa jẹ́ kí
  capture mode náà má wà.
- `assembleStandalone.mjs` máa ń da `build/Release/transparent.node` kọ sínú
  bundle standalone náà; `transparentSocket.ts` máa ń rí i ní module-relative àti
  cwd-relative (`<cwd>/src/mitm/tproxy/native/...`).
- `build/` àti `prebuilds/` jẹ́ git-ignored — binary náà ni a **ń kọ, a kò sì
  commit rẹ̀ láé**.

Loader náà máa ń ṣàyẹ̀wò nípa àṣẹ ààyò yìí:
`native/build/Release/transparent.node`, lẹ́yìn náà `native/prebuilds/transparent.node`
(mejèèjì ní module-relative àti lábẹ́ `<cwd>/src/mitm/tproxy/`).

## §4 CA aláyípadà fún SNI kọ̀ọ̀kan àti olùṣàgbékalẹ̀ ibi ìpamọ́ ìgbẹ́kẹ̀lé

> **Ìmúdójúìwọ̀n #6684:** olupin static AgentBridge (`src/mitm/server.cjs`) ti ń
> lo àwòṣe faaji CA/leaf kan náà yìí báyìí dípò leaf static kan ṣoṣo tí ó
> fọwọ́sí ara rẹ̀. Ó ń lo instance CA tí ó **yàtọ̀**
> (`src/mitm/cert/rootCa.ts`, tí a fi pamọ́ sí `<DATA_DIR>/mitm/ca.key`/`ca.crt`)
> ó sì ń fi sí abẹ́ slot ibi ìpamọ́ ìgbẹ́kẹ̀lé `omniroute-mitm.crt` tí ó ti wà tẹ́lẹ̀
> (tí ó rọ́pò leaf kan ṣoṣo àtijọ́ níbẹ̀ — kò sí ìmúkúrò ìgbẹ́kẹ̀lé méjì tí a nílò),
> tí a sì yà á pátápátá kúrò ní slot `omniroute-tproxy-ca.crt` tirẹ̀ fún TPROXY
> ní ìsàlẹ̀. Àwọn ìṣàgbékalẹ̀ AgentBridge tuntun máa ń gba àwòṣe CA náà
> láìfọwọ́ṣe; ìṣàgbékalẹ̀ tí ó ti gbẹ́kẹ̀lé leaf static àtijọ́ tẹ́lẹ̀ máa bá a
> lọ láti lò ó títí tí olùṣàkóso yóò fi yàn láti darapọ̀ nípasẹ̀
> `MITM_ROOT_CA_ENABLED=true` (wo `src/mitm/cert/migration.ts`) — CA MITM tí a
> gbẹ́kẹ̀lé, tí ó lè fọwọ́sí leaf fún **host èyíkéyìí**, lágbára ju leaf
> fixed-SAN àtijọ́ lọ ní pàtàkì, nítorí náà ìyípadà náà kì í ṣẹlẹ̀ láìsọ̀rọ̀
> fún ìṣàgbékalẹ̀ tí a ti gbẹ́kẹ̀lé tẹ́lẹ̀.

Ní ìtàn, ìwé-ẹ̀rí MITM static ti AgentBridge ṣiṣẹ́ nítorí pé AgentBridge
ń ṣe DNS-spoof fún àkójọpọ̀ host **tí a ti pinnu** nìkan (tí a ti ṣọ̀kan báyìí
pẹ̀lú àwòṣe tó wà ní ìsàlẹ̀). TPROXY ń dá àwọn host **èyíkéyìí** dúró, nítorí
náà listener rẹ̀ gbọ́dọ̀ ṣàfihàn leaf tó péye fún SNI èyíkéyìí tí client bá
béèrè — ohun kan náà ni AgentBridge nílò báyìí fún gbogbo àkójọpọ̀
`MITM_TOOL_HOSTS` (àwọn àkọsílẹ̀ irinṣẹ́ 9) dípò àwọn host antigravity 4
nìkan.

### CA aláyípadà (`src/mitm/tproxy/dynamicCert.ts`)

`DynamicCertStore` ń ṣiṣẹ́ CA abẹ́lẹ̀ kan (tí a kọ́ lórí dependency `selfsigned`) tí:

- Ń ṣẹ̀dá CA tí ó pẹ́ nípasẹ̀ `generateMitmCa()` (CN `"OmniRoute MITM CA"`,
  ìgbà ìwúlò ọdún 10, `basicConstraints CA=true` + `keyUsage keyCertSign,cRLSign`,
  RSA 2048-bit / SHA-256).
- Ń fún **host orúkọ SNI kọ̀ọ̀kan ní leaf nígbà tí a bá béèrè rẹ̀** nípasẹ̀
  `issueLeafCert()` (ìgbà ìwúlò ọdún 1, `subjectAltName` = host SNI) ó sì ń
  fi `tls.SecureContext` kan pamọ́ fún host orúkọ kọ̀ọ̀kan.
- Ń ṣí `createSNICallback()` sílẹ̀ fún olupin tó ń parí TLS (wo [§5](#5-how-decrypt-and-capture-work)).
- A lè kọ́ ọ pẹ̀lú `existingCa` láti jẹ́ kí CA dúró ṣinṣin láàárín àwọn
  ìtún-bẹ̀rẹ̀ (kí ibi ìpamọ́ ìgbẹ́kẹ̀lé má bàa nílò àtúnṣàgbékalẹ̀).

Kọ́kọ́rọ́ aládàáni CA **kì í jáde kúrò lórí ẹ̀rọ náà láéláé**.

### Olùṣàgbékalẹ̀ ibi ìpamọ́ ìgbẹ́kẹ̀lé (`src/mitm/tproxy/caTrust.ts`)

Client tí a dá dúró gbọ́dọ̀ gbẹ́kẹ̀lé CA aláyípadà náà, nítorí náà bíbẹ̀rẹ̀
mode capture máa ń fi ìwé-ẹ̀rí CA náà sínú ibi ìpamọ́ ìgbẹ́kẹ̀lé OS lábẹ́
**slot tí a yà sọ́tọ̀** — `omniroute-tproxy-ca.crt` (constant
`TPROXY_CA_CERT_NAME`) — tí a yà kúrò ní slot ìwé-ẹ̀rí MITM static
(`omniroute-mitm.crt`) kí àwọn méjèèjì má bàa kọ ara wọn lórí.

`installTproxyCa(caPem, sudoPassword?)` máa ń ṣàwárí directory anchor ti distro
(ní ìtòlẹ́sẹẹsẹ: irú Debian lákọ̀ọ́kọ́) ó sì ń ṣiṣẹ́ àṣẹ refresh tó bá a mu:

| Directory anchor                            | Àṣẹ refresh              |
| ------------------------------------------- | ------------------------ |
| `/usr/local/share/ca-certificates`          | `update-ca-certificates` |
| `/etc/ca-certificates/trust-source/anchors` | `update-ca-trust`        |
| `/etc/pki/ca-trust/source/anchors`          | `update-ca-trust`        |
| `/etc/pki/trust/anchors`                    | `update-ca-certificates` |

Ìṣàgbékalẹ̀ máa ń kọ́kọ́ gbé PEM sí fáìlì ìgbà díẹ̀, lẹ́yìn náà ó máa ń lo
`mkdir -p` pẹ̀lú àṣẹ gíga lórí directory anchor, `cp` fáìlì tí a gbé kalẹ̀
sínú rẹ̀, ó sì máa ń ṣiṣẹ́ àṣẹ refresh. `uninstallTproxyCa()` máa ń yọ slot
tí a yà sọ́tọ̀ nìkan (tí yóò fi ìwé-ẹ̀rí MITM static sílẹ̀ láìfọwọ́kàn án)
ó sì máa ń ṣe refresh — kò ṣe ohunkóhun lórí ètò tí kì í ṣe Linux.

Gbogbo àwọn àṣẹ tó nílò àṣẹ gíga máa ń ṣiṣẹ́ nípasẹ̀ `execFileWithPassword`
(`src/mitm/systemCommands.ts`) — `spawn` pẹ̀lú **àwọn array argument, láìsí
shell, láìsí string interpolation** (Òfin Líle #13). Nígbà tí process náà
jẹ́ root (fún àpẹẹrẹ, VPS), target náà máa ń ṣiṣẹ́ tààrà, kò sì nílò password;
lórí desktop tí kì í ṣe root, a máa ń fi `sudoPassword` ránṣẹ́ nípasẹ̀
`sudo -S` lórí stdin.

> A pèsè `sudoPassword` ti desktop nínú body POST láti fún ìṣàgbékalẹ̀ ibi
> ìpamọ́ ìgbẹ́kẹ̀lé láṣẹ; a kọ̀ ọ́ sílẹ̀ pátápátá nígbà tí process náà jẹ́ root.

## §5 Bí ìyọ̀kúrò-ìfipamọ́ àti gbígbà ṣe ń ṣiṣẹ́

Ìlànà iṣẹ́ náà (gbogbo rẹ̀ wà lábẹ́ `src/mitm/tproxy/`):

```
app agbègbè  ──TCP/443──▶  mangle OUTPUT ṣàmì sí ìsopọ̀ náà (fwmark)
                           ip rule → tábìlì ipa-ọ̀nà agbègbè → lo
                           mangle PREROUTING TPROXY → olùgbọ́ IP_TRANSPARENT (port 8443)
                               │  captureMode.ts: ka ibi tí ìsopọ̀ ti ń lọ ní ìpilẹ̀ṣẹ̀ láti socket.localAddress
                               ▼
                           tlsCapture.ts:
                             1. Parí TLS ti CLIENT pẹ̀lú ewé per-SNI kan (dynamicCert)
                             2. http.Server inú ètò tú plaintext tí a ti yọ ìfipamọ́ rẹ̀
                             3. gbà á → globalTrafficBuffer.push() pẹ̀lú source: "tproxy"
                                (sanitizeHeaders + maskSecret ni a lò)
                             4. fi í ránṣẹ́ sí ibi ìpilẹ̀ṣẹ̀ lẹ́yìn títún fi ìfipamọ́ sí i
                                lórí socket tí a fi àmì ìforíkọjá sí (connectMarked, ìdènà-lúùpù)
                               │
                               ▼
                           upstream ìpilẹ̀ṣẹ̀ (api.example.com)
```

- **Ìparí TLS** (`createTlsCaptureServer`): ó fi socket tí a dá dúró ní tààrà sínú `tls.TLSSocket` ti ẹ̀gbẹ́ server nípa lílo callback SNI ti CA aláyípadà, lẹ́yìn náà ó fi stream tí a ti yọ ìfipamọ́ rẹ̀ fún `http.Server` inú ètò (ọgbọ́n ìparí MITM tí ó wọ́pọ̀). `MITM_IDLE_TIMEOUT_MS` ló fi òpin sí iye àkókò tí socket lè wà láàyè, kí tunnel tí ó dì má bàa lo gbogbo àwọn file descriptor tán.
- **Gbígbà** (`handleDecryptedRequest`): ó fi `InterceptedRequest` kan ránṣẹ́ pẹ̀lú `source: "tproxy"`, status tí ó bẹ̀rẹ̀ pẹ̀lú `"in-flight"`, àwọn header tí a ti gbé gba inú `sanitizeHeaders()`, àti àwọn body tí a ti gbé gba inú `maskSecret()` kí wọ́n tó wọ buffer náà. Lẹ́yìn náà, a ṣe àfikún response, àwọn size, àti latency sí entry náà.
- **Ìfiranṣẹ́ tí a tún fi ìfipamọ́ sí** (`createForward` / `realForward`): ó tún fi ìfipamọ́ sí ìrìnàjò náà lọ sí ibi ìpilẹ̀ṣẹ̀. `rejectUnauthorized` jẹ́ **`true`** ní ìpilẹ̀ṣẹ̀ (ó ní ààbò ní ìpilẹ̀ṣẹ̀) — a ṣàyẹ̀wò cert upstream pẹ̀lú SNI/Host tí client béèrè, nítorí náà proxy náà kọ ohun kan náà tí client ìpilẹ̀ṣẹ̀ ìbá kọ̀.

### Ìdènà-lúùpù (SO_MARK)

Nítorí pé àwọn rule náà ń fi àmì sí àwọn ìsopọ̀ outbound agbègbè tuntun, ìfiranṣẹ́ tí proxy náà **fúnra rẹ̀** tún fi ìfipamọ́ sí yóò sábà tún jẹ́ dídá dúró — èyí yóò dá lúùpù aláìlópin sílẹ̀. Ọ̀nà ìfiranṣẹ́ náà ń dáàbò bo ara rẹ̀ lọ́wọ́ èyí pẹ̀lú àmì socket ìforíkọjá (**SO_MARK**):

- `realForward` ṣí socket upstream rẹ̀ nípasẹ̀ `connectMarked(ip, port, DEFAULT_BYPASS_MARK)` — `DEFAULT_BYPASS_MARK = 0x539` — èyí tí ó ṣètò **SO_MARK** **ṣáájú** `connect()`, kí SYN ti ìfiranṣẹ́ náà lè gbé àmì ìforíkọjá náà.
- Rule `mangle OUTPUT` yọ àwọn ìsopọ̀ tí wọ́n ti ní àmì ìforíkọjá kúrò (`-m mark ! --mark <bypassMark>`), nítorí náà a **kò** tún fi àmì sí ìfiranṣẹ́ proxy náà, bẹ́ẹ̀ ni kò tún wọ TPROXY.

> Àkíyèsí ìmúṣẹ: a gbọ́dọ̀ fi socket tí a fi àmì ìforíkọjá sí sori
> `createConnection` ti agent (`https.request({ createConnection })` ni a máa ń fojú fò ní ìdákẹ́jẹ́
> nígbà tí agent bá wà), bí bẹ́ẹ̀ kọ́, ìfiranṣẹ́ náà yóò ṣí socket tí kò ní àmì, lúùpù náà
> yóò sì padà. Èyí ni àtúnṣe ìdènà-lúùpù tí a fìdí rẹ̀ múlẹ̀ nípasẹ̀ e2e.

## §7 Lílo / yíyípadà ogiri-iná lọ́nà ìdúnàádúrà

Ìkọlù ètò kò gbọdọ̀ fi òfin `mangle` tàbí ipa-ọ̀nà àtijọ́ sílẹ̀ láé. Olùkọ́ àṣẹ
(`src/mitm/tproxy/commands.ts`) àti olùṣiṣẹ́ (`src/mitm/tproxy/setup.ts`) ṣe ìdánilójú pé
**revert jẹ́ òdìkejì apply gangan, ní ìtòlẹ́sẹẹsẹ àyídá**.

`applyTproxy(cfg)` ń ṣiṣẹ́ àwọn àṣẹ apply ní ìtòlẹ́sẹẹsẹ; lórí **eyikeyi** ìkùnà, ó ń ṣiṣẹ́
`revertTproxy(cfg)` kíkún ní gbogbo agbára rẹ̀, lẹ́yìn náà ó tún ju àṣìṣe náà jáde — nítorí náà, ogiri-iná yóò jẹ́
èyí tí a lò ní kíkún tàbí tí a yí padà ní kíkún, kì í ṣe èyí tí a lò ní ìdajì. `revertTproxy(cfg)` ń ṣiṣẹ́
àwọn àṣẹ òdìkejì ní ìtòlẹ́sẹẹsẹ àyídá, ó sì ń foju kọ àwọn ìkùnà (idempotent — ó láìléwu láti pè é
láìsí àídájú, fún àpẹẹrẹ láti inú ìmọ́tótó AgentBridge `repairMitm()`).

`validateTproxyConfig(cfg)` ń ṣiṣẹ́ kí àṣẹ kankan tó ṣiṣẹ́: àwọn port gbọdọ̀ wà láàárín `1–65535`,
`mark`/`routeTable`/`bypassMark` gbọdọ̀ jẹ́ àwọn odidi rere, `bypassMark` sì gbọdọ̀
yàtọ̀ sí `mark` (ìdènà-lúùpù).

### Àwọn àṣẹ apply (ní ìtòlẹ́sẹẹsẹ)

```bash
ip rule add fwmark <mark> lookup <routeTable>
ip route add local 0.0.0.0/0 dev lo table <routeTable>
iptables -t mangle -A OUTPUT -p tcp --dport <dport> -m mark ! --mark <bypassMark> -j MARK --set-mark <mark>
iptables -t mangle -A PREROUTING -p tcp --dport <dport> -m mark --mark <mark> -j TPROXY --on-port <onPort> --tproxy-mark <mark>
```

Revert ń pa wọ́n rẹ́ ní ìtòlẹ́sẹẹsẹ àyídá: `PREROUTING -D`, `OUTPUT -D`, `ip route del`, `ip rule del`.

> Ìlànà náà dá lórí **OUTPUT** nítorí pé lílo MITM jẹ́ fún traffic outbound _agbegbè_
> (àwọn app lórí host kan náà), èyí tí TPROXY nínú `PREROUTING` nìkan kò lè
> rí — `PREROUTING` ń rí traffic tí a darí síwájú nìkan. Chain `OUTPUT` ń fi àmì sí àwọn
> ìsopọ̀ agbègbè tuntun, `ip rule` ń tún darí wọn sí ìfijiṣẹ́ agbègbè (`lo`), àti
> `PREROUTING` sì ń yàn wọ́n sí listener aláṣípayá náà.

## §8 Ìṣètò

Ìbéèrè ìbẹ̀rẹ̀ (`POST /api/tools/agent-bridge/tproxy`) gba àwọn field wọ̀nyí,
tí `StartTproxyBodySchema` (`tproxy/route.ts`) ń fìdí rẹ̀ múlẹ̀. Gbogbo wọn jẹ́ àṣàyàn
wọ́n sì máa ń lo àwọn iye àiyípadà wọn bí a kò bá pèsè wọn:

| Field            | Irú                | Iye àiyípadà | Àwọn àkíyèsí                                                                                                              |
| ---------------- | ------------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------- |
| **dport**        | int (1–65535)      | `443`        | Port TCP ibi-àfojúsùn láti dá sí lọ́nà aláṣípayá                                                                           |
| **mark**         | int (≥1)           | `0x2333`     | Àmì ogiri-iná tí a ṣètò lórí `OUTPUT`, tí `ip rule` + `PREROUTING` ń bá mu                                                |
| **onPort**       | int (1–65535)      | `8443`       | Port tí listener aláṣípayá (**IP_TRANSPARENT**) so mọ́                                                                     |
| **routeTable**   | int (≥1)           | `233`        | Id tábìlì ìdarí-ipa-ọ̀nà-gẹ́gẹ́-bí-ìlànà tí ó ní ipa-ọ̀nà `local 0.0.0.0/0`                                                   |
| **bypassMark**   | int (≥1, ≠ `mark`) | `0x539`      | Àmì socket àfojúsílẹ̀ (**SO_MARK**) tí proxy ń ṣètò lórí àwọn ìsopọ̀ upstream tirẹ̀; a yọ ọ́ kúrò nínú `OUTPUT` (ìdènà-lúùpù) |
| **sudoPassword** | string             | —            | Fún desktop tí kì í ṣe root nìkan: ó fún fifi trust-store sílẹ̀ ní àṣẹ; a foju kọ ọ́ nígbà tí root bá jẹ́ olùlò              |

Kò sí **àwọn environment variable** fún TPROXY — gbogbo ìṣètò ń wá láti inú
body POST tàbí àwọn iye àiyípadà tó wà lókè.

     kò sí ètò irinṣẹ́ ìkọ́lé, tàbí a kò kọ àfikún náà). Wo [§2](#2-requirements) àti [§3](#3-the-native-ip_transparent-addon).
3. Tẹ bọ́tìnì náà. Ó máa ń pe `POST /api/tools/agent-bridge/tproxy` nípasẹ̀

   ń kọ CA aláyípadà, ń ṣí olùgbọ́ tí ó hàn gbangba, ń lo àwọn òfin ogiri iná,
   tí ó sì ń fi CA náà sínú ibi ìgbẹ́kẹ̀lé OS.
4. Nígbà tí ó bá ń ṣiṣẹ́, yíyípadà náà máa di àwọ̀ amber, yóò sì fi iye ìdásí láàyè hàn
   (`· <interceptCount>`). Àwọn ìbéèrè tí a dá sí máa hàn nínú àtòjọ ìbéèrè pẹ̀lú
   `source: "tproxy"`.
5. Tẹ ẹ lẹ́ẹ̀kan sí i láti dá a dúró — `DELETE /api/tools/agent-bridge/tproxy` nípasẹ̀
   `stopTproxyCaptureMode()` máa pa olùgbọ́ náà, yọ CA náà kúrò, yóò sì dá
   àwọn òfin ogiri iná padà.

Ipò ìpo-gbigba (ń ṣiṣẹ́ / wà / iye ìdásí / pọ́ọ̀tì olùgbọ́) wá
láti `GET /api/tools/agent-bridge/tproxy` (`getCaptureStatus()` nínú

ìgbìyànjú láti bẹ̀rẹ̀ èkejì ni a ó kọ̀ pẹ̀lú "Ìpo gbigba TPROXY ti ń ṣiṣẹ́ tẹ́lẹ̀".

## §10 Yíyanjú àwọn ìṣòro

### A mú yíyípadà náà ṣiṣẹ́ kúrò

A kò lè gbé àfikún abinibi náà wọlé. Jẹ́rìí sí i pé: o wà lórí Linux, o kọ àfikún náà
(`npm run build:native:tproxy`), àti pé ìlànà náà lè gbé `transparent.node` wọlé.
`isTransparentSocketAvailable()` ni ó ń ṣàkóso yíyípadà náà; `GET /api/tools/agent-bridge/tproxy`
máa dá `available: false` padà nígbà tí àfikún náà kò bá sí.

### A kò gba ohunkóhun

- Jẹ́rìí sí i pé ìlànà tí a dá sí ń sopọ̀ mọ́ `dport` tí a ṣètò gan-an
  (àìyípadà ni `443`).
- Jẹ́rìí sí i pé ìlànà náà fọkàn tán CA aláyípadà náà. A fi CA náà sí abẹ́
  `omniroute-tproxy-ca.crt`; àwọn app tí ó ní ibi ìgbẹ́kẹ̀lé tirẹ̀ (Firefox/Chrome NSS)
  lè nílò kí a tún fi cert náà kún ibẹ̀.
- Ṣi ìdánwò ara ẹni **Diagnose** ti AgentBridge (wo
  [`AGENTBRIDGE.md`](../frameworks/AGENTBRIDGE.md)) fún àwọn àyẹ̀wò ìgbẹ́kẹ̀lé cert / ìlera
  server.

### Àwọn òfin ogiri iná àtijọ́ lẹ́yìn ìjàmbá

`revertTproxy()` jẹ́ òdì pàtó ti ìlò, ó sì jẹ́ idempotent. Dídá
ìpo náà dúró máa ń dá àwọn òfin náà padà; tí a bá pa OmniRoute ní àárín àkókò, lo ìṣe
**Repair** ti AgentBridge (`POST /api/tools/agent-bridge/repair`) láti tú ipò ètò
tí kò ní olùdarí (àyípadà DNS, root CA, aṣojú ètò). Àwọn òfin `mangle` TPROXY àti route náà
máa ń fọ ara wọn kúrò nígbà tí ẹ̀rọ bá tún bẹ̀rẹ̀.

### Ìyíká àìlópin / aṣojú náà dá ìfiránṣẹ́ tirẹ̀ sí

Èyí ni ipò ìdènà-yíyípadà. Jẹ́rìí sí i pé `bypassMark` yàtọ̀ sí `mark` (ìmúdájú
fi èyí múlẹ̀) àti pé ìfiránṣẹ́ náà lo `connectMarked` (ó ṣe bẹ́ẹ̀ nínú `realForward`).
Wo [§5 Ìdènà-yíyípadà](#anti-loop-so_mark).
