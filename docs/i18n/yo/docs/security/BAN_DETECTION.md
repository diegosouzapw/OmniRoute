OmniRoute máa ń ṣàyẹ̀wò àwọn ìdáhùn àṣìṣe láti ọ̀dọ̀ àwọn olupèsè upstream fún àwọn àmì tó ń fi hàn pé
**àkọọ́lẹ̀ olupèsè kan ti kú pátápátá** (a ti dá a dúró / a ti mú un kúrò ní ṣíṣiṣẹ́ / a ti fòfin dè é nítorí ToS), àti pé, nígbà tí
àmì kan bá bá a mu, yóò gbé ìsopọ̀ náà sínú **ipò ìkẹyìn `banned`** kí a má bàa
yan án mọ́ fún àwọn ìbéèrè. Èyí ni ohun tí káàdì ààtò **Ààbò → Àwọn Ọ̀rọ̀ Kókó Tí A Fòfin Dè**
ń ṣètò ("Àwọn ọ̀rọ̀ kókó àfikún tí ń fa ìṣàwárí ìfòfindè àkọọ́lẹ̀ pátápátá.
Àwọn ọ̀rọ̀ kókó tí a kọ sínú rẹ̀ láti ìbẹ̀rẹ̀ máa ń lò ní gbogbo ìgbà.").

Ojú-ewé yìí ṣàkọsílẹ̀ àtòjọ tí a kọ sínú rẹ̀ láti ìbẹ̀rẹ̀, bí ìṣàwárí náà ṣe ń ṣiṣẹ́, ààlà rẹ̀, bí a ṣe lè fi
àwọn ọ̀rọ̀ kókó àdáni kún un láìléwu, àti bí a ṣe lè mú ìsopọ̀ tí a ti sàmì sí padà bọ̀ sípò. Ipò ìkẹyìn
náà fúnra rẹ̀ jẹ́ apá kan àwòṣe ìfaradà — wo
[RESILIENCE_GUIDE](../architecture/RESILIENCE_GUIDE.md) ("Àwọn ipò ìkẹyìn").

**Orísun òtítọ́:** `open-sse/services/accountFallback.ts`
(`ACCOUNT_DEACTIVATED_SIGNALS`, `getMergedBannedSignals()`, `isAccountDeactivated()`).

## Àwọn ọ̀rọ̀ kókó tí a kọ sínú rẹ̀ láti ìbẹ̀rẹ̀

Àwọn ọ̀rọ̀ abẹ́-okùn mẹ́jọ wọ̀nyí máa ń lò ní gbogbo ìgbà (láìka bóyá lẹ́tà ńlá tàbí kékeré), láìka àtòjọ àdáni èyíkéyìí sí:

```
account_deactivated
account has been deactivated
account has been disabled
your account has been suspended
this account is deactivated
verify your account to continue                                 (Antigravity / Google Cloud Code)
this service has been disabled in this account for violation    (Antigravity)
this service has been disabled in this account                  (Antigravity)
```

> Àtòjọ yìí máa ń yí padà bí àwọn olupèsè ṣe ń yí ọ̀nà tí wọ́n fi ń sọ ìfòfindè padà. Ẹ̀dà
> aláṣẹ ni `ACCOUNT_DEACTIVATED_SIGNALS` nínú `open-sse/services/accountFallback.ts`;
> ka búlọ́ọ̀kù òkè yìí sí àwòrán ìgbà kan.

Àwọn tábìlì àmì méjì tó wà lẹ́gbẹ̀ẹ́ ara wọn, tí wọ́n sì **yàtọ̀**, wà nínú fáìlì kan náà, wọn kò sì jẹ́ apá
ìṣàwárí ọ̀rọ̀ kókó ìfòfindè:

- `CREDITS_EXHAUSTED_SIGNALS` — owó ìsanwó/ìpín ti tán (`insufficient_quota`,
  `credit_balance_too_low`, `payment required`, …) → ipò ìkẹyìn `credits_exhausted`.
- `OAUTH_INVALID_TOKEN_SIGNALS` — **kì í ṣe ipò ìkẹyìn**; ìsọ̀tun token lè mú un padà bọ̀ sípò.

Àkíyèsí: àwọn gbólóhùn ìgbà díẹ̀ tó wọ́pọ̀ bí **`rate limit`** / `429` ni ipa-ọ̀nà
ààlà-oṣùwọ̀n / ìsinmi-ìsopọ̀ ń bójú tó, wọn kò sì jẹ́ àwọn àmì ìfòfindè.

## Bí ìṣàwárí ṣe ń ṣiṣẹ́

```
ìdáhùn àṣìṣe láti upstream
  → yí body padà sí string + lẹ́tà kékeré
  → isAccountDeactivated(body): getMergedBannedSignals().some(sig => body.includes(sig))   [ìbámu abẹ́-okùn]
  → ó bá a mu?
      → connection testStatus = "banned"      (títí láé — ìsinmi ọdún 1, kì í padà bọ̀ sípò fúnra rẹ̀ láé)
      → bí ààtò `autoDisableBannedAccounts` bá wà ní títàn, tí `autoDisableBannedScope` sì
        ní ìsopọ̀ yìí nínú (`all`, tàbí `subscription` fún OAuth/cookie/session)
        → pẹ̀lú isActive = false. Àwọn API keys tí a ti sanwó fún ṣáájú máa ń dúró ní ṣíṣiṣẹ́ nígbà tí scope jẹ́
        `subscription`.
      → a máa foju ìsopọ̀ náà kọ nígbà yíyan àkọọ́lẹ̀ (àwọn ipò QUOTA_BLOCKING combo)
```

- Ìbámu náà jẹ́ ìṣàwárí **abẹ́-okùn tí kò ka lẹ́tà ńlá tàbí kékeré sí** lórí **body**
  ìdáhùn (`isAccountDeactivated`, `accountFallback.ts`).
- Ṣíṣe e di ipò ìkẹyìn `banned` títí láé máa ń ṣẹlẹ̀ lórí body tó ní àmì ìfòfindè ní **ipò
  HTTP èyíkéyìí** (nípasẹ̀ `markAccountUnavailable` → `checkFallbackError`). Àmì
  **`deactivated`** tó ní ààlà díẹ̀ sí i (`isActive=false` nígbà tí ìsopọ̀ náà kò ní
  àwọn API keys àfikún) ni ipa-ọ̀nà inline `chatCore.ts` ń kọ sílẹ̀ lórí **HTTP 401 / 403**
  (tí a pín sí ẹ̀ka nípasẹ̀ `classifyProviderError` → `ACCOUNT_DEACTIVATED`). Ṣàkíyèsí pé
  ipa-ọ̀nà `markAccountUnavailable()` máa ń kọ ipò ìkẹyìn tó _yàtọ̀_ —
  **`expired`** — fún àmì `ACCOUNT_DEACTIVATED` kan náà (nípasẹ̀
  `resolveTerminalConnectionStatus`), nítorí náà ìfòfindè kan náà lè farahàn gẹ́gẹ́ bí
  `deactivated` tàbí `expired`, ó da lórí ipa-ọ̀nà tó bójú tó ìdáhùn náà. (Àlàyé kóòdù
  àtijọ́ sọ pé "nígbà tí body 401 kan bá ní àwọn string wọ̀nyí" — èyí kò sọ gbogbo
  ìwà lọ́wọ́lọ́wọ́.)
- A máa yọ ìsopọ̀ `banned` kúrò nínú yíyan ní gbogbo ibi tí a ti ń ṣe àlẹ̀mọ́ àwọn ipò ìkẹyìn
  (`isTerminalConnectionStatus`, combo `QUOTA_BLOCKING_CONNECTION_STATUSES`).

## Ìwọ̀n — àwọn olùpèsè wo ni a máa ṣàyẹ̀wò

**Gbogbo àwọn olùpèsè.** Àyẹ̀wò náà ń ṣiṣẹ́ nínú ọ̀nà ìṣàkóso àṣìṣe gbogbogbò tí gbogbo ìbéèrè upstream tí ó kùnà ń gbà kọjá — kò **dá lórí** àwọn scraper OAuth/subscription nìkan. Ipò terminal tí ó yọrí sí jẹ́ ti **àsopọ̀** kọ̀ọ̀kan, kì í ṣe ti olùpèsè kọ̀ọ̀kan.

Síbẹ̀, àwọn _ọ̀rọ̀_ tí a fi sínú rẹ̀ tẹ́lẹ̀ dá lórí àwọn olùpèsè subscription/OAuth tí ewu ìfòfindè gidi wà fún wọn (ChatGPT Web Codex, Claude Web, Codex, Muse Spark, Antigravity). Olùpèsè API-key kan yóò fa detector náà ṣiṣẹ́ kìkì bí ara àṣìṣe rẹ̀ bá ní ọ̀kan lára àwọn substring náà gẹ́gẹ́ bí a ṣe kọ ọ́ gan-an.

`autoDisableBannedScope` (`all` | `subscription`, àìyípadà rẹ̀ ni `all`) ń ṣàkóso bóyá ìbámu kan yóò tún yí `isActive=false`. `subscription` túmọ̀ sí àwọn seat tí wọ́n ń wọlé sí (àwọn subscription tí a sanwó fún àti àwọn àkọọ́lẹ̀ ọ̀fẹ́, pẹ̀lú àwọn session web-cookie). Ó ṣì máa ń ṣàkọsílẹ̀ `testStatus=banned` fún àwọn API key tí a ti sanwó wọn ṣáájú, ṣùgbọ́n ó fi wọ́n sílẹ̀ nínú routing pool. Àpẹẹrẹ tó lè dúró pẹ́ ni override fún olùpèsè kọ̀ọ̀kan àti àkọọ́lẹ̀ kọ̀ọ̀kan; enum gbogbogbò ni ìgbésẹ̀ àkọ́kọ́.

## Àwọn ọ̀rọ̀ ìfòfindè àdáni

Ṣàfikún tàbí yọ àwọn ọ̀rọ̀ kúrò ní **Security → Banned Keywords** (tí a tọ́jú gẹ́gẹ́ bí ètò gbogbogbò `customBannedSignals` nípasẹ̀ `PATCH /api/settings`). A máa **ṣàfikún wọn sí** àtòjọ tí a fi sínú rẹ̀ tẹ́lẹ̀ — wọn kì í rọ́pò rẹ̀ láé — wọ́n sì máa ń tún kojọpọ̀ lẹ́sẹ̀kẹsẹ̀ nígbà ìfipamọ́ (àti nígbà ìbẹ̀rẹ̀) nípasẹ̀ `setCustomBannedSignals()`. Ọ̀rọ̀ kọ̀ọ̀kan kò lè ju lẹ́tà 200 lọ; kò sí ààlà fún gígùn array náà.

**⚠ Ewu false-positive — yan àwọn gbólóhùn pàtó.** Ìṣàwárí náà jẹ́ ìbámu substring tààrà lórí gbogbo ara ìdáhùn náà, ìbámu kan sì jẹ́ **títí láé** (cooldown ọdún 1, ìmúpadàbọ̀sípò ọwọ́). Ọ̀rọ̀ tí ó gbòòrò lè fòfin de àsopọ̀ tí ó ní ìlera pípé:

- **Kò dáa:** `quota`, `limit`, `error`, `denied` — wọ́n máa ń hàn nínú ọ̀pọ̀ àṣìṣe tí ó jẹ́ ti ìgbà díẹ̀.
- **Ó dáa:** gbogbo gbólóhùn ìfòfindè, bí àpẹẹrẹ `your account has been suspended for`,
  `account permanently banned`, `violation of our terms`.

Yan gbólóhùn tó gùn jù lọ tí kò ní ìtumọ̀ méjì, tí olùpèsè náà máa ń dá padà nígbà ìfòfindè gidi. Bí o bá ń ṣiyèméjì, kọ́kọ́ wo `lastError` àsopọ̀ náà, lẹ́yìn náà ṣàfikún ọ̀rọ̀ náà gẹ́gẹ́ bí a ṣe kọ ọ́ gan-an.

## Mímú àsopọ̀ tí a ti sàmì sí padà

Àwọn ipò terminal `banned` / `deactivated` **kì í mú ara wọn padà láé** (a yọ wọ́n kúrò nínú tick proactive-recovery — àwọn cooldown `unavailable` nìkan ni wọ́n máa ń padà fúnra wọn). Olùdarí gbọ́dọ̀ pa wọ́n rẹ́ ní kedere:

1. **Tún àsopọ̀ náà dánwò** — iṣẹ́ **Test** lórí dashboard
   (`POST /api/providers/{id}/test`); probe tí ó ṣàṣeyọrí máa ń tún `testStatus` padà sí
   `active`, ó sì máa ń pa àwọn field àṣìṣe rẹ́.
2. **Tún ìfàṣẹsí ṣe / ṣàtúnṣe credentials** — fún àwọn olùpèsè OAuth, tún login
   / refresh flow ṣiṣẹ́; àwọn route create/import ti olùpèsè máa ń ṣètò `isActive = true`.
3. **Tún àsopọ̀ náà mú ṣiṣẹ́** — bí auto-disable bá ṣètò `isActive = false`
   (scope `all`, tàbí `subscription` fún àsopọ̀ OAuth/cookie/session),
   tún un tan lẹ́yìn títún àkọọ́lẹ̀ náà ṣe.

Kò sí bọ́tìnì "clear ban flag" lọ́tọ̀ — ìmúpadàbọ̀sípò jẹ́ títún dánwò, títún ìfàṣẹsí ṣe, tàbí títún mú un ṣiṣẹ́, ní ìbámu pẹ̀lú òfin gbogbogbò fún terminal-state nínú
[RESILIENCE_GUIDE](../architecture/RESILIENCE_GUIDE.md).

## Ìyàsọ́tọ̀ probe (model test-all)

**Ìkùnà tó pilẹ̀ láti probe** (model test-all / àwọn ìfiránṣẹ́ health-check tí a ṣe nínú `runAsProbe`) kì í yọ àsopọ̀ kan kúrò nínú pool láé (#9817): a máa **ṣàkọsílẹ̀ rẹ̀ kí ó lè hàn** (`last_error`, `last_error_type`, `error_code`,
`last_error_at`) ṣùgbọ́n a máa fo **gbogbo** ìyípadà routing kọjá — àwọn cooldown, ipò terminal (`banned` / `deactivated` / `credits_exhausted`), àwọn lockout fún model kọ̀ọ̀kan, provider circuit breaker, cache quota ìṣẹ́jú 5, OAuth token refresh àti auto-disable. Ìkùnà kan láti ọ̀nà ìbéèrè gidi nìkan ló máa ń pa á. Àṣìṣe tí a ṣàkọsílẹ̀ náà ló mú kí àkọọ́lẹ̀ tí a sàmì sí hàn lórí dashboard nígbà tí ó ṣì ń pèsè traffic.

Ojú ìpinnu kan ṣoṣo ni `shouldIsolateProbeFailures()`
(`src/shared/utils/probeOrigin.ts`), èyí tí **gbogbo** ibi tó lè yí ipò routing padà láti inú ìkùnà tó pilẹ̀ láti probe máa ń tọ́ka sí:

- `markAccountUnavailable` (`auth.ts`) — ṣàkọsílẹ̀-nìkan (`lastError` gẹ́gẹ́ bí raw text,
  `lastErrorType`, `errorCode`, `lastErrorAt`; a mọ̀ọ́mọ̀ **kò** fi
  `backoffLevel` sí i, nítorí èyí yóò fa selection-time auto-decay tí yóò sì nu
  àkọsílẹ̀ náà rẹ́)
- `maybeAutoDisableBannedAccount` — kò sí auto-disable
- `chatCore` — FORBIDDEN, ACCOUNT_DEACTIVATED, QUOTA_EXHAUSTED (ṣàkọsílẹ̀-nìkan,
  kò sí terminal `credits_exhausted`), GEO_BLOCKED (kò sí ìyọkúrò 24h),
  MODEL_NOT_FOUND (kò sí `lockModel`), codex 429 account-rotation failover
  (kò sí `markCodexScopeRateLimited`, kò sí `rate_limited_until` tí a tọ́jú, kò sí
  pípa session-affinity rẹ́), `persistCodexQuotaState` (kò sí kíkọ quota-state,
  kò sí cache invalidation), `recordKeyHealthStatus` (key-health rotator
  kò ní ìyípadà)
- OAuth refresh — mejeeji proactive refresh nínú executor base
  (`base.ts` `execute()`, kò sí refresh-token rotation tí a lò) àti
  reactive 401/403 path nínú `chatCore` (kò sí `expired` deactivation)
- `chat.ts` — provider circuit breaker àti cache quota ìṣẹ́jú 5
  (`markAccountExhaustedFrom429`) kì í dín agbára kù láé

Àṣìṣe tí a ṣàkọsílẹ̀ náà ló mú kí àkọọ́lẹ̀ tí a sàmì sí hàn lórí dashboard
nígbà tí ó ṣì ń pèsè traffic. Àkíyèsí: àkọsílẹ̀ probe máa ń tọ́jú ọ̀rọ̀ àṣìṣe **raw**
(tí a kò gé kúrú), yàtọ̀ sí gígé ti ọ̀nà gidi náà pẹ̀lú `slice(0,100)`.

Àwọn olùdarí tí wọ́n ń lo test-all gẹ́gẹ́ bí irinṣẹ́ maintenance lè mú ìhùwàsí ìṣáájú padà (probe máa kà bí generation gidi) nípasẹ̀ ọ̀kan nínú àwọn wọ̀nyí:

- ètò `probeCanDisable` (`POST /api/settings` pẹ̀lú
  `{"probeCanDisable": true}`, tàbí àtúnṣe `key_value` DB tààrà), tàbí
- feature flag **`PROBE_CAN_DISABLE=true`** (env tàbí DB override; ó borí
  ètò náà).

Ààbò nígbà ìkùnà: bí wíwá flag tàbí settings bá ju àṣìṣe, ìyàsọ́tọ̀ yóò ṣì wà ní ON.
