Ẹnu-ọ̀nà upstream `agentrouter` ń ṣiṣẹ́ àlẹ́mọ́ àkóónú tó dá lórí ọ̀rọ̀ pàtó lórí
`messages[].content`. Àlẹ́mọ́ náà jẹ́ onípinnu ní apá kan (ó máa ń dí
àwọn gbólóhùn kan ní gbogbo ìgbà) ó sì jẹ́ aláìdánilójú ní apá kan (ó máa ń fèsì sí
ìbéèrè tó pọ̀ lójijì — ó máa ń le sí i lẹ́yìn àwọn ìbéèrè tó yára tẹ̀lé ara wọn, ó sì máa ń
padà sí bó ṣe yẹ lẹ́yìn àkókò ìsinmi).

Nígbà tí WAF bá dí ìbéèrè kan, ó máa ń dá èyí padà:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Ìwọ̀n àlẹ́mọ́ náà

WAF ń ṣàyẹ̀wò `messages[].content` nìkan. Kò **ṣàyẹ̀wò**:

- Àṣẹ ìbẹ̀rẹ̀ `system`
- Àwọn ìdínà àkóónú tó ní ìṣètò (`tool_result`, `tool_use`, `thinking`, `image`)
- Àwọn pápá `description` àti `input_schema` ti irinṣẹ́
- Metadata ìbéèrè, àwọn header, tàbí model id

## Àwọn àpẹẹrẹ tí a máa ń dí ní gbogbo ìgbà (láìka lẹ́tà ńlá tàbí kékeré sí)

| Àpẹẹrẹ                          | Àwọn àkíyèsí                                               |
| ------------------------------- | ---------------------------------------------------------- |
| Èyíkéyìí irú `Lorem ipsum`      | Gbogbo àwọn ọ̀rọ̀ Lorem èdè Latin ni a dí                    |
| `language model` (ní òun nìkan) | "the language model" àti "large language model" máa ń kọjá |
| `virtual assistant`             | "AI assistant" máa ń kọjá                                  |
| `I'm here to help`              | "here to help" ní òun nìkan náà ni a máa ń dí              |
| `Claude, made by Anthropic`     | Gbogbo gbólóhùn náà nìkan                                  |

## Àwọn àpẹẹrẹ tí a fẹ́rẹ̀ẹ́ máa ń dí ní gbogbo ìgbà

| Àpẹẹrẹ                                                          | Àwọn àkíyèsí                                                           |
| --------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `placeholder`                                                   | Nígbà tó bá dúró ní òun nìkan (kì í ṣe gẹ́gẹ́ bí orúkọ parameter, abbl.) |
| `dummy data`                                                    | Gbólóhùn seed tí ó wọ́pọ̀ fún fixtures                                   |
| `foo bar baz`                                                   | Gbólóhùn placeholder àfọwọ́ṣe                                           |
| Àwọn token kúkúrú tí a tún sọ (`AAA BBB CCC`, `test test test`) | Olùṣàwárí fún kíkó àwọn keyword jọ lọ́pọ̀                                |

## Ìhùwàsí lábẹ́ ẹrù iṣẹ́

Lẹ́yìn nǹkan bí ìbéèrè yíyára 5 láàárín àkókò kúkúrú, WAF máa ń bẹ̀rẹ̀ sí í dí àkóónú
tí yóò kọjá nígbà míì. Bucket náà máa ń tú sílẹ̀ lẹ́yìn nǹkan bí ìṣẹ́jú-ààyá 5–10 tí
kò sí ìgbòkègbodò. Èyí ni rate limiter kan náà tó so mọ́ IP àti key, tó sì ń fa
àwọn àṣìṣe `400 content-blocked` aláìgbàdéédé nígbà tí Claude Code tàbí Codex CLI
bá ṣe ọ̀pọ̀ ìpè tool-use / message-send ní kíákíá léraléra.

## Àwọn ọ̀nà ìdènà tí a ti lò nínú OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — burst guard tó ń fipá mú kí
   àlàfo tó kéré jù jẹ́ 500 ms láàárín àwọn ìbéèrè outbound sí URL
   `agentrouter:*` èyíkéyìí. Àlàfo náà kéré gan-an ju ohun tí ènìyàn lè ṣàkíyèsí gẹ́gẹ́ bí latency lọ, ó sì ń dènà
   WAF láti ṣiṣẹ́ lórí traffic bó ṣe yẹ.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — nígbà tí upstream kan bá dá
   `400 content-blocked` padà, executor náà máa ń tún URL kan náà gbìyànjú pẹ̀lú
   exponential backoff (1.5 s, 3.0 s, max 2 attempts). Lẹ́yìn backoff náà,
   WAF sábà máa ń tú sílẹ̀, ìgbìyànjú tuntun náà sì máa ń ṣàṣeyọrí.

3. **`tests/unit/compression/harness.test.ts`** — test fixture náà
   `longInput` ni a yí padà láti `"lorem ipsum dolor sit amet ".repeat(40)`
   sí `"example content for testing purposes ".repeat(40)` kí nígbà tí
   Claude Code bá ka fáìlì yìí nípasẹ̀ irinṣẹ́ `Read`, àkóónú fáìlì náà
   má bàa tún ṣàn padà nípasẹ̀ ìdínà `tool_result` kí ó sì mú WAF ṣiṣẹ́.

## Ìtọ́sọ́nà fún àwọn àṣẹ àti àbájáde irinṣẹ́

Tí session Claude Code tàbí Codex CLI kan bá ń kọlu
`400 content-blocked` léraléra, ṣàyẹ̀wò ìfiránṣẹ́ olumulo tó ṣẹ̀ṣẹ̀ dé àti àbájáde
irinṣẹ́ tó ṣẹ̀ṣẹ̀ dé fún èyíkéyìí lára àwọn àpẹẹrẹ tó wà lókè, kí o sì tún un sọ ní ọ̀nà míì. Àwọn
ọ̀nà àbáyọ tó wọ́pọ̀:

- Rọ́pò `Lorem ipsum …` pẹ̀lú `example text …` tàbí àkóónú gidi
  tí test tàbí fixture náà ń gbìyànjú láti ṣàpẹẹrẹ.
- Rọ́pò `placeholder` (nígbà tó bá dúró ní òun nìkan) pẹ̀lú `example value`,
  `sample value`, tàbí iye gidi.
- Rọ́pò `language model` pẹ̀lú `large language model` tàbí `the model`.
- Rọ́pò `dummy data` pẹ̀lú `sample data` tàbí àwọn iye seed tó jọ òótọ́.
- Rọ́pò `I'm here to help` / `here to help` pẹ̀lú ọ̀rọ̀ ìbẹ̀rẹ̀ tó ṣe pàtó sí i
  (fún àpẹẹrẹ, "I'll review the file you mentioned").

## Jíjíṣẹ́ ìròyìn nípa àwọn false positive sí upstream

Àlẹ́mọ́ lọ́wọ́lọ́wọ́ le jù — ó máa ń dí "Lorem ipsum" nínú
àwọn ìdínà `tool_result` bó tilẹ̀ jẹ́ pé ó hàn kedere pé operator náà kò fẹ́
fi àṣẹ sínú rẹ̀. Àwọn operator tó fẹ́ kí a tún èyí ṣe láti orísun rẹ̀ gbọ́dọ̀
kàn sí `agentrouter.org` láti fi àwọn false positive náà tó wọn létí. Blocklist
tó wà lókè ni àbájáde ìdánwò upstream tí a ṣe ní 2026-08-03.
