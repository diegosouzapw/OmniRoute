> **Àkíyèsí ààlà:** `socket.yml` ń ṣètò àyẹ̀wò Socket.dev lẹ́yìn ìtẹ̀jáde ní ẹ̀gbẹ́ registry lórí artifact npm (àwọn ipa-ọ̀nà tí a máa foju kọ fún àkóónú tí a kò fi ránṣẹ́, bíi `tests/`, `docs/`, àti àwọn ìròyìn build). Kì í ṣe ohun tó ń so ẹnu-ọ̀nà ìdapọ̀ CI/PR pọ̀ — kò sí workflow kankan nínú `.github/workflows`, kò sí script `package.json` kankan, bẹ́ẹ̀ ni kò sí target `Makefile` kankan tó ń pe Socket.dev.

Ìwé yìí ni ìjẹ́rìísí tí olùtọ́jú kọ fún àwọn àbájáde mẹ́fà
`malware tó ṣeé ṣe tí AI ṣàwárí` tí a gbé dìde sí `omniroute@3.8.5`, àti
àwọn ìgbésẹ̀ ìdínkù-ewu tí a lò nínú `omniroute@3.8.6`. Ó wà kí:

1. Àwọn olùṣiṣẹ́ pipeline ààbò lè ní ìtọ́kasí kan ṣoṣo láti tọ́ka sí nígbà tí wọ́n bá nílò
   láti ṣe àyẹ̀wò àwọn àbájáde náà pẹ̀lú source gangan.
2. Àwọn scanner AI ọjọ́ iwájú lè rí ìkéde tí olùtọ́jú fọwọ́ sí pé ọ̀kọ̀ọ̀kan
   ipa-ọ̀nà tí a sàmì sí jẹ́ èyí tí a mọ̀ọ́mọ̀ ṣe, tí olùlò gbọ́dọ̀ yàn láti lo, tí a sì ṣàkọsílẹ̀ rẹ̀.
3. Kí a ní àkọsílẹ̀ ní kíkọ nípa _ìdí_ tí a fi ṣe ọ̀kọ̀ọ̀kan call site ní ọ̀nà tó rí —
   kí refactor ọjọ́ iwájú má bàa tún fingerprint kan padà láìmọ̀ọ́mọ̀,
   èyí tí a ti mọ̀ọ́mọ̀ yọ kúrò.

Tí ẹ bá ń ṣiṣẹ́ scanner kan tó tún sàmì sí èyíkéyìí nínú àwọn call site tó wà nísàlẹ̀ lẹ́yìn tí
àwọn ìgbésẹ̀ ìdínkù-ewu v3.8.6 bá ti jáde, ẹ jọ̀wọ́ ṣí issue kan pẹ̀lú trace àyẹ̀wò náà,
àwa yóò sì fa ìjẹ́rìísí tó wà níbí gùn sí i.

## §1 — Fífi root-CA MITM sílẹ̀ (`77484.js`)

**Àwọn fáìlì orísun**:

- `src/mitm/cert/install.ts` — `installCert()` / `uninstallCert()` gbogbogbò,
  àti `installCertWindows/Mac/Linux` fún platform kọ̀ọ̀kan.
- `src/mitm/systemCommands.ts` — àwọn olùrànlọ́wọ́ `execFile` / `spawn` / PowerShell
  tí gbogbo àwọn ipa-ọ̀nà ìfísílẹ̀ ń lò.

**Ohun tó ń mú un ṣiṣẹ́**: aṣàmúlò tẹ "Mú proxy MITM ṣiṣẹ́" nínú dashboard agbègbè ní
`/dashboard/cli-tools/mitm`. Route náà jẹ́ ti loopback nìkan — wo òfin líle #17 nínú
`CLAUDE.md` àti `src/server/authz/routeGuard.ts::isLocalOnlyPath()`. JWT kan tí ó tú jáde
nípasẹ̀ tunnel **kò lè** mú ipa-ọ̀nà kóòdù yìí ṣiṣẹ́.

**Àwọn iṣẹ́ tó nílò àṣẹ gíga tí a ṣe (fún platform kọ̀ọ̀kan)**:

| OS                     | Àṣẹ/Àwọn àṣẹ                                                                                                      |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Windows                | `certutil -addstore Root <cert>` nípasẹ̀ UAC                                                                       |
| macOS                  | `sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain <cert>`                     |
| Linux                  | `sudo cp <cert> <distro-trust-dir>` + `sudo update-ca-certificates` (Debian) / `sudo update-ca-trust` (RHEL/SUSE) |
| Linux+Firefox/Chromium | ìmúdójúìwọ̀n NSS DB fún profile kọ̀ọ̀kan nípasẹ̀ `certutil -d sql:<profile>`                                          |

Àwọn wọ̀nyí jẹ́ àwọn àṣẹ kan náà tí `mitmproxy`, Charles Proxy, Fiddler, àti
Caddy ń lò. Òtítọ́ pé wọ́n wà nínú OmniRoute ni a ṣe àkọsílẹ̀ rẹ̀ ní
`docs/security/STEALTH_GUIDE.md`.

**Ìgbésẹ̀ ìdènà v3.8.6**:

- `runElevatedPowerShell()` kò tún lo `-EncodedCommand <base64utf16le>` mọ́.
  A kọ payload tó ní àṣẹ gíga sí fáìlì `.ps1` temp kan fún ìpè kọ̀ọ̀kan (mode 0o600,
  nínú directory `mkdtempSync` aládàáni) a sì tọ́ka sí i nípasẹ̀ `-File`. A yọ
  fáìlì náà kúrò nínú `finally`. Èyí yọ àpẹẹrẹ ìdánimọ̀
  ìgbéga-àṣẹ-nípasẹ̀-PowerShell-pẹ̀lú-base64 tí a sábà máa ń rí, èyí tí olùṣètòsọ̀rí AI
  Socket.dev sàmì sí.
- `installCertWindows` ní block `SECURITY-AUDITOR-NOTE:` inú ìlà
  tó ń tọ́ka sí ibí.

**Ìdí tí a fi pa á mọ́**: proxy MITM jẹ́ ẹ̀ya kan tí a ti ṣe àkọsílẹ̀ rẹ̀, tí
`docs/security/STEALTH_GUIDE.md` àti `docs/frameworks/MITM-PROXY.md` ń lò. Yíyọ
ọ́ kúrò yóò ba àkójọpọ̀ àwọn ẹ̀ya agent-bridge jẹ́.

## §2 — Gbígbé ẹ̀rí Zed wọlé (`app/api/providers/zed/import/route.js`)

**Àwọn fáìlì orísun**:

- `src/app/api/providers/zed/discover/route.ts` _(tuntun ní v3.8.6)_
- `src/app/api/providers/zed/import/route.ts`
- `src/lib/zed-oauth/keychain-reader.ts`
- `src/lib/zed-oauth/credentialFingerprint.ts` _(tuntun ní v3.8.6)_

**Ohun tó ń mú un ṣiṣẹ́**: aṣàmúlò tẹ "Gbé wọlé láti Zed" ní ojú-ìwé àwọn Olùpèsè lórí dáṣíbọ́ọ̀dù agbègbè. `requireManagementAuth` ló ń ṣàkóso ààyè sí endpoint náà. Ẹ̀rọ àtúnṣe Zed fúnra rẹ̀ ń kọ àwọn kọ́kọ́rọ́ API olùpèsè rẹ̀ sínú ibi ìpamọ́ kọ́kọ́rọ́ OS lábẹ́ àwọn orúkọ iṣẹ́ tí a ṣàkọsílẹ̀ — wo https://zed.dev/docs/ai/llm-providers.

**Ìhùwàsí v3.8.5 (èyí tí Socket.dev sàmì sí)**:

`POST /import` ṣàwárí àwọn ẹ̀rí náà, ó sì fi wọ́n pamọ́ fúnra rẹ̀ sínú ibi ìpamọ́ SQLite agbègbè ní ìjápọ̀ kan ṣoṣo. Kò sí ìmúdájú fún àkọọ́lẹ̀ kọ̀ọ̀kan, kò sí ìtẹ̀ka-ìka, kìkì "a rí token N, a sì gbé gbogbo wọn wọlé."

**Ìdínkù ewu v3.8.6 — ìmúdájú onígbésẹ̀ méjì**:

1. **`POST /api/providers/zed/discover`** dá
   `{ candidates: [{ provider, service, account, fingerprint }] }` padà. A **kì í** fi token gidi ránṣẹ́ rárá. Ìtẹ̀ka-ìka náà ni
   `sha256(service|account|token).slice(0,16)`.
2. Dáṣíbọ́ọ̀dù náà ṣàfihàn àkójọ àwọn olùdíje, olùṣàkóso yan àwọn tí yóò
   gbé wọlé, ó sì fi `{ confirmedAccounts: [{ service, account, fingerprint }] }`
   ránṣẹ́ sí **`POST /api/providers/zed/import`**.
3. Endpoint gbígbéwọlé náà **tún ka ibi ìpamọ́ kọ́kọ́rọ́ lórí server** ó sì ṣe àsẹ̀ nípasẹ̀
   `(service, account, fingerprint)`. Ìdáhùn discover tí a ti yí padà tàbí tí a tún lò
   kò lè tan endpoint gbígbéwọlé náà láti fi token tí kò ní í ṣe pẹ̀lú rẹ̀ pamọ́ —
   bí token tó wà lọ́wọ́ bá ti yí padà lẹ́yìn discover, ìtẹ̀ka-ìka náà kò ní
   bá a mu mọ́, a ó sì fo ẹ̀rí náà.

Àmì env `OMNIROUTE_ZED_IMPORT_LEGACY_ONE_STEP=true` ń pa ìhùwàsí v3.8.5 mọ́
fún àwọn olùṣàkóso tí kò tíì ṣe ìmúdójúìwọ̀n àìfọwọ́ṣe wọn. A ó yọ ọ́ kúrò
ní v3.9.

**Ìdí tí a fi pa á mọ́**: Gbígbé wọlé láti Zed ni ọ̀nà ìbẹ̀rẹ̀ tó rọrùn jù lọ fún àwọn aṣàmúlò
tí wọ́n ti ń lo Zed tẹ́lẹ̀, tí wọ́n sì fẹ́ da àwọn kọ́kọ́rọ́ olùpèsè wọn sínú OmniRoute
láì tún wọn lẹ̀ mọ́.

## §3 — `execFile` / `spawn` / PowerShell aláṣẹ-gíga (`21843.js`)

**Àwọn fáìlì orísun**: `src/mitm/systemCommands.ts`.

**Ìdí tí a fi sàmì sí i**: chunk náà tún ń kó `execFileWithPassword`,
`runElevatedPowerShell`, àti olùrànlọ́wọ́ `quotePowerShell` tí wọ́n jọ ń lò jáde. Ẹ̀rọ ìsọ̀rí AI ti Socket.dev
rí wọn bíi “àkójọpọ̀ irinṣẹ́ gbogbogbò fún mímú nǹkan ṣiṣẹ́ lórí host + gbígbé àṣẹ ga.”
Nínú OmniRoute, ọ̀nà fífi cert MITM sí ẹ̀rọ (§1) àti `execFileWithPassword`
fún mímú àṣẹ `sudo` ṣiṣẹ́ nìkan ló ń lò wọ́n.

**Ìdínkù ewu v3.8.6**:

- Àtúnṣe `runElevatedPowerShell` (wo §1).
- Àkójọpọ̀ `SECURITY-AUDITOR-NOTE:` inú ìlà níbi
  `runElevatedPowerShell` àti `execFileWithPassword` ń ṣàkọsílẹ̀ àwọn olùpè tí a fọwọ́sí
  àti àkójọ executable tí a ti dì mú.
- Ìpè `spawn()` ti `execFileWithPassword` ní àmì `nosemgrep` pẹ̀lú
  àkójọ àwọn executable tí a fọwọ́sí fún olùrànlọ́wọ́ náà láti gbà — **kò sí
  ọ̀nà láti inú ìwọlé aṣàmúlò sí `finalCommand`/`finalArgs`**.

## §4 / §6 — Alábòójútó iṣẹ́ 9router (`api/services/9router/{start,restart}/route.js`)

**Àwọn fáìlì orísun**:

- `src/app/api/services/9router/{start,stop,restart,status,install,update,auto-start}/route.ts`.
- `src/lib/services/ServiceSupervisor.ts` — spawn gbogbogbò / ṣíṣe àyẹ̀wò ìlera léraléra / ibi ìdádúró log.

**Ohun tó ń mú un ṣiṣẹ́**: aṣàmúlò tẹ "Fi sí ẹrọ" / "Bẹ̀rẹ̀" lórí ojú-ìwé àwọn iṣẹ́ tí a fi sínú
dáṣíbọ́ọ̀dù agbègbè.

**Àwọn ààbò tó ti wà nílẹ̀**:

- Gbogbo route `/api/services/*` jẹ́ LOCAL_ONLY gẹ́gẹ́ bí
  `src/server/authz/routeGuard.ts` (òfin líle #17). Ìfipámú loopback
  máa ń ṣẹlẹ̀ ṣáájú àyẹ̀wò ìfàṣẹsí èyíkéyìí — JWT tó tú jáde kò lè dé ọ̀dọ̀ wọn.
- A gbin ìlà DB 9router gẹ́gẹ́ bí `status='not_installed', auto_start=0` (wo
  `src/lib/db/migrations/071_services.sql:19`). Iṣẹ́ náà **kì í** bẹ̀rẹ̀
  nígbà ìṣílọ́lẹ̀ àkọ́kọ́.
- A ń pe `spawn()` pẹ̀lú ipa-ọ̀nà binary tí
  `resolveSpawnArgs(apiKey, PORT)` dá padà nínú `src/lib/services/installers/ninerouter.ts`,
  èyí tí ó jẹ́ àkójọ binary tí a ṣe àtìlẹ́yìn fún, tí a sì ti dì mú.
- A ń fi Stdout/stderr pamọ́ sínú ìrántí fún ìgbà díẹ̀ (ìwọ̀n tó pọ̀ jù jẹ́ 5 MB, wo `_lib.ts`) — kò sí
  kíkọ sórí disk àyàfi bí aṣàmúlò bá tan logging láti inú dáṣíbọ́ọ̀dù.

**Ìdínkù ewu v3.8.6**: kò sí ìyípadà iṣẹ́. Profaili ìkọ́lé tó kéré jù
(`OMNIROUTE_BUILD_PROFILE=minimal`) rọ́pò
`src/lib/services/installers/ninerouter.ts` pẹ̀lú stub fún àwọn aṣàmúlò tí wọ́n fẹ́
kí a yọ àwọn ọ̀nà aláṣẹ-gíga náà kúrò nínú bundle ní ti ara.

**Ìdí tí a fi pa á mọ́**: 9router jẹ́ iṣẹ́ alábàákẹ́gbẹ́ àṣàyàn tí a lè fi sí ẹ̀rọ agbègbè
(rò ó bí: plugin ara WordPress) — ó nílò yíyan wọlé kedere.

## §5 — Ìkọ-padà àwọn ìjẹ́rìí Cloud Sync OmniRoute (`api/keys/[id]/route.js`)

**Àwọn fáìlì orísun**:

- `src/lib/cloudSync.ts` — `syncToCloud()` / `updateLocalTokens()`.
- `src/app/api/keys/[id]/route.ts` — ń pe `syncKeysToCloudIfEnabled()`.

**Ohun tó ń mú un ṣiṣẹ́**: `isCloudEnabled()` dá `true` padà (tí a ṣètò láti ojú ìdarí) **àti pé**
a ti ṣètò `CLOUD_URL`. Nígbà tí àwọn méjèèjì bá wà ní pípa, kò sí ìpè nẹ́tíwọ́ọ̀kì jáde tí a ó ṣe sí
Cloud endpoint.

**Ìhùwàsí v3.8.5 (àṣìṣe tí Socket.dev ṣàwárí lọ́nà tó tọ́)**:

`updateLocalTokens()` kọ `accessToken`, `refreshToken`, àti
`providerSpecificData` tuntun láti inú èsì Cloud nígbà tí
`cloudUpdatedAt > localUpdatedAt`. Kò sí HMAC, kò sí ìbuwọ́lù, kò sì sí checksum. `CLOUD_URL`
tí a ṣètò lọ́nà tí kò tọ́ tàbí tó léwu (tàbí MITM lórí ikanni náà) lè pààrọ̀
àwọn token OAuth olùpèsè ní ìkọ̀kọ̀.

**Ìdínkù ewu v3.8.6**:

1. **Ìjẹ́rìísí HMAC**: `verifyCloudSignature(rawBody, sigHeader)` ń yẹ
   header `X-Cloud-Sig` (`HMAC-SHA256(OMNIROUTE_CLOUD_SYNC_SECRET,
rawBody)`) wò kí ó tó ṣe ìtúpalẹ̀ JSON. Tí a bá ṣètò secret náà, a gbọ́dọ̀
   ní ìbuwọ́lù náà. Bí kò bá sí (ipò àtijọ́), a ó kọ ìkìlọ̀ sínú log, a ó sì
   gba èsì náà — secret náà yóò di dandan ní v3.9.
2. **Yíyan láti gba àwọn field aṣírí**: `accessToken` / `refreshToken` /
   `providerSpecificData` ni a ó **kàn** kọ tuntun nígbà tí
   `OMNIROUTE_CLOUD_SYNC_SECRETS=true`. Ipò àìyẹsẹ̀ ń mú metadata tí kì í ṣe
   ìjẹ́rìí nìkan bá ara wọn mu (`expiresAt`, `status`, `lastError*`,
   `rateLimitedUntil`, `updatedAt`). Èyí jẹ́ **ìyípadà tó ń já ìbámu** fún àwọn aṣàmúlò
   tí wọ́n gbẹ́kẹ̀ lé ìmúdójúìwọ̀n token láti ọ̀nà jíjìn — wọ́n gbọ́dọ̀ yan láti gbà á ní tààrà.

**Ìdí tí a fi pa á mọ́**: Cloud Sync ni ọ̀nà kan ṣoṣo fún ayálégbé OmniRoute Cloud
láti ṣe àkójọpọ̀ àwọn ìjẹ́rìí ẹgbẹ́ sí ibi kan. Àtúnṣe náà mú kí àwòṣe ewu náà ṣe kedere:
"server ń fọwọ́ sí i, client ń jẹ́rìí rẹ̀, operator sì ń yan láti gbà á."

## Àwòṣe ìkọ́lé: `minimal`

Fún àwọn aṣàmúlò tó nílò artifact tó bá Socket mu, kọ́ ọ pẹ̀lú:

```bash
OMNIROUTE_BUILD_PROFILE=minimal npm run build
```

Webpack `NormalModuleReplacementPlugin` ń so àwọn module mẹ́rin pọ̀ mọ́ àwọn stub gẹ́gẹ́ bí alias:

| Module                                      | Stub                                             |
| ------------------------------------------- | ------------------------------------------------ |
| `src/mitm/cert/install.ts`                  | `src/mitm/cert/install.stub.ts`                  |
| `src/lib/zed-oauth/keychain-reader.ts`      | `src/lib/zed-oauth/keychain-reader.stub.ts`      |
| `src/lib/cloudSync.ts`                      | `src/lib/cloudSync.stub.ts`                      |
| `src/lib/services/installers/ninerouter.ts` | `src/lib/services/installers/ninerouter.stub.ts` |

Stub kọ̀ọ̀kan ń export surface kan náà, ṣùgbọ́n gbogbo function ń ju
`featureDisabledError(name)` sílẹ̀ ní runtime. Àwọn route tó gbẹ́kẹ̀ lé module tí a pa
máa dá HTTP 503 padà pẹ̀lú ìfiranṣẹ́ tó ṣe kedere dípò kí wọ́n mú
code path tó ní ewu ṣiṣẹ́.

A pète bundle tí ó yọrí sí láti tẹ̀ jáde gẹ́gẹ́ bí `omniroute-secure`. Wo
`docs/ops/PUBLISHING_SECURE.md` fún ìlànà ìtẹ̀jáde.
