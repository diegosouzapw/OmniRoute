OmniRoute yà telemetry ìwọ̀n-ìlò olùpèsè sọ́tọ̀ kúrò nínú ìṣírò Ghostlight.

## Àwọn ipò tó jẹ́ òtítọ́

- `healthy` túmọ̀ sí pé orísun kan jabo pé agbára tó ṣì kù lè lò.
- `approaching_limit` túmọ̀ sí pé orísun kan jabo pé agbára tó ṣì kù wà ní ìwọ̀n ààlà tí a ṣètò tàbí ní ìsàlẹ̀ rẹ̀.
- `exhausted` ni a máa ń gbé jáde nìkan nígbà tí orísun kan bá jabo pé agbára kù sí òdo tàbí pé ìlò ti dé ìwọ̀n ààlà rẹ̀.
- `unavailable` túmọ̀ sí pé orísun tí a ṣe àtìlẹ́yìn fún kò lè dá data padà.
- `unknown` túmọ̀ sí pé kò sí orísun tí a ṣe àtìlẹ́yìn fún tàbí pé kò sí ìwọ̀n ààlà olùpèsè tí a mọ̀.

Àìmọ̀ kì í ṣe pé agbára ti tán, kò sì ní mú olùpèsè kan ṣiṣẹ́ mọ́.

A máa ń yan àwọn orísun gẹ́gẹ́ bí ètò yìí: API olùpèsè oníṣẹ́, API ìlò tó ní ìfàṣẹsí, àwọn response headers tí a ṣe mapping wọn ní kedere, ìṣètò alábòójútó, àwọn ìṣírò àdúgbò, àìmọ̀. A kì í fi àwọn ìṣírò àdúgbò hàn gẹ́gẹ́ bí data ìdíyelé olùpèsè.

A máa ń ṣe parsing àwọn response headers nípasẹ̀ mapping olùpèsè tí a sọ ní kedere nìkan. A kò kà àwọn orúkọ header gbogbogbò sí ohun tó kan gbogbo eto.
