OmniRoute ní àkójọpọ̀ àwọn próksì ọ̀fẹ́ tí a ti fara balẹ̀ yàn nínú tábìlì `free_proxies`,
tí a múṣiṣẹpọ̀ láti ọ̀dọ̀ àwọn olupèsè òde (1proxy, proxifly, iplocate, webshare). Pánẹ́ẹ̀lì
ìṣàkóso ń fi wọ́n hàn lábẹ́ **Settings → Free Proxies**. Ìwé yìí
ṣàlàyé àsẹ̀, títò-lẹ́sẹẹsẹ, kíkà, àti ìjábọ̀ àṣìṣe ìmúṣiṣẹpọ̀ ní ẹ̀gbẹ́ olupin
tí ipa-ọ̀nà àkójọ náà ń pèsè.

## Ipa-ọ̀nà àkójọ — `GET /api/settings/free-proxies`

Ó dá apá tí a ti ṣe àsẹ̀, tò lẹ́sẹẹsẹ, tí a sì pín sí ojú-ìwé padà pẹ̀lú àpapọ̀ iye. Àsẹ̀ àti
kíkà ń ṣẹlẹ̀ nínú SQL, nítorí náà UI lè fi àpapọ̀ gidi hàn (fún àpẹẹrẹ `Total: 0`)
láìgbé gbogbo ìlà sínú ìrántí.

### Àwọn pàrámítà ìbéèrè

| Pàrámítà          | Irú                                | Àìyípadà  | Ìtumọ̀                                                                                                                                             |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | ọ̀rọ̀                                | `""`      | `LIKE` tó ń fi ìyàtọ̀ lẹ́tà ńlá àti kékeré hàn lórí ọwọ̀n host (àti source).                                                                         |
| `protocol`        | ọ̀rọ̀                                | `""`      | Àsẹ̀ `type`: `http` / `https` / `socks4` / `socks5`. Òfo = gbogbo rẹ̀.                                                                              |
| `country`         | ọ̀rọ̀                                | `""`      | Àsẹ̀ `countryCode` (ISO-2). Òfo = gbogbo rẹ̀.                                                                                                       |
| `minQuality`      | nọ́ńbà                              | `0`       | Àwọn ìlà tí `qualityScore >= minQuality` nìkan. `0` = kò sí iye tó kéré jù.                                                                       |
| `disabledSources` | ọ̀rọ̀                                | `""`      | Àwọn id orísun tí kọ́mà yà sọ́tọ̀ láti yọ kúrò (fún àpẹẹrẹ `proxifly,webshare`).                                                                     |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = àmì láti gíga sí kékeré; `latency` = latency láti kékeré sí gíga (`null` ní ìkẹyìn); `recent` = `lastValidated` láti tuntun sí àtijọ́. |
| `offset`          | nọ́ńbà                              | `0`       | Ìbẹ̀rẹ̀ pípín sí ojú-ìwé.                                                                                                                           |
| `limit`           | nọ́ńbà                              | `50`      | Ìwọ̀n ojú-ìwé (tí a fi òpin sí ní ẹ̀gbẹ́ olupin).                                                                                                    |

### Ìdáhùn

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 láti orísun òkè"],
    "webshare": ["àsìkò nẹ́tíwọ̀ọ̀kì parí"]
  }
}
```

`total` ń ṣàfihàn àpapọ̀ tí a ti ṣe àsẹ̀ **ṣáájú** pípín sí ojú-ìwé, kí UI lè ṣe àfihàn
`Total: N` àti `hasMore` lọ́tọ̀ọ̀tọ̀. A ṣètò `syncErrors` nípa id orísun, a sì
kún un fún àwọn orísun tí ìmúṣiṣẹpọ̀ wọn tó kẹ́yìn kùnà nìkan — èsì `Total: 0`
kì í ṣe láìsí àlàyé.

## Ṣàfikún-sí-àkójọpọ̀ — `POST /api/settings/free-proxies/[id]/add-to-pool`

Ó gbé próksì ọ̀fẹ́ kan sókè sínú àkójọpọ̀ `proxy_registry` tí a ń ṣàkóso. Ó kọ́kọ́ fìdí
orísun òkè múlẹ̀; tí ó bá ṣàṣeyọrí, ó dá id próksì àkójọpọ̀ tuntun àti latency tí a wọ̀n padà.

## Ìmúṣiṣẹpọ̀ — `POST /api/settings/free-proxies/sync`

Ó tún fa gbogbo àwọn orísun tí a ti mú ṣiṣẹ́ (tàbí abala inú `{ "sources": [...] }`). Orísun
kọ̀ọ̀kan ń múṣiṣẹpọ̀ lọ́tọ̀; a máa gba orísun tó kùnà sílẹ̀ nínú `syncErrors`, àwọn
yòókù sì máa parí, nítorí náà ìmúṣiṣẹpọ̀ tí kò pé kì í pa dátà rere tó ti wà tẹ́lẹ̀ rẹ́.

## Àwọn ìṣirò — `GET /api/settings/free-proxies/stats`

Ó dá àkójọpọ̀ `total / inPool / avgQuality / bySource / lastSyncAt` padà
láìsí payload àwọn ìlà — àwọn ẹrọ-ìfihàn àkọlé pánẹ́ẹ̀lì ìṣàkóso ló ń lò ó.
