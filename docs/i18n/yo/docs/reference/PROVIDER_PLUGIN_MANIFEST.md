`open-sse/config/providerPluginManifest.ts` ń ṣàlàyé àdéhùn plugin olùpèsè tí ó
jẹ́ àìléwu fún JSON. `open-sse/config/providerPluginManifestRegistry.ts` so
àdéhùn yẹn mọ́ ìforúkọsílẹ̀ olùpèsè lọ́wọ́lọ́wọ́ fún àwọn sidecar bíi Bifrost,
CLIProxyAPI, tàbí router Go/Rust kan ní ọjọ́ iwájú. Ìforúkọsílẹ̀ TypeScript ṣì jẹ́
orisun òtítọ́, ṣùgbọ́n àwọn sidecar lè lo manifest náà láì ṣe àgbéwọlé
kóòdù executor, àwọn iye àkàyàn OAuth, àwọn header, tàbí ipò àyíká process.

Manifest kan náà tún wà lórí HTTP ní
`GET /api/v1/provider-plugin-manifest` fún àwọn sidecar tí ń ṣiṣẹ́ níta process.

OmniRoute ń polówó URL yẹn fún Bifrost àti CLIProxyAPI nípasẹ̀ header ìbéèrè
`X-OmniRoute-Provider-Manifest-Url`. Ṣètò
`OMNIROUTE_PROVIDER_MANIFEST_URL` nígbà tí sidecar bá nílò URL gbogbogbò tàbí URL
nẹ́tíwọ́ọ̀kì container dípò orísun ìbéèrè agbègbè.

## Ṣíṣe Àtúnṣe Manifest

Endpoint HTTP náà ń dá `Cache-Control: public, max-age=60` àti
`ETag` alágbára padà. Sidecar kan yẹ kí ó pa manifest tí a fọwọ́sí gbẹ̀yìn mọ́, kí ó sì fi ETag rẹ̀
ránṣẹ́ nínú `If-None-Match` nígbà àtúnṣe. Ìdáhùn `304 Not Modified` kò ní body;
sidecar náà yóò máa lo manifest tí ó wà nínú cache rẹ̀. Bí manifest tí a fọwọ́sí kò bá sí
nínú cache, sidecar náà gbọ́dọ̀ ṣe ìbéèrè láìsí àídájú dípò kí ó gba `304`.

## Ète

Gbé metadata olùpèsè sún mọ́ àdéhùn plugin kí ipa-ọ̀nà ìbéèrè gbígbóná lè
wá jẹ́ ohun tí sidecar alálọ́ra-kékeré ń ṣàkóso ní ọjọ́ iwájú, nígbà tí OmniRoute bá ń pa
route TypeScript mọ́ gẹ́gẹ́ bí ẹnubodè ìlànà àti àṣàyàn ìpadà. Manifest náà jẹ́ àfikún: kò
yí ìtọ́sọ́nà ìbéèrè padà fúnra rẹ̀.

## Àdéhùn

Manifest náà ní:

- id àti alias olùpèsè
- format upstream àti orúkọ executor
- irú auth, header auth, àti prefix auth àṣàyàn
- metadata endpoint tí kò yí padà
- yíyẹ fún sidecar àti àwọn ìdí tó ṣe kedere nígbà tí olùpèsè kan yẹ kí ó dúró lórí TS
- metadata model tí ó jẹ́ àìléwu fún JSON, bíi gígùn context, àwọn àmì vision/reasoning, àti
  àwọn params tí kò ní àtìlẹ́yìn
- àwọn àmì agbára tó ní `apikey`, `oauth`, `custom-executor`,
  `passthrough-models`, `responses`, `sidecar-candidate`, `usage-fetch`, àti `usage-supported`

Manifest náà mọ̀ọ́mọ̀ yọ àwọn wọ̀nyí sílẹ̀:

- àwọn àṣírí client OAuth àti àwọn iye àṣírí àkàyàn
- ìyanjú àyíká runtime
- àwọn header ìbéèrè àti àwọn olùrànlọ́wọ́ credential gbogbogbò
- àwọn URL builder tó ń yí padà
- àwọn function executor
- àwọn ohun inú session pool

## Àwọn Àmì Agbára

`capabilities` jẹ́ array àwọn àmì tí a tò lẹ́sẹẹsẹ, tí a sì yọ láti inú entry ìforúkọsílẹ̀. Àwọn olùṣepọ̀
yẹ kí wọ́n kà á sí ìdáhùn tí ẹ̀rọ lè kà sí "kí ni olùpèsè yìí lè ṣe", dípò
kí wọ́n tún ka àwọn source TypeScript.

| Àmì                  | Ìtumọ̀                                                                       |
| -------------------- | --------------------------------------------------------------------------- |
| `apikey`             | Gba API key (`authType` jẹ́ `apikey` tàbí `optional`).                       |
| `oauth`              | Lo OAuth tàbí ìṣàn session.                                                 |
| `responses`          | Ṣí URL ìpìlẹ̀ OpenAI Responses-API síta.                                     |
| `passthrough-models` | Pèsè àwọn model tààrà láti upstream dípò catalog tí kò yí padà.             |
| `custom-executor`    | Ṣiṣe executor tí kì í ṣe àkàyàn, nítorí náà ó dúró lórí ipa-ọ̀nà TypeScript. |
| `sidecar-candidate`  | Ṣe àfihàn `sidecar.eligible` — ó léwu láti gbé yẹ̀ wò fún àgbéwọlé sidecar.  |
| `usage-fetch`        | Ní olùkójọ usage tàbí quota tí a ti so pọ̀ (`getUsageForProvider`).          |
| `usage-supported`    | API usage gba olùpèsè yìí (`isSupportedUsageConnection`).                   |

`usage-fetch` jẹ́ fún ìṣàwárí nìkan. Ó ń jẹ́rìí pé OmniRoute mọ bí a ṣe ń ka usage fún
olùpèsè náà; kò ṣiṣẹ́ ìkójọ, kò yí ìtumọ̀ quota padà, bẹ́ẹ̀ ni kò túmọ̀ sí pé
widget quota Dashboard ti ṣiṣẹ́ fún olùpèsè náà — `USAGE_SUPPORTED_PROVIDERS` ló ń
ṣàkóso widget yẹn lọ́tọ̀. Orisun òtítọ́ ni `USAGE_FETCHER_PROVIDERS` nínú
`open-sse/services/usage/fetcherProviders.ts`.

Àwọn string tí dispatcher usage ń gba ni a fi ṣe key àtòjọ yẹn, nítorí náà ó da àwọn id canonical
pọ̀ mọ́ àwọn alias, ó sì gùn díẹ̀ ju iye àwọn olùpèsè tí a fi àmì sí: àwọn entry tí
kì í ṣe olùpèsè chat nínú ìforúkọsílẹ̀ manifest (fún àpẹẹrẹ, olùpèsè ìṣàwárí `firecrawl`
àti olùpèsè ACP `amazon-q`) kò ní entry manifest láti fi àmì sí.

`usage-supported` ń dáhùn bóyá àwọn route usage server àti Dashboard gba connection
fún olùpèsè náà. Ó ṣe àfihàn `isSupportedUsageConnection()` (`src/lib/usage/providerLimits.ts`)
àti `supportsProviderQuota()` (`src/shared/utils/providerQuotaVisibility.ts`), tí
`USAGE_SUPPORTED_PROVIDERS` (`open-sse/services/usage/supportedProviders.ts`) ń ṣàkóso àwọn méjèèjì. Yàtọ̀ sí
`usage-fetch`, a máa ń fi hàn lórí id olùpèsè nìkan — runtime guard náà ń ṣe
`USAGE_SUPPORTED_PROVIDERS.includes(providerId)` láì yanju alias, nítorí náà manifest náà
pa òfin kan náà mọ́. Àwọn àmì méjèèjì ní ààlà ọ̀tọ̀ọ̀tọ̀: àwọn olùpèsè 3 ló ní
`usage-fetch` nìkan (`opencode`, `opencode-zen`, `xai`), 1 sì ní
`usage-supported` nìkan (`xiaomi-mimo-token-plan`), nítorí náà ọ̀kan kò túmọ̀ sí èkejì.

## Lílo Sidecar

Àwọn sidecar yẹ kí wọ́n ka `sidecar.eligible` sí àmì olùdíje tí a fi ìṣọ́ra yan, kì í ṣe
gẹ́gẹ́ bí ìpinnu ìdarí tí kò ní àídájú. Ohun àkọ́kọ́ tí a ó gbé wọlé yẹ kí ó jẹ́
àwọn olùpèsè API-key àti static-endpoint tí wọ́n ń lo executor àìyípadà. Àwọn olùpèsè tí wọ́n ní
custom web executors, àwọn ìṣàn OAuth/session, dynamic URL builders, tàbí pool config
yóò dúró lórí ọ̀nà fallback TypeScript títí sidecar kan yóò fi ṣe àgbékalẹ̀ ìhùwàsí
tó dọ́gba, tí telemetry sì fi jẹ́rìí pé wọ́n wà ní ìpele kan náà.

Àwọn ìpele ìṣíkiri tí a dábàá:

1. Ṣẹ̀dá kí o sì fọwọ́sí manifest plugin olùpèsè láti inú registry TS.
2. Kọ́ Bifrost tàbí CLIProxyAPI láti gbé manifest náà wọlé fún àwọn olùpèsè
   API-key/static.
3. Darí àwọn olùpèsè tó yẹ gba inú sidecar lẹ́yìn `OMNIROUTE_RELAY_BACKEND`
   nígbà tí fallback TS ṣì wà ní ṣíṣiṣẹ́.
4. Ṣe ìgbéga àwọn olùpèsè kìkì nígbà tí ìwọ̀n àṣeyọrí, p99 latency, ìhùwàsí streaming,
   àti bí a ṣe ń bójú tó unsupported-param bá dọ́gba pẹ̀lú ọ̀nà TS.
5. Ṣàfikún àwọn plugin sidecar-native fún custom executors, ìdílé olùpèsè kan
   lẹ́ẹ̀kan.

## Ìdí Tí A Kò Fi Ní Fi Àwọn Olùpèsè Sínú Next Ní Tààrà

Frontend Next kò yẹ kí ó jẹ́ aláṣẹ ìṣiṣẹ́ àwọn olùpèsè. Ó yẹ kí ó pe ààlà API.
Lẹ́yìn náà, backend lè pinnu bóyá láti lo executor TypeScript,
Bifrost, CLIProxyAPI, tàbí sidecar abinibi kan ní ọjọ́ iwájú. Èyí ń jẹ́ kí request signing,
àwọn àyẹ̀wò allowlist, policy DB, àti ìhùwàsí fallback wà ní àárín gbùngbùn ṣáájú
fífà á lé sidecar lọ́wọ́.
