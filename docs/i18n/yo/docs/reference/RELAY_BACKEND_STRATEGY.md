## Àkótán

OmniRoute ti ń ṣe àtìlẹ́yìn fún àwọn ipò relay mẹ́ta báyìí fún `/api/v1/relay/chat/completions`:

- `ts`: Lo relay TypeScript nínú process náà.
- `bifrost`: Fipá mú lílo gateway Bifrost.
- `auto`: Yan Bifrost lákọ̀ọ́kọ́ nígbà tí ó bá wà, kí o sì padà sí TypeScript nígbà ìkùnà.

Nígbà tí o bá ń ṣiṣẹ́ pẹ̀lú ìwọ̀n ìbéèrè gíga (iye tokens púpọ̀/ọjọ́, throughput tí ó fẹ́rẹ̀ẹ́ máa bá a lọ láìdáwọ́), ọgbọ́n tó dára jù ni láti jẹ́ kí ọ̀nà fallback náà ṣe kedere kí ó sì yára, kí hot path má bàa dúró de sidecar tí kò ṣiṣẹ́.

## Ìhùwàsí àwọn ipò

- `ts`
  - Ó ní ìṣòro ìṣàkóso iṣẹ́ tó kéré jù.
  - Gbogbo routing àti validation ń ṣiṣẹ́ nínú Node.
  - Kò gbára lé sidecar fún availability.
- `bifrost`
  - Fipá mú gbogbo ìbéèrè láti kọjá nípasẹ̀ gateway sidecar.
  - Kò sí fallback aládàáṣe.
  - Ó wúlò nìkan nígbà tí ìlera àti latency sidecar bá dájú.
- `auto`
  - A máa lo sidecar nígbà tí a bá lè dé ọ̀dọ̀ rẹ̀ tí a sì ti mú un ṣiṣẹ́.
  - Àwọn ìgbìyànjú tí ó kùnà máa ń fa àwọn header fallback, wọ́n sì máa ń dá traffic padà sí TS kí àṣeyọrí ìbéèrè lè wà lábẹ́ ààlà tó dájú.
  - Ipò yìí ni àṣàyàn tó ní ààbò jù fún production nígbà tí uptime bá ṣe pàtàkì ju routing tó jẹ́ sidecar-nìkan lọ.

## 9router àti CLIPROXYAPI lónìí

9router àti CLIPROXYAPI jẹ́ àwọn integration méjèèjì tí, láti ìbẹ̀rẹ̀, ti ń pèsè àwọn ọ̀nà compatibility fún àwọn provider upstream.

- 9router jẹ́ ọ̀nà embedded fún orchestration upstream àti ìhùwàsí compatibility.
- CLIPROXYAPI jẹ́ bridge API proxy fún traffic ara CLI / SDK.
- Bifrost ni a ń mú dúró ṣinṣin gẹ́gẹ́ bí ọ̀nà externalized nígbà tí o bá nílò hop tí ó dàbí sidecar tí a yà sọ́tọ̀ àti dispatch local tó ní latency kékeré.

Tí o bá ń fi 9router/CLIPROXYAPI wéra lọ́wọ́lọ́wọ́:

- Jẹ́ kí request signing, àwọn àyẹ̀wò allowlist, àti àwọn gate policy DB wà nínú route API ṣáájú handoff.
- Tí workflow kan bá nílò ìhùwàsí sidecar tó muna àti variance tó kéré sí i fún ìbéèrè kọ̀ọ̀kan, lo `OMNIROUTE_RELAY_BACKEND=bifrost`.
- Tí o bá nílò resilience sidecar pẹ̀lú graceful degradation lábẹ́ àwọn ipò incident, lo `OMNIROUTE_RELAY_BACKEND=auto`.

## Àdéhùn ààlà backend

Ààlà product tó dúró ṣinṣin ni API relay OmniRoute, kì í ṣe implementation dashboard. Dashboard Next.js lè fi àwọn service local sílẹ̀, configure wọn, kí ó sì supervise wọn, ṣùgbọ́n request routing gbọ́dọ̀ wọlé nípasẹ̀ API relay, kí handoff sì ṣẹlẹ̀ lẹ́yìn ààlà yẹn.

Àwọn àṣàyàn backend fún ìgbà pípẹ́:

- Pa relay TypeScript mọ́ gẹ́gẹ́ bí ọ̀nà policy àti fallback inú process. Auth, allowlists, request normalization, accounting, àti àwọn àyẹ̀wò safety dúró síbí ṣáájú handoff sí backend èyíkéyìí.
- Lo Bifrost gẹ́gẹ́ bí sidecar Tier-1 high-throughput tí a fẹ́ràn jù nígbà tí deployment bá nílò variance routing tó kéré sí i, rotation provider tó wà ní àárín gbùngbùn, tàbí scale-out kọjá ọ̀pọ̀ replica OmniRoute.
- Pa 9router àti CLIPROXYAPI mọ́ gẹ́gẹ́ bí àwọn service compatibility embedded. Wọ́n ń ṣiṣẹ́ gẹ́gẹ́ bí àwọn process local tí a ń supervise, wọ́n sì wúlò nígbà tí ìhùwàsí provider/CLI wọn bá jẹ́ adapter tí a fẹ́, ṣùgbọ́n wọn kò gbọ́dọ̀ di engine routing Tier-1 àìyípadà.
- Má ṣe jẹ́ kí dashboard fi àwọn URL service aláìlódì sí hot path. Àwọn URL tí UI pèsè jẹ́ àwọn input configuration; kóòdù routing gbọ́dọ̀ resolve àwọn backend tí a forúkọsílẹ̀, tí a sì ti ṣe health-check wọn láti inú àwọn setting server-side àti state supervisor.
- Fẹ́ràn loopback HTTP fún àwọn service tí a ń supervise lónìí nítorí àwọn process tí a ń manage ti ń pèsè àwọn API tó bá HTTP mu, route guard lè audit ààlà náà, ìhùwàsí failure/fallback sì hàn nínú request logs. Ó yẹ kí a fi transport SDK tàbí socket kan kún un lọ́jọ́ iwájú nìkan tí ó bá dín latency routing p99 kù lọ́nà tí a lè wọn, láìsọ isolation tàbí semantics fallback di aláìlágbára.

Nítorí náà, fún deployment tó ní throughput gíga gan-an, ìdáhùn àìyípadà ni `auto` pẹ̀lú Bifrost tí a mú ṣiṣẹ́: lo sidecar Go lórí hot path, nígbà tí o ń pa fallback TypeScript mọ́ fún success rate. Lo `bifrost` nìkan nígbà tí ìhùwàsí sidecar-nìkan tó muna bá ṣe pàtàkì ju graceful degradation lọ.

## Ìtọ́sọ́nà fún throughput gíga

Fún RPM/RPS gíga tí ó dúró pẹ́ àti SLO àṣeyọrí tó muna:

1. Lo `auto` pẹ̀lú cooldown tó bójú mu àti telemetry failure.
2. Jẹ́ kí validation upstream àti àwọn àyẹ̀wò API-key wà ní ààlà route TypeScript.
3. Mú àwọn header/counter kedere ṣiṣẹ́ kí alerting rẹ lè rí ìgbà tí fallback ń ṣẹlẹ̀ àti àwọn ìdí rẹ̀.
4. Tune àwọn timeout sidecar kí wọ́n lè kùnà kíákíá, kì í ṣe láti dúró títí láé.
5. Jẹ́ kí auto-restart service àti loop telemetry health wà ní ìlera, kí fallback lè jẹ́ ohun tó ṣọ̀wọ́n ní tòótọ́.

## Ìpilẹ̀ tí a dábàá

- `OMNIROUTE_RELAY_BACKEND=auto`
- `BIFROST_ENABLED=1`
- Jẹ́ kí API keys, allowlist, sanitizer, àti àwọn àyẹ̀wò rate-limit ṣiṣẹ́ nínú àwọn route handler (wọ́n máa ń ṣiṣẹ́ nígbà gbogbo ṣáájú forwarding downstream).
- Export àwọn metric fallback láti inú reverse proxy àti request logs rẹ, kí àwọn outage sidecar lè hàn láàárín ìṣẹ́jú kan.
