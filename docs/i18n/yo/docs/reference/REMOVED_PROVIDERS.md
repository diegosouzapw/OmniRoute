Àwọn iṣẹ́ kan ni a ti ṣepọ̀ mọ́ OmniRoute tẹ́lẹ̀, tí a sì yọ kúrò lẹ́yìn náà nítorí àwọn tó ń
ṣiṣẹ́ wọn béèrè fún un. Ojúewé yìí ni àkọsílẹ̀ pípẹ́ fún àwọn ìyọkúrò wọ̀nyẹn. Ìdí kan ṣoṣo rẹ̀ ni láti
dènà wọn láti padà wá láìmọ̀ọ́mọ̀: olùkópa kan tó bá rí fork àtijọ́ kan, tarball npm
tí a fi pamọ́ sínú cache, issue tí a ti ṣàkọsílẹ̀ pamọ́ tàbí ìbéèrè “mú olùpèsè X padà” nílò ibi kan ṣoṣo tó sọ pé **má
ṣe dá a padà síbẹ̀**.

Ojúewé yìí **kì í ṣe** àkójọ àwọn iṣẹ́ tí ó ti kú tàbí tí a ti dáwọ́ dúró. A ń tọpinpin àwọn wọ̀nyẹn nínú
[`FREE_TIERS.md`](FREE_TIERS.md) (“A yọ kúrò / kò sí ipele ọ̀fẹ́”) wọ́n sì lè padà tí iṣẹ́ náà bá
padà. Àwọn àkọsílẹ̀ tó wà ní ìsàlẹ̀ lè padà nìkan pẹ̀lú ìyọ̀nda tí a kọ sílẹ̀ láti ọ̀dọ̀ olùṣàkóso tí a dárúkọ nínú
ìbéèrè náà, a sì gbọ́dọ̀ fi ìjápọ̀ sí ìyọ̀nda yẹn nínú àkọsílẹ̀ náà.

## Ìlànà

1. **A máa ń tẹ̀lé ìbéèrè ìyọkúrò láti ọ̀dọ̀ olùṣàkóso iṣẹ́, a kì í sì í ṣe àdéhùn lórí rẹ̀.** OmniRoute
   kò ní ìbáṣepọ̀ pẹ̀lú iṣẹ́ upstream kankan. Nígbà tí olùṣàkóso iṣẹ́ kan bá béèrè pé kí a yọ
   ìṣepọ̀ náà kúrò, a ó yọ ọ́ kúrò, yálà ìṣepọ̀ náà lo API àṣẹ tàbí bẹ́ẹ̀ kọ́.
2. **“A yọ kúrò” túmọ̀ sí gbogbo ojú-ọ̀nà tí OmniRoute ń ṣàkóso.** Executor, àkọsílẹ̀ registry, id àti alias
   olùpèsè, àkójọ model, endpoints, environment variables, icon, àwọn card dashboard,
   ìtọ́kasí olùpèsè tí a ṣẹ̀dá, `FREE_TIERS.md`, ìtọ́kasí environment, àwọn iye README,
   àwọn àwòkọ `llm.txt`, àwọn test pàtó àti golden snapshots, àwọn comment inú code, àwọn bullet CHANGELOG
   (pẹ̀lú ìbámu tí a kọ sínú ledger, wo `config/release/changelog-reconciliations.json`),
   àwọn àkọsílẹ̀ GitHub Releases, wiki, àti àwọn issue, discussion àti pull request GitHub tí
   kókó wọn jẹ́ olùpèsè yẹn (a pa àwọn issue àti discussion rẹ́; a tún àwọn pull request lórúkọ,
   a rọ́pò àpèjúwe wọn, a sì ti thread náà pa, nítorí GitHub kò lè pa àwọn pull request rẹ́).
3. **Má ṣe dá àkọsílẹ̀ kankan lórí ojúewé yìí padà láìsí ìyọ̀nda tí a kọ sílẹ̀.** Èyí kan
   fífi id tàbí alias náà padà sí catalog olùpèsè èyíkéyìí, fífi àwọn domain náà kun executor,
   gbígba PR olùkópa kan tó “mú un padà”, fífi í kun catalog model ọ̀fẹ́, tàbí
   ṣíṣe àkọsílẹ̀ ọ̀nà afọwọ́ṣe láti dé ọ̀dọ̀ rẹ̀ nípasẹ̀ OmniRoute. Pa irú àwọn PR àti issue bẹ́ẹ̀ pẹ̀lú
   ìjápọ̀ sí ojúewé yìí.
4. **Jẹ́ kí àkọsílẹ̀ náà kéré.** Ṣàkọsílẹ̀ ohun tí olùṣàyẹ̀wò nílò nìkan láti dá
   ìmúdápadà mọ̀: identifiers, domains, dates àti pull request tó ṣe ìyọkúrò náà.
   Má ṣe ṣàpèjúwe bí ìṣepọ̀ náà ṣe ń ṣiṣẹ́.
5. **Olùṣọ́ regression ni `tests/unit/removed-providers-blocklist.test.ts`.** Ó máa kuna nígbà tí
   identifier tàbí domain èyíkéyìí tó wà ní ìsàlẹ̀ bá tún farahàn nínú àwọn catalog olùpèsè, map executor tàbí
   àwọn source registry olùpèsè. Fi àwọn identifier tuntun kun test yẹn nínú PR kan náà tí
   ó fi row kan kun níbí.

## Fífi àkọsílẹ̀ kun

Nígbà tí ìbéèrè ìyọkúrò tuntun bá dé:

1. Jẹ́rìí sí i pé ìbéèrè náà wá láti ọ̀dọ̀ olùṣàkóso iṣẹ́ náà (àdírẹ́sì support wọn tàbí
   domain tí wọ́n ń ṣàkóso), kí o sì pa ìfiránṣẹ́ náà mọ́ ní ìkọ̀kọ̀.
2. Yọ ìṣepọ̀ náà kúrò nípa títẹ̀lé checklist tó wà ní ohun kejì nínú ìlànà. Lo
   [#12440](https://github.com/diegosouzapw/OmniRoute/pull/12440) gẹ́gẹ́ bí ìtọ́kasí fún
   olùpèsè aláìní kọ́kọ́rọ́ àti [#10210](https://github.com/diegosouzapw/OmniRoute/pull/10210) fún
   olùpèsè kọ́kọ́rọ́ API tó ní àwọn connection tí a fi pamọ́ (fi migration kan kun).
3. Fi row kan kun table tó wà lókè àti àwọn identifier náà sínú
   `tests/unit/removed-providers-blocklist.test.ts`, nínú PR kan náà.
4. Dá olùṣàkóso náà lóhùn lẹ́yìn tí a bá ti merge PR náà, kí o ṣe àkójọ ohun tí a yọ kúrò àti ohun tí OmniRoute
   kò lè yí padà (àwọn version npm àti Docker tí a ti tẹ̀ jáde, git history, àwọn fork ẹnikẹ́ta).
