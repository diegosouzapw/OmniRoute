Àwọn relay (Vercel, Deno, Cloudflare) máa ń fòpin sí ìsopọ̀ upstream lórí backend
serverless, kí OmniRoute lè jáde láti ẹkùn kan tó dúró ṣinṣin, nígbà tó sì ń pa
kọ́kọ́rọ́ API olupèsè mọ́ sí ẹ̀gbẹ́ server. Ìwé yìí ṣàlàyé àwọn ọ̀nà ìkùnà méjì
tí àwọn olùdarí máa ń bá pàdé ní production àti àwọn ọ̀nà ìmúpadàbọ̀sípò tí
OmniRoute pèsè fún ọ̀kọ̀ọ̀kan.

## Bí a ṣe ń tọ́jú ìfàṣẹsí relay

Nígbà tí o bá deploy relay kan láti **Settings → Proxy Pool → Deploy Relay**,
ìlànà deploy náà máa ń tọ́jú token ìfàṣẹsí relay sínú field JSON `notes` ti
proxy náà:

- Tí a bá ṣètò `STORAGE_ENCRYPTION_KEY`, a ó kọ token náà sí `relayAuthEnc`
  (tí a fi AES encrypt nígbà tí ó wà ní ìpamọ́).
- Bí bẹ́ẹ̀ kọ́, a ó kọ ọ́ sí `relayAuth` gẹ́gẹ́ bí plaintext.

Ní àkókò request, `extractRelayAuth(notes)` máa ń dá èyíkéyìí tó wà padà,
nítorí náà relay náà yóò máa ṣiṣẹ́ nìṣó lẹ́yìn àwọn restart.

## Ọ̀nà ìkùnà 1 — token tí kò ṣeé decrypt lẹ́yìn yíyí kọ́kọ́rọ́ padà

**Àmì:** àwọn relay tó ti ń ṣiṣẹ́ tẹ́lẹ̀ ń dá àwọn àṣìṣe upstream `401`/ìfàṣẹsí
padà lẹ́yìn yíyí `STORAGE_ENCRYPTION_KEY` padà nínú environment tàbí
secret-manager. A kò lè decrypt blob `relayAuthEnc` tí a tọ́jú mọ́, nítorí náà
`extractRelayAuth` máa ń dá string òfo padà, relay náà kò sì fi ìfàṣẹsí kankan
ránṣẹ́.

**Ìmúpadàbọ̀sípò — tún un ṣe níbi tó wà (láì deploy lẹ́ẹ̀kan sí i):**

1. Ṣí **Settings → Proxy Pool**.
2. Àwọn row relay tí ìfàṣẹsí wọn kò sí máa ń fi badge `auth missing` aláwọ̀
   ọ̀wọ̀ hàn pẹ̀lú bọ́tìnì **Repair**.
3. Tẹ **Repair**. OmniRoute máa ń pe
   `POST /api/settings/proxies/[id]/repair-relay`, èyí tí yóò:
   - decrypt `relayAuthEnc` pẹ̀lú kọ́kọ́rọ́ **lọ́wọ́lọ́wọ́**,
   - kọ plaintext `relayAuth` padà sínú `notes`,
   - dá `{ repaired: true, mode: "recovered" }` padà.

Relay náà yóò bẹ̀rẹ̀ sí í ṣiṣẹ́ padà láìsí pé o tún tẹ àwọn ẹ̀rí ìdánimọ̀ deploy
kankan wọlé.

Èyí máa ṣiṣẹ́ nìkan tí `STORAGE_ENCRYPTION_KEY` lọ́wọ́lọ́wọ́ bá ṣì lè decrypt
blob náà. Tí o bá yí kọ́kọ́rọ́ náà padà **láì ṣe** migration, kò ṣeé gba blob
náà padà mọ́.

## Ọ̀nà ìkùnà 2 — token tí kò ṣeé gba padà (a ti yí kọ́kọ́rọ́ àtijọ́ kúrò)

**Àmì:** o tẹ **Repair**, o sì rí
`{ repaired: false, mode: "redeploy", status: 409 }`.

**Ìmúpadàbọ̀sípò — deploy lẹ́ẹ̀kan sí i:**

A kò lè gba token tí a tọ́jú padà pẹ̀lú kọ́kọ́rọ́ lọ́wọ́lọ́wọ́. Deploy relay náà
lẹ́ẹ̀kan sí i láti modal kan náà tí o lò ní ìbẹ̀rẹ̀ (**Deploy Relay** menu →
Vercel / Deno / Cloudflare). Ìlànà deploy náà máa ń kọ token tuntun (tí a
encrypt pẹ̀lú kọ́kọ́rọ́ lọ́wọ́lọ́wọ́), badge `auth missing` ti row náà yóò sì
parẹ́.

Nínú UI, bọ́tìnì **Repair** fúnra rẹ̀ máa ń ṣí modal redeploy tí token náà kò
bá ṣeé gba padà, nítorí náà o kò ní láti wá a kiri fúnra rẹ.

## Ọ̀nà ìkùnà 3 — a lè dé relay ṣùgbọ́n kò ní ìlera

**Àmì:** ìdánwò proxy (bọ́tìnì `speed`) fi hàn pé relay náà ń ṣiṣẹ́, ṣùgbọ́n
àwọn request ṣì ń kùnà lẹ́ẹ̀kọ̀ọ̀kan.

Ṣàyẹ̀wò àwọn header ìmọ̀ nípa relay tí probe ìdánwò aládàáṣiṣẹ́ ti OmniRoute
dá padà (wo **Settings → Proxy Pool** àti àwọn counter `relayTested` /
`relayAlive`):

- `x-relay-url` — backend relay wo ló dáhùn.
- `x-relay-mode` — `ts` | `bifrost` | `auto` fún request náà.
- `x-relay-attempts` — iye hop relay tí a dánwò kí request tó ṣàṣeyọrí.
- `x-relay-fallback` — `true` nígbà tí request bá yí padà láti backend tí a
  fẹ́ràn sí relay TypeScript.

Oṣùwọ̀n `x-relay-fallback` tó ga pẹ̀lú `relayAlive` tó kéré túmọ̀ sí pé backend
sidecar náà kò ní ìlera, o sì yẹ kí o tún un ṣe tàbí kí o yí strategy backend
relay padà sí `ts` (wo `RELAY_BACKEND_STRATEGY.md`).

## Ìtọ́kasí API

| Method | Path                                      | Body                    | Àṣeyọrí                                                                                                                                | Ìkùnà                                                                            |
| ------ | ----------------------------------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `POST` | `/api/settings/proxies/[id]/repair-relay` | `{ "id": "<proxyId>" }` | `200 { repaired: true, mode: "recovered" }` nígbà tí a tún rí i; `200 { repaired: false, mode: "noop" }` nígbà tí plaintext ti wà tẹ́lẹ̀ | `409 { mode: "redeploy" }` kò ṣeé gba padà; `400` kì í ṣe irú relay; `404` kò sí |

Route àtòjọ `GET /api/settings/proxies` máa ń so
`relayInfo: { isRelay, authMissing, repairMode }` tí kò ní secret mọ́
ọ̀kọ̀ọ̀kan, kí dashboard lè fi ọ̀nà àtúnṣe hàn láì fi token náà hàn rárá.
