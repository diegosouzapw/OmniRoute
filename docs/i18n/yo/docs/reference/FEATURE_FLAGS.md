> Àwọn tógù àsìkò-ṣiṣe tí ń yí ìhùwàsí OmniRoute padà **láìṣe àtúnkóṣiṣẹ́**.
> Gbogbo àmì tí a tò síbí ni a ṣàlàyé nínú
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — orísun òtítọ́ kan ṣoṣo. Dásíbọ́ọ̀dù àti REST API méjèèjì ń kà láti inú
> fáìlì yẹn, nítorí náà a ṣe àgbéjáde tábìlì tó wà nísàlẹ̀ láti bá a mu ní 1:1.

---

## Kí Ni Àwọn Àmì Ẹ̀yà

Àmì ẹ̀yà jẹ́ tógù tó ní orúkọ (boolean tàbí enum) tí a lè yí iye rẹ̀ padà ní
àsìkò-ṣiṣe, tí a sì lè fi pamọ́ sínú dátábésì, láìní láti tún ìlànà ṣiṣẹ́. A
ṣàpèjúwe àmì kọ̀ọ̀kan pẹ̀lú `FeatureFlagDefinition` kan tó ní `key`, `label`,
`description`, `category`, `defaultValue`, `type`, àti ìtọ́kasí `requiresRestart`.

### Ètò Ìpinnu

[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ló ń pinnu
**iye tó ń ṣiṣẹ́** fún àmì kan gẹ́gẹ́ bí àtòlẹ́sẹẹsẹ yìí (èyí tó ga jù ló borí):

1. **Ìṣàkóso láti DB** — iye tí a fi pamọ́ sínú tábìlì `key_value` lábẹ́
   àyè-orúkọ `feature_flags` (tí a ṣètò nípasẹ̀ dásíbọ́ọ̀dù tàbí REST API).
2. **Àyípadà àyíká** — `process.env[<KEY>]`, bí a bá ṣètò rẹ̀ tí kò sì ṣófo.
3. **Àìròtẹ́lẹ̀ ìtumọ̀** — `defaultValue` láti inú `featureFlagDefinitions.ts`.

A ka àmì boolean sí **tí a ti mú ṣiṣẹ́** nígbà tí iye tó ń ṣiṣẹ́ rẹ̀ bá jẹ́ `"true"`,
`"1"`, tàbí `"yes"` (wo `isFeatureFlagEnabled()`).

> [!NOTE]
> Ọ̀pọ̀ jù lọ àwọn àmì náà tún ní àyípadà àyíká tó bá wọn mu, pẹ̀lú **orúkọ kan náà**,
> tí a ṣàkọsílẹ̀ rẹ̀ nínú [`ENVIRONMENT.md`](./ENVIRONMENT.md). Ìṣàkóso àmì láti DB
> ní ipò gíga ju àyípadà àyíká yẹn lọ. A máa fi àmì tó ní
> `requiresRestart: true` pamọ́ lẹ́sẹ̀kẹsẹ̀, ṣùgbọ́n a kàn tún un kà nígbà tí ìlànà
> bá bẹ̀rẹ̀ — yíyí i padà máa ń fi àsíá **"Tún Sẹ́fà Bẹ̀rẹ̀"** hàn lórí dásíbọ́ọ̀dù.

nígbà tí kò bá sí àtúnṣe DB tàbí àyípadà àyíká.

## Yíyan Àwọn Àsíá Tan/Pa

### Pánẹ́ẹ̀lì Ìṣàkóso

Lọ sí **Pánẹ́ẹ̀lì Ìṣàkóso → Àwọn Ètò → Àwọn Àsíá Ẹ̀ya-iṣẹ́**
(`/dashboard/settings/feature-flags`). Àkójọpọ̀ náà
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
ṣe àtìlẹ́yìn fún:

- **Ṣíṣàwárí** nípasẹ̀ kọ́kọ́rọ́ tàbí àpèjúwe, àti **àsẹ̀** nípasẹ̀ ẹ̀ka (pẹ̀lú àfihàn àtọwọ́dá
  **Nílò Àtúnṣe Ìbẹ̀rẹ̀**).
- **Bọ́tìnì yíyan tan/pa** fún àwọn àsíá boolean àti **àkojọ aṣàyàn** fún àwọn àsíá enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Àmì orísun** kan fún àsíá kọ̀ọ̀kan — `DB`, `ENV`, tàbí `DEF` — tí ń fi ibi tí
  iye tó ń ṣiṣẹ́ ti wá hàn.
- Bọ́tìnì **Tún Ṣètò** (tí a ń fi hàn fún àwọn àsíá tó ní orísun `DB` nìkan) láti yọ ìṣàkóso àfikún náà,
  àti bọ́tìnì **Tún Gbogbo Àwọn Ìṣàkóso Àfikún Ṣètò** ní ìsàlẹ̀.
- Àkíyèsí **Tún Sẹ́fà Bẹ̀rẹ̀** nígbà tí a bá yí àsíá `requiresRestart` padà.

### REST API

Gbogbo ìṣiṣẹ́ ń gba ọ̀nà kan ṣoṣo:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Gbogbo method nílò session pánẹ́ẹ̀lì ìṣàkóso tí a ti fìdí rẹ̀ múlẹ̀ (`401` bí bẹ́ẹ̀ kọ́).

#### `GET /api/settings/feature-flags`

Ó ń dá gbogbo àsíá padà pẹ̀lú iye tó ń ṣiṣẹ́, orísun, àti àkótán rẹ̀.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... gbogbo àsíá 75
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Ṣètò tàbí yọ ìṣàkóso àfikún kan ṣoṣo. Ara: `{ key: string; value?: string }`.
Tí a kò bá fi `value` sí i, yóò yọ ìṣàkóso àfikún náà kúrò (yíyí padà sí env / iye àiyipada).

```bash
# Ṣètò ìṣàkóso àfikún DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Yọ ìṣàkóso àfikún náà kúrò (kò sí "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Ìdáhùn náà ń tún `effectiveValue`/`source` tuntun, `previousValue`/
`previousSource`, àti `requiresRestart` padà. A máa kọ àwọn kọ́kọ́rọ́ tí a kò mọ̀ àti àwọn iye enum
tí kò sí láàárín ààlà pẹ̀lú `400`.

#### `DELETE /api/settings/feature-flags`

Ó ń pa **gbogbo** àwọn ìṣàkóso àfikún DB rẹ́ lẹ́ẹ̀kan náà, tí yóò sì dá gbogbo àsíá padà sí iye env / àiyipada
rẹ̀. Ó ń dá `{ cleared: <count>, message: "..." }` padà.

> [!NOTE]
> Àwọn àsíá tí ó ní `requiresRestart: true` kì í bẹ̀rẹ̀ sí í ṣiṣẹ́ títí di ìgbà tí a bá tún process náà rù.
> Ìlànà àtúnṣe ìbẹ̀rẹ̀ ti pánẹ́ẹ̀lì ìṣàkóso ń pe `POST /api/restart`, lẹ́yìn náà ó ń ṣe ìbéèrè léraléra sí
> `GET /api/health/ping` títí sẹ́fà yóò fi padà ṣiṣẹ́.

## Ìpadàsẹ́yìn Ìnáwó Pàjáwìrì

`OMNIROUTE_EMERGENCY_FALLBACK` (ẹ̀ka `runtime`, iye àìyípadà `true`) ń ṣàkóso
ọ̀nà ìpadàsẹ́yìn ọ̀fẹ́ pàjáwìrì nínú
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Nígbà tí ó bá ṣiṣẹ́, àwọn ìbéèrè tó ti lo gbogbo ìnáwó wọn ni a máa darí sí
olùpèsè/model ìpadàsẹ́yìn ọ̀fẹ́ dípò kí wọ́n kùnà pátápátá. Ṣètò rẹ̀ sí `false` (tàbí `0`) — nípasẹ̀
bọ́tìnì ṣíṣí/pípa pátákó ìṣàkóso, ìṣàkóso iye DB, tàbí environment variable `OMNIROUTE_EMERGENCY_FALLBACK`
— láti pa ìhùwàsí náà, kí àwọn ìbéèrè tí ìnáwó wọn ti tán sì kùnà.
(A fi hàn gẹ́gẹ́ bí bọ́tìnì ṣíṣí/pípa lórí pátákó ìṣàkóso nínú àwọn PR #3741 / #3752.)
