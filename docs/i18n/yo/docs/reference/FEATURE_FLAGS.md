> Àwọn tógù àsìkò-ṣiṣe tí ń yí ìhùwàsí OmniRoute padà **láìṣe àtúnkóṣiṣẹ́**.
> Gbogbo àmì tí a tò síbí ni a ṣàlàyé nínú
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — orísun òtítọ́ kan ṣoṣo. Dásíbọ́ọ̀dù àti REST API méjèèjì ń kà láti inú
> fáìlì yẹn, nítorí náà a ṣe àgbéjáde tábìlì tó wà nísàlẹ̀ láti bá a mu ní 1:1.

---

## Kí Ni Àwọn Àmì Ẹ̀yà

Àmì ẹ̀yà jẹ́ tógù tó ní orúkọ (boolean tàbí enum) tí a lè yí iye rẹ̀ padà ní
àsìkò-ṣiṣe, tí a sì lè fi pamọ́ sínú dátábésì, láìní láti tún ìlànà ṣiṣẹ́. A
ṣàpèjúwe àmì kọ̀ọ̀kan pẹ̀lú `FeatureFlagDefinition` kan tó ní `key`, `label`,
`description`, `category`, `defaultValue`, `type`, àti ìtọ́kasí `requiresRestart`.

### Ètò Ìpinnu

[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ló ń pinnu
**iye tó ń ṣiṣẹ́** fún àmì kan gẹ́gẹ́ bí àtòlẹ́sẹẹsẹ yìí (èyí tó ga jù ló borí):

1. **Ìṣàkóso láti DB** — iye tí a fi pamọ́ sínú tábìlì `key_value` lábẹ́
   àyè-orúkọ `feature_flags` (tí a ṣètò nípasẹ̀ dásíbọ́ọ̀dù tàbí REST API).
2. **Àyípadà àyíká** — `process.env[<KEY>]`, bí a bá ṣètò rẹ̀ tí kò sì ṣófo.
3. **Àìròtẹ́lẹ̀ ìtumọ̀** — `defaultValue` láti inú `featureFlagDefinitions.ts`.

A ka àmì boolean sí **tí a ti mú ṣiṣẹ́** nígbà tí iye tó ń ṣiṣẹ́ rẹ̀ bá jẹ́ `"true"`,
`"1"`, tàbí `"yes"` (wo `isFeatureFlagEnabled()`).

> [!NOTE]
> Ọ̀pọ̀ jù lọ àwọn àmì náà tún ní àyípadà àyíká tó bá wọn mu, pẹ̀lú **orúkọ kan náà**,
> tí a ṣàkọsílẹ̀ rẹ̀ nínú [`ENVIRONMENT.md`](./ENVIRONMENT.md). Ìṣàkóso àmì láti DB
> ní ipò gíga ju àyípadà àyíká yẹn lọ. A máa fi àmì tó ní
> `requiresRestart: true` pamọ́ lẹ́sẹ̀kẹsẹ̀, ṣùgbọ́n a kàn tún un kà nígbà tí ìlànà
> bá bẹ̀rẹ̀ — yíyí i padà máa ń fi àsíá **"Tún Sẹ́fà Bẹ̀rẹ̀"** hàn lórí dásíbọ́ọ̀dù.

## Ṣíṣí àti Pípa Àwọn Àsìá

### Pátákó Ìṣàkóso

Lọ sí **Pátákó Ìṣàkóso → Àwọn Ètò → Àwọn Àsìá Ẹ̀yà**
(`/dashboard/settings/feature-flags`). Àkójọpọ̀ alátẹ̀jáde náà
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
ṣe àtìlẹ́yìn fún:

- **Ìṣàwárí** nípasẹ̀ kọ́kọ́rọ́ tàbí àpèjúwe, àti **àsẹ̀** nípasẹ̀ ẹ̀ka (pẹ̀lú ìwòye
  **Nílò Àtúnrẹ̀ Ẹ̀rọ** tí a ṣẹ̀dá).
- **Bọ́tìnì ìṣí/pípa** fún àwọn àsìá boolean àti **àkojọ aṣàyàn** fún àwọn àsìá enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Àmì orísun** fún àsìá kọ̀ọ̀kan — `DB`, `ENV`, tàbí `DEF` — tí ń fi ibi tí
  iye tó ń ṣiṣẹ́ ti wá hàn.
- Bọ́tìnì **Túnṣe** (tí a máa ń fi hàn fún àwọn àsìá tó ní orísun `DB` nìkan) láti yọ ìkọ̀lé iye kúrò,
  àti bọ́tìnì **Tún Gbogbo Àwọn Ìkọ̀lé Iye Ṣe** ní ìsàlẹ̀.
- Àkíyèsí **Tún Olùpèsè Bẹ̀rẹ̀** nígbà tí a bá yí àsìá `requiresRestart` padà.

### REST API

Gbogbo ìṣe ń gba ipa-ọ̀nà kan ṣoṣo kọjá:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Ọ̀nà kọ̀ọ̀kan nílò ìjókòó pátákó ìṣàkóso tí a ti fìdí rẹ̀ múlẹ̀ (`401` bí kò bá rí bẹ́ẹ̀).

#### `GET /api/settings/feature-flags`

Ó máa ń dá gbogbo àsìá padà pẹ̀lú iye tó ń ṣiṣẹ́, orísun, àti àkótán rẹ̀.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... gbogbo àsìá 74
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Ṣètò tàbí yọ ìkọ̀lé iye kan ṣoṣo kúrò. Ara: `{ key: string; value?: string }`.
Tí a kò bá fi `value` sí i, yóò yọ ìkọ̀lé iye náà kúrò (yóò sì mú iye env / àìyípadà padà bọ̀ sípò).

```bash
# Ṣètò ìkọ̀lé iye DB kan
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Yọ ìkọ̀lé iye náà kúrò (kò sí "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Ìdáhùn náà máa ń dá `effectiveValue`/`source` tuntun, `previousValue`/
`previousSource`, àti `requiresRestart` padà. A máa kọ àwọn kọ́kọ́rọ́ àìmọ̀ àti àwọn iye enum
tí kò sí láàárín ààlà sílẹ̀ pẹ̀lú `400`.

#### `DELETE /api/settings/feature-flags`

Ó pa **gbogbo** ìkọ̀lé iye DB rẹ́ lẹ́ẹ̀kan náà, ó sì mú gbogbo àsìá padà sí iye env / àìyípadà
rẹ̀. Ó máa ń dá `{ cleared: <count>, message: "..." }` padà.

> [!NOTE]
> Àwọn àsìá tó ní `requiresRestart: true` kò ní bẹ̀rẹ̀ sí í ṣiṣẹ́ títí di ìgbà tí a bá tún ìlànà náà gbé wọlé.
> Ìṣàn àtúnrẹ̀ pátákó ìṣàkóso máa ń pe `POST /api/restart`, lẹ́yìn náà yóò máa ṣàyẹ̀wò
> `GET /api/health/ping` léraléra títí olùpèsè yóò fi padà ṣiṣẹ́.

## Ìpadàsẹ́yìn Ìnáwó Pàjáwìrì

`OMNIROUTE_EMERGENCY_FALLBACK` (ẹ̀ka `runtime`, iye àìyípadà `true`) ń ṣàkóso
ọ̀nà ìpadàsẹ́yìn ọ̀fẹ́ pàjáwìrì nínú
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Nígbà tí ó bá ṣiṣẹ́, àwọn ìbéèrè tó ti lo gbogbo ìnáwó wọn ni a máa darí sí
olùpèsè/model ìpadàsẹ́yìn ọ̀fẹ́ dípò kí wọ́n kùnà pátápátá. Ṣètò rẹ̀ sí `false` (tàbí `0`) — nípasẹ̀
bọ́tìnì ṣíṣí/pípa pátákó ìṣàkóso, ìṣàkóso iye DB, tàbí environment variable `OMNIROUTE_EMERGENCY_FALLBACK`
— láti pa ìhùwàsí náà, kí àwọn ìbéèrè tí ìnáwó wọn ti tán sì kùnà.
(A fi hàn gẹ́gẹ́ bí bọ́tìnì ṣíṣí/pípa lórí pátákó ìṣàkóso nínú àwọn PR #3741 / #3752.)
