> **Orísun òtítọ́:** `src/lib/{cloudflaredTunnel,ngrokTunnel,tailscaleTunnel}.ts`, `src/app/api/tunnels/`
> **Ìmúdójúìwọ̀n tó kẹ́yìn:** 2026-06-28 — v3.8.40

OmniRoute lè ṣí olupèsè agbègbè rẹ̀ (`http://localhost:20128`) sí íńtánẹ́ẹ̀tì
gbangba nípasẹ̀ àwọn ẹ̀yìn-ọ̀nà tunnel mẹ́ta. Èyí wúlò fún:

- Àwọn ìpèpadà OAuth láti ọ̀dọ̀ àwọn olupèsè cloud (Antigravity, Gemini, Cursor) tí wọ́n nílò
  URL àtúndarí tí gbogbo ènìyàn lè dé sí.
- Pípín instance agbègbè rẹ pẹ̀lú àwọn alábàáṣiṣẹ́ láìsí fífi VM kan ránṣẹ́ síṣẹ́.
- Ìdánwò lórí ẹ̀rọ alágbèéká, láti ọ̀nà jíjìn, tàbí láàárín àwọn nẹ́tíwọ́ọ̀kì.

Gbogbo àwọn ẹ̀yìn-ọ̀nà mẹ́tẹ̀ẹ̀ta ni a ń ṣàkóso láàrín process — OmniRoute ń bẹ̀rẹ̀/dá
binary tàbí SDK tó wà lẹ́yìn dúró láti dashboard tàbí REST API. Kò nílò ìṣètò
reverse-proxy tàbí systemd.

## Àkópọ̀ àwọn ẹ̀yìn-ọ̀nà

| Ẹ̀yìn-ọ̀nà                    | Ìdúróṣinṣin                                                           | Iye owó                 | Ìṣètò                                           |
| --------------------------- | --------------------------------------------------------------------- | ----------------------- | ----------------------------------------------- |
| **Cloudflare Quick Tunnel** | Fún ìgbà díẹ̀ (URL máa ń yí padà ní gbogbo ìgbà tí a bá tún un bẹ̀rẹ̀)   | Ọ̀fẹ́                     | Kò sí — ó máa ń fi `cloudflared` sílẹ̀ fúnra rẹ̀  |
| **ngrok**                   | Ó dúró ṣinṣin nígbà tí a bá ṣètò ètò ìsanwó tàbí domain tí kò yí padà | Ìpele ọ̀fẹ́ + ìsanwó      | Ó nílò àkọọ́lẹ̀ ngrok + authtoken                 |
| **Tailscale Funnel**        | Ó dúró ṣinṣin fún node kọ̀ọ̀kan láàrín tailnet rẹ                       | Ọ̀fẹ́ fún lílò ti ara ẹni | Ó nílò fífi Tailscale sílẹ̀ + ìwọlé + Funnel ACL |

Àwọn ìmúṣẹ náà wà nínú `src/lib/cloudflaredTunnel.ts`,
`src/lib/ngrokTunnel.ts`, àti `src/lib/tailscaleTunnel.ts`. Gbogbo mẹ́tẹ̀ẹ̀ta ń dá ohun
`status` tí ìrísí rẹ̀ jọra padà, pẹ̀lú àwọn field `phase`, `running`, `publicUrl`, `apiUrl`,
`targetUrl`, àti `lastError`, kí dashboard lè ṣàfihàn wọn ní ọ̀nà kan náà.

## 1. Cloudflare Tunnel (Quick Tunnel + Named Tunnel)

`src/lib/cloudflaredTunnel.ts` ń ṣiṣẹ́ `cloudflared` gẹ́gẹ́ bí child process. Ó ṣe àtìlẹ́yìn
fún mode méjì, tí a yàn nípa bóyá a pèsè ìṣètò named-tunnel:

- **Quick tunnel (àìyípadà).** Ó ń ṣiṣẹ́ `cloudflared tunnel --url
http://localhost:<apiPort>` ó sì ń yọ URL `*.trycloudflare.com` tí a yàn
  jáde láti stdout. Àwọn URL náà jẹ́ ti ìgbà díẹ̀, wọ́n sì máa ń yí padà ní gbogbo ìgbà tí a bá tún un bẹ̀rẹ̀.
- **Named tunnel (yíyàn àfikún).** Nígbà tí `CLOUDFLARED_CONFIG` bá tọ́ka sí
  `config.yml` cloudflared tí a ń ṣàkóso ní agbègbè, OmniRoute máa ń ṣiṣẹ́ `cloudflared tunnel --no-autoupdate
--config <path> run`, èyí tó ń fún ọ ní **hostname aláìyípadà tí a dárúkọ**. Ìṣètò náà
  ń pèsè UUID tunnel, `credentials-file`, àti ìtọ́sọ́nà `ingress`, nítorí náà a kì í
  fi `--url` ránṣẹ́, bẹ́ẹ̀ ni kò nílò token dashboard Zero Trust. `run` máa ń ka
  credentials láti path `credentials-file` pípé inú ìṣètò náà — kò nílò `cert.pem`
  (èyí wúlò fún ìṣàkóso lifecycle tunnel nìkan).

Àwọn ìhùwàsí pàtàkì:

- **Fífì sílẹ̀ láìfọwọ́ṣe.** Ní ìlò àkọ́kọ́, OmniRoute máa ń gba binary `cloudflared`
  tuntun jù lọ láti àwọn release GitHub osìṣẹ́ (fífì sílẹ̀ tí a ṣàkóso wà lábẹ́
  `DATA_DIR/cloudflared/`). A máa ń ṣàyẹ̀wò SHA256 asset tí a gbà sílẹ̀ pẹ̀lú
  manifest release kí a tó ṣiṣẹ́ ẹ.
- **Àbójútó process.** A máa ń fi PID cloudflared àti URL tí a ti pinnu pamọ́ sínú
  `quick-tunnel-state.json` kí dashboard lè tún ipò náà padà lẹ́yìn reload.

### Ìṣètò named tunnel (hostname aláìyípadà)

1. Ṣẹ̀dá tunnel tí a ń ṣàkóso ní agbègbè pẹ̀lú cloudflared CLI (lẹ́ẹ̀kan ṣoṣo):

   ```bash
   cloudflared tunnel login
   cloudflared tunnel create omniroute
   cloudflared tunnel route dns omniroute ai.example.com
   ```

2. Kọ `~/.cloudflared/config.yml` kan tó ń darí hostname rẹ sí port API agbègbè
   OmniRoute (àìyípadà 20128):

   ```yaml
   tunnel: <UUID-from-create>
   credentials-file: /home/you/.cloudflared/<UUID>.json
   ingress:
     - hostname: ai.example.com
       service: http://127.0.0.1:20128
     - service: http_status:404
   ```

3. Tọ́ka OmniRoute sí ìṣètò náà, kí o sì (tún) bẹ̀rẹ̀ tunnel náà:

   ```bash
   export CLOUDFLARED_CONFIG="/home/you/.cloudflared/config.yml"
   # àṣàyàn — èyí máa kọjá hostname tí OmniRoute ń jábọ̀; bí bẹ́ẹ̀ kọ́, a ó kà á láti
   # òfin ingress àkọ́kọ́ inú ìṣètò náà:
   # export CLOUDFLARED_HOSTNAME="ai.example.com"
   ```

   Mú tunnel náà ṣiṣẹ́ ní ọ̀nà kan náà bí quick tunnel (REST / dashboard / CLI
   nísàlẹ̀). Named tunnel kì í ṣe ìtẹ̀jáde URL gbogbogbo láti yọ jáde, nítorí náà a máa ń mọ̀
   pé ó ti ṣetán láti inú ìsopọ̀ edge tí cloudflared forúkọsílẹ̀, a sì máa ń jábọ̀
   `publicUrl`/`apiUrl` láti `CLOUDFLARED_HOSTNAME` (tàbí hostname ingress àkọ́kọ́ inú ìṣètò náà).

### Mú ṣiṣẹ́ / pa nípasẹ̀ REST

Endpoint náà ń lo body `{action: "enable" | "disable"}`, kì í ṣe path
`start`/`stop` ọ̀tọ̀ọ̀tọ̀. Ó nílò ìfàṣẹsí ìṣàkóso (session admin tàbí key API admin).

```bash
# Mú ṣiṣẹ́
curl -X POST http://localhost:20128/api/tunnels/cloudflared \
  -H "Content-Type: application/json" \
  -H "Cookie: auth_token=..." \
  -d '{"action":"enable"}'

# Ipò
curl http://localhost:20128/api/tunnels/cloudflared \
  -H "Cookie: auth_token=..."

# Pa
curl -X POST http://localhost:20128/api/tunnels/cloudflared \
  -H "Content-Type: application/json" \
  -H "Cookie: auth_token=..." \
  -d '{"action":"disable"}'
```

Tàbí nípasẹ̀ dashboard: **Settings → Tunnels → Cloudflare**.

### Àwọn env var àṣàyàn

| Àyípadà                                              | Ìdí lílò                                                                                                                                                                                     |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CLOUDFLARED_BIN`                                    | Ṣàtúnkọ ọ̀nà fáìlì aláṣẹ méjì. Tí a bá ṣètò rẹ̀ tí ó sì fẹsẹ̀ múlẹ̀, OmniRoute yóò lò ó dípò gbígbàsílẹ̀.                                                                                         |
| `CLOUDFLARED_PROTOCOL` / `TUNNEL_TRANSPORT_PROTOCOL` | Ìlànà ìgbéwọlé (àiyípadà àkọ́kọ́ `http2`; pẹ̀lú `quic`, `auto`).                                                                                                                                |
| `CLOUDFLARED_CONFIG`                                 | Ọ̀nà sí cloudflared `config.yml` tí a ń ṣàkóso ní agbègbè. Nígbà tí a bá ṣètò rẹ̀, OmniRoute yóò ṣiṣẹ́ oju-ọ̀nà **tí a dárúkọ/tí ó dúró pẹ́** (`tunnel --config <path> run`) dípò oju-ọ̀nà kíákíá. |
| `CLOUDFLARED_HOSTNAME`                               | Ṣàtúnkọ orúkọ agbalejo gbogbogbò tí oju-ọ̀nà tí a dárúkọ ròyìn (fún àpẹẹrẹ, `ai.example.com`). Nígbà tí a kò bá ṣètò rẹ̀, a ó kà á láti orúkọ agbalejo `ingress` àkọ́kọ́ inú àtòjọ ìṣètò náà.    |

## 2. ngrok

`src/lib/ngrokTunnel.ts` ń lo **`@ngrok/ngrok` SDK** (nínú ìlànà iṣẹ́ náà, láìsí ìlànà-abẹ́ CLI).
A máa ń ṣàkójọ module abinibi náà nígbà tí a bá kọ́kọ́ bẹ̀rẹ̀ rẹ̀, kí àwọn platform
tí kò ní binary tí a ti kọ́ tẹ́lẹ̀ má bàjẹ́ ìṣàfilọ́lẹ̀ náà nígbà ìbẹ̀rẹ̀.

### Àwọn ohun tí a nílò ṣáájú

1. Forúkọsílẹ̀ ní <https://ngrok.com>.
2. Da authtoken rẹ̀ kọ láti dashboard ngrok.
3. Pèsè rẹ̀ nípasẹ̀ ọ̀kan nínú àwọn ọ̀nà wọ̀nyí:
   - `.env`: `NGROK_AUTHTOKEN=<token>`, tàbí
   - Dashboard: **Settings → Tunnels → ngrok**, tàbí
   - Ara REST (lílò ẹ̀ẹ̀kan): `{"action":"enable","authToken":"<token>"}`.

Bí kò bá sí èyíkéyìí tí a ti ṣètò, ipò náà yóò dá `phase: "needs_auth"` padà.

### Mú ṣiṣẹ́ / mú kúrò nípasẹ̀ REST

```bash
# Mú ṣiṣẹ́ (ń lo NGROK_AUTHTOKEN láti env)
curl -X POST http://localhost:20128/api/tunnels/ngrok \
  -H "Content-Type: application/json" \
  -H "Cookie: auth_token=..." \
  -d '{"action":"enable"}'

# Mú ṣiṣẹ́ pẹ̀lú token inú ìbéèrè
curl -X POST http://localhost:20128/api/tunnels/ngrok \
  -H "Content-Type: application/json" \
  -H "Cookie: auth_token=..." \
  -d '{"action":"enable","authToken":"2abc..."}'

# Ipò
curl http://localhost:20128/api/tunnels/ngrok \
  -H "Cookie: auth_token=..."

# Mú kúrò
curl -X POST http://localhost:20128/api/tunnels/ngrok \
  -H "Content-Type: application/json" \
  -H "Cookie: auth_token=..." \
  -d '{"action":"disable"}'
```

Ìdáhùn náà ní `publicUrl` tí a yàn sí i (fún àpẹẹrẹ,
`https://abcd-1234.ngrok-free.app`). Àwọn domain àdáni, àwọn agbègbè, àti àwọn òfin policy
gbọdọ̀ jẹ́ ṣíṣe àtúnṣe wọn nínú dashboard ngrok — OmniRoute fúnra rẹ̀ kàn ń darí URL
àfojúsùn agbègbè náà lọ sí SDK.

## 3. Tailscale Funnel

`src/lib/tailscaleTunnel.ts` ń ṣètò CLI `tailscale` ti system láti ṣí
port API agbègbè náà síta nípasẹ̀ **Funnel** (ọ̀nà ìjáde Tailscale sí íńtánẹ́ẹ̀tì gbogbogbò fún serve).
Ó ṣe àtìlẹ́yìn fún gbogbo ìgbésí-ayé rẹ̀: fífi sori ẹ̀rọ, wíwọlé, bíbẹ̀rẹ̀ daemon, mímú ṣiṣẹ́, àti mímú kúrò.

Ìmúṣẹ náà ń pe `tailscale funnel --bg <port>` (ipò abẹ́lẹ̀). URL
gbogbogbò náà ní àpẹẹrẹ `https://<machine>.<tailnet>.ts.net/`.

### Àwọn ohun tí a nílò ṣáájú

1. Fi Tailscale sori ẹ̀rọ (tàbí jẹ́ kí OmniRoute ṣe é — wo endpoint `install` ní ìsàlẹ̀).
2. Wọlé (`tailscale login` tàbí nípasẹ̀ endpoint `login` ti OmniRoute).
3. Mú Funnel ṣiṣẹ́ fún tailnet rẹ nínú console alákóso Tailscale:
   <https://login.tailscale.com/admin/settings/features>.

Lórí Linux àti macOS, daemon (`tailscaled`) nílò `sudo` láti ṣàkóso rẹ̀. Àwọn
endpoint POST gba field `sudoPassword` tí kò pọndandan, èyí tí a máa ń fi ránṣẹ́ sí
ibi ìpamọ́ ọ̀rọ̀ aṣínà MITM ti OmniRoute (`getCachedPassword` / `setCachedPassword`) fún
àkókò tí ìpè náà bá fi ń ṣiṣẹ́. Windows ń lo service tí a fi sori ẹ̀rọ ní àìyípadà ní
`C:\Program Files\Tailscale\tailscale.exe`.

### Àwọn endpoint REST

Tailscale ní ojú iṣẹ́ tó gbòòrò ju àwọn backend yòókù lọ nítorí pé fífi sori ẹ̀rọ,
wíwọlé, daemon, àti tunnel jẹ́ ọ̀ràn ọ̀tọ̀ọ̀tọ̀.

| Endpoint                              | Ọ̀nà    | Ète                                                                                |
| ------------------------------------- | ------ | ---------------------------------------------------------------------------------- |
| `/api/tunnels/tailscale`              | `GET`  | Àkójọpọ̀ ipò tunnel (`phase`, `tunnelUrl`, `apiUrl`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ)                |
| `/api/tunnels/tailscale/check`        | `GET`  | Àyẹ̀wò ìpele-ìsàlẹ̀: ṣé a ti fi sori ẹ̀rọ? ṣé a ti wọlé? ṣé daemon ń ṣiṣẹ́?            |
| `/api/tunnels/tailscale/install`      | `POST` | Fi Tailscale sori ẹ̀rọ (àwọn ìṣẹ̀lẹ̀ ìlọsíwájú tí a ń sanwọlé pẹ̀lú SSE) — Linux/macOS |
| `/api/tunnels/tailscale/start-daemon` | `POST` | Bẹ̀rẹ̀ `tailscaled` lórí Linux/macOS                                                 |
| `/api/tunnels/tailscale/login`        | `POST` | Bẹ̀rẹ̀ ìlànà wíwọlé; ó dá `authUrl` padà láti ṣí nínú browser                        |
| `/api/tunnels/tailscale/enable`       | `POST` | Bẹ̀rẹ̀ Funnel fún port API                                                           |
| `/api/tunnels/tailscale/disable`      | `POST` | Dá Funnel dúró                                                                     |

Gbogbo àwọn endpoint Tailscale nílò ìfàṣẹsí ìṣàkóso (wo `routeUtils.ts ::
requireTailscaleAuth`).

Àpẹẹrẹ mímú ṣiṣẹ́:

```bash
curl -X POST http://localhost:20128/api/tunnels/tailscale/enable \
  -H "Content-Type: application/json" \
  -H "Cookie: auth_token=..." \
  -d '{"sudoPassword":"<linux-pwd>","port":20128}'
```

Bí Funnel kò bá ṣiṣẹ́ nínú console alákóso, ìdáhùn náà yóò ní
`funnelNotEnabled: true` pẹ̀lú `enableUrl` láti ṣí nínú browser.

### Àwọn env vars àṣàyàn

| Variable        | Ète                             |
| --------------- | ------------------------------- |
| `TAILSCALE_BIN` | Ṣàtúnṣe path binary `tailscale` |

## Àwọn ohun tó yẹ ká gbé yẹ̀ wò fún callback OAuth

Nígbà tí o bá ṣí OmniRoute síta nípasẹ̀ tunnel, dashboard àti àwọn ìṣàn OAuth gbọ́dọ̀
kọ àwọn URL callback ní lílo hostname **gbangba**, kì í ṣe `localhost`. Bí bẹ́ẹ̀ kọ́,
olùpèsè OAuth yóò darí aṣàmúlò padà sí URL tí àwọn server rẹ̀ kò lè dé,
ìfọwọ́sowọ́pọ̀ náà yóò sì kùnà.

Àwọn àtúnṣe dashboard àti fífi àwọn ààtò pamọ́ kò nílò fífi hostname tunnel náà dúró ṣinṣin nínú
`NEXT_PUBLIC_BASE_URL`. Dashboard tí a ti fìdí ìdánimọ̀ rẹ̀ múlẹ̀ ń fi àwọn ìbéèrè same-origin tí kò ní ààbò
ránṣẹ́ pẹ̀lú token CSRF tí a so mọ́ session, nítorí náà àwọn olùgbàlejò Cloudflare Quick Tunnel
tí ń yí padà ṣì lè jẹ́ lílò fún ìṣàkóso UI déédé lẹ́yìn tí a bá wọlé.

Ṣètò:

```bash
NEXT_PUBLIC_BASE_URL=https://<your-tunnel-host>
```

kí o sì tún OmniRoute bẹ̀rẹ̀ kí o tó bẹ̀rẹ̀ OAuth. Fún Cloudflare Quick
Tunnels tí ń yí padà, URL náà máa ń yí padà lẹ́yìn gbogbo ìtún-bẹ̀rẹ̀, nítorí náà yan ngrok pẹ̀lú domain
tí a ti fi pamọ́ tàbí Tailscale Funnel fún lílo OAuth ní production.

## Ìlera àti àbójútó

Dashboard náà ń ṣàfihàn ipò tunnel lábẹ́ **Settings → Tunnels**:

- Backend tó ń ṣiṣẹ́ àti `phase` lọ́wọ́lọ́wọ́ (`stopped`, `starting`, `running`,
  `needs_auth`, `error`).
- URL gbangba lọ́wọ́lọ́wọ́ àti URL API tí a ṣe jáde láti inú rẹ̀ (`<publicUrl>/v1`).
- URL ibi-afẹ́ local tí tunnel náà ń darí ìbáraẹnisọ̀rọ̀ sí.
- Ìfiránṣẹ́ àṣìṣe tó ṣẹ̀ṣẹ̀ kẹ́yìn, bí ó bá wà.

Fún àbójútó pẹ̀lú ètò, máa poll àwọn endpoint `GET` fún backend kọ̀ọ̀kan. Ṣíṣe backend ju
ọ̀kan lọ ní àkókò kan náà jẹ́ ìfàyègbà; OmniRoute yóò tọpinpin ọ̀kọ̀ọ̀kan
lọ́tọ̀.

## Yíyanjú ìṣòro

### "cloudflared binary not found"

OmniRoute máa ń gbìyànjú láti fi í sí ẹ̀rọ fúnra rẹ̀ ní ìgbà àkọ́kọ́ tí a bá lò ó. Tí a bá dí ìfísílẹ̀ náà
(nẹ́tíwọ́ọ̀kì tí a ní ààlà, kò sí àyè sí GitHub), gba `cloudflared` sílẹ̀ fúnra rẹ
láti <https://github.com/cloudflare/cloudflared/releases> kí o sì ṣètò
`CLOUDFLARED_BIN=/path/to/cloudflared`.

### "ngrok: authtoken required"

`phase: "needs_auth"` túmọ̀ sí pé a kò rí authtoken kankan. Ṣètò `NGROK_AUTHTOKEN` nínú
`.env`, ṣètò rẹ̀ nípasẹ̀ dashboard, tàbí fi `authToken` ránṣẹ́ nínú body POST
fún enable.

### "tailscale: funnel not enabled"

Nígbà tí ìdáhùn enable bá ní `funnelNotEnabled: true`, Funnel kò ṣiṣẹ́
fún tailnet rẹ. Ṣí `enableUrl` tí a dá padà (tàbí ojú-ewé feature nínú console
admin) kí o sì tan Funnel.

### Ìyípadà URL tunnel ń ba OAuth jẹ́

Lo ngrok pẹ̀lú domain tí a ti fi pamọ́ tàbí Tailscale Funnel (àwọn méjèèjì dúró ṣinṣin fún node kọ̀ọ̀kan).
Cloudflare Quick Tunnels ń yí padà gẹ́gẹ́ bí a ṣe ṣe wọ́n, a kò sì dábàá wọn fún
àwọn callback OAuth tí yóò wà fún ìgbà pípẹ́.

### A kọ ìfàyè sílẹ̀ lórí Linux/macOS fún Tailscale

`tailscaled` nílò root. Pèsè `sudoPassword` sí endpoint POST tó yẹ,
tàbí ṣiṣẹ́ daemon náà fúnra rẹ (`sudo systemctl start tailscaled`).
