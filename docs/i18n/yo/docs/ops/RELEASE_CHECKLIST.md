## Ìtẹ̀jáde npm Tí A Fọkàn Tán (àìyípadà láti v3.8.51) — títẹ̀jáde sí ìpele nígbà tí a bá béèrè, tààrà gẹ́gẹ́ bí ọ̀nà àfirọ́pò

`npm-publish.yml` ń tẹ̀jáde nípasẹ̀ **npm Trusted Publishing (OIDC)** gẹ́gẹ́ bí àìyípadà:
iṣẹ́ `stage-npm` (tí GitHub gbàlejò) ń pààrọ̀ id-token GitHub fún ẹ̀rí ìdánimọ̀ npm
alákòókò-kúkúrú fún ìṣiṣẹ́ yẹn — kò sí token npm alákòókò-gígùn nínú àwọn àṣírí ibi ìpamọ́, kò sí ìbéèrè 2FA, a sì so ẹ̀rí orísun mọ́ ọn.
Èyí ni ọ̀nà àkọjá tí npm fọwọ́ sí nísinsìnyí tí wọ́n ti ń fòpin sí àwọn token tí ń foju kọ 2FA;
ó mú ìṣàn aládàáṣiṣẹ́ pátápátá tí iṣẹ́ náà ní títí dé v3.8.48 padà, nígbà tí ó ń pa
ìdánilójú WS1.3 mọ́ (token tí ó ti tú jáde kò lè tẹ̀jáde ní òun nìkan — kò sí token).

**Ètò ẹ̀ẹ̀kan ṣoṣo (onílé):** npmjs.com → package `omniroute` → Settings → _Trusted
Publisher_ → GitHub: owner `diegosouzapw`, repo `OmniRoute`, workflow `npm-publish.yml`
(environment: none). Títí tí èyí yóò fi wà, ìgbésẹ̀ aládàáṣiṣẹ́ náà yóò kùnà pẹ̀lú `ENEEDAUTH`:
tún firánṣẹ́ pẹ̀lú `publish_mode=staged` (ní ìsàlẹ̀) tàbí `direct`.

### Títẹ̀jáde sí ìpele (nígbà tí a bá béèrè — `publish_mode=staged`)

Workflow npm-publish kò tẹ̀jáde tààrà mọ́: ó ń tan tarball tí a ti dì
(`check:pack-boot`) lẹ́yìn náà ó ń ṣiṣẹ́ `npm stage publish` — àwọn byte kan náà ni a fi pamọ́ sórí
registry, **a kò lè fi wọlé** títí onílé yóò fi fọwọ́ sí i. Ẹnu-ọ̀nà 2FA ti ènìyàn
ti kúrò ní ṢÁÁJÚ ẹ̀rí sí LẸ́YÌN rẹ̀.

**Ìṣàn onílé lẹ́yìn tí workflow bá di àwọ̀ ewé:**

1. `npm stage list omniroute` — wá stage id náà (a tún tẹ̀ ẹ́ jáde nínú àkótán workflow).
2. Ṣàyẹ̀wò àwọn byte tí a fi sí ìpele (a dábàá rẹ̀): `npm stage download <id>`, lẹ́yìn náà fi
   tarball tí a gba sílẹ̀ wọ inú prefix ìgbà díẹ̀ kí o sì tan án (`npm run check:pack-boot` ń ṣe
   ìdájọ́ pack→install→boot kan náà ní CI ní aládàáṣiṣẹ́).
3. `npm stage approve <id>` — ìbéèrè 2FA náà GAN-AN ni ìtẹ̀jáde. `npm stage reject <id>` ń sọ ọ́ nù.
4. Àwọ̀n ààbò lẹ́yìn ìtẹ̀jáde: olùṣàyẹ̀wò lẹ́yìn ìtẹ̀jáde (WS1.4 ti ètò v3.8.49) ń fi
   ẹ̀yà tí a tẹ̀jáde láti inú registry gbogbo ènìyàn wọ inú container mímọ́, ó sì ń tan án.

**Ọ̀nà àfirọ́pò pàjáwìrì:** `workflow_dispatch` pẹ̀lú `publish_mode=direct` ń mú
`npm publish` lẹ́sẹ̀kẹsẹ̀ ti àtijọ́ padà (lò ó nìkan bí fífi sí ìpele fúnra rẹ̀ kò bá ṣiṣẹ́ dáadáa; ṣàkọsílẹ̀ ìdí).

**Ìmúle ẹ̀ẹ̀kan ṣoṣo (onílé, npmjs.com):** ṣètò Trusted Publisher fún
`omniroute` ní ipo stage-only kí token alákòókò-gígùn tí ó tú jáde má baà lè ṣe `npm publish`
tààrà láti ibikíbi — CI lè fi sí ìpele nìkan; 2FA onílé nìkan ló lè tú u jáde.

**Ìtọ́sọ́nà fún artifact tó bàjẹ́ (kò yípadà):** `npm deprecate omniroute@<bad> "<reason> — use <fixed>"`
gẹ́gẹ́ bí ìgbésẹ̀ àkọ́kọ́ àìyípadà (ìṣẹ́jú díẹ̀, a lè yí i padà); `npm unpublish` nìkan láàárín àkókò 72h/no-dependents
kì í sì í ṣe ìgbésẹ̀ àkọ́kọ́ láé. Docker: má ṣe tún tag ẹ̀yà kọ láé — rollback ni
títọ́ka `latest` padà sí digest tó dára kẹ́yìn.

**Docker Hub `latest` (ó pọndandan fún gbogbo ìtẹ̀jáde SemVer tó dúró ṣinṣin):**
workflow `docker-publish` gbọ́dọ̀ fi tag sí **méjèèjì** `X.Y.Z` àti, nígbà tí
`should-promote-latest.sh` bá fohùn ṣọ̀kan pé èyí ni SemVer tó dúró ṣinṣin tó ga jù lọ, `:latest`
pẹ̀lú **digest kan náà**. Lẹ́yìn iṣẹ́ náà: digest Hub `latest` dọ́gba pẹ̀lú digest SemVer tuntun,
`last_updated` sì ti yí. Má fi `:latest` sí build àgbà nígbà tí àwọn àkọsílẹ̀ ìtújáde
ń sọ nípa àwọn àtúnṣe tí ó wà lórí git nìkan. Àwọn ìbẹ̀rẹ̀-kíákíá Compose ń lo `:latest`;
GitOps gbọ́dọ̀ máa tẹ̀síwájú láti ṣàmúlẹ̀ `X.Y.Z`. Wo
[Àwọn ikanni ìtújáde Docker](../guides/DOCKER_GUIDE.md#release-channels) àti #10317.

## Ọ̀nà-Yíyára fún Àtúnṣe-Pàjáwìrì (àmì `hotfix`)

PR tí a fi àmì `hotfix` sí máa fo matrix CI tó wuwo (E2E aláṣọ́-mẹ́sàn-án, ratchet ìborí,
quality-gate, quality-extended), yóò sì pa àwọn ibodè tó yára, tó sì ń fúnni ní àmì tó ṣe kedere mọ́: ìkọ́lé,
àwọn ṣọ́ọ̀ṣì unit, integration, vitest, lint/typecheck, docs-sync, `check:pack-artifact`
àti ìdánwò ìbẹ̀rẹ̀ tarball (`check:pack-boot`). Àfojúsùn: kí gbogbo rẹ̀ jẹ́ aláwọ̀-ewé láàárín ≤15min dípò ~33min.

**Ìlànà ìwọlé — gbogbo mẹ́rin ni a nílò (tí a ṣe àwòkọ́ṣe rẹ̀ láti ọ̀nà pàjáwìrì Chromium/VS Code/Node):**

1. **Ìpele ewu**: production ti bàjẹ́ — artifact tí a tẹ̀ jáde ń ṣubú nígbà ìbẹ̀rẹ̀ / àtúnṣe ààbò /
   gbogbo olùlò release náà ni ìṣòro náà kan. “Ó ṣe pàtàkì” kò túmọ̀ sí “ó bàjẹ́”.
2. **Àṣẹ**: olówó repository nìkan ló lè fi àmì `hotfix` sí. Àmì náà GAN-AN
   ni ìfọwọ́sí — kò gbọdọ̀ jẹ́ ohun tí ẹni fúnra rẹ̀ ṣe lórí PR campaign kan.
3. **Ẹ̀rí**: ara PR náà ní ìjápọ̀ sí heavy run tó kẹ́yìn tí gbogbo rẹ̀ jẹ́ aláwọ̀-ewé (suite tí
   àwọn job tí a fo yóò tún fìdí rẹ̀ múlẹ̀), pẹ̀lú ìdánwò àtúnṣe náà fúnra rẹ̀ tó kọ́kọ́ kùnà, tó sì wá kọjá.
4. **Ààlà iṣẹ́**: cherry-pick nìkan — àtúnṣe tó kéré jù lọ, kò sí refactor, kò sì sí iṣẹ́ mìíràn tí a bá a kó wọlé.

Next full run lórí ẹ̀ka release (release-green tó ń lọ láìdáwọ́dúró) yóò tún fìdí
coverage/ratchet surface tí a fo múlẹ̀ — ọ̀nà náà ń fo ÌDÚRÓ nìkan, kì í fo ìfọwọ́sí.
Àwọn diff tí ó jẹ́ ti ìdánwò nìkan (gbogbo fáìlì lábẹ́ `tests/`, kò sí èyíkéyìí lábẹ́ `tests/e2e/`) máa fo matrix E2E
láìfọwọ́yí, láìsí àmì kankan.

## Àtòjọ Àyẹ̀wò Alálàyé

### Ṣáájú release

- [ ] Gbogbo PR tí a darí sí release yìí ti darapọ̀ mọ́ `release/vX.Y.0`
- [ ] Gbogbo ohun Linear/issue tó ṣì ṣí fún version yìí ti di títì tàbí a ti sún wọn sí milestone tó tẹ̀ lé
- [ ] CI jẹ́ aláwọ̀-ewé lórí ẹ̀ka `release/vX.Y.0`
- [ ] Kò sí àmì `TODO(release)` nínú code: `grep -r "TODO(release)" src/ open-sse/`
- [ ] Docker base image jẹ́ ti ìgbàlódé (lọ́wọ́lọ́wọ́ `node:24.15.0-trixie-slim`)

### Version àti Changelog

- [ ] Ṣiṣe `/version-bump-cc <patch|minor|major>` (ọgbọ́n Claude Code)
  - Ó ń gbé version `package.json`, `electron/package.json` sókè
  - Ó ń tún `CHANGELOG.md` ṣe láti inú àwọn git commit láti tag tó kẹ́yìn
  - Ó ń ṣe àfikún ìgbàlódé sí àwọn badge README.md
- [ ] Ṣàyẹ̀wò CHANGELOG.md pẹ̀lú ọwọ́, kí o sì tún àwọn commit message ṣe bí ó bá yẹ
- [ ] Rí i dájú pé abala semver tuntun jù lọ nínú `CHANGELOG.md` bá version `package.json` mu
- [ ] Jẹ́ kí `## [Unreleased]` wà gẹ́gẹ́ bí abala changelog àkọ́kọ́ fún iṣẹ́ tó ń bọ̀
- [ ] Ṣe àfikún ìgbàlódé sí `docs/openapi.yaml` → `info.version` gbọ́dọ̀ bá version `package.json` mu

### Didára Code

- [ ] `npm run lint` — àṣìṣe 0 (àwọn ìkìlọ̀ ti wà tẹ́lẹ̀)
- [ ] `npm run typecheck:core` — mọ́
- [ ] `npm run typecheck:noimplicit:core` — mọ́ (tó muna)
- [ ] `npm run check:cycles` — kò sí dependency tó ń yípo
- [ ] `npm run check:any-budget:t11` — ó wà láàárín budget
- [ ] `npm run check:route-validation:t06` — mọ́
- [ ] `npm run check:node-runtime` — ó bá ìwọ̀n runtime tó kéré jù lọ tí a ṣe àtìlẹ́yìn fún mu (`>=22.22.2 <23`, `>=24.0.0 <27`, gẹ́gẹ́ bí `SUPPORTED_NODE_RANGE` nínú `src/shared/utils/nodeRuntimeSupport.ts`; ó bá `package.json` `engines` mu)

### Ìdánwò

- [ ] `npm run test:unit` — kọjá
- [ ] `npm run test:vitest` — kọjá (MCP server, autoCombo, cache)
- [ ] `npm run test:coverage` — ibodè 60/60/60/60 ti pé (statements/lines/functions/branches)
- [ ] `npm run test:integration` — kọjá (bí àwọn ìyípadà bá kan DB / handlers)
- [ ] `npm run test:combo:matrix` — kọjá (matrix ọgbọ́n combo: ó ń fìdí àwọn ìpinnu yíyan ti gbogbo ọgbọ́n routing 19 tó jẹ́ ti gbogbo ènìyàn múlẹ̀ lọ́nà tí àbájáde rẹ̀ dúró ṣinṣin; ṣiṣẹ́ rẹ̀ nígbà tí o bá kan combo routing, strategy resolution, tàbí fallback logic)
- [ ] `RUN_COMBO_LIVE=1 npm run test:combo:live` — **àṣàyàn/pẹ̀lú ọwọ́** (ìdánwò smoke real-upstream tí ibodè ń ṣàkóso; ó ń mú snapshot DB kíkà-nìkan láti VPS `root@192.168.0.15`; ó ń kan àwọn provider gidi, ó ń ná credit; kò ṣiṣẹ́ nínú CI láé; ó máa fo ní mímọ́ láìsí ibodè náà)
- [ ] `npm run test:combo:live:vps` — **àṣàyàn/pẹ̀lú ọwọ́** (ìdánwò smoke VPS laaye Ìpele-3: scenario HTTP 7 sí server `.15` tó wà láàyè nípasẹ̀ Node ESM lásán; ó nílò `ssh root@192.168.0.15`; ó ṣẹ̀dá/pa combo `__live_test__*` nìkan; ó ń kan àwọn provider gidi; kò ṣiṣẹ́ nínú CI láé)
- [ ] `npm run test:e2e` — kọjá (àwọn ìyípadà UI)
- [ ] `npm run test:protocols:e2e` — kọjá (àwọn ìyípadà MCP/A2A)

### Àwọn Hook (Husky ti fìdí wọn múlẹ̀)

Àwọn hook Husky wà nínú `.husky/`, wọ́n sì máa ń ṣiṣẹ́ láìfọwọ́yí lórí àwọn iṣẹ́ git.

- **pre-commit:** `npx lint-staged + node scripts/check/check-docs-sync.mjs + npm run check:any-budget:t11`
- **pre-push:** àwọn ibodè tó yára tí àbájáde wọn dúró ṣinṣin — `npm run check:any-budget:t11 && npm run check:tracked-artifacts` (a mú un ṣiṣẹ́ ní 2026-06-13). A mọ̀ọ́mọ̀ yọ `test:unit` kúrò (ó lọ́ra; job CI `test-unit` ló ń bójú tó o).
  - Ṣiṣe `npm run test:unit` pẹ̀lú ọwọ́ ṣáájú pípa ẹ̀ka release ránṣẹ́.

Bí hook kan bá kùnà: tún ìṣòro tó fà á ṣe, má ṣe forí rẹ̀ kọjá pẹ̀lú `--no-verify`.

### Àwọn Conventional Commit

Gbogbo commit tí yóò wọ release gbọ́dọ̀ tẹ̀lé fọ́ọ̀mù `type(scope): subject`.

**Àwọn type tó bófin mu:** `feat`, `fix`, `refactor`, `docs`, `test`, `chore`, `perf`, `style`, `ci`

**Àwọn scope tó bófin mu:** `db`, `sse`, `oauth`, `dashboard`, `api`, `cli`, `docker`, `ci`, `mcp`, `a2a`, `memory`, `skills`, `cloud-agent`, `guardrails`, `compression`, `auto-combo`, `resilience`, `providers`, `executors`, `translator`, `domain`, `authz`

### Ìṣètò Build

Repository náà ń lo directory àbájáde mẹ́ta ọ̀tọ̀ọ̀tọ̀ — má ṣe dà wọ́n pọ̀ láéláé:

| Directory | Ète                                                         | A ń tọ́pinpin?     |
| --------- | ----------------------------------------------------------- | ----------------- |
| `src/`    | Orísun application (TypeScript / TSX)                       | Bẹ́ẹ̀ ni            |
| `.build/` | Àwọn ohun àárín build — àbájáde `next build` (`distDir`)    | Rárá (gitignored) |
| `dist/`   | Bundle npm tí a lè fi ránṣẹ́ — tí `assembleStandalone` kó jọ | Rárá (gitignored) |

> **Àkọsílẹ̀ fún olùdarí:** directory image VPS jíjìn ṣì jẹ́ `/usr/lib/node_modules/omniroute/app/`.
> Àbájáde build **inú repo** nìkan ló ṣí (`app/` → `dist/`). Àwọn skill deploy máa ń fi rsync gbe
> àwọn àkóónú `dist/` sínú dir `app/` jíjìn — kò sí ìyípadà path VPS tí a nílò.

**Ìṣàn build-ẹyọkan:**

```
npm run build:release
  └─ rm -rf .build dist          (fọ́ ọ mọ́)
  └─ next build → .build/next/   (àwọn ohun àárín)
  └─ assembleStandalone          (ń da standalone + static + public + natives kọ sínú dist/)
  └─ writes dist/BUILD_SHA       (àmì ìṣọ́ HEAD)
```

MÁ ṢE ṣiṣẹ́ `npm run build` tí o sì tẹ̀lé e pẹ̀lú `npm run build:cli` lọ́tọ̀ fún deploy — lo
`npm run build:release` tí ó ṣe àtúnkọ́ mímọ́ + àmì ìṣọ́ nínú command kan.

- Ìbora ìdánwò gbọ́dọ̀ wà ní ≥60/60/60/60 (àwọn gbólóhùn/àwọn ìlà/àwọn iṣẹ́/àwọn ẹ̀ka)
- Fi àwọn ìdánwò kún un tàbí ṣe àfikún sí wọn nígbà gbogbo tí o bá ń yí kóòdù iṣẹ́ gidi padà nínú `src/`, `open-sse/`, `electron/`, tàbí `bin/`

## Àyẹ̀wò Ìmúdójúìwọ̀n Aládàáṣiṣẹ́

```bash
npm run check:docs-sync
```

CI tún máa ń ṣe àyẹ̀wò yìí nínú `.github/workflows/ci.yml` (iṣẹ́ lint).
