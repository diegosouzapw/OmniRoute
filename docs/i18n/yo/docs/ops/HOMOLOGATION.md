Ìfàṣẹ̀sí E2E ní àyíká gidi fún ìmúṣiṣẹ́ OmniRoute tí ń ṣiṣẹ́ lórí VPS homologation
(`HOMOLOG_BASE_URL`, àpẹẹrẹ `http://192.168.0.15:20128`). Àṣẹ kan ṣoṣo ni ó fi ìṣiṣẹ́ aládàáṣiṣẹ́ tí ń pèsè ẹ̀rí
rọ́pò àtòjọ ìṣàyẹ̀wò release STOP #2 tí a máa ń ṣe lọ́wọ́.

## Àwọn ohun tí a nílò ṣáájú

1. Da `.env.homolog.example` kọ sí `.env.homolog` (git kò tọ́pa rẹ̀ — má ṣe commit rẹ̀ láéláé), kí o sì kọ àwọn wọ̀nyí sínú rẹ̀:
   - `HOMOLOG_BASE_URL` — deploy tí a fẹ́ dán wò, àpẹẹrẹ `http://192.168.0.15:20128`.
   - `HOMOLOG_ADMIN_PASSWORD` — ọ̀rọ̀ aṣínà ìṣàkóso dashboard fún deploy yẹn.
   - `HOMOLOG_CRITICAL_PROVIDERS` — àwọn ìbẹ̀rẹ̀-orúkọ provider tí a fi kọ́mà yà sọ́tọ̀, tí yóò gba ìbéèrè smoke chat gidi
     (àpẹẹrẹ `openai,anthropic,gemini,codex,grok,glm,deepseek,openrouter`).
   - `HOMOLOG_API_KEY` — fi sílẹ̀ láìsí nǹkan nínú àwọn ìṣiṣẹ́ déédéé; suite náà yóò ṣẹ̀dá key onígbà-díẹ̀ tirẹ̀, yóò sì revoke rẹ̀.
     Ṣètò èyí kìkì nígbà tí o bá fẹ́ debug layer kan ṣoṣo lọ́tọ̀.
2. Ṣiṣe `npm install` nínú repo náà (àwọn dependencies suite náà — `httpyac`, `promptfoo`,
   `playwright-ctrf-json-reporter`, `junit-to-ctrf`, `ctrf` — jẹ́ devDependencies déédéé).
3. Ṣiṣe `npx playwright install` tí àwọn browser binaries kò bá tíì wà.

## Bí a ṣe ń ṣiṣẹ́ rẹ̀

```bash
npm run homolog
```

Láti validate sí deploy kan tí version rẹ̀ kò bá version inú `package.json` agbègbè mu
(àpẹẹrẹ, homologation box kan tí ó ṣì wà lórí patch release ti ìṣáájú), ṣàlàyé version
tí a ń retí ní tààrà:

```bash
HOMOLOG_EXPECT_VERSION=3.8.47 npm run homolog
```

Ìṣiṣẹ́ náà yóò jáde pẹ̀lú kóòdù tí kì í ṣe òdo tí layer èyíkéyìí bá kùnà, yóò sì máa gbìyànjú ní gbogbo ìgbà láti revoke
API key onígbà-díẹ̀ tí ó ṣẹ̀dá, kódà nígbà ìkùnà (`finally` block nínú `scripts/homolog/run.mjs`).

## Kíka report náà

Gbogbo output ni yóò wà nínú `homolog-report/` (git kò tọ́pa rẹ̀):

- `summary.md` — table kan náà tí a tẹ̀ jáde sí stdout, row kan fún layer kọ̀ọ̀kan (✅/❌ + àlàyé).
- `homolog-ctrf.json` — report CTRF àpapọ̀ (àkójọpọ̀ àwọn èsì API/SSE, provider-smoke, àti
  UI) — èyí ni artifact tí a ó so mọ́ àtòjọ àyẹ̀wò release STOP #2.
- `httpyac-junit.xml`, `api-ctrf.json`, `providers-ctrf.json`, `ui-ctrf.json` — àwọn
  report aise/àárín-gbùngbùn fún layer kọ̀ọ̀kan.
- `promptfooconfig.yaml`, `provider-misses.json` — config promptfoo tí a ṣẹ̀dá fún
  ìṣiṣẹ́ lọ́wọ́lọ́wọ́ àti àwọn provider pàtàkì èyíkéyìí tí kò sí nínú catalog gidi.

Ìkùnà L0 yóò dá gbogbo nǹkan dúró lẹ́sẹ̀kẹsẹ̀ (a kò ní ṣẹ̀dá key onígbà-díẹ̀) nítorí pé àìbáramu version/health
túmọ̀ sí pé gbogbo layer tó tẹ̀ lé e yóò máa validate deploy tí kò tọ́.

## Ṣíṣe baseline tuntun nígbà tí UI bá yí padà lọ́nà tó tọ́

Àwọn DOM locator gidi, kì í ṣe snapshots, ni ń darí L4b (route smoke) àti L4c (ìṣàn UI API-key),
nítorí náà ọ̀pọ̀ àwọn ìyípadà UI tó tọ́ kò nílò kí a ṣe update suite kankan. Nígbà tí ìyípadà kan
bá ba locator kan jẹ́ (àpẹẹrẹ, label button tí a tún lorúkọ tàbí ojú-ìwé settings tí a ti gbé):

1. Tún fìdí locator náà múlẹ̀ ní ìfiwéra pẹ̀lú source lọ́wọ́lọ́wọ́ (àwọn specs náà ti ṣàkọsílẹ̀ file/line
   tí a fi fìdí locator kọ̀ọ̀kan múlẹ̀ — tẹ̀lé pattern kan náà, má ṣe ṣírò).
2. Ṣe update spec náà nínú `tests/homolog/ui/`.
3. Tún `npm run homolog` ṣiṣẹ́ (tàbí Playwright spec tí ọ̀ràn náà kàn nìkan) sí VPS láti
   fìdí àtúnṣe náà múlẹ̀, lẹ́yìn náà ṣe commit.

Kò sí baseline visual/pixel nínú suite yìí (F1) — wo Roadmap fún èyí.

## Roadmap (F2 / F3)

Àpẹrẹ àti ìmúlò ní ìpele wà nínú spec ètò inú
`_tasks/superpowers/specs/2026-07-13-homolog-e2e-suite-design.md` (a kò fi link sí i — ó jẹ́ artifact
`_tasks/` inú, kì í ṣe apá kan àwọn docs tí repo yìí ń tọ́pa). Àkótán:

- **F2** — gbigbasilẹ walkthrough kíkún → Playwright Test Agents (`planner`/`generator`)
  yóò yí i padà sí àwọn flow specs (ṣẹ̀dá combo, dán provider wò, ṣàtúnṣe settings, àwọn irinṣẹ́ MCP) +
  baseline visual regression (Lost Pixel) pẹ̀lú masks lórí data tó ń yí padà (metrics,
  timestamps, logs) + routine ìtọ́jú `healer` fún release kọ̀ọ̀kan.
- **F3** — ààbò fún resilience/contract/wiring: toxiproxy + provider èké kan tó bá OpenAI mu
  lórí devbox, combo `homolog-resilience` kan lórí VPS tí a tọ́ka sí i
  (fi timeout sínú rẹ̀ → fìdí fallback + circuit breaker ṣíṣí/títì múlẹ̀ nípasẹ̀
  `/api/monitoring/health`); ìdánwò contract Schemathesis tí gate ń ṣàkóso sí
  `docs/openapi.yaml` (`--max-examples` kékeré, fixed seeds, àwọn endpoint tí kì í ṣe LLM nìkan); àti
  sisopọ̀ `npm run homolog` + `summary.md` rẹ̀ mọ́ ìpele `/generate-release` STOP #2.
