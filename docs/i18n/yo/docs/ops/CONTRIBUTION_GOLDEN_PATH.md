Lo ìtọ́sọ́nà yìí láti yan ìyípo ìdàgbàsókè tó kéré jù lọ tí ó sì ṣeé gbẹ́kẹ̀ lé fún pull request kan. Kò
rọ́pò àwọn ìwé àkọsílẹ̀ faaji àti ààbò tó jẹ́ ti agbègbè pàtó tí a so pọ̀ sí ní ìsàlẹ̀; ó so irú
ìyípadà kọ̀ọ̀kan tó wọ́pọ̀ pọ̀ mọ́ àwọn àdéhùn rẹ̀, àwọn àyẹ̀wò pàtó, àti ìṣàkóso CI.

## Ọ̀nà tí gbogbo ìyípadà ń gbà

1. **Yan base kí o tó bẹ̀rẹ̀ sí í ṣàtúnṣe.** Wá ẹ̀ka `release/v*` tó ga jù lọ tí ó ṣì ń ṣiṣẹ́, kí o sì ṣẹ̀dá ẹ̀ka láti
   tip rẹ̀. Dojú kọ ẹ̀ka yẹn, kì í ṣe `main`. Bí release freeze bá ń ṣiṣẹ́, má ṣe dojú kọ ẹ̀ka tí a ti
   dì; lo ìyípo tó ń ṣiṣẹ́ lẹ́yìn rẹ̀ gẹ́gẹ́ bí a ti ṣàlàyé nínú
   [Àwòṣe Ẹ̀ka & Ìtújáde](BRANCHING_MODEL.md).
2. **Dárúkọ àwọn àdéhùn náà.** Ṣàkọsílẹ̀ gbogbo catalog, schema, artifact tí a dá jáde, API gbogbogbò, tàbí
   ojú-ọ̀nà olùlò tí ìyípadà náà kan. Tábìlì tó wà ní ìsàlẹ̀ fi àkójọpọ̀ ìbẹ̀rẹ̀ tó kéré jù lọ hàn.
3. **Kọ tàbí ṣe àfikún sí àwọn ìdánwò pàtó.** Àwọn ìyípadà production nínú `src/`, `open-sse/`, `electron/`, tàbí
   `bin/` nílò ìdánwò aládàáṣiṣẹ́ nínú PR kan náà. Ṣiṣe àwọn fáìlì ìdánwò tó kéré jù lọ tí ó fi
   ìhùwàsí náà múlẹ̀, lẹ́yìn náà kí o ṣe àwọn gate pàtó tí a tò sílẹ̀.
4. **Jẹ́ kí CI ṣiṣẹ́ matrix gbòòrò náà.** Gbogbo unit shards, Vitest, coverage ratchet, àti
   production build ni a máa ṣiṣẹ́ lórí PR náà. Ṣiṣe suite gbòòrò ní agbègbè rẹ nìkan nígbà tí ìkùnà pàtó bá tọ́ka sí
   ipa tó gbòòrò sí i tàbí nígbà tí ìyípadà náà bá gba ọ̀pọ̀ subsystem kọjá.
5. **Ṣe ìbámu kí àyẹ̀wò tó bẹ̀rẹ̀.** Fetch base tó ń ṣiṣẹ́, ṣàyẹ̀wò àwọn commit tuntun rẹ̀ àti diff rẹ lòdì sí
   i, lẹ́yìn náà rebase tàbí merge base náà gẹ́gẹ́ bí workflow olùkópa. Yanjú àwọn ìforígbárí fáìlì
   tí a dá jáde àti catalog láti orísun wọn, tún dá wọn jáde, tún ìyípo pàtó náà ṣiṣẹ́, kí o sì jẹ́rìí pé
   PR náà ṣì ń dojú kọ ẹ̀ka ìtújáde tó ń ṣiṣẹ́.
6. **Ṣàkọsílẹ̀ ẹ̀rí.** Nínú àdàkọ PR, tò àwọn command tí a ṣiṣẹ́, gbogbo fáìlì ìdánwò tí a fi kún un tàbí tí a yí padà,
   migration tàbí feature flag, àti ìfàṣẹsí CI-only èyíkéyìí tó ṣì ń dúró.

## Àwọn ọ̀nà àpẹẹrẹ gẹ́gẹ́ bí irú ìyípadà

Àwọn command tó wà ní ìsàlẹ̀ ni àwọn àyẹ̀wò pàtó tó kéré jù lọ, kì í ṣe àṣẹ láti fo ìdánwò tó ń ṣàyẹ̀wò
ìhùwàsí tí o yí padà ní tààrà.

### Provider

**Àwọn àdéhùn**

- Ìtumọ̀ provider nínú `src/shared/constants/providers/` àti àkópọ̀ rẹ̀ nínú
  `src/shared/constants/providers.ts`.
- Àwọn model àti capability nínú `open-sse/config/providerRegistry.ts` tàbí àwọn fáìlì registry tí a yọ jáde láti inú rẹ̀.
- Yíyan executor/translator, ìṣètò OAuth tàbí API-key, àwọn asset dashboard, àti reference
  provider tí a dá jáde nígbà tó bá yẹ.
- Àwọn credential gbogbogbò gbọ́dọ̀ lo `resolvePublicCred()`; àwọn response error gbọ́dọ̀ lo àwọn helper
  error sanitized tí a pín. Wo `docs/security/PUBLIC_CREDS.md` (git; a kò compile rẹ̀ sínú `/docs`) àti
  [Ìsọdimímọ́ Error](../security/ERROR_SANITIZATION.md).

**Ìyípo pàtó**

```bash
npm run check:provider-consistency
npm run check:provider-assets
node --import tsx/esm --test tests/unit/provider-translate-path-golden.test.ts
node --import tsx/esm --test tests/unit/<provider-or-executor>.test.ts
npm run gen:provider-reference   # nígbà tí catalog bá yí padà; commit diff tí a dá jáde
npm run lint
```

Tún dán gbogbo request family tí ó kan wò: chat, Responses, images, embeddings, audio, tàbí video.
Ṣàyẹ̀wò catalog tí a dá jáde àti àwọn diff golden bí ìyípadà àdéhùn; má ṣe gba wọ́n láìṣàyẹ̀wò.

### Routing

**Àwọn àdéhùn**

- Àwọn value strategy gbogbogbò àti metadata UI nínú `src/shared/constants/routingStrategies.ts`.
- Dispatch àti ordering lábẹ́ `open-sse/services/combo.ts` àti `open-sse/services/combo/`.
- Àwọn schema combo, persistence, resilience state, capability model, àti àwọn control API/UI.
- [Ẹ́ńjìnnì Auto-Combo](../routing/AUTO-COMBO.md) àti ìwé àkọsílẹ̀ resilience nígbà tí ìhùwàsí bá yí padà.

**Ìyípo pàtó**

```bash
node --import tsx/esm --test tests/unit/combo-<behavior>.test.ts
npm run test:combo:matrix        # àwọn ìyípadà strategy tàbí dispatch
npm run check:known-symbols      # àwọn ìyípadà ìforúkọsílẹ̀ strategy
npm run lint
```

Lo àwọn ìdánwò mocked-upstream tó jẹ́ deterministic ní agbègbè rẹ. Àwọn smoke test combo live nílò credential, wọ́n sì jẹ́
ti ọwọ́, kì í ṣe ohun tó lè rọ́pò CI.

### UI / UX

**Àwọn àdéhùn**

- Route/page Next.js àti àwọn ààlà component tí a pín lábẹ́ `src/app/` àti
  `src/shared/components/`.
- Àwọn shape response API, àwọn state loading/empty/error, ìhùwàsí keyboard àti screen-reader,
  layout responsive, theming, àti ìfẹ̀sí locale.
- Àwọn string orísun UI Gẹ̀ẹ́sì nínú `src/i18n/messages/en.json`; má ṣe hard-code ọ̀rọ̀ tuntun tí olùlò máa rí.

**Ìyípo pàtó**

```bash
node --import tsx --test tests/unit/dashboard/<feature>.test.ts
npx vitest run --config vitest.config.ts tests/unit/ui/<component>.test.tsx
npm run check:dashboard-typecheck
npm run lint
```

Ṣiṣe app náà fún àwọn ìyípadà interaction tàbí visual, kí o sì ṣàyẹ̀wò viewport tóóró àti èyí tó fẹ̀. CI máa ń ṣiṣẹ́
production build àti àwọn suite tó gbòòrò sí i; ìhùwàsí visual ṣì nílò component pàtó, Playwright,
tàbí àyẹ̀wò ọwọ́ tí a ṣàkọsílẹ̀ tó bá ìyípadà náà mu.

### i18n

**Àwọn àdéhùn**

- `src/i18n/messages/en.json` ni orísun UI; `config/i18n.json` ni orísun locale.
- Àwọn catalog CLI wà ní ọ̀tọ̀ lábẹ́ `bin/cli/locales/`.
- Pa àwọn placeholder àti tag ICU mọ́ gẹ́gẹ́ bí wọ́n ṣe rí gan-an. Má ṣe túmọ̀ àwọn orúkọ product/provider/model,
  àwọn orúkọ protocol àti header, command, identifier code/JSON, URL, environment variable, tàbí
  àwọn ọ̀rọ̀ tó ní ààbò bíi `OmniRoute`, `OAuth`, `MCP`, àti `A2A`. Àkójọ orísun lọ́wọ́lọ́wọ́ ni
  `scripts/i18n/glossary/protected-terms.json`.

**Ìyípo pàtó**

```bash
npm run i18n:sync-ui:dry
npm run i18n:check-ui-coverage
npm run i18n:check-value-drift
npm run i18n:check-glossary
npm run check:cli-i18n          # nígbà tí àwọn string/catalog CLI bá yí padà
npm run lint
```

Èyí jẹ́ ìtọ́sọ́nà fún system tó wà tẹ́lẹ̀, kì í ṣe ìpè láti mú tooling tàbí key model rẹ̀ gbòòrò sí i.
Jẹ́ kí àwọn patch i18n jẹ́ kékeré, kí wọ́n sì dojú kọ ohun pàtó nígbà tí a ṣì ń ṣe àpẹrẹ system tó máa rọ́pò rẹ̀. Má ṣe ṣiṣẹ́ àwọn command translation
tí ń pe service òde àyàfi tí task náà bá béèrè ní kedere fún àwọn translation tí a dá jáde, tí
o sì ti ṣàyẹ̀wò diff tó yọrí sí i.

### CLI

**Àwọn àdéhùn**

- Àwọn àṣẹ àti àsíá gbangba nínú `bin/cli/`, àwọn àṣẹ API tí a ṣẹ̀dá, àwọn kóòdù ìjáde, stdout/stderr àti
  àwọn ìrísí àbájáde JSON, ìhùwàsí àtòjọ/àyíká, àti àwọn fáìlì tí a ṣàkójọ sínú package.
- Àwọn ọ̀rọ̀ CLI tí olùlò ń rí gbọ́dọ̀ lo ipele i18n CLI, kí àwọn àkójọ èdè `en`/`pt-BR` sì wà ní ìbámu.
- Ṣètìlẹ́yìn fún Node gẹ́gẹ́ bí runtime tí a fọwọ́sí, kí o sì pa àdéhùn binary tí a tẹ̀jáde mọ́.

**Ìyípo àfojúsùn**

```bash
node --import tsx/esm --test tests/unit/cli/<command>.test.ts
npm run check:cli-i18n
npm run build:cli             # àwọn àyípadà CLI tí a ṣẹ̀dá/tí a kó jọ
npm run check:pack-policy     # àwọn àyípadà sí ojú package
npm run lint
```

Lo àṣẹ gangan náà nínú àkọsílẹ̀ data ìgbà díẹ̀ nígbà tí ìhùwàsí bá dá lórí ìtúpalẹ̀, àwọn fáìlì, tàbí ipò
ìjáde. CI ń ṣe àwọn àyẹ̀wò artifact package àti ecosystem tó gbòòrò sí i.

### Database

**Àwọn àdéhùn**

- Àwọn module domain lábẹ́ `src/lib/db/`; ṣe àgbéwọlé àwọn module pàtó ní tààrà (a ti yọ ipele àtún-gbéjáde `localDb.ts` àtijọ́ kúrò).
- Àwọn migration SQL tó ní nọ́mbà, tí a lè tún ṣiṣẹ́ láìsí àbájáde míì, lábẹ́ `src/lib/db/migrations/`, ààbò transaction, ìhùwàsí
  ìgbésókè, àwọn index, àti gbogbo caller tí schema náà kan.
- Àwọn route àti handler kò gbọ́dọ̀ ṣe SQL raw ní tààrà láé.

**Ìyípo àfojúsùn**

```bash
npm run check:migration-numbering
npm run check:db-rules
node --import tsx/esm --test tests/unit/db/<domain>.test.ts
node --import tsx/esm --test tests/unit/db/migration-<number>.test.ts
npm run lint
```

Ṣe àyẹ̀wò database tuntun àti ìgbésókè láti schema tó ṣáájú nígbà tí o bá ń fi migration kún un. Àwọn àyẹ̀wò database
gbọ́dọ̀ pa àwọn handle, kí wọ́n sì pe `resetDbInstance()` nígbà ìmọ́tótó. Ṣiṣe `npm run test:bun:db` nìkan nígbà
tí ipa-ọ̀nà adapter Bun best-effort bá yí padà; Node ṣì ni orísun àṣẹ.

### Ìkọ́lé / ìmúṣiṣẹ́

**Àwọn àdéhùn**

- Àwọn manifest/lockfile root àti workspace, `scripts/build/`, àkójọpọ̀ standalone Next.js, àwọn àkóónú package `dist/`,
  metadata platform Electron, àwọn workflow CI, àti àwọn àmì ìṣọ́ deployment.
- Àwọn ìwọ̀n Node tí a ṣe àtìlẹ́yìn fún àti lílo Bun tí a gbà láàyè nínú `CLAUDE.md` gbọ́dọ̀ dúró ṣinṣin.
- Àwọn artifact ìkọ́lé kò gbọ́dọ̀ wà lábẹ́ ìtọ́pinpin; àwọn ìlànà dependency, license, workflow, àti package kan wọn.

**Ìyípo àfojúsùn**

```bash
node --import tsx/esm --test tests/unit/build/<behavior>.test.ts
npm run check:build-scope
npm run check:lockfile         # àwọn àyípadà dependency tàbí lockfile
npm run check:pack-policy      # àwọn àyípadà sí ojú package tí a tẹ̀jáde
npm run lint
```

Lo `npm run build` ní agbègbè rẹ nìkan nígbà tí àyípadà bá kan compilation, àkójọpọ̀ standalone, àwọn asset,
tàbí bundling runtime. Lo `npm run build:release` nìkan fún ìfàṣẹsí release/deploy. Ìkọ́lé CI ni
àmì ìkẹyìn káàkiri àwọn platform; àwọn àyípadà Electron tó jẹ́ ti platform pàtó nílò ìkọ́lé àfojúsùn tó bá a mu
tàbí ẹ̀rí smoke.

## Ìyípo olùdíje agbègbè

Àwọn ìdánwò kóòdù orísun kò lè fi ẹ̀rí hàn pé àbájáde tí a kó sínú package lè bẹ̀rẹ̀: àwọn àtòjọ ìkójọpọ̀, àwọn dependency tí a gé kúrò,
àti àwọn binary abinibi máa ń kùnà kìkì lẹ́yìn tí a bá fi tarball náà sílẹ̀ tí a sì bẹ̀rẹ̀ rẹ̀. `npm run dev:candidate`
(`scripts/dev/candidate.mjs`) ni apá agbègbè ti ìṣàn kọ-lẹ́ẹ̀kan / fọwọ́sí / gbé-lókè láti inú
RFC #8084: ó kọ olùdíje kan, ó fọwọ́sí àbájáde pàtó yẹn, ó gbé e lókè nípa yíyí orúkọ directory,
ó sì dá a padà bí slot tí a gbé lókè bá kùnà ìṣàyẹ̀wò ìlera rẹ̀.

```bash
npm run dev:candidate -- run --dry-run --json  # tẹ ètò náà jáde, má ṣe yí ohunkóhun padà
npm run dev:candidate -- run                   # kọ́ + fọwọ́sí + gbé-lókè, dá-padà láìfọwọ́ṣe
npm run dev:candidate -- build                 # npm pack + fi sí inú _artifacts/candidate/<id>/
npm run dev:candidate -- validate --id <id>    # bẹ̀rẹ̀ lórí port òfìfo, /api/health + /v1/models
npm run dev:candidate -- promote --id <id>     # <id> → current, current → previous
npm run dev:candidate -- rollback              # pààrọ̀ current àti previous
npm run dev:candidate -- run --from-tarball <file.tgz>  # tún tarball tí a kọ ní ibòmíràn lò (CI)
```

- **Kọ́ lẹ́ẹ̀kan.** `build` máa ń kó tree lọ́wọ́lọ́wọ́ sínú package (ó nílò `dist/server.js`, nítorí náà kọ́kọ́ ṣiṣẹ́
  `npm run build:release`) tàbí ó da `--from-tarball` kọ, lẹ́yìn náà ó fi tarball náà sínú
  prefix npm tí a yà sọ́tọ̀, nítorí tarball náà kò ní `node_modules`. Id náà ni sha `HEAD`
  kúkúrú (`-dirty` nígbà tí tree náà ní àwọn àyípadà agbègbè) tàbí `tgz-<sha256>` fún tarball kan. Id mímọ́ kan tí
  a ti kọ tẹ́lẹ̀ ni a ó tún lò dípò kí a tún un kọ; fi `--force` ránṣẹ́ láti tún un kọ.
- **Fọwọ́sí package náà, kì í ṣe kóòdù orísun.** `validate` máa ń bẹ̀rẹ̀ CLI tí a fi sílẹ̀
  (`serve --port <free port>`) pẹ̀lú `DATA_DIR=<candidate>/data` tuntun, àwọn secret èké, àti
  `OMNIROUTE_API_KEY`, `STORAGE_ENCRYPTION_KEY` àti `INITIAL_PASSWORD` ti olùṣàkóso tí a yọ kúrò nínú
  environment, kí ó lè ṣàyẹ̀wò ìṣètò loopback tí kò ní key fún ìfisílẹ̀ tuntun. Ó máa ń dúró de
  `GET /api/health` láti dá 200 padà, ó béèrè pé kí `GET /v1/models` dá 200 padà, ó dá process group dúró,
  ó sì ṣàkọsílẹ̀ ìdájọ́ náà sínú `validation.json` papọ̀ pẹ̀lú hash tarball náà.
- **Gbé àbájáde kan náà lókè.** `promote` kọ olùdíje tí kò ní ìfọwọ́sí àṣeyọrí fún
  hash tarball rẹ̀ lọ́wọ́lọ́wọ́. Slot tó ń ṣiṣẹ́ láìyípadà ni `_artifacts/candidate/current`; `--target <dir>`
  yan directory mìíràn lórí filesystem kan náà, slot rẹ̀ tẹ́lẹ̀ sì ni `<dir>.previous`.
  Ìyípadà orúkọ kọ̀ọ̀kan jẹ́ atomic, ìkùnà láàárín iṣẹ́ náà sì máa ń yí àwọn ìyípadà orúkọ tí ó ti ṣiṣẹ́ padà.
- **Dá padà.** `run` tún máa ń fọwọ́sí slot tí a gbé lókè, ó sì pààrọ̀ `current` àti `previous` padà nígbà tí
  ìṣàyẹ̀wò yẹn bá kùnà. A kì í gbé olùdíje tí ó kùnà ìfọwọ́sí àkọ́kọ́ lókè láé.

Gbogbo nǹkan ni a kọ sí abẹ́ `_artifacts/candidate/` tí git kò tọ́pa; a kò fọwọ́ kan ìfisílẹ̀ OmniRoute
tó ti wà tẹ́lẹ̀ tàbí directory data rẹ̀ láé. CLI tí a gbé lókè ni
`_artifacts/candidate/current/prefix/bin/omniroute`; bẹ̀rẹ̀ rẹ̀ pẹ̀lú `DATA_DIR` tirẹ nígbà tí o bá ń lò
ó. Àwọn exit code: `0` àṣeyọrí, `1` ìfọwọ́sí tàbí ìgbé-lókè tí ó kùnà, `2` àṣìṣe lílò tàbí build tí kò sí.

## Ìyípo abẹ́nú ní ìfiwéra pẹ̀lú CI

| Ṣiṣe ní abẹ́nú fún àtúnṣe kọ̀ọ̀kan                                                        | CI ń pèsè àmì ìwífún tó gbòòrò                                      |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Àwọn ìdánwò ìhùwàsí tààrà àti àwọn àyẹ̀wò ẹ̀ka tó wà lókè                                | Àkójọpọ̀ ìdánwò ẹyọ tó pé tí a pín sí ẹ̀ka àti àwọn ìdánwò tẹ̀lé-tẹ̀lé  |
| `npm run lint`                                                                         | Àwọn àkójọpọ̀ Vitest àti àwọn ìdíwọ̀n ìlọsíwájú coverage/dídára       |
| Ṣàyẹ̀wò irú tàbí kọ́ ọ́ kìkì nígbà tí àdéhùn tí ó kan bá béèrè fún un                     | Ìkọ́jáde production, ààbò, docs, dependency, àti àwọn àyẹ̀wò ìlànà PR |
| Ṣe ìbáṣepọ̀ afọwọ́ṣe/àyẹ̀wò alààyè kìkì nígbà tí automation kò lè fi ìhùwàsí náà hàn dájú | Ìṣọ̀kan láàárín àwọn job àti àwọn àyẹ̀wò platform tí workflow ṣètò    |

Ìyípo àfojúsùn tí ó jẹ́ aláwọ̀ ewé jẹ́ ẹ̀rí nípa àdéhùn tí a yí padà, kì í ṣe ẹ̀rí pé àwọn àyẹ̀wò CI tí kò ní í ṣe pẹ̀lú rẹ̀
yóò kọjá. Bákan náà, má ṣe jẹ́ kí gbogbo àtúnṣe abẹ́nú dúró de matrix ibi ìpamọ́ kódù tó pé.

## Àtòjọ àyẹ̀wò ìbámu

Ṣáájú kí o tó béèrè fún àyẹ̀wò:

- Jẹ́rìí pé ìpìlẹ̀ PR ṣì jẹ́ ẹ̀ka `release/v*` tó ga jù lọ tí ó sì ń ṣiṣẹ́.
- Fetch ìpìlẹ̀ náà, kí o sì ṣàyẹ̀wò àwọn commit tí wọlé láti ìgbà tí o ti ṣẹ̀dá ẹ̀ka rẹ.
- Ṣàyẹ̀wò `git diff <active-base>...HEAD` fún àwọn ìyípadà àìròtẹ́lẹ̀ tàbí èyí tí a ṣẹ̀dá ní aládàáṣiṣẹ́.
- Yanjú àwọn ìtakora inú catalog àti document tí a ṣẹ̀dá nípa mímúdójúìwọ̀n orísun àti ṣíṣẹ̀dá output náà padà.
- Tún gbogbo ìdánwò/àyẹ̀wò àfojúsùn tí a tò sínú àpèjúwe PR ṣe lẹ́yìn ìbámu.
- Má ṣe dín agbára àwọn assertion kù tàbí yọ àwọn ìdánwò tó ṣe pàtàkì kúrò kìkì láti bá ìpìlẹ̀ tí a ti gbé mu.
