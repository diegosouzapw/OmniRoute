## Apá 1 — Ìdájọ́ àti Ìsọ̀rí Ìdàgbàsókè

**Àmì àpapọ̀: A− / "Ìpele Gíga". Ó wà lára ~5–10% àwọn iṣẹ́-àkànṣe tó ga jù lọ.** Ètò náà ń ṣe
ọ̀pọ̀ àwọn àpẹẹrẹ tí ilé-iṣẹ́ ti fún ní orúkọ ní ọ̀nà òmìnira — èyí sì ni àmì ìbámu tó lágbára jù lọ
(a kò ṣàdàkọ àkójọ ohun àyẹ̀wò; a dé sí àwọn ìlànà tó tọ́ fúnra wa).

## Apá 2 — Ìṣàyẹ̀wò Pàtàkì (àwọn agbára + àwọn àìlera tí a sọ ní òtítọ́)

### Àwọn agbára (ohun tó ga ju ìwọ̀n àárín lọ)

1. **Ẹ́ńjìnnì ratchet oní-mẹ́tíríkì-púpọ̀.** Èyí ni ọkàn ètò náà. Mẹ́tíríkì 24 wà nínú `quality-baseline.json`
   - Àwọn baseline ìyàsọ́tọ̀ mẹ́rin, ọ̀kọ̀ọ̀kan pẹ̀lú ìtọ́sọ́nà (`up`/`down`), ààyè ìfaradà (`eps`), slack
     (`tightenSlack`) àti àmì `dedicatedGate`. Àwọn ohun tí a bá ti ṣàtúnṣe **yóò dúró** ní títúnṣe — ó jẹ́
     oògùn àtọ́jáde sí entropy codebase.
2. **Ààbò alápele-púpọ̀ fún supply-chain.** SAST (CodeQL/Sonar) + secrets (gitleaks pẹ̀lú
   `useDefault`) + SCA (osv/npm-audit/Trivy/Dependabot) + àwọn ìwé-àṣẹ + lockfile + SBOM + ìpilẹ̀ṣẹ̀
   SLSA + Scorecard + fífún workflow ní ààbò tó lágbára (zizmor). Àwọn codebase díẹ̀ ló ní stack tó pé báyìí.
3. **Àwọn oògùn àtọ́jáde sí Òfin Goodhart.** Lílo coverage gẹ́gẹ́ bí àfojúsùn jẹ́ anti-pattern tí a mọ̀ dáadáa
   ("nígbà tí ìwọ̀n kan bá di àfojúsùn, ó dẹ́kun jíjẹ́ ìwọ̀n tó dára"). A ní àwọn ohun ìwọ̀ntúnwọ̀nsì náà:
   **mutation testing** (ó ń díwọ̀n bóyá test náà mú bug náà, kì í ṣe pé ó kàn ṣiṣẹ́ lórí ìlà náà),
   **`check-test-masking`** (ó dènà fífọ àwọn assert rọ láti lè kọjá), **àwọn òkè ìsàlẹ̀ coverage fún
   module kọ̀ọ̀kan** (ó fipá mú kí a dán code tó ní ewu GÍGA wò, kì í ṣe àwọn apá tó rọrùn nìkan) àti
   **`check-pr-evidence`** (Òfin Líle #18).
4. **Àwọn gate ìdènà-hallucination / ìbámu.** Ẹ̀ka tó ṣọ̀wọ́n tí ó sì níye lórí ni:
   `check-known-symbols`, `check-fetch-targets`, `check-openapi-routes`, `check-docs-symbols`
   ń rí i dájú pé docs, specs àti àwọn string dispatch tọ́ka sí àwọn symbol tó ṣì wà láàyè. Ó ń rí
   “ìbàjẹ́” tí lint/test kò rí.
5. **Ìgbésí-ayé advisory→blocking.** Àwọn gate tuntun ń bẹ̀rẹ̀ gẹ́gẹ́ bí advisory (wọn kò dènà merge nígbà
   tí wọ́n ṣì ń dàgbà), lẹ́yìn náà wọ́n di blocking ní òpin cycle. Ó dín ìkọlù kù láì sọ ceiling nù.
6. **Skip tó bójú mu nígbà tí infra kò bá sí.** Àwọn scanner (`--ratchet`) máa jáde pẹ̀lú `exit 0` bí
   binary/network bá kùnà — infra tí kò sí kò ní dènà PR tó bófin mu láéláé. Ẹ̀rọ-ẹ̀rọ tó dàgbà.
7. **Àṣà tí a ti fi sínú kóòdù.** Àwọn Òfin Líle + `trust-but-verify` + stale-allowlist + evidence-gate
   sọ ìbáwí di ìjẹ́rìísí aládàáṣiṣẹ́.

### Àwọn àìlera tí a sọ ní òtítọ́ (àwọn àlàfo gidi)

1. **🔴 Pípín fast-gates ṣì fi àlàfo ìgbékalẹ̀ sílẹ̀.** `quality.yml` (PR→`release/**`)
   ń ṣiṣẹ́ typecheck, àwọn test deterministic tó yára, àti production build advisory fún àwọn PR kóòdù,
   ṣùgbọ́n kò tíì ṣiṣẹ́ gbogbo surface release-PR láti inú `ci.yml` (àwọn ratchet coverage,
   package artifact, integration, E2E, SonarQube). Ìdí náà (iyára) bófin mu, ṣùgbọ́n gate náà
   gbọ́dọ̀ wà níbi tí merge ti ń ṣẹlẹ̀ (shift-left). **Àtúnṣe ìgbékalẹ̀ tó tóbi jù lọ tí ó ṣì ń dúró.**
2. **🟠 Ewu pípọ̀jù gate/àárẹ̀.** Gate bíi ~46 + job 25 pọ̀ GAN-AN. Sonar fúnra rẹ̀ kìlọ̀ pé:
   àwọn condition tó pọ̀ jù ń fa “àárẹ̀ gate” àti àríyànjiyàn lórí ohun tó yẹ kó jẹ́ àkọ́kọ́, pẹ̀lú ewu pé
   a ó kọ gate kan sílẹ̀. DORA kìlọ̀ pé àwọn gate tó wuwo ń ná lead-time. A ń dín èyí kù pẹ̀lú àwọn ipele
   advisory àti àwọn ratchet tí kì í ṣe absolute, ṣùgbọ́n **àtúnyẹ̀wò ROI lẹ́ẹ̀kọ̀ọ̀kan fún gate kọ̀ọ̀kan**
   kò sí (a lè ṣàkójọpọ̀ díẹ̀ lára àwọn micro-gate fún doc-sync).
3. **🟠 Mutation score kò tíì jẹ́ ratchet.** Oògùn àtọ́jáde tó lágbára jù lọ sí coverage-gaming jẹ́
   **advisory**. Ó jẹ́ ohun tó níye jù lọ tí ó ṣì ń dúró (a sì ti kọ́ ọ dé 90%).
4. **🟡 Àwọn advisory tó yẹ kí wọ́n dènà (ní ààlà tó yẹ).** `osv` (vulnCount) àti `oasdiff` jẹ́
   advisory bó tilẹ̀ jẹ́ pé àwọn baseline náà ti di frozen. osv-advisory bóye mu (CVE tuntun lórí dep
   àtijọ́ yóò dènà PR tí kò ní í ṣe pẹ̀lú rẹ̀) — ṣùgbọ́n ọ̀nà àárín wà (dènà CRITICAL+fixable nìkan,
   gẹ́gẹ́ bí a ti ṣe pẹ̀lú Trivy). Bí oasdiff ṣe jẹ́ advisory túmọ̀ sí pé ìyípadà tó ń fọ contract lè kọjá.
5. **🟡 Ààbò runtime wà fún nightly nìkan.** schemathesis/garak/promptfoo/chaos/k6 ń ṣiṣẹ́ ní alẹ́.
   Ìpinnu tó tọ́ ni (wọ́n lọra, wọ́n nílò server tó ń ṣiṣẹ́), ṣùgbọ́n PR kan lè mú regression kan wá
   sínú injection-guard tí a kò ní rí títí di alẹ́ tó tẹ̀lé.
6. **🟡 Branch-protection lórí `main` wa ní OFF.** `BRANCH_LOCK_TOKEN` ń ti àwọn branch _release_ pa,
   ṣùgbọ́n `main` fúnra rẹ̀ kò ní ààbò. Scorecard/DSOMM ń dín àmì kù nítorí rẹ̀. Ìgbésẹ̀ owner ni a nílò.
7. **🟡 CodeQL default-setup; a kò tíì fi semgrep sínú kóòdù.** default-setup ń ṣiṣẹ́ (alert 0), ṣùgbọ́n
   `codeql.yml` tí a commit ń fúnni ní ìṣàkóso púpọ̀ sí i; semgrep ń ṣiṣẹ́ nípasẹ̀ external cloud platform,
   a kò sì ṣe version rẹ̀ nínú repo.

## Apá 3 — Àkójọ Kíkún ti Àwọn Ojú-Ìṣàyẹ̀wò Didára (tó ṣeé gbé kiri)

Àwọn ẹ̀ka 12 tó wà nísàlẹ̀ ni “ètò didára” ní ìrísí tí a lè tún lò. Ọ̀kọ̀ọ̀kan ṣàkọsílẹ̀
**ìdí pàtàkì** (ohun tí a fẹ́ dáàbò bo), **àwọn irinṣẹ́ tí a ń lò** àti **ọ̀nà àfidípò tí kò sinmi lé irinṣẹ́ kan pàtó**
láti tún un ṣe lórí àkójọpọ̀ ìmọ̀-ẹ̀rọ èyíkéyìí.

### 1. Ara ìkọ̀wé & ìṣètò (tó ní àbájáde kan náà ní gbogbo ìgbà, tó sì yára)

- **OmniRoute:** Prettier + ESLint nípasẹ̀ lint-staged (pre-commit), àyè méjì/àmì-àyọlò méjì/100col.
- **Gbogbogbò:** formatter kan tó lè ṣàtúnṣe fúnra rẹ̀ + linter kan, tí ń ṣiṣẹ́ ní pre-commit lórí àwọn fáìlì staged.

### 2. Àwọn type

- **OmniRoute:** `typecheck:core` (tó ń dí iṣẹ́ dúró) + `typecheck:noimplicit:core` (ìmọ̀ràn) + `type-coverage` ratchet 92.17% + ìwọ̀n any fún fáìlì kọ̀ọ̀kan.
- **Gbogbogbò:** strict typecheck nínú CI + òṣùwọ̀n type-coverage tí a fi ratchet sí + ìwọ̀n `any`/ọ̀nà-àbáyọ fún fáìlì kọ̀ọ̀kan.

### 3. Àwọn ìdánwò (ìgbóná rẹ̀)

- **OmniRoute:** runners 2 tí kò bo ara wọn (Node native + vitest), shards 8, àpapọ̀ coverage 60/60/60/60 + ratchet ~76% + **ìwọ̀n-kéré-jù 8 fún module kọ̀ọ̀kan lára àwọn module tó ṣe pàtàkì** + àwọn property tests alẹ́ + **mutation testing** alẹ́.
- **Gbogbogbò:** test runner(s) + ìwọ̀n-kéré-jù coverage tó jẹ́ **ojúlówó iye** (òdì sí òdo) + **ratchet** coverage (òdì sí ìfàsẹ́yìn) + **ìwọ̀n-kéré-jù fún module kọ̀ọ̀kan fún kóòdù tó ní ewu gíga** (òdì sí Goodhart) + ìdánwò tó dá lórí property fún pure logic + **mutation testing** alẹ́ gẹ́gẹ́ bí òṣùwọ̀n gidi fún didára ìdánwò.

### 4. Ìlànà ìdánwò (òdì sí yíyí ètò ṣeré)

- **OmniRoute:** `pr-test-policy` (kóòdù prod nílò ìdánwò), `check-test-masking` (ń dènà asserts tí a sọ di aláìlágbára), `pr-evidence` (ìkéde àṣeyọrí nílò evidence block), `test-discovery` (runner kan gbọ́dọ̀ kó gbogbo ìdánwò jọ).
- **Gbogbogbò:** ibodè “kóòdù tuntun ⇒ ìdánwò tuntun” + aṣàwárí assert tí a yọ/tautology + àìní-ẹni-kò evidence (TDD tàbí living test) + ìdánilójú pé kò sí ìdánwò tí a fi sílẹ̀ ní òde àwọn globs.

### 5. Ìdíjú & ìlera kóòdù (àwọn ratchet)

- **OmniRoute:** ESLint-warnings (3769↓), jscpd duplication (5.72%↓), cyclomatic+max-lines complexity (1800↓), cognitive complexity sonarjs (753↓), dead-code/unused-exports knip (339↓), ìwọ̀n fáìlì fún fáìlì kọ̀ọ̀kan (tí a ti dì mú, ó lè dín kù nìkan), circular-deps (Tarjan àdáni, tó ń dí iṣẹ́ dúró).
- **Gbogbogbò:** fi ratchet sí gbogbo òṣùwọ̀n ìlera (àwọn ìkìlọ̀, àtúnsọ, ìdíjú cyclomatic **àti** cognitive, dead code, ìwọ̀n fáìlì, import cycles). Ìtọ́sọ́nà náà jẹ́ “má ṣe fà sẹ́yìn” ní gbogbo ìgbà.

### 6. Ààbò statiki (SAST + àwọn àṣírí)

- **OmniRoute:** CodeQL (àwọn alert ratchet = 0), gitleaks (`[extend] useDefault=true` — ó ṣe pàtàkì gan-an!), SonarQube, àwọn òfin ààbò àdáni (public-creds, error-helper, route-guard-membership, route-validation).
- **Gbogbogbò:** SAST (CodeQL/Sonar/semgrep) pẹ̀lú alert ratchet + scanner àṣírí pẹ̀lú **ruleset àìyẹsẹ̀ tí a jogún** (àtòpọ̀ àdáni tó rọ́pò èyí àìyẹsẹ̀ = ìfọ́jú) + àwọn ibodè ààbò Òfin Tó Múná Doko tó jẹ́ ti iṣẹ́ náà pàtó.

### 7. Ẹ̀wọ̀n ìpèsè (àwọn dependency)

- **OmniRoute:** osv-scanner + npm-audit + Trivy + Dependabot (SCA), license-checker (SPDX allowlist), lockfile-lint (HTTPS+sha512+registry), `check-deps` anti-slopsquatting (allowlist + ọjọ́-orí ≥72h).
- **Gbogbogbò:** SCA láti ọ̀pọ̀ orísun + allowlist ìwé-àṣẹ + àyẹ̀wò ìdúróṣinṣin lockfile + allowlist dependency pẹ̀lú àyẹ̀wò ọjọ́-orí/typosquatting + bot ìmúdójúìwọ̀n tó ń pín wọn sí ẹgbẹ́.

### 8. Ẹ̀wọ̀n ìpèsè (build & release)

- **OmniRoute:** SBOM (CycloneDX + syft), ìjérìí orísun SLSA (`--provenance`), OpenSSF Scorecard (ọ̀sẹ̀ kọ̀ọ̀kan), fífún workflow lókun (zizmor: artipacked→`persist-credentials:false`, cache-poisoning, token-permissions).
- **Gbogbogbò:** ṣe SBOM nígbà publish + ìjérìí orísun tí a fọwọ́ sí (SLSA L2+) + Scorecard tí a ṣètò sí àsìkò + fún gbogbo workflow lókun (àwọn token tó ní àṣẹ tó kéré jù, kò gbọdọ̀ sí credentials tí a pa mọ́ lórí checkout tí kì í ṣe ti pusher, actions tí a so mọ́ SHA).

### 9. Àwọn àdéhùn & API

- **OmniRoute:** oasdiff (ìyípadà OpenAPI tó ń fọ́ nǹkan), schemathesis (contract fuzz alẹ́), openapi-coverage (% àwọn route tí a ṣàkọsílẹ̀, ratchet 38.3%), openapi-security-tiers (spec vs route-guard).
- **Gbogbogbò:** ìfiwéra àdéhùn fún ìyípadà tó ń fọ́ nǹkan (oasdiff/buf) + fuzz tó dá lórí property lòdì sí spec (schemathesis) + coverage ìwé-àkọsílẹ̀ tí a fi ratchet sí + ìbámu spec↔kóòdù.

### 10. Àwọn ìwé-àkọsílẹ̀ & i18n (òdì sí jíjẹrà)

- **OmniRoute:** docs-sync (àwọn ẹ̀yà tó ń ṣe àwòkọ́ṣe ara wọn), docs-counts-sync (àwọn nọ́ńbà nínú ìwé-àkọsílẹ̀ vs kóòdù), env-doc-sync, doc-links, fabricated-docs, cli-i18n, i18n-ui-coverage (`--threshold=65` + ratchet 80.1%).
- **Gbogbogbò:** mú àwọn ẹ̀yà/nọ́ńbà/env-vars nínú ìwé-àkọsílẹ̀ àti kóòdù bá ara wọn mu (ibodè, kì í ṣe ìgbẹ́kẹ̀lé) + fìdí àwọn link inú rẹ̀ múlẹ̀ + coverage i18n tí a fi ratchet sí.

### 11. Òdì sí ìrò-àròsọ / ìbámu (ẹ̀ka tí kò wọ́pọ̀)

- **OmniRoute:** known-symbols (string dispatch ⇒ living symbol), provider-consistency, fetch-targets (client fetch ⇒ route gidi), docs-symbols, db-rules (Àwọn Òfin Tó Múná Doko #2/#5), migration-numbering.
- **Gbogbogbò:** fún gbogbo “orísun òtítọ́ tí a ṣe àdáwòkọ” (registry, string dispatch, àwọn ìtọ́kasí tó ré kọjá layer), ibodè kan tó jẹ́rìí pé ẹ̀gbẹ́ méjèèjì bára mu. Ó ń mú jíjẹrà tí typecheck/test kò rí.

### 12. Ìfaradà & àgbègbè iṣẹ́ (tó jẹ́ ti ọjà náà pàtó)

- **OmniRoute:** chaos (fault-injection), heap-growth (leak), k6 (soak), promptfoo+garak (LLM red-team OWASP LLM Top 10), àwọn òfin ìfaradà 3 (circuit-breaker/cooldown/lockout).
- **Gbogbogbò:** ṣe ìdánimọ̀ àwọn ọ̀nà tí nǹkan lè kùnà nínú àgbègbè iṣẹ́ **tirẹ**, kí o sì ní ibodè kan (kódà bí ó bá jẹ́ ti alẹ́) fún ọ̀kọ̀ọ̀kan. Fún àwọn app AI: injection red-team. Fún àwọn distributed systems: chaos + leak + soak.

## Apá 4 — Ètò Àtúndá fún Iṣẹ́ Àkànṣe Èyíkéyìí

Kọ́ ọ ní **àwọn ìpele**, kí ọ̀kọ̀ọ̀kan sì máa mú iye wá fúnra rẹ̀. Má ṣe gbìyànjú gbogbo ẹ̀ka 12 lẹ́ẹ̀kan náà —
èyí máa ń fa àárẹ̀ ẹnubodè gan-an tí Apá 2 kìlọ̀ nípa rẹ̀. Gbogbo ẹnubodè tuntun máa bẹ̀rẹ̀ gẹ́gẹ́ bí **ìmọ̀ràn** yóò sì
di **adíwọ̀** nígbà tí ó bá dúró ṣinṣin.

### Kókó tí a lè tún lò: "ẹ̀yà ara ẹnubodè ratchet kan"

Gbogbo ètò náà dá lórí àpẹẹrẹ fáìlì 3 yìí. Kọ́kọ́ ṣe àdàkọ rẹ̀:

1. **`baseline.json`** — iye òṣùwọ̀n tí a ti dì múlẹ̀ + `direction` (`up`/`down`) + `eps` (ìdènà ìyípadà aláìdúró) + `tightenSlack` + `dedicatedGate`.
2. **`collect-metrics.<ext>`** — ń ṣiṣẹ́ irinṣẹ́ náà, ń yọ nọ́mbà náà jáde, ó sì ń kọ `metrics.json`.
3. **`check-ratchet.<ext>`** — ń fi `metrics.json` wé `baseline.json`; `exit 1` **kìkì** bí ìfàsẹ́yìn bá kọjá `eps`; `exit 0` (ìfò kọjá láìfa ìṣòro) bí irinṣẹ́/amúgbáyegbè bá ṣáìsí; pẹ̀lú `--require-tighten`, `exit 1` bí ó bá **dára sí i** láìṣe ìmúdójúìwọ̀n ìpilẹ̀ (ó ń dì èrè náà múlẹ̀).

Pẹ̀lú èyí ní ipò, **gbogbo** òṣùwọ̀n tuntun (ìbòrí, ìdíjú, àwọn ìkìlọ̀, àwọn ìtanilólobó SAST, ìwọ̀n ìdìpọ̀, àbájáde àyípadà…) jẹ́ ìlà kan ṣoṣo nínú ìpilẹ̀.

### Ìpele 0 — Ìpìlẹ̀ (ọ̀sẹ̀ 1)

CI ti wà; olùṣètò-ọ̀nà-kíkọ + olùṣàyẹ̀wò + àyẹ̀wò irú + olùṣiṣẹ́ ìdánwò 1 + ààlà ìbòrí **tí ó jẹ́ pípé**
(fún àpẹẹrẹ, 60%). Pre-commit máa ń ṣiṣẹ́ àwọn àyẹ̀wò yíyára tí a lè túnṣe fúnra wọn. _Àbájáde: kò sí PR tí yóò ba àwọn ìpìlẹ̀ jẹ́._

### Ìpele 1 — Ẹ́ńjìnnì ratchet (ọ̀sẹ̀ 2) — **ìpìlẹ̀ ohun gbogbo**

Ṣe àwọn fáìlì 3 lókè náà. Di àwọn ìpilẹ̀ múlẹ̀ fún: àwọn ìkìlọ̀, ìbòrí, ìdíjú, àtúnṣe ẹ̀dà,
kóòdù tí kò ṣiṣẹ́, ìwọ̀n fáìlì. _Àbájáde: ibi-kóòdù náà lè máa dára sí i nìkan láti ìsinsìnyí lọ._

### Ìpele 2 — Ìjìnlẹ̀ àyẹ̀wò aláìṣiṣẹ́ (ọ̀sẹ̀ 3)

SAST (CodeQL/Sonar/semgrep) pẹ̀lú ratchet ìtanilólobó; aṣàyẹ̀wò àṣírí (**jogún àkójọpọ̀ òfin àkóbá**);
SCA (osv/Dependabot) + àkójọ ìwé-àṣẹ tí a fàyè gbà + lockfile-lint. _Àbájáde: àwọn àìlera tí a mọ̀ àti
àwọn àṣírí tí ó ti tú jáde kò ní kọjá._

### Ìpele 3 — Pq ìpèsè ìkọ́lé (ọ̀sẹ̀ 4)

SBOM nígbà ìtẹ̀jáde + ẹ̀rí orísun tí a fọwọ́ sí (SLSA L2) + Scorecard tí a ṣètò sí àkókò + fífún ìṣàn-iṣẹ́ ní ààbò
(zizmor: àwọn àmì ìwọlé tí ó kéré jù, kò sí ẹ̀rí ìdánimọ̀ tí a fi pamọ́, àwọn ìgbésẹ̀ tí a dì mọ́ ẹ̀yà pàtó). _Àbájáde: àwọn ìtẹ̀jáde tí a lè tọpasẹ̀
tí a kò sì lè yí padà lọ́nà àrékérekè._

### Ìpele 4 — Okun ìdánwò (ọ̀sẹ̀ 5–6)

Olùṣiṣẹ́ kejì bí ó bá wúlò; **àwọn ààlà ìbòrí fún módù kọ̀ọ̀kan fún àwọn módù pàtàkì** (ìdènà-Goodhart);
ìdánwò tó dá lórí àwọn àbùdá fún ìrònú mímọ́; **ìdánwò àyípadà lóru** → nígbà tí àbájáde àkọ́kọ́ bá dé, ṣe
`mutationScore` ní ratchet. _Àbájáde: ìbòrí kò ní jẹ́ òṣùwọ̀n ìgbéraga mọ́; àwọn ìdánwò ń mú àṣìṣe ní ọ̀nà tí a lè fi ẹ̀rí múlẹ̀._

### Ìpele 5 — Àdéhùn & alágbára (ọ̀sẹ̀ 7)

Bí API gbogbogbò bá wà: oasdiff (ìyípadà tó lè ba nǹkan jẹ́, **adíwọ̀**) + schemathesis (fuzz lóru).
DAST/ẹgbẹ́-pupa lóru gẹ́gẹ́ bí ó ṣe yẹ fún ibùdó iṣẹ́ náà. _Àbájáde: àwọn àdéhùn kì í bàjẹ́ ní ìdákẹ́jẹ́._

### Ìpele 6 — Ìdènà àròsọ & ibùdó iṣẹ́ (ọ̀sẹ̀ 8)

Ẹnubodè ìbámu kan fún “òtítọ́ àdáwòkọ” kọ̀ọ̀kan nínú iṣẹ́ àkànṣe náà. Àwọn ẹnubodè ipò-ìkùnà
tó jẹ́ pàtó sí ibùdó iṣẹ́ (fún AI: ẹgbẹ́-pupa ìkọlù àbáwọlé). _Àbájáde: ìbàjẹ́ ètò àti àwọn ìkùnà ibùdó iṣẹ́ ní àwọ̀n ààbò._

### Ìpele 7 — Ìṣàkóso (tí ń lọ lọ́wọ́)

- Ìyípo ìmọ̀ràn→adíwọ̀ fún gbogbo ẹnubodè tuntun.
- `stale-allowlist`: gbogbo ìdákẹ́jẹ́ ní ìdáláre + ọ̀ràn; a máa rí ìdákẹ́jẹ́ tí kò wúlò mọ́.
- `evidence-gate`: ìkéde àṣeyọrí nínú PR nílò ẹ̀rí (ìdánwò tàbí ìdánwò tó ń ṣiṣẹ́).
- **Àyẹ̀wò ROI lọ́sọ̀ọ̀sẹ̀-mẹ́ta fún ẹnubodè kọ̀ọ̀kan** (yọ/fagilé ìnáwó àwọn tí kò san èrè padà — èyí ń gbógun ti àárẹ̀).
- Yí Àwọn Òfin Líle ti iṣẹ́ àkànṣe rẹ padà sí àwọn ẹnubodè tí a lè ṣiṣẹ́.

### Àwọn ìlànà tó gba gbogbo apá (tí a kò lè fi ẹnu kò)

- **Ratchet, kì í ṣe iye pípé.** Fi _àìṣe-ìfàsẹ́yìn_ ṣe ẹnubodè, kì í ṣe nọ́mbà kan tí a dì múlẹ̀ (àfi àwọn ààlà ìdènà-òdo).
- **Ààlà pípé + ratchet papọ̀.** Ààlà náà ń dènà ìwólulẹ̀; ratchet náà ń dènà ìrẹ̀wẹ̀sì díẹ̀díẹ̀.
- **Ìdènà-Goodhart nípasẹ̀ àpẹrẹ.** Gbogbo òṣùwọ̀n àfojúsùn nílò ohun ìwọ̀ntúnwọ̀nsì (ìbòrí ⇒ àyípadà + ìdènà ìbòjú; àwọn ààlà fún módù kọ̀ọ̀kan láti fi dandan mú ìdánwò kóòdù tó nira).
- **Ìfò kọjá láìfa ìṣòro.** Àìsí amúgbáyegbè kì í dí ọ̀nà; ìfàsẹ́yìn gidi nìkan ni yóò dí ọ̀nà.
- **`dedicatedGate` fún àwọn òṣùwọ̀n olówó ńlá.** Àwọn òṣùwọ̀n tó nílò fáìlì alakèrè òde máa ní àkọsílẹ̀-ìṣe tiwọn (pẹ̀lú ìfò kọjá), ní òde ratchet àárín tó ń ṣiṣẹ́ lẹ́sẹ̀kẹsẹ̀.
- **Fi ẹnubodè síbi tí ìdapọ̀ ti ń ṣẹlẹ̀.** Má ṣe fi àlàfo sílẹ̀ láàárín ẹnubodè yíyára àti ìdapọ̀ gangan (ẹ̀kọ́ láti inú ìpín àwọn ẹnubodè yíyára).
- **Àwọn ẹnubodè adíwọ̀ díẹ̀, tí a yàn dáadáa.** Sonar/DORA: àwọn ipò tó pọ̀ jù = àárẹ̀. Yan ìmọ̀ràn + ratchet dípò ògiri àwọn ẹnubodè adíwọ̀.

## Apá 5 — Àwọn ìmúgbòòrò tí a dábàá (ní ìtòlẹ́sẹẹsẹ ààyò, tó sì bá ètò tó wà mu)

**P0 — ROI tó ga jù, ó fẹ́rẹ̀ẹ́ ṣetán**

1. **Ratchet ìwọ̀n mutation** (lẹ́yìn tí ìṣiṣẹ́ Stryker alẹ́ àkọ́kọ́ bá ṣe àwọn iye jáde). Òògùn pàtàkì lòdì sí coverage-Goodhart; ó ti tó ~90% láti parí.
2. **Pa àlàfo fast-gates tó kù dé** — gbé production build inú `quality.yml` ga lẹ́yìn ọ̀sẹ̀ ìkìlọ̀ rẹ̀,
   kí o sì máa tẹ̀síwájú láti gbé àwọn àyẹ̀wò deterministic tí ó jẹ́ ti release-PR-nìkan sínú ipa-ọ̀nà PR→release.
3. **Ààbò ẹ̀ka lórí `main`** (ètò olówó) — ó ń mú Scorecard ga, ó sì ń pa àlàfo DSOMM dé.

**P1 — ó níyelórí** 4. **osv/oasdiff → dídènà pẹ̀lú ààlà tó tọ́** — osv fún CRITICAL+fixable nìkan (ìgbésẹ̀ méjì bíi Trivy); oasdiff ń dènà breaking-changes. 5. **`require-tighten` → dídènà** (ní òpin cycle) — ó ń mú kí àwọn èrè metric dúró ṣinṣin. 6. **Àyẹ̀wò ROI/àkókò fún gate kọ̀ọ̀kan** nínú `ci-summary` — wá àwọn gate tó lọ́ra/tí iye wọn kéré, kí o sì gé wọn kúrò.

**P2 — èrè tó ń dín kù** 7. **SLSA L3** — hermetic/reproducible builder (GitHub SLSA generator) bí o bá fẹ́ gòkè láti L2. 8. **CodeQL config tí a commit + semgrep tó ní version** — ìṣàkóso/reproducibility tó pọ̀ sí i. 9. **DAST smoke fún PR kọ̀ọ̀kan** — apá kékeré tó yára ti schemathesis/promptfoo lórí àwọn endpoint tó ní ewu jù (kì í ṣe ní alẹ́ nìkan). 10. **Dashboard flakiness + àwọn metric DORA** — rí i dájú pé àwọn gate kò ń dín iyára kù.

(`quality.yml`)**, èyí tí KÒ ṣiṣẹ́ gbogbo unit suite, tàbí `pr-test-policy` (test-masking), tàbí

   ohun tó ti pé. Static analysis yẹ kí ó ti rí èyí nínú PR #4034.
2. **Ìdánwò tó ti pé nítorí ìyípadà packaging** — `findMissingArtifactPaths ... root runtime files`:
   `dist/http-method-guard.cjs` di required-path tó bófin mu; àtòjọ expected inú ìdánwò náà di
   ohun tó ti pé.
3. **Ìyapa modularization tó ń sọ data nù (èyí tó le jù)** — `settings schemas accept ... unprefixed
toggle`: `updateSettingsSchema` tí a **modularize** (`schemas/settings.ts`, tí #3988 dá sílẹ̀) yà kúrò
   ní ti canonical (`settingsSchemas.ts`): **field 45 sí 85 — 40 sọnù + 6 yàtọ̀ (qdrant\*)**. Ó jẹ́
   **dead-code** (runtime ń lo ti canonical), nítorí náà kò ní ipa lórí eto tó ń ṣiṣẹ́, ṣùgbọ́n parity
   test tí a fi ọwọ́ kọ nìkan ló rí i. #4030 mú àwọn ohun 16 tí ó jọra tí ó sọnù láti #3988/#3993 padà, ṣùgbọ́n èyí yọ́ mọ́ wọn lọ.

**Àwọn gate tí a dábàá (Phase 9):**

- **G1 — Pa àlàfo fast-gates dé ní tòótọ́ (ó fa P0 #2 gùn).** Nínú `quality.yml` (PR→`release/**`),
  ní àfikún sí typecheck + àwọn ìdánwò tí ìyípadà kàn, ṣiṣẹ́ **`pr-test-policy` (test-masking) + gbogbo
  unit suite deterministic** (tàbí ó kéré tán àwọn fáìlì static/parity, tí wọ́n yára tí wọn kò sì flaky).
  Ní ọ̀nà yìí, a ó rí àwọn ìdánwò tó ti pé àti yíyọ assert kúrò nínú PR tó mú wọn wọlé — kì í ṣe ní
  ọjọ́ release. Má ṣe fi integration/e2e sí i (wọ́n lọ́ra/flaky), ṣùgbọ́n layer deterministic KÒ GBỌDỌ̀ wà
  nínú PR→main nìkan.
- **G2 — Gate parity modularization (TUNTUN, a kò tíì bo ó lónìí).** Àyẹ̀wò kan tí, fún symbol kọ̀ọ̀kan
  tí modularized barrel tún export (`src/shared/validation/schemas/*`, àwọn module `providerRegistry`,
  àti bẹ́ẹ̀ bẹ́ẹ̀ lọ), ń fi **shape** (`z.object` keys, registry entries) wé ti canonical
  source, tí ó sì **kùnà nígbà ìyapa** (field tó sọnù/tó pọ̀ ju). Ìyẹn ìbá ti rí field 40 tó sọnù láti
  #3988 nínú PR yẹn gan-an. Ó mú àwọn parity test tí a fi ọwọ́ kọ gbòòrò sí i (tí wọ́n wà níbi tí ẹnì kan
  rántí láti kọ wọ́n nìkan). Ó rọrùn: ó import àwọn méjèèjì, ó sì ṣe diff `Object.keys(shape)`.
- **G3 — Triage flake deterministic (àtìlẹ́yìn).** LiveWS-startup àti àwọn ìdánwò integration-combo/breaker
  ń kùnà nítorí server timeout/cascade nínú CI (env), kì í ṣe logic. Samisi wọn gẹ́gẹ́ bí
  `known-flaky` (tí a ya sọ́tọ̀ pẹ̀lú issue) kí àmì pupa release-PR jẹ́ **àwọn signal gidi nìkan**, kì í ṣe noise
  tó ń bo àwọn regression deterministic mọ́lẹ̀ láàrín.

**Ìlànà:** _gate náà gbọ́dọ̀ ṣiṣẹ́ níbi tí merge ti ń ṣẹlẹ̀_ (ó ti wà nínú “Àwọn ìlànà tó kàn gbogbo apá”). Ìṣẹ̀lẹ̀
v3.8.27 fi hàn pé èyí tún kan **layer ìdánwò deterministic**, kì í ṣe lint/typecheck nìkan —
bí bẹ́ẹ̀ kọ́, gbèsè àwọn ìdánwò tó ti pé + modularization tó ń sọ data nù yóò hàn nínú PR→main nìkan, ní batch, ní
àkókò tó burú jù.
