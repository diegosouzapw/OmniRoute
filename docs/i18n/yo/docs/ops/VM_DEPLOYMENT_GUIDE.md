## Àwọn ohun tí a nílò ṣáájú

| Ohun        | Èyí tó kéré jù             | Èyí tí a dábàá   |
| ----------- | -------------------------- | ---------------- |
| **CPU**     | 1 vCPU                     | 2 vCPU           |
| **RAM**     | 1 GB                       | 2 GB             |
| **Dísìkì**  | 10 GB SSD                  | 25 GB SSD        |
| **OS**      | Ubuntu 22.04 LTS           | Ubuntu 24.04 LTS |
| **Dó메ènì** | Forúkọsílẹ̀ lórí Cloudflare | —                |
| **Docker**  | Docker Engine 24+          | Docker 27+       |

**Àwọn olùpèsè tí a ti dánwò**: Akamai (Linode), DigitalOcean, Vultr, Hetzner, AWS Lightsail.

## 1. Ṣètò VM náà

### 1.1 Ṣẹ̀dá instance náà

Lórí olùpèsè VPS tí o fẹ́:

- Yan Ubuntu 24.04 LTS
- Yan ètò tó kéré jù (1 vCPU / 1 GB RAM)
- Ṣètò ọ̀rọ̀ aṣínà root tó lágbára tàbí ṣètò kọ́kọ́rọ́ SSH
- Ṣàkọsílẹ̀ **IP gbogbogbò** náà (fún àpẹẹrẹ, `203.0.113.10`)

### 1.2 Sopọ̀ nípasẹ̀ SSH

```bash
ssh root@203.0.113.10
```

### 1.3 Ṣe ìmúdójúìwọ̀n ètò náà

```bash
apt update && apt upgrade -y
```

### 1.4 Fi Docker sílẹ̀

```bash
# Fi àwọn ohun tí ó gbára lé sílẹ̀
apt install -y ca-certificates curl gnupg

# Ṣàfikún ibi ìpamọ́ Docker oníṣẹ́
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $ (. /etc/os-release && echo "$VERSION_CODENAME") stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

### 1.5 Fi nginx sílẹ̀

```bash
apt install -y nginx
```

### 1.6 Ṣètò Firewall (UFW)

```bash
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp    # SSH
ufw allow 80/tcp    # HTTP (àtúndarí)
ufw allow 443/tcp   # HTTPS
ufw enable
```

> **Ìmọ̀ràn**: Fún ààbò tó pọ̀ jù, dín ìráyè sí àwọn port 80 àti 443 kù sí àwọn IP Cloudflare nìkan. Wo abala [Ààbò Ìpele Gíga](#advanced-security).

## 2. Fi OmniRoute sílẹ̀

### 2.1 Ṣẹ̀dá àkójọ fáìlì ìṣètò

```bash
mkdir -p /opt/omniroute
```

### 2.2 Ṣẹ̀dá fáìlì àwọn oníyí àyíká

```bash
cat > /opt/omniroute/.env << 'EOF'
# === Ààbò ===
JWT_SECRET=CHANGE-TO-A-UNIQUE-64-CHAR-SECRET-KEY
INITIAL_PASSWORD=YourSecurePassword123!
API_KEY_SECRET=REPLACE-WITH-ANOTHER-SECRET-KEY
STORAGE_ENCRYPTION_KEY=REPLACE-WITH-THIRD-SECRET-KEY
STORAGE_ENCRYPTION_KEY_VERSION=v1
MACHINE_ID_SALT=CHANGE-TO-A-UNIQUE-SALT
OMNIROUTE_WS_BRIDGE_SECRET=REPLACE-WITH-WS-BRIDGE-SECRET  # Ó PỌNDÁN ní production: Codex Responses WS bridge ló ń lò ó

# === Ìṣàfilọ́lẹ̀ ===
PORT=20128
NODE_ENV=production
HOSTNAME=0.0.0.0
DATA_DIR=/app/data
APP_LOG_TO_FILE=true
AUTH_COOKIE_SECURE=true
REQUIRE_API_KEY=false

# === Àwọn URL (yí padà sí dó메ènì rẹ) ===
# URL ìpìlẹ̀ inú láti server sí server fún àwọn iṣẹ́ tí a ṣètò / àwọn self-fetch.
BASE_URL=http://127.0.0.1:20128
# URL tí aṣàwákiri ń lò fún àwọn callback OAuth, àwọn ìjápọ̀ dashboard, àti àwọn URL gbogbogbò tí a ṣẹ̀dá.
NEXT_PUBLIC_BASE_URL=https://llms.seudominio.com
# Ìṣàtúnṣe origin gbogbogbò tó ṣe kedere, tí kò pọndandan, fún àwọn URL asset gbogbogbò tí a ṣẹ̀dá.
# OMNIROUTE_PUBLIC_BASE_URL=https://llms.seudominio.com

# === Ìmúdójúìwọ̀n Cloud (kò pọndandan) ===
# CLOUD_URL=https://cloud.omniroute.online
# NEXT_PUBLIC_CLOUD_URL=https://cloud.omniroute.online
EOF
```

> ⚠️ **PÀTÀKÌ**: Ṣẹ̀dá àwọn kọ́kọ́rọ́ àṣírí aláìlẹ́gbẹ́! Lo `openssl rand -hex 32` fún kọ́kọ́rọ́ kọ̀ọ̀kan.

### 2.3 Bẹ̀rẹ̀ container náà

```bash
docker pull diegosouzapw/omniroute:latest

docker run -d \
  --name omniroute \
  --restart unless-stopped \
  --env-file /opt/omniroute/.env \
  -p 20128:20128 \
  -v omniroute-data:/app/data \
  diegosouzapw/omniroute:latest
```

### 2.4 Ṣàyẹ̀wò pé ó ń ṣiṣẹ́

```bash
docker ps | grep omniroute
docker logs omniroute --tail 20
```

Ó yẹ kí ó ṣàfihàn: `[DB] SQLite database ready` àti `listening on port 20128`.

## 3. Ṣètò nginx (Aṣojú Ìyípadà)

### 3.1 Ṣẹ̀dá ìwé-ẹ̀rí SSL (Cloudflare Origin)

Nínú pánẹ́ẹ̀lì ìṣàkóso Cloudflare:

1. Lọ sí **SSL/TLS → Origin Server**
2. Tẹ **Create Certificate**
3. Fi àwọn àṣàyàn àkọ́kọ́ sílẹ̀ bí wọ́n ṣe rí (ọdún 15, \*.yourdomain.com)
4. Da **Origin Certificate** àti **Private Key** kọ

```bash
mkdir -p /etc/nginx/ssl

# Lẹ ìwé-ẹ̀rí náà síbí
nano /etc/nginx/ssl/origin.crt

# Lẹ́ kọ́kọ́rọ́ àṣírí náà síbí
nano /etc/nginx/ssl/origin.key

chmod 600 /etc/nginx/ssl/origin.key
```

### 3.2 Ìṣètò Nginx

```bash
cat > /etc/nginx/sites-available/omniroute << 'NGINX'
# Sẹ́fà àkọ́kọ́ — ń dí ìráyè tààrà nípasẹ̀ IP
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    listen 443 ssl default_server;
    listen [::]:443 ssl default_server;
    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    server_name _;
    return 444;
}

# OmniRoute — HTTPS
server {
    listen 443 ssl;
    listen [::]:443 ssl;
    server_name llms.yourdomain.com;  # Yí i padà sí domain rẹ

    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    client_max_body_size 100M;

    location / {
        proxy_pass http://127.0.0.1:20128;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Àtìlẹ́yìn WebSocket
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # SSE (Àwọn Ìṣẹ̀lẹ̀ tí Sẹ́fà Firanṣẹ́) — ìṣàn àwọn ìdáhùn AI
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }
}

# Ìdarípadà HTTP → HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name llms.yourdomain.com;
    return 301 https://$server_name$request_uri;
}
NGINX
```

Jẹ́ kí àwọn àkókò ìdádúró ìṣàn aṣojú-ìyípadà bá àwọn oníyí env àkókò ìdádúró OmniRoute rẹ mu. Tí o bá mú
`FETCH_TIMEOUT_MS` / `STREAM_IDLE_TIMEOUT_MS` ga, mú `proxy_read_timeout` / `proxy_send_timeout`
ga ju ààlà kan náà lọ.

OmniRoute ń lo `NEXT_PUBLIC_BASE_URL` gẹ́gẹ́ bí orísun àṣẹ tí aṣàwákiri ń rí fún àwọn ìpèpadà
OAuth àti àwọn ìjápọ̀ gbogbogbò tí a ṣẹ̀dá. Àwọn ìkọ̀wé pánẹ́ẹ̀lì ìṣàkóso tí a ti fìdí ìdánimọ̀ wọn múlẹ̀ ń lo àwọn ìbéèrè orísun-kan-náà
pẹ̀lú ààbò CSRF tí a so mọ́ sáà, nítorí náà wọn kò nílò URL ìpìlẹ̀ gbogbogbò tó dúró ṣinṣin. Àwọn
àkọsori `X-Forwarded-*` tó wà lókè ṣì jẹ́ metadata ìdarí ipa tó wúlò, ṣùgbọ́n wọn kò lè rọ́pò
ṣíṣètò URL gbogbogbò tó ṣe kedere nígbà tí OAuth tàbí àwọn ìjápọ̀ aṣàwákiri tí a ṣẹ̀dá bá nílò rẹ̀. Ṣí
`OMNIROUTE_TRUST_PROXY` sílẹ̀ nìkan tí àwọn oníbàárà kò bá lè dé OmniRoute ní tààrà àti tí aṣojú rẹ
bá ń yọ/ń tún àwọn àkọsori ìfiranṣẹ́sí tó ń wọlé kọ́.

### 3.3 Mú Un Ṣiṣẹ́ kí o sì Dán An Wò

```bash
# Yọ ìṣètò àkọ́kọ́ kúrò
rm -f /etc/nginx/sites-enabled/default

# Mú OmniRoute ṣiṣẹ́
ln -sf /etc/nginx/sites-available/omniroute /etc/nginx/sites-enabled/omniroute

# Dán an wò kí o sì tún un gbé wọlé
nginx -t && systemctl reload nginx
```

## 4. Ṣètò DNS Cloudflare

### 4.1 Ṣàfikún àkọsílẹ̀ DNS

## Ìṣàtúnṣe fún Ìrántí Kékeré / VPS Kékeré

Fún ìmúṣiṣẹ́ lórí àwọn VPS kékeré (1 GB RAM tàbí kéré sí i):

- **Pa àwọn iṣẹ́ abẹ́lẹ̀** — ṣètò `OMNIROUTE_DISABLE_BACKGROUND_SERVICES=1` láti foju kọ olùṣètò àkókò, MCP server, àti àwọn iṣẹ́ ìtọ́jú àsìkò. Wo `docs/reference/ENVIRONMENT.md`.
- **Lo SQLite WAL mode** — ó ti ṣiṣẹ́ láìyẹsẹ̀, ó sì dín lílo ìrántí tó ga jù nígbà àwọn kíkà tó ń ṣẹlẹ̀ lẹ́ẹ̀kan náà.
- **Fi òpin sí V8 heap** — ṣètò `OMNIROUTE_MEMORY_MB` (fún àpẹẹrẹ `512`) kí runtime má bàa ṣe ìṣírò òpin tó tóbi ju VM lọ. Wo `docs/reference/ENVIRONMENT.md`.
- **Ìgbàwọlé iṣẹ́ wuwo máa ń ṣe ìwọ̀n ara rẹ̀ ní ìbámu pẹ̀lú òpin heap** -- ní kété tí a bá ṣètò `OMNIROUTE_MEMORY_MB` lókè, ìṣúná báìtì ìgbàwọlé (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) máa ń jẹyọ láti inú òpin kan náà, nítorí náà VM tí ìrántí rẹ̀ ní ààlà yóò gba ìṣúná kékeré fún àwọn ìbéèrè tó ń ṣiṣẹ́ lẹ́ẹ̀kan náà láìsí àtúnṣe míì; àwọn ìbéèrè tó pọ̀ jù yóò gba `503` tí a lè tún gbìyànjú pẹ̀lú `Retry-After` dípò kí wọ́n díje fún ìrántí. Ṣètò òpin iye ìbéèrè àtijọ́ `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` nìkan tí o bá nílò òpin líle ní àfikún sí èyí.
- **Yẹra fún `next build` lórí VPS** — kọ́ ọ́ ní agbègbè rẹ kí o sì fi àbájáde standalone (`.next/standalone/`) sílò.
- **Ṣàbójútó pẹ̀lú `top` / `free -m`** — OmniRoute sábà máa ń lo 200-400 MB RSS nígbà tí kò ṣiṣẹ́ lórí VM 1 GB.
