## Àwọn òfin

- Àwọn àfojúsùn ìborí kan àwọn fáìlì orísun, kì í ṣe `tests/**`.
- `open-sse/**` jẹ́ apá kan ọjà náà, ó sì gbọ́dọ̀ wà nínú ààlà.
- Kóòdù tuntun kò gbọ́dọ̀ dín ìborí kù ní àwọn agbègbè tí a bá yí padà.
- Yan ìdánwò ìhùwàsí àti àbájáde àwọn ẹ̀ka dípò àwọn kúlẹ̀kúlẹ̀ ìmúṣẹ.
- Yan àwọn ibi ìpamọ́ dátà SQLite fún ìgbà díẹ̀ àti àwọn àpẹẹrẹ kéékèèké dípò àwọn àfarawé gbòòrò fún `src/lib/db/**`.

## Àkójọpọ̀ àṣẹ lọ́wọ́lọ́wọ́

- `npm run test:coverage`
  - Ìdènà ìborí kóòdù orísun àkọ́kọ́ fún àkójọpọ̀ ìdánwò ẹyọ kọ̀ọ̀kan
  - Ó ń ṣe àgbéjáde `text-summary`, `html`, `json-summary`, àti `lcov`
- `npm run coverage:report`
  - Ìjábọ̀ ẹ̀kúnrẹ́rẹ́ fáìlì-kọ̀ọ̀kan láti inú ìdánwò tuntun jù lọ
- `npm run test:coverage:legacy`
  - Fún ìfiwéra pẹ̀lú ti àtijọ́ nìkan

## Ìlànà ratchet

Ṣe àfikún sí àwọn ààlà `npm run test:coverage` kìkì lẹ́yìn tí iṣẹ́ náà bá ti kọjá àmì-àfojúsùn tó tẹ̀ lé e ní ti gidi, pẹ̀lú ààyè ààbò tó dára.

**Ààlà lọ́wọ́lọ́wọ́:** `npm run test:coverage` ń fipá mú **60 statements / 60 lines / 60 functions / 60 branches** (a tún ìwọ̀n náà gbé ka lórí ìpìlẹ̀ tuntun ní Quality-Gates Ìpele 6A.1 — ìpìlẹ̀ 82.58% ti tẹ́lẹ̀ ga ju bó ṣe yẹ lọ nítorí pé ó ka àwọn fáìlì ìdánwò, ó sì yọ `open-sse` sílẹ̀). Àṣẹ `test:coverage:legacy` pa ìwọ̀n 50/50/50 àtijọ́ mọ́ fún ìfiwéra ìtàn.

Fún ṣíṣe àyẹ̀wò ààlà lẹ́sẹ̀kẹsẹ̀ lórí ìròyìn tuntun, lo:

```bash
node scripts/check/test-report-summary.mjs --threshold 75
```

## Àlàfo tí a mọ̀

Àṣẹ ààbò lọ́wọ́lọ́wọ́ ń díwọ̀n àkójọpọ̀ ìdánwò unit Node àkọ́kọ́, ó sì ní source tí wọ́n dé láti inú rẹ̀, pẹ̀lú `open-sse`. Kò tíì ṣàkópọ̀ ààbò Vitest sínú ìròyìn kan ṣoṣo tó ṣọ̀kan. Ó yẹ kí a ṣe àkópọ̀ yẹn nígbà míì, ṣùgbọ́n kì í ṣe ìdènà fún bíbẹ̀rẹ̀ ìlọsíwájú láti 60% -> 80%.
