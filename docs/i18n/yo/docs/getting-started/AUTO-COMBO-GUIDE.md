> **Ní ṣókí**: Ṣètò model rẹ sí `auto`, OmniRoute yóò sì yan olùpèsè AI tó dára jù lọ fún ìbéèrè kọ̀ọ̀kan láìfọwọ́yí. Kò sí ìṣètò kankan tí o nílò.

---

## Ohun Tó Ń Ṣe

Dípò kí o yan model AI kan pàtó (bíi GPT-4o tàbí Claude), o lè jẹ́ kí OmniRoute **yan èyí tó dára jù lọ láìfọwọ́yí** fún ìbéèrè kọ̀ọ̀kan. Ó máa ń gbé àwọn nǹkan wọ̀nyí yẹ̀ wò:

- **Ìlera** — Ṣé olùpèsè náà ń ṣiṣẹ́ ní báyìí?
- **Ìyára** — Báwo ló ṣe yára tó?
- **Ìnáwó** — Elo ni iye owó rẹ̀?
- **Dídára** — Ṣé ó dára fún irú iṣẹ́ yìí?
- **Agbára** — Ṣé quota ṣì kù fún un?

OmniRoute máa ń fún gbogbo àwọn olùpèsè tí o so pọ̀ ní àmì, yóò sì yan èyí tó dára jù lọ. Tí ó bá kùnà, yóò gbìyànjú èyí tó tẹ̀ lé e láìfọwọ́yí.

## Bẹ̀rẹ̀ Ní Kíákíá

**Ìgbésẹ̀ 1**: Ṣètò model rẹ sí `auto` nínú IDE tàbí CLI rẹ:

```
model: "auto"
```

**Ìgbésẹ̀ 2**: Èyí nìkan ni! OmniRoute yóò bójú tó ìyókù.

**Ìgbésẹ̀ 3** (kì í ṣe dandan): Lo variant kan fún àwọn iṣẹ́ pàtó:

```
model: "auto/coding"    # Tó dára jù lọ fún kóòdù
model: "auto/fast"      # Ìdáhùn tó yára jù lọ
model: "auto/cheap"     # Àṣàyàn tó din owó jù lọ
```

## "auto" Wo Ni Ó Yẹ Kí N Lo?

| Tí o bá fẹ́...               | Lo èyí         | Ó dára jù lọ fún                 | Bí ó ṣe ń ṣiṣẹ́                              |
| --------------------------- | -------------- | -------------------------------- | ------------------------------------------- |
| **Èyí tó dára jù lápapọ̀**   | `auto`         | Àwọn ìbéèrè gbogbogbò, ìfọ̀rọ̀wérọ̀ | Ó mú ìyára, ìnáwó, àti dídára dọ́gba         |
| **Kóòdù tó dára jù lọ**     | `auto/coding`  | Kíkọ kóòdù, ṣíṣe àtúnṣe àṣìṣe    | Ó yan àwọn model tó dára fún iṣẹ́ kóòdù      |
| **Ìdáhùn tó yára jù lọ**    | `auto/fast`    | Ìdáhùn kíákíá, latency kékeré    | Ó fi ìyára sí ipò àkọ́kọ́ ju gbogbo nǹkan lọ  |
| **Àṣàyàn tó din owó jù lọ** | `auto/cheap`   | Fífipamọ́ owó                     | Ó yan olùpèsè tó din owó jù lọ              |
| **Model tó gbọ́n jù lọ**     | `auto/smart`   | Àwọn iṣẹ́ tó díjú                 | Dídára lákọ̀ọ́kọ́ + ṣíṣàwárí àwọn model tuntun |
| **Èyí tó wà jù lọ**         | `auto/offline` | Nígbà tí àwọn olùpèsè bá dí      | Ó yan àwọn olùpèsè tó ní agbára tó pọ̀ jù lọ |

## Bí Ó Ṣe Ń Ṣiṣẹ́ (Ẹ̀yà Tó Rọrùn)

Nígbà tí o bá fi ìbéèrè kan ránṣẹ́ pẹ̀lú `model: "auto"`, OmniRoute yóò:

1. **Wo gbogbo àwọn olùpèsè tí o so pọ̀** — Gbogbo olùpèsè tí o ti ṣàfikún (OpenAI, Anthropic, Google, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ)
2. **Fún ọ̀kọ̀ọ̀kan ní àmì**, nípa gbígbé àwọn nǹkan wọ̀nyí yẹ̀ wò, lára àwọn ohun mìíràn:
   - Ṣé ó ń ṣiṣẹ́? (ìlera)
   - Ṣé ó ní agbára? (quota)
   - Elo ni iye owó rẹ̀? (iye)
   - Báwo ló ṣe yára tó? (ìyára)
   - Ṣé ó dára fún iṣẹ́ yìí? (dídára)
3. **Yan èyí tó dára jù lọ** — Olùpèsè tó ní àmì tó ga jù lọ ni yóò gba ìbéèrè rẹ
4. **Padà bọ̀ sípò láìfọwọ́yí** — Tí ó bá kùnà, OmniRoute yóò gbìyànjú èyí tó tẹ̀ lé e láìfọwọ́yí

### Ètò Fífún Ní Àmì

Olùpèsè kọ̀ọ̀kan máa ń gba àmì láti 0 sí 1. Bí àmì náà bá ṣe ga tó, bẹ́ẹ̀ ni yóò ṣe bá iṣẹ́ náà mu tó.

| Kókó             | Ìwúwo | Ohun tó túmọ̀ sí                                          |
| ---------------- | ----- | -------------------------------------------------------- |
| Ìlera            | 20%   | Ṣé olùpèsè náà ń ṣiṣẹ́? (ipò circuit breaker)             |
| Quota            | 15%   | Ṣé agbára ṣì kù fún un?                                  |
| Ìnáwó            | 15%   | Báwo ni iye owó rẹ̀ ṣe pọ̀ tó? (tó bá din owó = àmì tó ga) |
| Ìyára            | 12%   | Báwo ló ṣe yára tó? (latency tó kéré = àmì tó ga)        |
| Bíbá Iṣẹ́ Mu      | 8%    | Ṣé ó dára fún irú iṣẹ́ yìí?                               |
| Ìdúróṣinṣin      | 5%    | Ṣé ó dúró déédéé? (ìwọ̀n àṣìṣe kékeré)                    |
| Ìpele            | 5%    | Ìpele àkọọ́lẹ̀ (Ultra > Pro > Free)                        |
| Àwọn Ohun Mìíràn | 20%   | Context affinity, connection density, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ     |

### Bí Àwọn Variant Ṣe Ń Yí Fífún Ní Àmì Padà

Variant kọ̀ọ̀kan ń lo àwọn ìwúwo tó yàtọ̀:

| Variant        | Ohun Tó Fi Sí Ipò Àkọ́kọ́ | Àwọn Ìwúwo Pàtàkì               |
| -------------- | ----------------------- | ------------------------------- |
| `auto`         | Ìwọ̀ntúnwọ̀nsì            | health=20%, quota=15%, cost=15% |
| `auto/coding`  | Dídára                  | taskFit=37%, stability=15%      |
| `auto/fast`    | Ìyára                   | latency=32%, health=28%         |
| `auto/cheap`   | Ìnáwó                   | cost=37%                        |
| `auto/smart`   | Dídára + Ṣíṣàwárí       | taskFit=37%, exploration=10%    |
| `auto/offline` | Agbára                  | quota=37%, health=28%           |

## Bí Ó Ṣe N Kojú Àwọn Ìkùnà

OmniRoute ní **ìpele ààbò mẹ́ta**:

### 1. Ìyípadà Aifọwọ́yí

Tí olùpèsè tó dára jù lọ bá kùnà, OmniRoute yóò gbìyànjú èyí tó tẹ̀ lé e laifọwọ́yí. O kò nílò láti ṣe ohunkóhun.

### 2. Ìmúra-ẹni-padà

Tí olùpèsè kan bá ń kùnà léraléra:

- **Àmì < 0.2** → A ó yọ ọ́ kúrò fún ìṣẹ́jú 5
- **Olùdènà àyíká ṣí** → A ó yọ ọ́ kúrò laifọwọ́yí
- **Ó lé ní 50% àwọn olùpèsè ni kò ṣiṣẹ́** → Ipò ìṣẹ̀lẹ̀ pàjáwìrì (kò sí ìṣàwárí)

### 3. Ìyípadà Pàjáwìrì

Tí gbogbo àwọn olùpèsè bá kùnà, OmniRoute yóò darí ìbéèrè sí àwọn olùpèsè ọ̀fẹ́ tó dúró ṣinṣin (bíi Kiro tàbí Qoder) gẹ́gẹ́ bí ọ̀nà àṣàyàn ìkẹyìn.

---

## Àtìlẹ́yìn Fún Ọ̀pọ̀ Àkọọ́lẹ̀

Tí o bá ní ọ̀pọ̀ àkọọ́lẹ̀ fún olùpèsè kan náà (fún àpẹẹrẹ, kọ́kọ́rọ́ OpenAI méjì), OmniRoute yóò ka ọ̀kọ̀ọ̀kan sí **olùdíje ọ̀tọ̀ọ̀tọ̀**. Èyí túmọ̀ sí pé:

- Àkọọ́lẹ̀ A ṣì ní ìpín lílò tó kù → lò ó
- Àkọọ́lẹ̀ B ní ìdíwọ̀n ìwọ̀n-ìbéèrè → fo òun kọjá
- Àkọọ́lẹ̀ C din owó kù → fi í ṣáájú

A máa ń ṣe àgbéyẹ̀wò àmì àkọọ́lẹ̀ kọ̀ọ̀kan lọ́tọ̀, ní ìbámu pẹ̀lú ìlera, ìpín lílò, àti iyára tirẹ̀.

## Ìṣàwárí Bandit

OmniRoute máa ń **ṣàwárí** àwọn olùpèsè tuntun lẹ́ẹ̀kọ̀ọ̀kan láti rí àwọn àṣàyàn tó dára sí i:

- **Àìpéye**: 5% àwọn ìbéèrè ni a máa ń fi ránṣẹ́ sí àwọn olùpèsè laileto
- **Aifọwọ́yí/ọlọ́gbọ́n**: Ìwọ̀n ìṣàwárí 10%
- **A dá a dúró** nígbà tí ó lé ní 50% àwọn olùpèsè kò bá ní ìlera tó dára

Èyí ń ran OmniRoute lọ́wọ́ láti kọ́ àwọn olùpèsè wo ni ó ṣiṣẹ́ dáadáa jù lọ fún àwọn àṣà lílò rẹ.

## Àwọn Ìbéèrè Tí Ó Wọ́pọ̀

### "Ṣé yóò máa yan àwòṣe tó gbowó jù lọ ní gbogbo ìgbà?"

**Rárá.** Iye owó jẹ́ 15% péré nínú àmì náà ní àìpéye. Olùpèsè tí kò gbowó, tó yára, tí ó sì ní ìlera tó dára lè borí èyí tó gbowó. Lo `auto/cheap` tí o bá fẹ́ fi iye owó sí ipò àkọ́kọ́ sí i.

### "Kí ló máa ṣẹlẹ̀ tí olùpèsè kan kò bá ṣiṣẹ́?"

OmniRoute máa fo òun kọjá laifọwọ́yí, yóò sì gbìyànjú èyí tó tẹ̀ lé e. Tí olùpèsè kan bá ń kùnà léraléra, a ó yọ ọ́ kúrò fún ìgbà díẹ̀ (ìṣẹ́jú 5-30). O kò nílò láti ṣe ohunkóhun.

### "Ṣé mo lè rí olùpèsè tí a lò?"

Ṣàyẹ̀wò àwọn àkọlé ìdáhùn — OmniRoute máa ń ṣàfikún olùpèsè àti àwòṣe tí a lò sínú ìdáhùn kọ̀ọ̀kan.

### "Ṣé ó máa ń kẹ́kọ̀ọ́ láti inú lílò mi?"

Bẹ́ẹ̀ ni! Ètò fífi àmì ń lo dátà àtijọ́ (àkókò ìdádúró, ìwọ̀n àṣìṣe, ìwọ̀n àṣeyọrí) láti ṣe àwọn ìpinnu tó dára sí i bí àkókò ṣe ń lọ.

### "Kí ni ìyàtọ̀ láàárín `auto` àti `auto/smart`?"

- `auto` — Ó dọ́gba, ìṣàwárí 5%
- `auto/smart` — Didára ni àkọ́kọ́ (ìwọ̀n kan náà bí `auto/coding`), ìṣàwárí 10%

Lo `auto/smart` nígbà tí o bá fẹ́ didára tó ga jù lọ, tí o kò sì bìkítà fún ìṣàwárí lẹ́ẹ̀kọ̀ọ̀kan.

### "Ṣé mo lè fipá yan olùpèsè kan pàtó?"

Bẹ́ẹ̀ ni! Lo àpapọ̀ kan pẹ̀lú ọgbọ́n `priority` dípò `auto`, lẹ́yìn náà fi **orúkọ gangan** àpapọ̀ náà ránṣẹ́ gẹ́gẹ́ bí pápá `model` (fún àpẹẹrẹ, `model: "my-combo"` — kì í ṣe `auto`). Wo [Ìtọ́kasí Ìmọ̀-ẹ̀rọ](../routing/AUTO-COMBO.md) fún àlàyé.

### "Báwo ni èyí ṣe yàtọ̀ sí round-robin?"

Round-robin máa ń yí ká láàárín àwọn olùpèsè ní ìtòlẹ́sẹẹsẹ. Auto-combo máa ń **fún olùpèsè kọ̀ọ̀kan ní àmì**, yóò sì yan èyí tó dára jù lọ. Ó gbọ́n sí i — ó máa ń gbé ìlera, iyára, iye owó, àti didára yẹ̀ wò.
