Àkọsílẹ̀ yìí ṣàpèjúwe ìpìlẹ̀ ìdarí-ọ̀nà aṣamubadọgba tí ìdáhùn ń darí, èyí tí a ṣàfikún sí
OmniRoute. A mọ̀ọ́mọ̀ jẹ́ kó kéré: ó ṣàfikún ikanni àbájáde-ìdarí-ọ̀nà tí a ti sọ irú rẹ̀,
àmì dídára lórí-ayelujara tí ń pèsè ìdáhùn fún olùṣírò auto-combo tó ti wà, olùkó-jáde
OpenTelemetry àṣàyàn, àti endpoint ìṣàlàyé. Kò **rò** àkójọpọ̀ ìfaradà tó ti wà
(circuit breaker, connection cooldown, model lockout, health matrix, autopilot) — ó ń ṣe àfikún sí i.

## 1. Àyíká iṣẹ́-àwòrán

OmniRoute jẹ́ pẹ̀lẹ́bẹ̀ dátà tó ní **ọ̀nà kíákíá ìbéèrè** àti **pẹ̀lẹ́bẹ̀
ìṣàkóso/òye**. Ọ̀nà kíákíá náà gbọ́dọ̀ máa yára, lo ìrántí lọ́nà tó péye, ṣiṣẹ́ láìdúró-de,
ní ìfaradà, kí ó sì ṣeé sọ àsọtẹ́lẹ̀. Ìṣàyẹ̀wò, fífúnni ní àmì dídára, àdánwò àti ìtúpalẹ̀ ìtàn
jẹ́ ti pẹ̀lẹ́bẹ̀ ìṣàkóso.

```
Aṣojú AI / IDE
      │
      ▼
┌─────────────────────┐
│    OmniRoute        │   pẹ̀lẹ́bẹ̀ dátà (yára, sync, inú ìrántí)
│  ìdarí-ọ̀nà / failover │
│  ìlera / guardrail  │
│  cache / streaming  │
└──────────┬──────────┘
           │ RoutingEvent (rán-kí-o-gbagbé, ~0.2µs)
           ▼
┌─────────────────────┐
│  Àwọn ibi ìdáhùn   │   pẹ̀lẹ́bẹ̀ ìṣàkóso (async, ìsapá-tó-dára-jù)
│  olùtọpa dídára     │
│  olùkó-jáde OTel    │
│  ibi ìpamọ́ ìṣàlàyé │
└──────────┬──────────┘
           ▼  àmì dídára
      olùṣírò auto-combo
```

### Ohun tó ti wà tẹ́lẹ̀ (tí a ti ṣàyẹ̀wò, tí a kò ṣe àdàkọ rẹ̀)

| Èrò                                       | Ìmúlò tó ti wà                                                                                             |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Wíwà-lárọ̀ọ́wọ́ (ṣé a lè fi traffic ránṣẹ́?)  | Circuit breaker (CLOSED/DEGRADED/OPEN/HALF_OPEN, tí a fi pamọ́ sínú DB), connection cooldown, model lockout |
| Ìjábọ̀ ìlera                               | `providerHealthMatrix.ts`, `providerHealthAutopilot.ts`                                                    |
| Shadow traffic                            | `open-sse/services/combo/shadowRouting.ts`                                                                 |
| Àwọn guardrail                            | `src/lib/guardrails/` (àwọn hook ṣáájú/lẹ́yìn)                                                              |
| Cache gédégbé                             | `src/lib/semanticCache.ts` (tó dá lórí signature)                                                          |
| Àwọn evaluator / ìdarí-ọ̀nà tí eval ń darí | `src/lib/evals/`, `open-sse/services/evalRouting.ts`                                                       |
| Ìṣàlàyé ìpinnu combo                      | `open-sse/services/combo/decisionTrace.ts`                                                                 |
| Àwọn ìṣẹ̀lẹ̀ dashboard ní àkókò-gidi        | `src/lib/events/eventBus.ts` (ikanni ìfitónilétí UI, payload `unknown`, ìtàn onírẹ́kọ́ọ̀dù 100)               |

Pẹlẹbẹ routing-event **kì í ṣe** àtúnṣe `eventBus`: bus yẹn ni
ikanni ìfitónilétí àkókò-gidi ti dashboard (àwọn _orúkọ ìṣẹ̀lẹ̀_ tí a ti sọ irú wọn,
àwọn payload tí kò ṣe kedere, àwọn oníbàárà UI). `RoutingEvent` jẹ́ struct _àbájáde_ tí a ti sọ irú rẹ̀
(latency/tokens/cost/outcome/finish-reason), èyí tí àwọn ibi ìdáhùn ti pẹ̀lẹ́bẹ̀
ìṣàkóso ń lò (olùtọpa dídára, olùkó-jáde OTel, ibi ìpamọ́ ìṣàlàyé).

### Ohun tó ń ṣaláìsí (tí a ṣàfikún níbí)

1. **Ìṣẹ̀lẹ̀ àbájáde-ìdarí-ọ̀nà tí a ti sọ irú rẹ̀ + abstraction ibi ìdáhùn** (`RoutingEvent` /
   `RoutingEventSink`). `decisionTrace` wà fún combo nìkan, ó sì wà nínú ìrántí nìkan;
   `comboMetrics` jẹ́ àwọn counter àkójọpọ̀; `call_logs` jẹ́ ìfipamọ́ async aise.
   Kò sí èyíkéyìí tó jẹ́ ikanni àbájáde tó ní irú, tó dá lórí sink, tí olùtọpa dídára, olùkó-jáde
   OTel, tàbí evaluator irú Future-AGI lè forúkọ sí.
2. **Àmì dídára lórí-ayelujara** (EWMA) fún dídára àbájáde — tẹ́lẹ̀, olùṣírò náà
   máa ń fi ìbámu iṣẹ́ tó dúró ṣinṣin àti àwọn pass-rate eval àṣàyàn nìkan ṣe aṣojú “dídára”.
3. **Olùkó-jáde OTel àṣàyàn tí kò nílò dependency**, tó ń lo àwọn àṣà ìtumọ̀ GenAI.
4. **Endpoint ìṣàlàyé** tó ń dá àwọn ìpinnu ìdarí-ọ̀nà gidi + ipò dídára padà.

## 2. Àwọn Ìṣẹ̀lẹ̀ Ìdarí (ìpìlẹ̀ ìdáhùn-padà)

Àwọn fáìlì: `open-sse/services/routing/events.ts`, `.../index.ts`

`RoutingEvent` ń gbé metadata ìdarí nìkan:

```ts
interface RoutingEvent {
  requestId: string;
  provider: string;
  model: string;
  strategy: string; // "auto" | "priority" | "direct" | ...
  latencyMs: number;
  ttftMs: number | null;
  inputTokens: number | null;
  outputTokens: number | null;
  cost: number | null;
  retries: number;
  fallbackUsed: boolean;
  outcome: RoutingOutcome; // union tí ó wà nínú àkójọ ìyọ̀ǹda
  status: number | null;
  finishReason: string | null;
  connectionId: string | null;
  ts: number;
}
```

`RoutingEventSink` jẹ́ trait ara `Send+Sync` ní TypeScript:

```ts
interface RoutingEventSink {
  readonly name: string;
  record(event: RoutingEvent): void; // ó gbọ́dọ̀ jẹ́ O(1), kò gbọdọ̀ sí I/O amúṣiṣẹ́pọ̀
}
```

Ọ̀nà tí ó n ṣiṣẹ́ gidigidi ń pe `emitRoutingEvent(event)` lẹ́ẹ̀kan fún ìbéèrè kọ̀ọ̀kan tí ó parí
(callback ìparí streaming, ọ̀nà àṣeyọrí tí kì í ṣe streaming, àti ọ̀nà ìkùnà malformed-200
nínú `handleChatCore`). Pínpín jẹ́ fan-out amúṣiṣẹ́pọ̀ sí àwọn sinks tí a forúkọsílẹ̀,
ṣùgbọ́n sink kọ̀ọ̀kan kàn ń fi sínú ìlà tàbí ń ṣàfikún ipò inú memory. **Kò sí
ìkọ̀wé database amúṣiṣẹ́pọ̀, bẹ́ẹ̀ ni kò sí I/O network lórí ọ̀nà tí ó n ṣiṣẹ́ gidigidi.**

Àwọn sinks àkọ́kọ́:

- `MemoryRoutingEventStore` — ring buffer tí a fi ààlà sí (500), èyí tuntun kọ́kọ́, fún
  endpoint àlàyé.
- Oníbàárà `QualityTracker` — ń ṣàfikún ìṣírò didara EWMA.
- `OtlpHttpsEventSink` — àṣàyàn ni, a sì máa ń mú un ṣiṣẹ́ nígbà tí a bá ṣètò
  `OMNIROUTE_OTEL_ENDPOINT` (tàbí `OTEL_EXPORTER_OTLP_ENDPOINT`) nìkan.

### Ìnáwó àfikún tí a wọn (ìfiwéra òtítọ́)

`npm run bench:routing-events` lórí workstation yìí (100k ìyípo; àwọn iṣẹ́ sub-µs
ni a wọn gẹ́gẹ́ bí àpapọ̀ µs/op nítorí pé àwọn percentile iṣẹ́-kọ̀ọ̀kan wà lábẹ́
ìpele ìyàtọ̀ aago `performance.now()`):

| Ìṣẹ̀lẹ̀                             | µs/op  | ops/s  |
| --------------------------------- | ------ | ------ |
| ìpìlẹ̀ (ìṣírò score nìkan)         | ~0.045 | ~22 M  |
| ìpìlẹ̀ + RoutingEvent (2 sinks)    | ~0.168 | ~5.9 M |
| ìpìlẹ̀ + event + OTel enqueue      | ~0.163 | ~6.1 M |
| lẹ́ẹ̀kan-náà (8 interleaved bursts) | ~0.18  | —      |

Ìyàtọ̀ pínpín event lórí ìṣírò score ìpìlẹ̀ jẹ́ ~0.12 µs/request; sink OTel
kàn ń fi sínú ìlà (fífi sínú buffer O(1)), kò sì fi ohunkóhun tí a lè wọn kún un.
Àwọn nọ́mbà wọ̀nyí jẹ́ ti ẹ̀rọ yìí àti ti ìfiwéra — wọn kì í ṣe ìdánilójú fún
production. Àwòrán v1 "~0.2 µs" jẹ́ àfojúsùn àpapọ̀; ọ̀nà ìṣèwádìí yìí ya
ìṣírò score ìpìlẹ̀ sọ́tọ̀ kúrò nínú iye owó pínpín event.

## 3. Àmì Didara (ipò provider tí ìdáhùn-padà ń darí)

Àwọn fáìlì: `open-sse/services/routing/quality.ts`

v2 ya didara **ìṣiṣẹ́** sọ́tọ̀ kúrò nínú didara **ìtumọ̀**:

- **Ìṣiṣẹ́** — a ń rí i láti ọ̀nà ìdarí tí ó n ṣiṣẹ́ gidigidi (HTTP 4xx/5xx, ìkùnà
  àsopọ̀, 429s, àwọn ìdáhùn tí kò tọ́, ìdádúró stream, `finish_reason=length`,
  àwọn àṣeyọrí tí kò ní output, latency/TTFT EWMA). A KÒ ka 200 sí didara
  ìtumọ̀.
- **Ìtumọ̀** — iye gidi ti output tí a ṣe. Evaluator nìkan ló lè mú un jáde nípasẹ̀
  `setSemanticQuality()`. Ó jẹ́ `null` títí ẹnìkan yóò fi pèsè rẹ̀, kò sì ní
  wọ inú score ìṣiṣẹ́ láé.

Ipò fún (provider, model) kọ̀ọ̀kan (EWMA + àwọn counter tí a fi ààlà sí):

- `successEwma` — EWMA (α=0.2) ti àṣeyọrí àbájáde.
- `latencyEwma` / `ttftEwma` — EWMA ti latency (α=0.1).
- `samples`, `anomalies`, `rateLimited`, `semantic`, `semanticConfidence`.
- `recencyMs` — bí àkókò tí a rí model náà gbẹ̀yìn ṣe súnmọ́ tó.

### Ìgbẹ́kẹ̀lé / ìmọ̀ nípa iye sample

`confidence = clamp01(samples / 50)`, a sì ń da score tí a dá padà sí scorer pọ̀
sí ìtọ́ka àárín tí kò ṣe ojúṣàájú:

```
score = 0.5 + confidence * (operational - 0.5)
```

Àwọn àbájáde (tí àwọn test ti fìdí rẹ̀ múlẹ̀):

- Provider tuntun tí kò tíì ní data (0 samples) ní score **0.5** — a kò fi ẹ̀sùn
  àìtọ́ kàn án, ṣùgbọ́n kò lè borí provider tí ó ní ẹgbẹẹgbẹ̀rún àkíyèsí tó dára.
- Provider tí ó ní àṣeyọrí oríire 7 ni a fà sún mọ́ 0.5 (kò lè borí láti inú
  ìbẹ̀rẹ̀ onírètí).
- Provider tí ó ní samples 50+ ń sún mọ́ score ìṣiṣẹ́ gidi rẹ̀.
- Ìdínkù àti ìmúpadàbọ̀sípò ń ṣẹlẹ̀ díẹ̀díẹ̀ (EWMA), ìkùnà kan ṣoṣo tí ó yà sọ́tọ̀
  kò sì ba provider tí ó ní ìlera jẹ́.

`ProviderQuality` ń fi `{ operational, semantic, confidence, samples, anomalies,
rateLimited, successEwma, latencyEwmaMs, ttftEwmaMs, recencyMs }` hàn.

Èyí ń wọ scorer auto-combo gẹ́gẹ́ bí factor ìṣírò `quality`:

- `ScoringFactors.quality` / `ScoringWeights.quality` nínú
  `open-sse/services/autoCombo/scoring.ts`.
- `DEFAULT_WEIGHTS`: `health` 0.1905 → 0.1605, `quality` 0.03. Àpapọ̀ ṣì jẹ́ 1.0.
- `buildAutoCandidates` ń fi iye láti inú tracker sínú `candidate.quality`; àwọn
  candidates tí kò ní data máa ń lo **0.5** tí kò ṣe ojúṣàájú gẹ́gẹ́ bí àkọ́kọ́
  (candidate tuntun tí kò ní data kò gba àfikún, bẹ́ẹ̀ ni a kò jẹ ẹ́ níyà).

Ìyípo tí ó ti pa:

```
RoutingEvent → QualityTracker → getQualityScore → factor didara auto-combo
      ↑                                                    │
      └────── àbájáde ìbéèrè (handleChatCore) ←────────────┘
```

### Ìyọkúrò líle àti ìjìyà rírọ̀

Àmì didara jẹ́ **ìfẹ́ aṣàyàn rírọ̀ tí ń yí ara rẹ̀ mu** nìkan. Ìyọkúrò líle ṣì wà
lọ́wọ́ ètò resilience tó ti wà tẹ́lẹ̀: circuit breaker OPEN, quota tí ó ti tán,
ìkùnà auth, model lockout — score didara kò ní ipa lórí èyíkéyìí nínú wọn.
Provider tí score didara rẹ̀ bá lọ sílẹ̀ fún ìgbà díẹ̀ ni a máa dín ìfẹ́ sí kù,
a kì í pa á títí láé.

## 3b. Àkókò ṣiṣàn àṣepé (TTFT / ITL)

Àwọn fáìlì: `open-sse/utils/streamTiming.ts`

`createStreamTiming()` ni ojú-ọ̀nà ìṣàmúlò ohun-èlò ìwọ̀n kan ṣoṣo fún ọ̀nà ṣiṣàn,
tí a so mọ́ `createSSEStream` (open-sse/utils/stream.ts):

- `markByte()` — apá àkọ́kọ́ láti upstream tí a gbà.
- `markForward()` — apá àkọ́kọ́ tí a fi ránṣẹ́ sí client (tí a lò fún TTFT).
- `markInterrupted()` — àsìkò-parí/ìfagilé/àṣìṣe ṣiṣàn ṣáájú ìparí tó mọ́.
- `ttft()` = ìdádúró apá SSE àkọ́kọ́ tí a fi ránṣẹ́. **Èyí KÌ Í ṢE TTFT ní ìpele token** —
  apá SSE kan lè gbé token òdo/kan/ọ̀pọ̀. A ṣàkọsílẹ̀ rẹ̀ lọ́nà pípé.
- `avgItlMs()` = àárín ìyàtọ̀ àkókò láàárín àwọn apá (aṣojú ìdádúró apá fún ITL).

TTFT/ITL/interrupted ń wọ inú `RoutingEvent` (`ttftMs`, `itlMs`), a sì
ń kó wọn jáde gẹ́gẹ́ bí àwọn ànímọ́ span GenAI/OmniRoute nípasẹ̀ sink OTel.

## 4. Ìṣàkíyèsí OpenTelemetry / GenAI

Àwọn fáìlì: `open-sse/services/routing/otel.ts`

- Olùkójáde OTLP/HTTP JSON tí kò ní dependency (ó ń lo `fetch` àgbáyé, kò lo
  SDK `@opentelemetry/*`).
- Àwọn span ń tẹ̀lé àwọn àdéhùn ìtumọ̀ GenAI (`gen_ai.provider.name`,
  `gen_ai.request.model`, `gen_ai.usage.input_tokens/output_tokens`,
  `gen_ai.completion.finish_reason`, `gen_ai.system`) pẹ̀lú àwọn ànímọ́ ìdarí
  OmniRoute (àbájáde, ipò, ttft, àwọn ìgbìyànjú-àtúnṣe, fallback).
- `record()` kàn ń fi ohun sínú buffer oníwọ̀n tó lopin (O(1)); timer abẹ́lẹ̀ kan
  ń flush nípasẹ̀ `POST {endpoint}/v1/traces` láìdúró. Nígbà ìrùpọ̀ iṣẹ́,
  àwọn event tó ti pẹ́ jù ni a ń yọ kúrò (`dropped` counter) — kò gbọdọ̀ fa backpressure sí data
  plane láéláé.
- **A pa á títí tí a fi ṣètò rẹ̀.** A gbọ́dọ̀ ṣètò `OMNIROUTE_OTEL_ENDPOINT` (tàbí
  `OTEL_EXPORTER_OTLP_ENDPOINT`); bí kò bá rí bẹ́ẹ̀, a kò ní forúkọ sink náà
  sílẹ̀, kò sì sí kóòdù OTel kankan tí yóò ṣiṣẹ́.

## 5. Agbára ìṣàlàyé

- `GET /v1/explain/routing` ń dá àwọn `RoutingEvent` tuntun padà (àwọn ìpinnu
  gidi, èyí tó ṣẹ̀ṣẹ̀ dé ṣáájú) àti àwòrán-dídúró didara fún provider/model kọ̀ọ̀kan.
- Auth fara wé `/v1/combos` (kọ́kọ́rọ́ API Bearer tàbí session dashboard; aláìlórúkọ lórí
  àwọn ìfìdí-lẹ̀ ẹlẹ́lò-kan ti agbègbè pẹ̀lú `REQUIRE_API_KEY=false`).
- Àwọn trace ìpè kọ̀ọ̀kan ní ìpele combo ṣì wà nípasẹ̀
  `decisionTrace.ts` tó ti wà tẹ́lẹ̀ (header `X-OmniRoute-Combo-Trace`).
- Ààbò: àwọn event ń gbé metadata ìdarí nìkan, wọn kì í gbé prompts/bodies/credentials láéláé.

## 6. Ìṣọ̀kan pẹ̀lú evaluation-plane (Ìmúrasílẹ̀ fún Future AGI)

OmniRoute ka Future AGI (tàbí evaluator èyíkéyìí) sí **backend
ọgbọ́n/ìṣàyẹ̀wò tó ṣeé lò, kì í ṣe dependency**. Àwọn ojú-ọ̀nà náà ni:

- `RoutingEventSink` kan lè fi àwọn event ránṣẹ́ sí evaluator láìdúró.
- `MemoryRoutingEventStore` + àwòrán-dídúró didara ń fún evaluator ní ṣiṣàn
  ìpinnu aise.
- `Evaluator` ọjọ́ iwájú kan (onípinnu, adájọ́ agbègbè, HTTP, WASM) yóò gba
  àwọn event/trace, yóò sì dá `QualityScore` padà tí yóò wọ inú ọ̀nà
  `getQualityScore`/quality-factor kan náà.
- Ìdarí tí eval ń darí tó ti wà tẹ́lẹ̀ (`open-sse/services/evalRouting.ts`) ti ń
  tún àwọn ibi-àfojúsùn combo tò nípasẹ̀ àwọn ìwọ̀n àṣeyọrí `eval_runs` nígbà tí a bá mú un ṣiṣẹ́.

Kò sí ìṣàyẹ̀wò kankan tó ń ṣiṣẹ́ pẹ̀lú ìbéèrè lórí ọ̀nà ìbéèrè, gateway náà sì
ń ṣiṣẹ́ ní kíkún láìsí evaluator.

## 7. Àyẹ̀wò àkọ́lé-ẹ̀rọ ìkẹyìn

1. **Kí ló ṣì wà lórí ọ̀nà gbígbóná aláṣìkò-kan náà?** Ìdarí/ìṣírò-score, àwọn
   àyẹ̀wò guardrail ṣáájú, ìwádìí cache, àti fan-out `emitRoutingEvent` kan (~0.12 µs ju
   ìṣírò-score ìpilẹ̀ lọ) sí àwọn sink inú-memory.
2. **Kí ni a gbé lọ sí ìṣètò láìdúró?** Ìkójáde OTel (timer + fetch),
   ìtọ́jú `call_logs`/usage, àwọn ìkọ̀wé semantic-cache; didara wà nínú memory,
   ó sì jẹ́ O(1) (kò nílò async).
3. **Báwo ni àbájáde ìdarí ṣe di esi?** `handleChatCore` ń dá
   `RoutingEvent` jáde → `QualityTracker` ń ṣe ìmúdójúìwọ̀n ipò EWMA → `getQualityScore`
   ń pèsè factor `quality` fún auto-combo.
4. **Báwo ni didara ṣe ń ní ipa lórí ìdarí ọjọ́ iwájú?** Score didara kékeré ń dín
   score oníwọ̀n provider/model náà kù nínú `scoreAutoTargets`, nítorí náà
   díẹ̀díẹ̀ ni a kò fi àwọn model tó ti bàjẹ́ síwájú mọ́, wọn a sì tún bọ̀ sípò bí EWMA wọn ṣe ń dára sí i.
5. **Báwo ni Future AGI ṣe lè ṣọ̀kan láìdi dependency?** Nípasẹ̀
   interface `RoutingEventSink` / adapter `Evaluator` ọjọ́ iwájú — kò sí
   dependency tí a kọ sínú kóòdù tààrà.
6. **Kí ló ṣẹlẹ̀ nígbà tí evaluator kò bá sí?** Kò ní ipa lórí ìdarí;
   didara yóò lo iye àárín (1.0) fún àwọn model tí kò ní àmì kankan tí a ti rí.
7. **Kí ló ṣẹlẹ̀ nígbà tí telemetry kò bá sí?** A kì í kàn forúkọ sink OTel
   sílẹ̀; ìyókù routing layer yóò máa ṣiṣẹ́ láìyípadà.
8. **Kí ló ṣẹlẹ̀ nígbà ìrùpọ̀ iṣẹ́?** Buffer OTel yóò yọ àwọn event tó ti pẹ́ jù kúrò; a
   fi ààlà lé didara àti ring buffer nípa ìkọ́lé; kò sí backpressure.
9. **Báwo ni ipò provider ṣe ń bọ̀ sípò lẹ́yìn ìbàjẹ́?** EWMA ń tún sún mọ́ ìwọ̀ntúnwọ̀nsì bí
   àwọn àṣeyọrí ṣe ń pọ̀ sí i; warmup ń jẹ́ kí àwọn model tuntun wà ní iye àárín; circuit breaker
   sì ń bọ̀ sípò lọ́tọ̀ nípasẹ̀ àwọn probe HALF_OPEN.
10. **Àwọn ẹya wo ni a dábàá tí a mọ̀ọ́mọ̀ KÒ ṣe, kí sì ni ìdí?**
    - Shadow traffic / àwọn ìdánwò — a ti ṣe é tẹ́lẹ̀
      (`combo/shadowRouting.ts`); a kò tún un kọ́.
    - Guardrails — a ti ṣe wọ́n tẹ́lẹ̀ (`src/lib/guardrails/`); a kò ṣe ẹ̀dà wọn.
    - Semantic cache — a ti ṣe é tẹ́lẹ̀ (`src/lib/semanticCache.ts`); a kò
      ṣe ẹ̀dà rẹ̀.
    - Platform ìṣàkóso ìdánwò pípé, ohun-èlò dataset, platform ìmúdára prompt,
      vector DB, tàbí amáyédẹrùn OTel òde tó jẹ́ dandan — wọ́n kọjá
      ààlà data plane kékeré tó fẹ́rẹ̀ẹ́.
    - Struct `RoutingEvent` Rust kan — data plane náà jẹ́ TypeScript; type TS
      ni ìbádọ́gba tí a mú bá a mu.
