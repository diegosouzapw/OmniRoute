```
...
```

## Abala Àwọn Ìnáwó (tuntun, ipele 1)

Àkọ́kọ́ ọ̀nà: `/dashboard/costs/`

| Ohun         | URL                                  | Àpèjúwe                                      |
| ------------ | ------------------------------------ | -------------------------------------------- |
| Àkótán       | `/dashboard/costs`                   | Dashboard àpapọ̀ ìnáwó (a gbé e láti Ìtúpalẹ̀) |
| Ìdíyelé      | `/dashboard/costs/pricing`           | Tábìlì ìdíyelé fún model kọ̀ọ̀kan              |
| Ìṣúná        | `/dashboard/costs/budget`            | Àwọn ààlà ìṣúná + àwọn ìkìlọ̀                 |
| Pínpín Quota | `/dashboard/costs/quota-share`       | Àwọn pool Quota Share + ìlò                  |
| Ààtò Plan    | `/dashboard/costs/quota-share/plans` | Àwọn ìyípadà àkóso plan fún olùpèsè kọ̀ọ̀kan   |

**Ìdí**: Ìdíyelé, Ìṣúná, àti Pínpín Quota wà tẹ́lẹ̀ lábẹ́
`Àbójútó > Àwọn Pàràmítà Ìnáwó`. Gbigbé wọn lọ sí abala ipele-ókè tí a yà sọ́tọ̀
mú kí ó rọrùn láti rí wọn láìlọ kiri nínú àwọn irinṣẹ́ ìṣàkíyèsí.

## Abala Àbójútó (tún ṣètò)

Abala Àbójútó ní **Ìṣe ní òkè** báyìí, tí **àwọn ẹgbẹ́ kékeré 3** sì tẹ̀ lé e:

```
Àbójútó
├── Ìṣe                  ← Feed ìlà-àkókò (ohun ipele-ókè)
├── Ẹgbẹ́ Àkọsílẹ̀
│   ├── Àwọn Àkọsílẹ̀ (gbogbo rẹ̀)
│   ├── Àwọn Àkọsílẹ̀ Proxy
│   └── Àwọn Àkọsílẹ̀ Console
├── Ẹgbẹ́ Àyẹ̀wò
│   ├── Àkọsílẹ̀ Àyẹ̀wò
│   ├── Àyẹ̀wò MCP
│   └── Àyẹ̀wò A2A
└── Ẹgbẹ́ System
    ├── Ìlera
    └── Runtime
```

### Ohun tí ó yí padà láti inú ètò àtijọ́

| Tẹ́lẹ̀                                                                                         | Lẹ́yìn                                           |
| -------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| Ìṣe = tab inú Àwọn Àkọsílẹ̀ tó ń ṣàfihàn Àkọsílẹ̀ Àyẹ̀wò                                        | Ìṣe = feed tí a yà sọ́tọ̀ (`/dashboard/activity`) |
| Ẹgbẹ́ Àwọn Pàràmítà Ìnáwó nínú Àbójútó                                                        | A gbé e lọ sí abala Àwọn Ìnáwó                  |
| Àtòjọ pẹlẹbẹ: Àwọn Àkọsílẹ̀, Ìṣe (àwọn àkọsílẹ̀), Àyẹ̀wò, Ìlera, Runtime, Ìdíyelé, Ìṣúná, Quota | Ètò ẹgbẹ́ mẹ́ta + abala Àwọn Ìnáwó tí a yà sọ́tọ̀   |

## Ìṣe àti Àkọsílẹ̀ Àyẹ̀wò

Àwọn méjèèjì yìí yàtọ̀ báyìí:

| Ìwọ̀n                       | Ìṣe (`/dashboard/activity`)                                                 | Àkọsílẹ̀ Àyẹ̀wò (`/dashboard/audit`)        |
| -------------------------- | --------------------------------------------------------------------------- | ----------------------------------------- |
| **Ète**                    | Feed ìṣẹ̀lẹ̀ fún olùlò ("kí ló ṣẹlẹ̀ láìpẹ́")                                   | Àkọsílẹ̀ ìbámu / ààbò                      |
| **Orísun dátà**            | `GET /api/compliance/audit-log?level=high`                                  | `GET /api/compliance/audit-log?level=all` |
| **Ọ̀nà ìgbékalẹ̀**           | Ìlà-àkókò, tí a pín nípa ọjọ́, àwọn ọ̀rọ̀-ìṣe tó ṣeé kà fún ènìyàn + àwọn aami | Tábìlì pípẹ́ tó ní ojú-ewé, 50/ojú-ewé     |
| **Àwọn àsẹ̀**               | Ẹ̀ka irú ìṣẹ̀lẹ̀                                                               | Ìṣe, bí ó ṣe le tó, olùṣe, àárín ọjọ́      |
| **Ìkójáde**                | Kò sí                                                                       | Ìkójáde JSON                              |
| **Àlẹ̀mọ́ olùṣe**            | Kò kan sí i                                                                 | Ó ṣeé ṣe àlẹ̀mọ́ nípa olùṣe                 |
| **Àwọn ìṣẹ̀lẹ̀ tí a fi hàn** | Àwọn ìṣe ipele-gíga nìkan (allowlist)                                       | Gbogbo àwọn ìṣẹ̀lẹ̀ àyẹ̀wò                   |

### Allowlist Àwọn Ìṣe Ipele-Gíga

A ṣàlàyé rẹ̀ nínú `src/lib/audit/highLevelActions.ts`. Ó ń ṣàkóso àwọn ìṣẹ̀lẹ̀ tí yóò fara hàn nínú
feed Ìṣe. Allowlist náà ní:

- Àwọn ìṣẹ̀lẹ̀ fífi olùpèsè kún/un kúrò/dán an wò
- Ṣíṣẹ̀dá/ìmúdójúìwọ̀n/píparẹ́ àkójọpọ̀
- Ìgbésí-ayé kọ́kọ́rọ́ API (ṣẹ̀dá, fagilé, yípo)
- Dídé ààlà ìṣúná
- Wíwọlé/jíjáde ìfàṣẹsí
- Ṣíṣẹ̀dá session cloud agent
- Ìforúkọsílẹ̀ irinṣẹ́ MCP
- Ṣíṣẹ̀dá/píparẹ́ webhook
- Àwọn ìyípadà pool/plan Quota (`quota.*` actions, Group B)
- Àwọn ìṣẹ̀lẹ̀ platform (ìmúdójúìwọ̀n, deploy)
- Fífì skill sori ẹrọ/yíyọ kúrò

Àwọn ìṣẹ̀lẹ̀ tí kò sí nínú àtòjọ yìí yóò fara hàn nínú Àkọsílẹ̀ Àyẹ̀wò nìkan.

### Fífi ìṣe ipele-gíga tuntun kún un

Ṣàtúnṣe `src/lib/audit/highLevelActions.ts`, kí o sì fi ọ̀rọ̀ ìṣe náà kún
`HIGH_LEVEL_ACTIONS`. Èyí nílò PR (àtòjọ náà jẹ́ code, kì í ṣe ohun tí a lè ṣètò nínú DB).
A lè fi aami tó bá a mu kún `src/lib/audit/activityIcons.ts`.

## Ìdarípadà: `/dashboard/logs/activity`

A ń darí ọ̀nà àtijọ́ `/dashboard/logs/activity` padà títí láé (HTTP 308) sí
`/dashboard/activity` nípasẹ̀ `permanentRedirect()` nínú
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

A pa ID pẹpẹ ẹ̀gbẹ́ àtijọ́ `logs-activity` mọ́ nínú `HIDEABLE_SIDEBAR_ITEM_IDS`
(ṣùgbọ́n a yọ ọ́ kúrò nínú `SIDEBAR_DEFINITIONS`) láti má bà á jẹ́ fún àwọn preset olùlò tí
ń tọ́ka sí ID àtijọ́ náà.
