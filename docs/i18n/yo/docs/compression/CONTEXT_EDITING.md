**Ṣíṣàtúnṣe Àyíká** tí a fi lé lọ́wọ́ jẹ́ ẹ̀ya ìṣàkóso àyíká tí ó wà fún Claude nìkan. Yàtọ̀ sí àwọn ẹ̀rọ ìkójọpọ̀ agbègbè ti OmniRoute (Caveman, RTK, LLMLingua, stacked pipelines) — tí ń tún ara ìbéèrè kọ _ṣáájú_ kí ó tó kúrò nínú proxy — Ṣíṣàtúnṣe Àyíká máa ń ní kí **olùpèsè** pa àwọn ìdípọ̀ tool-use / tool-result tí kò ṣe pàtàkì mọ́ kúrò nínú fèrèsé àyíká tí ó ń lò lọ́wọ́. OmniRoute kàn so paramita ara kan (`context_management.edits[]`) mọ́ ọn; Claude ló ń ṣe ìparẹ́ gangan ní ìbámu pẹ̀lú tokenizer tirẹ̀.

Nípa ìṣẹ̀dá rẹ̀, agbára tí a fi lé lọ́wọ́ ni èyí: àwọn olùpèsè mìíràn máa ń kọ paramita náà, nítorí náà OmniRoute fi ààlà rẹ̀ mọ́ Claude àti àwọn relay tí ó bá Claude-Code mu nìkan.

Orísun òtítọ́: `open-sse/config/contextEditing.ts` (àwọn id ọ̀nà ìlànà, fífi sínú ara, àti yíyọ telemetry jáde), `open-sse/executors/base.ts` (ẹnubodè fífi sínú ara + ìpadà-ẹ̀yìn 400), àti `open-sse/services/compression/types.ts` (ìrísí àtòjọ ìṣètò + àìròtẹ́lẹ̀).

## Ohun tí `clear_tool_uses` ń ṣe

OmniRoute máa ń fi àtúnṣe kan ṣoṣo sínú ara Anthropic Messages tí a ń rán jáde:

```json
{
  "context_management": {
    "edits": [
      {
        "type": "clear_tool_uses_20250919",
        "trigger": { "type": "input_tokens", "value": 100000 },
        "keep": { "type": "tool_uses", "value": 3 }
      }
    ]
  }
}
```

- `type: "clear_tool_uses_20250919"` — id ọ̀nà ìlànà Anthropic tí a fi ọjọ́ sí (`CLEAR_TOOL_USES_STRATEGY`).
- `trigger.value: 100000` — nígbà tí àwọn token àbáwọlé ìbéèrè bá kọjá ààlà yìí, Claude máa bẹ̀rẹ̀ sí í pa àwọn ìdípọ̀ tool-use/result àtijọ́ rẹ́ (`CONTEXT_EDITING_DEFAULT_TRIGGER_TOKENS`, àìròtẹ́lẹ̀ Anthropic).
- `keep.value: 3` — àwọn ìdípọ̀ tool-use/result N tó ṣẹ̀ṣẹ̀ wá jù ni a ó fi sílẹ̀ láìfọwọ́kàn wọ́n (`CONTEXT_EDITING_DEFAULT_KEEP_TOOL_USES`).

A máa ń polówó beta náà nípasẹ̀ header `anthropic-beta: context-management-2025-06-27`, èyí tí OmniRoute ti ń rán jáde tẹ́lẹ̀ lórí àwọn ìbéèrè Claude.

`applyContextEditingToBody()` ló ń ṣe fífi sínú ara, ó sì jẹ́ **idempotent**: bí àtúnṣe `clear_tool_uses` bá ti wà nínú ara tẹ́lẹ̀ (tí ìpè ṣáájú fi kún un tàbí tí client pèsè), ara náà kò ní yí padà. Bí àtúnṣe `clear_thinking_20251015` bá tún wà, OmniRoute máa ń ṣe stable-sort fún àtúnṣe `clear_thinking` sí iwájú, nítorí Anthropic béèrè pé kí `clear_thinking` ṣáájú `clear_tool_uses` nínú array `edits[]`.

## Toggle ìmúlò fún àkójọpọ̀ kọ̀ọ̀kan

Ṣíṣàtúnṣe Àyíká jẹ́ **pípà ní àìròtẹ́lẹ̀**, ó sì nílò kí a yàn láti mú un ṣiṣẹ́. Toggle náà jẹ́ boolean kan ṣoṣo tí ó wà nínú àtòjọ ìṣètò ìkójọpọ̀:

- Kọ́kọ́rọ́ àtòjọ ìṣètò: `contextEditing.enabled` (camelCase — **kì í ṣe** `context_editing` / `context-editing`).
- Irú: `ContextEditingConfig { enabled: boolean }` nínú
  `open-sse/services/compression/types.ts`.
- Àìròtẹ́lẹ̀: `DEFAULT_CONTEXT_EDITING_CONFIG = { enabled: false }`.
- Schema Zod: `contextEditingConfigSchema` nínú `src/shared/validation/compressionConfigSchemas.ts`.
- Ìtọ́jú: a tọ́jú rẹ̀ pẹ̀lú ìyókù àwọn àtòjọ ìṣètò ìkójọpọ̀ (tí a ṣe normalize rẹ̀ nínú
  `src/lib/db/compression.ts`).

Nínú dashboard, toggle náà wà nínú ibùdó ìkójọpọ̀
(`src/app/(dashboard)/dashboard/context/combos/CompressionHub.tsx`), ó sì ń kọ
`{ contextEditing: { enabled: … } }` padà nípasẹ̀ `saveSettings()`. Nítorí pé ó ń rin lórí object àtòjọ-ìṣètò ìkójọpọ̀, ó ń ṣiṣẹ́ pọ̀ mọ́ profile ìkójọpọ̀ fún àkójọpọ̀ kọ̀ọ̀kan dípò kí ó jẹ́ ojú-iṣẹ́ òmìnira pátápátá — àtòjọ ìṣètò náà ní àmì títàn/pípà nìkan; gbogbo àwọn ààlà (`trigger`, `keep`) ni àwọn constant tí a ṣàkọsílẹ̀ lókè.

## Ìdènà fún Claude nìkan

Ìfisíṣẹ̀ máa ń ṣẹlẹ̀ fún Claude ojúlówó tàbí àwọn relay tó bá Claude-Code mu nìkan. Ìdènà inú
`open-sse/executors/base.ts` ni:

```ts
if (
  (this.provider === "claude" || isClaudeCodeCompatible(this.provider)) &&
  contextEditing?.enabled &&
  !contextEditingDisabled
) {
  applyContextEditingToBody(transformedBody, { enabled: true });
}
```

- `this.provider === "claude"` — kọ́kọ́rọ́ Anthropic/OAuth ojúlówó.
- `isClaudeCodeCompatible(this.provider)` — àwọn relay tí provider id wọn bẹ̀rẹ̀ pẹ̀lú àkọ́kọ́ ọ̀rọ̀
  `anthropic-compatible-cc-` (wọ́n polówó ìbámu pẹ̀lú Claude Code, nítorí náà wọ́n ni àwọn relay
  tó ṣeé ṣe jù lọ láti gba beta náà). Wo `open-sse/services/provider.ts`.

Àwọn tí a **yọ kúrò** pẹ̀lú èrò:

- `claude-web` — relay aṣàwákiri kan tó ní ìrísí ìbéèrè `create_conversation_params` tí kò rí
  `context_management` láé.
- Àwọn relay `anthropic-compatible-*` gbogbogbòò (láìsí àkọ́kọ́ ọ̀rọ̀ `-cc-`) — àwọn endpoint ẹnikẹta tí
  ìtìlẹ́yìn beta wọn kò dájú.

Àwọn provider tí kì í ṣe Claude kò gba paramita `context_management` láé, kódà nígbà tí toggle bá wà ní títàn.

## Ìpadà-àfẹ́yinti 400 / àgbègbè tí relay bo

Relay tó bá Claude mu lè polówó beta náà ṣùgbọ́n kó ṣì kọ paramita `context_management`
pẹ̀lú HTTP 400. Láti dín iṣẹ́ kù lọ́nà tó rọrùn dípò kí ìbéèrè náà kùnà, executor náà yọ
paramita náà kúrò, ó sì tún URL kan náà gbìyànjú **lẹ́ẹ̀kan**:

```ts
if (
  response.status === HTTP_STATUS.BAD_REQUEST &&
  contextEditing?.enabled &&
  !contextEditingDisabled &&
  transformedBody?.context_management !== undefined
) {
  const errText = await response
    .clone()
    .text()
    .catch(() => "");
  if (/context[_-]management|context editing/i.test(errText)) {
    contextEditingDisabled = true;
    delete transformedBody.context_management;
    let retryBody = JSON.stringify(transformedBody);
    if (isClaudeCodeCompatible(this.provider) || this.provider === "claude") {
      retryBody = await signRequestBody(retryBody);
    }
    response = await fetch(url, { ...fetchOptions, body: retryBody });
  }
}
```

Ìhùwàsí:

1. Ó máa ń ṣiṣẹ́ lórí `400` nìkan nígbà tí context editing bá ṣiṣẹ́, tí body náà sì ní
   `context_management` ní ti gidi.
2. A máa ka body 400 náà nípasẹ̀ `clone()` kí response ìpilẹ̀ṣẹ̀ lè wà bó ṣe rí fún ipa ọ̀nà tí kò bá
   bá àpẹẹrẹ mu.
3. Ọ̀rọ̀ àṣìṣe náà gbọ́dọ̀ bá `/context[_-]management|context editing/i` mu — 400 tí kò ní í ṣe pẹ̀lú rẹ̀ (fún àpẹẹrẹ
   `max_tokens must be >= 1`) **kò** ní mú ìpadà-àfẹ́yinti náà ṣiṣẹ́; àṣìṣe ìpilẹ̀ṣẹ̀ náà yóò tẹ̀síwájú.
4. Nígbà tí ó bá rí ìbámu, ó ṣètò `contextEditingDisabled = true` (èyí tó máa dènà àtún-fisíṣẹ̀ bí a bá
   tún kọ `transformedBody` tuntun lẹ́yìn náà fún URL ìtúngbìyànjú/ìpadà-àfẹ́yinti), ó pa `context_management` rẹ́,
   ó tún fọwọ́ sí body náà fún Claude / àwọn relay tó bá Claude-Code mu (`signRequestBody`), ó sì tún
   URL kan náà gbìyànjú lẹ́ẹ̀kan.

Claude ojúlówó máa ń gbé beta náà sínú `ANTHROPIC_BETA_BASE`, kò sì wọ ipa ọ̀nà ìpadà-àfẹ́yinti yìí.

## Telemetry `applied_edits`

Lẹ́yìn response Claude kan, OmniRoute máa ń ṣàkọsílẹ̀ iye context tí provider náà pa rẹ́ ní ti gidi. Èyí
**kì í ṣe** ohun tí a ń stream — a máa yọ ọ́ jáde láti inú body response tí kì í ṣe streaming, gẹ́gẹ́ bí ìsapá tó dára jù lọ, kò sì
ní ipa lórí response láé (a máa gbójú fo àwọn ìkùnà telemetry).

- Ìyọjáde: `extractContextEditingTelemetry(responseBody)` nínú `open-sse/config/contextEditing.ts`.
  Ó máa ń wá `applied_edits` ní ibi mẹ́ta (gẹ́gẹ́ bí ààbò lórí ìrísí response):
  - `context_management.applied_edits`
  - `usage.context_management.applied_edits`
  - `usage.applied_edits`
- Àwọn field fún edit kọ̀ọ̀kan tí a máa ń kà láti inú entry kọ̀ọ̀kan: `cleared_input_tokens` àti `cleared_tool_uses`
  (snake_case, ti Anthropic ní ìbẹ̀rẹ̀), pẹ̀lú àwọn ìpadà-àfẹ́yinti camelCase `clearedInputTokens` / `clearedToolUses`.
- Ó máa dá `null` padà nígbà tí a kò bá rí array `applied_edits` tàbí tí kò bá sí ohun kankan tí a pa rẹ́ ní ti gidi.

Ìrísí receipt náà ni `ContextEditingTelemetry { editCount, clearedInputTokens, clearedToolUses }`.
Ìkọsílẹ̀ máa ń ṣẹlẹ̀ nínú `open-sse/handlers/chatCore.ts` (tí a fi `provider === "claude"` ṣe ìdènà)
nípasẹ̀ `recordContextEditingTelemetry()` (`src/lib/db/compressionAnalytics.ts`), èyí tó máa kọ row analytics compression
tó ní àwọn tag wọ̀nyí:

- `mode: "context-editing"`
- `engine: "context-editing"`
- `tokens_saved` / `original_tokens` = iye input-token tí a pa rẹ́
- `request_id` tí a fi `::context-editing` kún ní ìparí

Nítorí náà, pípaarẹ́ tí a fi lé provider lọ́wọ́ máa ń hàn nínú analytics compression lẹ́gbẹ̀ẹ́ àwọn engine agbègbè, lábẹ́
àkọlé engine `context-editing`, a sì lè yà á sọ́tọ̀ kúrò lára ìfipamọ́ RTK/Caveman/LLMLingua.

## Ìbáṣepọ̀ pẹ̀lú àwọn ẹ̀rọ ìfúnpọ̀ agbègbè

| Abala               | Àwọn ẹ̀rọ agbègbè (Caveman / RTK / LLMLingua / stacked) | Ṣíṣe Àtúnṣe Àyíká Ọ̀rọ̀ Nípasẹ̀ Ìfọ̀rọ̀ránṣẹ́          |
| ------------------- | ------------------------------------------------------ | ------------------------------------------------ |
| Ibi tí ó ti ń ṣiṣẹ́  | Nínú OmniRoute, kí ìbéèrè tó jáde kúrò nínú proxy      | Nínú provider (Claude), ní ẹ̀gbẹ́ server           |
| Ohun tí ó ń ṣàtúnṣe | Prompt / context / ọ̀rọ̀ àbájáde tool                    | Àwọn block tool-use / tool-result àtijọ́          |
| Iwọn provider       | Gbogbo àwọn provider                                   | `claude` + `anthropic-compatible-cc-*` nìkan     |
| Yíyàn ìṣiṣẹ́         | Àwọn ètò mode ìfúnpọ̀                                   | `contextEditing.enabled`                         |
| Ìlànà ìkùnà         | Fail-open (ọ̀rọ̀ ìpilẹ̀ṣẹ̀)                                | 400-fallback: yọ param kúrò, tún gbìyànjú lẹ́ẹ̀kan |
| Telemetry ìfipamọ́   | `engine: <engine id>`                                  | `engine: "context-editing"`                      |

Àwọn méjèèjì ń ṣiṣẹ́ pọ̀ láti ṣàfikún ara wọn: àwọn ẹ̀rọ agbègbè ń fún àwọn byte tí OmniRoute ń fi ránṣẹ́ pọ̀; Ṣíṣe Àtúnṣe Àyíká Ọ̀rọ̀ sì ń jẹ́ kí
Claude gé àyíká ọ̀rọ̀ tó ń lọ lọ́wọ́ kù láàárín àwọn turn. A lè mú àwọn méjèèjì ṣiṣẹ́ papọ̀.
