Ìfúnpọ̀ Caveman lè ṣàkójọpọ̀ àwọn àkójọpọ̀ òfin tó jẹ́ ti èdè pàtó ní àfikún sí àwọn òfin Gẹ̀ẹ́sì tí a fi sínú rẹ̀ tẹ́lẹ̀.
Èyí ń jẹ́ kí ẹ́ńjìnnì pàtàkì dúró ṣinṣin, nígbà tó ń jẹ́ kí àwọn àkójọpọ̀ òfin Pọ́túgí, Sípáníìṣì, Jámánì, Faransé, Ítálì, Japaníìṣì, àti
àwọn èdè ọjọ́ iwájú lè dàgbà lọ́tọ̀ọ̀tọ̀.

## Ibi

Àwọn àkójọpọ̀ èdè wà lábẹ́:

```txt
open-sse/services/compression/rules/<language>/
```

Àwọn àkójọpọ̀ tí a ń pèsè lọ́wọ́lọ́wọ́ (tí a ti ṣàyẹ̀wò pẹ̀lú àwọn àkóónú ìtọ́sọ́nà `rules/`):

| Èdè               | Ìtọ́sọ́nà        | Àwọn ẹ̀ka òfin tó wà                                 |
| ----------------- | -------------- | --------------------------------------------------- |
| Gẹ̀ẹ́sì             | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Sípáníìṣì         | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Pọ́túgí (Bàràsílè) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonéṣíà         | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Ítálì             | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Jámánì            | `rules/de/`    | `context`, `filler`, `structural`                   |
| Faransé           | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japaníìṣì         | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Àkíyèsí ìbámu:** Àwọn àkójọpọ̀ `en`, `es`, `pt-BR`, `id`, àti `it` ní gbogbo ẹ̀ka márùn-ún; `de`, `fr`, `ja` ní ẹ̀ka mẹ́ta. Àwọn ẹ̀ka `dedup` àti `ultra` tí kò sí máa ń padà sí lílo àwọn òfin Gẹ̀ẹ́sì tí a fi sínú rẹ̀ tẹ́lẹ̀ láìfi ìkìlọ̀ hàn. A gba àwọn àfikún láti ṣàfikún `dedup.json` àti `ultra.json` fún àwọn àkójọpọ̀ kéékèèké náà.
>
> Àkójọpọ̀ `pt-BR` dá lórí **[Troglodita](https://github.com/leninejunior/troglodita)** láti ọwọ́ Lenine Júnior — ètò ìfúnpọ̀ tí a ṣe láti ìbẹ̀rẹ̀ pátápátá fún gírámà Pọ́túgí Bàràsílè (dídín àsọtúnsọ kù, yíyọ àwọn ọ̀rọ̀ àfikún PT-BR kúrò, àwọn àkékúrú ìmọ̀-ẹ̀rọ fún àwùjọ àwọn olùgbéejáde BR).
>
> Àtòjọ ẹ̀ka àṣẹ àti àwòrán ètò fún ẹ̀ka kọ̀ọ̀kan wà nínú [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12).

## Ìṣàwárí Èdè

`languageDetector.ts` ń lo àwọn ọ̀nà ìfojúrí tó fẹ́ẹ́rẹ́ láti mọ èdè láti inú ọ̀rọ̀ ìbéèrè. Èdè àìyípadà
tí a ṣètò ṣì jẹ́ èyí tí a bọ̀wọ̀ fún, a sì lè pa ìṣàwárí nípasẹ̀ àgbékalẹ̀ nígbà tí a bá nílò ìṣàkóso
pípé.

Àbájáde ìṣàwárí ni a ń lò láti yan àwọn àkójọpọ̀ òfin nìkan. Kò yí ìdarí olùpèsè, yíyan locale,
tàbí èdè UI padà.

## Ìrísí Àgbékalẹ̀

Àwọn àgbékalẹ̀ ìfúnpọ̀ lè ní:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` ń ṣàkóso àwọn àìyípadà dasibodu/àwòtẹ́lẹ̀. `cavemanConfig` ni àgbékalẹ̀ ẹ́ńjìnnì àsìkò-ṣiṣe
tí a ń lò nígbà tí Caveman bá ń fún ọ̀rọ̀ ìfiránṣẹ́ pọ̀.

## Fí Àkójọpọ̀ Èdè Kún Un

1. Ṣẹ̀dá `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Lo ìlànà àgbékalẹ̀ Caveman láti inú `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Jẹ́ kí àwọn ìrọ́pò jẹ́ ti ìṣọ́ra, kí o sì yẹra fún yíyí kóòdù, àwọn atọ́ka, URL, tàbí JSON padà.
4. Ṣàfikún tàbí ṣe àfikún sí àwọn ìdánwò fún yíyan èdè àti ìhùwàsí ìrọ́pò.
5. Ṣàfihàn àwọn àkọlé dashboard/i18n tuntun bí èdè náà bá farahàn nínú àwọn olùyan UI.

## API

A lè ṣèwádìí àwọn àkójọpọ̀ tó wà pẹ̀lú:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Endpoint àkọ́wò gba àwọn àtúnṣe sí àtòpọ̀ èdè:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Gbogbo àkójọpọ̀ èdè mẹ́fà gba abala `SHARED_BOUNDARIES` kan nínú v3.8.0, èyí tí a ń lò ní gbogbo
ìpele Caveman (LITE, FULL, ULTRA). Ó ń pàṣẹ fún ẹ́ńjìnnì náà láti pa àwọn àpẹẹrẹ wọ̀nyí mọ́ gẹ́gẹ́ bí wọ́n ṣe rí,
láìka yíyọ ọ̀rọ̀ àfikún tó yí wọn ká sí:

| Irú àpẹẹrẹ                     | Àpẹẹrẹ                                 |
| ------------------------------ | -------------------------------------- |
| Àwọn búlọ́ọ̀kù kóòdù olódi       | ` ```python\n...\n``` `                |
| Kóòdù inú ìlà                  | `` `my_var` ``                         |
| Àwọn URL                       | `https://example.com/path`             |
| Àwọn ipa fáìlì (pípé + ìbátan) | `/etc/hosts`, `./src/index.ts`         |
| Àwọn àkọlé àṣìṣe               | `Error:`, `TypeError:`, `SyntaxError:` |
| Àwọn ìlà àtẹ̀lé stack           | `  at functionName (file.ts:12:3)`     |

A ti ṣàfikún àwọn àpẹẹrẹ wọ̀nyí sínú `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (tó jẹ́ `[]` tẹ́lẹ̀). Àìyípadà
náà wà nínú `open-sse/services/compression/types.ts`.

### Ìdí tí èyí fi ṣe pàtàkì

Láìsí SHARED_BOUNDARIES, àwọn mode Caveman tó le koko lè yọ àkóónú tó dà bí
ọ̀rọ̀ àsọtúnsọ kúrò, nígbà tó jẹ́ pé àpẹẹrẹ kóòdù, ipa fáìlì, tàbí àtẹ̀lé stack àṣìṣe ni. SHARED_BOUNDARIES ń ṣiṣẹ́ gẹ́gẹ́ bí
ààbò tí kò sinmi lé èdè kankan, tí a ń lò ṣáájú kí àwọn ìlànà yíyọ ọ̀rọ̀ àfikún tó bẹ̀rẹ̀ sí í ṣiṣẹ́.

### Ṣíṣe preservePatterns ní àdáni

A lè ṣàfikún àwọn àpẹẹrẹ mìíràn ní àkókò ìṣiṣẹ́ nípasẹ̀ àwọn ààtò ìfúnpọ̀:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Àwọn àpẹẹrẹ àdáni máa ń fa àwọn àìpé mẹ́fà náà gùn (wọn kì í rọ́pò wọn).

## Àwọn Àkíyèsí Ìṣiṣẹ́

- Àwọn ìlànà English tí a kọ sínú rẹ̀ máa ń jẹ́ àṣàyàn ìpadàbọ̀ nígbà tí àkójọpọ̀ èdè kan kò bá sí.
- Àwọn àkójọpọ̀ JSON tí a kọ sínú rẹ̀ tí kò bófin mu máa ń kuna ìfọwọ́sí, kí àwọn ohun ìtújáde má bàa dín kù ní ìdákẹ́jẹ́.
- Àwọn àkójọpọ̀ ìlànà jẹ́ dátà nìkan, wọn kò sì gbọdọ̀ ṣàgbéwọlé kóòdù tàbí ṣiṣẹ́ lójúmọ́ ìrònú àìlákóso.
- Ìpele àtúpalẹ̀ ìfúnpọ̀ ń ṣàkọsílẹ̀ mode àti ẹ́ńjìnnì tí a yàn, kì í ṣe gbogbo ọ̀rọ̀ prompt.
