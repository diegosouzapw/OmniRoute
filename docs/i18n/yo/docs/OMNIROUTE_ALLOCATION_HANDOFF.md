Ìpín kì í ṣe ìwọ̀n lílò olùpèsè.

Àwọn àkójọpọ̀ ìwọ̀n lílò ń ṣàlàyé àwọn kọ́kọ́rọ́ API tí ó lè lo àkójọpọ̀ olùpèsè àti bí àwọn ìlànà líle, rírọ̀, tàbí lílò àṣekúdóró ṣe kan wọn. Ìwọ̀n lílò olùpèsè jẹ́ agbára ìta tí olùpèsè kan ròyìn tàbí tí orísun kan tí a ṣètò ní kedere pèsè. Àwọn ìnáwó Ghostlight inú jẹ́ àwọn ààlà ìṣàkóso tí alábòójútó ṣàlàyé.

Iṣẹ́ `ensurePool` jẹ́ idempotent: àkójọpọ̀ tí ó jẹ́ ọ̀kan náà pátápátá kò ní yí padà, ìpín tí ó yí padà ni a ó ṣe ìmúdójúìwọ̀n rẹ̀, a ó sì ṣẹ̀dá àkójọpọ̀ tí kò sí. Èyí jẹ́ fún adaṣiṣẹ́ àti àwọn olùpè API tí a fi ààlà sí.

Ojú-ọ̀nà ìpò tí ó jẹ́ ti kíkà nìkan ni `GET /api/omniroute/status`. Àṣẹ ìjẹ́rìísí ni `npm run omniroute:verify`; kò ṣe ìbéèrè awoṣe aláràyè kankan.
