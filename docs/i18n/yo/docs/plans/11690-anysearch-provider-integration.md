## 1. Òtítọ́ ìpìlẹ̀ iṣẹ́ náà (àwọn ìwé àṣẹ ìṣiṣẹ́, tí a tún ṣàyẹ̀wò)

- URL ìpìlẹ̀: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - àwọn paramita: `query` (dandan), `max_results` (1-10, àìyípadà 10), `tag` (`{domain}.{sub_domain}` fún ìdarí inárọ̀), `zone` (cn/intl), `language`, `params` (àwọn pápá inárọ̀ tí a ṣètò), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - àkójọ agbára, kò kà sí ìlò quota.
- `POST /v1/extract` - gba/yọ `{url, title, content}` jáde; body JSON tó muna, ààlà 16 KiB.
- `POST /v1/auth/email/register` - ìforúkọsílẹ̀ pẹ̀lú ìpè ẹyọ kan, ó dá kọ́kọ́rọ́ plaintext ìgbà-kan `as_sk_...` padà.
- Ìfàṣẹsí: `Authorization: Bearer <as_sk_...>` jẹ́ àṣàyàn; lílo láìmọ̀ọ́kàn ń dín kù sí àwọn ààlà fún IP kọ̀ọ̀kan, tí ń jẹ quota ọ̀fẹ́ ojoojúmọ́; kọ́kọ́rọ́ tí kò tọ́ ń dá 401/403 padà láìsí ìpadà-fallback aláìmọ̀ọ́kàn ní ìdákẹ́jẹ́.
- Ìpele ọ̀fẹ́: 1000 ìbéèrè/ọjọ́, 20 QPS fún kọ́kọ́rọ́ kọ̀ọ̀kan. Ìpele tí a sanwó fún: kò tíì ní iye owó (Coming Soon).
- Àpò ìdáhùn: àṣeyọrí `{code: 0, message: "success", request_id, data}`; ìkùnà `{code: -1, message}`. Àwọn àṣìṣe ìfàṣẹsí/quota kò ní `error_code` tí a ṣètò (ọ̀rọ̀ inú message ni àmì náà); àwọn àṣìṣe pàtó sí extract ní `error_code` (`invalid_extract_url`, `extract_failed`). Kò sí header `Retry-After` lórí 429.

## 3. Àwọn ìpinnu (gbogbo wọn ni a dé sí ní 2026-08-26)

1. **Ìlànà ìdarí: `fallbackOnly`.** Ìdí: olùpèsè ọ̀fẹ́ tí iye owó rẹ̀ jẹ́ 0 kò gbọdọ̀ borí ìdarí iye owó aládàáṣiṣẹ́ láé; yíyan ní tààrà àti ìpadà sí olùpèsè àfẹ́yìntì kò ní ìyípadà. Àpẹẹrẹ tẹ́lẹ̀: àkọsílẹ̀ xquik tí a ti dapọ̀.
2. **Ààlà iṣẹ́: webSearch + webFetch nípasẹ̀ `POST /v1/extract` nínú v1.** Èyí bá àwòrán èrò agbára-méjì ti tavily/exa mu. Àwọn ojú iṣẹ́ pàtó (`tag`, `sub-domains`, `batch_search`) kò sí nínú ààlà iṣẹ́ — kò sí IR fún àwọn paramítà iṣẹ́ pàtó ní báyìí.
3. **Ìfihàn ìpín iṣẹ́: `freeMonthlyQuota: 0`** (ìfihàn oníṣọ́ra ní ọ̀nà xquik). A fi iye gidi tí a yọ̀ǹda (1000 ìbéèrè/ọjọ́, àtúntò ojoojúmọ́) sínú ọ̀rọ̀ `authHint` ti àkójọ UI dípò rẹ̀. Ìdí: ìfihàn ìpín iṣẹ́ gbọdọ̀ bá ìlànà àtúntò mu; yíyí ààlà ojoojúmọ́ padà sí iye tó dọ́gba pẹ̀lú ti oṣooṣù (30000) jẹ́ ìlérí èké tí UI kò lè mú ṣẹ.
4. **searchTypes: `["web"]` nìkan.** Kò sí ẹ̀rí gbogbogbò pé apá ìṣàwárí ìròyìn/àwòrán wà nínú AnySearch API; àwọn ẹnu-ọ̀nà tí ń ṣàkóso àwọn API láìsí apá ìṣàwárí tí a ṣàkọsílẹ̀ (fún àpẹẹrẹ, Google Custom Search) máa ń fi wẹẹ̀bù nìkan hàn dípò kí wọ́n fi ìròyìn -> wẹẹ̀bù pamọ́-pamọ́.
5. **Ìlànà kọ́kọ́rọ́:** ó ń ṣiṣẹ́ láìsí kọ́kọ́rọ́; kọ́kọ́rọ́ tí kò fẹsẹ̀ múlẹ̀ máa dá 401/403 padà, a kò sì ní sọ ọ́ kalẹ̀ sí aláìlórúkọ ní ìkọ̀kọ̀ láé (èyí fara wé àdéhùn upstream).
6. **Àwọn ohun tí a mọ̀ọ́mọ̀ yọ kúrò:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (ìdásí àárín ìfọ̀rọ̀wérọ̀ ṣì wà lórí firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (àwọn endpoint jíjìn aláìlórúkọ ń pín adágún kan tí IP fi ààlà sí fún egress IP kọ̀ọ̀kan, nítorí náà extract aláìlórúkọ jẹ́ ohun tí a gbọdọ̀ yàn láti lò, kì í ṣe olùdíje fún ìdarí aládàáṣiṣẹ́); `QUOTA_STATUS_PROVIDERS` (AnySearch ń fi ìpín iṣẹ́ hàn nípasẹ̀ 429/envelope, kì í ṣe ipò 402/403).
