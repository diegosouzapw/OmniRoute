1. Fi àwọn ìdánwò tó dojú kọ ọ̀ràn náà mú àdéhùn semaphore oní-kọ́kọ́rọ́ kan tó wà tẹ́lẹ̀ àti àdéhùn atomiki oní-ọ̀pọ̀-kọ́kọ́rọ́ tuntun dúró ṣinṣin: kò gbọdọ̀ sí ìfipamọ́ apá kan, ìtòlẹ́sẹẹsẹ FIFO, ìfagilé, àkókò-parí, kíkún ìlà, ìtúsílẹ̀ tí kò yí àbájáde padà bí a bá tún ṣe é, àwọn ìṣirò, àti ìfọ̀mọ́.
2. Ṣe semaphore àkọọ́lẹ̀ tó wà tẹ́lẹ̀ ní àpapọ̀ sí i ní ibi kan náà. Jẹ́ kí `acquire()` dúró gẹ́gẹ́ bí wrapper ìbámu ní àyíká `acquireMany()`; má ṣe fi scheduler kejì tàbí dependency kan kún un.
3. Rọ́pò ìgba àṣẹ àkọọ́lẹ̀-nìkan nínú `chatCore` pẹ̀lú ìgba àṣẹ àkójọpọ̀ kan fún gbogbo-ètò/olùpèsè/àkọọ́lẹ̀ lẹ́sẹ̀kẹsẹ̀ ṣáájú `withRateLimit`. Tún gba gbogbo àkójọpọ̀ náà nígbàkigbà tí yíyí àkọọ́lẹ̀ bá yí àsopọ̀ padà, kí o sì pa ìtúsílẹ̀ náà mọ́ títí tí ṣiṣàn yóò fi parí.
4. Fa pipeline ètò ìfaradà tó wà tẹ́lẹ̀ gùn (àwọn irú, àwọn iye àìyípadà, ìṣètò sí ọ̀nà kan náà, schema, ìdáhùn API, UI, àti àwọn ìtumọ̀) pẹ̀lú àwọn òpin gbogbo-ètò àti olùpèsè. Tún fi àkọlé sí ìṣàkóso concurrency Bottleneck àtijọ́ gẹ́gẹ́ bí concurrency ti àsopọ̀/ààyè quota, kí ààyè gidi rẹ̀ lè hàn kedere.
5. Ṣiṣe àwọn ìdánwò tó dojú kọ ọ̀ràn náà, lint, typecheck, àwọn àyẹ̀wò static, àti gbogbo àkójọpọ̀ ìdánwò; ṣàkọsílẹ̀ ìyípadà ìhùwàsí náà sínú changelog.

Ìhùwàsí tí a mọ̀ọ́mọ̀ pa mọ́: concurrency odo/null máa kọjá gate kan, àwọn olùpè àṣẹ àkọọ́lẹ̀-nìkan yóò tẹ̀síwájú láti máa lo `acquire()`, àwọn ìṣàkóso àkọọ́lẹ̀ tí a dí mọ́ pa ọ̀nà kika kọ́kọ́rọ́ àti API wọn mọ́, àti pé ìhùwàsí ìlà rate-limit olùpèsè kò yí padà.
