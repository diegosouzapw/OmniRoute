OmniRoute ṣètò àwọn olùpèsè 352 tí ó ṣe àtìlẹ́yìn fún sí ìpele ọrọ̀ ajé 3. Ìbéèrè
kọ̀ọ̀kan máa ń gba inú wọn kọjá ní ṣísẹ̀-n-tẹ̀lé títí tí ọ̀kan yóò fi dáhùn ní àṣeyọrí — o
máa gba ìdáhùn tó péye tí ó sì din owó jù láìní láti kọ kóòdù àfẹ́yìntì rárá.

## Ìpele 1 — Ìforúkọsílẹ̀

**Àwọn olùpèsè tí o ti ń sanwó fún.** OmniRoute máa ń lo gbogbo ìwọ̀n ìpín rẹ kí
ó tó parí.

| Olùpèsè                            | Ìdí tó fi wà ní Ìpele 1                                    |
| ---------------------------------- | ---------------------------------------------------------- |
| Claude Code OAuth                  | Anthropic Pro/Team — owó-oṣù kan náà, a kì í sábà lò ó tán |
| OpenAI Codex (ìforúkọsílẹ̀ ChatGPT) | Plus/Team ní ìpín Codex nínú                               |
| GitHub Copilot                     | Fún àga kọ̀ọ̀kan — ìpín máa ń tún bẹ̀rẹ̀ lóṣooṣù               |
| Cursor IDE                         | Ìpín ètò Pro                                               |
| Antigravity / Devin Desktop        | Àwọn ìpín inú ètò                                          |

**Ìlànà**: kọ́kọ́ darí gbogbo ìbéèrè tó bá àwọn agbára awoṣe mu síbí.
Olùtọ́pa ìpín máa ń ṣọ́ àwọn àkókò ìtún-bẹ̀rẹ̀ tó ń sún mọ́lé, ìlànà àpapọ̀ `reset-aware`
sì máa ń ṣètò ààyò gẹ́gẹ́ bí ìyẹn. Láti kọ́kọ́ darí sí Ìpele 1 kí o sì kàn lọ
sí àwọn ìpele olówó nígbà tí ìpín bá parí, lo id `auto/thrifty` — tàbí `auto/subscription`
láti dúró lórí agbára tó wà nínú ètò kí ó sì kùnà láìlọ sí ìpele mìíràn dípò bẹ́ẹ̀. Wo
[Ìdarí tó fi ìforúkọsílẹ̀ sí ipò àkọ́kọ́](../routing/SUBSCRIPTION_LADDER.md).

## Ìpele 2 — Olówó Pọ́ọ̀kú

**Àwọn olùpèsè tí a ń sanwó fún tóókẹ̀n kọ̀ọ̀kan ní owó tí kò tó $1/1M tóókẹ̀n.** A fi wọ́n pamọ́ fún iṣẹ́ aláfẹ̀ẹ́fẹ́ púpọ̀
tàbí lẹ́yìn tí àwọn ìpín Ìpele 1 bá dé òpin.

| Olùpèsè                      | Iye owó (àgbàwọlé/àbájáde) | Àwọn agbára                       |
| ---------------------------- | -------------------------- | --------------------------------- |
| DeepSeek V4 Pro              | $0.27 / $1.10 fún 1M       | Kóòdù, ìrònú                      |
| GLM-4.5                      | $0.60 / $2.20 fún 1M       | Àyíká ọ̀rọ̀ gígùn                   |
| MiniMax M1                   | $0.20 / $1.10 fún 1M       | Ìyára                             |
| Qwen Coder                   | $0.30 / $1.20 fún 1M       | Kóòdù                             |
| OpenRouter (price-optimized) | ó yàtọ̀                     | Àwọn awoṣe 100+, ìyípadà aláìdúró |

**Ìlànà**: àpapọ̀ `cost-optimized` máa ń yan awoṣe tó ní iye $/tóókẹ̀n tó kéré jù tí ó bá
àsẹ̀ agbára iṣẹ́ náà mu (ìran, módù JSON, àwọn irinṣẹ́, àyíká-ọ̀rọ̀-tó-pọ̀jù).

## Ìpele 3 — Ọ̀fẹ́

**Àwọn olùpèsè aláìlówó** — àwọn ìpele ọ̀fẹ́, àwọn ètò kírẹ́díìtì, àwọn ìpín OAuth ojoojúmọ́.

| Olùpèsè          | Ìpín ọ̀fẹ́ / àwọn kírẹ́díìtì                  |
| ---------------- | ------------------------------------------ |
| Kiro AI          | Ìpele Claude ọ̀fẹ́ (lílò tó bọ́gbọ́n mu lọ́pọ̀)  |
| OpenCode Free    | Kò nílò ìfàṣẹsí, àwọn òpin ìwọ̀n lílò tó pọ̀ |
| Qoder            | OAuth ọ̀fẹ́                                  |
| Google Vertex AI | Kírẹ́díìtì $300 fún àkọọ́lẹ̀ tuntun           |
| Amazon Q         | Ìpele ọ̀fẹ́ fún àwọn aṣàmúlò AWS             |
| Pollinations     | API gbogbogbò tó ṣí sílẹ̀                   |
| Cloudflare AI    | Ìpele Workers AI ọ̀fẹ́                       |

**Ìlànà**: àpapọ̀ `auto` pẹ̀lú òpin ìnáwó máa ń darí síbí nígbà tí Ìpele 1+2 bá kùnà
tàbí nígbà tí a bá ṣètò `useFreeOnly=true`. Àwọn olùpèsè ọ̀fẹ́ sábà máa ń ní
òpin ìwọ̀n lílò tó kéré — olùdáwọ́lé àyíká máa ń mú wọn padà bọ̀ lẹ́yìn ìdádúró.

## Ṣíṣètò àwọn ìpele

Pánẹ́ẹ̀lì ìṣàkóso → **Àwọn Ìpele** → yan ìpele fún àwọn olùpèsè rẹ. Àwọn àtẹ̀jáde àkọ́kọ́ (láti inú `tierDefaults.json`) jẹ́
èyí tó bójú mu; ṣàtúnṣe wọn nígbà tí o bá ní àwọn ìforúkọsílẹ̀ pàtó láti fi sí ààyò tàbí àwọn olùpèsè láti yọ kúrò.

Ìṣírò onífókítà 16 ti Auto-Combo tún máa ń gbé ìpele yẹ̀ wò. Wo
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Tẹlímẹ́trì

Pánẹ́ẹ̀lì ìṣàkóso → **Ìlò** ń ṣàfihàn àwọn tóókẹ̀n tí a lò fún ìpele kọ̀ọ̀kan lójoojúmọ́. Lo èyí láti:

- Jẹ́rìí pé a lo Ìpele 1 ní kíkún (bí bẹ́ẹ̀ kọ́, o ń fi iye ìforúkọsílẹ̀ rẹ ṣòfò)
- Ṣàwárí àwọn awoṣe Ìpele 2 tí a ń yàn jù lọ (ṣàkójọpọ̀ wọn sí 1-2)
- Fìdí rẹ̀ múlẹ̀ pé Ìpele 3 ń dín owó kù lórí àwọn iṣẹ́ ìdánwò/àwárí

## Àwọn àpẹẹrẹ tó wọ́pọ̀

### Iṣẹ́ ọ̀fẹ́ pátápátá

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Ó máa ń darí lọ́nà tó lágbára sí Ìpele 3; Ìpele 2 nìkan ni yóò lò bí Ìpele 3 kò bá sí.

### Ìforúkọsílẹ̀ lákọ̀ọ́kọ́ pẹ̀lú àfẹ́yìntì olówó pọ́ọ̀kú

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Àtòjọ ṣíṣe-n-tẹ̀lé tó ṣe kedere tí ó bá Ìpele 1 → Ìpele 2 → Ìpele 3 mu.
