## 🔌 Àwọn Olùpèsè

Ṣàkóso àwọn ìsopọ̀ olùpèsè AI: àwọn olùpèsè OAuth (Claude Code, Codex), àwọn olùpèsè kọ́kọ́rọ́ API (Groq, DeepSeek, OpenRouter), àti àwọn olùpèsè ọ̀fẹ́ (Qoder, Kiro). Àwọn àkọọ́lẹ̀ Kiro ní ìtọ́pa iye kirẹditi — àwọn kirẹditi tó kù, àpapọ̀ iye tí a yọ̀ǹda, àti ọjọ́ ìsọdọ̀tun ni a lè rí ní Pátákó → Ìlò.

Àwọn ìsopọ̀ OpenRouter lè tọ́jú `preset` kan fún ìsopọ̀ kọ̀ọ̀kan nínú Àwọn Ètò Onítẹ̀síwájú. Nígbà tí a bá ṣètò rẹ̀, OmniRoute máa ń fi í ránṣẹ́ gẹ́gẹ́ bí pápá ìbéèrè ìpele-òkè OpenRouter, fún àpẹẹrẹ `"preset": "email-copywriter"`, àyàfi tí ìbéèrè oníbàárà bá ti pèsè `preset` tirẹ̀ tẹ́lẹ̀.

## 🎨 Àwọn Àkópọ̀

Ṣẹ̀dá àwọn àkópọ̀ ìdarí-ọ̀nà awoṣe pẹ̀lú ọgbọ́n gbogbogbò 19: priority, weighted, round-robin, context-relay, fill-first, p2c (yíyan agbára-méjì), random, least-used, cost-optimized, reset-aware, reset-window, headroom, strict-random, auto, lkgp (olùpèsè-tó-dára-tí-a-mọ̀-kẹ́yìn), context-optimized, cache-optimized, **fusion** (pín iṣẹ́ jáde sí ẹgbẹ́ àwọn awoṣe ní ìṣọ̀kan, lẹ́yìn náà kí adájọ́ ṣàkópọ̀ ìdáhùn kan), àti **pipeline**. Àkópọ̀ kọ̀ọ̀kan so ọ̀pọ̀ awoṣe pọ̀ pẹ̀lú ìpadà-sẹ́yìn aládàáṣe, ó sì ní àwọn àdàkọ ìbẹ̀rẹ̀ kíákíá àti àwọn àyẹ̀wò ìmúrasílẹ̀.

Àwọn ìlọsíwájú àkópọ̀ láìpẹ́:

- **Olùkọ́ àkópọ̀ oníṣètò** — ṣẹ̀dá ìgbésẹ̀ kọ̀ọ̀kan nípa yíyan olùpèsè, awoṣe, àti àkọọ́lẹ̀/ìsopọ̀ pàtó
- **Àtìlẹ́yìn fún olùpèsè tí a tún lò** — tún olùpèsè kan náà lò ní ọ̀pọ̀ ìgbà nínú àkópọ̀ kan, níwọ̀n ìgbà tí àkójọpọ̀ `(provider, model, connection)` jẹ́ aláìlẹ́gbẹ́
- **Ìlera ibi-àfojúsùn àkópọ̀** — ìtúpalẹ̀ àti àwọn àfihàn ìlera ti ń ṣe ìyàtọ̀ báyìí láàárín ibi-àfojúsùn/ìgbésẹ̀ àkópọ̀ kọ̀ọ̀kan dípò kí wọ́n pa gbogbo rẹ̀ pọ̀ sínú àwọn ọ̀rọ̀ awoṣe
- **Ìṣètò ìpele àpapọ̀** — `defaultTier -> fallbackTier` ti ń ní ipa báyìí lórí ìtòlẹ́sẹẹsẹ ìṣiṣẹ́/ìpadà-sẹ́yìn ní àkókò ìṣiṣẹ́ fún àwọn ìgbésẹ̀ àkópọ̀ ìpele-òkè
- **Àwọn àdàkọ ìtọ́ni ètò** — `system_message` àkópọ̀ ṣe àtìlẹ́yìn ní ẹ̀gbẹ́ olupin fún
  `{{MODEL_ID}}`, `{{PROVIDER_ID}}`, `{{ACCOUNT}}` àti `{{FINGERPRINT}}`
  àwọn ààyè ìròyìn, tí a máa ń fẹ̀ síi láti inú ibi-àfojúsùn tí a darí sí ní ti gidi kíákíá ṣáájú fífi ránṣẹ́.
  Wọ́n wà nínú àkójọ-ìyọ̀ǹda, wọn kì í sì í pe ara wọn padà; àwọn ààyè ìròyìn tí a kò mọ̀ dúró gẹ́gẹ́ bí wọ́n ṣe jẹ́; àwọn iye òfo
  máa ń fẹ̀ sí òfo; a kì í tún àwọn ìtọ́ni ètò oníbàárà kọ. `{{FINGERPRINT}}`
  ń yanjú fún àwọn olùpèsè ọ̀fẹ́ tó dá lórí fingerprint nìkan, tí wọ́n ní fingerprint tí a ti kàn mọ́lẹ̀ tàbí
  tí a ń yí padà láìfọwọ́sí — ó máa ń fẹ̀ sí òfo ní ibòmíràn (fún àpẹẹrẹ
  àwọn ìsopọ̀ fingerprint kan ṣoṣo, àwọn olùpèsè tí kì í ṣe fp). Ìfẹ̀síwájú yìí kan
  iyípo fífi-ránṣẹ́ boṣewa, round-robin, àti àwọn sáẹ́ṣọ̀nù àfipamọ́ àyíká-ọ̀rọ̀ tí a kàn mọ́lẹ̀;

- **Ìfaradà** — Ìtọ́jú ààlà oṣuwọn, àtúnṣe circuit breaker, pípa àwọn àkọọ́lẹ̀ tí a fòfin dè láìfọwọ́ṣe, àbójútó ọjọ́ ìparí olùpèsè, iye ààlà ìfàrọ́wọ́lé **Context Relay** àti ìṣètò módẹ́lì àkótán, ìsọ̀rí 429 fún olùpèsè kọ̀ọ̀kan àti ìyípadà tan/pà `useUpstream429BreakerHints`, àwọn àkókò ìsinmi módẹ́lì
- **Ìlọsíwájú** — Àwọn ìṣàtúnṣe ìṣètò, àkọsílẹ̀ àyẹ̀wò ìṣètò, ìpo ìdínkù fallback, ìdínkù ìpo abẹ́lẹ̀ fún Responses API

Ìmúṣẹ ìṣètò proxy tó péye káàkiri gbogbo ìlànà ìbéèrè:

## 🌐 V1 WebSocket Bridge _(v3.6.6+)_

OmniRoute ti ń ṣe àtìlẹ́yìn fún **àwọn WebSocket client tó bá OpenAI mu** báyìí nípasẹ̀ `/v1/ws` upgrade endpoint. Server àkànṣe `scripts/dev/v1-ws-bridge.mjs` máa ń fi Next.js ṣe àyíká, ó sì ń ṣe àfikún àwọn ìsopọ̀ WS sí àwọn session streaming oníbàárà méjèèjì kíkún. Ìfàṣẹsí ń lo API key kan náà tàbí session cookie bíi àwọn ìbéèrè HTTP.

Àwọn ìhùwàsí pàtàkì:

- `src/lib/ws/handshake.ts` máa ń fìdí WS upgrade múlẹ̀ ṣáájú kí ìsopọ̀ tó bẹ̀rẹ̀
- Àwọn stream máa ń dópin lọ́nà tó mọ́ nígbà tí session bá parí tàbí tí upstream error bá ṣẹlẹ̀
- Ó ń ṣiṣẹ́ lẹ́gbẹ̀ẹ́ ọ̀nà streaming HTTP+SSE tó ti wà tẹ́lẹ̀ ní àkókò kan náà

## 🔑 Àwọn Tókìnù Ìṣiṣẹ́pọ̀ & Àkójọpọ̀ Àtòjọ-ètò _(v3.6.6+)_

Ìráàyèsí láti ọ̀pọ̀ ẹ̀rọ àti láti ọ̀dọ̀ àwọn olùṣiṣẹ́ àgbékalẹ̀ òde ti ṣeé ṣe báyìí nípasẹ̀ **àwọn tókìnù ìṣiṣẹ́pọ̀ tí a fi ààlà sí**:

- **`POST /api/sync/tokens`** — Ṣẹ̀dá tókìnù ìṣiṣẹ́pọ̀ tuntun (tí a fi ààlà sí, pẹ̀lú àkókò ìparí tí kò pọn dandan)
- **`DELETE /api/sync/tokens/:id`** — Fagilé tókìnù kan
- **`GET /api/sync/bundle`** — Ṣe àgbàsílẹ̀ àwòrán-ipò JSON tí a fi ẹ̀yà àti ETag ṣe àmì rẹ̀, tó ní gbogbo àwọn àtòjọ-ètò tí kì í ṣe àṣírí (a fi àwọn ọ̀rọ̀ aṣínà pamọ́)

`src/lib/sync/bundle.ts` ló ń kọ àkójọpọ̀ àtòjọ-ètò náà. Àwọn olùlò máa ń fi àkọlé ìdáhùn `ETag` wé ara wọn láti ṣàwárí àwọn ìyípadà láìní láti tún gbogbo ẹrù dátà náà ṣe àgbàsílẹ̀.

## 🧠 Àtòjọ-ètò Tí a Ti Ṣètò Sílẹ̀ fún Ìrònú GLM _(v3.6.6+)_

**GLM Thinking (`glmt`)** ti di olupèsè ipele-àkọ́kọ́ tí a forúkọsílẹ̀ báyìí: tókìnù àbájáde tó pọ̀jù 65 536, ìpín tókìnù ìrònú 24 576, àkókò ìdúró àiyipada 900 s, ìlànà API tó bá Claude mu, àti ìṣiṣẹ́pọ̀ lílò tí a pín pẹ̀lú ẹbí GLM.

**Ìṣírò tókìnù àkójọpọ̀** tún dé sínú v3.6.6: nígbà tí olupèsè tó bá Claude mu bá pèsè `/messages/count_tokens`, OmniRoute máa ń pè é ṣáájú àwọn ìbéèrè ńlá, pẹ̀lú ìṣírò àfojúsùn àfẹ́yìntì tó rọrùn.

## 🛡️ Ìgbàjáde Òde Tó Láàbò & Ìdènà SSRF _(v3.6.6+)_

Gbogbo ìfọwọ́sí olupèsè àti àwọn ìpè ìṣàwárí módẹ́lì ń gba inú ìdènà ìjápọ̀ òde alápele méjì kọjá báyìí:

1. **Ìdènà URL** (`src/shared/network/outboundUrlGuard.ts`) — Ó dí àwọn ìpín IP àdáni/loopback/link-local kí socket tó ṣí.
2. **Àpò ìgbàjáde tó láàbò** (`src/shared/network/safeOutboundFetch.ts`) — Ó lo ìdènà URL, ó ṣe àkókò ìdúró déédéé, ó sì tún àwọn àṣìṣe ìgbà díẹ̀ gbìyànjú pẹ̀lú ìdádúró tó ń pọ̀ sí i lọ́nà exponential.

Àwọn ìrúfin ìdènà máa ń fara hàn gẹ́gẹ́ bí HTTP 422 (`URL_GUARD_BLOCKED`), a sì máa ń kọ wọ́n sínú àkọsílẹ̀ àyẹ̀wò ìbámu nípasẹ̀ `providerAudit.ts`.

## 🔄 Àwọn Ìgbìyànjú-Àtúnṣe Tó Mọ Ìgbà-ìsinmi _(v3.6.6+)_

Àwọn ìbéèrè ìfọ̀rọ̀wérọ̀ máa ń **tún ara wọn gbìyànjú láìfọwọ́yí** báyìí nígbà tí olupèsè òkè bá dá ìgbà-ìsinmi tó jẹ́ ti módẹ́lì kan pàtó padà. A lè ṣètò rẹ̀ nípasẹ̀ `REQUEST_RETRY` (àiyipada: 2) àti `MAX_RETRY_INTERVAL_SEC` (àiyipada: 30 s). Ìkẹ́kọ̀ọ́ àkọlé òṣùwọ̀n-ààlà ti sunwọ̀n sí i lórí `x-ratelimit-reset-requests`, `x-ratelimit-reset-tokens`, àti `Retry-After` — ipò ìgbà-ìsinmi fún módẹ́lì kọ̀ọ̀kan hàn nínú pánẹ́ẹ̀lì Resilience.

## 📋 Àyẹ̀wò Ìbámu v2 _(v3.6.6+)_

A ti mú àkọsílẹ̀ àyẹ̀wò gbòòrò sí i pẹ̀lú ìpín ojú-ìwé tó dá lórí kọ́sọ̀, fífi àlàyé àyíká ìbéèrè kún un (ID ìbéèrè, aṣojú olùlò, IP), àwọn ìṣẹ̀lẹ̀ ìfàṣẹsí tó ní ìgbékalẹ̀, àwọn ìṣẹ̀lẹ̀ CRUD olupèsè pẹ̀lú àlàyé ìyàtọ̀, àti ìkọsílẹ̀ ìfọwọ́sí tí SSRF dènà. Àwọn ìṣẹ̀lẹ̀ tuntun ni `src/lib/compliance/providerAudit.ts` ń ṣe jáde.
