**OmniCopilot** ń fi gbogbo model tí OmniRoute rẹ ń pèsè sínú olùyan model GitHub Copilot Chat
_abínibí_. Kò sí sidebar kejì, kò sí UI ìfọ̀rọ̀wérọ̀ ọ̀tọ̀ — mode aṣojú Copilot, pípè irinṣẹ́,
àwọn olupin MCP àti àwọn ìtọ́nisọ́nà àdáni yóò máa ṣiṣẹ́ bí ti tẹ́lẹ̀, ṣùgbọ́n lórí model tí o yàn.

| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Fi sílẹ̀ (VS Code)**         | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Fi sílẹ̀ (àwọn fork)**       | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Kóòdù orísun / àwọn ìṣòro** | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Ohun tí ó nílò**            | VS Code 1.104+                                                                                                                                  |

> **Kò nílò ìforúkọsílẹ̀ Copilot.** Láti VS Code 1.122, olùpèsè model èdè kan ń ṣiṣẹ́
> láì wọlé sí GitHub àti láìní ètò Copilot kankan. Àwọn ìparí inline àti
> àwọn ẹ̀yà tó dá lórí embeddings kò sí lábẹ́ API olùpèsè, wọ́n sì ṣì nílò Copilot.

## Ìṣètò

1. **Ṣiṣẹ́ OmniRoute** — `npm install -g omniroute && omniroute` (dashboard wà ní `http://localhost:20128`).
2. **Fi extension náà sílẹ̀** — wá "OmniRoute" nínú ojú-ìwòye Extensions.
3. **Yan model kan** — Copilot Chat → olùyan model → **Ṣàkóso Àwọn Model…** → **OmniRoute**, lẹ́yìn náà yan
   àwọn tí o fẹ́.

Kò sí ohun tí o nílò láti ṣètò nígbà tí OmniRoute bá ń ṣiṣẹ́ lórí port àìyípadà. Fún instance tó wà ní ọ̀nà jíjìn, ṣí
**àmì OmniRoute nínú Activity Bar** (tàbí ṣiṣẹ́ `OmniRoute: Manage Connection`) kí o sì ṣètò:

- **URL olupin** — root olupin náà, fún àpẹẹrẹ `http://192.168.0.15:20128`. Extension náà yóò
  fi suffix `/v1` kún un; má ṣe fi í sínú rẹ.
- **Kọ́kọ́rọ́ API** — nígbà tí olupin bá ṣètò `REQUIRE_API_KEY` nìkan. A máa tọ́jú rẹ̀ sínú keychain OS nípasẹ̀ VS
  Code SecretStorage, kì í ṣe nínú `settings.json` láé.

## Ohun tí olùyan náà yóò fi hàn

Extension náà kì í fi payload `GET /v1/models` tí kò tíì ṣe àtúnṣe hàn — ó ń ṣe àtò rẹ̀, iye tí o sì
rí kéré ju iye catalog lọ fún ìdí méjì tí a mọ̀ọ́mọ̀ yàn.

### Ó ń béèrè id kan fún model kọ̀ọ̀kan

`MODELS_CATALOG_PREFIX_MODE` máa ń lo **`dual`** gẹ́gẹ́ bí àìyípadà, èyí tó ń polówó model kọ̀ọ̀kan lẹ́ẹ̀mejì — lẹ́ẹ̀kan
lábẹ́ prefix alias kúkúrú àti lẹ́ẹ̀kan lábẹ́ prefix canonical ti olùpèsè — kí àwọn config client àtijọ́
lè máa rí fọ́ọ̀mù méjèèjì:

```
cc/claude-sonnet-4-6        ← prefix alias
claude/claude-sonnet-4-6    ← prefix canonical, model kan náà
```

Extension náà ń béèrè **`GET /v1/models?prefix=alias`** kí id kan ṣoṣo lè dé fún model kọ̀ọ̀kan, láì
yí ìṣètò gbogbo olupin padà fún àwọn client rẹ mìíràn. Lórí instance àpẹẹrẹ kan, èyí dín
**àwọn entry 2345 kù sí 1396 — duplicate 949, kò sí model kankan tó sọnù.**

Tí o bá fẹ́ ṣe àtúnṣe rẹ̀ fún gbogbo olupin fún _gbogbo_ client, ṣètò feature flag
`MODELS_CATALOG_PREFIX_MODE` sí `alias` nínú dashboard. Wo
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) fún
query parameter àti tábìlì mode kọ̀ọ̀kan.

### Ó ń fi àwọn model tí kò lè ṣe ìfọ̀rọ̀wérọ̀ pamọ́

Catalog náà tún ṣe àkójọ àwọn model àwòrán, fídíò, ohun, rerank, embedding àti moderation. A máa
kọ àwọn wọ̀nyẹn sílẹ̀ lórí ìbéèrè ìfọ̀rọ̀wérọ̀ lọ́nàkọnà:

```
HTTP 400 — Model '<id>' jẹ́ model ìṣẹ̀dá-àwòrán, a kò sì lè lò ó lórí
/v1/chat/completions. Lo POST /v1/images/generations dípò rẹ̀.
```

nítorí náà, a máa yọ wọ́n kúrò nípasẹ̀ field `type` wọn kí wọ́n tó dé ọ̀dọ̀ olùyan. **Àwọn model Responses-API
ni a ń pa mọ́** — gbogbo entry Codex / GPT-5.x ń polówó `supported_endpoints: ["responses"]`,
OmniRoute sì ń túmọ̀ àwọn wọ̀nyẹn fún `/v1/chat/completions`, nítorí náà wọ́n ṣeé lò dáadáa.

### Àwọn olùpèsè tí o kò ṣètò rí

Catalog náà ń ṣe àkójọ àwọn model láti ọ̀dọ̀ àwọn olùpèsè tó ní **àsopọ tó ń ṣiṣẹ́** _pẹ̀lú_ gbogbo olùpèsè **noAuth**
— àwọn tí kò nílò kọ́kọ́rọ́, tí wọ́n sì jẹ́ apá púpọ̀ nínú tier ọ̀fẹ́. Èyí jẹ́ àmọ̀ọ́mọ̀. Láti fi
wọ́n pamọ́, fi wọ́n kún `blockedProviders` nínú àwọn ìṣètò dashboard; kò sí ohun tó yí padà nínú
extension náà.

## Pátákó ìṣàkóso inú táàbù VS Code

`omnicopilot.dashboardOpen: "editor"` máa ń ṣàfihàn pátákó ìṣàkóso OmniRoute nínú táàbù olóòtú nípasẹ̀
Simple Browser dípò aṣàwákiri òde. Ìfìmọ́ra jẹ́ **ohun tí a gbọ́dọ̀ yàn láti mú ṣiṣẹ́ lórí apèsè** nípasẹ̀
`DASHBOARD_ALLOW_EMBED=vscode`, èyí tí ó ń fi àwọn ojú-ewé HTML ránṣẹ́ pẹ̀lú
`frame-ancestors 'self' vscode-webview:` dípò `frame-ancestors 'none'` +
`X-Frame-Options: DENY` àìyípadà. Ojú API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) ṣì ń pa
àwọn àkọlé tó le koko mọ́ lọ́nà méjèèjì.

> ⚠️ **Àmì àsìkò ìkọ́ ni, kì í ṣe ti àsìkò ìṣiṣẹ́.** Next.js máa ń ṣàkójọ `headers()` sínú àkọsílẹ̀ ipa-ọ̀nà,
> nítorí náà `next.config.mjs` máa ń ka oníyípadà náà nígbà tí a bá ń kọ́ àkójọpọ̀ náà
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Fífi í jáde níwájú apèsè tí a ti kọ́ tán kò ní yí ohunkóhun padà — àwọn àkọlé náà ti di apá kan àkójọpọ̀ náà.

```bash
# oníyípadà náà gbọ́dọ̀ wà lórí àṣẹ BUILD
DASHBOARD_ALLOW_EMBED=vscode npm run build        # tàbí npm run build:release
npm start
```

| Bí o ṣe fi í sí ẹrọ        | Ṣé o lè mú ìfìmọ́ra ṣiṣẹ́?                                                                                                                            |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Láti inú kóòdù orísun      | ✅ ṣètò oníyípadà náà lórí àṣẹ ìkọ́, gẹ́gẹ́ bí ó ṣe wà lókè                                                                                            |
| `npm install -g omniroute` | ❌ àpò tí a tẹ̀ jáde ní àkójọpọ̀ tí a ti kọ́ tẹ́lẹ̀ nínú — kọ́ ọ láti inú kóòdù orísun dípò rẹ̀                                                            |
| Àwòrán Docker              | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — àwòrán tí a ti kọ́ tẹ́lẹ̀ lórí Docker Hub kò ní ìfìmọ́ra tí a mú ṣiṣẹ́ |

Láìsí àkójọpọ̀ tí a mú ìfìmọ́ra ṣiṣẹ́ fún, ojú-ewé náà máa kọ̀ láti wọ inú férémù, àfikún náà máa ṣàwárí èyí láti inú
àwọn àkọlé ìdáhùn, yóò sì padà sí aṣàwákiri òde — kò sí ohun tí yóò bàjẹ́, yóò sì sọ èyí lẹ́ẹ̀kan.
Wo [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) àti ọ̀ràn
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Ṣíṣètò àwọn irinṣẹ́ rẹ mìíràn láti inú VS Code

**`OmniRoute: Configure Coding CLI`** máa ń darí CLI `omniroute` láti kọ àwọn prófáìlì tí ó ti ṣetán fún lílò
fún Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo àti Roo — àwọn ìṣètò kan náà tí a ṣàpèjúwe nínú
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). A máa ń fi kọ́kọ́rọ́ API náà fún CLI nípasẹ̀
oníyípadà àyíká `OMNIROUTE_API_KEY`, kì í ṣe lórí ìlà àṣẹ láé.
