> **Pátákó Ìṣàkóso:** Àwọn Ètò → **AI** → Ìwọ̀n Ìnáwó Ìrònú  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **Orísun:** `open-sse/services/thinkingBudget.ts`

Ìwọ̀n Ìnáwó Ìrònú ń ṣàkóso bóyá OmniRoute yóò **tún àwọn pàrámítà ìrònú/ìdáláre oníbàárà kọ** nígbà tí wọ́n ń lọ sí ọ̀dọ̀ àwọn olùpèsè. Kò **tan tàbí pa** ìfúnpọ̀, ìtọ́sọ́nà, tàbí kaṣe ìbéèrè.

## Àwọn ipò

| Ipò                          | Ohun tí OmniRoute ń ṣe                                                                                                              | Ìgbà tí ó yẹ kí o lò ó                                                                                                                                                                 |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (àìyípadà) | Kò yí àwọn ààyè oníbàárà padà (`reasoning`, `reasoning_effort`, `thinking` ti Claude, `thinking_config` ti Gemini, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ). | **Codex / Desktop / oníbàárà èyíkéyìí tí ó yẹ kí ó ṣàkóso ìsapá + àwọn àkótán ìdáláre.** Ó pọndandan fún àwọn pánẹ́ẹ̀lì ìrònú tí a lè rí nígbà tí oníbàárà bá béèrè `reasoning.summary`. |
| **`auto`**                   | **Yọ gbogbo** àwọn ààyè ìrònú/ìdáláre kúrò nínú request body kí ó tó lọ sí upstream.                                                | Nígbà tí o mọ̀ọ́mọ̀ fẹ́ kí **olùpèsè** dá àwọn àìyípadà tirẹ̀ sílẹ̀, tí o sì **kò** nílò ìrònú tí oníbàárà ń ṣàkóso. **Kì í ṣe** “fi ìrònú hàn láìfọwọ́yí”.                                   |
| **`custom`**                 | Ó fi ìwọ̀n token ìrònú kan tí kò yí padà rọ́pò èyí tó wà nínú gbogbo ìbéèrè.                                                          | Ààlà líle fún àwọn token ìrònú lórí gbogbo ìrìnnà.                                                                                                                                     |
| **`adaptive`**               | Ó ń ṣe àtúnṣe ìwọ̀n náà láti inú ìsapá ìpìlẹ̀ nípa lílo iye àwọn ìfiránṣẹ́, àwọn irinṣẹ́, àti gígùn ìbéèrè.                             | Ìṣàkóso token tí kò le jù láìyọ èrò oníbàárà kúrò pátápátá.                                                                                                                            |

### Ohun tí `auto` ń yọ kúrò

Nígbà tí ipò bá jẹ́ `auto`, `stripThinkingConfig()` máa ń pa àwọn wọ̀nyí rẹ́ (láàárín àwọn mìíràn):

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, àti `output_config.effort` nígbà tí ó bá wà
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

Tí oníbàárà kan (fún àpẹẹrẹ, Codex Desktop) bá fi `reasoning: { effort: "ultra", summary: "detailed" }` ránṣẹ́, **auto yóò yọ ohun náà kúrò**. Upstream lè ṣì gba owó fún àwọn token ìdáláre kan, ṣùgbọ́n ó sábà máa ń dá àwọn ohun ìdáláre tí ó **ṣófo tàbí tí a fi ìpàrokò pamọ́ nìkan** padà — nítorí náà UI kò ní fi ṣiṣàn ìrònú tó wúlò hàn.

## Ohun tí èyí **kì í ṣe**

| Ẹ̀yà                                           | Ìbáṣepọ̀                                                                                                                                  |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Ìfúnpọ̀** (Caveman, RTK, stacked, …)         | Pipeline ọ̀tọ̀. Ó ń ṣiṣẹ́ lábẹ́ gbogbo ipò thinking-budget.                                                                                  |
| **Kaṣe ìbéèrè / ìtumọ̀**                       | Ó jẹ́ ohun ọ̀tọ̀. Ipò thinking-budget kò ní ipa lórí rẹ̀.                                                                                    |
| **Ìtọ́sọ́nà àkójọpọ̀ / àwọn ìpadàsẹ́yìn**         | Ó jẹ́ ohun ọ̀tọ̀. Kò ní ipa lórí rẹ̀.                                                                                                        |
| **Àwọn ààlà token API-key / àwọn ìwọ̀n ìnáwó** | Ó jẹ́ ohun ọ̀tọ̀. Kò ní ipa lórí rẹ̀.                                                                                                        |
| **Kaṣe àtúnsì ìdáláre**                       | Àtúnfi-sí-lẹ̀ alápọ̀-ìpele fún àwọn olùpèsè tó muna (DeepSeek, Kimi, Qwen-thinking, …). Kò jẹ́ ohun kan náà pẹ̀lú “fi ìrònú hàn” ti Desktop. |
| **Ṣíṣí ìpàrokò `encrypted_content`**          | **Kò ṣeé ṣe.** Àwọn blob ìdáláre àdáni ti OpenAI/Codex kò ṣeé ṣí. OmniRoute kì í ṣí ìpàrokò wọn láéláé (#7095 / #7176 / #7304).          |

## Ìrònú tí ó hàn (àwọn oníbàárà Codex / Responses)

Kí oníbàárà kan lè fi ọ̀rọ̀ ìrònú hàn, o nílò **gbogbo** àwọn wọ̀nyí:

1. Ìpo Thinking Budget = **`passthrough`** (tàbí custom/adaptive tí ó ṣì jẹ́ kí àwọn ìbéèrè àkópọ̀ dúró láìyípadà tó fún ọ̀nà tí o ń lò).
2. Oníbàárà béèrè fún àkópọ̀, àpẹẹrẹ Codex `model_reasoning_summary = "detailed"` / `auto` (kì í ṣe `none`).
3. Upstream fi `response.reasoning_summary_text.*` ránṣẹ́ ní ṣiṣàn ní tòótọ́ (tàbí `reasoning.summary` tí kò ṣófo lórí ohun náà).

Tí ohun tí o bá rí bá jẹ́ “ìrònú àdáni tí a ti parọ́ mọ́” nìkan, bóyá:

- ìpo náà jẹ́ **`auto`** (a yọ ìbéèrè oníbàárà náà kúrò), tàbí
- upstream dá `encrypted_content` padà láìsí ọ̀rọ̀ àkópọ̀ (ìdíwọ̀n olùpèsè; OmniRoute lè fi ọ̀rọ̀ amúsípò hàn nìkan, kì í ṣe ọ̀rọ̀ tí kò parọ́ mọ́).

## Àwọn àpẹẹrẹ API

```bash
# Kà
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# A ṣe ìṣeduro rẹ̀ fún hírí ìrònú Codex / Desktop
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Àwòrán ètò (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier` jẹ́ àṣàyàn.

### Ìtọ́jú iye / ìtunbẹ̀rẹ̀

A tọ́jú iye náà sábẹ́ kọ́kọ́rọ́ ààtò `thinkingBudget`, a sì ń gbé e wọlé nígbà ìbẹ̀rẹ̀ iṣẹ́ (`hydrateThinkingBudgetConfig`). Lẹ́yìn yíyí i padà nípasẹ̀ DB tàbí àwọn ọ̀nà mìíràn tí kì í ṣe API, **tun iṣẹ́ OmniRoute bẹ̀rẹ̀** kí singleton inú ìrántí lè bá disiki mu.

## Àkójọ ìṣàyẹ̀wò olùdarí

- [ ] Àwọn aṣàmúlò Codex / Desktop: ìpo = **passthrough**
- [ ] Jẹ́ kí ìfúnpọ̀ ṣì ṣiṣẹ́ bí o bá fẹ́ dín lílo token kù lórí **àwọn ìfiránṣẹ́**, kì í ṣe nípa yíyọ ìrònú kúrò
- [ ] Má ṣe retí pé `auto` yóò “fi ìrònú púpọ̀ sí i hàn”
- [ ] Àwọn àkópọ̀ tí a parọ́ mọ́ nìkan jẹ́ ìhùwàsí **olùpèsè**; passthrough kò lè tú wọn kúrò nínú ìparọ́mọ́
