Ìtọ́sọ́nà pípé fún lílo Codex CLI tí a tọ́ka sí OmniRoute gẹ́gẹ́ bí olùpèsè ẹ̀yìn tó bá OpenAI mu.

---

> **TOML nìkan ni ọ̀nà tó munadoko.** Codex òde-òní máa ń ka `~/.codex/config.toml`
> nìkan ṣoṣo (a ti fìdí rẹ̀ múlẹ̀ pẹ̀lú codex-cli 0.147.0: `codex --help` ṣàkọsílẹ̀
> pé àwọn àtúnṣe `-c/--config` jẹ́ èyí tí a “kó láti inú `~/.codex/config.toml`”). `~/.codex/config.yaml`
> àtijọ́ jẹ́ ti npm CLI ogún, a sì máa ń kọjá rẹ̀ láìsọ ohunkóhun.
> Ẹ̀rọ amújáde dasibodu (`/api/cli-tools/apply`, irinṣẹ́ `codex`) máa ń kọ TOML pẹ̀lú
> ìdapọ̀ oníṣọ́ra — àwọn kọ́kọ́rọ́ tó ti wà àti àwọn búlọ́ọ̀kù olùpèsè mìíràn ni a dáàbò bò, kọ́kọ́rọ́
> API sì máa ń dúró sínú `OMNIROUTE_API_KEY` (kì í sí nínú fáìlì láé), a ó sì jabo
> `config.yaml` ogún tó ṣẹ́ kù gẹ́gẹ́ bí àkíyèsí ìṣílọ láìfọwọ́ kàn án.

## config.toml tó ti ṣetán láti lẹ̀ mọ́lẹ̀

Fi àwọn iye rẹ rọ́pò `<YOUR_HOST>` àti `<YOUR_KEY>`:

```toml
# ~/.codex/config.toml
model                          = "cx/gpt-5.5"
model_provider                 = "omniroute"
model_reasoning_effort         = "xhigh"
model_context_window           = 400000
model_auto_compact_token_limit = 350000
tool_output_token_limit        = 32768    # òpin ìpamọ́ ìtàn fún ìpè irinṣẹ́ kọ̀ọ̀kan

[model_providers.omniroute]
name                 = "OmniRoute"
base_url             = "http://<YOUR_HOST>:20128/v1"
env_key              = "OMNIROUTE_API_KEY"
requires_openai_auth = false
wire_api             = "responses"
```

```bash
# ~/.bashrc tàbí ~/.zshrc — iye kọ́kọ́rọ́ gidi, kì í sí nínú config.toml láé
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

### macOS: Codex tí a kó sínú ohun èlò ChatGPT

Tí o bá fi Codex sílẹ̀ nípasẹ̀ ohun èlò ori kọ̀ǹpútà ChatGPT, binary `codex` lè
wà nínú àkójọpọ̀ ohun èlò náà nìkan, kó má sì tíì wà lórí `PATH` shell rẹ. Ṣàfikún
àpò ìtọ́kasí àwọn ohun àmúlò náà sí fáìlì ìbẹ̀rẹ̀ shell rẹ:

```bash
export PATH="/Applications/ChatGPT.app/Contents/Resources:$PATH"
```

Ṣí shell tuntun, lẹ́yìn náà ṣàyẹ̀wò:

```bash
command -v codex
codex --version
```

### OmniRoute agbègbè tí kò nílò ìfàṣẹ̀sí: kọ́kọ́rọ́ afipò ti tó

Codex máa ń fìdí rẹ̀ múlẹ̀ pé oníyí àyíká tí `env_key` dárúkọ wà
**kí** ìbéèrè àkọ́kọ́ tó kúrò nínú CLI. Tí àpẹẹrẹ OmniRoute **agbègbè** rẹ
kò bá nílò ìfàṣẹ̀sí, afipò èyíkéyìí tí kò ṣófo yóò ṣiṣẹ́:

```bash
export OMNIROUTE_API_KEY="${OMNIROUTE_API_KEY:-local}"
```

Lo kọ́kọ́rọ́ gidi dípò rẹ̀ nígbà tí olupin OmniRoute rẹ bá ní ààbò tàbí tó wà ní jíjìnnà.

> **Àwọn àṣàyàn host tó wọ́pọ̀**
>
> | Ìráyè             | URL                           |
> | ----------------- | ----------------------------- |
> | Nẹ́tíwọ́ọ̀kì agbègbè | `http://192.168.0.1:20128/v1` |
> | Tailscale         | `http://100.x.x.x:20128/v1`   |
> | Loopback          | `http://localhost:20128/v1`   |

## `wire_api = "responses"` — ìdí tó fi ń ṣiṣẹ́ fún gbogbo àwọn model

Codex CLI fòpin sí lílo `wire_api = "chat"` (Chat Completions) ní February 2026, ó sì ń **béèrè** `wire_api = "responses"` (OpenAI Responses API) báyìí. Ṣíṣètò `wire_api = "chat"` máa ń fa ìjákulẹ̀ lẹ́sẹ̀kẹsẹ̀ nígbà ìbẹ̀rẹ̀ láti v0.138.

Ọ̀pọ̀ àwọn olùpèsè, pẹ̀lú GLM àti Kimi, ṣì ń pèsè endpoint Chat Completions nìkan. DeepSeek V4 ti ń pèsè Responses API abinibi báyìí, pẹ̀lú endpoint tó bá Anthropic mu; OmniRoute máa ń lo Responses ní àkọ́kọ́, ó sì ń jẹ́ kí ìsopọ̀ DeepSeek kọ̀ọ̀kan yan ìbámu Anthropic.

**OmniRoute máa ń yanjú èyí láìjẹ́ kó hàn sí ọ:**

```
Codex CLI
  → wire_api = "responses"
  → POST /v1/responses (OmniRoute)
    → OmniRoute máa ń yan ìlànà abinibi olùpèsè, ó sì ń túmọ̀ rẹ̀ nígbà tó bá yẹ
    → POST /responses (DeepSeek V4) tàbí /chat/completions (Mistral / GLM / Kimi / àwọn mìíràn)
```

O kò nílò proxy ìtumọ̀ lọ́tọ̀ nígbà tí o bá ń lo OmniRoute. **Gbogbo àwọn model ló ń lo `wire_api = "responses"`** — OmniRoute máa ń bójú tó ìyókù.

> **`wire_api` ni àiyẹsẹ̀** — iye àiyẹsẹ̀ pápá náà ni `"responses"`, a sì lè yọ ọ́ kúrò pátápátá nínú `config.toml`. Ṣètò rẹ̀ ní tààrà nìkan tí o bá fẹ́ ṣàkọsílẹ̀ ète rẹ.

## Fèrèsé àyíká ọ̀rọ̀ àti ìṣopọ̀

### Àwọn pápá ìṣètò token

| Pápá                             | Àpèjúwe                                                                                                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `model_context_window`           | Àpapọ̀ ìwọ̀n token fún model tó ń ṣiṣẹ́. Ṣètò rẹ̀ sí òpin tí model náà kéde.                                                                                                             |
| `model_auto_compact_token_limit` | Ààlà tó máa ń fa ìṣopọ̀ ìtàn aládàáṣiṣẹ́. **Èyí tó pọ̀ jù: 90% ti `model_context_window`** — a ó kọbi ara sí àwọn iye tó ju 90% lọ láìsọ.                                               |
| `tool_output_token_limit`        | Òpin iye token tí a fi pamọ́ fún àbájáde ìpè irinṣẹ́ kọ̀ọ̀kan nínú ìtàn. Ó ń dènà àbájáde irinṣẹ́ ńlá kan láti kún fèrèsé náà. **Èyí kì í ṣe àbájáde tó pọ̀ jù** — òpin ibi ìpamọ́ ìtàn ni. |
| `compact_prompt`                 | Àtúnṣe inú-láìnì fún system prompt tí a lò nígbà ìṣopọ̀ (v0.138+).                                                                                                                    |

> **Àkíyèsí nípa `model_max_output_tokens`**: Pápá yìí **kì í ṣe apá kan nínú schema ìṣètò Codex CLI** (kò sí nínú codebase Codex Rust). A ó kọbi ara sí i láìsọ bí a bá ṣètò rẹ̀. Má ṣe gbára lé e — lo `tool_output_token_limit` láti ṣàkóso iye àbájáde irinṣẹ́ tí a fi pamọ́ sínú ìtàn.

## Ìsapá Ìrònú

Ó ń ṣàkóso bí model ṣe máa “ronú” tó kí ó tó dáhùn.

| Iye      | Lò ó fún                                           |
| -------- | -------------------------------------------------- |
| `none`   | Kò sí ìrònú — ìdáhùn tààrà                         |
| `low`    | Àwọn iṣẹ́ rírọrùn (tún orúkọ sọ, ṣe àgbékalẹ̀)       |
| `medium` | **Àìyípadà server** nígbà tí a kò bá sọ ọ́          |
| `high`   | Àwọn iṣẹ́ agbedeméjì (àtúnṣe kóòdù, ìṣàtúnṣe àṣìṣe) |
| `xhigh`  | Àwòrán ètò, àyẹ̀wò jíjinlẹ̀, àwọn ìṣòro dídíjú       |

```bash
# Yípadà fún ìpè kọ̀ọ̀kan
codex -c model_reasoning_effort=low "rename variable x to count"
codex -c model_reasoning_effort=xhigh "design the auth module"
```

Tún ṣètò **àkótán** ìrònú kí Desktop lè ṣàfihàn ọ̀rọ̀ ìrònú (kì í ṣe àwọn ìdìpọ̀ tí a parọ́ mọ́ nìkan):

```toml
# ~/.codex/config.toml
model_reasoning_effort = "xhigh"   # tàbí ultra nígbà tí ó bá ní àtìlẹ́yìn
model_reasoning_summary = "detailed"  # auto | concise | detailed | none
```

### Ìwọ̀n Ìrònú OmniRoute (ètò server)

Lórí host OmniRoute, **Settings → AI → Thinking Budget** gbọ́dọ̀ jẹ́ **`passthrough`** kí ìsapá/àkótán Codex lè dé ọ̀dọ̀ upstream. Ipo **`auto` máa ń yọ** gbogbo àwọn field `reasoning` / `reasoning_effort` ti client kúrò, yóò sì sọ àwọn panel ìrònú di òfìfo kódà bí a bá ti ṣètò Codex lọ́nà tó tọ́.

Ìtọ́sọ́nà kíkún: [THINKING_BUDGET.md](./THINKING_BUDGET.md).

Ìfúnpọ̀ àti cache prompt jẹ́ olómìnira, wọ́n sì ń bá a lọ láti ṣiṣẹ́ lábẹ́ `passthrough`.

## Àwọn Profile — àwọn àtòjọ-ètò olórúkọ fún model/ìṣàn-iṣẹ́ kọ̀ọ̀kan

Àwọn profile jẹ́ kí o yí model + window context padà pẹ̀lú flag kan ṣoṣo. Profile kọ̀ọ̀kan jẹ́ fáìlì pẹlẹbẹ
`~/.codex/<name>.config.toml` tí ó bo `config.toml` ìpìlẹ̀ lé lórí.

> **Òfin fífún ní orúkọ (Codex CLI v0.137+):** fáìlì náà gbọ́dọ̀ jẹ́ `~/.codex/<name>.config.toml` — **kò gbọdọ̀ ní àmì ìbẹ̀rẹ̀ `profile-`**.
> CLI máa túmọ̀ `-p kimi-k27` sí `~/.codex/kimi-k27.config.toml`. Bí kò bá rí fáìlì náà, ètò àìyípadà máa ṣiṣẹ́ láìsọ ohunkóhun.

```bash
codex --profile kimi-k27 "analyze 10k lines of this codebase"
codex -p glm52 "architecture review"
codex --profile deepseek-flash "rename variable"   # yára, kò gbówó púpọ̀
```

### Àwọn profile ìsapá (model kan náà, ìsapá ọ̀tọ̀ọ̀tọ̀)

```bash
codex -p low      # cx/gpt-5.5, ìsapá=low
codex -p medium   # cx/gpt-5.5, ìsapá=medium
codex -p high     # cx/gpt-5.5, ìsapá=high
codex -p xhigh    # cx/gpt-5.5, ìsapá=xhigh (àìyípadà)
codex -p chat     # cx/gpt-5.5, kò ṣètò ìsapá (àìyípadà server)
```

## Ṣíṣẹ̀dá àwọn profaili láìfọwọ́ṣe pẹ̀lú `omniroute setup-codex`

Tí o bá ń ṣiṣẹ́ OmniRoute lórí VPS, o lè ṣẹ̀dá àwọn fáìlì profaili láìfọwọ́ṣe láti inú àkójọ àwọn módẹ́lì tó ń ṣiṣẹ́:

```bash
# Láti VPS kan (ó ń lo OmniRoute agbègbè lórí port 20128)
omniroute setup-codex

# Láti ẹ̀rọ èyíkéyìí — tọ́ka sí VPS rẹ
omniroute setup-codex --remote http://100.x.x.x:20128 --api-key sk-xxx

# Ṣàkọ́wò láìkọ fáìlì kankan
omniroute setup-codex --remote http://100.x.x.x:20128 --dry-run

# Ṣẹ̀dá àwọn profaili GLM àti Kimi nìkan
omniroute setup-codex --only glm,kimi

# Kọ ọ́ sí àkọsílẹ̀ àkànṣe kan
omniroute setup-codex --codex-home /path/to/.codex
```

Àṣẹ náà máa ń gba `/v1/models`, ó ń lo àwọn profaili tí a ti ṣètò dáadáa fún àwọn módẹ́lì tí a mọ̀, ó máa ń lo metadata àkójọ gẹ́gẹ́ bí àfidípò fún àwọn módẹ́lì ọ̀rọ̀ míì tó bá mu, ó sì ń kọ `~/.codex/<name>.config.toml` fún ọ̀kọ̀ọ̀kan. Ó jẹ́ aláìyípadà nígbà àtúnsí — ó láìléwu láti tún un ṣiṣẹ́.

OmniRoute tún lè **mú àwọn fáìlì profaili kan náà bára mu láìfọwọ́ṣe** lẹ́yìn tí ìṣàwárí/ìkó wọlé àwọn módẹ́lì olùpèsè bá ṣàṣeyọrí tí ó sì yí àkójọ tó ń ṣiṣẹ́ padà. **O gbọ́dọ̀ yàn án fúnra rẹ, ó sì wà ní pípa ní ìbẹ̀rẹ̀**: tan-an láti **CLI Code dashboard** ("CLI profile auto-sync" → Codex), tàbí ṣètò `OMNIROUTE_AUTO_SYNC_CODEX_PROFILES=true` (ó tún ń tẹ̀lé `CLI_ALLOW_CONFIG_WRITES`, èyí tó wà ní títàn ní ìbẹ̀rẹ̀). Nígbà tí a bá tan-an, àwọn fáìlì profaili `~/.codex/*.config.toml` ọ̀tọ̀ọ̀tọ̀ nìkan ni ó máa ń kọ; kò ní yí `~/.codex/config.toml` tó ń ṣiṣẹ́/tí a yàn gẹ́gẹ́ bí àkọ́kọ́, àwọn ètò Codex-lb, ìfàṣẹsí, tàbí yíyan olùpèsè padà láé.

## Àwọn iṣẹ́ tó ń gba àkókò pípẹ́

Àwọn àtòlẹ́sẹẹsẹ àìyípadà OmniRoute méjì lè ba àwọn session Codex CLI tó ń gba ọ̀pọ̀ wákàtí jẹ́ láìsí ìkìlọ̀. Kò sí èyíkéyìí nínú wọn tó jẹ́ ètò Codex CLI — àwọn méjèèjì wà ní ẹ̀gbẹ́ OmniRoute. Àwọn olùlò tó ń ṣí config kan láti àwọn proxy upstream tí wọ́n di account mọ́lẹ̀ tí wọ́n sì pa àwọn ìgéwọ̀n àkókò àìṣiṣẹ́ lè sábà dojú kọ àwọn méjèèjì, kí wọ́n sì parí èrò sí pé OmniRoute “kò lè mú session gígùn dúró.”

| Àmì àìsàn                                                                   | Ohun tó ṣeé ṣe kó fà á                                           | Knob                     |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------------ |
| Session ń yí account padà / ìtẹ̀síwájú prompt-cache ń sọnù láàárín àwọn turn | TTL ìbámu session jẹ́ `0` (a ti mú un má ṣiṣẹ́)                    | `sessionAffinityTtlMs`   |
| Ìsopọ̀ kú láàárín ìrònú láìsí prompt kankan tó dé ọ̀dọ̀ client                 | Alábojútó àìṣiṣẹ́ stream ṣiṣẹ́ lẹ́yìn ìṣẹ́jú 10 láìsí chunk upstream | `STREAM_IDLE_TIMEOUT_MS` |

Àwọn ìjíròrò tó jẹmọ́: [#7126](https://github.com/diegosouzapw/OmniRoute/discussions/7126) (àwọn iṣẹ́ gígùn ń jábọ̀), [#5718](https://github.com/diegosouzapw/OmniRoute/discussions/5718) (ìdí tí affinity fi jẹ́ pípa ní àìyípadà). Ìtọ́pa: [#7287](https://github.com/diegosouzapw/OmniRoute/issues/7287).

### 1. Ìbámu session — di ìjíròrò kan mọ́ account kan

**Àìyípadà:** `sessionAffinityTtlMs = 0` (a ti mú un má ṣiṣẹ́).

**Ibi tí a ti lè ṣètò rẹ̀**

- Dashboard → **Settings → Routing** → **Session affinity** → **Affinity TTL (seconds)** (`ComboDefaultsTab`)
- Tàbí ṣe PATCH sí àwọn settings pẹ̀lú `sessionAffinityTtlMs` ní **milliseconds** (ààyè Zod `0`–`86_400_000`, ìyẹn ni pé ó tó wákàtí 24)

> A tún orúkọ rẹ̀ sọ ní #7274 láti inú `codexSessionAffinityTtlMs` tó jẹ́ ti Codex nìkan. A ṣì gba key àtijọ́ gẹ́gẹ́ bí alias kíkà-nìkan; àwọn config tuntun gbọ́dọ̀ lo `sessionAffinityTtlMs`. Ní báyìí, affinity kan **èyíkéyìí** provider nígbà tí TTL bá ga ju `0` lọ, kì í ṣe Codex nìkan — wo [`docs/architecture/RESILIENCE_GUIDE.md`](../architecture/RESILIENCE_GUIDE.md) → Ìbámu session.

**Ohun tó máa bàjẹ́ tí ó bá dúró sí 0**

A máa route turn kọ̀ọ̀kan nínú ìjíròrò Codex onírúurú turn lọ́tọ̀ọ̀tọ̀ nípasẹ̀ ọ̀nà combo tó ń ṣiṣẹ́, ó sì lè dé orí **account tó yàtọ̀ fún turn kọ̀ọ̀kan**. Ìyẹn ń ba ìtẹ̀síwájú session / prompt-cache upstream jẹ́. OmniRoute máa ń wo àwọn header session Codex (`x-codex-session-id` / `x-session-id` / `x-omniroute-session`) àti àwọn ààyè body bíi `prompt_cache_key` / `session_id` nìkan nígbà tí TTL bá ga ju `0` lọ (`extractSessionAffinityKey` nínú `src/sse/services/auth.ts`).

**Àbá fún iṣẹ́ ẹyọ kan tó ń gba ọ̀pọ̀ wákàtí**

Ṣètò TTL sí iye tó **ga ju gígùn àkókò gidi tí a retí pé iṣẹ́ náà máa gba** (iye tó pọ̀jù ní UI jẹ́ **86400 seconds** = wákàtí 24):

| Gígùn iṣẹ́ tí a retí | Affinity TTL (UI, seconds) | `sessionAffinityTtlMs` |
| ------------------- | -------------------------- | ---------------------- |
| Wákàtí díẹ̀          | `14400` (4h)               | `14400000`             |
| Mọ́júmọ́jú / ~12h     | `43200` (12h)              | `43200000`             |
| Ọjọ́ kan gbáko       | `86400` (24h, iye tó pọ̀jù) | `86400000`             |

Yíyan láti darapọ̀ jẹ́ ìpinnu amúmúṣẹ: mímú affinity má ṣiṣẹ́ ń ṣe ànfààní fífi ẹrù pín káàkiri àwọn account; mímú un ṣiṣẹ́ ń ṣe ànfààní ìtẹ̀síwájú fún session agent gígùn kan. Ìtọ́sọ́nà yìí **kò** yí àìyípadà padà — àwọn olùṣàkóso tó ń ṣiṣẹ́ àwọn iṣẹ́ Codex gígùn gbọ́dọ̀ yàn láti mú un ṣiṣẹ́.

### 2. Àkókò ìparí àìṣiṣẹ́ stream — má ṣe pa àwọn turn ìrònú tó dákẹ́

**Àìyípadà:** `STREAM_IDLE_TIMEOUT_MS = 600000` (ìṣẹ́jú 10). Ó máa jogún láti `REQUEST_TIMEOUT_MS` tí a kò bá ṣètò rẹ̀; ìpìlẹ̀ tí wọ́n pín náà tún jẹ́ 600000. Wo [`docs/guides/SETUP_GUIDE.md`](SETUP_GUIDE.md) → Àwọn àkókò ìparí.

**Ohun tó máa bàjẹ́ ní àìyípadà**

Ìgbà ìrònú / lílo irinṣẹ́ Codex kan tí ó dákẹ́ fún ju ìṣẹ́jú 10 lọ láìsí **ẹyọ dátà gidi láti upstream** ni SSE idle watchdog (`open-sse/utils/stream.ts`) máa ń fi tipátipá pa. Ní ọ̀pọ̀ ìgbà, client máa ń rí bí asopọ̀ ṣe já lásán — èyí bá “ó dá dúró fúnra rẹ̀ láìsí ìfitónilétí kankan” mu.

Àlàyé pàtàkì: SSE **heartbeat àfọwọ́ṣe ti OmniRoute kì í tún** aago àìṣiṣẹ́ bẹ̀rẹ̀. Ẹyọ body gidi láti upstream nìkan ló ń ṣe àfikún `lastChunkTime`. Model tí ó dákẹ́ ṣùgbọ́n tí ó ṣì ń “ronú” dà bí upstream tí ó dúró pátápátá lójú watchdog.

Àìṣiṣẹ́ body Undici tó ní í ṣe pẹ̀lú èyí: `FETCH_BODY_TIMEOUT_MS` (ó tún máa ń lo ìpìlẹ̀ ìṣẹ́jú 10 kan náà gẹ́gẹ́ bí default; `0` máa ń pa á). Fún streaming, `FETCH_TIMEOUT_MS` kàn ń bo ìṣètò asopọ̀ / headers àkọ́kọ́ — lẹ́yìn tí stream bá ti ń ṣiṣẹ́, `STREAM_IDLE_TIMEOUT_MS` àti `FETCH_BODY_TIMEOUT_MS` ni wọ́n ń ṣàkóso àwọn ìdúró.

**Ohun tí a dábàá fún iṣẹ́ ẹyọ kan tó lè gba ọ̀pọ̀ wákàtí**

Nínú environment process OmniRoute (`.env` / compose / systemd):

```bash
# Pa àwọn ìdíwọ́ àìṣiṣẹ́ stream àti body fún àwọn ìgbà ìrònú gígùn
STREAM_IDLE_TIMEOUT_MS=0
FETCH_BODY_TIMEOUT_MS=0
```

Tàbí gbé wọn ga ju àkókò ìdákẹ́jẹ tó gùn jù lọ tí o ń retí lọ (milliseconds ni àwọn iye náà):

```bash
# Àpẹẹrẹ: gba ìdákẹ́jẹ tó tó wákàtí 2 láàárín àwọn ẹyọ upstream láàyè
STREAM_IDLE_TIMEOUT_MS=7200000
FETCH_BODY_TIMEOUT_MS=7200000
```

Tún OmniRoute bẹ̀rẹ̀ lẹ́yìn títún àwọn env vars wọ̀nyí ṣe.

### Ìlànà tó ṣe pàtó — iṣẹ́ Codex tó gba ọ̀pọ̀ wákàtí

1. **So account náà mọ́ ibi kan:** Dashboard → Settings → Routing → Session affinity → Affinity TTL = `43200` (12h) tàbí `86400` (24h max).
2. **Gbé àwọn ìdíwọ́ àìṣiṣẹ́ ga / pa wọ́n** nínú environment OmniRoute:

```bash
STREAM_IDLE_TIMEOUT_MS=0
FETCH_BODY_TIMEOUT_MS=0
```

3. Pa `config.toml` Codex tí a sábà máa ń lò mọ́ (`wire_api = "responses"`, `base_url` tó tọ́, `OMNIROUTE_API_KEY`) — kò sí àwọn àṣàyàn affinity/idle ní ẹ̀gbẹ́ Codex fún àwọn ìhùwàsí méjèèjì wọ̀nyí.
4. Tún OmniRoute bẹ̀rẹ̀, lẹ́yìn náà bẹ̀rẹ̀ iṣẹ́ Codex gígùn náà.

### Ìpinnu àwọn default (#7287)

| Àṣàyàn                   | Default tí a pín ká | Ṣé a yí i padà nínú ìtọ́sọ́nà yìí?                                                                        |
| ------------------------ | ------------------- | ------------------------------------------------------------------------------------------------------- |
| `sessionAffinityTtlMs`   | `0` (off)           | **Rárá** — ó ṣì jẹ́ opt-in (load-balancing vs continuity; wo Discussion #5718)                           |
| `STREAM_IDLE_TIMEOUT_MS` | `600000` (10 min)   | **Rárá** — ó ṣì jẹ́ ìṣẹ́jú 10 fún traffic gbogbogbòò; àwọn olùṣàkóso Codex gígùn máa ń gbé e ga tàbí pa á |

Yíyí èyíkéyìí nínú àwọn default náà padà ní gbogbo ètò yóò yí ìhùwàsí padà fún gbogbo client instance kan, kì í ṣe Codex nìkan. Ṣàkọsílẹ̀ àwọn àṣàyàn náà; fi àwọn default náà sílẹ̀ bí wọ́n ṣe wà títí ìpinnu olùṣàkóso tó ṣe kedere yóò fi sọ ohun mìíràn.

### Ṣíṣàyẹ̀wò àwọn ìdáwọ́ àìṣiṣẹ́

Nígbà tí idle watchdog bá ṣiṣẹ́, OmniRoute máa ń kọ line kan tó rí báyìí sínú log:

```text
[STREAM] Idle timeout: no data from codex for 600000ms (model: cx/gpt-5.5)
```

Lo grep láti wá `Idle timeout: no data from` (tàbí code `stream_idle_timeout` / orúkọ error `StreamIdleTimeoutError`). Apá provider náà ni ohunkóhun tí OmniRoute lò fún request yẹn (`codex`, provider id mìíràn, tàbí `provider` bí a kò bá mọ̀ ọ́) — kì í ṣe string `codex` gangan ní gbogbo ìgbà.

## Ìṣàtúnṣe Ìṣòro

**`Error: wire_api = "chat" is no longer supported`**
Yọ `wire_api = "chat"` kúrò nínú àtòjọ ìṣètò rẹ. Ṣètò `wire_api = "responses"` tàbí má fi pápá náà sílẹ̀ (ó ti máa ń lo `"responses"` gẹ́gẹ́ bí ìṣètò àkọ́kọ́ láti v0.138).

**`Error: model not found`**
Ṣàyẹ̀wò pé model náà wà nínú OmniRoute pẹ̀lú prefix tó tọ́. Lo `omniroute models list` tàbí ṣí `/dashboard/providers/<provider>`.

**`Authentication error`**
Jẹ́rìí pé a ti export `OMNIROUTE_API_KEY`: `echo $OMNIROUTE_API_KEY`.

**`ERROR: Missing environment variable: OMNIROUTE_API_KEY`**
Codex máa ń jẹ́rìí pé env var náà wà kí ó tó ṣe ìbéèrè àkọ́kọ́. Export
kọ́kọ́rọ́ gidi fún àwọn server tí a dáàbò bò, tàbí placeholder tí kò ṣófo bíi
`OMNIROUTE_API_KEY=local` nígbà tí instance OmniRoute **local** rẹ kò
béèrè auth. Tun shell náà bẹ̀rẹ̀ bí o bá fi kún `~/.bashrc` tàbí `~/.zshrc`.

**`Connection refused`**
Ṣàyẹ̀wò pé OmniRoute ń ṣiṣẹ́ àti pé host/port `base_url` tọ́ fún network rẹ (local sí Tailscale sí VPS).

**Session ń já nígbà tó bá sún mọ́ context limit**
Ṣètò `model_context_window` àti `model_auto_compact_token_limit` ní kedere. Wo tábìlì context window tó wà lókè.

**Compaction ń ṣiṣẹ́ pẹ́ jù**
Dín `model_auto_compact_token_limit` kù sí 80–85% window náà. Má ṣe ṣètò rẹ̀ ju 90% lọ láé.

**Profile kò ṣiṣẹ́ (`-p <name>` ni a kọjá láìsọ ohunkóhun)**
Jẹ́rìí pé fáìlì náà wà ní `~/.codex/<name>.config.toml` (láìsí prefix `profile-`). Ṣiṣe `ls ~/.codex/*.config.toml`.

**Iṣẹ́ Codex tó gùn ń dáwọ́ dúró láàárín ìṣiṣẹ́ / ń yí account padà láàárín àwọn turn**
Wo [Àwọn iṣẹ́ tó ń ṣiṣẹ́ fún ìgbà pípẹ́](#long-running-tasks). Mú session affinity ṣiṣẹ́ (TTL tó ju gígùn iṣẹ́ náà lọ), kí o sì mú `STREAM_IDLE_TIMEOUT_MS` / `FETCH_BODY_TIMEOUT_MS` ga tàbí kí o pa wọ́n. Lo grep láti wá `Idle timeout: no data from` nínú àwọn log OmniRoute.
