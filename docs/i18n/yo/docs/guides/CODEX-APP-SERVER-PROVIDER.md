OmniRoute ń pèsè ọ̀nà **méjì** láti lo OpenAI Codex:

| Olùpèsè                | Bí ó ṣe ń bá OpenAI sọ̀rọ̀                                                                                                                                                                         | Ìkìlọ̀ nípa lílò                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| **`codex`**            | Ó tún ń fi tọ́kìnì ChatGPT/OpenAI OAuth rẹ ránṣẹ́ tààrà sí Responses API                                                                                                                           | **Bẹ́ẹ̀ ni** — a kò fún sáẹ́ṣọ̀nù oníṣẹ́ náà láṣẹ fún lílò proxy/router |
| **`codex-app-server`** | Ó ń darí **`codex app-server` ti Codex CLI fúnra rẹ̀** lórí JSON-RPC/WebSocket; CLI náà ni ó ni OAuth rẹ̀, ó sì ń sọ ọ́ di ọ̀tun fúnra rẹ̀ (`~/.codex/auth.json`) gan-an bí sáẹ́ṣọ̀nù `codex` alábáṣepọ̀ | **Rárá** — OmniRoute kì í tún tọ́kìnì kan ránṣẹ́ sí API láé          |

Nítorí pé `codex-app-server` kì í tún tọ́kìnì kan ránṣẹ́ láé, ìkìlọ̀ lílò
nípa ṣíṣàtúnránṣẹ́ sáẹ́ṣọ̀nù kò kan án. Ó nílò **Codex CLI tí OmniRoute lè dé
ní URL app-server tí a ti ṣètò**, CLI náà sì gbọ́dọ̀ ti **wọlé**.

---

## 1. Àwòrán-ilana

```
┌─ Ìṣàfilọ́lẹ̀ OmniRoute ──────────┐        ┌─ sidecar codex-app-server ──────────┐
│  CodexAppServerExecutor          │  WS    │  codex app-server                   │
│  ws://codex-app-server:1456 ─────┼───────▶│  --listen ws://0.0.0.0:1456         │
│  (+ tọ́kìnì agbára)              │  JSON  │  --ws-auth capability-token         │
│                                  │  RPC   │  ń ṣàkóso OpenAI OAuth fúnra rẹ̀    │
└──────────────────────────────────┘        │  (~/.codex/auth.json, ìmúdójúìwọ̀n  │
        │ ń pín (àwọn volume compose)       │   aládàáṣe)                          │
        ▼                                   └─────────────────────────────────────┘
  codex-appserver-token   → tọ́kìnì agbára WS (àwọn méjèèjì ni wọ́n mount rẹ̀)
  codex-appserver-home    → ~/.codex (auth.json tí dashboard kọ,
                             tí codex app-server sidecar náà kà)
```

- Sidecar náà ń tẹ́tí **nikan** lórí nẹ́tíwọ́ọ̀kì compose inú
  (`ws://codex-app-server:1456`) lẹ́yìn tọ́kìnì agbára kan. A **kò** tẹ̀ ẹ́ jáde
  sí host tàbí íńtánẹ́ẹ̀tì láé.
- Codex CLI wà nínú `omniroute:base` láti ìbẹ̀rẹ̀, nítorí náà kò sí ìdí láti
  fi codex sori host tàbí ẹ̀rọ onílò nígbà tí o bá ń ṣiṣẹ́ sidecar náà.

## 2. Gbé e dìde

```bash
# Bẹ̀rẹ̀ stack PẸ̀LÚ profile sidecar codex app-server:
docker compose --profile base --profile codex-app-server up -d
# (podman: podman compose --profile base --profile codex-app-server up -d)
```

Sidecar náà ń ṣẹ̀dá tọ́kìnì agbára WS rẹ̀ ní ìgbà àkọ́kọ́ tí ó bá bẹ̀rẹ̀ (sínú
volume `codex-appserver-token` tí a ń pín), ìṣàfilọ́lẹ̀ náà sì ń ka tọ́kìnì kan
náà nípasẹ̀ `OMNIROUTE_CODEX_APPSERVER_WS_TOKEN_FILE`. Kò nílò àsopọ̀ tọ́kìnì
pẹ̀lú ọwọ́.

## 3. Sopọ̀ + wọlé

1. Nínú dashboard, ṣàfikún àsopọ̀ kan fún **OpenAI Codex (App-Server)**. Kò nílò
   kọ́kọ́rọ́ API tàbí tọ́kìnì (olùpèsè tí kò nílò ìfàṣẹsí ni — sidecar náà ni ó
   ni ìfàṣẹsí).
2. Tí Codex CLI sidecar náà **kò bá tíì wọlé**, àyẹ̀wò ìlera àsopọ̀ náà yóò
   sọ pé _"ó ń ṣiṣẹ́ ṣùgbọ́n kò tíì wọlé"_ (kì í ṣe àṣìṣe ìfàṣẹsí pupa). Lo
   **Wọlé pẹ̀lú ChatGPT**: èyí máa ń ṣiṣẹ́ device-OAuth Codex boṣewa nínú
   aṣàwákiri rẹ, lẹ́yìn náà yóò kọ `~/.codex/auth.json` sínú volume tí a ń pín
   nípasẹ̀ **Lo ìfàṣẹsí** (ìwọlé kan náà ni ó ń ṣiṣẹ́ fún àwọn olùpèsè `codex`
   àti `codex-app-server` méjèèjì).
3. Lẹ́yìn tí o bá wọlé, àyẹ̀wò ìlera yóò di aláwọ̀ ewé (ó ń ṣàyẹ̀wò `/readyz`
   **àti** `account/read` — ìyẹn ni pé ó wà nílẹ̀ _ó sì_ ti gba ìfàṣẹsí), iṣẹ́
   yóò sì bẹ̀rẹ̀.

Dashboard kì í kọ àkóónú tuntun bo `~/.codex/auth.json` tó wà ní ìlera láé —
ó ń kọ̀wé nígbà tí fáìlì náà kò bá sí tàbí tí tọ́kìnì rẹ̀ bá ti di àtijọ́ nìkan
(a máa ń ṣe àdàkọ-afẹ́yinti ní gbogbo ìgbà).

## 4. Àwọn ipò ìmúṣiṣẹ́

- **Olùṣàkóso tó ní Codex CLI tí ó ti gba ìfàṣẹsí tẹ́lẹ̀** — mount `~/.codex`
  host rẹ sínú sidecar (`codex-appserver-home`), kí o sì fo ìgbésẹ̀ ìwọlé náà.
- **Onílò gbogbogbò, tí kò ní codex lórí ẹ̀rọ rẹ̀** — kò ṣe pàtàkì: sidecar náà
  ní CLI. Onílò náà kàn ń gba ìfàṣẹsí nípasẹ̀ dashboard.
- **OmniRoute bare-metal (kò sí sidecar, codex host)** — tọ́ka
  `OMNIROUTE_CODEX_APPSERVER_WS` sí `codex app-server` tirẹ, kí o sì rí i dájú
  pé codex host ti wọlé; ìmọ̀ràn "a kò fi codex sori ẹrọ" yóò hàn tí binary náà
  kò bá sí.

## 5. Residential / UDP egress (àfikún olùṣàkóso, a kò fi í sínú ohun tí a pín)

Sidecar gbogbogbò lókè ń jáde nípasẹ̀ nẹ́tíwọ́ọ̀kì déédéé container náà.
Olùṣàkóso tó nílò kí ìrìn-àjò Codex jáde nípasẹ̀ **residential exit** (fún àpẹẹrẹ,
sidecar tailscale TUN tó ń gbé TCP + UDP/QUIC) yóò ṣiṣẹ́ èyí gẹ́gẹ́ bí compose
override ọ̀tọ̀; a mọ̀ọ́mọ̀ **kò** fi í sínú profile `codex-app-server` tí a pín.
Wo ìwé ìtọ́sọ́nà iṣẹ́ abẹ́nú fún ètò yẹn.
