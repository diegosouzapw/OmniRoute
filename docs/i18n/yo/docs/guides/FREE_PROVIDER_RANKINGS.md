> **Ní ṣókí**: OmniRoute ń ṣe ìpele àwọn olupèsè **ọ̀fẹ́** rẹ̀ nípa dídára àwòṣe, ní lílo àwọn **ìwọ̀n ELO Arena AI
> (ara-LMArena)**. Ṣí ojú-ewé **Ìpele Àwọn Olùpèsè Ọ̀fẹ́** nínú
> pánẹ́ẹ̀lì ìṣàkóso láti rí àwọn olupèsè ọ̀fẹ́ tí ń pèsè àwọn àwòṣe tó lágbára jù fún iṣẹ́ rẹ —
> lápapọ̀, tàbí nípasẹ̀ ṣíṣàlẹ̀mọ́ gẹ́gẹ́ bí ẹ̀ka (kíkọ kóòdù, àyẹ̀wò, ìkọ̀wé ìtọ́sọ́nà, àtúnṣe àṣìṣe).

## Ohun Tí Ó Jẹ́

OmniRoute forúkọsílẹ̀ àwọn olupèsè 329, pẹ̀lú àwọn àkọsílẹ̀ katalọ́ọ̀gù 155 tí a sàmì sí **ọ̀fẹ́/kò nílò ìfàṣẹsí**
(kò nílò ìfàṣẹsí,
OAuth onípele-ọ̀fẹ́, tàbí kọ́kọ́rọ́ API onípele-ọ̀fẹ́ — wo
[Ìtọ́sọ́nà Àwọn Ipele Ọ̀fẹ́](../getting-started/FREE-TIERS-GUIDE.md) àti
[àkójọ Àwọn Ipele Ọ̀fẹ́](../reference/FREE_TIERS.md) kíkún). Ohun tó yẹ ká kíyè sí ni pé: dídára
àwòṣe àwọn olupèsè ọ̀fẹ́ yàtọ̀ gidigidi. Olùpèsè tí kò nílò ìfàṣẹsí tí ń pèsè àwòṣe ìpele iwájú wúlò
gan-an ju èyí tó ń pèsè àwòṣe kékeré ti ìgbà àtijọ́ lọ.

**Ìpele Àwọn Olùpèsè Ọ̀fẹ́** ń dáhùn ìbéèrè náà, "**olùpèsè ọ̀fẹ́ wo ló fún mi ní àwòṣe tó dára jù?**", nípa
sísopọ̀ katalọ́ọ̀gù olùpèsè ọ̀fẹ́ kọ̀ọ̀kan mọ́ **àwọn ìwọ̀n dídára tí ọ̀pọ̀ ènìyàn kó jọ** láti
**àtẹ ìpele Arena AI** (ELO ààyò ènìyàn, èrò kan náà tó wà lẹ́yìn
pápá chatbot LMArena). Lẹ́yìn náà, a ṣe ìpele àwọn olupèsè ní ìbámu pẹ̀lú agbára **àwòṣe ọ̀fẹ́ tó dára jù** ti ọ̀kọ̀ọ̀kan wọn.

A ń ṣírò ìpele náà láti orísun gidi mẹ́ta:

1. Àwọn àkójọ olùpèsè ọ̀fẹ́ — `NOAUTH_PROVIDERS`, pẹ̀lú àwọn àkọsílẹ̀ `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` tí a fi àmì `hasFree` sí
   (`src/shared/constants/providers.ts`).
2. Katalọ́ọ̀gù àwòṣe olùpèsè kọ̀ọ̀kan láti inú àkọsílẹ̀ àwọn olupèsè
   (`open-sse/config/providerRegistry.ts`).
3. Àwọn ìwọ̀n ìbámu iṣẹ́ tí a yọ láti inú ELO, tí ẹ̀rọ ìmúdójúìwọ̀n Arena ELO
   (`src/lib/arenaEloSync.ts`) tọ́jú sínú tábìlì DB `model_intelligence`.

Ìlànà ìsopọ̀ náà wà nínú `src/lib/freeProviderRankings.ts`.

## Bí O Ṣe Lè Wọlé Sí I

### Ojú-ewé pánẹ́ẹ̀lì ìṣàkóso

Ṣí pánẹ́ẹ̀lì ìṣàkóso, kí o sì lọ sí **Àwọn Ìnáwó → Ìpele Àwọn Olùpèsè Ọ̀fẹ́**, tàbí lọ tààrà sí:

```
/dashboard/free-provider-rankings
```

Ojú-ewé náà (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) ń fi àwọn wọ̀nyí hàn:

- **Pẹpẹ àwọn mẹ́ta tó ga jù** (🥇 🥈 🥉) fún àwọn olupèsè ọ̀fẹ́ tí wọ́n ní ìpele tó dára jù.
- **Tábìlì ìpele** kíkún pẹ̀lú àwọn ọ̀wọ̀n: **Ìpele**, **Olùpèsè**, **Àwòṣe Tó Ga Jù**,
  **Ìwọ̀n**, **Ìwọ̀n Àpapọ̀**, **Àwọn Àwòṣe**, **Irú**.
- **Àwọn bọ́tìnì àsẹ ẹ̀ka**: _Gbogbo Àwọn Ẹ̀ka_, _Àiyípadà_, _Kíkọ Kóòdù_, _Àyẹ̀wò_,
  _Ìkọ̀wé Ìtọ́sọ́nà_, _Àtúnṣe Àṣìṣe_.

Báàjì **Irú** olùpèsè kọ̀ọ̀kan ń sọ bí iṣẹ́ rẹ̀ ṣe jẹ́ ọ̀fẹ́:

| Báàjì    | Ìtumọ̀                                            |
| -------- | ------------------------------------------------ |
| `NOAUTH` | Ó máa ń jẹ́ ọ̀fẹ́ nígbà gbogbo, kò nílò ẹ̀rí ìdánimọ̀ |
| `OAUTH`  | Olùpèsè OAuth tó ní ipele ọ̀fẹ́ (`hasFree`)        |
| `APIKEY` | Olùpèsè kọ́kọ́rọ́ API tó ní ipele ọ̀fẹ́ (`hasFree`)   |

A ń fi àwọn ìwọ̀n hàn gẹ́gẹ́ bí àmì tí ènìyàn lè lóye (fún àpẹẹrẹ, _Àrà Ọ̀tọ̀_, _Dára Púpọ̀_, _Dára Gan-an_,
_Dára_, _Àárín Gbùngbùn_) dípò àwọn nọ́ńbà gidi, nítorí pé iye tó wà lẹ́yìn rẹ̀ jẹ́
dídára ìpele ìfiwéra, kì í ṣe ìdá ọgọ́rùn-ún.

### Ojú-ọ̀nà API

Ojú-ewé náà ń lo ojú-ọ̀nà kíkà gbogbogbò
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Àwọn àlàyé ìbéèrè (tí a fìdí rẹ̀ múlẹ̀ pẹ̀lú Zod):

| Àlàyé      | Irú    | Àiyípadà | Àwọn àkíyèsí                                                                                        |
| ---------- | ------ | -------- | --------------------------------------------------------------------------------------------------- |
| `category` | string | (kò sí)  | Ọ̀kan lára `default`, `coding`, `review`, `documentation`, `debugging`. Yọ ọ́ kúrò fún ìpele àkójọpọ̀. |
| `limit`    | number | `50`     | A fi ààlà rẹ̀ sí àárín `1–100`.                                                                      |

Ìrísí èsì:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` ni iye Arena ELO àtilẹ̀wá; `score` ni iye ìbámu iṣẹ́ tí a ti mú sí ìwọ̀n
(wo ìsàlẹ̀). A yọ àwọn olupèsè tí kò ní àwòṣe kankan tí a ti fún ní ìwọ̀n kúrò nínú èsì náà.

## Bí Àwọn Ìwọ̀n Ṣe N Ṣiṣẹ́

### Orísun: Àtẹ Ìṣàkóso Arena AI

Ẹ̀rọ ìmúdójúìwọ̀n Arena ELO (`src/lib/arenaEloSync.ts`) máa ń gba àtẹ ìṣàkóso méjì — `text`
àti `code` — láti API àtẹ ìṣàkóso Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Gbogbo àkọsílẹ̀ inú àtẹ ìṣàkóso
ní orúkọ àwòṣe, olùpèsè, `score` ELO, àárín ìgbẹ́kẹ̀lé, àti iye ìbò.

Àwọn ẹ̀ka àtẹ ìṣàkóso bá àwọn ẹ̀ka iṣẹ́ OmniRoute mu báyìí:

| Àtẹ ìṣàkóso Arena | Àwọn ẹ̀ka iṣẹ́ OmniRoute                            |
| ----------------- | ------------------------------------------------- |
| `text`            | `default`, `review`, `documentation`, `debugging` |
| `code`            | `coding`                                          |

### Ìṣètò sí òṣùwọ̀n kan náà (ìwọ̀n ìbámu pẹ̀lú iṣẹ́)

Àwọn ìwọ̀n ELO àìṣàtúnṣe ni a máa ń ṣètò sí òṣùwọ̀n kan náà fún àtẹ ìṣàkóso kọ̀ọ̀kan sí **iye ìbámu pẹ̀lú iṣẹ́ nínú `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Ìwọ̀n náà kì í dé `0` tàbí `1`, èyí sì ń fi àyè sílẹ̀ fún àtúnṣe àwọn aṣàmúlò. Èyí ni
ààyè `score` tí o rí nínú èsì API àti àmì tí a fi hàn lórí pánẹ́ẹ̀lì ìṣàkóso.

### Ìgbẹ́kẹ̀lé

Àkọsílẹ̀ kọ̀ọ̀kan máa ń gba ìpele ìgbẹ́kẹ̀lé gẹ́gẹ́ bí iye ìbò Arena:

| Ìgbẹ́kẹ̀lé | Ìbò     |
| -------- | ------- |
| `high`   | ≥ 5,000 |
| `medium` | ≥ 1,000 |
| `low`    | < 1,000 |

### Ìpamọ́ àti bí dátà ṣe jẹ́ tuntun

Àwọn àkọsílẹ̀ tí a ṣètò sí òṣùwọ̀n kan náà ni a máa ń kọ sínú tábìlì DB `model_intelligence` pẹ̀lú
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Àwọn àkọsílẹ̀ **máa ń parí lẹ́yìn
ọjọ́ 7**, nítorí náà, olùpèsè tí ó dá ìmúdójúìwọ̀n dúró yóò yọ kúrò nígbẹ̀yìn dípò kí ó máa pèsè
dátà àtijọ́.

Ìmúdójúìwọ̀n náà **wà ní ṣíṣiṣẹ́ láti ìbẹ̀rẹ̀**:

- Ó máa ń ṣiṣẹ́ lẹ́ẹ̀kan nígbà tí olupin bá bẹ̀rẹ̀, lẹ́yìn náà yóò máa ṣiṣẹ́ lórí aago àsìkò déédéé
  (`src/lib/arenaEloSync.ts`, tí a so pọ̀ láti `src/instrumentation-node.ts`).
- Ó **kì í dá iṣẹ́ dúró, bẹ́ẹ̀ ni kì í fa ìkùnà pátápátá** — bí gbígba dátà láti orísun òkè bá kùnà, OmniRoute yóò tẹ̀síwájú
  láti ṣiṣẹ́, àwọn ìtòlẹ́sẹẹsẹ yóò sì kàn fi dátà tó dára jù lọ tí ó gbẹ̀yìn hàn (tàbí ipò òfo).

Àwọn àyípadà àyíká méjì ló ń ṣàkóso rẹ̀ (tí a ṣàkọsílẹ̀ nínú
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Àyípadà                   | Àìyípadà      | Ète                                           |
| ------------------------- | ------------- | --------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Ṣètò sí `false` láti kọ ìmúdójúìwọ̀n jáde náà. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | Àárín àsìkò ìmúdójúìwọ̀n, ní ìṣẹ́jú-ààyá.       |

### Ìmúdójúìwọ̀n afọwọ́ṣe / ipò / ìparẹ́

Fún àwọn olùdarí ètò, endpoint ìṣàkóso tí ó nílò ìfàṣẹsí ń pèsè àṣẹ afọwọ́ṣe
(`src/app/api/intelligence/sync/route.ts` — ó nílò ìfàṣẹsí ìṣàkóso):

```
GET    /api/intelligence/sync          # ipò ìmúdójúìwọ̀n lọ́wọ́lọ́wọ́ (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # bẹ̀rẹ̀ ìmúdójúìwọ̀n afọwọ́ṣe; ara: { "dryRun": true } láti ṣáájúwo láì kọ nǹkan
DELETE /api/intelligence/sync          # pa gbogbo àwọn àkọsílẹ̀ ìmọ̀ arena_elo tí a ti mú dójú ìwọ̀n rẹ́
```

Bí ojú ìwé ìtòlẹ́sẹẹsẹ bá ṣófo, `POST /api/intelligence/sync` afọwọ́ṣe kan (tàbí kí o kàn
tun olupin bẹ̀rẹ̀) yóò tún fi dátà kún un.

### Bíbá àwọn àwòṣe mu pẹ̀lú àtẹ ìṣàkóso

Àwọn ID àwòṣe inú àkọsílẹ̀ àti àwọn orúkọ àwòṣe Arena kì í sábà bá ara wọn mu pátápátá. Ìtòlẹ́sẹẹsẹ náà ń lo
ìbámu tó rọ̀ (`findMatchingIntelligence` nínú `src/lib/freeProviderRankings.ts`):

1. Ìbámu pípé lórí ID àwòṣe tí a ṣètò sí òṣùwọ̀n kan náà.
2. Ìbámu lẹ́yìn yíyọ àmì ẹ̀yà tí ó wà ní ìparí kúrò (f.à. `kimi-k2.6` → `kimi-k2`).
3. Ìbámu ìbẹ̀rẹ̀-orúkọ (orúkọ àwòṣe inú àtẹ ìṣàkóso jẹ́ ìbẹ̀rẹ̀ ID inú àkọsílẹ̀).

Ní ẹ̀gbẹ́ ìmúdójúìwọ̀n, a máa ń yọ àwọn ìbẹ̀rẹ̀-orúkọ olùpèsè tí a mọ̀ (`anthropic/`, `openai/`, `google/`, …)
kúrò, àwòrán alias kékeré kan sì máa ń fẹ àwọn orúkọ àgbà kalẹ̀ sí àwọn ìyàtọ̀ tí OmniRoute ń lò
ní inú, kí àwọn àwòṣe lè máa ṣeé rí lábẹ́ orúkọ èyíkéyìí.

### Bí a ṣe ń to olùpèsè sí ipò

Fún olùpèsè ọ̀fẹ́ kọ̀ọ̀kan, ẹ̀rọ náà máa ń fún gbogbo àwòṣe inú àkójọ rẹ̀ ní ìwọ̀n, lẹ́yìn náà:

- **Àwòṣe Tó Ga Jù** = àwòṣe olùpèsè náà tí ó ní ìwọ̀n tó ga jù.
- **Ìwọ̀n Àpapọ̀** = ìpíndọ́gba ìwọ̀n gbogbo àwọn àwòṣe olùpèsè náà tí a fún ní ìwọ̀n.
- **Àwọn Àwòṣe** = iye àwọn àwòṣe olùpèsè náà tí ó ní ìwọ̀n Arena.

A máa ń to àwọn olùpèsè nípasẹ̀ **ìwọ̀n àwòṣe tó ga jù** lákọ̀ọ́kọ́, lẹ́yìn náà nípasẹ̀ ìwọ̀n àpapọ̀. Èyí ń san
ẹ̀san fún olùpèsè tí ó pèsè ó kéré tán àwòṣe ọ̀fẹ́ alágbára kan.

## Lílo Èyí láti Yan Àwọn Olùpèsè Ọ̀fẹ́

1. **Yan ẹ̀ka tó tọ́.** Lo àsẹ̀ **Coding** fún àwọn iṣẹ́ aṣojú/kóòdù, tàbí
   fi sí **All Categories** / **Default** fún ìfọ̀rọ̀wérọ̀ gbogbogbòò. Olùpèsè kan náà lè
   ní ipò tó yàtọ̀ láàárín àwọn ẹ̀ka nítorí pé àwòṣe tó ga jù lọ rẹ̀ yàtọ̀ fún tábìlì ipò kọ̀ọ̀kan.
2. **Yan àwọn tó wà lórí pèpéle ẹ̀bùn fún ìṣètò ìgbà-kan.** Tí o bá fẹ́ so olùpèsè ọ̀fẹ́
   kan tàbí méjì péré pọ̀, bẹ̀rẹ̀ pẹ̀lú àwọn tó ní ipò tó ga jù lọ fún ẹ̀ka rẹ.
3. **Ṣàyẹ̀wò báàjì Type.** Àwọn olùpèsè `NOAUTH` ni ó yára jù lọ láti sopọ̀ (kò nílò
   ẹ̀rí ìdánimọ̀). Àwọn ìpele ọ̀fẹ́ `OAUTH` / `APIKEY` nílò ìforúkọsílẹ̀ kíákíá ṣùgbọ́n wọ́n sábà máa ń pèsè
   àwọn àwòṣe tó lágbára sí i. Wo [Ìtọ́sọ́nà Àwọn Ìpele Ọ̀fẹ́](../getting-started/FREE-TIERS-GUIDE.md) fún
   àwọn ìgbésẹ̀ ìsopọ̀.
4. **So ọ̀pọ̀ pọ̀ kí Auto-Combo sì pinnu.** Dátà Arena ELO kan náà tó ń fún
   ojú-ìwé yìí lágbára tún ń pèsè **task-fitness factor** fún ẹ́ńjìnnì ìṣírò Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, ìtòlẹ́sẹẹsẹ ìpinnu
   `user_override → arena_elo → models_dev_tier → static table`). Nítorí náà, lẹ́yìn tí o bá so
   àwọn olùpèsè ọ̀fẹ́ tó ga jù lọ pọ̀, ìdarí pẹ̀lú `model: "auto"` (fún àpẹẹrẹ `auto/coding`) yóò
   yan àwọn àwòṣe ọ̀fẹ́ tó ní dídára tó ga jù lọ fún ìbéèrè kọ̀ọ̀kan láìfọwọ́sí. Wo
   [Auto-Combo](../routing/AUTO-COMBO.md) fún ìṣírò kíkún tó ní kókó 16.
