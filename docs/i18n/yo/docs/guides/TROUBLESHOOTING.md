## Ìtọ́kasí Kíákíá

**Ṣé o jẹ́ tuntun sí OmniRoute?** Bẹ̀rẹ̀ níbí — àwọn wọ̀nyí ń yanjú 90% àwọn ìṣòro:

| Mo rí èyí                  | Ohun tí ó túmọ̀ sí                     | Ohun tí o yẹ kí o ṣe                                                                                                  |
| -------------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| "Kò lè sopọ̀"               | OmniRoute kò ṣiṣẹ́                     | Ṣiṣe `omniroute` tàbí `docker restart omniroute`                                                                      |
| "Kọ́kọ́rọ́ API kò tọ́"         | Kọ́kọ́rọ́ rẹ kò tọ́ tàbí ó ti parí        | Ṣe àdàkọ kọ́kọ́rọ́ náà lẹ́ẹ̀kan sí i láti ojúlé olùpèsè                                                                    |
| "Ààlà ìbéèrè ti kọjá"      | O ń fi àwọn ìbéèrè púpọ̀ jù ránṣẹ́      | Dúró fún ìṣẹ́jú 1, tàbí lo `model: "auto"` fún ìpadà-sẹ́yìn aládàáṣiṣẹ́                                                  |
| "Ìpín ti parí"             | O ti lo gbogbo ìpín ọ̀fẹ́/tí a sanwó rẹ | So àwọn olùpèsè míì pọ̀, tàbí lo àwọn olùpèsè ọ̀fẹ́ (Kiro, Pollinations)                                                 |
| "Àwọn ìdáhùn lọ́ra"         | Olùpèsè dí lọ́wọ́ tàbí ó jìnnà          | Lo `model: "auto/fast"` tàbí so olùpèsè tó yára jù pọ̀ (Groq, Cerebras)                                                |
| "Olùpèsè tí kò tọ́ ni a lò" | `auto` yan olùpèsè mìíràn             | Ìyẹn jẹ́ ohun tó wọ́pọ̀! `auto` máa ń yan èyí tó dára jù. Fi tipátipá yan olùpèsè kan pàtó pẹ̀lú `model: "openai/gpt-4o"` |
| "502 Ẹnu-ọ̀nà Búburú"       | Olùpèsè kò ṣiṣẹ́                       | Dúró kí o sì gbìyànjú lẹ́ẹ̀kan sí i, tàbí lo `model: "auto"` láti yí olùpèsè padà                                       |
| "401 Kò Ní Àṣẹ"            | Àwọn ẹ̀rí ìdánimọ̀ rẹ kò tọ́             | Ṣàyẹ̀wò kọ́kọ́rọ́ API rẹ tàbí tún ṣe ìfàṣẹsí pẹ̀lú OAuth                                                                   |
| "429 Àwọn Ìbéèrè Púpọ̀ Jù"  | A ti fi ààlà ìbéèrè lé e lórí         | Dúró fún ìṣẹ́jú 1, tàbí so àwọn olùpèsè míì pọ̀                                                                         |

## Ìṣàtúnṣe Ìṣòro Ní Ẹ̀kúnrẹ́rẹ́

### Fífi Ààlà Ìbéèrè Lórí Àwọn Olùpèsè Ọ̀fẹ́ (429 / 400 / 401)

**Àmì ìṣòro**: Nígbà tí o bá ń lo `model: "auto"` pẹ̀lú àwọn olùpèsè ọ̀fẹ́/tí kò nílò ìfàṣẹsí (opencode, auggie, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ), lẹ́ẹ̀kọ̀ọ̀kan o máa ń gba `HTTP 429`, `400`, tàbí `401` dípò àwọn ìdáhùn. Àwọn ìbéèrè náà máa ń ṣàṣeyọrí nígbà tí a bá tún ìtọ́ni kan náà gbìyànjú lẹ́yìn ìṣẹ́jú díẹ̀, ṣùgbọ́n ìṣiṣẹ́ aládàáṣiṣẹ́ (cron jobs, agents, scripts) máa ń dáwọ́ dúró ní kété tí ìkùnà àkọ́kọ́ bá ṣẹlẹ̀.

**Ìdí pàtàkì**: Àwọn ọ̀nà ìkùnà olómìnira mẹ́ta ń kó jọ:

1. **Ààlà ìbéèrè olùpèsè (`429`)**: Àwọn ipele ọ̀fẹ́ lè fi ìpín kan múlẹ̀ fún àkókò kọ̀ọ̀kan. Ìṣàn àwọn ìpè tó pọ̀ lẹ́ẹ̀kan náà máa ń jẹ gbogbo rẹ̀ tán, nítorí náà a máa kọ ìbéèrè tó tẹ̀ lé e títí àkókò náà yóò fi bẹ̀rẹ̀ láti ìbẹ̀rẹ̀.
2. **Àwoṣe tó bàjẹ́ nínú passthrough (`400`/`401`)**: Àwọn àkójọpọ̀ `auto/*` lè ní àwọn àwoṣe passthrough láti `opencode` tí a forúkọsílẹ̀ sínú catalog ṣùgbọ́n tí kò ní àwọn ẹ̀rí ìdánimọ̀ tó ń ṣiṣẹ́ (fún àpẹẹrẹ `oc/north-mini-code-free` → `401`). Auto-router máa ń gbìyànjú ọ̀kan, ó máa ń kùnà, àṣìṣe náà sì máa ń tàn ká ṣáájú kí ìpadà-sẹ́yìn tó bẹ̀rẹ̀.
3. **Ìmúgbòòrò ìṣiṣẹ́ lẹ́ẹ̀kan náà (`429` lábẹ́ ẹrù)**: Nígbà tí ọ̀pọ̀lọpọ̀ ìpàdé agent/cron bá kọlu `auto` lẹ́ẹ̀kan náà, àpapọ̀ ìwọ̀n ìbéèrè máa ń kọjá ohun tí àwọn olùpèsè ọ̀fẹ́ lè fara dà, nítorí náà a máa ń samisi àwọn ìpè tó bófin mu gẹ́gẹ́ bí ìlòkulò.

**Àtúnṣe tí a ti fìdí rẹ̀ múlẹ̀ (àwùjọ ló jàbọ̀ rẹ̀, 2026-08-10)**: ṣètò àwọn environment variables mẹ́ta kí yíyípo, ìṣiṣẹ́ lẹ́ẹ̀kan náà, àti ìpadà-sẹ́yìn lè gba ìyípadà ipele ọ̀fẹ́ náà dípò kí wọ́n dáwọ́ dúró nítorí rẹ̀:

```bash
export OMNIROUTE_ROTATE_ON_400=true           # lọ sí àwoṣe/olùpèsè mìíràn lórí 400/401 (ó fo àwọn àwoṣe passthrough tó bàjẹ́)
export OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=4   # òpin ìgbàwọlé iṣẹ́ ẹrù-wúwo tó ṣe kedere (a kò ṣètò rẹ̀ ní àkọ́kọ́: kò sí òpin iye ìbéèrè, wo àkíyèsí ní ìsàlẹ̀)
export OMNIROUTE_CHAT_ADMISSION_QUEUE_MS=5000 # ìdúró olókùn tó gùn sí i fún agbára ẹrù-wúwo dípò 503 tí a lè tún gbìyànjú lẹ́sẹ̀kẹsẹ̀
```

Ṣètò àwọn wọ̀nyí nínú process environment OmniRoute (daemon náà, fún àpẹẹrẹ nípasẹ̀ LaunchAgent plist tàbí `systemctl edit`), lẹ́yìn náà tún OmniRoute bẹ̀rẹ̀. Àmì yíyípo náà ni irinṣẹ́ kan ṣoṣo tó lágbára jù lọ: ó yí ìkùnà pátápátá padà sí àtúngbìyànjú tí kò hàn sí olùmúlò lòdì sí olùpèsè tó ní ìlera nínú àkójọpọ̀ náà.

**Àkíyèsí**: `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` ń fi òpin sí iye àwọn ìbéèrè ẹrù-wúwo — tí ó ní àyíká ọ̀rọ̀ gígùn — tó lè ṣiṣẹ́ lẹ́ẹ̀kan náà; òpin náà jẹ́ ẹnu-ọ̀nà ìgbàwọlé, kì í ṣe ohun èlò olùpèsè fún fífi ààlà ìbéèrè múlẹ̀. **Ìmúdójúìwọ̀n #503-fanout:** a kò ṣètò var yìí ní àkọ́kọ́ mọ́ (ó ń ṣiṣẹ́ nìkan nígbà tí a bá ṣètò rẹ̀ ní kedere, gẹ́gẹ́ bí ó ṣe wà lókè) — dípò bẹ́ẹ̀, ìgbàwọlé ẹrù-wúwo ń lo ìnáwó byte tí a ṣe àgbékalẹ̀ rẹ̀ láìfọwọ́ṣe (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`), èyí tó ń mú ara rẹ̀ bá òpin memory gidi ti host mu, nítorí náà deployment tuntun yẹ kí ó rí àwọn ìkọ̀sílẹ̀ `503 chat_admission_busy` díẹ̀ púpọ̀ láìṣètò var yìí rárá; ṣíṣètò rẹ̀ ní kedere níbí ṣì ń ṣiṣẹ́ gan-an gẹ́gẹ́ bí a ṣe ṣàkọsílẹ̀ rẹ̀. Àwọn ìyípadà ìnáwó byte tí a ṣètò ní kedere ní òpin 8 MiB–2 GiB. `413 body_exceeds_budget` kì í ṣe ohun tó máa kọjá fúnra rẹ̀: mú ìnáwó byte náà pọ̀ sí i, dín `OMNIROUTE_CHAT_HARD_MAX_BODY_BYTES` kù, tàbí mú òpin memory ti process pọ̀ sí i. Ìtújáde `inflight_bytes_budget` jẹ́ ìdíje agbára fún ìgbà díẹ̀, a sì lè tún un gbìyànjú. Fífi ààlà ìbéèrè múlẹ̀ fún olùpèsè kọ̀ọ̀kan (`open-sse/services/rateLimitManager.ts`) ni `RATE_LIMIT_MAX_WAIT_MS`, `RATE_LIMIT_MAX_QUEUE_DEPTH`, àti `RATE_LIMIT_AUTO_ENABLE` ń darí lọ́tọ̀ — wo `.env.example`.

**Bí o ṣe lè fìdí rẹ̀ múlẹ̀ pé ó ṣiṣẹ́**: ṣiṣe agent/cron rẹ lẹ́ẹ̀mejì ní kíákíá lẹ́yìn ara wọn, kí o sì fìdí rẹ̀ múlẹ̀ pé àwọn méjèèjì ṣàṣeyọrí. Ṣáájú àtúnṣe náà, ìṣiṣẹ́ kejì sábà máa ń dá `429`/`401` jáde. Lẹ́yìn àtúnṣe náà, àwọn ìkùnà (bí èyíkéyìí bá wà) ni a máa tún gbìyànjú láìjẹ́ kí ó hàn sí olùmúlò, ìpè náà yóò sì parí. O tún lè lo `curl /monitoring/health`, kí o sì ṣọ́ field `rateLimitedUntil` lórí àwọn ìsopọ̀ olùpèsè àti `circuitBreakers.providerBreakers[].state` fún àwọn olùpèsè tí ọ̀ràn náà kàn — state náà jẹ́ ọ̀kan lára `CLOSED`, `DEGRADED`, `OPEN`, tàbí `HALF_OPEN` (wo `src/shared/utils/circuitBreaker.ts`), olùpèsè tó sì ń kùnà léraléra yóò yí padà láti `CLOSED → DEGRADED → OPEN` kí window àtúntò tó jẹ́ kí ìdánwò kan kọjá (`HALF_OPEN`).

**Tí o bá ṣì ń rí 429**: àkọọ́lẹ̀ tó ń ṣiṣẹ́ fún olùpèsè yẹn ti lo gbogbo _quota_ rẹ̀ tán ní tòótọ́ (kì í ṣe ààlà ìbéèrè lásán). Ṣàfikún àkọọ́lẹ̀ kejì fún olùpèsè kan náà nínú OmniRoute dashboard → Providers → Accounts, tàbí lo olùpèsè ọ̀fẹ́ mìíràn pọ̀ mọ́ ọn (fún àpẹẹrẹ `routeway`, `auggie`). Yíyí àkọọ́lẹ̀ padà máa ń ṣèrànwọ́ fún ààlà ìbéèrè/400/401 tó jẹ́ ti ìgbà díẹ̀ nìkan; bí _quota_ bá ti tán pátápátá, o nílò ẹ̀rí ìdánimọ̀ kejì tàbí olùpèsè mìíràn.

**Tí o bá rí 403 lórí àwọn vision models (`auto/vision`, `bazaarlink/*`)**: àkọọ́lẹ̀ tí a so pọ̀ kò ní ètò alágbàsan tó ní vision nínú, tàbí API key náà kò ní àṣẹ tó. Ṣàyẹ̀wò nínú dashboard olùpèsè pé scope kọ́kọ́rọ́ náà ní vision/multimodal nínú, tàbí so àkọọ́lẹ̀ paid tier kan pọ̀ kí o sì fi sílẹ̀ gẹ́gẹ́ bí vision target.

## Àwọn Ìkìlọ̀ npm install (ERESOLVE / peer / deprecated)

Nígbà tí o bá ṣiṣẹ́ `npm install -g omniroute`, o lè rí ọ̀pọ̀lọpọ̀ ìkìlọ̀ bíi `npm warn ERESOLVE`, àwọn àkíyèsí nípa peer-dependency, àti àwọn ìfiránṣẹ́ `deprecated`. **Àwọn wọ̀nyí jẹ́ ohun tí a retí, wọn kò sì léwu.** Ìfìmọ́lẹ̀ rẹ ṣàṣeyọrí bí o bá rí `added <N> packages` nínú àbájáde náà.

Àwọn ìkìlọ̀ náà wá láti inú àwọn ìwọ̀n peer-dependency tí kò bá àkókò mu nínú àwọn package ẹni-kẹta tí OmniRoute kò ṣàkóso:

1. **`marked-terminal` fẹ́ `marked >=1 <16`, ṣùgbọ́n ó rí `marked@18`** — ó ń ṣiṣẹ́ dáadáa ní ìṣe; ìwọ̀n peer ti upstream náà ti kàn pé.
2. **`deprecated prebuild-install@7.1.3`** — olùrànlọ́wọ́ ìgbàjáde native-binary tí a jogún. A kò
   lò ó láti fi binding transport `wreq-js` tí a ti ṣètò sí version kan pàtó sílẹ̀, kò sì túmọ̀ sí pé ìṣètò transport
   ti olùpèsè web-cookie kùnà.

**Kò sí ìgbésẹ̀ kankan tí o nílò láti gbé** — a kò lè pa gbogbo àwọn ìkìlọ̀ náà lẹ́nu mọ́ láì ṣe fork àwọn package upstream.

## Àwọn Ìkìlọ̀ Èké Láti Ọ̀dọ̀ Antivirus

<a name="antivirus-false-positives"></a>

### Avast/AVG fi `README.md` sínú quarantine pẹ̀lú `MD:HttpRequest-inf[Susp]`

**Èyí jẹ́ ìkìlọ̀ èké. Kò sí ohunkóhun tí àkóràn kàn, kò sì sí ohun tí ó yẹ kí o ṣe.**

Avast àti AVG ń lo ìlànà heuristic kan tí ń sàmì sí àwọn fáìlì plain-text/Markdown tí ó ní ọ̀pọ̀
ọ̀nà-àsopọ̀ tó dà bí ìbéèrè HTTP. `README.md` ti OmniRoute wà nínú package npm (a
ṣàkọsílẹ̀ rẹ̀ nínú `package.json` → `files`), nítorí náà ó máa ń dé sí `node_modules/omniroute/README.md` nígbà
fífìmọ́lẹ̀ àgbáyé — ó sì ní nǹkan bí àpẹẹrẹ `http://localhost:20128/...` mẹ́ẹ̀ẹ́dógún (àwọn
endpoint HTTP/SSE ti MCP, URL `.well-known` ti A2A, àti àwọn àpẹẹrẹ `curl`). Bí àwọn
ọ̀nà-àsopọ̀ náà ṣe pọ̀ tó ti tó láti mú heuristic náà dá ìkìlọ̀ sílẹ̀.

Bí èyí bá ṣẹ̀ṣẹ̀ bẹ̀rẹ̀ láìpẹ́: irú fáìlì náà kò yí padà. Tábìlì endpoint inú README náà
fẹ̀ sí i (a fi MCP HTTP + SSE + A2A kún un), a sì ṣàfikún àwọn àpẹẹrẹ `curl` sí i, èyí tí
ó mú un kọjá ààlà náà.

Fáìlì náà jẹ́ ìwé àlàyé tí kò lè ṣiṣẹ́, kò sì ní àkóónú executable kankan. O lè dá a padà láìléwu
láti inú quarantine.

**Ohun tí o yẹ kí o ṣe:**

1. **Dá àwọn ìfitónilétí náà dúró** — yọ directory ìfìmọ́lẹ̀ náà kúrò nínú ohun tí antivirus rẹ ń ṣàyẹ̀wò
   (Avast: Settings → Exceptions), nípa fífi path `node_modules` àgbáyé rẹ àti/tàbí
   data dir OmniRoute (`~/.omniroute/`) kún un.
2. **Jábọ̀ ìkìlọ̀ èké náà** — <https://www.avast.com/false-positive-file-form.php>,
   kí o sì so `README.md` tí a fi sínú quarantine mọ́ ọn. Èyí ni àtúnṣe tí ó máa ran gbogbo ènìyàn lọ́wọ́, nítorí
   heuristic olùpèsè náà ló ń ṣe àsọdùn sí fáìlì ọ̀rọ̀ kan.

**Ìdí tí a kò fi “ṣe àtúnṣe” èyí ní ẹ̀gbẹ́ wa:** gbogbo àpẹẹrẹ náà jẹ́ `http://localhost`, àti
localhost kò lè jẹ́ `https` láìsí ìṣòro certificate tí ẹni fúnra rẹ̀ fọwọ́ sí. Yíyí ìwé àlàyé náà po
láti yẹra fún heuristic olùpèsè kan yóò ṣe gbogbo òǹkàwé níbi nítorí àṣìṣe scanner kan.

### Kaspersky sàmì sí app Desktop náà gẹ́gẹ́ bí `PDM:Trojan.Win32.Generic`

**Èyí jẹ́ ìkìlọ̀ èké láti ọ̀dọ̀ heuristic ìhùwàsí. Kò sí ohunkóhun tí àkóràn kàn.** Àkọ́kọ́ ọ̀rọ̀
`PDM:` ti Kaspersky túmọ̀ sí pé ìpinnu náà wá láti inú Proactive Defense Module (System Watcher) rẹ̀,
èyí tí ń ṣèdájọ́ ohun tí installer náà _ń ṣe_ dípò fífi wé malware tí a ti mọ̀. Nígbà tí
ó bá dá ìkìlọ̀ sílẹ̀, Kaspersky máa ń “yí gbogbo ìfìmọ́lẹ̀ náà padà” — ó máa ń pa àwọn fáìlì tí ó ti
kọ sílẹ̀ rẹ́ — nítorí náà app náà máa ń bàjẹ́ tàbí kí ó pòórá.

Àwọn fáìlì tí ó ń sàmì sí jẹ́ àwọn apá àtìlẹ́yìn bóṣewa láti inú àwọn dependency open-source tí a ti sọ ní gbangba, tí a sì kó pọ̀ mọ́
app desktop náà, bí àpẹẹrẹ:

- `resources/app/.build/next/node_modules/playwright-<hash>/lib/…/agentParser.js` àti
  `workerProcessEntry.js` — [Playwright](https://playwright.dev), library ìṣiṣẹ́ aṣàwákiri
  tí a ń lò fún iwọlé olùpèsè nínú app àti ìfọ̀rọ̀wérọ̀ tó dá lórí aṣàwákiri.
- `resources/app/.build/next/node_modules/@wreq-js/binding-win32-<arch>-msvc-<hash>/wreq-js.win32-<arch>-msvc.node`
  — native binding `wreq-js` tí a ti dì mọ́ version kan, tí a ń lò fún HTTP tó ní browser fingerprint lórí àwọn olùpèsè
  tó ń lo web-cookie (`<arch>` jẹ́ `x64` tàbí `arm64`).

**Ìdí tí ó fi ń dá ìkìlọ̀ sílẹ̀:** installer Windows náà **kò tíì ní code signature**, nítorí náà installer NSIS
tí kò ní signature kò ní orúkọ rere kankan, àwọn heuristic ìhùwàsí sì máa ń ṣiṣẹ́ pẹ̀lú líle tó pọ̀ jù. Nígbà tí èyí bá darapọ̀
pẹ̀lú native DLL kan àti ọgọ́rọ̀ọ̀rún fáìlì `.js` tí a kọ sí abẹ́
`%LOCALAPPDATA%\Programs\OmniRoute` (tí ó tún ní àwọn directory package tó ní hash ní òpin láti inú
standalone build Next.js), ó ti tó láti mú heuristic náà dá ìkìlọ̀ sílẹ̀. A ti wéwèé code signing;
títí tí a ó fi ṣe é, àwọn release tuntun lè tún fa èyí.

**Ohun tí o yẹ kí o ṣe:**

1. **Kọ́kọ́ ṣàyẹ̀wò download rẹ** (èyí yóò mú un dájú pé a kò yí fáìlì náà padà lọ́nà àìtọ́). Gbogbo release máa ń tẹ̀jáde
   `latest.yml`, tí field `sha512` rẹ̀ (base64) bo installer `OmniRoute.Setup.<version>.exe`.
   Nínú PowerShell, láti inú folder tí installer náà wà:
   ```powershell
   $b = [System.Security.Cryptography.SHA512]::Create().ComputeHash(
     [System.IO.File]::ReadAllBytes("$PWD\OmniRoute.Setup.<version>.exe"))
   [Convert]::ToBase64String($b)
   ```
   Output náà gbọ́dọ̀ bá `latest.yml` → `sha512` mu. Bí wọn kò bá mu, pa fáìlì náà rẹ́, kí o sì
   tún download rẹ̀ láti [ojú-ìwé àwọn release GitHub](https://github.com/diegosouzapw/OmniRoute/releases) nìkan.
2. **Dá a padà + yọ ọ́ kúrò nínú àyẹ̀wò** — dá àwọn ohun tí rollback kàn padà láti inú quarantine, kí o sì ṣàfikún exclusion
   fún `%LOCALAPPDATA%\Programs\OmniRoute` (Kaspersky → Settings → Threats and Exclusions),
   lẹ́yìn náà kí o tún fi í mọ́lẹ̀.
3. **Jábọ̀ ìkìlọ̀ èké náà** — <https://opentip.kaspersky.com/>. Àwọn ìròyìn FP
   tí àwọn olùlò fi ránṣẹ́ máa ń mú kí fífi sí allowlist yára sí i ní tòótọ́.

## Ìbámu Pẹ̀lú Node.js

<a name="nodejs-compatibility"></a>

### Ojú-ìwé ìwọlé ń jáwọ́ tàbí ń fi àṣìṣe "Module self-registration" hàn

**Okùnfà:** O ń lo ẹ̀yà Node.js kan tí kò bá ìpele ìṣiṣẹ́ tó ní ààbò tí OmniRoute fọwọ́ sí mu. Ọ̀ràn tó wọ́pọ̀ jù ni lílo ìpele àtúnṣe Node 22 tàbí 24 àtijọ́ kan tó wà ní ìsàlẹ̀ ìpele ààbò tí a ti ṣàtúnṣe tí OmniRoute béèrè fún.

**Àwọn àmì:**

- Ojú-ìwé ìwọlé ń fi ojú òfo tàbí àṣìṣe olupèsè hàn
- Console ń fi `Error: Module did not self-register` tàbí àwọn àṣìṣe ìsopọ̀ abinibi tó jọra hàn
- Ojú-ìwé ìwọlé ń fi **àsìá ìkìlọ̀ aláwọ̀ ọsàn** hàn pẹ̀lú ẹ̀yà Node rẹ bí àyíká ìṣiṣẹ́ náà kò bá wà lábẹ́ ìlànà ààbò tí a ń ṣe àtìlẹ́yìn fún

**Àtúnṣe:**

1. Fi ẹ̀yà Node.js LTS tí a ń ṣe àtìlẹ́yìn fún sílẹ̀ (èyí tí a dábàá: Node.js 24.x):
   ```bash
   nvm install 24
   nvm use 24
   ```
2. Ṣàyẹ̀wò ẹ̀yà rẹ: `node --version` yẹ kí ó fi `v24.0.0` tàbí tuntun jù bẹ́ẹ̀ lọ hàn lórí ẹ̀ka 24.x LTS
3. Tún OmniRoute fi sílẹ̀: `npm install -g omniroute`
4. Tún un bẹ̀rẹ̀: `omniroute`

> **Àwọn ẹ̀yà tó ní ààbò tí a ń ṣe àtìlẹ́yìn fún:** `>=22.22.2 <23` tàbí `>=24.0.0 <27`. A ń ṣe àtìlẹ́yìn ní kíkún fún Node.js 24.x LTS (Krypton) àti Node.js 26.

### npm v11+: a kò fi `better-sqlite3` sílẹ̀ (Kò rí module)

<a name="npm-v11-better-sqlite3-not-installed-cannot-find-module"></a>

**Okùnfà:** npm v11 (tí ó wà pẹ̀lú Node.js 24+) máa ń dí àwọn script ìfìsílẹ̀ fún àwọn àfikún
àṣàyàn lọ́nà àìyẹsẹ̀. Nítorí pé `better-sqlite3` wà nínú `optionalDependencies`
tí ó sì nílò àkójọ-kóòdù abinibi (`node-gyp rebuild`), npm máa ń fò ó kọjá láìsọ̀rọ̀.

**Àwọn àmì:**

- Olupèsè ń jáwọ́ nígbà ìbẹ̀rẹ̀ pẹ̀lú `Cannot find module 'better-sqlite3'`
- `ls node_modules/better-sqlite3` ń fi "No such file or directory" hàn
- `npm ls better-sqlite3` ń fi `(empty)` hàn

**Àtúnṣe:**

1. Fọwọ́ sí àwọn script ìfìsílẹ̀, kí o sì tún fi wọ́n sílẹ̀:
   ```bash
   npm approve-scripts better-sqlite3
   npm install
   ```
2. Tàbí fi àkójọpọ̀ tí a ti kọ́ tẹ́lẹ̀ sílẹ̀ fúnra rẹ:
   ```bash
   npm pack better-sqlite3@13.0.1
   tar -xzf better-sqlite3-*.tgz -C node_modules
   mv node_modules/package node_modules/better-sqlite3
   rm better-sqlite3-*.tgz
   ```
3. Ṣàyẹ̀wò pé ó ń ṣiṣẹ́: `node -e "require('better-sqlite3')(':memory:').close(); console.log('OK')"`

### macOS: `dlopen` / "slice is not valid mach-o file"

<a name="macos-native-module-rebuild"></a>

**Okùnfà:** Lẹ́yìn `npm install -g omniroute` àgbáyé, ó ṣeé ṣe kí binary abinibi `better-sqlite3` tó wà nínú package náà ti jẹ́ kíkó fún àwòṣe ẹ̀rọ tàbí ABI Node.js mìíràn tó yàtọ̀ sí èyí tó ń ṣiṣẹ́ lórí ẹ̀rọ náà. Èyí wọ́pọ̀ lórí macOS (Apple Silicon àti Intel méjèèjì) nígbà tí binary tí a ti kọ́ tẹ́lẹ̀ kò bá àyíká rẹ mu.

**Àwọn àmì:**

- Olupèsè ń kùnà lẹ́sẹ̀kẹsẹ̀ nígbà ìbẹ̀rẹ̀ pẹ̀lú àṣìṣe `dlopen`
- Àṣìṣe náà ní `slice is not valid mach-o file`
- Àpẹẹrẹ ní kíkún:

```
dlopen(/Users/<user>/.nvm/versions/node/v24.14.1/lib/node_modules/omniroute/app/node_modules/better-sqlite3/build/Release/better_sqlite3.node, 0x0001): tried: '...' (slice is not valid mach-o file)
```

**Àtúnṣe — tún un kọ́ fún àyíká ẹ̀rọ rẹ (kò nílò dídín ẹ̀yà Node.js kù):**

```bash
cd $(npm root -g)/omniroute/app
npm rebuild better-sqlite3
omniroute
```

> **Àkíyèsí:** Èyí máa tún ìsopọ̀ abinibi náà kọ́ ní ìbámu pẹ̀lú ẹ̀yà Node.js àti àwòṣe CPU ẹ̀rọ rẹ, tí yóò sì yanjú àìbámu binary náà. Àlà àyíká ìṣiṣẹ́ tí a ń ṣe àtìlẹ́yìn fún ní pàtó ni **`>=22.22.2 <23` tàbí `>=24.0.0 <27`** (`SUPPORTED_NODE_RANGE` nínú `src/shared/utils/nodeRuntimeSupport.ts`, tí ó bá pápá `engines` nínú `package.json` mu). A ń ṣe àtìlẹ́yìn ní kíkún fún Node.js 24.x LTS (Krypton) àti Node.js 26 pẹ̀lú `better-sqlite3` v12.x.

## Àwọn Ìṣòro Proxy

<a name="proxy-issues"></a>

### Ìfàṣẹsí olùpèsè ń fi "fetch failed" hàn

**Ìdí:** Ibi ìgbẹ̀yìn ìfàṣẹsí kọ́kọ́rọ́ API (`POST /api/providers/validate`) máa ń ré ìṣètò proxy kọjá tẹ́lẹ̀, èyí sì ń fa ìkùnà nínú àwọn àyíká tí ó nílò ìdarí nípasẹ̀ proxy.

**Àtúnṣe (v3.5.5+):** A ti ṣàtúnṣe èyí báyìí. Ìfàṣẹsí olùpèsè ń kọjá nípasẹ̀ `runWithProxyContext`, ó sì ń tẹ̀lé àwọn ìṣètò proxy ti olùpèsè àti ti àgbáyé láìfọwọ́ṣe.

### Àyẹ̀wò ìlera token kùnà pẹ̀lú "fetch failed"

**Ìdí:** Ìsọdọ̀tun token OAuth lẹ́yìn-iṣẹ́ kò ń yanjú ìṣètò proxy fún asopọ̀ kọ̀ọ̀kan.

**Àtúnṣe (v3.5.5+):** Olùṣètò àkókò àyẹ̀wò ìlera token ń yanjú ìṣètò proxy fún asopọ̀ kọ̀ọ̀kan báyìí kí ó tó gbìyànjú ìsọdọ̀tun. Ṣe ìmúdójúìwọ̀n sí v3.5.5+.

### Proxy SOCKS5 dáhùn pẹ̀lú "invalid onRequestStart method"

**Ìdí:** Lórí Node.js 22, dispatcher undici@8 kò bá ìmúṣẹ `fetch()` tí a kọ sínú Node mu.

**Àtúnṣe (v3.5.5+):** Ní báyìí, OmniRoute ń lo iṣẹ́ `fetch()` ti undici fúnra rẹ̀ nígbà tí dispatcher proxy bá ń ṣiṣẹ́, láti rí i dájú pé ìhùwàsí dúró déédéé. Ṣe ìmúdójúìwọ̀n sí v3.5.5+.

### Proxy MITM lábẹ́ WSL: àwọn ohun èlò desktop lórí Windows host kò ní di mímú

**Ìdí:** Proxy MITM àti ìwé-ẹ̀rí CA rẹ̀ ni a ń fi sínú àyíká tí OmniRoute ti ń ṣiṣẹ́. Lábẹ́ WSL, àyíká yẹn ni Linux guest, nígbà tí àwọn ohun èlò AI desktop (Kiro, Trae, Copilot, Zed, …) ń ṣiṣẹ́ lórí Windows host. Àwọn ohun èlò host kò fọkàn tán ibi ìpamọ́ ìwé-ẹ̀rí ti guest, wọn kò sì darí ìrìnàjò wọn nípasẹ̀ proxy ètò ti guest, nítorí náà dídá ìrìnàjò desktop mú kò ní ṣiṣẹ́ níbẹ̀.

**Ìmọ̀ràn:** Ṣiṣẹ́ OmniRoute ní ìbílẹ̀ lórí OS kan náà pẹ̀lú àwọn ohun èlò desktop tí o fẹ́ dá ìrìnàjò wọn mú (Windows fún àwọn ohun èlò Windows; bákan náà fún macOS/Linux). Títọ́jú OmniRoute sínú WSL nígbà tí o ń dojú kọ àwọn ohun èlò host nílò kí o fi ọwọ́ jẹ́ kí Windows host fọkàn tán ìwé-ẹ̀rí CA tí a ṣẹ̀dá, kí o sì tọ́ka àwọn ìṣètò nẹ́tíwọ́ọ̀kì/proxy ti ohun èlò host kọ̀ọ̀kan sí ibi ìgbẹ̀yìn proxy WSL — èyí jẹ́ ètò tí kò ní àtìlẹ́yìn, tí ó sì rọrùn láti bàjẹ́.

### Ọ̀pọ̀ àkọọ́lẹ̀ Kiro: àkọọ́lẹ̀ kejì sọ èkíní di aláìlèsúlò

**Ìdí:** Ẹ̀yìn-iṣẹ́ Kiro fi ipá mú kí session kan ṣoṣo ló lè ṣiṣẹ́ fún ìforúkọsílẹ̀ client OIDC kọ̀ọ̀kan.
Nígbà tí àkọọ́lẹ̀ méjì bá ń lo client tí a forúkọsílẹ̀ kan náà (àwọn asopọ̀ tí a gbé wọlé ṣáájú v3.8.0),
sísọ token àkọọ́lẹ̀ kan di ọ̀tun máa ń sọ refresh token ti èkejì di aláìlèsúlò.

**Àtúnṣe (v3.8.0+):** Tún àwọn asopọ̀ tí ọ̀ràn náà kàn gbé wọlé.
Bẹ̀rẹ̀ láti v3.8.0, gbogbo asopọ̀ Kiro tuntun tí a ṣẹ̀dá nípasẹ̀ **Gbé Token Wọlé**,
**Ìwọlé àwùjọ Google/GitHub**, tàbí **Ìgbéwọlé Láìfọwọ́ṣe** máa ń forúkọsílẹ̀ client OIDC
tí ó jẹ́ tirẹ̀ láìfọwọ́ṣe. Nítorí náà, asopọ̀ náà yà sọ́tọ̀ pátápátá, sísọ àkọọ́lẹ̀ kan
di ọ̀tun kò sì ní ipa kankan lórí àkọọ́lẹ̀ mìíràn.

Àwọn asopọ̀ tí a gbé wọlé _ṣáájú_ v3.8.0 kò ní ìforúkọsílẹ̀ client fún asopọ̀ kọ̀ọ̀kan.
Àwọn asopọ̀ wọ̀nyẹn ṣì ń lo ibi ìgbẹ̀yìn ìsọdọ̀tun social-auth tí gbogbo wọn ń pín.
Láti rí ìyàsọ́tọ̀, pa asopọ̀ àtijọ́ rẹ́ láti Dashboard → Àwọn Olùpèsè, kí o sì tún fi kún un
nípasẹ̀ èyíkéyìí nínú àwọn ọ̀nà ìgbéwọlé mẹ́tẹ̀ẹ̀ta náà.

Fún ẹ̀kúnrẹ́rẹ́ àlàyé àti àwọn ìtọ́nisọ́nà ìgbésẹ̀-ní-ìgbésẹ̀ fún fífi àkọọ́lẹ̀ Kiro méjì kún un lẹ́gbẹ̀ẹ́ ara wọn,
wo [`docs/guides/KIRO_SETUP.md`](./KIRO_SETUP.md).

## Àwọn Ìṣòro Awọsanma

### Àwọn Àṣìṣe Ìṣiṣẹ́pọ̀ Awọsanma

1. Ṣàyẹ̀wò pé `BASE_URL` tọ́ka sí instance rẹ tí ń ṣiṣẹ́ (àpẹẹrẹ, `http://localhost:20128`)
2. Ṣàyẹ̀wò pé `CLOUD_URL` tọ́ka sí endpoint awọsanma rẹ (àpẹẹrẹ, `https://omniroute.dev`)
3. Jẹ́ kí àwọn iye `NEXT_PUBLIC_*` bá àwọn iye ẹ̀gbẹ́ server mu

### `stream=false` Lórí Awọsanma Dá 500 Padà

**Àmì àìsàn:** `Unexpected token 'd'...` lórí endpoint awọsanma fún àwọn ìpè tí kì í ṣe streaming.

**Okùnfà:** Upstream dá payload SSE padà nígbà tí client ń retí JSON.

**Ọ̀nà àbáyọ:** Lo `stream=true` fún àwọn ìpè taara sí awọsanma. Runtime agbègbè ní ìrànlọ́wọ́ ìpadà SSE→JSON.

### Awọsanma Sọ Pé Ó Ti Sopọ̀ Ṣùgbọ́n Ó Fihàn "Invalid API key"

1. Ṣẹ̀dá key tuntun láti dashboard agbègbè (`/api/keys`)
2. Ṣiṣẹ́ ìṣiṣẹ́pọ̀ awọsanma: Tan Cloud → Sync Now
3. Àwọn key àtijọ́/tí a kò tíì ṣiṣẹ́pọ̀ ṣì lè dá `401` padà lórí awọsanma

## Àwọn Ìṣòro Docker

### Docker IPv6 / Ìtúnṣètò Ìsopọ̀

<a name="docker-ipv6"></a>

**Àwọn àmì àìsàn:** `curl http://localhost:20128/v1/models` dá `curl: (56) Recv failure: Connection reset by peer` padà. Dashboard àti àwọn endpoint tí kò nílò ìfàṣẹsí ń ṣiṣẹ́, ṣùgbọ́n àwọn endpoint tí ó nílò ìfàṣẹsí kuna — ó dà bí ìṣòro ìfàṣẹsí ṣùgbọ́n kì í ṣe bẹ́ẹ̀.

**Okùnfà:** `docker run -p 20128:20128` ń tẹ̀jáde lórí `0.0.0.0` (IPv4) àti `::` (IPv6) méjèèjì, ṣùgbọ́n process inú container ń tẹ́tí lórí IPv4 nìkan. Lórí àwọn host níbi tí `localhost` ti kọ́kọ́ yí padà sí `::1`, ìsopọ̀ náà dé sí port IPv6 tí a tẹ̀jáde láìsí listener lẹ́yìn rẹ̀ → ìtúnṣètò ìsopọ̀.

**Àtúnṣe:**

1. **Àyẹ̀wò kíákíá:** Ṣiṣe `curl -4 http://localhost:20128/v1/models`. Tí ó bá ṣiṣẹ́ pẹ̀lú `-4` ṣùgbọ́n ó kuna láìsí i, o ní àìbáramu bind IPv6.
2. **Àtúnṣe pípẹ́:** Ṣe bind sí IPv4 ní kedere nípa lílo `-p 127.0.0.1:20128:20128` nínú àṣẹ `docker run` rẹ:
   ```bash
   docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
     -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest
   ```
   Èyí ń fipá mú bind IPv4, ó sì tún ń dènà fífi proxy náà hàn lórí gbogbo interface host.

## Ṣíṣe Àwárí Àṣìṣe

### Mú Àwọn Fáìlì Log Ṣiṣẹ́

Ṣètò `APP_LOG_TO_FILE=true` nínú fáìlì `.env` rẹ. A kọ àwọn log application sí abẹ́ `logs/`.
A ń tọ́jú àwọn artifact request sí abẹ́ `${DATA_DIR}/call_logs/` nígbà tí pipeline log ìpè bá
ṣiṣẹ́ nínú settings.
Nígbà tí capture pipeline bá ṣiṣẹ́, ṣètò `CALL_LOG_PIPELINE_CAPTURE_STREAM_CHUNKS=false` láti yọ
àwọn payload chunk stream kúrò, tàbí ṣàtúnṣe `CALL_LOG_PIPELINE_MAX_SIZE_KB` láti yí òpin artifact padà ní KB.

### Ṣàyẹ̀wò Ìlera Provider

```bash
# Dashboard ìlera
http://localhost:20128/dashboard/health

# Àyẹ̀wò ìlera API
curl http://localhost:20128/api/monitoring/health
```

### Ibi Ìtọ́jú Runtime

- State àkọ́kọ́: `${DATA_DIR}/storage.sqlite` (àwọn provider, combo, alias, key, settings)
- Lílò: Àwọn table SQLite nínú `storage.sqlite` (`usage_history`, `call_logs`, `proxy_logs`) + `${DATA_DIR}/call_logs/` tí ó jẹ́ àṣàyàn
- Àwọn log application: `<repo>/logs/...` (nígbà tí `APP_LOG_TO_FILE=true`)
- Àwọn artifact log ìpè: `${DATA_DIR}/call_logs/YYYY-MM-DD/...` nígbà tí pipeline log ìpè bá ṣiṣẹ́

Ìgbésẹ̀ **Clean history** ojú-ewé Request Logs ń pa `call_logs`, `request_detail_logs`
àtijọ́, àti directory artifact agbègbè `${DATA_DIR}/call_logs/` rẹ́.

## Àwọn Ìṣòro Circuit Breaker

### Provider dúró sínú ipò OPEN

Nígbà tí circuit breaker ti provider kan bá wà ní ipò OPEN, àwọn ìbéèrè yóò di dídènà títí àkókò ìdádúró yóò fi parí.

**Àtúnṣe:**

1. Lọ sí **Dashboard → Settings → Resilience**
2. Ṣàyẹ̀wò káàdì circuit breaker fún provider tí ìṣòro náà kàn
3. Tẹ **Reset All** láti pa gbogbo breaker rẹ́, tàbí dúró de ìparí àkókò ìdádúró
4. Rí i dájú pé provider náà wà lárọ̀ọ́wọ́tó gangan kí o tó ṣe àtúntò

### Provider ń mú circuit breaker ṣiṣẹ́ léraléra

Tí provider kan bá ń wọ ipò OPEN léraléra:

1. Ṣàyẹ̀wò **Dashboard → Health → Provider Health** láti wo àpẹẹrẹ ìkùnà náà
2. Lọ sí **Settings → Resilience → Provider Profiles** kí o sì mú ààlà ìkùnà pọ̀ sí i
3. Ṣàyẹ̀wò bóyá provider náà ti yí àwọn ààlà API padà tàbí ó nílò ìfàṣẹsí tuntun
4. Ṣàyẹ̀wò telemetry ìdádúró — ìdádúró gíga lè fa àwọn ìkùnà tí àkókò píparí wọn dá lé

Lo **Dashboard → Translator** láti ṣàtúnṣe àwọn ìṣòro ìtumọ̀ fọ́ọ̀mù:

| Ipò              | Ìgbà Tí O Yẹ Kí O Lò Ó                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| **Playground**   | Ṣe àfiwé àwọn fọ́ọ̀mù àbáwọlé àti àbájáde lẹ́gbẹ̀ẹ́ ara wọn — lẹ ìbéèrè tó kùnà mọ́ ọn láti rí bí a ṣe túmọ̀ rẹ̀ |
| **Chat Tester**  | Fi àwọn ìfiránṣẹ́ lọ ní tààrà, kí o sì ṣàyẹ̀wò gbogbo payload ìbéèrè/ìdáhùn, pẹ̀lú àwọn header              |
| **Test Bench**   | Ṣiṣe àwọn ìdánwò lápapọ̀ lórí onírúurú àpapọ̀ fọ́ọ̀mù láti mọ àwọn ìtumọ̀ tí ó bàjẹ́                           |
| **Live Monitor** | Wo bí àwọn ìbéèrè ṣe ń ṣàn ní àkókò gidi láti rí àwọn ìṣòro ìtumọ̀ tí ń ṣẹlẹ̀ lẹ́ẹ̀kọ̀ọ̀kan                    |

### Àwọn ìṣòro fọ́ọ̀mù tó wọ́pọ̀

- **Àwọn tag ìrònú kò fara hàn** — Ṣàyẹ̀wò bóyá provider àfojúsùn ṣe àtìlẹ́yìn fún ìrònú àti ètò ààlà ìrònú
- **Àwọn tool call ń sọnù** — Àwọn ìtumọ̀ fọ́ọ̀mù kan lè yọ àwọn field tí a kò ṣètìlẹ́yìn fún kúrò; ṣàyẹ̀wò rẹ̀ ní ipò Playground
- **System prompt kò sí** — Claude àti Gemini ń bójú tó àwọn system prompt ní ọ̀nà tó yàtọ̀; ṣàyẹ̀wò àbájáde ìtumọ̀
- **SDK ń dá raw string padà dípò object** — A ti yanjú rẹ̀ ní v1.x; response sanitizer ń yọ àwọn field tí kò tẹ̀ lé ìlànà (`x_groq`, `usage_breakdown`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ) tí ń fa ìkùnà ìfàṣẹsí Pydantic OpenAI SDK. Tí o bá ṣì ń rí èyí lórí v3.x+, jọ̀wọ́ ṣí issue kan.
- **GLM/ERNIE kọ ipa `system`** — A ti yanjú rẹ̀ ní v1.x; role normalizer ń da àwọn system message pọ̀ mọ́ àwọn user message fún àwọn model tí kò bá a mu. Tí o bá ṣì ń rí èyí lórí v3.x+, jọ̀wọ́ ṣí issue kan.
- **A kò dá ipa `developer` mọ̀** — A ti yanjú rẹ̀ ní v1.x; a ń yí i padà sí `system` láìfọwọ́yí fún àwọn provider tí kì í ṣe OpenAI. Tí o bá ṣì ń rí èyí lórí v3.x+, jọ̀wọ́ ṣí issue kan.
- **`json_schema` kò ṣiṣẹ́ pẹ̀lú Gemini** — A ti yanjú rẹ̀ ní v1.x; a ti ń yí `response_format` padà sí `responseMimeType` + `responseSchema` ti Gemini báyìí. Tí o bá ṣì ń rí èyí lórí v3.x+, jọ̀wọ́ ṣí issue kan.

Àwọn prófáìlì olùpèsè ṣe àtìlẹ́yìn fún àwọn ètò wọ̀nyí:

- **Ìdádúró ìpilẹ̀** — Àkókò ìdúró àkọ́kọ́ lẹ́yìn ìkùnà àkọ́kọ́ (àiyipada: 1s)
- **Ìdádúró tó pọ̀ jù** — Òpin àkókò ìdúró tó pọ̀ jù (àiyipada: 30s)
- **Olùlọ́po** — Iye tí a ó fi mú ìdádúró pọ̀ sí fún ìkùnà kọ̀ọ̀kan tó tẹ̀lé ara wọn (àiyipada: 2x)

### Ìdènà ọ̀pọ̀-ìbéèrè-lójijì

Nígbà tí ọ̀pọ̀ ìbéèrè tó ń ṣiṣẹ́ lẹ́ẹ̀kan náà bá dé ọ̀dọ̀ olùpèsè tí a ti fi ìdíwọ̀n-oṣuwọn sí, OmniRoute máa ń lo mutex + ìdíwọ̀n-oṣuwọn aládàáṣe láti ṣètò àwọn ìbéèrè ní ọ̀kọ̀ọ̀kan àti láti dènà àwọn ìkùnà tó ń tẹ̀lé ara wọn. Èyí máa ń ṣẹlẹ̀ láìfọwọ́sí fún àwọn olùpèsè kọ́kọ́rọ́ API.

### Àwọn ìbéèrè ìfọ̀rọ̀wérọ̀ kùnà pẹ̀lú 503 / chat_admission_busy

**Àwọn àmì:**

- Ojú-ọ̀nà ìparí àwọn ìparí-ìfọ̀rọ̀wérọ̀ dá èsì `503` tí a lè tún gbìyànjú padà, tí kóòdù àṣìṣe rẹ̀ jẹ́
  `chat_admission_busy`.
- Èsì náà ní `Retry-After`. Láti #12135, iye náà jẹ́ èyí tí a yọ láti inú
  bí agbègbè náà ṣe kún tó — èyí tó tóbi jù láàárín fèrèsé `OMNIROUTE_CHAT_ADMISSION_QUEUE_MS` tí ìbéèrè náà ti
  dúró tẹ́lẹ̀ àti àkókò tí a ti di àwọn ìyálò ohun-èlò wúwo lọ́wọ́lọ́wọ́ mú — a yí i sókè sí àwọn
  ìṣẹ́jú-àáyá odidi, a sì fi òpin 60 sí i. Lórí ẹnu-ọ̀nà tí kò sí nǹkan lórí rẹ̀, ó pa àwọn ìwọ̀n-kéré ìtàn mọ́: ìṣẹ́jú-àáyá 2 lórí
  ipa tó dá lórí báìtì, ìṣẹ́jú-àáyá 1 lórí ipa tó dá lórí ìgbékalẹ̀ (èyí tí ó tún ní
  `reason: "structure_limit"`).
- Èyí lè ṣẹlẹ̀ nígbà tí ìfọ̀rọ̀wérọ̀ míì tó ń lo ohun-èlò púpọ̀ tàbí èsì ìṣànwọlé tó ń lọ fún àkókò gígùn ṣì
  ń ṣiṣẹ́.

Ara èsì tó dá lórí báìtì ni:

```json
{
  "error": {
    "message": "Chat admission capacity is temporarily unavailable. Retry shortly.",
    "type": "server_error",
    "code": "chat_admission_busy"
  }
}
```

Èsì tó dá lórí ìgbékalẹ̀ ń lo irú àti kóòdù kan náà, pẹ̀lú ìfiránṣẹ́
`Local chat admission capacity is busy for this structurally heavy request; upstream provider routing was not attempted. Retry shortly.`
àti `reason: "structure_limit"`.
Ní àwọn ìwọ̀n àiyipada, ìbéèrè kan wuwo nípa ìgbékalẹ̀ nígbà tí ó bá ní ó kéré tán àwọn ìfiránṣẹ́ `200`,
ó kéré tán àwọn irinṣẹ́ `64`, tàbí ó kéré tán àwọn tókìnì tí a fojú díwọ̀n sí `32,000`, tàbí nígbà tí ìṣírò ìgbékalẹ̀
tó ní ààlà bá parí àwọn ààlà rẹ̀ ti àwọn nóòdù `10,000` tí a bẹ̀wò tàbí ìjìnlẹ̀ `12`.

**Ìdí:** Èyí jẹ́ dídín ẹrù kù tí a mọ̀ọ́mọ̀ ṣe nínú OmniRoute, kì í ṣe ìkùnà olùpèsè ìpele-òkè.
Ilànà kọ̀ọ̀kan ń lo olùṣọ́ agbègbè-ilànà láti fi agbára ohun-èlò wúwo tó ní òpin pamọ́ ṣáájú dídadúró
àti ṣíṣe àtúpalẹ̀ ara ìbéèrè ńlá kan. Ìyálò ohun-èlò wúwo máa ń wà ní dídìmú fún gbogbo ìgbà tí èsì SSE
bá wà láàyè.

**#503-fanout:** ṣáájú àtúnṣe yìí, olùṣọ́ náà fi òpin sí ìṣiṣẹ́ lẹ́ẹ̀kan náà ní iye ÌBÉÈRÈ tó dúró ṣinṣin
(`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`, àiyipada `1`) láìka ìrántí agbàlejò sí, nítorí náà ìtànkálẹ̀ aṣojú-kóòdù
(ọ̀pọ̀ àwọn aṣojú-kékeré/CLI, àwọn ara tó máa ń ju 256 KB lọ déédéé) ṣubú sí ìṣiṣẹ́ lẹ́ẹ̀kan náà tó fẹ́rẹ̀ẹ́ jẹ́
1, ó sì ń dá 503 padà lábẹ́ ẹrù tó ṣe déédéé pátápátá. Olùṣọ́ náà ti ń ṣàtúnṣe ara rẹ̀ báyìí: a ń darí rẹ̀
pẹ̀lú ìnáwó BÁÌTÌ gbígbàwọlé tí a yọ jáde láìfọwọ́sí (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) tí a wọ̀n láti inú
òpin ìrántí gidi ti ilànà náà, ó sì tún ń ṣàyẹ̀wò àmì ìfúnpá ohun-èlò tó ń ṣẹlẹ̀ lọ́wọ́lọ́wọ́ — nítorí náà, ó
máa ń dín ẹrù kù nígbà tí agbàlejò bá wà lábẹ́ ìfúnpá ìrántí gidi nìkan, kì í ṣe nítorí pé ìbéèrè wúwo tó ju ẹyọ kan lọ
dé lẹ́ẹ̀kan náà. A ṣì ń bọ̀wọ̀ fún òpin iye àtijọ́ (`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`), ṣùgbọ́n
nígbà tí o bá ṣètò rẹ̀ ní pàtó nìkan.

Nígbà tí agbára bá dí, ìbéèrè ohun-èlò wúwo kan yóò kọ́kọ́ dúró fún tó
`OMNIROUTE_CHAT_ADMISSION_QUEUE_MS` (àiyipada `2000`, `0` máa ń pa ìdúró náà) kí àyè lè ṣí sílẹ̀
ṣáájú dídá `503` tí a lè tún gbìyànjú padà. Ìdúró tó ní ààlà náà wà kí àwọn oníbàárà irú-aṣojú
(OpenCode, Claude Code, Cursor) tí ń tan àwọn ìbéèrè-kékeré wúwo ká lẹ́ẹ̀kan náà lè ṣètò ìbúgbàù náà ní ọ̀kọ̀ọ̀kan
dípò kí wọ́n lo gbogbo ìnáwó àtúngbìyànjú wọn lórí ìkọ̀sílẹ̀ lẹ́sẹ̀kẹsẹ̀, kí wọ́n sì dáwọ́ dúró láárín iṣẹ́.
Ìkúnwọ̀n ìyálò ohun-èlò wúwo lọ́wọ́lọ́wọ́, ìnáwó báìtì tí a ti yanjú, àti bí ìfúnpá tó ń ṣẹlẹ̀ lọ́wọ́lọ́wọ́ ṣe le tó ni a
fi hàn ní `GET /api/monitoring/health` → `chatAdmission` (`inflightBytes`, `maxInflightBytes`,
`budgetSource`, `pressureSeverity`, `countCapEnabled`) — ṣàyẹ̀wò àwọn wọ̀nyí ṣáájú kí o tó fọwọ́ kan env var èyíkéyìí.
Settings → Resilience → Request Queue → Concurrent Requests kò darí èyí; ètò yẹn
ń darí ẹ̀rọ ìlà-ìbéèrè olùpèsè ọ̀tọ̀.

**Àtúnṣe:**

1. Kọ́kọ́ tún gbìyànjú. Àwọn oníbàárà gbọ́dọ̀ tẹ̀lé `Retry-After`, kí wọ́n sì lo ìfàsẹ́yìn dípò kí wọ́n
   tún ìbéèrè náà ṣe lẹ́sẹ̀kẹsẹ̀.
2. Ṣàyẹ̀wò `/api/monitoring/health` → `chatAdmission` ṣáájú ṣíṣe àtúnṣe ohunkóhun. `countCapEnabled:
false` àti `maxInflightBytes` tó pọ̀ túmọ̀ sí pé ìnáwó tí a yọ jáde láìfọwọ́sí ti ń ṣe
   iṣẹ́ rẹ̀; `pressureSeverity` ti `high`/`critical` túmọ̀ sí pé ìrántí agbàlejò náà kéré gan-an —
   a kò lè tún èyí ṣe pẹ̀lú env var ìgbàwọlé; ó nílò RAM púpọ̀ sí i tàbí ẹrù iṣẹ́ tó kéré sí i.
3. Kìkì bí `/api/monitoring/health` bá fi hàn pé ìnáwó tí a yọ jáde láìfọwọ́sí kéré jù fún
   agbàlejò rẹ (ó ṣọ̀wọ́n — ó ti ń ṣe ìwọ̀n láti inú container dé bare-metal), kọjá rẹ̀ ní tààrà pẹ̀lú
   `OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES` dípò pípadà sí òpin iye ìbéèrè àtijọ́.

Wo [ìtọ́kasí environment-variable](../reference/ENVIRONMENT.md#4-security--authentication)
fún àwọn ètò ìgbàwọlé aláṣẹ.

## Ìṣètò àṣàyàn fún ìpínrú ìkùnà RAG / LLM (ìṣòro 16)

Àwọn olùlo OmniRoute kan máa ń gbé gateway sí iwájú àwọn ètò RAG tàbí agent. Nínú irú àwọn ìṣètò bẹ́ẹ̀, ó wọ́pọ̀ láti rí àpẹẹrẹ àjèjì kan: OmniRoute dà bí ẹni pé ó ń ṣiṣẹ́ dáadáa (àwọn provider wà lórí afẹ́fẹ́, àwọn routing profile dára, kò sí ìkìlọ̀ rate limit), ṣùgbọ́n ìdáhùn ìkẹyìn ṣì jẹ́ àṣìṣe.

Ní ìṣe, àwọn ìṣẹ̀lẹ̀ wọ̀nyí sábà máa ń wá láti inú pipeline RAG tó wà lẹ́yìn rẹ̀, kì í ṣe láti inú gateway fúnra rẹ̀.

Tí o bá fẹ́ àwọn ọ̀rọ̀ àjọpín láti ṣàpèjúwe àwọn ìkùnà wọ̀nyẹn, o lè lo WFGY ProblemMap, ohun àmúlò ọ̀rọ̀ ìta kan tó ní ìwé-àṣẹ MIT, èyí tó ṣàlàyé àwọn àpẹẹrẹ ìkùnà RAG / LLM mẹ́rìndínlógún tó máa ń ṣẹlẹ̀ léraléra. Ní ìpele gíga, ó kó àwọn wọ̀nyí sínú:

- yíyapa retrieval kúrò ní ibi tó yẹ àti àwọn ààlà context tó bàjẹ́
- àwọn index àti vector store tó ṣófo tàbí tó ti pẹ́
- àìbáramu láàárín embedding àti semantic
- àwọn ìṣòro pípèsè prompt àti context window
- wólulẹ̀ logic àti àwọn ìdáhùn tó ní ìgbẹ́kẹ̀lé àpọ̀jù
- àwọn ìkùnà nínú chain gígùn àti ìṣọ̀kan àwọn agent
- memory àwọn multi agent àti yíyapa role
- àwọn ìṣòro bí deployment àti bootstrap ṣe tẹ̀lé ara wọn

Èrò náà rọrùn:

1. Nígbà tí o bá ń ṣèwádìí ìdáhùn tí kò dára, ṣàkọsílẹ̀:
   - iṣẹ́ àti ìbéèrè olùlo
   - route tàbí àkójọpọ̀ provider nínú OmniRoute
   - context RAG èyíkéyìí tí a lò lẹ́yìn rẹ̀ (àwọn document tí a retrieve, àwọn tool call, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ)
2. Ṣe ìbámu ìṣẹ̀lẹ̀ náà pẹ̀lú nọ́ńbà WFGY ProblemMap kan tàbí méjì (`No.1` … `No.16`).
3. Fi nọ́ńbà náà pamọ́ sínú dashboard, runbook, tàbí incident tracker rẹ lẹ́gbẹ̀ẹ́ àwọn log OmniRoute.
4. Lo ojú-ewé WFGY tó bá a mu láti pinnu bóyá o nílò láti yí RAG stack, retriever, tàbí routing strategy rẹ padà.

Gbogbo ọ̀rọ̀ àti àwọn ìlànà ìṣe tó ṣe kedere wà níbí (ìwé-àṣẹ MIT, ọ̀rọ̀ nìkan):

[README WFGY ProblemMap](https://github.com/onestardao/WFGY/blob/main/ProblemMap/README.md)

O lè foju kọ abala yìí tí o kò bá ń ṣiṣẹ́ RAG tàbí àwọn pipeline agent lẹ́yìn OmniRoute.

## Àwọn Ìṣòro Tí A Mọ̀ Nípa v3.8.0

Àwọn ìṣòro tó jẹ́ pàtó sí ìtújáde v3.8.0 àti àwọn ọ̀nà àtúnṣe wọn lọ́wọ́lọ́wọ́. Tí àtúnṣe bá dé nínú patch tó tẹ̀ lé e, a ó ṣe àfikún sí àkọsílẹ̀ náà tàbí yọ ọ́ kúrò.

### Àwọn ìkùnà ìfàṣẹsí Devin CLI

**Àwọn àmì:**

- "A kò rí Devin CLI" tàbí "ìfàṣẹsí kùnà" nígbà tí a bá ń pe àwọn irinṣẹ́ tó gbára lé Devin
- Àyẹ̀wò runtime CLI fi `installed=false` hàn

**Àwọn okùnfà:**

- `CLI_DEVIN_BIN` tọ́ka sí path tí kò sí
- A kò fi Devin CLI sori host náà

**Àtúnṣe:**

1. Fi Devin CLI sori ẹrọ fún platform rẹ
2. Ṣètò `CLI_DEVIN_BIN=/usr/local/bin/devin` (tàbí path gidi náà) nínú `.env`
3. Tun OmniRoute bẹ̀rẹ̀, kí o sì tún ṣe àyẹ̀wò láti **Dashboard → Àwọn Irinṣẹ́ CLI**

### Model cooldown di (àtúntò pẹ̀lú ọwọ́)

**Àwọn àmì:**

- Model kan ṣì wà nínú àkójọ cooldown lẹ́yìn tí àkókò ìparí ti kọjá
- Àwọn ìbéèrè ṣì ń fo model náà nínú combo routing bó tilẹ̀ jẹ́ pé timestamp náà ti kọjá

**Àtúntò pẹ̀lú ọwọ́:**

- **Dashboard:** **Àwọn Ètò → Àwọn Cooldown Model** → tẹ **Mú Ṣiṣẹ́ Padà** lórí card tó ní ìṣòro
- **API:** `DELETE /api/resilience/model-cooldowns` pẹ̀lú àwọn header ìfàṣẹsí ìṣàkóso

### Ìsopọ̀ provider Command Code kùnà pẹ̀lú 403

**Àwọn àmì:**

- 403 nígbà tí a bá ń dán ìsopọ̀ provider Command Code wò
- Card provider náà fi "kò ní àṣẹ" hàn lẹ́yìn fífi kún un tuntun

**Okùnfà:** Ìṣàn OAuth kò parí (a kò gba callback tàbí a kò fi token pamọ́).

**Àtúnṣe:**

- Ṣiṣe `omniroute providers` láti CLI láti tún ìṣàn OAuth bẹ̀rẹ̀, tàbí
- Tún OAuth ṣe láti **Dashboard → Àwọn Provider → Command Code → Tún Sopọ̀**

### ModelScope dá àwọn cooldown 429 tó le padà

**Àwọn àmì:**

- Àwọn cooldown tó kúrú gan-an tàbí tó bẹ̀rẹ̀ lẹ́sẹ̀kẹsẹ̀ lórí ModelScope lẹ́yìn ìṣàn kékeré ti àwọn ìbéèrè
- Combo routing fo ModelScope ṣáájú àkókò tí a retí

**Okùnfà:** ModelScope ń fi àwọn header `Retry-After` tó jẹ́ pàtó sí provider ránṣẹ́. v3.8.0 ní ìmúlò pàtó fún àwọn header wọ̀nyẹn, nítorí náà àwọn version àtijọ́ máa ń túmọ̀ wọn lọ́nà tí kò tọ́ gẹ́gẹ́ bí àwọn àmì rate-limit gbogbogbò.

**Àtúnṣe:**

- Rí i dájú pé o wà lórí v3.8.0 tàbí èyí tó tuntun sí i
- Ṣàyẹ̀wò pé toggle `useUpstream429BreakerHints` ti ṣiṣẹ́ lábẹ́ **Àwọn Ètò → Ìfaradà**

### OMNIROUTE_WS_BRIDGE_SECRET kò sí ní production

**Àwọn àmì:**

- 401 lórí gbogbo ìbéèrè WebSocket bridge Codex/Responses nígbà tí a bá ń ṣiṣẹ́ lórí host production jíjìn
- Handshake WebSocket bridge pa lẹ́sẹ̀kẹsẹ̀ lẹ́yìn ìsopọ̀

**Okùnfà:** Env var `OMNIROUTE_WS_BRIDGE_SECRET` kò sí nínú environment production.

**Àtúnṣe:**

1. Ṣẹ̀dá secret aláìlétò kan: `openssl rand -hex 32`
2. Ṣètò `OMNIROUTE_WS_BRIDGE_SECRET=<random-secret>` nínú env server production (àti nínú client èyíkéyìí tó ń bá bridge náà sọ̀rọ̀)
3. Tun OmniRoute bẹ̀rẹ̀

### Responses API: background mode dín kù sí synchronous

**Àwọn àmì:**

- Ìkìlọ̀ tí a kọ sínú log: `background mode degraded to synchronous`
- Ìbéèrè `background: true` kan dá ìdáhùn synchronous déédéé padà dípò handle iṣẹ́ background

**Okùnfà:** v3.8.0 mọ̀ọ́mọ̀ dín `background: true` lórí Responses API kù sí ìṣiṣẹ́ synchronous nígbà tó ń fi ìkìlọ̀ jáde. Ìṣiṣẹ́ async background tó péye jẹ́ ohun tí a ó pèsè lọ́jọ́ iwájú.

**Àtúnṣe:**

- Ṣàtúnṣe client náà kí ó pe láìlo `background`, tàbí
- Dúró de ìtújáde tó tẹ̀ lé e tí yóò ní async background mode tó péye (tọpinpin changelog náà)

## Ìbẹ̀rẹ̀ Tí Ó Falẹ̀ / Àkókò Ìmúrasílẹ̀ Tó Parí

Tí CLI bá tẹ̀wé `⚠ Server did not respond within 60s` ṣùgbọ́n server náà ń ṣiṣẹ́
ní tòótọ́, àkókò tí a yàn fún ìṣàyẹ̀wò ìmúrasílẹ̀ kéré jù fún àyíká rẹ.

Èyí sábà máa ń ṣẹlẹ̀ lórí Windows (antivirus, àwọn filesystem watchers) tàbí nínú containers
tí iṣẹ́ ìbẹ̀rẹ̀ wọn pọ̀.

**Àtúnṣe — mú àkókò náà pọ̀ sí i:**

```bash
# Nípasẹ̀ env var (yóò wà bẹ́ẹ̀ láàárín àwọn ìbẹ̀rẹ̀):
export OMNIROUTE_READY_TIMEOUT_MS=180000   # ìṣẹ́jú 3
omniroute serve

# Nípasẹ̀ àsìá CLI (fún ẹ̀ẹ̀kan ṣoṣo):
omniroute serve --ready-timeout 180000
```

Ìwọ̀n àkókò àiyipada jẹ́ 60 000 ms (60 s). Ìkìlọ̀ náà jẹ́ fún ìfitónilétí nìkan; server náà
yóò tẹ̀síwájú láti bẹ̀rẹ̀ ní abẹ́lẹ̀, a ó sì lè ráyè sí i lẹ́yìn tí ìbẹ̀rẹ̀ bá parí.

Wo [`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md) fún gbogbo
àlàyé nípa `OMNIROUTE_READY_TIMEOUT_MS`.
