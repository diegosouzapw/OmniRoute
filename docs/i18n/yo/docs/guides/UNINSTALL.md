## Yíyọ Kánkán (v3.6.2+)

OmniRoute pèsè àwọn skripti méjì tí a kọ sínú rẹ̀ fún yíyọ tó mọ́ tónítóní:

### Pa Dátà Rẹ Mọ́

```bash
npm run uninstall
```

Èyí yóò yọ ohun èlò OmniRoute kúrò ṣùgbọ́n yóò **pa** ibi ìpamọ́ dátà, àwọn àtòpọ̀, àwọn kọ́kọ́rọ́ API, àti àwọn ààtò olùpèsè rẹ mọ́ sínú `~/.omniroute/`. Lo èyí bí o bá pinnu láti tún un fi sílẹ̀ nígbà tó bá yá, tí o sì fẹ́ pa ètò rẹ mọ́.

### Yíyọ Pátápátá

```bash
npm run uninstall:full
```

Èyí yóò yọ ohun èlò náà kúrò, yóò sì **pa gbogbo dátà rẹ́ títí láé**:

- Ibi ìpamọ́ dátà (`storage.sqlite`)
- Àwọn àtòpọ̀ olùpèsè àti àwọn kọ́kọ́rọ́ API
- Àwọn fáìlì àfẹ́yìntì
- Àwọn fáìlì àkọsílẹ̀
- Gbogbo fáìlì inú àkọsílẹ̀ `~/.omniroute/`

> ⚠️ **Ìkìlọ̀:** `npm run uninstall:full` kò ṣeé dá padà. Gbogbo àwọn àsopọ̀ olùpèsè rẹ, àwọn àkójọpọ̀, àwọn kọ́kọ́rọ́ API, àti ìtàn lílò rẹ ni a ó parẹ́ títí láé.

## Yíyọ Pẹ̀lú Ọwọ́

### Fífì NPM Sílẹ̀ Kárí Ayé

```bash
# Yọ package kárí ayé kúrò
npm uninstall -g omniroute

# (Kì í ṣe dandan) Yọ àkọsílẹ̀ dátà kúrò
rm -rf ~/.omniroute
```

### Fífì pnpm Sílẹ̀ Kárí Ayé

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Dá container dúró kí o sì yọ ọ́ kúrò
docker stop omniroute
docker rm omniroute

# Yọ volume kúrò (ó ń pa gbogbo dátà rẹ́)
docker volume rm omniroute-data

# (Kì í ṣe dandan) Yọ image náà kúrò
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Dá àwọn container dúró kí o sì yọ wọ́n kúrò
docker compose down

# Yọ àwọn volume náà pẹ̀lú (ó ń pa gbogbo dátà rẹ́)
docker compose down -v
```

### Ohun Èlò Ojú-iṣẹ́ Electron

**Windows:**

- Ṣí `Settings → Apps → OmniRoute → Uninstall`
- Tàbí ṣiṣẹ́ ohun èlò NSIS uninstaller láti inú àkọsílẹ̀ fífìsílẹ̀

**macOS:**

- Fa `OmniRoute.app` láti `/Applications` sínú Trash
- Yọ dátà kúrò: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Yọ fáìlì AppImage kúrò
- Yọ dátà kúrò: `rm -rf ~/.omniroute`

### Fífì Láti Orísun Sílẹ̀ (git clone)

```bash
# Yọ àkọsílẹ̀ tí a ṣe clone rẹ̀ kúrò
rm -rf /path/to/omniroute

# (Kì í ṣe dandan) Yọ àkọsílẹ̀ dátà kúrò
rm -rf ~/.omniroute
```

## Àwọn Àkọsílẹ̀ Dátà

OmniRoute máa ń tọ́jú dátà sí àwọn ibi wọ̀nyí nípa àìyípadà:

| Pẹpẹ        | Ọ̀nà Àìyípadà                  | Ìyípadà                         |
| ----------- | ----------------------------- | ------------------------------- |
| Linux       | `~/.omniroute/`               | àyípadà àyíká `DATA_DIR`        |
| macOS       | `~/.omniroute/`               | àyípadà àyíká `DATA_DIR`        |
| Windows     | `%APPDATA%/omniroute/`        | àyípadà àyíká `DATA_DIR`        |
| Docker      | `/app/data/` (volume tí a so) | àyípadà àyíká `DATA_DIR`        |
| Tó tẹ̀lé XDG | `$XDG_CONFIG_HOME/omniroute/` | àyípadà àyíká `XDG_CONFIG_HOME` |

### Àwọn fáìlì inú àkọsílẹ̀ dátà

| Fáìlì/Àkọsílẹ̀        | Àpèjúwe                                                    |
| -------------------- | ---------------------------------------------------------- |
| `storage.sqlite`     | Ibi ìpamọ́ dátà àkọ́kọ́ (àwọn olùpèsè, àkójọpọ̀, ààtò, kọ́kọ́rọ́) |
| `storage.sqlite-wal` | Àkọsílẹ̀ SQLite ṣáájú kíkọ (fún ìgbà díẹ̀)                   |
| `storage.sqlite-shm` | Ìrántí pínpín SQLite (fún ìgbà díẹ̀)                        |
| `call_logs/`         | Àwọn àpamọ́ payload ìbéèrè                                  |
| `backups/`           | Àwọn àfẹ́yìntì ibi ìpamọ́ dátà aládàáṣe                      |
| `log.txt`            | Àkọsílẹ̀ ìbéèrè àtijọ́ (kì í ṣe dandan)                      |

## Ṣàyẹ̀wò Pé Ìyọkúrò Ti Pé

Lẹ́yìn yíyọ ọ́ kúrò, ṣàyẹ̀wò pé kò sí fáìlì kankan tó ṣẹ́kù:

```bash
# Ṣàyẹ̀wò package npm àgbáyé
npm list -g omniroute 2>/dev/null

# Ṣàyẹ̀wò ìtọ́nisọ́nà data
ls -la ~/.omniroute/ 2>/dev/null

# Ṣàyẹ̀wò àwọn process tó ń ṣiṣẹ́
pgrep -f omniroute
```

Tí process èyíkéyìí bá ṣì ń ṣiṣẹ́, dá a dúró:

```bash
pkill -f omniroute
```
