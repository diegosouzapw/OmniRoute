## 1. Antigravity pẹ̀lú Antigravity CLI (agy)

Àwọn olùpèsè méjèèjì ń lo **Google backend kan náà** — OAuth client, ìmúdójúìwọ̀n token, endpoints, àti àwọn àkọọ́lẹ̀ Google tó jẹ́ ọ̀kan náà. Ìyàtọ̀ náà ni àwọn model tí o rí.

> Wo [ìkéde Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli) fún ìfiwéra àṣẹ láti ọ̀dọ̀ Google.

| Abala                 | `antigravity` (IDE)                                           | `agy` (CLI)                                                       |
| --------------------- | ------------------------------------------------------------- | ----------------------------------------------------------------- |
| **Ọjà Google**        | Antigravity 2.0 / Antigravity IDE                             | Antigravity CLI                                                   |
| **Backend**           | Google Cloud Code API kan náà                                 | Google Cloud Code API kan náà                                     |
| **OAuth / Token**     | Client kan náà, ìmúdójúìwọ̀n kan náà                           | Client kan náà, ìmúdójúìwọ̀n kan náà                               |
| **Àkójọ model**       | Àkójọ àṣàyàn tó dúró ṣinṣin (tí a kọ sínú OmniRoute ní tààrà) | Tí a ń ṣàyẹ̀wò lọ́wọ́lọ́wọ́ láti Google nípasẹ̀ `:fetchAvailableModels` |
| **Àwọn model Claude** | Sonnet 4.6, Opus 4.6 (oríṣìíríṣìí 4 fún ọ̀kọ̀ọ̀kan)              | Sonnet 4.6, Opus 4.6 (oríṣìíríṣìí 4 fún ọ̀kọ̀ọ̀kan)                  |
| **Ìsọ̀rúkọ Gemini**    | Àwọn àmì tó mọ́ (Low/Medium/High)                              | Àwọn ID láti upstream (extra-low/low/agent)                       |
| **Àwọn model àfikún** | `gpt-oss-120b-medium`                                         | Ó lè ní àwọn model àfikún láti Google                             |
| **Ìlò àkọ́kọ́**         | Ìṣọ̀kan IDE (VS Code, JetBrains)                               | Ààyè CLI / API                                                    |
| **Ìpín ààlà**         | Pín pẹ̀lú agy (àkọọ́lẹ̀ Google kan náà)                          | Pín pẹ̀lú antigravity (àkọọ́lẹ̀ Google kan náà)                      |

**Àwọn model tó wà (tí a fi àdánwò ṣàrídájú, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (pẹ̀lú onírúurú ipele ìrònú)
- Claude: Sonnet 4.6, Opus 4.6 (ọ̀kọ̀ọ̀kan pẹ̀lú àwọn oríṣìíríṣìí default/low/medium/high)
- Àwọn míì: GPT-OSS 120B Medium
- **Claude Sonnet 5 kò sí** — àwọn oríṣìíríṣìí 4.6 nìkan ni a ń ṣe àtìlẹ́yìn fún

**Ìdí tí àkójọ model fi yàtọ̀**: CLI ti Google jẹ́ èyí tí a “ṣàtúnṣe fún iyára àti ìnáwó iṣẹ́ kékeré” tí a sì “ṣe àtúnṣe rẹ̀ papọ̀ pẹ̀lú àwọn model Gemini” (gẹ́gẹ́ bí búlọ́ọ̀gù àṣẹ Google ṣe sọ). Ọjà Web/IDE jẹ́ èyí tí a “ṣàtúnṣe fún ìkárí gbogbo.” CLI ń lo `:fetchAvailableModels` láti ṣàwárí àwọn model ní aládàáṣiṣẹ́, nígbà tí IDE ń lo àkójọ àṣàyàn tó dúró ṣinṣin.

**Ní ìlò gangan**: Lo ìpele-ìṣáájú `agy/` fún àwọn model Gemini (fún àpẹẹrẹ `agy/gemini-3.7-flash-high`). Lo `antigravity/` fún àkójọ àṣàyàn tó dúró ṣinṣin. Àwọn méjèèjì ń kan Google backend kan náà, ṣùgbọ́n wọ́n ń fi àwọn ọ̀nà ìsọ̀rúkọ model tó yàtọ̀ hàn. Ìpín ààlà náà jẹ́ pípín — lílo èyíkéyìí nínú àwọn olùpèsè náà ni a ó kà mọ́ àwọn ààlà àkọọ́lẹ̀ Google kan náà.

## 3. Bí O Ṣe Lè Gba projectId

Gbogbo àsopọ̀ antigravity/agy nílò Google Cloud Code `projectId`. Láìsí i, ojú-ọ̀nà `/v1internal:models` máa dá 404 padà.

### Ọ̀nà A: Fúnra Rẹ̀ (A Dábàá Rẹ̀)

OmniRoute máa ń bójú tó èyí fúnra rẹ̀. Nígbà tí o bá fi àkọọ́lẹ̀ Google tuntun kun nípasẹ̀ Dashboard OAuth:

1. OmniRoute máa sọ token náà di tuntun
2. Ó máa pe `loadCodeAssist` láti ṣàwárí projectId
3. Bí project kankan kò bá sí, ó máa pe `onboardUser` láti dá ọ̀kan sílẹ̀
4. Ó máa tún `loadCodeAssist` gbìyànjú láti gba projectId tí a ṣẹ̀ṣẹ̀ dá sílẹ̀
5. Ó máa fi pamọ́ sínú ibi ìpamọ́ dátà

**Èyí ń ṣiṣẹ́ fún ọ̀pọ̀ jù lọ àwọn àkọọ́lẹ̀** — kò nílò ìgbésẹ̀ ọwọ́ kankan.

### Ọ̀nà B: Pẹ̀lú Ọwọ́ nípasẹ̀ agy CLI

Bí ìṣàwárí aládàáṣiṣẹ́ bá kùnà (wo Abala 5 fún ìgbà tí èyí máa ń ṣẹlẹ̀):

```bash
# Fi agy CLI sí ẹrọ (bí kò bá sí tẹ́lẹ̀)
npm install -g @anthropic-ai/agy

# Wọlé pẹ̀lú àkọọ́lẹ̀ Google rẹ
agy login

# Yan àkọọ́lẹ̀ tí ó nílò ìforúkọsílẹ̀
# Èyí máa bẹ̀rẹ̀ ìforúkọsílẹ̀ Cloud Code, yóò sì yan projectId kan
```

Lẹ́yìn tí `agy login` bá ṣàṣeyọrí, sọ token náà di tuntun nínú OmniRoute Dashboard. A ó ṣàwárí projectId náà fúnra rẹ̀.

### Bí a ṣe lè ṣàyẹ̀wò rẹ̀

Ṣàyẹ̀wò ibi ìpamọ́ dátà:

```bash
# Nínú container OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Tàbí ṣàyẹ̀wò àwọn àkọsílẹ̀:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. URI Ìdarípadà OAuth

### Ìṣòro Náà

Google OAuth nílò URI ìdarípadà tó fẹsẹ̀ múlẹ̀. Ètò àiyípadà OmniRoute ń lo `http://127.0.0.1:20128/callback` (loopback). Èyí ń ṣiṣẹ́ fún àwọn build agbègbè ṣùgbọ́n **kì í ṣiṣẹ́ fún àwọn ìmúṣiṣẹ́ lórí ẹ̀rọ jíjìnnà** (fún àpẹẹrẹ, server tí a ń ráyè sí nípasẹ̀ LAN IP).

Google máa kọ àwọn URI ìdarípadà tí:

- Ó lo àwọn àdírẹ́sì IP (ó gbọ́dọ̀ jẹ́ domain tó parí sí `.com`, `.org`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ)
- Kò bá àwọn URI ìdarípadà tí a forúkọsílẹ̀ mu nínú àtòpọ̀ OAuth client

### Ojútùú Náà

**Àṣàyàn A: Lo ìṣàn OAuth tí a kọ sínú rẹ̀ (àiyípadà)**

- Ó ń ṣiṣẹ́ nígbà tí o bá ráyè sí OmniRoute láti `localhost` tàbí `127.0.0.1`
- Kò nílò àtòpọ̀ kankan

**Àṣàyàn B: Àwọn ẹ̀rí OAuth àkànṣe**

- Ṣètò `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` nínú environment rẹ
- Pèsè àwọn ẹ̀rí Google OAuth tirẹ:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Forúkọsílẹ̀ `https://your-domain.com/callback` gẹ́gẹ́ bí URI ìdarípadà tí a fún láṣẹ nínú Google Cloud Console

**Àṣàyàn C: Lo agy CLI fún ìwọlé àkọ́kọ́**

- Ṣiṣe `agy login` lórí ẹ̀rọ tí yóò ráyè sí OmniRoute
- Ìṣàn OAuth yóò parí ní agbègbè ẹ̀rọ náà, a ó sì tọ́jú àwọn token
- Gbé ìsopọ̀ náà wọ OmniRoute nípasẹ̀ Dashboard

### Àwọn Ààlà

- Àwọn ẹ̀rí OAuth àkànṣe nílò orúkọ domain (Google kì í gba àwọn àdírẹ́sì IP gẹ́gẹ́ bí URI ìdarípadà)
- Tí o kò bá ní domain, lo Àṣàyàn A tàbí C dípò rẹ̀

## 5. Yíyanjú Ìṣòro: Nígbà Tí Ìṣètò Aládàáṣiṣẹ́ Bá Kùnà

OmniRoute máa ń ṣàwárí projectId, ó sì máa ń ṣe onboarding láìfọwọ́ṣe fún ọ̀pọ̀lọpọ̀ account. Nígbà tí èyí bá kùnà, ọ̀kan lára àwọn wọ̀nyí ni ó sábà máa ń fa ìṣòro náà:

### A ti dí agbègbè account náà

**Àmì**: `agy login` dáhùn pé "Àyẹ̀wò ẹ̀tọ́ kùnà: Account rẹ lọ́wọ́lọ́wọ́ kò lẹ́tọ̀ọ́ sí Antigravity, nítorí kò tíì sí ní agbègbè rẹ."

**Ohun tó fa ìṣòro náà**: Àwọn Google account ní field "Country Association" kan ní backend, tí a ṣètò nígbà ìforúkọsílẹ̀. agy CLI àti Cloud Code API máa ń yẹ field yìí wò pẹ̀lú ìmúná tó muna — kò dà bí web Gemini, èyí tí ó máa ń yẹ IP rẹ lọ́wọ́lọ́wọ́ nìkan wò.

> Láti yẹ agbègbè tí a so mọ́ account rẹ wò tàbí láti yí i padà, ṣàbẹ̀wò sí [Google Country Association Form](https://policies.google.com/country-association-form).

**Ìdí tí web Gemini fi ń ṣiṣẹ́ ṣùgbọ́n tí agy kò fi ṣiṣẹ́**:

- Web Gemini / Google One: ó máa ń yẹ IP lọ́wọ́lọ́wọ́ nìkan wò (proxy lè kọjá àyẹ̀wò náà)
- agy CLI / Cloud Code API: ó máa ń ka field Country Association tó wà ní backend (proxy kò lè ṣèrànwọ́)

**Àtúnṣe**:

1. Ṣàbẹ̀wò sí [Google Country Association Form](https://policies.google.com/country-association-form) nígbà tí o wà lórí US IP
2. Fi ìbéèrè ìyípadà agbègbè sílẹ̀ (yan "Mo ń gbé ní orílẹ̀-èdè mìíràn")
3. Dúró fún wákàtí 1-24 kí Google lè ṣiṣẹ́ lórí rẹ̀ + ìfitónilétí email
4. Lẹ́yìn náà, `agy login` yẹ kí ó ṣiṣẹ́

### Account náà kò ní project Cloud Code

**Àmì**: Àwọn àkọsílẹ̀ fi `loadCodeAssist returned no project id` àti `onboardUser failed (400)` hàn.

**Ohun tó fa ìṣòro náà**: A kò tíì forúkọsílẹ̀ account náà pẹ̀lú Google Cloud Code rí, onboarding aládàáṣiṣẹ́ náà sì kùnà.

**Àtúnṣe**: Ṣiṣe `agy login` fúnra rẹ láti bẹ̀rẹ̀ ìforúkọsílẹ̀ Cloud Code, lẹ́yìn náà tún token náà sọ di tuntun nínú OmniRoute Dashboard.

### Token ti parí tàbí a ti fagilé rẹ̀

**Àmì**: Àwọn àṣìṣe 401 nínú àwọn àkọsílẹ̀, tàbí àwọn ifiranṣẹ́ "Token ti parí".

**Àtúnṣe**: Tún token náà sọ di tuntun ní Dashboard → Providers → agy → Tẹ àmì ìtúnṣe. Tí refresh token fúnra rẹ̀ bá ti di fífagilé, ìwọ yóò ní láti tún ṣe ìfàṣẹsí nípasẹ̀ OAuth.
