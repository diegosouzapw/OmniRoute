Ìtọ́sọ́nà yìí ṣàlàyé bí a ṣe lè ṣàfikún àwọn àkọọ́lẹ̀ Kiro (olùrànlọ́wọ́ ìkọ́ kóòdù AI tí AWS gbàlejò) sí OmniRoute,
pẹ̀lú àkíyèsí pàtàkì lórí ṣíṣe àwọn àkọọ́lẹ̀ púpọ̀ ní àkókò kan náà láìsí ìforígbárí sáà.

---

## Àlàyé Ìpìlẹ̀: Ìdí Tí Àwọn Àkọọ́lẹ̀ Kiro Fi Lè Forígbárí

Ẹ̀yìn-ọ̀rọ̀ Kiro ń lo àwọn ìforúkọsílẹ̀ oníbàárà AWS SSO OIDC láti tọpinpin àwọn sáà tó ń ṣiṣẹ́.
Ìdíwọ́ pàtàkì náà ni pé: **ìforúkọsílẹ̀ oníbàárà OIDC kọ̀ọ̀kan ń ṣe àtìlẹ́yìn fún sáà kan ṣoṣo
tó ń ṣiṣẹ́ ní àkókò kan**. Nígbà tí ẹ̀rọ kejì tàbí aṣàmúlò kejì bá ṣe ìfàṣẹsí nípa lílo
oníbàárà kan náà tí a forúkọ rẹ̀ sílẹ̀, ẹ̀yìn-ọ̀rọ̀ náà yóò sọ àmì ìdánimọ̀ ìmúdọ̀tun ti àkọọ́lẹ̀ àkọ́kọ́ di asán.

Èyí jẹ́ ìlànà kan náà tó máa ń fa ìṣòro nígbà tí a bá ń ṣiṣẹ́ `kiro-cli login` lórí
ẹ̀rọ kan níbi tí àkọọ́lẹ̀ Kiro mìíràn ti wọlé tẹ́lẹ̀ — ìwọlé tuntun náà máa fagilé
àmì ìdánimọ̀ àkọọ́lẹ̀ àkọ́kọ́.

---

## Bí OmniRoute Ṣe Yanjú Èyí (v3.8.0+)

Bẹ̀rẹ̀ láti v3.8.0, OmniRoute máa ń pe `registerClient()` (AWS SSO OIDC) nígbà gbogbo
tí a bá ń ṣàgbéwọlé ìsopọ̀ Kiro. Èyí ń fún ìsopọ̀ OmniRoute kọ̀ọ̀kan ní ìforúkọsílẹ̀ oníbàárà OIDC
tí a yà sọ́tọ̀ fún un. Nítorí pé ìforúkọsílẹ̀ oníbàárà kọ̀ọ̀kan dá dúró lọ́tọ̀, ìmúdọ̀tun tàbí
ìfàṣẹsí àkọọ́lẹ̀ kan lẹ́ẹ̀kan sí i kò ní ipa lórí àmì ìdánimọ̀ ìmúdọ̀tun ti àkọọ́lẹ̀ mìíràn.

Ìyàsọ́tọ̀ náà kan àwọn ọ̀nà ìṣàgbéwọlé àmì ìdánimọ̀ ìmúdọ̀tun, nígbà tí ìfàṣẹsí kọ́kọ́rọ́ API sì
yẹra fún àwọn sáà ìmúdọ̀tun OIDC pátápátá:

| Ọ̀nà ìṣàgbéwọlé                                                      | Ipò ìyàsọ́tọ̀                                                                                                                  |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Ìṣàn kóòdù-ẹ̀rọ AWS Builder ID / IDC                                 | Ti wà ní ìyàsọ́tọ̀ láti ìgbà tí a ti ṣe àgbékalẹ̀ ìṣàn kóòdù-ẹ̀rọ                                                                |
| **Ṣàgbéwọlé Àmì Ìdánimọ̀** (lílu àmì ìdánimọ̀ ìmúdọ̀tun mọ́lẹ̀ pẹ̀lú ọwọ́) | Ti wà ní ìyàsọ́tọ̀ láti v3.8.0                                                                                                 |
| **Ìwọlé Google / GitHub**                                           | Ti wà ní ìyàsọ́tọ̀ láti v3.8.0                                                                                                 |
| **Ìṣàgbéwọlé Aládàáṣiṣẹ́** (kiro-cli SQLite)                         | Ti wà ní ìyàsọ́tọ̀ láti v3.8.0 (ọ̀nà SQLite ti wà ní ìyàsọ́tọ̀ tẹ́lẹ̀; àṣàyàn ìpadà-sẹ́yìn ibi-ìpamọ́ SSO náà ti wà ní ìyàsọ́tọ̀ báyìí) |
| **Kọ́kọ́rọ́ API** (kọ́kọ́rọ́ CodeWhisperer ọlọ́jọ́-pípẹ́)                    | Kò ní sáà ìmúdọ̀tun; a fìdí kọ́kọ́rọ́ náà múlẹ̀, a sì tọ́jú rẹ̀ gẹ́gẹ́ bí ẹ̀rí ìwọlé bearer                                            |

## Àkíyèsí Ìṣíkiri fún Àwọn Ìsopọ̀ Tí A Ṣẹ̀dá Ṣáájú v3.8.0

Àwọn ìsopọ̀ tí a ṣàgbéwọlé ṣáájú v3.8.0 kò ní ìforúkọsílẹ̀ oníbàárà OIDC tí a yà sọ́tọ̀
tí a tọ́jú sínú `providerSpecificData`. Àwọn ìsopọ̀ wọ̀nyí yóò tẹ̀síwájú láti ṣiṣẹ́, ṣùgbọ́n wọ́n ń lo
ojú-ọ̀nà ìmúdọ̀tun ìfàṣẹsí àjọṣepọ̀ tí gbogbo wọn pín, èyí tó túmọ̀ sí pé irú ìsopọ̀ méjì bẹ́ẹ̀ ṣì lè sọ ti ara wọn
di asán.

**Láti rí ìyàsọ́tọ̀ gbà:** pa ìsopọ̀ àtijọ́ rẹ́ kúrò ní **Pátákó Ìṣàkóso → Àwọn Olùpèsè**, kí o sì
tún ṣàgbéwọlé rẹ̀ nípa lílo èyíkéyìí nínú àwọn ìṣàn ìṣàgbéwọlé tí a ṣe àtìlẹ́yìn fún. Gbogbo ìsopọ̀ tuntun tí a ṣẹ̀dá yóò
gba ìforúkọsílẹ̀ oníbàárà tirẹ̀ láìfọwọ́ṣe.

## Ṣíṣàfikún Àwọn Àkọọ́lẹ̀ Kiro Méjì Lẹ́gbẹ̀ẹ́ Ara Wọn

### Àwọn Ohun Tí A Nílò Ṣáájú

- OmniRoute v3.8.0 tàbí èyí tó tuntun sí i.
- Àkọọ́lẹ̀ Kiro tó ń ṣiṣẹ́ (ímẹ́lì + ọ̀rọ̀ aṣínà, ìwọlé Google, tàbí GitHub).
- Àkọọ́lẹ̀ Kiro kejì, bí o bá fẹ́.

### Ìgbésẹ̀ 1: Ṣàgbéwọlé àkọọ́lẹ̀ àkọ́kọ́

1. Ṣí **Pátákó Ìṣàkóso → Àwọn Olùpèsè → Ṣàfikún Olùpèsè → Kiro**.
2. Yan ọ̀kan nínú àwọn wọ̀nyí:
   - **Ṣàgbéwọlé Àmì Ìdánimọ̀** — lẹ àmì ìdánimọ̀ ìmúdọ̀tun tó bẹ̀rẹ̀ pẹ̀lú `aorAAAAAG` mọ́lẹ̀.
   - **Kọ́kọ́rọ́ API** — lẹ kọ́kọ́rọ́ API Kiro / CodeWhisperer ọlọ́jọ́-pípẹ́ mọ́lẹ̀.
   - **Ìwọlé Google / GitHub** — parí ìṣàn OAuth nínú ẹ̀rọ aṣàwákiri.
   - **Ìṣàgbéwọlé Aládàáṣiṣẹ́** — tẹ bọ́tìnì náà; OmniRoute máa ka àwọn ẹ̀rí ìwọlé láti inú
     ibi ìpamọ́ dátà kiro-cli abẹ́lẹ̀ tàbí `~/.aws/sso/cache`.
3. A ó fi ìsopọ̀ náà pamọ́. Àwọn ìṣàn àmì ìdánimọ̀ ìmúdọ̀tun máa forúkọ oníbàárà OIDC tí a yà sọ́tọ̀
   sílẹ̀ láìfọwọ́ṣe. Àwọn ìṣàn kọ́kọ́rọ́ API máa fìdí kọ́kọ́rọ́ náà múlẹ̀ pẹ̀lú AWS, wọn kì í sì í tọ́jú àmì ìdánimọ̀ ìmúdọ̀tun.

### Ìgbésẹ̀ 2: Ṣàgbéwọlé àkọọ́lẹ̀ kejì

Tún ìgbésẹ̀ 1 ṣe fún àkọọ́lẹ̀ kejì. Nítorí pé ìṣàgbéwọlé kọ̀ọ̀kan máa ń ṣẹ̀dá ìforúkọsílẹ̀ oníbàárà OIDC
tó yàtọ̀, àwọn ìsopọ̀ méjèèjì wà ní ìyàsọ́tọ̀ pátápátá.

### Ìgbésẹ̀ 3: Fìdí rẹ̀ múlẹ̀ pé ìsopọ̀ méjèèjì ń ṣiṣẹ́

1. **Pátákó Ìṣàkóso → Àwọn Olùpèsè** — àwọn ìsopọ̀ Kiro méjèèjì gbọ́dọ̀ fi ipò **Ń Ṣiṣẹ́** hàn.
2. **Pátákó Ìṣàkóso → Ìlera** — àwọn ìsopọ̀ méjèèjì gbọ́dọ̀ kọjá àyẹ̀wò ìlera àmì ìdánimọ̀ wọn.

### Ìgbésẹ̀ 4: Lo combo láti darí ìrìn-àjò láàárín àwọn àkọọ́lẹ̀

Ṣẹ̀dá combo pẹ̀lú ìsopọ̀ méjèèjì gẹ́gẹ́ bí ibi-àfojúsùn láti pín ẹrù tàbí láti yípadà sí ọ̀kan nígbà tí èkejì kò bá ṣiṣẹ́:

```
kiro/kiro-dev → kiro/kiro-pro
```

Wo [FEATURES.md](./FEATURES.md) àti àkọsílẹ̀ ìtọ́sọ́nà ìdarí fún ìṣètò combo.

## Àwọn Olùlò Ilé-iṣẹ́ / IDC

Fún àwọn àkọọ́lẹ̀ AWS IAM Identity Center (IDC), lo ìṣàn **AWS Builder ID / kóòdù-ẹ̀rọ IDC**
láti **Dashboard → Providers → Kiro → Device Code**. Ìṣàn kóòdù-ẹ̀rọ náà ti
wà ní ìyàsọ́tọ̀ pátápátá ní gbogbo ìgbà. Kò sí ìgbéwọlé-àtúnṣe tí a nílò fún àwọn àsopọ̀ wọ̀nyí.

Àwọn olùlò ilé-iṣẹ́ tí ń ṣiṣẹ́ ní ẹkùn AWS tí kì í ṣe ti àkọ́kọ́ lè sọ ẹkùn náà pàtó nígbà
tí wọ́n bá ń gbé wọlé nípasẹ̀ Import Token API:

```bash
curl -X POST http://localhost:20128/api/oauth/kiro/import \
  -H "Content-Type: application/json" \
  -d '{"refreshToken": "aorAAAAAG...", "region": "eu-west-1"}'
```

Ààyè `region` máa ń lo `us-east-1` gẹ́gẹ́ bí àkọ́kọ́ nígbà tí a kò bá fi í sílẹ̀.

## Ìṣàn Ìgbéwọlé API-Key

Ìfàṣẹsí API-key jẹ́ fún àwọn ẹ̀rí bearer Kiro / AWS CodeWhisperer tó wà fún ìgbà pípẹ́. Kò
lo ìmúdójúìwọ̀n OAuth, nítorí náà ó yẹra fún fífi ìjókòó OIDC tí a pín lò di asán.

### Dashboard

1. Ṣí **Dashboard -> Providers -> Kiro**.
2. Yan **API Key**.
3. Lẹ API key náà àti ẹkùn AWS àṣàyàn (`us-east-1` gẹ́gẹ́ bí àkọ́kọ́).
4. OmniRoute yóò fìdí key náà múlẹ̀, yóò sì fi àsopọ̀ náà pamọ́.

### API

```bash
curl -X POST http://localhost:20128/api/oauth/kiro/api-key \
  -H "Content-Type: application/json" \
  -d '{"apiKey": "kiro_or_codewhisperer_key", "region": "us-east-1"}'
```

### Àdéhùn Inú Ètò

Ọ̀nà API náà ń fìdí key náà múlẹ̀ nípa pípè `KiroService.validateApiKey()`, èyí tí
ń lo `ListAvailableProfiles` lòdì sí endpoint CodeWhisperer/Amazon Q tó bá ẹkùn náà mu,
tó sì ń pinnu `profileArn` kan.

Àsopọ̀ tí a fipamọ́ náà ń lo:

```json
{
  "authType": "apikey",
  "providerSpecificData": {
    "authMethod": "api_key",
    "region": "us-east-1",
    "profileArn": "arn:aws:codewhisperer:..."
  }
}
```

Ní àsìkò ìṣiṣẹ́, `KiroExecutor.buildHeaders()` ń fi key náà ránṣẹ́ gẹ́gẹ́ bí
`Authorization: Bearer <key>`, ó sì ń ṣàfikún `tokentype: API_KEY`. Àwọn ìpè quota/profile
ń lo àmì kan náà kí AWS lè ka bearer náà sí API key tó wà fún ìgbà pípẹ́ dípò
token ìráàyèsí OIDC tàbí ti àwùjọ.

## Ìparí Àkókò Oníbàárà OIDC

Àwọn oníbàárà gbogbogbò AWS SSO OIDC sábà máa ń parí lẹ́yìn ọjọ́ 90
(`clientSecretExpiresAt`). OmniRoute ń fi timestamp yìí pamọ́ sínú `providerSpecificData`
fún àkíyèsí iṣẹ́. Bí àsopọ̀ kan bá dáwọ́ ìmúdójúìwọ̀n dúró lẹ́yìn nǹkan bí ọjọ́ 90, tún
gbé àsopọ̀ náà wọlé láti gba ìforúkọsílẹ̀ oníbàárà OIDC tuntun. Ìforúkọsílẹ̀-àtúnṣe
aládàáṣiṣẹ́ nígbà ìparí àkókò jẹ́ àtúnṣe tí a ń tọ́pa fún ọjọ́ iwájú.

Àwọn àsopọ̀ API-key kò ní ìparí àkókò oníbàárà OIDC nítorí wọn kì í ṣe
ìmúdójúìwọ̀n nípasẹ̀ AWS SSO OIDC.

## Yíyanjú Ìṣòro

### Àkọọ́lẹ̀ kejì ń tẹ̀síwájú láti jáde kúrò nínú ètò

- Ṣàyẹ̀wò àwọn àsopọ̀ méjèèjì nínú **Dashboard → Providers**, kí o sì fìdí rẹ̀ múlẹ̀ pé ọ̀kọ̀ọ̀kan fi
  `clientId` tí kì í ṣe null hàn nínú JSON àìgbẹ́sẹ̀ rẹ̀ (tí a lè rí nípasẹ̀ àmì ìwífún). Bí ọ̀kan nínú
  àwọn àsopọ̀ náà kò bá ní `clientId`, a gbé e wọlé ṣáájú v3.8.0 — tún gbé e wọlé.

### Ìgbéwọlé kùnà pẹ̀lú "Ìfìdímúlẹ̀ token kùnà"

- Rí i dájú pé refresh token náà bẹ̀rẹ̀ pẹ̀lú `aorAAAAAG`.
- Rí i dájú pé OmniRoute lè dé `https://oidc.us-east-1.amazonaws.com` (tàbí ẹkùn tí a ti ṣètò).
  Bí o bá wà lẹ́yìn proxy ilé-iṣẹ́ kan, ṣètò proxy ipele-provider kan nínú
  **Dashboard → Settings → Proxies**.

### Ìgbéwọlé API-key kùnà

- Fìdí rẹ̀ múlẹ̀ pé key náà jẹ́ Kiro / CodeWhisperer API key, kì í ṣe refresh token.
- Fìdí rẹ̀ múlẹ̀ pé ẹkùn AWS náà bá key/àkọọ́lẹ̀ náà mu. `us-east-1` ni àkọ́kọ́.
