OmniRoute n pese ebi awon pipaṣẹ `setup-*` ti o n ṣeto CLI koodu (Codex, Claude Code, OpenCode, Cline, …) lati lo OmniRoute gege bi ẹhin rẹ — nitorinaa ohun elo naa n ba **ojuami kan** sọrọ ati OmniRoute n tọka si olupese to tọ pẹlu atunṣe-ara-ẹni. Pipaṣẹ kọọkan n ka katalogi awoṣe **laaye** lati OmniRoute ti n ṣiṣẹ (agbegbe tabi latọna jijin) ati pe o n kọ faili iṣeto ohun elo naa si ori ẹrọ **rẹ**. Bọtini API naa ni a n tọka si nipasẹ oniyipada agbegbe nibikibi ti ohun elo naa ba ṣe atilẹyin rẹ. A ti ṣe akiyesi awọn pipaṣẹ ti o n tọju faili agbegbe ohun elo ni isalẹ.

O tun wa ifilọlẹ gbogbogbo kan — `omniroute run <target>` — ti o n bẹrẹ `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` tabi `gemini` pẹlu agbegbe to tọ ti a fi sii, laisi kikọ iṣeto kankan rara. Awọn ibi-afẹde ati awọn orukọ-apeso wọn wa lati inu iwe-aṣẹ akọkọ `bin/cli/cli-manifest.mjs` (`claude-code|cc|anthropic`, `codex-cli|openai-codex|openai`, `goose-cli`, `open-code`, `qwen-code`, `gemini-cli`), ati `omniroute completion` n pese awọn ọrọ ibi-afẹde kanna ti o jade lati inu iwe-aṣẹ naa. Awọn ifilọlẹ ohun elo-kọọkan atijọ — `omniroute launch` (Claude Code) ati `omniroute launch-codex` (Codex) — wa ni lilo.

Ifilọlẹ olupese wa lati inu ipo agbegbe/latọna jijin kanna. Awọn pipaṣẹ API-akọkọ ni isalẹ n tọju ijẹrisi iṣakoso lọtọ si awọn iwe-ẹri olupese ati pe wọn ko tẹ iwe-ẹri jade ni ọna ti o ṣeto:

```bash
omniroute providers add glm --credential-env GLM_API_KEY --name work
omniroute providers import ./providers.json --dry-run --json
omniroute providers auth openai
omniroute providers edit <connection-id> --default-model glm/glm-5.2
omniroute providers remove <connection-id> --yes
```

Fun awọn iwe afọwọkọ, fẹran `--credential-stdin` tabi `--credential-env`; a ti tọju `--credential` fun lilo agbegbe ti a ṣakoso. `providers remove` nilo `--yes` lori ebute ti kii ṣe ibaraẹnisọrọ, ati gbogbo awọn pipaṣẹ marun n bọwọ fun ipo ti n ṣiṣẹ tabi awọn aṣayan agbaye `--base-url`/`--api-key`.

Awọn asayan olupese n kọ awọn asọtẹlẹ ID ti ko oye, awọn orukọ tabi awọn orukọ olupese; lo ID asopọ kikun nigbati ọpọlọpọ awọn asopọ ba baamu. Ṣiṣẹda ati ṣiṣatunṣe awọn pipaṣẹ n ka asopọ ti a ti fipamọ pada, ati yiyọ kuro n rii daju pe ko si ni kika mọ. Gbigbe wọle n foju kọja orisii olupese/orukọ ti o wa tẹlẹ. Awọn titẹ sii ti a gbe wọle ko le bori ojuami iṣakoso, ipo tabi awọn iwe-ẹri iṣakoso ti a pese si CLI.

Fun iṣeto ipilẹ ti a kọ pẹlu ọwọ, lẹẹkanṣoṣo ti awọn isọpọ meji ti o lọpọlọpọ julọ, wo awọn iwadii jinlẹ ohun elo-kọọkan:

- [Iṣeto Claude Code](./CLAUDE-CODE-CONFIGURATION.md)
- [Iṣeto Codex CLI](./CODEX-CLI-CONFIGURATION.md)
- [Ipo Latọna Jijin](./REMOTE-MODE.md) — wakọ OmniRoute latọna jijin (VPS / Tailnet) lati kọǹpútà alágbèéká rẹ
- [Iwiregbe VS Code Copilot](./VSCODE-COPILOT.md) — amugbooro OmniCopilot; o tun le ṣiṣẹ awọn pipaṣẹ `setup-*` wọnyi fun ọ lati inu olootu

## Tábìlì àkóso

Gbogbo àṣẹ ń tẹ̀lé **active context** (tí a ṣètò pẹ̀lú `omniroute connect`, wo
[Remote Mode](./REMOTE-MODE.md)) tàbí àwọn flag `--remote <url> --api-key <key>` tí a sọ ní tààrà.
"Local àti remote" nísàlẹ̀ túmọ̀ sí pé: láìsí flag kankan, ó ń darí sí `http://localhost:20128`;
pẹ̀lú `--remote` (tàbí active remote context), ó máa ń gba àkójọ náà láti
server yẹn, ó sì máa ń kọ ìṣètò náà sí ẹ̀rọ local.

Àwọn àkíyèsí lórí àwọn àsíá (tí a ti ṣàyẹ̀wò nínú orísun àṣẹ náà):

- `--remote <url>` — gba àkójọ náà láti OmniRoute jíjìnnà kan (ó borí `--port`
  àti àyíká tó ń ṣiṣẹ́). `--api-key <key>` ń pèsè ẹ̀rí ìdánimọ̀ fún
  olupin náà (àìyípadà rẹ̀ ni `OMNIROUTE_API_KEY` env var, tàbí token àyíká tó ń ṣiṣẹ́).
- `--only <patterns>` — àwọn ọ̀rọ̀-abẹ́ tí a fi àmì kọ́má yà; fi àwọn ID model tó bá
  mu nìkan sílẹ̀ (fún àpẹẹrẹ `--only glm,kimi`). Ó wà lórí `setup-codex`, `setup-claude`,
  `setup-opencode`, `setup-continue`, `setup-cursor`, `setup-crush`.
- `--dry-run` — tẹ ohun tí a máa kọ jáde gan-an láìfọwọ́ kan
  ètò fáìlì. Ó wà lórí gbogbo àṣẹ `setup-*` **àyàfi** `setup-cursor`
  (èyí tí kì í kọ fáìlì rárá).
- `--model <id>` — ó pọndandan (tàbí kí a yàn án ní ìbáṣepọ̀) fún àwọn irinṣẹ́ tí kò ní
  ìṣàwárí model aládàáṣe: Cline, Kilo, Roo, Goose, Qwen, Aider, 5dive. Àwọn irinṣẹ́ wọ̀nyẹn
  tún gba `--yes` fún àwọn ìṣiṣẹ́ aláìbáṣepọ̀ (èyí tí yóò sì béèrè `--model`).
  `setup-opencode` gba `--model` láti ṣètò model ipele-òkè àìyípadà.
- `--model <id>` lórí `omniroute run` ń tẹ̀lé àsopọ̀ tí manifest yàn fún target kọ̀ọ̀kan
  (`bin/cli/cli-manifest.mjs`): **aider** gba `--model openai/<id>` àti
  **opencode** gba `--model omniroute/<id>` (a máa fi ìṣáájú náà kún un nígbà tí id
  kò bá ti ní i); **qwen** àti **gemini** gba id náà bí ó ṣe rí;
  **claude** gba a nípasẹ̀ `ANTHROPIC_MODEL`, **goose** nípasẹ̀ `GOOSE_MODEL`, àti
  **codex** nípasẹ̀ àwọn àríyànjiyàn `-c model_providers.omniroute.*`. **Qwen nìkan ni target ìṣiṣẹ́
  tó fi dandan béèrè `--model`** — `omniroute run qwen` láìsí i máa jáde
  pẹ̀lú `2` àti àṣìṣe tó ṣe kedere.
- `--port <port>` — port OmniRoute abẹ́nú (àìyípadà `20128`, a máa kọ̀ ọ́ sílẹ̀ nígbà tí a bá ṣètò `--remote`).
  Ó wà lórí gbogbo `setup-*` àti àwọn olùpilẹ̀ṣẹ̀ méjèèjì.
- Àwọn kóòdù àbájáde `omniroute run`: a máa tan kóòdù àbájáde CLI ọmọ náà lọ
  bí ó ṣe rí; `2` = àwọn àríyànjiyàn tí kò tọ́ (target tí a kò ṣe àtìlẹ́yìn fún, `--model`
  tó pọndandan tí kò sí, ìdènà container); `127` = binary target náà kò sí nínú `PATH`;
  `130`/`143`/`129` nígbà tí `SIGINT`/`SIGTERM`/`SIGHUP` bá fòpin sí ìpilẹ̀ṣẹ̀ náà;
  `1` = ìkùnà ìpilẹ̀ṣẹ̀ runtime mìíràn.
- Àwọn olùpilẹ̀ṣẹ̀ méjèèjì (`launch`, `launch-codex`) gba `--profile <name>` láti yan
  profile tí `setup-claude` / `setup-codex` kọ, pẹ̀lú àwọn àríyànjiyàn tí a ń kọjá lọ fún
  binary `claude` / `codex` tó wà lábẹ́ rẹ̀.

Olùyàn ìbáṣepọ̀ náà tún jẹ́ ohun tí àwọn ilana ìṣètò ń pín:

```bash
# Yan láti inú àkójọ model abẹ́nú tàbí jíjìnnà tó ń ṣiṣẹ́, kí o sì ṣètò target náà.
omniroute configure claude
omniroute configure opencode --provider glm
omniroute configure qwen --model qwen/qwen3.8-max-preview --yes
```

Lọ́wọ́lọ́wọ́, `configure` ń fi iṣẹ́ lé àwọn ilana tí a ti dán wò fún `codex`, `claude`,
`opencode`, `qwen`, `aider`, `goose`, `cline`, `continue`, `kilo`, àti `5dive`.
Àwọn àkọsílẹ̀ àkójọ tó jẹ́ ti IDE-nìkan,
MITM, àti itọ́sọ́nà-nìkan ṣì jẹ́ àwọn ìṣàn `setup-*`/ọwọ́ tí a sọ ní kedere, a kò sì
fihàn wọn gẹ́gẹ́ bí àwọn target tí a lè ṣe ìpilẹ̀ṣẹ̀.

> `setup-opencode` ni ìṣọ̀kan OpenCode **fẹ́ẹ́rẹ́ openai-compatible**.
> Ìṣọ̀kan plugin tó lágbára sí i tún wà — `omniroute setup opencode` — èyí tí
> ń fi `@omniroute/opencode-plugin` sori ẹrọ. Àwọn àṣẹ ọ̀tọ̀ọ̀tọ̀ ni wọ́n; tábìlì
> tó wà lókè ṣàkọsílẹ̀ `setup-opencode`.
>
> Plugin náà wà nínú package méjì, ọ̀kan fún major OpenCode kọ̀ọ̀kan, nítorí àwọn
> loader méjèèjì ń retí entrypoint ọ̀tọ̀ọ̀tọ̀:
> `@omniroute/opencode-plugin` fún OpenCode v1 àti
> `@omniroute/opencode-plugin-v2` fún OpenCode v2. Package v2 náà jẹ́ tuntun
> (`0.1.0`), ó sì ń tẹ̀lé àdéhùn host kan tí ó ṣì ń yí padà, nítorí náà ó ń ka
> ìrísí tí OpenCode fi sínú àkọsílẹ̀ àkójọ dípò kó máa rò pé ìrísí kan ni. Fi
> í sori ẹrọ nípa fífi àkọsílẹ̀ `plugins` kún `opencode.json`; `omniroute setup opencode`
> ṣì ń fi package v1 sori ẹrọ. Àwọn aṣàyàn àti ètò ìṣáwárí ẹ̀rí ìdánimọ̀ wà nínú
> README package náà.

## Ìlò lórí ẹ̀rọ abẹ́lé

Nígbà tí OmniRoute bá ń ṣiṣẹ́ lórí `localhost:20128`, kan ṣiṣẹ́ àṣẹ ìṣètò fún
irinṣẹ́ rẹ. A máa ń gba àkójọ náà láti ẹ̀rọ apèsè abẹ́lé.

```bash
# Codex: kọ prófáìlì kan fún awoṣe kọ̀ọ̀kan tó bá mu sínú ~/.codex/
omniroute setup-codex
codex --profile glm52            # lo prófáìlì tí a ṣẹ̀dá

# Claude Code: kọ àwọn prófáìlì ọ̀tọ̀ọ̀tọ̀ fún awoṣe kọ̀ọ̀kan, lẹ́yìn náà ṣe ìfilọ́lẹ̀ ọ̀kan
omniroute setup-claude
omniroute launch --profile glm52

# OpenCode: kọ olùpèsè tó bá openai mu pẹ̀lú gbogbo àwọn awoṣe inú àkójọ
omniroute setup-opencode
export OMNIROUTE_API_KEY=sk-...  # a tọ́ka sí i nípasẹ̀ {env:OMNIROUTE_API_KEY}, kì í sí lórí disiki láéláé
opencode -m omniroute/glm/glm-5.2 "..."

# Àwọn irinṣẹ́ tí kò ní ìṣàwárí aládàáṣe nílò awoṣe tí a sọ ní pàtó:
omniroute setup-aider --model glm/glm-5.2
omniroute setup-qwen --model qwen/qwen3.8-max-preview

# Ṣàwòrán àkọ́kọ́ láì kọ ohunkóhun:
omniroute setup-continue --dry-run
```

Ṣe ìfilọ́lẹ̀ láì kọ àtòpọ̀ èyíkéyìí rárá (ìfi-àyíká-sí-nú nìkan):

```bash
omniroute launch                 # Claude Code → OmniRoute abẹ́lé
omniroute launch-codex           # Codex CLI → OmniRoute abẹ́lé
omniroute launch-codex --profile glm52
omniroute run claude --model openai/gpt-5.4
omniroute run codex --model openai/gpt-5.4 --dry-run --json
omniroute run aider --model glm/glm-5.2 -- --message "reply OK"
omniroute run goose --model glm/glm-5.2
omniroute run opencode --model glm/glm-5.2 -- run "reply OK"
omniroute run qwen --model glm/glm-5.2 -- -p "reply OK"
omniroute run gemini --model glm/glm-5.2 -- --skip-trust -p "reply OK"

# Ọ̀nà àṣẹ tí a sọ ní pàtó: fi ohunkóhun tó bá tẹ̀lé -- kọjá
omniroute run claude -- --print-system-prompt "review this diff"
```

## Ìlò láti ọ̀nà jíjìn

Darí àṣẹ ìṣètò èyíkéyìí sí OmniRoute jíjìn kan pẹ̀lú `--remote` + `--api-key`. A máa
ń gba àkójọ náà láti ẹ̀rọ jíjìn; a ó sì kọ àtòpọ̀ náà sórí ẹ̀rọ abẹ́lé rẹ.

```bash
# OpenCode lòdì sí VPS jíjìn kan, pa àwọn awoṣe glm/kimi nìkan mọ́
omniroute setup-opencode --remote http://192.168.0.15:20128 --api-key oma_live_xxx \
  --only glm,kimi
opencode -m omniroute/glm/glm-5.2 "..."   # kọ́kọ́ ṣe export OMNIROUTE_API_KEY

# Àwọn prófáìlì Codex láti àkójọ jíjìn kan
omniroute setup-codex --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Ṣe ìfilọ́lẹ̀ CLI kan tààrà lòdì sí ẹ̀rọ jíjìn náà
omniroute launch       --remote http://192.168.0.15:20128 --api-key oma_live_xxx
omniroute launch-codex --remote http://192.168.0.15:20128 --api-key oma_live_xxx
```

Dípò fífi `--remote`/`--api-key` ránṣẹ́ ní gbogbo ìgbà, wọlé lẹ́ẹ̀kan, kí o sì jẹ́ kí
**àyíká tó ń ṣiṣẹ́** pèsè wọn ní aládàáṣe:

```bash
omniroute connect 192.168.0.15        # ṣẹ̀dá tọ́kìnì tí a fi ààlà sí, ó sì tọ́jú àyíká náà
omniroute setup-codex                 # ← ó ti ń lo àkójọ jíjìn báyìí
omniroute setup-opencode              # ← bákan náà
omniroute launch                      # ← Claude Code lòdì sí ẹ̀rọ jíjìn náà
```

Wo [Ìpo Jíjìn](./REMOTE-MODE.md) fún àwọn àyíká, àwọn ààlà, àti ìṣàkóso tọ́kìnì.

## Àwọn ọ̀wọ́ aṣojú 5dive

[5dive](https://5dive.ai) ń ṣiṣẹ́ pẹ̀lú ọ̀wọ́ àwọn aṣojú ìkọ-kóòdù tó ń ṣiṣẹ́ fún ìgbà
pípẹ́, tí ọ̀kọ̀ọ̀kan jẹ́ ẹ̀ka systemd lábẹ́ aṣàmúlò Unix tirẹ̀. Kì í ṣe CLI ìkọ-kóòdù
fúnra rẹ̀, nítorí náà kò sí ohun tí `omniroute run` yóò ṣe ìfilọ́lẹ̀ rẹ̀ — `5dive`
jẹ́ ibi-àfojúsùn **fún ìṣètò nìkan**.

```bash
omniroute configure 5dive --model failover-demo --yes
omniroute setup-5dive --model failover-demo --auth-profile omniroute --agent worker1
```

Àwọn ọ̀nà méjèèjì kọ prófáìlì **ìfàṣẹsí** 5dive kan, gbogbo ìjókòó `claude` tí a
so mọ́ prófáìlì náà yóò sì bá OmniRoute sọ̀rọ̀. Ohun mẹ́ta ló jẹ́ pàtó sí ibi-àfojúsùn yìí:

- **Ó ń ṣiṣẹ́ lórí ẹ̀rọ olùgbàlejò ọ̀wọ́ náà, gẹ́gẹ́ bí root.** Àwọn ọ̀rọ̀-àṣẹ 5dive
  ń ṣiṣẹ́ lórí àwọn ẹ̀ka systemd abẹ́lé àti àpò ìpamọ́ ipò tí root ní; kò sí ìpo
  jíjìn. Ìlànà náà tún ara rẹ̀ ṣiṣẹ́ nípasẹ̀ `sudo` nígbà tí kò tíì jẹ́ root
  (`--no-sudo` yóò pa èyí, yóò sì tẹ àṣẹ náà jáde dípò rẹ̀).
- **Ibi ìbáṣepọ̀ náà gbọ́dọ̀ jẹ́ `https://` àfi tí ó bá jẹ́ loopback.** Kọ́kọ́rọ́ API
  aṣojú náà ń gba URL yẹn kọjá lórí gbogbo ìbéèrè, 5dive sì kọ ibi ìbáṣepọ̀ tí kò
  ní ìfipamọ́ tó wà níta ẹ̀rọ. Àdírẹ́sì LAN aládàáni kì í ṣe ìyọkúrò.
- **Àṣàyàn awoṣe ìjókòó kọ̀ọ̀kan ga ju ti prófáìlì lọ.** Prófáìlì náà ní
  `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL`, ṣùgbọ́n ìjókòó tí a ṣì so mọ́
  model id àkànṣe yóò kùnà ní ìgbésẹ̀ àkọ́kọ́ rẹ̀ pẹ̀lú _"Ìṣòro kan wà pẹ̀lú awoṣe
  tí a yàn"_. Fi `--agent <name>` ránṣẹ́ (o lè tún un ṣe) láti so àwọn ìjókòó
  náà mọ́ bákan náà; ìlànà náà yóò tẹ àṣẹ náà jáde nígbà tí o kò bá ṣe bẹ́ẹ̀.

A máa ń fi kọ́kọ́rọ́ API fún 5dive lórí **stdin** (`--api-key=-`), nítorí náà kò
ní hàn nínú àbájáde `ps` láéláé.

Dídarí prófáìlì náà sí **àkójọpọ̀** OmniRoute dípò awoṣe kan ṣoṣo ni ohun tó ń fún
ọ̀wọ́ náà ní ìyípadà sí olùpèsè mìíràn nígbà ìkùnà: nígbà tí ibi ìbáṣepọ̀ àkọ́kọ́
dákẹ́ pátápátá láàárín ìgbésẹ̀ kan nínú ìṣiṣẹ́ tí a ṣe àkọsílẹ̀ rẹ̀ lórí
[#11578](https://github.com/diegosouzapw/OmniRoute/issues/11578), aṣojú náà parí
àwọn ìgbésẹ̀ tó kù lórí èyí àfẹ́yìntì, kò sì fi ìdádúró náà hàn rárá.

## Mímú àwọn native deps dúró nígbà ìmúdójúìwọ̀n: `--include=optional`

Nígbà tí o bá ṣe ìmúdójúìwọ̀n pẹ̀lú `omniroute update` (lẹ́yìn ìmúdájú, tàbí pẹ̀lú `--apply`),
OmniRoute máa ń ṣiṣẹ́ ìfiṣọ́pọ̀ náà pẹ̀lú `--include=optional` tí a ti fi sínú rẹ̀:

```bash
npm install -g omniroute@latest --include=optional
```

Èyí **kì í ṣe** àsìá tí o máa ń fi ránṣẹ́ sí `omniroute update` — olùmúdójúìwọ̀n
máa ń lò ó nígbà gbogbo. Ó ń ṣe ìdánilójú pé `optionalDependencies` (`better-sqlite3`, `keytar`,
`tls-client`, àkójọpọ̀ LLMLingua SLM) yè ìmúdójúìwọ̀n náà, kódà bí àtòpọ̀ npm rẹ bá
ti ṣètò `omit=optional`, èyí tí ì bá mú awakọ SQLite àbínibí àti àsopọ̀ ibi-ìpamọ́ kọ́kọ́rọ́ OS
kúrò láìsí ìkìlọ̀. Láti ṣàkọ́kọ́ wo àṣẹ gangan láìlò ó:

```bash
omniroute update --dry-run
# [ÌṢÀDÁNWÒ LÁÌṢE] Yóò ṣiṣẹ́: npm install -g omniroute@latest --include=optional
```

Àwọn àsìá `omniroute update` mìíràn (tí a ti fìdí rẹ̀ múlẹ̀ nínú kóòdù): `--check` (jáde pẹ̀lú 1 bí
ó bá ti di àtijọ́), `--apply` (fi sílẹ̀ láìbéèrè ìmúdájú), `--changelog`, `--no-backup`,
`--yes`.

## Google Gemini CLI nípasẹ̀ `omniroute run gemini`

A ti fìdí àdéhùn múlẹ̀ pẹ̀lú `@google/gemini-cli` 0.50.0: CLI náà ń tẹ̀lé
`GOOGLE_GEMINI_BASE_URL`, ó sì ń fi `POST /v1beta/models/<model>:generateContent`
(àti `:streamGenerateContent?alt=sse`) ránṣẹ́ sí i — gẹ́gẹ́ bí ojú-iṣẹ́ Gemini
àbínibí OmniRoute (`/v1beta`) gan-an. `omniroute run gemini` ń so èyí pọ̀ láìfọwọ́ṣe:

- `GOOGLE_GEMINI_BASE_URL` → Base URL OmniRoute tó ń ṣiṣẹ́ (ìpìlẹ̀, láìsí `/v1`);
- `GEMINI_API_KEY` → ẹ̀rí ìdánimọ̀ OmniRoute tí a ti yanjú (àṣàyàn/env/context);
- **`GEMINI_CLI_HOME` àkókò díẹ̀ tí a yà sọ́tọ̀** tí `.gemini/settings.json` rẹ̀
  yan ìfàṣẹsí `gemini-api-key`, kí ìjókòó Google OAuth tí a ti fipamọ́ (Code Assist)
  má bàa borí ìpilẹ̀ṣẹ̀ tí a darí sí OmniRoute — a máa yọ ọ́ kúrò lẹ́yìn ìjáde;
- **ìmótótó env**: a máa yọ `GOOGLE_API_KEY`,
  `GOOGLE_GENAI_USE_VERTEXAI` àti `GOOGLE_GENAI_USE_GCA` kúrò nínú env ọmọ (èyí tí ì bá darí
  ìfàṣẹsí sí Vertex/Code Assist), a sì máa ṣètò `GEMINI_DEFAULT_AUTH_TYPE=gemini-api-key`
  gẹ́gẹ́ bí àfikún ààbò — àwọn ibi-afẹ́ `run` yòókù náà gba ìtọju kan náà
  fún àwọn oníyípadà tiwọn tó lè tako ara wọn;
- fífi `--model <id>` kún un láti inú `--provider`/`--model`.

```bash
omniroute run gemini --model glm/glm-5.2 -- --skip-trust -p "hello"
```

Olùṣọ́ ìgbẹ́kẹ̀lé workspace Gemini ṣì ń ṣiṣẹ́ ní ipò headless — fi
`--skip-trust` ránṣẹ́ (tàbí fọwọ́sí directory náà nípasẹ̀ ìbánisọ̀rọ̀) fúnra rẹ; olùpilẹ̀ṣẹ̀ náà
mọ̀ọ́mọ̀ kì í kọjá a. Olùpilẹ̀ṣẹ̀ yìí yàtọ̀ sí **ìforúkọsílẹ̀ ACP**
(`src/lib/acp/registry.ts`, `gemini --acp`), èyí tí ó ṣì jẹ́ ìṣọ̀kan
prótókólù aṣojú fún `/dashboard/acp-agents`.

## Ìdánwò smoke gidi ní ọ̀pọ̀ ibi (yíyan láti ṣiṣẹ́)

Àwọn ìṣiṣẹ́ ìpadàsẹ́yìn ètò ìbẹ̀rẹ̀ tó ṣeé tún ṣe ń ṣiṣẹ́ nínú CI (`tests/unit/cli/run-command.test.ts`,
`tests/unit/cli/run-execution.test.ts`). Láti fìdí àwọn binary GIDI múlẹ̀ pẹ̀lú olupin OmniRoute GIDI,
harness tí a lè yàn láti ṣiṣẹ́ wà ní
`tests/integration/upstream-cli-smoke.int.test.ts`. Kì í ṣiṣẹ́ láìfọwọ́ṣe rárá
(ìdánwò kékeré kọ̀ọ̀kan ni a máa fò kọjá àyàfi tí `RUN_CLI_SMOKE=1`), ó ń fi ẹ̀rí ìwọlé ránṣẹ́ nípasẹ̀ ORÚKỌ env-var
(kì í ṣe nípasẹ̀ iye rẹ̀ láé), ó ń bo àwọn ọ̀rọ̀ tó dà bí kọ́kọ́rọ́ mọ́lẹ̀ láti inú àbájáde èyíkéyìí tí a gbà sílẹ̀, ó ń fò
kọjá àwọn ibi-àfojúsùn tí binary wọn kò tíì fi sílẹ̀, ó sì ń pín àwọn ìkùnà sí
auth / upstream / config dípò boolean lásán:

```bash
RUN_CLI_SMOKE=1 \
OMNIROUTE_SMOKE_BASE_URL="http://localhost:20128" \
OMNIROUTE_SMOKE_MODEL="<provider/model>" \
OMNIROUTE_SMOKE_API_KEY_ENV="OMNIROUTE_API_KEY" \
node --import tsx/esm --test tests/integration/upstream-cli-smoke.int.test.ts
```

Àṣàyàn: `OMNIROUTE_SMOKE_TARGETS="codex,opencode,qwen"` ń fi ààlà sí àwọn ibi tí ìdánwò náà yóò dé;
`OMNIROUTE_SMOKE_TIMEOUT_MS` ń rọ́pò àkókò ìdádúró 120s fún ibi-àfojúsùn kọ̀ọ̀kan.
