OmniRoute ń pèsè ojú-ọ̀nà mẹ́ta ọ̀tọ̀ọ̀tọ̀ tó ní í ṣe pẹ̀lú àwọn agent. Wọ́n jọra ní ìwò àkọ́kọ́, ṣùgbọ́n wọ́n ń yanjú àwọn ìṣòro ọ̀tọ̀ọ̀tọ̀. Lo ojú-ewé yìí láti yan èyí tó tọ́.

## Ní ṣókí

| Ojú-ọ̀nà                          | Ó dára jù fún                                                                                                                                         | Ọ̀nà ìgbékalẹ̀                                 | Ìlànà                       |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- | --------------------------- |
| **A2A — Agent-sí-Agent**         | Ìfọwọ́sowọ́pọ̀ láàárín àwọn agent pẹ̀lú àwọn agent ẹlẹgbẹ́ tí wọ́n ń lo ìlànà A2A                                                                           | JSON-RPC 2.0 lórí HTTP                       | A2A v0.3 (àlàyé ìlànà ṣíṣí) |
| **ACP — Àkọsílẹ̀ Àwọn Agent CLI** | Ṣíṣàwárí / fíforúkọsílẹ̀ / ṣíṣe ìfilọ́lẹ̀ àwọn agent ìkọ̀-kóòdù CLI tí a fi sórí ẹ̀rọ olùlò (Cursor, Cline, Codex CLI, Claude Code, Aider, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ) | HTTP REST                                    | Ti OmniRoute pàtó           |
| **Àwọn Agent Cloud**             | Fífi àwọn iṣẹ́ ìkọ̀-kóòdù tó máa ń pé ránṣẹ́ sí àwọn iṣẹ́ cloud ita (Codex Cloud, Devin, Jules, Cursor Cloud)                                             | HTTP REST + àwọn iṣẹ́ tí DB ń ṣe àtìlẹ́yìn fún | Ti OmniRoute pàtó           |

Àwọn mẹ́tẹ̀ẹ̀ta ò sinmi lé ara wọn — yan èyíkéyìí nínú wọn.

## Igi Ìpinnu

```
Ṣé o nílò iṣẹ́ cloud láti ṣe iṣẹ́ níta ẹ̀rọ yìí (Codex Cloud / Cursor Cloud / Devin / Jules)?
├─ BẸ́Ẹ̀NI → Àwọn Agent Cloud (POST /api/v1/agents/tasks)
└─ RÁRÁ → Tẹ̀síwájú
    │

    └─ RÁRÁ → Tẹ̀síwájú
        │
        Ṣé o nílò láti ṣe àtòjọ / àtúnṣe àwọn agent ìkọ̀-kóòdù CLI tí a fi sórí ẹ̀rọ agbègbè?
        ├─ BẸ́Ẹ̀NI → ACP (GET /api/acp/agents)
        └─ RÁRÁ → Lo /v1/chat/completions lásán
```

## 1. A2A — Agent-sí-Agent

**Àlàyé ìlànà:** [A2A v0.3](https://a2a-protocol.org)
**Endpoint OmniRoute:** `POST /a2a` (JSON-RPC 2.0)
**Káàdì Agent:** `GET /.well-known/agent.json`

### Ìgbà tó yẹ kí o lò ó

- Ṣíṣe ètò agent púpọ̀ níbi tí OmniRoute ti jẹ́ ọ̀kan lára àwọn ẹlẹgbẹ́
- Ṣíṣí òye ìdarí OmniRoute (ìdarí ọlọ́gbọ́n, ìṣàkóso iye-ààyè, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ) sí àwọn agent nínú àwọn framework bíi Google ADK tàbí àwọn nẹ́tíwọ́ọ̀kì agent gbogbogbòò
- Ṣíṣàkójọpọ̀ OmniRoute lẹ́yìn ojú-ọ̀nà àwárí + ìpè tó tẹ̀lé ìlànà

### Àwọn Method

- `message/send` — fi ìfiránṣẹ́ ránṣẹ́, gba èsì sync
- `message/stream` — fi ránṣẹ́ + gba àwọn ìṣẹ̀lẹ̀ ìlọsíwájú tí a ń stream nípasẹ̀ SSE
- `tasks/get` — ka iṣẹ́ nípasẹ̀ ID
- `tasks/cancel` — fagilé iṣẹ́ tó ń ṣiṣẹ́

### Àwọn ọgbọ́n tí a ti kọ́ sínú rẹ̀ (6)

- `smart-routing` — darí prompt kan gba àkópọ̀ tó dára jù lọ
- `quota-management` — jálẹ̀ ìpo quota fún provider kọ̀ọ̀kan
- `provider-discovery` — ṣe àtòjọ àwọn provider tí a fi sílẹ̀ pẹ̀lú agbára wọn
- `cost-analysis` — ṣírò iye owó tí ìbéèrè/ìjíròrò kan lè ná
- `health-report` — kó ìpo breaker/cooldown/lockout jọ fún provider kọ̀ọ̀kan
- `list-capabilities` — ṣe àtòjọ gbogbo ọgbọ́n àti metadata tí agent náà ní

### Àlàyé jíjinlẹ̀

Wo [A2A-SERVER.md](./A2A-SERVER.md) fún àwọn àlàyé ọ̀nà ìgbékalẹ̀, ìṣètò káàdì agent, àtúnṣe TTL iṣẹ́, àti àdàkọ fún fífi àwọn ọgbọ́n tuntun kún un.

## 2. ACP — Ìforúkọsílẹ̀ Àwọn Aṣojú CLI

**OmniRoute endpoint:** `GET /api/acp/agents`
**Orísun:** `src/lib/acp/{index,manager,registry}.ts`

### Ohun tí ó jẹ́

ACP ni **àkójọ àwọn aṣojú CLI abẹ́nú** ti OmniRoute. Ó ń ṣàwárí àwọn CLI ìkọ́kóòdù tí a ti fi sórí ẹ̀rọ alágbàlejò (Cursor, Cline, Claude Code, Codex CLI, Continue, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ), ó ń pinnu àwọn ẹ̀yà wọn, ó sì ń fi wọ́n hàn lórí pánẹ́ẹ̀lì ìṣàkóso kí aṣàmúlò lè ṣètò CLI kọ̀ọ̀kan láti tọ́ka sí OmniRoute.

Èyí KÌ Í ṢE ìlànà ìbánisọ̀rọ̀ òde — ìforúkọsílẹ̀ abẹ́nú ni tí ó ń mú UI "CLI Tools" ṣiṣẹ́ àti ìtọpinpin àmì ìdánimọ̀ CLI (wo [CLI-TOOLS.md](../reference/CLI-TOOLS.md)).

### Ohun tí ó ń ṣe

- Ṣàyẹ̀wò ẹ̀rọ alágbàlejò fún àwọn fáìlì ètò CLI tí a ti fi sílẹ̀ (ó ń lo `which` / `where` ní ìbámu pẹ̀lú OS)
- Ka ẹ̀yà CLI kọ̀ọ̀kan (ó ń pe `<bin> --version`)
- Ó lè gba àwọn aṣojú àdáni tí aṣàmúlò ṣàlàyé (ọ̀nà fáìlì ètò + àṣẹ ìṣàyẹ̀wò ẹ̀yà + àwọn àríyànjiyàn ìfilọ́lẹ̀)
- Fi àwọn aṣojú àdáni pamọ́ sínú àwọn ààtò
- Dá àkójọ ìṣọ̀kan padà sí pánẹ́ẹ̀lì ìṣàkóso

### REST API

| Endpoint          | Ọ̀nà  | Àpèjúwe                                                                | Ìfàṣẹsí    |
| ----------------- | ---- | ---------------------------------------------------------------------- | ---------- |
| `/api/acp/agents` | GET  | Ṣàkójọ àwọn aṣojú tí a ṣàwárí + ti àdáni (iye tí a fi sílẹ̀/lápapọ̀)     | Kọ́kọ́rọ́ API |
| `/api/acp/agents` | POST | Ṣàfikún/ṣe àfikún sí/yọ aṣojú àdáni kúrò (olùyàtọ̀ ìṣe nínú ara ìbéèrè) | Kọ́kọ́rọ́ API |

Ìrísí ara ìbéèrè fún POST (`customAgentBodySchema` nínú `src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### Àwọn ọ̀nà ìlò

- Ojú-ewé "CLI Tools" lórí pánẹ́ẹ̀lì ìṣàkóso ń ṣàkójọ ohun tí a ti fi sílẹ̀, ó sì ń ràn ọ́ lọ́wọ́ láti tọ́ka ọ̀kọ̀ọ̀kan sí OmniRoute
- Àwọn aṣojú àdáni ń jẹ́ kí àwọn aṣàmúlò onímọ̀ lè forúkọsílẹ̀ àwọn CLI abẹ́nú/ohun-ìní tí OmniRoute kò mọ̀ nípasẹ̀ ààtò àkọ́kọ́
- Àbájáde ìṣàwárí ń pèsè dátà fún mátríìsì àmì ìdánimọ̀ `cli-tools`

### Ìgbà tí kò yẹ kí o lo ACP

- ACP kò _ṣiṣẹ́_ àwọn iṣẹ́. Ó kàn ń ṣàwárí + ṣètò àwọn CLI. Láti pe CLI kan ní tòótọ́, ìwọ fúnra rẹ ni yóò ṣe ìfilọ́lẹ̀ rẹ̀ pẹ̀lú àwọn env vars tí OmniRoute pèsè (`OPENAI_BASE_URL`, `OPENAI_API_KEY`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ).

## 3. Àwọn Aṣojú Àwọsánmà

**OmniRoute endpoints:** `/api/v1/agents/tasks/*` (ìgbésí-ayé) + `/api/cloud/*` (àsopọ̀ abẹ́nú)
**Orísun:** `src/lib/cloudAgent/`

### Ohun tí ó jẹ́

Àtẹ̀jáde ìṣọ̀kan kan lórí àwọn aṣojú ìkọ́kóòdù àwọsánmà ẹni-kẹta. O fi ìtọ́ni + URL ibi ìpamójú kóòdù ránṣẹ́, OmniRoute yóò fi ránṣẹ́ sí aṣojú àwọsánmà tó tọ́, yóò máa ṣàyẹ̀wò ipò rẹ̀, yóò sì dá àwọn àbájáde padà.

### Àwọn aṣojú tí a ṣe àtìlẹ́yìn fún (4, gbogbo wọn ni a ti fìdí rẹ̀ múlẹ̀ nínú `src/lib/cloudAgent/agents/`)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### Ìgbésí-ayé

```
POST /api/v1/agents/tasks
  → BaseAgent.createTask() fún kiláàsì aṣojú kọ̀ọ̀kan
  → iṣẹ́ òde bẹ̀rẹ̀ iṣẹ́
  → a ṣẹ̀dá ìlà iṣẹ́ nínú DB (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → ìṣiṣẹ́pọ̀ ipò lọ́nà ọ̀lẹ láti ọ̀dọ̀ olupèsè
  → dá ipò lọ́wọ́lọ́wọ́ + ètò + àkọsílẹ̀ ìgbòkègbodò padà
  ↓
POST /api/v1/agents/tasks/[id]   (action: "approve" | "message" | "cancel")
  → fi ránṣẹ́ sí olupèsè (tàbí samisi rẹ̀ gẹ́gẹ́ bí èyí tí a fagilé ní abẹ́nú)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → fagilé ní abẹ́nú
```

### Ìfàṣẹsí

⚠️ **Gbogbo àwọn endpoint `/api/v1/agents/tasks/*` nílò ìfàṣẹsí ìṣàkóso** (commit `588a0333`). Àwọn olùpè tó ń lo Bearer nìkan ń gba 401 láti v3.8.0.

### Àlàyé jíjinlẹ̀

Wo [CLOUD_AGENT.md](./CLOUD_AGENT.md) fún àdéhùn `CloudAgentBase`, àwọn àlàyé pàtó fún aṣojú kọ̀ọ̀kan, àwọn àlàyé schema, àti àwọn endpoint àsopọ̀ ẹ̀rí ìdánimọ̀.

## Ìfiwéra: A2A àti Cloud Agents

Àwọn méjèèjì ní “àwọn iṣẹ́ tó máa ń gba àkókò pípẹ́,” ṣùgbọ́n ní àwọn ìpele tó yàtọ̀:

| Abala                  | A2A                                                                                     | Cloud Agents                                             |
| ---------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Ìlànà                  | Open A2A v0.3                                                                           | Ìlànà pàtó fún OmniRoute                                 |
| Ibi tí ìṣirò ti ń ṣiṣẹ́ | Nínú OmniRoute (ó ń lo àwọn àkójọpọ̀ tí a ti ṣètò)                                       | Níta (àwọn olupin Codex / Devin / Jules)                 |
| Àkókò iṣẹ́              | TTL àìyípadà jẹ́ ìṣẹ́jú 5 (a lè ṣàtúnṣe rẹ̀ nínú `TaskManager`)                            | Láti ìṣẹ́jú dé ọ̀pọ̀ wákàtí                                 |
| Ìmọ̀ ibi-ìpamọ́ kóòdù    | Rárá (àwọn ìtọ́ni nìkan ni ó ń fi ránṣẹ́)                                                 | Bẹ́ẹ̀ ni (URL ibi-ìpamọ́ + ẹ̀ka)                             |
| Ìlò                    | Ìfọwọ́sowọ́pọ̀ láàárín àwọn aṣojú, ìdarí ọlọ́gbọ́n gẹ́gẹ́ bí iṣẹ́                               | Fífi “ṣe àfikún ẹ̀yà X sínú ibi-ìpamọ́ Y” lé ẹlòmíràn lọ́wọ́ |
| Ìfàṣẹsí                | `OMNIROUTE_API_KEY` jẹ́ àṣàyàn fún `/a2a`; ìṣàkóso fún àwọn olùrànlọ́wọ́ REST `/api/a2a/*` | Ìṣàkóso nígbà gbogbo                                     |

## Àwọn Àpẹẹrẹ Ìṣọ̀kan

### Ṣàwárí àwọn agbára A2A ti OmniRoute

```bash
curl http://localhost:20128/.well-known/agent.json
```

Ó ń dá Agent Card padà pẹ̀lú gbogbo ọgbọ́n mẹ́fà, àwọn ọ̀nà ìgbékalẹ̀, àti ẹ̀yà.

### Pe OmniRoute gẹ́gẹ́ bí aṣojú A2A

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### Ṣe àkójọ àwọn aṣojú CLI tí a ti fi sílẹ̀ nípasẹ̀ ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### Ṣàfikún aṣojú CLI àdáni

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
```

### Fi iṣẹ́ Cloud Agent kan ránṣẹ́

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Implement feature X in repo Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### Ṣàyẹ̀wò ipò iṣẹ́ cloud léraléra

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```

## Ìgbà Tó Yẹ Kí O Lo Ọ̀kọ̀ọ̀kan

- **Ìrísí chatbot / copilot** → `/v1/chat/completions` (ó bá OpenAI mu — kì í ṣe ìlànà aṣojú)
- **Ìfọwọ́sowọ́pọ̀ àwọn aṣojú púpọ̀** → A2A
- **Ṣíṣe àkójọ àwọn CLI abẹ́lẹ̀ nínú dashboard** → ACP
- **Fífi àwọn iṣẹ́ kíkó kóòdù tó máa ń gba àkókò pípẹ́ lé àwọn iṣẹ́ cloud lọ́wọ́** → Cloud Agents
