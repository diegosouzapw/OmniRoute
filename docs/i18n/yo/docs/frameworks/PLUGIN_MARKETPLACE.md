> **Orísun òtítọ́:** `src/lib/plugins/` (`marketplace.ts`, `manager.ts`, `manifest.ts`,
> `scanner.ts`, `loader.ts`), `src/app/api/plugins/`, àti
> `src/app/(dashboard)/dashboard/plugins/`
> **Ìgbà ìmúdójúìwọ̀n tó kẹ́yìn:** 2026-06-28 — v3.8.40

OmniRoute ní ètò plugin tó dà bí ti WordPress. Àwọn plugin jẹ́ àwọn àkójọpọ̀ fáìlì
olóminira — ọ̀kọ̀ọ̀kan ní manifest `plugin.json` àti fáìlì ìbẹ̀rẹ̀ — tí wọ́n ń so
ara wọn mọ́ ìṣàn ìbéèrè (`onRequest` / `onResponse` / `onError`) àti àwọn
ìṣẹ̀lẹ̀ ìgbésí-ayé (`onInstall` / `onActivate` / `onDeactivate` / `onUninstall`).

**Ọjà Plugin** ni ipele ìṣàwárí tó wà lórí ètò náà. Ó ń pèsè àkójọ àwọn plugin
tí a lè ṣàwárí tí a sì lè fi sí ẹrọ. Nípa àìṣe, àkójọ náà jẹ́ registry ìpilẹ̀ṣẹ̀
kékeré tó wà nínú ètò; olùṣàkóso lè darí rẹ̀ sí URL registry jíjìn àkànṣe, nígbà
náà ni a ó fi ìdábòbò SSRF tó ń yanjú DNS mú ìgbàjáde náà le
(wo [Ààbò](#security)).

Gbogbo ipa-ọ̀nà plugin jẹ́ **fún loopback nìkan** (Ìpele 1 — `LOCAL_ONLY`):
àwọn plugin ń ṣàkójọpọ̀ wọ́n sì ń ṣiṣẹ́ kóòdù nínú àwọn child process, nítorí náà
a kò lè dé àwọn ipa-ọ̀nà náà láti orísun tí kì í ṣe loopback láìka ìfàṣẹsí sí. Wo
[`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md).

## Bí Gbogbo Rẹ̀ Ṣe Ṣiṣẹ́ Pọ̀

```
Dasibodu (/dashboard/plugins)
  ├─ Taabu "Àwọn tí a ti fi sí ẹrọ" → GET /api/plugins            (listPlugins)
  │                                   POST /api/plugins/scan      (pluginManager.scan)
  │                                   POST /api/plugins/{name}/activate|deactivate
  │                                   DELETE /api/plugins/{name}   (yọ kúrò)
  └─ Taabu "Ọjà" → GET /api/plugins/marketplace
                    → listMarketplacePlugins()
                      ├─ kò sí URL àkànṣe → SEED_REGISTRY inú ètò
                      └─ URL àkànṣe → isSafeMarketplaceUrl() ìdábòbò SSRF
                                    → safeOutboundFetch(guard:"public-only")
```

- **Ipele registry** — `src/lib/plugins/marketplace.ts`: ń ṣàfihàn / ń ṣàwárí
  àkójọ náà, ó sì ń padà sí registry ìpilẹ̀ṣẹ̀ bí ìkùnà èyíkéyìí bá ṣẹlẹ̀.
- **Ipele ìgbésí-ayé** — `src/lib/plugins/manager.ts` (singleton `pluginManager`):
  fí sí ẹrọ, ṣe ìgbésókè, mú ṣiṣẹ́, dá dúró, yọ kúrò, ṣàyẹ̀wò, kó jọ nígbà ìbẹ̀rẹ̀.
- **Ipele manifest** — `src/lib/plugins/manifest.ts`: schema Zod + àwọn iye
  àìṣe fún `plugin.json`.
- **Ẹ̀rọ ìṣàyẹ̀wò** — `src/lib/plugins/scanner.ts`: ń ṣàwárí àwọn plugin lórí disk
  lábẹ́ àkójọpọ̀ fáìlì plugin.
- **Ẹ̀rọ ìkójọ** — `src/lib/plugins/loader.ts`: ń dá plugin kọ̀ọ̀kan ṣiṣẹ́ nínú
  child process tó ya sọ́tọ̀, ó sì ń ṣàkóso àwọn ìpè hook lórí IPC.

## Àkójọ Ọjà

`listMarketplacePlugins()` (`src/lib/plugins/marketplace.ts`) ń dá àkójọ àwọn
object `MarketplaceEntry` padà:

| Field         | Irú      | Àwọn àlàyé                                                |
| ------------- | -------- | --------------------------------------------------------- |
| `name`        | string   | Orúkọ plugin ní kebab-case                                |
| `version`     | string   | semver                                                    |
| `description` | string   | Àkótán kúkúrú                                             |
| `author`      | string   | Olùkọ̀wé / àjọ                                             |
| `license`     | string   | ID ìwé-àṣẹ ara SPDX                                       |
| `downloadUrl` | string   | URL ìgbàsílẹ̀ orísun (ó lè ṣófo)                           |
| `repository`  | string?  | URL repository àṣàyàn                                     |
| `tags`        | string[] | Àwọn tag ìṣàwárí/àsẹ                                      |
| `downloads`   | number   | Iye ìgbàsílẹ̀                                              |
| `rating`      | number   | 0–5                                                       |
| `verified`    | boolean  | Bóyá a ti samisi àkọsílẹ̀ náà gẹ́gẹ́ bí èyí tí a ti jẹ́rìí sí |
| `lastUpdated` | string   | Okùn ọ̀rọ̀ ọjọ́ tó dà bí ISO                                 |

Nígbà tí a kò bá ṣètò URL registry àkànṣe, àkójọ náà ni `SEED_REGISTRY` inú ètò
(lọ́wọ́lọ́wọ́ `request-logger`, `rate-limiter`, `cost-tracker`, àti
`theme-manager`). Registry ìpilẹ̀ṣẹ̀ náà wà nígbà gbogbo — tí registry jíjìn tí a
ṣètò kò bá ṣeé dé, tí ó bá dá status tí kì í ṣe `200` padà, tàbí tí ó bá dá body
tí a kò mọ̀ padà, `listMarketplacePlugins()` máa ń kọ ìkìlọ̀ sínú log, ó sì máa
padà sí àkójọ ìpilẹ̀ṣẹ̀.

> Àkíyèsí: **àkójọ** ọjà (wíwo/ṣíṣàwárí) ti ní ìsopọ̀ láti ìbẹ̀rẹ̀ dé òpin,
> ṣùgbọ́n fífi plugin **sí ẹrọ** pẹ̀lú ìtẹ̀ ẹ̀ẹ̀kan láti inú àkójọ náà kò tíì ṣeé
> lò — bọ́tìnì "Fi sí ẹrọ" lórí àkọsílẹ̀ ọjà kan nínú dasibodu ń ṣàfihàn ìfitónilétí
> "ń bọ̀ láìpẹ́" lọ́wọ́lọ́wọ́. Fífi sí ẹrọ lónìí ń gba inú ìṣàn fífi sí ẹrọ láti
> ipa-ọ̀nà agbègbè (`POST /api/plugins`) àti ìṣàwárí lórí disk
> (`POST /api/plugins/scan`).

## REST API

Gbogbo endpoint nílò ìfàṣẹsí ìṣàkóso (`requireManagementAuth`) **àti pé** wọ́n
wà fún loopback nìkan — `/api/plugins` àti `/api/plugins/` wà nínú àtòjọ
`LOCAL_ONLY_API_PREFIXES` (`src/server/authz/routeGuard.ts`).

| Endpoint                         | Ọ̀nà    | Àpèjúwe                                                         |
| -------------------------------- | ------ | --------------------------------------------------------------- |
| `/api/plugins`                   | GET    | Ṣe àtòjọ àwọn plugin tí a ti fi sílẹ̀ (àsẹ̀ `?status=` jẹ́ àṣàyàn) |
| `/api/plugins`                   | POST   | Fi plugin kan sílẹ̀ láti path agbègbè pípé                       |
| `/api/plugins/scan`              | POST   | Ṣàyẹ̀wò àpò-ọ̀nà plugin kí o sì forúkọsílẹ̀ àwọn plugin tuntun     |
| `/api/plugins/marketplace`       | GET    | Ṣe àtòjọ àwọn àkọsílẹ̀ katalogi ọjà                              |
| `/api/plugins/[name]`            | GET    | Gba àwọn àlàyé plugin tí a ti fi sílẹ̀                           |
| `/api/plugins/[name]`            | DELETE | Yọ plugin kan kúrò                                              |
| `/api/plugins/[name]/activate`   | POST   | Mú ṣiṣẹ́ (kó wọlé + forúkọsílẹ̀ àwọn hook)                        |
| `/api/plugins/[name]/deactivate` | POST   | Mú kúrò ní iṣẹ́ (ṣe `onDeactivate`, yọ ìforúkọsílẹ̀ àwọn hook)    |
| `/api/plugins/[name]/config`     | GET    | Gba config plugin + schema config                               |
| `/api/plugins/[name]/config`     | PUT    | Ṣe ìmúdójúìwọ̀n config plugin (tí a fìdí rẹ̀ múlẹ̀ pẹ̀lú schema)    |

Àlẹ̀mọ́ `status` fún `GET /api/plugins` gba ọ̀kan lára
`installed` / `active` / `inactive` / `error`. Iye tí kò tọ́ máa dá `400` padà.

### Ṣe àtòjọ àwọn plugin tí a ti fi sílẹ̀

```bash
curl http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..."
```

### Fi sílẹ̀ láti path agbègbè kan

```bash
curl -X POST http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "path": "/absolute/path/to/my-plugin" }'
```

`path` gbọ́dọ̀ jẹ́ **pípé**, kò sì gbọdọ̀ ní àwọn apá ìrìnàjò `..` tàbí
null bytes (Zod ló ń fipá mú èyí). Àpò-ọ̀nà orísun gbọ́dọ̀ ní
`plugin.json` tó péye (tàbí kí ó jẹ́ àpò-ọ̀nà òbí rẹ̀). Nígbà àṣeyọrí, ìdáhùn náà jẹ́ `201` pẹ̀lú
ìlà plugin tí a fi sílẹ̀.

### Ṣàwárí nínú ọjà

```bash
curl http://localhost:20128/api/plugins/marketplace \
  -H "Cookie: auth_token=..."
```

### Ṣe ìmúdójúìwọ̀n config plugin

```bash
curl -X PUT http://localhost:20128/api/plugins/my-plugin/config \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "config": { "level": "debug", "maxItems": 100 } }'
```

`PUT .../config` ń fìdí iye kọ̀ọ̀kan tí a pèsè múlẹ̀ pẹ̀lú
`configSchema` plugin náà (tí a kéde nínú manifest): àwọn field `number` ń tẹ̀lé `min`/`max`,
àwọn field `select` gbọ́dọ̀ bá `enum` tí a kéde mu. Àwọn key tí kò sí nínú schema
ni a gba láàyè láti kọjá.

## Ìṣètò

### Àpò-ọ̀nà plugin

Àwọn plugin wà lábẹ́ àpò-ọ̀nà dátà OmniRoute:

```
~/.omniroute/plugins/<plugin-name>/
  ├─ plugin.json
  └─ index.js          # (tàbí ohunkóhun tí manifest.main tọ́ka sí)
```

`getDefaultPluginDir()` (`src/lib/plugins/scanner.ts`) ń yanjú àpò-ọ̀nà yẹn ní
ìgbésẹ̀ mẹ́ta:

1. **`OMNIROUTE_PLUGINS_DIR`**, nígbà tí a bá ṣètò rẹ̀ — a lò ó bí ó ṣe rí, láìka ohun tí `HOME` sọ. Èyí ni
   ìṣàkóso pàtó fún Docker/K8s, níbi tí a ti fi igi plugin mọ́lẹ̀ ní path kan
   tí kò sábà ní ohunkóhun ṣe pẹ̀lú àpò-ọ̀nà ilé container náà (#11827).
2. `<home>/.omniroute/plugins`, níbi tí `<home>` ti wá láti inú àwọn environment variable `HOME` / `USERPROFILE`.
3. `/tmp/.omniroute/plugins`, nígbà tí process náà kò bá export àpò-ọ̀nà ilé rárá.

A máa log àpò-ọ̀nà tí a yanjú lẹ́ẹ̀kan ní ìbẹ̀rẹ̀ gẹ́gẹ́ bí `scanner.dir_resolved`, nípa dídárúkọ
input tó borí (`OMNIROUTE_PLUGINS_DIR`, `home`, tàbí `no-home-fallback`) — nítorí náà image kan
tí ó dé ìgbésẹ̀ 3 láìsọ ohunkóhun máa sọ bẹ́ẹ̀, dípò kí ó kàn ròyìn àtòjọ plugin òfo.
`POST /api/plugins/scan` ń ṣàwárí subdirectory èyíkéyìí níbẹ̀ tí ó ní
`plugin.json` tó péye, ó sì ń forúkọsílẹ̀ rẹ̀; àpò-ọ̀nà kan náà ni root tí
`pluginManager.install()` ń da àwọn plugin sí, nítorí náà override máa ń gbé ìṣàwárí àti
ìfísílẹ̀ papọ̀.

> **`OMNIROUTE_PLUGINS_DIR` kì í ṣe `OMNIROUTE_PLUGIN_PATH`.** Olùkójọpọ̀ command-plugin CLI
> (`bin/cli/plugins.mjs`) nìkan ló ń ka èkejì láti rí àwọn package npm `omniroute-cmd-*`
> tí ń fi àwọn subcommand `omniroute` kún un — kò ní ipa kankan lórí scanner runtime
> tí a ṣàpèjúwe níbí. Wo [PLUGINS.md](./PLUGINS.md) fún apá yẹn.

### URL registry ọjà àkànṣe

A ń ka orísun katalogi ọjà láti inú setting `pluginMarketplaceUrl`
(`src/lib/plugins/marketplace.ts` ń ka `settings.pluginMarketplaceUrl`). Nígbà tí
a bá ṣètò rẹ̀ sí URL `http(s)`, `listMarketplacePlugins()` máa fetch URL náà, yóò sì gba
yálà JSON array àwọn àkọsílẹ̀ ní ipele òkè tàbí object kan tó ní array `plugins`;
a máa yọ àwọn àkọsílẹ̀ tí kò ní `name` tó jẹ́ string kúrò. Nígbà tí a kò bá ṣètò rẹ̀ (tàbí tí fetch
bá kọjá ààbò SSRF / dá ìdáhùn búburú padà), a máa lo seed registry tó wà nínú ètò náà.

Tab "Marketplace" lórí dashboard ń fi field kan hàn fún URL yìí (tí a tún ka padà láti
`GET /api/settings`).

> Àkíyèsí ìmúṣẹ: ìṣe "Save" lórí dashboard ń fi
> `pluginMarketplaceUrl` ránṣẹ́ sí `PATCH /api/settings`. Ní àkókò tí a ń kọ èyí,
> a kò tíì kéde key yìí nínú `updateSettingsSchema`
> (`src/shared/validation/settingsSchemas.ts`), nítorí náà ṣàyẹ̀wò pé ó dúró sínú release rẹ
> kí o tó gbára lé e — path **kíkà** (`getSettings()` →
> `listMarketplacePlugins()`) máa ń tẹ̀lé key náà lẹ́yìn tí ó bá ti wà nínú ibi ìpamọ́ settings.

## Ààbò

### Ìpele ipa-ọ̀nà — loopback nìkan

Àwọn plugin ń ṣiṣẹ́ kóòdù nínú àwọn child process tí a ṣẹ̀dá, nítorí náà gbogbo ojú-ìṣàmúlò `/api/plugins`
ni a pín sí `LOCAL_ONLY` (Ìpele 1). Ìfipámú loopback máa ń ṣiṣẹ́
láìsí àídájú **ṣáájú** àyẹ̀wò ìfàṣẹsí èyíkéyìí, nítorí náà, kódà bí token ìṣàkóso kan bá tú jáde tí ó sì dé
ẹ̀rọ náà nípasẹ̀ tunnel, kò lè fi plugin sílẹ̀, mú un ṣiṣẹ́, tàbí yọ ọ́ kúrò.
Wo [`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md) àti
Àwọn Òfin Líle #15 / #17.

### Olùṣọ́ SSRF fún ìforúkọsílẹ̀ marketplace

URL ìforúkọsílẹ̀ àdáni jẹ́ àtúnṣe tí olùkọlù lè ní ipa lórí, nítorí náà ṣáájú
kí `listMarketplacePlugins()` tó gba a wá, ó máa ń fi í kọjá àwọn ipele méjì:

1. **`isSafeMarketplaceUrl(url)`** (`src/lib/plugins/marketplace.ts`):
   - Kọ ohunkóhun tí kì í ṣe `http:` / `https:`.
   - Kọ àwọn host private/loopback/link-local/ULA tí a kọ ní tààrà (IPv4 **àti** IPv6,
     pẹ̀lú IPv4-mapped) nípasẹ̀ `isPrivateHost` àṣẹ́ṣe
     (`src/shared/network/outboundUrlGuard.ts`).
   - Yanjú àwọn àkọsílẹ̀ `A` **àti** `AAAA` méjèèjì, ó sì kọ URL náà bí **èyíkéyìí** lára àwọn
     àdírẹ́sì tí a yanjú bá jẹ́ private — èyí ń dí ọ̀nà àbáyọ public-hostname → private-IP.
   - **Ó kọ̀ láìfàyè gba**: ìkùnà ìyànjú DNS máa ń jẹ́ kí a kọ URL náà.
2. **`safeOutboundFetch(url, { guard: "public-only", timeoutMs: 5000 })`**
   (`src/shared/network/safeOutboundFetch.ts`): tún lo olùṣọ́ URL public-only
   ní àkókò gbígbà, ó sì **dí àwọn àtúndarí lọ́nà** (kò sí ìyípadà public → private `30x`
   ).

URL tí ó kùnà ní èyíkéyìí lára àwọn ipele náà kò ní dá ìbéèrè náà dúró — marketplace
máa ń padà sí ìforúkọsílẹ̀ seed tí a fi sínú rẹ̀, ó sì máa ń ṣe àkọsílẹ̀ ìkìlọ̀.

> A mú olùṣọ́ yìí le sí i nínú PR #3774 ní pàtó láti yanjú A + AAAA àti láti lo
> `isPrivateHost` àṣẹ́ṣe dípò àyẹ̀wò IPv4-nìkan.

### Ìyàsọ́tọ̀ ìṣiṣẹ́ plugin

- **Ìyàsọ́tọ̀ process** — `loadPlugin()` (`src/lib/plugins/loader.ts`) máa ń ṣẹ̀dá
  plugin kọ̀ọ̀kan nínú child process Node.js ọ̀tọ̀, ó sì ń bá a sọ̀rọ̀ nípasẹ̀ IPC.
  Àwọn ìpè hook ní àkókò ìdúró tó pọ̀jù pẹ̀lú ìmúlọ́kànle `SIGTERM` → `SIGKILL`.
- **Àtòjọ ìyọ̀ǹda Env** — child náà gba àwọn environment variable tó wà nínú àtòjọ ìyọ̀ǹda
  nìkan; a máa ń fún un ní àkójọpọ̀ tó gbòòrò sí i nígbà tí manifest bá béèrè àṣẹ
  `env` nìkan.
- **Ìdènà path** — ìfisílẹ̀/ìgbéga/ìyọkúrò máa ń jẹ́rìí pé directory plugin
  àti `manifest.main` yanjú **láàárín** root plugin tí a ń ṣàkóso
  ṣáájú ẹ̀dà èyíkéyìí tàbí ìparẹ́ onípele (èyí ń dáàbò bo lòdì sí àwọn path DB tí a ti fọwọ́ bà
  àti ìrìn-àjò `../` nínú `manifest.main`). Ìmúṣiṣẹ́ máa ń yanjú àwọn symlink nípasẹ̀
  `realpath`, ó sì kọ̀ láti kó entry point tí ó jáde kúrò nínú directory
  plugin.
- **Integrity pin àṣàyàn** — manifest kan lè kéde field `integrity`
  (`sha256-<base64>`, fọ́ọ̀mù SRI). Nígbà tí ó bá wà, loader máa ń ṣàyẹ̀wò hash
  fáìlì ìbẹ̀rẹ̀ ní àkókò ìkó, ó sì kọ̀ láti mú un ṣiṣẹ́ bí wọn kò bá bára mu. Ó jẹ́
  ìṣàwárí ìfọwọ́bà àṣàyàn, **kì í ṣe** ààlà ààbò — ìtọ́sọ́nà loopback-nìkan
  àti àwòṣe àṣẹ ni àwọn ààlà gidi.

## Manifest (`plugin.json`)

`PluginManifestSchema` (`src/lib/plugins/manifest.ts`) ló ń fọwọ́sí i:

| Field              | Irú       | Àlàyé                                                        |
| ------------------ | --------- | ------------------------------------------------------------ |
| `name`             | string    | Dandan; kebab-case (`^[a-z0-9-]+$`), àmì 1–100               |
| `version`          | string    | Dandan; semver (`MAJOR.MINOR.PATCH`)                         |
| `description`      | string?   | ≤ àmì 500                                                    |
| `author`           | string?   | ≤ àmì 200                                                    |
| `license`          | string?   | Aiyipada rẹ̀ ni `MIT`                                         |
| `main`             | string?   | Fáìlì ìbẹ̀rẹ̀; aiyipada rẹ̀ ni `index.js`                       |
| `source`           | enum?     | `local` \| `marketplace` (aiyipada rẹ̀ ni `local`)            |
| `tags`             | string[]? | Àwọn tag ìṣàwárí                                             |
| `requires`         | object?   | `{ omniroute?, permissions[] }`                              |
| `hooks`            | object?   | Àwọn Boolean tó ń kéde àwọn hook tí plugin náà ṣe            |
| `skills`           | object[]? | Àwọn ìtumọ̀ skill àṣàyàn                                      |
| `enabledByDefault` | boolean?  | Mú ṣiṣẹ́ fúnra rẹ̀ nígbà ìfisílẹ̀                               |
| `configSchema`     | object?   | Map àwọn field config (`string`/`number`/`boolean`/`select`) |
| `integrity`        | string?   | Pin fáìlì ìbẹ̀rẹ̀ `sha256-<base64>` àṣàyàn                     |

A máa ń mú àwọn àṣẹ láti inú enum
`network` / `file-read` / `file-write` / `env` / `exec`.

## Ìṣàn Ìgbésí-ayé

```
fi sori ẹrọ (POST /api/plugins, ọ̀nà)
  → ṣàyẹ̀wò/fọwọ́sí manifest → daakọ sí staging → jẹ́rìí pé main wà nínú àpótí ìtọ́kasí
  → ṣe atomic rename sí ~/.omniroute/plugins/<name> → fi ìlà kún DB
  → ṣiṣẹ́ onInstall → tí enabledByDefault bá jẹ́ òótọ́: mú ṣiṣẹ́

mú ṣiṣẹ́ (POST /api/plugins/{name}/activate)
  → ṣe àyẹ̀wò pé realpath wà nínú ààlà → loadPlugin() (ṣẹ̀dá child process)
  → forúkọsílẹ̀ àwọn hook tí a kéde → status = "active" → ṣiṣẹ́ onActivate

mú kúrò ní ṣíṣiṣẹ́ (POST /api/plugins/{name}/deactivate)
  → ṣiṣẹ́ onDeactivate (ṢÁÁJÚ yíyọ kúrò nínú ìforúkọsílẹ̀) → yọ àwọn hook kúrò nínú ìforúkọsílẹ̀
  → dá child process dúró → status = "inactive"

yọ kúrò (DELETE /api/plugins/{name})
  → mú kúrò ní ṣíṣiṣẹ́ tí ó bá ń ṣiṣẹ́ → ṣiṣẹ́ onUninstall
  → pa àpótí ìtọ́kasí plugin rẹ́kọjá lẹ́yìn àyẹ̀wò ààlà → pa ìlà DB rẹ́
```

Ṣíṣe `install` lẹ́ẹ̀kansi lórí àpótí ìtọ́kasí kan tí ẹ̀yà manifest rẹ̀ jẹ́ **tuntun
gan-an** ju ẹ̀yà tí a ti fi sori ẹrọ lọ yóò ṣe àfikún ẹ̀yà laifọwọ́yi (fífi sori ẹrọ
mímọ́; config yóò padà sí àwọn iye àkọ́kọ́). Ẹ̀yà kan náà tàbí èyí tí ó ti pẹ́ ju ni a ó kọ̀.

## Pátákó Ìṣàkóso

Ojú-ewé pátákó ìṣàkóso ní `/dashboard/plugins`
(`src/app/(dashboard)/dashboard/plugins/page.tsx`) ní àwọn táàbù méjì:

- **Èyí tí a ti fi sori ẹrọ** — ó ṣe àtòjọ àwọn plugin tí a ti fi sori ẹrọ pẹ̀lú àwọn hook tí wọ́n kéde, bọ́tìnì
  àyípadà láti mú ṣiṣẹ́/mú kúrò ní ṣíṣiṣẹ́, bọ́tìnì yíyọ kúrò, àti iṣẹ́ “Ṣàyẹ̀wò fún àwọn plugin”
  (`POST /api/plugins/scan`).
- **Ọjà** — ó ṣàfihàn àkójọ láti `GET /api/plugins/marketplace` pẹ̀lú
  ààyè kan láti ṣètò URL registry àkànṣe.

Ojú-ewé config fún plugin kọ̀ọ̀kan wà ní `/dashboard/plugins/[name]/config`
(`src/app/(dashboard)/dashboard/plugins/[name]/config/page.tsx`).
