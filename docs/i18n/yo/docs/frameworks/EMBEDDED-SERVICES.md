## 1. Àkíyèsí gbogbogbò

### Kí nìdí tí a fi ní àwọn iṣẹ́ àfikún?

Àwọn iṣẹ́ márùn-ún ni a fi sínú rẹ̀:

| Iṣẹ́             | package npm                        | Port àìyípadà | Ète                                                                                                                                                                                              |
| --------------- | ---------------------------------- | :-----------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **9Router**     | `9router`                          |     20130     | Router AI tí OmniRoute lè lò gẹ́gẹ́ bí olùpèsè abẹ́lẹ̀. Àwọn model ni a ṣàfihàn gẹ́gẹ́ bí `9router/{sub}/{model}`                                                                                      |
| **CLIProxyAPI** | Binary ìtújáde GitHub (`cliproxy`) |     8317      | Adapter proxy agbègbè fún àwọn ìṣàn ìfàṣẹ̀sí Anthropic CLI. Ó ń pèsè ìtọ́sọ́nà àfẹ́yinti nígbà tí àwọn token OAuth bá parí                                                                           |
| **Mux**         | `mux` (headless `mux server`)      |     8322      | Daemon agbègbè fún ìṣètò àwọn agent (coder/mux). Ìṣàkóso ìgbésí-ayé nìkan — kì í ṣe ibi ìtọ́sọ́nà (kò ṣe proxying LLM).                                                                            |
| **Bifrost**     | `@maximhq/bifrost`                 |     8080      | Backend relay ẹnu-ọ̀nà AI Go. Nígbà tó bá ń ṣiṣẹ́, ipa-ọ̀nà relay (`/v1/relay/`) yóò yàn án fúnra rẹ̀                                                                                                |
| **Dario**       | `@askalf/dario`                    |     3456      | Proxy ìforúkọsílẹ̀ Claude — àṣàyàn mìíràn/àfẹ́yinti sí CLIProxyAPI fún traffic tó ní ìrísí Claude-Code; key tí a fi sínú rẹ̀ di `DARIO_ADMIN_TOKEN` tó ń dáàbò bo control plane OAuth `/admin/*` rẹ̀ |

Gbogbo àwọn márùn-ún ń tẹ̀lé àwòṣe ìṣàkóso kan náà:

- OmniRoute ń fi wọ́n sí abẹ́ `DATA_DIR/services/{name}/` (tí a ya sọ́tọ̀ kúrò nínú `package.json` ti OmniRoute fúnra rẹ̀)
- OmniRoute ń bẹ̀rẹ̀ wọn, ó sì ń ṣàkíyèsí wọn gẹ́gẹ́ bí àwọn child process
- OmniRoute ń fi API key ìgbà-díẹ̀ sínú environment ti child, ó sì ń yí i padà láìdá iṣẹ́ dúró (níbi tí ó bá yẹ)
- Gbogbo àwọn ipa-ọ̀nà ìṣàkóso (`/api/services/*`) jẹ́ **LOCAL_ONLY** — loopback nìkan ló lè wọ̀ wọ́n (òfin líle #17)

### Àwọn ìpinnu pàtàkì (láti inú ètò àpẹrẹ)

| Ìpinnu                                | Iye                                                                              |
| ------------------------------------- | -------------------------------------------------------------------------------- |
| Ìwọlé dashboard sí UI abinibi 9Router | Reverse proxy ní `/dashboard/providers/services/9router/embed/*`                 |
| Ọ̀nà fífi sórí ẹ̀rọ                     | `npm install {package}` nípasẹ̀ `execFile` (kò sí shell interpolation)            |
| Ìlànà lílò                            | A forúkọsílẹ̀ olùpèsè gẹ́gẹ́ bí `9router/{sub}/{model}` nínú routing engine         |
| Ìṣàkóso API key                       | OmniRoute ń ṣẹ̀dá rẹ̀, ń encrypt rẹ̀ níbi ìpamọ́ (AES-256-GCM), ó sì ń fi í sínú env |
| Ibi tí dashboard wà                   | `/dashboard/providers/services` (àwọn tab mẹ́ta)                                  |
| Ìbẹ̀rẹ̀ aládàáṣiṣẹ́                      | Toggle fún iṣẹ́ kọ̀ọ̀kan, OFF ni àìyípadà rẹ̀                                        |

## 3. Ẹ̀rọ ipò ìgbésí-ayé

```
                    install()
  ┌─────────────┐ ──────────► ┌─────────────┐
  │ not_installed│             │   stopped   │◄──────────────────┐
  └─────────────┘             └──────┬──────┘                   │
                                     │ start()                   │
                                     ▼                           │ stop()
                               ┌──────────┐                      │
                               │ starting │                      │
                               └────┬─────┘                     │
            àyẹ̀wò ìlera dára   │         ìjákulẹ̀ / SIGTERM     │
                               ┌────▼─────┐  (jáde láàárín 5s)  │
                               │ running  │──── ìjákulẹ̀ ───────►┤
                               └────┬─────┘                   ┌─▼────┐
                             stop() │                          │error │
                                    ▼                          └──────┘
                               ┌──────────┐
                               │ stopping │
                               └──────────┘
```

Àwọn ipò ni a fi pamọ́ sínú tábìlì DB `version_manager` (ọ̀wọ̀n `status`), a sì ń ṣe àwòkọ
wọn sínú ipò inú ìrántí `ServiceSupervisor`. Ipò inú ìrántí ni ó jẹ́ aláṣẹ fún
ìlànà tó ń ṣiṣẹ́; ipò DB ni àfẹ́yìntì tó dúró pẹ́ nígbà ìbẹ̀rẹ̀ ẹrọ.

### Àwọn ìyípadà ipò

| Láti            | Ìṣẹ̀lẹ̀                        | Sí                       |
| --------------- | ---------------------------- | ------------------------ |
| `not_installed` | `install()` ṣàṣeyọrí         | `stopped`                |
| `stopped`       | a pe `start()`               | `starting`               |
| `starting`      | àyẹ̀wò ìlera dá 200 padà      | `running`                |
| `starting`      | ìlànà jáde kí ó tó ní ìlera  | `error`                  |
| `running`       | a pe `stop()`                | `stopping` → `stopped`   |
| `running`       | ìlànà jáde láìròtẹ́lẹ̀ (< 5 s) | `error` (ìjákulẹ̀ kíákíá) |
| `running`       | ìlànà jáde láìròtẹ́lẹ̀ (> 5 s) | `error`                  |
| `error`         | a pe `start()`               | `starting`               |
| èyíkéyìí        | `stop()` nígbà `stopping`    | kò ṣe nǹkan kan          |

### Títì iṣẹ́

`ServiceSupervisor` ń ṣètò àwọn iṣẹ́ ìgbésí-ayé ní ọ̀kọ̀ọ̀kan nípasẹ̀ títì iṣẹ́ async kan
(`withLock()`). Àwọn ìpè `start()` tó wá lẹ́ẹ̀kan náà lórí supervisor kan náà máa yọrí sí
spawn kan ṣoṣo; ẹni tó pè lẹ́ẹ̀kejì yóò dúró, yóò sì dá ipò tó wà padà. Èyí ń dènà
àwọn ìṣòro ìdíje nígbà tí, fún àpẹẹrẹ, ìbẹ̀rẹ̀ aládàáṣiṣẹ́ àti bọ́tìnì UI bá ṣiṣẹ́ lẹ́ẹ̀kan náà.

## 4. Ìtọ́kasí API

### 4.6 Proxy ìdàkejì (ìfihàn dashboard 9Router)

Dashboard náà ṣàfihàn UI wẹ́ẹ̀bù 9Router nínú iframe nípasẹ̀ proxy ìdàkejì inú
ní:

```
GET|POST|... /dashboard/providers/services/9router/embed/[...path]
```

Proxy yìí:

- Rán ìbéèrè náà sí `http://127.0.0.1:{port}/{path}` (loopback nìkan)
- Yọ àwọn header `cookie` àti `authorization` tó ń wọlé kúrò (kò sí jíjáde session OmniRoute)
- Fi `Authorization: Bearer {apiKey}` sínú rẹ̀ fún ìfàṣẹsí 9Router
- Yọ `set-cookie`, `content-security-policy`, `x-frame-options`, `cross-origin-*` kúrò nínú èsì
- Tún àwọn èsì HTML kọ láti fi `<base href>` sínú wọn àti láti mú àwọn ipa-ọ̀nà absolute bá ìlànà kan náà (`/foo` → `/dashboard/.../embed/foo`)

Àwọn upgrade WebSocket fún dashboard tí a fi sínú rẹ̀ ni server alábàákẹ́gbẹ́ kan ń bójú tó lórí
port tí a yà sọ́tọ̀ (wo `src/lib/services/embedWsProxy.ts`).

**Ààbò:** Àwọn ipa-ọ̀nà proxy embed náà ni a pín sí abẹ́ `LOCAL_ONLY_API_PREFIXES`
àti pé láti loopback nìkan ni a ti lè wọlé sí wọn. Olùkọlù tó bá gba JWT nípasẹ̀
tunnel Cloudflare/Ngrok kò lè lo proxy wọ àwọn iṣẹ́ tí a fi sínú rẹ̀.

## 5. Ààbò

### Ìfipámúlò LOCAL_ONLY (òfin líle #17)

Gbogbo àwọn ọ̀nà tí ó wà lábẹ́ `/api/services/` àti `/dashboard/providers/services/*/embed/` ni a
sọ̀rí sí LOCAL_ONLY nínú `src/server/authz/routeGuard.ts`. Àyẹ̀wò loopback náà
máa ń ṣiṣẹ́ láìsí àídájú ṣáájú ẹ̀ka ìfàṣẹsí èyíkéyìí:

```
ìbéèrè dé
  → isLocalOnlyPath(path)?
      → kì í ṣe loopback → 403 LOCAL_ONLY (nígbà gbogbo, ṣáájú àyẹ̀wò ìfàṣẹsí)
      → loopback         → tẹ̀síwájú sí ìfàṣẹsí àtẹ̀wọ́dá
```

Èyí ń dí JWT tí ó ti tú jáde (fún àpẹẹrẹ, nípasẹ̀ tunnel) lọ́wọ́ láti fa `npm install` tàbí
ìpilẹ̀ṣẹ̀ process. Wo `docs/security/ROUTE_GUARD_TIERS.md` fún matrix ipele
kíkún.

### Ìfi API key sínú

9Router àti Mux nílò API key/bearer token fún àwọn endpoint HTTP tiwọn.
OmniRoute:

1. Ń ṣẹ̀dá key kan nípasẹ̀ `crypto.randomBytes(32).toString("base64url")` pẹ̀lú
   ìpele-iṣáájú tí ó jẹ́ ti service náà (`nr_` fún 9Router, `mx_` fún Mux).
2. Ń parọ́ọ̀dì rẹ̀ níbi ìpamọ́ nípa lílo AES-256-GCM (cipher kan náà tí a lò fún àwọn credential provider).
3. Ń yọ ìparọ́ọ̀dì náà, ó sì ń fi í sínú gẹ́gẹ́ bí environment variable ní àkókò spawn —
   `NINEROUTER_API_KEY` fún 9Router, `MUX_SERVER_AUTH_TOKEN` fún Mux (kì í ṣe flag CLI
   láé, kí token náà má bàa hàn nínú àwọn àtòjọ `ps`/process).
4. Kò dá plaintext key padà nínú ìdáhùn HTTP èyíkéyìí láé.

CLIProxyAPI gba data-plane key pàtó kan tí a fi sínú rẹ̀ ní àkókò spawn
(`needsApiKey: true` — tí a lò fún ìmúdójúìwọ̀n model pẹ̀lú adapter).

### Ààbò lòdì sí SSRF

Reverse HTTP proxy (`/dashboard/.../embed/[...path]`) jẹ́ èyí tí a hardcode láti fi ìbéèrè ránṣẹ́
sí `http://127.0.0.1:{port}` nìkan. Kò tẹ̀lé àwọn redirect sí ibi tí kì í ṣe loopback
láé. A ń lo library `ssrf-req-filter` láti kọ URL upstream èyíkéyìí tí ó
resolve sí òde ibú loopback.

### Ààbò shell (òfin líle #13)

A ń pe `npm install` nípasẹ̀ `execFile('npm', ['install', pkg, '--prefix', dir])` —
kò sí template literal, kò sí shell, kò sì sí interpolation àwọn path ìta sínú command
string. Àwọn iye runtime (ports, API keys) ni a ń gbé kọjá nípasẹ̀ object `env` ti child.

### Ìmọ́tótó error (òfin líle #12)

Gbogbo àwọn ìdáhùn error láti `/api/services/*` ń gba inú `buildErrorBody()` tàbí
`sanitizeErrorMessage()` kọjá. A kì í dá `err.stack` àti `err.message` aise
padà gẹ́gẹ́ bí wọ́n ṣe rí sí olùpè.

## 6. Fífi service tuntun tí a ṣàfikún mọ́ inú ètò kún un

Tẹ̀lé àwọn ìgbésẹ̀ 8 wọ̀nyí. Ka àwọn implementation tó ti wà ní `src/lib/services/installers/`
àti `src/app/api/services/` gẹ́gẹ́ bí ìtọ́kasí àṣẹ.

### Ìgbésẹ̀ 1 — Ṣẹ̀dá installer náà

Ṣẹ̀dá `src/lib/services/installers/{name}.ts` tí a ṣe ní àwòkọ́ṣe `ninerouter.ts`:

```typescript
export const NAME_PACKAGE = "your-npm-package";
export const NAME_DEFAULT_PORT = 20132; // yan port tí ó ṣí sílẹ̀

export async function install(version = "latest"): Promise<InstallResult> { ... }
export async function update(version = "latest"): Promise<InstallResult> { ... }
export async function uninstall(): Promise<void> { ... }
export function resolveSpawnArgs(apiKey: string, port: number): SpawnArgs { ... }
export async function getInstalledVersion(): Promise<string | null> { ... }
export async function getLatestVersion(): Promise<string | null> { ... }
```

Lo `runNpm(['install', NAME_PACKAGE, '--prefix', dir])` láti `installers/utils.ts`
— má lo `execSync` tàbí shell interpolation láé.

### Ìgbésẹ̀ 2 — Forúkọsílẹ̀ nínú bootstrap

Fi `ServiceEntry` kan kún array `SERVICES` nínú `src/lib/services/bootstrap.ts`:

```typescript
{
  tool: "myservice",
  port: NAME_DEFAULT_PORT,
  healthPath: "/health",
  healthIntervalMs: 5_000,
  stopTimeoutMs: 15_000,
  logsBufferBytes: 5_242_880,
  needsApiKey: true, // false bí kò bá nílò API key
}
```

Fa `buildSpawnArgsFactory()` gùn láti bójútó `cfg.tool === "myservice"`.

#### Àdéhùn provider-plugin tí a lè so mọ́ (Ìpele 1, #7333)

`src/lib/services/providerPlugins/` gbé àdéhùn `ServiceProviderPlugin` kan kalẹ̀ tí ó
kó àwọn field `ServiceEntry` inú `bootstrap.ts` ti backend kan àti àwọn field manifest-template
inú `serviceBackends.ts` jọ sínú object kan, dípò kí irú backend kan náà
jẹ́ àfihàn lọ́tọ̀ nínú àwọn file méjì tí kò ní ìbáṣepọ̀. Ní àkókò tí a ń kọ èyí **`9router` nìkan ni
a ti ṣí lọ** — `bootstrap.ts` ń yọ entry `SERVICES[]` rẹ̀ láti
`getServiceProviderPlugin("9router")` (`src/lib/services/providerPlugins/registry.ts`),
ó sì ń ju error ìbẹ̀rẹ̀ jáde bí plugin náà bá sọnù láé. `cliproxy`, `mux`, àti `bifrost`
ṣì wà lórí àwọn literal inline `SERVICES[]` tó ti wà tẹ́lẹ̀ láìyípadà.

`open-sse/config/providerPluginManifest.ts` tún gba helper àfikún
`createServiceBackendManifestEntry(pluginId, template)` tí ó ń kọ
`ProviderPluginManifestEntry` tí a ṣe dáadáa láti inú entry `SERVICE_BACKEND_MANIFEST_TEMPLATE` kan — a
**kò tíì** so ó mọ́ request path tó ń ṣiṣẹ́ kankan (bóyá `generateProviderPluginManifestFromRegistry()`
tàbí `/v1/providers/[provider]/models`); ìyẹn ṣì jẹ́ iṣẹ́ àtẹ̀lé lẹ́yìn tí a bá ti
jẹ́rìí àdéhùn náà fún backend kejì.

A sún un sí àwọn PR àtẹ̀lé, tí a ń tọpinpin lábẹ́ issue #7333: ṣíṣí `cliproxyapi` lọ nípasẹ̀
registry kan náà, ṣíṣe `mux`/`bifrost` ní gbogbogbòò sínú union `ServiceBackendPluginId`,
ṣíṣe àkójọpọ̀ special-casing executor-routing (`open-sse/executors/index.ts`,
`open-sse/handlers/chatCore/executorProxy.ts`) sínú àdéhùn plugin, àti síso
`createServiceBackendManifestEntry()` mọ́ manifest/models code path tó ń ṣiṣẹ́.

### Ìgbésẹ̀ 3 — Ṣàfikún migration àti DB seed

Tí service tí a fi sínú rẹ̀ bá ń pèsè endpoint `/v1/chat/completions` tó bá OpenAI mu:

1. Ṣàfikún àkọsílẹ̀ provider kan sínú `src/shared/constants/providers.ts` pẹ̀lú `isEmbeddedService: true`.
2. Ṣẹ̀dá `open-sse/executors/{name}.ts` tó ń jogún láti `BaseExecutor`. Ṣàwárí port àti
   API key lẹ́ẹ̀kan sí i fún request kọ̀ọ̀kan (má ṣe cache wọn nínú constructor láé). Dá ìdáhùn

3. Forúkọsílẹ̀ àwọn model sínú `open-sse/config/providerRegistry.ts` pẹ̀lú prefix service náà
   (fún àpẹẹrẹ, `myservice/sub/model`). `modelSync.ts` yóò máa mú wọn wà ní ìmúdójúìwọ̀n.

## 7. Yíyanjú àwọn ìṣòro

### Iṣẹ́ kò bẹ̀rẹ̀

**Àwọn àmì:** Bọ́tìnì ìbẹ̀rẹ̀ dá 503 padà, ipò sì dúró sí `"error"` tàbí `"starting"`.

**Àtòjọ ohun àyẹ̀wò:**

1. Ṣàyẹ̀wò `GET /api/services/{name}/logs` (tàbí pánẹ́ẹ̀lì Logs nínú dashboard). Wá
   àwọn ìlà bíi `Error: ENOENT`, `address already in use`, tàbí `Cannot find module`.
2. Jẹ́rìí pé `npm` wà nínú PATH: lo `which npm` láti inú àkọọ́lẹ̀ onílò kan náà tí ó ń ṣiṣẹ́ OmniRoute.
3. Jẹ́rìí pé a ti fi iṣẹ́ náà sílẹ̀: ṣàyẹ̀wò `GET /api/services/{name}/status` fún
   `installedVersion`. Tí ó bá jẹ́ `null`, kọ́kọ́ ṣiṣẹ́ ìfisílẹ̀.
4. Ṣàyẹ̀wò pé `DATA_DIR/services/{name}/node_modules/` wà àti pé kò ṣófo.
5. Ṣàyẹ̀wò ààyè `lastError` nínú ìdáhùn ipò fún ìdí ìjáde tí a ti sọ di àìléwu.

---

### Ìbẹ̀rẹ̀ tútù lọra (> 10 s láti dé `running`)

**Àwọn àmì:** Ipò dúró sí `"starting"` fún ìgbà pípẹ́ kí ó tó lọ sí `"running"` tàbí `"error"`.

**Àlàyé:** Ìbẹ̀rẹ̀ tútù 9Router ní gbígbé àwọn igi dependency ńlá wọlé (DNS,
tunnel, àwọn module MITM). Àkókò àárín àyẹ̀wò ìlera àkọ́kọ́ jẹ́ 2 s pẹ̀lú ìgbìyànjú mẹ́ta kí
supervisor tó kéde pé àkókò ti parí (ṣùgbọ́n ó máa ń tẹ̀síwájú láti ṣe polling).

**Àtúnṣe:** `healthIntervalMs` àti àkókò ìdúró `waitForHealthy`
(`healthIntervalMs * 3`) ṣeé túnto nínú `bootstrap.ts`. Fún àwọn iṣẹ́ tí
àkókò ìbẹ̀rẹ̀ wọn gùn sí i, mú `healthIntervalMs` pọ̀ sí 5000 àti `stopTimeoutMs` sí 30 000.

---

### Ìkọlù port (`EADDRINUSE`)

**Àwọn àmì:** Àwọn àkọsílẹ̀ fi `address already in use :::20130` hàn.

**Àwọn okùnfà:**

- Process mìíràn ti ń lo port 20130 tẹ́lẹ̀.
- Process 9Router tẹ́lẹ̀ kan kò dá dúró pátápátá (PID zombie).

**Àtúnṣe:**

1. Yí port àkọ́kọ́ padà nípasẹ̀ environment variable `NINEROUTER_PORT` nínú `.env`.
2. Wá process tó ń fa ìkọlù náà kí o sì pa á: `lsof -ti :20130 | xargs kill -9`.
3. A lè tún port ṣe fún iṣẹ́ kọ̀ọ̀kan nínú `bootstrap.ts` nípasẹ̀ ààyè `port`.

**Àkíyèsí:** 9Router máa ń lo port 20130 gẹ́gẹ́ bí àkọ́kọ́ ní pàtó láti yẹra fún ìkọlù pẹ̀lú
port àkọ́kọ́ OmniRoute, 20128.

---

### A kọ ìyọ̀nda (EACCES) nígbà ìfisílẹ̀

**Àwọn àmì:** Ìfisílẹ̀ dá 500 padà, àwọn àkọsílẹ̀ sì fi `EACCES` tàbí `permission denied` hàn.

**Àwọn okùnfà:**

- Process OmniRoute kò ní àṣẹ láti kọ sínú `DATA_DIR` tàbí directory òbí rẹ̀.
- Ṣíṣiṣẹ́ nínú Docker rootless láìní àṣẹ láti kọ sínú volume tí a so mọ́.

**Àtúnṣe:**

1. Ṣàyẹ̀wò `DATA_DIR` (àkọ́kọ́: `~/.omniroute/`): `ls -la ~/.omniroute/`
2. Rí i dájú pé onílò process OmniRoute ni directory náà: `chown -R $USER ~/.omniroute/`
3. Nínú Docker, rí i dájú pé volume mount ní àwọn ìyọ̀nda tó tọ́ fún onílò container náà.

---

### Ìmúdójúìwọ̀n kùnà (`npm install` timeout tàbí àṣìṣe nẹ́tíwọ́ọ̀kì)

**Àwọn àmì:** Ìmúdójúìwọ̀n dá 500 pẹ̀lú `InstallError` padà, àwọn àkọsílẹ̀ sì fi network timeout hàn.

**Àtòjọ ohun àyẹ̀wò:**

1. Jẹ́rìí pé a lè dé npm registry: `npm ping`.
2. Ṣàyẹ̀wò corporate proxy: `npm config get proxy`, `npm config get https-proxy`.
3. Gbìyànjú ìfisílẹ̀ náà pẹ̀lú ọwọ́: `npm install {package}@latest --prefix ~/.omniroute/services/{name}/`.
4. Tí o bá wà lẹ́yìn air-gap, kọ́kọ́ ṣe àgbàsílẹ̀ tarball náà, kí o sì lo `npm install /path/to/tarball.tgz`.

---

### Iṣẹ́ fi ipò `"error"` hàn lẹ́sẹ̀kẹsẹ̀ lẹ́yìn ìbẹ̀rẹ̀ (ìkọ̀lù yíyára)

**Àwọn àmì:** Ipò yí padà láti `"starting"` sí `"error"` láàárín ìṣẹ́jú-ààyá 5.
`lastError` fi `"Fast crash (exited with code 1)"` hàn.

**Àtòjọ ohun àyẹ̀wò:**

1. Ka gbogbo ìparí àkọsílẹ̀: `GET /api/services/{name}/logs?tail=500`.
2. Okùnfà tó wọ́pọ̀: àwọn environment variable tí iṣẹ́ náà ń retí kò sí.
3. Fún 9Router: jẹ́rìí pé `NINEROUTER_DISABLE_MITM=true` àti
   `NINEROUTER_DISABLE_TUNNEL=true` wà nínú env tí a fi ránṣẹ́ nígbà spawn (wo
   `installers/ninerouter.ts` `resolveSpawnArgs`).

## 8. Àwọn Ìbéèrè Tí A Máa Ń Béèrè Léraléra

**Ì: Ṣé mo lè ṣí àwọn endpoint iṣẹ́ tí a fi sínú rẹ̀ sílẹ̀ fún àwọn client tí kì í ṣe loopback?**

Rárá. Ìpele LOCAL_ONLY jẹ́ ohun tí a mọ̀ọ́mọ̀ ṣe (òfin líle #17). Àwọn route tí ó lè pe
`npm install` tàbí dá àwọn process `node` sílẹ̀ kò gbọdọ̀ ṣeé dé láti inú traffic tí kì í ṣe loopback,
nítorí JWT tí ó bá tú jáde nípasẹ̀ tunnel kan (Cloudflare, Ngrok, Tailscale) yóò
jẹ́ kí ó ṣeé ṣe láti dá process èyíkéyìí sílẹ̀. Kò sí ọ̀nà láti yọ ara ẹni kúrò nínú òfin yìí fún
`/api/services/` — ní ìyàtọ̀ sí `/api/mcp/`, a kò fi í sínú àtòjọ bypass
manage-scope. Wo `docs/security/ROUTE_GUARD_TIERS.md`.

---

**Ì: Ṣé 9Router àti CLIProxyAPI yóò wà fún àwọn ìmúṣiṣẹ́ production/cloud?**

Bẹ́ẹ̀ ni. Àwọn iṣẹ́ méjèèjì ń tẹ̀lé àwòṣe local-first kan náà bí OmniRoute fúnra rẹ̀. Wọ́n ń ṣiṣẹ́
lórí ẹ̀rọ kan náà, wọ́n sì ń bá ara wọn sọ̀rọ̀ nípasẹ̀ loopback. "Production" níbí túmọ̀ sí VPS
tàbí server agbègbè tí a ti fi OmniRoute sí, kì í ṣe cloud provider jíjìnnà kan.

---

**Ì: Báwo ni mo ṣe lè ṣe àyẹ̀wò àṣìṣe supervisor náà?**

1. Tẹ̀lé ìṣàn log SSE náà: `curl -N http://localhost:20128/api/services/9router/logs`.
2. Ṣàyẹ̀wò àwọn log tí a ṣètò létòlétò nínú output pino ti OmniRoute, tí a ti ṣe filter rẹ̀ pẹ̀lú
   namespace `service:supervisor`.
3. Ṣàyẹ̀wò row DB náà: `sqlite3 ~/.omniroute/omniroute.db "SELECT * FROM version_manager WHERE tool='9router'"`.
4. Lo `GET /api/services/9router/status` láti wo state tó ń ṣiṣẹ́ lọ́wọ́lọ́wọ́, PID, health,
   àti `lastError` nínú ìpè kan ṣoṣo.

---

**Ì: Supervisor náà ń fi `health: "degraded"` tàbí `health: "unknown"` hàn ṣùgbọ́n state jẹ́ `"running"`. Ṣé ìṣòro ni èyí?**

`"degraded"` túmọ̀ sí pé health probe náà dá response tí kì í ṣe 200 padà. `"unknown"` túmọ̀ sí pé kò sí
probe tí ó tíì parí (ìfìgbárí pẹ̀lú poll àkọ́kọ́). Àwọn méjèèjì jẹ́ ti ìgbà díẹ̀ nígbà startup.
Tí health bá dúró sí `"degraded"` fún ju `healthIntervalMs * 3` ms lẹ́yìn
`"running"`, iṣẹ́ tí a fi sínú rẹ̀ ń ṣiṣẹ́, ṣùgbọ́n HTTP API rẹ̀ kò ń dáhùn. Ṣàyẹ̀wò
bóyá port náà tọ̀nà nínú response status àti bóyá iṣẹ́ náà ń
gbọ́ ní port náà ní ti gidi.

---

**Ì: Ṣé mo lè yí key API 9Router padà láì ṣe restart ní kíkún?**

Rárá. A ń fi key API náà ránṣẹ́ sí 9Router nípasẹ̀ environment variable ní àkókò tí a bá ń dá process sílẹ̀.
A kò lè yí environment variable padà nínú process tó ń ṣiṣẹ́. `POST .../rotate-key`
yóò dá iṣẹ́ náà dúró, yóò sì tún bẹ̀rẹ̀ rẹ̀ láìfọwọ́sí láti fi key tuntun náà sílò. Yíyí key náà padà
yóò bẹ̀rẹ̀ sí í ṣiṣẹ́ láàárín `stopTimeoutMs` iṣẹ́ náà (default jẹ́ 15 s) pẹ̀lú àkókò
startup rẹ̀.

---

**Ì: Kí ni òpin ring buffer, kí sì ni yóò ṣẹlẹ̀ nígbà tí ó bá kún?**

Iṣẹ́ kọ̀ọ̀kan ní ring buffer 5 MB tirẹ̀. Nígbà tí buffer náà bá kún, a máa ń yọ àwọn
ìlà log tó ti pẹ́ jù lọ kúrò láti fi àyè sílẹ̀ fún àwọn tuntun. Event `snapshot` SSE náà máa ń dá
àwọn ìlà tuntun jù lọ tí ó wà láàárín òpin `tail` padà. A kì í fi àwọn log pamọ́ sí disk àyàfi tí
a bá ṣètò `logsBufferPath` nínú row DB náà.
