> **Orísun òtítọ́:** `src/lib/skills/` àti `src/app/api/skills/`
> **Ìmúdójúìwọ̀n tó kẹ́yìn:** 2026-06-28 — v3.8.40

OmniRoute ń pèsè ìlànà Skills tí a lè fẹ̀ sí i, èyí tó ń jẹ́ kí àwọn àwòṣe èdè (àti àwọn olùdarí) lè ṣàkójọpọ̀ àwọn agbára tí a lè tún lò — láti kíkà ètò-fáìlì àti àwọn ìbéèrè HTTP títí dé ṣíṣe kóòdù nínú àyíká ààbò àti àwọn skills ibi-ọjà tí a ti fara balẹ̀ yàn.

Skill jẹ́ ẹyọ iṣẹ́ tó ní ẹ̀yà, tí schema sì ṣàlàyé rẹ̀. OmniRoute lè fi àwọn skills sínú àwọn ìbéèrè tó ń jáde gẹ́gẹ́ bí àwọn ìtumọ̀ irinṣẹ́, dá àwọn ìpè irinṣẹ́ tó ń padà láti ọ̀dọ̀ àwòṣe dúró, ṣiṣẹ́ handler tó bá mu, kí ó sì fi àbájáde náà padà fún àwòṣe kí ìjíròrò lè tẹ̀síwájú. Àwòṣe náà kì í rí ìmúlò rẹ̀ — ojú-ọ̀nà irinṣẹ́ nìkan ló ń rí.

## Agent Skills àti Omni Skills

OmniRoute ní àwọn ètò skill méjì tó yàtọ̀ síra ṣùgbọ́n tí wọ́n ń ṣiṣẹ́ pọ̀:

| Ìwọ̀n           | **Omni Skills** (ìwé yìí)                                                 | **Agent Skills**                                                                                  |
| :------------- | :------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------ |
| Ète            | Fífi irinṣẹ́ LLM sínú ìbéèrè + ṣíṣe rẹ̀ nínú àyíká ààbò                     | Àkójọ SKILL.md fún àwọn agent òde láti ṣàwárí àti lò                                              |
| Orísun òtítọ́   | `src/lib/skills/` + ibi-ọjà                                               | `src/lib/agentSkills/` + àpò-ọ̀nà `skills/`                                                        |
| Ìpo àsìkò-ṣiṣe | A máa fi sínú àwọn ìbéèrè tó ń jáde, a sì máa ṣiṣẹ́ nígbà ìṣẹ̀lẹ̀ ìpè-irinṣẹ́ | Àkójọ markdown àìyípadà + àwọn endpoint ìṣàwárí REST/MCP/A2A                                      |
| Ẹni tó ń lò ó  | OmniRoute fúnra rẹ̀ (combo routing, àwọn ìpè LLM tó ń wọlé)                | Àwọn agent òde, àwọn client MCP, àwọn orchestrator A2A                                            |
| Iye            | Ó lè yípadà (ibi-ọjà ló ń darí rẹ̀)                                        | Àwọn àkọsílẹ̀ àkójọ 45 (23 API + 21 CLI + 1 config)                                                |
| Fọ́ọ̀mù          | `SkillDefinition` pẹ̀lú schema irinṣẹ́ + handler                            | frontmatter `SKILL.md` + ara markdown                                                             |
| Ìṣàwárí        | `/api/skills/*` REST + àwọn irinṣẹ́ MCP `omniroute_skills_*`               | `/api/agent-skills/*` REST + àwọn irinṣẹ́ MCP `omniroute_agent_skills_*` + A2A `list-capabilities` |

**Omni Skills** ni ẹ̀rọ ìṣiṣẹ́ — wọ́n ń ṣàlàyé ohun tí OmniRoute _lè ṣe_ nígbà tí LLM bá pe irinṣẹ́ kan.

**Agent Skills** ni àkójọ ìwé ìtọ́sọ́nà — wọ́n ń ṣàlàyé fún àwọn agent òde _bí a ṣe ń lo_ REST API àti CLI OmniRoute, pẹ̀lú àwọn fáìlì SKILL.md tó ní ìṣètò tí a lè fi sínú àwọn prompt agent ní tààrà.

Fún àkójọ Agent Skills, generator, àwọn irinṣẹ́ MCP, àti skill A2A, wo [docs/frameworks/AGENT-SKILLS.md](./AGENT-SKILLS.md).

## Àwọn Àròjinlẹ̀

### Àwọn Orísun Skill

Orísun skill mẹ́ta ló wà papọ̀ nínú registry kan náà:

1. **Àwọn skill tí a kọ́ sínú rẹ̀** (`src/lib/skills/builtins.ts`) — wọ́n wá pẹ̀lú OmniRoute. Wọ́n bo àwọn ọ̀ràn tó wọ́pọ̀:
   - `file_read`, `file_write` — workspace àyíká ààbò fún kọ́kọ́rọ́ API kọ̀ọ̀kan lábẹ́ `<DATA_DIR>/skills/workspaces/<hashed-key>/`
   - `http_request` — HTTP tó ń jáde nípasẹ̀ `safeOutboundFetch` pẹ̀lú `guard: "public-only"`
   - `web_search` — olùpèsè ìṣàwárí tí a lè yí padà pẹ̀lú caching (`executeWebSearch`)
   - `eval_code` — ṣíṣe `node` tàbí `python` tí Docker dá sí àyíká ààbò
   - `execute_command` — àṣẹ shell tí Docker dá sí àyíká ààbò
   - `browser` — ìpìlẹ̀ iṣẹ́ tí Playwright ń ṣe àtìlẹ́yìn fún, tí a pa nípa àìyípadà (`builtin/browser.ts`)
2. **SkillsMP** (Ibi-ọjà OmniRoute) — a máa ń mú un wá láti `https://skillsmp.com/api/v1/skills/search`. Ó nílò `skillsmpApiKey` nínú Settings.
3. **SkillsSH** (àkójọ àwùjọ `skills.sh`) — a máa ń mú un wá láti `https://skills.sh/api/search`. Kò nílò ìfàṣẹsí; a máa ń fa àkóónú SKILL.md láti GitHub raw.

“Olùpèsè tó ń ṣiṣẹ́” kan ṣoṣo ló ń ṣàkóso àkójọ tí dashboard máa fi ohun sílẹ̀ láti inú rẹ̀ (`src/lib/skills/providerSettings.ts`). Yí i padà lábẹ́ **Settings → Memory & Skills**. Àìyípadà: `skillsmp`.

### Ìdánimọ̀ Skill

A máa ń fi `name@version` ṣe kọ́kọ́rọ́ àwọn skills nínú registry inú-memory (`src/lib/skills/registry.ts`). Version gbọ́dọ̀ jẹ́ semver (`^\d+\.\d+\.\d+$`). `resolveVersion()` lóye `^`, `~`, `>`, `>=`, `<`, `<=`, `==`, àti àwọn ìdíwọ̀n ìbámu pípé.

### Ìpo Skill

Skill kọ̀ọ̀kan ní ìpo àsìkò-ṣiṣe tó ń ṣàkóso ìgbà tí a ó fi í sínú ìbéèrè:

| Ìpo    | Ìhùwàsí                                                                                                    |
| ------ | ---------------------------------------------------------------------------------------------------------- |
| `on`   | A máa ń fi í sínú ìbéèrè ní gbogbo ìgbà gẹ́gẹ́ bí ìtumọ̀ irinṣẹ́                                               |
| `off`  | A kì í fi í sínú ìbéèrè rárá, a kò sì lè ṣiṣẹ́ ẹ̀                                                            |
| `auto` | A máa ń fi ìbéèrè tó ń wọlé wọ̀n ọ́; a ó fi í sínú ìbéèrè nìkan tí àmì bá jẹ́ ≥ `AUTO_MIN_SCORE` (àìyípadà 3) |

`auto` ni àìyípadà fún àwọn skill tí a fi sílẹ̀ láti ibi-ọjà. `enabled=true` àti `mode="off"` papọ̀ túmọ̀ sí “a ti forúkọsílẹ̀ rẹ̀ ṣùgbọ́n kò ṣiṣẹ́” — yíyí `enabled` padà nípasẹ̀ column àtijọ́ tún máa ń gbé `mode` sókè kí àwọn codepath àtijọ́ lè wà ní ìbámu (`src/app/api/skills/[id]/route.ts`).

### Ipò (àwọn ìṣiṣẹ́)

A máa ń tọpa àwọn ìṣiṣẹ́ skill nínú table `skill_executions` pẹ̀lú àwọn ipò wọ̀nyí (`src/lib/skills/types.ts`):

```ts
enum SkillStatus {
  PENDING = "pending",
  RUNNING = "running",
  SUCCESS = "success",
  ERROR = "error",
  TIMEOUT = "timeout",
}
```

### Cache Registry

`SkillRegistry` jẹ́ singleton tó ní cache TTL ìṣẹ́jú-àáyá 60 (`registry.ts:14`). `loadFromDatabase()` jẹ́ idempotent, ó sì máa ń yọ àwọn ìpè tó ń lọ lẹ́ẹ̀kan náà tí wọ́n jọra kúrò nípasẹ̀ `pendingLoad`. Gbogbo ìkọ̀wé (`register`/`unregister`/`unregisterById`) máa ń sọ cache di asán. Ṣàwárí àwọn version nípasẹ̀ `getSkillVersions(name)` àti `resolveVersion(name, constraint)`.

### Fífi Sínú Ìbéèrè Tó Mọ Olùpèsè

`injectSkills()` nínú `src/lib/skills/injection.ts` ni ibi ìwọlé tó ń yí àwọn skill tí a forúkọsílẹ̀ padà sí àwọn ìtumọ̀ irinṣẹ́ tó bá olùpèsè kọ̀ọ̀kan mu:

- **OpenAI** — `{ type: "function", function: { name, description, parameters } }`
- **Anthropic** — `{ name, description, input_schema }`
- **Google (Gemini)** — `{ name, description, parameters }`

Orúkọ irinṣẹ́ náà jẹ́ ìṣàmúlò bí `name@version` kí olùdarí náà lè yan ẹ̀dà tó tọ́ nígbà tí módẹ́lì bá pè é padà.

### Ìṣírò AUTO

Nígbà tí `mode="auto"`, a máa ṣe ìṣírò olùdíje ọgbọ́n kọ̀ọ̀kan ní ìbámu pẹ̀lú àyíká ìbéèrè náà (`scoreAutoSkill()` nínú `injection.ts`):

| Àmì                                                | Ojúàmì        |
| -------------------------------------------------- | ------------- |
| Orúkọ ọgbọ́n hàn gẹ́gẹ́ bí ó ṣe rí nínú àyíká         | +6            |
| Tókìnì orúkọ kọ̀ọ̀kan bá tókìnì àyíká mu             | +2            |
| Apá ọ̀rọ̀ àmì kọ̀ọ̀kan bá àyíká mu                     | +3            |
| Tókìnì àpèjúwe kọ̀ọ̀kan bá àyíká mu                  | +1            |
| Ìdí abẹ́lẹ̀ bá tókìnì orúkọ mu                       | +2 fún tókìnì |
| Ìdí abẹ́lẹ̀ bá àmì mu                                | +2 fún tókìnì |
| Ìtọ́kasí olùpèsè nínú àwọn àmì bá olùpèsè ìbéèrè mu | +2 / −2       |

Àwọn ọgbọ́n `AUTO_MAX_SKILLS = 5` tó ga jù lọ, tí `score >= AUTO_MIN_SCORE = 3`, ni a ó fi sínú rẹ̀. A máa yanjú ìdọ́gba nípa `installCount` (láti èyí tó ga sí èyí tó kéré), lẹ́yìn náà nípa orúkọ ní títẹ̀lé álífábẹ́ẹ̀tì (`injection.ts:225-235`).

### Dídá Ìpè Irinṣẹ́ Dúró Láàárín

Olùdarí ìfọ̀rọ̀wérọ̀ máa ń pe `handleToolCallExecution()` nínú `src/lib/skills/interception.ts` lẹ́yìn tí olùpèsè òkè bá dá èsì ìpè-irinṣẹ́ padà:

1. `extractToolCalls()` máa ń ka àwọn ìrísí pàtó sí olùpèsè (OpenAI `tool_calls` / Responses `function_call`, Anthropic `tool_use`, Gemini `functionCalls`).
2. A kọ́kọ́ yanjú àwọn orúkọ àfikún irinṣẹ́ tí a kọ́ sínú rẹ̀ (fún àpẹẹrẹ, `omniroute_web_search` → `web_search`). Àwọn olùdarí tí a kọ́ sínú rẹ̀ máa ń ṣiṣẹ́ níbẹ̀ lẹ́sẹ̀kẹsẹ̀.
3. Ohun mìíràn yòówù máa ń gba ọ̀nà `skillExecutor.execute(name@version, args, { apiKeyId, sessionId })`.
4. A máa fi àwọn àbájáde padà sínú èsì náà — àwọn ohun `tool_results`, `function_call_output`, tàbí àwọn búlọ́ọ̀kù Anthropic `tool_result` bí ó ṣe yẹ.

A lè ṣètò `customSkillExecutionEnabled` nínú àyíká ìṣiṣẹ́ sí `false` láti gba dídá ìpè àwọn irinṣẹ́ tí a kọ́ sínú rẹ̀ dúró láàárín nìkan láàyè (èyí ni àwọn ọ̀nà ìbéèrè tí ó pa àwọn olùdarí tí olumulo ṣàlàyé mọ́ ní pàtó máa ń lò).

## Àyíká Ààbò Docker

Àwọn ipa-ọ̀nà kóòdù tí kì í ṣe èyí tí a kọ́ sínú rẹ̀ (`eval_code`, `execute_command`) ń ṣiṣẹ́ nínú Docker nípasẹ̀ `SandboxRunner` (`src/lib/skills/sandbox.ts`). Gbogbo container ni a ń ṣe ìfilọ́lẹ̀ rẹ̀ pẹ̀lú:

```
--rm --network none|bridge --cap-drop ALL
--security-opt no-new-privileges --pids-limit 100
--cpus <cpuLimit/1000> --memory <memoryLimit>m
--tmpfs /tmp:rw,noexec,nosuid,size=64m
--tmpfs /workspace:rw,noexec,nosuid,size=64m
--read-only (nígbà tí readOnly=true)
```

Àwọn iye àìyípadà (`SandboxRunner.DEFAULT_CONFIG`):

| Pápá             | Iye àìyípadà    | Àwọn àkíyèsí                                            |
| ---------------- | --------------- | ------------------------------------------------------- |
| `cpuLimit`       | 100 (= 0.1 CPU) | A pín in ní 1000 kí a tó fi ránṣẹ́ sí `--cpus`           |
| `memoryLimit`    | 256 MB          | Òpin líle                                               |
| `timeout`        | 30000 ms        | Dídá dúró pẹ̀lẹ́pẹ̀lẹ́ nípasẹ̀ `SIGTERM` + `docker kill`     |
| `networkEnabled` | `false`         | Ó di `--network none`                                   |
| `readOnly`       | `true`          | Root FS jẹ́ kíkà-nìkan; `/tmp` àti `/workspace` jẹ́ tmpfs |

`SandboxRunner.kill(id)` àti `killAll()` wà fún títì pa; a ń tọpa àwọn container tó ń ṣiṣẹ́ nínú `runningContainers: Map<string, ChildProcess>`.

### Àwọn Oníyípadà Àyíká Ààbò

A ṣètò wọn nípasẹ̀ `process.env` nínú `src/lib/skills/builtins.ts`:

| Oníyípadà Àyíká                   | Iye àìyípadà     | Ète                                                                                      |
| --------------------------------- | ---------------- | ---------------------------------------------------------------------------------------- |
| `SKILLS_MAX_FILE_BYTES`           | `1048576` (1 MB) | Òpin fún `file_read` àti `file_write`                                                    |
| `SKILLS_MAX_HTTP_RESPONSE_BYTES`  | `256000`         | Òpin fún ara ìdáhùn `http_request`                                                       |
| `SKILLS_MAX_SANDBOX_OUTPUT_CHARS` | `100000`         | Òpin fún stdout/stderr tí a dá padà sí olùpè                                             |
| `SKILLS_SANDBOX_TIMEOUT_MS`       | `10000`          | Àkókò àìyípadà fún àwọn àṣẹ inú àyíká ààbò; ó ní òpin 60 s                               |
| `SKILLS_SANDBOX_NETWORK_ENABLED`  | `false`          | Ìdènà àkọ́kọ́ fún ìjáde. Ṣètò sí `1` tàbí `true` láti gba ìforúkọsílẹ̀-fún-ìpè-kọ̀ọ̀kan láàyè |
| `SKILLS_ALLOWED_SANDBOX_IMAGES`   | (wo ìsàlẹ̀)       | Àtòjọ àwọn image Docker tí a yọ̀ǹda, tí kọ́mà yà sọ́tọ̀                                      |

Àwọn image tí a yọ̀ǹda ní àìyípadà: `alpine:3.20`, `node:22-alpine`, `python:3.12-alpine`. Gbogbo àfikún nípasẹ̀ `SKILLS_ALLOWED_SANDBOX_IMAGES` ni a dàpọ̀ mọ́ àwọn iye àìyípadà; `normalizeImage()` kọ àwọn image tí a kò mọ̀.

> Àkíyèsí: kò sí oníyípadà àyíká `SKILLS_EXECUTION_TIMEOUT_MS` ọ̀tọ̀. Àkókò ìparí fún olùtọ́jú tí kò sí nínú àyíká ààbò jẹ́ 30 s tí a kọ tààrà sínú `SkillExecutor` (`executor.ts:13`), ṣùgbọ́n a lè yí i padà ní àkókò ìṣiṣẹ́ nípasẹ̀ `skillExecutor.setTimeout(ms)`.

### Ìyàsọ́tọ̀ Àyè Iṣẹ́

`file_read` àti `file_write` ń túmọ̀ gbogbo ipa-ọ̀nà ní ìbámu pẹ̀lú àyè iṣẹ́ kan fún kọ́kọ́rọ́ API kọ̀ọ̀kan ní `<DATA_DIR>/skills/workspaces/<sha256(apiKeyId).slice(0,24)>/`. A kọ ìrìn-ipa-ọ̀nà (`..`) àti àwọn apá tí a fòfin dè (`.env`, `.git`, `.ssh`, `.omniroute`, `.codex`, `secrets`) kí iṣẹ́ I/O disiki èyíkéyìí tó bẹ̀rẹ̀.

### Fífún HTTP ní Ààbò Síi

`http_request` (`builtins.ts:257`):

- Àtòjọ àwọn method tí a yọ̀ǹda: `GET, HEAD, POST, PUT, PATCH, DELETE`
- Àwọn header ìjáde tí a dí: `host, connection, content-length, cookie, set-cookie, authorization, proxy-authorization`
- A pa àtúndarí (`allowRedirect: false`)
- A darí rẹ̀ gba `safeOutboundFetch` pẹ̀lú `guard: "public-only"` (a dí àwọn ìwọ̀n private/loopback)
- A gé ìdáhùn kúrú ní `SKILLS_MAX_HTTP_RESPONSE_BYTES`; client rí `truncated: true`

### Àpẹẹrẹ: fi skill àdáni sori

```bash
curl -X POST http://localhost:20128/api/skills/install \
  -H "Authorization: Bearer $OMNIROUTE_MGMT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "reverse-text",
    "version": "1.0.0",
    "description": "Reverses a string",
    "schema": {
      "input":  { "type": "object", "properties": { "text": { "type": "string" } }, "required": ["text"] },
      "output": { "type": "object", "properties": { "reversed": { "type": "string" } } }
    },
    "handlerCode": "echo-handler",
    "apiKeyId": "your-api-key-id"
  }'
```

Okùn `handlerCode` jẹ́ **ìwádìí orúkọ handler** — kì í ṣe kóòdù tí a lè ṣiṣẹ́. Olùṣiṣẹ́ náà ń ṣe ìbámu rẹ̀ nípasẹ̀ `skillExecutor.registerHandler(name, fn)` (`executor.ts:25`). Àwọn ìfisórí láti ọjà ń tọ́jú ọ̀rọ̀ SKILL.md sínú ààyè yìí gẹ́gẹ́ bí ìwé àlàyé, wọ́n sì ń darí ìṣiṣẹ́ nípasẹ̀ àwọn ìpè irinṣẹ́ tí módẹ́lì ṣẹ̀dá. A kì í lo eval lórí source tí olùlò pèsè láìsí ààlà.

## Àwọn Ìmọ̀ràn Ìṣiṣẹ́

- **Yíyọ̀ àkọ́kọ́:** `settings.skillsEnabled = false` ń dí gbogbo ìṣiṣẹ́, ó sì ń dá HTTP `503` padà lórí `/api/skills/executions`. Ilé ìforúkọsílẹ̀ náà ṣì ń bá a lọ láti ṣàkójọpọ̀.

- **Ìfagilé kášì:** pe `skillRegistry.invalidateCache()` lẹ́yìn àwọn àtúnṣe DB tí a ṣe lọ́wọ́; bí bẹ́ẹ̀ kọ́, dúró fún 60 s.
- **Àyè-iṣẹ́ aláìlórúkọ:** nígbà tí `apiKeyId` bá ṣófo, gbogbo ìpè yóò jẹ́ háṣì sí àyè-iṣẹ́ `"anonymous"` kan náà — kóòdù tó mọ nípa pínpín gbọ́dọ̀ máa fi kọ́kọ́rọ́ gidi ránṣẹ́ ní gbogbo ìgbà.

## Ìgbésí-ayé Ìmúṣẹ (v3.8.16+)

`SkillExecutor` (`src/lib/skills/executor.ts`) jẹ́ **singleton** tí ń ṣàkóso gbogbo ìpè ọgbọ́n. Òye ìgbésí-ayé rẹ̀ ṣe pàtàkì fún ṣíṣe àwárí àti àtúnṣe àwọn ìṣòro àsìkò-parí, àtúndánwò, àti ipò ìmúṣẹ.

### Ìgbésí-ayé Onípele 5

```
   execute() ni a pè
        │
        ▼
  ┌─────────────┐
  │  PENDING    │  ← ó wà ní ìlà, kò tíì bẹ̀rẹ̀ (a ṣẹ̀dá ìlà DB)
  └──────┬──────┘
         │ bẹ̀rẹ̀ handler
         ▼
  ┌─────────────┐
  │  RUNNING    │  ← a pe handler pẹ̀lú ààlà àsìkò
  └──────┬──────┘
         │
    ┌────┴────┬──────────┬──────────┐
    │         │          │          │
    ▼         ▼          ▼          ▼
  SUCCESS   ERROR     TIMEOUT   (kò sí ipa-ọ̀nà mìíràn — parent ló dá a dúró)
    │         │          │
    └────┬────┴──────────┘
         │
         ▼
   A ṣe ìmúdójúìwọ̀n ìlà DB pẹ̀lú ipò, àbájáde, durationMs
```

### Ìṣètò Àìyípadà

| Ètò          | Àìyípadà      | A lè ṣètò rẹ̀ nípasẹ̀                  |
| ------------ | ------------- | ------------------------------------ |
| `timeout`    | `30000` (30s) | `skillExecutor.setTimeout(ms)`       |
| `maxRetries` | `3`           | `skillExecutor.setMaxRetries(count)` |

> **Pàtàkì**: Executor jẹ́ singleton — pípè `setTimeout()` kan gbogbo àwọn ìpè tó bá tẹ̀lé jákèjádò. Àwọn ààlà àsìkò fún ọgbọ́n kọ̀ọ̀kan kò ní àtìlẹ́yìn lọ́wọ́lọ́wọ́; tí o bá nílò ààlà àsìkò ọ̀tọ̀ọ̀tọ̀ fún ọgbọ́n kọ̀ọ̀kan, fi àwọn process ọ̀tọ̀ọ̀tọ̀ ránṣẹ́ tàbí fork executor náà.

### Àwọn Iye Ipò

Láti `src/lib/skills/types.ts`:

```ts
enum SkillStatus {
  PENDING = "pending", // Ó wà ní ìlà, kò tíì bẹ̀rẹ̀
  RUNNING = "running", // A pe handler
  SUCCESS = "success", // Handler dá àbájáde tó bófin mu padà
  ERROR = "error", // Handler ju exception kan jáde
  TIMEOUT = "timeout", // Ó kọjá ààlà àsìkò executor
}
```

> **Àkíyèsí**: Ipò `TIMEOUT` wà nínú enum ṣùgbọ́n ìmúṣẹ executor lọ́wọ́lọ́wọ́ **kò kọ ọ́ sínú DB ní tòótọ́** — àwọn àsìkò-parí máa ń hàn bí `ERROR` pẹ̀lú ìfiránṣẹ́ `"Skill execution timed out"`. A fi enum ipò náà pamọ́ fún lílò lọ́jọ́ iwájú.

### Ṣíṣe Àyẹ̀wò Àwọn Ìmúṣẹ

```ts
import { skillExecutor } from "omniroute/skills/executor";

// Gba ìmúṣẹ kan pàtó nípasẹ̀ ID
const exec = skillExecutor.getExecution("exec-uuid-123");
if (exec) {
  console.log(`${exec.skillName}: ${exec.status} in ${exec.durationMs}ms`);
}

// Ṣe àkójọ àwọn ìmúṣẹ àìpẹ́ fún kọ́kọ́rọ́ API kan
const recent = skillExecutor.listExecutions("api-key-id", 50, 0);
for (const e of recent) {
  console.log(`${e.skillName} → ${e.status} (${e.durationMs}ms)`);
}

// Ka àpapọ̀ àwọn ìmúṣẹ
const total = skillExecutor.countExecutions("api-key-id");
```

### Ìhùwàsí Àtúndánwò

Ètò `maxRetries` wà ní ìpamọ́ ṣùgbọ́n ọ̀nà `execute()` ti executor **kò lò ó lọ́wọ́lọ́wọ́** — ó ṣe ìgbìyànjú ẹyọ kan ṣoṣo. Iye `maxRetries` wà ní gbangba fún ìmúṣẹ ọjọ́ iwájú àti fún àwọn hooks tí wọ́n fẹ́ kà á.

Ní báyìí, a gbọ́dọ̀ ṣe ìmúṣẹ àwọn àtúndánwò nínú handler ọgbọ́n fúnra rẹ̀. Àwọn ọgbọ́n tí a kọ́ sínú ètò
ni a forúkọsílẹ̀ pẹ̀lú executor (fún àpẹẹrẹ `registerBuiltinSkills(executor)`
/ `registerBrowserSkill(executor)` nínú `src/lib/skills/builtin/`); èyíkéyìí handler
tí o bá forúkọsílẹ̀ lè fi loop àtúndánwò tirẹ̀ yí ara rẹ̀ ká:

```ts
// nínú handler ọgbọ́n kan
async function handler(input, ctx) {
  const maxRetries = 3;
  let lastError: Error | null = null;

  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      return await fetchSomething(input);
    } catch (err) {
      lastError = err as Error;
      if (attempt < maxRetries) {
        await new Promise((r) => setTimeout(r, 1000 * attempt));
      }
    }
  }
  throw lastError;
}
```

## Àlàyé Kíkún nípa SkillMode

Enum `SkillMode` (`src/lib/skills/types.ts`) ń ṣàkóso **ìgbà àti ọ̀nà** tí a fi ń pe àwọn ọgbọ́n:

```ts
enum SkillMode {
  AUTO = "auto", // LLM ló ń pinnu ìgbà tí yóò pe ọgbọ́n náà
  MANUAL = "manual", // Ìbéèrè pàtó láti ọ̀dọ̀ aṣàmúlò nìkan ló lè pè é
  HYBRID = "hybrid", // Ìṣírò AUTO + àtúnṣe afọwọ́ṣe
}
```

> **Àkíyèsí**: Ìpìlẹ̀ kóòdù náà ṣàlàyé `SkillMode` (AUTO/MANUAL/HYBRID), nígbà tí ààyè `Skill.mode` ń lo ìrísí mìíràn (`"on" | "off" | "auto"`). Wọ́n ní ìbátan ṣùgbọ́n wọn kì í ṣe ohun kan náà — `SkillMode` jẹ́ fún ìlànà olùṣe, `Skill.mode` sì jẹ́ fún mímú ọgbọ́n kọ̀ọ̀kan ṣiṣẹ́ tàbí pípa á.

### Ìgbà Tí Ó Yẹ Kí A Lo Mode Kọ̀ọ̀kan

| Mode     | Ìhùwàsí LLM                                                          | Ìlò                                                              |
| -------- | -------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `AUTO`   | LLM lè pe ọgbọ́n náà nígbà tí ó bá rí i pé ó ṣe pàtàkì                | Àwọn ọgbọ́n fún ìlò gbogbogbò (kíka fáìlì, àwọn ìbéèrè HTTP)      |
| `MANUAL` | LLM kò lè pe ọgbọ́n náà; ìpè API `executeSkill` pàtó nìkan ló lè pè é | Àwọn iṣẹ́ tó nílò àbójútó (kíkọ sínú ibi ìpamọ́ dátà, àwọn ìsanwó) |
| `HYBRID` | LLM lè dábàá ọgbọ́n náà; aṣàmúlò gbọ́dọ̀ fọwọ́ sí i                      | Àwọn ọgbọ́n tó ní ipa ẹ̀gbẹ́ ṣùgbọ́n tí kò léwu                      |

### Ìṣírò AUTO

Nígbà tí mode `AUTO` bá ń ṣiṣẹ́, a máa ń ṣírò iye ọgbọ́n kọ̀ọ̀kan tó ṣeé yàn gẹ́gẹ́ bí ó ṣe bá àyíká ìbéèrè náà mu
pẹ̀lú `scoreAutoSkill()` nínú `src/lib/skills/injection.ts` — ètò àwọn point odidi
tí a ń fi kún ara wọn (ìbámu orúkọ ọgbọ́n, ìbádọ́gba token orúkọ/tag/àpèjúwe,
àwọn àmì ìtọ́kasí ìdí abẹ́lẹ̀, ẹ̀bùn/ìyọkúrò fún àmì ìtọ́kasí provider). Àwọn ọgbọ́n
`AUTO_MAX_SKILLS = 5` tó ga jù lọ tí wọ́n ní `score >= AUTO_MIN_SCORE = 3` ni a máa ń fi sí i gẹ́gẹ́ bí
àwọn irinṣẹ́ tí a lè pè; tí iye bá dọ́gba, `installCount` ni a kọ́kọ́ lò láti yanjú rẹ̀, lẹ́yìn náà orúkọ. Wo tábìlì point kíkún
nínú [**Ṣíṣẹ̀dá Schema Irinṣẹ́ → Ìṣírò AUTO**](#auto-scoring) ní apá ìṣáájú ìwé
yìí; kò sí ààlà float irú `0.6`, bẹ́ẹ̀ ni kò sí ìṣírò `registry.ts`.

## Àkójọ Àwọn Ọgbọ́n Tí a Kọ́ Sínú Rẹ̀

OmniRoute ní àkójọpọ̀ àwọn ọgbọ́n tí a ti fara balẹ̀ yàn, tí a kọ́ sínú `src/lib/skills/builtin/`. Àwọn tí a sábà máa ń lò jù lọ ni:

### Ọgbọ́n Ṣíṣe Browser Láìfọwọ́ṣe

Ọgbọ́n browser (`src/lib/skills/builtin/browser.ts`) ń pèsè ṣíṣe browser aláìní ojú-iṣẹ́ láìfọwọ́ṣe nípasẹ̀ Playwright/Puppeteer. **A ti mú un ṣiṣẹ́, ṣùgbọ́n kò sí nínú àkójọ àwọn ọgbọ́n àtìlẹ́yìn** — láti lò ó, fi plugin amúgbòòrò browser náà sí ẹ̀rọ lọ́tọ̀.

```ts
// Mú un ṣiṣẹ́ nínú àtòpọ̀ rẹ
const config: SkillConfig = {
  enabled: true,
  mode: SkillMode.MANUAL, // Ní gbogbo ìgbà, béèrè fún ìpè pàtó
  allowedSkills: ["browser"],
  timeout: 60000, // 60s fún kíkó àwọn ojúewé wọlé
  maxRetries: 1,
};
```

### Àwọn Ẹ̀ka Mìíràn Tí a Kọ́ Sínú Rẹ̀

| Ẹ̀ka           | Àwọn ọgbọ́n                                         | Mode   |
| ------------- | -------------------------------------------------- | ------ |
| Ìṣàkóso Fáìlì | `file_read`, `file_write`                          | AUTO   |
| HTTP          | `http_request`                                     | AUTO   |
| Ìṣàwárí       | `web_search`                                       | AUTO   |
| Ṣíṣe Kóòdù    | `eval_code` (JavaScript/Python tó wà nínú sandbox) | HYBRID |
| Sístẹ́mù       | `execute_command` (ṣíṣe CLI nínú sandbox)          | MANUAL |

### Fífi Ọgbọ́n Àdáni Kún Un

Wo [SDK Plugin & Ìṣọ̀kan Àwọn Ọgbọ́n](./PLUGIN_SDK.md) fún ọ̀nà láti fi ọgbọ́n àdáni kún un nípasẹ̀ ètò plugin.
