> **Orísun òtítọ́:** `src/lib/notion/api.ts` (oníbàárà REST), `src/lib/db/notion.ts`
> (ìtọ́jú token), `open-sse/mcp-server/tools/notionTools.ts` (irinṣẹ́ MCP mẹ́fà),
> `src/app/api/settings/notion/route.ts` (API ètò). Ìforúkọsílẹ̀ irinṣẹ́ àti ìsopọ̀ scope
> wà nínú `open-sse/mcp-server/server.ts`.

## Ohun tí ó jẹ́

OmniRoute lè sopọ̀ mọ́ workspace **Notion** gẹ́gẹ́ bí **orísun àyíká-ọ̀rọ̀** — ibi ìpamọ́
ìmọ̀ tí a lè kà sí àti kọ sí, tí àwọn agent ń ráyè sí nípasẹ̀ olupin MCP tí a kọ sínú rẹ̀.
Ní kété tí a bá ṣètò token integration Notion, àwọn irinṣẹ́ MCP yóò jẹ́ kí LLM lè ṣàwárí
àwọn page àti database, ka àkóónú page àti àwọn igi block, ṣe query sí àwọn database
pẹ̀lú filter/sort, kí ó sì fi àwọn block tuntun kún un — gbogbo rẹ̀ ni a ń ṣe nípasẹ̀
OmniRoute (pẹ̀lú ìgbìyànjú padà, timeout, àti ìsọ̀rí error), kí model má bàa ní ìfarakanra
taara pẹ̀lú API Notion.

Integration náà jẹ́ wrapper kékeré tí a ti mú lágbára lórí API REST Notion ọ̀fíṣialì
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`). Oníbàárà náà
(`src/lib/notion/api.ts`) ṣàfikún:

- **Ìgbìyànjú padà pẹ̀lú exponential backoff** (títí dé ìgbìyànjú mẹ́ta) fún `429` àti `5xx`.
- **Timeout ìbéèrè ìṣẹ́jú-àáyá 55** nípasẹ̀ `AbortController`.
- **Ìsọ̀rí error oníru** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, ó tẹ̀lé àwọn ìtọ́kasí `retry after`),
  `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- **Ìmọ́tótó ìfiránṣẹ́** tí ń yọ àwọn àjákù tó dà bí stack trace kúrò kí wọ́n tó hàn síta.

## Ìṣètò

Kò sí **environment variable** fún token Notion — a ń tọ́jú rẹ̀ sínú table SQLite
`key_value` (namespace `notion`, key `integration_token`) nípasẹ̀
`src/lib/db/notion.ts`. Ṣètò rẹ̀ láti inú tab **Context Sources** ti dashboard Endpoint
(ẹ̀gbọ́n `ObsidianSourceCard` tí í ṣe `NotionSourceCard`), tàbí nípasẹ̀ API REST ètò.

> [!NOTE]
> Token náà jẹ́ **token integration inú Notion**. Ṣẹ̀dá integration ní
> <https://www.notion.com/my-integrations>, lẹ́yìn náà pín àwọn page/database tí o fẹ́
> kí OmniRoute ráyè sí pẹ̀lú integration náà (àwòṣe ìyọ̀ǹda Notion dá lórí pípín,
> kì í ṣe gbogbo workspace).

### Ṣètò nípasẹ̀ REST

```bash
# Fi token integration pamọ́ + fìdí rẹ̀ múlẹ̀ (POST ń fìdí rẹ̀ múlẹ̀ nípa ṣíṣe ìṣàwárí ìdánwò)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# Ṣàyẹ̀wò ipò ìsopọ̀
curl http://localhost:20128/api/settings/notion

# Já ìsopọ̀ (yóò pa token tí a fi pamọ́ rẹ́)
curl -X DELETE http://localhost:20128/api/settings/notion
```

Gbogbo method mẹ́tẹ̀ẹ̀ta nílò ìfàṣẹsí dashboard (`isAuthenticated`). Lórí `POST`,
OmniRoute yóò fi token náà pamọ́, yóò sì ṣe ìṣàwárí ìdánwò ol èsì kan lẹ́sẹ̀kẹsẹ̀; bí Notion
bá dá object error padà, a ó pa token náà rẹ́, call náà yóò sì kùnà pẹ̀lú `400`.

## Àwọn irinṣẹ́ MCP (6)

A ṣàlàyé wọn nínú `open-sse/mcp-server/tools/notionTools.ts`. A máa ń yanjú token náà
ní àkókò call nípasẹ̀ `getNotionToken()`; bí a kò bá ṣètò ọ̀kan, irinṣẹ́ náà yóò ju
`"A kò tíì ṣètò token integration Notion. Ṣètò rẹ̀ ní Settings > Context Sources."`

| Irinṣẹ́                       | Scope          | Àpèjúwe                                                                                     |
| ---------------------------- | -------------- | ------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | Ṣàwárí àwọn page àti database pẹ̀lú query ọ̀rọ̀ (ó dá title, ID, URL padà). Ó ní pagination.   |
| `notion_get_page`            | `read:notion`  | Gba àkóónú àti metadata page kan nípasẹ̀ ID rẹ̀.                                              |
| `notion_list_block_children` | `read:notion`  | Ṣe àtòjọ gbogbo block ọmọ ti block tàbí page kan (igi block náà). Ó ní pagination.          |
| `notion_query_database`      | `read:notion`  | Ṣe query sí database pẹ̀lú `filter` + `sorts` àṣàyàn (ọ̀nà-kíkó API Notion). Ó ní pagination. |
| `notion_get_database`        | `read:notion`  | Gba schema/metadata database kan nípasẹ̀ ID.                                                 |
| `notion_append_blocks`       | `write:notion` | Fi àwọn block ọmọ kún block tàbí page tó wà tẹ́lẹ̀ (block 100 ó pọ̀jù fún ìbéèrè kọ̀ọ̀kan).      |

### Àwọn parameter input

- `notion_search` — `query` (lẹ́tà 1–500), `pageSize` (1–100, àkọ́kọ́ 20),
  `startCursor` (àṣàyàn).
- `notion_get_page` — `pageId` (hex onílẹ́tà 32 tàbí UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, àkọ́kọ́ 50),
  `startCursor` (àṣàyàn).
- `notion_query_database` — `databaseId`, `filter` (àṣàyàn, ọ̀nà-kíkó filter Notion),
  `sorts` (array àṣàyàn), `pageSize` (1–100, àkọ́kọ́ 50), `startCursor` (àṣàyàn).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (array àwọn object block),
  `after` (ipò àṣàyàn).

### Àwọn scope

Àwọn irinṣẹ́ kíkà nílò `read:notion`, irinṣẹ́ kíkọ sì nílò `write:notion`.
`withScopeEnforcement()` inú `open-sse/mcp-server/server.ts` ni ó ń fipá mú àwọn scope
nígbà tí `OMNIROUTE_MCP_ENFORCE_SCOPES=true` nìkan; àwọn scope tí a fàyè gba fún caller
wá láti `OMNIROUTE_MCP_SCOPES` (tí comma yà sọ́tọ̀) tàbí àyíká scope ti API key tí a
ti fìdí ìdánimọ̀ rẹ̀ múlẹ̀. Wo [MCP-SERVER.md](./MCP-SERVER.md) fún àwòṣe scope
ní ẹ̀kúnrẹ́rẹ́.

## Àwọn Endpoint

| Ọ̀nà      | Path                   | Ète                                  |
| -------- | ---------------------- | ------------------------------------ |
| `GET`    | `/api/settings/notion` | Dá `{ connected, hasToken }` padà.   |
| `POST`   | `/api/settings/notion` | Fi token ìṣọ̀kan pamọ́ + ṣàyẹ̀wò rẹ̀.    |
| `DELETE` | `/api/settings/notion` | Já ìsopọ̀ (pa token tí a fi pamọ́ rẹ́). |

> Àwọn wọ̀nyí jẹ́ àwọn route ètò dashboard. **Kò sí endpoint aṣojú Notion `/v1`
> fún gbogbo ènìyàn** — àwọn irinṣẹ́ MCP lókè nìkan ni a fi ń ráyè sí Notion.

## Àwọn ibi ìlò

- **Àwọn ìdáhùn tó dá lórí ìmọ̀** — jẹ́ kí agent kan lo `notion_search` láti wá inú workspace náà, kí ó sì
  lo `notion_get_page` fún àbájáde tó ga jù lọ kí ó tó dáhùn, kí àwọn ìdáhùn lè tọ́ka sí àwọn àkọsílẹ̀ inú ilé gidi.
- **Àwọn ìlànà iṣẹ́ tó dá lórí database** — lo `notion_query_database` lórí database àwọn iṣẹ́/CRM pẹ̀lú
  àwọn filter + sort, lẹ́yìn náà ṣe àkópọ̀ tàbí pín àwọn row náà sí ẹ̀ka gẹ́gẹ́ bí ìjẹ́pàtàkì.
- **Kíkọ padà / fífi log pamọ́** — lo `notion_append_blocks` láti fi àwọn àkọsílẹ̀ ìpàdé, àkópọ̀
  run, tàbí àbájáde agent kún page tó ti wà tẹ́lẹ̀ (àfikún nìkan; kò sí àtúnṣe apanirun).
- **Ṣíṣàwárí ìṣètò** — lo `notion_list_block_children` láti tọpasẹ̀ igi block page kan,
  tàbí `notion_get_database` láti ṣàwárí schema property database kan kí o tó béèrè ìwífún lọ́wọ́ rẹ̀.
