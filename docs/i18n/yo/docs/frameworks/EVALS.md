> **Orísun òtítọ́:** `src/lib/evals/`, `src/lib/db/evals.ts`, `src/app/api/evals/`
> **Ìgbà ìmúdójúìwọ̀n tó kẹ́yìn:** 2026-06-28 — v3.8.40

OmniRoute ní ètò àgbékalẹ̀ àyẹ̀wò gbogbogbò kan tí o lè lò láti fi díwọ̀n àwọn
àtòpọ̀ ìdarí-ọ̀nà, àwọn olùpèsè/àwòṣe kọ̀ọ̀kan, tàbí àwọn àkójọpọ̀ "golden set"
tí a kó sínú rẹ̀. Lò ó láti ṣàrídájú àwọn ìyípadà ìdarí-ọ̀nà, fọwọ́sí àwọn
olùpèsè tuntun, àti láti ṣàyẹ̀wò àwọn ìtújáde kí o tó gbé wọn lọ sí ìrìnnà
iṣẹ́-gidi.

A ṣe àgbékalẹ̀ ètò náà gẹ́gẹ́ bí:

- Ẹ̀rọ ìṣiṣẹ́ mímọ́ (`src/lib/evals/evalRunner.ts`) tó ń forúkọsílẹ̀ àwọn
  àkójọpọ̀ inú-ètò sínú ìrántí, tó ń ṣàyẹ̀wò àwọn àbájáde ní ìbámu pẹ̀lú àwọn
  àbáwọlé tí a retí, tí ó sì ń ṣàkójọpọ̀ àwọn káàdì ìwọ̀n.
- Ìpele ìtọ́jú pípẹ́ (`src/lib/db/evals.ts`) fún àwọn àkójọpọ̀ àdáni
  (tí olumulo ṣàlàyé) àti àwọn ìṣiṣẹ́ àtijọ́ nínú SQLite.
- Ìpele ìṣètò-àkóso (`src/lib/evals/runtime.ts`) tó ń ṣiṣẹ́ ọ̀ràn kọ̀ọ̀kan nípa
  fífi àwọn ìpè gidi ránṣẹ́ sí `POST /v1/chat/completions`, tó ń gba àkókò
  ìdádúró àti àwọn àbájáde sílẹ̀, tí ó sì ń tọ́jú ìṣiṣẹ́ náà.
- Àwọn ojú-ọ̀nà REST lábẹ́ `/api/evals/*` (ìfàṣẹsí ìṣàkóso nìkan).
- Ojú ìdarí ní `Dashboard → Usage → Evals` (`EvalsTab.tsx`).

## Àwọn Èròjà

### Àkójọpọ̀

Àkójọpọ̀ jẹ́ ìkójọpọ̀ àwọn ọ̀ràn ìdánwò tó ní orúkọ, pẹ̀lú `description` àti
ọ̀ràn kan tàbí jù bẹ́ẹ̀ lọ. Àwọn àkójọpọ̀ wá láti orísun méjì:

| Orísun     | Ibi tí a ti ṣàlàyé rẹ̀                           | Ṣé a lè yí i padà nígbà ìṣiṣẹ́? |
| ---------- | ----------------------------------------------- | ------------------------------ |
| `built-in` | Forúkọsílẹ̀ nípasẹ̀ `registerSuite()` nígbà ìbẹ̀rẹ̀ | Rárá (kóòdù ló ṣàlàyé rẹ̀)      |
| `custom`   | Tọ́jú sínú SQLite `eval_suites` + `eval_cases`   | Bẹ́ẹ̀ ni (nípasẹ̀ API/UI)         |

Àwọn àkójọpọ̀ inú-ètò tó wà lọ́wọ́lọ́wọ́ (wo `src/lib/evals/evalRunner.ts`):

- `golden-set` — ọ̀ràn ìpìlẹ̀ mẹ́wàá kọjá ìkíni/ìṣirò/ìtumọ̀/ààbò
- `coding-proficiency` — Python/JS/SQL/TS/ìmúdámọ̀ àṣìṣe
- `reasoning-logic` — àwọn ọ̀rọ̀-àròsọ ọgbọ́n, àwọn ìṣòro ọ̀rọ̀, ìdámọ̀ àpẹẹrẹ
- `multilingual` — ìtumọ̀ àti ìdámọ̀ èdè
- `safety-guardrails` — PII, jailbreak, kíkọ̀, ìmọ̀ nípa ojúsàájú
- `instruction-following` — JSON nìkan, àwọn àtòjọ onínọ́mbà, àwọn ìhámọ́ èdè
- `codex-comparison` — àwọn iṣẹ́ kíkó kóòdù ojú-kọ-ojú tí a pète fún ipò àfiwé

### Ọ̀ràn

Ọ̀ràn kọ̀ọ̀kan ní:

| Ààyè       | Àpèjúwe                                                                              |
| ---------- | ------------------------------------------------------------------------------------ |
| `id`       | Àmì ìdánimọ̀ tó dúró ṣinṣin (tí a lò gẹ́gẹ́ bí kọ́kọ́rọ́ fún àwọn àbájáde àti àwọn òṣùwọ̀n) |
| `name`     | Àkọlé tí ènìyàn lè kà                                                                |
| `model`    | Àwòṣe àìyípadà nígbà tí ìṣiṣẹ́ bá lo ìfojúsùn `suite-default`                         |
| `input`    | `{ messages, max_tokens? }` — a fi ránṣẹ́ sí `/v1/chat/completions`                   |
| `expected` | `{ strategy, value }` — ìlànà fífún ní àmì (wo ìsàlẹ̀)                                |
| `tags`     | Àwọn àkọlé àṣàyàn (fún àpẹẹrẹ `safety`, `pii`, `jailbreak`)                          |

### Ìfojúsùn

A lè ṣiṣẹ́ àkójọpọ̀ kan náà sí àwọn ìfojúsùn ọ̀tọ̀ọ̀tọ̀. Àwòrán ìfojúsùn náà ni
`evalTargetSchema` nínú `src/shared/validation/schemas.ts`:

| Irú ìfojúsùn    | `id`        | Ìhùwàsí                                                          |
| --------------- | ----------- | ---------------------------------------------------------------- |
| `suite-default` | `null`      | Ọ̀ràn kọ̀ọ̀kan ń lo ààyè `model` inú-ètò tirẹ̀                       |
| `model`         | orúkọ àwòṣe | Fi ipá mú gbogbo ọ̀ràn kọjá àwòṣe tààrà kan (fún àpẹẹrẹ `gpt-4o`) |
| `combo`         | orúkọ combo | Ṣiṣẹ́ gbogbo ọ̀ràn nípasẹ̀ combo kan (tó ń dán ẹ̀rọ ìdarí-ọ̀nà wò)    |

Fún `model` àti `combo`, ààyè `id` jẹ́ dandan (Zod
`superRefine` ló ń mú èyí ṣẹ). Nígbà tí a bá pèsè `compareTarget`, àwọn ìfojúsùn
méjèèjì gbọ́dọ̀ yàtọ̀ — ẹ̀rọ ìṣiṣẹ́ náà ń tọ́jú àwọn ìṣiṣẹ́ méjèèjì lábẹ́
`runGroupId` kan náà fún àfiwé A/B.

## Àwọn Ìlànà Fún Fífún Ní Àmì

A ṣe é sínú `evaluateCase()` (evalRunner.ts):

| Ọ̀nà        | Yóò kọjá nígbà tí…                                                                 |
| ---------- | ---------------------------------------------------------------------------------- |
| `exact`    | `actualOutput === expected.value`                                                  |
| `contains` | `actualOutput.toLowerCase().includes(expected.value.toLowerCase())`                |
| `regex`    | `new RegExp(expected.value).test(actualOutput)` jẹ́ òótọ́                            |
| `custom`   | `expected.fn(actualOutput, evalCase)` dá iye òótọ́ padà (èyí tí a kọ́ sínú rẹ̀ nìkan) |

**Àkíyèsí:** Fífún ní àmì pẹ̀lú iṣẹ́ àdáni jẹ́ fún àwọn suite tí a ṣàlàyé nínú kóòdù (èyí tí a kọ́ sínú rẹ̀)
nìkan, nítorí a kò lè ṣe àwọn iṣẹ́ ní serialization nípasẹ̀ API. `evalCaseBuilderSchema`
gba `contains | exact | regex` nìkan fún àwọn suite tí àwọn aṣàmúlò ṣẹ̀dá.

Kò sí LLM-bí-adájọ́ tàbí olùfúnni-ní-àmì ìjọra tó dá lórí embedding lónìí — yóò
jẹ́ ibi ìmúgbòòrò tó bójú mu nínú `evaluateCase()`.

## Schema Ibùdó Dátà

Tábìlì mẹ́ta (àwọn migration `030_create_eval_runs.sql` àti
`031_create_eval_suites.sql`):

| Tábìlì        | Ète                                                                                                                        |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `eval_suites` | Metadata suite àdáni (`id`, `name`, `description`)                                                                         |
| `eval_cases`  | Àwọn case fún suite kọ̀ọ̀kan — `input_json`, `expected_*`, `tags_json`                                                       |
| `eval_runs`   | Àwọn run ìtàn — `pass_rate`, `total`, `passed`, `failed`, `avg_latency_ms`, `summary_json`, `results_json`, `outputs_json` |

A **kò** tọ́jú àwọn suite tí a kọ́ sínú rẹ̀ nínú DB. Wọ́n wà nínú memory, a sì tún
forúkọ wọn sílẹ̀ ní gbogbo ìgbà tí a bá import `evalRunner.ts`.

## REST API

Gbogbo endpoint nílò ìfàṣẹ̀sí ìṣàkóso (`requireManagementAuth`) — wọn kì í ṣe
apá kan ojú-ọ̀nà proxy gbogbogbò.

| Endpoint                      | Method   | Àpèjúwe                                                           |
| ----------------------------- | -------- | ----------------------------------------------------------------- |
| `/api/evals`                  | `GET`    | Ṣe àtòjọ àwọn suite + run àìpẹ́ + scorecard + target + key         |
| `/api/evals`                  | `POST`   | Ṣiṣẹ́ suite kan (ẹyọ kan tàbí àfiwé) — schema `evalRunSuiteSchema` |
| `/api/evals/{suiteId}`        | `GET`    | Gba suite kan (èyí tí a kọ́ sínú rẹ̀ tàbí àdáni)                    |
| `/api/evals/suites`           | `POST`   | Ṣẹ̀dá suite àdáni — schema `evalSuiteSaveSchema`                   |
| `/api/evals/suites/{suiteId}` | `GET`    | Gba suite àdáni kan                                               |
| `/api/evals/suites/{suiteId}` | `PUT`    | Rọ́pò suite àdáni kan (a ó tún fi àwọn case sínú rẹ̀)               |
| `/api/evals/suites/{suiteId}` | `DELETE` | Pa suite àdáni kan àti àwọn case rẹ̀ rẹ́                            |

### Ṣíṣiṣẹ́ suite kan

```bash
curl -X POST http://localhost:20128/api/evals \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "suiteId": "golden-set",
    "target": { "type": "combo", "id": "my-combo" },
    "apiKeyId": "optional-api-key-uuid"
  }'
```

Àwọn field àṣàyàn:

- `outputs` — `Record<caseId, string>` ti àwọn output tí a ti ṣírò tẹ́lẹ̀. Nígbà tí a bá pèsè rẹ̀,
  runner náà **yóò fo dispatch** yóò sì fún àwọn output tí a fi pamọ́ sí cache ní àmì nìkan (ó wúlò fún
  àyẹ̀wò offline).
- `compareTarget` — target kejì láti ṣiṣẹ́ ní ìṣọ̀kan; àwọn run méjèèjì yóò pín
  `runGroupId` tí a ṣẹ̀dá fún wíwo wọn ní tààrà sí ara wọn.
- `apiKeyId` — API key abẹ́nú tí a lò láti fi ìdánimọ̀ múlẹ̀ fún àwọn ìpè
  `/v1/chat/completions` tí a dispatch. Ó pọndandan nígbà tí `REQUIRE_API_KEY` bá ṣiṣẹ́.

### Ṣíṣẹ̀dá suite àdáni kan

```bash
curl -X POST http://localhost:20128/api/evals/suites \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Production smoke",
    "description": "Quick sanity check before deploy",
    "cases": [
      {
        "name": "JSON shape",
        "model": "gpt-4o",
        "input": { "messages": [{ "role": "user", "content": "Reply with {\"ok\": true}" }] },
        "expected": { "strategy": "regex", "value": "\"ok\"\\s*:\\s*true" }
      }
    ]
  }'
```

## Ìlànà Ìfiranṣẹ́

`runEvalSuiteAgainstTarget()` (`src/lib/evals/runtime.ts`):

1. Ṣàwárí àkójọpọ̀ ìdánwò náà (èyí tí a kọ sínú rẹ̀ tàbí ti àdáni).
2. Fún ọ̀ràn kọ̀ọ̀kan, ó ṣẹ̀dá `Request` sí `/v1/chat/completions` pẹ̀lú
   `messages` ọ̀ràn náà, `model` tí a ti ṣàwárí, `stream: false`, àti `max_tokens: 512`
   (tàbí iye àtúnṣe ọ̀ràn náà).
3. Ó pe olùdarí ìjíròrò náà ní tààràtà (nínú ìlànà iṣẹ́ náà — kò sí ìrìn HTTP àfikún).
4. Ó ṣàkọsílẹ̀ àkókò ìdádúró, ó sì yọ ọ̀rọ̀ jáde láti inú `choices[0].message.content`
   tàbí ẹrù ìdáhùn Responses-API `output[]`.
5. Ó fún gbogbo àbájáde ní àmì nípasẹ̀ `runSuite()`, lẹ́yìn náà ó tọ́jú wọn nípasẹ̀ `saveEvalRun()`.

Àwọn ọ̀ràn máa ń ṣiṣẹ́ **lọ́kọ̀ọ̀kan ní tẹ̀lé-tẹ̀lé**. Kò sí àsíá iṣẹ́ alájọṣiṣẹ́pọ̀ lọ́wọ́lọ́wọ́.

## Pánẹ́ẹ̀lì Ìṣàkóso

Ojú-ìwòye náà wà ní `Dashboard → Usage → Evals`
(`src/app/(dashboard)/dashboard/usage/components/EvalsTab.tsx`). Láti ibẹ̀, o
lè:

- Ṣàwárí àwọn àkójọpọ̀ ìdánwò tí a kọ sínú rẹ̀ àti ti àdáni pẹ̀lú àkọ́wò ọ̀ràn kọ̀ọ̀kan.
- Ṣẹ̀dá/ṣàtúnṣe/parẹ́ àwọn àkójọpọ̀ ìdánwò àdáni pẹ̀lú olùkọ́ ọ̀ràn.
- Yan ibi àfojúsùn kan (àwọn iye àiyipada àkójọpọ̀ ìdánwò / model / combo), o tún lè yan
  `compareTarget` kejì, kọ́kọ́rọ́ API bí o bá fẹ́, lẹ́yìn náà ṣiṣẹ́ ẹ nígbà tí o bá fẹ́.
- Ṣàyẹ̀wò ìtàn àwọn ìṣiṣẹ́, ìrékọjá/ìkùnà ọ̀ràn kọ̀ọ̀kan, àkókò ìdádúró, àti àwọn àbájáde tí a ṣàkọsílẹ̀.
- Wo káàdì àmì yíyí tí a kó jọ láti inú ìṣiṣẹ́ tuntun jù lọ fún
  àyè `(suite, target)` kọ̀ọ̀kan.

## Ìbáṣepọ̀ pẹ̀lú RFC Auto-Assessment

Ètò abẹ́lẹ̀ ìṣàyẹ̀wò mìíràn tí ó ní àfojúsùn tóóró síi wà ní `src/domain/assessment/`
(wo [AUTO-COMBO.md](../routing/AUTO-COMBO.md) pẹ̀lú fún ẹ́ńjìnnì fífún àmì tó ń ṣiṣẹ́ lọ́wọ́).
Ètò abẹ́lẹ̀ yẹn dojú kọ ẹ́ńjìnnì Auto Combo — ó ń fún àwọn olùpèsè àti
àwọn model ní àmì láìfọwọ́ṣe kí àwọn combo lè tún ara wọn ṣe nígbà tí àwọn iṣẹ́ upstream bá kùnà. Ó ń lo olùṣiṣẹ́ tirẹ̀,
olùpín-ẹ̀ka tirẹ̀, àti ọgbọ́n fífún àmì tirẹ̀.

Férémù Evals tí a ṣàkọsílẹ̀ rẹ̀ níbí ni **ojú-ọ̀nà ìdánwò gbogbogbòò
tí ó gbòòrò síi**. Yan án fún àwọn àkójọpọ̀ ìdánwò ìfàsẹ́yìn oríṣiríṣi, àwọn ìfiwéra A/B,
àti àwọn ìdánwò ẹ̀fin fún ìtújáde kọ̀ọ̀kan. Lo ètò abẹ́lẹ̀ Auto-Assessment nígbà tí o bá nílò
ìlera olùpèsè ní àsìkò gidi láti ní ipa lórí àwọn ìpinnu ìdarí ọ̀nà.

## Ìṣọ̀kan CI

Kò sí script npm `eval:ci` pàtó lọ́wọ́lọ́wọ́. Ọ̀nà méjì ló wà bí o bá fẹ́
fi àbájáde eval ṣe ìdènà ìtújáde:

- **Ọ̀nà HTTP**: gbé server náà dìde, fi ìbéèrè `POST /api/evals` ránṣẹ́ pẹ̀lú
  `suiteId` + `target` tí a mọ̀, kí o sì fìdí `runs[].summary.passRate >= N` múlẹ̀ nínú
  ìdáhùn náà.
- **Ọ̀nà inú ìlànà iṣẹ́**: ṣàgbéwọlé `runEvalSuiteAgainstTarget()` láti
  `@/lib/evals/runtime` láti inú script kan, ṣiṣẹ́ sí DB ìdánwò kan, kí o sì ṣàyẹ̀wò
  `PersistedEvalRun.summary` tí a dá padà.

Àwọn ìdánwò tó bo route àti ìtàn wà ní
`tests/unit/evals-route.test.ts` àti `tests/unit/evals-history.test.ts`.

## Àwọn Ojúami Ìmúgbòòrò

Àwọn àyípadà tó wọ́pọ̀ àti ibi tí a ti lè ṣe wọ́n:

- **Ọgbọ́n fífún àmì tuntun** — mú ìdènà `switch (evalCase.expected.strategy)`
  gùn síi nínú `evaluateCase()` (`evalRunner.ts`), kí o sì mú `EvalCaseStrategy` gbòòrò síi nínú
  `src/lib/db/evals.ts` pẹ̀lú `evalCaseBuilderSchema` nínú `schemas.ts`.
- **Àkójọpọ̀ ìdánwò tuntun tí a kọ sínú rẹ̀** — ṣàlàyé ohun àkójọpọ̀ ìdánwò kan, kí o sì pe `registerSuite()` ní
  ìsàlẹ̀ `evalRunner.ts`. `listSuites()` yóò ṣàwárí rẹ̀ láìfọwọ́ṣe.
- **Ṣiṣẹ́ pẹ̀lú iṣẹ́ alájọṣiṣẹ́pọ̀** — yí loop `for` tẹ̀lé-tẹ̀lé padà nínú
  `runEvalSuiteAgainstTarget()` sí `Promise.all` tó ní ààlà (kò sí ìṣàkóso iṣẹ́
  alájọṣiṣẹ́pọ̀ lọ́wọ́lọ́wọ́).
- **Àwọn ọ̀ràn stream/tool-call** — lọ́wọ́lọ́wọ́, olùṣiṣẹ́ náà ń fi tipátipá lo `stream: false`.
  Ṣíṣànwọlé tàbí ìṣàyẹ̀wò tó mọ̀ nípa irinṣẹ́ yóò nílò àwọn àyípadà nínú `runtime.ts`
  (ṣàkọsílẹ̀ kí o sì ṣàkójọpọ̀ àwọn ègé SSE kí a tó fún wọn ní àmì).
