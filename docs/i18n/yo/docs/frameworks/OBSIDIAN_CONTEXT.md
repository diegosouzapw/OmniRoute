> **Orísun òtítọ́:** `src/lib/obsidian/api.ts` (REST + oníbàárà ìṣiṣẹ́pọ̀),
> `src/lib/db/obsidian.ts` (ìfipamọ́ token / base-URL / WebDAV),
> `src/lib/obsidianSync.ts` (ìṣiṣẹ́pọ̀ vault WebDAV), `open-sse/mcp-server/tools/obsidianTools.ts`
> (irinṣẹ́ MCP 22), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (àwọn API ètò). Ìforúkọsílẹ̀ irinṣẹ́
> àti àsopọ̀ scope wà nínú `open-sse/mcp-server/server.ts`.

## Ohun tí ó jẹ́

OmniRoute so mọ́ vault **Obsidian** gẹ́gẹ́ bí **orísun àyíká-ọ̀rọ̀** — ibi ìpamọ́ ìmọ̀
Markdown abẹ́lẹ̀ kan tí àwọn agent ń kà, tí wọ́n sì ń kọ sí nípasẹ̀ server MCP tí a kọ́ sínú rẹ̀.
Ìṣọ̀kan náà ń bá plugin àwùjọ **Obsidian Local REST API** tí ń ṣiṣẹ́ nínú app desktop
sọ̀rọ̀, kí àwọn agent lè ṣàwárí àwọn àkọsílẹ̀, kà/kọ́/ṣe àtúnṣe patch sí àwọn fáìlì,
ṣe àkójọ vault, ṣiṣẹ́ pẹ̀lú àwọn àkọsílẹ̀ àsìkò ojoojúmọ́/ọ̀sọ̀ọ̀sẹ̀, ṣàkóso àwọn tag,
ṣiṣẹ́ àwọn àṣẹ Obsidian, àti (bí a bá fẹ́) ṣètò ìṣiṣẹ́pọ̀ vault oníṣọ̀nà-méjì
desktop↔mobile.

Oníbàárà náà (`src/lib/obsidian/api.ts`) fi àwọ̀n yí Local REST API ká pẹ̀lú:

- **Àtúnìgbìyànjú pẹ̀lú backoff** fún `5xx` alákòókò, **àkókò ìdádúró ìṣẹ́jú-àáyá 30** nípasẹ̀ `AbortController`.
- **Ìsọ̀rí àṣìṣe oníirú** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Ìtọ́kasí “a kò lè dé Obsidian” tó rọrùn láti lóye** tí ó ṣàlàyé àṣìṣe port tó wọ́pọ̀
  (HTTP lórí `27123`, **kì í ṣe** endpoint MCP lórí `27124`) àti fọ́ọ̀mù Tailscale.
- **Ìṣàkọsílẹ̀ path** tó jẹ́ ìbátan sí vault, kí àwọn path àkọsílẹ̀ tó ní àyè/slash lè ní ààbò.

## Ìṣètò

Kò sí **environment variable** fún token Obsidian tàbí base URL — a fi àwọn méjèèjì pamọ́
sínú tábìlì SQLite `key_value` (namespace `obsidian`) nípasẹ̀
`src/lib/db/obsidian.ts`. Token náà jẹ́ **ìfipamọ́ tó ní ìfẹnukò** (AES-256-GCM, pẹ̀lú
plaintext fallback fún ìbámu sẹ́yìn). Ṣètò rẹ̀ láti taabu **Àwọn Orísun Àyíká-ọ̀rọ̀**
lórí dashboard Endpoint (`ObsidianSourceCard`), tàbí nípasẹ̀ API REST ètò.

> [!IMPORTANT]
> Plugin **Obsidian Local REST API** gbọ́dọ̀ ti fi sílẹ̀, ó sì gbọ́dọ̀ máa ṣiṣẹ́. Interface REST
> rẹ̀ ń tẹ́tí lórí **HTTP `127.0.0.1:27123`** (base URL àkọ́kọ́). Port `27124`
> jẹ́ endpoint MCP/HTTPS _ọ̀tọ̀_, route ètò sì kọ̀ ọ́ ní kedere.
> Bí o bá ń sopọ̀ láti ẹ̀rọ mìíràn, lo `http://<tailscale-ip>:27123`.

### Àwọn kọ́kọ́rọ́ ìṣètò (SQLite `key_value`, namespace `obsidian`)

| Kọ́kọ́rọ́            | Ète                                            | Ní ìfẹnukò |
| ----------------- | ---------------------------------------------- | ---------- |
| `api_key`         | Token bearer Local REST API                    | bẹ́ẹ̀ ni     |
| `base_url`        | Base URL REST (àkọ́kọ́ `http://127.0.0.1:27123`) | bẹ́ẹ̀ kọ́     |
| `vault_path`      | Path pípé sí directory vault (fún ìṣiṣẹ́pọ̀)     | bẹ́ẹ̀ kọ́     |
| `webdav_username` | Orúkọ aṣàmúlò WebDAV tí a ṣẹ̀dá (ìṣiṣẹ́pọ̀ vault) | bẹ́ẹ̀ kọ́     |
| `webdav_password` | Ọ̀rọ̀ aṣínà WebDAV tí a ṣẹ̀dá (ìṣiṣẹ́pọ̀ vault)     | bẹ́ẹ̀ ni     |
| `webdav_enabled`  | Bóyá ìṣiṣẹ́pọ̀ vault WebDAV ti ṣiṣẹ́              | bẹ́ẹ̀ kọ́     |

### Ṣètò nípasẹ̀ REST

```bash
# Fi token Local REST API pamọ́ + jẹ́rìí rẹ̀ (POST ń jẹ́rìí nípasẹ̀ àyẹ̀wò ipò)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Ṣàyẹ̀wò ipò àsopọ̀ (ó dá connected, hasToken, baseUrl, vaultPath padà)
curl http://localhost:20128/api/settings/obsidian

# Gé àsopọ̀ (ó pa token tí a fi pamọ́ rẹ́)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Gbogbo àwọn method nílò ìfàṣẹsí dashboard. `POST` kọ URL èyíkéyìí lórí port `27124`
ó sì jẹ́rìí token náà nípa pípè endpoint ipò Local REST API kí ó tó fi í pamọ́.

### Ìṣiṣẹ́pọ̀ vault WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` ń ṣàkóso ìṣiṣẹ́pọ̀ vault tí WebDAV
ṣe àtìlẹ́yìn fún, èyí tí kò pọndandan (tí `src/lib/obsidianSync.ts` ń darí). Ṣíṣe é ṣiṣẹ́
ń tọ́ OmniRoute sí directory vault abẹ́lẹ̀ kan, ó sì ń ṣẹ̀dá orúkọ aṣàmúlò/ọ̀rọ̀ aṣínà
WebDAV aláìlẹ́sẹẹsẹ kan:

```bash
# Ṣí ìṣiṣẹ́pọ̀ WebDAV ṣiṣẹ́ fún directory vault kan (ó ṣẹ̀dá orúkọ aṣàmúlò/ọ̀rọ̀ aṣínà)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Gba ipò ìṣiṣẹ́pọ̀ WebDAV (a máa dá credentials padà nígbà tí ó bá ṣiṣẹ́ nìkan)
curl http://localhost:20128/api/settings/obsidian/webdav

# Pa ìṣiṣẹ́pọ̀ WebDAV (ó pa credentials + .stignore tí a ń ṣàkóso rẹ́)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Orísun àyíká-ọ̀rọ̀ fún kọ́kọ́rọ́ API kọ̀ọ̀kan (kò pọndandan)

A lè fi config Obsidian sí scope **fún kọ́kọ́rọ́ API kọ̀ọ̀kan** nípasẹ̀ tábìlì
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Nígbà tí ìpè MCP kan
bá gbé id kọ́kọ́rọ́ API tí a ti fìdí rẹ̀ mú, `getObsidianConfigForApiKey()` máa kọ́kọ́
yan token/base-URL/vault-path ti kọ́kọ́rọ́ náà fúnra rẹ̀ (`source: "api_key"`), bí kò bá
sí bẹ́ẹ̀, yóò lo config àgbáyé gẹ́gẹ́ bí fallback (`source: "global"`).

## Àwọn irinṣẹ́ MCP (22)

A ṣàlàyé wọn nínú `open-sse/mcp-server/tools/obsidianTools.ts`. Token/base-URL ni a máa ń pinnu
nígbà ìpè kọ̀ọ̀kan (ti kọ́kọ́rọ́ API kọ̀ọ̀kan lákọ̀ọ́kọ́, lẹ́yìn náà ti àgbáyé). Àwọn irinṣẹ́ tó ń lo ẹ̀rọ aṣàmúlò **ìṣiṣẹ́pọ̀**
OmniRoute (àwọn irinṣẹ́ `obsidian_sync_*` mẹ́rin náà) tún nílò token ìfàṣẹsí ìṣiṣẹ́pọ̀ tí a ṣètò
nínú àwọn ààtò OmniRoute.

### Àwọn irinṣẹ́ kíkà (`read:obsidian`)

| Irinṣẹ́                       | Àpèjúwe                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Ṣàyẹ̀wò bóyá Local REST API ṣeé dé àti pé a ti fi ìdánimọ̀ múlẹ̀.                                               |
| `obsidian_search_simple`     | Ṣàwárí ọ̀rọ̀ kíkún nínú àkóónú àkọsílẹ̀; ó ń dá àwọn àjákù ọ̀rọ̀ padà pẹ̀lú àwọn ipa fáìlì.                        |
| `obsidian_search_structured` | Ṣàwárí nípa lílo gbólóhùn JSON Logic (àwọn àsẹ and/or/regex/path).                                           |
| `obsidian_read_note`         | Ka àkọsílẹ̀ nípasẹ̀ ipa tó jẹ́ mọ́ vault; ó lè jẹ́ àkọlé/block/frontmatter kan pàtó.                              |
| `obsidian_list_vault`        | Ṣe àtòjọ àwọn fáìlì àti àwọn àpò inú vault (igi àwọn àkọsílẹ̀).                                               |
| `obsidian_get_document_map`  | Gba ìṣètò àkọlé àkọsílẹ̀ náà gẹ́gẹ́ bí àwòrán àwọn àkọlé → àwọn nọ́ńbà ìlà.                                      |
| `obsidian_get_note_metadata` | Gba frontmatter, àwọn tag, àwọn link, àti iye ẹyọ ọ̀rọ̀/ọ̀rọ̀ láìgba gbogbo àkóónú.                              |
| `obsidian_get_active_file`   | Gba ipa + àkóónú fáìlì tó ń ṣiṣẹ́ lọ́wọ́lọ́wọ́ nínú Obsidian.                                                     |
| `obsidian_get_periodic_note` | Gba àkọsílẹ̀ àsìkò ojoojúmọ́/ọ̀sọ̀ọ̀sẹ̀/oṣooṣù fún ọjọ́ kan (òní bí a kò bá sọ ọ́).                                  |
| `obsidian_get_tags`          | Ṣe àtòjọ gbogbo tag inú vault pẹ̀lú iye ìgbà tí ọ̀kọ̀ọ̀kan farahàn.                                              |
| `obsidian_list_commands`     | Ṣe àtòjọ àwọn ID àṣẹ Obsidian tó wà (lò ó pẹ̀lú `obsidian_execute_command`).                                  |
| `obsidian_sync_status`       | Ipò ẹ̀rọ aṣàmúlò ìṣiṣẹ́pọ̀ OmniRoute: bóyá ó ń ṣiṣẹ́, orúkọ vault, port, àkókò tó ti ṣiṣẹ́, ìṣiṣẹ́pọ̀ tó ṣẹ̀ṣẹ̀ wáyé. |
| `obsidian_sync_conflicts`    | Ṣe àtòjọ àwọn ìtakora ìṣiṣẹ́pọ̀ tí a kò tíì yanjú (ipa, ipa ìtakora, ìgbà tí a rí i).                          |

### Àwọn irinṣẹ́ kíkọ (`write:obsidian`)

| Irinṣẹ́                           | Àpèjúwe                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------ |
| `obsidian_write_note`            | Ṣẹ̀dá àkọsílẹ̀ tàbí kọ lé e lórí pẹ̀lú àkóónú Markdown tí a fún un.                     |
| `obsidian_append_note`           | Fi àkóónú kún àkọsílẹ̀; ó lè jẹ́ sí àkọlé/block kan pàtó.                              |
| `obsidian_patch_note`            | Fi kún lẹ́yìn/fi kún ṣáájú/rọ́pò ní àkọlé, block, tàbí ààyè frontmatter lọ́nà pípéye.   |
| `obsidian_delete_note`           | Pa àkọsílẹ̀ rẹ́ pátápátá kúrò nínú vault.                                              |
| `obsidian_move_note`             | Gbé àkọsílẹ̀ tàbí tún un lorúkọ nínú vault.                                           |
| `obsidian_execute_command`       | Ṣàmúṣẹ àṣẹ Obsidian nípasẹ̀ ID àṣẹ rẹ̀.                                                |
| `obsidian_open_file`             | Ṣí fáìlì kan nínú Obsidian (ó máa ṣẹ̀dá rẹ̀ bí kò bá sí).                              |
| `obsidian_sync_trigger`          | Bẹ̀rẹ̀ ìṣiṣẹ́pọ̀ vault olójú-ọ̀nà-méjì desktop↔mobile lẹ́sẹ̀kẹsẹ̀.                           |
| `obsidian_sync_resolve_conflict` | Yanjú ìtakora ìṣiṣẹ́pọ̀: pa `local` (mobile) mọ́, `remote` (desktop), tàbí `keep-both`. |

> [!NOTE]
> Àwọn àfojúsùn `obsidian_patch_note` gba `targetType` ti `heading | block | frontmatter`
> àti `operation` ti `append | prepend | replace`, pẹ̀lú
> `createTargetIfMissing` tí kì í ṣe dandan. Àwọn irinṣẹ́ `obsidian_sync_*` mẹ́rin náà ń bá ẹ̀rọ aṣàmúlò ìṣiṣẹ́pọ̀ agbègbè
> (`http://127.0.0.1:27781` nípa àìyípadà) sọ̀rọ̀, wọ́n sì nílò token ìṣiṣẹ́pọ̀.

### Àwọn ààyè àṣẹ

Àwọn irinṣẹ́ kíkà nílò `read:obsidian`; àwọn irinṣẹ́ kíkọ nílò `write:obsidian`. Ìmúṣẹ
jẹ́ ọ̀nà kan náà pẹ̀lú Notion — `withScopeEnforcement()` nínú
`open-sse/mcp-server/server.ts` ló ń bójú tó o, `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ló sì ń ṣàkóso rẹ̀, pẹ̀lú
àwọn ààyè àṣẹ tí a gbà láti `OMNIROUTE_MCP_SCOPES` tàbí ọ̀rọ̀-àyíká ààyè àṣẹ kọ́kọ́rọ́ API náà. Wo
[MCP-SERVER.md](./MCP-SERVER.md).

## Àwọn endpoint

| Ọ̀nà      | Path                            | Ète                                                       |
| -------- | ------------------------------- | --------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Dá `{ connected, hasToken, baseUrl, vaultPath }` padà.    |
| `POST`   | `/api/settings/obsidian`        | Fi token pamọ́ + fìdí rẹ̀ múlẹ̀ (ó kọ port `27124`).         |
| `DELETE` | `/api/settings/obsidian`        | Já ìsopọ̀ (pa token tí a fi pamọ́ rẹ́).                      |
| `GET`    | `/api/settings/obsidian/webdav` | Ipò ìṣiṣẹ́pọ̀ WebDAV + àwọn ẹ̀rí ìwọlé (nígbà tí ó bá ṣiṣẹ́). |
| `POST`   | `/api/settings/obsidian/webdav` | Mú ìṣiṣẹ́pọ̀ WebDAV ṣiṣẹ́ fún àpò vault kan.                 |
| `DELETE` | `/api/settings/obsidian/webdav` | Pa ìṣiṣẹ́pọ̀ WebDAV.                                        |

> Àwọn wọ̀nyí jẹ́ àwọn route ètò dashboard. Vault fúnra rẹ̀ ni a ń dé sí nípasẹ̀ Obsidian
> Local REST API (`base_url` tí a ṣètò) àti nípasẹ̀ àwọn irinṣẹ́ MCP lókè — kò sí
> endpoint aṣojú Obsidian `/v1` fún gbogbo ènìyàn.

## Àwọn ọ̀nà lílò

- **Àwọn ìdáhùn tó dá lórí vault** — `obsidian_search_simple` / `obsidian_search_structured`
  lẹ́yìn náà `obsidian_read_note`, kí aṣojú lè dáhùn láti inú àwọn àkọsílẹ̀ gidi rẹ.
- **Kíkọ àkọsílẹ̀ / ìwé ìròyìn ojoojúmọ́** — `obsidian_write_note`, `obsidian_append_note`, tàbí
  `obsidian_patch_note` tó ń ṣe àtúnṣe pẹ̀lú ìṣọ́ra láti ṣàkọsílẹ̀ àbájáde aṣojú, àwọn àkótán, tàbí àwọn àkọsílẹ̀ ojoojúmọ́
  (`obsidian_get_periodic_note`) sínú vault.
- **Ìlọ kiri inú vault** — `obsidian_list_vault`, `obsidian_get_document_map`, àti
  `obsidian_get_tags` láti ṣàwárí ìṣètò rẹ̀ kí o tó kà/kọ.
- **Ìṣiṣẹ́ aládàáṣe Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` láti
  ṣàkóso àwọn plugin/àṣẹ láti ọ̀dọ̀ aṣojú; `obsidian_open_file` láti fi àkọsílẹ̀ hàn nínú UI.
- **Ìṣiṣẹ́pọ̀ alágbèéká** — mú ìṣiṣẹ́pọ̀ WebDAV ṣiṣẹ́, lẹ́yìn náà `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  láti ṣètò ìṣiṣẹ́pọ̀ kọ̀ǹpútà tabili↔alágbèéká àti láti yanjú àwọn ìforígbárí.
