## Olùkà ìkéde gbogbogbò

Olùkà ìkéde gbogbogbò yàtọ̀ sí àsíá ẹ̀yà Radar. Ojúlé Dashboard àti
olùwo Changelog máa ń gba `news.json` gbogbogbò ti ibi ìpamọ́ náà nípasẹ̀ `GET` lásán sí
`NEWS_JSON_URL` (`src/shared/utils/releaseNotes.ts`). Wọn kò fi ètò Radar, prompt, àtúnṣe
olùpèsè, àkọsílẹ̀ lílò, tàbí ipò ìkọ̀sílẹ̀ agbègbè kankan ránṣẹ́.

`news.json` ń lo schema v2 tí a ti pa mọ́ tí `parseNewsPayload()` ṣe àgbékalẹ̀ rẹ̀:

- `schemaVersion: 2` àti àkójọpọ̀ `items[]` tí a fi ààlà sí;
- àwọn iye `id` ìkéde tó dúró ṣinṣin, tí kò sì ṣe àdàkọ;
- àwọn field `active` àti ISO `publishedAt` tí a sọ ní kedere;
- ọ̀rọ̀ Gẹ̀ẹ́sì tó jẹ́ dandan pẹ̀lú ọ̀rọ̀ agbègbè tó jẹ́ àṣàyàn;
- àwọn link HTTPS tí kò nílò credential àti icon tó wà nínú allowlist, tí gbogbo wọn jẹ́ àṣàyàn;
- yíyan ohun tó ṣiṣẹ́ tuntun jù lọ lákọ̀ọ́kọ́, fífà sẹ́yìn láti locale sí Gẹ̀ẹ́sì, àti ìkọ̀sílẹ̀ agbègbè fún ID kọ̀ọ̀kan.

Parser náà gba ìrísí ẹyọ kan àtijọ́ `{ active, title, message, ... }` fún ìgbà díẹ̀ kí
àwọn fork àtijọ́ lè ṣe migration láì ba ojú Changelog jẹ́. Àwọn feed tí kò bófin mu kò ṣiṣẹ́. Àkọsílẹ̀ ìfilọ́lẹ̀ Radar
wá pẹ̀lú `active: false`; yíyí rẹ̀ sí `true` jẹ́ ìgbésẹ̀ ìtújáde ọ̀tọ̀ lẹ́yìn merge àti lẹ́yìn deploy,
kò sì yí `RADAR_ENABLED` tàbí ìforúkọsílẹ̀ feed-sync olómìnira padà.

## Àsíá: `RADAR_ENABLED` (ó jẹ́ pípa ní àkọ́kọ́)

A ṣàkóso Radar láti ìbẹ̀rẹ̀ dé òpin pẹ̀lú àsíá ẹ̀yà `RADAR_ENABLED`
(`src/shared/constants/featureFlagDefinitions.ts`, ẹ̀ka `policies`,
`defaultValue: "false"`).

**Nígbà tí àsíá náà bá wà ní pípa, ojú iṣẹ́ náà kò sí:**

- Gbogbo endpoint `/api/radar/*`, pẹ̀lú kíkà àti kíkọ ipò model agbègbè,
  máa dá `404` padà kí wọn tó kan module Radar kankan.
- Àwọn ojú dashboard (`/dashboard/radar`, `/dashboard/radar/setup`,
  `/dashboard/radar/combos`, `/dashboard/radar/offers`, `/dashboard/radar/intel`) máa render
  `notFound()`.
- `getRadarCatalog()` (`src/lib/radar/index.ts`) máa dá baseline tí a kò fọwọ́ kàn padà —
  iye àwọn àkọsílẹ̀ kan náà, àwọn iye kan náà, tí a fi `origin: "baseline"` sí gbogbo àkọsílẹ̀ — kò sì ní
  ka cache feed láé.
- Kò sí network call Radar kankan tí a ó ṣe; module sync kọ̀ọ̀kan máa dá `{ status: "disabled" }`
  padà kí ó tó kan `fetch`.

Èyí jẹ́ ẹnu-ọ̀nà superset tó muna: yíyí àsíá náà sí títàn máa ṣí àwọn _ojú_ náà nìkan,
kò ju bẹ́ẹ̀ lọ. Kò upload data, kò bẹ̀rẹ̀ sync abẹ́lẹ̀, kò sì yí
routing tàbí yíyan model padà — wo ìforúkọsílẹ̀ ọ̀tọ̀ ní ìsàlẹ̀.

## Sync data jẹ́ ìforúkọsílẹ̀ Ọ̀TỌ̀ — ìlérí àṣírí

Ṣíṣe `RADAR_ENABLED` sí títàn ń ṣí UI nìkan. Ṣíṣe sync feed nílò ìforúkọsílẹ̀ kejì,
tó dúró lọ́tọ̀, tí a fi pamọ́ sínú `radar_settings.opt_in` (`src/lib/db/radar.ts`,
migration `136_radar_cache_settings.sql`). `syncRadar()` máa ṣàyẹ̀wò àsíá náà _àti_
ìforúkọsílẹ̀ náà kí ó tó ṣe network call kankan:

```
Àsíá pípa       → { status: "disabled" }   — kò sí network call
Opt-in jẹ́ false → { status: "opt_out" }    — kò sí network call
```

Nígbà tí àwọn méjèèjì bá tàn, ọ̀nà sync náà ni:

1. `GET <feed base URL>/v1/catalog/latest` pẹ̀lú `x-omniroute-radar-schema: 2` àti header
   `Authorization: Bearer <supporter key>` tó jẹ́ àṣàyàn (wo ìsàlẹ̀). Àwọn server máa lo artifact ìyípadà v1
   tí a fọwọ́ sí lọ́tọ̀ gẹ́gẹ́ bí default nígbà tí header schema kò sí, kí àwọn client àtijọ́ tí a ti fi sílẹ̀ lè máa
   gba àwọn update.
2. Èyí jẹ́ ìṣàn application fún download nìkan, ṣùgbọ́n ó ṣì jẹ́ request HTTPS. Amáyédẹrùn
   tí a gbalejo máa gba metadata àsopọ̀ àjọṣe bíi IP orísun. Nígbà tí a bá ṣètò supporter
   key, sync tún máa fi key náà ránṣẹ́ nínú header Bearer kí service náà lè pinnu
   entitlement. Ní revision server aládàáni pàtó tí a dárúkọ nínú ààlà ẹ̀rí lókè,
   ìṣírò request feed ń lo hash key, lílò àkójọpọ̀, àti HMAC IP tí a gé kúrú tí ó ń yí padà lójoojúmọ́
   fún àyẹ̀wò abuse ọwọ́; àwọn table wọ̀nyẹn kò fi key tàbí IP pamọ́ ní ìrísí aise.
   Àwọn log ìwọlé amáyédẹrùn àti outbox ìfiránṣẹ́ tí a encrypt jẹ́ àwọn ààlà iṣẹ́
   ọ̀tọ̀.
3. OmniRoute kì í fi prompt, response, conversation, credential olùpèsè, traffic model,
   uptime, latency, tàbí àtúnṣe olùpèsè agbègbè ránṣẹ́ sí service Radar.
4. A máa verify response náà, validate rẹ̀, a sì máa cache rẹ̀ ní agbègbè (wo
   [Àwòṣe ààbò](#security-model)). Radar ní ọ̀nà network ẹgbẹ́ server mẹ́rin gan-an:
   `syncRadar()` fún catalog, `syncRadarReferrals()` fún referral, àti
   `syncRadarOffers()` / `syncRadarIntel()` fún offer àti Intel tí ó jẹ́ ti supporter nìkan.

**Supporter key** jẹ́ token Bearer tó jẹ́ àṣàyàn (`radar_settings.supporter_key`)
tí ó jẹ́ kí service feed pinnu tier tí yóò pèsè (wo
[Àwọn tier](#tiers-community-and-live)). Ó jẹ́:

- Tí a fi pamọ́ **ní ìrísí encrypted níbi ìpamọ́** pẹ̀lú àwọn helper AES-256-GCM `encrypt()`/`decrypt()`
  kan náà (`src/lib/db/encryption.ts`) tí a ń lò fún credential olùpèsè.
- Tí a ṣètò nípasẹ̀ `POST /api/radar/settings` (`{ supporterKey: "omr_" + 40 hex chars }`) tí a sì
  **kò dá padà láé** — response náà máa dá ìrísí tí a bo mọ́lẹ̀ padà (`omr_****abcd`).
- Yíyí tàbí pípa á rẹ́ máa invalidate cache catalog, referral, offer, àti Intel papọ̀ lẹ́ẹ̀kan náà.
  Sync/kíkà tó kàn máa pinnu entitlement tuntun ní ẹgbẹ́ server; fífi key pamọ́ fúnra rẹ̀ kò
  ṣe network request tàbí lo key activation ìlò-ẹ̀ẹ̀kan.
- Tí a fi ránṣẹ́ sí service feed gẹ́gẹ́ bí token Bearer lórí sync GET — kò sí nǹkan mìíràn nípa
  key náà tí yóò jáde kúrò lọ́dọ̀ client.

Pátákó ìdarí tí kò tíì ṣiṣẹ́ ń ṣe àfihàn àwọn òfin wọ̀nyí láti
`src/app/(dashboard)/dashboard/radar/RadarAccessExplainer.tsx` **ṣáájú** èyíkéyìí nínú àwọn ìgbésẹ̀ ìmúṣiṣẹ́.
Ìwọ̀n ìwọlé àṣẹ ni:

| Ìpele              | Ìtóótun                                                               | Ìwọlé                                                   | Òfin àtúnṣe/ìparí àkókò                                                               |

Àwọn PR tí a ti darapọ̀, àwọn ìfọwọ́sowọ́pọ̀ kóòdù, àti iye àwọn ìlà tí a yí padà jẹ́ **àwọn ohun èlò ìṣètò ipò nìkan**. Ìwọlé tí ó wà níta Top 100
kò ní gba ìfúnni olùkópa láìka iye PR sí. Àwọn rírà onígbà díẹ̀, àwọn ọrẹ, àwọn àkókò olùkópa, àti
àwọn ìfúnni afọwọ́ṣe máa ń kójọ láti ọjọ́ ìparí tó wà lọ́wọ́lọ́wọ́; títí ayé borí gbogbo rẹ̀. Ìyípadà ipò kì í
fagilé tàbí dín àkókò tí a ti fúnni tẹ́lẹ̀ kù lẹ́yìn-ò-rẹyìn.

Ìwé-àṣẹ tí a gbàlejò jẹ́ ti ara ẹni, òfin tí a sì fi hàn sí olumulo ni pé fifi sori ẹrọ kan ṣoṣo ló lè ṣiṣẹ́ lẹ́ẹ̀kan. Ẹ̀yà
yìí **kò** sọ pé ó ní ìdè ohun èlò: ìṣiṣẹ́pọ̀ OSS kì í gba àmì ìdánimọ̀ ohun èlò, bẹ́ẹ̀ ni kò bójú tó
iyálọ́wọ́ ẹ̀rọ tó jẹ́ ti ìkọ̀kọ̀. Ní àtúnyẹ̀wò olupin-àdáni tí a jẹ́rìí sí lókè, ìfipámúlò tí a ṣe
ni ìfìdímúlẹ̀ ẹ̀tọ́ pẹ̀lú àmì ìṣàyẹ̀wò afọwọ́ṣe nígbà tí a bá rí kọ́kọ́rọ́ alààyè kan náà láti IP
kẹrin tó yàtọ̀ láàárín wákàtí 24. Àmì yẹn kì í dí kọ́kọ́rọ́ tàbí fagilé rẹ̀ láìfọwọ́sí. Ìmúpadàbọ̀sípò
máa ń fagilé kọ́kọ́rọ́ tó sọnù, yóò sì fi tuntun rọ́pò rẹ̀ nígbà tí yóò pa ọjọ́ ìparí tó wà mọ́; kò ní tún
àkókò tí a rà tàbí tí a fúnni bẹ̀rẹ̀.

Àwọn ìpèsè alààyè ni a ń ṣàkóso afọwọ́ṣe, wọ́n sì lè yí padà tàbí parí. Ojú-ìwé jíjẹ́wọ́ náà tún sọ ààlà
àṣírí náà gan-an: a máa gba metadata àkójọ/ìtọ́kasí tí a fọwọ́ sí sílẹ̀; kọ́kọ́rọ́ tó fẹsẹ̀ múlẹ̀ tún máa ṣí
àwọn ìpèsè tí a fọwọ́ sí àti Intel; kọ́kọ́rọ́ Bearer àti metadata àsopọ̀ déédéé máa dé ọ̀dọ̀ iṣẹ́ tí a gbàlejò;
àwọn ìtọ́ni, àwọn ìdáhùn, àwọn ìjíròrò, àwọn ẹ̀rí ìdánimọ̀ olupèsè, ìrìn-àjò model, àkókò iṣẹ́, ìdádúró, àti
ètò olupèsè agbègbè kò ní dé ibẹ̀.

## Bí a ṣe ń gba kọ́kọ́rọ́ alátìlẹ́yìn

Ojú ìmúṣiṣẹ́ (`/dashboard/radar`) ní àwọn atọ́ka sí àwọn ìlànà méjì fún **gbígba**
kọ́kọ́rọ́ alátìlẹ́yìn. Ibi ìpamọ́ OSS fúnra rẹ̀ kì í ṣe ìmújáde kọ́kọ́rọ́, kì í ṣiṣẹ́ kóòdù ìsanwó, àti pé
**kì í sọ iye owó rárá** — iye owó ni a ń pinnu tí a sì ń ṣàfihàn pátápátá lórí àwọn
ojú-ewé ibi tí atọ́ka ń tọ́ sí, kì í ṣe nínú ibi ìpamọ́ yìí (ìpinnu àlàyé D14).

- **"Olùkópa ni mí"** — ń ṣí `RADAR_CONTRIBUTOR_CLAIM_URL` (àkọ́kọ́bẹ̀rẹ̀
  `https://radar.omniroute.online/auth/github`), ìlànà ìbéèrè GitHub OAuth tí a gbàlejò lórí
  olupin Radar aládani. Ó máa ń ṣàyẹ̀wò ìṣètò-ipò ọ̀sọ̀ọ̀sẹ̀ tó pé jù lọ: àwọn ipo 10 àkọ́kọ́ máa ń gba ọjọ́ 365
  àti àwọn ipo 11–100 máa ń gba ọjọ́ 90. Ní òde àwọn ipo 100 àkọ́kọ́, iye PR kì í fúnni ní ààyè; dípò bẹ́ẹ̀, ìlànà náà
  máa ń ṣàyẹ̀wò ìpele star + follow onílò-lẹẹ̀kan ọ̀tọ̀.
- **"Ṣe àtìlẹ́yìn fún iṣẹ́ náà"** — ń ṣí `RADAR_SUPPORTER_PLANS_URL` (àkọ́kọ́bẹ̀rẹ̀
  `https://radar.omniroute.online/planos`), ojú-ewé tí a gbàlejò fún àwọn aṣàyàn ìsanwó-ẹ̀ẹ̀kan ti oṣù 6, ọdún 1, àti
  gbogbo ìgbésí-ayé. Ojú-ewé OSS náà kò ṣàfihàn iye owó kankan síbẹ̀.

A máa ń yanjú URL méjèèjì ní ẹ̀gbẹ́ olupin (`src/lib/radar/links.ts`, àpẹẹrẹ ìkọjá-env
kan náà bí `RADAR_FEED_URL`) tí a sì ń fi wọ́n ránṣẹ́ sí pátákó ìdarí nípasẹ̀ ìdáhùn
`GET /api/radar/settings` tó ti wà (`contributorClaimUrl`, `supporterPlansUrl`) — kọ́ńpónẹ́ǹtì
oníbàárà kì í ka `process.env` fúnra rẹ̀.

| Var                           | Ète                                                                                    |
| ----------------------------- | -------------------------------------------------------------------------------------- |
| `RADAR_CONTRIBUTOR_CLAIM_URL` | Ṣe àtúnṣe URL ìbéèrè olùkópa (àkọ́kọ́bẹ̀rẹ̀ `https://radar.omniroute.online/auth/github`). |
| `RADAR_SUPPORTER_PLANS_URL`   | Ṣe àtúnṣe URL àwọn ètò alátìlẹ́yìn (àkọ́kọ́bẹ̀rẹ̀ `https://radar.omniroute.online/planos`). |

### Bíbọ̀sípò kọ́kọ́rọ́ alátìlẹ́yìn tó sọnù

Ojú-ọ̀nà ìbọ̀sípò iṣẹ́ tí a gbàlejò ni `https://radar.omniroute.online/recover`; atọ́ka rẹ̀ tún wà
lórí ojú-ewé àwọn ètò. Ìbọ̀sípò ṣì wà pátápátá ní òde oníbàárà OSS nítorí pé ìfisílẹ̀
agbegbe kì í gba e-mail olùra/olùkópa, kò sì lè tún kọ́kọ́rọ́ gidi ṣe láti inú
àwọn ètò rẹ̀ tí a fi ìpàrokò dáàbò bò.

1. Fi e-mail tó sopọ̀ mọ́ kọ́kọ́rọ́ náà ránṣẹ́. Iṣẹ́ náà máa ń dá ojú-ewé ìtẹ́wọ́gbà kan náà padà bóyá
   ìwé-àṣẹ tí a lè bọ̀sípò wà tàbí kò sí, nítorí náà fọ́ọ̀mù náà kì í ṣe àkójọ àwọn àkọọ́lẹ̀.
2. Tí ó bá yẹ, òṣìṣẹ́ ìfiránṣẹ́ máa ń fi atọ́ka onílò-lẹẹ̀kan tí àkókò rẹ̀ kúrú ránṣẹ́. Ṣíṣí i yóò gbé
   token náà lẹ́sẹ̀kẹsẹ̀ sínú kúkì alákòókò-kúkúrú `HttpOnly`/`Secure` tí a fi ìpàrokò dáàbò bò, yóò sì darí lọ sí URL
   `/recover` tó mọ́; ojú-ewé náà kò ní token, e-mail, kọ́kọ́rọ́ àtijọ́, tàbí kọ́kọ́rọ́ àròpò.
3. Fìdí ìfagilé múlẹ̀. Iṣẹ́ aládani náà máa ń fagilé kọ́kọ́rọ́ àtijọ́, dá àròpò sílẹ̀ pẹ̀lú
   ètò/àkókò ìparí kan náà, ó sì máa ń tò ó fún ìfiránṣẹ́ e-mail nínú ìdúnàádúrà kan. A kì í
   dá kọ́kọ́rọ́ àròpò náà padà sí aṣàwákiri.
4. Lẹ kọ́kọ́rọ́ àròpò náà sínú `/dashboard/radar`. Kọ́kọ́rọ́ àtijọ́ gbọ́dọ̀ sọ̀kalẹ̀ sí `community`; kọ́kọ́rọ́
   àròpò náà gbọ́dọ̀ mú ìbáṣiṣẹ́pọ̀ `live` tí a ti ṣàyẹ̀wò jáde. Ṣíṣí atọ́ka ìbọ̀sípò kan náà lẹ́ẹ̀kan sí i gbọ́dọ̀ kùnà pẹ̀lú
   ìdáhùn àpapọ̀ pé kò fẹsẹ̀múlẹ̀/ó ti parí.

Ojú-ọ̀nà ìbọ̀sípò tí a gbàlejò àti òṣìṣẹ́ mail lè wà nínú kóòdù síbẹ̀ tí wọn kò sì lè lò nínú
ìfisílẹ̀ kan. Má ṣe pe ìlànà náà ní èyí tó ti ṣe tán fún iṣelọpọ títí tí a ó fi fi olupin náà sílẹ̀, tí a ó fi ṣètò
olùpèsè ìfiránṣẹ́ pẹ̀lú olùgbà tí a ṣàkóso, tí a sì ti dán gbogbo atọ́ka onílò-lẹẹ̀kan náà wò.

Ní kété tí àlejò bá ti ní kọ́kọ́rọ́ (`omr_` + àwọn àmì hex 40), ojú ìmúṣiṣẹ́
(`src/app/(dashboard)/dashboard/radar/page.tsx`) ní ààyè ìlẹ̀-kọ́kọ́rọ́ gẹ́gẹ́ bí ọ̀nà
àkọ́kọ́: lílẹ kọ́kọ́rọ́ àti fífi í ránṣẹ́ máa ń fi `POST /api/radar/settings`
(`{ optIn: true, supporterKey }`) ránṣẹ́ lẹ́ẹ̀kan ṣoṣo — lílẹ kọ́kọ́rọ́ yóò ṣètò rẹ̀, yóò sì tún forúkọ-sílẹ̀,
tí yóò ṣí ojú náà. A kọ́kọ́ máa ń ṣàyẹ̀wò ìgbékalẹ̀ náà (`omr_` + àwọn àmì hex 40) ní ẹ̀gbẹ́ oníbàárà
pẹ̀lú olùrànlọ́wọ́ `isValidSupporterKeyFormat()` tí a pín (`src/lib/radar/supporterKey.ts`)
gẹ́gẹ́ bí ìrọ̀rùn UX; schema Zod olupin ni àyẹ̀wò aláṣẹ lọ́nàkọnà. Ní kété tí a bá ti ṣètò
kọ́kọ́rọ́ kan, ojú ìmúṣiṣẹ́ máa ń ṣàfihàn fọ́ọ̀mù tí a bo (`supporterKeyMasked` láti
`GET /api/radar/settings`) dípò ààyè òfìfo, pẹ̀lú ìṣàkóso "yí kọ́kọ́rọ́ padà" láti
lẹ tuntun kan — a kì í tún ṣàfihàn kọ́kọ́rọ́ gidi náà. Àwọn bọ́tìnì ìbéèrè/àwọn ètò méjèèjì lókè
ṣì ni ọ̀nà láti _gba_ kọ́kọ́rọ́ ní ìbẹ̀rẹ̀; ààyè yìí ni olùṣàkóso
tó ti ní ọ̀kan ti máa ń mú un ṣiṣẹ́.

### Ìmúṣiṣẹ́ láti ìbẹ̀rẹ̀ dé òpin àti ìṣètò pẹ̀lú ìtọ́sọ́nà

Iṣẹ́ feed aládani àti oníbàárà OSS yìí ní ààlà tóóró tí a mọ̀ọ́mọ̀ ṣe: iṣẹ́ náà
ń ṣe ìmújáde, ó sì ń fìdí kọ́kọ́rọ́ alátìlẹ́yìn múlẹ̀, nígbà tí ìfisílẹ̀ OmniRoute ti agbègbè ń fi ìpàrokò dáàbò bo kọ́kọ́rọ́ náà,
ń mú àwọn artifact tí a fọwọ́ sí bá ara wọn mu ní ẹ̀gbẹ́ olupin, ó sì ń ṣe ìtọ́sọ́nà ìṣètò olùpèsè. Ètò ìfọwọ́sí pẹ̀lú ìrànlọ́wọ́ ni:

1. Gba kọ́kọ́rọ́ tí a ṣẹ̀ṣẹ̀ fúnni tàbí tí a gba padà láti inú ìbéèrè olùkópa, plans/checkout, ìrìnàjò ìmúpadàbọ̀sípò, tàbí lọ́wọ́ olùṣàkóso olupin aládàáni tí a fún láṣẹ. Má ṣe lẹ kọ́kọ́rọ́ gidi náà sínú àwọn log,
   àwọn screenshot, àwọn àsọyé issue, tàbí àwọn argument command-line.
2. Mú feature flag `RADAR_ENABLED` ṣiṣẹ́ lórí fifi OmniRoute sori ẹ̀rọ abẹ́lé. Èyí yóò ṣí UI sílẹ̀
   ṣùgbọ́n kò ní ṣe ohunkóhun lórí nẹ́tíwọ́ọ̀kì títí tí a ó fi fi ìyọ̀ǹda ọ̀tọ̀ náà pamọ́.
3. Ṣí `/dashboard/radar`, lẹ kọ́kọ́rọ́ náà, kí o sì mú un ṣiṣẹ́. Browser náà fi ìbéèrè abẹ́lé kan ṣoṣo ránṣẹ́:
   `POST /api/radar/settings` pẹ̀lú `{ optIn: true, supporterKey }`; a pa kọ́kọ́rọ́ náà mọ́ ní ìkọ̀kọ̀ lórí ẹ̀rọ abẹ́lé, ìdáhùn náà sì ní `omr_****<last4>` nìkan.
4. Jẹ́ kí ojú ìmúṣiṣẹ́ náà ṣe ìmúdójúìwọ̀n catalog rẹ̀, tàbí yan **Ṣe ìmúdójúìwọ̀n báyìí**. Jẹ́rìí sí i pé ojú-ìwé náà
   ń ṣàfihàn `live`, ẹ̀yà feed kan, àti àkókò fetch kan. Fún àyẹ̀wò abẹ́lé tí a ti jẹ́rìí ìdánimọ̀ rẹ̀,
   `GET /api/radar/status` ń ṣàfihàn ìyọ̀ǹda/ìwàláàyè kọ́kọ́rọ́ àti àwọn ipò cache mẹ́rin láì dá
   kọ́kọ́rọ́ náà padà. `POST /api/radar/sync-all` lè ṣe ìmúdójúìwọ̀n catalog, referrals, offers, àti Intel ní kedere.
5. Ṣí `/dashboard/radar/setup?provider=<provider>`. Tẹ̀lé URL credential tí provider náà ní,
   yan **Ṣàfikún kọ́kọ́rọ́ API**, fi pamọ́ nípasẹ̀ fọ́ọ̀mù provider gidi, padà sí ìtọ́sọ́nà náà, kí o sì ṣe
   **Dán àsopọ̀ wò**. Ìtọ́sọ́nà náà ń lo àwọn route `/api/providers` àti
   `/api/providers/<connection-id>/test` déédéé; kò ṣẹ̀dá credential Radar mìíràn.
6. Ṣí `/dashboard/radar/combos` lẹ́yìn tí ó kéré tán àwọn àsopọ̀ provider méjì tó bá ara wọn mu ti ṣiṣẹ́.
   Ṣàyẹ̀wò family tí a dábàá, kí o sì ṣẹ̀dá combo náà nípasẹ̀ API combo tó wà tẹ́lẹ̀. Offers àti
   Intel ṣì jẹ́ àwọn cache tí a fọwọ́ sí, tí ó wà fún live nìkan, tí ó sì yàtọ̀; a sì lè ṣàyẹ̀wò wọn lórí àwọn ojú-ìwé Radar tí a yàn fún wọn.
7. Tún `/dashboard/radar` àti ojú-ìwé setup gbé wọlé. Ìyọ̀ǹda, ipò kọ́kọ́rọ́ tí a bo, cache tí a jẹ́rìí sí, àsopọ̀
   provider tí a fi pamọ́, àti iṣẹ́ ìdánwò gbọ́dọ̀ dúró lẹ́yìn ìtúngbérù náà. Gba ẹ̀rí kìkì lẹ́yìn tí
   kọ́kọ́rọ́ gidi àti credential provider kò bá hàn mọ́.

Fífipamọ́ kọ́kọ́rọ́ kan kì í ṣe ẹ̀rí fúnra rẹ̀ pé ẹ̀tọ́ live wà. Ẹ̀rí náà ni àpapọ̀ èsì
`GET /v1/license/check` iṣẹ́ aládàáni, tier `live` tí catalog OSS ń pèsè, cache tí a fọwọ́ sí
tí a sì jẹ́rìí, àti ìlànà àsopọ̀/ìdánwò provider gidi. Kọ́kọ́rọ́ tí kò tọ́, tí ó ti parí, tàbí tí a ti fagilé
yóò sọ catalog náà kalẹ̀ sí `community` láìléwu; a kò gbọ́dọ̀ jù ú sílẹ̀ gẹ́gẹ́ bí ìjẹ́rìísí kọ́kọ́rọ́ live tó ṣàṣeyọrí.

### Àsopọ̀ pánẹ́ẹ̀lì alákóso aládàáni

`RADAR_ADMIN_URL` lè ṣàfikún **Alákóso Radar ↗** lẹ́sẹ̀kẹsẹ̀ lẹ́yìn ohun Radar tó dojú kọ olumulo
ní apá Costs nínú sidebar. A mọ̀ọ́mọ̀ kò fún un ní iye àkọ́kọ́: nígbà tí variable náà
kò bá tíì ṣètò tàbí tí kò tọ́, sidebar static, command palette, àti ojú ìṣètò sidebar kò ní
ohun alákóso tàbí URL aládàáni kankan.

A máa yanjú iye náà ní ẹ̀gbẹ́ olupin, a sì máa fi í ránṣẹ́ nípasẹ̀ èsì
`GET /api/settings` tí management ti jẹ́rìí ìdánimọ̀ rẹ̀, sí session dashboard tí a jẹ́rìí ìdánimọ̀ rẹ̀ nìkan, tàbí sí
olùní loopback tí a gbẹ́kẹ̀ lé nígbà bootstrap abẹ́lé tí kò ní login. CLI, iṣẹ́ inú, àti ìjẹ́rìísí kọ́kọ́rọ́ API
manage-scope kò ní gbà á. Browser náà tún ń ṣàyẹ̀wò èsì náà kí ó tó mú
àsopọ̀ ita náà hàn, èyí tí yóò ṣí pẹ̀lú `noopener noreferrer`.

Lo URL tunnel/tailnet HTTPS tí kò ní credential. A gba HTTP lasan nìkan fún SSH
forward loopback bíi `http://127.0.0.1:9351`; àwọn scheme mìíràn, credential tí a fi sínú URL, URL tí kò dára, àti
àwọn ibi HTTP jíjìn yóò kuna ní ipò pípadé, yóò sì jẹ́ kí navigation má ṣiṣẹ́.

## Àwoṣe ààbò

### Ìbuwọ́lu Ed25519 lórí àwọn báìtì gangan

A fi Ed25519 buwọ́lu paylọ́ọ̀dù feed náà. `verifyFeedBytes()`
(`src/lib/radar/verify.ts`) ń ṣàyẹ̀wò ìbuwọ́lu náà lórí **àwọn báìtì ìdáhùn gangan**
tí a gbà lórí nẹ́tíwọọ̀kì — a kì í tún paylọ́ọ̀dù náà ṣe serialize ṣáájú ìṣàyẹ̀wò, nítorí náà
àtúnṣe encoding báìtì-fún-báìtì kò lè sọ ìṣàyẹ̀wò ìbuwọ́lu di asán tàbí kọjá rẹ̀ ní ìkọ̀kọ̀.
Ìkùnà ìṣàyẹ̀wò (`invalid_signature`) yóò dá ìṣiṣẹ́pọ̀ dúró kí a tó
parse tàbí cache paylọ́ọ̀dù náà.

### Kọ́kọ́rọ́ gbogbogbò tí a ti pin mọ́lẹ̀ + yíyípadà

A ti pin kọ́kọ́rọ́ gbogbogbò fún ìṣàyẹ̀wò mọ́lẹ̀ nínú `src/lib/radar/pinnedKeys.ts`
(`PINNED_FEED_PUBLIC_KEYS`), èyí jẹ́ array kí a lè fi kọ́kọ́rọ́ tuntun sí iwájú ṣáájú
yíyípadà, nígbà tí àwọn feed inú cache àtijọ́ tí a fi kọ́kọ́rọ́ tẹ́lẹ̀ buwọ́lu ṣì wúlò títí
a ó fi tún wọn sync.

### Àwọn override env tó rọrùn fún fork

Àwọn env var méjì jẹ́ kí àwọn fork àti àwọn olùgbàlejò-fúnra-wọn darí client sí feed tiwọn dípò
iṣẹ́ OmniRoute àiyipada — wo
[Bí a ṣe ń gbàlejò feed fúnra ẹni](#how-to-self-host-a-feed) nísàlẹ̀:

| Var                 | Ìdí                                                                                                                       |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `RADAR_FEED_URL`    | Ó rọ́pò URL ìpìlẹ̀ feed (àiyipada `https://radar.omniroute.online`).                                                        |
| `RADAR_FEED_PUBKEY` | Ó rọ́pò kọ́kọ́rọ́ gbogbogbò tí a pin mọ́lẹ̀ (base64-DER SPKI tàbí PEM), nípa fífi kọ́kọ́rọ́ kan ṣoṣo yìí rọ́pò array tó wà nínú rẹ̀. |

### Ìwọ̀n ìpìlẹ̀ version

`syncRadar()` kọ feed tí a gba sílẹ̀ tí `version` rẹ̀ kò bá tuntun jù
version tó wà nínú cache lọ (`compareVersions()`, ìfiwéra `YYYY.MM.DD.n` tó ní àmì-ẹ̀kúnrẹ́rẹ́) —
`{ status: "stale" }`. Èyí kò jẹ́ kí endpoint feed tí a ti ba jẹ́ tàbí tí a ṣètò lọ́nà tí kò tọ́
dá client padà sí paylọ́ọ̀dù àtijọ́ kan tí a fi ìbuwọ́lu ọ̀tọ̀ buwọ́lu.

### Ọjọ́ méjì, àti ìdí tí a fi pa àwọn méjèèjì mọ́

Feed inú cache ní ọjọ́ ọ̀tọ̀ọ̀tọ̀ méjì, àti pé dídà wọ́n rú ni gbogbo ìdí
tí a fi pa àwọn méjèèjì mọ́:

| Field         | Ibi tó ti wá         | Ohun tó ń dáhùn                    |
| ------------- | -------------------- | ---------------------------------- |
| `generatedAt` | ara feed tí a buwọ́lu | bí **data** náà ti pẹ́ tó           |
| `fetchedAt`   | aago install yìí     | ìgbà tí install yìí **gba** á sílẹ̀ |

Feed tí a ṣẹ̀ṣẹ̀ gba ní ìṣẹ́jú díẹ̀ sẹ́yìn lè ní àwọn nọ́mbà tó ti pé ọ̀sẹ̀ mélòó kan, nítorí náà `fetchedAt` nìkan kò lè
sọ fún operator bóyá overlay náà tuntun ju baseline tó jókòó lé lórí lọ. A
tọ́jú àwọn méjèèjì sínú `radar_feed_cache`, a dá wọn padà nípasẹ̀ `getRadarCatalog().meta`, a sì
jábọ̀ wọn lọ́tọ̀ọ̀tọ̀ nípasẹ̀ `GET /api/radar/status`. Row tí a fi sínú cache kí column `generated_at` tó
wà (migration 163) ni a kà padà gẹ́gẹ́ bí `null` — ohun àìmọ̀ ṣì jẹ́ àìmọ̀ dípò
kí ó yá àkókò gbigba náà. `radar_referrals_cache` ti pa `generated_at` tirẹ̀ mọ́ láti
migration 142.

Ìwọ̀n ìpìlẹ̀ version lókè ń fi `version` wé, kì í ṣe ọ̀kan nínú àwọn ọjọ́ náà.

Àlàfo méjì ṣì wà, a sì mọ̀ọ́mọ̀ fi wọ́n sílẹ̀: dashboard náà ṣì ń fi `Last fetched` nìkan hàn, nítorí náà kíka
ọjọ́ build níbẹ̀ nílò label tuntun (àti àwọn àkọsílẹ̀ locale 41 rẹ̀); àwọn cache offers àti intel
kò sì tọ́jú ọjọ́ build rárá, bí ó tilẹ̀ jẹ́ pé schema feed wọn ní ọ̀kan — nítorí náà `GET
/api/radar/status` yọ field náà kúrò fún àwọn méjèèjì dípò jíjá-bọ `null`
tí a lè kà sí "àìmọ̀".

### Ìmúdájú schema

A máa parse àwọn báìtì tí a gba sílẹ̀, a sì máa ṣàyẹ̀wò wọn pẹ̀lú `RadarFeedSchema`
(`src/lib/radar/feedSchema.ts`, schema Zod kan) **lẹ́yìn** ìṣàyẹ̀wò ìbuwọ́lu. Àìbámu
schema máa dá `{ status: "invalid_schema" }` padà, cache náà kò sì ní
yípadà. A tún máa ṣàyẹ̀wò paylọ́ọ̀dù inú cache lọ́nà ààbò ní gbogbo ìgbà tí a bá kà á
(`getRadarCatalog()`) — row cache tó bàjẹ́ tàbí tí a fi ọwọ́ ṣàtúnṣe máa padà sí
baseline dípò kí a fi í ránṣẹ́.

### Òpin ìwọ̀n ìdáhùn (10 MB)

`syncRadar()` fi **òpin líle 10 MB** lélẹ̀ lórí ara ìdáhùn feed — feed tí a
buwọ́lu jẹ́ ìwé JSON tó tó KB díẹ̀, nítorí náà ohunkóhun tó bá kọjá èyí tọ́ka sí
`RADAR_FEED_URL` tí a ṣètò lọ́nà tí kò tọ́ tàbí tó léwu (tàbí upstream tó ń fi ìdọ̀tí ránṣẹ́), kì í ṣe catalog tó bófin mu.
Ìmúlò òfin náà ní ìpele méjì:

1. Ìṣàyẹ̀wò àkọ́kọ́ `Content-Length` máa fò kọjá kíka ara náà pátápátá nígbà tí
   header náà bá ti sọ iye tó kọjá òpin.
2. Ìṣàyẹ̀wò àpapọ̀ tó ń lọ lọ́wọ́ nígbà kíka ara náà máa fi òpin náà múlẹ̀ kódà nígbà tí
   `Content-Length` kò bá sí tàbí tó sọ ìwọ̀n gidi kéré — a kò gbẹ́kẹ̀ lé header
   nìkan láé. Ṣíṣe concatenation àwọn chunk tí a kójọ pa àwọn báìtì gangan
   tí a nílò fún ìṣàyẹ̀wò ìbuwọ́lu Ed25519 lẹ́yìn náà mọ́.

Kíkọjá òpin náà máa dá `{ status: "too_large" }` padà, kò sì ní yí cache padà,
ní títẹ̀lé àpẹẹrẹ tí kì í ba data jẹ́ bí gbogbo ìkùnà sync yòókù
(`invalid_signature`, `invalid_schema`, `stale`).

## Àwọn ìpele: `community` àti `live`

Àwòrán feed náà ní ààyè `tier: "community" | "live"`, èyí tí iṣẹ́ feed ń pinnu **ní ẹ̀gbẹ́ olupèsè**
gẹ́gẹ́ bí ìbéèrè náà ṣe rí (wíwà àti ìfẹsẹ̀múlẹ̀ bọ́tìnnì alátìlẹ́yìn)
— oníbàárà kì í pinnu ìpele tirẹ̀ láé.

- **`community`** — àkójọ ọ̀fẹ́ tí ó pẹ́ sẹ́yìn ní nǹkan bí ọjọ́ 30 lẹ́yìn dátà tuntun
  jù lọ. Èyí ni ohun tí ìbéèrè tí kò ní ìjẹ́rìísí tàbí tí bọ́tìnnì rẹ̀ kò fẹsẹ̀múlẹ̀ ń gbà.
- **`live`** — àkójọ tuntun jù lọ, tí a ń pèsè fún àwọn ìbéèrè tí ó ní bọ́tìnnì
  alátìlẹ́yìn tó fẹsẹ̀múlẹ̀.

**Bọ́tìnnì alátìlẹ́yìn tí kò fẹsẹ̀múlẹ̀ tàbí tí ó ti parí máa sọ̀kalẹ̀ sí `community` — kì í
ṣe àṣìṣe láé.** Ọ̀nà ìṣiṣẹ́pọ̀ náà ń ṣe ìyàtọ̀ láàárín ìkùnà ìbùwọ́lù/àwòrán-ẹ̀rí/ẹ̀yà (gbogbo
rẹ̀ ṣeé mú padà bọ̀ sípò, gbogbo rẹ̀ kì í sì pa ipò tí a ti fi pamọ́ sínú cache run) àti àṣeyọrí `{ status:
"updated", version, tier }`. Kò sí ọ̀nà àṣìṣe pàtó sí ìpele kan tí oníbàárà nílò láti
bojútó.

### Ìpele tí a pèsè wá láti header ìdáhùn, kì í ṣe láti body tí a fọwọ́ sí

Ààyè `tier` inú **body** feed tí a fọwọ́ sí máa ń jẹ́ `"live"` nígbà gbogbo — iṣẹ́ feed ń fi
**ohun èlò méjì tí a fọwọ́ sí fún ẹ̀yà kọ̀ọ̀kan** jáde: live ní àwọn ìpolongo lọwọlọwọ nínú, community
sì yọ wọ́n kúrò. A fọwọ́ sí ohun èlò kọ̀ọ̀kan lórí àwọn byte gangan tirẹ̀. Body náà kò tíì
jẹ́ ibi tí a ti ń pinnu ẹ̀tọ́ ìráyè; ìpele tí a yàn ní tòótọ́ fún ìbéèrè kan wà
nínú **header ìdáhùn `x-omniroute-feed-tier`**, tí a pinnu ní ẹ̀gbẹ́ olupèsè láti inú bọ́tìnnì
`Authorization` ìbéèrè náà.

`syncRadar()` (`src/lib/radar/sync.ts::parseServedTierHeader()`) ni ibi kan ṣoṣo
tí ó ń pinnu ìpele tí oníbàárà yẹ kí ó gbẹ́kẹ̀ lé:

1. Ṣàtúpalẹ̀ `x-omniroute-feed-tier` pẹ̀lú `RadarTierSchema` (Zod) — header tí kò sí, tàbí
   iye tí kì í ṣe `"community"` tàbí `"live"` ní pàtó, ni a kà sí **èyí tí kò
   sí** (a kì í gbẹ́kẹ̀ lé e láti fi sínú cache/UI bí ó ṣe rí; èyí tún kan àwọn olupèsè feed
   àtijọ́ tí ó ti wà ṣáájú header náà).
2. Lo ààyè `tier` inú body tí a fọwọ́ sí (tí ó máa ń jẹ́ `"live"` nígbà gbogbo) gẹ́gẹ́ bí àfẹ́yinti nígbà tí ìgbésẹ̀ 1
   kò bá mú nǹkan kan jáde.
3. Ìpele tí a pinnu ni a máa fi pamọ́ sínú cache tí a sì dá padà gẹ́gẹ́ bí `{ status: "updated",
version, tier }` — iye yìí ni dashboard ń fi hàn, kì í ṣe ààyè body àìṣe
   àtúnṣe.

## Àwọn òfin ìdàpọ̀ overlay ní àkókò kíkà

`applyFeed()` (`src/lib/radar/applyFeed.ts`) ń da feed tí a fi pamọ́ sínú cache pọ̀ **lórí** ìpìlẹ̀
àìyípadà ní **àkókò kíkà**, nínú `getRadarCatalog()`. A kì í ṣe àtúnṣe sí array ìpìlẹ̀
(`FREE_MODEL_BUDGETS`) láé — a ń ṣe ìṣírò `MergedEntry[]` tuntun ní gbogbo
ìpè.

Àwọn òfin mẹ́rin, ní ìtòlẹ́sẹẹsẹ agbára wọn:

1. **Feed kì í kọ àtúnṣe abẹ́lé bò láé.** Fún ààyè kọ̀ọ̀kan: bí olùdarí bá ti
   ṣe àtúnṣe ààyè kan lórí àkọsílẹ̀ kan (map `localOverrides`, tí kọ́kọ́rọ́ rẹ̀ jẹ́ `provider:modelId`),
   a ó fo iye feed fún ààyè pàtó yẹn — iye olùdarí ló borí.
2. **`enabled: false` ń pa àkọsílẹ̀ náà, pẹ̀lú ìtọ́kasí orísun.** Àkọsílẹ̀ feed tí ó pa
   àkọsílẹ̀ kan yóò ṣètò `enabled: false` àti `disabledBy: "radar"` lórí àbájáde tí a dapọ̀,
   kí UI lè ṣàlàyé _ìdí_ tí àkọsílẹ̀ kan fi yí padà láti wà lárọ̀ọ́wọ́tó sí pípa.
3. **Àkọsílẹ̀ tí aṣàmúlò fi kún un tí kò sí nínú feed yóò wà láìyípadà.** Àwọn àkọsílẹ̀ tí
   ó wà nínú ìpìlẹ̀ nìkan (tàbí tí a fi kún un ní abẹ́lé) tí kò sì ní àkọsílẹ̀ feed tó bá wọn mu
   yóò kọjá lọ láìyípadà.
4. **A kì í mú àkọsílẹ̀ tí a ti fi tombstone sí jí dìde láé.** Bí olùdarí bá pa
   àkọsílẹ̀ kan ní pàtó (set `tombstones`), bí feed bá tún fi `provider:modelId` yẹn kún un nínú ẹ̀yà
   tó tẹ̀ lé e, kò ní mú un padà.

Àwọn ààyè tí a lè ṣàtúnṣe àti tombstones ni a fi pamọ́ sínú
`radar_local_model_state` (migration `153_radar_local_model_state.sql`). Adapter DB gbogbogbò
(`src/lib/db/radar.ts`) ń yí àwọn row wọ̀nyẹn padà sí map `localOverrides` àti set
`tombstones` tí `applyFeed()` ń lò; `getRadarCatalog()` ìṣelọ́pọ̀ máa ń kó ipò yẹn wọlé
lẹ́yìn tí àwọn ìdènà flag, cache, àti schema bá kọjá. `displayName` àti `enabled` nìkan ni
olùdarí lè ṣàtúnṣe. A kò lè kọ ìdánimọ̀ provider/model, ìtọ́kasí orísun feed, quota, capabilities, ToS,
àti dátà ìṣètò nípasẹ̀ ojú-ọ̀nà yìí.

Dashboard náà ní àwọn ìgbésẹ̀ abẹ́lé mẹ́rin:

- **Ṣàtúnṣe** ń yí orúkọ ìfihàn abẹ́lé àti ipò ìmúṣiṣẹ́ padà.
- **Tun àwọn àyípadà abẹ́lé ṣe** ń pa àwọn ààyè méjèèjì tí a lè ṣàtúnṣe rẹ́ láìyí tombstone padà.
- **Fi pamọ́** ń ṣẹ̀dá tombstone, kí àwọn ìmúdójúìwọ̀n feed tó bá wáyé lẹ́yìn náà má bàa lè tún row náà ṣẹ̀dá.
- **Mú padà** ń yọ tombstone kúrò; àtúnṣe èyíkéyìí tí a fi pamọ́ lọ́tọ̀ ṣì máa ń ṣiṣẹ́.

Feed `enabled: false` ṣì jẹ́ ààyè àyọkà ààbò: ó máa ń borí `enabled: true` abẹ́lé tí ó ti di
àtijọ́, ó ń jẹ́ kí àkọsílẹ̀ tí a dapọ̀ náà wà ní pípa, ó sì ń ṣàkọsílẹ̀ `disabledBy: "radar"`.

Àwọn ìtẹ̀jáde àkójọ ń lo `schemaVersion: 2`. `contextWindow` àti ọ̀kọ̀ọ̀kan nínú `tools`, `vision`, àti
`thinking` jẹ́ `number | null` / `boolean | null` lọ́tọ̀ọ̀tọ̀: `null` túmọ̀ sí àìmọ̀, nígbà tí
`false` túmọ̀ sí pé orísun provider oníṣẹ́ tí D16 fìdí rẹ̀ múlẹ̀ sọ ní pàtó pé capability náà kò sí.
A kì í gbé àwọn flag registry/model-spec OmniRoute inú lọ́nà tààrà sí ipò àwọn òtítọ́ feed láé. Oníbàárà
ṣì ń gba àwọn snapshot v1; nítorí builder àtijọ́ lo `false` gẹ́gẹ́ bí ààmì àìsí, a ń ṣe normalization v1 `false` sí àìmọ̀ nígbà tí v1 `true` ṣì jẹ́ òtítọ́. Àwọn ẹ̀yà schema àìmọ̀ máa ń kùnà lọ́nà tí ó di ohun gbogbo, cache tó fẹsẹ̀múlẹ̀ kẹ́yìn sì máa ń wà lárọ̀ọ́wọ́tó. Gbogbo model v2 tí ó ní context/capability tí kì í ṣe null gbọ́dọ̀ ní
`metadataEvidenceUrls[]` HTTPS tí kò nílò credential; bí bẹ́ẹ̀ kọ́, ìfẹsẹ̀múlẹ̀ schema yóò kùnà, a kò sì ní
rọ́pò cache náà. Tábìlì àkójọ ń fi gbogbo ipò mẹ́tẹ̀ẹ̀ta hàn gẹ́gẹ́ bí `✓`, `✕`, àti `?`.

### Àwọn combo ìtọ́sọ́nà àti ìráyè MCP

Àwọn iye `familyId` tí a ti fìdí rẹ̀ múlẹ̀ yóò la overlay àkókò kíkà já, wọn yóò sì darí module mímọ́
`buildRadarComboSuggestions()` (`src/lib/radar/comboSuggestions.ts`). A máa dábàá family kan
nígbà tí ó kéré tán provider ọ̀tọ̀ọ̀tọ̀ méjì bá ní àwọn connection tó ń ṣiṣẹ́ tí wọ́n sì ń ṣí model
ID tí a ti yan ní pàtó síta. Àwọn model tí a pa, àwọn provider tí kò ṣiṣẹ́, model ID tí kò sí, àwọn family tó ní ọ̀kan ṣoṣo, àti àwọn
ìbámu alias/prefix tí kò ṣe kedere máa ń kùnà lọ́nà tí ó di ohun gbogbo. Àwọn àbá máa ń lo strategy `priority` tó ti wà tẹ́lẹ̀, nípa títò
budget oṣooṣù tó ń wáyé léraléra tó tóbi jù lọ síwájú; UI máa ń ṣẹ̀dá wọn nípasẹ̀ `POST /api/combos` nìkan.

UI ìtọ́nisọ́nà náà wà ní `/dashboard/radar/combos`. Ó ń ka àwọn endpoint abẹ́lé
`GET /api/radar/catalog` àti `GET /api/combos/builder/options` nìkan. Kò máa ń ṣe ìmúdójúìwọ̀n Radar,
ka àwọn ẹ̀rí ìdánimọ̀ olùpèsè, tàbí kọ ohun kan tààrà sínú ibi ìpamọ́ dátà combo.

Àwọn oníbàárà MCP lè ka àfihàn abẹ́lé kan náà pẹ̀lú `omniroute_radar_catalog` (`read:radar`). Àwọn
àsẹ̀ àṣàyàn `provider`, `familyId`, àti `enabledOnly` ni a máa ń ṣàyẹ̀wò lẹ́yìn kíkà
`GET /api/radar/catalog` abẹ́lé lẹ́ẹ̀kan. Àbájáde tó ní ààlà rẹ̀ ní metadata catalog àti provider/model,
orúkọ àfihàn, `familyId`, quota, àwọn agbára, ipò ìmúlò, origin, àti `disabledBy`; àwọn URL ìṣètò,
àwọn ìgbésẹ̀, àwọn ìsopọ̀, àwọn àdírẹ́sì í-meèlì, àwọn kọ́kọ́rọ́, àti dátà ìtọ́kasí ni a kì í dá padà láé. Irinṣẹ́ yìí
jẹ́ fún kíkà nìkan, kò sì máa ń pe `/api/radar/sync` láé.

### Àwọn àmì orísun

Gbogbo àkọsílẹ̀ tí a dapọ̀ ní field `origin` kan tí UI ń ṣàfihàn gẹ́gẹ́ bí badge:

- `"baseline"` — kò yí padà láti inú catalog release aláìyípadà.
- `"radar"` — field kan tàbí jù bẹ́ẹ̀ lọ ni feed ti ṣe ìmúdójúìwọ̀n.
- `"local"` — olùṣàkóso ní ó kéré tán override abẹ́lé kan lórí àkọsílẹ̀ yìí (àwọn
  override abẹ́lé máa ń borí feed ní gbogbo ìgbà gẹ́gẹ́ bí òfin 1, láìka ohun tí feed sọ sí).

| `/api/radar/settings`          | POST   | Ó ṣètò ìfọwọ́sí àti/tàbí supporter key (tí a ti paroko).                                                                        |

server OmniRoute abẹ́lé nìkan sọ̀rọ̀. Àwọn module mẹ́rin tó ní ìbáṣepọ̀ pẹ̀lú iṣẹ́ Radar ni
`src/lib/radar/sync.ts` (katalogi), `src/lib/radar/referralsSync.ts` (referrals), àti
`src/lib/radar/offersSync.ts` (offers), pẹ̀lú `src/lib/radar/intelSync.ts` (Intel); gbogbo wọn ń ṣiṣẹ́
ní ẹ̀gbẹ́ server, kì í ṣe ní ẹ̀gbẹ́ client láéláé. Èyí mú kí
URL ìṣàn àti supporter key èyíkéyìí má hàn rárá nínú traffic network tó dojú kọ client.

Gbogbo endpoint Radar máa ń dá `404` padà nígbà tí `RADAR_ENABLED` bá wà ní pípa (wo
[Flag](#flag-radar_enabled-default-off) lókè), wọ́n sì ń darí àwọn response error nípasẹ̀
`buildErrorBody()`/`sanitizeErrorMessage()` gẹ́gẹ́ bí òfin ìwẹ̀nùmọ́ error tó kan gbogbo repo
(`docs/security/ERROR_SANITIZATION.md`).

### Ìfàṣẹsí

Gbogbo endpoint Radar nílò ìfàṣẹsí nípasẹ̀ `isAuthenticated()`
(`src/shared/utils/apiAuth.ts`) — cookie session dashboard tàbí API key tí scope rẹ̀ jẹ́ management,
ẹnu-ọ̀nà kan náà tó ń dá àwọn apá `/api/settings/*` yòókù láàbò. Àyẹ̀wò `404`
nígbà tí flag bá wà ní pípa máa ń ṣiṣẹ́ **ṣáájú** àyẹ̀wò auth nígbà gbogbo, nítorí náà installation kan tí `RADAR_ENABLED`
wà ní pípa máa ń jẹ́ byte-identical (kò sí ìbéèrè auth kìkì láti mọ̀ pé ojú-ọ̀nà náà kò sí);
ní kété tí flag bá ti wà ní titan, ìbéèrè tí kò ní ìfàṣẹsí máa gba `401` ṣáájú kí kíkà tàbí
kíkọ DB èyíkéyìí tó wáyé. `GET /api/radar/settings` kì í dá supporter key gidi padà láéláé láìka
ipò auth sí — fọ́ọ̀mù tí a ti bò nìkan àti boolean `hasSupporterKey` ni ó máa ń dá padà.

## Àwọn ìfilọ́lẹ̀ alátìlẹ́yìn

Àwọn ìfilọ́lẹ̀ máa ń lo artifact tí a fọwọ́sí tirẹ̀, `GET /v1/offers/latest`, wọn kì í sì í pín catalog tàbí cache referrals láé. Endpoint server náà nílò kọ́kọ́rọ́ Bearer alátìlẹ́yìn live tó péye; kò sí ìpadà-sẹ́yìn sí community. Nítorí náà, `syncRadarOffers()` máa ń dáwọ́ dúró kí ó tó dé network nígbà tí feature flag bá wà ní pípa, tí operator kò bá tíì yọ̀ǹda láti kópa, tàbí tí kò bá sí kọ́kọ́rọ́ alátìlẹ́yìn tí a ṣètò.

Lẹ́yìn GET tó ṣàṣeyọrí, client náà máa ń ṣàyẹ̀wò signature Ed25519 lórí response bytes náà gan-an, ó máa ń fìdí `RadarOffersFeedSchema` múlẹ̀, ó sì ń béèrè pé kí signed body àti header `x-omniroute-feed-tier` sọ `live`, ó ń fipá mú dotted version tuntun gidi, lẹ́yìn náà nìkan ló tó rọ́pò `radar_offers_cache` ní ọ̀nà atomic (migration `144_radar_offers_cache.sql`). Ààlà 10 MB kan náà fún header-pẹ̀lú-stream tí àwọn feeds yòókù ń lò náà kan án. Àwọn ìkùnà signature, schema, tier, replay, size, HTTP, àti network máa ń pa cache tí a fìdí rẹ̀ múlẹ̀ kẹ́yìn mọ́.

Ìrísí offer tí a ti pa mọ́ náà ṣe àtìlẹ́yìn fún oríṣi benefit mẹ́ta tí a lè fi wé ara wọn: percentage nínú basis points, credit nínú minor currency units, tàbí trial days. Offer partner kan gbọ́dọ̀ ní public baseline irú kan náà, benefit rẹ̀ sì gbọ́dọ̀ ga ju tirẹ̀ lọ ní kíkún; àwọn official offers kò ní partner baseline. Àwọn URLs gbọ́dọ̀ jẹ́ HTTPS tí kò ní credentials. `getRadarOffers()` máa ń tún cached payload náà fìdí múlẹ̀ fún ààbò, ó sì ń yọ àwọn entries tí àkókò wọn ti parí kúrò ní gbogbo local read; `/dashboard/radar/offers` tún máa ń yọ àwọn tí àkókò wọn ti parí kúrò kí rendering tó bẹ̀rẹ̀, ó máa ń lo ọ̀rọ̀ Portuguese nígbà tí ó bá wà pẹ̀lú English gẹ́gẹ́ bí fallback, ó sì máa ń fi àmì sí partner offers ní kedere.

Browser náà ń pe local routes nìkan: ó máa ń ka masked settings snapshot, ó béèrè lọ́wọ́ `POST /api/radar/offers/sync` láti ṣe refresh ní server-side, lẹ́yìn náà ó máa ń ka `GET /api/radar/offers`. Láìsí kọ́kọ́rọ́, ó máa ń fi contributor/support links tó ti wà tẹ́lẹ̀ hàn dípò gbígbìyànjú feed request. Àwọn external offer links máa ń ṣí nínú tab tuntun pẹ̀lú `noopener noreferrer`. Kò sí MCP tool `radar_offers` tí a ṣí síta nínú release yìí.

## Radar Intel, badge alátìlẹ́yìn, àti CLI

Intel jẹ́ artifact tí a fọwọ́sí ní `GET /v1/intel/latest`. `RadarIntelFeedSchema` tí a ti pa mọ́ gba àwọn ELO rankings tí Radar ní nìkan, èyí tí private curator yọ jáde láti inú confirmed comparisons àti factual catalog age/count deltas tí a yọ láti inú signed catalog snapshots. Methodology náà dúró ṣinṣin ní initial rating 1000 àti K=32. Ranking òfìfo jẹ́ èyí tó péye nígbà tí kò bá sí comparison tí a ti fìdí múlẹ̀; client náà kì í ṣẹ̀dá ọ̀kan fúnra rẹ̀ láé.

`syncRadarIntel()` máa ń lo Bearer server-side kan náà, timeout ìṣẹ́jú-àáyá 30, streamed cap 10 MiB, exact-byte Ed25519 verification, strict schema, ìbéèrè body/header `live`, version floor, àti pípa last-good-cache mọ́ bí offers. Lẹ́yìn tí a bá ti fi verified live snapshot pamọ́, client náà máa ń yọ `radar:<sha256(supporter key)>` jáde, ó máa ń tọ́jú one-way identity yẹn nìkan, ó sì ń ṣe ìjáde dedicated recognition event `radar_supporter`. Badge `radar-supporter` rẹ̀ jẹ́ idempotent, ó sì ń fúnni ní XP òdo; kò ṣe update leaderboards láé, bẹ́ẹ̀ ni kò tún lo `token_share`. `/dashboard/radar/intel` máa ń render badge náà láti inú verified local cache metadata nìkan.

CLI náà ṣí `omniroute radar status` àti `omniroute radar sync` síta. Àwọn méjèèjì ń bá local OmniRoute API nìkan sọ̀rọ̀. `status` máa ń ṣe read-only `GET /api/radar/status`; `sync` máa ń fi `POST /api/radar/sync-all` kan ránṣẹ́, ó sì ń tẹ result jáde fún feed kọ̀ọ̀kan. Kò sí èyíkéyìí nínú àwọn command náà tó ń ka, gba, tàbí tẹ kọ́kọ́rọ́ alátìlẹ́yìn jáde, bẹ́ẹ̀ ni kò sí èyíkéyìí tó ń kàn sí Radar service ní tààrà.

## Àwọn ọ̀nà asopọ ìtọ́kasí (kírẹ́díìtì ọ̀fẹ́)

A ń pèsè àwọn ọ̀nà asopọ ìtọ́kasí láti inú ìṣàn **adádúró, tí ó máa ń jẹ́ tuntun nígbà gbogbo** —
`GET /v1/referrals/latest` — tí ó yàtọ̀ sí ìṣàn kátálọ́ọ̀gù. Èyí jẹ́ àmọ̀ọ́mọ̀: ìṣàn
kátálọ́ọ̀gù lórí ipele àwùjọ jẹ́ àwòrán-àkókò tí ó lè ti pé tó ọjọ́ 30, nítorí náà,
ọ̀nà asopọ ìtọ́kasí tí a yọ jáde láti inú rẹ̀ máa ń pẹ́ sẹ́yìn àkójọ ọ̀nà asopọ gidi ti
sáfà fún iye àkókò kan náà (ìtọ́kasí tí a ṣẹ̀ṣẹ̀ ṣàfikún kò ní dé ọ̀dọ̀ aṣàmúlò
ọ̀fẹ́/àwùjọ fún àkókò tó lè tó oṣù kan). Ìṣàn àwọn ìtọ́kasí ń mú ìdádúró yẹn kúrò nípa
mímúṣiṣẹ́pọ̀ lórí ìgbàkígbà tirẹ̀, tí ó kúrú púpọ̀ sí i.

```ts
// Ara ìdáhùn GET /v1/referrals/latest (tí Ed25519 fọwọ́ sí, kọ́kọ́rọ́ àdìmọ́ kan náà bí
// ìṣàn kátálọ́ọ̀gù):
{
  feed: "omniroute-radar-referrals",
  schemaVersion: 1,
  generatedAt: string,           // ISO — tí ó ṣeé pinnu: max(updatedAt) káàkiri àwọn ọ̀nà
                                  // asopọ ìtọ́kasí, kí ìbéèrè méjì tí ó jọra lè ṣe àwọn báìtì/
                                  // ìfọwọ́sí kan náà gan-an
  referrals: {
    fixed: RadarReferral[],      // wà ní GBOGBO ipele, pẹ̀lú àìsí-àṣẹ/àwùjọ
    campaigns: RadarReferral[],  // a kún un fún kọ́kọ́rọ́ Bearer aláàyè tí ó bófin mu
                                  // (alátìlẹ́yìn) nìkan; ìbéèrè àìsí-àṣẹ/kọ́kọ́rọ́-tó-parí gba []
  },
}
// RadarReferral = { provider, url, kind: "fixo" | "campanha", validUntil,
//                    requiredAction, isDefault }
```

Ní ìyàtọ̀ sí ìṣàn kátálọ́ọ̀gù, ara yìí kò ní ààyè `tier` rárá — sáfà ni ó ń pinnu
ohun tí yóò fi sínú ìbéèrè kọ̀ọ̀kan ní ìbámu pẹ̀lú kọ́kọ́rọ́ `Authorization`, nítorí náà
àkọlé ìdáhùn `x-omniroute-feed-tier` nìkan ni orísun ipele tí a pèsè
(`referralsSync.ts::syncRadarReferrals`); àkọlé tí kò sí/tí a kò mọ̀ yóò dínkù sí
`"community"`, ìròyìn àìní-àṣẹ jù lọ. `RadarReferralsFeedSchema`
(`src/lib/radar/referralsFeedSchema.ts`) ń fìdí gbogbo ara múlẹ̀, nípa tún lílo
`RadarReferralSchema` kan náà fún ìtọ́kasí kọ̀ọ̀kan tí a kó jáde láti `feedSchema.ts`,
kí ìṣàn méjèèjì lè fìdí ìtọ́kasí kọ̀ọ̀kan múlẹ̀ lọ́nà kan náà. Gbogbo
`RadarReferral.url` gbọ́dọ̀ jẹ́ `https://` — url `http://` yóò kùnà ìfìdímúlẹ̀ schema.

A pa ààyè `referrals` ATIJỌ́ tí ó wà nínú kátálọ́ọ̀gù lórí `RadarFeedSchema`
(`feedSchema.ts`) mọ́ fún ìbámu-pẹ̀lú-ẹ̀yìn pẹ̀lú àwọn ìṣàn kátálọ́ọ̀gù tí a ti fi pamọ́
sínú cache tẹ́lẹ̀, ṣùgbọ́n `getRadarReferrals()` kò ka a mọ́ — wo
[Olùráàyèsí](#accessor) nísàlẹ̀.

### Ìmúṣiṣẹ́pọ̀

`syncRadarReferrals()` (`src/lib/radar/referralsSync.ts`) ni module NÌKAN tí ó
ń wọ nẹ́tíwọ́ọ̀kì fún àwọn ìtọ́kasí, tí ó ń fara wé àdéhùn `syncRadar()` pátápátá:
àsíá wà ní pípa → `disabled`; ìfàyègba jẹ́ irọ́ → `opt_out`; ó ń gba
`${RADAR_FEED_URL}/v1/referrals/latest` sílẹ̀ (àwọn àtúnṣe oríta
`RADAR_FEED_URL`/`RADAR_FEED_PUBKEY` kan náà bí ti kátálọ́ọ̀gù), ó ń ṣàyẹ̀wò ìfọwọ́sí
Ed25519 lórí àwọn báìtì ìdáhùn gan-an (`verifyFeedBytes`), ó ń fìdí rẹ̀ múlẹ̀ pẹ̀lú
`RadarReferralsFeedSchema`, ó sì ń fi pamọ́ sínú tábìlì `radar_referrals_cache`
(ìṣíkiri `142_radar_referrals_cache.sql`) — tábìlì tí ó yà pátápátá sí
`radar_feed_cache` ti kátálọ́ọ̀gù. Òpin ìdáhùn 10 MB àti ààlà ìsàlẹ̀ `generatedAt`
ń kọ ìṣàn tó ń wọlé tí ó ti dàgbà ju èyí tí ó wà nínú cache lọ, láti dáàbò bo lòdì sí
àtúnṣe àfihàn ohun-ẹ̀rí tí a ti fọwọ́ sí tó ti pẹ́. A gba àmì-àkókò tí ó dọ́gba:
sáfà mọ̀ọ́mọ̀ ń fún àwùjọ àti àwọn ẹ̀yà ìtọ́kasí aláàyè ní `generatedAt` kan náà tí
ó ṣeé pinnu, nítorí náà payload tí a fọwọ́ sí àti ipele tí a pèsè lè yí padà lẹ́yìn
àtúnṣe kọ́kọ́rọ́ alátìlẹ́yìn láìsí ìyípadà sí àkójọpọ̀ ọ̀nà asopọ abẹ́lẹ̀.
Kì í ju àṣìṣe síta láé — ó máa ń dá ohun ipò padà nígbà gbogbo; àwọn àṣìṣe kì í ní
àtẹ̀jáde stack nínú `reason`.

Àwọn okunfa méjì ń jẹ́ kí cache àwọn ìtọ́kasí máa gbóná, àwọn méjèèjì sì dúró lọ́tọ̀
kúrò ní ìgbàkígbà 24h ti kátálọ́ọ̀gù:

- **Ìmúṣiṣẹ́pọ̀-nígbà-kíkà** — `GET /api/radar/referrals` fúnra rẹ̀ ń pe
  `syncRadarReferrals()` lẹ́sẹ̀kẹsẹ̀ nígbàkigbà tí cache kò bá sí tàbí tí ó bá ti dàgbà
  ju `REFERRALS_STALE_MS` (1h, `shouldSyncReferralsOnRead()`), kí ó tó pèsè ìdáhùn.
  Èyí ni ó ń jẹ́ kí àwọn ọ̀nà asopọ tó dúró ṣinṣin jẹ́ “tuntun nígbà gbogbo” fún
  ìgbà tí dashboard bá tún kó lẹ́sẹ̀kẹsẹ̀, láìdúró de aago abẹ́lẹ̀ kankan.
- **Ìmúṣiṣẹ́pọ̀-ẹgbẹ́ olùṣètò** — `radarSchedulerTick()` (`scheduler.ts`) ń ṣe àyẹ̀wò
  lọ́tọ̀ síra bóyá àwọn ìtọ́kasí ti pẹ́ lórí ìlù-àkókò oníwákàtí kan náà tí kátálọ́ọ̀gù
  ń lò, nípa pípe `syncRadarReferrals()` nígbà tí àkókò bá tó. Èyí ń ṣiṣẹ́ láìka bóyá
  àkókò kátálọ́ọ̀gù fúnra rẹ̀ tó ní ìlù-àkókò yẹn, kò sì ní ipa lórí ìrísí
  `RadarTickResult` láé (ipa ẹgbẹ́ ìsapá-tí-ó-dára-jù nìkan, tí a ń gbé mì nígbà àṣìṣe).

### Olùráàyèsí

`src/lib/radar/index.ts` ń kó àwọn olùráàyèsí kíkà-nìkan méjì jáde, àwọn méjèèjì kì í
ju àṣìṣe síta láé (àdéhùn ààbò kan náà bí `getRadarCatalog()` — àsíá ní pípa, àìsí
cache, tàbí payload cache tó bàjẹ́, gbogbo wọn ń yọrí sí ìrísí òfo dípò àṣìṣe):

- `getRadarReferrals()` → `{ fixed: RadarReferral[], campaigns: RadarReferral[] }`,
  tí ó ń kà láti `radar_referrals_cache` (nípasẹ̀ `getRadarReferralsCache()`) tí ó sì
  ń fìdí rẹ̀ múlẹ̀ nípasẹ̀ `RadarReferralsFeedSchema` — **kì í ṣe** cache kátálọ́ọ̀gù.
- `getDefaultReferralFor(provider)` → ìtọ́kasí `fixed` pẹ̀lú `isDefault: true` fún
  provider yẹn, tàbí `null`. Ó ń wo `fixed` nìkan — a kì í lo ìpolongo gẹ́gẹ́ bí
  ọ̀nà asopọ “àkóbá” provider kan láé.

Òfin gidi fún “ìtọ́kasí wo ni àkóbá fún provider kan” wà nínú
`findDefaultReferral()` (`src/lib/radar/referrals.ts`), function pure kékeré kan tí
**kò ní import DB** — ó bójú mu láti import rẹ̀ sínú component `"use client"` kan.
`getRadarReferrals`/`getDefaultReferralFor` (nínú `index.ts`) ń fa
`@/lib/db/radar` wọlé, nítorí náà wọ́n wà fún sáfà-nìkan; dashboard àwọn provider
ń import `referrals.ts` tààrà dípò `index.ts` (wo nísàlẹ̀) láti yẹra fún fífi
`better-sqlite3` sínú bundle aṣàwákiri.

### `GET /api/radar/referrals`

Tẹ̀lé ìtòlẹ́sẹẹsẹ ìdènà kan náà gẹ́gẹ́ bí gbogbo ọ̀nà Radar mìíràn: `RADAR_ENABLED` ti wa ni pipa →
`404` (a ṣàyẹ̀wò rẹ̀ lákọ̀ọ́kọ́, ìdúróṣinṣin tó báyìí dé báyìí ní ìpele báìtì); ẹni tí kò jẹ́rìí ìdánimọ̀ → `401`; bí kò ṣe bẹ́ẹ̀,
ó máa ń fa ìmúdójúìwọ̀n-lórí-kíkà (wo òkè) nígbà tí dátà bá ti pẹ́, lẹ́yìn náà `200` pẹ̀lú
`{ fixed, campaigns, tier }` — `tier` wá tààrà láti ìlà cache (tó ṣeé ṣe kí a ṣẹ̀ṣẹ̀ sọ di tuntun)
ó sì jẹ́ fún ìfitonilétí nìkan (ó ń darí ọ̀rọ̀ ìpolówó-rọ́rọ́ UI tó wà nísàlẹ̀). Kò ṣe
àṣojú sí olupin feed tààrà láéláé — source ti route náà kò ní ìpè `fetch(` kankan;
nẹ́tíwọ́ọ̀kì máa ń ṣẹlẹ̀ nínú `syncRadarReferrals()` nìkan, ní ìbámu pẹ̀lú ìlànà
cache-agbègbè-nìkan kan náà bí `/api/radar/catalog`.

### UI Dashboard — taabu "Kirẹ́díìtì ọ̀fẹ́" lórí `/dashboard/radar`

Ó tún ojú-ewé Radar tó ti wà (`src/app/(dashboard)/dashboard/radar/page.tsx`) lò gẹ́gẹ́ bí
taabu kejì dípò route tuntun — èyí dín ibi tí routing/i18n gbọ́dọ̀ dé kù fún ẹ̀ya kan tó jẹ́
àtúnṣe lórí dátà tí ojú-ewé náà ti ń gbà tẹ́lẹ̀. Lẹ́yìn tí a bá forúkọ sí i, ọ̀pá taabu náà ń fúnni ní
**Kátálọ́ọ̀gù** (tábìlì tó ti wà) àti **Kirẹ́díìtì ọ̀fẹ́**:

- Àwọn link tí kò yí padà ni a ṣọ̀kan gẹ́gẹ́ bí olùpèsè, ọ̀kọ̀ọ̀kan sì ń fi `requiredAction` hàn (nígbà tí ó bá wà)
  àti bọ́tìnì `target="_blank" rel="noopener noreferrer"` sí URL referral náà.
- Àwọn campaign ń fi ohun kan náà hàn, pẹ̀lú `validUntil` nígbà tí ó bá wà.
- Nígbà tí `campaigns` bá ṣófo **tí** tier tí a pèsè sì jẹ́ `community`, UI náà máa fi
  àkíyèsí ìpolówó-rọ́rọ́ kékeré hàn ("àwọn campaign àkókò-kúkúrú jẹ́ àfikún fún olùtìlẹ́yìn") — èyí **kò**
  fi àtòjọ link tí kò yí padà pamọ́ tàbí dí i lọ́nà kankan, torí pé ó máa ń kún fún gbogbo tier. Ìpolówó náà
  jẹ́ ìfiránṣẹ́ rọ́rọ́ nìkan, kì í ṣe ìdènà láéláé.

### Link referral lórí orúkọ olùpèsè (dashboard àwọn olùpèsè)

`ProviderPageHeader` (`src/app/(dashboard)/dashboard/providers/[id]/components/`)
ti so orúkọ olùpèsè pọ̀ mọ́ `providerInfo.website` tẹ́lẹ̀ nígbà tí ó bá wà, pẹ̀lú
àpẹẹrẹ kan fún link tí ń wọlé fúnni: àkíyèsí partner-link Kimi (Moonshot AI)
(kọ́kọ́rọ́ i18n `providers.kimiPartnerLinkNote`). D28 tún lo àpẹẹrẹ àkíyèsí aláìfara-hàn
kan náà pátápátá fún àwọn referral àìyípadà Radar dípò kí ó dá kọ́kọ́rọ́ tuntun sílẹ̀.

Ìsopọ̀ tí kò le, gẹ́gẹ́ bí a ṣe ṣe é mọ́ọ̀mọ́:

- `resolveProviderHeaderLink()` (`src/app/(dashboard)/dashboard/providers/providerPageUtils.ts`)
  jẹ́ iṣẹ́ **mímọ́** — `(staticWebsite, referralUrl) => { website, isReferralLink }`
  — láìsí ìgbẹ́kẹ̀lé lórí `@/lib/radar` tàbí `@/lib/db/*`. `providerPageUtils.ts` lápapọ̀
  kò ní àwọn import wọ̀nyẹn (gẹ́gẹ́ bí
  `tests/unit/provider-header-referral-link.test.ts` ṣe fìdí rẹ̀ múlẹ̀).
- `ProviderDetailPageClient.tsx` (component `"use client"`) ni ibi kan ṣoṣo tí a gbà láàyè
  láti gba dátà Radar — nípasẹ̀ `fetch("/api/radar/referrals")`, àpẹẹrẹ route-agbègbè
  kan náà tí ojú-ewé dashboard Radar fúnra rẹ̀ ń lò — ó sì ń ṣírò referral àìyípadà
  ní ẹ̀gbẹ́ client pẹ̀lú `findDefaultReferral()` láti `src/lib/radar/referrals.ts` tí kò ní DB.
- Nígbà tí `RADAR_ENABLED` bá wa ni pipa, fetch náà máa dá `404` padà, `referralUrl` máa dúró sí `null`, àti
  `resolveProviderHeaderLink()` máa dá `website` kátálọ́ọ̀gù àìyípadà padà láìyípadà — ojú-ewé
  olùpèsè náà jẹ́ báìtì-fún-báìtì kan náà bí ó ti rí kí ẹ̀ya yìí tó wà. Àbájáde kan náà ló máa ń ṣẹlẹ̀ nígbà
  tí cache kò tíì sí tàbí tí referral àìyípadà kò bá sí fún olùpèsè pàtó yẹn.
- Nígbà tí referral àìyípadà bá wúlò, `ProviderPageHeader` máa gba `isReferralLink`
  yóò sì fi àkíyèsí/tooltip aláìfara-hàn kan náà bíi link alábàáṣiṣẹ́ Kimi hàn (nípa títún lo
  kọ́kọ́rọ́ `providers.kimiPartnerLinkNote`) — kì í ṣe ìṣàfihàn tuntun, ọ̀tọ̀ láéláé.

## Bí a ṣe lè gbàlejò feed fúnra ẹni

Fork tàbí olùgbàlejò-fúnra-ẹni tí ó fẹ́ ní àkóso kíkún lórí katalogi lè ṣiṣẹ́ iṣẹ́
feed tirẹ̀ láìfọwọ́ kan kóòdù client:

1. Pèsè endpoint `GET /v1/catalog/latest` tí yóò dá body JSON padà tí ó bá
   `RadarFeedSchema` (`src/lib/radar/feedSchema.ts`) mu — `feed:
"omniroute-radar"` ní ipele òkè, `schemaVersion: 2`, `version`, `tier`, `providers`, `models`,
   `quirks`, àti `totals`. Bọ̀wọ̀ fún `x-omniroute-radar-schema: 2`; server tó bá ìyípadà mu
   gbọ́dọ̀ lo artifact v1 tí a fọwọ́sí lọ́tọ̀ gẹ́gẹ́ bí àiyípadà fún àwọn request tí kò ní í.
2. Fọwọ́sí àwọn byte response náà gan-an pẹ̀lú key pair Ed25519 kí o sì dá signature base64
   padà nínú header response `x-omniroute-feed-signature`.
3. Ṣètò `RADAR_FEED_URL` sí URL ìpìlẹ̀ tuntun àti `RADAR_FEED_PUBKEY` sí public key tó bá a mu
   (base64-DER SPKI tàbí PEM) — wo
   [ìtọ́kasí env var](../reference/ENVIRONMENT.md#27-radar-feed-self-hosting).
4. Mú `RADAR_ENABLED` ṣiṣẹ́ kí o sì yọ̀ǹda láti kópa nípasẹ̀ `POST /api/radar/settings`
   (`{ optIn: true }`).

Kò sí àyípadà kóòdù mìíràn tí a nílò — `verifyFeedBytes()` máa ń lo override náà
fúnra rẹ̀ (`getFeedPublicKeys()` nínú `src/lib/radar/pinnedKeys.ts`), àti ìfiwéra version,
ìfọwọ́sí schema, àti àwọn òfin merge máa ń ṣiṣẹ́ lọ́nà kan náà fún feed tí a gbàlejò
fúnra ẹni.

Àwọn link ìtọ́kasí (wo [Àwọn link ìtọ́kasí (kirẹditi ọ̀fẹ́)](#referral-links-free-credits)
lókè) jẹ́ artifact àṣàyàn ọ̀tọ̀: fork kan tí ó ń pèsè `/v1/catalog/latest` nìkan
sì tún máa ṣiṣẹ́ ní kíkún — `syncRadarReferrals()` máa dín kù sí `{ status: "error" }` lórí `404`
láti `/v1/referrals/latest`, cache náà yóò sì wà ní òfo, nítorí náà
`GET /api/radar/referrals` yóò máa dá `{ fixed: [], campaigns: [], tier: null }` padà
dípò kí ó mú kí ìyókù ojú-ìwé náà kùnà. Láti tún pèsè àwọn link ìtọ́kasí, pèsè
`GET /v1/referrals/latest` tí ó bá `RadarReferralsFeedSchema`
(`src/lib/radar/referralsFeedSchema.ts`) mu, kí o sì fọwọ́ sí i pẹ̀lú key pair Ed25519 kan náà bí
feed katalogi náà.

Àwọn offer fún alátìlẹ́yìn tún jẹ́ artifact àṣàyàn mìíràn. Láti pèsè wọn, ṣe
`GET /v1/offers/latest` pẹ̀lú `RadarOffersFeedSchema` tí a ti pa mọ́
(`src/lib/radar/offersFeedSchema.ts`), béèrè entitlement tó wà láàyè, dá
`x-omniroute-feed-tier: live` padà, kí o sì fọwọ́ sí àwọn byte náà gan-an pẹ̀lú key kan náà. Fork tí kò bá
fi endpoint yìí sílẹ̀ yóò jẹ́ kí ìhùwàsí katalogi/ìtọ́kasí má yí padà; ìmúdójúìwọ̀n offer yóò kùnà
láìba nǹkan jẹ́, cache offer agbègbè tó gbẹ̀yìn tí a fìdí rẹ̀ múlẹ̀ yóò sì ṣì wà fún lílò.

Intel jẹ́ àṣàyàn lọ́nà kan náà. Olùgbàlejò-fúnra-ẹni lè pèsè `GET /v1/intel/latest` ní lílo
`RadarIntelFeedSchema` (`src/lib/radar/intelFeedSchema.ts`), béèrè entitlement tó wà láàyè, dá
`x-omniroute-feed-tier: live` padà, kí o sì fọwọ́ sí àwọn byte náà gan-an pẹ̀lú key Ed25519 tí a jọ ń lò. Tí a kò bá
fi endpoint náà sílẹ̀, katalogi, àwọn ìtọ́kasí, àti àwọn offer kò ní yí padà; ìmúdójúìwọ̀n Intel yóò pa
snapshot agbègbè tó gbẹ̀yìn tí a fìdí rẹ̀ múlẹ̀ mọ́.
