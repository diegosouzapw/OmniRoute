> **Ní ṣókí**: `open-sse/` ni ẹ̀rọ ìṣànwọlé pàtàkì tó ń fún gbogbo ìbéèrè LLM ní OmniRoute lágbára. Ó ní nǹkan bí fáìlì 1,400 tó ń ṣe ìmúṣẹ ọ̀nà ìṣàn ìbéèrè, àwọn olùṣiṣẹ́, àwọn iṣẹ́, olupin MCP, àti fẹ́lẹ́fẹ́lẹ́ ìtumọ̀. Ìtọ́sọ́nà yìí ṣàlàyé bí àwọn apá náà ṣe ń ṣiṣẹ́ pọ̀.

**Orísun:** `open-sse/` (package workspace, nǹkan bí fáìlì `.ts` 1,440 tí kì í ṣe ti ìdánwò)

## Kí Nìdí Tí Package Workspace Ọ̀tọ̀ Fi Wà?

`open-sse/` jẹ́ **workspace adádúró** nínú monorepo OmniRoute fún ọ̀pọ̀ ìdí:

1. **Àtúnlò** — a ṣe àtẹ̀jáde `open-sse` gẹ́gẹ́ bí `@omniroute/open-sse` lórí npm, nítorí náà àwọn iṣẹ́-àkànṣe mìíràn lè lò ó lọ́tọ̀
2. **Àwọn ààlà tó ṣe kedere** — a ya ẹ̀rọ ìṣànwọlé sọ́tọ̀ kúrò ní fẹ́lẹ́fẹ́lẹ́ UI/DB tó jẹ́ ti OmniRoute
3. **Ìṣiṣẹ́** — ẹ̀rọ náà kò ní àwọn ìgbẹ́kẹ̀lé Next.js, èyí tó ń mú kí ìbẹ̀rẹ̀ láti ipò tútù yára sí i nínú àwọn àyíká CLI/serverless
4. **Ìṣàkóso ẹ̀yà** — `open-sse` lè ṣe ìtújáde ní ìgbà tirẹ̀

```json
// package.json
"workspaces": ["open-sse"]
```

## Ọ̀nà Ìṣàn Ìbéèrè

Gbogbo ìbéèrè LLM ń gba inú **ọ̀nà ìṣàn alákòókò márùn-ún** kọjá:

```
                              ┌──────────────┐
   Ìbéèrè HTTP                │  1. DARÍ Ọ̀NÀ│   ìyànjú combo, yíyan model
   (ọ̀nà Next.js)             └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  2. TÚMỌ̀    │   ìyípadà ìrísí (OpenAI ↔ Claude ↔ Gemini)
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  3. ṢE       │   olùṣiṣẹ́ olupèsè, HTTP, àtúnṣe, olùdádúró
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  4. ṢÀN      │   ìyípadà SSE, ìfàsẹ́yìn
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  5. ṢÀKỌSÍLẸ̀│   títọpinpin lílò, àkọsílẹ̀ ìpè, ìṣọ̀rí àṣìṣe
                              └──────┬───────┘
                                     │
                                     ▼
                              Ìdáhùn HTTP (SSE tàbí JSON)
```

### Ìpele 1: Darí Ọ̀nà (services/combo.ts)

**Ojú-ọ̀nà ìwọlé**: `handleComboChat()` nínú `services/combo.ts`

Ó ń yanjú ìbéèrè náà sí tuple `(provider, model, account, credentials)` pàtó kan:

- Wá combo náà nípasẹ̀ ID (tàbí kọ́ combo foju kan fún àwọn model `auto/*`)
- Lo ọgbọ́n ìdarí ọ̀nà (ààyò, ìwọ̀n, round-robin, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ)
- Yọ àwọn olupèsè tí kò ní ìlera kúrò (circuit breaker)
- Yan ibi-afẹ́ tó ṣeé lò tó kàn

Fún àwọn model `auto/*`, ìpele yìí tún máa ń:

- Ṣiṣe algoridimu **ìṣírò kókó mẹ́rìndínlógún** (`services/autoCombo/`)
- Yan tọkọtaya `provider+model` kan ní ìbámu pẹ̀lú ìlera, iye owó, àkókò ìdádúró, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ

### Ìpele 2: Túmọ̀ (translator/)

Tí ìrísí orísun (fún àpẹẹrẹ, OpenAI) bá yàtọ̀ sí ìrísí ibi-afẹ́ (fún àpẹẹrẹ, Claude), a ó **túmọ̀** ìbéèrè náà:

- System prompt → system message
- Àwọn ìtumọ̀ irinṣẹ́ → ìrísí irinṣẹ́ pàtó fún olupèsè
- Àwọn paramita ìrònú → àwọn ohun tó bá wọn mu fún olupèsè
- Ìṣọ̀kan ipa ìránṣẹ́ (`developer` → `system` fún àwọn tí kì í ṣe OpenAI)

`translator/index.ts` ń ṣí àwọn wọ̀nyí síta:

```ts
translateRequest(body, sourceFormat, targetFormat): TranslatedRequest
needsTranslation(source, target): boolean
```

### Ìpele 3: Ṣe (executors/)

**Ojú-ọ̀nà ìwọlé**: `getExecutor(providerId).execute(request, options)`

Gbogbo àwọn olupèsè ló ń lo `DefaultExecutor` (`executors/default.ts`) nípasẹ̀ ìpadàbọ̀ factory `getExecutor()`. Olùṣiṣẹ́ náà máa ń:

- Kọ URL orísun òkè (`buildUrl()`)
- Ṣàfikún àwọn àkọlé pàtó fún olupèsè (`buildHeaders()`)
- Yí body ìbéèrè padà (`transformRequest()`)
- Fi ìbéèrè HTTP ránṣẹ́ pẹ̀lú àtúnṣe + ìdádúró tó ń pọ̀ sí i lọ́nà exponential
- Ṣàkóso ìsọdọ̀tun ìfàṣẹsí bí ó bá yẹ (àwọn olupèsè OAuth)

Gbogbo àwọn olùṣiṣẹ́ ló fa `BaseExecutor` gùn (`executors/base.ts`, LOC 1170), èyí tó ń pèsè:

- Ìlànà àtúnṣe tí ó wọ́pọ̀
- Ìṣọ̀kan proxy
- Ìṣọ̀kan circuit breaker
- Àwọn hook ìkọsílẹ̀ lílò

### Ìpele 4: Ṣàn (utils/stream.ts)

Fún àwọn ìdáhùn ìṣànwọlé, olùṣiṣẹ́ náà máa ń dá **ReadableStream** padà. Olùdarí náà máa ń:

- Ṣàn án gba inú ìyípadà SSE kan (`createSSETransformStreamWithLogger`)
- Lo àwọn ping heartbeat láti ṣàwárí àwọn ìsopọ̀ tó ti kú
- Ṣàkóso ìjáwọ́ oníbàárà láìfa ìṣòro (`pipeWithDisconnect`)
- Yí SSE → JSON padà fún àwọn oníbàárà tí kò lo ìṣànwọlé

Fún àwọn ìdáhùn tí kì í ṣe ìṣànwọlé, olùṣiṣẹ́ náà máa ń dá object JSON tí a ti ṣe ìtúpalẹ̀ rẹ̀ padà, tí a sì ń fi kọjá láìyípadà.

### Ìpele 5: Ṣàkọsílẹ̀ (services/usage.ts)

Lẹ́yìn ìdáhùn (àṣeyọrí tàbí ìkùnà), a máa ń ṣàkọsílẹ̀ lílò:

- `prompt_tokens`, `completion_tokens`, `cached_tokens` láti inú ìdáhùn náà
- `cost_usd` tí a ṣírò láti inú dátà iye owó
- `latency_ms`, `status`, `error_class` bí ó bá kùnà
- A fi pamọ́ sínú tábìlì `usage_history`

Àwọn ohun àkójọpọ̀ àkọsílẹ̀ ìpè (bí a bá ti mú wọn ṣiṣẹ́) ni a máa kọ sínú `${DATA_DIR}/call_logs/`.

## Ìwádìí Jinlẹ̀ Àwọn Fáìlì Pàtàkì

### chatCore.ts (àwọn ila 5977)

**Olùṣàkóso ìbéèrè pàtàkì jù lọ** ni. Bí ó tilẹ̀ jẹ́ pé ó tóbi, ó ní ìṣètò tó kedere:

```ts
// Ìṣètò àfihàn ti chatCore.ts
export async function handleChat(request: NextRequest) {
  // 1. Ìjẹ́rìí + CORS
  await authenticateRequest(request);
  applyCorsHeaders(response);

  // 2. Ìfàṣẹyìnsílẹ̀ body
  const body = await parseRequestBody(request);

  // 3. Ìwárí format + íyípadà
  const sourceFormat = detectFormat(request);
  const targetFormat = getTargetFormat(providerId);
  if (needsTranslation(sourceFormat, targetFormat)) {
    body = translateRequest(body, sourceFormat, targetFormat);
  }

  // 4. Ìtọ́sọ́nà combo
  const targets = await resolveComboTargets(comboId, body);
  for (const target of targets) {
    try {
      const result = await executeOnTarget(target, body);
      await recordUsage(result);
      return result;
    } catch (err) {
      // Tẹ̀síwájú sí àfojúsùn tókàn
    }
  }

  // 5. Ìpadàsẹ́yìn pajawiri
  return await emergencyFallback(body);
}
```

Bí ó tilẹ̀ jẹ́ function ńlá kan ṣoṣo, a pín ín sí **àwọn abala tí a ṣe àkíyèsí lórí** tí ó bá pipeline oní ipele 5 mu.

### combo.ts (4456 LOC)

**Ẹ̀rọ ìtọ́sọ́nà** tí ń yí combo kan padà sí àwọn àfojúsùn tó ṣe le lẹ́sẹ̀sẹ̀.

```ts
// services/combo.ts
export async function handleComboChat(body, comboId): Promise<ChatResult> {
  const targets = await resolveComboTargets(comboId, body);
  for (const target of targets) {
    try {
      return await handleSingleModel(target, body);
    } catch (err) {
      log.warn("target failed, trying next", { target, err });
    }
  }
  throw new ComboExhaustedError("All targets failed");
}
```

### base.ts (1170 LOC)

**Olùmúṣe abstract** tí gbogbo kiláàsì olùmúṣe ń gba lẹ́yìn (tàbí ní tààràà, tàbí nípasẹ̀ `DefaultExecutor` àti àwọn kiláàsì-ìtẹ̀sí mìíràn). Ó ní:

- `buildUrl()` — ìṣẹ̀dá URL àtìbòmọ́láwìí (àwọn kiláàsì-ìtẹ̀sí ń bó jù lọ fún ti pàtàkìsí)
- `buildHeaders()` — àwọn header àtìbòmọ́láwìí (ìjẹ́rìí, content-type)
- `transformRequest()` — ó ń kọjá lọ bí ó ṣe rí ní àtìbòmọ́láwìí
- `execute()` — lúùpù (loop) HTTP pàtàkì pẹ̀lú retry/backoff/breaker

```ts
// open-sse/executors/default.ts
export class DefaultExecutor extends BaseExecutor {
  // Ó ń ṣàkóso gbogbo àwọn olùpèsè tó bá OpenAI/Anthropic mu
  // Àwọn olùpèsè ń forúkọsílẹ̀ àwọn ìṣètò (URL, ìjẹ́rìí, àwọn header) ṣùgbọ́n wọ́n ń pín lógíìkì olùmúṣe kannáá
}
```

A ń ṣètò ìhùwàsí tó jẹ́ ti olùpèsè kọ̀ọ̀kan (àwọn header ìjẹ́rìí, URL ìpìlẹ̀, àwọn header ẹ̀yà) nípasẹ̀ Ìforúkọsílẹ̀ Olùpèsè (provider registry), kì í ṣe àwọn kiláàsì olùmúṣe tó yàtọ̀.

````

## Àwọn Executor (150 module)

Ní ìpọ̀pọ̀ jù lọ, fáìlì kan ni fún provider kọ̀ọ̀kan. Gbogbo àwọn kíláàsì executor ń gba `BaseExecutor` lẹ́yìn, wọ́n sì ń rọ́ ohun tó yàtọ̀ sípò; àwọn module yòókù jẹ́ àwọn olùrànlọ́wọ́ fún provider kọ̀ọ̀kan (àwọn schema irinṣẹ́, àwọn adapter fetch/TTS, àwọn olùṣàkóso quirk).

### Àwọn àpẹẹrẹ tó wọ́pọ̀

Wọ́n ń yanju àwọn provider nípasẹ̀ `getExecutor(providerId)`, èyí tó ń dá executor tí wọ́n ti ṣètò padà. Àwọn provider tó bá OpenAI/Anthropic ṣe é ń lo `DefaultExecutor` (`executors/default.ts`). Wọ́n ń ṣètò ìwà tó yàtọ̀ fún provider (base URL, auth headers, API version) nínú `open-sse/config/providers/`, nígbà tí wọ́n sì ń ṣàkóso àwọn ìyípadà ara ìbéèrè nínú `open-sse/translator/`.

Wọ́n ń ṣètò **URL àdáni** nípasẹ̀ ìṣètò provider:

```ts
// Ìṣètò provider nínú open-sse/config/providers/
export default {
  id: "together",
  baseURL: "https://api.together.xyz/v1/chat/completions",
}
````

Wọ́n ń ṣàkóso **auth àdáni** nípasẹ̀ ìṣètò auth ti registry provider (API key, OAuth, àwọn profaili header).

Àwọn ìyípadà **ara ìbéèrè àdáni** (fún àpẹẹrẹ, Anthropic tí ń ya `system` kúrò lára `messages`) ni wọ́n forúkọsilẹ̀ fún provider kọ̀ọ̀kan nínú `open-sse/translator/`.

````

### Ilé-iṣẹ́ Executor

`executors/index.ts` ń ṣe export `getExecutor(providerId)`:

```ts
import { getExecutor } from "@omniroute/open-sse/executors";

const executor = getExecutor("anthropic");
const result = await executor.execute({
  model: "claude-sonnet-4-5",
  messages: [...],
});
````

Ìyanju ń lọ nípasẹ̀ `ExecutorRegistry` (`executors/registry.ts`): wọ́n kéde gbogbo executor àmójútó nínú tábìlì abínúdá ti `executors/index.ts`, wọ́n sì forúkọsilẹ̀ rẹ̀ nípasẹ̀ `registerExecutor(alias, instance)` nígbà tí module bá ń load; `getExecutor()` ń kàn sí registry ó sì ń padà sí `DefaultExecutor` tí wọ́n ti memoize fún provider kankan tí kò ní entry àmójútó. Golden test `tests/unit/executor-map-golden.test.ts` ni ó ṣàpèjúwe gbogbo ìsopọ̀ alias → executor.

## Sẹ́fà MCP

`open-sse/mcp-server/` ń mú sẹ́fà **Model Context Protocol** ṣẹ:

- **irinṣẹ́ 110** (ìṣàkóso olùpèsè, àwọn àkójọpọ̀, ìrántí, cache, compression, proxy, àwọn ọgbọ́n, gamification, plugins, Notion, Obsidian, àkójọpọ̀ àdúgbò)
- **ọ̀nà ìgbéwọlé 3**: stdio, SSE, Streamable HTTP
- **àwọn scope 33** fún àṣẹ ìwọlé alálàyé

### Ìforúkọsílẹ̀ Irinṣẹ́

A forúkọsílẹ̀ àwọn irinṣẹ́ gẹ́gẹ́ bí fáìlì ọ̀tọ̀ọ̀tọ̀ nínú `open-sse/mcp-server/tools/`, ọ̀kọ̀ọ̀kan ń ṣe àgbéjáde orúkọ, schema, handler, àti scope:

```ts
// open-sse/mcp-server/tools/getHealth.ts
import { z } from "zod";
export default {
  name: "omniroute_get_health",
  description: "Get system health snapshot",
  scope: "read:health",
  inputSchema: z.object({}),
  handler: async (_args, ctx) => {
    return await getSystemHealth();
  },
};
```

### Àwọn Ọ̀nà Ìgbéwọlé

```ts
// stdio (lílò CLI)
startMcpStdio(server);

// SSE (ìṣàn tí ó dá lórí HTTP)
startMcpSse(server, port);

// Streamable HTTP (MCP òde òní)
startMcpStreamable(server, port);
```

### Àṣẹ Ìwọlé

Gbogbo ìpè irinṣẹ́ ń gba inú àwọn àyẹ̀wò scope kọjá (`open-sse/mcp-server/auth/`):

```ts
if (!hasScope(apiKey, "providers:read")) {
  throw new Error("Insufficient scope");
}
```

## Àwọn Olùyípadà

`open-sse/transformer/` ń yí padà láàárín àwọn ọ̀nà kika **Chat Completions** àti **Responses API**.

### Kí Nìdí Tí Olùyípadà Ọ̀tọ̀ Fi Ṣe Pàtàkì?

Responses API jẹ́ ọ̀nà kika tuntun ti OpenAI pẹ̀lú **àwọn ìjíròrò tí ó ní ipò** (`previous_response_id`). Nígbà tí client kan bá fi ìbéèrè Responses ránṣẹ́, OmniRoute:

1. Ń yí Responses → Chat Completions padà ní inú
2. Ń fi ránṣẹ́ sí olùpèsè (olùpèsè èyíkéyìí tí ó ṣe àtìlẹ́yìn fún Chat Completions)
3. Ń yí èsì náà padà sí ọ̀nà kika Responses
4. Ń san èsì tí a yí padà náà lọ sí client

Olùyípadà náà (`transformer/responsesTransformer.ts`) ń pèsè:

```ts
createResponsesApiTransformStream(): TransformStream
```

Èyí ń ṣàkóso:

- Àwọn ìṣẹ̀lẹ̀ `response.output_item.added`
- Àwọn ìṣẹ̀lẹ̀ `response.output_text.delta`
- Ìṣẹ̀lẹ̀ `response.completed`
- Ìbámu ìpè irinṣẹ́ (`function_call` ↔ `tool_calls`)

## Àwọn Àṣà Tí Kò Dára

❌ **Àwọn ìpè DB amúṣiṣẹ́pọ̀ nínú `combo.ts`** — ṣe ìṣirò ṣáájú kí o sì cache
❌ **Ìlànà àtúnṣe ìgbìyànjú nínú àwọn handler** — lo `retry()` láti resilience service
❌ **Wíwọlé provider config ní tààrà** — lo àwọn getter `providerRegistry`
❌ **Àwọn ẹ̀wọ̀n ìpadàsẹ́yìn tí a kọ sínú kóòdù** — ṣàlàyé wọn nínú `modelFamilyFallback.ts`
❌ **Àwọn ìyípadà state láàárín àwọn request tó ń ṣiṣẹ́ lẹ́ẹ̀kan náà** — lo context tó jẹ́ ti request nìkan

## Fífi Component Tuntun Kún Un

### Fífi Service Tuntun Kún Un

1. Ṣẹ̀dá `open-sse/services/[serviceName].ts` pẹ̀lú ojúṣe kan pàtó
2. Export function handler àkọ́kọ́ àti àwọn constant èyíkéyìí
3. Ṣàfikún àwọn unit test sínú `tests/unit/services/[serviceName].test.mjs`
4. Ṣàkópọ̀ rẹ̀ mọ́ request pipeline nínú `handlers/chatCore.ts` (bí ó bá ní í ṣe pẹ̀lú routing)
5. Ṣe àfikún sí ìlànà routing nínú `combo.ts` bí service náà bá kan yíyan target
6. Ṣàkọsílẹ̀ rẹ̀ nínú fáìlì yìí

### Fífi Executor Tuntun Kún Un

1. Ṣẹ̀dá `open-sse/executors/[provider].ts` tó ń jogún láti `BaseExecutor`
2. Forúkọsílẹ̀ rẹ̀ nínú `config/providerRegistry.ts`
3. Ṣàfikún rẹ̀ sí factory `executors/index.ts`
4. Ṣàfikún àwọn unit test fún executor náà
5. Ṣàkọsílẹ̀ rẹ̀ nínú `docs/architecture/ARCHITECTURE.md`

### Fífi Ohun Èlò MCP Tuntun Kún Un

1. Ṣẹ̀dá tàbí ṣe àfikún `open-sse/mcp-server/tools/[category]Tools.ts`
2. Ṣàlàyé schema Zod fún àwọn input
3. Forúkọsílẹ̀ ohun èlò náà nínú `mcp-server/index.ts`
4. Ṣàfikún rẹ̀ sí scope matrix nínú `mcp-server/auth/`
5. Ṣàfikún àwọn unit test
