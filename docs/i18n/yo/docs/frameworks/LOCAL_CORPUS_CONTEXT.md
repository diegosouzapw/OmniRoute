> `src/lib/localCorpus/configured.ts` (àsìkò-ṣiṣe tí a ti ṣètò),

> `open-sse/mcp-server/tools/localCorpusTools.ts` (irinṣẹ́ MCP mẹ́ta tí ó jẹ́ ti kíkà nìkan), àti
> `src/app/api/settings/local-corpus/route.ts` (API ètò).

## Ohun tí ó jẹ́

Local Corpus ń jẹ́ kí olùṣàkóso fi àkójọpọ̀ fáìlì ọ̀rọ̀ kan ṣoṣo tí a fọwọ́ sí ní pàtó hàn sí
sáfà MCP ti OmniRoute. Àwọn fáìlì náà dúró sínú àkójọpọ̀ fáìlì ìpilẹ̀ṣẹ̀ wọn: OmniRoute ń fi
ọ̀nà-gbòǹgbò canonical nìkan pamọ́ sínú SQLite, ó sì ń ṣètójú àtọ́ka ìṣàwárí inú ìrántí. Kì í
ṣe àdàkọ àkóónú corpus sínú ibi ìpamọ́ kóòdù tàbí ibi ìpamọ́ dátà.

Ìsọdọ̀tun àtọ́ka náà ń ṣẹlẹ̀ ní ìpele. Àwọn fáìlì tí kò yípadà ni a tún lò ní ìbámu pẹ̀lú ìwọ̀n àti
àkókò tí a ṣàtúnṣe wọn, àwọn fáìlì tí ó yípadà ni a tún kà tí a sì fi SHA-256 ṣe hash wọn, a sì ń yọ
àwọn fáìlì tí a ti pa rẹ́. Ìṣàwárí ń sọ àtọ́ka tí ó ti ju ìṣẹ́jú-àáyá 30 lọ di tuntun; àwọn olùpè tún lè béèrè
ìsọdọ̀tun lẹ́sẹ̀kẹsẹ̀.

## Ṣètò orísun náà

Route ètò náà nílò ìfàṣẹsí ìṣàkóso kan náà bí àwọn API ètò mìíràn.
Ọ̀nà tí a fi ránṣẹ́ gbọ́dọ̀ ti wà tẹ́lẹ̀, ó sì gbọ́dọ̀ jẹ́ ọ̀nà àkójọpọ̀ fáìlì alákòóso.

```bash
# So àkójọpọ̀ fáìlì tí a fọwọ́ sí pọ̀
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Ṣàyẹ̀wò ìṣètò àti ipò àtọ́ka
curl http://localhost:20128/api/settings/local-corpus

# Já ìsopọ̀ láìyí àwọn fáìlì orísun padà
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Àwọn irinṣẹ́ MCP

Gbogbo irinṣẹ́ mẹ́tẹ̀ẹ̀ta nílò `read:local-corpus`. Àwọn ìdáhùn irinṣẹ́ ń fi àwọn ọ̀nà ìbátan àti
basename ti àkójọpọ̀ fáìlì gbòǹgbò hàn, wọn kì í fi ọ̀nà alákòóso rẹ̀ hàn.

| Irinṣẹ́                | Àpèjúwe                                                                                    |
| :-------------------- | :----------------------------------------------------------------------------------------- |
| `local_corpus_status` | Jábọ̀ ipò ìṣètò, ìwọ̀n àtọ́ka, àwọn ààlà, àti àkókò ìsọdọ̀tun tó ṣẹ̀ṣẹ̀ wáyé                     |
| `local_corpus_search` | Ṣàwárí ọ̀rọ̀ tí a ti tọ́ka, kí o sì dá àwọn àyọkà onílà tí a fi ààlà sí padà (títí dé èsì 20) |
| `local_corpus_read`   | Ka ìwọ̀n àwọn ìlà tí a fi ààlà sí láti inú fáìlì ìbátan corpus kan tí a fàyè gbà            |

Àwọn àpẹẹrẹ ìwọlé MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Àwọn ààlà ààbò

- Allowlist náà dá lórí ọ̀rọ̀: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, àti `.yml`.
- A ń fo àwọn symlink kọjá. A ń sọ àwọn ọ̀nà kíkà di canonical, wọ́n sì gbọ́dọ̀ dúró sínú
  gbòǹgbò tí a ṣètò; a ń kọ àwọn ọ̀nà alákòóso àti àwọn ìgbìyànjú láti la àkójọpọ̀ fáìlì kọjá.
- A yọ àwọn orúkọ àkójọpọ̀ fáìlì tí ó ní ìfura àti èyí tí a ṣe jáde kúrò: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, àti
  `secrets`.
- Àwọn ààlà àìyípadà jẹ́ fáìlì 5,000, 1 MiB fún fáìlì kọ̀ọ̀kan, àpapọ̀ àkóónú tí a tọ́ka tó 64 MiB,
  nǹkan bí àmì-ọ̀rọ̀ 4,000 fún ẹ̀ka ìṣàwárí kọ̀ọ̀kan, àti ìlà 400 fún kíkà kọ̀ọ̀kan.
- A ka àwọn fáìlì tí ó ní NUL sí ohun tí kì í ṣe ọ̀rọ̀, a sì ń fo wọn kọjá tàbí kọ̀ wọ́n.

Àwọn ìwé alákójọpọ̀ alakomeji bí PDF, DOCX, àwọn àwòrán, àti àwọn àkójọpọ̀ pọpọ̀ kò ní àtìlẹ́yìn ní ìmọ̀ọ́mọ̀.
Yí wọn padà sí fọ́ọ̀mù ọ̀rọ̀ tí a fọwọ́ sí nínú àkójọpọ̀ fáìlì tí a ṣètò kí o tó ṣe atọ́ka.

## Àwọn àkíyèsí iṣẹ́

- Yíyí tàbí pípa gbòǹgbò tí a ṣètò rẹ́ ń pa àtọ́ka inú ìrántí tí a pín rẹ́.
- Àtúnìbẹ̀rẹ̀ process ń sọ àtọ́ka náà nù; ìṣàwárí tó tẹ̀ lé e yóò tún un kọ́ láti orísun tí a ṣètò.
- `local_corpus_status` kì í fipá mú scan kan. Lo `local_corpus_search` pẹ̀lú
  `refresh: true` nígbà tí a bá nílò àtúnṣe scan lẹ́sẹ̀kẹsẹ̀.
- A ń ka àwọn ìkùnà scan àti kíkà tàbí dá wọn padà gẹ́gẹ́ bí àwọn àṣìṣe tí a ti sọ di àìléwu; a kì í
  ṣàtúnṣe àwọn fáìlì orísun láéláé.
