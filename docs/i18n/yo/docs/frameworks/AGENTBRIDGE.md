AgentBridge jẹ́ proxy MITM (Man-in-the-Middle) ti OmniRoute, èyí tí ń dá ìrìnàjò HTTPS láti ọ̀dọ̀ àwọn aṣojú AI inú IDE dúró, tí ó sì ń darí rẹ̀ padà gba ẹ̀rọ ìdarí ìrìnàjò ìṣọ̀kan ti OmniRoute. Ó ṣe àtìlẹ́yìn fún **àwọn aṣojú IDE 10** — Antigravity, Kiro, GitHub Copilot, GHE Copilot, OpenAI Codex, Cursor, Zed, Claude Code, Open Code, àti Trae (tí a ń ṣèwádìí rẹ̀) — èyí tó mú kí OmniRoute jẹ́ proxy MITM tó ní ààlà ìṣàmúlò tó gbòòrò jù lọ fún àwọn olùrànlọ́wọ́ ìkọ kóòdù AI lórí ọjà.

**Ibi tí dasibodu wà:** `/dashboard/tools/agent-bridge`
**Ẹgbẹ́ pẹpẹ ẹ̀gbẹ́:** Tools (lẹ́yìn Cloud Agents)
**Tún wo:** [`TRAFFIC_INSPECTOR.md`](./TRAFFIC_INSPECTOR.md) — ṣàbójútó gbogbo ìrìnàjò tí a dá dúró ní àkókò gidi; `docs/security/MITM-TPROXY-DECRYPT.md` (git; a kò ṣàkójọ rẹ̀ sínú `/docs`) — ipò Linux TPROXY fún gbígba àti yíyọ ìfipamọ́ ìrìnàjò ní gbangba, èyí tí ipa-ọ̀nà `/api/tools/agent-bridge/tproxy` ń darí.

## §1 Àkótán

### Kí ni AgentBridge?

Nígbà tí aṣojú IDE kan (fún àpẹẹrẹ, GitHub Copilot, Cursor, Claude Code) bá ṣe ìpè API, ó máa ń sopọ̀ tààrà sí olùpèsè AI òkè (OpenAI, Anthropic, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ). AgentBridge máa ń dá àsopọ̀ yẹn dúró ní gbangba ní ìpele TLS — láì nílò ìyípadà èyíkéyìí sí ìṣètò aṣojú — ó sì tún ìbéèrè náà kọ láti gba OmniRoute kọjá.

Èyí túmọ̀ sí pé o lè:

- **Darí aṣojú èyíkéyìí padà sí olùpèsè èyíkéyìí**: Ṣé Copilot ń bá OpenAI sọ̀rọ̀? Darí rẹ̀ padà sí Anthropic Claude, Gemini, tàbí èyíkéyìí nínú àwọn olùpèsè 352 ti OmniRoute.
- **Lo àwọn ìbámu awoṣe**: `gemini-3-flash` → `claude-sonnet-4.7` ní gbangba ní ìpele olùṣàkóso.
- **Ṣàkíyèsí gbogbo ìrìnàjò aṣojú**: gbogbo ìbéèrè tí a dá dúró ni a máa ń tẹ̀jáde sí [Traffic Inspector](./TRAFFIC_INSPECTOR.md).
- **Lo agbára ìfaradà OmniRoute**: ìdarí ìrìnàjò àkójọpọ̀, àwọn olùdá àyíká dúró, àwọn ọ̀nà àfidípò, àti ìtọ́pasẹ̀ iye owó tún ń ṣiṣẹ́ fún ìrìnàjò aṣojú IDE.

## §2 Àkópọ̀ Ẹ̀rọ

### 2.1 Àkótán àwọn àjọṣe-ẹ̀yà

```
Aṣojú IDE (VS Code / Cursor / abbl.)
    │  HTTPS (port 443)
    ▼
/etc/hosts — 127.0.0.1 api.githubcopilot.com   ← Àtún darí DNS
    │
    ▼
src/mitm/server.cjs  (port 443, ìlànà-ọmọ CJS)
    │  ń wá ibi-àfojúsùn nípasẹ̀ SNI àkọsílẹ̀ Host
    │  ń ṣe ìwé-ẹ̀rí TLS fún SNI kọ̀ọ̀kan tí AgentBridge CA fọwọ́ sí
    ├── Bá àkójọ ìforíkọjá mu? → Ìkọjá TCP tààrà (kò sí ìtúpalẹ̀ ìpamọ́)
    ├── Bá ibi-àfojúsùn mu? → fetch → olulana OmniRoute (port 20128)
    │       └── handler.intercept() — TypeScript
    │               ├── maskSecrets() lórí ara/àwọn àkọsílẹ̀-ókè ìbéèrè
    │               ├── TrafficBuffer.push() — ń tẹ̀ jáde sí Olùṣàyẹ̀wò Ìṣàn-ọ̀nà
    │               └── fetchRouter() → /v1/chat/completions
    └── Kò bá ohunkóhun mu? → Ìkọjá TCP tààrà (kò sí ìtúpalẹ̀ ìpamọ́)
```

### 2.2 Sẹ́ńfà MITM (`src/mitm/server.cjs`)

Sẹ́ńfà MITM pàtàkì ń ṣiṣẹ́ gẹ́gẹ́ bí ìlànà-ọmọ Node.js CJS (láti yẹra fún àtúnkọ ibi-kóòdù CJS tó wà tẹ́lẹ̀). Ó:

- Ń fetí sílẹ̀ lórí port 443 (ó nílò àṣẹ ànfàní tàbí `authbind`/`setcap`)
- Ń gba àwọn ojú-ọ̀nà CONNECT láti inú OS (nípasẹ̀ àtún darí DNS `/etc/hosts`)
- Ń ṣe àwọn ìwé-ẹ̀rí TLS fún SNI kọ̀ọ̀kan tí AgentBridge CA (`DATA_DIR/mitm/ca.crt`) fọwọ́ sí
- Ń wá aṣojú ibi-àfojúsùn nípasẹ̀ àkọsílẹ̀-ókè Host láti inú àkọsílẹ̀ `targets/index.ts`
- Ń fi iṣẹ́ ránṣẹ́ sí ipele olùdarí TypeScript nípasẹ̀ HTTP sí `http://127.0.0.1:20128`

A ń gba `TARGET_HOSTS` láti `DATA_DIR/mitm/targets.json` (èyí tí `targets/index.ts` kọ nígbà ìbẹ̀rẹ̀), èyí sì ń jẹ́ kí àtúnṣe tó yí padà ṣeé ṣe láì tún sẹ́ńfà CJS bẹ̀rẹ̀.

> **Àwòṣe Root-CA (#6684).** Àpèjúwe ìwé-ẹ̀rí-fún-SNI-kọ̀ọ̀kan-tí-CA-fọwọ́-sí lókè
> ni àwòṣe root-CA tí a tọ́jú, tí a fi kún un nínú #6684 (`src/mitm/cert/rootCa.ts` +
> `src/mitm/_internal/rootCaShim.cjs`, tó tún ń lo ìṣírò-ìpamọ́ CA/leaf tí a ti
> fìdí rẹ̀ múlẹ̀ fún TPROXY nínú `src/mitm/tproxy/dynamicCert.ts`) — ó rọ́pò
> leaf oníwọlé-ara-ẹni kan ṣoṣo tó dúró ṣinṣin tẹ́lẹ̀ (`src/mitm/cert/generate.ts`, tí
> ààlà rẹ̀ ṣì jẹ́ àwọn host antigravity nìkan), èyí tí tọkọtaya `server.crt`/`server.key`
> lásán lórí disiki ń tọ́ka sí. **Ìhùwàsí ìṣípò**: ìfìdímúlẹ̀ tuntun (tí kò ní
> `server.crt` tẹ́lẹ̀) máa gba àwòṣe root-CA láìfọwọ́sí; ìfìdímúlẹ̀ tí ó ti
> fọkàn tán leaf adúróṣinṣin àtijọ́ yóò máa lò ó títí olùdarí yóò fi ṣètò
> `MITM_ROOT_CA_ENABLED=true` tí yóò sì tún bridge náà bẹ̀rẹ̀ (`src/mitm/cert/migration.ts`
> ni iṣẹ́ ìpinnu mímọ́ — MITM CA tí a fọkàn tán, tó lè fọwọ́ sí leaf fún
> host **èyíkéyìí**, lágbára púpọ̀ ju leaf SAN-adúróṣinṣin àtijọ́ lọ, nítorí náà
> ìyípadà náà kì í ṣẹlẹ̀ ní ìdákẹ́jẹ fún ìfìdímúlẹ̀ tí a ti fọkàn tán). A ń fi ìwé-ẹ̀rí CA
> sínú ààyè ibi-ìgbẹ́kẹ̀lé `omniroute-mitm.crt` kan náà tí leaf àtijọ́ ń lò
> (`cert/install.ts::installCaCert`) — kò nílò ìmúkúrò ìgbẹ́kẹ̀lé-méjì.

### 2.3 Ìpìlẹ̀ olùdarí (`src/mitm/handlers/base.ts`)

Gbogbo àwọn olùdarí aṣojú ń jogún láti `MitmHandlerBase`:

```ts
export abstract class MitmHandlerBase {
  abstract readonly agentId: AgentId;

  abstract intercept(
    req: IncomingMessage,
    res: ServerResponse,
    body: Buffer,
    mappedModel: string
  ): Promise<void>;

  // Àwọn olùrànlọ́wọ́ tí a dáàbò bò: fetchRouter, pipeSSE, hookBufferStart, hookBufferUpdate
}
```

Olùdarí kọ̀ọ̀kan ń pe `hookBufferStart()` kí ó tó ṣe proxy, ó sì ń pe `hookBufferUpdate()` nígbà tí ó bá parí. Àwọn wọ̀nyí ń fi àwọn àkọsílẹ̀ `InterceptedRequest` sínú `globalTrafficBuffer` (wo [Olùṣàyẹ̀wò Ìṣàn-ọ̀nà](./TRAFFIC_INSPECTOR.md) §4).

### 2.4 Àkọsílẹ̀ àwọn ibi-àfojúsùn (`src/mitm/targets/`)

Aṣojú kọ̀ọ̀kan ní fáìlì ibi-àfojúsùn alásọyé:

```ts
// src/mitm/targets/copilot.ts
export const COPILOT_TARGET: MitmTarget = {
  id: "copilot",
  name: "GitHub Copilot",
  hosts: ["api.githubcopilot.com", "copilot-proxy.githubusercontent.com"],
  port: 443,
  endpointPatterns: ["/chat/completions", "/v1/chat/completions"],
  defaultModels: [{ id: "gpt-4o", name: "GPT-4o", alias: "gpt-4o" }],
  handler: () => import("../handlers/copilot"),
  riskNoticeKey: "providers.riskNotice.oauth",
};
```

Àkọsílẹ̀ náà (`targets/index.ts`) ń ṣe àgbéjáde `ALL_TARGETS`, ó sì ń dá `DATA_DIR/mitm/targets.json` jáde nígbà ìbẹ̀rẹ̀.

### 2.5 Ìkọjá tààrà àti àkójọ ìforíkọjá (`src/mitm/passthrough.ts`)

**Àkójọ ìforíkọjá** (a máa yẹ̀ ẹ́ wò lákọ̀ọ́kọ́, ó sì ní ààyò ju ìbámu ibi-àfojúsùn lọ):

- Àwọn àpẹẹrẹ àkọ́kọ́: àwọn host ilé-ifowópamọ́, `.gov.`, àwọn olùpèsè OAuth/SSO (Okta, Auth0), abbl.
- Àwọn àpẹẹrẹ oníṣe: a tọ́jú wọn sínú tábìlì DB `agent_bridge_bypass`
- Àwọn host tí a foríkọjá ń gba ojú-ọ̀nà TCP tó ṣe kedere — a **kì í tú ìpamọ́ TLS láé**

**Ìkọjá tààrà àkọ́kọ́** (kò bá ibi-àfojúsùn mu, kò sì sí nínú àkójọ ìforíkọjá):

- Ó tún ń gba ojú-ọ̀nà TCP — a kì í já àwọn ìsopọ̀ láé
- Ó ń dí AgentBridge lọ́wọ́ láti dá ìṣàn HTTPS gbogbogbò ètò rú

Ààyò ìtọ́sọ́nà:

```
àkójọ ìforíkọjá → ìbámu ibi-àfojúsùn → ìkọjá tààrà
```

### 2.6 Ìwé-ẹ̀rí CA òkè-sísàn (`src/mitm/upstreamTrust.ts`)

Fún àwọn àyíká nẹ́tíwọ́ọ̀kì ilé-iṣẹ́ tó ní CA àdáni:

```bash
AGENTBRIDGE_UPSTREAM_CA_CERT=/path/to/corporate-ca.pem
```

Nígbà tí a bá ṣètò rẹ̀, ó ń tún olùpín àgbáyé `undici` ṣe pẹ̀lú àfikún ìwé-ẹ̀rí CA náà, èyí tó ń jẹ́ kí AgentBridge lè dé ọ̀dọ̀ àwọn olùpèsè òkè-sísàn nípasẹ̀ àwọn proxy ìparí TLS ilé-iṣẹ́.

### 2.7 Ìbòmọ́lẹ̀ àṣírí (`src/mitm/maskSecrets.ts`)

A ń lo aṣàyẹ̀wò clean-room olómìnira náà lórí àwọn ara ìbéèrè àti àwọn àkọsílẹ̀-ókè ẹ̀rí-ìdánimọ̀
**kí wọ́n tó** wọ inú buffer Olùṣàyẹ̀wò Ìṣàn-ọ̀nà tàbí àkọsílẹ̀ èyíkéyìí. Ó ń ṣe ìrékọjá olóòrùn kan ṣoṣo:

- Àwọn token tí `sk-` / `ak-` / `pk-` bẹ̀rẹ̀ (irú OpenAI/Anthropic)
- Àwọn ẹ̀rí-ìdánimọ̀ RFC 6750 `Authorization: Bearer <token>`, pẹ̀lú ààyò fún gbogbo token náà
- Àwọn token gbogbogbò tó gùn, tí ìtumọ̀ wọn kò hàn gbangba (≥40 àmì), pẹ̀lú àwọn fọ́ọ̀mù tó ní àmì-dot àti padding

`sanitizeHeaders()` ń sọ àwọn orúkọ tí a dá sílẹ̀ di lẹ́tà kékeré, ń so àwọn iye array pọ̀ ní ọ̀nà
tí ó dúró ṣinṣin, ń yọ àkójọ ìdènà hop-by-hop/framing tí a pín (pẹ̀lú ìfàṣẹsí proxy), ń pa
`cookie` àti `set-cookie` mọ́ pátápátá, ó sì ń fi àwọn iye ẹ̀rí-ìdánimọ̀ lé aṣàyẹ̀wò náà lọ́wọ́.

## §3 Ìṣètò

### 3.1 Bẹ̀rẹ̀/dá olupèsè MITM dúró

Lo Káàdì Olùpèsè AgentBridge ní `/dashboard/tools/agent-bridge`:

| Ìṣe              | Àpèjúwe                                                                    |
| ---------------- | -------------------------------------------------------------------------- |
| Bẹ̀rẹ̀ Olùpèsè     | Ṣẹ̀dá `src/mitm/server.cjs` lórí port 443                                   |
| Dá Olùpèsè Dúró  | Dá ìlànà ọmọ dúró lọ́nà tó bójú mu                                          |
| Tun Olùpèsè Bẹ̀rẹ̀ | Dá dúró + bẹ̀rẹ̀ (ó máa gba àwọn ìyípadà ibi àfojúsùn)                       |
| Fọkàn Tán Cert   | Fi `DATA_DIR/mitm/ca.crt` sínú ibi ìfọkànsìn OS                            |
| Ṣe Àgbàsílẹ̀ Cert | Ṣe àgbàsílẹ̀ `ca.crt` fún fífi sori ẹrọ pẹ̀lú ọwọ́                            |
| Ṣẹ̀dá Cert Tuntun | Ṣẹ̀dá CA keypair tuntun (gbogbo àwọn cert aṣojú kọ̀ọ̀kan tó wà yóò di aláìlò) |

### 3.2 Fọkàn tán certificate náà

OS gbọ́dọ̀ fọkàn tán certificate CA AgentBridge kí àwọn IDE tó lè gba àsopọ̀ MITM.

**Linux (NSS — Chrome/Firefox):**

```bash
certutil -A -d sql:$HOME/.pki/nssdb -n "OmniRoute AgentBridge" -t CT,, -i ~/.omniroute/mitm/ca.crt
```

**macOS (Keychain):**

```bash
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/.omniroute/mitm/ca.crt
```

**Windows (certmgr):**

```powershell
certutil -addstore -f Root $env:USERPROFILE\.omniroute\mitm\ca.crt
```

Tàbí lo bọ́tìnì "Fọkàn Tán Cert" nínú dashboard (ó máa ṣiṣẹ́ àṣẹ tó yẹ fún OS rẹ, pẹ̀lú ìbéèrè sudo bí ó bá ṣe pàtàkì).

#### Àwọn IDE tó dá lórí Electron máa ń kọ ibi ìfọkànsìn OS sílẹ̀ (`NODE_EXTRA_CA_CERTS`)

Àwọn IDE kan — pàápàá jùlọ **Antigravity IDE**, àti àwọn app Electron / tí wọ́n jáde láti VS Code — máa ń ṣàkójọpọ̀
runtime Node.js tiwọn tí **kì í wo ibi ìfọkànsìn OS** fún `fetch`/HTTPS tó ń jáde.
Fífọkàn tán CA ní ìpele OS/NSS tó fún backend abinibi **backend** IDE
(fún àpẹẹrẹ, olupèsè èdè Go kan, tó ń lo àkójọpọ̀ CA OS), ṣùgbọ́n **frontend Electron** yóò
ṣì kùnà TLS — èyí máa ń hàn bí ẹni pé app náà ti _jáde kúrò nínú àkọọ́lẹ̀_ tàbí pé ó ń fi _"àsìṣe àsopọ̀"_
hàn bó tilẹ̀ jẹ́ pé àkọsílẹ̀ MITM fi hàn pé àwọn ìpè ìbẹ̀rẹ̀ backend ń dá `200` padà. Ìgbésẹ̀ méjì ni
a nílò, àwọn méjèèjì sì ṣe pàtàkì:

1. Tọ́ka runtime náà sí CA ní tààrà:
   ```bash
   export NODE_EXTRA_CA_CERTS=/path/to/omniroute-agentbridge-ca.crt
   ```
2. **Ṣí IDE náà láti inú shell yẹn.** Ṣíṣí i láti àmì desktop / Dock / àkójọ Start
   **kì í** jogún àwọn export shell, àti pé `~/.config/environment.d/*.conf` máa ń ṣiṣẹ́ lẹ́yìn
   wíwọlé ayaworan tuntun nìkan. Pa IDE náà pátápátá lákọ̀ọ́kọ́ — ìdènà singleton Electron túmọ̀ sí pé ṣíṣí i
   lẹ́ẹ̀kejì kàn máa darí àfiyèsí sí ìlànà tó ti wà, a ó sì kọ àyíká tuntun náà sílẹ̀.

Ìgbésẹ̀ ìfọkànsìn-OS + NSS lókè ṣì ṣe pàtàkì (àkójọpọ̀ nẹ́tíwọ́ọ̀kì Chromium tí àwọn ìṣàn ìfàṣẹsí
kan ń lò máa ń ka ibi ìfọkànsìn NSS onílò kọ̀ọ̀kan, ó sì ní àwọn pin tó dúró ṣinṣin tirẹ̀ fún `*.googleapis.com` tí
CA tí a fọkàn tán ní abẹ́lẹ̀ máa ń borí). `NODE_EXTRA_CA_CERTS` bo ọ̀nà `fetch` Node ní àfikún sí i.

### 3.3 Ìdarí DNS

Fún aṣojú kọ̀ọ̀kan tí o fẹ́ dá sí, API host rẹ̀ gbọ́dọ̀ tọ́ka sí `127.0.0.1`. AgentBridge máa ń ṣàkóso àwọn àkọsílẹ̀ `/etc/hosts` láìfọwọ́yí nígbà tí o bá tan tàbí pa DNS fún aṣojú kan nínú Olùrànlọ́wọ́ Ìṣètò.

Àpẹẹrẹ àwọn àkọsílẹ̀ `/etc/hosts` fún GitHub Copilot:

```
127.0.0.1 api.githubcopilot.com
127.0.0.1 copilot-proxy.githubusercontent.com
```

### 3.4 Ìbáradọ́gba model

Lo Tábìlì Ìbáradọ́gba Model nínú káàdì aṣojú kọ̀ọ̀kan láti ṣàlàyé àwọn ìbáradọ́gba orísun → ibi àfojúsùn:

| Model orísun (abinibi aṣojú) | Model ibi àfojúsùn (OmniRoute) |
| ---------------------------- | ------------------------------ |
| `gpt-4o`                     | `claude-sonnet-4.7`            |
| `*` (wildcard)               | `claude-haiku-4.7`             |

Wildcard `*` máa ń so model èyíkéyìí tí a kò mọ̀ mọ́ ibi àfojúsùn tí a sọ pàtó. A tọ́jú rẹ̀ sínú tábìlì `agent_bridge_mappings`.

> **Ìmọ̀ràn — ṣàwárí àwọn ID model gidi ti aṣojú náà.** IDE kan lè fi àwọn orúkọ model ránṣẹ́ tí ó yàtọ̀ sí
> àwọn àkọlé UI rẹ̀, tí wọ́n sì ń yí padà láàárín àwọn version pàtàkì. Fún àpẹẹrẹ **Antigravity 2** máa ń fi
> `gemini-3.1-pro-low`, `gemini-pro-agent`, àti `gemini-3.1-flash-lite` ránṣẹ́ lórí asopọ̀ — kì í ṣe
> `gemini-2.5-pro` tí a fi hàn nínú àwọn ìwé àkọsílẹ̀ àtijọ́. Fi ìjíròrò kan ránṣẹ́ láìsí ìbáradọ́gba tó bá a mu nípò: MITM
> máa ṣàkọsílẹ̀ `model:` tó wọlé gan-an, yóò sì jẹ́ kí ìbéèrè náà kọjá lọ. So iye gangan yẹn pọ̀, lẹ́yìn náà
> a ó dá ìbéèrè tó kàn sí, a ó sì darí rẹ̀ sí ibi àfojúsùn rẹ.

### 3.5 Àkíyèsí ewu

AgentBridge máa ń dá àwọn ẹ̀rí ìdánimọ̀ (àwọn token OAuth, àwọn kọ́kọ́rọ́ API) tí IDE ń lò láti jẹ́rìí ìdánimọ̀ pẹ̀lú àwọn olupèsè upstream sí. A **máa ń bo wọ́n kí a tó ṣàkọsílẹ̀** (wo §2.7), ṣùgbọ́n wọ́n hàn sí ìpele MITM OmniRoute. Ìmúṣiṣẹ́ àkọ́kọ́ ti aṣojú kọ̀ọ̀kan máa ń fi modal àkíyèsí ewu kan hàn tí a lè pa tì.

### 3.6 Ìtọju & Ìwádìí Àṣìṣe

Dashboard náà ní káàdì **Ìtọju & Ìwádìí Àṣìṣe** (`AgentBridgeMaintenanceCard`, nínú `src/app/(dashboard)/dashboard/tools/agent-bridge/components/`) tó ń fi àwọn ipa-ọ̀nà MITM iṣẹ́ hàn, èyí tí kò ní UI tẹ́lẹ̀. Àkọlé kékeré rẹ̀ ni: _"Ṣe àyẹ̀wò ara ẹni fún ìṣàn gbigba, fagilé ipò ètò tó ṣẹ́kù, kí o sì gbé ìṣètò rẹ láàárín àwọn ẹ̀rọ."_ Àwọn olùrànlọ́wọ́ client káàdì náà wà nínú `src/lib/inspector/agentBridgeMaintenanceApi.ts`.

| Bọ́tìnì             | Ìtọ́pàá                                 | Ohun tí ó ń ṣe                                                                                                                                                                                                      |
| ------------------ | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ṣàyẹ̀wò**         | `GET /api/tools/agent-bridge/diagnose` | Ó ń ṣiṣẹ́ àdánwò-ara-ẹni fún capture-pipeline, ó sì ń fi ìròyìn hàn fún àyẹ̀wò kọ̀ọ̀kan (✓/✗ + ìmọ̀ràn àtúnṣe).                                                                                                          |
| **Ṣàtúnṣe**        | `POST /api/tools/agent-bridge/repair`  | Ó ń dá ipò ètò MITM tí kò ní olùdarí padà (àwọn àkọsílẹ̀ àfarawé DNS, root CA, aṣojú ètò) tí ìkọ̀lù tàbí SIGKILL fi sílẹ̀. Ó jẹ́ idempotent — ó ń jẹ́rìí "Kò sí ohun tí a ó ṣàtúnṣe" nígbà tí ipò bá mọ́.                 |
| **Yọ CA kúrò**     | `DELETE /api/tools/agent-bridge/cert`  | Ó ń yọ ìgbẹ́kẹ̀lé kúrò lórí MITM root CA, ó sì ń yọ ọ́ kúrò nínú ibi ìpamọ́ ìgbẹ́kẹ̀lé OS (ní kedere, idempotent). A máa ń fi hàn nìkan nígbà tí CA bá wà ní ìgbẹ́kẹ̀lé lọ́wọ́lọ́wọ́; ó nílò ìmúdájú "Yọ CA kúrò?" lójúkan náà. |
| **Gbé àtòpọ̀ jáde** | `GET /api/tools/agent-bridge/config`   | Ó ń gba JSON àtòpọ̀ tí a lè gbé kiri sílẹ̀ (wo §3.7).                                                                                                                                                                 |
| **Gbé àtòpọ̀ wọlé** | `POST /api/tools/agent-bridge/config`  | Ó ń ṣàgbéjọ́ JSON àtòpọ̀ tí a ti gbé jáde tẹ́lẹ̀ (wo §3.7).                                                                                                                                                             |

**Àwọn àyẹ̀wò ìṣàwárí àṣìṣe** (`summarizeDiagnostics()` nínú `src/mitm/inspector/diagnostics.ts`). Ìtọ́pàá náà ń ṣiṣẹ́ ìdánwò tó ní ipa fún ọ̀kọ̀ọ̀kan, ó sì ń fi àwọn iye boolean náà sínú olùṣàkótán mímọ́; ó ń dá ìdájọ́ `healthy` kan ṣoṣo padà pẹ̀lú ìmọ̀ràn fún ìkùnà kọ̀ọ̀kan:

| Orúkọ àyẹ̀wò        | Ohun tí ó ń fìdí rẹ̀ múlẹ̀                                     | Ìmọ̀ràn nígbà ìkùnà                                                                                                                                |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `server-running`   | Ilànà server MITM ń ṣiṣẹ́                                     | "Server MITM kò ṣiṣẹ́. Bẹ̀rẹ̀ rẹ̀ láti taabu AgentBridge."                                                                                            |
| `server-reachable` | Server MITM ń gba àwọn ìsopọ̀ lórí port rẹ̀ (ìdánwò TCP)       | "Server MITM kò gba àwọn ìsopọ̀ lórí port rẹ̀. Ṣàyẹ̀wò pé port náà ṣófo àti pé o ní àwọn àṣẹ láti so mọ́ ọn."                                         |

**Àkíyèsí ipò aláìlábòójútó:** nígbà tí ojú-ewé bá ṣàwárí ipò tí ìkọ̀lù fi sílẹ̀ (àfarawé DNS / CA / aṣojú ètò), káàdì náà máa ń fi àkíyèsí àwọ̀ amber hàn — _"Ìgbà ìṣiṣẹ́ tẹ́lẹ̀ fi ipò ètò sílẹ̀ (àfarawé DNS, CA, tàbí aṣojú ètò). Ṣiṣe Ṣàtúnṣe láti fọ ọ́ mọ́."_ — ó sì ń ṣe àfihàn bọ́tìnì **Ṣàtúnṣe**. `Repair` ni afọ́ṣe ipele-ìṣàfilọ́lẹ̀ ti àsíá `--cleanup` ti ProxyBridge (ó ń fi iṣẹ́ náà lé `repairMitm()` lọ́wọ́ nínú `src/mitm/manager.ts`).

> A máa ń jẹ́ kí MITM root CA wà ní fífi-sórí kọjá dídúró/ìbẹ̀rẹ̀ láti yẹra fún àwọn
> ìbéèrè sudo léraléra (ìhùwàsí kan náà bí mitmproxy/Charles), nítorí náà yíyọ ọ́ kúrò jẹ́ iṣẹ́
> **Yọ CA kúrò** ní kedere dípò ohun tí yóò ṣẹlẹ̀ fúnra rẹ̀ nígbà dídúró.

### 3.7 Gbigbé àtòpọ̀ tó ṣeé gbé kiri wọlé/jáde

AgentBridge lè ṣe serialization ipò **tí olùdarí lè ṣàtúnṣe** sínú blob JSON tó ní version kí a lè ṣe àdàkọ ìṣètò kan kọjá àwọn ẹ̀rọ. Serializer náà ni `src/lib/inspector/configPortability.ts` (`exportConfig()` / `importConfig()`), tí `AgentBridgeConfigSchema` sì ń fìdí rẹ̀ múlẹ̀.

Ohun tí a gbé jáde ní àwọn apá mẹ́ta gan-an (a mọ̀ọ́mọ̀ **KÒ** gbé àwọn àiyípadà àkọ́kọ́ tí a fi sínú rẹ̀ jáde, kí gbígbé wọlé má bàa ṣe ẹ̀dà wọn tàbí bá wọn figagbága):

| Field            | Orísun                                                        | Àwọn àkíyèsí                                                              |
| ---------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `bypassPatterns` | àwọn bypass pattern tí olùlò ṣàlàyé (`agent_bridge_bypass`)   | a yọ àwọn bank/gov/okta pattern àkọ́kọ́ kúrò                                |
| `customHosts`    | àwọn custom host Traffic Inspector (`inspector_custom_hosts`) | ọ̀kọ̀ọ̀kan: `{ host, kind: "llm"\|"app"\|"custom", label? }`                 |
| `agentMappings`  | àwọn model mapping fún agent kọ̀ọ̀kan (`agent_bridge_mappings`) | `{ [agentId]: [{ source, target }] }` fún gbogbo agent tó ní àwọn mapping |

```jsonc
// GET /api/tools/agent-bridge/config
{
  "version": 1,
  "bypassPatterns": ["*.internal.example.com"],
  "customHosts": [{ "host": "api.example.com", "kind": "llm", "label": null }],
  "agentMappings": {
    "copilot": [{ "source": "gpt-4o", "target": "claude-sonnet-4.7" }],
  },
}
```

**Ìhùwàsí gbígbé wọlé** (`POST /api/tools/agent-bridge/config`): àwọn bypass pattern àti mapping fún agent kọ̀ọ̀kan **rọ́pò gbogbo ohun tó wà**; a ń fi àwọn custom host kún un ní ọ̀nà **idempotent** (`INSERT OR IGNORE`). Ìdáhùn náà ń jẹ́rìí iye ọ̀kọ̀ọ̀kan tí a lò:

```jsonc
{ "ok": true, "bypassPatterns": 1, "customHosts": 1, "agents": 1 }
```

Ohun tí **KÒ SÍ** nínú àtòpọ̀ náà: ipò ṣíṣiṣẹ́ server, àwọn ipa-ọ̀nà cert, ipò DNS fún agent kọ̀ọ̀kan, ipa-ọ̀nà CA upstream, àti àwọn ètò TPROXY — ìwọ̀nyí jẹ́ ipò host/runtime, kì í ṣe àwọn ààyò tí a lè gbé kiri.

### Àwọn ìgbésẹ̀ olùrànlọ́wọ́ ìṣètò (fún aṣojú kọ̀ọ̀kan)

### Àtòjọ ìforíjìn fún àwọn host tó ṣe kókó

Àtòjọ ìforíjìn náà ń rí i dájú pé àwọn ilé-iṣẹ́ ìṣúná, àwọn olupèsè OAuth/SSO, àti àwọn host mìíràn tó ṣe kókó ni a **kò tú ìpamọ́ wọn láé**. Ìrìnàjò TLS wọn máa ń kọjá gẹ́gẹ́ bí oju eefin TCP tó hàn kedere — OmniRoute kì í rí plaintext náà láé.

Àwọn àpẹẹrẹ ìforíjìn àiyipada ní:

- `*.bank.*`, `*.gov.*` (ìṣúná/ìjọba)
- `*.okta.com`, `*.auth0.com`, `*.microsoft.com` (SSO/ìdánimọ̀)
- `*.apple.com`, `*.icloud.com` (àwọn iṣẹ́ ètò Apple)

Àwọn àpẹẹrẹ ìforíjìn tí olumulo fi kún ni a tọ́jú sínú tábìlì `agent_bridge_bypass`, wọ́n sì máa ń ṣáájú gbogbo ohun mìíràn.

### Ìbòjú àwọn àṣírí

A ń lo `maskSecrets()` láti `src/mitm/maskSecrets.ts`:

- Lórí body ìbéèrè kọ̀ọ̀kan ṣáájú `TrafficBuffer.push()`
- Lórí header kọ̀ọ̀kan ṣáájú logging tàbí broadcasting

Àwọn àpẹẹrẹ: àwọn token tó bẹ̀rẹ̀ pẹ̀lú `sk-`/`ak-`/`pk-`, àwọn token `Bearer`, àti àwọn token gbogbogbòò tó ní àmì ọ̀rọ̀ ≥40.

### Cert CA upstream

Nígbà tí a bá ṣètò `AGENTBRIDGE_UPSTREAM_CA_CERT`, a máa ka fáìlì náà nígbà ìbẹ̀rẹ̀. Bí ipa-ọ̀nà náà bá wà ṣùgbọ́n fáìlì náà kò ṣeé kà, AgentBridge máa ń ṣe àkọsílẹ̀ àṣìṣe tó ṣe kedere, yóò sì kọ̀ láti bẹ̀rẹ̀ (èyí ń dènà àwọn ìkùnà TLS tó dakẹ́ ní àwọn àyíká ilé-iṣẹ́).

### Àwọn ààlà tí a mọ̀

- **Port 443 nílò àṣẹ**: Lórí Linux, AgentBridge nílò `setcap 'cap_net_bind_service=+ep'` lórí binary Node, tàbí kí o ṣiṣẹ́ nípasẹ̀ `authbind`. Olùrànlọ́wọ́ Ìṣètò máa ń ṣàfihàn àwọn ìtọ́nisọ́nà tó bá OS mu.
- **A gbọ́dọ̀ tún IDE bẹ̀rẹ̀**: Lẹ́yìn àtún darí DNS, a gbọ́dọ̀ tún IDE bẹ̀rẹ̀ kí ìtúmọ̀ host tuntun lè ṣiṣẹ́.
- **Àwọn token OAuth tí a kọ taara sínú ètò**: Àwọn aṣojú kan (Kiro, Antigravity) ń tọ́jú àwọn OAuth refresh token sí abẹ́lẹ̀. Iwọ̀nyí hàn kedere sí AgentBridge — ó máa ń rí token Bearer nínú ìbéèrè kọ̀ọ̀kan, tí a sì máa ń bò kí a tó ṣe logging.
- **Àwọn frontend Electron nílò `NODE_EXTRA_CA_CERTS`**: Àwọn IDE tí frontend wọn ń ṣiṣẹ́ lórí runtime Node/Electron tí a kó pọ̀ kò ka ibi ìgbẹ́kẹ̀lé OS/NSS sí, a sì gbọ́dọ̀ ṣe ìfilọ́lẹ̀ wọn láti inú shell tí a ti ṣètò `NODE_EXTRA_CA_CERTS` (wo §3.2). Àmì àìsí rẹ̀: backend IDE ṣe ìfàṣẹsí (MITM fi àwọn `200` hàn) ṣùgbọ́n UI ṣì wà níta.
- **Àwọn ìfìsọ́ púpọ̀ ti IDE kan náà jẹ́ òmìnira sí ara wọn**: ìfìsọ́ system kan (fún àpẹẹrẹ, `/usr/share/antigravity/antigravity`) àti ìfìsọ́ "Full" abẹ́lẹ̀-olumulo kan (fún àpẹẹrẹ, `~/AntigravityIDE_Full/antigravity-ide`) jẹ́ àwọn process ọ̀tọ̀ọ̀tọ̀ pẹ̀lú runtime tiwọn — a gbọ́dọ̀ tún ọ̀kọ̀ọ̀kan ṣe ìfilọ́lẹ̀ pẹ̀lú CA tí a ti fi sínú rẹ̀. Ṣe ìdánimọ̀ èyí tó ń ṣiṣẹ́ nípa ipa-ọ̀nà binary rẹ̀ kí o tó tún un ṣe ìfilọ́lẹ̀.
- **System prompt aṣojú ló ń pinnu ìdánimọ̀, kì í ṣe model tí a darí sí**: nígbà tí o bá tún model aṣojú kan ṣe ìbámu sí olupèsè mìíràn, ìdáhùn náà ṣì máa ń sọ pé òun ni ìdánimọ̀ abinibi aṣojú náà (fún àpẹẹrẹ, Antigravity dáhùn pé "Gemini ló ń fún mi ní agbára") nítorí IDE ló fi èyí sínú system prompt. Jẹ́rìí backend gidi nínú `call_logs` / `proxy_logs` (`provider`, `model`, `target_format`), kì í ṣe nípa bíbéèrè lọ́wọ́ model náà pé ta ni.

## §6 Yíyanjú ìṣòro

### Ìtakora lórí port 443

Tí process mìíràn bá ti ń tẹ́tí sí port 443 (web server, VPN, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ):

```bash
lsof -i :443          # wá process náà
sudo fuser -k 443/tcp  # fi tipátipá pa á (lò ó pẹ̀lú ìṣọ́ra)
```

Gẹ́gẹ́ bí ọ̀nà mìíràn, ṣètò port tí kò nílò àṣẹ gíga nínú àwọn ètò AgentBridge, kí o sì ṣètò àwọn òfin àtúndarí `iptables` / `pf`.

### A kò fọkàn tán ìwé-ẹ̀rí náà

Tí IDE bá fi àwọn àṣìṣe TLS hàn lẹ́yìn tí o bá bẹ̀rẹ̀ AgentBridge:

1. Ṣàyẹ̀wò pé a ti fi cert náà sí ẹrọ: `security find-certificate -c "OmniRoute AgentBridge"` (macOS) tàbí `certutil -L -d sql:$HOME/.pki/nssdb` (Linux/NSS)
2. Àwọn app kan máa ń ṣàkóso ibi ìfọkàntán tiwọn (Firefox, Chrome lórí Linux). Ṣiṣe "Fọkàn Tán Cert" lẹ́ẹ̀kan sí i, kí o sì ṣàyẹ̀wò ibi ìpamọ́ cert pàtó fún NSS/Firefox.
3. Tun IDE bẹ̀rẹ̀ lẹ́yìn fífọkàn tán án — àwọn session TLS tó ń lọ lọ́wọ́ ń lo ipò ìfọkàntán àtijọ́.

### IDE ti jáde kúrò nínú àkọọ́lẹ̀ / "àṣìṣe àsopọ̀" bó tilẹ̀ jẹ́ pé CA jẹ́ fífọkàntán

Àmì ìṣòro: lẹ́yìn àtúndarí DNS àti fífọkàn tán CA, IDE tó dá lórí Electron (fún àpẹẹrẹ, Antigravity)
máa ń ṣí ní ipò **tí a ti jáde kúrò nínú àkọọ́lẹ̀** tàbí fi àṣìṣe ìfàṣẹ̀sí/àsopọ̀ hàn, síbẹ̀ log MITM fi hàn pé àwọn
bootstrap call (`loadCodeAssist`, `fetchAvailableModels`, …) ń dá `200` padà.

Ìdí: **Node/Electron runtime tí a kó sínú IDE kò ka ibi ìfọkàntán OS sí**. Backend abinibi
(language server Go kan) fọkàn tán OS CA, ó sì lè fìdí ẹni múlẹ̀, ṣùgbọ́n frontend Electron
kò ṣe bẹ́ẹ̀ — nítorí náà UI gbà pé kò sí lórí ayélujára.

Àtúnṣe (ìgbésẹ̀ méjèèjì): export `NODE_EXTRA_CA_CERTS=<ca.crt>` **kí o sì tún IDE ṣí láti inú
shell yẹn**, kì í ṣe láti aami desktop. Kọ́kọ́ pa IDE náà pátápátá — singleton lock Electron túmọ̀ sí pé
ìṣí kejì yóò kàn gbé process tó ti wà sí iwájú, a ó sì kọbi ara sí environment tuntun náà. Wo §3.2.
Èyí jọ ìròyìn upstream kan tó ṣì wà ní ṣíṣí, níbi tí agent olómìnira ti ń ṣiṣẹ́ nípasẹ̀ MITM ṣùgbọ́n variant IDE
kùnà lábẹ́ ìṣètò kan náà.

### DNS kò tíì tàn ká

Ṣàyẹ̀wò pé a ti ṣe àfikún sí `/etc/hosts`:

```bash
grep "omniroute\|127.0.0.1.*github\|127.0.0.1.*cursor" /etc/hosts
```

Nu cache DNS kúrò:

```bash
# macOS
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder
# Linux (systemd-resolved)
sudo systemctl restart systemd-resolved
# Windows
ipconfig /flushdns
```

### A kò rí IDE

Ìwárí aládàáṣiṣẹ́ ń lo àwọn installation path tó wọ́pọ̀. Tí ìwárí bá kùnà ṣùgbọ́n tí a ti fi IDE sí ẹrọ:

- Ṣàyẹ̀wò bóyá IDE binary wà ní ibi tí kò jẹ́ bóṣewa
- Setup Wizard ṣì ń ṣiṣẹ́ — ìkùnà ìwárí kàn túmọ̀ sí pé badge kò ní fi install path hàn

### Àwọn àṣìṣe handler (upstream fetch kùnà)

Tí AgentBridge bá ń dá àwọn ìbéèrè dúró ṣùgbọ́n tí gbogbo wọn bá kùnà:

1. Ṣàyẹ̀wò pé ó kéré tán provider kan ti sopọ̀ ní `/dashboard/providers`
2. Ṣàyẹ̀wò àwọn log server OmniRoute: `APP_LOG_LEVEL=debug` nínú `.env`
3. Ṣàyẹ̀wò pé `OMNIROUTE_BASE_URL` tọ́ka sí router endpoint tó tọ́ (àìyípadà: `http://127.0.0.1:20128`)

## §8 Àtòjọ-ètò ọjọ́ iwájú

### Ìwádìí Trae

Trae jẹ́ olùrànlọ́wọ́ AI fún kíkọ kóòdù tí ó ṣẹ̀ṣẹ̀ dé. Ṣáájú ṣíṣe handler kan:

1. Ṣe ìdánimọ̀ binary/extension náà ní àwọn ọjà VS Code / JetBrains tàbí gẹ́gẹ́ bí app aládàáṣe
2. Gba traffic pẹ̀lú mitmproxy láti ṣàwárí àwọn API host àti àwọn ìrísí endpoint
3. Ṣàwárí ọ̀nà authentication tí ó ń lò
4. Ṣe àyẹ̀wò go/no-go ní ìbámu pẹ̀lú TOS àti bí API ṣe ṣeé ṣàwárí tó

Títí ìwádìí yóò fi parí, káàdì Trae inú dashboard yóò máa fi àmì "Ó wà lábẹ́ ìwádìí" hàn pẹ̀lú ìjápọ̀ "Ṣàlàyé bóyá ó ṣeé ṣe". Àwòṣe handler ní `src/mitm/handlers/trae.ts` máa ń ju àṣìṣe `A kò tíì ṣe é` tí a ṣètò sílẹ̀.

### Àwọn agent inú backlog (MITM pọndandan — kò sí àtìlẹ́yìn fún custom base URL)

Àwọn irinṣẹ́ wọ̀nyí kò ṣe àtìlẹ́yìn fún custom base URL nínú àwọn ẹ̀yà wọn lọ́wọ́lọ́wọ́, èyí mú kí MITM jẹ́ ọ̀nà interception kan ṣoṣo. Àyẹ̀wò bóyá wọ́n ṣeé lò ṣì ń dúró:

- **Windsurf** (Codeium/Cognition)
- **Amp** (Sourcegraph)
- **Amazon Q / Kiro CLI** (AWS Bedrock — ó yàtọ̀ sí Kiro IDE)
- **Cowork** (Anthropic desktop)

Àkíyèsí: GitHub Copilot CLI ≥v1.0.19 ṣe àtìlẹ́yìn fún `COPILOT_PROVIDER_BASE_URL` — lo àtúnṣe tààrà dípò MITM fún irinṣẹ́ yẹn.
