Traffic Inspector jẹ́ olùṣàwárí àṣìṣe ìṣàn HTTPS tí a kọ́ sínú OmniRoute — irinṣẹ́ bíi Charles Proxy / mitmweb / HTTP Toolkit tí ó **mọ nípa LLM** tí ó sì **mọ nípa agent**. Ó wà ní `/dashboard/tools/traffic-inspector`, ó sì ń gba ìṣàn alárìnà láti orísun ìgbàasilẹ tó tó 5 lẹ́ẹ̀kan náà.

**Ibi tó wà lórí dashboard:** `/dashboard/tools/traffic-inspector`
**Ẹgbẹ́ sidebar:** Àwọn irinṣẹ́ (lẹ́yìn AgentBridge)
**Tún wo:** [`AGENTBRIDGE.md`](./AGENTBRIDGE.md) — AgentBridge ni ipò ìgbàasilẹ 1.

### Àpẹrẹ ìṣètò rẹ̀ ní ìpínrọ̀ kan

`TrafficBuffer` (`src/mitm/inspector/buffer.ts`) jẹ́ ring buffer inú memory tí gbogbo apá ń lò (àìpéye rẹ̀ jẹ́ entries 1000, a lè ṣètò rẹ̀ nípasẹ̀ `INSPECTOR_BUFFER_SIZE`). Gbogbo àwọn orísun ìgbàasilẹ ló ń kọ sínú rẹ̀ nípasẹ̀ `push()`. Kiláàsì buffer náà ń pín entry kọ̀ọ̀kan sí ẹ̀ka nípa lílo `kindDetector.ts` (ó ń pinnu bóyá ìbéèrè LLM ni), ó ń ṣe ìṣirò `contextKey` kan (fingerprint SHA-256 ti system prompt), ó sì ń ṣe ìkéde sí gbogbo àwọn alabapin WebSocket nípasẹ̀ `globalTrafficBuffer.subscribe()`. Dashboard náà ń sopọ̀ nípasẹ̀ `GET /api/tools/traffic-inspector/ws`, ó sì ń gba snapshot nígbà tó bá sopọ̀, lẹ́yìn náà àwọn ìṣẹ̀lẹ̀ `new`/`update`/`clear` á tẹ̀ lé e.

## §2 Àwọn ipò ìgbàwé

Traffic Inspector ṣe àtìlẹ́yìn fún **àwọn orísun ìgbàwé 5 ní ẹ̀ẹ̀kan náà**. A lè tan tàbí pa ọ̀kọ̀ọ̀kan wọn lọ́tọ̀ọ̀tọ̀. Pápá `source` lórí gbogbo `InterceptedRequest` (`src/mitm/inspector/types.ts`) jẹ́ ọ̀kan lára `"agent-bridge"`, `"custom-host"`, `"http-proxy"`, `"system-proxy"`, tàbí `"tproxy"`.

### Ipò 1 — AgentBridge (àìyípadà, ó máa ń wà ní títàn)

**Orísun:** Àwọn olùdarí AgentBridge (`src/mitm/handlers/base.ts`)
**Ọ̀nà ìṣiṣẹ́:** Gbogbo ìpè `intercept()` nínú `MitmHandlerBase` máa ń pe `hookBufferStart()` kí ó tó fi ránṣẹ́ síwájú, ó sì máa ń pe `hookBufferUpdate()` nígbà tí ó bá parí. Kò nílò àfikún àtúnṣe kankan — ó máa ń ṣiṣẹ́ ní kété tí AgentBridge bá ti ń ṣiṣẹ́.
**Ìbùdó:** Àwọn aṣojú IDE 9 tí a ṣètò nínú AgentBridge
**Àkíyèsí:** Pápá `source` nínú `InterceptedRequest` = `"agent-bridge"`

### Ipò 2 — Àwọn Olùgbàlejò Àdáni (àtúndarí DNS)

**Orísun:** Àkójọ àwọn olùgbàlejò tí aṣàmúlò ṣàlàyé (`inspector_custom_hosts` table)
**Ọ̀nà ìṣiṣẹ́:** Fífi olùgbàlejò kan kún un nípasẹ̀ UI máa ń fi `127.0.0.1 <host>` kún `/etc/hosts` (ó nílò sudo). Sẹ́bà MITM AgentBridge tó ti wà tẹ́lẹ̀ (port 443) máa ń dá ìjẹ́rìí SNI sílẹ̀ lọ́nà ìmúdàgba fún olùgbàlejò tuntun náà.
**Ìbùdó:** Ohun èlò èyíkéyìí tó ń lo olùgbàlejò tí a ṣàfikún — kò nílò ìyípadà àtúnṣe ohun èlò
**Àkíyèsí:** `source` = `"custom-host"`

Àwọn àpẹẹrẹ ibi ìlò:

- Ṣàkíyèsí `api.openai.com` láti inú àwọn ìwé afọwọ́kọ Python
- Ṣàwákiri àṣìṣe `my-internal-llm.company.com`
- Gba ìṣàn ìbánisọ̀rọ̀ láti àwọn ẹ̀rọ alágbèéká lórí nẹ́tíwọ́ọ̀kì kan náà (nípasẹ̀ ìfọ̀rọ̀ ARP — fún àwọn onímọ̀ gíga)

### Ipò 3 — Olùgbọ́ HTTP_PROXY (port 8080)

**Orísun:** Àwọn ohun èlò tó ń lo àwọn àyípadà àyíká `HTTP_PROXY`/`HTTPS_PROXY`
**Ọ̀nà ìṣiṣẹ́:** Olùgbọ́ kejì ní port 8080 (`src/mitm/inspector/httpProxyServer.ts`) tó ń ṣiṣẹ́ gẹ́gẹ́ bí aṣojú HTTP/HTTPS tí a ṣàlàyé ní tààrà. Ó gba àwọn oju eefin `CONNECT` (HTTPS) àti àwọn ìbéèrè HTTP tààrà.
**Ìbùdó:** Ohun èlò èyíkéyìí tó ń tẹ̀lé àyíká `HTTP_PROXY` — kò nílò ìyípadà DNS tàbí sudo
**Àkíyèsí:** `source` = `"http-proxy"`

```bash
# Ìgbàwé kíákíá fún àṣẹ kan ṣoṣo:
HTTPS_PROXY=http://127.0.0.1:8080 curl https://api.openai.com/v1/models

# Ìgbàwé tó máa bá a lọ nínú sáà shell kan:
export HTTP_PROXY=http://127.0.0.1:8080
export HTTPS_PROXY=http://127.0.0.1:8080
```

**Ìdíwọ́ TLS:** Àwọn oju eefin HTTPS `CONNECT` ni a máa ń gba gẹ́gẹ́ bí metadata nìkan (olùgbàlejò, port, àkókò) — a kì í ṣe ìtúpalẹ̀ àkóónú TLS ní àìyípadà. Tan aṣàyàn "Ṣe ìtúpalẹ̀ HTTPS ní ipò proxy" (a gbọ́dọ̀ yàn án, ó sì nílò kí ìjẹ́rìí AgentBridge jẹ́ ìgbẹ́kẹ̀lé) fún àyẹ̀wò àkóónú ní kíkún.

**Ìtakora port:** Tí port 8080 bá wà ní lílò, AgentBridge máa dá 409 padà pẹ̀lú àṣìṣe tó ní ìgbékalẹ̀. Yí port náà padà nípasẹ̀ àyípadà àyíká `INSPECTOR_HTTP_PROXY_PORT`.

### Ipò 4 — Aṣojú jákèjádò ètò (fún àwọn onímọ̀ gíga, a gbọ́dọ̀ yàn án)

**Orísun:** Àwọn àtúnṣe aṣojú ní ipele OS (ó kan gbogbo àwọn ohun èlò lórí ẹ̀rọ náà)
**Ọ̀nà ìṣiṣẹ́:** Ó ń lo àwọn API OS láti darí gbogbo ìṣàn HTTP/HTTPS kọjá nípasẹ̀ olùgbọ́ HTTP_PROXY:

- **macOS:** `networksetup -setwebproxy / -setsecurewebproxy`
- **Linux:** `gsettings set org.gnome.system.proxy` + `/etc/environment`
- **Windows:** `netsh winhttp set proxy 127.0.0.1:8080`
  **Ìbùdó:** Gbogbo ohun èlò lórí ẹ̀rọ náà tó ń tẹ̀lé àwọn àtúnṣe aṣojú ètò
  **Àkíyèsí:** `source` = `"system-proxy"`

**Àwọn ọ̀nà ààbò:**

- Aago pípa-aládàáṣiṣẹ́ (àìyípadà jẹ́ ìṣẹ́jú 30, a lè ṣètò rẹ̀ nípasẹ̀ `INSPECTOR_SYSTEM_PROXY_GUARD_MINUTES`)
- A máa ń fi ipò aṣojú ètò tẹ́lẹ̀ pamọ́ sínú DB, a sì máa ń mú un padà nígbà ìpadàsẹ́yìn
- Dashboard máa ń fi ìkìlọ̀ "Ń mú aṣojú ètò padà" hàn tí aṣàmúlò bá lọ kúrò ní ojú-ìwé nígbà tó ṣì ń ṣiṣẹ́
- UI máa ń fi àmì `⚠ Fún àwọn onímọ̀ gíga` hàn pẹ̀lú àpótí àyẹ̀wò ìjẹ́rìísí kedere

### Ipò 5 — Ìtúpalẹ̀ afihàn TPROXY (Linux, root, a gbọ́dọ̀ yàn án)

**Orísun:** TPROXY kernel + ìdarí ipa ọ̀nà gẹ́gẹ́ bí ìlànà (`src/mitm/tproxy/`)
**Ọ̀nà ìṣiṣẹ́:** Ó máa ń sàmì sí àwọn ìsopọ̀ TCP àbájáde agbègbè tuntun sí port àfojúsùn kan (àìyípadà `443`) nínú `mangle OUTPUT`; `ip rule` kan máa ń tún àwọn packet tí a sàmì sí náà darí sí ìfijiṣẹ́ agbègbè, àfojúsùn `TPROXY` ti `mangle PREROUTING` sì máa ń fi wọ́n fún olùgbọ́ afihàn (**IP_TRANSPARENT**) kan (port àìyípadà `8443`). Olùgbọ́ náà máa ń fòpin sí TLS pẹ̀lú ìjẹ́rìí ewé tí CA aláìmúdúró ń fúnni **fún hostname SNI kọ̀ọ̀kan nígbà tí a bá nílò rẹ̀**, ó máa ń gba pàṣípààrọ̀ tí a ti túpalẹ̀, ó sì máa ń fi ìbéèrè náà ránṣẹ́ sí ibi àfojúsùn ìpilẹ̀ṣẹ̀ lẹ́yìn títún paró mọ́ ọn.
**Ìbùdó:** Àwọn olùgbàlejò àfojúsùn **èyíkéyìí** lórí port àfojúsùn — kò nílò ẹ̀tàn `/etc/hosts`, àyíká `HTTP_PROXY`, tàbí ìyípadà aṣojú jákèjádò ètò. Ìlànà tí a dá sí kò nílò ìyípadà àtúnṣe kankan, ṣùgbọ́n ó gbọ́dọ̀ gbẹ́kẹ̀ lé CA aláìmúdúró náà.
**Àkíyèsí:** `source` = `"tproxy"`

**Àwọn ohun tí a nílò:** Linux nìkan (**IP_TRANSPARENT** wà fún Linux nìkan), agbára **CAP_NET_ADMIN** (root), àti àfikún N-API abinibi kan tí a gbọ́dọ̀ kọ́ pẹ̀lú irinṣẹ́ C (`npm run build:native:tproxy`). Nígbà tí kò bá sí, aṣàyàn dashboard náà máa jẹ́ aláìṣiṣẹ́ pẹ̀lú ìtọ́kasí "Ìtúpalẹ̀ TPROXY nílò Linux + root + àfikún abinibi náà". Àwọn òfin firewall máa ń lò, wọ́n sì máa ń padà sẹ́yìn gẹ́gẹ́ bí ìdúnàádúrà kan (ìkọ̀lù kò ní fi òfin `mangle` sílẹ̀ láéláé), wọ́n sì máa ń parẹ́ nígbà àtúnìbẹ̀rẹ̀. Ìdènà ìyípo tó dá lórí SO_MARK máa ń jẹ́ kí ìfiránṣẹ́ síwájú tí aṣojú náà tún paró má bàa tún jẹ́ dídá sí.

Èyí jẹ́ ètò abẹ́lẹ̀ ńlá kan tó ní ìtọ́sọ́nà olùṣiṣẹ́ tirẹ̀ — wo `docs/security/MITM-TPROXY-DECRYPT.md` (git; a kò kó ọ sínú `/docs`) fún àlàyé kíkún nípa ìlànà firewall, CA aláìmúdúró fún SNI kọ̀ọ̀kan + olùfi sí ibi ìgbẹ́kẹ̀lé, ipa ọ̀nà agbègbè-nìkan, àwọn àlàyé ìdènà ìyípo, àti schema àtúnṣe. `GET / POST / DELETE /api/tools/agent-bridge/tproxy` ló ń darí aṣàyàn náà (àkíyèsí: route náà wà lábẹ́ ìpele-àkọ́kọ́ AgentBridge, kì í ṣe lábẹ́ ìpele-àkọ́kọ́ Traffic Inspector).

### 3.2 Àtòkọ ìbéèrè (pánẹ́ẹ̀lì òsì)

- **Tí a ṣe ní fọ́ọ̀mù afáráyé** (`useVirtualList` + `ResizeObserver`): ń bójú tó ohun 1000 láì di
- **Yíyí lọ fúnra rẹ̀** pẹ̀lú toggle láti dá a dúró nígbà àyẹ̀wò
- **Ipò tí a fi àwọ̀ yàtọ̀ síra**: àwọ̀ ewé (2xx), àwọ̀ ọ̀wọ̀ (3xx), pupa (4xx/5xx), eérú (tí ó ń lọ lọ́wọ́)
- **Emoji agent**: 🔵 Antigravity, 🟢 Copilot, 🟠 Kiro, 🟣 Codex, 🔷 Cursor, 🟤 Zed, 🟡 Claude Code, ⚫ Open Code, 🌐 host àkànṣe
- **Pẹpẹ àwọ̀ àyíká-ọ̀rọ̀**: ààlà òsì 1px tí a fi `contextKey` ṣe àwọ̀ rẹ̀ (SHA-256 ti system prompt) — ó ń ṣàkójọpọ̀ àwọn ìjíròrò tó jọra ní ojú
- **Body tí a ń gbé jáde nígbà tí a bá nílò rẹ̀**: body ìbéèrè tí a yàn nìkan ni a ń mú wá sínú àwọn taabu àlàyé (èyí dènà ṣíṣe render body 1000 × 1MB)

## §4 Àwọn ẹ̀ya tó mọ nípa LLM

### 4.1 Olùṣàwárí irú (`src/mitm/inspector/kindDetector.ts`)

Ó ń pín ìbéèrè kọ̀ọ̀kan sí `"llm"`, `"app"`, tàbí `"unknown"` nípa lílo àmì mẹ́rin:

1. **Àkọsílẹ̀ host** — ~18 orúkọ host API LLM tí a mọ̀ (OpenAI, Anthropic, Gemini, Groq, Mistral, Together, Fireworks, Cohere, Perplexity, Hugging Face, OpenRouter, xAI, Moonshot, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ.)
2. **Àwọn àpẹẹrẹ path** — `/v1/chat/completions`, `/v1/messages`, `/generateContent`, `/v1/responses`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ.
3. **Ìrísí body** — ó ń ṣàwárí `messages[]` (OpenAI/Claude), `contents[]` (Gemini), àti àwọn field `prompt`, `input`
4. **Àwọn àmì user-agent** — `codex`, `claude`, `gemini`, `antigravity`, `kiro`, `copilot`, `cursor` nínú string UA

Àwọn host àkànṣe tí a fi kún un nípasẹ̀ Mode 2 máa ń jogún `kind` wọn láti inú input fọ́ọ̀mù (ìyẹn máa ń jẹ́ `"custom"` ní àìsí àtúnṣe).

### 4.2 Olùdapọ̀ SSE (`src/mitm/inspector/sseMerger.ts`)

**Ìmúṣẹ clean-room olómìnira.** Ṣíṣe parsing event tẹ̀lé
[alugoridimu event tí server ránṣẹ́ ti WHATWG](https://html.spec.whatwg.org/multipage/server-sent-events.html#parsing-an-event-stream),
nígbà tí àtúnkọ́ tẹ̀lé schema streaming gbangba ti [OpenAI](https://platform.openai.com/docs/api-reference/chat/create),
[Anthropic](https://platform.claude.com/docs/en/build-with-claude/streaming), àti
[Gemini](https://ai.google.dev/api/generate-content#method:-models.streamgeneratecontent).

Ó tún message ìkẹyìn ti assistant kọ́ láti inú àwọn event delta SSE àìṣẹ̀:

- **Anthropic**: ó ń kó `content_block_delta` jọ gẹ́gẹ́ bí index; ó ń bójú tó `text_delta`, `input_json_delta` (àwọn ìpè tool), `thinking_delta`
- **OpenAI**: ó ń kó àwọn choice/tool call Chat Completions àti àwọn output item Responses API jọ
  gẹ́gẹ́ bí index
- **Gemini**: ó ń kó `candidates[i].content.parts` jọ
- **Unknown**: ó dá àwọn event àìṣẹ̀ padà bí wọ́n ṣe rí

Tab Response fi toggle kan hàn: **"Àwọn event àìṣẹ̀ ↔ Tí a dapọ̀"**.

### 4.3 Olùṣe ìbánisọ̀rọ̀ di àwòṣe kan (`src/mitm/inspector/conversationNormalizer.ts`)

**Ìmúṣẹ clean-room olómìnira.** Àwọn contract black-box abẹ́nú àti schema message gbangba ti OpenAI, Anthropic, àti Gemini ni wọ́n ṣàlàyé normalization; a kò lo
source ìmúṣẹ upstream kankan.

Ó ń yí àwọn format message OpenAI, Anthropic, àti Gemini padà sí `NormalizedConversation` kan ṣoṣo kí rendering tó wáyé:

```ts
interface NormalizedConversation {
  request: NormalizedTurn[]; // àwọn message / content / prompt láti inú body ìbéèrè
  response: NormalizedTurn[]; // ìdáhùn assistant (tí a dapọ̀ nípasẹ̀ sseMerger)
  contextKey: string | null; // fingerprint SHA-256 ti system-prompt
}
```

Àwọn irú block: `text`, `tool_use`, `tool_result`. Tab Conversation máa ń lo ìrísí yìí láìka provider sí.

### 4.4 Fífi àwọ̀ sí context key (`src/mitm/inspector/contextKey.ts`)

- Ó ń ṣírò `SHA-256` ti system prompt (message `role:system` àkọ́kọ́, tàbí field `system`, tàbí `systemInstruction` Gemini)
- Ó ń dá prefix hex oníkọ̀ọ̀kan 12 padà (`"a3f9c2..."`)
- Frontend ń so key náà pọ̀ mọ́ àwọ̀ HSL tí kì í yí padà fún ọ̀pá ààlà òsì
- **Àlẹ̀mọ́ "context kan náà"**: títẹ chip `ctx #a3f` ń fi àlẹ̀mọ́ kan kún un láti fi àwọn ìbéèrè tó ní fingerprint kan náà nìkan hàn

Èyí mú kó rọrùn láti fi ojú ṣe ìyàtọ̀ láàárín onírúurú "persona" tàbí iṣẹ́ tó ń ṣiṣẹ́ nínú session agent kan náà.

### 4.5 Yíyọ metadata LLM jáde

Fún àwọn ìbéèrè LLM, tab LLM Details ń yọ àwọn wọ̀nyí jáde:

```ts
interface LlmMetadata {
  provider: string | null; // "openai" | "anthropic" | "gemini" | ...
  apiKind: string | null; // "chat.completions" | "messages" | "embeddings" | ...
  model: string | null; // láti inú body ìbéèrè tàbí ìdáhùn
  messages: number; // iye àwọn turn
  tokensIn: number | null; // usage.prompt_tokens / usage.input_tokens
  tokensOut: number | null; // usage.completion_tokens / usage.output_tokens
  streamed: boolean; // true bí ó bá jẹ́ ìdáhùn SSE
  mappedTo: string | null; // header x-omniroute-mapped
  costEstimateUsd: number | null; // ìṣírò owó tí a fojú díwọ̀n lórí ìdíyelé OmniRoute
}
```

### 4.6 Àlẹ̀mọ́ ìbéèrè in-flight lọ́wọ́lọ́wọ́

Field `status` ti ìbéèrè jẹ́ `number | "in-flight" | "error"` — a máa ń fi entry kan ránṣẹ́ gẹ́gẹ́ bí `"in-flight"` ní kété tí ìbéèrè bá bẹ̀rẹ̀, a sì máa ń **ṣe àfikún rẹ̀ ní ibi kan náà**
nígbà tí ìdáhùn (tàbí àṣìṣe) bá dé. Toggle **"Live"** inú toolbar
(`liveOnly`, key i18n `trafficInspector.liveOnly`) máa ń dí àtòkọ náà mọ́ àwọn entry
tí `status === "in-flight"` wọn, èyí tó ń jẹ́ kó o lè wo àwọn connection tó ṣí sílẹ̀ ní àkókò gidi.

Àlẹ̀mọ́ náà jẹ́ predicate client-side lásán nínú
`src/lib/inspector/matchesTrafficFilter.ts`:

```ts
if (f.liveOnly && req.status !== "in-flight") return false;
```

State toggle náà wà nínú `useTrafficFilters` (àwọn hook dashboard inspector), ó sì
ń darapọ̀ mọ́ àwọn àlẹ̀mọ́ yòókù (profile, host, agent, source, status, context).

### 4.7 Ìsọ̀rí process tó fa ìbéèrè (Linux)

Lórí Linux, a lè so ìbéèrè kọ̀ọ̀kan tí a dádúró mọ́ **process abẹ́nú tó pilẹ̀ rẹ̀**.
Àwọn field àṣàyàn méjì ni a fi kún `InterceptedRequest`:

```ts
pid?: number;          // id process tó pilẹ̀ rẹ̀ (Linux nìkan)
processName?: string;  // orúkọ process tó pilẹ̀ rẹ̀ (Linux nìkan)
```

`src/mitm/inspector/processAttribution.ts` ń so ephemeral port _client_ ti connection náà
mọ́ PID + orúkọ nípa:

1. Kíka `/proc/net/tcp` àti `/proc/net/tcp6` láti rí inode socket fún
   port náà (`parseProcNetTcpForInode`, parser mímọ́ tí a lè fi fixture dánwò).
2. Ṣíṣàyẹ̀wò `/proc/<pid>/fd/` fún symlink kan sí `socket:[<inode>]`.
3. Kíka orúkọ process láti `/proc/<pid>/comm`.

Cache TTL ìṣẹ́jú-àáyá 1 ń dín iye owó scan procfs kù lábẹ́ ẹrù. Ìsọ̀rí náà jẹ́
**ìgbìyànjú-tó-dára-jù** — ìkùnà èyíkéyìí máa ń yọrí sí `null`, kò sì ní dí capture dúró láé. Lórí
macOS/Windows, function náà ń dá `null` padà (stub; àtìlẹ́yìn `lsof`/`GetExtendedTcpTable`
jẹ́ iṣẹ́ tó máa tẹ̀lé).

## §5 Àwọn Sáẹ́ṣọ̀nù

### 5.1 Gígba sáẹ́ṣọ̀nù kan sílẹ̀

1. Tẹ **"● Gba sáẹ́ṣọ̀nù sílẹ̀"** nínú pẹpẹ irinṣẹ́ → tẹ orúkọ kan sí i (kò pọn dandan)
2. Ìṣàn aláàyè ń tẹ̀síwájú gẹ́gẹ́ bí ó ti yẹ; àmì pupa tí ń tàn-léraléra yóò fi `◉ REC · <name> · 00:42 · 23 reqs` hàn
3. Tẹ **"⏹ Dúró"** → àwòrán-ipò sáẹ́ṣọ̀nù náà ni a ó fi pamọ́ sínú `inspector_sessions` + `inspector_session_requests`

### 5.2 Wíwo sáẹ́ṣọ̀nù tí a gbà sílẹ̀

Àkojọ aṣàyàn **Àwọn Sáẹ́ṣọ̀nù** nínú pẹpẹ irinṣẹ́ ṣe àkójọ àwọn sáẹ́ṣọ̀nù tí a fi pamọ́. Nígbà tí o bá yan ọ̀kan:

- Ó ń ṣàkójọpọ̀ àwòrán-ipò sáẹ́ṣọ̀nù náà (ipò tí a ti dì)
- Àsíá kan yóò fi hàn: `Ń wo sáẹ́ṣọ̀nù tí a gbà sílẹ̀ "<name>" — [Padà sí ìṣàn aláàyè]`
- Táàbù Àwọn Ìṣirò yóò wà fún lílò pẹ̀lú àwọn àkójọpọ̀ Recharts

### 5.3 Àwọn ọ̀nà àgbéjáde

A lè gbé sáẹ́ṣọ̀nù kọ̀ọ̀kan jáde gẹ́gẹ́ bí:

| Ọ̀nà                      | Ìlò                                                                            |
| ------------------------ | ------------------------------------------------------------------------------ |
| **HAR** (Àpamọ́ HTTP 1.2) | Ó bá Chrome DevTools, Charles, Fiddler mu — gbé e wọlé fún ìtúpalẹ̀ láìsí àsopọ̀ |
| **JSONL**                | `InterceptedRequest` kan ní ìlà kọ̀ọ̀kan — ó bá ọ̀nà kika `llm-interceptor` mu    |

Gbé e jáde nípasẹ̀ `GET /api/tools/traffic-inspector/sessions/{id}/export.har` tàbí bọ́tìnì ⬇ nínú àkojọ aṣàyàn Àwọn Sáẹ́ṣọ̀nù.

## §6 Ààbò

Traffic Inspector ń fi **gbogbo ìrìnàjò HTTPS tí a dáwọ́ dúró** hàn, pẹ̀lú àwọn àkọsórí ìfàṣẹsí àti àwọn àkóónú ìbéèrè. Àwọn ìṣàkóso wọ̀nyí ló wà nípò:

| Ìṣàkóso                     | Àwọn àlàyé                                                                                                                                                                    |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LOCAL_ONLY**              | Gbogbo àwọn ipa-ọ̀nà àti ojú-ipari WebSocket jẹ́ ti loopback nìkan (a fipá mú un nínú `routeGuard.ts` ṣáájú ìfàṣẹsí)                                                            |
| **Ìbòjú aṣírí**             | Ẹ̀rọ àyẹ̀wò laini `maskSecret()` ń fi àmì ìbòjú bo àwọn ẹ̀rí RFC 6750 Bearer, àwọn kọ́kọ́rọ́ tí ìbẹ̀rẹ̀ wọn tọ́ka sí olùpèsè àti àwọn àmì aláìlópin gígùn ṣáájú `TrafficBuffer.push()` |
| **Òpin ìwọ̀n àkóónú**        | Àwọn àkóónú > `INSPECTOR_MAX_BODY_KB` (àìyípadà 1024 KB) ni a ké kúrú pẹ̀lú àkíyèsí `"(a ké e kúrú fún ìṣiṣẹ́ dáradára)"`                                                       |
| **Ìmọ́tótó àkọsórí**         | A sọ àwọn orúkọ di lẹ́tà kékeré; a yọ àwọn àkọsórí framing/hop-by-hop àti proxy-auth kúrò; a bo àwọn kúkì pátápátá; àwọn iye ẹ̀rí ni a fi lé `maskSecret()` lọ́wọ́                |
| **CSP**                     | Ìlànà Ààbò Àkóónú tó le lórí àwọn ojú-ewé Traffic Inspector láti dènà XSS nípasẹ̀ àwọn àkóónú ìdáhùn tí a fi wọlé                                                              |
| **Kò sí ìpamọ́ ní àìyípadà** | `TrafficBuffer` wà nínú ìrántí, ó sì máa ń sọnù nígbà tí olupin bá tún bẹ̀rẹ̀. Àwọn sáẹ́ṣọ̀nù ni a máa ń fi pamọ́ nígbà tí a bá gbà wọ́n sílẹ̀ ní kedere nìkan                       |

### Àwọn ààlà tí a mọ̀

- **Ipò aṣojú jákèjádò ètò** ní ipa lórí gbogbo àwọn ètò-ìṣàmúlò lórí ẹ̀rọ náà, pẹ̀lú àwọn oníbàárà VPN àti SSO. Máa lò ó pẹ̀lú aago ìdádúró aládàáṣe ní gbogbo ìgbà. Má ṣe lò ó lórí àwọn ẹ̀rọ tí ọ̀pọ̀ ènìyàn ń pín.
- **HTTPS inú ọ̀nà abẹ́lẹ̀ CONNECT**: Ipò 3 (HTTP_PROXY) ń gba metadata ọ̀nà abẹ́lẹ̀ nìkan fún àwọn ibi-àfojúsùn HTTPS àyàfi tí a bá mú ìdásí TLS ṣiṣẹ́. Èyí jẹ́ gẹ́gẹ́ bí a ṣe ṣe àgbékalẹ̀ rẹ̀ — gbígba ní gbangba láìjẹ́ pé a fọkàn tán ìwé-ẹ̀rí AgentBridge yóò ba ìjẹ́rìísí TLS jẹ́ fún àwọn ètò-ìṣàmúlò wọ̀nyẹn.
- **Àwọn ọ̀rọ̀ tí a kọ sínú kóòdù ní tààrà nínú díẹ̀ lára àwọn àkópọ̀**: Díẹ̀ lára àwọn àkópọ̀ UI (F7/F8) ní iye kékeré ti àwọn ọ̀rọ̀ tí a kọ sínú kóòdù ní tààrà tí àwọn kọ́kọ́rọ́ i18n kò tíì bo. A ṣàkọsílẹ̀ wọ̀nyí gẹ́gẹ́ bí Ààlà Tí A Mọ̀ nínú ìjábọ̀ àlàfo i18n; a ó ṣí wọn lọ ní ìpele àtẹ̀lé. Àwọn ọ̀rọ̀ tí èyí kàn jẹ́ àmì ọ̀ṣọ́ UI tí kò nílò ìtumọ̀ fún lílò iṣẹ́.

## §7 Yíyanjú ìṣòro

### Ìjáwọ́ WebSocket

Tí ìṣàn àyè-gidi bá fi "Asopọ̀ ti já" hàn:

1. Ṣàyẹ̀wò pé olupin ṣì ń ṣiṣẹ́: `GET /api/tools/traffic-inspector/capture-modes`
2. Tún ojúewé náà gbé — WebSocket yóò tún sopọ̀, yóò sì gba àwòrán-ipò tuntun
3. Tí a bá tún olupin náà bẹ̀rẹ̀, búfà inú ìrántí ti di mímọ́ — àwọn àkọọlẹ̀ àtijọ́ ti sọnù àyàfi tí a bá gba sáṣọ̀n kan sílẹ̀

### Ìforígbárí ibùdó 8080

Tí módù HTTP_PROXY kò bá le bẹ̀rẹ̀:

```bash
lsof -i :8080    # wá ìlànà iṣẹ́ náà
```

Yí ibùdó náà padà:

```bash
# .env
INSPECTOR_HTTP_PROXY_PORT=8888
```

### Aṣojú ẹ̀rọ tí a kò dá padà

Tí OmniRoute bá já lulẹ̀ nígbà tí módù aṣojú gbogbo ẹ̀rọ ń ṣiṣẹ́:

**macOS:**

```bash
networksetup -setwebproxystate Wi-Fi off
networksetup -setsecurewebproxystate Wi-Fi off
```

**Linux (GNOME):**

```bash
gsettings set org.gnome.system.proxy mode 'none'
```

**Windows:**

```cmd
netsh winhttp reset proxy
```

Dasibodu náà yóò tún fúnni ní "Dá aṣojú ẹ̀rọ padà" nígbà tí a bá tún gbé e lẹ́ẹ̀kan sí i, tí ó bá rí i pé ipò DB fi hàn pé aṣojú náà ń ṣiṣẹ́.

### Búfà ti kún

Nígbà tí búfà bá dé `INSPECTOR_BUFFER_SIZE` (àìyípadà rẹ̀ ni 1000), àwọn àkọọlẹ̀ tuntun yóò yọ àwọn èyí tí ó ti pé jù lọ kúrò. Tí àwọn ìbéèrè pàtàkì bá ń sọnù:

- Ṣàfikún `INSPECTOR_BUFFER_SIZE` (fún àpẹẹrẹ, 5000) — èyí ń fi ìrántí pàṣípààrọ̀ fún ìdádúró dátà
- Gba sáṣọ̀n kan sílẹ̀ láti tọ́jú àkókò tó yẹ sínú DB

## §8 Ìtọ́kasí API

Gbogbo àwọn ipa-ọ̀nà jẹ́ `LOCAL_ONLY` (loopback nìkan) àti `SPAWN_CAPABLE` (àwọn àṣẹ aṣojú ẹ̀rọ). Wo `src/server/authz/routeGuard.ts`.

Ipá-ọ̀nà ìpìlẹ̀: `/api/tools/traffic-inspector/`

### Ìṣàkóso ìbéèrè

| Ọ̀nà    | Ipá-ọ̀nà                     | Àpèjúwe                                                                                       |
| ------ | --------------------------- | --------------------------------------------------------------------------------------------- |
| GET    | `/requests`                 | Ṣe àkójọ àwọn ìbéèrè (ó ṣeé ṣe àlẹ̀mọ́: `?profile=llm&host=&agent=&status=&source=&sessionId=`) |
| GET    | `/requests/{id}`            | Àwọn ẹ̀kúnrẹ́rẹ́ ìbéèrè kan ṣoṣo                                                                 |
| DELETE | `/requests`                 | Pa búfà inú ìrántí rẹ́                                                                         |
| POST   | `/requests/{id}/replay`     | Ṣiṣe ìbéèrè kan náà lẹ́ẹ̀kan sí i nípasẹ̀ olùtọ́sọ́nà OmniRoute                                    |
| PUT    | `/requests/{id}/annotation` | Fi àkọsílẹ̀ kan pamọ́ tàbí ṣe ìmúdójúìwọ̀n rẹ̀ lórí ìbéèrè kan                                    |

### WebSocket

| Ọ̀nà | Ipá-ọ̀nà | Àpèjúwe                                                                                                       |
| --- | ------- | ------------------------------------------------------------------------------------------------------------- |
| GET | `/ws`   | Ìṣàn WebSocket àyè-gidi. Ó máa ń fi `snapshot` ránṣẹ́ nígbà àsopọ̀, lẹ́yìn náà àwọn ìṣẹ̀lẹ̀ `new`/`update`/`clear` |

### Ìkójáde

| Ọ̀nà | Ipá-ọ̀nà       | Àpèjúwe                                               |
| --- | ------------- | ----------------------------------------------------- |
| GET | `/export.har` | Kó àkójọ tí a ti ṣàlẹ̀mọ́ lọ́wọ́lọ́wọ́ jáde gẹ́gẹ́ bí HAR 1.2 |

### Àwọn host àkànṣe

| Ọ̀nà    | Ipá-ọ̀nà         | Àpèjúwe                                              |
| ------ | --------------- | ---------------------------------------------------- |
| GET    | `/hosts`        | Ṣe àkójọ àwọn host àkànṣe                            |
| POST   | `/hosts`        | Ṣàfikún host (ó máa ń ṣàtúnṣe `/etc/hosts` fúnra rẹ̀) |
| DELETE | `/hosts/{host}` | Yọ host kúrò                                         |
| PATCH  | `/hosts/{host}` | Yí `enabled` padà                                    |

### Àwọn módù ìgbàsílẹ̀

| Ọ̀nà  | Ipá-ọ̀nà                        | Àpèjúwe                                                                                         |
| ---- | ------------------------------ | ----------------------------------------------------------------------------------------------- |
| GET  | `/capture-modes`               | Ipò àwọn módù AgentBridge / àwọn host àkànṣe / HTTP_PROXY / aṣojú ẹ̀rọ + ìyípadà `tls-intercept` |
| POST | `/capture-modes/http-proxy`    | Bẹ̀rẹ̀/dá olùgbọ́ HTTP_PROXY dúró (`{action: "start"\|"stop"}`)                                    |
| POST | `/capture-modes/system-proxy`  | Lo/dá aṣojú gbogbo ẹ̀rọ padà (`{action: "apply"\|"revert"}`)                                     |
| POST | `/capture-modes/tls-intercept` | Yí ìtúpalẹ̀ àkóónú HTTPS padà nínú módù aṣojú (`{enabled: boolean}`)                             |

> **Ìtúpalẹ̀ TPROXY** (módù ìgbàsílẹ̀ 5) ni ipa-ọ̀nà **ọ̀tọ̀** kan lábẹ́
> ìṣáájú AgentBridge ń darí — `GET / POST / DELETE /api/tools/agent-bridge/tproxy` — kì í ṣe
> lábẹ́ `/api/tools/traffic-inspector/`. Wo
> `docs/security/MITM-TPROXY-DECRYPT.md` (git; a kò kó o sínú `/docs`).
