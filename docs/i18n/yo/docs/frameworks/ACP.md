> **Ní ṣókí**: ACP ń jẹ́ kí OmniRoute ṣe ìpilẹ̀ṣẹ̀ àwọn aṣojú CLI (bíi Claude Code, Codex) gẹ́gẹ́ bí àwọn ìlànà ọmọ dípò lílo àwọn API HTTP. Èyí ń fún ọ ní ọ̀nà ìgbéwọlé "CLI-gẹ́gẹ́-bí-ẹ̀yìn".

---

## Kí Ni ACP?

ACP (Agent Client Protocol) jẹ́ ọ̀nà ìgbéwọlé **"CLI-gẹ́gẹ́-bí-ẹ̀yìn"** fún OmniRoute. Dípò dídá àwọn ìpè API HTTP sí àwọn olùpèsè AI dúró, ACP **ń ṣe ìpilẹ̀ṣẹ̀ àwọn aṣojú CLI gẹ́gẹ́ bí àwọn ìlànà ọmọ** ó sì ń fi àwọn ìbéèrè ránṣẹ́ nípasẹ̀ ojú-ọ̀nà ìbánisọ̀rọ̀ abinibi wọn.

### Kí Nìdí Tí O Fi Yẹ Kí O Lo ACP?

| Àǹfààní                        | Àpèjúwe                                         |
| ------------------------------ | ----------------------------------------------- |
| **Kò nílò àwọn kọ́kọ́rọ́ API**    | Ó ń lo ìfàṣẹ̀sí CLI tí o ti ní tẹ́lẹ̀              |
| **Ìlànà abinibi**              | Ó ń lo ọ̀nà àgbéwọlé/àbájáde abinibi CLI kọ̀ọ̀kan  |
| **Ìṣàwárí aládàáṣiṣẹ́**         | Ó ń ṣàwárí àwọn CLI tí a ti fi sori ẹ̀rọ rẹ      |
| **Àwọn aṣojú 15 tí a kọ sínú** | A ti ṣètò wọn tẹ́lẹ̀ fún àwọn irinṣẹ́ CLI olókìkí  |
| **Àwọn aṣojú àdáni**           | Ṣàfikún àwọn irinṣẹ́ CLI tirẹ nípasẹ̀ àwọn ètò    |
| **Ìṣàkóso ìlànà**              | Ó ń bójú tó ìgbésí-ayé (ṣẹ̀dá, firánṣẹ́, dá dúró) |

### Ìgbésẹ̀ 1: Fi Aṣojú CLI Sori Ẹ̀rọ

```bash
# Àpẹẹrẹ: Fi Claude Code CLI sori ẹ̀rọ
npm install -g @anthropic-ai/claude-code

# Ṣàyẹ̀wò fifi sori ẹ̀rọ
claude --version
```

ACP ń ṣàwárí àwọn aṣojú CLI tí a ti fi sori ẹ̀rọ rẹ ní aládàáṣiṣẹ́. Kò nílò àtúnṣe ètò kankan!

### Ìgbésẹ̀ 3: Lo Ọ̀nà Ìgbéwọlé ACP

Lẹ́yìn tí a bá ti ṣàwárí rẹ̀, a lè lo ACP gẹ́gẹ́ bí ọ̀nà ìgbéwọlé fún olùpèsè èyíkéyìí tí a ṣètìlẹ́yìn fún. OmniRoute yóò lo ACP ní aládàáṣiṣẹ́ nígbà tí CLI bá wà.

## Bí ACP Ṣe Ń Ṣiṣẹ́

### Ìṣètò

```
┌─────────────────┐
│  OmniRoute      │
│  (Aṣojú HTTP)   │
└────────┬────────┘
         │
         │ spawn()
         ▼
┌─────────────────┐
│  Ìlànà Ọmọ      │
│  (Aṣojú CLI)    │
│                 │
│  stdin  ◄──────┤  Fi ìbéèrè ránṣẹ́
│  stdout ──────►│  Gba ìdáhùn
│  stderr ──────►│  Gba àwọn àṣìṣe
└─────────────────┘
```

### Ìgbésí-ayé Ìlànà

1. **Ṣẹ̀dá** — ACP ń ṣẹ̀dá ìlànà ọmọ kan fún aṣojú CLI
2. **Firánṣẹ́** — ACP ń kọ àwọn ìbéèrè sínú stdin ìlànà náà
3. **Gbà** — ACP ń ka àwọn ìdáhùn láti stdout/stderr
4. **Ìṣàwárí Àìṣiṣẹ́** — ACP ń dúró fún ìṣẹ́jú-àáyá 2 tí kò sí ìgbòkègbodò kí ó tó kà ìdáhùn náà sí èyí tí ó pé
5. **Dá Dúró** — ACP ń fòpin sí ìlànà náà (SIGTERM, lẹ́yìn náà SIGKILL lẹ́yìn 5s)

### Ìlànà Ìbánisọ̀rọ̀

ACP ń lo **stdio** (àgbéwọlé/àbájáde boṣewa) fún ìbánisọ̀rọ̀ pẹ̀lú àwọn aṣojú CLI. Ìlànà náà ni:

1. **Fi ìbéèrè ránṣẹ́** — Kọ sínú stdin pẹ̀lú ìlà tuntun
2. **Dúró de ìdáhùn** — Ka láti stdout títí tí kò fi sí ìgbòkègbodò (2s láìsí àbájáde)
3. **Àkókò tó pọ̀jù** — Ìṣẹ́jú-àáyá 120 ní àiyẹsẹ̀ (ó ṣeé ṣàtúnṣe)

## Ìtọ́kasí API

### Àwọn Ìṣe Registry

#### `detectInstalledAgents()`

Ń ṣàwárí gbogbo àwọn aṣojú CLI tí a ti fi sí ẹ̀rọ náà. A máa ń fi àwọn àbájáde pamọ́ fún ìṣẹ́jú-àáyá 60.

```typescript
import { detectInstalledAgents } from "@/lib/acp";

const agents = detectInstalledAgents();
// Ó ń dá padà: CliAgentInfo[]

interface CliAgentInfo {
  id: string; // àpẹẹrẹ, "codex", "claude"
  name: string; // Orúkọ ìfihàn
  binary: string; // Orúkọ binary tí a óò ṣe ìpilẹ̀ṣẹ̀ rẹ̀
  versionCommand: string; // Àṣẹ ìṣàwárí ẹ̀yà
  version: string | null; // Ẹ̀yà tí a ṣàwárí (null bí a kò bá fi í sílẹ̀)
  installed: boolean; // Bóyá a ti fi aṣojú náà sílẹ̀
  providerAlias: string; // ID olùpèsè nínú OmniRoute
  spawnArgs: string[]; // Àwọn àríyànjiyàn láti fi ránṣẹ́ nígbà ìpilẹ̀ṣẹ̀
  protocol: "stdio" | "http"; // Ìlànà ìbánisọ̀rọ̀
  isCustom?: boolean; // Bóyá èyí jẹ́ aṣojú àkànṣe tí olùlò ṣàlàyé
}
```

#### `getAvailableAgents()`

Ń gba àwọn aṣojú tí a ti fi sílẹ̀ tí wọ́n sì wà fún ACP nìkan.

```typescript
import { getAvailableAgents } from "@/lib/acp";

const available = getAvailableAgents();
// Ó ń dá padà: CliAgentInfo[] (àwọn aṣojú tí a ti fi sílẹ̀ nìkan)
```

#### `getAgentById(id)`

Ń gba aṣojú pàtó kan nípasẹ̀ ID.

```typescript
import { getAgentById } from "@/lib/acp";

const agent = getAgentById("claude");
// Ó ń dá padà: CliAgentInfo | undefined
```

#### `setCustomAgents(agents)`

Ń ṣètò àwọn ìtumọ̀ aṣojú àkànṣe láti inú àwọn ààtò.

```typescript
import { setCustomAgents } from "@/lib/acp";

setCustomAgents([
  {
    id: "my-custom-cli",
    name: "My Custom CLI",
    binary: "mycli",
    versionCommand: "mycli --version",
    providerAlias: "my-provider",
    spawnArgs: [],
    protocol: "stdio",
  },
]);
```

### Àwọn Ìṣe Alákóso

#### `acpManager.spawn(agentId, binary, args, env)`

Ń ṣe ìpilẹ̀ṣẹ̀ ìlànà aṣojú CLI tuntun kan.

```typescript
import { acpManager } from "@/lib/acp";

const session = acpManager.spawn("claude", "claude", ["--print", "--output-format", "json"], {
  /* àwọn oníyípadà env àkànṣe */
});
// Ó ń dá padà: AcpSession
```

**Àwọn ID aṣojú tí a fàyè gbà**: `["claude", "codex", "gemini", "qwen"]`

#### `acpManager.sendPrompt(sessionId, prompt, timeoutMs)`

Ń fi àṣẹ-ìbéèrè ránṣẹ́ sí aṣojú CLI kan, ó sì ń kó èsì náà jọ.

```typescript
import { acpManager } from "@/lib/acp";

const response = await acpManager.sendPrompt(
  "acp-claude-1234567890-abc123",
  "What is 2+2?",
  120000 // àkókò ìparí ìṣẹ́jú 2
);
// Ó ń dá padà: Promise<string>
```

#### `acpManager.kill(sessionId)`

Ń dá sáà kan dúró, ó sì ń ṣe ìmúnúdọ̀tí.

```typescript
import { acpManager } from "@/lib/acp";

const killed = acpManager.kill("acp-claude-1234567890-abc123");
// Ó ń dá padà: boolean
```

#### `acpManager.getActiveSessions()`

Ń gba gbogbo àwọn sáà tó ń ṣiṣẹ́.

```typescript
import { acpManager } from "@/lib/acp";

const sessions = acpManager.getActiveSessions();
// Ó ń dá padà: AcpSession[]
```

#### `acpManager.killAll()`

Ń dá gbogbo àwọn sáà dúró.

```typescript
import { acpManager } from "@/lib/acp";

acpManager.killAll();
```

### Ìjúmọ̀ọ́sọ́nà Sáà

```typescript
interface AcpSession {
  id: string; // ID sáà aláìlẹ́gbẹ́
  agentId: string; // ID aṣojú (àpẹẹrẹ, "claude")
  process: ChildProcess; // Ọ̀nà ìdarí ìlànà ọmọ
  alive: boolean; // Bóyá ìlànà náà ṣì ń ṣiṣẹ́
  stdoutBuffer: string; // Àkójọpọ̀ ìfipamọ́ stdout
  stderrBuffer: string; // Àkójọpọ̀ ìfipamọ́ stderr
  createdAt: Date; // Àmì-àkókò tí a dá a sílẹ̀
}
```

### Àwọn Ìṣẹ̀lẹ̀

`AcpManager` ń fa `EventEmitter` gùn, ó sì ń gbé àwọn ìṣẹ̀lẹ̀ wọ̀nyí jáde:

#### `stdout`

A máa ń gbé e jáde nígbà tí aṣojú CLI bá kọ sí stdout.

```typescript
acpManager.on("stdout", ({ sessionId, data }) => {
  console.log(`[${sessionId}] stdout: ${data}`);
});
```

#### `stderr`

A máa ń gbé e jáde nígbà tí aṣojú CLI bá kọ sí stderr.

```typescript
acpManager.on("stderr", ({ sessionId, data }) => {
  console.error(`[${sessionId}] stderr: ${data}`);
});
```

#### `exit`

A máa ń gbé e jáde nígbà tí ìlànà aṣojú CLI bá jáde.

```typescript
acpManager.on("exit", ({ sessionId, code, signal }) => {
  console.log(`[${sessionId}] exited with code ${code}, signal ${signal}`);
});
```

#### `error`

A máa ń gbé e jáde nígbà tí àṣìṣe bá ṣẹlẹ̀ sí ìlànà aṣojú CLI.

```typescript
acpManager.on("error", ({ sessionId, error }) => {
  console.error(`[${sessionId}] error: ${error}`);
});
```

## Ìṣètò

### Àwọn Àyípadà Àyíká

ACP máa ń jogún gbogbo àwọn àyípadà àyíká láti inú ìlànà òbí, a sì lè fi àwọn env vars àdáni kún wọn:

```typescript
acpManager.spawn("claude", "claude", [], {
  ANTHROPIC_API_KEY: "sk-...",
  DEBUG: "true",
});
```

### Àwọn Àríyànjiyàn Ìpilẹ̀ṣẹ̀

Olùṣojú kọ̀ọ̀kan ní àwọn àríyànjiyàn ìpilẹ̀ṣẹ̀ àìyípadà tí a ṣàlàyé sínú ìforúkọsílẹ̀. O lè kọjá lórí wọn:

```typescript
acpManager.spawn("claude", "claude", ["--print", "--verbose"], {});
```

### Àwọn Àkókò Ìdádúró Tó Pẹ́ Jù

Àkókò ìdádúró tó pẹ́ jù àìyípadà fún prompt jẹ́ **120 ìṣẹ́jú-ààyá** (ìṣẹ́jú 2). O lè kọjá lórí rẹ̀:

```typescript
await acpManager.sendPrompt(sessionId, prompt, 300000); // Ìṣẹ́jú 5
```

### Kaṣe Ìṣàwárí

A máa ń fi ìṣàwárí olùṣojú pamọ́ sínú kaṣe fún **60 ìṣẹ́jú-ààyá** láti yẹra fún àwọn àyẹ̀wò ètò fáìlì tí ń ná ohun àmúlò púpọ̀. Láti fipá mú un ṣe ìmúdójúìwọ̀n:

```typescript
import { refreshAgentCache } from "@/lib/acp";

refreshAgentCache();
```

## Ààbò

### Ìdènà Ìkọlù Nípasẹ̀ Àṣẹ

ACP máa ń fìdí àwọn àṣẹ ẹ̀yà múlẹ̀ láti dènà àwọn ìkọlù nípasẹ̀ àṣẹ:

```typescript
const DISALLOWED_VERSION_COMMAND_CHARS = /[;&|<>`$\r\n]/;
```

A máa kọ àwọn àṣẹ ẹ̀yà tí ó ní àwọn àmi wọ̀nyí:

- `;` — Olùpín àṣẹ
- `&` — Ìlànà abẹ́lẹ̀
- `|` — Píìpù
- `<`, `>` — Ìdarípadà
- `` ` `` — Ìrọ́pò àṣẹ
- `$` — Ìfẹ̀síwájú àyípadà
- `\r`, `\n` — Ìjá ìlà

### Ìfìdímúlẹ̀ Orúkọ Binary

ACP máa ń fìdí rẹ̀ múlẹ̀ pé binary àṣẹ ẹ̀yà bá orúkọ binary tí a retí mu (àfi bí ó bá jẹ́ olùṣojú àdáni).

### Ìyàsọ́tọ̀ Ìlànà

Ìgbà ACP kọ̀ọ̀kan máa ń ṣiṣẹ́ nínú ìlànà ọmọ tirẹ̀. A máa pa ìlànà náà nígbà tí ìgbà náà bá parí tàbí tí àkókò rẹ̀ bá kọjá.

## Ìṣiṣẹ́

### Ìṣiṣẹ́ Ìṣàwárí

- **Ìpè àkọ́kọ́**: ~50-200ms (ń ṣiṣẹ́ àṣẹ `version` fún olùṣojú kọ̀ọ̀kan)
- **Àwọn ìpè láti inú kaṣe**: <1ms (ń dá èsì padà láti inú kaṣe)
- **TTL kaṣe**: 60 ìṣẹ́jú-ààyá

### Ìṣiṣẹ́ Prompt

- **Ìpilẹ̀ṣẹ̀**: ~50-100ms
- **Fífi prompt ránṣẹ́**: ~10-50ms
- **Dídúró de èsì**: Ó sinmi lórí olùṣojú CLI (ní ọ̀pọ̀ ìgbà, ìṣẹ́jú-ààyá 1-30)
- **Pípa**: ~5 ìṣẹ́jú-ààyá (SIGTERM) + lẹ́sẹ̀kẹsẹ̀ (SIGKILL)

### Lílo Ohun Àmúlò

- **Ìrántí fún ìgbà kọ̀ọ̀kan**: ~10-50MB (ó sinmi lórí olùṣojú CLI)
- **CPU**: Kéré gan-an (I/O bound)
- **Dísìkì**: Kò sí

## Yíyanjú Ìṣòro

### Àṣìṣe "Unknown agent"

**Ìṣòro**: `acpManager.spawn()` máa ń ju `Unknown agent: <id>` jáde

**Ojútùú**: Àwọn olùṣojú wọ̀nyí nìkan ni a gbà láàyè nínú `spawn()`:

- `claude`
- `codex`
- `gemini`
- `qwen`

A gbọ́dọ̀ pilẹ̀ àwọn olùṣojú mìíràn pẹ̀lú ọwọ́ tàbí nípasẹ̀ àwọn àlàyé olùṣojú àdáni.

### Àṣìṣe "Session not alive"

**Ìṣòro**: `acpManager.sendPrompt()` máa ń ju `Session ${sessionId} is not alive` jáde

**Ojútùú**: Ó ṣeé ṣe kí ìgbà náà ti jáde tàbí kí a ti pa á. Ṣàyẹ̀wò ipò ìgbà náà:

```typescript
const session = acpManager.getSession(sessionId);
if (!session?.alive) {
  // Tún ìgbà náà pilẹ̀
  acpManager.spawn("claude", "claude", [], {});
}
```

### Àṣìṣe "ACP timeout"

**Ìṣòro**: `acpManager.sendPrompt()` máa ń ju `ACP timeout after 120000ms` jáde

**Ojútùú**: Mú àkókò ìdádúró tó pẹ́ jù pọ̀ sí i:

```typescript
await acpManager.sendPrompt(sessionId, prompt, 300000); // Ìṣẹ́jú 5
```

### A Kò Ṣàwárí CLI

**Ìṣòro**: `detectInstalledAgents()` kò rí CLI rẹ

**Àwọn ojútùú**:

1. **Ṣàyẹ̀wò PATH**: Rí i dájú pé CLI náà wà nínú PATH ètò rẹ
2. **Ṣàyẹ̀wò àṣẹ ẹ̀yà**: Ṣiṣẹ́ `claude --version` pẹ̀lú ọwọ́
3. **Ṣàyẹ̀wò àwọn àṣẹ ìyọ̀ǹda**: Rí i dájú pé CLI náà ṣeé ṣiṣẹ́
4. **Olùṣojú àdáni**: Ṣàfikún àlàyé olùṣojú àdáni fún àwọn CLI tí kì í ṣe ti ìlànà àárín

### A Kọ Àṣẹ Ìyọ̀ǹda

**Ìṣòro**: ACP kò lè ṣiṣẹ́ CLI náà

**Àwọn ojútùú**:

1. **Ṣàyẹ̀wò àwọn àṣẹ ìyọ̀ǹda fáìlì**: `chmod +x /usr/local/bin/claude`
2. **Ṣàyẹ̀wò ẹni tó ni ín**: Rí i dájú pé OmniRoute ní àwọn àṣẹ ìyọ̀ǹda láti kà á àti láti ṣiṣẹ́ ẹ
3. **Ṣàyẹ̀wò SELinux/AppArmor**: Ó lè dí ìpilẹ̀ṣẹ̀ ìlànà lọ́wọ́

## Àwọn Àpẹẹrẹ

### Àpẹẹrẹ 1: Ṣí Claude Code sílẹ̀ kí o sì Lò ó

```typescript
import { acpManager, detectInstalledAgents } from "@/lib/acp";

// Ṣàwárí àwọn agent tí a ti fi sórí ẹ̀rọ
const agents = detectInstalledAgents();
const claude = agents.find((a) => a.id === "claude");

if (claude?.installed) {
  // Ṣí session tuntun sílẹ̀
  const session = acpManager.spawn("claude", claude.binary, ["--print", "--output-format", "json"]);

  // Fi prompt ránṣẹ́
  const response = await acpManager.sendPrompt(
    session.id,
    "Explain quantum computing in 100 words"
  );

  console.log("Claude's response:", response);

  // Ṣe ìmọ́tótó
  acpManager.kill(session.id);
}
```

### Àpẹẹrẹ 2: Ìṣàwárí Aládàáṣe pẹ̀lú Àṣàyàn Ìpadà

```typescript
import { acpManager, getAvailableAgents } from "@/lib/acp";

const available = getAvailableAgents();

// Kọ́kọ́ gbìyànjú Claude, lo Codex gẹ́gẹ́ bí àṣàyàn ìpadà
let agentId = "claude";
if (!available.find((a) => a.id === "claude")) {
  if (available.find((a) => a.id === "codex")) {
    agentId = "codex";
  } else {
    throw new Error("No ACP-compatible CLI agent found");
  }
}

const agent = available.find((a) => a.id === agentId)!;
const session = acpManager.spawn(agentId, agent.binary, agent.spawnArgs);

const response = await acpManager.sendPrompt(session.id, "Hello!");

acpManager.kill(session.id);
```

### Àpẹẹrẹ 3: Agent Àkànṣe

```typescript
import { setCustomAgents, detectInstalledAgents } from "@/lib/acp";

// Forúkọsílẹ̀ agent CLI àkànṣe kan
setCustomAgents([
  {
    id: "my-llm-cli",
    name: "My LLM CLI",
    binary: "myllm",
    versionCommand: "myllm --version",
    providerAlias: "my-llm-provider",
    spawnArgs: ["--format", "json"],
    protocol: "stdio",
  },
]);

// Ní báyìí detectInstalledAgents() yóò ní "my-llm-cli" nínú
const agents = detectInstalledAgents();
```
