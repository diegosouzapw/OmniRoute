> **Orísun òtítọ́:** `src/lib/agentSkills/` (àkójọ, olùpilẹ̀ṣẹ̀, àwọn olùtúpalẹ̀) + àkójọpọ̀ fáìlì `skills/` (àwọn fáìlì SKILL.md)
> **Ìmúdójúìwọ̀n tó ṣẹ̀ṣẹ̀:** 2026-08-02 — v3.8.50

Agent Skills jẹ́ àwọn fáìlì SKILL.md tí a ṣètò sí ìlànà, tí ń kọ́ àwọn aṣojú òde, àwọn oníbàárà MCP, àti àwọn olùṣètò A2A bí wọ́n ṣe lè lo REST API àti CLI ti OmniRoute. Yàtọ̀ sí [Omni Skills](./SKILLS.md) (tí ó jẹ́ àwọn ìtumọ̀ irinṣẹ́ LLM tí a ń ṣiṣẹ́ nínú OmniRoute), Agent Skills jẹ́ _àkójọ àkọsílẹ̀_ — markdown aláìyípadà tí a lè fi tààrà sínú àyíká ọ̀rọ̀ aṣojú.

---

## Àkíyèsí Gbogbogbò

Àkójọ náà ní **45 Agent Skills** (23 REST API + 21 CLI + 1 ìṣàn-iṣẹ́ ìṣètò). Skill kọ̀ọ̀kan ní:

- **ID àṣẹ** kan (`omni-auth`, `cli-serve`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ)
- Fáìlì **SKILL.md** kan nínú `skills/{id}/SKILL.md` pẹ̀lú YAML frontmatter (`name`, `description`) + àkóónú markdown ọlọ́rọ̀
- **Àwọn endpoint REST** (àwọn skill API) tàbí **àwọn subcommand CLI** (àwọn skill CLI) tí a mú jáde láti inú OpenAPI spec àti àkọsílẹ̀ CLI
- **URL raw GitHub** kan fún gbígbà á ní tààrà: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Ìṣàwárí REST API

| Ojú-ọ̀nà                      | Ọ̀nà  | Àpèjúwe                                                               | Ìfàṣẹsí |
| :--------------------------- | :--- | :-------------------------------------------------------------------- | :------ |
| `/api/agent-skills`          | GET  | Ṣàkójọ katalọ́ọ̀gù (`?category=api\|cli\|config&area=<area>` jẹ́ àṣàyàn) | kò sí   |
| `/api/agent-skills/{id}`     | GET  | Gba metadata ọgbọ́n kan ṣoṣo                                           | kò sí   |
| `/api/agent-skills/{id}/raw` | GET  | Fa SKILL.md gẹ́gẹ́ bí `text/markdown`                                   | kò sí   |
| `/api/agent-skills/coverage` | GET  | Àwọn ìṣirò ìborí (iye fáìlì SKILL.md tí ó wà)                         | kò sí   |
| `/api/agent-skills/generate` | POST | Mú olùpilẹ̀ṣẹ̀ ṣiṣẹ́ (dryRun/prune/onlyIds)                              | ìṣàkóso |

Àpẹẹrẹ — ṣàkójọ gbogbo àwọn ọgbọ́n API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Àpẹẹrẹ — fa SKILL.md kan ṣoṣo:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Bí Àwọn Aṣojú Òde Ṣe Ń Lo Àwọn Ọgbọ́n

### 1. Ìṣàwárí nípasẹ̀ REST

```bash
# Gba gbogbo àkójọ náà
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Gba SKILL.md fún fífi ọ̀rọ̀-àyíká sínú
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Ìṣàwárí nípasẹ̀ MCP

```typescript
// Nínú Claude Desktop / Cursor MCP client kan:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → àkójọpọ̀ AgentSkill pẹ̀lú rawUrl fún ọ̀kọ̀ọ̀kan
```

### 3. Ìṣàwárí nípasẹ̀ A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table jẹ́ tábìlì markdown tí ó ní gbogbo ID ọgbọ́n 45 àti àwọn ọwọ̀n rawUrl
```

### 4. Gbígba raw láti GitHub ní tààrà (kò nílò server)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Ẹ̀rọ Ìṣẹ̀dá

Ẹ̀rọ ìṣẹ̀dá náà máa ń ka àkójọ tí a ti ṣètò + àlàyé OpenAPI + ìforúkọsílẹ̀ CLI, ó sì máa ń kọ `skills/{id}/SKILL.md` fún ohun kọ̀ọ̀kan:

```bash
# Àwòtẹ́lẹ̀ (ìṣiṣẹ́ ìdánwò, kò kọ ohunkóhun)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Àtúnṣẹ̀dá ní kíkún
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Ṣe àtúnṣẹ̀dá àwọn ID pàtó
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Ìdáhùn ẹ̀rọ ìṣẹ̀dá náà jẹ́ `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
