## Àkópọ̀

Playground Studio yí `/dashboard/playground` padà láti inú olóòtú tó rọrùn tí ó dá lórí Monaco sí
àyè iṣẹ́ ìdánwò tó ní gbogbo ẹ̀ya. Ó fi ikarahun `PlaygroundStudio` rọ́pò `page.tsx` àtijọ́,
èyí tó ń ṣàfihàn àwọn taabu mẹ́rin àti pánẹ́ẹ̀lì àtúnṣe tí wọ́n jọ ń lò.

## Àwọn Taabu

### Taabu Ìjíròrò

Ó mú `ChatPlayground.tsx` dàgbà sí ibi iṣẹ́ ṣiṣanwọlé oníyípo-púpọ̀:

- Ìṣàfihàn markdown ní ẹ̀kúnrẹ́rẹ́ nípasẹ̀ `MarkdownMessage.tsx` (àwọn ìdípọ̀ kóòdù, àwọn tábìlì, àwọn àtòjọ, àwọn ọ̀nà asopọ̀).
- Prompt ètò tí a mú láti inú pánẹ́ẹ̀lì Àtúnṣe àpapọ̀.
- Token/ìnáwó fún ọ̀kọ̀ọ̀kan ìfiránṣẹ́ (àwọn token prompt + ìparí).
- Ṣẹ̀dá èsì tó kẹ́yìn padà.
- Ó ń fi ránṣẹ́ sí `POST /v1/chat/completions` pẹ̀lú ṣiṣanwọlé SSE.

### Taabu Ìfiwéra

Ohun pàtàkì tó yà á sọ́tọ̀ fún proxy: ṣe prompt 1 lórí àwọn àwòṣe tó tó **4 ní àkókò kan náà**.

- Tó àwọn ọ̀wọ̀n 4, tí ọ̀kọ̀ọ̀kan ń ṣàn lọ́tọ̀ọ̀tọ̀ láti `/v1/chat/completions`.
- Bọ́tìnì `+ Fi àwòṣe kún un` (ọ̀nà abuja Cmd+K) láti fi àwọn ọ̀wọ̀n kún un.
- `Ṣe gbogbo rẹ̀ ▶` ń bẹ̀rẹ̀ gbogbo àwọn ṣiṣan ní àkókò kan náà nípasẹ̀ `Promise.all` + `AbortController` fún ọ̀kọ̀ọ̀kan ọ̀wọ̀n.
- **Fagilé gbogbo rẹ̀** àgbáyé ń dá gbogbo ṣiṣan tó ń lọ lọ́wọ́ dúró.
- `ProviderMetrics` ti ọ̀kọ̀ọ̀kan ọ̀wọ̀n ń ṣàfihàn TTFT, TPS, àwọn token, àti ìnáwó àfojúsùn ní àkókò gidi.
- A fi àmì **"àfojúsùn ẹgbẹ́ client"** (D12) sí àwọn ìwọ̀n — a wọn wọ́n láti SSE chunk àkọ́kọ́.

### Taabu API

Ó pa 100% olóòtú Monaco ìpilẹ̀ṣẹ̀ mọ́ fún àwọn olùmúlò alágbára (D14):

- Àwọn endpoint 10: àwọn ìparí ìjíròrò, àwọn ìparí, àwọn embeddings, àwọn àwòrán, ohun, ọ̀rọ̀, àwọn ìkọ̀wé-ọ̀rọ̀, àwọn moderations, rerank, ìṣàwárí.
- Ìrùsókè fáìlì multimodal.
- Ṣiṣanwọlé SSE pẹ̀lú àbájáde ní àkókò gidi.
- A dì í mọ́ra gẹ́gẹ́ bí `ApiTab.tsx` (a ń gbé e wọlé nígbà tí a nílò rẹ̀, `ssr: false`).

### Taabu Ìkọ́lé

Àwọn irinṣẹ́/pípè iṣẹ́ àti UI àbájáde tó ní ìṣètò:

- `ToolsBuilder.tsx` — fi kún/ṣàtúnṣe/yọ `tools[]` pẹ̀lú olóòtú schema JSON fún ọ̀kọ̀ọ̀kan irinṣẹ́.
  Ó ń fìdí àwọn parameters múlẹ̀ nípasẹ̀ `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — tan/pa ipò JSON + olóòtú schema JSON.
  Ó ń fìdí èsì múlẹ̀ pẹ̀lú schema nípasẹ̀ `StructuredOutputSchema` (Zod).
- Ó ń fi ìbéèrè ránṣẹ́ sí `/v1/chat/completions` pẹ̀lú `tools[]` àti/tàbí `response_format`.

## Páńẹ́ẹ̀lì Àtòpọ̀ (Pínpín)

`StudioConfigPane.tsx` — máa ń hàn nígbà gbogbo, ó sì ṣeé kó papọ̀.

| Ààyè           | Kọ́ńpọ́nẹ́ǹtì            | Àwọn àkíyèsí                                                           |
| -------------- | --------------------- | ---------------------------------------------------------------------- |
| Endpoint       | `<select>`            | Àwọn àṣàyàn 10 tó bá `PlaygroundEndpoint` mu                           |
| Model          | `<input>`             | ọ̀rọ̀ àìlópin, bí àpẹẹrẹ `openai/gpt-4o`                                 |
| System prompt  | `<textarea>`          | a máa fi sínú gbogbo táàbù                                             |
| Parameters     | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop |
| Presets        | `PresetPicker`        | kó/fipamọ́ àwọn àwòrán àtòpọ̀ tó ní orúkọ (tí a tọ́jú sínú DB)            |
| Improve prompt | `ImprovePromptButton` | ṣí módà ìkìlọ̀ ìwọ̀n-lílò, ó sì pe `/api/playground/improve-prompt`      |

A gbé state sókè sí `PlaygroundStudio.tsx`, a sì fi ránṣẹ́ sí gbogbo táàbù. Yíyí táàbù padà
ń pa state àtòpọ̀ mọ́.

## Módà Ìkóòdù Jáde

`ExportCodeModal.tsx` ń lo `codeExport.ts` láti ṣe àwọn àjákù curl / Python / TypeScript
láti inú `PlaygroundState` lọ́wọ́lọ́wọ́. Ààyè ìrọ́pò́ kọ́kọ́rọ́ API máa ń jẹ́ `$OMNIROUTE_API_KEY` nígbà gbogbo (D11).

## Ẹ̀rọ Ìmúdára Prompt

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Módà náà ń kìlọ̀ pé “yóò lo ìwọ̀n-lílò”.
2. Nígbà ìmúdájú, ó fi `{ system, prompt, model, tone }` ránṣẹ́ sí route náà.
3. Route náà ń pe `/v1/chat/completions` ní abẹ́nú pẹ̀lú `promptImprover.META_SYSTEM_PROMPT`.
4. Ó dá `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` padà.
5. UI náà ń ṣàtúnṣe system prompt inú páńẹ́ẹ̀lì Àtòpọ̀ àti user prompt inú táàbù Chat.

## Àwọn Preset

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- A tọ́jú wọn sínú tábìlì SQLite `playground_presets` (migration `084_playground_presets.sql`).
- Preset kọ̀ọ̀kan ń tọ́jú: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: àtòjọ `GET`, ìṣẹ̀dá `POST`, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Àwọn Mẹ́tíríkì Stream

`useStreamMetrics.ts` + `streamMetrics.ts` (fúnkíṣọ̀nù mímọ́):

- `start()` — ń ṣàkọsílẹ̀ àkókò tí ìbéèrè bẹ̀rẹ̀.
- `onFirstChunk()` — ń ṣàkọsílẹ̀ TTFT.
- `onChunk(n)` — ń ṣàkójọpọ̀ iye token ìparí.
- `finish(usage?)` — ń ṣírò àwọn mẹ́tíríkì ìkẹyìn: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Ìdíyelé wá láti inú tábìlì aláìyípadà ní `src/lib/playground/types.ts` (tí a fi àmì “ìṣírò” sí — D13).

## Àwọn Route Backend

| Ọ̀nà      | Path                             | Handler                                                                                             |
| -------- | -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | Ṣe ìfọwọ́sí pẹ̀lú Zod lórí `ImprovePromptRequestSchema`; ó pe `/v1/chat/completions` pẹ̀lú meta-prompt |
| `GET`    | `/api/playground/presets`        | Ó dá `{ presets: PlaygroundPresetListItem[] }` padà                                                 |
| `POST`   | `/api/playground/presets`        | Ó ṣẹ̀dá preset; ó sì ṣe ìfọwọ́sí `PlaygroundPresetCreateSchema`                                       |
| `GET`    | `/api/playground/presets/:id`    | Ó dá preset kan padà tàbí 404                                                                       |
| `PUT`    | `/api/playground/presets/:id`    | Ìmúdójúìwọ̀n apá kan                                                                                 |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                 |

Ìfàṣẹsí: àṣàyàn ni (`REQUIRE_API_KEY`). Àwọn àṣìṣe nípasẹ̀ `buildErrorBody()` (Òfin Líle #12).
