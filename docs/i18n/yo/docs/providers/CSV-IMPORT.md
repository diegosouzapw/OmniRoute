Dashboard → Providers → **Gbé wọlé láti inú fáìlì** ń ṣẹ̀dá àwọn àsopọ̀ API-key láti inú àkójọ CSV tàbí JSON. Ìlà kọ̀ọ̀kan lè tọ́ka sí olùpèsè ọ̀tọ̀. Ìkùnà apá kan jẹ́ ara àdéhùn náà: àwọn ìlà tó fẹsẹ̀ múlẹ̀ ṣì máa ń wọlé nígbà tí àwọn mìíràn bá kùnà, modal náà sì máa ń ṣàfihàn ìdí tí a fi kọ àwọn ìlà tó kùnà.

Ìgbéwọlé yìí **kì í** ṣẹ̀dá àwọn node endpoint tuntun tó bá OpenAI/Anthropic mu. Kọ́kọ́ ṣẹ̀dá wọn (Dashboard → Providers → Add OpenAI-Compatible, tàbí `omniroute nodes add`), lẹ́yìn náà, gbé àwọn ìlà wọlé tí column `provider` wọn jẹ́ id node náà. `baseUrl` fún ìlà kọ̀ọ̀kan ṣì lè rọ́pò URL node náà.

## CSV (ní ìtẹ̀lé ipò)

Àwọn orúkọ column jẹ́ ohun ọ̀ṣọ́ lásán. Parser náà ń pín ìlà kọ̀ọ̀kan, ó sì ń tú u ká nípasẹ̀ index:

| Index | Field      | Dandan | Àwọn àkíyèsí                                                                                                                          |
| ----- | ---------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| 0     | `provider` | bẹ́ẹ̀ ni | Id olùpèsè tó wà tẹ́lẹ̀ tí a ń ṣàkóso (`openai`, `anthropic`, …) **tàbí** id **node** tó bá OpenAI/Anthropic mu tí a ti forúkọsílẹ̀ tẹ́lẹ̀ |
| 1     | `name`     | bẹ́ẹ̀ ni | Orúkọ àsopọ̀ tí a ó ṣàfihàn                                                                                                            |
| 2     | `apiKey`   | bẹ́ẹ̀ ni | Kọ́kọ́rọ́ API                                                                                                                            |
| 3     | `baseUrl`  | bẹ́ẹ̀ kọ́ | URL ìrọ́pò fún ìlà kọ̀ọ̀kan                                                                                                              |
| 4     | `priority` | bẹ́ẹ̀ kọ́ | Odidi nọ́ńbà 1–100                                                                                                                     |

A máa fo ìlà àkọ́kọ́ tí column àkọ́kọ́ rẹ̀ jẹ́ ọ̀rọ̀ gangan `provider` (ní ọ̀nà ìkọ̀wé lẹ́tà ńlá tàbí kékeré èyíkéyìí) gẹ́gẹ́ bí header. A tún máa fo àwọn ìlà òfìfo àti àwọn comment `#`.

Ṣe ìgbàsílẹ̀ fáìlì ìbẹ̀rẹ̀ láti inú modal ìgbéwọlé (**Ṣe ìgbàsílẹ̀ àdàkọ CSV**). Àpẹẹrẹ:

```csv
# Ìgbéwọlé olùpèsè OmniRoute (àwọn column ní ìtẹ̀lé ipò)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

Id àròsọ bíi `openai-compatible-chat-001` kì í ṣe node. API náà máa dá `Unknown or unsupported provider` padà fún ìlà yẹn; modal náà sì máa ń ṣàfihàn rẹ̀ lẹ́gbẹ̀ẹ́ orúkọ ìlà náà.

## JSON

Array JSON àwọn object tó ní àwọn field kan náà (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Láìdàbí CSV, àwọn key JSON ní orúkọ.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
