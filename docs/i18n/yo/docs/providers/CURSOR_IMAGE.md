OmniRoute ń ṣí **ìṣẹ̀dá àwòrán** ètò Cursor síta lórí `POST /v1/images/generations` nípasẹ̀ id olùpèsè kan náà bí ìfọ̀rọ̀wérọ̀: `cursor` (orúkọ ìnagijẹ `cu`).

| Ààyè                 | Iye                                                                                     |
| -------------------- | --------------------------------------------------------------------------------------- |
| id `IMAGE_PROVIDERS` | `cursor`                                                                                |
| Fọ́ọ̀mù                | `cursor-agent-image`                                                                    |
| Ìfàṣẹsí              | Ìsopọ̀ OAuth / API-key kan náà bí ìfọ̀rọ̀wérọ̀ (`provider_connections.provider = "cursor"`) |
| Àwọn àwòṣe           | `cursor/auto`, `cursor/composer-2`, `cursor/composer-2.5`                               |

## Ìdí tí Agent CLI fi wà

Ìfọ̀rọ̀wérọ̀ Cursor nínú OmniRoute ń lo `agent.v1.AgentService/Run` (protobuf). Ọ̀nà yẹn **kọ̀** àwọn irinṣẹ́ oníbàárà tí a kọ sínú rẹ̀ (shell, write, …). Ìṣẹ̀dá àwòrán jẹ́ irinṣẹ́ abinibi Cursor tí **`agent` CLI** ń ṣiṣẹ́ lórí seat náà. Nítorí náà, olùṣàmúlò àwòrán máa ń dá `agent` sílẹ̀ pẹ̀lú prompt tí a ti tì pa àti workspace ìgbà díẹ̀ fún ìbéèrè kọ̀ọ̀kan (ní ìrísí kan náà bí àwọn afárá seat àwùjọ), lẹ́yìn náà ó máa ń dá `b64_json` tó bá OpenAI mu padà.

## Ìdíwọ̀n ìráyè (Àwọn Òfin Líle #15 + #17)

Èyí nìkan ni fọ́ọ̀mù `IMAGE_PROVIDERS` tó ń dá child process kan sílẹ̀ (binary `agent`
náà). Nítorí pé nǹkan bí 40 àwọn olùpèsè àwòrán mìíràn tí kì í dá process sílẹ̀, tí àwọn
olùpè latọna jijin sì ń lò lọ́nà tó tọ́, ń pín `POST /v1/images/generations`, gbogbo route náà
ni a **kò** pín sí `LOCAL_ONLY` — dípò bẹ́ẹ̀, `handleCursorAgentImageGeneration` ń fi gate
tirẹ̀ múlẹ̀ nípa lílo ìdájọ́ `AUTHZ_HEADER_PEER_LOCALITY` tí a fọkàn tán, èyí tí pipeline authz
ń tẹ̀ sórí gbogbo ìbéèrè (láti ọ̀dọ̀ TCP peer gidi, kì í ṣe header `Host` tí a lè ṣe èké sí):
àwọn olùpè `loopback` àti `lan` nìkan ló lè dé ibi spawn náà; gbogbo àwọn yòókù (pẹ̀lú API
key tó ti tú jáde tí a tún lò lórí tunnel gbogbogbò) yóò gba `403` kí ìṣàwárí credential tàbí
process spawn kankan tó ṣẹlẹ̀. Wo `src/server/authz/policies/management.ts` fún policy kan
náà tí a lò fún ìyókù tier `LOCAL_ONLY`.

## Gate concurrency wà ní ìpele module (ìdíwọ̀n instance kan ṣoṣo)

Counter/queue inú memory tí a fi mọ́ instance module
Node (`open-sse/handlers/imageGeneration/providers/cursorAgentImage.ts`) ló ń fipá mú
`CURSOR_IMG_MAX_CONCURRENT`. Ó ń fi tọ́ ṣe ààlà àwọn spawn `agent` tó lè ṣiṣẹ́ lẹ́ẹ̀kan
náà nínú process OmniRoute kan, ṣùgbọ́n **kò** ṣètò àjọṣe láàárín ọ̀pọ̀ process/instance
tó ń pín seat Cursor kan náà (fún àpẹẹrẹ, deployment tó ní ọ̀pọ̀ replica) — instance
kọ̀ọ̀kan ń fi ààlà tirẹ̀ tí kò gbára lé ti ẹlòmíràn múlẹ̀. Fún deployment instance kan ṣoṣo
(èyí tó jẹ́ àtẹ̀jáde àìyípadà), èyí péye; àwọn deployment tí a ti ṣe horizontal scaling
gbọ́dọ̀ jẹ́ kí `CURSOR_IMG_MAX_CONCURRENT` kéré pẹ̀lú ìṣọ́ra fún instance kọ̀ọ̀kan tàbí kí
wọ́n darí traffic àwòrán Cursor sí instance kan ṣoṣo.

## Àwọn ohun tí a nílò

1. Account Cursor tí a ti sopọ̀ nínú dashboard (OAuth tàbí API key `crsr_…`).
2. Binary Cursor Agent gbọ́dọ̀ wà níbi tí process OmniRoute ti lè dé:
   - env `CURSOR_AGENT_BIN=/path/to/agent`, tàbí
   - `~/.local/bin/agent`, tàbí
   - `providerSpecificData.agentBin` lórí ìsopọ̀ Cursor.

Àtúnṣe àṣàyàn:

| Env                         | Àìyípadà                | Ìtumọ̀                          |
| --------------------------- | ----------------------- | ------------------------------ |
| `CURSOR_IMG_TIMEOUT_MS`     | `210000`                | Àkókò gidi fún àwòrán kọ̀ọ̀kan   |
| `CURSOR_IMG_MAX_CONCURRENT` | `2`                     | Gate concurrency seat tí a pín |
| `CURSOR_IMG_MODEL`          | (àwòṣe ìbéèrè / `auto`) | Rọ́pò `--model` CLI             |

## Àpẹẹrẹ

```bash
curl -sS https://<host>/v1/images/generations \
  -H "Authorization: Bearer <omni-api-key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"cursor/auto","prompt":"a lantern in fog","size":"1024x1024"}'
```

Ìṣẹ̀dá sábà máa ń gba ìṣẹ́jú 1–2. Yan ọ̀nà network inú ilé; àwọn proxy etí nẹ́tíwọ̀ọ̀kì tó ní timeout nǹkan bí 100s yóò kùnà.

## LiteLLM

Forúkọsílẹ̀ àwòṣe àwòrán kan pẹ̀lú `mode: image_generation`, `api_base: http://omniroute:20128/v1`, àti `model: openai/cursor/auto` (tàbí `cursor/auto` lásán, gẹ́gẹ́ bí ẹ̀yà LiteLLM rẹ).
