`chatgpt-web-codex` (orúkọ àfirọ́pò `cgpt-codex`) ń so àwọn ìyípadà Codex Responses pọ̀ nípasẹ̀
ìgbà aṣàwákiri ChatGPT tí a ti fìdí ìdánimọ̀ rẹ̀ múlẹ̀. Ó dá dúró lọ́tọ̀ sí olùpèsè gbogbogbò
`chatgpt-web` tí a ti yọ lẹ́nu iṣẹ́, ó sì ń lo ìmúṣẹ tó ní àkíyèsí MIT lábẹ́
`open-sse/vendor/codex-chatgpt-web/`, tí a sọ di tuntun sí commit v4.0.7 láti upstream
`b59d7dc51b84fb1f465ff1d00f5207f3b2b4a494`.

## Yíyọ olùpèsè gbogbogbò lẹ́nu iṣẹ́

Àwọn ID olùpèsè gbogbogbò tẹ́lẹ̀ rí `chatgpt-web` àti `cgpt-web` kò sí nínú ìkójọpọ̀ mọ́ nítorí pé
a kò lè fìdí orísun ìmúṣẹ pre-key/proof-of-work wọn múlẹ̀. Àwọn ìbéèrè pàtó sí èyíkéyìí nínú àwọn ID náà, pẹ̀lú àwọn ID awoṣe tí slash wà níwájú àti àwọn orúkọ àfirọ́pò tí a ti tọ́jú, yóò
kùnà láìfi àyè sílẹ̀ pẹ̀lú HTTP `410` àti kóòdù **PROVIDER_RETIRED** kí ìbéèrè upstream kankan tó wáyé.

Ìṣíkiri `168_retire_chatgpt_web.sql` máa ń samisi àwọn ìsopọ̀ olùpèsè tó bá mu gẹ́gẹ́ bí èyí tí a ti yọ kúrò,
ó sì ń sọ àwọn lease ìgbà aṣàmúlò wọn tó ṣì ń ṣiṣẹ́ di asán. Ó ń pa ìtàn ìsopọ̀ àti àwọn allowlist API-key mọ́;
kò fi ààyè ìráàyèsí àfirọ́pò kún allowlist. Yíyọ yìí kò kan olùpèsè Codex àti
àwọn ìsopọ̀ rẹ̀.

## Àwọn ohun àkọ́kọ́ tí a nílò

- akọsori Cookie kíkún láti inú ìgbà ChatGPT tí a ti wọlé sí;
- Chrome tàbí Chromium pẹ̀lú ìgbà àwòrán tàbí display Xvfb fún àwọn ìfisórí npm, systemd, àti PM2;
- pẹ̀lú profile Docker `web`, iṣẹ́ Chromium inú láti
  `docker-compose.yml`;
- OpenAI `tunnel-client` v0.0.13 àti asopọ̀ àkànṣe ChatGPT kan fún àwọn irinṣẹ́ Codex agbègbè.

Tunnel náà wúlò fún àwọn ìyípadà irinṣẹ́ nìkan. Gbogbo route tí a tò sílẹ̀, pẹ̀lú `pro`, lè lo
agbára irinṣẹ́ agbègbè kan náà tí a dè mọ́ ìyípadà nígbà tí a bá ti ṣètò tunnel àti asopọ̀ náà.

## Ìṣètò dashboard

1. Ṣí olùpèsè **ChatGPT Web (Codex)** kí o sì ṣàfikún asopọ̀ kan.
2. Lẹ akọsórí ChatGPT Cookie kíkún, ID tunnel, kọ́kọ́rọ́ runtime, àti orúkọ connector
   àkànṣe náà mọ́lẹ̀. Àwọn ìṣètò tuntun tí ó lè lo irinṣẹ́ gbọ́dọ̀ lo connector tuntun tí a ṣẹ̀dá
   tí orúkọ rẹ̀ jẹ́ `OmniRoute Codex v2` gan-an, pẹ̀lú Authentication tí a ṣètò sí None àti
   Permissions tí a ṣètò sí Allow all actions.
3. Ṣe àyẹ̀wò asopọ̀ náà. OmniRoute máa ṣí Temporary Chat tí aṣàwákiri ń ṣe àtìlẹ́yìn fún,
   yóò sì ṣàwárí bóyá Sol àti Pro wà fún àkọọ́lẹ̀ náà.
4. Fi asopọ̀ náà pamọ́. OmniRoute máa rọ́pò cookie tí a lẹ mọ́lẹ̀ pẹ̀lú ipò ibi ìpamọ́
   Playwright tí a ti ṣàyẹ̀wò, yóò sì fi í pamọ́ pẹ̀lú kọ́kọ́rọ́ runtime nípasẹ̀
   àkópọ̀ ìtọ́jú ẹ̀rí ìdánimọ̀ tí a paroko.

A kì í pa cookie àìṣẹ̀dá náà mọ́ lẹ́yìn fífi í pamọ́ láṣeyọrí. Nígbà tí session náà bá parí,
ṣí asopọ̀ náà, lẹ akọsórí Cookie tuntun kíkún mọ́lẹ̀, kí o sì tún àyẹ̀wò náà ṣe. Ipò doctor
nínú àpótí ìjíròrò àtúnṣe máa ń jọ̀wọ́ ìròyìn lọ́tọ̀ọ̀tọ̀ nípa aṣàwákiri, ipò ibi ìpamọ́,
wíwọlé, Temporary Chat, tunnel, connector, àti ìrìn-àjò irinṣẹ́ lọ àti padà. Láti mú
ìmúdójúìwọ̀n cookie ṣiṣẹ́ láìfọwọ́ṣe nígbà tí àwọn session bá yí padà, wo irinṣẹ́ alábàákẹ́gbẹ́
nínú [Àfikún Ìṣiṣẹ́pọ̀ Session Aṣàwákiri](../guides/SESSION-SYNC-EXTENSION.md).

> Má ṣe commit cookie gidi, kọ́kọ́rọ́ runtime, ipò ibi ìpamọ́, tàbí token àṣẹ láéláé. Àwọn iye
> fún ìdánwò àti àkọsílẹ̀ gbọ́dọ̀ jẹ́ àwọn placeholder ní gbogbo ìgbà.

## Àwọn awoṣe àti combo

Àwọn route awoṣe tí a ti dì mú ni:

- `chatgpt-web-codex/luna` — GPT-5.6 Luna, ìsapá kékeré
- `chatgpt-web-codex/think` — GPT-5.6 Luna, ìsapá àárín
- `chatgpt-web-codex/instant`
- `chatgpt-web-codex/medium`
- `chatgpt-web-codex/high`
- `chatgpt-web-codex/extra-high`
- `chatgpt-web-codex/pro`

Ṣàfikún ọ̀kan lára wọn sí combo bí awoṣe mìíràn èyíkéyìí. App Codex máa ń fi orúkọ combo náà ránṣẹ́ gẹ́gẹ́ bí
`model` sí endpoint Responses déédéé, `/v1/responses`; kò sí endpoint Codex
tàbí yíyí mode lọ́tọ̀.

Àwọn àkọọ́lẹ̀ Free/Go ń fi àwọn route Luna hàn. Àwọn àkọọ́lẹ̀ tó lè lo Sol ń fi Instant títí dé
High hàn, àwọn àkọọ́lẹ̀ tó lè lo Pro sì tún ń fi Extra High àti Pro hàn. Route kọ̀ọ̀kan ní
awoṣe backend àti ìsapá ìrònú tí a ti dì mú; ìsapá Responses tí a sọ ní gbangba tó tako èyí yóò
kùnà láìfi àyè sílẹ̀ dípò kí ó yí mode aṣàwákiri tí a yàn padà láìjẹ́kí ẹnikẹ́ni mọ̀.

Má ṣe tún orúkọ asopọ̀ `Codex Native` tàbí `OmniRoute Codex` àtijọ́ ṣe, má sì tún lò ó. ChatGPT
ń cache àdéhùn MCP gbogbogbò nípasẹ̀ ìdánimọ̀ asopọ̀, nígbà tí bridge tí a sọ di tuntun ń lo
àdéhùn turn-token tààrà tuntun. Runtime kọ àwọn ìdánimọ̀ àtijọ́ wọ̀nyẹn, ó sì ń béèrè
asopọ̀ `OmniRoute Codex v2` tuntun.

## Àwòṣe ààbò

- Ọ̀nà abinibi nílò ìbéèrè Responses, ẹ̀rọ oníbàárà Codex tí a mọ̀, àti àwọn ìdánimọ̀ thread àti turn tí ó bá ara wọn mu.
- Workspace, sandbox, ìlànà ìfọwọ́sí, àti àkójọ irinṣẹ́ wá láti inú shell Codex abinibi; ọ̀rọ̀ prompt tí a kọ lọ́nà òmìnira kò ní àṣẹ lórí wọn.
- ChatGPT ń gba capability tí àkókò rẹ̀ kúkúrú nìkan fún turn kọ̀ọ̀kan. Alárinà MCP ń gba àwọn irinṣẹ́ tí Codex pèsè nínú turn pàtó yẹn nìkan.
- Ìmúdájú **Allow once** láìfọwọ́ṣe ń dá ìbéèrè irinṣẹ́ náà padà sí Codex nìkan. Codex nìkan ló ń pinnu lórí ìfọwọ́sí àti ìmúṣẹ.
- Ṣáájú àbájáde àkọ́kọ́, combo kan lè padà sí target míì tí ó bá a mu. Lẹ́yìn tí àbájáde bá ti bẹ̀rẹ̀, provider, model, connection, àti browser turn yóò dúró gẹ́gẹ́ bí a ti so wọ́n títí turn náà yóò fi parí.
- Cookies, runtime keys, storage state, àti capability tokens kì í hàn nínú àwọn ìdáhùn provider tàbí àwọn àkọsílẹ̀ ìbéèrè.

## VPS aláìní àpapọ̀ ìfihàn àti Docker

Fún àwọn ìfisórí ẹrọ npm, systemd, àti PM2, OmniRoute máa ń ṣàwárí àwọn ọ̀nà Chrome àti Chromium tí ó wọ́pọ̀.
Gẹ́gẹ́ bí ọ̀nà mìíràn, ṣètò `CHATGPT_WEB_CODEX_CHROME_PATH`. Àwọn runtime turn mọ̀ọ́mọ̀ ń lo Chrome
tí ó ní àpapọ̀ ìfihàn nítorí pé ChatGPT kọ̀ irú browser headless gidi. Nítorí náà, host aláìní àpapọ̀ ìfihàn gbọ́dọ̀
ṣiṣẹ́ OmniRoute pẹ̀lú àpapọ̀ Xvfb àdáni; ṣíṣètò ọ̀nà Chrome nìkan kò pèsè ọ̀kan.

Profile `web` Docker ń bẹ̀rẹ̀ `chatgpt-web-codex-browser` lórí network Compose inú.
Sidecar náà ń ṣiṣẹ́ Chrome tí ó ní àpapọ̀ ìfihàn nínú Xvfb, nítorí náà kò nílò àpapọ̀ ìfihàn ti ara. A kò tẹ port CDP
rẹ̀ jáde lórí host. Volume profile browser tí a dáàbò bò yàtọ̀ sí volume data
OmniRoute, browser náà sì ń gba shared memory tó. Proxy CDP inú
ń tẹ́tí sí port `9223` nìkan nínú network Compose; Chrome ṣì so mọ́ loopback nínú
sidecar.

Lease alábòójútó kan lábẹ́ `DATA_DIR` ń dí ọ̀pọ̀ process OmniRoute lọ́wọ́ láti ní
tunnel àti state broker kan náà. Doctor máa ń jẹ́dòó ìforígbárí.

## Ìmúpadàbọ̀ṣípò aláṣepọ̀

Ọ̀nà Docker aládàáṣiṣẹ́ kò ní window tí host lè rí, ṣùgbọ́n Chrome fúnra rẹ̀ ní àpapọ̀ ìfihàn nínú
àpapọ̀ Xvfb àdáni. Nígbà tí ChatGPT bá nílò ìwọlé aláṣepọ̀ tàbí ìpèníjà, a lè lo amáyédẹrùn browser VNC
tí ó ti wà fún ìmúpadàbọ̀ṣípò. Browser UI àti CDP gbọ́dọ̀ máa ṣeé dé lórí loopback,
àsopọ̀ ìṣàkóso tí a ti fìdí rẹ̀ múlẹ̀, tàbí tunnel SSH nìkan; noVNC yóò wà ní pípa
nígbà iṣẹ́ déédéé.

## Ọ̀nà àfẹ́yìntì WebSocket

Nígbà tí combo kan bá ní ChatGPT Web (Codex), afárá Responses WebSocket máa ń béèrè
ọ̀nà àfẹ́yìntì HTTP/SSE ṣáájú kíkàn sí upstream. Ìgbérafẹ́ náà yóò sì gba
`/v1/responses` kọjá.
