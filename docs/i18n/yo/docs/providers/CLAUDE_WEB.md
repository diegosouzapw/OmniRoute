## `claude-web`

`claude-web` ń fi àwọn ìbéèrè ìjíròrò tó tẹ̀lé ọ̀nà-kíkọ́ OpenAI ránṣẹ́ nípasẹ̀ ìjókòó aṣàwákiri `claude.ai` tí a ti fìdí rẹ̀ múlẹ̀. Olùṣiṣẹ́ náà ń mú kúkì tí a pèsè wá sí ìrísí boṣewa, ń yan àjọ kan tí a ti fìdí ìdánimọ̀ rẹ̀ múlẹ̀, ń pèsè ipò ìjíròrò sílẹ̀, ń yan ọ̀nà ìgbékalẹ̀ tààrà tàbí ti aṣàwákiri, ó sì ń túmọ̀ ìdáhùn SSE láti orísun òkè pẹ̀lú ìmúlò àwọn òfin tó muna. Ìṣètò gbogbo ìlànà náà wà ní
`open-sse/executors/claude-web.ts:320`.

> **Ṣé o ṣẹ̀ṣẹ̀ bẹ̀rẹ̀ sí í lo àwọn olùpèsè Web Cookie?**
>
> Ka **`docs/getting-started/WEB-COOKIE-GUIDE.md`** fún ìlànà ìṣètò gbogbogbò, ìtọ́sọ́nà ìfàṣẹsí, àwọn ààlà, àti yíyanjú ìṣòro kí o tó tẹ̀lé ìtọ́sọ́nà tó jẹ́ pàtó fún olùpèsè yìí.

### Àkójọ àwọn model

Ìforúkọsílẹ̀ olùpèsè ń ṣàfihàn àwọn ID model aláìyípadà méje wọ̀nyí gan-an lọ́wọ́lọ́wọ́
(`open-sse/config/providers/registry/claude/web/index.ts:11`):

| ID model                    | Orúkọ àfihàn            |
| --------------------------- | ----------------------- |
| `claude-fable-5`            | Claude Fable 5 (web)    |
| `claude-opus-4-8`           | Claude Opus 4.8 (web)   |
| `claude-sonnet-5`           | Claude Sonnet 5 (web)   |
| `claude-haiku-4-5-20251001` | Claude Haiku 4.5 (web)  |
| `claude-opus-4-7`           | Claude Opus 4.7 (web)   |
| `claude-opus-4-6`           | Claude Opus 4.6 (web)   |
| `claude-sonnet-4-6`         | Claude Sonnet 4.6 (web) |

A kò ṣe ìmúṣẹ ìṣàwárí model aláyípadà fún olùpèsè yìí. Àtòkọ òkè ni àkójọ tí àsìkò ìṣiṣẹ́ ń lò.

### Àwọn ẹ̀rí ìwọlé àti ìyanju àjọ

Pèsè bóyá àkọlé Cookie `claude.ai` ní kíkún tàbí iye ìjókòó lásán. Àwọn iye lásán ni a ń mú wá sí ìrísí `sessionKey`; àwọn kúkì mìíràn ni a ń fi sílẹ̀ bí a bá pèsè wọn. Olùṣiṣẹ́ náà gba kúkì nípasẹ̀ `cookie` tàbí `apiKey`, ó sì
ń ka àwọn iye `deviceId` àti `orgId` àṣàyàn láti inú dátà ìsopọ̀
(`open-sse/executors/claude-web.ts:72`).

Tí `orgId` kò bá sí, olùṣiṣẹ́ náà máa pe `GET https://claude.ai/api/organizations`, yóò sì lo àjọ àkọ́kọ́ tí ìjókòó Claude Web tí a ti fìdí rẹ̀ múlẹ̀ dá padà
(`open-sse/executors/claude-web.ts:141`). Yóò dá iṣẹ́ dúró pátápátá tí kò bá rí àjọ tó fẹsẹ̀ múlẹ̀, yóò jabo ìkọ̀ ìfàṣẹsí ìjókòó gẹ́gẹ́ bí 401, yóò sì ṣe ìyàtọ̀ láàárín ìpèníjà Cloudflare àti ìkùnà ìfàṣẹsí.

### Àwọn iṣẹ́ ìjíròrò

Object `claude_web` àṣàyàn tó wà ní ìpele òkè tẹ̀lé òfin tó muna. A kọ àwọn field tí a kò mọ̀. Àwọn field tí ó gbà ni a ṣàlàyé ní `open-sse/executors/claude-web/session.ts:50`:

| Field                 | Ìtumọ̀                                                           |
| --------------------- | --------------------------------------------------------------- |
| `operation`           | `completion` ní àìrídìmú; lo `retry` láti tún turn kan gbìyànjú |
| `conversation_id`     | UUID tó ṣe kedere fún ìjíròrò tó ti wà                          |
| `parent_message_uuid` | UUID tó ṣe kedere fún ìfiránṣẹ́ olùrànlọ́wọ́ tó jẹ́ parent          |
| `timezone`            | Orúkọ agbègbè àkókò IANA tó fẹsẹ̀ múlẹ̀                           |
| `locale`              | Locale tó bá ìgbékalẹ̀ mu                                        |
| `tool_states`         | Array ipò irinṣẹ́ àkọọ́lẹ̀ àṣàyàn, tó ní ààlà 128 entries          |

Àwọn ìbéèrè tí a pèsè sílẹ̀ ń lo ọ̀kan nínú endpoint orísun òkè méjì
(`open-sse/executors/claude-web.ts:203`):

- Turn tuntun tàbí títẹ̀síwájú máa ń fi ránṣẹ́ sí
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/completion`.
- Ìtúnṣègbìyànjú máa ń fi ránṣẹ́ sí
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion`.

Turn tuntun máa ń ní `create_conversation_params`. Títẹ̀síwájú tí a ti cache tàbí tí a so pọ̀ ní kedere máa ń ní `parent_message_uuid`, kò sì ní `create_conversation_params`. Ìtúnṣègbìyànjú nílò ipò ìjíròrò àti ti parent-message méjèèjì, kò sì fi prompt kankan ránṣẹ́
(`open-sse/executors/claude-web/session.ts:254`). Àwọn ìjíròrò tuntun máa ń ṣí UI tí a ti fìdí rẹ̀ múlẹ̀ ní `/new`; àwọn títẹ̀síwájú tí a ti cache tàbí tí a so pọ̀ ní kedere máa ń ṣí ojú ìwé ìjíròrò náà gan-an
(`open-sse/executors/claude-web/session.ts:324`).

Ipò ìjíròrò jẹ́ cache inú-memory tí a fi scope àkọọ́lẹ̀ SHA-256 àti transcript olùpè ní ìrísí canonical ṣe key. Àwọn entry máa ń parí lẹ́yìn ìṣẹ́jú 30, cache náà sì ní ààlà entries 5,000
(`open-sse/executors/claude-web/session.ts:12`). A máa ń commit ipò náà lẹ́yìn tí parser stream tó muna bá rí `message_stop` nìkan; ìtúnibẹ̀rẹ̀ process máa ń pa á tì. Tí cache miss bá ṣẹlẹ̀, a máa serialize ìbéèrè olópọ̀-ìfiránṣẹ́ sí prompt ìmúpadàbọ̀sípò kan dípò kí a pa àwọn ìfiránṣẹ́ ìṣáájú rẹ́ ní ìdákẹ́jẹ́.

Locale àti agbègbè àkókò ń lo ìṣáájú yìí: iye `claude_web` ìbéèrè, iye ìsopọ̀, iye àsìkò ìṣiṣẹ́, lẹ́yìn náà `en-US` fún locale tàbí `UTC` fún agbègbè àkókò
(`open-sse/executors/claude-web/session.ts:218`).

### Àwọn irinṣẹ́ àti payload ìbéèrè

Àwọn ìbéèrè tààrà ń yí àwọn irinṣẹ́ function OpenAI tí olùpè pèsè, tí wọ́n sì bá ìgbékalẹ̀ mu, nìkan padà. Kò sí àtòkọ irinṣẹ́ aláìyípadà àìrídìmú tí a dá lásán
(`open-sse/executors/claude-web/payload.ts:102`).

Àwọn ìbéèrè aṣàwákiri, ní ìdakejì, máa ń capture ìbéèrè UI tí a ti fìdí rẹ̀ múlẹ̀, wọ́n sì ń pa àwọn irinṣẹ́ àkọọ́lẹ̀ rẹ̀, àwọn ipò irinṣẹ́, àti àwọn style àdáni mọ́. Ìjíròrò, model, reasoning, prompt, àti àwọn field UUID ìfiránṣẹ́ tí a pèsè sílẹ̀ ṣì máa ń kọjá lórí ìbéèrè tí a capture
(`open-sse/executors/claude-web/browserTransport.ts:175`). A ń fi hash ti àkọọ́lẹ̀, àjọ, kúkì, locale, àti agbègbè àkókò pinnu scope àwọn template aṣàwákiri, wọ́n sì máa ń parí lẹ́yìn ìṣẹ́jú 30
(`open-sse/executors/claude-web/browserTransport.ts:11`,
`open-sse/executors/claude-web/browserTransport.ts:158`). Nígbà tí ìbéèrè tààrà kò bá ní irinṣẹ́ olùpè, ó lè tún template tó ní scope yẹn lò; àwọn irinṣẹ́ olùpè tí a sọ ní kedere ni wọ́n ní ìṣáájú
(`open-sse/executors/claude-web/browserTransport.ts:214`).

### Ìyan ọ̀nà ìgbékalẹ̀

Ọ̀nà àìrídìmú ni `sendClaudeWebDirect()`, èyí tó ń pe `tlsFetchClaude()` pẹ̀lú profile Chrome 146 tí a ti ṣètò àti kúkì tí a pèsè (`open-sse/services/claudeTlsClient.ts:23`). Kò ṣe ìfilọ́lẹ̀ solver tàbí dá kúkì àfidípò kan sílẹ̀.

Ṣètò `WEB_COOKIE_USE_BROWSER` sí `1`, `true`, tàbí `on` láti jẹ́ kí adapter aṣàwákiri tó ní ààlà sí àkọọ́lẹ̀ jẹ́ ọ̀nà ìgbéwọlé àkọ́kọ́. Ṣètò `OMNIROUTE_BROWSER_POOL` sí ọ̀kan lára àwọn iye kan náà láti
jẹ́ kí ìpèníjà Cloudflare 403 tí a mọ̀ lè yí padà láti ọ̀nà ìgbéwọlé tààrà sí
adapter aṣàwákiri (`open-sse/executors/claude-web.ts:195`). Àwọn ìkùnà HTTP mìíràn kì í fa
ìyípadà padà yẹn.

Adapter aṣàwákiri ń pa àwọn cookie mọ́ sínú context Playwright tí a kó jọ kan náà, ó ń lo key
hashed tó ní ààlà tí a ṣàlàyé lókè, ó sì ń fi ìparí iṣẹ́ ránṣẹ́ láti inú context yẹn
(`open-sse/executors/claude-web/browserTransport.ts:444`). Kò máa ń gbe cookie tí aṣàwákiri
ti yanjú jáde sí client TLS tààrà láé. Àwọn ìgbìyànjú aṣàwákiri lẹ́ẹ̀kansi nílò template UI
tí kò tíì parí tí a so mọ́ context Playwright gangan kan náà
(`open-sse/executors/claude-web/browserTransport.ts:467`). Kíka ìdáhùn aṣàwákiri ń ṣiṣẹ́ ní
ìpele-ní-ìpele nínú ojú-ìwé tí a ti jẹ́rìí sí, ó ń bọ̀wọ̀ fún ìfagilé request, ó sì ń fagilé
body upstream ní kété tí ó bá kọjá 16 MiB
(`open-sse/executors/claude-web/browserTransport.ts:259`).

Executor náà ń dá àfihàn audit tí a ti fi àwọn apá ìkọ̀kọ̀ pamọ́ padà sí logger request tí a
ń pín: organization, UUID conversation àti message, ọ̀rọ̀ prompt, àwọn ìtumọ̀ tool, cookies,
àti àwọn device identifiers ni a yọ kúrò (`open-sse/executors/claude-web.ts:237`,
`open-sse/executors/claude-web.ts:252`). Àwọn exception transport tún ń dá àṣìṣe ìsopọ̀
gbogbogbò padà dípò message tí a ju jáde.

### Ìhùwàsí SSE

`createClaudeWebResponse()` ń bójú tó framing LF tàbí CRLF àti àwọn field `data:` ọlọ̀pọ̀
ìlà. Ó ń yí àwọn text delta sí `content`, àwọn thinking delta sí `reasoning_content`, àti
àwọn event metadata tí a mọ̀ sí extension ìdáhùn `claude_web`. Event metadata kọ̀ọ̀kan ni a
ń ṣe àfihàn rẹ̀ nípasẹ̀ allowlist field tirẹ̀
(`open-sse/executors/claude-web/stream.ts:37`). Metadata conversation, parent-message,
assistant-message, àti operation tún wà nínú àwọn header `X-OmniRoute-Claude-Web-*`
(`open-sse/executors/claude-web/stream.ts:364`).

Parser náà ń dá iṣẹ́ dúró láìláyè tẹ̀síwájú lórí JSON tí kò péye, àwọn event `error` upstream,
àwọn irú event tí a kò mọ̀, ìṣètò tí kò tọ́, àìbáramu content-block, tàbí EOF ṣáájú
`message_stop`. Output streaming ń mú chunk ìparí kan àti `[DONE]` kan jáde; output buffered
ń lo parser kan náà. Parser náà ka `message_stop` sí òpin lẹ́sẹ̀kẹsẹ̀, ó ń fagilé data upstream
tó ń bọ̀ lẹ́yìn, ó sì ń tan ìfagilé downstream lọ sí reader upstream
(`open-sse/executors/claude-web/stream.ts:461`,
`open-sse/executors/claude-web/stream.ts:563`). Àwọn ìlà SSE tí a kò parí àti àwọn event tí
a kójọ ni a fi ààlà 1 MiB sí (`open-sse/executors/claude-web/stream.ts:17`,
`open-sse/executors/claude-web/stream.ts:62`).

### Ìdánwò

Ṣi suite Claude Web tó ṣe àbájáde kan náà ní gbogbo ìgbà láìlo àwọn credential gidi:

```powershell
node --import tsx/esm --test tests/unit/claude-web-auto-refresh.test.ts tests/unit/claude-web-browser-transport.test.ts tests/unit/claude-web-executor-split.test.ts tests/unit/claude-web-live-alignment.test.ts tests/unit/claude-web-payload-runtime.test.ts tests/unit/claude-web-session.test.ts tests/unit/claude-web-sonnet5-registry-6209.test.ts tests/unit/claude-web-stream.test.ts tests/unit/claude-web-transport.test.ts tests/unit/claude-web.test.ts tests/unit/issue-6662-repro.test.ts
```

Àwọn case tó gbára lé Playwright nínú `tests/unit/claude-web-auto-refresh.test.ts` ni a fo
kọjá ní tààrà. Repository yìí kò tíì ní script live-test Claude Web tó ń lo credential
lọ́wọ́lọ́wọ́, nítorí náà àwọn case tí a fo kọjá yẹn kì í ṣe ẹ̀rí runtime.

### Ìṣètò

1. Bẹ̀rẹ̀ OmniRoute pẹ̀lú `npm run dev` tàbí installation tí a ti build.
2. Ṣí Dashboard → Providers → Add Provider.
3. Yan ẹ̀ka Web Cookie àti Claude Web.
4. Lẹ Cookie header kíkún tí a daakọ láti request `claude.ai` tí a ti jẹ́rìí sí.
