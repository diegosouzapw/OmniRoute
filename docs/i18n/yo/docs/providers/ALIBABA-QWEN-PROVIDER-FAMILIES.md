Ìwé yìí ṣàkọsílẹ̀ ìpinnu ìmúṣẹ fún
[Issue #7854](https://github.com/diegosouzapw/OmniRoute/issues/7854). Àwọn ọjà gbogbogbòò ni a
ṣojú gẹ́gẹ́ bí ìdílé olùpèsè mẹ́rin. Ẹkùn jẹ́ dátà ìsopọ̀, kì í ṣe ọjà ọ̀tọ̀.

## Ìpinnu

| Ìdílé olùpèsè                                   | ID OmniRoute            | Ẹkùn àgbáyé | Ẹkùn Ṣáínà |
| ----------------------------------------------- | ----------------------- | ----------- | ---------- |
| Alibaba Cloud Model Studio (san bí o ṣe ń lò ó) | `alibaba`               | Singapore   | Beijing    |
| Alibaba Cloud Token Plan                        | `bailian-coding-plan`   | Singapore   | Beijing    |
| Qwen Cloud (san bí o ṣe ń lò ó)                 | `qwen-cloud`            | Àgbáyé      | Beijing    |
| Qwen Cloud Token Plan                           | `qwen-cloud-token-plan` | Singapore   | Beijing    |

ID `alibaba-cn` tó ti wà tẹ́lẹ̀ ṣì jẹ́ orúkọ ìnagijẹ ìbámu ní àsìkò ìṣiṣẹ́ fún àwọn ìsopọ̀ tí a ti fipamọ́, àwọn
ipa-ọ̀nà àwòṣe, àwọn àkójọpọ̀, àti ìlò àtijọ́. A ti da káàdì pánẹ́ẹ̀lì rẹ̀ pọ̀ mọ́ `alibaba`; kò sí àtúnkọ
ibi ìpamọ́ dátà tí a nílò.

Qwen Cloud tí a ń san owó rẹ̀ bí a ṣe ń lò ó àti Alibaba Cloud Model Studio ń lo àwọn olùgbàlejò ìṣiṣẹ́ tó bá DashScope mu
lọ́wọ́lọ́wọ́, ṣùgbọ́n wọ́n ṣì jẹ́ ìdánimọ̀ olùpèsè ọ̀tọ̀ọ̀tọ̀ nítorí àwọn aṣàmúlò ń gba àwọn kọ́kọ́rọ́, wọ́n sì ń ṣàkóso
àwọn àkọọ́lẹ̀ nípasẹ̀ àwọn ojú ọjà tó yàtọ̀. Àwọn ọjà Alibaba àti Qwen Cloud Token Plan ń lo
àwọn ìdílé endpoint tó yàtọ̀, nítorí náà gbogbo ọjà mẹ́rin náà ṣì jẹ́ ID olùpèsè ọ̀tọ̀ọ̀tọ̀.

## Àtẹ ìbámu endpoint

| Ìdílé olùpèsè           | `global-sg`                                                              | `china-beijing`                                                      | Ọ̀nà ìṣètò dátà |
| ----------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------- | -------------- |
| `alibaba`               | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI         |
| `bailian-coding-plan`   | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/apps/anthropic/v1`  | `https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic/v1`  | Anthropic      |
| `qwen-cloud`            | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI         |
| `qwen-cloud-token-plan` | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` | `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | OpenAI         |

Kọ́kọ́rọ́ API àti endpoint gbọ́dọ̀ jẹ́ ti ọjà àti ẹkùn kan náà. Yíyan ẹkùn kan ń yí
endpoint àtètò tí ìfọwọ́sí àti àwọn ìbéèrè déédéé ń lò padà.

## Àdéhùn ìsopọ̀

Àwọn ìsopọ̀ tuntun ń tọ́jú kọ́kọ́rọ́ ẹkùn tí kò yípadà sínú `providerSpecificData`:

```json
{
  "region": "global-sg"
}
```

Àwọn iye tí a gbà láàyè ni `global-sg` àti `china-beijing`. A ń yọ endpoint jáde láti ibi àárín nípasẹ̀
ID olùpèsè àti ẹkùn. `providerSpecificData.baseUrl` tí kì í ṣe àtètò ṣì jẹ́ ìforíborí olùṣàkóso
tó ṣe kedere, ó sì ní ipò àkọ́kọ́, nígbà tí a ń ṣe àtúnṣe àwọn URL àtètò àtijọ́ tí a ti fipamọ́ padà sí àtẹ
ẹkùn.

Èyí ń jẹ́ kí àwòrán ìṣètò ìsopọ̀ ṣeé fẹ̀ sí i: a lè fi ẹkùn mìíràn kún olùyànjú láì
ṣẹ̀dá káàdì olùpèsè mìíràn tàbí yí àwọn ID olùpèsè tí a ti fipamọ́ padà.

## Ìbámu àti ìmújáde

1. Ṣàfikún olùyanjú endpoint ẹkùn, kí o sì dá àwọn àiyípadà àgbáyé tó wà lọ́wọ́lọ́wọ́ dúró.
2. Lo ìṣàwárí DashScope `/models` ẹkùn tó ń ṣiṣẹ́ lọ́wọ́lọ́wọ́ fún `alibaba`, ID ìbámu `alibaba-cn` rẹ̀,
   àti `qwen-cloud`. Àwọn èsì wọn kọ́kọ́ kọjá nínú àlẹ̀mọ́ ìṣẹ̀dá-ọ̀rọ̀ kan nítorí pé endpoint gbogbogbò náà
   tún ń dá àwọn awoṣe àwòrán, fídíò, ohun, embedding, àti àwọn awoṣe mìíràn tí kì í ṣe ti ìfọ̀rọ̀wérọ̀ padà. Lẹ́yìn náà, `qwen-cloud`
   yóò lo allowlist tí a ń bójú tó, èyí tí a kéde nínú registry provider rẹ̀. Alibaba Model Studio
   àti Qwen Cloud yóò pa àwọn katalogi tí a ti ṣètò lọ́tọ̀, bí ó tilẹ̀ jẹ́ pé wọ́n ń lo àwọn runtime host kan náà lọ́wọ́lọ́wọ́.
3. Forúkọsílẹ̀ `qwen-cloud-token-plan` pẹ̀lú allowlist awoṣe-ọ̀rọ̀ Token Plan tó wà lọ́wọ́lọ́wọ́.
4. Ṣàfikún olùyan ẹkùn tó ní type sí àwọn dialog ìṣàfikún/àtúnṣe connection.
5. Fi card `alibaba-cn` àdáwòkọ pamọ́, kí o sì fi àwọn connection rẹ̀ tó ti wà tẹ́lẹ̀ kún ojú-ewé provider `alibaba`.
6. Jẹ́ kí àwọn override endpoint àdáni ṣì wà fún àwọn ìmúṣiṣẹ́ tó ti ní ìlọsíwájú àti àwọn tó jẹ́ pàtó sí workspace.

Àwọn awoṣe media Token Plan ṣì wà níta katalogi ìfọ̀rọ̀wérọ̀ nítorí pé wọ́n ń lo àwọn endpoint tí a yà sọ́tọ̀.
A forúkọsílẹ̀ `wan2.7-image` àti `wan2.7-image-pro` nínú `open-sse/config/imageRegistry.ts`;
a forúkọsílẹ̀ `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, àti `happyhorse-1.1-r2v` nínú
`open-sse/config/videoRegistry.ts`. Àwọn registry méjèèjì tún lo identity connection `qwen-cloud-token-plan`
àti àwọn credential rẹ̀ tó jẹ́ pàtó sí ẹkùn.

Qwen Cloud déédéé ní àwọn katalogi àwòrán àti fídíò pay-as-you-go lọ́tọ̀ lábẹ́ identity `qwen-cloud`.
Àwọn awoṣe àwòrán rẹ̀ ni `wan2.7-image-pro`, `wan2.7-image`, `qwen-image-3.0-pro`,
`qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0-2026-03-03`, àti `z-image-turbo`. Àwọn awoṣe fídíò
rẹ̀ ni `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`,
`happyhorse-1.0-video-edit`, `wan2.7-t2v`, `wan2.7-i2v`, `wan2.7-r2v-2026-06-12`, àti
`wan2.7-videoedit`. Àwọn awoṣe wọ̀nyí tún lo connection `qwen-cloud` déédéé nìkan àti endpoint media
DashScope ẹkùn. Àwọn registry Token Plan àti pay-as-you-go kì í jogún tàbí dapọ̀
àwọn àkójọ awoṣe ara wọn.

Identity `bailian-coding-plan` náà ní àwọn allowlist media tirẹ̀:
`wan2.7-image`, `wan2.7-image-pro`, `qwen-image-2.0`, àti `qwen-image-2.0-pro` fún ìṣẹ̀dá
àwòrán, pẹ̀lú
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, àti `happyhorse-1.1-r2v` fún ìṣẹ̀dá
fídíò. Ó ń lo connection Bailian Coding Plan nìkan àti endpoint Coding Plan ẹkùn.
Àwọn registry àwòrán àti fídíò rẹ̀ kì í jogún láti ọ̀dọ̀ tàbí dapọ̀ mọ́ èyíkéyìí nínú àwọn provider Qwen Cloud.

Identity `alibaba` déédéé ní àwọn allowlist àwòrán àti fídíò lọ́tọ̀. Àwọn awoṣe àwòrán rẹ̀ ni
`qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0`,
`z-image-turbo`, àti `wan2.6-t2i`. Àwọn awoṣe fídíò tí a ṣàfikún sí i ni `happyhorse-1.1-i2v`,
`happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`,
`wan2.7-i2v-2026-04-25`, `wan2.6-i2v-flash`, `wan2.7-t2v-2026-06-12`,
`wan2.7-r2v-2026-06-12`, àti `wan2.7-videoedit`. Àwọn awoṣe wọ̀nyí ń lo connection Alibaba Model Studio
nìkan àti endpoint media ẹkùn tí a yàn fún un; a kò ṣàfikún wọn sí registry Coding Plan tàbí Qwen
Cloud kankan.

Katalogi ìfọ̀rọ̀wérọ̀ Qwen Cloud Token Plan ń tẹ̀lé allowlist ọ̀rọ̀ exact-string ti ètò Individual:
`qwen3.8-max-preview`, `qwen3.7-max`, `qwen3.7-plus`, `qwen3.6-flash`, `glm-5.2`, àti
`deepseek-v4-pro`. Àwọn àkọsílẹ̀ Wan àti HappyHorse jẹ́ ti àwọn API ìṣẹ̀dá àwòrán/fídíò lọ́tọ̀.

Alibaba Token Plan ń pèsè àwọn ID awoṣe ìṣẹ̀dá-ọ̀rọ̀ mẹ́fà kan náà tó wà lọ́wọ́lọ́wọ́ nípasẹ̀
endpoint tó bá Anthropic mu. Àṣàyàn Singapore rẹ̀ ń tọ́jú region key `global-sg` tó ti wà;
label tí olumulo ń rí nìkan ló yàtọ̀ sí àwọn ìdílé provider tí wọ́n ń pe ẹkùn náà ní Global.

A mọ̀ọ́mọ̀ mú katalogi ìfọ̀rọ̀wérọ̀ Qwen Cloud déédéé dín ju gbogbo èsì ọ̀rọ̀ tó ń ṣiṣẹ́ lọ́wọ́lọ́wọ́ lọ. Allowlist
tí a ń bójú tó wà nínú `open-sse/config/providers/registry/qwen-cloud/index.ts`; ìṣàwárí
tó ń ṣiṣẹ́ lọ́wọ́lọ́wọ́ máa ń dá àwọn ID tó wà nínú èsì upstream àti àkójọ registry yẹn méjèèjì nìkan padà.

Alibaba Model Studio ń tẹ̀lé òfin live-intersection kan náà pẹ̀lú allowlist rẹ̀ tí a ń bójú tó lọ́tọ̀
nínú `open-sse/config/providers/registry/alibaba/index.ts`. Provider ìbámu `alibaba-cn`
tún lo katalogi yẹn nígbà tó ń yanju ìṣàwárí sí endpoint Beijing.
