`copilot-m365-web` (orúkọ àpèjúwe `m365copilot`) ń fi àwọn ìbéèrè ìfọ̀rọ̀wérọ̀ ní ìlànà OpenAI ránṣẹ́ nípasẹ̀ ìgbà aṣàwákiri Microsoft 365 Copilot BizChat tí a ti jẹ́rìí sí ní
`m365.cloud.microsoft/chat`. Ìsopọ̀ yìí kì í ṣe ti ìjọba.

> **Ṣé o ṣẹ̀ṣẹ̀ bẹ̀rẹ̀ sí í lo àwọn olùpèsè Web Cookie?**
>
> Ka **`docs/getting-started/WEB-COOKIE-GUIDE.md`** fún ìlànà ìṣètò gbogbogbò, ìtọ́sọ́nà ìjẹ́rìísí, àwọn ààlà, àti ìṣàtúnṣe ìṣòro kí o tó tẹ̀lé ìtọ́sọ́nà tó jẹ́ ti olùpèsè yìí.
>
> **Pàtàkì:** Ẹ̀rí ìwọlé fún olùpèsè yìí **kì í ṣe cookie**. Má ṣe da àwọn
> cookie láti `m365.cloud.microsoft` kọ. Ẹ̀rí ìwọlé náà jẹ́ pàrámítà ìbéèrè URL WebSocket
> àti abala ipa-ọ̀nà kan, tí a máa kà láti taabu Network inú DevTools.

## Àwọn ohun tí a nílò ṣáájú

- Àkọọ́lẹ̀ Microsoft 365 kan tó ní ààyè sí BizChat ní `m365.cloud.microsoft/chat`
- Aṣàwákiri tó dá lórí Chromium (Chrome, Edge) fún ṣíṣe àyẹ̀wò WebSocket nínú DevTools
- Ìwé-àṣẹ M365 Copilot kan (tó wà pẹ̀lú ọ̀pọ̀lọpọ̀ ètò Microsoft 365 Business/Enterprise)

## Gbígba ẹ̀rí ìwọlé (ọ̀nà WebSocket)

1. Wọlé ní `https://m365.cloud.microsoft/chat` kí o sì bẹ̀rẹ̀ ìfọ̀rọ̀wérọ̀ kan.
2. Ṣí **DevTools → Network**.
3. Ṣe àlẹ̀mọ́ pẹ̀lú **WS** (WebSocket).
4. Tẹ àsopọ̀ Chathub WebSocket náà. Wá URL kan tó bẹ̀rẹ̀ pẹ̀lú
   `wss://substrate.office.com/m365Copilot/Chathub/`.
5. Láti inú **Request URL** rẹ̀, da àwọn wọ̀nyí kọ:
   - Iye pàrámítà ìbéèrè `access_token` (JWT alákókò-kúkúrú).
   - Abala ipa-ọ̀nà Chathub lẹ́yìn `/Chathub/` (fún àpẹẹrẹ, `<oid>@<tenant>`).

URL kíkún náà ní ìrísí yìí:

```
wss://substrate.office.com/m365Copilot/Chathub/<oid>@<tenant>?...&access_token=<jwt>
```

6. Nínú OmniRoute, lọ sí **Providers → Add Provider**, yan **Microsoft 365 Copilot
   (BizChat)**, kí o sì lẹ ẹ̀rí ìwọlé náà mọ́ ní ìlànà yìí:

```
access_token=<jwt>; chathubPath=<oid>@<tenant>
```

7. Tẹ **Test Connection** àti **Save**.

## Gbígba ẹ̀rí ìwọlé (gbígbé HAR wọlé)

Dípò dídà àwọn iye kọ́ lọ́wọ́ láti URL WebSocket, o lè ṣe àgbéjáde fáìlì HAR
DevTools kan:

1. Ṣí **DevTools → Network**.
2. Bẹ̀rẹ̀ tàbí tẹ̀síwájú pẹ̀lú ìfọ̀rọ̀wérọ̀ BizChat kan (èyí ló ń mú àsopọ̀ WebSocket ṣiṣẹ́).
3. Tẹ bọ́tìnì ọ̀tún nínú pánẹ́ẹ̀lì Network, kí o sì yan **Save all as HAR with content**.
4. Nínú OmniRoute, lo bọ́tìnì **Import .har file** lórí àpótí ìbánisọ̀rọ̀ àsopọ̀ olùpèsè.

OmniRoute máa ń ṣàyẹ̀wò HAR náà fún URL Chathub WebSocket, ó máa ń yọ
`access_token` àti `chathubPath` jáde, ó sì máa ń fi àwọn ààyè ẹ̀rí ìwọlé kún fúnra rẹ̀. Gbígbé
HAR wọlé máa ń tú àkókò ìparí JWT, ó sì máa ń fi iye àkókò tó kù fún token náà hàn.

> **Má ṣe fi àgbéjáde HAR gidi, access token, tàbí refresh token sí ibi ìpamọ́ kóòdù láéláé.** Àwọn iye ìdánwò àti
> àkọsílẹ̀ gbọ́dọ̀ jẹ́ àwọn iye àfidípò ní gbogbo ìgbà.

## Àkókò ìwúlò token àti ìsọdọ̀tun

`access_token` ní àkókò ìwúlò kúkúrú (ní àṣà, **~75 ìṣẹ́jú**). Lẹ́yìn tó bá parí, olùpèsè
máa ń jìyìn àṣìṣe àsopọ̀, o sì gbọ́dọ̀ tún gba ẹ̀rí ìwọlé náà.

### Ìsọdọ̀tun aládàáṣiṣẹ́ pẹ̀lú `refreshToken`

Láti yẹra fún àtúngba ẹ̀rí ìwọlé lọ́wọ́, o lè fi Microsoft refresh token pamọ́ sínú
**Advanced Settings → providerSpecificData** ti àsopọ̀ náà:

| Ààyè           | Àpèjúwe                                                               |
| -------------- | --------------------------------------------------------------------- |
| `refreshToken` | Microsoft OAuth refresh token fún scope `substrate.office.com/sydney` |
| `tier`         | `individual` (àiyípadà), `edu`, tàbí `enterprise`                     |

Gba refresh token náà láti inú ìṣàn device-code tàbí authorization-code Microsoft
tó ní scope `substrate.office.com/sydney`. Nígbà tí a bá ṣètò `refreshToken`, OmniRoute
máa ń tún `access_token` ṣe ṣáájú ìbéèrè kọ̀ọ̀kan, nítorí náà o kò nílò láti
tún gba ẹ̀rí ìwọlé lẹ́yìn gbogbo ìparí tó tó ~75 ìṣẹ́jú.

Tí a kò bá ṣètò `refreshToken`, o gbọ́dọ̀ tún gba ẹ̀rí ìwọlé WebSocket náà lọ́wọ́
lẹ́yìn ìparí kọ̀ọ̀kan.

### Yíyan ìpele

| Ìpele        | Orúkọ àpèjúwe | Ojú-iṣẹ́                            |
| ------------ | ------------- | ---------------------------------- |
| `individual` | _(àiyípadà)_  | M365 Copilot fún olùmúlò gbogbogbò |
| `edu`        | `included`    | M365 Copilot fún ẹ̀kọ́               |
| `enterprise` | `work`        | M365 Copilot fún Iṣẹ́               |

Ṣètò ìpele náà ní **Advanced Settings → providerSpecificData → tier**. Ìpele náà ní ipa lórí
ìdarí ọ̀nà BizChat àti ààyè sí model.

## Àwòṣe ààbò

- **Ìṣọ̀kan tí kì í ṣe ti òṣèlú.** Olùpèsè yìí ṣàwárí bí ìlànà WebSocket BizChat ṣe ń ṣiṣẹ́ nípasẹ̀ ìtúpalẹ̀ àyípadà. Ó lè dáwọ́ iṣẹ́ dúró láìsí ìkìlọ̀ nígbà tí Microsoft bá yí endpoint náà padà.
- Àmì `subscriptionRisk: true` fi hàn pé ìṣọ̀kan náà gbára lé endpoint tí kò ní àkọsílẹ̀ ìlànà. Ó ṣeé ṣe kí àkọọ́lẹ̀ ní àwọn ìdíwọ́, ṣùgbọ́n a kò tíì fìdí èyí múlẹ̀.
- Access token náà jẹ́ JWT aláìpẹ́. Ṣe é bí ọ̀rọ̀ aṣínà: má ṣe commit rẹ̀, má ṣe kọ ọ́ sínú log, má sì ṣe pín in.
- Refresh token náà ń fúnni ní ààyè ìwọlé pípẹ́ sí ojú-iṣẹ́ BizChat. Tọ́jú rẹ̀ pẹ̀lú ìṣọ́ra kan náà bí API key.

## Yíyanjú ìṣòro

### Ìfàṣẹsí kùnà lẹ́sẹ̀kẹsẹ̀

- Ṣàyẹ̀wò pé o daakọ láti inú **WebSocket URL**, kì í ṣe láti inú ìbéèrè XHR/Fetch. Ẹ̀rí ìwọlé náà wà nínú query parameter `access_token` ti ìsopọ̀ Chathub WebSocket — kì í ṣe nínú header `Authorization: Bearer`.
- Rí i dájú pé `chathubPath` ní gbogbo apá `<oid>@<tenant>` láti inú ipa-ọ̀nà URL.

### Token parí lẹ́yìn ~75 ìṣẹ́jú

Èyí ni a retí. Láìsí `refreshToken`, access token náà kì í pẹ́. Ṣe ọ̀kan nínú àwọn wọ̀nyí:

- Tun gba ẹ̀rí ìwọlé náà láti DevTools, tàbí
- Ṣètò `refreshToken` nínú Àwọn Ètò Ìlọsíwájú fún ìmúdójúìwọ̀n aládàáṣe.

### Ìdánwò Ìsopọ̀ kọjá ṣùgbọ́n chat dá 401 padà

Ó ṣeé ṣe kí token náà ti parí láàárín àkókò ìfìdímúlẹ̀ àti ìbéèrè àkọ́kọ́. Tun gba ẹ̀rí ìwọlé tuntun.

### Copilot kò farahàn nínú àkójọ àwọn olùpèsè

Rí i dájú pé `copilot-m365-web` ti ṣiṣẹ́ nínú **Dashboard → Providers**. Olùpèsè náà lè jẹ́ fífipamọ́ gẹ́gẹ́ bí àtẹ̀jáde àìyípadà nínú àwọn ipele kan.
