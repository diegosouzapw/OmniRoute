> A máa ṣiṣẹ́ bí a bá yàn án, ó sì jẹ́ pípa ní àkọ́kọ́ (`settings.freeAccessPolicy !== "strict"` ń fi gbogbo àkójọpọ̀ olùdíje `auto/*`
> sílẹ̀ láìyí báìtì kankan). Ó jẹ́ ẹ̀gbọ́n tó muna jù ti `hidePaidModels`
> (`open-sse/services/autoCombo/paidModelFilter.ts`, #6512) fún àwọn olùṣàkóso tó nílò ìdánilójú
> tó lágbára pé KÒ SÍ ìnáwó owó àfikún kankan, kì í ṣe pé “a ṣàkọsílẹ̀ rẹ̀ gẹ́gẹ́ bí ọ̀fẹ́” nìkan.

## Ìdí tí èyí fi wà, àti ìdí tí `hidePaidModels` nìkan kò fi tó

`hidePaidModels` ń dáhùn ìbéèrè náà pé “ṣé a pín model yìí sí ọ̀fẹ́ nínú `FREE_MODEL_BUDGETS` ní báyìí?” —
èyí jẹ́ òtítọ́ nípa katalọ́ọ̀gù ní àkókò kan pàtó, tí a ṣàyẹ̀wò nípasẹ̀ `isFreeModel()`/`providerHasFreeModels()`
(`src/shared/utils/freeModels.ts`). Kò sọ ohunkóhun nípa àwọn ewu gidi méjì:

1. Àyè ìlò ọ̀fẹ́ ti ipele `recurring-*`/`one-time-initial` lè ti **tán** — katalọ́ọ̀gù
   ṣì ń ṣe àkójọ model náà gẹ́gẹ́ bí ọ̀fẹ́, ṣùgbọ́n account tó wà lẹ́yìn rẹ̀ kò ní àyè tó kù mọ́.
2. Líla ààlà ipele ọ̀fẹ́ kì í sábà jẹ́ ìdádúró pátápátá. Àwọn provider kan sọ ní kedere pé a kò
   lè so ọ̀nà ìsanwó mọ́ ọn láé (“a kò nílò káàdì kirẹ́díìtì”); àwọn mìíràn kò sọ bẹ́ẹ̀, àwọn
   díẹ̀ sì máa ń gba owó láìfọwọ́yí lẹ́yìn tí àyè ìlò ọ̀fẹ́ bá tán.

`hidePaidModels` kò lè ṣe ìyàtọ̀ láàárín àwọn wọ̀nyí — a kò dá a sílẹ̀ fún ìyẹn rí. STRICT_ZERO_COST ń ṣàfikún
àwọn àyẹ̀wò méjèèjì yìí gan-an, tí a ń ṣe fún olùdíje kọ̀ọ̀kan, **ṣáájú** ìṣètò category/tier àti **ṣáájú**
fífi request ránṣẹ́ — kì í ṣe lẹ́yìn tí request kan ti jáde tán.

## Ìpínsọ̀rí àwọn olùdíje

Fún gbogbo olùdíje tó wà nínú àkójọpọ̀ náà (`open-sse/services/autoCombo/virtualFactory.ts::buildPreparedPool`,
lẹ́sẹ̀kẹsẹ̀ lẹ́yìn `filterPaidOnlyCandidates`):

1. **Kò sí nínú `FREE_MODEL_BUDGETS` rárá** → a yọ ọ́ kúrò. Èyí kan àwọn model tí a ń sanwó fún ní tòótọ́ àti
   provider/model èyíkéyìí tí OmniRoute kò tíì pín sí ẹ̀ka kan — àwọn olùdíje tuntun máa bẹ̀rẹ̀ gẹ́gẹ́ bí
   ẹni tí a yọ kúrò, kì í ṣe ẹni tí a fi kún un.
2. **`freeType: "keyless"`** → ó kọjá lẹ́sẹ̀kẹsẹ̀, **ṣùgbọ́n fún olùdíje tí ó dé ní tòótọ́
   nípasẹ̀ ọ̀nà tí kò nílò ìfàṣẹsí nìkan** (`connectionId === SYNTHETIC_NOAUTH_CONNECTION_ID`,
   `open-sse/services/autoCombo/resilienceCandidateFilter.ts`). Kò sí credential fún
   olùdíje yẹn, nítorí náà kò sí request sí i tí a lè gba owó rẹ̀ láé — kò nílò àyẹ̀wò nígbà ìṣiṣẹ́,
   kò sì ṣeé ṣe. Provider/model `keyless` kan náà tí a kọ sínú katalọ́ọ̀gù, tí a dé ọ̀dọ̀ rẹ̀ nípasẹ̀
   connection DB **gidi** kan (`connectionId` jẹ́ id connection gidi kan, tàbí olùdíje náà ní
   `allowedConnectionIds`) kò gba ọ̀nà àbáyọ yìí — metadata `keyless` ṣe àpèjúwe ọ̀nà tí kò nílò
   ìfàṣẹsí ní pàtó, kì í ṣe provider náà lápapọ̀, kò sì fún account gidi kan tó ní credential
   láṣẹ láé. Irú olùdíje bẹ́ẹ̀ tẹ̀ síwájú sí àyẹ̀wò 3 gẹ́gẹ́ bí gbogbo àwọn mìíràn, níbi tí a ó ti
   yọ ọ́ kúrò àfi bí ìkọ̀sílẹ̀ katalọ́ọ̀gù náà bá tún ní `hardStopGuaranteed: true` lọ́tọ̀ (àwọn
   ìkọ̀sílẹ̀ `keyless` gidi kò ní èyí láé — ọ̀nà àbáyọ náà ni ọ̀nà ààbò wọn kan ṣoṣo).
3. **Eyikeyi `freeType` mìíràn** (`recurring-daily`, `recurring-monthly`, `recurring-credit`,
   `recurring-uncapped`, `one-time-initial`, àti eyikeyi type ọjọ́ iwájú tí module yìí kò
   bá ṣe àkànṣe ìtọ́jú fún) → yóò kọjá bí **gbogbo** àwọn ìpèsè wọ̀nyí bá pé nìkan:
   - A ṣètò `hardStopGuaranteed: true` lórí ìkọ̀sílẹ̀ katalọ́ọ̀gù náà (`FreeModelBudget.hardStopGuaranteed`,
     `open-sse/config/freeModelCatalog.ts`) — èyí jẹ́ **òtítọ́ tí a fara balẹ̀ yàn, tí a sì ṣètò pẹ̀lú ọwọ́**
     nípa àwọn ìlànà tí provider fúnra rẹ̀ tẹ̀ jáde (fún àpẹẹrẹ, ìjẹ́rìí kedere pé “a kò nílò káàdì
     kirẹ́díìtì”), a kò sì ń yọ ọ́ láti inú `freeType` tàbí ìdáhùn API ní tààrà láé. Bí a kò bá ṣètò rẹ̀
     (`undefined`) àti `false`, a máa ka àwọn méjèèjì sí “kò ní ìdánilójú”.
   - Adapter ìlò kan wà fún provider náà nínú `USAGE_FETCHER_PROVIDERS`
     (`open-sse/services/usage.ts`) — registry kan náà tó ti ń ṣe àtìlẹ́yìn fún dashboard quota àti
     `getUsageForProvider()`. Kò sí adapter → a yọ ọ́ kúrò títí láé, títí di ìgbà tí a bá fi ọ̀kan kún un.
   - `FreeAccessState` alààyè, tí a ti cache, fún **connection pàtó tí a ń
     ṣàyẹ̀wò ní tòótọ́** jẹ́ `status: "SAFE"`, a sì ti ṣàyẹ̀wò rẹ̀ láàárín
     `settings.autoRefreshProviderQuotaInterval` (180s ní àkọ́kọ́ — setting tó ti wà tẹ́lẹ̀, kì í ṣe
     nọ́mbà tuntun), ó sì jèròyìn `remainingFreeAllowance` tó ga ju àlà ààbò kékeré kan lọ.
4. **`freeType: "discontinued"`** → a máa yọ ọ́ kúrò ní gbogbo ìgbà.

## Ààbò ìsopọ̀ (ìjẹ́rìísí fún ìsopọ̀ kọ̀ọ̀kan, kì í ṣe fún olùdíje kọ̀ọ̀kan)

Olùdíje kan nínú àkójọpọ̀ auto-combo kì í ṣe pé ó máa ń so mọ́ ìsopọ̀ kan ṣoṣo ní gbogbo ìgbà. Olùdíje “ọgbọ́n-ẹ̀rọ”
(`connectionId: null`) ní àkójọ ìyọ̀ǹda `allowedConnectionIds` — ìyẹn ìsopọ̀/àkọọ́lẹ̀
olùpèsè gidi kan tàbí jù bẹ́ẹ̀ lọ, tí èyíkéyìí nínú wọn lè bójú tó ìbéèrè náà — a sì máa pinnu àkọọ́lẹ̀ tí
a ó lò nígbà tí a bá ń fi iṣẹ́ ránṣẹ́, nípasẹ̀ `open-sse/services/combo/autoStrategy.ts`
(nípa mímú ibi tí `allowedConnectionIds` àti ọgbọ́n yíyan ìsopọ̀ tirẹ̀ bá pàdé, ~ìlà 315-331).

STRICT_ZERO_COST máa ń jẹ́rìí ipò ìráyè-ọ̀fẹ́ ti **ìsopọ̀ kọ̀ọ̀kan nínú àkójọ ìyọ̀ǹda náà
lọ́tọ̀ọ̀tọ̀** (`evaluateCandidateConnections()` nínú `strictZeroCostFilter.ts`), ó sì tún
`allowedConnectionIds` kọ sí ìpín kékeré gan-an tí ó dáhùn padà gẹ́gẹ́ bí `SAFE` — kì í ṣe gbogbo
àkójọ àkọ́kọ́, bẹ́ẹ̀ ni kì í ṣe ọmọ ẹgbẹ́ kan tí a yàn láìní ìlànà. Ní pàtó:

- Àkọọ́lẹ̀ A jẹ́ `SAFE`, àkọọ́lẹ̀ B jẹ́ `UNKNOWN`/ti lo ààlà tán/tí a lè gba owó lé lórí → A nìkan ló ṣì ṣeé yàn.
- Gbogbo àkọọ́lẹ̀ jẹ́ `UNKNOWN` → a yọ olùdíje náà kúrò pátápátá (àkójọpọ̀ àìléwu ṣófo).
- Olùdíje oní-ìsopọ̀-kan (`connectionId` tí a ṣètò tààrà, láìsí àkójọ ìyọ̀ǹda) tí ó kùnà ni a
  yọ kúrò lẹ́sẹ̀kẹsẹ̀; a kì í dá a padà pẹ̀lú `allowedConnectionIds` tí ó ṣófo.

Nítorí pé `autoStrategy.ts` ti ń fipá mú `allowedConnectionIds` gẹ́gẹ́ bí àkójọ ìyọ̀ǹda líle kí ó tó
yan ìsopọ̀ tí a ó fi iṣẹ́ ránṣẹ́ sí, títún un kọ sí ìpín `SAFE` tí a ti jẹ́rìí rẹ̀ tó láti
ṣe ìdánilójú pé ìsopọ̀ tí a lò nígbà fífi iṣẹ́ ránṣẹ́ jẹ́ ọ̀kan tí àsẹ́ yìí fúnra rẹ̀ ti jẹ́rìí rẹ̀ ní gbogbo ìgbà —
kì í ṣe àkọọ́lẹ̀ mìíràn tí a kò jẹ́rìí rẹ̀ lórí olùdíje kan náà. Wo
`tests/unit/autoCombo/strict-zero-cost-connection-safety.test.ts` fún ẹ̀rí ìdènà ìpadàsẹ́yìn
(àwọn ọ̀ràn A/B/C ti keyless-bypass, àwọn ọ̀ràn 1-5 ti ọ̀pọ̀-àkọọ́lẹ̀).

`discovered automatically`: olùpèsè/àwòṣe kan tí a bá tú jáde lọ́la pẹ̀lú metadata tó péye (nínú
kátálọ́ọ̀gù, pẹ̀lú usage adapter, `hardStopGuaranteed: true`) ṣeé lò ní kété tí OmniRoute bá mọ̀
nípa rẹ̀ — kò nílò ìyípadà kóòdù, kò nílò àfikún sí whitelist, kò sì sí ohun tí a nílò láti ṣàtúnṣe nínú module yìí. Èyí tí a bá yọ
kúrò nínú kátálọ́ọ̀gù yóò pòórá lọ́nà kan náà. Wo
`tests/unit/autoCombo/strict-zero-cost-autodiscovery.test.ts` fún ẹ̀rí ìdènà ìpadàsẹ́yìn (nípasẹ̀
àwọn fixture tí a lè fi sínú rẹ̀, kì í ṣe nípa yíyí kátálọ́ọ̀gù gidi padà).

## Ìfipamọ́ quota sínú cache (`open-sse/services/autoCombo/freeAccessQuota.ts`)

Ó tún ń lo `getUsageForProvider()` — kò sí ètò quota kejì. Cache kékeré kan tí ó wà nínú memory,
tí ó sì wà jálẹ̀ gbogbo ìgbà ayé process, wà níwájú rẹ̀ (TTL tó dọ́gba pẹ̀lú
`autoRefreshProviderQuotaInterval` àìyípadà) kí ìwọ̀n ìbéèrè tó tó ti Telegram má bàa fa
ìpè billing-API lọ́wọ́lọ́wọ́ fún olùdíje kọ̀ọ̀kan nínú ìbéèrè kọ̀ọ̀kan. Kíkà máa ń ṣẹlẹ̀ lẹ́sẹ̀kẹsẹ̀: àìrí nǹkan nínú cache máa dá
`undefined` padà (→ a yọ ọ́ kúrò, a sì ti i pa nígbà ìkùnà), ó sì bẹ̀rẹ̀ ìmúdójúìwọ̀n lẹ́yìn-rìn fún kíkà _tó kàn_ —
kò sí ohunkóhun nínú ipa ọ̀nà ìkọ́ àkójọpọ̀ olùdíje tí ó dúró de ìpè nẹ́tíwọ́ọ̀kì.

A máa ń pe `invalidateFreeAccessState(provider, connectionId)` láti inú
`src/sse/services/auth.ts::markAccountUnavailable()` ní kété tí ìsopọ̀ kan bá kùnà fún ìdí
èyíkéyìí, nítorí náà ìkọ́ àkójọpọ̀ tó tẹ̀ lé e yóò rí àìrí nǹkan nínú cache tó mọ́ dípò àkọọlẹ̀ `SAFE` tí ó ti pẹ́ —
kò nílò láti dúró kí TTL parí lẹ́yìn ìdáhùn 402/403/quota-exhausted.

## Ìdábòbò ToS (olóminira kúrò nínú ààbò ọrọ̀ ajé)

`excludeTosAvoid` (àìyípadà rẹ̀ ni `false`) máa ń yọ olùdíje èyíkéyìí tí ìdájọ́ `tos` tí a ti ṣàkóso rẹ̀
(`FreeModelBudget.tos`) bá jẹ́ `"avoid"` — ó tún lo field kan náà tí àwọn àkọsílẹ̀ ẹlẹgbẹ́ `hidePaidModels`
(`docs/reference/FREE_TIERS.md`) ti ń kún tẹ́lẹ̀. A mọ̀ọ́mọ̀ yà á sọ́tọ̀ kúrò nínú
`freeAccessPolicy`: olùdíje kan lè jẹ́ `SAFE` nípa ọrọ̀ ajé, síbẹ̀ kí a yọ ọ́ kúrò níbí fún
àwọn ìdí àdéhùn, tàbí kí a fi í sílẹ̀ nígbà tí ìdábòbò yìí bá wà ní pípa, kódà bí `freeAccessPolicy: "strict"` bá wà ní títàn.

## Rírí ohun tí ìdábòbò náà yọ kúrò

`GET /v1/auto-combo/{channel}/candidates` ṣe àkójọ gbogbo olùdíje, pẹ̀lú àwọn tí ìdábòbò yìí
ì bá ti dá dúró láti rán jáde, olúkúlùkù sì ní `freeAccessExclusion` — `null` nígbà tí a bá
tẹ́ ìdábòbò náà lọ́rùn, bí bẹ́ẹ̀ kọ́, ó jẹ́ ìdí náà. Àkójọ náà ń jabo nìkan; kò fipá mú ohunkóhun. Pípa ìlànà náà
máa ń fi field náà sí `null` ní gbogbo ibi, kò sì ná ohunkóhun.

| `freeAccessExclusion`  | Ohun tí ó túmọ̀ sí                                                                                                          | Ohun tí a lè ṣe nípa rẹ̀                                                                                                      |
| :--------------------- | :------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| `not-in-catalog`       | Tọkọtaya olùpèsè/model náà kò sí nínú `FREE_MODEL_BUDGETS`.                                                                | Ṣàfikún àkọsílẹ̀ tí a ti ṣàkóso, tàbí gba pé a máa yọ àwọn tọkọtaya tuntun kúrò ní ìbẹ̀rẹ̀ — bẹ́ẹ̀ ni a ṣe ṣe àpẹrẹ rẹ̀.           |
| `regime-not-free`      | Ó wà nínú àkójọ, ṣùgbọ́n `freeType` rẹ̀ kì í ṣe èyí tí ó ń fúnni ní ààyè ìlò ọ̀fẹ́ (fún àpẹẹrẹ, ìpele tí a ti fòpin sí).       | Kò sí ohun tí a lè túnṣe. Model náà ń ná owó.                                                                                |
| `no-hard-stop`         | Ètò ọ̀fẹ́ ni, ṣùgbọ́n `hardStopGuaranteed` kì í ṣe `true`, nítorí náà lílo ju ìyè ààyè náà lọ lè bẹ̀rẹ̀ sí í gba owó láìkìlọ̀.   | Ṣàyẹ̀wò àwọn òfin olùpèsè náà, kí o sì ṣètò flag náà pẹ̀lú orísun inú àlàyé — má ṣe é láti mú kí àkójọ náà tóbi láé.           |
| `contradictory-noauth` | Olùdíje tí kò nílò ìfàṣẹsí, ṣùgbọ́n tí àkọsílẹ̀ rẹ̀ nínú àkójọ kì í ṣe `keyless`. Ó máa ń kọ̀ nígbà tí metadata kò bá bára mu. | Ṣàtúnṣe àkọsílẹ̀ inú àkójọ náà; àwọn òtítọ́ méjèèjì kò bára mu.                                                                |
| `exhausted`            | Ìkà tuntun fi hàn pé a ti lo gbogbo ìyè ààyè náà tán.                                                                      | Dúró de àtúntò rẹ̀. Èyí máa ń yanjú ara rẹ̀.                                                                                   |
| `state-unknown`        | Kò sí ìkà quota, tàbí ó ti pẹ́ jù débi pé a kò lè gbẹ́kẹ̀ lé e.                                                               | Lọ ṣàyẹ̀wò: ó ṣeé ṣe kí olùpèsè náà má ní usage adapter tí a forúkọ rẹ̀ sílẹ̀, tàbí kí gbígba quota náà má ṣiṣẹ́.                |
| `no-connection`        | Olùdíje náà kò ní account kankan láti ṣàyẹ̀wò rárá.                                                                         | Kì í ṣe ìṣòro quota: a kọ olùdíje náà láìsí connection, nítorí náà kò sí ohun tí a ṣàyẹ̀wò rí. Ṣàyẹ̀wò bí a ṣe kó pool náà jọ. |

Àwọn méjì tó kẹ́yìn ni ó yẹ kí a yà sọ́tọ̀. Ìyè ààyè tí a ti lò tán máa ń tún ara rẹ̀ ṣe; ìkà
tí kò dé rárá túmọ̀ sí pé ìwádìí fúnra rẹ̀ ti bàjẹ́, títí di báyìí sì ni àwọn méjèèjì ti dà bí ohun kan náà láti
ìta — olùdíje náà kàn pòórá.

**Àlàfo kan ṣì wà, a sì mọ̀ọ́mọ̀ fi í sílẹ̀.** `excludeTosAvoid` ṣì ń yọ àwọn olùdíje kúrò kí a tó
kọ àkójọ náà, nítorí náà model tí a ti ṣàkóso gẹ́gẹ́ bí `tos: "avoid"` kò ní hàn láìsí ìdí kankan — àìríkan náà
gan-an tí abala yìí ṣẹ̀ṣẹ̀ yanjú fún ìdábòbò aláìnáwó. Títẹ̀síwájú láti yanjú èyí pẹ̀lú túmọ̀ sí ṣíṣe ìpinnu ohun tí
ìyọkúrò ToS yẹ kí ó jabo, èyí sì jẹ́ ìbéèrè tó yàtọ̀ sí ààbò ọrọ̀ ajé; ojú-ewé yìí dárúkọ
àlàfo náà dípò ṣíṣe bí ẹni pé kò sí níbẹ̀.

Fún àfiwé offline ṣáájú/lẹ́yìn, `npx tsx scripts/ad-hoc/dry-run-strict-zero-cost.ts` ṣì ń ṣiṣẹ́
lórí candidates output ti instance tó ń ṣiṣẹ́; ó máa ń ka `connectionId` gidi ti olùdíje kọ̀ọ̀kan, nítorí náà ó
tún máa ń dán ipa-ọ̀nà ààbò connection wò. Àwọn olùdíje keyless gbọ́dọ̀ dé pẹ̀lú
`connectionId` no-auth àfọwọ́ṣe, kì í ṣe connection gidi láé. Ipa-ọ̀nà auto keyless tí a kọ sínú rẹ̀ lọ́wọ́lọ́wọ́ ni OpenCode Free; iye àwọn olùdíje gan-an
ṣì sinmi lórí ìṣàwárí model ní àsìkò gidi, ó sì yẹ kí a wọn án lórí deployment tí a fẹ́ lò dípò
dídà á kọ láti inú ìṣiṣẹ́ àtijọ́. Olùdíje `recurring-*` máa ń kọjá nìkan nígbà tí ó bá ní
usage adapter tí a forúkọ rẹ̀ sílẹ̀ àti `hardStopGuaranteed: true`; metadata tí kò pé ṣì máa ń fa ìkọ̀sílẹ̀.

Pẹ̀lú `excludeTosAvoid: true`, a máa yọ gbogbo olùdíje tí a ti ṣàkóso gẹ́gẹ́ bí `tos: "avoid"` kúrò. OpenCode Free
ní ìdájọ́ yẹn lọ́wọ́lọ́wọ́, nítorí náà títan ìdábòbò náà lè sọ pool keyless tó ṣẹ́ kù nínú deployment di òfo.
Èyí jẹ́ pàṣípààrọ̀ tí a retí nígbà títan ìdábòbò ToS, kì í ṣe àṣìṣe: ìdábòbò náà jẹ́ `false`
ní àìyípadà fún ìdí yìí gan-an (wo "Ìdábòbò ToS" lókè).

## Ṣíṣe ìmúṣiṣẹ́

```json
PUT /api/settings
{ "freeAccessPolicy": "strict", "excludeTosAvoid": false }
```

Àwọn ètò tuntun méjèèjì lo àwọn iye tí wọ́n ní ṣáájú àfikún ẹ̀yà náà gẹ́gẹ́ bí àìyípadà (`"off"` / `false`) — ṣíṣàì mú èyíkéyìí ṣiṣẹ́
kò ní yí ìhùwàsí ìtọ́sọ́nà `auto/*` èyíkéyìí tó wà tẹ́lẹ̀ padà.
