## Àkíyèsí gbogbogbò

Ẹ́ńjìnnì Pípín Ìwọ̀n-àyè ń pín ìwọ̀n-àyè tó dá lórí àkókò ti olupèsè kan (fún àpẹẹrẹ, Codex
fèrèsé wákàtí 5, Kimi 1500 req/h) lọ́nà tó dọ́gba láàárín ọ̀pọ̀ kọ́kọ́rọ́ API tí wọ́n ń lo
àsopọ̀ kan náà.

**Ìṣòro tí ó ń yanjú:** OmniRoute ń ṣe aṣojú ọ̀pọ̀ kọ́kọ́rọ́ API sí àkọọ́lẹ̀ olupèsè
ókè kan náà. Láìsí ọgbọ́n pípín, ìṣàn ńlá láti ọ̀dọ̀ kọ́kọ́rọ́ A lè lo gbogbo
ìwọ̀n-àyè olupèsè fún wákàtí náà tán, tí yóò sì mú kí àwọn kọ́kọ́rọ́ B àti C di dídènà títí fèrèsé náà yóò fi tún bẹ̀rẹ̀.
Ẹ́ńjìnnì náà ń dènà èyí nípa:

1. Títọpinpin ìlò yíyípo kọ́kọ́rọ́ kọ̀ọ̀kan fún ìwọ̀n kọ̀ọ̀kan (%, àwọn ìbéèrè, àwọn token, $).
2. Lílo algoridimu ìpín-dọ́gba tó ń lo gbogbo agbára tó wà: kọ́kọ́rọ́ kan lè yá láti inú àwọn ìpín
   tí a kò lò nígbà tí àkójọpọ̀ gbogbogbò kò tíì kún.
3. Mímú àbájáde náà ṣẹ ní ọ̀nà ìṣiṣẹ́ pàtàkì (`chatCore.ts`) kí ìbéèrè náà tó
   dé ọ̀dọ̀ olùṣiṣẹ́ òkè.

## Algoridimu: Ìpín-Dọ́gba Tó Ń Lo Gbogbo Agbára Tó Wà

A ṣe àgbékalẹ̀ rẹ̀ nínú `src/lib/quota/fairShare.ts`.

### Àwọn ipò

| Ipò                                        | Módù       | Ìhùwàsí                                                  |
| ------------------------------------------ | ---------- | -------------------------------------------------------- |
| `globalUsedPercent < saturationThreshold`  | **Ọ̀làwọ́**  | Kọ́kọ́rọ́ lè yá títí dé ààlà gbogbogbò dín àpapọ̀ tí a ti lò |
| `globalUsedPercent >= saturationThreshold` | **Mímúná** | Fi ìpín-dọ́gba ẹnìkọ̀ọ̀kan múlẹ̀ láìyẹsẹ̀                     |

Àiyípadà `saturationThreshold = 0.5` (env `QUOTA_SATURATION_THRESHOLD`).

### Ìpinnu fún ìwọ̀n kọ̀ọ̀kan

Fún ìwọ̀n tó ń ṣiṣẹ́ kọ̀ọ̀kan nínú àkójọpọ̀ náà, ẹ́ńjìnnì ń ṣírò:

```
fairShareAllowed = poolLimit × (allocationWeight / 100)
consumed        = iye yíyípo lọ́wọ́lọ́wọ́ fún kọ́kọ́rọ́ yìí (láti QuotaStore.peek)
remaining       = fairShareAllowed - consumed
```

Lẹ́yìn náà:

- **`policy = hard`**: tí `consumed > fairShareAllowed` tí módù sì jẹ́ mímúná → **dènà**.
- **`policy = soft`**: tí `consumed > fairShareAllowed` tí módù sì jẹ́ mímúná → **fi ìjìyà kàn án** (dín ipò ààyò rẹ̀ kù nínú àpapọ̀; má ṣe dènà rẹ̀ pátápátá láé).
- **`policy = burst`**: gbà á láàyè níwọ̀n ìgbà tí ààyè àfikún gbogbogbò bá ṣì wà láìka ìpín-dọ́gba sí.

### Ààlà pípé

`capValue` + `capUnit` lórí ìpín kan jẹ́ ààlà gíga líle tí kò dá lórí módù tàbí
policy. Ìwọ̀n èyíkéyìí níbi tí `consumed >= capValue` ti máa ń **dènà** ìbéèrè náà ní gbogbo ìgbà.

### Àyẹ̀wò ọ̀pọ̀ ìwọ̀n

A máa dènà ìbéèrè kan tí **ìwọ̀n èyíkéyìí** nínú àkójọpọ̀ náà bá lè dènà rẹ̀. Àwọn ìwọ̀n
jẹ́ òmìnira lọ́tọ̀ọ̀tọ̀ — píparí 5h% kò ní ipa lórí ìwọ̀n weekly%.

### Yíyá

Ní módù ọ̀làwọ́, kọ́kọ́rọ́ kan tí kò tíì lo gbogbo ìpín rẹ̀ lè lo àfikún láti inú
àwọn ìpín tí a kò lò ti àwọn kọ́kọ́rọ́ míì. Fọ́ọ̀mùlà náà ni:

```
maxAllowed = globalLimit - consumedByOtherKeys
```

níbi tí `consumedByOtherKeys = consumedTotal - consumedByThisKey`. Ààlà gíga gbogbogbò
(`limit` àkójọpọ̀ fún ìwọ̀n yẹn) ni ààlà líle ní gbogbo ìgbà.

## Ẹ̀rọ Ìṣírò Fèrèsé Yíyípo

A ṣe àgbékalẹ̀ rẹ̀ nínú `src/lib/quota/sqliteQuotaStore.ts` àti `redisQuotaStore.ts`.

Àpò méjì fún `(apiKeyId, dimensionKey)` kọ̀ọ̀kan:

- `curr`: àpò lọ́wọ́lọ́wọ́ (`floor(nowMs / windowMs)`)
- `prev`: àpò tó ṣáájú (`curr - 1`)

Iye yíyípo tó fẹsẹ̀ múlẹ̀:

```
effectiveBucketIndex = floor(nowMs / windowMs)
bucketStartMs        = effectiveBucketIndex × windowMs
elapsed              = nowMs - bucketStartMs
weight               = 1 - elapsed / windowMs

effective = prev × weight + curr
```

**Ìpéye**: ó pé tó ~99%. Àṣìṣe náà kò ju 1% ti ìwọ̀n fèrèsé lọ ní
ààlà láàárín àwọn àpò (èyí jẹ́ àbùdá àfojúsùn àpò méjì náà).

### Ìṣiṣẹ́ pọ̀ lẹ́ẹ̀kan náà

Díràìfà SQLite: mutex inú ìrántí fún kọ́kọ́rọ́ `(apiKeyId | dimensionKey)` kọ̀ọ̀kan ń dènà
ìjà read-modify-write. Àpẹẹrẹ náà dà bí ọgbọ́n anti-thundering-herd nínú `src/sse/services/auth.ts`.

Díràìfà Redis: Lua EVAL script fún ìfikún atomiki — ó ń ṣiṣẹ́ gẹ́gẹ́ bí àṣẹ Redis kan ṣoṣo.

## Àwọn awakọ̀

### SQLite (àìyípadà, kò nílò ìfiṣọ́lẹ̀)

- Tábìlì: `quota_consumption` (wo ìṣíkiri `073_quota_pools.sql` / `074_quota_consumption.sql`).
- Ó dára jù fún àwọn ìmúṣiṣẹ́lẹ̀ ẹ̀dà kan ṣoṣo.
- Gbogbo ìtọ́jú dátà wà nínú DB SQLite OmniRoute tó ti wà tẹ́lẹ̀ (`DATA_DIR/storage.sqlite`).

### Redis (àṣàyàn, ọ̀pọ̀ ẹ̀dà)

- Ó nílò package npm `ioredis`.
- Àwọn kàǹtà ni a tọ́jú sínú Redis; metadata (àwọn pool/allocation) ṣì wà nínú SQLite.
- Ó dára jù fún àwọn ìmúṣiṣẹ́lẹ̀ aláfẹ̀dà-púpọ̀ níbi tí àwọn kàǹtà gbọ́dọ̀ jẹ́ pínpín.

### Yíyí àwọn awakọ̀ padà

Nípasẹ̀ UI ètò (`/dashboard/settings` → Ibi Ìtọ́jú Quota), tàbí nípasẹ̀ àwọn env vars:

```bash
QUOTA_STORE_DRIVER=redis
QUOTA_STORE_REDIS_URL=redis://localhost:6379
```

Ètò DB ní ààyò ju env lọ. Bí `driver=redis` ṣùgbọ́n URL kò sí tàbí
a kò fi `ioredis` sílẹ̀, factory náà yóò padà sí SQLite, yóò sì ṣàkọsílẹ̀ ìkìlọ̀ kan.

Ètò àṣàyàn awakọ̀:

1. Ètò DB `quotaStore.driver`
2. Env `QUOTA_STORE_DRIVER`
3. Àìyípadà: `sqlite`

## Ìṣọ̀kan Pẹ̀lú Pipeline

### Hook PRE (`open-sse/handlers/chatCore.ts`)

Ó máa ń ṣiṣẹ́ ṣáájú executor upstream, lẹ́yìn àwọn àyẹ̀wò ìfàṣẹsí àti ìlànà:

```
resolveComboTargets / handleSingleModel
  → enforceQuotaShare(apiKeyId, connectionId, provider, estimatedCost)
      → getQuotaStore().peek() fún ìwọ̀n kọ̀ọ̀kan
      → fairShare.decideFairShare()
      → bí a bá dí i → dá 429 padà (buildErrorBody, Òfin Líle #12)
      → bí a bá fàyè gbà á + deprioritize → ṣètò quotaSoftPenalty=true lórí candidate
  → executor.execute()
```

**Fail-open**: bí `enforceQuotaShare` bá ju àṣìṣe jáde, a ó fàyè gba ìbéèrè náà láti kọjá
pẹ̀lú àkọsílẹ̀ `pino.warn`. Èyí ń dènà àṣìṣe quota-engine kan láti dí gbogbo
ìrìnwọlé.

### Hook POST (ṣàkọsílẹ̀ lílò)

Lẹ́yìn ìdáhùn àṣeyọrí kan:

```
executor dá àṣeyọrí padà
  → spendRecorder.recordConsumption(apiKeyId, connectionId, provider, actualCost)
      → getQuotaStore().consume() fún ìwọ̀n kọ̀ọ̀kan
      → fail-open: a ṣàkọsílẹ̀ àwọn àṣìṣe gẹ́gẹ́ bí pino.warn, a kì í tan wọn dé ọ̀dọ̀ client
```

**Àkíyèsí ìyapa**: bí `consume` bá kùnà lẹ́yìn ìdáhùn, rolling counter yóò ka lílò sílẹ̀ ju bó ṣe yẹ lọ.
Àmì saturation láti ọ̀dọ̀ olùpèsè (fún àpẹẹrẹ `anthropic-ratelimit-unified-5h-utilization`)
yóò ṣe àtúnṣe ìṣírò àpapọ̀ ní ìbéèrè tó kàn.

### Ìjìyà rọ́rọ́ combo (`open-sse/services/combo.ts`)

Nígbà tí `decision.deprioritize === true`:

```ts
if (candidate.quotaSoftPenalty) {
  score *= QUOTA_SOFT_DEPRIORITIZE_FACTOR; // àìyípadà 0.7
}
```

A máa ń lo ìjìyà náà lẹ́yìn gbogbo àwọn ifosiwewe ìṣírò míì. Ó ń dín iṣeeṣe auto-combo
láti yan key tó ti kún kù láìdí i pátápátá.

## Àwọn Variable Ayíká

| Variable                           | Àìyípadà | Àpèjúwe                                               |
| ---------------------------------- | -------- | ----------------------------------------------------- |
| `QUOTA_STORE_DRIVER`               | `sqlite` | Driver láti lò: `sqlite` tàbí `redis`                 |
| `QUOTA_STORE_REDIS_URL`            | _(òfo)_  | URL Redis, àpẹẹrẹ `redis://localhost:6379`            |
| `QUOTA_SATURATION_THRESHOLD`       | `0.5`    | 0..1; `>= threshold` ń mú mode tó muna ṣiṣẹ́           |
| `QUOTA_SOFT_DEPRIORITIZE_FACTOR`   | `0.7`    | 0..1; multiplier fún score àpapọ̀ soft-policy          |
| `QUOTA_CONSUMPTION_RETENTION_DAYS` | `14`     | Ọjọ́ kí GC tó yọ àwọn bucket `quota_consumption` àtijọ́ |

Àwọn ìṣètò DB (`quotaStore.*`) ní ipò gíga ju àwọn variable ayíká lọ.

## Yíyanjú Ìṣòro

### A ti ṣètò Redis ṣùgbọ́n kò sopọ̀

Ṣàyẹ̀wò pé a ti fi `ioredis` sílẹ̀ (`npm ls ioredis`) àti pé a lè dé
`QUOTA_STORE_REDIS_URL`. Nígbà tí àsopọ̀ bá kùnà, factory náà máa padà lo SQLite
(a máa ṣe àkọsílẹ̀ rẹ̀ ní `warn`).

### `peek` ń dá data àtijọ́ padà / fail-open

Tí `peek` bá ju àṣìṣe jáde, `enforceQuotaShare` máa ka èsì náà sí "fàyè gba"
(fail-open). Ṣàyẹ̀wò àwọn àkọsílẹ̀ `pino` fún àwọn àkọọlẹ̀ `quota:enforce` àti
`quota:factory` láti mọ ohun tó fa ìṣòro náà.

### Yíyapa counter lílò

Tí lílò olupèsè gangan bá yàtọ̀ sí àwọn counter, ohun tí a retí ni — sliding
window oníbucket méjì ní àṣìṣe tó tó ~1% ní àwọn ààlà window, àti pé `consume`
jẹ́ iṣẹ́ post-response tí kò dúró de èsì. Àmì saturation (`saturationSignals.ts`)
ń ka lílò olupèsè gangan pẹ̀lú TTL 30s, ó sì ń ṣàtúnṣe `globalUsedPercent`
gẹ́gẹ́ bí ó ṣe yẹ.

### Pool ń fi "kò sí data" hàn fún burn rate

`computeBurnRate` nílò ó kéré tán àwọn sample ìtàn méjì. Àwọn pool tuntun tí kò ní
àwọn ìpè `consume` tẹ́lẹ̀ yóò fi `tokensPerSecond: 0` àti `timeToExhaustionMs: null`
hàn.

## Ìṣípadà láti localStorage

Nígbà tí `/dashboard/costs/quota-share` bá kọ́kọ́ ṣí, ìkọ̀ `useLocalStoragePoolMigration`
máa ṣàyẹ̀wò pé:

1. `localStorage.getItem("omniroute:quota-share:pools")` kò ṣófo.
2. `GET /api/quota/pools` dá `[]` padà (DB ṣófo).

Tí àwọn méjèèjì bá jẹ́ òótọ́, yóò fi ọ̀kọ̀ọ̀kan àwọn pool àtijọ́ ránṣẹ́ sí `POST /api/quota/pools` ní ìdìpọ̀,
lẹ́yìn náà yóò yọ́ kọ́kọ́rọ́ localStorage náà kúrò. Ìṣípadà náà jẹ́ idempotent: ipò 2 ń dènà
àtún-ṣíṣípadà.

## Ìsọ̀rí Ọgbọ́n Inú Ẹ̀rọ

`quota-share` jẹ́ ọgbọ́n ìdarí ipa-ọ̀nà **tí a lò nínú ẹ̀rọ nìkan** (`INTERNAL_ROUTING_STRATEGY_VALUES` nínú
`src/shared/constants/routingStrategies.ts`). Àwọn àkójọpọ̀ pool `qtSd/` tí ẹ̀rọ dá nìkan ni wọ́n ń lò ó fún,
a sì mọ̀ọ́mọ̀ yọ ọ́ kúrò nínú `ROUTING_STRATEGY_VALUES` kí ó má bàa hàn gẹ́gẹ́ bí àṣàyàn tí olùlò lè yàn nínú UI tàbí API.

## Àkótán Schema DB

Tábìlì mẹ́ta ni a fi kún un nípasẹ̀ àwọn migration `078`, `079` àti `085`:

- `quota_pools` + `quota_allocations` — àwọn ìtumọ̀ pool àti àwọn ìpín fún kọ́kọ́rọ́ kọ̀ọ̀kan.
- `quota_consumption` — àwọn counter bucket méjì tó ń yí lọ fún `(apiKeyId, dimensionKey)`.
- `provider_plans` — àwọn override ètò provider tí a ṣètò lọ́wọ́ (JSON dimension fún connectionId kọ̀ọ̀kan).

Gbogbo tábìlì ni a fi kún un nípasẹ̀ àwọn migration `CREATE TABLE IF NOT EXISTS` tí ó jẹ́ idempotent.
