Àwọn òfin ìdarí reasoning mú ìdarí model àti combo tó ti wà tẹ́lẹ̀ gbòòrò sí i. Nígbà tí kò sí òfin tó ń ṣiṣẹ́ tí ó bá ìbéèrè mu,
ìhùwàsí thinking, suffix, connection-default, àti provider-translation tó ti wà tẹ́lẹ̀ yóò dúró
láìyípadà.

## Ìṣàkóso

Ìṣàkóso òfin wà lábẹ́ **Settings → Global Routing**. Olootu API-key náà pèsè
UI ìṣàkóso kan náà tí a ti ṣe àlẹ̀mọ́ rẹ̀ sí key tí a yàn.

API ìṣàkóso náà wà nípasẹ̀ àwọn route wọ̀nyí:

- `GET` àti `POST` ní `/api/settings/reasoning-routing-rules`
- `GET`, `PATCH`, àti `DELETE` ní `/api/settings/reasoning-routing-rules/[id]`
- `POST` ní `/api/settings/reasoning-routing-rules/simulate`

Gbogbo àwọn route lo `requireManagementAuth`. A máa ń fọwọ́sí àwọn input pẹ̀lú schemas inú
`src/shared/validation/schemas/reasoningRouting.ts`. Simulator kì í ṣe upstream call rárá.

## Ìyanjú Òfin

Ìṣàyẹ̀wò àkọ́kọ́ yan òfin kan ṣoṣo. A máa ń ṣàyẹ̀wò àwọn scope ní ìtòlẹ́sẹẹsẹ yìí:

1. `apiKey`
2. `combo`
3. `model`
4. `global`

Láàárín scope kan, `priority` tó ga jù ni yóò kọ́kọ́ borí, lẹ́yìn náà model match gangan yóò borí glob pattern,
nígbà náà ni ìtòlẹ́sẹẹsẹ `createdAt` àti `id` tó dúró ṣinṣin yóò tẹ̀lé. A máa ń ka `requestTags` láti inú `metadata.tags`
nìkan, wọ́n sì ṣe àtìlẹ́yìn fún ìbámu `any` tàbí `all`.

A máa ń ṣàyẹ̀wò òfin `connection` kìkì nígbà tí kò sí òfin àkọ́kọ́ tó borí, tí a sì ti yan provider connection
kan pàtó. Ó lè yí effort àti budget nìkan padà.

## Effort àti Budget

`sourceEffort` gba `any`, `missing`, `none`, `low`, `medium`, `high`, `xhigh`, `max`, àti
`ultra`. `missing` túmọ̀ sí pé ìbéèrè náà kò ní discrete effort, thinking toggle,
tàbí thinking budget. Nítorí náà, `any` nìkan ni ó lè bá àmì budget-only mu.

`effortMode` ní àwọn oríṣi mẹ́ta:

- `inherit` pa client effort mọ́, nígbà tó ṣì ń gba model tàbí combo láyè láti yí padà.
- `default` ṣètò `targetEffort` kìkì nígbà tí kò sí àmì reasoning kedere.
- `force` fi `targetEffort` rọ́pò discrete effort.

Ní ọ̀nà òmìnira, `budgetAction` lè jẹ́ `preserve`, `remove`, tàbí `set`. `force` pẹ̀lú `none` yọ
gbogbo effort àti budget field tí a mọ̀ kúrò. `none` papọ̀ pẹ̀lú `set` kò bófin mu.

A máa kọ àwọn ìbéèrè tó ń fojú sí model tí a mọ̀ pé kò bá a mu kí upstream call tó wáyé. Fún àwọn
combo target, a máa yọ àwọn entry tí kò bá a mu kúrò; bí kò bá sí èyíkéyìí tó kù, ìbéèrè náà yóò dá status `400` padà.
Àlàyé capability tí a kò mọ̀ máa ń ṣe ìkìlọ̀, yóò sì fi òfin náà sílẹ̀ ní ipò iṣẹ́.

## Ààbò àti Àwọn Ọ̀nà Gbigbe

Source model àti target model, tàbí source combo àti target combo, ṣì wà lábẹ́ policy API-key
tó ti wà tẹ́lẹ̀. Òfin reasoning kì í fa model, combo, tàbí àṣẹ quota gbòòrò sí i láé.

A ti ṣepọ̀ engine náà mọ́ Chat Completions, Responses, Anthropic Messages, àti
ọ̀nà Codex WebSocket abẹ́nú. Ọ̀nà WebSocket gba àwọn Codex target model nìkan; kò ṣeé
ṣe àwọn combo target níbẹ̀. A máa ń fi ìpinnu òfin pamọ́ sínú route trace tó ti wà tẹ́lẹ̀ láìsí secrets.

## Ìtọ́jú Dátà

Migration `src/lib/db/migrations/126_reasoning_routing_rules.sql` ṣẹ̀dá
table `reasoning_routing_rules`. Àwọn òfin tọ́ka sí àwọn API key, combo, àti provider connection tí a ti tọ́jú.
Àwọn ìparẹ́ máa ń nu àwọn òfin tó jọmọ́ rẹ̀ kúrò. Database access layer inú
`src/lib/db/reasoningRoutingRules.ts` ń bójú tó cache tí a lè sọ di aláìwúlò fún request path.

Àwọn òfin wà nínú backup SQLite, export database kíkún, àti bundle config-sync.
`reconcileReasoningRulesForSync` máa ń pa àwọn òfin tí a import tí reference wọn kò sí mọ́, ó sì máa ń jabo
àwọn conflict wọ̀nyẹn.
