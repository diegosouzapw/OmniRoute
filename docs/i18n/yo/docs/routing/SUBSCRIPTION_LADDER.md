> Àwọn id `auto/*` tuntun méjì — `auto/subscription` àti `auto/thrifty`. Àwọn méjèèjì jẹ́ ohun tí a máa ń yàn láti lò nípa
> bíbéèrè fún wọn: kò sí ohunkóhun tí a máa darí gba inú wọn àyàfi tí olùpè kan bá béèrè fún id náà ní orúkọ, kò sì sí
> pool, strategy, tàbí default tó ti wà tẹ́lẹ̀ tí yóò yí padà.

## Ìdí tí èyí fi wà

OmniRoute ti ń dáhùn ìbéèrè méjì nípa iye owó tẹ́lẹ̀, kò sì sí èyíkéyìí nínú wọn tó jẹ́ èyí tí ọ̀pọ̀ jù lọ àwọn olùṣiṣẹ́ máa ń béèrè.

| Ètò tó ti wà                                             | Ohun tí ó ń dáhùn                                  |
| -------------------------------------------------------- | -------------------------------------------------- |
| `hidePaidModels` (`autoCombo/paidModelFilter.ts`)        | "ṣé a ṣàkọsílẹ̀ model yìí gẹ́gẹ́ bí ọ̀fẹ́?"             |
| `freeAccessPolicy: "strict"` (`strictZeroCostFilter.ts`) | "ṣé connection yìí lè gba owó lọ́wọ́ mi láéláé?"     |
| `quotaPreflight` (`combo/quotaExhaustionCutoff.ts`)      | "ṣé connection yìí ti sún mọ́ ààlà rẹ̀?"             |
| `budgetCap` / `budgetFallback` (`autoCombo/engine.ts`)   | "fi òpin sí ìnáwó, sọ ọ́ kalẹ̀ sí èyí tó din owó jù" |

Gbogbo ètò tí ó jẹ́ ti ọ̀fẹ́ nìkan **máa ń kọ̀ láìfi ọ̀nà sílẹ̀** — pool ọ̀fẹ́ tí ó ti tán jẹ́ pool òfo, kì í ṣe
ìgbésẹ̀ sókè sí aṣayan tí a ń sanwó fún — gbogbo ètò tó jẹ́ ti ẹ̀gbẹ́ ìsanwó sì kò ka tier sí. Kò sí èyíkéyìí tó dáhùn:

> "Lo quota tí mo ti ń sanwó fún. Nígbà tí ó bá tán, yálà kí o dáwọ́ dúró, tàbí kí o gòkè ní ìpele kan
> lẹ́ẹ̀kan ṣoṣo gba àwọn aṣayan ìsanwó tó din owó jù — kí o sì padà lẹ́sẹ̀kẹsẹ̀ tí ó bá reset."

## Ìsanwó jẹ́ òtítọ́ nípa connection, kì í ṣe òtítọ́ nípa model

`classifyTier()` (`open-sse/services/tierResolver.ts`) ń lo `(provider, model)` gẹ́gẹ́ bí kọ́kọ́rọ́, ó sì ń dá
`free | cheap | premium` padà láti inú iye owó inú catalog. Ṣùgbọ́n bóyá request kan yóò ná owó àfikún
dá lórí **connection tí ó ń ṣiṣẹ́ request náà**: model kan náà wà lábẹ́ plan nípasẹ̀ Claude Code
OAuth connection, ṣùgbọ́n a ń gba owó fún token kọ̀ọ̀kan nípasẹ̀ API-key connection.

`provider_connections.auth_type` kì í ṣe àmì àrídájú tó dáa ní ọ̀nà méjèèjì — àwọn OAuth
connections tí a ń díwọ̀n ìlò wọn wà, àwọn API-key connections tí plan sì ti ní nínú rẹ̀ tún wà (Copilot seat token kì í ṣe
API key tí a ń díwọ̀n ìlò rẹ̀). Nítorí náà, billing class ń wá láti inú **catalog tí a ti fara balẹ̀ yàn**,
`open-sse/config/connectionBillingCatalog.ts`, tí a ṣètò pẹ̀lú ọwọ́ láti inú àwọn àdéhùn tí provider kọ̀ọ̀kan tẹ̀ jáde —
àpẹẹrẹ kan náà tí `FreeModelBudget.hardStopGuaranteed` ti fi lélẹ̀ tẹ́lẹ̀ fún àwọn model ọ̀fẹ́.

```ts
type ConnectionBillingClass = "subscription" | "metered" | "keyless" | "unknown";
type ConnectionOverageBehavior = "hard-stop" | "meters-to-paid" | "unknown";
```

Ètò ìyanjú (`autoCombo/connectionBilling.ts`): synthetic no-auth sentinel →
`keyless`; àkọsílẹ̀ catalog kan tó bá provider **àti** `authType` mu; àkọsílẹ̀ tó kan gbogbo provider;
bí bẹ́ẹ̀ kọ́, `unknown`. **Ohun tí a kò tíì ṣàkójọ kì í ṣe ọ̀fẹ́** — a máa ń lò `unknown` bí `metered`
níbi gbogbo, nítorí náà provider tí a bá ṣàfikún lọ́la yóò bẹ̀rẹ̀ níta ìpele subscription, a sì gbọ́dọ̀
fara balẹ̀ ṣàkójọ rẹ̀ sínú rẹ̀.

## Àwòṣe ìpele

Ìpele márùn-ún ní ìtòlẹ́sẹẹsẹ ìgòkè. Kì í ṣe iye owó nìkan ni wọ́n fi yàtọ̀ — ọ̀kọ̀ọ̀kan ní àmì
ìtán tirẹ̀, ìdí nìyẹn tí èyí kì í ṣe ìṣètò lẹ́sẹẹsẹ lásán.

| #   | Ìpele          | Àwọn ọmọ ẹgbẹ́ rẹ̀                                   | Ìgbà tí a kà á sí pé ó ti tán              |
| --- | -------------- | -------------------------------------------------- | ------------------------------------------ |
| 0   | `subscription` | `billing: "subscription"` tí a ti fara balẹ̀ ṣàkójọ | quota window wà ní cutoff tàbí ní ìsàlẹ̀ rẹ̀ |
| 1   | `keyless`      | synthetic no-auth path                             | connection cooldown / breaker              |
| 2   | `free`         | metered connection, `classifyTier() === "free"`    | free allowance ti tán                      |
| 3   | `cheap`        | metered connection, `classifyTier() === "cheap"`   | budget ìpele náà ti tán                    |
| 4   | `premium`      | metered connection, `classifyTier() === "premium"` | budget ìpele náà ti tán                    |

Àwọn ìpele 0-2 máa ń tán nítorí **quota**, èyí tí a lè ṣàkíyèsí tí a sì ti ń tọpinpin rẹ̀ tẹ́lẹ̀. Àwọn ìpele 3-4 kò ní
quota — connection ìsanwó máa ń ṣiṣẹ́ títí láé — nítorí náà àmì ìtán tó bógbọ́n mu kan ṣoṣo fún wọn ni
**budget** fún ìpele kọ̀ọ̀kan. Láìsí èyí, "gòkè nígbà tí cheap bá ti tán" kò ní ohun tó máa mú un ṣiṣẹ́.

## `auto/subscription` — kùnà ní títìpa

Àkójọpọ̀ = ìpele àkàbà 0 nìkan, tí a fi mọ́ àwọn àsopọ̀ tí ìlò àfikún wọn jẹ́ `hard-stop` tí a ṣàkọsílẹ̀, tí a sì ti ṣàyẹ̀wò ọ̀kọ̀ọ̀kan wọn ní tààrà pé ààyè ṣì wà nínú ìwọ̀n lílò wọn. Gbogbo ohun tí kò ṣe kedere ni a yọ kúrò: olupèsè tí a kò tíì ṣe àyẹ̀wò rẹ̀, kíkà ìwọ̀n lílò tí a kò lè fìdí rẹ̀ múlẹ̀, kíkà tí ó ti di àtijọ́, tàbí ìlò àfikún tí a ń wọn fún ìsanwó.

Àkójọpọ̀ òfo ni èsì tí a **fẹ́**, kì í ṣe àbùkù — ọ̀nà àkójọpọ̀-òfo tí olùpè ní tẹ́lẹ̀ yí i padà sí àṣìṣe tó ṣe kedere dípò ìpadàsẹ́yìn tí kò ní ìkìlọ̀ tí a sì lè gba owó fún. Ìlérí gbogbo id náà nìyẹn.

`keyless` mọ̀ọ́mọ̀ **kò** tóótun: àkójọpọ̀ yìí túmọ̀ sí “ètò tí mo ń sanwó fún”, nítorí náà backend tí kò ní ìfàṣẹsí kò yẹ kó wà nínú rẹ̀. Lo `auto/thrifty` (tàbí `auto/best-free`) fún ìyẹn.

### Ààbò àsopọ̀

Olùdíje kan kì í ṣe dandan kí ó so mọ́ àsopọ̀ kan ṣoṣo — olùdíje oníṣe-èrò kan ní àtòjọ ìyọ̀ǹda `allowedConnectionIds`, àsopọ̀ tí a ó sì lò gan-an ni a yàn lẹ́yìn náà, nígbà ìfiránṣẹ́, láti ọwọ́ `open-sse/services/combo/autoStrategy.ts`. Nítorí náà, àwọn àkójọpọ̀ méjèèjì ń ṣàyẹ̀wò **àsopọ̀ kọ̀ọ̀kan lọ́tọ̀ọ̀tọ̀**, wọ́n sì tún `allowedConnectionIds` kọ sí ìpín kékeré tó ṣẹ́kù gan-an — kì í ṣe gbogbo àtòjọ àkọ́kọ́, bẹ́ẹ̀ ni kì í ṣe ọmọ ẹgbẹ́ kan tí a yàn láìní ìlànà. Nítorí `autoStrategy.ts` ti ń fi àtòjọ náà múlẹ̀ gẹ́gẹ́ bí àtòjọ ìyọ̀ǹda tó muna, títún un kọ níbí mú kí “èyí tí a ti ṣàyẹ̀wò” àti “èyí tí a lò gan-an” jẹ́ àkójọpọ̀ kan náà láti inú ìṣètò rẹ̀. Èyí ni ìlànà àìyípadà kan náà, àti ìrònú kan náà, bí
[STRICT_ZERO_COST](./STRICT_ZERO_COST.md).

## `auto/thrifty` — gòkè sí ìpele àkàbà kan lẹ́ẹ̀kan

Àkójọpọ̀ = gbogbo àwọn ìpele àkàbà, tí a tò nípasẹ̀ atọ́ka ìpele àkàbà, tí a sì ti dí àwọn olùdíje tí ìwọ̀n lílò wọn ti tán mọ́ta. Ẹ̀rọ `auto` ṣì ń fún wọn ní àmì **nínú** àkójọpọ̀ tó ṣẹ́kù: àkàbà ló pinnu àwọn ìpele tí yóò kópa, fífún ní àmì ló sì pinnu olùdíje tí yóò ṣẹ́gun láàárín wọn. Ìtòlẹ́sẹẹsẹ dúró ṣinṣin nínú ìpele àkàbà kan, nítorí náà ìpele tí olùfúnni-ní-àmì fúnra rẹ̀ ṣètò kì í ṣe àtúntò láti ọwọ́ àfikún yìí.

Èyí jẹ́ àfikún ìtòlẹ́sẹẹsẹ + ìdènà, **kì í ṣe** olùfiránṣẹ́ tuntun: yíyí àfojúsùn tí `combo.ts` ń ṣe tẹ́lẹ̀ ti ń rìn la àwọn àfojúsùn kọjá ní títẹ̀lé ìtòlẹ́sẹẹsẹ, ó sì ń tẹ̀síwájú sí èyí tó kàn nígbà ìkùnà, nítorí náà bí ìwọ̀n lílò bá tán ní àsìkò ìṣiṣẹ́ tí àyẹ̀wò ṣáájú kò rí, yóò ṣì gòkè sí ìpele àkàbà tó kàn láàárín ìbéèrè kan náà.

Níbi tí `auto/subscription` ti ń kùnà ní **títìpa**, `auto/thrifty` ń kùnà ní **ṣíṣí**: àsopọ̀ tó wà nínú ètò ṣíṣe tí kò ní kíkà ìwọ̀n lílò tó ṣeé lò ni a ṣì máa gbìyànjú lákọ̀ọ́kọ́. Gbígbìyànjú rẹ̀ kò ná ohunkóhun, bí ó bá sì hàn pé ìwọ̀n lílò rẹ̀ ti tán, ìtẹ̀síwájú lẹ́yìn ìkùnà yóò dé ìpele àkàbà tó kàn — ṣùgbọ́n kíkọ̀ láti gbìyànjú rẹ̀ yóò fi ìbéèrè náà ránṣẹ́ sí ìpele àkàbà tí a ń sanwó fún nítorí telemetry tí ó sọnù, èyí gan-an sì ni àbájáde tí a dá àkójọpọ̀ náà sílẹ̀ láti yẹra fún.

## Pípadà sí ètò lẹ́yìn ìtúnṣètò

Ohun mẹ́ta tí kò gbára lé ara wọn gbọ́dọ̀ dópin kí ìdarí tó padà sí ìpele àkàbà 0. Títún ọ̀kan ṣoṣo ṣe yóò fi àkàbà náà há sórí àwọn ìpele tí a ń sanwó fún fún ìgbà pípẹ́ lẹ́yìn tí ètò náà ti tún kún.

1. **Kaṣe ipò ìwọ̀n lílò** — `freeAccessQuota.ts` ń ṣe kaṣe fún `(provider, connection)` kọ̀ọ̀kan pẹ̀lú TTL 180s. Àkọsílẹ̀ kaṣe tí `resetAt` tirẹ̀ ti kọjá ṣàpèjúwe àkókò kan tí kò sí mọ́, nítorí náà a ń kà á sí àtijọ́ báyìí **láìka ọjọ́-orí rẹ̀ sí**, ó sì ń fipá mú ìmúdójúìwọ̀n. Láìsí èyí, ètò kan tó tún kún ní ọ̀gànjọ́ òru yóò máa bá a lọ láti ka pé ó ti tán títí TTL yóò fi dópin fúnra rẹ̀.
2. **Ipò àkàbà fúnra rẹ̀** — kò sí rárá, gẹ́gẹ́ bí a ṣe mọ̀ọ́mọ̀ ṣe é. A tún ń ṣírò yíyẹ ìpele àkàbà láti inú ipò ìwọ̀n lílò ní tààrà ní gbogbo ìgbà tí a bá kọ àkójọpọ̀; kò sí àkọsílẹ̀ “ní ìpele àkàbà 3 lọ́wọ́lọ́wọ́” tí a tọ́jú tí ó lè wà kọjá ìtúnṣètò kí ó sì mú kí ìdarí há.
3. **Àkókò ìdádúró àsopọ̀** — 429 tó fi hàn pé ìwọ̀n lílò ti tán ń ṣètò `rateLimitedUntil` láti inú exponential backoff, èyí tí ó lè kọjá àkókò ìtúnṣètò gidi fún àsopọ̀ ètò kan. `clampCooldownToReset()` (`subscriptionLadder.ts`) ń dín àkókò ìdádúró kù sí àkókò ìtúnṣètò ti upstream fúnra rẹ̀, kò sì lè gùn ún sí i láéláé. **A ti ṣàmúlò rẹ̀, a sì ti dán an wò, ṣùgbọ́n a kò tíì so ó pọ̀**: a ń sọ kaṣe ìwọ̀n lílò di asán nínú `src/sse/services/auth.ts` _ṣáájú_ kí a tó kọ àkókò ìdádúró èyíkéyìí, nítorí náà a gbọ́dọ̀ gba `resetAt` ṣáájú nínú function náà — ìyípadà sí ọ̀nà pàtàkì ti resilience tí ó yẹ kí ó wà nínú PR tirẹ̀ tí a ṣe àyẹ̀wò. Títí di ìgbà náà, pípadà wọlé yóò dúró de òpin àkókò ìdádúró àsopọ̀ (èyí tí ó ti ń fi àwọn àmì `Retry-After` láti upstream síwájú nígbà tí olupèsè bá fi wọ́n ránṣẹ́).

### Ìdènà yíyípadà-léraléra

A kì í tún gba ìpele àkàbà kan tó ṣẹ̀ṣẹ̀ tún ara rẹ̀ ṣe wọlé àyàfi tí ó bá ga ju `reentryMinRemainingPercent` (àìyípadà 5), nígbà tí àsopọ̀ tó ti ń ṣiṣẹ́ kò nílò ju pé kí ó dúró lókè `exitCutoffPercent` (àìyípadà 2, tó bá `quotaPreflight.defaultThresholdPercent` mu). Àlàfo náà ni hysteresis band — láìsí rẹ̀, àsopọ̀ kan tó ń rìn káàkiri ààlà ìdádúró yóò máa yí padà láàárín àwọn ìpele àkàbà lórí àwọn ìbéèrè tó tẹ̀lé ara wọn.

## Ìṣètò

Fún àtúnṣe ìṣiṣẹ́ nìkan. A mọ̀ọ́mọ̀ **kò** fi àsíá `enabled` sí i: bọ́tìnì ìyípadà tó lè pa àwọn wọ̀nyí
yóò jẹ́ kí `auto/subscription` máa pèsè gbogbo àkójọpọ̀ náà ní ìdákẹ́jẹ́ — pẹ̀lú àwọn mọ́dẹ́lì tí a ń sanwó fún — lábẹ́
orúkọ tó ṣèlérí ohun tó lòdì sí èyí.

```jsonc
{
  "subscriptionLadder": {
    "exitCutoffPercent": 2,
    "reentryMinRemainingPercent": 5,
    "rungBudgetUsd": { "cheap": 5.0, "premium": 0 }, // 0 máa ń pa ìpele kan pátápátá
  },
}
```

Ìdènà tó dá lórí ìnáwó kò ṣiṣẹ́ títí tí a ó fi so olùṣàwárí ìnáwó pọ̀: nígbà tí kò bá sí ètò ìṣírò, a máa
to ìpele tí a ń sanwó fún ṣùgbọ́n a kì í dènà rẹ̀ láé. Láti v3.8.51, àgbékalẹ̀ `rungBudgetUsd` jẹ́ èyí tí
schema gbà, ṣùgbọ́n a kò tíì fipá mú un ṣiṣẹ́ — ka a sí ìṣètò tí a fi pamọ́ fún ọjọ́ iwájú, kì í ṣe òpin ìnáwó tó ń ṣiṣẹ́. Bí a ṣe ń to àwọn ìpele, bí ìpín lílò ṣe ń fa ìparí ohun tó wà, àti bí a ṣe ń tún wọlé lẹ́yìn ìtúnṣètò, gbogbo wọn
ń ṣiṣẹ́ láìsí i.

## Àkópọ̀

`subscription` àti `thrifty` jẹ́ àwọn iye `AutoTier`, nítorí náà wọ́n lè darapọ̀ mọ́ gbogbo ẹ̀ka:
`auto/coding:thrifty`, `auto/reasoning:subscription`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ. Àwọn id alápẹrẹ méjèèjì náà
(`auto/subscription`, `auto/thrifty`) ni a polówó nínú `/v1/models` àti ojú ìdarí.

Kò sí èyíkéyìí nínú àwọn id náà tó jẹ́ ìpele tí a ń sanwó fún, nítorí náà `isPaidTierAutoId()` máa dá `false` padà fún àwọn méjèèjì, àti pé
`auto/subscription` yóò ṣì wà lẹ́yìn `hidePaidModels`.
