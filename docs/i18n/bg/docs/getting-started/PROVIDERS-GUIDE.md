## Какво представлява доставчикът?

Представете си доставчика като **мобилен оператор**. Точно както ви е необходим мобилен оператор, за да провеждате разговори, ви е необходим доставчик на изкуствен интелект, за да използвате AI модели. OmniRoute е като телефон, който работи с **всички оператори** — можете автоматично да превключвате между тях.

### Видове доставчици

| Вид               | Какво представлява              | Примери                           | Цена                        |
| ----------------- | ------------------------------- | --------------------------------- | --------------------------- |
| **Безплатен**     | Не се изисква плащане           | Kiro, OpenCode Free, Pollinations | $0                          |
| **API ключ**      | Необходим ви е API ключ         | OpenAI, Anthropic, Google         | Плащане според използването |
| **OAuth**         | Влизане с вашия акаунт          | Claude Code, GitHub Copilot       | Абонамент                   |
| **Уеб бисквитка** | Използва сесията на браузъра ви | ChatGPT Web (Codex), Gemini Web   | $0 (използва вашия акаунт)  |

### Доставчици с уеб бисквитки

Вижте **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** за общи инструкции за настройване, ограничения, отстраняване на неизправности и насоки за удостоверяване, специфични за отделните доставчици.

## Бърз старт: Свържете първия си доставчик

### Незадължително първоначално настройване на безплатни доставчици

При първото стартиране съветникът предлага отделна карта **Настройване на безплатни доставчици**. Той извлича текущия
списък с подходящи доставчици от регистъра на OmniRoute за доставчици без удостоверяване, след което ви позволява да прегледате и премахнете избора за всеки
доставчик, преди да потвърдите. OmniRoute показва предупреждението на доставчика и връзка към неговия сайт,
за да можете първо да прегледате условията, поверителността, наличността и ограниченията на заявките на третата страна.

Това действие не е задължително: завършването на съветника никога не създава неявно връзки с безплатни доставчици.
То създава само доставчици, които все още липсват, оставя съществуващите персонализирани връзки
непроменени и отчита поотделно създадените, вече конфигурираните и неуспешните доставчици. След частично успешно изпълнение можете
безопасно да опитате отново само за неуспешните.

### Вариант A: Безплатен доставчик (без кредитна карта)

1. Отворете таблото за управление на `http://localhost:20128`
2. Отидете на **Доставчици** → **Добавяне на доставчик**
3. Изберете един от следните безплатни доставчици:
   - **Kiro AI** — Безплатни модели Claude (не се изисква удостоверяване)
   - **OpenCode Free** — Безплатни GPT модели (не се изисква удостоверяване)
   - **Pollinations** — Безплатни GPT-5, Claude, Gemini (не е необходим ключ)
   - **LongCat** — 10 млн. безплатни токена (еднократно предоставяне, изисква акаунт + KYC)
   - **Cloudflare AI** — Над 50 модела, 10 хил. неврона/ден
   - **MLX Gemma 26B** — Локален модел за Apple Silicon (~38.5 токена/сек., ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — Локален модел за Apple Silicon (~9.1 токена/сек., ~13.1GB RAM)
4. Щракнете върху **Свързване**
5. Готово! Вече имате безплатен достъп до изкуствен интелект.

### Вариант B: Доставчик с API ключ (платен)

1. Получете API ключ от уебсайта на доставчика:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Отворете таблото за управление на `http://localhost:20128`
3. Отидете на **Доставчици** → **Добавяне на доставчик**
4. Изберете своя доставчик
5. Поставете своя API ключ
6. Щракнете върху **Свързване**
7. Готово! Вече имате достъп до моделите на този доставчик.

### Вариант C: OAuth доставчик (абонамент)

1. Отворете таблото за управление на `http://localhost:20128`
2. Отидете на **Доставчици** → **Добавяне на доставчик**
3. Изберете своя доставчик (напр. Claude Code, GitHub Copilot)
4. Щракнете върху **Свързване чрез OAuth**
5. Влезте със своя акаунт
6. Готово! Вече имате достъп до моделите, включени във вашия абонамент.

### Вариант D: Локални MLX модели (Apple Silicon)

За компютри Mac с Apple Silicon и обединена памет OmniRoute поддържа свързване към локални MLX модели, изпълнявани чрез `mlx-lm.server`, като обикновени локални доставчици, съвместими с OpenAI.

#### Предварителни изисквания

- **Mac с Apple Silicon** (M1/M2/M3/M4), като се препоръчва обединена памет от поне 24GB
- Мениджър на пакети **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Бърз старт

1. **Инсталирайте зависимостите**:

   ```bash
   # Инсталирайте uv, ако все още не е инсталиран
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Инсталирайте mlx-lm
   uv pip install mlx-lm
   ```

2. **Стартирайте ръчно MLX сървърите** (в отделни терминали):

   ```bash
   # Терминал 1: Gemma 4 26B A4B IT-QAT (порт 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Терминал 2: Qwen 3.8 27B MLX Mixed (порт 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Свържете се чрез таблото за управление на OmniRoute**:
   - Отидете на **Доставчици** → **Добавяне на доставчик**
   - Изберете **MLX Gemma 26B** или **MLX Qwen 3.8 27B**
   - Щракнете върху **Свързване** (не е необходим API ключ)

4. **Използвайте с OpenCode**:
   ```bash
   # Конфигурирайте OpenCode да използва OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Използвайте MLX модели
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Управление на паметта

**Важно**: При 24GB обединена памет само **един голям MLX модел може да работи едновременно**.

- Gemma 26B: ~15.9GB пикова памет
- Qwen 3.8 27B: ~13.1GB пикова памет

Трябва да управлявате това ръчно:

- Изпълнявайте само един MLX сървър в даден момент или
- Изпълнявайте двата на отделни машини, или
- Спрете единия, преди да стартирате другия

OmniRoute не управлява автоматично процесите на MLX сървъра — той само насочва заявките към конфигурираните от вас крайни точки, съвместими с OpenAI.

#### Поддръжка за извикване на инструменти

И двата модела поддържат извикване на инструменти, съвместимо с OpenAI. Тествайте с:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Отстраняване на неизправности

| Проблем                                | Решение                                                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Сървърът не се стартира                | Проверете `uv run mlx_lm.server --help` и идентификаторите на моделите                                             |
| Недостатъчно памет                     | Уверете се, че работи само един модел; затворете другите приложения; проверете Activity Monitor                    |
| Връзката е отказана                    | Проверете дали сървърът работи на правилния порт (11435/11436)                                                     |
| Бавни отговори                         | При първата заявка моделът се зарежда в паметта (~30-60s); следващите заявки са бързи                              |
| Извикването на инструменти е неуспешно | Уверете се, че моделът поддържа инструменти; проверете регистрационните файлове на OmniRoute за грешки при превода |

## Как да свържете доставчик (стъпка по стъпка)

### Стъпка 1: Отворете таблото за управление

Отворете `http://localhost:20128` във вашия браузър.

### Стъпка 2: Отидете на „Доставчици“

Щракнете върху **Доставчици** в страничната лента.

### Стъпка 3: Щракнете върху „Добавяне на доставчик“

Щракнете върху бутона **+ Добавяне на доставчик**.

### Стъпка 4: Изберете вашия доставчик

Прегледайте списъка или потърсете вашия доставчик. Щракнете върху него.

### Стъпка 5: Въведете идентификационните данни

- **Безплатни доставчици**: Не са необходими идентификационни данни — просто щракнете върху **Свързване**
- **Доставчици с API ключ**: Поставете вашия API ключ
- **Доставчици с OAuth**: Щракнете върху **Свързване с OAuth** и влезте в профила си

### Стъпка 6: Тествайте връзката

Щракнете върху **Тестване на връзката**, за да проверите дали работи.

### Стъпка 7: Готово!

Вашият доставчик вече е свързан. Можете да го използвате с `model: "auto"` или да посочите доставчика директно.

## Използване на няколко доставчика

OmniRoute работи най-добре с **няколко доставчика**. Това ви осигурява:

- **Автоматично превключване към резервен доставчик** — Ако един доставчик не работи, OmniRoute опитва следващия
- **Оптимизиране на разходите** — OmniRoute избира най-евтиния доставчик за всяка заявка
- **Оптимизиране на скоростта** — OmniRoute избира най-бързия доставчик за всяка заявка
- **Оптимизиране на качеството** — OmniRoute избира най-добрия доставчик за всяка задача

### Препоръчителна конфигурация

Свържете поне **3 доставчика** за най-добро изживяване:

1. **Един безплатен доставчик** (Kiro, OpenCode Free или Pollinations) — Винаги наличен
2. **Един бърз доставчик** (Groq, Cerebras) — За бързи отговори
3. **Един висококачествен доставчик** (OpenAI, Anthropic, Google) — За сложни задачи

След това използвайте `model: "auto"` и OmniRoute автоматично ще избира най-добрия за всяка заявка.

## Често задавани въпроси

### „Трябва ли да плащам, за да използвам OmniRoute?“

**Не!** OmniRoute е безплатен и с отворен код. Можете да използвате безплатни доставчици (Kiro, OpenCode Free, Pollinations), без да плащате нищо. Плащате само ако изберете платени доставчици.

### „С кой доставчик да започна?“

Започнете с **Kiro AI** — той е безплатен, не изисква API ключ и ви предоставя достъп до моделите на Claude. След това добавете още доставчици според нуждите си.

### „Мога ли да използвам няколко доставчика едновременно?“

**Да!** Това е основната идея на OmniRoute. Свържете няколко доставчика и използвайте `model: "auto"`, за да позволите на OmniRoute да избере най-добрия за всяка заявка.

### „Какво става, ако даден доставчик спре да работи?“

OmniRoute автоматично пропуска неуспешните доставчици и опитва следващия. Не е необходимо да правите нищо.

### „Как да прекъсна връзката с доставчик?“

Отидете на Доставчици → щракнете върху доставчика → щракнете върху **Прекъсване на връзката**.

### „Мога ли да използвам съществуващите си API ключове?“

**Да!** Ако вече имате API ключове за OpenAI, Anthropic, Google и др., можете да ги използвате в OmniRoute. Просто ги поставете, когато свързвате доставчика.
