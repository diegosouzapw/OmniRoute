## Стъпка 1: Инсталирайте OmniRoute

Изберете предпочитания от вас метод:

### Вариант A: npm (препоръчително)

```bash
npm install -g omniroute
```

### Вариант B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` е най-високата **публикувана** стабилна версия според SemVer. Тя **не** следва git `main`. За GitOps фиксирайте `diegosouzapw/omniroute:X.Y.Z`. Вижте [Тагове на образите/канали за издания](../guides/DOCKER_GUIDE.md#release-channels).

### Вариант C: От изходния код

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Стъпка 2: Стартирайте OmniRoute

```bash
omniroute
```

OmniRoute се стартира на `http://localhost:20128`. Таблото за управление се отваря автоматично.

---

## Стъпка 3: Свържете безплатен доставчик

Можете да използвате OmniRoute **напълно безплатно**, като свържете безплатен доставчик.

### Вариант A: Kiro (безплатен Claude — без кредитна карта)

1. Отворете таблото за управление на `http://localhost:20128`
2. Отидете на **Доставчици** → **Добавяне на доставчик**
3. Изберете **Kiro AI**
4. Щракнете върху **Свързване** (не е необходим API ключ!)
5. Готово! Вече имате безплатен достъп до моделите на Claude.

### Вариант B: OpenCode Free (без удостоверяване)

1. Отворете таблото за управление на `http://localhost:20128`
2. Отидете на **Доставчици** → **Добавяне на доставчик**
3. Изберете **OpenCode Free**
4. Щракнете върху **Свързване** (не е необходим API ключ!)
5. Готово! Вече имате безплатен достъп до множество модели.

### Вариант C: Pollinations (не е необходим ключ)

1. Отворете таблото за управление на `http://localhost:20128`
2. Отидете на **Доставчици** → **Добавяне на доставчик**
3. Изберете **Pollinations**
4. Щракнете върху **Свързване** (не е необходим API ключ!)
5. Готово! Вече имате безплатен достъп до GPT-5, Claude, Gemini и други.

## Стъпка 4: Проверете дали работи

От [API ключове](http://localhost:20128/dashboard/api-manager) създайте нов ключ. Запазете го, тъй като няма да бъде показан отново. Имайте предвид, че този ключ служи за достъп на инструментите до OmniRoute, а не за достъп до доставчиците нагоре по веригата.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Трябва да видите списък със свързаните модели.

## Стъпка 5: Насочете вашата IDE или CLI към OmniRoute

Във вашата IDE или CLI задайте:

```
Основен URL адрес: http://localhost:20128/v1
API ключ:          [копирайте от Табло за управление → Крайни точки]
Модел:             auto
```

Това е всичко! Вашата IDE вече използва OmniRoute с автоматичен избор на доставчик.

### Пример за IDE: VSCode/Continue.dev

1. Във VSCode инсталирайте разширението [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Актуализирайте вашия `~/.continue/config.yaml`, като добавите следните редове:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. В панела за чат на Continue.dev изберете `OmniRoute - Auto` и ще изпращате заявки към OmniRoute.
4. (По избор) Упражнение за читателя — накарайте вашата IDE да актуализира `config.yaml` с всички останали предварително създадени конфигурации 😊

### Пример за CLI: Codex CLI

1. В операционната си система задайте променливата на средата постоянно.
   За macOS/Linux (добавете към вашия `~/.bashrc` или `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

За Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Сега нека стартираме Codex, но конфигуриран за OmniRoute. Изпълнете:

```
omniroute launch-codex --model auto
```

Можете да направите това ръчно чрез `codex` и параметри от командния ред, за да посочите крайна точка и API ключ, но с горната команда OmniRoute се грижи за всичко вместо вас.

Същото стартиране с една команда работи и за други CLI инструменти чрез универсалната програма за стартиране — `omniroute run <target>` поддържа `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` и `gemini` (вижте [CLI интеграции](../guides/CLI-INTEGRATIONS.md)).

3. Сега CLI трябва да изпраща заявки към OmniRoute.

### Потвърдете, че инструментът ви маршрутизира към OmniRoute

Можете да видите подробностите за заявката, като щракнете върху [Наблюдение/Регистри](http://localhost:20128/dashboard/logs) в лявата странична лента. Преминаването през отделните записи показва повече подробности. Между другото, можете да видите каква информация се изпраща от предпочитаната от вас среда. Това е полезно за обучение и отстраняване на грешки.

## Често задавани въпроси

### „Необходим ли ми е API ключ?“

**Не!** Можете да използвате безплатни доставчици (Kiro, OpenCode Free, Pollinations) без никакъв API ключ. Просто ги свържете в таблото за управление.

### „Какво представлява `auto`?“

`auto` указва на OmniRoute автоматично да избира най-добрия доставчик за всяка заявка. Вземат се предвид скоростта, цената, качеството и наличността. Вижте [Ръководството за Auto-Combo](./AUTO-COMBO-GUIDE.md) за подробности.

### „Колко струва?“

Самият OmniRoute е **безплатен и с отворен код**. Плащате само за доставчиците, които използвате. Много доставчици имат безплатни планове — вижте [Ръководството за безплатните планове](./FREE-TIERS-GUIDE.md).

### „Мога ли да го използвам с Claude Code / Cursor / Copilot?“

**Да!** OmniRoute работи с всеки инструмент, който поддържа формата на OpenAI. Просто задайте основния URL адрес на `http://localhost:20128/v1`. Вижте [Ръководството за CLI инструменти](../reference/CLI-TOOLS.md) за конкретни инструкции за настройка.

### „Какво става, ако даден доставчик спре да работи?“

OmniRoute автоматично пропуска неуспешните доставчици и опитва следващия. Не е необходимо да правите нищо. Вижте [Ръководството за Auto-Combo](./AUTO-COMBO-GUIDE.md) за подробности.
