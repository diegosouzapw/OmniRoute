Caveman компресията може да зарежда специфични за езика пакети с правила в допълнение към вградените правила за английски език.
Това запазва стабилността на основния механизъм, като същевременно позволява пакетите за португалски, испански, немски, френски, италиански, японски и
бъдещи езици да се развиват независимо.

## Местоположение

Езиковите пакети се намират в:

```txt
open-sse/services/compression/rules/<language>/
```

Текущо предоставяни пакети (проверени спрямо съдържанието на директорията `rules/`):

| Език                   | Директория     | Налични категории правила                           |
| ---------------------- | -------------- | --------------------------------------------------- |
| Английски              | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Испански               | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Португалски (Бразилия) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Индонезийски           | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Италиански             | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Немски                 | `rules/de/`    | `context`, `filler`, `structural`                   |
| Френски                | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Японски                | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Бележка за съответствието:** Пакетите `en`, `es`, `pt-BR`, `id` и `it` разполагат с пълния набор от 5 категории; `de`, `fr` и `ja` се предоставят с 3 категории. При липсващите категории `dedup` и `ultra` без уведомяване се използват резервно вградените правила за английски език. Приносите за добавяне на `dedup.json` и `ultra.json` към по-малките пакети са добре дошли.
>
> Пакетът `pt-BR` е базиран на **[Troglodita](https://github.com/leninejunior/troglodita)** от Lenine Júnior — система за компресия, създадена от нулата за граматиката на бразилския португалски език (намаляване на плеоназмите, премахване на паразитни думи в PT-BR, технически съкращения за бразилската общност от разработчици).
>
> Каноничният списък с категории и схемата за всяка категория се намират в [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema, чернова 2020-12).

## Откриване на езика

`languageDetector.ts` използва леки евристични методи, за да определи езика от текста на подканата. Конфигурираният език по подразбиране продължава да се зачита, а откриването може да бъде деактивирано чрез конфигурацията, когато е необходим прецизен контрол.

Резултатът от откриването се използва единствено за избор на пакети с правила. Той не променя маршрутизирането към доставчика, избора на локал или езика на потребителския интерфейс.

## Структура на конфигурацията

Настройките за компресия могат да включват:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` управлява настройките по подразбиране за таблото и предварителния преглед. `cavemanConfig` е конфигурацията на механизма по време на изпълнение, използвана, когато Caveman компресира текста на съобщенията.

## Добавяне на езиков пакет

1. Създайте `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Използвайте формата за правила Caveman от `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Поддържайте замените консервативни и избягвайте промени в код, идентификатори, URL адреси или JSON.
4. Добавете или актуализирайте тестове за избора на език и поведението при замяна.
5. Предоставете нови етикети за таблото за управление/i18n, ако езикът присъства в селекторите на потребителския интерфейс.

## API

Наличните пакети могат да бъдат заявени чрез:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Крайната точка за предварителен преглед приема заместващи настройки за езиковата конфигурация:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Всичките 6 езикови пакета получиха клауза `SHARED_BOUNDARIES` във v3.8.0, която се прилага при всяко
ниво на интензивност на Caveman (LITE, FULL, ULTRA). Тя указва на системата да запазва дословно тези шаблони
независимо от премахването на заобикалящите ги излишни изрази:

| Тип на шаблона                           | Пример                                 |
| ---------------------------------------- | -------------------------------------- |
| Оградени блокове с код                   | ` ```python\n...\n``` `                |
| Вграден код                              | `` `my_var` ``                         |
| URL адреси                               | `https://example.com/path`             |
| Файлови пътища (абсолютни + относителни) | `/etc/hosts`, `./src/index.ts`         |
| Заглавни редове за грешки                | `Error:`, `TypeError:`, `SyntaxError:` |
| Редове от трасировка на стека            | `  at functionName (file.ts:12:3)`     |

Тези шаблони се задават в `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (преди `[]`). Константата
се намира в `open-sse/services/compression/types.ts`.

### Защо това е важно

Без SHARED_BOUNDARIES агресивните режими на Caveman биха могли да премахнат съдържание, което изглежда като повтарящ се
текст, но всъщност е фрагмент от код, файлов път или стек на грешка. SHARED_BOUNDARIES действа като
независима от езика защитна мрежа, прилагана преди правилата за премахване на излишни изрази.

### Персонализиране на preservePatterns

Допълнителни шаблони могат да бъдат добавени по време на изпълнение чрез настройките за компресиране:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Персонализираните шаблони разширяват (а не заменят) 6-те стойности по подразбиране.

## Оперативни бележки

- Вградените правила за английски език остават резервният вариант, когато липсва езиков пакет.
- Невалидните вградени JSON пакети не преминават проверката, така че ресурсите на изданието да не се влошават без предупреждение.
- Пакетите с правила съдържат само данни и не трябва да импортират код или да изпълняват произволна логика.
- Аналитичният слой за компресиране записва избраните режим и система, а не пълния текст на подканата.
