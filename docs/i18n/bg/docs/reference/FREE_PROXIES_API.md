OmniRoute предоставя подбран набор от безплатни прокси сървъри в таблицата `free_proxies`,
синхронизиран с външни доставчици (1proxy, proxifly, iplocate, webshare). Таблото
ги показва в **Настройки → Безплатни прокси сървъри**. Този документ
описва филтрирането, сортирането, броенето и отчитането на грешки при синхронизация
от страна на сървъра, предоставяни от маршрута за списъка.

## Маршрут за списъка — `GET /api/settings/free-proxies`

Връща филтриран, сортиран и странициран набор от записи заедно с общия им брой. Филтрирането и
броенето се извършват в SQL, така че потребителският интерфейс да може да показва действителния общ брой (напр. `Общо: 0`),
без да зарежда всеки ред в паметта.

### Параметри на заявката

| Параметър         | Тип                                | По подразбиране | Значение                                                                                                                                        |
| ----------------- | ---------------------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | низ                                | `""`            | `LIKE`, чувствителен към регистъра, върху колоната за хост (и източник).                                                                        |
| `protocol`        | низ                                | `""`            | Филтър по `type`: `http` / `https` / `socks4` / `socks5`. Празна стойност = всички.                                                             |
| `country`         | низ                                | `""`            | Филтър по `countryCode` (ISO-2). Празна стойност = всички.                                                                                      |
| `minQuality`      | число                              | `0`             | Само редове с `qualityScore >= minQuality`. `0` = без минимален праг.                                                                           |
| `disabledSources` | низ                                | `""`            | Разделени със запетаи идентификатори на източници за изключване (напр. `proxifly,webshare`).                                                    |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`       | `quality` = низходящо по оценка; `latency` = възходящо по латентност (нулевите стойности са последни); `recent` = низходящо по `lastValidated`. |
| `offset`          | число                              | `0`             | Начална позиция за страницирането.                                                                                                              |
| `limit`           | число                              | `50`            | Размер на страницата (ограничен от страна на сървъра).                                                                                          |

### Отговор

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 от сървъра нагоре по веригата"],
    "webshare": ["изтече времето за изчакване на мрежата"]
  }
}
```

`total` отразява общия брой филтрирани записи **преди** страницирането, така че потребителският интерфейс да може да визуализира
`Общо: N` и `hasMore` независимо. `syncErrors` използва идентификатора на източника като ключ и
се попълва само за източници, чиято последна синхронизация е била неуспешна — резултатът `Общо: 0`
никога не остава без пояснение.

## Добавяне към набора — `POST /api/settings/free-proxies/[id]/add-to-pool`

Добавя безплатен прокси сървър към управлявания набор `proxy_registry`. Първо валидира
външния източник; при успех връща идентификатора на новия прокси сървър в набора и измерената латентност.

## Синхронизация — `POST /api/settings/free-proxies/sync`

Извлича отново всички активирани източници (или подмножеството в `{ "sources": [...] }`). Всеки
източник се синхронизира независимо; неуспешният източник се записва в `syncErrors`, а
останалите продължават до завършване, така че частичните синхронизации никога да не изтриват предишни валидни данни.

## Статистика — `GET /api/settings/free-proxies/stats`

Връща обобщените стойности `total / inPool / avgQuality / bySource / lastSyncAt`
без данните за редовете — използва се от уиджетите в заглавната част на таблото.
