OmniRoute организира 352-та поддържани доставчика в 3 икономически нива. Всяка
заявка преминава през тях последователно, докато някой не върне успешен резултат —
получавате най-евтиния работещ отговор, без изобщо да пишете код за резервни варианти.

## Ниво 1 — Абонамент

**Доставчици, за които вече плащате.** OmniRoute използва цялата налична квота, преди
тя да изтече.

| Доставчик                           | Защо е в Ниво 1                                           |
| ----------------------------------- | --------------------------------------------------------- |
| Claude Code OAuth                   | Anthropic Pro/Team — фиксирана цена, често не се използва |
| OpenAI Codex (абонамент за ChatGPT) | Plus/Team включва квота за Codex                          |
| GitHub Copilot                      | На потребител — квотата се нулира ежемесечно              |
| Cursor IDE                          | Квота от план Pro                                         |
| Antigravity / Devin Desktop         | Вградени квоти                                            |

**Стратегия**: насочвайте първо тук всяка заявка, която съответства на силните
страни на модела. Механизмът за проследяване на квотите следи наближаващите нулирания, а
комбинираната стратегия `reset-aware` задава приоритетите по съответния начин. За да насочвате
първо към Ниво 1 и да преминавате към платените нива само когато квотата се изчерпи,
използвайте идентификатора `auto/thrifty` — или `auto/subscription`, за да останете в рамките
на включения в плана капацитет и в противен случай заявката да завърши с грешка. Вижте
[Маршрутизиране с приоритет на абонамента](../routing/SUBSCRIPTION_LADDER.md).

## Ниво 2 — Евтини

**Доставчици с таксуване на токен под $1/1M токена.** Запазени за задачи с голям обем
или за случаите, когато квотите от Ниво 1 достигнат лимитите си.

| Доставчик                        | Цена (вход/изход)   | Силни страни           |
| -------------------------------- | ------------------- | ---------------------- |
| DeepSeek V4 Pro                  | $0.27 / $1.10 за 1M | Код, разсъждения       |
| GLM-4.5                          | $0.60 / $2.20 за 1M | Дълъг контекст         |
| MiniMax M1                       | $0.20 / $1.10 за 1M | Скорост                |
| Qwen Coder                       | $0.30 / $1.20 за 1M | Код                    |
| OpenRouter (оптимизиран по цена) | варира              | 100+ модела, динамичен |

**Стратегия**: комбинацията `cost-optimized` избира модела с най-ниска цена на токен, който
отговаря на филтъра за необходимите възможности на задачата (визуално разпознаване, JSON режим, инструменти, максимален контекст).

## Ниво 3 — Безплатни

**Доставчици с нулева цена** — безплатни планове, кредитни програми, дневни OAuth квоти.

| Доставчик        | Безплатна квота / кредити                                 |
| ---------------- | --------------------------------------------------------- |
| Kiro AI          | Безплатно ниво на Claude (щедро добросъвестно използване) |
| OpenCode Free    | Без удостоверяване, щедри ограничения на честотата        |
| Qoder            | Безплатен OAuth                                           |
| Google Vertex AI | $300 кредити за нов акаунт                                |
| Amazon Q         | Безплатно ниво за потребители на AWS                      |
| Pollinations     | Отворен публичен API                                      |
| Cloudflare AI    | Безплатно ниво на Workers AI                              |

**Стратегия**: комбинацията `auto` с бюджетен лимит насочва заявките тук, когато Нива 1 и 2 са
неуспешни или когато е зададено `useFreeOnly=true`. Безплатните доставчици често имат по-строги
ограничения на честотата — прекъсвачът на веригата ги възстановява след изчакване.

## Конфигуриране на нивата

Табло → **Нива** → задайте своите доставчици. Стойностите по подразбиране (от `tierDefaults.json`) са
подходящи; редактирайте ги, когато имате конкретни абонаменти, на които да дадете приоритет, или доставчици, които да изключите.

16-факторното оценяване на Auto-Combo също взема предвид нивото. Вижте
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Телеметрия

Табло → **Използване** показва изразходваните токени по нива за всеки ден. Използвайте това, за да:

- Потвърдите, че Ниво 1 се използва пълноценно (в противен случай губите стойност от абонамента)
- Установите кои модели от Ниво 2 се избират най-често (сведете ги до 1–2)
- Проверите дали Ниво 3 спестява средства при тестови и проучвателни натоварвания

## Често срещани модели

### Изцяло безплатно натоварване

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Насочва с висок приоритет към Ниво 3; използва Ниво 2 само ако Ниво 3 не е налично.

### Първо абонаментът, с евтин резервен вариант

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Изрично подреден списък, съответстващ на Ниво 1 → Ниво 2 → Ниво 3.
