> **TL;DR**: Asenna → Yhdistä maksuton palveluntarjoaja → Ohjaa IDE käyttämään OmniRoutea. Valmista.

---

## Vaihe 1: Asenna OmniRoute

Valitse haluamasi asennustapa:

### Vaihtoehto A: npm (suositeltu)

```bash
npm install -g omniroute
```

### Vaihtoehto B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` on uusin **julkaistu** vakaa SemVer-versio. Se **ei** seuraa git-haaraa `main`. Käytä GitOpsissa kiinteää tunnistetta `diegosouzapw/omniroute:X.Y.Z`. Katso [näköistiedostojen tunnisteet ja julkaisukanavat](../guides/DOCKER_GUIDE.md#release-channels).

### Vaihtoehto C: Lähdekoodista

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Vaihe 2: Käynnistä OmniRoute

```bash
omniroute
```

OmniRoute käynnistyy osoitteessa `http://localhost:20128`. Hallintapaneeli avautuu automaattisesti.

---

## Vaihe 3: Yhdistä maksuton palveluntarjoaja

Voit käyttää OmniRoutea **täysin maksutta** yhdistämällä maksuttoman palveluntarjoajan.

### Vaihtoehto A: Kiro (maksuton Claude — ei luottokorttia)

1. Avaa hallintapaneeli osoitteessa `http://localhost:20128`
2. Siirry kohtaan **Providers** → **Add Provider**
3. Valitse **Kiro AI**
4. Napsauta **Connect** (API-avainta ei tarvita!)
5. Valmista! Voit nyt käyttää Claude-malleja maksutta.

### Vaihtoehto B: OpenCode Free (ei tunnistautumista)

1. Avaa hallintapaneeli osoitteessa `http://localhost:20128`
2. Siirry kohtaan **Providers** → **Add Provider**
3. Valitse **OpenCode Free**
4. Napsauta **Connect** (API-avainta ei tarvita!)
5. Valmista! Voit nyt käyttää useita malleja maksutta.

### Vaihtoehto C: Pollinations (avainta ei tarvita)

1. Avaa hallintapaneeli osoitteessa `http://localhost:20128`
2. Siirry kohtaan **Providers** → **Add Provider**
3. Valitse **Pollinations**
4. Napsauta **Connect** (API-avainta ei tarvita!)
5. Valmista! Voit nyt käyttää maksutta GPT-5:tä, Claudea, Geminiä ja muita malleja.

---

## Vaihe 4: Varmista toiminta

Luo uusi avain kohdassa [API Keys](http://localhost:20128/dashboard/api-manager). Tallenna avain, sillä sitä ei näytetä uudelleen. Huomaa, että työkalut käyttävät tätä avainta OmniRouten käyttämiseen, eivät ylävirran palveluntarjoajien käyttämiseen.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Yhdistettyjen malliesi pitäisi näkyä luettelossa.

## Vaihe 5: Ohjaa IDE tai CLI käyttämään OmniRoutea

Määritä IDE- tai CLI-työkalussasi:

```
Base URL: http://localhost:20128/v1
API Key:  [kopioi kohdasta Dashboard → Endpoints]
Model:    auto
```

Siinä kaikki! IDE käyttää nyt OmniRoutea ja valitsee palveluntarjoajan automaattisesti.

### IDE-esimerkki: VSCode/Continue.dev

1. Asenna [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue)-laajennus VSCodeen.
2. Lisää seuraavat rivit tiedostoon `~/.continue/config.yaml`:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Valitse Continue.dev-keskustelupaneelissa `OmniRoute - Auto`, minkä jälkeen pyyntösi lähetetään OmniRoutelle.
4. (Valinnainen) Harjoitus lukijalle: pyydä IDEä päivittämään `config.yaml` kaikilla muilla valmiiksi laadituilla määrityksillä 😊

### CLI-esimerkki: Codex CLI

1. Määritä ympäristömuuttuja pysyvästi käyttöjärjestelmässäsi.
   macOS/Linux (lisää tiedostoon `~/.bashrc` tai `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Käynnistetään seuraavaksi Codex OmniRoutelle määritettynä. Suorita:

```
omniroute launch-codex --model auto
```

Voit tehdä tämän manuaalisesti käyttämällä `codex`-komentoa ja komentoriviparametreja päätepisteen sekä API-avaimen määrittämiseen, mutta yllä olevalla komennolla OmniRoute hoitaa kaiken puolestasi.

Sama yhden komennon käynnistys toimii myös muissa CLI-työkaluissa yleisen käynnistimen avulla — `omniroute run <target>` tukee kohteita `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` ja `gemini` (katso [CLI-integraatiot](../guides/CLI-INTEGRATIONS.md)).

3. CLI:n pitäisi nyt lähettää pyynnöt OmniRoutelle.

### Varmista, että työkalusi reitittää OmniRoutelle

Näet pyynnön tiedot napsauttamalla vasemmasta sivupalkista kohtaa [Monitoring/Logs](http://localhost:20128/dashboard/logs). Napsauttamalla kohteita saat näkyviin lisätietoja. Samalla voit nähdä, mitä tietoja käyttämäsi työkalu lähettää eteenpäin. Tästä on hyötyä oppimisen ja virheenkorjauksen kannalta.

## Usein kysytyt kysymykset

### "Tarvitsenko API-avaimen?"

**Et!** Voit käyttää maksuttomia palveluntarjoajia (Kiro, OpenCode Free ja Pollinations) ilman API-avainta. Yhdistä ne vain hallintapaneelissa.

### "Mikä `auto` on?"

`auto` pyytää OmniRoutea valitsemaan automaattisesti parhaan palveluntarjoajan kullekin pyynnölle. Valinnassa huomioidaan nopeus, kustannukset, laatu ja saatavuus. Katso lisätietoja [Auto-Combo-oppaasta](./AUTO-COMBO-GUIDE.md).

### "Kuinka paljon se maksaa?"

OmniRoute itsessään on **maksuton ja avoimen lähdekoodin ohjelmisto**. Maksat vain käyttämistäsi palveluntarjoajista. Monilla palveluntarjoajilla on maksuttomia käyttöpaketteja — katso [maksuttomien käyttöpakettien opas](./FREE-TIERS-GUIDE.md).

### "Voinko käyttää sitä Claude Coden / Cursorin / Copilotin kanssa?"

**Kyllä!** OmniRoute toimii kaikkien OpenAI-muotoa tukevien työkalujen kanssa. Aseta perus-URL-osoitteeksi `http://localhost:20128/v1`. Katso työkalukohtaiset määritysohjeet [CLI-työkalujen oppaasta](../reference/CLI-TOOLS.md).

### "Entä jos palveluntarjoaja lakkaa toimimasta?"

OmniRoute ohittaa epäonnistuneet palveluntarjoajat automaattisesti ja kokeilee seuraavaa. Sinun ei tarvitse tehdä mitään. Katso lisätietoja [Auto-Combo-oppaasta](./AUTO-COMBO-GUIDE.md).
