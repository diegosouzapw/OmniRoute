## Mikä on palveluntarjoaja?

Ajattele palveluntarjoajaa **puhelinoperaattorina**. Aivan kuten tarvitset puhelinoperaattorin puheluiden soittamiseen, tarvitset tekoälypalveluntarjoajan tekoälymallien käyttämiseen. OmniRoute on kuin puhelin, joka toimii **kaikkien operaattorien** kanssa — voit vaihtaa niiden välillä automaattisesti.

### Palveluntarjoajatyypit

| Tyyppi           | Mitä se tarkoittaa        | Esimerkkejä                       | Hinta                |
| ---------------- | ------------------------- | --------------------------------- | -------------------- |
| **Ilmainen**     | Maksua ei vaadita         | Kiro, OpenCode Free, Pollinations | $0                   |
| **API-avain**    | Tarvitset API-avaimen     | OpenAI, Anthropic, Google         | Käytön mukaan        |
| **OAuth**        | Kirjaudu sisään tililläsi | Claude Code, GitHub Copilot       | Tilaus               |
| **Verkkoeväste** | Käyttää selainistuntoasi  | ChatGPT Web (Codex), Gemini Web   | $0 (käyttää tiliäsi) |

### Verkkoevästeitä käyttävät palveluntarjoajat

Katso yleiset käyttöönotto-ohjeet, rajoitukset, vianmääritys ja palveluntarjoajakohtaiset todennusohjeet tiedostosta **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**.

## Pika-aloitus: yhdistä ensimmäinen palveluntarjoajasi

### Valinnainen ilmaisten palveluntarjoajien määritys ensimmäisellä käynnistyskerralla

Ensimmäisen käynnistyskerran ohjattu toiminto sisältää erillisen **Määritä ilmaiset palveluntarjoajat** -kortin. Se muodostaa nykyisen
kelvollisten palveluntarjoajien luettelon OmniRouten todennusta vaatimattomien palveluntarjoajien rekisteristä ja antaa sitten tarkistaa jokaisen
palveluntarjoajan sekä poistaa niiden valintoja ennen vahvistamista. OmniRoute näyttää palveluntarjoajan varoituksen ja linkin sen sivustolle,
jotta voit ensin tarkistaa kolmannen osapuolen ehdot, tietosuojan, saatavuuden ja käyttörajoitukset.

Tämä toiminto on valinnainen: ohjatun toiminnon viimeistely ei koskaan luo ilmaisten palveluntarjoajien yhteyksiä huomaamatta.
Se luo vain vielä puuttuvat palveluntarjoajat, jättää olemassa olevat mukautetut yhteydet
ennalleen ja ilmoittaa erikseen luodut, jo määritetyt ja epäonnistuneet palveluntarjoajat. Osittaisen tuloksen jälkeen voit
turvallisesti yrittää uudelleen vain epäonnistuneita palveluntarjoajia.

### Vaihtoehto A: ilmainen palveluntarjoaja (ei luottokorttia)

1. Avaa hallintapaneeli osoitteessa `http://localhost:20128`
2. Siirry kohtaan **Palveluntarjoajat** → **Lisää palveluntarjoaja**
3. Valitse jokin näistä ilmaisista palveluntarjoajista:
   - **Kiro AI** — Ilmaisia Claude-malleja (todennusta ei tarvita)
   - **OpenCode Free** — Ilmaisia GPT-malleja (todennusta ei tarvita)
   - **Pollinations** — Ilmaiset GPT-5-, Claude- ja Gemini-mallit (avainta ei tarvita)
   - **LongCat** — 10M ilmaista tokenia (kertaluonteinen etu, vaatii tilin ja KYC-tunnistautumisen)
   - **Cloudflare AI** — Yli 50 mallia, 10K neuronia päivässä
   - **MLX Gemma 26B** — Paikallinen Apple Silicon -malli (~38.5 tokenia/s, ~15.9GB RAM-muistia)
   - **MLX Qwen 3.8 27B** — Paikallinen Apple Silicon -malli (~9.1 tokenia/s, ~13.1GB RAM-muistia)
4. Napsauta **Yhdistä**
5. Valmista! Käytössäsi on nyt ilmainen tekoäly-yhteys.

### Vaihtoehto B: API-avainpalveluntarjoaja (maksullinen)

1. Hanki API-avain palveluntarjoajan verkkosivustolta:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Avaa hallintapaneeli osoitteessa `http://localhost:20128`
3. Siirry kohtaan **Palveluntarjoajat** → **Lisää palveluntarjoaja**
4. Valitse palveluntarjoajasi
5. Liitä API-avaimesi
6. Napsauta **Yhdistä**
7. Valmista! Käytössäsi ovat nyt kyseisen palveluntarjoajan mallit.

### Vaihtoehto C: OAuth-palveluntarjoaja (tilaus)

1. Avaa hallintapaneeli osoitteessa `http://localhost:20128`
2. Siirry kohtaan **Palveluntarjoajat** → **Lisää palveluntarjoaja**
3. Valitse palveluntarjoajasi (esim. Claude Code tai GitHub Copilot)
4. Napsauta **Yhdistä OAuthilla**
5. Kirjaudu sisään tililläsi
6. Valmista! Käytössäsi ovat nyt tilaukseesi sisältyvät mallit.

### Vaihtoehto D: paikalliset MLX-mallit (Apple Silicon)

OmniRoute tukee yhtenäisellä muistilla varustetuissa Apple Silicon Mac -tietokoneissa `mlx-lm.server`-palvelimen kautta suoritettavien paikallisten MLX-mallien yhdistämistä tavallisina paikallisina OpenAI-yhteensopivina palveluntarjoajina.

#### Esivaatimukset

- **Apple Silicon Mac** (M1/M2/M3/M4), jolle suositellaan vähintään 24GB yhtenäistä muistia
- **uv**-paketinhallinta: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Pika-aloitus

1. **Asenna riippuvuudet**:

   ```bash
   # Asenna uv, jos sitä ei ole jo asennettu
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Asenna mlx-lm
   uv pip install mlx-lm
   ```

2. **Käynnistä MLX-palvelimet manuaalisesti** (erillisissä päätteissä):

   ```bash
   # Pääte 1: Gemma 4 26B A4B IT-QAT (portti 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Pääte 2: Qwen 3.8 27B MLX Mixed (portti 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Yhdistä OmniRouten hallintapaneelissa**:
   - Siirry kohtaan **Palveluntarjoajat** → **Lisää palveluntarjoaja**
   - Valitse **MLX Gemma 26B** tai **MLX Qwen 3.8 27B**
   - Napsauta **Yhdistä** (API-avainta ei tarvita)

4. **Käytä OpenCoden kanssa**:
   ```bash
   # Määritä OpenCode käyttämään OmniRoutea
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <oma-omniroute-api-avaimesi>

   # Käytä MLX-malleja
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Muistinhallinta

**Tärkeää**: Jos yhtenäistä muistia on 24GB, vain **yhtä suurta MLX-mallia voidaan suorittaa kerrallaan**.

- Gemma 26B: ~15.9GB muistin huippukäyttö
- Qwen 3.8 27B: ~13.1GB muistin huippukäyttö

Sinun on hallittava tätä manuaalisesti:

- Suorita vain yhtä MLX-palvelinta kerrallaan, tai
- Suorita palvelimia eri tietokoneissa, tai
- Pysäytä toinen ennen toisen käynnistämistä

OmniRoute ei hallitse MLX-palvelinprosesseja automaattisesti — se vain reitittää pyynnöt määrittämiisi OpenAI-yhteensopiviin päätepisteisiin.

#### Työkalukutsujen tuki

Molemmat mallit tukevat OpenAI-yhteensopivia työkalukutsuja. Testaa näin:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "Paljonko on 2+2? Käytä laskintyökalua."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Laske", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Vianmääritys

| Ongelma                  | Ratkaisu                                                                                             |
| ------------------------ | ---------------------------------------------------------------------------------------------------- |
| Palvelin ei käynnisty    | Tarkista `uv run mlx_lm.server --help` ja varmista mallitunnukset                                    |
| Muisti loppuu            | Varmista, että vain yksi malli on käynnissä; sulje muut sovellukset; tarkista Aktiivisuuden seuranta |
| Yhteys evätty            | Varmista, että palvelin on käynnissä oikeassa portissa (11435/11436)                                 |
| Hitaat vastaukset        | Ensimmäinen pyyntö lataa mallin muistiin (~30–60 s); seuraavat pyynnöt ovat nopeita                  |
| Työkalukutsu epäonnistuu | Varmista, että malli tukee työkaluja; tarkista OmniRoute-lokeista käännösvirheet                     |

## Palveluntarjoajan yhdistäminen (vaihe vaiheelta)

### Vaihe 1: Avaa hallintapaneeli

Siirry selaimessasi osoitteeseen `http://localhost:20128`.

### Vaihe 2: Siirry palveluntarjoajiin

Napsauta sivupalkista kohtaa **Palveluntarjoajat**.

### Vaihe 3: Napsauta Lisää palveluntarjoaja

Napsauta **+ Lisää palveluntarjoaja** -painiketta.

### Vaihe 4: Valitse palveluntarjoajasi

Selaa luetteloa tai etsi palveluntarjoajaasi. Napsauta sitä.

### Vaihe 5: Anna tunnistetiedot

- **Ilmaiset palveluntarjoajat**: Tunnistetietoja ei tarvita — napsauta vain **Yhdistä**
- **API-avainta käyttävät palveluntarjoajat**: Liitä API-avaimesi
- **OAuth-palveluntarjoajat**: Napsauta **Yhdistä OAuthilla** ja kirjaudu sisään

### Vaihe 6: Testaa yhteys

Varmista yhteyden toimivuus napsauttamalla **Testaa yhteys**.

### Vaihe 7: Valmista!

Palveluntarjoajasi on nyt yhdistetty. Voit käyttää sitä asetuksella `model: "auto"` tai määrittää palveluntarjoajan suoraan.

## Useiden palveluntarjoajien käyttäminen

OmniRoute toimii parhaiten **useiden palveluntarjoajien** kanssa. Näin saat:

- **Automaattisen varajärjestelyn** — Jos yksi palveluntarjoaja epäonnistuu, OmniRoute kokeilee seuraavaa
- **Kustannusten optimoinnin** — OmniRoute valitsee halvimman palveluntarjoajan kullekin pyynnölle
- **Nopeuden optimoinnin** — OmniRoute valitsee nopeimman palveluntarjoajan kullekin pyynnölle
- **Laadun optimoinnin** — OmniRoute valitsee parhaan palveluntarjoajan kuhunkin tehtävään

### Suositeltu määritys

Yhdistä vähintään **3 palveluntarjoajaa** parhaan käyttökokemuksen saavuttamiseksi:

1. **Yksi ilmainen palveluntarjoaja** (Kiro, OpenCode Free tai Pollinations) — Aina käytettävissä
2. **Yksi nopea palveluntarjoaja** (Groq, Cerebras) — Nopeita vastauksia varten
3. **Yksi laadukas palveluntarjoaja** (OpenAI, Anthropic, Google) — Monimutkaisia tehtäviä varten

Käytä sitten asetusta `model: "auto"`, jolloin OmniRoute valitsee automaattisesti parhaan vaihtoehdon kullekin pyynnölle.

## Yleisiä kysymyksiä

### "Pitääkö OmniRouten käytöstä maksaa?"

**Ei!** OmniRoute on ilmainen ja avoimen lähdekoodin ohjelmisto. Voit käyttää ilmaisia palveluntarjoajia (Kiro, OpenCode Free, Pollinations) maksamatta mitään. Maksat vain, jos päätät käyttää maksullisia palveluntarjoajia.

### "Mistä palveluntarjoajasta minun kannattaa aloittaa?"

Aloita **Kiro AI:sta** — se on ilmainen, ei vaadi API-avainta ja tarjoaa käyttöösi Claude-malleja. Lisää sitten muita palveluntarjoajia tarpeen mukaan.

### "Voinko käyttää useita palveluntarjoajia samanaikaisesti?"

**Kyllä!** Se on OmniRouten keskeinen idea. Yhdistä useita palveluntarjoajia ja käytä asetusta `model: "auto"`, jolloin OmniRoute valitsee parhaan vaihtoehdon jokaista pyyntöä varten.

### "Entä jos palveluntarjoaja lakkaa toimimasta?"

OmniRoute ohittaa automaattisesti palveluntarjoajat, joiden käyttö epäonnistuu, ja kokeilee seuraavaa. Sinun ei tarvitse tehdä mitään.

### "Miten katkaisen yhteyden palveluntarjoajaan?"

Siirry kohtaan Palveluntarjoajat → napsauta palveluntarjoajaa → napsauta **Katkaise yhteys**.

### "Voinko käyttää nykyisiä API-avaimiani?"

**Kyllä!** Jos sinulla on jo API-avaimia OpenAI:lle, Anthropicille, Googlelle jne., voit käyttää niitä OmniRoutessa. Liitä ne vain yhdistäessäsi palveluntarjoajan.
