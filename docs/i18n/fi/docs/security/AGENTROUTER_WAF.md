`agentrouter`-ylävirran yhdyskäytävä käyttää avainsanoihin perustuvaa sisältösuodatinta
kenttään `messages[].content`. Suodatin on osittain deterministinen (estää aina
tietyt ilmaukset) ja osittain probabilistinen (herkkä pyyntöryöpyille — muuttuu
aggressiivisemmaksi nopeiden peräkkäisten pyyntöjen jälkeen ja palautuu jäähdyttelyjakson jälkeen).

Kun WAF estää pyynnön, se palauttaa:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Suodattimen kattavuus

WAF tarkastaa vain kentän `messages[].content`. Se **ei** tarkasta:

- `system`-kehotetta
- Rakenteisia sisältölohkoja (`tool_result`, `tool_use`, `thinking`, `image`)
- Työkalujen `description`- ja `input_schema`-kenttiä
- Pyynnön metatietoja, otsakkeita tai mallitunnusta

## Aina estetyt kuviot (kirjainkoosta riippumatta)

| Kuvio                                 | Huomautukset                                             |
| ------------------------------------- | -------------------------------------------------------- |
| Mikä tahansa `Lorem ipsum` -muunnelma | Koko latinankielinen lorem-sanasto estetään              |
| `language model` (yksinään)           | "the language model" ja "large language model" sallitaan |
| `virtual assistant`                   | "AI assistant" sallitaan                                 |
| `I'm here to help`                    | Myös pelkkä "here to help" estetään                      |
| `Claude, made by Anthropic`           | Vain koko ilmaus                                         |

## Lähes aina estetyt kuviot

| Kuvio                                                         | Huomautukset                                                |
| ------------------------------------------------------------- | ----------------------------------------------------------- |
| `placeholder`                                                 | Kun se esiintyy yksinään (ei esimerkiksi parametrin nimenä) |
| `dummy data`                                                  | Yleinen alustavan testidatan ilmaus                         |
| `foo bar baz`                                                 | Kanoninen paikkamerkki-ilmaus                               |
| Toistuvat lyhyet tunnisteet (`AAA BBB CCC`, `test test test`) | Avainsanojen liiallisen syöttämisen tunnistin               |

## Käyttäytyminen kuormituksen aikana

Noin viiden lyhyen ajan sisällä tehdyn nopean pyynnön jälkeen WAF alkaa estää sisältöä,
joka normaalisti sallittaisiin. Rajoitin palautuu noin 5–10 sekunnin
joutoajan jälkeen. Kyseessä on sama IP-osoitteeseen ja avaimeen sidottu nopeusrajoitin, joka aiheuttaa
ajoittaisia `400 content-blocked` -virheitä, kun Claude Code tai Codex CLI
tekee useita työkalunkäyttö- tai viestinlähetyskutsuja nopeasti peräkkäin.

## OmniRouteen jo toteutetut lievennykset

1. **`open-sse/services/wafRateLimit.ts`** — pyyntöryöppysuoja, joka pakottaa
   vähintään 500 ms:n välin lähteville pyynnöille mihin tahansa `agentrouter:*`-
   URL-osoitteeseen. Viive on selvästi ihmisen havaitsemiskynnyksen alapuolella ja estää
   WAF:ää aktivoitumasta normaalissa liikenteessä.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — kun ylävirta palauttaa virheen
   `400 content-blocked`, suorittaja yrittää samaa URL-osoitetta uudelleen
   eksponentiaalisella viiveellä (1,5 s, 3,0 s, enintään 2 yritystä). Viiveen jälkeen
   WAF on yleensä palautunut ja uudelleenyritys onnistuu.

3. **`tests/unit/compression/harness.test.ts`** — testikiinteen
   `longInput` arvo muutettiin arvosta `"lorem ipsum dolor sit amet ".repeat(40)`
   arvoon `"example content for testing purposes ".repeat(40)`, jotta kun
   Claude Code lukee tämän tiedoston `Read`-työkalulla, tiedoston sisältö
   ei palaudu `tool_result`-lohkon kautta eikä laukaise WAF:ää.

## Ohjeita kehotteisiin ja työkalujen tulosteisiin

Jos Claude Code- tai Codex CLI -istunto saa toistuvasti virheen
`400 content-blocked`, tarkista viimeisin käyttäjäviesti ja viimeisin
työkalun tulos edellä mainittujen kuvioiden varalta ja muotoile sisältö uudelleen. Yleisiä
kiertotapoja:

- Korvaa `Lorem ipsum …` ilmauksella `example text …` tai sillä varsinaisella sisällöllä,
  jota testi tai kiinne yrittää mallintaa.
- Korvaa `placeholder` (kun se esiintyy yksinään) ilmauksella `example value`,
  `sample value` tai todellisella arvolla.
- Korvaa `language model` ilmauksella `large language model` tai `the model`.
- Korvaa `dummy data` ilmauksella `sample data` tai realistisilla alkuarvoilla.
- Korvaa `I'm here to help` / `here to help` täsmällisemmällä
  aloituksella (esim. "I'll review the file you mentioned").

## Virheellisten osumien ilmoittaminen ylävirran ylläpitäjälle

Nykyinen suodatin on liian aggressiivinen — se estää ilmauksen "Lorem ipsum"
`tool_result`-lohkoissa, vaikka käyttäjän tarkoituksena ei selvästikään ollut
syöttää kehotetta. Ylläpitäjien, jotka haluavat ongelman korjattavan sen lähteessä, tulisi
ottaa yhteyttä osoitteeseen `agentrouter.org` ja ilmoittaa virheellisistä osumista. Edellä oleva estoluettelo
perustuu ylävirran empiiriseen testaamiseen 2026-08-03.
