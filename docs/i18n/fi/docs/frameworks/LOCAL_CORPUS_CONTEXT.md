> `src/app/api/settings/local-corpus/route.ts` (asetusten API).

## Mikä se on

Local Corpus antaa ylläpitäjän asettaa yhden erikseen hyväksytyn tekstitiedostohakemiston
OmniRouten MCP-palvelimen käytettäväksi. Tiedostot säilyvät alkuperäisessä hakemistossaan:
OmniRoute tallentaa SQLite-tietokantaan vain kanonisen juuripolun ja ylläpitää hakemistoa
muistissa. Se ei kopioi korpuksen sisältöä repositorioon tai tietokantaan.

Indeksi päivitetään inkrementaalisesti. Muuttumattomat tiedostot käytetään uudelleen koon
ja muokkausajan perusteella, muuttuneet tiedostot luetaan uudelleen ja niistä lasketaan
SHA-256-tiiviste, ja poistetut tiedostot poistetaan indeksistä. Haku päivittää yli 30
sekuntia vanhan indeksin; kutsujat voivat myös pyytää välitöntä päivitystä.

## Lähteen määrittäminen

Asetusreitti edellyttää samaa hallinnan todennusta kuin muut asetusrajapinnat.
Lähetetyn polun on oltava jo olemassa oleva absoluuttinen hakemistopolku.

```bash
# Yhdistä hyväksytty hakemisto
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Tarkista määrityksen ja indeksin tila
curl http://localhost:20128/api/settings/local-corpus

# Katkaise yhteys muuttamatta lähdetiedostoja
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP-työkalut

Kaikki kolme työkalua edellyttävät `read:local-corpus`-oikeutta. Työkalujen vastaukset
sisältävät suhteelliset polut ja juurihakemiston perusnimen, eivät koskaan sen
absoluuttista polkua.

| Työkalu               | Kuvaus                                                                                               |
| :-------------------- | :--------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Raportoi määrityksen tilan, indeksin koon, rajat ja viimeisimmän päivityksen ajankohdan              |
| `local_corpus_search` | Hakee indeksoitua tekstiä ja palauttaa rajattuja, riveihin sidottuja katkelmia (enintään 20 tulosta) |
| `local_corpus_read`   | Lukee rajatun rivivälin yhdestä sallitusta korpukseen suhteutetusta tiedostosta                      |

Esimerkkejä MCP-syötteistä:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Turvallisuusrajat

- Sallittujen tiedostojen luettelo on tekstipainotteinen: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` ja `.yml`.
- Symboliset linkit ohitetaan. Lukupolut kanonisoidaan, ja niiden on pysyttävä määritetyn
  juuren sisällä; absoluuttiset polut ja yritykset siirtyä hakemistorakenteessa hylätään.
- Arkaluonteisten ja generoitujen hakemistojen nimet suljetaan pois: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` ja
  `secrets`.
- Oletusrajat ovat 5 000 tiedostoa, 1 MiB tiedostoa kohden, yhteensä 64 MiB indeksoitua
  sisältöä, noin 4 000 merkkiä hakukatkelmaa kohden ja 400 riviä lukua kohden.
- NUL-merkkejä sisältävät tiedostot tulkitaan muiksi kuin tekstitiedostoiksi ja ohitetaan tai hylätään.

Binäärisiä asiakirjoja, kuten PDF- ja DOCX-tiedostoja, kuvia ja arkistoja, ei tarkoituksella
tueta. Muunna ne hyväksyttyyn tekstimuotoon määritetyssä hakemistossa ennen indeksointia.

## Käyttöä koskevat huomautukset

- Määritetyn juuren muuttaminen tai poistaminen tyhjentää jaetun muistissa olevan indeksin.
- Prosessin uudelleenkäynnistys hävittää indeksin; seuraava haku rakentaa sen uudelleen
  määritetystä lähteestä.
- `local_corpus_status` ei pakota hakemiston läpikäyntiä. Käytä `local_corpus_search`-työkalua
  asetuksella `refresh: true`, kun välitön uudelleenskannaus on tarpeen.
- Läpikäynti- ja lukuvirheet lasketaan tai palautetaan puhdistettuina virheinä;
  lähdetiedostoja ei koskaan muokata.
