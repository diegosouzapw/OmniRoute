> **Totuuden lähde:** `src/lib/obsidian/api.ts` (REST- ja synkronointiasiakas),
> `src/lib/db/obsidian.ts` (tunnuksen / perus-URL:n / WebDAV-asetusten pysyvä tallennus),
> `src/lib/obsidianSync.ts` (WebDAV-holvin synkronointi), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP-työkalua), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (asetusrajapinnat). Työkalujen rekisteröinti
> ja käyttöalueiden kytkennät sijaitsevat tiedostossa `open-sse/mcp-server/server.ts`.

## Mikä se on

OmniRoute yhdistää **Obsidian**-holviin **kontekstilähteenä** — paikallisena Markdown-
tietämyskanta­na, jota agentit lukevat ja johon ne kirjoittavat sisäänrakennetun MCP-palvelimen
kautta. Integraatio kommunikoi työpöytäsovelluksessa suoritettavan yhteisön
**Obsidian Local REST API** -lisäosan kanssa, joten agentit voivat hakea muistiinpanoja,
lukea, kirjoittaa ja muokata tiedostoja, luetella holvin sisällön, käsitellä päivittäisiä
ja viikoittaisia jaksottaisia muistiinpanoja, hallita tunnisteita, suorittaa Obsidian-komentoja
sekä valinnaisesti koordinoida kaksisuuntaista työpöytä↔mobiili-holvisynkronointia.

Asiakas (`src/lib/obsidian/api.ts`) paketoi Local REST API -rajapinnan seuraavilla ominaisuuksilla:

- **Uudelleenyritys kasvavalla viiveellä** tilapäisille `5xx`-virheille ja **30 sekunnin aikakatkaisu** `AbortController`-ohjaimen avulla.
- **Tyypitetty virheluokittelu** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Käyttäjäystävällinen "Obsidianiin ei saada yhteyttä" -vihje**, joka mainitsee yleisen porttivirheen
  (HTTP portissa `27123`, **ei** MCP-päätepiste portissa `27124`) ja Tailscale-muodon.
- Holviin suhteutettu **polkujen koodaus**, jotta välilyöntejä ja vinoviivoja sisältävät muistiinpanopolut ovat turvallisia.

## Määritys

Obsidian-tunnukselle tai perus-URL:lle **ei ole ympäristömuuttujaa** — molemmat
tallennetaan SQLiten `key_value`-tauluun (nimiavaruus `obsidian`) tiedoston
`src/lib/db/obsidian.ts` kautta. Tunnus **salataan levossa** (AES-256-GCM,
taaksepäin yhteensopivalla selväkielisen tekstin varavaihtoehdolla). Määritä asetukset
Endpoint-hallintapaneelin **Kontekstilähteet**-välilehdeltä (`ObsidianSourceCard`) tai
asetusten REST-rajapinnan kautta.

> [!IMPORTANT]
> **Obsidian Local REST API** -lisäosan on oltava asennettuna ja käynnissä. Sen REST-
> rajapinta kuuntelee osoitteessa **HTTP `127.0.0.1:27123`** (oletusarvoinen perus-URL). Portti `27124`
> on _erillinen_ MCP/HTTPS-päätepiste, jonka asetusreitti nimenomaisesti hylkää.
> Jos yhteys muodostetaan toisesta laitteesta, käytä osoitetta `http://<tailscale-ip>:27123`.

### Määritysavaimet (SQLiten `key_value`, nimiavaruus `obsidian`)

| Avain             | Tarkoitus                                         | Salattu |
| ----------------- | ------------------------------------------------- | ------- |
| `api_key`         | Local REST API -rajapinnan bearer-tunnus          | kyllä   |
| `base_url`        | REST-perus-URL (oletus `http://127.0.0.1:27123`)  | ei      |
| `vault_path`      | Holvikansion absoluuttinen polku (synkronointiin) | ei      |
| `webdav_username` | Luotu WebDAV-käyttäjänimi (holvisynkronointi)     | ei      |
| `webdav_password` | Luotu WebDAV-salasana (holvisynkronointi)         | kyllä   |
| `webdav_enabled`  | Onko WebDAV-holvisynkronointi käytössä            | ei      |

### Määritys REST-rajapinnan kautta

```bash
# Tallenna ja vahvista Local REST API -tunnus (POST vahvistaa sen tilantarkistuksella)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Tarkista yhteyden tila (palauttaa connected-, hasToken-, baseUrl- ja vaultPath-kentät)
curl http://localhost:20128/api/settings/obsidian

# Katkaise yhteys (poistaa tallennetun tunnuksen)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Kaikki menetelmät edellyttävät hallintapaneelin todennusta. `POST` hylkää kaikki porttia `27124`
käyttävät URL-osoitteet ja vahvistaa tunnuksen kutsumalla Local REST API -rajapinnan
tilapäätepistettä ennen tallennusta.

### WebDAV-holvisynkronointi

`src/app/api/settings/obsidian/webdav/route.ts` hallitsee valinnaista WebDAV-pohjaista
holvisynkronointia (jonka toteuttaa `src/lib/obsidianSync.ts`). Sen käyttöönotto ohjaa
OmniRouten paikalliseen holvikansioon ja luo satunnaisen WebDAV-käyttäjänimi- ja
salasanaparin:

```bash
# Ota WebDAV-synkronointi käyttöön holvikansiolle (luo käyttäjänimen ja salasanan)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Hae WebDAV-synkronoinnin tila (tunnistetiedot palautetaan vain sen ollessa käytössä)
curl http://localhost:20128/api/settings/obsidian/webdav

# Poista WebDAV-synkronointi käytöstä (poistaa tunnistetiedot ja hallitun .stignore-tiedoston)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### API-avainkohtainen kontekstilähde (valinnainen)

Obsidian-määritys voidaan rajata **API-avainkohtaisesti** `api_key_context_sources`-taulun
kautta (`src/lib/db/apiKeyContextSources.ts`). Kun MCP-kutsu sisältää todennetun API-
avaimen tunnisteen, `getObsidianConfigForApiKey()` käyttää ensisijaisesti kyseisen avaimen
omaa tunnusta, perus-URL:ää ja holvipolkua (`source: "api_key"`) ja käyttää muussa tapauksessa
yleistä määritystä (`source: "global"`).

## MCP-työkalut (22)

Määritelty tiedostossa `open-sse/mcp-server/tools/obsidianTools.ts`. Tunnus/base-URL selvitetään
kutsukohtaisesti (ensin API-avaimelle määritetty, sitten yleinen). OmniRouten **synkronointipalvelimeen**
yhteyttä ottavat työkalut (neljä `obsidian_sync_*`-työkalua) edellyttävät lisäksi OmniRouten
asetuksissa määritettyä synkronoinnin todennustunnusta.

### Lukutyökalut (`read:obsidian`)

| Työkalu                      | Kuvaus                                                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Tarkista, onko Local REST API saavutettavissa ja todennettu.                                                                             |
| `obsidian_search_simple`     | Muistiinpanojen sisällön kokotekstihaku; palauttaa katkelmat tiedostopolkuineen.                                                         |
| `obsidian_search_structured` | Hae JSON Logic -lausekkeella (and/or/regex/path-suodattimet).                                                                            |
| `obsidian_read_note`         | Lue muistiinpano säilöön suhteutetun polun perusteella; valinnaisesti tietty otsikko, lohko tai frontmatter.                             |
| `obsidian_list_vault`        | Listaa säilön tiedostot ja hakemistot (merkintäpuuna).                                                                                   |
| `obsidian_get_document_map`  | Hae muistiinpanon otsikkorakenne karttana, jossa otsikot → rivinumerot.                                                                  |
| `obsidian_get_note_metadata` | Hae frontmatter, tunnisteet, linkit sekä merkki- ja sanamäärä ilman koko sisältöä.                                                       |
| `obsidian_get_active_file`   | Hae Obsidianissa parhaillaan aktiivisen tiedoston polku ja sisältö.                                                                      |
| `obsidian_get_periodic_note` | Hae tietyn päivämäärän päivittäinen, viikoittainen tai kuukausittainen jaksottainen muistiinpano (tänään, jos päivämäärä jätetään pois). |
| `obsidian_get_tags`          | Listaa kaikki säilön tunnisteet esiintymismäärineen.                                                                                     |
| `obsidian_list_commands`     | Listaa käytettävissä olevat Obsidian-komentotunnukset (käytettäväksi työkalun `obsidian_execute_command` kanssa).                        |
| `obsidian_sync_status`       | OmniRouten synkronointipalvelimen tila: käynnissäolo, säilön nimi, portti, käyntiaika ja viimeisin synkronointi.                         |
| `obsidian_sync_conflicts`    | Listaa ratkaisemattomat synkronointiristiriidat (polku, ristiriitapolku ja havaitsemisaika).                                             |

### Kirjoitustyökalut (`write:obsidian`)

| Työkalu                          | Kuvaus                                                                                              |
| -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Luo tai korvaa muistiinpano annetulla Markdown-sisällöllä.                                          |
| `obsidian_append_note`           | Lisää sisältöä muistiinpanon loppuun; valinnaisesti tiettyyn otsikkoon tai lohkoon.                 |
| `obsidian_patch_note`            | Lisää kirurgisen tarkasti otsikon, lohkon tai frontmatter-kentän loppuun tai alkuun tai korvaa sen. |
| `obsidian_delete_note`           | Poista muistiinpano pysyvästi säilöstä.                                                             |
| `obsidian_move_note`             | Siirrä muistiinpano tai nimeä se uudelleen säilön sisällä.                                          |
| `obsidian_execute_command`       | Suorita Obsidian-komento sen komentotunnuksen perusteella.                                          |
| `obsidian_open_file`             | Avaa tiedosto Obsidianissa (luo sen, jos sitä ei ole olemassa).                                     |
| `obsidian_sync_trigger`          | Käynnistä välitön kaksisuuntainen työpöytä↔mobiili-säilösynkronointi.                               |
| `obsidian_sync_resolve_conflict` | Ratkaise synkronointiristiriita: säilytä `local` (mobiili), `remote` (työpöytä) tai `keep-both`.    |

> [!NOTE]
> Työkalun `obsidian_patch_note` kohteiden `targetType` voi olla `heading | block | frontmatter`
> ja `operation` voi olla `append | prepend | replace`; valinnainen asetus on
> `createTargetIfMissing`. Neljä `obsidian_sync_*`-työkalua käyttävät paikallista
> synkronointipalvelinta (oletuksena `http://127.0.0.1:27781`) ja edellyttävät synkronointitunnusta.

### Käyttöoikeusalueet

Lukutyökalut edellyttävät käyttöoikeusaluetta `read:obsidian`; kirjoitustyökalut edellyttävät käyttöoikeusaluetta `write:obsidian`. Valvonta
toimii samoin kuin Notionissa — sen käsittelee `withScopeEnforcement()` tiedostossa
`open-sse/mcp-server/server.ts`, ja se otetaan käyttöön asetuksella `OMNIROUTE_MCP_ENFORCE_SCOPES=true`.
Sallitut käyttöoikeusalueet haetaan muuttujasta `OMNIROUTE_MCP_SCOPES` tai API-avaimen käyttöoikeusaluekontekstista. Katso
[MCP-SERVER.md](./MCP-SERVER.md).

## Päätepisteet

| Menetelmä | Polku                           | Tarkoitus                                                   |
| --------- | ------------------------------- | ----------------------------------------------------------- |
| `GET`     | `/api/settings/obsidian`        | Palauttaa `{ connected, hasToken, baseUrl, vaultPath }`.    |
| `POST`    | `/api/settings/obsidian`        | Tallentaa ja vahvistaa tunnuksen (hylkää portin `27124`).   |
| `DELETE`  | `/api/settings/obsidian`        | Katkaisee yhteyden (poistaa tallennetun tunnuksen).         |
| `GET`     | `/api/settings/obsidian/webdav` | WebDAV-synkronoinnin tila ja tunnistetiedot (kun käytössä). |
| `POST`    | `/api/settings/obsidian/webdav` | Ottaa WebDAV-synkronoinnin käyttöön holvihakemistolle.      |
| `DELETE`  | `/api/settings/obsidian/webdav` | Poistaa WebDAV-synkronoinnin käytöstä.                      |

> Nämä ovat hallintapaneelin asetusreittejä. Itse holvia käytetään Obsidianin
> paikallisen REST API:n (määritetty `base_url`) ja yllä olevien MCP-työkalujen kautta —
> julkista Obsidian-välityspäätepistettä `/v1` ei ole.

## Käyttötapaukset

- **Holviin perustuvat vastaukset** — `obsidian_search_simple` / `obsidian_search_structured`
  ja sitten `obsidian_read_note`, jotta agentti vastaa todellisten muistiinpanojesi perusteella.
- **Muistiinpanojen kirjoittaminen / päiväkirjan pitäminen** — `obsidian_write_note`, `obsidian_append_note` tai
  täsmällisiin muokkauksiin tarkoitettu `obsidian_patch_note`, jolla agentin tuottamat tekstit, yhteenvedot tai päivittäiset muistiinpanot
  (`obsidian_get_periodic_note`) kirjataan holviin.
- **Holvissa siirtyminen** — `obsidian_list_vault`, `obsidian_get_document_map` ja
  `obsidian_get_tags` rakenteen tutkimiseen ennen lukemista tai kirjoittamista.
- **Obsidianin automatisointi** — `obsidian_list_commands` + `obsidian_execute_command`
  lisäosien ja komentojen ohjaamiseen agentista käsin; `obsidian_open_file` avaa muistiinpanon käyttöliittymässä.
- **Mobiilisynkronointi** — ota WebDAV-synkronointi käyttöön ja käytä sitten työkaluja `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  työpöytä- ja mobiililaitteen välisen synkronoinnin koordinointiin ja ristiriitojen ratkaisemiseen.
