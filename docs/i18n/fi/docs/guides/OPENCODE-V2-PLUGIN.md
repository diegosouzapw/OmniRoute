`@omniroute/opencode-plugin-v2` tuo koko OmniRoute-luettelosi — mallit, yhdistelmät ja
automaattiset yhdistelmät — OpenCode v2:n mallivalitsimeen näyttönimineen, hintoineen ja maksuttoman tason
käyttörajoineen.

Se on eri paketti kuin `@omniroute/opencode-plugin`, koska OpenCode v1 ja v2 lataavat
liitännäiset eri rajapintojen kautta. Valitse OpenCoden pääversiotasi vastaava paketti; ne eivät
jaa mitään keskenään, joten toisen päivittäminen ei koskaan pakota päivittämään toista.

## Vaatimukset

- OpenCode v2.
- Saavutettavissa oleva OmniRoute-yhdyskäytävä (oletuksena `http://localhost:20128`).
- Node.js 22 tai 24.

## Asennus

Lisää liitännäinen tiedostoon `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Mallit näkyvät tämän jälkeen muodossa `omniroute/<provider>/<model>`; `providerId` määrittää tämän etuliitteen ja
sen integraation tunnuksen, jonka alle OpenCode tallentaa tunnistetiedon.

## Tunnistetiedot

Liitännäinen etsii yhdyskäytäväavainta seuraavista kolmesta paikasta tässä järjestyksessä:

1. **OpenCodeen yhdistämäsi tunnistetieto.** Liitännäinen rekisteröi integraation, joten
   OpenCoden oma todennuskulku voi tallentaa avaimen. Mitään ei tallenneta tiedostoon `opencode.json` — suosi tätä vaihtoehtoa.
2. Liitännäisen asetusten `apiKey` projektikohtaista ohitusta varten. Se sijoittaa avaimen tiedostoon, jonka
   saatat sisällyttää versionhallintaan.
3. Ympäristön `OMNIROUTE_API_KEY`.

Jos mitään näistä kolmesta ei ole määritetty, luettelo on tyhjä ja liitännäinen ilmoittaa siitä kerran käynnistyksen yhteydessä sen sijaan,
että mallivalitsin jäisi tyhjäksi ilman ilmoitusta.

### Hallintatunnus on eri avain

Yhdistelmät, palveluntarjoajien tila ja rikastetut tiedot (näyttönimet, hinnat ja maksuttoman tason käyttörajat) haetaan
yhdyskäytävän `/api/*`-päätepisteistä, jotka useimmissa käyttöönotoissa on suojattu **hallintatunnuksella**
päättelyavaimen sijaan:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<hallinnan lukutunnus>"
}
```

Jos `managementReadToken` jätetään määrittämättä, se käyttää varavaihtoehtona `apiKey`-arvoa. Kun yhdyskäytävä hylkää tämän varavaihtoehdon,
luettelo julkaistaan silti, mutta siinä käytetään raakoja mallitunnuksia näyttönimien sijaan, kanonisten aliasten
kaksoiskappaleita ei poisteta, hinnoittelua ei näytetä eikä yhdistelmiä ole saatavilla. Liitännäinen varoittaa tästä kerran päätepistettä kohden
ja nimeää päätepisteen sekä menetetyt tiedot — joten suppeamman mallivalitsimen syy ei koskaan jää epäselväksi.

## Asetukset

| Avain                            | Oletus                                               | Huomautukset                                                                                                     |
| -------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                        | Palveluntarjoajan tunnus, integraation tunnus ja etuliite, jonka alla mallit näkyvät                             |
| `baseURL`                        | pakollinen                                           | Yhdyskäytävän juuri, vain `http(s)`; `/v1`-jälkiliite lisätään tarvittaessa                                      |
| `apiKey`                         | yhdistetty tunnistetieto, sitten `OMNIROUTE_API_KEY` | Keskusteluavain päätepisteille `/v1/*`                                                                           |
| `managementReadToken`            | käyttää varavaihtoehtona `apiKey`-arvoa              | Avain päätepisteille `/api/*` — yleensä **ei** sama avain                                                        |
| `displayName`                    | `"OmniRoute"`                                        | Palveluntarjoajan nimi mallivalitsimessa                                                                         |
| `timeoutMs`                      | `10000`                                              | Päätepistekohtainen haun aikakatkaisu (automaattiset yhdistelmät käyttävät 5 sekuntia)                           |
| `modelCacheTtlMs`                | `300000`                                             | Luettelovälimuistin TTL; levylle tallennettu tilannevedos nopeuttaa kylmäkäynnistyksiä                           |
| `timeouts`                       | käyttää varavaihtoehtona `timeoutMs`-arvoa           | Päätepistekohtaiset aikarajat millisekunteina: `models`, `combos`, `autoCombos`, `enrichment`                    |
| `enrichment`                     | `true`                                               | Hae nimet, hinnat ja maksuttoman tason käyttörajat                                                               |
| `providerTag`                    | `true`                                               | Lisää näyttönimen eteen sen palveluntarjoajan nimi, jolle pyyntö reititetään                                     |
| `usableOnly`                     | `false`                                              | Säilytä vain palveluntarjoajat, jotka yhdyskäytävä ilmoittaa valmistelluiksi                                     |
| `visibleModels` / `hiddenModels` | `[]`                                                 | Tarkan vastaavuuden tai jälkiliitteen perusteella toimivat sallittujen luettelot; esto ohittaa sallimisen        |
| `geminiSanitization`             | `true`                                               | Poista työkaluskeemoista Geminiin hylkäämät JSON Schema -avainsanat (`$ref`-työkalut välitetään muuttamattomina) |
| `apiFormat.allowAnthropic`       | `false`                                              | Reititä sallittujen luettelossa olevat tunnukset Anthropicin API-lohkon kautta                                   |
| `apiFormat.anthropicModels`      | `[]`                                                 | Anthropiciin reititettävät täydelliset mallitunnukset                                                            |
| `logLevel` / `startupDebug`      | `warn` / `false`                                     | Lokituksen yksityiskohtaisuus                                                                                    |

## Miten luettelo pysyy ajan tasalla

Luettelo noudetaan laiskasti ja tallennetaan välimuistiin `modelCacheTtlMs`-ajaksi, ja levylle tallennettu tilannevedos pitää viimeksi tunnetun luettelon saatavilla, kun yhdyskäytävään ei saada yhteyttä — käyttökatkos vaikuttaa vain ajantasaisuuteen. Mallit ja yhdistelmät julkaistaan heti niiden saavuttua; automaattiset yhdistelmät, palveluntarjoajaluettelo ja rikastuskerros yhdistetään mukaan niiden valmistuttua, joten yksi hidas päätepiste ei voi pitää koko valitsinta panttivankina.

Nimet sisältävät yhdyskäytävän tuntemat tiedot: ylätason palveluntarjoajan, jolle malli reititetään, `[Free]`-merkinnän sekä siihen liittyvän budjetin — näin kaksi samaa mallia myyvää yhteyttä voidaan erottaa toisistaan. Poista etuliite käytöstä asetuksella `"providerTag": false`.

Manuaalista päivityskomentoa ei ole: OpenCode v2:n komennot ovat kehotemalleja, eivät takaisinkutsuja, joten liitännäinen ei voi tarjota sellaista. Päivitykset noudattavat TTL-arvoa; isäntää pyydetään lataamaan uudelleen vain, kun luettelo tai rikastuskerros on todella muuttunut, ei jokaisen päivityksen yhteydessä.

## Työkalukutsut Geminissä

Gemini hylkää koko pyynnön, jos sen työkalumääritykset sisältävät `$schema`- tai `additionalProperties`-avainsanan, ja vastaa virheellä `400 INVALID_ARGUMENT`. Liitännäinen poistaa nämä avainsanat tämän palveluntarjoajan Gemini-mallille tarkoitetuista työkaluskeemoista ja jättää kaikki muut pyynnöt ennalleen. `$ref`-viittauksen sisältävä työkalu välitetään muuttamattomana sen sijaan, että siitä poistettaisiin avainsanoja, koska viittauksen poistaminen laajentaisi skeeman hyväksymään mitä tahansa.
Poista toiminto käytöstä asetuksella `"geminiSanitization": false`.

## Vianmääritys

| Oire                                                       | Syy                                                                                                                                          |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Valitsin ei näytä OmniRoute-malleja                        | Avainta ei voitu selvittää (tarkista käynnistysvaroitus) tai yhdyskäytävään ei saada yhteyttä                                                |
| Raakoja mallitunnisteita, ei yhdistelmiä eikä hinnoittelua | Hallintapäätepisteet hylkäsivät tunnuksen — aseta `managementReadToken`                                                                      |
| Istunto on kiinnitetty kohteeseen `opencode-<id>/…`        | v1-liitännäinen julkaisi tunnisteen `opencode-<id>`; v2 julkaisee paljaan `<id>`-tunnisteen, joten valitse malli uudelleen kohdasta `<id>/…` |
