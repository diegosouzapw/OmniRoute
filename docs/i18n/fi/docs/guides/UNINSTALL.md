## Nopea asennuksen poisto (v3.6.2+)

OmniRoute sisältää kaksi sisäänrakennettua komentosarjaa siistiä poistamista varten:

### Säilytä tietosi

```bash
npm run uninstall
```

Tämä poistaa OmniRoute-sovelluksen mutta **säilyttää** tietokantasi, määrityksesi, API-avaimesi ja palveluntarjoaja-asetuksesi hakemistossa `~/.omniroute/`. Käytä tätä, jos aiot asentaa sovelluksen myöhemmin uudelleen ja haluat säilyttää nykyiset asetuksesi.

### Täydellinen poisto

```bash
npm run uninstall:full
```

Tämä poistaa sovelluksen **ja hävittää pysyvästi** kaikki tiedot:

- Tietokanta (`storage.sqlite`)
- Palveluntarjoajien määritykset ja API-avaimet
- Varmuuskopiotiedostot
- Lokitiedostot
- Kaikki `~/.omniroute/`-hakemiston tiedostot

> ⚠️ **Varoitus:** `npm run uninstall:full` -komentoa ei voi perua. Kaikki palveluntarjoajayhteytesi, yhdistelmäsi, API-avaimesi ja käyttöhistoriasi poistetaan pysyvästi.

## Manuaalinen asennuksen poisto

### Globaali NPM-asennus

```bash
# Poista globaali paketti
npm uninstall -g omniroute

# (Valinnainen) Poista datahakemisto
rm -rf ~/.omniroute
```

### Globaali pnpm-asennus

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Pysäytä ja poista säilö
docker stop omniroute
docker rm omniroute

# Poista taltio (poistaa kaikki tiedot)
docker volume rm omniroute-data

# (Valinnainen) Poista levykuva
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Pysäytä ja poista säilöt
docker compose down

# Poista myös taltiot (poistaa kaikki tiedot)
docker compose down -v
```

### Electron-työpöytäsovellus

**Windows:**

- Avaa `Asetukset → Sovellukset → OmniRoute → Poista asennus`
- Tai suorita NSIS-asennuksenpoisto-ohjelma asennushakemistosta

**macOS:**

- Vedä `OmniRoute.app` hakemistosta `/Applications` roskakoriin
- Poista tiedot: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Poista AppImage-tiedosto
- Poista tiedot: `rm -rf ~/.omniroute`

### Lähdekoodista tehty asennus (git clone)

```bash
# Poista kloonattu hakemisto
rm -rf /path/to/omniroute

# (Valinnainen) Poista datahakemisto
rm -rf ~/.omniroute
```

## Datahakemistot

OmniRoute tallentaa tiedot oletusarvoisesti seuraaviin sijainteihin:

| Alusta           | Oletuspolku                    | Ohitus                              |
| ---------------- | ------------------------------ | ----------------------------------- |
| Linux            | `~/.omniroute/`                | `DATA_DIR`-ympäristömuuttuja        |
| macOS            | `~/.omniroute/`                | `DATA_DIR`-ympäristömuuttuja        |
| Windows          | `%APPDATA%/omniroute/`         | `DATA_DIR`-ympäristömuuttuja        |
| Docker           | `/app/data/` (liitetty taltio) | `DATA_DIR`-ympäristömuuttuja        |
| XDG-yhteensopiva | `$XDG_CONFIG_HOME/omniroute/`  | `XDG_CONFIG_HOME`-ympäristömuuttuja |

### Datahakemiston tiedostot

| Tiedosto/hakemisto   | Kuvaus                                                             |
| -------------------- | ------------------------------------------------------------------ |
| `storage.sqlite`     | Päätietokanta (palveluntarjoajat, yhdistelmät, asetukset, avaimet) |
| `storage.sqlite-wal` | SQLiten ennakkokirjausloki (väliaikainen)                          |
| `storage.sqlite-shm` | SQLiten jaettu muisti (väliaikainen)                               |
| `call_logs/`         | Pyyntöjen tietosisältöarkistot                                     |
| `backups/`           | Automaattiset tietokannan varmuuskopiot                            |
| `log.txt`            | Vanha pyyntöloki (valinnainen)                                     |

## Varmista täydellinen poistaminen

Varmista asennuksen poistamisen jälkeen, ettei tiedostoja ole jäljellä:

```bash
# Tarkista globaali npm-paketti
npm list -g omniroute 2>/dev/null

# Tarkista datahakemisto
ls -la ~/.omniroute/ 2>/dev/null

# Tarkista käynnissä olevat prosessit
pgrep -f omniroute
```

Jos jokin prosessi on edelleen käynnissä, pysäytä se:

```bash
pkill -f omniroute
```
