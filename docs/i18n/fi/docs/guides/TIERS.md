OmniRoute järjestää 352 tuettua palveluntarjoajaa kolmeen taloudelliseen tasoon. Jokainen
pyyntö kulkee niiden läpi järjestyksessä, kunnes jokin niistä palauttaa onnistuneen vastauksen —
saat edullisimman toimivan vastauksen kirjoittamatta lainkaan varakoodia.

## Taso 1 — Tilaus

**Palveluntarjoajat, joista jo maksat.** OmniRoute käyttää kiintiön viimeiseen pisaraan ennen
sen vanhenemista.

| Palveluntarjoaja              | Miksi taso 1                                          |
| ----------------------------- | ----------------------------------------------------- |
| Claude Code OAuth             | Anthropic Pro/Team — kiinteä hinta, usein käyttämätön |
| OpenAI Codex (ChatGPT-tilaus) | Plus/Team sisältää Codex-kiintiön                     |
| GitHub Copilot                | Käyttäjäkohtainen — kiintiö nollautuu kuukausittain   |
| Cursor IDE                    | Pro-paketin kiintiö                                   |
| Antigravity / Devin Desktop   | Sisäänrakennetut kiintiöt                             |

**Strategia**: reititä tänne ensin jokainen pyyntö, joka sopii mallin
vahvuuksiin. Kiintiöseuranta valvoo lähestyviä nollauksia, ja `reset-aware`-yhdistelmästrategia
priorisoi niitä vastaavasti. Jos haluat reitittää ensin tasolle 1 ja siirtyä maksullisille
tasoille vasta kiintiön loppuessa, käytä tunnusta `auto/thrifty` — tai `auto/subscription`,
jos haluat pysyä tilaukseen sisältyvässä kapasiteetissa ja epäonnistua suljetusti sen sijaan. Katso
[Tilaus ensin -reititys](../routing/SUBSCRIPTION_LADDER.md).

## Taso 2 — Edullinen

**Käytön mukaan veloittavat palveluntarjoajat, joiden hinta on alle $1/1M tokenia.** Varattu suuren volyymin työhön
tai käytettäväksi, kun tason 1 kiintiöt ovat täynnä.

| Palveluntarjoaja            | Hinta (syöte/tuloste) | Vahvuudet                  |
| --------------------------- | --------------------- | -------------------------- |
| DeepSeek V4 Pro             | $0.27 / $1.10 per 1M  | Koodi, päättely            |
| GLM-4.5                     | $0.60 / $2.20 per 1M  | Pitkä konteksti            |
| MiniMax M1                  | $0.20 / $1.10 per 1M  | Nopeus                     |
| Qwen Coder                  | $0.30 / $1.20 per 1M  | Koodi                      |
| OpenRouter (hintaoptimoitu) | vaihtelee             | Yli 100 mallia, dynaaminen |

**Strategia**: yhdistelmä `cost-optimized` valitsee pienimmän $/token-hinnan mallin, joka täyttää
tehtävän kyvykkyyssuodattimen vaatimukset (kuvat, JSON-tila, työkalut, enimmäiskonteksti).

## Taso 3 — Ilmainen

**Maksuttomat palveluntarjoajat** — ilmaiset tasot, krediittiohjelmat, päivittäiset OAuth-kiintiöt.

| Palveluntarjoaja | Ilmainen kiintiö / krediitit                   |
| ---------------- | ---------------------------------------------- |
| Kiro AI          | Ilmainen Claude-taso (avokätinen kohtuukäyttö) |
| OpenCode Free    | Ei tunnistautumista, avokätiset käyttörajat    |
| Qoder            | Ilmainen OAuth                                 |
| Google Vertex AI | $300 krediittejä uusille tileille              |
| Amazon Q         | Ilmainen taso AWS-käyttäjille                  |
| Pollinations     | Avoin julkinen API                             |
| Cloudflare AI    | Workers AI:n ilmainen taso                     |

**Strategia**: yhdistelmä `auto` budjettikatolla reitittää tänne, kun tasot 1 ja 2 epäonnistuvat
tai kun `useFreeOnly=true` on asetettu. Ilmaisilla palveluntarjoajilla on usein tiukemmat
käyttörajat — circuit breaker palauttaa ne käyttöön odotusajan jälkeen.

## Tasojen määrittäminen

Hallintapaneeli → **Tasot** → määritä palveluntarjoajasi. Oletukset (tiedostosta `tierDefaults.json`) ovat
järkeviä; muokkaa niitä, kun haluat priorisoida tiettyjä tilauksia tai sulkea palveluntarjoajia pois.

Auto-Combon 16 tekijän pisteytys ottaa myös tason huomioon. Katso
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetria

Hallintapaneeli → **Käyttö** näyttää päivittäin käytetyt tokenit tasoittain. Käytä tätä seuraaviin tarkoituksiin:

- Varmista, että taso 1 hyödynnetään kokonaan (muuten hukkaat tilauksen arvoa)
- Tunnista, mitkä tason 2 mallit valitaan useimmin (keskitä käyttö 1–2 malliin)
- Varmista, että taso 3 säästää rahaa testaus- ja kokeilukuormissa

## Yleiset käyttötavat

### Täysin ilmainen työkuorma

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Ohjaa voimakkaasti kohti tasoa 3; käyttää tasoa 2 vain, jos taso 3 ei ole käytettävissä.

### Tilaus ensin, edullinen varavaihtoehto

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Eksplisiittinen järjestetty luettelo, joka vastaa tasoja 1 → 2 → 3.
