## 1. Antigravity vs. Antigravity CLI (agy)

Molemmat palveluntarjoajat käyttävät **samaa Googlen taustajärjestelmää** — samaa OAuth-asiakasohjelmaa, tunnisteen uusimista, päätepisteitä ja Google-tilejä. Erona on se, mitkä mallit näet.

> Katso Googlen virallinen vertailu [Antigravity CLI:n julkistuksesta](https://antigravity.google/blog/introducing-google-antigravity-cli).

| Ominaisuus             | `antigravity` (IDE)                                      | `agy` (CLI)                                                            |
| ---------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Google-tuote**       | Antigravity 2.0 / Antigravity IDE                        | Antigravity CLI                                                        |
| **Taustajärjestelmä**  | Sama Google Cloud Code API                               | Sama Google Cloud Code API                                             |
| **OAuth / tunniste**   | Sama asiakasohjelma, sama uusiminen                      | Sama asiakasohjelma, sama uusiminen                                    |
| **Malliluettelo**      | Staattinen kuratoitu luettelo (kovakoodattu OmniRouteen) | Haetaan reaaliaikaisesti Googlelta `:fetchAvailableModels`-toiminnolla |
| **Claude-mallit**      | Sonnet 4.6, Opus 4.6 (kummastakin 4 varianttia)          | Sonnet 4.6, Opus 4.6 (kummastakin 4 varianttia)                        |
| **Gemini-nimeäminen**  | Selkeät nimet (Low/Medium/High)                          | Alkuperäiset tunnisteet (extra-low/low/agent)                          |
| **Lisämallit**         | `gpt-oss-120b-medium`                                    | Voi sisältää Googlen lisämalleja                                       |
| **Oletuskäyttötapaus** | IDE-integraatio (VS Code, JetBrains)                     | CLI- / API-käyttö                                                      |
| **Kiintiö**            | Jaettu agy:n kanssa (sama Google-tili)                   | Jaettu antigravityn kanssa (sama Google-tili)                          |

**Saatavilla olevat mallit (kokeellisesti vahvistettu 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (eri päättelytasoilla)
- Claude: Sonnet 4.6, Opus 4.6 (kummastakin default/low/medium/high-variantit)
- Muut: GPT-OSS 120B Medium
- **Claude Sonnet 5 EI ole saatavilla** — vain 4.6-variantteja tuetaan

**Miksi malliluettelot eroavat toisistaan**: Googlen CLI on Googlen virallisen blogin mukaan ”optimoitu nopeutta ja vähäistä lisäkuormaa varten” sekä ”optimoitu yhdessä Gemini-mallien kanssa”. Verkko-/IDE-tuote on ”optimoitu kattavuutta varten”. CLI käyttää `:fetchAvailableModels`-toimintoa mallien dynaamiseen löytämiseen, kun taas IDE käyttää staattista kuratoitua luetteloa.

**Käytännössä**: Käytä Gemini-malleille `agy/`-etuliitettä (esim. `agy/gemini-3.7-flash-high`). Käytä staattiselle kuratoidulle luettelolle `antigravity/`-etuliitettä. Molemmat käyttävät samaa Googlen taustajärjestelmää, mutta tarjoavat erilaiset mallien nimeämistavat. Kiintiö on yhteinen — kumman tahansa palveluntarjoajan käyttö lasketaan saman Google-tilin rajoihin.

## 2. Google One AI Pro: Kiintiöjärjestelmä

> Katso viralliset kiintiötiedot sivulta [Antigravity-dokumentaatio: Sopimukset](https://antigravity.google/docs/plans) ja uusimmat hinnoittelumuutokset sivulta [Antigravity-sopimusten muutokset](https://antigravity.google/blog/changes-to-antigravity-plans).

Google Antigravity käyttää viestimäärän sijaan **kaksitasoista kiintiötä**, joka perustuu tehtyyn työhön ("Work Done" eli laskennallinen kuormitus).

### Kaksi tasoa

| Taso                   | Kuvaus                             | Päivitysjakso                                                                                    |
| ---------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------ |
| **5 tunnin jakso**     | Välittömästi käytettävä työkiintiö | Nollautuu 5 tuntia istunnon ensimmäisen pyynnön jälkeen                                          |
| **7 päivän perustaso** | Viikoittainen ehdoton yläraja      | Ohittaa 5 tunnin päivityksen, jos raja täyttyy; käyttö estetään seuraavaan 7 päivän jaksoon asti |

**Tehdyn työn ("Work Done") laskeminen**: Paljon agenttitoimintoja edellyttävät tehtävät (esim. "Refaktoroi tämä koko tietovarasto") kuluttavat kiintiötä huomattavasti nopeammin kuin yksinkertaiset tehtävät (esim. "Korjaa tämä funktio"). Kulutusta näyttävää reaaliaikaista hallintapaneelia ei ole.

### Sopimustasot

| Sopimus      | Hinta      | Kiintiö                                   | Viikoittainen raja                                |
| ------------ | ---------- | ----------------------------------------- | ------------------------------------------------- |
| Free         | $0         | Merkittävä kiintiö, päivittyy viikoittain | Kyllä                                             |
| AI Pro       | $19.99/kk  | Suuri kiintiö, liukuva 5 tunnin päivitys  | Kyllä (ohittaa 5 tunnin päivityksen täyttyessään) |
| AI Ultra 5x  | $99.99/kk  | 5x Pro-kiintiö                            | Ei viikoittaista rajaa                            |
| AI Ultra 20x | $199.99/kk | 20x Pro-kiintiö                           | Ei viikoittaista rajaa                            |

### Gemini-mallit ja muut mallit

- **Gemini-mallit** (Flash + Pro): Jakavat yhden nopeusrajoituksen, jota kulutetaan API-hinnoittelun mukaan. Jos Flash on 8x halvempi kuin Pro, saat 8x enemmän Flash-tunnisteita.
- **Muut kuin Gemini-mallit** (Claude, GPT-OSS): Niillä on **erilliset** nopeusrajoitukset. Ne voivat olla edelleen käytettävissä, vaikka Geminin käyttö olisi estetty.

### AI-krediitit (ylikulutus)

> Katso krediittien toimintaperiaate sivulta [Google One AI -krediitit](https://support.google.com/googleone/answer/14534406).

Kun perustason kiintiö on käytetty loppuun:

- **Ei koskaan**: Odota kiintiön päivittymistä; näyttää ilmoituksen "Baseline model quota reached"
- **Aina**: Käytä AI-krediittejä automaattisesti; järjestelmä palaa perustasoon, kun sen kiintiö päivittyy

Krediitit ostetaan erikseen, ja niitä vähennetään API:n vakiohinnoittelun mukaisesti.

### Keskeiset tiedot

- Kiintiö on **tilikohtainen ja jaettu** — sama Google-tili jakaa yhden kiintiön Antigravity IDE:n, CLI:n ja OmniRouten välillä
- Jokaisella Google-tilillä on oma erillinen kiintiönsä — useita tilejä = useita kiintiöitä
- AI Pro -käyttäjät ovat raportoineet **7 päivän käyttöestoista** 5 tunnin nollausten sijaan, kun viikoittainen perustason kiintiö täyttyy (Google on vahvistanut, että tämä on tarkoituksellista suuren kysynnän vuoksi)

**Kun tilisi kiintiö on käytetty loppuun**: OmniRoute yrittää automaattisesti uudelleen yhdistelmäreitin seuraavalla käytettävissä olevalla tilillä. Manuaalisia toimenpiteitä ei tarvita.

## 3. projectId-tunnuksen hankkiminen

Jokainen antigravity/agy-yhteys tarvitsee Google Cloud Coden `projectId`-tunnuksen. Ilman sitä `/v1internal:models`-päätepiste palauttaa 404-virheen.

### Menetelmä A: Automaattinen (suositeltu)

OmniRoute hoitaa tämän automaattisesti. Kun lisäät uuden Google-tilin hallintapaneelin OAuth-toiminnon kautta:

1. OmniRoute päivittää tunnuksen
2. Kutsuu `loadCodeAssist`-toimintoa projectId-tunnuksen löytämiseksi
3. Jos projektia ei ole, luo sellaisen kutsumalla `onboardUser`-toimintoa
4. Yrittää uudelleen `loadCodeAssist`-kutsua saadakseen juuri luodun projectId-tunnuksen
5. Tallentaa sen tietokantaan

**Tämä toimii useimmilla tileillä** — manuaalisia vaiheita ei tarvita.

### Menetelmä B: Manuaalisesti agy CLI:n kautta

Jos automaattinen tunnistus epäonnistuu (katso kohdasta 5, milloin näin tapahtuu):

```bash
# Asenna agy CLI (jos sitä ei ole jo asennettu)
npm install -g @anthropic-ai/agy

# Kirjaudu sisään Google-tililläsi
agy login

# Valitse tili, joka on otettava käyttöön
# Tämä käynnistää Cloud Code -rekisteröinnin ja määrittää projectId-tunnuksen
```

Kun `agy login` onnistuu, päivitä tunnus OmniRouten hallintapaneelissa. projectId löydetään automaattisesti.

### Vahvistaminen

Tarkista tietokanta:

```bash
# OmniRoute-säilön sisällä
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Tai tarkista lokit:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuth-uudelleenohjaus-URI

### Ongelma

Google OAuth edellyttää kelvollista uudelleenohjaus-URI:a. OmniRouten oletusarvo on `http://127.0.0.1:20128/callback` (loopback-osoite). Tämä toimii paikallisissa koontiversioissa, mutta **ei etäkäyttöönotossa** (esimerkiksi palvelimella, jota käytetään lähiverkon IP-osoitteen kautta).

Google hylkää uudelleenohjaus-URI:t, jotka:

- Käyttävät IP-osoitteita (osoitteen on oltava verkkotunnus, jonka pääte on esimerkiksi `.com` tai `.org`)
- Eivät vastaa OAuth-asiakkaan määrityksiin rekisteröityjä uudelleenohjaus-URI:eja

### Ratkaisu

**Vaihtoehto A: Käytä sisäänrakennettua OAuth-kulkua (oletus)**

- Toimii, kun käytät OmniRoutea osoitteesta `localhost` tai `127.0.0.1`
- Määrityksiä ei tarvita

**Vaihtoehto B: Mukautetut OAuth-tunnistetiedot**

- Aseta ympäristössäsi `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web`
- Anna omat Google OAuth -tunnistetietosi:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Rekisteröi `https://your-domain.com/callback` valtuutetuksi uudelleenohjaus-URI:ksi Google Cloud Consolessa

**Vaihtoehto C: Käytä agy CLI:tä ensimmäiseen kirjautumiseen**

- Suorita `agy login` koneella, jolla OmniRoutea käytetään
- OAuth-kulku suoritetaan paikallisesti loppuun ja tunnukset tallennetaan
- Tuo yhteys OmniRouteen Dashboardin kautta

### Rajoitukset

- Mukautetut OAuth-tunnistetiedot edellyttävät verkkotunnusta (Google ei hyväksy IP-osoitteita uudelleenohjaus-URI:eiksi)
- Jos sinulla ei ole verkkotunnusta, käytä sen sijaan vaihtoehtoa A tai C

## 5. Vianmääritys: Kun automaattinen määritys epäonnistuu

OmniRoute käsittelee projectId:n löytämisen ja käyttöönoton automaattisesti useimmilla tileillä. Jos se epäonnistuu, perimmäinen syy on yleensä jokin seuraavista:

### Tilin alue on estetty

**Oire**: `agy login` palauttaa ilmoituksen "Kelpoisuustarkistus epäonnistui: nykyinen tilisi ei ole oikeutettu käyttämään Antigravitya, koska se ei ole tällä hetkellä saatavilla sijainnissasi."

**Perimmäinen syy**: Google-tileillä on taustajärjestelmän "Country Association" -kenttä, joka määritetään rekisteröinnin yhteydessä. agy CLI ja Cloud Code API tarkistavat tämän kentän tiukasti — toisin kuin Gemini-verkkopalvelu, joka tarkistaa vain nykyisen IP-osoitteesi.

> Voit tarkistaa tiliisi liitetyn alueen tai muuttaa sitä [Googlen maan liittämislomakkeella](https://policies.google.com/country-association-form).

**Miksi Gemini-verkkopalvelu toimii mutta agy ei**:

- Gemini-verkkopalvelu / Google One: tarkistaa vain nykyisen IP-osoitteen (välityspalvelin toimii)
- agy CLI / Cloud Code API: lukee taustajärjestelmän Country Association -kentän (välityspalvelin ei auta)

**Korjaus**:

1. Siirry [Googlen maan liittämislomakkeelle](https://policies.google.com/country-association-form) käyttäessäsi yhdysvaltalaista IP-osoitetta
2. Lähetä alueen muutospyyntö (valitse "Asun eri maassa")
3. Odota 1–24 tuntia, että Google käsittelee pyynnön ja lähettää sähköposti-ilmoituksen
4. Tämän jälkeen komennon `agy login` pitäisi onnistua

### Tilillä ei ole Cloud Code -projektia

**Oire**: Lokeissa näkyy `loadCodeAssist returned no project id` ja `onboardUser failed (400)`.

**Perimmäinen syy**: Tiliä ei ole koskaan rekisteröity Google Cloud Codeen, ja automaattinen käyttöönotto epäonnistui.

**Korjaus**: Suorita `agy login` manuaalisesti käynnistääksesi Cloud Code -rekisteröinnin ja päivitä sitten tunnus OmniRoute Dashboardissa.

### Tunnus on vanhentunut tai peruutettu

**Oire**: Lokeissa näkyy 401-virheitä tai "Tunnus on vanhentunut" -ilmoituksia.

**Korjaus**: Päivitä tunnus kohdassa Dashboard → Providers → agy → napsauta päivityskuvaketta. Jos itse päivitystunnus on peruutettu, sinun on tunnistauduttava uudelleen OAuthin kautta.

```
├─ Onko tilillä Google One AI Pro -tilaus?

│  └─ KYLLÄ ↓
│

│
└─ Manuaalisesti: Suorita `agy login` koneella

   └─ Epäonnistuu → Tarkista virheilmoitus; ongelma liittyy todennäköisesti alueeseen tai tilaukseen
```
