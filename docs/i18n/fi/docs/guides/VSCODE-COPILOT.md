**OmniCopilot** tuo kaikki OmniRouten tarjoamat mallit _suoraan_ GitHub Copilot Chatin
natiiviin mallinvalitsimeen. Ei toista sivupalkkia eikä erillistä keskustelukäyttöliittymää — Copilotin agenttitila, työkalukutsut,
MCP-palvelimet ja mukautetut ohjeet toimivat edelleen, mutta käyttävät valitsemaasi mallia.

|                           |                                                                                                                                                 |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Asennus (VS Code)**     | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Asennus (forkit)**      | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Lähdekoodi / ongelmat** | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Vaatimukset**           | VS Code 1.104+                                                                                                                                  |

> **Copilot-tilausta ei tarvita.** VS Code 1.122:sta alkaen kielimallipalveluntarjoaja toimii
> ilman GitHub-kirjautumista ja ilman Copilot-tilausta. Automaattiset täydennykset suoraan editorissa ja
> upotuksiin perustuvat ominaisuudet eivät kuulu palveluntarjoajan APIin ja vaativat edelleen Copilotin.

## Määritys

1. **Käynnistä OmniRoute** — `npm install -g omniroute && omniroute` (hallintapaneeli osoitteessa `http://localhost:20128`).
2. **Asenna laajennus** — etsi laajennusnäkymässä hakusanalla "OmniRoute".
3. **Valitse malli** — Copilot Chat → mallinvalitsin → **Manage Models…** → **OmniRoute** ja valitse sitten
   haluamasi mallit.

Mitään ei tarvitse määrittää, kun OmniRoute käyttää oletusporttia. Etäinstanssia varten avaa
**OmniRoute-kuvake toimintopalkissa** (tai suorita `OmniRoute: Manage Connection`) ja määritä:

- **Palvelimen URL-osoite** — palvelimen juuriosoite, esim. `http://192.168.0.15:20128`. Laajennus lisää
  `/v1`-päätteen; älä sisällytä sitä osoitteeseen.
- **API-avain** — vain, kun palvelimella on asetettu `REQUIRE_API_KEY`. Tallennetaan käyttöjärjestelmän avainnippuun VS
  Coden SecretStoragen kautta, ei koskaan `settings.json`-tiedostoon.

## Mitä mallinvalitsin näyttää

Laajennus ei näytä raakaa `GET /v1/models` -hyötykuormaa, vaan muotoilee sen, ja näkyvä
määrä on luettelon kokoa pienempi kahdesta tarkoituksellisesta syystä.

### Se pyytää yhden tunnisteen mallia kohden

`MODELS_CATALOG_PREFIX_MODE`-asetuksen oletusarvo on **`dual`**, jolloin jokainen malli ilmoitetaan kahdesti — kerran
lyhyen aliaksen etuliitteellä ja kerran ensisijaisen palveluntarjoajan etuliitteellä — jotta vanhempien asiakasohjelmien
määritykset löytävät edelleen kummankin muodon:

```
cc/claude-sonnet-4-6        ← alias prefix
claude/claude-sonnet-4-6    ← canonical prefix, same model
```

Laajennus pyytää osoitetta **`GET /v1/models?prefix=alias`**, jolloin kustakin mallista saadaan yksi tunniste
muuttamatta palvelimen laajuista asetusta muiden asiakasohjelmiesi osalta. Vertailuinstanssissa tämä vähensi
**2345 tietuetta 1396 tietueeseen — 949 kaksoiskappaletta, eikä yhtään menetettyä mallia.**

Jos haluat korjata tämän palvelimen laajuisesti _kaikille_ asiakasohjelmille, aseta
`MODELS_CATALOG_PREFIX_MODE`-ominaisuuslipun arvoksi `alias` hallintapaneelissa. Katso
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix), jossa kuvataan
kyselyparametri ja tilakohtainen taulukko.

### Se piilottaa mallit, jotka eivät tue keskustelua

Luettelo sisältää myös kuva-, video-, ääni-, uudelleenjärjestely-, upotus- ja moderointimalleja. Ne
hylätään joka tapauksessa keskustelupyynnössä:

```
HTTP 400 — Model '<id>' is an image-generation model and cannot be used on
/v1/chat/completions. Use POST /v1/images/generations instead.
```

joten ne suodatetaan `type`-kentän perusteella ennen mallinvalitsimeen päätymistä. **Responses-API-mallit
säilytetään** — jokainen Codex- / GPT-5.x-tietue ilmoittaa `supported_endpoints: ["responses"]`,
ja OmniRoute muuntaa ne `/v1/chat/completions`-rajapintaa varten, joten ne ovat täysin käyttökelpoisia.

### Palveluntarjoajat, joita et ole määrittänyt

Luettelossa näkyvät niiden palveluntarjoajien mallit, joilla on **aktiivinen yhteys**, sekä kaikki **noAuth**-palveluntarjoajat
— avaimettomat palveluntarjoajat, jotka muodostavat suuren osan ilmaistasosta. Tämä on tarkoituksellista. Voit piilottaa
ne lisäämällä ne hallintapaneelin asetusten `blockedProviders`-kohtaan; laajennukseen ei tarvitse tehdä
muutoksia.

## Hallintapaneeli VS Code -välilehdellä

`omnicopilot.dashboardOpen: "editor"` näyttää OmniRoute-hallintapaneelin editorivälilehdellä Simple Browserin kautta ulkoisen selaimen sijaan. Upottaminen on **otettava erikseen käyttöön palvelimella** asetuksella `DASHBOARD_ALLOW_EMBED=vscode`, jolloin HTML-sivut toimitetaan otsakkeella `frame-ancestors 'self' vscode-webview:` oletusarvoisten otsakkeiden `frame-ancestors 'none'` + `X-Frame-Options: DENY` sijaan. API-rajapinnat (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) säilyttävät tiukat otsakkeet kummassakin tapauksessa.

> ⚠️ **Tämä on käännösaikainen, ei ajonaikainen asetus.** Next.js kääntää `headers()`-määrityksen reittiluetteloon, joten `next.config.mjs` lukee muuttujan pakettia käännettäessä
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Sen vieminen ympäristöön jo käännetyn palvelimen käynnistyksen yhteydessä ei muuta mitään — otsakkeet on sisällytetty pakettiin.

```bash
# muuttujan on oltava käytettävissä BUILD-komennossa
DASHBOARD_ALLOW_EMBED=vscode npm run build        # tai npm run build:release
npm start
```

| Asennustapa                | Voiko upottamisen ottaa käyttöön?                                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Lähdekoodista              | ✅ aseta muuttuja käännöskomennossa yllä esitetyllä tavalla                                                                                                  |
| `npm install -g omniroute` | ❌ julkaistu paketti sisältää valmiiksi käännetyn paketin — käännä sen sijaan lähdekoodista                                                                  |
| Docker-levykuva            | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — Docker Hubin valmiiksi käännetyssä levykuvassa upottaminen ei ole käytössä |

Ilman upottamisen sallivaa koontiversiota sivu kieltäytyy näkymästä kehyksessä. Laajennus tunnistaa tämän vastauksen otsakkeista ja käyttää ulkoista selainta vararatkaisuna — mikään ei rikkoudu, ja laajennus ilmoittaa tästä kerran.
Katso [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) ja ongelma
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Muiden työkalujen määrittäminen VS Codesta käsin

**`OmniRoute: Configure Coding CLI`** käyttää `omniroute`-komentorivityökalua kirjoittaakseen käyttövalmiit profiilit työkaluille Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code, Kilo ja Roo — samat määritykset on kuvattu tiedostossa
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). API-avain välitetään komentorivityökalulle `OMNIROUTE_API_KEY`-ympäristömuuttujan kautta, ei koskaan komentorivillä.

## Vianmääritys

| Oire                                                            | Syy / korjaus                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OmniRoute-malleja ei näy valitsimessa                           | Palvelimeen ei saada yhteyttä. Tilarivin piste muuttuu harmaaksi; suorita `OmniRoute: Check Connection`. Mallien etsintä on tarkoituksella hiljainen eikä kehota käyttäjää, vaan jättää mallit lisäämättä.                                                                                                |
| Jokainen malli näkyy kahdesti                                   | Käytössäsi on OmniCopilot-versio, joka on vanhempi kuin 1.0.1 — päivitä se. Laajennus pyytää nyt `?prefix=alias`.                                                                                                                                                                                         |
| Aiemmin luettelossa ollut kuva-/äänimalli on kadonnut           | Tämä on tarkoituksellista versiosta 1.0.1 lähtien — kyseinen malli ei pystynyt koskaan vastaamaan keskustelupyyntöön.                                                                                                                                                                                     |
| Paneeli puuttuu aktiviteettipalkista                            | VS Code siirtää ylimääräiset näkymäsäilöt aktiviteettipalkin alareunan **"…"**-ylivuotovalikkoon, ja hiiren kakkospainikkeella piilotettu säilö pysyy piilotettuna. Napsauta aktiviteettipalkkia hiiren kakkospainikkeella → valitse **OmniRoute** tai avaa se komennolla `OmniRoute: Manage Connection`. |
| Hallintapaneeli avautuu selaimessa `editor`-tilasta huolimatta  | Palvelinta ei **käännetty** asetuksella `DASHBOARD_ALLOW_EMBED=vscode` (katso yllä) — sen asettaminen valmiiksi käännetyn asennuksen käynnistyksen yhteydessä ei vaikuta mihinkään. Vararatkaisu on tarkoituksellinen.                                                                                    |
| Malliluettelo ei päivity palveluntarjoajien vaihtamisen jälkeen | Suorita `OmniRoute: Refresh Models` tai käytä paneelin ↻-linkkiä.                                                                                                                                                                                                                                         |
