Palveluntarjoajia yhteensä: **360**. Katso luokkakohtainen erittely alta.

## Luokat

- **Ilmainen** — maksuton taso API-avaimella (määritetään hallintapaneelissa)
- **Ei tunnistautumista** — julkiset päätepisteet, jotka eivät edellytä avainta tai kirjautumista
- **OAuth** — OmniRoute hoitaa kirjautumisprosessin, eikä API-avainta tarvita
- **Verkkoeväste** — käyttää palveluntarjoajan verkkosovellusta evästetunnistautumisen kautta
- **API-avain** — maksullinen palveluntarjoaja, joka määritetään API-avaimella (ilmaisia krediittejä voi olla saatavilla)
- **Paikallinen** — suoritetaan käyttäjän tietokoneella (Ollama, LM Studio, vLLM jne.)
- **Haku** — verkkohakupalveluntarjoajat
- **Ääni** — vain ääntä käsittelevät palveluntarjoajat (TTS/STT)
- **Ylävirran välityspalvelin** — palveluntarjoajat, jotka välittävät pyynnöt muille palveluntarjoajille
- **Pilviagentti** — pitkäkestoiset ohjelmointiagentit (Codex Cloud, Devin, Jules)
- **Järjestelmä** — OmniRouten sisäiset palveluntarjoajat (loopback jne.)

Lisätunnisteet: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Työkalukutsut` (jos näkyvissä): `native` — todellinen funktiokutsu-API; `emulated` — `tools`-taulukkoa emuloidaan kehotteessa `webTools.ts`-tiedoston avulla (regex-jäsennetyt `<tool>{...}</tool>`-lohkot); `none` — `tools` jätetään tällä hetkellä hiljaisesti huomiotta. Katso #7286.

Ota kukin palveluntarjoaja käyttöön sekä määritä ja testaa se hallintapaneelissa osoitteessa `/dashboard/providers`.
