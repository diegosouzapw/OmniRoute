OmniRoute sisältää kuratoidun valikoiman ilmaisia välityspalvelimia `free_proxies`-taulussa,
joka synkronoidaan ulkoisilta palveluntarjoajilta (1proxy, proxifly, iplocate, webshare).
Hallintapaneelissa ne näkyvät kohdassa **Asetukset → Ilmaiset välityspalvelimet**. Tässä dokumentissa
käsitellään luetteloreitin tarjoamaa palvelinpuolen suodatusta, lajittelua, laskentaa ja
synkronointivirheiden raportointia.

## Luetteloreitti — `GET /api/settings/free-proxies`

Palauttaa suodatetun, lajitellun ja sivutetun osajoukon sekä kokonaismäärän. Suodatus ja
laskenta tehdään SQL:ssä, joten käyttöliittymä voi näyttää todellisen kokonaismäärän (esim. `Yhteensä: 0`)
lataamatta kaikkia rivejä muistiin.

### Kyselyparametrit

| Parametri         | Tyyppi                             | Oletus    | Merkitys                                                                                                                     |
| ----------------- | ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `search`          | merkkijono                         | `""`      | Kirjainkoon huomioiva `LIKE` host- (ja lähde-) sarakkeessa.                                                                  |
| `protocol`        | merkkijono                         | `""`      | `type`-suodatin: `http` / `https` / `socks4` / `socks5`. Tyhjä = kaikki.                                                     |
| `country`         | merkkijono                         | `""`      | `countryCode`-suodatin (ISO-2). Tyhjä = kaikki.                                                                              |
| `minQuality`      | numero                             | `0`       | Vain rivit, joilla `qualityScore >= minQuality`. `0` = ei alarajaa.                                                          |
| `disabledSources` | merkkijono                         | `""`      | Pilkuilla erotellut poissuljettavat lähdetunnisteet (esim. `proxifly,webshare`).                                             |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = pisteet laskevasti; `latency` = viive nousevasti (null-arvot viimeisinä); `recent` = `lastValidated` laskevasti. |
| `offset`          | numero                             | `0`       | Sivutuksen aloituskohta.                                                                                                     |
| `limit`           | numero                             | `50`      | Sivun koko (rajoitetaan palvelinpuolella).                                                                                   |

### Vastaus

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` ilmaisee suodatetun kokonaismäärän **ennen** sivutusta, joten käyttöliittymä voi näyttää
`Yhteensä: N`-arvon ja käsitellä `hasMore`-arvoa siitä riippumatta. `syncErrors` käyttää lähdetunnistetta
avaimena, ja se täytetään vain lähteille, joiden viimeisin synkronointi epäonnistui — `Yhteensä: 0` -tulos
ei koskaan jää ilman selitystä.

## Lisääminen varantoon — `POST /api/settings/free-proxies/[id]/add-to-pool`

Siirtää ilmaisen välityspalvelimen hallittuun `proxy_registry`-varantoon. Validoi
ylävirran palvelun ensin; onnistumisen yhteydessä palauttaa uuden varannon välityspalvelimen tunnisteen ja mitatun viiveen.

## Synkronointi — `POST /api/settings/free-proxies/sync`

Noutaa kaikki käytössä olevat lähteet uudelleen (tai osajoukon kentästä `{ "sources": [...] }`). Jokainen
lähde synkronoidaan itsenäisesti; epäonnistunut lähde kirjataan `syncErrors`-kenttään ja
muut suoritetaan silti loppuun, joten osittaiset synkronoinnit eivät koskaan poista aiempia kelvollisia tietoja.

## Tilastot — `GET /api/settings/free-proxies/stats`

Palauttaa `total / inPool / avgQuality / bySource / lastSyncAt`-koosteen
ilman rivien tietosisältöä — hallintapaneelin otsakewidgetit käyttävät tätä.
