Caveman-pakkaus voi ladata kielikohtaisia sääntöpaketteja sisäänrakennettujen englannin sääntöjen lisäksi.
Näin ydinmoottori pysyy vakaana, samalla kun portugalin, espanjan, saksan, ranskan, italian, japanin ja
tulevien kielten sääntöpaketteja voidaan kehittää itsenäisesti.

## Sijainti

Kielipaketit sijaitsevat hakemistossa:

```txt
open-sse/services/compression/rules/<language>/
```

Nykyiset toimitettavat paketit (vahvistettu `rules/`-hakemiston sisällön perusteella):

| Kieli                | Hakemisto      | Käytettävissä olevat sääntöluokat                   |
| -------------------- | -------------- | --------------------------------------------------- |
| Englanti             | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Espanja              | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugali (Brasilia) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonesia            | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italia               | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Saksa                | `rules/de/`    | `context`, `filler`, `structural`                   |
| Ranska               | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japani               | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Kattavuushuomautus:** `en`-, `es`-, `pt-BR`-, `id`- ja `it`-paketeissa ovat kaikki viisi luokkaa; `de`-, `fr`- ja `ja`-paketeissa toimitetaan kolme luokkaa. Puuttuvissa `dedup`- ja `ultra`-luokissa käytetään automaattisesti sisäänrakennettuja englannin sääntöjä. Täydennykset pienempien pakettien `dedup.json`- ja `ultra.json`-tiedostojen lisäämiseksi ovat tervetulleita.
>
> `pt-BR`-paketti perustuu Lenine Júniorin **[Troglodita](https://github.com/leninejunior/troglodita)**-järjestelmään — alusta alkaen Brasilian portugalin kielioppia varten suunniteltuun pakkausjärjestelmään (pleonasmien vähentäminen, PT-BR-täytesanojen poistaminen ja tekniset lyhenteet brasilialaiselle kehittäjäyhteisölle).
>
> Kanoninen luokkaluettelo ja luokkakohtainen skeema sijaitsevat tiedostossa [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draft 2020-12).

## Kielen tunnistus

`languageDetector.ts` käyttää kevyitä heuristiikkoja kielen päättelemiseen kehotetekstistä. Määritettyä
oletuskieltä noudatetaan edelleen, ja tunnistus voidaan poistaa käytöstä asetuksista, kun tarvitaan
täsmällistä hallintaa.

Tunnistuksen tulosta käytetään vain sääntöpakettien valitsemiseen. Se ei muuta palveluntarjoajan reititystä, aluekohtaisten
asetusten valintaa tai käyttöliittymän kieltä.

## Asetusten rakenne

Pakkausasetukset voivat sisältää seuraavat tiedot:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` hallitsee hallintapaneelin ja esikatselun oletusasetuksia. `cavemanConfig` on suorituksenaikainen moottorin määritys,
jota käytetään, kun Caveman pakkaa viestitekstiä.

## Kielipaketin lisääminen

1. Luo `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Käytä Caveman-sääntömuotoa, joka on kuvattu tiedostossa `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Pidä korvaukset maltillisina ja vältä koodin, tunnisteiden, URL-osoitteiden tai JSON-datan muuttamista.
4. Lisää tai päivitä kielivalinnan ja korvaustoiminnan testit.
5. Lisää uudet hallintapaneelin/i18n:n selitteet näkyviin, jos kieli esiintyy käyttöliittymän valitsimissa.

## API

Saatavilla olevat paketit voidaan hakea seuraavasti:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Esikatselupäätepiste hyväksyy kielimääritysten ohitukset:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Kaikkiin kuuteen kielipakettiin lisättiin versiossa v3.8.0 `SHARED_BOUNDARIES`-lauseke, jota käytetään kaikilla
Caveman-intensiteeteillä (LITE, FULL, ULTRA). Se ohjeistaa moottoria säilyttämään nämä mallit sanatarkasti
riippumatta ympäröivän täytetekstin poistamisesta:

| Mallin tyyppi                                | Esimerkki                              |
| -------------------------------------------- | -------------------------------------- |
| Aidatut koodilohkot                          | ` ```python\n...\n``` `                |
| Rivinsisäinen koodi                          | `` `my_var` ``                         |
| URL-osoitteet                                | `https://example.com/path`             |
| Tiedostopolut (absoluuttiset + suhteelliset) | `/etc/hosts`, `./src/index.ts`         |
| Virheotsikot                                 | `Error:`, `TypeError:`, `SyntaxError:` |
| Pinon jäljitysrivit                          | `  at functionName (file.ts:12:3)`     |

Nämä mallit määritetään kohdassa `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (aiemmin `[]`). Vakio
sijaitsee tiedostossa `open-sse/services/compression/types.ts`.

### Miksi tämä on tärkeää

Ilman SHARED_BOUNDARIES-lauseketta aggressiiviset Caveman-tilat saattaisivat poistaa sisältöä, joka vaikutti toistuvalta
proosalta mutta olikin todellisuudessa koodikatkelma, tiedostopolku tai virheiden pinojäljitys. SHARED_BOUNDARIES toimii
kielestä riippumattomana turvaverkkona, jota sovelletaan ennen täytetekstisääntöjen suorittamista.

### preservePatterns-mallien mukauttaminen

Lisämalleja voidaan lisätä ajon aikana pakkausasetusten kautta:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Mukautetut mallit laajentavat kuutta oletusmallia eivätkä korvaa niitä.

## Käyttöä koskevat huomautukset

- Sisäänrakennettuja englanninkielisiä sääntöjä käytetään varavaihtoehtona, kun kielipaketti puuttuu.
- Virheelliset sisäänrakennetut JSON-paketit hylätään validoinnissa, jotta julkaisuversioiden resurssit eivät heikkene huomaamatta.
- Sääntöpaketit sisältävät vain dataa, eikä niiden pidä tuoda koodia tai suorittaa mielivaltaista logiikkaa.
- Pakkauksen analytiikkakerros tallentaa valitun tilan ja moottorin, ei kehotteen koko tekstiä.
