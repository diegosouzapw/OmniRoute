> **Джерело істини:** `src/lib/agentSkills/` (каталог, генератор, парсери) + каталог `skills/` (файли SKILL.md)
> **Останнє оновлення:** 2026-08-02 — v3.8.50

Навички агентів — це структуровані файли SKILL.md, які навчають зовнішніх агентів, клієнтів MCP та оркестратори A2A використовувати REST API та CLI OmniRoute. На відміну від [навичок Omni](./SKILLS.md) (визначень інструментів LLM, що виконуються всередині OmniRoute), навички агентів є _каталогом документації_ — статичним markdown-вмістом, який можна безпосередньо додавати до контексту агента.

---

## Огляд

Каталог містить **45 навичок агентів** (23 для REST API + 21 для CLI + 1 робочий процес конфігурації). Кожна навичка має:

- **Канонічний ID** (`omni-auth`, `cli-serve` тощо)
- Файл **SKILL.md** у `skills/{id}/SKILL.md` із YAML frontmatter (`name`, `description`) і детальним markdown-вмістом
- **Кінцеві точки REST** (навички API) або **підкоманди CLI** (навички CLI), отримані зі специфікації OpenAPI та реєстру CLI
- **Необроблену URL-адресу GitHub** для отримання актуальної версії: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Архітектура

```
src/shared/constants/agentSkills.ts    — кураторський список із 45 записів (name/desc/category/area/icon)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() записує SKILL.md до skills/{id}/
  openapiParser.ts                     — видобуває кінцеві точки REST із docs/openapi.yaml
  cliRegistryParser.ts                 — видобуває підкоманди CLI з bin/cli-registry.ts
  schemas.ts                           — схеми Zod: AgentSkillSchema, SkillCoverageSchema тощо
  types.ts                             — інтерфейси TypeScript: AgentSkill, SkillCoverage тощо

skills/{id}/SKILL.md                   — згенеровані та впорядковані markdown-файли (усього 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (потрібна автентифікація)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 інструменти MCP (список, отримання, покриття)
src/lib/a2a/skills/listCapabilities.ts        — навичка A2A: list-capabilities
```

## Формат SKILL.md

```markdown
---
name: omni-providers
description: "Керуйте підключеннями до провайдерів: додавайте, тестуйте, оновлюйте та видаляйте облікові дані."
---

<!-- згенеровано src/lib/agentSkills/generator.ts; внесені вручну зміни буде перезаписано -->

## Огляд

...

## Автентифікація

...

## Кінцеві точки

...

<!-- skill:custom-start -->

## Спеціальний розділ (зберігається під час повторної генерації)

...

<!-- skill:custom-end -->
```

Під час повторної генерації генератор зберігає вміст між `<!-- skill:custom-start -->` і `<!-- skill:custom-end -->`. Десять навичок мають впорядковані спеціальні блоки:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Виявлення REST API

| Кінцева точка                | Метод | Опис                                                                     | Автентифікація |
| :--------------------------- | :---- | :----------------------------------------------------------------------- | :------------- |
| `/api/agent-skills`          | GET   | Список каталогу (необов’язково `?category=api\|cli\|config&area=<area>`) | немає          |
| `/api/agent-skills/{id}`     | GET   | Отримати метадані окремої навички                                        | немає          |
| `/api/agent-skills/{id}/raw` | GET   | Отримати SKILL.md як `text/markdown`                                     | немає          |
| `/api/agent-skills/coverage` | GET   | Статистика покриття (кількість наявних файлів SKILL.md)                  | немає          |
| `/api/agent-skills/generate` | POST  | Запустити генератор (dryRun/prune/onlyIds)                               | керування      |

Приклад — вивести список усіх навичок API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Приклад — отримати окремий файл SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Виявлення MCP

У межах області `read:catalog` зареєстровано три інструменти MCP:

| Інструмент                        | Опис                                                               |
| :-------------------------------- | :----------------------------------------------------------------- |
| `omniroute_agent_skills_list`     | Вивести список навичок (необов’язкові фільтри `category` / `area`) |
| `omniroute_agent_skills_get`      | Отримати метадані + SKILL.md для однієї навички за `id`            |
| `omniroute_agent_skills_coverage` | Статистика покриття (наявні/загальна кількість API/CLI)            |

Відомості про налаштування областей доступу й автентифікацію див. у [MCP-SERVER.md](./MCP-SERVER.md).

## Виявлення A2A

Навичка A2A `list-capabilities` повертає повний каталог із 45 навичок як артефакт у вигляді таблиці markdown. Зовнішні оркестратори можуть викликати її так:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "Перелічити всі можливості" }]
  }
}
```

Докладні відомості про протокол див. у [A2A-SERVER.md](./A2A-SERVER.md).

## Як зовнішні агенти використовують навички

### 1. Виявлення через REST

```bash
# Отримати повний каталог
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Отримати SKILL.md для додавання до контексту
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Виявлення через MCP

```typescript
// У клієнті MCP для Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → масив AgentSkill із rawUrl для кожного елемента
```

### 3. Виявлення через A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table — це таблиця Markdown з усіма 45 ідентифікаторами навичок і стовпцями rawUrl
```

### 4. Пряме отримання необробленого файлу з GitHub (сервер не потрібен)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Генератор

Генератор читає підготовлений каталог, специфікацію OpenAPI та реєстр CLI і записує `skills/{id}/SKILL.md` для кожного запису:

```bash
# Попередній перегляд (пробний запуск без запису)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Повна повторна генерація
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Повторно згенерувати конкретні ідентифікатори
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Відповідь генератора — це `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
