`@omniroute/opencode-plugin-v2` додає весь ваш каталог OmniRoute — моделі, комбінації та
автокомбінації — до засобу вибору моделей OpenCode v2 разом із відображуваними назвами, цінами та
лімітами безкоштовного рівня.

Це окремий пакет від `@omniroute/opencode-plugin`, оскільки OpenCode v1 і v2 завантажують
плагіни за різними контрактами. Виберіть пакет, що відповідає вашій основній версії OpenCode; між
ними немає нічого спільного, тому оновлення одного ніколи не вимагає оновлення іншого.

## Вимоги

- OpenCode v2.
- Доступний шлюз OmniRoute (`http://localhost:20128` за замовчуванням).
- Node.js 22 або 24.

## Встановлення

Додайте плагін до `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Після цього моделі з'являться як `omniroute/<provider>/<model>`; `providerId` визначає цей префікс та
ідентифікатор інтеграції, під яким OpenCode зберігає облікові дані.

## Облікові дані

Плагін шукає ключ шлюзу в трьох місцях у такому порядку:

1. **Облікові дані, які ви підключили в OpenCode.** Плагін реєструє інтеграцію, тому
   власний процес автентифікації OpenCode може зберегти ключ. До `opencode.json` нічого не
   записується — надавайте перевагу цьому способу.
2. `apiKey` у параметрах плагіна для перевизначення на рівні проєкту. У такому разі ключ потрапляє до файлу, який ви
   можете додати до репозиторію.
3. `OMNIROUTE_API_KEY` у середовищі.

Якщо не задано жодного з трьох варіантів, каталог буде порожнім, а плагін один раз повідомить про це під час запуску замість
того, щоб залишити вас із мовчки порожнім засобом вибору.

### Токен керування — це інший ключ

Комбінації, стан постачальників і збагачення даних (відображувані назви, ціни, ліміти безкоштовного рівня) надходять із
кінцевих точок шлюзу `/api/*`, які в більшості розгортань захищені **керівним** токеном,
а не ключем для виконання запитів:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<токен керування з правами читання>"
}
```

Якщо `managementReadToken` не задано, використовується `apiKey`. Коли шлюз відхиляє такий резервний варіант,
каталог усе одно публікується, але з необробленими ідентифікаторами моделей замість відображуваних назв, без
усунення дублікатів за канонічними псевдонімами, без цін і без комбінацій. Плагін один раз попереджає про кожну кінцеву точку, коли це трапляється,
зазначаючи кінцеву точку й те, які дані було втрачено, — тож причина обмеженого засобу вибору завжди зрозуміла.

## Параметри

| Ключ                             | За замовчуванням                                    | Примітки                                                                                                                 |
| -------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `providerId`                     | `"omniroute"`                                       | Ідентифікатор постачальника, ідентифікатор інтеграції та префікс, під яким відображаються моделі                         |
| `baseURL`                        | обов'язковий                                        | Коренева адреса шлюзу, лише `http(s)`; суфікс `/v1` додається там, де потрібно                                           |
| `apiKey`                         | підключені облікові дані, потім `OMNIROUTE_API_KEY` | Ключ чату для `/v1/*`                                                                                                    |
| `managementReadToken`            | резервно використовується `apiKey`                  | Ключ для `/api/*` — зазвичай **не** той самий                                                                            |
| `displayName`                    | `"OmniRoute"`                                       | Назва постачальника в засобі вибору                                                                                      |
| `timeoutMs`                      | `10000`                                             | Час очікування отримання даних для кожної кінцевої точки (для автокомбінацій — 5 с)                                      |
| `modelCacheTtlMs`                | `300000`                                            | TTL кешу каталогу; знімок на диску пришвидшує холодні запуски                                                            |
| `timeouts`                       | резервно використовується `timeoutMs`               | Часові бюджети для кожної кінцевої точки в мс: `models`, `combos`, `autoCombos`, `enrichment`                            |
| `enrichment`                     | `true`                                              | Отримувати назви, ціни та ліміти безкоштовного рівня                                                                     |
| `providerTag`                    | `true`                                              | Додавати до відображуваної назви префікс постачальника, до якого вона спрямовується                                      |
| `usableOnly`                     | `false`                                             | Залишати лише постачальників, які шлюз позначає як налаштовані                                                           |
| `visibleModels` / `hiddenModels` | `[]`                                                | Списки дозволів за точним збігом або суфіксом; заборона має пріоритет                                                    |
| `geminiSanitization`             | `true`                                              | Видаляти зі схем інструментів ключові слова JSON Schema, які відхиляє Gemini (інструменти з `$ref` передаються без змін) |
| `apiFormat.allowAnthropic`       | `false`                                             | Спрямовувати дозволені ідентифікатори через блок API Anthropic                                                           |
| `apiFormat.anthropicModels`      | `[]`                                                | Повні ідентифікатори моделей, які спрямовуються до Anthropic                                                             |
| `logLevel` / `startupDebug`      | `warn` / `false`                                    | Докладність журналювання                                                                                                 |

## Як каталог залишається актуальним

Каталог завантажується відкладено та кешується протягом `modelCacheTtlMs`, а знімок на диску зберігає
останню відому версію каталогу доступною, коли шлюз недоступний — збій коштуватиме вам лише
актуальності даних. Моделі та комбінації публікуються щойно надходять; автоматичні комбінації, список
провайдерів і шар доповнення додаються після надходження, тому одна повільна кінцева точка не може
затримувати весь засіб вибору.

Назви містять відомі шлюзу дані: вищестоящого провайдера, до якого спрямовується модель, позначку `[Free]`
і відповідний бюджет — тож два підключення, що пропонують одну й ту саму модель, залишаються
розрізнюваними. Вимкніть префікс за допомогою `"providerTag": false`.

Команди ручного оновлення немає: команди OpenCode v2 — це шаблони запитів, а не зворотні виклики,
тому плагін не може надати таку команду. Оновлення відбуваються відповідно до TTL; запит до хоста
на перезавантаження надсилається лише тоді, коли каталог або шар доповнення справді змінився, а не
під час кожного оновлення.

## Виклик інструментів у Gemini

Gemini відхиляє весь запит, якщо оголошення інструментів містять `$schema` або
`additionalProperties`, відповідаючи `400 INVALID_ARGUMENT`. Плагін видаляє ці ключові слова зі
схем інструментів, призначених для моделі Gemini цього провайдера, і залишає всі інші запити без змін.
Інструмент, що містить `$ref`, пересилається без змін, оскільки видалення посилання розширило б
схему до «приймати будь-що».
Установіть `"geminiSanitization": false`, щоб вимкнути це.

## Усунення несправностей

| Ознака                                                     | Причина                                                                                                   |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Засіб вибору не показує моделі OmniRoute                   | Ключ не визначено (перевірте попередження під час запуску) або шлюз недоступний                           |
| Необроблені ідентифікатори моделей, немає комбінацій і цін | Кінцеві точки керування відхилили токен — установіть `managementReadToken`                                |
| Сесію закріплено за `opencode-<id>/…`                      | Плагін v1 публікував `opencode-<id>`; v2 публікує просто `<id>`, тому повторно виберіть модель у `<id>/…` |
