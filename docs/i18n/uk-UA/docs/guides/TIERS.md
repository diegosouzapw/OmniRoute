OmniRoute розподіляє 352 підтримуваних провайдерів за 3 економічними рівнями. Кожен
запит послідовно проходить через них, доки один із провайдерів не поверне успішну відповідь — ви
отримуєте найдешевшу придатну відповідь без необхідності писати код резервного перемикання.

## Рівень 1 — Передплата

**Провайдери, за яких ви вже платите.** OmniRoute використовує всю доступну квоту до того,
як спливе термін її дії.

| Провайдер                         | Чому рівень 1                                                  |
| --------------------------------- | -------------------------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — фіксована ціна, часто не використовується |
| OpenAI Codex (передплата ChatGPT) | Plus/Team включає квоту Codex                                  |
| GitHub Copilot                    | Оплата за користувача — квота скидається щомісяця              |
| Cursor IDE                        | Квота плану Pro                                                |
| Antigravity / Devin Desktop       | Вбудовані квоти                                                |

**Стратегія**: спершу спрямовуйте сюди кожен запит, що відповідає сильним сторонам
моделі. Засіб відстеження квот контролює наближення скидань, а комбінована стратегія
`reset-aware` відповідно визначає пріоритети. Щоб спочатку спрямовувати запити на рівень 1
і переходити до платних рівнів лише після вичерпання квоти, використовуйте ідентифікатор
`auto/thrifty` — або `auto/subscription`, щоб залишатися в межах передбачених планом
ресурсів і завершувати роботу з помилкою, якщо вони недоступні. Див.
[Маршрутизація з пріоритетом передплат](../routing/SUBSCRIPTION_LADDER.md).

## Рівень 2 — Дешеві

**Провайдери з оплатою за токени вартістю менш ніж $1 за 1 млн токенів.** Зарезервовані для
великих обсягів роботи або випадків, коли квоти рівня 1 вичерпано.

| Провайдер                     | Ціна (вхід/вихід)      | Сильні сторони                      |
| ----------------------------- | ---------------------- | ----------------------------------- |
| DeepSeek V4 Pro               | $0.27 / $1.10 за 1 млн | Код, міркування                     |
| GLM-4.5                       | $0.60 / $2.20 за 1 млн | Довгий контекст                     |
| MiniMax M1                    | $0.20 / $1.10 за 1 млн | Швидкість                           |
| Qwen Coder                    | $0.30 / $1.20 за 1 млн | Код                                 |
| OpenRouter (оптимізація ціни) | різниться              | Понад 100 моделей, динамічний вибір |

**Стратегія**: комбінація `cost-optimized` вибирає модель із найнижчою вартістю
за токен, яка відповідає фільтру можливостей завдання (комп’ютерний зір, режим JSON,
інструменти, максимальний контекст).

## Рівень 3 — Безкоштовні

**Провайдери з нульовою вартістю** — безкоштовні рівні, кредитні програми, щоденні квоти OAuth.

| Провайдер        | Безкоштовна квота / кредити                                          |
| ---------------- | -------------------------------------------------------------------- |
| Kiro AI          | Безкоштовний рівень Claude (щедрі умови добросовісного використання) |
| OpenCode Free    | Без автентифікації, щедрі обмеження частоти                          |
| Qoder            | Безкоштовний OAuth                                                   |
| Google Vertex AI | $300 кредитів для нових облікових записів                            |
| Amazon Q         | Безкоштовний рівень для користувачів AWS                             |
| Pollinations     | Відкритий загальнодоступний API                                      |
| Cloudflare AI    | Безкоштовний рівень Workers AI                                       |

**Стратегія**: комбінація `auto` з обмеженням бюджету спрямовує запити сюди, коли рівні 1 і 2
недоступні або коли встановлено `useFreeOnly=true`. Безкоштовні провайдери часто мають
суворіші обмеження частоти — автоматичний запобіжник відновлює їх після затримки повторних спроб.

## Налаштування рівнів

Панель керування → **Рівні** → призначте своїх провайдерів. Значення за замовчуванням
(із `tierDefaults.json`) є доцільними; змініть їх, якщо потрібно надати пріоритет певним
передплатам або виключити окремих провайдерів.

16-факторна система оцінювання Auto-Combo також ураховує рівень. Див.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Телеметрія

Панель керування → **Використання** показує кількість токенів, витрачених на кожному рівні
за день. Використовуйте ці дані, щоб:

- Переконатися, що рівень 1 використовується повністю (інакше ви марнуєте цінність передплати)
- Визначити, які моделі рівня 2 вибираються найчастіше (скоротити їхню кількість до 1–2)
- Перевірити, що рівень 3 заощаджує кошти на тестових і дослідницьких навантаженнях

## Поширені шаблони

### Повністю безкоштовне робоче навантаження

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Наполегливо спрямовує запити на рівень 3; використовує рівень 2, лише якщо рівень 3 недоступний.

### Передплата передусім із дешевим резервним варіантом

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Явний упорядкований список, що відповідає послідовності: рівень 1 → рівень 2 → рівень 3.
