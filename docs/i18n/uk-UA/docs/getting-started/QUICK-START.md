## Крок 1: Установіть OmniRoute

Виберіть зручний для вас спосіб:

### Варіант A: npm (рекомендовано)

```bash
npm install -g omniroute
```

### Варіант B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` — це найвища **опублікована** стабільна версія SemVer. Цей тег **не** відстежує гілку git `main`. Для GitOps зафіксуйте `diegosouzapw/omniroute:X.Y.Z`. Див. [Теги образів / Канали випусків](../guides/DOCKER_GUIDE.md#release-channels).

### Варіант C: з вихідного коду

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Крок 2: Запустіть OmniRoute

```bash
omniroute
```

OmniRoute запускається за адресою `http://localhost:20128`. Панель керування відкриється автоматично.

---

## Крок 3: Підключіть безкоштовного провайдера

Ви можете користуватися OmniRoute **абсолютно безкоштовно**, підключивши безкоштовного провайдера.

### Варіант A: Kiro (безкоштовний Claude — без кредитної картки)

1. Відкрийте панель керування за адресою `http://localhost:20128`
2. Перейдіть до **Провайдери** → **Додати провайдера**
3. Виберіть **Kiro AI**
4. Натисніть **Підключити** (API-ключ не потрібен!)
5. Готово! Тепер ви маєте безкоштовний доступ до моделей Claude.

### Варіант B: OpenCode Free (без автентифікації)

1. Відкрийте панель керування за адресою `http://localhost:20128`
2. Перейдіть до **Провайдери** → **Додати провайдера**
3. Виберіть **OpenCode Free**
4. Натисніть **Підключити** (API-ключ не потрібен!)
5. Готово! Тепер ви маєте безкоштовний доступ до кількох моделей.

### Варіант C: Pollinations (ключ не потрібен)

1. Відкрийте панель керування за адресою `http://localhost:20128`
2. Перейдіть до **Провайдери** → **Додати провайдера**
3. Виберіть **Pollinations**
4. Натисніть **Підключити** (API-ключ не потрібен!)
5. Готово! Тепер ви маєте безкоштовний доступ до GPT-5, Claude, Gemini тощо.

---

## Крок 4: Перевірте, чи все працює

У розділі [API-ключі](http://localhost:20128/dashboard/api-manager) створіть новий ключ. Збережіть його, оскільки він більше не відображатиметься. Зверніть увагу: цей ключ потрібен інструментам для доступу до OmniRoute, а не для доступу до зовнішніх провайдерів.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Ви маєте побачити список підключених моделей.

## Крок 5: Спрямуйте свою IDE або CLI до OmniRoute

У своїй IDE або CLI-утиліті задайте:

```
Базова URL-адреса: http://localhost:20128/v1
API-ключ:           [скопіюйте з Панелі керування → Кінцеві точки]
Модель:             auto
```

Ось і все! Тепер ваша IDE використовує OmniRoute з автоматичним вибором провайдера.

### Приклад для IDE: VSCode/Continue.dev

1. У VSCode встановіть розширення [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Оновіть свій файл `~/.continue/config.yaml`, додавши такі рядки:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. На панелі чату Continue.dev виберіть `OmniRoute - Auto`, після чого запити надсилатимуться до OmniRoute.
4. (Необов'язково) Вправа для читача: попросіть свою IDE доповнити `config.yaml` усіма іншими готовими конфігураціями 😊

### Приклад для CLI: Codex CLI

1. У своїй операційній системі задайте змінну середовища на постійній основі.
   Для macOS/Linux (додайте до `~/.bashrc` або `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Для Windows (командний рядок):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Тепер запустімо Codex, налаштований для OmniRoute. Виконайте:

```
omniroute launch-codex --model auto
```

Це можна зробити вручну через `codex` і параметри командного рядка, указавши кінцеву точку та API-ключ, але з наведеною вище командою OmniRoute подбає про все за вас.

Такий самий запуск однією командою працює для інших CLI через універсальний засіб запуску — `omniroute run <target>` підтримує `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` і `gemini` (див. [Інтеграції CLI](../guides/CLI-INTEGRATIONS.md)).

3. Тепер CLI має надсилати запити до OmniRoute.

### Переконайтеся, що ваш інструмент маршрутизує запити до OmniRoute

Докладні відомості про запит можна переглянути, натиснувши [Моніторинг/Журнали](http://localhost:20128/dashboard/logs) на лівій бічній панелі. Перейшовши до запису, ви побачите додаткові подробиці. Також можна переглянути, яку інформацію надсилає ваше улюблене середовище. Це корисно для навчання та налагодження.

## Поширені запитання

### «Чи потрібен мені API-ключ?»

**Ні!** Ви можете користуватися безкоштовними провайдерами (Kiro, OpenCode Free, Pollinations) без жодного API-ключа. Просто підключіть їх на панелі керування.

### «Що таке `auto`?»

`auto` вказує OmniRoute автоматично вибирати найкращого провайдера для кожного запиту. При цьому враховуються швидкість, вартість, якість і доступність. Докладніше див. у [Посібнику з Auto-Combo](./AUTO-COMBO-GUIDE.md).

### «Скільки це коштує?»

Сам OmniRoute є **безкоштовним програмним забезпеченням із відкритим вихідним кодом**. Ви платите лише за провайдерів, якими користуєтеся. Багато провайдерів мають безкоштовні рівні — див. [Посібник із безкоштовних рівнів](./FREE-TIERS-GUIDE.md).

### «Чи можна використовувати його з Claude Code / Cursor / Copilot?»

**Так!** OmniRoute працює з будь-яким інструментом, що підтримує формат OpenAI. Просто задайте базову URL-адресу `http://localhost:20128/v1`. Конкретні інструкції з налаштування див. у [Посібнику з інструментів CLI](../reference/CLI-TOOLS.md).

### «Що робити, якщо провайдер перестане працювати?»

OmniRoute автоматично пропускає провайдерів, у яких стався збій, і пробує наступного. Вам не потрібно нічого робити. Докладніше див. у [Посібнику з Auto-Combo](./AUTO-COMBO-GUIDE.md).
