> **Коротко**: постачальник — це підключення до сервісу ШІ (наприклад, OpenAI, Anthropic або Google). Для використання OmniRoute потрібен принаймні один постачальник.

---

## Що таке постачальник?

Уявіть постачальника як **мобільного оператора**. Так само як для здійснення дзвінків потрібен мобільний оператор, для використання моделей ШІ потрібен постачальник ШІ. OmniRoute схожий на телефон, який працює з **усіма операторами** — ви можете автоматично перемикатися між ними.

### Типи постачальників

| Тип                | Що це                                      | Приклади                          | Вартість                              |
| ------------------ | ------------------------------------------ | --------------------------------- | ------------------------------------- |
| **Безкоштовний**   | Оплата не потрібна                         | Kiro, OpenCode Free, Pollinations | $0                                    |
| **Ключ API**       | Потрібен ключ API                          | OpenAI, Anthropic, Google         | Оплата за фактичне використання       |
| **OAuth**          | Вхід за допомогою вашого облікового запису | Claude Code, GitHub Copilot       | Підписка                              |
| **Вебфайл cookie** | Використовує сеанс вашого браузера         | ChatGPT Web (Codex), Gemini Web   | $0 (використовує ваш обліковий запис) |

### Постачальники, що використовують вебфайли cookie

Загальні інструкції з налаштування, обмеження, способи усунення несправностей і настанови щодо автентифікації для окремих постачальників наведено у файлі **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**.

## Швидкий старт: підключення першого постачальника

### Необов’язкове початкове налаштування безкоштовних постачальників

Під час першого запуску майстер пропонує окрему картку **Налаштувати безкоштовних постачальників**. Він формує поточний
список доступних постачальників із реєстру постачальників OmniRoute, які не потребують автентифікації, а потім дає змогу переглянути кожного
постачальника та скасувати його вибір перед підтвердженням. OmniRoute показує застереження постачальника та посилання на його сайт,
щоб ви могли спочатку ознайомитися з умовами стороннього постачальника, політикою конфіденційності, доступністю й обмеженнями частоти запитів.

Ця дія необов’язкова: завершення роботи майстра ніколи не створює підключення до безкоштовних постачальників без вашого відома.
Він створює лише підключення до постачальників, яких іще немає, не змінює наявні налаштовані підключення
та окремо повідомляє про створених, уже налаштованих постачальників і постачальників, яких не вдалося підключити. У разі частково успішного результату ви можете
безпечно повторити спробу лише для невдалих підключень.

### Варіант A: безкоштовний постачальник (без кредитної картки)

1. Відкрийте панель керування за адресою `http://localhost:20128`
2. Перейдіть до **Постачальники** → **Додати постачальника**
3. Виберіть одного із цих безкоштовних постачальників:
   - **Kiro AI** — безкоштовні моделі Claude (автентифікація не потрібна)
   - **OpenCode Free** — безкоштовні моделі GPT (автентифікація не потрібна)
   - **Pollinations** — безкоштовні GPT-5, Claude, Gemini (ключ не потрібен)
   - **LongCat** — 10 млн безкоштовних токенів (одноразове нарахування, потрібні обліковий запис і KYC)
   - **Cloudflare AI** — понад 50 моделей, 10 тис. нейронів на день
   - **MLX Gemma 26B** — локальна модель для Apple Silicon (~38,5 токена/с, ~15,9 ГБ оперативної пам’яті)
   - **MLX Qwen 3.8 27B** — локальна модель для Apple Silicon (~9,1 токена/с, ~13,1 ГБ оперативної пам’яті)
4. Натисніть **Підключити**
5. Готово! Тепер у вас є безкоштовний доступ до ШІ.

### Варіант B: постачальник із ключем API (платний)

1. Отримайте ключ API на сайті постачальника:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Відкрийте панель керування за адресою `http://localhost:20128`
3. Перейдіть до **Постачальники** → **Додати постачальника**
4. Виберіть свого постачальника
5. Вставте свій ключ API
6. Натисніть **Підключити**
7. Готово! Тепер у вас є доступ до моделей цього постачальника.

### Варіант C: постачальник OAuth (підписка)

1. Відкрийте панель керування за адресою `http://localhost:20128`
2. Перейдіть до **Постачальники** → **Додати постачальника**
3. Виберіть свого постачальника (наприклад, Claude Code або GitHub Copilot)
4. Натисніть **Підключити через OAuth**
5. Увійдіть за допомогою свого облікового запису
6. Готово! Тепер у вас є доступ до моделей, передбачених вашою підпискою.

### Варіант D: локальні моделі MLX (Apple Silicon)

На комп’ютерах Mac з Apple Silicon та уніфікованою пам’яттю OmniRoute підтримує підключення до локальних моделей MLX, запущених через `mlx-lm.server`, як до звичайних локальних постачальників, сумісних з OpenAI.

#### Передумови

- **Mac з Apple Silicon** (M1/M2/M3/M4); рекомендовано щонайменше 24 ГБ уніфікованої пам’яті
- Менеджер пакетів **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Швидкий старт

1. **Установіть залежності**:

   ```bash
   # Установіть uv, якщо його ще не встановлено
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Установіть mlx-lm
   uv pip install mlx-lm
   ```

2. **Запустіть сервери MLX вручну** (в окремих терміналах):

   ```bash
   # Термінал 1: Gemma 4 26B A4B IT-QAT (порт 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Термінал 2: Qwen 3.8 27B MLX Mixed (порт 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Підключіть у панелі керування OmniRoute**:
   - Перейдіть до **Постачальники** → **Додати постачальника**
   - Виберіть **MLX Gemma 26B** або **MLX Qwen 3.8 27B**
   - Натисніть **Підключити** (ключ API не потрібен)

4. **Використовуйте з OpenCode**:
   ```bash
   # Налаштуйте OpenCode для використання OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Використовуйте моделі MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Керування пам’яттю

**Важливо**: за наявності 24 ГБ уніфікованої пам’яті одночасно може працювати лише **одна велика модель MLX**.

- Gemma 26B: пікове використання пам’яті ~15,9 ГБ
- Qwen 3.8 27B: пікове використання пам’яті ~13,1 ГБ

Цим потрібно керувати вручну:

- Запускайте лише один сервер MLX одночасно, або
- Запускайте обидва на різних комп’ютерах, або
- Зупиняйте один перед запуском іншого

OmniRoute не керує процесами сервера MLX автоматично — він лише спрямовує запити до налаштованих вами кінцевих точок, сумісних з OpenAI.

#### Підтримка виклику інструментів

Обидві моделі підтримують виклик інструментів, сумісний з OpenAI. Перевірте за допомогою:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "Скільки буде 2+2? Використай інструмент калькулятора."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Обчислення", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Усунення несправностей

| Проблема                      | Рішення                                                                                                    |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Сервер не запускається        | Перевірте `uv run mlx_lm.server --help` і правильність ідентифікаторів моделей                             |
| Недостатньо пам’яті           | Переконайтеся, що запущено лише одну модель; закрийте інші програми; перевірте Activity Monitor            |
| Відмовлено в підключенні      | Переконайтеся, що сервер працює на правильному порту (11435/11436)                                         |
| Повільні відповіді            | Перший запит завантажує модель у пам’ять (~30–60 с); наступні запити виконуються швидко                    |
| Виклик інструментів не вдався | Переконайтеся, що модель підтримує інструменти; перевірте журнали OmniRoute на наявність помилок перекладу |

## Як підключити провайдера (покроково)

### Крок 1: відкрийте панель керування

Перейдіть у браузері за адресою `http://localhost:20128`.

### Крок 2: перейдіть до розділу провайдерів

Натисніть **Провайдери** на бічній панелі.

### Крок 3: натисніть «Додати провайдера»

Натисніть кнопку **+ Додати провайдера**.

### Крок 4: виберіть свого провайдера

Перегляньте список або знайдіть свого провайдера через пошук. Натисніть на нього.

### Крок 5: введіть облікові дані

- **Безкоштовні провайдери**: облікові дані не потрібні — просто натисніть **Підключити**
- **Провайдери з API-ключем**: вставте свій API-ключ
- **Провайдери з OAuth**: натисніть **Підключити через OAuth** та увійдіть у систему

### Крок 6: перевірте підключення

Натисніть **Перевірити підключення**, щоб переконатися, що воно працює.

### Крок 7: готово!

Тепер вашого провайдера підключено. Ви можете використовувати його з `model: "auto"` або вказати провайдера безпосередньо.

## Використання кількох провайдерів

OmniRoute найкраще працює з **кількома провайдерами**. Це надає вам:

- **Автоматичне резервне перемикання** — якщо один провайдер не працює, OmniRoute спробує наступного
- **Оптимізацію витрат** — OmniRoute вибирає найдешевшого провайдера для кожного запиту
- **Оптимізацію швидкості** — OmniRoute вибирає найшвидшого провайдера для кожного запиту
- **Оптимізацію якості** — OmniRoute вибирає найкращого провайдера для кожного завдання

### Рекомендоване налаштування

Для найкращої роботи підключіть щонайменше **3 провайдерів**:

1. **Один безкоштовний провайдер** (Kiro, OpenCode Free або Pollinations) — завжди доступний
2. **Один швидкий провайдер** (Groq, Cerebras) — для швидких відповідей
3. **Один високоякісний провайдер** (OpenAI, Anthropic, Google) — для складних завдань

Після цього використовуйте `model: "auto"`, і OmniRoute автоматично вибиратиме найкращого провайдера для кожного запиту.

## Поширені запитання

### "Чи потрібно платити за використання OmniRoute?"

**Ні!** OmniRoute — безкоштовний проєкт із відкритим вихідним кодом. Ви можете користуватися безкоштовними провайдерами (Kiro, OpenCode Free, Pollinations), нічого не сплачуючи. Платити потрібно, лише якщо ви вирішите використовувати платних провайдерів.

### "З якого провайдера варто почати?"

Почніть із **Kiro AI** — він безкоштовний, не потребує ключа API та надає доступ до моделей Claude. Потім за потреби додайте інших провайдерів.

### "Чи можна використовувати кількох провайдерів одночасно?"

**Так!** У цьому й полягає головна ідея OmniRoute. Підключіть кількох провайдерів і використовуйте `model: "auto"`, щоб OmniRoute вибирав найкращого для кожного запиту.

### "Що робити, якщо провайдер припинить працювати?"

OmniRoute автоматично пропускає провайдерів, які не відповідають, і пробує наступного. Вам не потрібно нічого робити.

### "Як відключити провайдера?"

Перейдіть до розділу Провайдери → натисніть на провайдера → натисніть **Відключити**.

### "Чи можна використовувати наявні ключі API?"

**Так!** Якщо у вас уже є ключі API для OpenAI, Anthropic, Google тощо, ви можете використовувати їх в OmniRoute. Просто вставте їх під час підключення провайдера.
