## Категорії

- **Безкоштовні** — безкоштовний рівень з API-ключем (налаштовується через панель керування)
- **Без автентифікації** — загальнодоступні кінцеві точки, які взагалі не потребують ключа чи входу
- **OAuth** — процес входу виконується OmniRoute, API-ключ не потрібен
- **Вебcookie** — обгортає вебзастосунок провайдера з автентифікацією через cookie
- **API-ключ** — платний провайдер, налаштований за допомогою API-ключа (можуть надаватися безкоштовні кредити)
- **Локальні** — працюють на комп’ютері користувача (Ollama, LM Studio, vLLM тощо)
- **Пошук** — провайдери вебпошуку
- **Аудіо** — провайдери лише для аудіо (TTS/STT)
- **Висхідний проксі** — провайдери, які проксіюють запити до інших провайдерів
- **Хмарний агент** — довготривалі агенти для програмування (Codex Cloud, Devin, Jules)
- **Системні** — внутрішні провайдери OmniRoute (loopback тощо)

Додаткові теги: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Виклик інструментів` (якщо вказано): `native` — справжній API виклику функцій; `emulated` — масив `tools` емулюється через промпт за допомогою `webTools.ts` (блоки `<tool>{...}</tool>` розбираються регулярними виразами); `none` — наразі `tools` мовчки відкидається. Див. #7286.

Використовуйте панель керування за адресою `/dashboard/providers`, щоб увімкнути, налаштувати й протестувати кожного провайдера.
