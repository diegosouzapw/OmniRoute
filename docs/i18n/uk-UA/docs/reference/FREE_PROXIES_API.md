OmniRoute постачається з підібраним набором безкоштовних проксі в таблиці `free_proxies`,
синхронізованим із зовнішніми постачальниками (1proxy, proxifly, iplocate, webshare).
На інформаційній панелі вони доступні в розділі **Налаштування → Безкоштовні проксі**. У цьому документі
описано серверну фільтрацію, сортування, підрахунок і повідомлення про помилки синхронізації,
які надає маршрут списку.

## Маршрут списку — `GET /api/settings/free-proxies`

Повертає відфільтровану, відсортовану сторінку даних разом із загальною кількістю. Фільтрація та
підрахунок виконуються в SQL, тому інтерфейс може показувати фактичну загальну кількість (наприклад, `Усього: 0`)
без завантаження кожного рядка в пам’ять.

### Параметри запиту

| Параметр          | Тип                                | Значення за замовчуванням | Значення                                                                                                                        |
| ----------------- | ---------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | рядок                              | `""`                      | Чутливий до регістру пошук `LIKE` у стовпці хоста (і джерела).                                                                  |
| `protocol`        | рядок                              | `""`                      | Фільтр `type`: `http` / `https` / `socks4` / `socks5`. Порожнє значення = усі.                                                  |
| `country`         | рядок                              | `""`                      | Фільтр `countryCode` (ISO-2). Порожнє значення = усі.                                                                           |
| `minQuality`      | число                              | `0`                       | Лише рядки з `qualityScore >= minQuality`. `0` = без мінімального порога.                                                       |
| `disabledSources` | рядок                              | `""`                      | Ідентифікатори джерел, які потрібно виключити, розділені комами (наприклад, `proxifly,webshare`).                               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`                 | `quality` = оцінка за спаданням; `latency` = затримка за зростанням (null наприкінці); `recent` = `lastValidated` за спаданням. |
| `offset`          | число                              | `0`                       | Початок пагінації.                                                                                                              |
| `limit`           | число                              | `50`                      | Розмір сторінки (обмежується на сервері).                                                                                       |

### Відповідь

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 від зовнішнього сервісу"],
    "webshare": ["час очікування мережі вичерпано"]
  }
}
```

`total` відображає загальну кількість відфільтрованих записів **до** пагінації, тому інтерфейс може незалежно
відображати `Усього: N` і `hasMore`. `syncErrors` використовує ідентифікатор джерела як ключ і
заповнюється лише для джерел, остання синхронізація яких завершилася невдало — результат `Усього: 0`
ніколи не залишається без пояснення.

## Додавання до пулу — `POST /api/settings/free-proxies/[id]/add-to-pool`

Переносить безкоштовний проксі до керованого пулу `proxy_registry`. Спочатку перевіряє
зовнішній проксі; у разі успіху повертає ідентифікатор нового проксі в пулі та виміряну затримку.

## Синхронізація — `POST /api/settings/free-proxies/sync`

Повторно отримує дані з усіх увімкнених джерел (або з підмножини, зазначеної в `{ "sources": [...] }`). Кожне
джерело синхронізується незалежно; помилка окремого джерела записується в `syncErrors`, а
інші джерела продовжують синхронізацію, тому часткова синхронізація ніколи не видаляє раніше отримані коректні дані.

## Статистика — `GET /api/settings/free-proxies/stats`

Повертає агреговані показники `total / inPool / avgQuality / bySource / lastSyncAt`
без рядків даних — використовується віджетами заголовка інформаційної панелі.
