## Коротко — який обсяг безкоштовного інференсу насправді агрегує OmniRoute?

| Показник                                              | Токенів на місяць             | Значення                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Задокументований регулярний обсяг (сталий)**        | **~1.62B**                    | **Пули** безкоштовних рівнів (каталог для кожної моделі), кожен спільний пул враховано **один раз**. Актуальне джерело даних для `/api/free-tier/summary` і сторінки бюджету безкоштовного рівня на панелі керування. **Використовуйте це число.**                                                                                                         |
| **+ перший місяць із реєстраційними кредитами**       | **~2.22B**                    | Сталий обсяг + одноразові реєстраційні кредити (Z.AI 20M, DeepSeek 5M, …), з усуненням дублювання для кожного облікового запису. **Лише перший місяць** — не поновлюється.                                                                                                                                                                                 |
| **+ безкоштовно назавжди, без опублікованого ліміту** | _неможливо кількісно оцінити_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — реальний регулярний доступ, обмежений частотою запитів/паралельністю, **без ліміту токенів, який можна було б врахувати**. Перелічуються, але ніколи не підсумовуються (оцінювання як `RPM×24/7` — це завищення, яке ми відкидаємо). |
| **+ приріст після внесення депозиту**                 | **+~24M**                     | Одноразове поповнення OpenRouter на **$10** збільшує його безкоштовний пул із 50 до 1000 запитів на день. Наводиться окремо, щоб ніколи не завищувати сталий показник.                                                                                                                                                                                     |
| **+ після регіональної перевірки особи**              | **+~6M**                      | `modelscope` (прив’язування Alibaba Cloud + перевірка справжнього імені в материковому Китаї). Реальна регулярна квота, представлена як `gatedRecurringTokens` / `gatedProviders` і на панелі керування. Ніколи не додається до головного показника: +~6M після регіональної перевірки особи.                                                              |
| Теоретична верхня межа (усі ліміти частоти, 24/7)     | ~10B                          | Сума лімітів частоти всіх провайдерів, екстрапольована на безперервне використання. **Не гарантується** — не виносьте це в заголовок.                                                                                                                                                                                                                      |

**Чесний заголовок:** _OmniRoute агрегує **~1.62B задокументованих безкоштовних токенів на місяць** (до ~2.22B у перший місяць із реєстраційними кредитами) у 35 пулах безкоштовних рівнів — плюс довгий хвіст назавжди безкоштовних провайдерів без ліміту, — а стиснення RTK + Caveman (економія токенів на 15–95%) дає змогу використати їх ще ефективніше._

> **Чому показник знизився з попередніх ~1.94B.** Оновлення від 2026-06-17 — це виправлення задля достовірності, а не втрата: `gemini` тепер дедупліковано на рівні пулу (раніше показник був завищений через окремий підрахунок кожного варіанта Flash, 462M → 60M), `cloudflare-ai` скориговано до фактичних 10k Neurons/день (122M → 30M), `doubao` перекласифіковано як одноразовий кредит за реєстрацію (а не регулярний), а закриті рівні видалено (`chutes`/`phind`/`kluster` припинили роботу). Це частково компенсовано завдяки `llm7` (правильне значення 5M/день → 150M) і новим безкоштовним провайдерам (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Додатково скориговано до ~1.37B у v3.8.42:** `longcat` було перекласифіковано з регулярного гранту 150M/міс. на одноразовий кредит 10M за реєстрацію після завершення безкоштовного попереднього доступу. Те саме правило достовірності — жодного провайдера не було видалено помилково.
>
> **Оновлено 2026-08-26 після виведення з експлуатації Felo Web:** Felo Web виключено, поки походження/ліцензування на основі GPL залишається в статусі HOLD; на той час джерело повідомляло про 38 ключів пулу. Кількість пулів оновлюється в реальному часі та контролюється CI (`check:docs-counts` завершує збірку з помилкою, якщо наведені вище числа розходяться з `computeFreeModelTotals()`).
>
> **Повторно перевірено 2026-09-02 за власними сторінками провайдерів** (джерела: коментарі `// докази:` біля кожного повторно перевіреного запису в `open-sse/config/freeModelCatalog.data.ts`): `gemini` і `ollama-cloud` більше не публікують кількість токенів (Google видалила безкоштовну таблицю для окремих моделей 2025-12-23; безкоштовний план Ollama — це «стартові кредити на використання») і тепер зазначені як **без обмежень**, ніколи не додаються до суми (−80M); `groq` має п’ять лімітів 200K TPD **на кожну модель** (по 6M, +15M), а три виведені з експлуатації ідентифікатори видалено; `nara` — це один пул 7M/день (+60M, 210M). Значення 1B для `mistral` можна побачити лише в консолі облікового запису — див. _Класи доказів_ у розділі «Методологія».
>
> **Виправлено 2026-09-03 (#11773):** `cerebras` було перекласифіковано з регулярного гранту 30M/міс. (попередня пробна пропозиція без картки на 1M токенів/день) на одноразовий кредит $5 за реєстрацію, для якого потрібен спосіб оплати. Те саме правило достовірності, що й для LongCat.
>
> **Плюс xKiro (2026-09-03):** новий пул `xkiro-free` (150M/міс.) додає 35-й регулярний ключ пулу. Felo Web залишається виключеним, поки його походження/ліцензування на основі GPL має статус HOLD. Тепер джерело повідомляє про **35 регулярних ключів пулу** та **~1.62B стабільного обсягу** — це актуальне число, контрольоване CI (`check:docs-counts` завершує збірку з помилкою, якщо воно розходиться з `computeFreeModelTotals()`).

Найбільші **документально підтверджені** складові: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (п’ять лімітів на кожну модель), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` виключено — його грант LongCat-2.0 на 10M є одноразовим кредитом за реєстрацію, що вимагає проходження KYC, а не регулярним місячним бюджетом.)

> ⚠️ Теоретична верхня межа (~10B) завищена через провайдерів, обмежених лише швидкістю запитів і **без опублікованого ліміту токенів** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), чиї показники обчислювалися б як `RPM/TPM × 24/7 × 30d` — теоретичний максимум, який не зможе стабільно підтримувати жоден окремий обліковий запис. Їх **виключено** з обґрунтованого показника (натомість показано в рядку «назавжди безкоштовно, без ліміту»). Саме через таке завищення багатомільярдні заяви конкурентів є ненадійними.

- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` припинили роботу 2026-06-01, а `2.5 Pro` було вилучено з безкоштовного рівня (2026-04); тепер безкоштовний рівень охоплює **лише сімейство Flash** (2.5/3/3.1/3.5 Flash + Gemma). Тепер каталог **об’єднує** сімейство Flash у спільний пул (раніше показник був завищений через окремий підрахунок кожного варіанта: 462M → 60M).
- **Виправлені показники:** `cloudflare-ai` 122M → **30M** (реальні 10k Neurons/день), `doubao` перекласифіковано як одноразовий бонус за реєстрацію (а не регулярний), `llm7` 4M → **150M** (задокументовано 5M токенів/день), кінцеві точки `together` з позначкою «-Free» закрито → бонус $25 за реєстрацію також видалено (потрібна мінімальна покупка на $5, без безкоштовного пробного періоду), період Preview для `longcat` завершено + моделі Flash виведено з експлуатації → лише **LongCat-2.0**, перекласифіковано як одноразовий бонус за реєстрацію обсягом **10M** токенів (потрібне проходження KYC, бонус не регулярний).
- **Виявлено нових безкоштовних провайдерів:** ⭐ **Kilo Code** (`kilo-gateway` — змінний набір «Auto Free»: сімейство NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 змінних безкоштовних моделей для програмування), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash безкоштовні назавжди + бонус 20M за реєстрацію), а також `arcee-ai` Trinity Large Preview.
- **Нові чесні рівні** (див. Методологію): категорія _постійно безкоштовних без обмеження обсягу_ (реальний регулярний доступ без ліміту токенів, який можна було б підрахувати) та _бонус за внесення депозиту_ (OpenRouter $10 → +24M/міс.), обидві відображаються **окремо**, щоб вони ніколи не завищували головний показник.

## Два режими — підрахунок і прийняття рішень

OmniRoute відповідає на запитання «чи це безкоштовно?» за допомогою двох режимів, які навмисно використовують
різні джерела:

| Режим                         | Джерело істини                                                                                                                                                                 | Де використовується                                                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Підрахунок / відображення** | Розгорнутий каталог — базова версія постачання з накладеними даними стрічки Radar (`getRadarCatalog`)                                                                          | Підсумки безкоштовного рівня, картка бюджету, інформаційні панелі                                                                         |
| **Прийняття рішень**          | Лише каталог постачання (`FREE_MODEL_BUDGETS` у `open-sse/config/freeModelCatalog.data.ts`) разом із локальними евристиками (суфікс `:free`, нульова ціна, `grantsFreeAccess`) | Усі споживачі `src/shared/utils/freeModels.ts`: імпорт моделей, маршрутизація `auto/*`, `GET /v1/models` і попередні перегляди у браузері |

Підрахунок може покращуватися щоразу, коли доступна стрічка даних. Прийняття рішень залишається прив’язаним до
артефакту релізу, тому відповідь є однаковою у браузері та на сервері,
відтворюваною офлайн і придатною до тестування без бази даних. Якби попередній
перегляд у браузері використовував одне джерело, а імпорт на сервері — інше, попередній
перегляд не відповідав би тому, що відбувається після натискання, — цей поділ збережено
навмисно.

## Методологія та застереження

- Числа є **оцінками верхньої межі**, отриманими з документованих обмежень безкоштовного рівня кожного постачальника станом на **2026-06-17** шляхом вебдослідження. Безкоштовні рівні постійно змінюються — перевіряйте дані повторно, перш ніж покладатися на певне значення.
- **Що насправді засвідчує запис.** Жоден запис не має окремої оцінки достовірності на рівні рядка, і API її не надає — розглядайте кожне наведене вище значення як оцінку однакової, не вказаної явно якості. Два факти відрізняються, оскільки їх перевірено вручну, а не отримано шляхом логічного висновку: 44 записи мають незалежно задокументоване жорстке припинення обслуговування (39 із них — рядки xKiro, які мають однаковий добовий ліміт), а 13 записів містять розкриття інформації про навчання на запитах. `hardStopGuaranteed` встановлюється лише тоді, коли у власних умовах постачальника зазначено, що перевищення безкоштовного ліміту призводить до відхилення запиту, а не до непомітного початку тарифікації, із джерелом у коментарі поруч із записом; для нього ніколи не встановлюється значення `true` за замовчуванням, а в неперевіреному записі це поле залишається невстановленим. Тож відсутність прапорця жорсткого припинення означає «не встановлено», а не «відомо, що з вас стягуватимуть плату». **Режим STRICT** (захисний механізм маршрутизації `freeAccessPolicy=strict`, який потрібно ввімкнути явно) довіряє лише записам із цим прапорцем; усі інші безкоштовні рівні виключаються як `no-hard-stop` (див. `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Коли захисний механізм фільтрує пул, у видимому оператору журналі зазначаються як кількість виключень, так і частка `no-hard-stop` серед них.
- `estMonthlyFreeTokens` = лише щомісячні токени, що поновлюються. **Одноразові кредити за реєстрацію не поновлюються** й враховуються як 0. Припинені рівні також враховуються як 0.
- Добовий ліміт токенів → `monthly = daily × 30`. Якщо задокументовано лише RPD → `RPD × ~800 вихідних токенів × 30`. Якщо є лише RPM/TPM (без добового ліміту) → **без обмеження** (див. нижче).
- **Назавжди безкоштовні, але без опублікованого ліміту токенів** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): це справжній регулярний безкоштовний доступ, обмежений частотою запитів або кількістю одночасних операцій. Ми класифікуємо їх як `recurring-uncapped` і **ніколи не додаємо до загальної суми** — множення `RPM × 24/7 × 30d` дало б фантастичну верхню межу (саме таке завищення ми відкидаємо). Їх наведено, щоб ви знали про їхнє існування.
- **Підвищення після внесення депозиту:** невелике одноразове поповнення, яке назавжди збільшує безкоштовну квоту (OpenRouter: $10 → 1000 запитів/день ≈ +24M/місяць). Подається як окреме значення й не включається до основного стабільного показника.
- **Квоти з обмеженням за відповідністю вимогам** (`eligibilityGate: "regional-identity"`): справжня регулярна квота, яка стає доступною лише після перевірки особи, прив’язаної до певного регіону (наразі — перевірка справжнього імені в материковому Китаї). Враховується за тим самим правилом усунення дублікатів у пулі в окремому показнику (`gatedRecurringTokens`) і ніколи не включається до основного стабільного показника. Режим (`freeType`) не змінюється, тому маршрутизація також не змінюється.
- **Класи доказів.** Правило: число в каталозі має посилання на джерело в коментарі `// evidence:` поруч із записом — `public-page` (сторінка постачальника, доступна будь-кому), `api-public` (ендпоінт постачальника без автентифікації, наприклад загальнодоступний ендпоінт планів NaraRouter за адресою router.bynara.id) або `console-verified <date> por <who>` (значення доступне лише в консолі облікового запису; у коментарі вказано, хто й коли його бачив, а також наведено загальнодоступну сторінку, де сказано про існування ліміту). Поточний стан: п’ять блоків, повторно перевірених 2026-09-02, містять його (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); записи, створені до повторної перевірки 2026-09-02, успадковують результати попереднього дослідження, доки їх не буде змінено; будь-яке **нове або змінене** число без коментаря з доказом є помилкою. Наразі лише `mistral` має статус `console-verified`.

## Чому наше число менше, ніж в інших агрегаторів

Більшість показників «безкоштовних токенів на місяць» у цій сфері є сумами лімітів для окремих моделей. Наш показник навмисно розраховується інакше:

- **Кожен спільний пул враховується один раз.** Безкоштовний план Mistral передбачає один ліміт у 1B на місяць для кожної організації; зазначення цього ліміту для п’яти моделей не перетворює його на 5B. Якщо підсумувати ліміти для кожної моделі, наш власний каталог показував би **~7.4B** (перераховано 2026-09-03; цей показник не контролюється CI — перераховуйте його щоразу, коли змінюється каталог), але в заголовку зазначено **~1.47B**, оскільки саме стільки фактично може витратити один обліковий запис у кожного провайдера.
- **Добові ліміти перераховуються, а обмеження швидкості — ні.** Задокументований ліміт токенів на день перетворюється на `× 30`; задокументований ліміт запитів на день — на `RPD × ~800 токенів × 30`; провайдер, який публікує лише кількість запитів за хвилину, **не має** місячного показника та позначається як _безлімітний_ і ніколи не додається до суми. Множення обмеження швидкості на цілодобове використання — це завищення, від якого ми відмовляємося.
- **Квоти, доступні лише після регіональної перевірки особи, показуються окремо** (`+~6M після регіональної перевірки особи`), оскільки більшість читачів не може ними скористатися.
- **Кредити за реєстрацію діють лише протягом першого місяця** та відображаються як окремий другий показник, ніколи не поєднуючись зі сталим показником.
- **Відповідність показника забезпечується CI.** `npm run check:docs-counts` перераховує підсумки з каталогу та завершує збірку помилкою, якщо цей файл, README або картка бюджету перестають їм відповідати.

## Таблиця застережень щодо ToS

> **Позначка ToS має рекомендаційний характер і не є обмеженням маршрутизації.** Провайдери з позначкою `tos` за замовчуванням усе одно включаються до маршрутизації та комбінацій/резервних варіантів; позначка лише відображається на `/dashboard/free-tiers` і `/api/free-tier/summary`. Параметр запиту `excludeTosAvoid` впливає лише на зведене представлення, а не на глобальну маршрутизацію. Висновок міститься в `open-sse/config/freeTierCatalog.ts` (має інформаційний характер і не зчитується рушіями маршрутизації).

> Короткий огляд умов кожного провайдера щодо самостійно розміщеного особистого проксі для одного користувача. `caution` = умова щодо особистого використання або проксі, яку варто перевірити; `ambiguous` = незрозуміло; `ok` = явно дозволено. Інформація не є юридичною консультацією — рішення ухвалюєте ви.

## Глосарій

| Термін                  | Значення                                                                      |
| ----------------------- | ----------------------------------------------------------------------------- |
| **RPM / RPD / RPH**     | Запити за хвилину / день / годину                                             |
| **TPM / TPD**           | Токени за хвилину / день                                                      |
| **Документована квота** | Провайдер публікує явний денний/місячний ліміт токенів (обґрунтований бюджет) |
| **Теоретична межа**     | `rate-limit × 24/7 × 30d` — максимум, а не гарантований бюджет                |
| **Нейрон**              | Одиниця обчислювальних ресурсів Cloudflare (~1 вихідний токен)                |
