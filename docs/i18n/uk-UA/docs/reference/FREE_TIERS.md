> **Для користувачів**: Шукаєте простий посібник? Покрокові інструкції щодо отримання безкоштовного ШІ див. у [Посібнику з безкоштовних рівнів](../getting-started/FREE-TIERS-GUIDE.md).

> **Останнє дослідження:** 2026-06-17 — вебдослідження для кожного провайдера (офіційна документація + новини за останні 7 днів, прохід 50 агентами з перевіркою на стійкість до помилок), у межах якого оновлено всі квоти безкоштовних рівнів і Умови надання послуг. **Частковий повторний аудит 2026-09-02** (`gemini`, `ollama-cloud`, `groq`, `nara`, `mistral` — див. датовану примітку нижче).
> **Джерело істини (каталог):** `open-sse/config/freeModelCatalog.ts` (бюджети для кожної МОДЕЛІ з усуненням дублікатів пулів). Наведені нижче дані про бюджет токенів отримано в результаті актуального вебдослідження, і вони є **приблизними** — див. [Методологію та застереження](#methodology--caveats).

## TL;DR — скільки безкоштовного інференсу насправді агрегує OmniRoute?

| Метрика                                               | Токенів / місяць                  | Значення                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------------------------------- | --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Задокументована регулярна квота (стала)**           | **~1.62B**                        | Безкоштовні **пули** (за каталогом моделей), кожен спільний пул враховано **один раз**. Актуальне джерело для `/api/free-tier/summary` і сторінки «Бюджет безкоштовного рівня» на інформаційній панелі. **Використовуйте це число.**                                                                                                                           |
| **+ перший місяць із кредитами за реєстрацію**        | **~2.22B**                        | Стала квота + одноразові кредити за реєстрацію (Z.AI 20M, DeepSeek 5M, …), дедупліковані для кожного облікового запису. **Лише перший місяць** — не поновлюються.                                                                                                                                                                                              |
| **+ постійно безкоштовні, без опублікованого ліміту** | _не піддається кількісній оцінці_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — реальний регулярний доступ, обмежений частотою запитів/паралельністю, **без ліміту токенів, який можна було б порахувати**. Перелічуються, але ніколи не підсумовуються (їх підрахунок як `RPM×24/7` — це завищення, яке ми відкидаємо). |
| **+ збільшення після внесення коштів**                | **+~24M**                         | Одноразове поповнення OpenRouter на **$10** збільшує його безкоштовний пул із 50 → 1000 запитів/день. Зазначається окремо, щоб ніколи не завищувати сталий показник.                                                                                                                                                                                           |
| **+ після регіональної перевірки особи**              | **+~6M**                          | `modelscope` (прив’язування Alibaba Cloud + перевірка справжнього імені в материковому Китаї). Реальна регулярна квота, представлена як `gatedRecurringTokens` / `gatedProviders` і на інформаційній панелі. Ніколи не додається до головного показника: +~6M після регіональної перевірки особи.                                                              |
| Теоретична межа (усі обмеження частоти, 24/7)         | ~10B                              | Сума обмежень частоти всіх провайдерів, екстрапольована на безперервне використання. **Не є гарантією** — не виносьте це в заголовок.                                                                                                                                                                                                                          |

**Чесний заголовок:** _OmniRoute агрегує **~1.62B задокументованих безкоштовних токенів на місяць** (до ~2.22B у перший місяць із кредитами за реєстрацію) у 35 пулах безкоштовного рівня — плюс довгий хвіст постійно безкоштовних провайдерів без ліміту, — а стиснення RTK + Caveman (економія токенів на 15–95%) дає змогу використати їх ще ефективніше._

> **Чому цей показник знизився з попередніх ~1.94B.** Оновлення від 2026-06-17 — це виправлення задля чесності, а не втрата: `gemini` тепер дедупліковано на рівні пулу (раніше показник був завищений через окремий підрахунок кожного варіанта Flash, 462M → 60M), `cloudflare-ai` скориговано до фактичних 10k Neurons/день (122M → 30M), `doubao` перекласифіковано як одноразовий кредит за реєстрацію (а не регулярний), а закриті рівні видалено (`chutes`/`phind`/`kluster` припинили роботу). Це частково компенсовано `llm7` (правильні 5M/день → 150M) і новими безкоштовними провайдерами (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Додатково скориговано до ~1.37B у v3.8.42:** `longcat` було перекласифіковано з регулярної квоти 150M/міс. на одноразовий кредит за реєстрацію в розмірі 10M після завершення безкоштовного попереднього доступу. Те саме правило чесності — жодного провайдера не було видалено помилково.
>
> **Оновлено 2026-08-26 після виведення Felo Web з експлуатації:** Felo Web виключено, поки походження/ліцензування похідного від GPL коду залишається в статусі HOLD; на той момент джерело повідомляло про 38 ключів пулів. Кількість пулів оновлюється в реальному часі та контролюється CI (`check:docs-counts` спричиняє збій збірки, якщо наведені вище числа розходяться з `computeFreeModelTotals()`).
>
> **Повторно перевірено 2026-09-02 за власними сторінками провайдерів** (джерела: коментарі `// evidence:` біля кожного повторно перевіреного запису в `open-sse/config/freeModelCatalog.data.ts`): `gemini` і `ollama-cloud` більше не публікують кількість токенів (Google видалив безкоштовну таблицю для окремих моделей 2025-12-23; безкоштовний план Ollama — це «початкові кредити на використання») і тепер перелічуються як **безлімітні**, ніколи не підсумовуючись (−80M); `groq` має п’ять **окремих для кожної моделі** лімітів по 200K-TPD (по 6M кожен, +15M), а три виведені з експлуатації ідентифікатори видалено; `nara` — це один пул на 7M/день (+60M, 210M). 1B від `mistral` видно лише в консолі облікового запису — див. _Класи доказів_ у розділі «Методологія».
>
> **Скориговано 2026-09-03 (#11773):** `cerebras` було перекласифіковано з регулярної квоти 30M/міс. (старий пробний період без картки з 1M токенів/день) на одноразовий кредит за реєстрацію в розмірі $5, для якого потрібен спосіб оплати. Те саме правило чесності, що й для LongCat.
>
> **А також xKiro (2026-09-03):** новий пул `xkiro-free` (150M/міс.) додає 35-й ключ регулярного пулу. Felo Web залишається виключеним, поки походження/ліцензування похідного від GPL коду перебуває в статусі HOLD. Тепер джерело повідомляє про **35 ключів регулярних пулів** і **~1.62B сталої квоти** — актуальний показник, контрольований CI (`check:docs-counts` спричиняє збій збірки, якщо він розходиться з `computeFreeModelTotals()`).

Найбільші **задокументовані** внески: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (п’ять окремих лімітів для моделей), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` виключено — його квота LongCat-2.0 у розмірі 10M є одноразовим кредитом за реєстрацію з обов’язковою KYC-перевіркою, а не регулярним місячним бюджетом.)

> ⚠️ Теоретична верхня межа (~10B) завищена через провайдерів, які обмежують лише частоту запитів і **не публікують обмеження на кількість токенів** (`tencent`, `siliconflow`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), чиї показники обчислювалися б як `RPM/TPM × 24/7 × 30d` — це теоретичний максимум, який не зможе стабільно підтримувати жоден окремий обліковий запис. Їх **виключено** з обґрунтованого показника (натомість наведено в рядку «назавжди безкоштовно, без обмежень»). Саме таке завищення робить заяви конкурентів про багатомільярдні показники ненадійними.

## Оновлення від 2026-06-17 — що змінилося з 2026-06-05

Увесь каталог було оновлено в межах вебдослідження за участю 50 агентів (офіційна документація + новини за останні 7 днів, перевірені з урахуванням потенційних суперечностей). Основне:

- **Видалено / немає безкоштовного рівня (2026):** `chutes` (безкоштовний рівень припинив діяти 2026-03), `phind` (компанія припинила роботу 2026-01), `kluster` (закрито 2026-06-09 → MITO), `gitlawb` + `gitlawb-gmi` (безкоштовний доступ до MiMo скасовано 2026-05-24, промоакція Nemotron завершилася 2026-06 — повторно перевірено 2026-06-18), `aimlapi` (безкоштовний рівень призупинено — повторно перевірено 2026-06-18), `yi` (Yi-Light виведено з експлуатації, оплата за фактом використання — повторно перевірено 2026-06-18), `featherless-ai` (наразі немає безкоштовного рівня), `chipotle` («Pepper AI» від Chipotle — віджет чату Amelia на `amelia.chipotle.com`, відтворений методом зворотної розробки, з яким взаємодіяв провайдер, тепер повертає 404 для кожного маршруту, включно з кореневим; бекенд виведено з експлуатації або перенесено, підтверджено 2026-09-15 — повністю видалено з каталогу, #13131/#4037). `iflytek` / `sparkdesk` залишаються в переліку, але мають примітку із застереженням щодо умов використання (Spark Lite безкоштовний; умови використання обмежують застосування проксі/ретрансляції).
- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` припинили роботу 2026-06-01, а `2.5 Pro` залишив безкоштовний рівень (2026-04); тепер на безкоштовному рівні доступна **лише родина Flash** (2.5/3/3.1/3.5 Flash + Gemma). Тепер каталог **об’єднує в один пул** родину Flash (раніше показник був завищений через окремий підрахунок кожного варіанта: 462M → 60M).
- **Виправлені показники:** `cloudflare-ai` 122M → **30M** (реальні 10 тис. нейронів на день), `doubao` перекласифіковано як одноразовий бонус за реєстрацію (а не регулярний), `llm7` 4M → **150M** (задокументовані 5M токенів на день), кінцеві точки `together` «-Free» закрито → бонус $25 за реєстрацію також видалено (потрібна мінімальна покупка на $5, безкоштовного пробного періоду немає), попередній перегляд `longcat` завершено, а моделі Flash виведено з експлуатації → залишилася лише **LongCat-2.0**, перекласифікована як одноразовий бонус за реєстрацію в розмірі **10M** токенів (потрібне проходження KYC, бонус не є регулярним).
- **Виявлено нових безкоштовних провайдерів:** ⭐ **Kilo Code** (`kilo-gateway` — ротаційний набір «Auto Free»: родина NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 6 ротаційних безкоштовних моделей для програмування), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash постійно безкоштовні + бонус 20M за реєстрацію), а також Trinity Large Preview від `arcee-ai`.
- **Нові прозорі категорії** (див. Методологію): категорія _постійно безкоштовних, але без установленого ліміту_ (реальний регулярний доступ без обмеження кількості токенів для підрахунку) і _збільшення ліміту після внесення депозиту_ (OpenRouter $10 → +24M/міс.), обидві відображаються **окремо**, щоб вони ніколи не завищували головний показник.

> Детальна таблиця за кожним провайдером нижче є **знімком станом на 2026-06-05**; наведені вище зміни мають вищий пріоритет. Актуальним канонічним джерелом є каталог за моделями `open-sse/config/freeModelCatalog.ts`.

## Два режими — підрахунок і визначення

OmniRoute відповідає на запитання «чи це безкоштовно?» за допомогою двох режимів, які навмисно використовують
різні джерела:

| Режим                         | Джерело істини                                                                                                                                                                    | Сфери застосування                                                                                                                        |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Підрахунок / відображення** | Сформований каталог — базова версія з постачання, доповнена даними Radar (`getRadarCatalog`)                                                                                      | Загальні показники безкоштовного рівня, картка бюджету, інформаційні панелі                                                               |
| **Визначення**                | Лише каталог із постачання (`FREE_MODEL_BUDGETS` у `open-sse/config/freeModelCatalog.data.ts`) разом із локальними евристиками (суфікс `:free`, нульова ціна, `grantsFreeAccess`) | Усі споживачі `src/shared/utils/freeModels.ts`: імпорт моделей, маршрутизація `auto/*`, `GET /v1/models` і попередній перегляд у браузері |

Підрахунок може ставати точнішим щоразу, коли доступний канал даних. Визначення залишається прив’язаним до
артефакту релізу, тому відповідь однакова в браузері та на сервері,
відтворюється офлайн і може тестуватися без бази даних. Якби попередній
перегляд у браузері використовував одне джерело, а серверний імпорт — інше, це призвело б до того,
що попередній перегляд не відповідав би фактичному результату після натискання — такий поділ збережено
навмисно.

## Методологія та застереження

- Числа є **оцінками верхньої межі**, отриманими з документованих обмежень безкоштовного рівня кожного постачальника станом на **2026-06-17** і зібраними шляхом вебдослідження. Безкоштовні рівні постійно змінюються — перевіряйте дані повторно, перш ніж покладатися на певне значення.
- **Що насправді засвідчує кожен запис.** Жоден запис не має окремої оцінки достовірності, і API також її не надає — вважайте кожне наведене вище значення оцінкою однакової, не зазначеної явно якості. Два факти відрізняються, оскільки їх перевіряють вручну, а не визначають опосередковано: 44 записи мають незалежно задокументоване жорстке припинення обслуговування (39 із них — рядки xKiro, які використовують однаковий добовий ліміт), а 13 записів містять розкриття інформації щодо навчання на промптах. `hardStopGuaranteed` встановлюється лише тоді, коли у власних умовах постачальника зазначено, що перевищення безкоштовного ліміту призводить до відхилення запиту, а не до непомітного початку виставлення рахунків; джерело вказується в коментарі поруч із записом. Значення ніколи не встановлюється як `true` за замовчуванням, а в неперевіреному записі воно залишається невстановленим. Отже, відсутність позначки жорсткого припинення означає «не встановлено», а не «відомо, що з вас стягуватимуть плату». **Режим STRICT** (необов’язковий захист маршрутизації `freeAccessPolicy=strict`) довіряє лише записам із цією позначкою; усі інші безкоштовні рівні виключаються як `no-hard-stop` (див. `open-sse/services/autoCombo/strictZeroCostFilter.ts`).
- `estMonthlyFreeTokens` = лише регулярні щомісячні токени. **Одноразові кредити за реєстрацію не поновлюються** й зараховуються як 0. Припинені рівні також зараховуються як 0.
- Добовий ліміт токенів → `monthly = daily × 30`. Якщо задокументовано лише RPD → `RPD × ~800 вихідних токенів × 30`. Якщо є лише RPM/TPM (без добового ліміту) → **без обмеження** (див. нижче).
- **Постійно безкоштовно, але без опублікованого ліміту токенів** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): це реальний регулярний безкоштовний доступ, обмежений швидкістю запитів або паралелізмом. Ми класифікуємо його як `recurring-uncapped` і **ніколи не додаємо до загальної суми** — множення `RPM × 24/7 × 30d` дало б фантастичну верхню межу (саме таке завищення ми відкидаємо). Ці варіанти наведено, щоб ви знали про їхнє існування.
- **Збільшення після внесення депозиту:** невелике одноразове поповнення, яке назавжди підвищує безкоштовну квоту (OpenRouter: $10 → 1000 запитів на день ≈ +24 млн/міс.). Подається як окреме значення й не включається до основного показника стабільної квоти.
- **Квоти з обмеженнями щодо відповідності вимогам** (`eligibilityGate: "regional-identity"`): реальна регулярна квота, яка стає доступною лише після перевірки особи, прив’язаної до певного регіону (нині — перевірка справжнього імені в материковому Китаї). Враховується за тим самим правилом усунення дублікатів пулів в окремому показнику (`gatedRecurringTokens`) і ніколи не включається до основного показника стабільної квоти. Режим (`freeType`) залишається незмінним, тому маршрутизація також не змінюється.
- **Класи доказів.** Правило: число в каталозі посилається на своє джерело в коментарі `// evidence:` поруч із записом — `public-page` (сторінка постачальника, доступна для читання будь-кому), `api-public` (неавтентифікована кінцева точка постачальника, наприклад загальнодоступна кінцева точка планів NaraRouter за адресою router.bynara.id) або `console-verified <date> por <who>` (значення видно лише в консолі облікового запису; у коментарі зазначено, хто й коли його бачив, а також наведено загальнодоступну сторінку, на якій сказано, що ліміт існує). Поточний стан: п’ять блоків, повторно перевірених 2026-09-02, містять такий коментар (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); записи, створені до повторної перевірки 2026-09-02, успадковують результати попереднього дослідження, доки їх не буде змінено; будь-яке **нове або змінене** число без коментаря з доказом є помилкою. Наразі лише `mistral` підтверджено через консоль.

## Чому наше число менше, ніж в інших агрегаторів

Більшість показників «безкоштовних токенів на місяць» у цій сфері є сумами лімітів для окремих моделей. Наш показник навмисно розраховується інакше:

- **Кожен спільний пул враховується один раз.** Безкоштовний план Mistral надає один ліміт у 1B/місяць на організацію; зазначення його для п’яти моделей не перетворює його на 5B. Якщо підсумувати за моделями, наш власний каталог показував би **~7.4B** (перераховано 2026-09-03; цей показник не перевіряється CI — перераховуйте його щоразу, коли змінюється каталог), але в заголовку зазначено **~1.47B**, оскільки саме стільки фактично може витратити один обліковий запис у кожного провайдера.
- **Добові обмеження конвертуються, обмеження швидкості — ні.** Задокументований ліміт токенів на день перетворюється на `× 30`; задокументований ліміт запитів на день — на `RPD × ~800 токенів × 30`; якщо провайдер публікує лише кількість запитів за хвилину, для нього **немає** місячного показника й він зазначається як _без обмеження_, але ніколи не додається до суми. Множення обмеження швидкості на режим 24/7 — це завищення, від якого ми відмовляємося.
- **Квоти, доступні після регіональної перевірки особи, показуються окремо** (`+~6M після регіональної перевірки особи`), оскільки більшість читачів не може ними скористатися.
- **Кредити за реєстрацію діють лише протягом першого місяця** й зазначаються як окремий другий показник, ніколи не змішуючись зі стабільним показником.
- **Коректність показника забезпечується CI.** `npm run check:docs-counts` повторно обчислює підсумки з каталогу та спричиняє помилку збірки, якщо значення в цьому файлі, README або картці бюджету перестають їм відповідати.

## Таблиця застережень щодо Умов використання

> **Позначка ToS має рекомендаційний характер і не є обмеженням маршрутизації.** Провайдери з позначкою `tos` за замовчуванням усе одно включаються до маршрутизації та комбінацій/резервних варіантів; позначка відображається лише на `/dashboard/free-tiers` і `/api/free-tier/summary`. Параметр запиту `excludeTosAvoid` впливає лише на зведене представлення, а не на глобальну маршрутизацію. Висновок міститься в `open-sse/config/freeTierCatalog.ts` (має інформаційний характер і не зчитується механізмами маршрутизації).

> Короткий огляд умов кожного провайдера щодо самостійно розгорнутого персонального проксі для одного користувача. `caution` = варто перевірити положення про особисте використання або проксі; `ambiguous` = неоднозначно; `ok` = явно дозволено. Інформація має довідковий характер і не є юридичною консультацією — рішення ухвалюєте ви.

## Глосарій

| Термін                   | Значення                                                                       |
| ------------------------ | ------------------------------------------------------------------------------ |
| **RPM / RPD / RPH**      | Запити за хвилину / день / годину                                              |
| **TPM / TPD**            | Токени за хвилину / день                                                       |
| **Документований ліміт** | Провайдер публікує чіткий денний/місячний ліміт токенів (обґрунтований бюджет) |
| **Теоретична межа**      | `rate-limit × 24/7 × 30d` — максимум, а не гарантований бюджет                 |
| **Нейрон**               | Одиниця обчислень Cloudflare (~1 вихідний токен)                               |
