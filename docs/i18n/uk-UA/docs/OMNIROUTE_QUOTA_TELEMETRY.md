OmniRoute відокремлює телеметрію квот постачальника від обліку Ghostlight.

## Достовірні стани

- `healthy` означає, що джерело повідомило про наявність доступного залишку ресурсу.
- `approaching_limit` означає, що джерело повідомило про залишок ресурсу на рівні налаштованого порогового значення або нижче нього.
- `exhausted` повертається лише тоді, коли джерело повідомляє про нульовий залишок ресурсу або про використання на рівні ліміту.
- `unavailable` означає, що підтримуване джерело не змогло повернути дані.
- `unknown` означає, що підтримуваного джерела немає або ліміт постачальника невідомий.

Невідомий стан не означає вичерпання й не вимикає постачальника.

Джерела мають такий порядок пріоритетності: офіційний API постачальника, автентифікований API використання, явно зіставлені заголовки відповіді, конфігурація адміністратора, локальні оцінки, невідомий стан. Локальні оцінки ніколи не подаються як дані постачальника для виставлення рахунків.

Заголовки відповіді аналізуються лише відповідно до явного зіставлення для конкретного постачальника. Не вважається, що загальні назви заголовків застосовуються глобально.
