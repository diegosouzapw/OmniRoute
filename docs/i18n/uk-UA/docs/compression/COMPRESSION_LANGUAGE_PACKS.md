Стиснення Caveman може завантажувати набори правил для певних мов на додачу до вбудованих правил англійської мови.
Це дає змогу зберігати стабільність основного рушія, водночас дозволяючи наборам правил для португальської, іспанської, німецької, французької, італійської, японської та
майбутніх мов розвиватися незалежно.

## Розташування

Мовні пакети розташовані в:

```txt
open-sse/services/compression/rules/<language>/
```

Пакети, що наразі постачаються (перевірено за вмістом каталогу `rules/`):

| Мова                     | Каталог        | Наявні категорії правил                             |
| ------------------------ | -------------- | --------------------------------------------------- |
| Англійська               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Іспанська                | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Португальська (Бразилія) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Індонезійська            | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Італійська               | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Німецька                 | `rules/de/`    | `context`, `filler`, `structural`                   |
| Французька               | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Японська                 | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Примітка щодо паритету:** пакети `en`, `es`, `pt-BR`, `id` та `it` мають повний набір із 5 категорій; `de`, `fr` і `ja` постачаються з 3 категоріями. Для відсутніх категорій `dedup` та `ultra` автоматично й без сповіщень використовуються вбудовані правила англійської мови. Запрошуємо долучатися до додавання `dedup.json` та `ultra.json` для менших пакетів.
>
> Пакет `pt-BR` базується на **[Troglodita](https://github.com/leninejunior/troglodita)** авторства Lenine Júnior — системі стиснення, створеній із нуля для граматики бразильського варіанта португальської мови (скорочення плеоназмів, видалення слів-заповнювачів PT-BR, технічні скорочення для бразильської спільноти розробників).
>
> Канонічний список категорій і схема кожної категорії містяться у файлі [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema, чернетка 2020-12).

## Визначення мови

`languageDetector.ts` використовує легкі евристики для визначення мови за текстом запиту. Налаштована
мова за замовчуванням усе одно враховується, а визначення можна вимкнути в конфігурації, якщо потрібен
точний контроль.

Результат визначення використовується лише для вибору наборів правил. Він не змінює маршрутизацію провайдера, вибір
локалі чи мову інтерфейсу користувача.

## Структура конфігурації

Налаштування стиснення можуть містити:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` керує налаштуваннями за замовчуванням для панелі керування та попереднього перегляду. `cavemanConfig` — це конфігурація рушія під час виконання,
яка використовується, коли Caveman стискає текст повідомлення.

## Додавання мовного пакета

1. Створіть `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Використовуйте формат правил Caveman із `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Застосовуйте заміни обережно й не змінюйте код, ідентифікатори, URL-адреси або JSON.
4. Додайте або оновіть тести для вибору мови та поведінки замін.
5. Додайте нові мітки для панелі керування/i18n, якщо мова відображається в селекторах інтерфейсу.

## API

Доступні пакети можна отримати за допомогою:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Кінцева точка попереднього перегляду приймає перевизначення конфігурації мови:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Усі 6 мовних пакетів у v3.8.0 отримали положення `SHARED_BOUNDARIES`, яке застосовується за кожного
рівня інтенсивності Caveman (LITE, FULL, ULTRA). Воно вказує рушію зберігати ці шаблони без змін,
незалежно від видалення навколишніх слів-заповнювачів:

| Тип шаблону                            | Приклад                                |
| -------------------------------------- | -------------------------------------- |
| Огороджені блоки коду                  | ` ```python\n...\n``` `                |
| Вбудований код                         | `` `my_var` ``                         |
| URL-адреси                             | `https://example.com/path`             |
| Шляхи до файлів (абсолютні + відносні) | `/etc/hosts`, `./src/index.ts`         |
| Заголовки помилок                      | `Error:`, `TypeError:`, `SyntaxError:` |
| Рядки трасування стека                 | `  at functionName (file.ts:12:3)`     |

Ці шаблони заповнюються в `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (раніше `[]`). Ця
константа міститься в `open-sse/services/compression/types.ts`.

### Чому це важливо

Без SHARED_BOUNDARIES агресивні режими Caveman могли видаляти вміст, який виглядав як повторюваний
текст, але насправді був фрагментом коду, шляхом до файлу або стеком помилок. SHARED_BOUNDARIES діє як
незалежний від мови захисний механізм, що застосовується перед виконанням правил видалення слів-заповнювачів.

### Налаштування preservePatterns

Додаткові шаблони можна додавати під час виконання через налаштування стиснення:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Користувацькі шаблони розширюють (а не замінюють) 6 стандартних шаблонів.

## Примітки щодо експлуатації

- Вбудовані правила для англійської мови залишаються резервним варіантом, якщо мовний пакет відсутній.
- Недійсні вбудовані JSON-пакети не проходять перевірку, щоб не допустити непомітного погіршення ресурсів випуску.
- Пакети правил містять лише дані й не повинні імпортувати код або виконувати довільну логіку.
- Рівень аналітики стиснення записує вибрані режим і рушій, але не повний текст запиту.
