## اخراجات کا حصہ (نیا، سطح 1)

پاتھ کا سابقہ: `/dashboard/costs/`

| آئٹم          | URL                                  | وضاحت                                            |
| ------------- | ------------------------------------ | ------------------------------------------------ |
| جائزہ         | `/dashboard/costs`                   | مجموعی اخراجات کا ڈیش بورڈ (تجزیات سے منتقل شدہ) |
| قیمتیں        | `/dashboard/costs/pricing`           | ہر ماڈل کی قیمتوں کا جدول                        |
| بجٹ           | `/dashboard/costs/budget`            | بجٹ کی حدیں + انتباہات                           |
| کوٹا شیئرنگ   | `/dashboard/costs/quota-share`       | کوٹا شیئر پولز + استعمال                         |

مشاہداتی ٹولنگ میں نیویگیٹ کیے بغیر انہیں تلاش کرنا آسان ہو جاتا ہے۔

## نگرانی کا حصہ (ازسرِنو منظم)

نگرانی کے حصے میں اب سب سے اوپر **سرگرمی** ہے، جس کے بعد **3 ذیلی گروپس** ہیں:

```
نگرانی
├── سرگرمی             ← ٹائم لائن فیڈ (اعلیٰ سطحی آئٹم)
├── لاگز گروپ
│   ├── لاگز (تمام)
│   ├── پراکسی لاگز
│   └── کنسول لاگز
├── آڈٹ گروپ
│   ├── آڈٹ لاگ
│   ├── MCP آڈٹ
│   └── A2A آڈٹ
└── سسٹم گروپ
    ├── صحت
    └── رن ٹائم
```

### پرانے ڈھانچے کے مقابلے میں کیا تبدیل ہوا

| پہلے                                                                  | بعد میں                                    |
| --------------------------------------------------------------------- | ------------------------------------------ |
| سرگرمی = لاگز کے اندر ایک ٹیب جو آڈٹ لاگ دکھاتا تھا                   | سرگرمی = مخصوص فیڈ (`/dashboard/activity`) |
| نگرانی میں اخراجات کے پیرامیٹرز کا گروپ                               | اخراجات کے حصے میں منتقل کر دیا گیا        |
| سادہ فہرست: لاگز، سرگرمی (لاگز)، آڈٹ، صحت، رن ٹائم، قیمتیں، بجٹ، کوٹا | منظم 3 گروپس + اخراجات کا مخصوص حصہ        |

## سرگرمی بمقابلہ آڈٹ لاگ

اب یہ دونوں الگ ہیں:

| پہلو                  | سرگرمی (`/dashboard/activity`)                              | آڈٹ لاگ (`/dashboard/audit`)              |
| --------------------- | ----------------------------------------------------------- | ----------------------------------------- |
| **مقصد**              | صارف کے لیے ایونٹ فیڈ ("حال ہی میں کیا ہوا")                | تعمیل / سیکیورٹی لاگ                      |
| **ڈیٹا کا ماخذ**      | `GET /api/compliance/audit-log?level=high`                  | `GET /api/compliance/audit-log?level=all` |
| **فارمیٹ**            | ٹائم لائن، دن کے لحاظ سے گروپ شدہ، قابلِ فہم افعال + آئیکنز | جامع صفحات پر مشتمل جدول، 50/صفحہ         |
| **فلٹرز**             | ایونٹ کی قسم کا زمرہ                                        | عمل، شدت، عامل، تاریخ کی حد               |
| **برآمد**             | دستیاب نہیں                                                 | JSON برآمد                                |
| **عامل کا فلٹر**      | قابلِ اطلاق نہیں                                            | عامل کے لحاظ سے فلٹر کیا جا سکتا ہے       |
| **دکھائے گئے ایونٹس** | صرف اعلیٰ سطحی اعمال (اجازت یافتہ فہرست)                    | تمام آڈٹ ایونٹس                           |

### اعلیٰ سطحی اعمال کی اجازت یافتہ فہرست

`src/lib/audit/highLevelActions.ts` میں متعین ہے۔ یہ کنٹرول کرتی ہے کہ سرگرمی
فیڈ میں کون سے ایونٹس ظاہر ہوں۔ اجازت یافتہ فہرست میں شامل ہیں:

- فراہم کنندہ شامل کرنے/ہٹانے/جانچنے کے ایونٹس
- کومبو بنانا/اپ ڈیٹ کرنا/حذف کرنا
- API کی کا لائف سائیکل (بنانا، منسوخ کرنا، گھمانا)
- بجٹ کی حد تک پہنچنا
- توثیقی لاگ اِن/لاگ آؤٹ
- کلاؤڈ ایجنٹ سیشن بنانا
- MCP ٹول کی رجسٹریشن
- ویب ہُک بنانا/حذف کرنا
- کوٹا پول/پلان میں تبدیلیاں (`quota.*` اعمال، گروپ B)
- پلیٹ فارم ایونٹس (اپ ڈیٹ، تعیناتی)
- اسکل انسٹال کرنا/ہٹانا

اس فہرست میں شامل نہ ہونے والے ایونٹس صرف آڈٹ لاگ میں ظاہر ہوتے ہیں۔

### نیا اعلیٰ سطحی عمل شامل کرنا

`src/lib/audit/highLevelActions.ts` میں ترمیم کریں اور عمل کی اسٹرنگ کو
`HIGH_LEVEL_ACTIONS` میں شامل کریں۔ اس کے لیے PR درکار ہے (فہرست کوڈ میں ہے، DB کے ذریعے قابلِ ترتیب نہیں)۔
متعلقہ آئیکن کو `src/lib/audit/activityIcons.ts` میں شامل کیا جا سکتا ہے۔

## ری ڈائریکٹ: `/dashboard/logs/activity`

پرانا پاتھ `/dashboard/logs/activity`، `src/app/(dashboard)/dashboard/logs/activity/page.tsx`
میں `permanentRedirect()` کے ذریعے مستقل طور پر (HTTP 308) `/dashboard/activity` پر
ری ڈائریکٹ کیا جاتا ہے۔

پرانا سائڈ بار ID `logs-activity`، `HIDEABLE_SIDEBAR_ITEM_IDS` میں برقرار رکھا گیا ہے
(لیکن `SIDEBAR_DEFINITIONS` سے ہٹا دیا گیا ہے) تاکہ پرانے ID کا حوالہ دینے والے صارف
پری سیٹس متاثر نہ ہوں۔

## i18n

گروپ B کے ذریعے شامل کیے گئے نیم اسپیسز:

| نیم اسپیس کی کلید       | دائرۂ کار                                                       |
| ----------------------- | --------------------------------------------------------------- |
| `sidebar.costsSection`  | اخراجات کے حصے کا لیبل                                          |
| `sidebar.activity`      | سرگرمی کا سائڈ بار آئٹم                                         |
| `sidebar.logsGroup`     | لاگز کے ذیلی گروپ کا لیبل                                       |
| `sidebar.systemGroup`   | سسٹم کے ذیلی گروپ کا لیبل                                       |
| `sidebar.costsOverview` | اخراجات کے جائزے کا آئٹم                                        |
| `activity.*`            | سرگرمی کے صفحے کی تمام اسٹرنگز (عنوان، افعال، فلٹرز، خالی حالت) |

`next-intl` کے فال بیک طریقۂ کار کے ذریعے انگریزی استعمال کرتی ہیں (جسے `src/i18n/config.ts` میں ترتیب دیا گیا ہے)۔
