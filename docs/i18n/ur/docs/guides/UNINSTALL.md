## فوری اَن انسٹال (v3.6.2+)

OmniRoute صاف طور پر ہٹانے کے لیے دو بلٹ اِن اسکرپٹس فراہم کرتا ہے:

### اپنا ڈیٹا محفوظ رکھیں

```bash
npm run uninstall
```

یہ OmniRoute ایپلیکیشن کو ہٹا دیتا ہے، لیکن `~/.omniroute/` میں موجود آپ کے ڈیٹابیس، کنفیگریشنز، API کلیدوں اور فراہم کنندہ کی ترتیبات کو **محفوظ رکھتا** ہے۔ اگر آپ بعد میں دوبارہ انسٹال کرنے کا ارادہ رکھتے ہیں اور اپنا سیٹ اپ برقرار رکھنا چاہتے ہیں تو اسے استعمال کریں۔

### مکمل طور پر ہٹانا

```bash
npm run uninstall:full
```

یہ ایپلیکیشن کو ہٹانے کے ساتھ تمام ڈیٹا کو **مستقل طور پر مٹا دیتا ہے**:

- ڈیٹابیس (`storage.sqlite`)
- فراہم کنندہ کی کنفیگریشنز اور API کلیدیں
- بیک اپ فائلیں
- لاگ فائلیں
- `~/.omniroute/` ڈائریکٹری میں موجود تمام فائلیں

> ⚠️ **انتباہ:** `npm run uninstall:full` کو واپس نہیں کیا جا سکتا۔ آپ کے تمام فراہم کنندہ کنکشنز، کومبوز، API کلیدیں اور استعمال کی سرگزشت مستقل طور پر حذف ہو جائیں گے۔

## دستی طور پر اَن انسٹال کرنا

### NPM گلوبل انسٹالیشن

```bash
# گلوبل پیکیج ہٹائیں
npm uninstall -g omniroute

# (اختیاری) ڈیٹا ڈائریکٹری ہٹائیں
rm -rf ~/.omniroute
```

### pnpm گلوبل انسٹالیشن

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# کنٹینر کو روکیں اور ہٹائیں
docker stop omniroute
docker rm omniroute

# والیوم ہٹائیں (تمام ڈیٹا حذف کر دیتا ہے)
docker volume rm omniroute-data

# (اختیاری) امیج ہٹائیں
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# کنٹینرز کو روکیں اور ہٹائیں
docker compose down

# والیومز بھی ہٹائیں (تمام ڈیٹا حذف کر دیتا ہے)
docker compose down -v
```

### Electron ڈیسک ٹاپ ایپ

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` کھولیں
- یا انسٹالیشن ڈائریکٹری سے NSIS اَن انسٹالر چلائیں

**macOS:**

- `/Applications` سے `OmniRoute.app` کو Trash میں گھسیٹیں
- ڈیٹا ہٹائیں: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage فائل ہٹائیں
- ڈیٹا ہٹائیں: `rm -rf ~/.omniroute`

### سورس انسٹالیشن (git clone)

```bash
# کلون کی گئی ڈائریکٹری ہٹائیں
rm -rf /path/to/omniroute

# (اختیاری) ڈیٹا ڈائریکٹری ہٹائیں
rm -rf ~/.omniroute
```

## ڈیٹا ڈائریکٹریز

OmniRoute بطور ڈیفالٹ درج ذیل مقامات پر ڈیٹا محفوظ کرتا ہے:

| پلیٹ فارم                | ڈیفالٹ پاتھ                     | اوور رائیڈ                        |
| ------------------------ | ------------------------------- | --------------------------------- |
| Linux                    | `~/.omniroute/`                 | `DATA_DIR` ماحولیاتی متغیر        |
| macOS                    | `~/.omniroute/`                 | `DATA_DIR` ماحولیاتی متغیر        |
| Windows                  | `%APPDATA%/omniroute/`          | `DATA_DIR` ماحولیاتی متغیر        |
| Docker                   | `/app/data/` (ماؤنٹ شدہ والیوم) | `DATA_DIR` ماحولیاتی متغیر        |
| XDG سے مطابقت رکھنے والا | `$XDG_CONFIG_HOME/omniroute/`   | `XDG_CONFIG_HOME` ماحولیاتی متغیر |

### ڈیٹا ڈائریکٹری میں موجود فائلیں

| فائل/ڈائریکٹری       | تفصیل                                                  |
| -------------------- | ------------------------------------------------------ |
| `storage.sqlite`     | مرکزی ڈیٹابیس (فراہم کنندگان، کومبوز، ترتیبات، کلیدیں) |
| `storage.sqlite-wal` | SQLite رائٹ-اہیڈ لاگ (عارضی)                           |
| `storage.sqlite-shm` | SQLite مشترکہ میموری (عارضی)                           |
| `call_logs/`         | درخواست کے پے لوڈ کے آرکائیوز                          |
| `backups/`           | خودکار ڈیٹابیس بیک اپس                                 |
| `log.txt`            | سابقہ درخواست لاگ (اختیاری)                            |

## مکمل طور پر ہٹائے جانے کی تصدیق کریں

اَن انسٹال کرنے کے بعد، تصدیق کریں کہ کوئی فائل باقی نہیں ہے:

```bash
# گلوبل npm پیکیج کی جانچ کریں
npm list -g omniroute 2>/dev/null

# ڈیٹا ڈائریکٹری کی جانچ کریں
ls -la ~/.omniroute/ 2>/dev/null

# چلتے ہوئے پراسیسز کی جانچ کریں
pgrep -f omniroute
```

اگر کوئی پراسیس اب بھی چل رہا ہو، تو اسے روک دیں:

```bash
pkill -f omniroute
```
