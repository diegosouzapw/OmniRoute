**OmniCopilot** ہر اس ماڈل کو، جسے آپ کا OmniRoute پیش کرتا ہے، _مقامی_ GitHub Copilot Chat
ماڈل پِکر میں شامل کر دیتا ہے۔ نہ کوئی دوسری سائیڈ بار، نہ الگ چیٹ UI — Copilot کا ایجنٹ موڈ، ٹول کالنگ،
MCP سرورز اور حسبِ ضرورت ہدایات بدستور کام کرتی رہتی ہیں، بس آپ کے منتخب کردہ ماڈل پر چلتی ہیں۔

> embeddings پر مبنی خصوصیات فراہم کنندہ API سے باہر رہتی ہیں اور ان کے لیے اب بھی Copilot درکار ہے۔

## سیٹ اپ

1. **OmniRoute چلائیں** — `npm install -g omniroute && omniroute` (ڈیش بورڈ `http://localhost:20128` پر)۔
2. **ایکسٹینشن انسٹال کریں** — Extensions منظر میں "OmniRoute" تلاش کریں۔
3. **ماڈل منتخب کریں** — Copilot Chat → ماڈل پِکر → **Manage Models…** → **OmniRoute**، پھر
   اپنی مطلوبہ چیزوں پر نشان لگائیں۔

جب OmniRoute ڈیفالٹ پورٹ پر چل رہا ہو تو کچھ بھی کنفیگر کرنے کی ضرورت نہیں۔ ریموٹ انسٹینس کے لیے،
**Activity Bar میں OmniRoute آئیکن** کھولیں (یا `OmniRoute: Manage Connection` چلائیں) اور یہ سیٹ کریں:

- **سرور URL** — سرور کا روٹ، مثلاً `http://192.168.0.15:20128`۔ `/v1` لاحقہ
  ایکسٹینشن خود شامل کرتی ہے؛ اسے شامل نہ کریں۔
- **API کلید** — صرف اس وقت جب سرور `REQUIRE_API_KEY` سیٹ کرے۔ یہ VS
  Code SecretStorage کے ذریعے OS keychain میں محفوظ ہوتی ہے، `settings.json` میں کبھی نہیں۔

## پِکر میں کیا دکھائی دے گا

ایکسٹینشن خام `GET /v1/models` پے لوڈ نہیں دکھاتی — یہ اسے مناسب شکل دیتی ہے، اور آپ کو نظر آنے والی
تعداد دو دانستہ وجوہات کی بنا پر کیٹلاگ کے حجم سے کم ہوتی ہے۔

### یہ ہر ماڈل کے لیے ایک id طلب کرتی ہے

`MODELS_CATALOG_PREFIX_MODE` کی ڈیفالٹ قدر **`dual`** ہے، جو ہر ماڈل کو دو مرتبہ مشتہر کرتی ہے — ایک بار
مختصر alias prefix کے تحت اور ایک بار canonical provider prefix کے تحت — تاکہ پرانی کلائنٹ
کنفیگریشنز دونوں صورتوں کو بدستور حل کر سکیں:

```
cc/claude-sonnet-4-6        ← alias prefix
claude/claude-sonnet-4-6    ← canonical prefix, same model
```

ایکسٹینشن **`GET /v1/models?prefix=alias`** کی درخواست کرتی ہے تاکہ دوسرے کلائنٹس کے لیے سرور کی مجموعی
ترتیب تبدیل کیے بغیر، ہر ماڈل کے لیے ایک id موصول ہو۔ ایک حوالہ جاتی انسٹینس پر اس سے
**2345 اندراجات کم ہو کر 1396 رہ گئے — 949 نقول، اور ایک بھی ماڈل ضائع نہیں ہوا۔**

اگر آپ اسے _ہر_ کلائنٹ کے لیے پورے سرور پر درست کرنا چاہیں تو ڈیش بورڈ میں
`MODELS_CATALOG_PREFIX_MODE` فیچر فلیگ کو `alias` پر سیٹ کریں۔ query parameter اور ہر موڈ کی
جدول کے لیے [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) دیکھیں۔

### یہ ان ماڈلز کو چھپا دیتی ہے جو چیٹ نہیں کر سکتے

کیٹلاگ میں تصویر، ویڈیو، آڈیو، rerank، embedding اور moderation ماڈلز بھی درج ہوتے ہیں۔ ویسے بھی
چیٹ درخواست پر انہیں مسترد کر دیا جاتا ہے:

```
HTTP 400 — Model '<id>' is an image-generation model and cannot be used on
/v1/chat/completions. Use POST /v1/images/generations instead.
```

اس لیے پِکر تک پہنچنے سے پہلے انہیں ان کے `type` فیلڈ کے مطابق فلٹر کر دیا جاتا ہے۔ **Responses-API
ماڈلز برقرار رکھے جاتے ہیں** — ہر Codex / GPT-5.x اندراج `supported_endpoints: ["responses"]`
مشتہر کرتا ہے، اور OmniRoute انہیں `/v1/chat/completions` کے لیے تبدیل کرتا ہے، اس لیے وہ مکمل طور پر قابلِ استعمال ہیں۔

### وہ فراہم کنندگان جنہیں آپ نے کبھی کنفیگر نہیں کیا

کیٹلاگ ان فراہم کنندگان کے ماڈلز درج کرتا ہے جن کا **فعال کنکشن** موجود ہو، _نیز_ ہر **noAuth**
فراہم کنندہ — یعنی وہ جن کے لیے کلید درکار نہیں اور جو مفت درجے کا بڑا حصہ بناتے ہیں۔ یہ دانستہ ہے۔ انہیں چھپانے کے لیے
ڈیش بورڈ کی ترتیبات میں انہیں `blockedProviders` میں شامل کریں؛ ایکسٹینشن میں کچھ تبدیل نہیں ہوتا۔

## VS Code ٹیب کے اندر Dashboard

`omnicopilot.dashboardOpen: "editor"` بیرونی براؤزر کے بجائے Simple Browser کے ذریعے OmniRoute dashboard کو editor ٹیب میں دکھاتا ہے۔ سرور پر embedding کو **واضح طور پر فعال کرنا ضروری ہے**، جس کے لیے `DASHBOARD_ALLOW_EMBED=vscode` استعمال ہوتا ہے۔ یہ HTML صفحات کو ڈیفالٹ `frame-ancestors 'none'` + `X-Frame-Options: DENY` کے بجائے `frame-ancestors 'self' vscode-webview:` کے ساتھ پیش کرتا ہے۔ API سطح (`/api`، `/v1`، `/v1beta`، `/a2a`، `/healthz`) دونوں صورتوں میں سخت headers برقرار رکھتی ہے۔

> ⚠️ **یہ build-time flag ہے، runtime flag نہیں۔** Next.js، `headers()` کو route
> manifest میں compile کرتا ہے، اس لیے `next.config.mjs` متغیر کو bundle بناتے وقت پڑھتا ہے
> (`next.config.mjs` → `resolveDashboardEmbedMode`، `scripts/build/dashboardEmbed.mjs`)۔
> پہلے سے build شدہ سرور کو شروع کرنے سے پہلے اسے export کرنے سے کچھ تبدیل نہیں ہوتا — headers پہلے ہی شامل کیے جا چکے ہوتے ہیں۔

```bash
# متغیر کا BUILD command میں موجود ہونا ضروری ہے
DASHBOARD_ALLOW_EMBED=vscode npm run build        # یا npm run build:release
npm start
```

| آپ نے کیسے انسٹال کیا      | کیا آپ embedding فعال کر سکتے ہیں؟                                                                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| source سے                  | ✅ متغیر کو، جیسا کہ اوپر دکھایا گیا ہے، build command پر سیٹ کریں                                                                              |
| `npm install -g omniroute` | ❌ شائع شدہ package میں prebuilt bundle شامل ہے — اس کے بجائے source سے build کریں                                                              |
| Docker image               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — Docker Hub پر موجود prebuilt image میں embedding فعال نہیں ہے |

embed-enabled build کے بغیر صفحہ frame ہونے سے انکار کر دیتا ہے۔ extension، response headers سے اس کا پتا لگا کر بیرونی براؤزر پر واپس چلی جاتی ہے — کچھ خراب نہیں ہوتا، اور یہ ایک بار اس بارے میں اطلاع بھی دیتی ہے۔
[`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) اور issue
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273) دیکھیں۔

## VS Code کے اندر سے اپنے دیگر tools کو configure کرنا

**`OmniRoute: Configure Coding CLI`**، `omniroute` CLI کو استعمال کرتے ہوئے Codex CLI، Claude Code، Cline، Continue، Cursor، Aider، OpenCode، Goose، Crush، Qwen Code، Kilo اور Roo کے لیے استعمال کے لیے تیار profiles لکھتا ہے — یہی configs
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md) میں بیان کیے گئے ہیں۔ API key، CLI کو `OMNIROUTE_API_KEY` environment variable کے ذریعے فراہم کی جاتی ہے، command line پر کبھی نہیں۔
