OmniRoute معاونت یافتہ 352 فراہم کنندگان کو 3 اقتصادی درجات میں منظم کرتا ہے۔ ہر
درخواست باری باری ان سے گزرتی ہے، یہاں تک کہ کوئی ایک کامیابی سے جواب دے — یوں
آپ کو کبھی بھی fallback کوڈ لکھے بغیر سب سے سستا قابلِ عمل جواب ملتا ہے۔

## درجہ 1 — سبسکرپشن

**وہ فراہم کنندگان جن کے لیے آپ پہلے ہی ادائیگی کرتے ہیں۔** OmniRoute کوٹہ ختم ہونے
سے پہلے اس کا ایک ایک حصہ استعمال کرتا ہے۔

| فراہم کنندہ                     | درجہ 1 میں ہونے کی وجہ                               |
| ------------------------------- | ---------------------------------------------------- |
| Claude Code OAuth               | Anthropic Pro/Team — مقررہ شرح، اکثر غیر استعمال شدہ |
| OpenAI Codex (ChatGPT سبسکرپشن) | Plus/Team میں Codex کوٹہ شامل ہے                     |
| GitHub Copilot                  | فی صارف — کوٹہ ماہانہ ری سیٹ ہوتا ہے                 |
| Cursor IDE                      | Pro پلان کا کوٹہ                                     |
| Antigravity / Devin Desktop     | پہلے سے شامل کوٹے                                    |

**حکمتِ عملی**: ہر ایسی درخواست کو پہلے یہاں روٹ کریں جو ماڈل کی صلاحیتوں
سے مطابقت رکھتی ہو۔ کوٹہ ٹریکر قریب آتے ہوئے ری سیٹس کی نگرانی کرتا ہے، اور `reset-aware`
combo حکمتِ عملی اسی کے مطابق ترجیح دیتی ہے۔ درجہ 1 کو پہلے استعمال کرنے اور کوٹہ ختم
ہونے پر ہی بامعاوضہ درجات کی طرف جانے کے لیے `auto/thrifty` id استعمال کریں — یا صرف
پلان میں شامل گنجائش تک محدود رہنے اور بصورتِ دیگر ناکام ہونے کے لیے `auto/subscription`
استعمال کریں۔ [سبسکرپشن کو ترجیح دینے والی روٹنگ](../routing/SUBSCRIPTION_LADDER.md)
دیکھیں۔

## درجہ 2 — سستا

**فی 1M ٹوکن $1 سے کم قیمت والے فی ٹوکن ادائیگی کے فراہم کنندگان۔** زیادہ حجم والے کام
یا درجہ 1 کے کوٹے اپنی حد تک پہنچنے کے بعد استعمال کے لیے محفوظ۔

| فراہم کنندہ                                 | قیمت (ان پٹ/آؤٹ پٹ) | خوبیاں            |
| ------------------------------------------- | ------------------- | ----------------- |
| DeepSeek V4 Pro                             | $0.27 / $1.10 فی 1M | کوڈ، استدلال      |
| GLM-4.5                                     | $0.60 / $2.20 فی 1M | طویل سیاق و سباق  |
| MiniMax M1                                  | $0.20 / $1.10 فی 1M | رفتار             |
| Qwen Coder                                  | $0.30 / $1.20 فی 1M | کوڈ               |
| OpenRouter (قیمت کے لحاظ سے بہتر بنایا گیا) | مختلف               | 100+ ماڈلز، متحرک |

**حکمتِ عملی**: combo `cost-optimized` سب سے کم $/token والا ایسا ماڈل منتخب کرتا ہے جو
کام کے صلاحیتی فلٹر (وژن، JSON موڈ، ٹولز، زیادہ سے زیادہ سیاق) پر پورا اترتا ہو۔

## درجہ 3 — مفت

**صفر لاگت والے فراہم کنندگان** — مفت درجات، کریڈٹ پروگرامز، OAuth کے یومیہ کوٹے۔

| فراہم کنندہ      | مفت کوٹہ / کریڈٹس                      |
| ---------------- | -------------------------------------- |
| Kiro AI          | مفت Claude درجہ (فراخ منصفانہ استعمال) |
| OpenCode Free    | تصدیق درکار نہیں، فراخ شرح کی حدود     |
| Qoder            | مفت OAuth                              |
| Google Vertex AI | نئے اکاؤنٹ کے لیے $300 کریڈٹس          |
| Amazon Q         | AWS صارفین کے لیے مفت درجہ             |
| Pollinations     | کھلا عوامی API                         |
| Cloudflare AI    | Workers AI کا مفت درجہ                 |

**حکمتِ عملی**: بجٹ کی حد کے ساتھ combo `auto` اس وقت یہاں روٹ کرتا ہے جب درجہ 1+2 ناکام
ہو جائیں یا جب `useFreeOnly=true` مقرر ہو۔ مفت فراہم کنندگان کی شرح کی حدود اکثر
زیادہ سخت ہوتی ہیں — circuit breaker انہیں backoff کے بعد بحال کرتا ہے۔

## درجات کی تشکیل

Dashboard → **درجات** → اپنے فراہم کنندگان تفویض کریں۔ طے شدہ ترتیبات (`tierDefaults.json` سے) معقول
ہیں؛ جب آپ کے پاس ترجیح دینے کے لیے مخصوص سبسکرپشنز یا خارج کرنے کے لیے فراہم کنندگان ہوں تو انہیں تبدیل کریں۔

Auto-Combo کی 16 عوامل پر مبنی اسکورنگ درجہ بھی مدِنظر رکھتی ہے۔ دیکھیں
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md)۔

## ٹیلی میٹری

Dashboard → **استعمال** ہر روز ہر درجہ میں خرچ ہونے والے ٹوکنز دکھاتا ہے۔ اسے درج ذیل کے لیے استعمال کریں:

- تصدیق کریں کہ درجہ 1 مکمل طور پر استعمال ہو رہا ہے (ورنہ آپ سبسکرپشن کی قدر ضائع کر رہے ہیں)
- شناخت کریں کہ درجہ 2 کے کون سے ماڈلز سب سے زیادہ منتخب ہوتے ہیں (انہیں 1-2 تک محدود کریں)
- تصدیق کریں کہ درجہ 3 ٹیسٹ/تجرباتی کاموں پر رقم بچاتا ہے

## عام طریقے

### مکمل طور پر مفت کام

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

درجہ 3 کی طرف بھرپور ترجیح دیتا ہے؛ درجہ 2 صرف اسی وقت استعمال کرتا ہے جب درجہ 3 دستیاب نہ ہو۔

### سبسکرپشن کو ترجیح، سستا fallback

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

درجہ 1 → درجہ 2 → درجہ 3 سے مماثل واضح مرتب فہرست۔
