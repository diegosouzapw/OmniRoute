## تنصیب کے طریقے

### npm (تجویز کردہ)

```bash
npm install -g omniroute
omniroute
```

ڈیش بورڈ `http://localhost:20128` پر کھلتا ہے اور API کا بنیادی URL `http://localhost:20128/v1` ہے۔

### pnpm

```bash
pnpm add -g omniroute@latest --allow-build=better-sqlite3 --allow-build=@swc/core
omniroute
```

> **pnpm صارفین:** `better-sqlite3` اور `@swc/core` کے لیے مقامی بلڈ اسکرپٹس فعال کرنے کی خاطر `--allow-build` فلیگ درکار ہے۔ pnpm v11 پر عالمی تنصیبات کے لیے `pnpm approve-builds -g` کمانڈ معاونت یافتہ نہیں ہے۔

### Arch Linux (AUR)

```bash
yay -S omniroute-bin
systemctl --user enable --now omniroute.service
```

[AUR پیکیج](https://aur.archlinux.org/packages/omniroute-bin) OmniRoute انسٹال کرتا ہے اور systemd صارف سروس فراہم کرتا ہے۔

### سورس سے

```bash
npm install
PORT=20128 DASHBOARD_PORT=20129 NEXT_PUBLIC_BASE_URL=http://localhost:20129 npm run dev
```

> **Windows نوٹ:** بطور ڈیفالٹ، اگر پرانی `%USERPROFILE%\.omniroute` ڈائریکٹری موجود نہ ہو تو OmniRoute `%APPDATA%\omniroute` استعمال کرتا ہے۔ ڈیٹا ڈائریکٹری کا مختلف مقام منتخب کرنے کے لیے `DATA_DIR` سیٹ کریں۔

> **نوٹ:** پہلی بار چلانے پر `npm install`، `.env.example` سے `.env` خودکار طور پر تیار کرتا ہے۔ بعد کی تنصیبات موجودہ `.env` کو اوور رائٹ نہیں کریں گی، اس لیے تخصیصات محفوظ رہتی ہیں۔ اسے دوبارہ ابتدائی حالت سے بنانے کے لیے، دوبارہ چلانے سے پہلے `.env` حذف کریں۔

### Docker

Compose پروفائلز اور Caddy HTTPS سمیت Docker کے مکمل سیٹ اپ کے لیے [Docker گائیڈ](./DOCKER_GUIDE.md) دیکھیں۔

### ڈیسک ٹاپ ایپ (Electron)

OmniRoute کے ساتھ Electron 41 + electron-builder 26.10 پر بنایا گیا ایک ڈیسک ٹاپ ریپر فراہم کیا جاتا ہے۔ دستیاب اسکرپٹس (ورک اسپیس روٹ):

```bash
npm run electron:dev          # ہاٹ ری لوڈ کے ساتھ ڈیسک ٹاپ چلائیں
npm run electron:build        # موجودہ OS کے لیے بلڈ کریں (خودکار طور پر شناخت شدہ)
npm run electron:build:win    # Windows انسٹالر (NSIS + پورٹیبل)
npm run electron:build:mac    # macOS (dmg + zip، arm64+x64)
npm run electron:build:linux  # Linux (AppImage + deb + rpm)
npm run electron:smoke:packaged  # پیکیج شدہ بلڈ کا اسموک ٹیسٹ کریں
```

ڈیسک ٹاپ انسٹالرز کی ریلیزز GitHub Releases کے ساتھ منسلک ہوتی ہیں۔ Electron کی مکمل تفصیلی رہنمائی (سائننگ، IPC برج، ڈسٹری بیوشنز) کے لیے، [`ELECTRON_GUIDE.md`](./ELECTRON_GUIDE.md) دیکھیں _(بعد کے مرحلے میں تیار کیا گیا)_۔

### ہیڈ لیس سرور (CI/خودکاری)

بلا نگرانی سیٹ اپس (Docker، Kubernetes، CI) کے لیے، استعمال کریں:

```bash
omniroute setup --non-interactive
omniroute providers test-batch
```

env vars (`INITIAL_PASSWORD`، `OMNIROUTE_WS_BRIDGE_SECRET` وغیرہ) کے ساتھ ملا کر، اس سے آپ مکمل طور پر اسکرپٹ کیے جا سکنے والے انداز میں OmniRoute انسٹینس چلا سکتے ہیں۔

### CLI اختیارات

| کمانڈ                   | وضاحت                                                           |
| ----------------------- | --------------------------------------------------------------- |
| `omniroute`             | سرور شروع کریں (`PORT=20128`، API اور ڈیش بورڈ ایک ہی پورٹ پر)  |
| `omniroute setup`       | پاس ورڈ اور پہلے پرووائیڈر کے لیے رہنمائی پر مبنی CLI آن بورڈنگ |
| `omniroute doctor`      | سرور شروع کیے بغیر مقامی صحت کی جانچیں چلائیں                   |
| `omniroute providers`   | CLI سے پرووائیڈرز دریافت، فہرست، توثیق اور ٹیسٹ کریں            |
| `omniroute config`      | CLI ٹول کی تشکیل — کنفیگز کی فہرست، حصول، ترتیب اور توثیق       |
| `omniroute status`      | آف لائن اسٹیٹس ڈیش بورڈ — ورژن، DB، ٹولز، کنفیگ                 |
| `omniroute logs`        | API سے استعمال کے لاگز اسٹریم کریں (`--follow` معاونت یافتہ ہے) |
| `omniroute update`      | OmniRoute اپ ڈیٹس تلاش یا لاگو کریں                             |
| `omniroute provider`    | پرووائیڈر کنکشنز کا نظم کریں — شامل، فہرست، حذف، ٹیسٹ، ڈیفالٹ   |
| `omniroute --port 3000` | کینونیکل/API پورٹ کو 3000 پر سیٹ کریں                           |
| `omniroute --mcp`       | MCP سرور شروع کریں (stdio ٹرانسپورٹ)                            |
| `omniroute --no-open`   | براؤزر خودکار طور پر نہ کھولیں                                  |
| `omniroute --help`      | مدد دکھائیں                                                     |

ہیڈ لیس سیٹ اپ کو فلیگز یا ماحولیاتی متغیرات کے ذریعے اسکرپٹ کیا جا سکتا ہے:

```bash
omniroute setup --non-interactive --password "$OMNIROUTE_PASSWORD"
omniroute setup --non-interactive --add-provider --provider openai --api-key "$OPENAI_API_KEY"
omniroute setup --non-interactive --add-provider --provider openai --api-key "$OPENAI_API_KEY" --test-provider
```

ڈیش بورڈ کھولے بغیر مقامی تشخیصی جانچیں چلائیں:

```bash
omniroute doctor
omniroute doctor --json
omniroute doctor --no-liveness
```

ڈیش بورڈ کھولے بغیر SSH یا اسکرپٹس سے پرووائیڈرز کا نظم کریں:

```bash
omniroute providers available
omniroute providers available --search openai
omniroute providers available --category api-key
omniroute providers list
omniroute providers test <id-or-name>
omniroute providers test-all
omniroute providers validate
```

## CLI ٹول کی کنفیگریشن

### 1) فراہم کنندگان کو منسلک کریں اور API کلید بنائیں

1. Dashboard → `Providers` کھولیں اور کم از کم ایک فراہم کنندہ منسلک کریں (OAuth یا API کلید)۔
2. Dashboard → `Endpoints` کھولیں اور ایک API کلید بنائیں۔
3. (اختیاری) Dashboard → `Combos` کھولیں اور اپنی فال بیک چین مقرر کریں۔

### 2) اپنے کوڈنگ ٹول کو ہدف کی طرف متوجہ کریں

```txt
بنیادی URL: http://localhost:20128/v1
API کلید:  [Endpoint صفحے سے کاپی کریں]
ماڈل:    if/qwen3.8-max-preview (یا کوئی بھی provider/model سابقہ)
```

اگر آپ کا ایڈیٹر `Authorization: Bearer ...` نہیں بھیج سکتا تو اس کے بجائے ٹوکن پر مبنی مطابقتی بنیاد استعمال کریں:

```txt
بنیادی URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/
ماڈلز کا URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/models
چیٹ کا URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/chat/completions
Ollama ٹیگز کا URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/api/tags
```

Claude Code، Codex CLI، Cursor، Cline، OpenClaw، OpenCode، اور OpenAI سے مطابقت رکھنے والی SDKs کے ساتھ کام کرتا ہے۔

#### `setup-*` کے ذریعے خودکار کنفیگریشن

بنیادی URL اور کلید کو دستی طور پر پیسٹ کرنے کے بجائے، OmniRoute کو لائیو ماڈل کیٹلاگ سے ہر ٹول کی اپنی کنفیگ لکھنے دیں۔ ہر ٹول کے لیے ایک کمانڈ:

```bash
omniroute setup-codex        # ~/.codex/<name>.config.toml پروفائلز
omniroute setup-claude       # ~/.claude/profiles/<name>/settings.json
omniroute setup-opencode     # ~/.config/opencode/opencode.json (OpenAI سے مطابقت رکھنے والا)
omniroute setup-cline        # Cline CLI + VS Code ایکسٹینشن کی ترتیبات
omniroute setup-kilo         # Kilo Code
omniroute setup-continue     # ~/.continue/config.yaml (Continue / cn)
omniroute setup-cursor       # Cursor کے اندرونِ ایپ مراحل پرنٹ کرتا ہے
omniroute setup-roo          # Roo Code درآمد + autoImport پوائنٹر
omniroute setup-crush        # ~/.config/crush/crush.json
omniroute setup-goose        # ~/.config/goose/config.yaml
omniroute setup-aider        # ~/.aider.conf.yml
omniroute setup-qwen         # ~/.qwen/settings.json + ~/.qwen/.env
```

مقامی ٹول کو **ریموٹ** OmniRoute کے لیے کنفیگر کرنے کی خاطر ہر کمانڈ `--remote <url> --api-key <key>` قبول کرتی ہے، نیز پیش منظر دیکھنے کے لیے `--dry-run` بھی۔ درست env شامل کر کے اور کوئی کنفیگ لکھے بغیر CLI چلانے کے لیے عمومی لانچر `omniroute run <target>` (claude, codex, aider, goose, opencode, qwen, gemini) استعمال کریں؛ پرانے فی ٹول لانچرز `omniroute launch` (Claude Code) اور `omniroute launch-codex` (Codex) بدستور دستیاب ہیں۔

مکمل جدول (ہر کمانڈ کیا لکھتی ہے، تمام فلیگز، مقامی بمقابلہ ریموٹ، بنیادی URL کے `/v1` اصول) کے لیے **[CLI انٹیگریشنز](./CLI-INTEGRATIONS.md)** دیکھیں۔

ہر ٹول کی تفصیلی کنفیگریشن (Claude Code، Codex CLI، Cursor، Cline، OpenClaw، Kilo Code، Copilot، اور مزید) کے لیے مخصوص **[CLI ٹولز گائیڈ](../reference/CLI-TOOLS.md)** دیکھیں۔

## پروٹوکول سیٹ اپ (MCP + A2A)

### MCP سیٹ اپ (Model Context Protocol)

stdio موڈ میں MCP ٹرانسپورٹ شروع کریں:

```bash
omniroute --mcp
```

تجویز کردہ توثیقی عمل:

```bash
# 1. MCP سرور شروع کریں
omniroute --mcp

# 2. اپنے MCP کلائنٹ سے یہ کال کریں:
omniroute_get_health        # اسے سسٹم کی صحت واپس کرنی چاہیے
omniroute_list_combos       # اسے فعال combos واپس کرنے چاہییں

# 3. یا مکمل E2E سوٹ چلائیں:
npm run test:protocols:e2e
```

#### MCP کلائنٹ کی کنفیگریشن

**Claude Code:**

```bash
claude mcp add-server omniroute --type http --url http://localhost:20128/api/mcp/stream
```

**Cursor / Cline:**

اپنی MCP ترتیبات میں شامل کریں:

```json
{
  "mcpServers": {
    "omniroute": {
      "command": "omniroute",
      "args": ["--mcp"],
      "env": {}
    }
  }
}
```

**MCP کی مکمل دستاویزات:** [MCP سرور README](../../open-sse/mcp-server/README.md) — 110 ٹولز، IDE کنفیگز، Python/TS/Go کلائنٹس۔

### A2A سیٹ اپ (Agent-to-Agent Protocol)

Agent Card کی توثیق کریں:

```bash
curl http://localhost:20128/.well-known/agent.json
```

ایک ٹاسک بھیجیں:

```bash
curl -X POST http://localhost:20128/a2a \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":"quickstart","method":"message/send","params":{"skill":"quota-management","messages":[{"role":"user","content":"Give me a short quota summary."}]}}'
```

**A2A کی مکمل دستاویزات:** [A2A سرور README](../../src/lib/a2a/README.md) — JSON-RPC 2.0، مہارتیں، اسٹریمنگ، ٹاسک لائف سائیکل۔

## ٹائم آؤٹ کی تشکیل

### بنیادی ٹائم آؤٹس

زیادہ تر تعیناتیوں کے لیے، آپ کو صرف ان دو متغیرات کی ضرورت ہوتی ہے:

| متغیر                    | طے شدہ قدر                    | مقصد                                                                                                                                                  |
| ------------------------ | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `REQUEST_TIMEOUT_MS`     | `600000`                      | اپ اسٹریم جواب شروع ہونے کے ٹائم آؤٹ، پوشیدہ Undici ٹائم آؤٹس، TLS فنگر پرنٹ درخواستوں، اور API برج درخواست/پراکسی ٹائم آؤٹس کے لیے مشترکہ بنیادی قدر |
| `STREAM_IDLE_TIMEOUT_MS` | `REQUEST_TIMEOUT_MS` سے ماخوذ | اسٹریمنگ چنکس کے درمیان زیادہ سے زیادہ وقفہ، جس کے بعد OmniRoute، SSE اسٹریم کو منقطع کر دیتا ہے                                                      |

پچھلے ورژنز کے ساتھ مطابقت برقرار رکھی گئی ہے: موجودہ `FETCH_TIMEOUT_MS`، `API_BRIDGE_PROXY_TIMEOUT_MS`، اور دیگر فی-لیئر ٹائم آؤٹ متغیرات بدستور کام کرتے ہیں اور مشترکہ بنیادی قدر پر فوقیت رکھتے ہیں۔

### فراہم کنندہ سے متعلق مخصوص نکات

Claude Code سے مطابقت رکھنے والے اپ اسٹریمز (`anthropic-compatible-cc-*`) کے لیے، OmniRoute حل شدہ فیچ ٹائم آؤٹ سے آؤٹ باؤنڈ `X-Stainless-Timeout` ہیڈر اخذ کرتا ہے، تاکہ فراہم کنندہ کی جانب کے ریڈ ٹائم آؤٹس آپ کی env تشکیل کے مطابق رہیں۔

فریق ثالث کے Claude Code سے مطابقت رکھنے والے ریورس پراکسیز کے لیے، OmniRoute طے شدہ `anthropic-beta` سیٹ کو محتاط رکھتا ہے اور جب `Client Cache Control` کو `Auto` پر چھوڑا جائے تو صرف کلائنٹ کی فراہم کردہ `cache_control` علامات کو آگے بھیجتا ہے۔ فی کنکشن "Enable redact-thinking beta" ٹوگل صرف اس وقت فعال کریں جب اپ اسٹریم کو خاص طور پر حذف شدہ Claude تھنکنگ اسٹریمز درکار ہوں۔

### جدید ٹائم آؤٹ اوور رائیڈز

| متغیر                                    | طے شدہ قدر                                 | مقصد                                                                         |
| ---------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------- |
| `FETCH_TIMEOUT_MS`                       | `REQUEST_TIMEOUT_MS` سے ماخوذ              | اپ اسٹریم جواب شروع ہونے کا ٹائم آؤٹ، جو جوابی ہیڈرز آنے تک استعمال ہوتا ہے  |
| `FETCH_HEADERS_TIMEOUT_MS`               | `FETCH_TIMEOUT_MS` سے ماخوذ                | اپ اسٹریم جوابی ہیڈرز وصول کرنے کے لیے Undici کی وقت کی حد                   |
| `FETCH_BODY_TIMEOUT_MS`                  | `FETCH_TIMEOUT_MS` سے ماخوذ                | اپ اسٹریم باڈی چنکس کے درمیان Undici کی وقت کی حد (`0` اسے غیر فعال کرتا ہے) |
| `FETCH_CONNECT_TIMEOUT_MS`               | `30000`                                    | Undici TCP کنکشن ٹائم آؤٹ                                                    |
| `FETCH_KEEPALIVE_TIMEOUT_MS`             | `4000`                                     | Undici کے غیر فعال keep-alive ساکٹ کا ٹائم آؤٹ                               |
| `TLS_CLIENT_TIMEOUT_MS`                  | `FETCH_TIMEOUT_MS` سے ماخوذ                | `wreq-js` کے ذریعے کی جانے والی TLS فنگر پرنٹ درخواستوں کا ٹائم آؤٹ          |
| `API_BRIDGE_PROXY_TIMEOUT_MS`            | `REQUEST_TIMEOUT_MS` سے ماخوذ یا `600000`  | API پورٹ سے ڈیش بورڈ پورٹ تک `/v1` پراکسی فارورڈنگ کا ٹائم آؤٹ               |
| `API_BRIDGE_SERVER_REQUEST_TIMEOUT_MS`   | `max(API_BRIDGE_PROXY_TIMEOUT_MS, 300000)` | API برج سرور پر آنے والی درخواست کا ٹائم آؤٹ                                 |
| `API_BRIDGE_SERVER_HEADERS_TIMEOUT_MS`   | `60000`                                    | API برج سرور پر آنے والے ہیڈرز کا ٹائم آؤٹ                                   |
| `API_BRIDGE_SERVER_KEEPALIVE_TIMEOUT_MS` | `5000`                                     | API برج سرور پر keep-alive ٹائم آؤٹ                                          |
| `API_BRIDGE_SERVER_SOCKET_TIMEOUT_MS`    | `0`                                        | API برج سرور پر ساکٹ کی غیرفعالیت کا ٹائم آؤٹ (`0` اسے غیر فعال کرتا ہے)     |

> **نوٹ:** اسٹریمنگ درخواستوں کے لیے، `FETCH_TIMEOUT_MS` صرف کنکشن قائم کرنے / پہلے اپ اسٹریم جواب کا انتظار کرنے کا احاطہ کرتا ہے۔ اسٹریم فعال ہو جانے کے بعد، OmniRoute صرف حقیقی تعطل (`STREAM_IDLE_TIMEOUT_MS`) یا Undici باڈی کی غیرفعالیت (`FETCH_BODY_TIMEOUT_MS`) کی صورت میں اسے منقطع کرے گا۔

### ریورس پراکسی مطابقت

اگر آپ OmniRoute کو Nginx، Caddy، Cloudflare، یا کسی اور ریورس پراکسی کے پیچھے چلاتے ہیں تو یقینی بنائیں کہ پراکسی ٹائم آؤٹس بھی آپ کے OmniRoute اسٹریم/فیچ ٹائم آؤٹس سے زیادہ ہوں۔

## Void Linux (`xbps-src`) ٹیمپلیٹ

Void Linux کے صارفین `xbps-src` استعمال کرکے ایک مقامی پیکیج بنا سکتے ہیں۔ اس بلاک کو `srcpkgs/omniroute/template` کے طور پر محفوظ کریں:

```bash
# 'omniroute' کے لیے ٹیمپلیٹ فائل
pkgname=omniroute
version=3.8.0
revision=1
hostmakedepends="nodejs python3 make"
depends="openssl"
short_desc="Universal AI gateway with smart routing for multiple LLM providers"
maintainer="zenobit <zenobit@disroot.org>"
license="MIT"
homepage="https://github.com/diegosouzapw/OmniRoute"
distfiles="https://github.com/diegosouzapw/OmniRoute/archive/refs/tags/v${version}.tar.gz"
# ہر ریلیز کے لیے checksum کو اس کے ذریعے دوبارہ بنائیں:
#   curl -L -o /tmp/omniroute.tar.gz "https://github.com/diegosouzapw/OmniRoute/archive/refs/tags/v${version}.tar.gz" && sha256sum /tmp/omniroute.tar.gz
checksum=PLACEHOLDER_REGENERATE_PER_RELEASE
system_accounts="_omniroute"
omniroute_homedir="/var/lib/omniroute"
export NODE_ENV=production
export npm_config_engine_strict=false
export npm_config_loglevel=error
export npm_config_fund=false
export npm_config_audit=false

do_build() {
	local _gyp_arch
	case "$XBPS_TARGET_MACHINE" in
		aarch64*) _gyp_arch=arm64 ;;
		armv7*|armv6*) _gyp_arch=arm ;;
		i686*) _gyp_arch=ia32 ;;
		*) _gyp_arch=x64 ;;
	esac

	NODE_ENV=development npm ci --ignore-scripts
	npm run build
	cp -r .next/static .next/standalone/.next/static
	[ -d public ] && cp -r public .next/standalone/public || true

	local _node_gyp=/usr/lib/node_modules/npm/node_modules/node-gyp/bin/node-gyp.js
	(cd node_modules/better-sqlite3 && node "$_node_gyp" rebuild --arch="$_gyp_arch")

	local _bs3_release=.next/standalone/node_modules/better-sqlite3/build/Release
	mkdir -p "$_bs3_release"
	cp node_modules/better-sqlite3/build/Release/better_sqlite3.node "$_bs3_release/"

	rm -rf .next/standalone/node_modules/@img

	for _mod in pino-abstract-transport split2 process-warning; do
		cp -r "node_modules/$_mod" .next/standalone/node_modules/
	done
}

do_check() {
	npm run test:unit
}

do_install() {
	vmkdir usr/lib/omniroute/.next
	vcopy .next/standalone/. usr/lib/omniroute/.next/standalone

	for _d in \
		.next/standalone/.next/server/app/dashboard \
		.next/standalone/.next/server/app/dashboard/settings \
		.next/standalone/.next/server/app/dashboard/providers; do
		touch "${DESTDIR}/usr/lib/omniroute/${_d}/.keep"
	done

	cat > "${WRKDIR}/omniroute" <<'EOF'
#!/bin/sh
export PORT="${PORT:-20128}"
export DATA_DIR="${DATA_DIR:-${XDG_DATA_HOME:-${HOME}/.local/share}/omniroute}"
export APP_LOG_TO_FILE="${APP_LOG_TO_FILE:-false}"
mkdir -p "${DATA_DIR}"
exec node /usr/lib/omniroute/.next/standalone/server.js "$@"
EOF
	vbin "${WRKDIR}/omniroute"
}

post_install() {
	vlicense LICENSE
}
```
