OmniRoute ہر درخواست کی لاگت کا تخمینہ کیسے لگاتا، اسے ریکارڈ کرتا، اور اس کی رپورٹ
کیسے پیش کرتا ہے — اور ڈیش بورڈ پر موجود عدد **بچت کا ٹریکر** کیوں ہے، بل کیوں نہیں۔

یہ بھی دیکھیں: [صارف کی رہنما کتاب](./USER_GUIDE.md) · [خصوصیات کی گیلری](./FEATURES.md)

## یہ کیا ہے (اور کیا نہیں ہے)

OmniRoute ٹوکن کی تعداد کو ماڈل کے نرخوں سے ضرب دے کر ہر تکمیل کے لیے فی درخواست
USD لاگت منسوب کرتا ہے۔ یہ اعداد **لاگتیں** ڈیش بورڈ، `omniroute cost` / `omniroute usage`
CLI، CSV/JSON برآمدات، اور فی API کلید بجٹ کو تقویت دیتے ہیں۔

> **ڈیش بورڈ کی "لاگت" بچت کا ٹریکر ہے، بل نہیں۔** OmniRoute آپ سے کبھی رقم وصول نہیں کرتا
> — یہ آپ کی درخواستوں کو ان فراہم کنندگان تک بھیجتا ہے جنہیں آپ پہلے ہی منسلک کر چکے ہیں
> (آپ کی اپنی سبسکرپشنز، مفت درجات، اور API کلیدیں)۔ مفت ماڈلز پر مکمل طور پر جمع ہونے والی
> "$290 کل لاگت" کا مطلب ہے کہ تقریباً **$290 آپ نے کسی بامعاوضہ API کو ادا _نہیں_ کیے**۔
> یہ عدد اس بات کا _تخمینہ_ ہے کہ معیاری فہرستی نرخوں پر اسی ٹریفک کی لاگت کتنی ہوتی، تاکہ
> آپ دیکھ سکیں کہ آپ کا استعمال کہاں مرتکز ہے اور سستے/مفت فراہم کنندگان تک روٹنگ سے آپ
> کتنی بچت کر رہے ہیں۔

یہ وضاحت منصوبے کی [README](../../README.md) میں براہِ راست بیان کی گئی ہے ("ڈیش بورڈ کی
'لاگت' بچت کا ٹریکر ہے، بل نہیں")۔

چونکہ یہ عدد ایک تخمینہ ہے:

- یہ ہر ماڈل کے لیے OmniRoute کے پاس موجود قیمتوں کے جدول پر منحصر ہے۔ قیمت کا اندراج نہ
  رکھنے والا ماڈل `0` لاگت شامل کرتا ہے (ایکسپلورر میں یہ "پرانا / مفت" قطار کے طور پر دکھائی دیتا ہے)۔
- مفت درجے اور سبسکرپشن کی ٹریفک پر بھی ایک _تخمینی_ لاگت جمع ہوتی ہے — یہ وہ رقم ہے
  جو آپ بچا رہے ہیں، نہ کہ وہ رقم جو آپ پر واجب الادا ہے۔

## لاگتوں کا تخمینہ کیسے لگایا جاتا ہے

### قیمتوں کا ماخذ

لاگتیں قیمتوں کے ایک جدول سے آتی ہیں، جسے ترجیح کی اس ترتیب کے مطابق حل کیا جاتا ہے
([`src/lib/pricingSync.ts`](../../src/lib/pricingSync.ts)):

1. **صارف کی اوور رائیڈز** — وہ قیمتیں جو آپ ڈیش بورڈ میں / `PATCH /api/pricing` کے ذریعے مقرر کرتے ہیں۔
2. **ہم وقت کردہ بیرونی قیمتیں** — ہم وقتی فعال ہونے پر LiteLLM کی عوامی
   `model_prices_and_context_window.json` سے حاصل کی جاتی ہیں (ایک الگ
   `pricing_synced` نیم اسپیس میں محفوظ ہوتی ہیں تاکہ وہ کبھی آپ کی اوور رائیڈز کو مٹا نہ سکیں)۔
3. **ہارڈ کوڈ شدہ طے شدہ قیمتیں** — OmniRoute کے ساتھ فراہم کی جاتی ہیں۔

بیرونی قیمتوں کی ہم وقتی **اختیاری** ہے، اور طے شدہ طور پر غیر فعال ہوتی ہے۔ متعلقہ env vars
([`.env.example`](../../.env.example) دیکھیں):

| Env var                 | طے شدہ    | مقصد                                                               |
| ----------------------- | --------- | ------------------------------------------------------------------ |
| `PRICING_SYNC_ENABLED`  | `false`   | آغاز پر پس منظر میں LiteLLM قیمتوں کی ہم وقتی فعال کریں۔           |
| `PRICING_SYNC_INTERVAL` | `86400`   | ہم وقتی کا وقفہ **سیکنڈز** میں (طے شدہ طور پر روزانہ)۔             |
| `PRICING_SYNC_SOURCES`  | `litellm` | کوما سے جدا کردہ ماخذ کی فہرست (آج صرف `litellm` معاونت یافتہ ہے)۔ |

### لاگت کا فارمولا

لاگت کا حساب فی درخواست ٹوکن کی تعداد اور فی دس لاکھ ٹوکن نرخوں سے
[`src/lib/usage/costCalculator.ts`](../../src/lib/usage/costCalculator.ts)
(`computeCostFromPricing` / `calculateCost`) میں لگایا جاتا ہے:

- **ان پٹ ٹوکنز** (کیش ریڈز اور کیش تخلیق کے ٹوکنز منہا کر کے) × `input` نرخ۔
- **کیش ریڈ ٹوکنز** × `cached` نرخ (دستیاب نہ ہونے پر ان پٹ نرخ استعمال ہوتا ہے)۔
- **کیش تخلیق کے ٹوکنز** × `cache_creation` نرخ (دستیاب نہ ہونے پر ان پٹ نرخ استعمال ہوتا ہے)۔
- **آؤٹ پٹ ٹوکنز** × `output` نرخ۔
- **استدلالی ٹوکنز** × `reasoning` نرخ (دستیاب نہ ہونے پر آؤٹ پٹ نرخ استعمال ہوتا ہے)۔

تمام نرخوں کی تشریح فی 1,000,000 ٹوکنز USD کے طور پر کی جاتی ہے۔ Codex کا "fast"/"priority" یا
"flex" سروس درجہ لاگت کا ضارب (`getCodexFastCostMultiplier`) لاگو کرتا ہے — مثلاً flex
پر ٹوکن کی قیمت میں 50% رعایت ہوتی ہے، جسے ڈیش بورڈ میں **flex بچت** کے طور پر دکھایا جاتا ہے۔

ماڈل کے نام پہلے معمول پر لائے جاتے ہیں (فراہم کنندہ پاتھ کے سابقے، جیسے `openai/` یا
`accounts/fireworks/models/`، ہٹا دیے جاتے ہیں) تاکہ تاریخی قطاریں بھی قیمت سے مماثل رہیں۔

### خرچ کیسے ریکارڈ کیا جاتا ہے

- فی درخواست لاگت کا حساب جواب کے بعد کیا جاتا ہے اور اسے بغیر انتظار کے ریکارڈ کیا جاتا ہے تاکہ
  کلائنٹ کے لیے کبھی تاخیر پیدا نہ ہو۔ مشترکہ کوٹے کی کھپت اگلے ایونٹ لوپ ٹِک پر
  [`src/lib/quota/spendRecorder.ts`](../../src/lib/quota/spendRecorder.ts) کے ذریعے شیڈول کی جاتی ہے۔
- API کلید کا خرچ بفر کیا جاتا ہے اور
  [`SpendBatchWriter`](../../src/lib/spend/batchWriter.ts) کے ذریعے بیچز میں فلش کیا جاتا ہے (طے شدہ 60s فلش وقفہ،
  1,000 اندراجات کا بفر)۔ اسے درج ذیل کے ذریعے ترتیب دیا جا سکتا ہے:

  | Env var                             | طے شدہ  | مقصد                                                  |
  | ----------------------------------- | ------- | ----------------------------------------------------- |
  | `OMNIROUTE_SPEND_FLUSH_INTERVAL_MS` | `60000` | فلش کا وقفہ ملی سیکنڈز میں۔                           |
  | `OMNIROUTE_SPEND_MAX_BUFFER_SIZE`   | `1000`  | فلش سے پہلے بفر شدہ اندراجات کی زیادہ سے زیادہ تعداد۔ |

ڈیش بورڈ میں لاگت کے اعداد کسی محفوظ شدہ فی قطار ڈالر رقم سے **نہیں** پڑھے جاتے — جب بھی
تجزیاتی اینڈ پوائنٹ چلتا ہے، انہیں ٹوکن کی تعداد اور موجودہ قیمتوں کے جدول سے اسی وقت
دوبارہ شمار کیا جاتا ہے۔ اس کا مطلب ہے کہ غلط قیمت درست کرنے (اور دوبارہ ہم وقت کرنے) سے
تاریخی لاگت کے تخمینے سابقہ مدت کے لیے بھی اپ ڈیٹ ہو جاتے ہیں۔

## ڈیش بورڈ: اخراجات کا صفحہ

**اخراجات** کا صفحہ `/dashboard/costs`
(`src/app/(dashboard)/dashboard/costs/`) پر موجود ہے۔
اس کا مرکزی منظر **اخراجات کا جائزہ** ٹیب ہے
(`src/app/(dashboard)/dashboard/costs/CostOverviewTab.tsx`)،
جو تمام ڈیٹا `GET /api/usage/analytics` سے لوڈ کرتا ہے۔

یہ کیا دکھاتا ہے:

- **اخراجات کی ٹائلز** — _آج (1d)_، _7d_، _30d_، اور منتخب کردہ
  مدت کے تخمینی اخراجات۔ مدت منتخب کرنے کے اختیارات: `7d`، `30d`، `90d`، `all`۔
- **نمایاں میٹرکس** — مدت کے دوران درخواستیں، فعال فراہم کنندگان، فعال ماڈلز، اور فی
  درخواست اوسط لاگت۔
- **کاسٹ ایکسپلورر** — ایک قابلِ ترتیب/فلٹر جدول، جس کی گروپ بندی **فراہم کنندہ**، **ماڈل**،
  **API کلید**، **اکاؤنٹ**، یا **سروس ٹیئر** کے لحاظ سے کی جا سکتی ہے، اور جس میں لاگت، درخواستیں، ٹوکنز، فی درخواست اوسط
  لاگت، اور کل میں حصہ % شامل ہیں۔
- **ٹوکن کا استعمال** — کل / ان پٹ / آؤٹ پٹ ٹوکنز اور ان پٹ:آؤٹ پٹ تناسب۔
- **روٹنگ کی کارکردگی** — فال بیک کی تعداد، فال بیک کی شرح، اور درخواست کردہ ماڈل کی کوریج۔
- **ماہانہ پیش گوئی** — حالیہ یومیہ اوسط کی بنیاد پر مہینے کے اختتام تک کے اخراجات کا تخمینہ۔
- **مدت کا موازنہ** — مدت کے پہلے اور دوسرے نصف کے درمیان % تبدیلی۔
- **چارٹس** — یومیہ لاگت کا رجحان، فراہم کنندگان کا حصہ (پائی)، سرفہرست فراہم کنندگان، سرفہرست ماڈلز، API کلید
  کے لحاظ سے لاگت، اکاؤنٹ کے لحاظ سے لاگت، ہفتہ وار استعمال کا پیٹرن، اور سرگرمی کا ہیٹ میپ۔
- **برآمد** — موجودہ مدت کو **CSV** یا **JSON** کے طور پر ڈاؤن لوڈ کریں (بٹن اس وقت
  ظاہر ہوتے ہیں جب لاگت کا ڈیٹا صفر سے زیادہ ہو)۔

جب قیمت شدہ ٹریفک موجود نہ ہو تو قطاریں `$0` کے بجائے "Legacy / Free" لیبل کے طور پر رینڈر ہوتی ہیں،
جو بچت ٹریکر ماڈل کی عکاسی کرتا ہے۔

### اخراجات سے متعلق ذیلی صفحات

اخراجات کے حصے میں یہ صفحات بھی شامل ہیں (سبھی `/dashboard/costs/` کے تحت):

- **قیمت بندی** (`/dashboard/costs/pricing`) — ہر ماڈل کی قیمتیں دیکھیں اور انہیں اوور رائیڈ کریں (مشترکہ
  قیمت بندی ٹیب کو رینڈر کرتا ہے)۔
- **بجٹ** (`/dashboard/costs/budget`) — ہر دائرۂ کار کے لیے اخراجات کی حدود مقرر کریں (مشترکہ
  بجٹ ٹیب کو رینڈر کرتا ہے)۔
- **کوٹا شیئر** (`/dashboard/costs/quota-share`) — مشترکہ کوٹا پولز اور خرچ ہونے کی شرح
  کے مناظر۔

## API اینڈ پوائنٹس

ان سب کے لیے مینجمنٹ توثیق (لوپ بیک/JWT، بذریعہ `requireManagementAuth`) درکار ہے، سوائے اس کے کہ
کچھ اور درج ہو۔

### استعمال اور لاگت کے تجزیات

| طریقہ | اینڈ پوائنٹ              | مقصد                                                                                                                                                               |
| ----- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `GET` | `/api/usage/analytics`   | لاگت/استعمال کے مکمل تجزیات: خلاصہ، یومیہ رجحان، فراہم کنندہ/ماڈل/API کلید/اکاؤنٹ/ٹیئر کے لحاظ سے۔ کوئری: `range`، `startDate`، `endDate`، `apiKeyIds`، `presets`۔ |
| `GET` | `/api/usage/utilization` | وقت کے ساتھ ہر فراہم کنندہ کے کوٹے کا استعمال۔ کوئری: `range` (`1h`/`24h`/`7d`/`30d`)، `provider`۔                                                                 |
| `GET` | `/api/usage/history`     | استعمال کی تاریخ کی خام قطاریں۔                                                                                                                                    |
| `GET` | `/api/usage/call-logs`   | ہر درخواست کے کال لاگز (ماڈل، ٹوکنز، لاگت، تاخیر، اسٹیٹس)۔                                                                                                         |
| `GET` | `/api/usage/quota`       | فراہم کنندہ کے کوٹے کی حالت۔                                                                                                                                       |
| `GET` | `/api/usage/proxy-logs`  | پراکسی درخواست کے لاگز۔                                                                                                                                            |

### بجٹس

| طریقہ  | اینڈ پوائنٹ              | مقصد                                                                                  |
| ------ | ------------------------ | ------------------------------------------------------------------------------------- |
| `GET`  | `/api/usage/budget`      | ایک API کلید کے لیے لاگت کا خلاصہ + بجٹ کی جانچ (`apiKeyId` کوئری پیرامیٹر درکار ہے)۔ |
| `POST` | `/api/usage/budget`      | ایک API کلید کے لیے یومیہ/ہفتہ وار/ماہانہ USD حدود + انتباہی حد مقرر کریں۔            |
| `GET`  | `/api/usage/budget/bulk` | API کلیدوں میں مجموعی بجٹ کے خلاصے۔                                                   |

> بجٹ API کا دائرۂ کار ہر **API کلید** (`apiKeyId`) تک محدود ہے۔ `GET /api/usage/budget`
> کی واپس کردہ حدود میں `dailyLimitUsd`، `weeklyLimitUsd`، `monthlyLimitUsd`،
> ایک `warningThreshold`، اور جاری مجموعے (`totalCostToday`، `totalCostMonth`، …) شامل ہیں۔

### قیمت بندی

| -------- | ----------------------- | ----------------------------------------------------------------------------------------------------------- |

| `DELETE` | `/api/pricing`          | قیمت بندی کو ڈیفالٹس پر ری سیٹ کریں (اختیاری طور پر `?provider=&model=` کے ذریعے دائرۂ کار محدود کریں)۔     |
| `GET`    | `/api/pricing/defaults` | فی 1M ڈیفالٹ فال بیک نرخ دکھائیں۔                                                                           |

| `DELETE` | `/api/pricing/sync`     | تمام ہم وقت شدہ قیمت بندی کا ڈیٹا صاف کریں۔                                                                 |

## CLI

OmniRoute کا CLI لاگت، استعمال، اور قیمتوں سے متعلق کمانڈز فراہم کرتا ہے (جو
[`bin/cli/commands/registry.mjs`](../../bin/cli/commands/registry.mjs) میں رجسٹرڈ ہیں)۔

### `omniroute cost`

`/api/usage/analytics` سے مجموعی لاگت کی رپورٹ۔

```bash
omniroute cost                          # گزشتہ 30d، فراہم کنندہ کے لحاظ سے گروپ کردہ
omniroute cost --period 7d              # گزشتہ 7 دن
omniroute cost --group-by model         # provider | model | combo | api-key | day کے لحاظ سے گروپ کریں
omniroute cost --since 2026-06-01 --until 2026-06-13
omniroute cost --api-key <key> --limit 50
```

کالمز: گروپ، درخواستیں، اِن/آؤٹ ٹوکنز، لاگت (USD)، اور کل کا فیصد۔ آخر میں مجموعی کل کی سطر
پرنٹ کی جاتی ہے (جسے `--quiet` یا `--output json` کے ذریعے چھپایا جا سکتا ہے)۔

### `omniroute usage`

```bash
omniroute usage analytics --period 30d [--provider <id>]   # ہر فراہم کنندہ کے لیے لاگت کا خلاصہ
omniroute usage logs [--limit 100] [--follow] [--api-key <k>] [--search <q>]
omniroute usage quota [--provider <id>] [--check]
omniroute usage utilization [--api-key <k>]
omniroute usage history [--limit 100]
omniroute usage proxy-logs [--limit 100]

# بجٹس
omniroute usage budget list
omniroute usage budget get [scope]
omniroute usage budget set <amount> [--scope global] [--period monthly]
omniroute usage budget reset [scope]
```

### `omniroute pricing`

```bash
omniroute pricing list [--provider <p>] [--model <m>] [--limit 200]
omniroute pricing get <model>
omniroute pricing sync [--provider <p>] [--force]   # POST /api/pricing/sync
omniroute pricing diff [--model <m>]
omniroute pricing defaults show
omniroute pricing defaults set [--input <p>] [--output <p>] [--cache-read <p>] [--cache-write <p>]
```

> `pricing defaults show`، `GET /api/pricing/defaults` کو پڑھتا ہے۔ اس کے بجائے انفرادی ماڈلز
> کی قیمتوں میں ترمیم کرنے کے لیے **Pricing** ڈیش بورڈ صفحہ یا `PATCH /api/pricing` استعمال کریں۔

## مسائل کا حل

- **تمام لاگتیں $0 / "Legacy / Free" دکھاتی ہیں۔** زیرِ استعمال ماڈلز کے لیے قیمت کا کوئی اندراج موجود نہیں۔
  بیرونی سنک فعال کریں (`PRICING_SYNC_ENABLED=true`) اور `omniroute pricing sync` چلائیں، یا
  Pricing صفحے / `PATCH /api/pricing` کے ذریعے دستی طور پر قیمتیں مقرر کریں۔
- **کسی تاریخی ماڈل کی قیمت غلط ہے۔** قیمت درست کریں (اوور رائیڈ یا دوبارہ سنک کریں) — ہر بار اینالیٹکس پڑھنے پر
  لاگت کو ٹوکنز کی تعداد سے دوبارہ شمار کیا جاتا ہے، اس لیے تخمینے سابقہ مدت کے لیے بھی اپ ڈیٹ ہو جاتے ہیں۔
- **اخراجات حقیقی وقت سے پیچھے ہیں۔** ہر کلید کے اخراجات بیچز میں پراسیس کیے جاتے ہیں؛ اگر آپ کو زیادہ تازہ اعداد و شمار درکار ہوں تو
  `OMNIROUTE_SPEND_FLUSH_INTERVAL_MS` کم کریں۔
