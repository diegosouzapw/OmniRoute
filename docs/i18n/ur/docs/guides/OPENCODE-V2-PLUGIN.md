`@omniroute/opencode-plugin-v2` آپ کے پورے OmniRoute کیٹلاگ — ماڈلز، کومبوز اور
آٹو کومبوز — کو OpenCode v2 کے ماڈل پیکر میں ڈسپلے ناموں، قیمتوں اور فری ٹائر
بجٹس کے ساتھ شامل کرتا ہے۔

یہ `@omniroute/opencode-plugin` سے الگ پیکیج ہے کیونکہ OpenCode v1 اور v2 پلگ اِنز کو
مختلف معاہدوں کے ذریعے لوڈ کرتے ہیں۔ اپنے OpenCode کے میجر ورژن سے مطابقت رکھنے والا پیکیج
منتخب کریں؛ ان کے درمیان کچھ بھی مشترک نہیں، اس لیے ایک کو اپ گریڈ کرنے سے دوسرے کو اپ گریڈ
کرنا لازم نہیں ہوتا۔

## تقاضے

- OpenCode v2۔
- قابلِ رسائی OmniRoute گیٹ وے (ڈیفالٹ طور پر `http://localhost:20128`)۔
- Node.js 22 یا 24۔

## انسٹالیشن

پلگ اِن کو `opencode.json` میں شامل کریں:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

اس کے بعد ماڈلز `omniroute/<provider>/<model>` کے طور پر ظاہر ہوتے ہیں؛ `providerId` اس سابقے
اور اس انٹیگریشن کی id کا تعین کرتا ہے جس کے تحت OpenCode اسناد محفوظ کرتا ہے۔

## اسناد

پلگ اِن درج ذیل تین مقامات پر، اسی ترتیب سے، گیٹ وے کلید تلاش کرتا ہے:

1. **وہ سند جسے آپ نے OpenCode میں منسلک کیا ہے۔** پلگ اِن ایک انٹیگریشن رجسٹر کرتا ہے، لہٰذا
   OpenCode کا اپنا تصدیقی عمل کلید محفوظ کر سکتا ہے۔ `opencode.json` میں کچھ بھی درج نہیں ہوتا — اسے ترجیح دیں۔
2. پلگ اِن کے آپشنز میں `apiKey`، فی پروجیکٹ اوور رائیڈ کے لیے۔ اس سے کلید ایک ایسی فائل میں
   آ جاتی ہے جسے آپ ممکنہ طور پر کمیٹ کر رہے ہوں۔
3. ماحول میں `OMNIROUTE_API_KEY`۔

اگر ان تینوں میں سے کوئی بھی موجود نہ ہو تو کیٹلاگ خالی رہتا ہے، اور پلگ اِن خاموشی سے خالی پیکر
چھوڑنے کے بجائے آغاز پر ایک بار اس کی اطلاع دیتا ہے۔

### مینجمنٹ ٹوکن ایک مختلف کلید ہے

کومبوز، فراہم کنندہ کی صحت، اور افزودگی (ڈسپلے نام، قیمتیں، فری ٹائر بجٹس) گیٹ وے کے
`/api/*` اینڈ پوائنٹس سے آتے ہیں، جنہیں زیادہ تر تعیناتیاں اِنفرنس کلید کے بجائے ایک **مینجمنٹ** ٹوکن
کے ذریعے محفوظ کرتی ہیں:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

اگر `managementReadToken` سیٹ نہ ہو تو یہ `apiKey` کو متبادل کے طور پر استعمال کرتا ہے۔ جب کوئی گیٹ وے اس متبادل
کو مسترد کرتا ہے تو کیٹلاگ پھر بھی شائع ہوتا ہے، لیکن ڈسپلے ناموں کے بجائے خام ماڈل ids کے ساتھ،
کینونیکل عرف کی تکرار ختم کیے بغیر، قیمتوں کے بغیر، اور کومبوز کے بغیر۔ ایسا ہونے پر پلگ اِن ہر اینڈ پوائنٹ کے لیے
ایک بار تنبیہ کرتا ہے، جس میں اینڈ پوائنٹ اور ضائع ہونے والی معلومات کا نام شامل ہوتا ہے — اس لیے محدود پیکر کبھی معمہ نہیں رہتا۔

## آپشنز

| کلید                             | ڈیفالٹ                             | نوٹس                                                                                                                         |
| -------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                      | فراہم کنندہ کی id، انٹیگریشن کی id، اور وہ سابقہ جس کے تحت ماڈلز ظاہر ہوتے ہیں                                               |
| `baseURL`                        | درکار                              | گیٹ وے روٹ، صرف `http(s)`؛ ضرورت کے مطابق `/v1` لاحقہ شامل کیا جاتا ہے                                                       |
| `apiKey`                         | منسلک سند، پھر `OMNIROUTE_API_KEY` | `/v1/*` کے لیے چیٹ کلید                                                                                                      |
| `managementReadToken`            | متبادل کے طور پر `apiKey`          | `/api/*` کے لیے کلید — عموماً **وہی** کلید نہیں ہوتی                                                                         |
| `displayName`                    | `"OmniRoute"`                      | پیکر میں فراہم کنندہ کا نام                                                                                                  |
| `timeoutMs`                      | `10000`                            | فی اینڈ پوائنٹ فیچ ٹائم آؤٹ (آٹو کومبوز 5s استعمال کرتے ہیں)                                                                 |
| `modelCacheTtlMs`                | `300000`                           | کیٹلاگ کیش TTL؛ ڈسک اسنیپ شاٹ کولڈ اسٹارٹس کو تیز کرتا ہے                                                                    |
| `timeouts`                       | متبادل کے طور پر `timeoutMs`       | ms میں فی اینڈ پوائنٹ بجٹس: `models`، `combos`، `autoCombos`، `enrichment`                                                   |
| `enrichment`                     | `true`                             | نام، قیمتیں اور فری ٹائر بجٹس حاصل کریں                                                                                      |
| `providerTag`                    | `true`                             | ڈسپلے نام سے پہلے اس اپ اسٹریم فراہم کنندہ کا نام لگائیں جس کی طرف یہ روٹ کرتا ہے                                            |
| `usableOnly`                     | `false`                            | صرف ان فراہم کنندگان کو رکھیں جنہیں گیٹ وے پروویژن شدہ رپورٹ کرتا ہے                                                         |
| `visibleModels` / `hiddenModels` | `[]`                               | عین مطابق یا لاحقے پر مبنی اجازت فہرستیں؛ ممانعت کو فوقیت حاصل ہے                                                            |
| `geminiSanitization`             | `true`                             | ٹول اسکیماؤں سے JSON-Schema کے وہ کلیدی الفاظ ہٹائیں جنہیں Gemini مسترد کرتا ہے (`$ref` ٹولز بغیر تبدیلی کے فارورڈ ہوتے ہیں) |
| `apiFormat.allowAnthropic`       | `false`                            | اجازت فہرست میں شامل ids کو Anthropic API بلاک کے ذریعے روٹ کریں                                                             |
| `apiFormat.anthropicModels`      | `[]`                               | Anthropic کی طرف روٹ کیے جانے والے مکمل ماڈل ids                                                                             |
| `logLevel` / `startupDebug`      | `warn` / `false`                   | لاگر کی تفصیل کی سطح                                                                                                         |

## کیٹلاگ تازہ کیسے رہتا ہے

کیٹلاگ ضرورت کے وقت حاصل کیا جاتا ہے اور `modelCacheTtlMs` کے لیے کیش کیا جاتا ہے، جبکہ ڈسک اسنیپ شاٹ آخری معلوم کیٹلاگ کو اس وقت بھی دستیاب رکھتا ہے جب گیٹ وے ناقابلِ رسائی ہو — بندش سے آپ کا تازگی کے سوا کچھ متاثر نہیں ہوتا۔ ماڈلز اور کومبوز آتے ہی شائع کر دیے جاتے ہیں؛ آٹو کومبوز، فراہم کنندگان کی فہرست اور افزودگی اوورلے دستیاب ہوتے ہی شامل ہو جاتے ہیں، لہٰذا ایک سست اینڈ پوائنٹ پورے ماڈل چنندہ کو معطل نہیں رکھ سکتا۔

ناموں میں وہ معلومات شامل ہوتی ہیں جو گیٹ وے جانتا ہے: وہ اپ اسٹریم فراہم کنندہ جس کی طرف ماڈل روٹ ہوتا ہے، ایک `[Free]` نشان، اور اس کے ساتھ ملنے والا بجٹ — یوں ایک ہی ماڈل فروخت کرنے والے دو کنکشنز میں فرق برقرار رہتا ہے۔ `"providerTag": false` کے ذریعے سابقہ بند کریں۔

دستی ریفریش کی کوئی کمانڈ نہیں ہے: OpenCode v2 کمانڈز پرامپٹ ٹیمپلیٹس ہیں، کال بیکس نہیں، اس لیے پلگ اِن ایسی کمانڈ فراہم نہیں کر سکتا۔ ریفریش TTL کے مطابق ہوتے ہیں؛ ہوسٹ سے صرف اسی وقت دوبارہ لوڈ کرنے کو کہا جاتا ہے جب کیٹلاگ یا اوورلے واقعی تبدیل ہوا ہو، نہ کہ ہر ریفریش پر۔

## Gemini پر ٹول کالنگ

Gemini ایسی پوری درخواست مسترد کر دیتا ہے جس کے ٹول ڈیکلریشنز میں `$schema` یا `additionalProperties` موجود ہوں، اور جواب میں `400 INVALID_ARGUMENT` دیتا ہے۔ پلگ اِن اس فراہم کنندہ کے Gemini ماڈل کو بھیجے جانے والے ٹول اسکیماؤں سے ان کلیدی الفاظ کو ہٹا دیتا ہے اور باقی ہر درخواست کو بغیر تبدیلی کے چھوڑ دیتا ہے۔ `$ref` رکھنے والا ٹول حذف و ترمیم کے بغیر آگے بھیج دیا جاتا ہے، کیونکہ ریفرنس ہٹانے سے اسکیما وسیع ہو کر "کچھ بھی قبول کریں" بن جائے گا۔
اسے بند کرنے کے لیے `"geminiSanitization": false` مقرر کریں۔

## مسائل کا ازالہ

| علامت                                          | وجہ                                                                                                                   |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| چنندہ کوئی OmniRoute ماڈل نہیں دکھاتا          | کوئی کلید دستیاب نہیں ہوئی (آغاز کی تنبیہ دیکھیں)، یا گیٹ وے ناقابلِ رسائی ہے                                         |
| خام ماڈل ids، کوئی کومبوز نہیں، کوئی قیمت نہیں | انتظامی اینڈ پوائنٹس نے ٹوکن مسترد کر دیا — `managementReadToken` مقرر کریں                                           |
| `opencode-<id>/…` سے منسلک سیشن                | v1 پلگ اِن نے `opencode-<id>` شائع کیا تھا؛ v2 صرف `<id>` شائع کرتا ہے، اس لیے `<id>/…` کے تحت ماڈل دوبارہ منتخب کریں |
