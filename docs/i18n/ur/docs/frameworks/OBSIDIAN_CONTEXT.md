## یہ کیا ہے

OmniRoute ایک **Obsidian** والٹ سے بطور **سیاقی ماخذ** منسلک ہوتا ہے — ایک مقامی Markdown
نالج بیس جسے ایجنٹس بلٹ اِن MCP سرور کے ذریعے پڑھتے اور اس میں لکھتے ہیں۔ یہ
انٹیگریشن ڈیسک ٹاپ ایپ کے اندر چلنے والے کمیونٹی پلگ اِن **Obsidian Local REST API**
سے رابطہ کرتا ہے، تاکہ ایجنٹس نوٹس تلاش کر سکیں، فائلیں پڑھ/لکھ/پیچ کر سکیں، والٹ کی
فہرست دیکھ سکیں، روزانہ/ہفتہ وار دوریاتی نوٹس کے ساتھ کام کر سکیں، ٹیگز منظم کر سکیں،
Obsidian کمانڈز چلا سکیں، اور (اختیاری طور پر) دو طرفہ ڈیسک ٹاپ↔موبائل والٹ سنک کو
مربوط کر سکیں۔

کلائنٹ (`src/lib/obsidian/api.ts`) Local REST API کو درج ذیل خصوصیات کے ساتھ ریپ کرتا ہے:

- عارضی `5xx` خرابیوں کے لیے **بیک آف کے ساتھ دوبارہ کوشش**، اور `AbortController` کے ذریعے **30 سیکنڈ کا ٹائم آؤٹ**۔
- **ٹائپ شدہ خرابیوں کی درجہ بندی** — `ObsidianAuthError` (401/403)،
  `ObsidianNotFoundError` (404)، `ObsidianServerError` (5xx)، `ObsidianTimeoutError`۔
- ایک **آسان فہم "Obsidian تک رسائی ممکن نہیں" اشارہ** جو پورٹ کی عام غلطی
  (HTTP کے لیے `27123`، `27124` پر موجود MCP اینڈ پوائنٹ **نہیں**) اور Tailscale فارمیٹ کی وضاحت کرتا ہے۔
- والٹ سے متعلق **پاتھ انکوڈنگ** تاکہ اسپیسز/سلیشز والے نوٹ پاتھ محفوظ رہیں۔

## سیٹ اپ

Obsidian ٹوکن یا بنیادی URL کے لیے **کوئی ماحولیتی متغیر نہیں ہے** — دونوں کو
`src/lib/db/obsidian.ts` کے ذریعے SQLite کی `key_value` ٹیبل (نیم اسپیس `obsidian`) میں
محفوظ کیا جاتا ہے۔ ٹوکن **محفوظ حالت میں انکرپٹ شدہ** ہوتا ہے (AES-256-GCM، نیز
سادہ متن کے لیے پسماندہ مطابقت کا فال بیک)۔ Endpoint ڈیش بورڈ کے **Context Sources**
ٹیب (`ObsidianSourceCard`) سے، یا ترتیباتی REST API کے ذریعے کنفیگر کریں۔

> [!IMPORTANT]
> **Obsidian Local REST API** پلگ اِن کا انسٹال اور فعال ہونا ضروری ہے۔ اس کا REST
> انٹرفیس **HTTP `127.0.0.1:27123`** (ڈیفالٹ بنیادی URL) پر سنتا ہے۔ پورٹ `27124`
> ایک _علیحدہ_ MCP/HTTPS اینڈ پوائنٹ ہے اور ترتیباتی روٹ اسے واضح طور پر مسترد کرتا ہے۔
> کسی دوسرے آلے سے منسلک ہوتے وقت `http://<tailscale-ip>:27123` استعمال کریں۔

### کنفیگریشن کیز (SQLite `key_value`، نیم اسپیس `obsidian`)

| کلید              | مقصد                                              | انکرپٹ شدہ |
| ----------------- | ------------------------------------------------- | ---------- |
| `api_key`         | Local REST API بیئرر ٹوکن                         | ہاں        |
| `base_url`        | REST بنیادی URL (ڈیفالٹ `http://127.0.0.1:27123`) | نہیں       |
| `vault_path`      | والٹ ڈائریکٹری کا مطلق پاتھ (سنک کے لیے)          | نہیں       |
| `webdav_username` | تیار کردہ WebDAV صارف نام (والٹ سنک)              | نہیں       |
| `webdav_password` | تیار کردہ WebDAV پاس ورڈ (والٹ سنک)               | ہاں        |
| `webdav_enabled`  | آیا WebDAV والٹ سنک فعال ہے                       | نہیں       |

### REST کے ذریعے کنفیگر کریں

```bash
# Local REST API ٹوکن محفوظ + توثیق کریں (POST اسٹیٹس چیک کے ذریعے توثیق کرتا ہے)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# کنکشن اسٹیٹس چیک کریں (connected، hasToken، baseUrl، vaultPath واپس کرتا ہے)
curl http://localhost:20128/api/settings/obsidian

# منقطع کریں (محفوظ شدہ ٹوکن صاف کرتا ہے)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

تمام طریقوں کے لیے ڈیش بورڈ کی تصدیق درکار ہے۔ `POST` پورٹ `27124` پر موجود کسی بھی URL
کو مسترد کرتا ہے اور محفوظ کرنے سے پہلے Local REST API کے اسٹیٹس اینڈ پوائنٹ کو کال
کر کے ٹوکن کی توثیق کرتا ہے۔

### WebDAV والٹ سنک

`src/app/api/settings/obsidian/webdav/route.ts` ایک اختیاری WebDAV پر مبنی
والٹ سنک کو منظم کرتا ہے (جسے `src/lib/obsidianSync.ts` چلاتا ہے)۔ اسے فعال کرنے سے
OmniRoute ایک مقامی والٹ ڈائریکٹری کی طرف اشارہ کرتا ہے اور WebDAV کے لیے بے ترتیب
صارف نام/پاس ورڈ کا جوڑا تیار کرتا ہے:

```bash
# والٹ ڈائریکٹری کے لیے WebDAV سنک فعال کریں (صارف نام/پاس ورڈ تیار کرتا ہے)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV سنک اسٹیٹس حاصل کریں (اسناد صرف فعال ہونے کی حالت میں واپس کی جاتی ہیں)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV سنک غیر فعال کریں (اسناد + زیرِ انتظام .stignore صاف کرتا ہے)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### فی API کلید سیاقی ماخذ (اختیاری)

Obsidian کنفیگ کو `api_key_context_sources` ٹیبل کے ذریعے **فی API کلید** اسکوپ کیا
جا سکتا ہے (`src/lib/db/apiKeyContextSources.ts`)۔ جب کسی MCP کال کے ساتھ تصدیق شدہ API
کلید کی id موجود ہو، تو `getObsidianConfigForApiKey()` اس کلید کے اپنے ٹوکن/بنیادی
URL/والٹ پاتھ (`source: "api_key"`) کو ترجیح دیتا ہے، اور بصورتِ دیگر عالمی کنفیگ
(`source: "global"`) کو فال بیک کے طور پر استعمال کرتا ہے۔

## MCP ٹولز (22)

`open-sse/mcp-server/tools/obsidianTools.ts` میں متعین ہیں۔ ٹوکن/base-URL ہر کال کے لیے حل کیے جاتے ہیں (پہلے فی-API-key، پھر عالمی)۔ OmniRoute **sync server** سے رابطہ کرنے والے ٹولز (چار `obsidian_sync_*` ٹولز) کے لیے اضافی طور پر OmniRoute کی ترتیبات میں تشکیل کردہ sync auth token درکار ہوتا ہے۔

### پڑھنے کے ٹولز (`read:obsidian`)

| ٹول                          | وضاحت                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | جانچیں کہ آیا Local REST API قابلِ رسائی ہے اور اس کی توثیق ہو چکی ہے۔                           |
| `obsidian_search_simple`     | نوٹ کے مواد میں مکمل متن کی تلاش؛ فائل پاتھز کے ساتھ اقتباسات لوٹاتا ہے۔                         |
| `obsidian_search_structured` | JSON Logic expression (and/or/regex/path فلٹرز) استعمال کرتے ہوئے تلاش کریں۔                     |
| `obsidian_read_note`         | vault-relative path کے ذریعے نوٹ پڑھیں؛ اختیاری طور پر کوئی مخصوص heading/block/frontmatter۔     |
| `obsidian_list_vault`        | vault میں موجود فائلوں اور ڈائریکٹریز کی فہرست بنائیں (اندراجات کی tree)۔                        |
| `obsidian_get_document_map`  | نوٹ کی heading ساخت کو headings → line numbers کے نقشے کے طور پر حاصل کریں۔                      |
| `obsidian_get_note_metadata` | مکمل مواد کے بغیر frontmatter، tags، links، اور حروف/الفاظ کی تعداد حاصل کریں۔                   |
| `obsidian_get_active_file`   | Obsidian میں فی الحال فعال فائل کا path + content حاصل کریں۔                                     |
| `obsidian_get_periodic_note` | کسی تاریخ کے لیے روزانہ/ہفتہ وار/ماہانہ periodic note حاصل کریں (اگر تاریخ نہ دی جائے تو آج کا)۔ |
| `obsidian_get_tags`          | vault کے تمام tags کو ان کی frequencies کے ساتھ فہرست کریں۔                                      |
| `obsidian_list_commands`     | دستیاب Obsidian command IDs کی فہرست بنائیں (`obsidian_execute_command` کے ساتھ استعمال کریں)۔   |
| `obsidian_sync_status`       | OmniRoute sync server کی حالت: چل رہا ہے یا نہیں، vault کا نام، port، uptime، آخری sync۔         |
| `obsidian_sync_conflicts`    | حل نہ ہونے والے sync conflicts کی فہرست بنائیں (path، conflict path، detected-at)۔               |

### لکھنے کے ٹولز (`write:obsidian`)

| ٹول                              | وضاحت                                                                                     |
| -------------------------------- | ----------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | دیے گئے Markdown مواد کے ساتھ نوٹ بنائیں یا اسے overwrite کریں۔                           |
| `obsidian_append_note`           | نوٹ میں مواد شامل کریں؛ اختیاری طور پر کسی مخصوص heading/block میں۔                       |
| `obsidian_patch_note`            | heading، block، یا frontmatter field پر درستگی سے append/prepend/replace کریں۔            |
| `obsidian_delete_note`           | vault سے نوٹ مستقل طور پر حذف کریں۔                                                       |
| `obsidian_move_note`             | vault کے اندر نوٹ منتقل کریں یا اس کا نام تبدیل کریں۔                                     |
| `obsidian_execute_command`       | Obsidian command کو اس کی command ID کے ذریعے چلائیں۔                                     |
| `obsidian_open_file`             | Obsidian میں فائل کھولیں (اگر موجود نہ ہو تو اسے بنا دیتا ہے)۔                            |
| `obsidian_sync_trigger`          | فوری دوطرفہ desktop↔mobile vault sync شروع کریں۔                                          |
| `obsidian_sync_resolve_conflict` | sync conflict حل کریں: `local` (mobile)، `remote` (desktop)، یا `keep-both` برقرار رکھیں۔ |

> [!NOTE]
> `obsidian_patch_note` کے targets، `heading | block | frontmatter` میں سے کوئی `targetType`
> اور `append | prepend | replace` میں سے کوئی `operation` قبول کرتے ہیں، جبکہ
> `createTargetIfMissing` اختیاری ہے۔ چار `obsidian_sync_*` ٹولز مقامی sync
> server (بطور ڈیفالٹ `http://127.0.0.1:27781`) سے رابطہ کرتے ہیں اور ان کے لیے sync token درکار ہے۔

### Scopes

پڑھنے کے ٹولز کے لیے `read:obsidian`؛ لکھنے کے ٹولز کے لیے `write:obsidian` درکار ہے۔ نفاذ
Notion جیسا ہی ہے — اسے `open-sse/mcp-server/server.ts` میں `withScopeEnforcement()` کے ذریعے
سنبھالا جاتا ہے، `OMNIROUTE_MCP_ENFORCE_SCOPES=true` کے تحت فعال کیا جاتا ہے، جبکہ
اجازت یافتہ scopes، `OMNIROUTE_MCP_SCOPES` یا API key کے scope context سے حاصل ہوتے ہیں۔ دیکھیں
[MCP-SERVER.md](./MCP-SERVER.md)۔

## اینڈ پوائنٹس

| طریقہ    | راستہ                           | مقصد                                                             |
| -------- | ------------------------------- | ---------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | `{ connected, hasToken, baseUrl, vaultPath }` واپس کرتا ہے۔      |
| `POST`   | `/api/settings/obsidian`        | ٹوکن محفوظ اور توثیق کرتا ہے (پورٹ `27124` مسترد کر دی جاتی ہے)۔ |
| `DELETE` | `/api/settings/obsidian`        | منقطع کرتا ہے (محفوظ شدہ ٹوکن صاف کرتا ہے)۔                      |

| `POST`   | `/api/settings/obsidian/webdav` | والٹ ڈائریکٹری کے لیے WebDAV سنک فعال کرتا ہے۔                   |
| `DELETE` | `/api/settings/obsidian/webdav` | WebDAV سنک غیر فعال کرتا ہے۔                                     |

> یہ ڈیش بورڈ کی ترتیبات کے روٹس ہیں۔ خود والٹ تک Obsidian
> Local REST API (ترتیب شدہ `base_url`) اور اوپر دیے گئے MCP ٹولز کے ذریعے رسائی حاصل کی جاتی ہے —
> کوئی عوامی `/v1` Obsidian پراکسی اینڈ پوائنٹ موجود نہیں ہے۔

## استعمال کے منظرنامے

- **والٹ پر مبنی جوابات** — `obsidian_search_simple` / `obsidian_search_structured`
  اور پھر `obsidian_read_note`، تاکہ ایجنٹ آپ کے حقیقی نوٹس کی بنیاد پر جواب دے۔
- **نوٹ لکھنا / روزنامچہ نویسی** — ایجنٹ کی آؤٹ پٹ، خلاصے، یا روزانہ کے نوٹس
  (`obsidian_get_periodic_note`) والٹ میں درج کرنے کے لیے `obsidian_write_note`، `obsidian_append_note`، یا
  مخصوص تبدیلیوں کے لیے `obsidian_patch_note`۔
- **والٹ میں نیویگیشن** — پڑھنے/لکھنے سے پہلے ساخت دریافت کرنے کے لیے `obsidian_list_vault`، `obsidian_get_document_map`، اور
  `obsidian_get_tags`۔
- **Obsidian آٹومیشن** — ایجنٹ کے ذریعے پلگ انز/کمانڈز چلانے کے لیے `obsidian_list_commands` + `obsidian_execute_command`؛
  UI میں نوٹ دکھانے کے لیے `obsidian_open_file`۔
- **موبائل سنک** — WebDAV سنک فعال کریں، پھر ڈیسک ٹاپ↔موبائل ہم وقت سازی اور تنازعات حل کرنے کے لیے `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  استعمال کریں۔
