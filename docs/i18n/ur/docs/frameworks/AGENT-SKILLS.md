> **مستند ماخذ:** `src/lib/agentSkills/` (کیٹلاگ، جنریٹر، پارسرز) + `skills/` ڈائریکٹری (SKILL.md فائلیں)
> **آخری بار اپ ڈیٹ کیا گیا:** 2026-08-02 — v3.8.50

Agent Skills منظم SKILL.md فائلیں ہیں جو بیرونی ایجنٹس، MCP کلائنٹس، اور A2A آرکیسٹریٹرز کو OmniRoute کی REST API اور CLI استعمال کرنے کا طریقہ سکھاتی ہیں۔ [Omni Skills](./SKILLS.md) (جو OmniRoute کے اندر چلائی جانے والی LLM ٹول تعریفیں ہیں) کے برعکس، Agent Skills ایک _دستاویزی کیٹلاگ_ ہیں — جامد مارک ڈاؤن جسے براہِ راست ایجنٹ کے سیاق و سباق میں شامل کیا جا سکتا ہے۔

---

## جائزہ

کیٹلاگ میں **45 Agent Skills** شامل ہیں (23 REST API + 21 CLI + 1 کنفیگریشن ورک فلو)۔ ہر اسکل میں یہ چیزیں ہوتی ہیں:

- ایک **کینونیکل ID** (`omni-auth`، `cli-serve`، وغیرہ)
- `skills/{id}/SKILL.md` میں ایک **SKILL.md** فائل، جس میں YAML فرنٹ میٹر (`name`، `description`) + تفصیلی مارک ڈاؤن باڈی ہوتی ہے
- OpenAPI اسپیک اور CLI رجسٹری سے اخذ کردہ **REST اینڈ پوائنٹس** (API اسکلز) یا **CLI ذیلی کمانڈز** (CLI اسکلز)
- براہِ راست حاصل کرنے کے لیے ایک **GitHub خام URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

```markdown

name: omni-providers

---

<!-- src/lib/agentSkills/generator.ts کے ذریعے تیار کردہ؛ دستی ترامیم اوور رائٹ ہو جائیں گی -->

## جائزہ

...

## توثیق

...

## اینڈ پوائنٹس

...

<!-- skill:custom-start -->
```

دوبارہ تیاری کے دوران جنریٹر `<!-- skill:custom-start -->` اور `<!-- skill:custom-end -->` کے درمیان موجود مواد کو محفوظ رکھتا ہے۔ دس اسکلز میں منتخب حسبِ ضرورت بلاکس ہیں:

`omni-mcp`، `omni-compression`، `cli-providers`، `cli-eval`، `omni-agents-a2a`، `omni-combos-routing`، `omni-auth`، `omni-resilience`، `omni-inference`، `cli-serve`۔

## REST API دریافت کاری

| اینڈ پوائنٹ                  | طریقہ | وضاحت                                                              | توثیق     |
| :--------------------------- | :---- | :----------------------------------------------------------------- | :-------- |
| `/api/agent-skills`          | GET   | کیٹلاگ کی فہرست (اختیاری `?category=api\|cli\|config&area=<area>`) | کوئی نہیں |
| `/api/agent-skills/{id}`     | GET   | کسی ایک اسکل کا میٹا ڈیٹا حاصل کریں                                | کوئی نہیں |
| `/api/agent-skills/{id}/raw` | GET   | SKILL.md کو `text/markdown` کے طور پر حاصل کریں                    | کوئی نہیں |
| `/api/agent-skills/coverage` | GET   | کوریج کے اعداد و شمار (کتنی SKILL.md فائلیں موجود ہیں)             | کوئی نہیں |
| `/api/agent-skills/generate` | POST  | جنریٹر متحرک کریں (dryRun/prune/onlyIds)                           | انتظامی   |

مثال — تمام API اسکلز کی فہرست:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

مثال — ایک SKILL.md حاصل کریں:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## بیرونی ایجنٹس اسکلز کو کیسے استعمال کرتے ہیں

### 1. REST کے ذریعے دریافت

```bash
# مکمل کیٹلاگ حاصل کریں
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# سیاق و سباق شامل کرنے کے لیے SKILL.md حاصل کریں
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP کے ذریعے دریافت

```typescript
// ایک Claude Desktop / Cursor MCP کلائنٹ میں:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → AgentSkill کی صف، جس میں ہر ایک کے لیے rawUrl موجود ہے
```

### 3. A2A کے ذریعے دریافت

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table ایک markdown جدول ہے جس میں تمام 45 اسکل IDs اور rawUrl کالم موجود ہیں
```

### 4. GitHub سے براہ راست raw حصول (سرور درکار نہیں)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## جنریٹر

جنریٹر منتخب شدہ کیٹلاگ + OpenAPI تفصیلات + CLI رجسٹری کو پڑھتا ہے اور ہر اندراج کے لیے `skills/{id}/SKILL.md` لکھتا ہے:

```bash
# پیش منظر (آزمائشی اجرا، کوئی تحریر نہیں)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# مکمل ازسرِنو تخلیق
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# مخصوص IDs کو ازسرِنو تخلیق کریں
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

جنریٹر کا جواب ایک `GeneratorReport` ہے:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
