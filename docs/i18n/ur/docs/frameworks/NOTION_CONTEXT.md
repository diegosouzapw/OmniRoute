> **حتمی ماخذ:** `src/lib/notion/api.ts` (REST کلائنٹ)، `src/lib/db/notion.ts`
> (ٹوکن کی مستقل ذخیرہ کاری)، `open-sse/mcp-server/tools/notionTools.ts` (6 MCP ٹولز)،
> `src/app/api/settings/notion/route.ts` (ترتیبات API)۔ ٹول رجسٹریشن اور اسکوپ
> وائرنگ `open-sse/mcp-server/server.ts` میں موجود ہے۔

## یہ کیا ہے

OmniRoute ایک **Notion** ورک اسپیس سے بطور **سیاقی ماخذ** منسلک ہو سکتا ہے — ایک پڑھنے/لکھنے
کے قابل علمی ذخیرہ، جس تک ایجنٹس بلٹ اِن MCP سرور کے ذریعے رسائی حاصل کرتے ہیں۔ Notion
انٹیگریشن ٹوکن کنفیگر ہو جانے کے بعد، MCP ٹولز LLM کو صفحات اور ڈیٹابیسز تلاش کرنے،
صفحے کا مواد اور بلاک ٹریز پڑھنے، فلٹرز/ترتیب کے ساتھ ڈیٹابیسز کوئری کرنے، اور نئے
بلاکس شامل کرنے کی سہولت دیتے ہیں — یہ سب OmniRoute کے ذریعے پراکسی ہوتا ہے (دوبارہ کوشش،
ٹائم آؤٹ، اور خرابی کی درجہ بندی کے ساتھ)، تاکہ ماڈل کبھی بھی براہِ راست Notion API
تک رسائی حاصل نہ کرے۔

یہ انٹیگریشن آفیشل Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) کے اوپر ایک مختصر مگر مضبوط حفاظتی تہہ ہے۔ کلائنٹ
(`src/lib/notion/api.ts`) درج ذیل خصوصیات شامل کرتا ہے:

- `429` اور `5xx` کے لیے **ایکسپونینشل بیک آف کے ساتھ دوبارہ کوشش** (زیادہ سے زیادہ 3 کوششیں)۔
- `AbortController` کے ذریعے **55 سیکنڈ کا ریکوئسٹ ٹائم آؤٹ**۔
- **ٹائپ شدہ خرابی کی درجہ بندی** — `NotionAuthError` (401/403)،
  `NotionNotFoundError` (404)، `NotionRateLimitError` (429، `retry after`
  اشاروں کا لحاظ رکھتا ہے)، `NotionValidationError` (400/409)، `NotionServerError` (5xx)،
  `NotionTimeoutError`۔
- **پیغام کی صفائی**، جو ظاہر کرنے سے پہلے اسٹیک ٹریس جیسے حصے ہٹا دیتی ہے۔

## سیٹ اپ

Notion ٹوکن کے لیے **کوئی انوائرمنٹ ویری ایبل نہیں ہے** — اسے
`src/lib/db/notion.ts` کے ذریعے SQLite کی `key_value` ٹیبل (نیم اسپیس `notion`، کلید `integration_token`) میں
محفوظ کیا جاتا ہے۔ اسے Endpoint ڈیش بورڈ کے **Context Sources** ٹیب
(`ObsidianSourceCard` کے ہم سطح `NotionSourceCard`) سے، یا ترتیبات REST API کے ذریعے کنفیگر کریں۔

> [!NOTE]
> یہ ٹوکن ایک **Notion اندرونی انٹیگریشن ٹوکن** ہے۔ ایک انٹیگریشن
> <https://www.notion.com/my-integrations> پر بنائیں، پھر وہ صفحات/ڈیٹابیسز، جن تک آپ
> OmniRoute کو رسائی دینا چاہتے ہیں، اس انٹیگریشن کے ساتھ شیئر کریں (Notion کا اجازتوں کا ماڈل شیئرنگ پر مبنی ہے،
> پورے ورک اسپیس پر نہیں)۔

### REST کے ذریعے کنفیگر کریں

```bash
# انٹیگریشن ٹوکن محفوظ اور توثیق کریں (POST ایک آزمائشی تلاش جاری کر کے توثیق کرتا ہے)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# کنکشن کی حالت چیک کریں
curl http://localhost:20128/api/settings/notion

# منقطع کریں (محفوظ شدہ ٹوکن صاف کر دیتا ہے)
curl -X DELETE http://localhost:20128/api/settings/notion
```

تینوں طریقوں کے لیے ڈیش بورڈ کی تصدیق (`isAuthenticated`) درکار ہے۔ `POST` پر،
OmniRoute ٹوکن محفوظ کرتا ہے اور فوراً 1 نتیجے والی آزمائشی تلاش چلاتا ہے؛ اگر Notion
ایک خرابی آبجیکٹ واپس کرے تو ٹوکن صاف کر دیا جاتا ہے اور کال `400` کے ساتھ ناکام ہو جاتی ہے۔

## MCP ٹولز (6)

`open-sse/mcp-server/tools/notionTools.ts` میں متعین ہیں۔ ٹوکن کو کال
کے وقت `getNotionToken()` کے ذریعے حاصل کیا جاتا ہے؛ اگر کوئی ٹوکن کنفیگر نہ ہو تو ٹول
`"Notion integration token not configured. Set it in Settings > Context Sources."`
خرابی پھینکتا ہے۔

| ٹول                          | اسکوپ          | تفصیل                                                                                       |
| ---------------------------- | -------------- | ------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | متنی کوئری کے ذریعے صفحات اور ڈیٹابیسز تلاش کریں (عنوان، IDs، URLs واپس کرتا ہے)۔ صفحہ بند۔ |
| `notion_get_page`            | `read:notion`  | کسی صفحے کی ID کے ذریعے اس کا مواد اور میٹا ڈیٹا حاصل کریں۔                                 |
| `notion_list_block_children` | `read:notion`  | کسی بلاک یا صفحے کے تمام ذیلی بلاکس (بلاک ٹری) کی فہرست بنائیں۔ صفحہ بند۔                   |
| `notion_query_database`      | `read:notion`  | اختیاری `filter` + `sorts` (Notion API فارمیٹ) کے ساتھ ڈیٹابیس کوئری کریں۔ صفحہ بند۔        |
| `notion_get_database`        | `read:notion`  | ID کے ذریعے ڈیٹابیس کا اسکیما/میٹا ڈیٹا حاصل کریں۔                                          |
| `notion_append_blocks`       | `write:notion` | موجودہ بلاک یا صفحے میں ذیلی بلاکس شامل کریں (فی ریکوئسٹ زیادہ سے زیادہ 100 بلاکس)۔         |

### ان پٹ پیرامیٹرز

- `notion_search` — `query` (1–500 حروف)، `pageSize` (1–100، ڈیفالٹ 20)،
  `startCursor` (اختیاری)۔
- `notion_get_page` — `pageId` (32 حروف پر مشتمل hex یا UUID)۔
- `notion_list_block_children` — `blockId`، `pageSize` (1–100، ڈیفالٹ 50)،
  `startCursor` (اختیاری)۔
- `notion_query_database` — `databaseId`، `filter` (اختیاری، Notion فلٹر فارمیٹ)،
  `sorts` (اختیاری ارے)، `pageSize` (1–100، ڈیفالٹ 50)، `startCursor` (اختیاری)۔
- `notion_get_database` — `databaseId`۔
- `notion_append_blocks` — `blockId`، `children` (بلاک آبجیکٹس کی ارے)،
  `after` (اختیاری پوزیشن)۔

### اسکوپس

پڑھنے والے ٹولز کے لیے `read:notion` اور لکھنے والے ٹول کے لیے `write:notion` درکار ہے۔
اسکوپس کو `open-sse/mcp-server/server.ts` میں `withScopeEnforcement()` کے ذریعے صرف اس وقت
نافذ کیا جاتا ہے جب `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ہو؛ کال کرنے والے کے مجاز اسکوپس
`OMNIROUTE_MCP_SCOPES` (کاما سے علیحدہ) یا تصدیق شدہ API کلید کے اسکوپ سیاق سے حاصل ہوتے ہیں۔
مکمل اسکوپ ماڈل کے لیے [MCP-SERVER.md](./MCP-SERVER.md) دیکھیں۔

## اینڈ پوائنٹس

| طریقہ    | پاتھ                   | مقصد                                  |
| -------- | ---------------------- | ------------------------------------- |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` واپس کریں۔  |
| `POST`   | `/api/settings/notion` | انٹیگریشن ٹوکن محفوظ اور توثیق کریں۔  |
| `DELETE` | `/api/settings/notion` | منقطع کریں (محفوظ شدہ ٹوکن صاف کریں)۔ |

> یہ ڈیش بورڈ کی ترتیبات کے روٹس ہیں۔ کوئی عوامی `/v1` Notion پراکسی
> اینڈ پوائنٹ **نہیں ہے** — Notion تک رسائی صرف اوپر موجود MCP ٹولز کے ذریعے ہوتی ہے۔

## استعمال کے طریقے

- **علم پر مبنی جوابات** — کسی ایجنٹ کو ورک اسپیس میں `notion_search` کرنے اور
  جواب دینے سے پہلے بہترین نتیجے پر `notion_get_page` استعمال کرنے دیں، تاکہ جوابات میں حقیقی داخلی دستاویزات کے حوالے شامل ہوں۔
- **ڈیٹابیس پر مبنی ورک فلوز** — فلٹرز + ترتیب کے ساتھ ٹاسکس/CRM ڈیٹابیس پر
  `notion_query_database` استعمال کریں، پھر قطاروں کا خلاصہ بنائیں یا ان کی ترجیح طے کریں۔
- **واپس لکھنا / لاگنگ** — میٹنگ کے نوٹس، رَن کے خلاصے، یا ایجنٹ کا آؤٹ پٹ کسی موجودہ صفحے میں شامل کرنے کے لیے `notion_append_blocks` استعمال کریں (صرف اضافہ؛ کوئی تباہ کن ترامیم نہیں)۔
- **ساخت کی کھوج** — کسی صفحے کے بلاک ٹری میں آگے بڑھنے کے لیے `notion_list_block_children`
  یا کسی ڈیٹابیس سے استفسار کرنے سے پہلے اس کی پراپرٹی اسکیم دریافت کرنے کے لیے `notion_get_database` استعمال کریں۔
