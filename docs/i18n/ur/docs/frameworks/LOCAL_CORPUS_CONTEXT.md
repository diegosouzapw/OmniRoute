> `src/app/api/settings/local-corpus/route.ts` (ترتیبات API)۔

## یہ کیا ہے

Local Corpus کسی آپریٹر کو متنی فائلوں کی ایک واضح طور پر منظور شدہ ڈائریکٹری OmniRoute کے MCP سرور کے لیے دستیاب کرنے کی سہولت دیتا ہے۔ فائلیں اپنی اصل ڈائریکٹری میں رہتی ہیں: OmniRoute صرف مستند روٹ پاتھ کو SQLite میں محفوظ کرتا ہے اور میموری میں تلاش کا اشاریہ برقرار رکھتا ہے۔ یہ کارپس کا مواد ریپوزٹری یا ڈیٹابیس میں نقل نہیں کرتا۔

اشاریے کی تازہ کاری تدریجی ہوتی ہے۔ غیر تبدیل شدہ فائلیں حجم اور ترمیم کے وقت کی بنیاد پر دوبارہ استعمال کی جاتی ہیں، تبدیل شدہ فائلیں دوبارہ پڑھی جاتی ہیں اور SHA-256 کے ساتھ ہیش کی جاتی ہیں، جبکہ حذف شدہ فائلیں ہٹا دی جاتی ہیں۔ تلاش کے دوران 30 سیکنڈ سے زیادہ پرانے اشاریے کو تازہ کیا جاتا ہے؛ کالرز فوری تازہ کاری کی درخواست بھی کر سکتے ہیں۔

## ماخذ کو ترتیب دیں

ترتیبات کے روٹ کے لیے وہی انتظامی توثیق درکار ہے جو دیگر ترتیبات APIs کے لیے ہوتی ہے۔ فراہم کردہ پاتھ پہلے سے موجود ہونا چاہیے اور ایک مطلق ڈائریکٹری پاتھ ہونا چاہیے۔

```bash
# ایک منظور شدہ ڈائریکٹری منسلک کریں
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# ترتیب اور اشاریے کی حالت چیک کریں
curl http://localhost:20128/api/settings/local-corpus

# ماخذ فائلوں کو تبدیل کیے بغیر منقطع کریں
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP ٹولز

تینوں ٹولز کے لیے `read:local-corpus` درکار ہے۔ ٹولز کے جوابات میں نسبتی پاتھ اور روٹ ڈائریکٹری کا بنیادی نام ظاہر ہوتا ہے، اس کا مطلق پاتھ کبھی ظاہر نہیں ہوتا۔

| ٹول                   | وضاحت                                                                                     |
| :-------------------- | :---------------------------------------------------------------------------------------- |
| `local_corpus_status` | ترتیب کی حالت، اشاریے کا حجم، حدود، اور آخری تازہ کاری کا وقت رپورٹ کرتا ہے               |
| `local_corpus_search` | اشاریہ شدہ متن تلاش کر کے محدود، سطر پر مبنی اقتباسات لوٹاتا ہے (زیادہ سے زیادہ 20 نتائج) |
| `local_corpus_read`   | ایک اجازت یافتہ، کارپس سے نسبتی فائل سے سطروں کی محدود رینج پڑھتا ہے                      |

MCP ان پٹس کی مثالیں:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## حفاظتی حدود

- اجازت یافتہ فائلوں کی فہرست متن پر مرکوز ہے: `.cfg`، `.csv`، `.geojson`، `.htm`، `.html`، `.ini`،
  `.js`، `.json`، `.jsonl`، `.jsx`، `.log`، `.md`، `.mjs`، `.ps1`، `.py`، `.sh`،
  `.sql`، `.toml`، `.ts`، `.tsx`، `.txt`، `.xml`، `.yaml`، اور `.yml`۔
- سمبولک لنکس نظر انداز کیے جاتے ہیں۔ پڑھنے کے پاتھ مستند بنائے جاتے ہیں اور انہیں ترتیب شدہ روٹ کے اندر ہی رہنا چاہیے؛ مطلق پاتھ اور ڈائریکٹری سے باہر جانے کی کوششیں مسترد کر دی جاتی ہیں۔
- حساس اور خودکار طور پر تیار ہونے والی ڈائریکٹریوں کے نام خارج کیے جاتے ہیں: `.build`، `.codex`، `.env`،
  `.git`، `.next`، `.omniroute`، `.ssh`، `coverage`، `dist`، `node_modules`، اور
  `secrets`۔
- طے شدہ حدود 5,000 فائلیں، فی فائل 1 MiB، اشاریہ شدہ کل مواد 64 MiB، فی تلاش حصے میں تقریباً 4,000 حروف، اور فی مطالعہ 400 سطریں ہیں۔
- NUL پر مشتمل فائلوں کو غیر متنی سمجھا جاتا ہے اور انہیں نظر انداز یا مسترد کر دیا جاتا ہے۔

بائنری دستاویزات، جیسے PDF، DOCX، تصاویر، اور آرکائیوز، دانستہ طور پر معاونت یافتہ نہیں ہیں۔ اشاریہ سازی سے پہلے انہیں ترتیب شدہ ڈائریکٹری میں کسی منظور شدہ متنی فارمیٹ میں تبدیل کریں۔

## عملیاتی نوٹس

- ترتیب شدہ روٹ کو تبدیل یا حذف کرنے سے مشترکہ درونِ میموری اشاریہ صاف ہو جاتا ہے۔
- پراسیس دوبارہ شروع ہونے پر اشاریہ ضائع ہو جاتا ہے؛ اگلی تلاش اسے ترتیب شدہ ماخذ سے دوبارہ بناتی ہے۔
- `local_corpus_status` لازماً اسکین نہیں کرتا۔ جب فوری طور پر دوبارہ اسکین درکار ہو تو `local_corpus_search` کو `refresh: true` کے ساتھ استعمال کریں۔
- اسکین اور مطالعہ کی ناکامیاں شمار کی جاتی ہیں یا صاف شدہ خرابیوں کے طور پر لوٹائی جاتی ہیں؛ ماخذ فائلوں میں کبھی ترمیم نہیں کی جاتی۔
