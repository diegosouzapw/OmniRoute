## پرووائیڈر کیا ہے؟

پرووائیڈر کو ایک **فون کیریئر** کی طرح سمجھیں۔ جس طرح کال کرنے کے لیے آپ کو فون کیریئر درکار ہوتا ہے، اسی طرح AI ماڈلز استعمال کرنے کے لیے آپ کو AI پرووائیڈر درکار ہوتا ہے۔ OmniRoute ایک ایسے فون کی طرح ہے جو **تمام کیریئرز** کے ساتھ کام کرتا ہے — آپ خودکار طور پر ان کے درمیان سوئچ کر سکتے ہیں۔

### پرووائیڈرز کی اقسام

| قسم          | یہ کیا ہے                         | مثالیں                            | لاگت                              |
| ------------ | --------------------------------- | --------------------------------- | --------------------------------- |
| **مفت**      | کسی ادائیگی کی ضرورت نہیں         | Kiro، OpenCode Free، Pollinations | $0                                |
| **API کلید** | آپ کو API کلید درکار ہے           | OpenAI، Anthropic، Google         | استعمال کے مطابق ادائیگی          |
| **OAuth**    | اپنے اکاؤنٹ سے لاگ اِن کریں       | Claude Code، GitHub Copilot       | سبسکرپشن                          |
| **ویب کوکی** | آپ کا براؤزر سیشن استعمال کرتا ہے | ChatGPT Web (Codex)، Gemini Web   | $0 (آپ کا اکاؤنٹ استعمال کرتا ہے) |

### ویب کوکی پرووائیڈرز

عمومی سیٹ اپ ہدایات، حدود، مسائل کے حل، اور پرووائیڈر سے مخصوص توثیقی رہنمائی کے لیے **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** دیکھیں۔

## فوری آغاز: اپنا پہلا پرووائیڈر منسلک کریں

### پہلی بار کے لیے اختیاری مفت پرووائیڈر سیٹ اپ

پہلی بار چلنے والا وزرڈ واضح **مفت پرووائیڈرز سیٹ اپ کریں** کارڈ پیش کرتا ہے۔ یہ OmniRoute کی بغیر توثیق والے پرووائیڈرز کی رجسٹری سے موجودہ اہل فہرست اخذ کرتا ہے، پھر تصدیق کرنے سے پہلے آپ کو ہر پرووائیڈر کا جائزہ لینے اور اس کا انتخاب ختم کرنے کی سہولت دیتا ہے۔ OmniRoute پرووائیڈر کا احتیاطی نوٹس اور اس کی سائٹ کا لنک دکھاتا ہے تاکہ آپ پہلے تیسرے فریق کی شرائط، رازداری، دستیابی، اور شرح کی حدود کا جائزہ لے سکیں۔

یہ کارروائی اختیاری ہے: وزرڈ مکمل کرنے سے کبھی بھی خاموشی سے مفت پرووائیڈر کنکشنز تخلیق نہیں ہوتے۔ یہ صرف وہ پرووائیڈرز تخلیق کرتا ہے جو ابھی تک موجود نہیں ہیں، پہلے سے حسبِ ضرورت بنائے گئے کنکشنز کو بغیر تبدیلی کے چھوڑتا ہے، اور تخلیق شدہ، پہلے سے کنفیگر شدہ، اور ناکام پرووائیڈرز کی الگ الگ اطلاع دیتا ہے۔ جزوی نتیجے کے بعد آپ محفوظ طریقے سے صرف ناکام پرووائیڈرز کے لیے دوبارہ کوشش کر سکتے ہیں۔

### اختیار A: مفت پرووائیڈر (کریڈٹ کارڈ درکار نہیں)

1. `http://localhost:20128` پر ڈیش بورڈ کھولیں
2. **پرووائیڈرز** → **پرووائیڈر شامل کریں** پر جائیں
3. ان مفت پرووائیڈرز میں سے ایک منتخب کریں:
   - **Kiro AI** — مفت Claude ماڈلز (توثیق درکار نہیں)
   - **OpenCode Free** — مفت GPT ماڈلز (توثیق درکار نہیں)
   - **Pollinations** — مفت GPT-5، Claude، Gemini (کلید درکار نہیں)
   - **LongCat** — 10M ٹوکنز مفت (ایک بار کی گرانٹ، اکاؤنٹ + KYC درکار)
   - **Cloudflare AI** — 50+ ماڈلز، 10K نیورونز/دن
   - **MLX Gemma 26B** — مقامی Apple Silicon ماڈل (~38.5 tok/s، ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — مقامی Apple Silicon ماڈل (~9.1 tok/s، ~13.1GB RAM)
4. **منسلک کریں** پر کلک کریں
5. مکمل! اب آپ کو مفت AI رسائی حاصل ہے۔

### اختیار B: API کلید والا پرووائیڈر (بامعاوضہ)

1. پرووائیڈر کی ویب سائٹ سے API کلید حاصل کریں:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` پر ڈیش بورڈ کھولیں
3. **پرووائیڈرز** → **پرووائیڈر شامل کریں** پر جائیں
4. اپنا پرووائیڈر منتخب کریں
5. اپنی API کلید پیسٹ کریں
6. **منسلک کریں** پر کلک کریں
7. مکمل! اب آپ کو اس پرووائیڈر کے ماڈلز تک رسائی حاصل ہے۔

### اختیار C: OAuth پرووائیڈر (سبسکرپشن)

1. `http://localhost:20128` پر ڈیش بورڈ کھولیں
2. **پرووائیڈرز** → **پرووائیڈر شامل کریں** پر جائیں
3. اپنا پرووائیڈر منتخب کریں (مثلاً Claude Code، GitHub Copilot)
4. **OAuth کے ساتھ منسلک کریں** پر کلک کریں
5. اپنے اکاؤنٹ سے لاگ اِن کریں
6. مکمل! اب آپ کو اپنے سبسکرپشن ماڈلز تک رسائی حاصل ہے۔

### اختیار D: مقامی MLX ماڈلز (Apple Silicon)

یونیفائیڈ میموری والے Apple Silicon Macs کے لیے، OmniRoute باقاعدہ OpenAI سے مطابقت رکھنے والے مقامی پرووائیڈرز کے طور پر `mlx-lm.server` کے ذریعے چلنے والے مقامی MLX ماڈلز سے کنکشن کی معاونت کرتا ہے۔

#### پیشگی تقاضے

- **Apple Silicon Mac** (M1/M2/M3/M4)، 24GB+ یونیفائیڈ میموری تجویز کی جاتی ہے
- **uv** پیکیج مینیجر: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### فوری آغاز

1. **انحصارات انسٹال کریں**:

   ```bash
   # اگر uv پہلے سے انسٹال نہیں ہے تو اسے انسٹال کریں
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm انسٹال کریں
   uv pip install mlx-lm
   ```

2. **MLX سرورز دستی طور پر شروع کریں** (الگ ٹرمینلز میں):

   ```bash
   # ٹرمینل 1: Gemma 4 26B A4B IT-QAT (پورٹ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ٹرمینل 2: Qwen 3.8 27B MLX Mixed (پورٹ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ڈیش بورڈ میں منسلک کریں**:
   - **پرووائیڈرز** → **پرووائیڈر شامل کریں** پر جائیں
   - **MLX Gemma 26B** یا **MLX Qwen 3.8 27B** منتخب کریں
   - **منسلک کریں** پر کلک کریں (API کلید درکار نہیں)

4. **OpenCode کے ساتھ استعمال کریں**:
   ```bash
   # OmniRoute استعمال کرنے کے لیے OpenCode کو کنفیگر کریں
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX ماڈلز استعمال کریں
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### میموری کا نظم

**اہم**: 24GB یونیفائیڈ میموری کے ساتھ، ایک وقت میں صرف **ایک بڑا MLX ماڈل چل سکتا ہے**۔

- Gemma 26B: ~15.9GB بلند ترین میموری استعمال
- Qwen 3.8 27B: ~13.1GB بلند ترین میموری استعمال

آپ کو اس کا نظم دستی طور پر کرنا ہوگا:

- ایک وقت میں صرف ایک MLX سرور چلائیں، یا
- دونوں کو الگ مشینوں پر چلائیں، یا
- دوسرے کو شروع کرنے سے پہلے ایک کو روک دیں

OmniRoute خودکار طور پر MLX سرور پراسیسز کا نظم نہیں کرتا — یہ صرف درخواستوں کو آپ کے کنفیگر کردہ OpenAI سے مطابقت رکھنے والے اینڈ پوائنٹس کی طرف بھیجتا ہے۔

#### ٹول کالنگ کی معاونت

دونوں ماڈلز OpenAI سے مطابقت رکھنے والی ٹول کالنگ کی معاونت کرتے ہیں۔ اس کے ساتھ جانچ کریں:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "2+2 کیا ہے؟ کیلکولیٹر ٹول استعمال کریں۔"}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "حساب لگائیں", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### مسائل کا حل

| مسئلہ                   | حل                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------- |
| سرور شروع نہیں ہوتا     | `uv run mlx_lm.server --help` چیک کریں اور ماڈل IDs کی تصدیق کریں                           |
| میموری ناکافی ہے        | یقینی بنائیں کہ صرف ایک ماڈل چل رہا ہو؛ دیگر ایپس بند کریں؛ Activity Monitor چیک کریں       |
| کنکشن مسترد ہو گیا      | تصدیق کریں کہ سرور درست پورٹ (11435/11436) پر چل رہا ہے                                     |
| جوابات سست ہیں          | پہلی درخواست ماڈل کو میموری میں لوڈ کرتی ہے (~30-60s)؛ بعد کی درخواستیں تیز ہوتی ہیں        |
| ٹول کالنگ ناکام ہوتی ہے | یقینی بنائیں کہ ماڈل ٹولز کو سپورٹ کرتا ہے؛ ترجمے کی خرابیوں کے لیے OmniRoute لاگز چیک کریں |

### مرحلہ 1: ڈیش بورڈ کھولیں

اپنے براؤزر میں `http://localhost:20128` پر جائیں۔

### مرحلہ 2: فراہم کنندگان پر جائیں

سائیڈ بار میں **فراہم کنندگان** پر کلک کریں۔

### مرحلہ 3: فراہم کنندہ شامل کریں پر کلک کریں

**+ فراہم کنندہ شامل کریں** بٹن پر کلک کریں۔

### مرحلہ 4: اپنا فراہم کنندہ منتخب کریں

فہرست دیکھیں یا اپنے فراہم کنندہ کو تلاش کریں۔ اس پر کلک کریں۔

### مرحلہ 5: اسناد درج کریں

- **مفت فراہم کنندگان**: کسی سند کی ضرورت نہیں — صرف **منسلک کریں** پر کلک کریں
- **API کلید والے فراہم کنندگان**: اپنی API کلید چسپاں کریں
- **OAuth فراہم کنندگان**: **OAuth کے ساتھ منسلک کریں** پر کلک کرکے لاگ اِن کریں

### مرحلہ 6: کنکشن کی جانچ کریں

یہ تصدیق کرنے کے لیے کہ کنکشن کام کر رہا ہے، **کنکشن کی جانچ کریں** پر کلک کریں۔

### مرحلہ 7: مکمل!

آپ کا فراہم کنندہ اب منسلک ہے۔ آپ اسے `model: "auto"` کے ساتھ استعمال کر سکتے ہیں یا براہِ راست فراہم کنندہ کی وضاحت کر سکتے ہیں۔

## متعدد فراہم کنندگان کا استعمال

OmniRoute **متعدد فراہم کنندگان** کے ساتھ بہترین کام کرتا ہے۔ اس سے آپ کو یہ فوائد حاصل ہوتے ہیں:

- **خودکار متبادل** — اگر ایک فراہم کنندہ ناکام ہو جائے تو OmniRoute اگلے کو آزماتا ہے
- **لاگت کی بہتری** — OmniRoute ہر درخواست کے لیے سب سے سستا فراہم کنندہ منتخب کرتا ہے
- **رفتار کی بہتری** — OmniRoute ہر درخواست کے لیے سب سے تیز فراہم کنندہ منتخب کرتا ہے
- **معیار کی بہتری** — OmniRoute ہر کام کے لیے بہترین فراہم کنندہ منتخب کرتا ہے

### تجویز کردہ ترتیب

بہترین تجربے کے لیے کم از کم **3 فراہم کنندگان** منسلک کریں:

1. **ایک مفت فراہم کنندہ** (Kiro، OpenCode Free، یا Pollinations) — ہمیشہ دستیاب
2. **ایک تیز فراہم کنندہ** (Groq، Cerebras) — فوری جوابات کے لیے
3. **ایک معیاری فراہم کنندہ** (OpenAI، Anthropic، Google) — پیچیدہ کاموں کے لیے

پھر `model: "auto"` استعمال کریں اور OmniRoute ہر درخواست کے لیے خودکار طور پر بہترین فراہم کنندہ منتخب کرے گا۔

## عام سوالات

### "کیا مجھے OmniRoute استعمال کرنے کے لیے ادائیگی کرنی ہوگی؟"

**نہیں!** OmniRoute مفت اور اوپن سورس ہے۔ آپ کچھ بھی ادا کیے بغیر مفت فراہم کنندگان (Kiro، OpenCode Free، Pollinations) استعمال کر سکتے ہیں۔ آپ صرف اسی صورت میں ادائیگی کرتے ہیں جب آپ بامعاوضہ فراہم کنندگان استعمال کرنے کا انتخاب کریں۔

### "مجھے کس فراہم کنندہ سے آغاز کرنا چاہیے؟"

**Kiro AI** سے آغاز کریں — یہ مفت ہے، اسے کسی API کلید کی ضرورت نہیں، اور یہ آپ کو Claude ماڈلز تک رسائی دیتا ہے۔ پھر ضرورت کے مطابق مزید فراہم کنندگان شامل کریں۔

### "کیا میں ایک ہی وقت میں متعدد فراہم کنندگان استعمال کر سکتا ہوں؟"

**ہاں!** یہی OmniRoute کا بنیادی مقصد ہے۔ متعدد فراہم کنندگان کو منسلک کریں اور `model: "auto"` استعمال کریں تاکہ OmniRoute ہر درخواست کے لیے بہترین فراہم کنندہ منتخب کرے۔

### "اگر کوئی فراہم کنندہ کام کرنا بند کر دے تو کیا ہوگا؟"

OmniRoute خودکار طور پر ناکام فراہم کنندگان کو چھوڑ دیتا ہے اور اگلے کو آزماتا ہے۔ آپ کو کچھ کرنے کی ضرورت نہیں۔

### "میں کسی فراہم کنندہ کا رابطہ کیسے منقطع کروں؟"

فراہم کنندگان پر جائیں → فراہم کنندہ پر کلک کریں → **رابطہ منقطع کریں** پر کلک کریں۔

### "کیا میں اپنی موجودہ API کلیدیں استعمال کر سکتا ہوں؟"

**ہاں!** اگر آپ کے پاس OpenAI، Anthropic، Google وغیرہ کے لیے پہلے سے API کلیدیں موجود ہیں تو آپ انہیں OmniRoute میں استعمال کر سکتے ہیں۔ فراہم کنندہ کو منسلک کرتے وقت بس انہیں پیسٹ کریں۔
