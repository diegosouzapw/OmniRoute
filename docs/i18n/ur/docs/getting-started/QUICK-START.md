## مرحلہ 1: OmniRoute انسٹال کریں

اپنا پسندیدہ طریقہ منتخب کریں:

### آپشن A: npm (تجویز کردہ)

```bash
npm install -g omniroute
```

### آپشن B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` سب سے اعلیٰ **شائع شدہ** مستحکم SemVer ہے۔ یہ git `main` کو ٹریک **نہیں** کرتا۔ GitOps کے لیے `diegosouzapw/omniroute:X.Y.Z` کو پن کریں۔ [امیج ٹیگز / ریلیز چینلز](../guides/DOCKER_GUIDE.md#release-channels) دیکھیں۔

### آپشن C: سورس سے

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## مرحلہ 2: OmniRoute شروع کریں

```bash
omniroute
```

OmniRoute، `http://localhost:20128` پر شروع ہوتا ہے۔ ڈیش بورڈ خود بخود کھل جاتا ہے۔

---

## مرحلہ 3: ایک مفت فراہم کنندہ منسلک کریں

آپ ایک مفت فراہم کنندہ منسلک کرکے OmniRoute کو **کچھ بھی ادا کیے بغیر** استعمال کر سکتے ہیں۔

### آپشن A: Kiro (مفت Claude — کریڈٹ کارڈ کی ضرورت نہیں)

1. `http://localhost:20128` پر ڈیش بورڈ کھولیں
2. **Providers** → **Add Provider** پر جائیں
3. **Kiro AI** منتخب کریں
4. **Connect** پر کلک کریں (API کلید درکار نہیں!)
5. ہو گیا! اب آپ کو Claude ماڈلز تک مفت رسائی حاصل ہے۔

### آپشن B: OpenCode Free (تصدیق درکار نہیں)

1. `http://localhost:20128` پر ڈیش بورڈ کھولیں
2. **Providers** → **Add Provider** پر جائیں
3. **OpenCode Free** منتخب کریں
4. **Connect** پر کلک کریں (API کلید درکار نہیں!)
5. ہو گیا! اب آپ کو متعدد ماڈلز تک مفت رسائی حاصل ہے۔

### آپشن C: Pollinations (کلید درکار نہیں)

1. `http://localhost:20128` پر ڈیش بورڈ کھولیں
2. **Providers** → **Add Provider** پر جائیں
3. **Pollinations** منتخب کریں
4. **Connect** پر کلک کریں (API کلید درکار نہیں!)
5. ہو گیا! اب آپ کو GPT-5، Claude، Gemini، اور مزید ماڈلز تک مفت رسائی حاصل ہے۔

---

## مرحلہ 4: تصدیق کریں کہ یہ کام کر رہا ہے

[API Keys](http://localhost:20128/dashboard/api-manager) سے ایک نئی کلید بنائیں۔ اس کلید کو محفوظ کر لیں کیونکہ یہ دوبارہ ظاہر نہیں ہوگی۔ یاد رکھیں کہ یہ کلید ٹولز کو OmniRoute تک رسائی دینے کے لیے ہے، اپ اسٹریم فراہم کنندگان تک رسائی کے لیے نہیں۔

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

آپ کو اپنے منسلک ماڈلز کی فہرست نظر آنی چاہیے۔

---

## مرحلہ 5: اپنے IDE یا CLI کو OmniRoute کی طرف پوائنٹ کریں

اپنے IDE یا CLI ٹول میں یہ سیٹ کریں:

```
بنیادی URL: http://localhost:20128/v1
API کلید:   [ڈیش بورڈ → اینڈ پوائنٹس سے کاپی کریں]
ماڈل:       auto
```

بس ہو گیا! اب آپ کا IDE فراہم کنندہ کے خودکار انتخاب کے ساتھ OmniRoute استعمال کرتا ہے۔

### IDE کی مثال: VSCode/Continue.dev

1. VSCode میں [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ایکسٹینشن انسٹال کریں۔
2. درج ذیل لائنیں شامل کرنے کے لیے اپنی `~/.continue/config.yaml` اپ ڈیٹ کریں:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev چیٹ پین میں `OmniRoute - Auto` منتخب کریں، اور آپ OmniRoute کو درخواستیں بھیجنے لگیں گے۔
4. (اختیاری) قارئین کے لیے مشق — اپنے IDE سے `config.yaml` کو دیگر تمام پہلے سے تیار کردہ کنفیگریشنز کے ساتھ اپ ڈیٹ کروائیں 😊

### CLI کی مثال: Codex CLI

1. اپنے آپریٹنگ سسٹم میں ماحول کا متغیر مستقل طور پر سیٹ کریں۔
   macOS/Linux کے لیے (اپنی `~/.bashrc` یا `~/.zshrc` میں شامل کریں):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows (Command Prompt) کے لیے:

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. اب Codex کو OmniRoute کے لیے کنفیگر کرکے چلائیں۔ یہ کمانڈ چلائیں:

```
omniroute launch-codex --model auto
```

آپ اینڈ پوائنٹ اور API کلید متعین کرنے کے لیے `codex` اور کمانڈ لائن پیرامیٹرز کے ذریعے یہ کام دستی طور پر کر سکتے ہیں، لیکن اوپر دی گئی کمانڈ کے ساتھ OmniRoute آپ کے لیے ہر چیز سنبھال لیتا ہے۔

اسی طرح ایک کمانڈ سے لانچ کرنے کا طریقہ عمومی لانچر کے ذریعے دیگر CLIs کے لیے بھی کام کرتا ہے — `omniroute run <target>`، `claude`، `codex`، `aider`، `goose`، `opencode`، `qwen`، اور `gemini` کو سپورٹ کرتا ہے ([CLI انٹیگریشنز](../guides/CLI-INTEGRATIONS.md) دیکھیں)۔

3. اب CLI کو OmniRoute کو درخواستیں بھیجنی چاہئیں۔

### تصدیق کریں کہ آپ کا ٹول OmniRoute کے ذریعے روٹنگ کر رہا ہے

آپ بائیں سائڈبار سے [مانیٹرنگ/لاگز](http://localhost:20128/dashboard/logs) پر کلک کرکے درخواست کی تفصیلات دیکھ سکتے ہیں۔ مزید اندر کلک کرنے سے آپ کو مزید تفصیلات دکھائی دیں گی۔ ضمنی بات کے طور پر، آپ دیکھ سکتے ہیں کہ آپ کے پسندیدہ ہارنس سے کون سی معلومات بھیجی جاتی ہیں۔ یہ تعلیمی اور ڈیبگنگ کے نقطۂ نظر سے مفید ہے۔

## عام سوالات

### "کیا مجھے API کلید کی ضرورت ہے؟"

**نہیں!** آپ کسی API کلید کے بغیر مفت فراہم کنندگان (Kiro، OpenCode Free، Pollinations) استعمال کر سکتے ہیں۔ بس انہیں ڈیش بورڈ میں منسلک کریں۔

### "`auto` کیا ہے؟"

`auto`، OmniRoute کو ہر درخواست کے لیے خودکار طور پر بہترین فراہم کنندہ منتخب کرنے کی ہدایت دیتا ہے۔ یہ رفتار، لاگت، معیار اور دستیابی کو مدِنظر رکھتا ہے۔ تفصیلات کے لیے [Auto-Combo رہنما](./AUTO-COMBO-GUIDE.md) دیکھیں۔

### "اس کی قیمت کتنی ہے؟"

OmniRoute بذاتِ خود **مفت اور اوپن سورس** ہے۔ آپ صرف استعمال کیے گئے فراہم کنندگان کے لیے ادائیگی کرتے ہیں۔ بہت سے فراہم کنندگان مفت درجے پیش کرتے ہیں — [مفت درجوں کا رہنما](./FREE-TIERS-GUIDE.md) دیکھیں۔

### "کیا میں اسے Claude Code / Cursor / Copilot کے ساتھ استعمال کر سکتا ہوں؟"

**ہاں!** OmniRoute ہر اس ٹول کے ساتھ کام کرتا ہے جو OpenAI فارمیٹ کو سپورٹ کرتا ہے۔ بس بنیادی URL کو `http://localhost:20128/v1` پر سیٹ کریں۔ مخصوص سیٹ اپ ہدایات کے لیے [CLI ٹولز رہنما](../reference/CLI-TOOLS.md) دیکھیں۔

### "اگر کوئی فراہم کنندہ بند ہو جائے تو کیا ہوگا؟"

OmniRoute خودکار طور پر ناکام فراہم کنندگان کو چھوڑ دیتا ہے اور اگلے کو آزماتا ہے۔ آپ کو کچھ کرنے کی ضرورت نہیں۔ تفصیلات کے لیے [Auto-Combo رہنما](./AUTO-COMBO-GUIDE.md) دیکھیں۔
