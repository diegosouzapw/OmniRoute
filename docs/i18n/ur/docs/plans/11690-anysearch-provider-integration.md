## 1. سروس کی مستند حقیقت (سرکاری دستاویزات، باہمی تصدیق شدہ)

- بنیادی URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP، JSON-RPC 2.0)۔
- `POST /v1/search` - پیرامیٹرز: `query` (لازمی)، `max_results` (1-10، ڈیفالٹ 10)، `tag` (`{domain}.{sub_domain}` عمودی روٹنگ)، `zone` (cn/intl)، `language`، `params` (ساخت یافتہ عمودی فیلڈز)، `format` (json/markdown)۔
- `GET /v1/sub-domains?domain=...` - صلاحیتوں کا کیٹلاگ، کوٹے میں شمار نہیں ہوتا۔
- `POST /v1/extract` - `{url, title, content}` حاصل/اخذ کرتا ہے؛ سخت JSON باڈی، 16 KiB حد۔
- `POST /v1/auth/email/register` - ایک ہی کال میں رجسٹریشن، ایک بار استعمال ہونے والی سادہ متن کلید `as_sk_...` واپس کرتا ہے۔
- توثیق: اختیاری `Authorization: Bearer <as_sk_...>`؛ گمنام رسائی فی-IP حدود تک محدود ہو جاتی ہے اور روزانہ مفت کوٹا استعمال کرتی ہے؛ غلط کلید 401/403 واپس کرتی ہے اور خاموشی سے گمنام رسائی پر واپس نہیں جاتی۔
- مفت درجہ: روزانہ 1000 درخواستیں، فی کلید 20 QPS۔ بامعاوضہ درجہ: قیمت مقرر نہیں (جلد آ رہا ہے)۔
- جوابی لفافہ: کامیابی `{code: 0, message: "success", request_id, data}`؛ ناکامی `{code: -1, message}`۔ توثیق/کوٹا کی خرابیوں میں ساخت یافتہ `error_code` نہیں ہوتا (پیغام کا متن ہی اشارہ ہے)؛ اخذ سے مخصوص خرابیوں میں `error_code` ہوتا ہے (`invalid_extract_url`، `extract_failed`)۔ 429 پر کوئی `Retry-After` ہیڈر نہیں ہوتا۔

## 3. فیصلے (تمام 2026-08-26 کو کیے گئے)

1. **روٹنگ طرزِ عمل: `fallbackOnly`۔** جواز: لاگت-0 والا مفت فراہم کنندہ کبھی بھی خودکار لاگت پر مبنی روٹنگ پر غالب نہیں آنا چاہیے؛ واضح انتخاب اور فیل اوور واپسی اس سے متاثر نہیں ہوتے۔ نظیر: ضم شدہ xquik اندراج۔
2. **دائرۂ کار: v1 میں `POST /v1/extract` کے ذریعے webSearch + webFetch۔** یہ tavily/exa کے دوہری صلاحیت والے ذہنی ماڈل سے ہم آہنگ ہے۔ عمودی سطحیں (`tag`، `sub-domains`، `batch_search`) دائرۂ کار سے باہر رہیں گی — فی الحال عمودی پیرامیٹرز کے لیے کوئی IR موجود نہیں۔
3. **کوٹہ ڈسپلے: `freeMonthlyQuota: 0`** (xquik طرز کا محتاط ڈسپلے)۔ اصل حد (1000 درخواستیں/دن، روزانہ ری سیٹ) اس کے بجائے UI کیٹلاگ کی `authHint` عبارت میں درج ہے۔ جواز: کوٹہ ڈسپلے کو ری سیٹ کی معنویت سے مطابقت رکھنی چاہیے؛ روزانہ کی حد کو ماہانہ مساوی قدر (30000) میں تبدیل کرنا ایک ایسا جھوٹا وعدہ ہے جسے UI پورا نہیں کر سکتا۔
4. **searchTypes: صرف `["web"]`۔** AnySearch API میں خبروں/تصاویر کی عمودی تلاش کا کوئی عوامی ثبوت موجود نہیں؛ وہ گیٹ ویز جو کسی دستاویز شدہ عمودی تلاش کے بغیر APIs کو مربوط کرتے ہیں (مثلاً Google Custom Search)، خبروں کو خاموشی سے ویب پر میپ کرنے کے بجائے صرف ویب کو ظاہر کرتے ہیں۔
5. **کلید کا طرزِ عمل:** کلید کے بغیر کام کرتا ہے؛ ایک نامعتبر کلید 401/403 لوٹاتی ہے اور اسے کبھی بھی خاموشی سے گمنام رسائی میں تنزلی نہیں دی جاتی (یہ اپ اسٹریم معاہدے کی عکاسی کرتا ہے)۔
6. **دانستہ اخراجات:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (چیٹ انٹرسیپشن firecrawl/jina/tavily تک محدود رہتی ہے)؛ `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (گمنام ریموٹ اینڈ پوائنٹس ہر ایگریس IP کے لیے ایک مشترکہ IP-محدود پول استعمال کرتے ہیں، اس لیے کلید کے بغیر extract آپٹ اِن ہے، خودکار روٹنگ کا امیدوار نہیں)؛ `QUOTA_STATUS_PROVIDERS` (AnySearch کوٹہ کی اطلاع 402/403 اسٹیٹس کے بجائے 429/انوَیلپ کے ذریعے دیتا ہے)۔
