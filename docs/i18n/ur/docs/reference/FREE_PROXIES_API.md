OmniRoute، `free_proxies` ٹیبل میں مفت پراکسیز کا ایک منتخب مجموعہ فراہم کرتا ہے،
جسے بیرونی فراہم کنندگان (1proxy، proxifly، iplocate، webshare) سے ہم آہنگ کیا جاتا ہے۔
ڈیش بورڈ انہیں **Settings → Free Proxies** کے تحت دکھاتا ہے۔ یہ دستاویز
فہرست کے روٹ کی جانب سے فراہم کردہ سرور سائیڈ فلٹرنگ، ترتیب، گنتی، اور مطابقت پذیری کی خرابیوں کی رپورٹنگ
کا احاطہ کرتی ہے۔

## فہرست کا روٹ — `GET /api/settings/free-proxies`

فلٹر شدہ، مرتب شدہ، صفحہ بند حصہ اور مجموعی تعداد واپس کرتا ہے۔ فلٹرنگ اور
گنتی SQL میں ہوتی ہے، تاکہ UI ہر قطار کو میموری میں لوڈ کیے بغیر حقیقی مجموعہ
(مثلاً `Total: 0`) دکھا سکے۔

### کوئری پیرامیٹرز

| پیرامیٹر          | قسم                                | ڈیفالٹ    | مفہوم                                                                                               |
| ----------------- | ---------------------------------- | --------- | --------------------------------------------------------------------------------------------------- |
| `search`          | اسٹرنگ                             | `""`      | ہوسٹ (اور ماخذ) کالم پر حروف کی صورت کا لحاظ رکھنے والا `LIKE`۔                                     |
| `protocol`        | اسٹرنگ                             | `""`      | `type` فلٹر: `http` / `https` / `socks4` / `socks5`۔ خالی = سبھی۔                                   |
| `country`         | اسٹرنگ                             | `""`      | `countryCode` فلٹر (ISO-2)۔ خالی = سبھی۔                                                            |
| `minQuality`      | عدد                                | `0`       | صرف وہ قطاریں جن میں `qualityScore >= minQuality` ہو۔ `0` = کوئی کم از کم حد نہیں۔                  |
| `disabledSources` | اسٹرنگ                             | `""`      | خارج کیے جانے والے ماخذ ids، کاما سے الگ کردہ (مثلاً `proxifly,webshare`)۔                          |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = اسکور نزولی؛ `latency` = لیٹنسی صعودی (null آخر میں)؛ `recent` = `lastValidated` نزولی۔ |
| `offset`          | عدد                                | `0`       | صفحہ بندی کا آغاز۔                                                                                  |
| `limit`           | عدد                                | `50`      | صفحے کا حجم (سرور سائیڈ پر محدود)۔                                                                  |

### جواب

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` صفحہ بندی سے **پہلے** فلٹر شدہ مجموعی تعداد کو ظاہر کرتا ہے، تاکہ UI
`Total: N` اور `hasMore` کو الگ الگ رینڈر کر سکے۔ `syncErrors` میں کلید ماخذ id ہوتی ہے اور
یہ صرف ان ماخذوں کے لیے پُر کیا جاتا ہے جن کی آخری مطابقت پذیری ناکام ہوئی ہو — `Total: 0` کا نتیجہ
کبھی خاموش نہیں رہتا۔

## پول میں شامل کرنا — `POST /api/settings/free-proxies/[id]/add-to-pool`

ایک مفت پراکسی کو زیر انتظام `proxy_registry` پول میں منتقل کرتا ہے۔ پہلے
اپ اسٹریم کی توثیق کرتا ہے؛ کامیابی پر نئے پول پراکسی کی id اور ناپی گئی لیٹنسی واپس کرتا ہے۔

## مطابقت پذیری — `POST /api/settings/free-proxies/sync`

تمام فعال ماخذوں (یا `{ "sources": [...] }` میں موجود ذیلی مجموعے) کو دوبارہ حاصل کرتا ہے۔ ہر
ماخذ الگ سے مطابقت پذیر ہوتا ہے؛ ناکام ہونے والے ماخذ کو `syncErrors` میں درج کیا جاتا ہے اور
باقی پھر بھی مکمل ہو جاتے ہیں، اس لیے جزوی مطابقت پذیری کبھی پہلے سے موجود درست ڈیٹا کو حذف نہیں کرتی۔

## اعداد و شمار — `GET /api/settings/free-proxies/stats`

قطاروں کے پے لوڈ کے بغیر `total / inPool / avgQuality / bySource / lastSyncAt` کا مجموعی خلاصہ
واپس کرتا ہے — اسے ڈیش بورڈ کے ہیڈر ویجٹس استعمال کرتے ہیں۔
