الاٹمنٹ فراہم کنندہ کا کوٹہ نہیں ہے۔

کوٹہ پولز یہ طے کرتے ہیں کہ کون سی API keys فراہم کنندہ کا پول استعمال کر سکتی ہیں اور hard، soft، یا burst پالیسیاں کیسے لاگو ہوتی ہیں۔ فراہم کنندہ کا کوٹہ وہ بیرونی گنجائش ہے جس کی اطلاع فراہم کنندہ دیتا ہے یا جو کسی واضح طور پر ترتیب دیے گئے ماخذ سے حاصل ہوتی ہے۔ Ghostlight کے داخلی بجٹس منتظم کی جانب سے متعین کردہ انتظامی حدود ہیں۔

`ensurePool` آپریشن idempotent ہے: یکساں پول میں کوئی تبدیلی نہیں ہوتی، تبدیل شدہ الاٹمنٹ اپ ڈیٹ ہو جاتی ہے، اور غیر موجود پول تخلیق کر دیا جاتا ہے۔ اس کا مقصد آٹومیشن اور محدود API callers کے لیے استعمال ہونا ہے۔

صرف پڑھنے کے لیے status endpoint یہ ہے: `GET /api/omniroute/status`۔ تصدیقی کمانڈ `npm run omniroute:verify` ہے؛ یہ کسی live model request کو انجام نہیں دیتی۔
