`agentrouter` اپ اسٹریم گیٹ وے `messages[].content` پر کلیدی الفاظ پر مبنی مواد کا فلٹر چلاتا ہے۔ فلٹر جزوی طور پر تعینی ہے (بعض فقروں کو ہمیشہ بلاک کرتا ہے) اور جزوی طور پر احتمالی ہے (درخواستوں کے تیز سلسلے کے لیے حساس — تیزی سے درخواستیں آنے کے بعد زیادہ سخت ہو جاتا ہے اور وقفۂ سکون کے بعد بحال ہو جاتا ہے)۔

جب WAF کسی درخواست کو بلاک کرتا ہے تو یہ درج ذیل جواب لوٹاتا ہے:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## فلٹر کا دائرۂ کار

WAF صرف `messages[].content` کا معائنہ کرتا ہے۔ یہ درج ذیل کا معائنہ **نہیں** کرتا:

- `system` پرامپٹ
- ساختہ مواد کے بلاکس (`tool_result`, `tool_use`, `thinking`, `image`)
- ٹول کے `description` اور `input_schema` فیلڈز
- درخواست کا میٹا ڈیٹا، ہیڈرز، یا ماڈل آئی ڈی

## ہمیشہ بلاک ہونے والے نمونے (حروف کی نوعیت سے غیر حساس)

| نمونہ                         | نوٹس                                                         |
| ----------------------------- | ------------------------------------------------------------ |
| `Lorem ipsum` کی کوئی بھی شکل | مکمل لاطینی lorem ذخیرۂ الفاظ بلاک ہے                        |
| `language model` (اکیلا)      | "the language model" اور "large language model" گزر جاتے ہیں |
| `virtual assistant`           | "AI assistant" گزر جاتا ہے                                   |
| `I'm here to help`            | صرف "here to help" بھی بلاک ہو جاتا ہے                       |
| `Claude, made by Anthropic`   | صرف مکمل فقرہ                                                |

## تقریباً ہمیشہ بلاک ہونے والے نمونے

| نمونہ                                                  | نوٹس                                                   |
| ------------------------------------------------------ | ------------------------------------------------------ |
| `placeholder`                                          | جب یہ اکیلا ہو (نہ کہ پیرامیٹر کے نام وغیرہ کے طور پر) |
| `dummy data`                                           | فکسچرز کے لیے عام سیڈ فقرہ                             |
| `foo bar baz`                                          | معیاری پلیس ہولڈر فقرہ                                 |
| مختصر ٹوکنز کی تکرار (`AAA BBB CCC`, `test test test`) | کلیدی الفاظ کی بھرمار کا پتہ لگانے والا آلہ            |

## بوجھ کے تحت رویہ

مختصر دورانیے میں تقریباً 5 تیز درخواستوں کے بعد، WAF ایسے مواد کو بلاک کرنا شروع کر دیتا ہے جو عام حالات میں گزر جاتا۔ تقریباً 5–10 سیکنڈ کی غیرفعال مدت کے بعد بکٹ میں نرمی آ جاتی ہے۔ یہ وہی IP اور کلید سے منسلک شرح محدود کنندہ ہے جو Claude Code یا Codex CLI کی جانب سے یکے بعد دیگرے متعدد ٹول استعمال / پیغام بھیجنے کی کالز کرنے پر وقفے وقفے سے `400 content-blocked` خرابیاں پیدا کرتا ہے۔

## OmniRoute میں پہلے سے لاگو تخفیفی اقدامات

1. **`open-sse/services/wafRateLimit.ts`** — برسٹ گارڈ جو کسی بھی `agentrouter:*` URL کو جانے والی درخواستوں کے درمیان کم از کم 500 ms کا وقفہ نافذ کرتا ہے۔ یہ وقفہ تاخیر کے انسانی ادراک سے بہت کم ہے اور عام ٹریفک پر WAF کو فعال ہونے سے روکتا ہے۔

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — جب اپ اسٹریم `400 content-blocked` لوٹاتا ہے تو ایگزیکیوٹر اسی URL کو افزایشی بیک آف کے ساتھ دوبارہ آزماتا ہے (1.5 s، 3.0 s، زیادہ سے زیادہ 2 کوششیں)۔ بیک آف کے بعد WAF عموماً نرم پڑ جاتا ہے اور دوبارہ کوشش کامیاب ہو جاتی ہے۔

3. **`tests/unit/compression/harness.test.ts`** — ٹیسٹ فکسچر `longInput` کو `"lorem ipsum dolor sit amet ".repeat(40)` سے بدل کر `"example content for testing purposes ".repeat(40)` کر دیا گیا تاکہ جب Claude Code اس فائل کو `Read` ٹول کے ذریعے پڑھے تو فائل کا مواد `tool_result` بلاک کے ذریعے واپس نہ گزرے اور WAF کو متحرک نہ کرے۔

## پرامپٹس اور ٹول آؤٹ پٹ کے لیے رہنمائی

اگر Claude Code یا Codex CLI سیشن کو بار بار `400 content-blocked` کا سامنا ہو تو تازہ ترین صارف پیغام اور تازہ ترین ٹول نتیجے میں اوپر دیے گئے نمونوں میں سے کسی کی موجودگی جانچیں اور عبارت کو نئے انداز میں لکھیں۔ عام متبادل طریقے:

- `Lorem ipsum …` کو `example text …` یا اس اصل مواد سے بدلیں جس کی نمائندگی ٹیسٹ یا فکسچر کرنا چاہتا ہے۔
- `placeholder` (جب اکیلا ہو) کو `example value`، `sample value`، یا اصل قدر سے بدلیں۔
- `language model` کو `large language model` یا `the model` سے بدلیں۔
- `dummy data` کو `sample data` یا حقیقت پسندانہ سیڈ اقدار سے بدلیں۔
- `I'm here to help` / `here to help` کو زیادہ مخصوص ابتدائی جملے سے بدلیں (مثلاً "I'll review the file you mentioned")۔

## غلط مثبت نتائج کی اپ اسٹریم اطلاع دینا

موجودہ فلٹر حد سے زیادہ سخت ہے — یہ `tool_result` بلاکس میں "Lorem ipsum" کو بلاک کرتا ہے، حالانکہ آپریٹر کا واضح طور پر پرامپٹ داخل کرنے کا ارادہ نہیں تھا۔ جو آپریٹرز اسے منبع پر درست کروانا چاہتے ہیں، انہیں غلط مثبت نتائج کی اطلاع دینے کے لیے `agentrouter.org` سے رابطہ کرنا چاہیے۔ اوپر دی گئی بلاک لسٹ 2026-08-03 تک اپ اسٹریم کی جانچ سے حاصل ہونے والا تجرباتی نتیجہ ہے۔
