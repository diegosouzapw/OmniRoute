## Cuándo elegir OmniRoute

- Autohospedas tu infraestructura y quieres la **máxima cobertura de proveedores** (329 proveedores y 155 entradas del catálogo gratuitas/sin autenticación)
- Necesitas un **servidor MCP integrado** (herramientas de LLM, memoria y habilidades expuestas como herramientas)
- Necesitas el **protocolo A2A** para flujos de trabajo entre agentes
- Quieres **ocultar la huella digital** (JA3/JA4) para evitar que los CAPTCHA de servicios ascendentes te detecten
- Necesitas **funcionalidades empresariales** (medidas de protección, evaluaciones y registro de auditoría) sin pagar una factura de SaaS

## Cuándo elegir LiteLLM

- Trabajas **principalmente con Python** y necesitas una integración estrecha con `litellm.completion()`
- Necesitas **recetas maduras para despliegues en producción** (k8s, gráficos de Helm)
- Tu equipo ya utiliza microservicios de Python

## Cuándo elegir OpenRouter (SaaS)

- No quieres autohospedar
- No te importa pagar por token con el recargo de un SaaS
- Necesitas un **único método de pago** para todos los proveedores

## Cuándo elegir Portkey

- Necesitas un **SLA comercial** con garantías de disponibilidad
- Prefieres un **panel de control gestionado** sin carga operativa
- Necesitas **funcionalidades de cumplimiento normativo empresarial** listas para usar
