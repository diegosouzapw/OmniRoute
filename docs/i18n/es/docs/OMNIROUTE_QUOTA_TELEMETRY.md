OmniRoute separa la telemetría de cuotas del proveedor de la contabilidad de Ghostlight.

## Estados veraces

- `healthy` significa que una fuente informó de capacidad restante utilizable.
- `approaching_limit` significa que una fuente informó de una capacidad restante igual o inferior al umbral configurado.
- `exhausted` se emite únicamente cuando una fuente informa de capacidad cero o de un uso que ha alcanzado su límite.
- `unavailable` significa que una fuente compatible no pudo devolver datos.
- `unknown` significa que no existe ninguna fuente compatible o que no se conoce ningún límite del proveedor.

Desconocido no significa agotado y no deshabilita a un proveedor.

Las fuentes se priorizan en este orden: API oficial del proveedor, API de uso autenticada, encabezados de respuesta mapeados explícitamente, configuración del administrador, estimaciones locales, desconocido. Las estimaciones locales nunca se presentan como datos de facturación del proveedor.

Los encabezados de respuesta solo se analizan mediante un mapeo explícito del proveedor. No se presupone que los nombres genéricos de los encabezados sean válidos globalmente.
