La asignación no es la cuota del proveedor.

Los grupos de cuotas definen qué claves de API pueden consumir un grupo de proveedor y cómo se aplican las políticas estrictas, flexibles o de ráfaga. La cuota del proveedor es la capacidad externa informada por un proveedor o por una fuente configurada explícitamente. Los presupuestos internos de Ghostlight son límites de gobernanza definidos por el administrador.

La operación `ensurePool` es idempotente: un grupo idéntico permanece sin cambios, una asignación modificada se actualiza y un grupo inexistente se crea. Está diseñada para la automatización y para clientes de API con límites definidos.

El endpoint de estado de solo lectura es `GET /api/omniroute/status`. El comando de verificación es `npm run omniroute:verify`; no realiza ninguna solicitud a un modelo en producción.
