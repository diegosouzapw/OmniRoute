## Qué es

Local Corpus permite que un operador exponga al servidor MCP de OmniRoute un directorio de archivos de texto aprobado explícitamente. Los archivos permanecen en su directorio original: OmniRoute almacena únicamente la ruta raíz canónica en SQLite y mantiene un índice de búsqueda en memoria. No copia el contenido del corpus en el repositorio ni en la base de datos.

La actualización del índice es incremental. Los archivos sin cambios se reutilizan según su tamaño y fecha de modificación; los archivos modificados se vuelven a leer y se les calcula un hash SHA-256, y los archivos eliminados se quitan. Las búsquedas actualizan los índices con más de 30 segundos de antigüedad; los clientes también pueden solicitar una actualización inmediata.

## Configurar la fuente

La ruta de configuración requiere la misma autenticación de administración que las demás API de configuración. La ruta enviada debe existir y ser una ruta absoluta a un directorio.

```bash
# Conectar un directorio aprobado
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Comprobar la configuración y el estado del índice
curl http://localhost:20128/api/settings/local-corpus

# Desconectar sin modificar los archivos de origen
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Herramientas MCP

Las tres herramientas requieren `read:local-corpus`. Las respuestas de las herramientas exponen rutas relativas y el nombre base del directorio raíz, nunca su ruta absoluta.

| Herramienta           | Descripción                                                                                                 |
| :-------------------- | :---------------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Informa del estado de configuración, el tamaño del índice, los límites y la hora de la última actualización |
| `local_corpus_search` | Busca en el texto indexado y devuelve fragmentos acotados por líneas (hasta 20 resultados)                  |
| `local_corpus_read`   | Lee un intervalo acotado de líneas de un archivo permitido cuya ruta es relativa al corpus                  |

Ejemplos de entradas MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Límites de seguridad

- La lista de permitidos está orientada a texto: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` y `.yml`.
- Los enlaces simbólicos se omiten. Las rutas de lectura se convierten a su forma canónica y deben permanecer dentro de la raíz configurada; se rechazan las rutas absolutas y los intentos de atravesar directorios.
- Se excluyen los nombres de directorios sensibles y generados: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` y
  `secrets`.
- Los límites predeterminados son 5.000 archivos, 1 MiB por archivo, 64 MiB de contenido indexado total, aproximadamente 4.000 caracteres por fragmento de búsqueda y 400 líneas por lectura.
- Los archivos que contienen NUL se consideran no textuales y se omiten o rechazan.

Los documentos binarios, como PDF, DOCX, imágenes y archivos comprimidos, no se admiten de forma intencionada. Conviértalos a un formato de texto aprobado dentro del directorio configurado antes de indexarlos.

## Notas operativas

- Cambiar o eliminar la raíz configurada borra el índice compartido en memoria.
- Un reinicio del proceso descarta el índice; la siguiente búsqueda lo reconstruye a partir de la fuente configurada.
- `local_corpus_status` no fuerza un análisis. Use `local_corpus_search` con
  `refresh: true` cuando sea necesario volver a analizar inmediatamente.
- Los fallos de análisis y lectura se contabilizan o se devuelven como errores depurados; los archivos de origen nunca se modifican.
