> **TL;DR**: Instala → Conecta un proveedor gratuito → Configura tu IDE para que apunte a OmniRoute. Listo.

---

## Paso 1: Instalar OmniRoute

Elige el método que prefieras:

### Opción A: npm (recomendado)

```bash
npm install -g omniroute
```

### Opción B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` es la versión estable de SemVer **publicada** más reciente. **No** sigue la rama `main` de git. Fija `diegosouzapw/omniroute:X.Y.Z` para GitOps. Consulta [Etiquetas de imagen / Canales de publicación](../guides/DOCKER_GUIDE.md#release-channels).

### Opción C: Desde el código fuente

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Paso 2: Iniciar OmniRoute

```bash
omniroute
```

OmniRoute se inicia en `http://localhost:20128`. El panel se abre automáticamente.

---

## Paso 3: Conectar un proveedor gratuito

Puedes usar OmniRoute **sin pagar nada** conectando un proveedor gratuito.

### Opción A: Kiro (Claude gratuito — Sin tarjeta de crédito)

1. Abre el panel en `http://localhost:20128`
2. Ve a **Proveedores** → **Añadir proveedor**
3. Selecciona **Kiro AI**
4. Haz clic en **Conectar** (¡no se necesita una clave de API!)
5. ¡Listo! Ahora tienes acceso gratuito a los modelos de Claude.

### Opción B: OpenCode Free (sin autenticación)

1. Abre el panel en `http://localhost:20128`
2. Ve a **Proveedores** → **Añadir proveedor**
3. Selecciona **OpenCode Free**
4. Haz clic en **Conectar** (¡no se necesita una clave de API!)
5. ¡Listo! Ahora tienes acceso gratuito a varios modelos.

### Opción C: Pollinations (sin necesidad de clave)

1. Abre el panel en `http://localhost:20128`
2. Ve a **Proveedores** → **Añadir proveedor**
3. Selecciona **Pollinations**
4. Haz clic en **Conectar** (¡no se necesita una clave de API!)
5. ¡Listo! Ahora tienes acceso gratuito a GPT-5, Claude, Gemini y más.

---

## Paso 4: Comprobar que funciona

En [Claves de API](http://localhost:20128/dashboard/api-manager), crea una clave nueva. Guarda esta clave, ya que no volverá a mostrarse. Ten en cuenta que esta clave permite que las herramientas accedan a OmniRoute, no a los proveedores ascendentes.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Deberías ver una lista de los modelos conectados.

---

## Paso 5: Configurar tu IDE o CLI para que apunte a OmniRoute

En tu IDE o herramienta de CLI, configura:

```
URL base:     http://localhost:20128/v1
Clave de API: [cópiala desde Panel → Puntos de conexión]
Modelo:       auto
```

¡Eso es todo! Ahora tu IDE usa OmniRoute con selección automática de proveedor.

### Ejemplo de IDE: VSCode/Continue.dev

1. En VSCode, instala la extensión [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Actualiza tu `~/.continue/config.yaml` para añadir las siguientes líneas:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. En el panel de chat de Continue.dev, selecciona `OmniRoute - Auto` para realizar solicitudes a OmniRoute.
4. (Opcional) Ejercicio para el lector: haz que tu IDE actualice `config.yaml` con todas las demás configuraciones predefinidas 😊

### Ejemplo de CLI: Codex CLI

1. En tu sistema operativo, configura la variable de entorno de forma persistente.
   Para macOS/Linux (añádela a `~/.bashrc` o `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Para Windows (Símbolo del sistema):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Ahora iniciemos Codex, pero configurado para OmniRoute. Ejecuta:

```
omniroute launch-codex --model auto
```

Puedes hacerlo manualmente mediante `codex` y parámetros de línea de comandos para especificar el punto de conexión y la clave de API, pero con el comando anterior, OmniRoute se encarga de todo.

El mismo inicio con un solo comando funciona para otras CLI mediante el lanzador genérico: `omniroute run <target>` es compatible con `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` y `gemini` (consulta [Integraciones con CLI](../guides/CLI-INTEGRATIONS.md)).

3. Ahora la CLI debería estar enviando solicitudes a OmniRoute.

### Confirmar que tu herramienta enruta las solicitudes a OmniRoute

Puedes consultar los detalles de la solicitud haciendo clic en [Supervisión/Registros](http://localhost:20128/dashboard/logs) en la barra lateral izquierda. Al hacer clic, podrás ver más detalles. Como observación adicional, puedes ver qué información envía tu entorno de trabajo favorito. Esto resulta útil con fines educativos y de depuración.

## Preguntas frecuentes

### "¿Necesito una clave de API?"

**¡No!** Puedes usar proveedores gratuitos (Kiro, OpenCode Free, Pollinations) sin ninguna clave de API. Solo tienes que conectarlos desde el panel.

### "¿Qué es `auto`?"

`auto` indica a OmniRoute que elija automáticamente el mejor proveedor para cada solicitud. Tiene en cuenta la velocidad, el coste, la calidad y la disponibilidad. Consulta la [Guía de Auto-Combo](./AUTO-COMBO-GUIDE.md) para obtener más información.

### "¿Cuánto cuesta?"

OmniRoute es **gratuito y de código abierto**. Solo pagas por los proveedores que uses. Muchos proveedores ofrecen niveles gratuitos; consulta la [Guía de niveles gratuitos](./FREE-TIERS-GUIDE.md).

### "¿Puedo usarlo con Claude Code / Cursor / Copilot?"

**¡Sí!** OmniRoute funciona con cualquier herramienta compatible con el formato de OpenAI. Solo tienes que establecer la URL base como `http://localhost:20128/v1`. Consulta la [Guía de herramientas de CLI](../reference/CLI-TOOLS.md) para ver instrucciones específicas de configuración.

### "¿Qué ocurre si un proveedor deja de funcionar?"

OmniRoute omite automáticamente los proveedores que fallen y prueba con el siguiente. No necesitas hacer nada. Consulta la [Guía de Auto-Combo](./AUTO-COMBO-GUIDE.md) para obtener más información.
