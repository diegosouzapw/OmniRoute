OmniRoute organiza los 352 proveedores compatibles en 3 niveles económicos. Cada
solicitud pasa por ellos en orden hasta que uno responde correctamente, por lo que
obtienes la respuesta viable más barata sin tener que escribir código de respaldo.

## Nivel 1 — Suscripción

**Proveedores por los que ya pagas.** OmniRoute aprovecha hasta la última parte de la cuota antes
de que caduque.

| Proveedor                          | Por qué está en el nivel 1                          |
| ---------------------------------- | --------------------------------------------------- |
| Claude Code OAuth                  | Anthropic Pro/Team: tarifa plana, a menudo sin usar |
| OpenAI Codex (suscripción ChatGPT) | Plus/Team incluye cuota de Codex                    |
| GitHub Copilot                     | Por usuario: la cuota se restablece mensualmente    |
| Cursor IDE                         | Cuota del plan Pro                                  |
| Antigravity / Devin Desktop        | Cuotas integradas                                   |

**Estrategia**: enruta primero aquí todas las solicitudes que se ajusten a los puntos fuertes
del modelo. El rastreador de cuotas supervisa los próximos restablecimientos, y la estrategia
combinada `reset-aware` establece las prioridades en consecuencia. Para enrutar primero al nivel 1
y recurrir a los niveles de pago únicamente a medida que se agote la cuota, utiliza el identificador
`auto/thrifty`; también puedes usar `auto/subscription` para limitarte a la capacidad incluida
en el plan y detenerte con un error si no está disponible. Consulta
[Enrutamiento con prioridad para suscripciones](../routing/SUBSCRIPTION_LADDER.md).

## Nivel 2 — Económico

**Proveedores de pago por token por debajo de $1/1M de tokens.** Reservados para trabajos de gran volumen
o para cuando las cuotas del nivel 1 alcancen sus límites.

| Proveedor                          | Precio (entrada/salida) | Puntos fuertes                         |
| ---------------------------------- | ----------------------- | -------------------------------------- |
| DeepSeek V4 Pro                    | $0.27 / $1.10 por 1M    | Código, razonamiento                   |
| GLM-4.5                            | $0.60 / $2.20 por 1M    | Contexto extenso                       |
| MiniMax M1                         | $0.20 / $1.10 por 1M    | Velocidad                              |
| Qwen Coder                         | $0.30 / $1.20 por 1M    | Código                                 |
| OpenRouter (optimizado por precio) | variable                | Más de 100 modelos, selección dinámica |

**Estrategia**: la combinación `cost-optimized` elige el modelo con el menor coste por token que cumpla
el filtro de capacidades de la tarea (visión, modo JSON, herramientas, contexto máximo).

## Nivel 3 — Gratuito

**Proveedores sin coste**: niveles gratuitos, programas de créditos y cuotas diarias mediante OAuth.

| Proveedor        | Cuota gratuita / créditos                         |
| ---------------- | ------------------------------------------------- |
| Kiro AI          | Nivel gratuito de Claude (uso razonable generoso) |
| OpenCode Free    | Sin autenticación, límites de uso generosos       |
| Qoder            | OAuth gratuito                                    |
| Google Vertex AI | $300 en créditos para cuentas nuevas              |
| Amazon Q         | Nivel gratuito para usuarios de AWS               |
| Pollinations     | API pública abierta                               |
| Cloudflare AI    | Nivel gratuito de Workers AI                      |

**Estrategia**: la combinación `auto` con un límite de presupuesto enruta aquí cuando los niveles 1 y 2 fallan
o cuando se establece `useFreeOnly=true`. Los proveedores gratuitos suelen tener límites de uso
más restrictivos; el disyuntor los recupera después del tiempo de espera.

## Configuración de los niveles

Panel de control → **Niveles** → asigna tus proveedores. Los valores predeterminados (de `tierDefaults.json`) son
adecuados; edítalos cuando tengas suscripciones específicas que quieras priorizar o proveedores que quieras excluir.

La puntuación de 16 factores de Auto-Combo también tiene en cuenta el nivel. Consulta
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetría

Panel de control → **Uso** muestra los tokens consumidos por nivel y día. Utiliza esta información para:

- Confirmar que el nivel 1 se aprovecha por completo (de lo contrario, estás desperdiciando el valor de la suscripción)
- Identificar qué modelos del nivel 2 se eligen con más frecuencia (consolídalos en 1 o 2)
- Verificar que el nivel 3 ahorra dinero en cargas de trabajo de pruebas y exploración

## Patrones habituales

### Carga de trabajo completamente gratuita

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Favorece claramente el nivel 3; solo utiliza el nivel 2 si el nivel 3 no está disponible.

### Prioridad para la suscripción con respaldo económico

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Lista ordenada explícita que corresponde al nivel 1 → nivel 2 → nivel 3.
