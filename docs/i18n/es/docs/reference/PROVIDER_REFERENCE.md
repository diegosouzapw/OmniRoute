## Categorías

- **Gratis** — nivel gratuito con clave de API (configurada mediante el panel)
- **Sin autenticación** — endpoints públicos que no requieren ninguna clave ni inicio de sesión
- **OAuth** — flujo de inicio de sesión gestionado por OmniRoute, sin necesidad de clave de API
- **Cookie web** — encapsula la aplicación web del proveedor mediante autenticación por cookies
- **Clave de API** — proveedor de pago configurado mediante una clave de API (puede incluir créditos gratuitos)
- **Local** — se ejecuta en el equipo del usuario (Ollama, LM Studio, vLLM, etc.)
- **Búsqueda** — proveedores de búsqueda web
- **Audio** — proveedores exclusivamente de audio (TTS/STT)
- **Proxy ascendente** — proveedores que actúan como proxy para otros proveedores
- **Agente en la nube** — agentes de programación de larga duración (Codex Cloud, Devin, Jules)
- **Sistema** — proveedores internos de OmniRoute (loopback, etc.)

Etiquetas adicionales: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Llamadas a herramientas` (cuando se muestran): `native` — API real de llamadas a funciones; `emulated` — el array `tools` se emula mediante prompts a través de `webTools.ts` (bloques `<tool>{...}</tool>` analizados mediante expresiones regulares); `none` — actualmente, `tools` se descarta silenciosamente. Consulte #7286.

Use el panel en `/dashboard/providers` para habilitar, configurar y probar cada proveedor.
