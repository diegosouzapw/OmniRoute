OmniRoute incluye un conjunto seleccionado de proxies gratuitos en la tabla `free_proxies`,
sincronizado desde proveedores externos (1proxy, proxifly, iplocate, webshare). El
panel los muestra en **Configuración → Proxies gratuitos**. Este documento
describe el filtrado, la ordenación, el recuento y la notificación de errores de
sincronización del lado del servidor que expone la ruta de listado.

## Ruta de listado — `GET /api/settings/free-proxies`

Devuelve un subconjunto filtrado, ordenado y paginado, además del recuento total.
El filtrado y el recuento se realizan en SQL, por lo que la interfaz puede mostrar
el total real (p. ej., `Total: 0`) sin cargar todas las filas en memoria.

### Parámetros de consulta

| Parámetro         | Tipo                               | Predeterminado | Significado                                                                                                                   |
| ----------------- | ---------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`           | `LIKE` sensible a mayúsculas y minúsculas en la columna de host (y de origen).                                                |
| `protocol`        | string                             | `""`           | Filtro `type`: `http` / `https` / `socks4` / `socks5`. Vacío = todos.                                                         |
| `country`         | string                             | `""`           | Filtro `countryCode` (ISO-2). Vacío = todos.                                                                                  |
| `minQuality`      | number                             | `0`            | Solo filas con `qualityScore >= minQuality`. `0` = sin límite mínimo.                                                         |
| `disabledSources` | string                             | `""`           | Identificadores de origen separados por comas que se deben excluir (p. ej., `proxifly,webshare`).                             |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`      | `quality` = puntuación descendente; `latency` = latencia ascendente (nulos al final); `recent` = `lastValidated` descendente. |
| `offset`          | number                             | `0`            | Inicio de la paginación.                                                                                                      |
| `limit`           | number                             | `50`           | Tamaño de página (limitado en el servidor).                                                                                   |

### Respuesta

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` refleja el total filtrado **antes** de la paginación, por lo que la interfaz
puede representar `Total: N` y `hasMore` de forma independiente. `syncErrors`
utiliza el identificador de origen como clave y solo se rellena para los orígenes
cuya última sincronización falló; un resultado `Total: 0` nunca queda sin explicación.

## Añadir al conjunto — `POST /api/settings/free-proxies/[id]/add-to-pool`

Promueve un proxy gratuito al conjunto administrado `proxy_registry`. Primero
valida el servidor de origen; si la operación tiene éxito, devuelve el identificador
del nuevo proxy del conjunto y la latencia medida.

## Sincronización — `POST /api/settings/free-proxies/sync`

Vuelve a obtener todos los orígenes habilitados (o el subconjunto indicado en
`{ "sources": [...] }`). Cada origen se sincroniza de forma independiente; los
errores de un origen se registran en `syncErrors` y los demás siguen hasta
completarse, por lo que las sincronizaciones parciales nunca eliminan datos
válidos anteriores.

## Estadísticas — `GET /api/settings/free-proxies/stats`

Devuelve el agregado `total / inPool / avgQuality / bySource / lastSyncAt` sin la
carga útil de las filas; lo utilizan los widgets del encabezado del panel.
