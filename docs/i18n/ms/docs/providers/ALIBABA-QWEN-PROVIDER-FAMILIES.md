Dokumen ini merekodkan keputusan pelaksanaan untuk
[Isu #7854](https://github.com/diegosouzapw/OmniRoute/issues/7854). Produk awam diwakili sebagai
empat keluarga penyedia. Rantau ialah data sambungan, bukan produk yang berasingan.

## Keputusan

| Keluarga penyedia                                  | ID OmniRoute            | Rantau global | Rantau China |
| -------------------------------------------------- | ----------------------- | ------------- | ------------ |
| Alibaba Cloud Model Studio (bayar ikut penggunaan) | `alibaba`               | Singapura     | Beijing      |
| Pelan Token Alibaba Cloud                          | `bailian-coding-plan`   | Singapura     | Beijing      |
| Qwen Cloud (bayar ikut penggunaan)                 | `qwen-cloud`            | Global        | Beijing      |
| Pelan Token Qwen Cloud                             | `qwen-cloud-token-plan` | Singapura     | Beijing      |

ID `alibaba-cn` yang sedia ada kekal sebagai alias keserasian masa jalan untuk sambungan tersimpan, laluan
model, gabungan dan penggunaan terdahulu. Kad papan pemukanya digabungkan ke dalam `alibaba`; tiada penulisan
semula pangkalan data diperlukan.

Qwen Cloud bayar ikut penggunaan dan Alibaba Cloud Model Studio kini berkongsi hos masa jalan yang serasi
dengan DashScope, tetapi kedua-duanya kekal sebagai identiti penyedia yang berasingan kerana pengguna memperoleh kunci dan mengurus
akaun melalui antara muka produk yang berbeza. Produk Pelan Token Alibaba dan Qwen Cloud menggunakan
keluarga titik akhir yang berbeza, maka keempat-empat produk kekal sebagai ID penyedia yang berasingan.

## Matriks titik akhir

| Keluarga penyedia       | `global-sg`                                                              | `china-beijing`                                                      | Format penghantaran |
| ----------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------- | ------------------- |
| `alibaba`               | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI              |
| `bailian-coding-plan`   | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/apps/anthropic/v1`  | `https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic/v1`  | Anthropic           |
| `qwen-cloud`            | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI              |
| `qwen-cloud-token-plan` | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` | `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | OpenAI              |

Kunci API dan titik akhir mesti tergolong dalam produk dan rantau yang sama. Pemilihan rantau mengubah
titik akhir pratetap yang digunakan oleh pengesahan dan permintaan biasa.

## Kontrak sambungan

Sambungan baharu menyimpan kunci rantau yang stabil dalam `providerSpecificData`:

```json
{
  "region": "global-sg"
}
```

Nilai yang dibenarkan ialah `global-sg` dan `china-beijing`. Titik akhir diperoleh secara berpusat daripada
ID penyedia dan rantau. `providerSpecificData.baseUrl` bukan pratetap kekal sebagai penggantian eksplisit oleh
pengendali dan diberi keutamaan, manakala URL pratetap lama yang tersimpan dinormalkan kembali kepada matriks
rantau.

Ini memastikan skema sambungan boleh diperluas: rantau lain boleh ditambahkan pada penyelesai tanpa
mencipta kad penyedia lain atau mengubah ID penyedia yang tersimpan.

## Keserasian dan pelaksanaan

1. Tambahkan penyelesai titik akhir serantau dan kekalkan lalai global semasa.
2. Gunakan penemuan langsung `/models` DashScope serantau untuk `alibaba`, ID keserasiannya
   `alibaba-cn`, dan `qwen-cloud`. Responsnya terlebih dahulu melalui satu penapis penjanaan teks
   kerana titik akhir generik turut mengembalikan model imej, video, audio, pembenaman, dan model
   bukan sembang yang lain. `qwen-cloud` kemudiannya menggunakan senarai dibenarkan yang
   diselenggarakan dan diisytiharkan dalam pendaftaran penyedianya. Alibaba Model Studio dan Qwen
   Cloud mengekalkan katalog pilihan yang berasingan walaupun kedua-duanya kini berkongsi hos masa
   jalanan.
3. Daftarkan `qwen-cloud-token-plan` dengan senarai dibenarkan model teks Token Plan semasa.
4. Tambahkan pemilih rantau berjenis pada dialog tambah/edit sambungan.
5. Sembunyikan kad pendua `alibaba-cn` dan sertakan sambungannya yang sedia ada pada halaman
   penyedia `alibaba`.
6. Kekalkan tindihan titik akhir tersuai untuk penggunaan lanjutan dan penggunaan khusus ruang
   kerja.

Model media Token Plan kekal di luar katalog sembang kerana model tersebut menggunakan titik akhir
khusus. `wan2.7-image` dan `wan2.7-image-pro` didaftarkan dalam
`open-sse/config/imageRegistry.ts`; `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, dan
`happyhorse-1.1-r2v` didaftarkan dalam `open-sse/config/videoRegistry.ts`. Kedua-dua pendaftaran
menggunakan semula identiti sambungan `qwen-cloud-token-plan` dan kelayakan khusus rantaunya.

Qwen Cloud biasa mempunyai katalog imej dan video bayar mengikut penggunaan yang berasingan di bawah
identiti `qwen-cloud`. Model imejnya ialah `wan2.7-image-pro`, `wan2.7-image`,
`qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0-2026-03-03`, dan
`z-image-turbo`. Model videonya ialah `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`,
`happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`, `wan2.7-t2v`, `wan2.7-i2v`,
`wan2.7-r2v-2026-06-12`, dan `wan2.7-videoedit`. Model ini hanya menggunakan semula sambungan
`qwen-cloud` biasa dan titik akhir media DashScope serantau. Pendaftaran Token Plan dan bayar
mengikut penggunaan tidak mewarisi atau menggabungkan senarai model antara satu sama lain.

Identiti `bailian-coding-plan` juga mempunyai senarai dibenarkan medianya sendiri:
`wan2.7-image`, `wan2.7-image-pro`, `qwen-image-2.0`, dan `qwen-image-2.0-pro` untuk penjanaan
imej, serta
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, dan `happyhorse-1.1-r2v` untuk penjanaan
video. Ia hanya menggunakan sambungan Bailian Coding Plan dan titik akhir Coding Plan serantau.
Pendaftaran imej dan videonya tidak mewarisi atau bergabung dengan mana-mana penyedia Qwen Cloud.

Identiti `alibaba` biasa mempunyai senarai dibenarkan imej dan video yang berasingan. Model imejnya
ialah `qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0`,
`z-image-turbo`, dan `wan2.6-t2i`. Model video tambahannya ialah `happyhorse-1.1-i2v`,
`happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`,
`wan2.7-i2v-2026-04-25`, `wan2.6-i2v-flash`, `wan2.7-t2v-2026-06-12`,
`wan2.7-r2v-2026-06-12`, dan `wan2.7-videoedit`. Model ini hanya menggunakan sambungan Alibaba
Model Studio dan titik akhir media serantau yang dipilih; model tersebut tidak ditambahkan pada
mana-mana pendaftaran Coding Plan atau Qwen Cloud.

Katalog sembang Qwen Cloud Token Plan mengikuti senarai dibenarkan teks padanan rentetan tepat bagi
pelan Individual:
`qwen3.8-max-preview`, `qwen3.7-max`, `qwen3.7-plus`, `qwen3.6-flash`, `glm-5.2`, dan
`deepseek-v4-pro`. Entri Wan dan HappyHorse tergolong dalam API penjanaan imej/video yang
berasingan.

Alibaba Token Plan mendedahkan enam ID model penjanaan teks semasa yang sama melalui titik akhir
serasi Anthropic. Pilihan Singapuranya menyimpan kekunci rantau `global-sg` yang sedia ada; hanya
label yang dipaparkan kepada pengguna berbeza daripada keluarga penyedia yang memanggil rantau
tersebut Global.

Katalog sembang Qwen Cloud biasa sengaja dibuat lebih sempit daripada respons teks langsung penuh.
Senarai dibenarkan yang diselenggarakan berada dalam
`open-sse/config/providers/registry/qwen-cloud/index.ts`; penemuan langsung hanya mengembalikan ID
yang terdapat dalam kedua-dua respons huluan dan senarai pendaftaran tersebut.

Alibaba Model Studio mengikuti peraturan persilangan langsung yang sama dengan senarai dibenarkan
yang diselenggarakan secara bebas dalam `open-sse/config/providers/registry/alibaba/index.ts`.
Penyedia keserasian `alibaba-cn` menggunakan semula katalog tersebut sambil menyelesaikan penemuan
terhadap titik akhir Beijing.
