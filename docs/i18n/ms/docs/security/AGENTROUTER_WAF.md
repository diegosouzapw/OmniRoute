Gerbang huluan `agentrouter` menjalankan penapis kandungan berasaskan kata kunci pada
`messages[].content`. Penapis ini sebahagiannya bersifat deterministik (sentiasa menyekat
frasa tertentu) dan sebahagiannya bersifat kebarangkalian (sensitif terhadap lonjakan — menjadi
lebih agresif selepas permintaan pantas dan pulih selepas tempoh bertenang).

Apabila WAF menyekat permintaan, ia mengembalikan:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Skop penapis

WAF hanya memeriksa `messages[].content`. Ia **tidak** memeriksa:

- Prom `system`
- Blok kandungan berstruktur (`tool_result`, `tool_use`, `thinking`, `image`)
- Medan `description` dan `input_schema` alat
- Metadata permintaan, pengepala, atau id model

## Corak yang sentiasa disekat (tidak peka huruf besar/kecil)

| Corak                           | Catatan                                                    |
| ------------------------------- | ---------------------------------------------------------- |
| Sebarang varian `Lorem ipsum`   | Keseluruhan kosa kata lorem Latin disekat                  |
| `language model` (bersendirian) | "the language model" dan "large language model" dibenarkan |
| `virtual assistant`             | "AI assistant" dibenarkan                                  |
| `I'm here to help`              | "here to help" sahaja turut disekat                        |
| `Claude, made by Anthropic`     | Frasa penuh sahaja                                         |

## Corak yang hampir sentiasa disekat

| Corak                                                   | Catatan                                                                      |
| ------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `placeholder`                                           | Apabila digunakan bersendirian (bukan sebagai nama parameter dan sebagainya) |
| `dummy data`                                            | Frasa benih yang lazim untuk lekapan ujian                                   |
| `foo bar baz`                                           | Frasa ruang letak kanonik                                                    |
| Token pendek berulang (`AAA BBB CCC`, `test test test`) | Pengesan untuk penyumbatan kata kunci                                        |

## Tingkah laku ketika beban tinggi

Selepas ~5 permintaan pantas dalam tempoh yang singkat, WAF mula menyekat kandungan
yang biasanya dibenarkan. Baldi kembali longgar selepas ~5–10 saat tanpa
aktiviti. Ini ialah pengehad kadar terikat IP dan kunci yang sama, yang menyebabkan
ralat `400 content-blocked` berselang-seli apabila Claude Code atau Codex CLI
membuat beberapa panggilan penggunaan alat / penghantaran mesej secara berturut-turut dengan pantas.

## Mitigasi yang telah digunakan dalam OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — pelindung lonjakan yang menguatkuasakan
   sela minimum 500 ms antara permintaan keluar ke mana-mana URL `agentrouter:*`.
   Sela tersebut jauh di bawah tahap kelewatan yang dapat dirasai manusia dan menghalang
   WAF daripada diaktifkan oleh trafik biasa.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — apabila huluan mengembalikan
   `400 content-blocked`, pelaksana mencuba semula URL yang sama dengan
   undur eksponen (1.5 s, 3.0 s, maksimum 2 percubaan). Selepas tempoh undur,
   WAF biasanya kembali longgar dan percubaan semula berjaya.

3. **`tests/unit/compression/harness.test.ts`** — lekapan ujian
   `longInput` telah ditukar daripada `"lorem ipsum dolor sit amet ".repeat(40)`
   kepada `"example content for testing purposes ".repeat(40)` supaya apabila
   Claude Code membaca fail ini melalui alat `Read`, kandungan fail
   tidak mengalir semula melalui blok `tool_result` dan mencetuskan WAF.

## Panduan untuk prom dan output alat

Jika sesi Claude Code atau Codex CLI berulang kali menerima
`400 content-blocked`, semak mesej pengguna yang paling terkini dan hasil alat yang paling
terkini untuk mengenal pasti mana-mana corak di atas, kemudian ungkapkannya semula. Penyelesaian
lazim:

- Gantikan `Lorem ipsum …` dengan `example text …` atau kandungan sebenar
  yang cuba dimodelkan oleh ujian atau lekapan tersebut.
- Gantikan `placeholder` (apabila digunakan bersendirian) dengan `example value`,
  `sample value`, atau nilai sebenar.
- Gantikan `language model` dengan `large language model` atau `the model`.
- Gantikan `dummy data` dengan `sample data` atau nilai benih yang realistik.
- Gantikan `I'm here to help` / `here to help` dengan ayat pembuka yang lebih khusus
  (contohnya, "I'll review the file you mentioned").

## Melaporkan positif palsu kepada pihak huluan

Penapis semasa terlalu agresif — ia menyekat "Lorem ipsum" dalam
blok `tool_result` walaupun pengendali jelas tidak berniat untuk
menyuntik prom. Pengendali yang mahu masalah ini dibetulkan pada sumbernya hendaklah
menghubungi `agentrouter.org` untuk melaporkan positif palsu tersebut. Senarai sekatan
di atas ialah hasil empirikal daripada pengujian huluan setakat 2026-08-03.
