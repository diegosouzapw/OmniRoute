`@omniroute/opencode-plugin-v2` memasukkan keseluruhan katalog OmniRoute anda — model, kombo dan
kombo automatik — ke dalam pemilih model OpenCode v2, lengkap dengan nama paparan, harga dan bajet
peringkat percuma.

Ia merupakan pakej yang berasingan daripada `@omniroute/opencode-plugin` kerana OpenCode v1 dan v2 memuatkan
pemalam melalui kontrak yang berbeza. Pilih pakej yang sepadan dengan versi utama OpenCode anda; tiada apa-apa yang
dikongsi antara kedua-duanya, jadi menaik taraf satu pakej tidak akan memaksa pakej yang satu lagi dinaik taraf.

## Keperluan

- OpenCode v2.
- Gerbang OmniRoute yang boleh dicapai (`http://localhost:20128` secara lalai).
- Node.js 22 atau 24.

## Pemasangan

Tambahkan pemalam pada `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Model kemudiannya muncul sebagai `omniroute/<provider>/<model>`; `providerId` menentukan awalan tersebut dan
id integrasi yang digunakan oleh OpenCode untuk menyimpan kelayakan.

## Kelayakan

Pemalam mencari kunci gerbang di tiga tempat mengikut turutan berikut:

1. **Kelayakan yang anda sambungkan dalam OpenCode.** Pemalam mendaftarkan satu integrasi supaya
   aliran pengesahan OpenCode sendiri boleh menyimpan kunci tersebut. Tiada apa-apa disimpan dalam `opencode.json` — utamakan kaedah ini.
2. `apiKey` dalam pilihan pemalam, untuk penggantian bagi setiap projek. Kaedah ini meletakkan kunci dalam fail yang
   mungkin anda komitkan.
3. `OMNIROUTE_API_KEY` dalam persekitaran.

Jika ketiga-tiganya tiada, katalog akan kosong dan pemalam akan memaklumkannya sekali semasa permulaan, bukannya
membiarkan anda dengan pemilih kosong tanpa sebarang pemberitahuan.

### Token pengurusan ialah kunci yang berbeza

Kombo, kesihatan penyedia dan pengayaan (nama paparan, harga, bajet peringkat percuma) diperoleh daripada
titik akhir `/api/*` gerbang, yang dalam kebanyakan penggunaan dilindungi oleh token **pengurusan**
dan bukannya kunci inferens:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token baca pengurusan>"
}
```

Jika tidak ditetapkan, `managementReadToken` akan menggunakan `apiKey` sebagai sandaran. Apabila gerbang menolak penggunaan sandaran tersebut,
katalog masih diterbitkan, tetapi dengan id model mentah dan bukannya nama paparan, tanpa penyahduplikasian
alias kanonik, tanpa harga dan tanpa kombo. Pemalam memberi amaran sekali bagi setiap titik akhir apabila hal itu berlaku,
dengan menyatakan titik akhir dan perkara yang hilang — supaya sebab pemilih berfungsi secara terhad sentiasa jelas.

## Pilihan

| Kunci                            | Lalai                                                     | Catatan                                                                                                            |
| -------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `providerId`                     | `"omniroute"`                                             | Id penyedia, id integrasi dan awalan bagi model yang dipaparkan                                                    |
| `baseURL`                        | diperlukan                                                | Akar gerbang, `http(s)` sahaja; akhiran `/v1` ditambahkan apabila diperlukan                                       |
| `apiKey`                         | kelayakan yang disambungkan, kemudian `OMNIROUTE_API_KEY` | Kunci sembang untuk `/v1/*`                                                                                        |
| `managementReadToken`            | menggunakan `apiKey` sebagai sandaran                     | Kunci untuk `/api/*` — biasanya **bukan** kunci yang sama                                                          |
| `displayName`                    | `"OmniRoute"`                                             | Nama penyedia dalam pemilih                                                                                        |
| `timeoutMs`                      | `10000`                                                   | Had masa pengambilan bagi setiap titik akhir (kombo automatik menggunakan 5s)                                      |
| `modelCacheTtlMs`                | `300000`                                                  | TTL cache katalog; petikan cakera mempercepatkan permulaan sejuk                                                   |
| `timeouts`                       | menggunakan `timeoutMs` sebagai sandaran                  | Bajet bagi setiap titik akhir dalam ms: `models`, `combos`, `autoCombos`, `enrichment`                             |
| `enrichment`                     | `true`                                                    | Dapatkan nama, harga dan bajet peringkat percuma                                                                   |
| `providerTag`                    | `true`                                                    | Awalkan nama paparan dengan penyedia huluan yang menjadi sasaran penghalaan                                        |
| `usableOnly`                     | `false`                                                   | Kekalkan hanya penyedia yang dilaporkan oleh gerbang sebagai telah diperuntukkan                                   |
| `visibleModels` / `hiddenModels` | `[]`                                                      | Senarai benarkan padanan tepat atau akhiran; penafian mengatasi kebenaran                                          |
| `geminiSanitization`             | `true`                                                    | Buang kata kunci JSON-Schema yang ditolak oleh Gemini daripada skema alat (alat `$ref` diteruskan tanpa perubahan) |
| `apiFormat.allowAnthropic`       | `false`                                                   | Halakan id dalam senarai benarkan melalui blok API Anthropic                                                       |
| `apiFormat.anthropicModels`      | `[]`                                                      | Id model penuh yang dihalakan kepada Anthropic                                                                     |
| `logLevel` / `startupDebug`      | `warn` / `false`                                          | Tahap keterperincian pengelog                                                                                      |

## Cara katalog kekal terkini

Katalog diambil secara malas dan dicache selama `modelCacheTtlMs`, manakala syot kilat cakera memastikan
katalog terakhir yang diketahui kekal tersedia apabila get laluan tidak dapat dicapai — gangguan hanya menjejaskan
kesegaran. Model dan kombo diterbitkan sebaik sahaja tersedia; kombo automatik, senarai penyedia
dan tindanan pengayaan digabungkan apabila tersedia, jadi satu titik akhir yang perlahan tidak boleh menyekat
keseluruhan pemilih.

Nama mengandungi maklumat yang diketahui oleh get laluan: penyedia huluan yang menjadi destinasi penghalaan model, penanda `[Free]`
dan belanjawan yang disertakan bersamanya — supaya dua sambungan yang menawarkan model yang sama kekal
dapat dibezakan. Matikan awalan dengan `"providerTag": false`.

Tiada perintah segar semula manual: perintah OpenCode v2 ialah templat prom, bukannya panggil balik,
jadi pemalam tidak boleh menyediakannya. Segar semula mengikut TTL; hos hanya diminta untuk memuatkan semula apabila
katalog atau tindanan benar-benar berubah, bukan sekali bagi setiap segar semula.

## Panggilan alat pada Gemini

Gemini menolak keseluruhan permintaan yang pengisytiharan alatnya mengandungi `$schema` atau
`additionalProperties`, dengan respons `400 INVALID_ARGUMENT`. Pemalam membuang kata kunci tersebut daripada
skema alat yang ditujukan kepada model Gemini daripada penyedia ini dan membiarkan setiap permintaan lain tanpa perubahan.
Alat yang mengandungi `$ref` dimajukan tanpa perubahan dan bukannya dibuang, kerana mengalih keluar
rujukan tersebut akan meluaskan skema kepada "terima apa sahaja".
Tetapkan `"geminiSanitization": false` untuk mematikannya.

## Penyelesaian masalah

| Gejala                                    | Punca                                                                                                                 |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Pemilih tidak menunjukkan model OmniRoute | Tiada kekunci berjaya dikenal pasti (semak amaran permulaan), atau get laluan tidak dapat dicapai                     |
| ID model mentah, tiada kombo, tiada harga | Titik akhir pengurusan menolak token — tetapkan `managementReadToken`                                                 |
| Sesi dipinkan kepada `opencode-<id>/…`    | Pemalam v1 menerbitkan `opencode-<id>`; v2 menerbitkan `<id>` tanpa awalan, jadi pilih semula model di bawah `<id>/…` |
