**OmniCopilot** meletakkan setiap model yang disediakan oleh OmniRoute anda ke dalam pemilih model
_asli_ GitHub Copilot Chat. Tiada bar sisi kedua, tiada UI sembang berasingan — mod ejen Copilot, panggilan alat,
pelayan MCP dan arahan tersuai semuanya terus berfungsi, cuma dijalankan pada model yang anda pilih.

|                      |                                                                                                                                                 |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Pasang (VS Code)** | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Pasang (fork)**    | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Sumber / isu**     | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Keperluan**        | VS Code 1.104+                                                                                                                                  |

> **Langganan Copilot tidak diperlukan.** Sejak VS Code 1.122, penyedia model bahasa berfungsi
> tanpa log masuk GitHub dan tanpa sebarang pelan Copilot. Pelengkapan sebaris dan
> ciri berasaskan pembenaman kekal di luar API penyedia dan masih memerlukan Copilot.

## Persediaan

1. **Jalankan OmniRoute** — `npm install -g omniroute && omniroute` (papan pemuka di `http://localhost:20128`).
2. **Pasang sambungan** — cari "OmniRoute" dalam paparan Extensions.
3. **Pilih model** — Copilot Chat → pemilih model → **Manage Models…** → **OmniRoute**, kemudian tandakan
   model yang anda mahu.

Tiada apa-apa yang perlu dikonfigurasikan apabila OmniRoute berjalan pada port lalai. Untuk tika jauh, buka
**ikon OmniRoute dalam Activity Bar** (atau jalankan `OmniRoute: Manage Connection`) dan tetapkan:

- **URL pelayan** — akar pelayan, contohnya `http://192.168.0.15:20128`. Akhiran `/v1`
  ditambahkan oleh sambungan; jangan sertakannya.
- **Kunci API** — hanya apabila pelayan menetapkan `REQUIRE_API_KEY`. Disimpan dalam rantai kunci OS melalui VS
  Code SecretStorage, bukan sekali-kali dalam `settings.json`.

## Perkara yang akan dipaparkan oleh pemilih

Sambungan ini tidak memaparkan muatan mentah `GET /v1/models` — ia membentuk semula muatan tersebut dan bilangan yang anda
lihat adalah lebih rendah daripada saiz katalog atas dua sebab yang disengajakan.

### Ia meminta satu id bagi setiap model

`MODELS_CATALOG_PREFIX_MODE` ditetapkan secara lalai kepada **`dual`**, yang mengiklankan setiap model dua kali — sekali
di bawah awalan alias pendek dan sekali di bawah awalan penyedia kanonik — supaya konfigurasi klien lama
terus dapat menyelesaikan kedua-dua bentuk:

```
cc/claude-sonnet-4-6        ← awalan alias
claude/claude-sonnet-4-6    ← awalan kanonik, model yang sama
```

Sambungan meminta **`GET /v1/models?prefix=alias`** supaya satu id diterima bagi setiap model, tanpa
mengubah tetapan seluruh pelayan untuk klien anda yang lain. Pada tika rujukan, ini mengurangkan
**2345 entri kepada 1396 — 949 pendua, sifar model hilang.**

Jika anda lebih suka membetulkannya di seluruh pelayan untuk _setiap_ klien, tetapkan bendera ciri
`MODELS_CATALOG_PREFIX_MODE` kepada `alias` dalam papan pemuka. Lihat
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) untuk
parameter pertanyaan dan jadual bagi setiap mod.

### Ia menyembunyikan model yang tidak boleh bersembang

Katalog turut menyenaraikan model imej, video, audio, penarafan semula, pembenaman dan penyederhanaan. Model tersebut
tetap akan ditolak apabila permintaan sembang dibuat:

```
HTTP 400 — Model '<id>' ialah model penjanaan imej dan tidak boleh digunakan pada
/v1/chat/completions. Sebaliknya, gunakan POST /v1/images/generations.
```

oleh itu, model tersebut ditapis berdasarkan medan `type` sebelum sampai kepada pemilih. **Model Responses-API
dikekalkan** — setiap entri Codex / GPT-5.x mengiklankan `supported_endpoints: ["responses"]`,
dan OmniRoute menterjemahkannya untuk `/v1/chat/completions`, maka semuanya boleh digunakan dengan sempurna.

### Penyedia yang tidak pernah anda konfigurasikan

Katalog menyenaraikan model daripada penyedia yang mempunyai **sambungan aktif** _serta_ setiap penyedia **noAuth**
— penyedia tanpa kunci yang membentuk sebahagian besar peringkat percuma. Ini disengajakan. Untuk menyembunyikannya,
tambahkan penyedia tersebut pada `blockedProviders` dalam tetapan papan pemuka; tiada apa-apa yang berubah dalam
sambungan.

## Papan pemuka dalam tab VS Code

`omnicopilot.dashboardOpen: "editor"` memaparkan papan pemuka OmniRoute dalam tab editor melalui
Simple Browser dan bukannya pelayar luaran. Pembenaman perlu **didayakan secara pilihan pada pelayan** melalui
`DASHBOARD_ALLOW_EMBED=vscode`, yang menyediakan halaman HTML dengan
`frame-ancestors 'self' vscode-webview:` dan bukannya tetapan lalai `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Permukaan API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) mengekalkan
pengepala yang ketat dalam kedua-dua keadaan.

> ⚠️ **Ini ialah penanda masa binaan, bukan masa jalan.** Next.js mengkompil `headers()` ke dalam manifes
> laluan, jadi `next.config.mjs` membaca pemboleh ubah tersebut semasa berkas dibina
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Mengeksportnya sebelum memulakan pelayan yang telah dibina tidak mengubah apa-apa — pengepala tersebut telah diterapkan.

```bash
# pemboleh ubah mesti tersedia pada perintah BUILD
DASHBOARD_ALLOW_EMBED=vscode npm run build        # atau npm run build:release
npm start
```

| Cara anda memasang         | Bolehkah anda mendayakan pembenaman?                                                                                                          |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Daripada sumber            | ✅ tetapkan pemboleh ubah pada perintah binaan, seperti di atas                                                                               |
| `npm install -g omniroute` | ❌ pakej yang diterbitkan disertakan dengan berkas prabina — bina daripada sumber sebagai gantinya                                            |
| Imej Docker                | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — imej prabina di Docker Hub tidak didayakan untuk pembenaman |

Tanpa binaan yang mendayakan pembenaman, halaman tersebut enggan dipaparkan dalam bingkai. Sambungan mengesan perkara itu daripada
pengepala respons lalu kembali menggunakan pelayar luaran — tiada apa-apa yang rosak dan ia memaklumkan perkara itu sekali sahaja.
Lihat [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) dan isu
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Mengkonfigurasi alat anda yang lain dari dalam VS Code

**`OmniRoute: Configure Coding CLI`** menggunakan CLI `omniroute` untuk menulis profil sedia digunakan
bagi Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo dan Roo — konfigurasi yang sama seperti yang diterangkan dalam
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). Kunci API diserahkan kepada CLI melalui pemboleh ubah persekitaran
`OMNIROUTE_API_KEY`, dan tidak sekali-kali melalui baris perintah.

## Penyelesaian masalah

| Gejala                                                        | Punca / penyelesaian                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tiada model OmniRoute dalam pemilih                           | Pelayan tidak dapat dicapai. Titik bar status bertukar kelabu; jalankan `OmniRoute: Check Connection`. Penemuan tidak memaparkan pemberitahuan secara sengaja dan tidak menyumbang sebarang model, dan bukannya memaparkan gesaan.                                           |
| Setiap model muncul dua kali                                  | Anda menggunakan OmniCopilot yang lebih lama daripada 1.0.1 — kemas kini. Sambungan kini meminta `?prefix=alias`.                                                                                                                                                            |
| Model imej/audio yang pernah disenaraikan kini tiada          | Disengajakan sejak 1.0.1 — model tersebut sememangnya tidak dapat menjawab permintaan sembang.                                                                                                                                                                               |
| Panel tiada pada Bar Aktiviti                                 | VS Code memindahkan bekas paparan tambahan ke limpahan **"…"** di bahagian bawah Bar Aktiviti, dan bekas yang disembunyikan melalui klik kanan akan kekal tersembunyi. Klik kanan Bar Aktiviti → tandakan **OmniRoute**, atau bukanya dengan `OmniRoute: Manage Connection`. |
| Papan pemuka dibuka dalam pelayar walaupun dalam mod `editor` | Pelayan tidak **dibina** dengan `DASHBOARD_ALLOW_EMBED=vscode` (lihat di atas) — menetapkannya semasa permulaan pada pemasangan prabina tidak mengubah apa-apa. Penggunaan pelayar luaran sebagai sandaran adalah disengajakan.                                              |
| Senarai model lapuk selepas menukar penyedia                  | `OmniRoute: Refresh Models`, atau pautan ↻ dalam panel.                                                                                                                                                                                                                      |
