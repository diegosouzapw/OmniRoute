OmniRoute menyusun 352 penyedia yang disokong kepada 3 peringkat ekonomi. Setiap
permintaan melalui peringkat tersebut mengikut turutan sehingga salah satunya berjaya memberikan respons — anda
mendapat respons sesuai yang paling murah tanpa perlu menulis kod sandaran.

## Peringkat 1 — Langganan

**Penyedia yang telah anda bayar.** OmniRoute menggunakan setiap baki kuota sebelum
ia tamat tempoh.

| Penyedia                         | Mengapa Peringkat 1                                      |
| -------------------------------- | -------------------------------------------------------- |
| Claude Code OAuth                | Anthropic Pro/Team — kadar rata, sering tidak digunakan  |
| OpenAI Codex (langganan ChatGPT) | Plus/Team merangkumi kuota Codex                         |
| GitHub Copilot                   | Mengikut pengguna — kuota ditetapkan semula setiap bulan |
| Cursor IDE                       | Kuota pelan Pro                                          |
| Antigravity / Devin Desktop      | Kuota terbina dalam                                      |

**Strategi**: halakan ke sini terlebih dahulu bagi setiap permintaan yang sepadan dengan
kekuatan model. Penjejak kuota memantau penetapan semula yang semakin hampir dan strategi gabungan
`reset-aware` menetapkan keutamaan sewajarnya. Untuk menghalakan ke Peringkat 1 terlebih dahulu dan hanya beralih
ke peringkat berbayar apabila kuota habis, gunakan ID `auto/thrifty` — atau `auto/subscription`
untuk kekal menggunakan kapasiti yang disertakan dalam pelan dan gagal secara tertutup. Lihat
[Penghalaan mengutamakan langganan](../routing/SUBSCRIPTION_LADDER.md).

## Peringkat 2 — Murah

**Penyedia bayar mengikut token di bawah $1/1M token.** Dikhaskan untuk beban kerja berjumlah tinggi
atau selepas kuota Peringkat 1 mencapai had.

| Penyedia                        | Harga (input/output) | Kekuatan            |
| ------------------------------- | -------------------- | ------------------- |
| DeepSeek V4 Pro                 | $0.27 / $1.10 per 1M | Kod, penaakulan     |
| GLM-4.5                         | $0.60 / $2.20 per 1M | Konteks panjang     |
| MiniMax M1                      | $0.20 / $1.10 per 1M | Kelajuan            |
| Qwen Coder                      | $0.30 / $1.20 per 1M | Kod                 |
| OpenRouter (dioptimumkan harga) | berbeza-beza         | 100+ model, dinamik |

**Strategi**: gabungan `cost-optimized` memilih model dengan $/token terendah yang memenuhi
penapis keupayaan tugas (penglihatan, mod JSON, alat, konteks maksimum).

## Peringkat 3 — Percuma

**Penyedia kos sifar** — peringkat percuma, program kredit, kuota harian OAuth.

| Penyedia         | Kuota / kredit percuma                                    |
| ---------------- | --------------------------------------------------------- |
| Kiro AI          | Peringkat Claude percuma (penggunaan saksama yang banyak) |
| OpenCode Free    | Tiada pengesahan, had kadar yang banyak                   |
| Qoder            | OAuth percuma                                             |
| Google Vertex AI | Kredit $300 untuk akaun baharu                            |
| Amazon Q         | Peringkat percuma untuk pengguna AWS                      |
| Pollinations     | API awam terbuka                                          |
| Cloudflare AI    | Peringkat percuma Workers AI                              |

**Strategi**: gabungan `auto` dengan had belanjawan menghalakan permintaan ke sini apabila Peringkat 1+2 gagal
atau apabila `useFreeOnly=true` ditetapkan. Penyedia percuma selalunya mempunyai
had kadar yang lebih ketat — pemutus litar memulihkannya selepas tempoh tunggu.

## Mengkonfigurasi peringkat

Papan pemuka → **Peringkat** → tetapkan penyedia anda. Tetapan lalai (daripada `tierDefaults.json`) adalah
munasabah; ubah apabila anda mempunyai langganan tertentu untuk diutamakan atau penyedia untuk dikecualikan.

Pemarkahan 16 faktor Auto-Combo turut mengambil kira peringkat. Lihat
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetri

Papan pemuka → **Penggunaan** menunjukkan token yang dibelanjakan bagi setiap peringkat setiap hari. Gunakan maklumat ini untuk:

- Mengesahkan Peringkat 1 digunakan sepenuhnya (jika tidak, anda mensia-siakan nilai langganan)
- Mengenal pasti model Peringkat 2 yang paling kerap dipilih (satukan kepada 1-2)
- Memastikan Peringkat 3 menjimatkan wang untuk beban kerja pengujian/penerokaan

## Corak lazim

### Beban kerja percuma sepenuhnya

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Mendorong dengan kuat ke arah Peringkat 3; hanya menggunakan Peringkat 2 jika Peringkat 3 tidak tersedia.

### Mengutamakan langganan dengan sandaran murah

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Senarai tersusun secara eksplisit yang sepadan dengan Peringkat 1 → Peringkat 2 → Peringkat 3.
