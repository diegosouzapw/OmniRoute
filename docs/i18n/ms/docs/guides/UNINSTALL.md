## Nyahpasang Pantas (v3.6.2+)

OmniRoute menyediakan dua skrip terbina dalam untuk penyingkiran bersih:

### Kekalkan Data Anda

```bash
npm run uninstall
```

Ini menyingkirkan aplikasi OmniRoute tetapi **mengekalkan** pangkalan data, konfigurasi, kunci API dan tetapan penyedia anda dalam `~/.omniroute/`. Gunakan pilihan ini jika anda bercadang untuk memasang semula kemudian dan mahu mengekalkan persediaan anda.

### Penyingkiran Penuh

```bash
npm run uninstall:full
```

Ini menyingkirkan aplikasi **dan memadamkan secara kekal** semua data:

- Pangkalan data (`storage.sqlite`)
- Konfigurasi penyedia dan kunci API
- Fail sandaran
- Fail log
- Semua fail dalam direktori `~/.omniroute/`

> ⚠️ **Amaran:** `npm run uninstall:full` tidak boleh dibuat asal. Semua sambungan penyedia, kombo, kunci API dan sejarah penggunaan anda akan dipadamkan secara kekal.

## Nyahpasang Secara Manual

### Pemasangan Global NPM

```bash
# Singkirkan pakej global
npm uninstall -g omniroute

# (Pilihan) Singkirkan direktori data
rm -rf ~/.omniroute
```

### Pemasangan Global pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Hentikan dan singkirkan bekas
docker stop omniroute
docker rm omniroute

# Singkirkan volum (memadamkan semua data)
docker volume rm omniroute-data

# (Pilihan) Singkirkan imej
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Hentikan dan singkirkan bekas
docker compose down

# Singkirkan volum juga (memadamkan semua data)
docker compose down -v
```

### Aplikasi Desktop Electron

**Windows:**

- Buka `Settings → Apps → OmniRoute → Uninstall`
- Atau jalankan penyahpasang NSIS daripada direktori pemasangan

**macOS:**

- Seret `OmniRoute.app` dari `/Applications` ke Tong Sampah
- Singkirkan data: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Singkirkan fail AppImage
- Singkirkan data: `rm -rf ~/.omniroute`

### Pemasangan daripada Sumber (git clone)

```bash
# Singkirkan direktori yang diklon
rm -rf /path/to/omniroute

# (Pilihan) Singkirkan direktori data
rm -rf ~/.omniroute
```

## Direktori Data

Secara lalai, OmniRoute menyimpan data di lokasi berikut:

| Platform   | Laluan Lalai                    | Penggantian                         |
| ---------- | ------------------------------- | ----------------------------------- |
| Linux      | `~/.omniroute/`                 | Pemboleh ubah env `DATA_DIR`        |
| macOS      | `~/.omniroute/`                 | Pemboleh ubah env `DATA_DIR`        |
| Windows    | `%APPDATA%/omniroute/`          | Pemboleh ubah env `DATA_DIR`        |
| Docker     | `/app/data/` (volum dilekapkan) | Pemboleh ubah env `DATA_DIR`        |
| Serasi XDG | `$XDG_CONFIG_HOME/omniroute/`   | Pemboleh ubah env `XDG_CONFIG_HOME` |

### Fail dalam direktori data

| Fail/Direktori       | Penerangan                                             |
| -------------------- | ------------------------------------------------------ |
| `storage.sqlite`     | Pangkalan data utama (penyedia, kombo, tetapan, kunci) |
| `storage.sqlite-wal` | Log tulis dahulu SQLite (sementara)                    |
| `storage.sqlite-shm` | Memori dikongsi SQLite (sementara)                     |
| `call_logs/`         | Arkib muatan permintaan                                |
| `backups/`           | Sandaran pangkalan data automatik                      |
| `log.txt`            | Log permintaan legasi (pilihan)                        |

## Sahkan Pengalihan Keluar Sepenuhnya

Selepas menyahpasang, sahkan bahawa tiada fail yang masih berbaki:

```bash
# Semak pakej npm global
npm list -g omniroute 2>/dev/null

# Semak direktori data
ls -la ~/.omniroute/ 2>/dev/null

# Semak proses yang sedang berjalan
pgrep -f omniroute
```

Jika masih terdapat proses yang sedang berjalan, hentikannya:

```bash
pkill -f omniroute
```
