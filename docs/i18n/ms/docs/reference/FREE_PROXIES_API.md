OmniRoute menyediakan kumpulan proksi percuma terpilih dalam jadual `free_proxies`,
yang disegerakkan daripada penyedia luaran (1proxy, proxifly, iplocate, webshare).
Papan pemuka memaparkannya di bawah **Tetapan → Proksi Percuma**. Dokumen ini
merangkumi penapisan, pengisihan, pengiraan dan pelaporan ralat penyegerakan pada
sisi pelayan yang didedahkan oleh laluan senarai.

## Laluan senarai — `GET /api/settings/free-proxies`

Mengembalikan subset yang ditapis, diisih dan dipaginakan berserta jumlah
keseluruhan. Penapisan dan pengiraan dilakukan dalam SQL, supaya UI boleh
memaparkan jumlah sebenar (contohnya `Jumlah: 0`) tanpa memuatkan setiap baris
ke dalam memori.

### Parameter pertanyaan

| Parameter         | Jenis                              | Lalai     | Maksud                                                                                                            |
| ----------------- | ---------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------- |
| `search`          | rentetan                           | `""`      | `LIKE` sensitif huruf besar-kecil pada lajur hos (dan sumber).                                                    |
| `protocol`        | rentetan                           | `""`      | Penapis `type`: `http` / `https` / `socks4` / `socks5`. Kosong = semua.                                           |
| `country`         | rentetan                           | `""`      | Penapis `countryCode` (ISO-2). Kosong = semua.                                                                    |
| `minQuality`      | nombor                             | `0`       | Hanya baris dengan `qualityScore >= minQuality`. `0` = tiada had minimum.                                         |
| `disabledSources` | rentetan                           | `""`      | ID sumber dipisahkan dengan koma untuk dikecualikan (contohnya `proxifly,webshare`).                              |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = skor menurun; `latency` = kependaman menaik (nilai nol terakhir); `recent` = `lastValidated` menurun. |
| `offset`          | nombor                             | `0`       | Permulaan pemaginan.                                                                                              |
| `limit`           | nombor                             | `50`      | Saiz halaman (dihadkan pada sisi pelayan).                                                                        |

### Respons

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 daripada pelayan huluan"],
    "webshare": ["tamat masa rangkaian"]
  }
}
```

`total` mencerminkan jumlah yang ditapis **sebelum** pemaginan, supaya UI boleh
memaparkan `Jumlah: N` dan `hasMore` secara berasingan. `syncErrors` menggunakan
ID sumber sebagai kunci dan diisi hanya untuk sumber yang gagal dalam
penyegerakan terakhir — hasil `Jumlah: 0` tidak pernah dipaparkan tanpa
penjelasan.

## Tambah ke kumpulan — `POST /api/settings/free-proxies/[id]/add-to-pool`

Menaik taraf proksi percuma ke dalam kumpulan `proxy_registry` terurus.
Mengesahkan penyedia huluan terlebih dahulu; apabila berjaya, mengembalikan ID
proksi kumpulan baharu dan kependaman yang diukur.

## Penyegerakan — `POST /api/settings/free-proxies/sync`

Mengambil semula semua sumber yang didayakan (atau subset dalam
`{ "sources": [...] }`). Setiap sumber disegerakkan secara berasingan; sumber
yang gagal direkodkan dalam `syncErrors` manakala sumber lain tetap selesai,
jadi penyegerakan separa tidak akan memadamkan data baik yang terdahulu.

## Statistik — `GET /api/settings/free-proxies/stats`

Mengembalikan agregat `total / inPool / avgQuality / bySource / lastSyncAt`
tanpa muatan baris — digunakan oleh widget pengepala papan pemuka.
