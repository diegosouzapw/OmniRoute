> Togol masa jalan yang mengubah tingkah laku OmniRoute **tanpa penggunaan semula**.
> Setiap bendera yang disenaraikan di sini ditakrifkan dalam
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — satu-satunya sumber rujukan. Papan pemuka dan REST API kedua-duanya membaca daripada
> fail tersebut, maka jadual di bawah dijana agar sepadan dengannya secara 1:1.

---

## Apakah Itu Bendera Ciri

Bendera ciri ialah togol bernama (boolean atau enum) yang nilainya boleh diubah pada
masa jalan dan dikekalkan dalam pangkalan data, tanpa memerlukan penggunaan semula proses. Setiap
bendera diterangkan oleh `FeatureFlagDefinition` dengan `key`, `label`,
`description`, `category`, `defaultValue`, `type` dan petunjuk `requiresRestart`.

### Turutan Resolusi

**Nilai berkuat kuasa** bagi sesuatu bendera ditentukan oleh
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) mengikut
keutamaan ini (yang tertinggi diutamakan):

1. **Penggantian DB** — nilai yang disimpan dalam jadual `key_value` di bawah ruang nama
   `feature_flags` (ditetapkan melalui papan pemuka atau REST API).
2. **Pemboleh ubah persekitaran** — `process.env[<KEY>]`, jika ditetapkan dan tidak kosong.
3. **Lalai definisi** — `defaultValue` daripada `featureFlagDefinitions.ts`.

Bendera boolean dianggap **didayakan** apabila nilai berkuat kuasanya ialah `"true"`,
`"1"` atau `"yes"` (lihat `isFeatureFlagEnabled()`).

> [!NOTE]
> Kebanyakan bendera turut mempunyai pemboleh ubah persekitaran yang sepadan dengan **nama yang sama**
> dan didokumentasikan dalam [`ENVIRONMENT.md`](./ENVIRONMENT.md). Penggantian DB bendera
> diutamakan berbanding pemboleh ubah persekitaran tersebut. Bendera dengan
> `requiresRestart: true` dikekalkan serta-merta tetapi hanya dibaca semula ketika proses
> dimulakan — menogolnya memaparkan sepanduk **"Mulakan Semula Pelayan"** dalam papan pemuka.

## Katalog Flag

80 flag merentas 6 kategori. **Lalai** ialah lalai definisi — nilai yang
digunakan apabila tiada penggantian DB mahupun pemboleh ubah persekitaran.

## Menukar Bendera

### Papan Pemuka

Navigasi ke **Papan Pemuka → Tetapan → Bendera Ciri**
(`/dashboard/settings/feature-flags`). Grid
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
menyokong:

- **Cari** mengikut kunci atau penerangan, dan **tapis** mengikut kategori (ditambah paparan sintetik **Memerlukan Mulakan Semula**).
- Satu **togol** untuk bendera boolean dan satu **menu lungsur** untuk bendera enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Satu **lencana sumber** bagi setiap bendera — `DB`, `ENV`, atau `DEF` — menunjukkan dari mana nilai berkesan itu berasal.
- Butang **Set Semula** (ditunjukkan hanya untuk bendera bersumber `DB`) untuk menggugurkan penggantian, dan butang **Set Semula Semua Penggantian** di bahagian bawah.
- Sepanduk **Mulakan Semula Pelayan** apabila bendera `requiresRestart` diubah.

### API REST

Semua operasi melalui satu laluan:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Setiap kaedah memerlukan sesi papan pemuka yang disahkan (`401` jika tidak).

#### `GET /api/settings/feature-flags`

Mengembalikan setiap bendera dengan nilai berkesan, sumber, dan ringkasannya.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... semua 77 bendera
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Tetapkan atau buang satu penggantian. Badan: `{ key: string; value?: string }`.
Mengabaikan `value` membuang penggantian (mengembalikan env / lalai).

```bash
# Tetapkan penggantian DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Buang penggantian (tiada "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Respons mengulangi `effectiveValue`/`source` yang baharu, `previousValue`/
`previousSource` yang sebelumnya, dan `requiresRestart`. Kunci yang tidak diketahui dan nilai enum di luar julat ditolak dengan `400`.

#### `DELETE /api/settings/feature-flags`

Mengosongkan **semua** penggantian DB sekaligus, mengembalikan setiap bendera kepada nilai env / lalainya. Mengembalikan `{ cleared: <count>, message: "..." }`.

> [!NOTA]
> Bendera dengan `requiresRestart: true` hanya berkuat kuasa selepas proses dimuat semula.
> Aliran mulakan semula papan pemuka memanggil `POST /api/restart` dan kemudian meninjau
> `GET /api/health/ping` sehingga pelayan kembali beroperasi.

## Sandaran Bajet Kecemasan

`OMNIROUTE_EMERGENCY_FALLBACK` (kategori `runtime`, lalai `true`) mengawal laluan
sandaran percuma kecemasan dalam
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Apabila didayakan, permintaan yang telah menghabiskan bajetnya dihalakan kepada
penyedia/model sandaran percuma dan bukannya gagal sepenuhnya. Tetapkannya kepada `false` (atau `0`) — melalui
togol papan pemuka, penggantian DB, atau pemboleh ubah persekitaran
`OMNIROUTE_EMERGENCY_FALLBACK` — untuk menyahdayakan tingkah laku tersebut dan membiarkan permintaan
yang telah kehabisan bajet gagal. (Ditampilkan sebagai togol papan pemuka dalam PR #3741 / #3752.)
