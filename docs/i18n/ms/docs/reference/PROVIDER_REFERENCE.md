## Kategori

- **Percuma** — peringkat percuma dengan kunci API (dikonfigurasikan melalui papan pemuka)
- **Tanpa pengesahan** — titik akhir awam yang langsung tidak memerlukan kunci atau log masuk
- **OAuth** — aliran log masuk dikendalikan oleh OmniRoute, tanpa memerlukan kunci API
- **Kuki web** — membalut aplikasi web penyedia melalui pengesahan kuki
- **Kunci API** — penyedia berbayar yang dikonfigurasikan melalui kunci API (kredit percuma mungkin tersedia)
- **Setempat** — berjalan pada mesin pengguna (Ollama, LM Studio, vLLM, dll.)
- **Carian** — penyedia carian web
- **Audio** — penyedia audio sahaja (TTS/STT)
- **Proksi huluan** — penyedia yang bertindak sebagai proksi kepada penyedia lain
- **Ejen awan** — ejen pengekodan yang berjalan lama (Codex Cloud, Devin, Jules)
- **Sistem** — penyedia dalaman OmniRoute (gelung balik, dll.)

Tag tambahan: `imej`, `video`, `pengagregat`, `perusahaan`, `pembenaman/penyusunan semula`, `dihoskan sendiri`.

`Pemanggilan alat` (jika ditunjukkan): `asli` — API pemanggilan fungsi sebenar; `ditiru` — tatasusunan `tools` ditiru melalui gesaan menggunakan `webTools.ts` (blok `<tool>{...}</tool>` dihuraikan dengan regex); `tiada` — `tools` pada masa ini digugurkan secara senyap. Lihat #7286.

Gunakan papan pemuka di `/dashboard/providers` untuk mendayakan, mengkonfigurasikan dan menguji setiap penyedia.
