## Navigasi Peringkat Tinggi

Bar sisi papan pemuka (selepas Kumpulan B) mempunyai bahagian peringkat atas berikut mengikut urutan:

```
Laman Utama
Penyedia
Kombo
Kunci API
Tetapan
Analitik
Kos            ← BAHARU (Kumpulan B, pelan 16)
Pemantauan     ← DISUSUN SEMULA (Kumpulan B, pelan 16)
...
```

---

## Bahagian Kos (baharu, tahap 1)

Awalan laluan: `/dashboard/costs/`

| Item                 | URL                                  | Penerangan                                              |
| -------------------- | ------------------------------------ | ------------------------------------------------------- |
| Gambaran Keseluruhan | `/dashboard/costs`                   | Papan pemuka kos teragregat (dipindahkan dari Analitik) |
| Harga                | `/dashboard/costs/pricing`           | Jadual harga bagi setiap model                          |
| Belanjawan           | `/dashboard/costs/budget`            | Ambang belanjawan + makluman                            |
| Perkongsian Kuota    | `/dashboard/costs/quota-share`       | Kumpulan Perkongsian Kuota + penggunaan                 |
| Konfigurasi Pelan    | `/dashboard/costs/quota-share/plans` | Penggantian pelan bagi setiap penyedia                  |

**Rasional**: Harga, Belanjawan dan Perkongsian Kuota sebelum ini berada di bawah
`Pemantauan > Parameter Kos`. Memindahkannya ke bahagian peringkat atas khusus
memudahkan item tersebut ditemukan tanpa perlu menavigasi melalui alat kebolehcerapan.

## Bahagian Pemantauan (disusun semula)

Bahagian Pemantauan kini mempunyai **Aktiviti di bahagian atas**, diikuti oleh **3 subkumpulan**:

```
Pemantauan
├── Aktiviti              ← Suapan garis masa (item peringkat atas)
├── Kumpulan Log
│   ├── Log (semua)
│   ├── Log Proksi
│   └── Log Konsol
├── Kumpulan Audit
│   ├── Log Audit
│   ├── Audit MCP
│   └── Audit A2A
└── Kumpulan Sistem
    ├── Kesihatan
    └── Masa Jalan
```

### Perubahan daripada struktur lama

| Sebelum                                                                                   | Selepas                                          |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Aktiviti = tab dalam Log yang memaparkan Log Audit                                        | Aktiviti = suapan khusus (`/dashboard/activity`) |
| Kumpulan Parameter Kos dalam Pemantauan                                                   | Dipindahkan ke bahagian Kos                      |
| Senarai rata: Log, Aktiviti (log), Audit, Kesihatan, Masa Jalan, Harga, Belanjawan, Kuota | 3 kumpulan berstruktur + bahagian Kos khusus     |

## Aktiviti berbanding Log Audit

Kedua-duanya kini berbeza:

| Dimensi                  | Aktiviti (`/dashboard/activity`)                                           | Log Audit (`/dashboard/audit`)            |
| ------------------------ | -------------------------------------------------------------------------- | ----------------------------------------- |
| **Tujuan**               | Suapan peristiwa untuk pengguna ("perkara yang berlaku baru-baru ini")     | Log pematuhan / keselamatan               |
| **Sumber data**          | `GET /api/compliance/audit-log?level=high`                                 | `GET /api/compliance/audit-log?level=all` |
| **Format**               | Garis masa, dikumpulkan mengikut hari, kata kerja + ikon yang mudah dibaca | Jadual berhalaman padat, 50/halaman       |
| **Penapis**              | Kategori jenis peristiwa                                                   | Tindakan, keterukan, pelaku, julat tarikh |
| **Eksport**              | Tidak tersedia                                                             | Eksport JSON                              |
| **Penapis pelaku**       | Tidak berkenaan                                                            | Boleh ditapis mengikut pelaku             |
| **Peristiwa dipaparkan** | Tindakan peringkat tinggi sahaja (senarai dibenarkan)                      | Semua peristiwa audit                     |

### Senarai tindakan peringkat tinggi yang dibenarkan

Ditakrifkan dalam `src/lib/audit/highLevelActions.ts`. Mengawal peristiwa yang muncul dalam
suapan Aktiviti. Senarai yang dibenarkan merangkumi:

- Peristiwa tambah/alih keluar/uji penyedia
- Cipta/kemas kini/padam kombo
- Kitaran hayat kunci API (cipta, batalkan, putar)
- Ambang belanjawan dicapai
- Log masuk/log keluar pengesahan
- Penciptaan sesi ejen awan
- Pendaftaran alat MCP
- Cipta/padam webhook
- Perubahan kumpulan/pelan kuota (tindakan `quota.*`, Kumpulan B)
- Peristiwa platform (kemas kini, kerahkan)
- Pasang/alih keluar kemahiran

Peristiwa yang tiada dalam senarai ini hanya muncul dalam Log Audit.

### Menambah tindakan peringkat tinggi baharu

Edit `src/lib/audit/highLevelActions.ts` dan tambahkan rentetan tindakan pada
`HIGH_LEVEL_ACTIONS`. Ini memerlukan PR (senarai tersebut ialah kod, bukan boleh dikonfigurasikan melalui DB).
Ikon yang sepadan boleh ditambahkan pada `src/lib/audit/activityIcons.ts`.

## Ubah hala: `/dashboard/logs/activity`

Laluan lama `/dashboard/logs/activity` diubah hala secara kekal (HTTP 308) ke
`/dashboard/activity` melalui `permanentRedirect()` dalam
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

ID bar sisi legasi `logs-activity` dikekalkan dalam `HIDEABLE_SIDEBAR_ITEM_IDS`
(tetapi dialih keluar daripada `SIDEBAR_DEFINITIONS`) untuk mengelakkan pratetap pengguna yang
merujuk ID lama daripada rosak.

## i18n

Ruang nama yang ditambahkan oleh Kumpulan B:

| Kunci ruang nama        | Merangkumi                                                                   |
| ----------------------- | ---------------------------------------------------------------------------- |
| `sidebar.costsSection`  | Label bahagian Kos                                                           |
| `sidebar.activity`      | Item bar sisi Aktiviti                                                       |
| `sidebar.logsGroup`     | Label subkumpulan Log                                                        |
| `sidebar.systemGroup`   | Label subkumpulan Sistem                                                     |
| `sidebar.costsOverview` | Item gambaran keseluruhan Kos                                                |
| `activity.*`            | Semua rentetan halaman Aktiviti (tajuk, kata kerja, penapis, keadaan kosong) |

Penyetempatan sumber rujukan: `pt-BR` dan `en`. Kesemua 40 penyetempatan lain kembali menggunakan
bahasa Inggeris melalui mekanisme sandaran `next-intl` (dikonfigurasikan dalam `src/i18n/config.ts`).
