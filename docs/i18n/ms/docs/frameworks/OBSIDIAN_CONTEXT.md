> **Sumber rujukan utama:** `src/lib/obsidian/api.ts` (klien REST + penyegerakan),
> `src/lib/db/obsidian.ts` (pengekalan token / URL asas / WebDAV),
> `src/lib/obsidianSync.ts` (penyegerakan bilik kebal WebDAV), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 alat MCP), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API tetapan). Pendaftaran alat
> dan pendawaian skop berada dalam `open-sse/mcp-server/server.ts`.

## Apakah ini

OmniRoute bersambung kepada bilik kebal **Obsidian** sebagai **sumber konteks** — pangkalan
pengetahuan Markdown setempat yang dibaca dan ditulis oleh ejen melalui pelayan MCP terbina
dalam. Integrasi ini berkomunikasi dengan pemalam komuniti **Obsidian Local REST API** yang
berjalan dalam aplikasi desktop, supaya ejen boleh mencari nota, membaca/menulis/menampal
fail, menyenaraikan bilik kebal, bekerja dengan nota berkala harian/mingguan, mengurus tag,
menjalankan perintah Obsidian dan (secara pilihan) menyelaraskan penyegerakan bilik kebal
dua hala desktop↔mudah alih.

Klien (`src/lib/obsidian/api.ts`) membalut Local REST API dengan:

- **Percubaan semula dengan sela masa meningkat** untuk ralat sementara `5xx`, **tamat masa 30 saat** melalui `AbortController`.
- **Pengelasan ralat berjenis** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Petunjuk mesra "tidak dapat mencapai Obsidian"** yang menerangkan kesilapan port lazim
  (HTTP pada `27123`, **bukan** titik akhir MCP pada `27124`) dan format Tailscale.
- **Pengekodan laluan** relatif kepada bilik kebal supaya laluan nota yang mengandungi ruang/garis condong adalah selamat.

## Persediaan

Tiada **pemboleh ubah persekitaran** untuk token atau URL asas Obsidian — kedua-duanya
disimpan dalam jadual SQLite `key_value` (ruang nama `obsidian`) melalui
`src/lib/db/obsidian.ts`. Token tersebut **disulitkan ketika disimpan** (AES-256-GCM,
dengan sandaran keserasian ke belakang teks biasa). Konfigurasikan daripada tab **Sumber Konteks**
pada papan pemuka Titik Akhir (`ObsidianSourceCard`), atau melalui API REST tetapan.

> [!IMPORTANT]
> Pemalam **Obsidian Local REST API** mesti dipasang dan sedang berjalan. Antara muka
> REST-nya mendengar pada **HTTP `127.0.0.1:27123`** (URL asas lalai). Port `27124`
> ialah titik akhir MCP/HTTPS yang _berasingan_ dan ditolak secara jelas oleh laluan tetapan.
> Jika menyambung daripada peranti lain, gunakan `http://<tailscale-ip>:27123`.

### Kekunci konfigurasi (SQLite `key_value`, ruang nama `obsidian`)

| Kekunci           | Tujuan                                                      | Disulitkan |
| ----------------- | ----------------------------------------------------------- | ---------- |
| `api_key`         | Token pembawa Local REST API                                | ya         |
| `base_url`        | URL asas REST (lalai `http://127.0.0.1:27123`)              | tidak      |
| `vault_path`      | Laluan mutlak ke direktori bilik kebal (untuk penyegerakan) | tidak      |
| `webdav_username` | Nama pengguna WebDAV yang dijana (penyegerakan bilik kebal) | tidak      |
| `webdav_password` | Kata laluan WebDAV yang dijana (penyegerakan bilik kebal)   | ya         |
| `webdav_enabled`  | Sama ada penyegerakan bilik kebal WebDAV didayakan          | tidak      |

### Konfigurasikan melalui REST

```bash
# Simpan + sahkan token Local REST API (POST mengesahkan melalui semakan status)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Semak status sambungan (mengembalikan connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Putuskan sambungan (mengosongkan token yang disimpan)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Semua kaedah memerlukan pengesahan papan pemuka. `POST` menolak sebarang URL pada port `27124`
dan mengesahkan token dengan memanggil titik akhir status Local REST API sebelum menyimpannya.

### Penyegerakan bilik kebal WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` mengurus penyegerakan bilik kebal berasaskan
WebDAV yang bersifat pilihan (dikuasakan oleh `src/lib/obsidianSync.ts`). Apabila didayakan,
OmniRoute akan dihalakan kepada direktori bilik kebal setempat dan pasangan nama
pengguna/kata laluan WebDAV rawak akan dijana:

```bash
# Dayakan penyegerakan WebDAV untuk direktori bilik kebal (menjana nama pengguna/kata laluan)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Dapatkan status penyegerakan WebDAV (kelayakan dikembalikan hanya semasa didayakan)
curl http://localhost:20128/api/settings/obsidian/webdav

# Nyahdayakan penyegerakan WebDAV (mengosongkan kelayakan + .stignore terurus)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Sumber konteks bagi setiap kekunci API (pilihan)

Konfigurasi Obsidian boleh diskop **bagi setiap kekunci API** melalui jadual
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Apabila panggilan MCP
membawa id kekunci API yang telah disahkan, `getObsidianConfigForApiKey()` mengutamakan
token/URL-asas/laluan-bilik-kebal milik kekunci tersebut (`source: "api_key"`) dan jika tidak,
menggunakan konfigurasi global sebagai sandaran (`source: "global"`).

## Alat MCP (22)

Ditakrifkan dalam `open-sse/mcp-server/tools/obsidianTools.ts`. Token/URL asas ditentukan
bagi setiap panggilan (kunci per-API didahulukan, kemudian global). Alat yang mengakses **pelayan penyegerakan**
OmniRoute (empat alat `obsidian_sync_*`) juga memerlukan token pengesahan penyegerakan yang dikonfigurasikan
dalam tetapan OmniRoute.

### Alat baca (`read:obsidian`)

| Alat                         | Penerangan                                                                                                  |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Semak sama ada Local REST API boleh dicapai dan telah disahkan.                                             |
| `obsidian_search_simple`     | Carian teks penuh bagi kandungan nota; mengembalikan petikan berserta laluan fail.                          |
| `obsidian_search_structured` | Cari menggunakan ungkapan JSON Logic (penapis and/or/regex/path).                                           |
| `obsidian_read_note`         | Baca nota mengikut laluan relatif peti besi; secara pilihan, tajuk/blok/frontmatter tertentu.               |
| `obsidian_list_vault`        | Senaraikan fail dan direktori dalam peti besi (pepohon entri).                                              |
| `obsidian_get_document_map`  | Dapatkan struktur tajuk nota sebagai peta tajuk → nombor baris.                                             |
| `obsidian_get_note_metadata` | Dapatkan frontmatter, tag, pautan, kiraan aksara/perkataan tanpa kandungan penuh.                           |
| `obsidian_get_active_file`   | Dapatkan laluan + kandungan fail yang sedang aktif dalam Obsidian.                                          |
| `obsidian_get_periodic_note` | Dapatkan nota berkala harian/mingguan/bulanan untuk sesuatu tarikh (hari ini jika tidak dinyatakan).        |
| `obsidian_get_tags`          | Senaraikan semua tag peti besi berserta kekerapannya.                                                       |
| `obsidian_list_commands`     | Senaraikan ID perintah Obsidian yang tersedia (gunakan dengan `obsidian_execute_command`).                  |
| `obsidian_sync_status`       | Status pelayan penyegerakan OmniRoute: berjalan, nama peti besi, port, masa operasi, penyegerakan terakhir. |
| `obsidian_sync_conflicts`    | Senaraikan konflik penyegerakan yang belum diselesaikan (laluan, laluan konflik, masa dikesan).             |

### Alat tulis (`write:obsidian`)

| Alat                             | Penerangan                                                                                            |
| -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Cipta atau tulis ganti nota dengan kandungan Markdown yang diberikan.                                 |
| `obsidian_append_note`           | Tambahkan kandungan pada nota; secara pilihan pada tajuk/blok tertentu.                               |
| `obsidian_patch_note`            | Tambah di belakang/tambah di hadapan/ganti secara tepat pada tajuk, blok, atau medan frontmatter.     |
| `obsidian_delete_note`           | Padam nota secara kekal daripada peti besi.                                                           |
| `obsidian_move_note`             | Pindahkan atau namakan semula nota dalam peti besi.                                                   |
| `obsidian_execute_command`       | Jalankan perintah Obsidian mengikut ID perintahnya.                                                   |
| `obsidian_open_file`             | Buka fail dalam Obsidian (menciptanya jika fail tersebut tidak wujud).                                |
| `obsidian_sync_trigger`          | Cetuskan penyegerakan peti besi desktop↔mudah alih dua hala dengan segera.                            |
| `obsidian_sync_resolve_conflict` | Selesaikan konflik penyegerakan: kekalkan `local` (mudah alih), `remote` (desktop), atau `keep-both`. |

> [!NOTE]
> Sasaran `obsidian_patch_note` menerima `targetType` berupa `heading | block | frontmatter`
> dan `operation` berupa `append | prepend | replace`, dengan
> `createTargetIfMissing` sebagai pilihan. Empat alat `obsidian_sync_*` berkomunikasi dengan pelayan penyegerakan
> setempat (`http://127.0.0.1:27781` secara lalai) dan memerlukan token penyegerakan.

### Skop

Alat baca memerlukan `read:obsidian`; alat tulis memerlukan `write:obsidian`. Penguatkuasaan
adalah sama seperti Notion — dikendalikan oleh `withScopeEnforcement()` dalam
`open-sse/mcp-server/server.ts`, tertakluk pada `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, dengan
skop yang dibenarkan diperoleh daripada `OMNIROUTE_MCP_SCOPES` atau konteks skop kunci API. Lihat
[MCP-SERVER.md](./MCP-SERVER.md).

## Titik akhir

| Kaedah   | Laluan                          | Tujuan                                                       |
| -------- | ------------------------------- | ------------------------------------------------------------ |
| `GET`    | `/api/settings/obsidian`        | Mengembalikan `{ connected, hasToken, baseUrl, vaultPath }`. |
| `POST`   | `/api/settings/obsidian`        | Simpan + sahkan token (menolak port `27124`).                |
| `DELETE` | `/api/settings/obsidian`        | Putuskan sambungan (padam token yang disimpan).              |
| `GET`    | `/api/settings/obsidian/webdav` | Status penyegerakan WebDAV + kelayakan (semasa didayakan).   |
| `POST`   | `/api/settings/obsidian/webdav` | Dayakan penyegerakan WebDAV untuk direktori peti simpanan.   |
| `DELETE` | `/api/settings/obsidian/webdav` | Nyahdayakan penyegerakan WebDAV.                             |

> Ini ialah laluan tetapan papan pemuka. Peti simpanan itu sendiri dicapai melalui Obsidian
> Local REST API (`base_url` yang dikonfigurasikan) dan melalui alatan MCP di atas — tiada
> titik akhir proksi Obsidian `/v1` awam.

## Kes penggunaan

- **Jawapan berasaskan peti simpanan** — `obsidian_search_simple` / `obsidian_search_structured`
  kemudian `obsidian_read_note` supaya ejen menjawab berdasarkan nota sebenar anda.
- **Pengarangan nota / penjurnalan** — `obsidian_write_note`, `obsidian_append_note`, atau
  `obsidian_patch_note` yang tepat untuk merekodkan output ejen, ringkasan atau nota harian
  (`obsidian_get_periodic_note`) ke dalam peti simpanan.
- **Navigasi peti simpanan** — `obsidian_list_vault`, `obsidian_get_document_map`, dan
  `obsidian_get_tags` untuk meneroka struktur sebelum membaca/menulis.
- **Automasi Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` untuk
  mengendalikan pemalam/perintah daripada ejen; `obsidian_open_file` untuk memaparkan nota dalam UI.
- **Penyegerakan mudah alih** — dayakan penyegerakan WebDAV, kemudian `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  untuk menyelaraskan desktop↔mudah alih dan menyelesaikan konflik.
