> **Sumber rujukan utama:** `src/lib/agentSkills/` (katalog, penjana, penghurai) + direktori `skills/` (fail SKILL.md)
> **Kemas kini terakhir:** 2026-08-02 — v3.8.50

Agent Skills ialah fail SKILL.md berstruktur yang mengajar ejen luaran, klien MCP dan pengatur A2A cara menggunakan REST API dan CLI OmniRoute. Tidak seperti [Omni Skills](./SKILLS.md) (yang merupakan definisi alat LLM yang dilaksanakan dalam OmniRoute), Agent Skills ialah _katalog dokumentasi_ — markdown statik yang boleh dimasukkan terus ke dalam konteks ejen.

---

## Gambaran Keseluruhan

Katalog ini mengandungi **45 Agent Skills** (23 REST API + 21 CLI + 1 aliran kerja konfigurasi). Setiap kemahiran mempunyai:

- **ID kanonik** (`omni-auth`, `cli-serve`, dan sebagainya)
- Fail **SKILL.md** dalam `skills/{id}/SKILL.md` dengan bahagian hadapan YAML (`name`, `description`) + kandungan markdown yang lengkap
- **Titik akhir REST** (kemahiran API) atau **subperintah CLI** (kemahiran CLI) yang diterbitkan daripada spesifikasi OpenAPI dan daftar CLI
- **URL mentah GitHub** untuk pengambilan langsung: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Format SKILL.md

```markdown
---
name: omni-providers
description: "Urus sambungan penyedia: tambah, uji, putar dan alih keluar kelayakan."
---

<!-- dijana oleh src/lib/agentSkills/generator.ts; suntingan manual akan ditulis ganti -->

## Gambaran Keseluruhan

...

## Pengesahan

...

## Titik Akhir

...

<!-- skill:custom-start -->

## Bahagian Tersuai (dikekalkan merentasi penjanaan semula)

...

<!-- skill:custom-end -->
```

Penjana mengekalkan kandungan antara `<!-- skill:custom-start -->` dan `<!-- skill:custom-end -->` semasa penjanaan semula. Sepuluh kemahiran mempunyai blok tersuai yang disusun:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Penemuan API REST

| Titik Akhir                  | Kaedah | Penerangan                                                            | Pengesahan |
| :--------------------------- | :----- | :-------------------------------------------------------------------- | :--------- |
| `/api/agent-skills`          | GET    | Senaraikan katalog (`?category=api\|cli\|config&area=<area>` pilihan) | tiada      |
| `/api/agent-skills/{id}`     | GET    | Dapatkan metadata kemahiran tunggal                                   | tiada      |
| `/api/agent-skills/{id}/raw` | GET    | Dapatkan SKILL.md sebagai `text/markdown`                             | tiada      |
| `/api/agent-skills/coverage` | GET    | Statistik liputan (bilangan fail SKILL.md yang wujud)                 | tiada      |
| `/api/agent-skills/generate` | POST   | Cetuskan penjana (dryRun/prune/onlyIds)                               | pengurusan |

Contoh — senaraikan semua kemahiran API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Contoh — dapatkan satu SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Penemuan A2A

Kemahiran A2A `list-capabilities` mengembalikan katalog penuh 45 kemahiran sebagai artifak jadual markdown. Pengatur luaran boleh memanggilnya melalui:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

Lihat [A2A-SERVER.md](./A2A-SERVER.md) untuk butiran protokol.

## Cara Ejen Luaran Menggunakan Kemahiran

### 1. Penemuan melalui REST

```bash
# Dapatkan katalog penuh
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Dapatkan SKILL.md untuk suntikan konteks
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Penemuan melalui MCP

```typescript
// Dalam klien MCP Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → tatasusunan AgentSkill dengan rawUrl bagi setiap satu
```

### 3. Penemuan melalui A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table ialah jadual markdown dengan kesemua 45 ID kemahiran + lajur rawUrl
```

### 4. Pengambilan mentah terus daripada GitHub (pelayan tidak diperlukan)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Penjana

Penjana membaca katalog tersusun + spesifikasi OpenAPI + daftaran CLI dan menulis `skills/{id}/SKILL.md` bagi setiap entri:

```bash
# Pratonton (larian kering, tiada penulisan)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Penjanaan semula penuh
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Jana semula ID tertentu
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Respons penjana ialah `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
