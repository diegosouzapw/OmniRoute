Kompresia Caveman môže okrem vstavaných pravidiel pre angličtinu načítať aj jazykovo špecifické balíky pravidiel.
Vďaka tomu zostáva jadro mechanizmu stabilné, zatiaľ čo balíky pre portugalčinu, španielčinu, nemčinu, francúzštinu, taliančinu, japončinu a
budúce jazyky sa môžu vyvíjať nezávisle.

## Umiestnenie

Jazykové balíky sa nachádzajú v:

```txt
open-sse/services/compression/rules/<language>/
```

Aktuálne dodávané balíky (overené podľa obsahu adresára `rules/`):

| Jazyk                   | Adresár        | Prítomné kategórie pravidiel                        |
| ----------------------- | -------------- | --------------------------------------------------- |
| Angličtina              | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Španielčina             | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugalčina (Brazília) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonézština            | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Taliančina              | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Nemčina                 | `rules/de/`    | `context`, `filler`, `structural`                   |
| Francúzština            | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japončina               | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Poznámka o parite:** Balíky `en`, `es`, `pt-BR`, `id` a `it` obsahujú všetkých 5 kategórií; balíky `de`, `fr` a `ja` sa dodávajú s 3 kategóriami. Pri chýbajúcich kategóriách `dedup` a `ultra` sa bez upozornenia použijú vstavané pravidlá pre angličtinu. Príspevky na doplnenie súborov `dedup.json` a `ultra.json` do menších balíkov sú vítané.
>
> Balík `pt-BR` je založený na systéme **[Troglodita](https://github.com/leninejunior/troglodita)** od Lenineho Júniora — kompresnom systéme navrhnutom od základov pre gramatiku brazílskej portugalčiny (obmedzenie pleonazmov, odstraňovanie výplňových výrazov PT-BR, technické skratky pre brazílsku vývojársku komunitu).
>
> Kanonický zoznam kategórií a schéma jednotlivých kategórií sa nachádzajú v súbore [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema, návrh 2020-12).

## Detekcia jazyka

`languageDetector.ts` používa jednoduché heuristiky na určenie jazyka z textu výzvy. Nakonfigurovaný predvolený jazyk sa
naďalej rešpektuje a detekciu možno prostredníctvom konfigurácie vypnúť, ak sa vyžaduje presné
riadenie.

Výstup detekcie sa používa iba na výber balíkov pravidiel. Nemení smerovanie poskytovateľov, výber
lokalizácie ani jazyk používateľského rozhrania.

## Štruktúra konfigurácie

Nastavenia kompresie môžu obsahovať:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` riadi predvolené nastavenia ovládacieho panela a náhľadu. `cavemanConfig` je konfigurácia mechanizmu za behu,
ktorá sa používa, keď Caveman komprimuje text správy.

## Pridanie jazykového balíka

1. Vytvorte `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Použite formát pravidiel Caveman zo súboru `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Zachovajte konzervatívne náhrady a nemeňte kód, identifikátory, URL adresy ani JSON.
4. Pridajte alebo aktualizujte testy výberu jazyka a správania náhrad.
5. Ak sa jazyk zobrazuje vo výberových prvkoch používateľského rozhrania, sprístupnite nové označenia pre dashboard/i18n.

## API

Dostupné balíky možno zistiť pomocou:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Koncový bod náhľadu prijíma prepísanie konfigurácie jazyka:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Všetkých 6 jazykových balíkov dostalo vo verzii v3.8.0 klauzulu `SHARED_BOUNDARIES`, ktorá sa uplatňuje pri každej
úrovni intenzity Caveman (LITE, FULL, ULTRA). Nariaďuje enginu zachovať tieto vzory doslovne
bez ohľadu na odstraňovanie okolitého výplňového textu:

| Typ vzoru                               | Príklad                                |
| --------------------------------------- | -------------------------------------- |
| Ohraničené bloky kódu                   | ` ```python\n...\n``` `                |
| Vnorený kód                             | `` `my_var` ``                         |
| URL adresy                              | `https://example.com/path`             |
| Cesty k súborom (absolútne + relatívne) | `/etc/hosts`, `./src/index.ts`         |
| Hlavičky chýb                           | `Error:`, `TypeError:`, `SyntaxError:` |
| Riadky trasovania zásobníka             | `  at functionName (file.ts:12:3)`     |

Tieto vzory sa nachádzajú v `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (predtým `[]`). Táto
konštanta sa nachádza v súbore `open-sse/services/compression/types.ts`.

### Prečo je to dôležité

Bez SHARED_BOUNDARIES by agresívne režimy Caveman mohli odstrániť obsah, ktorý vyzeral ako opakujúci sa
text, ale v skutočnosti išlo o úryvok kódu, cestu k súboru alebo zásobník chýb. SHARED_BOUNDARIES funguje ako
bezpečnostná vrstva nezávislá od jazyka, ktorá sa uplatní pred pravidlami odstraňovania výplňového textu.

### Prispôsobenie preservePatterns

Ďalšie vzory možno pridať počas behu prostredníctvom nastavení kompresie:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Vlastné vzory rozširujú (nenahrádzajú) 6 predvolených vzorov.

## Prevádzkové poznámky

- Vstavané pravidlá pre angličtinu zostávajú záložnou možnosťou, keď jazykový balík chýba.
- Neplatné vstavané balíky JSON neprejdú validáciou, aby nedošlo k nepozorovanému zhoršeniu kvality artefaktov vydania.
- Balíky pravidiel obsahujú iba údaje a nemali by importovať kód ani spúšťať ľubovoľnú logiku.
- Analytická vrstva kompresie zaznamenáva zvolený režim a engine, nie celý text promptu.
