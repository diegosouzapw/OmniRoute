`chatgpt-web-codex` (alias `cgpt-codex`) prepája kolá Codex Responses prostredníctvom
overenej relácie ChatGPT v prehliadači. Je nezávislý od vyradeného spoločného
poskytovateľa `chatgpt-web` a používa implementáciu s oznámením MIT v adresári
`open-sse/vendor/codex-chatgpt-web/`, aktualizovanú podľa upstreamového commitu v4.0.7
`b59d7dc51b84fb1f465ff1d00f5207f3b2b4a494`.

## Vyradenie spoločného poskytovateľa

Predchádzajúce ID spoločného poskytovateľa `chatgpt-web` a `cgpt-web` sa už nedodávajú,
pretože nebolo možné objasniť pôvod ich implementácie pre-key/proof-of-work. Explicitné
požiadavky na ktorékoľvek z týchto ID vrátane ID modelov s úvodnou lomkou a uložených
aliasov bezpečne zlyhajú s HTTP `410` a kódom **PROVIDER_RETIRED** ešte pred akoukoľvek upstreamovou požiadavkou.

Migrácia `168_retire_chatgpt_web.sql` označí zodpovedajúce pripojenia poskytovateľov ako
vyradené a zneplatní ich aktívne prenájmy relácií. Zachová históriu pripojení a zoznamy
povolených API kľúčov; do zoznamu povolených nepridáva náhradný prístup. Toto vyradenie
sa nevzťahuje na poskytovateľa Codex ani na jeho pripojenia.

## Predpoklady

- úplná hlavička Cookie z prihlásenej relácie ChatGPT;
- Chrome alebo Chromium spolu s grafickou reláciou alebo displejom Xvfb pre inštalácie
  npm, systemd a PM2;
- pri profile Docker `web` interná služba Chromium z
  `docker-compose.yml`;
- OpenAI `tunnel-client` v0.0.13 a vlastný konektor ChatGPT pre lokálne nástroje Codex.

Tunel je potrebný iba pri kolách s nástrojmi. Každá uvedená trasa vrátane `pro` môže
používať rovnakú lokálnu funkcionalitu nástrojov viazanú na kolo, ak sú tunel a konektor
nakonfigurované.

## Nastavenie v ovládacom paneli

1. Otvorte poskytovateľa **ChatGPT Web (Codex)** a pridajte pripojenie.
2. Vložte úplnú hlavičku Cookie služby ChatGPT, ID tunela, runtime kľúč a názov vlastného
   konektora. Nové nastavenia podporujúce nástroje musia používať novovytvorený konektor
   s presným názvom `OmniRoute Codex v2`, s možnosťou Authentication nastavenou na None
   a Permissions nastavenou na Allow all actions.
3. Spustite kontrolu pripojenia. OmniRoute otvorí prehliadačom podporovaný Temporary Chat
   a zistí, či sú pre daný účet dostupné režimy Sol a Pro.
4. Uložte pripojenie. OmniRoute nahradí vložený súbor cookie overeným stavom úložiska
   Playwright a uloží ho spolu s runtime kľúčom prostredníctvom abstrakcie šifrovaných
   prihlasovacích údajov.

Nespracovaný súbor cookie sa po úspešnom uložení neuchováva. Keď relácia vyprší, otvorte
pripojenie, vložte novú úplnú hlavičku Cookie a znova spustite kontrolu. Stav diagnostiky
v dialógovom okne úprav samostatne uvádza stav prehliadača, úložiska, prihlásenia,
Temporary Chat, tunela, konektora a obojsmernej komunikácie s nástrojom.

> Nikdy neukladajte skutočný súbor cookie, runtime kľúč, stav úložiska ani token
> funkcionality do repozitára. Hodnoty v testoch a dokumentácii musia byť vždy zástupné.

## Modely a kombinácie

Pevne stanovené trasy modelov sú:

- `chatgpt-web-codex/luna` — GPT-5.6 Luna, nízka úroveň úsilia
- `chatgpt-web-codex/think` — GPT-5.6 Luna, stredná úroveň úsilia
- `chatgpt-web-codex/instant`
- `chatgpt-web-codex/medium`
- `chatgpt-web-codex/high`
- `chatgpt-web-codex/extra-high`
- `chatgpt-web-codex/pro`

Pridajte ktorúkoľvek z nich do kombinácie rovnako ako akýkoľvek iný model. Aplikácia
Codex odosiela názov kombinácie ako `model` do bežného koncového bodu Responses,
`/v1/responses`; neexistuje samostatný koncový bod Codex ani prepínač režimu.

Účty Free/Go sprístupňujú trasy Luna. Účty podporujúce Sol sprístupňujú trasy od Instant
po High a účty podporujúce Pro navyše sprístupňujú Extra High a Pro. Každá trasa má
pevne stanovený backendový model a úroveň úsilia pri uvažovaní; konfliktná explicitná
úroveň úsilia Responses bezpečne zlyhá namiesto toho, aby potichu zmenila vybraný režim
prehliadača.

Nemeňte názov staršieho konektora `Codex Native` ani `OmniRoute Codex` a opätovne ho
nepoužívajte. ChatGPT ukladá verejný kontrakt MCP do vyrovnávacej pamäte podľa identity
konektora, zatiaľ čo aktualizovaný most používa nový priamy kontrakt tokenu kola.
Runtime tieto staršie identity odmieta a vyžaduje nový konektor `OmniRoute Codex v2`.

## Bezpečnostný model

- Natívna cesta vyžaduje požiadavku Responses, rozpoznaného klienta Codex a zhodné
  identity vlákna a ťahu.
- Pracovný priestor, sandbox, zásady schvaľovania a katalóg nástrojov pochádzajú z natívneho shellu Codex;
  voľne formulovaný text výzvy pre ne nie je autoritatívny.
- ChatGPT dostane pre každý ťah iba krátkodobé oprávnenie. Broker MCP prijíma iba
  nástroje, ktoré Codex ponúkol presne v danom ťahu.
- Automatické potvrdenie možnosti **Povoliť raz** iba vráti požiadavku na nástroj systému Codex. O schválení
  a vykonaní rozhoduje výhradne Codex.
- Pred prvým výstupom môže kombinácia prejsť na iný kompatibilný cieľ. Po začatí
  výstupu zostanú poskytovateľ, model, pripojenie a ťah prehliadača pripnuté až do dokončenia
  ťahu.
- Súbory cookie, runtime kľúče, stav úložiska a tokeny oprávnení sa nezobrazujú v odpovediach
  poskytovateľa ani v protokoloch požiadaviek.

## VPS bez displeja a Docker

Pri inštaláciách cez npm, systemd a PM2 OmniRoute zisťuje bežné cesty k prehliadačom Chrome a Chromium.
Prípadne nastavte `CHATGPT_WEB_CODEX_CHROME_PATH`. Runtime ťahy zámerne používajú Chrome
s grafickým rozhraním, pretože ChatGPT odmieta charakteristiky skutočne bezhlavého prehliadača. Hostiteľ bez displeja preto musí
spúšťať OmniRoute so súkromným displejom Xvfb; samotné nastavenie cesty k prehliadaču Chrome ho neposkytne.

Profil `web` systému Docker spúšťa `chatgpt-web-codex-browser` v internej sieti
Compose. Sprievodný kontajner spúšťa Chrome s grafickým rozhraním v prostredí Xvfb, takže nie je potrebný žiadny fyzický displej. Jeho port CDP
nie je publikovaný na hostiteľovi. Chránený zväzok profilu prehliadača je oddelený od
dátového zväzku OmniRoute a prehliadač dostáva dostatok zdieľanej pamäte. Interný proxy server CDP
počúva iba na porte `9223` v sieti Compose; Chrome zostáva v sprievodnom kontajneri naviazaný na loopback.

Prenájom supervízora v rámci `DATA_DIR` zabraňuje tomu, aby viacero procesov OmniRoute vlastnilo
rovnaký stav tunela a brokera. Konflikt nahlási diagnostický nástroj.

## Interaktívne obnovenie

Automatizovaná cesta Docker nemá okno viditeľné na hostiteľovi, ale samotný Chrome beží s grafickým rozhraním v
súkromnom displeji Xvfb. Keď ChatGPT vyžaduje interaktívne prihlásenie alebo overenie, na obnovenie možno
použiť existujúcu infraštruktúru prehliadača VNC. Používateľské rozhranie prehliadača a CDP musia zostať dostupné iba
cez loopback, autentifikované správcovské pripojenie alebo tunel SSH; noVNC zostáva počas
bežnej prevádzky vypnuté.

## Záložný mechanizmus WebSocket

Keď kombinácia obsahuje ChatGPT Web (Codex), most WebSocket pre Responses si pred
pripojením k nadradenému serveru vyžiada záložný mechanizmus HTTP/SSE. Prenos potom prebieha cez
`/v1/responses`.
