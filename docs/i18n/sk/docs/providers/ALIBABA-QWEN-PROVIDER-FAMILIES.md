Tento dokument zaznamenáva rozhodnutie o implementácii pre
[Issue #7854](https://github.com/diegosouzapw/OmniRoute/issues/7854). Verejné produkty sú
reprezentované ako štyri rodiny poskytovateľov. Región je údaj pripojenia, nie samostatný produkt.

## Rozhodnutie

| Rodina poskytovateľov                         | OmniRoute ID            | Globálny región | Región Čína |
| --------------------------------------------- | ----------------------- | --------------- | ----------- |
| Alibaba Cloud Model Studio (priebežné platby) | `alibaba`               | Singapur        | Peking      |
| Alibaba Cloud Token Plan                      | `bailian-coding-plan`   | Singapur        | Peking      |
| Qwen Cloud (priebežné platby)                 | `qwen-cloud`            | Globálny        | Peking      |
| Qwen Cloud Token Plan                         | `qwen-cloud-token-plan` | Singapur        | Peking      |

Existujúce ID `alibaba-cn` zostáva aliasom spätnej kompatibility za behu pre uložené pripojenia, trasy
modelov, kombinácie a historické využitie. Jeho karta na ovládacom paneli je zlúčená s kartou
`alibaba`; nie je potrebný žiadny prepis databázy.

Qwen Cloud s priebežnými platbami a Alibaba Cloud Model Studio v súčasnosti používajú rovnakých
hostiteľov za behu kompatibilných s DashScope, ale zostávajú samostatnými identitami poskytovateľov,
pretože používatelia získavajú kľúče a spravujú účty prostredníctvom rôznych produktových rozhraní.
Produkty Alibaba a Qwen Cloud Token Plan používajú rôzne rodiny koncových bodov, takže všetky štyri
produkty zostávajú samostatnými ID poskytovateľov.

## Matica koncových bodov

| Rodina poskytovateľov   | `global-sg`                                                              | `china-beijing`                                                      | Formát prenosu |
| ----------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------- | -------------- |
| `alibaba`               | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI         |
| `bailian-coding-plan`   | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/apps/anthropic/v1`  | `https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic/v1`  | Anthropic      |
| `qwen-cloud`            | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI         |
| `qwen-cloud-token-plan` | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` | `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | OpenAI         |

Kľúč API a koncový bod musia patriť k rovnakému produktu a regiónu. Výberom regiónu sa zmení
prednastavený koncový bod používaný pri overovaní a bežných požiadavkách.

## Kontrakt pripojenia

Nové pripojenia ukladajú stabilný kľúč regiónu v `providerSpecificData`:

```json
{
  "region": "global-sg"
}
```

Povolené hodnoty sú `global-sg` a `china-beijing`. Koncový bod sa centrálne odvodzuje z ID
poskytovateľa a regiónu. Hodnota `providerSpecificData.baseUrl`, ktorá nie je prednastavená, zostáva
explicitným prepísaním zo strany operátora a má prednosť, zatiaľ čo staré uložené prednastavené URL
sa normalizujú späť podľa regionálnej matice.

Tým zostáva schéma pripojenia rozšíriteľná: do resolvera možno pridať ďalší región bez vytvorenia
ďalšej karty poskytovateľa alebo zmeny uložených ID poskytovateľov.

## Kompatibilita a nasadenie

1. Pridajte resolver regionálnych koncových bodov a zachovajte súčasné globálne predvolené hodnoty.
2. Použite živé regionálne zisťovanie DashScope `/models` pre `alibaba`, jeho kompatibilné ID
   `alibaba-cn` a `qwen-cloud`. Ich odpovede najprv prejdú filtrom modelov na generovanie textu,
   pretože všeobecný koncový bod vracia aj obrazové, video, zvukové, embeddingové a ďalšie
   nechatové modely. `qwen-cloud` následne použije udržiavaný zoznam povolených modelov deklarovaný
   v jeho registri poskytovateľa. Alibaba Model Studio a Qwen Cloud si zachovávajú oddelené
   spravované katalógy, hoci momentálne zdieľajú hostiteľov runtime.
3. Zaregistrujte `qwen-cloud-token-plan` so súčasným zoznamom povolených textových modelov plánu Token Plan.
4. Pridajte typovaný výber regiónu do dialógových okien na pridanie alebo úpravu pripojenia.
5. Skryte duplicitnú kartu `alibaba-cn` a zahrňte jej existujúce pripojenia na stránke poskytovateľa
   `alibaba`.
6. Ponechajte možnosť vlastného nastavenia koncových bodov pre pokročilé nasadenia a nasadenia
   špecifické pre pracovný priestor.

Mediálne modely plánu Token Plan zostávajú mimo katalógu chatu, pretože používajú vyhradené koncové
body. `wan2.7-image` a `wan2.7-image-pro` sú zaregistrované v `open-sse/config/imageRegistry.ts`;
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v` a `happyhorse-1.1-r2v` sú zaregistrované v
`open-sse/config/videoRegistry.ts`. Oba registre opätovne používajú identitu pripojenia
`qwen-cloud-token-plan` a jej prihlasovacie údaje špecifické pre región.

Bežný Qwen Cloud má samostatné priebežne platené katalógy obrazových a video modelov pod identitou
`qwen-cloud`. Jeho obrazové modely sú `wan2.7-image-pro`, `wan2.7-image`, `qwen-image-3.0-pro`,
`qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0-2026-03-03` a `z-image-turbo`. Jeho video
modely sú `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`,
`happyhorse-1.0-video-edit`, `wan2.7-t2v`, `wan2.7-i2v`, `wan2.7-r2v-2026-06-12` a
`wan2.7-videoedit`. Tieto modely opätovne používajú iba bežné pripojenie `qwen-cloud` a regionálny
mediálny koncový bod DashScope. Registre plánu Token Plan a priebežne plateného variantu navzájom
nededia ani nezlučujú svoje zoznamy modelov.

Identita `bailian-coding-plan` má takisto vlastné zoznamy povolených mediálnych modelov:
`wan2.7-image`, `wan2.7-image-pro`, `qwen-image-2.0` a `qwen-image-2.0-pro` na generovanie
obrázkov a
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v` a `happyhorse-1.1-r2v` na generovanie videa.
Používa iba pripojenie Bailian Coding Plan a regionálny koncový bod Coding Plan. Jeho registre
obrázkov a videí nededia zo žiadneho poskytovateľa Qwen Cloud ani sa s ním nezlučujú.

Bežná identita `alibaba` má samostatné zoznamy povolených obrazových a video modelov. Jej obrazové
modely sú `qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0`,
`z-image-turbo` a `wan2.6-t2i`. Jej pridané video modely sú `happyhorse-1.1-i2v`,
`happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`,
`wan2.7-i2v-2026-04-25`, `wan2.6-i2v-flash`, `wan2.7-t2v-2026-06-12`,
`wan2.7-r2v-2026-06-12` a `wan2.7-videoedit`. Tieto modely používajú iba pripojenie Alibaba Model
Studio a jeho vybratý regionálny mediálny koncový bod; nepridávajú sa do žiadneho registra Coding
Plan ani Qwen Cloud.

Katalóg chatu Qwen Cloud Token Plan sa riadi zoznamom presne zodpovedajúcich textových modelov
plánu Individual: `qwen3.8-max-preview`, `qwen3.7-max`, `qwen3.7-plus`, `qwen3.6-flash`, `glm-5.2`
a `deepseek-v4-pro`. Položky Wan a HappyHorse patria do samostatných API na generovanie obrázkov
a videa.

Alibaba Token Plan sprístupňuje rovnakých šesť súčasných ID modelov na generovanie textu
prostredníctvom svojho koncového bodu kompatibilného s Anthropic. Jeho možnosť pre Singapur ukladá
existujúci kľúč regiónu `global-sg`; od rodín poskytovateľov, ktoré tento región nazývajú Global,
sa líši iba označenie zobrazované používateľovi.

Bežný katalóg chatu Qwen Cloud je zámerne užší než úplná živá odpoveď textových modelov. Jeho
udržiavaný zoznam povolených modelov sa nachádza v
`open-sse/config/providers/registry/qwen-cloud/index.ts`; živé zisťovanie vracia iba ID, ktoré sa
nachádzajú v odpovedi nadradenej služby aj v tomto zozname registra.

Alibaba Model Studio sa riadi rovnakým pravidlom prieniku so živými údajmi a používa svoj nezávisle
udržiavaný zoznam povolených modelov v `open-sse/config/providers/registry/alibaba/index.ts`.
Kompatibilný poskytovateľ `alibaba-cn` opätovne používa tento katalóg, pričom zisťovanie smeruje na
pekinský koncový bod.
