> **TL;DR**: Nainštalujte → Pripojte bezplatného poskytovateľa → Nasmerujte svoje IDE na OmniRoute. Hotovo.

---

## Krok 1: Nainštalujte OmniRoute

Vyberte si preferovaný spôsob:

### Možnosť A: npm (odporúčané)

```bash
npm install -g omniroute
```

### Možnosť B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` je najvyššia **publikovaná** stabilná verzia SemVer. Nesleduje git `main`. Pre GitOps pripnite `diegosouzapw/omniroute:X.Y.Z`. Pozrite si [Značky obrazov / kanály vydaní](../guides/DOCKER_GUIDE.md#release-channels).

### Možnosť C: Zo zdrojového kódu

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Krok 2: Spustite OmniRoute

```bash
omniroute
```

OmniRoute sa spustí na adrese `http://localhost:20128`. Ovládací panel sa otvorí automaticky.

---

## Krok 3: Pripojte bezplatného poskytovateľa

OmniRoute môžete používať **úplne zadarmo** pripojením bezplatného poskytovateľa.

### Možnosť A: Kiro (bezplatný Claude — bez kreditnej karty)

1. Otvorte ovládací panel na adrese `http://localhost:20128`
2. Prejdite na **Poskytovatelia** → **Pridať poskytovateľa**
3. Vyberte **Kiro AI**
4. Kliknite na **Pripojiť** (nie je potrebný žiadny kľúč API!)
5. Hotovo! Teraz máte bezplatný prístup k modelom Claude.

### Možnosť B: OpenCode Free (bez overenia)

1. Otvorte ovládací panel na adrese `http://localhost:20128`
2. Prejdite na **Poskytovatelia** → **Pridať poskytovateľa**
3. Vyberte **OpenCode Free**
4. Kliknite na **Pripojiť** (nie je potrebný žiadny kľúč API!)
5. Hotovo! Teraz máte bezplatný prístup k viacerým modelom.

### Možnosť C: Pollinations (bez potreby kľúča)

1. Otvorte ovládací panel na adrese `http://localhost:20128`
2. Prejdite na **Poskytovatelia** → **Pridať poskytovateľa**
3. Vyberte **Pollinations**
4. Kliknite na **Pripojiť** (nie je potrebný žiadny kľúč API!)
5. Hotovo! Teraz máte bezplatný prístup k modelom GPT-5, Claude, Gemini a ďalším.

---

## Krok 4: Overte, že všetko funguje

V časti [Kľúče API](http://localhost:20128/dashboard/api-manager) vytvorte nový kľúč. Tento kľúč si uložte, pretože sa už znova nezobrazí. Upozorňujeme, že tento kľúč slúži nástrojom na prístup k OmniRoute, nie na prístup k upstream poskytovateľom.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Mali by ste vidieť zoznam pripojených modelov.

## Krok 5: Nasmerujte svoje IDE alebo CLI na OmniRoute

Vo svojom nástroji IDE alebo CLI nastavte:

```
Základná URL: http://localhost:20128/v1
Kľúč API:     [skopírujte z Ovládací panel → Koncové body]
Model:        auto
```

To je všetko! Vaše IDE teraz používa OmniRoute s automatickým výberom poskytovateľa.

### Príklad IDE: VSCode/Continue.dev

1. Vo VSCode nainštalujte rozšírenie [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Aktualizujte svoj súbor `~/.continue/config.yaml` pridaním nasledujúcich riadkov:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Na paneli chatu Continue.dev vyberte `OmniRoute - Auto` a vaše požiadavky sa budú odosielať do OmniRoute.
4. (Voliteľné) Cvičenie pre čitateľa — nechajte svoje IDE aktualizovať súbor `config.yaml` o všetky ostatné vopred pripravené konfigurácie 😊

### Príklad CLI: Codex CLI

1. Vo svojom operačnom systéme nastavte premennú prostredia natrvalo.
   Pre macOS/Linux (pridajte do svojho súboru `~/.bashrc` alebo `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Pre Windows (Príkazový riadok):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Teraz spustíme Codex, ale nakonfigurovaný pre OmniRoute. Spustite:

```
omniroute launch-codex --model auto
```

Môžete to urobiť manuálne pomocou príkazu `codex` a parametrov príkazového riadka na určenie koncového bodu a kľúča API, ale s vyššie uvedeným príkazom sa OmniRoute postará o všetko za vás.

Rovnaké spustenie jedným príkazom funguje aj pre ďalšie nástroje CLI prostredníctvom všeobecného spúšťača — `omniroute run <target>` podporuje `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` a `gemini` (pozrite si [Integrácie CLI](../guides/CLI-INTEGRATIONS.md)).

3. CLI by teraz malo odosielať požiadavky do OmniRoute.

### Overte, že váš nástroj smeruje požiadavky do OmniRoute

Podrobnosti požiadavky si môžete pozrieť kliknutím na položku [Monitorovanie/Protokoly](http://localhost:20128/dashboard/logs) na ľavom bočnom paneli. Po rozkliknutí uvidíte ďalšie podrobnosti. Okrem toho môžete vidieť, aké informácie odosiela váš obľúbený nástroj. Je to užitočné na vzdelávacie účely a pri ladení.

## Časté otázky

### „Potrebujem kľúč API?“

**Nie!** Bezplatných poskytovateľov (Kiro, OpenCode Free, Pollinations) môžete používať bez akéhokoľvek kľúča API. Stačí ich pripojiť v ovládacom paneli.

### „Čo je `auto`?“

`auto` prikazuje OmniRoute, aby pre každú požiadavku automaticky vybral najlepšieho poskytovateľa. Zohľadňuje rýchlosť, cenu, kvalitu a dostupnosť. Podrobnosti nájdete v [Sprievodcovi Auto-Combo](./AUTO-COMBO-GUIDE.md).

### „Koľko to stojí?“

Samotný OmniRoute je **bezplatný a má otvorený zdrojový kód**. Platíte iba za poskytovateľov, ktorých používate. Mnohí poskytovatelia majú bezplatné úrovne — pozrite si [Sprievodcu bezplatnými úrovňami](./FREE-TIERS-GUIDE.md).

### „Môžem ho používať s Claude Code / Cursor / Copilot?“

**Áno!** OmniRoute funguje s každým nástrojom, ktorý podporuje formát OpenAI. Stačí nastaviť základnú URL na `http://localhost:20128/v1`. Konkrétne pokyny na nastavenie nájdete v [Sprievodcovi nástrojmi CLI](../reference/CLI-TOOLS.md).

### „Čo ak poskytovateľ prestane fungovať?“

OmniRoute automaticky preskočí nefunkčných poskytovateľov a vyskúša ďalšieho. Nemusíte robiť nič. Podrobnosti nájdete v [Sprievodcovi Auto-Combo](./AUTO-COMBO-GUIDE.md).
