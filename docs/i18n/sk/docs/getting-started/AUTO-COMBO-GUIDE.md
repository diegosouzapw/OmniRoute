> **TL;DR**: Nastavte svoj model na `auto` a OmniRoute automaticky vyberie najlepšieho poskytovateľa AI pre každú požiadavku. Nie je potrebná žiadna konfigurácia.

---

## Čo to robí

Namiesto výberu konkrétneho modelu AI (napríklad GPT-4o alebo Claude) môžete nechať OmniRoute, aby **automaticky vybral ten najlepší** pre každú požiadavku. Zohľadňuje:

- **Stav** — Funguje poskytovateľ práve teraz?
- **Rýchlosť** — Ako rýchlo odpovedá?
- **Cena** — Koľko stojí?
- **Kvalita** — Je vhodný pre tento typ úlohy?
- **Kapacita** — Zostáva mu dostupná kvóta?

OmniRoute ohodnotí všetkých vašich pripojených poskytovateľov a vyberie toho najlepšieho. Ak zlyhá, automaticky vyskúša ďalšieho.

---

## Rýchly štart

**Krok 1**: Nastavte svoj model na `auto` vo svojom IDE alebo CLI:

```
model: "auto"
```

**Krok 2**: To je všetko! OmniRoute sa postará o zvyšok.

**Krok 3** (voliteľné): Pre konkrétne úlohy použite variant:

```
model: "auto/coding"    # Najlepšie pre kód
model: "auto/fast"      # Najrýchlejšia odpoveď
model: "auto/cheap"     # Najlacnejšia možnosť
```

---

## Ktorú možnosť „auto“ mám použiť?

| Ak chcete...                 | Použite        | Najlepšie pre                   | Ako to funguje                               |
| ---------------------------- | -------------- | ------------------------------- | -------------------------------------------- |
| **Celkovo najlepšie**        | `auto`         | Všeobecné otázky, chat          | Vyvažuje rýchlosť, cenu a kvalitu            |
| **Najlepší kód**             | `auto/coding`  | Písanie kódu, ladenie           | Vyberá modely vhodné na programovacie úlohy  |
| **Najrýchlejšiu odpoveď**    | `auto/fast`    | Rýchle odpovede, nízka latencia | Uprednostňuje rýchlosť pred všetkým ostatným |
| **Najlacnejšiu možnosť**     | `auto/cheap`   | Šetrenie peňazí                 | Vyberá najlacnejšieho poskytovateľa          |
| **Najinteligentnejší model** | `auto/smart`   | Komplexné úlohy                 | Uprednostňuje kvalitu + skúša nové modely    |
| **Najvyššiu dostupnosť**     | `auto/offline` | Keď sú poskytovatelia vyťažení  | Vyberá poskytovateľov s najväčšou kapacitou  |

### Príklady

```bash
# Všeobecný chat — vyvážený
curl http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'

# Generovanie kódu — kvalita na prvom mieste
curl http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto/coding","messages":[{"role":"user","content":"Write a Python function"}]}'

# Rýchla odpoveď — rýchlosť na prvom mieste
curl http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto/fast","messages":[{"role":"user","content":"What is 2+2?"}]}'
```

## Ako to funguje (jednoduchá verzia)

Keď odošlete požiadavku s `model: "auto"`, OmniRoute:

1. **Skontroluje všetkých vašich pripojených poskytovateľov** — Každého poskytovateľa, ktorého ste pridali (OpenAI, Anthropic, Google atď.)
2. **Ohodnotí každého z nich**, pričom okrem iného zohľadní:
   - Funguje? (stav)
   - Má dostupnú kapacitu? (kvóta)
   - Koľko stojí? (cena)
   - Ako rýchlo odpovedá? (rýchlosť)
   - Je vhodný pre túto úlohu? (kvalita)
3. **Vyberie toho najlepšieho** — Vašu požiadavku dostane poskytovateľ s najvyšším skóre
4. **Automaticky obnoví spracovanie** — Ak zlyhá, OmniRoute automaticky vyskúša ďalšieho

### Systém hodnotenia

Každý poskytovateľ získa skóre od 0 do 1. Čím vyššie skóre, tým vhodnejšia voľba.

| Faktor             | Váha | Čo znamená                                            |
| ------------------ | ---- | ----------------------------------------------------- |
| Stav               | 20%  | Funguje poskytovateľ? (stav ističa)                   |
| Kvóta              | 15%  | Zostáva mu dostupná kapacita?                         |
| Cena               | 15%  | Aký je drahý? (nižšia cena = vyššie skóre)            |
| Rýchlosť           | 12%  | Ako rýchlo odpovedá? (nižšia latencia = vyššie skóre) |
| Vhodnosť pre úlohu | 8%   | Je vhodný pre tento typ úlohy?                        |
| Stabilita          | 5%   | Je konzistentný? (nízka miera chýb)                   |
| Úroveň             | 5%   | Úroveň účtu (Ultra > Pro > Free)                      |
| Ostatné            | 20%  | Afinita kontextu, hustota pripojení atď.              |

### Ako varianty menia hodnotenie

Každý variant používa odlišné váhy:

| Variant        | Uprednostňuje      | Kľúčové váhy                    |
| -------------- | ------------------ | ------------------------------- |
| `auto`         | Vyváženosť         | health=20%, quota=15%, cost=15% |
| `auto/coding`  | Kvalitu            | taskFit=37%, stability=15%      |
| `auto/fast`    | Rýchlosť           | latency=32%, health=28%         |
| `auto/cheap`   | Cenu               | cost=37%                        |
| `auto/smart`   | Kvalitu + skúšanie | taskFit=37%, exploration=10%    |
| `auto/offline` | Kapacitu           | quota=37%, health=28%           |

## Ako rieši zlyhania

OmniRoute má **tri vrstvy ochrany**:

### 1. Automatický fallback

Ak najlepší poskytovateľ zlyhá, OmniRoute automaticky vyskúša ďalšieho. Nemusíte nič robiť.

### 2. Automatická obnova

Ak poskytovateľ opakovane zlyháva:

- **Skóre < 0.2** → Vylúčený na 5 minút
- **Istič okruhu je otvorený** → Automaticky vylúčený
- **Viac ako 50 % poskytovateľov je nedostupných** → Režim incidentu (bez prieskumu)

### 3. Núdzový fallback

Ak zlyhajú všetci poskytovatelia, OmniRoute ako poslednú možnosť presmeruje požiadavku na stabilných bezplatných poskytovateľov (napríklad Kiro alebo Qoder).

---

## Podpora viacerých účtov

Ak máte viacero účtov u toho istého poskytovateľa (napr. dva kľúče OpenAI), OmniRoute považuje každý z nich za **samostatného kandidáta**. To znamená:

- Účet A má zostávajúcu kvótu → použiť ho
- Účet B má obmedzenú frekvenciu požiadaviek → preskočiť ho
- Účet C je lacnejší → uprednostniť ho

Každý účet sa hodnotí nezávisle na základe vlastného stavu, kvóty a rýchlosti.

---

## Prieskum pomocou bandit algoritmu

OmniRoute príležitostne **preskúmava** nových poskytovateľov, aby objavil lepšie možnosti:

- **Predvolené nastavenie**: 5 % požiadaviek smeruje k náhodným poskytovateľom
- **Auto/smart**: 10 % miera prieskumu
- **Vypnuté**, keď je viac ako 50 % poskytovateľov v nevyhovujúcom stave

OmniRoute sa tak môže naučiť, ktorí poskytovatelia najlepšie vyhovujú vašim spôsobom používania.

## Časté otázky

### „Vyberie vždy najdrahší model?“

**Nie.** Cena predvolene tvorí iba 15 % skóre. Lacný, rýchly a spoľahlivý poskytovateľ môže prekonať drahého. Ak chcete cenu uprednostniť ešte viac, použite `auto/cheap`.

### „Čo ak poskytovateľ prestane fungovať?“

OmniRoute ho automaticky preskočí a vyskúša ďalšieho. Ak poskytovateľ opakovane zlyháva, bude dočasne vylúčený (na 5 – 30 minút). Nemusíte nič robiť.

### „Môžem zistiť, ktorý poskytovateľ bol použitý?“

Skontrolujte hlavičky odpovede — OmniRoute v každej odpovedi uvádza použitého poskytovateľa a model.

### „Učí sa z môjho používania?“

Áno! Systém hodnotenia používa historické údaje (latenciu, mieru chýb a mieru úspešnosti), aby časom prijímal lepšie rozhodnutia.

### „Aký je rozdiel medzi `auto` a `auto/smart`?“

- `auto` — Vyvážený režim, 5 % prieskumu
- `auto/smart` — Kvalita na prvom mieste (rovnaké váhy ako pri `auto/coding`), 10 % prieskumu

Použite `auto/smart`, keď chcete najvyššiu kvalitu a neprekáža vám príležitostný prieskum.

### „Môžem vynútiť konkrétneho poskytovateľa?“

Áno! Namiesto `auto` použite kombináciu so stratégiou `priority` a potom odošlite **presný názov** kombinácie v poli `model` (napr. `model: "my-combo"` — nie `auto`). Podrobnosti nájdete v [technickej referencii](../routing/AUTO-COMBO.md).

### „Ako sa to líši od algoritmu round-robin?“

Round-robin cyklicky prechádza poskytovateľov v stanovenom poradí. Auto-combo **ohodnotí každého poskytovateľa** a vyberie najlepšieho. Je inteligentnejší — zohľadňuje stav, rýchlosť, cenu a kvalitu.
