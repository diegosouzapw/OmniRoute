## Kedy si vybrať OmniRoute

- Hostujete ho sami a chcete **maximálne pokrytie poskytovateľov** (329 poskytovateľov, 155 bezplatných položiek katalógu / bez autentifikácie)
- Potrebujete **vstavaný server MCP** (nástroje LLM, pamäť a zručnosti sprístupnené ako nástroje)
- Potrebujete **protokol A2A** pre pracovné postupy medzi agentmi
- Chcete **maskovanie odtlačku** (JA3/JA4), aby ste sa vyhli detekcii systémami CAPTCHA na nadradených službách
- Potrebujete **podnikové funkcie** (ochranné mechanizmy, vyhodnocovanie, auditný záznam) bez účtu za SaaS

## Kedy si vybrať LiteLLM

- Uprednostňujete **Python** a potrebujete úzku integráciu s `litellm.completion()`
- Potrebujete **vyzreté návody na produkčné nasadenie** (k8s, Helm charts)
- Váš tím už prevádzkuje mikroslužby v Pythone

## Kedy si vybrať OpenRouter (SaaS)

- Nechcete hostovať riešenie sami
- Nevadí vám platiť za token s prirážkou SaaS
- Potrebujete **jeden spôsob platby** pre všetkých poskytovateľov

## Kedy si vybrať Portkey

- Potrebujete **komerčnú SLA** so zárukami dostupnosti
- Uprednostňujete **spravovaný ovládací panel** bez prevádzkovej réžie
- Potrebujete hotové **funkcie na zabezpečenie podnikového súladu**
