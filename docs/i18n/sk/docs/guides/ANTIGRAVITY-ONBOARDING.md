## 1. Antigravity verzus Antigravity CLI (agy)

Obaja poskytovatelia používajú **rovnaký backend Google** — identického klienta OAuth, obnovovanie tokenov, koncové body a účty Google. Rozdiel spočíva v tom, ktoré modely sa vám zobrazujú.

> Oficiálne porovnanie od spoločnosti Google nájdete v [oznámení Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli).

| Aspekt                         | `antigravity` (IDE)                                         | `agy` (CLI)                                                      |
| ------------------------------ | ----------------------------------------------------------- | ---------------------------------------------------------------- |
| **Produkt Google**             | Antigravity 2.0 / Antigravity IDE                           | Antigravity CLI                                                  |
| **Backend**                    | Rovnaké Google Cloud Code API                               | Rovnaké Google Cloud Code API                                    |
| **OAuth / Token**              | Rovnaký klient, rovnaké obnovovanie                         | Rovnaký klient, rovnaké obnovovanie                              |
| **Katalóg modelov**            | Statický kurátorovaný zoznam (pevne zakódovaný v OmniRoute) | Dynamicky zisťovaný zo služby Google cez `:fetchAvailableModels` |
| **Modely Claude**              | Sonnet 4.6, Opus 4.6 (po 4 varianty)                        | Sonnet 4.6, Opus 4.6 (po 4 varianty)                             |
| **Názvy Gemini**               | Jednoduché označenia (Low/Medium/High)                      | Identifikátory upstreamu (extra-low/low/agent)                   |
| **Ďalšie modely**              | `gpt-oss-120b-medium`                                       | Môže zahŕňať ďalšie modely od spoločnosti Google                 |
| **Predvolený prípad použitia** | Integrácia s IDE (VS Code, JetBrains)                       | Prístup cez CLI / API                                            |
| **Kvóta**                      | Zdieľaná s agy (rovnaký účet Google)                        | Zdieľaná s antigravity (rovnaký účet Google)                     |

**Dostupné modely (overené experimentálne, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (rôzne úrovne uvažovania)
- Claude: Sonnet 4.6, Opus 4.6 (každý vo variantoch default/low/medium/high)
- Ostatné: GPT-OSS 120B Medium
- **Claude Sonnet 5 NIE JE dostupný** — podporované sú iba varianty 4.6

**Prečo sa katalógy modelov líšia**: CLI od spoločnosti Google je „optimalizované na rýchlosť a nízku réžiu“ a „spoločne optimalizované s modelmi Gemini“ (podľa oficiálneho blogu spoločnosti Google). Webový produkt/produkt pre IDE je „optimalizovaný na komplexnosť“. CLI používa `:fetchAvailableModels` na dynamické zisťovanie modelov, zatiaľ čo IDE používa statický kurátorovaný zoznam.

**V praxi**: Pre modely Gemini používajte predponu `agy/` (napr. `agy/gemini-3.7-flash-high`). Pre statický kurátorovaný zoznam používajte `antigravity/`. Obe možnosti pristupujú k rovnakému backendu Google, ale používajú odlišné názvy modelov. Kvóta je zdieľaná — používanie ktoréhokoľvek poskytovateľa sa započítava do limitov rovnakého účtu Google.

## 2. Google One AI Pro: Systém kvót

> Oficiálne podrobnosti o kvótach nájdete v dokumentácii [Antigravity Docs: Plans](https://antigravity.google/docs/plans) a najnovšie informácie o cenách v článku [Changes to Antigravity Plans](https://antigravity.google/blog/changes-to-antigravity-plans).

Google Antigravity používa **dvojúrovňovú kvótu** založenú na „vykonanej práci“ (výpočtovej náročnosti), nie na počte správ.

### Dve úrovne

| Úroveň                | Čo predstavuje                    | Cyklus obnovenia                                                                                      |
| --------------------- | --------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **5-hodinový šprint** | Okamžitá zásoba „vykonanej práce“ | Obnoví sa 5 hodín po prvej požiadavke v rámci relácie                                                 |
| **7-dňový základ**    | Pevný týždenný limit              | Po dosiahnutí má prednosť pred 5-hodinovým obnovením; zablokuje prístup do ďalšieho 7-dňového obdobia |

**Ako sa počíta „vykonaná práca“**: Úlohy náročné na prácu agenta (napr. „Refaktoruj celý tento repozitár“) vyčerpávajú kvótu oveľa rýchlejšie než jednoduché úlohy (napr. „Oprav túto funkciu“). Neexistuje žiadny panel zobrazujúci spotrebu v reálnom čase.

### Úrovne programov

| Program      | Cena       | Kvóta                                        | Týždenný limit                                           |
| ------------ | ---------- | -------------------------------------------- | -------------------------------------------------------- |
| Free         | $0         | Významná kvóta obnovovaná týždenne           | Áno                                                      |
| AI Pro       | $19.99/mo  | Vysoká kvóta, priebežné 5-hodinové obnovenie | Áno (po dosiahnutí má prednosť pred 5-hodinovým limitom) |
| AI Ultra 5x  | $99.99/mo  | 5-násobok kvóty Pro                          | Bez týždenného limitu                                    |
| AI Ultra 20x | $199.99/mo | 20-násobok kvóty Pro                         | Bez týždenného limitu                                    |

### Modely Gemini a ostatné modely

- **Modely Gemini** (Flash + Pro): Zdieľajú jeden rýchlostný limit, ktorý sa čerpá podľa cien API. Ak je Flash 8-krát lacnejší než Pro, získate 8-krát viac tokenov Flash.
- **Modely iné než Gemini** (Claude, GPT-OSS): Majú **samostatné** rýchlostné limity. Môžu zostať dostupné aj vtedy, keď je prístup k Gemini zablokovaný.

### Kredity AI (prekročenie kvóty)

> Informácie o fungovaní kreditov nájdete na stránke [Google One AI credits](https://support.google.com/googleone/answer/14534406).

Keď sa základná kvóta vyčerpá:

- **Nikdy**: Čaká sa na obnovenie kvóty; zobrazí sa „Dosiahnutá základná kvóta modelu“
- **Vždy**: Automaticky sa použijú kredity AI; po obnovení základnej kvóty sa systém prepne späť na ňu

Kredity sa kupujú samostatne a odpočítavajú sa podľa štandardných cien API.

### Kľúčové podrobnosti

- Kvóta je **zdieľaná na úrovni účtu** — ten istý účet Google v Antigravity IDE, CLI a OmniRoute zdieľa jednu zásobu kvóty
- Každý účet Google má vlastnú nezávislú kvótu — viacero účtov = viacero zásob kvót
- Používatelia AI Pro hlásili **7-dňové zablokovanie** namiesto 5-hodinového obnovenia po dosiahnutí týždenného základného limitu (Google potvrdil, že pri vysokom dopyte ide o zámerné správanie)

**Keď je kvóta vášho účtu vyčerpaná**: OmniRoute automaticky zopakuje požiadavku s ďalším dostupným účtom v kombinovanej trase. Nie je potrebný žiadny manuálny zásah.

## 3. Ako získať projectId

Každé pripojenie antigravity/agy potrebuje `projectId` služby Google Cloud Code. Bez neho koncový bod `/v1internal:models` vráti chybu 404.

### Metóda A: Automaticky (odporúčané)

OmniRoute to spracuje automaticky. Keď pridáte nový účet Google prostredníctvom OAuth na ovládacom paneli:

1. OmniRoute obnoví token
2. Zavolá `loadCodeAssist`, aby zistil projectId
3. Ak projekt neexistuje, zavolá `onboardUser`, aby ho vytvoril
4. Zopakuje volanie `loadCodeAssist`, aby získal novovytvorený projectId
5. Uloží ho do databázy

**Funguje to pri väčšine účtov** — nie sú potrebné žiadne manuálne kroky.

### Metóda B: Manuálne prostredníctvom agy CLI

Ak automatické zisťovanie zlyhá (informácie o prípadoch, keď k tomu dochádza, nájdete v časti 5):

```bash
# Nainštalujte agy CLI (ak ešte nie je nainštalované)
npm install -g @anthropic-ai/agy

# Prihláste sa pomocou svojho účtu Google
agy login

# Vyberte účet, ktorý je potrebné zaregistrovať
# Tým sa spustí registrácia v Cloud Code a priradí sa projectId
```

Po úspešnom dokončení `agy login` obnovte token na ovládacom paneli OmniRoute. projectId sa zistí automaticky.

### Ako vykonať overenie

Skontrolujte databázu:

```bash
# V kontajneri OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Alebo skontrolujte protokoly:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. URI presmerovania OAuth

### Problém

Google OAuth vyžaduje platný URI presmerovania. OmniRoute predvolene používa `http://127.0.0.1:20128/callback` (loopback). Funguje to pri lokálnych zostaveniach, ale **zlyháva pri vzdialených nasadeniach** (napr. pri serveri sprístupnenom cez IP adresu v sieti LAN).

Google odmieta URI presmerovania, ktoré:

- Používajú IP adresy (musí ísť o doménu končiacu na `.com`, `.org` atď.)
- Nezodpovedajú registrovaným URI presmerovania v konfigurácii klienta OAuth

### Riešenie

**Možnosť A: Použite vstavaný postup OAuth (predvolené)**

- Funguje, keď k OmniRoute pristupujete cez `localhost` alebo `127.0.0.1`
- Nie je potrebná žiadna konfigurácia

**Možnosť B: Vlastné prihlasovacie údaje OAuth**

- Vo svojom prostredí nastavte `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web`
- Zadajte vlastné prihlasovacie údaje Google OAuth:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- V Google Cloud Console zaregistrujte `https://your-domain.com/callback` ako autorizovaný URI presmerovania

**Možnosť C: Na prvé prihlásenie použite agy CLI**

- Spustite `agy login` na zariadení, ktoré bude pristupovať k OmniRoute
- Postup OAuth sa dokončí lokálne a tokeny sa uložia
- Importujte pripojenie do OmniRoute prostredníctvom ovládacieho panela

### Obmedzenia

- Vlastné prihlasovacie údaje OAuth vyžadujú názov domény (Google neprijíma IP adresy ako URI presmerovania)
- Ak nemáte doménu, použite namiesto toho možnosť A alebo C

## 5. Riešenie problémov: Keď automatické nastavenie zlyhá

OmniRoute pri väčšine účtov automaticky zabezpečuje zisťovanie projectId a úvodné nastavenie. Keď tento proces zlyhá, hlavnou príčinou je zvyčajne jeden z nasledujúcich problémov:

### Región účtu je blokovaný

**Príznak**: `agy login` vráti hlásenie „Kontrola oprávnenosti zlyhala: Váš aktuálny účet nemá nárok na Antigravity, pretože táto služba momentálne nie je vo vašej lokalite dostupná.“

**Hlavná príčina**: Účty Google majú v backende pole „Priradenie krajiny“, ktoré sa nastavuje pri registrácii. agy CLI a Cloud Code API toto pole kontrolujú striktne — na rozdiel od webovej verzie Gemini, ktorá kontroluje iba vašu aktuálnu IP adresu.

> Ak chcete skontrolovať alebo zmeniť región priradený k vášmu účtu, navštívte [formulár Google na priradenie krajiny](https://policies.google.com/country-association-form).

**Prečo webová verzia Gemini funguje, ale agy nie**:

- Webová verzia Gemini / Google One: kontroluje iba aktuálnu IP adresu (proxy postačuje)
- agy CLI / Cloud Code API: načítava pole Priradenie krajiny z backendu (proxy nepomôže)

**Oprava**:

1. Pri použití IP adresy z USA navštívte [formulár Google na priradenie krajiny](https://policies.google.com/country-association-form)
2. Odošlite žiadosť o zmenu regiónu (vyberte možnosť „Žijem v inej krajine“)
3. Počkajte 1 – 24 hodín, kým Google žiadosť spracuje a odošle e-mailové oznámenie
4. Potom by mal príkaz `agy login` uspieť

### Účet nemá projekt Cloud Code

**Príznak**: V protokoloch sa zobrazujú hlásenia `loadCodeAssist returned no project id` a `onboardUser failed (400)`.

**Hlavná príčina**: Účet nebol nikdy zaregistrovaný v službe Google Cloud Code a automatické úvodné nastavenie zlyhalo.

**Oprava**: Manuálne spustite `agy login`, aby sa aktivovala registrácia v službe Cloud Code, a potom obnovte token v ovládacom paneli OmniRoute.

### Platnosť tokenu vypršala alebo bol odvolaný

**Príznak**: Chyby 401 v protokoloch alebo hlásenia „Platnosť tokenu vypršala“.

**Oprava**: Obnovte token v časti Ovládací panel → Poskytovatelia → agy → Kliknite na ikonu obnovenia. Ak bol odvolaný samotný obnovovací token, budete sa musieť znova overiť prostredníctvom OAuth.
