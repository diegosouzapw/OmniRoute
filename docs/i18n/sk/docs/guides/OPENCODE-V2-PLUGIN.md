`@omniroute/opencode-plugin-v2` sprístupňuje celý váš katalóg OmniRoute — modely, kombinácie a
automatické kombinácie — vo výbere modelov OpenCode v2 spolu so zobrazovanými názvami, cenami a
limitmi bezplatnej úrovne.

Ide o samostatný balík od `@omniroute/opencode-plugin`, pretože OpenCode v1 a v2 načítavajú
pluginy prostredníctvom odlišných rozhraní. Vyberte si ten, ktorý zodpovedá hlavnej verzii vášho OpenCode;
nič medzi nimi nie je zdieľané, takže aktualizácia jedného nikdy nevynúti aktualizáciu druhého.

## Požiadavky

- OpenCode v2.
- Dostupná brána OmniRoute (predvolene `http://localhost:20128`).
- Node.js 22 alebo 24.

## Inštalácia

Pridajte plugin do súboru `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modely sa potom zobrazia ako `omniroute/<provider>/<model>`; `providerId` určuje tento prefix a
identifikátor integrácie, pod ktorým OpenCode ukladá prihlasovací údaj.

## Prihlasovacie údaje

Plugin hľadá kľúč brány na troch miestach v tomto poradí:

1. **Prihlasovací údaj, ktorý ste pripojili v OpenCode.** Plugin zaregistruje integráciu, takže
   vlastný autorizačný proces OpenCode môže kľúč uložiť. Nič sa nezapíše do `opencode.json` — túto možnosť uprednostnite.
2. `apiKey` v možnostiach pluginu na prepísanie nastavenia pre konkrétny projekt. Kľúč sa tým uloží do súboru,
   ktorý môžete odosielať do repozitára.
3. `OMNIROUTE_API_KEY` v prostredí.

Ak nie je k dispozícii žiadna z týchto troch možností, katalóg zostane prázdny a plugin to oznámi raz pri spustení
namiesto toho, aby vám ponechal prázdny výber bez upozornenia.

### Token na správu je iný kľúč

Kombinácie, stav poskytovateľov a obohatenie (zobrazované názvy, ceny a limity bezplatnej úrovne) pochádzajú z
koncových bodov brány `/api/*`, ktoré väčšina nasadení chráni **správcovským** tokenom,
nie inferenčným kľúčom:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<správcovský token na čítanie>"
}
```

Ak `managementReadToken` nie je nastavený, použije sa `apiKey`. Keď brána toto náhradné riešenie odmietne,
katalóg sa aj tak zverejní, ale s nespracovanými identifikátormi modelov namiesto zobrazovaných názvov, bez
odstraňovania duplicít kanonických aliasov, cien a kombinácií. Keď k tomu dôjde, plugin upozorní raz pre každý koncový bod,
pričom uvedie koncový bod a chýbajúce údaje — zhoršená podoba výberu tak nikdy nebude záhadou.

## Možnosti

| Kľúč                             | Predvolená hodnota                                       | Poznámky                                                                                                                    |
| -------------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                            | ID poskytovateľa, ID integrácie a prefix, pod ktorým sa zobrazujú modely                                                    |
| `baseURL`                        | povinné                                                  | Koreňová adresa brány, iba `http(s)`; prípona `/v1` sa pridá tam, kde je to potrebné                                        |
| `apiKey`                         | pripojené prihlasovacie údaje, potom `OMNIROUTE_API_KEY` | Kľúč pre chat pre `/v1/*`                                                                                                   |
| `managementReadToken`            | použije `apiKey`, ak nie je nastavené                    | Kľúč pre `/api/*` — zvyčajne **nie je** rovnaký                                                                             |
| `displayName`                    | `"OmniRoute"`                                            | Názov poskytovateľa vo výbere                                                                                               |
| `timeoutMs`                      | `10000`                                                  | Časový limit načítania pre jednotlivé koncové body (automatické kombinácie používajú 5 s)                                   |
| `modelCacheTtlMs`                | `300000`                                                 | TTL vyrovnávacej pamäte katalógu; snímka na disku urýchľuje studené spustenia                                               |
| `timeouts`                       | použije `timeoutMs`, ak nie je nastavené                 | Limity pre jednotlivé koncové body v ms: `models`, `combos`, `autoCombos`, `enrichment`                                     |
| `enrichment`                     | `true`                                                   | Načítať názvy, ceny a limity bezplatnej úrovne                                                                              |
| `providerTag`                    | `true`                                                   | Pred zobrazovaný názov pridať poskytovateľa, ku ktorému smeruje                                                             |
| `usableOnly`                     | `false`                                                  | Ponechať iba poskytovateľov, ktorých brána uvádza ako nakonfigurovaných                                                     |
| `showcasePerOwner`               | `10`                                                     | Počet položiek na poskytovateľa zachovaných v predvolenom zobrazení                                                         |
| `freshPerOwner`                  | `10`                                                     | Počet nových položiek na poskytovateľa zachovaných v predvolenom zobrazení                                                  |
| `freshWindowDays`                | `90`                                                     | Časové okno aktuálnosti v dňoch pre vetvu nových položiek                                                                   |
| `usageMemory`                    | `true`                                                   | Obnoviť staticky odstránené položky uvedené v analytike používania za 30 dní (vyžaduje token na správu)                     |
| `visibleModels` / `hiddenModels` | `[]`                                                     | Zoznamy povolených položiek s presnou zhodou alebo zhodou prípony; zákaz má prednosť                                        |
| `geminiSanitization`             | `true`                                                   | Odstrániť kľúčové slová schémy JSON, ktoré Gemini odmieta, zo schém nástrojov (nástroje s `$ref` sa preposielajú bez zmien) |
| `apiFormat.allowAnthropic`       | `false`                                                  | Smerovať povolené ID cez blok API Anthropic                                                                                 |
| `apiFormat.anthropicModels`      | `[]`                                                     | Úplné ID modelov smerované do Anthropic                                                                                     |
| `logLevel` / `startupDebug`      | `warn` / `false`                                         | Podrobnosť zaznamenávania do denníka                                                                                        |

Pamäť používania je predvolene zapnutá. Bez tokenu na správu zostane neaktívna
(pri spustení sa zaznamená upozornenie) a nič sa neobnoví.

## Ako katalóg zostáva aktuálny

Katalóg sa načítava len v prípade potreby a ukladá sa do vyrovnávacej pamäte na dobu `modelCacheTtlMs`, pričom snímka na disku uchováva
posledný známy katalóg dostupný aj vtedy, keď je brána nedostupná — výpadok vás nestojí nič okrem
aktuálnosti. Modely a kombinácie sa zverejnia ihneď po ich získaní; automatické kombinácie, zoznam
poskytovateľov a vrstva obohatenia sa začlenia po doručení, takže jeden pomalý koncový bod nemôže
zablokovať celý výber.

Názvy obsahujú informácie, ktoré pozná brána: nadradeného poskytovateľa, ku ktorému je model smerovaný, značku `[Free]`
a rozpočet, ktorý s ňou získate — takže dve pripojenia ponúkajúce rovnaký model zostanú
rozlíšiteľné. Prefix vypnete pomocou `"providerTag": false`.

Príkaz na manuálne obnovenie neexistuje: príkazy OpenCode v2 sú šablóny výziev, nie spätné volania,
takže ho doplnok nemôže sprístupniť. Obnovovanie sa riadi hodnotou TTL; hostiteľ je požiadaný o opätovné načítanie iba vtedy,
keď sa katalóg alebo vrstva obohatenia skutočne zmenili, nikdy nie pri každom obnovení.

## Volanie nástrojov v Gemini

Gemini odmietne celú požiadavku, ktorej deklarácie nástrojov obsahujú `$schema` alebo
`additionalProperties`, a odpovie `400 INVALID_ARGUMENT`. Doplnok odstráni tieto kľúčové slová zo
schém nástrojov určených pre model Gemini tohto poskytovateľa a všetky ostatné požiadavky ponechá nezmenené.
Nástroj obsahujúci `$ref` sa odošle bez zmeny namiesto odstránenia kľúčových slov, pretože odstránenie
odkazu by rozšírilo schému tak, aby „prijímala čokoľvek“.
Ak to chcete vypnúť, nastavte `"geminiSanitization": false`.

## Riešenie problémov

| Príznak                                             | Príčina                                                                                                    |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Výber nezobrazuje žiadny model OmniRoute            | Nenašiel sa žiadny kľúč (skontrolujte upozornenie pri spustení) alebo je brána nedostupná                  |
| Nespracované ID modelov, žiadne kombinácie ani ceny | Koncové body správy odmietli token — nastavte `managementReadToken`                                        |
| Relácia pripnutá k `opencode-<id>/…`                | Doplnok v1 zverejnil `opencode-<id>`; v2 zverejňuje samotné `<id>`, preto model znova vyberte pod `<id>/…` |
