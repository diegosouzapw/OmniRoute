**OmniCopilot** pridáva každý model poskytovaný službou OmniRoute do _natívneho_ výberu modelov
v GitHub Copilot Chat. Žiadny druhý bočný panel, žiadne samostatné používateľské rozhranie chatu — režim agenta Copilotu, volanie nástrojov,
servery MCP aj vlastné pokyny naďalej fungujú, iba sa spúšťajú na modeli, ktorý si vyberiete.

|                             |                                                                                                                                                 |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Inštalácia (VS Code)**    | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Inštalácia (forky)**      | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Zdrojový kód / problémy** | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Požiadavky**              | VS Code 1.104+                                                                                                                                  |

> **Predplatné Copilot nie je potrebné.** Od VS Code 1.122 funguje poskytovateľ jazykového modelu
> bez prihlásenia do GitHubu a bez akéhokoľvek plánu Copilot. Vnorené dokončovanie kódu a
> funkcie založené na embeddingoch zostávajú mimo API poskytovateľa a naďalej vyžadujú Copilot.

## Nastavenie

1. **Spustite OmniRoute** — `npm install -g omniroute && omniroute` (ovládací panel na `http://localhost:20128`).
2. **Nainštalujte rozšírenie** — vo zobrazení Rozšírenia vyhľadajte „OmniRoute“.
3. **Vyberte model** — Copilot Chat → výber modelu → **Spravovať modely…** → **OmniRoute**, potom začiarknite
   požadované modely.

Keď OmniRoute beží na predvolenom porte, nie je potrebné nič konfigurovať. Pre vzdialenú inštanciu otvorte
**ikonu OmniRoute na paneli aktivít** (alebo spustite `OmniRoute: Manage Connection`) a nastavte:

- **URL servera** — koreňová adresa servera, napr. `http://192.168.0.15:20128`. Príponu `/v1`
  pridáva rozšírenie; nezahŕňajte ju.
- **Kľúč API** — iba ak má server nastavené `REQUIRE_API_KEY`. Ukladá sa do kľúčenky operačného systému prostredníctvom
  VS Code SecretStorage, nikdy nie do `settings.json`.

## Čo sa zobrazí vo výbere

Rozšírenie nezobrazuje nespracovaný obsah odpovede `GET /v1/models` — upravuje ho, takže počet, ktorý
vidíte, je nižší než veľkosť katalógu, a to z dvoch zámerných dôvodov.

### Vyžaduje jedno id pre každý model

Predvolená hodnota `MODELS_CATALOG_PREFIX_MODE` je **`dual`**, čo znamená, že každý model je uvedený dvakrát — raz
s krátkym prefixom aliasu a raz s kanonickým prefixom poskytovateľa — aby staršie konfigurácie klientov
naďalej dokázali rozpoznať obe podoby:

```
cc/claude-sonnet-4-6        ← prefix aliasu
claude/claude-sonnet-4-6    ← kanonický prefix, rovnaký model
```

Rozšírenie odosiela požiadavku **`GET /v1/models?prefix=alias`**, takže pre každý model dostane jedno id bez
zmeny celoserverového nastavenia pre ostatných klientov. Na referenčnej inštancii sa tým počet znížil
z **2345 položiek na 1396 — 949 duplicít, nula stratených modelov.**

Ak to radšej chcete opraviť na úrovni celého servera pre _každého_ klienta, nastavte príznak funkcie
`MODELS_CATALOG_PREFIX_MODE` na hodnotu `alias` v ovládacom paneli. Informácie o parametri
dotazu a tabuľku jednotlivých režimov nájdete v časti
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix).

### Skrýva modely, ktoré nedokážu četovať

Katalóg obsahuje aj modely na generovanie obrázkov, videa a zvuku, zmenu poradia, embeddingy a moderovanie. Tie by
boli pri požiadavke na čet aj tak odmietnuté:

```
HTTP 400 — Model '<id>' je model na generovanie obrázkov a nemožno ho použiť na
/v1/chat/completions. Namiesto toho použite POST /v1/images/generations.
```

preto sú ešte pred zobrazením vo výbere odfiltrované podľa poľa `type`. **Modely Responses-API
zostávajú zachované** — každá položka Codex / GPT-5.x uvádza `supported_endpoints: ["responses"]`
a OmniRoute ich prekladá pre `/v1/chat/completions`, takže sú plne použiteľné.

### Poskytovatelia, ktorých ste nikdy nenakonfigurovali

Katalóg obsahuje modely od poskytovateľov s **aktívnym pripojením** _a tiež_ všetkých poskytovateľov **noAuth**
— teda poskytovateľov bez potreby kľúča, ktorí tvoria veľkú časť bezplatnej úrovne. Je to zámerné. Ak ich chcete skryť,
pridajte ich do `blockedProviders` v nastaveniach ovládacieho panela; v rozšírení sa nič nemení.

## Ovládací panel na karte VS Code

`omnicopilot.dashboardOpen: "editor"` vykreslí ovládací panel OmniRoute na karte editora prostredníctvom
Simple Browser namiesto externého prehliadača. Vkladanie je **na serveri voliteľné** prostredníctvom
`DASHBOARD_ALLOW_EMBED=vscode`, čo zabezpečí poskytovanie stránok HTML s
`frame-ancestors 'self' vscode-webview:` namiesto predvoleného `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Rozhrania API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) si v oboch
prípadoch zachovávajú prísne hlavičky.

> ⚠️ **Ide o príznak nastavený pri zostavení, nie počas behu.** Next.js skompiluje `headers()` do manifestu
> trás, takže `next.config.mjs` načíta premennú počas zostavovania balíka
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Jej exportovanie pred spustením už zostaveného servera nič nezmení — hlavičky sú pevne zakomponované.

```bash
# premenná musí byť prítomná v príkaze BUILD
DASHBOARD_ALLOW_EMBED=vscode npm run build        # alebo npm run build:release
npm start
```

| Spôsob inštalácie          | Je možné povoliť vkladanie?                                                                                                                    |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Zo zdrojového kódu         | ✅ nastavte premennú v príkaze zostavenia, ako je uvedené vyššie                                                                               |
| `npm install -g omniroute` | ❌ publikovaný balík obsahuje vopred zostavený balík — namiesto toho ho zostavte zo zdrojového kódu                                            |
| Obraz Docker               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — vopred zostavený obraz na Docker Hub nemá povolené vkladanie |

Bez zostavenia s povoleným vkladaním stránka odmietne zobrazenie v rámci, rozšírenie to zistí z
hlavičiek odpovede a použije externý prehliadač — nič sa nepokazí a jednorazovo vás o tom informuje.
Pozrite si [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) a problém
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Konfigurácia ďalších nástrojov priamo vo VS Code

**`OmniRoute: Configure Coding CLI`** používa rozhranie CLI `omniroute` na zapisovanie profilov pripravených
na použitie pre Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo a Roo — rovnakých konfigurácií, aké sú opísané v
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). Kľúč API sa rozhraniu CLI odovzdáva prostredníctvom
premennej prostredia `OMNIROUTE_API_KEY`, nikdy nie cez príkazový riadok.

## Riešenie problémov

| Príznak                                                        | Príčina / riešenie                                                                                                                                                                                                                                                                           |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vo výbere nie sú žiadne modely OmniRoute                       | Server je nedostupný. Bodka v stavovom riadku sa zmení na sivú; spustite `OmniRoute: Check Connection`. Zisťovanie je zámerne tiché a namiesto zobrazovania výzvy nepridá žiadne modely.                                                                                                     |
| Každý model sa zobrazuje dvakrát                               | Používate OmniCopilot starší než 1.0.1 — aktualizujte ho. Rozšírenie teraz požaduje `?prefix=alias`.                                                                                                                                                                                         |
| Model obrázkov/zvuku sa predtým zobrazoval a zmizol            | Od verzie 1.0.1 je to zámerné — nikdy nedokázal odpovedať na chatovú požiadavku.                                                                                                                                                                                                             |
| Na paneli aktivity chýba panel                                 | VS Code presúva ďalšie kontajnery zobrazení do ponuky **„…“** v spodnej časti panela aktivity a kontajner skrytý kliknutím pravým tlačidlom zostane skrytý. Kliknite pravým tlačidlom na panel aktivity → začiarknite **OmniRoute** alebo ho otvorte pomocou `OmniRoute: Manage Connection`. |
| Ovládací panel sa napriek režimu `editor` otvorí v prehliadači | Server nebol **zostavený** s `DASHBOARD_ALLOW_EMBED=vscode` (pozrite vyššie) — jeho nastavenie pri spustení vopred zostavenej inštalácie nič nezmení. Použitie náhradného riešenia je zámerné.                                                                                               |
| Zoznam modelov je po zmene poskytovateľov neaktuálny           | Použite `OmniRoute: Refresh Models` alebo odkaz ↻ na paneli.                                                                                                                                                                                                                                 |
