OmniRoute zoskupuje 352 podporovaných poskytovateľov do 3 ekonomických úrovní. Každá
požiadavka cez ne prechádza v danom poradí, kým ju niektorý úspešne nespracuje —
získate najlacnejšiu dostupnú odpoveď bez toho, aby ste museli písať kód pre záložné riešenia.

## Úroveň 1 — Predplatné

**Poskytovatelia, za ktorých už platíte.** OmniRoute využije každú časť kvóty skôr,
než vyprší jej platnosť.

| Poskytovateľ                      | Prečo úroveň 1                               |
| --------------------------------- | -------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — paušál, často nevyužitý |
| OpenAI Codex (predplatné ChatGPT) | Plus/Team zahŕňa kvótu Codex                 |
| GitHub Copilot                    | Za používateľa — kvóta sa obnovuje mesačne   |
| Cursor IDE                        | Kvóta programu Pro                           |
| Antigravity / Devin Desktop       | Zabudované kvóty                             |

**Stratégia**: každú požiadavku, ktorá zodpovedá silným stránkam modelu, smerujte
najprv sem. Sledovanie kvót monitoruje blížiace sa obnovenia a kombinovaná stratégia
`reset-aware` podľa toho určuje priority. Ak chcete najprv smerovať na úroveň 1 a
prejsť na platené úrovne až po vyčerpaní kvóty, použite identifikátor `auto/thrifty` —
alebo `auto/subscription`, ak chcete zostať pri kapacite zahrnutej v predplatnom a
v opačnom prípade požiadavku ukončiť neúspechom. Pozrite si
[Smerovanie s uprednostnením predplatného](../routing/SUBSCRIPTION_LADDER.md).

## Úroveň 2 — Lacné

**Poskytovatelia s platbou za token pod $1/1M tokenov.** Vyhradené na prácu
s veľkým objemom alebo na použitie po dosiahnutí limitov kvót úrovne 1.

| Poskytovateľ                           | Cena (vstup/výstup) | Silné stránky                         |
| -------------------------------------- | ------------------- | ------------------------------------- |
| DeepSeek V4 Pro                        | $0.27 / $1.10 za 1M | Kód, logické uvažovanie               |
| GLM-4.5                                | $0.60 / $2.20 za 1M | Dlhý kontext                          |
| MiniMax M1                             | $0.20 / $1.10 za 1M | Rýchlosť                              |
| Qwen Coder                             | $0.30 / $1.20 za 1M | Kód                                   |
| OpenRouter (optimalizovaný podľa ceny) | rôzna               | Viac ako 100 modelov, dynamický výber |

**Stratégia**: kombinácia `cost-optimized` vyberie model s najnižšou cenou za token,
ktorý spĺňa filter schopností potrebných pre úlohu (spracovanie obrazu, režim JSON,
nástroje, maximálna dĺžka kontextu).

## Úroveň 3 — Bezplatné

**Poskytovatelia s nulovými nákladmi** — bezplatné programy, kreditné programy,
denné kvóty OAuth.

| Poskytovateľ     | Bezplatná kvóta/kredity                             |
| ---------------- | --------------------------------------------------- |
| Kiro AI          | Bezplatná úroveň Claude (štedré primerané využitie) |
| OpenCode Free    | Bez overenia, štedré limity požiadaviek             |
| Qoder            | Bezplatné OAuth                                     |
| Google Vertex AI | Kredity $300 pre nové účty                          |
| Amazon Q         | Bezplatná úroveň pre používateľov AWS               |
| Pollinations     | Otvorené verejné API                                |
| Cloudflare AI    | Bezplatná úroveň Workers AI                         |

**Stratégia**: kombinácia `auto` s rozpočtovým limitom smeruje požiadavky sem,
keď úrovne 1 a 2 zlyhajú alebo keď je nastavené `useFreeOnly=true`. Bezplatní
poskytovatelia majú často prísnejšie limity požiadaviek — istič ich po uplynutí
času čakania znova sprístupní.

## Konfigurácia úrovní

Ovládací panel → **Úrovne** → priraďte svojich poskytovateľov. Predvolené nastavenia
(z `tierDefaults.json`) sú rozumné; upravte ich, ak máte konkrétne predplatné, ktoré
chcete uprednostniť, alebo poskytovateľov, ktorých chcete vylúčiť.

16-faktorové hodnotenie Auto-Combo zohľadňuje aj úroveň. Pozrite si
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetria

Ovládací panel → **Využitie** zobrazuje počet tokenov spotrebovaných denne podľa
jednotlivých úrovní. Použite ho na:

- Potvrdenie, že je úroveň 1 využitá naplno (inak plytváte hodnotou predplatného)
- Zistenie, ktoré modely úrovne 2 sa vyberajú najčastejšie (zúžte ich počet na 1 až 2)
- Overenie, že úroveň 3 šetrí peniaze pri testovacích a prieskumných úlohách

## Bežné vzory

### Výlučne bezplatná pracovná záťaž

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Výrazne uprednostňuje úroveň 3; úroveň 2 použije iba vtedy, keď úroveň 3 nie je dostupná.

### Prednostné použitie predplatného s lacným záložným riešením

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Explicitný usporiadaný zoznam zodpovedajúci poradiu úroveň 1 → úroveň 2 → úroveň 3.
