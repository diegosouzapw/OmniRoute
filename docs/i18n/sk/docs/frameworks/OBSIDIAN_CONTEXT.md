> **Zdroj pravdy:** `src/lib/obsidian/api.ts` (REST + synchronizačný klient),
> `src/lib/db/obsidian.ts` (uchovávanie tokenu / základnej URL / WebDAV),
> `src/lib/obsidianSync.ts` (WebDAV synchronizácia trezora), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 nástrojov MCP), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API nastavení). Registrácia nástrojov
> a prepojenie rozsahov sa nachádzajú v `open-sse/mcp-server/server.ts`.

## Čo to je

OmniRoute sa pripája k trezoru **Obsidian** ako k **zdroju kontextu** — lokálnej znalostnej
báze vo formáte Markdown, ktorú agenti čítajú a zapisujú prostredníctvom vstavaného servera MCP.
Integrácia komunikuje s komunitným doplnkom **Obsidian Local REST API**, ktorý je spustený v
desktopovej aplikácii, takže agenti môžu vyhľadávať poznámky, čítať/zapisovať/upravovať súbory, zobrazovať
obsah trezora, pracovať s dennými/týždennými periodickými poznámkami, spravovať značky, spúšťať príkazy
Obsidianu a (voliteľne) koordinovať obojsmernú synchronizáciu trezora medzi desktopom a mobilom.

Klient (`src/lib/obsidian/api.ts`) poskytuje nad Local REST API tieto funkcie:

- **Opakovanie s exponenciálnym oneskorením** pri dočasných chybách `5xx`, **30-sekundový časový limit** prostredníctvom `AbortController`.
- **Typovú klasifikáciu chýb** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Zrozumiteľnú nápovedu „nemožno sa pripojiť k Obsidianu“**, ktorá upozorňuje na bežnú chybu portu
  (HTTP na `27123`, **nie** koncový bod MCP na `27124`) a na formát pre Tailscale.
- **Kódovanie ciest** relatívnych k trezoru, aby boli cesty k poznámkam s medzerami/lomkami bezpečné.

## Nastavenie

Pre token ani základnú URL Obsidianu **neexistuje žiadna premenná prostredia** — obe hodnoty sú
uložené v tabuľke SQLite `key_value` (menný priestor `obsidian`) prostredníctvom
`src/lib/db/obsidian.ts`. Token je **zašifrovaný v úložisku** (AES-256-GCM, so
spätnou kompatibilitou pre nezašifrovaný text). Konfiguráciu vykonajte na karte **Zdroje kontextu**
ovládacieho panela koncového bodu (`ObsidianSourceCard`) alebo prostredníctvom REST API nastavení.

> [!IMPORTANT]
> Doplnok **Obsidian Local REST API** musí byť nainštalovaný a spustený. Jeho rozhranie REST
> počúva na adrese **HTTP `127.0.0.1:27123`** (predvolená základná URL). Port `27124`
> je _samostatný_ koncový bod MCP/HTTPS a cesta nastavení ho explicitne odmieta.
> Pri pripájaní z iného zariadenia použite `http://<tailscale-ip>:27123`.

### Konfiguračné kľúče (SQLite `key_value`, menný priestor `obsidian`)

| Kľúč              | Účel                                                            | Šifrované |
| ----------------- | --------------------------------------------------------------- | --------- |
| `api_key`         | Nosný token Local REST API                                      | áno       |
| `base_url`        | Základná URL REST (predvolene `http://127.0.0.1:27123`)         | nie       |
| `vault_path`      | Absolútna cesta k adresáru trezora (na synchronizáciu)          | nie       |
| `webdav_username` | Vygenerované používateľské meno WebDAV (synchronizácia trezora) | nie       |
| `webdav_password` | Vygenerované heslo WebDAV (synchronizácia trezora)              | áno       |
| `webdav_enabled`  | Určuje, či je synchronizácia trezora cez WebDAV povolená        | nie       |

### Konfigurácia prostredníctvom REST

```bash
# Uloženie + overenie tokenu Local REST API (POST ho overí kontrolou stavu)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Kontrola stavu pripojenia (vracia connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Odpojenie (vymaže uložený token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Všetky metódy vyžadujú autentifikáciu ovládacieho panela. `POST` odmieta každú URL na porte `27124`
a pred uložením overuje token volaním koncového bodu stavu Local REST API.

### Synchronizácia trezora cez WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` spravuje voliteľnú synchronizáciu
trezora založenú na WebDAV (zabezpečuje ju `src/lib/obsidianSync.ts`). Jej povolením sa OmniRoute nasmeruje na
lokálny adresár trezora a vygeneruje sa náhodná dvojica používateľského mena a hesla WebDAV:

```bash
# Povolenie synchronizácie cez WebDAV pre adresár trezora (vygeneruje používateľské meno/heslo)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Získanie stavu synchronizácie WebDAV (prihlasovacie údaje sa vrátia len vtedy, keď je povolená)
curl http://localhost:20128/api/settings/obsidian/webdav

# Zakázanie synchronizácie WebDAV (vymaže prihlasovacie údaje + spravovaný súbor .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Zdroj kontextu pre jednotlivé kľúče API (voliteľné)

Konfiguráciu Obsidianu možno nastaviť **pre jednotlivé kľúče API** prostredníctvom tabuľky `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Keď volanie MCP obsahuje id autentifikovaného kľúča API,
`getObsidianConfigForApiKey()` uprednostní vlastný token/základnú URL/cestu k trezoru daného kľúča
(`source: "api_key"`), inak použije globálnu konfiguráciu (`source: "global"`).

## Nástroje MCP (22)

Definované v `open-sse/mcp-server/tools/obsidianTools.ts`. Token/základná URL sa zisťujú
pri každom volaní (najskôr podľa kľúča API, potom globálne). Nástroje, ktoré pristupujú k **synchronizačnému serveru**
OmniRoute (štyri nástroje `obsidian_sync_*`), navyše vyžadujú autentifikačný token synchronizácie nakonfigurovaný
v nastaveniach OmniRoute.

### Nástroje na čítanie (`read:obsidian`)

| Nástroj                      | Popis                                                                                                                 |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Skontroluje, či je Local REST API dostupné a autentifikované.                                                         |
| `obsidian_search_simple`     | Fulltextové vyhľadávanie v obsahu poznámok; vracia úryvky s cestami k súborom.                                        |
| `obsidian_search_structured` | Vyhľadávanie pomocou výrazu JSON Logic (filtre and/or/regex/path).                                                    |
| `obsidian_read_note`         | Prečíta poznámku podľa cesty relatívnej k trezoru; voliteľne konkrétny nadpis/blok/frontmatter.                       |
| `obsidian_list_vault`        | Zobrazí zoznam súborov a adresárov v trezore (strom položiek).                                                        |
| `obsidian_get_document_map`  | Získa štruktúru nadpisov poznámky ako mapu nadpisov → čísla riadkov.                                                  |
| `obsidian_get_note_metadata` | Získa frontmatter, značky, odkazy a počet znakov/slov bez celého obsahu.                                              |
| `obsidian_get_active_file`   | Získa cestu a obsah súboru, ktorý je aktuálne aktívny v Obsidiane.                                                    |
| `obsidian_get_periodic_note` | Získa dennú/týždennú/mesačnú periodickú poznámku pre dátum (ak sa vynechá, použije sa dnešok).                        |
| `obsidian_get_tags`          | Zobrazí všetky značky v trezore spolu s ich početnosťou.                                                              |
| `obsidian_list_commands`     | Zobrazí dostupné ID príkazov Obsidianu (na použitie s `obsidian_execute_command`).                                    |
| `obsidian_sync_status`       | Stav synchronizačného servera OmniRoute: spustený stav, názov trezoru, port, čas prevádzky a posledná synchronizácia. |
| `obsidian_sync_conflicts`    | Zobrazí nevyriešené konflikty synchronizácie (cesta, cesta konfliktu, čas zistenia).                                  |

### Nástroje na zápis (`write:obsidian`)

| Nástroj                          | Popis                                                                                           |
| -------------------------------- | ----------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Vytvorí alebo prepíše poznámku zadaným obsahom vo formáte Markdown.                             |
| `obsidian_append_note`           | Pripojí obsah k poznámke; voliteľne ku konkrétnemu nadpisu/bloku.                               |
| `obsidian_patch_note`            | Presne pripojí/predradí/nahradí obsah pri nadpise, bloku alebo poli frontmatteru.               |
| `obsidian_delete_note`           | Natrvalo odstráni poznámku z trezoru.                                                           |
| `obsidian_move_note`             | Presunie alebo premenuje poznámku v rámci trezoru.                                              |
| `obsidian_execute_command`       | Vykoná príkaz Obsidianu podľa jeho ID príkazu.                                                  |
| `obsidian_open_file`             | Otvorí súbor v Obsidiane (ak neexistuje, vytvorí ho).                                           |
| `obsidian_sync_trigger`          | Spustí okamžitú obojsmernú synchronizáciu trezoru medzi počítačom a mobilným zariadením.        |
| `obsidian_sync_resolve_conflict` | Vyrieši konflikt synchronizácie: ponechá `local` (mobil), `remote` (počítač) alebo `keep-both`. |

> [!NOTE]
> Ciele nástroja `obsidian_patch_note` akceptujú `targetType` s hodnotou `heading | block | frontmatter`
> a `operation` s hodnotou `append | prepend | replace`, s voliteľnou možnosťou
> `createTargetIfMissing`. Štyri nástroje `obsidian_sync_*` komunikujú s lokálnym synchronizačným
> serverom (predvolene `http://127.0.0.1:27781`) a vyžadujú synchronizačný token.

### Rozsahy oprávnení

Nástroje na čítanie vyžadujú `read:obsidian`; nástroje na zápis vyžadujú `write:obsidian`. Vynucovanie
je rovnaké ako v Notione — spracúva ho `withScopeEnforcement()` v súbore
`open-sse/mcp-server/server.ts`, pričom je podmienené nastavením `OMNIROUTE_MCP_ENFORCE_SCOPES=true`
a povolené rozsahy sa získavajú z `OMNIROUTE_MCP_SCOPES` alebo z kontextu rozsahov kľúča API. Pozrite si
[MCP-SERVER.md](./MCP-SERVER.md).

## Koncové body

| Metóda   | Cesta                           | Účel                                                              |
| -------- | ------------------------------- | ----------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Vráti `{ connected, hasToken, baseUrl, vaultPath }`.              |
| `POST`   | `/api/settings/obsidian`        | Uloží a overí token (odmietne port `27124`).                      |
| `DELETE` | `/api/settings/obsidian`        | Odpojí (vymaže uložený token).                                    |
| `GET`    | `/api/settings/obsidian/webdav` | Stav synchronizácie WebDAV + prihlasovacie údaje (ak je zapnutá). |
| `POST`   | `/api/settings/obsidian/webdav` | Zapne synchronizáciu WebDAV pre adresár trezora.                  |
| `DELETE` | `/api/settings/obsidian/webdav` | Vypne synchronizáciu WebDAV.                                      |

> Toto sú trasy nastavení ovládacieho panela. K samotnému trezoru sa pristupuje cez lokálne
> REST API Obsidian (nakonfigurovanú adresu `base_url`) a prostredníctvom vyššie uvedených nástrojov MCP —
> verejný koncový bod proxy `/v1` pre Obsidian neexistuje.

## Prípady použitia

- **Odpovede založené na obsahu trezora** — `obsidian_search_simple` / `obsidian_search_structured`
  a následne `obsidian_read_note`, aby agent odpovedal na základe vašich skutočných poznámok.
- **Tvorba poznámok / vedenie denníka** — `obsidian_write_note`, `obsidian_append_note` alebo
  presný nástroj `obsidian_patch_note` na zaznamenávanie výstupov agenta, súhrnov či denných poznámok
  (`obsidian_get_periodic_note`) do trezora.
- **Navigácia v trezore** — `obsidian_list_vault`, `obsidian_get_document_map` a
  `obsidian_get_tags` na preskúmanie štruktúry pred čítaním alebo zapisovaním.
- **Automatizácia Obsidianu** — `obsidian_list_commands` + `obsidian_execute_command` na
  ovládanie pluginov/príkazov agentom; `obsidian_open_file` na zobrazenie poznámky v používateľskom rozhraní.
- **Mobilná synchronizácia** — zapnite synchronizáciu WebDAV a potom použite `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  na koordináciu synchronizácie medzi počítačom a mobilným zariadením a riešenie konfliktov.
