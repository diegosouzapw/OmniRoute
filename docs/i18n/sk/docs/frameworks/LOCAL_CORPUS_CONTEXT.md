> **Zdroj pravdy:** `src/lib/localCorpus/index.ts` (obmedzený textový index),
> `src/lib/localCorpus/configured.ts` (nakonfigurované runtime prostredie),
> `src/lib/db/localCorpus.ts` (perzistencia koreňovej cesty),
> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 MCP nástroje iba na čítanie) a
> `src/app/api/settings/local-corpus/route.ts` (API nastavení).

## Čo to je

Local Corpus umožňuje operátorovi sprístupniť jeden explicitne schválený adresár textových súborov
MCP serveru OmniRoute. Súbory zostávajú vo svojom pôvodnom adresári: OmniRoute ukladá v SQLite iba
kanonickú koreňovú cestu a udržiava vyhľadávací index v pamäti. Obsah korpusu
nekopíruje do repozitára ani databázy.

Obnovovanie indexu je prírastkové. Nezmenené súbory sa opätovne používajú na základe veľkosti a času
úpravy, zmenené súbory sa znova načítajú a vypočíta sa z nich hash SHA-256 a odstránené súbory sa vyradia.
Vyhľadávanie obnoví index starší ako 30 sekúnd; volajúci môžu tiež požiadať o okamžité
obnovenie.

## Konfigurácia zdroja

Trasa nastavení vyžaduje rovnaké overenie správcu ako ostatné API nastavení.
Odoslaná cesta už musí existovať a musí byť absolútnou cestou k adresáru.

```bash
# Pripojenie schváleného adresára
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Kontrola konfigurácie a stavu indexu
curl http://localhost:20128/api/settings/local-corpus

# Odpojenie bez zmeny zdrojových súborov
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP nástroje

Všetky tri nástroje vyžadujú `read:local-corpus`. Odpovede nástrojov sprístupňujú relatívne cesty a
základný názov koreňového adresára, nikdy nie jeho absolútnu cestu.

| Nástroj               | Popis                                                                                      |
| :-------------------- | :----------------------------------------------------------------------------------------- |
| `local_corpus_status` | Hlási stav konfigurácie, veľkosť indexu, limity a čas posledného obnovenia                 |
| `local_corpus_search` | Vyhľadáva v indexovanom texte a vracia obmedzené úryvky po riadkoch (najviac 20 výsledkov) |
| `local_corpus_read`   | Načíta obmedzený rozsah riadkov z jedného povoleného súboru s cestou relatívnou ku korpusu |

Príklady vstupov MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Bezpečnostné hranice

- Zoznam povolených prípon je zameraný na text: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` a `.yml`.
- Symbolické odkazy sa preskakujú. Cesty na čítanie sa kanonizujú a musia zostať v rámci
  nakonfigurovaného koreňového adresára; absolútne cesty a pokusy o prechod mimo neho sa odmietajú.
- Citlivé a generované názvy adresárov sú vylúčené: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` a
  `secrets`.
- Predvolené limity sú 5 000 súborov, 1 MiB na súbor, celkovo 64 MiB indexovaného obsahu,
  približne 4 000 znakov na jeden vyhľadávací blok a 400 riadkov na jedno čítanie.
- Súbory obsahujúce znak NUL sa považujú za netextové a preskočia sa alebo odmietnu.

Binárne dokumenty, ako sú PDF, DOCX, obrázky a archívy, zámerne nie sú podporované.
Pred indexovaním ich skonvertujte na schválený textový formát v nakonfigurovanom adresári.

## Prevádzkové poznámky

- Zmena alebo odstránenie nakonfigurovaného koreňového adresára vymaže zdieľaný index v pamäti.
- Reštart procesu zahodí index; nasledujúce vyhľadávanie ho znova zostaví z nakonfigurovaného
  zdroja.
- `local_corpus_status` nevynucuje skenovanie. Ak je potrebné okamžité opätovné skenovanie, použite `local_corpus_search` s
  `refresh: true`.
- Zlyhania skenovania a čítania sa započítajú alebo vrátia ako sanitizované chyby; zdrojové súbory sa
  nikdy neupravujú.
