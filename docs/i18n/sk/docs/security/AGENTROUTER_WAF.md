Upstream brána `agentrouter` používa na `messages[].content` filter obsahu založený na kľúčových slovách. Filter je čiastočne deterministický (vždy blokuje určité frázy) a čiastočne pravdepodobnostný (je citlivý na nárazovú prevádzku — po rýchlo po sebe nasledujúcich požiadavkách sa stáva agresívnejším a po uplynutí času na upokojenie sa obnoví).

Keď WAF zablokuje požiadavku, vráti:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Rozsah filtra

WAF kontroluje iba `messages[].content`. **Nekontroluje**:

- Systémovú výzvu `system`
- Bloky štruktúrovaného obsahu (`tool_result`, `tool_use`, `thinking`, `image`)
- Polia nástrojov `description` a `input_schema`
- Metadáta požiadavky, hlavičky ani identifikátor modelu

## Vždy blokované vzory (bez ohľadu na veľkosť písmen)

| Vzor                            | Poznámky                                             |
| ------------------------------- | ---------------------------------------------------- |
| Akýkoľvek variant `Lorem ipsum` | Blokovaná je celá latinská slovná zásoba lorem       |
| `language model` (samostatne)   | "the language model" a "large language model" prejdú |
| `virtual assistant`             | "AI assistant" prejde                                |
| `I'm here to help`              | Blokuje sa aj samostatné "here to help"              |
| `Claude, made by Anthropic`     | Iba celá fráza                                       |

## Takmer vždy blokované vzory

| Vzor                                                      | Poznámky                                                   |
| --------------------------------------------------------- | ---------------------------------------------------------- |
| `placeholder`                                             | Keď sa vyskytuje samostatne (nie ako názov parametra atď.) |
| `dummy data`                                              | Bežná počiatočná fráza pre testovacie dáta                 |
| `foo bar baz`                                             | Kanonická zástupná fráza                                   |
| Opakované krátke tokeny (`AAA BBB CCC`, `test test test`) | Detektor zahlcovania kľúčovými slovami                     |

## Správanie pri zaťažení

Po približne 5 rýchlo po sebe nasledujúcich požiadavkách v krátkom časovom okne začne WAF blokovať obsah, ktorý by za normálnych okolností prešiel. Limit sa uvoľní po približne 5–10 sekundách nečinnosti. Ide o rovnaký obmedzovač frekvencie viazaný na IP adresu a kľúč, ktorý spôsobuje prerušované chyby `400 content-blocked`, keď Claude Code alebo Codex CLI vykoná viacero volaní použitia nástroja alebo odoslania správy rýchlo po sebe.

## Zmiernenia už použité v OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — ochrana proti nárazovej prevádzke, ktorá vynucuje minimálny interval 500 ms medzi odchádzajúcimi požiadavkami na ľubovoľnú URL `agentrouter:*`. Tento interval je výrazne pod hranicou, pri ktorej by človek vnímal oneskorenie, a zabraňuje aktivácii WAF pri bežnej prevádzke.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — keď upstream vráti chybu `400 content-blocked`, executor zopakuje požiadavku na rovnakú URL s exponenciálnym odkladom (1,5 s, 3,0 s, maximálne 2 pokusy). Po tomto odklade sa WAF zvyčajne uvoľní a opakovaná požiadavka uspeje.

3. **`tests/unit/compression/harness.test.ts`** — testovacia hodnota `longInput` bola zmenená z `"lorem ipsum dolor sit amet ".repeat(40)` na `"example content for testing purposes ".repeat(40)`, aby pri čítaní tohto súboru nástrojom `Read` v Claude Code obsah súboru neprechádzal späť cez blok `tool_result` a nespustil WAF.

## Odporúčania pre výzvy a výstup nástrojov

Ak relácia Claude Code alebo Codex CLI opakovane naráža na chybu `400 content-blocked`, skontrolujte najnovšiu správu používateľa a najnovší výsledok nástroja, či neobsahujú niektorý z vyššie uvedených vzorov, a preformulujte ich. Bežné alternatívy:

- Nahraďte `Lorem ipsum …` výrazom `example text …` alebo skutočným obsahom, ktorý sa test alebo testovacie dáta snažia modelovať.
- Nahraďte samostatne stojace `placeholder` výrazom `example value`, `sample value` alebo skutočnou hodnotou.
- Nahraďte `language model` výrazom `large language model` alebo `the model`.
- Nahraďte `dummy data` výrazom `sample data` alebo realistickými počiatočnými hodnotami.
- Nahraďte `I'm here to help` / `here to help` konkrétnejším úvodom (napr. "I'll review the file you mentioned").

## Nahlasovanie falošne pozitívnych výsledkov upstreamu

Aktuálny filter je príliš agresívny — blokuje "Lorem ipsum" v blokoch `tool_result`, hoci operátor zjavne nemal v úmysle vložiť výzvu. Prevádzkovatelia, ktorí chcú tento problém odstrániť pri zdroji, by mali kontaktovať `agentrouter.org` a nahlásiť falošne pozitívne výsledky. Uvedený zoznam blokovaných výrazov je empirickým výsledkom testovania upstreamu k dátumu 2026-08-03.
