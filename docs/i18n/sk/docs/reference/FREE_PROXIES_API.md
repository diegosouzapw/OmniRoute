OmniRoute poskytuje starostlivo vybranú skupinu bezplatných proxy serverov v tabuľke `free_proxies`,
synchronizovanú z externých poskytovateľov (1proxy, proxifly, iplocate, webshare).
Ovládací panel ich zobrazuje v časti **Nastavenia → Bezplatné proxy servery**. Tento dokument
opisuje filtrovanie, zoraďovanie, počítanie a hlásenie chýb synchronizácie na strane servera,
ktoré poskytuje trasa zoznamu.

## Trasa zoznamu — `GET /api/settings/free-proxies`

Vracia filtrovanú, zoradenú a stránkovanú časť spolu s celkovým počtom. Filtrovanie a
počítanie prebieha v SQL, takže používateľské rozhranie môže zobraziť skutočný celkový počet (napr. `Celkom: 0`)
bez načítania všetkých riadkov do pamäte.

### Parametre dopytu

| Parameter         | Typ                                | Predvolená hodnota | Význam                                                                                                                     |
| ----------------- | ---------------------------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `search`          | reťazec                            | `""`               | Rozlišovanie veľkých a malých písmen pomocou `LIKE` v stĺpci hostiteľa (a zdroja).                                         |
| `protocol`        | reťazec                            | `""`               | Filter `type`: `http` / `https` / `socks4` / `socks5`. Prázdna hodnota = všetky.                                           |
| `country`         | reťazec                            | `""`               | Filter `countryCode` (ISO-2). Prázdna hodnota = všetky.                                                                    |
| `minQuality`      | číslo                              | `0`                | Iba riadky s `qualityScore >= minQuality`. `0` = bez minimálnej hodnoty.                                                   |
| `disabledSources` | reťazec                            | `""`               | Identifikátory zdrojov oddelené čiarkami, ktoré sa majú vylúčiť (napr. `proxifly,webshare`).                               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`          | `quality` = skóre zostupne; `latency` = latencia vzostupne (nulové hodnoty nakoniec); `recent` = `lastValidated` zostupne. |
| `offset`          | číslo                              | `0`                | Začiatok stránkovania.                                                                                                     |
| `limit`           | číslo                              | `50`               | Veľkosť stránky (obmedzená na strane servera).                                                                             |

### Odpoveď

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` predstavuje filtrovaný celkový počet **pred** stránkovaním, takže používateľské rozhranie môže vykresliť
`Celkom: N` a `hasMore` nezávisle od seba. `syncErrors` používa identifikátory zdrojov ako kľúče a
vypĺňa sa iba pre zdroje, ktorých posledná synchronizácia zlyhala — výsledok `Celkom: 0`
nikdy nezostane bez vysvetlenia.

## Pridanie do skupiny — `POST /api/settings/free-proxies/[id]/add-to-pool`

Povýši bezplatný proxy server do spravovanej skupiny `proxy_registry`. Najprv overí
nadradený zdroj; pri úspechu vráti identifikátor nového proxy servera v skupine a nameranú latenciu.

## Synchronizácia — `POST /api/settings/free-proxies/sync`

Znova načíta všetky povolené zdroje (alebo podmnožinu v `{ "sources": [...] }`). Každý
zdroj sa synchronizuje nezávisle; zlyhávajúci zdroj sa zaznamená v `syncErrors` a
ostatné sa napriek tomu dokončia, takže čiastočné synchronizácie nikdy nevymažú predchádzajúce platné údaje.

## Štatistiky — `GET /api/settings/free-proxies/stats`

Vracia súhrn `total / inPool / avgQuality / bySource / lastSyncAt`
bez dátového obsahu riadkov — používa sa v hlavičkových miniaplikáciách ovládacieho panela.
