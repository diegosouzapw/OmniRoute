## Kategórie

- **Bezplatné** — bezplatná úroveň s kľúčom API (konfiguruje sa cez ovládací panel)
- **Bez autentifikácie** — verejné koncové body, ktoré vôbec nevyžadujú kľúč ani prihlásenie
- **OAuth** — proces prihlásenia zabezpečuje OmniRoute, kľúč API nie je potrebný
- **Webový súbor cookie** — sprostredkúva webovú aplikáciu poskytovateľa pomocou autentifikácie cez súbor cookie
- **Kľúč API** — platený poskytovateľ nakonfigurovaný pomocou kľúča API (môžu byť k dispozícii bezplatné kredity)
- **Lokálne** — spúšťa sa na počítači používateľa (Ollama, LM Studio, vLLM atď.)
- **Vyhľadávanie** — poskytovatelia webového vyhľadávania
- **Zvuk** — poskytovatelia zameraní iba na zvuk (TTS/STT)
- **Nadradený proxy server** — poskytovatelia, ktorí sprostredkúvajú prístup k iným poskytovateľom
- **Cloudový agent** — dlho bežiace programovacie agenty (Codex Cloud, Devin, Jules)
- **Systémové** — interní poskytovatelia OmniRoute (loopback atď.)

Ďalšie značky: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Volanie nástrojov` (ak je uvedené): `native` — skutočné API na volanie funkcií; `emulated` — pole `tools` sa emuluje v prompte prostredníctvom `webTools.ts` (bloky `<tool>{...}</tool>` analyzované regulárnym výrazom); `none` — pole `tools` sa momentálne bez upozornenia zahodí. Pozrite si #7286.

Na povolenie, konfiguráciu a testovanie jednotlivých poskytovateľov použite ovládací panel na adrese `/dashboard/providers`.
