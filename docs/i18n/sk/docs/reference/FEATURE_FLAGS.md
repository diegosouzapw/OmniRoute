> Prepínače za behu, ktoré menia správanie OmniRoute **bez opätovného nasadenia**.
> Každý príznak uvedený v tomto dokumente je definovaný v súbore
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — jedinom zdroji pravdy. Ovládací panel aj REST API čítajú údaje z
> tohto súboru, takže tabuľka nižšie je vygenerovaná tak, aby mu zodpovedala v pomere 1:1.

---

## Čo sú príznaky funkcií

Príznak funkcie je pomenovaný prepínač (boolean alebo enum), ktorého hodnotu možno meniť
za behu a trvalo uložiť do databázy bez potreby opätovného nasadenia procesu. Každý
príznak opisuje objekt `FeatureFlagDefinition` s atribútmi `key`, `label`,
`description`, `category`, `defaultValue`, `type` a pomocným údajom `requiresRestart`.

### Poradie vyhodnocovania

**Efektívna hodnota** príznaku sa určuje pomocou
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) podľa tejto
priority (vyššia má prednosť):

1. **Prepísanie z DB** — hodnota uložená v tabuľke `key_value` v mennom priestore
   `feature_flags` (nastavená prostredníctvom ovládacieho panela alebo REST API).
2. **Premenná prostredia** — `process.env[<KEY>]`, ak je nastavená a nie je prázdna.
3. **Predvolená hodnota definície** — hodnota `defaultValue` zo súboru `featureFlagDefinitions.ts`.

Príznak typu boolean sa považuje za **zapnutý**, keď je jeho efektívna hodnota `"true"`,
`"1"` alebo `"yes"` (pozrite si `isFeatureFlagEnabled()`).

> [!NOTE]
> Väčšina príznakov má tiež zodpovedajúcu premennú prostredia s **rovnakým názvom**,
> ktorá je zdokumentovaná v súbore [`ENVIRONMENT.md`](./ENVIRONMENT.md). Prepísanie príznaku z DB
> má pred touto premennou prostredia prednosť. Príznak s hodnotou
> `requiresRestart: true` sa uloží okamžite, ale opätovne sa načíta až pri spustení
> procesu — jeho prepnutie zobrazí na ovládacom paneli banner **„Reštartovať server“**.

použitá v prípade, že nie je prítomné prepísanie z DB ani premenná prostredia.

## Prepínanie príznakov

### Ovládací panel

Prejdite na **Ovládací panel → Nastavenia → Príznaky funkcií**
(`/dashboard/settings/feature-flags`). Mriežka
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
podporuje:

- **Vyhľadávanie** podľa kľúča alebo popisu a **filtrovanie** podľa kategórie (vrátane syntetického zobrazenia
  **Vyžaduje reštart**).
- **Prepínač** pre booleovské príznaky a **rozbaľovaciu ponuku** pre enumeračné príznaky
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Odznak zdroja** pre každý príznak — `DB`, `ENV` alebo `DEF` — ktorý zobrazuje, odkiaľ pochádza
  výsledná hodnota.
- Tlačidlo **Obnoviť** (zobrazuje sa iba pri príznakoch zo zdroja `DB`) na odstránenie prepísania
  a tlačidlo **Obnoviť všetky prepísania** v spodnej časti.
- Banner **Reštartovať server**, keď sa zmení príznak `requiresRestart`.

### REST API

Všetky operácie prechádzajú cez jednu trasu:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Každá metóda vyžaduje autentifikovanú reláciu ovládacieho panela (inak vráti `401`).

#### `GET /api/settings/feature-flags`

Vráti každý príznak spolu s jeho výslednou hodnotou, zdrojom a súhrnom.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... všetkých 74 príznakov
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Nastaví alebo odstráni jedno prepísanie. Telo: `{ key: string; value?: string }`.
Vynechanie `value` odstráni prepísanie (obnoví hodnotu z prostredia/predvolenú hodnotu).

```bash
# Nastavenie prepísania v DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Odstránenie prepísania (bez "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Odpoveď obsahuje novú hodnotu `effectiveValue`/`source`, predchádzajúcu hodnotu `previousValue`/
`previousSource` a `requiresRestart`. Neznáme kľúče a enumeračné hodnoty mimo povoleného rozsahu
sú odmietnuté s kódom `400`.

#### `DELETE /api/settings/feature-flags`

Naraz odstráni **všetky** prepísania v DB a obnoví pre každý príznak jeho hodnotu z prostredia/predvolenú
hodnotu. Vráti `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Príznaky s `requiresRestart: true` sa prejavia až po opätovnom načítaní procesu.
> Proces reštartovania z ovládacieho panela volá `POST /api/restart` a následne opakovane kontroluje
> `GET /api/health/ping`, kým server nebude znova dostupný.

## Núdzové záložné riešenie pri vyčerpaní rozpočtu

`OMNIROUTE_EMERGENCY_FALLBACK` (kategória `runtime`, predvolená hodnota `true`) riadi
núdzovú bezplatnú záložnú cestu v
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Keď je táto možnosť povolená, požiadavky, ktoré vyčerpajú svoj rozpočet, sú namiesto úplného zlyhania
smerované k bezplatnému záložnému poskytovateľovi/modelu. Nastavte ju na `false` (alebo `0`) — pomocou
prepínača na ovládacom paneli, prepísania v DB alebo premennej prostredia
`OMNIROUTE_EMERGENCY_FALLBACK` — čím toto správanie zakážete a umožníte zlyhanie požiadaviek
s vyčerpaným rozpočtom. (Sprístupnené ako prepínač na ovládacom paneli v PR #3741 / #3752.)
