OmniRoute პროვაიდერის კვოტის ტელემეტრიას Ghostlight-ის აღრიცხვისგან განცალკევებით ამუშავებს.

## ზუსტი მდგომარეობები

- `healthy` ნიშნავს, რომ წყარომ გამოსაყენებელი დარჩენილი რესურსი დააფიქსირა.
- `approaching_limit` ნიშნავს, რომ წყაროს მიერ დაფიქსირებული დარჩენილი რესურსი კონფიგურირებულ ზღვარს უტოლდება ან მასზე ნაკლებია.
- `exhausted` გენერირდება მხოლოდ მაშინ, როდესაც წყარო ნულოვან რესურსს ან ლიმიტის ტოლ გამოყენებას აფიქსირებს.
- `unavailable` ნიშნავს, რომ მხარდაჭერილმა წყარომ მონაცემების დაბრუნება ვერ შეძლო.
- `unknown` ნიშნავს, რომ მხარდაჭერილი წყარო არ არსებობს ან პროვაიდერის ლიმიტი უცნობია.

უცნობი მდგომარეობა არ ნიშნავს რესურსის ამოწურვას და პროვაიდერს არ თიშავს.

წყაროებს უპირატესობა შემდეგი თანმიმდევრობით ენიჭება: პროვაიდერის ოფიციალური API, ავთენტიფიცირებული გამოყენების API, პასუხის ცალსახად ასახული სათაურები, ადმინისტრატორის კონფიგურაცია, ლოკალური შეფასებები, უცნობი. ლოკალური შეფასებები არასოდეს არის წარმოდგენილი, როგორც პროვაიდერის ბილინგის მონაცემები.

პასუხის სათაურები მუშავდება მხოლოდ პროვაიდერის ცალსახა შესაბამისობის სქემის მიხედვით. სათაურების ზოგადი სახელები გლობალურად ნაგულისხმევად არ მიიჩნევა.
