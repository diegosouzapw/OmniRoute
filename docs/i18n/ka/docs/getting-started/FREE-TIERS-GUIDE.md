OmniRoute აერთიანებს თქვენ მიერ კონფიგურირებულ კავშირებს; ის არ გასცემს რეკლამირებულ ჯამურ ტოკენების ბიუჯეტს. უფასო წვდომისთვის შეიძლება საჭირო იყოს რეგისტრაცია, API გასაღები, დამტკიცება ან გადახდის მეთოდი. პროვაიდერის ლიმიტები, კონფიდენციალურობის პოლიტიკები და პირობები კვლავ მოქმედებს.

## რა არის უფასო ტარიფები?

ხელოვნური ინტელექტის მრავალი პროვაიდერი გვთავაზობს **უფასო წვდომის** გარკვეულ ფორმას. პროვაიდერის მიხედვით, ეს შეიძლება ნიშნავდეს ავთენტიფიკაციის არმომთხოვნ საბოლოო წერტილს, პერიოდულად განახლებად კვოტას, სიხშირით შეზღუდულ ულიმიტო წვდომას, რეგისტრაციისას მინიჭებულ კრედიტს, ხელით დამტკიცებას ან დროებით აქციას. ზოგიერთი ვარიანტი საჭიროებს ანგარიშს, API გასაღებს, საკრედიტო ბარათს, KYC-ს ან პროვაიდერის სპეციფიკური პირობების მიღებას.

OmniRoute კონფიგურირებულ კავშირებს ერთ საბოლოო წერტილში **აერთიანებს**. თითოეულ პროვაიდერთან, რომელიც ანგარიშს მოითხოვს, კვლავ ცალ-ცალკე უნდა დარეგისტრირდეთ. დააკავშირეთ ეს ანგარიშები და შესაბამის სამიზნეებს შორის მარშრუტიზაციისთვის გამოიყენეთ `model: "auto"`. ახალ ინსტალაციას შეიძლება არ ჰქონდეს გასაღების არმომთხოვნი არცერთი შესაბამისი სამიზნე; მხოლოდ OmniRoute-ის ინსტალაცია ჩატიდან წარმატებული პასუხის მიღების გარანტიას არ იძლევა.

4. **LongCat** — რეგისტრაციისას ერთჯერადად გამოყოფილი კრედიტი (საჭიროებს KYC-ს)

OAuth-ისა და API გასაღების მქონე პროვაიდერები უნდა დააკავშიროთ მათი დოკუმენტირებული ანგარიშის პროცედურის მეშვეობით. თუ როუტერის ავთენტიფიკაცია ჩართულია, თქვენი კლიენტი კვლავ იყენებს OmniRoute-ის API გასაღებს, რომელიც ნაჩვენებია განყოფილებაში **მართვის პანელი → საბოლოო წერტილები**.

### ნაბიჯი 6: გაიმეორეთ

## კატალოგის სწორად წაკითხვა

- `NOAUTH` ნიშნავს, რომ OmniRoute არ მოგთხოვთ პროვაიდერის ავტორიზაციის მონაცემებს; ეს არ
  იძლევა ხელმისაწვდომობის, კონფიდენციალურობის ან შეუზღუდავი სიმძლავრის გარანტიას.
- `hasFree` არის აღმოჩენისთვის განკუთვნილი მეტამონაცემი. ის შეიძლება აღნიშნავდეს განმეორებად კვოტას, გასაღების გარეშე წვდომას,
  რეგისტრაციის კრედიტს, დამტკიცების პროგრამას ან აქციას.
- `recurring-uncapped` ნიშნავს, რომ გამოქვეყნებული ტოკენების ზედა ზღვარი ხელმისაწვდომი არ იყო; სიხშირისა და
  კონკურენტული მოთხოვნების შეზღუდვები კვლავ მოქმედებს.

- `tos: avoid` ნიშნით მონიშნული პროვაიდერები ნაგულისხმევად გამორიცხულია ავტომატური მარშრუტიზაციიდან (`excludeTosAvoid`). ანგარიშის დაკავშირება ამ ფილტრს არ აუვლის გვერდს. ოპერატორის მიერ ნებისმიერი გამონაკლისის დაშვებამდე უნდა გადაიხედოს პროვაიდერის პირობები და ანგარიშთან დაკავშირებული რისკები.
- `discontinued` ნიშნით მონიშნული ჩანაწერები ისტორიულ მტკიცებულებად რჩება და არ უნდა იყოს წარმოდგენილი, როგორც
  ამჟამად უფასო.

OmniRoute თითოეული მოთხოვნისთვის **საუკეთესო უფასო პროვაიდერს** შემდეგი კრიტერიუმების საფუძველზე ირჩევს:

- რესურსი — რომელ პროვაიდერს დარჩა კვოტა?

### 3. ტოკენების დაზოგვა

OmniRoute-ის შეკუმშვის კონვეიერს შეუძლია შეამციროს მოთხოვნისა და ხელსაწყოს შედეგის შესაბამისი ტოკენების რაოდენობა.
რეალური დანაზოგი დამოკიდებულია შიგთავსზე, არჩეულ ძრავებზე, პროვაიდერის აღრიცხვის წესსა და სიზუსტის
პარამეტრებზე; შეკუმშვა თითოეული პროვაიდერის კვოტას ფიქსირებული კოეფიციენტით არ ზრდის.

### 4. მრავალი ანგარიშის მხარდაჭერა

თუ პროვაიდერის პირობები მრავალი ანგარიშის ან ავტორიზაციის მონაცემის გამოყენებას უშვებს, OmniRoute-ს შეუძლია თითოეული

## გავრცელებული კითხვები

### "ეს ნამდვილად უფასოა?"

კატალოგში აღირიცხება პროვაიდერების მიერ გამოქვეყნებული პირობები და პროექტის კვლევის შედეგები, თუმცა შეთავაზებები შეიძლება შეიცვალოს.
გამოყენებამდე გადაამოწმეთ პროვაიდერის მიმდინარე ფასები, კვოტა, კონფიდენციალურობის პოლიტიკა და შესაბამისობის მოთხოვნები.

### "უფასო ტარიფის ლიმიტი ამოიწურება?"

ნებისმიერ პროვაიდერს შეუძლია მოთხოვნების სიხშირის შეზღუდვა, მოდელების შეცვლა, წვდომის შეჩერება ან ხაზგარეშე გადასვლა. მრავალი
კავშირი აუმჯობესებს სარეზერვო ვარიანტებით დაფარვას, თუმცა ხელმისაწვდომი უფასო მარშრუტის არსებობის გარანტიას არ იძლევა.

### "შემიძლია უფასო პროვაიდერები საწარმოო გარემოში გამოვიყენო?"

მხოლოდ იმ შემთხვევაში, თუ პროვაიდერის SLA, მონაცემთა დამუშავების წესები, ლიმიტები და პირობები აკმაყოფილებს თქვენს საწარმოო
მოთხოვნებს. კრიტიკულ სამუშაო დატვირთვებს უნდა ჰქონდეს მონიტორინგის ქვეშ მყოფი, კონტრაქტის პირობებთან შესაბამისი სარეზერვო ვარიანტი.

### "რა არის აქ დაფარული პირობა?"

კომპრომისები შეიძლება მოიცავდეს მკაცრ ლიმიტებს, მომლოდინეთა სიებს, KYC-ს, საკრედიტო ბარათით ვერიფიკაციას, მოთხოვნებზე
წვრთნას, სუსტ კონფიდენციალურობას, SLA-ის არარსებობას, მოდელების ხშირ ცვლას, გეოგრაფიულ შეზღუდვებს, ლიმიტს ზემოთ ფასიან გამოყენებას ან
ანგარიშის პოლიტიკასთან დაკავშირებულ რისკს. OmniRoute ხელმისაწვდომ მეტამონაცემებს გაჩვენებთ; თქვენ ირჩევთ, რა ჩართოთ.

### "როგორ მივიღო მეტი უფასო კვოტა?"

1. დააკავშირეთ მეტი უფასო პროვაიდერი
2. ჩართეთ შესაბამისი შეკუმშვის ძრავები და გაზომეთ დანაზოგი თქვენი სამუშაო დატვირთვისთვის
3. გამოიყენეთ `auto/cheap`, რათა პრიორიტეტი მიანიჭოთ უფასო/იაფ პროვაიდერებს
4. დაამატეთ სხვა ნებადართული პროვაიდერები ან ავტორიზაციის მონაცემები პროვაიდერის პირობების დარღვევის გარეშე

### "უფასო პროვაიდერებს უფრო დაბალი ხარისხი აქვთ?"

არა აუცილებლად. ზოგიერთი პროვაიდერი ხელმისაწვდომს ხდის მოდელების იმავე ოჯახებს, რომლებიც ფასიანი
მარშრუტებითაც არის ხელმისაწვდომი, თუმცა ლიმიტები, დაყოვნება, კონფიდენციალურობა, საიმედოობა და მოდელის ვერსიები შეიძლება განსხვავდებოდეს. ხარისხის ინდიკატორად გამოიყენეთ
უფასო პროვაიდერების რეიტინგების გვერდი და გადაამოწმეთ, რეალურად რომელი მოდელი მოგეწოდებათ.
