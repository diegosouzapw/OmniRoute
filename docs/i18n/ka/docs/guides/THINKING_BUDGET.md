> **მართვის პანელი:** პარამეტრები → **AI** → აზროვნების ბიუჯეტი  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **წყარო:** `open-sse/services/thinkingBudget.ts`

აზროვნების ბიუჯეტი განსაზღვრავს, გადააკეთებს თუ არა OmniRoute **კლიენტის აზროვნების/მსჯელობის პარამეტრებს** პროვაიდერებთან მოთხოვნების გადაგზავნისას. ის **არ** რთავს ან თიშავს შეკუმშვას, მარშრუტიზაციას ან მოთხოვნის ქეშს.

### რას შლის `auto`

როდესაც რეჟიმია `auto`, `stripThinkingConfig()` სხვა ველებთან ერთად შლის:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking` და, არსებობის შემთხვევაში, `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

თუ კლიენტმა (მაგალითად, Codex Desktop-მა) გაგზავნა `reasoning: { effort: "ultra", summary: "detailed" }`, **`auto` ამ ობიექტს შლის**. ზედა დონის სისტემამ შესაძლოა მაინც დარიცხოს მსჯელობის გარკვეული ტოკენების ღირებულება, თუმცა ხშირად აბრუნებს **ცარიელ ან მხოლოდ დაშიფრულ** მსჯელობის ელემენტებს — ამიტომ ინტერფეისში აზროვნების სასარგებლო ნაკადი არ ჩანს.

## ხილული აზროვნება (Codex / Responses კლიენტები)

იმისთვის, რომ კლიენტმა აზროვნების ტექსტი აჩვენოს, საჭიროა **ყველა** შემდეგი პირობის შესრულება:

1. Thinking Budget რეჟიმი = **`passthrough`** (ან custom/adaptive, რომელიც შეჯამების მოთხოვნებს მაინც საკმარისად უცვლელად ტოვებს თქვენ მიერ გამოყენებული გზისთვის).
2. კლიენტი ითხოვს შეჯამებას, მაგ., Codex `model_reasoning_summary = "detailed"` / `auto` (`none`-ის ნაცვლად).
3. ზედა დონის სერვისი რეალურად ნაკადად გადასცემს `response.reasoning_summary_text.*`-ს (ან ელემენტში არის არაცარიელი `reasoning.summary`).

თუ მხოლოდ „დაშიფრულ პირად აზროვნებას“ იღებთ, მაშინ:

- რეჟიმი იყო **`auto`** (კლიენტის მოთხოვნა ამოშლილი იყო), ან
- ზედა დონის სერვისმა დააბრუნა `encrypted_content` შეჯამების ტექსტის გარეშე (პროვაიდერის შეზღუდვა; OmniRoute-ს შეუძლია მხოლოდ ჩანაცვლების ტექსტის ჩვენება და არა ღია ტექსტის).

## API-ის მაგალითები

```bash
# წაკითხვა
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# რეკომენდებულია Codex / Desktop-ში აზროვნების ხილვადობისთვის
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

სქემა (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; არასავალდებულო `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### მუდმივი შენახვა / ხელახლა გაშვება

მნიშვნელობა ინახება პარამეტრების `thinkingBudget` გასაღების ქვეშ და იტვირთება პროცესის გაშვებისას (`hydrateThinkingBudgetConfig`). DB-ის ან ზოგიერთი არა-API გზის მეშვეობით ცვლილების შემდეგ **ხელახლა გაუშვით OmniRoute-ის პროცესი**, რათა მეხსიერებაში არსებული singleton დისკზე შენახულ მნიშვნელობას დაემთხვეს.
