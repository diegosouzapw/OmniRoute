## სწრაფი დეინსტალაცია (v3.6.2+)

OmniRoute სუფთა წაშლისთვის ორ ჩაშენებულ სკრიპტს გთავაზობთ:

### შეინარჩუნეთ თქვენი მონაცემები

```bash
npm run uninstall
```

ეს შლის OmniRoute აპლიკაციას, მაგრამ **ინარჩუნებს** თქვენს მონაცემთა ბაზას, კონფიგურაციებს, API გასაღებებსა და პროვაიდერის პარამეტრებს `~/.omniroute/`-ში. გამოიყენეთ ეს ვარიანტი, თუ მოგვიანებით ხელახლა ინსტალაციას გეგმავთ და გსურთ თქვენი კონფიგურაციის შენარჩუნება.

### სრული წაშლა

```bash
npm run uninstall:full
```

ეს შლის აპლიკაციას **და სამუდამოდ აქრობს** ყველა მონაცემს:

- მონაცემთა ბაზას (`storage.sqlite`)
- პროვაიდერის კონფიგურაციებსა და API გასაღებებს
- სარეზერვო ასლებს
- ჟურნალის ფაილებს
- `~/.omniroute/` დირექტორიაში არსებულ ყველა ფაილს

> ⚠️ **გაფრთხილება:** `npm run uninstall:full` შეუქცევადია. თქვენი პროვაიდერების ყველა კავშირი, კომბინაცია, API გასაღები და გამოყენების ისტორია სამუდამოდ წაიშლება.

## ხელით დეინსტალაცია

### NPM-ის გლობალური ინსტალაცია

```bash
# გლობალური პაკეტის წაშლა
npm uninstall -g omniroute

# (არასავალდებულო) მონაცემთა დირექტორიის წაშლა
rm -rf ~/.omniroute
```

### pnpm-ის გლობალური ინსტალაცია

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# კონტეინერის გაჩერება და წაშლა
docker stop omniroute
docker rm omniroute

# ტომის წაშლა (შლის ყველა მონაცემს)
docker volume rm omniroute-data

# (არასავალდებულო) იმიჯის წაშლა
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# კონტეინერების გაჩერება და წაშლა
docker compose down

# ტომების წაშლაც (შლის ყველა მონაცემს)
docker compose down -v
```

### Electron-ის დესკტოპ აპლიკაცია

**Windows:**

- გახსენით `Settings → Apps → OmniRoute → Uninstall`
- ან ინსტალაციის დირექტორიიდან გაუშვით NSIS-ის დეინსტალატორი

**macOS:**

- გადაიტანეთ `OmniRoute.app` `/Applications`-დან სანაგვე ურნაში
- წაშალეთ მონაცემები: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- წაშალეთ AppImage ფაილი
- წაშალეთ მონაცემები: `rm -rf ~/.omniroute`

### საწყისი კოდიდან ინსტალაცია (git clone)

```bash
# კლონირებული დირექტორიის წაშლა
rm -rf /path/to/omniroute

# (არასავალდებულო) მონაცემთა დირექტორიის წაშლა
rm -rf ~/.omniroute
```

## მონაცემთა დირექტორიები

ნაგულისხმევად, OmniRoute მონაცემებს შემდეგ მდებარეობებში ინახავს:

| პლატფორმა     | ნაგულისხმევი მისამართი         | გადაფარვა                        |
| ------------- | ------------------------------ | -------------------------------- |
| Linux         | `~/.omniroute/`                | `DATA_DIR` გარემოს ცვლადი        |
| macOS         | `~/.omniroute/`                | `DATA_DIR` გარემოს ცვლადი        |
| Windows       | `%APPDATA%/omniroute/`         | `DATA_DIR` გარემოს ცვლადი        |
| Docker        | `/app/data/` (მიერთებული ტომი) | `DATA_DIR` გარემოს ცვლადი        |
| XDG-თავსებადი | `$XDG_CONFIG_HOME/omniroute/`  | `XDG_CONFIG_HOME` გარემოს ცვლადი |

### მონაცემთა დირექტორიაში არსებული ფაილები

| ფაილი/დირექტორია     | აღწერა                                                                       |
| -------------------- | ---------------------------------------------------------------------------- |
| `storage.sqlite`     | მთავარი მონაცემთა ბაზა (პროვაიდერები, კომბინაციები, პარამეტრები, გასაღებები) |
| `storage.sqlite-wal` | SQLite-ის წინასწარი ჩაწერის ჟურნალი (დროებითი)                               |
| `storage.sqlite-shm` | SQLite-ის საზიარო მეხსიერება (დროებითი)                                      |
| `call_logs/`         | მოთხოვნის მონაცემების არქივები                                               |
| `backups/`           | მონაცემთა ბაზის ავტომატური სარეზერვო ასლები                                  |
| `log.txt`            | მოთხოვნების მოძველებული ჟურნალი (არასავალდებულო)                             |

## სრული წაშლის გადამოწმება

დეინსტალაციის შემდეგ გადაამოწმეთ, რომ დარჩენილი ფაილები არ არსებობს:

```bash
# გლობალური npm პაკეტის შემოწმება
npm list -g omniroute 2>/dev/null

# მონაცემთა დირექტორიის შემოწმება
ls -la ~/.omniroute/ 2>/dev/null

# გაშვებული პროცესების შემოწმება
pgrep -f omniroute
```

თუ რომელიმე პროცესი ჯერ კიდევ გაშვებულია, გააჩერეთ:

```bash
pkill -f omniroute
```
