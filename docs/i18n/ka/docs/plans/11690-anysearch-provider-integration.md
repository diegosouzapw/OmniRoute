## 1. სერვისის ზუსტი მონაცემები (ოფიციალური დოკუმენტაცია, გადამოწმებული)

- საბაზისო URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - პარამეტრები: `query` (სავალდებულო), `max_results` (1-10, ნაგულისხმევად 10), `tag` (`{domain}.{sub_domain}` ვერტიკალური მარშრუტიზაცია), `zone` (cn/intl), `language`, `params` (სტრუქტურირებული ვერტიკალური ველები), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - შესაძლებლობების კატალოგი, კვოტაში არ ითვლება.
- `POST /v1/extract` - `{url, title, content}`-ის მიღება/ამოღება; მკაცრი JSON-ის სხეული, 16 KiB ლიმიტი.
- `POST /v1/auth/email/register` - რეგისტრაცია ერთი გამოძახებით, აბრუნებს ერთჯერად ღია ტექსტურ გასაღებს `as_sk_...`.
- ავთენტიფიკაცია: არასავალდებულო `Authorization: Bearer <as_sk_...>`; ანონიმური წვდომა გადადის თითო IP-ზე დაწესებულ ლიმიტებზე და იყენებს უფასო დღიურ კვოტას; არასწორი გასაღები აბრუნებს 401/403-ს ანონიმურ რეჟიმზე შეუმჩნეველი გადართვის გარეშე.
- უფასო ტარიფი: 1000 მოთხოვნა/დღე, 20 QPS თითო გასაღებზე. ფასიანი ტარიფი: ფასი ჯერ არ არის განსაზღვრული (Coming Soon).
- პასუხის გარსი: წარმატება `{code: 0, message: "success", request_id, data}`; წარუმატებლობა `{code: -1, message}`. ავთენტიფიკაციის/კვოტის შეცდომები არ შეიცავს სტრუქტურირებულ `error_code`-ს (სიგნალს შეტყობინების ტექსტი წარმოადგენს); ამოღებასთან დაკავშირებული შეცდომები კი შეიცავს `error_code`-ს (`invalid_extract_url`, `extract_failed`). 429 პასუხს `Retry-After` სათაური არ ახლავს.

## 3. გადაწყვეტილებები (ყველა მიღებულია 2026-08-26-ს)

1. **მარშრუტიზაციის რეჟიმი: `fallbackOnly`.** დასაბუთება: 0-ღირებულების უფასო პროვაიდერმა არასოდეს უნდა დაიკავოს უპირატესი პოზიცია ღირებულებაზე დაფუძნებულ ავტომატურ მარშრუტიზაციაში; მკაფიო არჩევასა და შეფერხების შემდეგ დაბრუნებაზე ეს არ მოქმედებს. პრეცედენტი: გაერთიანებული xquik ჩანაწერი.
2. **მოცულობა: webSearch + webFetch `POST /v1/extract`-ის მეშვეობით v1-ში.** ეს შეესაბამება tavily/exa-ს ორმაგი შესაძლებლობების კონცეპტუალურ მოდელს. ვერტიკალური ზედაპირები (`tag`, `sub-domains`, `batch_search`) მოცულობის ფარგლებს გარეთ რჩება — ამჟამად ვერტიკალური პარამეტრებისთვის IR არ არსებობს.
3. **კვოტის ჩვენება: `freeMonthlyQuota: 0`** (xquik-ის სტილის კონსერვატიული ჩვენება). რეალური ლიმიტი (1000 მოთხოვნა/დღე, ყოველდღიური განულება) ამის ნაცვლად UI-ის კატალოგის `authHint` ტექსტშია მითითებული. დასაბუთება: კვოტის ჩვენება განულების სემანტიკას უნდა შეესაბამებოდეს; დღიური ლიმიტის თვიურ ეკვივალენტად (30000) გარდაქმნა მცდარი დაპირებაა, რომლის შესრულებაც UI-ს არ შეუძლია.
4. **searchTypes: მხოლოდ `["web"]`.** AnySearch API-ში სიახლეების/სურათების ვერტიკალის არსებობის საჯარო მტკიცებულება არ არსებობს; gateway-ები, რომლებიც დოკუმენტირებული ვერტიკალის არმქონე API-ებთან ინტეგრირდებიან (მაგ., Google Custom Search), მხოლოდ web-ს ხელმისაწვდომს ხდიან, ნაცვლად იმისა, რომ news უხმაუროდ დაუკავშირონ web-ს.
5. **გასაღების რეჟიმი:** გასაღების გარეშეც მუშაობს; არასწორი გასაღები აბრუნებს 401/403-ს და არასოდეს გადადის უხმაუროდ ანონიმურ რეჟიმზე (იმეორებს upstream-ის კონტრაქტს).
6. **განზრახ გამონაკლისები:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (ჩატის გადაჭერა რჩება firecrawl/jina/tavily-ზე); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (ანონიმური დისტანციური endpoint-ები თითოეულ egress IP-ზე ერთ საერთო IP-ით შეზღუდულ პულს იყენებენ, ამიტომ გასაღების გარეშე extract ხელით ჩასართავია და არა ავტომატური მარშრუტიზაციის კანდიდატი); `QUOTA_STATUS_PROVIDERS` (AnySearch კვოტის ამოწურვას 429/envelope-ის მეშვეობით მიუთითებს და არა 402/403 სტატუსით).
