## რეჩეტის პოლიტიკა

განაახლეთ `npm run test:coverage`-ის ზღვრები მხოლოდ მას შემდეგ, რაც პროექტი რეალურად გადააჭარბებს მომდევნო ეტაპის მაჩვენებლებს საკმარისი მარაგით.
