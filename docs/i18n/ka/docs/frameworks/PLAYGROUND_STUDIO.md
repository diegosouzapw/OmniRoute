## მიმოხილვა

Playground Studio `/dashboard/playground`-ს Monaco-ზე დაფუძნებული მარტივი რედაქტორიდან
სრულფასოვან სატესტო სამუშაო სივრცედ გარდაქმნის. ის ძველ `page.tsx`-ს ანაცვლებს `PlaygroundStudio`
გარსით, რომელიც ოთხ ჩანართსა და კონფიგურაციის საერთო პანელს აჩვენებს.

## ჩანართები

### ჩატის ჩანართი

`ChatPlayground.tsx` გარდაიქმნება მრავალსვლიანი სტრიმინგის სამუშაო გარემოდ:

- Markdown-ის სრული რენდერინგი `MarkdownMessage.tsx`-ის მეშვეობით (კოდის ბლოკები, ცხრილები, სიები, ბმულები).
- სისტემური მოთხოვნა მიიღება კონფიგურაციის საერთო პანელიდან.
- ტოკენები/ღირებულება თითოეული შეტყობინებისთვის (მოთხოვნის + დასრულების ტოკენები).
- ბოლო პასუხის ხელახლა გენერირება.
- იგზავნება `POST /v1/chat/completions`-ზე SSE სტრიმინგით.

### შედარების ჩანართი

პროქსისთვის მთავარი განმასხვავებელი შესაძლებლობა: 1 მოთხოვნის გაშვება მაქსიმუმ **4 მოდელზე პარალელურად**.

- მაქსიმუმ 4 სვეტი, თითოეული დამოუკიდებელი სტრიმინგით `/v1/chat/completions`-იდან.
- სვეტების დასამატებლად განკუთვნილი `+ მოდელის დამატება` ღილაკი (Cmd+K მალსახმობი).
- `ყველას გაშვება ▶` ყველა სტრიმს ერთდროულად უშვებს `Promise.all`-ისა და თითოეული სვეტისთვის ცალკე `AbortController`-ის გამოყენებით.
- გლობალური **ყველას გაუქმება** ყველა მიმდინარე სტრიმს წყვეტს.
- თითოეული სვეტის `ProviderMetrics` რეალურ დროში აჩვენებს TTFT-ს, TPS-ს, ტოკენებსა და სავარაუდო ღირებულებას.
- მეტრიკებს აქვს წარწერა **„კლიენტის მხარის შეფასება“** (D12) — იზომება პირველი SSE ფრაგმენტიდან.

### API ჩანართი

გამოცდილი მომხმარებლებისთვის სრულად ინარჩუნებს Monaco-ს თავდაპირველ რედაქტორს (D14):

- 10 საბოლოო წერტილი: ჩატის დასრულებები, დასრულებები, ემბედინგები, სურათები, აუდიო, მეტყველება, ტრანსკრიფციები, მოდერაციები, ხელახალი რანჟირება, ძიება.
- მულტიმოდალური ფაილის ატვირთვა.
- SSE სტრიმინგი რეალურ დროში მიღებული შედეგით.
- შეფუთულია როგორც `ApiTab.tsx` (ზარმაცად იტვირთება, `ssr: false`).

### აგების ჩანართი

ინსტრუმენტების/ფუნქციების გამოძახებისა და სტრუქტურირებული შედეგის ინტერფეისი:

- `ToolsBuilder.tsx` — `tools[]`-ის დამატება/რედაქტირება/წაშლა, თითოეული ინსტრუმენტისთვის JSON სქემის რედაქტორით.
  პარამეტრებს ამოწმებს `ToolDefinitionSchema`-ის (Zod) მეშვეობით.
- `StructuredOutputEditor.tsx` — JSON რეჟიმის გადამრთველი + JSON სქემის რედაქტორი.
  პასუხს სქემასთან შესაბამისობაზე ამოწმებს `StructuredOutputSchema`-ის (Zod) მეშვეობით.
- მოთხოვნას აგზავნის `/v1/chat/completions`-ზე `tools[]`-ით და/ან `response_format`-ით.

## მოთხოვნის გამაუმჯობესებელი

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. მოდალური ფანჯარა აფრთხილებს, რომ „კვოტა დაიხარჯება“.
2. დადასტურებისას მარშრუტს უგზავნის `{ system, prompt, model, tone }`-ს.
3. მარშრუტი შიდა დონეზე იძახებს `/v1/chat/completions`-ს `promptImprover.META_SYSTEM_PROMPT`-ით.
4. აბრუნებს `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`-ს.
5. UI განაახლებს კონფიგურაციის პანელის სისტემურ მოთხოვნასა და ჩატის ჩანართის მომხმარებლის მოთხოვნას.

## ნაკადის მეტრიკები

`useStreamMetrics.ts` + `streamMetrics.ts` (სუფთა ფუნქცია):

- `start()` — იწერს მოთხოვნის დაწყების დროს.
- `onFirstChunk()` — იწერს TTFT-ს.
- `onChunk(n)` — აგროვებს დასრულების ტოკენების რაოდენობას.
- `finish(usage?)` — ითვლის საბოლოო მეტრიკებს: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- ფასები აღებულია `src/lib/playground/types.ts`-ის სტატიკური ცხრილიდან (მონიშნულია როგორც „სავარაუდო“ — D13).
