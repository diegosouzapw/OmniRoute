Agent Skills წარმოადგენს სტრუქტურირებულ SKILL.md ფაილებს, რომლებიც გარე აგენტებს, MCP კლიენტებსა და A2A ორკესტრატორებს ასწავლის OmniRoute-ის REST API-ისა და CLI-ის გამოყენებას. [Omni Skills](./SKILLS.md)-ისგან განსხვავებით (რომლებიც OmniRoute-ის შიგნით შესრულებადი LLM ხელსაწყოების განსაზღვრებებია), Agent Skills არის _დოკუმენტაციის კატალოგი_ — სტატიკური markdown, რომლის პირდაპირ დამატებაც შეიძლება აგენტის კონტექსტში.

## მიმოხილვა

კატალოგი შეიცავს **45 Agent Skills-ს** (23 REST API + 21 CLI + 1 კონფიგურაციის სამუშაო პროცესი). თითოეულ უნარს აქვს:

- **კანონიკური ID** (`omni-auth`, `cli-serve` და ა.შ.)
- **SKILL.md** ფაილი `skills/{id}/SKILL.md`-ში, YAML frontmatter-ით (`name`, `description`) + შინაარსობრივად მდიდარი markdown ტექსტით
- OpenAPI სპეციფიკაციიდან და CLI რეესტრიდან მიღებული **REST საბოლოო წერტილები** (API უნარები) ან **CLI ქვეკომანდები** (CLI უნარები)
- რეალურ დროში მიღებისთვის განკუთვნილი **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API-ის აღმოჩენა

| საბოლოო წერტილი              | მეთოდი | აღწერა                                                                  | ავტორიზაცია |
| :--------------------------- | :----- | :---------------------------------------------------------------------- | :---------- |
| `/api/agent-skills`          | GET    | კატალოგის სია (არასავალდებულო `?category=api\|cli\|config&area=<area>`) | არ არის     |
| `/api/agent-skills/{id}`     | GET    | ერთი უნარის მეტამონაცემების მიღება                                      | არ არის     |
| `/api/agent-skills/{id}/raw` | GET    | SKILL.md-ის მიღება `text/markdown` ფორმატში                             | არ არის     |
| `/api/agent-skills/coverage` | GET    | დაფარვის სტატისტიკა (რამდენი SKILL.md ფაილი არსებობს)                   | არ არის     |
| `/api/agent-skills/generate` | POST   | გენერატორის გაშვება (dryRun/prune/onlyIds)                              | მართვა      |

მაგალითი — API-ის ყველა უნარის ჩამონათვალი:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

მაგალითი — ერთი SKILL.md-ის მიღება:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## A2A-ის აღმოჩენა

A2A უნარი `list-capabilities` აბრუნებს 45-ვე უნარის სრულ კატალოგს Markdown ცხრილის არტეფაქტის სახით. გარე ორკესტრატორებს მისი გამოძახება შეუძლიათ შემდეგი გზით:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

პროტოკოლის დეტალებისთვის იხილეთ [A2A-SERVER.md](./A2A-SERVER.md).

```bash

# კონტექსტში ჩასართავად SKILL.md-ის მიღება

```

### 2. აღმოჩენა MCP-ის მეშვეობით

// Claude Desktop / Cursor MCP კლიენტში:
const result = await client.callTool("omniroute_agent_skills_list", {
