> **სანდო პირველწყარო (კატალოგი):** `open-sse/config/freeModelCatalog.ts` (თითოეული მოდელის ბიუჯეტები, საერთო პულების დუბლირების გარეშე). ქვემოთ მოცემული ტოკენების ბიუჯეტები რეალურ დროში ჩატარებულ ვებკვლევას ეფუძნება და **მიახლოებითია** — იხილეთ [მეთოდოლოგია და შენიშვნები](#methodology--caveats).

**რეალისტური მთავარი მაჩვენებელი:** _OmniRoute აერთიანებს **თვეში ~1.62B დოკუმენტირებულ უფასო ტოკენს** (რეგისტრაციის კრედიტების ჩათვლით, პირველ თვეში — ~2.22B-მდე) უფასო ტარიფის 35 პულში — ამას ემატება მუდმივად უფასო, ლიმიტის არმქონე პროვაიდერების გრძელი სია — ხოლო RTK + Caveman შეკუმშვა (ტოკენების 15–95%-იანი დაზოგვა) ამ რესურსს კიდევ უფრო ზრდის._

> **რატომ შემცირდა ეს მაჩვენებელი წინა ~1.94B-დან.** 2026-06-17-ის განახლება სიზუსტის შესწორებაა და არა დანაკარგი: `gemini` ახლა პულის დონეზე დუბლიკატებისგან გაწმენდილია (მანამდე მაჩვენებელი ხელოვნურად იყო გაზრდილი Flash-ის თითოეული ვარიანტის ცალ-ცალკე დათვლით, 462M → 60M), `cloudflare-ai` შესწორდა მის რეალურ 10k-Neurons/დღე ლიმიტამდე (122M → 30M), `doubao` ხელახლა კლასიფიცირდა, როგორც რეგისტრაციისას ერთჯერადი კრედიტი (და არა პერიოდული), ხოლო გაუქმებული ტარიფები ამოიღეს (`chutes`/`phind`/`kluster` შეწყვეტილია). ეს ნაწილობრივ დააბალანსა `llm7`-მა (სწორი 5M/დღე → 150M) და ახალმა უფასო პროვაიდერებმა (Kilo, OpenCode Zen, Z.AI GLM-Flash).

> **v3.8.42-ში დამატებით შესწორდა ~1.37B-მდე:** უფასო საცდელი პერიოდის დასრულების შემდეგ `longcat` ხელახლა კლასიფიცირდა 150M/თვე პერიოდული გრანტიდან რეგისტრაციისას ერთჯერად 10M კრედიტად. მოქმედებს სიზუსტის იგივე წესი — არცერთი პროვაიდერი შეცდომით არ ამოღებულა.

> **განახლებულია 2026-08-26-ს, Felo Web-ის გაუქმების შემდეგ:** Felo Web გამორიცხულია, სანამ მისი GPL-დან ნაწარმოები წარმოშობისა და ლიცენზირების სტატუსი HOLD-ად რჩება; იმ მომენტისთვის წყარო პულის 38 გასაღებს აფიქსირებდა. პულების რაოდენობა დინამიკურია და CI-ით კონტროლდება (`check:docs-counts` აგებას წარუმატებლად ასრულებს, თუ ზემოთ მოცემული რიცხვები `computeFreeModelTotals()`-ის შედეგებს აღარ ემთხვევა).
>
> **2026-09-02-ს ხელახლა შემოწმდა უშუალოდ პროვაიდერების გვერდებთან შედარებით** (წყაროები: `open-sse/config/freeModelCatalog.data.ts`-ში თითოეული ხელახლა შემოწმებული ჩანაწერის გვერდით არსებული `// evidence:` კომენტარები): `gemini` და `ollama-cloud` ტოკენების რაოდენობას აღარ აქვეყნებენ (Google-მა თითოეული მოდელის უფასო ცხრილი 2025-12-23-ს წაშალა; Ollama-ს Free გეგმა არის „starter usage credits“) და ახლა მითითებულია, როგორც **ლიმიტის გარეშე**, ამიტომ ჯამში არასოდეს ითვლება (−80M); `groq`-ს აქვს ხუთი **თითო მოდელზე ცალკე** 200K-TPD ლიმიტი (თითოეული 6M, +15M), ხოლო სამი გაუქმებული ID ამოღებულია; `nara` არის ერთი 7M/დღე პული (+60M, 210M). `mistral`-ის 1B მხოლოდ ანგარიშის კონსოლში ჩანს — იხილეთ მეთოდოლოგიის ქვეშ _მტკიცებულებების კლასები_.
