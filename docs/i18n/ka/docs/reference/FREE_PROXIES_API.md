OmniRoute მოიცავს უფასო პროქსი-სერვერების შერჩეულ ნაკრებს `free_proxies` ცხრილში,
რომელიც სინქრონიზებულია გარე მომწოდებლებთან (1proxy, proxifly, iplocate, webshare).
მართვის პანელში ისინი ნაჩვენებია **Settings → Free Proxies** განყოფილებაში. ეს დოკუმენტი
აღწერს სერვერის მხარეს ფილტრაციას, დახარისხებას, დათვლასა და სინქრონიზაციის შეცდომების
ანგარიშგებას, რომელსაც სიის მარშრუტი უზრუნველყოფს.

## სიის მარშრუტი — `GET /api/settings/free-proxies`

აბრუნებს გაფილტრულ, დახარისხებულ და გვერდებად დაყოფილ ნაწილს, ასევე ჩანაწერების საერთო რაოდენობას. ფილტრაცია და
დათვლა SQL-ში სრულდება, ამიტომ UI-ს შეუძლია რეალური საერთო რაოდენობის ჩვენება (მაგ. `Total: 0`)
ყველა ჩანაწერის მეხსიერებაში ჩატვირთვის გარეშე.

### მოთხოვნის პარამეტრები

| პარამეტრი         | ტიპი                               | ნაგულისხმევი | მნიშვნელობა                                                                                                            |
| ----------------- | ---------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `search`          | სტრიქონი                           | `""`         | რეგისტრზე დამოკიდებული `LIKE` ძიება ჰოსტის (და წყაროს) სვეტში.                                                         |
| `protocol`        | სტრიქონი                           | `""`         | `type` ფილტრი: `http` / `https` / `socks4` / `socks5`. ცარიელი = ყველა.                                                |
| `country`         | სტრიქონი                           | `""`         | `countryCode` ფილტრი (ISO-2). ცარიელი = ყველა.                                                                         |
| `minQuality`      | რიცხვი                             | `0`          | მხოლოდ ის ჩანაწერები, სადაც `qualityScore >= minQuality`. `0` = ქვედა ზღვრის გარეშე.                                   |
| `disabledSources` | სტრიქონი                           | `""`         | გამოსარიცხი წყაროების მძიმით გამოყოფილი id-ები (მაგ. `proxifly,webshare`).                                             |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`    | `quality` = ქულა კლებადობით; `latency` = შეყოვნება ზრდადობით (null-ები ბოლოში); `recent` = `lastValidated` კლებადობით. |
| `offset`          | რიცხვი                             | `0`          | გვერდებად დაყოფის საწყისი პოზიცია.                                                                                     |
| `limit`           | რიცხვი                             | `50`         | გვერდის ზომა (შეზღუდულია სერვერის მხარეს).                                                                             |

### პასუხი

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` ასახავს გაფილტრული ჩანაწერების საერთო რაოდენობას გვერდებად დაყოფამდე, ამიტომ UI-ს შეუძლია
`Total: N`-ისა და `hasMore`-ის ერთმანეთისგან დამოუკიდებლად გამოჩენა. `syncErrors` ინდექსირებულია წყაროს id-ით და
ივსება მხოლოდ იმ წყაროებისთვის, რომელთა ბოლო სინქრონიზაციაც წარუმატებელი იყო — `Total: 0` შედეგი
არასოდეს რჩება განმარტების გარეშე.

## ნაკრებში დამატება — `POST /api/settings/free-proxies/[id]/add-to-pool`

უფასო პროქსი გადააქვს მართულ `proxy_registry` ნაკრებში. თავდაპირველად ამოწმებს
გარე წყაროს; წარმატების შემთხვევაში აბრუნებს ნაკრებში ახალი პროქსის id-სა და გაზომილ შეყოვნებას.

## სინქრონიზაცია — `POST /api/settings/free-proxies/sync`

ხელახლა იღებს მონაცემებს ყველა ჩართული წყაროდან (ან `{ "sources": [...] }`-ში მითითებული ქვესიმრავლიდან). თითოეული
წყარო დამოუკიდებლად სინქრონიზდება; წარუმატებელი წყარო ჩაიწერება `syncErrors`-ში, ხოლო
დანარჩენები მაინც სრულდება, ამიტომ ნაწილობრივი სინქრონიზაცია არასოდეს შლის ადრე მიღებულ გამართულ მონაცემებს.

## სტატისტიკა — `GET /api/settings/free-proxies/stats`

აბრუნებს `total / inPool / avgQuality / bySource / lastSyncAt` აგრეგირებულ მონაცემებს
ჩანაწერების მონაცემების გარეშე — გამოიყენება მართვის პანელის სათაურის ვიჯეტებში.
