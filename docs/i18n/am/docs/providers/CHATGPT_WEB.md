`chatgpt-web-codex` (ተለዋጭ ስም `cgpt-codex`) የCodex Responses ዙሮችን በተረጋገጠ የChatGPT አሳሽ ክፍለ ጊዜ በኩል ያገናኛል። ይህ ከጡረታ ከወጣው የጋራ `chatgpt-web` አቅራቢ ነፃ ሲሆን፣ በ`open-sse/vendor/codex-chatgpt-web/` ስር ያለውን የMIT ማስታወቂያ የያዘ ትግበራ ይጠቀማል፤ ይህም በዋናው ምንጭ v4.0.7 commit `b59d7dc51b84fb1f465ff1d00f5207f3b2b4a494` ታድሷል።

## የጋራ አቅራቢው ከአገልግሎት መውጣት

የቀድሞዎቹ የጋራ አቅራቢ መለያዎች `chatgpt-web` እና `cgpt-web` ከእንግዲህ አይቀርቡም፤ ምክንያቱም የpre-key/proof-of-work ትግበራቸው መነሻ ሊረጋገጥ አልቻለም። በስላሽ የሚጀምሩ የሞዴል መለያዎችን እና የተቀመጡ ተለዋጭ ስሞችን ጨምሮ፣ ወደ ሁለቱም መለያዎች የሚደረጉ ግልጽ ጥያቄዎች ማንኛውም ወደ ላይኛው ምንጭ የሚላክ ጥያቄ ከመኖሩ በፊት በHTTP `410` እና **PROVIDER_RETIRED** ኮድ ዝግ ሆነው ይከሽፋሉ።

ማይግሬሽን `168_retire_chatgpt_web.sql` ተዛማጅ የአቅራቢ ግንኙነቶችን እንደተሰረዙ ምልክት ያደርጋል እና ንቁ የክፍለ ጊዜ ፈቃዶቻቸውን ዋጋ አልባ ያደርጋል። የግንኙነት ታሪክን እና የAPI ቁልፍ ፍቃድ ዝርዝሮችን ይጠብቃል፤ በፍቃድ ዝርዝር ላይ ምትክ መዳረሻ አይጨምርም። የCodex አቅራቢው እና ግንኙነቶቹ በዚህ ከአገልግሎት ማውጣት አይነኩም።

## ቅድመ ሁኔታዎች

- ወደ ChatGPT ከገባ ክፍለ ጊዜ የተገኘ ሙሉ Cookie ራስጌ፤
- ለnpm፣ systemd እና PM2 ጭነቶች Chrome ወይም Chromium፣ ከግራፊክ ክፍለ ጊዜ ወይም Xvfb ማሳያ ጋር፤
- ከDocker `web` መገለጫ ጋር፣ ከ`docker-compose.yml` የሚገኘው ውስጣዊ Chromium አገልግሎት፤
- ለአካባቢያዊ Codex መሣሪያዎች OpenAI `tunnel-client` v0.0.13 እና የChatGPT ብጁ አገናኝ።

ቱነሉ የሚያስፈልገው መሣሪያ ለሚጠቀሙ ዙሮች ብቻ ነው። `pro`ን ጨምሮ በዝርዝሩ ያለው እያንዳንዱ መስመር፣ ቱነሉ እና አገናኙ ሲዋቀሩ ከዙሩ ጋር የተሳሰረውን ተመሳሳይ የአካባቢ መሣሪያ ችሎታ መጠቀም ይችላል።

## የዳሽቦርድ ማዋቀር

1. የ**ChatGPT Web (Codex)** አቅራቢውን ይክፈቱ እና ግንኙነት ያክሉ።
2. ሙሉውን የChatGPT Cookie ራስጌ፣ የቱነል መለያ፣ የአሂድ ጊዜ ቁልፍ እና የብጁ አገናኙን ስም ይለጥፉ። አዲስ መሣሪያ-ተኳኋኝ ማዋቀሪያዎች በትክክል `OmniRoute Codex v2` የተባለ አዲስ የተፈጠረ አገናኝ መጠቀም አለባቸው፤ Authentication ወደ None እና Permissions ወደ Allow all actions መዋቀር አለባቸው።
3. የግንኙነት ማረጋገጫውን ያሂዱ። OmniRoute በአሳሽ የሚደገፍ Temporary Chat ይከፍታል እና Sol እና Pro ለመለያው መገኘታቸውን ያረጋግጣል።
4. ግንኙነቱን ያስቀምጡ። OmniRoute የተለጠፈውን cookie በተረጋገጠው የPlaywright ማከማቻ ሁኔታ ይተካል እና ከአሂድ ጊዜ ቁልፉ ጋር በተመሰጠረው የምስክርነት መረጃ ማጠቃለያ በኩል ያከማቸዋል።

የተሳካ ማስቀመጥ ከተከናወነ በኋላ ጥሬው cookie አይቀመጥም። ክፍለ ጊዜው ሲያበቃ፣ ግንኙነቱን ይክፈቱ፣ አዲስ ሙሉ Cookie ራስጌ ይለጥፉ እና ማረጋገጫውን እንደገና ያሂዱ። በአርትዖት መገናኛ ሳጥኑ ውስጥ ያለው የdoctor ሁኔታ፣ የአሳሽን፣ የማከማቻ ሁኔታን፣ የመግባትን፣ Temporary Chatን፣ ቱነልን፣ አገናኝን እና የመሣሪያ ዙር-ጉዞን ለየብቻ ሪፖርት ያደርጋል።

- ChatGPT በእያንዳንዱ ተራ ለአጭር ጊዜ የሚቆይ ችሎታ ብቻ ይቀበላል። የMCP ደላላው
  Codex በዚያው ትክክለኛ ተራ ያቀረባቸውን መሣሪያዎች ብቻ ይቀበላል።
- **Allow once**ን በራስ-ሰር ማረጋገጥ የመሣሪያውን ጥያቄ ወደ Codex ብቻ ይመልሳል። Codex ብቻ
  ስለማጽደቅ እና ስለማስፈጸም ይወስናል።
- ከመጀመሪያው ውጤት በፊት፣ አንድ ጥምረት ወደ ሌላ ተኳሃኝ ዒላማ ሊመለስ ይችላል። ውጤት
  ከጀመረ በኋላ፣ provider፣ model፣ connection እና browser turn ተራው እስኪጠናቀቅ ድረስ
  ተቆልፈው ይቆያሉ።
- Cookies፣ runtime keys፣ storage state እና capability tokens በprovider
  ምላሾች ወይም በጥያቄ ምዝግቦች ውስጥ አይታዩም።

## ማሳያ የሌለው VPS እና Docker

ለnpm፣ systemd እና PM2 ጭነቶች፣ OmniRoute የተለመዱ የChrome እና Chromium መንገዶችን ይለያል።
እንደ አማራጭ፣ `CHATGPT_WEB_CODEX_CHROME_PATH`ን ያዘጋጁ። ChatGPT እውነተኛ-headless የአሳሽ ቅርጽን ስለማይቀበል፣ runtime turns ሆን ብለው ማሳያ ያለው
Chrome ይጠቀማሉ። ስለዚህ ማሳያ የሌለው host OmniRouteን በግላዊ Xvfb ማሳያ ማስኬድ
አለበት፤ የChromeን መንገድ ብቻ ማዘጋጀት ማሳያ አያቀርብም።

የDocker `web` profile በውስጣዊው Compose
አውታረ መረብ ላይ `chatgpt-web-codex-browser`ን ያስጀምራል። sidecar በXvfb ውስጥ ማሳያ ያለው Chromeን ያስኬዳል፣ ስለዚህ አካላዊ ማሳያ አያስፈልግም። የእሱ CDP
port በhost ላይ አይታተምም። የተጠበቀው የbrowser profile volume ከ
OmniRoute data volume የተለየ ሲሆን፣ browser በቂ shared memory ይቀበላል። ውስጣዊው CDP proxy
በCompose አውታረ መረብ ውስጥ በport `9223` ብቻ ያዳምጣል፤ Chrome በ
sidecar ውስጥ ከloopback ጋር እንደተሳሰረ ይቆያል።

በ`DATA_DIR` ስር ያለ supervisor lease በርካታ OmniRoute processes ተመሳሳይ tunnel እና broker stateን እንዳይቆጣጠሩ ይከላከላል። ግጭት በdoctor ሪፖርት ይደረጋል።

## መስተጋብራዊ መልሶ ማግኛ

ራስ-ሰር የሆነው የDocker መንገድ ለhost የሚታይ መስኮት የለውም፣ ነገር ግን Chrome ራሱ በግላዊው
Xvfb ማሳያ ውስጥ ማሳያ ያለው ነው። ChatGPT መስተጋብራዊ መግቢያ ወይም challenge ሲፈልግ፣ ነባሩ የVNC
browser infrastructure ለመልሶ ማግኛ ጥቅም ላይ ሊውል ይችላል። Browser UI እና CDP በloopback፣ ማንነት በተረጋገጠ management connection ወይም SSH tunnel ብቻ ተደራሽ ሆነው መቆየት
አለባቸው፤ noVNC በመደበኛ አሠራር ጊዜ እንደተሰናከለ ይቆያል።
