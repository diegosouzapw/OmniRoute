የ`agentrouter` የላይኛው ጌትዌይ በ`messages[].content` ላይ በቁልፍ ቃላት ላይ የተመሠረተ የይዘት ማጣሪያ ያስኬዳል። ማጣሪያው በከፊል ቆራጥ ነው (የተወሰኑ ሐረጎችን ሁልጊዜ ያግዳል) እና በከፊል ዕድላዊ ነው (ለተከታታይ ፈጣን ጥያቄዎች ስሱ ነው — ከፈጣን ጥያቄዎች በኋላ የበለጠ ጥብቅ ይሆናል፣ ከማቀዝቀዣ ጊዜ በኋላም ወደ መደበኛ ሁኔታው ይመለሳል)።

WAF አንድን ጥያቄ ሲያግድ የሚከተለውን ይመልሳል፦

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## የማጣሪያው ወሰን

WAF `messages[].content`ን ብቻ ይመረምራል። የሚከተሉትን **አይመረምርም**፦

- የ`system` መጠየቂያ
- የተዋቀሩ የይዘት ብሎኮች (`tool_result`፣ `tool_use`፣ `thinking`፣ `image`)
- የመሣሪያ `description` እና `input_schema` መስኮች
- የጥያቄ ሜታዳታ፣ ራስጌዎች ወይም የሞዴል መለያ

## ሁልጊዜ የሚታገዱ ንድፎች (የፊደል መጠን ልዩነትን የማይመለከት)

| ንድፍ                         | ማስታወሻዎች                                             |
| --------------------------- | --------------------------------------------------- |
| ማንኛውም የ`Lorem ipsum` ልዩነት   | ሙሉው የላቲን lorem የቃላት ስብስብ ይታገዳል                      |
| `language model` (ብቻውን)     | "the language model" እና "large language model" ያልፋሉ |
| `virtual assistant`         | "AI assistant" ያልፋል                                 |
| `I'm here to help`          | "here to help" ብቻውንም ይታገዳል                          |
| `Claude, made by Anthropic` | ሙሉው ሐረግ ብቻ                                          |

## ከሞላ ጎደል ሁልጊዜ የሚታገዱ ንድፎች

| ንድፍ                                               | ማስታወሻዎች                          |
| ------------------------------------------------- | -------------------------------- |
| `placeholder`                                     | ብቻውን ሲቀርብ (እንደ መለኪያ ስም ወዘተ ሳይሆን) |
| `dummy data`                                      | ለመሞከሪያ ውሂብ የተለመደ የመነሻ ሐረግ        |
| `foo bar baz`                                     | የተለመደ የቦታ መያዣ ሐረግ                |
| የተደጋገሙ አጭር ቶከኖች (`AAA BBB CCC`፣ `test test test`) | የቁልፍ ቃላት መደርደር መመርመሪያ            |

## በከፍተኛ ጭነት ጊዜ ያለው ባህሪ

በአጭር የጊዜ መስኮት ውስጥ ከ~~5 ፈጣን ጥያቄዎች በኋላ፣ WAF በመደበኛነት የሚያልፍ ይዘትን ማገድ ይጀምራል። ባኬቱ ከ~~5–10 ሰከንዶች የእረፍት ጊዜ በኋላ ይላላል። ይህ፣ Claude Code ወይም Codex CLI በፍጥነት ተከታታይ የመሣሪያ አጠቃቀም / የመልዕክት መላኪያ ጥሪዎችን ሲያደርጉ፣ አልፎ አልፎ የ`400 content-blocked` ስህተቶችን የሚያስከትለው በIP እና በቁልፍ የተያያዘው ተመሳሳይ የጥያቄ መጠን ገዳቢ ነው።

## በOmniRoute ውስጥ አስቀድመው የተተገበሩ ማቃለያዎች

1. **`open-sse/services/wafRateLimit.ts`** — ወደ ማንኛውም `agentrouter:*` URL በሚላኩ ጥያቄዎች መካከል የ500 ms ዝቅተኛ ክፍተትን የሚያስገድድ የተከታታይ ፈጣን ጥያቄዎች መከላከያ። ክፍተቱ በሰው ልጅ ከሚስተዋለው መዘግየት እጅግ ያነሰ ሲሆን፣ WAF በመደበኛ ትራፊክ ላይ እንዳይነቃ ይከላከላል።

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — የላይኛው አገልግሎት `400 content-blocked`ን ሲመልስ፣ አስፈጻሚው በኤክስፖኔንሺያል መዘግየት (1.5 s፣ 3.0 s፣ ከፍተኛው 2 ሙከራዎች) ተመሳሳዩን URL እንደገና ይሞክራል። ከመዘግየቱ በኋላ WAF ብዙውን ጊዜ ይላላል እና ድጋሚ ሙከራው ይሳካል።

3. **`tests/unit/compression/harness.test.ts`** — የመሞከሪያ ውሂብ `longInput` ከ`"lorem ipsum dolor sit amet ".repeat(40)` ወደ `"example content for testing purposes ".repeat(40)` ተቀይሯል፤ በዚህም Claude Code ይህን ፋይል በ`Read` መሣሪያ ሲያነብ፣ የፋይሉ ይዘቶች በ`tool_result` ብሎክ በኩል ተመልሰው እንዳይፈሱ እና WAFን እንዳያስነሱ ተደርጓል።

## ለመጠየቂያዎች እና ለመሣሪያ ውጤት መመሪያ

አንድ Claude Code ወይም Codex CLI ክፍለ ጊዜ `400 content-blocked`ን በተደጋጋሚ ካጋጠመው፣ በጣም የቅርብ ጊዜውን የተጠቃሚ መልዕክት እና በጣም የቅርብ ጊዜውን የመሣሪያ ውጤት ከላይ ካሉት ንድፎች ለማንኛውም ይፈትሹ እና በሌላ አገላለጽ ይጻፉት። የተለመዱ መፍትሔዎች፦

- `Lorem ipsum …`ን በ`example text …` ወይም ፈተናው ወይም የመሞከሪያ ውሂቡ ለመወከል በሚሞክረው እውነተኛ ይዘት ይተኩ።
- `placeholder`ን (ብቻውን ሲቀርብ) በ`example value`፣ `sample value` ወይም በእውነተኛው እሴት ይተኩ።
- `language model`ን በ`large language model` ወይም `the model` ይተኩ።
- `dummy data`ን በ`sample data` ወይም በእውነታዊ የመነሻ እሴቶች ይተኩ።
- `I'm here to help` / `here to help`ን ይበልጥ በተወሰነ የመክፈቻ ሐረግ ይተኩ (ለምሳሌ፣ "I'll review the file you mentioned")።

## የተሳሳቱ አዎንታዊ ውጤቶችን ለላይኛው አገልግሎት ማሳወቅ

የአሁኑ ማጣሪያ ከመጠን በላይ ጥብቅ ነው — ኦፕሬተሩ መጠየቂያ ለማስገባት እንዳላሰበ ግልጽ ቢሆንም፣ በ`tool_result` ብሎኮች ውስጥ "Lorem ipsum"ን ያግዳል። ይህ ከምንጩ እንዲስተካከል የሚፈልጉ ኦፕሬተሮች የተሳሳቱ አዎንታዊ ውጤቶችን ለማሳወቅ `agentrouter.org`ን ማነጋገር አለባቸው። ከላይ ያለው የእገዳ ዝርዝር እስከ 2026-08-03 ድረስ የላይኛውን አገልግሎት በመፈተሽ የተገኘ ተጨባጭ ውጤት ነው።
