> **ዳሽቦርድ:** ቅንብሮች → **AI** → የአስተሳሰብ በጀት  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **ምንጭ:** `open-sse/services/thinkingBudget.ts`

የአስተሳሰብ በጀት OmniRoute ወደ አቅራቢዎች በሚልክበት ጊዜ **የደንበኛውን የአስተሳሰብ/የምክንያታዊ ትንተና መለኪያዎች እንደገና ይጽፍ እንደሆነ** ይቆጣጠራል። መጭመቅን፣ ማዘዋወርን ወይም የጥያቄ መሸጎጫን አያበራም ወይም አያጠፋም።

## ሁነታዎች

| ሁነታ                     | OmniRoute የሚያደርገው                                                                                              | መቼ መጠቀም እንደሚገባ                                                                                                                        |
| ----------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (ነባሪ) | የደንበኛውን መስኮች ሳይቀይር ይተዋል (`reasoning`፣ `reasoning_effort`፣ የClaude `thinking`፣ የGemini `thinking_config`፣ ወዘተ)። | **Codex / Desktop / ጥረትን እና የምክንያታዊ ትንተና ማጠቃለያዎችን መቆጣጠር ያለበት ማንኛውም ደንበኛ።** ደንበኛው `reasoning.summary`ን ሲጠይቅ የአስተሳሰብ ፓነሎች እንዲታዩ ያስፈልጋል። |
| **`auto`**              | ወደ ዋናው አቅራቢ ከመላኩ በፊት **ሁሉንም** የአስተሳሰብ/የምክንያታዊ ትንተና መስኮች ከጥያቄው ይሰርዛል።                                           | **አቅራቢው** ነባሪ እሴቶችን እንዲወስን ሆን ብለው ሲፈልጉ እና በደንበኛ የሚቆጣጠር አስተሳሰብ በማያስፈልግዎት ጊዜ ብቻ። “አስተሳሰብን በራስ-ሰር አሳይ” ማለት **አይደለም**።                    |
| **`custom`**            | እያንዳንዱን ጥያቄ በቋሚ የአስተሳሰብ ቶከን በጀት ይተካል።                                                                          | ለሁሉም ትራፊክ በአስተሳሰብ ቶከኖች ላይ ጥብቅ ገደብ ለማድረግ።                                                                                              |
| **`adaptive`**          | የመልዕክት ብዛትን፣ መሣሪያዎችን እና የጥያቄውን ርዝመት በመጠቀም በጀቱን ከመሠረታዊ ጥረት ያመጣጥናል።                                              | የደንበኛውን ዓላማ ሙሉ በሙሉ ሳያስወግዱ ቶከኖችን ለስላሳ ቁጥጥር ለማድረግ።                                                                                      |

### `auto` የሚያስወግደው

ሁነታው `auto` ሲሆን፣ `stripThinkingConfig()` ከሌሎች ጋር የሚከተሉትን ይሰርዛል፦

- OpenAI / Responses: `reasoning`፣ `reasoning_effort`
- Claude: `thinking`፣ እንዲሁም በሚገኝበት ጊዜ `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

አንድ ደንበኛ (ለምሳሌ Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` ከላከ፣ **auto ያንን ኦብጀክት ያስወግዳል**። ዋናው አቅራቢ አሁንም ለአንዳንድ የምክንያታዊ ትንተና ቶከኖች ክፍያ ሊያስከፍል ይችላል፣ ነገር ግን ብዙውን ጊዜ **ባዶ ወይም የተመሰጠሩ-ብቻ** የሆኑ የምክንያታዊ ትንተና ንጥሎችን ይመልሳል — ስለዚህ UIው ጠቃሚ የአስተሳሰብ ዥረት አያሳይም።

## የሚታይ አስተሳሰብ (Codex / Responses ደንበኞች)

አንድ ደንበኛ የአስተሳሰብ ጽሑፍን እንዲያሳይ **እነዚህ ሁሉ** ያስፈልጋሉ፦

1. Thinking Budget ሁነታ = **`passthrough`** (ወይም ለሚጠቀሙበት መንገድ የማጠቃለያ ጥያቄዎችን በበቂ ሁኔታ ሳይቀይር የሚያስቀር custom/adaptive)።
2. ደንበኛው ማጠቃለያ መጠየቅ አለበት፣ ለምሳሌ Codex `model_reasoning_summary = "detailed"` / `auto` (`none` ሳይሆን)።
3. Upstream በተጨባጭ `response.reasoning_summary_text.*` በዥረት ማስተላለፍ አለበት (ወይም በንጥሉ ላይ ባዶ ያልሆነ `reasoning.summary` መኖር አለበት)።

“የተመሰጠረ የግል አስተሳሰብ” ብቻ ከደረሰዎት፣ ምክንያቱ ከሚከተሉት አንዱ ነው፦

- ሁነታው **`auto`** ነበር (የደንበኛው ጥያቄ ተወግዷል)፣ ወይም
- Upstream ያለ ማጠቃለያ ጽሑፍ `encrypted_content` መልሷል (የአቅራቢ ገደብ፤ OmniRoute ማሳየት የሚችለው ቦታ ያዥ ብቻ ነው፣ ግልጽ ጽሑፍን አይደለም)።

## የAPI ምሳሌዎች

```bash
# አንብብ
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# ለCodex / Desktop የአስተሳሰብ ታይነት የሚመከር
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Schema (`updateThinkingBudgetSchema`)፦ `mode` ∈ `passthrough|auto|custom|adaptive`፤ አማራጭ `customBudget`፣ `effortLevel`፣ `baseBudget`፣ `complexityMultiplier`።

### ቋሚነት / ዳግም ማስጀመር

እሴቱ `thinkingBudget` በተባለው የቅንብሮች ቁልፍ ስር ይከማቻል፣ እና ሂደቱ ሲጀምር ይጫናል (`hydrateThinkingBudgetConfig`)። በDB ወይም API ባልሆኑ አንዳንድ መንገዶች ከቀየሩት በኋላ፣ በማህደረ ትውስታ ያለው singleton በዲስክ ላይ ካለው ጋር እንዲዛመድ **የOmniRoute ሂደቱን ዳግም ያስጀምሩ**።

## የኦፕሬተር ማረጋገጫ ዝርዝር

- [ ] Codex / Desktop ተጠቃሚዎች፦ ሁነታ = **passthrough**
- [ ] አስተሳሰብን በማስወገድ ሳይሆን በ**መልዕክቶች** ላይ የቶከን ቁጠባ ከፈለጉ Compression እንደነቃ ይቆይ
- [ ] `auto` “የበለጠ አስተሳሰብ እንዲያሳይ” አይጠብቁ
- [ ] የተመሰጠሩ-ብቻ ማጠቃለያዎች የ**አቅራቢ** ባህሪ ናቸው፤ passthrough ዲክሪፕት ሊያደርጋቸው አይችልም
