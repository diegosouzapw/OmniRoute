ጥያቄ አንዱ በተሳካ ሁኔታ ምላሽ እስኪሰጥ ድረስ በቅደም ተከተል በእነሱ ውስጥ ያልፋል — ምንም
የመጠባበቂያ ኮድ ሳይጽፉ በጣም ርካሹን ተግባራዊ ምላሽ ያገኛሉ።

## ደረጃ 1 — የደንበኝነት ምዝገባ

**አስቀድመው ክፍያ የሚፈጽሙላቸው አቅራቢዎች።** OmniRoute የኮታው ጊዜ ከማለቁ በፊት
እያንዳንዱን የኮታ ክፍል ይጠቀማል።

| ----------------------------------- | ------------------------------------------------- |

| OpenAI Codex (የChatGPT ደንበኝነት ምዝገባ) | Plus/Team የCodex ኮታን ያካትታል                        |

የኮታ መከታተያው እየቀረቡ ያሉ ዳግም መጀመሪያዎችን ይከታተላል፣ እና `reset-aware`
ጥምር ስልትም በዚሁ መሠረት ቅድሚያ ይሰጣል። መጀመሪያ ወደ ደረጃ 1 ለማስተላለፍ እና ኮታው
ሲያልቅ ብቻ ወደ ክፍያ ደረጃዎች ለመሸጋገር `auto/thrifty` idን ይጠቀሙ — ወይም በዕቅዱ
ውስጥ በተካተተው አቅም ላይ ለመቆየትና ካልተገኘ ጥያቄውን ዝግ ለማድረግ `auto/subscription`ን
ይጠቀሙ። [ለደንበኝነት ምዝገባ ቅድሚያ የሚሰጥ ማስተላለፍ](../routing/SUBSCRIPTION_LADDER.md)ን ይመልከቱ።

ዳሽቦርድ → **ደረጃዎች** → አቅራቢዎችዎን ይመድቡ። ነባሪዎቹ (ከ`tierDefaults.json`) ምክንያታዊ
ናቸው፤ ቅድሚያ ሊሰጧቸው የሚፈልጓቸው የተወሰኑ የደንበኝነት ምዝገባዎች ወይም ሊያስወግዷቸው የሚፈልጓቸው አቅራቢዎች ሲኖሩ ያርትዑ።

## ቴሌሜትሪ

ዳሽቦርድ → **አጠቃቀም** በየቀኑ በእያንዳንዱ ደረጃ የወጡትን ቶከኖች ያሳያል። ይህን ለሚከተሉት ይጠቀሙ፦

- ደረጃ 1 ሙሉ በሙሉ ጥቅም ላይ መዋሉን ያረጋግጡ (ካልሆነ የደንበኝነት ምዝገባ ዋጋን እያባከኑ ነው)
- የትኞቹ የደረጃ 2 ሞዴሎች በብዛት እንደሚመረጡ ይለዩ (ወደ 1-2 ያጠቃልሉ)
- ደረጃ 3 በሙከራ/ዳሰሳ የሥራ ጫናዎች ላይ ገንዘብ እንደሚቆጥብ ያረጋግጡ

## የተለመዱ ንድፎች

### ሙሉ በሙሉ ነፃ የሥራ ጫና

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

በጥብቅ ወደ ደረጃ 3 ያዘነብላል፤ ደረጃ 3 የማይገኝ ከሆነ ብቻ ደረጃ 2ን ይጠቀማል።

### ለደንበኝነት ምዝገባ ቅድሚያ ከሚሰጥ ርካሽ መጠባበቂያ ጋር

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

ከደረጃ 1 → ደረጃ 2 → ደረጃ 3 ጋር የሚዛመድ በግልጽ የተደረደረ ዝርዝር።
