## ማዋቀር

1. **OmniRouteን ያስኪዱ** — `npm install -g omniroute && omniroute` (ዳሽቦርዱ `http://localhost:20128` ላይ ነው)።
2. **ቅጥያውን ይጫኑ** — በExtensions እይታ ውስጥ "OmniRoute" ብለው ይፈልጉ።
3. **ሞዴል ይምረጡ** — Copilot Chat → የሞዴል መምረጫ → **ሞዴሎችን ያስተዳድሩ…** → **OmniRoute**፣ ከዚያ የሚፈልጉትን ምልክት ያድርጉበት።

OmniRoute በነባሪው ወደብ ላይ ሲሰራ የሚዋቀር ነገር የለም። ለርቀት ምሳሌ፣
**በActivity Bar ውስጥ ያለውን የOmniRoute አዶ ይክፈቱ** (ወይም `OmniRoute: Manage Connection`ን ያስኪዱ) እና የሚከተሉትን ያዋቅሩ፦

- **የሰርቨር URL** — የሰርቨሩ ስር፣ ለምሳሌ `http://192.168.0.15:20128`። የ`/v1` ቅጥያ
  በቅጥያው በራስ-ሰር ይጨመራል፤ እርስዎ አያካትቱት።
- **የAPI ቁልፍ** — ሰርቨሩ `REQUIRE_API_KEY`ን ሲያዘጋጅ ብቻ። በVS
  Code SecretStorage በኩል በስርዓተ ክወናው የቁልፍ ማከማቻ ውስጥ ይቀመጣል፤ በ`settings.json` ውስጥ ፈጽሞ አይቀመጥም።

## መምረጫው የሚያሳየው

ቅጥያው ጥሬውን የ`GET /v1/models` ውሂብ አያሳይም — ቅርጽ ይሰጠዋል፣ እና የሚያዩት ብዛት
ከካታሎጉ መጠን ያነሰ የሚሆነው ሆን ተብለው በተደረጉ ሁለት ምክንያቶች ነው።

### ለእያንዳንዱ ሞዴል አንድ id ይጠይቃል

`MODELS_CATALOG_PREFIX_MODE` በነባሪ **`dual`** ነው፣ ይህም እያንዳንዱን ሞዴል ሁለት ጊዜ ያስተዋውቃል — አንድ ጊዜ
በአጭሩ ተለዋጭ ቅድመ ቅጥያ እና አንድ ጊዜ በመደበኛው የአቅራቢ ቅድመ ቅጥያ — ስለዚህ የቆዩ የደንበኛ
ውቅሮች ከሁለቱም ቅርጾች ማናቸውንም ማግኘት ይቀጥላሉ፦

```
cc/claude-sonnet-4-6        ← ተለዋጭ ቅድመ ቅጥያ
claude/claude-sonnet-4-6    ← መደበኛ ቅድመ ቅጥያ፣ ተመሳሳይ ሞዴል
```

ቅጥያው **`GET /v1/models?prefix=alias`**ን ይጠይቃል፤ በዚህም ለሌሎች ደንበኞችዎ በሰርቨር ደረጃ ያለውን ቅንብር ሳይቀይር
ለእያንዳንዱ ሞዴል አንድ id ይመጣል። በማጣቀሻ ምሳሌ ላይ ይህ
**2345 ግቤቶችን ወደ 1396 አሳንሷል — 949 ድግግሞሾች፣ የጠፋ ሞዴል ዜሮ።**

በምትኩ ይህን በሰርቨር ደረጃ ለ_እያንዳንዱ_ ደንበኛ ማስተካከል ከፈለጉ፣ በዳሽቦርዱ ውስጥ የ
`MODELS_CATALOG_PREFIX_MODE` ባህሪ ጠቋሚን ወደ `alias` ያዘጋጁ። ለመጠይቅ
መለኪያው እና ለእያንዳንዱ ሁነታ ሰንጠረዥ [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix)ን ይመልከቱ።

### መወያየት የማይችሉ ሞዴሎችን ይደብቃል

ካታሎጉ የምስል፣ ቪዲዮ፣ ድምፅ፣ ዳግም ደረጃ ሰጪ፣ embedding እና የይዘት ክትትል ሞዴሎችንም ይዘረዝራል። እነዚህ
በውይይት ጥያቄ ላይ ለማንኛውም ውድቅ ይደረጋሉ፦

```
HTTP 400 — ሞዴል '<id>' የምስል-ማመንጫ ሞዴል ስለሆነ በ
/v1/chat/completions ላይ ጥቅም ላይ ሊውል አይችልም። በምትኩ POST /v1/images/generationsን ይጠቀሙ።
```

ስለዚህ ወደ መምረጫው ከመድረሳቸው በፊት በ`type` መስካቸው መሠረት ይጣራሉ። **የResponses-API
ሞዴሎች ይቀመጣሉ** — እያንዳንዱ Codex / GPT-5.x ግቤት `supported_endpoints: ["responses"]`ን ያስተዋውቃል፣
እና OmniRoute እነዚያን ለ`/v1/chat/completions` ይተረጉማል፣ ስለዚህ ሙሉ በሙሉ ጥቅም ላይ ሊውሉ ይችላሉ።

### ፈጽሞ ያላዋቀሯቸው አቅራቢዎች

ካታሎጉ **ንቁ ግንኙነት** ካላቸው አቅራቢዎች የመጡ ሞዴሎችን _እና_ ሁሉንም **noAuth**
አቅራቢዎችን — የነፃውን ደረጃ አብዛኛውን የሚያካትቱ ቁልፍ አልባ አቅራቢዎችን — ይዘረዝራል። ይህ ሆን ተብሎ የተደረገ ነው። እነሱን ለመደበቅ
በዳሽቦርዱ ቅንብሮች ውስጥ ወደ `blockedProviders` ያክሏቸው፤ በቅጥያው ውስጥ ምንም ነገር አይቀየርም።

## በVS Code ትር ውስጥ ያለ Dashboard

`omnicopilot.dashboardOpen: "editor"` የOmniRoute dashboardን በውጫዊ browser ፈንታ በSimple Browser በኩል በeditor ትር ውስጥ ያሳያል። ማካተት **በserver ላይ በምርጫ የሚነቃ** ሲሆን፣ ይህም በ`DASHBOARD_ALLOW_EMBED=vscode` ይከናወናል፤ የHTML ገጾቹን በነባሪው `frame-ancestors 'none'` +
`X-Frame-Options: DENY` ፈንታ በ`frame-ancestors 'self' vscode-webview:` ያቀርባል። የAPI ወሰን (`/api`፣ `/v1`፣ `/v1beta`፣ `/a2a`፣ `/healthz`) በሁለቱም ሁኔታዎች ጥብቅ headersን እንዳሉ ይጠብቃል።

> ⚠️ **ይህ የbuild ጊዜ flag ነው፣ የruntime አይደለም።** Next.js `headers()`ን ወደ route
> manifest ያጠናቅራል፣ ስለዚህ bundleው በሚገነባበት ጊዜ `next.config.mjs` variableውን ያነባል
> (`next.config.mjs` → `resolveDashboardEmbedMode`፣ `scripts/build/dashboardEmbed.mjs`)።
> ቀድሞ በተገነባ server ፊት ለፊት variableውን export ማድረግ ምንም ነገር አይቀይርም — headersዎቹ በbuildው ውስጥ ተካትተዋል።

```bash
# variableው በBUILD command ላይ መኖር አለበት
DASHBOARD_ALLOW_EMBED=vscode npm run build        # ወይም npm run build:release
npm start
```
