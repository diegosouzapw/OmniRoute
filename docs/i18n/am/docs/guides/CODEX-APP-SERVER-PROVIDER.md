OmniRoute OpenAI Codexን ለመጠቀም **ሁለት** መንገዶችን ያቀርባል፦

| አቅራቢ                   | ከOpenAI ጋር የሚገናኝበት መንገድ                                                                                                                              | የአጠቃቀም ገደብ                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **`codex`**            | የChatGPT/OpenAI OAuth ቶከንዎን በቀጥታ ወደ Responses API ደግሞ ይልካል                                                                                           | **አዎ** — ይፋዊው ክፍለ-ጊዜ ለፕሮክሲ/ራውተር አጠቃቀም ፈቃድ የለውም |
| **`codex-app-server`** | የ**Codex CLI የራሱን `codex app-server`** በJSON-RPC/WebSocket ያንቀሳቅሳል፤ CLIው ልክ እንደ በይነተገናኝ `codex` ክፍለ-ጊዜ የራሱን OAuth (`~/.codex/auth.json`) ይዞ በራሱ ያድሳል | **አይ** — OmniRoute ቶከንን ወደ API በፍጹም ደግሞ አይልክም  |

`codex-app-server` ቶከንን ደግሞ ስለማይልክ፣ የክፍለ-ጊዜ ድጋሚ-መላክ
የአጠቃቀም ገደቡ አይመለከተውም። ነገር ግን፣ **በተዋቀረው app-server
URL ላይ ሊደረስበት የሚችል Codex CLI** ያስፈልገዋል፣ እና CLIው **በመለያ መግባት** አለበት።

## 1. አርክቴክቸር

```
┌─ OmniRoute መተግበሪያ ──────────────┐        ┌─ codex-app-server የጎን ኮንቴይነር ─────┐
│  CodexAppServerExecutor          │  WS    │  codex app-server                   │
│  ws://codex-app-server:1456 ─────┼───────▶│  --listen ws://0.0.0.0:1456         │
│  (+ የችሎታ ቶከን)                  │  JSON  │  --ws-auth capability-token         │
│                                  │  RPC   │  OpenAI OAuthን በራሱ ያስተዳድራል       │
└──────────────────────────────────┘        │  (~/.codex/auth.json, ራስ-ሰር ዕድሳት) │
        │ ይጋራል (compose volumes)           └─────────────────────────────────────┘
        ▼
  codex-appserver-token   → የWS ችሎታ ቶከን (ሁለቱም ይሰቅሉታል)
  codex-appserver-home    → ~/.codex (auth.json በዳሽቦርዱ ይጻፋል፣
                             በጎን ኮንቴይነሩ codex app-server ይነበባል)
```

- የጎን ኮንቴይነሩ ከችሎታ ቶከን ጀርባ **በውስጣዊው compose አውታረ መረብ ላይ ብቻ**
  (`ws://codex-app-server:1456`) ጥያቄዎችን ይቀበላል። ለአስተናጋጁ ወይም ለበይነመረብ
  **ፈጽሞ** አይጋለጥም።
- Codex CLI በ`omniroute:base` ውስጥ አስቀድሞ ተካትቷል፤ ስለዚህ የጎን ኮንቴይነሩን
  ሲያስኬዱ በአስተናጋጁ ወይም በተጠቃሚው ማሽን ላይ codexን መጫን አያስፈልግም።

## 2. ማስነሳት

```bash
# ስብስቡን ከcodex app-server የጎን ኮንቴይነር መገለጫ ጋር ያስጀምሩ፦
docker compose --profile base --profile codex-app-server up -d
# (podman፦ podman compose --profile base --profile codex-app-server up -d)
```

የጎን ኮንቴይነሩ በመጀመሪያው መነሳት የWS ችሎታ ቶከኑን ያመነጫል (ወደ የጋራ
`codex-appserver-token` volume)፣ መተግበሪያውም ተመሳሳዩን ቶከን
በ`OMNIROUTE_CODEX_APPSERVER_WS_TOKEN_FILE` ያነባል። ቶከኑን በእጅ ማገናኘት አያስፈልግም።

## 3. መገናኘት + በመለያ መግባት

1. በዳሽቦርዱ ውስጥ ለ**OpenAI Codex (App-Server)** ግንኙነት ያክሉ። ምንም API
   ቁልፍ ወይም ቶከን አያስፈልግም (ማረጋገጫ የማይፈልግ አቅራቢ ነው — ማረጋገጫውን የጎን ኮንቴይነሩ ይይዛል)።
2. የጎን ኮንቴይነሩ Codex CLI **እስካሁን በመለያ ካልገባ**፣ የግንኙነት ጤና
   ምርመራው _"እየሰራ ነው፣ ነገር ግን በመለያ አልገባም"_ ብሎ ያሳያል (ቀይ የማረጋገጫ ስህተት አይደለም)።
   **በChatGPT ይግቡ**ን ይጠቀሙ፦ ይህ መደበኛውን Codex device-OAuth በአሳሽዎ
   ውስጥ ያስኬዳል፣ ከዚያም በ**ማረጋገጫውን ተግብር** አማካኝነት `~/.codex/auth.json`ን ወደ የጋራ volume
   ይጽፋል (ያው አንድ መግቢያ ለ`codex` እና ለ`codex-app-server`
   አቅራቢዎች ያገለግላል)።
3. በመለያ ከገቡ በኋላ፣ የጤና ምርመራው አረንጓዴ ይሆናል (`/readyz`ን **እና**
   `account/read`ን ያረጋግጣል — ማለትም አገልግሎቱ መነሳቱን _እና_ ማረጋገጫ ማግኘቱን) እና መስራት ይጀምራል።

ዳሽቦርዱ በትክክል እየሰራ ያለ `~/.codex/auth.json`ን ፈጽሞ አይተካም — የሚጽፈው
ፋይሉ ከሌለ ወይም ቶከኑ ጊዜው ካለፈበት ብቻ ነው (ምትኬ ሁልጊዜ ይወሰዳል)።

## 4. የማሰማሪያ ሁኔታዎች

- **አስቀድሞ ማረጋገጫ ያገኘ Codex CLI ያለው ኦፕሬተር** — የአስተናጋጅዎን
  `~/.codex` በጎን ኮንቴይነሩ (`codex-appserver-home`) ውስጥ ይስቀሉ እና የመግቢያ ደረጃውን ይዝለሉ።
- **ይፋዊ ተጠቃሚ፣ codex በአካባቢው ያልተጫነ** — ችግር የለውም፦ የጎን ኮንቴይነሩ
  CLIውን ይዟል። ተጠቃሚው በዳሽቦርዱ በኩል ብቻ ማረጋገጫ ያደርጋል።
- **Bare-metal OmniRoute (የጎን ኮንቴይነር የሌለው፣ የአስተናጋጅ codex)** —
  `OMNIROUTE_CODEX_APPSERVER_WS`ን ወደ ራስዎ `codex app-server` ያመልክቱ እና የአስተናጋጁ
  codex በመለያ መግባቱን ያረጋግጡ፤ binaryው ከሌለ "codex አልተጫነም" የሚለው ፍንጭ
  ይታያል።

## 5. የመኖሪያ / UDP ወጪ ትራፊክ (ለኦፕሬተር ተጨማሪ፣ አብሮ አይቀርብም)

ከላይ ያለው አጠቃላይ የጎን ኮንቴይነር ወጪ ትራፊኩን በኮንቴይነሩ መደበኛ አውታረ መረብ ይልካል።
የCodex ትራፊክ በ**መኖሪያ መውጫ** በኩል እንዲወጣ የሚፈልግ ኦፕሬተር (ለምሳሌ TCP + UDP/QUICን
የሚያስተላልፍ TUN tailscale የጎን ኮንቴይነር) ያንን እንደ የተለየ compose
override ያስኬዳል፤ ሆን ተብሎም ከቀረበው `codex-app-server`
መገለጫ ውስጥ **አልተካተተም**። ለዚያ ውቅር ውስጣዊውን የኦፕሬሽን መመሪያ ይመልከቱ።
