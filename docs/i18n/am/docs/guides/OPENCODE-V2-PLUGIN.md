`@omniroute/opencode-plugin-v2` ሙሉውን የOmniRoute ካታሎግዎን — ሞዴሎችን፣ ኮምቦዎችን እና
ራስ-ሰር ኮምቦዎችን — ከማሳያ ስሞች፣ ዋጋ እና የነጻ ደረጃ
በጀቶች ጋር ወደ OpenCode v2 ሞዴል መራጭ ያክላል።

OpenCode v1 እና v2 ፕለጊኖችን በተለያዩ ውሎች ስለሚጭኑ፣ ይህ ከ`@omniroute/opencode-plugin`
የተለየ ፓኬጅ ነው። ከዋናው የOpenCode ስሪትዎ ጋር የሚዛመደውን ይምረጡ፤ ምንም ነገር
በመካከላቸው አይጋራም፣ ስለዚህ አንዱን ማሻሻል ሌላውን እንዲያሻሽሉ አያስገድድዎትም።

## መስፈርቶች

- OpenCode v2።
- ሊደረስበት የሚችል OmniRoute ጌትዌይ (በነባሪ `http://localhost:20128`)።
- Node.js 22 ወይም 24።

## መጫን

ፕለጊኑን ወደ `opencode.json` ያክሉ፦

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

ከዚያ ሞዴሎች እንደ `omniroute/<provider>/<model>` ይታያሉ፤ `providerId` ያንን ቅድመ ቅጥያ እና
OpenCode ምስክርነቱን የሚያከማችበትን የውህደት መታወቂያ ይወስናል።

## ምስክርነቶች

ፕለጊኑ የጌትዌይ ቁልፍን በሦስት ቦታዎች፣ በዚህ ቅደም ተከተል ይፈልጋል፦

1. **በOpenCode ውስጥ ያገናኙት ምስክርነት።** ፕለጊኑ ውህደት ስለሚመዘግብ፣
   የOpenCode የራሱ የማረጋገጫ ፍሰት ቁልፉን ማከማቸት ይችላል። ምንም ነገር በ`opencode.json` ውስጥ አይቀመጥም — ይህን ይምረጡ።
2. ለእያንዳንዱ ፕሮጀክት የተለየ መተካት ለማድረግ፣ በፕለጊኑ አማራጮች ውስጥ `apiKey`። ይህ ቁልፉን
   ወደ ማከማቻ ሊያስገቡት በሚችሉ ፋይል ውስጥ ያስቀምጣል።
3. በአካባቢው ውስጥ `OMNIROUTE_API_KEY`።

ከሦስቱ አንዱም ከሌለ፣ ካታሎጉ ባዶ ይሆናል፤ ፕለጊኑም ዝም ብሎ ባዶ መራጭ
ከመተው ይልቅ ሲጀምር አንድ ጊዜ ይህን ያሳውቃል።

### የአስተዳደር ቶከኑ የተለየ ቁልፍ ነው

ኮምቦዎች፣ የአቅራቢ ጤንነት እና ማበልጸግ (የማሳያ ስሞች፣ ዋጋ፣ የነጻ ደረጃ በጀቶች) የሚመጡት
ከጌትዌዩ `/api/*` የመጨረሻ ነጥቦች ነው፤ አብዛኛዎቹ ማሰማራቶች እነዚህን ከየጥያቄ ቁልፉ ይልቅ በ**አስተዳደር** ቶከን
ይጠብቃሉ፦

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

ካልተዋቀረ፣ `managementReadToken` ወደ `apiKey` ይመለሳል። ጌትዌዩ ያንን መመለሻ
ውድቅ ሲያደርግ፣ ካታሎጉ አሁንም ይታተማል፤ ነገር ግን ከማሳያ ስሞች ይልቅ ጥሬ የሞዴል መታወቂያዎችን ይይዛል፣ መደበኛ
ቅጽል ስም ድግግሞሽ ማስወገድ፣ ዋጋ እና ኮምቦዎችም አይኖሩትም። ይህ ሲከሰት ፕለጊኑ ለእያንዳንዱ የመጨረሻ ነጥብ አንድ ጊዜ፣
የመጨረሻ ነጥቡን እና የጠፋውን በመጥቀስ ያስጠነቅቃል — ስለዚህ አቅሙ የቀነሰ መራጭ በፍጹም ምስጢር አይሆንም።

## አማራጮች

| ቁልፍ                              | ነባሪ                                   | ማስታወሻዎች                                                                                   |
| -------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                         | የአቅራቢ መታወቂያ፣ የውህደት መታወቂያ እና ሞዴሎች የሚታዩበት ቅድመ ቅጥያ                                           |
| `baseURL`                        | አስፈላጊ                                 | የጌትዌይ ሥር፣ `http(s)` ብቻ፤ የ`/v1` ቅጥያ አስፈላጊ በሆነበት ቦታ ይጨመራል                                   |
| `apiKey`                         | የተገናኘ ምስክርነት፣ ከዚያ `OMNIROUTE_API_KEY` | ለ`/v1/*` የውይይት ቁልፍ                                                                        |
| `managementReadToken`            | ወደ `apiKey` ይመለሳል                     | ለ`/api/*` ቁልፍ — ብዙውን ጊዜ **ተመሳሳይ** አይደለም                                                   |
| `displayName`                    | `"OmniRoute"`                         | በመራጩ ውስጥ የአቅራቢው ስም                                                                        |
| `timeoutMs`                      | `10000`                               | ለእያንዳንዱ የመጨረሻ ነጥብ የማምጣት ጊዜ ገደብ (ራስ-ሰር ኮምቦዎች 5 ሰከንድ ይጠቀማሉ)                                 |
| `modelCacheTtlMs`                | `300000`                              | የካታሎግ መሸጎጫ TTL፤ የዲስክ ቅጽበታዊ ገጽታ ቀዝቃዛ ጅማሮዎችን ያፋጥናል                                          |
| `timeouts`                       | ወደ `timeoutMs` ይመለሳል                  | በms ለእያንዳንዱ የመጨረሻ ነጥብ በጀቶች፦ `models`፣ `combos`፣ `autoCombos`፣ `enrichment`                |
| `enrichment`                     | `true`                                | ስሞችን፣ ዋጋን እና የነጻ ደረጃ በጀቶችን ያምጡ                                                            |
| `providerTag`                    | `true`                                | ሞዴሉ የሚመራበትን የላይኛው አቅራቢ ከማሳያ ስሙ በፊት እንደ ቅድመ ቅጥያ ያክሉ                                        |
| `usableOnly`                     | `false`                               | ጌትዌዩ እንደተዘጋጁ የሚዘግባቸውን አቅራቢዎች ብቻ ያቆዩ                                                       |
| `visibleModels` / `hiddenModels` | `[]`                                  | ትክክለኛ-ወይም-ቅጥያ የፈቃድ ዝርዝሮች፤ ክልከላ ቅድሚያ ያገኛል                                                  |
| `geminiSanitization`             | `true`                                | Gemini ከመሣሪያ መርሃግብሮች ውድቅ የሚያደርጋቸውን የJSON-Schema ቁልፍ ቃላት ያስወግዱ (`$ref` መሣሪያዎች ሳይነኩ ይተላለፋሉ) |
| `apiFormat.allowAnthropic`       | `false`                               | በፈቃድ ዝርዝሩ ውስጥ ያሉ መታወቂያዎችን በAnthropic API ብሎክ በኩል ያስተላልፉ                                   |
| `apiFormat.anthropicModels`      | `[]`                                  | ወደ Anthropic የሚመሩ ሙሉ የሞዴል መታወቂያዎች                                                         |
| `logLevel` / `startupDebug`      | `warn` / `false`                      | የመዝገብ ማስታወሻ ዝርዝር ደረጃ                                                                      |

## ካታሎጉ እንዴት ወቅታዊ ሆኖ እንደሚቆይ

ካታሎጉ በሚያስፈልግበት ጊዜ ይመጣል እና ለ`modelCacheTtlMs` በካሽ ይቀመጣል፤ የዲስክ ቅጽበታዊ ቅጂም ጌትዌዩ ሊደረስበት በማይችልበት ጊዜ የመጨረሻው የታወቀ ካታሎግ እንዲገኝ ያደርጋል — መቋረጡ ከወቅታዊነት በስተቀር ምንም አያሳጣዎትም። ሞዴሎች እና ጥምረቶች እንደደረሱ ይታተማሉ፤ ራስ-ጥምረቶች፣ የአቅራቢዎች ዝርዝር እና የማበልጸጊያ ተደራቢው ሲደርሱ ይካተታሉ፣ ስለዚህ አንድ ዘገምተኛ የመገናኛ ነጥብ ሙሉውን መራጭ አግቶ ሊይዝ አይችልም።

ስሞቹ ጌትዌዩ የሚያውቀውን መረጃ ይይዛሉ፦ ሞዴሉ የሚመራበትን የላይኛው አቅራቢ፣ የ`[Free]` ምልክት እና አብሮት የሚመጣውን በጀት — ስለዚህ ተመሳሳዩን ሞዴል የሚሸጡ ሁለት ግንኙነቶች እንደተለያዩ ይቆያሉ። ቅድመ ቅጥያውን በ`"providerTag": false` ያጥፉት።

በእጅ የሚደረግ የማደስ ትዕዛዝ የለም፦ የOpenCode v2 ትዕዛዞች የጥያቄ አብነቶች እንጂ የመልሶ ጥሪ ተግባራት አይደሉም፣ ስለዚህ ፕለጊን እንዲህ ያለውን ማቅረብ አይችልም። ማደሶች TTLን ይከተላሉ፤ አስተናጋጁ እንዲጭን የሚጠየቀው ካታሎጉ ወይም ተደራቢው በእርግጥ ሲለወጥ ብቻ ነው፣ በእያንዳንዱ ማደስ ጊዜ አይደለም።

## በGemini ላይ የመሣሪያ ጥሪ

Gemini የመሣሪያ መግለጫዎቻቸው `$schema` ወይም `additionalProperties` የያዙ ሙሉ ጥያቄዎችን `400 INVALID_ARGUMENT` በማለት ውድቅ ያደርጋል። ፕለጊኑ የዚህ አቅራቢ Gemini ሞዴል ከሚቀበላቸው የመሣሪያ ንድፎች ውስጥ እነዚያን ቁልፍ ቃላት ያስወግዳል፣ ሌሎቹን ጥያቄዎች በሙሉ ሳይነካ ይተዋቸዋል። `$ref` የያዘ መሣሪያ ሳይለወጥ ይተላለፋል እንጂ ቁልፍ ቃላቱ አይወገዱበትም፤ ምክንያቱም ማጣቀሻውን ማስወገድ ንድፉን "ማንኛውንም ነገር ተቀበል" ወደሚል ያሰፋዋል።
ይህን ለማጥፋት `"geminiSanitization": false` ያዘጋጁ።
