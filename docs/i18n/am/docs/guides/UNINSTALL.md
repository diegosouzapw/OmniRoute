ይህ መመሪያ OmniRouteን ከስርዓትዎ ላይ በንጽህና እንዴት ማስወገድ እንደሚችሉ ያብራራል።

## ፈጣን ማራገፍ (v3.6.2+)

OmniRoute ሙሉ በሙሉ ለማስወገድ ሁለት አብሮገነብ ስክሪፕቶችን ያቀርባል፦

### ውሂብዎን ማቆየት

```bash
npm run uninstall
```

ይህ OmniRoute መተግበሪያን ያስወግዳል፣ ነገር ግን በ`~/.omniroute/` ውስጥ ያሉትን የውሂብ ጎታዎን፣ ውቅሮችዎን፣ API ቁልፎችዎን እና የአቅራቢ ቅንብሮችዎን **ይጠብቃል**። በኋላ እንደገና ለመጫን ካቀዱ እና ውቅርዎን ማቆየት ከፈለጉ ይህን ይጠቀሙ።

### ሙሉ በሙሉ ማስወገድ

```bash
npm run uninstall:full
```

ይህ መተግበሪያውን ያስወግዳል **እንዲሁም ሁሉንም ውሂብ በቋሚነት ይሰርዛል**፦

- የውሂብ ጎታ (`storage.sqlite`)
- የአቅራቢ ውቅሮች እና API ቁልፎች
- የምትኬ ፋይሎች
- የምዝግብ ማስታወሻ ፋይሎች
- በ`~/.omniroute/` ማውጫ ውስጥ ያሉ ሁሉም ፋይሎች

> ⚠️ **ማስጠንቀቂያ፦** `npm run uninstall:full` ከተፈጸመ ወደነበረበት መመለስ አይቻልም። ሁሉም የአቅራቢ ግንኙነቶችዎ፣ ጥምረቶችዎ፣ API ቁልፎችዎ እና የአጠቃቀም ታሪክዎ በቋሚነት ይሰረዛሉ።

## በእጅ ማራገፍ

### NPM ዓለም አቀፍ ጭነት

```bash
# ዓለም አቀፍ ፓኬጁን ያስወግዱ
npm uninstall -g omniroute

# (አማራጭ) የውሂብ ማውጫውን ያስወግዱ
rm -rf ~/.omniroute
```

### pnpm ዓለም አቀፍ ጭነት

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# ኮንቴይነሩን ያቁሙ እና ያስወግዱ
docker stop omniroute
docker rm omniroute

# ቮልዩሙን ያስወግዱ (ሁሉንም ውሂብ ይሰርዛል)
docker volume rm omniroute-data

# (አማራጭ) ኢሜጁን ያስወግዱ
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# ኮንቴይነሮችን ያቁሙ እና ያስወግዱ
docker compose down

# ቮልዩሞችንም ያስወግዱ (ሁሉንም ውሂብ ይሰርዛል)
docker compose down -v
```

### Electron የዴስክቶፕ መተግበሪያ

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` ይክፈቱ
- ወይም ከመጫኛ ማውጫው የNSIS ማራገፊያውን ያስኪዱ

**macOS:**

- `OmniRoute.app`ን ከ`/Applications` ወደ መጣያ ይጎትቱ
- ውሂብን ያስወግዱ፦ `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- የAppImage ፋይሉን ያስወግዱ
- ውሂብን ያስወግዱ፦ `rm -rf ~/.omniroute`

### ከምንጭ ኮድ መጫን (git clone)

```bash
# በክሎን የተፈጠረውን ማውጫ ያስወግዱ
rm -rf /path/to/omniroute

# (አማራጭ) የውሂብ ማውጫውን ያስወግዱ
rm -rf ~/.omniroute
```

## የውሂብ ማውጫዎች

OmniRoute በነባሪነት ውሂብን በሚከተሉት ቦታዎች ያከማቻል፦

| መድረክ     | ነባሪ ዱካ                        | መተኪያ                          |
| -------- | ----------------------------- | ----------------------------- |
| Linux    | `~/.omniroute/`               | `DATA_DIR` የአካባቢ ተለዋዋጭ        |
| macOS    | `~/.omniroute/`               | `DATA_DIR` የአካባቢ ተለዋዋጭ        |
| Windows  | `%APPDATA%/omniroute/`        | `DATA_DIR` የአካባቢ ተለዋዋጭ        |
| Docker   | `/app/data/` (የተጫነ ቮልዩም)      | `DATA_DIR` የአካባቢ ተለዋዋጭ        |
| XDG-ተኳሃኝ | `$XDG_CONFIG_HOME/omniroute/` | `XDG_CONFIG_HOME` የአካባቢ ተለዋዋጭ |

### በውሂብ ማውጫው ውስጥ ያሉ ፋይሎች

| ፋይል/ማውጫ              | መግለጫ                                    |
| -------------------- | --------------------------------------- |
| `storage.sqlite`     | ዋና የውሂብ ጎታ (አቅራቢዎች፣ ጥምረቶች፣ ቅንብሮች፣ ቁልፎች) |
| `storage.sqlite-wal` | SQLite ቅድመ-ጽሑፍ ምዝግብ ማስታወሻ (ጊዜያዊ)        |
| `storage.sqlite-shm` | SQLite የጋራ ማህደረ ትውስታ (ጊዜያዊ)             |
| `call_logs/`         | የጥያቄ ውሂብ ማህደሮች                          |
| `backups/`           | ራስ-ሰር የውሂብ ጎታ ምትኬዎች                     |
| `log.txt`            | የቀድሞ ስሪት የጥያቄ ምዝግብ ማስታወሻ (አማራጭ)         |

## ሙሉ በሙሉ መወገዱን ያረጋግጡ

ካራገፉ በኋላ፣ ምንም የቀሩ ፋይሎች እንደሌሉ ያረጋግጡ፦

```bash
# ዓለም አቀፍ npm ፓኬጅ መኖሩን ያረጋግጡ
npm list -g omniroute 2>/dev/null

# የውሂብ ማውጫውን ያረጋግጡ
ls -la ~/.omniroute/ 2>/dev/null

# እየሰሩ ያሉ ፕሮሰሶችን ያረጋግጡ
pgrep -f omniroute
```

ማንኛውም ፕሮሰስ አሁንም እየሰራ ከሆነ፣ ያቁሙት፦

```bash
pkill -f omniroute
```
