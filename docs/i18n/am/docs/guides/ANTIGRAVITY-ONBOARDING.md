## 1. Antigravity ከAntigravity CLI (agy) ጋር

ሁለቱም አቅራቢዎች **ተመሳሳዩን የGoogle የኋላ ስርዓት** ይጋራሉ — አንድ ዓይነት OAuth ደንበኛ፣ የቶከን እድሳት፣ የመጨረሻ ነጥቦች እና የGoogle መለያዎች። ልዩነቱ የሚያዩዋቸው ሞዴሎች ናቸው።

> የGoogleን ይፋዊ ንጽጽር ለማየት [የAntigravity CLI ማስታወቂያን](https://antigravity.google/blog/introducing-google-antigravity-cli) ይመልከቱ።

| ገጽታ                | `antigravity` (IDE)                        | `agy` (CLI)                                       |
| ------------------ | ------------------------------------------ | ------------------------------------------------- |
| **የGoogle ምርት**    | Antigravity 2.0 / Antigravity IDE          | Antigravity CLI                                   |
| **የኋላ ስርዓት**       | ተመሳሳዩ Google Cloud Code API                | ተመሳሳዩ Google Cloud Code API                       |
| **OAuth / ቶከን**    | ተመሳሳይ ደንበኛ፣ ተመሳሳይ እድሳት                     | ተመሳሳይ ደንበኛ፣ ተመሳሳይ እድሳት                            |
| **የሞዴል ካታሎግ**      | ቋሚ የተመረጠ ዝርዝር (በOmniRoute ውስጥ በቋሚነት የተቀመጠ) | `:fetchAvailableModels`ን በመጠቀም ከGoogle በቀጥታ የሚፈተሽ |
| **Claude ሞዴሎች**    | Sonnet 4.6፣ Opus 4.6 (እያንዳንዳቸው 4 ልዩነቶች)    | Sonnet 4.6፣ Opus 4.6 (እያንዳንዳቸው 4 ልዩነቶች)           |
| **የGemini አሰያየም**  | ግልጽ መለያዎች (Low/Medium/High)                | የต้น ምንጭ IDs (extra-low/low/agent)                |
| **ተጨማሪ ሞዴሎች**      | `gpt-oss-120b-medium`                      | ከGoogle የሚቀርቡ ተጨማሪ ሞዴሎችን ሊያካትት ይችላል               |
| **ነባሪ የአጠቃቀም ሁኔታ** | የIDE ውህደት (VS Code፣ JetBrains)             | የCLI / API መዳረሻ                                   |
| **ኮታ**             | ከagy ጋር የጋራ (ተመሳሳዩ Google መለያ)             | ከantigravity ጋር የጋራ (ተመሳሳዩ Google መለያ)            |

**የሚገኙ ሞዴሎች (በሙከራ የተረጋገጡ፣ 2026-07-29)**፦

- Gemini፦ 3.6 Flash፣ 3.5 Flash፣ 3.1 Pro፣ 3 Flash፣ 2.5 Flash (የተለያዩ የማሰብ ደረጃዎች)
- Claude፦ Sonnet 4.6፣ Opus 4.6 (እያንዳንዳቸው default/low/medium/high ልዩነቶች ያሏቸው)
- ሌላ፦ GPT-OSS 120B Medium
- **Claude Sonnet 5 አይገኝም** — የሚደገፉት የ4.6 ልዩነቶች ብቻ ናቸው

**የሞዴል ካታሎጉ የሚለያይበት ምክንያት**፦ የGoogle CLI «ለፍጥነት እና ለዝቅተኛ ተጨማሪ ጭነት የተመቻቸ» እና «ከGemini ሞዴሎች ጋር በጋራ የተመቻቸ» ነው (በGoogle ይፋዊ ብሎግ መሠረት)። የWeb/IDE ምርቱ «ለሁሉን አቀፍነት የተመቻቸ» ነው። CLI ሞዴሎችን በተለዋዋጭ ሁኔታ ለማግኘት `:fetchAvailableModels`ን ይጠቀማል፣ IDE ግን ቋሚ የተመረጠ ዝርዝር ይጠቀማል።

**በተግባር**፦ ለGemini ሞዴሎች `agy/` ቅድመ ቅጥያን ይጠቀሙ (ለምሳሌ `agy/gemini-3.7-flash-high`)። ለቋሚው የተመረጠ ዝርዝር `antigravity/`ን ይጠቀሙ። ሁለቱም ተመሳሳዩን የGoogle የኋላ ስርዓት ይጠቀማሉ፣ ነገር ግን የተለያዩ የሞዴል አሰያየሞችን ያቀርባሉ። ኮታው የጋራ ነው — ከሁለቱ አቅራቢዎች አንዱን መጠቀም በተመሳሳዩ የGoogle መለያ ገደቦች ላይ ይቆጠራል።

## 2. Google One AI Pro፡ የኮታ ስርዓት

> ስለ ይፋዊ የኮታ ዝርዝሮች [Antigravity Docs: Plans](https://antigravity.google/docs/plans)ን፣ ስለ አዳዲስ የዋጋ ለውጦች ደግሞ [Changes to Antigravity Plans](https://antigravity.google/blog/changes-to-antigravity-plans)ን ይመልከቱ።

Google Antigravity በመልዕክት ብዛት ሳይሆን በ"የተሰራ ሥራ" (የስሌት ክብደት) ላይ የተመሠረተ **ባለሁለት-ደረጃ ኮታ** ይጠቀማል።

| ----------------- | -------------------------------- | ---------------------------------------------------------- |
| **የ5-ሰዓት ፈጣን ዙር** | ወዲያውኑ ጥቅም ላይ የሚውል የ"ተሰራ ሥራ" ክምችት | በአንድ ክፍለ ጊዜ ውስጥ ከመጀመሪያው ጥያቄ በኋላ በ5 ሰዓት ዳግም ይጀመራል           |

## 3. projectIdን እንዴት ማግኘት እንደሚቻል

እያንዳንዱ antigravity/agy ግንኙነት የGoogle Cloud Code `projectId` ያስፈልገዋል። ያለእሱ፣ `/v1internal:models` endpoint 404 ይመልሳል።

### ዘዴ A፡ ራስ-ሰር (የሚመከር)

OmniRoute ይህን በራስ-ሰር ያከናውናል። በDashboard OAuth በኩል አዲስ Google መለያ ሲያክሉ፦

1. OmniRoute ቶከኑን ያድሳል
2. projectIdን ለማግኘት `loadCodeAssist`ን ይጠራል
3. ምንም project ከሌለ፣ አንድ ለመፍጠር `onboardUser`ን ይጠራል
4. አዲስ የተፈጠረውን projectId ለማግኘት `loadCodeAssist`ን እንደገና ይሞክራል
5. ወደ database ያስቀምጠዋል

**ይህ ለአብዛኞቹ መለያዎች ይሰራል** — ምንም በእጅ የሚከናወን ደረጃ አያስፈልግም።

### ዘዴ B፡ በagy CLI በኩል በእጅ

ራስ-ሰር ማግኘቱ ካልተሳካ (ይህ መቼ እንደሚከሰት ክፍል 5ን ይመልከቱ)፦

```bash
# agy CLIን ይጫኑ (አስቀድሞ ካልተጫነ)
npm install -g @anthropic-ai/agy

# በGoogle መለያዎ ይግቡ
agy login

# ማስጀመር የሚያስፈልገውን መለያ ይምረጡ
# ይህ Cloud Code ምዝገባን ያስጀምርና projectId ይመድባል
```

`agy login` በተሳካ ሁኔታ ከተጠናቀቀ በኋላ፣ በOmniRoute Dashboard ውስጥ ቶከኑን ያድሱ። projectId በራስ-ሰር ይገኛል።

### እንዴት ማረጋገጥ እንደሚቻል

databaseን ይፈትሹ፦

```bash
# በOmniRoute container ውስጥ
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

ወይም logsን ይፈትሹ፦

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuth የማዞሪያ URI

### ችግሩ

Google OAuth ትክክለኛ የማዞሪያ URI ይፈልጋል። የOmniRoute ነባሪ ቅንብር `http://127.0.0.1:20128/callback` (loopback) ይጠቀማል። ይህ ለአካባቢያዊ ግንባታዎች ይሠራል፣ ነገር ግን **ለርቀት ማሰማራቶች አይሠራም** (ለምሳሌ፣ በLAN IP በኩል የሚደረስበት ሰርቨር)።

Google የሚከተሉትን የማዞሪያ URIዎች ውድቅ ያደርጋል፦

- IP አድራሻዎችን የሚጠቀሙ (`.com`፣ `.org`፣ ወዘተ. የሚያልቅ ዶሜይን መሆን አለበት)
- በOAuth ደንበኛ ውቅር ውስጥ ከተመዘገቡት የማዞሪያ URIዎች ጋር የማይዛመዱ

### መፍትሔው

**አማራጭ A፦ አብሮ የተካተተውን OAuth ፍሰት ይጠቀሙ (ነባሪ)**

- OmniRouteን ከ`localhost` ወይም `127.0.0.1` ሲደርሱበት ይሠራል
- ምንም ውቅር አያስፈልግም

**አማራጭ B፦ ብጁ OAuth ማረጋገጫዎች**

- በአካባቢዎ ውስጥ `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` ያዘጋጁ
- የራስዎን Google OAuth ማረጋገጫዎች ያቅርቡ፦
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- በGoogle Cloud Console ውስጥ `https://your-domain.com/callback`ን እንደ ተፈቀደ የማዞሪያ URI ይመዝግቡ

**አማራጭ C፦ ለመጀመሪያ መግቢያ agy CLIን ይጠቀሙ**

- OmniRouteን በሚደርስበት ማሽን ላይ `agy login`ን ያስኪዱ
- የOAuth ፍሰቱ በአካባቢው ይጠናቀቃል፣ ቶከኖችም ይከማቻሉ
- በDashboard በኩል ግንኙነቱን ወደ OmniRoute ያስመጡ

### ገደቦች

- ብጁ OAuth ማረጋገጫዎች የዶሜይን ስም ይፈልጋሉ (Google IP አድራሻዎችን እንደ የማዞሪያ URIዎች አይቀበልም)
- ዶሜይን ከሌለዎት፣ በምትኩ አማራጭ A ወይም Cን ይጠቀሙ

## 5. ችግር መፍታት፦ ራስ-ሰር ማዋቀር ሳይሳካ ሲቀር

OmniRoute ለአብዛኛዎቹ መለያዎች የprojectId ፍለጋን እና የመጀመሪያ ምዝገባን በራስ-ሰር ያስተናግዳል። ይህ ሳይሳካ ሲቀር፣ ዋናው ምክንያት ብዙውን ጊዜ ከሚከተሉት አንዱ ነው፦

### የመለያው ክልል ታግዷል

**ምልክት**፦ `agy login` "Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location." የሚል መልዕክት ይመልሳል።

**ዋና ምክንያት**፦ Google መለያዎች በምዝገባ ጊዜ የሚዘጋጅ የጀርባ ስርዓት "Country Association" መስክ አላቸው። agy CLI እና Cloud Code API ይህን መስክ በጥብቅ ይፈትሻሉ — የድር Gemini ግን የአሁኑን IPዎን ብቻ ይፈትሻል።

> ከመለያዎ ጋር የተያያዘውን ክልል ለመፈተሽ ወይም ለመለወጥ፣ [Google Country Association Form](https://policies.google.com/country-association-form)ን ይጎብኙ።

**የድር Gemini ለምን ይሠራል፣ agy ግን ለምን አይሠራም**፦

- የድር Gemini / Google One፦ የአሁኑን IP ብቻ ይፈትሻል (proxy ያልፋል)
- agy CLI / Cloud Code API፦ የጀርባ ስርዓቱን Country Association መስክ ያነባል (proxy አይረዳም)

**መፍትሔ**፦

1. በUS IP ላይ ሆነው [Google Country Association Form](https://policies.google.com/country-association-form)ን ይጎብኙ
2. የክልል ለውጥ ጥያቄ ያስገቡ ("I live in a different country"ን ይምረጡ)
3. Google ጥያቄውን እስኪያስኬድ እና የኢሜይል ማሳወቂያ እስኪልክ ከ1-24 ሰዓታት ይጠብቁ
4. ከዚያ `agy login` ሊሳካ ይገባል

### መለያው Cloud Code ፕሮጀክት የለውም

**ምልክት**፦ ምዝግቦቹ `loadCodeAssist returned no project id` እና `onboardUser failed (400)` ያሳያሉ።

**ዋና ምክንያት**፦ መለያው ከዚህ በፊት በGoogle Cloud Code ተመዝግቦ አያውቅም፣ እና ራስ-ሰር የመጀመሪያ ምዝገባው አልተሳካም።

**መፍትሔ**፦ የCloud Code ምዝገባን ለማስጀመር `agy login`ን በእጅ ያስኪዱ፣ ከዚያም በOmniRoute Dashboard ውስጥ ቶከኑን ያድሱ።

### ቶከኑ ጊዜው አልፏል ወይም ተሰርዟል

**ምልክት**፦ በምዝግቦች ውስጥ የ401 ስህተቶች፣ ወይም "Token has expired" መልዕክቶች ይታያሉ።

**መፍትሔ**፦ ቶከኑን በDashboard → Providers → agy → የማደሻ አዶን ጠቅ ያድርጉ በሚለው መንገድ ያድሱ። የማደሻ ቶከኑ ራሱ ከተሰረዘ፣ በOAuth በኩል እንደገና ማረጋገጥ ያስፈልግዎታል።

```
   └─ አይሰራም → የስህተት መልዕክቱን ይመልከቱ፤ ምናልባት የክልል ወይም የደንበኝነት ችግር ነው
```
