## አጠቃላይ እይታ

ካታሎጉ **45 Agent Skills** (23 REST API + 21 CLI + 1 የውቅር የሥራ ፍሰት) ይዟል። እያንዳንዱ ክህሎት የሚከተሉት አሉት፦

- **መደበኛ ID** (`omni-auth`፣ `cli-serve`፣ ወዘተ)
- በ`skills/{id}/SKILL.md` ውስጥ YAML frontmatter (`name`፣ `description`) + ዝርዝር markdown ይዘት ያለው **SKILL.md** ፋይል
- ከOpenAPI ዝርዝር መግለጫ እና ከCLI መዝገብ የተወሰዱ **REST መጨረሻ ነጥቦች** (የAPI ክህሎቶች) ወይም **CLI ንዑስ ትዕዛዞች** (የCLI ክህሎቶች)
- በቀጥታ ለማምጣት **GitHub raw URL**፦ `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## የREST API ማግኛ

| መጨረሻ ነጥብ                     | ዘዴ   | መግለጫ                                                        | ማረጋገጫ  |
| :--------------------------- | :--- | :---------------------------------------------------------- | :----- |
| `/api/agent-skills`          | GET  | ካታሎግን ይዘርዝሩ (አማራጭ `?category=api\|cli\|config&area=<area>`) | የለም    |
| `/api/agent-skills/{id}`     | GET  | የአንድ ክህሎት ሜታዳታን ያግኙ                                         | የለም    |
| `/api/agent-skills/{id}/raw` | GET  | SKILL.mdን እንደ `text/markdown` ያምጡ                           | የለም    |
| `/api/agent-skills/coverage` | GET  | የሽፋን ስታቲስቲክስ (ምን ያህል የSKILL.md ፋይሎች እንዳሉ)                   | የለም    |
| `/api/agent-skills/generate` | POST | አመንጪውን ያስነሱ (dryRun/prune/onlyIds)                          | አስተዳደር |

ምሳሌ — ሁሉንም የAPI ክህሎቶች ይዘርዝሩ፦

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ምሳሌ — አንድ SKILL.md ያምጡ፦

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## የA2A ማግኛ

የA2A ክህሎት `list-capabilities` ሙሉውን የ45 ክህሎቶች ካታሎግ እንደ markdown ሠንጠረዥ አርቲፋክት ይመልሳል። ውጫዊ ኦርኬስትሬተሮች በሚከተለው መንገድ ሊጠሩት ይችላሉ፦

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

ለፕሮቶኮል ዝርዝሮች [A2A-SERVER.md](./A2A-SERVER.md)ን ይመልከቱ።

## ውጫዊ ኤጀንቶች Skillsን እንዴት እንደሚጠቀሙ

### 1. በ REST በኩል ማግኘት

```bash
# ሙሉውን ካታሎግ ያግኙ
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# ወደ አውድ ለማስገባት SKILL.mdን ያግኙ
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. በ MCP በኩል ማግኘት

// በ Claude Desktop / Cursor MCP ደንበኛ ውስጥ፦

// result.skills → ለእያንዳንዱ rawUrl ያለው የ AgentSkill ድርድር

### 3. በ A2A በኩል ማግኘት

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={

# table ሁሉንም 45 የ skill IDዎች + rawUrl ዓምዶች የያዘ የ markdown ሰንጠረዥ ነው
```

## ማመንጫ

ማመንጫው የተመረጠውን ካታሎግ + OpenAPI ዝርዝር መግለጫ + CLI መዝገብ በማንበብ፣ ለእያንዳንዱ ግቤት `skills/{id}/SKILL.md`ን ይጽፋል፦

```bash
# ቅድመ እይታ (የሙከራ አሂድ፣ ምንም አይጻፍም)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# ሙሉ ዳግም ማመንጨት
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# የተወሰኑ IDዎችን ዳግም ማመንጨት
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```
