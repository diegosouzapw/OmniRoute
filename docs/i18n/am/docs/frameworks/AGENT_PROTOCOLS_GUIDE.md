    └─ አይ → ይቀጥሉ

## 1. A2A — ከወኪል ወደ ወኪል

**መስፈርት፦** [A2A v0.3](https://a2a-protocol.org)
**የOmniRoute መዳረሻ፦** `POST /a2a` (JSON-RPC 2.0)
**የወኪል ካርድ፦** `GET /.well-known/agent.json`

### መቼ መጠቀም እንዳለብዎት

- OmniRoute ከአቻዎቹ አንዱ የሆነበትን ባለብዙ-ወኪል ሥርዓት ሲገነቡ
- የOmniRouteን የማስተላለፊያ ብልህነት (ብልህ ማስተላለፊያ፣ የኮታ አስተዳደር፣ ወዘተ) Google ADKን በመሳሰሉ ማዕቀፎች ወይም አጠቃላይ የወኪል መረቦች ውስጥ ላሉ ወኪሎች ሲያቀርቡ
- OmniRouteን በመደበኛ የፍለጋ + የጥሪ በይነገጽ ኋላ ሲያቀናጁ

### ስልቶች

- `message/send` — መልዕክት ያስገቡ፣ የተመሳሰለ ምላሽ ይቀበሉ
- `message/stream` — ያስገቡ + በSSE የሚለቀቁ የሂደት ክስተቶችን ይቀበሉ
- `tasks/get` — ተግባሩን በID ያንብቡ
- `tasks/cancel` — በመሠራት ላይ ያለን ተግባር ይሰርዙ

### አብረው የተካተቱ ክህሎቶች (6)

- `smart-routing` — ጥያቄን በምርጥ ጥምረት በኩል ያስተላልፉ
- `quota-management` — የእያንዳንዱን አቅራቢ የኮታ ሁኔታ ሪፖርት ያድርጉ
- `provider-discovery` — የተጫኑ አቅራቢዎችን ከችሎታዎቻቸው ጋር ይዘርዝሩ
- `cost-analysis` — የጥያቄ/ውይይት ወጪን ይገምቱ
- `health-report` — የእያንዳንዱን አቅራቢ breaker/cooldown/lockout ሁኔታ ያጠቃልሉ
- `list-capabilities` — የወኪሉን የሚገኙ ክህሎቶችና ሜታዳታ ይዘርዝሩ

### ዝርዝር ማብራሪያ

ስለ ማጓጓዣ ዝርዝሮች፣ የወኪል ካርድ መዋቅር፣ የተግባር TTL ውቅር እና አዳዲስ ክህሎቶችን ለመጨመር የሚያገለግለው አብነት [A2A-SERVER.md](./A2A-SERVER.md)ን ይመልከቱ።

## 2. ACP — የCLI ወኪሎች መዝገብ

**የOmniRoute መዳረሻ:** `GET /api/acp/agents`
**ምንጭ:** `src/lib/acp/{index,manager,registry}.ts`

### ምንድን ነው

ACP የOmniRoute **የአካባቢ CLI ወኪሎች ዝርዝር** ነው። በአስተናጋጁ ላይ የትኞቹ የኮድ ማዘጋጃ CLI-ዎች እንደተጫኑ (Cursor፣ Cline፣ Claude Code፣ Codex CLI፣ Continue፣ ወዘተ) ይለያል፣ ስሪቶቻቸውን ያጣራል፣ እና ተጠቃሚው እያንዳንዱን CLI ወደ OmniRoute እንዲያመለክት ማዋቀር እንዲችል በዳሽቦርዱ ላይ ያሳያቸዋል።

ይህ ውጫዊ ፕሮቶኮል አይደለም — የ"CLI Tools" የተጠቃሚ በይነገጽን እና የCLI አሻራ ክትትልን የሚያንቀሳቅስ ውስጣዊ መዝገብ ነው ([CLI-TOOLS.md](../reference/CLI-TOOLS.md)ን ይመልከቱ)።

### ምን ያደርጋል

- የተጫኑ የCLI ሁለትዮሽ ፋይሎችን ለማግኘት አስተናጋጁን ይመረምራል (እንደ OS-ው `which` / `where` ይጠቀማል)
- የእያንዳንዱን CLI ስሪት ያነባል (`<bin> --version`ን ይጠራል)
- እንደ አማራጭ በተጠቃሚ የተወሰኑ ብጁ ወኪሎችን ይቀበላል (የሁለትዮሽ ፋይል ዱካ + የስሪት ምርመራ + የማስጀመሪያ ነጋሪ እሴቶች)
- ብጁ ወኪሎችን በቅንብሮች ውስጥ ያስቀምጣል
- የተዋሃደውን ዝርዝር ወደ ዳሽቦርዱ ይመልሳል

### REST API

| መዳረሻ              | ዘዴ   | መግለጫ                                               | ማረጋገጫ   |
| ----------------- | ---- | -------------------------------------------------- | ------- |
| `/api/acp/agents` | GET  | የተገኙ + ብጁ ወኪሎችን ይዘረዝራል (የተጫኑ/ጠቅላላ ብዛቶች)            | API ቁልፍ |
| `/api/acp/agents` | POST | ብጁ ወኪል ያክላል/ያዘምናል/ያስወግዳል (የድርጊት መለያ በጥያቄው ይዘት ውስጥ) | API ቁልፍ |

የPOST ጥያቄ ይዘት ቅርጽ (`customAgentBodySchema` በ`src/app/api/acp/agents/route.ts` ውስጥ):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### የአጠቃቀም ሁኔታዎች

- የዳሽቦርዱ "CLI Tools" ገጽ የተጫኑትን ይዘረዝራል እና እያንዳንዱን ወደ OmniRoute እንዲያመለክት ለማዋቀር ያግዝዎታል
- ብጁ ወኪሎች የላቁ ተጠቃሚዎች OmniRoute በነባሪነት የማያውቃቸውን ውስጣዊ/የባለቤትነት CLI-ዎች እንዲመዘግቡ ያስችላሉ
- የማወቂያ ውጤቱ የ`cli-tools` አሻራ ማትሪክስን ያቀርባል

### ACPን መጠቀም የሌለብዎት ጊዜ

- ACP ተግባራትን _አያስኬድም_። CLI-ዎችን የሚለየው እና የሚያዋቅረው ብቻ ነው። CLIን በተግባር ለመጥራት፣ OmniRoute በሚያቀርባቸው የአካባቢ ተለዋዋጮች (`OPENAI_BASE_URL`፣ `OPENAI_API_KEY`፣ ወዘተ) ራስዎ ያስጀምሩት።

## 3. የደመና ወኪሎች

**የOmniRoute መዳረሻዎች:** `/api/v1/agents/tasks/*` (የሕይወት ዑደት) + `/api/cloud/*` (መሠረታዊ ግንኙነቶች)
**ምንጭ:** `src/lib/cloudAgent/`

### ምንድን ነው

በሦስተኛ ወገን የደመና ኮድ ማዘጋጃ ወኪሎች ላይ ወጥ የሆነ በይነገጽ ነው። መመሪያ + የማከማቻ ዩአርኤል ያስገባሉ፣ OmniRoute ወደ ትክክለኛው የደመና ወኪል ይልካል፣ ሁኔታውን በየጊዜው ይፈትሻል፣ ውጤቶችንም ይመልሳል።

### የሚደገፉ ወኪሎች (4፣ ሁሉም በ`src/lib/cloudAgent/agents/` ውስጥ የተረጋገጡ)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### የሕይወት ዑደት

```
POST /api/v1/agents/tasks
  → BaseAgent.createTask() ለእያንዳንዱ የወኪል ክፍል
  → ውጫዊ አገልግሎቱ ሥራውን ይጀምራል
  → የተግባር ረድፍ በDB ውስጥ ይፈጠራል (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → ከአቅራቢው የዘገየ የሁኔታ ማመሳሰል
  → የአሁኑን ሁኔታ + ዕቅድ + የእንቅስቃሴ ምዝግብ ይመልሳል
  ↓
POST /api/v1/agents/tasks/[id]   (action: "approve" | "message" | "cancel")
  → ወደ አቅራቢው ያስተላልፋል (ወይም በአካባቢው እንደተሰረዘ ምልክት ያደርጋል)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → በአካባቢው ይሰርዛል
```

### ማረጋገጫ

⚠️ **ሁሉም የ`/api/v1/agents/tasks/*` መዳረሻዎች የአስተዳደር ማረጋገጫ ይፈልጋሉ** (commit `588a0333`)። Bearer ብቻ የሚጠቀሙ ጠሪዎች ከv3.8.0 ጀምሮ 401 ይቀበላሉ።

### ጥልቅ ማብራሪያ

ስለ `CloudAgentBase` ውል፣ የእያንዳንዱ ወኪል ዝርዝሮች፣ የመርሃግብር ዝርዝሮች እና የማረጋገጫ መረጃ ግንኙነት መዳረሻዎች [CLOUD_AGENT.md](./CLOUD_AGENT.md)ን ይመልከቱ።
