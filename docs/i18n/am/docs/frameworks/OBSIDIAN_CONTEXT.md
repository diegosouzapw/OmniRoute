## ምንድን ነው

OmniRoute ከ**Obsidian** vault ጋር እንደ **የአውድ ምንጭ** ይገናኛል — ወኪሎች
አብሮ በተሰራው MCP አገልጋይ አማካይነት የሚያነቡትና የሚጽፉበት አካባቢያዊ Markdown
የእውቀት ማከማቻ ነው። ውህደቱ በዴስክቶፕ መተግበሪያው ውስጥ ከሚሰራው
የማህበረሰብ **Obsidian Local REST API** plugin ጋር ይገናኛል፤ በዚህም ወኪሎች
ማስታወሻዎችን መፈለግ፣ ፋይሎችን ማንበብ/መጻፍ/ማስተካከል፣ vaultን መዘርዘር፣
ከዕለታዊ/ሳምንታዊ ወቅታዊ ማስታወሻዎች ጋር መስራት፣ tagsን ማስተዳደር፣
የObsidian ትዕዛዞችን ማስኬድ እና (እንደ አማራጭ) ባለሁለት አቅጣጫ
የዴስክቶፕ↔ሞባይል vault ማመሳሰልን ማስተባበር ይችላሉ።

ደንበኛው (`src/lib/obsidian/api.ts`) Local REST APIን በሚከተሉት ባህሪያት ይሸፍናል፦

- ለጊዜያዊ `5xx` ስህተቶች **ከbackoff ጋር ዳግም መሞከር**፣ በ`AbortController` በኩል **የ30 ሰከንድ timeout**።
- **በtype የተደረገ የስህተት ምደባ** — `ObsidianAuthError` (401/403)፣
  `ObsidianNotFoundError` (404)፣ `ObsidianServerError` (5xx)፣ `ObsidianTimeoutError`።
- የተለመደውን የport ስህተት (HTTP በ`27123` ላይ፣ በ`27124` ላይ ያለው MCP
  endpoint **አይደለም**) እና የTailscale ቅርጸቱን የሚጠቅስ ቀላል
  **«Obsidianን ማግኘት አልተቻለም» ፍንጭ**።
- ክፍተት/slash ያላቸው የማስታወሻ ዱካዎች ደህንነታቸው እንዲጠበቅ፣ ከvault አንጻር
  የሚደረግ **የዱካ ኢንኮዲንግ**።

## ማዋቀር

ለObsidian token ወይም base URL **ምንም environment variable የለም** — ሁለቱም
በ`src/lib/db/obsidian.ts` በኩል በSQLite `key_value` ሰንጠረዥ (namespace `obsidian`)
ውስጥ ይከማቻሉ። tokenው **በማከማቻ ላይ ሳለ የተመሰጠረ** ነው (AES-256-GCM፣
ከplaintext የኋላ-ተኳኋኝ fallback ጋር)። ከEndpoint dashboard
(`ObsidianSourceCard`) **Context Sources** tab ወይም በቅንብሮች REST API
በኩል ያዋቅሩ።

> [!IMPORTANT]
> የ**Obsidian Local REST API** plugin መጫንና እየሰራ መሆን አለበት። የREST
> interfaceው በ**HTTP `127.0.0.1:27123`** (ነባሪው base URL) ላይ ያዳምጣል። Port `27124`
> _የተለየ_ MCP/HTTPS endpoint ሲሆን በቅንብሮች route በግልጽ ውድቅ ይደረጋል።
> ከሌላ መሣሪያ ሲገናኙ `http://<tailscale-ip>:27123`ን ይጠቀሙ።

### የውቅር keys (SQLite `key_value`፣ namespace `obsidian`)

| Key               | ዓላማ                                           | የተመሰጠረ |
| ----------------- | --------------------------------------------- | ------ |
| `api_key`         | የLocal REST API bearer token                  | አዎ     |
| `base_url`        | የREST base URL (ነባሪ `http://127.0.0.1:27123`) | አይ     |
| `vault_path`      | ወደ vault directory የሚወስድ ፍጹም ዱካ (ለማመሳሰል)      | አይ     |
| `webdav_username` | የመነጨ WebDAV username (የvault ማመሳሰል)           | አይ     |
| `webdav_password` | የመነጨ WebDAV password (የvault ማመሳሰል)           | አዎ     |
| `webdav_enabled`  | የWebDAV vault ማመሳሰል መንቃቱን                     | አይ     |

### በREST በኩል ማዋቀር

```bash
# የLocal REST API tokenን ያስቀምጡ + ያረጋግጡ (POST በstatus ፍተሻ ያረጋግጣል)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# የግንኙነት statusን ይፈትሹ (connected፣ hasToken፣ baseUrl፣ vaultPath ይመልሳል)
curl http://localhost:20128/api/settings/obsidian

# ግንኙነቱን ያቋርጡ (የተከማቸውን token ያጸዳል)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

ሁሉም methods የdashboard authentication ይፈልጋሉ። `POST` በport `27124`
ላይ ያለ ማንኛውንም URL ውድቅ ያደርጋል፤ ከማከማቸቱ በፊትም የLocal REST API
status endpointን በመጥራት tokenውን ያረጋግጣል።

### የWebDAV vault ማመሳሰል

`src/app/api/settings/obsidian/webdav/route.ts` እንደ አማራጭ በWebDAV የተደገፈ
የvault ማመሳሰልን ያስተዳድራል (በ`src/lib/obsidianSync.ts` የሚመራ)። ማንቃቱ
OmniRouteን ወደ አካባቢያዊ vault directory ያመለክታል እና በዘፈቀደ የWebDAV
username/password ጥንድ ይፈጥራል፦

```bash
# ለvault directory የWebDAV ማመሳሰልን ያንቁ (username/password ይፈጥራል)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# የWebDAV ማመሳሰል statusን ያግኙ (credentials የሚመለሱት ከነቃ ብቻ ነው)
curl http://localhost:20128/api/settings/obsidian/webdav

# የWebDAV ማመሳሰልን ያሰናክሉ (credentials + የሚተዳደረውን .stignore ያጸዳል)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### በእያንዳንዱ API key የሚወሰን የአውድ ምንጭ (አማራጭ)

የObsidian ውቅር በ`api_key_context_sources` ሰንጠረዥ
(`src/lib/db/apiKeyContextSources.ts`) በኩል **ለእያንዳንዱ API key** ሊወሰን
ይችላል። የMCP ጥሪ የተረጋገጠ API key id ሲይዝ፣ `getObsidianConfigForApiKey()`
የዚያን key የራሱን token/base-URL/vault-path (`source: "api_key"`) ቅድሚያ
ይሰጣል፤ ካልሆነ ወደ ዓለም አቀፉ ውቅር (`source: "global"`) fallback ያደርጋል።

## MCP መሣሪያዎች (22)

በ`open-sse/mcp-server/tools/obsidianTools.ts` ውስጥ ተገልጸዋል። token/base-URL ለእያንዳንዱ ጥሪ ይወሰናሉ (መጀመሪያ የየ-API-key፣ ከዚያም ዓለም አቀፍ)። የOmniRoute **sync server**ን የሚጠቀሙ መሣሪያዎች
(አራቱ `obsidian_sync_*` መሣሪያዎች) በተጨማሪ በOmniRoute ቅንብሮች ውስጥ የተዋቀረውን የsync ማረጋገጫ token ይፈልጋሉ።

| `obsidian_get_note_metadata` | ሙሉ ይዘቱን ሳያካትት frontmatter፣ tags፣ links እና የቁምፊ/ቃላት ብዛትን ያገኛል።                     |
| `obsidian_get_active_file`   | በአሁኑ ጊዜ በObsidian ውስጥ ንቁ የሆነውን ፋይል path + content ያገኛል።                           |
| `obsidian_get_periodic_note` | ለአንድ ቀን ዕለታዊ/ሳምንታዊ/ወርሃዊ ወቅታዊ ማስታወሻን ያገኛል (ካልተገለጸ ዛሬ)።                             |
| `obsidian_get_tags`          | ሁሉንም የvault tags ከድግግሞሻቸው ጋር ይዘረዝራል።                                              |
| `obsidian_list_commands`     | የሚገኙ የObsidian command IDsን ይዘረዝራል (ከ`obsidian_execute_command` ጋር ይጠቀሙ)።         |
| `obsidian_sync_status`       | የOmniRoute sync server ሁኔታ፦ እየሄደ መሆኑ፣ የvault ስም፣ port፣ uptime፣ የመጨረሻ sync።        |
| `obsidian_sync_conflicts`    | ያልተፈቱ sync ግጭቶችን (path፣ conflict path፣ detected-at) ይዘረዝራል።                       |

### የመጻፊያ መሣሪያዎች (`write:obsidian`)

| መሣሪያ                             | መግለጫ                                                                         |
| -------------------------------- | ---------------------------------------------------------------------------- |
| `obsidian_write_note`            | በተሰጠ Markdown ይዘት ማስታወሻን ይፈጥራል ወይም በላዩ ላይ ደርቦ ይጽፋል።                          |
| `obsidian_append_note`           | ይዘትን ወደ ማስታወሻ ያክላል፤ እንደ አማራጭም ወደ ተወሰነ heading/block ያክላል።                    |
| `obsidian_patch_note`            | በheading፣ block ወይም frontmatter field ላይ በትክክል append/prepend/replace ያደርጋል። |
| `obsidian_delete_note`           | ማስታወሻን ከvault እስከመጨረሻው ይሰርዛል።                                                |
| `obsidian_move_note`             | ማስታወሻን በvault ውስጥ ያንቀሳቅሳል ወይም ስሙን ይቀይራል።                                     |
| `obsidian_execute_command`       | የObsidian commandን በcommand ID ያስፈጽማል።                                       |
| `obsidian_open_file`             | ፋይልን በObsidian ውስጥ ይከፍታል (ከሌለ ይፈጥረዋል)።                                       |
| `obsidian_sync_trigger`          | አፋጣኝ ባለሁለት አቅጣጫ desktop↔mobile vault sync ያስጀምራል።                            |
| `obsidian_sync_resolve_conflict` | የsync ግጭትን ይፈታል፦ `local` (mobile)፣ `remote` (desktop) ወይም `keep-both`ን ያቆያል። |

> [!NOTE]
> የ`obsidian_patch_note` targets `targetType` እንደ `heading | block | frontmatter`
> እና `operation` እንደ `append | prepend | replace` ይቀበላሉ፤
> `createTargetIfMissing` ደግሞ አማራጭ ነው። አራቱ `obsidian_sync_*` መሣሪያዎች ከአካባቢያዊው sync
> server (`http://127.0.0.1:27781` በነባሪ) ጋር ይገናኛሉ፣ እና sync token ይፈልጋሉ።

### ወሰኖች

የማንበቢያ መሣሪያዎች `read:obsidian`ን፣ የመጻፊያ መሣሪያዎች ደግሞ `write:obsidian`ን ይፈልጋሉ። ማስፈጸሙ
ከNotion ጋር ተመሳሳይ ነው — በ`open-sse/mcp-server/server.ts` ውስጥ በ`withScopeEnforcement()` ይከናወናል፣
በ`OMNIROUTE_MCP_ENFORCE_SCOPES=true` ይቆጣጠራል፣ የተፈቀዱ ወሰኖችም ከ`OMNIROUTE_MCP_SCOPES` ወይም ከAPI key scope context ይመጣሉ።
[MCP-SERVER.md](./MCP-SERVER.md)ን ይመልከቱ።

## መጨረሻ ነጥቦች

| ዘዴ       | መንገድ                            | ዓላማ                                                   |
| -------- | ------------------------------- | ----------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | `{ connected, hasToken, baseUrl, vaultPath }`ን ይመልሳል። |
| `POST`   | `/api/settings/obsidian`        | ቶከኑን ያስቀምጣል + ያረጋግጣል (`27124` ወደብን አይቀበልም)።           |
| `DELETE` | `/api/settings/obsidian`        | ግንኙነቱን ያቋርጣል (የተቀመጠውን ቶከን ያጸዳል)።                      |
| `GET`    | `/api/settings/obsidian/webdav` | የWebDAV ማመሳሰል ሁኔታ + የመግቢያ ማረጋገጫዎች (ነቅቶ ሳለ)።           |
| `POST`   | `/api/settings/obsidian/webdav` | ለአንድ vault ማውጫ የWebDAV ማመሳሰልን ያነቃል።                   |
| `DELETE` | `/api/settings/obsidian/webdav` | የWebDAV ማመሳሰልን ያሰናክላል።                                |

> Local REST API (በተዋቀረው `base_url`) እና ከላይ ባሉት MCP መሣሪያዎች በኩል ይደረስበታል — ይፋዊ
> `/v1` Obsidian ፕሮክሲ መጨረሻ ነጥብ የለም።

## የአጠቃቀም ሁኔታዎች

- **በvault ላይ የተመሠረቱ መልሶች** — `obsidian_search_simple` / `obsidian_search_structured`
  ከዚያም `obsidian_read_note`፤ ይህም ወኪሉ ከእውነተኛ ማስታወሻዎችዎ ተነስቶ እንዲመልስ ያደርጋል።
- **ማስታወሻ መጻፍ / ዕለታዊ ማስታወሻ መያዝ** — `obsidian_write_note`፣ `obsidian_append_note`፣ ወይም
  የወኪሉን ውጤት፣ ማጠቃለያዎችን ወይም ዕለታዊ ማስታወሻዎችን
  (`obsidian_get_periodic_note`) ወደ vault ለመመዝገብ ትክክለኛ ክፍልን የሚያርም `obsidian_patch_note`።
- **በvault ውስጥ ማሰስ** — ከማንበብ/ከመጻፍ በፊት መዋቅሩን ለማሰስ `obsidian_list_vault`፣ `obsidian_get_document_map` እና
  `obsidian_get_tags`።
- **የObsidian አውቶሜሽን** — ፕለጊኖችን/ትዕዛዞችን ከወኪል ለማስኬድ `obsidian_list_commands` + `obsidian_execute_command`፤
  አንድን ማስታወሻ በUI ውስጥ ለማሳየት `obsidian_open_file`።
- **የሞባይል ማመሳሰል** — የWebDAV ማመሳሰልን ያንቁ፣ ከዚያም ዴስክቶፕ↔ሞባይልን ለማስተባበር እና ግጭቶችን ለመፍታት `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  ይጠቀሙ።
