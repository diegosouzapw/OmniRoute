## ምንድን ነው

OmniRoute ከ**Notion** የሥራ ቦታ ጋር እንደ **የዐውድ ምንጭ** — ወኪሎች አብሮ በተሰራው MCP አገልጋይ በኩል የሚደርሱበት ማንበብ/መጻፍ የሚቻልበት
የእውቀት ማከማቻ — ሊገናኝ ይችላል። የNotion
ውህደት ቶከን አንዴ ከተዋቀረ፣ የMCP መሣሪያዎቹ LLM ገጾችን እና ዳታቤዞችን እንዲፈልግ፣
የገጽ ይዘትን እና የብሎክ ዛፎችን እንዲያነብ፣ ዳታቤዞችን በማጣሪያዎች/መደርደሪያዎች እንዲጠይቅ እና አዳዲስ
ብሎኮችን እንዲያክል ያስችሉታል — ሞዴሉ የNotion APIን በቀጥታ ፈጽሞ እንዳይጠቀም
ሁሉም ጥያቄዎች በOmniRoute በኩል (ከድጋሚ ሙከራ፣ የጊዜ ገደብ እና የስህተት ምደባ ጋር) ይተላለፋሉ።

ውህደቱ በይፋዊው Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) ላይ የተገነባ ቀላልና የተጠናከረ መጠቅለያ ነው። ደንበኛው
(`src/lib/notion/api.ts`) የሚከተሉትን ይጨምራል፦

- ለ`429` እና `5xx` **በጨመረ የመጠበቂያ ጊዜ ድጋሚ መሞከር** (እስከ 3 ሙከራዎች)።
- በ`AbortController` በኩል **የ55 ሰከንድ የጥያቄ ጊዜ ገደብ**።
- **በዓይነት የተለየ የስህተት ምደባ** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429፣ የ`retry after`
  ፍንጮችን ያከብራል), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`።
- ከማሳየት በፊት የቁልል ዱካ የሚመስሉ ክፍሎችን የሚያስወግድ **የመልዕክት ማጽዳት**።

## ማዋቀር

ለNotion ቶከን **ምንም የአካባቢ ተለዋዋጭ የለም** — በ
`src/lib/db/notion.ts` በኩል በSQLite `key_value` ሰንጠረዥ (namespace `notion`፣ key `integration_token`) ውስጥ
ይከማቻል። ከEndpoint ዳሽቦርድ **Context Sources** ትር
(`ObsidianSourceCard` ጎን ያለው `NotionSourceCard`) ወይም በቅንብሮች REST API በኩል ያዋቅሩት።

> [!NOTE]
> ቶከኑ **የNotion ውስጣዊ ውህደት ቶከን** ነው። በ
> <https://www.notion.com/my-integrations> ላይ ውህደት ይፍጠሩ፣ ከዚያ OmniRoute እንዲደርስባቸው የሚፈልጓቸውን
> ገጾች/ዳታቤዞች ለዚያ ውህደት ያጋሩ (የNotion የፈቃድ ሞዴል በማጋራት ላይ የተመሠረተ ነው፣
> ሙሉ የሥራ ቦታ ፈቃድ አይደለም)።

### በREST በኩል ማዋቀር

```bash
# የውህደት ቶከኑን ያስቀምጡ + ያረጋግጡ (POST የሙከራ ፍለጋ በማድረግ ያረጋግጣል)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# የግንኙነት ሁኔታን ይፈትሹ
curl http://localhost:20128/api/settings/notion

# ግንኙነቱን ያቋርጡ (የተከማቸውን ቶከን ያጸዳል)
curl -X DELETE http://localhost:20128/api/settings/notion
```

ሦስቱም ዘዴዎች የዳሽቦርድ ማረጋገጫ (`isAuthenticated`) ይፈልጋሉ። `POST` ሲደረግ፣
OmniRoute ቶከኑን ያስቀምጣል እና ወዲያውኑ 1 ውጤት ያለው የሙከራ ፍለጋ ያከናውናል፤ Notion
የስህተት ነገር ከመለሰ ቶከኑ ይጸዳል እና ጥሪው በ`400` ይከሽፋል።

## MCP መሣሪያዎች (6)

በ`open-sse/mcp-server/tools/notionTools.ts` ውስጥ ተገልጸዋል። ቶከኑ በጥሪ ጊዜ
በ`getNotionToken()` በኩል ይፈለጋል፤ ምንም ካልተዋቀረ መሣሪያው
`"Notion integration token not configured. Set it in Settings > Context Sources."` የሚለውን ስህተት ይጥላል።

| መሣሪያ                         | ወሰን            | መግለጫ                                                                  |
| ---------------------------- | -------------- | --------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | ገጾችን እና ዳታቤዞችን በጽሑፍ ጥያቄ ይፈልጋል (ርዕሶችን፣ IDsን፣ URLsን ይመልሳል)። በገጽ የተከፋፈለ። |
| `notion_get_page`            | `read:notion`  | የአንድን ገጽ ይዘት እና ሜታዳታ በIDው ያገኛል።                                       |
| `notion_list_block_children` | `read:notion`  | የብሎክ ወይም የገጽ ልጅ ብሎኮችን በሙሉ (የብሎክ ዛፉን) ይዘረዝራል። በገጽ የተከፋፈለ።              |
| `notion_query_database`      | `read:notion`  | ዳታቤዝን በአማራጭ `filter` + `sorts` (የNotion API ቅርጸት) ይጠይቃል። በገጽ የተከፋፈለ።  |
| `notion_get_database`        | `read:notion`  | የዳታቤዝን መዋቅር/ሜታዳታ በID ያገኛል።                                            |
| `notion_append_blocks`       | `write:notion` | በነባር ብሎክ ወይም ገጽ ላይ ልጅ ብሎኮችን ያክላል (በአንድ ጥያቄ ከፍተኛው 100 ብሎኮች)።           |

### የግቤት መለኪያዎች

- `notion_search` — `query` (1–500 ቁምፊዎች), `pageSize` (1–100፣ ነባሪ 20),
  `startCursor` (አማራጭ)።
- `notion_get_page` — `pageId` (32 ቁምፊ ሄክስ ወይም UUID)።
- `notion_list_block_children` — `blockId`, `pageSize` (1–100፣ ነባሪ 50),
  `startCursor` (አማራጭ)።
- `notion_query_database` — `databaseId`, `filter` (አማራጭ፣ የNotion ማጣሪያ ቅርጸት),
  `sorts` (አማራጭ ድርድር), `pageSize` (1–100፣ ነባሪ 50), `startCursor` (አማራጭ)።
- `notion_get_database` — `databaseId`።
- `notion_append_blocks` — `blockId`, `children` (የብሎክ ነገሮች ድርድር),
  `after` (አማራጭ ቦታ)።

### ወሰኖች

የማንበብ መሣሪያዎቹ `read:notion`ን እና የመጻፍ መሣሪያው `write:notion`ን ይፈልጋሉ።
ወሰኖቹ በ`open-sse/mcp-server/server.ts` ውስጥ ባለው `withScopeEnforcement()` የሚተገበሩት
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` ሲሆን ብቻ ነው፤ የጠሪው የተፈቀዱ ወሰኖች ከ
`OMNIROUTE_MCP_SCOPES` (በኮማ የተለዩ) ወይም ከተረጋገጠው API ቁልፍ የወሰን ዐውድ
ይመጣሉ። ለሙሉ የወሰን ሞዴሉ [MCP-SERVER.md](./MCP-SERVER.md)ን ይመልከቱ።

> መጨረሻ ነጥብ **የለም** — Notion የሚደረስበት ከላይ ባሉት MCP መሣሪያዎች ብቻ ነው።

## የአጠቃቀም ሁኔታዎች

- **በዕውቀት ላይ የተመሠረቱ መልሶች** — አንድ ወኪል መልስ ከመስጠቱ በፊት የሥራ ቦታውን `notion_search` እንዲያደርግ እና ከፍተኛውን ውጤት `notion_get_page` እንዲያደርግ ይፍቀዱ፤ በዚህም ምላሾች እውነተኛ ውስጣዊ ሰነዶችን ይጠቅሳሉ።
- **በውሂብ ጎታ የሚደገፉ የሥራ ፍሰቶች** — የተግባራት/CRM ውሂብ ጎታን በማጣሪያዎች + ቅደም ተከተሎች `notion_query_database` ያድርጉ፣ ከዚያም ረድፎቹን ያጠቃልሉ ወይም በቅድሚያ ይመድቡ።
- **መልሶ መጻፍ / ምዝግብ ማስቀመጥ** — የስብሰባ ማስታወሻዎችን፣ የክንውን ማጠቃለያዎችን ወይም የወኪል ውጤትን ወደ ነባር ገጽ ለማከል `notion_append_blocks`ን ይጠቀሙ (መጨመር ብቻ፤ አጥፊ አርትዖቶች የሉም)።
- **የመዋቅር ዳሰሳ** — የአንድን ገጽ የብሎኮች ዛፍ ለመዳሰስ `notion_list_block_children`ን፣ ወይም ከመጠየቅዎ በፊት የውሂብ ጎታውን የባህሪ መርሃግብር ለማወቅ `notion_get_database`ን ይጠቀሙ።
