## ምንድን ነው

Local Corpus አንድ አስተዳዳሪ በግልጽ የተፈቀደ የጽሑፍ ፋይሎች ማውጫን ለOmniRoute MCP አገልጋይ እንዲያቀርብ ያስችለዋል። ፋይሎቹ በመጀመሪያው ማውጫቸው ውስጥ ይቆያሉ፦ OmniRoute በSQLite ውስጥ የሚያከማቸው መደበኛውን የስር ዱካ ብቻ ሲሆን፣ በማህደረ ትውስታ ውስጥ ያለ የፍለጋ ማውጫን ይጠብቃል። የኮርፐስ ይዘትን ወደ ማከማቻው ወይም ዳታቤዙ አይቀዳም።

የማውጫው እድሳት ደረጃ በደረጃ የሚከናወን ነው። ያልተለወጡ ፋይሎች በመጠንና በተሻሻሉበት ጊዜ መሠረት እንደገና ጥቅም ላይ ይውላሉ፤ የተለወጡ ፋይሎች እንደገና ተነበው በSHA-256 ሃሽ ይደረጋሉ፣ የተሰረዙ ፋይሎችም ይወገዳሉ። ፍለጋ ከ30 ሰከንድ በላይ ያረጀ ማውጫን ያድሳል፤ ጠሪዎችም አፋጣኝ እድሳት ሊጠይቁ ይችላሉ።

## ምንጩን ማዋቀር

የቅንብሮች መስመሩ እንደሌሎች የቅንብሮች APIዎች ተመሳሳይ የአስተዳደር ማረጋገጫ ይፈልጋል። የሚላከው ዱካ አስቀድሞ ያለ መሆን እና ፍጹም የማውጫ ዱካ መሆን አለበት።

```bash
# የተፈቀደ ማውጫን ያገናኙ
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# ውቅሩን እና የማውጫውን ሁኔታ ያረጋግጡ
curl http://localhost:20128/api/settings/local-corpus

# የምንጭ ፋይሎችን ሳይቀይሩ ያላቅቁ
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP መሳሪያዎች

ሦስቱም መሳሪያዎች `read:local-corpus` ይፈልጋሉ። የመሳሪያዎቹ ምላሾች አንጻራዊ ዱካዎችን እና የስር ማውጫውን መሠረታዊ ስም ያሳያሉ፤ ፍጹም ዱካውን ፈጽሞ አያሳዩም።

| መሳሪያ                  | መግለጫ                                                                    |
| :-------------------- | :---------------------------------------------------------------------- |
| `local_corpus_status` | የውቅር ሁኔታን፣ የማውጫውን መጠን፣ ገደቦችን እና የመጨረሻውን የእድሳት ጊዜ ያሳውቃል                  |
| `local_corpus_search` | በማውጫ የተመዘገበ ጽሑፍን ይፈልጋል እና የተገደቡ፣ በመስመር የተወሰኑ ቅንጭቦችን ይመልሳል (እስከ 20 ውጤቶች) |
| `local_corpus_read`   | ከአንድ ከተፈቀደ የኮርፐስ-አንጻራዊ ፋይል የተገደበ የመስመር ክልል ያነባል                         |

የMCP ግብዓቶች ምሳሌ፦

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```
