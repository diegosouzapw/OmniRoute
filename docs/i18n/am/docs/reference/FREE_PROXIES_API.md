OmniRoute ከውጫዊ አቅራቢዎች (1proxy, proxifly, iplocate, webshare) የሚመሳሰል፣
በጥንቃቄ የተመረጠ የነፃ ፕሮክሲዎች ስብስብ በ`free_proxies` ሰንጠረዥ ውስጥ ይዞ ይመጣል።
ዳሽቦርዱ እነዚህን በ**Settings → Free Proxies** ስር ያሳያል። ይህ ሰነድ
የዝርዝሩ መንገድ የሚያቀርባቸውን የሰርቨር-ጎን ማጣሪያ፣ መደርደር፣ መቁጠር እና የማመሳሰል-ስህተት ሪፖርት አቀራረብ
ይሸፍናል።

## የዝርዝር መንገድ — `GET /api/settings/free-proxies`

የተጣራ፣ የተደረደረ እና በገጽ የተከፋፈለ ክፍል ከአጠቃላይ ብዛት ጋር ይመልሳል። ማጣራት እና
መቁጠር በSQL ውስጥ ይከናወናሉ፤ ስለዚህ UIው እያንዳንዱን ረድፍ ወደ ማህደረ ትውስታ ሳይጭን
ትክክለኛውን አጠቃላይ ብዛት (ለምሳሌ `Total: 0`) ማሳየት ይችላል።

### የጥያቄ መለኪያዎች

| መለኪያ              | ዓይነት                               | ነባሪ       | ትርጉም                                                                                                                           |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `search`          | ሕብረቁምፊ                             | `""`      | በአስተናጋጅ (እና ምንጭ) አምድ ላይ የፊደል መጠንን የሚለይ `LIKE`።                                                                                 |
| `protocol`        | ሕብረቁምፊ                             | `""`      | የ`type` ማጣሪያ፦ `http` / `https` / `socks4` / `socks5`። ባዶ = ሁሉም።                                                                |
| `country`         | ሕብረቁምፊ                             | `""`      | የ`countryCode` ማጣሪያ (ISO-2)። ባዶ = ሁሉም።                                                                                         |
| `minQuality`      | ቁጥር                                | `0`       | `qualityScore >= minQuality` የሆኑ ረድፎች ብቻ። `0` = ዝቅተኛ ገደብ የለም።                                                                  |
| `disabledSources` | ሕብረቁምፊ                             | `""`      | ለማስወገድ በኮማ የተለዩ የምንጭ መለያዎች (ለምሳሌ `proxifly,webshare`)።                                                                         |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = ውጤት በወራጅ ቅደም ተከተል፤ `latency` = መዘግየት በዕድገት ቅደም ተከተል (null ዋጋዎች መጨረሻ ላይ)፤ `recent` = `lastValidated` በወራጅ ቅደም ተከተል። |
| `offset`          | ቁጥር                                | `0`       | የገጽ ክፍፍል መጀመሪያ።                                                                                                                |
| `limit`           | ቁጥር                                | `50`      | የገጽ መጠን (በሰርቨር በኩል ገደብ ይደረግበታል)።                                                                                               |

### ምላሽ

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` ከገጽ ክፍፍል **በፊት** ያለውን የተጣራ አጠቃላይ ብዛት ያመለክታል፤ ስለዚህ UIው
`Total: N` እና `hasMore`ን በተናጥል ማሳየት ይችላል። `syncErrors` በምንጭ መለያ ቁልፍ የተደረገ ሲሆን
የመጨረሻው ማመሳሰላቸው ለከሸፈባቸው ምንጮች ብቻ ይሞላል — የ`Total: 0` ውጤት
ፈጽሞ ያለ ማብራሪያ አይቀርም።

## ወደ ስብስብ ማከል — `POST /api/settings/free-proxies/[id]/add-to-pool`

አንድን ነፃ ፕሮክሲ ወደሚተዳደረው የ`proxy_registry` ስብስብ ያስገባል። በመጀመሪያ
የላይኛውን ምንጭ ያረጋግጣል፤ ሲሳካ የአዲሱን የስብስብ ፕሮክሲ መለያ እና የተለካውን መዘግየት ይመልሳል።

## ማመሳሰል — `POST /api/settings/free-proxies/sync`

ሁሉንም የነቁ ምንጮች (ወይም በ`{ "sources": [...] }` ውስጥ ያለውን ንዑስ ስብስብ) እንደገና
ይስባል። እያንዳንዱ ምንጭ በተናጥል ይመሳሰላል፤ የከሸፈ ምንጭ በ`syncErrors` ውስጥ ይመዘገባል እና
ሌሎቹ መጠናቀቃቸውን ይቀጥላሉ፤ ስለዚህ ከፊል ማመሳሰሎች ቀደም ሲል የነበሩ ትክክለኛ ውሂቦችን ፈጽሞ አያጠፉም።

## ስታቲስቲክስ — `GET /api/settings/free-proxies/stats`

የረድፍ ውሂብ ሳይካተት የ`total / inPool / avgQuality / bySource / lastSyncAt` ድምርን
ይመልሳል — ይህም በዳሽቦርዱ ራስጌ መግብሮች ጥቅም ላይ ይውላል።
