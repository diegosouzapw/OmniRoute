## የToS ትኩረት ሰንጠረዥ

> **የToS ምልክት ምክር ሰጪ እንጂ የማስተላለፍ መግቢያ መቆጣጠሪያ አይደለም።** `tos` ምልክት ያላቸው አቅራቢዎች በነባሪነት በማስተላለፍ እና combo/fallback ውስጥ አሁንም ይካተታሉ፤ ምልክቱ የሚታየው በ`/dashboard/free-tiers` እና `/api/free-tier/summary` ላይ ብቻ ነው። የ`excludeTosAvoid` የጥያቄ መለኪያ የሚነካው የማጠቃለያ እይታውን ብቻ እንጂ አጠቃላይ ማስተላለፉን አይደለም። ውሳኔው በ`open-sse/config/freeTierCatalog.ts` ውስጥ ይገኛል (መረጃ ሰጪ ነው፣ በማስተላለፊያ ሞተሮች አይነበብም)።

> ራስ-አስተናጋጅ፣ ለአንድ ተጠቃሚ የግል ፕሮክሲ በተመለከተ የእያንዳንዱን አቅራቢ ውሎች በፍጥነት የሚያሳይ ንባብ። `caution` = ሊመረመር የሚገባው የግል አጠቃቀም ወይም የፕሮክሲ ድንጋጌ፤ `ambiguous` = ግልጽ ያልሆነ፤ `ok` = በግልጽ የተፈቀደ። ይህ መረጃ ሰጪ እንጂ የሕግ ምክር አይደለም — የሚወስኑት እርስዎ ነዎት።
