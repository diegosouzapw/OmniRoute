| ንጥል        | ዝቅተኛ               | የሚመከር            |
| ---------- | ------------------ | ---------------- |
| **CPU**    | 1 vCPU             | 2 vCPU           |
| **RAM**    | 1 GB               | 2 GB             |
| **ዲስክ**    | 10 GB SSD          | 25 GB SSD        |
| **OS**     | Ubuntu 22.04 LTS   | Ubuntu 24.04 LTS |
| **ዶሜይን**   | በCloudflare የተመዘገበ | —                |
| **Docker** | Docker Engine 24+  | Docker 27+       |

## 1. VMን ያዋቅሩ

### 1.1 ኢንስታንሱን ይፍጠሩ

በመረጡት VPS አቅራቢ ላይ፦

- Ubuntu 24.04 LTSን ይምረጡ
- ዝቅተኛውን ዕቅድ (1 vCPU / 1 GB RAM) ይምረጡ
- ጠንካራ የroot የይለፍ ቃል ያዘጋጁ ወይም SSH key ያዋቅሩ
- **ይፋዊ IP**ውን ይመዝግቡ (ለምሳሌ፣ `203.0.113.10`)

### 1.2 በSSH ይገናኙ

```bash
ssh root@203.0.113.10
```

### 1.3 ስርዓቱን ያዘምኑ

```bash
apt update && apt upgrade -y
```

### 1.4 Dockerን ይጫኑ

```bash
# ጥገኛ ጥቅሎችን ይጫኑ
apt install -y ca-certificates curl gnupg

# ይፋዊውን የDocker ማከማቻ ያክሉ
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $ (. /etc/os-release && echo "$VERSION_CODENAME") stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

### 1.5 nginxን ይጫኑ

```bash
apt install -y nginx
```

### 1.6 Firewall (UFW)ን ያዋቅሩ

```bash
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp    # SSH
ufw allow 80/tcp    # HTTP (ማዘዋወሪያ)
ufw allow 443/tcp   # HTTPS
ufw enable
```

> **ጠቃሚ ምክር**: ለከፍተኛ ደህንነት፣ ports 80 እና 443ን ለCloudflare IPs ብቻ ይገድቡ። የ[የላቀ ደህንነት](#advanced-security) ክፍልን ይመልከቱ።

```bash
cat > /opt/omniroute/.env << 'EOF'

# ለOAuth callbacks፣ dashboard links እና ለሚፈጠሩ ይፋዊ URLs የሚያገለግል ለbrowser የሚታይ URL።

# ለሚፈጠሩ ይፋዊ የasset URLs አማራጭ ግልጽ የpublic origin መተኪያ።
# OMNIROUTE_PUBLIC_BASE_URL=https://llms.seudominio.com

# === Cloud Sync (አማራጭ) ===
# CLOUD_URL=https://cloud.omniroute.online
```

## 3. nginx ያዋቅሩ (ተገላቢጦሽ ፕሮክሲ)

### 3.1 የSSL ሰርተፍኬት ይፍጠሩ (Cloudflare Origin)

በCloudflare ዳሽቦርድ ውስጥ፦

1. ወደ **SSL/TLS → Origin Server** ይሂዱ
2. **Create Certificate** የሚለውን ጠቅ ያድርጉ
3. ነባሪ ቅንብሮቹን ይተዉ (15 ዓመታት፣ \*.yourdomain.com)
4. **Origin Certificate** እና **Private Key** ይቅዱ

```bash
mkdir -p /etc/nginx/ssl

# ሰርተፍኬቱን እዚህ ይለጥፉ
nano /etc/nginx/ssl/origin.crt

# የግል ቁልፉን እዚህ ይለጥፉ
nano /etc/nginx/ssl/origin.key

chmod 600 /etc/nginx/ssl/origin.key
```

### 3.2 የNginx ውቅር

```bash
cat > /etc/nginx/sites-available/omniroute << 'NGINX'
# ነባሪ ሰርቨር — በIP በኩል በቀጥታ መድረስን ያግዳል
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    listen 443 ssl default_server;
    listen [::]:443 ssl default_server;
    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    server_name _;
    return 444;
}

# OmniRoute — HTTPS
server {
    listen 443 ssl;
    listen [::]:443 ssl;
    server_name llms.yourdomain.com;  # ወደ ዶሜንዎ ይቀይሩ

    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    client_max_body_size 100M;

    location / {
        proxy_pass http://127.0.0.1:20128;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # የWebSocket ድጋፍ
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # SSE (Server-Sent Events) — የAI ምላሾችን በዥረት ማስተላለፍ
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }
}

# HTTP → HTTPS ማዘዋወር
server {
    listen 80;
    listen [::]:80;
    server_name llms.yourdomain.com;
    return 301 https://$server_name$request_uri;
}
NGINX
```

የተገላቢጦሽ ፕሮክሲ ዥረት የጊዜ ገደቦችን ከOmniRoute የጊዜ ገደብ env vars ጋር የተመሳሰሉ አድርገው ያቆዩ።
`FETCH_TIMEOUT_MS` / `STREAM_IDLE_TIMEOUT_MS` ከፍ ካደረጉ፣ `proxy_read_timeout` / `proxy_send_timeout`ን
ከተመሳሳዩ ገደብ በላይ ከፍ ያድርጉ።

OmniRoute `NEXT_PUBLIC_BASE_URL`ን ለOAuth የመልስ ጥሪዎች እና ለሚፈጠሩ ይፋዊ አገናኞች
ዋናው ለአሳሽ የሚታይ origin አድርጎ ይጠቀማል። ማንነታቸው የተረጋገጠ የዳሽቦርድ የመጻፍ ጥያቄዎች same-origin ጥያቄዎችን
ከክፍለ-ጊዜ ጋር የተያያዘ የCSRF ጥበቃ ጋር ስለሚጠቀሙ፣ ቋሚ ይፋዊ base URL አያስፈልጋቸውም። ከላይ ያሉት
`X-Forwarded-*` headers አሁንም ጠቃሚ የማዘዋወሪያ metadata ናቸው፣ ነገር ግን OAuth ወይም የሚፈጠሩ የአሳሽ አገናኞች ሲያስፈልጉ
ግልጽ የሆነውን ይፋዊ URL ከማዘጋጀት አይተኩም። OmniRoute በደንበኞች በቀጥታ ሊደረስበት የማይችል ከሆነ እና ፕሮክሲዎ
ወደ ውስጥ የሚገቡ forwarded headersን የሚያስወግድ/እንደገና የሚገነባ ከሆነ ብቻ
`OMNIROUTE_TRUST_PROXY`ን ያንቁ።

## የአነስተኛ ማህደረ ትውስታ / አነስተኛ VPS ማመቻቸት

በአነስተኛ VPS ኢንስታንሶች (1 GB RAM ወይም ከዚያ በታች) ላይ ለሚደረጉ ስምሪቶች፦

- **የጀርባ አገልግሎቶችን ያሰናክሉ** — መርሐግብር አስኪያጁን፣ MCP አገልጋዩን እና ወቅታዊ የጥገና ተግባራትን ለመዝለል `OMNIROUTE_DISABLE_BACKGROUND_SERVICES=1` ያዘጋጁ። `docs/reference/ENVIRONMENT.md`ን ይመልከቱ።
- **የSQLite WAL ሁነታን ይጠቀሙ** — በነባሪ የነቃ ሲሆን፣ በተመሳሳይ ጊዜ በሚከናወኑ ንባቦች ወቅት ከፍተኛውን የማህደረ ትውስታ አጠቃቀም ይቀንሳል።
- **የV8 heap ገደብ ያስቀምጡ** — runtime ከVM የሚበልጥ ከፍተኛ ገደብ እንዳያሰላ `OMNIROUTE_MEMORY_MB`ን (ለምሳሌ `512`) ያዘጋጁ። `docs/reference/ENVIRONMENT.md`ን ይመልከቱ።
- **ከባድ ጭነቶችን የመቀበል አቅም ከheap ገደቡ ጋር በራስ-ሰር ይመጣጠናል** -- `OMNIROUTE_MEMORY_MB` ከላይ አንዴ ከተዋቀረ፣ የግብዓት ባይት በጀቱ (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) ከዚያው ገደብ ራሱን ያመነጫል፤ ስለዚህ የማህደረ ትውስታ ገደብ ያለበት VM ያለ ተጨማሪ ማስተካከያ አነስተኛ የተመሳሳይ ጊዜ ጥያቄዎች በጀት ያገኛል፤ ከመጠን በላይ የሆኑ ጥያቄዎች ለማህደረ ትውስታ ከመፎካከር ይልቅ እንደገና ሊሞከር የሚችል `503` ከ`Retry-After` ጋር ያገኛሉ። ከዚያ በተጨማሪ ጥብቅ ከፍተኛ ገደብ ካስፈለገዎት ብቻ የቀድሞውን `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` የጥያቄ-ብዛት ገደብ ያዘጋጁ።
- **በVPS ላይ `next build`ን ያስወግዱ** — በአካባቢዎ ይገንቡና ራሱን የቻለውን ውጤት (`.next/standalone/`) ያሰማሩ።
