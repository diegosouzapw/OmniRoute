## ደረጃ 1፦ OmniRouteን ይጫኑ

የሚመርጡትን ዘዴ ይምረጡ፦

### አማራጭ A፦ npm (የሚመከር)

```bash
npm install -g omniroute
```

### አማራጭ B፦ Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` ከታተሙት የተረጋጉ SemVer ስሪቶች ከፍተኛው ነው። git `main`ን **አይከታተልም**። ለGitOps `diegosouzapw/omniroute:X.Y.Z`ን ይወስኑ። [የምስል መለያዎች / የልቀት ቻናሎች](../guides/DOCKER_GUIDE.md#release-channels)ን ይመልከቱ።

### አማራጭ C፦ ከምንጭ ኮድ

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## ደረጃ 2፦ OmniRouteን ያስጀምሩ

```bash
omniroute
```

OmniRoute በ`http://localhost:20128` ይጀምራል። ዳሽቦርዱ በራስ-ሰር ይከፈታል።

---

## ደረጃ 3፦ ነፃ አቅራቢን ያገናኙ

ነፃ አቅራቢን በማገናኘት OmniRouteን **ምንም ክፍያ ሳይከፍሉ** መጠቀም ይችላሉ።

### አማራጭ A፦ Kiro (ነፃ Claude — የክሬዲት ካርድ አያስፈልግም)

1. በ`http://localhost:20128` ያለውን ዳሽቦርድ ይክፈቱ
2. ወደ **አቅራቢዎች** → **አቅራቢ አክል** ይሂዱ
3. **Kiro AI**ን ይምረጡ
4. **አገናኝ**ን ጠቅ ያድርጉ (የAPI ቁልፍ አያስፈልግም!)
5. ተጠናቋል! አሁን የClaude ሞዴሎችን በነፃ መጠቀም ይችላሉ።

### አማራጭ B፦ OpenCode Free (ማረጋገጫ አያስፈልግም)

1. በ`http://localhost:20128` ያለውን ዳሽቦርድ ይክፈቱ
2. ወደ **አቅራቢዎች** → **አቅራቢ አክል** ይሂዱ
3. **OpenCode Free**ን ይምረጡ
4. **አገናኝ**ን ጠቅ ያድርጉ (የAPI ቁልፍ አያስፈልግም!)
5. ተጠናቋል! አሁን በርካታ ሞዴሎችን በነፃ መጠቀም ይችላሉ።

### አማራጭ C፦ Pollinations (ቁልፍ አያስፈልግም)

1. በ`http://localhost:20128` ያለውን ዳሽቦርድ ይክፈቱ
2. ወደ **አቅራቢዎች** → **አቅራቢ አክል** ይሂዱ
3. **Pollinations**ን ይምረጡ
4. **አገናኝ**ን ጠቅ ያድርጉ (የAPI ቁልፍ አያስፈልግም!)
5. ተጠናቋል! አሁን GPT-5፣ Claude፣ Gemini እና ሌሎችንም በነፃ መጠቀም ይችላሉ።

---

## ደረጃ 4፦ እንደሚሠራ ያረጋግጡ

ከ[API ቁልፎች](http://localhost:20128/dashboard/api-manager) አዲስ ቁልፍ ይፍጠሩ። ይህ ቁልፍ እንደገና ስለማይታይ በደህና ያስቀምጡት። ይህ ቁልፍ መሣሪያዎች OmniRouteን እንዲያገኙበት እንጂ የላይኛውን አቅራቢዎች ለመድረስ እንዳልሆነ ያስታውሱ።

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

ያገናኟቸው ሞዴሎች ተዘርዝረው መታየት አለባቸው።

## ደረጃ 5፦ IDEዎን ወይም CLIዎን ወደ OmniRoute ያመልክቱ

በIDEዎ ወይም በCLI መሣሪያዎ ውስጥ የሚከተሉትን ያዋቅሩ፦

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

ይኸው ነው! አሁን IDEዎ በራስ-ሰር የአቅራቢ ምርጫ ከሚያደርገው OmniRoute ጋር ይሠራል።

### የIDE ምሳሌ፦ VSCode/Continue.dev

1. በVSCode ውስጥ የ[Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ቅጥያን ይጫኑ።
2. የሚከተሉትን መስመሮች ለማከል `~/.continue/config.yaml`ዎን ያዘምኑ፦

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. በContinue.dev የውይይት ፓነል ውስጥ `OmniRoute - Auto`ን ይምረጡ፤ ከዚያም ጥያቄዎችን ወደ OmniRoute ይልካሉ።
4. (አማራጭ) ለአንባቢው ልምምድ — IDEዎ በቅድሚያ በተገነቡት ሌሎች ውቅሮች በሙሉ `config.yaml`ን እንዲያዘምን ያድርጉ 😊

### የCLI ምሳሌ፦ Codex CLI

1. በክወና ስርዓትዎ ውስጥ የአካባቢ ተለዋዋጩን ቋሚ አድርገው ያዋቅሩ።
   ለmacOS/Linux (ወደ `~/.bashrc` ወይም `~/.zshrc`ዎ ያክሉ)፦

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

ለWindows (Command Prompt)፦

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. አሁን Codexን ለOmniRoute በተዋቀረ መልኩ እናስጀምር። ይህን ያስኪዱ፦

```
omniroute launch-codex --model auto
```

endpointን እና api keyን ለመወሰን `codex`ን እና የትዕዛዝ መስመር መለኪያዎችን በመጠቀም ይህንን በእጅ ማድረግ ይችላሉ፤ ነገር ግን ከላይ ባለው ትዕዛዝ OmniRoute ሁሉንም ነገር ያከናውንልዎታል።

ተመሳሳዩ የአንድ-ትዕዛዝ ማስጀመሪያ በአጠቃላይ ማስጀመሪያው በኩል ለሌሎች CLIዎችም ይሠራል — `omniroute run <target>`፣ `claude`፣ `codex`፣ `aider`፣ `goose`፣ `opencode`፣ `qwen` እና `gemini`ን ይደግፋል ([የCLI ውህደቶች](../guides/CLI-INTEGRATIONS.md)ን ይመልከቱ)።

3. አሁን CLIው ጥያቄዎችን ወደ OmniRoute መላክ አለበት።

### መሣሪያዎ ወደ OmniRoute እያስተላለፈ መሆኑን ያረጋግጡ

ከግራ የጎን አሞሌው [ክትትል/ምዝግብ ማስታወሻዎች](http://localhost:20128/dashboard/logs)ን ጠቅ በማድረግ የጥያቄውን ዝርዝር ማየት ይችላሉ። ወደ ውስጥ ጠቅ በማድረግ ተጨማሪ ዝርዝሮችን ያያሉ። በተጨማሪም ከሚወዱት harness ምን መረጃ እንደሚላክ ማየት ይችላሉ። ይህ ከትምህርት እና ከስህተት ማረም አንጻር ጠቃሚ ነው።

## የተለመዱ ጥያቄዎች

### "የAPI ቁልፍ ያስፈልገኛል?"

**አይ!** ነፃ አቅራቢዎችን (Kiro፣ OpenCode Free፣ Pollinations) ያለምንም የAPI ቁልፍ መጠቀም ይችላሉ። በዳሽቦርዱ ውስጥ ብቻ ያገናኟቸው።

### "`auto` ምንድን ነው?"

`auto`፣ OmniRoute ለእያንዳንዱ ጥያቄ ምርጡን አቅራቢ በራስ-ሰር እንዲመርጥ ያዛል። ፍጥነትን፣ ወጪን፣ ጥራትን እና ተገኝነትን ከግምት ያስገባል። ለዝርዝሮች [የAuto-Combo መመሪያ](./AUTO-COMBO-GUIDE.md)ን ይመልከቱ።

### "ምን ያህል ያስከፍላል?"
