Web Cookie አቅራቢዎች OmniRoute የAPI ቁልፍን ከመጠቀም ይልቅ በነባሩ የአሳሽ ክፍለ-ጊዜዎ በኩል የAI አገልግሎትን እንዲጠቀም ያስችሉታል። በድረ-ገጹ በኩል የአገልግሎቱ መዳረሻ ካለዎት እና OmniRoute ያንኑ ማንነቱ የተረጋገጠ ክፍለ-ጊዜ እንዲጠቀም ሲፈልጉ ጠቃሚ ናቸው።

ከAPI-key አቅራቢዎች በተለየ፣ Web Cookie አቅራቢዎች አሳሽዎ ወደ ድረ-ገጹ የሚልካቸውን የማረጋገጫ መረጃዎች በመጠቀም ማንነትን ያረጋግጣሉ።

# ከመጀመርዎ በፊት

> **አስፈላጊ፦** የማረጋገጫ መረጃዎችን ሁልጊዜ ከ**ቀጥታ የአውታረ መረብ ጥያቄ** ይቅዱ፤ ከአሳሽዎ cookie ማከማቻ **አይቅዱ**።

ብዙ የማንነት ማረጋገጫ ችግሮች የሚከሰቱት cookies ከተሳሳተ ቦታ በመቅዳት ነው።

## ከCookie ማከማቻ አይቅዱ

አብዛኛዎቹ አሳሾች የተከማቹ cookiesን በሚከተለው መንገድ ያሳያሉ፦

```
DevTools
→ Application (ወይም Storage)
→ Cookies
```

እነዚህ cookies ትክክል ቢመስሉም፣ ምናልባት፦

- ጊዜ ያለፈባቸው
- ያልተሟሉ
- በማንነት በተረጋገጡ ጥያቄዎች ላይ ብቻ የሚላኩ cookies የጎደሏቸው

ሊሆኑ ይችላሉ።

እነዚህን እሴቶች መጠቀም፣ ትክክል ቢመስሉም እንኳ፣ የማንነት ማረጋገጫ እንዳይሳካ ሊያደርግ ይችላል።

## ከቀጥታ ጥያቄ ይቅዱ

በምትኩ፣ ከተሳካ ጥያቄ የተገኙትን cookies ይጠቀሙ፦

```
DevTools
→ Network
→ ገጹን ያድሱ
→ የውይይት ወይም የንግግር ጥያቄ ይክፈቱ
→ Request Headers
→ Cookie
```

የ`Cookie` ጥያቄ ራስጌ አሳሽዎ በተሳካ ሁኔታ የተጠቀመበትን ትክክለኛ የማንነት ማረጋገጫ መረጃ ይዟል።

ለአብዛኛዎቹ Web Cookie አቅራቢዎች፣ ይህ ወደ OmniRoute መለጠፍ ያለበት እሴት ነው።

---

# አጠቃላይ ማዋቀር

ለአብዛኛዎቹ Web Cookie አቅራቢዎች የማዋቀር ሂደቱ ተመሳሳይ ነው።

1. ወደ አቅራቢው ድረ-ገጽ ይግቡ።
2. የአሳሹን Developer Tools ይክፈቱ።
3. የ**Network** ትርን ይክፈቱ።
4. ገጹን ያድሱ።
5. ማንነቱ የተረጋገጠ የውይይት ወይም የንግግር ጥያቄ ይክፈቱ።
6. የሚያስፈልጉትን የማረጋገጫ መረጃዎች ይቅዱ።
7. OmniRouteን ይክፈቱ።
8. ወደ **Providers → Add Provider** ይሂዱ።
9. የWeb Cookie አቅራቢዎን ይምረጡ።
10. የማረጋገጫ መረጃዎቹን ይለጥፉ።
11. **Test Connection**ን ጠቅ ያድርጉ።
12. አቅራቢውን ያስቀምጡ።

የሚያስፈልጉት ትክክለኛ የማረጋገጫ መረጃዎች እንደ አቅራቢው ይለያያሉ።

# Web Cookie አቅራቢዎች ምን ማድረግ ይችላሉ እና ምን ማድረግ አይችሉም

Web Cookie አቅራቢዎች የድረ-ገጽን የውይይት በይነገጽ እንደገና ይጠቀማሉ። ከይፋዊ APIs ጋር ተመሳሳይ ችሎታዎችን **አይሰጡም**።

## የሚደገፉ

- ነባሩን የአሳሽ ክፍለ-ጊዜዎን በመጠቀም ማንነትን ማረጋገጥ
- በመለያዎ በኩል የሚገኙ ሞዴሎችን መድረስ
- የውይይት ምላሾችን በዥረት መቀበል
- የAPI ቁልፍ አያስፈልግም

## የማይደገፉ

- የፈንክሽን ጥሪ
- የመሣሪያ ጥሪ
- ራስ-ሰር የፋይል አርትዖት
- በወኪል የሚከናወኑ የIDE የሥራ ፍሰቶች
- በAPI ብቻ የሚገኙ ባህሪያት

ይህ የሚጠበቅ ባህሪ ነው እና ስህተት **አይደለም**።

የመሣሪያ አፈጻጸም፣ ራስ-ሰር የፋይል አርትዖት ወይም ሌሎች የወኪል የሥራ ፍሰቶች ካስፈለጉዎት፣ ከWeb Cookie አቅራቢ ይልቅ **API-key አቅራቢ** ይጠቀሙ።

# የማረጋገጫ ገደብ

የማንነት ማረጋገጫ አሁንም ካልተሳካ፣ የማረጋገጫ መረጃዎቹን ከአሳሽ cookie ማከማቻ ሳይሆን ከቀጥታ የአውታረ መረብ ጥያቄ መቅዳትዎን ያረጋግጡ።

```
Application
→ Cookies
```
