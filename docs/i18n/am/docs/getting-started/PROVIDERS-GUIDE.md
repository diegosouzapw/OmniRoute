## አቅራቢ ምንድን ነው?

አቅራቢን እንደ **የስልክ አገልግሎት አቅራቢ** ያስቡት። ጥሪዎችን ለማድረግ የስልክ አገልግሎት አቅራቢ እንደሚያስፈልግዎት ሁሉ፣ AI ሞዴሎችን ለመጠቀም የAI አቅራቢ ያስፈልግዎታል። OmniRoute ከ**ሁሉም አቅራቢዎች** ጋር እንደሚሰራ ስልክ ነው — በመካከላቸው በራስ-ሰር መቀያየር ይችላሉ።

| ----------- | ------------------- | --------------------------------- | ---------------- |

## ፈጣን ጅምር፦ የመጀመሪያ አቅራቢዎን ያገናኙ

### አማራጭ የመጀመሪያ አጠቃቀም የነፃ አቅራቢ ማዋቀር

የመጀመሪያ አጠቃቀም አዋቂው ግልጽ የሆነ **ነፃ አቅራቢዎችን ያዋቅሩ** ካርድ ያቀርባል። አሁን ብቁ የሆኑትን
ዝርዝር ከOmniRoute ማረጋገጫ የማይፈልጉ አቅራቢዎች መዝገብ ያዘጋጃል፤ ከዚያም ከማረጋገጥዎ በፊት እያንዳንዱን
አቅራቢ እንዲገመግሙና ምርጫውን እንዲያነሱ ያስችልዎታል። OmniRoute መጀመሪያ የሦስተኛ ወገን ውሎችን፣ ግላዊነትን፣ ተገኝነትን እና የአጠቃቀም መጠን ገደቦችን
እንዲገመግሙ የአቅራቢውን የጥንቃቄ ማስታወቂያ እና ወደ ጣቢያው የሚወስድ አገናኝ ያሳያል።

ይህ እርምጃ አማራጭ ነው፦ አዋቂውን መጨረስ በስውር የነፃ አቅራቢ ግንኙነቶችን አይፈጥርም።
አሁንም የሌሉትን አቅራቢዎች ብቻ ይፈጥራል፣ ነባር የተበጁ ግንኙነቶችን
ሳይነካ ይተዋል፣ እንዲሁም የተፈጠሩ፣ አስቀድመው የተዋቀሩ እና ያልተሳኩ አቅራቢዎችን በተናጠል ሪፖርት ያደርጋል። ከፊል ውጤት ከተገኘ በኋላ
ያልተሳኩትን ብቻ ያለስጋት እንደገና መሞከር ይችላሉ።

### አማራጭ A፦ ነፃ አቅራቢ (የብድር ካርድ አያስፈልግም)

1. ዳሽቦርዱን በ`http://localhost:20128` ይክፈቱ
2. ወደ **አቅራቢዎች** → **አቅራቢ ያክሉ** ይሂዱ
3. ከእነዚህ ነፃ አቅራቢዎች አንዱን ይምረጡ፦
   - **Kiro AI** — ነፃ Claude ሞዴሎች (ማረጋገጫ አያስፈልግም)
   - **OpenCode Free** — ነፃ GPT ሞዴሎች (ማረጋገጫ አያስፈልግም)
   - **Pollinations** — ነፃ GPT-5፣ Claude፣ Gemini (ቁልፍ አያስፈልግም)
   - **LongCat** — 10M ቶከኖች በነፃ (የአንድ ጊዜ ስጦታ፣ መለያ + KYC ያስፈልጋል)
   - **Cloudflare AI** — 50+ ሞዴሎች፣ 10K ኒውሮኖች/ቀን
   - **MLX Gemma 26B** — የአካባቢ Apple Silicon ሞዴል (~38.5 ቶከን/ሰከንድ፣ ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — የአካባቢ Apple Silicon ሞዴል (~9.1 ቶከን/ሰከንድ፣ ~13.1GB RAM)
4. **አገናኝ**ን ጠቅ ያድርጉ
5. ተጠናቋል! አሁን ነፃ የAI መዳረሻ አለዎት።

### አማራጭ D፦ የአካባቢ MLX ሞዴሎች (Apple Silicon)

የተዋሃደ ማህደረ ትውስታ ላላቸው Apple Silicon Mac ኮምፒውተሮች፣ OmniRoute በ`mlx-lm.server` በኩል እየሰሩ ካሉ የአካባቢ MLX ሞዴሎች ጋር እንደ መደበኛ OpenAI-ተኳሃኝ የአካባቢ አቅራቢዎች መገናኘትን ይደግፋል።

#### ቅድመ ሁኔታዎች

- **Apple Silicon Mac** (M1/M2/M3/M4)፤ 24GB+ የተዋሃደ ማህደረ ትውስታ ይመከራል
- **uv** የፓኬጅ አስተዳዳሪ፦ `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### ፈጣን ጅምር

1. **ጥገኞችን ይጫኑ**፦

   ```bash
   # uv አስቀድሞ ካልተጫነ ይጫኑ
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lmን ይጫኑ
   uv pip install mlx-lm
   ```

2. **የMLX አገልጋዮችን በእጅ ያስጀምሩ** (በተለያዩ ተርሚናሎች)፦

   ```bash
   # ተርሚናል 1፦ Gemma 4 26B A4B IT-QAT (ወደብ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ተርሚናል 2፦ Qwen 3.8 27B MLX Mixed (ወደብ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **በOmniRoute ዳሽቦርድ ውስጥ ያገናኙ**፦
   - ወደ **አቅራቢዎች** → **አቅራቢ ያክሉ** ይሂዱ
   - **MLX Gemma 26B** ወይም **MLX Qwen 3.8 27B**ን ይምረጡ
   - **አገናኝ**ን ጠቅ ያድርጉ (API ቁልፍ አያስፈልግም)

4. **ከOpenCode ጋር ይጠቀሙ**፦
   ```bash
   # OpenCode OmniRouteን እንዲጠቀም ያዋቅሩ
   opencode config set api.base_url http://localhost:20128/v1
   ```

### "ብዙ አቅራቢዎችን በአንድ ጊዜ መጠቀም እችላለሁ?"

**አዎ!** የOmniRoute ዋና ዓላማ ይህ ነው። ብዙ አቅራቢዎችን ያገናኙ እና OmniRoute ለእያንዳንዱ ጥያቄ ምርጡን እንዲመርጥ `model: "auto"`ን ይጠቀሙ።

### "አንድ አቅራቢ መስራት ቢያቆምስ?"

OmniRoute ያልተሳኩ አቅራቢዎችን በራስ-ሰር ይዘላቸዋል እና ቀጣዩን ይሞክራል። እርስዎ ምንም ማድረግ አያስፈልግዎትም።

### "አቅራቢን እንዴት አለያያለሁ?"

ወደ አቅራቢዎች ይሂዱ → አቅራቢውን ጠቅ ያድርጉ → **ግንኙነት ያቋርጡ**ን ጠቅ ያድርጉ።

### "ነባር የAPI ቁልፎቼን መጠቀም እችላለሁ?"

**አዎ!** ቀድሞውኑ ለOpenAI፣ Anthropic፣ Google፣ ወዘተ የAPI ቁልፎች ካሉዎት፣ በOmniRoute ውስጥ ሊጠቀሙባቸው ይችላሉ። አቅራቢውን ሲያገናኙ ቁልፎቹን ብቻ ይለጥፉ።
