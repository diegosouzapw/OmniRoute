አብነት፦ xquik #11370 (በ release/v3.8.51 ውስጥ ተዋህዷል)። አቋም፦ `fallbackOnly`።
የላይኛው ምንጭ ሀሳብ፦ issue diegosouzapw/OmniRoute#11637።

## 1. የአገልግሎቱ ትክክለኛ መረጃ (ኦፊሴላዊ ሰነዶች፣ በሌሎች ምንጮች የተረጋገጠ)

- መሠረታዊ URL፦ `https://api.anysearch.com` (REST) + `POST /mcp` (MCP፣ JSON-RPC 2.0)።
- `POST /v1/search` - መለኪያዎች፦ `query` (ያስፈልጋል)፣ `max_results` (1-10፣ ነባሪ 10)፣ `tag` (`{domain}.{sub_domain}` ቋሚ አቅጣጫ ማስተላለፊያ)፣ `zone` (cn/intl)፣ `language`፣ `params` (መዋቅራዊ ቋሚ መስኮች)፣ `format` (json/markdown)።
- `GET /v1/sub-domains?domain=...` - የችሎታ ካታሎግ፤ በኮታው ላይ አይቆጠርም።
- `POST /v1/extract` - `{url, title, content}`ን ያመጣል/ያወጣል፤ ጥብቅ JSON body፣ የ16 KiB ገደብ።
- `POST /v1/auth/email/register` - በአንድ ጥሪ ምዝገባ፤ ለአንድ ጊዜ ብቻ የሚያገለግል ያልተመሰጠረ ቁልፍ `as_sk_...` ይመልሳል።
- ማረጋገጫ፦ አማራጭ `Authorization: Bearer <as_sk_...>`፤ ማንነቱ ያልተገለጸ ጥያቄ የዕለታዊውን ነፃ ኮታ ወደሚጠቀሙ በ-IP ገደቦች ይወርዳል፤ ልክ ያልሆነ ቁልፍ፣ ዝምተኛ ወደ ማንነት-አልባ ሁኔታ መመለሻ ሳይኖር፣ 401/403 ይመልሳል።
- ነፃ ደረጃ፦ በቀን 1000 ጥያቄዎች፣ በእያንዳንዱ ቁልፍ 20 QPS። የሚከፈልበት ደረጃ፦ ዋጋው አልተወሰነም (በቅርቡ ይመጣል)።
- የምላሽ መጠቅለያ፦ ስኬት `{code: 0, message: "success", request_id, data}`፤ ውድቀት `{code: -1, message}`። የማረጋገጫ/ኮታ ስህተቶች መዋቅራዊ `error_code` የላቸውም (የመልዕክቱ ጽሑፍ ምልክቱ ነው)፤ ለማውጣት ብቻ የተወሰኑ ስህተቶች ግን `error_code` (`invalid_extract_url`፣ `extract_failed`) አላቸው። በ429 ላይ `Retry-After` header የለም።

## 3. ውሳኔዎች (ሁሉም 2026-08-26 ላይ የተደረሱ)

1. **የራውቲንግ አቋም፦ `fallbackOnly`።** ምክንያት፦ ወጪው 0 የሆነ ነፃ አቅራቢ በራስ-ሰር የወጪ ራውቲንግ ላይ ፈጽሞ የበላይነት ሊኖረው አይገባም፤ ግልጽ ምርጫ እና የመክሸፍ ሽግግር ውጤት አይነኩም። ቀዳሚ ምሳሌ፦ የተዋሃደው xquik ግቤት።
2. **ወሰን፦ በv1 ውስጥ webSearch + webFetch በ`POST /v1/extract` በኩል።** ከtavily/exa የሁለት-አቅም አስተሳሰብ ሞዴል ጋር የተጣጣመ ነው። ቋሚ የፍለጋ ገጽታዎች (`tag`፣ `sub-domains`፣ `batch_search`) ከወሰን ውጭ ይቆያሉ — በአሁኑ ጊዜ ለቋሚ የፍለጋ መለኪያዎች IR የለም።
3. **የኮታ ማሳያ፦ `freeMonthlyQuota: 0`** (የxquik ዓይነት ጥንቃቄ የተሞላበት ማሳያ)። ትክክለኛው ፈቃድ (በቀን 1000 ጥያቄዎች፣ ዕለታዊ ዳግም ማስጀመር) በምትኩ በUI ካታሎጉ `authHint` ጽሑፍ ውስጥ ይገለጻል። ምክንያት፦ የኮታ ማሳያው ከዳግም ማስጀመሪያ ሥርዓቱ ጋር መጣጣም አለበት፤ ዕለታዊ ገደብን ወደ ወርሃዊ አቻ (30000) መቀየር UI ሊያሟላው የማይችል የሐሰት ቃል ኪዳን ነው።
4. **searchTypes፦ `["web"]` ብቻ።** በAnySearch API ውስጥ የዜና/ምስሎች ቋሚ ፍለጋ እንዳለ የሚያሳይ ይፋዊ ማስረጃ የለም፤ የተመዘገበ ቋሚ ፍለጋ የሌላቸውን APIዎች የሚያዋህዱ ጌትዌዮች (ለምሳሌ Google Custom Search) ዜናን በዝምታ ወደ ድር ከመመደብ ይልቅ ድርን ብቻ ያቀርባሉ።
5. **የቁልፍ አቋም፦** ያለ ቁልፍ ይሠራል፤ ልክ ያልሆነ ቁልፍ 401/403 ይመልሳል፣ እና በዝምታ ወደ ማንነት-አልባ ሁኔታ ፈጽሞ አይወርድም (የላይኛውን አገልግሎት ውል ያንጸባርቃል)።
6. **ሆን ተብለው የተገለሉ፦** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (የውይይት መጥለፍ firecrawl/jina/tavily ሆኖ ይቆያል)፤ `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (ማንነት-አልባ የርቀት መጨረሻ ነጥቦች ለእያንዳንዱ የወጪ ትራፊክ IP አንድ IP-የተገደበ ማከማቻ ይጋራሉ፣ ስለዚህ ቁልፍ-አልባ extract በፍላጎት የሚመረጥ እንጂ ለራስ-ሰር ራውቲንግ እጩ አይደለም)፤ `QUOTA_STATUS_PROVIDERS` (AnySearch ኮታን በ429/ኤንቨሎፕ ያመለክታል፣ በ402/403 ሁኔታ አይደለም)።
