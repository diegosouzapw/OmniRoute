## 1. Fakta acuan layanan (dokumentasi resmi, diverifikasi silang)

- URL dasar: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - parameter: `query` (wajib), `max_results` (1-10, default 10), `tag` (perutean vertikal `{domain}.{sub_domain}`), `zone` (cn/intl), `language`, `params` (bidang vertikal terstruktur), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - katalog kapabilitas, TIDAK diperhitungkan dalam kuota.
- `POST /v1/extract` - mengambil/mengekstrak `{url, title, content}`; body JSON ketat, batas 16 KiB.
- `POST /v1/auth/email/register` - pendaftaran dengan satu panggilan, mengembalikan kunci teks biasa sekali pakai `as_sk_...`.
- Autentikasi: `Authorization: Bearer <as_sk_...>` opsional; akses anonim diturunkan ke batas per IP yang menggunakan kuota gratis harian; kunci tidak valid menghasilkan 401/403 TANPA fallback anonim diam-diam.
- Tingkat gratis: 1000 permintaan/hari, 20 QPS per kunci. Tingkat berbayar: belum diberi harga (Segera Hadir).
- Selubung respons: berhasil `{code: 0, message: "success", request_id, data}`; gagal `{code: -1, message}`. Kesalahan autentikasi/kuota tidak memiliki `error_code` terstruktur (teks pesan menjadi sinyalnya); kesalahan khusus ekstraksi memiliki `error_code` (`invalid_extract_url`, `extract_failed`). Tidak ada header `Retry-After` pada 429.

## 3. Keputusan (semuanya ditetapkan pada 2026-08-26)

1. **Postur perutean: `fallbackOnly`.** Alasan: penyedia gratis dengan biaya 0 tidak boleh mendominasi perutean biaya otomatis; pemilihan eksplisit dan pengembalian failover tidak terpengaruh. Preseden: entri xquik yang telah digabungkan.
2. **Cakupan: webSearch + webFetch melalui `POST /v1/extract` di v1.** Selaras dengan model mental kapabilitas ganda tavily/exa. Antarmuka vertikal (`tag`, `sub-domains`, `batch_search`) tetap berada di luar cakupan — saat ini tidak ada IR untuk parameter vertikal.
3. **Tampilan kuota: `freeMonthlyQuota: 0`** (tampilan konservatif ala xquik). Jatah sebenarnya (1000 permintaan/hari, direset setiap hari) dicantumkan dalam teks `authHint` pada katalog UI. Alasan: tampilan kuota harus sesuai dengan semantik reset; mengonversi batas harian menjadi ekuivalen bulanan (30000) merupakan janji palsu yang tidak dapat dipenuhi oleh UI.
4. **searchTypes: `["web"]` saja.** Tidak ada bukti publik mengenai vertikal berita/gambar dalam AnySearch API; gateway yang mengintegrasikan API tanpa vertikal terdokumentasi (misalnya Google Custom Search) hanya menyediakan web alih-alih secara diam-diam memetakan berita -> web.
5. **Postur kunci:** dapat berfungsi tanpa kunci; kunci yang tidak valid menghasilkan 401/403 dan tidak pernah secara diam-diam diturunkan ke akses anonim (mencerminkan kontrak upstream).
6. **Pengecualian yang disengaja:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (intersepsi chat tetap menggunakan firecrawl/jina/tavily); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (endpoint jarak jauh anonim berbagi satu kumpulan berbatas IP untuk setiap IP egress, sehingga extract tanpa kunci bersifat opsional, bukan kandidat perutean otomatis); `QUOTA_STATUS_PROVIDERS` (AnySearch menandakan kuota melalui 429/envelope, bukan status 402/403).
