Dashboard → Penyedia → **Impor dari file** membuat koneksi kunci API dari daftar CSV atau JSON. Setiap baris dapat menargetkan penyedia yang berbeda. Kegagalan parsial merupakan perilaku yang dijamin: baris yang valid tetap diimpor ketika baris lainnya gagal, dan modal mencantumkan alasan penolakan baris yang gagal.

Impor ini **tidak** membuat node endpoint baru yang kompatibel dengan OpenAI/Anthropic. Buat node tersebut terlebih dahulu (Dashboard → Penyedia → Tambahkan yang Kompatibel dengan OpenAI, atau `omniroute nodes add`), lalu impor baris yang kolom `provider`-nya berisi id node tersebut. `baseUrl` per baris tetap dapat menggantikan URL node.

## CSV (berdasarkan posisi)

Nama kolom hanya bersifat kosmetis. Parser memisahkan setiap baris dan melakukan destrukturisasi berdasarkan indeks:

| Indeks | Kolom      | Wajib | Catatan                                                                                                                                          |
| ------ | ---------- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0      | `provider` | ya    | id penyedia terkelola yang sudah ada (`openai`, `anthropic`, …) **atau** id **node** yang kompatibel dengan OpenAI/Anthropic dan sudah terdaftar |
| 1      | `name`     | ya    | Nama tampilan koneksi                                                                                                                            |
| 2      | `apiKey`   | ya    | Kunci API                                                                                                                                        |
| 3      | `baseUrl`  | tidak | Penggantian URL per baris                                                                                                                        |
| 4      | `priority` | tidak | Bilangan bulat 1–100                                                                                                                             |

Baris pertama yang kolom pertamanya berupa kata literal `provider` (dengan kapitalisasi apa pun) dilewati sebagai header. Baris kosong dan komentar `#` dilewati.

Unduh file awal dari modal impor (**Unduh templat CSV**). Contoh:

```csv
# Impor penyedia OmniRoute (kolom berdasarkan posisi)
provider,name,apiKey,baseUrl,priority
openai,Prod OpenAI,sk-your-openai-key,,1
```

id rekaan seperti `openai-compatible-chat-001` bukanlah sebuah node. API mengembalikan `Penyedia tidak dikenal atau tidak didukung` untuk baris tersebut; modal menampilkannya di samping nama baris.

## JSON

Array JSON yang berisi objek dengan kolom yang sama (`provider`, `name`, `apiKey`, `baseUrl?`, `priority?`). Tidak seperti CSV, kunci JSON memiliki nama.

```json
[
  {
    "provider": "openai",
    "name": "Prod OpenAI",
    "apiKey": "sk-your-openai-key",
    "priority": 1
  }
]
```
