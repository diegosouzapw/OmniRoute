## 1. Antigravity vs Antigravity CLI (agy)

Kedua penyedia menggunakan **backend Google yang sama** — klien OAuth, penyegaran token, endpoint, dan akun Google yang identik. Perbedaannya terletak pada model yang dapat Anda lihat.

> Lihat [pengumuman Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli) untuk perbandingan resmi dari Google.

| Aspek                        | `antigravity` (IDE)                           | `agy` (CLI)                                                   |
| ---------------------------- | --------------------------------------------- | ------------------------------------------------------------- |
| **Produk Google**            | Antigravity 2.0 / Antigravity IDE             | Antigravity CLI                                               |
| **Backend**                  | Google Cloud Code API yang sama               | Google Cloud Code API yang sama                               |
| **OAuth / Token**            | Klien yang sama, penyegaran yang sama         | Klien yang sama, penyegaran yang sama                         |
| **Katalog model**            | Daftar pilihan statis (tertanam di OmniRoute) | Dipindai langsung dari Google melalui `:fetchAvailableModels` |
| **Model Claude**             | Sonnet 4.6, Opus 4.6 (masing-masing 4 varian) | Sonnet 4.6, Opus 4.6 (masing-masing 4 varian)                 |
| **Penamaan Gemini**          | Label yang ringkas (Low/Medium/High)          | ID upstream (extra-low/low/agent)                             |
| **Model tambahan**           | `gpt-oss-120b-medium`                         | Dapat mencakup model tambahan dari Google                     |
| **Kasus penggunaan default** | Integrasi IDE (VS Code, JetBrains)            | Akses CLI / API                                               |
| **Kuota**                    | Digunakan bersama agy (akun Google yang sama) | Digunakan bersama antigravity (akun Google yang sama)         |

**Model yang tersedia (diverifikasi melalui eksperimen, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (berbagai tingkat pemikiran)
- Claude: Sonnet 4.6, Opus 4.6 (masing-masing dengan varian default/low/medium/high)
- Lainnya: GPT-OSS 120B Medium
- **Claude Sonnet 5 TIDAK tersedia** — hanya varian 4.6 yang didukung

**Mengapa katalog model berbeda**: CLI Google "dioptimalkan untuk kecepatan dan overhead rendah" serta "dioptimalkan bersama model Gemini" (menurut blog resmi Google). Produk Web/IDE "dioptimalkan untuk kelengkapan." CLI menggunakan `:fetchAvailableModels` untuk menemukan model secara dinamis, sedangkan IDE menggunakan daftar pilihan statis.

**Dalam praktiknya**: Gunakan prefiks `agy/` untuk model Gemini (misalnya `agy/gemini-3.7-flash-high`). Gunakan `antigravity/` untuk daftar pilihan statis. Keduanya mengakses backend Google yang sama, tetapi menampilkan penamaan model yang berbeda. Kuotanya digunakan bersama — penggunaan salah satu penyedia akan diperhitungkan terhadap batas akun Google yang sama.

## 2. Google One AI Pro: Sistem Kuota

> Lihat [Dokumentasi Antigravity: Paket](https://antigravity.google/docs/plans) untuk detail kuota resmi dan [Perubahan pada Paket Antigravity](https://antigravity.google/blog/changes-to-antigravity-plans) untuk pembaruan harga terbaru.

Google Antigravity menggunakan **kuota dua lapis** berdasarkan "Pekerjaan yang Dilakukan" (bobot komputasi), bukan jumlah pesan.

### Dua Lapisan

| Lapisan                | Penjelasan                                                        | Siklus pembaruan                                                                           |
| ---------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **Sprint 5 jam**       | Kumpulan "pekerjaan yang dilakukan" yang dapat langsung digunakan | Direset 5 jam setelah permintaan pertama dalam suatu sesi                                  |
| **Batas dasar 7 hari** | Batas maksimum mingguan                                           | Menggantikan pembaruan 5 jam jika tercapai; akses dikunci hingga periode 7 hari berikutnya |

**Cara menghitung "Pekerjaan yang Dilakukan"**: Tugas intensif agen (misalnya, "Lakukan refaktor pada seluruh repositori ini") menghabiskan kuota jauh lebih cepat dibandingkan tugas sederhana (misalnya, "Perbaiki fungsi ini"). Tidak ada dasbor waktu nyata yang menunjukkan konsumsi.

### Tingkatan Paket

| Paket        | Harga         | Kuota                                         | Batas mingguan                                |
| ------------ | ------------- | --------------------------------------------- | --------------------------------------------- |
| Gratis       | $0            | Kuota memadai, diperbarui setiap minggu       | Ya                                            |
| AI Pro       | $19.99/bulan  | Kuota tinggi, pembaruan bergulir setiap 5 jam | Ya (menggantikan periode 5 jam jika tercapai) |
| AI Ultra 5x  | $99.99/bulan  | 5x kuota Pro                                  | Tanpa batas mingguan                          |
| AI Ultra 20x | $199.99/bulan | 20x kuota Pro                                 | Tanpa batas mingguan                          |

### Model Gemini vs Non-Gemini

- **Model Gemini** (Flash + Pro): Berbagi satu batas laju, yang berkurang berdasarkan tarif API. Jika Flash 8x lebih murah daripada Pro, Anda mendapatkan token Flash 8x lebih banyak.
- **Model non-Gemini** (Claude, GPT-OSS): Memiliki batas laju **terpisah**. Model tersebut mungkin tetap tersedia meskipun Gemini terkunci.

### Kredit AI (Penggunaan Berlebih)

> Lihat [Kredit AI Google One](https://support.google.com/googleone/answer/14534406) untuk mengetahui cara kerja kredit.

Ketika kuota dasar habis:

- **Tidak pernah**: Tunggu hingga kuota diperbarui; menampilkan "Kuota model dasar tercapai"
- **Selalu**: Gunakan kredit AI secara otomatis; kembali ke kuota dasar ketika diperbarui

Kredit dibeli secara terpisah dan dipotong sesuai tarif API standar.

### Detail Utama

- Kuota **dibagikan pada tingkat akun** — akun Google yang sama di Antigravity IDE, CLI, dan OmniRoute menggunakan satu kumpulan kuota bersama
- Setiap akun Google memiliki kuota independennya sendiri — beberapa akun = beberapa kumpulan kuota
- Pengguna AI Pro telah melaporkan **penguncian selama 7 hari**, bukan reset 5 jam, ketika batas dasar mingguan tercapai (Google mengonfirmasi bahwa hal ini memang dirancang demikian untuk permintaan tinggi)

**Saat kuota akun Anda habis**: OmniRoute secara otomatis mencoba kembali dengan akun berikutnya yang tersedia dalam rute kombinasi. Tidak diperlukan intervensi manual.

## 3. Cara Mendapatkan projectId

Setiap koneksi antigravity/agy memerlukan `projectId` Google Cloud Code. Tanpanya, endpoint `/v1internal:models` mengembalikan 404.

### Metode A: Otomatis (Direkomendasikan)

OmniRoute menangani hal ini secara otomatis. Ketika Anda menambahkan akun Google baru melalui OAuth Dasbor:

1. OmniRoute memperbarui token
2. Memanggil `loadCodeAssist` untuk menemukan projectId
3. Jika tidak ada proyek, memanggil `onboardUser` untuk membuatnya
4. Mencoba kembali `loadCodeAssist` untuk mendapatkan projectId yang baru dibuat
5. Menyimpannya ke basis data

**Ini berfungsi untuk sebagian besar akun** — tidak diperlukan langkah manual.

### Metode B: Manual melalui agy CLI

Jika penemuan otomatis gagal (lihat Bagian 5 untuk kondisi yang menyebabkan hal ini):

```bash
# Instal agy CLI (jika belum)
npm install -g @anthropic-ai/agy

# Masuk dengan akun Google Anda
agy login

# Pilih akun yang perlu menjalani orientasi
# Tindakan ini memicu pendaftaran Cloud Code dan menetapkan projectId
```

Setelah `agy login` berhasil, perbarui token di Dasbor OmniRoute. projectId akan ditemukan secara otomatis.

### Cara memverifikasi

Periksa basis data:

```bash
# Di dalam kontainer OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Atau periksa log:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. URI Pengalihan OAuth

### Masalah

Google OAuth memerlukan URI pengalihan yang valid. Secara default, OmniRoute menggunakan `http://127.0.0.1:20128/callback` (loopback). Ini berfungsi untuk build lokal, tetapi **gagal pada deployment jarak jauh** (misalnya, server yang diakses melalui IP LAN).

Google menolak URI pengalihan yang:

- Menggunakan alamat IP (harus berupa domain yang berakhiran `.com`, `.org`, dan sebagainya)
- Tidak cocok dengan URI pengalihan yang terdaftar dalam konfigurasi klien OAuth

### Solusi

**Opsi A: Gunakan alur OAuth bawaan (default)**

- Berfungsi saat Anda mengakses OmniRoute dari `localhost` atau `127.0.0.1`
- Tidak memerlukan konfigurasi

**Opsi B: Kredensial OAuth kustom**

- Atur `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` di environment Anda
- Berikan kredensial Google OAuth Anda sendiri:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Daftarkan `https://your-domain.com/callback` sebagai URI pengalihan resmi di Google Cloud Console

**Opsi C: Gunakan agy CLI untuk login awal**

- Jalankan `agy login` pada mesin yang akan mengakses OmniRoute
- Alur OAuth diselesaikan secara lokal dan token disimpan
- Impor koneksi ke OmniRoute melalui Dashboard

### Batasan

- Kredensial OAuth kustom memerlukan nama domain (Google tidak menerima alamat IP sebagai URI pengalihan)
- Jika Anda tidak memiliki domain, gunakan Opsi A atau C

## 5. Pemecahan Masalah: Ketika Penyiapan Otomatis Gagal

OmniRoute menangani penemuan projectId dan onboarding secara otomatis untuk sebagian besar akun. Ketika proses ini gagal, penyebab utamanya biasanya salah satu dari hal berikut:

### Wilayah akun diblokir

**Gejala**: `agy login` menampilkan "Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location."

**Penyebab utama**: Akun Google memiliki kolom backend "Country Association" yang ditetapkan saat pendaftaran. agy CLI dan Cloud Code API memeriksa kolom ini secara ketat — tidak seperti Gemini versi web yang hanya memeriksa IP Anda saat ini.

> Untuk memeriksa atau mengubah wilayah yang dikaitkan dengan akun Anda, kunjungi [Formulir Asosiasi Negara Google](https://policies.google.com/country-association-form).

**Mengapa Gemini versi web berfungsi tetapi agy tidak**:

- Gemini versi web / Google One: hanya memeriksa IP saat ini (proxy dapat melewatinya)
- agy CLI / Cloud Code API: membaca kolom backend Country Association (proxy tidak membantu)

**Perbaikan**:

1. Kunjungi [Formulir Asosiasi Negara Google](https://policies.google.com/country-association-form) saat menggunakan IP AS
2. Kirim permintaan perubahan wilayah (pilih "I live in a different country")
3. Tunggu 1-24 jam hingga Google memprosesnya dan mengirimkan notifikasi email
4. Setelah itu, `agy login` seharusnya berhasil

### Akun tidak memiliki proyek Cloud Code

**Gejala**: Log menampilkan `loadCodeAssist returned no project id` dan `onboardUser failed (400)`.

**Penyebab utama**: Akun belum pernah didaftarkan ke Google Cloud Code dan onboarding otomatis gagal.

**Perbaikan**: Jalankan `agy login` secara manual untuk memicu pendaftaran Cloud Code, lalu segarkan token di OmniRoute Dashboard.

### Token kedaluwarsa atau dicabut

**Gejala**: Terjadi error 401 dalam log, atau muncul pesan "Token has expired".

**Perbaikan**: Segarkan token di Dashboard → Providers → agy → Klik ikon segarkan. Jika token penyegaran telah dicabut, Anda perlu melakukan autentikasi ulang melalui OAuth.
