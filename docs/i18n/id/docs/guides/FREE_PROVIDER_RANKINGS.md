> **TL;DR**: OmniRoute memeringkat penyedia **gratis** berdasarkan kualitas model menggunakan **skor ELO Arena AI
> (bergaya LMArena)**. Buka halaman **Peringkat Penyedia Gratis** di
> dasbor untuk melihat penyedia gratis mana yang menyediakan model terkuat untuk tugas Anda —
> secara keseluruhan, atau difilter berdasarkan kategori (coding, peninjauan, dokumentasi, debugging).

---

## Apa Itu

OmniRoute mendaftarkan 329 penyedia, termasuk 155 entri katalog yang ditandai **gratis/tanpa autentikasi**
(tanpa autentikasi,
OAuth tingkat gratis, atau kunci API tingkat gratis — lihat
[Panduan Tingkat Gratis](../getting-started/FREE-TIERS-GUIDE.md) dan
[Direktori Tingkat Gratis](../reference/FREE_TIERS.md) lengkap). Namun, kualitas model
dari penyedia gratis sangat bervariasi. Penyedia tanpa autentikasi yang menyajikan model frontier jauh lebih berguna
daripada penyedia yang menyajikan model lama berukuran kecil.

**Peringkat Penyedia Gratis** menjawab "**penyedia gratis mana yang memberi saya model terbaik?**" dengan
menggabungkan katalog setiap penyedia gratis dengan **skor kualitas berbasis kontribusi komunitas** dari
**papan peringkat Arena AI** (ELO berdasarkan preferensi manusia, konsep yang sama di balik arena
chatbot LMArena). Penyedia kemudian diperingkat berdasarkan kekuatan **model gratis terbaik** mereka.

Peringkat dihitung dari tiga sumber nyata:

1. Daftar penyedia gratis — `NOAUTH_PROVIDERS`, ditambah entri `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` yang ditandai `hasFree`
   (`src/shared/constants/providers.ts`).
2. Katalog model setiap penyedia dari registri penyedia
   (`open-sse/config/providerRegistry.ts`).
3. Skor kesesuaian tugas yang diturunkan dari ELO dan disimpan dalam tabel DB `model_intelligence` oleh
   mesin sinkronisasi ELO Arena (`src/lib/arenaEloSync.ts`).

Logika penggabungan berada di `src/lib/freeProviderRankings.ts`.

## Cara Mengakses

### Halaman dasbor

Buka dasbor dan masuk ke **Biaya → Peringkat Penyedia Gratis**, atau navigasikan langsung ke:

```
/dashboard/free-provider-rankings
```

Halaman tersebut (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) menampilkan:

- **Podium 3 teratas** (🥇 🥈 🥉) untuk penyedia gratis dengan peringkat terbaik.
- **Tabel peringkat** lengkap dengan kolom: **Peringkat**, **Penyedia**, **Model Teratas**,
  **Skor**, **Skor Rata-rata**, **Model**, **Jenis**.
- **Tombol filter kategori**: _Semua Kategori_, _Default_, _Coding_, _Peninjauan_,
  _Dokumentasi_, _Debugging_.

Lencana **Jenis** setiap penyedia memberi tahu Anda bagaimana layanan tersebut tersedia secara gratis:

| Lencana  | Arti                                                 |
| -------- | ---------------------------------------------------- |
| `NOAUTH` | Selalu gratis, tidak memerlukan kredensial           |
| `OAUTH`  | Penyedia OAuth dengan tingkat gratis (`hasFree`)     |
| `APIKEY` | Penyedia kunci API dengan tingkat gratis (`hasFree`) |

Skor ditampilkan sebagai label yang mudah dibaca manusia (misalnya _Elite_, _Luar Biasa_, _Sangat Baik_,
_Baik_, _Rata-rata_), bukan sebagai angka mentah, karena nilai dasarnya merupakan kualitas
peringkat relatif, bukan persentase.

### Endpoint API

Halaman ini didukung oleh endpoint baca publik
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parameter kueri (divalidasi dengan Zod):

| Parameter  | Jenis  | Default     | Catatan                                                                                                          |
| ---------- | ------ | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| `category` | string | (tidak ada) | Salah satu dari `default`, `coding`, `review`, `documentation`, `debugging`. Hilangkan untuk peringkat gabungan. |
| `limit`    | number | `50`        | Dibatasi ke rentang `1–100`.                                                                                     |

Bentuk respons:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` adalah nilai ELO Arena asli; `score` adalah nilai kesesuaian tugas yang dinormalisasi
(lihat di bawah). Penyedia yang tidak memiliki model dengan skor tidak disertakan dalam respons.

## Cara Kerja Skor

### Sumber: papan peringkat Arena AI

Mesin sinkronisasi ELO Arena (`src/lib/arenaEloSync.ts`) mengambil dua papan peringkat — `text`
dan `code` — dari API papan peringkat Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Setiap entri papan peringkat
memuat nama model, vendor, `score` ELO, interval kepercayaan, dan jumlah suara.

Kategori papan peringkat dipetakan ke kategori tugas OmniRoute:

| Papan peringkat Arena | Kategori tugas OmniRoute                          |
| --------------------- | ------------------------------------------------- |
| `text`                | `default`, `review`, `documentation`, `debugging` |
| `code`                | `coding`                                          |

### Normalisasi (skor kesesuaian tugas)

Skor ELO mentah dinormalisasi per papan peringkat menjadi **nilai kesesuaian tugas dalam `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Skor tidak pernah mencapai `0` atau `1`, sehingga menyisakan ruang untuk penimpaan oleh pengguna. Ini adalah
bidang `score` yang Anda lihat dalam respons API dan label yang ditampilkan di dasbor.

### Tingkat kepercayaan

Setiap entri mendapatkan tingkat kepercayaan berdasarkan jumlah suara Arena:

| Tingkat kepercayaan | Suara   |
| ------------------- | ------- |
| `high`              | ≥ 5.000 |
| `medium`            | ≥ 1.000 |
| `low`               | < 1.000 |

### Penyimpanan dan kebaruan

Entri yang telah dinormalisasi ditulis ke tabel DB `model_intelligence` dengan
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Entri **kedaluwarsa setelah
7 hari**, sehingga penyedia yang berhenti melakukan sinkronisasi pada akhirnya akan dikeluarkan alih-alih menyajikan
data yang sudah usang.

Sinkronisasi **aktif secara default**:

- Sinkronisasi dijalankan sekali saat server dimulai, lalu secara berkala berdasarkan pengatur waktu
  (`src/lib/arenaEloSync.ts`, dihubungkan dari `src/instrumentation-node.ts`).
- Sinkronisasi ini **tidak memblokir dan tidak pernah menyebabkan kegagalan fatal** — jika pengambilan data dari sumber hulu gagal, OmniRoute tetap
  berjalan dan peringkat hanya menampilkan data valid terakhir (atau status kosong).

Dua variabel lingkungan mengontrolnya (didokumentasikan dalam
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Variabel                  | Default       | Tujuan                                                   |
| ------------------------- | ------------- | -------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Atur ke `false` untuk menonaktifkan sinkronisasi keluar. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | Interval sinkronisasi, dalam detik.                      |

### Sinkronisasi manual / status / pembersihan

Untuk operator, endpoint pengelolaan terautentikasi menyediakan kontrol manual
(`src/app/api/intelligence/sync/route.ts` — memerlukan autentikasi pengelolaan):

```
GET    /api/intelligence/sync          # status sinkronisasi saat ini (diaktifkan, sinkronisasi terakhir, sinkronisasi berikutnya, interval dalam milidetik)
POST   /api/intelligence/sync          # memicu sinkronisasi manual; isi: { "dryRun": true } untuk melihat pratinjau tanpa menulis
DELETE /api/intelligence/sync          # menghapus semua entri inteligensi arena_elo yang telah disinkronkan
```

Jika halaman peringkat kosong, `POST /api/intelligence/sync` secara manual (atau cukup
memulai ulang server) akan mengisinya kembali.

### Mencocokkan model dengan papan peringkat

ID model registri dan nama model Arena tidak selalu sama persis. Pemeringkatan menggunakan
pencocokan fleksibel (`findMatchingIntelligence` dalam `src/lib/freeProviderRankings.ts`):

1. Kecocokan persis pada ID model yang telah dinormalisasi.
2. Kecocokan setelah menghapus sufiks versi di akhir (misalnya `kimi-k2.6` → `kimi-k2`).
3. Kecocokan prefiks (nama model papan peringkat merupakan prefiks dari ID registri).

Di sisi sinkronisasi, prefiks vendor yang dikenal (`anthropic/`, `openai/`, `google/`, …)
dihapus dan peta alias kecil memperluas nama kanonis menjadi varian yang digunakan OmniRoute
secara internal, sehingga model tetap dapat ditemukan dengan nama apa pun.

### Cara penyedia diberi peringkat

Untuk setiap penyedia gratis, mesin menilai setiap model dalam katalognya, kemudian:

- **Model Teratas** = model penyedia dengan skor tertinggi.
- **Skor Rata-rata** = skor rata-rata dari semua model penyedia yang dinilai.
- **Model** = jumlah model penyedia yang memiliki skor Arena.

Penyedia diurutkan terlebih dahulu berdasarkan **skor model teratas**, lalu berdasarkan skor rata-rata. Hal ini memberi penghargaan kepada
penyedia yang menawarkan setidaknya satu model gratis yang unggul.

## Menggunakannya untuk Memilih Penyedia Gratis

1. **Pilih kategori yang tepat.** Gunakan filter **Coding** untuk beban kerja agen/kode, atau
   biarkan pada **All Categories** / **Default** untuk percakapan umum. Penyedia yang sama dapat
   memiliki peringkat berbeda di setiap kategori karena model terbaiknya berbeda pada tiap papan peringkat.
2. **Utamakan posisi podium untuk penyiapan sekali jalan.** Jika Anda hanya ingin menghubungkan satu atau dua
   penyedia gratis, mulailah dengan penyedia berperingkat tertinggi untuk kategori Anda.
3. **Periksa lencana Type.** Penyedia `NOAUTH` paling cepat dihubungkan (tanpa
   kredensial). Tingkat gratis `OAUTH` / `APIKEY` memerlukan pendaftaran singkat, tetapi sering kali menyediakan
   model yang lebih canggih. Lihat [Panduan Tingkat Gratis](../getting-started/FREE-TIERS-GUIDE.md) untuk
   langkah-langkah koneksi.
4. **Hubungkan beberapa penyedia dan biarkan Auto-Combo menentukan pilihan.** Data Arena ELO yang sama yang mendukung
   halaman ini juga digunakan sebagai **faktor kecocokan tugas** oleh mesin penilaian Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, urutan resolusi
   `user_override → arena_elo → models_dev_tier → static table`). Jadi, setelah Anda menghubungkan
   penyedia gratis teratas, perutean dengan `model: "auto"` (misalnya `auto/coding`) akan
   secara otomatis mengutamakan model gratis berkualitas lebih tinggi untuk setiap permintaan. Lihat
   [Auto-Combo](../routing/AUTO-COMBO.md) untuk sistem penilaian 16 faktor secara lengkap.
