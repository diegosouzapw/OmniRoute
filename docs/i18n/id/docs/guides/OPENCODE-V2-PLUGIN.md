`@omniroute/opencode-plugin-v2` memasukkan seluruh katalog OmniRoute Anda — model, combo, dan
auto-combo — ke pemilih model OpenCode v2, lengkap dengan nama tampilan, harga, dan
anggaran tingkat gratis.

Paket ini terpisah dari `@omniroute/opencode-plugin` karena OpenCode v1 dan v2 memuat
plugin melalui kontrak yang berbeda. Pilih paket yang sesuai dengan versi mayor OpenCode Anda;
tidak ada komponen yang digunakan bersama, sehingga meningkatkan versi salah satunya tidak pernah
memaksa peningkatan versi yang lain.

## Persyaratan

- OpenCode v2.
- Gateway OmniRoute yang dapat dijangkau (`http://localhost:20128` secara default).
- Node.js 22 atau 24.

## Instalasi

Tambahkan plugin ke `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Model kemudian muncul sebagai `omniroute/<provider>/<model>`; `providerId` menentukan prefiks
tersebut dan id integrasi tempat OpenCode menyimpan kredensial.

## Kredensial

Plugin mencari kunci gateway di tiga tempat, dengan urutan berikut:

1. **Kredensial yang Anda hubungkan di OpenCode.** Plugin mendaftarkan integrasi, sehingga
   alur autentikasi bawaan OpenCode dapat menyimpan kunci tersebut. Tidak ada yang disimpan dalam
   `opencode.json` — utamakan cara ini.
2. `apiKey` dalam opsi plugin, untuk penimpaan per proyek. Cara ini menempatkan kunci dalam sebuah
   file yang mungkin Anda commit.
3. `OMNIROUTE_API_KEY` dalam environment.

Jika ketiganya tidak tersedia, katalog akan kosong dan plugin akan memberitahukannya sekali saat
startup, alih-alih membiarkan Anda menghadapi pemilih kosong tanpa penjelasan.

### Token manajemen adalah kunci yang berbeda

Combo, status penyedia, dan pengayaan (nama tampilan, harga, serta anggaran tingkat gratis) berasal
dari endpoint `/api/*` milik gateway, yang pada sebagian besar deployment dilindungi oleh token
**manajemen**, bukan kunci inferensi:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token baca manajemen>"
}
```

Jika tidak ditetapkan, `managementReadToken` akan menggunakan `apiKey` sebagai fallback. Ketika
gateway menolak fallback tersebut, katalog tetap dipublikasikan, tetapi menggunakan id model mentah
alih-alih nama tampilan, tanpa deduplikasi alias kanonis, tanpa harga, dan tanpa combo. Plugin
memberikan peringatan satu kali per endpoint ketika hal itu terjadi, dengan menyebutkan endpoint dan
apa yang hilang — sehingga penyebab pemilih yang terdegradasi selalu jelas.

## Opsi

| Kunci                            | Default                                        | Catatan                                                                                                       |
| -------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                  | Id penyedia, id integrasi, dan prefiks tempat model ditampilkan                                               |
| `baseURL`                        | wajib                                          | Root gateway, hanya `http(s)`; sufiks `/v1` ditambahkan jika diperlukan                                       |
| `apiKey`                         | kredensial terhubung, lalu `OMNIROUTE_API_KEY` | Kunci chat untuk `/v1/*`                                                                                      |
| `managementReadToken`            | menggunakan `apiKey` sebagai fallback          | Kunci untuk `/api/*` — biasanya **bukan** kunci yang sama                                                     |
| `displayName`                    | `"OmniRoute"`                                  | Nama penyedia dalam pemilih                                                                                   |
| `timeoutMs`                      | `10000`                                        | Batas waktu pengambilan per endpoint (auto-combo menggunakan 5 detik)                                         |
| `modelCacheTtlMs`                | `300000`                                       | TTL cache katalog; snapshot pada disk mempercepat cold start                                                  |
| `timeouts`                       | menggunakan `timeoutMs` sebagai fallback       | Batas waktu per endpoint dalam milidetik: `models`, `combos`, `autoCombos`, `enrichment`                      |
| `enrichment`                     | `true`                                         | Mengambil nama, harga, dan anggaran tingkat gratis                                                            |
| `providerTag`                    | `true`                                         | Memberikan prefiks berupa penyedia upstream tujuan perutean pada nama tampilan                                |
| `usableOnly`                     | `false`                                        | Hanya mempertahankan penyedia yang dilaporkan gateway sebagai telah disediakan                                |
| `visibleModels` / `hiddenModels` | `[]`                                           | Daftar izin berdasarkan kecocokan persis atau sufiks; penolakan selalu diutamakan                             |
| `geminiSanitization`             | `true`                                         | Menghapus kata kunci JSON-Schema yang ditolak Gemini dari skema alat (alat `$ref` diteruskan tanpa perubahan) |
| `apiFormat.allowAnthropic`       | `false`                                        | Merutekan id dalam daftar izin melalui blok API Anthropic                                                     |
| `apiFormat.anthropicModels`      | `[]`                                           | Id model lengkap yang dirutekan ke Anthropic                                                                  |
| `logLevel` / `startupDebug`      | `warn` / `false`                               | Tingkat detail logger                                                                                         |

## Cara katalog tetap mutakhir

Katalog diambil secara lazy dan di-cache selama `modelCacheTtlMs`, dan snapshot pada disk memastikan
katalog terakhir yang diketahui tetap tersedia saat gateway tidak dapat dijangkau — gangguan hanya
mengurangi kemutakhiran. Model dan kombo dipublikasikan segera setelah tersedia; kombo otomatis, daftar
penyedia, dan overlay pengayaan digabungkan saat masing-masing tersedia, sehingga satu endpoint yang lambat
tidak dapat menghambat seluruh pemilih.

Nama memuat informasi yang diketahui gateway: penyedia upstream yang menjadi tujuan perutean model, penanda
`[Free]`, serta anggaran yang menyertainya — sehingga dua koneksi yang menawarkan model yang sama tetap
dapat dibedakan. Nonaktifkan prefiks dengan `"providerTag": false`.

Tidak ada perintah penyegaran manual: perintah OpenCode v2 adalah templat prompt, bukan callback,
sehingga plugin tidak dapat menyediakannya. Penyegaran mengikuti TTL; host hanya diminta memuat ulang saat
katalog atau overlay benar-benar berubah, bukan setiap kali penyegaran dilakukan.

## Pemanggilan alat di Gemini

Gemini menolak seluruh permintaan yang deklarasi alatnya memuat `$schema` atau
`additionalProperties`, dengan respons `400 INVALID_ARGUMENT`. Plugin menghapus kata kunci tersebut dari
skema alat yang ditujukan untuk model Gemini dari penyedia ini dan membiarkan setiap permintaan lainnya
tidak berubah. Alat yang memuat `$ref` diteruskan tanpa perubahan alih-alih dihapus, karena menghapus
referensi tersebut akan memperluas skema menjadi "terima apa pun".
Atur `"geminiSanitization": false` untuk menonaktifkannya.

## Pemecahan masalah

| Gejala                                    | Penyebab                                                                                                                   |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Pemilih tidak menampilkan model OmniRoute | Tidak ada kunci yang ditemukan (periksa peringatan saat startup), atau gateway tidak dapat dijangkau                       |
| ID model mentah, tanpa kombo, tanpa harga | Endpoint manajemen menolak token — atur `managementReadToken`                                                              |
| Sesi disematkan ke `opencode-<id>/…`      | Plugin v1 memublikasikan `opencode-<id>`; v2 memublikasikan `<id>` tanpa prefiks, jadi pilih ulang model di bawah `<id>/…` |
