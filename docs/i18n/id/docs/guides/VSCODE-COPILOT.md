**OmniCopilot** menampilkan setiap model yang disediakan OmniRoute Anda di pemilih model
_native_ GitHub Copilot Chat. Tanpa sidebar kedua, tanpa antarmuka chat terpisah — mode agen Copilot, pemanggilan alat,
server MCP, dan instruksi khusus semuanya tetap berfungsi, hanya saja dijalankan pada model yang Anda pilih.

|                      |                                                                                                                                                 |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Instal (VS Code)** | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Instal (fork)**    | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Sumber / isu**     | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Persyaratan**      | VS Code 1.104+                                                                                                                                  |

> **Tidak memerlukan langganan Copilot.** Sejak VS Code 1.122, penyedia model bahasa dapat berfungsi
> tanpa perlu masuk ke GitHub dan tanpa paket Copilot apa pun. Pelengkapan inline dan
> fitur berbasis embedding tetap berada di luar API penyedia dan masih memerlukan Copilot.

---

## Penyiapan

1. **Jalankan OmniRoute** — `npm install -g omniroute && omniroute` (dasbor di `http://localhost:20128`).
2. **Instal ekstensi** — cari "OmniRoute" di tampilan Extensions.
3. **Pilih model** — Copilot Chat → pemilih model → **Manage Models…** → **OmniRoute**, lalu centang
   model yang Anda inginkan.

Tidak ada yang perlu dikonfigurasi ketika OmniRoute berjalan pada port default. Untuk instans jarak jauh, buka
**ikon OmniRoute di Activity Bar** (atau jalankan `OmniRoute: Manage Connection`) dan atur:

- **URL server** — root server, misalnya `http://192.168.0.15:20128`. Sufiks `/v1`
  ditambahkan oleh ekstensi; jangan sertakan sufiks tersebut.
- **Kunci API** — hanya ketika server menetapkan `REQUIRE_API_KEY`. Disimpan di keychain OS melalui VS
  Code SecretStorage, tidak pernah di `settings.json`.

## Yang akan ditampilkan oleh pemilih

Ekstensi tidak menampilkan payload mentah `GET /v1/models` — ekstensi mengolahnya, dan jumlah yang
Anda lihat lebih sedikit daripada ukuran katalog karena dua alasan yang disengaja.

### Ekstensi meminta satu id per model

`MODELS_CATALOG_PREFIX_MODE` secara default bernilai **`dual`**, yang mengiklankan setiap model dua kali — sekali
dengan prefiks alias pendek dan sekali dengan prefiks penyedia kanonis — sehingga konfigurasi klien lama
tetap dapat me-resolve kedua bentuk tersebut:

```
cc/claude-sonnet-4-6        ← prefiks alias
claude/claude-sonnet-4-6    ← prefiks kanonis, model yang sama
```

Ekstensi meminta **`GET /v1/models?prefix=alias`** agar satu id diterima per model, tanpa
mengubah pengaturan server secara keseluruhan untuk klien Anda yang lain. Pada instans referensi, ini mengurangi
**2345 entri menjadi 1396 — 949 duplikat, tanpa kehilangan model.**

Jika Anda lebih memilih untuk memperbaikinya di seluruh server bagi _setiap_ klien, atur feature flag
`MODELS_CATALOG_PREFIX_MODE` menjadi `alias` di dasbor. Lihat
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) untuk
parameter kueri dan tabel per mode.

### Ekstensi menyembunyikan model yang tidak dapat digunakan untuk chat

Katalog juga mencantumkan model gambar, video, audio, rerank, embedding, dan moderasi. Model-model tersebut
bagaimanapun juga akan ditolak pada permintaan chat:

```
HTTP 400 — Model '<id>' adalah model pembuatan gambar dan tidak dapat digunakan pada
/v1/chat/completions. Gunakan POST /v1/images/generations sebagai gantinya.
```

sehingga model-model tersebut difilter berdasarkan kolom `type` sebelum mencapai pemilih. **Model Responses-API
tetap disertakan** — setiap entri Codex / GPT-5.x mengiklankan `supported_endpoints: ["responses"]`,
dan OmniRoute menerjemahkannya untuk `/v1/chat/completions`, sehingga semuanya dapat digunakan dengan sempurna.

### Penyedia yang tidak pernah Anda konfigurasi

Katalog mencantumkan model dari penyedia dengan **koneksi aktif** _serta_ setiap penyedia **noAuth**
— penyedia tanpa kunci yang mencakup sebagian besar tingkat gratis. Ini disengaja. Untuk menyembunyikannya,
tambahkan penyedia tersebut ke `blockedProviders` di pengaturan dasbor; tidak ada yang berubah di
ekstensi.

## Dasbor di dalam tab VS Code

`omnicopilot.dashboardOpen: "editor"` merender dasbor OmniRoute di tab editor melalui
Simple Browser, bukan di browser eksternal. Penyematan harus **diaktifkan secara eksplisit di server** melalui
`DASHBOARD_ALLOW_EMBED=vscode`, yang menyajikan halaman HTML dengan
`frame-ancestors 'self' vscode-webview:`, bukan dengan nilai default `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Permukaan API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) tetap
menggunakan header yang ketat dalam kedua kondisi tersebut.

> ⚠️ **Ini adalah flag waktu build, bukan waktu proses.** Next.js mengompilasi `headers()` ke dalam manifes
> rute, sehingga `next.config.mjs` membaca variabel tersebut saat bundle dibuat
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Mengekspornya sebelum menjalankan server yang sudah dibuat tidak mengubah apa pun — header sudah tertanam.

```bash
# variabel harus tersedia pada perintah BUILD
DASHBOARD_ALLOW_EMBED=vscode npm run build        # atau npm run build:release
npm start
```

| Cara Anda menginstal       | Dapatkah Anda mengaktifkan penyematan?                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Dari kode sumber           | ✅ atur variabel pada perintah build, seperti di atas                                                                                       |
| `npm install -g omniroute` | ❌ paket yang dipublikasikan menyertakan bundle siap pakai — sebagai gantinya, lakukan build dari kode sumber                               |
| Image Docker               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — image siap pakai di Docker Hub tidak mendukung penyematan |

Tanpa build yang mendukung penyematan, halaman akan menolak ditampilkan dalam frame. Ekstensi mendeteksi hal itu dari
header respons dan beralih ke browser eksternal — tidak ada yang rusak, dan ekstensi akan memberitahukannya satu kali.
Lihat [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) dan isu
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Mengonfigurasi alat lain dari dalam VS Code

**`OmniRoute: Configure Coding CLI`** menjalankan CLI `omniroute` untuk membuat profil siap pakai
bagi Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo, dan Roo — konfigurasi yang sama seperti yang dijelaskan dalam
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). Kunci API diteruskan ke CLI melalui variabel lingkungan
`OMNIROUTE_API_KEY`, tidak pernah melalui baris perintah.

## Pemecahan masalah

| Gejala                                                   | Penyebab / perbaikan                                                                                                                                                                                                                                                                     |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tidak ada model OmniRoute di pemilih                     | Server tidak dapat dijangkau. Titik pada bilah status berubah menjadi abu-abu; jalankan `OmniRoute: Check Connection`. Penemuan model sengaja dilakukan tanpa notifikasi dan tidak menambahkan model apa pun alih-alih menampilkan perintah interaktif.                                  |
| Setiap model muncul dua kali                             | Anda menggunakan OmniCopilot versi sebelum 1.0.1 — lakukan pembaruan. Ekstensi kini meminta `?prefix=alias`.                                                                                                                                                                             |
| Model gambar/audio yang sebelumnya tercantum kini hilang | Disengaja sejak 1.0.1 — model tersebut memang tidak pernah dapat menjawab permintaan obrolan.                                                                                                                                                                                            |
| Panel tidak ada di Bilah Aktivitas                       | VS Code memindahkan kontainer tampilan tambahan ke menu luapan **"…"** di bagian bawah Bilah Aktivitas, dan kontainer yang disembunyikan melalui klik kanan akan tetap tersembunyi. Klik kanan Bilah Aktivitas → centang **OmniRoute**, atau buka dengan `OmniRoute: Manage Connection`. |
| Dasbor terbuka di browser meskipun dalam mode `editor`   | Server tidak **dibuat** dengan `DASHBOARD_ALLOW_EMBED=vscode` (lihat di atas) — mengaturnya saat startup pada instalasi siap pakai tidak berpengaruh. Peralihan ke browser eksternal memang disengaja.                                                                                   |
| Daftar model tidak mutakhir setelah mengubah penyedia    | `OmniRoute: Refresh Models`, atau tautan ↻ di panel.                                                                                                                                                                                                                                     |
