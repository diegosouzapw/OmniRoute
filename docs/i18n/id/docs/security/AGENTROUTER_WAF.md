Gateway upstream `agentrouter` menjalankan filter konten berbasis kata kunci pada
`messages[].content`. Filter tersebut sebagian bersifat deterministik (selalu memblokir
frasa tertentu) dan sebagian bersifat probabilistik (sensitif terhadap lonjakan — menjadi
lebih agresif setelah permintaan cepat berturut-turut, lalu pulih setelah periode jeda).

Ketika WAF memblokir permintaan, respons yang dikembalikan adalah:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Cakupan filter

WAF hanya memeriksa `messages[].content`. WAF **tidak** memeriksa:

- Prompt `system`
- Blok konten terstruktur (`tool_result`, `tool_use`, `thinking`, `image`)
- Field `description` dan `input_schema` milik tool
- Metadata permintaan, header, atau id model

## Pola yang selalu diblokir (tidak peka huruf besar/kecil)

| Pola                          | Catatan                                               |
| ----------------------------- | ----------------------------------------------------- |
| Varian `Lorem ipsum` apa pun  | Seluruh kosakata lorem Latin diblokir                 |
| `language model` (tersendiri) | "the language model" dan "large language model" lolos |
| `virtual assistant`           | "AI assistant" lolos                                  |
| `I'm here to help`            | "here to help" saja juga diblokir                     |
| `Claude, made by Anthropic`   | Hanya frasa lengkap                                   |

## Pola yang hampir selalu diblokir

| Pola                                                    | Catatan                                                     |
| ------------------------------------------------------- | ----------------------------------------------------------- |
| `placeholder`                                           | Ketika berdiri sendiri (bukan sebagai nama parameter, dll.) |
| `dummy data`                                            | Frasa seed yang umum untuk fixture                          |
| `foo bar baz`                                           | Frasa placeholder kanonis                                   |
| Token pendek berulang (`AAA BBB CCC`, `test test test`) | Detektor untuk penjejalan kata kunci                        |

## Perilaku saat beban tinggi

Setelah ~5 permintaan cepat dalam rentang waktu singkat, WAF mulai memblokir konten
yang biasanya akan lolos. Bucket kembali longgar setelah ~5–10 detik tanpa
aktivitas. Ini adalah rate limiter berbasis IP dan key yang sama dengan yang menyebabkan
error `400 content-blocked` berselang ketika Claude Code atau Codex CLI
melakukan beberapa panggilan penggunaan tool / pengiriman pesan secara berurutan dengan cepat.

## Mitigasi yang sudah diterapkan di OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — burst guard yang memberlakukan
   jeda minimum 500 ms antara permintaan keluar ke URL `agentrouter:*`
   mana pun. Jeda tersebut jauh di bawah ambang persepsi latensi manusia dan mencegah
   WAF aktif pada lalu lintas normal.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — ketika upstream mengembalikan
   `400 content-blocked`, executor mencoba kembali URL yang sama dengan
   exponential backoff (1,5 dtk, 3,0 dtk, maksimum 2 percobaan). Setelah backoff,
   WAF biasanya kembali longgar dan percobaan ulang berhasil.

3. **`tests/unit/compression/harness.test.ts`** — fixture pengujian
   `longInput` diubah dari `"lorem ipsum dolor sit amet ".repeat(40)`
   menjadi `"example content for testing purposes ".repeat(40)` agar ketika
   Claude Code membaca file ini melalui tool `Read`, konten file
   tidak mengalir kembali melalui blok `tool_result` dan memicu WAF.

## Panduan untuk prompt dan output tool

Jika sesi Claude Code atau Codex CLI berulang kali mengalami
`400 content-blocked`, periksa pesan pengguna terbaru dan hasil tool
terbaru untuk menemukan pola mana pun di atas, lalu ubah frasanya. Solusi
umum:

- Ganti `Lorem ipsum …` dengan `example text …` atau konten sebenarnya
  yang ingin direpresentasikan oleh pengujian atau fixture.
- Ganti `placeholder` (ketika berdiri sendiri) dengan `example value`,
  `sample value`, atau nilai sebenarnya.
- Ganti `language model` dengan `large language model` atau `the model`.
- Ganti `dummy data` dengan `sample data` atau nilai seed yang realistis.
- Ganti `I'm here to help` / `here to help` dengan pembuka yang lebih spesifik
  (misalnya, "I'll review the file you mentioned").

## Melaporkan false positive ke upstream

Filter saat ini terlalu agresif — filter tersebut memblokir "Lorem ipsum" dalam
blok `tool_result`, meskipun operator jelas tidak bermaksud
menyisipkan prompt. Operator yang ingin masalah ini diperbaiki pada sumbernya sebaiknya
menghubungi `agentrouter.org` untuk melaporkan false positive tersebut. Blocklist
di atas merupakan hasil empiris dari pengujian upstream per 2026-08-03.
