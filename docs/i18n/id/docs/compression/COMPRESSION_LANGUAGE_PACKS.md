Kompresi Caveman dapat memuat paket aturan khusus bahasa selain aturan bawaan bahasa Inggris.
Hal ini menjaga mesin inti tetap stabil sekaligus memungkinkan paket bahasa Portugis, Spanyol, Jerman, Prancis, Italia, Jepang, dan
bahasa lainnya di masa mendatang berkembang secara independen.

## Lokasi

Paket bahasa berada di:

```txt
open-sse/services/compression/rules/<language>/
```

Paket yang saat ini disertakan (diverifikasi berdasarkan isi direktori `rules/`):

| Bahasa            | Direktori      | Kategori aturan yang tersedia                       |
| ----------------- | -------------- | --------------------------------------------------- |
| Inggris           | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spanyol           | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugis (Brasil) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonesia         | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italia            | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Jerman            | `rules/de/`    | `context`, `filler`, `structural`                   |
| Prancis           | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Jepang            | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Catatan kesetaraan:** Paket `en`, `es`, `pt-BR`, `id`, dan `it` memiliki kelima kategori secara lengkap; `de`, `fr`, dan `ja` menyertakan 3 kategori. Kategori `dedup` dan `ultra` yang tidak tersedia secara otomatis menggunakan aturan bawaan bahasa Inggris sebagai fallback. Kontribusi untuk menambahkan `dedup.json` dan `ultra.json` ke paket yang lebih kecil dipersilakan.
>
> Paket `pt-BR` didasarkan pada **[Troglodita](https://github.com/leninejunior/troglodita)** oleh Lenine Júnior — sistem kompresi yang dirancang dari awal untuk tata bahasa Portugis Brasil (pengurangan pleonasme, penghapusan kata pengisi PT-BR, singkatan teknis untuk komunitas pengembang Brasil).
>
> Daftar kategori kanonis dan skema per kategori tersedia di [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema draf 2020-12).

## Deteksi Bahasa

`languageDetector.ts` menggunakan heuristik ringan untuk menyimpulkan bahasa dari teks prompt. Bahasa
default yang dikonfigurasi tetap dipatuhi, dan deteksi dapat dinonaktifkan melalui konfigurasi ketika kontrol
yang presisi diperlukan.

Output deteksi hanya digunakan untuk memilih paket aturan. Output ini tidak mengubah perutean penyedia, pemilihan
locale, atau bahasa UI.

## Struktur Konfigurasi

Pengaturan kompresi dapat mencakup:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` mengontrol nilai default dasbor/pratinjau. `cavemanConfig` adalah konfigurasi mesin runtime
yang digunakan saat Caveman mengompresi teks pesan.

## Menambahkan Paket Bahasa

1. Buat `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Gunakan format aturan Caveman dari `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Pertahankan penggantian secara konservatif dan hindari mengubah kode, pengidentifikasi, URL, atau JSON.
4. Tambahkan atau perbarui pengujian untuk pemilihan bahasa dan perilaku penggantian.
5. Tampilkan label dasbor/i18n baru jika bahasa tersebut muncul di pemilih UI.

## API

Paket yang tersedia dapat dikueri dengan:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Endpoint pratinjau menerima penggantian konfigurasi bahasa:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Keenam paket bahasa menerima klausul `SHARED_BOUNDARIES` dalam v3.8.0 yang diterapkan pada setiap
intensitas Caveman (LITE, FULL, ULTRA). Klausul ini menginstruksikan mesin untuk mempertahankan pola-pola berikut apa adanya,
terlepas dari penghapusan kata pengisi di sekitarnya:

| Jenis pola                     | Contoh                                 |
| ------------------------------ | -------------------------------------- |
| Blok kode berpagar             | ` ```python\n...\n``` `                |
| Kode sebaris                   | `` `my_var` ``                         |
| URL                            | `https://example.com/path`             |
| Jalur file (absolut + relatif) | `/etc/hosts`, `./src/index.ts`         |
| Header kesalahan               | `Error:`, `TypeError:`, `SyntaxError:` |
| Baris jejak tumpukan           | `  at functionName (file.ts:12:3)`     |

Pola-pola ini diisikan ke `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (sebelumnya `[]`). Konstanta
tersebut berada di `open-sse/services/compression/types.ts`.

### Mengapa ini penting

Tanpa SHARED_BOUNDARIES, mode Caveman yang agresif dapat menghapus konten yang tampak seperti prosa
berulang, tetapi sebenarnya merupakan cuplikan kode, jalur file, atau tumpukan kesalahan. SHARED_BOUNDARIES bertindak sebagai
jaring pengaman yang tidak bergantung pada bahasa dan diterapkan sebelum aturan kata pengisi dijalankan.

### Menyesuaikan preservePatterns

Pola tambahan dapat ditambahkan saat runtime melalui pengaturan kompresi:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Pola kustom memperluas (bukan menggantikan) 6 pola bawaan.

## Catatan Operasional

- Aturan bawaan bahasa Inggris tetap menjadi fallback ketika paket bahasa tidak tersedia.
- Paket JSON bawaan yang tidak valid akan gagal divalidasi agar aset rilis tidak mengalami penurunan kualitas secara diam-diam.
- Paket aturan hanya berisi data dan tidak boleh mengimpor kode atau menjalankan logika arbitrer.
- Lapisan analitik kompresi mencatat mode dan mesin yang dipilih, bukan teks prompt lengkap.
