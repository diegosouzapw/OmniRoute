## Kategori

- **Gratis** — tingkat gratis dengan kunci API (dikonfigurasi melalui dasbor)
- **Tanpa autentikasi** — endpoint publik yang sama sekali tidak memerlukan kunci atau proses masuk
- **OAuth** — alur proses masuk ditangani oleh OmniRoute, tanpa memerlukan kunci API
- **Cookie web** — membungkus aplikasi web penyedia melalui autentikasi cookie
- **Kunci API** — penyedia berbayar yang dikonfigurasi melalui kunci API (kredit gratis mungkin berlaku)
- **Lokal** — berjalan di mesin pengguna (Ollama, LM Studio, vLLM, dll.)
- **Pencarian** — penyedia pencarian web
- **Audio** — penyedia khusus audio (TTS/STT)
- **Proksi upstream** — penyedia yang meneruskan permintaan melalui proksi ke penyedia lain
- **Agen cloud** — agen pengodean yang berjalan lama (Codex Cloud, Devin, Jules)
- **Sistem** — penyedia internal OmniRoute (loopback, dll.)

Tag tambahan: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Pemanggilan alat` (jika ditampilkan): `native` — API pemanggilan fungsi yang sesungguhnya; `emulated` — array `tools` diemulasikan melalui prompt menggunakan `webTools.ts` (blok `<tool>{...}</tool>` diurai dengan regex); `none` — `tools` saat ini diabaikan tanpa pemberitahuan. Lihat #7286.

Gunakan dasbor di `/dashboard/providers` untuk mengaktifkan, mengonfigurasi, dan menguji setiap penyedia.
