> **TL;DR**: Instal → Hubungkan penyedia gratis → Arahkan IDE Anda ke OmniRoute. Selesai.

---

## Langkah 1: Instal OmniRoute

Pilih metode yang Anda inginkan:

### Opsi A: npm (Direkomendasikan)

```bash
npm install -g omniroute
```

### Opsi B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` adalah versi SemVer stabil **yang telah dipublikasikan** dengan nomor tertinggi. Tag ini **tidak** mengikuti `main` di git. Sematkan `diegosouzapw/omniroute:X.Y.Z` untuk GitOps. Lihat [Tag Image / Kanal Rilis](../guides/DOCKER_GUIDE.md#release-channels).

### Opsi C: Dari Kode Sumber

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Langkah 2: Jalankan OmniRoute

```bash
omniroute
```

OmniRoute berjalan di `http://localhost:20128`. Dasbor akan terbuka secara otomatis.

---

## Langkah 3: Hubungkan Penyedia Gratis

Anda dapat menggunakan OmniRoute **tanpa membayar apa pun** dengan menghubungkan penyedia gratis.

### Opsi A: Kiro (Claude Gratis — Tanpa Kartu Kredit)

1. Buka dasbor di `http://localhost:20128`
2. Buka **Penyedia** → **Tambahkan Penyedia**
3. Pilih **Kiro AI**
4. Klik **Hubungkan** (tidak memerlukan kunci API!)
5. Selesai! Sekarang Anda memiliki akses gratis ke model-model Claude.

### Opsi B: OpenCode Free (Tanpa Autentikasi)

1. Buka dasbor di `http://localhost:20128`
2. Buka **Penyedia** → **Tambahkan Penyedia**
3. Pilih **OpenCode Free**
4. Klik **Hubungkan** (tidak memerlukan kunci API!)
5. Selesai! Sekarang Anda memiliki akses gratis ke beberapa model.

### Opsi C: Pollinations (Tidak Memerlukan Kunci)

1. Buka dasbor di `http://localhost:20128`
2. Buka **Penyedia** → **Tambahkan Penyedia**
3. Pilih **Pollinations**
4. Klik **Hubungkan** (tidak memerlukan kunci API!)
5. Selesai! Sekarang Anda memiliki akses gratis ke GPT-5, Claude, Gemini, dan lainnya.

---

## Langkah 4: Pastikan Semuanya Berfungsi

Dari [Kunci API](http://localhost:20128/dashboard/api-manager), buat kunci baru. Simpan kunci ini karena tidak akan ditampilkan lagi. Perhatikan bahwa kunci ini digunakan oleh alat untuk mengakses OmniRoute, bukan untuk mengakses penyedia upstream.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Anda seharusnya melihat daftar model yang telah terhubung.

---

## Langkah 5: Arahkan IDE atau CLI Anda ke OmniRoute

Di IDE atau alat CLI Anda, atur:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

Selesai! IDE Anda kini menggunakan OmniRoute dengan pemilihan penyedia otomatis.

### Contoh IDE: VSCode/Continue.dev

1. Di VSCode, instal ekstensi [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Perbarui `~/.continue/config.yaml` Anda dengan menambahkan baris-baris berikut:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Di panel obrolan Continue.dev, pilih `OmniRoute - Auto`, lalu permintaan Anda akan dikirim ke OmniRoute.
4. (Opsional) Latihan untuk pembaca—mintalah IDE Anda memperbarui `config.yaml` dengan semua konfigurasi bawaan lainnya 😊

### Contoh CLI: Codex CLI

1. Di sistem operasi Anda, atur variabel lingkungan secara permanen.
   Untuk macOS/Linux (tambahkan ke `~/.bashrc` atau `~/.zshrc` Anda):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Untuk Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Sekarang mari jalankan Codex, tetapi dengan konfigurasi untuk OmniRoute. Jalankan:

```
omniroute launch-codex --model auto
```

Anda dapat melakukannya secara manual melalui `codex` dan parameter baris perintah untuk menentukan endpoint serta kunci API, tetapi dengan perintah di atas, OmniRoute akan menangani semuanya untuk Anda.

Peluncuran dengan satu perintah yang sama juga berfungsi untuk CLI lain melalui peluncur generik—`omniroute run <target>` mendukung `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, dan `gemini` (lihat [Integrasi CLI](../guides/CLI-INTEGRATIONS.md)).

3. Sekarang CLI seharusnya mengirimkan permintaan ke OmniRoute.

### Pastikan alat Anda merutekan permintaan ke OmniRoute

Anda dapat melihat detail permintaan dengan mengeklik [Pemantauan/Log](http://localhost:20128/dashboard/logs) dari bilah sisi kiri. Dengan mengeklik lebih lanjut, Anda dapat melihat detail tambahan. Sebagai catatan tambahan, Anda dapat melihat informasi apa saja yang dikirimkan oleh harness favorit Anda. Hal ini berguna untuk pembelajaran dan proses debugging.

## Pertanyaan Umum

### "Apakah saya memerlukan kunci API?"

**Tidak!** Anda dapat menggunakan penyedia gratis (Kiro, OpenCode Free, Pollinations) tanpa kunci API apa pun. Cukup hubungkan penyedia tersebut di dasbor.

### "Apa itu `auto`?"

`auto` memberi tahu OmniRoute untuk secara otomatis memilih penyedia terbaik bagi setiap permintaan. OmniRoute mempertimbangkan kecepatan, biaya, kualitas, dan ketersediaan. Lihat [Panduan Auto-Combo](./AUTO-COMBO-GUIDE.md) untuk detailnya.

### "Berapa biayanya?"

OmniRoute sendiri **gratis dan bersumber terbuka**. Anda hanya membayar penyedia yang Anda gunakan. Banyak penyedia menawarkan tingkat gratis—lihat [Panduan Tingkat Gratis](./FREE-TIERS-GUIDE.md).

### "Bisakah saya menggunakannya dengan Claude Code / Cursor / Copilot?"

**Ya!** OmniRoute dapat digunakan dengan alat apa pun yang mendukung format OpenAI. Cukup atur URL dasar ke `http://localhost:20128/v1`. Lihat [Panduan Alat CLI](../reference/CLI-TOOLS.md) untuk petunjuk penyiapan spesifik.

### "Bagaimana jika suatu penyedia mengalami gangguan?"

OmniRoute secara otomatis melewati penyedia yang gagal dan mencoba penyedia berikutnya. Anda tidak perlu melakukan apa pun. Lihat [Panduan Auto-Combo](./AUTO-COMBO-GUIDE.md) untuk detailnya.
