## Apa itu Local Corpus

Local Corpus memungkinkan operator menyediakan satu direktori berisi file teks yang disetujui secara eksplisit untuk server MCP OmniRoute. File tetap berada di direktori asalnya: OmniRoute hanya menyimpan jalur root kanonis di SQLite dan memelihara indeks pencarian dalam memori. Local Corpus tidak menyalin konten korpus ke repositori atau basis data.

Penyegaran indeks dilakukan secara inkremental. File yang tidak berubah digunakan kembali berdasarkan ukuran dan waktu modifikasi, file yang berubah dibaca ulang dan di-hash dengan SHA-256, sedangkan file yang dihapus dikeluarkan dari indeks. Pencarian akan menyegarkan indeks yang berusia lebih dari 30 detik; pemanggil juga dapat meminta penyegaran langsung.

## Mengonfigurasi sumber

Rute pengaturan memerlukan autentikasi pengelolaan yang sama seperti API pengaturan lainnya. Jalur yang dikirimkan harus sudah ada dan harus berupa jalur direktori absolut.

```bash
# Hubungkan direktori yang disetujui
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Periksa konfigurasi dan status indeks
curl http://localhost:20128/api/settings/local-corpus

# Putuskan koneksi tanpa mengubah file sumber
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Alat MCP

Ketiga alat memerlukan `read:local-corpus`. Respons alat menampilkan jalur relatif dan nama dasar direktori root, bukan jalur absolutnya.

| Alat                  | Deskripsi                                                                                  |
| :-------------------- | :----------------------------------------------------------------------------------------- |
| `local_corpus_status` | Melaporkan status konfigurasi, ukuran indeks, batas, dan waktu penyegaran terakhir         |
| `local_corpus_search` | Mencari teks yang diindeks dan mengembalikan cuplikan terbatas per baris (hingga 20 hasil) |
| `local_corpus_read`   | Membaca rentang baris terbatas dari satu file relatif terhadap korpus yang diizinkan       |

Contoh input MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Batasan keamanan

- Daftar yang diizinkan berorientasi pada teks: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, dan `.yml`.
- Symlink dilewati. Jalur pembacaan dikanoniskan dan harus tetap berada di dalam root
  yang dikonfigurasi; jalur absolut dan upaya traversal ditolak.
- Nama direktori sensitif dan hasil pembuatan dikecualikan: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, dan
  `secrets`.
- Batas bawaan adalah 5.000 file, 1 MiB per file, total konten terindeks sebesar 64 MiB,
  sekitar 4.000 karakter per potongan pencarian, dan 400 baris per pembacaan.
- File yang berisi NUL diperlakukan sebagai file nonteks dan dilewati atau ditolak.

Dokumen biner seperti PDF, DOCX, gambar, dan arsip sengaja tidak didukung. Konversikan dokumen tersebut ke format teks yang disetujui di dalam direktori yang dikonfigurasi sebelum pengindeksan.

## Catatan operasional

- Mengubah atau menghapus root yang dikonfigurasi akan mengosongkan indeks bersama dalam memori.
- Memulai ulang proses akan menghapus indeks; pencarian berikutnya akan membangunnya kembali dari sumber
  yang dikonfigurasi.
- `local_corpus_status` tidak memaksakan pemindaian. Gunakan `local_corpus_search` dengan
  `refresh: true` ketika pemindaian ulang langsung diperlukan.
- Kegagalan pemindaian dan pembacaan akan dihitung atau dikembalikan sebagai galat yang telah disanitasi; file sumber
  tidak pernah diubah.
