> **Sumber acuan:** `src/lib/agentSkills/` (katalog, generator, parser) + direktori `skills/` (file SKILL.md)
> **Terakhir diperbarui:** 2026-08-02 — v3.8.50

Agent Skills adalah file SKILL.md terstruktur yang mengajarkan agen eksternal, klien MCP, dan orkestrator A2A cara menggunakan REST API dan CLI OmniRoute. Tidak seperti [Omni Skills](./SKILLS.md) (yang merupakan definisi alat LLM yang dijalankan di dalam OmniRoute), Agent Skills adalah sebuah _katalog dokumentasi_ — markdown statis yang dapat dimasukkan secara langsung ke dalam konteks agen.

---

## Ikhtisar

Katalog ini berisi **45 Agent Skills** (23 REST API + 21 CLI + 1 alur kerja konfigurasi). Setiap skill memiliki:

- Sebuah **ID kanonis** (`omni-auth`, `cli-serve`, dll.)
- Sebuah file **SKILL.md** di `skills/{id}/SKILL.md` dengan frontmatter YAML (`name`, `description`) + isi markdown yang kaya
- **Endpoint REST** (skill API) atau **subperintah CLI** (skill CLI) yang diturunkan dari spesifikasi OpenAPI dan registri CLI
- Sebuah **URL raw GitHub** untuk pengambilan langsung: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Format SKILL.md

```markdown
---
name: omni-providers
description: "Kelola koneksi penyedia: tambahkan, uji, rotasikan, dan hapus kredensial."
---

<!-- dihasilkan oleh src/lib/agentSkills/generator.ts; perubahan manual akan ditimpa -->

## Ikhtisar

...

## Autentikasi

...

## Endpoint

...

<!-- skill:custom-start -->

## Bagian Khusus (dipertahankan selama regenerasi)

...

<!-- skill:custom-end -->
```

Generator mempertahankan konten di antara `<!-- skill:custom-start -->` dan `<!-- skill:custom-end -->` selama regenerasi. Sepuluh skill memiliki blok khusus yang dikurasi:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Penemuan REST API

| Endpoint                     | Metode | Deskripsi                                                                   | Autentikasi |
| :--------------------------- | :----- | :-------------------------------------------------------------------------- | :---------- |
| `/api/agent-skills`          | GET    | Daftar katalog (`?category=api\|cli\|config&area=<area>` bersifat opsional) | tidak ada   |
| `/api/agent-skills/{id}`     | GET    | Dapatkan metadata satu keterampilan                                         | tidak ada   |
| `/api/agent-skills/{id}/raw` | GET    | Ambil SKILL.md sebagai `text/markdown`                                      | tidak ada   |
| `/api/agent-skills/coverage` | GET    | Statistik cakupan (jumlah file SKILL.md yang tersedia)                      | tidak ada   |
| `/api/agent-skills/generate` | POST   | Picu generator (dryRun/prune/onlyIds)                                       | manajemen   |

Contoh — tampilkan semua keterampilan API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Contoh — ambil satu SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Cara Agen Eksternal Menggunakan Skill

### 1. Penemuan melalui REST

```bash
# Dapatkan katalog lengkap
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Dapatkan SKILL.md untuk injeksi konteks
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Penemuan melalui MCP

```typescript
// Di klien MCP Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → larik AgentSkill dengan rawUrl untuk masing-masing
```

### 3. Penemuan melalui A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table adalah tabel markdown dengan semua 45 ID skill + kolom rawUrl
```

### 4. Pengambilan langsung raw GitHub (tidak memerlukan server)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generator

Generator membaca katalog yang dikurasi + spesifikasi OpenAPI + registri CLI, lalu menulis `skills/{id}/SKILL.md` untuk setiap entri:

```bash
# Pratinjau (uji coba, tanpa penulisan)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Regenerasi penuh
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Regenerasi ID tertentu
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Respons generator adalah `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
