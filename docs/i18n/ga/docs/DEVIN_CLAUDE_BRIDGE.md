Ligeann `devin-cli-agentic` d’am rite Claude Code OmniRoute a úsáid go háitiúil leis an gcríochphointe Anthropic
Messages, agus soláthraíonn Devin CLI oifigiúil freagraí na samhla thar ACP stdio. Ní
mhodhnaíonn sé na soláthraithe Anthropic, Claude OAuth, Claude Web, ná `devin-cli` atá ann cheana.

> **Stádas reatha: Claude Code `2.1.258` feistithe; bailíochtú as líne agus beo taifeadta go
> deireanach ar `2.1.220`.** Chuir feistiú `2.1.220` trí chás leithlisithe i gcrích trí Devin CLI
> `3000.2.17` agus samhail `swe-1-7-lightning`; chruthaigh an rith beo deiridh sin sealanna `Read`,
> `Edit`, agus `Bash` faoi úinéireacht an chliaint, torthaí rathúla `npm test`, aimsiú orduithe agus
> scileanna tionscadail, ródú chuig Devin amháin, agus gan aon eis-sreabhadh chuig Claude. Ardaíodh
> an feistiú ansin go `2.1.258` (glúin an CLI a ndéanann aitheantas Claude OmniRoute aithris uirthi,
> agus an chéad líne ina soláthraítear sraith Fable 5.1 go dúchasach). Ar an bhfeistiú nua,
> fíoraíodh an tsraith suiteála agus `claude --version` ar an mbuníomhá fheistithe, agus éiríonn le
> sraith aonad an droichid, `compose config`, agus an cruthúnas statach leithlisithe — ach níor
> ritheadh an cás bréige as líne ná an tsraith bheo trí chás arís go fóill. Rith arís iad
> (féach "Uirlisí feistithe a nuashonrú") sula mbraitheann tú ar an droichead leis an bhfeistiú seo.

## Ailtireacht

```text
Claude Code 2.1.258 (coimeádán Linux leithlisithe nach bhfuil fréamhaithe)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (formáid Claude, soláthraí gan fíordheimhniú)
  -> devin acp --agent-type summarizer (ACP stdio oifigiúil, gan uirlisí Devin)
  -> Cuntas Devin san imleabhar tiomnaithe devin-auth
```

Is féidir le gníomhaire réamhshocraithe ACP an CLI oifigiúil a chuid uirlisí féin a rith, mar sin ní úsáideann
an droichead seo é. Tosaíonn sé an gníomhaire seasta ACP `summarizer`, nach bhfuil aon uirlisí aige i mód
oifigiúil an CLI, agus frámaíonn sé an t-iarratas sraithealaithe Anthropic mar rian feidhmithe. Nuair a bhíonn
gníomh eile faoi úinéireacht Claude de dhíth, ní mór don fhreagra imchlúdach uirlise cliaint amháin go díreach
a bheith ann. Diúltaítear d’aon `tool_call` nó `tool_call_update` ACP sular féidir freagra a thuairisciú mar
fhreagra rathúil.

Caomhnaíonn an sraitheoir in `open-sse/executors/devin-agentic/serializer.ts` `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, agus na
huirlisí a sholáthraíonn Claude Code. Teipeann ar íomhánna agus ar bhloic anaithnide go sainráite. Úsáideann
torthaí móra uirlisí marcóir sofheicthe teasctha.

Glacann an parsálaí le himchlúdach neamhspleách amháin `<tool>{...}</tool>` in aghaidh sheal na samhla. Seiceálann
sé an t-ainm i gcoinne liosta uirlisí an iarratais, bailíochtaíonn sé na hargóintí i gcoinne JSON Schema na
huirlise sin, diúltaíonn sé do mheascán reacaireachta/gníomhartha, agus ceadaíonn sé deisiú teoranta amháin.
Ritheann Claude Code an `tool_use` Anthropic mar thoradh air sin go háitiúil ansin agus seolann sé an
`tool_result` ar ais trí OmniRoute.

## Leithlisiú agus samhail bhagartha

Tá suiteáil, cuntas agus cumraíocht Claude an óstríomhaire lasmuigh den raon feidhme agus caitear leo mar
rudaí toirmiscthe. Déanann seirbhísí Compose an méid seo a leanas:

- ritheann siad mar UID/GID `10001:10001`, le córas fréamhchomhad inléite amháin, cumais ligthe anuas, agus
  `no-new-privileges`;
- úsáideann siad `/home/bridge` príobháideach, imleabhar tiomnaithe cumraíochta Claude, sonraí leithlisithe OmniRoute,
  agus imleabhar ar leith `devin-auth`;
- gléasann siad spásanna oibre/fianaise indiúscartha `.sandbox` amháin;
- ní ghléasann siad baile an óstríomhaire, Keychain, SSH, dintiúir néil, ná soicéad Docker;
- cruthaíonn siad timpeallachtaí sainráite agus baineann siad athróga API/OAuth/ródaithe Anthropic;
- treoraíonn siad tátal Claude Code chuig `http://omniroute:20128` amháin le heochair áitiúil amháin.

Úsáideann an phróifíl as líne líonra inmheánach. Sa phróifíl bheo, ní shroicheann OmniRoute críochphointí
oifigiúla Devin ach trí `network-guard`; diúltaítear do chinn scríbe nach mbaineann leo. Tá garda eis-sreafa
ar leith ag Claude Code a dhiúltaíonn do gach rud, agus ní féidir leis ach an tseirbhís áitiúil OmniRoute
a shroicheadh trí `NO_PROXY`. Ní ghléasann ach a bpróiseas garda féin comhaid iniúchta na ngardaí. Fíoraíonn na
scripteanna úinéireacht comhaid, mód, comhaireamh nasc, agus gach cinneadh sula n-easpórtálann siad fianaise
gan chomharthaí.

Rith an cruthúnas leithlisithe go neamhspleách:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Bailíochtaíonn sé an toipeolaíocht, gléasanna ainmnithe, socruithe neamhfhréimhe/inléite amháin, ródú áitiúil
sainráite, easpa athróg íogair timpeallachta, easpa shoicéad Docker, rochtain bhlocáilte ar
`api.anthropic.com` agus `claude.ai`, roghnú soláthraí chuig Devin amháin, agus teip shainráite nuair nach
mbíonn inneall ACP ar fáil.

## Socrú céaduaire agus gnáthúsáid

Tóg an íomhá phionnáilte:

```bash
./scripts/devin-bridge/build
```

Fíordheimhnigh imleabhar leithlisithe Devin amháin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Úsáideann an t-ordú logála isteach an sreabhadh oifigiúil comhartha láimhe atá ceaptha do
thimpeallachtaí cianda/coimeádáin. Cuirtear an luach isteach go díreach ag leid an CLI; ní
chuirtear ar aghaidh é mar argóint próisis, ní scríobhtar chuig Git é, agus ní chóipeáiltear ón óstach é.

Seol timpeallacht rite leithlisithe Claude Code:

```bash
./scripts/devin-bridge/launch
```

Seiceálann `launch` an leithlisiú, fíordheimhniú Devin, agus aimsiú samhlacha arís sula dtosaíonn sé
Claude Code coimeádánaithe. Ní ritheann sé clár inrite Claude an óstaigh riamh. Is féidir ailiasanna samhlacha a
shocrú in `.env.devin-bridge`; ní mór do gach luach cumraithe an réimír
`devin-cli-agentic/` a choinneáil.

## Orduithe bailíochtaithe

Ní éilíonn an chonair in-atáirgthe as líne cuntas Devin agus níl rochtain Idirlín aici ag am rite:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Seo í an chonair bheo fhíordheimhnithe ar gá roghnú isteach inti:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Fanann an riteoir beo idir cásanna chun seisiúin ACP a sheachaint a oscailt ina rabharta agus
bailíochtaíonn sé teagmhais struchtúrtha srutha Claude in ionad muinín a chur i maímh théacsúla. Cruthaíonn na trí
chás seo:

1. léamh díreach tionscadail agus anailís ar lochtanna;
2. fíor-`Edit`, `Bash` `npm test` faoi úinéireacht an chliaint, agus toradh teirminéil;
3. `/bridge-check` mar aon le haimsiú `bridge-proof`, léamh tionscadail, `npm test` rathúil eile
   faoi úinéireacht an chliaint, agus críochnú gan obair ar feitheamh.

Seiceálann an geata deiridh iniúchadh líonra Devin freisin agus éilíonn sé go bhfanfaidh iniúchadh
amachshrutha Claude folamh.

## Uirlisí pionnáilte a nuashonrú

Tá Node, Claude Code, agus Devin CLI pionnáilte san íomhá in
`docker/devin-bridge/Dockerfile`. Chun iad a nuashonrú:

1. athraigh na leaganacha sainráite;
2. cuir luachanna don déantán oifigiúil in ionad an dá shuim sheiceála cartlainne Devin a bhaineann go sonrach le hailtireacht;
3. atóg agus rith gach ordú bailíochtaithe as líne;
4. deimhnigh na leaganacha laistigh den íomhá;
5. athrith an tsraith bheo fhíordheimhnithe trí chás.

Ná suiteáil ceachtar CLI go domhanda ar an óstach agus ná cuir íoslódáil neamhfhíoraithe in
ionad fhíorú na suime seiceála.

## Diagnóis agus glanadh

- Taispeánann `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  ródú áitiúil agus earráidí sláintithe an fhorghníomhaitheora.
- Taifeadann `.sandbox/evidence/mock-acp.jsonl` gníomhartha cinntitheacha bréige ACP.
- Taifeadann `.sandbox/evidence/claude-stream.jsonl` fíor-rith as líne Claude Code.
- Taifeadann `.sandbox/evidence/live-*.jsonl` na trí shruth bheo bhailíochtaithe.
- Is cóipeanna bailíochtaithe saor ó chomharthaí d'iniúchtaí an gharda iad `.sandbox/evidence/egress.jsonl` agus `.sandbox/evidence/claude-egress.jsonl`.

Stop coimeádáin agus líonraí faoi úinéireacht agus imleabhair logála isteach/cumraíochta á gcaomhnú:

```bash
./scripts/devin-bridge/clean
```

Bain timpeallacht iomlán an droichid atá faoina úinéireacht, lena n-áirítear imleabhair ainmnithe:

```bash
./scripts/devin-bridge/clean --all
```

## Teorainneacha

- Braitheann an droichead ar an ról seasta gan uirlisí `summarizer` toisc nach gcuireann Devin CLI `3000.2.17`
  gníomhaire neodrach ACP gan uirlisí ar fáil. Déanann an cuibheoir cúiteamh as freagraí idirmheánacha
  atá múnlaithe mar achoimrí, ach d’fhéadfadh teip shainráite tarlú fós le linn deis theoranta amháin deisiúcháin.
- Is féidir le glaonna beo ACP freagraí sealadacha `502`/`504` a thabhairt ar ais. Cuireann an creat tástála spás idir cásanna;
  má leanann an teip ar aghaidh, fanann sé dúnta ar mhaithe le sábháilteacht agus ní roghnaíonn sé soláthraí eile riamh.
- Atógtar comhthéacs ACP ó gach iarratas Anthropic; níl aon
  chleamhnas próisis/seisiúin ann.
- Tacaítear le glao uirlise amháin in aghaidh gach freagra ón tsamhail; diúltaítear do ghlaonna comhthreomhara.
- Ní thacaítear le híomhánna go sainráite. Ní fhógraítear fís, aschur smaointeoireachta, rialuithe iarrachta, ná fuinneog comhthéacs 1M.
- Úsáideann SSE teagmhais bhailí shaolré Anthropic, ach astaítear iad tar éis an seal teoranta ACP a
  bhailiú; ní chuirtear smutáin ACP ar aghaidh go hincriminteach.
