---

## An Rud a Dhéanann Sé

In ionad samhail shonrach IS a roghnú (amhail GPT-4o nó Claude), is féidir leat ligean do OmniRoute **an ceann is fearr a roghnú go huathoibríoch** do gach iarratas. Cuireann sé na nithe seo a leanas san áireamh:

- **Sláinte** — An bhfuil an soláthraí ag obair faoi láthair?
- **Luas** — Cé chomh tapa is atá sé?
- **Costas** — Cé mhéad a chosnaíonn sé?
- **Cáilíocht** — An bhfuil sé go maith don chineál seo taisc?
- **Acmhainn** — An bhfuil cuóta fágtha aige?

Tugann OmniRoute scór do gach ceann de do sholáthraithe nasctha agus roghnaíonn sé an ceann is fearr. Má theipeann air, baineann sé triail as an gcéad cheann eile go huathoibríoch.

---

## Tús Tapa

**Céim 1**: Socraigh do mhúnla mar `auto` i do IDE nó CLI:

```
model: "auto"
```

**Céim 2**: Sin é! Láimhseálann OmniRoute an chuid eile.

**Céim 3** (roghnach): Úsáid malairt le haghaidh tascanna sonracha:

```
model: "auto/coding"    # Is fearr le haghaidh cód
model: "auto/fast"      # An freagra is tapúla
model: "auto/cheap"     # An rogha is saoire
```

## Cén "auto" Ba Chóir Dom a Úsáid?

| Más mian leat...                   | Úsáid é seo    | Is fearr le haghaidh                 | An chaoi a n-oibríonn sé                                    |
| ---------------------------------- | -------------- | ------------------------------------ | ----------------------------------------------------------- |
| **An ceann is fearr ar an iomlán** | `auto`         | Ceisteanna ginearálta, comhrá        | Cothromaíonn sé luas, costas agus cáilíocht                 |
| **An cód is fearr**                | `auto/coding`  | Cód a scríobh, dífhabhtú             | Roghnaíonn sé samhlacha atá go maith do thascanna códúcháin |
| **An freagra is tapúla**           | `auto/fast`    | Freagraí tapa, aga folaigh íseal     | Tugann sé tús áite don luas thar gach rud eile              |
| **An rogha is saoire**             | `auto/cheap`   | Airgead a shábháil                   | Roghnaíonn sé an soláthraí is saoire                        |
| **An tsamhail is cliste**          | `auto/smart`   | Tascanna casta                       | Cáilíocht ar dtús + samhlacha nua a iniúchadh               |
| **An ceann is mó atá ar fáil**     | `auto/offline` | Nuair a bhíonn soláthraithe gnóthach | Roghnaíonn sé na soláthraithe ag a bhfuil an acmhainn is mó |

### Samplaí

```bash
# Comhrá ginearálta — cothromaithe
curl http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'

# Giniúint cóid — cáilíocht ar dtús
curl http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto/coding","messages":[{"role":"user","content":"Write a Python function"}]}'

# Freagra tapa — luas ar dtús
curl http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto/fast","messages":[{"role":"user","content":"What is 2+2?"}]}'
```

## An Chaoi a n-Oibríonn Sé (Leagan Simplí)

Nuair a sheolann tú iarratas le `model: "auto"`, déanann OmniRoute na rudaí seo a leanas:

1. **Féachann sé ar do sholáthraithe nasctha go léir** — Gach soláthraí atá curtha agat leis (OpenAI, Anthropic, Google, srl.)
2. **Tugann sé scór do gach ceann acu**, agus na nithe seo a leanas, i measc nithe eile, á gcur san áireamh:
   - An bhfuil sé ag obair? (sláinte)
   - An bhfuil acmhainn aige? (cuóta)
   - Cé mhéad a chosnaíonn sé? (praghas)
   - Cé chomh tapa is atá sé? (luas)
   - An bhfuil sé go maith don tasc seo? (cáilíocht)
3. **Roghnaíonn sé an ceann is fearr** — Faigheann an soláthraí leis an scór is airde d'iarratas
4. **Athshlánaíonn sé go huathoibríoch** — Má theipeann air, baineann OmniRoute triail as an gcéad cheann eile go huathoibríoch

### An Córas Scórála

Faigheann gach soláthraí scór ó 0 go 1. Dá airde an scór, is ea is fearr a oireann sé.

| Fachtóir            | Ualú | An bhrí atá leis                                                   |
| ------------------- | ---- | ------------------------------------------------------------------ |
| Sláinte             | 20%  | An bhfuil an soláthraí ag obair? (staid an scoradáin chiorcaid)    |
| Cuóta               | 15%  | An bhfuil acmhainn fágtha aige?                                    |
| Costas              | 15%  | Cé chomh costasach is atá sé? (níos saoire = scór níos airde)      |
| Luas                | 12%  | Cé chomh tapa is atá sé? (aga folaigh níos ísle = scór níos airde) |
| Oiriúnacht don Tasc | 8%   | An bhfuil sé go maith don chineál seo taisc?                       |
| Cobhsaíocht         | 5%   | An bhfuil sé comhsheasmhach? (ráta íseal earráidí)                 |
| Leibhéal            | 5%   | Leibhéal cuntais (Ultra > Pro > Free)                              |
| Eile                | 20%  | Cleamhnas comhthéacs, dlús ceangail, srl.                          |

### An Chaoi a n-Athraíonn Malairtí an Scóráil

Úsáideann gach malairt ualuithe éagsúla:

| Malairt        | Tugann sí tús áite do | Príomh-Ualuithe                 |
| -------------- | --------------------- | ------------------------------- |
| `auto`         | Cothromaíocht         | health=20%, quota=15%, cost=15% |
| `auto/coding`  | Cáilíocht             | taskFit=37%, stability=15%      |
| `auto/fast`    | Luas                  | latency=32%, health=28%         |
| `auto/cheap`   | Costas                | cost=37%                        |
| `auto/smart`   | Cáilíocht + Iniúchadh | taskFit=37%, exploration=10%    |
| `auto/offline` | Acmhainn              | quota=37%, health=28%           |

## An Chaoi a Láimhseálann Sé Teipeanna

Tá **trí shraith chosanta** ag OmniRoute:

### 1. Cúltaca Uathoibríoch

Má theipeann ar an soláthraí is fearr, baineann OmniRoute triail as an gcéad cheann eile go huathoibríoch. Ní gá duit aon rud a dhéanamh.

### 2. Féinleigheas

Má leanann soláthraí de bheith ag teip:

- **Scór < 0.2** → Eisiata ar feadh 5 nóiméad
- **Scoradán ciorcaid oscailte** → Eisiata go huathoibríoch
- **Níos mó ná 50% de na soláthraithe as feidhm** → Mód teagmhais (gan taiscéalaíocht)

### 3. Cúltaca Éigeandála

Má theipeann ar gach soláthraí, seolann OmniRoute iarrataí chuig soláthraithe cobhsaí saor in aisce (amhail Kiro nó Qoder) mar rogha dheiridh.

---

## Tacaíocht d’Ilchuntais

Má tá roinnt cuntas agat don soláthraí céanna (m.sh., dhá eochair OpenAI), déileálann OmniRoute le gach ceann acu mar **iarrthóir ar leith**. Ciallaíonn sé seo:

- Tá cuóta fágtha i gCuntas A → úsáid é
- Tá teorainn ráta curtha ar Chuntas B → gabh thairis air
- Tá Cuntas C níos saoire → tabhair tús áite dó

Scóráiltear gach cuntas go neamhspleách bunaithe ar a shláinte, a chuóta agus a luas féin.

---

## Taiscéalaíocht Bandit

Déanann OmniRoute **iniúchadh** ar sholáthraithe nua ó am go chéile chun roghanna níos fearr a aimsiú:

- **Réamhshocrú**: Téann 5% d’iarratais chuig soláthraithe randamacha
- **Auto/smart**: Ráta taiscéalaíochta 10%
- **Díchumasaithe** nuair atá níos mó ná 50% de na soláthraithe míshláintiúil

Cuidíonn sé seo le OmniRoute a fháil amach cé na soláthraithe is fearr a oibríonn do do phatrúin úsáide.

## Ceisteanna Coitianta

### "An roghnóidh sé an tsamhail is costasaí i gcónaí?"

**Ní roghnóidh.** Ní dhéanann costas ach 15% den scór de réir réamhshocraithe. Is féidir le soláthraí saor, tapa, sláintiúil ceann daor a shárú. Úsáid `auto/cheap` más mian leat tús áite níos mó fós a thabhairt don chostas.

### "Cad a tharlaíonn má théann soláthraí as feidhm?"

Gabhann OmniRoute thairis air go huathoibríoch agus baineann sé triail as an gcéad cheann eile. Má leanann soláthraí de bheith ag teip, eisiatar go sealadach é (5-30 nóiméad). Ní gá duit aon rud a dhéanamh.

### "An féidir liom a fheiceáil cén soláthraí a úsáideadh?"

Seiceáil ceanntásca an fhreagra — cuireann OmniRoute an soláthraí agus an tsamhail a úsáideadh san áireamh i ngach freagra.

### "An bhfoghlaimíonn sé ó m’úsáid?"

Foghlaimíonn! Úsáideann an córas scórála sonraí stairiúla (aga folaigh, rátaí earráide, rátaí ratha) chun cinntí níos fearr a dhéanamh le himeacht ama.

### "Cad é an difríocht idir `auto` agus `auto/smart`?"

- `auto` — Cothromaithe, taiscéalaíocht 5%
- `auto/smart` — Tús áite don cháilíocht (na hualuithe céanna le `auto/coding`), taiscéalaíocht 10%

Úsáid `auto/smart` nuair is mian leat an cháilíocht is fearr agus tú sásta le taiscéalaíocht ó am go chéile.

### "An féidir liom iallach a chur air soláthraí ar leith a úsáid?"

Is féidir! Úsáid teaglaim leis an straitéis `priority` in ionad `auto`, ansin seol **ainm beacht** na teaglaime mar an réimse `model` (m.sh. `model: "my-combo"` — ní `auto`). Féach an [Tagairt Theicniúil](../routing/AUTO-COMBO.md) le haghaidh sonraí.

### "Cén difríocht atá idir seo agus round-robin?"

Rothlaíonn round-robin trí na soláthraithe in ord. **Scórálann auto-combo gach soláthraí** agus roghnaíonn sé an ceann is fearr. Tá sé níos cliste — cuireann sé sláinte, luas, costas agus cáilíocht san áireamh.
