> **Go hachomair**: Suiteáil → Ceangail soláthraí saor in aisce → Dírigh d’IDE ar OmniRoute. Sin é.

---

## Céim 1: Suiteáil OmniRoute

Roghnaigh an modh is fearr leat:

### Rogha A: npm (Molta)

```bash
npm install -g omniroute
```

### Rogha B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

Is é `:latest` an leagan cobhsaí SemVer **foilsithe** is airde. Ní leanann sé `main` git. Pionnáil `diegosouzapw/omniroute:X.Y.Z` le haghaidh GitOps. Féach [Clibeanna Íomhá / Cainéil Eisiúna](../guides/DOCKER_GUIDE.md#release-channels).

### Rogha C: Ón gCód Foinseach

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Céim 2: Tosaigh OmniRoute

```bash
omniroute
```

Tosaíonn OmniRoute ag `http://localhost:20128`. Osclaítear an deais go huathoibríoch.

---

## Céim 3: Ceangail Soláthraí Saor in Aisce

Is féidir leat OmniRoute a úsáid **gan aon rud a íoc** ach soláthraí saor in aisce a cheangal.

### Rogha A: Kiro (Claude Saor in Aisce — Gan Cárta Creidmheasa)

1. Oscail an deais ag `http://localhost:20128`
2. Téigh chuig **Soláthraithe** → **Cuir Soláthraí Leis**
3. Roghnaigh **Kiro AI**
4. Cliceáil **Ceangail** (níl eochair API ag teastáil!)
5. Sin é! Tá rochtain saor in aisce agat anois ar shamhlacha Claude.

### Rogha B: OpenCode Free (Gan Fíordheimhniú)

1. Oscail an deais ag `http://localhost:20128`
2. Téigh chuig **Soláthraithe** → **Cuir Soláthraí Leis**
3. Roghnaigh **OpenCode Free**
4. Cliceáil **Ceangail** (níl eochair API ag teastáil!)
5. Sin é! Tá rochtain saor in aisce agat anois ar roinnt samhlacha.

### Rogha C: Pollinations (Níl Eochair de Dhíth)

1. Oscail an deais ag `http://localhost:20128`
2. Téigh chuig **Soláthraithe** → **Cuir Soláthraí Leis**
3. Roghnaigh **Pollinations**
4. Cliceáil **Ceangail** (níl eochair API ag teastáil!)
5. Sin é! Tá rochtain saor in aisce agat anois ar GPT-5, Claude, Gemini, agus tuilleadh.

---

## Céim 4: Deimhnigh go nOibríonn Sé

Ó [Eochracha API](http://localhost:20128/dashboard/api-manager), cruthaigh eochair nua. Coinnigh an eochair seo slán mar ní thaispeánfar arís í. Tabhair faoi deara gur chun rochtain a thabhairt d’uirlisí ar OmniRoute atá an eochair seo, agus ní chun rochtain a fháil ar sholáthraithe réamhtheachtacha.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Ba cheart duit liosta de do shamhlacha ceangailte a fheiceáil.

## Céim 5: Dírigh d’IDE nó CLI ar OmniRoute

I d’uirlis IDE nó CLI, socraigh:

```
Bun-URL:    http://localhost:20128/v1
Eochair API: [cóipeáil ó Deais → Críochphointí]
Samhail:     auto
```

Sin é! Úsáideann d’IDE OmniRoute anois agus roghnaítear an soláthraí go huathoibríoch.

### Sampla IDE: VSCode/Continue.dev

1. In VSCode, suiteáil an breiseán [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Nuashonraigh do `~/.continue/config.yaml` chun na línte seo a leanas a chur leis:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. I bpána comhrá Continue.dev, roghnaigh `OmniRoute - Auto` agus seolfaidh tú iarratais chuig OmniRoute.
4. (Roghnach) Cleachtadh don léitheoir — iarr ar d’IDE an `config.yaml` a nuashonrú leis na cumraíochtaí réamhthógtha eile ar fad 😊

### Sampla CLI: Codex CLI

1. I do chóras oibriúcháin, socraigh an athróg timpeallachta go buan.
   Le haghaidh macOS/Linux (cuir le do `~/.bashrc` nó `~/.zshrc` í):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Le haghaidh Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Anois seolfaimid Codex, ach é cumraithe le haghaidh OmniRoute. Rith:

```
omniroute launch-codex --model auto
```

Is féidir leat é seo a dhéanamh de láimh trí `codex` agus paraiméadair líne na n-orduithe a úsáid chun an críochphointe agus an eochair API a shonrú, ach leis an ordú thuas, déanann OmniRoute cúram de gach rud duit.

Oibríonn an seoladh aonordaithe céanna le haghaidh CLIanna eile tríd an lainseálaí ginearálta — tacaíonn `omniroute run <target>` le `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, agus `gemini` (féach [Comhtháthuithe CLI](../guides/CLI-INTEGRATIONS.md)).

3. Ba cheart don CLI a bheith ag seoladh iarratas chuig OmniRoute anois.

### Deimhnigh go bhfuil d’uirlis ag ródú chuig OmniRoute

Is féidir leat sonraí an iarratais a fheiceáil trí [Monatóireacht/Logaí](http://localhost:20128/dashboard/logs) a chliceáil sa bharra taoibh ar chlé. Taispeántar tuilleadh sonraí duit nuair a chliceálann tú isteach. Mar nóta breise, is féidir leat a fheiceáil cén fhaisnéis a sheoltar ó do chóras is fearr leat. Tá sé seo úsáideach ó thaobh na foghlama agus na dífhabhtaithe de.

## Ceisteanna Coitianta

### "An bhfuil eochair API de dhíth orm?"

**Níl!** Is féidir leat soláthraithe saor in aisce (Kiro, OpenCode Free, Pollinations) a úsáid gan aon eochair API. Níl le déanamh agat ach iad a cheangal sa deais.

### "Cad é `auto`?"

Insíonn `auto` do OmniRoute an soláthraí is fearr a roghnú go huathoibríoch do gach iarratas. Cuireann sé luas, costas, cáilíocht agus infhaighteacht san áireamh. Féach an [Treoir Auto-Combo](./AUTO-COMBO-GUIDE.md) le haghaidh sonraí.

### "Cé mhéad a chosnaíonn sé?"

Tá OmniRoute féin **saor in aisce agus foinse oscailte**. Ní íocann tú ach as na soláthraithe a úsáideann tú. Tá sraitheanna saor in aisce ag go leor soláthraithe — féach an [Treoir do Shraitheanna Saor in Aisce](./FREE-TIERS-GUIDE.md).

### "An féidir liom é a úsáid le Claude Code / Cursor / Copilot?"

**Is féidir!** Oibríonn OmniRoute le haon uirlis a thacaíonn le formáid OpenAI. Níl le déanamh agat ach an bun-URL a shocrú mar `http://localhost:20128/v1`. Féach an [Treoir d’Uirlisí CLI](../reference/CLI-TOOLS.md) le haghaidh treoracha sonracha cumraithe.

### "Cad a tharlaíonn má theipeann ar sholáthraí?"

Scipeálann OmniRoute soláthraithe ar theip orthu go huathoibríoch agus baineann sé triail as an gcéad cheann eile. Ní gá duit aon rud a dhéanamh. Féach an [Treoir Auto-Combo](./AUTO-COMBO-GUIDE.md) le haghaidh sonraí.
