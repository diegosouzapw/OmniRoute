## Cad is Soláthraí ann?

Samhlaigh soláthraí mar **oibreoir teileafóin**. Díreach mar a theastaíonn oibreoir teileafóin uait chun glaonna a dhéanamh, teastaíonn soláthraí IS uait chun samhlacha IS a úsáid. Tá OmniRoute cosúil le teileafón a oibríonn le **gach oibreoir** — is féidir leat aistriú eatarthu go huathoibríoch.

### Cineálacha Soláthraithe

| Cineál              | Cad atá ann                         | Samplaí                           | Costas                       |
| ------------------- | ----------------------------------- | --------------------------------- | ---------------------------- |
| **Saor in aisce**   | Ní theastaíonn íocaíocht            | Kiro, OpenCode Free, Pollinations | $0                           |
| **Eochair API**     | Teastaíonn eochair API uait         | OpenAI, Anthropic, Google         | Íoc de réir úsáide           |
| **OAuth**           | Logáil isteach le do chuntas        | Claude Code, GitHub Copilot       | Síntiús                      |
| **Fianán Gréasáin** | Úsáideann sé do sheisiún brabhsálaí | ChatGPT Web (Codex), Gemini Web   | $0 (úsáideann sé do chuntas) |

### Soláthraithe Fianán Gréasáin

Féach **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** le haghaidh treoracha ginearálta cumraíochta, teorainneacha, fabhtcheartaithe agus treorach fíordheimhnithe a bhaineann go sonrach le gach soláthraí.

## Tús Tapa: Ceangail Do Chéad Soláthraí

### Cumraíocht roghnach soláthraithe saor in aisce ar an gcéad rith

Tairgeann an draoi céadrite cárta sainráite **Cumraigh soláthraithe saor in aisce**. Faigheann sé an liosta incháilithe reatha
ó chlárlann soláthraithe gan fhíordheimhniú OmniRoute, agus ansin ligeann sé duit gach
soláthraí a athbhreithniú agus a dhíroghnú sula ndeimhníonn tú. Taispeánann OmniRoute fógra rabhaidh an tsoláthraí agus nasc chuig a shuíomh
ionas gur féidir leat téarmaí tríú páirtí, príobháideachas, infhaighteacht agus teorainneacha ráta a athbhreithniú ar dtús.

Tá an gníomh seo roghnach: ní chruthaítear ceangail le soláthraithe saor in aisce go ciúin riamh nuair a chríochnaítear an draoi.
Ní chruthaíonn sé ach soláthraithe atá fós in easnamh, fágann sé ceangail shaincheaptha atá ann cheana
gan athrú, agus tuairiscíonn sé soláthraithe cruthaithe, soláthraithe atá cumraithe cheana agus soláthraithe ar theip orthu ceann ar cheann. Tar éis toradh páirteach, is féidir leat
triail eile a bhaint go sábháilte as na cinn ar theip orthu amháin.

### Rogha A: Soláthraí Saor in Aisce (Ní Theastaíonn Cárta Creidmheasa)

1. Oscail an deais ag `http://localhost:20128`
2. Téigh chuig **Soláthraithe** → **Cuir Soláthraí Leis**
3. Roghnaigh ceann de na soláthraithe saor in aisce seo:
   - **Kiro AI** — Samhlacha Claude saor in aisce (ní theastaíonn fíordheimhniú)
   - **OpenCode Free** — Samhlacha GPT saor in aisce (ní theastaíonn fíordheimhniú)
   - **Pollinations** — GPT-5, Claude, Gemini saor in aisce (ní theastaíonn eochair)
   - **LongCat** — 10M comhartha saor in aisce (deontas aonuaire, teastaíonn cuntas + KYC)
   - **Cloudflare AI** — 50+ samhail, 10K néarón/lá
   - **MLX Gemma 26B** — Samhail áitiúil Apple Silicon (~38.5 comhartha/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — Samhail áitiúil Apple Silicon (~9.1 comhartha/s, ~13.1GB RAM)
4. Cliceáil **Ceangail**
5. Sin é! Tá rochtain saor in aisce ar IS agat anois.

### Rogha B: Soláthraí Eochrach API (Íoctha)

1. Faigh eochair API ó shuíomh gréasáin an tsoláthraí:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Oscail an deais ag `http://localhost:20128`
3. Téigh chuig **Soláthraithe** → **Cuir Soláthraí Leis**
4. Roghnaigh do sholáthraí
5. Greamaigh d'eochair API
6. Cliceáil **Ceangail**
7. Sin é! Tá rochtain agat anois ar shamhlacha an tsoláthraí sin.

### Rogha C: Soláthraí OAuth (Síntiús)

1. Oscail an deais ag `http://localhost:20128`
2. Téigh chuig **Soláthraithe** → **Cuir Soláthraí Leis**
3. Roghnaigh do sholáthraí (m.sh., Claude Code, GitHub Copilot)
4. Cliceáil **Ceangail le OAuth**
5. Logáil isteach le do chuntas
6. Sin é! Tá rochtain agat anois ar na samhlacha i do shíntiús.

### Rogha D: Samhlacha Áitiúla MLX (Apple Silicon)

I gcás Macanna Apple Silicon a bhfuil cuimhne aontaithe acu, tacaíonn OmniRoute le ceangal le samhlacha áitiúla MLX atá ag rith trí `mlx-lm.server` mar ghnáthsholáthraithe áitiúla atá comhoiriúnach le OpenAI.

#### Réamhriachtanais

- **Mac Apple Silicon** (M1/M2/M3/M4) le 24GB+ de chuimhne aontaithe molta
- Bainisteoir pacáistí **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Tús Tapa

1. **Suiteáil spleáchais**:

   ```bash
   # Suiteáil uv mura bhfuil sé suiteáilte cheana
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Suiteáil mlx-lm
   uv pip install mlx-lm
   ```

2. **Tosaigh freastalaithe MLX de láimh** (i dteirminéil ar leith):

   ```bash
   # Teirminéal 1: Gemma 4 26B A4B IT-QAT (port 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Teirminéal 2: Qwen 3.8 27B MLX Mixed (port 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Ceangail i nDeais OmniRoute**:
   - Téigh chuig **Soláthraithe** → **Cuir Soláthraí Leis**
   - Roghnaigh **MLX Gemma 26B** nó **MLX Qwen 3.8 27B**
   - Cliceáil **Ceangail** (ní theastaíonn eochair API)

4. **Úsáid le OpenCode**:
   ```bash
   # Cumraigh OpenCode chun OmniRoute a úsáid
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Úsáid samhlacha MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Bainistíocht Cuimhne

**Tábhachtach**: Le 24GB de chuimhne aontaithe, ní féidir ach **samhail mhór MLX amháin a rith ag an am**.

- Gemma 26B: ~15.9GB buaicchuimhne
- Qwen 3.8 27B: ~13.1GB buaicchuimhne

Ní mór duit é seo a bhainistiú de láimh:

- Ná rith ach freastalaí MLX amháin ag an am, nó
- Rith an dá cheann ar mheaisíní ar leith, nó
- Stop ceann amháin sula dtosaíonn tú an ceann eile

Ní bhainistíonn OmniRoute próisis fhreastalaí MLX go huathoibríoch — ní dhéanann sé ach iarratais a ródú chuig na críochphointí atá comhoiriúnach le OpenAI a chumraíonn tú.

#### Tacaíocht do Ghlaoch Uirlisí

Tacaíonn an dá shamhail le glaoch uirlisí atá comhoiriúnach le OpenAI. Déan tástáil le:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "Cad é 2+2? Úsáid an uirlis áireamháin."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Ríomh", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

| Fadhb                       | Réiteach                                                                                                   |
| --------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Ní thosaíonn an freastalaí  | Seiceáil `uv run mlx_lm.server --help` agus deimhnigh aitheantais na samhlacha                             |
| Cuimhne ídithe              | Cinntigh nach bhfuil ach samhail amháin ag rith; dún aipeanna eile; seiceáil Activity Monitor              |
| Diúltaíodh don nasc         | Deimhnigh go bhfuil an freastalaí ag rith ar an bport ceart (11435/11436)                                  |

## Conas Ceangal le Soláthraí (Céim ar Chéim)

### Céim 1: Oscail an Deais

Téigh chuig `http://localhost:20128` i do bhrabhsálaí.

### Céim 2: Téigh chuig Soláthraithe

Cliceáil **Soláthraithe** sa bharra taoibh.

### Céim 3: Cliceáil Cuir Soláthraí Leis

Cliceáil an cnaipe **+ Cuir Soláthraí Leis**.

### Céim 4: Roghnaigh do Sholáthraí

Brabhsáil an liosta nó déan cuardach ar do sholáthraí. Cliceáil air.

### Céim 5: Cuir Dintiúir Isteach

- **Soláthraithe saor in aisce**: Níl dintiúir de dhíth — níl le déanamh ach cliceáil ar **Ceangail**
- **Soláthraithe eochrach API**: Greamaigh d'eochair API
- **Soláthraithe OAuth**: Cliceáil **Ceangail le OAuth** agus logáil isteach

### Céim 6: Tástáil an Ceangal

Cliceáil **Tástáil an Ceangal** chun a fhíorú go n-oibríonn sé.

### Céim 7: Déanta!

Tá do sholáthraí ceangailte anois. Is féidir leat é a úsáid le `model: "auto"` nó an soláthraí a shonrú go díreach.

## Il-Soláthraithe a Úsáid

Is fearr a oibríonn OmniRoute le **hil-soláthraithe**. Tugann sé seo duit:

- **Cúltaca uathoibríoch** — Má theipeann ar sholáthraí amháin, baineann OmniRoute triail as an gcéad cheann eile
- **Optamú costais** — Roghnaíonn OmniRoute an soláthraí is saoire do gach iarratas
- **Optamú luais** — Roghnaíonn OmniRoute an soláthraí is tapúla do gach iarratas
- **Optamú cáilíochta** — Roghnaíonn OmniRoute an soláthraí is fearr do gach tasc

### Socrú Molta

Ceangail **3 sholáthraí** ar a laghad chun an t-eispéireas is fearr a fháil:

1. **Soláthraí amháin saor in aisce** (Kiro, OpenCode Free, nó Pollinations) — Ar fáil i gcónaí
2. **Soláthraí tapa amháin** (Groq, Cerebras) — Le haghaidh freagraí gasta
3. **Soláthraí ardchaighdeáin amháin** (OpenAI, Anthropic, Google) — Le haghaidh tascanna casta

Ansin úsáid `model: "auto"` agus roghnóidh OmniRoute an ceann is fearr do gach iarratas go huathoibríoch.

## Ceisteanna Coitianta

### "An gá dom íoc chun OmniRoute a úsáid?"

**Ní gá!** Tá OmniRoute saor in aisce agus foinse oscailte. Is féidir leat soláthraithe saor in aisce (Kiro, OpenCode Free, Pollinations) a úsáid gan aon íocaíocht a dhéanamh. Ní íocann tú ach amháin má roghnaíonn tú soláthraithe íoctha a úsáid.

### "Cén soláthraí ar cheart dom tosú leis?"

Tosaigh le **Kiro AI** — tá sé saor in aisce, ní theastaíonn eochair API uaidh, agus tugann sé rochtain duit ar shamhlacha Claude. Ansin cuir tuilleadh soláthraithe leis de réir mar is gá.

### "An féidir liom níos mó ná soláthraí amháin a úsáid ag an am céanna?"

**Is féidir!** Sin é bun agus barr OmniRoute. Ceangail roinnt soláthraithe agus úsáid `model: "auto"` chun ligean do OmniRoute an ceann is fearr a roghnú do gach iarratas.

### "Cad a tharlaíonn má stopann soláthraí de bheith ag obair?"

Scipeálann OmniRoute soláthraithe ar theip orthu go huathoibríoch agus baineann sé triail as an gcéad cheann eile. Ní gá duit aon rud a dhéanamh.

### "Conas a dhícheanglaím soláthraí?"

Téigh chuig Soláthraithe → cliceáil ar an soláthraí → cliceáil **Dícheangail**.

### "An féidir liom na heochracha API atá agam cheana féin a úsáid?"

**Is féidir!** Má tá eochracha API agat cheana féin le haghaidh OpenAI, Anthropic, Google, srl., is féidir leat iad a úsáid in OmniRoute. Níl le déanamh ach iad a ghreamú agus an soláthraí á cheangal agat.
