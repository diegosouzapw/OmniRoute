Bain úsáid as an treoir seo chun an lúb forbartha iontaofa is lú a roghnú d’iarratas tarraingthe. Ní
thagann sí in ionad na ndoiciméad ailtireachta agus slándála a bhaineann go sonrach leis na réimsí agus
atá nasctha thíos; nascann sí gach cineál coitianta athraithe lena chonarthaí, lena sheiceálacha
dírithe, agus lena chumhdach CI.

## An chonair a leanann gach athrú

1. **Roghnaigh an bonn sula ndéanann tú eagarthóireacht.** Aimsigh an brainse gníomhach `release/v*`
   is airde agus cruthaigh brainse óna bharr. Dírigh ar an mbrainse sin, seachas ar `main`. Má tá
   reo eisiúna i bhfeidhm, ná dírigh ar an mbrainse reoite; bain úsáid as an gcéad timthriall gníomhach
   eile a bhfuil cur síos air in
   [Samhail Bhrainseála & Eisiúna](BRANCHING_MODEL.md).
2. **Ainmnigh na conarthaí.** Sainaithin gach catalóg, scéimre, déantán ginte, API poiblí, nó comhéadan
   úsáideora a mbíonn tionchar ag an athrú air. Tugann an tábla thíos an tacar tosaigh íosta.
3. **Scríobh nó nuashonraigh tástálacha dírithe.** Éilíonn athruithe táirgeachta in `src/`, `open-sse/`,
   `electron/`, nó `bin/` tástáil uathoibrithe san iarratas tarraingthe céanna. Rith na comhaid
   tástála is lú a chruthaíonn an t-iompar, agus ansin na geataí dírithe liostaithe.
4. **Lig do CI an mhaitrís leathan a rith.** Ritheann na deighiltí iomlána tástálacha aonaid, Vitest,
   an raicín cumhdaigh, agus an tógáil táirgeachta ar an iarratas tarraingthe. Ná rith sraith leathan
   go háitiúil ach amháin nuair a léiríonn teip dhírithe tionchar níos leithne nó nuair a chuimsíonn
   an t-athrú roinnt fochóras.
5. **Réitigh na difríochtaí roimh an athbhreithniú.** Faigh an bonn gníomhach, scrúdaigh a chuid
   gealltanas nua agus do dhifríocht ina choinne, agus ansin athbhunaigh nó cumaisc an bonn de réir
   shreabhadh oibre na rannpháirtithe. Réitigh coinbhleachtaí i gcomhaid ghinte agus i gcatalóga óna
   bhfoinse, gin arís iad, athrith an lúb dhírithe, agus deimhnigh go bhfuil an t-iarratas tarraingthe
   fós dírithe ar an mbrainse eisiúna gníomhach.
6. **Taifead an fhianaise.** I dteimpléad an iarratais tarraingthe, liostaigh na horduithe a ritheadh,
   gach comhad tástála a cuireadh leis nó a athraíodh, aistrithe nó bratacha gnéithe, agus aon
   bhailíochtú CI amháin atá fós ar feitheamh.

## Conairí caighdeánacha de réir cineáil athraithe

Is seiceálacha dírithe íosta iad na horduithe thíos, ní cead iad tástáil a chumhdaíonn go díreach an
t-iompar a d’athraigh tú a scipeáil.

### Soláthraí

**Conarthaí**

- Sainmhíniú an tsoláthraí in `src/shared/constants/providers/` agus a chomhdhéanamh in
  `src/shared/constants/providers.ts`.
- Samhlacha agus cumais in `open-sse/config/providerRegistry.ts` nó ina chomhaid clárlainne
  eastósctha.
- Roghnú seiceadóra/aistritheora, cumraíocht OAuth nó eochrach API, sócmhainní an deais, agus tagairt
  ghinte an tsoláthraí nuair is infheidhme.
- Ní mór do dhintiúir phoiblí `resolvePublicCred()` a úsáid; ní mór do fhreagraí earráide na
  comhchúntóirí sláintithe earráide a úsáid. Féach `docs/security/PUBLIC_CREDS.md` (git; ní
  thiomsaítear é isteach in `/docs`) agus
  [Sláintiú Earráidí](../security/ERROR_SANITIZATION.md).

**Lúb dhírithe**

```bash
npm run check:provider-consistency
npm run check:provider-assets
node --import tsx/esm --test tests/unit/provider-translate-path-golden.test.ts
node --import tsx/esm --test tests/unit/<provider-or-executor>.test.ts
npm run gen:provider-reference   # nuair a athraíonn an chatalóg; geall an difríocht ghinte
npm run lint
```

Déan tástáil freisin ar gach teaghlach iarratais a ndéantar difear dó: comhrá, Responses, íomhánna,
leabuithe, fuaim, nó físeán. Athbhreithnigh difríochtaí catalóige ginte agus caighdeánacha mar
athruithe conartha; ná glac leo go dall.

### Ródú

**Conarthaí**

- Luachanna straitéise poiblí agus meiteashonraí UI in `src/shared/constants/routingStrategies.ts`.
- Seoladh agus ordú faoi `open-sse/services/combo.ts` agus `open-sse/services/combo/`.
- Scéimeanna teaglama, marthanacht, staid athléimneachta, cumais samhla, agus rialtáin API/UI.
- [Inneall Auto-Combo](../routing/AUTO-COMBO.md) agus doiciméadacht athléimneachta nuair a athraíonn
  an t-iompar.

**Lúb dhírithe**

```bash
node --import tsx/esm --test tests/unit/combo-<behavior>.test.ts
npm run test:combo:matrix        # athruithe straitéise nó seolta
npm run check:known-symbols      # athruithe ar chlárú straitéise
npm run lint
```

Bain úsáid as tástálacha cinntitheacha le réamhtheachtacha bréige go háitiúil. Teastaíonn dintiúir
ó thástálacha deataigh beo ar theaglamaí agus is tástálacha láimhe iad, ní ionadaigh CI.

### UI / UX

**Conarthaí**

- Bealach/leathanach Next.js agus teorainneacha comhpháirteanna comhroinnte faoi `src/app/` agus
  `src/shared/components/`.
- Cruthanna freagartha API, staideanna lódála/folmha/earráide, iompar méarchláir agus léitheora
  scáileáin, leagan amach sofhreagrach, téamaí, agus leathnú logchaighdeán.
- Teaghráin fhoinseacha Bhéarla don UI in `src/i18n/messages/en.json`; ná crua-chódaigh téacs nua
  atá dírithe ar úsáideoirí.

**Lúb dhírithe**

```bash
node --import tsx --test tests/unit/dashboard/<feature>.test.ts
npx vitest run --config vitest.config.ts tests/unit/ui/<component>.test.tsx
npm run check:dashboard-typecheck
npm run lint
```

Rith an aip le haghaidh athruithe idirghníomhaíochta nó amhairc agus seiceáil amhairc chúnga agus
leathana araon. Ritheann CI an tógáil táirgeachta agus sraitheanna níos leithne; teastaíonn fós
comhpháirt dhírithe, Playwright, nó seiceáil láimhe dhoiciméadaithe atá oiriúnach don athrú chun
iompar amhairc a fhíorú.

### i18n

**Conarthaí**

- Is é `src/i18n/messages/en.json` foinse an UI; is é `config/i18n.json` foinse na logchaighdeán.
- Coinnítear catalóga CLI ar leithligh faoi `bin/cli/locales/`.
- Caomhnaigh ionadchoinneálaithe agus clibeanna ICU go díreach. Ná haistrigh ainmneacha
  táirgí/soláthraithe/samhlacha, ainmneacha prótacail agus ceanntásca, orduithe, aitheantóirí
  cóid/JSON, URLanna, athróga timpeallachta, nó téarmaí cosanta amhail `OmniRoute`, `OAuth`, `MCP`,
  agus `A2A`. Is é `scripts/i18n/glossary/protected-terms.json` an liosta foinse reatha.

**Lúb dhírithe**

```bash
npm run i18n:sync-ui:dry
npm run i18n:check-ui-coverage
npm run i18n:check-value-drift
npm run i18n:check-glossary
npm run check:cli-i18n          # nuair a athraíonn teaghráin/catalóga CLI
npm run lint
```

Is treoir í seo don chóras reatha, ní cuireadh chun a chuid uirlisí ná a shamhail eochracha a
leathnú. Coinnigh paistí i18n beacht agus an córas ionaid á dhearadh. Ná rith orduithe aistriúcháin
a ghlaonn ar sheirbhísí seachtracha mura n-éilíonn an tasc aistriúcháin ghinte go sainráite agus
mura bhfuil athbhreithniú déanta agat ar an difríocht a tháinig astu.

### CLI

**Conarthaí**

- Orduithe agus bratacha poiblí in `bin/cli/`, orduithe API ginte, cóid scoir, stdout/stderr agus
  cruthanna aschuir JSON, iompar cumraíochta/comhshaoil, agus comhaid phacáistithe.
- Ní mór do theaghráin don úsáideoir sa CLI ciseal i18n an CLI a úsáid agus catalóga `en`/`pt-BR` a choinneáil ailínithe.
- Caomhnaigh Node mar an t-am rite tacaithe agus conradh an dénártha fhoilsithe.

**Lúb fhócasaithe**

```bash
node --import tsx/esm --test tests/unit/cli/<command>.test.ts
npm run check:cli-i18n
npm run build:cli             # athruithe ar an CLI ginte/cuachta
npm run check:pack-policy     # athruithe ar dhromchla an phacáiste
npm run lint
```

Úsáid an t-ordú beacht i gcomhadlann sonraí shealadach nuair a bhraitheann an t-iompar ar pharsáil, ar chomhaid nó ar stádas
scoir. Déanann CI na seiceálacha níos leithne ar dhéantáin phacáiste agus ar an éiceachóras.

### Bunachar sonraí

**Conarthaí**

- Modúil fearainn faoi `src/lib/db/`; iompórtáil modúil shonracha go díreach (baineadh an seanchiseal ath-easpórtála `localDb.ts`).
- Imircí SQL uimhrithe, idéimitheacha faoi `src/lib/db/migrations/`, sábháilteacht idirbheart, iompar
  uasghrádaithe, innéacsanna, agus gach glaoiteoir a ndéanann an scéimre difear dó.
- Ní eisíonn bealaí ná láimhseálaithe SQL amh go díreach riamh.

**Lúb fhócasaithe**

```bash
npm run check:migration-numbering
npm run check:db-rules
node --import tsx/esm --test tests/unit/db/<domain>.test.ts
node --import tsx/esm --test tests/unit/db/migration-<number>.test.ts
npm run lint
```

Tástáil bunachar sonraí úr agus uasghrádú ón scéimre roimhe seo araon agus imirce á cur leis. Ní mór do thástálacha bunachair sonraí
na hanlaí a dhúnadh agus `resetDbInstance()` a ghlaoch le linn glantacháin. Ná rith `npm run test:bun:db` ach amháin nuair a
athraíonn conair chuibheoir Bun ar bhonn na hiarrachta is fearr; is é Node an t-údarás i gcónaí.

### Tógáil / imscaradh

**Conarthaí**

- Manifisteanna fréimhe agus spás oibre/comhad glais, `scripts/build/`, cóimeáil neamhspleách Next.js, inneachar pacáiste
  `dist/`, meiteashonraí ardáin Electron, sreafaí oibre CI, agus fairtheoirí imscartha.
- Ní mór na raonta Node tacaithe agus úsáid Bun ar an liosta ceadaithe in `CLAUDE.md` a choinneáil slán.
- Fanann déantáin tógála gan rianú; tá feidhm ag beartais spleáchais, ceadúnais, sreafa oibre agus pacáiste.

**Lúb fhócasaithe**

```bash
node --import tsx/esm --test tests/unit/build/<behavior>.test.ts
npm run check:build-scope
npm run check:lockfile         # athruithe ar spleáchais nó ar an gcomhad glais
npm run check:pack-policy      # athruithe ar dhromchla an phacáiste fhoilsithe
npm run lint
```

Ná húsáid `npm run build` go háitiúil ach amháin nuair a théann an t-athrú i bhfeidhm ar thiomsú, ar chóimeáil neamhspleách, ar shócmhainní,
nó ar chuachadh ama rite. Ná húsáid `npm run build:release` ach amháin le haghaidh bailíochtú eisiúna/imscartha. Is é tógáil CI
an comhartha deiridh trasardáin; teastaíonn an tógáil fhócasaithe chomhfhreagrach nó fianaise tástála deataigh le haghaidh athruithe Electron a bhaineann go sonrach le hardán.

## Lúb áitiúil i gcomparáid le CI

| Rith go háitiúil do gach paiste                                                                               | Soláthraíonn CI an comhartha leathan                                                     |
| ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Tástálacha díreacha iompair agus na geataí catagóire thuas                                                    | Sraith iomlán tástálacha aonaid roinnte agus tástálacha srathacha                        |
| `npm run lint`                                                                                                | Sraitheanna Vitest agus raicíní clúdaigh/cáilíochta                                      |
| Seiceáil cineáil nó tógáil ach amháin nuair a éilíonn an conradh lena mbaineann é                             | Tógáil táirgthe, slándáil, doiciméid, spleáchais agus geataí beartais PR                 |
| Seiceálacha idirghníomhaíochta/beo de láimh ach amháin nuair nach féidir le huathoibriú an t-iompar a chruthú | Seiceálacha comhtháthaithe trasphoist agus ardáin atá cumraithe de réir an tsreafa oibre |

Is fianaise í lúb fhócasaithe ghlas faoin gconradh athraithe, ní cruthúnas go n-éireoidh le seiceálacha CI
neamhghaolmhara. Os a choinne sin, ná cuir iallach ar gach eagarthóireacht áitiúil fanacht le maitrís iomlán na stórtha.

## Seicliosta réitigh

Sula n-iarrtar athbhreithniú:

- Deimhnigh gurb é bonn an PR fós an brainse gníomhach `release/v*` is airde.
- Faigh an bonn sin agus athbhreithnigh na coimiteanna a cuireadh i dtír ó chruthaigh tú do bhrainse.
- Athbhreithnigh `git diff <active-base>...HEAD` le haghaidh athruithe de thaisme nó athruithe ginte.
- Réitigh coinbhleachtaí catalóige agus doiciméad ginte tríd an bhfoinse a nuashonrú agus an t-aschur a athghiniúint.
- Athrith gach tástáil/geata fhócasaithe atá liostaithe sa tuairisc PR tar éis an réitigh.
- Ná lagaigh dearbhuithe ná ná bain tástálacha riachtanacha ach amháin chun bonn atá bogtha a mheaitseáil.

Le haghaidh rialacha reo eisiúna agus athspriocdhírithe, úsáid
[Samhail na mBrainsí & na nEisiúintí](BRANCHING_MODEL.md). Le haghaidh fardal iomlán CI, úsáid
[Tagairt do Gheataí Cáilíochta](../architecture/QUALITY_GATES.md).
