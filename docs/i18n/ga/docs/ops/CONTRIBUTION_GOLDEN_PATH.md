Úsáid an treoir seo chun an lúb forbartha iontaofa is lú a roghnú le haghaidh iarratas tarraingthe. Ní
ghlacann sí ionad na ndoiciméad ailtireachta agus slándála a bhaineann go sonrach leis an réimse agus atá nasctha thíos; nascann sí gach cineál coitianta
athraithe lena chonarthaí, lena sheiceálacha dírithe agus lena chumhdach CI.

## An chonair a leanann gach athrú

1. **Roghnaigh an bonn sula ndéanann tú eagarthóireacht.** Aimsigh an brainse gníomhach `release/v*` is airde agus cruthaigh brainse ó
   bharr an bhrainse sin. Dírigh ar an mbrainse sin, ní ar `main`. Má tá reo eisiúna i bhfeidhm, ná dírigh ar an mbrainse
   reoite; úsáid an chéad timthriall gníomhach eile a bhfuil cur síos air in
   [Samhail Bhrainseála & Eisiúna](BRANCHING_MODEL.md).
2. **Ainmnigh na conarthaí.** Sainaithin gach catalóg, scéimre, déantán ginte, API poiblí nó comhéadan
   úsáideora a dtéann an t-athrú i bhfeidhm air. Tugann an tábla thíos an tacar tosaigh íosta.
3. **Scríobh nó nuashonraigh tástálacha dírithe.** Éilíonn athruithe táirgeachta in `src/`, `open-sse/`, `electron/`, nó
   `bin/` tástáil uathoibrithe san PR céanna. Rith na comhaid tástála is lú a chruthaíonn an
   t-iompar, agus ansin na geataí dírithe atá liostaithe.
4. **Lig do CI an mhaitrís leathan a rith.** Ritheann na míreanna iomlána aonaid, Vitest, an raicín cumhdaigh agus
   an tiomsú táirgeachta ar an PR. Ná rith sraith leathan go háitiúil ach amháin nuair a léiríonn teip dhírithe
   tionchar níos leithne nó nuair a chuimsíonn an t-athrú roinnt fochóras.
5. **Réitigh na difríochtaí roimh an athbhreithniú.** Faigh an bonn gníomhach, scrúdaigh a chuid tiomantas nua agus do dhifríocht ina
   choinne, ansin déan rebase nó cumasc ar an mbonn de réir shreabhadh oibre na rannpháirtithe. Réitigh coinbhleachtaí i gcomhaid
   ghinte agus i gcatalóga óna bhfoinse, gin arís iad, athrith an lúb dírithe, agus deimhnigh go bhfuil an
   PR fós dírithe ar an mbrainse eisiúna gníomhach.
6. **Taifead an fhianaise.** Sa teimpléad PR, liostaigh na horduithe a ritheadh, gach comhad tástála a cuireadh leis nó a athraíodh,
   ascnaimh nó bratacha gné, agus aon bhailíochtú CI-amháin atá fós ar feitheamh.

## Conairí caighdeánacha de réir cineáil athraithe

Is iad na horduithe thíos na seiceálacha dírithe íosta, ní cead chun tástáil a chlúdaíonn go díreach an
t-iompar a d’athraigh tú a fhágáil ar lár.

### Soláthraí

**Conarthaí**

- Sainmhíniú an tsoláthraí in `src/shared/constants/providers/` agus a chomhdhéanamh in
  `src/shared/constants/providers.ts`.
- Samhlacha agus cumais in `open-sse/config/providerRegistry.ts` nó ina chomhaid chlárlainne eastósctha.
- Roghnú an fhorghníomhaitheora/an aistritheora, cumraíocht OAuth nó eochrach API, sócmhainní an deais, agus tagairt ghinte
  an tsoláthraí nuair is infheidhme.
- Ní mór do dhintiúir phoiblí `resolvePublicCred()` a úsáid; ní mór do fhreagraí earráide na cúntóirí comhroinnte
  sláintithe earráide a úsáid. Féach `docs/security/PUBLIC_CREDS.md` (git; ní thiomsaítear é isteach in `/docs`) agus
  [Sláintiú Earráidí](../security/ERROR_SANITIZATION.md).

**Lúb dhírithe**

```bash
npm run check:provider-consistency
npm run check:provider-assets
node --import tsx/esm --test tests/unit/provider-translate-path-golden.test.ts
node --import tsx/esm --test tests/unit/<provider-or-executor>.test.ts
npm run gen:provider-reference   # nuair a athraíonn an chatalóg; tiomnaigh an difríocht ghinte
npm run lint
```

Déan tástáil freisin ar gach teaghlach iarratais lena mbaineann: comhrá, Responses, íomhánna, leabuithe, fuaim nó físeán.
Déan athbhreithniú ar dhifríochtaí ginte catalóige agus tagartha mar athruithe conartha; ná glac leo gan iad a scrúdú.

### Ródú

**Conarthaí**

- Luachanna straitéise poiblí agus meiteashonraí UI in `src/shared/constants/routingStrategies.ts`.
- Seoladh agus ordú faoi `open-sse/services/combo.ts` agus `open-sse/services/combo/`.
- Scéimrí teaglama, marthanacht, staid athléimneachta, cumais samhlacha, agus rialuithe API/UI.
- [Inneall Auto-Combo](../routing/AUTO-COMBO.md) agus doiciméadacht athléimneachta nuair a athraíonn an t-iompar.

**Lúb dhírithe**

```bash
node --import tsx/esm --test tests/unit/combo-<behavior>.test.ts
npm run test:combo:matrix        # athruithe straitéise nó seolta
npm run check:known-symbols      # athruithe ar chlárú straitéise
npm run lint
```

Úsáid tástálacha cinntitheacha le réamhtheacht mockáilte go háitiúil. Teastaíonn dintiúir le haghaidh tástálacha deataigh beo ar theaglamaí agus is
tástálacha láimhe iad, ní ionadaithe ar CI.

### UI / UX

**Conarthaí**

- Bealach/leathanach Next.js agus teorainneacha comhpháirteanna comhroinnte faoi `src/app/` agus
  `src/shared/components/`.
- Cruthanna freagraí API, staideanna luchtaithe/folmha/earráide, iompar méarchláir agus léitheora scáileáin,
  leagan amach sofhreagrúil, téamaí, agus leathnú logchaighdeán.
- Teaghráin fhoinseacha Bhéarla an UI in `src/i18n/messages/en.json`; ná crua-chódaigh téacs nua atá dírithe ar úsáideoirí.

**Lúb dhírithe**

```bash
node --import tsx --test tests/unit/dashboard/<feature>.test.ts
npx vitest run --config vitest.config.ts tests/unit/ui/<component>.test.tsx
npm run check:dashboard-typecheck
npm run lint
```

Rith an feidhmchlár le haghaidh athruithe idirghníomhaíochta nó amhairc agus seiceáil amhairc chúnga agus leathana araon. Ritheann CI an
tiomsú táirgeachta agus na sraitheanna níos leithne; teastaíonn comhpháirt dhírithe, Playwright,
nó seiceáil láimhe dhoiciméadaithe atá oiriúnach don athrú le haghaidh iompar amhairc fós.

### i18n

**Conarthaí**

- Is é `src/i18n/messages/en.json` foinse an UI; is é `config/i18n.json` foinse na logchaighdeán.
- Tá catalóga CLI ar leithligh faoi `bin/cli/locales/`.
- Caomhnaigh ionadchoinneálaithe agus clibeanna ICU go díreach. Ná haistrigh ainmneacha táirgí/soláthraithe/samhlacha,
  ainmneacha prótacail agus ceanntásca, orduithe, aitheantóirí cóid/JSON, URLanna, athróga timpeallachta, nó
  téarmaí cosanta amhail `OmniRoute`, `OAuth`, `MCP`, agus `A2A`. Is é an liosta foinse reatha
  `scripts/i18n/glossary/protected-terms.json`.

**Lúb dhírithe**

```bash
npm run i18n:sync-ui:dry
npm run i18n:check-ui-coverage
npm run i18n:check-value-drift
npm run i18n:check-glossary
npm run check:cli-i18n          # nuair a athraíonn teaghráin/catalóga CLI
npm run lint
```

Treoir don chóras atá ann cheana is ea seo, ní cuireadh chun a chuid uirlisí nó samhail eochracha a leathnú.
Coinnigh paistí i18n beacht agus an córas ionaid á dhearadh. Ná rith orduithe aistriúcháin
a ghlaonn ar sheirbhísí seachtracha mura n-éilíonn an tasc aistriúcháin ghinte go sainráite agus
mura bhfuil athbhreithniú déanta agat ar an difríocht a tháinig as.

### CLI

**Conarthaí**

- Orduithe agus bratacha poiblí in `bin/cli/`, orduithe API ginte, cóid scoir, stdout/stderr agus
  cruthanna aschuir JSON, iompar cumraíochta/comhshaoil, agus comhaid phacáistithe.
- Ní mór do theaghráin CLI atá dírithe ar úsáideoirí ciseal i18n an CLI a úsáid agus catalóga `en`/`pt-BR` a choinneáil ailínithe.
- Caomhnaigh Node mar an t-am rite tacaithe agus conradh na dénártha foilsithe.

**Lúb dhírithe**

```bash
node --import tsx/esm --test tests/unit/cli/<command>.test.ts
npm run check:cli-i18n
npm run build:cli             # athruithe ar an CLI ginte/cuachta
npm run check:pack-policy     # athruithe ar dhromchla an phacáiste
npm run lint
```

Úsáid an t-ordú beacht in eolaire sealadach sonraí nuair a bhraitheann an t-iompar ar pharsáil, ar chomhaid, nó ar stádas
scoir. Déanann CI na seiceálacha níos leithne ar dhéantáin phacáiste agus ar an éiceachóras.

### Bunachar sonraí

**Conarthaí**

- Modúil fearainn faoi `src/lib/db/`; iompórtáil modúil shonracha go díreach (baineadh an seanchiseal athonnmhairithe `localDb.ts`).
- Ascnaimh SQL uimhrithe, idéinpóiteacha faoi `src/lib/db/migrations/`, sábháilteacht idirbheart, iompar
  uasghrádaithe, innéacsanna, agus gach glaoiteoir a mbíonn tionchar ag an scéimre air.
- Ní eisíonn bealaí ná láimhseálaithe SQL amh go díreach riamh.

**Lúb dhírithe**

```bash
npm run check:migration-numbering
npm run check:db-rules
node --import tsx/esm --test tests/unit/db/<domain>.test.ts
node --import tsx/esm --test tests/unit/db/migration-<number>.test.ts
npm run lint
```

Déan tástáil ar bhunachar sonraí úr agus ar uasghrádú ón scéimre roimhe seo araon nuair a chuirtear ascnamh leis. Ní mór do thástálacha bunachair sonraí
hanlaí a dhúnadh agus `resetDbInstance()` a ghlaoch le linn glanta. Ná rith `npm run test:bun:db` ach amháin nuair a athraíonn
cosán an oiriúnaitheora Bun atá ar bhonn na hiarrachta is fearr; is é Node an t-údarás i gcónaí.

### Tógáil / imscaradh

**Conarthaí**

- Lastliostaí/glaschomhad fréimhe agus spás oibre, `scripts/build/`, cóimeáil neamhspleách Next.js, inneachar pacáiste
  `dist/`, meiteashonraí ardáin Electron, sreafaí oibre CI, agus faireoirí imscartha.
- Ní mór raonta tacaithe Node agus úsáid Bun atá ar an liosta ceadaithe in `CLAUDE.md` a choinneáil slán.
- Fanann déantáin tógála gan rianú; tá feidhm ag beartais spleáchais, ceadúnais, sreafa oibre agus pacáiste.

**Lúb dhírithe**

```bash
node --import tsx/esm --test tests/unit/build/<behavior>.test.ts
npm run check:build-scope
npm run check:lockfile         # athruithe ar spleáchais nó ar an nglaschomhad
npm run check:pack-policy      # athruithe ar dhromchla an phacáiste fhoilsithe
npm run lint
```

Ná húsáid `npm run build` go háitiúil ach amháin nuair a théann an t-athrú i bhfeidhm ar thiomsú, cóimeáil neamhspleách, sócmhainní,
nó cuachadh ama rite. Ná húsáid `npm run build:release` ach amháin le haghaidh bailíochtú eisiúna/imscartha. Is é tógáil CI
an comhartha trasardáin deiridh; teastaíonn an tógáil dhírithe chomhfhreagrach nó fianaise ó thástáil deataigh le haghaidh athruithe Electron a bhaineann go sonrach le hardán.

## Lúb iarrthóra áitiúil

Ní féidir le tástálacha foinse a chruthú go dtosaíonn an déantán pacáistithe: ní theipeann ar liostaí pacáistithe, spleáchais bhearrtha,
ná dénártha dúchasacha ach amháin nuair a shuiteáiltear agus a thosaítear an tarball. Is é `npm run dev:candidate`
(`scripts/dev/candidate.mjs`) an taobh áitiúil den sreabhadh tóg uair amháin / bailíochtaigh / cuir chun cinn ó
RFC #8084: tógann sé iarrthóir amháin, bailíochtaíonn sé an déantán cruinn sin, cuireann sé chun cinn é trí
eolairí a athainmniú, agus rollann sé siar é nuair a theipeann ar sheiceáil sláinte na sliotán curtha chun cinn.

```bash
npm run dev:candidate -- run --dry-run --json  # priontáil an plean, ná hathraigh aon rud
npm run dev:candidate -- run                   # tógáil + bailíochtú + cur chun cinn, uath-rolladh siar
npm run dev:candidate -- build                 # npm pack + suiteáil isteach in _artifacts/candidate/<id>/
npm run dev:candidate -- validate --id <id>    # tosú ar phort saor, /api/health + /v1/models
npm run dev:candidate -- promote --id <id>     # <id> → current, current → previous
npm run dev:candidate -- rollback              # malartaigh current agus previous
npm run dev:candidate -- run --from-tarball <file.tgz>  # athúsáid tarball a tógadh in áit eile (CI)
```

- **Tóg uair amháin.** Pacálann `build` an crann reatha (teastaíonn `dist/server.js` uaidh, mar sin rith
  `npm run build:release` ar dtús) nó cóipeálann sé `--from-tarball`, ansin suiteálann sé an tarball i
  réimír npm leithlisithe, toisc nach bhfuil `node_modules` ar bith sa tarball. Is é an id an sha gairid `HEAD`
  (`-dirty` nuair atá athruithe áitiúla sa chrann) nó `tgz-<sha256>` i gcás tarball. Athúsáidtear id glan atá
  tógtha cheana féin in ionad é a atógáil; úsáid `--force` chun é a atógáil.
- **Bailíochtaigh an pacáiste, ní an fhoinse.** Tosaíonn `validate` an CLI suiteáilte
  (`serve --port <free port>`) le `DATA_DIR=<candidate>/data` úr, rúin bhréige, agus
  `OMNIROUTE_API_KEY`, `STORAGE_ENCRYPTION_KEY` agus `INITIAL_PASSWORD` an oibreora bainte den
  timpeallacht, ionas go seiceálann sé staidiúir lúbaischuir gan eochair suiteála úire. Fanann sé go dtí go
  dtugann `GET /api/health` 200 ar ais, éilíonn sé go dtabharfaidh `GET /v1/models` 200 ar ais, stopann sé an grúpa próiseas,
  agus taifeadann sé an breithiúnas in `validation.json` mar aon le hais an tarball.
- **Cuir an déantán céanna chun cinn.** Diúltaíonn `promote` d’iarrthóir gan bailíochtú rathúil dá
  hais tarball reatha. Is é `_artifacts/candidate/current` an sliotán gníomhach réamhshocraithe; roghnaíonn `--target <dir>`
  eolaire eile ar an gcóras comhad céanna, agus is é `<dir>.previous` an sliotán roimhe sin.
  Is adamhach gach athainmniú, agus má tharlaíonn teip leath bealaigh aisiompaítear na hathainmnithe a ritheadh cheana féin.
- **Rollaigh siar.** Bailíochtaíonn `run` an sliotán curtha chun cinn arís agus malartaíonn sé `current` agus `previous` ar ais nuair
  a theipeann ar an tseiceáil sin. Ní chuirtear iarrthóir a dteipeann air sa chéad bhailíochtú chun cinn riamh.

Scríobhtar gach rud faoin `_artifacts/candidate/` a ndéanann git neamhaird de; ní dhéantar teagmháil riamh le suiteáil OmniRoute
atá ann cheana ná lena heolaire sonraí. Is é
`_artifacts/candidate/current/prefix/bin/omniroute` an CLI curtha chun cinn; tosaigh é le do `DATA_DIR` féin nuair a úsáideann tú
é. Cóid scoir: `0` rath, `1` bailíochtú nó cur chun cinn teipthe, `2` earráid úsáide nó tógáil ar iarraidh.

## Lúb áitiúil i gcomparáid le CI

| Rith go háitiúil do gach paiste                                                                       | Soláthraíonn CI an comhartha leathan                                                |
| ----------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Tástálacha díreacha iompair agus na geataí catagóire thuas                                            | Sraith iomlán tástálacha aonaid roinnte agus tástálacha srathacha                   |
| `npm run lint`                                                                                        | Sraitheanna Vitest agus raicíní cumhdaigh/cáilíochta                                |
| Seiceáil cineáil nó tógáil ach amháin nuair a éilíonn an conradh lena mbaineann é                     | Tógáil táirgthe, geataí slándála, doiciméadachta, spleáchais agus beartais PR       |
| Idirghníomhú láimhe/seiceálacha beo ach amháin nuair nach féidir le huathoibriú an t-iompar a chruthú | Seiceálacha comhtháthaithe trastasc agus ardáin atá cumraithe ag an sreabhadh oibre |

Is fianaise í lúb fhócasaithe ghlas faoin gconradh a athraíodh, ní cruthúnas go n-éireoidh le seiceálacha CI nach mbaineann leis
dul tríd. Os a choinne sin, ná cuir ar gach eagarthóireacht áitiúil fanacht le maitrís iomlán na stórtha.

## Seicliosta réitigh

Sula n-iarrtar athbhreithniú:

- Deimhnigh gurb é bonn an PR fós an brainse gníomhach `release/v*` is airde.
- Faigh an bonn sin agus athbhreithnigh na gealltanais a cuireadh i dtír ó chruthaigh tú do bhrainse.
- Athbhreithnigh `git diff <active-base>...HEAD` le haghaidh athruithe de thaisme nó athruithe ginte.
- Réitigh coinbhleachtaí catalóige agus doiciméad ginte tríd an bhfoinse a nuashonrú agus an t-aschur a athghiniúint.
- Athrith gach tástáil/geata fhócasaithe atá liostaithe sa tuairisc PR tar éis an réitigh.
- Ná lagaigh dearbhuithe ná ná bain tástálacha riachtanacha díreach chun iad a chur in oiriúint do bhonn a bogadh.

Maidir le rialacha reo eisiúna agus athspriocdhírithe, úsáid
[Samhail Brainseála & Eisiúna](BRANCHING_MODEL.md). Chun fardal iomlán CI a fháil, úsáid
[Tagairt do Gheataí Cáilíochta](../architecture/QUALITY_GATES.md).
