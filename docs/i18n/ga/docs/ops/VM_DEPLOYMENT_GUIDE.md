## 1. Cumraigh an VM

### 1.1 Cruthaigh an t-ásc

Ar do rogha soláthraí VPS:

- Roghnaigh Ubuntu 24.04 LTS
- Roghnaigh an plean íosta (1 vCPU / 1 GB RAM)
- Socraigh pasfhocal láidir root nó cumraigh eochair SSH
- Breac síos an **IP poiblí** (m.sh., `203.0.113.10`)

### 1.2 Ceangail trí SSH

```bash
ssh root@203.0.113.10
```

### 1.3 Nuashonraigh an córas

```bash
apt update && apt upgrade -y
```

### 1.4 Suiteáil Docker

```bash
# Suiteáil na spleáchais
apt install -y ca-certificates curl gnupg

# Cuir stór oifigiúil Docker leis
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $ (. /etc/os-release && echo "$VERSION_CODENAME") stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

### 1.5 Suiteáil nginx

```bash
apt install -y nginx
```

### 1.6 Cumraigh an Balla Dóiteáin (UFW)

```bash
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp    # SSH
ufw allow 80/tcp    # HTTP (atreorú)
ufw allow 443/tcp   # HTTPS
ufw enable
```

> **Leid**: Ar mhaithe leis an tslándáil is fearr, cuir srian ar phoirt 80 agus 443 ionas nach mbeidh rochtain orthu ach ag IPanna Cloudflare. Féach an rannán [Ardslándáil](#advanced-security).

## 2. Suiteáil OmniRoute

### 2.1 Cruthaigh an chomhadlann chumraíochta

```bash
mkdir -p /opt/omniroute
```

### 2.2 Cruthaigh comhad na n-athróg timpeallachta

```bash
cat > /opt/omniroute/.env << 'EOF'
# === Slándáil ===
JWT_SECRET=CHANGE-TO-A-UNIQUE-64-CHAR-SECRET-KEY
INITIAL_PASSWORD=YourSecurePassword123!
API_KEY_SECRET=REPLACE-WITH-ANOTHER-SECRET-KEY
STORAGE_ENCRYPTION_KEY=REPLACE-WITH-THIRD-SECRET-KEY
STORAGE_ENCRYPTION_KEY_VERSION=v1
MACHINE_ID_SALT=CHANGE-TO-A-UNIQUE-SALT
OMNIROUTE_WS_BRIDGE_SECRET=REPLACE-WITH-WS-BRIDGE-SECRET  # RIACHTANACH sa táirgeadh: úsáideann droichead Codex Responses WS é

# === Aip ===
PORT=20128
NODE_ENV=production
HOSTNAME=0.0.0.0
DATA_DIR=/app/data
APP_LOG_TO_FILE=true
AUTH_COOKIE_SECURE=true
REQUIRE_API_KEY=false

# === URLanna (athraigh go dtí d'fhearann féin) ===
# Bun-URL inmheánach ó fhreastalaí go freastalaí le haghaidh jabanna sceidealaithe / féin-aisghabhálacha.
BASE_URL=http://127.0.0.1:20128
# URL don bhrabhsálaí a úsáidtear le haghaidh aisghlaonna OAuth, naisc deais agus URLanna poiblí ginte.
NEXT_PUBLIC_BASE_URL=https://llms.seudominio.com
# Sárú sainráite roghnach ar an mbunús poiblí le haghaidh URLanna sócmhainní poiblí ginte.
# OMNIROUTE_PUBLIC_BASE_URL=https://llms.seudominio.com

# === Sioncrónú Néalríomhaireachta (roghnach) ===
# CLOUD_URL=https://cloud.omniroute.online
# NEXT_PUBLIC_CLOUD_URL=https://cloud.omniroute.online
EOF
```

> ⚠️ **TÁBHACHTACH**: Gin eochracha rúnda uathúla! Úsáid `openssl rand -hex 32` le haghaidh gach eochrach.

### 2.3 Tosaigh an coimeádán

```bash
docker pull diegosouzapw/omniroute:latest

docker run -d \
  --name omniroute \
  --restart unless-stopped \
  --env-file /opt/omniroute/.env \
  -p 20128:20128 \
  -v omniroute-data:/app/data \
  diegosouzapw/omniroute:latest
```

### 2.4 Deimhnigh go bhfuil sé ag rith

```bash
docker ps | grep omniroute
docker logs omniroute --tail 20
```

Ba cheart dó na nithe seo a thaispeáint: `[DB] SQLite database ready` agus `listening on port 20128`.

## 3. Cumraigh nginx (Seachfhreastalaí Droim ar Ais)

### 3.1 Gin teastas SSL (Cloudflare Origin)

I ndeais Cloudflare:

1. Téigh chuig **SSL/TLS → Origin Server**
2. Cliceáil **Create Certificate**
3. Coinnigh na réamhshocruithe (15 bliana, \*.yourdomain.com)
4. Cóipeáil an **Origin Certificate** agus an **Private Key**

```bash
mkdir -p /etc/nginx/ssl

# Greamaigh an teastas
nano /etc/nginx/ssl/origin.crt

# Greamaigh an eochair phríobháideach
nano /etc/nginx/ssl/origin.key

chmod 600 /etc/nginx/ssl/origin.key
```

### 3.2 Cumraíocht Nginx

```bash
cat > /etc/nginx/sites-available/omniroute << 'NGINX'
# Freastalaí réamhshocraithe — cuireann sé bac ar rochtain dhíreach trí IP
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    listen 443 ssl default_server;
    listen [::]:443 ssl default_server;
    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    server_name _;
    return 444;
}

# OmniRoute — HTTPS
server {
    listen 443 ssl;
    listen [::]:443 ssl;
    server_name llms.yourdomain.com;  # Athraigh go dtí d'fhearann

    ssl_certificate     /etc/nginx/ssl/origin.crt;
    ssl_certificate_key /etc/nginx/ssl/origin.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    client_max_body_size 100M;

    location / {
        proxy_pass http://127.0.0.1:20128;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Tacaíocht WebSocket
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # SSE (Imeachtaí arna Seoladh ag an bhFreastalaí) — freagraí AI a shruthú
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }
}

# Atreorú HTTP → HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name llms.yourdomain.com;
    return 301 https://$server_name$request_uri;
}
NGINX
```

Coinnigh teorainneacha ama shruth an tseachfhreastalaí droim ar ais ailínithe le hathróga timpeallachta teorann ama OmniRoute. Má ardaíonn tú
`FETCH_TIMEOUT_MS` / `STREAM_IDLE_TIMEOUT_MS`, ardaigh `proxy_read_timeout` / `proxy_send_timeout`
os cionn na tairsí céanna.

Úsáideann OmniRoute `NEXT_PUBLIC_BASE_URL` mar an bhfoinse chanónach atá os comhair an bhrabhsálaí le haghaidh
aisghlaonna OAuth agus nasc poiblí ginte. Úsáideann scríbhinní fíordheimhnithe na deaise iarratais den bhunús céanna
mar aon le cosaint CSRF atá ceangailte leis an seisiún, mar sin ní theastaíonn bun-URL poiblí statach uathu. Is
meiteashonraí ródaithe úsáideacha fós iad na ceanntásca `X-Forwarded-*` thuas, ach ní hionann iad agus an URL poiblí
sainráite a shocrú nuair a bhíonn ceann de dhíth ar OAuth nó ar naisc bhrabhsálaí ghinte. Ná cumasaigh
`OMNIROUTE_TRUST_PROXY` ach amháin mura bhfuil OmniRoute inrochtana go díreach ag cliaint agus má bhaineann do sheachfhreastalaí
na ceanntásca seolta isteach agus má atógann sé iad.

### 3.3 Cumasaigh agus Tástáil

```bash
# Bain an chumraíocht réamhshocraithe
rm -f /etc/nginx/sites-enabled/default

# Cumasaigh OmniRoute
ln -sf /etc/nginx/sites-available/omniroute /etc/nginx/sites-enabled/omniroute

# Tástáil agus athlódáil
nginx -t && systemctl reload nginx
```

## 4. Cumraigh DNS Cloudflare

### 4.1 Cuir taifead DNS leis

I ndeais Cloudflare → DNS:

| Cineál | Ainm   | Ábhar                     | Seachfhreastalaí     |
| ------ | ------ | ------------------------- | -------------------- |
| A      | `llms` | `203.0.113.10` (IP an VM) | ✅ Seachfhreastáilte |

### 4.2 Cumraigh SSL

Faoi **SSL/TLS → Forbhreathnú**:

- Mód: **Iomlán (Docht)**

Faoi **SSL/TLS → Teastais Imeallacha**:

- Úsáid HTTPS i gCónaí: ✅ Ar siúl
- Leagan Íosta TLS: TLS 1.2
- Athscríobh Uathoibríoch HTTPS: ✅ Ar siúl

### 4.3 Tástáil

```bash
curl -sI https://llms.seudominio.com/health
# Ba cheart HTTP/2 200 a fháil mar fhreagra
```

## Optamú le haghaidh Cuimhne Íseal / VPS Beag

Le haghaidh imlonnuithe ar áscanna beaga VPS (1 GB RAM nó níos lú):

- **Díchumasaigh seirbhísí cúlra** — socraigh `OMNIROUTE_DISABLE_BACKGROUND_SERVICES=1` chun an sceidealóir, an freastalaí MCP agus tascanna cothabhála tréimhsiúla a fhágáil ar lár. Féach `docs/reference/ENVIRONMENT.md`.
- **Úsáid mód WAL SQLite** — cumasaithe de réir réamhshocraithe; laghdaíonn sé buaicúsáid cuimhne le linn léamha comhthráthacha.
- **Cuir teorainn leis an gcarn V8** — socraigh `OMNIROUTE_MEMORY_MB` (m.sh. `512`) ionas nach ndéanfaidh an t-am rite uasteorainn níos mó ná an VM a chalabrú. Féach `docs/reference/ENVIRONMENT.md`.
- **Scálaíonn cead isteach trom go huathoibríoch de réir theorainn an chairn** -- a luaithe a shocraítear `OMNIROUTE_MEMORY_MB` thuas, díorthaítear buiséad beart an ionghabhála (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) ón uasteorainn chéanna, mar sin faigheann VM atá srianta ó thaobh cuimhne de buiséad níos lú d’iarratais chomhthráthacha gan aon mhionchoigeartú breise; faigheann iarratais bharrachais freagra `503` ar féidir triail eile a bhaint as, mar aon le `Retry-After`, in ionad dul in iomaíocht le haghaidh cuimhne. Ná socraigh teorainn oidhreachta líon na n-iarratas `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` ach amháin má theastaíonn uasteorainn chrua sa bhreis air sin.
- **Seachain `next build` ar an VPS** — déan an tógáil go háitiúil agus imlonnaigh an t-aschur neamhspleách (`.next/standalone/`).
- **Déan monatóireacht le `top` / `free -m`** — is gnách go n-úsáideann OmniRoute 200-400 MB RSS agus é díomhaoin ar VM 1 GB.
