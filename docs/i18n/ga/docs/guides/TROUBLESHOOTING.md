| ----------------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| "Can't connect"         | Níl OmniRoute ag rith                        | Rith `omniroute` nó `docker restart omniroute`                                                                  |
| "Invalid API key"       | Tá do eochair mícheart nó imithe in éag      | Cóipeáil an eochair arís ó shuíomh gréasáin an tsoláthraí                                                       |
| "Rate limit exceeded"   | Tá tú ag seoladh an iomarca iarratas         | Fan 1 nóiméad, nó úsáid `model: "auto"` le haghaidh aischéimniú uathoibríoch                                    |

### Teorannú Ráta ar Sholáthraithe Saora (429 / 400 / 401)

**Comhartha**: Agus `model: "auto"` á úsáid le soláthraithe saora/gan-údarú (opencode, auggie, srl.), faigheann tú `HTTP 429`, `400`, nó `401` go heatraimseach in ionad freagraí. Éiríonn leis na hiarratais nuair a dhéanann tú iarracht arís an leid chéanna nóiméad ina dhiaidh sin, ach briseann uathoibriú (poist cron, gníomhairí, scripteanna) ar an gcéad teip.

**Fréamhchúis**: Tá trí mhodh teipe neamhspleácha ag carnadh:

1. **Teorannú ráta soláthraí (`429`)**: Is féidir le leibhéil saora cuóta in aghaidh na fuinneoige a fhorfheidhmiú. Ídíonn pléasctha de ghlaonna comhthreomhara é, mar sin diúltaítear don chéad iarratas eile go dtí go n-athshocraíonn an fhuinneog.
2. **Múnla briste i bpas-trí (`400`/`401`)**: Is féidir le linnte `auto/*` múnlaí pas-trí ó `opencode` a áireamh atá cláraithe sa chatalóg ach nach bhfuil dintiúir bheo acu (m.sh. `oc/north-mini-code-free` → `401`). Déanann an ródaire uathoibríoch iarracht ar cheann, teipeann air, agus scaipeann an earráid sula dtosaíonn an aischéimniú.
3. **Aimplithe comhthráthachta (`429` faoi ualach)**: Nuair a bhuaileann seisiúin iolracha gníomhaire/cron `auto` ag an am céanna, sáraíonn an ráta iarratas comhiomlán an méid a fhulaingíonn soláthraithe saora, mar sin marcáiltear glaonna dlisteanacha mar mhí-úsáideacha.

**Réiteach deimhnithe (tuairiscithe ag an bpobal, 2026-08-10)**: tiúnaigh trí athróg timpeallachta ionas go n-ionsúnn rothlú, comhthráthacht, agus aischéimniú an corraíl leibhéal-saor in ionad bás a fháil air:

```bash
export OMNIROUTE_ROTATE_ON_400=true           # hop to another model/provider on 400/401 (skips broken passthrough models)
export OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=4   # explicit heavyweight admission ceiling (unset by default: no request-count cap, see note below)
export OMNIROUTE_CHAT_ADMISSION_QUEUE_MS=5000 # longer bounded wait for heavyweight capacity instead of an immediate retryable 503
```

Socraigh iad seo i dtimpeallacht phróisis OmniRoute (an daemon, m.sh. trí plist LaunchAgent nó `systemctl edit`), ansin atosaigh OmniRoute. Is é an bratach rothlaithe an luamhán is airde-tionchair: déanann sé teip chrua a thiontú ina athiarracht thrédhearcach i gcoinne soláthraí sláintiúil sa linn.

**Nóta**: Cáipéanna `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` cé mhéad iarratas trom-mheáchain — comhthéacs-fhada — a ritheann ag an am céanna; is geata iontrála é an teorainn, ní teorantóir ráta soláthraí. **Nuashonrú #503-fanout:** ní shocraítear an athróg seo a thuilleadh de réir réamhshocraithe (ní cheanglaíonn sé anois ach nuair a chumraítear go sainráite é, mar thuas) — tá iontráil trom-mheáchain gáitéaraithe ina ionad sin ag buiséad beart uath-dhíorthaithe (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) a scálaíonn é féin ó uasteorainn chuimhne fíor an óstaigh, mar sin ba cheart go bhfeicfeadh imscaradh úr i bhfad níos lú diúltaithe `503 chat_admission_busy` gan an athróg seo a shocrú ar chor ar bith; oibríonn é a shocrú go sainráite anseo go díreach mar atá doiciméadaithe. Clampáiltear sáruithe buiséid bheart shainráite go 8 MiB–2 GiB. Níl `413 body_exceeds_budget` neamhsheachantach: méadaigh an buiséad beart sin, ísligh `OMNIROUTE_CHAT_HARD_MAX_BODY_BYTES`, nó méadaigh uasteorainn chuimhne an phróisis. Is brú tráchta sealadach é scaoileadh `inflight_bytes_budget` agus fanann sé in-athiarrachta. Rialaítear an teorannú ráta in aghaidh an tsoláthraí (`open-sse/services/rateLimitManager.ts`) ar leithligh ag `RATE_LIMIT_MAX_WAIT_MS`, `RATE_LIMIT_MAX_QUEUE_DEPTH`, agus `RATE_LIMIT_AUTO_ENABLE` — féach `.env.example`.

**Conas a fhíorú gur oibrigh sé**: rith do ghníomhaire/cron faoi dhó i ndiaidh a chéile agus deimhnigh go n-éiríonn leis an dá cheann. Roimh an réiteach, caitheann an dara rith `429`/`401` de ghnáth. Tar éis an réitigh, déantar teipeanna (más ann) a athiarracht go trédhearcach agus críochnaíonn an glao. Is féidir leat freisin `curl /monitoring/health` a dhéanamh agus féachaint ar an réimse `rateLimitedUntil` ar na naisc soláthraí agus ar `circuitBreakers.providerBreakers[].state` do na soláthraithe lena mbaineann — tá an stát ar cheann de `CLOSED`, `DEGRADED`, `OPEN`, nó `HALF_OPEN` (féach `src/shared/utils/circuitBreaker.ts`), agus casfaidh soláthraí a leanann ag teipeadh `CLOSED → DEGRADED → OPEN` sula ligfidh an fhuinneog athshocraithe trí thástáil (`HALF_OPEN`).

**Má fheiceann tú 429 fós**: tá an _cuóta_ (ní hamháin an ráta) ídithe go fírinneach ag an gcuntas gníomhach don soláthraí sin. Cuir dara cuntas leis don soláthraí céanna i ndeais OmniRoute → Soláthraithe → Cuntais, nó measc isteach soláthraí saor eile (m.sh. `routeway`, `auggie`). Ní chabhraíonn rothlú ach le ráta/400/401 neamhsheachantach; éilíonn ídithe cuóta crua dara dintiúr nó soláthraí difriúil.

**Má fheiceann tú 403 ar mhúnlaí fís (`auto/vision`, `bazaarlink/*`)**: níl plean páite ag an gcuntas ceangailte a chuimsíonn fís, nó níl ceadanna leordhóthanacha ag an eochair API. Fíoraigh i ndeais an tsoláthraí go n-áiríonn scóip na heochrach fís/ilmhódach, nó ceangail cuntas leibhéal páite agus coinnigh é mar sprioc na fís.

## Rabhaidh npm install (ERESOLVE / comhthiomsú / tréigthe)

Nuair a rith tú `npm install -g omniroute`, b'fhéidir gur feicfidh tú balla de rabhaidh cosúil le `npm warn ERESOLVE`, fógraí comhthiomsú, agus teachtaíochtaí `tréigthe`. **Tá siad seo ionchasach agus neamhdhíobhálach.** D'éirigh le do shuiteáil má fheiceann tú `added <N> packages` san aschur.

Tagann na rabhaidh ó raon comhthiomsú seanchaite i bpacáistí tríú páirtí nach mbialann OmniRoute orthu:

1. **`marked-terminal` ag iarraidh `marked >=1 <16`, aimsíodh `marked@18`** — oibríonn sé i ngnáthsheoladh; tá raon comhthiomsú an tsréidribh seanchaite díreach.
2. **`tréigthe prebuild-install@7.1.3`** — cúntóir tarrthála dénártha dúchais idirthurais. Ní úsáidtear é chun ceangal iompar `wreq-js` fheistithe a shuiteáil agus ní thaispeánann sé go raibh teip ar shocrúchán iompar soláthraí fianán gréasáin.

**Gan aon ghnóthú de dhíth** — ní féidir na rabhaidh a chur i bhfolach go hiomlán gan pacáistí an tsréidribh a bhacadh.

## Dearfacha Bréagacha Frithvíreas

<a name="antivirus-false-positives"></a>

### Cuaraintín Avast/AVG ar `README.md` le `MD:HttpRequest-inf[Susp]`

**Is dearfach bréagach é seo. Níl aon rud ionfhabhtaithe, agus ní gá aon ghníomh.**

Ritheann Avast agus AVG heorastúil a mharcálann comhaid gnáth-théacs/Markdown a bhfuil go leor naisc iontu a bhreathnaíonn ar iarratais HTTP. Seoltar `README.md` OmniRoute taobh istigh den phacáiste npm (tá sé liostaithe in `package.json` → `files`), mar sin tagann sé i dtír ag `node_modules/omniroute/README.md` ar shuiteáil dhomhanda — agus tá ~15 sampla `http://localhost:20128/...` ann (na críochphointí MCP HTTP/SSE, URL `.well-known` A2A, agus blúirí `curl`). Tá an dlús naisc sin go leor chun an heorastúil a spreagadh.

Má thosaigh sé seo le déanaí: níor athraigh an comhad ó thaobh cineáil. D'fhás tábla críochphointí an README (cuireadh MCP HTTP + SSE + A2A leis) agus níos mó samplaí `curl`, rud a bhrúigh thar an tairseach é.

Is doiciméadacht neamhghníomhach é an comhad gan aon inneachar inrite. Is féidir leat é a chur ar ais ón gcuaraintín go sábháilte.

**Cad atá le déanamh:**

1. **Stop na fógraí** — eisiaigh an t-eolaire suiteála i do fhrithvíreas (Avast: Socruithe → Eisceachtaí), ag cur do chonair dhomhanda `node_modules` agus/nó eolaire sonraí OmniRoute (`~/.omniroute/`) leis.
2. **Tuairiscigh an dearfach bréagach** — <https://www.avast.com/false-positive-file-form.php>, ag ceangal an `README.md` cuaraintín. Is é seo an réiteach a chabhraíonn le gach duine, ós rud é go bhfuil heorastúil an díoltóra ag ró-imoibriú le comhad téacs.

**Cén fáth nach ndéanaimid "dearadh" air seo ar ár dtaobh:** tá na samplaí go léir `http://localhost`, agus ní féidir le localhost a bheith `https` gan frithchuimilt deimhnithe féin-shínithe. Chuirfeadh sé isteach ar gach léitheoir na doiciméid a shaobhadh chun heorastúil díoltóra amháin a sheachaint chun fabht scanóra a shásamh.

### Kaspersky ag marcáil an aip Deisce mar `PDM:Trojan.Win32.Generic`

**Is dearfach bréagach é seo ó heorastúil iompraíochta. Níl aon rud ionfhabhtaithe.** Ciallaíonn réimír `PDM:` Kaspersky go dtagann an breithiúnas óna Mhodúl Cosanta Réamhghníomhach (System Watcher), a mheasann cad a dhéanann an suiteálaí _i ndáiríre_ seachas é a mheaitseáil i gcoinne malware aitheanta. Nuair a scaoileann sé, "rollann" Kaspersky ar ais an tsuiteáil iomlán — ag scriosadh comhaid a scríobh sé cheana — mar sin críochnaíonn an aip briste nó ar iarraidh.

Is iad na comhaid a mharcálann sé ná codanna caighdeánacha de spleáchais fhoinse oscailte dhearbhaithe atá pacáilte leis an aip deisce, mar shampla:

- `resources/app/.build/next/node_modules/playwright-<hash>/lib/…/agentParser.js` agus `workerProcessEntry.js` — [Playwright](https://playwright.dev), an leabharlann uathoibrithe brabhsálaí a úsáidtear le haghaidh logáil isteach soláthraí in-app agus comhrá le tacaíocht bhrabhsálaí.
- `resources/app/.build/next/node_modules/@wreq-js/binding-win32-<arch>-msvc-<hash>/wreq-js.win32-<arch>-msvc.node` — an ceangal dúchais `wreq-js` socraithe a úsáidtear le haghaidh HTTP le méarlorg brabhsálaí ar sholáthraithe fianán gréasáin (`<arch>` ná `x64` nó `arm64`).

**Cén fáth a scaoileann sé:** níl an suiteálaí Windows **sínithe le cód fós**, mar sin níl aon chlú ag suiteálaí NSIS neamhshínithe agus ritheann heorastúil iompraíochta ag an ionsaí uasta. Le DLL dúchais pacáilte agus na céadta comhad `.js` scríofa faoi `%LOCALAPPDATA%\Programs\OmniRoute` (lena n-áirítear eolairí pacáiste le hiarmhír hash ó thógáil neamhspleách Next.js), is leor sin chun an heorastúil a spreagadh. Tá síniú cód beartaithe; go dtí go dtiocfaidh sé, is féidir le heisiúintí nua é seo a athdhéanamh.

**Cad atá le déanamh:**

1. **Deimhnigh d'íoslódáil ar dtús** (cuireann sé comhad a ndearnadh cur isteach air as an áireamh). Foilsíonn gach eisiúint `latest.yml`, a bhfuil a réimse `sha512` (base64) ag clúdach an suiteálaí `OmniRoute.Setup.<version>.exe`. I PowerShell, ón bhfillteán ina bhfuil an suiteálaí:
   ```powershell
   $b = [System.Security.Cryptography.SHA512]::Create().ComputeHash(
     [System.IO.File]::ReadAllBytes("$PWD\OmniRoute.Setup.<version>.exe"))
   [Convert]::ToBase64String($b)
   ```
   Caithfidh an t-aschur a bheith ag teacht le `latest.yml` → `sha512`. Mura bhfuil, scrios an comhad agus íoslódáil arís ach amháin ó [leathanach eisiúintí GitHub](https://github.com/diegosouzapw/OmniRoute/releases).
2. **Cuir ar ais + eisiaigh** — cuir na míreanna rollta ar ais ón gcuaraintín agus cuir eisceacht le haghaidh `%LOCALAPPDATA%\Programs\OmniRoute` (Kaspersky → Socruithe → Bagairtí agus Eisceachtaí), ansin athshuiteáil.
3. **Tuairiscigh an dearfach bréagach** — <https://opentip.kaspersky.com/>. Luathaíonn tuairiscí FP ó úsáideoirí an liostú ceadaithe i ndáiríre.

## Comhoiriúnacht Node.js

<a name="nodejs-compatibility"></a>

### Tuairteálann an leathanach logáil isteach nó taispeánann sé earráid "Module self-registration"

**Cúis:** Tá leagan Node.js á rith agat atá lasmuigh d'íosleibhéal rithim slán ceadaithe OmniRoute. Is é an cás is coitianta ná leagan paiste níos sine de Node 22 nó 24 a bheith á rith agat atá faoi bhun an íosleibhéil slándála paisteáilte a éilíonn OmniRoute.

**Comharthaí:**

- Taispeánann an leathanach logáil isteach scáileán bán nó earráid freastalaí
- Taispeánann an consól `Error: Module did not self-register` nó earráidí ceangail dúchais comhchosúla
- Taispeánann an leathanach logáil isteach **meirge rabhaidh oráiste** le do leagan Node má tá an rithim lasmuigh den bheartas slán tacaithe

**Réiteach:**

1. Suiteáil eisiúint LTS Node.js tacaithe (molta: Node.js 24.x):
   ```bash
   nvm install 24
   nvm use 24
   ```
2. Deimhnigh do leagan: ba cheart go dtaispeánfadh `node --version` `v24.0.0` nó níos nuaí ar líne LTS 24.x
3. Athshuiteáil OmniRoute: `npm install -g omniroute`
4. Atosaigh: `omniroute`

> **Leaganacha slána tacaithe:** `>=22.22.2 <23` nó `>=24.0.0 <27`. Tacaítear go hiomlán le Node.js 24.x LTS (Krypton) agus Node.js 26.

### npm v11+: `better-sqlite3` gan suiteáil (Cannot find module)

<a name="npm-v11-better-sqlite3-not-installed-cannot-find-module"></a>

**Cúis:** Cuireann npm v11 (a sheoltar le Node.js 24+) bac ar scripteanna suiteála le haghaidh spleáchais roghnacha de réir réamhshocraithe. Ós rud é go bhfuil `better-sqlite3` liostaithe in `optionalDependencies` agus go dteastaíonn tiomsú dúchais uaidh (`node-gyp rebuild`), scipeálann npm é go ciúin.

**Comharthaí:**

- Tuairteálann an freastalaí ag tosú le `Cannot find module 'better-sqlite3'`
- Taispeánann `ls node_modules/better-sqlite3` "No such file or directory"
- Taispeánann `npm ls better-sqlite3` `(empty)`

**Réiteach:**

1. Ceadaigh na scripteanna suiteála agus athshuiteáil:
   ```bash
   npm approve-scripts better-sqlite3
   npm install
   ```
2. Nó suiteáil an réamhthógtha de láimh:
   ```bash
   npm pack better-sqlite3@13.0.1
   tar -xzf better-sqlite3-*.tgz -C node_modules
   mv node_modules/package node_modules/better-sqlite3
   rm better-sqlite3-*.tgz
   ```
3. Deimhnigh go n-oibríonn sé: `node -e "require('better-sqlite3')(':memory:').close(); console.log('OK')"`

### macOS: `dlopen` / "slice is not valid mach-o file"

<a name="macos-native-module-rebuild"></a>

**Cúis:** Tar éis `npm install -g omniroute` domhanda, seans go raibh an dénártha dúchais `better-sqlite3` laistigh den phacáiste tiomsaithe d'ailtireacht nó ABI Node.js éagsúil ón gceann atá á rith go háitiúil. Tá sé seo coitianta ar macOS (Apple Silicon agus Intel araon) nuair nach ionann an dénártha réamhthógtha agus do thimpeallacht.

**Comharthaí:**

- Teipeann ar an bhfreastalaí láithreach ag tosú le hearráid `dlopen`
- Tá `slice is not valid mach-o file` san earráid
- Sampla iomlán:

```
dlopen(/Users/<user>/.nvm/versions/node/v24.14.1/lib/node_modules/omniroute/app/node_modules/better-sqlite3/build/Release/better_sqlite3.node, 0x0001): tried: '...' (slice is not valid mach-o file)
```

**Réiteach — atógáil do do thimpeallacht áitiúil (ní gá Node.js a íosghrádú):**

```bash
cd $(npm root -g)/omniroute/app
npm rebuild better-sqlite3
omniroute
```

> **Nóta:** Déanann sé seo an ceangal dúchais a aththiomsú i gcoinne do leagan Node.js áitiúil agus ailtireacht LAP, ag réiteach an neamhréir dénártha. Is é an raon rithim tacaithe go hoifigiúil **`>=22.22.2 <23` nó `>=24.0.0 <27`** (`SUPPORTED_NODE_RANGE` in `src/shared/utils/nodeRuntimeSupport.ts`, ailínithe le réimse `engines` an `package.json`). Tacaítear go hiomlán le Node.js 24.x LTS (Krypton) agus Node.js 26 le `better-sqlite3` v12.x.

## Saincheisteanna seachadthoraidh

<a name="proxy-issues"></a>

### Léiríonn bailíochtú soláthraithe "theip ar fheidhmiú"

**Cúis:** Bhí deireadh pointe bailíochtaithe API key (`POST /api/providers/validate`) ag cur timpeall cumraíochta seachadthoraidh roimhe seo, rud a d'earraigh teipeanna i dtimpeallachtaí a dteastaíonn feidhmiú seachadthoraidh uathu.

**Socair (v3.5.5+):** Tá sé seo socraithe anois. Téann bailíochtú soláthraithe trí `runWithProxyContext`, ag ómóid shocruithe seachadthoraidh ag leibhéal an tsoláthraí agus go domhanda go huathoibríoch.

### Teipeann seiceáil shláinte toicín le "theip ar fheidhmiú"

**Cúis:** Ní raibh athnuadh token OAuth cúlra ag réiteach cumraíochta seachadthoraidh in aghaidh an cheangail.

**Socair (v3.5.5+):** Réitíonn an planda seiceáil shláinte toicín anois cumraíocht seachadthoraidh in aghaidh an cheangail sula ndéanann sé iarracht athnuadh. Uasghrádaigh go v3.5.5+.

### Filleann seachadthoraidh SOCKS5 "modh onRequestStart neamhbhailí"

**Cúis:** Ar Node.js 22, tá an dispatcher undici@8 mí-ailíneach le cur i bhfeidhm `fetch()` ionsuite Node.

**Socair (v3.5.5+):** Úsáideann OmniRoute anois feidhm `fetch()` féin undici nuair a bhíonn dispatcher seachadthoraidh gníomhach, rud a chinntíonn iompar comhsheasmhach. Uasghrádaigh go v3.5.5+.

### Seachadthoraidh MITM faoi WSL: ní bhreithnightear aipeanna deisce ar an óstach Windows

**Cúis:** suiteáiltear seachadthoraidh MITM agus a deimhniú CA san timpeallacht a bhfuil OmniRoute ag rith ann. Faoi WSL is é an timpeallacht sin an trealamh Linux, ach rith na aip deisce AI (Kiro, Trae, Copilot, Zed, …) ar an óstach Windows. Ní chreideann aipeanna an óstach stóras deimhniúcháin an trealaimh agus ní dhéanann siad feidhmiú trí phríomhshreanga seachadthoraidh an trealaimh, mar sin ní ghníomhachtaíonn cur isteach deisce ansin.

**Moladh:** Rith OmniRoute go dúchasach ar an gcóras oibriúcháin chéanna le haghaidh na n-aip deisce is mian leat a ghabháil (Windows le haghaidh aip Windows; macOS/Linux araon). Má choimeádann tú OmniRoute laistigh de WSL agus díriú ar aip an óstagh, is gá deimhniú CA ginte a chur ar iontaoibh go lámhleabhar ar an óstach Windows agus suíomhanna líonra/seachadthoraidh gach aip óstagh a shocrú ag an chríochphointe seachadthoraidh WSL – socruithe gan tacaíocht,脆弱a.

## Saincheisteanna Docker

### Docker IPv6 / Athshocrú Ceangail

<a name="docker-ipv6"></a>

**Comharthaí:** Filleann `curl http://localhost:20128/v1/models` `curl: (56) Recv failure: Connection reset by peer`. Oibríonn an stiúrthóir agus na críochphointí neamhfhordhmhlaithe, ach teipeann na cinn fordhmhlaithe — is cosúil gur fadhb údarúcháin é ach níl.

**Cúis:** Folaíonn `docker run -p 20128:20128` ar `0.0.0.0` (IPv4) agus `::` (IPv6), ach éistann an próiseas laistigh den choimeádán le IPv4 amháin. Ar óstáin ina n-orlannann `localhost` ar `::1` ar dtús, luann an ceangal port IPv6 foilsithe gan éisteacht taobh thiar de → athshocrú ceangail.

**Ceartú:**

1. **Diagnóis tapa:** Rith `curl -4 http://localhost:20128/v1/models`. Má oibríonn sé le `-4` ach teipeann gan é, tá míshocrú ceangail IPv6 agat.
2. **Ceartú buan:** Ceangail le IPv4 go sainráite trí `-p 127.0.0.1:20128:20128` a úsáid i d'ordú `docker run`:
   ```bash
   docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
     -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest
   ```
   Éascaíonn sé seo ceangal IPv4 agus seachain é a nochtadh ar gach comhéadan óstach freisin.

| **Binse Tástála**   | Rith tástálacha baisce thar chomhcheangail fhormáide chun a fháil amach cé na haistriúcháin atá briste                          |
| **Monatóir Beo**    | Féach ar shreabhadh iarratais i bhfíor-am chun fadhbanna aistriúcháin eatramhacha a ghabháil                                    |

### Fadhbanna formáide coitianta

- **Clibeanna smaointeoireachta gan a bheith le feiceáil** — Seiceáil an dtacaíonn an soláthraí sprioc le smaointeoireacht agus le socrú bhuiséad na smaointeoireachta
- **Glaonna uirlisí ag titim amach** — D'fhéadfadh roinnt aistriúchán formáide réimsí neamhthacaithe a bhaint; fíoraigh i mód Clós Súgartha
- **Leid chórais in easnamh** — Láimhseálann Claude agus Gemini leideanna córais ar bhealach difriúil; seiceáil aschur an aistriúcháin
- **Filleann an SDK teaghrán amh in ionad réad** — Réitithe i v1.x; baineann an sláintitheoir freagartha réimsí neamhchaighdeánacha (`x_groq`, `usage_breakdown`, etc.) a chruthaíonn teipeanna bailíochtaithe Pydantic SDK OpenAI. Má fheiceann tú é seo fós ar v3.x+, comhdaigh ceist le do thoil.
- **Diúltaíonn GLM/ERNIE do ról `system`** — Réitithe i v1.x; comhtháthaíonn an normalóir róil teachtaireachtaí córais le teachtaireachtaí úsáideora go huathoibríoch do mhúnlaí neamh-chomhoiriúnacha. Má fheiceann tú é seo fós ar v3.x+, comhdaigh ceist le do thoil.
- **Ní aithnítear ról `developer`** — Réitithe i v1.x; tiontaítear go huathoibríoch go `system` do sholáthraithe neamh-OpenAI. Má fheiceann tú é seo fós ar v3.x+, comhdaigh ceist le do thoil.
- **Ní oibríonn `json_schema` le Gemini** — Réitithe i v1.x; tiontaítear `response_format` anois go `responseMimeType` + `responseSchema` Gemini. Má fheiceann tú é seo fós ar v3.x+, comhdaigh ceist le do thoil.

## Socruithe Athléirthineachta

### Ní ghníomhaíonn rátáil-uathoibríoch

- Ní bhaineann rátáil-uathoibríoch ach le soláthraithe eochracha API (ní OAuth/leannáin)
- Cinntigh go bhfuil **Socruithe → Athléirthineacht → Próifílí Soláthraithe** cumasaithe le haghaidh rátáil-uathoibríoch
- Seiceáil an dteastaíonn stádas-cód `429` nó ceannteidil `Retry-After` ón soláthraí

### Coigeartú moill ardú eispidéimeach

Tacaíonn próifílí soláthraí leis na socruithe seo:

- **Bun-mhoill** — Am feithimh tosaigh tar éis an chéad theipmh (réamhshocrú: 1s)
- **Uas-mhoill** — Huasteorainn ama feithimh (réamhshocrú: 30s)
- **Iolrachóir** — Méid ardaithe na moille in aghaidh gach theipmh as a chéile (réamhshocrú: 2x)

### Cosaint i gcoinne torann tanú

Nuair a théann iarrataí iomadúla comhthráthacha i dteagmháil le soláthraí a bhfuil rátáil-fhormhaisiú air, úsáideann OmniRoute mutex + rátáil-uathoibríoch chun iarrataí a shreangú agus teipeanna liathróide a chosc. Tá sé seo uathoibríoch do sholáthraithe eochracha API.

### Teipeann iarrataí comhrá le 503 / chat_admission_busy

**Comharthaí aitheantais:**

- Filleann críochfort chríochnúcháin comhrá freagra `503` in-in-athrá ina bhfuil an cód earráide
  `chat_admission_busy`.
- Áirítear sa fhreagra `Retry-After`. Ó #112135, tá an luach díorthaithe ón áitiúlacht a bhreathnaítear — is é an níos mó é de fhuinneog `OMNIROUTE_CHAT_ADMISSION_QUEUE_MS` a bhfuil an t-iarratas curtha ag feitheamh ann cheana féin agus an t-am a bhfuil na cúnantacha meáchainmhara reatha coinnte — cruinnithe suas go dtí soicindí iomlána agus teoranta ag 60. Ar ghléas díghníomhach, coinníonn sé na híosanna stairiúla: 2 shoicind ar an gcosán bunaithe ar bhíteanna, 1 soicind ar an gcosán bunaithe ar struchtúr (a áiríonn freisin `reason: "structure_limit"`).
- Is féidir seo tarlú nuair a bheidh comhrá eile meáchainmhara nó freagra srutha fadtéarmach fós ag eitilt.

Is é corp an fhreagra bunaithe ar bhíteanna:

```json
{
  "error": {
    "message": "Tá acmhainn iontrála comhrá ar fáil go sealadach. Déan iarracht arís go luath.",
    "type": "server_error",
    "code": "chat_admission_busy"
  }
}
```

Úsáideann an freagra bunaithe ar struchtúr an cineál agus an cód céanna, leis an teachtaireacht
`Tá acmhainn iontrála comhrá áitiúil gafa le haghaidh an iarratais seo a bhfuil ualach struchtúrach air; ní rinneadh iarracht ródú chuig an soláthraí bhun. Déan iarracht arís go luath.`
agus `reason: "structure_limit"`.
Ag na socruithe réamhshocraithe, is é iarratas a bhfuil ualach struchtúrach air nuair a bhfuil
ar a laghad `200` teachtaireacht, ar a laghad `64` uirlis, nó ar a laghad `32,000` comhartha
meastaithe, nó nuair a éiríonn le meastachán struchtúr theoranta a theorainn de `10,000`
nód cuairte nó domhainne `12`.

**Cúis:** Is é seo seilg ualach dhéanmhasach laistigh de OmniRoute, nach teip soláthraí-bhun é. Úsáid gach próiseálaí garda próiseála-áitiúil chun cumas meáchainmhara teoranta a chur in áirithe roimh choirp iarratais mhóra a choinneáil agus a pharsáil. Coinnítear cúnanta meáchainmhara ar feadh saoil freagra SSE.

**#503-fanout:** roimh an gceartú seo, rinne an garda teorainn le comhthráthacht ag líon sOCRAITHE iarrataí seasta (`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`, réamhshocrú `1`) beag beann ar chuimhne an óstach, mar sin thit amach folaúcháin gníomhairí-códála (fo-iarratasóirí/CLIanna iolracha, corp níos mó ná 256 KB de ghnáth) go comhthráthacht éifeachtach ~1 agus thug siad 503 faoi ualach go hiomlán gnáth. Tá an garda an-tógtha anois: tá sé faoi ghlas ag buiséad ionghabhála BYTE uathordaithe (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) a bhfuil méid aige ó uasteorainn cuimhne fíor an phróiseálaí, agus fiafraíonn sé freisin ó shíniú brú acmhainne beo — mar sin ní sheilgeann sé ach nuair a bhfuil an t-ostach i ndáiríre faoi bhrú cuimhne, ní hamháin toisc go dteachtann níos mó ná iarratas amháin meáchainmhara ag an am céanna. Glactar fós leis an sean-teorainn líon (`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`), ach amháin má shocrann tú go sainráite é.

Nuair a bhíonn cumas gafa, fanann iarratas meáchainmhara ar feadh suas go dtí
`OMNIROUTE_CHAT_ADMISSION_QUEUE_MS` (réamhshocrú `2000`, `0` dhíghníomhaíonn an fanacht) le haghaidh sliotán a shaoradh
sula bhfreagraíonn sé an `503` in-athrá. Tá an fanacht teoranta ann ionas go sreangóidh cliant-stíl
gníomhaire (OpenCode, Claude Code, Cursor) a dhéanann iniúchadh ar fo-iarrataí meáchainmhara comhthráthacha
tuileadh in ionad a mbuiséad athrá iomlán a loiscfidh ar diúltúcháin láithreach agus a bhásfaidh i lár tasc. Tá
áitiúlacht cúnanta meáchainmhara reatha, buiséad biteanna réitithe, agus déine brú beo le feiceáil ag
`GET /api/monitoring/health` → `chatAdmission` (`inflightBytes`, `maxInflightBytes`,
`budgetSource`, `pressureSeverity`, `countCapEnabled`) — seiceáil iad seo sula mbuailfidh tú aon athróg timpeallachta.
Ní rialaíonn Socruithe → Athléirthineacht → Líne Iarrataí → Iarrataí Comhthráthacha an ceann seo; rialaíonn an socruithe sin
meicníocht líne iarrataí soláthraí ar leith.

**Ceartú:**

1. Athrá ar dtús. Ba cheart do chliaint cloí le `Retry-After` agus moill ardaithe a úsáid in ionad an t-iarratas a dhéanamh arís go láithreach.
2. Seiceáil `/api/monitoring/health` → `chatAdmission` sula gcuireann tú ar aon rud in eagar. Léiríonn `countCapEnabled: false` agus `maxInflightBytes` flaithiúil go bhfuil an buiséad uathordaithe ag déanamh a chuid oibre cheana féin; léiríonn `pressureSeverity` de `high`/`critical` go bhfuil an t-ostach i ndáiríre íseal ar chuimhne — ní féidir é sin a shocrú le hathróg iontrála, teastaíonn RAM níos mó nó ualach oibre níos lú uaidh.
3. Ach amháin más léir ó `/api/monitoring/health` go bhfuil an buiséad uathordaithe ró-bheag do d'ósthach (annamh — scálaíonn sé cheana féin ó coimeádán go miotal nocht), déan é a shárú go díreach le `OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES` in ionad dul ar ais go dtí an sean-teorainn líon iarrataí.

Féach ar an [tagairt athróg timpeallachta](../reference/ENVIRONMENT.md#4-security--authentication)
le haghaidh na socruithe iontrála údarásacha.

## Roghnach RAG / LLM teip aicme (16 fhadhbanna)

Cuirtear an geata i bhfroimhthaíochtaí roinnt úsáideoirí OmniRoute os cionn fruilíní RAG nó gníomhairí. Sna suíomhanna sin, is iondúil go bhfeictear patrún aisteach: Breathnaíonn OmniRoute sláintiúil (soláthraithe ar bun, próifíliú routála go maith, gan aon aláraim ráta teorann), ach tá an freagra deiridh fós mícheart.

I bhformhór na n-ionsaithe seo, tagann siad as an tsráidbhreiseán RAG síos, ní as an geata féin.

Más mian leat comhchaint choiteann a bhaineann leis na teipeanna seo a úsáid, is féidir leat Mapa Fhadhbanna WFGY a úsáid, acmhainn téacs ceadúnais MIT seachtrach a shainíonn sé déag patternaí teip RAG / LLM atá ag teacht ar ais. Ar leibhéal ard, clúdaíonn sé:

- drámaíocht aisghníomhach agus teorainneacha comhthéacs briste
- innéacsanna nó stórais veicteor folamh nó sean
- easnamh idir leabú agus comhchiall
- fadhbonnálaíocht puist agus saincheisteanna fuinneoga comhthéacs
- teip loigic agus freagraí róchinnte
- teip comhordaithe gníomhaire agus slabhra fada
- drámaíocht cuimhne agus ról gníomhairí iolrach
- fadhbanna ordúcháin suiteála agus tosaithe

Is simplí an smaoineamh:

1. Nuair a imscrúdaíonn tú freagra droch, cuimsigh:
   - tasc agus iarratas an úsáideora
   - comhcheangal ródú nó soláthraí in OmniRoute
   - aon chomhthéacs RAG úsáidte síos (doiciméid aisghníomhach, glaonna uirlisí, srl.)
2. Cuir an eachtra i leith uimhir amháin nó dhó de Mapa Fhadhbanna WFGY (`No.1` … `No.16`).
3. Stóráil an uimhir i do chlár riaracháin féin, leabhar rith, nó rianaire eachtraí in aice le logchomhaid OmniRoute.
4. Úsáid leathanach WFGY comhfhreagrach chun a chinneadh an gá duit do chruach RAG, aisghníomhairí, nó straitéis ródú a athrú.

Tá an téacs iomlán agus na blastáin chruinne anseo (ceadúnas MIT, téacs amháin):

[README Mapa Fhadhbanna WFGY](https://github.com/onestardao/WFGY/blob/main/main/ProblemMap/README.md)

Is féidir leat an rannán seo neamhurramú a dhéanamh mura n-oibríonn tú fruilíní RAG nó gníomhairí taobh thiar de OmniRoute.

## v3.8.0 Easnamh Sainiúil

Easnamh sainiúil don scaoileadh v3.8.0 agus na réitigh reatha atá acu. Má shroichann leigheas in alt eile, déanfar an iontráil a nuashonrú nó a bhaint.

### Teipeanna auth le CLI Devin

**Symptoms:**

- "Devin CLI gan aimsiú" nó "auth theip" agus uirlisí a bhfuil tacaíocht acu le Devin á n-athbhreithniú
- Deir seiceáil rith CLI `installed=false`

**Causes:**

- Taispeánann `CLI_DEVIN_BIN` cosán nach bhfuil ann
- Níl an CLI Devin suiteáilte ar an óstach

**Fix:**

1. Suiteáil an CLI Devin do do ardán
2. Socraigh `CLI_DEVIN_BIN=/usr/local/bin/devin` (nó an cosán fíor) i `.env`
3. Atosaigh OmniRoute agus aththástáil ó **Dashboard → CLI Tools**

### Model cooldown stuck (athshocrú láimhe)

**Symptoms:**

- Tá samhaltún liostaithe sa fhuarú fiú tar éis an t-am dul in éag a bheith rite
- Déanann iarratais fós an samhaltún a scipeáil sa chomhcheangal ródú cé go bhfuil an stampa ama san am atá thart

**Athshocrú láimhe:**

- **Dashboard:** **Settings → Model Cooldowns** → cliceáil **Re-enable** ar an gchártha buailte
- **API:** `DELETE /api/resilience/model-cooldowns` le ceannteidil údaraithe bainistíochta

### Teipeann ceangal soláthraí Command Code le 403

**Symptoms:**

- 403 agus ceangal soláthraí Command Code á thástáil
- Taispeánann cártha an tseoltóra "gan údarú" tar éis cuirfidh úr

**Cause:** Níor chríochnaigh an sruth OAuth (nár glacadh le comhfhreagras nó nár stóráladh an teochomhartha).

**Fix:**

- Rith `omniroute providers` ón CLI chun an sruth OAuth a ath-thionscail, nó
- Ath-rith OAuth ó **Dashboard → Providers → Command Code → Reconnect**

### Athfhilleadh 429 ionsaitheach ó ModelScope

**Symptoms:**

- Fuarúcháin an-ghearr nó láithreach ar ModelScope tar éis béilín beag iarrataí
- Scipeálann comhcheangal ródú ModelScope níos luaithe ná mar a bhíothas ag súil leis

**Cause:** Seolann ModelScope ceannteidil `Retry-After` ar leith don tseoltóir. Tá láimhseáil speisialta ag v3.8.0 do na ceannteidil sin, mar sin léigh na leaganacha níos sine iad mar leideanna teorann ráta ginearálta.

**Fix:**

- Bí ag v3.8.0 nó níos déanaí
- Deimhnigh go bhfuil an t-aistriúchán `useUpstream429BreakerHints” cumasaithe faoi **Settings → Resilience**

### OMNIROUTE_WS_BRIDGE_SECRET in easnamh i dtáirgeadh

**Symptoms:**

- 401 ar gach iarratas droichead WebSocket Codex/Responses agus iad ag rith ar óstach táirgeadh cianda
- Dúnann seoideáil an droichead WebSocket díreach i ndiaidh ceangal

**Cause:** Tá an athróg timpeallachta `OMNIROUTE_WS_BRIDGE_SECRET` in easnamh ón timpeallacht táirgeadh.

**Fix:**

1. Glac rún randamach: `openssl rand -hex 32`
2. Socraigh `OMNIROUTE_WS_BRIDGE_SECRET=<rún-randamach>` sa timpeallacht freastalaí táirgeadh (agus aon chliaint a labhraíonn leis an droichead)
3. Atosaigh OmniRoute

### API Freagraí: mód cúltaca laghdaithe go synchronous

**Symptoms:**

- Logáilte Rabhadh: `background mode degraded to synchronous`
- Freagra synchronous normala in ionad seilf oibre cúltaca a thabhairt ar iarratas `background: true`

**Cause:** Laghdaíonn v3.80 go díreach `background: true` ar an API Freagraí go rith synchronous agus rabhadh á sheoladh. Is í seachadadh sa todhchaí é rith cúltaca async iomlán.

**Fix:**

- Coigeartigh an cliant gan `background` a ghairm, nó
- Fan le scaoileadh níos déanaí a sheolann mód cúltaca async iomlán (rian an changelog)
