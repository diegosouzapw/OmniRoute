## Fabhtcheartú Mionsonraithe

### Teorannú Ráta ar Sholáthraithe Saor in Aisce (429 / 400 / 401)

**Siomptóm**: Agus `model: "auto"` á úsáid agat le soláthraithe saor in aisce/gan fíordheimhniú (opencode, auggie, srl.), faigheann tú `HTTP 429`, `400`, nó `401` ó am go chéile in ionad freagraí. Éiríonn leis na hiarratais nuair a bhaintear triail eile as an leid chéanna cúpla nóiméad ina dhiaidh sin, ach teipeann ar uathoibriú (jabanna cron, gníomhairí, scripteanna) ar an gcéad teip.

**Bunchúis**: Tagann trí mhodh teipe neamhspleácha le chéile:

1. **Teorainn ráta an tsoláthraí (`429`)**: Féadfaidh sraitheanna saor in aisce cuóta in aghaidh na fuinneoige a chur i bhfeidhm. Ídíonn ráig glaonna comhthreomhara é, agus mar sin diúltaítear don chéad iarratas eile go dtí go n-athshocraítear an fhuinneog.
2. **Samhail bhriste sa chur ar aghaidh (`400`/`401`)**: Féadfaidh samhlacha curtha ar aghaidh ó `opencode` a bheith i linnte `auto/*`, ar samhlacha iad atá cláraithe sa chatalóg ach nach bhfuil dintiúir bheo acu (m.sh. `oc/north-mini-code-free` → `401`). Baineann an t-uathródaire triail as ceann amháin, teipeann air, agus iomadaítear an earráid sula dtosaíonn an cúltaca.
3. **Aimpliú comhthráthachta (`429` faoi ualach)**: Nuair a úsáideann roinnt seisiún gníomhaire/cron `auto` ag an am céanna, sáraíonn ráta comhiomlán na n-iarratas an méid is féidir le soláthraithe saor in aisce a fhulaingt, agus dá bhrí sin marcáiltear glaonna dlisteanacha mar mhí-úsáid.

**Réiteach deimhnithe (tuairiscithe ag an bpobal, 2026-08-10)**: coigeartaigh trí athróg timpeallachta ionas go maolóidh rothlú, comhthráthacht agus cúltaca luaineacht na sraithe saor in aisce seachas teip dá barr:

```bash
export OMNIROUTE_ROTATE_ON_400=true           # léim chuig samhail/soláthraí eile ar 400/401 (scipeálann sé samhlacha briste curtha ar aghaidh)
export OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=4   # uasteorainn iontrála shainráite d’iarratais throma (gan socrú de réir réamhshocraithe: níl teorainn ar líon na n-iarratas, féach an nóta thíos)
export OMNIROUTE_CHAT_ADMISSION_QUEUE_MS=5000 # fanacht teoranta níos faide ar acmhainn d’iarratais throma in ionad 503 in-atriallach láithreach
```

Socraigh iad seo i dtimpeallacht phróiseas OmniRoute (an deamhan, m.sh. tríd an LaunchAgent plist nó `systemctl edit`), agus ansin atosaigh OmniRoute. Is í bratach an rothlaithe an luamhán aonair is éifeachtaí: athraíonn sí teip chrua ina hatriail thrédhearcach le soláthraí sláintiúil sa linn.

**Nóta**: Cuireann `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` teorainn le líon na n-iarratas trom — comhthéacs fada — a ritheann ag an am céanna; geata iontrála is ea an teorainn, ní teorantóir ráta soláthraí. **Nuashonrú #503-fanout:** ní shocraítear an athróg seo de réir réamhshocraithe a thuilleadh (ní bhíonn sí ceangailte anois ach nuair a chumraítear go sainráite í, mar atá thuas) — ina ionad sin, déantar iontráil iarratas trom a rialú le buiséad beart a dhíorthaítear go huathoibríoch (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) agus a scálaíonn é féin ó fhíortheorainn chuimhne an óstaigh, agus mar sin ba cheart go mbeadh i bhfad níos lú diúltuithe `503 chat_admission_busy` le feiceáil in imscaradh úr gan an athróg seo a shocrú ar chor ar bith; má shocraítear go sainráite anseo í, oibríonn sí go díreach mar atá doiciméadaithe. Cuirtear teorainn 8 MiB–2 GiB ar sháruithe sainráite bhuiséad na mbeart. Ní riocht sealadach é `413 body_exceeds_budget`: méadaigh an buiséad beart sin, ísligh `OMNIROUTE_CHAT_HARD_MAX_BODY_BYTES`, nó méadaigh teorainn chuimhne an phróisis. Is achrann sealadach é díluchtú `inflight_bytes_budget` agus is féidir triail eile a bhaint as fós. Déantar teorannú ráta in aghaidh an tsoláthraí (`open-sse/services/rateLimitManager.ts`) a rialú ar leithligh le `RATE_LIMIT_MAX_WAIT_MS`, `RATE_LIMIT_MAX_QUEUE_DEPTH`, agus `RATE_LIMIT_AUTO_ENABLE` — féach `.env.example`.

**Conas a dheimhniú gur oibrigh sé**: rith d’oibreán/cron faoi dhó go gairid i ndiaidh a chéile agus deimhnigh go n-éiríonn leis an dá rith. Roimh an gceartúchán, is gnách go gcaitheann an dara rith `429`/`401`. Tar éis an cheartúcháin, baintear atriail as teipeanna (más ann dóibh) go trédhearcach agus cuirtear an glao i gcrích. Is féidir leat `curl /monitoring/health` a úsáid freisin agus súil a choinneáil ar an réimse `rateLimitedUntil` ar na naisc soláthraí agus ar `circuitBreakers.providerBreakers[].state` do na soláthraithe lena mbaineann — is é ceann de `CLOSED`, `DEGRADED`, `OPEN`, nó `HALF_OPEN` an staid (féach `src/shared/utils/circuitBreaker.ts`), agus athróidh soláthraí a leanann de bheith ag teip ó `CLOSED → DEGRADED → OPEN` sula gceadaíonn an fhuinneog athshocraithe do thóraíocht dul tríd (`HALF_OPEN`).

**Má fheiceann tú 429 fós**: tá a _chuóta_ ídithe i ndáiríre ag an gcuntas gníomhach don soláthraí sin (ní hé an ráta amháin atá i gceist). Cuir dara cuntas leis don soláthraí céanna i ndeais OmniRoute → Soláthraithe → Cuntais, nó cuir soláthraí saor in aisce eile san áireamh (m.sh. `routeway`, `auggie`). Ní chuidíonn an rothlú ach le ráta/400/401 sealadach; má tá an cuóta ídithe go hiomlán, teastaíonn an dara dintiúr nó soláthraí eile.

**Má fheiceann tú 403 ar shamhlacha amhairc (`auto/vision`, `bazaarlink/*`)**: níl plean íoctha lena n-áirítear fís ag an gcuntas nasctha, nó níl dóthain ceadanna ag an eochair API. Deimhnigh i ndeais an tsoláthraí go n-áirítear fís/ilmhódúlacht i scóip na heochrach, nó nasc cuntas ar shraith íoctha agus coinnigh é mar sprioc na físe.

## Rabhaidh npm install (ERESOLVE / piara / dímholta)

Nuair a ritheann tú `npm install -g omniroute`, seans go bhfeicfidh tú lear mór rabhadh amhail `npm warn ERESOLVE`, fógraí faoi spleáchais phiara, agus teachtaireachtaí `deprecated`. **Tá siad seo ionchasach agus neamhdhíobhálach.** D’éirigh le do shuiteáil má fheiceann tú `added <N> packages` san aschur.

Chun na rabhaidh maidir le réiteach spleáchas piara a cheilt, úsáid an fhoirm suiteála a dtacaíonn OmniRoute léi:

```bash
npm install -g omniroute --legacy-peer-deps
```

Ní cheileann `--legacy-peer-deps` ach `ERESOLVE` agus fógraí faoi spleáchais phiara. Fanann fógraí dímholtachta infheicthe toisc go dtagann siad ó phacáistí trasdulta tríú páirtí; ní thugann siad le fios gur theip ar an tsuiteáil.

Tagann na rabhaidh ó raonta spleáchas piara atá as dáta i bpacáistí tríú páirtí nach bhfuil faoi rialú OmniRoute:

1. **Teastaíonn `marked >=1 <16` ó `marked-terminal`, ach aimsíodh `marked@18`** — oibríonn sé go breá go praiticiúil; níl ach an raon piara réamhtheachtach as dáta.
2. **`deprecated prebuild-install@7.1.3`** — uirlis chúnta thrasdultach chun dénártha dúchasacha a fháil. Ní úsáidtear í
   chun an ceangal iompair `wreq-js` pionnáilte a shuiteáil agus ní thugann sí le fios gur theip ar
   shocrú iompair an tsoláthraí fianán gréasáin.

**Ní gá aon ghníomh a dhéanamh** — ní féidir na rabhaidh a cheilt go hiomlán gan pacáistí réamhtheachtacha a fhorcáil.

## Gemini Web agus Playwright Chromium

Má fhilleann iarratas Gemini Web `503` le teachtaireacht nach bhfuil Playwright Chromium
suiteáilte, tá an pacáiste npm i láthair ach tá dénártha an bhrabhsálaí ar iarraidh.
Coinníonn Playwright íoslódálacha brabhsálaí scartha ó shuiteáil an phacáiste npm
d’aon ghnó, mar sin táthar ag súil leis an bhfreagra seo go dtí go suiteálfar an brabhsálaí.

I gcás suiteáil dhomhanda npm, suiteáil Chromium ó chomhadlann phacáiste
OmniRoute ionas go mbaineann taisce an bhrabhsálaí leis an tsuiteáil chéanna Playwright:

```bash
cd "$(npm root -g)/omniroute"
npx playwright install chromium
```

Atosaigh OmniRoute tar éis na suiteála, ansin bain triail eile as an iarratas Gemini Web. Má
ritheann tú OmniRoute ó íomhá Docker, úsáid an íomhá `-web` (nó an sprioc tógála `runner-web`),
ina bhfuil Chromium agus a spleáchais cuachta; níl siad san íomhá bhunúsach.

## Bréagdheimhneachtaí Frithvíreas

<a name="antivirus-false-positives"></a>

### Cuireann Avast/AVG `README.md` ar coraintín le `MD:HttpRequest-inf[Susp]`

**Is bréagdheimhneacht é seo. Níl aon rud ionfhabhtaithe, agus ní gá aon ghníomh a dhéanamh.**

Ritheann Avast agus AVG heorastúil a mharcálann comhaid ghnáth-théacs/Markdown ina bhfuil go leor
nasc a bhfuil cuma iarrataí HTTP orthu. Seoltar `README.md` OmniRoute laistigh den phacáiste npm (tá sé
liostaithe in `package.json` → `files`), mar sin cuirtear ag `node_modules/omniroute/README.md` é le linn
suiteáil dhomhanda — agus tá thart ar 15 shampla `http://localhost:20128/...` ann (críochphointí
HTTP/SSE MCP, URL `.well-known` A2A, agus sleachta `curl`). Is leor dlús na nasc sin chun an
heorastúil a spreagadh.

Murar thosaigh sé seo ach le déanaí: níor athraigh cineál an chomhaid. Cuireadh tuilleadh le tábla
críochphointí an README (cuireadh MCP HTTP + SSE + A2A leis) agus cuireadh tuilleadh samplaí `curl`
leis, rud a bhrúigh thar an tairseach é.

Doiciméadacht támh atá sa chomhad agus níl aon ábhar inrite ann. Is féidir leat é a athchóiriú
ón gcoraintín go sábháilte.

**Cad atá le déanamh:**

1. **Stop na fógraí** — fág an t-eolaire suiteála as áireamh i do fhrithvíreas
   (Avast: Socruithe → Eisceachtaí), agus cuir cosán domhanda `node_modules` agus/nó
   eolaire sonraí OmniRoute (`~/.omniroute/`) leis.
2. **Tuairiscigh an bhréagdheimhneacht** — <https://www.avast.com/false-positive-file-form.php>,
   agus ceangail an `README.md` atá ar coraintín. Seo é an réiteach a chuidíonn le gach duine, ós é
   heorastúil an díoltóra atá ag rófhreagairt do chomhad téacs.

**Cén fáth nach ndéanaimid é seo a “dheisiú” ar ár dtaobh féin:** is `http://localhost` iad na samplaí
go léir, agus ní féidir le localhost a bheith ina `https` gan castacht a bhaineann le teastais
fhéinshínithe. Dhéanfadh saobhadh na ndoiciméad chun heorastúil díoltóra amháin a sheachaint dochar
do gach léitheoir chun fabht scanóra a shásamh.

### Marcálann Kaspersky an aip Deisce mar `PDM:Trojan.Win32.Generic`

**Is bréagdheimhneacht ó heorastúil iompraíochta é seo. Níl aon rud ionfhabhtaithe.** Ciallaíonn
réimír `PDM:` Kaspersky gur óna Mhodúl Cosanta Réamhghníomhaí (Monatóir Córais) a thagann an breithiúnas,
modúl a dhéanann breithiúnas ar an méid a _dhéanann_ an suiteálaí seachas é a mheaitseáil le bogearraí
mailíseacha aitheanta. Nuair a spreagtar é, déanann Kaspersky an tsuiteáil iomlán a “rolladh siar” —
ag scriosadh comhad a bhí scríofa aige cheana — agus dá bhrí sin bíonn an aip briste nó ar iarraidh.

Is gnáthchodanna de spleáchais dhearbhaithe foinse oscailte iad na comhaid a mharcálann sé, agus iad
cuachta leis an aip deisce, mar shampla:

- `resources/app/.build/next/node_modules/playwright-<hash>/lib/…/agentParser.js` agus
  `workerProcessEntry.js` — [Playwright](https://playwright.dev), an leabharlann uathoibrithe brabhsálaí
  a úsáidtear le haghaidh logáil isteach i soláthraithe laistigh den aip agus comhrá le tacaíocht
  brabhsálaí.
- `resources/app/.build/next/node_modules/@wreq-js/binding-win32-<arch>-msvc-<hash>/wreq-js.win32-<arch>-msvc.node`
  — an ceangal dúchasach pionáilte `wreq-js` a úsáidtear le haghaidh HTTP le méarlorg brabhsálaí ar
  sholáthraithe fianán gréasáin (`<arch>` ná `x64` nó `arm64`).

**Cén fáth a spreagtar é:** níl an suiteálaí Windows **sínithe le cód fós**, mar sin níl aon
cháil ar shuiteálaí NSIS gan síniú agus ritheann heorastúla iompraíochta ar an leibhéal ionsaitheachta
is airde. In éineacht le DLL dúchasach cuachta agus na céadta comhad `.js` a scríobhtar faoi
`%LOCALAPPDATA%\Programs\OmniRoute` (lena n-áirítear eolairí pacáiste le hiarmhíreanna hais ón
leagan neamhspleách Next.js), is leor sin chun an heorastúil a spreagadh. Tá síniú cóid beartaithe;
go dtí go gcuirfear i bhfeidhm é, d’fhéadfadh sé seo tarlú arís le heisiúintí nua.

**Cad atá le déanamh:**

1. **Fíoraigh d’íoslódáil ar dtús** (cuireann sé seo comhad ar baineadh dó as an áireamh). Foilsítear
   `latest.yml` le gach eisiúint, agus clúdaíonn a réimse `sha512` (base64) an suiteálaí
   `OmniRoute.Setup.<version>.exe`. In PowerShell, ón bhfillteán ina bhfuil an suiteálaí:
   ```powershell
   $b = [System.Security.Cryptography.SHA512]::Create().ComputeHash(
     [System.IO.File]::ReadAllBytes("$PWD\OmniRoute.Setup.<version>.exe"))
   [Convert]::ToBase64String($b)
   ```
   Caithfidh an t-aschur a bheith mar an gcéanna le `latest.yml` → `sha512`. Mura bhfuil, scrios an comhad agus
   íoslódáil arís é ó [leathanach eisiúintí GitHub](https://github.com/diegosouzapw/OmniRoute/releases) amháin.
2. **Athchóirigh + fág as áireamh** — athchóirigh na míreanna a rolladh siar ón gcoraintín agus cuir
   eisceacht le haghaidh `%LOCALAPPDATA%\Programs\OmniRoute` leis (Kaspersky → Socruithe → Bagairtí agus Eisceachtaí),
   ansin athshuiteáil.
3. **Tuairiscigh an bhréagdheimhneacht** — <https://opentip.kaspersky.com/>. Cuireann tuairiscí FP
   ó úsáideoirí dlús dáiríre le cur ar an liosta ceadaithe.

## Comhoiriúnacht Node.js

<a name="nodejs-compatibility"></a>

### Tuairteálann an leathanach logála isteach nó taispeánann sé an earráid "Module self-registration"

**Cúis:** Tá leagan de Node.js á rith agat atá lasmuigh d’íosleibhéal slán ceadaithe OmniRoute. Is é an cás is coitianta ná leibhéal paiste níos sine de Node 22 nó 24 a rith atá faoi bhun an íosleibhéil slándála paisteáilte a éilíonn OmniRoute.

**Comharthaí:**

- Taispeánann an leathanach logála isteach scáileán bán nó earráid fhreastalaí
- Taispeánann an consól `Error: Module did not self-register` nó earráidí comhchosúla maidir le nascadh dúchasach
- Taispeánann an leathanach logála isteach **meirge rabhaidh oráiste** le do leagan de Node má tá an t-am rite lasmuigh den pholasaí slán a dtacaítear leis

**Réiteach:**

1. Suiteáil eisiúint LTS de Node.js a dtacaítear léi (molta: Node.js 24.x):
   ```bash
   nvm install 24
   nvm use 24
   ```
2. Deimhnigh do leagan: ba cheart do `node --version` `v24.0.0` nó leagan níos nuaí ar líne LTS 24.x a thaispeáint
3. Athshuiteáil OmniRoute: `npm install -g omniroute`
4. Atosaigh: `omniroute`

> **Leaganacha slána a dtacaítear leo:** `>=22.22.2 <23` nó `>=24.0.0 <27`. Tugtar tacaíocht iomlán do Node.js 24.x LTS (Krypton) agus Node.js 26.

### npm v11+: níl `better-sqlite3` suiteáilte (Ní féidir an modúl a aimsiú)

<a name="npm-v11-better-sqlite3-not-installed-cannot-find-module"></a>

**Cúis:** Cuireann npm v11 (a chuirtear ar fáil le Node.js 24+) bac de réir réamhshocraithe ar scripteanna suiteála do spleáchais
roghnacha. Ós rud é go bhfuil `better-sqlite3` liostaithe in `optionalDependencies`
agus go dteastaíonn tiomsú dúchasach (`node-gyp rebuild`) uaidh, scipeálann npm é gan fógra.

**Comharthaí:**

- Tuairteálann an freastalaí ag am tosaithe le `Cannot find module 'better-sqlite3'`
- Taispeánann `ls node_modules/better-sqlite3` "Níl a leithéid de chomhad nó comhadlann ann"
- Taispeánann `npm ls better-sqlite3` `(folamh)`

**Réiteach:**

1. Ceadaigh na scripteanna suiteála agus athshuiteáil:
   ```bash
   npm approve-scripts better-sqlite3
   npm install
   ```
2. Nó suiteáil an leagan réamhthógtha de láimh:
   ```bash
   npm pack better-sqlite3@13.0.1
   tar -xzf better-sqlite3-*.tgz -C node_modules
   mv node_modules/package node_modules/better-sqlite3
   rm better-sqlite3-*.tgz
   ```
3. Deimhnigh go n-oibríonn sé: `node -e "require('better-sqlite3')(':memory:').close(); console.log('OK')"`

### macOS: `dlopen` / "slice is not valid mach-o file"

<a name="macos-native-module-rebuild"></a>

**Cúis:** Tar éis `npm install -g omniroute` domhanda, d’fhéadfadh sé gur tiomsaíodh dénártha dúchasach `better-sqlite3` laistigh den phacáiste le haghaidh ailtireachta nó ABI Node.js eile seachas an ceann atá á rith go háitiúil. Tarlaíonn sé seo go minic ar macOS (ar Apple Silicon agus Intel araon) nuair nach bhfuil an dénártha réamhthógtha comhoiriúnach le do thimpeallacht.

**Comharthaí:**

- Teipeann ar an bhfreastalaí láithreach ag am tosaithe le hearráid `dlopen`
- Tá `slice is not valid mach-o file` san earráid
- Sampla iomlán:

```
dlopen(/Users/<user>/.nvm/versions/node/v24.14.1/lib/node_modules/omniroute/app/node_modules/better-sqlite3/build/Release/better_sqlite3.node, 0x0001): tried: '...' (slice is not valid mach-o file)
```

**Réiteach — atóg do do thimpeallacht áitiúil (ní gá íosghrádú Node.js a dhéanamh):**

```bash
cd $(npm root -g)/omniroute/app
npm rebuild better-sqlite3
omniroute
```

> **Nóta:** Aththiomsaíonn sé seo an nasc dúchasach i gcoinne do leagain áitiúil de Node.js agus d’ailtireacht LAP, rud a réitíonn an neamh-chomhoiriúnacht dhénártha. Is é **`>=22.22.2 <23` nó `>=24.0.0 <27`** an raon ama rite a dtacaítear leis go hoifigiúil (`SUPPORTED_NODE_RANGE` in `src/shared/utils/nodeRuntimeSupport.ts`, ailínithe leis an réimse `engines` in `package.json`). Tugtar tacaíocht iomlán do Node.js 24.x LTS (Krypton) agus Node.js 26 le `better-sqlite3` v12.x.

## Fadhbanna Seachfhreastalaí

<a name="proxy-issues"></a>

### Taispeánann bailíochtú an tsoláthraí "fetch failed"

**Cúis:** Roimhe seo, bhí críochphointe bailíochtaithe na heochrach API (`POST /api/providers/validate`) ag seachaint chumraíocht an tseachfhreastalaí, rud a bhí ina chúis le teipeanna i dtimpeallachtaí a éilíonn ródú trí sheachfhreastalaí.

**Réiteach (v3.5.5+):** Tá sé seo réitithe anois. Déantar iarratais bhailíochtaithe soláthraí a ródú trí `runWithProxyContext`, agus tugtar aird go huathoibríoch ar shocruithe seachfhreastalaí ar leibhéal an tsoláthraí agus ar na socruithe domhanda.

### Teipeann ar sheiceáil sláinte an chomhartha le "fetch failed"

**Cúis:** Ní raibh athnuachan cúlra chomharthaí OAuth ag réiteach chumraíocht an tseachfhreastalaí de réir ceangail.

**Réiteach (v3.5.5+):** Réitíonn sceidealóir seiceáil sláinte na gcomharthaí cumraíocht an tseachfhreastalaí de réir ceangail anois sula ndéanann sé iarracht athnuachan. Nuashonraigh go v3.5.5+.

### Tugann seachfhreastalaí SOCKS5 "invalid onRequestStart method" ar ais

**Cúis:** Ar Node.js 22, níl seoltóir undici@8 comhoiriúnach le cur chun feidhme ionsuite `fetch()` de chuid Node.

**Réiteach (v3.5.5+):** Úsáideann OmniRoute feidhm `fetch()` de chuid undici féin anois nuair a bhíonn seoltóir seachfhreastalaí gníomhach, rud a chinntíonn iompar comhsheasmhach. Nuashonraigh go v3.5.5+.

### Seachfhreastalaí MITM faoi WSL: ní idircheapann sé aipeanna deisce ar an óstríomhaire Windows

**Cúis:** Suiteáiltear an seachfhreastalaí MITM agus a theastas CA sa timpeallacht ina ritheann OmniRoute. Faoi WSL is é aoi Linux an timpeallacht sin, agus ritheann na haipeanna deisce AI (Kiro, Trae, Copilot, Zed, …) ar an óstríomhaire Windows. Níl muinín ag aipeanna an óstríomhaire as stór teastas an aoi agus ní ródálann siad trí sheachfhreastalaí córais an aoi, mar sin ní chuirtear idircheapadh deisce i bhfeidhm ansin.

**Moladh:** Rith OmniRoute go dúchasach ar an gcóras oibriúcháin céanna leis na haipeanna deisce is mian leat a idircheapadh (Windows d’aipeanna Windows; mar an gcéanna do macOS/Linux). Má choinnítear OmniRoute laistigh de WSL agus má dhírítear ar aipeanna an óstríomhaire, ní mór muinín a chur de láimh sa teastas CA ginte ar an óstríomhaire Windows agus socruithe líonra/seachfhreastalaí gach aip óstríomhaire a dhíriú ar chríochphointe seachfhreastalaí WSL — socrú leochaileach nach dtacaítear leis.

## Fadhbanna Scamaill

### Earráidí Sioncronaithe Scamaill

1. Deimhnigh go bhfuil `BASE_URL` dírithe ar an ásc atá á rith agat (m.sh., `http://localhost:20128`)
2. Deimhnigh go bhfuil `CLOUD_URL` dírithe ar do chríochphointe scamaill (m.sh., `https://omniroute.dev`)
3. Coinnigh luachanna `NEXT_PUBLIC_*` ailínithe leis na luachanna ar thaobh an fhreastalaí

### Tugann `stream=false` sa Scamall 500 ar Ais

**Siomptóm:** `Unexpected token 'd'...` ar an gcríochphointe scamaill do ghlaonna neamhshruthaithe.

**Cúis:** Tugann an tseirbhís réamhtheachtach pálasta SSE ar ais agus an cliant ag súil le JSON.

**Réiteach sealadach:** Úsáid `stream=true` le haghaidh glaonna díreacha scamaill. Tá cúltaca SSE→JSON san áireamh san am rite áitiúil.

### Deir an Scamall go bhfuil sé Ceangailte ach Faightear "Invalid API key"

1. Cruthaigh eochair nua ón deais áitiúil (`/api/keys`)
2. Rith sioncronú scamaill: Cumasaigh an Scamall → Sioncronaigh Anois
3. Is féidir le sean-eochracha nó eochracha neamhshioncronaithe `401` a thabhairt ar ais sa scamall fós

## Fadhbanna Docker

### Docker IPv6 / Athshocrú Ceangail

<a name="docker-ipv6"></a>

**Siomptóim:** Tugann `curl http://localhost:20128/v1/models` `curl: (56) Recv failure: Connection reset by peer` ar ais. Oibríonn an deais agus na críochphointí gan fíordheimhniú, ach teipeann ar chríochphointí fíordheimhnithe — is cosúil gur fadhb fíordheimhnithe atá ann, ach ní hea.

**Cúis:** Foilsíonn `docker run -p 20128:20128` ar `0.0.0.0` (IPv4) agus `::` (IPv6) araon, ach ní éisteann an próiseas laistigh den choimeádán ach ar IPv4. Ar óstaigh ina réitítear `localhost` go `::1` ar dtús, sroicheann an ceangal an port foilsithe IPv6 gan aon éisteoir taobh thiar de → athshocraítear an ceangal.

**Ceartúchán:**

1. **Diagnóis thapa:** Rith `curl -4 http://localhost:20128/v1/models`. Má oibríonn sé le `-4` ach má theipeann air gan é, tá neamhréir cheangailteach IPv6 agat.
2. **Ceartúchán buan:** Ceangail le IPv4 go sainráite trí `-p 127.0.0.1:20128:20128` a úsáid i d'ordú `docker run`:
   ```bash
   docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
     -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest
   ```
   Cuireann sé seo an ceangal IPv4 i bhfeidhm agus seachnaíonn sé freisin an seachfhreastalaí a nochtadh ar chomhéadain uile an óstaigh.

### Deir Uirlis CLI Nach bhfuil Sí Suiteáilte

1. Seiceáil réimsí an ama rite: `curl http://localhost:20128/api/cli-tools/runtime/codex | jq`

### Teipeann ar iarratais chomhrá le 503 / chat_admission_busy

**Comharthaí:**

- Filleann críochphointe na gcomhlánuithe comhrá freagra `503` ar féidir triail eile a bhaint as agus is é
  `chat_admission_busy` a chód earráide.
- Áirítear `Retry-After` sa fhreagra. Ó #12135 i leith, díorthaítear an luach ón áitíocht bhreathnaithe —
  an luach is mó idir an fhuinneog `OMNIROUTE_CHAT_ADMISSION_QUEUE_MS` ar fhan an t-iarratas léi cheana
  agus an tréimhse a raibh na léasanna tromualaithe reatha á sealbhú — slánaithe suas go soicindí iomlána
  agus teorannaithe ag 60. Ar gheata díomhaoin, coinnítear na híosluachanna stairiúla: 2 shoicind ar an
  gconair bheartbhunaithe, 1 soicind ar an gconair struchtúrbhunaithe (ina n-áirítear freisin
  `reason: "structure_limit"`).
- Féadfaidh sé seo tarlú agus comhrá tromualaithe eile nó freagra sruthaithe fadtréimhseach fós
  ar siúl.

Seo é corp an fhreagra bheartbhunaithe:

```json
{
  "error": {
    "message": "Chat admission capacity is temporarily unavailable. Retry shortly.",
    "type": "server_error",
    "code": "chat_admission_busy"
  }
}
```

Úsáideann an freagra struchtúrbhunaithe an cineál agus an cód céanna, leis an teachtaireacht
`Local chat admission capacity is busy for this structurally heavy request; upstream provider routing was not attempted. Retry shortly.`
agus `reason: "structure_limit"`.
Ag na tairseacha réamhshocraithe, meastar iarratas a bheith trom ó thaobh struchtúir de nuair a bhíonn `200` teachtaireacht ar a laghad ann,
`64` uirlis ar a laghad, nó `32,000` comhartha measta ar a laghad, nó nuair a ídíonn meastachán struchtúir teoranta
a theorainneacha de `10,000` nód ar tugadh cuairt orthu nó doimhneacht `12`.

**Cúis:** Is díluchtú ualaigh d'aon ghnó é seo laistigh de OmniRoute, ní teip ó sholáthraí réamhtheachtach.
Úsáideann gach próiseas garda áitiúil don phróiseas chun acmhainn theoranta tromualaigh a chur in áirithe sula gcoinnítear
agus sula bparsáiltear corp mór iarratais. Coinnítear léas tromualaithe ar feadh shaolré freagra SSE.

**#503-fanout:** roimh an socrú seo, chuir an garda teorainn leis an gcomhthráthacht ag COMHAIREAMH seasta iarratas
(`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`, réamhshocrú `1`) beag beann ar chuimhne an óstaigh, agus mar sin thit
scaip-amach gníomhairí códúcháin (ilfho-ghníomhairí/CLIanna, coirp níos mó ná 256 KB go rialta) go dtí
comhthráthacht éifeachtach de ~1 agus fuarthas 503anna faoi ghnáthualach amach is amach. Déanann an garda
féinchoigeartú anois: rialaítear é le buiséad BEART ionghabhála uathdhíorthaithe (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`)
a mhéadaítear de réir fhíoruasteorainn chuimhne an phróisis, agus téann sé i gcomhairle freisin le comhartha beo
brú acmhainní — mar sin ní dhíluchtaíonn sé ach amháin nuair atá an t-óstach faoi fhíorbhrú cuimhne, seachas
díreach toisc gur tháinig níos mó ná iarratas trom amháin ag an am céanna. Urramaítear an tseanteorainn chomhairimh
(`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`) fós, ach amháin má shocraíonn tú go sainráite í.

Nuair atá an acmhainn gnóthach, fanann iarratas tromualaithe ar feadh suas le
`OMNIROUTE_CHAT_ADMISSION_QUEUE_MS` (réamhshocrú `2000`, díchumasaíonn `0` an fanacht) ar dtús go dtí go scaoiltear sliotán
sula dtugtar an freagra `503` ar féidir triail eile a bhaint as. Tá an fanacht teoranta ann ionas go srathaíonn cliaint ar nós gníomhairí
(OpenCode, Claude Code, Cursor), a scaipeann fo-iarratais throma go comhthráthach, an borradh
seachas a mbuiséad iomlán atrialacha a ídiú ar dhiúltuithe láithreacha agus teip leath bealaigh tríd an tasc.
Taispeántar áitíocht reatha na léasanna tromualaithe, an buiséad beart réitithe, agus déine bheo an bhrú
ag `GET /api/monitoring/health` → `chatAdmission` (`inflightBytes`, `maxInflightBytes`,
`budgetSource`, `pressureSeverity`, `countCapEnabled`) — seiceáil iad seo sula n-athraíonn tú aon athróg timpeallachta.
Ní rialaíonn Socruithe → Athléimneacht → Ciú Iarratas → Iarratais Chomhthráthacha é seo; rialaíonn an socrú sin
meicníocht ar leith do chiú iarratas an tsoláthraí.

**Réiteach:**

1. Bain triail eile as ar dtús. Ba cheart do chliaint `Retry-After` a urramú agus cúlú a úsáid seachas
   an t-iarratas a athdhéanamh láithreach.
2. Seiceáil `/api/monitoring/health` → `chatAdmission` sula ndéanann tú aon mhionchoigeartú. Ciallaíonn `countCapEnabled:
false` agus `maxInflightBytes` flaithiúil go bhfuil an buiséad uathdhíorthaithe ag déanamh a
   chuid oibre cheana féin; ciallaíonn `pressureSeverity` de `high`/`critical` go bhfuil an t-óstach fíoríseal ar chuimhne —
   ní féidir é sin a réiteach le hathróg timpeallachta iontrála; teastaíonn tuilleadh RAM nó ualach oibre níos lú.
3. Ach amháin má léiríonn `/api/monitoring/health` go bhfuil an buiséad uathdhíorthaithe róbheag i ndáiríre do
   d'óstach (rud annamh — méadaítear é cheana féin ó choimeádán go miotal lom), sáraigh go díreach é le
   `OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES` seachas filleadh ar an tseanteorainn comhairimh iarratas.

Féach ar an [tagairt d'athróga timpeallachta](../reference/ENVIRONMENT.md#4-security--authentication)
chun na socruithe údarásacha iontrála a fháil.

## Tacsanomaíocht roghnach teipeanna RAG / LLM (16 fhadhb)

Cuireann roinnt úsáideoirí OmniRoute an geata os comhair stoic RAG nó stoic gníomhairí. Sna cumraíochtaí sin is coitianta patrún aisteach a fheiceáil: is cosúil go bhfuil OmniRoute sláintiúil (soláthraithe ar fáil, próifílí ródúcháin i gceart, gan aon fholáirimh teorann ráta) ach bíonn an freagra deiridh mícheart fós.

Go praiticiúil, is gnách gur ón bpíblíne RAG iartheachtach a thagann na teagmhais seo, seachas ón ngeata féin.

Más mian leat stór focal comhroinnte chun cur síos a dhéanamh ar na teipeanna sin, is féidir leat WFGY ProblemMap a úsáid, acmhainn téacs sheachtrach faoi cheadúnas MIT a shainíonn sé phatrún déag athfhillteacha teipe RAG / LLM. Ar leibhéal ard, clúdaíonn sé:

- seachrán aisghabhála agus teorainneacha comhthéacs briste
- innéacsanna agus stórtha veicteoirí atá folamh nó as dáta
- neamhréir idir leabú agus séimeantaic
- fadhbanna le tiomsú leid agus le fuinneog an chomhthéacs
- cliseadh loighce agus freagraí rómhuiníneacha
- teipeanna i slabhraí fada agus i gcomhordú gníomhairí
- seachrán cuimhne agus róil i gcórais ilghníomhairí
- fadhbanna le hordú imlonnaithe agus tosaithe

Tá an smaoineamh simplí:

1. Nuair a imscrúdaíonn tú drochfhreagra, gabh:
   - tasc agus iarratas an úsáideora
   - an teaglaim bealaigh nó soláthraithe in OmniRoute
   - aon chomhthéacs RAG a úsáideadh iartheachtach (doiciméid aisghafa, glaonna uirlisí, etc)
2. Mapáil an teagmhas chuig uimhir nó dhó in WFGY ProblemMap (`No.1` … `No.16`).
3. Stóráil an uimhir i do dheais, i do lámhleabhar oibríochta, nó i do rianaire teagmhas féin in aice le logaí OmniRoute.
4. Úsáid an leathanach comhfhreagrach WFGY chun a chinneadh an gá duit do stoc RAG, d’aisghabhálaí, nó do straitéis ródúcháin a athrú.

Tá an téacs iomlán agus oidis nithiúla ar fáil anseo (ceadúnas MIT, téacs amháin):

[README WFGY ProblemMap](https://github.com/onestardao/WFGY/blob/main/ProblemMap/README.md)

Is féidir leat neamhaird a dhéanamh den rannán seo mura ritheann tú píblínte RAG nó píblínte gníomhairí taobh thiar de OmniRoute.

**Cúis:** Astaíonn ModelScope ceanntásca `Retry-After` a bhaineann go sonrach leis an soláthraí. Tagann v3.8.0 le láimhseáil thiomnaithe do na ceanntásca sin, agus mar sin léann leaganacha níos sine go mícheart iad mar leideanna cineálacha teorann ráta.

### OMNIROUTE_WS_BRIDGE_SECRET ar iarraidh i dtáirgeadh

**Comharthaí:**

- 401 ar gach iarratas droichid WebSocket Codex/Responses agus é á rith ar óstríomhaire cianda táirgeachta
- Dúnann cumarsáid tosaigh dhroichead WebSocket díreach tar éis ceangail

**Cúis:** Tá an athróg timpeallachta `OMNIROUTE_WS_BRIDGE_SECRET` ar iarraidh ón timpeallacht táirgeachta.

**Réiteach:**

1. Gin rún randamach: `openssl rand -hex 32`
2. Socraigh `OMNIROUTE_WS_BRIDGE_SECRET=<random-secret>` i dtimpeallacht an fhreastalaí táirgeachta (agus in aon chliant a dhéanann cumarsáid leis an droichead)
3. Atosaigh OmniRoute

### Responses API: mód cúlra íslithe go mód sioncronach

**Comharthaí:**

- Logáiltear rabhadh: `background mode degraded to synchronous`
- Tugann iarratas `background: true` gnáthfhreagra sioncronach ar ais in ionad hanla taisc chúlra

**Cúis:** In v3.8.0, íslítear `background: true` d’aon ghnó ar Responses API go cur i gcrích sioncronach agus rabhadh á astú ag an am céanna. Is sprioc insoláthartha amach anseo é cur i gcrích cúlra iomlán asincrónach.

**Réiteach:**

- Coigeartaigh an cliant chun glao a dhéanamh gan `background`, nó
- Fan le heisiúint níos déanaí ina mbeidh mód cúlra iomlán asincrónach ar fáil (rian é sa loga athruithe)

## Tosú Mall / Teorainn Ama Ullmhachta

Má phriontálann an CLI `⚠ Server did not respond within 60s` ach go bhfuil an freastalaí
ag obair i ndáiríre, tá buiséad an tóireadóra ullmhachta róghairid do do thimpeallacht.

Tarlaíonn sé seo go coitianta ar Windows (frithvíreas, faireoirí córas comhad) nó i gcoimeádáin
a bhfuil ualaí troma oibre acu le linn tosaithe.

**Réiteach — méadaigh an buiséad:**

```bash
# Trí athróg timpeallachta (fanann sé i bhfeidhm idir tosuithe):
export OMNIROUTE_READY_TIMEOUT_MS=180000   # 3 nóiméad
omniroute serve

# Trí bhratach CLI (aonuaire):
omniroute serve --ready-timeout 180000
```

Is é 60 000 ms (60 s) an réamhshocrú. Is chun críche faisnéise amháin atá an rabhadh; leanann an freastalaí
air ag tosú sa chúlra agus beidh sé inrochtana nuair a bheidh an tosú curtha i gcrích.

Féach ar [`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md) chun sonraí iomlána a fháil
faoi `OMNIROUTE_READY_TIMEOUT_MS`.
