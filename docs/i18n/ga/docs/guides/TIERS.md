Eagraíonn OmniRoute na 352 soláthraí a dtacaítear leo i 3 shraith eacnamaíocha. Téann gach
iarratas tríothu in ord go dtí go n-éiríonn le ceann acu — faigheann tú
an freagra inmharthana is saoire gan cód cúltaca a scríobh riamh.

## Sraith 1 — Síntiús

**Soláthraithe a n-íocann tú astu cheana féin.** Úsáideann OmniRoute gach braon den chuóta sula
dtéann sé in éag.

| Soláthraí                      | Cén fáth a bhfuil sé i Sraith 1                               |
| ------------------------------ | ------------------------------------------------------------- |
| Claude Code OAuth              | Anthropic Pro/Team — ráta comhréidh, gan úsáid go minic       |
| OpenAI Codex (síntiús ChatGPT) | Cuimsíonn Plus/Team cuóta Codex                               |
| GitHub Copilot                 | In aghaidh an tsuíocháin — athshocraítear an cuóta go míosúil |
| Cursor IDE                     | Cuóta an phlean Pro                                           |
| Antigravity / Devin Desktop    | Cuótaí ionsuite                                               |

**Straitéis**: treoraigh anseo ar dtús gach iarratas a oireann do
láidreachtaí na samhla. Déanann rianaire an chuóta monatóireacht ar athshocruithe atá ag
teannadh, agus tugann an straitéis teaglama `reset-aware` tosaíocht dá réir. Chun Sraith 1 a úsáid ar dtús agus gan dul
amach chuig sraitheanna íoctha ach amháin de réir mar a ídítear an cuóta, úsáid an t-aitheantas `auto/thrifty` — nó `auto/subscription`
chun fanacht laistigh den acmhainn atá san áireamh sa phlean agus teip i mód dúnta ina ionad sin. Féach
[Routing a thugann tús áite do shíntiúis](../routing/SUBSCRIPTION_LADDER.md).

## Sraith 2 — Saor

**Soláthraithe íoctha in aghaidh an chomhartha faoi bhun $1/1M comhartha.** Curtha in áirithe d'obair ardtoirte
nó tar éis do chuótaí Shraith 1 a dteorainneacha a bhaint amach.

| Soláthraí                                 | Praghas (ionchur/aschur)    | Láidreachtaí              |
| ----------------------------------------- | --------------------------- | ------------------------- |
| DeepSeek V4 Pro                           | $0.27 / $1.10 in aghaidh 1M | Cód, réasúnaíocht         |
| GLM-4.5                                   | $0.60 / $2.20 in aghaidh 1M | Comhthéacs fada           |
| MiniMax M1                                | $0.20 / $1.10 in aghaidh 1M | Luas                      |
| Qwen Coder                                | $0.30 / $1.20 in aghaidh 1M | Cód                       |
| OpenRouter (optamaithe ó thaobh praghais) | athraíonn                   | 100+ samhail, dinimiciúil |

**Straitéis**: roghnaíonn teaglama `cost-optimized` an tsamhail leis an $/comhartha is ísle a chomhlíonann
scagaire cumais an taisc (fís, mód JSON, uirlisí, comhthéacs uasta).

## Sraith 3 — Saor in aisce

**Soláthraithe gan chostas** — sraitheanna saor in aisce, cláir chreidmheasa, cuótaí laethúla OAuth.

| Soláthraí        | Cuóta saor in aisce / creidmheasanna                  |
| ---------------- | ----------------------------------------------------- |
| Kiro AI          | Sraith Claude saor in aisce (úsáid chóir fhlaithiúil) |
| OpenCode Free    | Gan fíordheimhniú, teorainneacha ráta flaithiúla      |
| Qoder            | OAuth saor in aisce                                   |
| Google Vertex AI | $300 i gcreidmheasanna do chuntas nua                 |
| Amazon Q         | Sraith saor in aisce d'úsáideoirí AWS                 |
| Pollinations     | API poiblí oscailte                                   |
| Cloudflare AI    | Sraith saor in aisce Workers AI                       |

**Straitéis**: treoraíonn teaglama `auto` le teorainn bhuiséid anseo nuair a theipeann ar Shraith 1+2
nó nuair a shocraítear `useFreeOnly=true`. Is minic a bhíonn teorainneacha
ráta níos laige ag soláthraithe saor in aisce — cuireann an scoradán ciorcaid ar ais iad tar éis tréimhse chúlaithe.

## Sraitheanna a chumrú

Painéal → **Sraitheanna** → sann do sholáthraithe. Tá na réamhshocruithe (ó `tierDefaults.json`)
ciallmhar; cuir in eagar iad nuair atá síntiúis ar leith agat ar mhaith leat tosaíocht a thabhairt dóibh nó soláthraithe le heisiamh.

Cuireann scóráil 16 fhachtóir Auto-Combo an tsraith san áireamh freisin. Féach
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Teiliméadracht

Taispeánann Painéal → **Úsáid** na comharthaí a caitheadh de réir sraithe agus lae. Úsáid é seo chun:

- A dheimhniú go n-úsáidtear Sraith 1 go hiomlán (murach sin tá luach do shíntiúis á chur amú agat)
- A aithint cé na samhlacha i Sraith 2 is minice a roghnaítear (comhdhlúthaigh go 1-2 cheann)
- A fhíorú go sábhálann Sraith 3 airgead ar ualaí oibre tástála/taiscéalaíochta

## Patrúin choitianta

### Ualach oibre atá go hiomlán saor in aisce

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Treoraíonn sé go láidir i dtreo Shraith 3; ní úsáideann sé Sraith 2 ach amháin mura bhfuil Sraith 3 ar fáil.

### Síntiús ar dtús le cúltaca saor

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Liosta sainráite ordaithe a mheaitseálann Sraith 1 → Sraith 2 → Sraith 3.
