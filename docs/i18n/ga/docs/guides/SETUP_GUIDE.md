## Modhanna Suiteála

### npm (molta)

```bash
npm install -g omniroute
omniroute
```

Osclaítear an painéal ag `http://localhost:20128` agus is é `http://localhost:20128/v1` bun-URL an API.

### pnpm

```bash
pnpm add -g omniroute@latest --allow-build=better-sqlite3 --allow-build=@swc/core
omniroute
```

> **Úsáideoirí pnpm:** tá an bhratach `--allow-build` riachtanach chun scripteanna dúchasacha tógála a chumasú do `better-sqlite3` agus `@swc/core`. Ní thacaítear leis an ordú `pnpm approve-builds -g` le haghaidh suiteálacha domhanda ar pnpm v11.

### Arch Linux (AUR)

```bash
yay -S omniroute-bin
systemctl --user enable --now omniroute.service
```

Suiteálann an [pacáiste AUR](https://aur.archlinux.org/packages/omniroute-bin) OmniRoute agus soláthraíonn sé seirbhís úsáideora systemd.

### Ón bhFoinse

```bash
npm install
PORT=20128 DASHBOARD_PORT=20129 NEXT_PUBLIC_BASE_URL=http://localhost:20129 npm run dev
```

> **Nóta maidir le Windows:** De réir réamhshocraithe, úsáideann OmniRoute `%APPDATA%\omniroute` nuair nach bhfuil an t-eolaire oidhreachta `%USERPROFILE%\.omniroute` ann. Socraigh `DATA_DIR` chun suíomh eile a roghnú don eolaire sonraí.

> **Nóta:** Gineann `npm install` `.env` go huathoibríoch ó `.env.example` ar an gcéad rith. Ní fhorscríobhfaidh suiteálacha ina dhiaidh sin `.env` atá ann cheana, agus mar sin caomhnaítear saincheapuithe. Chun é a athshíolú, scrios `.env` sula ritear arís é.

### Docker

Féach ar an [Treoir Docker](./DOCKER_GUIDE.md) chun socrú iomlán Docker a fháil, lena n-áirítear próifílí Compose agus Caddy HTTPS.

### Aip Deisce (Electron)

Tagann OmniRoute le fillteán deisce atá tógtha ar Electron 41 + electron-builder 26.10. Na scripteanna atá ar fáil (fréamh an spáis oibre):

```bash
npm run electron:dev          # Rith an deasc le hathlódáil the
npm run electron:build        # Tóg don OS reatha (braitear go huathoibríoch é)
npm run electron:build:win    # Suiteálaí Windows (NSIS + iniompartha)
npm run electron:build:mac    # macOS (dmg + zip, arm64+x64)
npm run electron:build:linux  # Linux (AppImage + deb + rpm)
npm run electron:smoke:packaged  # Déan tástáil deataigh ar an tógáil phacáistithe
```

Ceanglaítear eisiúintí na suiteálaithe deisce le GitHub Releases. Chun mionléargas iomlán ar Electron a fháil (síniú, droichead IPC, dáiltí), féach ar [`ELECTRON_GUIDE.md`](./ELECTRON_GUIDE.md) _(cruthaithe ag céim níos déanaí)_.

### Freastalaí gan chomhéadan grafach (CI/uathoibriú)

Le haghaidh socruithe gan duine i láthair (Docker, Kubernetes, CI), úsáid:

```bash
omniroute setup --non-interactive
omniroute providers test-batch
```

In éineacht le hathróga timpeallachta (`INITIAL_PASSWORD`, `OMNIROUTE_WS_BRIDGE_SECRET`, srl.), ligeann sé seo duit ásc OmniRoute atá inscriptithe go hiomlán a chur ar bun.

### Roghanna CLI

| Ordú                    | Cur Síos                                                                           |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `omniroute`             | Tosaigh an freastalaí (`PORT=20128`, API agus painéal ar an bport céanna)          |
| `omniroute setup`       | Ionduchtú treoraithe CLI don fhocal faire agus don chéad soláthraí                 |
| `omniroute doctor`      | Rith seiceálacha sláinte áitiúla gan an freastalaí a thosú                         |
| `omniroute providers`   | Aimsigh, liostaigh, bailíochtaigh agus tástáil soláthraithe ón CLI                 |
| `omniroute config`      | Cumraíocht uirlis CLI — liostaigh, faigh, socraigh agus bailíochtaigh cumraíochtaí |
| `omniroute status`      | Painéal stádais as líne — leagan, DB, uirlisí, cumraíocht                          |
| `omniroute logs`        | Sruthaigh logaí úsáide ón API (tacaíonn sé le `--follow`)                          |
| `omniroute update`      | Seiceáil le haghaidh nuashonruithe OmniRoute nó cuir i bhfeidhm iad                |
| `omniroute provider`    | Bainistigh naisc soláthraithe — cuir leis, liostaigh, bain, tástáil, réamhshocrú   |
| `omniroute --port 3000` | Socraigh an port canónach/API go 3000                                              |
| `omniroute --mcp`       | Tosaigh freastalaí MCP (iompar stdio)                                              |
| `omniroute --no-open`   | Ná hoscail an brabhsálaí go huathoibríoch                                          |
| `omniroute --help`      | Taispeáin cabhair                                                                  |

Is féidir socrú gan chomhéadan grafach a scriptiú le bratacha nó le hathróga timpeallachta:

```bash
omniroute setup --non-interactive --password "$OMNIROUTE_PASSWORD"
omniroute setup --non-interactive --add-provider --provider openai --api-key "$OPENAI_API_KEY"
omniroute setup --non-interactive --add-provider --provider openai --api-key "$OPENAI_API_KEY" --test-provider
```

Rith diagnóisic áitiúil gan an painéal a oscailt:

```bash
omniroute doctor
omniroute doctor --json
omniroute doctor --no-liveness
```

Bainistigh soláthraithe ó SSH nó ó scripteanna gan an painéal a oscailt:

```bash
omniroute providers available
omniroute providers available --search openai
omniroute providers available --category api-key
omniroute providers list
omniroute providers test <id-or-name>
omniroute providers test-all
omniroute providers validate
```

## Cumraíocht na hUirlise CLI

### 1) Ceangail Soláthraithe agus Cruthaigh Eochair API

1. Oscail Deais → `Providers` agus ceangail soláthraí amháin ar a laghad (OAuth nó eochair API).
2. Oscail Deais → `Endpoints` agus cruthaigh eochair API.
3. (Roghnach) Oscail Deais → `Combos` agus socraigh do shlabhra cúltaca.

### 2) Dírigh d’Uirlis Ríomhchláraithe

```txt
Bun-URL:   http://localhost:20128/v1
Eochair API:  [cóipeáil ón leathanach Endpoint]
Samhail:   if/qwen3.8-max-preview (nó aon réimír soláthraí/samhla)
```

Mura féidir le d’eagarthóir `Authorization: Bearer ...` a sheoladh, úsáid an bun-URL comhoiriúnachta comharthaithe ina ionad:

```txt
Bun-URL: http://localhost:20128/api/v1/vscode/YOUR_KEY/
URL na Samhlacha: http://localhost:20128/api/v1/vscode/YOUR_KEY/models
URL Comhrá: http://localhost:20128/api/v1/vscode/YOUR_KEY/chat/completions
URL Clibeanna Ollama: http://localhost:20128/api/v1/vscode/YOUR_KEY/api/tags
```

Oibríonn sé le Claude Code, Codex CLI, Cursor, Cline, OpenClaw, OpenCode, agus SDKanna atá comhoiriúnach le OpenAI.

#### Uathchumraigh le `setup-*`

In ionad an bun-URL agus an eochair a ghreamú de láimh, lig do OmniRoute cumraíocht
féin gach uirlise a scríobh ón gcatalóg bheo samhlacha. Ordú amháin in aghaidh na huirlise:

```bash
omniroute setup-codex        # Próifílí ~/.codex/<name>.config.toml
omniroute setup-claude       # ~/.claude/profiles/<name>/settings.json
omniroute setup-opencode     # ~/.config/opencode/opencode.json (comhoiriúnach le OpenAI)
omniroute setup-cline        # Socruithe Cline CLI + eisínteacht VS Code
omniroute setup-kilo         # Kilo Code
omniroute setup-continue     # ~/.continue/config.yaml (Continue / cn)
omniroute setup-cursor       # Priontálann sé céimeanna Cursor laistigh den aip
omniroute setup-roo          # Iompórtáil Roo Code + pointeoir autoImport
omniroute setup-crush        # ~/.config/crush/crush.json
omniroute setup-goose        # ~/.config/goose/config.yaml
omniroute setup-aider        # ~/.aider.conf.yml
omniroute setup-qwen         # ~/.qwen/settings.json + ~/.qwen/.env
```

Glacann gach ceann acu le `--remote <url> --api-key <key>` chun uirlis áitiúil a chumrú i gcoinne
OmniRoute **cianda**, chomh maith le `--dry-run` chun réamhamharc a fháil. Chun CLI a sheoladh leis an
timpeallacht cheart insteallta agus gan aon chumraíocht a scríobh ar chor ar bith, úsáid an tosaitheoir ginearálta
`omniroute run <target>` (claude, codex, aider, goose, opencode, qwen, gemini);
tá na tosaitheoirí oidhreachta in aghaidh na huirlise `omniroute launch` (Claude Code) agus
`omniroute launch-codex` (Codex) ar fáil fós.

Chun an tábla iomlán a fheiceáil (an méid a scríobhann gach ordú, gach bratach, áitiúil i gcomparáid le cianda, coinbhinsiúin
`/v1` an bhun-URL), féach **[Comhtháthuithe CLI](./CLI-INTEGRATIONS.md)**.

Le haghaidh cumraíocht mhionsonraithe in aghaidh na huirlise (Claude Code, Codex CLI, Cursor, Cline, OpenClaw, Kilo Code, Copilot, agus tuilleadh), féach an **[Treoir d’Uirlisí CLI](../reference/CLI-TOOLS.md)** tiomnaithe.

## Socrú Prótacail (MCP + A2A)

### Socrú MCP (Prótacal Comhthéacs Samhla)

Tosaigh iompar MCP i mód stdio:

```bash
omniroute --mcp
```

Sreabhadh bailíochtaithe molta:

```bash
# 1. Tosaigh an freastalaí MCP
omniroute --mcp

# 2. Ó do chliant MCP, glaoigh ar:
omniroute_get_health        # Ba cheart dó sláinte an chórais a thabhairt ar ais
omniroute_list_combos       # Ba cheart dó teaglamaí gníomhacha a thabhairt ar ais

# 3. Nó rith an tsraith iomlán E2E:
npm run test:protocols:e2e
```

#### Cumraíocht Chliaint MCP

**Claude Code:**

```bash
claude mcp add-server omniroute --type http --url http://localhost:20128/api/mcp/stream
```

**Cursor / Cline:**

Cuir le do shocruithe MCP é:

```json
{
  "mcpServers": {
    "omniroute": {
      "command": "omniroute",
      "args": ["--mcp"],
      "env": {}
    }
  }
}
```

**Doiciméadacht iomlán MCP:** [README Fhreastalaí MCP](../../open-sse/mcp-server/README.md) — 110 uirlis, cumraíochtaí IDE, cliaint Python/TS/Go.

### Socrú A2A (Prótacal Gníomhaire-go-Gníomhaire)

Fíoraigh Cárta an Ghníomhaire:

```bash
curl http://localhost:20128/.well-known/agent.json
```

Seol tasc:

```bash
curl -X POST http://localhost:20128/a2a \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":"quickstart","method":"message/send","params":{"skill":"quota-management","messages":[{"role":"user","content":"Give me a short quota summary."}]}}'
```

**Doiciméadacht iomlán A2A:** [README Fhreastalaí A2A](../../src/lib/a2a/README.md) — JSON-RPC 2.0, scileanna, sruthú, saolré tascanna.

## Cumraíocht Teorainneacha Ama

### Teorainneacha Ama Bunúsacha

I gcás fhormhór na n-imscaradh, níl uait ach an dá athróg seo:

| Athróg                   | Réamhshocrú                                      | Cuspóir                                                                                                                                                                                                                                 |
| ------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `REQUEST_TIMEOUT_MS`     | `600000`                                         | Bonnlíne chomhroinnte don teorainn ama chun tús freagartha ón bhfoinse réamhtheachtach a fháil, do theorainneacha ama folaithe Undici, d’iarratais méarloirg TLS, agus do theorainneacha ama iarratais/seachfhreastalaí an droichid API |
| `STREAM_IDLE_TIMEOUT_MS` | faigheann sé `REQUEST_TIMEOUT_MS` le hoidhreacht | An bhearna uasta idir smutáin sruthaithe sula gcuireann OmniRoute deireadh leis an sruth SSE                                                                                                                                            |

Caomhnaítear comhoiriúnacht siarghabhálach: oibríonn `FETCH_TIMEOUT_MS`, `API_BRIDGE_PROXY_TIMEOUT_MS`, agus athróga eile teorann ama de réir sraithe atá ann cheana fós agus sáraíonn siad an bhonnlíne chomhroinnte.

### Nótaí a Bhaineann go Sonrach le Soláthraithe

I gcás foinsí réamhtheachtacha atá comhoiriúnach le Claude Code (`anthropic-compatible-cc-*`), díorthaíonn OmniRoute an ceanntásc amach `X-Stainless-Timeout` ón teorainn ama réitithe fetch ionas go bhfanfaidh teorainneacha ama léite ar thaobh an tsoláthraí ailínithe le cumraíocht d’imshaoil.

I gcás seachfhreastalaithe droim ar ais tríú páirtí atá comhoiriúnach le Claude Code, coinníonn OmniRoute an tacar réamhshocraithe `anthropic-beta` coimeádach agus, nuair a fhágtar `Client Cache Control` ar `Auto`, ní chuireann sé ar aghaidh ach marcóirí `cache_control` arna soláthar ag an gcliant. Cumasaigh an scorán "Cumasaigh béite redact-thinking" in aghaidh an naisc nuair a éilíonn an fhoinse réamhtheachtach sruthanna smaointeoireachta folaithe Claude go sonrach, agus sa chás sin amháin.

### Sáruithe Ardleibhéil ar Theorainneacha Ama

| Athróg                                   | Réamhshocrú                                                  | Cuspóir                                                                                                                    |
| ---------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `FETCH_TIMEOUT_MS`                       | faigheann sé `REQUEST_TIMEOUT_MS` le hoidhreacht             | Teorainn ama chun tús freagartha ón bhfoinse réamhtheachtach a fháil, a úsáidtear go dtí go dtagann ceanntásca an fhreagra |
| `FETCH_HEADERS_TIMEOUT_MS`               | faigheann sé `FETCH_TIMEOUT_MS` le hoidhreacht               | Teorainn ama Undici chun ceanntásca freagartha ón bhfoinse réamhtheachtach a fháil                                         |
| `FETCH_BODY_TIMEOUT_MS`                  | faigheann sé `FETCH_TIMEOUT_MS` le hoidhreacht               | Teorainn ama Undici idir smutáin de chorp na foinse réamhtheachtaí (díchumasaíonn `0` í)                                   |
| `FETCH_CONNECT_TIMEOUT_MS`               | `30000`                                                      | Teorainn ama Undici chun nasc TCP a bhunú                                                                                  |
| `FETCH_KEEPALIVE_TIMEOUT_MS`             | `4000`                                                       | Teorainn ama Undici do shoicéad díomhaoin coinneála beo                                                                    |
| `TLS_CLIENT_TIMEOUT_MS`                  | faigheann sé `FETCH_TIMEOUT_MS` le hoidhreacht               | Teorainn ama d’iarratais méarloirg TLS a dhéantar trí `wreq-js`                                                            |
| `API_BRIDGE_PROXY_TIMEOUT_MS`            | faigheann sé `REQUEST_TIMEOUT_MS` nó `600000` le hoidhreacht | Teorainn ama do chur ar aghaidh seachfhreastalaí `/v1` ón bport API chuig port an deais                                    |
| `API_BRIDGE_SERVER_REQUEST_TIMEOUT_MS`   | `max(API_BRIDGE_PROXY_TIMEOUT_MS, 300000)`                   | Teorainn ama d’iarratais isteach ar fhreastalaí an droichid API                                                            |
| `API_BRIDGE_SERVER_HEADERS_TIMEOUT_MS`   | `60000`                                                      | Teorainn ama do cheanntásca isteach ar fhreastalaí an droichid API                                                         |
| `API_BRIDGE_SERVER_KEEPALIVE_TIMEOUT_MS` | `5000`                                                       | Teorainn ama coinneála beo ar fhreastalaí an droichid API                                                                  |
| `API_BRIDGE_SERVER_SOCKET_TIMEOUT_MS`    | `0`                                                          | Teorainn ama neamhghníomhaíochta soicéid ar fhreastalaí an droichid API (díchumasaíonn `0` í)                              |

> **Nóta:** I gcás iarratais sruthaithe, ní chumhdaíonn `FETCH_TIMEOUT_MS` ach socrú an naisc / fanacht leis an gcéad fhreagra ón bhfoinse réamhtheachtach. Nuair a bhíonn an sruth gníomhach, ní chuirfidh OmniRoute deireadh leis ach amháin i gcás marbhántacht iarbhír (`STREAM_IDLE_TIMEOUT_MS`) nó neamhghníomhaíocht choirp Undici (`FETCH_BODY_TIMEOUT_MS`).

### Comhoiriúnacht Seachfhreastalaí Droim ar Ais

Má ritheann tú OmniRoute taobh thiar de Nginx, Caddy, Cloudflare, nó seachfhreastalaí droim ar ais eile, cinntigh go bhfuil teorainneacha ama an tseachfhreastalaí níos airde freisin ná teorainneacha ama srutha/fetch OmniRoute.

## Teimpléad Void Linux (xbps-src)

Más úsáideoir Void Linux thú, is féidir leat pacáiste dúchasach a thógáil le `xbps-src`. Sábháil an bloc seo mar `srcpkgs/omniroute/template`:

```bash
# Comhad teimpléid le haghaidh 'omniroute'
pkgname=omniroute
version=3.8.0
revision=1
hostmakedepends="nodejs python3 make"
depends="openssl"
```
