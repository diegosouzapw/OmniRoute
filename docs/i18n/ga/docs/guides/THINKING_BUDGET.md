> **Deais:** Socruithe → **AI** → Buiséad Smaointeoireachta  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **Foinse:** `open-sse/services/thinkingBudget.ts`

Rialaíonn an Buiséad Smaointeoireachta cibé acu a **athscríobhann OmniRoute paraiméadair smaointeoireachta/réasúnaíochta an chliaint** ar an mbealach chuig soláthraithe. Ní chuireann sé comhbhrú, ródú ná taisce na leide ar siúl ná as.

## Móid

| Mód                             | Cad a dhéanann OmniRoute                                                                                                     | Cathain ba cheart é a úsáid                                                                                                                                                                                                      |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (réamhshocrú) | Fágann sé réimsí an chliaint gan athrú (`reasoning`, `reasoning_effort`, `thinking` Claude, `thinking_config` Gemini, srl.). | **Codex / Desktop / aon chliant ar cheart dó an iarracht + achoimrí réasúnaíochta a rialú.** Riachtanach do phainéil smaointeoireachta infheicthe nuair a iarrann an cliant `reasoning.summary`.                                 |
| **`auto`**                      | **Baineann sé gach** réimse smaointeoireachta/réasúnaíochta de chorp na hiarrata sula seoltar in aghaidh an tsrutha í.       | Ach amháin nuair is mian leat d’aon ghnó go gceapfadh an **soláthraí** réamhshocruithe agus nuair nach gá duit smaointeoireacht faoi rialú an chliaint. **Ní hionann é agus** “smaointeoireacht a thaispeáint go huathoibríoch”. |
| **`custom`**                    | Forscríobhann sé gach iarratas le buiséad seasta comharthaí smaointeoireachta.                                               | Uasteorainn dhocht ar chomharthaí smaointeoireachta don trácht ar fad.                                                                                                                                                           |
| **`adaptive`**                  | Scálaíonn sé an buiséad ó bhuniarracht de réir líon na dteachtaireachtaí, na n-uirlisí agus fhad na leide.                   | Rialú bog ar chomharthaí gan rún an chliaint a bhaint go hiomlán.                                                                                                                                                                |

### An méid a bhaineann `auto` de

Nuair atá an mód socraithe mar `auto`, scriosann `stripThinkingConfig()` na nithe seo a leanas (i measc nithe eile):

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, agus `output_config.effort` nuair atá sé ann
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

Má sheol cliant (m.sh. Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }`, **caitheann auto an réad sin i leataobh**. D’fhéadfadh an tseirbhís in aghaidh an tsrutha táille a ghearradh fós ar roinnt comharthaí réasúnaíochta, ach is minic a fhilleann sí míreanna réasúnaíochta atá **folamh nó criptithe amháin** — mar sin ní thaispeánann an Chomhéadain sruth úsáideach smaointeoireachta.

## An rud **nach bhfuil** i gceist leis seo

| Gné                                                          | Gaol                                                                                                                                               |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Comhbhrú** (Caveman, RTK, cruachta, …)                     | Píblíne ar leith. Oibríonn sé faoi gach mód buiséid smaointeoireachta.                                                                             |
| **Taisce leide / shéimeantach**                              | Ar leith. Ní dhéanann mód an bhuiséid smaointeoireachta difear dó.                                                                                 |
| **Ródú teaglama / cúltacaí**                                 | Ar leith. Ní dhéanann sé difear dó.                                                                                                                |
| **Teorainneacha comharthaí eochrach API / buiséid chostais** | Ar leith. Ní dhéanann sé difear dóibh.                                                                                                             |
| **Taisce athsheinnte réasúnaíochta**                         | Ath-instealladh ilseala do sholáthraithe dochta (DeepSeek, Kimi, Qwen-thinking, …). Ní hionann é agus “smaointeoireacht a thaispeáint” in Desktop. |
| **Díchriptiú `encrypted_content`**                           | **Dodhéanta.** Tá blobaí réasúnaíochta príobháideacha OpenAI/Codex dofheicthe. Ní dhíchriptíonn OmniRoute iad riamh (#7095 / #7176 / #7304).       |

## Smaointeoireacht infheicthe (cliaint Codex / Responses)

Chun go dtaispeánfaidh cliant téacs smaointeoireachta, teastaíonn **gach ceann** díobh seo:

1. Mód Thinking Budget = **`passthrough`** (nó custom/adaptive a fhágann iarratais achoimre slán go leor don chonair a úsáideann tú).
2. Iarrann an cliant achoimre, m.sh. Codex `model_reasoning_summary = "detailed"` / `auto` (ní `none`).
3. Sruthaíonn an tseirbhís réamhtheachtach `response.reasoning_summary_text.*` i ndáiríre (nó tá `reasoning.summary` neamhfholamh ar an mír).

Mura bhfaigheann tú ach “réasúnaíocht phríobháideach chriptithe”, is amhlaidh:

- gur **`auto`** a bhí sa mhód (baineadh iarratas an chliaint), nó
- gur chuir an tseirbhís réamhtheachtach `encrypted_content` ar ais gan téacs achoimre (teorainn de chuid an tsoláthraí; ní féidir le OmniRoute ach ionadchoinneálaí a thaispeáint, ní gnáth-théacs).

## Samplaí API

```bash
# Léigh
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Molta chun smaointeoireacht a dhéanamh infheicthe in Codex / Desktop
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

Scéimre (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier` roghnach.

### Marthanacht / atosú

Stóráiltear an luach faoin eochair socruithe `thinkingBudget` agus lódáiltear é ag tús an phróisis (`hydrateThinkingBudgetConfig`). Tar éis é a athrú tríd an mbunachar sonraí nó trí chonairí áirithe nach mbaineann leis an API, **atosaigh próiseas OmniRoute** ionas go mbeidh an t-aonán cuimhne ag teacht leis an diosca.

## Seicliosta don oibreoir

- [ ] Úsáideoirí Codex / Desktop: mód = **passthrough**
- [ ] Coinnigh comhbhrú cumasaithe más mian leat comharthaí a shábháil ar **theachtaireachtaí**, seachas tríd an smaointeoireacht a bhaint
