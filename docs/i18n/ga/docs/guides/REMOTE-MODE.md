Rith an CLI `omniroute` ar do ríomhaire glúine agus OmniRoute féin ag rith áit éigin eile
(VPS, freastalaí baile, ríomhaire eile ar do Tailnet). Logálann tú isteach uair amháin le
`omniroute connect`, agus as sin amach díríonn **gach** ordú CLI ar an gcianfhreastalaí
sin — na horduithe céanna, an t-aschur céanna, ach iad curtha i gcrích ar an gcianfhreastalaí.

Níl aon dara uirlis le suiteáil: is éard atá sa mhód cianda ná an gnáth-CLI `omniroute`
mar aon le **comharthaí rochtana** a bhfuil raon feidhme acu.

```bash
npm install -g omniroute                 # an gnáth-CLI
omniroute connect 192.168.0.15           # logáil isteach (pasfhocal → comhartha le raon feidhme)
omniroute models list                    # ← liostaítear anois samhlacha an CHIANFHREASTALAÍ
omniroute configure codex                # ← scríobhtar próifíl áitiúil Codex ón gcatalóg chianda
```

## Conas a oibríonn sé

```
do ríomhaire glúine                       OmniRoute cianda (VPS)
┌────────────────────┐                   ┌───────────────────────────────┐
│ CLI omniroute      │  POST /api/cli/connect  (pasfhocal → comhartha)    │
│  comhthéacs: vps   │ ───────────────►  │ eisítear comhartha rochtana    │
│  baseUrl, comhartha│  Authorization: Bearer oma_live_…                  │
│                    │ ───────────────►  │ gach bealach bainistíochta,    │
│ scríobhann sé      │ ◄───────────────  │ seiceáilte de réir raon feidhme│
│ cumraíochtaí GO    │                   │ an chomhartha                  │
│ HÁITIÚIL           │                   └───────────────────────────────┘
└────────────────────┘
```

- Stórálann **comhthéacsanna** freastalaí amháin an ceann (`~/.omniroute/config.json`, `chmod 600`).
  Athraíonn `omniroute contexts use <name>` an freastalaí gníomhach; tá `default` áitiúil.
- Údaraíonn **comharthaí rochtana** (`oma_live_…`) orduithe bainistíochta. Tá siad
  éagsúil le heochracha API tátail (`sk-…`, a úsáidtear le haghaidh `/v1/chat/completions`).
- Ní stóráiltear ar thaobh an fhreastalaí ach hais SHA-256 de chomhartha. Taispeántar an gnáth-théacs
  **uair amháin**, tráth a chruthaithe.

## Ag nascadh

### Leis an bpasfhocal bainistíochta (tosú)

```bash
omniroute connect 192.168.0.15
# Pasfhocal bainistíochta do http://192.168.0.15:20128: ********
# ✔ Ceangailte le http://192.168.0.15:20128 — comhthéacs '192.168.0.15' (raon feidhme: admin)
```

Eisíonn sreabhadh an phasfhocail comhartha **admin** de réir réamhshocraithe (tá an pasfhocal agat, mar sin
tá smacht iomlán agat cheana féin). Laghdaigh an raon feidhme le `--scope`:

```bash
omniroute connect 192.168.0.15 --scope write
```

Roghanna: `--port <p>` (nuair nach bhfuil port ag an óstach), `--name <ctx>` (ainm an chomhthéacs),
`--scope read|write|admin`. Cloítear le URL iomlán díreach mar atá:
`omniroute connect https://omni.example.com`.

### Le comhartha réamhghinte

Gin comhartha a bhfuil raon feidhme aige sa deais (nó le `omniroute tokens create`) agus
greamaigh é — níl pasfhocal ag teastáil:

```bash
omniroute connect 192.168.0.15 --key oma_live_xxxxxxxx
```

Bailíochtaíonn an CLI é trí `GET /api/cli/whoami` agus sábhálann sé mar an comhthéacs gníomhach é.

## Raonta feidhme

Trí leibhéal, in ordlathas (`admin ⊃ write ⊃ read`):

| Raon feidhme | Cad is féidir a dhéanamh                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------ |
| `read`       | liostú/iniúchadh — `models list`, `providers status`, `logs`, `usage`, `cost`                    |
| `write`      | léamh **+** cumrú/cur i bhfeidhm — `setup-codex`, `keys add`, `config set`, teaglamaí            |
| `admin`      | scríobh **+** bainistiú — CRUD `tokens`, soláthraithe, seirbhísí, polasaí agus oauth a chur leis |

Tátalaíonn an freastalaí an raon feidhme a theastaíonn ó gach bealach ón modh HTTP
(`GET`→read, athruithe→write), chomh maith le liosta ceadaithe admin le haghaidh dromchlaí íogaire
(athruithe ar `/api/cli/tokens` agus `/api/providers`, `/api/oauth`, `/api/services`, …).
Faigheann comhartha nach bhfuil raon feidhme leordhóthanach aige `403` mar aon le teachtaireacht shoiléir.

> Fanann bealaí a sheolann próisis (`/api/services/*`, `/api/mcp/*`, …)
> **teoranta don lúb siar amháin** — ní féidir le comhartha cianda iad a rochtain choíche, beag beann ar a raon feidhme.

## Antigravity a nascadh ar shuiteáil chianda

Úsáideann Antigravity scáileán toilithe firstparty/nativeapp Google. Ní eisíonn Google
an cód údaraithe ach amháin nuair atá an **atreorú lúb-ais**
(`http://127.0.0.1:<port>/callback`) **insroichte ón mbrabhsálaí a
cheadaíonn an síniú isteach**. Ar shuiteáil chianda VPS, tá an lúb-ais sin ar an
bhfreastalaí, ní ar do ríomhaire, mar sin **crochann an scáileán toilithe go deo agus
ní eisíonn sé cód riamh** — níl aon rud le greamú ag an ngnáthrogha chúltaca
"greamaigh URL an aisghlaoigh". (Is srian de chuid Google é seo: tarlaíonn an chrochadh
céanna in aon seachfhreastalaí a úsáideann an cliant deisce Antigravity atá cuachta
leis, ní in OmniRoute amháin.)

Aimsíonn an deais é seo sula dtéann tú i bhfostú: nuair a osclaítear **Soláthraithe → Antigravity →
Ceangail** ó sheoladh nach localhost é, cuirtear an dá réiteach thíos in ionad an fhógra
chineálaigh "cóipeáil URL an aisghlaoigh", agus d'óstach agus do phort líonta isteach
cheana féin i ngach ceann acu. (Áirítear seoladh LAN — ní localhost é `192.168.x.x`
a mhéid a bhaineann leis an aisghlaoch seo.)

Tá dhá bhealach tacaithe ann chun Antigravity a nascadh le OmniRoute cianda.

### Rogha A — cúntóir logála isteach áitiúil (molta)

Rith OAuth ar **do ríomhaire féin**, áit a bhfuil `127.0.0.1` insroichte. Labhraíonn an cúntóir
go díreach le Google, mar sin cuirtear an toiliú i gcrích san áit nach féidir le leagan
na deaise é a dhéanamh.

**Má tá tú nasctha cheana féin** (`omniroute connect <host>`), níl aon rud le
cóipeáil — seachadann an cúntóir an dintiúr chuig an tsuiteáil sin duit:

```bash
# Ar do ríomhaire ÁITIÚIL (teastaíonn Node.js + brabhsálaí):
omniroute connect 192.168.0.15        # uair amháin — cruthaíonn sé comhartha comhthéacs le raon feidhme riarthóra
npx omniroute login antigravity
#   ↳ osclaíonn sé toiliú Google, gabhann sé an t-aisghlaoch ar phort lúb-ais áitiúil,
#     malartaíonn sé é, agus POSTálann sé an dintiúr chuig an gcomhthéacs gníomhach:
#
#   Antigravity nasctha ar http://192.168.0.15:20128 (nasc abc123).
#   Níl aon rud le greamú — is féidir leat an teirminéal seo a dhúnadh.
```

Tarlaíonn an brú go huathoibríoch aon uair a dhíríonn an comhthéacs gníomhach ar ríomhaire
eile. Cuir i bhfeidhm é ar cheachtar bealach le `--push` / `--no-push`, nó dírigh ar
chomhthéacs sonrach le `--context <name>`.

**Mura féidir le do ríomhaire an VPS a bhaint amach** (balla dóiteáin, gan SSH, deasc
aer-bhearnaithe), oibríonn an cúntóir fós — ní _theastaíonn_ uaidh ach Google. Úsáid
`--no-push`, nó lig don bhrú teip: mar rogha chúltaca, priontálann sé an blob seachas
údarú atá curtha i gcrích agat cheana féin a chaitheamh i leataobh.

```bash
npx omniroute login antigravity --no-push
#   omniroute-cred-v1.eyJ2IjoxLCJ...
```

Ansin, sa deais **chianda**: **Soláthraithe → Antigravity → Ceangail**, agus greamaigh
an blob `omniroute-cred-v1.…` isteach sa réimse **Céim 2** (glacann sé le URL
aisghlaoigh nó le blob dintiúir). Díchódaíonn OmniRoute é, ritheann sé ionduchtú
Cloud Code ar thaobh an fhreastalaí, agus coinníonn sé an nasc.

> Tá comhartha athnuachana sa bhlob — caith leis mar fhocal faire. Ar chonair an bhrú,
> seoltar uair amháin é thar nasc fíordheimhnithe do chomhthéacs; ar chonair an
> ghreamaithe, thar nasc do dheaise. Cibé bealach, stóráiltear criptithe é ar fos, agus
> ní phriontálann brú rathúil chuig do theirminéal é riamh.

Bratacha: `--no-browser` (priontáil an URL seachas é a oscailt go huathoibríoch), `--port <n>`
(socraigh an port lúb-ais), `--timeout <ms>`, `--push` / `--no-push` (sáraigh an
seachadadh uathoibríoch), `--context <name>` (dírigh ar chomhthéacs sonrach).

### Rogha B — tollán curtha ar aghaidh go háitiúil trí SSH

Má tá rochtain SSH agat ar an VPS, cuir port na deaise ar aghaidh ionas go
réiteoidh an t-aisghlaoch lúb-ais ar ais chuig an bhfreastalaí tríd an tollán:

```bash
# Ar do ríomhaire ÁITIÚIL:
ssh -L 20128:127.0.0.1:20128 user@your-vps
# ansin oscail http://localhost:20128 i do bhrabhsálaí ÁITIÚIL agus nasc Antigravity
# mar is gnách — sroicheann an t-atreorú 127.0.0.1:20128/callback an VPS anois trí SSH.
```

Toisc go sroicheann tú an deais mar `localhost:20128`, cuirtear toiliú Google
i gcrích agus seachadtar an t-aisghlaoch chuig an bhfreastalaí tríd an tollán céanna —
ní theastaíonn blob. Coinnigh an tollán ar oscailt go dtí go léirítear an nasc mar ghníomhach.

Murab ionann agus na soláthraithe lúb-ais sheasta thíos, **is leor cur ar aghaidh amháin**
anseo: úsáideann aisghlaoch Antigravity port na deaise féin, mar sin níl aon dara
port a bhaineann go sonrach leis an soláthraí le cur trí thollán.

> Rogha eile atá go hiomlán gan chomhéadan (gan chúntóir, gan tollán) is ea do
> dhintiúir ghréasáin Google OAuth **féin** + URL bonn poiblí a chumrú; féach ar
> athróga timpeallachta OAuth an tsoláthraí. Ní theastaíonn aon socrú breise Google
> ón dá rogha thuas.

## Codex / Grok a nascadh ar shuiteáil chianda (soláthraithe aisfhillte fhosaithe)

Cláraíonn Codex, xAI (`xai-oauth`) agus Grok CLI (`grok-cli`) `redirect_uri`
aisfhillte **fosaithe** lena bhfeidhmchlár OAuth réamhtheachtach. Ní féidir le
OmniRoute é a athrú — seolann an soláthraí an brabhsálaí ar ais chuig an seoladh
céanna atá códaithe go crua i gcónaí:

| Soláthraí   | Aisghlao fosaithe a ndéanann an soláthraí atreorú chuige |
| ----------- | -------------------------------------------------------- |
| `codex`     | `http://localhost:1455/auth/callback`                    |
| `xai-oauth` | `http://127.0.0.1:56121/callback`                        |
| `grok-cli`  | `http://127.0.0.1:56122/callback`                        |

Ciallaíonn `localhost` ansin **an ríomhaire ar a bhfuil an brabhsálaí ag rith**,
agus éisteann freastalaí aisghlao PKCE OmniRoute ar aisfhilleadh an
**fhreastalaí**. Oscail an painéal ag seoladh LAN amhail
`http://192.168.0.15:20128` agus ní thagann an dá cheann le chéile choíche:
seachadtar an cód údaraithe chuig `localhost:1455` do ríomhaire glúine féin, áit
nach bhfuil aon rud ag éisteacht, agus teipeann ar an soláthraí an síniú isteach
gan earráid a thaispeáint.

Aimsíonn an painéal é seo sula n-osclaítear an phreabfhuinneog agus taispeánann
sé an t-ordú tolláin in ionad ligean don logáil isteach teip go ciúin (#8046).

### Réiteach — cuir **an dá** phort ar aghaidh

```bash
# Ar an ríomhaire ar a bhfuil an BRABHSÁLAÍ ag rith:
ssh -L 20128:127.0.0.1:20128 -L 1455:127.0.0.1:1455 <user>@192.168.0.15
# ansin téigh chuig http://localhost:20128 agus nasc Codex as sin
```

Tá dhá chur ar aghaidh riachtanach, agus teipeann fós mura gcuirtear ach ceann
amháin ar aghaidh:

- Fágann **`20128`** (port an phainéil) gur fíor-óstach logánta é an tionscnamh,
  rud a chuireann ar OmniRoute freastalaí aisghlao PKCE a thosú ar chor ar bith —
  ní shroicheann tionscnamh LAN an brainse sin choíche.
- Is é **`1455`** (port aisghlao fosaithe an tsoláthraí) an áit a seoltar an
  brabhsálaí ar ais chuici; ní mór dó dul tríd an tollán chuig aisfhilleadh an
  fhreastalaí.

Cuir `56121`/`56122` in ionad `1455` agus xAI nó Grok CLI á nascadh agat, agus
cuir port iarbhír do phainéil in ionad `20128`. Coinnigh an tollán oscailte go
dtí go dtaispeántar go bhfuil an nasc gníomhach.

> **Gan rochtain SSH?** Glacann Codex agus Grok CLI le comhartha greamaithe
> freisin — an cluaisín **Greamaigh Eochair API** / **Iompórtáil auth.json** sa
> dialóg naisc. Níl aon aisghlao aisfhillte ag baint leis an gconair sin, mar sin
> oibríonn sí ó aon tionscnamh. Ina theannta sin, glacann Codex le comhartha
> rochtana lom nó le blob seisiúin `~/.codex/auth.json`.

## Comharthaí a bhainistiú

```bash
omniroute tokens create --name "laptop" --scope write [--expires 30]
#   ↳ priontálann sé an rún UAIR AMHÁIN — cóipeáil anois é
omniroute tokens list                 # folaithe: aitheantas, ainm, scóip, réimír, stádas, dul in éag
omniroute tokens revoke <id|prefix>   # cúlghair láithreach
omniroute tokens scopes               # mínigh na trí scóip
```

Teastaíonn dintiúr **riarthóra** ó na horduithe `tokens`. Is féidir leat
comharthaí a bhainistiú sa phainéal freisin faoi **Socruithe → Comharthaí
Rochtana** (cruthaigh, cúlghair, cóipeáil uair amháin).

## CLI códúcháin a chumrú ón gcatalóg chianda

Léann `omniroute configure` catalóg bheo samhlacha an **fhreastalaí ghníomhaigh**
agus scríobhann sé cumraíocht ar **do** ríomhaire.

```bash
omniroute configure codex
#   Soláthraithe: glm, kmc, ollamacloud, opencode-go, …
#   Soláthraí: glm
#   Aitheantas samhla: glm/glm-5.2
#   ✔ Scríobhadh ~/.codex/glm52.config.toml
#   Úsáid é:  codex --profile glm52

# neamh-idirghníomhach
omniroute configure codex --provider glm --model glm/glm-5.2 --name glm52

# coinnigh samhail a úsáidtear go minic ag barr an roghnóra idirghníomhaigh
omniroute configure codex --provider glm --model glm/glm-5.2 --favorite --yes
```

Ní choinníonn an roghnóir ach aitheantais samhlacha (ní choinníonn sé URLanna ná
dintiúir choíche) sa chomhad áitiúil `model-preferences.json`, arna scópáil de
réir comhthéacs agus sprice CLI. Taispeántar ceanáin roimh roghanna a rinneadh le
déanaí; úsáid `--unfavorite` chun samhail roghnaithe a bhaint den liosta
comhthéacs/sprice sin.

Tagraíonn an phróifíl scríofa don eochair tátail trí athróg timpeallachta
(`OMNIROUTE_API_KEY`) — ní scríobhtar an rún ar diosca choíche. Le haghaidh
bunshocrú aonuaire Codex (an bloc `[model_providers.omniroute]`), féach
[CODEX-CLI-CONFIGURATION.md](./CODEX-CLI-CONFIGURATION.md).

### CLI a sheoladh i gcoinne an chianfhreastalaí (gan cumraíocht a scríobh)

Cloíonn `omniroute run <target>` leis an gcomhthéacs gníomhach freisin: ní
instealltar an bun-URL cianda ná dintiúr an chomhthéacs ach amháin sa phróiseas
a sceitear.

```bash
omniroute connect 192.168.0.15
omniroute run claude   --model openai/gpt-5.4          # Claude Code → cianfhreastalaí
omniroute run gemini   --model glm/glm-5.2 -- --skip-trust -p "hello"
omniroute run opencode --model glm/glm-5.2 -- run "reply OK"

# Réamhamharc beacht ar an méid a sceithfí (AINMNEACHA EOCHRACHA timpeallachta amháin, luachanna choíche):
omniroute run codex --dry-run --json
```

Spriocanna: `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, `gemini`
(foinse aonair: `bin/cli/cli-manifest.mjs`). Ritheann Qwen agus Gemini le
heolaire baile sealadach leithlisithe a bhaintear nuair a scoirtear, mar sin ní
bhaineann an seoladh le cumraíocht phearsanta d'uirlise — ná ní sceitheann sé
isteach inti — choíche.

## Comhthéacsanna a bhainistiú (aistriú idir freastalaithe)

Is freastalaí sábháilte é **comhthéacs** (baseUrl + dintiúr + raon feidhme). Cruthaíonn `omniroute connect`
ceann agus déanann sé gníomhach é; uaidh sin amach díríonn gach ordú air. Bainistigh iad agus
aistrigh eatarthu le `omniroute contexts`:

```bash
omniroute contexts list            # gach comhthéacs; marcáiltear an ceann gníomhach le ●
omniroute contexts current         # an freastalaí gníomhach, stádas fíordheimhnithe, raon feidhme
```

```text
  | Ainm    | Bun-URL                    | Fíordheimhniú | Raon feidhme | Cur síos
● | vps     | http://100.67.86.91:20128 | token         | admin        | OmniRoute cianda (…)
  | default | http://localhost:20128    | ✗             |              |
```

**Aistrigh freastalaithe** — leanann gach ordú ina dhiaidh sin an comhthéacs gníomhach:

```bash
omniroute contexts use vps         # → díríonn gach ordú anois ar an VPS cianda
omniroute tokens list              #   (ritear é in aghaidh an VPS)

omniroute contexts use default     # → ar ais go localhost
omniroute tokens list              #   (ritear é in aghaidh an fhreastalaí logánta)
```

**Cuir comhthéacs leis de láimh** (in ionad `connect`), scrúdaigh é, nó athainmnigh é:

```bash
omniroute contexts add staging --url https://staging.example.com:20128 \
  --access-token oma_live_xxxx --scope write --description "staging box"
omniroute contexts show staging    # sonraí iomlána do chomhthéacs amháin
omniroute contexts rename staging stg
```

**Bain comhthéacs** — iarrtar deimhniú; tabhair `--yes` chun é a scipeáil
(riachtanach do scripteanna / blaoscanna neamh-idirghníomhacha, a dhiúltaíonn go sábháilte murach sin):

```bash
omniroute contexts remove stg --yes
```

> Ní féidir `default` (localhost) a bhaint. Má bhaintear an comhthéacs gníomhach, filleann sé
> ar `default`. Leid: ní bhaineann baint comhthéacs ach an dintiúr sábháilte **logánta** —
> cúlghair an comhartha ar an bhfreastalaí le `omniroute tokens revoke <id>` chun rochtain a
> scor i ndáiríre.

**Easpórtáil / iompórtáil** comhthéacsanna (m.sh. chun iad a aistriú idir ríomhairí). Ní choinníonn comhthéacsanna nua
ach tagairt don eochairshlabhra; ní chóipeáiltear dintiúir isteach san easpórtáil nuair atá
eochairshlabhra an OS ar fáil:

```bash
omniroute contexts export --out contexts.json     # réamhshocrú: stdout
omniroute contexts import contexts.json            # forscríobh; --merge chun na cinn atá ann a choinneáil
omniroute contexts migrate --yes                  # bog comharthaí gnáth-théacs oidhreachta chuig an eochairshlabhra
```

Ar chórais gan chomhéadan grafach nach bhfuil eochairshlabhra OS inúsáidte acu, filleann an CLI ar
`config.json` le mód `0600` agus priontálann sé rabhadh aonuaire. Caith le heaspórtálacha ón
gcúltaca sin (agus le haon chumraíocht oidhreachta roimh an asc imirce) mar ábhar rúnda.

## Seiceáil thapa ó cheann ceann

Saolré is féidir a chóipeáil agus a ghreamú chun socrú cianda a fhíorú ón tús — ceangail, eisiúint
comhartha faoi raon feidhme, treoraigh ordú, aistrigh ar ais, agus bain an socrú. Cuir óstach/IP
d'fhreastalaí in ionad `192.168.0.15` (Tailscale, LAN, nó URL poiblí
`https://…`).

```bash
# 1. Ceangail (pasfhocal → comhartha admin, sábháilte mar chomhthéacs a éiríonn gníomhach)
omniroute connect 192.168.0.15                 # nó: --key oma_live_xxxx  (gan pasfhocal)
omniroute contexts current                     # taispeánann sé an freastalaí cianda + raon feidhme

# 2. Úsáid é — ritear orduithe bainistíochta anois in aghaidh an chinn chianda
omniroute tokens create --name laptop --scope read   # eisigh comhartha le raon feidhme níos cúinge
omniroute tokens list                                 # liosta mascaithe, ón gcianfhreastalaí

# 3. Aistrigh anonn is anall
omniroute contexts use default                 # → logánta
omniroute contexts use 192-168-0-15            # → cianda arís (ainm ó `contexts list`)

# 4. Bain an socrú. TABHAIR FAOI DEARA: ní scriosann `contexts remove` ach an dintiúr LOGÁNTA —
#    NÍ chúlghaireann sé an comhartha ar an bhfreastalaí. Cúlghair ar thaobh an fhreastalaí é ar dtús más
#    mian leat rochtain a scor i ndáiríre.
omniroute tokens revoke <id|prefix>            # scoireann sé rochtain ar an bhfreastalaí
omniroute contexts remove 192-168-0-15 --yes   # bain an comhthéacs logánta (fiú má tá sé gníomhach → filleann sé ar default), gan leid
```

> Déanann `--yes` `contexts remove` neamh-idirghníomhach (riachtanach i scripteanna/CI; gan é,
> diúltaíonn blaosc neamh-idirghníomhach go sábháilte in ionad crochadh). Má bhaintear an comhthéacs
> **gníomhach**, filleann sé ar `default` go huathoibríoch.

## Nótaí slándála

- Ní thaispeántar gnáth-théacs an chomhartha ach uair amháin; ní choinnítear ach an hais SHA-256 (mar a dhéantar le heochracha API).
- Athúsáideann `omniroute connect` an frithdhúnadh i gcoinne iarrachtaí logála isteach le fórsa brúidiúil agus an logáil iniúchta.
- Moltar HTTPS nó Tailnet a úsáid don iompar; úsáidtear `http://` de réir réamhshocraithe le haghaidh óstach lom
  ar mhaithe le háisiúlacht LAN/Tailscale — tabhair URL iomlán `https://…` le haghaidh TLS.
- Is é `~/.omniroute/config.json` (`chmod 600`) an comhad comhthéacs áitiúil is fearr,
  nach bhfuil ann ach `credentialRef`; stóráiltear an comhartha féin i slabhra eochracha an chórais oibriúcháin
  (`keytar`) agus ní phriontáiltear i logaí riamh é. Úsáideann suiteálacha gan chomhéadan nach bhfuil slabhra
  eochracha dúchasach oibre acu an comhad `0600` céanna mar chúltaca sainráite agus
  eisíonn siad rabhadh uair amháin. Úsáid `omniroute contexts migrate --yes` tar éis duit inneall
  slabhra eochracha a shuiteáil.
