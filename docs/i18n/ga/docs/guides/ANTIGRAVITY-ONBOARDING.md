## 1. Antigravity i gcomparáid le Antigravity CLI (agy)

Úsáideann an dá sholáthraí an **t-inneall céanna ó Google** — an cliant OAuth céanna, an t-athnuachan comhartha céanna, na críochphointí céanna, agus na cuntais Google chéanna. Is é an difríocht na samhlacha a fheiceann tú.

> Féach [fógra Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli) chun comparáid oifigiúil Google a fháil.

| Gné                            | `antigravity` (IDE)                                   | `agy` (CLI)                                                |
| ------------------------------ | ----------------------------------------------------- | ---------------------------------------------------------- |
| **Táirge Google**              | Antigravity 2.0 / Antigravity IDE                     | Antigravity CLI                                            |
| **Inneall**                    | An Google Cloud Code API céanna                       | An Google Cloud Code API céanna                            |
| **OAuth / Comhartha**          | An cliant céanna, an t-athnuachan céanna              | An cliant céanna, an t-athnuachan céanna                   |
| **Catalóg samhlacha**          | Liosta statach coimeádta (cruachódaithe in OmniRoute) | Aimsithe beo ó Google trí `:fetchAvailableModels`          |
| **Samhlacha Claude**           | Sonnet 4.6, Opus 4.6 (4 leagan an ceann)              | Sonnet 4.6, Opus 4.6 (4 leagan an ceann)                   |
| **Ainmniú Gemini**             | Lipéid shoiléire (Low/Medium/High)                    | Aitheantóirí réamhtheachtacha (extra-low/low/agent)        |
| **Samhlacha breise**           | `gpt-oss-120b-medium`                                 | D’fhéadfadh samhlacha breise ó Google a bheith san áireamh |
| **Cás úsáide réamhshocraithe** | Comhtháthú IDE (VS Code, JetBrains)                   | Rochtain CLI / API                                         |
| **Cuóta**                      | Comhroinnte le agy (an cuntas Google céanna)          | Comhroinnte le antigravity (an cuntas Google céanna)       |

**Samhlacha atá ar fáil (fíoraithe trí thurgnamh, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (leibhéil éagsúla réasúnaíochta)
- Claude: Sonnet 4.6, Opus 4.6 (gach ceann acu le leaganacha default/low/medium/high)
- Eile: GPT-OSS 120B Medium
- **NÍL Claude Sonnet 5 ar fáil** — ní thacaítear ach leis na leaganacha 4.6

**An fáth a bhfuil difríocht idir na catalóga samhlacha**: Tá CLI Google “optamaithe le haghaidh luais agus forchostais ísil” agus “comh-optamaithe le samhlacha Gemini” (de réir bhlag oifigiúil Google). Tá an táirge Gréasáin/IDE “optamaithe le haghaidh cuimsitheachta.” Úsáideann an CLI `:fetchAvailableModels` chun samhlacha a aimsiú go dinimiciúil, agus úsáideann an IDE liosta statach coimeádta.

**Go praiticiúil**: Úsáid an réimír `agy/` le haghaidh samhlacha Gemini (m.sh. `agy/gemini-3.7-flash-high`). Úsáid `antigravity/` le haghaidh an liosta stataigh choimeádta. Úsáideann an dá cheann an t-inneall céanna ó Google, ach taispeánann siad ainmniú éagsúil samhlacha. Tá an cuóta comhroinnte — áirítear úsáid ceachtar soláthraí i dtreo theorainneacha an chuntais Google chéanna.

## 3. Conas projectId a Fháil

Teastaíonn `projectId` Google Cloud Code ó gach nasc antigravity/agy. Gan é, filleann an críochphointe `/v1internal:models` 404.

### Modh A: Uathoibríoch (Molta)

Láimhseálann OmniRoute é seo go huathoibríoch. Nuair a chuireann tú cuntas nua Google leis trí OAuth na Deaise:

1. Athnuann OmniRoute an comhartha
2. Glaonn sé `loadCodeAssist` chun an projectId a aimsiú
3. Mura bhfuil tionscadal ann, glaonn sé `onboardUser` chun ceann a chruthú
4. Déanann sé iarracht eile le `loadCodeAssist` chun an projectId nuachruthaithe a fháil
5. Sábhálann sé sa bhunachar sonraí é

**Oibríonn sé seo d’fhormhór na gcuntas** — ní gá aon chéimeanna de láimh.

### Modh B: De Láimh trí agy CLI

Má theipeann ar an aimsiú uathoibríoch (féach Cuid 5 le fáil amach cathain a tharlaíonn sé seo):

```bash
# Suiteáil agy CLI (mura bhfuil sé suiteáilte cheana)
npm install -g @anthropic-ai/agy

# Logáil isteach le do chuntas Google
agy login

# Roghnaigh an cuntas nach mór é a ionduchtú
# Spreagann sé seo clárú Cloud Code agus sannann sé projectId
```

Tar éis do `agy login` éirí leis, athnuaigh an comhartha i nDeais OmniRoute. Aimseofar an projectId go huathoibríoch.

### Conas é a fhíorú

Seiceáil an bunachar sonraí:

```bash
# Laistigh de choimeádán OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Nó seiceáil na logaí:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. URI Atreoraithe OAuth

### An Fhadhb

Éilíonn Google OAuth URI atreoraithe bailí. Úsáideann réamhshocrú OmniRoute `http://127.0.0.1:20128/callback` (lúb-ais). Oibríonn sé seo do leaganacha áitiúla ach **teipeann air i gcás imlonnuithe cianda** (m.sh., freastalaí a bhfuil rochtain air trí sheoladh IP LAN).

Diúltaíonn Google do URIanna atreoraithe:

- A úsáideann seoltaí IP (ní mór fearann a úsáid a chríochnaíonn le `.com`, `.org`, etc.)
- Nach ionann iad agus na URIanna atreoraithe cláraithe i gcumraíocht an chliaint OAuth

### An Réiteach

**Rogha A: Úsáid an sreabhadh OAuth ionsuite (réamhshocrú)**

- Oibríonn sé nuair a fhaigheann tú rochtain ar OmniRoute ó `localhost` nó `127.0.0.1`
- Níl aon chumraíocht ag teastáil

**Rogha B: Dintiúir shaincheaptha OAuth**

- Socraigh `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` i do thimpeallacht
- Cuir do dhintiúir Google OAuth féin ar fáil:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Cláraigh `https://your-domain.com/callback` mar URI atreoraithe údaraithe in Google Cloud Console

**Rogha C: Úsáid agy CLI don chéad logáil isteach**

- Rith `agy login` ar an meaisín a gheobhaidh rochtain ar OmniRoute
- Cuirtear an sreabhadh OAuth i gcrích go háitiúil agus stóráiltear na comharthaí
- Iompórtáil an nasc isteach in OmniRoute tríd an Deais

### Teorainneacha

- Teastaíonn ainm fearainn le haghaidh dintiúir shaincheaptha OAuth (ní ghlacann Google le seoltaí IP mar URIanna atreoraithe)
- Mura bhfuil fearann agat, úsáid Rogha A nó C ina ionad

## 5. Fabhtcheartú: Nuair a Theipeann ar an Socrú Uathoibríoch

Láimhseálann OmniRoute aimsiú projectId agus an próiseas ionduchtaithe go huathoibríoch d'fhormhór na gcuntas. Nuair a theipeann air, is gnách gurb é ceann díobh seo a leanas an bhunchúis:

### Tá réigiún an chuntais blocáilte

**Siomptóm**: Filleann `agy login` "Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location."

**Bunchúis**: Tá réimse inneall an chórais darb ainm "Country Association" ag cuntais Google, a shocraítear tráth an chlárúcháin. Seiceálann agy CLI agus Cloud Code API an réimse seo go docht — murab ionann agus Gemini gréasáin, nach seiceálann ach do sheoladh IP reatha.

> Chun réigiún bainteach do chuntais a sheiceáil nó a athrú, tabhair cuairt ar [Fhoirm Google um Chomhlachas Tíre](https://policies.google.com/country-association-form).

**Cén fáth a n-oibríonn Gemini gréasáin ach nach n-oibríonn agy**:

- Gemini gréasáin / Google One: ní sheiceálann sé ach an seoladh IP reatha (éiríonn le seachfhreastalaí)
- agy CLI / Cloud Code API: léann sé an réimse inneall "Country Association" (ní chuidíonn seachfhreastalaí)

**Réiteach**:

1. Tabhair cuairt ar [Fhoirm Google um Chomhlachas Tíre](https://policies.google.com/country-association-form) agus seoladh IP de chuid SAM á úsáid agat
2. Cuir iarratas isteach chun an réigiún a athrú (roghnaigh "I live in a different country")
3. Fan 1-24 uair an chloig go dtí go bpróiseálfaidh Google é agus go bhfaighidh tú fógra ríomhphoist
4. Ansin, ba cheart go n-éireodh le `agy login`

### Níl tionscadal Cloud Code ag an gcuntas

**Siomptóm**: Taispeánann na logaí `loadCodeAssist returned no project id` agus `onboardUser failed (400)`.

**Bunchúis**: Níor cláraíodh an cuntas riamh le Google Cloud Code, agus theip ar an bpróiseas ionduchtaithe uathoibríoch.

**Réiteach**: Rith `agy login` de láimh chun clárú Cloud Code a thionscnamh, ansin athnuaigh an comhartha i nDeais OmniRoute.

### Tá an comhartha imithe in éag nó cúlghairthe

**Siomptóm**: Earráidí 401 sna logaí, nó teachtaireachtaí "Token has expired".

**Réiteach**: Athnuaigh an comhartha in Deais → Soláthraithe → agy → Cliceáil ar dheilbhín na hathnuachana. Má cúlghaireadh an comhartha athnuachana féin, beidh ort athfhíordheimhniú a dhéanamh trí OAuth.
