Clúdaíonn an treoir seo cuntais Kiro (cúntóir códaithe AI arna óstáil ag AWS) a chur le OmniRoute,
agus dírítear inti ar ilchuntais a rith go comhuaineach gan coinbhleachtaí seisiúin.

---

## Cúlra: Cén Fáth ar Féidir le Cuntais Kiro Teacht Salach ar a Chéile

Úsáideann inneall Kiro clárúcháin cliaint AWS SSO OIDC chun seisiúin ghníomhacha a rianú.
Is é seo an srian ríthábhachtach: **ní thacaíonn gach clárúchán cliaint OIDC ach le seisiún gníomhach
amháin ag aon am ar leith**. Nuair a fhíordheimhníonn dara gléas nó úsáideoir leis an gcliant
cláraithe céanna, déanann an t-inneall comhartha athnuachana an chéad chuntais a neamhbhailíochtú.

Is é seo an mheicníocht chéanna is cúis le fadhbanna nuair a ritheann tú `kiro-cli login` ar
ríomhaire ar a bhfuil cuntas Kiro eile sínithe isteach cheana féin — cúlghaireann an logáil isteach nua
comhartha an chéad chuntais.

---

## An Chaoi a Réitíonn OmniRoute É Seo (v3.8.0+)

Ag tosú le v3.8.0, glaonn OmniRoute ar `registerClient()` (AWS SSO OIDC) le linn gach
iompórtála naisc Kiro. Tugann sé seo a chlárúchán tiomnaithe cliaint OIDC féin do gach nasc OmniRoute.
Toisc go bhfuil gach clárúchán cliaint neamhspleách, ní théann athnuachan ná
athfhíordheimhniú cuntais amháin i bhfeidhm ar chomhartha athnuachana aon chuntais eile.

Baineann an leithlisiú leis na modhanna iompórtála comhartha athnuachana, agus seachnaíonn fíordheimhniú
eochrach API seisiúin athnuachana OIDC go hiomlán:

| Modh iompórtála                                                     | Stádas leithlisithe                                                                                                       |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Sreabhadh chóid ghléis AWS Builder ID / IDC                         | Leithlisithe ó tugadh sreabhadh chóid an ghléis isteach                                                                   |
| **Iompórtáil Comhartha** (comhartha athnuachana a ghreamú de láimh) | Leithlisithe ó v3.8.0                                                                                                     |
| **Logáil isteach shóisialta Google / GitHub**                       | Leithlisithe ó v3.8.0                                                                                                     |
| **Uath-Iompórtáil** (SQLite kiro-cli)                               | Leithlisithe ó v3.8.0 (bhí an chonair SQLite leithlisithe cheana; tá an t-ionadach taisce SSO leithlisithe anois freisin) |
| **Eochair API** (eochair fhadtéarmach CodeWhisperer)                | Gan seisiún athnuachana; déantar an eochair a bhailíochtú agus a stóráil mar dhintiúr iompróra                            |

---

## Nóta Imirce do Naisc a Cruthaíodh Roimh v3.8.0

Níl clárúchán tiomnaithe cliaint OIDC stóráilte in `providerSpecificData` ag naisc
a iompórtáladh roimh v3.8.0. Leanann na naisc seo ag obair ach úsáideann siad an críochphointe comhroinnte
athnuachana fíordheimhnithe shóisialta, rud a chiallaíonn gur féidir le dhá nasc den chineál sin a chéile a
neamhbhailíochtú fós.

**Chun leithlisiú a fháil:** scrios an seannasc ó **Painéal → Soláthraithe** agus
ath-iompórtáil é trí úsáid a bhaint as aon cheann de na sreafaí iompórtála a dtacaítear leo. Gheobhaidh gach
nasc nuachruthaithe a chlárúchán cliaint féin go huathoibríoch.

## Dhá Chuntas Kiro a Chur Leis Taobh le Taobh

### Réamhriachtanais

- OmniRoute v3.8.0 nó níos déanaí.
- Cuntas Kiro atá ag obair (ríomhphost + pasfhocal, logáil isteach Google, nó GitHub).
- An dara cuntas Kiro, más mian leat.

### Céim 1: Iompórtáil an chéad chuntas

1. Oscail **Painéal → Soláthraithe → Cuir Soláthraí Leis → Kiro**.
2. Roghnaigh ceann díobh seo:
   - **Iompórtáil Comhartha** — greamaigh comhartha athnuachana a thosaíonn le `aorAAAAAG`.
   - **Eochair API** — greamaigh eochair API fhadtéarmach Kiro / CodeWhisperer.
   - **Logáil isteach Google / GitHub** — cuir sreabhadh OAuth i gcrích sa bhrabhsálaí.
   - **Uath-Iompórtáil** — cliceáil an cnaipe; léann OmniRoute dintiúir ón
     mbunachar sonraí áitiúil kiro-cli nó ó `~/.aws/sso/cache`.
3. Sábháiltear an nasc. Cláraíonn sreafaí comhartha athnuachana cliant tiomnaithe
   OIDC go huathoibríoch. Déanann sreafaí eochrach API an eochair a bhailíochtú le AWS agus ní stórálann siad comhartha athnuachana.

### Céim 2: Iompórtáil an dara cuntas

Déan céim 1 arís don dara cuntas. Toisc go gcruthaíonn gach iompórtáil clárúchán ar leith
cliaint OIDC, tá an dá nasc leithlisithe go hiomlán.

### Céim 3: Deimhnigh go bhfuil an dá nasc gníomhach

1. **Painéal → Soláthraithe** — ba cheart go mbeadh an stádas **Gníomhach** le feiceáil ar an dá nasc Kiro.
2. **Painéal → Sláinte** — ba cheart don dá nasc pas a fháil sa tseiceáil sláinte comhartha.

### Céim 4: Úsáid teaglaim chun ródú idir cuntais

Cruthaigh teaglaim a bhfuil an dá nasc mar spriocanna aici chun ualach a chothromú nó chun aistriú cúltaca a dhéanamh eatarthu:

```
kiro/kiro-dev → kiro/kiro-pro
```

Féach [FEATURES.md](./FEATURES.md) agus an doiciméadacht ródaithe chun teaglaim a chumrú.

## Úsáideoirí Fiontair / IDC

I gcás cuntais AWS IAM Identity Center (IDC), úsáid an sreabhadh **AWS Builder ID / cód gléis IDC**
ó **Deais → Soláthraithe → Kiro → Cód Gléis**. Bhí sreabhadh an chóid gléis
leithlisithe go hiomlán i gcónaí. Ní gá na naisc seo a athiompórtáil.

Is féidir le húsáideoirí fiontair a oibríonn i réigiún AWS nach é an réigiún réamhshocraithe é an réigiún a shonrú agus
iad ag iompórtáil tríd an Import Token API:

```bash
curl -X POST http://localhost:20128/api/oauth/kiro/import \
  -H "Content-Type: application/json" \
  -d '{"refreshToken": "aorAAAAAG...", "region": "eu-west-1"}'
```

Úsáideann an réimse `region` `us-east-1` mar réamhshocrú nuair a fhágtar ar lár é.

## Sreabhadh Iompórtála Eochrach API

Tá fíordheimhniú le heochair API ceaptha do dhintiúir iompróra fhadtéarmacha Kiro / AWS CodeWhisperer. Ní
úsáideann sé athnuachan OAuth, agus mar sin seachnaíonn sé neamhbhailíochtú seisiún comhroinnte OIDC.

### Deais

1. Oscail **Deais -> Soláthraithe -> Kiro**.
2. Roghnaigh **Eochair API**.
3. Greamaigh an eochair API agus réigiún roghnach AWS (`us-east-1` mar réamhshocrú).
4. Bailíochtaíonn OmniRoute an eochair agus sábhálann sé an nasc.

### API

```bash
curl -X POST http://localhost:20128/api/oauth/kiro/api-key \
  -H "Content-Type: application/json" \
  -d '{"apiKey": "kiro_or_codewhisperer_key", "region": "us-east-1"}'
```

### Conradh Inmheánach

Bailíochtaíonn an bealach API an eochair trí `KiroService.validateApiKey()` a ghlaoch, rud a
úsáideann `ListAvailableProfiles` i gcoinne chríochphointe CodeWhisperer/Amazon Q
a mheaitseálann an réigiún agus a réitíonn `profileArn`.

Úsáideann an nasc sábháilte:

```json
{
  "authType": "apikey",
  "providerSpecificData": {
    "authMethod": "api_key",
    "region": "us-east-1",
    "profileArn": "arn:aws:codewhisperer:..."
  }
}
```

Ag am rite, seolann `KiroExecutor.buildHeaders()` an eochair mar
`Authorization: Bearer <key>` agus cuireann sé `tokentype: API_KEY` leis. Úsáideann glaonna cuóta/próifíle
an marcóir céanna ionas go gcaitheann AWS leis an iompróir mar eochair API fhadtéarmach seachas
mar chomhartha rochtana OIDC nó sóisialta.

---

## Dul in Éag an Chliaint OIDC

De ghnáth téann cliaint phoiblí AWS SSO OIDC in éag tar éis 90 lá
(`clientSecretExpiresAt`). Stórálann OmniRoute an stampa ama seo in `providerSpecificData`
ar mhaithe le hinbhraiteacht. Má stopann nasc de bheith á athnuachan tar éis thart ar 90 lá, athiompórtáil an
nasc chun clárúchán úr cliaint OIDC a fháil. Tá athchlárú uathoibríoch nuair a théann sé
in éag á rianú mar fheabhsúchán amach anseo.

Ní théann cliaint OIDC in éag i gcás naisc le heochair API toisc nach ndéanann siad athnuachan
trí AWS SSO OIDC.

## Fabhtcheartú

### Bíonn an dara cuntas á logáil amach i gcónaí

- Seiceáil an dá nasc in **Deais → Soláthraithe** agus deimhnigh go dtaispeánann gach ceann acu
  `clientId` nach bhfuil null ina JSON amh (atá le feiceáil tríd an deilbhín faisnéise). Má tá
  `clientId` in easnamh ar cheachtar nasc, iompórtáladh é roimh v3.8.0 — athiompórtáil é.

### Teipeann ar an iompórtáil le "Theip ar bhailíochtú an chomhartha"

- Cinntigh go dtosaíonn an comhartha athnuachana le `aorAAAAAG`.
- Cinntigh gur féidir le OmniRoute `https://oidc.us-east-1.amazonaws.com` (nó an réigiún
  cumraithe) a bhaint amach. Má tá tú taobh thiar de sheachfhreastalaí corparáideach, socraigh seachfhreastalaí ar leibhéal an tsoláthraí in
  **Deais → Socruithe → Seachfhreastalaithe**.

### Teipeann ar iompórtáil eochrach API

- Deimhnigh gur eochair API Kiro / CodeWhisperer í an eochair, agus nach comhartha athnuachana í.
- Deimhnigh go meaitseálann réigiún AWS an eochair/cuntas. Is é `us-east-1` an réamhshocrú.
- Ní mór don eochair a bheith in ann `ListAvailableProfiles` a ghlaoch; murach sin, ní féidir le OmniRoute
  an `profileArn` riachtanach a réiteach.

Le haghaidh fadhbanna eile, féach an príomhchomhad [TROUBLESHOOTING.md](./TROUBLESHOOTING.md).
