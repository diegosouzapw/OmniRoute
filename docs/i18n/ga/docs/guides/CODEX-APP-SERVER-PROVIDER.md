Nochtann OmniRoute **dhá** bhealach chun OpenAI Codex a úsáid:

| Soláthraí              | Conas a dhéanann sé cumarsáid le OpenAI                                                                                                                                                                                               | Foráil úsáide                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **`codex`**            | Athsheinneann sé do chomhartha ChatGPT/OpenAI OAuth go díreach chuig Responses API                                                                                                                                                    | **Tá** — níl an seisiún oifigiúil údaraithe lena úsáid trí sheachfhreastalaí/ródaire |
| **`codex-app-server`** | Tiomáineann sé **`codex app-server` de chuid Codex CLI féin** thar JSON-RPC/WebSocket; is leis an CLI a OAuth agus déanann sé é a athnuachan go huathoibríoch (`~/.codex/auth.json`) díreach cosúil le seisiún idirghníomhach `codex` | **Níl** — ní athsheinneann OmniRoute comhartha chuig an API riamh                    |

Ós rud é nach n-athsheinneann `codex-app-server` comhartha riamh, ní bhaineann an
fhoráil úsáide maidir le hathsheinm seisiúin leis. Éilíonn sé, áfach, go mbeidh
**Codex CLI inrochtana ag URL cumraithe an fhreastalaí feidhmchláir**, agus ní mór
don CLI sin a bheith **sínithe isteach**.

---

## 1. Ailtireacht

```
┌─ Aip OmniRoute ─────────────────┐        ┌─ Taobhcharr codex-app-server ────────┐
│  CodexAppServerExecutor          │  WS    │  codex app-server                   │
│  ws://codex-app-server:1456 ─────┼───────▶│  --listen ws://0.0.0.0:1456         │
│  (+ comhartha cumais)            │  JSON  │  --ws-auth capability-token         │
│                                  │  RPC   │  bainistíonn sé OpenAI OAuth féin   │
└──────────────────────────────────┘        │  (~/.codex/auth.json, uath-athnuachan)│
        │ comhroinneann (imleabhair compose) └─────────────────────────────────────┘
        ▼
  codex-appserver-token   → comhartha cumais WS (gléasann an dá cheann é)
  codex-appserver-home    → ~/.codex (scríobhann an painéal auth.json,
                             léann codex app-server an taobhchairr é)
```

- Éisteann an taobhcharr **amháin** ar an líonra inmheánach compose
  (`ws://codex-app-server:1456`) taobh thiar de chomhartha cumais. **Ní**
  fhoilsítear riamh é chuig an óstríomhaire ná chuig an idirlíon.
- Tá Codex CLI ionsuite in `omniroute:base`, mar sin ní gá codex a shuiteáil ar
  an óstríomhaire ná ar ríomhaire an úsáideora nuair a ritheann tú an taobhcharr.

## 2. Cuir ar bun é

```bash
# Tosaigh an chruach LE próifíl taobhchairr codex app-server:
docker compose --profile base --profile codex-app-server up -d
# (podman: podman compose --profile base --profile codex-app-server up -d)
```

Cruthaíonn an taobhcharr a chomhartha cumais WS ar an gcéad tosú (san imleabhar
comhroinnte `codex-appserver-token`) agus léann an aip an comhartha céanna trí
`OMNIROUTE_CODEX_APPSERVER_WS_TOKEN_FILE`. Ní gá aon chumrú comhartha de láimh.

## 3. Ceangail + sínigh isteach

1. Sa phainéal, cuir nasc leis le haghaidh **OpenAI Codex (App-Server)**. Ní
   theastaíonn eochair API ná comhartha (is soláthraí gan fíordheimhniú é —
   is leis an taobhcharr an fíordheimhniú).
2. Mura bhfuil Codex CLI an taobhchairr **sínithe isteach fós**, tuairiscíonn
   seiceáil sláinte an naisc _"ag rith ach gan a bheith sínithe isteach"_ (ní
   earráid dhearg fíordheimhnithe í). Úsáid **Sínigh isteach le ChatGPT**:
   ritheann sé seo gnáthphróiseas gléis-OAuth Codex i do bhrabhsálaí agus ansin
   scríobhann sé `~/.codex/auth.json` san imleabhar comhroinnte trí
   **Cuir fíordheimhniú i bhfeidhm** (freastalaíonn an logáil isteach chéanna ar
   na soláthraithe `codex` agus `codex-app-server` araon).
3. Nuair a bheidh tú sínithe isteach, casann an tseiceáil sláinte glas
   (fíoraíonn sí `/readyz` **agus** `account/read` araon — is é sin, go bhfuil sé
   ar bun _agus_ fíordheimhnithe) agus tosaíonn sé ag obair.

Ní fhorscríobhann an painéal `~/.codex/auth.json` sláintiúil atá ann cheana —
ní scríobhann sé ach nuair atá an comhad ar iarraidh nó nuair atá a chomhartha
as dáta (déantar cóip chúltaca i gcónaí).

## 4. Cásanna imlonnaithe

- **Oibreoir a bhfuil Codex CLI fíordheimhnithe aige cheana** — gléas do
  `~/.codex` óstach sa taobhcharr (`codex-appserver-home`) agus fág céim an
  tsínithe isteach ar lár.
- **Úsáideoir poiblí, gan codex suiteáilte go háitiúil** — ní bhaineann sé sin
  le hábhar: tá an CLI sa taobhcharr. Ní dhéanann an t-úsáideoir ach
  fíordheimhniú tríd an bpainéal.
- **OmniRoute ar chrua-earraí lom (gan taobhcharr, codex ar an óstríomhaire)** —
  socraigh `OMNIROUTE_CODEX_APPSERVER_WS` chuig do `codex app-server` féin agus
  cinntigh go bhfuil codex an óstríomhaire sínithe isteach; taispeántar an leid
  "codex gan a bheith suiteáilte" má tá an dénártha ar iarraidh.

## 5. Éalú cónaitheach / UDP (breisrogha don oibreoir, gan a bheith san áireamh)

Éalaíonn an taobhcharr cineálach thuas thar ghnáthlíonra an choimeádáin. Ritheann
oibreoir a dteastaíonn uaidh go n-éalódh trácht Codex trí **bhealach amach
cónaitheach** (m.sh. taobhcharr TUN tailscale a iompraíonn TCP + UDP/QUIC) é sin
mar shárú compose ar leith; d'aon ghnó **ní** cuid den phróifíl
`codex-app-server` a sheoltar é. Féach an lámhleabhar inmheánach oibríochtaí don
socrú sin.
