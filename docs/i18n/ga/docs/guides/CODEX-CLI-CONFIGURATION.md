> **Is é TOML an t-aon fhormáid éifeachtach.** Léann Codex nua-aimseartha `~/.codex/config.toml`
> amháin (fíoraithe le codex-cli 0.147.0: sonraíonn `codex --help` go ndéantar
> sáruithe `-c/--config` a "loaded from `~/.codex/config.toml`"). Bhain an sean-
> `~/.codex/config.yaml` leis an CLI npm oidhreachta agus déantar neamhaird de gan fógra.
> Scríobhann gineadóir an deais (`/api/cli-tools/apply`, uirlis `codex`) TOML le
> cumasc coimeádach — caomhnaítear eochracha atá ann cheana agus bloic soláthraithe eile,
> fanann an eochair API in `OMNIROUTE_API_KEY` (ní chuirtear sa chomhad riamh í), agus
> tuairiscítear `config.yaml` oidhreachta atá fágtha mar nóta ascnaimh gan baint leis.

## config.toml réidh le greamú

Cuir do luachanna féin in ionad `<YOUR_HOST>` agus `<YOUR_KEY>`:

```toml
# ~/.codex/config.toml
model                          = "cx/gpt-5.5"
model_provider                 = "omniroute"
model_reasoning_effort         = "xhigh"
model_context_window           = 400000
model_auto_compact_token_limit = 350000
tool_output_token_limit        = 32768    # uasteorainn stórála staire do gach glao uirlise

[model_providers.omniroute]
name                 = "OmniRoute"
base_url             = "http://<YOUR_HOST>:20128/v1"
env_key              = "OMNIROUTE_API_KEY"
requires_openai_auth = false
wire_api             = "responses"
```

```bash
# ~/.bashrc nó ~/.zshrc — luach iarbhír na heochrach, ní chuirtear in config.toml riamh é
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

### macOS: Codex cuachta laistigh den aip ChatGPT

Má shuiteáil tú Codex tríd an aip deisce ChatGPT, d'fhéadfadh an dénártha `codex`
a bheith ann laistigh de bheart na haipe amháin agus gan a bheith ar `PATH` do bhlaoisce fós. Cuir
an t-eolaire acmhainní le comhad tosaithe do bhlaoisce:

```bash
export PATH="/Applications/ChatGPT.app/Contents/Resources:$PATH"
```

Oscail blaosc nua, ansin fíoraigh:

```bash
command -v codex
codex --version
```

### OmniRoute áitiúil gan fíordheimhniú: is leor eochair ionadchoinneála

Deimhníonn Codex go bhfuil an athróg timpeallachta atá ainmnithe ag `env_key` ann
**sula** bhfágann an chéad iarratas an CLI. Mura n-éilíonn do shampla **áitiúil**
OmniRoute fíordheimhniú, oibreoidh aon ionadchoinneálaí nach bhfuil folamh:

```bash
export OMNIROUTE_API_KEY="${OMNIROUTE_API_KEY:-local}"
```

Úsáid fíoreochair ina ionad sin nuair atá do fhreastalaí OmniRoute cosanta nó cianda.

> **Roghanna coitianta óstach**
>
> | Rochtain       | URL                           |
> | -------------- | ----------------------------- |
> | Líonra áitiúil | `http://192.168.0.1:20128/v1` |
> | Tailscale      | `http://100.x.x.x:20128/v1`   |
> | Aislúb         | `http://localhost:20128/v1`   |

## `wire_api = "responses"` — an fáth a n-oibríonn sé do gach samhail

Chuir Codex CLI `wire_api = "chat"` (Chat Completions) as feidhm i mí Feabhra 2026 agus **éilíonn** sé `wire_api = "responses"` (OpenAI Responses API) anois. Má shocraítear `wire_api = "chat"`, tuairteálfaidh sé láithreach ag am tosaithe ó v0.138 i leith.

Ní chuireann go leor soláthraithe, GLM agus Kimi ina measc, ar fáil fós ach críochphointe Chat Completions. Cuireann DeepSeek V4 Responses API dúchasach ar fáil anois chomh maith le críochphointe atá comhoiriúnach le Anthropic; úsáideann OmniRoute Responses de réir réamhshocraithe agus ligeann sé do gach nasc DeepSeek comhoiriúnacht Anthropic a roghnú.

**Réitíonn OmniRoute é seo go trédhearcach:**

```
Codex CLI
  → wire_api = "responses"
  → POST /v1/responses (OmniRoute)
    → Roghnaíonn OmniRoute prótacal dúchasach an tsoláthraí agus aistríonn sé nuair is gá
    → POST /responses (DeepSeek V4) nó /chat/completions (Mistral / GLM / Kimi / cinn eile)
```

Ní bhíonn seachfhreastalaí aistriúcháin ar leith de dhíth ort riamh agus OmniRoute á úsáid agat. **Úsáideann gach samhail `wire_api = "responses"`** — láimhseálann OmniRoute an chuid eile.

> **Is é `wire_api` an réamhshocrú** — is é `"responses"` luach réamhshocraithe an réimse agus is féidir é a fhágáil ar lár go hiomlán ó `config.toml`. Ná socraigh go sainráite é ach amháin má tá tú ag taifeadadh na hintinne.

## Fuinneog chomhthéacs agus dlúthú

### Réimsí cumraíochta comharthaí

| Réimse                           | Cur síos                                                                                                                                                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model_context_window`           | Buiséad iomlán comharthaí don tsamhail ghníomhach. Socraigh é de réir theorainn fhógartha na samhla.                                                                                                                      |
| `model_auto_compact_token_limit` | Tairseach a thionscnaíonn dlúthú uathoibríoch na staire. **Uasmhéid: 90% de `model_context_window`** — déantar neamhaird gan rabhadh de luachanna os cionn 90%.                                                           |
| `tool_output_token_limit`        | Teorainn ar na comharthaí a stóráiltear in aghaidh aschur glao uirlise sa stair. Cuireann sé cosc ar fhreagra mór aonair ó uirlis an fhuinneog a líonadh. **Ní hé seo an t-aschur uasta** — is teorainn stórála staire é. |
| `compact_prompt`                 | Sárú inlíne ar an leid chórais a úsáidtear le linn dlúthaithe (v0.138+).                                                                                                                                                  |

> **Nóta faoi `model_max_output_tokens`**: **Ní cuid de scéimre cumraíochta Codex CLI é** an réimse seo (níl sé i mbunachar cód Codex Rust). Déantar neamhaird gan rabhadh de má shocraítear é. Ná bí ag brath air — úsáid `tool_output_token_limit` chun an méid aschuir uirlise a stóráiltear sa stair a rialú.

## Iarracht Réasúnaíochta

Rialaíonn sé seo an méid “machnaimh” a dhéanann an tsamhail sula bhfreagraíonn sí.

| Luach    | Úsáid le haghaidh                                  |
| -------- | -------------------------------------------------- |
| `none`   | Gan réasúnaíocht — freagra díreach                 |
| `low`    | Tascanna fánacha (athainmniú, formáidiú)           |
| `medium` | **Réamhshocrú an fhreastalaí** mura sonraítear é   |
| `high`   | Tascanna idirmheánacha (athfhachtóiriú, dífhabhtú) |
| `xhigh`  | Ailtireacht, grinnanailís, fadhbanna casta         |

```bash
# Sárú do gach agairt
codex -c model_reasoning_effort=low "athainmnigh an athróg x mar count"
codex -c model_reasoning_effort=xhigh "dear an modúl fíordheimhnithe"
```

Socraigh **achoimre** réasúnaíochta freisin ionas gur féidir le Desktop téacs an mhachnaimh a rindreáil (seachas blobaí criptithe amháin):

```toml
# ~/.codex/config.toml
model_reasoning_effort = "xhigh"   # nó ultra nuair a thacaítear leis
model_reasoning_summary = "detailed"  # auto | concise | detailed | none
```

### Buiséad Machnaimh OmniRoute (socrú freastalaí)

Ar óstach OmniRoute, ní mór **Settings → AI → Thinking Budget** a bheith socraithe mar **`passthrough`** chun go sroichfidh iarracht/achoimre Codex an soláthraí réamhtheachtach. Baineann mód **`auto` na réimsí uile** `reasoning` / `reasoning_effort` de chuid an chliaint agus fágfaidh sé painéil mhachnaimh folamh fiú nuair atá Codex cumraithe i gceart.

Treoir iomlán: [THINKING_BUDGET.md](./THINKING_BUDGET.md).

Tá comhbhrú agus taisce na leide neamhspleách ar a chéile agus leanann siad ag obair faoi `passthrough`.

## Próifílí — cumraíochtaí ainmnithe de réir samhla/sreafa oibre

Ligeann próifílí duit samhail + fuinneog chomhthéacs a athrú le bratach amháin. Is comhad cothrom
`~/.codex/<name>.config.toml` gach próifíl, a fhorleagann ar bharr an bhunchomhaid `config.toml`.

> **Riail ainmniúcháin (Codex CLI v0.137+):** ní mór don chomhad a bheith mar `~/.codex/<name>.config.toml` — **gan réimír `profile-`**.
> Réitíonn an CLI `-p kimi-k27` → `~/.codex/kimi-k27.config.toml`. Mura bhfaightear an comhad, cuirtear an réamhshocrú i bhfeidhm gan fógra.

```bash
codex --profile kimi-k27 "déan anailís ar 10k líne den bhunachar cód seo"
codex -p glm52 "athbhreithniú ailtireachta"
codex --profile deepseek-flash "athainmnigh athróg"   # tapa, saor
```

### Próifílí iarrachta (an tsamhail chéanna, iarracht éagsúil)

```bash
codex -p low      # cx/gpt-5.5, iarracht=low
codex -p medium   # cx/gpt-5.5, iarracht=medium
codex -p high     # cx/gpt-5.5, iarracht=high
codex -p xhigh    # cx/gpt-5.5, iarracht=xhigh (réamhshocrú)
codex -p chat     # cx/gpt-5.5, gan iarracht socraithe (réamhshocrú an fhreastalaí)
```

## Próifílí a ghiniúint go huathoibríoch le `omniroute setup-codex`

Má ritheann tú OmniRoute ar VPS, is féidir leat comhaid phróifíle a uathghiniúint ón gcatalóg bheo samhlacha:

```bash
# Ó VPS (úsáideann sé OmniRoute áitiúil ar phort 20128)
omniroute setup-codex

# Ó aon ríomhaire — dírigh ar do VPS é
omniroute setup-codex --remote http://100.x.x.x:20128 --api-key sk-xxx

# Réamhamharc gan comhaid a scríobh
omniroute setup-codex --remote http://100.x.x.x:20128 --dry-run

# Ná gin ach próifílí GLM agus Kimi
omniroute setup-codex --only glm,kimi

# Scríobh chuig eolaire saincheaptha
omniroute setup-codex --codex-home /path/to/.codex
```

Faigheann an t-ordú `/v1/models`, úsáideann sé próifílí mionchoigeartaithe do shamhlacha aitheanta, téann sé i muinín meiteashonraí na catalóige do shamhlacha téacs comhoiriúnacha eile, agus scríobhann sé `~/.codex/<name>.config.toml` do gach ceann acu. Tá sé idéimpitéinseach — is féidir é a rith arís go sábháilte.

Is féidir le OmniRoute na comhaid phróifíle chéanna seo a **uathshioncronú** freisin tar éis d’aimsiú/iompórtáil rathúil samhlacha soláthraí an chatalóg bheo a athrú. Is gné **roghnach í seo agus tá sí múchta de réir réamhshocraithe**: scoránaigh í ón **deais CLI Code** ("Uathshioncronú próifílí CLI" → Codex), nó socraigh `OMNIROUTE_AUTO_SYNC_CODEX_PROFILES=true` (urramaíonn sí `CLI_ALLOW_CONFIG_WRITES` freisin, atá cumasaithe de réir réamhshocraithe). Nuair atá sí cumasaithe, ní scríobhann sí ach comhaid phróifíle ar leith `~/.codex/*.config.toml`; ní athraíonn sí riamh an comhad gníomhach/réamhshocraithe `~/.codex/config.toml`, socruithe Codex-lb, fíordheimhniú ná roghnú soláthraí.

## Tascanna fadtréimhseacha

Is féidir le dhá réamhshocrú OmniRoute loitiméireacht chiúin a dhéanamh ar sheisiúin Codex CLI a mhaireann roinnt uaireanta. Ní socrú Codex CLI ceachtar acu — tá an dá cheann ar thaobh OmniRoute. Is minic a bhuaileann úsáideoirí atá ag aistriú cumraíochta ó sheachfhreastalaithe réamhtheachtacha a phionnálann cuntais agus a dhíchumasaíonn teorainneacha díomhaointis leis an dá cheann, agus tagann siad ar an tátal nach féidir le OmniRoute “seisiún fada a choinneáil ar bun.”

| Siomptóm                                                                                      | Cúis dhóchúil                                                                                  | Rialtán                  |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------ |
| Coinníonn an seisiún air ag athrú cuntas / cailltear leanúnachas taisce na leid idir sealanna | Is é `0` TTL chleamhnas an tseisiúin (díchumasaithe)                                           | `sessionAffinityTtlMs`   |
| Teipeann ar an gceangal i lár réasúnaithe gan aon leid don chliant                            | Gníomhachtaíodh faireoir díomhaointis an tsrutha tar éis 10 nóiméad gan smután réamhtheachtach | `STREAM_IDLE_TIMEOUT_MS` |

Plé gaolmhar: [#7126](https://github.com/diegosouzapw/OmniRoute/discussions/7126) (teipeanna ar thascanna fada), [#5718](https://github.com/diegosouzapw/OmniRoute/discussions/5718) (an fáth a bhfuil cleamhnas múchta de réir réamhshocraithe). Rianú: [#7287](https://github.com/diegosouzapw/OmniRoute/issues/7287).

### 1. Cleamhnas seisiúin — pionnáil comhrá amháin le cuntas amháin

**Réamhshocrú:** `sessionAffinityTtlMs = 0` (díchumasaithe).

**Cá háit lena shocrú**

- Deais → **Socruithe → Ródú** → **Cleamhnas seisiúin** → **TTL cleamhnais (soicindí)** (`ComboDefaultsTab`)
- Nó déan PATCH ar na socruithe le `sessionAffinityTtlMs` i **milleasoicindí** (raon Zod `0`–`86_400_000`, i.e. suas le 24 uair an chloig)

> Athainmníodh é in #7274 ón `codexSessionAffinityTtlMs` a bhain le Codex amháin. Glactar leis an eochair oidhreachta fós mar ailias inléite amháin; ba cheart do chumraíochtaí nua `sessionAffinityTtlMs` a úsáid. Baineann cleamhnas anois le **soláthraí ar bith** a luaithe a bhíonn an TTL os cionn `0`, ní le Codex amháin — féach [`docs/architecture/RESILIENCE_GUIDE.md`](../architecture/RESILIENCE_GUIDE.md) → Cleamhnas seisiúin.

**Cad a bhriseann nuair a fhanann sé ag 0**

Ródaítear gach seal i gcomhrá Codex ilseal go neamhspleách de réir na straitéise teaglaim gníomhaí agus féadfaidh sé teacht i dtír ar **chuntas difriúil in aghaidh an tseala**. Briseann sé sin leanúnachas seisiúin / taisce leide an chórais réamhtheachtaigh. Ní théann OmniRoute i gcomhairle le ceanntásca seisiúin Codex (`x-codex-session-id` / `x-session-id` / `x-omniroute-session`) ná le réimsí coirp amhail `prompt_cache_key` / `session_id` ach amháin nuair atá an TTL níos mó ná `0` (`extractSessionAffinityKey` in `src/sse/services/auth.ts`).

**Molta do thasc aonair a mhaireann roinnt uaireanta**

Socraigh an TTL **os cionn fhad ionchasach an taisc de réir an chloig bhalla** (is é **86400 soicind** = 24 uair an chloig uasmhéid an chomhéadain úsáideora):

| Fad ionchasach an taisc | TTL cleamhnais (comhéadan úsáideora, soicindí) | `sessionAffinityTtlMs` |
| ----------------------- | ---------------------------------------------- | ---------------------- |
| Cúpla uair an chloig    | `14400` (4h)                                   | `14400000`             |
| Thar oíche / ~12h       | `43200` (12h)                                  | `43200000`             |
| Lá iomlán               | `86400` (24h, uasmhéid)                        | `86400000`             |

Tá an rogha isteach d'aon ghnó: má dhíchumasaítear cleamhnas, tugtar tús áite do chothromú ualaigh thar chuntais; má chumasaítear é, tugtar tús áite do leanúnachas i seisiún fada gníomhaire amháin. Ní athraíonn an treoir seo an réamhshocrú — ní mór d'oibreoirí a ritheann tascanna fada Codex roghnú isteach.

### 2. Teorainn ama dhíomhaointis srutha — ná maraigh sealanna ciúine réasúnaithe

**Réamhshocrú:** `STREAM_IDLE_TIMEOUT_MS = 600000` (10 nóiméad). Faigheann sé a luach le hoidhreacht ó `REQUEST_TIMEOUT_MS` nuair nach bhfuil sé socraithe; is é 600000 an bhunlíne chomhroinnte freisin. Féach [`docs/guides/SETUP_GUIDE.md`](SETUP_GUIDE.md) → Teorainneacha ama.

**Cad a bhriseann leis an réamhshocrú**

Dúnann faireoir díomhaointis SSE (`open-sse/utils/stream.ts`) go héigeantach seal réasúnaíochta / uirlise Codex a fhanann ciúin ar feadh níos mó ná 10 nóiméad gan **aon fhíorchnapán réamhtheachtach**. Is minic nach bhfeiceann an cliant ach titim lom sa nasc — rud a mheaitseálann “stopadh go huathoibríoch gan aon fhógra.”

Sonra ríthábhachtach: **ní athshocraíonn** buille croí sintéiseach SSE OmniRoute an clog díomhaointis. Ní nuashonraítear `lastChunkTime` ach le fíorchnapán coirp réamhtheachtach. Ó thaobh an fhaireora de, tá samhail chiúin atá fós “ag smaoineamh” do-aitheanta ó fhoinse réamhtheachtach atá stoptha.

Neamhghníomhaíocht ghaolmhar i gcorp Undici: `FETCH_BODY_TIMEOUT_MS` (is é an bhunlíne chéanna 10 nóiméad an réamhshocrú freisin; díchumasaíonn `0` é). Maidir le sruthú, ní chumhdaíonn `FETCH_TIMEOUT_MS` ach socrú an naisc / na chéad cheanntásca — a luaithe a bhíonn an sruth gníomhach, rialaítear stopanna le `STREAM_IDLE_TIMEOUT_MS` agus `FETCH_BODY_TIMEOUT_MS`.

**Molta do thasc aonair iluaire**

I dtimpeallacht phróisis OmniRoute (`.env` / compose / systemd):

```bash
# Díchumasaigh teorainneacha díomhaointis srutha agus neamhghníomhaíochta coirp le haghaidh sealanna fada réasúnaíochta
STREAM_IDLE_TIMEOUT_MS=0
FETCH_BODY_TIMEOUT_MS=0
```

Nó ardaigh iad os cionn na bearna ciúine is faide a bhfuil súil agat léi (is milleasoicindí iad na luachanna):

```bash
# Sampla: ceadaigh suas le 2 uair an chloig de chiúnas idir cnapaí réamhtheachtacha
STREAM_IDLE_TIMEOUT_MS=7200000
FETCH_BODY_TIMEOUT_MS=7200000
```

Atosaigh OmniRoute tar éis na hathróga timpeallachta seo a athrú.

### Oideas nithiúil — tasc iluaire Codex

1. **Pionnáil an cuntas:** Dashboard → Settings → Routing → Session affinity → Affinity TTL = `43200` (12u) nó `86400` (uasmhéid 24u).
2. **Ardaigh / díchumasaigh teorainneacha díomhaointis** i dtimpeallacht OmniRoute:

```bash
STREAM_IDLE_TIMEOUT_MS=0
FETCH_BODY_TIMEOUT_MS=0
```

3. Coinnigh an gnáth-`config.toml` Codex (`wire_api = "responses"`, an `base_url` ceart, `OMNIROUTE_API_KEY`) — níl aon socruithe cleamhnais/díomhaointis ar thaobh Codex ann don dá iompraíocht seo.
4. Atosaigh OmniRoute, ansin cuir tús leis an tasc fada Codex.

### Cinneadh maidir le réamhshocruithe (#7287)

| Rialtán                  | Réamhshocrú seolta | Athrú sa treoir seo?                                                                                      |
| ------------------------ | ------------------ | --------------------------------------------------------------------------------------------------------- |
| `sessionAffinityTtlMs`   | `0` (as)           | **Níl** — fanann sé roghnach (cothromú ualaigh vs leanúnachas; féach Discussion #5718)                    |
| `STREAM_IDLE_TIMEOUT_MS` | `600000` (10 nóim) | **Níl** — fanann sé ag 10 nóiméad do thrácht ginearálta; ardaíonn nó díchumasaíonn oibreoirí fada Codex é |

D’athródh aisiompú ceachtar réamhshocraithe go domhanda an iompraíocht do gach cliant ar ásc, ní do Codex amháin. Déan na rialtáin a dhoiciméadú; fág na réamhshocruithe mar atá go dtí go gcinnfidh oibreoir a mhalairt go sainráite.

### Diagnóisiú ciorruithe díomhaointis

Nuair a ghníomhaíonn an faireoir díomhaointis, logálann OmniRoute líne den chruth seo:

```text
[STREAM] Idle timeout: no data from codex for 600000ms (model: cx/gpt-5.5)
```

Cuardaigh le grep le haghaidh `Idle timeout: no data from` (nó an cód `stream_idle_timeout` / ainm na hearráide `StreamIdleTimeoutError`). Is é deighleog an tsoláthraí cibé rud a d’úsáid OmniRoute don iarratas sin (`codex`, aitheantas soláthraí eile, nó `provider` mura bhfuil sé ar eolas) — ní hé an teaghrán litriúil `codex` é i gcónaí.

## Fabhtcheartú

**`Error: wire_api = "chat" is no longer supported`**
Bain `wire_api = "chat"` de do chumraíocht. Socraigh `wire_api = "responses"` nó fág an réimse ar lár (is é `"responses"` an réamhshocrú ó v0.138).

**`Error: model not found`**
Deimhnigh go bhfuil an tsamhail ann in OmniRoute leis an réimír cheart. Úsáid `omniroute models list` nó oscail `/dashboard/providers/<provider>`.

**`Authentication error`**
Deimhnigh go bhfuil `OMNIROUTE_API_KEY` easpórtáilte: `echo $OMNIROUTE_API_KEY`.

**`ERROR: Missing environment variable: OMNIROUTE_API_KEY`**
Deimhníonn Codex go bhfuil an athróg timpeallachta ann sula ndéanann sé an chéad iarratas. Easpórtáil
fíoreochair le haghaidh freastalaithe cosanta, nó ionadchoinneálaí neamhfholamh amhail
`OMNIROUTE_API_KEY=local` nuair nach dteastaíonn fíordheimhniú ó d'ásc **áitiúil** OmniRoute.
Atosaigh an bhlaosc má chuir tú le `~/.bashrc` nó `~/.zshrc` í.

**`Connection refused`**
Deimhnigh go bhfuil OmniRoute ar siúl agus go bhfuil óstach/port `base_url` ceart do do líonra (áitiúil seachas Tailscale seachas VPS).

**Tuairteálann an seisiún gar don teorainn comhthéacs**
Socraigh `model_context_window` agus `model_auto_compact_token_limit` go sainráite. Féach an tábla fuinneoige comhthéacs thuas.

**Tarlaíonn an dlúthú ró-mhall**
Ísligh `model_auto_compact_token_limit` go 80–85% den fhuinneog. Ná socraigh os cionn 90% riamh é.

**Ní lódáiltear an phróifíl (déantar neamhaird de `-p <name>` gan foláireamh)**
Deimhnigh go bhfuil an comhad ann ag `~/.codex/<name>.config.toml` (gan réimír `profile-`). Rith `ls ~/.codex/*.config.toml`.

**Titeann tasc fada Codex amach i lár a rite / athraíonn sé cuntais idir sealanna**
Féach [Tascanna fadreatha](#long-running-tasks). Cumasaigh cleamhnas seisiúin (TTL níos faide ná fad an taisc) agus ardaigh nó díchumasaigh `STREAM_IDLE_TIMEOUT_MS` / `FETCH_BODY_TIMEOUT_MS`. Cuardaigh `Idle timeout: no data from` i logaí OmniRoute le grep.
