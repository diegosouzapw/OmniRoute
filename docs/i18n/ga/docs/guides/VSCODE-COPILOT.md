Cuireann **OmniCopilot** gach samhail a fhreastalaíonn do OmniRoute uirthi isteach i roghnóir samhlacha _dúchais_ GitHub Copilot Chat.
Níl aon dara taobhbharra ná aon chomhéadan comhrá ar leith ann — leanann mód gníomhaire Copilot, glaoch uirlisí,
freastalaithe MCP agus treoracha saincheaptha ar aghaidh ag obair, ach iad ag rith ar an tsamhail a roghnaíonn tú.

| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Suiteáil (VS Code)**        | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Suiteáil (forcanna)**       | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Cód foinseach / fadhbanna** | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Riachtanais**               | VS Code 1.104+                                                                                                                                  |

> **Níl síntiús Copilot ag teastáil.** Ó VS Code 1.122 i leith, oibríonn soláthraí samhla teanga
> gan síniú isteach ar GitHub agus gan aon phlean Copilot. Fanann comhlánuithe inlíne agus
> gnéithe bunaithe ar leabuithe lasmuigh d'API an tsoláthraí agus tá Copilot fós ag teastáil uathu.

## Socrú

1. **Rith OmniRoute** — `npm install -g omniroute && omniroute` (an deais ar `http://localhost:20128`).
2. **Suiteáil an eisínteacht** — cuardaigh "OmniRoute" san amharc Eisínteachtaí.
3. **Roghnaigh samhail** — Copilot Chat → roghnóir samhlacha → **Bainistigh Samhlacha…** → **OmniRoute**, ansin cuir tic leis
   na cinn atá uait.

Ní gá aon rud a chumrú nuair a ritheann OmniRoute ar an bport réamhshocraithe. I gcás cianásc, oscail
**deilbhín OmniRoute sa Bharra Gníomhaíochta** (nó rith `OmniRoute: Manage Connection`) agus socraigh:

- **URL an fhreastalaí** — fréamh an fhreastalaí, m.sh. `http://192.168.0.15:20128`. Cuireann an eisínteacht
  an iarmhír `/v1` leis; ná cuir san áireamh í.
- **Eochair API** — ach amháin nuair a shocraíonn an freastalaí `REQUIRE_API_KEY`. Stóráiltear í i slabhra eochracha an chórais oibriúcháin trí VS
  Code SecretStorage, agus ní stóráiltear riamh í in `settings.json`.

## An méid a thaispeánfaidh an roghnóir

Ní thaispeánann an eisínteacht pálasta amh `GET /v1/models` — déanann sí é a mhúnlú, agus tá an líon a
fheiceann tú níos lú ná méid na catalóige ar dhá chúis bheartaithe.

### Iarrann sé aitheantas amháin in aghaidh na samhla

Is é **`dual`** luach réamhshocraithe `MODELS_CATALOG_PREFIX_MODE`, rud a fhógraíonn gach samhail faoi dhó — uair amháin
faoi réimír ghearr an ailias agus uair amháin faoi réimír chanónach an tsoláthraí — ionas go leanfaidh cumraíochtaí
cliant níos sine de cheachtar foirm a réiteach:

```
cc/claude-sonnet-4-6        ← réimír ailias
claude/claude-sonnet-4-6    ← réimír chanónach, an tsamhail chéanna
```

Iarrann an eisínteacht **`GET /v1/models?prefix=alias`** ionas go dtiocfaidh aitheantas amháin isteach in aghaidh na samhla, gan
an socrú ar fud an fhreastalaí a athrú do do chliaint eile. Ar ásc tagartha, laghdaigh sé seo
**2345 iontráil go 1396 — 949 dúblach, gan aon samhail caillte.**

Más fearr leat é seo a cheartú ar fud an fhreastalaí do _gach_ cliant, socraigh bratach gné
`MODELS_CATALOG_PREFIX_MODE` go `alias` sa deais. Féach
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) don
pharaiméadar iarratais agus don tábla de réir móid.

### Folaíonn sé samhlacha nach féidir leo comhrá a dhéanamh

Liostaítear sa chatalóg freisin samhlacha íomhá, físe, fuaime, athrangaithe, leabaithe agus modhnóireachta. Diúltaítear
dóibh sin ar iarratas comhrá ar aon nós:

```
HTTP 400 — Is samhail giniúna íomhánna í an tsamhail '<id>' agus ní féidir í a úsáid ar
/v1/chat/completions. Úsáid POST /v1/images/generations ina ionad.
```

mar sin scagtar amach iad de réir a réimse `type` sula sroicheann siad an roghnóir. **Coinnítear samhlacha Responses-API
** — fógraíonn gach iontráil Codex / GPT-5.x `supported_endpoints: ["responses"]`,
agus aistríonn OmniRoute iad sin do `/v1/chat/completions`, mar sin is féidir iad a úsáid gan stró.

### Soláthraithe nár chumraigh tú riamh

Liostaíonn an chatalóg samhlacha ó sholáthraithe a bhfuil **nasc gníomhach** acu _móide_ gach soláthraí **noAuth**
— na cinn gan eochair atá ina gcuid mhór den tsraith saor in aisce. Tá sé sin d'aon ghnó. Chun iad
a fholú, cuir le `blockedProviders` iad i socruithe na deaise; ní athraítear aon rud san
eisínteacht.

## Painéal taobh istigh de chluaisín VS Code

Rindreálann `omnicopilot.dashboardOpen: "editor"` painéal OmniRoute i gcluaisín eagarthóra tríd an
Simple Browser seachas i mbrabhsálaí seachtrach. Ní mór leabú a **roghnú go sainráite ar an bhfreastalaí** trí
`DASHBOARD_ALLOW_EMBED=vscode`, a fhreastalaíonn na leathanaigh HTML le
`frame-ancestors 'self' vscode-webview:` seachas an réamhshocrú `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Coinníonn dromchla an API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) na
ceanntásca dochta i gceachtar cás.

> ⚠️ **Bratach ama tógála atá inti, ní bratach ama rite.** Tiomsaíonn Next.js `headers()` isteach i bhforléargas na mbealaí,
> mar sin léann `next.config.mjs` an athróg agus an beartán á thógáil
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Ní athraíonn a heaspórtáil roimh fhreastalaí atá tógtha cheana aon rud — tá na ceanntásca ionsuite ann.

```bash
# ní mór don athróg a bheith i láthair ar an ordú TÓGÁLA
DASHBOARD_ALLOW_EMBED=vscode npm run build        # nó npm run build:release
npm start
```

| An chaoi ar shuiteáil tú é | An féidir leat leabú a chumasú?                                                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Ón bhfoinse                | ✅ socraigh an athróg ar an ordú tógála, mar atá thuas                                                                                      |
| `npm install -g omniroute` | ❌ tagann beartán réamhthógtha leis an bpacáiste foilsithe — tóg ón bhfoinse ina ionad sin                                                  |
| Íomhá Docker               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — níl leabú cumasaithe san íomhá réamhthógtha ar Docker Hub |

Gan leagan tógtha ina bhfuil leabú cumasaithe, diúltaíonn an leathanach é féin a chur i bhfráma; braitheann an eisínteacht é sin ó
cheanntásca an fhreagra agus téann sí ar ais chuig an mbrabhsálaí seachtrach — ní bhristear aon rud, agus deir sí é sin uair amháin.
Féach [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) agus saincheist
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Do chuid uirlisí eile a chumrú ón taobh istigh de VS Code

Úsáideann **`OmniRoute: Configure Coding CLI`** an CLI `omniroute` chun próifílí atá réidh le húsáid a scríobh
do Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code,
Kilo agus Roo — na cumraíochtaí céanna a bhfuil cur síos orthu in
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). Cuirtear an eochair API ar fáil don CLI tríd an
athróg timpeallachta `OMNIROUTE_API_KEY`, agus ní chuirtear ar líne na n-orduithe riamh í.
