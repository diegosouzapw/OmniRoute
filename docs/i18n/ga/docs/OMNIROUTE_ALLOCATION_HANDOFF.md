Ní ionann leithdháileadh agus cuóta soláthraí.

Sainíonn comhthiomsuithe cuóta cé na heochracha API a fhéadfaidh comhthiomsú soláthraí a úsáid agus conas a chuirtear beartais chrua, bhoga nó bhorrtha i bhfeidhm. Is éard atá i gcuóta soláthraí ná acmhainn sheachtrach arna tuairisciú ag soláthraí nó ag foinse atá cumraithe go sainráite. Is teorainneacha rialachais iad buiséid inmheánacha Ghostlight arna sainiú ag an riarthóir.

Tá an oibríocht `ensurePool` idé-idéimitheach: fágtar comhthiomsú comhionann gan athrú, nuashonraítear leithdháileadh athraithe, agus cruthaítear comhthiomsú atá ar iarraidh. Tá sé seo beartaithe le haghaidh uathoibrithe agus glaoiteoirí API faoi theorainn.

Is é `GET /api/omniroute/status` an críochphointe stádais inléite amháin. Is é `npm run omniroute:verify` an t-ordú fíorúcháin; ní dhéanann sé aon iarratas beo ar shamhail.
