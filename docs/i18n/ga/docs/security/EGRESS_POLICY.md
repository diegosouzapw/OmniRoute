> **Ceangail trácht amach le teaghlach IP amháin — `auto`, `ipv4`, nó `ipv6` — in aghaidh an tseachfhreastalaí, ionas nach sceithfidh bealach amach IPv6-amháin ar ais go IPv4 go ciúin choíche.**

> **Foinse na fírinne:** `open-sse/utils/proxyFamily.ts`, `open-sse/utils/proxyDispatcher.ts`, `open-sse/utils/proxyFetch.ts`, `open-sse/utils/socksConnectorWithFamily.ts`, `open-sse/utils/proxyFamilyResolve.ts`, `src/shared/validation/schemas.ts`, `src/lib/db/proxies.ts`, `src/lib/db/upstreamProxy.ts`, `src/lib/db/migrations/099_proxy_family.sql`

Ligeann OmniRoute do gach seachfhreastalaí **treoir bhealaigh amach do theaghlach seoltaí** a iompar. De réir réamhshocraithe, roghnaíonn an córas oibriúcháin IPv4 nó IPv6 (dé-chruach, "Happy Eyeballs"). Nuair a shocraíonn tú an treoir mar `ipv4` nó `ipv6`, ceanglaíonn OmniRoute gach nasc tríd an seachfhreastalaí sin leis an teaghlach roghnaithe agus **teipeann sé go dúnta** seachas filleadh ar an teaghlach eile.

Mínítear ar an leathanach seo cad é an treoir, cén fáth a bhfuil sí ann, cá gcumraítear í, agus conas a réitíonn an córas reatha í.

## Cad É

Tá réimse `family` ag gach seachfhreastalaí sa chlár, le trí luach fhéideartha, arna mbailíochtú ag enum Zod:

```ts
// src/shared/validation/schemas.ts
family: z.enum(["auto", "ipv4", "ipv6"]).optional().default("auto"),
```

Is é `"auto"` réamhshocrú an réimse, rud a chaomhnaíonn an t-iompar dé-chruaiche a bhí ann roimhe seo. Má shocraítear é mar `ipv4` nó `ipv6`, ceanglaítear teaghlach an naisc don seachfhreastalaí sin.

Déantar an treoir a normalú i ngach áit trí chúntóir amháin, ionas go laghdaítear aon luach anaithnid go `auto`:

```ts
// open-sse/utils/proxyFamily.ts
export type ProxyFamily = "auto" | "ipv4" | "ipv6";

export function parseProxyFamily(value: unknown): ProxyFamily {
  return value === "ipv4" || value === "ipv6" ? value : "auto";
}
```

## Cén Fáth a Bhfuil Sí Ann

Tugadh isteach í in PR [#3777](https://github.com/diegosouzapw/OmniRoute/pull/3777). Seo iad na fadhbanna ba chúis léi:

| Fadhb                                                            | Cad a réitíonn an treoir                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bealach amach IPv6-amháin ag sceitheadh go IPv4**              | Nuair atá taifid A agus AAAA araon ag óstach seachfhreastalaí (nó nuair is fearr leis an gcóras oibriúcháin IPv4), is féidir le Happy Eyeballs ceangal amach thar IPv4 fiú nuair atá bealach IPv6-amháin beartaithe agat. Má cheanglaítear `ipv6`, cuirtear deireadh leis an sceitheadh sin.                                                                                                        |
| **Cúlghairm de bharr aimhrialtacht bealaigh amach chomhroinnte** | Cúlghairíonn soláthraithe rothlacha (codex/openai) comharthaí nuair a théann go leor cuntas amach tríd an IP **céanna** ar ardtoirt. Is cuid de na cuntais a choinneáil ar bhealaí amach ar leith intuartha é teaghlach an bhealaigh amach a rialú (féach [`src/lib/proxyEgress.ts`](../../src/lib/proxyEgress.ts) le haghaidh dhiagnóisic IP an bhealaigh amach a úsáidtear in éineacht leis seo). |
| **Bealach amach cinntitheach le haghaidh comhlíonta/tástála**    | Nuair is gá duit a ráthú go bhfágann trácht thar theaghlach sonrach, ní leor `auto`.                                                                                                                                                                                                                                                                                                                |

Tá an treoir **in aghaidh an tseachfhreastalaí** d’aon ghnó, seachas a bheith domhanda — is féidir beartais éagsúla a bheith ag seachfhreastalaithe éagsúla i do linn.

## Na Trí Luach

| Luach  | Lipéad comhéadain   | Iompar                                                                                                                                                                                                                    |
| ------ | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto` | `Auto (dual-stack)` | Roghnaíonn an córas oibriúcháin an teaghlach. I gcás óstach seachfhreastalaí ar litearthacht IP é, is cuid dhílis den litearthacht é an teaghlach; i gcás óstainm, tá an dá theaghlach incháilithe. Seo é an réamhshocrú. |
| `ipv4` | `IPv4 only`         | Ceanglaíonn sé an nasc le IPv4. Teipeann sé go dúnta mura bhfuil taifead IPv4 (A) ag óstach an tseachfhreastalaí.                                                                                                         |
| `ipv6` | `IPv6 only`         | Ceanglaíonn sé an nasc le IPv6. Teipeann sé go dúnta mura bhfuil taifead IPv6 (AAAA) ag óstach an tseachfhreastalaí.                                                                                                      |

Tá teaghráin an chomhéadain in `src/i18n/messages/en.json` (`labelFamily`, `familyAuto`, `familyIpv4`, `familyIpv6`, `familyHint`).

## Conas É a Chumrú

### Deais

Tá an roghnóir i bhfoirm an tseachfhreastalaí sa chluaisín **Comhthiomsú Seachfhreastalaí**:

1. Oscail **Deais → Socruithe → Seachfhreastalaí → Comhthiomsú Seachfhreastalaí**
2. Cuir seachfhreastalaí leis nó cuir ceann in eagar
3. Socraigh an roghchlár anuas **Teaghlach IP** go `Auto (dual-stack)`, `IPv4 only`, nó `IPv6 only`
4. Sábháil

Déanann `ProxyRegistryManager.tsx` an rialtán a rindreáil (agus é gléasta in `proxy/ProxyPoolTab.tsx`).

### API

Tá an réimse `family` mar chuid de phálódálacha cruthaithe/nuashonraithe chlárlann an tseachfhreastalaí, arna bhailíochtú ag `createProxyRegistrySchema` / `updateProxyRegistrySchema` (`src/shared/validation/schemas.ts`) agus arna láimhseáil ag `POST` / `PATCH /api/v1/management/proxies`:

```bash
# Cruthaigh seachfhreastalaí IPv6-amháin
curl -X POST http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{
    "name": "IPv6 egress",
    "type": "socks5",
    "host": "proxy.example.com",
    "port": 1080,
    "family": "ipv6"
  }'

# Athraigh seachfhreastalaí atá ann cheana go IPv4-amháin
curl -X PATCH http://localhost:20128/api/v1/management/proxies \
  -H "Content-Type: application/json" \
  -d '{ "id": "proxy-uuid-here", "family": "ipv4" }'
```

Glacann an oibiacht chumraíochta seachfhreastalaí inlíne a úsáidtear le haghaidh iontrálacha seachfhreastalaí réamhtheachtach leis an réimse céanna freisin (`upstream_proxy_config.family`, féach [Samhail Sonraí](#data-model)).

Maidir leis an gcuid eile den API CRUD/sannta seachfhreastalaí, féach [PROXY_GUIDE.md](../ops/PROXY_GUIDE.md).

## Conas a Réitíonn `auto`

Nuair is é `auto` luach `family`, **ní** chuireann OmniRoute aon treoir leis — úsáidtear URL an tseachfhreastalaí mar atá agus cinntear an teaghlach ceangail go bunúsach.

Ag am tógála an URL (`proxyConfigToUrl` / `normalizeProxyUrl` in `open-sse/utils/proxyDispatcher.ts`), táirgeann seachfhreastalaí `auto` URL simplí gan marcóir:

```ts
// open-sse/utils/proxyDispatcher.ts
const fam = parseProxyFamily(config.family);
const normalized = normalizeProxyUrl(proxyUrlStr, "context proxy", {
  allowSocks5,
});
return fam === "auto" ? normalized : `${normalized}?family=${fam}`;
```

Ag am seolta (`resolveDispatcherFamily`), réitíonn `auto` go teaghlach bunúsach óstaigh ar litearthacht IP é, nó go `null` (lig don chóras oibriúcháin cinneadh a dhéanamh) i gcás óstainm:

```ts
// open-sse/utils/proxyDispatcher.ts
function resolveDispatcherFamily(parsed: URL): 4 | 6 | null {
  const directive = parseProxyFamily(parsed.searchParams.get("family") ?? undefined);
  const literal = detectIpLiteralFamily(parsed.hostname);
  if (directive === "auto") return literal; // null i gcás óstainm → roghnaíonn an córas oibriúcháin
  // ...
}
```

Mar sin:

- `auto` + óstach ar litearthacht IP é (`192.0.2.1` / `[2001:db8::1]`) → teaghlach na litearthachta sin.
- `auto` + óstainm → `null` → réiteach caighdeánach déchruach ag an gcóras oibriúcháin.

## Conas a Fhorfheidhmítear `ipv4` / `ipv6`

Taistealaíonn treoir nach `auto` í mar mharcóir fiosraithe sintéiseach aonair — `?family=ipv4` nó `?family=ipv6` — a chuirtear uair amháin leis an URL seachfhreastalaí normalaithe. Cinntíonn `normalizeProxyUrl` go mbaintear an marcóir seo agus go gcuirtear leis arís é go díreach uair amháin, ionas nach ndéanfaidh sé parsáil an phoirt a thruailliú choíche.

Nuair a thógtar an seoltóir, léitear an marcóir agus tiontaítear é ina theaghlach ceangail nithiúil. Más litiréal IP den teaghlach **contrártha** é an t-óstach, caitheann OmniRoute earráid (dúntar ar theip i gcás contrárthachta):

```ts
// open-sse/utils/proxyDispatcher.ts
const want = directive === "ipv6" ? 6 : 4;
if (literal !== null && literal !== want) {
  throw new Error(
    `[ProxyDispatcher] Proxy family directive ${directive} contradicts ${literal === 6 ? "IPv6" : "IPv4"} literal host`
  );
}
```

Déantar an teaghlach nithiúil a fheannadh den nascóir ansin:

- **Seachfhreastalaithe HTTP/HTTPS** (`ProxyAgent`): `proxyTls: { family, autoSelectFamily: false }` — díchumasaíonn sé Happy Eyeballs ionas gurb é an teaghlach roghnaithe an t-aon cheann a dhiailtear.
- **Seachfhreastalaithe SOCKS5**: snáithíonn nascóir saincheaptha `socket_options: { family, autoSelectFamily: false }` isteach sa chliant SOCKS (féach [Comhoiriúnacht SOCKS5](#socks5-compatibility)).

## Comhoiriúnacht SOCKS5

Oibríonn feannadh an teaghlaigh le seachfhreastalaithe SOCKS5, ach ní nochtann an leagan caighdeánach de `fetch-socks` na roghanna soicéid is gá chun teaghlach léim an tseachfhreastalaí a fheannadh. Soláthraíonn OmniRoute a nascóir féin chuige sin:

```ts
// open-sse/utils/socksConnectorWithFamily.ts
export function buildSocksFamilySocketOptions(family: 4 | 6 | null): Record<string, unknown> {
  if (family === 6) return { family: 6, autoSelectFamily: false };
  if (family === 4) return { family: 4, autoSelectFamily: false };
  return {};
}
```

Téann gach seoladh SOCKS5 trí `createSocksDispatcherWithFamily` beag beann ar `family` (lena n-áirítear `null` / `auto` thar óstainm): tugann `buildSocksFamilySocketOptions(null)` `{}` ar ais, agus úsáidtear an chonair chéanna `SocksClient.createConnection` + TLS `buildConnector` le feannadh `socket_options`, ionas nach féidir le Happy Eyeballs IPv4 a roghnú do bheartas éalaithe atá teoranta do IPv6 amháin.

Tá tacaíocht SOCKS5 féin cumasaithe de réir réamhshocraithe (is féidir diúltú di trí `ENABLE_SOCKS5_PROXY=false`); féach [PROXY_GUIDE.md → Athróga Timpeallachta](../ops/PROXY_GUIDE.md#environment-variables).

## Iompar Dúnta ar Theip

Is é cuspóir iomlán na treorach ná **diúltú** seachas filleadh go ciúin ar an teaghlach mícheart. Forfheidhmíonn dhá chosaint é seo:

1. **Contrárthacht litiréil** — caitheann treoir a thagann salach ar óstach ar litiréal IP é earráid ag am tógála an tseoltóra (`resolveDispatcherFamily`, léirithe thuas).

2. **Réamhsheiceáil DNS óstainm** — i gcás seachfhreastalaí óstainm a bhfuil teaghlach feannta aige, fíoraíonn `proxyFetch.ts` go bhfuil taifead sa teaghlach riachtanach ag an óstainm **sula** ndéantar éalú, trí `assertHostnameSupportsFamily`:

   ```ts
   // open-sse/utils/proxyFamilyResolve.ts
   const hasFamily = records.some((r) => r.family === family);
   if (!hasFamily) {
     throw new Error(
       `[ProxyFamily] Proxy host ${host} has no ${family === 6 ? "IPv6 (AAAA)" : "IPv4 (A)"} record; ` +
         `refusing ${family === 6 ? "IPv6" : "IPv4"}-only egress (fail-closed)`
     );
   }
   ```

   Ar theip, clibeálann `proxyFetch.ts` an earráid le `code = "PROXY_FAMILY_UNAVAILABLE"` agus `statusCode = 503`. Caitear le teip réitigh DNS mar theip dhúnta freisin (diúltaítear d’éalú).

Ní dhéanann an réamhsheiceáil DNS aon ní i gcás óstach ar litiréal IP — tá a dteaghlach intreach agus ní gá é a chuardach.

## Samhail Sonraí

Cuireadh an colún `family` le **dhá** thábla leis an asc迁ú `099_proxy_family.sql`:

```sql
-- src/lib/db/migrations/099_proxy_family.sql
ALTER TABLE proxy_registry ADD COLUMN family TEXT NOT NULL DEFAULT 'auto';
ALTER TABLE upstream_proxy_config ADD COLUMN family TEXT NOT NULL DEFAULT 'auto';
```

- `proxy_registry.family` — an treoir in aghaidh an tseachfhreastalaí le haghaidh iontrálacha sa chlárlann (`src/lib/db/proxies.ts`). Roghnaíonn fiosruithe réitigh `family` in éineacht leis na colúin seachfhreastalaí eile, agus déantar luach atá in easnamh nó nach teaghrán é a chomhéigniú go `"auto"`.
- `upstream_proxy_config.family` — an treoir le haghaidh iontrálacha seachfhreastalaí réamhtheachtach (`src/lib/db/upstreamProxy.ts`), leis an réamhshocrú céanna `"auto"`.

Nuair a bhíonn `family` nach `auto` é ag réad seachfhreastalaí réitithe, cuireann `proxyConfigToUrl` an marcóir `?family=` leis ionas go gcoinnítear an socrú seasta an bealach ar fad chuig an seoltóir.
