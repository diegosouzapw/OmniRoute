Foilsíonn OmniRoute déantáin npm + Docker. Soláthraíonn na geataí seo bunáitíocht,
fardal (SBOM) agus scanadh CVE, iad uile OSS, agus iad comhtháite i sreafaí oibre eisiúna.
Seasamh **comhairleach ar dtús** — tuairiscíonn siad anois, agus cuirtear chun cinn iad mar
gheataí blocála tar éis na chéad eisiúna glaise.

| Geata                  | Uirlis                                         | Cá háit                          | An gcuireann sé bac?                    | Aschur                                             |
| ---------------------- | ---------------------------------------------- | -------------------------------- | --------------------------------------- | -------------------------------------------------- |
| Bunáitíocht SLSA (npm) | `npm --provenance` (OIDC)                      | `npm-publish.yml`                | ach amháin má theipeann ar an bhfoilsiú | suaitheantas npmjs / `npm audit signatures`        |
| SBOM npm               | `@cyclonedx/cyclonedx-npm`                     | `npm-publish.yml`                | ach amháin má theipeann ar an nginiúint | Sócmhainn eisiúna + déantán                        |
| Íomhá SBOM             | `anchore/sbom-action` (syft)                   | `docker-publish.yml` (cumascadh) | comhairleach                            | Déantán CycloneDX                                  |
| Trivy CVE (SARIF)      | `aquasecurity/trivy-action`                    | `docker-publish.yml` (cumascadh) | comhairleach                            | SARIF (HIGH+CRITICAL) → cluaisín Security          |
| Geata CRITICAL Trivy   | `aquasecurity/trivy-action`                    | `docker-publish.yml` (cumascadh) | **blocála**                             | `exit-code: '1'` ar CRITICAL indeisithe            |
| vulnCount osv          | `osv-scanner` (`check:vuln-ratchet --ratchet`) | `ci.yml` (`quality-extended`)    | **blocála**                             | daingníonn sé `metrics.vulnCount` (direction:down) |
| Scórchárta OpenSSF     | `ossf/scorecard-action`                        | `scorecard.yml` (cron)           | comhairleach                            | SARIF → Security + suaitheantas                    |

Úsáideann raicín CVE na híomhá **dhá chéim** in `docker-publish.yml`: coinníonn céim SARIF
(`HIGH,CRITICAL`, `exit-code: 0`) HIGH+CRITICAL infheicthe sa chluaisín Security
gan bac a chur; teipeann céim an _gheata CRITICAL_ (`severity: CRITICAL`, `ignore-unfixed: true`,
`exit-code: 1`) ar an eisiúint i gcás CVE CRITICAL **a bhfuil réiteach ar fáil dó**. Cuireann `ignore-unfixed`
cosc ar an eisiúint a bhlocáil mar gheall ar CVE buníomhá nach bhfuil paiste réamhtheachtach ar fáil dó.

## ⚠️ Athraitheacht CVE (geataí blocála osv/Trivy)

Cuireann osv agus Trivy spleáchais i gcomparáid le bunachair sonraí CVE a bhíonn **ag fás go leanúnach**. Is féidir le PR
nach **mbaineann le haon spleáchas** dul dearg go tobann toisc gur nochtadh CVE nua
i spleáchas atá ann cheana (osv: `vulnCount` tomhaiste > bonnlíne; Trivy: CRITICAL nua
indeisithe san íomhá). **Is é seo iompar oibríochtúil A BHFUILTEAR AG SÚIL LEIS ó gheata blocála
CVE, ní cúlchéimniú sa táirge.**

Nuair a théann osv nó Trivy dearg mar gheall ar CVE a nochtadh le déanaí, seo an réiteach:

1. **Nuashonraigh an spleáchas lena mbaineann** (is fearr é seo) — uasghrádaigh go dtí an leagan paisteáilte trí `package.json`
   `overrides` (spleáchais thrasdultacha) nó atóg an íomhá ar bhuníomhá phaisteáilte.
2. **Mura bhfuil réiteach réamhtheachtach ann:**
   - **osv:** athshocraigh bonnlíne `metrics.vulnCount` in `config/quality/quality-baseline.json`
     (ní chlúdaíonn `npm run quality:ratchet -- --update` geataí tiomnaithe — cuir an luach in eagar
     de láimh, `direction:down`) le nóta údaráis + saincheist rianaithe.
   - **Trivy:** cuir iontráil le `.trivyignore` (CVE-ID amháin in aghaidh na líne) le nóta tráchta
     údaráis + saincheist rianaithe. Clúdaíonn `ignore-unfixed: true` CVEanna gan
     phaistí go huathoibríoch cheana féin.

Déanann an dá gheata **SKIP go slachtmhar** (scoir 0) nuair nach bhfuil an uirlis ann nó nuair a theipeann
ar an tomhas (osv-scanner gan a bheith in PATH, osv.dev/an líonra dorochtana, JSON neamhbhailí) — ní chuireann
teip **tomhais** bac riamh; ní chuireann ach cúlchéimniú **tomhaiste** bac.
