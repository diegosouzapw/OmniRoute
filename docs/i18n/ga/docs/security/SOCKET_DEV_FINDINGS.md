3. Go mbeidh taifead scríofa againn ar an gcúis a bhfuil gach suíomh glao cumtha mar atá sé —

Má oibríonn tú scanóir a mharcálann aon cheann de na suíomhanna glao thíos arís tar éis

## §1 — Suiteáil fréamh-CA MITM (`77484.js`)

**Comhaid foinse**:

- `src/mitm/cert/install.ts` — `installCert()` / `uninstallCert()` poiblí,
  `installCertWindows/Mac/Linux` de réir ardáin.
- `src/mitm/systemCommands.ts` — cúntóirí comhroinnte `execFile` / `spawn` / PowerShell
  a úsáideann na cosáin suiteála.

**Truicear**: cliceálann an t-úsáideoir "Cumasaigh seachfhreastalaí MITM" sa deais áitiúil ag
`/dashboard/cli-tools/mitm`. Tá an bealach teoranta don lúb-ais amháin — féach riail dhocht #17 in
`CLAUDE.md` agus `src/server/authz/routeGuard.ts::isLocalOnlyPath()`. **Ní féidir** le JWT sceite
a nochtar trí thollán an cosán cóid seo a spreagadh.

**Oibríochtaí faoi phribhléid a dhéantar (de réir ardáin)**:

| CO                     | Ordú/Orduithe                                                                                                     |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Windows                | `certutil -addstore Root <cert>` trí UAC                                                                          |
| macOS                  | `sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain <cert>`                     |
| Linux                  | `sudo cp <cert> <distro-trust-dir>` + `sudo update-ca-certificates` (Debian) / `sudo update-ca-trust` (RHEL/SUSE) |
| Linux+Firefox/Chromium | nuashonrú DB NSS de réir próifíle trí `certutil -d sql:<profile>`                                                 |

Is ionann iad seo agus na horduithe a úsáideann `mitmproxy`, Charles Proxy, Fiddler, agus
Caddy. Tá sé doiciméadaithe ag
`docs/security/STEALTH_GUIDE.md` go bhfuil siad ann in OmniRoute.

**Maolú v3.8.6**:

- Ní úsáideann `runElevatedPowerShell()` `-EncodedCommand <base64utf16le>` a thuilleadh.
  Scríobhtar an t-ualach ardaithe chuig comhad sealadach `.ps1` do gach glao (mód 0o600,
  taobh istigh d'eolaire príobháideach `mkdtempSync`) agus déantar tagairt dó trí `-File`. Baintear
  nasc an chomhaid in `finally`. Cuireann sé seo deireadh leis an méarlorg clasaiceach
  ardaithe-trí-PowerShell-le-base64 a bhrataigh aicmitheoir IS Socket.dev.
- Tá bloc inlíne `SECURITY-AUDITOR-NOTE:` in `installCertWindows`
  a threoraíonn anseo.

**An fáth a gcoinnímid é**: is gné dhoiciméadaithe é an seachfhreastalaí MITM a úsáideann
`docs/security/STEALTH_GUIDE.md` agus `docs/frameworks/MITM-PROXY.md`. Dá mbainfí
é, bhrisfí tacar gnéithe an droichid gníomhairí.

## §2 — Iompórtáil dintiúr Zed (`app/api/providers/zed/import/route.js`)

**Comhaid foinse**:

- `src/app/api/providers/zed/discover/route.ts` _(nua in v3.8.6)_
- `src/app/api/providers/zed/import/route.ts`
- `src/lib/zed-oauth/keychain-reader.ts`
- `src/lib/zed-oauth/credentialFingerprint.ts` _(nua in v3.8.6)_

**Truicear**: cliceálann an t-úsáideoir "Iompórtáil ó Zed" ar leathanach Soláthraithe
an deais áitiúil. Tá an críochphointe cosanta ag `requireManagementAuth`. Scríobhann
eagarthóir Zed féin eochracha API a sholáthraithe chuig slabhra eochracha an OS faoi
ainmneacha seirbhíse doiciméadaithe — féach https://zed.dev/docs/ai/llm-providers.

**Iompar v3.8.5 (an ceann a mharcáil Socket.dev)**:

D’aimsigh `POST /import` na dintiúir agus rinne sé iad a uathshábháil sa stór áitiúil
SQLite in aon bhabhta amháin. Ní raibh aon deimhniú in aghaidh an chuntais ná aon
mhéarlorg ann, díreach "aimsíodh N comhartha, iompórtáladh iad uile."

**Maolú v3.8.6 — deimhniú 2 chéim**:

1. Tugann **`POST /api/providers/zed/discover`**
   `{ candidates: [{ provider, service, account, fingerprint }] }` ar ais. Ní
   tharchuirtear an comhartha amh **riamh**. Is é an méarlorg
   `sha256(service|account|token).slice(0,16)`.
2. Rindreálann an deais liosta na n-iarrthóirí, roghnaíonn an t-oibreoir na cinn atá
   le hiompórtáil, agus seolann sé `{ confirmedAccounts: [{ service, account, fingerprint }] }`
   chuig **`POST /api/providers/zed/import`**.
3. **Athléann an críochphointe iompórtála an slabhra eochracha ar an bhfreastalaí**
   agus scagann sé de réir `(service, account, fingerprint)`. Ní féidir le freagairt
   aimsithe ar baineadh cúbláil aisti nó a athsheinneadh a chur faoi deara go sábhálfadh
   an críochphointe iompórtála comhartha neamhghaolmhar — má tá an comhartha beo
   athraithe ó rinneadh an t-aimsiú, ní mheaitseálann an méarlorg a thuilleadh agus
   fágtar an dintiúr ar lár.

Caomhnaíonn bratach timpeallachta `OMNIROUTE_ZED_IMPORT_LEGACY_ONE_STEP=true` iompar
v3.8.5 d’oibreoirí nár nuashonraigh a n-uathoibriú fós. Bainfear é in v3.9.

**Cén fáth a gcoinnímid é**: Is é iompórtáil Zed an bealach ionduchtaithe is
cairdiúla d’úsáideoirí a úsáideann Zed cheana féin agus ar mian leo eochracha a
soláthraithe a scáthánú isteach in OmniRoute gan iad a ghreamú arís.

## §3 — `execFile` / `spawn` / PowerShell ardaithe (`21843.js`)

**Comhaid foinse**: `src/mitm/systemCommands.ts`.

**Cén fáth ar marcáladh é**: athonnmhairíonn an smután `execFileWithPassword`,
`runElevatedPowerShell`, agus an cúntóir comhroinnte `quotePowerShell`. Feiceann
aicmitheoir AI Socket.dev iad mar “fhoireann uirlisí ghinearálta chun orduithe a
rith ar an óstríomhaire agus pribhléidí a ardú.” Laistigh de OmniRoute, ní úsáidtear
iad ach ag cosán suiteála teastais MITM (§1) agus ag `execFileWithPassword` chun
orduithe `sudo` a rith.

**Maolú v3.8.6**:

- Athfhachtóiriú `runElevatedPowerShell` (féach §1).
- Déanann bloc inlíne `SECURITY-AUDITOR-NOTE:` ag `runElevatedPowerShell` agus
  `execFileWithPassword` araon na glaoiteoirí ar an liosta ceadaithe agus liosta
  na gcomhad inrite feistithe a dhoiciméadú.
- Tá marcóir `nosemgrep` ar ghlao `spawn()` `execFileWithPassword`, mar aon leis
  an liosta ceadaithe de chomhaid inrite a bhfuil cead ag an gcúntóir iad a fháil —
  níl **aon chosán ó ionchur úsáideora chuig `finalCommand`/`finalArgs`**.

## §4 / §6 — Maoirseoir seirbhíse 9router (`api/services/9router/{start,restart}/route.js`)

**Comhaid foinse**:

- `src/app/api/services/9router/_lib.ts` — monarcha an mhaoirseora.
- `src/app/api/services/9router/{start,stop,restart,status,install,update,auto-start}/route.ts`.
- `src/lib/services/ServiceSupervisor.ts` — `spawn` ginearálta / timthriall sláinte / maolán logaí.

**Truicear**: cliceálann an t-úsáideoir "Suiteáil" / "Tosaigh" ar leathanach na
seirbhísí leabaithe sa deais áitiúil.

**Cosaintí atá i bhfeidhm cheana féin**:

- Tá gach bealach `/api/services/*` LOCAL_ONLY de réir
  `src/server/authz/routeGuard.ts` (riail dhocht #17). Tarlaíonn forfheidhmiú
  aislúbtha roimh aon seiceáil fíordheimhnithe — ní féidir le JWT sceite iad a
  rochtain.
- Síolraítear ró DB 9router mar `status='not_installed', auto_start=0` (féach
  `src/lib/db/migrations/071_services.sql:19`). Ní thosaíonn an tseirbhís
  **ar chor ar bith** ar an gcéad lainseáil.
- Glaoitear `spawn()` leis an gcosán dénártha a thugann
  `resolveSpawnArgs(apiKey, PORT)` ar ais in `src/lib/services/installers/ninerouter.ts`,
  ar liosta ceadaithe seasta de dhénártha tacaithe é.
- Cuirtear stdout/stderr i maolán cuimhne (uasteorainn 5 MB, féach `_lib.ts`) —
  ní scríobhtar aon rud ar diosca mura gcumasaíonn an t-úsáideoir logáil ón deais.

**Maolú v3.8.6**: níl aon athrú feidhmiúil ann. Cuireann an phróifíl tógála íosta
(`OMNIROUTE_BUILD_PROFILE=minimal`) stub in ionad
`src/lib/services/installers/ninerouter.ts` d’úsáideoirí ar mian leo na cosáin
phribhléideacha a bhaint go fisiciúil den bheart.

**Cén fáth a gcoinnímid é**: Is seirbhís chompánach roghnach é 9router is féidir
a shuiteáil go háitiúil (smaoinigh ar: breiseán ar nós WordPress) — roghnú isteach
docht.

## §5 — Aisscríobh dintiúr OmniRoute Cloud Sync (`api/keys/[id]/route.js`)

**Comhaid fhoinse**:

- `src/lib/cloudSync.ts` — `syncToCloud()` / `updateLocalTokens()`.
- `src/app/api/keys/[id]/route.ts` — glaonn sé `syncKeysToCloudIfEnabled()`.

**Truicear**: Filleann `isCloudEnabled()` `true` (socraithe ón deais) **agus**
tá `CLOUD_URL` cumraithe. Nuair atá an dá cheann díchumasaithe, ní dhéantar aon
ghlao líonra amach chuig críochphointe Cloud.

**Iompar v3.8.5 (an fabht a d’aithin Socket.dev i gceart)**:

Rinne `updateLocalTokens()` `accessToken`, `refreshToken`, agus
`providerSpecificData` a fhorscríobh ón bhfreagairt Cloud nuair a bhí
`cloudUpdatedAt > localUpdatedAt`. Gan HMAC, gan síniú, gan suim sheiceála.
D’fhéadfadh `CLOUD_URL` a bhí míchumraithe nó mailíseach (nó MITM ar an
gcainéal) comharthaí OAuth an tsoláthraí a mhalartú go ciúin.

**Maolú v3.8.6**:

1. **Fíorú HMAC**: Seiceálann `verifyCloudSignature(rawBody, sigHeader)`
   an ceanntásc `X-Cloud-Sig` (`HMAC-SHA256(OMNIROUTE_CLOUD_SYNC_SECRET,
rawBody)`) sula bparsáiltear an JSON. Má tá an rún socraithe, tá an síniú
   riachtanach. Mura bhfuil (mód oidhreachta), logáiltear rabhadh agus
   glactar leis an bhfreagairt — beidh an rún riachtanach in v3.9.
2. **Réimsí rúnda ar bhonn rogha isteach**: Ní fhorscríobhtar `accessToken` /
   `refreshToken` / `providerSpecificData` **ach amháin** nuair atá
   `OMNIROUTE_CLOUD_SYNC_SECRETS=true`. Ní shioncronaíonn an mód réamhshocraithe
   ach meiteashonraí nach dintiúir iad (`expiresAt`, `status`, `lastError*`,
   `rateLimitedUntil`, `updatedAt`). Is **athrú bristeach** é seo d’úsáideoirí
   a bhí ag brath ar shioncrónú cianda comharthaí — ní mór dóibh rogha isteach
   a dhéanamh go sainráite.

**Cén fáth a gcoinnímid é**: Is é Cloud Sync an t-aon bhealach atá ag tionónta
OmniRoute Cloud chun dintiúir foirne a lárú. Déanann an ceartúchán an tsamhail
bhagartha macánta: "síníonn an freastalaí, fíoraíonn an cliant, roghnaíonn an
t-oibreoir dul isteach."

## Próifíl tógála: `minimal`

D’úsáideoirí a bhfuil déantán atá oiriúnach do Socket de dhíth orthu, tógtar é le:

```bash
OMNIROUTE_BUILD_PROFILE=minimal npm run build
```

Úsáideann `NormalModuleReplacementPlugin` webpack ailiasanna chun ceithre
mhodúl a chur in ionad leaganacha ionaid:

| Modúl                                       | Leagan ionaid                                    |
| ------------------------------------------- | ------------------------------------------------ |
| `src/mitm/cert/install.ts`                  | `src/mitm/cert/install.stub.ts`                  |
| `src/lib/zed-oauth/keychain-reader.ts`      | `src/lib/zed-oauth/keychain-reader.stub.ts`      |
| `src/lib/cloudSync.ts`                      | `src/lib/cloudSync.stub.ts`                      |
| `src/lib/services/installers/ninerouter.ts` | `src/lib/services/installers/ninerouter.stub.ts` |

Easpórtálann gach leagan ionaid an dromchla céanna, ach caitheann gach feidhm
`featureDisabledError(name)` ag am rite. Filleann bealaí a bhraitheann ar an
modúl díchumasaithe HTTP 503 le teachtaireacht shoiléir in ionad an chonair
íogair chóid a ghníomhachtú.

Tá sé beartaithe an beartán a eascraíonn as seo a fhoilsiú mar
`omniroute-secure`. Féach `docs/ops/PUBLISHING_SECURE.md` chun an t-oideas
foilsithe a fháil.

San fhadtéarma, tá sé i gceist againn an pacáiste npm a dheighilt ina mhodúil
ar féidir iad a iniúchadh go neamhspleách. Féach ar chloch mhíle v4 i rianaire saincheisteanna GitHub don
tsaincheist rianaithe.
