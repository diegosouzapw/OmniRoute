Ritheann geata réamhtheachtach `agentrouter` scagaire inneachair bunaithe ar eochairfhocail ar
`messages[].content`. Tá an scagaire cinntitheach i bpáirt (cuireann sé bac i gcónaí ar
fhrásaí áirithe) agus dóchúlach i bpáirt (íogair do ráigeanna — éiríonn sé
níos ionsaithí tar éis iarrataí gasta agus téann sé i bhfeabhas tar éis tréimhse shuaimhnithe).

Nuair a chuireann an WAF bac ar iarratas, seolann sé an méid seo ar ais:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Raon feidhme an scagaire

Ní scrúdaíonn an WAF ach `messages[].content`. Ní scrúdaíonn sé:

- An leid `system`
- Bloic inneachair struchtúrtha (`tool_result`, `tool_use`, `thinking`, `image`)
- Réimsí `description` agus `input_schema` na n-uirlisí
- Meiteashonraí iarratais, ceanntásca, ná aitheantas na samhla

## Patrúin a gcuirtear bac orthu i gcónaí (gan beann ar chás)

| Patrún                       | Nótaí                                                       |
| ---------------------------- | ----------------------------------------------------------- |
| Aon leagan de `Lorem ipsum`  | Cuirtear bac ar stór focal iomlán Lorem na Laidine          |
| `language model` (leis féin) | Glactar le "the language model" agus "large language model" |
| `virtual assistant`          | Glactar le "AI assistant"                                   |
| `I'm here to help`           | Cuirtear bac ar "here to help" leis féin freisin            |
| `Claude, made by Anthropic`  | An frása iomlán amháin                                      |

## Patrúin a gcuirtear bac orthu beagnach i gcónaí

| Patrún                                                       | Nótaí                                                          |
| ------------------------------------------------------------ | -------------------------------------------------------------- |
| `placeholder`                                                | Nuair a sheasann sé leis féin (ní mar ainm paraiméadair, srl.) |
| `dummy data`                                                 | Frása síolaithe coitianta le haghaidh daingneán                |
| `foo bar baz`                                                | Frása ionadchoinneála canónta                                  |
| Comharthaí gearra athráite (`AAA BBB CCC`, `test test test`) | Brathadóir do líonadh eochairfhocal                            |

## Iompar faoi ualach

Tar éis ~5 iarratas ghasta laistigh d’achar gairid, tosaíonn an WAF ag cur bac ar inneachar
a nglacfaí leis de ghnáth. Maolaíonn an buicéad tar éis ~5–10 soicind gan
ghníomhaíocht. Is é seo an teorantóir ráta céanna, atá ceangailte leis an IP agus leis an eochair, is cúis le
hearráidí eatramhacha `400 content-blocked` nuair a dhéanann Claude Code nó Codex CLI
glaonna iomadúla úsáide uirlise / seolta teachtaireachta go tapa as a chéile.

## Maoluithe atá curtha i bhfeidhm cheana féin in OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — cosaint ar ráigeanna a fhorfheidhmíonn
   bearna íosta 500 ms idir iarrataí amach chuig aon URL `agentrouter:*`.
   Tá an bhearna i bhfad faoi thairseach aireachtála moille an duine agus cuireann sí cosc
   ar an WAF gníomhachtú ar ghnáththrácht.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — nuair a sheolann réamhtheachtaí
   `400 content-blocked` ar ais, baineann an seiceadóir triail eile as an URL céanna le
   cúlú easpónantúil (1.5 s, 3.0 s, 2 iarracht ar a mhéad). Tar éis an chúlaithe
   maolaíonn an WAF de ghnáth agus éiríonn leis an atriail.

3. **`tests/unit/compression/harness.test.ts`** — athraíodh an daingneán tástála
   `longInput` ó `"lorem ipsum dolor sit amet ".repeat(40)`
   go `"example content for testing purposes ".repeat(40)` ionas, nuair a
   léann Claude Code an comhad seo tríd an uirlis `Read`, nach sreabhann inneachar an chomhaid
   ar ais trí bhloc `tool_result` agus nach ngníomhachtaíonn sé an WAF.

## Treoir maidir le leideanna agus aschur uirlisí

Má thagann seisiún Claude Code nó Codex CLI ar
`400 content-blocked` arís agus arís eile, seiceáil an teachtaireacht úsáideora is déanaí agus an toradh uirlise is
déanaí le haghaidh aon cheann de na patrúin thuas agus athfhrásaigh iad. Réitigh sheachanta
choitianta:

- Cuir `example text …` nó an t-inneachar iarbhír atá an tástáil nó an daingneán
  ag iarraidh a shamhaltú in ionad `Lorem ipsum …`.
- Cuir `example value`, `sample value`, nó an fíorluach in ionad
  `placeholder` (nuair a sheasann sé leis féin).
- Cuir `large language model` nó `the model` in ionad `language model`.
- Cuir `sample data` nó luachanna síolaithe réalaíocha in ionad `dummy data`.
- Cuir tús níos sainiúla in ionad `I'm here to help` / `here to help`
  (m.sh. "I'll review the file you mentioned").

## Na torthaí bréagacha a thuairisciú don réamhtheachtaí

Tá an scagaire reatha ró-ionsaitheach — cuireann sé bac ar "Lorem ipsum" i
mbloic `tool_result` cé gur léir nárbh é rún an oibreora
leid a instealladh. Ba cheart d’oibreoirí ar mian leo go réiteofaí é seo ag an bhfoinse
teagmháil a dhéanamh le `agentrouter.org` chun na torthaí bréagacha a thuairisciú. Is é atá sa bhlocliosta
thuas toradh eimpíreach ar fhiosrú an réamhtheachtaí amhail 2026-08-03.
