Is comhaid JSON iad rialacha comhbhrúite a luchtaítear ag am rite. Is sonraí amháin atá iontu d’aon ghnó ionas gur féidir pacáistí teanga nua agus scagairí orduithe RTK a athbhreithniú gan cód an innill a athrú.

> **Scéimre chanónach (foinse na fírinne):** [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (dréacht 2020-12 de JSON Schema).
> Is samplaí léiriúcháin iad na samplaí thíos — má bhíonn amhras ort, bailíochtaigh do phacáiste in aghaidh `_schema.json`.

## Pacáistí Rialacha Caveman

Tá pacáistí rialacha Caveman suite faoi:

```txt
open-sse/services/compression/rules/<language>/<pack>.json
```

Tá ionaduithe i ngach pacáiste a chuirtear i bhfeidhm ar ghnáthphrós tar éis na réigiúin chosanta a leithlisiú.

```json
{
  "language": "en",
  "category": "filler",
  "rules": [
    {
      "name": "question_to_directive",
      "pattern": "\\b(?:Can you explain why|Could you show me how)\\b\\s*",
      "replacement": "Explain why ",
      "replacementMap": {
        "can you explain why": "Explain why ",
        "could you show me how": "Show how "
      },
      "flags": "gi",
      "context": "all",
      "category": "context",
      "minIntensity": "lite",
      "description": "Convert verbose questions into direct requests."
    }
  ]
}
```

### Réimsí Caveman

| Réimse                   | Riachtanach | Cur síos                                                                                                |
| ------------------------ | ----------- | ------------------------------------------------------------------------------------------------------- |
| `language`               | tá          | Eochair teanga cosúil le BCP-47, amhail `en`, `pt-BR`, `es`                                             |
| `category`               | tá          | Ainm comhaid/catagóir an phacáiste, mar shampla `filler` nó `dedup`                                     |
| `rules`                  | tá          | Eagar de rialacha ionadaithe regex                                                                      |
| `rules[].name`           | tá          | Ainm cobhsaí na rialach                                                                                 |
| `rules[].pattern`        | tá          | Foinse regex JavaScript                                                                                 |
| `rules[].flags`          | níl         | Bratacha regex JavaScript; `gi` de réir réamhshocraithe                                                 |
| `rules[].replacement`    | níl         | Teaghrán ionaid nó luach cúltaca nuair nach bhfaigheann `replacementMap` meaitseáil                     |
| `rules[].replacementMap` | níl         | Ionaduithe a bhaineann go sonrach le meaitseáil, agus an téacs meaitseáilte normalaithe mar eochair acu |
| `rules[].context`        | níl         | `all`, `user`, `assistant`, nó `system`; `all` de réir réamhshocraithe                                  |
| `rules[].category`       | níl         | `filler`, `context`, `structural`, `dedup`, `terse`, nó `ultra`                                         |
| `rules[].minIntensity`   | níl         | `lite`, `full`, nó `ultra`; `lite` de réir réamhshocraithe                                              |
| `rules[].description`    | níl         | Achoimre inléite ag daoine ar an riail                                                                  |

Úsáid `flags` nuair atá meaitseáil cásíogair tábhachtach, mar shampla chun alt a bhaint roimh phrós i gcás íochtair gan `the OpenAI API` a bhaint. Úsáid `replacementMap` nuair atá ilroghanna malartacha ag regex amháin a dteastaíonn aschuir éagsúla uathu; coimeádann sé seo pacáistí rialacha JSON mar shonraí amháin agus ag an am céanna caomhnaíonn sé iompar na bhfeidhmeanna ionadaithe ionsuite TypeScript atá níos saibhre.

## Pacáistí Scagairí RTK

Tá scagairí RTK suite faoi:

```txt
open-sse/services/compression/engines/rtk/filters/<filter>.json
```

Déanann gach scagaire cur síos ar conas teaghlach d’aschur ordaithe a aithint agus a chomhbhrú.

```json
{
  "id": "test-vitest",
  "label": "Vitest output",
  "category": "test",
  "priority": 92,
  "match": {
    "outputTypes": ["test-vitest"],
    "commands": ["vitest", "npm test", "npm run test"],
    "patterns": ["\\bFAIL\\b", "\\bPASS\\b", "\\bTest Files\\b"]
  },
  "rules": {
    "stripAnsi": true,
    "replace": [{ "pattern": "\\s+\\[[0-9]+ms\\]", "replacement": "" }],
    "matchOutput": [
      {
        "pattern": "All tests passed",
        "message": "vitest: ok",
        "unless": "FAIL|Error:"
      }
    ],
    "includePatterns": ["FAIL", "Error:", "Test Files", "Tests"],
    "dropPatterns": ["^\\s*$", "Duration\\s+\\d+"],
    "collapsePatterns": ["^\\s+at "],
    "deduplicate": true,
    "truncateLineAt": 240,
    "maxLines": 160,
    "headLines": 24,
    "tailLines": 40,
    "onEmpty": "vitest: ok",
    "filterStderr": false
  },
  "preserve": {
    "errorPatterns": ["FAIL", "Error:", "AssertionError"],
    "summaryPatterns": ["Test Files", "Tests", "Snapshots"]
  },
  "tests": [
    {
      "name": "keeps failing tests",
      "command": "vitest",
      "input": "FAIL test/a.test.ts\\nError: boom\\nTest Files 1 failed",
      "expected": "FAIL test/a.test.ts\\nError: boom\\nTest Files 1 failed"
    }
  ]
}
```

### Réimsí RTK

| Réimse                     | Riachtanach | Cur síos                                                                               |
| -------------------------- | ----------- | -------------------------------------------------------------------------------------- |
| `id`                       | tá          | Aitheantas cobhsaí an scagaire                                                         |
| `label`                    | tá          | Ainm atá inléite ar an deais                                                           |
| `category`                 | tá          | Teaghlach an scagaire: git, test, build, shell, docker, package, infra, cloud, generic |
| `priority`                 | níl         | Bíonn an bua ag an tosaíocht is airde nuair a mheaitseálann roinnt scagairí            |
| `match.outputTypes`        | níl         | Aitheantais aschuir ón mbrathadóir a roghnaíonn an scagaire seo                        |
| `match.commands`           | níl         | Comharthaí ordaithe a roghnaíonn an scagaire seo                                       |
| `match.patterns`           | níl         | Patrúin sloinn ionadaíochta a roghnaíonn an scagaire seo ó théacs an aschuir           |
| `rules.stripAnsi`          | níl         | Bain seichimh éalúcháin ANSI roimh chéimeanna na sloinn ionadaíochta                   |
| `rules.replace`            | níl         | Ionadaíochtaí ordaithe sloinn ionadaíochta a chuirtear i bhfeidhm líne ar líne         |
| `rules.matchOutput`        | níl         | Rialacha aschuir gearrchiorcaid le coinníoll cosanta roghnach `unless`                 |
| `rules.includePatterns`    | níl         | Línte ar cheart tosaíocht a thabhairt dá gcaomhnú                                      |
| `rules.dropPatterns`       | níl         | Línte le baint mar thorann                                                             |
| `rules.collapsePatterns`   | níl         | Línte meaitseála athfhillteacha is féidir a chrapadh                                   |
| `rules.deduplicate`        | níl         | Crap línte normalaithe dúblacha                                                        |
| `rules.truncateLineAt`     | níl         | Teorainn charachtar Unicode-shábháilte in aghaidh na líne                              |
| `rules.maxLines`           | níl         | Uasmhéid línte a choinnítear sula gcaomhnaítear an t-eireaball                         |
| `rules.headLines`          | níl         | Línte cinn a choinnítear le linn teasctha                                              |
| `rules.tailLines`          | níl         | Línte eireabaill a choinnítear le haghaidh comhthéacs le déanaí                        |
| `rules.onEmpty`            | níl         | Teachtaireacht chúltaca nuair a bhaineann an scagadh an t-ábhar ar fad                 |
| `rules.filterStderr`       | níl         | Normalaigh réimíreanna coitianta stderr roimh chéimeanna scagtha níos déanaí           |
| `preserve.errorPatterns`   | níl         | Línte earráide ar cheart dóibh teacht slán ón teasctha                                 |
| `preserve.summaryPatterns` | níl         | Línte achoimre ar cheart dóibh teacht slán ón teasctha                                 |
| `tests[]`                  | níl         | Samplaí fíoraithe inlíne a úsáideann geata fíoraithe RTK                               |

Cuireann RTK céimeanna dearbhaitheacha i bhfeidhm san ord seo: `stripAnsi`, `filterStderr`, `replace`,
`matchOutput`, `dropPatterns`/`includePatterns`, `truncateLineAt`, `headLines`/`tailLines`,
`maxLines`, agus `onEmpty`.

Is féidir scagairí saincheaptha a lódáil ó:

1. Chomhaid tionscadail `.rtk/filters.json`, ach amháin tar éis hais `.rtk/trust.json` meaitseála a bheith ann nó
   `trustProjectFilters` a bheith cumasaithe.
2. `DATA_DIR/rtk/filters.json` domhanda.
3. Scagairí ionsuite.

Féadfaidh réad scagaire amháin nó eagar réad scagaire a bheith i gcomhaid saincheaptha tionscadail/dhomhanda. Déantar scagairí
saincheaptha neamhbhailí a scipeáil le diagnóisic; teipeann ar bhailíochtú i gcás scagairí ionsuite neamhbhailí.

Comhad iontaoibhe an tionscadail:

```json
{
  "filtersSha256": "0123456789abcdef..."
}
```

Cuireann an sárú timpeallachta `OMNIROUTE_RTK_TRUST_PROJECT_FILTERS=1` muinín i scagairí tionscadail gan
hais agus níor cheart é a úsáid ach amháin i bhforbairt áitiúil rialaithe.

## Rialacha Sábháilteachta

- Coinnigh na rialacha idé-phóitéinsiúil: níor cheart go ndéanfadh rith an scagaire chéanna faoi dhó an t-aschur a thruailliú.
- Caomhnaigh téacs cruinn earráidí, conairí comhaid, uimhreacha línte agus achoimrí orduithe nuair is féidir.
- Seachain rialacha a athraíonn bloic chóid, pálastaí JSON, URLanna nó rúin.
- Cuir clúdach aonad le haghaidh teaghlaigh nua orduithe sna tástálacha braiteora/scagaire.
- Cuir samplaí `tests[]` le gach scagaire ionsuite agus le scagairí comhroinnte saincheaptha.

## Bailíochtú

Déantar pacáistí rialacha a bhailíochtú sula n-úsáidtear iad. Teipeann pacáistí ionsuite Caveman agus scagairí ionsuite RTK láithreach
le linn bailíochtaithe ionas go n-aimsítear sócmhainní eisiúna briste roimh a seoladh. Déantar scagairí saincheaptha RTK a
scipeáil agus faisnéis dhiagnóiseach a thabhairt nuair a theipeann ar pharsáil nó ar bhailíochtú iontaoibhe.

Bailíochtú dírithe:

```bash
node --import tsx/esm --test tests/unit/compression/rule-loader.test.ts tests/unit/compression/language-packs.test.ts
node --import tsx/esm --test tests/unit/compression/rtk-verify.test.ts tests/unit/compression/rtk-dsl-pipeline.test.ts
```
