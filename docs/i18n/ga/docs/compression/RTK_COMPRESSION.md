Is é comhbhrú RTK inneall comhbhrúcháin OmniRoute atá feasach ar orduithe le haghaidh aschur teirminéil agus uirlisí. Tá sé
deartha do sheisiúin oibreán códaithe ina dtagann formhór an fháis comhthéacs ó logaí tástála, aschur tiomsaithe,
torann ó bhainisteoirí pacáistí, tras-scríbhinní blaosc, aschur Docker, aschur git, agus rianta cruaiche.

Is féidir RTK a rith go díreach le `defaultMode: "rtk"` nó mar an chéad chéim i bpíblíne chruachta, mar seo de ghnáth:

```txt
rtk -> caveman
```

Comhbhrúnn an t-ord sin aschur torannach meaisín ar dtús, agus ansin ligeann sé do Caveman an prós atá fágtha a chomhdhlúthú.

Tuairiscíonn RTK réamhtheachtach coigilteas `60-90%` ar aschur orduithe. Téann an seisiún samplach ina README ó
`~118,000` comhartha caighdeánach go `~23,900` comhartha RTK, is é sin coigilteas `79.7%` (`~80%`). Úsáideann OmniRoute
an meán réamhtheachtach sin chun an coigilteas cruachta a ríomh le comhbhrú ionchuir Caveman:

```txt
Meán RTK:       coigilteas 80%
Ionchur Caveman: coigilteas 46%
Cruachta:       1 - (1 - 0.80) * (1 - 0.46) = coigilteas 89.2%
Raon:           1 - (1 - 0.60..0.90) * (1 - 0.46) = coigilteas 78.4-94.6%
```

nach leor aicme ordaithe.

## Réiteach Scagairí

Lódálann RTK scagairí san ord seo:

1. Scagairí tionscadail ó `.rtk/filters.toml` agus `.rtk/filters.json`, nuair a bhíonn siad iontaofa amháin.
2. Scagairí domhanda ó `DATA_DIR/rtk/filters.toml` agus `DATA_DIR/rtk/filters.json`.
3. Scagairí ionsuite ó `open-sse/services/compression/engines/rtk/filters/`.

Laistigh den scóip chéanna, tugtar tús áite do scagairí TOML scéimre v1 RTK thar scagairí JSON OmniRoute. Seiceáiltear
sloinn TOML `match_command` roimh mheaitseáil de réir cineál ordaithe ionas gur féidir le scagaire iompórtáilte a bhaineann
go sonrach le hordú dul in ionad scagaire níos leithne sa scóip sin. Tugtar tús áite fós do scóip an tionscadail thar an scóip
dhomhanda, beag beann ar fhormáid an chomhaid.

Tá geata iontaoibhe ar scagairí tionscadail d'aon ghnó toisc gur féidir le scagairí slonn ionadaíochta an chaoi a dtaispeántar
aschur uirlisí d'oibreáin a athrú. Glactar le comhad scagaire tionscadail nuair atá ceann díobh seo fíor:

- Tá `rtkConfig.trustProjectFilters` socraithe mar `true`.
- Tá `OMNIROUTE_RTK_TRUST_PROJECT_FILTERS=1` socraithe.
- Tá an hais SHA-256 comhoiriúnach don chomhad scagaire tionscadail in `.rtk/trust.json`.

Sampla de chomhad iontaoibhe:

```json
{
  "filtersSha256": "0123456789abcdef...",
  "filtersTomlSha256": "fedcba9876543210..."
}
```

Tá na haiseanna ar leithligh: cuireann `filtersSha256` muinín in `.rtk/filters.json`, agus cuireann `filtersTomlSha256`
muinín in `.rtk/filters.toml`. Má chuirtear ceachtar comhad in eagar, ní dhéantar ach a iontráil iontaoibhe féin a neamhbhailíochtú. Suiteálann
riarthóirí comhaid dhomhanda agus úsáideann siad iompar iontaoibhe reatha na scagairí domhanda.

Is féidir le scagairí saincheaptha a bheith ina réad scagaire amháin nó ina n-eagar de réada scagaire. Déantar scagairí saincheaptha
neamhbhailí a scipeáil agus a thuairisciú i ndiagnóisic `/api/context/rtk/filters`. Teipeann scagairí ionsuite neamhbhailí láithreach.

## Comhoiriúnacht le scéimre TOML RTK v1

Is féidir le OmniRoute comhaid scagaire dhearbhaitheacha a pharsáil, a bhailíochtú, a thástáil agus a shuiteáil trí scéimre TOML RTK v1 a úsáid.
Is iad na réimsí a dtacaítear leo ná `description`, `match_command`, `strip_ansi`, `filter_stderr`,
`strip_lines_matching`, `keep_lines_matching`, `replace`, `match_output`, `truncate_lines_at`,
`head_lines`, `tail_lines`, `max_lines`, `on_empty`, agus tástálacha inlíne `[[tests.<filter>]]`.
Diúltaítear do réimsí anaithnide, do shloinn ionadaíochta neamhbhailí nó neamhshábháilte, do rialacha lomtha/coimeádta comhuaineacha, do chomhaid os cionn
1 MiB, agus do thagairtí do scagairí anaithnide. Is féidir comhad a dteipeann ar a thástálacha inlíne
a bhailíochtú lena iniúchadh, ach ní féidir é a shuiteáil ná a luchtú. Fanann teipeanna luchtaithe comhad saincheaptha
oscailte ar theip: déantar an comhad neamhbhailí a scipeáil agus leanann na scagairí eile de bheith ag obair.

Faigheann OmniRoute aschur na huirlise tar éis don chliant é a ghabháil cheana féin, mar sin ní féidir le `filter_stderr = true`
gabháil an phróisis a athrú. Glactar leis an réimse mar neamh-oibríocht agus tugann an bhailíochtú rabhadh ar ais.
Déantar cur síos air seo d’aon ghnó mar **chomhoiriúnacht le scéimre TOML RTK v1**, seachas mar chomhoiriúnacht iomlán
le comhad inrite RTK, crúcaí blaoisce, feidhmiúcháin orduithe Rust, nó leagan amach a stór iontaoibhe.

Glacann amharc ardleibhéil RTK an deais le TOML greamaithe nó uaslódáilte. Is inléite amháin atá an bhailíochtú.
Scríobhann an tsuiteáil `DATA_DIR/rtk/filters.toml` go hadamhach le ceadanna sriantacha agus athnuachan sí
catalóg bheo na scagairí gan atosú. Chun comhad atá ann cheana a ionadú, teastaíonn deimhniú sainráite `overwrite`
agus cruthaítear `DATA_DIR/rtk/filters.toml.bak` ar dtús.

## DSL scagairí

Úsáideann scagairí an scéimre JSON a ndéantar cur síos air in [Formáid na Rialacha Comhbhrúite](./COMPRESSION_RULES_FORMAT.md).
Cuireann an córas rite na céimeanna seo i bhfeidhm san ord seo:

```txt
stripAnsi -> filterStderr -> replace -> matchOutput -> línte a ligean ar lár/a chur san áireamh
  -> truncateLineAt -> head/tail/maxLines -> onEmpty
```

Réimsí tábhachtacha:

| Réimse                       | Cuspóir                                                                          |
| ---------------------------- | -------------------------------------------------------------------------------- |
| `rules.stripAnsi`            | Seichimh datha/rialaithe teirminéil a bhaint roimh mheaitseáil                   |
| `rules.filterStderr`         | Réimíreanna coitianta stderr a normalú roimh mheaitseáil/scagadh                 |
| `rules.replace`              | Ionaduithe sloinn ionadaíochta ordaithe a chur i bhfeidhm                        |
| `rules.matchOutput`          | Achoimre dhlúth a thabhairt ar ais nuair a mheaitseálann aschur riocht aitheanta |
| `rules.matchOutput[].unless` | An t-aicearra a scipeáil nuair atá patrún earráide/teipe ann                     |
| `rules.dropPatterns`         | Línte torannacha a bhaint                                                        |
| `rules.includePatterns`      | Tús áite a thabhairt do línte inghníomhaithe                                     |
| `rules.collapsePatterns`     | Línte meaitseála athdhéanta a chomhfhilleadh                                     |
| `rules.deduplicate`          | Rogha an scagaire: línte dúblacha comhleanúnacha a chomhfhilleadh                |
| `rules.truncateLineAt`       | Teascadh sábháilte Unicode de réir líne                                          |
| `rules.onEmpty`              | Teachtaireacht chúltaca má scagtar amach gach líne                               |
| `tests[]`                    | Samplaí inlíne a úsáideann an geata fíoraithe                                    |

Táthar ag súil go mbeidh samplaí inlíne `tests[]` i scagairí ionsuite. Ba cheart iad a bheith i scagairí saincheaptha
freisin, go háirithe nuair a roinntear iad idir tionscadail.

## Dídhúbailt Línte (dhá shraith)

Laghdaíonn RTK línte dúblacha ag dhá shraith neamhspleácha:

1. **`deduplicate` in aghaidh an scagaire (roghnach, `false` de réir réamhshocraithe).** Is féidir le scagaire `rules.deduplicate: true` a shocrú
   chun línte dúblacha comhleanúnacha a laghdú _laistigh d'aschur meaitseáilte an scagaire sin_, roimh theascadh.
   Ritheann sé seo laistigh de `lineFilter.ts`. I gcás scagairí oidhreachta, cumasaítear go huathoibríoch é nuair a shainíonn an scagaire
   `collapsePatterns`. Scéimre: `deduplicate: z.boolean().default(false)` in
   `open-sse/services/compression/engines/rtk/filterSchema.ts`.
2. **`deduplicateThreshold` ar fud an innill (`3` de réir réamhshocraithe).** Tar éis do na scagairí uile rith, laghdaíonn an t-inneall
   aon seicheamh de `>= deduplicateThreshold` líne chomhionanna chomhleanúnacha ar fud an toraidh iomláin
   (`deduplicateRepeatedLines`, curtha i bhfeidhm in `engines/rtk/index.ts`). Cuirtear teorainn 2–100 leis an luach le linn
   normalaithe.

Ritheann an chéim in aghaidh an scagaire ar dtús (laistigh den scagaire), agus ritheann an chéim ar fud an innill ar deireadh (thar an aschur
ceangailte), mar sin oibríonn an dá cheann le chéile gan comhaireamh dúbailte.

## Grúpáil Línte (`enableGrouping`)

Nuair atá `rtkConfig.enableGrouping` socraithe mar `true` (`false` de réir réamhshocraithe), ritheann RTK céim bhreise `groupSimilarLines`
thar an toradh iar-dhídhúbailte, céim a laghdaíonn seichimh de línte comhleanúnacha atá _beagnach coibhéiseach_ (nach ionann iad beart ar bheart).
Is é `rtkConfig.groupingThreshold` (`3` de réir réamhshocraithe) an fad íosta seichimh a spreagann
grúpáil. Is é seo an comhchuid struchtúrach de `deduplicateThreshold`: láimhseálann dídhúbailt athrá beacht,
agus láimhseálann grúpáil "an cruth céanna le difríochtaí beaga". Tá an dá bhratach mar chuid den JSON `rtkConfig`
a choimeádtar sa tábla `key_value` (féach Cumraíocht thuas), mar sin maireann an socrú tar éis atosuithe.

## Nótaí Cóid a Bhaint (`stripCodeComments` / `preserveDocstrings`)

Nuair atá `rtkConfig.applyToCodeBlocks` cumasaithe, is féidir le RTK nótaí a bhaint as bloic chóid fhálaithe freisin:

- `stripCodeComments` (`false` de réir réamhshocraithe) — roghnach. Nuair atá sé `true`, baineann RTK nótaí as bloic fhálaithe JavaScript
  agus TypeScript. Go stairiúil, léití an bhratach ach níor cuireadh i bhfeidhm riamh í, mar sin fanann an réamhshocrú
  ag "caomhnaigh" chun athrú táirgthe ciúin a sheachaint.
- `preserveDocstrings` (`true` de réir réamhshocraithe) — agus nótaí á mbaint, coimeádtar blocnótaí JSDoc/`/** … */`
  (tá doiciméadú API iontu ar fiú níos mó é ná costas na mbeart). Socraigh mar `false` é chun
  iad sin a bhaint freisin.

Cuirtear baint nótaí i bhfeidhm in `open-sse/services/compression/engines/rtk/codeStripper.ts`. Úsáideann sé
an **parsálaí TypeScript** (ní slonn ionadaíochta) ionas nach nglactar trí dhearmad riamh le teaghráin, teimpléid ná teaghráin rialta
mar nótaí, agus stopann sé go hiomlán nuair a bhraitear JSX (ionas nach ndéantar truailliú riamh ar nótaí i gcoimeádáin slonn JSX).
Faoi láthair, ní bhaineann baint nótaí ach le **JavaScript agus TypeScript** — bíonn laghdú línte folmha agus
spás bán ag teangacha eile i dtacar `CodeLanguage` an bhaintóra (Python, Rust, Go, Ruby, Java), ach ní bhaintear nótaí astu. Cuirtear an chlib `rtk:code-strip` ar rith an bhloic bhainte in
`rulesApplied`.

> **Nóta — is inneall ar leith é GCF / ionchódú táblach.** Ní chuimsíonn RTK an t-ionchódóir JSON táblach/colúnach "GCF"
> (Graph Compact Format). Tá an t-ionchódóir sin — a tháinig in ionad ionchódóra `omni-tabular` níos sine — san inneall **headroom**
> (`open-sse/services/compression/engines/headroom/`, agus an codec cuachta faoi
> `headroom/gcf/`). Níl aon bhaint aige le píblíne scagtha RTK atá doiciméadaithe anseo.

## Cumraíocht

Tá socruithe domhanda ar fáil trí `/api/settings/compression`. Tá socruithe a bhaineann go sonrach le RTK
ar fáil freisin trí `/api/context/rtk/config`.

```json
{
  "defaultMode": "stacked",
  "autoTriggerMode": "stacked",
  "autoTriggerTokens": 32000,
  "stackedPipeline": [
    { "engine": "rtk", "intensity": "standard" },
    { "engine": "caveman", "intensity": "full" }
  ],
  "rtkConfig": {
    "enabled": true,
    "intensity": "standard",
    "applyToToolResults": true,
    "applyToCodeBlocks": false,
    "applyToAssistantMessages": false,
    "enabledFilters": [],
    "disabledFilters": [],
    "maxLinesPerResult": 120,
    "maxCharsPerResult": 12000,
    "deduplicateThreshold": 3,
    "customFiltersEnabled": true,
    "trustProjectFilters": false,
    "rawOutputRetention": "never",
    "rawOutputMaxBytes": 1048576,
    "enableGrouping": false,
    "groupingThreshold": 3,
    "stripCodeComments": false,
    "preserveDocstrings": true
  }
}
```

Úsáideann `enabledFilters` agus `disabledFilters` aitheantais scagairí, mar shampla `test-vitest` nó `git-diff`.

Sainítear cruth iomlán `rtkConfig` le `RtkConfig` / `DEFAULT_RTK_CONFIG` in
`open-sse/services/compression/types.ts`. Déantar an réad iomlán a bhuanú mar luach JSON aonair sa tábla SQLite
`key_value` faoi `namespace = "compression"`, `key = "rtkConfig"`
(`src/lib/db/compression.ts`), agus normalú á dhéanamh air tráth léite ag `normalizeRtkConfig`. Mar sin, téann gach réimse thíos
— lena n-áirítear `enableGrouping`, `groupingThreshold`, `stripCodeComments`, agus `preserveDocstrings` —
tríd an stór céanna sa dá threo agus maireann sé tar éis atosaithe.

| Eochair                | Réamhshocrú | Cuspóir                                                                                                |
| ---------------------- | ----------- | ------------------------------------------------------------------------------------------------------ |
| `deduplicateThreshold` | `3`         | Ar fud an innill: íoslíon línte comhionanna i ndiaidh a chéile lena gcomhfhilleadh (teoranta do 2–100) |
| `enableGrouping`       | `false`     | Rogha isteach: comhfhill sraitheanna de línte i ndiaidh a chéile atá beagnach coibhéiseach             |
| `groupingThreshold`    | `3`         | Íoslíon línte comhchosúla i ndiaidh a chéile a spreagann grúpáil                                       |
| `stripCodeComments`    | `false`     | Rogha isteach: bain nótaí tráchta de bhloic chóid fhálaithe (`applyToCodeBlocks` de dhíth)             |
| `preserveDocstrings`   | `true`      | Agus nótaí tráchta á mbaint, coinnigh bloic JSDoc/`/** … */`                                           |

Ualach tástála RTK:

```json
{
  "command": "npm test",
  "text": "FAIL tests/example.test.ts\nAssertionError: expected true\nTest Files 1 failed",
  "config": {
    "intensity": "standard"
  }
}
```

Ualach réamhamhairc comhbhrúcháin:

```json
{
  "mode": "stacked",
  "messages": [
    {
      "role": "tool",
      "content": "FAIL tests/example.test.ts\nAssertionError: expected true\nTest Files 1 failed"
    }
  ],
  "config": {
    "rtkConfig": {
      "rawOutputRetention": "failures"
    }
  }
}
```

Éilíonn bealaí bainistíochta fíordheimhniú bainistíochta an deais nó an polasaí API-eochrach comhfhreagrach.

Ualach bailíochtaithe RTK TOML:

```json
{
  "action": "validate",
  "content": "schema_version = 1\n\n[filters.my-tool]\nmatch_command = \"^my-tool\\\\b\"\nmax_lines = 20\n"
}
```

Úsáid `"action": "install"` chun an comhad bailíochtaithe a shuiteáil go domhanda. Ná cuir `"overwrite": true` leis ach amháin
tar éis duit athbhreithniú a dhéanamh ar chomhad domhanda atá ann cheana agus a ionadú a dheimhniú.

## Aisghabháil Aschuir Amh

De ghnáth, ní fhilleann RTK ach téacs comhbhrúite. Chun dífhabhtú a dhéanamh, is féidir le `rawOutputRetention` aschur amh folaithe a choinneáil:

| Luach      | Iompar                                                     |
| ---------- | ---------------------------------------------------------- |
| `never`    | Ná coinnigh aschur amh                                     |
| `failures` | Ná coinnigh ach aschur ar dócha gur aschur teipe é         |
| `always`   | Coinnigh gach aschur amh comhbhrúite RTK, tar éis folaithe |

Scríobhtar comhaid choinnithe faoi:

```txt
DATA_DIR/rtk/raw-output/
```

Déantar rúin a fholú sula ndéantar iad a bhuanú, lena n-áirítear comharthaí coitianta iompróra, eochracha API, comharthaí Slack,
eochracha rochtana AWS, agus luachanna ar nós `token=...`, `secret=...`, `password=...` a úsáidtear mar shannacháin. Ní stórálann an anailísíocht
ach aitheantas an phointeora, an méid, agus meiteashonraí an haise.

## Leibhéil Déine (v3.8.16+)

Tacaíonn RTK le **3 leibhéal déine** a dhéanann comhréiteach idir **ionsaitheacht an chomhbhrúite** agus **sábháilteacht**. Socraítear an leibhéal trí `config.intensity` i gcumraíocht an innill.

### Na 3 Leibhéal

| Leibhéal                 | Tairseach teasctha      | Coigilteas comharthaí | Riosca    | Is fearr le haghaidh                   |
| ------------------------ | ----------------------- | --------------------- | --------- | -------------------------------------- |
| `minimal`                | 24 líne in aghaidh ailt | ~20-40%               | An-íseal  | Táirgeadh le comhthéacs ríthábhachtach |
| `standard` (réamhshocrú) | 24 líne in aghaidh ailt | ~50-70%               | Íseal     | Seisiúin laethúla códaithe             |
| `aggressive`             | 16 líne in aghaidh ailt | ~70-90%               | Measartha | Seisiúin fhada, coigilteas uasta       |

### An Áit a dtarlaíonn an Teascadh

Téann tairseach an teasctha i bhfeidhm ar `lineFilter.ts`:

```ts
// Ó open-sse/services/compression/engines/rtk/index.ts:329-330
config.intensity === "aggressive" ? 16 : 24,
config.intensity === "aggressive" ? 16 : 24,
```

Caomhnaítear **ceann** agus **deireadh** gach ailt; caitear amach an t-ábhar sa lár nuair a chuirtear an teascadh i bhfeidhm.

### An Méid a Fhanann i gComparáid leis an Méid a Ghearrtar

| Ábhar                          | minimal        | standard       | aggressive     |
| ------------------------------ | -------------- | -------------- | -------------- |
| Earráidí / loirg chruaiche     | ✅ caomhnaithe | ✅ caomhnaithe | ✅ caomhnaithe |
| Teipeanna tástála              | ✅ caomhnaithe | ✅ caomhnaithe | ✅ caomhnaithe |
| Earráidí tógála                | ✅ caomhnaithe | ✅ caomhnaithe | ✅ caomhnaithe |
| Tástálacha rathúla (foclach)   | ✅ caomhnaithe | 🟡 comhdhlúite | 🟡 comhdhlúite |
| Gnáth-aschur (logaí faisnéise) | 🟡 comhdhlúite | 🟡 comhdhlúite | ❌ caite amach |
| Barraí dul chun cinn           | 🟡 comhdhlúite | ❌ caite amach | ❌ caite amach |
| Meirge / ealaín ASCII          | 🟡 comhdhlúite | ❌ caite amach | ❌ caite amach |

### Scagairí Saincheaptha a Lódáil

Cuir an comhad i suíomh aitheanta:

```

<project>/.rtk/filters/my-filter.json      # Leibhéal an tionscadail
```

Lódáiltear scagairí go huathoibríoch ag am tosaithe trí `loadRtkFilters()` in `open-sse/services/compression/engines/rtk/filterLoader.ts`. Aimsíonn an lódálaí scagairí ó:

- Catalóg ionsuite: `open-sse/services/compression/engines/rtk/filters/`
- Eolaire an úsáideora: `~/.omniroute/rtk/filters/`
- Eolaire an tionscadail: `<project>/.rtk/filters/`

```ts
import { loadRtkFilters } from "@omniroute/open-sse/services/compression/engines/rtk/filterLoader";

// Roghanna: customFiltersEnabled (lódáil scagairí úsáideora/tionscadail, cumasaithe de réir réamhshocraithe),

const filters = loadRtkFilters({ customFiltersEnabled: true });
```

### Bailíochtú

Déantar scagairí a bhailíochtú de réir scéimre Zod agus iad á lódáil. Ní lódálfar scagaire a bhfuil struchtúr mícheart aige agus logálfar earráid:

```
RTK_FILTER_LOADER: filter "my-filter" failed validation:
  - rules.replace.0.pattern: Invalid regex
  - match.commands: must not be empty
```

Chun gach scagaire suiteáilte a bhailíochtú, glaoigh ar `runRtkFilterTests()`, a easpórtáiltear ó `open-sse/services/compression/engines/rtk/verify.ts`.

### Dea-Chleachtais

1. **Cuir `tests[]` san áireamh i gcónaí** — cruthaíonn siad go n-oibríonn do scagaire agus cuireann siad cosc ar aischéimnithe
2. **Úsáid `matchOutput` le haghaidh gearrchiorcaduithe** — más leor líne amháin chun an scéal a insint, cuir í in ionad an bhloic iomláin
3. **Tabhair tús áite do `keep` thar `strip`** — tá rialacha sainráite a deir "caomhnaigh i gcónaí" níos sábháilte ná rialacha a deir "bain i gcónaí"
4. **Déan tástáil ag na 3 leibhéal déine ar fad** — ba cheart do `minimal` gan aon athrú a dhéanamh, agus ba cheart do `aggressive` earráidí a chaomhnú fós
5. **Úsáid an réimse `unless`** — cosain gearrchiorcaduithe le "ná gníomhachtaigh má tá X i láthair"

Nuair a chomhbhrúnn RTK aschur go tréan, is féidir leat **an buntéacs a aisghabháil** le haghaidh dífhabhtaithe, iniúchta nó athsheinnte.

### Conas a Oibríonn Aisghabháil Aschuir Amh

```
Bun-aschur (10K comhartha)
        │
        ▼
Comhbhrú RTK (le rawOutput.enabled=true)
        │
        ├─▶ Aschur comhbhrúite (2K comhartha)  ──▶ chuig LLM
```

### An Geata Fíoraithe

Déanann **Fíorú Scagairí RTK** (`open-sse/services/compression/engines/rtk/verify.ts`) gach scagaire a bhailíochtú i gcoinne a `tests[]` agus cinntíonn sé go mbíonn an t-iompar ceart ag gach ceann de na 3 leibhéal déine.

**Glaoigh ar `runRtkFilterTests()`** chun an fíorú a rith:

```ts
import { runRtkFilterTests } from "open-sse/services/compression/engines/rtk/verify";

const result = runRtkFilterTests();
console.log(`Passed: ${result.outcomes.filter((o) => o.passed).length}`);
console.log(`Failed: ${result.outcomes.filter((o) => !o.passed).length}`);
if (!result.passed) {
  console.error("Filters failed verification");
  result.outcomes
    .filter((o) => !o.passed)
    .forEach((o) => {
      console.error(
        `  - ${o.filterId} / ${o.testName}: expected "${o.expected}", got "${o.actual}"`
      );
    });
}
```

**Na rudaí a bhailíochtaíonn sé**:

1. Lódálann gach scagaire agus éiríonn leis an mbailíochtú scéime
2. Táirgeann gach iontráil `tests[]` an t-aschur a bhfuiltear ag súil leis
3. Is neamh-oibríocht í déine `minimal` (caomhnaíonn sí an buntéacs agus ní chuireann sí ach scagairí struchtúracha i bhfeidhm)
4. Caomhnaíonn déine `aggressive` earráidí, teipeanna tástála agus lorgáin chruach
5. Ní bhíonn an t-aschur comhbhrúite níos mó ná an t-ionchur bunaidh riamh

- Foinse: `open-sse/services/compression/engines/rtk/` (63 comhad, ~70KB)

- **Sula gcumascann tú athrú scagaire** — cinntigh i gcónaí go n-éiríonn leis na tástálacha

- **Go tréimhsiúil le linn monatóireachta** — cosnaíonn sé ar shleamhnú i ndaingneáin tástála
