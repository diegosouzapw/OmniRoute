Is féidir le comhbhrú Caveman pacáistí rialacha teanga ar leith a lódáil de bhreis ar na rialacha Béarla ionsuite.
Coinníonn sé seo an croí-inneall cobhsaí agus ligeann sé do phacáistí Portaingéilise, Spáinnise, Gearmáinise, Fraincise, Iodáilise, Seapáinise agus
do phacáistí teanga amach anseo forbairt go neamhspleách.

## Suíomh

Tá pacáistí teanga lonnaithe faoi:

```txt
open-sse/services/compression/rules/<language>/
```

Pacáistí a sheoltar faoi láthair (fíoraithe i gcoinne inneachar na comhadlainne `rules/`):

| Teanga                      | Comhadlann     | Catagóirí rialacha atá ar fáil                      |
| --------------------------- | -------------- | --------------------------------------------------- |
| Béarla                      | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spáinnis                    | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portaingéilis (an Bhrasaíl) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indinéisis                  | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Iodáilis                    | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Gearmáinis                  | `rules/de/`    | `context`, `filler`, `structural`                   |
| Fraincis                    | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Seapáinis                   | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Nóta maidir le comhionannas:** Tá na 5 chatagóir iomlána sna pacáistí `en`, `es`, `pt-BR`, `id`, agus `it`; seoltar 3 chatagóir le `de`, `fr`, `ja`. Úsáidtear na rialacha ionsuite Béarla go ciúin mar chúltaca do na catagóirí `dedup` agus `ultra` atá ar iarraidh. Fáiltítear roimh rannchuidithe chun `dedup.json` agus `ultra.json` a chur leis na pacáistí beaga.
>
> Tá an pacáiste `pt-BR` bunaithe ar **[Troglodita](https://github.com/leninejunior/troglodita)** le Lenine Júnior — córas comhbhrúite a dearadh ón mbonn aníos do ghramadach Phortaingéilis na Brasaíle (laghdú pléonasma, focail líonta PT-BR a bhaint, giorrúcháin theicniúla do phobal forbróirí na Brasaíle).
>
> Tá liosta údarásach na gcatagóirí agus an scéimre do gach catagóir le fáil in [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (dréacht 2020-12 de JSON Schema).

## Brath Teanga

Úsáideann `languageDetector.ts` heorastachtaí éadroma chun an teanga a thuiscint ó théacs na leide. Tugtar
aird fós ar an teanga réamhshocraithe chumraithe, agus is féidir an brath a dhíchumasú sa chumraíocht nuair a bhíonn
rialú beacht de dhíth.

Ní úsáidtear aschur an bhraite ach chun pacáistí rialacha a roghnú. Ní athraíonn sé ródú soláthraithe, roghnú
logchaighdeáin ná teanga an chomhéadain úsáideora.

## Struchtúr na Cumraíochta

Is féidir na nithe seo a bheith i socruithe comhbhrúite:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

Rialaíonn `languageConfig` na luachanna réamhshocraithe don deais/réamhamharc. Is é `cavemanConfig` cumraíocht an innill ag am rite
a úsáidtear nuair a chomhbhrúnn Caveman téacs teachtaireachta.

## Pacáiste Teanga a Chur Leis

1. Cruthaigh `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Úsáid formáid rialacha Caveman ó `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Bí coimeádach maidir le hionaduithe agus seachain cód, aitheantóirí, URLanna nó JSON a athrú.
4. Cuir tástálacha leis nó nuashonraigh tástálacha maidir le roghnú teanga agus iompar ionadaithe.
5. Cuir lipéid nua deais/i18n ar fáil má bhíonn an teanga le feiceáil i roghnóirí an chomhéadain úsáideora.

## API

Is féidir na pacáistí atá ar fáil a fhiosrú le:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Glacann an críochphointe réamhamhairc le sáruithe cumraíochta teanga:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Fuair gach ceann de na 6 phacáiste teanga clásal `SHARED_BOUNDARIES` in v3.8.0 a chuirtear i bhfeidhm ag gach
déine Caveman (LITE, FULL, ULTRA). Treoraíonn sé don inneall na patrúin seo a chaomhnú focal ar fhocal,
beag beann ar ábhar líonta mórthimpeall a bhaint:

| Cineál patrúin                         | Sampla                                 |
| -------------------------------------- | -------------------------------------- |
| Bloic chóid fhálaithe                  | ` ```python\n...\n``` `                |
| Cód inlíne                             | `` `my_var` ``                         |
| URLanna                                | `https://example.com/path`             |
| Conairí comhaid (dearbh + coibhneasta) | `/etc/hosts`, `./src/index.ts`         |
| Ceanntásca earráide                    | `Error:`, `TypeError:`, `SyntaxError:` |
| Línte rianaithe cruachta               | `  at functionName (file.ts:12:3)`     |

Cuirtear na patrúin seo in `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (`[]` roimhe seo). Tá an
tairiseach suite in `open-sse/services/compression/types.ts`.

### Cén fáth a bhfuil sé seo tábhachtach

Gan SHARED_BOUNDARIES, d'fhéadfadh modhanna ionsaitheacha Caveman ábhar a bhaint a raibh cuma próis
athráigh air ach arbh é blúire cóid, conair comhaid nó cruach earráide a bhí ann i ndáiríre. Feidhmíonn SHARED_BOUNDARIES mar
líontán sábhála neamhspleách ar theanga a chuirtear i bhfeidhm sula ritear rialacha líonta.

### preservePatterns a shaincheapadh

Is féidir patrúin bhreise a chur leis le linn rite trí na socruithe comhbhrúite:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Leathnaíonn patrúin shaincheaptha na 6 réamhshocrú (ní chuirtear ina n-ionad iad).

## Nótaí Oibríochtúla

- Fanann rialacha ionsuite Béarla mar rogha thacach nuair a bhíonn pacáiste teanga ar iarraidh.
- Teipeann ar phacáistí JSON ionsuite neamhbhailí sa bhailíochtú ionas nach ndíghrádóidh sócmhainní eisiúna go ciúin.
- Sonraí amháin atá i bpacáistí rialacha agus níor cheart dóibh cód a iompórtáil ná loighic threallach a rith.
- Taifeadann an tsraith anailísíochta comhbhrúite an modh agus an t-inneall roghnaithe, ní téacs iomlán an leid.
