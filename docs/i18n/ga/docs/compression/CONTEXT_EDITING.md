Is gné bainistíochta comhthéacs do Claude amháin í **Eagarthóireacht Chomhthéacs** tharmligthe. Murab ionann agus innill áitiúla
comhbhrúite OmniRoute (Caveman, RTK, LLMLingua, píblínte cruachta) — a athscríobhann corp na hiarrata
_sula_ bhfágann sé an seachfhreastalaí — iarrann Eagarthóireacht Chomhthéacs ar an **soláthraí** bloic as dáta
úsáide uirlisí / torthaí uirlisí a ghlanadh óna fhuinneog chomhthéacs reatha féin. Ní dhéanann OmniRoute ach paraiméadar coirp
a cheangal (`context_management.edits[]`); déanann Claude an glanadh iarbhír i gcoinne a chomharthóra féin.

Is cumas tarmligthe é seo ó nádúr: diúltaíonn soláthraithe eile don pharaiméadar, mar sin cuireann OmniRoute a raon feidhme
go docht le Claude agus le hathsheachadáin atá comhoiriúnach le Claude Code.

Foinse na fírinne: `open-sse/config/contextEditing.ts` (aitheantais straitéise, instealladh coirp, asbhaint
teiliméadrachta), `open-sse/executors/base.ts` (geata insteallta + cúltiomáint 400), agus
`open-sse/services/compression/types.ts` (cruth na cumraíochta + réamhshocrú).

## Cad a dhéanann `clear_tool_uses`

Insteallann OmniRoute eagarthóireacht amháin isteach i gcorp teachtaireachtaí Anthropic atá ag dul amach:

```json
{
  "context_management": {
    "edits": [
      {
        "type": "clear_tool_uses_20250919",
        "trigger": { "type": "input_tokens", "value": 100000 },
        "keep": { "type": "tool_uses", "value": 3 }
      }
    ]
  }
}
```

- `type: "clear_tool_uses_20250919"` — aitheantas dátaithe straitéise Anthropic (`CLEAR_TOOL_USES_STRATEGY`).
- `trigger.value: 100000` — a luaithe a sháraíonn comharthaí ionchuir na hiarrata an tairseach seo, tosaíonn Claude ag
  glanadh seanphéirí úsáide/torthaí uirlisí (`CONTEXT_EDITING_DEFAULT_TRIGGER_TOKENS`, réamhshocrú Anthropic).
- `keep.value: 3` — coimeádtar na N péire úsáide/torthaí uirlisí is déanaí gan athrú
  (`CONTEXT_EDITING_DEFAULT_KEEP_TOOL_USES`).

Fógraítear an béite tríd an gceanntásc `anthropic-beta: context-management-2025-06-27`, a
astaíonn OmniRoute cheana féin ar iarrataí Claude.

Is é `applyContextEditingToBody()` a dhéanann an t-instealladh agus tá sé **idéimpitéinseach**: má tá eagarthóireacht `clear_tool_uses`
ar an gcorp cheana féin (curtha leis ag glao roimhe seo nó curtha ar fáil ag an gcliant), fágtar an corp
mar atá. Má tá eagarthóireacht `clear_thinking_20251015` ann freisin, déanann OmniRoute sórtáil chobhsaí ar an
eagarthóireacht `clear_thinking` chun í a chur chun tosaigh, toisc go n-éilíonn Anthropic go dtagann `clear_thinking` roimh
`clear_tool_uses` san eagar `edits[]`.

## An scorán cumasaithe de réir teaglaim

Tá Eagarthóireacht Chomhthéacs **múchta de réir réamhshocraithe** agus ní mór roghnú isteach inti. Is Booleach amháin é an scorán a iompraítear sa
chumraíocht chomhbhrúite:

- Eochair socraithe: `contextEditing.enabled` (camelCase — **ní** `context_editing` / `context-editing`).
- Cineál: `ContextEditingConfig { enabled: boolean }` in
  `open-sse/services/compression/types.ts`.
- Réamhshocrú: `DEFAULT_CONTEXT_EDITING_CONFIG = { enabled: false }`.
- Scéimre Zod: `contextEditingConfigSchema` in `src/shared/validation/compressionConfigSchemas.ts`.
- Stóráil: marthanaithe leis an gcuid eile de na socruithe comhbhrúite (normalaithe in
  `src/lib/db/compression.ts`).

Sa deais, tá an scorán sa mhol comhbhrúite
(`src/app/(dashboard)/dashboard/context/combos/CompressionHub.tsx`) agus scríobhann sé
`{ contextEditing: { enabled: … } }` ar ais trí `saveSettings()`. Toisc go dtaistealaíonn sé ar réad na
socruithe comhbhrúite, oibríonn sé i dteannta na próifíle comhbhrúite de réir teaglaim seachas a bheith ina
dhromchla iomlán neamhspleách — ní iompraíonn an chumraíocht ach an bhratach air/as; is iad na tairisigh atá doiciméadaithe thuas na tairseacha uile (`trigger`,
`keep`).

## Geatáil do Claude amháin

Ní tharlaíonn an t-instealladh ach i gcás fíor-Claude nó athsheachadáin atá comhoiriúnach le Claude Code. Seo é an geata in
`open-sse/executors/base.ts`:

```ts
if (
  (this.provider === "claude" || isClaudeCodeCompatible(this.provider)) &&
  contextEditing?.enabled &&
  !contextEditingDisabled
) {
  applyContextEditingToBody(transformedBody, { enabled: true });
}
```

- `this.provider === "claude"` — fíoreochair Anthropic/OAuth.
- `isClaudeCodeCompatible(this.provider)` — athsheachadáin a dtosaíonn a n-aitheantas soláthraí leis an réimír
  `anthropic-compatible-cc-` (fógraíonn siad comhoiriúnacht le Claude Code, mar sin is iad na hathsheachadáin
  is dóichí a ghlacfaidh leis an mbéite). Féach `open-sse/services/provider.ts`.

**Eisiata** d’aon ghnó:

- `claude-web` — athsheachadán brabhsálaí ag a bhfuil cruth iarratais `create_conversation_params` nach bhfeiceann
  `context_management` riamh.
- Athsheachadáin chineálacha `anthropic-compatible-*` (gan an réimír `-cc-`) — críochphointí tríú páirtí a bhfuil
  tacaíocht éiginnte béite acu.

Ní fhaigheann soláthraithe nach Claude iad an paraiméadar `context_management` riamh, fiú nuair atá an lasc scoránaigh casta air.

## An cúltitim 400 / cumhdach athsheachadáin

D’fhéadfadh athsheachadán atá comhoiriúnach le Claude an béite a fhógairt ach an paraiméadar `context_management`
a dhiúltú fós le HTTP 400. Chun díghrádú go stuama seachas teip ar an iarratas, baineann an seiceadóir an
paraiméadar agus atriaileann sé an URL céanna **uair amháin**:

```ts
if (
  response.status === HTTP_STATUS.BAD_REQUEST &&
  contextEditing?.enabled &&
  !contextEditingDisabled &&
  transformedBody?.context_management !== undefined
) {
  const errText = await response
    .clone()
    .text()
    .catch(() => "");
  if (/context[_-]management|context editing/i.test(errText)) {
    contextEditingDisabled = true;
    delete transformedBody.context_management;
    let retryBody = JSON.stringify(transformedBody);
    if (isClaudeCodeCompatible(this.provider) || this.provider === "claude") {
      retryBody = await signRequestBody(retryBody);
    }
    response = await fetch(url, { ...fetchOptions, body: retryBody });
  }
}
```

Iompar:

1. Ní ghníomhaítear é ach ar `400` nuair atá eagarthóireacht comhthéacs cumasaithe agus nuair atá
   `context_management` sa chorp i ndáiríre.
2. Léitear corp an 400 trí `clone()` ionas go bhfanann an bunfhreagra slán don chonair nach meaitseálann.
3. Ní mór don téacs earráide `/context[_-]management|context editing/i` a mheaitseáil — ní ghníomhachtaíonn 400
   neamhghaolmhar (e.g. `max_tokens must be >= 1`) an cúltitim; iomadaítear an bhunearráid.
4. Ar mheaitseáil, socraíonn sé `contextEditingDisabled = true` (rud a choisceann ath-instealladh má chruthaítear
   `transformedBody` úr níos déanaí le haghaidh URL atrialach/cúltitime), scriosann sé `context_management`,
   athshíníonn sé an corp d’athsheachadáin Claude / atá comhoiriúnach le Claude Code (`signRequestBody`), agus atriaileann sé an
   URL céanna uair amháin.

Iompraíonn fíor-Claude an béite in `ANTHROPIC_BETA_BASE` agus ní théann sé tríd an gconair chúltitime seo.

## Teiliméadracht `applied_edits`

Tar éis freagra Claude, taifeadann OmniRoute an méid comhthéacs a ghlan an soláthraí i ndáiríre. **Ní**
shruthaítear é seo — baintear as corp an fhreagra neamhshruthaithe é, ar bhonn na hiarrachta is fearr, agus ní
imríonn sé tionchar ar an bhfreagra riamh (slogtar teipeanna teiliméadrachta).

- Eastóscadh: `extractContextEditingTelemetry(responseBody)` in `open-sse/config/contextEditing.ts`.
  Scrúdaíonn sé `applied_edits` i dtrí shuíomh (go cosantach mar gheall ar chruth an fhreagra):
  - `context_management.applied_edits`
  - `usage.context_management.applied_edits`
  - `usage.applied_edits`
- Réimsí in aghaidh na heagarthóireachta a léitear ó gach iontráil: `cleared_input_tokens` agus `cleared_tool_uses`
  (snake_case, dúchasach do Anthropic), le `clearedInputTokens` / `clearedToolUses` mar chúltitimí camelCase.
- Filleann sé `null` nuair nach bhfaightear aon eagar `applied_edits` nó nuair nár glanadh aon rud i ndáiríre.

Is é cruth na hadmhála `ContextEditingTelemetry { editCount, clearedInputTokens, clearedToolUses }`.
Déantar an taifeadadh in `open-sse/handlers/chatCore.ts` (geataithe do `provider === "claude"`) trí
`recordContextEditingTelemetry()` (`src/lib/db/compressionAnalytics.ts`), a scríobhann ró anailísíochta
comhbhrúite ar a bhfuil na clibeanna:

- `mode: "context-editing"`
- `engine: "context-editing"`
- `tokens_saved` / `original_tokens` = líon na dtócan ionchuir a glanadh
- `request_id` agus `::context-editing` mar iarmhír air

Mar sin, taispeántar glanadh tarmligthe san anailísíocht chomhbhrúite in éineacht leis na hinnill áitiúla, faoin
lipéad innill `context-editing`, agus is féidir é a idirdhealú ó choigilteas RTK/Caveman/LLMLingua.

## An gaol leis na hinnill chomhbhrúite áitiúla

| Gné                         | Innill áitiúla (Caveman / RTK / LLMLingua / cruachta)         | Eagarthóireacht Chomhthéacsach Tharmligthe            |
| --------------------------- | ------------------------------------------------------------- | ----------------------------------------------------- |
| Cá ritheann sé              | In OmniRoute, sula bhfágann an t-iarratas an seachfhreastalaí | Sa soláthraí (Claude), ar thaobh an fhreastalaí       |
| Cad a chuireann sé in eagar | Téacs leid / comhthéacs / toradh uirlise                      | Seanbhloic úsáide uirlise / torthaí uirlise           |
| Raon feidhme soláthraithe   | Gach soláthraí                                                | `claude` + `anthropic-compatible-cc-*` amháin         |
| Scorán                      | Socruithe mód comhbhrúite                                     | `contextEditing.enabled`                              |
| Mód teipe                   | Leanúint ar aghaidh ar theip (an buntéacs)                    | Cúltaca 400: bain an paraiméadar, atriail uair amháin |
| Teiliméadracht choigiltis   | `engine: <engine id>`                                         | `engine: "context-editing"`                           |

Comhlánaíonn an dá cheann a chéile: comhbhrúnn na hinnill áitiúla na bearta a sheolann OmniRoute; ligeann Eagarthóireacht Chomhthéacsach do
Claude an comhthéacs reatha a bhearradh thar sealanna. Is féidir iad a chumasú le chéile.
