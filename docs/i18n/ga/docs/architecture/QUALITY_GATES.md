Is é an doiciméad seo an tagairt údarásach do gach geata cáilíochta CI in OmniRoute.
Déantar cur síos ann ar gach geata, ar a bhfíoraíonn sé, ar an jab CI ina ritear é, ar cé acu a úsáideann sé
bonnlíne raicéid nó polasaí pas/teip, agus ar cé acu a chuireann sé bac ar an tógáil nó atá sé comhairleach.

Le haghaidh achoimre ghairid agus pholasaí an liosta ceadaithe, féach an rannán "Geataí Cáilíochta & Raicéid"
in `AGENTS.md`. Le haghaidh an mheasúnaithe chriticiúil, an aicmithe aibíochta, agus an phlean macasamhlaithe
neamhspleách ar uirlisí don chóras céanna, féach an
[Leabhar Súgartha do Gheataí Cáilíochta](../ops/QUALITY_GATE_PLAYBOOK.md).

## Fardal Geataí (~90 script)

Tá na scripteanna faoi `scripts/check/` (geataí beartais) agus `scripts/quality/` (inneall raicéid).
Is é `.github/workflows/ci.yml` foinse fhírinne an CI.

### Mearchosán PR eisiúna (`quality.yml`)

Ritheann `.github/workflows/quality.yml` ar PRanna a dhíríonn ar `release/**`. Coinníonn sé brainsí rannchuiditheoirí
ag gluaiseacht le geataí tapa scagtha de réir cosáin, chomh maith le comhartha comhairleach amháin maidir le tógáil táirgeachta le haghaidh athruithe
cóid:

#### Tuairisc ar thástálacha siblín dearmadta

Athúsáideann `npm run check:forgotten-sibling-tests` an réiteoir allmhairithe taobh thiar den léarscáil tionchair tástála.
I gcás gach modúil táirgeachta athraithe, tuairiscíonn sé slabhraí cinntitheacha
`changed module/symbol -> static consumer -> candidate sibling test` nuair nach bhfuil an tástáil
iarrthach i ndifríocht na hiarrata tarraingthe. Coinnítear an achoimre Markdown agus an toradh JSON mar
dhéantán sreafa oibre `forgotten-sibling-tests` le haghaidh calabrúcháin roimh aon rolladh amach blocála.

Is diagnóisic réitigh amháin iad athonnmhairí bairille agus allmhairí dinimiciúla; ní chruthaíonn siad toradh
blocála riamh. Tá eisceachtaí athbhreithnithe i
`config/quality/forgotten-sibling-allowlist.json`. Ní mór do gach iontráil an tomhaltóir agus an tástáil
iarrthach a ainmniú, réasúnaíocht shonrach a thabhairt, agus nasc a dhéanamh le heisiúint GitHub nó le hiarratas tarraingthe. Teipeann
iontrálacha míchumtha go dúnta. Ní féidir le heisceachtaí tástáil iarrthach scriosta ná difríocht a chuireann `.skip`/`.todo` leis a shochtadh;
is leis an ngeata blocála neamhspleách
`check:test-masking` fós iad lagú dearbhuithe agus cineálacha eile ceilte.

#### `check-ui-value-drift` — geata aistriúchán as dáta

Aimsíonn sé an t-aon aischéimniú i18n nach féidir leis na geataí eile a fheiceáil ó thaobh struchtúir de: athscríobhtar luach Béarla
agus fágtar na haistriúcháin a díorthaíodh ón mBéarla _roimhe seo_ ina ndiaidh, ionas go
léann úsáideoirí nach labhraíonn Béarla téacs atá muiníneach ina fhriotal ach atá mícheart anois.

Tharla sé seo i leagan eisithe i ndáiríre. Athscríobhadh `oauthModal.googleOAuthWarning` nuair a
cuireadh cúntóir logála isteach Antigravity leis (#5203); choinnigh **39 as 43 logchaighdeán** téacs a dúirt le hoibreoirí "an
URL iomlán a chóipeáil agus é a ghreamú thíos" — sreabhadh nach féidir a chur i gcrích don soláthraí sin. Níor
tugadh faoi deara é go dtí #8463 mar:

- ní chuireann `sync-ui-keys` ach eochracha atá **as láthair** isteach mar ais-líonadh, agus ní dhéanann sé amhlaidh riamh d’eochracha atá **as dáta**;
- comhaireann `check-ui-keys-coverage` _láithreacht_ eochrach, mar sin áirítear aistriúchán as dáta mar cheann clúdaithe;
- rianaíonn `check-translation-drift` na scátháin doiciméadachta `docs/i18n/<locale>/**.md` —
  ní léann sé `src/i18n/messages/*.json` riamh. Tá sé blocála i jab `docs-sync-strict` ón
  athshioncronú 2026-09: cuir croídhoiciméad in eagar → `npm run i18n:run -- --files=<doc>` (ar leibhéal na rannóige, saor).

**Feasach ar an diff, gan a bheith bunaithe ar bhonnlíne.** Cuireann sé `en.json` ag an mbonn cumaisc i gcomparáid leis an
gcrann oibre; i gcás gach eochrach ar athraíodh a luach Béarla, tá aon logchaighdeán a bhfuil
aistriúchán gan athrú aige fós as dáta. Déanann sé seo **fiachas atá ann cheana a reo** d’aon ghnó — ní féidir le diff
a nochtadh cén sean-Bhéarla ónar tháinig aistriúchán seanbhunaithe, mar sin ní dhéanann an geata breithiúnas
ach ar a mbaineann an t-athrú reatha leis. Chosnódh an rogha eile (bonnlíne haise in aghaidh na heochrach)
comhad ginte ~600 KB, 3× níos mó ná an bhonnlíne reatha is mó, agus bheadh athruithe leanúnacha ann ar gach PR i18n.

Tá dhá bhealach ann chun é a shásamh:

1. nuashonraigh na haistriúcháin lena mbaineann, nó
2. socraigh iad mar `__MISSING__:<new english>` — soláthraíonn an t-am rite an Béarla ceartaithe ansin
   (`src/i18n/request.ts::deepMergeFallback`, #7258) agus cuirtear an eochair sa scuaine le haistriú.

Má tháinig athrú ar **bhrí** na teaghrán, is fearr **an eochair a athainmniú**: ní féidir le heochair nua
aistriúchán as dáta a fháil le hoidhreacht. Sin é an patrún a d’úsáid #8463.

```bash
npm run i18n:check-value-drift          # dian (an méid a ritheann CI)
npm run i18n:check-value-drift:warn     # tuairisc amháin
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Scoireann sé le 0 agus `SKIP reason=base-unresolved` nuair nach féidir an bhunchatalóg a léamh (clón éadomhain
gan tagairt an bhoinn), ar aon dul le `check-openapi-breaking`.

### Raicín CodeQL: minicíocht athnuachana agus truicear láimhe

Léann `check:codeql-ratchet` **staid an stórtha, a athnuaitear de réir sceidil — ní do gach PR.**
Tuairiscíonn `gh api repos/diegosouzapw/OmniRoute/code-scanning/default-setup`
`state: configured`, `schedule: weekly`: scanadh socraithe réamhshocraithe GitHub, ní anailís
do gach brú. Dá thoradh sin: tar éis PR a DHEISÍONN foláirimh a chumasc, leanann an raicín air ag léamh
an tseanchomhaireamh níos airde go dtí go ritear an chéad scanadh sceidealaithe eile — mar sin tuairiscíonn sé cúlú
ar gach PR oscailte, lena n-áirítear PRanna leantacha an PR deisiúcháin féin, go dtí go dtagann an scanadh suas leis.

**Athnuachan láimhe**: ritheann `gh workflow run codeql.yml --ref release/vX.Y.Z` an
anailís arís agus athfhoilsíonn sé foláirimh laistigh de nóiméid. Léigh `.github/workflows/codeql.yml`
ar dtús — mínítear ina cheanntásc gur `workflow_dispatch`-amháin atá ann **toisc go dtagann sé salach ar
“shocrú réamhshocraithe” GitHub** (`CodeQL analyses from advanced configurations cannot be
processed when the default setup is enabled`). Chun truicir `push`/`pull_request`/
`schedule` a athbhunú, teastaíonn **gníomh ón úinéir ar dtús**: Socruithe → Slándáil cóid →
CodeQL: Réamhshocrú → Ardleibhéal. Ná cuir truicear `schedule:` leis gan an lasc sin — ní
chruthóidh sé ach rití a dteipeann orthu.

**Teannaigh an bhunlíne tar éis don chomhaireamh titim** — scríobhann `node scripts/check/check-codeql-ratchet.mjs
--update` an comhaireamh nua tomhaiste isteach in `quality-baseline.json` →
`metrics.codeqlAlerts.value`, ionas nach gceadóidh an raicín go ciúin cúlú ar ais
go dtí an seanuasteorainn. Sampla oibrithe (2026-09-02/03): dheisigh PR #12502 7 bhfíorfholáireamh
(13 → 6 cinn oscailte arna dtomhas); theannaigh PR #12530 an bhunlíne reoite ó 11 → 6 chun teacht leis; díbríodh
na 6 cinn eile ansin le bonn cirt ar leith do gach foláireamh, síos go 0 cinn oscailte.

**Is é cinneadh an oibreora iad na díbirtí (Riail Dhocht #14)** — ná díbir foláireamh CodeQL riamh
gan an bonn cirt teicniúil a thaifeadadh sa nóta díbeartha: `won't fix` i gcás
riachtanas prótacail réamhtheachtaigh, `used in tests` i gcás daingneáin tástála, `false positive`
i gcás díghalrán nach féidir le CodeQL a fheiceáil (fasach: `docs/security/ERROR_SANITIZATION.md`).

## Laghduithe Raicín a Chur i dTaisce — an treo anuas (#8584)

Níl an raicín ach leath-uathoibríoch, agus is é an leath mícheart é. Is eagarthóireacht láimhe JSON é **uasteorainn a ardú**
a thógann deich soicind agus is é an bealach is tapúla é chun PR teipthe a dhíbhlocáil.
Chun ceann a **ísliú**, ní mór do dhuine `--update` a rith agus an toradh a chur i dtiomantas — agus go dtí
gur cuireadh an jab `bank-ratchet-shrinks` i bhfeidhm, níor rith aon sreabhadh oibre é. An iarmhairt thomhaiste
(2026-07-25): 18 gcomhad reoite a bhí cheana féin ag nó faoi bhun na huasteorann 800 líne do chomhad nua, an ceann is measa
ag 132× (`src/shared/validation/schemas.ts`, 19 líne agus uasteorainn 2,523 aige); d'ardaigh
uasteorainn na castachta `1794 → 2169` thar ~37 nóta athbhunaithe bunlíne agus laghdú amháin go díreach
(−1); agus scríobhadh "teannaigh trí `--update` sa chéad timthriall eile" 31 uair agus cloíodh leis
uair amháin. Déanann uasteorainn a mhaireann níos faide ná an cód a thuill í lamháltas fáis go ciúin de gach
dí-chomhdhéanamh críochnaithe don chéad duine eile a chuireann an comhad in eagar.

Dúnann `nightly-release-green.yml` → jab **`bank-ratchet-shrinks`** an lúb sin:

|             |                                                                                                                             |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Ritheann ar | `schedule` (3×/lá) + `workflow_dispatch` — **ní** `push`, d'aon ghnó                                                        |
| Tomhaiseann | an `release/vX.Y.Z` is airde, leis an réiteach céanna + cosaint insteallta agus atá ag `release-green`                      |
| Scríobhann  | `check:file-size --update` agus `check:complexity-ratchets --update` (ní dhéanann ceachtar acu ach laghdú de réir dearaidh) |
| Fíoraíonn   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                                    |
| Seachadann  | PR amháin atá cothrom le dáta i gcónaí i gcoinne an bhrainse eisiúna — nuashonraithe le fórsa, gan turscar riamh            |

Déantar an cur i dtaisce i mbaisceanna seachas in aghaidh gach brú toisc nach bhfuil aon riachtanas aga folaigh aige (is leor laghdú
a chur i dtaisce laistigh de 8h), ach dhéanfadh rith in aghaidh gach cumaisc brainse an PR a atógáil arís agus arís eile
le linn feachtais chumaisc agus d'íocfadh sé as siúl iomlán ESLint gach uair. Fanann an brath ar
push (`release-green`); ní dhéantar ach an cur i dtaisce i mbaisceanna.

### An fíoraitheoir sábháilteachta

Scríobhann an jab chuig na bunlínte gan mhaoirseacht, mar sin is é `verify-ratchet-bank.mjs` a fhágann
go bhfuil sé sin inghlactha. Déanann sé diff den chrann tar éis `--update` i gcoinne `HEAD` agus **tobscoireann sé an jab
sula mbíonn aon tiomantas ann** — gan aon PR a oscailt — mura bhfuil gach athrú ar cheann díobh seo:

- iontráil uimhriúil `frozen` / `testFrozen` **íslithe** nó **bainte**
- `complexity-baseline.json` → `count` **íslithe**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` **íslithe**

Teipeann ar aon rud eile: uimhir a ardú, iontráil a chur leis, `cap`/`testCap` a athrú, nó
nóta `_rebaseline_*` a scriosadh/athscríobh (is iad na nótaí sin an rian iniúchta a mhíníonn cén fáth a bhfuil gach
uasteorainn ann agus stóráiltear iad laistigh den oibiacht `frozen` chéanna leis na hiontrálacha comhaid).
Bheadh bota a d'fhéadfadh uasteorainn a ardú i bhfad níos measa ná an staid reatha. Cosaint ar chúlchéimniú:
`tests/unit/verify-ratchet-bank.test.ts`.

Ní bhrúnn an jab chuig `release/*` riamh — cumascann duine an PR, mar sin ní féidir le droch-thomhas
teacht i bhfeidhm gan athbhreithniú.

## Beartas an Liosta Ceadaithe

Úsáideann gach geata nach féidir leis teip mar gheall ar sháruithe a bhí ann cheana liosta ceadaithe reoite
(m.sh., `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Is é seo an beartas:

**Ceartaigh an bhunchúis; ná húsáid an liosta ceadaithe ach amháin nuair a bhí an sárú ann cheana agus
nach féidir é a cheartú san PR céanna.**

Agus iontráil á cur le liosta ceadaithe:

1. Cuir nóta tráchta san áireamh leis an údar.
2. Déan tagairt don tsaincheist rianaithe (m.sh., `// #3498 — Gné de Chéim 2, gan cur i bhfeidhm fós`).
3. Bain an iontráil san PR céanna a cheartaíonn an sárú — is fabht ann féin é iontráil as dáta nach
   gcuireann sárú gníomhach faoi chois a thuilleadh (cuirfidh forfheidhmiú um iontrálacha as dáta 6A.3
   faoi deara go dteipfidh ar an ngeata mar gheall ar iontráil dhílleachta sa liosta ceadaithe nuair a chuirfear i bhfeidhm é).

Ná cuir iontrálacha le liostaí ceadaithe chun go n-éireoidh le tástálacha níos tapúla. Tugann geata glas le liosta
ceadaithe atá ag fás tuiscint bhréagach ar cháilíocht.

### Nuair a theipeann ar gheata ar do PR

1. **Léigh aschur an gheata go cúramach** — insíonn sé duit go díreach cén comhad nó siombail a sháraigh
   an riail.
2. **Ceartaigh an sárú** — seiceálacha cinntitheacha ar an gcóras comhad iad formhór na ngeataí agus éiríonn leo a luaithe
   atá an cód ceart.
3. **Má bhí an sárú ann cheana** (is é sin, ní tusa a thug isteach é ach clúdaíonn an geata anois
   é): cuir iontráil leis an liosta ceadaithe mar aon le nóta tráchta údaraithe agus saincheist rianaithe.
4. **Más raicín é an geata** (clúdach, rabhaidh ESLint, dúbailt, castacht):
   rinne d'athrú an mhéadracht níos measa. Ceartaigh an bhunfhadhb, nó (go hannamh) rith
   `npm run quality:ratchet -- --update` má tá an t-athrú d'aon ghnó agus má tá meath na méadrachta
   inghlactha — ach mínigh an fáth i gcur síos an PR.
5. Is chun faisnéise iad **geataí comhairleacha** (`continue-on-error: true`) — ní chuireann siad bac ar
   chumasc ach bíonn siad le feiceáil in achoimre CI. Ceartaigh iad mar sin féin.
