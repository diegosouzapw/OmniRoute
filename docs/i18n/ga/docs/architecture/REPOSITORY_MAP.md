## `src/` — Feidhmchlár Next.js

```
src/
├── app/                 # App Router (leathanaigh + bealaí API + leathanaigh stádais + leathanach tuirlingthe)
├── lib/                 # Croíleabharlanna / modúil fearainn (80 fochomhadlann + ~70 comhad barrleibhéil)
├── domain/              # Loighic íon fearainn (inneall polasaí, cúltaca, costas, frithdhúnadh, comboResolver, measúnú)
├── server/              # Modúil don fhreastalaí amháin (píblíne authz, cors, lárearraí fíordheimhnithe) — ní féidir iad a iompórtáil ón gcliant
├── shared/              # Comhroinnte idir an freastalaí agus an cliant nuair atá sé sábháilte (tairisigh, cineálacha, bailíochtú, conarthaí, fóntais)
├── i18n/                # Cumraíocht next-intl + JSON teachtaireachtaí do gach logchaighdeán (42 logchaighdeán)
├── middleware/          # Lárearraí Next.js (saibhriú iarratais, brath logchaighdeáin)
├── mitm/                # Croí seachfhreastalaí MITM: giniúint/suiteáil teastas, láimhseálaithe, spriocanna, cigire, maisc, cur ar aghaidh gan athrú
│   ├── handlers/        # 9 n-aicme láimhseálaithe gníomhairí IDE a shíneann MitmHandlerBase (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # Sraith gabhála tráchta: maolán (fáinne cuimhneacháin), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # Gliú oiriúnaitheora samhlacha (sean-shim)
├── scripts/             # Scripteanna cothabhála laistigh den chrann (m.sh., backfillAggregation)
├── sse/                 # Láimhseálaithe/seirbhísí oidhreachta SSE (chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # Stór oidhreachta sa chuimhne (á scor de réir a chéile i bhfabhar src/lib/db)
├── types/               # Comhaid chomhroinnte cineálacha TS
├── instrumentation.ts   # Crúca teiliméadrachta Next.js (brabhsálaí + imeall)
├── instrumentation-node.ts  # Ionstraimíocht do Node amháin
└── proxy.ts             # Shim iontrála seachfhreastalaí HTTP
```

## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — Lasmuigh den chrann

Coinníonn na heolairí seo, a bhfuil fostríoc rompu, ábhar nach seoltar:

- **`_mono_repo/`** — fothionscadail stairiúla (omnirouteCloud, omnirouteSite, vscode-extension)
- **`_references/`** — clóin inléite amháin de thionscadail ghaolmhara OSS (LiteLLM, 9router, ClawRouter, CLIProxyAPI, modelrelay, new-api, srl.) le haghaidh crostagartha le linn na forbartha
- **`_tasks/`** — comhaid neamhfhoirmiúla rianaithe tascanna de réir eisiúna

Ní áirítear iad in aschur `npm pack`. Féach `.npmignore`.
