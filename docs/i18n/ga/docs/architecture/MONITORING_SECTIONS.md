```

Anailísíocht

Monatóireacht     ← ATHEAGRAITHE (Grúpa B, plean 16)
...
```

## Rannán Costas (nua, leibhéal 1)

Réimír conair: `/dashboard/costs/`

| Mír              | URL                                  | Cur síos                                              |
| ---------------- | ------------------------------------ | ----------------------------------------------------- |
| Forbhreathnú     | `/dashboard/costs`                   | Deais chomhiomlánaithe costas (bogtha ó Anailísíocht) |
| Praghsáil        | `/dashboard/costs/pricing`           | Tábla praghsála de réir samhla                        |
| Buiséad          | `/dashboard/costs/budget`            | Tairseacha buiséid + foláirimh                        |
| Comhroinnt Cuóta | `/dashboard/costs/quota-share`       | Linnte Comhroinnte Cuóta + úsáid                      |
| Cumraíocht Plean | `/dashboard/costs/quota-share/plans` | Sáruithe plean de réir soláthraí                      |

**Réasúnaíocht**: Bhí Praghsáil, Buiséad agus Comhroinnt Cuóta faoi
`Monatóireacht > Paraiméadair Chostas` roimhe seo. Trína mbogadh chuig rannán
tiomnaithe ardleibhéil, is féidir iad a aimsiú gan nascleanúint trí uirlisí
inbhraiteachta.

## Rannán Monatóireachta (atheagraithe)

Tá **Gníomhaíocht ag an mbarr** anois sa rannán Monatóireachta, agus **3 fhoghrúpa** ina diaidh:

```
Monatóireacht
├── Gníomhaíocht             ← Fotha amlíne (mír ardleibhéil)
├── Grúpa Logaí
│   ├── Logaí (uile)
│   ├── Logaí Seachfhreastalaí
│   └── Logaí Consóil
├── Grúpa Iniúchta
│   ├── Loga Iniúchta
│   ├── Iniúchadh MCP
│   └── Iniúchadh A2A
└── Grúpa Córais
    ├── Sláinte
    └── Am Rite
```

### Cad a d’athraigh ón seanstruchtúr

| Roimhe seo                                                                                            | Ina dhiaidh sin                                         |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Gníomhaíocht = cluaisín laistigh de Logaí a léirigh an Loga Iniúchta                                  | Gníomhaíocht = fotha tiomnaithe (`/dashboard/activity`) |
| Grúpa Paraiméadar Costas i Monatóireacht                                                              | Bogtha chuig an rannán Costas                           |
| Liosta comhréidh: Logaí, Gníomhaíocht (logaí), Iniúchadh, Sláinte, Am Rite, Praghsáil, Buiséad, Cuóta | 3 ghrúpa struchtúrtha + rannán tiomnaithe Costas        |

## Gníomhaíocht vs Loga Iniúchta

Tá siad seo ar leithligh anois:

| Toise                        | Gníomhaíocht (`/dashboard/activity`)                        | Loga Iniúchta (`/dashboard/audit`)        |
| ---------------------------- | ----------------------------------------------------------- | ----------------------------------------- |
| **Cuspóir**                  | Fotha imeachtaí don úsáideoir ("cad a tharla le déanaí")    | Loga comhlíontachta / slándála            |
| **Foinse sonraí**            | `GET /api/compliance/audit-log?level=high`                  | `GET /api/compliance/audit-log?level=all` |
| **Formáid**                  | Amlíne, grúpáilte de réir lae, briathra soléite + deilbhíní | Tábla dlúth uimhrithe, 50/leathanach      |
| **Scagairí**                 | Catagóir chineál an imeachta                                | Gníomh, déine, gníomhaí, raon dátaí       |
| **Easpórtáil**               | Níl sí ar fáil                                              | Easpórtáil JSON                           |
| **Scagaire gníomhaí**        | Neamhbhainteach                                             | Inscagtha de réir gníomhaí                |
| **Imeachtaí a thaispeántar** | Gníomhartha ardleibhéil amháin (ceadliosta)                 | Gach imeacht iniúchta                     |

### Ceadliosta Gníomhartha Ardleibhéil

Sainmhínítear é in `src/lib/audit/highLevelActions.ts`. Rialaíonn sé na himeachtaí
a thaispeántar san fhotha Gníomhaíochta. Áirítear sa cheadliosta:

- Imeachtaí soláthraí a chur leis/a bhaint/a thástáil
- Teaglaim a chruthú/a nuashonrú/a scriosadh
- Saolré eochrach API (cruthú, cúlghairm, rothlú)
- Tairseach buiséid bainte amach
- Logáil isteach/amach fíordheimhnithe
- Seisiún gníomhaire néil a chruthú
- Uirlis MCP a chlárú
- Crúca gréasáin a chruthú/a scriosadh
- Athruithe ar linn/plean cuóta (gníomhartha `quota.*`, Grúpa B)
- Imeachtaí ardáin (nuashonrú, imscaradh)
- Scil a shuiteáil/a bhaint

Ní thaispeántar imeachtaí nach bhfuil ar an liosta seo ach amháin sa Loga Iniúchta.

### Gníomh ardleibhéil nua a chur leis

Cuir `src/lib/audit/highLevelActions.ts` in eagar agus cuir teaghrán an ghnímh le
`HIGH_LEVEL_ACTIONS`. Teastaíonn PR chuige seo (is cód é an liosta, ní féidir é
a chumrú sa DB). Is féidir an deilbhín comhfhreagrach a chur le
`src/lib/audit/activityIcons.ts`.

## Atreorú: `/dashboard/logs/activity`

Déantar an tseanchonair `/dashboard/logs/activity` a atreorú go buan (HTTP 308) chuig
`/dashboard/activity` trí `permanentRedirect()` in
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`.

Coinnítear aitheantas oidhreachta an bharra taoibh `logs-activity` in `HIDEABLE_SIDEBAR_ITEM_IDS`
(ach baineadh é ó `SIDEBAR_DEFINITIONS`) chun nach mbrisfear réamhshocruithe úsáideoirí
a dhéanann tagairt don seanaithneantas.

## i18n

Spásanna ainmneacha a chuir Grúpa B leis:

| Eochair spáis ainmneacha | A bhfuil clúdaithe aici                                                                   |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| `sidebar.costsSection`   | Lipéad na rannóige Costas                                                                 |
| `sidebar.activity`       | Mír Gníomhaíochta sa bharra taoibh                                                        |
| `sidebar.logsGroup`      | Lipéad fhoghrúpa na Logaí                                                                 |
| `sidebar.systemGroup`    | Lipéad fhoghrúpa an Chórais                                                               |
| `sidebar.costsOverview`  | Mír fhorbhreathnaithe na gCostas                                                          |
| `activity.*`             | Gach teaghrán ar an leathanach Gníomhaíochta (teideal, briathra, scagairí, staid fholamh) |

Logchaighdeáin foinse na fírinne: `pt-BR` agus `en`. Filleann na 40 logchaighdeán
eile ar Bhéarla trí mheicníocht chúltaca `next-intl` (cumraithe in `src/i18n/config.ts`).
