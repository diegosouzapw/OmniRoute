> Dhá ID nua `auto/*` — `auto/subscription` agus `auto/thrifty`. Ní úsáidtear ceachtar acu ach amháin má
> iarrtar iad: ní dhéantar aon rud a ródú tríothu mura n-iarrann glaoiteoir an ID de réir ainm, agus ní
> athraítear aon linn, straitéis ná réamhshocrú atá ann cheana.

## Cén fáth a bhfuil sé seo ann

Freagraíonn OmniRoute dhá cheist faoi chostas cheana féin, ach ní ceachtar acu an cheist a chuireann formhór na n-oibreoirí.

| Meicníocht atá ann cheana                                | An cheist a fhreagraíonn sí                                              |
| -------------------------------------------------------- | ------------------------------------------------------------------------ |
| `hidePaidModels` (`autoCombo/paidModelFilter.ts`)        | "an bhfuil an tsamhail seo catalógaithe mar shaor in aisce?"             |
| `freeAccessPolicy: "strict"` (`strictZeroCostFilter.ts`) | "an féidir leis an gceangal seo táille a ghearradh orm riamh?"           |
| `quotaPreflight` (`combo/quotaExhaustionCutoff.ts`)      | "an bhfuil an ceangal seo gar dá theorainn?"                             |
| `budgetCap` / `budgetFallback` (`autoCombo/engine.ts`)   | "cuir teorainn leis an gcaiteachas, téigh siar chuig an rogha is saoire" |

**Teipeann dúnta** ar gach meicníocht atá teoranta do roghanna saor in aisce — is linn fholamh í linn shaor in aisce atá ídithe, agus ní
céim suas chuig rogha íoctha í choíche — agus ní dhéanann aon mheicníocht ar thaobh na roghanna íoctha idirdhealú idir sraitheanna. Ní fhreagraíonn ceachtar acu:

> "Úsáid an cuóta a bhfuilim ag íoc as cheana féin. Nuair a ídítear é, stad, nó téigh suas céim amháin
> ag an am trí na roghanna íoctha is saoire — agus fill air a luaithe a athshocraítear é."

## Is fíric faoin gceangal í an bhilleáil, ní fíric faoin tsamhail

Úsáideann `classifyTier()` (`open-sse/services/tierResolver.ts`) `(provider, model)` mar eochair agus tugann sé
`free | cheap | premium` ar ais bunaithe ar phraghsáil na catalóige. Ach braitheann cibé acu a chosnaíonn iarratas airgead breise
ar **an gceangal a fhreastalaíonn air**: tá an tsamhail chéanna san áireamh sa phlean trí cheangal OAuth Claude Code
agus gearrtar táille in aghaidh an chomhartha uirthi trí cheangal eochrach API.

Ní seachfhreastalaí sábháilte é `provider_connections.auth_type` i gceachtar treo — tá ceangail OAuth
mhéadraithe ann, agus tá ceangail eochrach API atá san áireamh sa phlean ann (ní eochair API
mhéadraithe é comhartha suíocháin Copilot). Mar sin, tagann an aicme billeála ó **chatalóg choimeádta**,
`open-sse/config/connectionBillingCatalog.ts`, a shocraítear de láimh de réir théarmaí foilsithe gach soláthraí —
an patrún céanna a bhunaigh `FreeModelBudget.hardStopGuaranteed` cheana féin do shamhlacha saor in aisce.

```ts
type ConnectionBillingClass = "subscription" | "metered" | "keyless" | "unknown";
type ConnectionOverageBehavior = "hard-stop" | "meters-to-paid" | "unknown";
```

Ord réitigh (`autoCombo/connectionBilling.ts`): an feighlí sintéiseach gan fíordheimhniú →
`keyless`; iontráil chatalóige a mheaitseálann an soláthraí **agus** `authType`; iontráil uile-sholáthraí;
nó `unknown` murach sin. **Ní chiallaíonn neamhchoimeádta saor in aisce** — caitear le `unknown` mar `metered`
i ngach áit, mar sin tosaíonn soláthraí a chuirtear leis amárach lasmuigh den chéim síntiúis agus caithfear é a
choimeád d’aon ghnó.

## Samhail na gcéimeanna

Cúig chéim in ord géaraithe. Ní hé praghas amháin a dhéanann idirdhealú eatarthu — tá a comhartha
ídithe **féin** ag gach ceann acu, agus sin an fáth nach sórtáil amháin atá anseo.

| #   | Céim           | Ballraíocht                                        | Ídithe nuair a                                                       |
| --- | -------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| 0   | `subscription` | `billing: "subscription"` coimeádta                | atá fuinneog an chuóta ag an scoithphointe nó faoina bhun            |
| 1   | `keyless`      | an chonair shintéiseach gan fíordheimhniú          | atá an ceangal i dtréimhse shuaimhnithe / a scoradán gníomhachtaithe |
| 2   | `free`         | ceangal méadraithe, `classifyTier() === "free"`    | atá an liúntas saor in aisce ídithe                                  |
| 3   | `cheap`        | ceangal méadraithe, `classifyTier() === "cheap"`   | atá buiséad na céime ídithe                                          |
| 4   | `premium`      | ceangal méadraithe, `classifyTier() === "premium"` | atá buiséad na céime ídithe                                          |

Ídítear céimeanna 0-2 bunaithe ar **chuóta**, rud atá inbhraite agus a rianaítear cheana féin. Níl aon
chuóta ag céimeanna 3-4 — leanann ceangal íoctha de bheith ag freastal go deo — mar sin is é **buiséad**
in aghaidh na céime an t-aon chomhartha ídithe ciallmhar atá acu. Gan buiséad den sórt sin, níl aon truicear ag
"géaraigh nuair atá an chéim shaor ídithe".

## `auto/subscription` — teip dúnta

Linn = runga 0 amháin, srianta do naisc a bhfuil a bhfarasbarr doiciméadaithe mar `hard-stop`, agus gach ceann acu fíoraithe beo go bhfuil lamháil chuóta ar fáil aige. Eisiatar gach rud débhríoch: soláthraí neamhchoimeádta, léamh cuóta nach féidir a fhíorú, léamh seanchaite, nó farasbarr a mhéadairítear mar úsáid íoctha.

Is é linn fholamh an freagra **beartaithe**, ní fabht — tiontaíonn cosán linn fholamh reatha an ghlaoiteora é ina earráid shoiléir seachas cúltaca ciúin inmhuirir. Sin é gealltanas iomlán an aitheantóra.

Ní cháilíonn `keyless` d'aon ghnó: ciallaíonn an grúpáil seo "an plean a n-íocaim as", mar sin ní bhaineann inneall cúltaca gan fíordheimhniú léi. Úsáid `auto/thrifty` (nó `auto/best-free`) chuige sin.

### Sábháilteacht naisc

Ní bhíonn iarrthóir ceangailte le nasc amháin i gcónaí — iompraíonn iarrthóir loighciúil ceadliosta `allowedConnectionIds`, agus roghnaíonn `open-sse/services/combo/autoStrategy.ts` an cuntas a úsáidtear i ndáiríre níos déanaí, tráth an tseolta. Dá bhrí sin, fíoraíonn an dá ghrúpáil **gach nasc ina aonar** agus athscríobhann siad `allowedConnectionIds` síos go dtí an fo-thacar marthanach go díreach — ní go dtí an liosta bunaidh iomlán riamh, ná go dtí ball amháin roghnaithe go treallach. Ós rud é go bhforfheidhmíonn `autoStrategy.ts` an t-eagar sin mar cheadliosta docht cheana féin, fágann a athscríobh anseo gurb ionann an tacar "fíoraithe" agus an tacar "a úsáidtear i ndáiríre" de réir tógála. Is é seo an t-athraitheach céanna, agus an réasúnaíocht chéanna, agus atá in [STRICT_ZERO_COST](./STRICT_ZERO_COST.md).

## `auto/thrifty` — ardaigh runga amháin ag an am

Linn = gach runga, ordaithe de réir innéacs runga, agus iarrthóirí ídithe geataithe amach. Scórálann an t-inneall `auto` **laistigh** den linn mharthanach fós: cinneann an dréimire cé na rungaí atá i bhfeidhm, agus cinneann an scóráil cén t-iarrthóir a bhuann laistigh díobh. Bíonn an t-ord cobhsaí laistigh de runga, mar sin ní athshuaitheadh an forleagan seo rangú an scórálaí féin riamh.

Forleagan ordaithe + geatála atá anseo, **ní** seoltóir nua é: siúlann lúb amhantrach `combo.ts` trí spriocanna in ord cheana féin agus téann sí ar aghaidh nuair a theipeann orthu, mar sin má tharlaíonn ídiú ag am rite nár aimsigh an réamheitilt, ardaítear go dtí an chéad runga eile laistigh den iarratas céanna fós.

Sa chás ina dteipeann `auto/subscription` **dúnta**, teipeann `auto/thrifty` **oscailte**: baintear triail fós ar dtús as nasc atá san áireamh sa phlean ach nach bhfuil léamh cuóta inúsáidte aige. Ní chosnaíonn an triail sin aon rud, agus má tharlaíonn sé go bhfuil sé ídithe, sroicheann an dul-ar-aghaidh an chéad runga eile ar aon nós — ach dá ndiúltófaí triail a bhaint as, chuirfí an t-iarratas chuig runga íoctha de bharr teiliméadracht a bheith in easnamh, arb é go díreach an toradh a bhfuil an ghrúpáil ann lena sheachaint.

## Filleadh ar an bplean tar éis athshocraithe

Ní mór do thrí rud neamhspleácha dul in éag sula bhfillfidh an ródú ar runga 0. Má cheartaítear ceann amháin acu, fanann an dréimire sáinnithe ar rungaí íoctha i bhfad tar éis athlíonadh an phlean.

1. **Taisce staid an chuóta** — déanann `freeAccessQuota.ts` taisceadh de réir `(provider, connection)` le TTL 180s. Déanann iontráil taisce a bhfuil a `resetAt` féin caite cheana cur síos ar fhuinneog nach ann di a thuilleadh, mar sin caitear léi anois mar iontráil sheanchaite **beag beann ar a haois** agus cuirtear athnuachan i bhfeidhm. Gan é seo, leanann léamh plean a athlíonadh ag meán oíche de bheith ídithe go dtí go dtarlaíonn sé go dtéann an TTL in éag.
2. **Staid an dréimire féin** — níl aon staid ann, de réir dearaidh. Athríomhtar incháilitheacht runga ó staid bheo an chuóta gach uair a thógtar an linn; níl aon taifead marthanach "ar runga 3 faoi láthair" ann a d'fhéadfadh maireachtáil níos faide ná athshocrú agus an ródú a sháinniú.
3. **Tréimhse mharbhántachta an naisc** — socraíonn an 429 íditheach `rateLimitedUntil` ó chúlú easpónantúil, rud a d'fhéadfadh dul thar an bhfíor-athshocrú i gcás nasc plean. Cúngaíonn `clampCooldownToReset()` (`subscriptionLadder.ts`) tréimhse mharbhántachta go meandar athshocraithe na seirbhíse réamhtheachtaí féin agus ní féidir leis tréimhse a shíneadh riamh. **Tá sé curtha i bhfeidhm agus tástáilte ach níl sé sreangaithe fós**: déantar taisce an chuóta a neamhbhailíochtú in `src/sse/services/auth.ts` _sula_ scríobhtar aon tréimhse mharbhántachta, mar sin ní mór `resetAt` a ghabháil níos luaithe san fheidhm sin — athrú ar an gcosán te athléimneachta ar cheart dó a bheith ina PR athbhreithnithe ar leith. Go dtí sin, fanann an athiontráil go dtí go mbíonn tréimhse mharbhántachta an naisc caite (agus tugann sí sin tús áite cheana féin do leideanna réamhtheachtacha `Retry-After` nuair a sheolann an soláthraí iad).

### Frith-luaineacht

Ní ligtear runga atá díreach athshocraithe ar ais isteach ach amháin os cionn `reentryMinRemainingPercent` (5 mar réamhshocrú), agus ní gá do nasc atá in úsáid cheana féin ach fanacht os cionn `exitCutoffPercent` (2 mar réamhshocrú, ag teacht le `quotaPreflight.defaultThresholdPercent`). Is í an bhearna sin an banda hisitéiréise — gan í, luainíonn nasc atá ar foluain ag an tairseach idir rungaí ar iarratais chomhleanúnacha.

## Cumraíocht

Mionchoigeartú amháin. D'aon ghnó, níl aon bhratach `enabled` ann: dá bhféadfaí iad seo a mhúchadh le scorán,
d'fhágfaí `auto/subscription` ag freastal go ciúin ar an linn iomlán — samhlacha íoctha san áireamh — faoi
ainm a gheallann a mhalairt.

```jsonc
{
  "subscriptionLadder": {
    "exitCutoffPercent": 2,
    "reentryMinRemainingPercent": 5,
    "rungBudgetUsd": { "cheap": 5.0, "premium": 0 }, // díchumasaíonn 0 céim go hiomlán
  },
}
```

Ní dhéanann geatáil buiséid aon ní go dtí go nasctar réiteoir caiteachais: mura bhfuil cuntasaíocht ar fáil, cuirtear
céim íoctha san ord ach ní chuirtear geatáil i bhfeidhm uirthi riamh. Ó v3.8.51 ar aghaidh, glacann an scéimre leis an socrú
`rungBudgetUsd`, ach NÍ chuirtear i bhfeidhm go fóill é — caith leis mar chumraíocht fhorchoimeádta, ní mar uasteorainn ghníomhach caiteachais. Oibríonn ordú na gcéimeanna, ídiú bunaithe ar chuóta, agus athiontráil tar éis athshocraithe
gan é.

## Comhdhéanamh

Is luachanna `AutoTier` iad `subscription` agus `thrifty`, mar sin is féidir iad a chomhdhéanamh le gach catagóir:
`auto/coding:thrifty`, `auto/reasoning:subscription`, agus mar sin de. Fógraítear an dá aitheantas comhréidh
(`auto/subscription`, `auto/thrifty`) in `/v1/models` agus sa deais.

Ní bhaineann ceachtar aitheantas leis an tsraith íoctha, mar sin tugann `isPaidTierAutoId()` `false` ar ais don dá cheann agus
maireann `auto/subscription` trí `hidePaidModels`.
