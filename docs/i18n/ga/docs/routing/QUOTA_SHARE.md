## Forléargas

Dáileann an tInneall Comhroinnte Cuóta cuóta ama soláthraí (m.sh. fuinneog 5 uair
Codex, Kimi 1500 req/h) go cothrom ar eochracha iomadúla API a chomhroinneann an
nasc céanna.

**An fhadhb a réitíonn sé:** Seachfhreastalaíonn OmniRoute go leor eochracha API ar an
gcuntas céanna soláthraí réamhtheachtaigh. Gan loighic chomhroinnte, féadfaidh ráig ó eochair A
cuóta an tsoláthraí don uair a ídiú, rud a fhágann eochracha B agus C blocáilte go dtí go
n-athshocraítear an fhuinneog. Cuireann an t-inneall cosc air seo trí:

1. Tomhaltas rollach gach eochrach de réir toise (%, iarratais, comharthaí, $) a rianú.
2. Algartam cothromroinnte a chaomhnaíonn obair a chur i bhfeidhm: féadfaidh eochair iasacht a fháil ó
   scaireanna díomhaoin fad nach bhfuil an linn dhomhanda sáithithe.
3. An toradh a fhorfheidhmiú sa chonair the (`chatCore.ts`) sula sroicheann an t-iarratas
   an forghníomhaitheoir réamhtheachtaigh.

## Algartam: Cothromroinnt a Chaomhnaíonn Obair

Curtha i bhfeidhm in `src/lib/quota/fairShare.ts`.

### Móid

| Coinníoll                                  | Mód            | Iompar                                                                                           |
| ------------------------------------------ | -------------- | ------------------------------------------------------------------------------------------------ |
| `globalUsedPercent < saturationThreshold`  | **Flaithiúil** | Féadfaidh eochair iasacht a fháil suas go dtí an teorainn dhomhanda lúide an t-iomlán tomhaltais |
| `globalUsedPercent >= saturationThreshold` | **Docht**      | Cuir an chothromroinnt aonair i bhfeidhm go docht                                                |

Is é `saturationThreshold = 0.5` an luach réamhshocraithe (env `QUOTA_SATURATION_THRESHOLD`).

### Cinneadh de réir toise

I gcás gach toise gníomhaí sa linn, ríomhann an t-inneall:

```
fairShareAllowed = poolLimit × (allocationWeight / 100)
consumed        = current rolling value for this key (from QuotaStore.peek)
remaining       = fairShareAllowed - consumed
```

Ansin:

- **`policy = hard`**: má tá `consumed > fairShareAllowed` agus má tá an mód docht → **blocáil**.
- **`policy = soft`**: má tá `consumed > fairShareAllowed` agus má tá an mód docht → **gearr pionós** (tabhair tosaíocht níos ísle dó sa teaglaim; ná déan crua-bhlocáil riamh).
- **`policy = burst`**: ceadaigh é fad atá spás breise domhanda ar fáil, beag beann ar an gcothromroinnt.

### Uasteorainn Dhearbh

Is uasteorainn chrua iad `capValue` + `capUnit` ar leithdháileadh, neamhspleách ar an mód nó ar an
mbeartas. Déanann aon toise ina bhfuil `consumed >= capValue` an t-iarratas a **bhlocáil** i gcónaí.

### Seiceáil iltoiseach

Blocáiltear iarratas dá gcuirfeadh **aon** toise sa linn bac air. Tá na toisí
neamhspleách — ní théann ídiú 5h% i bhfeidhm ar an toise seachtainiúil%.

### Iasachtú

Sa mhód flaithiúil, féadfaidh eochair nach bhfuil a leithdháileadh tomhalta go hiomlán aici barrachas ó
scaireanna neamhdháilte eochracha eile a úsáid. Seo í an fhoirmle:

```
maxAllowed = globalLimit - consumedByOtherKeys
```

inar `consumedByOtherKeys = consumedTotal - consumedByThisKey`. Is í an uasteorainn dhomhanda
(`limit` na linne don toise sin) an uasteorainn chrua i gcónaí.

## Áiritheoir Fuinneoige Sleamhnáin

Curtha i bhfeidhm in `src/lib/quota/sqliteQuotaStore.ts` agus `redisQuotaStore.ts`.

Dhá bhuicéad in aghaidh `(apiKeyId, dimensionKey)`:

- `curr`: an buicéad reatha (`floor(nowMs / windowMs)`)
- `prev`: an buicéad roimhe seo (`curr - 1`)

Luach rollach éifeachtach:

```
effectiveBucketIndex = floor(nowMs / windowMs)
bucketStartMs        = effectiveBucketIndex × windowMs
elapsed              = nowMs - bucketStartMs
weight               = 1 - elapsed / windowMs

effective = prev × weight + curr
```

**Cruinneas**: cruinneas ~99%. Is é 1% de mhéid na fuinneoige, ar a mhéad, an earráid ag an
teorainn idir buicéid (rud is dual don neastachán 2-bhuicéad).

### Comhreireacht

Tiománaí SQLite: cuireann frithdhúnadh sa chuimhne in aghaidh na heochrach `(apiKeyId | dimensionKey)` cosc ar an
rás léigh-modhnaigh-scríobh. Leanann an patrún sampla frith-thréada-tréadaithe `src/sse/services/auth.ts`.

Tiománaí Redis: script Lua EVAL le haghaidh incrimint adamhach — ritear é mar ordú aonair Redis.

## Tiománaithe

### SQLite (réamhshocrú, gan suiteáil)

- Tábla: `quota_consumption` (féach an t-aistriú `073_quota_pools.sql` / `074_quota_consumption.sql`).
- Is fearr é d’imlonnuithe aon ásc amháin.
- Tá an mharthanacht ar fad sa bhunachar sonraí SQLite OmniRoute atá ann cheana (`DATA_DIR/storage.sqlite`).

### Redis (roghnach, ilásc)

- Teastaíonn an pacáiste npm `ioredis`.
- Stóráiltear cuntair in Redis; fanann meiteashonraí (linnte/leithdháiltí) in SQLite.
- Is fearr é d’imlonnuithe il-mhacasamhla ina gcaithfear cuntair a chomhroinnt.

### Tiománaithe a athrú

Trí chomhéadan úsáideora na socruithe (`/dashboard/settings` → Stór Cuótaí), nó trí athróga timpeallachta:

```bash
QUOTA_STORE_DRIVER=redis
QUOTA_STORE_REDIS_URL=redis://localhost:6379
```

Tá tosaíocht ag socrú an bhunachair sonraí ar an timpeallacht. Má tá `driver=redis` ach mura bhfuil URL ann nó
mura bhfuil `ioredis` suiteáilte, filleann an mhonarcha ar SQLite agus logálann sí rabhadh.

Ord roghnúcháin an tiománaí:

1. Socrú bunachair sonraí `quotaStore.driver`
2. Timpeallacht `QUOTA_STORE_DRIVER`
3. Réamhshocrú: `sqlite`

## Comhtháthú na Píblíne

### Duán PRE (`open-sse/handlers/chatCore.ts`)

Ritheann sé roimh an seiceadóir réamhtheachtach, tar éis seiceálacha fíordheimhnithe agus beartais:

```
resolveComboTargets / handleSingleModel
  → enforceQuotaShare(apiKeyId, connectionId, provider, estimatedCost)
      → getQuotaStore().peek() do gach toise
      → fairShare.decideFairShare()
      → más blocáil é → seol 429 ar ais (buildErrorBody, Riail Dhocht #12)
      → más ceadú + ísliú tosaíochta é → socraigh quotaSoftPenalty=true ar an iarrthóir
  → executor.execute()
```

**Teip-oscailte**: má chaitheann `enforceQuotaShare` eisceacht, ligtear don iarratas dul ar aghaidh
le logáil `pino.warn`. Cuireann sé seo cosc ar fhabht san inneall cuótaí an trácht ar fad a bhlocáil.

### Duán POST (tomhaltas a thaifeadadh)

Tar éis freagra rathúil:

```
seolann an seiceadóir rath ar ais
  → spendRecorder.recordConsumption(apiKeyId, connectionId, provider, actualCost)
      → getQuotaStore().consume() do gach toise
      → teip-oscailte: logáiltear earráidí mar pino.warn, ní sheoltar chuig an gcliant riamh iad
```

**Nóta maidir le diallas**: má theipeann ar `consume` tar éis an fhreagra, déanann an cuntar rollach an tomhaltas a thearc-chomhaireamh.
Ceartaíonn an comhartha sáithiúcháin ón soláthraí (m.sh. `anthropic-ratelimit-unified-5h-utilization`)
an meastachán domhanda ar an gcéad iarratas eile.

### Pionós bog teaglama (`open-sse/services/combo.ts`)

Nuair atá `decision.deprioritize === true`:

```ts
if (candidate.quotaSoftPenalty) {
  score *= QUOTA_SOFT_DEPRIORITIZE_FACTOR; // réamhshocrú 0.7
}
```

Cuirtear an pionós i bhfeidhm tar éis gach toisc scórála eile. Laghdaíonn sé an dóchúlacht go roghnóidh an t-uath-theaglama
eochair sháithithe gan bac crua a chur uirthi.

## Fabhtcheartú

### Redis cumraithe ach gan nascadh

Seiceáil go bhfuil `ioredis` suiteáilte (`npm ls ioredis`) agus go bhfuil `QUOTA_STORE_REDIS_URL`
insroichte. Má theipeann ar an nasc, filleann an mhonarcha ar SQLite (logáilte ag
`warn`).

### Tugann `peek` sonraí seanchaite / teip-oscailte ar ais

Má chaitheann `peek` earráid, déileálann `enforceQuotaShare` leis an toradh mar "ceadaigh" (teip-oscailte).
Seiceáil logaí `pino` le haghaidh iontrálacha `quota:enforce` agus `quota:factory` chun
an bhunchúis a aithint.

### Diall sa chuntar ídithe

Má tá úsáid iarbhír an tsoláthraí éagsúil ó na cuntair, táthar ag súil leis sin — tá
earráid ~1% ag teorainneacha na fuinneoige san fhuinneog sleamhnáin 2-bhuicéad, agus is oibríocht
iarfhreagartha gan fanacht é `consume`. Léann an comhartha sáithithe (`saturationSignals.ts`)
fíorúsáid an tsoláthraí le TTL 30s agus coigeartaíonn sé `globalUsedPercent`
dá réir.

### Taispeánann an linn "gan sonraí" don ráta ídithe

Teastaíonn 2 shampla stairiúla ar a laghad ó `computeBurnRate`. Taispeánfaidh linnte nua gan glaonna
`consume` roimhe seo `tokensPerSecond: 0` agus `timeToExhaustionMs: null`.

ar athaistriú.

## Achoimre ar Scéimre an Bhunachair Sonraí

Cuireadh trí thábla leis trí na haistrithe `078`, `079` agus `085`:
