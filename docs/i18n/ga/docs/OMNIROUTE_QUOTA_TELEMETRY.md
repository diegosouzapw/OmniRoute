Scarann OmniRoute teiliméadracht chuóta an tsoláthraí ó chuntasaíocht Ghostlight.

## Staideanna fírinneacha

- Ciallaíonn `healthy` gur thuairiscigh foinse acmhainn inúsáidte a bhí fágtha.
- Ciallaíonn `approaching_limit` gur thuairiscigh foinse acmhainn a bhí fágtha ag an tairseach chumraithe nó faoina bun.
- Ní astaítear `exhausted` ach amháin nuair a thuairiscíonn foinse acmhainn nialasach nó úsáid atá ag a teorainn.
- Ciallaíonn `unavailable` gur theip ar fhoinse a dtacaítear léi sonraí a thabhairt ar ais.
- Ciallaíonn `unknown` nach ann d’fhoinse a dtacaítear léi nó nach eol aon teorainn soláthraí.

Ní hionann anaithnid agus ídithe, agus ní dhíchumasaíonn sé soláthraí.

Tugtar tús áite d’fhoinsí san ord seo: API oifigiúil an tsoláthraí, API úsáide fíordheimhnithe, ceanntásca freagartha atá mapáilte go sainráite, cumraíocht riarthóra, meastacháin áitiúla, anaithnid. Ní chuirtear meastacháin áitiúla i láthair riamh mar shonraí billeála an tsoláthraí.

Ní pharsáiltear ceanntásca freagartha ach amháin trí mhapáil shainráite soláthraí. Ní ghlactar leis go mbaineann ainmneacha cineálacha ceanntásca le gach soláthraí.
