Is é Traffic Inspector dífhabhtóir tráchta HTTPS ionsuite OmniRoute — uirlis ar nós Charles Proxy / mitmweb / HTTP Toolkit atá **feasach ar LLManna** agus **feasach ar ghníomhairí**. Tá sé lonnaithe ag `/dashboard/tools/traffic-inspector` agus faigheann sé trácht beo ó suas le 5 fhoinse gabhála chomhuaineacha.

**Suíomh ar an deais:** `/dashboard/tools/traffic-inspector`
**Grúpa sa bharra taoibh:** Uirlisí (i ndiaidh AgentBridge)
**Féach freisin:** [`AGENTBRIDGE.md`](./AGENTBRIDGE.md) — Is é AgentBridge mód gabhála 1.

### An ailtireacht in aon alt amháin

Is maolán fáinne comhroinnte sa chuimhne é an `TrafficBuffer` (`src/mitm/inspector/buffer.ts`) (1000 iontráil de réir réamhshocraithe, inchumraithe trí `INSPECTOR_BUFFER_SIZE`). Scríobhann gach foinse gabhála chuige trí `push()`. Aicmíonn an maolán gach iontráil trí `kindDetector.ts` a úsáid (cinneann sé cé acu is iarratas LLM é), ríomhann sé `contextKey` (méarlorg SHA-256 den leid chórais), agus craolann sé chuig gach síntiúsóir WebSocket trí `globalTrafficBuffer.subscribe()`. Nascann an deais trí `GET /api/tools/traffic-inspector/ws` agus faigheann sí seat den staid tráth an naisc, agus teagmhais `new`/`update`/`clear` ina dhiaidh sin.

## §2 Móid ghabhála

Tacaíonn Traffic Inspector le **5 fhoinse ghabhála chomhuaineacha**. Is féidir gach ceann díobh a scoránú go neamhspleách. Tá an réimse `source` ar gach `InterceptedRequest` (`src/mitm/inspector/types.ts`) ar cheann de `"agent-bridge"`, `"custom-host"`, `"http-proxy"`, `"system-proxy"`, nó `"tproxy"`.

### Mód 1 — AgentBridge (réamhshocrú, ar siúl i gcónaí)

**Foinse:** Láimhseálaithe AgentBridge (`src/mitm/handlers/base.ts`)
**Meicníocht:** Glaonn gach glao `intercept()` in `MitmHandlerBase` ar `hookBufferStart()` sula gcuirtear ar aghaidh é agus ar `hookBufferUpdate()` nuair a bhíonn sé críochnaithe. Níl aon chumraíocht bhreise de dhíth — oibríonn sé a luaithe a bhíonn AgentBridge ag rith.
**Raon:** Na 9 ngníomhaire IDE atá cumraithe in AgentBridge
**Nóta:** Réimse `source` in `InterceptedRequest` = `"agent-bridge"`

### Mód 2 — Óstaigh Shaincheaptha (atreorú DNS)

**Foinse:** Liosta óstach arna shainiú ag an úsáideoir (tábla `inspector_custom_hosts`)
**Meicníocht:** Nuair a chuirtear óstach leis tríd an gcomhéadan úsáideora, cuirtear `127.0.0.1 <host>` le `/etc/hosts` (tá sudo de dhíth). Gineann an freastalaí MITM AgentBridge atá ann cheana (port 443) teastas SNI go dinimiciúil don óstach nua.
**Raon:** Aon fheidhmchlár a úsáideann an t-óstach a cuireadh leis — ní gá cumraíocht an fheidhmchláir a athrú
**Nóta:** `source` = `"custom-host"`

Samplaí de chásanna úsáide:

- Monatóireacht a dhéanamh ar `api.openai.com` ó scripteanna Python
- Dífhabhtú a dhéanamh ar `my-internal-llm.company.com`
- Trácht a ghabháil ó ghléasanna móibíleacha ar an líonra céanna (trí bhréagú ARP — ardleibhéal)

### Mód 3 — Éisteoir HTTP_PROXY (port 8080)

**Foinse:** Feidhmchláir a úsáideann athróga timpeallachta `HTTP_PROXY`/`HTTPS_PROXY`
**Meicníocht:** Éisteoir tánaisteach ar phort 8080 (`src/mitm/inspector/httpProxyServer.ts`) a fheidhmíonn mar ghnáthsheachfhreastalaí sainráite HTTP/HTTPS. Glacann sé le tolláin `CONNECT` (HTTPS) agus iarratais dhíreacha HTTP.
**Raon:** Aon fheidhmchlár a urramaíonn timpeallacht `HTTP_PROXY` — gan athrú DNS, gan sudo
**Nóta:** `source` = `"http-proxy"`

```bash
# Gabháil thapa le haghaidh ordú aonair:
HTTPS_PROXY=http://127.0.0.1:8080 curl https://api.openai.com/v1/models

# Gabháil mharthanach i seisiún blaoisce:
export HTTP_PROXY=http://127.0.0.1:8080
export HTTPS_PROXY=http://127.0.0.1:8080
```

**Teorainn TLS:** Ní ghabhtar tolláin HTTPS `CONNECT` ach mar mheiteashonraí (óstach, port, uainiú) — ní dhíchriptítear corp TLS de réir réamhshocraithe. Cumasaigh an scorán "Díchriptigh HTTPS i mód seachfhreastalaí" (rogha isteach, ní mór muinín a bheith as teastas AgentBridge) chun an corp iomlán a iniúchadh.

**Coinbhleacht poirt:** Má tá port 8080 in úsáid, seolann AgentBridge 409 ar ais le hearráid struchtúrtha. Athraigh an port tríd an athróg timpeallachta `INSPECTOR_HTTP_PROXY_PORT`.

### Mód 4 — Seachfhreastalaí ar fud an chórais (ardleibhéal, rogha isteach)

**Foinse:** Socruithe seachfhreastalaí ar leibhéal an OS (baineann siad le gach feidhmchlár ar an ríomhaire)
**Meicníocht:** Úsáideann sé APIanna an OS chun an trácht HTTP/HTTPS uile a atreorú tríd an éisteoir HTTP_PROXY:

- **macOS:** `networksetup -setwebproxy / -setsecurewebproxy`
- **Linux:** `gsettings set org.gnome.system.proxy` + `/etc/environment`
- **Windows:** `netsh winhttp set proxy 127.0.0.1:8080`
  **Raon:** Gach feidhmchlár ar an ríomhaire a urramaíonn socruithe seachfhreastalaí an chórais
  **Nóta:** `source` = `"system-proxy"`

**Meicníochtaí sábháilteachta:**

- Uaineadóir uathdhíchumasaithe (30 nóiméad de réir réamhshocraithe, inchumraithe trí `INSPECTOR_SYSTEM_PROXY_GUARD_MINUTES`)
- Sábháiltear staid roimhe seo sheachfhreastalaí an chórais sa DB agus aisghairtear í nuair a fhilltear
- Taispeánann an deais leid "Seachfhreastalaí an chórais á fhilleadh" má dhéanann an t-úsáideoir nascleanúint ar shiúl agus é gníomhach
- Taispeánann an comhéadan úsáideora suaitheantas `⚠ Ardleibhéal` + ticbhosca follasach deimhnithe

### Mód 5 — Díchriptiú trédhearcach TPROXY (Linux, root, rogha isteach)

**Foinse:** TPROXY eithne + ródú beartais (`src/mitm/tproxy/`)
**Meicníocht:** Marcálann sé naisc TCP áitiúla nua amach chuig spriocphort (`443` de réir réamhshocraithe) in `mangle OUTPUT`, athródaíonn `ip rule` na paicéid mharcáilte chuig seachadadh áitiúil, agus tugann sprioc `TPROXY` de chuid `mangle PREROUTING` iad d'éisteoir trédhearcach (**IP_TRANSPARENT**) (`8443` mar phort réamhshocraithe). Cuireann an t-éisteoir deireadh le TLS le teastas duille arna eisiúint **do gach óstainm SNI ar éileamh** ag CA dinimiciúil, gabhann sé an malartú díchriptithe, agus cuireann sé an t-iarratas ar aghaidh, athchriptithe, chuig an gceann scríbe bunaidh.
**Raon:** Óstaigh chinn scríbe **threallacha** ar an spriocphort — gan bhréagú `/etc/hosts`, gan timpeallacht `HTTP_PROXY`, gan athrú ar sheachfhreastalaí an chórais ar fad. Ní gá aon athrú cumraíochta a dhéanamh ar an bpróiseas idircheaptha, ach caithfidh sé muinín a bheith aige as an CA dinimiciúil.
**Nóta:** `source` = `"tproxy"`

**Riachtanais:** Linux amháin (níl **IP_TRANSPARENT** ar fáil ach ar Linux), an cumas **CAP_NET_ADMIN** (root), agus breiseán dúchasach N-API nach mór a thógáil le slabhra uirlisí C (`npm run build:native:tproxy`). Nuair nach mbíonn siad ar fáil, díchumasaítear scorán na deaise leis an leid uirlise "Éilíonn díchriptiú TPROXY Linux + root + an breiseán dúchasach". Cuirtear na rialacha balla dóiteáin i bhfeidhm agus aisiompaítear iad go hidirbheartach (ní fhágann tuairt riail `mangle` ina diaidh riamh) agus glantar iad nuair a atosaítear an córas. Cuireann frithlúb bunaithe ar SO_MARK cosc ar sheoladh athchriptithe an tseachfhreastalaí féin a bheith idircheaptha arís.

Is fochóras suntasach é seo a bhfuil treoir thiomnaithe oibreora dá chuid féin aige — féach `docs/security/MITM-TPROXY-DECRYPT.md` (git; ní thiomsaítear é isteach in `/docs`) le haghaidh oideas iomlán an bhalla dóiteáin, an CA dinimiciúil do gach SNI + suiteálaí an stóir iontaoibhe, an bealach áitiúil amháin, sonraí frithlúibe, agus scéimre na cumraíochta. Tá an scorán á rialú ag `GET / POST / DELETE /api/tools/agent-bridge/tproxy` (nóta: tá an bealach faoin réimír AgentBridge, ní faoin réimír Traffic Inspector).

### 3.2 Liosta iarratas (painéal ar chlé)

- **Fíorúlaithe** (`useVirtualList` + `ResizeObserver`): láimhseálann sé 1000 mír gan reo
- **Uathscrollú** le scorán chun é a chur ar sos le linn iniúchta
- **Stádas dathchódaithe**: glas (2xx), buí (3xx), dearg (4xx/5xx), liath (ar siúl)
- **Emoji gníomhaire**: 🔵 Antigravity, 🟢 Copilot, 🟠 Kiro, 🟣 Codex, 🔷 Cursor, 🟤 Zed, 🟡 Claude Code, ⚫ Open Code, 🌐 óstach saincheaptha
- **Barra datha comhthéacs**: imeall clé 1px daite de réir `contextKey` (SHA-256 den leid chórais) — grúpálann sé comhráite gaolmhara go hamhairc
- **Corp leisciúil**: ní chuirtear ach corp an iarratais roghnaithe i gcrích sna cluaisíní sonraí (seachnaíonn sé rindreáil 1000 × corp 1MB)

## §4 Gnéithe atá feasach ar LLM

### 4.1 Brathadóir cineáil (`src/mitm/inspector/kindDetector.ts`)

Aicmíonn sé gach iarratas mar `"llm"`, `"app"`, nó `"unknown"` trí úsáid a bhaint as 4 chomhartha:

1. **Clárlann óstach** — ~18 óstainm aitheanta d’APIanna LLM (OpenAI, Anthropic, Gemini, Groq, Mistral, Together, Fireworks, Cohere, Perplexity, Hugging Face, OpenRouter, xAI, Moonshot, etc.)
2. **Patrúin conairí** — `/v1/chat/completions`, `/v1/messages`, `/generateContent`, `/v1/responses`, etc.
3. **Cruth an choirp** — braitheann sé réimsí `messages[]` (OpenAI/Claude), `contents[]` (Gemini), `prompt`, `input`
4. **Leideanna ón ngníomhaire úsáideora** — `codex`, `claude`, `gemini`, `antigravity`, `kiro`, `copilot`, `cursor` sa teaghrán UA

Faigheann óstaigh shaincheaptha a chuirtear leis trí Mhód 2 a `kind` ón ionchur foirme (`"custom"` de réir réamhshocraithe).

### 4.2 Cumascóir SSE (`src/mitm/inspector/sseMerger.ts`)

**Cur chun feidhme neamhspleách glanseomra.** Leanann parsáil imeachtaí
[algartam imeachtaí arna seoladh ag an bhfreastalaí de chuid WHATWG](https://html.spec.whatwg.org/multipage/server-sent-events.html#parsing-an-event-stream),
agus leanann an t-athchruthú scéimeanna sruthaithe poiblí
[OpenAI](https://platform.openai.com/docs/api-reference/chat/create),
[Anthropic](https://platform.claude.com/docs/en/build-with-claude/streaming), agus
[Gemini](https://ai.google.dev/api/generate-content#method:-models.streamgeneratecontent).

Athchruthaíonn sé teachtaireacht deiridh an chúntóra ó imeachtaí amh deilte SSE:

- **Anthropic**: carnann sé `content_block_delta` de réir innéacs; láimhseálann sé `text_delta`, `input_json_delta` (glaonna uirlise), `thinking_delta`
- **OpenAI**: carnann sé roghanna/glaonna uirlise Chat Completions agus míreanna aschuir Responses API
  de réir innéacs
- **Gemini**: carnann sé `candidates[i].content.parts`
- **Anaithnid**: tugann sé imeachtaí amha ar ais mar atá siad

Taispeánann an cluaisín Response scorán: **"Imeachtaí amha ↔ Cumaiscthe"**.

### 4.3 Normalaitheoir comhrá (`src/mitm/inspector/conversationNormalizer.ts`)

**Cur chun feidhme neamhspleách glanseomra.** Sainítear an normalú le conarthaí áitiúla bosca dhuibh
agus scéimeanna poiblí teachtaireachtaí OpenAI, Anthropic, agus Gemini; ní úsáidtear aon fhoinse
chur chun feidhme réamhtheachtach.

Tiontaíonn sé formáidí teachtaireachtaí OpenAI, Anthropic, agus Gemini go `NormalizedConversation` aonair roimh rindreáil:

```ts
interface NormalizedConversation {
  request: NormalizedTurn[]; // teachtaireachtaí / inneachar / leid ó chorp an iarratais
  response: NormalizedTurn[]; // freagra an chúntóra (cumaiscthe trí sseMerger)
  contextKey: string | null; // méarlorg SHA-256 leid an chórais
}
```

Cineálacha bloic: `text`, `tool_use`, `tool_result`. Úsáideann an cluaisín Conversation an cruth seo beag beann ar an soláthraí.

### 4.4 Dathú na heochrach comhthéacs (`src/mitm/inspector/contextKey.ts`)

- Ríomhann sé `SHA-256` leid an chórais (an chéad teachtaireacht `role:system`, nó an réimse `system`, nó `systemInstruction` Gemini)
- Tugann sé réimír heicsidheachúlach 12 charachtar ar ais (`"a3f9c2..."`)
- Mapálann an ceann tosaigh an eochair go dath HSL cinntitheach don bharra ar an imeall clé
- **Scagaire "an comhthéacs céanna"**: nuair a chliceáiltear an tslis `ctx #a3f`, cuirtear scagaire leis chun iarratais a bhfuil an méarlorg céanna acu amháin a thaispeáint

Fágann sé seo gur furasta "pearsantachtaí" nó tascanna éagsúla atá ar siúl sa seisiún gníomhaire céanna a idirdhealú óna chéile ó thaobh amhairc de.

### 4.5 Eastóscadh meiteashonraí LLM

I gcás iarratais LLM, eastóscann an cluaisín LLM Details:

```ts
interface LlmMetadata {
  provider: string | null; // "openai" | "anthropic" | "gemini" | ...
  apiKind: string | null; // "chat.completions" | "messages" | "embeddings" | ...
  model: string | null; // ó chorp an iarratais nó ón bhfreagra
  messages: number; // líon babhtaí
  tokensIn: number | null; // usage.prompt_tokens / usage.input_tokens
  tokensOut: number | null; // usage.completion_tokens / usage.output_tokens
  streamed: boolean; // true más freagra SSE é
  mappedTo: string | null; // ceanntásc x-omniroute-mapped
  costEstimateUsd: number | null; // costas measta bunaithe ar phraghsáil OmniRoute
}
```

### 4.6 Scagaire beo d’iarratais atá ar siúl

Is é `number | "in-flight" | "error"` réimse `status` an iarratais — cuirtear iontráil
isteach mar `"in-flight"` a luaithe a thosaíonn an t-iarratas agus **nuashonraítear san áit chéanna í**
nuair a thagann an freagra (nó an earráid). Cuireann scorán **"Beo"** an bharra uirlisí
(`liveOnly`, eochair i18n `trafficInspector.liveOnly`) srian leis an liosta ionas nach mbíonn ann ach iontrálacha
a bhfuil `status === "in-flight"` acu, rud a ligeann duit féachaint ar naisc oscailte i bhfíor-am.

Is preideacáid íon ar thaobh an chliaint é an scagaire in
`src/lib/inspector/matchesTrafficFilter.ts`:

```ts
if (f.liveOnly && req.status !== "in-flight") return false;
```

Tá staid an scoráin in `useTrafficFilters` (crúcaí dheais an chigire) agus
comhcheanglaítear í leis na scagairí eile (próifíl, óstach, gníomhaire, foinse, stádas, comhthéacs).

### 4.7 Sannadh próisis (Linux)

Ar Linux, is féidir gach iarratas idircheaptha a shannadh don **phróiseas áitiúil tionscnaimh**.
Cuirtear dhá réimse roghnacha le `InterceptedRequest`:

```ts
pid?: number;          // aitheantas an phróisis tionscnaimh (Linux amháin)
processName?: string;  // ainm an phróisis tionscnaimh (Linux amháin)
```

Mapálann `src/mitm/inspector/processAttribution.ts` port sealadach _cliaint_ an naisc
go PID + ainm tríd an méid seo a leanas a dhéanamh:

1. Léann sé `/proc/net/tcp` agus `/proc/net/tcp6` chun inóid an tsoicéid don
   phort a aimsiú (`parseProcNetTcpForInode`, parsálaí íon atá intástáilte le daingneáin).
2. Scanann sé `/proc/<pid>/fd/` le haghaidh nasc siombalach chuig `socket:[<inode>]`.
3. Léann sé ainm an phróisis ó `/proc/<pid>/comm`.

Cuireann taisce TTL 1 soicind teorainn leis an gcostas a bhaineann le scanadh procfs faoi ualach. Is
**iarracht is fearr** é an sannadh — réitíonn aon teip go `null` agus ní chuireann sí bac ar ghabháil riamh. Ar
macOS/Windows tugann an fheidhm `null` ar ais (stob; is obair leantach í tacaíocht
`lsof`/`GetExtendedTcpTable`).

## §5 Seisiúin

### 5.1 Seisiún a thaifeadadh

1. Cliceáil **"● Taifead seisiún"** sa bharra uirlisí → cuir ainm isteach (roghnach)

## §6 Slándáil

Taispeánann an Cigire Tráchta **an trácht HTTPS idircheaptha ar fad**, lena n-áirítear ceanntásca údaraithe agus coirp iarratais. Tá na rialuithe seo a leanas i bhfeidhm:

| Rialú                                           | Sonraí                                                                                                                                                                                            |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LOCAL_ONLY**                                  | Tá gach bealach agus críochphointe WebSocket teoranta don loopback amháin (forfheidhmithe in `routeGuard.ts` roimh fhíordheimhniú)                                                                |
| **Mascadh rún**                                 | Folaíonn scanóir líneach `maskSecret()` dintiúir Bearer RFC 6750, eochracha le réimír soláthraí agus comharthaí fada doiléire roimh `TrafficBuffer.push()`                                        |
| **Teorainn mhéid an choirp**                    | Ciorraítear coirp > `INSPECTOR_MAX_BODY_KB` (réamhshocrú 1024 KB) agus cuirtear an fógra `"(ciorraithe ar mhaithe le feidhmíocht)"` leo                                                           |
| **Sláintiú ceanntásc**                          | Tiontaítear ainmneacha go litreacha beaga; baintear ceanntásca frámaithe/hop-by-hop agus seachfhíordheimhnithe; foláirtear fianáin go hiomlán; tarmligeann luachanna dintiúr chuig `maskSecret()` |
| **CSP**                                         | Beartas Slándála Ábhair dian ar leathanaigh an Chigire Tráchta chun XSS trí choirp freagartha insteallta a chosc                                                                                  |
| **Gan bhuanseasmhacht de réir réamhshocraithe** | Tá an `TrafficBuffer` sa chuimhne agus cailltear é nuair a atosaítear an freastalaí. Ní bhuantar seisiúin ach amháin nuair a thaifeadtar iad go sainráite                                         |

### Rialacha Dochta a chuirtear i bhfeidhm

| Riail                             | Cur i bhfeidhm                                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------------ |
| **#12** `sanitizeErrorMessage`    | Sláintítear gach freagra earráide HTTP ó bhealaí an Chigire Tráchta                              |
| **#15 + #17** `isLocalOnlyPath()` | Tá `/api/tools/traffic-inspector/` LOCAL_ONLY + SPAWN_CAPABLE (orduithe seachfhreastalaí córais) |

### Teorainneacha aitheanta

- Bíonn tionchar ag **mód seachfhreastalaí ar fud an chórais** ar gach feidhmchlár ar an ríomhaire, lena n-áirítear cliaint VPN agus SSO. Úsáid i gcónaí é leis an amadóir uathdhíchumasaithe. Ná húsáid ar ríomhairí comhroinnte é.
- **HTTPS tolláin CONNECT**: Ní ghabhann Mód 3 (HTTP_PROXY) ach meiteashonraí tolláin le haghaidh cinn scríbe HTTPS mura bhfuil idircheapadh TLS cumasaithe. Is d'aon ghnó é seo — bhrisfeadh gabháil thrédhearcach fíorú TLS do na haipeanna sin mura mbeadh muinín as teastas AgentBridge.
- **Teaghráin chrua-chódaithe i roinnt comhpháirteanna**: Tá líon beag teaghrán crua-chódaithe i roinnt comhpháirteanna den Chomhéadan Úsáideora (F7/F8) nach bhfuil clúdaithe fós ag eochracha i18n. Tá siad seo doiciméadaithe mar Theorainn Aitheanta sa tuarascáil ar bhearnaí i18n; aistreofar iad i dtriail leantach. Is lipéid mhaisiúla sa Chomhéadan Úsáideora iad na teaghráin lena mbaineann agus ní gá iad a aistriú le haghaidh úsáid fheidhmiúil.

## §7 Fabhtcheartú

### Dícheangal WebSocket

Má thaispeánann an rian beo "Dícheangailte":

1. Seiceáil go bhfuil an freastalaí fós ag rith: `GET /api/tools/traffic-inspector/capture-modes`
2. Athlódáil an leathanach — athcheanglaíonn an WebSocket agus faigheann sé léargas úr
3. Má atosaíodh an freastalaí, glanadh an maolán cuimhne — tá na seaniontrálacha imithe mura ndearnadh seisiún a thaifeadadh

### Coinbhleacht ar phort 8080

Má theipeann ar mhód HTTP_PROXY tosú:

```bash
lsof -i :8080    # aimsigh an próiseas
```

Athraigh an port:

```bash
# .env
INSPECTOR_HTTP_PROXY_PORT=8888
```

### Seachfhreastalaí an chórais gan filleadh ar an seansocrú

Má thuairteálann OmniRoute agus mód seachfhreastalaí uile-chórais gníomhach:

**macOS:**

```bash
networksetup -setwebproxystate Wi-Fi off
networksetup -setsecurewebproxystate Wi-Fi off
```

**Linux (GNOME):**

```bash
gsettings set org.gnome.system.proxy mode 'none'
```

**Windows:**

```cmd
netsh winhttp reset proxy
```

Tairgfidh an deais "Cuir seachfhreastalaí an chórais ar ais" ar an gcéad lódáil eile freisin má bhraitheann sí go léiríonn staid an bhunachair sonraí go raibh an seachfhreastalaí gníomhach.

### Maolán lán

Nuair a shroicheann an maolán `INSPECTOR_BUFFER_SIZE` (1000 de réir réamhshocraithe), cuireann iontrálacha nua na hiontrálacha is sine amach. Má tá iarratais thábhachtacha á gcailliúint:

- Méadaigh `INSPECTOR_BUFFER_SIZE` (m.sh., 5000) — malartaítear cuimhne ar choinneáil
- Taifead seisiún chun an tréimhse ábhartha a bhuanú sa bhunachar sonraí
