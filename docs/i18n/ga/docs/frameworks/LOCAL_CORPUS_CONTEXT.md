> `src/lib/localCorpus/configured.ts` (am rite cumraithe),

> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 uirlis MCP inléite amháin), agus
> `src/app/api/settings/local-corpus/route.ts` (API socruithe).

## Cad é atá ann

Cuireann Local Corpus ar chumas oibreora eolaire amháin de chomhaid téacs atá faofa go sainráite a nochtadh do
fhreastalaí MCP OmniRoute. Fanann na comhaid ina n-eolaire bunaidh: ní stórálann OmniRoute ach
an chonair fhréimhe chanónach in SQLite agus coinníonn sé innéacs cuardaigh sa chuimhne. Ní
chóipeálann sé ábhar an chorpais isteach sa stór ná sa bhunachar sonraí.

Déantar an t-innéacs a athnuachan go hincriminteach. Athúsáidtear comhaid nár athraíodh bunaithe ar a méid agus ar am a
modhnaithe, athléitear comhaid athraithe agus déantar hais SHA-256 díobh, agus baintear comhaid scriosta.
Athnuachann cuardach innéacs atá níos sine ná 30 soicind; is féidir le glaoiteoirí athnuachan láithreach
a iarraidh freisin.

## Cumraigh an fhoinse

Éilíonn bealach na socruithe an fíordheimhniú bainistíochta céanna le APIanna socruithe eile.
Ní mór don chonair a chuirtear isteach a bheith ann cheana féin agus ní mór di a bheith ina conair absalóideach eolaire.

```bash
# Ceangail eolaire faofa
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Seiceáil an chumraíocht agus stádas an innéacs
curl http://localhost:20128/api/settings/local-corpus

# Dícheangail gan na comhaid fhoinseacha a athrú
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Uirlisí MCP

Éilíonn na trí uirlis ar fad `read:local-corpus`. Nochtann freagraí na n-uirlisí conairí coibhneasta agus
bunainm an eolaire fréimhe, ach ní nochtann siad a chonair absalóideach riamh.

| Uirlis                | Cur síos                                                                                            |
| :-------------------- | :-------------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Tuairiscigh staid na cumraíochta, méid an innéacs, teorainneacha, agus am na hathnuachana deireanaí |
| `local_corpus_search` | Cuardaigh téacs innéacsaithe agus tabhair míreanna teoranta de réir líne ar ais (suas le 20 toradh) |
| `local_corpus_read`   | Léigh raon teoranta línte ó chomhad ceadaithe amháin atá coibhneasta leis an gcorpas                |

Samplaí d'ionchuir MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Teorainneacha sábháilteachta

- Tá an liosta ceada dírithe ar théacs: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml`, agus `.yml`.
- Fágtar naisc shiombalacha ar lár. Déantar conairí léite a chanónú agus ní mór dóibh fanacht laistigh den
  fhréamh chumraithe; diúltaítear do chonairí absalóideacha agus d'iarrachtaí trasnaithe.
- Eisiatar ainmneacha eolairí íogaire agus ginte: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules`, agus
  `secrets`.
- Is iad na teorainneacha réamhshocraithe ná 5,000 comhad, 1 MiB in aghaidh an chomhaid, 64 MiB d'ábhar innéacsaithe san iomlán,
  thart ar 4,000 carachtar in aghaidh na smután cuardaigh, agus 400 líne in aghaidh na léitheoireachta.
- Caitear le comhaid ina bhfuil NUL mar chomhaid neamhtéacs agus fágtar ar lár iad nó diúltaítear dóibh.

Ní thacaítear d'aon ghnó le doiciméid dhénártha amhail PDF, DOCX, íomhánna agus cartlanna.
Tiontaigh iad go formáid téacs fhaofa san eolaire cumraithe sula ndéantar iad a innéacsú.

## Nótaí oibríochtúla

- Má athraítear nó má scriostar an fhréamh chumraithe, glantar an t-innéacs comhroinnte sa chuimhne.
- Má atosaítear próiseas, caitear an t-innéacs i leataobh; atógann an chéad chuardach eile é ón bhfoinse
  chumraithe.
- Ní chuireann `local_corpus_status` scanadh i bhfeidhm. Úsáid `local_corpus_search` le
  `refresh: true` nuair is gá athscanadh láithreach.
- Déantar teipeanna scantha agus léite a chomhaireamh nó a thabhairt ar ais mar earráidí sláintithe; ní
  mhodhnaítear comhaid fhoinseacha riamh.
