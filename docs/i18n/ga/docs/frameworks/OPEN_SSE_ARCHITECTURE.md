> **TL;DR**: Is é `open-sse/` an croí-inneall sruthaithe a chumhachtaíonn gach iarratas LLM in OmniRoute. Tá ~1,400 comhad ann a chuireann píblíne na n-iarratas, na seiceadóirí, na seirbhísí, an freastalaí MCP agus an tsraith aistriúcháin i bhfeidhm. Míníonn an treoir seo conas a oibríonn na codanna le chéile.

**Foinse:** `open-sse/` (pacáiste spáis oibre, ~1,440 comhad `.ts` nach comhaid tástála iad)

## Cén Fáth a bhfuil Pacáiste Spáis Oibre ar Leith ann?

Is **spás oibre neamhspleách** é `open-sse/` i monorepo OmniRoute ar roinnt cúiseanna:

1. **In-athúsáidteacht** — foilsítear `open-sse` mar `@omniroute/open-sse` ar npm, ionas gur féidir le tionscadail eile é a úsáid go neamhspleách
2. **Teorainneacha soiléire** — tá an t-inneall sruthaithe díchúpláilte ón tsraith UI/DB a bhaineann go sonrach le OmniRoute
3. **Feidhmíocht** — níl aon spleáchais Next.js ag an inneall, rud a chumasaíonn tosuithe fuara níos tapúla i gcomhthéacsanna CLI/gan fhreastalaí
4. **Leaganú** — is féidir le `open-sse` leaganacha a eisiúint de réir a sceidil féin

```json
// package.json
"workspaces": ["open-sse"]
```

## Píblíne na nIarratas

Téann gach iarratas LLM trí **phíblíne 5 chéim**:

```
                              ┌──────────────┐
   Iarratas HTTP               │  1. RÓDAIGH  │   réiteach teaglama, roghnú samhla
   (bealach Next.js)           └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  2. AISTRIGH │   tiontú formáide (OpenAI ↔ Claude ↔ Gemini)
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  3. RITH     │   seiceadóir soláthraí, HTTP, atriail, scoradán
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  4. SRUTHAIGH│   trasfhoirmiú SSE, cúlbhrú
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  5. TAIFEAD  │   rianú úsáide, logáil glaonna, aicmiú earráidí
                              └──────┬───────┘
                                     │
                                     ▼
                              Freagairt HTTP (SSE nó JSON)
```

### Céim 1: Ródú (services/combo.ts)

**Pointe iontrála**: `handleComboChat()` in `services/combo.ts`

Réitíonn sé an t-iarratas go tuple nithiúil `(provider, model, account, credentials)`:

- Aimsigh an teaglama de réir ID (nó tóg teaglama fíorúil do shamhlacha `auto/*`)
- Cuir an straitéis ródaithe i bhfeidhm (tosaíocht, ualaithe, rothlach, srl.)
- Scag amach soláthraithe míshláintiúla (scoradán ciorcaid)
- Roghnaigh an chéad sprioc inmharthana eile

I gcás samhlacha `auto/*`, déanann an chéim seo na nithe seo freisin:

- Ritheann sí an t-algartam **scórála 16 fhachtóir** (`services/autoCombo/`)
- Roghnaíonn sí péire `provider+model` bunaithe ar shláinte, costas, aga folaigh, srl.

### Céim 2: Aistriú (translator/)

Má tá formáid na foinse (m.sh., OpenAI) difriúil ó fhormáid na sprice (m.sh., Claude), déantar an t-iarratas a **aistriú**:

- Leid chórais → teachtaireacht chórais
- Sainmhínithe uirlisí → formáid uirlisí a bhaineann go sonrach leis an soláthraí
- Paraiméadair réasúnaíochta/smaointeoireachta → coibhéisí a bhaineann go sonrach leis an soláthraí
- Normalú ról teachtaireachta (`developer` → `system` i gcás córais nach OpenAI iad)

Nochtann `translator/index.ts`:

```ts
translateRequest(body, sourceFormat, targetFormat): TranslatedRequest
needsTranslation(source, target): boolean
```

### Céim 3: Rith (executors/)

**Pointe iontrála**: `getExecutor(providerId).execute(request, options)`

Úsáideann gach soláthraí `DefaultExecutor` (`executors/default.ts`) trí chúltaca mhonarcha `getExecutor()`. Déanann an seiceadóir na nithe seo:

- Tógann sé an URL réamhtheachtach (`buildUrl()`)
- Cuireann sé ceanntásca a bhaineann go sonrach leis an soláthraí leis (`buildHeaders()`)
- Trasfhoirmíonn sé corp an iarratais (`transformRequest()`)
- Seolann sé an t-iarratas HTTP le hatriail + cúlú easpónantúil
- Láimhseálann sé athnuachan fíordheimhnithe más gá (soláthraithe OAuth)

Síneann gach seiceadóir `BaseExecutor` (`executors/base.ts`, 1170 líne de chód), a sholáthraíonn:

- Loighic choiteann atrialach
- Comhtháthú seachfhreastalaí
- Comhtháthú scoradáin chiorcaid
- Crúcaí taifeadta úsáide

### Céim 4: Sruthú (utils/stream.ts)

I gcás freagairtí sruthaithe, seolann an seiceadóir **ReadableStream** ar ais. Déanann an láimhseálaí na nithe seo:

- Píobann sé trí thrasfhoirmiú SSE (`createSSETransformStreamWithLogger`)
- Cuireann sé pingeacha croíbhuille i bhfeidhm chun naisc mharbha a bhrath
- Láimhseálann sé dínascadh an chliaint go réidh (`pipeWithDisconnect`)
- Trasfhoirmíonn sé SSE → JSON do chliaint nach gcliant sruthaithe iad

I gcás freagairtí nach bhfuil sruthaithe, seolann an seiceadóir oibiacht JSON parsáilte ar ais, a chuirtear ar aghaidh gan athrú.

### Céim 5: Taifeadadh (services/usage.ts)

Tar éis an fhreagra (cibé acu rath nó teip), taifeadtar an úsáid:

- `prompt_tokens`, `completion_tokens`, `cached_tokens` ón bhfreagra
- `cost_usd` arna ríomh ó shonraí praghsála
- `latency_ms`, `status`, `error_class` má theipeann air
- Marthanaithe sa tábla `usage_history`

Scríobhtar déantáin loga glaonna (má tá siad cumasaithe) chuig `${DATA_DIR}/call_logs/`.

## Mionanailís ar na Príomhchomhaid

### chatCore.ts (5977 líne)

An **príomhláimhseálaí iarratas**. In ainneoin a mhéide, tá struchtúr soiléir aige:

```ts
// Bréagstruchtúr chatCore.ts
export async function handleChat(request: NextRequest) {
  // 1. Fíordheimhniú + CORS
  await authenticateRequest(request);
  applyCorsHeaders(response);

  // 2. Bailíochtú na colainne
  const body = await parseRequestBody(request);

  // 3. Brath formáide + aistriú
  const sourceFormat = detectFormat(request);
  const targetFormat = getTargetFormat(providerId);
  if (needsTranslation(sourceFormat, targetFormat)) {
    body = translateRequest(body, sourceFormat, targetFormat);
  }

  // 4. Ródú teaglama
  const targets = await resolveComboTargets(comboId, body);
  for (const target of targets) {
    try {
      const result = await executeOnTarget(target, body);
      await recordUsage(result);
      return result;
    } catch (err) {
      // Lean ar aghaidh chuig an chéad sprioc eile
    }
  }

  // 5. Cúltaca éigeandála
  return await emergencyFallback(body);
}
```

Cé gur feidhm ollmhór amháin atá ann, tá sí eagraithe ina **rannóga a bhfuil nótaí tráchta orthu** a chomhfhreagraíonn don phíblíne 5 chéim.

## Seiceadóirí (75+ comhad)

Comhad amháin in aghaidh an tsoláthraí. Síneann siad uile `BaseExecutor` agus sáraíonn siad an méid atá éagsúil.

### Patrúin Choitianta

Réitítear soláthraithe trí `getExecutor(providerId)`, a thugann an seiceadóir cumraithe ar ais. Úsáideann soláthraithe atá comhoiriúnach le OpenAI/Anthropic `DefaultExecutor` (`executors/default.ts`). Cumraítear iompar a bhaineann go sonrach leis an soláthraí (bun-URL, ceanntásca fíordheimhnithe, leagan API) in `open-sse/config/providers/`, agus láimhseáiltear claochluithe ar chorp an iarratais in `open-sse/translator/`.

Socraítear **URL saincheaptha** trí chumraíocht an tsoláthraí:

```ts
// Cumraíocht soláthraí in open-sse/config/providers/
export default {
  id: "together",
  baseURL: "https://api.together.xyz/v1/chat/completions",
}
````

Láimhseáiltear **fíordheimhniú saincheaptha** trí chumraíocht fíordheimhnithe chlárlann an tsoláthraí (eochair API, OAuth, próifílí ceanntásca).

Cláraítear claochluithe **saincheaptha ar chorp an iarratais** (m.sh., Anthropic ag scaradh `system` ó `messages`) de réir soláthraí in `open-sse/translator/`.

````

### Monarcha na Seiceadóirí

Easpórtálann `executors/index.ts` `getExecutor(providerId)`:

```ts
import { getExecutor } from "@omniroute/open-sse/executors";

const executor = getExecutor("anthropic");
const result = await executor.execute({
  model: "claude-sonnet-4-5",
  messages: [...],
});
````

Téann an réiteach tríd an `ExecutorRegistry` (`executors/registry.ts`): dearbhaítear gach seiceadóir speisialaithe sa tábla ionsuite in `executors/index.ts` agus cláraítear é trí `registerExecutor(alias, instance)` agus an modúl á lódáil; téann `getExecutor()` i gcomhairle leis an gclárlann agus téann sé ar ais chuig `DefaultExecutor` meamaithe i gcás aon soláthraí nach bhfuil iontráil speisialaithe aige. Saintréithítear an mhapáil iomlán ailias → seiceadóir leis an tástáil órga `tests/unit/executor-map-golden.test.ts`.

## Aistritheoirí

Aistrigh idir **3 fhormáid**: OpenAI, Anthropic, Gemini, chomh maith leis an Responses API nua.

### Cathain a Tharlaíonn an tAistriúchán

```ts
import { needsTranslation, translateRequest } from "@omniroute/open-sse/translator";

if (needsTranslation(sourceFormat, targetFormat)) {
  body = translateRequest(body, sourceFormat, targetFormat);
}
```

Aistriúcháin choitianta:

- `OpenAI → Anthropic`: réimse `system` ar leith, ceanntásc `x-api-key`
- `OpenAI → Gemini`: `contents` in ionad `messages`, `systemInstruction`
- `OpenAI → Responses API`: eagar `input`, staid `previous_response_id`

### Cásanna Imeallacha a Láimhseáiltear

- ról `developer` → `system` i gcás córais nach OpenAI iad
- ról `system` → cumasctha isteach sa chéad teachtaireacht úsáideora i gcás GLM/ERNIE
- `json_schema` → `responseMimeType` + `responseSchema` Gemini
- `tools` → formáid uirlisí a bhaineann go sonrach leis an soláthraí
- Paraiméadair smaointeoireachta (o1, Claude) → coibhéisí a bhaineann go sonrach leis an soláthraí

## Trasfhoirmeoirí

Tiontaíonn `open-sse/transformer/` idir formáidí **Chat Completions** agus **Responses API**.

### Cén Fáth a bhfuil Trasfhoirmeoir ar Leith Ann?

Is í Responses API formáid nua OpenAI ina bhfuil **comhráite staideacha** (`previous_response_id`). Nuair a sheolann cliant iarratas Responses, déanann OmniRoute an méid seo a leanas:

1. Tiontaíonn sé Responses → Chat Completions go hinmheánach
2. Seolann sé chuig an soláthraí é (aon soláthraí a thacaíonn le Chat Completions)
3. Tiontaíonn sé an freagra ar ais go formáid Responses
4. Sruthaíonn sé an freagra tiontaithe chuig an gcliant

Soláthraíonn an trasfhoirmeoir (`transformer/responsesTransformer.ts`):

```ts
createResponsesApiTransformStream(): TransformStream
```

Láimhseálann sé seo:

- teagmhais `response.output_item.added`
- teagmhais `response.output_text.delta`
- teagmhas `response.completed`
- Mapáil glaonna uirlise (`function_call` ↔ `tool_calls`)

## Comhpháirt Nua a Chur Leis

### Seirbhís Nua a Chur Leis

1. Cruthaigh `open-sse/services/[serviceName].ts` le freagracht shonrach
2. Easpórtáil an phríomhfheidhm láimhseála agus aon tairisigh
3. Cuir tástálacha aonaid leis in `tests/unit/services/[serviceName].test.mjs`
4. Comhtháthaigh í i bpíblíne na n-iarratas in `handlers/chatCore.ts` (má bhaineann sí le ródú)
5. Nuashonraigh an loighic ródaithe in `combo.ts` má théann an tseirbhís i bhfeidhm ar roghnú sprice
6. Déan í a dhoiciméadú sa chomhad seo

### Riteoir Nua a Chur Leis

1. Cruthaigh `open-sse/executors/[provider].ts` a leathnaíonn `BaseExecutor`
2. Cláraigh é in `config/providerRegistry.ts`
3. Cuir le monarcha `executors/index.ts` é
4. Cuir tástálacha aonaid leis don riteoir
5. Déan é a dhoiciméadú in `docs/architecture/ARCHITECTURE.md`

### Uirlis Nua MCP a Chur Leis

1. Cruthaigh nó nuashonraigh `open-sse/mcp-server/tools/[category]Tools.ts`
2. Sainmhínigh scéimre Zod le haghaidh ionchur
3. Cláraigh an uirlis in `mcp-server/index.ts`
4. Cuir leis an maitrís scóipe in `mcp-server/auth/` í
5. Cuir tástálacha aonaid leis
