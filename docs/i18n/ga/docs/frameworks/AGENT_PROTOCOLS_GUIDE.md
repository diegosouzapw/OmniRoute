Cuireann OmniRoute trí chomhéadan éagsúla a bhaineann le gníomhairí ar fáil. Tá cuma chomhchosúil orthu ar an gcéad amharc, ach réitíonn siad fadhbanna éagsúla. Úsáid an leathanach seo chun an ceann ceart a roghnú.

## Go hachomair

| Comhéadan                          | Is fearr é le haghaidh                                                                                                                                   | Iompar                                             | Caighdeán                      |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------ |
| **A2A — Gníomhaire le Gníomhaire** | Comhoibriú idir gníomhairí le piarghníomhairí a úsáideann prótacal A2A                                                                                   | JSON-RPC 2.0 thar HTTP                             | A2A v0.3 (sonraíocht oscailte) |
| **ACP — Clárlann Gníomhairí CLI**  | Gníomhairí códúcháin CLI atá suiteáilte ar ríomhaire an úsáideora a bhrath / a chlárú / a lainseáil (Cursor, Cline, Codex CLI, Claude Code, Aider, etc.) | HTTP REST                                          | Sainiúil do OmniRoute          |
| **Gníomhairí Néalríomhaireachta**  | Tascanna códúcháin fadtréimhseacha a chur faoi bhráid seirbhísí seachtracha néalríomhaireachta (Codex Cloud, Devin, Jules, Cursor Cloud)                 | HTTP REST + tascanna le tacaíocht bunachair sonraí | Sainiúil do OmniRoute          |

Tá na trí cinn neamhspleách ar a chéile — roghnaigh aon fhothacar díobh.

## Crann Cinnidh

```
An dteastaíonn seirbhís néalríomhaireachta uait chun obair a dhéanamh lasmuigh den ríomhaire seo (Codex Cloud / Cursor Cloud / Devin / Jules)?
├─ TÁ → Gníomhairí Néalríomhaireachta (POST /api/v1/agents/tasks)
└─ NÍL → Lean ar aghaidh
    │
    An bhfuil piarghníomhaire agat a úsáideann A2A agus ar mian leis comhoibriú?
    ├─ TÁ → A2A (POST /a2a)
    └─ NÍL → Lean ar aghaidh
        │
        An gá duit gníomhairí códúcháin CLI atá suiteáilte go háitiúil a liostú / a chumrú?
        ├─ TÁ → ACP (GET /api/acp/agents)
        └─ NÍL → Úsáid /v1/chat/completions lom
```

## 1. A2A — Gníomhaire le Gníomhaire

**Sonraíocht:** [A2A v0.3](https://a2a-protocol.org)
**Críochphointe OmniRoute:** `POST /a2a` (JSON-RPC 2.0)
**Cárta Gníomhaire:** `GET /.well-known/agent.json`

### Cathain ba cheart é a úsáid

- Córas ilghníomhaire a thógáil ina bhfuil OmniRoute ar cheann de na piaraí
- Faisnéis ródúcháin OmniRoute (ródú cliste, bainistiú cuótaí, etc.) a chur ar fáil do ghníomhairí i gcreataí amhail Google ADK nó i mogaill ghinearálta gníomhairí
- OmniRoute a fhilleadh taobh thiar de chomhéadan caighdeánach aimsithe + agartha

### Modhanna

- `message/send` — cuir teachtaireacht isteach agus faigh freagairt shioncrónach
- `message/stream` — cuir teachtaireacht isteach + faigh teagmhais dul chun cinn a shruthaítear trí SSE
- `tasks/get` — léigh tasc de réir a aitheantais
- `tasks/cancel` — cealaigh tasc atá ar siúl

### Scileanna ionsuite (6)

- `smart-routing` — ródáil leid tríd an teaglaim is fearr
- `quota-management` — tuairiscigh staid chuóta gach soláthraí
- `provider-discovery` — liostaigh soláthraithe suiteáilte agus a gcumais
- `cost-analysis` — déan costas iarratais/comhrá a mheas
- `health-report` — comhiomlánaigh staid scoradáin/tréimhse shuaimhnithe/frithdhúnadh gach soláthraí
- `list-capabilities` — liostaigh scileanna agus meiteashonraí an ghníomhaire atá ar fáil

### Mionscrúdú

Féach ar [A2A-SERVER.md](./A2A-SERVER.md) le haghaidh sonraí iompair, struchtúr an chárta gníomhaire, cumraíocht TTL na dtascanna, agus an teimpléad chun scileanna nua a chur leis.

## 2. ACP — Clárlann Gníomhairí CLI

**Críochphointe OmniRoute:** `GET /api/acp/agents`
**Foinse:** `src/lib/acp/{index,manager,registry}.ts`

### Cad é atá ann

Is é ACP **fardal áitiúil gníomhairí CLI** OmniRoute. Aimsíonn sé cé na CLIanna códaithe atá suiteáilte ar an óstríomhaire (Cursor, Cline, Claude Code, Codex CLI, Continue, srl.), aimsíonn sé a leaganacha, agus cuireann sé ar fáil don deais iad ionas gur féidir leis an úsáideoir gach CLI a chumrú chun OmniRoute a úsáid.

NÍ prótacal seachtrach é seo — is clárlann inmheánach é a chumhachtaíonn comhéadan úsáideora "CLI Tools" agus rianú méarlorg CLI (féach [CLI-TOOLS.md](../reference/CLI-TOOLS.md)).

### Cad a dhéanann sé

- Scrúdaíonn sé an t-óstríomhaire le haghaidh dénártha CLI suiteáilte (úsáideann sé `which` / `where` de réir an chórais oibriúcháin)
- Léann sé leagan gach CLI (glaonn sé `<bin> --version`)
- Glacann sé, go roghnach, le gníomhairí saincheaptha arna sainiú ag an úsáideoir (conair dhénártha + tóireadóir leagain + argóintí sceite)
- Coinníonn sé gníomhairí saincheaptha sna socruithe
- Seolann sé an liosta aontaithe ar ais chuig an deais

### API REST

| Críochphointe     | Modh | Cur síos                                                                                 | Fíordheimhniú |
| ----------------- | ---- | ---------------------------------------------------------------------------------------- | ------------- |
| `/api/acp/agents` | GET  | Liosta de ghníomhairí aimsithe + saincheaptha (líon suiteáilte/iomlán)                   | Eochair API   |
| `/api/acp/agents` | POST | Cuir gníomhaire saincheaptha leis/nuashonraigh/bain é (idirdhealaitheoir gnímh sa chorp) | Eochair API   |

Cruth an choirp le haghaidh POST (`customAgentBodySchema` in `src/app/api/acp/agents/route.ts`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### Cásanna úsáide

- Liostaíonn leathanach "CLI Tools" na deaise a bhfuil suiteáilte agus cabhraíonn sé leat gach ceann acu a dhíriú ar OmniRoute
- Ligeann gníomhairí saincheaptha d’ardúsáideoirí CLIanna inmheánacha/dílseánaigh nach n-aithníonn OmniRoute de réir réamhshocraithe a chlárú
- Cuireann toradh an bhraite sonraí ar fáil don mhaitrís méarlorg `cli-tools`

### Cathain NÁ húsáid ACP

- Ní _ritheann_ ACP tascanna. Ní dhéanann sé ach CLIanna a bhrath + a chumrú. Chun CLI a agairt i ndáiríre, seolann tú féin é leis na hathróga timpeallachta a chuireann OmniRoute ar fáil (`OPENAI_BASE_URL`, `OPENAI_API_KEY`, srl.).

## 3. Gníomhairí Néalríomhaireachta

**Críochphointí OmniRoute:** `/api/v1/agents/tasks/*` (saolré) + `/api/cloud/*` (bonneagar nasctha)
**Foinse:** `src/lib/cloudAgent/`

### Cad é atá ann

Comhéadan aonfhoirmeach thar ghníomhairí códaithe néalríomhaireachta tríú páirtí. Cuireann tú leid + URL stórtha isteach, seolann OmniRoute chuig an ngníomhaire néalríomhaireachta ceart é, déanann sé stádas a pholláil, agus seolann sé na torthaí ar ais.

### Gníomhairí a dtacaítear leo (4, iad uile deimhnithe in `src/lib/cloudAgent/agents/`)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### Saolré

```
POST /api/v1/agents/tasks
  → BaseAgent.createTask() de réir aicme an ghníomhaire
  → tosaíonn an tseirbhís sheachtrach an obair
  → cruthaítear ró tasc sa bhunachar sonraí (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → sioncronú leisciúil stádais ón soláthraí
  → seolann sé an stádas reatha + plean + loga gníomhaíochta ar ais
  ↓
POST /api/v1/agents/tasks/[id]   (gníomh: "approve" | "message" | "cancel")
  → cuirtear ar aghaidh chuig an soláthraí é (nó marcáiltear mar chealaithe go háitiúil é)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → cealú áitiúil
```

### Fíordheimhniú

⚠️ **Teastaíonn fíordheimhniú bainistíochta ó gach críochphointe `/api/v1/agents/tasks/*`** (tiomantas `588a0333`). Faigheann glaoiteoirí nach n-úsáideann ach Bearer freagra 401 ó v3.8.0 i leith.

### Mionscrúdú

Féach [CLOUD_AGENT.md](./CLOUD_AGENT.md) le haghaidh chonradh `CloudAgentBase`, sonraí a bhaineann go sonrach le gach gníomhaire, mionsonraí scéimre, agus críochphointí bhonneagar na ndintiúr.

## Comparáid: A2A vs Gníomhairí Néalríomhaireachta

Tá “tascanna fadtéarmacha” ag an dá cheann, ach ag sraitheanna éagsúla:

| Gné                  | A2A                                                                                 | Gníomhairí Néalríomhaireachta                       |
| -------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
| Caighdeán            | Open A2A v0.3                                                                       | Sonrach do OmniRoute                                |
| Cá ritheann an ríomh | Laistigh de OmniRoute (úsáideann sé teaglamaí cumraithe)                            | Go seachtrach (freastalaithe Codex / Devin / Jules) |
| Fad an taisc         | TTL réamhshocraithe 5 nóiméad (inchumraithe in `TaskManager`)                       | Nóiméid go huaireanta                               |
| Feasach ar stór      | Níl (ní sheolann sé ach leideanna)                                                  | Tá (URL an stóir + brainse)                         |
| Cás úsáide           | Comhoibriú trasghníomhairí, ródú cliste mar sheirbhís                               | “Cuir gné X i bhfeidhm i stór Y” a tharmligean      |
| Fíordheimhniú        | `OMNIROUTE_API_KEY` roghnach do `/a2a`; bainistíocht do chúntóirí REST `/api/a2a/*` | Bainistíocht i gcónaí                               |

## Samplaí Comhtháthaithe

### Faigh amach cumais A2A OmniRoute

```bash
curl http://localhost:20128/.well-known/agent.json
```

Seolann sé an Cárta Gníomhaire ar ais leis na 6 scil, na hiompróirí agus an leagan go léir.

### Glaoigh ar OmniRoute mar ghníomhaire A2A

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### Liostaigh gníomhairí CLI suiteáilte trí ACP

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### Cuir gníomhaire saincheaptha CLI leis

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

### Cuir tasc Gníomhaire Néalríomhaireachta isteach

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Implement feature X in repo Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### Seiceáil stádas an taisc néalríomhaireachta go tréimhsiúil

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```

## Cathain is Ceart Gach Ceann a Úsáid

- **Comhéadan úsáideora róbhrá / comhphíolóta** → `/v1/chat/completions` (comhoiriúnach le OpenAI — ní prótacal gníomhaire é)
- **Comhoibriú ilghníomhairí** → A2A
- **CLIanna áitiúla a liostú sa deais** → ACP
- **Tascanna códúcháin fadtéarmacha a tharmligean chuig seirbhísí néalríomhaireachta** → Gníomhairí Néalríomhaireachta
