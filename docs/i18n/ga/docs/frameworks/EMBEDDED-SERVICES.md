## 3. Meaisín staide saolré

```
                    install()
  ┌─────────────┐ ──────────► ┌─────────────┐
  │ not_installed│             │   stopped   │◄──────────────────┐
  └─────────────┘             └──────┬──────┘                   │
                                     │ start()                   │
                                     ▼                           │ stop()
                               ┌──────────┐                      │
                               │ starting │                      │
                               └────┬─────┘                     │
            taiscéalaí sláinte ceart│         tuairt / SIGTERM   │
                               ┌────▼─────┐  (scor laistigh de 5s)│
                               │ running  │──── tuairt ──────────►┤
                               └────┬─────┘                   ┌─▼────┐
                             stop() │                          │error │
                                    ▼                          └──────┘
                               ┌──────────┐
                               │ stopping │
                               └──────────┘
```

Stóráiltear na staideanna i dtábla DB `version_manager` (colún `status`) agus déantar
iad a scáthánú i staid chuimhne inmheánach `ServiceSupervisor`. Is í an staid chuimhne
inmheánach an fhoinse údarásach do phróiseas atá ar siúl; is í staid DB an rogha
mharthanach chúltaca tráth tosaithe.

### Trasdulta staide

| Ó               | Teagmhas                                        | Go dtí                 |
| --------------- | ----------------------------------------------- | ---------------------- |
| `not_installed` | éiríonn le `install()`                          | `stopped`              |
| `stopped`       | glaoitear `start()`                             | `starting`             |
| `starting`      | filleann an taiscéalaí sláinte 200              | `running`              |
| `starting`      | scoireann an próiseas sula mbíonn sé sláintiúil | `error`                |
| `running`       | glaoitear `stop()`                              | `stopping` → `stopped` |
| `running`       | scoireann an próiseas gan choinne (< 5 s)       | `error` (tuairt thapa) |
| `running`       | scoireann an próiseas gan choinne (> 5 s)       | `error`                |
| `error`         | glaoitear `start()`                             | `starting`             |
| aon cheann      | `stop()` agus é `stopping`                      | gan oibríocht          |

### Glas oibríochta

Déanann `ServiceSupervisor` oibríochtaí saolré a shraithiú trí ghlas oibríochta
aisioncronach (`withLock()`). Má dhéantar glaonna comhthráthacha ar `start()` ar an
maoirseoir céanna, ní chruthaítear ach próiseas amháin; fanann an dara glaoiteoir agus
filleann sé an stádas atá ann cheana. Cuireann sé seo cosc ar riochtaí rása nuair,
mar shampla, a ghníomhaíonn uath-thosú agus cnaipe sa chomhéadan úsáideora ag an am céanna.

## 4. Tagairt API

Tá gach bealach faoi `/api/services/` **LOCAL_ONLY** (aisch lúibe amháin, riail dhocht #17).
Faigheann iarratais nach ón aisch lúibe iad `403 LOCAL_ONLY` beag beann ar an chomhartha fíordheimhnithe.

### 4.1 Críochphointí 9Router (11 bhealach)

#### `POST /api/services/9router/install`

Suiteáil 9Router ó npm. Cruthaítear `DATA_DIR/services/9router/` lena
`package.json` agus `node_modules/` féin. Ní thagann sé salach ar spleáchais OmniRoute féin.

**Corp an iarratais** (iad uile roghnach):

```json
{ "version": "latest" }
```

| Réimse    | Cineál   | Réamhshocrú | Cur síos                               |
| --------- | -------- | ----------- | -------------------------------------- |
| `version` | `string` | `"latest"`  | Clib leagain npm nó semver le suiteáil |

**Freagraí:**

| Stádas | Cur síos                                                                 |
| ------ | ------------------------------------------------------------------------ |
| `200`  | `{ ok: true, installedVersion: "x.y.z", path: "..." }`                   |
| `400`  | Corp iarratais neamhbhailí (teip bailíochtaithe Zod)                     |
| `409`  | Suiteáil ar bun cheana féin (glas á choinneáil)                          |
| `500`  | Theip ar shuiteáil npm — féach `message` le haghaidh earráide sothuigthe |

**Nótaí:** Úsáidtear `execFile('npm', [...])` — gan bhlaosc, gan idirshuíomh (riail dhocht #13).
Taispeántar earráidí EACCES mar theachtaireachtaí sothuigthe.

---

#### `POST /api/services/9router/start`

Tosaigh 9Router. Cláraítear maoirseoir mura bhfuil ceann cláraithe cheana, agus ansin glaoitear ar
`supervisor.start()`. Tá sé iديमphoitéinseach má tá sé ag rith cheana féin.

**Corp an iarratais:** gan aon cheann

**Freagraí:**

| Stádas | Cur síos                                               |
| ------ | ------------------------------------------------------ |
| `200`  | Oibiacht `ServiceStatus` (féach an scéimre thíos)      |
| `409`  | Níl 9Router suiteáilte (`status: "not_installed"`)     |
| `503`  | Theip ar an tosú (earráid próisis — féach `lastError`) |

**Scéimre ServiceStatus:**

```json
{
  "tool": "9router",
  "state": "running",
  "pid": 12345,
  "port": 20130,
  "health": "healthy",
  "startedAt": "2026-05-25T10:00:00.000Z",
  "lastError": null
}
```

### 4.8 Seachfhreastalaí droim ar ais (leabú dheais 9Router)

Leabaíonn an deais comhéadan gréasáin 9Router laistigh de iframe trí
sheachfhreastalaí droim ar ais inmheánach ag:

```
GET|POST|... /dashboard/providers/services/9router/embed/[...path]
```

Déanann an seachfhreastalaí seo na nithe seo a leanas:

- Cuireann sé an t-iarratas ar aghaidh chuig `http://127.0.0.1:{port}/{path}` (aischúrsáil amháin)
- Baineann sé na ceanntásca `cookie` agus `authorization` atá ag teacht isteach (ní sceitear seisiún OmniRoute)
- Insteallann sé `Authorization: Bearer {apiKey}` le haghaidh fhíordheimhniú 9Router
- Baineann sé `set-cookie`, `content-security-policy`, `x-frame-options`, `cross-origin-*` den fhreagra
- Athscríobhann sé freagraí HTML chun `<base href>` a instealladh agus conairí absalóideacha a normalú (`/foo` → `/dashboard/.../embed/foo`)

Láimhseálann freastalaí compánach ar phort tiomnaithe uasghráduithe WebSocket
don deais leabaithe (féach `src/lib/services/embedWsProxy.ts`).

**Slándáil:** aicmítear bealaí an tseachfhreastalaí leabaithe faoi
`LOCAL_ONLY_API_PREFIXES` agus ní féidir iad a rochtain ach ón aischúrsáil.
Ní féidir le hionsaitheoir a fhaigheann JWT trí thollán Cloudflare/Ngrok
seachfhreastáil isteach i seirbhísí leabaithe.

## 5. Slándáil

### Forfheidhmiú LOCAL_ONLY (riail dhocht #17)

Aicmítear gach bealach faoi `/api/services/` agus `/dashboard/providers/services/*/embed/`
mar LOCAL_ONLY in `src/server/authz/routeGuard.ts`. Ritheann an tseiceáil loopback
gan choinníoll roimh aon bhrainse fíordheimhnithe:

```
tagann an t-iarratas
  → isLocalOnlyPath(path)?
      → ní loopback é → 403 LOCAL_ONLY (i gcónaí, roimh an tseiceáil fíordheimhnithe)
      → loopback é    → lean ar aghaidh chuig an ngnáthfhíordheimhniú
```

Cuireann sé seo cosc ar JWT sceite (m.sh., trí thollán) `npm install` nó
sceitheadh próisis a thionscnamh. Féach `docs/security/ROUTE_GUARD_TIERS.md` don
mhaitrís iomlán sraitheanna.

### Instealladh eochrach API

Teastaíonn eochair API/comhartha iompróra ó 9Router agus Mux dá gcríochphointí HTTP féin.
Déanann OmniRoute an méid seo a leanas:

1. Gineann sé eochair trí `crypto.randomBytes(32).toString("base64url")` le
   réimír a bhaineann go sonrach leis an tseirbhís (`nr_` do 9Router, `mx_` do Mux).
2. Criptíonn sé í agus í ar fos ag úsáid AES-256-GCM (an sifear céanna a úsáidtear do dhintiúir soláthraithe).
3. Díchriptíonn agus insteallann sé í mar athróg timpeallachta tráth sceite —
   `NINEROUTER_API_KEY` do 9Router, `MUX_SERVER_AUTH_TOKEN` do Mux (ní mar bhratach CLI
   riamh, ionas nach mbíonn an comhartha le feiceáil riamh i liostaí `ps`/próiseas).
4. Ní sheolann sé an eochair ghnáth-théacs ar ais riamh in aon fhreagairt HTTP.

Faigheann CLIProxyAPI eochair thiomnaithe don phlána sonraí a instealltar tráth sceite
(`needsApiKey: true` — úsáidtear í chun samhlacha a shioncronú leis an oiriúntóir).

### Cosaint SSRF

Tá an seachfhreastalaí droim ar ais HTTP (`/dashboard/.../embed/[...path]`) códaithe go docht ionas nach gcuireann sé
ar aghaidh ach chuig `http://127.0.0.1:{port}`. Ní leanann sé atreoruithe chuig
cinn scríbe nach loopback iad riamh. Úsáidtear leabharlann `ssrf-req-filter` chun aon URL réamhtheachtach a
réitíonn lasmuigh den raon loopback a dhiúltú.

### Sábháilteacht bhlaoisce (riail dhocht #13)

Glaoitear `npm install` trí `execFile('npm', ['install', pkg, '--prefix', dir])` —
gan aon teimpléid liteartha, blaosc ná idirshuíomh conairí seachtracha i dteaghrán na
hordaithe. Cuirtear luachanna am rite (poirt, eochracha API) ar aghaidh trí oibiacht `env` an phróisis linbh.

### Sláintíocht earráidí (riail dhocht #12)

Téann gach freagairt earráide ó `/api/services/*` trí `buildErrorBody()` nó
`sanitizeErrorMessage()`. Ní sheoltar `err.stack` ná `err.message` amh ar ais
focal ar fhocal chuig an nglaoiteoir riamh.

#### Conradh breiseáin soláthraí inphlugáilte (Céim 1, #7333)

Tugann `src/lib/services/providerPlugins/` conradh `ServiceProviderPlugin` isteach a
phacáistíonn réimsí `ServiceEntry` ó `bootstrap.ts` de chuid inneall cúil agus réimsí

chéanna a chur in iúl ar leithligh in dhá chomhad neamhghaolmhara. Agus é seo á scríobh, **níl ach `9router`

`getServiceProviderPlugin("9router")` (`src/lib/services/providerPlugins/registry.ts`),
agus caitear earráid tosaithe má bhíonn an breiseán ar iarraidh riamh. Fanann `cliproxy`, `mux`, agus `bifrost`
ar na liteartha inlíne `SERVICES[]` a bhí ann cheana, gan athrú.

Cuireadh cúntóir breisitheach
`createServiceBackendManifestEntry(pluginId, template)` le `open-sse/config/providerPluginManifest.ts` freisin, a thógann
`ProviderPluginManifestEntry` dea-chumtha ó iontráil `SERVICE_BACKEND_MANIFEST_TEMPLATE` — níl sé
**nasctha** le haon chonair iarratais bheo fós (ná le `generateProviderPluginManifestFromRegistry()`
ná le `/v1/providers/[provider]/models`); fanann sin mar obair leantach a luaithe a bheidh an conradh
cruthaithe do dhara hinneall cúil.

Cuireadh siar chuig PRanna leantacha é, arna rianú faoi shaincheist #7333: `cliproxyapi` a aistriú tríd an
gclárlann chéanna, `mux`/`bifrost` a ghinearálú isteach san aontas `ServiceBackendPluginId`,
an láimhseáil speisialta ar ródú seiceadóirí (`open-sse/executors/index.ts`,
`open-sse/handlers/chatCore/executorProxy.ts`) a ionchorprú sa chonradh breiseáin, agus

## 7. Fabhtcheartú

### Ní thosaíonn an tseirbhís

**Comharthaí:** Tugann an cnaipe tosaithe 503 ar ais, agus fanann an staid mar `"error"` nó `"starting"`.

**Seicliosta:**

1. Seiceáil `GET /api/services/{name}/logs` (nó painéal na Logaí sa deais). Cuardaigh
   línte amhail `Error: ENOENT`, `address already in use`, nó `Cannot find module`.
2. Deimhnigh go bhfuil `npm` in PATH: `which npm` ón gcuntas úsáideora céanna a ritheann OmniRoute.
3. Deimhnigh go bhfuil an tseirbhís suiteáilte: seiceáil `GET /api/services/{name}/status` le haghaidh
   `installedVersion`. Más `null` atá ann, rith an tsuiteáil ar dtús.
4. Seiceáil go bhfuil `DATA_DIR/services/{name}/node_modules/` ann agus nach bhfuil sé folamh.
5. Seiceáil an réimse `lastError` sa fhreagairt stádais le haghaidh chúis slánaithe an scortha.

---

### Tá an fuarthosú mall (> 10 s chun `running` a bhaint amach)

**Comharthaí:** Fanann an staid mar `"starting"` ar feadh i bhfad sula n-athraíonn sí go `"running"` nó `"error"`.

**Míniú:** Áirítear le fuarthosú 9Router crainn mhóra spleáchas a iompórtáil (DNS,
tollán, modúil MITM). Is é 2 s an t-eatramh réamhshocraithe sláinte, le 3 iarracht sula
bhfógraíonn an maoirseoir teorainn ama (ach leanann sé den vótaíocht).

**Réiteach:** Is féidir an teorainn ama `healthIntervalMs` agus `waitForHealthy`
(`healthIntervalMs * 3`) a chumrú in `bootstrap.ts`. I gcás seirbhísí a bhfuil agaí
tosaithe níos faide acu, méadaigh `healthIntervalMs` go 5000 agus `stopTimeoutMs` go 30 000.

---

### Imbhualadh poirt (`EADDRINUSE`)

**Comharthaí:** Taispeánann na logaí `address already in use :::20130`.

**Cúiseanna:**

- Tá próiseas eile ag úsáid phort 20130 cheana féin.
- Níor stopadh próiseas 9Router roimhe seo go hiomlán (PID zombaí).

**Réiteach:**

1. Athraigh an port réamhshocraithe tríd an athróg timpeallachta `NINEROUTER_PORT` in `.env`.
2. Aimsigh agus maraigh an próiseas atá ag teacht salach air: `lsof -ti :20130 | xargs kill -9`.
3. Is féidir an port a chumrú do gach seirbhís in `bootstrap.ts` tríd an réimse `port`.

**Nóta:** Úsáideann 9Router port 20130 de réir réamhshocraithe go sonrach chun imbhualadh le
port réamhshocraithe OmniRoute, 20128, a sheachaint.

---

### Cead diúltaithe (EACCES) le linn suiteála

**Comharthaí:** Tugann an tsuiteáil 500 ar ais, agus taispeánann na logaí `EACCES` nó `permission denied`.

**Cúiseanna:**

- Níl `DATA_DIR` ná a mháthairchomhadlann inscríofa ag próiseas OmniRoute.
- Tá sé á rith laistigh de Docker gan phribhléidí fréimhe agus gan rochtain scríofa ar an imleabhar mapáilte.

**Réiteach:**

1. Seiceáil `DATA_DIR` (réamhshocrú: `~/.omniroute/`): `ls -la ~/.omniroute/`
2. Cinntigh gur le húsáideoir phróiseas OmniRoute an chomhadlann: `chown -R $USER ~/.omniroute/`
3. In Docker, cinntigh go bhfuil na ceadanna cearta don úsáideoir coimeádáin ag gléasadh an imleabhair.

---

### Teipeann ar an nuashonrú (teorainn ama `npm install` nó earráid líonra)

**Comharthaí:** Tugann an nuashonrú 500 ar ais le `InstallError`, agus taispeánann na logaí teorainn ama líonra.

**Seicliosta:**

1. Deimhnigh gur féidir clárlann npm a rochtain: `npm ping`.
2. Seiceáil seachfhreastalaí corparáideach: `npm config get proxy`, `npm config get https-proxy`.
3. Bain triail as an tsuiteáil de láimh: `npm install {package}@latest --prefix ~/.omniroute/services/{name}/`.
4. Má tá tú taobh thiar de bhearna aeir, réamh-íoslódáil an tarball agus úsáid `npm install /path/to/tarball.tgz`.

---

### Taispeánann an tseirbhís staid `"error"` díreach tar éis tosaithe (tuairt thapa)

**Comharthaí:** Athraíonn an staid ó `"starting"` go `"error"` laistigh de 5 shoicind.
Taispeánann `lastError` `"Fast crash (exited with code 1)"`.

**Seicliosta:**

1. Léigh eireaball iomlán an loga: `GET /api/services/{name}/logs?tail=500`.
2. Cúis choitianta: athróga timpeallachta a bhfuil an tseirbhís ag súil leo a bheith ar iarraidh.
3. I gcás 9Router: deimhnigh go bhfuil `NINEROUTER_DISABLE_MITM=true` agus
   `NINEROUTER_DISABLE_TUNNEL=true` sa timpeallacht a chuirtear ar aghaidh tráth sceite (féach
   `installers/ninerouter.ts` `resolveSpawnArgs`).

## 8. Ceisteanna Coitianta

**C: An féidir liom críochphointí na seirbhísí leabaithe a nochtadh do chliaint nach cliaint loopback iad?**

Ní féidir. Tá an tsraith LOCAL_ONLY ann d’aon ghnó (riail dhocht #17). Ní ceadmhach bealaí ar féidir leo
`npm install` a agairt nó próisis `node` a thosú a bheith inrochtana ó thrácht nach trácht loopback é,
mar dá sceithfí JWT trí thollán (Cloudflare, Ngrok, Tailscale), d’fhéadfaí próisis threallacha
a thosú murach sin. Níl aon eisceacht roghnach ann do
`/api/services/` — murab ionann agus `/api/mcp/`, tá sé eisiata ó liosta seachanta an scóip bhainistíochta.
Féach `docs/security/ROUTE_GUARD_TIERS.md`.

---

**C: An mbeidh 9Router agus CLIProxyAPI ar fáil in imscaradh táirgthe/scamaill?**

Beidh. Leanann an dá sheirbhís an tsamhail chéanna atá áitiúil ar dtús agus a leanann OmniRoute féin. Ritheann siad
ar an meaisín céanna agus déanann siad cumarsáid thar loopback. Ciallaíonn "táirgeadh" anseo an VPS
nó an freastalaí áitiúil ar a bhfuil OmniRoute imscartha, seachas soláthraí cianda néalríomhaireachta.

---

**C: Conas a dhéanaim dífhabhtú ar an maoirseoir?**

1. Lean sruth loga SSE: `curl -N http://localhost:20128/api/services/9router/logs`.
2. Seiceáil na logaí struchtúrtha in aschur pino OmniRoute agus iad scagtha de réir
   an ainmspáis `service:supervisor`.
3. Scrúdaigh an ró sa bhunachar sonraí: `sqlite3 ~/.omniroute/omniroute.db "SELECT * FROM version_manager WHERE tool='9router'"`.
4. Úsáid `GET /api/services/9router/status` chun an staid bheo reatha, PID, sláinte,
   agus `lastError` a fheiceáil in aon ghlao amháin.

---

**C: Taispeánann an maoirseoir `health: "degraded"` nó `health: "unknown"` ach is é `"running"` an staid. An fadhb é sin?**

Ciallaíonn `"degraded"` gur thug an tóireadóir sláinte freagra nach freagra 200 é. Ciallaíonn `"unknown"` nach bhfuil aon
tóireadóir críochnaithe fós (rás leis an gcéad vótaíocht). Bíonn an dá cheann sealadach le linn tosaithe.
Má fhanann an tsláinte ag `"degraded"` ar feadh níos mó ná `healthIntervalMs * 3` ms tar éis
`"running"`, tá an tseirbhís leabaithe ag rith ach níl a API HTTP ag freagairt. Seiceáil
an bhfuil an port ceart sa fhreagra stádais agus an bhfuil an tseirbhís ag éisteacht
ar an bport sin i ndáiríre.

---

**C: An féidir liom eochair API 9Router a athrú gan atosú iomlán?**

Ní féidir. Cuirtear an eochair API ar aghaidh chuig 9Router trí athróg timpeallachta tráth tosaithe an phróisis.
Ní féidir athróga timpeallachta a athrú i bpróiseas atá ag rith. Stopann agus atosaíonn `POST .../rotate-key`
an tseirbhís go huathoibríoch chun an eochair nua a chur i bhfeidhm. Tagann rothlú na heochrach
i bhfeidhm laistigh de `stopTimeoutMs` na seirbhíse (15 s de réir réamhshocraithe) móide a tréimhse
tosaithe.

---

**C: Cad é teorainn an mhaoláin fháinnigh agus cad a tharlaíonn nuair a líontar é?**

Tá maolán fáinneach tiomnaithe 5 MB ag gach seirbhís. Nuair a bhíonn an maolán lán, díbrítear na línte loga
is sine chun spás a dhéanamh do chinn nua. Tugann an teagmhas SSE `snapshot`
na línte is déanaí laistigh den teorainn `tail` ar ais. Ní bhuanchoimeádtar logaí ar diosca mura bhfuil
`logsBufferPath` socraithe sa ró sa bhunachar sonraí.
