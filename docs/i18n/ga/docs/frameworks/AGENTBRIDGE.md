Is é AgentBridge seachfhreastalaí MITM (Man-in-the-Middle) OmniRoute a idircheapann trácht HTTPS ó ghníomhairí AI in IDEanna agus a athródálann é trí inneall ródaithe aontaithe OmniRoute. Tacaíonn sé le **10 ngníomhaire IDE** — Antigravity, Kiro, GitHub Copilot, GHE Copilot, OpenAI Codex, Cursor, Zed, Claude Code, Open Code, agus Trae (faoi fhiosrú) — rud a fhágann gurb é OmniRoute an seachfhreastalaí MITM don réimse is leithne cúntóirí códaithe AI ar an margadh.

**Suíomh an deais:** `/dashboard/tools/agent-bridge`
**Grúpa sa bharra taoibh:** Uirlisí (i ndiaidh Cloud Agents)
**Féach freisin:** [`TRAFFIC_INSPECTOR.md`](./TRAFFIC_INSPECTOR.md) — déan monatóireacht ar an trácht idircheaptha ar fad i bhfíor-am; `docs/security/MITM-TPROXY-DECRYPT.md` (git; gan a bheith tiomsaithe isteach in `/docs`) — mód gabhála trédhearcach-díchriptithe Linux TPROXY atá á rialú ag an mbealach `/api/tools/agent-bridge/tproxy`.

## §1 Forbhreathnú

### Cad é AgentBridge?

Nuair a dhéanann gníomhaire IDE (m.sh., GitHub Copilot, Cursor, Claude Code) glao API, nascann sé go díreach leis an soláthraí AI réamhtheachtach (OpenAI, Anthropic, srl.). Idircheapann AgentBridge an nasc sin go trédhearcach ag an leibhéal TLS — gan aon athrú cumraíochta ar an ngníomhaire a éileamh — agus athscríobhann sé an t-iarratas trí OmniRoute.

Ciallaíonn sé seo gur féidir leat:

- **Aon ghníomhaire a athródú chuig aon soláthraí**: Copilot ag cumarsáid le OpenAI? Atreoraigh é chuig Anthropic Claude, Gemini, nó aon cheann de 352 soláthraí OmniRoute.
- **Mapálacha samhlacha a chur i bhfeidhm**: `gemini-3-flash` → `claude-sonnet-4.7` go trédhearcach ag leibhéal an láimhseálaí.
- **Trácht uile na ngníomhairí a bhreathnú**: foilsítear gach iarratas idircheaptha sa [Chigire Tráchta](./TRAFFIC_INSPECTOR.md).
- **Athléimneacht OmniRoute a chur i bhfeidhm**: oibríonn ródú teaglama, scoradáin chiorcaid, cúltacaí, agus rianú costas do thrácht gníomhairí IDE freisin.

## §2 Ailtireacht

### 2.1 Forbhreathnú ar na comhpháirteanna

```
Gníomhaire IDE (VS Code / Cursor / etc.)
    │  HTTPS (port 443)
    ▼
/etc/hosts — 127.0.0.1 api.githubcopilot.com   ← Atreorú DNS
    │
    ▼
src/mitm/server.cjs  (port 443, próiseas mac CJS)
    │  réitíonn sé an sprioc de réir SNI an cheanntáisc Host
    │  gineann sé teastas TLS in aghaidh an SNI sínithe ag CA AgentBridge
    ├── Meaitseáil sa liosta seachanta? → TCP passthrough (gan díchriptiú)
    ├── Meaitseáil sprice? → fetch → ródaire OmniRoute (port 20128)
    │       └── handler.intercept() — TypeScript
    │               ├── maskSecrets() ar chorp/ceanntásca an iarratais
    │               ├── TrafficBuffer.push() — foilsíonn sé chuig an gCigire Tráchta
    │               └── fetchRouter() → /v1/chat/completions
    └── Gan mheaitseáil? → TCP passthrough (gan díchriptiú)
```

### 2.2 Freastalaí MITM (`src/mitm/server.cjs`)

Ritheann croífhreastalaí MITM mar phróiseas mac Node.js CJS (chun athscríobh an bhunachair chóid CJS reatha a sheachaint). Déanann sé na nithe seo a leanas:

- Éisteann sé ar phort 443 (teastaíonn pribhléid nó `authbind`/`setcap`)
- Faigheann sé tolláin CONNECT ón OS (trí atreorú DNS `/etc/hosts`)
- Gineann sé teastais TLS in aghaidh an SNI atá sínithe ag CA AgentBridge (`DATA_DIR/mitm/ca.crt`)
- Réitíonn sé an gníomhaire sprice de réir an cheanntáisc Host trí chlárlann `targets/index.ts`
- Seolann sé chuig sraith láimhseála TypeScript trí HTTP ag `http://127.0.0.1:20128`

Lódáiltear `TARGET_HOSTS` ó `DATA_DIR/mitm/targets.json` (arna scríobh ag `targets/index.ts` tráth tosaithe), rud a cheadaíonn nuashonruithe dinimiciúla gan an freastalaí CJS a atosú.

> **Samhail fréamh-CA (#6684).** Is í an cur síos thuas ar theastas in aghaidh an SNI arna shíniú ag CA
> an tsamhail bhuanaithe fréamh-CA a cuireadh leis in #6684 (`src/mitm/cert/rootCa.ts` +
> `src/mitm/_internal/rootCaShim.cjs`, ag athúsáid chripteagrafaíocht CA/duilleoige atá
> cruthaithe cheana féin do TPROXY in `src/mitm/tproxy/dynamicCert.ts`) — tagann sí in ionad na
> seanduilleoige stataí féinshínithe aonair (`src/mitm/cert/generate.ts`, atá
> teoranta fós do na hóstach antigravity amháin) a léiríonn péire lom
> `server.crt`/`server.key` ar an diosca. **Iompar imirce**: faigheann suiteáil úr (gan
> `server.crt` roimhe seo) an tsamhail fréamh-CA go huathoibríoch; leanann suiteáil a raibh
> muinín aici as an tseanduilleog statach dá húsáid go dtí go socraíonn an t-oibreoir
> `MITM_ROOT_CA_ENABLED=true` agus go n-atosaíonn sé an droichead (`src/mitm/cert/migration.ts`
> an fheidhm chinnteoireachta íon — tá CA MITM iontaofa atá in ann duilleog a shíniú do
> **aon** óstach i bhfad níos cumhachtaí ná an tseanduilleog SAN seasta, mar sin ní dhéantar
> an t-athrú go ciúin riamh i gcás suiteáil a bhfuil muinín aici aisti cheana féin). Suiteáiltear teastas an CA
> sa sliotán céanna `omniroute-mitm.crt` sa stór muiníne a d'úsáid an tseanduilleog
> (`cert/install.ts::installCaCert`) — ní gá glantachán démhuiníne.

### 2.3 Bonn an láimhseálaí (`src/mitm/handlers/base.ts`)

Leathnaíonn gach láimhseálaí gníomhaire `MitmHandlerBase`:

```ts
export abstract class MitmHandlerBase {
  abstract readonly agentId: AgentId;

  abstract intercept(
    req: IncomingMessage,
    res: ServerResponse,
    body: Buffer,
    mappedModel: string
  ): Promise<void>;

  // Cúntóirí cosanta: fetchRouter, pipeSSE, hookBufferStart, hookBufferUpdate
}
```

Glaonn gach láimhseálaí ar `hookBufferStart()` roimh sheachfhreastáil agus ar `hookBufferUpdate()` nuair atá sé críochnaithe. Cuireann siad seo iontrálacha `InterceptedRequest` isteach in `globalTrafficBuffer` (féach [Cigire Tráchta](./TRAFFIC_INSPECTOR.md) §4).

### 2.4 Clárlann spriocanna (`src/mitm/targets/`)

Tá comhad spriocanna dearbhaitheach ag gach gníomhaire:

```ts
// src/mitm/targets/copilot.ts
export const COPILOT_TARGET: MitmTarget = {
  id: "copilot",
  name: "GitHub Copilot",
  hosts: ["api.githubcopilot.com", "copilot-proxy.githubusercontent.com"],
  port: 443,
  endpointPatterns: ["/chat/completions", "/v1/chat/completions"],
  defaultModels: [{ id: "gpt-4o", name: "GPT-4o", alias: "gpt-4o" }],
  handler: () => import("../handlers/copilot"),
  riskNoticeKey: "providers.riskNotice.oauth",
};
```

Easpórtálann an chlárlann (`targets/index.ts`) `ALL_TARGETS` agus astaíonn sí `DATA_DIR/mitm/targets.json` tráth tosaithe.

### 2.5 Seachsheoladh agus liosta seachanta (`src/mitm/passthrough.ts`)

**Liosta seachanta** (seiceáiltear ar dtús é, agus tá tosaíocht aige ar mheaitseáil sprice):

- Patrúin réamhshocraithe: óstaigh bhaincéireachta, `.gov.`, soláthraithe OAuth/SSO (Okta, Auth0), etc.
- Patrúin úsáideora: stóráiltear iad i dtábla DB `agent_bridge_bypass`
- Faigheann óstaigh sheachanta tollán trédhearcach TCP — **ní dhéantar TLS a dhíchriptiú riamh**

**Seachsheoladh réamhshocraithe** (gan mheaitseáil sprice agus gan a bheith sa liosta seachanta):

- Faigheann sé tollán TCP freisin — ní bhristear naisc riamh
- Cuireann sé cosc ar AgentBridge cur isteach ar thrácht ginearálta HTTPS an chórais

Ord tosaíochta an ródaithe:

```
liosta seachanta → meaitseáil sprice → seachsheoladh
```

### 2.6 Teastas CA réamhtheachtach (`src/mitm/upstreamTrust.ts`)

Le haghaidh timpeallachtaí líonra corparáideacha a bhfuil CA saincheaptha acu:

```bash
AGENTBRIDGE_UPSTREAM_CA_CERT=/path/to/corporate-ca.pem
```

Nuair a shocraítear é, cumraíonn sé seoltóir domhanda `undici` leis an teastas CA breise, rud a ligeann do AgentBridge soláthraithe réamhtheachtacha a bhaint amach trí sheachfhreastalaithe corparáideacha foirceanta TLS.

### 2.7 Ceilt rún (`src/mitm/maskSecrets.ts`)

Cuirtear an scanóir neamhspleách glansheomra i bhfeidhm ar choirp iarratais agus ar cheanntásca dintiúr
**sula** dtéann siad isteach i maolán an Chigire Tráchta nó in aon loga. Déanann sé pas líneach amháin:

- Comharthaí le réimír `sk-` / `ak-` / `pk-` (ar nós OpenAI/Anthropic)
- Dintiúir RFC 6750 `Authorization: Bearer <token>`, agus tosaíocht ag an gcomhartha iomlán
- Comharthaí teimhneacha fada cineálacha (≥40 carachtar), lena n-áirítear foirmeacha le poncanna agus stuáil

Tiontaíonn `sanitizeHeaders()` ainmneacha coinnithe go cás íochtair, nascann sé luachanna eagair go cinntitheach, baineann sé
an liosta comhroinnte séanta hop-ar-hop/frámála (lena n-áirítear fíordheimhniú seachfhreastalaí), folaimhíonn sé `cookie` agus
`set-cookie` go hiomlán, agus tarmligeann sé luachanna dintiúr chuig an scanóir.

## §3 Socrú

### 3.1 Freastalaí MITM a thosú/a stopadh

Úsáid Cárta Freastalaí AgentBridge ag `/dashboard/tools/agent-bridge`:

| Gníomh                 | Cur síos                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| Tosaigh an Freastalaí  | Seolann sé `src/mitm/server.cjs` ar phort 443                                                      |
| Stop an Freastalaí     | Múchann sé an próiseas mac go slachtmhar                                                           |
| Atosaigh an Freastalaí | Stopadh + tosú (cuirtear athruithe sprice i bhfeidhm)                                              |
| Cuir Muinín sa Teastas | Suiteálann sé `DATA_DIR/mitm/ca.crt` i stór muiníne an OS                                          |
| Íoslódáil an Teastas   | Íoslódálann sé `ca.crt` lena shuiteáil de láimh                                                    |
| Athghin an Teastas     | Cruthaíonn sé eochairphéire CA nua (neamhbhailítear gach teastas reatha in aghaidh an ghníomhaire) |

### 3.2 Muinín a chur sa teastas

Ní mór d'fheidhmchóras an teastas CA AgentBridge a bheith iontaofa sula nglacfaidh IDEanna leis an nasc MITM.

**Linux (NSS — Chrome/Firefox):**

```bash
certutil -A -d sql:$HOME/.pki/nssdb -n "OmniRoute AgentBridge" -t CT,, -i ~/.omniroute/mitm/ca.crt
```

**macOS (Keychain):**

```bash
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/.omniroute/mitm/ca.crt
```

**Windows (certmgr):**

```powershell
certutil -addstore -f Root $env:USERPROFILE\.omniroute\mitm\ca.crt
```

Nó úsáid an cnaipe "Cuir Muinín sa Teastas" sa deais (ritheann sé an t-ordú cuí do d'OS, le leid sudo más gá).

#### Déanann IDEanna atá bunaithe ar Electron neamhaird de stór muiníne an OS (`NODE_EXTRA_CA_CERTS`)

Cuimsíonn roinnt IDEanna — go háirithe **Antigravity IDE**, agus aipeanna eile atá díorthaithe ó Electron / VS Code —
a dtimpeallacht rite Node.js féin nach **seiceálann stór muiníne an OS** le haghaidh
`fetch`/HTTPS amach. Is leor muinín a chur sa CA ar leibhéal an OS/NSS do **chúl-inneall** dúchasach an IDE
(m.sh. freastalaí teanga Go, a úsáideann beart CA an OS), ach teipfidh TLS fós sa
**chomhéadan Electron** — feictear é seo mar an aip a bheith _logáilte amach_ nó mar
_"earráid naisc"_ fiú agus a léiríonn loga MITM go bhfuil `200` á thabhairt ar ais ag glaonna
tosaithe an chúl-innill. Tá dhá chéim riachtanach, agus tá an dá cheann tábhachtach:

1. Dírigh an timpeallacht rite ar an CA go sainráite:
   ```bash
   export NODE_EXTRA_CA_CERTS=/path/to/omniroute-agentbridge-ca.crt
   ```
2. **Seol an IDE ón mblaosc sin.** Má thosaítear é ón deilbhín deisce / Dock / roghchlár Start,
   ní bhfaighidh sé na heaspórtálacha blaosca mar oidhreacht, agus ní chuirtear `~/.config/environment.d/*.conf`
   i bhfeidhm ach amháin tar éis logáil isteach ghrafach úr. Scoir den IDE go hiomlán ar dtús — ciallaíonn
   glas aonáis Electron nach ndéanann an dara seoladh ach an próiseas reatha a thabhairt chun tosaigh agus
   déantar neamhaird den timpeallacht nua.

Tá an chéim muiníne OS + NSS thuas riachtanach fós (léann cruach líonra Chromium a úsáideann roinnt sreafaí
fíordheimhnithe an stór NSS in aghaidh an úsáideora, agus tá pionnaí statacha dá chuid féin aige do
`*.googleapis.com` a sháraíonn CA a bhfuil muinín áitiúil ann as). Clúdaíonn `NODE_EXTRA_CA_CERTS`
cosán `fetch` Node sa bhreis air sin.

### 3.3 Ródú DNS

I gcás gach gníomhaire is mian leat a idircheapadh, ní mór dá óstach API nó dá óstaigh API réiteach go `127.0.0.1`. Bainistíonn AgentBridge iontrálacha `/etc/hosts` go huathoibríoch nuair a scoránaíonn tú DNS do ghníomhaire sa Draoi Socraithe.

Samplaí d'iontrálacha `/etc/hosts` do GitHub Copilot:

```
127.0.0.1 api.githubcopilot.com
127.0.0.1 copilot-proxy.githubusercontent.com
```

### 3.4 Mapáil samhlacha

Úsáid an Tábla Mapála Samhlacha i ngach cárta gníomhaire chun mapálacha foinse → sprioc a shainiú:

| Samhail foinse (dúchasach don ghníomhaire) | Samhail sprice (OmniRoute) |
| ------------------------------------------ | -------------------------- |
| `gpt-4o`                                   | `claude-sonnet-4.7`        |
| `*` (saoróg)                               | `claude-haiku-4.7`         |

Mapálann an tsaoróg `*` aon samhail neamhaitheanta chuig an sprioc shonraithe. Coinnítear í sa tábla `agent_bridge_mappings`.

> **Leid — aimsigh fíor-IDanna samhlacha an ghníomhaire.** Féadfaidh IDE ainmneacha samhlacha a sheoladh atá éagsúil
> óna lipéid chomhéadain agus a athraíonn idir mórleaganacha. Mar shampla, seolann **Antigravity 2**
> `gemini-3.1-pro-low`, `gemini-pro-agent`, agus `gemini-3.1-flash-lite` thar an nasc — ní hé
> `gemini-2.5-pro` a thaispeántar i ndoiciméid níos sine. Seol comhrá amháin gan aon mhapáil mheaitseála i bhfeidhm:
> logálann MITM an `model:` isteach cruinn agus ligeann sé don iarratas dul tríd. Mapáil an luach litriúil sin,
> agus ansin déantar an chéad iarratas eile a idircheapadh agus a ródú chuig do sprioc.

### 3.5 Fógra riosca

Idircheapann AgentBridge na dintiúir (comharthaí OAuth, eochracha API) a úsáideann an IDE chun fíordheimhniú le soláthraithe réamhtheachtacha. Déantar iad seo a **mhascadh roimh logáil** (féach §2.7), ach tá siad infheicthe ag ciseal MITM OmniRoute. Taispeántar dialóg mhódúil fógra riosca is féidir a dhúnadh nuair a ghníomhachtaítear gach gníomhaire den chéad uair.

### 3.6 Cothabháil & Diagnóisic

Cuireann an deais cárta **Cothabháil & Diagnóisic** (`AgentBridgeMaintenanceCard`, in `src/app/(dashboard)/dashboard/tools/agent-bridge/components/`) ar fáil, a nochtann bealaí oibríochtúla MITM nach raibh aon chomhéadan úsáideora acu roimhe seo. A fhotheideal: _"Déan féintástáil ar an bpíblíne gabhála, cealaigh staid chórais atá fágtha, agus bog do shocrú idir meaisíní."_ Tá cúntóirí cliaint an chárta in `src/lib/inspector/agentBridgeMaintenanceApi.ts`.

| Cnaipe                    | Bealach                                | A dhéanann sé                                                                                                                                                                                                                                 |
| ------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Diagnóisigh**           | `GET /api/tools/agent-bridge/diagnose` | Ritheann sé féintástáil na píblíne gabhála agus taispeánann sé tuairisc do gach seiceáil (✓/✗ + leid leasúcháin).                                                                                                                             |
| **Deisigh**               | `POST /api/tools/agent-bridge/repair`  | Cealaíonn sé staid dhílleachtach MITM sa chóras (iontrálacha bréagaithe DNS, CA fréimhe, seachfhreastalaí córais) a fágadh tar éis tuairteála nó SIGKILL. | Ainm na seiceála   | A bhfíoraíonn sé                                                | Leid ar theip                                                                                                                                                                                 |
| ------------------ | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Rith Deisigh chun í a ghlanadh."_ — agus aibhsíonn sé an cnaipe **Deisigh**. > Coinnítear CA fréimhe MITM suiteáilte idir stopadh agus tosú chun leideanna sudo
> athfhillteacha a sheachaint (an t-iompar céanna le mitmproxy/Charles), mar sin is gníomh sainráite
> **Bain CA** é a bhaint seachas rud a tharlaíonn go huathoibríoch nuair a stoptar é.

### 3.7 Iompórtáil/easpórtáil cumraíochta iniompartha

Is féidir le AgentBridge an staid **is féidir leis an oibreoir a choigeartú** a shraithiú ina bhlob JSON le leagan, ionas gur féidir socrú a mhacasamhlú thar mheaisíní éagsúla. Is é `src/lib/inspector/configPortability.ts` an sraitheoir (`exportConfig()` / `importConfig()`), arna bhailíochtú ag `AgentBridgeConfigSchema`.

Cuimsíonn an t-easpórtáil trí phíosa go díreach (ní easpórtáiltear na réamhshocruithe ionsuite d’aon ghnó, ionas nach ndéanfaidh iompórtáil iad a dhúbailt ná teacht salach orthu choíche):

| Réimse           | Foinse                                                                    | Nótaí                                                                            |
| ---------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `bypassPatterns` | patrúin seachghabhála arna sainiú ag an úsáideoir (`agent_bridge_bypass`) | fágtar na patrúin réamhshocraithe bainc/rialtais/okta as an áireamh              |
| `customHosts`    | óstaigh shaincheaptha Traffic Inspector (`inspector_custom_hosts`)        | gach ceann: `{ host, kind: "llm"\|"app"\|"custom", label? }`                     |
| `agentMappings`  | mapálacha samhlacha de réir gníomhaire (`agent_bridge_mappings`)          | `{ [agentId]: [{ source, target }] }` do gach gníomhaire a bhfuil mapálacha aige |

```jsonc
// GET /api/tools/agent-bridge/config
{
  "version": 1,
  "bypassPatterns": ["*.internal.example.com"],
  "customHosts": [{ "host": "api.example.com", "kind": "llm", "label": null }],
  "agentMappings": {
    "copilot": [{ "source": "gpt-4o", "target": "claude-sonnet-4.7" }],
  },
}
```

**Iompar iompórtála** (`POST /api/tools/agent-bridge/config`): cuirtear patrúin seachghabhála agus mapálacha de réir gníomhaire in ionad a chéile **go hiomlán**; cuirtear óstaigh shaincheaptha leis **go hidéimpitéinseach** (`INSERT OR IGNORE`). Tuairiscíonn an freagra cé mhéad de gach ceann a cuireadh i bhfeidhm:

```jsonc
{ "ok": true, "bypassPatterns": 1, "customHosts": 1, "agents": 1 }
```

Cad é nach bhfuil sa chumraíocht: staid reatha an fhreastalaí, conairí teastais, staid DNS gach gníomhaire, conair an CA réamhtheachtaigh, ná socruithe TPROXY — is staid óstaigh/ama rite iad sin, ní sainroghanna iniompartha.

### Liosta seachanta d'óstaigh íogaire

Cinntíonn an liosta seachanta nach ndéantar trácht ó institiúidí airgeadais, ó sholáthraithe OAuth/SSO ná ó óstaigh íogaire eile a **dhíchriptiú choíche**. Gabhann a dtrácht TLS tríd mar thollán trédhearcach TCP — ní fheiceann OmniRoute an gnáth-théacs choíche.

Áirítear iad seo a leanas leis na patrúin seachanta réamhshocraithe:

- `*.bank.*`, `*.gov.*` (airgeadas/rialtas)
- `*.okta.com`, `*.auth0.com`, `*.microsoft.com` (SSO/aitheantas)
- `*.apple.com`, `*.icloud.com` (seirbhísí córais Apple)

Stóráiltear patrúin seachanta a chuireann úsáideoirí leis sa tábla `agent_bridge_bypass` agus bíonn tosaíocht acu ar gach rud eile.

### Folú rún

Cuirtear `maskSecrets()` ó `src/mitm/maskSecrets.ts` i bhfeidhm:

- Ar gach corp iarratais roimh `TrafficBuffer.push()`
- Ar gach ceanntásc roimh logáil nó craoladh

Patrúin: comharthaí leis na réimíreanna `sk-`/`ak-`/`pk-`, comharthaí `Bearer`, agus comharthaí cineálacha ina bhfuil ≥40 carachtar.

### Teastas CA réamhtheachtach

Nuair a shocraítear `AGENTBRIDGE_UPSTREAM_CA_CERT`, léitear an comhad ag am tosaithe. Má tá an chonair ann ach mura féidir an comhad a léamh, logálann AgentBridge earráid shoiléir agus diúltaíonn sé tosú (rud a chuireann cosc ar theipeanna ciúine TLS i dtimpeallachtaí corparáideacha).

### Teorainneacha aitheanta

- **Teastaíonn pribhléid ó phort 443**: Ar Linux, teastaíonn `setcap 'cap_net_bind_service=+ep'` ó AgentBridge ar dhénártha Node, nó ní mór é a rith trí `authbind`. Taispeánann an Treoraí Socraithe treoracha a bhaineann go sonrach leis an gcóras oibriúcháin.
- **Ní mór an IDE a atosú**: Tar éis an atreoraithe DNS, ní mór an IDE a atosú chun go dtiocfaidh taifeach nua an óstaigh i bhfeidhm.
- **Comharthaí OAuth cruachódaithe**: Stórálann roinnt gníomhairí (Kiro, Antigravity) comharthaí athnuachana OAuth go háitiúil. Tá siad seo trédhearcach do AgentBridge — feiceann sé an comhartha Bearer i ngach iarratas, agus foluítear é roimh logáil.
- **Teastaíonn `NODE_EXTRA_CA_CERTS` ó chomhéadain Electron**: Déanann IDEanna a bhfuil a gcomhéadan ag rith ar am rite cuachta Node/Electron neamhaird de stór muiníne an chórais oibriúcháin/NSS agus ní mór iad a sheoladh ó bhlaosc ina bhfuil `NODE_EXTRA_CA_CERTS` socraithe (féach §3.2). Siomptóm nuair atá sé ar iarraidh: fíordheimhníonn inneall cúil an IDE (taispeánann MITM `200`anna) ach fanann an comhéadan úsáideora logáilte amach.
- **Tá suiteálacha iolracha den IDE céanna neamhspleách ar a chéile**: is próisis ar leith iad suiteáil chórais (m.sh. `/usr/share/antigravity/antigravity`) agus suiteáil úsáideora-áitiúil "Full" (m.sh. `~/AntigravityIDE_Full/antigravity-ide`), agus a n-amanna rite féin acu — ní mór gach ceann acu a athsheoladh agus an CA insteallta ann. Sainaithin cé acu atá ag rith de réir chonair a dhénártha sula n-athsheoltar é.
- **Socraítear an t-aitheantas le leid chórais an ghníomhaire, ní leis an tsamhail ródaithe**: nuair a athmhapálann tú samhail gníomhaire chuig soláthraí eile, maíonn an freagra fós aitheantas dúchasach an ghníomhaire (m.sh. freagraíonn Antigravity "Táim á chumhachtú ag Gemini") toisc go n-insteallann an IDE é sin sa leid chórais. Deimhnigh an fíor-inneall cúil in `call_logs` / `proxy_logs` (`provider`, `model`, `target_format`), seachas fiafraí den tsamhail cé hí féin.

## §6 Fabhtcheartú

### Coinbhleacht ar phort 443

Má tá próiseas eile ag éisteacht ar phort 443 cheana féin (freastalaí gréasáin, VPN, srl.):

```bash
lsof -i :443          # aimsigh an próiseas
sudo fuser -k 443/tcp  # marú éigeantach (úsáid go cúramach)
```

Mar rogha eile, cumraigh port neamhphribhléideach i socruithe AgentBridge agus socraigh rialacha atreoraithe `iptables` / `pf`.

### Níl muinín as an teastas

Má thaispeánann an IDE earráidí TLS tar éis AgentBridge a thosú:

1. Deimhnigh gur suiteáladh an teastas: `security find-certificate -c "OmniRoute AgentBridge"` (macOS) nó `certutil -L -d sql:$HOME/.pki/nssdb` (Linux/NSS)
2. Coinníonn roinnt aipeanna a stór muiníne féin (Firefox, Chrome ar Linux). Rith "Trust Cert" arís agus seiceáil an stór teastas a bhaineann go sonrach le NSS/Firefox.
3. Atosaigh an IDE tar éis muinín a chur sa teastas — úsáideann seisiúin TLS atá ar bun cheana féin an seanstádas muiníne.

### IDE logáilte amach / "earráid cheangail" in ainneoin CA iontaofa

Siomptóm: tar éis DNS a atreorú agus muinín a chur sa CA, osclaítear IDE bunaithe ar Electron (m.sh. Antigravity)
agus é **logáilte amach** nó taispeánann sé earráid fíordheimhnithe/cheangail, cé go léiríonn loga MITM go bhfuil na
glaonna tosaithe (`loadCodeAssist`, `fetchAvailableModels`, …) ag filleadh `200`.

Cúis: déanann **am rite Node/Electron cuachta an IDE neamhaird de stór muiníne an OS**. Cuireann an t-inneall
dúchais (freastalaí teanga Go) muinín i CA an OS agus fíordheimhníonn sé, ach ní dhéanann an ceann tosaigh Electron
amhlaidh — mar sin creideann an Chomhéadain go bhfuil sí as líne.

Réiteach (an dá chéim): easpórtáil `NODE_EXTRA_CA_CERTS=<ca.crt>` **agus atosaigh an IDE ón
mblaosc sin**, ní ón deilbhín deisce. Scoir den IDE go hiomlán ar dtús — ciallaíonn glas aonáis Electron
nach ndéanann an dara seoladh ach an próiseas atá ann cheana a thabhairt chun tosaigh agus go ndéantar neamhaird den timpeallacht nua. Féach §3.2.
Tá sé seo ar aon dul le tuairisc oscailte réamhtheachtach ina n-oibríonn gníomhaire neamhspleách trí MITM ach ina dteipeann ar an leagan
IDE faoin socrú céanna.

### DNS gan a bheith iomadaithe

Seiceáil gur nuashonraíodh `/etc/hosts`:

```bash
grep "omniroute\|127.0.0.1.*github\|127.0.0.1.*cursor" /etc/hosts
```

Glan taisce DNS:

```bash
# macOS
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder
# Linux (systemd-resolved)
sudo systemctl restart systemd-resolved
# Windows
ipconfig /flushdns
```

### IDE gan a bheith braite

Úsáideann uathbhrath conairí suiteála coitianta. Má theipeann ar an mbrath ach go bhfuil an IDE suiteáilte:

- Seiceáil an bhfuil dénártha an IDE i suíomh neamhchaighdeánach
- Oibríonn an Draoi Socraithe fós — ní chiallaíonn teip braite ach nach dtaispeánfaidh an suaitheantas an chonair suiteála

### Earráidí láimhseálaí (teipeann ar an aisghabháil réamhtheachtach)

Má dhéanann AgentBridge idircheapadh ach má theipeann ar gach iarratas:

1. Deimhnigh go bhfuil soláthraí amháin ar a laghad ceangailte ag `/dashboard/providers`
2. Seiceáil logaí freastalaí OmniRoute: `APP_LOG_LEVEL=debug` in `.env`
3. Deimhnigh go ndíríonn `OMNIROUTE_BASE_URL` ar chríochphointe ceart an ródaire (réamhshocrú: `http://127.0.0.1:20128`)

## §8 Treochlár

### Imscrúdú ar Trae

Is cúntóir códaithe AI measartha nua é Trae. Sula gcuirtear láimhseálaí i bhfeidhm:

1. Sainaithin an clár dénártha/an eisínteacht i margaí VS Code / JetBrains nó mar aip neamhspleách
2. Gabh an trácht le mitmproxy chun óstaigh API agus cruthanna críochphointí a aimsiú
3. Aimsigh an mheicníocht fíordheimhnithe
4. Déan cinneadh dul ar aghaidh/gan dul ar aghaidh bunaithe ar na TOS agus ar in-aimsitheacht an API

Go dtí go mbeidh an t-imscrúdú críochnaithe, taispeánfaidh cárta Trae sa deais suaitheantas "Á Imscrúdú" mar aon le nasc "Tuairiscigh inmharthanacht". Caitheann creatlach an láimhseálaí ag `src/mitm/handlers/trae.ts` earráid struchtúrtha `Níl sé curtha i bhfeidhm fós`.

### Gníomhairí sa riaráiste (MITM riachtanach — gan aon tacaíocht do bhun-URL saincheaptha)

Ní thacaíonn na huirlisí seo a leanas le bun-URLanna saincheaptha ina leaganacha reatha, rud a fhágann gurb é MITM an t-aon bhealach idircheaptha. Tá measúnú inmharthanachta fós ar feitheamh:

- **Windsurf** (Codeium/Cognition)
- **Amp** (Sourcegraph)
- **Amazon Q / Kiro CLI** (AWS Bedrock — ar leithligh ó Kiro IDE)
- **Cowork** (aip deisce Anthropic)

Nóta: Tacaíonn GitHub Copilot CLI ≥v1.0.19 le `COPILOT_PROVIDER_BASE_URL` — bain úsáid as cumraíocht dhíreach in ionad MITM don uirlis sin.
