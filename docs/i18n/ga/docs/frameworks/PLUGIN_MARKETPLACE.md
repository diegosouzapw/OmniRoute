> **Foinse na fírinne:** `src/lib/plugins/` (`marketplace.ts`, `manager.ts`, `manifest.ts`,
> `scanner.ts`, `loader.ts`), `src/app/api/plugins/`, agus
> `src/app/(dashboard)/dashboard/plugins/`
> **Nuashonraithe go deireanach:** 2026-06-28 — v3.8.40

Tagann OmniRoute le córas breiseán ar nós WordPress. Is eolairí féinchuimsitheacha
iad na breiseáin — agus forléiriú `plugin.json` agus comhad iontrála ag gach ceann acu — a
nascann leis an bpíblíne iarratais (`onRequest` / `onResponse` / `onError`) agus le
teagmhais saolré (`onInstall` / `onActivate` / `onDeactivate` / `onUninstall`).

Is é **Margadh na mBreiseán** an tsraith aimsithe atá ar bharr an chórais sin. Cuireann sé
catalóg inbhrabhsáilte de bhreiseáin insuiteáilte ar fáil. De réir réamhshocraithe, is
clárlann síl bheag ionsuite í an chatalóg; is féidir le hoibreoir í a dhíriú ar URL clárlainne
cianda saincheaptha, agus sa chás sin déantar an t-aisghabháil a chruachan le cosantóir SSRF
a réitíonn DNS (féach [Slándáil](#security)).

Is **don lúb siar amháin** gach bealach breiseáin (Sraith 1 — `LOCAL_ONLY`): lódálann
agus ritheann breiseáin cód i bpróisis mhic, mar sin ní féidir na bealaí a bhaint amach ó
fhoinse nach lúb siar í, beag beann ar fhíordheimhniú. Féach
[`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md).

## An chaoi a n-oibríonn sé le chéile

```
Deais (/dashboard/plugins)
  ├─ Cluaisín "Suiteáilte" → GET /api/plugins            (listPlugins)
  │                         POST /api/plugins/scan      (pluginManager.scan)
  │                         POST /api/plugins/{name}/activate|deactivate
  │                         DELETE /api/plugins/{name}   (díshuiteáil)
  └─ Cluaisín "Margadh"    → GET /api/plugins/marketplace
                              → listMarketplacePlugins()
                                ├─ gan URL saincheaptha → SEED_REGISTRY ionsuite
                                └─ URL saincheaptha → cosantóir SSRF isSafeMarketplaceUrl()
                                                    → safeOutboundFetch(guard:"public-only")
```

- **Sraith na clárlainne** — `src/lib/plugins/marketplace.ts`: liostaíonn / cuardaíonn sí an
  chatalóg, agus téann sí ar ais chuig an gclárlann síl má tharlaíonn aon teip.
- **Sraith na saolré** — `src/lib/plugins/manager.ts` (aonairín `pluginManager`):
  suiteáil, uasghrádú, gníomhachtú, díghníomhachtú, díshuiteáil, scanadh, lódáil tosaithe.
- **Sraith an fhorléirithe** — `src/lib/plugins/manifest.ts`: scéimre Zod + luachanna réamhshocraithe do
  `plugin.json`.
- **Scanóir** — `src/lib/plugins/scanner.ts`: aimsíonn sé breiseáin ar an diosca faoi
  eolaire na mbreiseán.
- **Lódálaí** — `src/lib/plugins/loader.ts`: seolann sé gach breiseán i bpróiseas mic
  leithlisithe agus idirghabhálann sé glaonna crúcaí thar IPC.

## Catalóg an Mhargaidh

Tugann `listMarketplacePlugins()` (`src/lib/plugins/marketplace.ts`) liosta de
réada `MarketplaceEntry` ar ais:

| Réimse        | Cineál   | Nótaí                                                 |
| ------------- | -------- | ----------------------------------------------------- |
| `name`        | string   | Ainm breiseáin i gcás kebab                           |
| `version`     | string   | semver                                                |
| `description` | string   | Achoimre ghairid                                      |
| `author`      | string   | Údar / eagraíocht                                     |
| `license`     | string   | Aitheantas ceadúnais ar nós SPDX                      |
| `downloadUrl` | string   | URL íoslódála foinse (d'fhéadfadh sé a bheith folamh) |
| `repository`  | string?  | URL roghnach stórtha                                  |
| `tags`        | string[] | Clibeanna cuardaigh/scagtha                           |
| `downloads`   | number   | Líon íoslódálacha                                     |
| `rating`      | number   | 0–5                                                   |
| `verified`    | boolean  | An bhfuil an iontráil marcáilte mar fhíoraithe        |
| `lastUpdated` | string   | Teaghrán dáta ar nós ISO                              |

Nuair nach bhfuil URL clárlainne saincheaptha cumraithe, is í an `SEED_REGISTRY`
ionsuite an chatalóg (`request-logger`, `rate-limiter`, `cost-tracker`, agus
`theme-manager` faoi láthair). Bíonn an chlárlann síl ar fáil i gcónaí — má tá clárlann
chianda chumraithe doshroichte, má thugann sí stádas nach `200` é ar ais, nó má thugann sí
corp neamhaitheanta ar ais, logálann `listMarketplacePlugins()` rabhadh agus téann sé ar
ais chuig an liosta síl.

> Nóta: tá **catalóg** an mhargaidh (brabhsáil/cuardach) ceangailte ó cheann ceann, ach
> níl **suiteáil** aonchliceáil ón gcatalóg curtha i bhfeidhm fós — taispeánann cnaipe
> "Suiteáil" na deaise ar iontráil sa mhargadh fógra "ag teacht go luath" faoi láthair.
> Déantar an tsuiteáil inniu trí shreabhadh suiteála an chosáin logánta
> (`POST /api/plugins`) agus trí aimsiú ar an diosca (`POST /api/plugins/scan`).

## API REST

Éilíonn gach críochphointe fíordheimhniú bainistíochta (`requireManagementAuth`) **agus** níl siad
inrochtana ach ón loopback — tá `/api/plugins` agus `/api/plugins/` liostaithe in
`LOCAL_ONLY_API_PREFIXES` (`src/server/authz/routeGuard.ts`).

| Críochphointe                    | Modh   | Cur síos                                                              |
| -------------------------------- | ------ | --------------------------------------------------------------------- |
| `/api/plugins`                   | GET    | Liostaigh breiseáin suiteáilte (scagaire roghnach `?status=`)         |
| `/api/plugins`                   | POST   | Suiteáil breiseán ó chonair áitiúil absalóideach                      |
| `/api/plugins/scan`              | POST   | Scan eolaire na mbreiseán agus cláraigh breiseáin nua                 |
| `/api/plugins/marketplace`       | GET    | Liostaigh iontrálacha chatalóg an mhargaidh                           |
| `/api/plugins/[name]`            | GET    | Faigh sonraí breiseáin suiteáilte                                     |
| `/api/plugins/[name]`            | DELETE | Díshuiteáil breiseán                                                  |
| `/api/plugins/[name]/activate`   | POST   | Gníomhachtaigh (lódáil + cláraigh crúcaí)                             |
| `/api/plugins/[name]/deactivate` | POST   | Díghníomhachtaigh (rith `onDeactivate`, díchláraigh crúcaí)           |
| `/api/plugins/[name]/config`     | GET    | Faigh cumraíocht breiseáin + scéimre cumraíochta                      |
| `/api/plugins/[name]/config`     | PUT    | Nuashonraigh cumraíocht breiseáin (bailíochtaithe de réir na scéimre) |

Glacann scagaire `status` `GET /api/plugins` le ceann amháin de
`installed` / `active` / `inactive` / `error`. Seoltar `400` ar ais i gcás luach neamhbhailí.

### Liostaigh breiseáin suiteáilte

```bash
curl http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..."
```

### Suiteáil ó chonair áitiúil

```bash
curl -X POST http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "path": "/absolute/path/to/my-plugin" }'
```

Ní mór do `path` a bheith **absalóideach** agus ní ceadmhach deighleoga trasnaithe `..` ná
bearta nialasacha a bheith ann (arna fhorfheidhmiú ag Zod). Ní mór `plugin.json`
bailí a bheith san eolaire foinseach (nó ní mór dó bheith ina eolaire tuismitheora de cheann).
Má éiríonn leis, is é `201` an freagra, mar aon le ró an bhreiseáin suiteáilte.

### Brabhsáil an margadh

```bash
curl http://localhost:20128/api/plugins/marketplace \
  -H "Cookie: auth_token=..."
```

### Nuashonraigh cumraíocht breiseáin

```bash
curl -X PUT http://localhost:20128/api/plugins/my-plugin/config \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "config": { "level": "debug", "maxItems": 100 } }'
```

Bailíochtaíonn `PUT .../config` gach luach a sholáthraítear de réir `configSchema`
an bhreiseáin (arna dhearbhú sa lastliosta): cloíonn réimsí `number` le `min`/`max`,
agus ní mór do réimsí `select` an `enum` dearbhaithe a mheaitseáil. Ceadaítear eochracha
nach bhfuil sa scéimre.

## Cumraíocht

### Eolaire breiseán

Tá breiseáin lonnaithe faoi eolaire sonraí OmniRoute:

```
~/.omniroute/plugins/<plugin-name>/
  ├─ plugin.json
  └─ index.js          # (nó cibé rud a ndíríonn manifest.main air)
```

Réitíonn `getDefaultPluginDir()` (`src/lib/plugins/scanner.ts`) an t-eolaire sin i
dtrí chéim:

1. **`OMNIROUTE_PLUGINS_DIR`**, nuair a bhíonn sé socraithe — úsáidtear é focal ar fhocal, is cuma cad a deir `HOME`. Seo é
   an rialtán sainráite do Docker/K8s, áit a bhfuil crann na mbreiseán nasctha isteach ag conair
   nach mbíonn baint ar bith aici le heolaire baile an choimeádáin de ghnáth (#11827).
2. `<home>/.omniroute/plugins`, áit a dtagann `<home>` ó na hathróga timpeallachta `HOME` / `USERPROFILE`.
3. `/tmp/.omniroute/plugins`, nuair nach n-easpórtálann an próiseas aon eolaire baile ar chor ar bith.

Logáiltear an t-eolaire réitithe uair amháin ag am tosaithe mar `scanner.dir_resolved`, agus luaitear an
t-ionchur a bhí i réim (`OMNIROUTE_PLUGINS_DIR`, `home`, nó `no-home-fallback`) — mar sin, má
thiteann íomhá go ciúin ar chéim 3, deirtear amhlaidh, seachas gan ach liosta folamh breiseán a thuairisciú.
Aimsíonn `POST /api/plugins/scan` aon fho-eolaire ansin ina bhfuil `plugin.json`
bailí agus cláraíonn sé é; is é an t-eolaire céanna an fhréamh a gcóipeálann
`pluginManager.install()` breiseáin isteach inti, mar sin bogann sárú an t-aimsiú agus an
tsuiteáil le chéile.

> **Ní hionann `OMNIROUTE_PLUGINS_DIR` agus `OMNIROUTE_PLUGIN_PATH`.** Ní léann ach
> lódálaí breiseán ordaithe na CLI (`bin/cli/plugins.mjs`) an dara ceann chun pacáistí npm
> `omniroute-cmd-*` a aimsiú a chuireann fo-orduithe `omniroute` leis — níl aon éifeacht aige ar an scanóir ama rite
> a bhfuil cur síos air anseo. Féach [PLUGINS.md](./PLUGINS.md) don taobh sin.

### URL saincheaptha do chlárlann an mhargaidh

Léitear foinse chatalóg an mhargaidh ón socrú `pluginMarketplaceUrl`
(léann `src/lib/plugins/marketplace.ts` `settings.pluginMarketplaceUrl`). Nuair a
shocraítear é mar URL `http(s)`, faigheann `listMarketplacePlugins()` an URL sin agus glacann sé
le heagar JSON iontrálacha ag an mbarrleibhéal nó le réad a bhfuil eagar `plugins` ann;
scagtar amach iontrálacha nach bhfuil `name` teaghráin iontu. Nuair nach mbíonn sé socraithe
(nó nuair nach n-éiríonn leis an iarratas mar gheall ar an gcosaint SSRF / nuair a sheoltar drochfhreagra ar ais),
úsáidtear an chlárlann síl ionsuite.

Taispeánann cluaisín "Marketplace" an deais réimse don URL seo (arna léamh ar ais ó
`GET /api/settings`).

> Nóta cur chun feidhme: seolann gníomh "Save" na deaise
> `pluginMarketplaceUrl` chuig `PATCH /api/settings`. Agus é seo á scríobh,
> níl an eochair seo dearbhaithe in `updateSettingsSchema`
> (`src/shared/validation/settingsSchemas.ts`), mar sin deimhnigh go bhfuil sí á buanú i d'eisiúint
> sula mbraitheann tú uirthi — cloíonn an chonair **léite** (`getSettings()` →
> `listMarketplacePlugins()`) leis an eochair a luaithe a bhíonn sí i stór na socruithe.

## Slándáil

### Sraith bealaigh — aisfhillte amháin

Ritheann breiseáin cód i bpróisis mhac-sceite, mar sin aicmítear dromchla iomlán `/api/plugins`
mar `LOCAL_ONLY` (Sraith 1). Cuirtear srian aisfhillte i bhfeidhm
gan choinníoll **roimh** aon seiceáil fíordheimhnithe, mar sin fiú má shroicheann
comhartha bainistíochta sceite an meaisín trí thollán, ní féidir leis breiseán a
shuiteáil, a ghníomhachtú ná a dhíshuiteáil. Féach
[`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md) agus
Rialacha Dochta #15 / #17.

### Cosaint SSRF do chlárlann an mhargaidh

Is cumraíocht í URL saincheaptha clárlainne ar féidir le hionsaitheoir tionchar
a imirt uirthi, mar sin sula n-aisghabhann `listMarketplacePlugins()` í, cuirtear
trí dhá shraith í:

1. **`isSafeMarketplaceUrl(url)`** (`src/lib/plugins/marketplace.ts`):
   - Diúltaíonn sé d’aon rud nach `http:` / `https:` é.
   - Diúltaíonn sé d’óstaigh phríobháideacha/aisfhillte/logánta naisc/ULA
     liteartha (IPv4 **agus** IPv6, lena n-áirítear IPv4-mapáilte) tríd an
     `isPrivateHost` canónta (`src/shared/network/outboundUrlGuard.ts`).
   - Réitíonn sé taifid `A` **agus** `AAAA` araon agus diúltaíonn sé má tá
     **aon** seoladh réitithe príobháideach — rud a dhúnann seachaint
     ó óstainm poiblí → IP príobháideach.
   - **Teipeann sé go dúnta**: má theipeann ar réiteach DNS, diúltaítear don URL.
2. **`safeOutboundFetch(url, { guard: "public-only", timeoutMs: 5000 })`**
   (`src/shared/network/safeOutboundFetch.ts`): cuireann sé an chosaint URL
   phoiblí-amháin i bhfeidhm arís tráth na haisghabhála agus **blocálann sé
   atreoruithe** (ní cheadaítear maighdeog `30x` ó phoiblí → príobháideach).

Ní chuireann URL a dteipeann ceachtar sraith air deireadh leis an iarratas —
filleann an margadh ar chlárlann síl ionsuite gan fógra agus logálann sé rabhadh.

> Neartaíodh an chosaint seo in PR #3774 go sonrach chun A + AAAA a réiteach agus
> an `isPrivateHost` canónta a úsáid in ionad seiceáil IPv4 amháin.

### Leithlisiú fhorghníomhú breiseán

- **Leithlisiú próisis** — sceitheann `loadPlugin()` (`src/lib/plugins/loader.ts`)
  gach breiseán i bpróiseas mac Node.js ar leith agus déanann sé cumarsáid thar
  IPC. Tá teorainn ama ar ghlaonna crúca, le hardú ó `SIGTERM` → `SIGKILL`.
- **Liosta ceadaithe athróg timpeallachta** — ní fhaigheann an próiseas mac ach
  tacar ceadaithe d’athróga timpeallachta; ní dheonaítear an tacar níos leithne
  ach nuair a iarrann an lastliosta an cead `env`.
- **Coinneáil conairí** — deimhníonn suiteáil/uasghrádú/díshuiteáil go réitítear
  eolaire an bhreiseáin agus `manifest.main` **laistigh** de fhréamh bhainistithe
  na mbreiseán sula ndéantar aon chóipeáil nó scriosadh athchúrsach (cosnaíonn
  sé seo ar chonairí bunachair sonraí ar cuireadh isteach orthu agus ar thrasnú
  `../` in `manifest.main`). Réitíonn gníomhachtú naisc shiombalacha trí
  `realpath` agus diúltaíonn sé pointe iontrála a éalaíonn ó eolaire an
  bhreiseáin a lódáil.
- **Biorán sláine roghnach** — féadfaidh lastliosta réimse `integrity`
  (`sha256-<base64>`, formáid SRI) a dhearbhú. Nuair atá sé i láthair,
  fíoraíonn an lódálaí hais an chomhaid iontrála tráth lódála agus diúltaíonn sé
  don ghníomhachtú mura meaitseálann siad. Brath roghnach ar chur isteach atá
  ann, **ní** teorainn slándála é — is iad ródú aisfhillte amháin agus samhail
  na gceadanna na fíortheorainneacha.

## Lastliosta (`plugin.json`)

Bailíochtaithe ag `PluginManifestSchema` (`src/lib/plugins/manifest.ts`):

| Réimse             | Cineál    | Nótaí                                                                       |
| ------------------ | --------- | --------------------------------------------------------------------------- |
| `name`             | string    | Riachtanach; kebab-case (`^[a-z0-9-]+$`), 1–100 carachtar                   |
| `version`          | string    | Riachtanach; semver (`MAJOR.MINOR.PATCH`)                                   |
| `description`      | string?   | ≤ 500 carachtar                                                             |
| `author`           | string?   | ≤ 200 carachtar                                                             |
| `license`          | string?   | `MIT` de réir réamhshocraithe                                               |
| `main`             | string?   | Comhad iontrála; `index.js` de réir réamhshocraithe                         |
| `source`           | enum?     | `local` \| `marketplace` (`local` de réir réamhshocraithe)                  |
| `tags`             | string[]? | Clibeanna cuardaigh                                                         |
| `requires`         | object?   | `{ omniroute?, permissions[] }`                                             |
| `hooks`            | object?   | Luachanna Boole a dhearbhaíonn na crúcaí a chuireann an breiseán i bhfeidhm |
| `skills`           | object[]? | Sainmhínithe roghnacha scileanna                                            |
| `enabledByDefault` | boolean?  | Gníomhachtaigh go huathoibríoch tráth suiteála                              |
| `configSchema`     | object?   | Mapa réimsí cumraíochta (`string`/`number`/`boolean`/`select`)              |
| `integrity`        | string?   | Biorán roghnach `sha256-<base64>` don chomhad iontrála                      |

Tagann na ceadanna ón enum
`network` / `file-read` / `file-write` / `env` / `exec`.

## Sreabhadh Saolré

```
suiteáil (POST /api/plugins, conair)
  → scan manifest/bailíochtaigh é → cóipeáil chuig staging → dearbhaigh go bhfuil main laistigh den chomhadlann
  → athainmnigh go hadamhach isteach in ~/.omniroute/plugins/<name> → cuir ró leis an mbunachar sonraí
  → spreag onInstall → más enabledByDefault: gníomhachtaigh

gníomhachtaigh (POST /api/plugins/{name}/activate)
  → seiceáil coimeádta realpath → loadPlugin() (seol próiseas linbh)
  → cláraigh na crúcaí dearbhaithe → status = "active" → spreag onActivate

díghníomhachtaigh (POST /api/plugins/{name}/deactivate)
  → spreag onDeactivate (ROIMH dhíchlárú) → díchláraigh crúcaí
  → maraigh próiseas an linbh → status = "inactive"

díshuiteáil (DELETE /api/plugins/{name})
  → díghníomhachtaigh má tá sé gníomhach → spreag onUninstall
  → scrios athchúrsach, agus coimeád seiceáilte, ar chomhadlann an bhreiseáin → scrios ró an bhunachair sonraí
```

Má ritear `install` arís ar chomhadlann a bhfuil leagan a manifest **go docht
níos nuaí** ná an leagan suiteáilte, déantar uasghrádú uathoibríoch (athshuiteáil ghlan; athshocraítear an chumraíocht
chuig na réamhshocruithe). Diúltaítear do leagan atá mar an gcéanna nó níos sine.

## Deais

Tá dhá chluaisín ar leathanach na deaise ag `/dashboard/plugins`
(`src/app/(dashboard)/dashboard/plugins/page.tsx`):

- **Suiteáilte** — liostaítear breiseáin shuiteáilte lena gcrúcaí dearbhaithe, scorán
  gníomhachtaithe/díghníomhachtaithe, cnaipe díshuiteála, agus gníomh "Scan le haghaidh breiseán"
  (`POST /api/plugins/scan`).
- **Margadh** — taispeántar an chatalóg ó `GET /api/plugins/marketplace` mar aon le
  réimse chun URL na clárlainne saincheaptha a shocrú.

Tá leathanach cumraíochta do gach breiseán ar leith ag `/dashboard/plugins/[name]/config`
(`src/app/(dashboard)/dashboard/plugins/[name]/config/page.tsx`).
