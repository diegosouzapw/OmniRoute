Déanann OmniRoute gníomhairí códúcháin tríú páirtí arna n-óstáil sa néal (Codex Cloud, Cursor,
Devin, Jules) a chomhordú mar thascanna fadtéarmacha. Cuirtear gach gníomhaire taobh thiar de chomhéadan aonfhoirmeach ionas
gur féidir le cliaint leid + URL stórtha a chur isteach agus torthaí a fháil gan a bheith ag plé le
APIanna a bhaineann go sonrach leis an soláthraí.

**Ní** gnáth-chomhlánú comhrá é tasc Gníomhaire Néil. Is aonad oibre marthanach, ilchéime é
a d'fhéadfadh nóiméid nó uaireanta a thógáil, a d'fhéadfadh Iarratas Tarraingthe a tháirgeadh mar a
dhéantán, agus a thacaíonn le teachtaireachtaí leantacha agus (i gcás roinnt soláthraithe) geataí formheasa pleananna.

## Ailtireacht

```
Cliant (Deais / CLI / API)
  → POST /api/v1/agents/tasks (fíordheimhniú bainistíochta riachtanach)
    → bailíochtú CreateCloudAgentTaskSchema (Zod)
    → registry.getAgent(providerId)
    → getCloudAgentCredentials(providerId)
      └─ tarraingíonn sé ó getProviderConnections({ provider, isActive: true })
         (apiKey ar dtús, accessToken mar chúltaca)
    → agent.createTask({ prompt, source, options }, credentials)
      └─ HTTP POST chuig API an tsoláthraí réamhtheachtaigh
      └─ tugann sé CloudAgentTask ar ais le id inmheánach + externalId
    → insertCloudAgentTask(...) isteach in cloud_agent_tasks (SQLite)

Fiosrú tréimhsiúil (sioncronú leisciúil ar léamh):
  GET /api/v1/agents/tasks/[id]
    → getCloudAgentTaskById(id)
    → agent.getStatus(externalId, credentials)  // athnuann sé stádas + gníomhaíochtaí
    → updateCloudAgentTask(...) le stádas, toradh, completed_at nua
    → tugann sé an tasc srathaithe ar ais

Idirghníomhaíochtaí:
  POST /api/v1/agents/tasks/[id]  corp: { action: "approve" | "message" | "cancel" }
    → agent.approvePlan(externalId, credentials)        le haghaidh "approve"
    → agent.sendMessage(externalId, message, credentials) le haghaidh "message"
    → athraíonn an stádas go "cancelled"                le haghaidh "cancel" (áitiúil amháin)
```

Tá an sioncronú **leisciúil**: athnuaitear an stádas ón gcóras réamhtheachtach ar gach `GET /tasks/[id]`.
Níl aon fhiosraitheoir cúlra ann. Ba cheart do dheaiseanna a bhfuil staid úr de dhíth orthu an críochphointe GET a fhiosrú
go tréimhsiúil ag eatramh ciallmhar.

## Comhéadan `CloudAgentBase`

Foinse: `src/lib/cloudAgent/baseAgent.ts`

```typescript
export interface AgentCredentials {
  apiKey: string;
  baseUrl?: string;
}

export interface CreateTaskParams {
  prompt: string;
  source: CloudAgentSource;
  options: {
    autoCreatePr?: boolean;
    planApprovalRequired?: boolean;
    environment?: Record<string, string>;
  };
}

export interface GetStatusResult {
  status: CloudAgentStatus;
  externalId?: string;
  result?: CloudAgentResult;
  activities: CloudAgentActivity[];
  error?: string;
}

export abstract class CloudAgentBase {
  abstract readonly providerId: string;
  abstract readonly baseUrl: string;

  abstract createTask(p: CreateTaskParams, c: AgentCredentials): Promise<CloudAgentTask>;
  abstract getStatus(externalId: string, c: AgentCredentials): Promise<GetStatusResult>;
  abstract approvePlan(externalId: string, c: AgentCredentials): Promise<void>;
  abstract sendMessage(
    externalId: string,
    message: string,
    c: AgentCredentials
  ): Promise<CloudAgentActivity>;
  abstract listSources(
    c: AgentCredentials
  ): Promise<{ name: string; url: string; branch?: string }[]>;

  protected mapStatus(raw: string): CloudAgentStatus; // teaghrán réamhtheachtach heorastúil → enum
  protected generateTaskId(): string; // `task_<ts>_<rand>`
  protected generateActivityId(): string; // `act_<ts>_<rand>`
}
```

Caitheann `CodexCloudAgent.approvePlan` eisceacht d’aon ghnó — déanann Codex Cloud pleanáil go huathoibríoch agus
níl geata ceadaithe aige. Tugann `CodexCloudAgent.listSources` `[]` ar ais.

Rialaíonn `CursorCloudAgent` Gníomhairí Cúlra / Néil Cursor trína REST API oifigiúil
(`api.cursor.com/v0`) le **heochair API úsáideora nó cuntais seirbhíse** — an rogha chéadpháirtí
níos sábháilte seachas seisiún OAuth IDE Cursor a athúsáid (soláthraí `cursor`,
a bhfuil rabhadh faoi riosca coisc ag gabháil leis). Is cuibheoir REST simplí é (gan aon spleáchas dúchasach
`@cursor/sdk`). Caitheann `approvePlan` eisceacht (ritheann gníomhairí Cursor go neamhspleách); liostaíonn `listSources`
na stórtha a bhfuil rochtain ag an eochair orthu. Tugann Cursor enumanna stádais i gCÁS UACHTAIR ar ais
(`CREATING`/`RUNNING`/`FINISHED`/`ERROR`), a mhapáiltear go sainráite chuig an
`CloudAgentStatus` comhroinnte. Is féidir `baseUrl` a shárú de réir dintiúir ionas gur féidir
leagan/conair an API a cheartú gan athrú cód.

export const CLOUD_AGENT_STATUS = {
  QUEUED: "queued",
  RUNNING: "running",
  AWAITING_APPROVAL: "awaiting_approval",
  COMPLETED: "completed",
  FAILED: "failed",
  CANCELLED: "cancelled",
} as const;

export interface CloudAgentSource {
  repoName: string;
  repoUrl: string; // ní mór dó a bheith ina URL bailí
  branch?: string;

export interface CloudAgentResult {

  prNumber?: number;

  diffUrl?: string;

export interface CloudAgentActivity {
  id: string;
  type: "plan" | "command" | "code_change" | "message" | "error" | "completion";
  content: string;
  timestamp: string; // ISO 8601
  metadata?: Record<string, unknown>;
}

export interface CloudAgentTask {
  id: string; // aitheantas inmheánach `task_...`

  status: CloudAgentStatus;
  prompt: string; // 1..10000 carachtar
  source: CloudAgentSource;

    autoCreatePr?: boolean;
    planApprovalRequired?: boolean;

  result?: CloudAgentResult;
  activities: CloudAgentActivity[];
  error?: string;
  createdAt: string;
  updatedAt: string;
  completedAt?: string;

## Bunachar Sonraí

Foinse: `src/lib/cloudAgent/db.ts` — cruthaítear an tábla go leisciúil trí
`createCloudAgentTaskTable()` (glaoitear air freisin ó `src/lib/cloudAgent/index.ts` tráth
iompórtála an mhodúil).

```sql
CREATE TABLE IF NOT EXISTS cloud_agent_tasks (
  id           TEXT PRIMARY KEY,
  provider_id  TEXT NOT NULL,
  external_id  TEXT,
  status       TEXT NOT NULL DEFAULT 'queued',
  prompt       TEXT NOT NULL,
  source       TEXT NOT NULL,             -- JSON
  options      TEXT DEFAULT '{}',         -- JSON
  result       TEXT,                       -- JSON
  activities   TEXT DEFAULT '[]',          -- JSON
  error        TEXT,
  created_at   TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at   TEXT NOT NULL DEFAULT (datetime('now')),
  completed_at TEXT
);
CREATE INDEX IF NOT EXISTS idx_cloud_agent_tasks_provider ON cloud_agent_tasks(provider_id);
CREATE INDEX IF NOT EXISTS idx_cloud_agent_tasks_status   ON cloud_agent_tasks(status);
CREATE INDEX IF NOT EXISTS idx_cloud_agent_tasks_created  ON cloud_agent_tasks(created_at DESC);
```

Cuireann `updateCloudAgentTask` **bánliosta colún** i bhfeidhm chun instealladh SQL a chosc:
`status`, `prompt`, `source`, `options`, `result`, `activities`, `error`,
`completed_at`. Caitear aon eochair eile sa pháirt-nuashonrú amach gan fógra.

## REST API — Saolré an Taisc

**Fíordheimhniú:** Teastaíonn **fíordheimhniú bainistíochta** ó gach críochphointe
`/api/v1/agents/tasks*` (`requireCloudAgentManagementAuth` mar fhillteán ar
`requireManagementAuth` ó `src/lib/api/requireManagementAuth`). Cuirtear é seo i
bhfeidhm tar éis commit `588a0333`
(_"fix(auth): require management auth for agent and cooldown APIs"_).

| Modh    | Conair                        | Cuspóir                                                                                    |
| ------- | ----------------------------- | ------------------------------------------------------------------------------------------ |
| OPTIONS | `/api/v1/agents/tasks`        | Réamhiarratas CORS                                                                         |
| GET     | `/api/v1/agents/tasks`        | Liostaigh tascanna (scagaire: `provider`, `status`, `limit≤500`)                           |
| POST    | `/api/v1/agents/tasks`        | Cruthaigh tasc (seoltar chuig an tseirbhís réamhtheachtach + déantar é a bhuanú)           |
| DELETE  | `/api/v1/agents/tasks?id=...` | Scrios tasc de réir id an fhiosrúcháin (**ní** chealaítear é sa tseirbhís réamhtheachtach) |
| OPTIONS | `/api/v1/agents/tasks/[id]`   | Réamhiarratas CORS                                                                         |
| GET     | `/api/v1/agents/tasks/[id]`   | Léigh tasc + sioncronaigh an stádas go leisciúil ón tseirbhís réamhtheachtach              |
| POST    | `/api/v1/agents/tasks/[id]`   | Gníomh: `approve` / `message` / `cancel`                                                   |
| DELETE  | `/api/v1/agents/tasks/[id]`   | Scrios tasc de réir id na conaire                                                          |

### Cruthaigh tasc

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Fix the bug in src/foo.ts where the parser returns null",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    },
    "options": {
      "autoCreatePr": true,
      "planApprovalRequired": false
    }
  }'
```

Freagra `201`:

```json
{
  "data": {
    "id": "task_1731512345678_abc123def",
    "providerId": "devin",
    "externalId": "session_xyz",
    "status": "queued",
    "prompt": "...",
    "source": { "repoName": "user/repo", "repoUrl": "...", "branch": "main" },
    "options": { "autoCreatePr": true },
    "createdAt": "2026-05-13T12:34:56.789Z"
  }
}
```

### Faomh plean

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks/<id> \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{"action":"approve"}'
```

### Seol teachtaireacht leantach

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks/<id> \
  -d '{"action":"message","message":"Also add a unit test for the parser"}'
```

### Cealaigh (stádas áitiúil amháin)

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks/<id> \
  -d '{"action":"cancel"}'
```

Athraíonn `cancel` `status` go `"cancelled"` sa bhunachar sonraí áitiúil ach **ní**
ghlaonn sé ar an soláthraí réamhtheachtach — níl aon RPC scoir in `CloudAgentBase`.
Chun stop a chur le billeáil sa tseirbhís réamhtheachtach, cuir deireadh leis an tasc
i gconsól an tsoláthraí féin.

## REST API — Bonneagar Soláthraí Néil

Úsáideann cianchliaint na críochphointí cúnta seo faoi `src/app/api/cloud/`
(an CLI, an aip Electron, nó oibrithe sioncronaithe) chun meiteashonraí naisc soláthraí
a léamh agus ailiasanna samhlacha a réiteach. Fíordheimhnítear iad le **gnáth-eochair API**
(trí `validateApiKey`), seachas leis an bhfíordheimhniú bainistíochta a úsáideann críochphointí na dtascanna.

| Modh | Conair                          | Cuspóir                                                                                      |
| ---- | ------------------------------- | -------------------------------------------------------------------------------------------- |
| POST | `/api/cloud/auth`               | Bailíochtaigh eochair API, seol meiteashonraí naisc mascaithe + ailiasanna samhlacha ar ais  |
| PUT  | `/api/cloud/credentials/update` | Athnuaigh `accessToken` / `refreshToken` / `expiresAt`                                       |
| POST | `/api/cloud/model/resolve`      | Réitigh ailias samhla go `{ provider, model }`                                               |
| GET  | `/api/cloud/models/alias`       | Liostaigh gach ailias samhla                                                                 |
| PUT  | `/api/cloud/models/alias`       | Socraigh ailias samhla (agus sioncronaigh go huathoibríoch leis an Néal má tá sé cumasaithe) |

Ní sheolann `/api/cloud/auth` `apiKey` / `accessToken` / `refreshToken` amh ar ais riamh. Seolann sé
`hasApiKey`, `hasAccessToken`, `hasRefreshToken`, agus réamhamharc mascaithe ar ais
(`maskedApiKey`: an chéad 4 + `****` + an 4 dheireanacha).

## Réiteach Dintiúr

`getCloudAgentCredentials(providerId)` in `src/lib/cloudAgent/api.ts`:

1. Lódálann sé naisc ghníomhacha soláthraí trí `getProviderConnections({ provider: providerId, isActive: true })`.
2. I gcás gach naisc, tugann sé tús áite do `apiKey` (agus spás bán bainte). Mura bhfuil sé sin ar fáil, úsáideann sé `accessToken`.
3. Seolann sé an chéad chomhartha neamhfholamh ar ais fillte mar `{ apiKey: token }`.
4. Seolann sé `null` ar ais mura bhfaightear comhartha inúsáidte — freagraíonn an API le `400` agus
   `"Níl aon dintiúir ghníomhacha cumraithe do sholáthraí an ghníomhaire néil: <id>"`.

Ciallaíonn sé seo go n-athúsáideann Gníomhairí Néil an tábla céanna Naisc Soláthraí agus a úsáideann gnáthsholáthraithe
LLM. Chun Jules a chumasú, cruthaigh nasc gníomhach le `provider: "jules"`
agus `apiKey` líonta isteach.

## Deais

Foinse: `src/app/(dashboard)/dashboard/cloud-agents/page.tsx`

Leathanach React le `"use client"` a dhéanann na nithe seo a leanas:

- Liostaíonn sé tascanna (a phollaítear trí `GET /api/v1/agents/tasks`).
- Cuireann sé tascanna nua isteach trí fhoirm a mhapálann chuig `CreateCloudAgentTaskSchema`.
- Taispeánann sé suaitheantais stádais (`queued`, `running`, `awaiting_approval`, `completed`,
  `failed`, `cancelled`) agus rindreálann sé amlíne `activities[]`.
- Taispeánann sé `result.prUrl` / `commitMessage` / `summary` nuair atá `status === "completed"`.

## Comhtháthú le A2A

Is féidir Gníomhairí Néil a nochtadh mar scileanna A2A trí scil A2A a chlárú a tharmligeann
a láimhseálaí `tasks/send` chuig `getAgent(...).createTask(...)` agus a aistríonn teagmhais
stádais tascanna A2A chuig prótacal JSON-RPC 2.0. Féach [A2A-SERVER.md](./A2A-SERVER.md).

## Gníomhaire Néil Nua a Chur Leis

1. Cruthaigh `src/lib/cloudAgent/agents/<name>.ts` a leathnaíonn `CloudAgentBase`.
2. Cuir `createTask`, `getStatus`, `approvePlan` (nó caith earráid mura mbaineann sé le hábhar),
   `sendMessage`, `listSources` i bhfeidhm. Úsáid `this.mapStatus(...)` chun stádas a normalú.
3. Cláraigh é in `src/lib/cloudAgent/registry.ts` faoi `providerId` cobhsaí.
4. Leathnaigh aontas liteartha `providerId` in `src/lib/cloudAgent/types.ts`
   (`CloudAgentTask.providerId` agus `CreateCloudAgentTaskSchema`).
5. Cuir an soláthraí le `src/shared/constants/providers.ts` má theastaíonn taifead naisc
   uaidh. Teastaíonn `src/lib/oauth/providers/` ó sholáthraithe OAuth freisin.
6. Cuir tástálacha faoi `tests/unit/cloud-agent-*.test.ts`.
7. Nuashonraigh an cháipéis seo agus tairiseach `CLOUD_AGENTS` na deaise.

## Cumraíocht

| Athróg Timpeallachta | Cuspóir                                                                        |
| -------------------- | ------------------------------------------------------------------------------ |
| `DATA_DIR`           | Suíomh bhunachar sonraí SQLite ina bhfuil `cloud_agent_tasks`                  |
| `JWT_SECRET`         | Riachtanach le haghaidh fíordheimhniú bainistíochta ar chríochphointí tascanna |
| `API_KEY_SECRET`     | Riachtanach chun dintiúir naisc soláthraithe a chriptiú agus iad ar fos        |

tábla `provider_connections`.
