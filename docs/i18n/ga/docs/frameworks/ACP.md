> **TL;DR**: Ligeann ACP do OmniRoute gníomhairí CLI (amhail Claude Code, Codex) a sheoladh mar phróisis mhac in ionad APIanna HTTP a úsáid. Tugann sé seo iompar "CLI-mar-inneall" duit.

---

## Cad É ACP?

Is iompar **"CLI-mar-inneall"** é ACP (Agent Client Protocol) do OmniRoute. In ionad glaonna API HTTP chuig soláthraithe IS a idircheapadh, **seolann ACP gníomhairí CLI mar phróisis mhac** agus cuireann sé leideanna chucu trína gcomhéadan dúchasach.

### Cén Fáth ACP a Úsáid?

| Buntáiste                      | Cur Síos                                                  |
| ------------------------------ | --------------------------------------------------------- |
| **Níl eochracha API de dhíth** | Úsáideann sé an fíordheimhniú CLI atá agat cheana         |
| **Prótacal dúchasach**         | Úsáideann sé formáid dhúchasach ionchuir/aschuir gach CLI |
| **Uathfhionnachtain**          | Aimsíonn sé CLIanna atá suiteáilte ar do chóras           |
| **15 ghníomhaire ionsuite**    | Réamhchumraithe d'uirlisí CLI a bhfuil tóir orthu         |
| **Gníomhairí saincheaptha**    | Cuir d'uirlisí CLI féin leis trí na socruithe             |
| **Bainistíocht próiseas**      | Láimhseálann sé an saolré (seoladh, seol, marú)           |

## Conas a Oibríonn ACP

### Ailtireacht

```
┌─────────────────┐
│  OmniRoute      │
│  (Seachfhreastalaí HTTP) │
└────────┬────────┘
         │
         │ spawn()
         ▼
┌─────────────────┐
│  Próiseas Mac   │
│  (Gníomhaire CLI) │
│                 │
│  stdin  ◄──────┤  Seol leid
│  stdout ──────►│  Faigh freagra
│  stderr ──────►│  Faigh earráidí
└─────────────────┘
```

### Saolré an Phróisis

1. **Seoladh** — Cruthaíonn ACP próiseas mac don ghníomhaire CLI
2. **Seol** — Scríobhann ACP leideanna chuig stdin an phróisis
3. **Glac** — Léann ACP freagraí ó stdout/stderr
4. **Brath Díomhaointis** — Fanann ACP ar feadh 2 shoicind neamhghníomhaíochta sula measann sé go bhfuil an freagra críochnaithe
5. **Marú** — Cuireann ACP deireadh leis an bpróiseas (SIGTERM, ansin SIGKILL tar éis 5s)

### Prótacal Cumarsáide

Úsáideann ACP **stdio** (ionchur/aschur caighdeánach) chun cumarsáid a dhéanamh le gníomhairí CLI. Seo é an prótacal:

1. **Seol leid** — Scríobh chuig stdin agus líne nua ina dhiaidh
2. **Fan le freagra** — Léigh ó stdout go dtí go mbeidh sé díomhaoin (2s gan aschur)
3. **Teorainn ama** — 120 soicind de réir réamhshocraithe (inchumraithe)

## Tagairt API

### Feidhmeanna na Clárlainne

#### `detectInstalledAgents()`

Aimsíonn sé gach gníomhaire CLI atá suiteáilte ar an gcóras. Cuirtear na torthaí i dtaisce ar feadh 60 soicind.

```typescript
import { detectInstalledAgents } from "@/lib/acp";

const agents = detectInstalledAgents();
// Filleann sé: CliAgentInfo[]

interface CliAgentInfo {
  id: string; // m.sh., "codex", "claude"
  name: string; // Ainm taispeána
  binary: string; // Ainm an chomhaid dhénártha atá le seoladh
  versionCommand: string; // Ordú braite leagain
  version: string | null; // Leagan braite (null mura bhfuil sé suiteáilte)
  installed: boolean; // An bhfuil an gníomhaire suiteáilte
  providerAlias: string; // Aitheantas an tsoláthraí in OmniRoute
  spawnArgs: string[]; // Argóintí atá le cur ar aghaidh agus é á sheoladh
  protocol: "stdio" | "http"; // Prótacal cumarsáide
  isCustom?: boolean; // An gníomhaire saincheaptha atá sainithe ag an úsáideoir é seo
}
```

#### `getAvailableAgents()`

Faigheann sé na gníomhairí amháin atá suiteáilte agus ar fáil do ACP.

```typescript
import { getAvailableAgents } from "@/lib/acp";

const available = getAvailableAgents();
// Filleann sé: CliAgentInfo[] (gníomhairí suiteáilte amháin)
```

#### `getAgentById(id)`

Faigheann sé gníomhaire sonrach de réir a aitheantais.

```typescript
import { getAgentById } from "@/lib/acp";

const agent = getAgentById("claude");
// Filleann sé: CliAgentInfo | undefined
```

#### `setCustomAgents(agents)`

Socraíonn sé sainmhínithe gníomhairí saincheaptha ó na socruithe.

```typescript
import { setCustomAgents } from "@/lib/acp";

setCustomAgents([
  {
    id: "my-custom-cli",
    name: "My Custom CLI",
    binary: "mycli",
    versionCommand: "mycli --version",
    providerAlias: "my-provider",
    spawnArgs: [],
    protocol: "stdio",
  },
]);
```

### Feidhmeanna an Bhainisteora

#### `acpManager.spawn(agentId, binary, args, env)`

Seolann sé próiseas nua gníomhaire CLI.

```typescript
import { acpManager } from "@/lib/acp";

const session = acpManager.spawn("claude", "claude", ["--print", "--output-format", "json"], {
  /* athróga timpeallachta saincheaptha */
});
// Filleann sé: AcpSession
```

**Aitheantais ghníomhairí a cheadaítear**: `["claude", "codex", "gemini", "qwen"]`

#### `acpManager.sendPrompt(sessionId, prompt, timeoutMs)`

Seolann sé leid chuig gníomhaire CLI agus bailíonn sé an freagra.

```typescript
import { acpManager } from "@/lib/acp";

const response = await acpManager.sendPrompt(
  "acp-claude-1234567890-abc123",
  "What is 2+2?",
  120000 // Teorainn ama 2 nóiméad
);
// Filleann sé: Promise<string>
```

#### `acpManager.kill(sessionId)`

Stadann sé seisiún agus glanann sé suas é.

```typescript
import { acpManager } from "@/lib/acp";

const killed = acpManager.kill("acp-claude-1234567890-abc123");
// Filleann sé: boolean
```

#### `acpManager.getActiveSessions()`

Faigheann sé gach seisiún gníomhach.

```typescript
import { acpManager } from "@/lib/acp";

const sessions = acpManager.getActiveSessions();
// Filleann sé: AcpSession[]
```

#### `acpManager.killAll()`

Stadann sé gach seisiún.

```typescript
import { acpManager } from "@/lib/acp";

acpManager.killAll();
```

### Comhéadan Seisiúin

```typescript
interface AcpSession {
  id: string; // Aitheantas uathúil an tseisiúin
  agentId: string; // Aitheantas an ghníomhaire (m.sh., "claude")
  process: ChildProcess; // Hanla an mhacphróisis
  alive: boolean; // An bhfuil an próiseas beo
  stdoutBuffer: string; // Maolán carntha stdout
  stderrBuffer: string; // Maolán carntha stderr
  createdAt: Date; // Stampa ama cruthaithe
}
```

### Teagmhais

Leathnaíonn `AcpManager` `EventEmitter` agus astaíonn sé na teagmhais seo a leanas:

#### `stdout`

Astaítear é nuair a scríobhann an gníomhaire CLI chuig stdout.

```typescript
acpManager.on("stdout", ({ sessionId, data }) => {
  console.log(`[${sessionId}] stdout: ${data}`);
});
```

#### `stderr`

Astaítear é nuair a scríobhann an gníomhaire CLI chuig stderr.

```typescript
acpManager.on("stderr", ({ sessionId, data }) => {
  console.error(`[${sessionId}] stderr: ${data}`);
});
```

#### `exit`

Astaítear é nuair a chríochnaíonn próiseas an ghníomhaire CLI.

```typescript
acpManager.on("exit", ({ sessionId, code, signal }) => {
  console.log(`[${sessionId}] exited with code ${code}, signal ${signal}`);
});
```

#### `error`

Astaítear é nuair a tharlaíonn earráid i bpróiseas an ghníomhaire CLI.

```typescript
acpManager.on("error", ({ sessionId, error }) => {
  console.error(`[${sessionId}] error: ${error}`);
});
```

## Cumraíocht

### Athróga Timpeallachta

Faigheann ACP gach athróg timpeallachta le hoidhreacht ón máthairphróiseas agus is féidir é a leathnú le hathróga timpeallachta saincheaptha:

```typescript
acpManager.spawn("claude", "claude", [], {
  ANTHROPIC_API_KEY: "sk-...",
  DEBUG: "true",
});
```

### Argóintí Sceite

Tá argóintí sceite réamhshocraithe ag gach gníomhaire atá sainithe sa chlárlann. Is féidir leat iad a shárú:

```typescript
acpManager.spawn("claude", "claude", ["--print", "--verbose"], {});
```

### Teorainneacha Ama

Is é **120 soicind** (2 nóiméad) an teorainn ama réamhshocraithe do leid. Is féidir leat í a shárú:

```typescript
await acpManager.sendPrompt(sessionId, prompt, 300000); // 5 nóiméad
```

### Taisce Braite

Déantar brath gníomhairí a thaisceadh ar feadh **60 soicind** chun scanadh costasach ar an gcóras comhad a sheachaint. Chun athnuachan a éigean:

```typescript
import { refreshAgentCache } from "@/lib/acp";

refreshAgentCache();
```

## Slándáil

### Ionsá Orduithe a Chosc

Déanann ACP orduithe leagain a bhailíochtú chun ionsaithe ionsáite orduithe a chosc:

```typescript
const DISALLOWED_VERSION_COMMAND_CHARS = /[;&|<>`$\r\n]/;
```

Diúltaítear d’orduithe leagain ina bhfuil na carachtair seo:

- `;` — Deighilteoir orduithe
- `&` — Próiseas cúlra
- `|` — Píopa
- `<`, `>` — Atreorú
- `` ` `` — Ionadú ordaithe
- `$` — Leathnú athróige
- `\r`, `\n` — Bristeacha líne

### Bailíochtú Ainm Dénártha

Deimhníonn ACP go meaitseálann dénártha an ordaithe leagain an t-ainm dénártha a bhfuiltear ag súil leis (mura gníomhaire saincheaptha é).

### Leithlisiú Próisis

Ritheann gach seisiún ACP ina mhacphróiseas féin. Maraítear an próiseas nuair a chríochnaíonn an seisiún nó nuair a shroichtear an teorainn ama.

## Feidhmíocht

### Feidhmíocht Braite

- **An chéad ghlao**: ~50-200ms (ritheann sé an t-ordú `version` do gach gníomhaire)
- **Glaonna taiscthe**: <1ms (seoltar ar ais ón taisce)
- **TTL na taisce**: 60 soicind

### Feidhmíocht Leide

- **Sceitheadh**: ~50-100ms
- **Leid a sheoladh**: ~10-50ms
- **Fanacht le freagra**: Braitheann sé ar an ngníomhaire CLI (1-30 soicind de ghnáth)
- **Marú**: ~5 shoicind (SIGTERM) + láithreach (SIGKILL)

### Úsáid Acmhainní

- **Cuimhne in aghaidh an tseisiúin**: ~10-50MB (braitheann sé ar an ngníomhaire CLI)
- **CPU**: Íosta (teoranta ag I/O)
- **Diosca**: Dada

## Fabhtcheartú

### Earráid "Unknown agent"

**Fadhb**: Caitheann `acpManager.spawn()` an earráid `Unknown agent: <id>`

**Réiteach**: Ní cheadaítear ach na gníomhairí seo in `spawn()`:

- `claude`
- `codex`
- `gemini`
- `qwen`

Ní mór gníomhairí eile a sceitheadh de láimh nó trí shainmhínithe gníomhairí saincheaptha.

### Earráid "Session not alive"

**Fadhb**: Caitheann `acpManager.sendPrompt()` an earráid `Session ${sessionId} is not alive`

**Réiteach**: Seans gur scoir an seisiún nó gur maraíodh é. Seiceáil stádas an tseisiúin:

```typescript
const session = acpManager.getSession(sessionId);
if (!session?.alive) {
  // Sceith an seisiún arís
  acpManager.spawn("claude", "claude", [], {});
}
```

### Earráid "ACP timeout"

**Fadhb**: Caitheann `acpManager.sendPrompt()` an earráid `ACP timeout after 120000ms`

**Réiteach**: Méadaigh an teorainn ama:

```typescript
await acpManager.sendPrompt(sessionId, prompt, 300000); // 5 nóiméad
```

### CLI Gan Bhrath

**Fadhb**: Ní aimsíonn `detectInstalledAgents()` do CLI

**Réitigh**:

1. **Seiceáil PATH**: Cinntigh go bhfuil an CLI i PATH do chórais
2. **Seiceáil an t-ordú leagain**: Rith `claude --version` de láimh
3. **Seiceáil ceadanna**: Cinntigh gur féidir an CLI a rith
4. **Gníomhaire saincheaptha**: Cuir sainmhíniú gníomhaire saincheaptha leis le haghaidh CLIanna neamhchaighdeánacha

### Cead Diúltaithe

**Fadhb**: Ní féidir le ACP an CLI a rith

**Réitigh**:

1. **Seiceáil ceadanna comhaid**: `chmod +x /usr/local/bin/claude`
2. **Seiceáil úinéireacht**: Cinntigh go bhfuil ceadanna léite/rite ag OmniRoute
3. **Seiceáil SELinux/AppArmor**: D’fhéadfadh siad sceitheadh próisis a bhlocáil

## Samplaí

### Sampla 1: Claude Code a Thosú agus a Úsáid

```typescript
import { acpManager, detectInstalledAgents } from "@/lib/acp";

// Gníomhairí suiteáilte a bhrath
const agents = detectInstalledAgents();
const claude = agents.find((a) => a.id === "claude");

if (claude?.installed) {
  // Seisiún nua a thosú
  const session = acpManager.spawn("claude", claude.binary, ["--print", "--output-format", "json"]);

  // Leid a sheoladh
  const response = await acpManager.sendPrompt(
    session.id,
    "Explain quantum computing in 100 words"
  );

  console.log("Claude's response:", response);

  // Glanadh suas
  acpManager.kill(session.id);
}
```

### Sampla 2: Uathaimsiú le Rogha Mhalartach

```typescript
import { acpManager, getAvailableAgents } from "@/lib/acp";

const available = getAvailableAgents();

// Bain triail as Claude ar dtús, agus úsáid Codex mar rogha mhalartach
let agentId = "claude";
if (!available.find((a) => a.id === "claude")) {
  if (available.find((a) => a.id === "codex")) {
    agentId = "codex";
  } else {
    throw new Error("No ACP-compatible CLI agent found");
  }
}

const agent = available.find((a) => a.id === agentId)!;
const session = acpManager.spawn(agentId, agent.binary, agent.spawnArgs);

const response = await acpManager.sendPrompt(session.id, "Hello!");

acpManager.kill(session.id);
```

### Sampla 3: Gníomhaire Saincheaptha

```typescript
import { setCustomAgents, detectInstalledAgents } from "@/lib/acp";

// Gníomhaire saincheaptha CLI a chlárú
setCustomAgents([
  {
    id: "my-llm-cli",
    name: "My LLM CLI",
    binary: "myllm",
    versionCommand: "myllm --version",
    providerAlias: "my-llm-provider",
    spawnArgs: ["--format", "json"],
    protocol: "stdio",
  },
]);

// Áireofar "my-llm-cli" anois in detectInstalledAgents()
const agents = detectInstalledAgents();
```
