## Céard atá ann

Nascann OmniRoute le taisce **Obsidian** mar **fhoinse comhthéacs** — bunachar eolais
Markdown áitiúil a léann agus a scríobhann gníomhairí tríd an bhfreastalaí MCP ionsuite.
Déanann an comhtháthú cumarsáid leis an mbreiseán pobail **Obsidian Local REST API** atá
ag rith laistigh den aip deisce, ionas gur féidir le gníomhairí nótaí a chuardach,
comhaid a léamh/a scríobh/a phaisteáil, inneachar na taisce a liostú, oibriú le nótaí
tréimhsiúla laethúla/seachtainiúla, clibeanna a bhainistiú, orduithe Obsidian a rith,
agus (go roghnach) sioncronú déthreoch taisce idir ríomhaire deisce agus gléas móibíleach
a chomhordú.

Cuimsíonn an cliant (`src/lib/obsidian/api.ts`) an Local REST API leis na gnéithe seo:

- **Atriail le cúlú** i gcás earráidí sealadacha `5xx`, agus **teorainn ama 30 soicind**
  trí `AbortController`.
- **Aicmiú earráidí clóscríofa** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- Leid sholéite **“ní féidir Obsidian a bhaint amach”** a luann an botún coitianta maidir
  leis an bport (HTTP ar `27123`, **ní** an críochphointe MCP ar `27124`) agus an
  fhoirm Tailscale.
- **Ionchódú conairí** i gcoibhneas leis an taisce, ionas go mbeidh conairí nótaí ina
  bhfuil spásanna/slais sábháilte.

## Socrú

Níl **aon athróg timpeallachta** ann don chomhartha Obsidian ná don bhun-URL — stóráiltear
an dá cheann sa tábla SQLite `key_value` (ainmspás `obsidian`) trí
`src/lib/db/obsidian.ts`. Tá an comhartha **criptithe agus é stóráilte** (AES-256-GCM,
le cúl-taca comhoiriúnachta siar do ghnáth-théacs). Cumraigh é ón gcluaisín
**Foinsí Comhthéacs** ar dheais an Chríochphointe (`ObsidianSourceCard`), nó trí REST API
na socruithe.

> [!IMPORTANT]
> Ní mór an breiseán **Obsidian Local REST API** a bheith suiteáilte agus ag rith.
> Éisteann a chomhéadan REST ar **HTTP `127.0.0.1:27123`** (an bun-URL réamhshocraithe).
> Is críochphointe MCP/HTTPS _ar leith_ é port `27124` agus diúltaíonn bealach na socruithe
> dó go sainráite. Má táthar ag nascadh ó ghléas eile, úsáid
> `http://<tailscale-ip>:27123`.

### Eochracha cumraíochta (SQLite `key_value`, ainmspás `obsidian`)

| Eochair           | Cuspóir                                                | Criptithe |
| ----------------- | ------------------------------------------------------ | --------- |
| `api_key`         | Comhartha iompróra Local REST API                      | tá        |
| `base_url`        | Bun-URL REST (réamhshocrú `http://127.0.0.1:27123`)    | níl       |
| `vault_path`      | Conair absalóideach chuig comhadlann na taisce (sionc) | níl       |
| `webdav_username` | Ainm úsáideora WebDAV ginte (sioncronú taisce)         | níl       |
| `webdav_password` | Focal faire WebDAV ginte (sioncronú taisce)            | tá        |
| `webdav_enabled`  | An bhfuil sioncronú taisce WebDAV cumasaithe           | níl       |

### Cumrú trí REST

```bash
# Sábháil + bailíochtaigh an comhartha Local REST API (bailíochtaíonn POST é trí sheiceáil stádais)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Seiceáil stádas an naisc (tugtar connected, hasToken, baseUrl, vaultPath ar ais)
curl http://localhost:20128/api/settings/obsidian

# Dícheangail (glantar an comhartha stóráilte)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Teastaíonn fíordheimhniú na deaise ó gach modh. Diúltaíonn `POST` d'aon URL ar phort
`27124` agus bailíochtaíonn sé an comhartha trí chríochphointe stádais Local REST API
a ghlaoch sula ndéantar é a bhuanú.

### Sioncronú taisce WebDAV

Bainistíonn `src/app/api/settings/obsidian/webdav/route.ts` sioncronú roghnach taisce
le tacaíocht WebDAV (arna thiomáint ag `src/lib/obsidianSync.ts`). Nuair a chumasaítear
é, dírítear OmniRoute ar chomhadlann áitiúil taisce agus gintear péire randamach
ainm úsáideora/focal faire WebDAV:

```bash
# Cumasaigh sioncronú WebDAV do chomhadlann taisce (gintear ainm úsáideora/focal faire)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Faigh stádas shioncronú WebDAV (ní thugtar dintiúir ar ais ach nuair atá sé cumasaithe)
curl http://localhost:20128/api/settings/obsidian/webdav

# Díchumasaigh sioncronú WebDAV (glantar dintiúir + .stignore bainistithe)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Foinse comhthéacs in aghaidh na heochrach API (roghnach)

Is féidir cumraíocht Obsidian a scópáil **in aghaidh na heochrach API** tríd an tábla
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Nuair a bhíonn
aitheantas eochrach API fíordheimhnithe ag glao MCP, tugann
`getObsidianConfigForApiKey()` tús áite do chomhartha/bhun-URL/chonair taisce na
heochrach féin (`source: "api_key"`); murach sin, úsáidtear an chumraíocht dhomhanda
mar chúltaca (`source: "global"`).

## Uirlisí MCP (22)

Sainmhínítear iad in `open-sse/mcp-server/tools/obsidianTools.ts`. Réitítear an comhartha/an bun-URL
do gach glao (de réir na heochrach API ar dtús, ansin go domhanda). Éilíonn uirlisí a dhéanann teagmháil le **freastalaí sioncronaithe**
OmniRoute (na ceithre uirlis `obsidian_sync_*`) an comhartha fíordheimhnithe sioncronaithe atá cumraithe
i socruithe OmniRoute freisin.

### Uirlisí léite (`read:obsidian`)

| Uirlis                       | Cur síos                                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Seiceáil an bhfuil an Local REST API insroichte agus fíordheimhnithe.                                              |
| `obsidian_search_simple`     | Cuardach lántéacs ar inneachar nótaí; tugtar blúirí le conairí comhad ar ais.                                      |
| `obsidian_search_structured` | Cuardaigh le slonn JSON Logic (scagairí and/or/regex/path).                                                        |
| `obsidian_read_note`         | Léigh nóta de réir conair atá coibhneasta leis an taisclann; ceannteideal/bloc/frontmatter ar leith de rogha.      |
| `obsidian_list_vault`        | Liostaigh comhaid agus eolairí sa taisclann (crann iontrálacha).                                                   |
| `obsidian_get_document_map`  | Faigh struchtúr ceannteideal an nóta mar mhapa de cheannteidil → uimhreacha línte.                                 |
| `obsidian_get_note_metadata` | Faigh frontmatter, clibeanna, naisc, líon carachtar/focal gan an t-inneachar iomlán.                               |
| `obsidian_get_active_file`   | Faigh conair + inneachar an chomhaid atá gníomhach in Obsidian faoi láthair.                                       |
| `obsidian_get_periodic_note` | Faigh an nóta tréimhsiúil laethúil/seachtainiúil/míosúil do dháta (inniu má fhágtar ar lár é).                     |
| `obsidian_get_tags`          | Liostaigh clibeanna uile na taisclainne lena minicíochtaí.                                                         |
| `obsidian_list_commands`     | Liostaigh aitheantais orduithe Obsidian atá ar fáil (úsáid le `obsidian_execute_command`).                         |
| `obsidian_sync_status`       | Stádas fhreastalaí sioncronaithe OmniRoute: ag rith, ainm na taisclainne, port, aga fónaimh, sioncronú deireanach. |
| `obsidian_sync_conflicts`    | Liostaigh coinbhleachtaí sioncronaithe gan réiteach (conair, conair choinbhleachta, am braite).                    |

### Uirlisí scríofa (`write:obsidian`)

| Uirlis                           | Cur síos                                                                                           |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Cruthaigh nó forscríobh nóta leis an inneachar Markdown a thugtar.                                 |
| `obsidian_append_note`           | Cuir inneachar le nóta; le ceannteideal/bloc ar leith de rogha.                                    |
| `obsidian_patch_note`            | Cuir leis/cuir roimh/ionadaigh go beacht ag ceannteideal, bloc, nó réimse frontmatter.             |
| `obsidian_delete_note`           | Scrios nóta go buan ón taisclann.                                                                  |
| `obsidian_move_note`             | Bog nó athainmnigh nóta laistigh den taisclann.                                                    |
| `obsidian_execute_command`       | Rith ordú Obsidian de réir a aitheantais ordaithe.                                                 |
| `obsidian_open_file`             | Oscail comhad in Obsidian (cruthaítear é mura bhfuil sé ann).                                      |
| `obsidian_sync_trigger`          | Spreag sioncronú déthreoch láithreach idir taisclann an deisce↔an fhóin phóca.                     |
| `obsidian_sync_resolve_conflict` | Réitigh coinbhleacht sioncronaithe: coinnigh `local` (fón póca), `remote` (deasc), nó `keep-both`. |

> [!NOTE]
> Glacann spriocanna `obsidian_patch_note` le `targetType` de `heading | block | frontmatter`
> agus `operation` de `append | prepend | replace`, le
> `createTargetIfMissing` roghnach. Déanann na ceithre uirlis `obsidian_sync_*` cumarsáid leis an bhfreastalaí sioncronaithe
> logánta (`http://127.0.0.1:27781` de réir réamhshocraithe) agus éilíonn siad an comhartha sioncronaithe.

### Scóip

Éilíonn uirlisí léite `read:obsidian`; éilíonn uirlisí scríofa `write:obsidian`. Is ionann an forfheidhmiú
agus forfheidhmiú Notion — láimhseálann `withScopeEnforcement()` é in
`open-sse/mcp-server/server.ts`, faoi rialú `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, agus
faightear na scóip cheadaithe ó `OMNIROUTE_MCP_SCOPES` nó ó chomhthéacs scóipe na heochrach API. Féach
[MCP-SERVER.md](./MCP-SERVER.md).

## Críochphointí

| Modh     | Conair                          | Cuspóir                                                              |
| -------- | ------------------------------- | -------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Seol `{ connected, hasToken, baseUrl, vaultPath }` ar ais.           |
| `POST`   | `/api/settings/obsidian`        | Sábháil + bailíochtaigh an comhartha (diúltaítear do phort `27124`). |
| `DELETE` | `/api/settings/obsidian`        | Dícheangail (glan an comhartha stóráilte).                           |
| `GET`    | `/api/settings/obsidian/webdav` | Stádas sioncronaithe WebDAV + dintiúir (fad atá sé cumasaithe).      |
| `POST`   | `/api/settings/obsidian/webdav` | Cumasaigh sioncronú WebDAV do chomhadlann taisce.                    |
| `DELETE` | `/api/settings/obsidian/webdav` | Díchumasaigh sioncronú WebDAV.                                       |

> Is bealaí socruithe don deais iad seo. Sroichtear an taisce féin trí Local REST API
> Obsidian (an `base_url` cumraithe) agus trí na huirlisí MCP thuas — níl aon
> chríochphointe seachfhreastalaí poiblí Obsidian `/v1` ann.

## Cásanna úsáide

- **Freagraí bunaithe ar an taisce** — `obsidian_search_simple` / `obsidian_search_structured`
  agus ansin `obsidian_read_note`, ionas go bhfreagraíonn gníomhaire ó do chuid nótaí féin.
- **Cumadh nótaí / iriseoireacht** — `obsidian_write_note`, `obsidian_append_note`, nó
  an uirlis bheacht `obsidian_patch_note` chun aschur gníomhaire, achoimrí, nó nótaí laethúla
  (`obsidian_get_periodic_note`) a thaifeadadh sa taisce.
- **Nascleanúint na taisce** — `obsidian_list_vault`, `obsidian_get_document_map`, agus
  `obsidian_get_tags` chun an struchtúr a iniúchadh roimh léamh/scríobh.
- **Uathoibriú Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` chun
  breiseáin/orduithe a rialú ó ghníomhaire; `obsidian_open_file` chun nóta a thaispeáint sa chomhéadan úsáideora.
- **Sioncronú móibíleach** — cumasaigh sioncronú WebDAV, ansin `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  chun ríomhaire deisce↔gléas móibíleach a chomhordú agus coinbhleachtaí a réiteach.
