> **Foinse na fírinne:** `src/lib/skills/` agus `src/app/api/skills/`
> **Nuashonraithe go deireanach:** 2026-06-28 — v3.8.40

Cuireann OmniRoute creat insínte Scileanna ar fáil a ligeann do shamhlacha teanga (agus d’oibreoirí) cumais in-athúsáidte a chur le chéile — ó léamh córas comhad agus iarratais HTTP go forghníomhú cód i mbosca gainimh agus scileanna coimeádta ón margadh.

Is aonad oibre leaganaithe, sainithe le scéimre í scil. Is féidir le OmniRoute scileanna a instealladh mar shainmhínithe uirlisí isteach in iarratais amach, glaonna uirlise a thagann ar ais ón tsamhail a idircheapadh, an láimhseálaí meaitseála a rith, agus an toradh a thabhairt ar ais don tsamhail ionas gur féidir leis an gcomhrá leanúint ar aghaidh. Ní fheiceann an tsamhail an cur chun feidhme riamh — ní fheiceann sí ach comhéadan na huirlise.

## Scileanna Gníomhaire vs Scileanna Omni

Tá dhá chóras scileanna ar leith ach comhlántach ag OmniRoute:

| Gné               | **Scileanna Omni** (an cháipéis seo)                                      | **Scileanna Gníomhaire**                                                                      |
| :---------------- | :------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------- |
| Cuspóir           | Instealladh uirlisí LLM + forghníomhú i mbosca gainimh                    | Catalóg SKILL.md le gur féidir le gníomhairí seachtracha í a aimsiú agus a úsáid              |
| Foinse na fírinne | `src/lib/skills/` + an margadh                                            | `src/lib/agentSkills/` + comhadlann `skills/`                                                 |
| Mód ama rite      | Insteallta in iarratais amach, forghníomhaithe ar theagmhais glao uirlise | Catalóg statach markdown + críochphointí aimsithe REST/MCP/A2A                                |
| Cé a úsáideann é  | OmniRoute féin (routáil teaglama, glaonna LLM isteach)                    | Gníomhairí seachtracha, cliaint MCP, ceolfhoirneoirí A2A                                      |
| Líon              | Athraitheach (faoi stiúir an mhargaidh)                                   | 45 iontráil chatalóige (23 API + 21 CLI + 1 chumraíocht)                                      |
| Formáid           | `SkillDefinition` le scéimre uirlise + láimhseálaí                        | Ábhar tosaigh `SKILL.md` + corp markdown                                                      |
| Aimsiú            | REST `/api/skills/*` + uirlisí MCP `omniroute_skills_*`                   | REST `/api/agent-skills/*` + uirlisí MCP `omniroute_agent_skills_*` + `list-capabilities` A2A |

Is iad **Scileanna Omni** an t-inneall forghníomhaithe — sainíonn siad an méid is _féidir le OmniRoute a dhéanamh_ nuair a agraíonn LLM uirlis.

Is í **Scileanna Gníomhaire** an chatalóg doiciméadúcháin — míníonn siad do ghníomhairí seachtracha _conas_ REST API agus CLI OmniRoute a úsáid, le comhaid struchtúrtha SKILL.md ar féidir iad a chur go díreach i leideanna gníomhairí.

Maidir le catalóg, gineadóir, uirlisí MCP agus scil A2A na Scileanna Gníomhaire, féach [docs/frameworks/AGENT-SKILLS.md](./AGENT-SKILLS.md).

## Coincheapa

### Foinsí Scileanna

Tá trí fhoinse scileanna taobh le taobh sa chlárlann chéanna:

1. **Scileanna ionsuite** (`src/lib/skills/builtins.ts`) — soláthraítear iad le OmniRoute. Clúdaíonn siad na cásanna coitianta:
   - `file_read`, `file_write` — spás oibre bosca gainimh ar leith do gach eochair API faoi `<DATA_DIR>/skills/workspaces/<hashed-key>/`
   - `http_request` — HTTP amach trí `safeOutboundFetch` le `guard: "public-only"`
   - `web_search` — soláthraí cuardaigh inphlugáilte le taisceadh (`executeWebSearch`)
   - `eval_code` — forghníomhú `node` nó `python` i mbosca gainimh Docker
   - `execute_command` — ordú blaoisce a fhorghníomhú i mbosca gainimh Docker
   - `browser` — creatlach bunaithe ar Playwright, díchumasaithe de réir réamhshocraithe (`builtin/browser.ts`)
2. **SkillsMP** (Margadh OmniRoute) — faightear iad ó `https://skillsmp.com/api/v1/skills/search`. Teastaíonn `skillsmpApiKey` sna Socruithe.
3. **SkillsSH** (catalóg phobail `skills.sh`) — faightear iad ó `https://skills.sh/api/search`. Ní theastaíonn fíordheimhniú; tarraingítear ábhar SKILL.md ó ábhar amh GitHub.

Rialaíonn "soláthraí gníomhach" amháin cén chatalóg óna ndéanann an deais suiteáil (`src/lib/skills/providerSettings.ts`). Athraigh é faoi **Socruithe → Cuimhne & Scileanna**. Réamhshocrú: `skillsmp`.

### Aitheantas Scile

Úsáidtear `name@version` mar eochair do scileanna sa chlárlann sa chuimhne (`src/lib/skills/registry.ts`). Ní mór don leagan a bheith ina semver (`^\d+\.\d+\.\d+$`). Tuigeann `resolveVersion()` na srianta `^`, `~`, `>`, `>=`, `<`, `<=`, `==`, agus srianta meaitseála beaichte.

### Mód Scile

Tá mód ama rite ag gach scil a rialaíonn cathain a instealltar í:

| Mód    | Iompar                                                                                                                                 |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| `on`   | Instealltar i gcónaí í mar shainmhíniú uirlise                                                                                         |
| `off`  | Ní instealltar riamh í agus ní féidir í a fhorghníomhú                                                                                 |
| `auto` | Scóráiltear í i gcoinne an iarratais isteach; ní instealltar í ach amháin má tá an scór ≥ `AUTO_MIN_SCORE` (3 de réir réamhshocraithe) |

Is é `auto` an réamhshocrú do scileanna suiteáilte ón margadh. Ciallaíonn `enabled=true` agus `mode="off"` le chéile "cláraithe ach neamhghníomhach" — nuair a scoránaítear `enabled` tríd an gcolún oidhreachta, nuashonraítear `mode` freisin ionas go bhfanfaidh sean-chonairí cóid comhsheasmhach (`src/app/api/skills/[id]/route.ts`).

### Stádas (forghníomhuithe)

Déantar forghníomhuithe scileanna a rianú sa tábla `skill_executions` leis na stádais seo a leanas (`src/lib/skills/types.ts`):

```ts
enum SkillStatus {
  PENDING = "pending",
  RUNNING = "running",
  SUCCESS = "success",
  ERROR = "error",
  TIMEOUT = "timeout",
}
```

### Taisce na Clárlainne

Is singleton í `SkillRegistry` le taisce TTL 60 soicind (`registry.ts:14`). Tá `loadFromDatabase()` idéimitheach agus dí-dhúblaíonn sí glaonna comhthráthacha trí `pendingLoad`. Déanann aon scríobh (`register`/`unregister`/`unregisterById`) an taisce a neamhbhailíochtú. Cuardaigh leaganacha trí `getSkillVersions(name)` agus `resolveVersion(name, constraint)`.

### Instealladh Feasach ar Sholáthraí

Is é `injectSkills()` in `src/lib/skills/injection.ts` an pointe iontrála a athraíonn scileanna cláraithe ina sainmhínithe uirlisí a bhaineann go sonrach leis an soláthraí:

- **OpenAI** — `{ type: "function", function: { name, description, parameters } }`
- **Anthropic** — `{ name, description, input_schema }`
- **Google (Gemini)** — `{ name, description, parameters }`

Ionchódaítear ainm na huirlise mar `name@version` ionas gur féidir leis an láimhseálaí an leagan ceart a roghnú nuair a ghlaonn an tsamhail ar ais í.

### Scóráil AUTO

Nuair atá `mode="auto"`, scóráiltear gach scil iarrthóra i gcoinne chomhthéacs na hiarrata (`scoreAutoSkill()` in `injection.ts`):

| Comhartha                                                              | Pointí                           |
| ---------------------------------------------------------------------- | -------------------------------- |
| Tá ainm na scile le feiceáil focal ar fhocal sa chomhthéacs            | +6                               |
| Meaitseálann gach téacschomhartha ainm téacschomhartha comhthéacs      | +2                               |
| Meaitseálann gach fotheaghrán clibe leis an gcomhthéacs                | +3                               |
| Meaitseálann gach téacschomhartha tuairisce téacschomhartha comhthéacs | +1                               |
| Meaitseálann cúis chúlra téacschomhartha ainm                          | +2 in aghaidh an téacschomhartha |
| Meaitseálann cúis chúlra clib                                          | +2 in aghaidh an téacschomhartha |
| Meaitseálann leid soláthraí sna clibeanna soláthraí na hiarrata        | +2 / −2                          |

Instealltar na `AUTO_MAX_SKILLS = 5` scil is airde a bhfuil `score >= AUTO_MIN_SCORE = 3` acu. Réitítear comhscóir de réir `installCount` (in ord íslitheach), agus ansin de réir ainm aibítreach (`injection.ts:225-235`).

### Idircheapadh Glaonna Uirlise

Glaonn an láimhseálaí comhrá `handleToolCallExecution()` in `src/lib/skills/interception.ts` tar éis don tseirbhís réamhtheachtach freagra glaoite uirlise a thabhairt ar ais:

1. Léann `extractToolCalls()` cruthanna a bhaineann go sonrach le soláthraithe (OpenAI `tool_calls` / Responses `function_call`, Anthropic `tool_use`, Gemini `functionCalls`).
2. Réitítear ailiasanna uirlisí ionsuite (m.sh. `omniroute_web_search` → `web_search`) ar dtús. Ritheann láimhseálaithe ionsuite inlíne.
3. Seoltar gach rud eile trí `skillExecutor.execute(name@version, args, { apiKeyId, sessionId })`.
4. Cuirtear na torthaí isteach arís sa fhreagra — míreanna `tool_results`, `function_call_output`, nó bloic Anthropic `tool_result`, de réir mar is cuí.

Is féidir `customSkillExecutionEnabled` sa chomhthéacs rite a shocrú go `false` chun idircheapadh ionsuite amháin a cheadú (úsáideann conairí iarrata é seo nuair a dhíchumasaíonn siad láimhseálaithe sainithe ag úsáideoirí go sainráite).

## Bosca Gainimh Docker

Ritear conairí cóid nach bhfuil ionsuite (`eval_code`, `execute_command`) laistigh de Docker trí `SandboxRunner` (`src/lib/skills/sandbox.ts`). Seoltar gach coimeádán leis na roghanna seo:

```
--rm --network none|bridge --cap-drop ALL
--security-opt no-new-privileges --pids-limit 100
--cpus <cpuLimit/1000> --memory <memoryLimit>m
--tmpfs /tmp:rw,noexec,nosuid,size=64m
--tmpfs /workspace:rw,noexec,nosuid,size=64m
--read-only (nuair atá readOnly=true)
```

Réamhshocruithe (`SandboxRunner.DEFAULT_CONFIG`):

| Réimse           | Réamhshocrú     | Nótaí                                                                            |
| ---------------- | --------------- | -------------------------------------------------------------------------------- |
| `cpuLimit`       | 100 (= 0.1 CPU) | Roinntear ar 1000 é sula gcuirtear ar aghaidh chuig `--cpus` é                   |
| `memoryLimit`    | 256 MB          | Teorainn chrua                                                                   |
| `timeout`        | 30000 ms        | Marú bog trí `SIGTERM` + `docker kill`                                           |
| `networkEnabled` | `false`         | Déantar `--network none` de                                                      |
| `readOnly`       | `true`          | Tá an córas comhad fréimhe inléite amháin; is tmpfs iad `/tmp` agus `/workspace` |

Tá `SandboxRunner.kill(id)` agus `killAll()` nochta le haghaidh múchta; rianaítear coimeádáin atá ag rith in `runningContainers: Map<string, ChildProcess>`.

### Athróga Timpeallachta an Bhosca Gainimh

Cumraítear iad trí `process.env` in `src/lib/skills/builtins.ts`:

| Athróg Timpeallachta              | Réamhshocrú      | Cuspóir                                                                                                    |
| --------------------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------- |
| `SKILLS_MAX_FILE_BYTES`           | `1048576` (1 MB) | Uasteorainn do `file_read` agus `file_write`                                                               |
| `SKILLS_MAX_HTTP_RESPONSE_BYTES`  | `256000`         | Uasteorainn do chorp freagartha `http_request`                                                             |
| `SKILLS_MAX_SANDBOX_OUTPUT_CHARS` | `100000`         | Uasteorainn do stdout/stderr a chuirtear ar ais chuig an nglaoiteoir                                       |
| `SKILLS_SANDBOX_TIMEOUT_MS`       | `10000`          | Teorainn ama réamhshocraithe d’orduithe bosca gainimh; uasteorainn 60 s                                    |
| `SKILLS_SANDBOX_NETWORK_ENABLED`  | `false`          | Máistirgheata don trácht amach. Socraigh go `1` nó `true` chun roghnú isteach in aghaidh an ghlao a cheadú |
| `SKILLS_ALLOWED_SANDBOX_IMAGES`   | (féach thíos)    | Liosta ceadaithe d’íomhánna Docker, deighilte le camóga                                                    |

Íomhánna réamhshocraithe ceadaithe: `alpine:3.20`, `node:22-alpine`, `python:3.12-alpine`. Cumascfar aon íomhánna a chuirtear leis trí `SKILLS_ALLOWED_SANDBOX_IMAGES` leis na réamhshocruithe; diúltaíonn `normalizeImage()` d’íomhánna anaithnide.

> Nóta: níl aon athróg timpeallachta `SKILLS_EXECUTION_TIMEOUT_MS` ar leith ann. Tá teorainn ama an láimhseálaí nach mbaineann leis an mbosca gainimh crua-chódaithe go 30 s in `SkillExecutor` (`executor.ts:13`), ach is féidir í a shárú ag am rite trí `skillExecutor.setTimeout(ms)`.

### Leithlisiú an Spáis Oibre

Réitíonn `file_read` agus `file_write` gach conair i gcoibhneas le spás oibre in aghaidh na heochrach API ag `<DATA_DIR>/skills/workspaces/<sha256(apiKeyId).slice(0,24)>/`. Diúltaítear do thrasnú conaire (`..`) agus do mhíreanna toirmiscthe (`.env`, `.git`, `.ssh`, `.omniroute`, `.codex`, `secrets`) sula ndéantar aon I/O diosca.

### Cruachan HTTP

`http_request` (`builtins.ts:257`):

- Liosta ceadaithe modhanna: `GET, HEAD, POST, PUT, PATCH, DELETE`
- Ceanntásca amach blocáilte: `host, connection, content-length, cookie, set-cookie, authorization, proxy-authorization`
- Atreoruithe díchumasaithe (`allowRedirect: false`)
- Seoltar trí `safeOutboundFetch` é le `guard: "public-only"` (cuirtear bac ar raonta príobháideacha/aisfhillte)
- Teasctar an freagra ag `SKILLS_MAX_HTTP_RESPONSE_BYTES`; feiceann an cliant `truncated: true`

## REST API

Tá gach críochphointe faoi `src/app/api/skills/`. Éilíonn críochphointí bainistíochta (`/api/skills`, `/api/skills/[id]`, `/api/skills/install`) **fíordheimhniú bainistíochta** trí `requireManagementAuth()`. Úsáideann sreafaí an mhargaidh/na suiteála an `isAuthenticated()` níos éadroime (seisiún nó eochair API).

| Críochphointe | Modh | Cuspóir |
| --------------------------------- | ------ | ------------------------------------------------------------------------ | --- | ------------------------ | -------- | ------------------ |
| `/api/skills` | GET | Liostaigh scileanna cláraithe. Tacaíonn sé le `?q=`, `?mode=on          | off | auto`, `?source=skillsmp | skillssh | local`, uimhriú leathanach |
| `/api/skills/[id]` | PUT | Nuashonraigh `enabled` nó `mode` |
| `/api/skills/[id]` | DELETE | Díchláraigh de réir aitheantais |
| `/api/skills/install` | POST | Suiteáil scil shaincheaptha (cód láimhseálaí + scéimre) |
| `/api/skills/marketplace` | GET | Cuardaigh catalóg SkillsMP (filleann sé réamhshocruithe móréilimh nuair atá `q` folamh) |
| `/api/skills/marketplace/install` | POST | Suiteáil scil SkillsMP (éilíonn soláthraí gníomhach = `skillsmp`) |
| `/api/skills/skillssh` | GET | Cuardaigh catalóg skills.sh (`?q=&limit=`, teoranta do 100) |
| `/api/skills/skillssh/install` | POST | Suiteáil scil skills.sh (éilíonn soláthraí gníomhach = `skillssh`) |
| `/api/skills/executions` | GET | Stair rite uimhrithe de réir leathanaigh (`?apiKeyId=`) |
| `/api/skills/executions` | POST | Rith scil chláraithe ar bhonn ad hoc |

Filleann an críochphointe `POST /api/skills/executions` HTTP `503` le `{ error: "Skills execution is disabled..." }` nuair atá `settings.skillsEnabled === false` (`executor.ts:42-45`). Is féidir le hoibreoirí an máistirlasc a athrú ó **Socruithe → IS**.

### Sampla: suiteáil scil shaincheaptha

```bash
curl -X POST http://localhost:20128/api/skills/install \
  -H "Authorization: Bearer $OMNIROUTE_MGMT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "reverse-text",
    "version": "1.0.0",
    "description": "Reverses a string",
    "schema": {
      "input":  { "type": "object", "properties": { "text": { "type": "string" } }, "required": ["text"] },
      "output": { "type": "object", "properties": { "reversed": { "type": "string" } } }
    },
    "handlerCode": "echo-handler",
    "apiKeyId": "your-api-key-id"
  }'
```

Is **cuardach ainm láimhseálaí** é an teaghrán `handlerCode` — ní cód inrite. Mapálann an reáchtálaí é trí `skillExecutor.registerHandler(name, fn)` (`executor.ts:25`). Stórálann suiteálacha ón margadh téacs SKILL.md sa réimse seo mar dhoiciméadacht agus seolann siad an rith trí ghlaonna uirlise arna nginiúint ag an tsamhail. Ní dhéantar eval ar fhoinse threallach arna soláthar ag úsáideoir.

## Leideanna Oibríochtúla

- **Máistirlasc:** cuireann `settings.skillsEnabled = false` bac ar gach rith agus tugann sé HTTP `503` ar `/api/skills/executions`. Leanann an chlárlann de bheith á lódáil.
- **Cuir srian ar thrácht amach:** fág `SKILLS_SANDBOX_NETWORK_ENABLED` gan socrú (an réamhshocrú) le haghaidh bosca gainimh atá go hiomlán scoite ón líonra. Teastaíonn cead ón máistirgheata fós ó `networkEnabled: true` in aghaidh an ghlao.
- **Ceadaigh íomhánna sonracha:** socraigh `SKILLS_ALLOWED_SANDBOX_IMAGES="myorg/sandbox:1.0,node:22-alpine"` chun an liosta ceadaithe a leathnú.
- **Iniúch rití:** déanann `/dashboard/skills/executions` agus `omniroute_skills_executions` araon ceist ar `skill_executions`. Áirítear `durationMs` le rití rathúla; áirítear `errorMessage` le teipeanna.
- **Neamhbhailíochtú taisce:** glaoigh ar `skillRegistry.invalidateCache()` tar éis athruithe láimhe ar an mbunachar sonraí; murach sin fan 60 s.
- **Spás oibre anaithnid:** nuair atá `apiKeyId` folamh, déantar hais de gach glao chuig an spás oibre `"anonymous"` céanna — ba cheart do chód atá feasach ar chomhroinnt fíoreochair a chur ar aghaidh i gcónaí.

## Saolré an Fhorghníomhaithe (v3.8.16+)

Is **aontonach** é `SkillExecutor` (`src/lib/skills/executor.ts`) a bhainistíonn gach gairm scile. Tá sé ríthábhachtach a shaolré a thuiscint chun teorainneacha ama, atrialacha agus staid an fhorghníomhaithe a dhífhabhtú.

### An Saolré 5 Chéim

```
   glaodh ar execute()
        │
        ▼
  ┌─────────────┐
  │  PENDING    │  ← sa scuaine, gan tosú fós (ró DB cruthaithe)
  └──────┬──────┘
         │ tosaigh an láimhseálaí
         ▼
  ┌─────────────┐
  │  RUNNING    │  ← glaodh ar an láimhseálaí le teorainn ama
  └──────┬──────┘
         │
    ┌────┴────┬──────────┬──────────┐
    │         │          │          │
    ▼         ▼          ▼          ▼
  SUCCESS   ERROR     TIMEOUT   (níl aon chonair eile — maraithe ag an máthairphróiseas)
    │         │          │
    └────┬────┴──────────┘
         │
         ▼
   Ró DB nuashonraithe le stádas, aschur, durationMs
```

### Cumraíocht Réamhshocraithe

| Socrú        | Réamhshocrú   | Inchumraithe trí                     |
| ------------ | ------------- | ------------------------------------ |
| `timeout`    | `30000` (30s) | `skillExecutor.setTimeout(ms)`       |
| `maxRetries` | `3`           | `skillExecutor.setMaxRetries(count)` |

> **Tábhachtach**: Is aontonach é an forghníomhaitheoir — bíonn tionchar domhanda ag glao ar `setTimeout()` ar gach gairm ina dhiaidh sin. Ní thacaítear faoi láthair le teorainneacha ama de réir scile; má theastaíonn teorainneacha ama éagsúla uait do gach scil, seol próisis ar leith nó cruthaigh gabhal den fhorghníomhaitheoir.

### Luachanna Stádais

Ó `src/lib/skills/types.ts`:

```ts
enum SkillStatus {
  PENDING = "pending", // Sa scuaine, gan tosú fós
  RUNNING = "running", // Glaodh ar an láimhseálaí
  SUCCESS = "success", // D'fhill an láimhseálaí aschur bailí
  ERROR = "error", // Chaith an láimhseálaí eisceacht
  TIMEOUT = "timeout", // Sáraíodh teorainn ama an fhorghníomhaitheora
}
```

> **Nóta**: Tá an stádas `TIMEOUT` sainmhínithe san enum ach **ní scríobhann** cur chun feidhme reatha an fhorghníomhaitheora chuig an DB é — léirítear teorainneacha ama mar `ERROR` leis an teachtaireacht `"Skill execution timed out"`. Tá an enum stádais curtha in áirithe lena úsáid amach anseo.

### Forghníomhuithe a Iniúchadh

```ts
import { skillExecutor } from "omniroute/skills/executor";

// Faigh forghníomhú ar leith de réir ID
const exec = skillExecutor.getExecution("exec-uuid-123");
if (exec) {
  console.log(`${exec.skillName}: ${exec.status} in ${exec.durationMs}ms`);
}

// Liostaigh forghníomhuithe le déanaí le haghaidh eochair API
const recent = skillExecutor.listExecutions("api-key-id", 50, 0);
for (const e of recent) {
  console.log(`${e.skillName} → ${e.status} (${e.durationMs}ms)`);
}

// Comhair líon iomlán na bhforghníomhuithe
const total = skillExecutor.countExecutions("api-key-id");
```

### Iompar Atrialacha

Stóráiltear an socrú `maxRetries` ach **ní úsáideann** modh `execute()` an fhorghníomhaitheora é faoi láthair — ní dhéanann sé ach aon iarracht amháin. Cuirtear an luach `maxRetries` ar fáil le haghaidh cur chun feidhme amach anseo agus le haghaidh duán ar mian leo é a léamh.

Faoi láthair, ní mór atrialacha a chur chun feidhme laistigh den láimhseálaí scile féin. Cláraítear
scileanna ionsuite leis an bhforghníomhaitheoir (m.sh. `registerBuiltinSkills(executor)`
/ `registerBrowserSkill(executor)` in `src/lib/skills/builtin/`); is féidir le cibé láimhseálaí
a chláraíonn tú a lúb atrialacha féin a chuimsiú:

```ts
// laistigh de láimhseálaí scile
async function handler(input, ctx) {
  const maxRetries = 3;
  let lastError: Error | null = null;

  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      return await fetchSomething(input);
    } catch (err) {
      lastError = err as Error;
      if (attempt < maxRetries) {
        await new Promise((r) => setTimeout(r, 1000 * attempt));
      }
    }
  }
  throw lastError;
}
```

## SkillMode go Mion

Rialaíonn an t-enum `SkillMode` (`src/lib/skills/types.ts`) **cathain agus conas** a agraítear scileanna:

```ts
enum SkillMode {
  AUTO = "auto", // Cinneann an LLM cathain is ceart an scil a ghlaoch
  MANUAL = "manual", // Ní agraítear í ach ar iarratas sainráite ón úsáideoir
  HYBRID = "hybrid", // Scóráil AUTO + sárú láimhe
}
```

> **Nóta**: Sainmhíníonn an bunachar cód `SkillMode` (AUTO/MANUAL/HYBRID), agus úsáideann an réimse `Skill.mode` struchtúr eile (`"on" | "off" | "auto"`). Tá gaol eatarthu ach ní hionann iad — baineann `SkillMode` le polasaí an fheidhmitheora, agus baineann `Skill.mode` le cumasú gach scile ar leith.

### Cathain is Ceart Gach Mód a Úsáid

| Mód      | Iompar an LLM                                                                                | Cás úsáide                                                        |
| -------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `AUTO`   | Is féidir leis an LLM an scil a ghlaoch nuair a mheasann sé gur gá                           | Scileanna ilchuspóireacha (léamh comhad, iarratais HTTP)          |
| `MANUAL` | Ní féidir leis an LLM an scil a ghlaoch; ní agraíonn ach glao sainráite API `executeSkill` í | Oibríochtaí íogaire (scríobh chuig bunachar sonraí, íocaíochtaí)  |
| `HYBRID` | Is féidir leis an LLM an scil a mholadh; ní mór don úsáideoir í a dheimhniú                  | Scileanna a bhfuil fo-éifeachtaí acu ach nach bhfuil contúirteach |

### Scóráil AUTO

Nuair atá mód `AUTO` gníomhach, déantar gach scil iarrthach a scóráil i gcoinne chomhthéacs
an iarratais le `scoreAutoSkill()` in `src/lib/skills/injection.ts` — córas suimitheach
pointí slánuimhreacha (meaitseáil ainm na scile, forluí comharthaí ainm/clib/tuairisce,
leideanna cúise cúlra, bónas/pionós leide soláthraí). Instealltar na
`AUTO_MAX_SKILLS = 5` scil is airde a bhfuil `score >= AUTO_MIN_SCORE = 3` acu mar
uirlisí inghlaoite; réitítear comhscóir de réir `installCount` agus ansin de réir ainm. Féach an tábla iomlán pointí
in [**Giniúint Scéimre Uirlisí → Scóráil AUTO**](#auto-scoring) níos luaithe sa
cháipéis seo; níl aon tairseach snámhphointe ar nós `0.6` ann agus ní dhéantar aon scóráil in `registry.ts`.
