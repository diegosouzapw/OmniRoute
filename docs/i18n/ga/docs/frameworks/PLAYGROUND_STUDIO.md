## Forbhreathnú

Athraíonn Playground Studio `/dashboard/playground` ó eagarthóir simplí bunaithe ar Monaco go
spás oibre tástála lánfheistithe. Cuireann sé blaosc `PlaygroundStudio` in ionad an tseanleagain
`page.tsx`, a rindreálann ceithre chluaisín agus pána cumraíochta comhroinnte.

```
┌ Playground ──────────────────────────────────────────────────────────┐
│ [💬 Comhrá] [⚖ Comparáid] [{} API] [🔧 Tógáil] 142↑ 38↓ · $0.002 </>│
├──────────────────────────────────────────┬───────────────────────────┤
│  {ábhar an chluaisín ghníomhaigh}        │ ─ Cumraíocht              │
│                                          │ Críochphointe [chat ∨]    │
│                                          │ Samhail       [gpt-5.4 ∨] │
│                                          │ Córas         [textarea]  │
│                                          │ Teocht        ▕▕▔▔ 0.7    │
│                                          │ Réamhshocruithe           │
│                                          │ [▾ lódáil][sábháil]       │
│                                          │ [✨ Feabhsaigh an leid]    │
└──────────────────────────────────────────┴───────────────────────────┘
```

## Cluaisíní

### Cluaisín Comhrá

Forbraíonn sé `ChatPlayground.tsx` ina bhinse oibre sruthaithe ilseal:

- Rindreáil iomlán Markdown trí `MarkdownMessage.tsx` (bloic chóid, táblaí, liostaí, naisc).
- Leid chórais a fhaightear ón bpána Cumraíochta comhroinnte.
- Comharthaí/costas in aghaidh na teachtaireachta (comharthaí leid + críochnaithe).
- Athghin an freagra deireanach.
- Seolann sé chuig `POST /v1/chat/completions` le sruthú SSE.

### Cluaisín Comparáide

An príomhfhachtóir idirdhealaitheach do sheachfhreastalaí: rith 1 leid thar suas le **4 shamhail go comhthreomhar**.

- Suas le 4 cholún, agus gach ceann acu ag sruthú go neamhspleách ó `/v1/chat/completions`.
- Cnaipe `+ Cuir samhail leis` (aicearra Cmd+K) chun colúin a chur leis.
- Cuireann `Rith iad uile ▶` tús leis na sruthanna uile ag an am céanna trí `Promise.all` + `AbortController` do gach colún.
- Tobscoireann **Cealaigh iad uile** domhanda gach sruth atá ar siúl.
- Taispeánann `ProviderMetrics` do gach colún TTFT, TPS, comharthaí agus costas measta i bhfíor-am.
- Lipéadaítear na méadrachtaí mar **"meastachán ar thaobh an chliaint"** (D12) — tomhaiste ón gcéad smután SSE.

### Cluaisín API

Caomhnaíonn sé 100% den eagarthóir Monaco bunaidh d’úsáideoirí ardchumais (D14):

- 10 gcríochphointe: críochnuithe comhrá, críochnuithe, leabuithe, íomhánna, fuaim, urlabhra, tras-scríbhinní, modhnóireacht, athrangú, cuardach.
- Uaslódáil comhad ilmhódach.
- Sruthú SSE le haschur fíor-ama.
- Fillte mar `ApiTab.tsx` (luchtaithe go leisciúil, `ssr: false`).

### Cluaisín Tógála

Comhéadan úsáideora le haghaidh uirlisí/glaoch feidhme agus aschur struchtúrtha:

- `ToolsBuilder.tsx` — cuir `tools[]` leis, cuir in eagar iad nó bain iad, le heagarthóir scéimre JSON do gach uirlis.
  Bailíochtaíonn sé paraiméadair trí `ToolDefinitionSchema` (Zod).
- `StructuredOutputEditor.tsx` — scoránaigh mód JSON + eagarthóir scéimre JSON.
  Bailíochtaíonn sé an freagra in aghaidh na scéimre trí `StructuredOutputSchema` (Zod).
- Seolann sé iarratas chuig `/v1/chat/completions` le `tools[]` agus/nó `response_format`.

## Pána Cumraíochta (Comhroinnte)

`StudioConfigPane.tsx` — infheicthe i gcónaí, infhillte.

| Réimse          | Comhpháirt            | Nótaí                                                                             |
| --------------- | --------------------- | --------------------------------------------------------------------------------- |
| Críochphointe   | `<select>`            | 10 rogha a mheaitseálann `PlaygroundEndpoint`                                     |
| Samhail         | `<input>`             | téacs saor, m.sh. `openai/gpt-4o`                                                 |
| Leid chórais    | `<textarea>`          | cuirtear isteach i ngach cluaisín í                                               |
| Paraiméadair    | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop            |
| Réamhshocruithe | `PresetPicker`        | luchtaigh/sábháil pictiúir chumraíochta ainmnithe (marthanach sa DB)              |

Ardaítear an staid go `PlaygroundStudio.tsx` agus cuirtear ar aghaidh í chuig gach cluaisín. Coinnítear
staid na cumraíochta agus cluaisíní á n-athrú.

## Mód Dialóige Easpórtála Cóid

Úsáideann `ExportCodeModal.tsx` `codeExport.ts` chun blúirí curl / Python / TypeScript a ghiniúint
ón `PlaygroundState` reatha. Is é `$OMNIROUTE_API_KEY` an t-ionadchoinneálaí don eochair API i gcónaí (D11).

---

## Feabhsaitheoir Leide

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. Tugann an mód dialóige rabhadh go “n-úsáidfear cuóta”.
2. Tar éis deimhniúcháin, seolann sé `{ system, prompt, model, tone }` chuig an mbealach.
3. Glaonn an bealach `/v1/chat/completions` go hinmheánach le `promptImprover.META_SYSTEM_PROMPT`.
4. Filleann sé `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }`.
5. Paisteálann an Chomhéadain leid chórais an Phána Cumraíochta agus leid úsáideora an chluaisín Comhrá.

---

## Réamhshocruithe

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- Stóráiltear iad sa tábla SQLite `playground_presets` (imirce `084_playground_presets.sql`).
- Stórálann gach réamhshocrú: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: liosta `GET`, cruthú `POST`, `GET /:id`, `PUT /:id`, `DELETE /:id`.

---

## Méadrachtaí Srutha

`useStreamMetrics.ts` + `streamMetrics.ts` (feidhm íon):

- `start()` — taifeadann sé am tosaithe na hiarrata.
- `onFirstChunk()` — taifeadann sé TTFT.
- `onChunk(n)` — carnann sé líon na gcomharthaí comhlánaithe.
- `finish(usage?)` — ríomhann sé na méadrachtaí deiridh: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- Praghsáil ón tábla statach in `src/lib/playground/types.ts` (lipéadaithe “measta” — D13).
