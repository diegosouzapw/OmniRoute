> **Foinse na fírinne:** `src/lib/agentSkills/` (catalóg, gineadóir, parsálaithe) + comhadlann `skills/` (comhaid SKILL.md)
> **Nuashonraithe an uair dheireanach:** 2026-08-02 — v3.8.50

Is comhaid struchtúrtha SKILL.md iad Scileanna Gníomhaire a mhúineann do ghníomhairí seachtracha, do chliaint MCP, agus do cheolfhoirneoirí A2A conas REST API agus CLI OmniRoute a úsáid. Murab ionann agus [Scileanna Omni](./SKILLS.md) (ar sainmhínithe uirlisí LLM iad a ritear laistigh de OmniRoute), is _catalóg doiciméadúcháin_ iad Scileanna Gníomhaire — markdown statach is féidir a chur go díreach i gcomhthéacs gníomhaire.

---

## Forléargas

Tá **45 Scil Gníomhaire** sa chatalóg (23 REST API + 21 CLI + 1 sreabhadh oibre cumraíochta). Tá na nithe seo a leanas ag gach scil:

- **Aitheantas canónach** (`omni-auth`, `cli-serve`, etc.)
- Comhad **SKILL.md** in `skills/{id}/SKILL.md` le réamhábhar YAML (`name`, `description`) + corp saibhir markdown
- **Críochphointí REST** (scileanna API) nó **fo-orduithe CLI** (scileanna CLI) a dhíorthaítear ó shonraíocht OpenAPI agus ó chlárlann CLI
- **URL amh GitHub** le haghaidh aisghabháil bheo: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Aimsiú REST API

| Críochphointe                | Modh | Cur síos                                                                  | Fíordheimhniú  |
| :--------------------------- | :--- | :------------------------------------------------------------------------ | :------------- |
| `/api/agent-skills`          | GET  | Liostaigh an chatalóg (`?category=api\|cli\|config&area=<area>` roghnach) | gan aon cheann |
| `/api/agent-skills/{id}`     | GET  | Faigh meiteashonraí scile aonair                                          | gan aon cheann |
| `/api/agent-skills/{id}/raw` | GET  | Faigh SKILL.md mar `text/markdown`                                        | gan aon cheann |
| `/api/agent-skills/coverage` | GET  | Staitisticí cumhdaigh (líon na gcomhad SKILL.md atá ann)                  | gan aon cheann |
| `/api/agent-skills/generate` | POST | Cuir an gineadóir ar siúl (dryRun/prune/onlyIds)                          | bainistíocht   |

Sampla — liostaigh gach scil API:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Sampla — faigh SKILL.md aonair:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

```json

  "method": "message/send",
  "params": {
```

## Conas a Úsáideann Gníomhairí Seachtracha Scileanna

### 1. Aimsiú trí REST

```bash
# Faigh an chatalóg iomlán
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Faigh SKILL.md lena instealladh sa chomhthéacs
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Aimsiú trí MCP

```typescript
// I gcliant MCP Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → eagar de AgentSkill agus rawUrl do gach ceann acu
```

### 3. Aimsiú trí A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# Is tábla markdown é table ina bhfuil na 45 aitheantas scile ar fad + colúin rawUrl
```

### 4. Aisghabháil dhíreach amh ó GitHub (níl freastalaí ag teastáil)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Gineadóir

Léann an gineadóir an chatalóg choimeádta + sonraíocht OpenAPI + clárlann CLI agus scríobhann sé `skills/{id}/SKILL.md` do gach iontráil:

```bash
# Réamhamharc (rith thirim, gan aon scríobh)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Athghiniúint iomlán
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Athghin aitheantais shonracha
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Is `GeneratorReport` é freagra an ghineadóra:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
