## `claude-web`

Seolann `claude-web` iarratais chomhrá i bhformáid OpenAI trí sheisiún fíordheimhnithe brabhsálaí `claude.ai`. Normalaíonn an seiceadóir an fianán a soláthraíodh, réitíonn sé eagraíocht fhíordheimhnithe amháin, ullmhaíonn sé staid an chomhrá, roghnaíonn sé iompar díreach nó iompar brabhsálaí, agus aistríonn sé freagra SSE réamhtheachtach go docht. Tá an t-orcastrúchán in `open-sse/executors/claude-web.ts:320`.

> **An bhfuil soláthraithe Fianán Gréasáin nua duit?**
>
> Léigh **`docs/getting-started/WEB-COOKIE-GUIDE.md`** chun eolas a fháil faoin bpróiseas socraithe ginearálta, faoin treoir fíordheimhnithe, faoi na teorainneacha agus faoin bhfabhtcheartú sula leanfaidh tú an treoir seo a bhaineann go sonrach leis an soláthraí seo.

### Catalóg samhlacha

Faoi láthair, nochtann clárlann an tsoláthraí na seacht n-aitheantas samhla statacha seo go díreach
(`open-sse/config/providers/registry/claude/web/index.ts:11`):

| Aitheantas samhla           | Ainm taispeána              |
| --------------------------- | --------------------------- |
| `claude-fable-5`            | Claude Fable 5 (gréasán)    |
| `claude-opus-4-8`           | Claude Opus 4.8 (gréasán)   |
| `claude-sonnet-5`           | Claude Sonnet 5 (gréasán)   |
| `claude-haiku-4-5-20251001` | Claude Haiku 4.5 (gréasán)  |
| `claude-opus-4-7`           | Claude Opus 4.7 (gréasán)   |
| `claude-opus-4-6`           | Claude Opus 4.6 (gréasán)   |
| `claude-sonnet-4-6`         | Claude Sonnet 4.6 (gréasán) |

Níl aimsiú dinimiciúil samhlacha curtha i bhfeidhm don soláthraí seo. Is é an liosta thuas an chatalóg ag am rite.

### Dintiúir agus réiteach eagraíochta

Soláthair ceanntásc iomlán Cookie `claude.ai` nó luach seisiúin lom. Normalaítear luachanna loma go `sessionKey`; caomhnaítear fianáin eile má sholáthraítear iad. Glacann an seiceadóir leis an bhfianán trí `cookie` nó `apiKey` agus léann sé luachanna roghnacha `deviceId` agus `orgId` ó shonraí an naisc
(`open-sse/executors/claude-web.ts:72`).

Mura bhfuil `orgId` ann, glaonn an seiceadóir ar `GET https://claude.ai/api/organizations` agus úsáideann sé an chéad eagraíocht a chuireann seisiún fíordheimhnithe Claude Web ar ais
(`open-sse/executors/claude-web.ts:141`). Teipeann sé go dúnta nuair nach gcuirtear aon eagraíocht bhailí ar ais, tuairiscíonn sé údarú seisiúin diúltaithe mar 401, agus déanann sé idirdhealú idir dúshlán Cloudflare agus teip fíordheimhnithe.

### Oibríochtaí comhrá

Tá an réad ardleibhéil roghnach `claude_web` docht. Diúltaítear do réimsí anaithnide. Sainmhínítear na réimsí a nglacann sé leo in `open-sse/executors/claude-web/session.ts:50`:

| Réimse                | Brí                                                                            |
| --------------------- | ------------------------------------------------------------------------------ |
| `operation`           | `completion` de réir réamhshocraithe; úsáid `retry` le haghaidh seal atrialach |
| `conversation_id`     | UUID sainráite do chomhrá atá ann cheana                                       |
| `parent_message_uuid` | UUID sainráite do theachtaireacht chúntóra na máthar                           |
| `timezone`            | Ainm crios ama bailí IANA                                                      |
| `locale`              | Logchaighdeán atá bailí ó thaobh struchtúir de                                 |
| `tool_states`         | Eagar roghnach de staideanna uirlisí cuntais, teoranta do 128 iontráil         |

Úsáideann iarratais ullmhaithe ceann amháin de dhá chríochphointe réamhtheachtacha
(`open-sse/executors/claude-web.ts:203`):

- Seoltar seal nua nó seal leantach chuig
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/completion`.
- Seoltar atriail chuig
  `POST https://claude.ai/api/organizations/{orgId}/chat_conversations/{conversationId}/retry_completion`.

Cuimsíonn seal nua `create_conversation_params`. Cuimsíonn seal leantach atá i dtaisce nó nasctha go sainráite `parent_message_uuid` agus fágtar `create_conversation_params` ar lár. Éilíonn atriail staid an chomhrá agus staid na teachtaireachta máthar araon agus ní sheolann sí leid
(`open-sse/executors/claude-web/session.ts:254`). Osclaíonn comhráite nua an comhéadain úsáideora fhíordheimhnithe ag `/new`; osclaíonn seala leantacha atá i dtaisce nó nasctha go sainráite leathanach cruinn an chomhrá
(`open-sse/executors/claude-web/session.ts:324`).

Is taisce cuimhneacháin í staid an chomhrá atá eochraithe de réir scóip chuntais SHA-256 agus tras-scríbhinn chanónach an ghlaoiteora. Téann iontrálacha in éag tar éis 30 nóiméad agus tá teorainn 5,000 iontráil leis an taisce
(`open-sse/executors/claude-web/session.ts:12`). Ní dhéantar an staid a thiomnú ach amháin tar éis don pharsálaí docht srutha `message_stop` a bhreathnú; caitheann atosuithe próisis i leataobh í. Má theipeann ar chuardach sa taisce, sraithítear iarratas ilteachtaireachta in aon leid athshlánaithe amháin seachas teachtaireachtaí níos luaithe a ligean ar lár go ciúin.

Úsáideann an logchaighdeán agus an crios ama an t-ord tosaíochta seo: luach `claude_web` an iarratais, luach an naisc, luach ag am rite, ansin `en-US` don logchaighdeán nó `UTC` don chrios ama
(`open-sse/executors/claude-web/session.ts:218`).

### Uirlisí agus pálóidí iarratais

Ní athraíonn iarratais dhíreacha ach uirlisí feidhme OpenAI atá bailí ó thaobh struchtúir de agus a sholáthraíonn an glaoiteoir. Níl aon liosta réamhshocraithe statach uirlisí déanta suas ann
(`open-sse/executors/claude-web/payload.ts:102`).

Ina ionad sin, gabhann iarratais bhrabhsálaí iarratas an chomhéadain úsáideora fhíordheimhnithe agus coinníonn siad a uirlisí cuntais, staideanna uirlisí agus stíleanna pearsantaithe. Sáraíonn réimsí ullmhaithe an chomhrá, na samhla, na réasúnaíochta, na leide agus UUID na teachtaireachta an t-iarratas gafa fós
(`open-sse/executors/claude-web/browserTransport.ts:175`). Déantar teimpléid bhrabhsálaí a scópáil de réir hais den chuntas, den eagraíocht, den fhianán, den logchaighdeán agus den chrios ama, agus téann siad in éag tar éis 30 nóiméad
(`open-sse/executors/claude-web/browserTransport.ts:11`,
`open-sse/executors/claude-web/browserTransport.ts:158`). Nuair nach mbíonn aon uirlisí ón nglaoiteoir ag iarratas díreach, is féidir leis an teimpléad scóipeáilte sin a athúsáid; tugtar tús áite d'uirlisí sainráite an ghlaoiteora
(`open-sse/executors/claude-web/browserTransport.ts:214`).

### Roghnú iompair

Is é `sendClaudeWebDirect()` an chonair réamhshocraithe, a ghlaonn ar `tlsFetchClaude()` leis an bpróifíl chumraithe Chrome 146 agus leis an bhfianán a soláthraíodh (`open-sse/services/claudeTlsClient.ts:23`). Ní sheolann sé réiteoir agus ní dhéanann sé fianán ionaid.

Socraigh `WEB_COOKIE_USE_BROWSER` mar `1`, `true`, nó `on` chun an cuibheoir brabhsálaí atá scópáilte don chuntas a dhéanamh mar an príomhiompar. Socraigh `OMNIROUTE_BROWSER_POOL` mar cheann de na luachanna céanna chun ligean do dhúshlán aitheanta Cloudflare 403 aistriú ón iompar díreach chuig an gcuibheoir brabhsálaí (`open-sse/executors/claude-web.ts:195`). Ní spreagann teipeanna HTTP eile an t-aistriú sin.

Coinníonn an cuibheoir brabhsálaí fianáin laistigh den chomhthéacs comhthiomsaithe Playwright céanna, úsáideann sé an eochair haiseáilte scópáilte a bhfuil cur síos uirthi thuas, agus seolann sé an comhlánú ón gcomhthéacs sin (`open-sse/executors/claude-web/browserTransport.ts:444`). Ní easpórtálann sé riamh fianán a réitigh an brabhsálaí chuig an gcliant díreach TLS. Éilíonn atrialacha brabhsálaí teimpléad UI nach bhfuil imithe in éag agus atá ceangailte leis an gcomhthéacs Playwright iarbhír céanna (`open-sse/executors/claude-web/browserTransport.ts:467`). Déantar freagraí brabhsálaí a léamh go hin incriminteach ar an leathanach fíordheimhnithe, urramaítear cealú iarratais, agus cealaítear an corp réamhtheachtach a luaithe a sháraíonn sé 16 MiB (`open-sse/executors/claude-web/browserTransport.ts:259`).

Tugann an seiceadóir teilgean iniúchta folaithe ar ais chuig logálaí comhroinnte na n-iarratas: fágtar eagraíocht, UUIDanna comhráite agus teachtaireachtaí, téacs leide, sainmhínithe uirlisí, fianáin, agus aitheantóirí gléis as an áireamh (`open-sse/executors/claude-web.ts:237`,
`open-sse/executors/claude-web.ts:252`). Tugann eisceachtaí iompair earráid ghinearálta cheangail ar ais freisin in ionad na teachtaireachta a caitheadh.

### Iompar SSE

Láimhseálann `createClaudeWebResponse()` frámaíocht LF nó CRLF agus réimsí il-líne `data:`. Mapálann sé deilteanna téacs chuig `content`, deilteanna smaointeoireachta chuig `reasoning_content`, agus teagmhais mheiteashonraí aitheanta chuig an eisínteacht freagartha `claude_web`. Teilgtear gach teagmhas meiteashonraí trína liosta ceadaithe réimsí féin (`open-sse/executors/claude-web/stream.ts:37`). Tugtar meiteashonraí an chomhrá, na máthairtheachtaireachta, theachtaireacht an chúntóra, agus na hoibríochta ar ais freisin i gceanntásca `X-OmniRoute-Claude-Web-*` (`open-sse/executors/claude-web/stream.ts:364`).

Teipeann an parsálaí go dúnta i gcás JSON míchumtha, teagmhas réamhtheachtach `error`, cineálacha teagmhais anaithnide, ord neamhbhailí, neamhréireanna bloc inneachair, nó EOF roimh `message_stop`. Astaíonn aschur sruthaithe smután críochnaithe amháin agus `[DONE]` amháin; úsáideann aschur maolánaithe an parsálaí céanna. Déileálann an parsálaí le `message_stop` mar chríochfort láithreach, cealaíonn sé sonraí réamhtheachtacha ina dhiaidh, agus iomadaíonn sé cealú iartheachtach chuig an léitheoir réamhtheachtach (`open-sse/executors/claude-web/stream.ts:461`,
`open-sse/executors/claude-web/stream.ts:563`). Tá teorainn 1 MiB ar línte SSE neamhchríochnaithe agus ar theagmhais charntha (`open-sse/executors/claude-web/stream.ts:17`,
`open-sse/executors/claude-web/stream.ts:62`).

### Socrú

1. Tosaigh OmniRoute le `npm run dev` nó le suiteáil tiomsaithe.
2. Oscail Deais → Soláthraithe → Cuir Soláthraí Leis.
3. Roghnaigh catagóir Web Cookie agus Claude Web.
4. Greamaigh an ceanntásc iomlán Cookie a cóipeáladh ó iarratas fíordheimhnithe `claude.ai`.
