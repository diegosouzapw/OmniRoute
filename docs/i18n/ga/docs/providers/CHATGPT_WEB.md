Déanann `chatgpt-web-codex` (ailias `cgpt-codex`) sealanna Codex Responses a nascadh trí
sheisiún fíordheimhnithe brabhsálaí ChatGPT. Tá sé neamhspleách ar an soláthraí coiteann
`chatgpt-web` atá scortha agus úsáideann sé an cur chun feidhme lena ngabhann fógra MIT faoi
`open-sse/vendor/codex-chatgpt-web/`, arna athnuachan trí thiomantas v4.0.7 réamhtheachtach
`b59d7dc51b84fb1f465ff1d00f5207f3b2b4a494`.

## Scor an tsoláthraí choitinn

Ní chuirtear iar-IDanna an tsoláthraí choitinn `chatgpt-web` agus `cgpt-web` ar fáil a thuilleadh toisc nárbh
fhéidir foinse a gcur chun feidhme réamheochrach/cruthúnais-oibre a dheimhniú. Teipeann go
dúnta ar iarratais shainráite ar cheachtar ID, lena n-áirítear IDanna samhla a bhfuil slais rompu agus ailiasanna marthanacha,
le HTTP `410` agus an cód **PROVIDER_RETIRED** sula ndéantar aon iarratas réamhtheachtach.

Cuireann an t-aistriú `168_retire_chatgpt_web.sql` leac thuama ar naisc soláthraí a mheaitseálann agus
neamhbhailíonn sé léasanna a seisiún gníomhach. Caomhnaíonn sé stair na nasc agus liostaí ceadaithe eochracha API;
ní chuireann sé rochtain ionaid le liosta ceadaithe. Ní mheaitseálann an scor seo soláthraí Codex ná
a naisc.

## Réamhriachtanais

- ceanntásc iomlán Cookie ó sheisiún ChatGPT a bhfuil síniú isteach déanta ann;
- Chrome nó Chromium chomh maith le seisiún grafach nó taispeáint Xvfb le haghaidh suiteálacha npm, systemd, agus PM2;
- leis an bpróifíl Docker `web`, an tseirbhís inmheánach Chromium ó
  `docker-compose.yml`;
- OpenAI `tunnel-client` v0.0.13 agus nascóir saincheaptha ChatGPT le haghaidh uirlisí áitiúla Codex.

Ní theastaíonn an tollán ach le haghaidh sealanna uirlise. Is féidir le gach bealach atá liostaithe, `pro` san áireamh, an
cumas céanna uirlise áitiúla atá ceangailte leis an seal a úsáid nuair atá an tollán agus an nascóir cumraithe.

## Socrú an deais

1. Oscail an soláthraí **ChatGPT Web (Codex)** agus cuir nasc leis.
2. Greamaigh ceanntásc iomlán ChatGPT Cookie, ID an tolláin, an eochair ama rite, agus ainm an nascóra
   shaincheaptha. Ní mór do shocruithe nua atá in ann uirlisí a úsáid nascóir nuachruthaithe a úsáid darb ainm go díreach
   `OmniRoute Codex v2`, le Authentication socraithe go None agus Permissions socraithe go Allow all
   actions.
3. Rith seiceáil an naisc. Osclaíonn OmniRoute Temporary Chat le tacaíocht brabhsálaí agus braitheann sé
   an bhfuil Sol agus Pro ar fáil don chuntas.
4. Sábháil an nasc. Cuireann OmniRoute an staid stórála fhíoraithe
   Playwright in ionad an fhianáin ghreamaithe agus stórálann sé í leis an eochair ama rite tríd an astarraingt
   dintiúr chriptithe.

Ní choinnítear an fianán amh tar éis sábháil rathúil. Nuair a théann an seisiún in éag, oscail
an nasc, greamaigh ceanntásc iomlán úr Cookie, agus rith an tseiceáil arís. Tuairiscíonn stádas an dochtúra
sa dialóg eagarthóireachta an brabhsálaí, an staid stórála, an síniú isteach, Temporary Chat, an tollán,
an nascóir, agus an turas iomlán uirlise ar leithligh.

> Ná tiomnaigh fíorfhianán, eochair ama rite, staid stórála ná comhartha cumais riamh. Ní mór
> luachanna tástála agus doiciméadachta a bheith ina sealbhóirí áite i gcónaí.

## Samhlacha agus teaglamaí

Is iad seo a leanas na bealaí seasta samhla:

- `chatgpt-web-codex/luna` — GPT-5.6 Luna, iarracht íseal
- `chatgpt-web-codex/think` — GPT-5.6 Luna, iarracht mheánach
- `chatgpt-web-codex/instant`
- `chatgpt-web-codex/medium`
- `chatgpt-web-codex/high`
- `chatgpt-web-codex/extra-high`
- `chatgpt-web-codex/pro`

Cuir ceann acu le teaglama mar a dhéanfá le haon samhail eile. Seolann aip Codex ainm an teaglama mar
`model` chuig gnáthchríochphointe Responses, `/v1/responses`; níl aon chríochphointe Codex
ná lasc mód ar leith ann.

Cuireann cuntais Free/Go na bealaí Luna ar fáil. Cuireann cuntais atá in ann Sol a úsáid na bealaí ó Instant go
High ar fáil, agus cuireann cuntais atá in ann Pro a úsáid Extra High agus Pro ar fáil chomh maith. Tá samhail innill agus
iarracht réasúnaíochta sheasta ag gach bealach; teipeann iarracht shainráite chontrártha Responses
go dúnta seachas an mód roghnaithe brabhsálaí a athrú go ciúin.

Ná hathainmnigh ná athúsáid nascóir `Codex Native` nó `OmniRoute Codex` níos sine. Déanann ChatGPT
conradh poiblí MCP a thaisceadh de réir aitheantas an nascóra, agus úsáideann an droichead athnuaite
conradh nua díreach comhartha sealanna. Diúltaíonn an t-am rite do na haitheantais oidhreachta sin agus éilíonn sé
nascóir nua `OmniRoute Codex v2`.

## Samhail slándála

- Éilíonn an chonair dhúchasach iarratas Responses, cliant Codex aitheanta, agus aitheantais
  snáithe agus seal a mheaitseálann.
- Tagann an spás oibre, an bosca gainimh, an polasaí ceadaithe, agus catalóg na n-uirlisí ó shliogán dúchasach Codex;
  ní údarás ina leith é téacs saorfhoirme an leid.
- Ní fhaigheann ChatGPT ach cumas gearrshaolach in aghaidh an tseala. Ní ghlacann bróicéir MCP ach leis na
  huirlisí a thairg Codex sa seal cruinn sin.
- Ní dhéanann uathdheimhniú **Ceadaigh uair amháin** ach an t-iarratas uirlise a chur ar ais chuig Codex. Is é Codex amháin
  a dhéanann cinneadh maidir le ceadú agus rith.
- Roimh an gcéad aschur, féadfaidh teaglaim filleadh ar sprioc chomhoiriúnach eile. Tar éis
  thús an aschuir, fanann an soláthraí, an tsamhail, an nasc, agus seal an bhrabhsálaí feistithe go dtí go
  gcríochnaíonn an seal.
- Ní bhíonn fianáin, eochracha am rite, staid stórála, ná comharthaí cumais le feiceáil i bhfreagraí
  soláthraithe ná i logaí iarratas.

## VPS gan taispeáint agus Docker

I gcás suiteálacha npm, systemd, agus PM2, braitheann OmniRoute gnáthchonairí Chrome agus Chromium.
Mar rogha eile, socraigh `CHATGPT_WEB_CODEX_CHROME_PATH`. Úsáideann seala am rite Chrome le comhéadan
d'aon ghnó toisc go ndiúltaíonn ChatGPT do chruth brabhsálaí atá fíorcheann‑gan‑chomhéadan. Dá bhrí sin, ní mór d'óstach gan taispeáint
OmniRoute a rith le taispeáint phríobháideach Xvfb; ní sholáthraíonn socrú chonair Chrome amháin taispeáint.

Tosaíonn próifíl Docker `web` `chatgpt-web-codex-browser` ar líonra inmheánach Compose.
Ritheann an taobhcharr Chrome le comhéadan laistigh de Xvfb, mar sin ní theastaíonn taispeáint fhisiciúil. Ní fhoilsítear a phort CDP
ar an óstach. Tá toirt phróifíle chosanta an bhrabhsálaí ar leithligh ó
thoirt sonraí OmniRoute, agus faigheann an brabhsálaí dóthain cuimhne chomhroinnte. Ní éisteann an seachfhreastalaí inmheánach CDP
ach ar phort `9223` laistigh de líonra Compose; fanann Chrome ceangailte leis an gcomhéadan lúb-ais sa
taobhcharr.

Cuireann léas maoirseora faoi `DATA_DIR` cosc ar iliomad próiseas OmniRoute úinéireacht a bheith acu ar
an tollán agus ar staid an bhróicéara chéanna. Tuairiscíonn an diagnóiseoir coinbhleacht.

## Athshlánú idirghníomhach

Níl aon fhuinneog infheicthe ag an óstach sa chonair uathoibrithe Docker, ach tá Chrome féin ag rith le comhéadan laistigh den
taispeáint phríobháideach Xvfb. Nuair a éilíonn ChatGPT síniú isteach nó dúshlán idirghníomhach, is féidir bonneagar VNC
reatha an bhrabhsálaí a úsáid le haghaidh athshlánaithe. Ní mór do chomhéadan úsáideora an bhrabhsálaí agus CDP fanacht inrochtana
thar lúb-ais, nasc bainistíochta fíordheimhnithe, nó tollán SSH amháin; fanann noVNC díchumasaithe
le linn gnáthoibríochta.

## Cúltaca WebSocket

Nuair a bhíonn ChatGPT Web (Codex) i dteaglaim, iarrann droichead WebSocket Responses an
cúltaca HTTP/SSE sula nascann sé leis an bhfoinse réamhtheachtach. Téann an t-aistriú ansin trí
`/v1/responses`.
