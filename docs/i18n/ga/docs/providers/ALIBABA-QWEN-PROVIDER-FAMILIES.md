Taifeadann an doiciméad seo an cinneadh cur chun feidhme maidir le
[Heisiúint #7854](https://github.com/diegosouzapw/OmniRoute/issues/7854). Léirítear na táirgí poiblí
mar cheithre theaghlach soláthraithe. Is sonraí ceangail é an réigiún, ní táirge ar leith.

## Cinneadh

| Teaghlach soláthraithe                           | ID OmniRoute            | Réigiún domhanda | Réigiún na Síne |
| ------------------------------------------------ | ----------------------- | ---------------- | --------------- |
| Alibaba Cloud Model Studio (íoc mar a úsáidtear) | `alibaba`               | Singeapór        | Béising         |
| Alibaba Cloud Token Plan                         | `bailian-coding-plan`   | Singeapór        | Béising         |
| Qwen Cloud (íoc mar a úsáidtear)                 | `qwen-cloud`            | Domhanda         | Béising         |
| Qwen Cloud Token Plan                            | `qwen-cloud-token-plan` | Singeapór        | Béising         |

Fanann an ID `alibaba-cn` atá ann cheana ina ailias comhoiriúnachta ag am rite le haghaidh ceangail
shábháilte, bealaí samhlacha, teaglamaí agus úsáid stairiúil. Déantar a chárta deais a chomhtháthú
in `alibaba`; ní gá an bunachar sonraí a athscríobh.

Úsáideann Qwen Cloud ar bhonn íoc-mar-a-úsáidtear agus Alibaba Cloud Model Studio na hóstach ama rite
atá comhoiriúnach le DashScope faoi láthair, ach fanann siad ina gcéannachtaí soláthraí ar leith toisc
go bhfaigheann úsáideoirí eochracha agus go mbainistíonn siad cuntais trí chomhéadain táirge éagsúla.
Úsáideann táirgí Alibaba agus Qwen Cloud Token Plan teaghlaigh críochphointí éagsúla, mar sin fanann
na ceithre tháirge ar fad mar IDanna soláthraí ar leith.

## Maitrís críochphointí

| Teaghlach soláthraithe  | `global-sg`                                                              | `china-beijing`                                                      | Formáid sreinge |
| ----------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------- | --------------- |
| `alibaba`               | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI          |
| `bailian-coding-plan`   | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/apps/anthropic/v1`  | `https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic/v1`  | Anthropic       |
| `qwen-cloud`            | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`                 | `https://dashscope.aliyuncs.com/compatible-mode/v1`                  | OpenAI          |
| `qwen-cloud-token-plan` | `https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` | `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | OpenAI          |

Ní mór don eochair API agus don chríochphointe a bheith bainteach leis an táirge agus leis an réigiún
céanna. Nuair a roghnaítear réigiún, athraítear an críochphointe réamhshocraithe a úsáidtear le haghaidh
bailíochtaithe agus gnáthiarratas.

## Conradh ceangail

Stórálann ceangail nua eochair chobhsaí an réigiúin in `providerSpecificData`:

```json
{
  "region": "global-sg"
}
```

Is iad `global-sg` agus `china-beijing` na luachanna ceadaithe. Díorthaítear an críochphointe go
lárnach ó ID an tsoláthraí agus ón réigiún. Fanann `providerSpecificData.baseUrl` neamh-réamhshocraithe
ina shárú sainráite oibreora agus tugtar tús áite dó, agus normalútear sean-URLanna réamhshocraithe
sábháilte ar ais chuig an maitrís réigiúnach.

Coinníonn sé seo scéimre an cheangail insínte: is féidir réigiún eile a chur leis an réiteoir gan
cárta soláthraí eile a chruthú ná IDanna soláthraí sábháilte a athrú.

## Comhoiriúnacht agus cur i bhfeidhm

1. Cuir an réiteoir críochphointe réigiúnach leis agus coinnigh na réamhshocruithe domhanda reatha.
2. Úsáid aimsiú beo réigiúnach DashScope `/models` le haghaidh `alibaba`, a ID comhoiriúnachta
   `alibaba-cn`, agus `qwen-cloud`. Cuirtear a gcuid freagraí trí scagaire amháin giniúna téacs ar
   dtús toisc go gcuireann an críochphointe ginearálta samhlacha íomhá, físe, fuaime, leabaithe agus
   samhlacha eile nach samhlacha comhrá iad ar ais freisin. Ansin cuireann `qwen-cloud` an liosta
   ceadaithe cothabháilte atá dearbhaithe ina chlárlann soláthraí i bhfeidhm. Coinníonn Alibaba Model
   Studio agus Qwen Cloud catalóga coimeádta ar leith cé go roinneann siad óstaigh am rite faoi láthair.
3. Cláraigh `qwen-cloud-token-plan` leis an liosta ceadaithe reatha de shamhlacha téacs don Token Plan.
4. Cuir roghnóir réigiúin clóscríofa le dialóga chun nasc a chur leis nó a chur in eagar.
5. Folaigh an cárta dúblach `alibaba-cn` agus cuir a naisc reatha san áireamh ar leathanach an
   tsoláthraí `alibaba`.
6. Coinnigh sáruithe saincheaptha críochphointe ar fáil d’imscaradh ardleibhéil agus d’imscaradh a
   bhaineann go sonrach le spás oibre.

Fanann samhlacha meán Token Plan lasmuigh den chatalóg chomhrá toisc go n-úsáideann siad críochphointí
tiomnaithe. Tá `wan2.7-image` agus `wan2.7-image-pro` cláraithe in
`open-sse/config/imageRegistry.ts`; tá `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, agus
`happyhorse-1.1-r2v` cláraithe in `open-sse/config/videoRegistry.ts`. Athúsáideann an dá chlárlann
aitheantas naisc `qwen-cloud-token-plan` agus a dhintiúir réigiúnsonracha.

Tá catalóga íomhá agus físe íoc-mar-a-úsáidtear ar leith ag Qwen Cloud rialta faoin aitheantas
`qwen-cloud`. Is iad a shamhlacha íomhá `wan2.7-image-pro`, `wan2.7-image`,
`qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0-2026-03-03`, agus
`z-image-turbo`. Is iad a shamhlacha físe `happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`,
`happyhorse-1.1-r2v`, `happyhorse-1.0-video-edit`, `wan2.7-t2v`, `wan2.7-i2v`,
`wan2.7-r2v-2026-06-12`, agus `wan2.7-videoedit`. Ní athúsáideann na samhlacha seo ach an nasc
rialta `qwen-cloud` agus críochphointe meán réigiúnach DashScope. Ní fhaigheann clárlanna Token Plan
agus íoc-mar-a-úsáidtear liostaí samhlacha a chéile le hoidhreacht agus ní chumascann siad iad.

Tá a liostaí ceadaithe meán féin ag an aitheantas `bailian-coding-plan` freisin:
`wan2.7-image`, `wan2.7-image-pro`, `qwen-image-2.0`, agus `qwen-image-2.0-pro` le haghaidh
giniúint íomhánna, chomh maith le
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, agus `happyhorse-1.1-r2v` le haghaidh
giniúint físeán. Ní úsáideann sé ach nasc Bailian Coding Plan agus críochphointe réigiúnach Coding Plan.
Ní fhaigheann a chlárlanna íomhá agus físe aon rud le hoidhreacht ó cheachtar soláthraí Qwen Cloud
agus ní chumascann siad leo.

Tá liostaí ceadaithe íomhá agus físe ar leith ag an aitheantas rialta `alibaba`. Is iad a shamhlacha
íomhá `qwen-image-3.0-pro`, `qwen-image-2.0-pro-2026-06-22`, `qwen-image-2.0`,
`z-image-turbo`, agus `wan2.6-t2i`. Is iad na samhlacha físe a cuireadh leis
`happyhorse-1.1-i2v`, `happyhorse-1.1-t2v`, `happyhorse-1.1-r2v`,
`happyhorse-1.0-video-edit`, `wan2.7-i2v-2026-04-25`, `wan2.6-i2v-flash`,
`wan2.7-t2v-2026-06-12`, `wan2.7-r2v-2026-06-12`, agus `wan2.7-videoedit`. Ní úsáideann na
samhlacha seo ach nasc Alibaba Model Studio agus an críochphointe meán réigiúnach roghnaithe aige;
ní chuirtear iad le clárlann ar bith de chuid Coding Plan ná Qwen Cloud.

Leanann catalóg chomhrá Qwen Cloud Token Plan liosta ceadaithe téacs an phlean Individual ina bhfuil
meaitseáil bheacht teaghrán:
`qwen3.8-max-preview`, `qwen3.7-max`, `qwen3.7-plus`, `qwen3.6-flash`, `glm-5.2`, agus
`deepseek-v4-pro`. Baineann iontrálacha Wan agus HappyHorse leis na APIanna ar leith chun
íomhánna/físeáin a ghiniúint.

Nochtann Alibaba Token Plan na sé ID reatha chéanna de shamhlacha giniúna téacs trína chríochphointe
atá comhoiriúnach le Anthropic. Stórálann a rogha Singeapór an eochair réigiúin reatha `global-sg`;
níl difríocht ach sa lipéad a fheiceann an t-úsáideoir i gcomparáid le teaghlaigh soláthraithe a
thugann Domhanda ar an réigiún.

Tá catalóg chomhrá rialta Qwen Cloud níos cúinge d’aon ghnó ná an freagra beo téacs iomlán. Tá a
liosta ceadaithe cothabháilte in `open-sse/config/providers/registry/qwen-cloud/index.ts`; ní
chuireann aimsiú beo ar ais ach IDanna atá i bhfreagra an tsoláthraí réamhtheachtaigh agus sa liosta
clárlainne sin araon.

Leanann Alibaba Model Studio an riail chéanna maidir le trasnú beo lena liosta ceadaithe a
chothaítear go neamhspleách in `open-sse/config/providers/registry/alibaba/index.ts`. Athúsáideann
an soláthraí comhoiriúnachta `alibaba-cn` an chatalóg sin agus aimsiú á réiteach aige i gcoinne
chríochphointe Bhéising.
