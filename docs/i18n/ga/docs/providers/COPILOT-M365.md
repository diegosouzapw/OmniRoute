Seolann `copilot-m365-web` (ailias `m365copilot`) iarratais chomhrá i bhformáid OpenAI trí sheisiún brabhsálaí fíordheimhnithe Microsoft 365 Copilot BizChat ag
`m365.cloud.microsoft/chat`. Comhtháthú neamhoifigiúil é seo.

> **An bhfuil tú nua d’fheidhmitheoirí Fianán Gréasáin?**
>
> Léigh **`docs/getting-started/WEB-COOKIE-GUIDE.md`** chun eolas a fháil ar an bpróiseas socraithe ginearálta, ar threoir fíordheimhnithe, ar theorainneacha agus ar fhabhtcheartú sula leanann tú an treoir seo a bhaineann go sonrach leis an soláthraí.
>
> **Tábhachtach:** Ní fianán é an dintiúr don soláthraí seo. Ná cóipeáil
> fianáin ó `m365.cloud.microsoft`. Is é atá sa dintiúr ná paraiméadar iarratais URL WebSocket
> agus mír chosáin, agus léitear an dá cheann ó chluaisín Líonra DevTools.

## Réamhriachtanais

- Cuntas Microsoft 365 a bhfuil rochtain aige ar BizChat ag `m365.cloud.microsoft/chat`
- Brabhsálaí bunaithe ar Chromium (Chrome, Edge) chun WebSocket a iniúchadh in DevTools
- Ceadúnas M365 Copilot (atá san áireamh le go leor pleananna Microsoft 365 Business/Enterprise)

## Gabháil dintiúir (modh WebSocket)

1. Sínigh isteach ag `https://m365.cloud.microsoft/chat` agus cuir tús le comhrá.
2. Oscail **DevTools → Líonra**.
3. Scag de réir **WS** (WebSocket).
4. Cliceáil ar an nasc WebSocket Chathub. Cuardaigh URL a thosaíonn le
   `wss://substrate.office.com/m365Copilot/Chathub/`.
5. Óna **URL Iarratais**, cóipeáil:
   - Luach pharaiméadar iarratais `access_token` (JWT gearrshaolach).
   - Mír chosáin Chathub i ndiaidh `/Chathub/` (m.sh. `<oid>@<tenant>`).

Tá an fhoirm seo a leanas ar an URL iomlán:

```
wss://substrate.office.com/m365Copilot/Chathub/<oid>@<tenant>?...&access_token=<jwt>
```

6. In OmniRoute, téigh chuig **Soláthraithe → Cuir Soláthraí Leis**, roghnaigh **Microsoft 365 Copilot
   (BizChat)**, agus greamaigh an dintiúr san fhormáid seo:

```
access_token=<jwt>; chathubPath=<oid>@<tenant>
```

7. Cliceáil **Tástáil an Nasc** agus **Sábháil**.

## Gabháil dintiúir (iompórtáil HAR)

In ionad luachanna a chóipeáil de láimh ón URL WebSocket, is féidir leat comhad HAR DevTools
a easpórtáil:

1. Oscail **DevTools → Líonra**.
2. Cuir tús le comhrá BizChat nó lean ar aghaidh leis (spreagann sé seo an nasc WebSocket).
3. Deaschliceáil sa phainéal Líonra agus roghnaigh **Sábháil gach rud mar HAR le hábhar**.
4. In OmniRoute, úsáid an cnaipe **Iompórtáil comhad .har** sa dialóg naisc soláthraí.

Scanann OmniRoute an HAR chun URL WebSocket Chathub a aimsiú, asbhaineann sé
`access_token` agus `chathubPath`, agus líonann sé réimsí an dintiúir go huathoibríoch. Díchódaíonn
an t-iompórtáil HAR dul in éag an JWT agus taispeánann sí an tréimhse saoil atá fágtha ag an chomhartha.

> **Ná cuir fíor-easpórtáil HAR, comhartha rochtana ná comhartha athnuachana faoi rialú leaganacha choíche.** Ní mór luachanna tástála agus
> doiciméadúcháin a bheith ina n-ionadchoinneálaithe i gcónaí.

## Saolré agus athnuachan an chomhartha

Tá `access_token` gearrshaolach (**~75 nóiméad** de ghnáth). Tar éis dó dul in éag, tuairiscíonn an soláthraí
earráid naisc agus ní mór duit an dintiúr a ghabháil arís.

### Athnuachan uathoibríoch le `refreshToken`

Chun nach mbeidh ort é a ghabháil arís de láimh, is féidir leat comhartha athnuachana Microsoft a stóráil i
**Ardsocruithe → providerSpecificData** an naisc:

| Réimse         | Cur síos                                                                     |
| -------------- | ---------------------------------------------------------------------------- |
| `refreshToken` | Comhartha athnuachana Microsoft OAuth do scóip `substrate.office.com/sydney` |
| `tier`         | `individual` (réamhshocrú), `edu`, nó `enterprise`                           |

Faigh an comhartha athnuachana ó shreabhadh cód gléis nó cód údaraithe Microsoft
atá scóipeáilte chuig `substrate.office.com/sydney`. Agus `refreshToken` socraithe, déanann OmniRoute
`access_token` a réamh-athnuachan roimh gach iarratas, mar sin ní gá duit é a
ghabháil arís tar éis gach dul in éag thart ar 75 nóiméad.

Mura bhfuil `refreshToken` socraithe, ní mór duit an dintiúr WebSocket a ghabháil arís de láimh
tar éis gach dul in éag.

### Roghnú sraithe

| Sraith       | Ailias          | Comhéadan                    |
| ------------ | --------------- | ---------------------------- |
| `individual` | _(réamhshocrú)_ | M365 Copilot do Thomhaltóirí |
| `edu`        | `included`      | M365 Copilot don Oideachas   |
| `enterprise` | `work`          | M365 Copilot don Obair       |

Socraigh an tsraith in **Ardsocruithe → providerSpecificData → tier**. Bíonn tionchar ag an tsraith ar
ródú BizChat agus ar rochtain ar shamhlacha.

## Samhail slándála

- **Comhtháthú neamhoifigiúil.** Déanann an soláthraí seo prótacal WebSocket
  BizChat a ais-innealtóireacht. D’fhéadfadh sé éirí as feidhm gan fógra nuair a athraíonn Microsoft an críochphointe.
- Léiríonn an bhratach `subscriptionRisk: true` go mbraitheann an comhtháthú ar
  chríochphointe nach bhfuil doiciméadaithe. D’fhéadfadh srianta cuntais a bheith i gceist, ach níl sé sin deimhnithe.
- Is JWT gearrshaolach é an comhartha rochtana. Caith leis mar fhocal faire: ná déan é a chur faoi rialú leaganacha,
  a logáil ná a chomhroinnt.
- Tugann an comhartha athnuachana rochtain fhadtéarmach ar chomhéadan BizChat. Stóráil é leis an
  gcúram céanna agus a thabharfá d’eochair API.

## Fabhtcheartú

### Teipeann ar an bhfíordheimhniú láithreach

- Deimhnigh gur chóipeáil tú ón **URL WebSocket**, agus ní ó iarratas XHR/Fetch. Tá an
  dintiúr i bparaiméadar iarratais `access_token` an naisc WebSocket Chathub
  — níl sé i gceanntásc `Authorization: Bearer`.
- Cinntigh go bhfuil an mhír iomlán `<oid>@<tenant>` ó chonair an URL san áireamh sa
  `chathubPath`.

### Téann an comhartha in éag tar éis ~75 nóiméad

Tá coinne leis seo. Gan `refreshToken`, bíonn an comhartha rochtana gearrshaolach. Déan ceann amháin díobh seo:

- Gabh an dintiúr arís ó DevTools, nó
- Cumraigh `refreshToken` sna hArdsocruithe le haghaidh athnuachan uathoibríoch.

### Éiríonn leis an Nasc Tástála ach tugann an comhrá 401 ar ais

D’fhéadfadh an comhartha a bheith imithe in éag idir an bailíochtú agus an chéad iarratas. Gabh
dintiúr úr arís.

### Ní bhíonn Copilot le feiceáil i liosta na soláthraithe

Cinntigh go bhfuil `copilot-m365-web` cumasaithe in **Deais → Soláthraithe**. D’fhéadfadh an soláthraí
a bheith folaithe de réir réamhshocraithe i roinnt sraitheanna.
