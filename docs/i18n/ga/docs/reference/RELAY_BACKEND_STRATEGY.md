## Achoimre

Tacaíonn OmniRoute anois le trí mhodh sealaíochta le haghaidh `/api/v1/relay/chat/completions`:

- `ts`: Úsáid an sealaí TypeScript laistigh den phróiseas.
- `bifrost`: Cuir iallach ar úsáid gheata Bifrost.
- `auto`: Tabhair tús áite do Bifrost nuair atá sé ar fáil, agus téigh ar ais chuig TypeScript má theipeann air.

Nuair atá ráta ard iarratas á láimhseáil agat (líon mór comharthaí in aghaidh an lae, tréchur beagnach seasmhach), is í an straitéis is fearr ná an chonair chúltaca a choinneáil sainráite agus tapa ionas nach gcuirfidh seachphróiseas neamhfhreagrúil bac ar an gconair the riamh.

## Iompar na modhanna

- `ts`
  - An chastacht oibríochtúil is ísle.
  - Ritheann an ródú agus an bailíochtú ar fad in Node.
  - Níl aon spleáchas ar sheachphróiseas ó thaobh infhaighteachta de.
- `bifrost`
  - Cuir gach iarratas tríd an ngeata seachphróisis.
  - Níl aon chúltaca uathoibríoch ann.
  - Níl sé úsáideach ach amháin nuair atá sláinte agus aga folaigh an tseachphróisis ráthaithe.
- `auto`
  - Úsáidtear an seachphróiseas nuair is féidir teacht air agus nuair atá sé cumasaithe.
  - Gníomhaíonn iarrachtaí teipthe ceanntásca cúltaca agus seolann siad an trácht ar ais chuig TS ionas go bhfanfaidh rath na n-iarratas faoi theorainn ama.
  - Is é seo an rogha is sábháilte don táirgeadh nuair is tábhachtaí an t-aga fónaimh ná ródú docht tríd an seachphróiseas amháin.

## 9router i gcomparáid le CLIPROXYAPI inniu

Is comhtháthuithe iad 9router agus CLIPROXYAPI araon a chuir conairí comhoiriúnachta ar fáil go stairiúil do sholáthraithe réamhtheachtacha.

- Is conair leabaithe é 9router le haghaidh ceolfhoirniú réamhtheachtach agus iompar comhoiriúnachta.
- Is droichead API seachfhreastalaí é CLIPROXYAPI le haghaidh tráchta de chineál CLI / SDK.
- Tá Bifrost á chobhsú mar an chonair sheachtrach nuair atá céim thiomnaithe de chineál seachphróisis agus seoladh áitiúil íseal-aga-folaigh ag teastáil.

Má tá 9router/CLIPROXYAPI á gcur i gcomparáid agat faoi láthair:

- Coinnigh síniú iarratas, seiceálacha liosta ceadaithe, agus geataí beartais DB sa chonair API roimh an aistriú.
- Má tá iompar docht seachphróisis agus éagsúlacht níos ísle in aghaidh an iarratais ag teastáil ó shreabhadh oibre, úsáid `OMNIROUTE_RELAY_BACKEND=bifrost`.
- Má tá teacht aniar an tseachphróisis agus díghrádú rianúil faoi dhálaí teagmhais ag teastáil, úsáid `OMNIROUTE_RELAY_BACKEND=auto`.

## Conradh theorainn an innill

Is é API sealaíochta OmniRoute teorainn chobhsaí an táirge, ní cur chun feidhme an deais. Féadfaidh deais Next.js seirbhísí áitiúla a shuiteáil, a chumrú agus a mhaoirsiú, ach ba cheart don ródú iarratas dul isteach tríd an API sealaíochta agus a bheith aistrithe taobh thiar den teorainn sin.

Roghanna fadtéarmacha don inneall:

- Coinnigh an sealaí TypeScript mar chonair beartais agus chúltaca laistigh den phróiseas. Fanann fíordheimhniú, liostaí ceadaithe, normalú iarratas, cuntasaíocht agus seiceálacha sábháilteachta anseo roimh aon aistriú chuig inneall.
- Úsáid Bifrost mar an seachphróiseas Leibhéal-1 ard-tréchuir is fearr nuair atá éagsúlacht ródaithe níos ísle, rothlú láraithe soláthraithe, nó scálú amach thar mhacasamhlacha iomadúla OmniRoute ag teastáil ón imscaradh.
- Coinnigh 9router agus CLIPROXYAPI mar sheirbhísí comhoiriúnachta leabaithe. Ritheann siad mar phróisis áitiúla faoi mhaoirseacht agus bíonn siad úsáideach nuair is é a n-iompar soláthraí/CLI an cuibheoir atá ag teastáil, ach níor cheart dóibh a bheith ina n-inneall ródaithe Leibhéal-1 réamhshocraithe.
- Ná lig don deais URLanna treallacha seirbhíse a chur isteach sa chonair the. Is ionchuir chumraíochta iad URLanna a sholáthraíonn an comhéadan úsáideora; ba cheart don chód ródaithe innill chláraithe a bhfuil a sláinte seiceáilte a réiteach ó shocruithe ar thaobh an fhreastalaí agus ó staid an mhaoirseora.
- Tabhair tús áite do HTTP lúb-aisiompaithe le haghaidh seirbhísí faoi mhaoirseacht inniu toisc go nochtann na próisis bhainistithe APIanna atá comhoiriúnach le HTTP cheana féin, gur féidir le garda na conaire iniúchadh a dhéanamh ar an teorainn, agus go mbíonn iompar teipe/cúltaca le feiceáil i logaí iarratas. Ní fiú iompar SDK nó soicéid a chur leis amach anseo ach amháin má laghdaíonn sé aga folaigh ródaithe p99 go hinbhraite gan aonrú ná séimeantaic chúltaca a lagú.

Dá bhrí sin, i gcás imscaradh an-ard-tréchuir, is é `auto` le Bifrost cumasaithe an freagra réamhshocraithe: úsáid seachphróiseas Go ar an gconair the agus an cúltaca TypeScript á chaomhnú ar mhaithe leis an ráta ratha. Ná húsáid `bifrost` ach amháin nuair is tábhachtaí iompar docht tríd an seachphróiseas amháin ná díghrádú rianúil.

## Treoir maidir le hard-tréchur

Le haghaidh RPM/RPS ard marthanach agus SLO ratha docht:

1. Úsáid `auto` le tréimhse shuaimhnithe phraiticiúil agus teiliméadracht teipe.
2. Coinnigh bailíochtú réamhtheachtach agus seiceálacha eochrach API ar theorainn na conaire TypeScript.
3. Cumasaigh ceanntásca/áiritheoirí sainráite ionas go bhfeicfidh do chóras foláirimh minicíocht agus cúiseanna an chúltaca.
4. Tiúin teorainneacha ama an tseachphróisis chun teip go tapa, seachas fanacht go deo.
5. Coinnigh uath-atosú na seirbhíse agus lúb na teiliméadrachta sláinte slán ionas gur eisceacht amach is amach é an cúltaca.

## Bunlíne mholta

- `OMNIROUTE_RELAY_BACKEND=auto`
- `BIFROST_ENABLED=1`
- Coinnigh eochracha API, an liosta ceadaithe, an sláintitheoir agus seiceálacha teorannaithe ráta cumasaithe sna láimhseálaithe conaire (ritheann siad i gcónaí roimh chur ar aghaidh iartheachtach).
- Easpórtáil méadrachtaí cúltaca ó do sheachfhreastalaí droim ar ais agus ó logaí iarratas ionas go mbeidh bristí an tseachphróisis infheicthe laistigh d’aon nóiméad amháin.
