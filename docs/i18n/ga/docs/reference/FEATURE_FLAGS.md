> Scoránaigh ama rite a athraíonn iompar OmniRoute **gan ath-imscaradh**.
> Sainmhínítear gach bratach atá liostaithe anseo in
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — an t-aon fhoinse fhírinne. Léann an deais agus an REST API araon ón
> gcomhad sin, mar sin gintear an tábla thíos chun é a mheaitseáil 1:1.

---

## Cad is Bratacha Gné ann

Is éard is bratach gné ann ná scorán ainmnithe (booleach nó enum) ar féidir a luach a athrú ag
am rite agus a bhuanú sa bhunachar sonraí, gan gá le hath-imscaradh próisis. Déantar cur síos ar gach
bratach le `FeatureFlagDefinition` ina bhfuil `key`, `label`,
`description`, `category`, `defaultValue`, `type`, agus leid `requiresRestart`.

### Ord Réitigh

Réitíonn
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) **luach éifeachtach** brataí de réir na
tosaíochta seo (is ag an gceann is airde atá an bua):

1. **Sárú DB** — luach atá stóráilte sa tábla `key_value` faoin
   ainmspás `feature_flags` (socraithe tríd an deais nó an REST API).
2. **Athróg timpeallachta** — `process.env[<KEY>]`, má tá sí socraithe agus neamhfholamh.
3. **Réamhshocrú sainmhínithe** — an `defaultValue` ó `featureFlagDefinitions.ts`.

Meastar bratach bhooleach a bheith **cumasaithe** nuair is é `"true"`,
`"1"`, nó `"yes"` a luach éifeachtach (féach `isFeatureFlagEnabled()`).

> [!NOTE]
> Tá athróg timpeallachta mheaitseála den **ainm céanna** ag formhór na mbratach freisin,
> mar atá doiciméadaithe in [`ENVIRONMENT.md`](./ENVIRONMENT.md). Bíonn tosaíocht ag sárú DB na brataí
> ar an athróg timpeallachta sin. Déantar bratach a bhfuil
> `requiresRestart: true` aici a bhuanú láithreach ach ní athléitear í ach amháin ag am
> tosaithe an phróisis — má scorthaítear í, taispeántar meirge **"Atosaigh an Freastalaí"** sa deais.

## Lasca a Athrú

### Painéal

Téigh go dtí **Painéal → Socruithe → Lasca Gnéithe**
(`/dashboard/settings/feature-flags`). Tacaíonn an greille
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
leis an méid seo a leanas:

- **Cuardach** de réir eochrach nó tuairisce, agus **scagadh** de réir catagóire (chomh maith le radharc sintéiseach **Éilíonn Atosaigh**).
- **Lasca** le haghaidh lasca Boole agus **roghchlár anuas** le haghaidh lasca enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Suaitheantas foinse** in aghaidh an lasca — `DB`, `ENV`, nó `DEF` — ag taispeáint cárb as a tháinig an luach éifeachtach.
- Cnaipe **Athshocraigh** (nach dtaispeántar ach amháin le haghaidh lasca a thagann ó `DB`) chun an sárú a scaoileadh, agus cnaipe **Athshocraigh Gach Sárú** ag an mbun.
- Meirge **Atosaigh Freastalaí** nuair a athraítear lasc `requiresRestart`.

### API REST

Téann gach oibríocht trí bhealach amháin:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Éilíonn gach modh seisiún painéil fíordheimhnithe (`401` murach sin).

#### `GET /api/settings/feature-flags`

Filleann sé gach lasc lena luach éifeachtach, foinse, agus achoimre.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 77 flags
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Socraigh nó bain sárú amháin. Comhlacht: `{ key: string; value?: string }`.
Má fágann tú `value` ar lár, baintear an sárú (ag athchóiriú env / réamhshocraithe).

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Léiríonn an freagra an `effectiveValue`/`source` nua, an `previousValue`/
`previousSource` roimhe seo, agus `requiresRestart`. Diúltaítear d'eochracha anaithnid agus do luachanna enum atá lasmuigh den raon le `400`.

#### `DELETE /api/settings/feature-flags`

Glanann sé **gach** sárú DB ag an am céanna, ag athchóiriú gach lasc chuig a luach env / réamhshocraithe. Filleann sé `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Ní thagann lasca le `requiresRestart: true` i bhfeidhm ach amháin tar éis athlódáil próisis. Glaonn sreabhadh atosaithe an phainéil `POST /api/restart` agus ansin déanann sé vótaíocht ar `GET /api/health/ping` go dtí go mbíonn an freastalaí ar ais ag feidhmiú.

## Cúltaca Éigeandála don Bhuiséad

Rialaíonn `OMNIROUTE_EMERGENCY_FALLBACK` (catagóir `runtime`, réamhshocrú `true`)
an chonair chúltaca éigeandála saor in aisce in
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Nuair atá sé cumasaithe, seoltar iarratais a ídíonn a mbuiséad chuig soláthraí/samhail
chúltaca saor in aisce seachas teip iomlán a dhéanamh. Socraigh go `false` (nó `0`) é — trí
scorán na deaise, forshárú DB, nó an athróg timpeallachta
`OMNIROUTE_EMERGENCY_FALLBACK` — chun an t-iompar a dhíchumasú agus ligean d’iarratais a bhfuil a mbuiséad ídithe acu
teip. (Cuireadh ar fáil mar scorán deaise in PRanna #3741 / #3752.)
