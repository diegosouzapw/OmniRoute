Soláthraithe iomlána: **358**. Féach miondealú na gcatagóirí thíos.

## Catagóirí

- **Saor in aisce** — sraith saor in aisce le heochair API (cumraithe tríd an deais)
- **Gan fíordheimhniú** — críochphointí poiblí nach dteastaíonn eochair ná síniú isteach uathu ar chor ar bith
- **OAuth** — sreabhadh sínithe isteach arna láimhseáil ag OmniRoute, gan aon eochair API de dhíth
- **Fianán gréasáin** — fillteán ar aip gréasáin an tsoláthraí trí fhíordheimhniú fianáin
- **Eochair API** — soláthraí íoctha arna chumrú trí eochair API (d’fhéadfadh creidmheasanna saor in aisce a bheith i gceist)
- **Áitiúil** — ritear ar ríomhaire an úsáideora é (Ollama, LM Studio, vLLM, srl.)
- **Cuardach** — soláthraithe cuardaigh gréasáin
- **Fuaim** — soláthraithe fuaime amháin (TTS/STT)
- **Seachfhreastalaí réamhtheachtach** — soláthraithe a dhéanann seachfhreastal ar sholáthraithe eile
- **Gníomhaire néil** — gníomhairí códaithe fadreatha (Codex Cloud, Devin, Jules)
- **Córas** — soláthraithe inmheánacha OmniRoute (aischúrsáil, srl.)

Clibeanna breise: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Glaoch uirlisí` (nuair a thaispeántar é): `native` — fíor-API glaoite feidhmeanna; `emulated` — déantar aithris leid-bhunaithe ar an eagar `tools` trí `webTools.ts` (bloic `<tool>{...}</tool>` parsáilte le sloinn ionadaíochta); `none` — fágtar `tools` ar lár go ciúin faoi láthair. Féach #7286.

Úsáid an deais ag `/dashboard/providers` chun gach soláthraí a chumasú, a chumrú agus a thástáil.
