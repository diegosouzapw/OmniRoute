Stiskanje Caveman lahko poleg vgrajenih pravil za angleščino naloži tudi jezikovno specifične pakete pravil.
Tako jedro mehanizma ostane stabilno, medtem ko se lahko paketi za portugalščino, španščino, nemščino, francoščino, italijanščino, japonščino in
prihodnje jezike razvijajo neodvisno.

## Lokacija

Jezikovni paketi so v:

```txt
open-sse/services/compression/rules/<language>/
```

Trenutno vključeni paketi (preverjeno glede na vsebino imenika `rules/`):

| Jezik                     | Imenik         | Prisotne kategorije pravil                          |
| ------------------------- | -------------- | --------------------------------------------------- |
| Angleščina                | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Španščina                 | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugalščina (Brazilija) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonezijščina            | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italijanščina             | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Nemščina                  | `rules/de/`    | `context`, `filler`, `structural`                   |
| Francoščina               | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japonščina                | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Opomba o enakovrednosti:** Paketi `en`, `es`, `pt-BR`, `id` in `it` vsebujejo vseh 5 kategorij; paketi `de`, `fr` in `ja` pa vsebujejo 3 kategorije. Pri manjkajočih kategorijah `dedup` in `ultra` se sistem brez opozorila vrne na vgrajena angleška pravila. Prispevki za dodajanje datotek `dedup.json` in `ultra.json` v manjše pakete so dobrodošli.
>
> Paket `pt-BR` temelji na sistemu **[Troglodita](https://github.com/leninejunior/troglodita)** avtorja Lenina Júniorja — sistemu stiskanja, ki je bil od začetka zasnovan za brazilsko portugalsko slovnico (zmanjševanje pleonazmov, odstranjevanje mašil v PT-BR, tehnične okrajšave za brazilsko razvijalsko skupnost).
>
> Kanonični seznam kategorij in shema za posamezno kategorijo sta v datoteki [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema, osnutek 2020-12).

## Zaznavanje jezika

`languageDetector.ts` uporablja preproste hevristike za ugotavljanje jezika iz besedila poziva. Nastavljeni privzeti jezik se še vedno upošteva, zaznavanje pa je mogoče onemogočiti v konfiguraciji, kadar je potreben natančen
nadzor.

Rezultat zaznavanja se uporablja samo za izbiro paketov pravil. Ne spreminja usmerjanja ponudnikov, izbire območnih nastavitev
ali jezika uporabniškega vmesnika.

## Struktura konfiguracije

Nastavitve stiskanja lahko vključujejo:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` nadzoruje privzete nastavitve nadzorne plošče in predogleda. `cavemanConfig` je izvajalna konfiguracija mehanizma,
ki se uporablja, ko Caveman stiska besedilo sporočila.

## Dodajanje jezikovnega paketa

1. Ustvarite `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Uporabite obliko pravil Caveman iz `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Zamenjave naj bodo konservativne in naj ne spreminjajo kode, identifikatorjev, URL-jev ali JSON-a.
4. Dodajte ali posodobite teste za izbiro jezika in delovanje zamenjav.
5. Če je jezik prikazan v izbirnikih uporabniškega vmesnika, dodajte nove oznake nadzorne plošče/i18n.

## API

Pakete, ki so na voljo, lahko poizvedujete z:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Končna točka za predogled sprejema preglasitve jezikovne konfiguracije:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Vseh 6 jezikovnih paketov je v različici v3.8.0 prejelo določilo `SHARED_BOUNDARIES`, ki se uporabi pri vsaki
intenzivnosti Caveman (LITE, FULL, ULTRA). Mehanizmu naroča, naj te vzorce ohrani dobesedno,
ne glede na odstranjevanje okoliških mašil:

| Vrsta vzorca                         | Primer                                 |
| ------------------------------------ | -------------------------------------- |
| Ograjeni bloki kode                  | ` ```python\n...\n``` `                |
| Vrstična koda                        | `` `my_var` ``                         |
| URL-ji                               | `https://example.com/path`             |
| Poti datotek (absolutne + relativne) | `/etc/hosts`, `./src/index.ts`         |
| Glave napak                          | `Error:`, `TypeError:`, `SyntaxError:` |
| Vrstice sledenja skladu              | `  at functionName (file.ts:12:3)`     |

Ti vzorci so vključeni v `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (prej `[]`). Konstanta
se nahaja v `open-sse/services/compression/types.ts`.

### Zakaj je to pomembno

Brez `SHARED_BOUNDARIES` bi lahko agresivni načini Caveman odstranili vsebino, ki je bila videti kot ponavljajoče se
besedilo, vendar je bila v resnici izsek kode, pot datoteke ali sklad napake. `SHARED_BOUNDARIES` deluje kot
od jezika neodvisna varnostna mreža, ki se uporabi, preden se izvedejo pravila za odstranjevanje mašil.

### Prilagajanje `preservePatterns`

Dodatne vzorce je mogoče med izvajanjem dodati prek nastavitev stiskanja:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Vzorci po meri razširijo (ne nadomestijo) 6 privzetih vzorcev.

## Operativne opombe

- Vgrajena angleška pravila ostanejo nadomestna možnost, kadar jezikovni paket manjka.
- Neveljavni vgrajeni paketi JSON ne prestanejo preverjanja veljavnosti, zato se kakovost izdajnih artefaktov ne poslabša neopazno.
- Paketi pravil vsebujejo samo podatke ter ne smejo uvažati kode ali izvajati poljubne logike.
- Analitična plast stiskanja beleži izbrani način in mehanizem, ne pa celotnega besedila poziva.
