OmniRoute vključuje skrbno izbran nabor brezplačnih posredniških strežnikov v tabeli `free_proxies`,
sinhroniziranih z zunanjimi ponudniki (1proxy, proxifly, iplocate, webshare).
Nadzorna plošča jih prikazuje pod **Nastavitve → Brezplačni posredniški strežniki**. Ta dokument
opisuje strežniško filtriranje, razvrščanje, štetje in poročanje o napakah pri sinhronizaciji,
ki jih ponuja pot za prikaz seznama.

## Pot za prikaz seznama — `GET /api/settings/free-proxies`

Vrne filtriran, razvrščen in ostranjen izsek skupaj s skupnim številom rezultatov. Filtriranje in
štetje se izvajata v SQL-u, zato lahko uporabniški vmesnik prikaže dejansko skupno število (npr. `Skupaj: 0`),
ne da bi moral vse vrstice naložiti v pomnilnik.

### Parametri poizvedbe

| Parameter         | Vrsta                              | Privzeto  | Pomen                                                                                                                           |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | niz                                | `""`      | `LIKE`, občutljiv na velikost črk, v stolpcu gostitelja (in vira).                                                              |
| `protocol`        | niz                                | `""`      | Filter `type`: `http` / `https` / `socks4` / `socks5`. Prazno = vsi.                                                            |
| `country`         | niz                                | `""`      | Filter `countryCode` (ISO-2). Prazno = vse.                                                                                     |
| `minQuality`      | število                            | `0`       | Samo vrstice, pri katerih velja `qualityScore >= minQuality`. `0` = brez spodnje meje.                                          |
| `disabledSources` | niz                                | `""`      | Z vejicami ločeni ID-ji virov, ki naj bodo izključeni (npr. `proxifly,webshare`).                                               |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = ocena padajoče; `latency` = zakasnitev naraščajoče (ničelne vrednosti zadnje); `recent` = `lastValidated` padajoče. |
| `offset`          | število                            | `0`       | Začetek ostranjevanja.                                                                                                          |
| `limit`           | število                            | `50`      | Velikost strani (omejena na strežniški strani).                                                                                 |

### Odgovor

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 od nadrejenega strežnika"],
    "webshare": ["časovna omejitev omrežja"]
  }
}
```

`total` predstavlja skupno število filtriranih rezultatov **pred** ostranjevanjem, zato lahko uporabniški vmesnik neodvisno prikaže
`Skupaj: N` in `hasMore`. `syncErrors` uporablja ID vira kot ključ in
se izpolni samo za vire, katerih zadnja sinhronizacija ni uspela — rezultat `Skupaj: 0`
nikoli ni brez pojasnila.

## Dodajanje v nabor — `POST /api/settings/free-proxies/[id]/add-to-pool`

Brezplačni posredniški strežnik poviša v upravljani nabor `proxy_registry`. Najprej preveri
nadrejeni strežnik; ob uspehu vrne ID novega posredniškega strežnika v naboru in izmerjeno zakasnitev.

## Sinhronizacija — `POST /api/settings/free-proxies/sync`

Znova pridobi podatke iz vseh omogočenih virov (ali podmnožice v `{ "sources": [...] }`). Vsak
vir se sinhronizira neodvisno; neuspešen vir se zabeleži v `syncErrors`, drugi pa
se kljub temu dokončajo, zato delne sinhronizacije nikoli ne izbrišejo predhodno veljavnih podatkov.

## Statistika — `GET /api/settings/free-proxies/stats`

Vrne agregirane vrednosti `total / inPool / avgQuality / bySource / lastSyncAt`
brez podatkov vrstic — uporablja se za gradnike v glavi nadzorne plošče.
