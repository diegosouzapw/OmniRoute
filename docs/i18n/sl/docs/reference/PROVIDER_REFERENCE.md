## Kategorije

- **Free** — brezplačna raven s ključem API (nastavljena prek nadzorne plošče)
- **No-auth** — javne končne točke, ki ne zahtevajo ključa ali prijave
- **OAuth** — postopek prijave upravlja OmniRoute, ključ API ni potreben
- **Web cookie** — ovije ponudnikovo spletno aplikacijo z uporabo preverjanja pristnosti prek piškotkov
- **API key** — plačljivi ponudnik, nastavljen s ključem API (morda so na voljo brezplačni dobroimetji)
- **Local** — izvaja se v uporabnikovem računalniku (Ollama, LM Studio, vLLM itd.)
- **Search** — ponudniki spletnega iskanja
- **Audio** — ponudniki samo za zvok (TTS/STT)
- **Upstream proxy** — ponudniki, ki posredujejo zahteve drugim ponudnikom
- **Cloud agent** — dolgotrajno delujoči agenti za programiranje (Codex Cloud, Devin, Jules)
- **System** — interni ponudniki OmniRoute (loopback itd.)

Dodatne oznake: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (kjer je prikazano): `native` — pravi API za klicanje funkcij; `emulated` — polje `tools` se posnema prek poziva z uporabo `webTools.ts` (bloki `<tool>{...}</tool>`, razčlenjeni z regularnimi izrazi); `none` — polje `tools` se trenutno tiho zavrže. Glejte #7286.

Za omogočanje, nastavljanje in preizkušanje posameznih ponudnikov uporabite nadzorno ploščo na `/dashboard/providers`.
