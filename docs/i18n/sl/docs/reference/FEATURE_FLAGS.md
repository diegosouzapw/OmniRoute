> Stikala med izvajanjem, ki spreminjajo vedenje sistema OmniRoute **brez ponovne uvedbe**.
> Vsaka tukaj navedena zastavica je opredeljena v datoteki
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — edinem viru resnice. Nadzorna plošča in REST API podatke bereta iz
> te datoteke, zato je spodnja tabela ustvarjena tako, da se z njo ujema v razmerju 1 : 1.

---

## Kaj so funkcijske zastavice

Funkcijska zastavica je poimenovano stikalo (logična vrednost ali naštevanje), katerega vrednost je mogoče spremeniti med
izvajanjem in trajno shraniti v podatkovni zbirki, ne da bi bila potrebna ponovna uvedba procesa. Vsaka
zastavica je opisana z objektom `FeatureFlagDefinition`, ki vsebuje `key`, `label`,
`description`, `category`, `defaultValue`, `type` in namig `requiresRestart`.

### Vrstni red razreševanja

**Dejanska vrednost** zastavice se razreši s funkcijo
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) po naslednjem
prednostnem vrstnem redu (višja prednost prevlada):

1. **Preglasitev v podatkovni zbirki** — vrednost, shranjena v tabeli `key_value` v imenskem prostoru
   `feature_flags` (nastavljena prek nadzorne plošče ali REST API-ja).
2. **Okoljska spremenljivka** — `process.env[<KEY>]`, če je nastavljena in ni prazna.
3. **Privzeta vrednost definicije** — `defaultValue` iz datoteke `featureFlagDefinitions.ts`.

Logična zastavica se šteje za **omogočeno**, kadar je njena dejanska vrednost `"true"`,
`"1"` ali `"yes"` (glejte `isFeatureFlagEnabled()`).

> [!NOTE]
> Večina zastavic ima tudi ustrezno okoljsko spremenljivko z **enakim imenom**,
> dokumentirano v datoteki [`ENVIRONMENT.md`](./ENVIRONMENT.md). Preglasitev zastavice v podatkovni zbirki
> ima prednost pred to okoljsko spremenljivko. Zastavica z
> `requiresRestart: true` se takoj trajno shrani, vendar se znova prebere šele ob
> zagonu procesa — njen preklop na nadzorni plošči prikaže pasico **»Ponovno zaženi strežnik«**.

72 zastavic v 6 kategorijah. **Privzeto** je privzeta vrednost definicije — vrednost,
ki se uporabi, kadar ni prisotna niti preglasitev v podatkovni zbirki niti okoljska spremenljivka.

## Preklapljanje zastavic

### Nadzorna plošča

Pomaknite se na **Nadzorna plošča → Nastavitve → Zastavice funkcij**
(`/dashboard/settings/feature-flags`). Mreža
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
podpira:

- **Iskanje** po ključu ali opisu in **filtriranje** po kategoriji (vključno s sintetičnim
  pogledom **Zahteva ponovni zagon**).
- **Preklopno stikalo** za logične zastavice in **spustni seznam** za naštevne zastavice
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Oznako vira** za vsako zastavico — `DB`, `ENV` ali `DEF` — ki prikazuje, od kod
  izvira dejanska vrednost.
- Gumb **Ponastavi** (prikazan samo za zastavice z virom `DB`) za odstranitev preglasitve
  in gumb **Ponastavi vse preglasitve** na dnu.
- Pasico **Ponovno zaženi strežnik**, ko se spremeni zastavica `requiresRestart`.

### REST API

Vse operacije potekajo prek ene same poti:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Vsaka metoda zahteva overjeno sejo nadzorne plošče (sicer vrne `401`).

#### `GET /api/settings/feature-flags`

Vrne vse zastavice z njihovo dejansko vrednostjo, virom in povzetkom.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... vseh 72 zastavic
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Nastavi ali odstrani posamezno preglasitev. Telo: `{ key: string; value?: string }`.
Če izpustite `value`, se preglasitev odstrani (s čimer se obnovi vrednost iz okolja / privzeta vrednost).

```bash
# Nastavi preglasitev v DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Odstrani preglasitev (brez "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Odgovor vrne novi vrednosti `effectiveValue`/`source`, prejšnji vrednosti `previousValue`/
`previousSource` in `requiresRestart`. Neznani ključi in naštevne vrednosti zunaj dovoljenega
obsega so zavrnjeni s kodo `400`.

#### `DELETE /api/settings/feature-flags`

Hkrati odstrani **vse** preglasitve v DB in za vsako zastavico obnovi vrednost iz okolja /
privzeto vrednost. Vrne `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Zastavice z `requiresRestart: true` začnejo veljati šele po ponovnem nalaganju procesa.
> Potek ponovnega zagona na nadzorni plošči pokliče `POST /api/restart`, nato pa preverja
> `GET /api/health/ping`, dokler strežnik ni znova na voljo.

## Rezervni način ob prekoračitvi proračuna

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, privzeto `true`) nadzoruje
rezervno brezplačno pot za nujne primere v
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Ko je možnost omogočena, se zahteve, ki izčrpajo svoj proračun, namesto takojšnje zavrnitve
preusmerijo k brezplačnemu rezervnemu ponudniku/modelu. Nastavite jo na `false` (ali `0`) —
prek preklopnega stikala na nadzorni plošči, preglasitve v DB ali okoljske spremenljivke
`OMNIROUTE_EMERGENCY_FALLBACK` — da onemogočite to vedenje in dovolite, da zahteve z
izčrpanim proračunom ne uspejo. (Na nadzorni plošči je prikazano kot preklopno stikalo
v PR-jih #3741 / #3752.)
