`@omniroute/opencode-plugin-v2` doda vaš celoten katalog OmniRoute — modele, kombinacije in
samodejne kombinacije — v izbirnik modelov OpenCode v2, skupaj s prikaznimi imeni, cenami in
omejitvami brezplačne ravni.

Gre za ločen paket od `@omniroute/opencode-plugin`, ker OpenCode v1 in v2 nalagata
vtičnike prek različnih pogodb. Izberite tistega, ki ustreza vaši glavni različici OpenCode; med
njima ni nič skupnega, zato nadgradnja enega nikoli ne zahteva nadgradnje drugega.

## Zahteve

- OpenCode v2.
- Dosegljiv prehod OmniRoute (privzeto `http://localhost:20128`).
- Node.js 22 ali 24.

## Namestitev

Dodajte vtičnik v `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modeli se nato prikažejo kot `omniroute/<provider>/<model>`; `providerId` določa to predpono in
ID integracije, pod katerim OpenCode shrani poverilnico.

## Poverilnice

Vtičnik išče ključ prehoda na treh mestih, in sicer v naslednjem vrstnem redu:

1. **Poverilnica, ki ste jo povezali v OpenCode.** Vtičnik registrira integracijo, zato lahko
   OpenCode shrani ključ prek lastnega postopka preverjanja pristnosti. V `opencode.json` se ne
   zapiše nič — priporočamo ta način.
2. `apiKey` v možnostih vtičnika za preglasitev na ravni projekta. S tem se ključ shrani v
   datoteko, ki jo morda vključujete v repozitorij.
3. `OMNIROUTE_API_KEY` v okolju.

Če ni nastavljen nobeden od teh treh virov, je katalog prazen, vtičnik pa to enkrat sporoči ob
zagonu, namesto da bi prikazal neopazno prazen izbirnik.

### Žeton za upravljanje je drug ključ

Kombinacije, stanje ponudnikov in obogatitev (prikazna imena, cene, omejitve brezplačne ravni)
prihajajo iz končnih točk `/api/*` prehoda, ki jih večina uvedb zaščiti z **upravljavskim**
žetonom namesto s ključem za izvajanje sklepanja:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<upravljavski žeton za branje>"
}
```

Če `managementReadToken` ni nastavljen, se uporabi `apiKey`. Ko prehod zavrne to nadomestno
možnost, se katalog še vedno objavi, vendar s surovimi ID-ji modelov namesto prikaznih imen,
brez odstranjevanja podvojenih kanoničnih vzdevkov, brez cen in brez kombinacij. Vtičnik v tem
primeru enkrat opozori za vsako končno točko ter navede končno točko in izgubljene podatke —
zato okrnjen izbirnik nikoli ni skrivnost.

## Možnosti

| Ključ                            | Privzeto                                       | Opombe                                                                                                                 |
| -------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                  | ID ponudnika, ID integracije in predpona, pod katero se prikažejo modeli                                               |
| `baseURL`                        | obvezno                                        | Koren prehoda, samo `http(s)`; pripona `/v1` se doda, kjer je potrebna                                                 |
| `apiKey`                         | povezana poverilnica, nato `OMNIROUTE_API_KEY` | Ključ za klepet za `/v1/*`                                                                                             |
| `managementReadToken`            | uporabi `apiKey`, če ni nastavljen             | Ključ za `/api/*` — običajno **ni** isti                                                                               |
| `displayName`                    | `"OmniRoute"`                                  | Ime ponudnika v izbirniku                                                                                              |
| `timeoutMs`                      | `10000`                                        | Časovna omejitev pridobivanja za posamezno končno točko (samodejne kombinacije uporabljajo 5 s)                        |
| `modelCacheTtlMs`                | `300000`                                       | TTL predpomnilnika kataloga; posnetek na disku pospeši hladne zagone                                                   |
| `timeouts`                       | uporabi `timeoutMs`, če ni nastavljeno         | Časovne omejitve po končnih točkah v ms: `models`, `combos`, `autoCombos`, `enrichment`                                |
| `enrichment`                     | `true`                                         | Pridobi imena, cene in omejitve brezplačne ravni                                                                       |
| `providerTag`                    | `true`                                         | Prikaznemu imenu doda predpono ponudnika višje ravni, h kateremu je model usmerjen                                     |
| `usableOnly`                     | `false`                                        | Ohrani samo ponudnike, za katere prehod poroča, da so konfigurirani                                                    |
| `visibleModels` / `hiddenModels` | `[]`                                           | Seznami dovoljenih modelov z natančnim ujemanjem ali ujemanjem pripone; prepoved ima prednost                          |
| `geminiSanitization`             | `true`                                         | Iz shem orodij odstrani ključne besede JSON Schema, ki jih Gemini zavrača (orodja `$ref` se posredujejo nespremenjena) |
| `apiFormat.allowAnthropic`       | `false`                                        | ID-je s seznama dovoljenih usmeri prek bloka API-ja Anthropic                                                          |
| `apiFormat.anthropicModels`      | `[]`                                           | Celotni ID-ji modelov, usmerjeni v Anthropic                                                                           |
| `logLevel` / `startupDebug`      | `warn` / `false`                               | Podrobnost beleženja                                                                                                   |

## Kako katalog ostaja posodobljen

Katalog se pridobi šele po potrebi in se predpomni za `modelCacheTtlMs`, posnetek na disku pa zagotavlja
razpoložljivost zadnjega znanega kataloga, kadar prehod ni dosegljiv — izpad vas stane le
ažurnosti. Modeli in kombinacije so objavljeni takoj, ko prispejo; samodejne kombinacije, seznam
ponudnikov in obogatitveni sloj se vključijo ob prihodu, zato ena počasna končna točka ne more zadrževati
celotnega izbirnika.

Imena vsebujejo informacije, ki jih pozna prehod: ponudnika višje ravni, h kateremu je model usmerjen, oznako `[Free]`
in pripadajoči proračun — tako ostaneta dve povezavi, ki ponujata isti model,
razločljivi. Predpono izklopite z `"providerTag": false`.

Ukaza za ročno osvežitev ni: ukazi OpenCode v2 so predloge pozivov in ne povratni klici,
zato ga vtičnik ne more omogočiti. Osvežitve sledijo TTL-ju; gostitelj prejme zahtevo za ponovno nalaganje le,
ko se katalog ali sloj dejansko spremeni, nikoli ob vsaki osvežitvi.

## Klicanje orodij v Gemini

Gemini zavrne celotno zahtevo, katere deklaracije orodij vsebujejo `$schema` ali
`additionalProperties`, in odgovori z `400 INVALID_ARGUMENT`. Vtičnik odstrani ti ključni besedi iz
shem orodij, namenjenih modelu Gemini tega ponudnika, vse druge zahteve pa pusti nespremenjene.
Orodje, ki vsebuje `$ref`, je posredovano nespremenjeno in ne očiščeno, saj bi odstranitev
sklica razširila shemo tako, da bi »sprejela karkoli«.
Če želite to izklopiti, nastavite `"geminiSanitization": false`.

## Odpravljanje težav

| Simptom                                          | Vzrok                                                                                                |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| Izbirnik ne prikazuje nobenega modela OmniRoute  | Noben ključ ni bil razrešen (preverite opozorilo ob zagonu) ali pa prehod ni dosegljiv               |
| Neobdelani ID-ji modelov, brez kombinacij in cen | Končne točke za upravljanje so zavrnile žeton — nastavite `managementReadToken`                      |
| Seja, pripeta na `opencode-<id>/…`               | Vtičnik v1 je objavil `opencode-<id>`; v2 objavi goli `<id>`, zato znova izberite model pod `<id>/…` |
