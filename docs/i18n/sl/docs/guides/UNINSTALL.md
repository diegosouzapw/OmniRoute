Ta vodnik opisuje, kako sistematično in v celoti odstraniti OmniRoute iz sistema.

## Hitra odstranitev (v3.6.2+)

OmniRoute ponuja dva vgrajena skripta za popolno odstranitev:

### Ohranitev podatkov

```bash
npm run uninstall
```

S tem odstranite aplikacijo OmniRoute, vendar **ohranite** svojo podatkovno zbirko, konfiguracije, ključe API in nastavitve ponudnikov v `~/.omniroute/`. To možnost uporabite, če nameravate aplikacijo pozneje znova namestiti in želite ohraniti svoje nastavitve.

### Popolna odstranitev

```bash
npm run uninstall:full
```

S tem odstranite aplikacijo **in trajno izbrišete** vse podatke:

- Podatkovno zbirko (`storage.sqlite`)
- Konfiguracije ponudnikov in ključe API
- Varnostne kopije
- Dnevniške datoteke
- Vse datoteke v imeniku `~/.omniroute/`

> ⚠️ **Opozorilo:** Ukaza `npm run uninstall:full` ni mogoče razveljaviti. Vse vaše povezave s ponudniki, kombinacije, ključi API in zgodovina uporabe bodo trajno izbrisani.

## Ročna odstranitev

### Globalna namestitev NPM

```bash
# Odstranite globalni paket
npm uninstall -g omniroute

# (Izbirno) Odstranite podatkovni imenik
rm -rf ~/.omniroute
```

### Globalna namestitev pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Ustavite in odstranite vsebnik
docker stop omniroute
docker rm omniroute

# Odstranite nosilec (izbriše vse podatke)
docker volume rm omniroute-data

# (Izbirno) Odstranite sliko
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Ustavite in odstranite vsebnike
docker compose down

# Odstranite tudi nosilce (izbriše vse podatke)
docker compose down -v
```

### Namizna aplikacija Electron

**Windows:**

- Odprite `Nastavitve → Aplikacije → OmniRoute → Odstrani`
- Ali zaženite program za odstranitev NSIS iz namestitvenega imenika

**macOS:**

- Povlecite `OmniRoute.app` iz `/Applications` v Koš
- Odstranite podatke: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Odstranite datoteko AppImage
- Odstranite podatke: `rm -rf ~/.omniroute`

### Namestitev iz izvorne kode (git clone)

```bash
# Odstranite klonirani imenik
rm -rf /path/to/omniroute

# (Izbirno) Odstranite podatkovni imenik
rm -rf ~/.omniroute
```

## Podatkovni imeniki

OmniRoute privzeto shranjuje podatke na naslednjih mestih:

| Platforma        | Privzeta pot                  | Preglasitev                              |
| ---------------- | ----------------------------- | ---------------------------------------- |
| Linux            | `~/.omniroute/`               | okoljska spremenljivka `DATA_DIR`        |
| macOS            | `~/.omniroute/`               | okoljska spremenljivka `DATA_DIR`        |
| Windows          | `%APPDATA%/omniroute/`        | okoljska spremenljivka `DATA_DIR`        |
| Docker           | `/app/data/` (vpeti nosilec)  | okoljska spremenljivka `DATA_DIR`        |
| Združljivo z XDG | `$XDG_CONFIG_HOME/omniroute/` | okoljska spremenljivka `XDG_CONFIG_HOME` |

### Datoteke v podatkovnem imeniku

| Datoteka/imenik      | Opis                                                                  |
| -------------------- | --------------------------------------------------------------------- |
| `storage.sqlite`     | Glavna podatkovna zbirka (ponudniki, kombinacije, nastavitve, ključi) |
| `storage.sqlite-wal` | Dnevnik vnaprejšnjega zapisovanja SQLite (začasno)                    |
| `storage.sqlite-shm` | Deljeni pomnilnik SQLite (začasno)                                    |
| `call_logs/`         | Arhivi vsebin zahtev                                                  |
| `backups/`           | Samodejne varnostne kopije podatkovne zbirke                          |
| `log.txt`            | Podedovani dnevnik zahtev (izbirno)                                   |

## Preverjanje popolne odstranitve

Po odstranitvi preverite, ali ni ostala nobena datoteka:

```bash
# Preverite globalni paket npm
npm list -g omniroute 2>/dev/null

# Preverite podatkovni imenik
ls -la ~/.omniroute/ 2>/dev/null

# Preverite izvajajoče se procese
pgrep -f omniroute
```

Če se kateri koli proces še vedno izvaja, ga ustavite:

```bash
pkill -f omniroute
```
