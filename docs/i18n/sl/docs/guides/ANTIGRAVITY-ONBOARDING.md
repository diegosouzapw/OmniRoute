## 1. Antigravity v primerjavi z Antigravity CLI (agy)

Oba ponudnika uporabljata **isto Googlovo zaledje** — enakega odjemalca OAuth, osveževanje žetonov, končne točke in Google račune. Razlika je v tem, kateri modeli so prikazani.

> Googlovo uradno primerjavo najdete v [najavi Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli).

| Vidik                       | `antigravity` (IDE)                          | `agy` (CLI)                                                 |
| --------------------------- | -------------------------------------------- | ----------------------------------------------------------- |
| **Googlov izdelek**         | Antigravity 2.0 / Antigravity IDE            | Antigravity CLI                                             |
| **Zaledje**                 | Isti Google Cloud Code API                   | Isti Google Cloud Code API                                  |
| **OAuth / žeton**           | Isti odjemalec, enako osveževanje            | Isti odjemalec, enako osveževanje                           |
| **Katalog modelov**         | Statičen izbran seznam (vgrajen v OmniRoute) | Dinamično pridobljen od Googla prek `:fetchAvailableModels` |
| **Modeli Claude**           | Sonnet 4.6, Opus 4.6 (vsak po 4 različice)   | Sonnet 4.6, Opus 4.6 (vsak po 4 različice)                  |
| **Poimenovanje Gemini**     | Jasne oznake (Low/Medium/High)               | Izvorni ID-ji (extra-low/low/agent)                         |
| **Dodatni modeli**          | `gpt-oss-120b-medium`                        | Lahko vključuje dodatne Googlove modele                     |
| **Privzeti primer uporabe** | Integracija z IDE-ji (VS Code, JetBrains)    | Dostop prek CLI-ja/API-ja                                   |
| **Kvota**                   | Deljena z agy (isti Google račun)            | Deljena z antigravity (isti Google račun)                   |

**Razpoložljivi modeli (preverjeno s preizkusom, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (različne ravni razmišljanja)
- Claude: Sonnet 4.6, Opus 4.6 (vsak z različicami default/low/medium/high)
- Drugo: GPT-OSS 120B Medium
- **Claude Sonnet 5 NI na voljo** — podprte so samo različice 4.6

**Zakaj se katalog modelov razlikuje**: Googlov CLI je »optimiziran za hitrost in nizko režijo« ter »sočasno optimiziran z modeli Gemini« (skladno z Googlovim uradnim spletnim dnevnikom). Spletni izdelek/izdelek IDE je »optimiziran za celovitost«. CLI uporablja `:fetchAvailableModels` za dinamično odkrivanje modelov, medtem ko IDE uporablja statičen izbran seznam.

**V praksi**: Za modele Gemini uporabite predpono `agy/` (npr. `agy/gemini-3.7-flash-high`). Za statičen izbran seznam uporabite `antigravity/`. Oba uporabljata isto Googlovo zaledje, vendar modele poimenujeta drugače. Kvota je skupna — uporaba katerega koli ponudnika se šteje v omejitve istega Google računa.

## 2. Google One AI Pro: Sistem kvot

> Za uradne podrobnosti o kvotah glejte [Dokumentacija Antigravity: Paketi](https://antigravity.google/docs/plans), za najnovejše posodobitve cen pa [Spremembe paketov Antigravity](https://antigravity.google/blog/changes-to-antigravity-plans).

Google Antigravity uporablja **dvostopenjsko kvoto**, ki temelji na »opravljenem delu« (računski zahtevnosti), ne na številu sporočil.

### Dve stopnji

| Stopnja             | Kaj predstavlja                     | Cikel osveževanja                                                                                   |
| ------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------- |
| **5-urni interval** | Trenutna zaloga »opravljenega dela« | Ponastavi se 5 ur po prvi zahtevi v seji                                                            |
| **7-dnevna osnova** | Tedenska stroga omejitev            | Če je dosežena, preglasi 5-urno osveževanje; dostop je onemogočen do naslednjega 7-dnevnega obdobja |

**Kako se izračuna »opravljeno delo«**: Opravila, ki intenzivno uporabljajo agente (npr. »Preoblikuj celotno skladišče«), porabijo kvoto veliko hitreje kot preprosta opravila (npr. »Popravi to funkcijo«). Nadzorna plošča, ki bi prikazovala porabo v realnem času, ne obstaja.

### Ravni paketov

| Paket        | Cena          | Kvota                                   | Tedenska omejitev                             |
| ------------ | ------------- | --------------------------------------- | --------------------------------------------- |
| Brezplačni   | $0            | Znatna kvota, osvežena tedensko         | Da                                            |
| AI Pro       | $19.99/mesec  | Visoka kvota, tekoče 5-urno osveževanje | Da (če je dosežena, preglasi 5-urno omejitev) |
| AI Ultra 5x  | $99.99/mesec  | 5-kratna kvota paketa Pro               | Brez tedenske omejitve                        |
| AI Ultra 20x | $199.99/mesec | 20-kratna kvota paketa Pro              | Brez tedenske omejitve                        |

### Modeli Gemini in drugi modeli

- **Modeli Gemini** (Flash + Pro): Souporabljajo eno omejitev hitrosti, ki se zmanjšuje glede na cene API-ja. Če je Flash 8-krat cenejši od Pro, dobite 8-krat več žetonov Flash.
- **Modeli, ki niso Gemini** (Claude, GPT-OSS): Imajo **ločene** omejitve hitrosti. Morda ostanejo na voljo tudi, ko je dostop do Gemini onemogočen.

### Dobroimetje AI (prekoračitev)

> Za informacije o delovanju dobroimetja glejte [Dobroimetje Google One AI](https://support.google.com/googleone/answer/14534406).

Ko je osnovna kvota izčrpana:

- **Nikoli**: Počakajte, da se kvota osveži; prikazano je »Dosežena je osnovna kvota modela«
- **Vedno**: Samodejno uporabi dobroimetje AI; ob osvežitvi znova preklopi na osnovno kvoto

Dobroimetje se kupi ločeno in se odšteva po standardnih cenah API-ja.

### Ključne podrobnosti

- Kvota je **skupna na ravni računa** — isti Google račun v okolju Antigravity IDE, CLI in OmniRoute uporablja skupno zalogo kvote
- Vsak Google račun ima svojo neodvisno kvoto — več računov pomeni več zalog kvote
- Uporabniki paketa AI Pro so poročali o **7-dnevnih onemogočenjih dostopa** namesto 5-urnih ponastavitev, ko je dosežena tedenska osnovna omejitev (Google je potrdil, da je to zaradi velikega povpraševanja predvideno delovanje)

**Ko je kvota vašega računa izčrpana**: OmniRoute samodejno znova poskusi z naslednjim razpoložljivim računom v kombinirani poti. Ročno posredovanje ni potrebno.

## 3. Kako pridobiti projectId

Vsaka povezava antigravity/agy potrebuje Google Cloud Code `projectId`. Brez njega končna točka `/v1internal:models` vrne napako 404.

### Način A: Samodejno (priporočeno)

OmniRoute to izvede samodejno. Ko prek OAutha na nadzorni plošči dodate nov Google račun:

1. OmniRoute osveži žeton
2. Pokliče `loadCodeAssist`, da odkrije projectId
3. Če projekt ne obstaja, pokliče `onboardUser`, da ga ustvari
4. Znova pokliče `loadCodeAssist`, da pridobi na novo ustvarjeni projectId
5. Shrani ga v podatkovno zbirko

**To deluje za večino računov** — ročni koraki niso potrebni.

### Način B: Ročno prek agy CLI

Če samodejno odkrivanje ne uspe (glejte 5. razdelek, kjer so opisani takšni primeri):

```bash
# Namestite agy CLI (če še ni nameščen)
npm install -g @anthropic-ai/agy

# Prijavite se s svojim Google računom
agy login

# Izberite račun, ki ga je treba vključiti
# To sproži registracijo v Cloud Code in dodeli projectId
```

Ko je ukaz `agy login` uspešno izveden, osvežite žeton na nadzorni plošči OmniRoute. projectId bo odkrit samodejno.

### Kako preveriti

Preverite podatkovno zbirko:

```bash
# Znotraj vsebnika OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Ali preverite dnevnike:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. URI za preusmeritev OAuth

### Težava

Google OAuth zahteva veljaven URI za preusmeritev. OmniRoute privzeto uporablja `http://127.0.0.1:20128/callback` (povratna zanka). To deluje pri lokalnih namestitvah, vendar **ne deluje pri oddaljenih namestitvah** (npr. strežnik, do katerega dostopate prek naslova IP v omrežju LAN).

Google zavrne URI-je za preusmeritev, ki:

- uporabljajo naslove IP (uporabljena mora biti domena, ki se konča z `.com`, `.org` itd.),
- se ne ujemajo z registriranimi URI-ji za preusmeritev v konfiguraciji odjemalca OAuth.

### Rešitev

**Možnost A: Uporabite vgrajeni potek OAuth (privzeto)**

- Deluje, ko do OmniRoute dostopate prek `localhost` ali `127.0.0.1`
- Konfiguracija ni potrebna

**Možnost B: Lastne poverilnice OAuth**

- V svojem okolju nastavite `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web`
- Navedite svoje poverilnice Google OAuth:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- V konzoli Google Cloud Console registrirajte `https://your-domain.com/callback` kot pooblaščeni URI za preusmeritev

**Možnost C: Za začetno prijavo uporabite agy CLI**

- Zaženite `agy login` v računalniku, ki bo dostopal do OmniRoute
- Potek OAuth se dokonča lokalno, žetoni pa se shranijo
- Povezavo uvozite v OmniRoute prek nadzorne plošče

### Omejitve

- Lastne poverilnice OAuth zahtevajo domensko ime (Google ne sprejema naslovov IP kot URI-jev za preusmeritev)
- Če nimate domene, namesto tega uporabite možnost A ali C

## 5. Odpravljanje težav: ko samodejna nastavitev ne uspe

OmniRoute za večino računov samodejno izvede odkrivanje projectId in začetno nastavitev. Ko to ne uspe, je glavni vzrok običajno eden od naslednjih:

### Regija računa je blokirana

**Simptom**: `agy login` vrne »Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location.«

**Glavni vzrok**: Googlovi računi imajo v zalednem sistemu polje »Country Association«, ki se nastavi ob registraciji. agy CLI in Cloud Code API to polje strogo preverjata — za razliko od spletnega vmesnika Gemini, ki preverja samo vaš trenutni naslov IP.

> Če želite preveriti ali spremeniti regijo, povezano z vašim računom, obiščite [Googlov obrazec za povezavo z državo](https://policies.google.com/country-association-form).

**Zakaj spletni Gemini deluje, agy pa ne**:

- Spletni Gemini / Google One: preveri samo trenutni naslov IP (posredniški strežnik zadostuje)
- agy CLI / Cloud Code API: prebere polje »Country Association« v zalednem sistemu (posredniški strežnik ne pomaga)

**Rešitev**:

1. Obiščite [Googlov obrazec za povezavo z državo](https://policies.google.com/country-association-form), medtem ko uporabljate naslov IP iz ZDA
2. Pošljite zahtevo za spremembo regije (izberite »I live in a different country«)
3. Počakajte 1–24 ur, da Google obdela zahtevo in vam pošlje e-poštno obvestilo
4. Nato bi moral biti ukaz `agy login` uspešen

### Račun nima projekta Cloud Code

**Simptom**: Dnevniki prikazujejo `loadCodeAssist returned no project id` in `onboardUser failed (400)`.

**Glavni vzrok**: Račun še nikoli ni bil registriran v storitvi Google Cloud Code, samodejna začetna nastavitev pa ni uspela.

**Rešitev**: Ročno zaženite `agy login`, da sprožite registracijo v Cloud Code, nato pa osvežite žeton na nadzorni plošči OmniRoute.

### Žeton je potekel ali je bil preklican

**Simptom**: Napake 401 v dnevnikih ali sporočila »Token has expired«.

**Rešitev**: Osvežite žeton v Nadzorna plošča → Ponudniki → agy → kliknite ikono za osvežitev. Če je bil preklican tudi žeton za osvežitev, boste morali znova izvesti preverjanje pristnosti prek OAuth.
