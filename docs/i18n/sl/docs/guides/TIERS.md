OmniRoute razvršča 352 podprtih ponudnikov v 3 cenovne razrede. Vsaka
zahteva potuje skozi njih po vrsti, dokler je eden uspešno ne obdela — tako
dobite najcenejši izvedljiv odgovor, ne da bi morali napisati kodo za nadomestne možnosti.

## Razred 1 — Naročnina

**Ponudniki, ki jih že plačujete.** OmniRoute izkoristi vso kvoto, preden
ta poteče.

| Ponudnik                         | Zakaj razred 1                                            |
| -------------------------------- | --------------------------------------------------------- |
| Claude Code OAuth                | Anthropic Pro/Team — pavšalna cena, pogosto neizkoriščeno |
| OpenAI Codex (naročnina ChatGPT) | Plus/Team vključuje kvoto za Codex                        |
| GitHub Copilot                   | Na uporabnika — kvota se ponastavi mesečno                |
| Cursor IDE                       | Kvota paketa Pro                                          |
| Antigravity / Devin Desktop      | Vgrajene kvote                                            |

**Strategija**: sem najprej usmerite vsako zahtevo, ki ustreza zmogljivostim
modela. Sledilnik kvot spremlja bližajoče se ponastavitve, kombinirana strategija
`reset-aware` pa jim ustrezno daje prednost. Če želite najprej usmerjati v razred 1
in preiti na plačljive razrede šele, ko zmanjka kvote, uporabite ID `auto/thrifty` — ali
`auto/subscription`, če želite ostati znotraj zmogljivosti, vključenih v naročnino,
in zahtevo v nasprotnem primeru zavrniti. Glejte
[Usmerjanje z naročnino na prvem mestu](../routing/SUBSCRIPTION_LADDER.md).

## Razred 2 — Poceni

**Ponudniki z obračunavanjem po žetonih pod 1 USD/1 milijon žetonov.** Namenjeni so obsežnim opravilom
ali uporabi po doseženih omejitvah kvot razreda 1.

| Ponudnik                         | Cena (vhod/izhod)             | Prednosti                      |
| -------------------------------- | ----------------------------- | ------------------------------ |
| DeepSeek V4 Pro                  | 0,27 USD / 1,10 USD na 1 mio. | Koda, sklepanje                |
| GLM-4.5                          | 0,60 USD / 2,20 USD na 1 mio. | Dolg kontekst                  |
| MiniMax M1                       | 0,20 USD / 1,10 USD na 1 mio. | Hitrost                        |
| Qwen Coder                       | 0,30 USD / 1,20 USD na 1 mio. | Koda                           |
| OpenRouter (cenovno optimiziran) | različno                      | Več kot 100 modelov, dinamično |

**Strategija**: kombinacija `cost-optimized` izbere model z najnižjo ceno na žeton,
ki ustreza filtru zmogljivosti opravila (vid, način JSON, orodja, največji kontekst).

## Razred 3 — Brezplačno

**Ponudniki brez stroškov** — brezplačni paketi, programi dobropisov, dnevne kvote OAuth.

| Ponudnik         | Brezplačna kvota/dobropisi                          |
| ---------------- | --------------------------------------------------- |
| Kiro AI          | Brezplačni paket Claude (radodarna poštena uporaba) |
| OpenCode Free    | Brez avtentikacije, radodarne omejitve hitrosti     |
| Qoder            | Brezplačni OAuth                                    |
| Google Vertex AI | 300 USD dobropisa za nove račune                    |
| Amazon Q         | Brezplačni paket za uporabnike AWS                  |
| Pollinations     | Odprti javni API                                    |
| Cloudflare AI    | Brezplačni paket Workers AI                         |

**Strategija**: kombinacija `auto` z omejitvijo proračuna usmerja sem, kadar razreda 1 in 2 odpovesta
ali kadar je nastavljeno `useFreeOnly=true`. Brezplačni ponudniki imajo pogosto strožje
omejitve hitrosti — varovalka tokokroga jih po zakasnitvi znova omogoči.

## Konfiguriranje razredov

Nadzorna plošča → **Razredi** → dodelite svoje ponudnike. Privzete nastavitve (iz `tierDefaults.json`) so
smiselne; uredite jih, kadar želite dati prednost določenim naročninam ali izključiti ponudnike.

16-faktorsko ocenjevanje Auto-Combo upošteva tudi razred. Glejte
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetrija

Nadzorna plošča → **Poraba** prikazuje dnevno porabo žetonov po razredih. Uporabite to za:

- Potrditev, da je razred 1 v celoti izkoriščen (sicer zapravljate vrednost naročnine)
- Ugotavljanje, kateri modeli razreda 2 so najpogosteje izbrani (združite jih na 1–2)
- Preverjanje, ali razred 3 prihrani denar pri testnih/raziskovalnih delovnih obremenitvah

## Pogosti vzorci

### Povsem brezplačna delovna obremenitev

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Močno usmerja proti razredu 3; razred 2 uporabi le, če razred 3 ni na voljo.

### Najprej naročnina, nato poceni nadomestna možnost

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Izrecno urejen seznam, ki ustreza razredu 1 → razredu 2 → razredu 3.
