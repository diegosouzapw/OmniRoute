> **Na kratko**: Namestite → Povežite brezplačnega ponudnika → Usmerite svoj IDE na OmniRoute. Končano.

---

## 1. korak: Namestite OmniRoute

Izberite želeni način:

### Možnost A: npm (priporočeno)

```bash
npm install -g omniroute
```

### Možnost B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` je najvišja **objavljena** stabilna različica SemVer. Ne sledi veji git `main`. Za GitOps pripnite `diegosouzapw/omniroute:X.Y.Z`. Glejte [Oznake slik/kanali izdaj](../guides/DOCKER_GUIDE.md#release-channels).

### Možnost C: Iz izvorne kode

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## 2. korak: Zaženite OmniRoute

```bash
omniroute
```

OmniRoute se zažene na naslovu `http://localhost:20128`. Nadzorna plošča se odpre samodejno.

---

## 3. korak: Povežite brezplačnega ponudnika

OmniRoute lahko uporabljate **popolnoma brezplačno**, tako da povežete brezplačnega ponudnika.

### Možnost A: Kiro (brezplačni Claude — brez kreditne kartice)

1. Odprite nadzorno ploščo na naslovu `http://localhost:20128`
2. Pojdite na **Ponudniki** → **Dodaj ponudnika**
3. Izberite **Kiro AI**
4. Kliknite **Poveži** (ključ API ni potreben!)
5. Končano! Zdaj imate brezplačen dostop do modelov Claude.

### Možnost B: OpenCode Free (brez preverjanja pristnosti)

1. Odprite nadzorno ploščo na naslovu `http://localhost:20128`
2. Pojdite na **Ponudniki** → **Dodaj ponudnika**
3. Izberite **OpenCode Free**
4. Kliknite **Poveži** (ključ API ni potreben!)
5. Končano! Zdaj imate brezplačen dostop do več modelov.

### Možnost C: Pollinations (ključ ni potreben)

1. Odprite nadzorno ploščo na naslovu `http://localhost:20128`
2. Pojdite na **Ponudniki** → **Dodaj ponudnika**
3. Izberite **Pollinations**
4. Kliknite **Poveži** (ključ API ni potreben!)
5. Končano! Zdaj imate brezplačen dostop do GPT-5, Claude, Gemini in drugih modelov.

---

## 4. korak: Preverite delovanje

Na strani [Ključi API](http://localhost:20128/dashboard/api-manager) ustvarite nov ključ. Shranite ga, saj ne bo več prikazan. Upoštevajte, da je ta ključ namenjen dostopu orodij do OmniRoute in ne dostopu do ponudnikov višje ravni.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Prikazan bi moral biti seznam povezanih modelov.

---

## 5. korak: Usmerite svoj IDE ali CLI na OmniRoute

V svojem orodju IDE ali CLI nastavite:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

To je vse! Vaš IDE zdaj uporablja OmniRoute s samodejno izbiro ponudnika.

### Primer za IDE: VSCode/Continue.dev

1. V VSCode namestite razširitev [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Posodobite datoteko `~/.continue/config.yaml` in dodajte naslednje vrstice:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. V podoknu za klepet Continue.dev izberite `OmniRoute - Auto` in zahteve boste pošiljali storitvi OmniRoute.
4. (Izbirno) Vaja za bralca – naj vaš IDE posodobi datoteko `config.yaml` z vsemi drugimi vnaprej pripravljenimi konfiguracijami 😊

### Primer za CLI: Codex CLI

1. V operacijskem sistemu trajno nastavite spremenljivko okolja.
   Za macOS/Linux (dodajte v `~/.bashrc` ali `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Za Windows (ukazni poziv):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Zdaj zaženimo Codex, vendar konfiguriran za OmniRoute. Zaženite:

```
omniroute launch-codex --model auto
```

To lahko izvedete ročno z ukazom `codex` in parametri ukazne vrstice, s katerimi določite končno točko in ključ API, vendar z zgornjim ukazom OmniRoute vse uredi namesto vas.

Enak zagon z enim ukazom deluje tudi za druge odjemalce CLI prek splošnega zaganjalnika — `omniroute run <target>` podpira `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` in `gemini` (glejte [Integracije CLI](../guides/CLI-INTEGRATIONS.md)).

3. CLI bi moral zdaj pošiljati zahteve storitvi OmniRoute.

### Preverite, ali vaše orodje usmerja zahteve v OmniRoute

Podrobnosti zahteve si lahko ogledate tako, da v levi stranski vrstici kliknete [Spremljanje/dnevniki](http://localhost:20128/dashboard/logs). S klikanjem si lahko ogledate več podrobnosti. Mimogrede lahko vidite, katere informacije vaše priljubljeno ogrodje pošilja ponudniku. To je koristno z izobraževalnega vidika in pri odpravljanju napak.

## Pogosta vprašanja

### »Ali potrebujem ključ API?«

**Ne!** Brezplačne ponudnike (Kiro, OpenCode Free, Pollinations) lahko uporabljate brez ključa API. Preprosto jih povežite na nadzorni plošči.

### »Kaj je `auto`?«

`auto` naroči OmniRoute, naj za vsako zahtevo samodejno izbere najboljšega ponudnika. Pri tem upošteva hitrost, stroške, kakovost in razpoložljivost. Za podrobnosti glejte [Vodnik za Auto-Combo](./AUTO-COMBO-GUIDE.md).

### »Koliko stane?«

OmniRoute je **brezplačen in odprtokoden**. Plačate samo ponudnike, ki jih uporabljate. Številni ponudniki imajo brezplačne pakete — glejte [Vodnik po brezplačnih paketih](./FREE-TIERS-GUIDE.md).

### »Ali ga lahko uporabljam s Claude Code/Cursor/Copilot?«

**Da!** OmniRoute deluje z vsakim orodjem, ki podpira obliko OpenAI. Osnovni URL preprosto nastavite na `http://localhost:20128/v1`. Za posebna navodila za nastavitev glejte [Vodnik po orodjih CLI](../reference/CLI-TOOLS.md).

### »Kaj se zgodi, če ponudnik preneha delovati?«

OmniRoute samodejno preskoči nedelujoče ponudnike in poskusi naslednjega. Ni vam treba storiti ničesar. Za podrobnosti glejte [Vodnik za Auto-Combo](./AUTO-COMBO-GUIDE.md).
