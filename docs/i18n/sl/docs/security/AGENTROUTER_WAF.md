Vhodni prehod `agentrouter` izvaja filter vsebine na podlagi ključnih besed v
`messages[].content`. Filter je delno determinističen (vedno blokira
določene fraze) in delno verjetnosten (občutljiv na zaporedne zahteve — po
hitro poslanih zahtevah postane strožji, po obdobju mirovanja pa se obnovi).

Ko WAF blokira zahtevo, vrne:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Obseg filtra

WAF pregleduje samo `messages[].content`. **Ne** pregleduje:

- Sistemskega poziva `system`
- Strukturiranih vsebinskih blokov (`tool_result`, `tool_use`, `thinking`, `image`)
- Polj orodij `description` in `input_schema`
- Metapodatkov zahteve, glav ali ID-ja modela

## Vedno blokirani vzorci (ne glede na velikost črk)

| Vzorec                              | Opombe                                                         |
| ----------------------------------- | -------------------------------------------------------------- |
| Katera koli različica `Lorem ipsum` | Blokirano je celotno latinsko besedišče Lorem ipsum            |
| `language model` (samostojno)       | "the language model" in "large language model" nista blokirana |
| `virtual assistant`                 | "AI assistant" ni blokirano                                    |
| `I'm here to help`                  | Tudi samostojni "here to help" je blokiran                     |
| `Claude, made by Anthropic`         | Samo celotna fraza                                             |

## Skoraj vedno blokirani vzorci

| Vzorec                                                          | Opombe                                                  |
| --------------------------------------------------------------- | ------------------------------------------------------- |
| `placeholder`                                                   | Ko je uporabljen samostojno (ne kot ime parametra itd.) |
| `dummy data`                                                    | Pogosta začetna fraza za testne podatke                 |
| `foo bar baz`                                                   | Kanonična fraza za nadomestno besedilo                  |
| Ponavljajoči se kratki žetoni (`AAA BBB CCC`, `test test test`) | Detektor kopičenja ključnih besed                       |

## Obnašanje pod obremenitvijo

Po približno 5 hitro poslanih zahtevah v kratkem časovnem obdobju začne WAF blokirati vsebino,
ki bi običajno prestala preverjanje. Omejitev se sprosti po približno 5–10 sekundah
mirovanja. Gre za isti omejevalnik hitrosti, vezan na IP in ključ, ki povzroča
občasne napake `400 content-blocked`, ko Claude Code ali Codex CLI
hitro zaporedoma izvede več klicev za uporabo orodij oziroma pošiljanje sporočil.

## Omilitveni ukrepi, ki so že uporabljeni v OmniRoute

1. **`open-sse/services/wafRateLimit.ts`** — zaščita pred zaporednimi zahtevami, ki uveljavlja
   najmanj 500 ms presledka med izhodnimi zahtevami na kateri koli URL
   `agentrouter:*`. Presledek je precej pod pragom, pri katerem bi človek zaznal zakasnitev,
   in preprečuje, da bi se WAF aktiviral pri običajnem prometu.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — ko izvorna storitev vrne
   `400 content-blocked`, izvajalnik znova poskusi z istim URL-jem in
   eksponentnim časovnim zamikom (1,5 s, 3,0 s, največ 2 poskusa). Po tem zamiku
   se WAF običajno sprosti in ponovni poskus uspe.

3. **`tests/unit/compression/harness.test.ts`** — testni podatek
   `longInput` je bil spremenjen iz `"lorem ipsum dolor sit amet ".repeat(40)`
   v `"example content for testing purposes ".repeat(40)`, tako da se ob
   branju te datoteke z orodjem `Read` v Claude Code vsebina datoteke
   ne posreduje nazaj skozi blok `tool_result` in ne sproži WAF-a.

## Smernice za pozive in izhod orodij

Če seja Claude Code ali Codex CLI vedno znova naleti na
`400 content-blocked`, preverite najnovejše uporabniško sporočilo in
najnovejši rezultat orodja glede katerega koli od zgornjih vzorcev ter ga preoblikujte. Pogoste
rešitve:

- Zamenjajte `Lorem ipsum …` z `example text …` ali z dejansko vsebino,
  ki jo poskuša ponazoriti test ali testni podatek.
- Zamenjajte samostojni `placeholder` z `example value`,
  `sample value` ali z dejansko vrednostjo.
- Zamenjajte `language model` z `large language model` ali `the model`.
- Zamenjajte `dummy data` s `sample data` ali z realističnimi začetnimi vrednostmi.
- Zamenjajte `I'm here to help` / `here to help` z bolj specifičnim
  uvodom (npr. "I'll review the file you mentioned").

## Prijavljanje lažno pozitivnih zaznav izvorni storitvi

Trenutni filter je preveč agresiven — blokira "Lorem ipsum" v
blokih `tool_result`, čeprav operater očitno ni nameraval
vstaviti poziva. Operaterji, ki želijo, da se to odpravi pri izvoru, naj
stopijo v stik z `agentrouter.org` in prijavijo lažno pozitivne zaznave. Zgornji
seznam blokiranih izrazov je empirični rezultat preverjanja izvorne storitve na dan 2026-08-03.
