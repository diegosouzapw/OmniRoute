> **Vir resnice:** `src/lib/obsidian/api.ts` (odjemalec REST + sinhronizacija),
> `src/lib/db/obsidian.ts` (hramba žetona / osnovnega URL-ja / WebDAV),
> `src/lib/obsidianSync.ts` (sinhronizacija trezorja prek WebDAV), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 orodij MCP), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API-ji za nastavitve). Registracija orodij
> in povezovanje obsegov sta v `open-sse/mcp-server/server.ts`.

## Kaj je to

OmniRoute se poveže s trezorjem **Obsidian** kot **virom konteksta** — lokalno zbirko znanja
v obliki Markdown, ki jo agenti berejo in vanjo pišejo prek vgrajenega strežnika MCP.
Integracija komunicira z vtičnikom skupnosti **Obsidian Local REST API**, ki se izvaja v
namizni aplikaciji, zato lahko agenti iščejo po zapiskih, berejo/pišejo/popravljajo datoteke,
prikazujejo vsebino trezorja, delajo z dnevnimi/tedenskimi periodičnimi zapiski, upravljajo
oznake, izvajajo ukaze Obsidian in (izbirno) usklajujejo dvosmerno sinhronizacijo trezorja
med namizno in mobilno napravo.

Odjemalec (`src/lib/obsidian/api.ts`) ovije Local REST API z naslednjimi zmožnostmi:

- **Ponovni poskusi z zakasnitvijo** za prehodne napake `5xx` in **30-sekundna časovna omejitev** prek `AbortController`.
- **Tipizirano razvrščanje napak** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Prijazen namig »povezave z Obsidianom ni mogoče vzpostaviti«**, ki opozori na pogosto
  napako pri izbiri vrat (HTTP na `27123`, **ne** končna točka MCP na `27124`) in obliko naslova Tailscale.
- **Kodiranje poti** glede na koren trezorja, zato so poti zapiskov s presledki/poševnicami varne.

## Nastavitev

Za žeton Obsidian ali osnovni URL **ni okoljske spremenljivke** — oba sta shranjena
v tabeli SQLite `key_value` (imenski prostor `obsidian`) prek
`src/lib/db/obsidian.ts`. Žeton je **šifriran v mirovanju** (AES-256-GCM, z rezervno
združljivostjo za nešifrirano besedilo). Nastavite ga na zavihku **Viri konteksta** na
nadzorni plošči končne točke (`ObsidianSourceCard`) ali prek nastavitev REST API-ja.

> [!IMPORTANT]
> Vtičnik **Obsidian Local REST API** mora biti nameščen in zagnan. Njegov vmesnik REST
> posluša na **HTTP `127.0.0.1:27123`** (privzeti osnovni URL). Vrata `27124`
> predstavljajo _ločeno_ končno točko MCP/HTTPS in jih pot za nastavitve izrecno zavrne.
> Če se povezujete iz druge naprave, uporabite `http://<tailscale-ip>:27123`.

### Konfiguracijski ključi (SQLite `key_value`, imenski prostor `obsidian`)

| Ključ             | Namen                                                       | Šifrirano |
| ----------------- | ----------------------------------------------------------- | --------- |
| `api_key`         | Nosilni žeton Local REST API-ja                             | da        |
| `base_url`        | Osnovni URL REST (privzeto `http://127.0.0.1:27123`)        | ne        |
| `vault_path`      | Absolutna pot do imenika trezorja (za sinhronizacijo)       | ne        |
| `webdav_username` | Ustvarjeno uporabniško ime WebDAV (sinhronizacija trezorja) | ne        |
| `webdav_password` | Ustvarjeno geslo WebDAV (sinhronizacija trezorja)           | da        |
| `webdav_enabled`  | Ali je sinhronizacija trezorja prek WebDAV omogočena        | ne        |

### Nastavitev prek REST-a

```bash
# Shrani in preveri žeton Local REST API-ja (POST ga preveri s preverjanjem stanja)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Preveri stanje povezave (vrne connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Prekini povezavo (izbriše shranjeni žeton)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Vsi načini zahtevajo avtentikacijo nadzorne plošče. `POST` zavrne vsak URL na vratih `27124`
in pred shranjevanjem preveri žeton s klicem končne točke stanja Local REST API-ja.

### Sinhronizacija trezorja prek WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` upravlja izbirno sinhronizacijo
trezorja prek WebDAV (poganja jo `src/lib/obsidianSync.ts`). Ko jo omogočite, OmniRoute
usmeri na imenik lokalnega trezorja ter ustvari naključen par uporabniškega imena in gesla WebDAV:

```bash
# Omogoči sinhronizacijo WebDAV za imenik trezorja (ustvari uporabniško ime/geslo)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Pridobi stanje sinhronizacije WebDAV (poverilnice se vrnejo le, ko je omogočena)
curl http://localhost:20128/api/settings/obsidian/webdav

# Onemogoči sinhronizacijo WebDAV (izbriše poverilnice in upravljano datoteko .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Vir konteksta za posamezen ključ API (izbirno)

Konfiguracijo Obsidian je mogoče omejiti **na posamezen ključ API** prek tabele
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Ko klic MCP vsebuje
ID avtenticiranega ključa API, `getObsidianConfigForApiKey()` prednostno uporabi
žeton/osnovni URL/pot trezorja tega ključa (`source: "api_key"`), sicer pa uporabi
globalno konfiguracijo (`source: "global"`).

## Orodja MCP (22)

Opredeljena so v `open-sse/mcp-server/tools/obsidianTools.ts`. Žeton/osnovni URL se razrešita
pri vsakem klicu (najprej za posamezni ključ API, nato globalno). Orodja, ki dostopajo do **sinhronizacijskega strežnika**
OmniRoute (štiri orodja `obsidian_sync_*`), dodatno zahtevajo žeton za preverjanje pristnosti pri sinhronizaciji, konfiguriran
v nastavitvah OmniRoute.

### Orodja za branje (`read:obsidian`)

| Orodje                       | Opis                                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Preveri, ali je lokalni REST API dosegljiv in ali je preverjanje pristnosti uspešno.                                   |
| `obsidian_search_simple`     | Iskanje po celotnem besedilu vsebine zapiskov; vrne odlomke s potmi do datotek.                                        |
| `obsidian_search_structured` | Iskanje z izrazom JSON Logic (filtri and/or/regex/path).                                                               |
| `obsidian_read_note`         | Prebere zapisek glede na pot, relativno na trezor; po želji določen naslov/blok/frontmatter.                           |
| `obsidian_list_vault`        | Navede datoteke in imenike v trezorju (drevo vnosov).                                                                  |
| `obsidian_get_document_map`  | Pridobi strukturo naslovov zapiska kot preslikavo naslovov → številke vrstic.                                          |
| `obsidian_get_note_metadata` | Pridobi frontmatter, oznake, povezave ter število znakov/besed brez celotne vsebine.                                   |
| `obsidian_get_active_file`   | Pridobi pot in vsebino trenutno aktivne datoteke v Obsidianu.                                                          |
| `obsidian_get_periodic_note` | Pridobi dnevni/tedenski/mesečni periodični zapisek za datum (če je izpuščen, za danes).                                |
| `obsidian_get_tags`          | Navede vse oznake v trezorju in pogostost njihove uporabe.                                                             |
| `obsidian_list_commands`     | Navede razpoložljive ID-je ukazov Obsidian (za uporabo z `obsidian_execute_command`).                                  |
| `obsidian_sync_status`       | Stanje sinhronizacijskega strežnika OmniRoute: delovanje, ime trezorja, vrata, čas delovanja in zadnja sinhronizacija. |
| `obsidian_sync_conflicts`    | Navede nerešena sinhronizacijska navzkrižja (pot, pot navzkrižja, čas zaznave).                                        |

### Orodja za pisanje (`write:obsidian`)

| Orodje                           | Opis                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Ustvari ali prepiše zapisek z dano vsebino Markdown.                                               |
| `obsidian_append_note`           | Doda vsebino zapisku; po želji pod določen naslov/blok.                                            |
| `obsidian_patch_note`            | Natančno doda pred/za ali zamenja vsebino pri naslovu, bloku ali polju frontmatter.                |
| `obsidian_delete_note`           | Trajno izbriše zapisek iz trezorja.                                                                |
| `obsidian_move_note`             | Premakne ali preimenuje zapisek znotraj trezorja.                                                  |
| `obsidian_execute_command`       | Izvede ukaz Obsidian glede na njegov ID ukaza.                                                     |
| `obsidian_open_file`             | Odpre datoteko v Obsidianu (ustvari jo, če ne obstaja).                                            |
| `obsidian_sync_trigger`          | Sproži takojšnjo dvosmerno sinhronizacijo trezorja med namizno in mobilno napravo.                 |
| `obsidian_sync_resolve_conflict` | Razreši sinhronizacijsko navzkrižje: ohrani `local` (mobilno), `remote` (namizno) ali `keep-both`. |

> [!NOTE]
> Cilji za `obsidian_patch_note` sprejemajo `targetType` z vrednostjo `heading | block | frontmatter`
> in `operation` z vrednostjo `append | prepend | replace` ter neobvezni
> `createTargetIfMissing`. Štiri orodja `obsidian_sync_*` komunicirajo z lokalnim sinhronizacijskim
> strežnikom (privzeto `http://127.0.0.1:27781`) in zahtevajo sinhronizacijski žeton.

### Obsegi

Orodja za branje zahtevajo `read:obsidian`; orodja za pisanje zahtevajo `write:obsidian`. Uveljavljanje
je enako kot pri Notionu — obravnava ga `withScopeEnforcement()` v
`open-sse/mcp-server/server.ts`, pogojeno z `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, pri čemer
dovoljeni obsegi izvirajo iz `OMNIROUTE_MCP_SCOPES` ali konteksta obsegov ključa API. Glejte
[MCP-SERVER.md](./MCP-SERVER.md).

## Končne točke

| Metoda   | Pot                             | Namen                                                          |
| -------- | ------------------------------- | -------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Vrne `{ connected, hasToken, baseUrl, vaultPath }`.            |
| `POST`   | `/api/settings/obsidian`        | Shrani in preveri žeton (zavrne vrata `27124`).                |
| `DELETE` | `/api/settings/obsidian`        | Prekine povezavo (izbriše shranjeni žeton).                    |
| `GET`    | `/api/settings/obsidian/webdav` | Stanje sinhronizacije WebDAV in poverilnice (ko je omogočena). |
| `POST`   | `/api/settings/obsidian/webdav` | Omogoči sinhronizacijo WebDAV za imenik trezorja.              |
| `DELETE` | `/api/settings/obsidian/webdav` | Onemogoči sinhronizacijo WebDAV.                               |

> To so poti nastavitev nadzorne plošče. Do samega trezorja se dostopa prek lokalnega
> API-ja REST Obsidian (nastavljeni `base_url`) in zgornjih orodij MCP — javna posredniška
> končna točka `/v1` za Obsidian ne obstaja.

## Primeri uporabe

- **Odgovori na podlagi trezorja** — `obsidian_search_simple` / `obsidian_search_structured`,
  nato `obsidian_read_note`, da agent odgovarja na podlagi vaših dejanskih zapiskov.
- **Ustvarjanje zapiskov / vodenje dnevnika** — `obsidian_write_note`, `obsidian_append_note` ali
  natančni `obsidian_patch_note` za beleženje izhodnih podatkov agenta, povzetkov ali dnevnih zapiskov
  (`obsidian_get_periodic_note`) v trezor.
- **Krmarjenje po trezorju** — `obsidian_list_vault`, `obsidian_get_document_map` in
  `obsidian_get_tags` za raziskovanje strukture pred branjem/pisanjem.
- **Avtomatizacija aplikacije Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` za
  upravljanje vtičnikov/ukazov prek agenta; `obsidian_open_file` za prikaz zapiska v uporabniškem vmesniku.
- **Mobilna sinhronizacija** — omogočite sinhronizacijo WebDAV, nato pa uporabite `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  za usklajevanje med namizno in mobilno napravo ter razreševanje sporov.
