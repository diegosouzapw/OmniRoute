## Kaj je to

Local Corpus omogoča skrbniku, da strežniku MCP sistema OmniRoute omogoči dostop do enega izrecno odobrenega imenika z besedilnimi datotekami. Datoteke ostanejo v izvornem imeniku: OmniRoute v SQLite shrani samo kanonično korensko pot in vzdržuje iskalni indeks v pomnilniku. Vsebine korpusa ne kopira v repozitorij ali podatkovno zbirko.

Osveževanje indeksa je inkrementalno. Nespremenjene datoteke se ponovno uporabijo glede na velikost in čas spremembe, spremenjene datoteke se znova preberejo in zgostijo z algoritmom SHA-256, izbrisane datoteke pa se odstranijo. Iskanje osveži indeks, starejši od 30 sekund; klicatelji lahko zahtevajo tudi takojšnjo osvežitev.

## Konfiguriranje vira

Pot nastavitev zahteva enako upravljavsko avtentikacijo kot drugi API-ji za nastavitve. Poslana pot mora že obstajati in mora biti absolutna pot do imenika.

```bash
# Povežite odobreni imenik
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Preverite konfiguracijo in stanje indeksa
curl http://localhost:20128/api/settings/local-corpus

# Prekinite povezavo brez spreminjanja izvornih datotek
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## Orodja MCP

Vsa tri orodja zahtevajo `read:local-corpus`. Odgovori orodij razkrijejo relativne poti in osnovno ime korenskega imenika, nikoli pa njegove absolutne poti.

| Orodje                | Opis                                                                                      |
| :-------------------- | :---------------------------------------------------------------------------------------- |
| `local_corpus_status` | Poroča o stanju konfiguracije, velikosti indeksa, omejitvah in času zadnje osvežitve      |
| `local_corpus_search` | Išče po indeksiranem besedilu in vrne omejene izseke po vrsticah (do 20 rezultatov)       |
| `local_corpus_read`   | Prebere omejen razpon vrstic iz ene dovoljene datoteke s potjo, relativno glede na korpus |

Primeri vhodov MCP:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Varnostne meje

- Seznam dovoljenih vrst datotek je usmerjen v besedilne datoteke: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` in `.yml`.
- Simbolne povezave se preskočijo. Poti za branje se kanonizirajo in morajo ostati znotraj
  konfiguriranega korenskega imenika; absolutne poti in poskusi prehajanja po imenikih so zavrnjeni.
- Občutljiva in ustvarjena imena imenikov so izključena: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` in
  `secrets`.
- Privzete omejitve so 5.000 datotek, 1 MiB na datoteko, 64 MiB skupne indeksirane vsebine,
  približno 4.000 znakov na iskalni segment in 400 vrstic na branje.
- Datoteke, ki vsebujejo NUL, se obravnavajo kot nebesedilne in se preskočijo ali zavrnejo.

Binarni dokumenti, kot so PDF, DOCX, slike in arhivi, namenoma niso podprti. Pred indeksiranjem jih pretvorite v odobreno besedilno obliko v konfiguriranem imeniku.

## Opombe za uporabo

- Sprememba ali izbris konfiguriranega korenskega imenika počisti skupni indeks v pomnilniku.
- Ponovni zagon procesa zavrže indeks; naslednje iskanje ga znova zgradi iz konfiguriranega
  vira.
- `local_corpus_status` ne sproži pregledovanja. Uporabite `local_corpus_search` z
  `refresh: true`, kadar je potrebno takojšnje ponovno pregledovanje.
- Napake pri pregledovanju in branju se preštejejo ali vrnejo kot očiščene napake; izvorne datoteke se
  nikoli ne spremenijo.
