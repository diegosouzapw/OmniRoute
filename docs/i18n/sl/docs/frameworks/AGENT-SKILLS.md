> **Vir resnice:** `src/lib/agentSkills/` (katalog, generator, razčlenjevalniki) + imenik `skills/` (datoteke SKILL.md)
> **Nazadnje posodobljeno:** 2026-08-02 — v3.8.50

Agent Skills so strukturirane datoteke SKILL.md, ki zunanje agente, odjemalce MCP in orkestratorje A2A učijo uporabljati OmniRoute REST API in CLI. Za razliko od [Omni Skills](./SKILLS.md) (ki so definicije orodij LLM, izvedene znotraj OmniRoute) so Agent Skills _katalog dokumentacije_ — statični markdown, ki ga je mogoče neposredno vključiti v kontekst agenta.

---

## Pregled

Katalog vsebuje **45 Agent Skills** (23 za REST API + 21 za CLI + 1 potek dela za konfiguracijo). Vsaka veščina ima:

- **Kanonični ID** (`omni-auth`, `cli-serve` itd.)
- Datoteko **SKILL.md** v `skills/{id}/SKILL.md` z uvodnimi metapodatki YAML (`name`, `description`) in obsežno vsebino markdown
- **Končne točke REST** (veščine API) ali **podukaze CLI** (veščine CLI), izpeljane iz specifikacije OpenAPI in registra CLI
- **Neobdelani URL GitHub** za sprotno pridobivanje: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Arhitektura

```
src/shared/constants/agentSkills.ts    — ročno izbran seznam s 45 vnosi (ime/opis/kategorija/področje/ikona)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() zapisuje SKILL.md v skills/{id}/
  openapiParser.ts                     — pridobi končne točke REST iz docs/openapi.yaml
  cliRegistryParser.ts                 — pridobi podukaze CLI iz bin/cli-registry.ts
  schemas.ts                           — sheme Zod: AgentSkillSchema, SkillCoverageSchema itd.
  types.ts                             — vmesniki TypeScript: AgentSkill, SkillCoverage itd.

skills/{id}/SKILL.md                   — ustvarjene in ročno dopolnjene datoteke markdown (skupaj 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (zahtevana avtentikacija)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 orodja MCP (seznam, pridobivanje, pokritost)
src/lib/a2a/skills/listCapabilities.ts        — veščina A2A: list-capabilities
```

```markdown

name: omni-providers

---

<!-- ustvarjeno z src/lib/agentSkills/generator.ts; ročne spremembe bodo prepisane -->

## Pregled

...

## Avtentikacija

...

## Končne točke

...

<!-- skill:custom-start -->

## Razdelek po meri (ohranjen pri ponovnem ustvarjanju)

...

<!-- skill:custom-end -->
```

Generator pri ponovnem ustvarjanju ohrani vsebino med `<!-- skill:custom-start -->` in `<!-- skill:custom-end -->`. Deset veščin ima ročno dopolnjene bloke po meri:

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## Odkrivanje prek REST API-ja

| Končna točka                 | Metoda | Opis                                                               | Avtentikacija |
| :--------------------------- | :----- | :----------------------------------------------------------------- | :------------ |
| `/api/agent-skills`          | GET    | Seznam kataloga (izbirno `?category=api\|cli\|config&area=<area>`) | brez          |
| `/api/agent-skills/{id}`     | GET    | Pridobi metapodatke posamezne veščine                              | brez          |
| `/api/agent-skills/{id}/raw` | GET    | Pridobi SKILL.md kot `text/markdown`                               | brez          |
| `/api/agent-skills/coverage` | GET    | Statistika pokritosti (koliko datotek SKILL.md obstaja)            | brez          |
| `/api/agent-skills/generate` | POST   | Sproži generator (dryRun/prune/onlyIds)                            | upravljavska  |

Primer — seznam vseh veščin API-ja:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Primer — pridobitev posamezne datoteke SKILL.md:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

Veščina A2A `list-capabilities` vrne celoten katalog 45 veščin kot artefakt v obliki tabele markdown. Zunanji orkestratorji jo lahko prikličejo prek:

```json

  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {

    "messages": [{ "role": "user", "content": "List all capabilities" }]
```

## Kako zunanji agenti uporabljajo veščine

### 1. Odkrivanje prek REST

```bash
# Pridobite celoten katalog
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Pridobite SKILL.md za vstavljanje konteksta
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Odkrivanje prek MCP

```typescript
// V odjemalcu MCP za Claude Desktop / Cursor:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → polje objektov AgentSkill z rawUrl za vsakega
```

### 3. Odkrivanje prek A2A

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table je tabela markdown z vsemi 45 ID-ji veščin in stolpci rawUrl
```

### 4. Neposreden prenos neobdelane vsebine iz GitHub (strežnik ni potreben)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generator

Generator prebere ročno urejen katalog, specifikacijo OpenAPI in register CLI ter za vsak vnos zapiše `skills/{id}/SKILL.md`:

```bash
# Predogled (poskusni zagon brez zapisovanja)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Popolna ponovna izdelava
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Ponovna izdelava določenih ID-jev
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Odziv generatorja je `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
