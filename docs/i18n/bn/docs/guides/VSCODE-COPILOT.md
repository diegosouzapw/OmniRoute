**OmniCopilot** আপনার OmniRoute দ্বারা পরিবেশিত প্রতিটি মডেলকে _নেটিভ_ GitHub Copilot Chat
মডেল পিকারে যুক্ত করে। কোনো দ্বিতীয় সাইডবার বা আলাদা চ্যাট UI নেই — Copilot-এর এজেন্ট মোড, টুল কলিং,
MCP সার্ভার এবং কাস্টম নির্দেশাবলি সবই কাজ করতে থাকে, শুধু আপনার বেছে নেওয়া মডেলে চলে।

## সেটআপ

1. **OmniRoute চালান** — `npm install -g omniroute && omniroute` (`http://localhost:20128`-এ ড্যাশবোর্ড)।
2. **এক্সটেনশনটি ইনস্টল করুন** — Extensions ভিউতে "OmniRoute" খুঁজুন।
3. **একটি মডেল বেছে নিন** — Copilot Chat → মডেল পিকার → **Manage Models…** → **OmniRoute**, তারপর
   আপনার পছন্দের মডেলগুলোতে টিক দিন।

OmniRoute ডিফল্ট পোর্টে চললে কিছুই কনফিগার করতে হবে না। রিমোট ইনস্ট্যান্সের জন্য,
**Activity Bar-এ OmniRoute আইকন** খুলুন (অথবা `OmniRoute: Manage Connection` চালান) এবং সেট করুন:

- **Server URL** — সার্ভারের রুট, যেমন `http://192.168.0.15:20128`। `/v1` সাফিক্সটি
  এক্সটেনশন নিজেই যোগ করে; এটি অন্তর্ভুক্ত করবেন না।
- **API key** — শুধুমাত্র সার্ভারে `REQUIRE_API_KEY` সেট করা থাকলে। এটি VS
  Code SecretStorage-এর মাধ্যমে OS keychain-এ সংরক্ষিত হয়, কখনোই `settings.json`-এ নয়।

## পিকারে যা দেখা যাবে

এক্সটেনশনটি অপরিবর্তিত `GET /v1/models` পেলোড দেখায় না — এটি পেলোডটিকে সাজায়, এবং আপনি যে সংখ্যা
দেখেন তা দুটি ইচ্ছাকৃত কারণে ক্যাটালগের আকারের চেয়ে কম।

### এটি প্রতিটি মডেলের জন্য একটি id চায়

`MODELS_CATALOG_PREFIX_MODE`-এর ডিফল্ট মান **`dual`**, যা প্রতিটি মডেলকে দুবার প্রকাশ করে — একবার
সংক্ষিপ্ত alias prefix-এর অধীনে এবং একবার canonical provider prefix-এর অধীনে — যাতে পুরোনো ক্লায়েন্ট
কনফিগ উভয় রূপই রিজলভ করতে পারে:

```
cc/claude-sonnet-4-6        ← alias prefix
claude/claude-sonnet-4-6    ← canonical prefix, একই মডেল
```

এক্সটেনশনটি **`GET /v1/models?prefix=alias`** অনুরোধ করে, ফলে আপনার অন্যান্য ক্লায়েন্টের জন্য
সার্ভারব্যাপী সেটিং পরিবর্তন না করেই প্রতিটি মডেলের জন্য একটি করে id আসে। একটি রেফারেন্স ইনস্ট্যান্সে এটি
**2345টি এন্ট্রিকে কমিয়ে 1396 করেছে — 949টি ডুপ্লিকেট, কোনো মডেল হারায়নি।**

আপনি যদি এর পরিবর্তে _প্রতিটি_ ক্লায়েন্টের জন্য সার্ভারব্যাপী এটি ঠিক করতে চান, তাহলে ড্যাশবোর্ডে
`MODELS_CATALOG_PREFIX_MODE` feature flag-টি `alias`-এ সেট করুন। query parameter এবং
প্রতিটি মোডের টেবিলের জন্য [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) দেখুন।

### এটি চ্যাট করতে পারে না এমন মডেল লুকিয়ে রাখে

ক্যাটালগে image, video, audio, rerank, embedding এবং moderation মডেলও তালিকাভুক্ত থাকে। চ্যাট
অনুরোধে এগুলো এমনিতেই প্রত্যাখ্যাত হয়:

```
HTTP 400 — Model '<id>' একটি image-generation মডেল এবং এটি
/v1/chat/completions-এ ব্যবহার করা যায় না। পরিবর্তে POST /v1/images/generations ব্যবহার করুন।
```

তাই পিকারে পৌঁছানোর আগেই এগুলোকে তাদের `type` ফিল্ড অনুযায়ী ফিল্টার করা হয়। **Responses-API
মডেলগুলো রাখা হয়** — প্রতিটি Codex / GPT-5.x এন্ট্রি `supported_endpoints: ["responses"]`
প্রকাশ করে, এবং OmniRoute সেগুলোকে `/v1/chat/completions`-এর জন্য রূপান্তর করে, তাই সেগুলো সম্পূর্ণ ব্যবহারযোগ্য।

### যেসব provider আপনি কখনো কনফিগার করেননি

ক্যাটালগে **সক্রিয় সংযোগ** থাকা provider-এর মডেলগুলোর পাশাপাশি প্রতিটি **noAuth**
provider-ও তালিকাভুক্ত থাকে — এগুলো এমন keyless provider, যা ফ্রি টিয়ারের বড় একটি অংশ তৈরি করে। এটি ইচ্ছাকৃত। এগুলো
লুকাতে ড্যাশবোর্ড সেটিংসে `blockedProviders`-এ যোগ করুন; এক্সটেনশনে কিছুই পরিবর্তন হবে না।

## VS Code ট্যাবের ভিতরে ড্যাশবোর্ড

`omnicopilot.dashboardOpen: "editor"` একটি বাহ্যিক ব্রাউজারের পরিবর্তে Simple Browser-এর মাধ্যমে একটি এডিটর ট্যাবে OmniRoute ড্যাশবোর্ড রেন্ডার করে। এম্বেডিং **সার্ভারে অপ্ট-ইন করতে হয়**
`DASHBOARD_ALLOW_EMBED=vscode`-এর মাধ্যমে, যা ডিফল্ট `frame-ancestors 'none'` +
`X-Frame-Options: DENY`-এর পরিবর্তে `frame-ancestors 'self' vscode-webview:` সহ HTML পেজগুলো পরিবেশন করে। উভয় ক্ষেত্রেই API সারফেস (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) কঠোর হেডারগুলো বজায় রাখে।

> ⚠️ **এটি বিল্ড-টাইম ফ্ল্যাগ, রানটাইম ফ্ল্যাগ নয়।** Next.js `headers()`-কে রুট
> ম্যানিফেস্টে কম্পাইল করে, তাই বান্ডেল বিল্ড করার সময় `next.config.mjs` ভেরিয়েবলটি পড়ে
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`)।
> ইতিমধ্যে বিল্ড করা সার্ভার চালুর আগে এটি এক্সপোর্ট করলে কিছুই পরিবর্তন হয় না — হেডারগুলো বিল্ডের মধ্যেই স্থায়ীভাবে সংযুক্ত থাকে।

```bash
# ভেরিয়েবলটি BUILD কমান্ডে উপস্থিত থাকতে হবে
DASHBOARD_ALLOW_EMBED=vscode npm run build        # অথবা npm run build:release
npm start
```

| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| সোর্স থেকে                 | ✅ উপরে দেখানো অনুযায়ী বিল্ড কমান্ডে ভেরিয়েবলটি সেট করুন                                                                                  |

| Docker ইমেজ                | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — Docker Hub-এর আগে থেকে বিল্ড করা ইমেজে এম্বেড সক্রিয় নেই |

এম্বেড-সক্রিয় বিল্ড ছাড়া পেজটি ফ্রেমে প্রদর্শিত হতে অস্বীকার করে; এক্সটেনশনটি রেসপন্স হেডার থেকে তা শনাক্ত করে এবং বাহ্যিক ব্রাউজারে ফিরে যায় — কিছুই নষ্ট হয় না, এবং এটি একবার সে কথা জানায়।

Kilo এবং Roo-এর জন্য ব্যবহারের উপযোগী প্রোফাইল তৈরি করে — এগুলো
