`@omniroute/opencode-plugin-v2` আপনার সম্পূর্ণ OmniRoute ক্যাটালগ — মডেল, কম্বো এবং
অটো-কম্বো — প্রদর্শনের নাম, মূল্য এবং ফ্রি-টিয়ার বাজেটসহ OpenCode v2-এর মডেল পিকারে
যুক্ত করে।

এটি `@omniroute/opencode-plugin` থেকে আলাদা একটি প্যাকেজ, কারণ OpenCode v1 এবং v2 ভিন্ন
কন্ট্রাক্টের মাধ্যমে প্লাগইন লোড করে। আপনার OpenCode-এর মেজর সংস্করণের সঙ্গে মেলে এমনটি
বেছে নিন; এদের মধ্যে কিছুই শেয়ার করা হয় না, তাই একটি আপগ্রেড করলে অন্যটি আপগ্রেড করতে হয় না।

## প্রয়োজনীয়তা

- OpenCode v2।
- অ্যাক্সেসযোগ্য একটি OmniRoute গেটওয়ে (ডিফল্টভাবে `http://localhost:20128`)।
- Node.js 22 বা 24।

## ইনস্টলেশন

`opencode.json`-এ প্লাগইনটি যোগ করুন:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

এরপর মডেলগুলো `omniroute/<provider>/<model>` হিসেবে দেখা যাবে; `providerId` ওই প্রিফিক্স এবং
যে ইন্টিগ্রেশনের অধীনে OpenCode ক্রেডেনশিয়াল সংরক্ষণ করে, তার আইডি নির্ধারণ করে।

## ক্রেডেনশিয়াল

প্লাগইনটি নিচের তিনটি স্থানে এই ক্রমে গেটওয়ে কী খোঁজে:

1. **OpenCode-এ আপনার সংযুক্ত করা ক্রেডেনশিয়াল।** প্লাগইনটি একটি ইন্টিগ্রেশন নিবন্ধন করে, ফলে
   OpenCode-এর নিজস্ব অথেন্টিকেশন ফ্লো কীটি সংরক্ষণ করতে পারে। `opencode.json`-এ কিছুই লেখা হয় না — এটিই অগ্রাধিকার দিন।
2. প্রতি-প্রজেক্ট ওভাররাইডের জন্য প্লাগইন অপশনের `apiKey`। এতে কীটি এমন একটি ফাইলে রাখা হয়
   যা আপনি কমিট করে ফেলতে পারেন।
3. এনভায়রনমেন্টের `OMNIROUTE_API_KEY`।

এই তিনটির কোনোটিই না থাকলে ক্যাটালগটি খালি থাকে এবং নীরবে একটি খালি পিকার দেখানোর পরিবর্তে
প্লাগইনটি স্টার্টআপের সময় একবার তা জানায়।

### ম্যানেজমেন্ট টোকেনটি একটি আলাদা কী

কম্বো, প্রোভাইডারের স্বাস্থ্য এবং সমৃদ্ধকরণের তথ্য (প্রদর্শনের নাম, মূল্য, ফ্রি-টিয়ার বাজেট)
গেটওয়ের `/api/*` এন্ডপয়েন্ট থেকে আসে, যেগুলো অধিকাংশ ডিপ্লয়মেন্টে ইনফারেন্স কীর পরিবর্তে একটি
**ম্যানেজমেন্ট** টোকেন দিয়ে সুরক্ষিত থাকে:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

সেট না করা থাকলে `managementReadToken`, `apiKey`-তে ফলব্যাক করে। কোনো গেটওয়ে সেই ফলব্যাক
প্রত্যাখ্যান করলে ক্যাটালগ তবুও প্রকাশিত হয়, তবে প্রদর্শনের নামের পরিবর্তে অপরিবর্তিত মডেল আইডি থাকে,
ক্যানোনিক্যাল অ্যালিয়াস ডিডুপ্লিকেশন, মূল্য এবং কম্বো থাকে না। এমনটি ঘটলে প্লাগইনটি প্রতিটি এন্ডপয়েন্টের
জন্য একবার সতর্ক করে এবং এন্ডপয়েন্ট ও কী হারিয়েছে তা উল্লেখ করে — ফলে অবনমিত পিকার কখনোই রহস্যজনক থাকে না।

## অপশন

| কী                               | ডিফল্ট                                          | নোট                                                                                                           |
| -------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                   | প্রোভাইডার আইডি, ইন্টিগ্রেশন আইডি এবং যে প্রিফিক্সের অধীনে মডেলগুলো দেখা যায়                                 |
| `baseURL`                        | আবশ্যক                                          | গেটওয়ে রুট, শুধু `http(s)`; যেখানে প্রয়োজন সেখানে `/v1` সাফিক্স যোগ করা হয়                                 |
| `apiKey`                         | সংযুক্ত ক্রেডেনশিয়াল, এরপর `OMNIROUTE_API_KEY` | `/v1/*`-এর জন্য চ্যাট কী                                                                                      |
| `managementReadToken`            | `apiKey`-তে ফলব্যাক করে                         | `/api/*`-এর জন্য কী — সাধারণত **একই কী নয়**                                                                  |
| `displayName`                    | `"OmniRoute"`                                   | পিকারে প্রোভাইডারের নাম                                                                                       |
| `timeoutMs`                      | `10000`                                         | প্রতি-এন্ডপয়েন্ট ফেচ টাইমআউট (অটো-কম্বোর জন্য 5 সেকেন্ড)                                                     |
| `modelCacheTtlMs`                | `300000`                                        | ক্যাটালগ ক্যাশ TTL; ডিস্ক স্ন্যাপশট কোল্ড স্টার্ট দ্রুত করে                                                   |
| `timeouts`                       | `timeoutMs`-তে ফলব্যাক করে                      | মিলিসেকেন্ডে প্রতি-এন্ডপয়েন্ট বাজেট: `models`, `combos`, `autoCombos`, `enrichment`                          |
| `enrichment`                     | `true`                                          | নাম, মূল্য এবং ফ্রি-টিয়ার বাজেট ফেচ করে                                                                      |
| `providerTag`                    | `true`                                          | প্রদর্শনের নামের আগে যে আপস্ট্রিম প্রোভাইডারে রাউট করা হয়, তার নামের প্রিফিক্স যোগ করে                       |
| `usableOnly`                     | `false`                                         | গেটওয়ে যেসব প্রোভাইডারকে প্রভিশন করা হয়েছে বলে জানায়, শুধু সেগুলো রাখে                                     |
| `visibleModels` / `hiddenModels` | `[]`                                            | হুবহু-মিল-বা-সাফিক্স অ্যালাউলিস্ট; নিষেধাজ্ঞা অগ্রাধিকার পায়                                                 |
| `geminiSanitization`             | `true`                                          | টুল স্কিমা থেকে Gemini-এর প্রত্যাখ্যান করা JSON-Schema কীওয়ার্ড সরায় (`$ref` টুল অপরিবর্তিতভাবে পাঠানো হয়) |
| `apiFormat.allowAnthropic`       | `false`                                         | অ্যালাউলিস্টে থাকা আইডিগুলো Anthropic API ব্লকের মাধ্যমে রাউট করে                                             |
| `apiFormat.anthropicModels`      | `[]`                                            | Anthropic-এ রাউট করা পূর্ণ মডেল আইডি                                                                          |
| `logLevel` / `startupDebug`      | `warn` / `false`                                | লগারের বিস্তারিততার মাত্রা                                                                                    |

## ক্যাটালগ যেভাবে হালনাগাদ থাকে

ক্যাটালগটি প্রয়োজনের সময় ফেচ করা হয় এবং `modelCacheTtlMs` সময়কাল পর্যন্ত ক্যাশে রাখা হয়, আর গেটওয়েতে পৌঁছানো না গেলে একটি ডিস্ক স্ন্যাপশট সর্বশেষ জানা ক্যাটালগটি উপলভ্য রাখে — কোনো বিভ্রাটে আপনার শুধু হালনাগাদ তথ্যই হারায়। মডেল ও কম্বোগুলো পৌঁছামাত্র প্রকাশিত হয়; অটো-কম্বো, প্রোভাইডার তালিকা এবং এনরিচমেন্ট ওভারলে এসে পৌঁছালে সেগুলোও যুক্ত হয়, ফলে কোনো একটি ধীর এন্ডপয়েন্ট পুরো পিকারকে আটকে রাখতে পারে না।

নামগুলোতে গেটওয়ের জানা তথ্য থাকে: কোনো মডেল যে আপস্ট্রিম প্রোভাইডারে রাউট হয়, একটি `[Free]` চিহ্ন এবং এর সঙ্গে থাকা বাজেট — ফলে একই মডেল বিক্রি করা দুটি সংযোগকে আলাদা করে চেনা যায়। `"providerTag": false` দিয়ে প্রিফিক্সটি বন্ধ করুন।

কোনো ম্যানুয়াল রিফ্রেশ কমান্ড নেই: OpenCode v2 কমান্ডগুলো প্রম্পট টেমপ্লেট, কলব্যাক নয়, তাই কোনো প্লাগইন এমন কমান্ড উন্মুক্ত করতে পারে না। রিফ্রেশগুলো TTL অনুসরণ করে; ক্যাটালগ বা ওভারলে বাস্তবে পরিবর্তিত হলেই কেবল হোস্টকে পুনরায় লোড করতে বলা হয়, প্রতিটি রিফ্রেশে নয়।

## Gemini-তে টুল কলিং

এই প্রোভাইডারের কোনো Gemini মডেলের জন্য পাঠানো টুল স্কিমায় `$schema` বা `additionalProperties` থাকলে Gemini পুরো অনুরোধটি প্রত্যাখ্যান করে এবং `400 INVALID_ARGUMENT` উত্তর দেয়। প্লাগইনটি সেইসব টুল স্কিমা থেকে ওই কীওয়ার্ডগুলো সরিয়ে দেয় এবং অন্য সব অনুরোধ অপরিবর্তিত রাখে। `$ref` থাকা কোনো টুলকে কিছু না সরিয়েই ফরওয়ার্ড করা হয়, কারণ রেফারেন্সটি সরালে স্কিমাটি প্রসারিত হয়ে "যেকোনো কিছু গ্রহণ করুন"-এ পরিণত হবে।
এটি বন্ধ করতে `"geminiSanitization": false` সেট করুন।

## সমস্যা সমাধান

| লক্ষণ                                       | কারণ                                                                                                              |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| পিকারে কোনো OmniRoute মডেল দেখা যায় না     | কোনো কী পাওয়া যায়নি (স্টার্টআপ সতর্কতা পরীক্ষা করুন), অথবা গেটওয়েতে পৌঁছানো যাচ্ছে না                          |
| কাঁচা মডেল আইডি, কোনো কম্বো নেই, মূল্যও নেই | ম্যানেজমেন্ট এন্ডপয়েন্টগুলো টোকেনটি প্রত্যাখ্যান করেছে — `managementReadToken` সেট করুন                          |
| একটি সেশন `opencode-<id>/…`-এ পিন করা       | v1 প্লাগইন `opencode-<id>` প্রকাশ করত; v2 শুধু `<id>` প্রকাশ করে, তাই `<id>/…`-এর অধীনে মডেলটি আবার নির্বাচন করুন |
