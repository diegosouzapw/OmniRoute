| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | -------------------------------- |

তিনটি একে অপরের থেকে স্বাধীন — যেকোনো উপসেট বেছে নিন।

## সিদ্ধান্তের ধাপসমূহ

```
এই মেশিনের বাইরে কাজ সম্পাদনের জন্য আপনার কি কোনো ক্লাউড পরিষেবা প্রয়োজন (Codex Cloud / Cursor Cloud / Devin / Jules)?
├─ হ্যাঁ → ক্লাউড এজেন্ট (POST /api/v1/agents/tasks)
└─ না → এগিয়ে যান
    │
    আপনার কি এমন কোনো সমকক্ষ এজেন্ট আছে, যা A2A ব্যবহার করে এবং সহযোগিতা করতে চায়?
    ├─ হ্যাঁ → A2A (POST /a2a)
    └─ না → এগিয়ে যান
        │
        স্থানীয়ভাবে ইনস্টল করা CLI কোডিং এজেন্টগুলোর তালিকা দেখতে / কনফিগার করতে হবে?
        ├─ হ্যাঁ → ACP (GET /api/acp/agents)
        └─ না → সাধারণ /v1/chat/completions ব্যবহার করুন
```

## 1. A2A — এজেন্ট-টু-এজেন্ট

**স্পেসিফিকেশন:** [A2A v0.3](https://a2a-protocol.org)
**OmniRoute এন্ডপয়েন্ট:** `POST /a2a` (JSON-RPC 2.0)
**এজেন্ট কার্ড:** `GET /.well-known/agent.json`

### কখন ব্যবহার করবেন

- এমন একটি বহু-এজেন্ট সিস্টেম তৈরি করার সময়, যেখানে OmniRoute সমকক্ষগুলোর একটি
- Google ADK-এর মতো ফ্রেমওয়ার্ক বা সাধারণ এজেন্ট মেশে থাকা এজেন্টগুলোর জন্য OmniRoute-এর রাউটিং সক্ষমতা (`smart-routing`, `quota-management` ইত্যাদি) উন্মুক্ত করার সময়
- একটি প্রমিত অনুসন্ধান + আহ্বান ইন্টারফেসের আড়ালে OmniRoute-কে মোড়ানোর সময়

### মেথডসমূহ

- `message/send` — একটি বার্তা জমা দিন এবং সিঙ্ক্রোনাস প্রতিক্রিয়া গ্রহণ করুন
- `message/stream` — বার্তা জমা দিন + SSE-এর মাধ্যমে স্ট্রিম করা অগ্রগতির ইভেন্ট গ্রহণ করুন
- `tasks/get` — ID অনুযায়ী টাস্ক পড়ুন
- `tasks/cancel` — চলমান টাস্ক বাতিল করুন

### অন্তর্নির্মিত দক্ষতা (6)

- `smart-routing` — সর্বোত্তম কম্বোর মাধ্যমে একটি প্রম্পট রাউট করুন
- `quota-management` — প্রতিটি প্রদানকারীর কোটা-অবস্থা রিপোর্ট করুন
- `provider-discovery` — সক্ষমতাসহ ইনস্টল করা প্রদানকারীদের তালিকা দেখান
- `cost-analysis` — একটি অনুরোধ/কথোপকথনের আনুমানিক খরচ নির্ধারণ করুন
- `health-report` — প্রতিটি প্রদানকারীর breaker/cooldown/lockout অবস্থা একত্রিত করুন
- `list-capabilities` — এজেন্টটির উপলভ্য দক্ষতা ও মেটাডেটা তালিকাভুক্ত করুন

### বিস্তারিত আলোচনা

পরিবহন ব্যবস্থার বিস্তারিত, এজেন্ট কার্ডের কাঠামো, টাস্ক TTL কনফিগারেশন এবং নতুন দক্ষতা যোগ করার টেমপ্লেটের জন্য [A2A-SERVER.md](./A2A-SERVER.md) দেখুন।

## 2. ACP — CLI এজেন্ট রেজিস্ট্রি

**OmniRoute এন্ডপয়েন্ট:** `GET /api/acp/agents`
**সোর্স:** `src/lib/acp/{index,manager,registry}.ts`

### এটি কী

ACP হলো OmniRoute-এর **স্থানীয় CLI এজেন্ট ইনভেন্টরি**। এটি হোস্টে কোন কোন কোডিং CLI ইনস্টল করা আছে (Cursor, Cline, Claude Code, Codex CLI, Continue ইত্যাদি) তা শনাক্ত করে, সেগুলোর সংস্করণ নির্ধারণ করে এবং ড্যাশবোর্ডে প্রদর্শন করে, যাতে ব্যবহারকারী প্রতিটি CLI-কে OmniRoute-এর দিকে নির্দেশ করার জন্য সংযুক্ত করতে পারেন।

এটি কোনো বাহ্যিক প্রোটোকল নয় — এটি একটি অভ্যন্তরীণ রেজিস্ট্রি, যা "CLI Tools" UI এবং CLI ফিঙ্গারপ্রিন্ট ট্র্যাকিং পরিচালনা করে ([CLI-TOOLS.md](../reference/CLI-TOOLS.md) দেখুন)।

### এটি কী করে

- ইনস্টল করা CLI বাইনারির জন্য হোস্ট পরীক্ষা করে (OS অনুযায়ী `which` / `where` ব্যবহার করে)
- প্রতিটি CLI-এর সংস্করণ পড়ে (`<bin> --version` কল করে)
- ঐচ্ছিকভাবে ব্যবহারকারী-সংজ্ঞায়িত কাস্টম এজেন্ট গ্রহণ করে (বাইনারি পাথ + সংস্করণ অনুসন্ধান + স্পন আর্গুমেন্ট)
- সেটিংসে কাস্টম এজেন্ট সংরক্ষণ করে
- ড্যাশবোর্ডে সমন্বিত তালিকা ফেরত দেয়

### REST API

| এন্ডপয়েন্ট       | মেথড | বিবরণ                                                            | অথ     |
| ----------------- | ---- | ---------------------------------------------------------------- | ------ |
| `/api/acp/agents` | GET  | শনাক্ত করা + কাস্টম এজেন্টের তালিকা (ইনস্টল করা/মোট সংখ্যা)      | API কী |
| `/api/acp/agents` | POST | কাস্টম এজেন্ট যোগ/আপডেট/অপসারণ করে (বডিতে অ্যাকশন ডিসক্রিমিনেটর) | API কী |

POST-এর বডি কাঠামো (`src/app/api/acp/agents/route.ts`-এ `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### ব্যবহারের ক্ষেত্র

- ড্যাশবোর্ডের "CLI Tools" পৃষ্ঠা কোনগুলো ইনস্টল করা আছে তা তালিকাভুক্ত করে এবং প্রতিটিকে OmniRoute-এর দিকে নির্দেশ করতে সহায়তা করে
- কাস্টম এজেন্টের মাধ্যমে অভিজ্ঞ ব্যবহারকারীরা এমন অভ্যন্তরীণ/মালিকানাধীন CLI নিবন্ধন করতে পারেন, যেগুলো সম্পর্কে OmniRoute ডিফল্টভাবে জানে না
- শনাক্তকরণের ফলাফল `cli-tools` ফিঙ্গারপ্রিন্ট ম্যাট্রিক্সে তথ্য সরবরাহ করে

### কখন ACP ব্যবহার করবেন না

- ACP কোনো টাস্ক _চালায়_ না। এটি শুধু CLI শনাক্ত ও কনফিগার করে। বাস্তবে কোনো CLI আহ্বান করতে, OmniRoute-এর দেওয়া এনভায়রনমেন্ট ভেরিয়েবল (`OPENAI_BASE_URL`, `OPENAI_API_KEY` ইত্যাদি) ব্যবহার করে আপনাকেই সেটি চালু করতে হবে।

## 3. ক্লাউড এজেন্ট

**OmniRoute এন্ডপয়েন্টসমূহ:** `/api/v1/agents/tasks/*` (লাইফসাইকেল) + `/api/cloud/*` (অভ্যন্তরীণ সংযোগব্যবস্থা)
**সোর্স:** `src/lib/cloudAgent/`

### এটি কী

তৃতীয়-পক্ষের ক্লাউড কোডিং এজেন্টগুলোর জন্য একটি অভিন্ন ইন্টারফেস। আপনি একটি প্রম্পট + রিপোজিটরি URL জমা দেন, OmniRoute সেটি সঠিক ক্লাউড এজেন্টের কাছে পাঠায়, স্ট্যাটাস পোল করে এবং ফলাফল ফেরত দেয়।

### সমর্থিত এজেন্ট (৪টি, সবগুলোই `src/lib/cloudAgent/agents/`-এ নিশ্চিত করা হয়েছে)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### লাইফসাইকেল

```
POST /api/v1/agents/tasks
  → প্রতিটি এজেন্ট ক্লাস অনুযায়ী BaseAgent.createTask()
  → বাহ্যিক সার্ভিস কাজ শুরু করে
  → DB-তে টাস্কের সারি তৈরি হয় (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → প্রোভাইডার থেকে বিলম্বিত স্ট্যাটাস সিঙ্ক
  → বর্তমান স্ট্যাটাস + পরিকল্পনা + অ্যাক্টিভিটি লগ ফেরত দেয়
  ↓
POST /api/v1/agents/tasks/[id]   (অ্যাকশন: "approve" | "message" | "cancel")
  → প্রোভাইডারের কাছে ফরওয়ার্ড করে (অথবা স্থানীয়ভাবে বাতিল হিসেবে চিহ্নিত করে)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → স্থানীয়ভাবে বাতিল করে
```

### অথ

⚠️ **সব `/api/v1/agents/tasks/*` এন্ডপয়েন্টে ম্যানেজমেন্ট অথ আবশ্যক** (কমিট `588a0333`)। v3.8.0 থেকে শুধু Bearer ব্যবহারকারী কলাররা 401 পায়।

### বিস্তারিত আলোচনা

`CloudAgentBase` কনট্র্যাক্ট, প্রতিটি এজেন্টের নির্দিষ্ট বিবরণ, স্কিমার বিস্তারিত এবং ক্রেডেনশিয়াল সংযোগব্যবস্থার এন্ডপয়েন্টের জন্য [CLOUD_AGENT.md](./CLOUD_AGENT.md) দেখুন।

## তুলনা: A2A বনাম Cloud Agents

উভয়েরই "দীর্ঘমেয়াদি কাজ" রয়েছে, তবে ভিন্ন স্তরে:

| দিক                | A2A                                                                                    | Cloud Agents                                  |
| ------------------ | -------------------------------------------------------------------------------------- | --------------------------------------------- |
| স্ট্যান্ডার্ড      | উন্মুক্ত A2A v0.3                                                                      | OmniRoute-নির্দিষ্ট                           |
| কম্পিউট কোথায় চলে | OmniRoute-এর অভ্যন্তরে (কনফিগার করা কম্বো ব্যবহার করে)                                 | বাহ্যিকভাবে (Codex / Devin / Jules সার্ভারে)  |
| কাজের সময়কাল      | ডিফল্ট TTL 5 মিনিট (`TaskManager`-এ কনফিগারযোগ্য)                                      | কয়েক মিনিট থেকে কয়েক ঘণ্টা                  |
| রিপো-সচেতন         | না (শুধু প্রম্পট পাঠায়)                                                               | হ্যাঁ (রিপো URL + ব্রাঞ্চ)                    |
| ব্যবহারের ক্ষেত্র  | এজেন্টগুলোর মধ্যে সহযোগিতা, পরিষেবা হিসেবে স্মার্ট রাউটিং                              | "রিপো Y-তে ফিচার X বাস্তবায়ন করুন" অর্পণ করা |
| প্রমাণীকরণ         | `/a2a`-এর জন্য ঐচ্ছিক `OMNIROUTE_API_KEY`; `/api/a2a/*` REST সহায়কের জন্য ব্যবস্থাপনা | সর্বদা ব্যবস্থাপনা                            |

## ইন্টিগ্রেশনের উদাহরণ

### OmniRoute-এর A2A সক্ষমতাগুলো আবিষ্কার করুন

```bash
curl http://localhost:20128/.well-known/agent.json
```

সব 6টি দক্ষতা, ট্রান্সপোর্ট এবং সংস্করণসহ Agent Card ফেরত দেয়।

### A2A এজেন্ট হিসেবে OmniRoute-কে কল করুন

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### ACP-এর মাধ্যমে ইনস্টল করা CLI এজেন্টগুলোর তালিকা দেখুন

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### একটি কাস্টম CLI এজেন্ট যোগ করুন

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

### একটি Cloud Agent কাজ জমা দিন

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Implement feature X in repo Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### ক্লাউড কাজের স্থিতি পোল করুন

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```

## কখন কোনটি ব্যবহার করবেন

- **চ্যাটবট / কোপাইলট ফ্রন্টএন্ড** → `/v1/chat/completions` (OpenAI-সামঞ্জস্যপূর্ণ—এটি কোনো এজেন্ট প্রোটোকল নয়)
- **একাধিক এজেন্টের মধ্যে সহযোগিতা** → A2A
- **ড্যাশবোর্ডে স্থানীয় CLI-গুলোর তালিকা দেখানো** → ACP
- **দীর্ঘমেয়াদি কোডিংয়ের কাজ ক্লাউড পরিষেবায় অর্পণ করা** → Cloud Agents
