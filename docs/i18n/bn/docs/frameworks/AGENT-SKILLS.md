## সংক্ষিপ্ত বিবরণ

ক্যাটালগটিতে **45টি Agent Skills** (23টি REST API + 21টি CLI + 1টি কনফিগারেশন ওয়ার্কফ্লো) রয়েছে। প্রতিটি স্কিলে রয়েছে:

- একটি **ক্যানোনিক্যাল ID** (`omni-auth`, `cli-serve` ইত্যাদি)
- `skills/{id}/SKILL.md`-এ একটি **SKILL.md** ফাইল, যাতে YAML frontmatter (`name`, `description`) + সমৃদ্ধ markdown বডি রয়েছে
- OpenAPI স্পেসিফিকেশন ও CLI রেজিস্ট্রি থেকে প্রাপ্ত **REST এন্ডপয়েন্টসমূহ** (API স্কিল) অথবা **CLI সাবকমান্ডসমূহ** (CLI স্কিল)
- সরাসরি ফেচ করার জন্য একটি **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API আবিষ্কার

| এন্ডপয়েন্ট                  | মেথড | বিবরণ                                                               | অথেন্টিকেশন |
| :--------------------------- | :--- | :------------------------------------------------------------------ | :---------- |
| `/api/agent-skills`          | GET  | ক্যাটালগের তালিকা (ঐচ্ছিক `?category=api\|cli\|config&area=<area>`) | নেই         |
| `/api/agent-skills/{id}`     | GET  | একটি স্কিলের মেটাডেটা পান                                           | নেই         |
| `/api/agent-skills/{id}/raw` | GET  | `text/markdown` হিসেবে SKILL.md আনুন                                | নেই         |
| `/api/agent-skills/coverage` | GET  | কভারেজ পরিসংখ্যান (কতটি SKILL.md ফাইল বিদ্যমান)                     | নেই         |
| `/api/agent-skills/generate` | POST | জেনারেটর ট্রিগার করুন (dryRun/prune/onlyIds)                        | ব্যবস্থাপনা |

উদাহরণ — সব API স্কিলের তালিকা:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

উদাহরণ — একটি SKILL.md আনুন:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

| `omniroute_agent_skills_get`      | `id` অনুযায়ী একটি স্কিলের মেটাডেটা + SKILL.md পান  |
| `omniroute_agent_skills_coverage` | কভারেজ পরিসংখ্যান (API/CLI বিদ্যমান/মোট)            |

## A2A আবিষ্কার

A2A স্কিল `list-capabilities` সম্পূর্ণ 45-স্কিলের ক্যাটালগ একটি markdown টেবিল আর্টিফ্যাক্ট হিসেবে ফেরত দেয়। বহিরাগত অর্কেস্ট্রেটরগুলো এটি এভাবে আহ্বান করতে পারে:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

প্রোটোকলের বিস্তারিত তথ্যের জন্য [A2A-SERVER.md](./A2A-SERVER.md) দেখুন।

## বহিরাগত এজেন্টগুলো যেভাবে স্কিল ব্যবহার করে

### 1. REST-এর মাধ্যমে অনুসন্ধান

```bash
# সম্পূর্ণ ক্যাটালগ সংগ্রহ করুন
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# কনটেক্সট ইনজেকশনের জন্য SKILL.md সংগ্রহ করুন
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP-এর মাধ্যমে অনুসন্ধান

```typescript
// একটি Claude Desktop / Cursor MCP ক্লায়েন্টে:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → প্রতিটির rawUrl-সহ AgentSkill-এর অ্যারে
```

### 3. A2A-এর মাধ্যমে অনুসন্ধান

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table হলো একটি markdown টেবিল, যাতে সব 45টি skill ID + rawUrl কলাম রয়েছে
```

## জেনারেটর

জেনারেটরটি সুবিন্যস্ত ক্যাটালগ + OpenAPI স্পেসিফিকেশন + CLI রেজিস্ট্রি পড়ে এবং প্রতিটি এন্ট্রির জন্য `skills/{id}/SKILL.md` লেখে:

```bash
# প্রিভিউ (ড্রাই রান, কোনো লেখা হবে না)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# সম্পূর্ণ পুনরুৎপাদন
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# নির্দিষ্ট ID-গুলো পুনরুৎপাদন করুন
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

জেনারেটরের প্রতিক্রিয়াটি একটি `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
