## এটি কী

OmniRoute একটি **Obsidian** ভল্টের সঙ্গে **কনটেক্সট উৎস** হিসেবে সংযুক্ত হয় — এটি একটি
স্থানীয় Markdown জ্ঞানভান্ডার, যা এজেন্টরা বিল্ট-ইন MCP সার্ভারের মাধ্যমে পড়ে ও লেখে।
ইন্টিগ্রেশনটি ডেস্কটপ অ্যাপের ভেতরে চলমান **Obsidian Local REST API** কমিউনিটি প্লাগইনের
সঙ্গে যোগাযোগ করে, ফলে এজেন্টরা নোট অনুসন্ধান, ফাইল পড়া/লেখা/প্যাচ করা, ভল্টের তালিকা
দেখা, দৈনিক/সাপ্তাহিক পর্যায়ক্রমিক নোট নিয়ে কাজ করা, ট্যাগ পরিচালনা, Obsidian কমান্ড
চালানো এবং (ঐচ্ছিকভাবে) দ্বিমুখী ডেস্কটপ↔মোবাইল ভল্ট সিঙ্ক সমন্বয় করতে পারে।

ক্লায়েন্টটি (`src/lib/obsidian/api.ts`) Local REST API-কে নিম্নলিখিত সুবিধাসহ আবৃত করে:

- ক্ষণস্থায়ী `5xx` ত্রুটির জন্য **ব্যাকঅফসহ পুনঃচেষ্টা**, `AbortController`-এর মাধ্যমে
  **30-সেকেন্ডের টাইমআউট**।
- **টাইপযুক্ত ত্রুটি শ্রেণিবিন্যাস** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`।
- একটি **সহজবোধ্য "Obsidian-এ পৌঁছানো যাচ্ছে না" ইঙ্গিত**, যা সাধারণ পোর্ট-সংক্রান্ত
  ভুলটি উল্লেখ করে (HTTP-এর জন্য `27123`, MCP এন্ডপয়েন্টের `27124` **নয়**) এবং
  Tailscale-এর বিন্যাসটি দেখায়।
- ভল্ট-আপেক্ষিক **পাথ এনকোডিং**, যাতে স্পেস/স্ল্যাশযুক্ত নোটের পাথ নিরাপদ থাকে।

## সেটআপ

Obsidian টোকেন বা বেস URL-এর জন্য **কোনো এনভায়রনমেন্ট ভেরিয়েবল নেই** — উভয়ই
`src/lib/db/obsidian.ts`-এর মাধ্যমে SQLite-এর `key_value` টেবিলে (`obsidian` নেমস্পেস)
সংরক্ষণ করা হয়। টোকেনটি **স্থায়ী সংরক্ষণে এনক্রিপ্ট করা থাকে** (AES-256-GCM, প্লেইনটেক্সট
পশ্চাৎ-সামঞ্জস্য ফলব্যাকসহ)। Endpoint ড্যাশবোর্ডের **Context Sources** ট্যাব
(`ObsidianSourceCard`) থেকে অথবা সেটিংস REST API-এর মাধ্যমে কনফিগার করুন।

> [!IMPORTANT]
> **Obsidian Local REST API** প্লাগইনটি অবশ্যই ইনস্টল করা এবং চালু থাকতে হবে। এর REST
> ইন্টারফেস **HTTP `127.0.0.1:27123`**-এ শোনে (ডিফল্ট বেস URL)। পোর্ট `27124`
> একটি _পৃথক_ MCP/HTTPS এন্ডপয়েন্ট এবং সেটিংস রুট এটিকে স্পষ্টভাবে প্রত্যাখ্যান করে।
> অন্য কোনো ডিভাইস থেকে সংযোগ করলে `http://<tailscale-ip>:27123` ব্যবহার করুন।

### কনফিগারেশন কীসমূহ (SQLite `key_value`, নেমস্পেস `obsidian`)

| Key               | উদ্দেশ্য                                       | এনক্রিপ্ট করা |
| ----------------- | ---------------------------------------------- | ------------- |
| `api_key`         | Local REST API বেয়ারার টোকেন                  | হ্যাঁ         |
| `base_url`        | REST বেস URL (ডিফল্ট `http://127.0.0.1:27123`) | না            |
| `vault_path`      | ভল্ট ডিরেক্টরির অ্যাবসলিউট পাথ (সিঙ্কের জন্য)  | না            |
| `webdav_username` | তৈরি করা WebDAV ব্যবহারকারীর নাম (ভল্ট সিঙ্ক)  | না            |
| `webdav_password` | তৈরি করা WebDAV পাসওয়ার্ড (ভল্ট সিঙ্ক)        | হ্যাঁ         |
| `webdav_enabled`  | WebDAV ভল্ট সিঙ্ক সক্রিয় আছে কি না            | না            |

### REST-এর মাধ্যমে কনফিগার করুন

```bash
# Local REST API টোকেন সংরক্ষণ + যাচাই করুন (POST একটি স্ট্যাটাস পরীক্ষা করে যাচাই করে)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# সংযোগের স্থিতি পরীক্ষা করুন (connected, hasToken, baseUrl, vaultPath ফেরত দেয়)
curl http://localhost:20128/api/settings/obsidian

# সংযোগ বিচ্ছিন্ন করুন (সংরক্ষিত টোকেন মুছে দেয়)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

সব মেথডের জন্য ড্যাশবোর্ড প্রমাণীকরণ আবশ্যক। `POST` পোর্ট `27124`-এর যেকোনো URL
প্রত্যাখ্যান করে এবং সংরক্ষণের আগে Local REST API-এর স্ট্যাটাস এন্ডপয়েন্ট কল করে
টোকেনটি যাচাই করে।

### WebDAV ভল্ট সিঙ্ক

`src/app/api/settings/obsidian/webdav/route.ts` একটি ঐচ্ছিক WebDAV-সমর্থিত
ভল্ট সিঙ্ক পরিচালনা করে (যা `src/lib/obsidianSync.ts` দ্বারা চালিত)। এটি সক্রিয় করলে
OmniRoute-কে একটি স্থানীয় ভল্ট ডিরেক্টরির দিকে নির্দেশ করা হয় এবং একটি এলোমেলো
WebDAV ব্যবহারকারীর নাম/পাসওয়ার্ড জোড়া তৈরি করা হয়:

```bash
# একটি ভল্ট ডিরেক্টরির জন্য WebDAV সিঙ্ক সক্রিয় করুন (ব্যবহারকারীর নাম/পাসওয়ার্ড তৈরি করে)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV সিঙ্কের স্থিতি পান (শুধু সক্রিয় থাকা অবস্থায় ক্রেডেনশিয়াল ফেরত দেওয়া হয়)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV সিঙ্ক নিষ্ক্রিয় করুন (ক্রেডেনশিয়াল + পরিচালিত .stignore মুছে দেয়)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### প্রতি-API-কী কনটেক্সট উৎস (ঐচ্ছিক)

`api_key_context_sources` টেবিলের মাধ্যমে Obsidian কনফিগকে **প্রতি API কী অনুযায়ী**
স্কোপ করা যায় (`src/lib/db/apiKeyContextSources.ts`)। যখন কোনো MCP কলে একটি
প্রমাণীকৃত API কী id থাকে, তখন `getObsidianConfigForApiKey()` সেই কী-এর নিজস্ব
টোকেন/বেস-URL/ভল্ট-পাথকে (`source: "api_key"`) অগ্রাধিকার দেয়; অন্যথায় এটি
গ্লোবাল কনফিগে (`source: "global"`) ফলব্যাক করে।

## MCP টুলসমূহ (22)

`open-sse/mcp-server/tools/obsidianTools.ts`-এ সংজ্ঞায়িত। টোকেন/base-URL প্রতিটি কলের জন্য নির্ধারিত হয় (প্রথমে প্রতি-API-key, তারপর গ্লোবাল)। OmniRoute **sync server**-এ অনুরোধ পাঠানো টুলগুলোর (চারটি `obsidian_sync_*` টুল) জন্য অতিরিক্তভাবে OmniRoute সেটিংসে কনফিগার করা sync auth token প্রয়োজন।

| `obsidian_search_simple`     | নোটের কনটেন্টে পূর্ণ-পাঠ অনুসন্ধান; ফাইল পাথসহ স্নিপেট প্রদান করে।                                  |
| `obsidian_search_structured` | একটি JSON Logic expression (and/or/regex/path ফিল্টার) ব্যবহার করে অনুসন্ধান করে।                   |
| `obsidian_read_note`         | vault-relative পাথ অনুযায়ী একটি নোট পড়ে; ঐচ্ছিকভাবে নির্দিষ্ট heading/block/frontmatter পড়ে।     |
| `obsidian_list_vault`        | vault-এর ফাইল ও ডিরেক্টরিগুলো তালিকাভুক্ত করে (এন্ট্রির ট্রি)।                                      |
| `obsidian_get_document_map`  | নোটের heading কাঠামোকে headings → line numbers-এর ম্যাপ হিসেবে প্রদান করে।                          |
| `obsidian_get_note_metadata` | সম্পূর্ণ কনটেন্ট ছাড়াই frontmatter, tags, links এবং char/word count প্রদান করে।                    |
| `obsidian_get_active_file`   | Obsidian-এ বর্তমানে সক্রিয় ফাইলের পাথ + কনটেন্ট প্রদান করে।                                        |
| `obsidian_get_periodic_note` | একটি তারিখের দৈনিক/সাপ্তাহিক/মাসিক periodic note প্রদান করে (বাদ দিলে আজকের তারিখ)।                 |
| `obsidian_get_tags`          | vault-এর সব tag তাদের frequency-সহ তালিকাভুক্ত করে।                                                 |
| `obsidian_list_commands`     | উপলভ্য Obsidian command ID-গুলো তালিকাভুক্ত করে (`obsidian_execute_command`-এর সঙ্গে ব্যবহার করুন)। |
| `obsidian_sync_status`       | OmniRoute sync server-এর অবস্থা: চালু আছে কি না, vault-এর নাম, port, uptime, সর্বশেষ sync।          |
| `obsidian_sync_conflicts`    | অমীমাংসিত sync conflict-গুলো তালিকাভুক্ত করে (পাথ, conflict পাথ, শনাক্তকরণের সময়)।                 |

### রাইট টুলসমূহ (`write:obsidian`)

| টুল                              | বিবরণ                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | প্রদত্ত Markdown কনটেন্ট দিয়ে একটি নোট তৈরি বা ওভাররাইট করে।                               |
| `obsidian_append_note`           | একটি নোটে কনটেন্ট যোগ করে; ঐচ্ছিকভাবে নির্দিষ্ট heading/block-এ।                            |
| `obsidian_patch_note`            | কোনো heading, block বা frontmatter field-এ নির্দিষ্টভাবে append/prepend/replace করে।        |
| `obsidian_delete_note`           | vault থেকে একটি নোট স্থায়ীভাবে মুছে দেয়।                                                  |
| `obsidian_move_note`             | vault-এর মধ্যে একটি নোট স্থানান্তর করে বা নাম পরিবর্তন করে।                                 |
| `obsidian_execute_command`       | কোনো Obsidian command তার command ID দিয়ে কার্যকর করে।                                     |
| `obsidian_open_file`             | Obsidian-এ একটি ফাইল খোলে (ফাইলটি না থাকলে তৈরি করে)।                                       |
| `obsidian_sync_trigger`          | তাৎক্ষণিক দ্বিমুখী desktop↔mobile vault sync ট্রিগার করে।                                   |
| `obsidian_sync_resolve_conflict` | একটি sync conflict সমাধান করে: `local` (mobile), `remote` (desktop), অথবা `keep-both` রাখে। |

> [!NOTE]
> `obsidian_patch_note`-এর target-গুলো `heading | block | frontmatter` মানের `targetType`
> এবং `append | prepend | replace` মানের `operation` গ্রহণ করে, সঙ্গে একটি ঐচ্ছিক
> `createTargetIfMissing`। চারটি `obsidian_sync_*` টুল স্থানীয় sync
> server-এর (`http://127.0.0.1:27781` ডিফল্টভাবে) সঙ্গে যোগাযোগ করে এবং sync token প্রয়োজন।

### স্কোপসমূহ

রিড টুলগুলোর জন্য `read:obsidian` প্রয়োজন; রাইট টুলগুলোর জন্য `write:obsidian` প্রয়োজন। প্রয়োগব্যবস্থা
Notion-এর মতোই — `open-sse/mcp-server/server.ts`-এ থাকা `withScopeEnforcement()` দ্বারা পরিচালিত,
`OMNIROUTE_MCP_ENFORCE_SCOPES=true`-এর ভিত্তিতে নিয়ন্ত্রিত, যেখানে অনুমোদিত স্কোপগুলো
`OMNIROUTE_MCP_SCOPES` অথবা API key-এর scope context থেকে নেওয়া হয়। দেখুন
[MCP-SERVER.md](./MCP-SERVER.md)।

## এন্ডপয়েন্টসমূহ

| মেথড     | পাথ                             | উদ্দেশ্য                                                     |
| -------- | ------------------------------- | ------------------------------------------------------------ |
| `GET`    | `/api/settings/obsidian`        | `{ connected, hasToken, baseUrl, vaultPath }` রিটার্ন করে।   |
| `POST`   | `/api/settings/obsidian`        | টোকেন সংরক্ষণ + যাচাই করে (`27124` পোর্ট প্রত্যাখ্যান করে)।  |
| `DELETE` | `/api/settings/obsidian`        | সংযোগ বিচ্ছিন্ন করে (সংরক্ষিত টোকেন মুছে দেয়)।              |
| `GET`    | `/api/settings/obsidian/webdav` | সক্রিয় থাকা অবস্থায় WebDAV সিঙ্কের স্থিতি + শংসাপত্র দেয়। |
| `POST`   | `/api/settings/obsidian/webdav` | একটি ভল্ট ডিরেক্টরির জন্য WebDAV সিঙ্ক সক্রিয় করে।          |
| `DELETE` | `/api/settings/obsidian/webdav` | WebDAV সিঙ্ক নিষ্ক্রিয় করে।                                 |

> এগুলো ড্যাশবোর্ড সেটিংসের রুট। ভল্টটিতে প্রবেশ করা হয় Obsidian
> Local REST API (কনফিগার করা `base_url`) এবং উপরের MCP টুলগুলোর মাধ্যমে — কোনো
> সর্বজনীন `/v1` Obsidian প্রক্সি এন্ডপয়েন্ট নেই।

## ব্যবহারের ক্ষেত্রসমূহ

- **ভল্ট-ভিত্তিক উত্তর** — প্রথমে `obsidian_search_simple` / `obsidian_search_structured`,
  এরপর `obsidian_read_note`, যাতে কোনো এজেন্ট আপনার প্রকৃত নোট থেকে উত্তর দেয়।
- **নোট লেখা / জার্নালিং** — এজেন্টের আউটপুট, সারাংশ বা দৈনিক নোট
  (`obsidian_get_periodic_note`) ভল্টে সংরক্ষণ করতে `obsidian_write_note`, `obsidian_append_note`, অথবা
  নির্দিষ্ট অংশে পরিবর্তনের জন্য `obsidian_patch_note` ব্যবহার করুন।
- **ভল্ট নেভিগেশন** — পড়া/লেখার আগে কাঠামো অন্বেষণ করতে `obsidian_list_vault`, `obsidian_get_document_map`, এবং
  `obsidian_get_tags` ব্যবহার করুন।
- **Obsidian অটোমেশন** — কোনো এজেন্ট থেকে প্লাগইন/কমান্ড পরিচালনা করতে
  `obsidian_list_commands` + `obsidian_execute_command`; UI-তে কোনো নোট দেখাতে `obsidian_open_file` ব্যবহার করুন।
- **মোবাইল সিঙ্ক** — WebDAV সিঙ্ক সক্রিয় করুন, এরপর ডেস্কটপ↔মোবাইল সমন্বয় এবং দ্বন্দ্ব সমাধান করতে
  `obsidian_sync_trigger` / `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  ব্যবহার করুন।
