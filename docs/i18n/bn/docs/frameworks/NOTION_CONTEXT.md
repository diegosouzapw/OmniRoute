> সংযোগের লজিক `open-sse/mcp-server/server.ts`-এ রয়েছে।

## এটি কী

OmniRoute একটি **Notion** ওয়ার্কস্পেসের সঙ্গে **কনটেক্সট সোর্স** হিসেবে সংযুক্ত হতে পারে — এটি একটি পঠন/লিখনযোগ্য
নলেজ বেস, যা এজেন্টরা বিল্ট-ইন MCP সার্ভারের মাধ্যমে ব্যবহার করে। একটি Notion
ইন্টিগ্রেশন টোকেন কনফিগার করার পর, MCP টুলগুলো কোনো LLM-কে পেজ ও ডেটাবেস অনুসন্ধান,
পেজের কনটেন্ট ও ব্লক ট্রি পড়া, ফিল্টার/সর্ট ব্যবহার করে ডেটাবেস কোয়েরি করা এবং নতুন
ব্লক যোগ করার সুযোগ দেয় — সবকিছু OmniRoute-এর মাধ্যমে প্রক্সি করা হয় (রিট্রাই, টাইমআউট ও ত্রুটি শ্রেণিবিন্যাসসহ),
ফলে মডেলটি কখনোই সরাসরি Notion API ব্যবহার করে না।

ইন্টিগ্রেশনটি অফিসিয়াল Notion REST API-এর ওপর তৈরি একটি হালকা ও শক্তিশালী র্যাপার
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`)। ক্লায়েন্টটি
(`src/lib/notion/api.ts`) যা যোগ করে:

- `429` ও `5xx`-এর জন্য **এক্সপোনেনশিয়াল ব্যাকঅফসহ রিট্রাই** (সর্বোচ্চ ৩টি প্রচেষ্টা)।
- `AbortController`-এর মাধ্যমে **৫৫-সেকেন্ডের রিকোয়েস্ট টাইমআউট**।
- **টাইপযুক্ত ত্রুটি শ্রেণিবিন্যাস** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  নির্দেশনা মেনে চলে), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`।
- **বার্তা স্যানিটাইজেশন**, যা প্রদর্শনের আগে স্ট্যাক-ট্রেস-সদৃশ অংশ সরিয়ে দেয়।

## সেটআপ

Notion টোকেনের জন্য **কোনো এনভায়রনমেন্ট ভেরিয়েবল নেই** — এটি
`src/lib/db/notion.ts`-এর মাধ্যমে SQLite `key_value` টেবিলে (নেমস্পেস `notion`, কী `integration_token`)
সংরক্ষণ করা হয়। Endpoint ড্যাশবোর্ডের **Context Sources** ট্যাব থেকে
(`ObsidianSourceCard`-এর সহোদর `NotionSourceCard`), অথবা সেটিংস REST API-এর মাধ্যমে এটি কনফিগার করুন।

> [!NOTE]
> টোকেনটি একটি **Notion অভ্যন্তরীণ ইন্টিগ্রেশন টোকেন**। এখানে একটি ইন্টিগ্রেশন তৈরি করুন:
> <https://www.notion.com/my-integrations>, এরপর OmniRoute-কে যেসব পেজ/ডেটাবেসে
> প্রবেশাধিকার দিতে চান, সেগুলো ওই ইন্টিগ্রেশনের সঙ্গে শেয়ার করুন (Notion-এর অনুমতি মডেলটি শেয়ার-ভিত্তিক,
> পুরো ওয়ার্কস্পেসভিত্তিক নয়)।

### REST-এর মাধ্যমে কনফিগার করুন

```bash
# ইন্টিগ্রেশন টোকেন সংরক্ষণ + যাচাই করুন (POST একটি পরীক্ষামূলক অনুসন্ধান চালিয়ে যাচাই করে)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# সংযোগের অবস্থা পরীক্ষা করুন
curl http://localhost:20128/api/settings/notion

# সংযোগ বিচ্ছিন্ন করুন (সংরক্ষিত টোকেন মুছে দেয়)
curl -X DELETE http://localhost:20128/api/settings/notion
```

তিনটি মেথডের সবগুলোর জন্যই ড্যাশবোর্ড প্রমাণীকরণ (`isAuthenticated`) প্রয়োজন। `POST`-এর ক্ষেত্রে,
OmniRoute টোকেনটি সংরক্ষণ করে এবং সঙ্গে সঙ্গে ১টি ফলাফলের একটি পরীক্ষামূলক অনুসন্ধান চালায়; Notion
কোনো ত্রুটি অবজেক্ট ফেরত দিলে টোকেনটি মুছে ফেলা হয় এবং কলটি `400` সহ ব্যর্থ হয়।

## MCP টুলসমূহ (৬টি)

`open-sse/mcp-server/tools/notionTools.ts`-এ সংজ্ঞায়িত। কলের সময়
`getNotionToken()`-এর মাধ্যমে টোকেন নির্ধারণ করা হয়; কোনো টোকেন কনফিগার করা না থাকলে টুলটি
`"Notion integration token not configured. Set it in Settings > Context Sources."`
ত্রুটি নিক্ষেপ করে।

| টুল                          | স্কোপ          | বিবরণ                                                                                      |
| ---------------------------- | -------------- | ------------------------------------------------------------------------------------------ |
| `notion_search`              | `read:notion`  | টেক্সট কোয়েরি দিয়ে পেজ ও ডেটাবেস অনুসন্ধান করে (শিরোনাম, ID ও URL ফেরত দেয়)। পেজিনেটেড। |
| `notion_get_page`            | `read:notion`  | ID দিয়ে একটি পেজের কনটেন্ট ও মেটাডেটা সংগ্রহ করে।                                         |
| `notion_list_block_children` | `read:notion`  | একটি ব্লক বা পেজের সব চাইল্ড ব্লক তালিকাভুক্ত করে (ব্লক ট্রি)। পেজিনেটেড।                  |
| `notion_query_database`      | `read:notion`  | ঐচ্ছিক `filter` + `sorts` (Notion API ফরম্যাট) দিয়ে একটি ডেটাবেস কোয়েরি করে। পেজিনেটেড।  |
| `notion_get_database`        | `read:notion`  | ID দিয়ে একটি ডেটাবেসের স্কিমা/মেটাডেটা সংগ্রহ করে।                                        |
| `notion_append_blocks`       | `write:notion` | বিদ্যমান কোনো ব্লক বা পেজে চাইল্ড ব্লক যোগ করে (প্রতি রিকোয়েস্টে সর্বোচ্চ ১০০টি ব্লক)।    |

### ইনপুট প্যারামিটার

- `notion_search` — `query` (১–৫০০ অক্ষর), `pageSize` (১–১০০, ডিফল্ট ২০),
  `startCursor` (ঐচ্ছিক)।
- `notion_get_page` — `pageId` (৩২-অক্ষরের হেক্স বা UUID)।
- `notion_list_block_children` — `blockId`, `pageSize` (১–১০০, ডিফল্ট ৫০),
  `startCursor` (ঐচ্ছিক)।
- `notion_query_database` — `databaseId`, `filter` (ঐচ্ছিক, Notion ফিল্টার ফরম্যাট),
  `sorts` (ঐচ্ছিক অ্যারে), `pageSize` (১–১০০, ডিফল্ট ৫০), `startCursor` (ঐচ্ছিক)।
- `notion_get_database` — `databaseId`।
- `notion_append_blocks` — `blockId`, `children` (ব্লক অবজেক্টের অ্যারে),
  `after` (ঐচ্ছিক অবস্থান)।

### স্কোপসমূহ

পঠন টুলগুলোর জন্য `read:notion` এবং লিখন টুলটির জন্য `write:notion` প্রয়োজন।
শুধু `OMNIROUTE_MCP_ENFORCE_SCOPES=true` হলে
`open-sse/mcp-server/server.ts`-এর `withScopeEnforcement()` দ্বারা স্কোপ প্রয়োগ করা হয়;
কলারের অনুমোদিত স্কোপগুলো `OMNIROUTE_MCP_SCOPES` (কমা দিয়ে পৃথক করা) অথবা
প্রমাণীকৃত API কী-এর স্কোপ কনটেক্সট থেকে আসে। সম্পূর্ণ স্কোপ মডেলের জন্য
[MCP-SERVER.md](./MCP-SERVER.md) দেখুন।

## এন্ডপয়েন্টসমূহ

| মেথড     | পাথ                    | উদ্দেশ্য                                        |
| -------- | ---------------------- | ----------------------------------------------- |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` ফেরত দেয়।            |
| `POST`   | `/api/settings/notion` | ইন্টিগ্রেশন টোকেন সংরক্ষণ ও যাচাই করে।          |
| `DELETE` | `/api/settings/notion` | সংযোগ বিচ্ছিন্ন করে (সংরক্ষিত টোকেন মুছে দেয়)। |

> এগুলো ড্যাশবোর্ড সেটিংস রুট। কোনো পাবলিক `/v1` Notion প্রক্সি
> এন্ডপয়েন্ট **নেই** — Notion-এ শুধু উপরের MCP টুলগুলোর মাধ্যমেই পৌঁছানো হয়।

## ব্যবহারের ক্ষেত্রসমূহ

- **জ্ঞানভিত্তিক উত্তর** — উত্তর দেওয়ার আগে কোনো এজেন্টকে ওয়ার্কস্পেসে `notion_search`
  এবং শীর্ষ ফলাফলে `notion_get_page` ব্যবহার করতে দিন, যাতে উত্তরে প্রকৃত অভ্যন্তরীণ ডকুমেন্টের উদ্ধৃতি থাকে।
- **ডেটাবেস-সমর্থিত ওয়ার্কফ্লো** — ফিল্টার ও সর্টসহ কোনো টাস্ক/CRM ডেটাবেসে
  `notion_query_database` ব্যবহার করুন, এরপর সারিগুলো সংক্ষেপে উপস্থাপন বা অগ্রাধিকার অনুযায়ী বাছাই করুন।
- **ফেরত লেখা / লগিং** — বিদ্যমান কোনো পৃষ্ঠায় মিটিং নোট, রান
  সারাংশ বা এজেন্টের আউটপুট যোগ করতে `notion_append_blocks` ব্যবহার করুন (শুধু সংযোজনযোগ্য; কোনো ধ্বংসাত্মক সম্পাদনা নয়)।
- **কাঠামো অন্বেষণ** — কোনো পৃষ্ঠার ব্লক ট্রি পর্যায়ক্রমে দেখতে `notion_list_block_children`
  অথবা কোনো ডেটাবেসে কোয়েরি করার আগে সেটির প্রপার্টি স্কিমা জানতে `notion_get_database` ব্যবহার করুন।
