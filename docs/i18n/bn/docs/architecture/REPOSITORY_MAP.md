## `open-sse/` — স্ট্রিমিং ইঞ্জিন ওয়ার্কস্পেস

পৃথক npm ওয়ার্কস্পেস (`@omniroute/open-sse`)। রিকোয়েস্ট প্রক্রিয়াকরণ + প্রোভাইডার এক্সিকিউশন পরিচালনা করে।

```
open-sse/
├── handlers/            # ১৬টি ফাইল (১২টি হ্যান্ডলার + ৪টি হেল্পার): chatCore, responsesHandler, embeddings, audio, image, video, music, rerank, moderations, search ইত্যাদি।
├── executors/           # ৬৭টি প্রোভাইডার-নির্দিষ্ট এক্সিকিউটর (BaseExecutor এক্সটেন্ড করে)
├── translator/          # ফরম্যাট কনভার্টার (৯টি রিকোয়েস্ট, ৯টি রেসপন্স, ৯টি হেল্পার)
├── transformer/         # Responses API ↔ Chat Completions (TransformStream)
├── services/            # ~৮০টির বেশি সার্ভিস মডিউল (combo, accountFallback, autoCombo, reasoningCache, claude code/chatgpt stealth, modelDeprecation, taskAwareRouter, workflowFSM ইত্যাদি)
├── mcp-server/          # MCP সার্ভার (১১০টি টুল, ৩টি ট্রান্সপোর্ট, ৩৩টি স্কোপ)
├── config/              # প্রোভাইডার/মডেল রেজিস্ট্রি, হেডার কনফিগ, মডেল অ্যালিয়াস
├── utils/               # TLS ক্লায়েন্ট, প্রক্সি fetch/dispatcher, নেটওয়ার্ক হেল্পার
├── index.ts             # ওয়ার্কস্পেস এন্ট্রি
├── package.json         # ওয়ার্কস্পেস ম্যানিফেস্ট
├── tsconfig.json        # ওয়ার্কস্পেস TS কনফিগ
└── types.d.ts           # ওয়ার্কস্পেস টাইপ ডিক্লারেশন
```

## নেভিগেশন পরামর্শ

- **নতুন অবদানকারী?** `CONTRIBUTING.md` → `CLAUDE.md` → `docs/architecture/ARCHITECTURE.md` → `docs/architecture/CODEBASE_DOCUMENTATION.md` পড়ুন।
- **কোনো প্রোভাইডার যোগ করছেন?** `docs/architecture/ARCHITECTURE.md § Adding a New Provider` অনুসরণ করুন + `docs/reference/PROVIDER_REFERENCE.md` দিয়ে যাচাই করুন।
- **কোনো রুট যোগ করছেন?** `docs/architecture/ARCHITECTURE.md § Adding a New API Route` + `src/shared/validation/schemas.ts` দেখুন।
- **কোনো MCP টুল যোগ করছেন?** `docs/frameworks/MCP-SERVER.md § Adding a Tool` দেখুন।
- **কোনো A2A স্কিল যোগ করছেন?** `docs/frameworks/A2A-SERVER.md § Adding a New Skill` দেখুন।
- **লোকালি চালাচ্ছেন?** `docs/guides/SETUP_GUIDE.md` দেখুন।
- **ডিপ্লয় করছেন?** `docs/guides/DOCKER_GUIDE.md` / `docs/ops/VM_DEPLOYMENT_GUIDE.md` / `docs/ops/FLY_IO_DEPLOYMENT_GUIDE.md` দেখুন।
- **রিলিজ করছেন?** `docs/ops/RELEASE_CHECKLIST.md` (এবং `/generate-release-cc` Claude Code স্কিল) দেখুন।
