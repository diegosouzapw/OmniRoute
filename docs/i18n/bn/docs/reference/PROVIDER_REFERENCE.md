## বিভাগসমূহ

- **বিনামূল্যে** — API key-সহ বিনামূল্যের স্তর (dashboard-এর মাধ্যমে কনফিগার করা হয়)
- **No-auth** — সর্বজনীন endpoint, যার জন্য কোনো key বা sign-in একেবারেই প্রয়োজন হয় না
- **OAuth** — sign-in প্রক্রিয়া OmniRoute পরিচালনা করে, কোনো API key প্রয়োজন নেই
- **Web cookie** — cookie auth-এর মাধ্যমে প্রোভাইডারের web app-কে আবৃত করে
- **API key** — API key-এর মাধ্যমে কনফিগার করা পেইড প্রোভাইডার (বিনামূল্যের credit প্রযোজ্য হতে পারে)
- **Local** — ব্যবহারকারীর মেশিনে চলে (Ollama, LM Studio, vLLM ইত্যাদি)
- **Search** — web search প্রোভাইডার
- **Audio** — শুধুমাত্র audio প্রোভাইডার (TTS/STT)
- **Upstream proxy** — যেসব প্রোভাইডার অন্য প্রোভাইডারের কাছে proxy করে
- **Cloud agent** — দীর্ঘ সময় ধরে চলা coding agent (Codex Cloud, Devin, Jules)
- **System** — OmniRoute-এর অভ্যন্তরীণ প্রোভাইডার (loopback ইত্যাদি)

অতিরিক্ত tag: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`।

`Tool calling` (যেখানে দেখানো হয়েছে): `native` — প্রকৃত function-calling API; `emulated` — `tools` array-টি `webTools.ts`-এর মাধ্যমে prompt-emulated হয় (regex দিয়ে parse করা `<tool>{...}</tool>` block); `none` — বর্তমানে `tools` নীরবে বাদ দেওয়া হয়। #7286 দেখুন।

প্রতিটি প্রোভাইডার সক্রিয়, কনফিগার ও পরীক্ষা করতে `/dashboard/providers`-এ থাকা dashboard ব্যবহার করুন।
