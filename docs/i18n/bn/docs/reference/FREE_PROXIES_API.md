OmniRoute `free_proxies` টেবিলে বিনামূল্যের প্রক্সিগুলোর একটি বাছাইকৃত সংগ্রহ সরবরাহ করে,
যা বহিরাগত প্রদানকারীদের (1proxy, proxifly, iplocate, webshare) থেকে সিঙ্ক করা হয়। ড্যাশবোর্ডে
এগুলো **Settings → Free Proxies**-এর অধীনে দেখানো হয়। এই নথিতে তালিকা রুটে উপলভ্য
সার্ভার-সাইড ফিল্টারিং, সর্টিং, গণনা এবং সিঙ্ক-ত্রুটি রিপোর্টিং
বর্ণনা করা হয়েছে।

## তালিকা রুট — `GET /api/settings/free-proxies`

মোট গণনাসহ ফিল্টার করা, সাজানো এবং পৃষ্ঠাভিত্তিক একটি অংশ ফেরত দেয়। ফিল্টারিং এবং
গণনা SQL-এ সম্পন্ন হয়, ফলে UI প্রতিটি সারি মেমরিতে লোড না করেই প্রকৃত মোট সংখ্যা
(যেমন `Total: 0`) দেখাতে পারে।

### কোয়েরি প্যারামিটার

| প্যারামিটার       | ধরন                                | ডিফল্ট    | অর্থ                                                                                                              |
| ----------------- | ---------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------- |
| `search`          | স্ট্রিং                            | `""`      | হোস্ট (এবং সোর্স) কলামে কেস-সংবেদনশীল `LIKE`।                                                                     |
| `protocol`        | স্ট্রিং                            | `""`      | `type` ফিল্টার: `http` / `https` / `socks4` / `socks5`। খালি = সব।                                                |
| `country`         | স্ট্রিং                            | `""`      | `countryCode` ফিল্টার (ISO-2)। খালি = সব।                                                                         |
| `minQuality`      | সংখ্যা                             | `0`       | শুধু `qualityScore >= minQuality` হওয়া সারিগুলো। `0` = কোনো সর্বনিম্ন সীমা নেই।                                  |
| `disabledSources` | স্ট্রিং                            | `""`      | বাদ দেওয়ার জন্য কমা দিয়ে পৃথক করা সোর্স আইডি (যেমন `proxifly,webshare`)।                                        |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = স্কোর অবরোহী; `latency` = ল্যাটেন্সি ঊর্ধ্বক্রমে (null সবার শেষে); `recent` = `lastValidated` অবরোহী। |
| `offset`          | সংখ্যা                             | `0`       | পেজিনেশন শুরুর অবস্থান।                                                                                           |
| `limit`           | সংখ্যা                             | `50`      | পৃষ্ঠার আকার (সার্ভার-সাইডে সীমাবদ্ধ)।                                                                            |

### প্রতিক্রিয়া

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["আপস্ট্রিম থেকে HTTP 429"],
    "webshare": ["নেটওয়ার্ক টাইমআউট"]
  }
}
```

`total` পেজিনেশনের **আগের** ফিল্টার করা মোট সংখ্যা নির্দেশ করে, ফলে UI
`Total: N` এবং `hasMore` স্বাধীনভাবে রেন্ডার করতে পারে। `syncErrors` সোর্স আইডি দিয়ে কী করা থাকে এবং
শুধু যেসব সোর্সের সর্বশেষ সিঙ্ক ব্যর্থ হয়েছে সেগুলোর জন্য পূরণ করা হয় — কোনো `Total: 0` ফলাফল
কখনো নীরব থাকে না।

## পুলে যোগ করা — `POST /api/settings/free-proxies/[id]/add-to-pool`

একটি বিনামূল্যের প্রক্সিকে পরিচালিত `proxy_registry` পুলে উন্নীত করে। প্রথমে
আপস্ট্রিম যাচাই করে; সফল হলে নতুন পুল প্রক্সির আইডি এবং পরিমাপ করা ল্যাটেন্সি ফেরত দেয়।

## সিঙ্ক — `POST /api/settings/free-proxies/sync`

সক্রিয় সব সোর্স (অথবা `{ "sources": [...] }`-এ থাকা উপসেট) পুনরায় সংগ্রহ করে। প্রতিটি
সোর্স স্বাধীনভাবে সিঙ্ক হয়; ব্যর্থ সোর্স `syncErrors`-এ রেকর্ড করা হয় এবং
অন্যগুলো তবুও সম্পন্ন হয়, ফলে আংশিক সিঙ্ক কখনো আগের ভালো ডেটা মুছে ফেলে না।

## পরিসংখ্যান — `GET /api/settings/free-proxies/stats`

সারির পেলোড ছাড়াই `total / inPool / avgQuality / bySource / lastSyncAt` সমষ্টি
ফেরত দেয় — ড্যাশবোর্ডের হেডার উইজেটগুলো এটি ব্যবহার করে।
