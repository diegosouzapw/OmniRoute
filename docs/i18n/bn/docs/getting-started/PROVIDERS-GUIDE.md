> **সংক্ষেপে**: একটি প্রোভাইডার হলো কোনো AI পরিষেবার সঙ্গে সংযোগ (যেমন OpenAI, Anthropic, Google)। OmniRoute ব্যবহার করতে আপনার অন্তত একটি প্রোভাইডার প্রয়োজন।

---

## প্রোভাইডার কী?

একটি প্রোভাইডারকে **মোবাইল অপারেটর** হিসেবে ভাবুন। কল করার জন্য যেমন একটি মোবাইল অপারেটর প্রয়োজন, তেমনি AI মডেল ব্যবহার করতে আপনার একটি AI প্রোভাইডার প্রয়োজন। OmniRoute এমন একটি ফোনের মতো, যা **সব অপারেটরের** সঙ্গে কাজ করে — আপনি স্বয়ংক্রিয়ভাবে তাদের মধ্যে পরিবর্তন করতে পারেন।

### প্রোভাইডারের ধরন

| ধরন            | এটি কী                          | উদাহরণ                            | খরচ                               |
| -------------- | ------------------------------- | --------------------------------- | --------------------------------- |
| **বিনামূল্যে** | কোনো অর্থপ্রদানের প্রয়োজন নেই  | Kiro, OpenCode Free, Pollinations | $0                                |
| **API Key**    | আপনার একটি API key প্রয়োজন     | OpenAI, Anthropic, Google         | ব্যবহার অনুযায়ী মূল্য            |
| **OAuth**      | আপনার অ্যাকাউন্ট দিয়ে লগইন     | Claude Code, GitHub Copilot       | সাবস্ক্রিপশন                      |
| **Web Cookie** | আপনার ব্রাউজার সেশন ব্যবহার করে | ChatGPT Web (Codex), Gemini Web   | $0 (আপনার অ্যাকাউন্ট ব্যবহার করে) |

### Web Cookie প্রোভাইডার

সাধারণ সেটআপ নির্দেশনা, সীমাবদ্ধতা, সমস্যা সমাধান এবং প্রোভাইডার-নির্দিষ্ট প্রমাণীকরণ নির্দেশিকার জন্য **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** দেখুন।

## দ্রুত শুরু: আপনার প্রথম প্রোভাইডার সংযুক্ত করুন

### ঐচ্ছিক প্রথমবারের বিনামূল্যের প্রোভাইডার সেটআপ

প্রথমবার চালুর উইজার্ডে একটি স্পষ্ট **বিনামূল্যের প্রোভাইডার সেটআপ করুন** কার্ড রয়েছে। এটি OmniRoute-এর প্রমাণীকরণ-বিহীন প্রোভাইডার রেজিস্ট্রি থেকে বর্তমানে
যোগ্য তালিকা তৈরি করে, তারপর নিশ্চিত করার আগে আপনাকে প্রতিটি
প্রোভাইডার পর্যালোচনা ও অনির্বাচিত করার সুযোগ দেয়। OmniRoute প্রোভাইডারের সতর্কতামূলক বিজ্ঞপ্তি এবং তার সাইটের একটি লিংক দেখায়,
যাতে আপনি প্রথমে তৃতীয় পক্ষের শর্তাবলি, গোপনীয়তা, প্রাপ্যতা এবং রেট লিমিট পর্যালোচনা করতে পারেন।

এই পদক্ষেপটি ঐচ্ছিক: উইজার্ড সম্পন্ন করলে কখনোই নীরবে বিনামূল্যের প্রোভাইডার সংযোগ তৈরি হয় না।
এটি শুধু এখনো অনুপস্থিত প্রোভাইডারগুলো তৈরি করে, বিদ্যমান কাস্টমাইজ করা সংযোগগুলো
অপরিবর্তিত রাখে এবং তৈরি হওয়া, ইতিমধ্যে কনফিগার করা ও ব্যর্থ প্রোভাইডারগুলোর বিষয়ে আলাদাভাবে প্রতিবেদন দেয়। আংশিক ফলাফল পাওয়ার পর
আপনি নিরাপদে শুধু ব্যর্থগুলোই আবার চেষ্টা করতে পারেন।

### বিকল্প A: বিনামূল্যের প্রোভাইডার (ক্রেডিট কার্ডের প্রয়োজন নেই)

1. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
2. **প্রোভাইডার** → **প্রোভাইডার যোগ করুন**-এ যান
3. এই বিনামূল্যের প্রোভাইডারগুলোর যেকোনো একটি নির্বাচন করুন:
   - **Kiro AI** — বিনামূল্যের Claude মডেল (প্রমাণীকরণের প্রয়োজন নেই)
   - **OpenCode Free** — বিনামূল্যের GPT মডেল (প্রমাণীকরণের প্রয়োজন নেই)
   - **Pollinations** — বিনামূল্যের GPT-5, Claude, Gemini (key-এর প্রয়োজন নেই)
   - **LongCat** — 10M tokens বিনামূল্যে (এককালীন বরাদ্দ, অ্যাকাউন্ট + KYC প্রয়োজন)
   - **Cloudflare AI** — 50+ মডেল, দৈনিক 10K নিউরন
   - **MLX Gemma 26B** — স্থানীয় Apple Silicon মডেল (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — স্থানীয় Apple Silicon মডেল (~9.1 tok/s, ~13.1GB RAM)
4. **সংযুক্ত করুন**-এ ক্লিক করুন
5. সম্পন্ন! এখন আপনার বিনামূল্যে AI ব্যবহারের সুযোগ রয়েছে।

### বিকল্প B: API Key প্রোভাইডার (সশুল্ক)

1. প্রোভাইডারের ওয়েবসাইট থেকে একটি API key নিন:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
3. **প্রোভাইডার** → **প্রোভাইডার যোগ করুন**-এ যান
4. আপনার প্রোভাইডার নির্বাচন করুন
5. আপনার API key পেস্ট করুন
6. **সংযুক্ত করুন**-এ ক্লিক করুন
7. সম্পন্ন! এখন আপনার সেই প্রোভাইডারের মডেলগুলো ব্যবহারের সুযোগ রয়েছে।

### বিকল্প C: OAuth প্রোভাইডার (সাবস্ক্রিপশন)

1. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
2. **প্রোভাইডার** → **প্রোভাইডার যোগ করুন**-এ যান
3. আপনার প্রোভাইডার নির্বাচন করুন (যেমন Claude Code, GitHub Copilot)
4. **OAuth দিয়ে সংযুক্ত করুন**-এ ক্লিক করুন
5. আপনার অ্যাকাউন্ট দিয়ে লগইন করুন
6. সম্পন্ন! এখন আপনার সাবস্ক্রিপশনের মডেলগুলো ব্যবহারের সুযোগ রয়েছে।

### বিকল্প D: স্থানীয় MLX মডেল (Apple Silicon)

ইউনিফায়েড মেমরিসহ Apple Silicon Mac-এর জন্য OmniRoute, `mlx-lm.server`-এর মাধ্যমে চলমান স্থানীয় MLX মডেলগুলোকে নিয়মিত OpenAI-সামঞ্জস্যপূর্ণ স্থানীয় প্রোভাইডার হিসেবে সংযুক্ত করার সুবিধা দেয়।

#### পূর্বশর্ত

- **Apple Silicon Mac** (M1/M2/M3/M4); 24GB+ ইউনিফায়েড মেমরি সুপারিশ করা হয়
- **uv** প্যাকেজ ম্যানেজার: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### দ্রুত শুরু

1. **নির্ভরতা ইনস্টল করুন**:

   ```bash
   # আগে থেকে ইনস্টল করা না থাকলে uv ইনস্টল করুন
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm ইনস্টল করুন
   uv pip install mlx-lm
   ```

2. **MLX সার্ভারগুলো ম্যানুয়ালি চালু করুন** (আলাদা টার্মিনালে):

   ```bash
   # টার্মিনাল 1: Gemma 4 26B A4B IT-QAT (পোর্ট 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # টার্মিনাল 2: Qwen 3.8 27B MLX Mixed (পোর্ট 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ড্যাশবোর্ডে সংযুক্ত করুন**:
   - **প্রোভাইডার** → **প্রোভাইডার যোগ করুন**-এ যান
   - **MLX Gemma 26B** অথবা **MLX Qwen 3.8 27B** নির্বাচন করুন
   - **সংযুক্ত করুন**-এ ক্লিক করুন (কোনো API key প্রয়োজন নেই)

4. **OpenCode-এর সঙ্গে ব্যবহার করুন**:
   ```bash
   # OmniRoute ব্যবহার করার জন্য OpenCode কনফিগার করুন
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX মডেল ব্যবহার করুন
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### মেমরি ব্যবস্থাপনা

**গুরুত্বপূর্ণ**: 24GB ইউনিফায়েড মেমরির ক্ষেত্রে একই সময়ে শুধু **একটি বড় MLX মডেল চলতে পারে**।

- Gemma 26B: সর্বোচ্চ ~15.9GB মেমরি
- Qwen 3.8 27B: সর্বোচ্চ ~13.1GB মেমরি

আপনাকে এটি ম্যানুয়ালি পরিচালনা করতে হবে:

- একই সময়ে শুধু একটি MLX সার্ভার চালান, অথবা
- দুটি আলাদা মেশিনে চালান, অথবা
- অন্যটি চালু করার আগে একটি বন্ধ করুন

OmniRoute স্বয়ংক্রিয়ভাবে MLX সার্ভার প্রসেস পরিচালনা করে না — এটি শুধু আপনার কনফিগার করা OpenAI-সামঞ্জস্যপূর্ণ এন্ডপয়েন্টগুলোতে অনুরোধ রাউট করে।

#### টুল কলিং সমর্থন

উভয় মডেলই OpenAI-সামঞ্জস্যপূর্ণ টুল কলিং সমর্থন করে। এটি দিয়ে পরীক্ষা করুন:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "২+২ কত? ক্যালকুলেটর টুল ব্যবহার করুন।"}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "গণনা করুন", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

## কীভাবে একটি প্রদানকারী সংযুক্ত করবেন (ধাপে ধাপে)

### ধাপ 1: ড্যাশবোর্ড খুলুন

আপনার ব্রাউজারে `http://localhost:20128`-এ যান।

### ধাপ 2: প্রদানকারী বিভাগে যান

সাইডবারে **প্রদানকারী**-তে ক্লিক করুন।

### ধাপ 3: প্রদানকারী যোগ করুন-এ ক্লিক করুন

**+ প্রদানকারী যোগ করুন** বোতামে ক্লিক করুন।

### ধাপ 4: আপনার প্রদানকারী নির্বাচন করুন

তালিকাটি দেখুন অথবা আপনার প্রদানকারীকে খুঁজুন। সেটিতে ক্লিক করুন।

### ধাপ 5: পরিচয়পত্র লিখুন

- **বিনামূল্যের প্রদানকারী**: কোনো পরিচয়পত্রের প্রয়োজন নেই — শুধু **সংযুক্ত করুন**-এ ক্লিক করুন
- **API কী প্রদানকারী**: আপনার API কী পেস্ট করুন
- **OAuth প্রদানকারী**: **OAuth দিয়ে সংযুক্ত করুন**-এ ক্লিক করে লগইন করুন

### ধাপ 6: সংযোগ পরীক্ষা করুন

এটি কাজ করছে কি না যাচাই করতে **সংযোগ পরীক্ষা করুন**-এ ক্লিক করুন।

### ধাপ 7: সম্পন্ন!

আপনার প্রদানকারী এখন সংযুক্ত। আপনি এটি `model: "auto"` দিয়ে ব্যবহার করতে পারেন অথবা সরাসরি প্রদানকারী নির্দিষ্ট করতে পারেন।

## একাধিক প্রদানকারী ব্যবহার করা

OmniRoute **একাধিক প্রদানকারীর** সঙ্গে সবচেয়ে ভালো কাজ করে। এতে আপনি পাবেন:

- **স্বয়ংক্রিয় ফলব্যাক** — কোনো প্রদানকারী ব্যর্থ হলে OmniRoute পরবর্তীটি চেষ্টা করে
- **খরচ অপ্টিমাইজেশন** — OmniRoute প্রতিটি অনুরোধের জন্য সবচেয়ে সাশ্রয়ী প্রদানকারী বেছে নেয়
- **গতি অপ্টিমাইজেশন** — OmniRoute প্রতিটি অনুরোধের জন্য সবচেয়ে দ্রুত প্রদানকারী বেছে নেয়
- **মান অপ্টিমাইজেশন** — OmniRoute প্রতিটি কাজের জন্য সেরা প্রদানকারী বেছে নেয়

### প্রস্তাবিত সেটআপ

সেরা অভিজ্ঞতার জন্য অন্তত **3টি প্রদানকারী** সংযুক্ত করুন:

1. **একটি বিনামূল্যের প্রদানকারী** (Kiro, OpenCode Free অথবা Pollinations) — সর্বদা উপলভ্য
2. **একটি দ্রুত প্রদানকারী** (Groq, Cerebras) — দ্রুত প্রতিক্রিয়ার জন্য
3. **একটি উচ্চমানের প্রদানকারী** (OpenAI, Anthropic, Google) — জটিল কাজের জন্য

এরপর `model: "auto"` ব্যবহার করুন এবং OmniRoute প্রতিটি অনুরোধের জন্য স্বয়ংক্রিয়ভাবে সেরা প্রদানকারী বেছে নেবে।

## সাধারণ প্রশ্নাবলি

### "OmniRoute ব্যবহার করতে কি আমাকে অর্থ প্রদান করতে হবে?"

**না!** OmniRoute বিনামূল্যের এবং ওপেন-সোর্স। কোনো অর্থ প্রদান না করেই আপনি বিনামূল্যের প্রোভাইডারগুলো (Kiro, OpenCode Free, Pollinations) ব্যবহার করতে পারেন। আপনি কেবল অর্থপ্রদত্ত প্রোভাইডার ব্যবহার করার সিদ্ধান্ত নিলেই অর্থ প্রদান করবেন।

### "কোন প্রোভাইডার দিয়ে আমার শুরু করা উচিত?"

**Kiro AI** দিয়ে শুরু করুন — এটি বিনামূল্যের, কোনো API কী প্রয়োজন হয় না এবং এটি আপনাকে Claude মডেলগুলো ব্যবহারের সুযোগ দেয়। এরপর প্রয়োজন অনুযায়ী আরও প্রোভাইডার যোগ করুন।

### "আমি কি একই সঙ্গে একাধিক প্রোভাইডার ব্যবহার করতে পারি?"

**হ্যাঁ!** এটাই OmniRoute-এর মূল উদ্দেশ্য। একাধিক প্রোভাইডার সংযুক্ত করুন এবং প্রতিটি অনুরোধের জন্য OmniRoute-কে সেরা প্রোভাইডারটি বেছে নিতে দিতে `model: "auto"` ব্যবহার করুন।

### "কোনো প্রোভাইডার বন্ধ হয়ে গেলে কী হবে?"

OmniRoute স্বয়ংক্রিয়ভাবে ব্যর্থ প্রোভাইডারগুলো এড়িয়ে যায় এবং পরেরটি চেষ্টা করে। আপনাকে কিছুই করতে হবে না।

### "কোনো প্রোভাইডারের সংযোগ কীভাবে বিচ্ছিন্ন করব?"

প্রোভাইডার → প্রোভাইডারটিতে ক্লিক করুন → **সংযোগ বিচ্ছিন্ন করুন**-এ ক্লিক করুন।

### "আমি কি আমার বিদ্যমান API কীগুলো ব্যবহার করতে পারি?"

**হ্যাঁ!** OpenAI, Anthropic, Google ইত্যাদির জন্য আপনার কাছে আগে থেকেই API কী থাকলে, সেগুলো OmniRoute-এ ব্যবহার করতে পারেন। প্রোভাইডার সংযুক্ত করার সময় শুধু সেগুলো পেস্ট করুন।
