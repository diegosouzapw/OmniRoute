## ধাপ 1: OmniRoute ইনস্টল করুন

আপনার পছন্দের পদ্ধতি বেছে নিন:

### বিকল্প A: npm (প্রস্তাবিত)

```bash
npm install -g omniroute
```

### বিকল্প B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` হলো সর্বোচ্চ **প্রকাশিত** স্থিতিশীল SemVer। এটি git `main` অনুসরণ করে **না**। GitOps-এর জন্য `diegosouzapw/omniroute:X.Y.Z` পিন করুন। [ইমেজ ট্যাগ / রিলিজ চ্যানেল](../guides/DOCKER_GUIDE.md#release-channels) দেখুন।

### বিকল্প C: সোর্স থেকে

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## ধাপ 2: OmniRoute চালু করুন

```bash
omniroute
```

OmniRoute `http://localhost:20128`-এ চালু হয়। ড্যাশবোর্ড স্বয়ংক্রিয়ভাবে খুলে যায়।

---

## ধাপ 3: একটি বিনামূল্যের প্রোভাইডার সংযুক্ত করুন

একটি বিনামূল্যের প্রোভাইডার সংযুক্ত করে আপনি **কোনো অর্থ পরিশোধ না করেই** OmniRoute ব্যবহার করতে পারেন।

### বিকল্প A: Kiro (বিনামূল্যের Claude — ক্রেডিট কার্ডের প্রয়োজন নেই)

1. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
2. **Providers** → **Add Provider**-এ যান
3. **Kiro AI** নির্বাচন করুন
4. **Connect**-এ ক্লিক করুন (API key-এর প্রয়োজন নেই!)
5. হয়ে গেছে! এখন Claude মডেলগুলোতে আপনার বিনামূল্যে অ্যাক্সেস রয়েছে।

### বিকল্প B: OpenCode Free (প্রমাণীকরণের প্রয়োজন নেই)

1. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
2. **Providers** → **Add Provider**-এ যান
3. **OpenCode Free** নির্বাচন করুন
4. **Connect**-এ ক্লিক করুন (API key-এর প্রয়োজন নেই!)
5. হয়ে গেছে! এখন একাধিক মডেলে আপনার বিনামূল্যে অ্যাক্সেস রয়েছে।

### বিকল্প C: Pollinations (Key-এর প্রয়োজন নেই)

1. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
2. **Providers** → **Add Provider**-এ যান
3. **Pollinations** নির্বাচন করুন
4. **Connect**-এ ক্লিক করুন (API key-এর প্রয়োজন নেই!)
5. হয়ে গেছে! এখন GPT-5, Claude, Gemini এবং আরও অনেক মডেলে আপনার বিনামূল্যে অ্যাক্সেস রয়েছে।

## ধাপ 4: এটি কাজ করছে কি না যাচাই করুন

[API Keys](http://localhost:20128/dashboard/api-manager) থেকে একটি নতুন key তৈরি করুন। এই key-টি সংরক্ষণ করুন, কারণ এটি আর দেখানো হবে না। মনে রাখবেন, এই key-টি টুলগুলোর OmniRoute অ্যাক্সেস করার জন্য, আপস্ট্রিম প্রোভাইডারগুলো অ্যাক্সেস করার জন্য নয়।

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

আপনার সংযুক্ত মডেলগুলো তালিকাভুক্ত দেখতে পাওয়ার কথা।

## ধাপ 5: আপনার IDE বা CLI-কে OmniRoute-এর দিকে নির্দেশ করুন

আপনার IDE বা CLI টুলে এগুলো সেট করুন:

```
Base URL: http://localhost:20128/v1
API Key:  [Dashboard → Endpoints থেকে কপি করুন]
Model:    auto
```

ব্যস! এখন আপনার IDE স্বয়ংক্রিয় প্রোভাইডার নির্বাচনের মাধ্যমে OmniRoute ব্যবহার করছে।

### IDE উদাহরণ: VSCode/Continue.dev

1. VSCode-এ [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) এক্সটেনশনটি ইনস্টল করুন।
2. নিচের লাইনগুলো যোগ করতে আপনার `~/.continue/config.yaml` আপডেট করুন:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev চ্যাট প্যানে `OmniRoute - Auto` নির্বাচন করুন; এরপর আপনার অনুরোধগুলো OmniRoute-এ পাঠানো হবে।
4. (ঐচ্ছিক) পাঠকের জন্য অনুশীলন—অন্য সব পূর্বনির্মিত কনফিগারেশন দিয়ে `config.yaml` আপডেট করতে আপনার IDE-কে বলুন 😊

### CLI উদাহরণ: Codex CLI

1. আপনার অপারেটিং সিস্টেমে এনভায়রনমেন্ট ভ্যারিয়েবলটি স্থায়ীভাবে সেট করুন।
   macOS/Linux-এর জন্য (আপনার `~/.bashrc` বা `~/.zshrc`-এ যোগ করুন):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows-এর জন্য (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. এবার OmniRoute-এর জন্য কনফিগার করে Codex চালু করা যাক। চালান:

```
omniroute launch-codex --model auto
```

এন্ডপয়েন্ট ও API key নির্দিষ্ট করতে `codex` এবং কমান্ড-লাইন প্যারামিটার ব্যবহার করে আপনি এটি নিজে করতে পারেন, তবে ওপরের কমান্ডটি ব্যবহার করলে OmniRoute আপনার হয়ে সবকিছু পরিচালনা করে।

একই এক-কমান্ডের লঞ্চ জেনেরিক লঞ্চারের মাধ্যমে অন্যান্য CLI-এর ক্ষেত্রেও কাজ করে—`omniroute run <target>` দ্বারা `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` এবং `gemini` সমর্থিত (দেখুন [CLI ইন্টিগ্রেশন](../guides/CLI-INTEGRATIONS.md))।

3. এখন CLI-এর OmniRoute-এ অনুরোধ পাঠানোর কথা।

### আপনার টুল OmniRoute-এ রাউট করছে কি না নিশ্চিত করুন

বাম পাশের সাইডবার থেকে [Monitoring/Logs](http://localhost:20128/dashboard/logs)-এ ক্লিক করে আপনি অনুরোধের বিস্তারিত দেখতে পারেন। সেখানে ক্লিক করে এগোলে আরও বিস্তারিত তথ্য দেখা যাবে। প্রসঙ্গত, আপনার পছন্দের হারনেস থেকে কোন তথ্য পাঠানো হচ্ছে তাও আপনি দেখতে পারেন। শেখা এবং ডিবাগিং—উভয় দৃষ্টিকোণ থেকেই এটি সহায়ক।

## সাধারণ প্রশ্ন

### "আমার কি একটি API key প্রয়োজন?"

**না!** কোনো API key ছাড়াই আপনি বিনামূল্যের প্রোভাইডারগুলো (Kiro, OpenCode Free, Pollinations) ব্যবহার করতে পারেন। শুধু ড্যাশবোর্ডে সেগুলো সংযুক্ত করুন।

### "`auto` কী?"

`auto` OmniRoute-কে প্রতিটি অনুরোধের জন্য স্বয়ংক্রিয়ভাবে সেরা প্রোভাইডার বেছে নিতে বলে। এটি গতি, খরচ, গুণমান এবং প্রাপ্যতা বিবেচনা করে। বিস্তারিত জানতে [Auto-Combo নির্দেশিকা](./AUTO-COMBO-GUIDE.md) দেখুন।

### "এর খরচ কত?"

OmniRoute নিজেই **বিনামূল্যের এবং ওপেন-সোর্স**। আপনি শুধু যেসব প্রোভাইডার ব্যবহার করেন, সেগুলোর জন্য অর্থ প্রদান করবেন। অনেক প্রোভাইডারের বিনামূল্যের টিয়ার রয়েছে—[বিনামূল্যের টিয়ার নির্দেশিকা](./FREE-TIERS-GUIDE.md) দেখুন।

### "আমি কি এটি Claude Code / Cursor / Copilot-এর সঙ্গে ব্যবহার করতে পারি?"

**হ্যাঁ!** OpenAI ফরম্যাট সমর্থন করে এমন যেকোনো টুলের সঙ্গে OmniRoute কাজ করে। শুধু base URL হিসেবে `http://localhost:20128/v1` সেট করুন। নির্দিষ্ট সেটআপ নির্দেশনার জন্য [CLI টুল নির্দেশিকা](../reference/CLI-TOOLS.md) দেখুন।

### "কোনো প্রোভাইডার বন্ধ হয়ে গেলে কী হবে?"

OmniRoute স্বয়ংক্রিয়ভাবে ব্যর্থ প্রোভাইডারগুলো এড়িয়ে পরবর্তীটি চেষ্টা করে। আপনাকে কিছুই করতে হবে না। বিস্তারিত জানতে [Auto-Combo নির্দেশিকা](./AUTO-COMBO-GUIDE.md) দেখুন।
