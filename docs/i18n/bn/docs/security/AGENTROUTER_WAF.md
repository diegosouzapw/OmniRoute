`agentrouter` আপস্ট্রিম গেটওয়ে `messages[].content`-এর ওপর একটি কীওয়ার্ড-ভিত্তিক কনটেন্ট ফিল্টার চালায়। ফিল্টারটি আংশিকভাবে নির্ধারিত (কিছু নির্দিষ্ট বাক্যাংশ সবসময় ব্লক করে) এবং আংশিকভাবে সম্ভাব্যতাভিত্তিক (বার্স্ট-সংবেদনশীল — দ্রুত অনুরোধের পর আরও আক্রমণাত্মক হয়ে ওঠে এবং কিছুক্ষণ অপেক্ষার পর স্বাভাবিক হয়)।

WAF কোনো অনুরোধ ব্লক করলে এটি ফেরত দেয়:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## ফিল্টারের পরিধি

WAF কেবল `messages[].content` পরীক্ষা করে। এটি নিচের বিষয়গুলো পরীক্ষা করে **না**:

- `system` প্রম্পট
- স্ট্রাকচার্ড কনটেন্ট ব্লক (`tool_result`, `tool_use`, `thinking`, `image`)
- টুলের `description` এবং `input_schema` ফিল্ড
- অনুরোধের মেটাডেটা, হেডার বা মডেল আইডি

## সর্বদা-ব্লক হওয়া প্যাটার্ন (কেস-অসংবেদনশীল)

| প্যাটার্ন                         | নোট                                                     |
| --------------------------------- | ------------------------------------------------------- |
| যেকোনো `Lorem ipsum` ভ্যারিয়েন্ট | সম্পূর্ণ লাতিন lorem শব্দভান্ডার ব্লক করা হয়           |
| `language model` (একা)            | "the language model" এবং "large language model" পাস করে |
| `virtual assistant`               | "AI assistant" পাস করে                                  |
| `I'm here to help`                | শুধু "here to help"-ও ব্লক হয়                          |
| `Claude, made by Anthropic`       | শুধু সম্পূর্ণ বাক্যাংশটি                                |

## প্রায়-সর্বদা-ব্লক হওয়া প্যাটার্ন

| প্যাটার্ন                                                    | নোট                                                     |
| ------------------------------------------------------------ | ------------------------------------------------------- |
| `placeholder`                                                | যখন এটি একা থাকে (প্যারামিটারের নাম ইত্যাদি হিসেবে নয়) |
| `dummy data`                                                 | ফিক্সচারের জন্য প্রচলিত সিড বাক্যাংশ                    |
| `foo bar baz`                                                | আদর্শ প্লেসহোল্ডার বাক্যাংশ                             |
| পুনরাবৃত্ত সংক্ষিপ্ত টোকেন (`AAA BBB CCC`, `test test test`) | কীওয়ার্ড স্টাফিং শনাক্তকারী                            |

## লোডের অধীনে আচরণ

অল্প সময়ের মধ্যে প্রায় ৫টি দ্রুত অনুরোধের পর WAF এমন কনটেন্টও ব্লক করা শুরু করে, যা সাধারণত পাস করত। প্রায় ৫–১০ সেকেন্ড নিষ্ক্রিয় থাকার পর বাকেটটি শিথিল হয়। এটি একই IP-এবং-কী-ভিত্তিক রেট লিমিটার, যার কারণে Claude Code বা Codex CLI দ্রুত পরপর একাধিক টুল-ব্যবহার / বার্তা-পাঠানোর কল করলে অনিয়মিতভাবে `400 content-blocked` ত্রুটি দেখা দেয়।

## OmniRoute-এ ইতিমধ্যে প্রয়োগ করা প্রশমন ব্যবস্থা

1. **`open-sse/services/wafRateLimit.ts`** — একটি বার্স্ট গার্ড, যা যেকোনো `agentrouter:*` URL-এ পাঠানো বহির্গামী অনুরোধগুলোর মধ্যে ন্যূনতম 500 ms ব্যবধান নিশ্চিত করে। এই ব্যবধান মানুষের উপলব্ধিযোগ্য বিলম্বের তুলনায় অনেক কম এবং স্বাভাবিক ট্রাফিকে WAF সক্রিয় হওয়া প্রতিরোধ করে।

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — কোনো আপস্ট্রিম `400 content-blocked` ফেরত দিলে এক্সিকিউটর একই URL-এ এক্সপোনেনশিয়াল ব্যাকঅফসহ পুনরায় চেষ্টা করে (1.5 s, 3.0 s, সর্বোচ্চ 2টি প্রচেষ্টা)। ব্যাকঅফের পর WAF সাধারণত শিথিল হয় এবং পুনঃচেষ্টা সফল হয়।

3. **`tests/unit/compression/harness.test.ts`** — টেস্ট ফিক্সচার `longInput`-কে `"lorem ipsum dolor sit amet ".repeat(40)` থেকে `"example content for testing purposes ".repeat(40)`-এ পরিবর্তন করা হয়েছে, যাতে Claude Code যখন `Read` টুলের মাধ্যমে এই ফাইলটি পড়ে, তখন ফাইলের বিষয়বস্তু কোনো `tool_result` ব্লকের মধ্য দিয়ে ফিরে এসে WAF-কে ট্রিগার না করে।

## প্রম্পট ও টুল আউটপুটের জন্য নির্দেশনা

কোনো Claude Code বা Codex CLI সেশনে বারবার `400 content-blocked` দেখা দিলে, সর্বশেষ ব্যবহারকারী বার্তা এবং সর্বশেষ টুল ফলাফলে ওপরের কোনো প্যাটার্ন আছে কি না পরীক্ষা করুন এবং বাক্যটি অন্যভাবে লিখুন। প্রচলিত বিকল্প উপায়:

- `Lorem ipsum …`-এর পরিবর্তে `example text …` অথবা টেস্ট বা ফিক্সচারটি যে প্রকৃত কনটেন্ট মডেল করার চেষ্টা করছে, সেটি ব্যবহার করুন।
- `placeholder` (যখন একা থাকে)-এর পরিবর্তে `example value`, `sample value` অথবা প্রকৃত মান ব্যবহার করুন।
- `language model`-এর পরিবর্তে `large language model` অথবা `the model` ব্যবহার করুন।
- `dummy data`-এর পরিবর্তে `sample data` অথবা বাস্তবসম্মত সিড মান ব্যবহার করুন।
- `I'm here to help` / `here to help`-এর পরিবর্তে আরও নির্দিষ্ট কোনো সূচনা ব্যবহার করুন (যেমন, "I'll review the file you mentioned")।

## আপস্ট্রিমে ফলস পজিটিভ রিপোর্ট করা

বর্তমান ফিল্টারটি অতিরিক্ত আক্রমণাত্মক — এটি `tool_result` ব্লকের মধ্যে থাকা "Lorem ipsum"-ও ব্লক করে, যদিও অপারেটর স্পষ্টতই কোনো প্রম্পট ইনজেক্ট করতে চাননি। যেসব অপারেটর উৎস পর্যায়ে এটি ঠিক করাতে চান, তাঁদের ফলস পজিটিভ রিপোর্ট করতে `agentrouter.org`-এর সঙ্গে যোগাযোগ করা উচিত। ওপরের ব্লকলিস্টটি 2026-08-03 তারিখে আপস্ট্রিম পরীক্ষা করে পাওয়া ব্যবহারিক ফলাফল।
