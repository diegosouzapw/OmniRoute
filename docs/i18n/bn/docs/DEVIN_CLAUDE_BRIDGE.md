`devin-cli-agentic` প্রকৃত Claude Code রানটাইমকে OmniRoute-এর লোকাল Anthropic
Messages এন্ডপয়েন্ট ব্যবহার করতে দেয়, যেখানে অফিসিয়াল Devin CLI ACP stdio-এর মাধ্যমে মডেল
প্রতিক্রিয়া সরবরাহ করে। এটি বিদ্যমান Anthropic, Claude OAuth, Claude Web, অথবা `devin-cli`
প্রোভাইডার পরিবর্তন করে না।

> **বর্তমান অবস্থা: Claude Code `2.1.258`-এ পিন করা হয়েছে; সর্বশেষ অফলাইন ও লাইভ যাচাইকরণ
> `2.1.220`-এ রেকর্ড করা হয়েছিল।** `2.1.220` পিনটি Devin CLI
> `3000.2.17` এবং মডেল `swe-1-7-lightning`-এর মাধ্যমে তিনটি বিচ্ছিন্ন দৃশ্যপট সম্পন্ন করেছে; সেই চূড়ান্ত লাইভ রানটি ক্লায়েন্টের মালিকানাধীন `Read`,
> `Edit`, এবং `Bash` টার্ন, সফল `npm test` ফলাফল, প্রজেক্ট কমান্ড ও স্কিল
> আবিষ্কার, শুধু-Devin রাউটিং, এবং Claude-এ শূন্য বহির্গামী ট্র্যাফিক প্রমাণ করেছে। এরপর পিনটি `2.1.258`-এ
> উন্নীত করা হয়েছিল (OmniRoute-এর Claude পরিচয় যে CLI প্রজন্মের ছদ্মবেশ ধারণ করে, এবং
> যেটি নেটিভভাবে Fable 5.1 টিয়ার সরবরাহকারী প্রথম লাইন)। নতুন পিনে পিন করা বেস ইমেজে ইনস্টলেশন স্তর এবং `claude --version`
> যাচাই করা হয়েছে, এবং ব্রিজ ইউনিট স্যুট, `compose config` ও
> স্ট্যাটিক আইসোলেশন প্রমাণ সফল হয়েছে — তবে অফলাইন মক দৃশ্যপট এবং লাইভ তিন-দৃশ্যপটের
> স্যুটটি এখনো পুনরায় চালানো হয়নি। এই পিনসহ ব্রিজটির ওপর নির্ভর করার আগে সেগুলো পুনরায় চালান
> ("পিন করা টুল আপডেট করা" দেখুন)।

## আর্কিটেকচার

```text
Claude Code 2.1.258 (বিচ্ছিন্ন নন-রুট Linux কনটেইনার)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ফরম্যাট, প্রমাণীকরণবিহীন প্রোভাইডার)
  -> devin acp --agent-type summarizer (অফিসিয়াল ACP stdio, কোনো Devin টুল নেই)
  -> নিবেদিত devin-auth ভলিউমে Devin অ্যাকাউন্ট
```

অফিসিয়াল CLI-এর ডিফল্ট ACP এজেন্ট তার নিজস্ব টুল চালাতে পারে, তাই এই ব্রিজ এটি ব্যবহার
করে না। এটি নির্দিষ্ট `summarizer` ACP এজেন্ট চালু করে, যার অফিসিয়াল CLI মোডে কোনো টুল নেই, এবং
সিরিয়ালাইজ করা Anthropic অনুরোধটিকে একটি এক্সিকিউশন ট্রেস হিসেবে ফ্রেম করে। Claude-এর মালিকানাধীন আরেকটি
অ্যাকশনের প্রয়োজন হলে, প্রতিক্রিয়ায় অবশ্যই ঠিক একটি ক্লায়েন্ট টুল এনভেলপ থাকতে হবে। কোনো ACP
`tool_call` বা `tool_call_update`-কে প্রতিক্রিয়া সফল হিসেবে রিপোর্ট করার আগেই প্রত্যাখ্যান করা হয়।

`open-sse/executors/devin-agentic/serializer.ts`-এর সিরিয়ালাইজারটি `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, এবং
Claude Code সরবরাহ করা টুলগুলো সংরক্ষণ করে। ইমেজ ও অজানা ব্লকগুলো সুস্পষ্টভাবে ব্যর্থ হয়। বড় টুল ফলাফলে
একটি দৃশ্যমান ট্রাঙ্কেশন চিহ্ন ব্যবহার করা হয়।

পার্সারটি প্রতি মডেল টার্নে একটি স্বতন্ত্র `<tool>{...}</tool>` এনভেলপ গ্রহণ করে। এটি
অনুরোধের টুল তালিকার সঙ্গে নামটি যাচাই করে, সেই টুলের JSON
Schema অনুযায়ী আর্গুমেন্ট যাচাই করে, মিশ্র বর্ণনা/অ্যাকশন প্রত্যাখ্যান করে, এবং সীমাবদ্ধ একবার মেরামতের অনুমতি দেয়। এরপর Claude Code
ফলস্বরূপ Anthropic `tool_use` লোকালভাবে চালায় এবং `tool_result`-টি OmniRoute-এর মাধ্যমে
ফেরত পাঠায়।

## আইসোলেশন এবং হুমকি মডেল

হোস্টের Claude ইনস্টলেশন, অ্যাকাউন্ট, এবং কনফিগারেশন এই পরিধির বাইরে এবং সেগুলোকে
নিষিদ্ধ হিসেবে বিবেচনা করা হয়। Compose সার্ভিসগুলো:

- UID/GID `10001:10001` হিসেবে চলে, একটি রিড-অনলি রুট ফাইলসিস্টেম, অপসারিত সক্ষমতা, এবং
  `no-new-privileges` সহ;
- একটি ব্যক্তিগত `/home/bridge`, নিবেদিত Claude কনফিগ ভলিউম, বিচ্ছিন্ন OmniRoute ডেটা,
  এবং একটি পৃথক `devin-auth` ভলিউম ব্যবহার করে;
- শুধু অস্থায়ী `.sandbox` ওয়ার্কস্পেস/প্রমাণ মাউন্ট করে;
- হোস্ট হোম, Keychain, SSH, ক্লাউড ক্রেডেনশিয়াল, বা Docker সকেট মাউন্ট করে না;
- সুস্পষ্ট এনভায়রনমেন্ট নির্মাণ করে এবং Anthropic API/OAuth/রাউটিং ভেরিয়েবল সরিয়ে দেয়;
- একটি শুধু-লোকাল কী দিয়ে Claude Code ইনফারেন্সকে কেবল `http://omniroute:20128`-এ নির্দেশ করে।

অফলাইন প্রোফাইল একটি অভ্যন্তরীণ নেটওয়ার্ক ব্যবহার করে। লাইভ প্রোফাইলে OmniRoute কেবল
`network-guard`-এর মাধ্যমে অফিসিয়াল Devin এন্ডপয়েন্টে পৌঁছায়; সম্পর্কহীন গন্তব্যগুলো প্রত্যাখ্যান করা হয়।
Claude Code-এর একটি পৃথক, সব বহির্গামী ট্র্যাফিক প্রত্যাখ্যানকারী গার্ড রয়েছে এবং এটি `NO_PROXY`-এর মাধ্যমে শুধু লোকাল OmniRoute
সার্ভিসে পৌঁছাতে পারে। গার্ড অডিট ফাইলগুলো কেবল তাদের সংশ্লিষ্ট গার্ড প্রসেস দ্বারা মাউন্ট করা হয়।
স্ক্রিপ্টগুলো টোকেন-মুক্ত প্রমাণ এক্সপোর্ট করার আগে ফাইলের মালিকানা, মোড, লিংক সংখ্যা, এবং প্রতিটি সিদ্ধান্ত
যাচাই করে।

আইসোলেশন প্রমাণটি স্বাধীনভাবে চালান:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

এটি টপোলজি, নামযুক্ত মাউন্ট, নন-রুট/রিড-অনলি সেটিংস, সুস্পষ্ট লোকাল রাউটিং,
সংবেদনশীল এনভায়রনমেন্ট ভেরিয়েবলের অনুপস্থিতি, Docker সকেটের অনুপস্থিতি, `api.anthropic.com`
এবং `claude.ai`-এ ব্লক করা অ্যাক্সেস, শুধু-Devin প্রোভাইডার নির্বাচন, এবং ACP ব্যাকএন্ড
অনুপলব্ধ হলে সুস্পষ্ট ব্যর্থতা যাচাই করে।

## প্রথমবার সেটআপ এবং স্বাভাবিক ব্যবহার

পিন করা ইমেজটি বিল্ড করুন:

```bash
./scripts/devin-bridge/build
```

শুধু বিচ্ছিন্ন Devin ভলিউমটিকে প্রমাণীকরণ করুন:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

লগইন কমান্ডটি রিমোট/কনটেইনার পরিবেশের জন্য নির্ধারিত অফিসিয়াল ম্যানুয়াল-টোকেন প্রবাহ ব্যবহার করে। মানটি সরাসরি CLI প্রম্পটে প্রবেশ করানো হয়; এটি প্রসেস আর্গুমেন্ট হিসেবে পাস করা হয় না, Git-এ লেখা হয় না বা হোস্ট থেকে কপি করা হয় না।

বিচ্ছিন্ন Claude Code রানটাইম চালু করুন:

```bash
./scripts/devin-bridge/launch
```

কনটেইনারভিত্তিক Claude Code শুরু করার আগে `launch` বিচ্ছিন্নতা, Devin প্রমাণীকরণ এবং মডেল অনুসন্ধান পুনরায় পরীক্ষা করে। এটি কখনোই হোস্টের Claude এক্সিকিউটেবল চালায় না। মডেল অ্যালিয়াসগুলো `.env.devin-bridge`-এ সেট করা যেতে পারে; কনফিগার করা প্রতিটি মানে অবশ্যই `devin-cli-agentic/` প্রিফিক্সটি থাকতে হবে।

## যাচাইকরণ কমান্ড

পুনরুৎপাদনযোগ্য অফলাইন পাথটির জন্য কোনো Devin অ্যাকাউন্টের প্রয়োজন হয় না এবং রানটাইমে ইন্টারনেটও লাগে না:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

প্রমাণীকৃত অপ্ট-ইন লাইভ পাথটি হলো:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

ACP সেশনগুলো একসঙ্গে হঠাৎ করে খোলা এড়াতে লাইভ রানারটি দৃশ্যপটগুলোর মধ্যে অপেক্ষা করে এবং পাঠ্য দাবির ওপর নির্ভর করার পরিবর্তে কাঠামোবদ্ধ Claude স্ট্রিম ইভেন্ট যাচাই করে। এর তিনটি দৃশ্যপট প্রমাণ করে:

1. সরাসরি প্রজেক্ট পড়া এবং ত্রুটি বিশ্লেষণ;
2. একটি বাস্তব `Edit`, ক্লায়েন্ট-মালিকানাধীন `Bash` `npm test` এবং একটি টার্মিনাল ফলাফল;
3. `/bridge-check`-এর সঙ্গে `bridge-proof` অনুসন্ধান, প্রজেক্ট পড়া, ক্লায়েন্ট-মালিকানাধীন আরেকটি সফল `npm test` এবং কোনো কাজ অমীমাংসিত না রেখে সম্পন্ন হওয়া।

চূড়ান্ত গেটটি Devin নেটওয়ার্ক অডিটও পরীক্ষা করে এবং Claude এগ্রেস অডিটটি খালি থাকা আবশ্যক করে।

## পিন করা টুল আপডেট করা

ইমেজটি `docker/devin-bridge/Dockerfile`-এ Node, Claude Code এবং Devin CLI-এর সংস্করণ পিন করে। আপডেট করতে:

1. সুনির্দিষ্ট সংস্করণগুলো পরিবর্তন করুন;
2. অফিসিয়াল আর্টিফ্যাক্টের মান দিয়ে উভয় আর্কিটেকচার-নির্দিষ্ট Devin আর্কাইভ চেকসাম প্রতিস্থাপন করুন;
3. পুনরায় বিল্ড করুন এবং প্রতিটি অফলাইন যাচাইকরণ কমান্ড চালান;
4. ইমেজের ভেতরের সংস্করণগুলো নিশ্চিত করুন;
5. প্রমাণীকৃত তিন-দৃশ্যপটের লাইভ স্যুটটি পুনরায় চালান।

হোস্টে কোনো CLI-ই গ্লোবালি ইনস্টল করবেন না বা চেকসাম যাচাইকরণকে অযাচাইকৃত ডাউনলোড দিয়ে প্রতিস্থাপন করবেন না।

## রোগ নির্ণয় এবং পরিষ্কারকরণ

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  স্থানীয় রাউটিং এবং সংবেদনশীল তথ্য অপসারণ করা এক্সিকিউটর ত্রুটি দেখায়।
- `.sandbox/evidence/mock-acp.jsonl` নির্ধারক মক ACP অ্যাকশন রেকর্ড করে।
- `.sandbox/evidence/claude-stream.jsonl` বাস্তব Claude Code অফলাইন রান রেকর্ড করে।
- `.sandbox/evidence/live-*.jsonl` যাচাইকৃত তিনটি লাইভ স্ট্রিম রেকর্ড করে।
- `.sandbox/evidence/egress.jsonl` এবং `.sandbox/evidence/claude-egress.jsonl` হলো গার্ড অডিটের যাচাইকৃত, টোকেন-মুক্ত কপি।

লগইন/কনফিগ ভলিউম সংরক্ষণ করে মালিকানাধীন কনটেইনার এবং নেটওয়ার্ক বন্ধ করুন:

```bash
./scripts/devin-bridge/clean
```

নামযুক্ত ভলিউমসহ ব্রিজ-মালিকানাধীন সম্পূর্ণ পরিবেশ সরান:

```bash
./scripts/devin-bridge/clean --all
```

## সীমাবদ্ধতা

- ব্রিজটি নির্দিষ্ট no-tools `summarizer` ভূমিকার ওপর নির্ভর করে, কারণ Devin CLI `3000.2.17` কোনো নিরপেক্ষ no-tools ACP এজেন্ট প্রকাশ করে না। অ্যাডাপ্টারটি সারাংশ-সদৃশ মধ্যবর্তী প্রতিক্রিয়াগুলোর জন্য ক্ষতিপূরণ করে, তবে একটি সীমাবদ্ধ মেরামত প্রচেষ্টাও স্পষ্টভাবে ব্যর্থ হতে পারে।
- লাইভ ACP কলগুলো সাময়িক `502`/`504` প্রতিক্রিয়া দিতে পারে। হারনেসটি দৃশ্যপটগুলোর মধ্যে বিরতি রাখে; স্থায়ী ব্যর্থতার ক্ষেত্রে fail-closed আচরণ বজায় থাকে এবং কখনোই অন্য কোনো প্রোভাইডার নির্বাচন করা হয় না।
- প্রতিটি Anthropic অনুরোধ থেকে ACP কনটেক্সট পুনর্গঠন করা হয়; কোনো প্রসেস/সেশন অ্যাফিনিটি নেই।
- প্রতিটি মডেল প্রতিক্রিয়ায় একটি টুল কল সমর্থিত; সমান্তরাল কল প্রত্যাখ্যান করা হয়।
- ছবি স্পষ্টভাবে অসমর্থিত। ভিশন, থিংকিং আউটপুট, এফোর্ট নিয়ন্ত্রণ এবং 1M কনটেক্সট উইন্ডোর সুবিধা ঘোষণা করা হয় না।
- SSE বৈধ Anthropic লাইফসাইকেল ইভেন্ট ব্যবহার করে, তবে সীমাবদ্ধ ACP টার্ন সংগ্রহ করার পর সেগুলো নির্গত হয়; ACP খণ্ডগুলো ক্রমবর্ধমানভাবে ফরওয়ার্ড করা হয় না।
