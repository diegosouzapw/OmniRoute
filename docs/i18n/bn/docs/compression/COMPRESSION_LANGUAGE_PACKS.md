Caveman কম্প্রেশন বিল্ট-ইন ইংরেজি নিয়মগুলোর পাশাপাশি ভাষা-নির্দিষ্ট রুল প্যাক লোড করতে পারে।
এটি মূল ইঞ্জিনকে স্থিতিশীল রাখে, একই সঙ্গে পর্তুগিজ, স্প্যানিশ, জার্মান, ফরাসি, ইতালীয়, জাপানি এবং
ভবিষ্যতের ভাষা প্যাকগুলোকে স্বাধীনভাবে বিকশিত হতে দেয়।

## অবস্থান

ভাষা প্যাকগুলো এখানে থাকে:

```txt
open-sse/services/compression/rules/<language>/
```

বর্তমানে সরবরাহ করা প্যাকগুলো (`rules/` ডিরেক্টরির বিষয়বস্তুর সঙ্গে যাচাইকৃত):

| ভাষা               | ডিরেক্টরি      | উপস্থিত নিয়মের বিভাগ                               |
| ------------------ | -------------- | --------------------------------------------------- |
| ইংরেজি             | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| স্প্যানিশ          | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| পর্তুগিজ (ব্রাজিল) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ইন্দোনেশীয়        | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ইতালীয়            | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| জার্মান            | `rules/de/`    | `context`, `filler`, `structural`                   |
| ফরাসি              | `rules/fr/`    | `context`, `filler`, `structural`                   |
| জাপানি             | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **সমতা-সংক্রান্ত নোট:** `en`, `es`, `pt-BR`, `id`, এবং `it` প্যাকে সম্পূর্ণ ৫টি বিভাগ রয়েছে; `de`, `fr`, `ja`-তে ৩টি বিভাগ সরবরাহ করা হয়। অনুপস্থিত `dedup` এবং `ultra` বিভাগগুলো নীরবে বিল্ট-ইন ইংরেজি নিয়ম ব্যবহার করে। ছোট প্যাকগুলোর জন্য `dedup.json` এবং `ultra.json` যোগ করতে অবদান স্বাগত।
>
> `pt-BR` প্যাকটি Lenine Júnior-এর **[Troglodita](https://github.com/leninejunior/troglodita)**-এর ওপর ভিত্তি করে তৈরি—এটি ব্রাজিলীয় পর্তুগিজ ব্যাকরণের জন্য শুরু থেকে নকশা করা একটি কম্প্রেশন সিস্টেম (অতিরিক্ত শব্দপ্রয়োগ হ্রাস, PT-BR ফিলার অপসারণ, ব্রাজিলীয় ডেভেলপার কমিউনিটির জন্য কারিগরি সংক্ষিপ্ত রূপ)।
>
> প্রামাণ্য বিভাগ তালিকা এবং প্রতিটি বিভাগের স্কিমা [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json)-এ রয়েছে (JSON Schema draft 2020-12)।

## ভাষা শনাক্তকরণ

`languageDetector.ts` প্রম্পটের টেক্সট থেকে ভাষা অনুমান করতে হালকা হিউরিস্টিক ব্যবহার করে। কনফিগার করা
ডিফল্ট ভাষা এখনও মান্য করা হয় এবং সুনির্দিষ্ট নিয়ন্ত্রণের প্রয়োজন হলে কনফিগের মাধ্যমে শনাক্তকরণ
নিষ্ক্রিয় করা যায়।

শনাক্তকরণের আউটপুট শুধু রুল প্যাক বেছে নিতে ব্যবহৃত হয়। এটি প্রোভাইডার রাউটিং, লোকেল
নির্বাচন বা UI-এর ভাষা পরিবর্তন করে না।

## কনফিগের কাঠামো

কম্প্রেশন সেটিংসে এগুলো অন্তর্ভুক্ত থাকতে পারে:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` ড্যাশবোর্ড/প্রিভিউয়ের ডিফল্ট মান নিয়ন্ত্রণ করে। `cavemanConfig` হলো রানটাইম ইঞ্জিন কনফিগ,
যা Caveman বার্তার টেক্সট কম্প্রেস করার সময় ব্যবহৃত হয়।

## একটি ভাষা প্যাক যোগ করা

1. `open-sse/services/compression/rules/<language>/<pack>.json` তৈরি করুন।
2. `docs/compression/COMPRESSION_RULES_FORMAT.md`-এ বর্ণিত Caveman নিয়মের ফরম্যাট ব্যবহার করুন।
3. প্রতিস্থাপনগুলো সীমিত রাখুন এবং কোড, আইডেন্টিফায়ার, URL বা JSON পরিবর্তন করা এড়িয়ে চলুন।
4. ভাষা নির্বাচন ও প্রতিস্থাপনের আচরণের জন্য টেস্ট যোগ বা আপডেট করুন।
5. ভাষাটি UI নির্বাচকে প্রদর্শিত হলে নতুন dashboard/i18n লেবেল উন্মুক্ত করুন।

## API

উপলভ্য প্যাকগুলো নিম্নলিখিতভাবে অনুসন্ধান করা যায়:

```bash
curl http://localhost:20128/api/compression/language-packs
```

প্রিভিউ এন্ডপয়েন্ট ভাষার কনফিগ ওভাররাইড গ্রহণ করে:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

v3.8.0-এ সব 6টি ভাষা প্যাকে একটি `SHARED_BOUNDARIES` ক্লজ যোগ করা হয়েছে, যা প্রতিটি
Caveman তীব্রতায় (LITE, FULL, ULTRA) প্রয়োগ করা হয়। এটি ইঞ্জিনকে আশপাশের অপ্রয়োজনীয় অংশ
অপসারণ নির্বিশেষে নিম্নলিখিত প্যাটার্নগুলো হুবহু সংরক্ষণ করার নির্দেশ দেয়:

| প্যাটার্নের ধরন                 | উদাহরণ                                 |
| ------------------------------- | -------------------------------------- |
| ফেন্সড কোড ব্লক                 | ` ```python\n...\n``` `                |
| ইনলাইন কোড                      | `` `my_var` ``                         |
| URL                             | `https://example.com/path`             |
| ফাইল পাথ (অ্যাবসলিউট + রিলেটিভ) | `/etc/hosts`, `./src/index.ts`         |
| এরর হেডার                       | `Error:`, `TypeError:`, `SyntaxError:` |
| স্ট্যাক ট্রেস লাইন              | `  at functionName (file.ts:12:3)`     |

এই প্যাটার্নগুলো `DEFAULT_CAVEMAN_CONFIG.preservePatterns`-এ (আগে `[]` ছিল) অন্তর্ভুক্ত থাকে।
কনস্ট্যান্টটি `open-sse/services/compression/types.ts`-এ রয়েছে।

### এটি কেন গুরুত্বপূর্ণ

SHARED_BOUNDARIES ছাড়া, আক্রমণাত্মক Caveman মোডগুলো এমন কনটেন্ট বাদ দিতে পারত, যা দেখতে
পুনরাবৃত্তিমূলক গদ্যের মতো হলেও আসলে একটি কোড স্নিপেট, ফাইল পাথ বা এরর স্ট্যাক ছিল। SHARED_BOUNDARIES
একটি ভাষা-নিরপেক্ষ সুরক্ষা-ব্যবস্থা হিসেবে কাজ করে, যা অপ্রয়োজনীয় অংশ অপসারণের নিয়ম চালানোর আগে প্রয়োগ করা হয়।

### preservePatterns কাস্টমাইজ করা

কম্প্রেশন সেটিংসের মাধ্যমে রানটাইমে অতিরিক্ত প্যাটার্ন যোগ করা যেতে পারে:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

কাস্টম প্যাটার্নগুলো 6টি ডিফল্টকে প্রতিস্থাপন করে না; বরং সেগুলোকে সম্প্রসারিত করে।

## পরিচালনাগত নোট

- কোনো ভাষা প্যাক অনুপস্থিত থাকলে বিল্ট-ইন ইংরেজি নিয়মগুলো ফলব্যাক হিসেবে ব্যবহৃত হয়।
- অবৈধ বিল্ট-ইন JSON প্যাকগুলো ভ্যালিডেশনে ব্যর্থ হয়, যাতে রিলিজ অ্যাসেটের মান নীরবে হ্রাস না পায়।
- নিয়ম প্যাকগুলো কেবল ডেটা-ভিত্তিক এবং এগুলো কোড ইমপোর্ট বা নির্বিচার লজিক চালানো উচিত নয়।
- কম্প্রেশন অ্যানালিটিক্স স্তরটি নির্বাচিত মোড ও ইঞ্জিন রেকর্ড করে, সম্পূর্ণ প্রম্পট টেক্সট নয়।
