## ഇത് എന്താണ്

OmniRoute ഒരു **Obsidian** വോൾട്ടുമായി **കോൺടെക്സ്റ്റ് ഉറവിടമായി** ബന്ധപ്പെടുന്നു — ബിൽറ്റ്-ഇൻ MCP സെർവർ വഴി ഏജന്റുകൾ വായിക്കുകയും എഴുതുകയും ചെയ്യുന്ന ഒരു ലോക്കൽ Markdown
വിജ്ഞാനശേഖരം. ഡെസ്ക്ടോപ്പ് ആപ്പിനുള്ളിൽ പ്രവർത്തിക്കുന്ന **Obsidian Local REST API**
കമ്മ്യൂണിറ്റി പ്ലഗിനുമായി ഈ സംയോജനം ആശയവിനിമയം നടത്തുന്നു. അതുവഴി ഏജന്റുകൾക്ക് കുറിപ്പുകൾ തിരയാനും, ഫയലുകൾ വായിക്കാനും/എഴുതാനും/പാച്ച് ചെയ്യാനും, വോൾട്ടിന്റെ പട്ടിക ലഭ്യമാക്കാനും, ദൈനംദിന/പ്രതിവാര ആവർത്തന കുറിപ്പുകളിൽ പ്രവർത്തിക്കാനും, ടാഗുകൾ കൈകാര്യം ചെയ്യാനും, Obsidian കമാൻഡുകൾ പ്രവർത്തിപ്പിക്കാനും, കൂടാതെ (ഐച്ഛികമായി)
ദ്വിദിശ ഡെസ്ക്ടോപ്പ്↔മൊബൈൽ വോൾട്ട് സിങ്ക് ഏകോപിപ്പിക്കാനും കഴിയും.

ക്ലയന്റ് (`src/lib/obsidian/api.ts`) Local REST API-യെ ഇനിപ്പറയുന്ന സൗകര്യങ്ങളോടെ പൊതിയുന്നു:

- താൽക്കാലിക `5xx` പിശകുകൾക്കായി **ബാക്ക്ഓഫോടെയുള്ള പുനഃശ്രമം**, `AbortController` വഴിയുള്ള **30 സെക്കൻഡ് സമയപരിധി**.
- **ടൈപ്പ് ചെയ്ത പിശക് വർഗ്ഗീകരണം** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- സാധാരണ സംഭവിക്കുന്ന പോർട്ട് പിശകും (MCP എൻഡ്പോയിന്റായ `27124` അല്ല, `27123`-ലെ HTTP ആണ് വേണ്ടത്) Tailscale രൂപവും എടുത്തുപറയുന്ന, **"Obsidian-ലേക്ക് എത്താനാകുന്നില്ല" എന്ന സൗഹൃദപരമായ സൂചന**.
- സ്പേസുകളും സ്ലാഷുകളും ഉള്ള കുറിപ്പ് പാതകൾ സുരക്ഷിതമാക്കുന്ന വോൾട്ട്-ആപേക്ഷിക **പാത എൻകോഡിംഗ്**.

## സജ്ജീകരണം

Obsidian ടോക്കണിനോ അടിസ്ഥാന URL-നോ വേണ്ടി **എൻവയോൺമെന്റ് വേരിയബിൾ ഇല്ല** — രണ്ടും
`src/lib/db/obsidian.ts` വഴി SQLite `key_value` പട്ടികയിൽ (`obsidian` നെയിംസ്പേസ്) സംഭരിക്കുന്നു. ടോക്കൺ **സംഭരണാവസ്ഥയിൽ എൻക്രിപ്റ്റ് ചെയ്തതാണ്** (AES-256-GCM, പ്ലെയിൻടെക്സ്റ്റ് ബാക്ക്വേഡ്-കോംപാറ്റിബിലിറ്റി ഫാൾബാക്കോടുകൂടി). Endpoint ഡാഷ്ബോർഡിലെ **Context Sources** ടാബിൽനിന്ന്
(`ObsidianSourceCard`) അല്ലെങ്കിൽ ക്രമീകരണ REST API വഴി കോൺഫിഗർ ചെയ്യുക.

> [!IMPORTANT]
> **Obsidian Local REST API** പ്ലഗിൻ ഇൻസ്റ്റാൾ ചെയ്ത് പ്രവർത്തിപ്പിച്ചിരിക്കണം. അതിന്റെ REST
> ഇന്റർഫേസ് **HTTP `127.0.0.1:27123`**-ൽ ശ്രവിക്കുന്നു (ഡിഫോൾട്ട് അടിസ്ഥാന URL). പോർട്ട് `27124`
> ഒരു _വേറിട്ട_ MCP/HTTPS എൻഡ്പോയിന്റാണ്; ക്രമീകരണ റൂട്ട് അത് വ്യക്തമായി നിരസിക്കുന്നു.
> മറ്റൊരു ഉപകരണത്തിൽനിന്ന് ബന്ധപ്പെടുകയാണെങ്കിൽ, `http://<tailscale-ip>:27123` ഉപയോഗിക്കുക.

### കോൺഫിഗറേഷൻ കീകൾ (SQLite `key_value`, `obsidian` നെയിംസ്പേസ്)

| കീ                | ഉദ്ദേശ്യം                                              | എൻക്രിപ്റ്റ് ചെയ്തത് |
| ----------------- | ------------------------------------------------------ | -------------------- |
| `api_key`         | Local REST API ബെയറർ ടോക്കൺ                            | അതെ                  |
| `base_url`        | REST അടിസ്ഥാന URL (ഡിഫോൾട്ട് `http://127.0.0.1:27123`) | അല്ല                 |
| `vault_path`      | വോൾട്ട് ഡയറക്ടറിയിലേക്കുള്ള സമ്പൂർണ്ണ പാത (സിങ്കിനായി) | അല്ല                 |
| `webdav_username` | സൃഷ്ടിച്ച WebDAV ഉപയോക്തൃനാമം (വോൾട്ട് സിങ്ക്)         | അല്ല                 |
| `webdav_password` | സൃഷ്ടിച്ച WebDAV പാസ്വേഡ് (വോൾട്ട് സിങ്ക്)             | അതെ                  |
| `webdav_enabled`  | WebDAV വോൾട്ട് സിങ്ക് പ്രവർത്തനക്ഷമമാണോ എന്ന്          | അല്ല                 |

### REST വഴി കോൺഫിഗർ ചെയ്യുക

```bash
# Local REST API ടോക്കൺ സംരക്ഷിച്ച് സാധൂകരിക്കുക (POST ഒരു സ്റ്റാറ്റസ് പരിശോധനയിലൂടെ സാധൂകരിക്കുന്നു)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# കണക്ഷൻ നില പരിശോധിക്കുക (connected, hasToken, baseUrl, vaultPath എന്നിവ തിരികെ നൽകുന്നു)
curl http://localhost:20128/api/settings/obsidian

# വിച്ഛേദിക്കുക (സംഭരിച്ച ടോക്കൺ മായ്ക്കുന്നു)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

എല്ലാ മെത്തഡുകൾക്കും ഡാഷ്ബോർഡ് പ്രാമാണീകരണം ആവശ്യമാണ്. പോർട്ട് `27124`-ലുള്ള ഏത് URL-ഉം `POST` നിരസിക്കുകയും, നിലനിർത്തുന്നതിന് മുമ്പ് Local REST API സ്റ്റാറ്റസ് എൻഡ്പോയിന്റ് വിളിച്ച് ടോക്കൺ സാധൂകരിക്കുകയും ചെയ്യുന്നു.

### WebDAV വോൾട്ട് സിങ്ക്

`src/app/api/settings/obsidian/webdav/route.ts`, `src/lib/obsidianSync.ts` നിയന്ത്രിക്കുന്ന ഒരു ഐച്ഛിക WebDAV-പിന്തുണയുള്ള
വോൾട്ട് സിങ്ക് കൈകാര്യം ചെയ്യുന്നു. ഇത് പ്രവർത്തനക്ഷമമാക്കുന്നത് OmniRoute-നെ ഒരു
ലോക്കൽ വോൾട്ട് ഡയറക്ടറിയിലേക്ക് ചൂണ്ടിക്കാണിക്കുകയും ക്രമരഹിതമായ ഒരു WebDAV ഉപയോക്തൃനാമം/പാസ്വേഡ് ജോടി സൃഷ്ടിക്കുകയും ചെയ്യുന്നു:

```bash
# ഒരു വോൾട്ട് ഡയറക്ടറിക്കായി WebDAV സിങ്ക് പ്രവർത്തനക്ഷമമാക്കുക (ഉപയോക്തൃനാമം/പാസ്വേഡ് സൃഷ്ടിക്കുന്നു)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV സിങ്ക് നില ലഭ്യമാക്കുക (പ്രവർത്തനക്ഷമമായിരിക്കുമ്പോൾ മാത്രം ക്രെഡൻഷ്യലുകൾ തിരികെ നൽകുന്നു)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV സിങ്ക് പ്രവർത്തനരഹിതമാക്കുക (ക്രെഡൻഷ്യലുകളും നിയന്ത്രിത .stignore-ഉം മായ്ക്കുന്നു)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### ഓരോ API കീയ്ക്കുമുള്ള കോൺടെക്സ്റ്റ് ഉറവിടം (ഐച്ഛികം)

`api_key_context_sources` പട്ടിക വഴി Obsidian കോൺഫിഗറേഷൻ **ഓരോ API കീയ്ക്കും** പ്രത്യേകം സ്കോപ്പ് ചെയ്യാം
(`src/lib/db/apiKeyContextSources.ts`). ഒരു MCP കോളിൽ പ്രാമാണീകരിച്ച API
കീ id ഉൾപ്പെടുമ്പോൾ, `getObsidianConfigForApiKey()` ആ കീയുടെ സ്വന്തം ടോക്കൺ/അടിസ്ഥാന URL/വോൾട്ട് പാതയ്ക്ക്
(`source: "api_key"`) മുൻഗണന നൽകുകയും, അത് ലഭ്യമല്ലെങ്കിൽ ആഗോള കോൺഫിഗറേഷനിലേക്ക് (`source: "global"`) ഫാൾബാക്ക് ചെയ്യുകയും ചെയ്യുന്നു.

## MCP ടൂളുകൾ (22)

`open-sse/mcp-server/tools/obsidianTools.ts`-ൽ നിർവചിച്ചിരിക്കുന്നു. ടോക്കൺ/base-URL ഓരോ കോളിനും
പരിഹരിക്കപ്പെടുന്നു (ആദ്യം ഓരോ API കീയ്ക്കുമുള്ളത്, തുടർന്ന് ഗ്ലോബൽ). OmniRoute **sync server**-നെ
സമീപിക്കുന്ന ടൂളുകൾക്ക് (നാല് `obsidian_sync_*` ടൂളുകൾ) OmniRoute ക്രമീകരണങ്ങളിൽ കോൺഫിഗർ ചെയ്തിരിക്കുന്ന
sync auth token കൂടി ആവശ്യമാണ്.

### റീഡ് ടൂളുകൾ (`read:obsidian`)

| ടൂൾ                          | വിവരണം                                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Local REST API ലഭ്യമാണോ എന്നും പ്രാമാണീകരിച്ചിട്ടുണ്ടോ എന്നും പരിശോധിക്കുക.                                |
| `obsidian_search_simple`     | നോട്ടിന്റെ ഉള്ളടക്കത്തിൽ പൂർണ്ണ-ടെക്സ്റ്റ് തിരയൽ; ഫയൽ പാതകളോടുകൂടിയ സ്നിപ്പെറ്റുകൾ നൽകുന്നു.               |
| `obsidian_search_structured` | ഒരു JSON Logic എക്സ്പ്രഷൻ ഉപയോഗിച്ച് തിരയുക (and/or/regex/path ഫിൽട്ടറുകൾ).                                |
| `obsidian_read_note`         | vault-ആപേക്ഷിക പാത ഉപയോഗിച്ച് ഒരു നോട്ട് വായിക്കുക; ആവശ്യമെങ്കിൽ ഒരു നിർദ്ദിഷ്ട heading/block/frontmatter. |
| `obsidian_list_vault`        | vault-ലുള്ള ഫയലുകളും ഡയറക്ടറികളും പട്ടികപ്പെടുത്തുക (എൻട്രികളുടെ ട്രീ).                                    |
| `obsidian_get_document_map`  | നോട്ടിന്റെ heading ഘടന, headings → line numbers എന്ന മാപ്പായി നേടുക.                                       |
| `obsidian_get_note_metadata` | പൂർണ്ണ ഉള്ളടക്കമില്ലാതെ frontmatter, ടാഗുകൾ, ലിങ്കുകൾ, അക്ഷര/വാക്ക് എണ്ണം എന്നിവ നേടുക.                    |
| `obsidian_get_active_file`   | Obsidian-ൽ നിലവിൽ സജീവമായ ഫയലിന്റെ പാത + ഉള്ളടക്കം നേടുക.                                                  |
| `obsidian_get_periodic_note` | ഒരു തീയതിക്കായുള്ള ദൈനംദിന/പ്രതിവാര/പ്രതിമാസ periodic note നേടുക (ഒഴിവാക്കിയാൽ ഇന്ന്).                     |
| `obsidian_get_tags`          | എല്ലാ vault ടാഗുകളും അവയുടെ ആവൃത്തികളോടൊപ്പം പട്ടികപ്പെടുത്തുക.                                            |
| `obsidian_list_commands`     | ലഭ്യമായ Obsidian command ID-കൾ പട്ടികപ്പെടുത്തുക (`obsidian_execute_command`-നൊപ്പം ഉപയോഗിക്കുക).          |
| `obsidian_sync_status`       | OmniRoute sync server നില: പ്രവർത്തിക്കുന്നുണ്ടോ, vault-ന്റെ പേര്, പോർട്ട്, uptime, അവസാന sync.            |
| `obsidian_sync_conflicts`    | പരിഹരിക്കാത്ത sync conflicts പട്ടികപ്പെടുത്തുക (പാത, conflict പാത, കണ്ടെത്തിയ സമയം).                       |

### റൈറ്റ് ടൂളുകൾ (`write:obsidian`)

| ടൂൾ                              | വിവരണം                                                                                                   |
| -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | നൽകിയ Markdown ഉള്ളടക്കം ഉപയോഗിച്ച് ഒരു നോട്ട് സൃഷ്ടിക്കുകയോ തിരുത്തിയെഴുതുകയോ ചെയ്യുക.                  |
| `obsidian_append_note`           | ഒരു നോട്ടിലേക്ക് ഉള്ളടക്കം ചേർക്കുക; ആവശ്യമെങ്കിൽ ഒരു നിർദ്ദിഷ്ട heading/block-ലേക്ക്.                   |
| `obsidian_patch_note`            | ഒരു heading, block, അല്ലെങ്കിൽ frontmatter field-ൽ കൃത്യമായി append/prepend/replace ചെയ്യുക.             |
| `obsidian_delete_note`           | vault-ൽ നിന്ന് ഒരു നോട്ട് ശാശ്വതമായി ഇല്ലാതാക്കുക.                                                       |
| `obsidian_move_note`             | vault-നുള്ളിൽ ഒരു നോട്ട് നീക്കുകയോ പുനർനാമകരണം ചെയ്യുകയോ ചെയ്യുക.                                        |
| `obsidian_execute_command`       | ഒരു Obsidian command അതിന്റെ command ID ഉപയോഗിച്ച് പ്രവർത്തിപ്പിക്കുക.                                   |
| `obsidian_open_file`             | Obsidian-ൽ ഒരു ഫയൽ തുറക്കുക (അത് നിലവിലില്ലെങ്കിൽ സൃഷ്ടിക്കുന്നു).                                       |
| `obsidian_sync_trigger`          | ഉടനടി bidirectional desktop↔mobile vault sync ആരംഭിക്കുക.                                                |
| `obsidian_sync_resolve_conflict` | ഒരു sync conflict പരിഹരിക്കുക: `local` (mobile), `remote` (desktop), അല്ലെങ്കിൽ `keep-both` നിലനിർത്തുക. |

> [!NOTE]
> `obsidian_patch_note` targets, `heading | block | frontmatter` എന്ന `targetType`-ഉം
> `append | prepend | replace` എന്ന `operation`-ഉം സ്വീകരിക്കുന്നു; കൂടാതെ ഐച്ഛികമായ
> `createTargetIfMissing`-ഉം സ്വീകരിക്കുന്നു. നാല് `obsidian_sync_*` ടൂളുകൾ ലോക്കൽ sync
> server-നോട് (സ്ഥിരസ്ഥിതിയായി `http://127.0.0.1:27781`) ആശയവിനിമയം നടത്തുകയും sync token ആവശ്യപ്പെടുകയും ചെയ്യുന്നു.

### സ്കോപ്പുകൾ

റീഡ് ടൂളുകൾക്ക് `read:obsidian` ആവശ്യമാണ്; റൈറ്റ് ടൂളുകൾക്ക് `write:obsidian` ആവശ്യമാണ്. നടപ്പാക്കൽ
Notion-ലേതിന് സമാനമാണ് — `open-sse/mcp-server/server.ts`-ലെ `withScopeEnforcement()` ആണ് ഇത്
കൈകാര്യം ചെയ്യുന്നത്; `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ആയിരിക്കുമ്പോൾ ഇത് പ്രാബല്യത്തിൽ വരുന്നു, കൂടാതെ
അനുവദനീയമായ സ്കോപ്പുകൾ `OMNIROUTE_MCP_SCOPES`-ൽ നിന്നോ API കീയുടെ സ്കോപ്പ് കോൺടെക്സ്റ്റിൽ നിന്നോ ലഭിക്കുന്നു. കാണുക
[MCP-SERVER.md](./MCP-SERVER.md).

## എൻഡ്പോയിന്റുകൾ

| രീതി     | പാത                             | ഉദ്ദേശ്യം                                                                |
| -------- | ------------------------------- | ------------------------------------------------------------------------ |
| `GET`    | `/api/settings/obsidian`        | `{ connected, hasToken, baseUrl, vaultPath }` മടക്കിനൽകുന്നു.            |
| `POST`   | `/api/settings/obsidian`        | ടോക്കൺ സംരക്ഷിച്ച് സാധൂകരിക്കുന്നു (`27124` പോർട്ട് നിരസിക്കുന്നു).      |
| `DELETE` | `/api/settings/obsidian`        | ബന്ധം വിച്ഛേദിക്കുന്നു (സംഭരിച്ച ടോക്കൺ മായ്ക്കുന്നു).                   |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV സമന്വയ നിലയും ക്രെഡൻഷ്യലുകളും (പ്രവർത്തനക്ഷമമാക്കിയിരിക്കുമ്പോൾ). |
| `POST`   | `/api/settings/obsidian/webdav` | ഒരു വോൾട്ട് ഡയറക്ടറിക്കായി WebDAV സമന്വയം പ്രവർത്തനക്ഷമമാക്കുന്നു.       |
| `DELETE` | `/api/settings/obsidian/webdav` | WebDAV സമന്വയം പ്രവർത്തനരഹിതമാക്കുന്നു.                                  |

> ഇവ ഡാഷ്ബോർഡ് ക്രമീകരണ റൂട്ടുകളാണ്. വോൾട്ടിലേക്ക് പ്രവേശിക്കുന്നത് Obsidian
> Local REST API (ക്രമീകരിച്ച `base_url`) വഴിയും മുകളിലുള്ള MCP ടൂളുകൾ വഴിയുമാണ് —
> പൊതുവായ `/v1` Obsidian പ്രോക്സി എൻഡ്പോയിന്റ് ഇല്ല.

## ഉപയോഗ സാഹചര്യങ്ങൾ

- **വോൾട്ടിനെ അടിസ്ഥാനമാക്കിയുള്ള ഉത്തരങ്ങൾ** — ആദ്യം `obsidian_search_simple` / `obsidian_search_structured`,
  തുടർന്ന് `obsidian_read_note`; ഇതിലൂടെ ഒരു ഏജന്റ് നിങ്ങളുടെ യഥാർത്ഥ കുറിപ്പുകളിൽനിന്ന് ഉത്തരം നൽകുന്നു.
- **കുറിപ്പ് തയ്യാറാക്കൽ / ജേണലിംഗ്** — ഏജന്റിന്റെ ഔട്ട്പുട്ട്, സംഗ്രഹങ്ങൾ, അല്ലെങ്കിൽ ദൈനംദിന കുറിപ്പുകൾ
  (`obsidian_get_periodic_note`) വോൾട്ടിൽ രേഖപ്പെടുത്താൻ `obsidian_write_note`, `obsidian_append_note`, അല്ലെങ്കിൽ
  കൃത്യമായ മാറ്റങ്ങൾക്കായി `obsidian_patch_note` ഉപയോഗിക്കുക.
- **വോൾട്ട് നാവിഗേഷൻ** — വായിക്കുന്നതിനും എഴുതുന്നതിനും മുമ്പ് ഘടന പര്യവേക്ഷണം ചെയ്യാൻ
  `obsidian_list_vault`, `obsidian_get_document_map`, `obsidian_get_tags` എന്നിവ ഉപയോഗിക്കുക.
- **Obsidian ഓട്ടോമേഷൻ** — ഒരു ഏജന്റിൽനിന്ന് പ്ലഗിനുകൾ/കമാൻഡുകൾ പ്രവർത്തിപ്പിക്കാൻ
  `obsidian_list_commands` + `obsidian_execute_command`; UI-യിൽ ഒരു കുറിപ്പ് പ്രദർശിപ്പിക്കാൻ `obsidian_open_file`.
- **മൊബൈൽ സമന്വയം** — WebDAV സമന്വയം പ്രവർത്തനക്ഷമമാക്കിയ ശേഷം ഡെസ്ക്ടോപ്പ്↔മൊബൈൽ സമന്വയിപ്പിക്കാനും വൈരുദ്ധ്യങ്ങൾ
  പരിഹരിക്കാനും `obsidian_sync_trigger` / `obsidian_sync_status` / `obsidian_sync_conflicts` /
  `obsidian_sync_resolve_conflict` ഉപയോഗിക്കുക.
