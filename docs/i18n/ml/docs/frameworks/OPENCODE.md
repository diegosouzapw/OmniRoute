> **നില:** പൊതുവായി ലഭ്യമാണ്.
> **ഉദ്ദേശിച്ച പ്രേക്ഷകർ:** OpenCode-നെ ഒരു OmniRoute വിന്യാസവുമായി ബന്ധിപ്പിക്കുന്ന ഓപ്പറേറ്റർമാർ.
> **ആധികാരിക ഉറവിടം (കോൺഫിഗറേഷൻ സ്കീമ):** `src/shared/services/opencodeConfig.ts`
> **ആധികാരിക ഉറവിടം (npm പാക്കേജ്):** `@omniroute/opencode-provider/` (പ്രസിദ്ധീകരിക്കാവുന്ന വർക്ക്സ്പേസ്)

[OpenCode](https://opencode.ai) ഒരു ഏജന്റിക് CLI/ഡെസ്ക്ടോപ്പ് AI ക്ലയന്റാണ്. ഇത് അതിന്റെ പ്രൊവൈഡർ കാറ്റലോഗ് `~/.config/opencode/opencode.json`-ൽ നിന്ന് (അല്ലെങ്കിൽ `opencode.jsonc`) വായിക്കുകയും `https://opencode.ai/config.json`-ലെ സ്കീമ പിന്തുടരുകയും ചെയ്യുന്നു. OmniRoute ആ പ്രൊവൈഡർമാരിൽ ഒന്നായി OpenCode-ന് സ്വയം ലഭ്യമാക്കുന്നു — ഓരോ അഭ്യർത്ഥനയും OmniRoute-ന്റെ സ്റ്റാൻഡേർഡ് OpenAI-അനുയോജ്യമായ `/v1` സർഫേസിലൂടെ കടന്നുപോകുന്നതിനാൽ, Auto-Combo റൂട്ടിംഗ്, സർക്യൂട്ട് ബ്രേക്കറുകൾ, കീ പോളിസികൾ, നിരീക്ഷണക്ഷമത തുടങ്ങിയവയുടെ പ്രയോജനം OpenCode-ന് സ്വയമേവ ലഭിക്കുന്നു.

പിന്തുണയ്ക്കുന്ന **രണ്ട് ഇന്റഗ്രേഷൻ മാർഗങ്ങളുണ്ട്**. ഒന്ന് തിരഞ്ഞെടുക്കുക — രണ്ടും ഒരേ കോൺഫിഗറേഷനാണ് സൃഷ്ടിക്കുന്നത്.

## മാർഗം 1 — CLI ജനറേറ്റർ (npm ഇൻസ്റ്റാൾ ആവശ്യമില്ല)

അന്തിമ ഉപയോക്താക്കൾക്കായി ശുപാർശ ചെയ്യുന്നു. OmniRoute-നൊപ്പം ലഭ്യമാകുന്നു. നിലവിലുള്ള സ്ഥാനത്ത് `opencode.json` എഴുതുന്നു.

```bash
# OmniRoute ഇൻസ്റ്റാൾ ചെയ്തതിന് ശേഷം (npm i -g @omniroute/cli അല്ലെങ്കിൽ ലോക്കൽ ക്ലോൺ)
omniroute config opencode \
  --base-url http://localhost:20128 \
  --api-key "$OMNIROUTE_API_KEY"
```

പശ്ചാത്തലത്തിൽ CLI, `mergeOpenCodeConfigText()` (`src/shared/services/opencodeConfig.ts:104`) വിളിക്കുന്നു; അതിനാൽ നിലവിലുള്ള `opencode.json`-ലെ മറ്റ് പ്രൊവൈഡർമാരും കമന്റുകളും നിലനിർത്തപ്പെടുന്നു. OmniRoute എൻട്രി അറ്റോമിക്കായി ചേർക്കുകയോ മാറ്റിസ്ഥാപിക്കുകയോ ചെയ്യുന്നു.

ലഭിക്കുന്ന ഫയൽ (ഡിഫോൾട്ട് മോഡൽ കാറ്റലോഗ്):

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "omniroute": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "OmniRoute",
      "options": {
        "baseURL": "http://localhost:20128/v1",
        "apiKey": "<your-key>",
      },
      "models": {
        "claude-opus-4-5-thinking": { "name": "claude-opus-4-5-thinking" },
        "claude-sonnet-4-5-thinking": { "name": "claude-sonnet-4-5-thinking" },
        "gemini-3.1-pro-high": { "name": "gemini-3.1-pro-high" },
        "gemini-3-flash": { "name": "gemini-3-flash" },
      },
    },
  },
}
```

## മാർഗം 2 — npm പാക്കേജ് `@omniroute/opencode-provider`

Node/TS-ൽ നിന്ന് കോൺഫിഗറേഷൻ സ്ക്രിപ്റ്റ് ചെയ്യുമ്പോൾ ശുപാർശ ചെയ്യുന്നു (CI പൈപ്പ്ലൈനുകൾ, മോണോറെപ്പോകൾ, ഇഷ്ടാനുസൃത ഇൻസ്റ്റാളർ ഫ്ലോകൾ).

```bash
npm install --save-dev @omniroute/opencode-provider
```

```ts
import { writeFileSync } from "node:fs";
import { buildOmniRouteOpenCodeConfig } from "@omniroute/opencode-provider";

const config = buildOmniRouteOpenCodeConfig({
  baseURL: "http://localhost:20128",
  apiKey: process.env.OMNIROUTE_API_KEY ?? "sk_omniroute",
  // ഐച്ഛികം: OpenCode-ന് ലഭ്യമാക്കുന്ന മോഡൽ കാറ്റലോഗ് അസാധുവാക്കുക
  models: ["auto", "claude-opus-4-7", "gpt-5.5"],
  modelLabels: { auto: "Auto-Combo" },
});

writeFileSync("opencode.json", JSON.stringify(config, null, 2));
```

നിലവിലുള്ള ഒരു ഫയലുമായി നാശകരമല്ലാത്ത രീതിയിൽ ലയിപ്പിക്കാൻ, `opencodeConfig.ts`-ൽ നിന്നുള്ള `mergeOpenCodeConfigText()` പുനഃസൃഷ്ടിക്കുകയോ CLI ജനറേറ്റർ വിളിക്കുകയോ ചെയ്യുക.

പൂർണ്ണ API-ക്കായി [പാക്കേജ് README](../../@omniroute/opencode-provider/README.md) കാണുക.

## റൺടൈം യഥാർത്ഥത്തിൽ ചെയ്യുന്നത്

രണ്ട് മാർഗങ്ങളും ഒരേ `provider.omniroute.npm: "@ai-sdk/openai-compatible"` സൃഷ്ടിക്കുന്നു. റൺടൈമിൽ, OpenCode `@ai-sdk/openai-compatible` ലോഡ് ചെയ്യുകയും (ഇത് ഇതിനകം OpenCode-ന്റെ ഒരു ട്രാൻസിറ്റീവ് ഡിപ്പൻഡൻസിയാണ്) `baseURL` + `apiKey` ഉപയോഗിച്ച് കോൺഫിഗർ ചെയ്യുകയും ചെയ്യുന്നു. അവിടെ നിന്ന്:

```
OpenCode UI/ഏജന്റ്
   → @ai-sdk/openai-compatible
      → HTTP POST {baseURL}/chat/completions          (OmniRoute OpenAI സർഫേസ്)
         → OmniRoute /v1/chat/completions ഹാൻഡ്ലർ     (open-sse/handlers/chatCore.ts)
            → കോംബോ റൂട്ടിംഗ് / Auto-Combo / എക്സിക്യൂട്ടർ
               → അപ്സ്ട്രീം പ്രൊവൈഡർ
```

പ്ലഗിൻ ഒരിക്കലും HTTP കൈകാര്യം ചെയ്യുന്നില്ല. അത് കോൺഫിഗറേഷൻ മാത്രമാണ് പുറപ്പെടുവിക്കുന്നത്.

## മോഡൽ കാറ്റലോഗ് ഡിഫോൾട്ടുകൾ

```ts
export const OMNIROUTE_DEFAULT_OPENCODE_MODELS = [
  "claude-opus-4-5-thinking",
  "claude-sonnet-4-5-thinking",
  "gemini-3.1-pro-high",
  "gemini-3-flash",
] as const;
```

`models: [...]` വഴി നിങ്ങൾക്ക് ഇത് മാറ്റിയെഴുതാം. ശുപാർശ ചെയ്യുന്ന കൂട്ടിച്ചേർക്കലുകൾ:

- `"auto"` — OmniRoute-ന്റെ [Auto-Combo](../routing/AUTO-COMBO.md) സീറോ-കോൺഫിഗ് റൂട്ടർ ലഭ്യമാക്കുന്നു. കാറ്റലോഗിൽ ഹാർഡ്-കോഡ് ചെയ്യാതെ തന്നെ "ലഭ്യമായതിൽ ഏറ്റവും മികച്ച മോഡൽ" തിരഞ്ഞെടുക്കാൻ OpenCode-നെ അനുവദിക്കുന്നു.
- `"<combo-name>"` — ഡാഷ്ബോർഡിൽ നിങ്ങൾ നിർവചിച്ചിട്ടുള്ള ഏത് കോംബോയും; OmniRoute അത് സുതാര്യമായി പരിഹരിക്കുന്നു.

## URL നോർമലൈസേഷൻ

ഹെൽപ്പർ രണ്ട് രൂപങ്ങളും സ്വീകരിക്കുകയും കൃത്യമായി ഒരു `/v1` മാത്രം ഔട്ട്പുട്ട് ചെയ്യുകയും ചെയ്യുന്നു:

| ഇൻപുട്ട്                       | ഔട്ട്പുട്ട് (`options.baseURL`) |
| ------------------------------ | ------------------------------- |
| `http://localhost:20128`       | `http://localhost:20128/v1`     |
| `http://localhost:20128/`      | `http://localhost:20128/v1`     |
| `http://localhost:20128/v1`    | `http://localhost:20128/v1`     |
| `http://localhost:20128/v1///` | `http://localhost:20128/v1`     |

ഈ ഡീഡ്യൂപ്ലിക്കേഷനാണ് പഴയ കോൺഫിഗുകളിൽ കാണുന്ന **ഏറ്റവും സാധാരണമായ തകരാർ**. `/v1/v1/...`-ലേക്ക് ചൂണ്ടുന്ന v3.8.0-ന് മുമ്പുള്ള ഒരു `opencode.json` നിങ്ങളുടെ പക്കലുണ്ടെങ്കിൽ, ജനറേറ്റർ വീണ്ടും പ്രവർത്തിപ്പിക്കുക അല്ലെങ്കിൽ `createOmniRouteProvider` വീണ്ടും വിളിക്കുക.

## പ്രാമാണീകരണ മോഡുകൾ

| OmniRoute ക്രമീകരണം                              | ശുപാർശ ചെയ്യുന്ന `apiKey` മൂല്യം                        |
| ------------------------------------------------ | ------------------------------------------------------- |
| `REQUIRE_API_KEY=false` (ലോക്കലിനുള്ള ഡിഫോൾട്ട്) | `sk_omniroute` (അക്ഷരാർഥത്തിലുള്ള പ്ലേസ്ഹോൾഡർ)          |
| `REQUIRE_API_KEY=true`                           | ഡാഷ്ബോർഡ് → API Keys-ൽ നിന്നുള്ള യഥാർഥ ഉപയോക്തൃ API കീ. |

`x-api-key` + `anthropic-version` അയയ്ക്കുന്ന Anthropic-ശൈലിയിലുള്ള ക്ലയന്റുകൾക്കായി, OmniRoute-ന്റെ `extractApiKey`, `x-api-key`-യിൽ നിന്നുള്ള കീയും പരിഗണിക്കുന്നു. OpenCode, OpenAI ഇന്റർഫേസ് ഉപയോഗിക്കുന്നതിനാൽ അത് എപ്പോഴും `Authorization: Bearer ${apiKey}` അയയ്ക്കും — ഇവിടെ Anthropic-നുള്ള പ്രത്യേക പരിഗണന ബാധകമല്ല.
