## അവലോകനം

Playground Studio, `/dashboard/playground`-നെ ഒരു ലളിതമായ Monaco അധിഷ്ഠിത എഡിറ്ററിൽ നിന്ന്
സമ്പൂർണ്ണ സവിശേഷതകളുള്ള ഒരു ടെസ്റ്റിംഗ് വർക്ക്സ്പേസാക്കി മാറ്റുന്നു. നാല് ടാബുകളും പങ്കിട്ട config പെയിനും റെൻഡർ ചെയ്യുന്ന `PlaygroundStudio`
ഷെൽ ഉപയോഗിച്ച് പഴയ `page.tsx`-നെ ഇത് മാറ്റിസ്ഥാപിക്കുന്നു.

## ടാബുകൾ

### ചാറ്റ് ടാബ്

`ChatPlayground.tsx`-നെ മൾട്ടി-ടേൺ സ്ട്രീമിംഗ് വർക്ക്ബെഞ്ചായി വികസിപ്പിക്കുന്നു:

- `MarkdownMessage.tsx` വഴി പൂർണ്ണ markdown റെൻഡറിംഗ് (കോഡ് ബ്ലോക്കുകൾ, പട്ടികകൾ, ലിസ്റ്റുകൾ, ലിങ്കുകൾ).
- പങ്കിട്ട Config പെയിനിൽ നിന്ന് ലഭിക്കുന്ന സിസ്റ്റം പ്രോംപ്റ്റ്.
- ഓരോ സന്ദേശത്തിനുമുള്ള ടോക്കൺ/ചെലവ് (പ്രോംപ്റ്റ് + പൂർത്തീകരണ ടോക്കണുകൾ).
- അവസാന പ്രതികരണം വീണ്ടും സൃഷ്ടിക്കുക.
- SSE സ്ട്രീമിംഗോടെ `POST /v1/chat/completions`-ലേക്ക് അയയ്ക്കുന്നു.

### താരതമ്യ ടാബ്

ഒരു പ്രോക്സിയുടെ പ്രധാന വ്യത്യസ്തത: ഒരു പ്രോംപ്റ്റ് പരമാവധി **4 മോഡലുകളിൽ സമാന്തരമായി** പ്രവർത്തിപ്പിക്കുക.

- പരമാവധി 4 കോളങ്ങൾ; ഓരോന്നും `/v1/chat/completions`-ൽ നിന്ന് സ്വതന്ത്രമായി സ്ട്രീം ചെയ്യുന്നു.
- കോളങ്ങൾ ചേർക്കുന്നതിനുള്ള `+ മോഡൽ ചേർക്കുക` ബട്ടൺ (Cmd+K ഷോർട്ട്കട്ട്).
- `എല്ലാം പ്രവർത്തിപ്പിക്കുക ▶`, `Promise.all` + ഓരോ കോളത്തിനും പ്രത്യേകം `AbortController` ഉപയോഗിച്ച് എല്ലാ സ്ട്രീമുകളും ഒരേസമയം ട്രിഗർ ചെയ്യുന്നു.
- ഗ്ലോബൽ **എല്ലാം റദ്ദാക്കുക** പ്രവർത്തനത്തിലിരിക്കുന്ന എല്ലാ സ്ട്രീമുകളും നിർത്തുന്നു.
- ഓരോ കോളത്തിലുമുള്ള `ProviderMetrics`, TTFT, TPS, ടോക്കണുകൾ, കണക്കാക്കിയ ചെലവ് എന്നിവ തത്സമയം കാണിക്കുന്നു.
- മെട്രിക്കുകൾക്ക് **"ക്ലയന്റ്-സൈഡ് ഏകദേശ കണക്ക്"** (D12) എന്ന് ലേബൽ നൽകിയിരിക്കുന്നു — ആദ്യ SSE ചങ്ക് മുതൽ അളക്കുന്നു.

### API ടാബ്

പരിചയസമ്പന്നരായ ഉപയോക്താക്കൾക്കായി യഥാർത്ഥ Monaco എഡിറ്ററിന്റെ 100% സവിശേഷതകളും നിലനിർത്തുന്നു (D14):

- 10 എൻഡ്പോയിന്റുകൾ: ചാറ്റ് പൂർത്തീകരണങ്ങൾ, പൂർത്തീകരണങ്ങൾ, embeddings, ചിത്രങ്ങൾ, ഓഡിയോ, സംഭാഷണം, ട്രാൻസ്ക്രിപ്ഷനുകൾ, മോഡറേഷനുകൾ, rerank, തിരയൽ.
- മൾട്ടിമോഡൽ ഫയൽ അപ്ലോഡ്.
- തത്സമയ ഔട്ട്പുട്ടോടുകൂടിയ SSE സ്ട്രീമിംഗ്.
- `ApiTab.tsx` ആയി പൊതിഞ്ഞിരിക്കുന്നു (lazy-loaded, `ssr: false`).

### ബിൽഡ് ടാബ്

ടൂളുകൾ/function calling, structured output UI:

- `ToolsBuilder.tsx` — ഓരോ ടൂളിനും JSON schema എഡിറ്ററോടുകൂടി `tools[]` ചേർക്കുക/എഡിറ്റ് ചെയ്യുക/നീക്കം ചെയ്യുക.
  `ToolDefinitionSchema` (Zod) വഴി പാരാമീറ്ററുകൾ സാധൂകരിക്കുന്നു.
- `StructuredOutputEditor.tsx` — JSON മോഡ് + JSON schema എഡിറ്റർ ടോഗിൾ ചെയ്യുക.
  `StructuredOutputSchema` (Zod) വഴി schema-യ്ക്കെതിരെ പ്രതികരണം സാധൂകരിക്കുന്നു.
- `tools[]` കൂടാതെ/അല്ലെങ്കിൽ `response_format` ഉപയോഗിച്ച് `/v1/chat/completions`-ലേക്ക് അഭ്യർത്ഥന അയയ്ക്കുന്നു.

## പ്രോംപ്റ്റ് മെച്ചപ്പെടുത്തൽ

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. "ക്വോട്ട ഉപയോഗിക്കും" എന്ന് മോഡൽ മുന്നറിയിപ്പ് നൽകുന്നു.
2. സ്ഥിരീകരിക്കുമ്പോൾ, റൂട്ടിലേക്ക് `{ system, prompt, model, tone }` അയയ്ക്കുന്നു.
3. റൂട്ട് `promptImprover.META_SYSTEM_PROMPT` ഉപയോഗിച്ച് ആന്തരികമായി `/v1/chat/completions` വിളിക്കുന്നു.
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` മടക്കിനൽകുന്നു.
5. UI കോൺഫിഗ് പെയിനിലെ സിസ്റ്റം പ്രോംപ്റ്റും ചാറ്റ് ടാബിലെ ഉപയോക്തൃ പ്രോംപ്റ്റും പാച്ച് ചെയ്യുന്നു.

## സ്ട്രീം മെട്രിക്കുകൾ

`useStreamMetrics.ts` + `streamMetrics.ts` (പ്യൂർ ഫങ്ഷൻ):

- `start()` — അഭ്യർത്ഥന ആരംഭിച്ച സമയം രേഖപ്പെടുത്തുന്നു.
- `onFirstChunk()` — TTFT രേഖപ്പെടുത്തുന്നു.
- `onChunk(n)` — പൂർത്തീകരണ ടോക്കണുകളുടെ എണ്ണം ശേഖരിക്കുന്നു.
- `finish(usage?)` — അന്തിമ മെട്രിക്കുകൾ കണക്കാക്കുന്നു: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- `src/lib/playground/types.ts`-ലെ സ്റ്റാറ്റിക് പട്ടികയിൽ നിന്നുള്ള നിരക്കുകൾ ("കണക്കാക്കിയത്" എന്ന് ലേബൽ ചെയ്തിരിക്കുന്നു — D13).
