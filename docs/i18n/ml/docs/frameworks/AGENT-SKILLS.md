> **അവസാനം പുതുക്കിയത്:** 2026-08-02 — v3.8.50

OmniRoute-ന്റെ REST API-യും CLI-യും എങ്ങനെ ഉപയോഗിക്കണമെന്ന് ബാഹ്യ ഏജന്റുമാരെയും MCP ക്ലയന്റുകളെയും A2A ഓർക്കസ്ട്രേറ്ററുകളെയും പഠിപ്പിക്കുന്ന ഘടനാപരമായ SKILL.md ഫയലുകളാണ് Agent Skills. OmniRoute-നുള്ളിൽ നിർവഹിക്കപ്പെടുന്ന LLM ടൂൾ നിർവചനങ്ങളായ [Omni Skills](./SKILLS.md)-ൽ നിന്ന് വ്യത്യസ്തമായി, Agent Skills ഒരു _ഡോക്യുമെന്റേഷൻ കാറ്റലോഗ്_ ആണ് — ഏജന്റ് കോൺടെക്സ്റ്റിലേക്ക് നേരിട്ട് നൽകാവുന്ന സ്റ്റാറ്റിക് മാർക്ക്ഡൗൺ.

## അവലോകനം

കാറ്റലോഗിൽ **45 Agent Skills** അടങ്ങിയിരിക്കുന്നു (23 REST API + 21 CLI + 1 കോൺഫിഗറേഷൻ വർക്ക്ഫ്ലോ). ഓരോ സ്കില്ലിലും ഇവയുണ്ട്:

- ഒരു **കാനോണിക്കൽ ID** (`omni-auth`, `cli-serve` തുടങ്ങിയവ)
- YAML ഫ്രണ്ട്മാറ്ററും (`name`, `description`) സമ്പന്നമായ മാർക്ക്ഡൗൺ ഉള്ളടക്കവുമുള്ള `skills/{id}/SKILL.md` എന്ന **SKILL.md** ഫയൽ
- OpenAPI സ്പെക്കിൽ നിന്നും CLI രജിസ്ട്രിയിൽ നിന്നും ലഭ്യമാക്കുന്ന **REST എൻഡ്പോയിന്റുകൾ** (API സ്കില്ലുകൾ) അല്ലെങ്കിൽ **CLI സബ്കമാൻഡുകൾ** (CLI സ്കില്ലുകൾ)
- തത്സമയം ലഭ്യമാക്കുന്നതിനുള്ള ഒരു **GitHub റോ URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API കണ്ടെത്തൽ

| എൻഡ്പോയിന്റ്                 | രീതി | വിവരണം                                                                          | പ്രാമാണീകരണം |
| :--------------------------- | :--- | :------------------------------------------------------------------------------ | :----------- |
| `/api/agent-skills`          | GET  | കാറ്റലോഗ് പട്ടികപ്പെടുത്തുക (ഐച്ഛികം: `?category=api\|cli\|config&area=<area>`) | ആവശ്യമില്ല   |
| `/api/agent-skills/{id}`     | GET  | ഒരു സ്കില്ലിന്റെ മെറ്റാഡാറ്റ നേടുക                                              | ആവശ്യമില്ല   |
| `/api/agent-skills/{id}/raw` | GET  | SKILL.md `text/markdown` ആയി ലഭ്യമാക്കുക                                        | ആവശ്യമില്ല   |
| `/api/agent-skills/coverage` | GET  | കവറേജ് സ്ഥിതിവിവരക്കണക്കുകൾ (എത്ര SKILL.md ഫയലുകൾ നിലവിലുണ്ട്)                  | ആവശ്യമില്ല   |
| `/api/agent-skills/generate` | POST | ജനറേറ്റർ പ്രവർത്തിപ്പിക്കുക (dryRun/prune/onlyIds)                              | മാനേജ്മെന്റ് |

ഉദാഹരണം — എല്ലാ API സ്കില്ലുകളും പട്ടികപ്പെടുത്തുക:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ഉദാഹരണം — ഒരൊറ്റ SKILL.md ലഭ്യമാക്കുക:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## MCP കണ്ടെത്തൽ

`read:catalog` സ്കോപ്പിന് കീഴിൽ മൂന്ന് MCP ടൂളുകൾ രജിസ്റ്റർ ചെയ്തിട്ടുണ്ട്:

| ടൂൾ                               | വിവരണം                                                               |
| :-------------------------------- | :------------------------------------------------------------------- |
| `omniroute_agent_skills_list`     | സ്കില്ലുകൾ പട്ടികപ്പെടുത്തുക (ഐച്ഛിക `category` / `area` ഫിൽട്ടറുകൾ) |
| `omniroute_agent_skills_get`      | `id` ഉപയോഗിച്ച് ഒരു സ്കില്ലിന്റെ മെറ്റാഡാറ്റയും SKILL.md-ഉം നേടുക    |
| `omniroute_agent_skills_coverage` | കവറേജ് സ്ഥിതിവിവരക്കണക്കുകൾ (API/CLI നിലവിലുള്ളത്/ആകെ)               |

സ്കോപ്പ് വയറിങ്ങിനും പ്രാമാണീകരണത്തിനും [MCP-SERVER.md](./MCP-SERVER.md) കാണുക.

## A2A കണ്ടെത്തൽ

A2A സ്കിൽ `list-capabilities`, 45 സ്കില്ലുകളുള്ള പൂർണ്ണ കാറ്റലോഗ് ഒരു മാർക്ക്ഡൗൺ പട്ടിക ആർട്ടിഫാക്റ്റായി തിരികെ നൽകുന്നു. ബാഹ്യ ഓർക്കസ്ട്രേറ്ററുകൾക്ക് ഇത് ഇപ്രകാരം ഇൻവോക്ക് ചെയ്യാം:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

പ്രോട്ടോക്കോൾ വിശദാംശങ്ങൾക്ക് [A2A-SERVER.md](./A2A-SERVER.md) കാണുക.

### 1. REST വഴിയുള്ള കണ്ടെത്തൽ

```bash
# പൂർണ്ണ കാറ്റലോഗ് നേടുക

# സന്ദർഭ ഇൻജക്ഷനുവേണ്ടി SKILL.md നേടുക
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. MCP വഴിയുള്ള കണ്ടെത്തൽ

```typescript
// ഒരു Claude Desktop / Cursor MCP ക്ലയന്റിൽ:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",

```

### 3. A2A വഴിയുള്ള കണ്ടെത്തൽ

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={

```

## ജനറേറ്റർ

ജനറേറ്റർ ക്രമീകരിച്ച കാറ്റലോഗ് + OpenAPI സ്പെക് + CLI രജിസ്ട്രി വായിക്കുകയും ഓരോ എൻട്രിക്കുമായി `skills/{id}/SKILL.md` എഴുതുകയും ചെയ്യുന്നു:

```bash
# പ്രിവ്യൂ (ഡ്രൈ റൺ, ഒന്നും എഴുതില്ല)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# പൂർണ്ണമായി വീണ്ടും ജനറേറ്റ് ചെയ്യുക
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# നിർദ്ദിഷ്ട ID-കൾ വീണ്ടും ജനറേറ്റ് ചെയ്യുക
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

ജനറേറ്ററിന്റെ പ്രതികരണം ഒരു `GeneratorReport` ആണ്:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
