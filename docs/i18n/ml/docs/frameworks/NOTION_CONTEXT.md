## ഇത് എന്താണ്

OmniRoute-ന് ഒരു **Notion** വർക്ക്സ്പേസിനെ **കോൺടെക്സ്റ്റ് ഉറവിടമായി** ബന്ധിപ്പിക്കാൻ കഴിയും — ബിൽറ്റ്-ഇൻ MCP സെർവർ വഴി ഏജന്റുകൾക്ക് ഉപയോഗിക്കാനാകുന്ന ഒരു റീഡ്/റൈറ്റ്
നോളജ് ബേസ്. ഒരു Notion ഇന്റഗ്രേഷൻ ടോക്കൺ ക്രമീകരിച്ചുകഴിഞ്ഞാൽ, പേജുകളും ഡാറ്റാബേസുകളും തിരയാനും,
പേജ് ഉള്ളടക്കവും ബ്ലോക്ക് ട്രീകളും വായിക്കാനും, ഫിൽട്ടറുകൾ/സോർട്ടുകൾ ഉപയോഗിച്ച് ഡാറ്റാബേസുകൾ ക്വറി ചെയ്യാനും, പുതിയ
ബ്ലോക്കുകൾ കൂട്ടിച്ചേർക്കാനും MCP ടൂളുകൾ ഒരു LLM-നെ അനുവദിക്കുന്നു — ഇവയെല്ലാം OmniRoute വഴി പ്രോക്സി ചെയ്യപ്പെടുന്നു (റീട്രൈ, ടൈംഔട്ട്, പിശക് വർഗ്ഗീകരണം എന്നിവയോടെ);
അതിനാൽ മോഡൽ ഒരിക്കലും Notion API നേരിട്ട് ഉപയോഗിക്കുന്നില്ല.

ഈ ഇന്റഗ്രേഷൻ ഔദ്യോഗിക Notion REST API-യുടെ
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) ലളിതവും സുരക്ഷിതവുമാക്കിയ ഒരു റാപ്പറാണ്. ക്ലയന്റ്
(`src/lib/notion/api.ts`) ഇനിപ്പറയുന്നവ ചേർക്കുന്നു:

- `429`, `5xx` എന്നിവയ്ക്കായി **എക്സ്പോണൻഷ്യൽ ബാക്ക്ഓഫോടെയുള്ള റീട്രൈ** (പരമാവധി 3 ശ്രമങ്ങൾ).
- `AbortController` വഴിയുള്ള **55-സെക്കൻഡ് അഭ്യർത്ഥനാ ടൈംഔട്ട്**.
- **ടൈപ്പ് ചെയ്ത പിശക് വർഗ്ഗീകരണം** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  സൂചനകൾ പാലിക്കുന്നു), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- പിശകുകൾ പുറത്തുകാണിക്കുന്നതിന് മുമ്പ് സ്റ്റാക്ക്-ട്രേസ് പോലുള്ള ഭാഗങ്ങൾ നീക്കം ചെയ്യുന്ന **സന്ദേശ ശുചീകരണം**.

## സജ്ജീകരണം

Notion ടോക്കണിനായി **പരിസ്ഥിതി വേരിയബിൾ ഇല്ല** — ഇത്
`src/lib/db/notion.ts` വഴി SQLite `key_value` പട്ടികയിൽ (നെയിംസ്പേസ് `notion`, കീ `integration_token`) സംഭരിക്കപ്പെടുന്നു.
Endpoint ഡാഷ്ബോർഡിലെ **Context Sources** ടാബിൽ നിന്ന്
(`ObsidianSourceCard`-ന്റെ സമാന ഘടകമായ `NotionSourceCard`) ഇത് ക്രമീകരിക്കുക, അല്ലെങ്കിൽ ക്രമീകരണ REST API ഉപയോഗിക്കുക.

> [!NOTE]
> ടോക്കൺ ഒരു **Notion ഇന്റേണൽ ഇന്റഗ്രേഷൻ ടോക്കൺ** ആണ്.
> <https://www.notion.com/my-integrations>-ൽ ഒരു ഇന്റഗ്രേഷൻ സൃഷ്ടിക്കുക, തുടർന്ന് OmniRoute ആക്സസ് ചെയ്യണമെന്ന് നിങ്ങൾ ആഗ്രഹിക്കുന്ന
> പേജുകൾ/ഡാറ്റാബേസുകൾ ആ ഇന്റഗ്രേഷനുമായി പങ്കിടുക (Notion-ന്റെ അനുമതി മോഡൽ ഷെയർ അടിസ്ഥാനമാക്കിയുള്ളതാണ്,
> വർക്ക്സ്പേസ്-വ്യാപകമല്ല).

### REST വഴി ക്രമീകരിക്കുക

```bash
# ഇന്റഗ്രേഷൻ ടോക്കൺ സംരക്ഷിച്ച് സാധൂകരിക്കുക (POST ഒരു പരീക്ഷണ തിരച്ചിൽ നടത്തി സാധൂകരിക്കുന്നു)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# കണക്ഷൻ നില പരിശോധിക്കുക
curl http://localhost:20128/api/settings/notion

# വിച്ഛേദിക്കുക (സംഭരിച്ച ടോക്കൺ മായ്ക്കുന്നു)
curl -X DELETE http://localhost:20128/api/settings/notion
```

മൂന്ന് രീതികൾക്കും ഡാഷ്ബോർഡ് പ്രാമാണീകരണം (`isAuthenticated`) ആവശ്യമാണ്. `POST` ചെയ്യുമ്പോൾ,
OmniRoute ടോക്കൺ സംരക്ഷിക്കുകയും ഉടൻതന്നെ 1 ഫലം ആവശ്യപ്പെടുന്ന ഒരു പരീക്ഷണ തിരച്ചിൽ നടത്തുകയും ചെയ്യുന്നു; Notion
ഒരു പിശക് ഒബ്ജക്റ്റ് മടക്കിനൽകുകയാണെങ്കിൽ, ടോക്കൺ മായ്ക്കപ്പെടുകയും കോൾ `400` പിശകോടെ പരാജയപ്പെടുകയും ചെയ്യും.

## MCP ടൂളുകൾ (6)

`open-sse/mcp-server/tools/notionTools.ts`-ൽ നിർവചിച്ചിരിക്കുന്നു. കോൾ ചെയ്യുന്ന
സമയത്ത് `getNotionToken()` വഴി ടോക്കൺ കണ്ടെത്തുന്നു; ഒന്നും ക്രമീകരിച്ചിട്ടില്ലെങ്കിൽ ടൂൾ
`"Notion integration token not configured. Set it in Settings > Context Sources."` എന്ന പിശക് ഉയർത്തുന്നു.

| ടൂൾ                          | സ്കോപ്പ്       | വിവരണം                                                                                                                                       |
| ---------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | ടെക്സ്റ്റ് ക്വറി ഉപയോഗിച്ച് പേജുകളും ഡാറ്റാബേസുകളും തിരയുന്നു (ശീർഷകങ്ങൾ, ID-കൾ, URL-കൾ എന്നിവ മടക്കിനൽകുന്നു). പേജിനേറ്റ് ചെയ്തിരിക്കുന്നു. |
| `notion_get_page`            | `read:notion`  | ഒരു പേജിന്റെ ID ഉപയോഗിച്ച് അതിന്റെ ഉള്ളടക്കവും മെറ്റാഡാറ്റയും നേടുന്നു.                                                                      |
| `notion_list_block_children` | `read:notion`  | ഒരു ബ്ലോക്കിന്റെയോ പേജിന്റെയോ എല്ലാ ചൈൽഡ് ബ്ലോക്കുകളും (ബ്ലോക്ക് ട്രീ) പട്ടികപ്പെടുത്തുന്നു. പേജിനേറ്റ് ചെയ്തിരിക്കുന്നു.                    |
| `notion_query_database`      | `read:notion`  | ഓപ്ഷണൽ `filter` + `sorts` (Notion API ഫോർമാറ്റ്) ഉപയോഗിച്ച് ഒരു ഡാറ്റാബേസ് ക്വറി ചെയ്യുന്നു. പേജിനേറ്റ് ചെയ്തിരിക്കുന്നു.                    |
| `notion_get_database`        | `read:notion`  | ID ഉപയോഗിച്ച് ഒരു ഡാറ്റാബേസിന്റെ സ്കീമ/മെറ്റാഡാറ്റ നേടുന്നു.                                                                                 |
| `notion_append_blocks`       | `write:notion` | നിലവിലുള്ള ഒരു ബ്ലോക്കിലേക്കോ പേജിലേക്കോ ചൈൽഡ് ബ്ലോക്കുകൾ കൂട്ടിച്ചേർക്കുന്നു (ഒരു അഭ്യർത്ഥനയിൽ പരമാവധി 100 ബ്ലോക്കുകൾ).                     |

### ഇൻപുട്ട് പാരാമീറ്ററുകൾ

- `notion_search` — `query` (1–500 പ്രതീകങ്ങൾ), `pageSize` (1–100, ഡിഫോൾട്ട് 20),
  `startCursor` (ഓപ്ഷണൽ).
- `notion_get_page` — `pageId` (32-പ്രതീക ഹെക്സ് അല്ലെങ്കിൽ UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, ഡിഫോൾട്ട് 50),
  `startCursor` (ഓപ്ഷണൽ).
- `notion_query_database` — `databaseId`, `filter` (ഓപ്ഷണൽ, Notion ഫിൽട്ടർ ഫോർമാറ്റ്),
  `sorts` (ഓപ്ഷണൽ അറേ), `pageSize` (1–100, ഡിഫോൾട്ട് 50), `startCursor` (ഓപ്ഷണൽ).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (ബ്ലോക്ക് ഒബ്ജക്റ്റുകളുടെ അറേ),
  `after` (ഓപ്ഷണൽ സ്ഥാനം).

### സ്കോപ്പുകൾ

റീഡ് ടൂളുകൾക്ക് `read:notion` ആവശ്യമാണ്; റൈറ്റ് ടൂളിന് `write:notion` ആവശ്യമാണ്.
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` ആയിരിക്കുമ്പോൾ മാത്രം
`open-sse/mcp-server/server.ts`-ലെ `withScopeEnforcement()` ഉപയോഗിച്ച് സ്കോപ്പുകൾ നിർബന്ധിതമാക്കപ്പെടുന്നു;
കോൾ ചെയ്യുന്നയാളുടെ അനുവദനീയമായ സ്കോപ്പുകൾ `OMNIROUTE_MCP_SCOPES`-ൽ നിന്ന് (കോമ ഉപയോഗിച്ച് വേർതിരിച്ചത്) അല്ലെങ്കിൽ
പ്രാമാണീകരിച്ച API കീയുടെ സ്കോപ്പ് കോൺടെക്സ്റ്റിൽ നിന്ന് ലഭിക്കുന്നു. പൂർണ്ണമായ
സ്കോപ്പ് മോഡലിനായി [MCP-SERVER.md](./MCP-SERVER.md) കാണുക.

| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` മടക്കിനൽകുന്നു.        |
| `POST`   | `/api/settings/notion` | ഇന്റഗ്രേഷൻ ടോക്കൺ സംരക്ഷിച്ച് സാധൂകരിക്കുന്നു.   |
| `DELETE` | `/api/settings/notion` | വിച്ഛേദിക്കുന്നു (സംഭരിച്ച ടോക്കൺ മായ്ക്കുന്നു). |

> ഇവ ഡാഷ്ബോർഡ് ക്രമീകരണ റൂട്ടുകളാണ്. പൊതു `/v1` Notion പ്രോക്സി
> എൻഡ്പോയിന്റ് **ഇല്ല** — മുകളിലുള്ള MCP ടൂളുകളിലൂടെ മാത്രമാണ് Notion ആക്സസ് ചെയ്യുന്നത്.

## ഉപയോഗ സാഹചര്യങ്ങൾ

- **അറിവിനെ അടിസ്ഥാനമാക്കിയുള്ള ഉത്തരങ്ങൾ** — ഉത്തരം നൽകുന്നതിന് മുമ്പ് വർക്ക്സ്പേസിൽ `notion_search` നടത്താനും
  ഏറ്റവും പ്രസക്തമായ ഫലത്തിൽ `notion_get_page` ഉപയോഗിക്കാനും ഒരു ഏജന്റിനെ അനുവദിക്കുക, അതുവഴി പ്രതികരണങ്ങളിൽ യഥാർത്ഥ ആന്തരിക ഡോക്യുമെന്റുകൾ ഉദ്ധരിക്കപ്പെടും.
- **ഡാറ്റാബേസ് അടിസ്ഥാനമാക്കിയുള്ള വർക്ക്ഫ്ലോകൾ** — ഫിൽട്ടറുകളും ക്രമീകരണങ്ങളും ഉപയോഗിച്ച് ഒരു ടാസ്ക്/CRM ഡാറ്റാബേസിൽ
  `notion_query_database` നടത്തുക, തുടർന്ന് വരികൾ സംഗ്രഹിക്കുകയോ മുൻഗണന നിശ്ചയിക്കുകയോ ചെയ്യുക.
- **തിരികെ എഴുതൽ / ലോഗിംഗ്** — മീറ്റിംഗ് കുറിപ്പുകൾ, പ്രവർത്തന
  സംഗ്രഹങ്ങൾ, അല്ലെങ്കിൽ ഏജന്റ് ഔട്ട്പുട്ട് നിലവിലുള്ള ഒരു പേജിലേക്ക് ചേർക്കാൻ `notion_append_blocks` ഉപയോഗിക്കുക (ചേർക്കൽ മാത്രം; നശിപ്പിക്കുന്ന തിരുത്തലുകളില്ല).
- **ഘടനാ പര്യവേക്ഷണം** — ഒരു പേജിന്റെ ബ്ലോക്ക് ട്രീയിലൂടെ സഞ്ചരിക്കാൻ `notion_list_block_children` ഉപയോഗിക്കുക,
  അല്ലെങ്കിൽ ഒരു ഡാറ്റാബേസ് ക്വറി ചെയ്യുന്നതിന് മുമ്പ് അതിന്റെ പ്രോപ്പർട്ടി സ്കീമ കണ്ടെത്താൻ `notion_get_database` ഉപയോഗിക്കുക.
