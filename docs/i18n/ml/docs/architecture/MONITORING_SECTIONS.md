ഡാഷ്ബോർഡ് സൈഡ്ബാറിൽ (Group B-യ്ക്ക് ശേഷം) ഇനിപ്പറയുന്ന ഉന്നതതല വിഭാഗങ്ങൾ ഈ ക്രമത്തിൽ ഉണ്ടായിരിക്കും:

```
ഹോം

നിരീക്ഷണം         ← പുനഃസംഘടിപ്പിച്ചത് (Group B, plan 16)
...
```

## ചെലവുകൾ വിഭാഗം (പുതിയത്, ലെവൽ 1)

പാത്ത് പ്രിഫിക്സ്: `/dashboard/costs/`

| ഇനം             | URL                                  | വിവരണം                                                 |
| --------------- | ------------------------------------ | ------------------------------------------------------ |
| അവലോകനം         | `/dashboard/costs`                   | സംയോജിത ചെലവ് ഡാഷ്ബോർഡ് (Analytics-ൽ നിന്ന് മാറ്റിയത്) |
| നിരക്കുകൾ       | `/dashboard/costs/pricing`           | ഓരോ മോഡലിനുമുള്ള നിരക്ക് പട്ടിക                        |
| ബജറ്റ്          | `/dashboard/costs/budget`            | ബജറ്റ് പരിധികൾ + അലേർട്ടുകൾ                            |
| ക്വാട്ട പങ്കിടൽ | `/dashboard/costs/quota-share`       | Quota Share പൂളുകൾ + ഉപയോഗം                            |
| പ്ലാൻ കോൺഫിഗ്   | `/dashboard/costs/quota-share/plans` | ഓരോ പ്രൊവൈഡറിനുമുള്ള പ്ലാൻ ഓവർറൈഡുകൾ                   |

**യുക്തി**: നിരക്കുകൾ, ബജറ്റ്, ക്വാട്ട പങ്കിടൽ എന്നിവ മുമ്പ്
`Monitoring > Costs Parameters` എന്നതിന് കീഴിലായിരുന്നു. അവയെ ഒരു പ്രത്യേക ഉന്നതതല വിഭാഗത്തിലേക്ക്
മാറ്റുന്നത്, നിരീക്ഷണക്ഷമതാ ടൂളുകളിലൂടെ നാവിഗേറ്റ് ചെയ്യാതെ തന്നെ അവ കണ്ടെത്താൻ സഹായിക്കുന്നു.

## നിരീക്ഷണ വിഭാഗം (പുനഃസംഘടിപ്പിച്ചത്)

നിരീക്ഷണ വിഭാഗത്തിൽ ഇപ്പോൾ **ഏറ്റവും മുകളിൽ ആക്റ്റിവിറ്റി**, തുടർന്ന് **3 ഉപഗ്രൂപ്പുകൾ** എന്നിവയുണ്ട്:

```
നിരീക്ഷണം
├── ആക്റ്റിവിറ്റി             ← ടൈംലൈൻ ഫീഡ് (ഉന്നതതല ഇനം)
├── ലോഗുകൾ ഗ്രൂപ്പ്
│   ├── ലോഗുകൾ (എല്ലാം)
│   ├── പ്രോക്സി ലോഗുകൾ
│   └── കൺസോൾ ലോഗുകൾ
├── ഓഡിറ്റ് ഗ്രൂപ്പ്
│   ├── ഓഡിറ്റ് ലോഗ്
│   ├── MCP ഓഡിറ്റ്
│   └── A2A ഓഡിറ്റ്
└── സിസ്റ്റം ഗ്രൂപ്പ്
    ├── ഹെൽത്ത്
    └── റൺടൈം
```

### പഴയ ഘടനയിൽ നിന്ന് മാറിയ കാര്യങ്ങൾ

| മുമ്പ്                                                                                 | ഇപ്പോൾ                                           |
| -------------------------------------------------------------------------------------- | ------------------------------------------------ |

| നിരപ്പായ പട്ടിക: Logs, Activity (logs), Audit, Health, Runtime, Pricing, Budget, Quota | ഘടനാപരമായ 3 ഗ്രൂപ്പുകൾ + പ്രത്യേക Costs വിഭാഗം   |

## ആക്റ്റിവിറ്റിയും ഓഡിറ്റ് ലോഗും

ഇവ രണ്ടും ഇപ്പോൾ വ്യത്യസ്തമാണ്:

| മാനം                     | ആക്റ്റിവിറ്റി (`/dashboard/activity`)                                            | ഓഡിറ്റ് ലോഗ് (`/dashboard/audit`)                 |
| ------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------- |
| **ഉദ്ദേശ്യം**            | ഉപയോക്താക്കൾക്കായുള്ള ഇവന്റ് ഫീഡ് ("അടുത്തിടെ എന്താണ് സംഭവിച്ചത്")               | അനുപാലന / സുരക്ഷാ ലോഗ്                            |
| **ഡാറ്റ ഉറവിടം**         | `GET /api/compliance/audit-log?level=high`                                       | `GET /api/compliance/audit-log?level=all`         |
| **ഫോർമാറ്റ്**            | ദിവസം അനുസരിച്ച് ഗ്രൂപ്പ് ചെയ്ത ടൈംലൈൻ, വായിക്കാൻ എളുപ്പമുള്ള ക്രിയകൾ + ഐക്കണുകൾ | സാന്ദ്രമായ പേജിനേറ്റഡ് പട്ടിക, ഒരു പേജിൽ 50 എണ്ണം |
| **ഫിൽട്ടറുകൾ**           | ഇവന്റ് തരം വിഭാഗം                                                                | പ്രവർത്തനം, തീവ്രത, ആക്ടർ, തീയതി പരിധി            |
| **എക്സ്പോർട്ട്**         | ലഭ്യമല്ല                                                                         | JSON എക്സ്പോർട്ട്                                 |
| **ആക്ടർ ഫിൽട്ടർ**        | ബാധകമല്ല                                                                         | ആക്ടർ അനുസരിച്ച് ഫിൽട്ടർ ചെയ്യാം                  |
| **കാണിക്കുന്ന ഇവന്റുകൾ** | ഉന്നതതല പ്രവർത്തനങ്ങൾ മാത്രം (അനുവദനപ്പട്ടിക)                                    | എല്ലാ ഓഡിറ്റ് ഇവന്റുകളും                          |

### ഉന്നതതല പ്രവർത്തനങ്ങളുടെ അനുവദനപ്പട്ടിക

`src/lib/audit/highLevelActions.ts`-ൽ നിർവചിച്ചിരിക്കുന്നു. ആക്റ്റിവിറ്റി ഫീഡിൽ ഏതൊക്കെ ഇവന്റുകൾ
ദൃശ്യമാകണമെന്ന് ഇത് നിയന്ത്രിക്കുന്നു. അനുവദനപ്പട്ടികയിൽ ഉൾപ്പെടുന്നവ:

- പ്രൊവൈഡറെ ചേർക്കൽ/നീക്കംചെയ്യൽ/പരിശോധിക്കൽ ഇവന്റുകൾ
- കോംബോ സൃഷ്ടിക്കൽ/അപ്ഡേറ്റ് ചെയ്യൽ/ഇല്ലാതാക്കൽ
- API കീയുടെ ലൈഫ്സൈക്കിൾ (സൃഷ്ടിക്കൽ, അസാധുവാക്കൽ, റൊട്ടേറ്റ് ചെയ്യൽ)
- ബജറ്റ് പരിധിയിലെത്തൽ
- ഓതന്റിക്കേഷൻ ലോഗിൻ/ലോഗൗട്ട്
- ക്ലൗഡ് ഏജന്റ് സെഷൻ സൃഷ്ടിക്കൽ
- MCP ടൂൾ രജിസ്ട്രേഷൻ
- വെബ്ഹുക്ക് സൃഷ്ടിക്കൽ/ഇല്ലാതാക്കൽ
- ക്വാട്ട പൂൾ/പ്ലാൻ മാറ്റങ്ങൾ (`quota.*` പ്രവർത്തനങ്ങൾ, Group B)
- പ്ലാറ്റ്ഫോം ഇവന്റുകൾ (അപ്ഡേറ്റ്, ഡിപ്ലോയ്)
- സ്കിൽ ഇൻസ്റ്റാൾ ചെയ്യൽ/നീക്കംചെയ്യൽ

ഈ പട്ടികയിൽ ഇല്ലാത്ത ഇവന്റുകൾ ഓഡിറ്റ് ലോഗിൽ മാത്രം ദൃശ്യമാകും.

### പുതിയ ഉന്നതതല പ്രവർത്തനം ചേർക്കുന്നത്

`src/lib/audit/highLevelActions.ts` എഡിറ്റ് ചെയ്ത് പ്രവർത്തന സ്ട്രിംഗ്
`HIGH_LEVEL_ACTIONS`-ലേക്ക് ചേർക്കുക. ഇതിന് ഒരു PR ആവശ്യമാണ് (ഈ പട്ടിക കോഡാണ്, DB വഴി കോൺഫിഗർ ചെയ്യാനാവില്ല).
അനുബന്ധ ഐക്കൺ `src/lib/audit/activityIcons.ts`-ലേക്ക് ചേർക്കാം.

## റീഡയറക്റ്റ്: `/dashboard/logs/activity`

പഴയ പാത്തായ `/dashboard/logs/activity`,
`src/app/(dashboard)/dashboard/logs/activity/page.tsx`-ലെ `permanentRedirect()` വഴി
`/dashboard/activity`-ലേക്ക് സ്ഥിരമായി റീഡയറക്റ്റ് ചെയ്യുന്നു (HTTP 308).

പഴയ ID പരാമർശിക്കുന്ന ഉപയോക്തൃ പ്രീസെറ്റുകൾ തകരുന്നത് ഒഴിവാക്കാൻ, ലെഗസി സൈഡ്ബാർ ID ആയ `logs-activity`,
`HIDEABLE_SIDEBAR_ITEM_IDS`-ൽ നിലനിർത്തിയിട്ടുണ്ട്
(എന്നാൽ `SIDEBAR_DEFINITIONS`-ൽ നിന്ന് നീക്കംചെയ്തു).
