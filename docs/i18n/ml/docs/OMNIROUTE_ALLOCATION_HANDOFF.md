അലോക്കേഷൻ എന്നത് പ്രൊവൈഡർ ക്വോട്ടയല്ല.

ഏത് API കീകൾക്ക് ഒരു പ്രൊവൈഡർ പൂൾ ഉപയോഗിക്കാമെന്നും ഹാർഡ്, സോഫ്റ്റ്, അല്ലെങ്കിൽ ബർസ്റ്റ് നയങ്ങൾ എങ്ങനെ ബാധകമാകുമെന്നും ക്വോട്ട പൂളുകൾ നിർവചിക്കുന്നു. പ്രൊവൈഡർ റിപ്പോർട്ട് ചെയ്യുന്ന ബാഹ്യ ശേഷിയോ വ്യക്തമായി കോൺഫിഗർ ചെയ്ത ഉറവിടമോ ആണ് പ്രൊവൈഡർ ക്വോട്ട. Ghostlight-ന്റെ ആന്തരിക ബജറ്റുകൾ അഡ്മിനിസ്ട്രേറ്റർ നിർവചിക്കുന്ന ഭരണപരമായ പരിധികളാണ്.

`ensurePool` ഓപ്പറേഷൻ ഐഡംപൊട്ടന്റാണ്: സമാനമായ ഒരു പൂൾ മാറ്റമില്ലാതെ തുടരുന്നു, മാറ്റം വരുത്തിയ അലോക്കേഷൻ അപ്ഡേറ്റ് ചെയ്യപ്പെടുന്നു, നിലവിലില്ലാത്ത പൂൾ സൃഷ്ടിക്കപ്പെടുന്നു. ഇത് ഓട്ടോമേഷനും പരിധിബദ്ധമായ API കോളർമാർക്കുമായി ഉദ്ദേശിച്ചിട്ടുള്ളതാണ്.

റീഡ്-ഒൺലി സ്റ്റാറ്റസ് എൻഡ്പോയിന്റ് `GET /api/omniroute/status` ആണ്. വെരിഫിക്കേഷൻ കമാൻഡ് `npm run omniroute:verify` ആണ്; ഇത് ലൈവ് മോഡൽ റിക്വസ്റ്റ് ഒന്നും നടത്തില്ല.
