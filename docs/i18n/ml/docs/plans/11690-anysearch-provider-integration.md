## 1. സേവനത്തിന്റെ അടിസ്ഥാന വസ്തുതകൾ (ഔദ്യോഗിക ഡോക്യുമെന്റേഷൻ, ക്രോസ്-ചെക്ക് ചെയ്തത്)

- അടിസ്ഥാന URL: `https://api.anysearch.com` (REST) + `POST /mcp` (MCP, JSON-RPC 2.0).
- `POST /v1/search` - പാരാമീറ്ററുകൾ: `query` (നിർബന്ധം), `max_results` (1-10, ഡിഫോൾട്ട് 10), `tag` (`{domain}.{sub_domain}` വെർട്ടിക്കൽ റൂട്ടിങ്), `zone` (cn/intl), `language`, `params` (ഘടനാപരമായ വെർട്ടിക്കൽ ഫീൽഡുകൾ), `format` (json/markdown).
- `GET /v1/sub-domains?domain=...` - ശേഷികളുടെ കാറ്റലോഗ്, ക്വോട്ടയിൽ കണക്കാക്കില്ല.
- `POST /v1/extract` - `{url, title, content}` ഫെച്ച്/എക്സ്ട്രാക്റ്റ് ചെയ്യുന്നു; കർശനമായ JSON ബോഡി, 16 KiB പരിധി.
- `POST /v1/auth/email/register` - ഒറ്റ കോളിലുള്ള രജിസ്ട്രേഷൻ, ഒറ്റത്തവണ ഉപയോഗിക്കാവുന്ന പ്ലെയിൻടെക്സ്റ്റ് കീ `as_sk_...` തിരികെ നൽകുന്നു.
- ഓതന്റിക്കേഷൻ: `Authorization: Bearer <as_sk_...>` ഐച്ഛികമാണ്; അജ്ഞാത ആക്സസ് പ്രതിദിന സൗജന്യ ക്വോട്ട ഉപയോഗിക്കുന്ന ഓരോ-IP പരിധികളിലേക്ക് താഴ്ത്തപ്പെടുന്നു; അസാധുവായ കീ 401/403 തിരികെ നൽകും, നിശ്ശബ്ദമായ അജ്ഞാത ഫാൾബാക്ക് ഉണ്ടായിരിക്കില്ല.
- സൗജന്യ ടയർ: പ്രതിദിനം 1000 അഭ്യർത്ഥനകൾ, ഓരോ കീയ്ക്കും 20 QPS. പണമടച്ചുള്ള ടയർ: വില നിശ്ചയിച്ചിട്ടില്ല (ഉടൻ വരുന്നു).
- റെസ്പോൺസ് എൻവലപ്പ്: വിജയം `{code: 0, message: "success", request_id, data}`; പരാജയം `{code: -1, message}`. ഓതന്റിക്കേഷൻ/ക്വോട്ട പിശകുകളിൽ ഘടനാപരമായ `error_code` ഉണ്ടാകില്ല (സന്ദേശത്തിലെ ടെക്സ്റ്റാണ് സൂചന); എക്സ്ട്രാക്റ്റുമായി ബന്ധപ്പെട്ട പിശകുകളിൽ `error_code` (`invalid_extract_url`, `extract_failed`) ഉണ്ടായിരിക്കും. 429-ൽ `Retry-After` ഹെഡർ ഉണ്ടായിരിക്കില്ല.

## 3. തീരുമാനങ്ങൾ (എല്ലാം 2026-08-26-ന് എടുത്തത്)

1. **റൂട്ടിംഗ് നിലപാട്: `fallbackOnly`.** യുക്തി: ചെലവ് 0 ആയ ഒരു സൗജന്യ ദാതാവ് ഓട്ടോമാറ്റിക് ചെലവ്-അധിഷ്ഠിത റൂട്ടിംഗിൽ ഒരിക്കലും ആധിപത്യം പുലർത്തരുത്; വ്യക്തമായ തിരഞ്ഞെടുപ്പിനും ഫെയിൽഓവർ റിട്ടേണിനും മാറ്റമില്ല. മുൻമാതൃക: ലയിപ്പിച്ച xquik എൻട്രി.
2. **പരിധി: v1-ൽ `POST /v1/extract` വഴി webSearch + webFetch.** tavily/exa-യുടെ ദ്വി-ശേഷി മാനസിക മാതൃകയുമായി യോജിക്കുന്നു. വെർട്ടിക്കൽ സർഫേസുകൾ (`tag`, `sub-domains`, `batch_search`) പരിധിക്ക് പുറത്തുതന്നെ തുടരും — നിലവിൽ വെർട്ടിക്കൽ പാരാമീറ്ററുകൾക്കായി IR ഇല്ല.
3. **ക്വോട്ട പ്രദർശനം: `freeMonthlyQuota: 0`** (xquik-ശൈലിയിലുള്ള യാഥാസ്ഥിതിക പ്രദർശനം). യഥാർഥ അലവൻസ് (പ്രതിദിനം 1000 അഭ്യർഥനകൾ, ദിവസേന റീസെറ്റ്) പകരം UI കാറ്റലോഗിലെ `authHint` പകർപ്പിൽ ഉൾപ്പെടുത്തിയിരിക്കുന്നു. യുക്തി: ക്വോട്ട പ്രദർശനം റീസെറ്റ് സെമാന്റിക്സുമായി പൊരുത്തപ്പെടണം; പ്രതിദിന പരിധിയെ പ്രതിമാസ തുല്യതയിലേക്ക് (30000) പരിവർത്തനം ചെയ്യുന്നത് UI-ക്ക് പാലിക്കാനാകാത്ത ഒരു തെറ്റായ വാഗ്ദാനമാണ്.
4. **searchTypes: `["web"]` മാത്രം.** AnySearch API-യിൽ വാർത്ത/ചിത്രങ്ങൾക്കായുള്ള വെർട്ടിക്കൽ ഉണ്ടെന്നതിന് പൊതുവായ തെളിവുകളൊന്നുമില്ല; രേഖപ്പെടുത്തപ്പെട്ട വെർട്ടിക്കൽ ഇല്ലാത്ത API-കൾ സംയോജിപ്പിക്കുന്ന ഗേറ്റ്വേകൾ (ഉദാ. Google Custom Search), news -> web എന്ന് നിശ്ശബ്ദമായി മാപ്പ് ചെയ്യുന്നതിനു പകരം web മാത്രം ലഭ്യമാക്കുന്നു.
5. **കീ നിലപാട്:** കീ ഇല്ലാതെ പ്രവർത്തിക്കും; അസാധുവായ കീ 401/403 തിരികെ നൽകും, ഒരിക്കലും നിശ്ശബ്ദമായി അജ്ഞാത മോഡിലേക്ക് തരംതാഴ്ത്തില്ല (അപ്സ്ട്രീം കരാറിനെ പ്രതിഫലിപ്പിക്കുന്നു).
6. **ബോധപൂർവമായ ഒഴിവാക്കലുകൾ:** `FETCH_BACKEND_TO_PROVIDER` / `FetchInterceptionBackend` (ചാറ്റ് ഇന്റർസെപ്ഷൻ firecrawl/jina/tavily ആയി തുടരും); `ANONYMOUS_CAPABLE_WEB_FETCH_PROVIDERS` (അജ്ഞാത റിമോട്ട് എൻഡ്പോയിന്റുകൾ ഓരോ എഗ്രസ് IP-ക്കും ഒരൊറ്റ IP-പരിമിത പൂളാണ് പങ്കിടുന്നത്, അതിനാൽ കീ ഇല്ലാത്ത extract ഓപ്റ്റ്-ഇൻ ആണ്, ഓട്ടോ-റൂട്ടിംഗ് സ്ഥാനാർഥിയല്ല); `QUOTA_STATUS_PROVIDERS` (AnySearch ക്വോട്ടയെ 402/403 സ്റ്റാറ്റസിലൂടെയല്ല, 429/എൻവലപ്പ് വഴിയാണ് സൂചിപ്പിക്കുന്നത്).

## 4. റഫറൻസുകൾ
