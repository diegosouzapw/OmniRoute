Web Cookie പ്രൊവൈഡറുകൾ, API കീയ്ക്ക് പകരം നിലവിലുള്ള ബ്രൗസർ സെഷൻ ഉപയോഗിച്ച് ഒരു AI സേവനം പ്രയോജനപ്പെടുത്താൻ OmniRoute-നെ അനുവദിക്കുന്നു. ഒരു സേവനത്തിന്റെ വെബ്സൈറ്റ് വഴി നിങ്ങൾക്ക് ഇതിനകം ആക്സസ് ഉണ്ടായിരിക്കുകയും, അതേ പ്രാമാണീകരിച്ച സെഷൻ OmniRoute ഉപയോഗിക്കണമെന്ന് ആഗ്രഹിക്കുകയും ചെയ്യുമ്പോൾ ഇവ പ്രയോജനകരമാണ്.

API-key പ്രൊവൈഡറുകളിൽ നിന്ന് വ്യത്യസ്തമായി, നിങ്ങളുടെ ബ്രൗസർ വെബ്സൈറ്റിലേക്ക് അയയ്ക്കുന്ന ക്രെഡൻഷ്യലുകൾ ഉപയോഗിച്ചാണ് Web Cookie പ്രൊവൈഡറുകൾ പ്രാമാണീകരിക്കുന്നത്.

# ആരംഭിക്കുന്നതിന് മുമ്പ്

> **പ്രധാനം:** ക്രെഡൻഷ്യലുകൾ എല്ലായ്പ്പോഴും **തത്സമയ നെറ്റ്വർക്ക് അഭ്യർത്ഥനയിൽ** നിന്നാണ് പകർത്തേണ്ടത്, നിങ്ങളുടെ ബ്രൗസറിന്റെ കുക്കി സ്റ്റോറേജിൽ നിന്നല്ല.

തെറ്റായ സ്ഥലത്തുനിന്ന് കുക്കികൾ പകർത്തുന്നതാണ് പല പ്രാമാണീകരണ പ്രശ്നങ്ങൾക്കും കാരണം.

## Cookie Storage-ൽ നിന്ന് പകർത്തരുത്

മിക്ക ബ്രൗസറുകളിലും സംഭരിച്ച കുക്കികൾ ഇനിപ്പറയുന്ന രീതിയിൽ കാണാൻ കഴിയും:

```
DevTools
→ Application (അല്ലെങ്കിൽ Storage)
→ Cookies
```

ഈ കുക്കികൾ ശരിയാണെന്ന് തോന്നാമെങ്കിലും, അവ:

- കാലഹരണപ്പെട്ടതാകാം
- അപൂർണ്ണമായിരിക്കാം
- പ്രാമാണീകരിച്ച അഭ്യർത്ഥനകളിൽ മാത്രം അയയ്ക്കുന്ന കുക്കികൾ ഉൾപ്പെടാതിരിക്കാം

ഈ മൂല്യങ്ങൾ സാധുവാണെന്ന് തോന്നിയാലും, അവ ഉപയോഗിക്കുന്നത് പ്രാമാണീകരണം പരാജയപ്പെടാൻ കാരണമായേക്കാം.

## തത്സമയ അഭ്യർത്ഥനയിൽ നിന്ന് പകർത്തുക

പകരം, വിജയകരമായ ഒരു അഭ്യർത്ഥനയിലെ കുക്കികൾ ഉപയോഗിക്കുക:

```
DevTools
→ Network
→ പേജ് പുതുക്കുക
→ ഒരു ചാറ്റ് അല്ലെങ്കിൽ സംഭാഷണ അഭ്യർത്ഥന തുറക്കുക
→ Request Headers
→ Cookie
```

നിങ്ങളുടെ ബ്രൗസർ വിജയകരമായി ഉപയോഗിച്ച കൃത്യമായ പ്രാമാണീകരണ വിവരങ്ങൾ `Cookie` അഭ്യർത്ഥനാ ഹെഡറിൽ അടങ്ങിയിരിക്കുന്നു.

മിക്ക Web Cookie പ്രൊവൈഡറുകൾക്കും OmniRoute-ൽ ഒട്ടിക്കേണ്ട മൂല്യം ഇതാണ്.

# പൊതുവായ സജ്ജീകരണം

മിക്ക Web Cookie പ്രൊവൈഡറുകൾക്കും സജ്ജീകരണ പ്രക്രിയ ഒരുപോലെയാണ്.

1. പ്രൊവൈഡറുടെ വെബ്സൈറ്റിൽ സൈൻ ഇൻ ചെയ്യുക.
2. ബ്രൗസറിന്റെ Developer Tools തുറക്കുക.
3. **Network** ടാബ് തുറക്കുക.
4. പേജ് പുതുക്കുക.
5. പ്രാമാണീകരിച്ച ഒരു ചാറ്റ് അല്ലെങ്കിൽ സംഭാഷണ അഭ്യർത്ഥന തുറക്കുക.
6. ആവശ്യമായ പ്രാമാണീകരണ ക്രെഡൻഷ്യലുകൾ പകർത്തുക.
7. OmniRoute തുറക്കുക.
8. **Providers → Add Provider** എന്നതിലേക്ക് പോകുക.
9. നിങ്ങളുടെ Web Cookie പ്രൊവൈഡർ തിരഞ്ഞെടുക്കുക.
10. ക്രെഡൻഷ്യലുകൾ ഒട്ടിക്കുക.
11. **Test Connection** ക്ലിക്ക് ചെയ്യുക.
12. പ്രൊവൈഡർ സംരക്ഷിക്കുക.

ആവശ്യമായ കൃത്യമായ ക്രെഡൻഷ്യലുകൾ പ്രൊവൈഡറെ ആശ്രയിച്ചിരിക്കുന്നു.

# Web Cookie പ്രൊവൈഡറുകൾക്ക് ചെയ്യാൻ കഴിയുന്നതും കഴിയാത്തതും

Web Cookie പ്രൊവൈഡറുകൾ ഒരു വെബ്സൈറ്റിന്റെ ചാറ്റ് ഇന്റർഫേസ് പുനരുപയോഗിക്കുന്നു. ഔദ്യോഗിക API-കളുടെ അതേ ശേഷികൾ അവ നൽകുന്നില്ല.

## പിന്തുണയ്ക്കുന്നവ

- നിങ്ങളുടെ നിലവിലുള്ള ബ്രൗസർ സെഷൻ ഉപയോഗിച്ച് പ്രാമാണീകരിക്കുക
- നിങ്ങളുടെ അക്കൗണ്ടിലൂടെ ലഭ്യമായ മോഡലുകൾ ആക്സസ് ചെയ്യുക
- ചാറ്റ് പ്രതികരണങ്ങൾ സ്ട്രീം ചെയ്യുക
- API കീ ആവശ്യമില്ല

## പിന്തുണയ്ക്കാത്തവ

- ഫങ്ഷൻ കോളിംഗ്
- ടൂൾ കോളിംഗ്
- സ്വയമേവയുള്ള ഫയൽ എഡിറ്റിംഗ്
- ഏജന്റിക് IDE വർക്ക്ഫ്ലോകൾ
- API-യിൽ മാത്രം ലഭ്യമായ ഫീച്ചറുകൾ

ഇത് പ്രതീക്ഷിക്കുന്ന പ്രവർത്തനരീതിയാണ്, ഇത് ഒരു ബഗ് **അല്ല**.

നിങ്ങൾക്ക് ടൂൾ നിർവഹണം, സ്വയമേവയുള്ള ഫയൽ എഡിറ്റിംഗ് അല്ലെങ്കിൽ മറ്റ് ഏജന്റ് വർക്ക്ഫ്ലോകൾ ആവശ്യമാണെങ്കിൽ, Web Cookie പ്രൊവൈഡറിന് പകരം ഒരു **API-key പ്രൊവൈഡർ** ഉപയോഗിക്കുക.

# സാധൂകരണവുമായി ബന്ധപ്പെട്ട പരിമിതി

വിജയകരമായ **Test Connection** അല്ലെങ്കിൽ കുക്കി സാധൂകരണം, നൽകിയ ക്രെഡൻഷ്യലുകൾ പ്രതീക്ഷിക്കുന്ന ഫോർമാറ്റിലാണെന്ന് തോന്നുന്നതു മാത്രമാണ് സ്ഥിരീകരിക്കുന്നത്.

Issue #7857 പരിഹരിക്കപ്പെടുന്നതുവരെ, വിജയകരമായ സാധൂകരണം പ്രൊവൈഡർ വിജയകരമായി പ്രാമാണീകരിക്കപ്പെടുമെന്ന് **ഉറപ്പുനൽകുന്നില്ല**.

പ്രാമാണീകരണം ഇപ്പോഴും പരാജയപ്പെടുകയാണെങ്കിൽ, ബ്രൗസർ കുക്കി സ്റ്റോറേജിൽ നിന്നല്ല, തത്സമയ നെറ്റ്വർക്ക് അഭ്യർത്ഥനയിൽ നിന്നാണ് ക്രെഡൻഷ്യലുകൾ പകർത്തിയതെന്ന് സ്ഥിരീകരിക്കുക.

# പ്രശ്നപരിഹാരം

## പ്രാമാണീകരണം പരാജയപ്പെടുന്നു

ക്രെഡൻഷ്യലുകൾ ഇനിപ്പറയുന്ന സ്ഥലത്തുനിന്നാണ് പകർത്തിയതെന്ന് സ്ഥിരീകരിക്കുക:

```
Network
→ Request Headers
→ Cookie
```

ഇനിപ്പറയുന്ന സ്ഥലത്തുനിന്ന് പകർത്തിയതല്ലെന്നും ഉറപ്പാക്കുക:

```
Application
→ Cookies
```

---

## കുക്കി ബ്രൗസറിൽ പ്രവർത്തിക്കുന്നു, പക്ഷേ OmniRoute-ൽ പ്രവർത്തിക്കുന്നില്ല

ചില പ്രൊവൈഡറുകൾ പ്രാമാണീകരിച്ച അഭ്യർത്ഥനകളിൽ മാത്രം അയയ്ക്കുന്ന കുക്കികൾ ഉൾപ്പെടുത്തുന്നു.

ഒരു സംഭാഷണം വിജയകരമായി തുറന്നശേഷം, പുതിയൊരു നെറ്റ്വർക്ക് അഭ്യർത്ഥനയിൽ നിന്ന് ക്രെഡൻഷ്യലുകൾ വീണ്ടും പകർത്തുക.

---

## സെഷൻ കാലഹരണപ്പെട്ടു

Web Cookie പ്രൊവൈഡറുകൾ നിങ്ങളുടെ നിലവിലുള്ള ബ്രൗസർ സെഷൻ ഉപയോഗിക്കുന്നു.

നിങ്ങളുടെ ബ്രൗസർ സെഷൻ കാലഹരണപ്പെടുകയോ നിങ്ങൾ സൈൻ ഔട്ട് ചെയ്യുകയോ ചെയ്താൽ, പുതിയൊരു സെറ്റ് ക്രെഡൻഷ്യലുകൾ പകർത്തണം.

# മികച്ച രീതികൾ

- പുതിയൊരു പ്രാമാണീകരിച്ച അഭ്യർത്ഥനയിൽ നിന്ന് ക്രെഡൻഷ്യലുകൾ പകർത്തുക.
- പഴയ കുക്കികൾ വീണ്ടും ഉപയോഗിക്കുന്നത് ഒഴിവാക്കുക.
- Web Cookie പ്രൊവൈഡറുകൾ ഉപയോഗിക്കുമ്പോൾ നിങ്ങളുടെ ബ്രൗസർ സെഷൻ സജീവമായി നിലനിർത്തുക.
- പകർത്തിയ കുക്കികളെ സെൻസിറ്റീവ് ക്രെഡൻഷ്യലുകളായി പരിഗണിക്കുക.
- ഫങ്ഷൻ കോളിംഗോ ഏജന്റ് വർക്ക്ഫ്ലോകളോ ആവശ്യമുള്ളപ്പോൾ API-key പ്രൊവൈഡറുകൾ ഉപയോഗിക്കുക.
