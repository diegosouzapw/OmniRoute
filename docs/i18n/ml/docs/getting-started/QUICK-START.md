> **ചുരുക്കത്തിൽ**: ഇൻസ്റ്റാൾ ചെയ്യുക → ഒരു സൗജന്യ പ്രൊവൈഡറെ ബന്ധിപ്പിക്കുക → നിങ്ങളുടെ IDE-യെ OmniRoute-ലേക്ക് ചൂണ്ടിക്കാണിക്കുക. കഴിഞ്ഞു.

## ഘട്ടം 1: OmniRoute ഇൻസ്റ്റാൾ ചെയ്യുക

നിങ്ങൾക്ക് ഇഷ്ടമുള്ള രീതി തിരഞ്ഞെടുക്കുക:

### ഓപ്ഷൻ A: npm (ശുപാർശ ചെയ്യുന്നത്)

```bash
npm install -g omniroute
```

### ഓപ്ഷൻ B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` എന്നത് **പ്രസിദ്ധീകരിച്ചിട്ടുള്ളതിൽ** ഏറ്റവും ഉയർന്ന സ്ഥിരതയുള്ള SemVer ആണ്. ഇത് git `main`-നെ പിന്തുടരുന്നില്ല. GitOps-നായി `diegosouzapw/omniroute:X.Y.Z` പിൻ ചെയ്യുക. [ഇമേജ് ടാഗുകൾ / റിലീസ് ചാനലുകൾ](../guides/DOCKER_GUIDE.md#release-channels) കാണുക.

### ഓപ്ഷൻ C: സോഴ്സിൽ നിന്ന്

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## ഘട്ടം 2: OmniRoute ആരംഭിക്കുക

```bash
omniroute
```

OmniRoute `http://localhost:20128`-ൽ ആരംഭിക്കുന്നു. ഡാഷ്ബോർഡ് സ്വയമേവ തുറക്കും.

---

## ഘട്ടം 3: ഒരു സൗജന്യ പ്രൊവൈഡറെ ബന്ധിപ്പിക്കുക

ഒരു സൗജന്യ പ്രൊവൈഡറെ ബന്ധിപ്പിച്ചുകൊണ്ട് നിങ്ങൾക്ക് **പണമൊന്നും നൽകാതെ** OmniRoute ഉപയോഗിക്കാം.

### ഓപ്ഷൻ A: Kiro (സൗജന്യ Claude — ക്രെഡിറ്റ് കാർഡ് ആവശ്യമില്ല)

1. `http://localhost:20128`-ൽ ഡാഷ്ബോർഡ് തുറക്കുക
2. **പ്രൊവൈഡറുകൾ** → **പ്രൊവൈഡറെ ചേർക്കുക** എന്നതിലേക്ക് പോകുക
3. **Kiro AI** തിരഞ്ഞെടുക്കുക
4. **ബന്ധിപ്പിക്കുക** ക്ലിക്ക് ചെയ്യുക (API കീ ആവശ്യമില്ല!)
5. കഴിഞ്ഞു! ഇപ്പോൾ നിങ്ങൾക്ക് Claude മോഡലുകളിലേക്കുള്ള സൗജന്യ ആക്സസ് ലഭിച്ചു.

### ഓപ്ഷൻ B: OpenCode Free (ഓതന്റിക്കേഷൻ ആവശ്യമില്ല)

1. `http://localhost:20128`-ൽ ഡാഷ്ബോർഡ് തുറക്കുക
2. **പ്രൊവൈഡറുകൾ** → **പ്രൊവൈഡറെ ചേർക്കുക** എന്നതിലേക്ക് പോകുക
3. **OpenCode Free** തിരഞ്ഞെടുക്കുക
4. **ബന്ധിപ്പിക്കുക** ക്ലിക്ക് ചെയ്യുക (API കീ ആവശ്യമില്ല!)
5. കഴിഞ്ഞു! ഇപ്പോൾ നിങ്ങൾക്ക് ഒന്നിലധികം മോഡലുകളിലേക്കുള്ള സൗജന്യ ആക്സസ് ലഭിച്ചു.

### ഓപ്ഷൻ C: Pollinations (കീ ആവശ്യമില്ല)

1. `http://localhost:20128`-ൽ ഡാഷ്ബോർഡ് തുറക്കുക
2. **പ്രൊവൈഡറുകൾ** → **പ്രൊവൈഡറെ ചേർക്കുക** എന്നതിലേക്ക് പോകുക
3. **Pollinations** തിരഞ്ഞെടുക്കുക
4. **ബന്ധിപ്പിക്കുക** ക്ലിക്ക് ചെയ്യുക (API കീ ആവശ്യമില്ല!)
5. കഴിഞ്ഞു! ഇപ്പോൾ നിങ്ങൾക്ക് GPT-5, Claude, Gemini എന്നിവയിലേക്കും മറ്റനേകം മോഡലുകളിലേക്കും സൗജന്യ ആക്സസ് ലഭിച്ചു.

## ഘട്ടം 4: ഇത് പ്രവർത്തിക്കുന്നുണ്ടെന്ന് സ്ഥിരീകരിക്കുക

[API കീകൾ](http://localhost:20128/dashboard/api-manager) എന്നതിൽ നിന്ന് ഒരു പുതിയ കീ സൃഷ്ടിക്കുക. ഈ കീ വീണ്ടും ദൃശ്യമാകില്ല എന്നതിനാൽ അത് സൂക്ഷിച്ചുവെക്കുക. ഈ കീ അപ്സ്ട്രീം പ്രൊവൈഡറുകളെ ആക്സസ് ചെയ്യാനല്ല, ടൂളുകൾക്ക് OmniRoute ആക്സസ് ചെയ്യാനാണെന്ന കാര്യം ശ്രദ്ധിക്കുക.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

നിങ്ങൾ ബന്ധിപ്പിച്ച മോഡലുകൾ പട്ടികപ്പെടുത്തിയതായി കാണണം.

## ഘട്ടം 5: നിങ്ങളുടെ IDE അല്ലെങ്കിൽ CLI-യെ OmniRoute-ലേക്ക് ചൂണ്ടിക്കാണിക്കുക

നിങ്ങളുടെ IDE അല്ലെങ്കിൽ CLI ടൂളിൽ ഇനിപ്പറയുന്നവ സജ്ജമാക്കുക:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

അത്രമാത്രം! ഇപ്പോൾ നിങ്ങളുടെ IDE സ്വയമേവയുള്ള പ്രൊവൈഡർ തിരഞ്ഞെടുപ്പോടെ OmniRoute ഉപയോഗിക്കുന്നു.

### IDE ഉദാഹരണം: VSCode/Continue.dev

1. VSCode-ൽ [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) എക്സ്റ്റൻഷൻ ഇൻസ്റ്റാൾ ചെയ്യുക.
2. ഇനിപ്പറയുന്ന വരികൾ ചേർക്കാൻ നിങ്ങളുടെ `~/.continue/config.yaml` അപ്ഡേറ്റ് ചെയ്യുക:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev ചാറ്റ് പെയിനിൽ `OmniRoute - Auto` തിരഞ്ഞെടുക്കുക; തുടർന്ന് നിങ്ങൾ OmniRoute-ലേക്ക് അഭ്യർത്ഥനകൾ നടത്തും.
4. (ഐച്ഛികം) വായനക്കാരനുള്ള അഭ്യാസം — മുൻകൂട്ടി തയ്യാറാക്കിയ മറ്റെല്ലാ കോൺഫിഗറേഷനുകളും ഉൾപ്പെടുത്തി `config.yaml` അപ്ഡേറ്റ് ചെയ്യാൻ നിങ്ങളുടെ IDE-യെ പ്രേരിപ്പിക്കുക 😊

### CLI ഉദാഹരണം: Codex CLI

1. നിങ്ങളുടെ ഓപ്പറേറ്റിംഗ് സിസ്റ്റത്തിൽ എൻവയോൺമെന്റ് വേരിയബിൾ സ്ഥിരമായി സജ്ജമാക്കുക.
   macOS/Linux-നായി (നിങ്ങളുടെ `~/.bashrc` അല്ലെങ്കിൽ `~/.zshrc`-ലേക്ക് ചേർക്കുക):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows-നായി (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. ഇനി OmniRoute-നായി കോൺഫിഗർ ചെയ്തുകൊണ്ട് Codex ആരംഭിക്കാം. പ്രവർത്തിപ്പിക്കുക:

```
omniroute launch-codex --model auto
```

എൻഡ്പോയിന്റും API കീയും വ്യക്തമാക്കുന്നതിന് `codex`-ഉം കമാൻഡ്-ലൈൻ പാരാമീറ്ററുകളും ഉപയോഗിച്ച് ഇത് മാനുവലായി ചെയ്യാം. എന്നാൽ മുകളിലെ കമാൻഡ് ഉപയോഗിക്കുമ്പോൾ OmniRoute നിങ്ങൾക്കായി എല്ലാം കൈകാര്യം ചെയ്യും.

മറ്റ് CLI-കൾക്കും ഇതേ ഒറ്റ-കമാൻഡ് ലോഞ്ച് ജെനറിക് ലോഞ്ചർ വഴി പ്രവർത്തിക്കും — `omniroute run <target>` എന്നത് `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, `gemini` എന്നിവയെ പിന്തുണയ്ക്കുന്നു ([CLI ഇന്റഗ്രേഷനുകൾ](../guides/CLI-INTEGRATIONS.md) കാണുക).

3. ഇപ്പോൾ CLI, OmniRoute-ലേക്ക് അഭ്യർത്ഥനകൾ അയയ്ക്കുന്നുണ്ടാകണം.

### നിങ്ങളുടെ ടൂൾ OmniRoute-ലേക്ക് റൂട്ട് ചെയ്യുന്നുണ്ടെന്ന് സ്ഥിരീകരിക്കുക

ഇടത് സൈഡ്ബാറിൽ നിന്ന് [നിരീക്ഷണം/ലോഗുകൾ](http://localhost:20128/dashboard/logs) ക്ലിക്ക് ചെയ്ത് അഭ്യർത്ഥനയുടെ വിശദാംശങ്ങൾ കാണാം. തുടർന്ന് ക്ലിക്ക് ചെയ്താൽ കൂടുതൽ വിശദാംശങ്ങൾ കാണാം. അനുബന്ധമായി, നിങ്ങളുടെ പ്രിയപ്പെട്ട ഹാർനെസിൽ നിന്ന് എന്തൊക്കെ വിവരങ്ങളാണ് അയയ്ക്കപ്പെടുന്നതെന്നും നിങ്ങൾക്ക് കാണാം. പഠനത്തിനും ഡീബഗ്ഗിങ്ങിനും ഇത് സഹായകരമാണ്.

- **[പ്രശ്നപരിഹാരം](../guides/TROUBLESHOOTING.md)** — സാധാരണ പ്രശ്നങ്ങൾ പരിഹരിക്കുക

## സാധാരണ ചോദ്യങ്ങൾ

### "എനിക്ക് ഒരു API കീ ആവശ്യമാണോ?"

**അല്ല!** API കീയൊന്നും ഇല്ലാതെ നിങ്ങൾക്ക് സൗജന്യ പ്രൊവൈഡർമാരെ (Kiro, OpenCode Free, Pollinations) ഉപയോഗിക്കാം. ഡാഷ്ബോർഡിൽ അവരെ ബന്ധിപ്പിച്ചാൽ മാത്രം മതി.

### "`auto` എന്നാൽ എന്താണ്?"

ഓരോ അഭ്യർത്ഥനയ്ക്കും ഏറ്റവും മികച്ച പ്രൊവൈഡറെ സ്വയമേവ തിരഞ്ഞെടുക്കാൻ `auto` OmniRoute-നോട് നിർദേശിക്കുന്നു. വേഗത, ചെലവ്, ഗുണനിലവാരം, ലഭ്യത എന്നിവ ഇത് പരിഗണിക്കുന്നു. വിശദാംശങ്ങൾക്ക് [Auto-Combo ഗൈഡ്](./AUTO-COMBO-GUIDE.md) കാണുക.

### "ഇതിന് എത്ര ചെലവാകും?"

OmniRoute തന്നെ **സൗജന്യവും ഓപ്പൺ സോഴ്സുമാണ്**. നിങ്ങൾ ഉപയോഗിക്കുന്ന പ്രൊവൈഡർമാർക്ക് മാത്രമാണ് പണം നൽകേണ്ടത്. പല പ്രൊവൈഡർമാർക്കും സൗജന്യ ടിയറുകളുണ്ട് — [സൗജന്യ ടിയറുകളുടെ ഗൈഡ്](./FREE-TIERS-GUIDE.md) കാണുക.

### "Claude Code / Cursor / Copilot എന്നിവയ്ക്കൊപ്പം ഇത് ഉപയോഗിക്കാമോ?"

**അതെ!** OpenAI ഫോർമാറ്റ് പിന്തുണയ്ക്കുന്ന ഏത് ടൂളുമായും OmniRoute പ്രവർത്തിക്കും. ബേസ് URL `http://localhost:20128/v1` ആയി സജ്ജമാക്കിയാൽ മാത്രം മതി. പ്രത്യേക സജ്ജീകരണ നിർദ്ദേശങ്ങൾക്കായി [CLI ടൂളുകളുടെ ഗൈഡ്](../reference/CLI-TOOLS.md) കാണുക.

### "ഒരു പ്രൊവൈഡർ പ്രവർത്തനരഹിതമായാൽ എന്ത് സംഭവിക്കും?"

പരാജയപ്പെട്ട പ്രൊവൈഡർമാരെ OmniRoute സ്വയമേവ ഒഴിവാക്കി അടുത്തത് പരീക്ഷിക്കും. നിങ്ങൾ ഒന്നും ചെയ്യേണ്ടതില്ല. വിശദാംശങ്ങൾക്ക് [Auto-Combo ഗൈഡ്](./AUTO-COMBO-GUIDE.md) കാണുക.
