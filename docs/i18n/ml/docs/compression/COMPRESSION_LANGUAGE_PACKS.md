Caveman കംപ്രഷന് അന്തർനിർമ്മിത ഇംഗ്ലീഷ് നിയമങ്ങൾക്ക് പുറമെ ഭാഷ-നിർദ്ദിഷ്ട റൂൾ പാക്കുകളും ലോഡ് ചെയ്യാനാകും.
ഇത് കോർ എഞ്ചിന്റെ സ്ഥിരത നിലനിർത്തുന്നതിനൊപ്പം പോർച്ചുഗീസ്, സ്പാനിഷ്, ജർമ്മൻ, ഫ്രഞ്ച്, ഇറ്റാലിയൻ, ജാപ്പനീസ് എന്നിവയ്ക്കും
ഭാവിയിലെ ഭാഷാ പാക്കുകൾക്കും സ്വതന്ത്രമായി വികസിക്കാൻ അനുവദിക്കുന്നു.

## സ്ഥാനം

ഭാഷാ പാക്കുകൾ താഴെപ്പറയുന്നിടത്താണ് സ്ഥിതിചെയ്യുന്നത്:

```txt
open-sse/services/compression/rules/<language>/
```

നിലവിൽ വിതരണം ചെയ്യുന്ന പാക്കുകൾ (`rules/` ഡയറക്ടറിയിലെ ഉള്ളടക്കവുമായി പരിശോധിച്ചുറപ്പിച്ചത്):

| ഭാഷ                  | ഡയറക്ടറി       | നിലവിലുള്ള റൂൾ വിഭാഗങ്ങൾ                            |
| -------------------- | -------------- | --------------------------------------------------- |
| ഇംഗ്ലീഷ്             | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| സ്പാനിഷ്             | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| പോർച്ചുഗീസ് (ബ്രസീൽ) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ഇന്തോനേഷ്യൻ          | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ഇറ്റാലിയൻ            | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| ജർമ്മൻ               | `rules/de/`    | `context`, `filler`, `structural`                   |
| ഫ്രഞ്ച്              | `rules/fr/`    | `context`, `filler`, `structural`                   |
| ജാപ്പനീസ്            | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **തുല്യതാ കുറിപ്പ്:** `en`, `es`, `pt-BR`, `id`, `it` പാക്കുകളിൽ 5 വിഭാഗങ്ങളും പൂർണ്ണമായി ഉൾപ്പെടുന്നു; `de`, `fr`, `ja` എന്നിവ 3 വിഭാഗങ്ങളോടെയാണ് വിതരണം ചെയ്യുന്നത്. ലഭ്യമല്ലാത്ത `dedup`, `ultra` വിഭാഗങ്ങൾ അറിയിപ്പൊന്നുമില്ലാതെ അന്തർനിർമ്മിത ഇംഗ്ലീഷ് നിയമങ്ങളിലേക്ക് മടങ്ങുന്നു. ചെറിയ പാക്കുകളിലേക്ക് `dedup.json`, `ultra.json` എന്നിവ ചേർക്കുന്നതിനുള്ള സംഭാവനകൾ സ്വാഗതം ചെയ്യുന്നു.
>
> `pt-BR` പാക്ക് Lenine Júnior സൃഷ്ടിച്ച **[Troglodita](https://github.com/leninejunior/troglodita)** അടിസ്ഥാനമാക്കിയുള്ളതാണ് — ബ്രസീലിയൻ പോർച്ചുഗീസ് വ്യാകരണത്തിനായി ആദ്യം മുതൽ രൂപകൽപ്പന ചെയ്ത ഒരു കംപ്രഷൻ സിസ്റ്റമാണിത് (അനാവശ്യ ആവർത്തനങ്ങളുടെ കുറവ്, PT-BR ഫില്ലർ നീക്കംചെയ്യൽ, ബ്രസീലിയൻ ഡെവലപ്പർ സമൂഹത്തിനുള്ള സാങ്കേതിക ചുരുക്കെഴുത്തുകൾ).
>
> ഔദ്യോഗിക വിഭാഗപ്പട്ടികയും ഓരോ വിഭാഗത്തിന്റെയും സ്കീമയും [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json)-ൽ ലഭ്യമാണ് (JSON Schema draft 2020-12).

## ഭാഷ കണ്ടെത്തൽ

പ്രോംപ്റ്റ് ടെക്സ്റ്റിൽ നിന്ന് ഭാഷ അനുമാനിക്കാൻ `languageDetector.ts` ലഘുവായ ഹ്യൂറിസ്റ്റിക്കുകൾ ഉപയോഗിക്കുന്നു.
കോൺഫിഗർ ചെയ്ത ഡിഫോൾട്ട് ഭാഷ തുടർന്നും മാനിക്കപ്പെടും; കൃത്യമായ നിയന്ത്രണം ആവശ്യമായപ്പോൾ കോൺഫിഗിലൂടെ കണ്ടെത്തൽ
പ്രവർത്തനരഹിതമാക്കാനും കഴിയും.

കണ്ടെത്തലിന്റെ ഔട്ട്പുട്ട് റൂൾ പാക്കുകൾ തിരഞ്ഞെടുക്കാൻ മാത്രമാണ് ഉപയോഗിക്കുന്നത്. ഇത് പ്രൊവൈഡർ റൂട്ടിംഗ്, ലോക്കേൽ
തിരഞ്ഞെടുപ്പ്, അല്ലെങ്കിൽ UI ഭാഷ എന്നിവ മാറ്റുന്നില്ല.

## കോൺഫിഗ് ഘടന

കംപ്രഷൻ ക്രമീകരണങ്ങളിൽ ഇനിപ്പറയുന്നവ ഉൾപ്പെടുത്താം:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` ഡാഷ്ബോർഡ്/പ്രിവ്യൂ ഡിഫോൾട്ടുകൾ നിയന്ത്രിക്കുന്നു. Caveman സന്ദേശ ടെക്സ്റ്റ് കംപ്രസ് ചെയ്യുമ്പോൾ ഉപയോഗിക്കുന്ന
റൺടൈം എഞ്ചിൻ കോൺഫിഗാണ് `cavemanConfig`.

## ഭാഷാ പാക്ക് ചേർക്കൽ

1. `open-sse/services/compression/rules/<language>/<pack>.json` സൃഷ്ടിക്കുക.
2. `docs/compression/COMPRESSION_RULES_FORMAT.md`-ലെ Caveman നിയമ ഫോർമാറ്റ് ഉപയോഗിക്കുക.
3. റീപ്ലേസ്മെന്റുകൾ പരിമിതമായി നിലനിർത്തുകയും കോഡ്, ഐഡന്റിഫയറുകൾ, URL-കൾ, അല്ലെങ്കിൽ JSON എന്നിവ മാറ്റുന്നത് ഒഴിവാക്കുകയും ചെയ്യുക.
4. ഭാഷ തിരഞ്ഞെടുക്കുന്നതിനും റീപ്ലേസ്മെന്റ് പ്രവർത്തനത്തിനുമുള്ള ടെസ്റ്റുകൾ ചേർക്കുകയോ അപ്ഡേറ്റ് ചെയ്യുകയോ ചെയ്യുക.
5. UI സെലക്ടറുകളിൽ ഭാഷ ദൃശ്യമാകുന്നുവെങ്കിൽ പുതിയ ഡാഷ്ബോർഡ്/i18n ലേബലുകൾ ലഭ്യമാക്കുക.

## API

ലഭ്യമായ പാക്കുകൾ ഇപ്രകാരം അന്വേഷിക്കാം:

```bash
curl http://localhost:20128/api/compression/language-packs
```

പ്രിവ്യൂ എൻഡ്പോയിന്റ് ഭാഷാ കോൺഫിഗറേഷൻ ഓവർറൈഡുകൾ സ്വീകരിക്കുന്നു:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

v3.8.0-ൽ എല്ലാ 6 ഭാഷാ പാക്കുകൾക്കും ഓരോ Caveman തീവ്രതയിലും (LITE, FULL, ULTRA) പ്രയോഗിക്കപ്പെടുന്ന ഒരു `SHARED_BOUNDARIES` ക്ലോസ് ലഭിച്ചു. ചുറ്റുമുള്ള അനാവശ്യ പദങ്ങൾ നീക്കം ചെയ്യുന്നതിനെ പരിഗണിക്കാതെ, ഈ പാറ്റേണുകൾ അതേപടി സംരക്ഷിക്കാൻ ഇത് എഞ്ചിനോട് നിർദേശിക്കുന്നു:

| പാറ്റേൺ തരം                           | ഉദാഹരണം                                |
| ------------------------------------- | -------------------------------------- |
| ഫെൻസ്ഡ് കോഡ് ബ്ലോക്കുകൾ               | ` ```python\n...\n``` `                |
| ഇൻലൈൻ കോഡ്                            | `` `my_var` ``                         |
| URL-കൾ                                | `https://example.com/path`             |
| ഫയൽ പാതകൾ (അബ്സല്യൂട്ട് + റിലേറ്റീവ്) | `/etc/hosts`, `./src/index.ts`         |
| പിശക് ഹെഡറുകൾ                         | `Error:`, `TypeError:`, `SyntaxError:` |
| സ്റ്റാക്ക് ട്രേസ് വരികൾ               | `  at functionName (file.ts:12:3)`     |

ഈ പാറ്റേണുകൾ `DEFAULT_CAVEMAN_CONFIG.preservePatterns`-ൽ പൂരിപ്പിക്കപ്പെടുന്നു (മുമ്പ് `[]` ആയിരുന്നു). ഈ കോൺസ്റ്റന്റ് `open-sse/services/compression/types.ts`-ലാണ് സ്ഥിതിചെയ്യുന്നത്.

### ഇത് പ്രധാനമാകുന്നത് എന്തുകൊണ്ട്

SHARED_BOUNDARIES ഇല്ലെങ്കിൽ, ആവർത്തന സ്വഭാവമുള്ള ഗദ്യംപോലെ തോന്നിയിരുന്നെങ്കിലും യഥാർത്ഥത്തിൽ കോഡ് സ്നിപ്പറ്റ്, ഫയൽ പാത, അല്ലെങ്കിൽ എറർ സ്റ്റാക്ക് ആയിരുന്ന ഉള്ളടക്കം അഗ്രസീവ് Caveman മോഡുകൾ നീക്കം ചെയ്തേക്കാം. അനാവശ്യ പദങ്ങൾ നീക്കം ചെയ്യുന്നതിനുള്ള നിയമങ്ങൾ പ്രവർത്തിക്കുന്നതിന് മുമ്പ് പ്രയോഗിക്കപ്പെടുന്ന, ഭാഷയെ ആശ്രയിക്കാത്ത ഒരു സുരക്ഷാ സംവിധാനമായി SHARED_BOUNDARIES പ്രവർത്തിക്കുന്നു.

### preservePatterns ഇഷ്ടാനുസൃതമാക്കൽ

കംപ്രഷൻ ക്രമീകരണങ്ങളിലൂടെ റൺടൈമിൽ അധിക പാറ്റേണുകൾ ചേർക്കാം:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

ഇഷ്ടാനുസൃത പാറ്റേണുകൾ 6 ഡിഫോൾട്ടുകളെ മാറ്റിസ്ഥാപിക്കുകയല്ല, വിപുലീകരിക്കുകയാണ് ചെയ്യുന്നത്.

## പ്രവർത്തനപരമായ കുറിപ്പുകൾ

- ഒരു ഭാഷാ പാക്ക് ലഭ്യമല്ലാത്തപ്പോൾ ഇംഗ്ലീഷിലെ ബിൽറ്റ്-ഇൻ നിയമങ്ങൾ ഫാൾബാക്കായി തുടരും.
- അസാധുവായ ബിൽറ്റ്-ഇൻ JSON പാക്കുകളുടെ വാലിഡേഷൻ പരാജയപ്പെടുന്നതിനാൽ റിലീസ് അസറ്റുകളുടെ നിലവാരം നിശ്ശബ്ദമായി കുറയുകയില്ല.
- നിയമ പാക്കുകൾ ഡാറ്റ മാത്രമായിരിക്കണം; അവ കോഡ് ഇംപോർട്ട് ചെയ്യുകയോ അനിയന്ത്രിതമായ ലോജിക് പ്രവർത്തിപ്പിക്കുകയോ ചെയ്യരുത്.
- കംപ്രഷൻ അനലിറ്റിക്സ് ലെയർ പൂർണ്ണ പ്രോംപ്റ്റ് ടെക്സ്റ്റിന് പകരം തിരഞ്ഞെടുത്ത മോഡും എഞ്ചിനും രേഖപ്പെടുത്തുന്നു.
