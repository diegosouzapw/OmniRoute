റൂട്ടിംഗ് നിലവിലുള്ള ശേഷി, കോംബോ തിരഞ്ഞെടുക്കൽ ലോജിക് നിലനിർത്തുകയും തുടർന്ന് അലോക്കേഷൻ, ഹെൽത്ത്, സർക്യൂട്ട്, ക്വോട്ട, ലേറ്റൻസി, വിശ്വാസ്യത, മോഡൽ മുൻഗണന, ചെലവ് മുൻഗണന എന്നീ ഘടകങ്ങൾ പ്രയോഗിക്കുകയും ചെയ്യുന്നു.

അഡാപ്റ്റീവ് സ്കോർ വിശദീകരിക്കാവുന്നതാണ്; ഇത് തിരഞ്ഞെടുത്ത കാൻഡിഡേറ്റിനെയും റാങ്ക് ചെയ്ത എല്ലാ കാൻഡിഡേറ്റുകളെയും തിരികെ നൽകുന്നു. ക്വോട്ട തീർന്നവ, അലോക്കേഷൻ നിഷേധിക്കപ്പെട്ടവ, ഓപ്പൺ സർക്യൂട്ടുകൾ എന്നിവ യോഗ്യമല്ല. അജ്ഞാത ക്വോട്ട ന്യൂട്രൽ ക്വോട്ട ഘടകത്തോടെ യോഗ്യമായി തുടരുന്നു.

റൂട്ട് പ്രിവ്യൂ നിർണായക സ്വഭാവമുള്ളതാണ്, കൂടാതെ അപ്സ്ട്രീം മോഡൽ അഭ്യർത്ഥനകളൊന്നും നടത്തുന്നില്ല:

`POST /api/omniroute/route/preview`

പ്രതികരണത്തിൽ കാൻഡിഡേറ്റ് സ്കോറുകൾ, ഘടകങ്ങൾ, കാരണങ്ങൾ, തിരഞ്ഞെടുത്ത പ്രൊവൈഡർ, `liveRequestExecuted: false` എന്നിവ ഉൾപ്പെടുന്നു.
