> **ഡാഷ്ബോർഡ്:** Settings → **AI** → ചിന്താ ബജറ്റ്  
> **API:** `GET` / `PUT` `/api/settings/thinking-budget`  
> **സോഴ്സ്:** `open-sse/services/thinkingBudget.ts`

പ്രൊവൈഡർമാരിലേക്കുള്ള വഴിയിൽ OmniRoute **ക്ലയന്റിന്റെ ചിന്താ/യുക്തിവിചാര പാരാമീറ്ററുകൾ മാറ്റിയെഴുതണമോ** എന്നത് ചിന്താ ബജറ്റ് നിയന്ത്രിക്കുന്നു. ഇത് കംപ്രഷൻ, റൂട്ടിംഗ്, അല്ലെങ്കിൽ പ്രോംപ്റ്റ് കാഷ് ഓണോ ഓഫോ ആക്കുന്നില്ല.

## മോഡുകൾ

| മോഡ്                          | OmniRoute ചെയ്യുന്നത്                                                                                                             | എപ്പോൾ ഉപയോഗിക്കണം                                                                                                                                                                       |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`passthrough`** (ഡിഫോൾട്ട്) | ക്ലയന്റ് ഫീൽഡുകൾ മാറ്റാതെ വിടുന്നു (`reasoning`, `reasoning_effort`, Claude `thinking`, Gemini `thinking_config` തുടങ്ങിയവ).      | **Codex / Desktop / എഫർട്ടും യുക്തിവിചാര സംഗ്രഹങ്ങളും നിയന്ത്രിക്കേണ്ട ഏതൊരു ക്ലയന്റും.** ക്ലയന്റ് `reasoning.summary` അഭ്യർത്ഥിക്കുമ്പോൾ ദൃശ്യമാകുന്ന ചിന്താ പാനലുകൾക്ക് ഇത് ആവശ്യമാണ്. |
| **`auto`**                    | അപ്സ്ട്രീമിലേക്ക് അയയ്ക്കുന്നതിന് മുമ്പ് അഭ്യർത്ഥന ബോഡിയിൽനിന്ന് എല്ലാ ചിന്താ/യുക്തിവിചാര ഫീൽഡുകളും **നീക്കംചെയ്യുന്നു**.         | **പ്രൊവൈഡർ** തന്നെ ഡിഫോൾട്ടുകൾ നിശ്ചയിക്കണമെന്നും ക്ലയന്റ് നിയന്ത്രിക്കുന്ന ചിന്ത ആവശ്യമില്ലെന്നും നിങ്ങൾ മനഃപൂർവം തീരുമാനിക്കുമ്പോൾ മാത്രം. ഇത് “ചിന്ത സ്വയമേവ കാണിക്കുക” എന്നതല്ല.     |
| **`custom`**                  | ഓരോ അഭ്യർത്ഥനയിലും ഒരു നിശ്ചിത ചിന്താ ടോക്കൺ ബജറ്റ് നിർബന്ധമായി സജ്ജമാക്കുന്നു.                                                   | എല്ലാ ട്രാഫിക്കിലെയും ചിന്താ ടോക്കണുകൾക്കുള്ള കർശന പരിധി.                                                                                                                                |
| **`adaptive`**                | സന്ദേശങ്ങളുടെ എണ്ണം, ടൂളുകൾ, പ്രോംപ്റ്റിന്റെ നീളം എന്നിവ ഉപയോഗിച്ച് ഒരു അടിസ്ഥാന എഫർട്ടിൽനിന്ന് ബജറ്റ് ക്രമാനുസൃതമായി മാറ്റുന്നു. | ക്ലയന്റിന്റെ ഉദ്ദേശ്യം പൂർണ്ണമായി നീക്കംചെയ്യാതെ മൃദുവായ ടോക്കൺ നിയന്ത്രണം.                                                                                                              |

### `auto` നീക്കംചെയ്യുന്നവ

മോഡ് `auto` ആയിരിക്കുമ്പോൾ, `stripThinkingConfig()` ഇനിപ്പറയുന്നവ ഉൾപ്പെടെയുള്ളവ ഇല്ലാതാക്കുന്നു:

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking`, കൂടാതെ നിലവിലുണ്ടെങ്കിൽ `output_config.effort`
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

ഒരു ക്ലയന്റ് (ഉദാ. Codex Desktop) `reasoning: { effort: "ultra", summary: "detailed" }` അയച്ചാൽ, **auto ആ ഒബ്ജക്റ്റ് ഒഴിവാക്കുന്നു**. അപ്സ്ട്രീം അപ്പോഴും ചില യുക്തിവിചാര ടോക്കണുകൾക്ക് നിരക്ക് ഈടാക്കിയേക്കാം, എന്നാൽ പലപ്പോഴും **ശൂന്യമായതോ എൻക്രിപ്റ്റ് ചെയ്തവ മാത്രമുള്ളതോ ആയ** യുക്തിവിചാര ഇനങ്ങളാണ് മടക്കിനൽകുക — അതിനാൽ UI-യിൽ പ്രയോജനകരമായ ചിന്താ സ്ട്രീം കാണില്ല.

| ഫീച്ചർ                                      | ബന്ധം                                                                                                                                             |

| **കംപ്രഷൻ** (Caveman, RTK, stacked, …)      | വേറിട്ട പൈപ്പ്ലൈൻ. എല്ലാ ചിന്താ-ബജറ്റ് മോഡുകളിലും പ്രവർത്തിക്കുന്നു.                                                                              |
| **പ്രോംപ്റ്റ് / സെമാന്റിക് കാഷ്**           | വേറിട്ടതാണ്. ചിന്താ-ബജറ്റ് മോഡ് ഇതിനെ ബാധിക്കില്ല.                                                                                                |
| **കോംബോ റൂട്ടിംഗ് / ഫാൾബാക്കുകൾ**           | വേറിട്ടതാണ്. ബാധിക്കില്ല.                                                                                                                         |
| **API-key ടോക്കൺ പരിധികൾ / ചെലവ് ബജറ്റുകൾ** | വേറിട്ടതാണ്. ബാധിക്കില്ല.                                                                                                                         |
| **യുക്തിവിചാര റീപ്ലേ കാഷ്**                 | കർശനമായ പ്രൊവൈഡർമാർക്കുള്ള (DeepSeek, Kimi, Qwen-thinking, …) മൾട്ടി-ടേൺ പുനഃചേർക്കൽ. Desktop-ലെ “ചിന്ത കാണിക്കുക” എന്നതിന് തുല്യമല്ല.            |
| **`encrypted_content` ഡീക്രിപ്റ്റ് ചെയ്യൽ** | **അസാധ്യമാണ്.** OpenAI/Codex സ്വകാര്യ യുക്തിവിചാര ബ്ലോബുകൾ അതാര്യമാണ്. OmniRoute ഒരിക്കലും അവ ഡീക്രിപ്റ്റ് ചെയ്യുന്നില്ല (#7095 / #7176 / #7304). |

## ദൃശ്യമാകുന്ന ചിന്താപ്രക്രിയ (Codex / Responses ക്ലയന്റുകൾ)

ഒരു ക്ലയന്റിൽ ചിന്താപ്രക്രിയയുടെ ടെക്സ്റ്റ് കാണിക്കുന്നതിന്, താഴെപ്പറയുന്നവ **എല്ലാം** ആവശ്യമാണ്:

1. Thinking Budget മോഡ് = **`passthrough`** (അല്ലെങ്കിൽ നിങ്ങൾ ഉപയോഗിക്കുന്ന പാതയ്ക്ക് ആവശ്യമായ summary അഭ്യർത്ഥനകൾ മതിയായ രീതിയിൽ നിലനിർത്തുന്ന custom/adaptive).
2. ക്ലയന്റ് ഒരു summary അഭ്യർത്ഥിക്കണം, ഉദാ. Codex `model_reasoning_summary = "detailed"` / `auto` (`none` അല്ല).
3. അപ്സ്ട്രീം യഥാർത്ഥത്തിൽ `response.reasoning_summary_text.*` സ്ട്രീം ചെയ്യണം (അല്ലെങ്കിൽ ഇനത്തിൽ ശൂന്യമല്ലാത്ത `reasoning.summary` ഉണ്ടായിരിക്കണം).

നിങ്ങൾക്ക് “എൻക്രിപ്റ്റ് ചെയ്ത സ്വകാര്യ ചിന്താപ്രക്രിയ” മാത്രമാണ് ലഭിക്കുന്നതെങ്കിൽ, ഒന്നുകിൽ:

- മോഡ് **`auto`** ആയിരുന്നു (ക്ലയന്റ് അഭ്യർത്ഥന നീക്കം ചെയ്യപ്പെട്ടു), അല്ലെങ്കിൽ
- summary ടെക്സ്റ്റ് ഇല്ലാതെ അപ്സ്ട്രീം `encrypted_content` മടക്കി നൽകി (പ്രൊവൈഡറുടെ പരിമിതി; OmniRoute-ന് പ്ലെയിൻടെക്സ്റ്റ് നൽകാനാകില്ല, ഒരു പ്ലേസ്ഹോൾഡർ മാത്രമേ കാണിക്കാനാകൂ).

## API ഉദാഹരണങ്ങൾ

```bash
# വായിക്കുക
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# Codex / Desktop-ൽ ചിന്താപ്രക്രിയ ദൃശ്യമാക്കുന്നതിന് ശുപാർശ ചെയ്യുന്നത്
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

സ്കീമ (`updateThinkingBudgetSchema`): `mode` ∈ `passthrough|auto|custom|adaptive`; ഐച്ഛികമായി `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier`.

### സ്ഥിരസംഭരണം / പുനരാരംഭം

മൂല്യം `thinkingBudget` എന്ന settings കീയ്ക്ക് കീഴിൽ സംഭരിക്കുകയും പ്രോസസ്സ് ആരംഭിക്കുമ്പോൾ (`hydrateThinkingBudgetConfig`) ലോഡ് ചെയ്യുകയും ചെയ്യുന്നു. DB വഴിയോ ചില API-ഇതര പാതകളിലൂടെയോ മാറ്റിയ ശേഷം, ഇൻ-മെമ്മറി singleton ഡിസ്കിലുള്ളതുമായി പൊരുത്തപ്പെടുന്നതിനായി **OmniRoute പ്രോസസ്സ് പുനരാരംഭിക്കുക**.
