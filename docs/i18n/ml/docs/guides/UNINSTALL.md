## വേഗത്തിലുള്ള അൺഇൻസ്റ്റാൾ (v3.6.2+)

വൃത്തിയായി നീക്കംചെയ്യുന്നതിനായി OmniRoute രണ്ട് ബിൽറ്റ്-ഇൻ സ്ക്രിപ്റ്റുകൾ നൽകുന്നു:

### നിങ്ങളുടെ ഡാറ്റ നിലനിർത്തുക

```bash
npm run uninstall
```

ഇത് OmniRoute ആപ്ലിക്കേഷൻ നീക്കംചെയ്യുന്നു, എന്നാൽ `~/.omniroute/`-ലുള്ള നിങ്ങളുടെ ഡാറ്റാബേസ്, കോൺഫിഗറേഷനുകൾ, API കീകൾ, പ്രൊവൈഡർ ക്രമീകരണങ്ങൾ എന്നിവ **നിലനിർത്തുന്നു**. പിന്നീട് വീണ്ടും ഇൻസ്റ്റാൾ ചെയ്യാൻ ഉദ്ദേശിക്കുന്നുവെന്നും നിലവിലെ സജ്ജീകരണം നിലനിർത്താൻ ആഗ്രഹിക്കുന്നുവെന്നും ആണെങ്കിൽ ഇത് ഉപയോഗിക്കുക.

### പൂർണ്ണമായി നീക്കംചെയ്യൽ

```bash
npm run uninstall:full
```

ഇത് ആപ്ലിക്കേഷൻ നീക്കംചെയ്യുകയും എല്ലാ ഡാറ്റയും **ശാശ്വതമായി മായ്ക്കുകയും** ചെയ്യുന്നു:

- ഡാറ്റാബേസ് (`storage.sqlite`)
- പ്രൊവൈഡർ കോൺഫിഗറേഷനുകളും API കീകളും
- ബാക്കപ്പ് ഫയലുകൾ
- ലോഗ് ഫയലുകൾ
- `~/.omniroute/` ഡയറക്ടറിയിലെ എല്ലാ ഫയലുകളും

> ⚠️ **മുന്നറിയിപ്പ്:** `npm run uninstall:full` പഴയപടിയാക്കാനാകില്ല. നിങ്ങളുടെ എല്ലാ പ്രൊവൈഡർ കണക്ഷനുകളും കോംബോകളും API കീകളും ഉപയോഗ ചരിത്രവും ശാശ്വതമായി ഇല്ലാതാക്കപ്പെടും.

## മാനുവൽ അൺഇൻസ്റ്റാൾ

### NPM ഗ്ലോബൽ ഇൻസ്റ്റാൾ

```bash
# ഗ്ലോബൽ പാക്കേജ് നീക്കംചെയ്യുക
npm uninstall -g omniroute

# (ഐച്ഛികം) ഡാറ്റാ ഡയറക്ടറി നീക്കംചെയ്യുക
rm -rf ~/.omniroute
```

### pnpm ഗ്ലോബൽ ഇൻസ്റ്റാൾ

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# കണ്ടെയ്നർ നിർത്തി നീക്കംചെയ്യുക
docker stop omniroute
docker rm omniroute

# വോള്യം നീക്കംചെയ്യുക (എല്ലാ ഡാറ്റയും ഇല്ലാതാക്കുന്നു)
docker volume rm omniroute-data

# (ഐച്ഛികം) ഇമേജ് നീക്കംചെയ്യുക
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# കണ്ടെയ്നറുകൾ നിർത്തി നീക്കംചെയ്യുക
docker compose down

# വോള്യങ്ങളും നീക്കംചെയ്യുക (എല്ലാ ഡാറ്റയും ഇല്ലാതാക്കുന്നു)
docker compose down -v
```

### Electron ഡെസ്ക്ടോപ്പ് ആപ്പ്

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` തുറക്കുക
- അല്ലെങ്കിൽ ഇൻസ്റ്റാൾ ഡയറക്ടറിയിൽനിന്ന് NSIS അൺഇൻസ്റ്റാളർ പ്രവർത്തിപ്പിക്കുക

**macOS:**

- `/Applications`-ൽനിന്ന് `OmniRoute.app` ട്രാഷിലേക്ക് വലിച്ചിടുക
- ഡാറ്റ നീക്കംചെയ്യുക: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage ഫയൽ നീക്കംചെയ്യുക
- ഡാറ്റ നീക്കംചെയ്യുക: `rm -rf ~/.omniroute`

### സോഴ്സ് ഇൻസ്റ്റാൾ (git clone)

```bash
# ക്ലോൺ ചെയ്ത ഡയറക്ടറി നീക്കംചെയ്യുക
rm -rf /path/to/omniroute

# (ഐച്ഛികം) ഡാറ്റാ ഡയറക്ടറി നീക്കംചെയ്യുക
rm -rf ~/.omniroute
```

## ഡാറ്റാ ഡയറക്ടറികൾ

OmniRoute ഡിഫോൾട്ടായി ഇനിപ്പറയുന്ന ലൊക്കേഷനുകളിൽ ഡാറ്റ സംഭരിക്കുന്നു:

| പ്ലാറ്റ്ഫോം   | ഡിഫോൾട്ട് പാത്ത്                   | അസാധുവാക്കൽ                             |
| ------------- | ---------------------------------- | --------------------------------------- |
| Linux         | `~/.omniroute/`                    | `DATA_DIR` എൻവയോൺമെന്റ് വേരിയബിൾ        |
| macOS         | `~/.omniroute/`                    | `DATA_DIR` എൻവയോൺമെന്റ് വേരിയബിൾ        |
| Windows       | `%APPDATA%/omniroute/`             | `DATA_DIR` എൻവയോൺമെന്റ് വേരിയബിൾ        |
| Docker        | `/app/data/` (മൗണ്ട് ചെയ്ത വോള്യം) | `DATA_DIR` എൻവയോൺമെന്റ് വേരിയബിൾ        |
| XDG-അനുയോജ്യം | `$XDG_CONFIG_HOME/omniroute/`      | `XDG_CONFIG_HOME` എൻവയോൺമെന്റ് വേരിയബിൾ |

### ഡാറ്റാ ഡയറക്ടറിയിലെ ഫയലുകൾ

| ഫയൽ/ഡയറക്ടറി         | വിവരണം                                                       |
| -------------------- | ------------------------------------------------------------ |
| `storage.sqlite`     | പ്രധാന ഡാറ്റാബേസ് (പ്രൊവൈഡർമാർ, കോംബോകൾ, ക്രമീകരണങ്ങൾ, കീകൾ) |
| `storage.sqlite-wal` | SQLite റൈറ്റ്-എഹെഡ് ലോഗ് (താൽക്കാലികം)                       |
| `storage.sqlite-shm` | SQLite പങ്കിട്ട മെമ്മറി (താൽക്കാലികം)                        |
| `call_logs/`         | അഭ്യർത്ഥന പേലോഡ് ആർക്കൈവുകൾ                                  |
| `backups/`           | സ്വയമേവയുള്ള ഡാറ്റാബേസ് ബാക്കപ്പുകൾ                          |
| `log.txt`            | ലെഗസി അഭ്യർത്ഥനാ ലോഗ് (ഐച്ഛികം)                              |

## പൂർണ്ണമായി നീക്കംചെയ്തെന്ന് സ്ഥിരീകരിക്കുക

അൺഇൻസ്റ്റാൾ ചെയ്തതിനുശേഷം, അവശേഷിക്കുന്ന ഫയലുകളൊന്നുമില്ലെന്ന് സ്ഥിരീകരിക്കുക:

```bash
# ഗ്ലോബൽ npm പാക്കേജ് പരിശോധിക്കുക
npm list -g omniroute 2>/dev/null

# ഡാറ്റ ഡയറക്ടറി പരിശോധിക്കുക
ls -la ~/.omniroute/ 2>/dev/null

# പ്രവർത്തിച്ചുകൊണ്ടിരിക്കുന്ന പ്രോസസ്സുകൾ പരിശോധിക്കുക
pgrep -f omniroute
```

ഏതെങ്കിലും പ്രോസസ്സ് ഇപ്പോഴും പ്രവർത്തിക്കുന്നുണ്ടെങ്കിൽ, അത് നിർത്തുക:

```bash
pkill -f omniroute
```
