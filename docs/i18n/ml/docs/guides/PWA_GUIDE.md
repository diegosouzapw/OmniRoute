OmniRoute പൂർണ്ണമായി ഇൻസ്റ്റാൾ ചെയ്യാവുന്ന Progressive Web App ആയി ലഭ്യമാണ്. Android (Chrome) അല്ലെങ്കിൽ iOS (Safari) എന്നിങ്ങനെ ഏതെങ്കിലും മൊബൈൽ ബ്രൗസറിൽ നിന്ന് ഡാഷ്ബോർഡ് ആക്സസ് ചെയ്യുമ്പോൾ, നിങ്ങൾക്ക് "ഹോം സ്ക്രീനിലേക്ക് ചേർക്കുക" എന്ന ഓപ്ഷൻ ഉപയോഗിച്ച് ആപ്പ് സ്റ്റോർ ആവശ്യമില്ലാതെ നേറ്റീവ് ആപ്പിന് സമാനമായ അനുഭവം നേടാം.

## എന്താണ് PWA?

ഒരു Progressive Web App, OmniRoute വെബ് ഡാഷ്ബോർഡിനെ നേറ്റീവ് മൊബൈൽ ആപ്പ് പോലെ കാണുകയും പ്രവർത്തിക്കുകയും ചെയ്യുന്ന ഒന്നാക്കി മാറ്റുന്നു. ഇൻസ്റ്റാൾ ചെയ്തുകഴിഞ്ഞാൽ, അത്:

- സ്വന്തം ഐക്കണോടുകൂടി നിങ്ങളുടെ ഹോം സ്ക്രീനിൽ നിന്ന് ആരംഭിക്കുന്നു
- പൂർണ്ണസ്ക്രീനിൽ തുറക്കുന്നു — ബ്രൗസർ വിലാസ ബാറോ ടാബ് UI-യോ ഇല്ല
- കണക്റ്റിവിറ്റിക്കായി സമർപ്പിതമായ പേജിനൊപ്പം ഓഫ്ലൈനിലും പ്രവർത്തിക്കുന്നു
- വേഗത്തിൽ ലോഡ് ചെയ്യുന്നതിനായി സ്റ്റാറ്റിക് അസറ്റുകൾ കാഷ് ചെയ്യുന്നു
- പോർട്രെയ്റ്റ്, ലാൻഡ്സ്കേപ്പ് ഓറിയന്റേഷനുകൾ പിന്തുണയ്ക്കുന്നു

## ഇൻസ്റ്റാളേഷൻ

### Android (Chrome)

1. Chrome-ൽ OmniRoute ഡാഷ്ബോർഡ് തുറക്കുക: `http://YOUR_IP:20128`
2. Chrome സ്വയമേവ **"ഹോം സ്ക്രീനിലേക്ക് OmniRoute ചേർക്കുക"** എന്ന ബാനർ കാണിക്കും, അല്ലെങ്കിൽ:
   - **⋮** മെനു (മൂന്ന് ഡോട്ടുകൾ) ടാപ്പ് ചെയ്യുക → **"ഹോം സ്ക്രീനിലേക്ക് ചേർക്കുക"** അല്ലെങ്കിൽ **"ആപ്പ് ഇൻസ്റ്റാൾ ചെയ്യുക"**
3. പ്രോംപ്റ്റ് സ്ഥിരീകരിക്കുക
4. ഒരു സ്വതന്ത്ര ആപ്പായി OmniRoute നിങ്ങളുടെ ഹോം സ്ക്രീനിൽ ദൃശ്യമാകും

### iOS (Safari)

1. Safari-യിൽ OmniRoute ഡാഷ്ബോർഡ് തുറക്കുക: `http://YOUR_IP:20128`
2. **പങ്കിടുക** ബട്ടൺ (അമ്പടയാളമുള്ള ബോക്സ്) ടാപ്പ് ചെയ്യുക
3. താഴേക്ക് സ്ക്രോൾ ചെയ്ത് **"ഹോം സ്ക്രീനിലേക്ക് ചേർക്കുക"** ടാപ്പ് ചെയ്യുക
4. അതിന് ഒരു പേര് നൽകുക (സ്ഥിരസ്ഥിതിയായി "OmniRoute") തുടർന്ന് **ചേർക്കുക** ടാപ്പ് ചെയ്യുക
5. ആപ്പ് ഐക്കണോടുകൂടി OmniRoute നിങ്ങളുടെ ഹോം സ്ക്രീനിൽ ദൃശ്യമാകും

### ഡെസ്ക്ടോപ്പ് (Chrome / Edge)

1. OmniRoute ഡാഷ്ബോർഡ് തുറക്കുക
2. വിലാസ ബാറിലെ **ഇൻസ്റ്റാൾ ഐക്കൺ** ക്ലിക്ക് ചെയ്യുക (അല്ലെങ്കിൽ ⋮ → "OmniRoute ഇൻസ്റ്റാൾ ചെയ്യുക...")
3. പ്രോംപ്റ്റ് സ്ഥിരീകരിക്കുക
4. OmniRoute ഒരു സ്വതന്ത്ര വിൻഡോയായി തുറക്കും — ടാബുകളില്ല, വിലാസ ബാറില്ല

## സവിശേഷതകൾ

### പൂർണ്ണസ്ക്രീൻ അനുഭവം

മാനിഫെസ്റ്റ് `display: "fullscreen"` ഉപയോഗിച്ചാണ് കോൺഫിഗർ ചെയ്തിരിക്കുന്നത്. അതായത് ഇൻസ്റ്റാൾ ചെയ്ത ആപ്പ് മുഴുവൻ സ്ക്രീനും ഉപയോഗിക്കും — ബ്രൗസർ UI ഇല്ല, സ്റ്റാറ്റസ് ബാർ ഓവർലാപ്പും ഇല്ല. ഇത് ഡാഷ്ബോർഡിന് യഥാർത്ഥ നേറ്റീവ് ആപ്പിന്റെ അനുഭവം നൽകുന്നു.

### ഓഫ്ലൈൻ പിന്തുണ

ബുദ്ധിപരമായ കാഷിംഗ് നൽകുന്ന ഒരു സർവീസ് വർക്കർ (`sw.js`) OmniRoute-ൽ ഉൾപ്പെടുത്തിയിരിക്കുന്നു:

| അസറ്റ് തരം                                                   | തന്ത്രം                                    | പ്രവർത്തനം                                                                                                         |
| ------------------------------------------------------------ | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| **ആപ്പ് ഷെൽ**                                                | ആദ്യം കാഷ്                                 | ഇൻസ്റ്റാൾ ചെയ്യുമ്പോൾ `/`, `/offline`, മാനിഫെസ്റ്റ്, ഐക്കണുകൾ എന്നിവ മുൻകൂട്ടി കാഷ് ചെയ്യുന്നു                     |
| **സ്റ്റാറ്റിക് അസറ്റുകൾ** (CSS, JS, ചിത്രങ്ങൾ, ഫോണ്ടുകൾ)     | കാഷ് ഫാൾബാക്കോടുകൂടി ആദ്യം നെറ്റ്വർക്ക്    | നെറ്റ്വർക്കിൽ നിന്ന് പുതിയ പതിപ്പ് ലഭ്യമാക്കുന്നു; ഓഫ്ലൈനാണെങ്കിൽ കാഷിലേക്ക് മടങ്ങുന്നു                            |
| **Next.js ബണ്ടിലുകൾ** (`/_next/`)                            | കാഷ് അപ്ഡേറ്റോടുകൂടി ആദ്യം നെറ്റ്വർക്ക്    | നെറ്റ്വർക്കിൽ നിന്ന് ലഭ്യമാക്കി കാഷ് അപ്ഡേറ്റ് ചെയ്യുന്നു; ഓഫ്ലൈനാണെങ്കിൽ കാഷ് ചെയ്ത പതിപ്പ് നൽകുന്നു              |
| **നാവിഗേഷൻ അഭ്യർത്ഥനകൾ**                                     | ബൈപാസ് (ഒരിക്കലും ഇന്റർസെപ്റ്റ് ചെയ്യില്ല) | HTTP/3→HTTP/2 ഫാൾബാക്ക് ബ്രൗസർ കൈകാര്യം ചെയ്യുന്നു; പ്രവർത്തനരഹിതമായ QUIC സോക്കറ്റ് `Response.error()` ആയി മാറരുത് |
| **API / ഡാഷ്ബോർഡ് റൂട്ടുകൾ** (`/api/`, `/a2a`, `/dashboard`) | ബൈപാസ് (ഒരിക്കലും കാഷ് ചെയ്യില്ല)          | എല്ലായ്പ്പോഴും നേരിട്ട് സെർവറിലേക്ക് പോകുന്നു — സർവീസ് വർക്കർ ഒരിക്കലും ഇന്റർസെപ്റ്റ് ചെയ്യില്ല                    |

### ഓഫ്ലൈൻ പേജ്

നെറ്റ്വർക്ക് ലഭ്യമല്ലാത്തപ്പോൾ ഉപയോക്താവ് ഒരു പുതിയ പേജിലേക്ക് നാവിഗേറ്റ് ചെയ്താൽ, സർവീസ് വർക്കർ ഒരു സമർപ്പിത `/offline` പേജ് നൽകുന്നു. അത്:

- വ്യക്തമായ **"കണക്റ്റിവിറ്റി പ്രശ്നം"** സന്ദേശം പ്രദർശിപ്പിക്കുന്നു
- തത്സമയം അപ്ഡേറ്റ് ചെയ്യുന്ന ഒരു ലൈവ് **ഓൺലൈൻ/ഓഫ്ലൈൻ സ്റ്റാറ്റസ് ഇൻഡിക്കേറ്റർ** കാണിക്കുന്നു
- കണക്റ്റിവിറ്റി പുനഃസ്ഥാപിക്കുമ്പോൾ റീലോഡ് ചെയ്യുന്നതിനായി **"കണക്ഷൻ വീണ്ടും ശ്രമിക്കുക"** ബട്ടൺ നൽകുന്നു
- ഡയഗ്നോസ്റ്റിക്സിനായി **സ്റ്റാറ്റസ് പേജിലേക്ക്** ലിങ്ക് നൽകുന്നു

### ആപ്പ് ഐക്കണുകൾ

ഓരോ പ്ലാറ്റ്ഫോമിനുമായി ഒപ്റ്റിമൈസ് ചെയ്ത ഐക്കണുകൾ OmniRoute നൽകുന്നു:

| ഫയൽ                    | വലുപ്പം               | ഉപയോഗിക്കുന്ന ഇടം                               |
| ---------------------- | --------------------- | ----------------------------------------------- |
| `icon-512.png`         | 512×512               | Android ഇൻസ്റ്റാൾ പ്രോംപ്റ്റ്, സ്പ്ലാഷ് സ്ക്രീൻ |
| `apple-touch-icon.png` | 180×180               | iOS ഹോം സ്ക്രീൻ ഐക്കൺ                           |
| `icon-192.svg`         | 192×192 (വെക്റ്റർ)    | Android അഡാപ്റ്റീവ് ഐക്കൺ                       |
| `apple-touch-icon.svg` | 180×180 (വെക്റ്റർ)    | Apple ഫാൾബാക്ക്                                 |
| `favicon.svg`          | വെക്റ്റർ              | ബ്രൗസർ ടാബുകൾ                                   |
| `favicon.ico`          | ഒന്നിലധികം വലുപ്പങ്ങൾ | പഴയ ബ്രൗസറുകൾ                                   |

### സ്വയമേവയുള്ള രജിസ്ട്രേഷൻ

റൂട്ട് ലേഔട്ടിലെ `<PwaRegister />` ഘടകം വഴി സർവീസ് വർക്കർ സ്വയമേവ രജിസ്റ്റർ ചെയ്യപ്പെടുന്നു. ഉപയോക്താവിന്റെ ഭാഗത്ത് നിന്ന് യാതൊരു നടപടിയും ആവശ്യമില്ല — സാധുവായ മാനിഫെസ്റ്റും സർവീസ് വർക്കറും ബ്രൗസർ കണ്ടെത്തുന്ന ഉടൻ ആപ്പ് ഇൻസ്റ്റാൾ ചെയ്യാവുന്നതായി മാറുന്നു.

### സർവീസ് വർക്കർ (`public/sw.js`)

ഫ്രെയിംവർക്ക് ഡിപെൻഡൻസികളൊന്നുമില്ലാത്ത ഒരു സാധാരണ സർവീസ് വർക്കർ, ഇതിൽ ഉൾപ്പെടുന്നത്:

- **ഇൻസ്റ്റാൾ ഘട്ടം**: ആപ്പ് ഷെൽ മുൻകൂട്ടി കാഷ് ചെയ്യുന്നു (റൂട്ട്, ഓഫ്ലൈൻ പേജ്, മാനിഫെസ്റ്റ്, ഐക്കണുകൾ)
- **ആക്ടിവേറ്റ് ഘട്ടം**: പഴയ കാഷ് പതിപ്പുകൾ നീക്കം ചെയ്യുകയും എല്ലാ ക്ലയന്റുകളുടെയും നിയന്ത്രണം ഏറ്റെടുക്കുകയും ചെയ്യുന്നു
- **ഫെച്ച് ഘട്ടം**: അഭ്യർത്ഥനയുടെ തരത്തെ അടിസ്ഥാനമാക്കിയുള്ള ബുദ്ധിപരമായ റൂട്ടിംഗ് (നാവിഗേഷൻ, സ്റ്റാറ്റിക് അസറ്റ്, API)
- **കാഷ് പതിപ്പാക്കൽ**: `omniroute-pwa-v3` — അപ്ഡേറ്റ് ചെയ്യുമ്പോൾ പുതിയ കാഷ് നിർബന്ധമാക്കാൻ ഇത് വർദ്ധിപ്പിക്കുക

### ലേഔട്ട് മെറ്റാഡാറ്റ (`src/app/layout.tsx`)

PWA മാനദണ്ഡങ്ങൾ പാലിക്കുന്നതിന് ആവശ്യമായ എല്ലാ മെറ്റാ ടാഗുകളും റൂട്ട് ലേഔട്ട് നൽകുന്നു:

- `/manifest.webmanifest`-ലേക്കുള്ള `manifest` ലിങ്ക്
- iOS സ്റ്റാൻഡ്എലോൺ മോഡിനായി `apple-web-app-capable: true`
- `apple-web-app-status-bar-style: black-translucent`
- Android Chrome-നായി `mobile-web-app-capable: yes`
- `theme-color: #0b0f1a`
- അരികുമുതൽ അരികുവരെ റെൻഡർ ചെയ്യുന്നതിനായി `viewport-fit: cover`

### ഘടകം: `PwaRegister`

`src/shared/components/PwaRegister.tsx`-ൽ സ്ഥിതിചെയ്യുന്ന ഈ ക്ലയന്റ് ഘടകം:

1. മൗണ്ട് ചെയ്യുമ്പോൾ പ്രവർത്തിക്കുന്നു (ക്ലയന്റ് ഭാഗത്ത് മാത്രം)
2. ബ്രൗസറിൽ `serviceWorker` പിന്തുണയുണ്ടോയെന്ന് പരിശോധിക്കുന്നു
3. `/sw.js` നിശ്ശബ്ദമായി രജിസ്റ്റർ ചെയ്യുന്നു (ആപ്പ് ബ്ലോക്ക് ചെയ്യുന്നത് ഒഴിവാക്കാൻ പിശകുകൾ അവഗണിക്കുന്നു)
4. ഒന്നും റെൻഡർ ചെയ്യുന്നില്ല (`return null`) — ഇത് സൈഡ് ഇഫക്റ്റുകൾക്കായി മാത്രമുള്ള ഘടകമാണ്

## Termux-നൊപ്പം ഉപയോഗിക്കൽ (Android)

Android-ൽ Termux വഴി OmniRoute പ്രവർത്തിപ്പിക്കുമ്പോൾ, PWA തടസ്സമില്ലാതെ പ്രവർത്തിക്കുന്നു:

1. Termux-ൽ OmniRoute ആരംഭിക്കുക: `npx omniroute`
2. അതേ ഫോണിൽ Chrome തുറക്കുക: `http://localhost:20128`
3. "ഹോം സ്ക്രീനിലേക്ക് ചേർക്കുക" വഴി PWA ഇൻസ്റ്റാൾ ചെയ്യുക
4. PWA പ്രാദേശിക Termux സർവറുമായി ബന്ധിപ്പിക്കുന്നു — എല്ലാം ഉപകരണത്തിൽത്തന്നെ പ്രവർത്തിക്കുന്നു

ഈ സംയോജനം നിങ്ങളുടെ Android ഫോണിനെ **സർവറും** (Termux) **ക്ലയന്റും** (PWA) ആക്കുന്നു — പൂർണ്ണമായും സ്വയംപര്യാപ്തമായ ഒരു AI ഗേറ്റ്വേ.

## മറ്റ് ഉപകരണങ്ങളിൽ നിന്ന് ഉപയോഗിക്കൽ

നിങ്ങളുടെ OmniRoute സർവറിലേക്ക് ബ്രൗസർ ആക്സസ് ഉള്ള ഏത് ഉപകരണത്തിലും PWA ഇൻസ്റ്റാൾ ചെയ്യുക:

- **മറ്റൊരു ഫോൺ/ടാബ്ലെറ്റ്**: `http://PHONE_IP:20128`-ലേക്ക് പോയി PWA ഇൻസ്റ്റാൾ ചെയ്യുക
- **ലാപ്ടോപ്പ്**: Chrome/Edge തുറന്ന് ഒരു ഡെസ്ക്ടോപ്പ് PWA ആയി ഇൻസ്റ്റാൾ ചെയ്യുക
- **ബ്രൗസറുള്ള സ്മാർട്ട് TV**: ഡാഷ്ബോർഡ് പൂർണ്ണസ്ക്രീനിൽ ആക്സസ് ചെയ്യുക

## ഇഷ്ടാനുസൃതമാക്കൽ

### ഇൻസ്റ്റൻസ് പേര്

`Dashboard → Settings`-ലെ **Instance Name** ക്രമീകരണം PWA ശീർഷകത്തിൽ പ്രതിഫലിക്കും. നിങ്ങളുടെ ഇൻസ്റ്റൻസിന്റെ പേര് "My AI Gateway" എന്നാക്കി മാറ്റിയാൽ, ഇൻസ്റ്റാൾ ചെയ്ത PWA ആ പേര് പ്രദർശിപ്പിക്കും.

### ഇഷ്ടാനുസൃത ഫാവിക്കോൺ

`Dashboard → Settings` വഴി നിങ്ങൾ ഒരു ഇഷ്ടാനുസൃത ഫാവിക്കോൺ അപ്ലോഡ് ചെയ്താൽ, ഡെസ്ക്ടോപ്പിലെ PWA ഐക്കണിൽ ആ ഇഷ്ടാനുസൃത ഐക്കൺ പ്രതിഫലിക്കും. മൊബൈൽ ഹോം സ്ക്രീൻ ഐക്കണുകൾ മുൻകൂട്ടി തയ്യാറാക്കിയ `icon-512.png`, `apple-touch-icon.png` ഫയലുകൾ ഉപയോഗിക്കുന്നു.

## പരിമിതികൾ

- **പുഷ് അറിയിപ്പുകളില്ല** — സർവീസ് വർക്കർ Push API നടപ്പിലാക്കുന്നില്ല. പകരം അറിയിപ്പുകൾ Electron ആപ്പാണ് കൈകാര്യം ചെയ്യുന്നത്.
- **പശ്ചാത്തല സമന്വയമില്ല** — ഓഫ്ലൈൻ പ്രവർത്തനങ്ങൾ പിന്നീട് വീണ്ടും നടപ്പിലാക്കുന്നതിനായി ക്യൂവിൽ ചേർക്കുന്നില്ല. PWA പ്രധാനമായും ഒരു ഡാഷ്ബോർഡ് വ്യൂവറാണ്.
- **iOS നിയന്ത്രണങ്ങൾ** — iOS-ലെ Safari എല്ലാ PWA സവിശേഷതകളെയും പിന്തുണയ്ക്കുന്നില്ല (ഉദാ., ഇൻസ്റ്റാൾ നിർദ്ദേശങ്ങൾ സ്വമേധയാ നടത്തണം, കൂടാതെ പശ്ചാത്തല സർവീസ് വർക്കറുകൾക്ക് പരിമിതികളുണ്ട്).
- **കാഷ് വലുപ്പം** — സർവീസ് വർക്കർ സ്റ്റാറ്റിക് അസറ്റുകൾ മാത്രം കാഷ് ചെയ്യുന്നു. `/api/` റൂട്ടുകളിൽ നിന്നുള്ള വലിയ റെസ്പോൺസ് പേലോഡുകൾ ഒരിക്കലും കാഷ് ചെയ്യില്ല.
- **മൊബൈലിലെ ഇഷ്ടാനുസൃത ഐക്കണുകൾ** — ക്രമീകരണങ്ങളിൽ ഫേവിക്കോൺ മാറ്റുന്നത് മൊബൈലിലെ ഹോം സ്ക്രീൻ ഐക്കൺ അപ്ഡേറ്റ് ചെയ്യുന്നില്ല (ഇതിന് PWA ഐക്കണുകൾ വീണ്ടും സൃഷ്ടിക്കേണ്ടതുണ്ട്).
