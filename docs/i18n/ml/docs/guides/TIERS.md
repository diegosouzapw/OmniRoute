OmniRoute പിന്തുണയ്ക്കുന്ന 352 പ്രൊവൈഡർമാരെ 3 സാമ്പത്തിക ടിയറുകളായി ക്രമീകരിക്കുന്നു. ഓരോ
അഭ്യർത്ഥനയും വിജയകരമായ പ്രതികരണം ലഭിക്കുന്നതുവരെ ക്രമത്തിൽ അവയിലൂടെ കടന്നുപോകുന്നു — അതിനാൽ
ഫോൾബാക്ക് കോഡ് എഴുതാതെതന്നെ ഏറ്റവും ചെലവുകുറഞ്ഞ പ്രായോഗിക പ്രതികരണം നിങ്ങൾക്ക് ലഭിക്കുന്നു.

## ടിയർ 1 — സബ്സ്ക്രിപ്ഷൻ

**നിങ്ങൾ ഇതിനകം പണം നൽകുന്ന പ്രൊവൈഡർമാർ.** ക്വാട്ട കാലഹരണപ്പെടുന്നതിന് മുമ്പ്
OmniRoute അതിന്റെ ഓരോ തുള്ളിയും ഉപയോഗിക്കുന്നു.

| പ്രൊവൈഡർ                             | ടിയർ 1 ആക്കാനുള്ള കാരണം                                           |
| ------------------------------------ | ----------------------------------------------------------------- |
| Claude Code OAuth                    | Anthropic Pro/Team — സ്ഥിരനിരക്ക്, പലപ്പോഴും ഉപയോഗിക്കപ്പെടാത്തത് |
| OpenAI Codex (ChatGPT സബ്സ്ക്രിപ്ഷൻ) | Plus/Team-ൽ Codex ക്വാട്ട ഉൾപ്പെടുന്നു                            |
| GitHub Copilot                       | ഓരോ സീറ്റിനും — ക്വാട്ട പ്രതിമാസം പുനഃസജ്ജമാക്കപ്പെടുന്നു         |
| Cursor IDE                           | Pro പ്ലാൻ ക്വാട്ട                                                 |
| Antigravity / Devin Desktop          | അന്തർനിർമ്മിത ക്വാട്ടകൾ                                           |

**തന്ത്രം**: മോഡലിന്റെ കഴിവുകൾക്ക് അനുയോജ്യമായ എല്ലാ അഭ്യർത്ഥനകളും ആദ്യം ഇവിടെ റൂട്ട് ചെയ്യുക.
ക്വാട്ട ട്രാക്കർ അടുത്തുവരുന്ന റീസെറ്റുകൾ നിരീക്ഷിക്കുകയും `reset-aware`
കോംബോ തന്ത്രം അതനുസരിച്ച് മുൻഗണന നൽകുകയും ചെയ്യുന്നു. ആദ്യം ടിയർ 1-ലേക്ക് റൂട്ട് ചെയ്യാനും ക്വാട്ട
തീരുമ്പോൾ മാത്രം പണമടച്ചുള്ള ടിയറുകളിലേക്ക് മാറാനും `auto/thrifty` id ഉപയോഗിക്കുക — അല്ലെങ്കിൽ
പ്ലാനിൽ ഉൾപ്പെട്ട ശേഷിയിൽ തന്നെ തുടരാനും അത് ലഭ്യമല്ലെങ്കിൽ പരാജയപ്പെടാനും `auto/subscription`
ഉപയോഗിക്കുക. [സബ്സ്ക്രിപ്ഷൻ-ആദ്യ റൂട്ടിങ്](../routing/SUBSCRIPTION_LADDER.md) കാണുക.

## ടിയർ 2 — ചെലവുകുറഞ്ഞത്

**1M ടോക്കണുകൾക്ക് $1-ൽ താഴെ നിരക്കുള്ള പേ-പർ-ടോക്കൺ പ്രൊവൈഡർമാർ.** ഉയർന്ന തോതിലുള്ള ജോലികൾക്കോ
ടിയർ 1 ക്വാട്ടകൾ പരിധിയിലെത്തിയ ശേഷമോ ഉപയോഗിക്കുന്നതിനായി മാറ്റിവെച്ചിരിക്കുന്നു.

| പ്രൊവൈഡർ                       | വില (ഇൻപുട്ട്/ഔട്ട്പുട്ട്) | മികവുകൾ                   |
| ------------------------------ | -------------------------- | ------------------------- |
| DeepSeek V4 Pro                | 1M-ന് $0.27 / $1.10        | കോഡ്, യുക്തിചിന്ത         |
| GLM-4.5                        | 1M-ന് $0.60 / $2.20        | ദൈർഘ്യമേറിയ കോൺടെക്സ്റ്റ് |
| MiniMax M1                     | 1M-ന് $0.20 / $1.10        | വേഗത                      |

| OpenRouter (വില-ഒപ്റ്റിമൈസ്ഡ്) | വ്യത്യാസപ്പെടുന്നു         | 100+ മോഡലുകൾ, ഡൈനാമിക്    |

**തന്ത്രം**: ടാസ്കിന്റെ ശേഷി ഫിൽട്ടർ (വിഷൻ, JSON മോഡ്, ടൂളുകൾ, പരമാവധി-കോൺടെക്സ്റ്റ്)
പാലിക്കുന്ന ഏറ്റവും കുറഞ്ഞ $/ടോക്കൺ മോഡൽ `cost-optimized` കോംബോ തിരഞ്ഞെടുക്കുന്നു.

## ടിയർ 3 — സൗജന്യം

**ചെലവില്ലാത്ത പ്രൊവൈഡർമാർ** — സൗജന്യ ടിയറുകൾ, ക്രെഡിറ്റ് പ്രോഗ്രാമുകൾ, OAuth പ്രതിദിന ക്വാട്ടകൾ.

| പ്രൊവൈഡർ         | സൗജന്യ ക്വാട്ട / ക്രെഡിറ്റുകൾ                    |
| ---------------- | ------------------------------------------------ |
| Kiro AI          | സൗജന്യ Claude ടിയർ (ഉദാരമായ ന്യായോപയോഗ പരിധി)    |
| OpenCode Free    | ഓതന്റിക്കേഷൻ ആവശ്യമില്ല, ഉദാരമായ നിരക്ക് പരിധികൾ |
| Qoder            | സൗജന്യ OAuth                                     |
| Google Vertex AI | പുതിയ അക്കൗണ്ടിന് $300 ക്രെഡിറ്റുകൾ              |
| Amazon Q         | AWS ഉപയോക്താക്കൾക്കുള്ള സൗജന്യ ടിയർ              |
| Pollinations     | തുറന്ന പൊതു API                                  |
| Cloudflare AI    | Workers AI സൗജന്യ ടിയർ                           |

**തന്ത്രം**: ടിയർ 1+2 പരാജയപ്പെടുമ്പോഴോ `useFreeOnly=true` സജ്ജമാക്കിയിരിക്കുമ്പോഴോ
ബജറ്റ് പരിധിയോടുകൂടിയ `auto` കോംബോ അഭ്യർത്ഥനകൾ ഇവിടെ റൂട്ട് ചെയ്യുന്നു. സൗജന്യ പ്രൊവൈഡർമാർക്ക് പലപ്പോഴും
ദുർബലമായ നിരക്ക് പരിധികളായിരിക്കും — ബാക്ക്ഓഫിന് ശേഷം സർക്യൂട്ട് ബ്രേക്കർ അവയെ പുനഃസ്ഥാപിക്കുന്നു.

## ടിയറുകൾ കോൺഫിഗർ ചെയ്യൽ

ഡാഷ്ബോർഡ് → **ടിയറുകൾ** → നിങ്ങളുടെ പ്രൊവൈഡർമാരെ നിയോഗിക്കുക. ഡിഫോൾട്ടുകൾ (`tierDefaults.json`-ൽ നിന്നുള്ളവ)
യുക്തിസഹമാണ്; മുൻഗണന നൽകേണ്ട പ്രത്യേക സബ്സ്ക്രിപ്ഷനുകളോ ഒഴിവാക്കേണ്ട പ്രൊവൈഡർമാരോ ഉണ്ടെങ്കിൽ തിരുത്തുക.

Auto-Combo-യുടെ 16-ഘടക സ്കോറിങ്ങിൽ ടിയറും പരിഗണിക്കപ്പെടുന്നു.
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md) കാണുക.

## ടെലിമെട്രി

ഡാഷ്ബോർഡ് → **ഉപയോഗം** ഓരോ ടിയറിലും പ്രതിദിനം ചെലവഴിച്ച ടോക്കണുകൾ കാണിക്കുന്നു. ഇത് ഉപയോഗിച്ച്:

- ടിയർ 1 പൂർണ്ണമായി ഉപയോഗിക്കപ്പെടുന്നുണ്ടെന്ന് സ്ഥിരീകരിക്കുക (അല്ലെങ്കിൽ നിങ്ങൾ സബ്സ്ക്രിപ്ഷന്റെ മൂല്യം പാഴാക്കുകയാണ്)
- ഏറ്റവും കൂടുതൽ തിരഞ്ഞെടുക്കപ്പെടുന്ന ടിയർ 2 മോഡലുകൾ കണ്ടെത്തുക (1-2 എണ്ണത്തിലേക്ക് ഏകീകരിക്കുക)
- ടെസ്റ്റ്/പര്യവേക്ഷണ വർക്ക്ലോഡുകളിൽ ടിയർ 3 പണം ലാഭിക്കുന്നുവെന്ന് ഉറപ്പാക്കുക

## സാധാരണ പാറ്റേണുകൾ

### പൂർണ്ണമായും സൗജന്യമായ വർക്ക്ലോഡ്

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

ടിയർ 3-ലേക്ക് ശക്തമായി നയിക്കുന്നു; ടിയർ 3 ലഭ്യമല്ലെങ്കിൽ മാത്രമേ ടിയർ 2 ഉപയോഗിക്കൂ.

### ചെലവുകുറഞ്ഞ ഫോൾബാക്കോടുകൂടിയ സബ്സ്ക്രിപ്ഷൻ-ആദ്യ രീതി

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

ടിയർ 1 → ടിയർ 2 → ടിയർ 3 എന്ന ക്രമവുമായി പൊരുത്തപ്പെടുന്ന വ്യക്തമായ ക്രമീകൃത പട്ടിക.
