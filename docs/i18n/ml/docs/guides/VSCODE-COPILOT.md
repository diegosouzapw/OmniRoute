**OmniCopilot**, നിങ്ങളുടെ OmniRoute നൽകുന്ന എല്ലാ മോഡലുകളെയും _നേറ്റീവ്_ GitHub Copilot Chat
മോഡൽ പിക്കറിൽ ലഭ്യമാക്കുന്നു. രണ്ടാമത്തെ സൈഡ്ബാറോ പ്രത്യേക ചാറ്റ് UI-യോ ഇല്ല — Copilot-ന്റെ ഏജന്റ് മോഡ്, ടൂൾ കോളിംഗ്,
MCP സെർവറുകൾ, ഇഷ്ടാനുസൃത നിർദ്ദേശങ്ങൾ എന്നിവയെല്ലാം തുടർന്നും പ്രവർത്തിക്കും; നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന മോഡലിലാണ് അവ പ്രവർത്തിക്കുക.

## സജ്ജീകരണം

1. **OmniRoute പ്രവർത്തിപ്പിക്കുക** — `npm install -g omniroute && omniroute` (`http://localhost:20128`-ൽ ഡാഷ്ബോർഡ്).
2. **എക്സ്റ്റൻഷൻ ഇൻസ്റ്റാൾ ചെയ്യുക** — Extensions വ്യൂവിൽ "OmniRoute" തിരയുക.
3. **ഒരു മോഡൽ തിരഞ്ഞെടുക്കുക** — Copilot Chat → മോഡൽ പിക്കർ → **Manage Models…** → **OmniRoute**, തുടർന്ന്
   നിങ്ങൾക്ക് ആവശ്യമുള്ളവ ടിക്ക് ചെയ്യുക.

OmniRoute ഡിഫോൾട്ട് പോർട്ടിൽ പ്രവർത്തിക്കുമ്പോൾ ഒന്നും കോൺഫിഗർ ചെയ്യേണ്ടതില്ല. ഒരു റിമോട്ട് ഇൻസ്റ്റൻസിനായി,
**Activity Bar-ലെ OmniRoute ഐക്കൺ** തുറന്ന് (അല്ലെങ്കിൽ `OmniRoute: Manage Connection` പ്രവർത്തിപ്പിച്ച്) ഇനിപ്പറയുന്നവ സജ്ജമാക്കുക:

- **Server URL** — സെർവർ റൂട്ട്, ഉദാ. `http://192.168.0.15:20128`. `/v1` സഫിക്സ്
  എക്സ്റ്റൻഷൻ ചേർക്കും; അത് ഉൾപ്പെടുത്തരുത്.
- **API key** — സെർവർ `REQUIRE_API_KEY` സജ്ജമാക്കിയിട്ടുണ്ടെങ്കിൽ മാത്രം. VS
  Code SecretStorage വഴി OS കീചെയിനിൽ സംഭരിക്കുന്നു; ഒരിക്കലും `settings.json`-ൽ സംഭരിക്കില്ല.

## പിക്കറിൽ കാണിക്കുന്നവ

എക്സ്റ്റൻഷൻ അസംസ്കൃതമായ `GET /v1/models` പേലോഡ് കാണിക്കില്ല — അത് പേലോഡിനെ ക്രമീകരിക്കുന്നു; രണ്ട് ബോധപൂർവമായ
കാരണങ്ങളാൽ നിങ്ങൾ കാണുന്ന എണ്ണം കാറ്റലോഗിന്റെ വലുപ്പത്തേക്കാൾ കുറവായിരിക്കും.

### ഓരോ മോഡലിനും ഒരു id ആവശ്യപ്പെടുന്നു

`MODELS_CATALOG_PREFIX_MODE` ഡിഫോൾട്ടായി **`dual`** ആണ്; ഇത് ഓരോ മോഡലും രണ്ടുതവണ പരസ്യപ്പെടുത്തുന്നു — ഒന്ന്
ഹ്രസ്വ അലിയാസ് പ്രിഫിക്സിന് കീഴിലും മറ്റൊന്ന് കാനോണിക്കൽ പ്രൊവൈഡർ പ്രിഫിക്സിന് കീഴിലും — അതുവഴി പഴയ ക്ലയന്റ്
കോൺഫിഗറേഷനുകൾക്ക് രണ്ട് രൂപങ്ങളും തുടർന്നും പരിഹരിക്കാനാകും:

```
cc/claude-sonnet-4-6        ← അലിയാസ് പ്രിഫിക്സ്
claude/claude-sonnet-4-6    ← കാനോണിക്കൽ പ്രിഫിക്സ്, അതേ മോഡൽ
```

എക്സ്റ്റൻഷൻ **`GET /v1/models?prefix=alias`** അഭ്യർത്ഥിക്കുന്നതിനാൽ ഓരോ മോഡലിനും ഒരു id വീതം ലഭിക്കുന്നു;
നിങ്ങളുടെ മറ്റ് ക്ലയന്റുകൾക്കുള്ള സെർവർ-വ്യാപക ക്രമീകരണം ഇതിലൂടെ മാറുന്നില്ല. ഒരു റഫറൻസ് ഇൻസ്റ്റൻസിൽ ഇത്
**2345 എൻട്രികളെ 1396 ആയി ചുരുക്കി — 949 ഡ്യൂപ്ലിക്കേറ്റുകൾ, നഷ്ടപ്പെട്ട മോഡലുകൾ പൂജ്യം.**

പകരം _എല്ലാ_ ക്ലയന്റുകൾക്കുമായി ഇത് സെർവർ-വ്യാപകമായി പരിഹരിക്കാനാണ് നിങ്ങൾ ആഗ്രഹിക്കുന്നതെങ്കിൽ, ഡാഷ്ബോർഡിൽ
`MODELS_CATALOG_PREFIX_MODE` ഫീച്ചർ ഫ്ലാഗ് `alias` ആയി സജ്ജമാക്കുക. ക്വറി
പാരാമീറ്ററിനും ഓരോ മോഡിനുമുള്ള പട്ടികയ്ക്കുമായി [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) കാണുക.

### ചാറ്റ് ചെയ്യാനാകാത്ത മോഡലുകളെ ഇത് മറയ്ക്കുന്നു

ഇമേജ്, വീഡിയോ, ഓഡിയോ, റീറാങ്ക്, എംബെഡ്ഡിംഗ്, മോഡറേഷൻ മോഡലുകളും കാറ്റലോഗിൽ ഉൾപ്പെടുന്നു. ചാറ്റ് അഭ്യർത്ഥനയിൽ
അവ എന്തായാലും നിരസിക്കപ്പെടും:

```
HTTP 400 — മോഡൽ '<id>' ഒരു ഇമേജ്-ജനറേഷൻ മോഡലാണ്, അതിനാൽ ഇത്
/v1/chat/completions-ൽ ഉപയോഗിക്കാനാവില്ല. പകരം POST /v1/images/generations ഉപയോഗിക്കുക.
```

അതിനാൽ പിക്കറിൽ എത്തുന്നതിനു മുമ്പ് അവയുടെ `type` ഫീൽഡ് ഉപയോഗിച്ച് അവ ഫിൽട്ടർ ചെയ്യപ്പെടുന്നു. **Responses-API
മോഡലുകൾ നിലനിർത്തുന്നു** — ഓരോ Codex / GPT-5.x എൻട്രിയും `supported_endpoints: ["responses"]` പരസ്യപ്പെടുത്തുന്നു;
OmniRoute അവയെ `/v1/chat/completions`-നായി പരിവർത്തനം ചെയ്യുന്നതിനാൽ അവ പൂർണ്ണമായും ഉപയോഗയോഗ്യമാണ്.

### നിങ്ങൾ ഒരിക്കലും കോൺഫിഗർ ചെയ്തിട്ടില്ലാത്ത പ്രൊവൈഡറുകൾ

**സജീവ കണക്ഷൻ** ഉള്ള പ്രൊവൈഡർമാരുടെ മോഡലുകളും എല്ലാ **noAuth**
പ്രൊവൈഡർമാരുടെയും മോഡലുകളും കാറ്റലോഗിൽ ഉൾപ്പെടുന്നു — സൗജന്യ ടയറിന്റെ വലിയൊരു ഭാഗം ഉൾക്കൊള്ളുന്ന, കീ ആവശ്യമില്ലാത്തവയാണിവ. ഇത് ബോധപൂർവമാണ്. അവ മറയ്ക്കാൻ,
ഡാഷ്ബോർഡ് ക്രമീകരണങ്ങളിലെ `blockedProviders`-ൽ അവ ചേർക്കുക; എക്സ്റ്റൻഷനിൽ ഒന്നും മാറില്ല.

## VS Code ടാബിനുള്ളിലെ ഡാഷ്ബോർഡ്

`omnicopilot.dashboardOpen: "editor"` എന്നത് ഒരു ബാഹ്യ ബ്രൗസറിന് പകരം Simple Browser വഴി OmniRoute ഡാഷ്ബോർഡ് ഒരു എഡിറ്റർ ടാബിൽ റെൻഡർ ചെയ്യുന്നു. എംബെഡ്ഡിംഗ് **സെർവറിൽ ഓപ്റ്റ്-ഇൻ ചെയ്യേണ്ടതാണ്**; ഇതിനായി `DASHBOARD_ALLOW_EMBED=vscode` ഉപയോഗിക്കുന്നു. ഇത് ഡിഫോൾട്ടായ `frame-ancestors 'none'` +
`X-Frame-Options: DENY` എന്നതിന് പകരം `frame-ancestors 'self' vscode-webview:` ഉപയോഗിച്ച് HTML പേജുകൾ നൽകുന്നു. ഏത് സാഹചര്യത്തിലും API ഉപരിതലം (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) കർശനമായ ഹെഡറുകൾ നിലനിർത്തുന്നു.

> ⚠️ **ഇത് ഒരു ബിൽഡ്-ടൈം ഫ്ലാഗാണ്, റൺടൈം ഫ്ലാഗല്ല.** Next.js, `headers()`-നെ റൂട്ട്
> മാനിഫെസ്റ്റിലേക്ക് കംപൈൽ ചെയ്യുന്നതിനാൽ, ബണ്ടിൽ ബിൽഡ് ചെയ്യുമ്പോൾ `next.config.mjs` വേരിയബിൾ വായിക്കുന്നു
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> ഇതിനകം ബിൽഡ് ചെയ്ത സെർവർ ആരംഭിക്കുന്നതിന് മുമ്പ് ഇത് എക്സ്പോർട്ട് ചെയ്യുന്നത് ഒന്നും മാറ്റില്ല — ഹെഡറുകൾ ബിൽഡിൽ തന്നെ പതിഞ്ഞിരിക്കുന്നു.

```bash
# വേരിയബിൾ BUILD കമാൻഡിൽ ഉണ്ടായിരിക്കണം
DASHBOARD_ALLOW_EMBED=vscode npm run build        # അല്ലെങ്കിൽ npm run build:release
npm start
```
