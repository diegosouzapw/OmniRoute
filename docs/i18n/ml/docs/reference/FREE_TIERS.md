> **ഉപയോക്താക്കൾക്കായി**: ലളിതമായ ഒരു മാർഗ്ഗനിർദ്ദേശമാണോ അന്വേഷിക്കുന്നത്? സൗജന്യ AI ലഭിക്കുന്നതിനുള്ള ഘട്ടംഘട്ടമായ നിർദ്ദേശങ്ങൾക്കായി [സൗജന്യ ടിയറുകളുടെ മാർഗ്ഗനിർദ്ദേശം](../getting-started/FREE-TIERS-GUIDE.md) കാണുക.

> **അവസാനം ഗവേഷണം നടത്തിയത്:** 2026-06-17 — ഓരോ ദാതാവിനും വെബ് ഗവേഷണം (ഔദ്യോഗിക ഡോക്യുമെന്റേഷൻ + കഴിഞ്ഞ 7 ദിവസത്തെ വാർത്തകൾ, പ്രതികൂല പരിശോധനയോടുകൂടിയ 50-ഏജന്റ് പാസ്), ഓരോ സൗജന്യ-ടിയർ ക്വോട്ടയും + ToS-ഉം പുതുക്കുന്നു. **ഭാഗിക പുനഃപരിശോധന 2026-09-02** (`gemini`, `ollama-cloud`, `groq`, `nara`, `mistral` — താഴെയുള്ള തീയതിയിട്ട കുറിപ്പ് കാണുക).
> **ആധികാരിക ഉറവിടം (കാറ്റലോഗ്):** `open-sse/config/freeModelCatalog.ts` (ഓരോ MODEL-നുമുള്ള ബജറ്റുകൾ, പൂൾ-ഡീഡ്യൂപ്ലിക്കേറ്റ് ചെയ്തത്). താഴെയുള്ള ടോക്കൺ-ബജറ്റ് സംഖ്യകൾ തത്സമയ വെബ് ഗവേഷണത്തിൽ നിന്നുള്ളവയും ഒരു **ഏകദേശ കണക്കും** ആണ് — [രീതിശാസ്ത്രവും പരിമിതികളും](#methodology--caveats) കാണുക.

## TL;DR — OmniRoute യഥാർത്ഥത്തിൽ എത്ര സൗജന്യ ഇൻഫറൻസ് സമാഹരിക്കുന്നു?

| മെട്രിക്                                             | ടോക്കണുകൾ / മാസം | അർത്ഥം                                                                                                                                                                                                                                                                                                                                           |
| ---------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **രേഖപ്പെടുത്തിയ ആവർത്തന ഗ്രാന്റ് (സ്ഥിരം)**         | **~1.62B**       | സൗജന്യ-ടിയർ **പൂളുകൾ** (ഓരോ മോഡലിനുമുള്ള കാറ്റലോഗ്), പങ്കിടുന്ന ഓരോ പൂളും **ഒരിക്കൽ മാത്രം** കണക്കാക്കുന്നു. `/api/free-tier/summary`-നും ഡാഷ്ബോർഡിലെ സൗജന്യ-ടിയർ ബജറ്റ് പേജിനും പിന്നിലുള്ള തത്സമയ ഉറവിടം. **ഈ സംഖ്യ ഉപയോഗിക്കുക.**                                                                                                             |
| **+ സൈൻഅപ്പ് ക്രെഡിറ്റുകളോടെയുള്ള ആദ്യ മാസം**        | **~2.22B**       | സ്ഥിരം ഗ്രാന്റ് + ഒറ്റത്തവണ സൈൻഅപ്പ് ക്രെഡിറ്റുകൾ (Z.AI 20M, DeepSeek 5M, …), ഓരോ അക്കൗണ്ടിലും ഡീഡ്യൂപ്ലിക്കേറ്റ് ചെയ്തത്. **ആദ്യ മാസം മാത്രം** — ഇത് ആവർത്തിക്കില്ല.                                                                                                                                                                            |
| **+ ശാശ്വതമായി സൗജന്യം, പ്രസിദ്ധീകരിച്ച പരിധിയില്ല** | _അളക്കാനാവില്ല_  | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — യഥാർത്ഥ ആവർത്തന ആക്സസ്, നിരക്ക്/സമകാലികതാ പരിധികളുണ്ട്, **കണക്കാക്കാൻ ടോക്കൺ പരിധിയില്ല**. പട്ടികപ്പെടുത്തുന്നു, ഒരിക്കലും ആകെ കൂട്ടുന്നില്ല (`RPM×24/7` എന്ന രീതിയിൽ കണക്കാക്കുന്നത് ഞങ്ങൾ നിരസിക്കുന്ന പെരുപ്പിക്കലാണ്). |
| **+ ഡെപ്പോസിറ്റ്-അൺലോക്ക് വർധന**                     | **+~24M**        | ഒറ്റത്തവണ **$10** OpenRouter ടോപ്പ്-അപ്പ് അതിന്റെ സൗജന്യ പൂൾ 50 → 1000 req/day ആയി ഉയർത്തുന്നു. സ്ഥിരം സംഖ്യയെ ഒരിക്കലും പെരുപ്പിക്കാതിരിക്കാനായി ഇത് പ്രത്യേകം റിപ്പോർട്ട് ചെയ്യുന്നു.                                                                                                                                                          |
| **+ പ്രാദേശിക തിരിച്ചറിയൽ പരിശോധനയ്ക്കു പിന്നിൽ**    | **+~6M**         | `modelscope` (Alibaba Cloud ബന്ധിപ്പിക്കൽ + മെയിൻലാൻഡ് ചൈനയിലെ യഥാർത്ഥ-പേര് സ്ഥിരീകരണം). യഥാർത്ഥ ആവർത്തന ക്വോട്ട, `gatedRecurringTokens` / `gatedProviders` ആയും ഡാഷ്ബോർഡിലും പ്രദർശിപ്പിക്കുന്നു. പ്രധാന സംഖ്യയിൽ ഒരിക്കലും കൂട്ടിച്ചേർക്കുന്നില്ല: പ്രാദേശിക തിരിച്ചറിയൽ സ്ഥിരീകരണത്തിനു പിന്നിൽ +~6M.                                         |
| സൈദ്ധാന്തിക പരമാവധി (എല്ലാ നിരക്ക് പരിധികളും, 24/7)  | ~10B             | നിർത്താതെയുള്ള ഉപയോഗത്തിലേക്ക് എക്സ്ട്രാപൊളേറ്റ് ചെയ്ത എല്ലാ ദാതാക്കളുടെയും നിരക്ക് പരിധികളുടെ ആകെത്തുക. **ഇത് ഒരു ഉറപ്പല്ല** — ഇത് പ്രധാന തലക്കെട്ടാക്കരുത്.                                                                                                                                                                                    |

**സത്യസന്ധമായ പ്രധാന തലക്കെട്ട്:** _35 സൗജന്യ-ടിയർ പൂളുകളിലായി OmniRoute പ്രതിമാസം **~1.62B രേഖപ്പെടുത്തിയ സൗജന്യ ടോക്കണുകൾ** സമാഹരിക്കുന്നു (സൈൻഅപ്പ് ക്രെഡിറ്റുകൾ ഉൾപ്പെടെ ആദ്യ മാസത്തിൽ ~2.22B വരെ) — കൂടാതെ ശാശ്വതമായി സൗജന്യവും പരിധിയില്ലാത്തതുമായ നിരവധി ദാതാക്കളും — RTK + Caveman കംപ്രഷൻ (15–95% ടോക്കൺ ലാഭം) അത് ഇനിയും കൂടുതൽ പ്രയോജനപ്പെടുത്താൻ സഹായിക്കുന്നു._

> **മുമ്പത്തെ ~1.94B-ൽ നിന്ന് ഇത് കുറഞ്ഞത് എന്തുകൊണ്ട്.** 2026-06-17-ലെ പുതുക്കൽ ഒരു സത്യസന്ധതാ തിരുത്തലാണ്, നഷ്ടമല്ല: `gemini` ഇപ്പോൾ പൂൾ അടിസ്ഥാനത്തിൽ ഡീഡ്യൂപ്ലിക്കേറ്റ് ചെയ്തിരിക്കുന്നു (മുമ്പ് ഓരോ Flash വകഭേദവും വെവ്വേറെ എണ്ണിയതിനാൽ കണക്ക് പെരുപ്പിച്ചിരുന്നു, 462M → 60M), `cloudflare-ai` അതിന്റെ യഥാർത്ഥ 10k-Neurons/day ആയി തിരുത്തി (122M → 30M), `doubao` ആവർത്തിച്ച് ലഭിക്കുന്നതല്ലാത്ത, ഒറ്റത്തവണ സൈൻ-അപ്പ് ക്രെഡിറ്റായി പുനർവർഗ്ഗീകരിച്ചു, കൂടാതെ പ്രവർത്തനം അവസാനിപ്പിച്ച ടയറുകൾ നീക്കം ചെയ്തു (`chutes`/`phind`/`kluster` നിർത്തലാക്കി). `llm7` (ശരിയായ 5M/day → 150M), പുതിയ സൗജന്യ പ്രൊവൈഡർമാർ (Kilo, OpenCode Zen, Z.AI GLM-Flash) എന്നിവ ഇത് ഭാഗികമായി നികത്തുന്നു.
>
> **v3.8.42-ൽ വീണ്ടും തിരുത്തി ~1.37B ആക്കി:** സൗജന്യ പ്രിവ്യൂ അവസാനിച്ചതിന് ശേഷം `longcat`-നെ ആവർത്തിച്ച് ലഭിക്കുന്ന 150M/mo ഗ്രാന്റിൽ നിന്ന് ഒറ്റത്തവണ ലഭിക്കുന്ന 10M സൈൻ-അപ്പ് ക്രെഡിറ്റായി പുനർവർഗ്ഗീകരിച്ചു. അതേ സത്യസന്ധതാ നിയമം തന്നെ — അബദ്ധത്തിൽ ഒരു പ്രൊവൈഡറെയും ഒഴിവാക്കിയിട്ടില്ല.

## രീതിശാസ്ത്രവും പരിമിതികളും

- വെബ് ഗവേഷണത്തിലൂടെ ശേഖരിച്ച, **2026-06-17**-ലെ ഓരോ ദാതാവിന്റെയും രേഖപ്പെടുത്തിയ സൗജന്യ-ടയർ പരിധികളിൽനിന്നുള്ള **പരമാവധി-പരിധി അനുമാനങ്ങളാണ്** ഈ സംഖ്യകൾ. സൗജന്യ ടയറുകൾ നിരന്തരം മാറുന്നു — ഒരു കണക്കിനെ ആശ്രയിക്കുന്നതിനുമുമ്പ് വീണ്ടും പരിശോധിക്കുക.
- **ഒരു എൻട്രി യഥാർത്ഥത്തിൽ എന്താണ് ഉറപ്പുനൽകുന്നത്.** ഓരോ വരിക്കും പ്രത്യേകമായ വിശ്വാസ്യതാ റേറ്റിംഗ് ഒരു എൻട്രിയിലും ഇല്ല, API-യും അത്തരം റേറ്റിംഗ് നൽകുന്നില്ല — മുകളിലുള്ള എല്ലാ കണക്കുകളെയും ഒരേ, വ്യക്തമാക്കാത്ത ഗുണനിലവാരത്തിലുള്ള അനുമാനങ്ങളായി കണക്കാക്കുക. എന്നാൽ രണ്ട് വസ്തുതകൾ വ്യത്യസ്തമാണ്, കാരണം അവ അനുമാനിച്ച് കണ്ടെത്തിയതല്ല, കൈകൊണ്ട് ക്യൂറേറ്റ് ചെയ്തവയാണ്: 44 എൻട്രികളിൽ സ്വതന്ത്രമായി രേഖപ്പെടുത്തിയ നിർബന്ധിത നിർത്തൽ ഉണ്ട് (അവയിൽ 39 എണ്ണം xKiro വരികളാണ്; അവയെല്ലാം ഒരേ പ്രതിദിന അലവൻസ് പങ്കിടുന്നു), കൂടാതെ 13 എൻട്രികളിൽ പ്രോംപ്റ്റ്-പരിശീലന വെളിപ്പെടുത്തൽ ഉണ്ട്. സൗജന്യ അലവൻസ് കവിഞ്ഞാൽ നിശ്ശബ്ദമായി ബില്ലിംഗ് ആരംഭിക്കുന്നതിനുപകരം അഭ്യർത്ഥന നിരസിക്കുമെന്ന് ദാതാവിന്റെ സ്വന്തം നിബന്ധനകൾ പറയുമ്പോൾ മാത്രമാണ് `hardStopGuaranteed` സജ്ജമാക്കുന്നത്; ഉറവിടം എൻട്രിയുടെ അടുത്തുള്ള ഒരു കമന്റിൽ നൽകുന്നു. ഇത് ഒരിക്കലും ഡിഫോൾട്ടായി `true` ആക്കില്ല; ആരും പരിശോധിച്ചിട്ടില്ലാത്ത ഒരു എൻട്രിയിൽ ഇത് സജ്ജീകരിക്കാതെ തുടരും. അതിനാൽ hard-stop ഫ്ലാഗ് ഇല്ലാത്തത് "സ്ഥിരീകരിച്ചിട്ടില്ല" എന്നാണ് അർത്ഥമാക്കുന്നത്, "നിങ്ങളിൽനിന്ന് നിരക്ക് ഈടാക്കുമെന്ന് അറിയാം" എന്നല്ല. **STRICT മോഡ്** (സ്വമേധയാ പ്രവർത്തനക്ഷമമാക്കുന്ന `freeAccessPolicy=strict` റൂട്ടിംഗ് ഗാർഡ്) ഫ്ലാഗുള്ള എൻട്രികളെ മാത്രമാണ് വിശ്വസിക്കുന്നത്; മറ്റെല്ലാ സൗജന്യ ടയറുകളും `no-hard-stop` ആയി ഒഴിവാക്കപ്പെടുന്നു (`open-sse/services/autoCombo/strictZeroCostFilter.ts` കാണുക). ഗാർഡ് ഒരു പൂൾ ഫിൽട്ടർ ചെയ്യുമ്പോൾ, ഓപ്പറേറ്റർക്ക് ദൃശ്യമാകുന്ന ലോഗ് ഒഴിവാക്കിയവയുടെ എണ്ണവും അവയിൽ `no-hard-stop`-ന്റെ വിഹിതവും റിപ്പോർട്ട് ചെയ്യുന്നു.
- `estMonthlyFreeTokens` = ആവർത്തിച്ച് ലഭിക്കുന്ന പ്രതിമാസ ടോക്കണുകൾ മാത്രം. **ഒറ്റത്തവണ ലഭിക്കുന്ന സൈൻഅപ്പ് ക്രെഡിറ്റുകൾ ആവർത്തിച്ച് ലഭിക്കില്ല**, അതിനാൽ അവ 0 ആയി കണക്കാക്കുന്നു. നിർത്തലാക്കിയ ടയറുകളും 0 ആണ്.
- പ്രതിദിന ടോക്കൺ പരിധി → `monthly = daily × 30`. RPD മാത്രം രേഖപ്പെടുത്തിയിട്ടുണ്ടെങ്കിൽ → `RPD × ~800 ഔട്ട്പുട്ട് ടോക്കണുകൾ × 30`. RPM/TPM മാത്രം (പ്രതിദിന പരിധിയില്ല) → **പരിധിയില്ലാത്തത്** (താഴെ കാണുക).
- **സ്ഥിരമായി സൗജന്യം, എന്നാൽ പ്രസിദ്ധീകരിച്ച ടോക്കൺ പരിധിയില്ല** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): ഇവ നിരക്ക്/സമകാലികതാ പരിധികളുള്ള, യഥാർത്ഥത്തിൽ ആവർത്തിച്ച് ലഭിക്കുന്ന സൗജന്യ ആക്സസുകളാണ്. ഇവയെ ഞങ്ങൾ `recurring-uncapped` ആയി വർഗ്ഗീകരിക്കുകയും **ഒരിക്കലും ആകെ കണക്കിൽ ചേർക്കാതിരിക്കുകയും ചെയ്യുന്നു** — `RPM × 24/7 × 30d` എന്ന് ഗുണിക്കുന്നത് യാഥാർഥ്യമല്ലാത്ത പരമാവധി പരിധി സൃഷ്ടിക്കും (ഞങ്ങൾ നിരസിക്കുന്ന പെരുപ്പിക്കൽ). ഇവ നിലവിലുണ്ടെന്ന് നിങ്ങൾ അറിയുന്നതിനായി പട്ടികപ്പെടുത്തിയിരിക്കുന്നു.
- **ഡെപ്പോസിറ്റ്-അൺലോക്ക് വർധന:** സൗജന്യ ക്വോട്ട സ്ഥിരമായി ഉയർത്തുന്ന ചെറിയ ഒറ്റത്തവണ ടോപ്പ്-അപ്പ് (OpenRouter: $10 → 1000 req/day ≈ +24M/mo). ഇത് ഒരു പ്രത്യേക കണക്കായി റിപ്പോർട്ട് ചെയ്യുകയും സ്ഥിരമായ പ്രധാന കണക്കിൽ ഉൾപ്പെടുത്താതിരിക്കുകയും ചെയ്യുന്നു.
- **യോഗ്യതാ നിയന്ത്രണമുള്ള ക്വോട്ടകൾ** (`eligibilityGate: "regional-identity"`): പ്രദേശബന്ധിതമായ തിരിച്ചറിയൽ പരിശോധനയ്ക്കുശേഷം മാത്രം ലഭ്യമാകുന്ന, യഥാർത്ഥത്തിൽ ആവർത്തിക്കുന്ന ക്വോട്ട (നിലവിൽ ചൈനീസ് മെയിൻലാൻഡിലെ യഥാർഥ-പേര് സ്ഥിരീകരണം). ഇതേ പൂൾ-ഡീഡ്യൂപ്പ് നിയമം ഉപയോഗിച്ച് പ്രത്യേക കണക്കായ (`gatedRecurringTokens`) ഇതിൽ ഉൾപ്പെടുത്തുന്നു; സ്ഥിരമായ പ്രധാന കണക്കിൽ ഒരിക്കലും ഉൾപ്പെടുത്തുന്നില്ല. വ്യവസ്ഥ (`freeType`) മാറ്റമില്ലാതെ തുടരുന്നതിനാൽ റൂട്ടിംഗും മാറ്റമില്ലാതെ തുടരുന്നു.
- **തെളിവ് വിഭാഗങ്ങൾ.** നിയമം: കാറ്റലോഗിലെ ഒരു സംഖ്യ അതിന്റെ ഉറവിടം എൻട്രിയുടെ അടുത്തുള്ള `// evidence:` കമന്റിൽ ഉദ്ധരിക്കുന്നു — `public-page` (ആർക്കും വായിക്കാവുന്ന ദാതാവിന്റെ പേജ്), `api-public` (ദാതാവിന്റെ ഓതന്റിക്കേഷൻ ആവശ്യമില്ലാത്ത എൻഡ്പോയിന്റ്, ഉദാ. router.bynara.id-ലെ NaraRouter-ന്റെ പൊതു പ്ലാൻസ് എൻഡ്പോയിന്റ്), അല്ലെങ്കിൽ `console-verified <date> por <who>` (കണക്ക് ഒരു അക്കൗണ്ട് കൺസോളിനുള്ളിൽ മാത്രമേ ദൃശ്യമാകൂ; അത് ആരാണ് എപ്പോൾ കണ്ടതെന്നും പരിധി നിലവിലുണ്ടെന്ന് പറയുന്ന പൊതു പേജും കമന്റിൽ രേഖപ്പെടുത്തുന്നു). നിലവിലെ സ്ഥിതി: 2026-09-02-ന് വീണ്ടും ഓഡിറ്റ് ചെയ്ത അഞ്ച് ബ്ലോക്കുകളിൽ ഇത് ഉൾപ്പെടുന്നു (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); 2026-09-02-ലെ പുനഃപരിശോധനയ്ക്ക് മുമ്പുള്ള എൻട്രികൾ പുതുക്കുന്നതുവരെ മുമ്പത്തെ ഗവേഷണം അവകാശപ്പെടുന്നു; തെളിവ് കമന്റില്ലാത്ത ഏതൊരു **പുതിയതോ മാറ്റം വരുത്തിയതോ ആയ** സംഖ്യയും ഒരു ബഗാണ്. നിലവിൽ `mistral` മാത്രമാണ് കൺസോൾ-സ്ഥിരീകരിച്ചത്.

## ഞങ്ങളുടെ സംഖ്യ മറ്റ് അഗ്രിഗേറ്ററുകളുടേതിനേക്കാൾ ചെറുതാകുന്നത് എന്തുകൊണ്ട്

ഈ മേഖലയിലെ മിക്ക "പ്രതിമാസ സൗജന്യ ടോക്കണുകൾ" എന്ന കണക്കുകളും ഓരോ മോഡലിന്റെയും ലേബലുകൾ കൂട്ടിച്ചേർത്തതാണ്. ഞങ്ങളുടേത് മനഃപൂർവം അങ്ങനെയല്ല:

- **പങ്കിട്ട ഓരോ പൂളും ഒരിക്കൽ മാത്രമാണ് കണക്കാക്കുന്നത്.** Mistral-ന്റെ സൗജന്യ പ്ലാൻ ഓരോ സ്ഥാപനത്തിനും പ്രതിമാസം അനുവദിക്കുന്ന ഒരൊറ്റ 1B അലവൻസാണ്; അഞ്ച് മോഡലുകൾക്ക് കീഴിൽ അത് പട്ടികപ്പെടുത്തിയതുകൊണ്ട് അത് 5B ആകുന്നില്ല. ഓരോ മോഡലിനും പ്രത്യേകം കൂട്ടിയാൽ, ഞങ്ങളുടെ സ്വന്തം കാറ്റലോഗിലെ കണക്ക് **~7.4B** ആയിരിക്കും (2026-09-03-ന് വീണ്ടും കണക്കാക്കിയത്; ഈ കണക്ക് CI നിയന്ത്രിതമല്ല — കാറ്റലോഗിൽ മാറ്റം വരുമ്പോഴെല്ലാം വീണ്ടും അളക്കുക) — പ്രധാന കണക്ക് **~1.47B** എന്നാണ് പറയുന്നത്, കാരണം ഓരോ പ്രൊവൈഡറിലും ഒരു അക്കൗണ്ടിന് യഥാർഥത്തിൽ ചെലവഴിക്കാനാകുന്നത് അത്രയുമാണ്.
- **ദൈനംദിന പരിധികൾ പരിവർത്തനം ചെയ്യുന്നു, നിരക്കുകൾ ചെയ്യുന്നില്ല.** രേഖപ്പെടുത്തിയ tokens/day പരിധി `× 30` ആക്കുന്നു; രേഖപ്പെടുത്തിയ requests/day പരിധി `RPD × ~800 tokens × 30` ആക്കുന്നു; requests-per-minute മാത്രം പ്രസിദ്ധീകരിക്കുന്ന പ്രൊവൈഡറിന് പ്രതിമാസ കണക്ക് **ഇല്ല**, അതിനാൽ അത് _പരിധിയില്ലാത്തത്_ എന്ന് പട്ടികപ്പെടുത്തുന്നു, ഒരിക്കലും ആകെ കണക്കിൽ ചേർക്കുന്നില്ല. ഒരു നിരക്കുപരിധിയെ 24/7 കൊണ്ട് ഗുണിച്ച് പെരുപ്പിക്കുന്നതിനെ ഞങ്ങൾ നിരസിക്കുന്നു.
- **പ്രാദേശിക ഐഡന്റിറ്റി പരിശോധനയ്ക്കു പിന്നിലുള്ള ക്വോട്ടകൾ പ്രത്യേകം കാണിക്കുന്നു** (`+~6M behind regional identity verification`), കാരണം മിക്ക വായനക്കാർക്കും അവ ഉപയോഗിക്കാനാകില്ല.
- **സൈൻഅപ്പ് ക്രെഡിറ്റുകൾ ആദ്യ മാസത്തിൽ മാത്രം ലഭിക്കുന്നവയാണ്**, അവ സ്ഥിരമായ കണക്കിൽ കലർത്താതെ രണ്ടാമത്തെ കണക്കായി റിപ്പോർട്ട് ചെയ്യുന്നു.
- **ഈ കണക്ക് CI ഉപയോഗിച്ച് നടപ്പിലാക്കുന്നു.** `npm run check:docs-counts` കാറ്റലോഗിൽ നിന്ന് മൊത്തം കണക്കുകൾ വീണ്ടും കണക്കാക്കുകയും ഈ ഫയൽ, README അല്ലെങ്കിൽ ബജറ്റ് കാർഡ് എന്നിവയിലെ കണക്കുകൾ അവയിൽ നിന്ന് വ്യതിചലിക്കുമ്പോൾ ബിൽഡ് പരാജയപ്പെടുത്തുകയും ചെയ്യുന്നു.

## ToS ശ്രദ്ധാ പട്ടിക

> **ToS ഫ്ലാഗ് ഒരു ഉപദേശം മാത്രമാണ്, റൂട്ടിംഗ് ഗേറ്റ് അല്ല.** `tos` എന്ന് അടയാളപ്പെടുത്തിയ പ്രൊവൈഡർമാരെയും ഡിഫോൾട്ടായി റൂട്ടിംഗിലും combo/fallback-ലും ഉൾപ്പെടുത്തുന്നു; ഫ്ലാഗ് `/dashboard/free-tiers`, `/api/free-tier/summary` എന്നിവയിൽ മാത്രമാണ് ദൃശ്യമാകുന്നത്. `excludeTosAvoid` ക്വറി പാരാമീറ്റർ സമ്മറി വ്യൂവിനെ മാത്രമാണ് ബാധിക്കുന്നത്, ആഗോള റൂട്ടിംഗിനെ അല്ല. വിലയിരുത്തൽ `open-sse/config/freeTierCatalog.ts`-ലാണ് നിലനിൽക്കുന്നത് (വിവരദായകം മാത്രം, റൂട്ടിംഗ് എൻജിനുകൾ ഇത് വായിക്കുന്നില്ല).

> സ്വയം ഹോസ്റ്റ് ചെയ്ത, ഒരൊറ്റ ഉപയോക്താവിനുള്ള വ്യക്തിഗത പ്രോക്സിയുമായി ബന്ധപ്പെട്ട് ഓരോ പ്രൊവൈഡറുടെയും നിബന്ധനകളെക്കുറിച്ചുള്ള ഒരു ദ്രുത അവലോകനം. `caution` = പരിശോധിക്കേണ്ട വ്യക്തിഗത-ഉപയോഗ അല്ലെങ്കിൽ പ്രോക്സി വ്യവസ്ഥ; `ambiguous` = അവ്യക്തം; `ok` = വ്യക്തമായി അനുവദിച്ചിരിക്കുന്നു. ഇത് വിവരദായകം മാത്രമാണ്, നിയമോപദേശമല്ല — തീരുമാനം നിങ്ങളുടേതാണ്.

### ⚠️ ജാഗ്രത — പരിശോധിക്കേണ്ട വ്യക്തിഗത-ഉപയോഗ / പ്രോക്സി വ്യവസ്ഥകൾ (16)

## OpenCode Free: ക്ലയന്റ്-കോൺട്രാക്ട് നിയന്ത്രണം (#14313)

കീലെസ് `opencode` പ്രൊവൈഡർ (പബ്ലിക് `https://opencode.ai/zen/v1`), OpenCode ക്ലയന്റ് കോൺട്രാക്ടുമായി പൊരുത്തപ്പെടാത്ത ഏതൊരു അഭ്യർത്ഥനയും **403 `FreeTierError`** സഹിതവും _"OpenCode-നുള്ളിൽ നിന്ന് മാത്രമേ OpenCode-ന്റെ സൗജന്യ ടിയർ ഉപയോഗിക്കാനാകൂ"_ എന്ന വാചകത്തോടെയും നിരസിക്കുന്നു. ഇത് ഒരു അഭ്യർത്ഥന-സ്കോപ്പ്ഡ് നിരസിക്കലാണ് (ഒരേ അഭ്യർത്ഥനാ ഘടനയ്ക്ക് എല്ലാ അക്കൗണ്ടുകളിലും ഒരേ വിധി), മോഡൽ നിരോധനമോ കണക്ഷൻ കൂൾഡൗണോ അല്ല — OmniRoute ഇതിനെ `project_route_error` ആയി വർഗ്ഗീകരിക്കുകയും മോഡൽ ലോക്ക്ഔട്ട് / കൂൾഡൗൺ ഒഴിവാക്കുകയും (സിന്തറ്റിക് `noauth` പാതയിൽ) ചെറിയൊരു TTL കാലയളവിലേക്ക് ഓട്ടോ-കോംബോ പുനഃതിരഞ്ഞെടുപ്പ് താൽക്കാലികമായി നിർത്തുകയും ചെയ്യുന്നു. ശൂന്യമല്ലാത്ത ടൂൾ ലിസ്റ്റ്, `stream: true`, OpenCode സെഷൻ/UA ഹെഡറുകൾ (`opencodeFreeTierContract.ts`) എന്നിവ ഉൾക്കൊള്ളുന്ന അഭ്യർത്ഥനകൾ അയയ്ക്കുക; അല്ലെങ്കിൽ 403 പ്രതീക്ഷിക്കുക.
