OmniRoute, `free_proxies` പട്ടികയിൽ ക്രമീകരിച്ച സൗജന്യ പ്രോക്സികളുടെ ഒരു ശേഖരം നൽകുന്നു;
ഇത് ബാഹ്യ ദാതാക്കളിൽനിന്ന് (1proxy, proxifly, iplocate, webshare) സമന്വയിപ്പിക്കുന്നു.
ഡാഷ്ബോർഡിൽ ഇവ **Settings → Free Proxies** എന്നതിന് കീഴിൽ ലഭ്യമാണ്. ലിസ്റ്റ് റൂട്ട് ലഭ്യമാക്കുന്ന
സെർവർ-സൈഡ് ഫിൽട്ടറിംഗ്, സോർട്ടിംഗ്, എണ്ണൽ, സമന്വയ-പിശക് റിപ്പോർട്ടിംഗ് എന്നിവ
ഈ പ്രമാണം വിശദീകരിക്കുന്നു.

## ലിസ്റ്റ് റൂട്ട് — `GET /api/settings/free-proxies`

ഫിൽട്ടർ ചെയ്തതും സോർട്ട് ചെയ്തതുമായ, പേജിനേഷൻ പ്രയോഗിച്ച ഒരു ഭാഗവും ആകെ എണ്ണവും നൽകുന്നു. ഫിൽട്ടറിംഗും
എണ്ണലും SQL-ൽ നടക്കുന്നതിനാൽ, എല്ലാ വരികളും മെമ്മറിയിലേക്ക് ലോഡ് ചെയ്യാതെ തന്നെ UI-യ്ക്ക് യഥാർത്ഥ ആകെ എണ്ണം
(ഉദാ. `Total: 0`) കാണിക്കാൻ കഴിയും.

### ക്വറി പാരാമീറ്ററുകൾ

| പാരാമീറ്റർ        | തരം                                | ഡിഫോൾട്ട് | അർത്ഥം                                                                                                                                      |
| ----------------- | ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | സ്ട്രിംഗ്                          | `""`      | ഹോസ്റ്റ് (കൂടാതെ സോഴ്സ്) കോളത്തിൽ കേസ്-സെൻസിറ്റീവ് `LIKE`.                                                                                  |
| `protocol`        | സ്ട്രിംഗ്                          | `""`      | `type` ഫിൽട്ടർ: `http` / `https` / `socks4` / `socks5`. ശൂന്യം = എല്ലാം.                                                                    |
| `country`         | സ്ട്രിംഗ്                          | `""`      | `countryCode` ഫിൽട്ടർ (ISO-2). ശൂന്യം = എല്ലാം.                                                                                             |
| `minQuality`      | സംഖ്യ                              | `0`       | `qualityScore >= minQuality` ആയ വരികൾ മാത്രം. `0` = കുറഞ്ഞ പരിധിയില്ല.                                                                      |
| `disabledSources` | സ്ട്രിംഗ്                          | `""`      | ഒഴിവാക്കേണ്ട സോഴ്സ് ഐഡികളുടെ കോമ ഉപയോഗിച്ച് വേർതിരിച്ച പട്ടിക (ഉദാ. `proxifly,webshare`).                                                   |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = സ്കോർ അവരോഹണക്രമത്തിൽ; `latency` = ലേറ്റൻസി ആരോഹണക്രമത്തിൽ (null മൂല്യങ്ങൾ അവസാനം); `recent` = `lastValidated` അവരോഹണക്രമത്തിൽ. |
| `offset`          | സംഖ്യ                              | `0`       | പേജിനേഷന്റെ ആരംഭം.                                                                                                                          |
| `limit`           | സംഖ്യ                              | `50`      | പേജ് വലുപ്പം (സെർവർ-സൈഡിൽ പരിമിതപ്പെടുത്തിയിരിക്കുന്നു).                                                                                    |

### പ്രതികരണം

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["അപ്സ്ട്രീമിൽനിന്നുള്ള HTTP 429"],
    "webshare": ["നെറ്റ്വർക്ക് ടൈംഔട്ട്"]
  }
}
```

`total` എന്നത് പേജിനേഷന് **മുമ്പുള്ള** ഫിൽട്ടർ ചെയ്ത ആകെ എണ്ണത്തെ സൂചിപ്പിക്കുന്നു; അതിനാൽ UI-യ്ക്ക്
`Total: N`, `hasMore` എന്നിവ സ്വതന്ത്രമായി റെൻഡർ ചെയ്യാൻ കഴിയും. `syncErrors` സോഴ്സ് ഐഡി അടിസ്ഥാനമാക്കി കീ ചെയ്തിരിക്കുന്നു,
കൂടാതെ അവസാന സമന്വയം പരാജയപ്പെട്ട സോഴ്സുകൾക്കായി മാത്രം ഇത് പൂരിപ്പിക്കപ്പെടുന്നു — `Total: 0` ഫലം
ഒരിക്കലും വിശദീകരണമില്ലാതെ വരില്ല.

## പൂളിലേക്ക് ചേർക്കൽ — `POST /api/settings/free-proxies/[id]/add-to-pool`

ഒരു സൗജന്യ പ്രോക്സിയെ മാനേജ് ചെയ്യുന്ന `proxy_registry` പൂളിലേക്ക് ഉയർത്തുന്നു. ആദ്യം
അപ്സ്ട്രീം സാധൂകരിക്കുന്നു; വിജയിക്കുമ്പോൾ പുതിയ പൂൾ പ്രോക്സി ഐഡിയും അളന്ന ലേറ്റൻസിയും നൽകുന്നു.

## സമന്വയം — `POST /api/settings/free-proxies/sync`

പ്രവർത്തനക്ഷമമാക്കിയ എല്ലാ സോഴ്സുകളും (അല്ലെങ്കിൽ `{ "sources": [...] }` എന്നതിലെ ഉപഗണവും) വീണ്ടും ലഭ്യമാക്കുന്നു. ഓരോ
സോഴ്സും സ്വതന്ത്രമായി സമന്വയിപ്പിക്കുന്നു; പരാജയപ്പെടുന്ന സോഴ്സ് `syncErrors`-ൽ രേഖപ്പെടുത്തുകയും
മറ്റുള്ളവ പൂർത്തിയാകുകയും ചെയ്യുന്നു. അതിനാൽ ഭാഗിക സമന്വയങ്ങൾ മുമ്പത്തെ സാധുവായ ഡാറ്റ ഒരിക്കലും മായ്ക്കില്ല.

## സ്ഥിതിവിവരക്കണക്കുകൾ — `GET /api/settings/free-proxies/stats`

വരി പേലോഡ് ഇല്ലാതെ `total / inPool / avgQuality / bySource / lastSyncAt` സംഗ്രഹം
നൽകുന്നു — ഡാഷ്ബോർഡ് ഹെഡർ വിജറ്റുകൾ ഇത് ഉപയോഗിക്കുന്നു.
