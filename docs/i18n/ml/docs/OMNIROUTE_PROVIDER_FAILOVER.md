വീണ്ടും ശ്രമിക്കണമോ എന്ന തീരുമാനം എടുക്കുന്നതിന് മുമ്പ് പരാജയങ്ങളെ വർഗ്ഗീകരിക്കുന്നു.

സമയപരിധി ലംഘനങ്ങൾ, നെറ്റ്വർക്ക് പിശകുകൾ, നിരക്ക് പരിധികൾ, ദാതാവിൽ നിന്നുള്ള 5xx പ്രതികരണങ്ങൾ എന്നിവ പോലുള്ള താൽക്കാലിക പരാജയങ്ങൾ സംഭവിക്കുമ്പോൾ മറ്റൊരു ദാതാവിലേക്ക് മാറിയേക്കാം. പ്രാമാണീകരണ പിശകുകൾ, അനുമതി പിശകുകൾ, അസാധുവായ അഭ്യർത്ഥനകൾ, ലഭ്യമല്ലാത്ത മോഡലുകൾ, അജ്ഞാത പരാജയങ്ങൾ എന്നിവയ്ക്ക് അന്ധമായി വീണ്ടും ശ്രമിക്കില്ല.

സ്ഥിരസ്ഥിതിയായ ക്രോസ്-പ്രൊവൈഡർ നയം പരമാവധി മൂന്ന് ദാതൃ ശ്രമങ്ങൾ അനുവദിക്കുകയും നിരക്ക് പരിധികളും സമയപരിധി ലംഘനങ്ങളും നേരിടുമ്പോൾ വീണ്ടും ശ്രമിക്കുകയും ചെയ്യുന്നു. കൂടാതെ, ഭരണപരമായ പ്രവർത്തനരഹിതമാക്കലിനെ താൽക്കാലിക സർക്യൂട്ട് നിലയിൽ നിന്ന് വേർതിരിച്ചുനിർത്തുന്നു.

സർക്യൂട്ട് നിലകൾ `closed`, `open`, `half_open` എന്നിവയാണ്. ഒരു കൂൾഡൗൺ പരിമിതമായ ഒരു പരിശോധന ഷെഡ്യൂൾ ചെയ്യുന്നു; വിജയകരമായ പരിശോധന സർക്യൂട്ട് അടയ്ക്കുകയും പരാജയപ്പെട്ട പരിശോധന അത് വീണ്ടും തുറക്കുകയും ചെയ്യുന്നു.
