## ជំហានទី 1៖ ដំឡើង OmniRoute

ជ្រើសរើសវិធីសាស្ត្រដែលអ្នកពេញចិត្ត៖

### ជម្រើស A៖ npm (បានណែនាំ)

```bash
npm install -g omniroute
```

### ជម្រើស B៖ Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` គឺជា SemVer ស្ថិរភាពខ្ពស់បំផុតដែលបាន **ចេញផ្សាយ**។ វា **មិន** តាមដាន git `main` ទេ។ សម្រាប់ GitOps សូមចាក់សោទៅកាន់ `diegosouzapw/omniroute:X.Y.Z`។ សូមមើល [ស្លាក Image / ឆានែលចេញផ្សាយ](../guides/DOCKER_GUIDE.md#release-channels)។

### ជម្រើស C៖ ពីកូដប្រភព

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

## ជំហានទី 2៖ ចាប់ផ្តើម OmniRoute

```bash
omniroute
```

OmniRoute ចាប់ផ្តើមនៅ `http://localhost:20128`។ ផ្ទាំងគ្រប់គ្រងនឹងបើកដោយស្វ័យប្រវត្តិ។

## ជំហានទី 3៖ ភ្ជាប់អ្នកផ្តល់សេវាឥតគិតថ្លៃ

អ្នកអាចប្រើ OmniRoute **ដោយមិនចាំបាច់បង់ប្រាក់អ្វីទាំងអស់** ដោយភ្ជាប់អ្នកផ្តល់សេវាឥតគិតថ្លៃ។

### ជម្រើស A៖ Kiro (Claude ឥតគិតថ្លៃ — មិនត្រូវការកាតឥណទាន)

1. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
2. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
3. ជ្រើសរើស **Kiro AI**
4. ចុច **ភ្ជាប់** (មិនត្រូវការ API key ទេ!)
5. រួចរាល់! ឥឡូវនេះ អ្នកអាចចូលប្រើម៉ូដែល Claude ដោយឥតគិតថ្លៃ។

### ជម្រើស B៖ OpenCode Free (មិនត្រូវការផ្ទៀងផ្ទាត់អត្តសញ្ញាណ)

1. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
2. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
3. ជ្រើសរើស **OpenCode Free**
4. ចុច **ភ្ជាប់** (មិនត្រូវការ API key ទេ!)
5. រួចរាល់! ឥឡូវនេះ អ្នកអាចចូលប្រើម៉ូដែលជាច្រើនដោយឥតគិតថ្លៃ។

### ជម្រើស C៖ Pollinations (មិនត្រូវការ Key)

1. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
2. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
3. ជ្រើសរើស **Pollinations**
4. ចុច **ភ្ជាប់** (មិនត្រូវការ API key ទេ!)
5. រួចរាល់! ឥឡូវនេះ អ្នកអាចចូលប្រើ GPT-5, Claude, Gemini និងម៉ូដែលជាច្រើនទៀតដោយឥតគិតថ្លៃ។

## ជំហានទី 4៖ ផ្ទៀងផ្ទាត់ថាវាដំណើរការ

ពី [API Keys](http://localhost:20128/dashboard/api-manager) សូមបង្កើត key ថ្មីមួយ។ រក្សាទុក key នេះ ព្រោះវានឹងមិនបង្ហាញម្តងទៀតទេ។ សូមចំណាំថា key នេះគឺសម្រាប់ឧបករណ៍នានាចូលប្រើ OmniRoute មិនមែនសម្រាប់ចូលប្រើអ្នកផ្តល់សេវាខាងលើទេ។

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

អ្នកគួរតែឃើញបញ្ជីម៉ូដែលដែលបានភ្ជាប់របស់អ្នក។

## ជំហានទី 5៖ កំណត់ IDE ឬ CLI របស់អ្នកឱ្យប្រើ OmniRoute

នៅក្នុង IDE ឬឧបករណ៍ CLI របស់អ្នក សូមកំណត់៖

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

ប៉ុណ្ណឹងជាការស្រេច! ឥឡូវនេះ IDE របស់អ្នកប្រើ OmniRoute ជាមួយនឹងការជ្រើសរើសអ្នកផ្តល់សេវាដោយស្វ័យប្រវត្តិ។

### ឧទាហរណ៍ IDE៖ VSCode/Continue.dev

1. នៅក្នុង VSCode សូមដំឡើងផ្នែកបន្ថែម [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue)។
2. ធ្វើបច្ចុប្បន្នភាព `~/.continue/config.yaml` របស់អ្នក ដើម្បីបន្ថែមបន្ទាត់ខាងក្រោម៖

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. នៅក្នុងផ្ទាំងជជែក Continue.dev សូមជ្រើសរើស `OmniRoute - Auto` ហើយអ្នកនឹងធ្វើសំណើទៅកាន់ OmniRoute។
4. (ជាជម្រើស) លំហាត់សម្រាប់អ្នកអាន — ឱ្យ IDE របស់អ្នកធ្វើបច្ចុប្បន្នភាព `config.yaml` ជាមួយការកំណត់ដែលបានរៀបចំជាមុនផ្សេងទៀតទាំងអស់ 😊

### ឧទាហរណ៍ CLI៖ Codex CLI

1. នៅក្នុងប្រព័ន្ធប្រតិបត្តិការរបស់អ្នក សូមកំណត់ environment variable ជាអចិន្ត្រៃយ៍។
   សម្រាប់ macOS/Linux (បន្ថែមទៅក្នុង `~/.bashrc` ឬ `~/.zshrc` របស់អ្នក)៖

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

សម្រាប់ Windows (Command Prompt)៖

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. ឥឡូវនេះ ចូរចាប់ផ្តើម Codex ដែលបានកំណត់រចនាសម្ព័ន្ធសម្រាប់ OmniRoute។ ដំណើរការ៖

```
omniroute launch-codex --model auto
```

អ្នកអាចធ្វើវាដោយដៃតាមរយៈ `codex` និងប៉ារ៉ាម៉ែត្របន្ទាត់ពាក្យបញ្ជា ដើម្បីបញ្ជាក់ endpoint និង API key ប៉ុន្តែជាមួយពាក្យបញ្ជាខាងលើ OmniRoute នឹងរៀបចំអ្វីៗគ្រប់យ៉ាងជំនួសអ្នក។

ការចាប់ផ្តើមដោយពាក្យបញ្ជាតែមួយដូចគ្នានេះក៏ដំណើរការសម្រាប់ CLI ផ្សេងទៀតតាមរយៈកម្មវិធីចាប់ផ្តើមទូទៅផងដែរ — `omniroute run <target>` គាំទ្រ `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` និង `gemini` (សូមមើល [ការរួមបញ្ចូល CLI](../guides/CLI-INTEGRATIONS.md))។

3. ឥឡូវនេះ CLI គួរតែកំពុងផ្ញើសំណើទៅកាន់ OmniRoute។

### បញ្ជាក់ថាឧបករណ៍របស់អ្នកកំពុងបញ្ជូនសំណើទៅកាន់ OmniRoute

អ្នកអាចមើលព័ត៌មានលម្អិតនៃសំណើដោយចុច [ការត្រួតពិនិត្យ/កំណត់ហេតុ](http://localhost:20128/dashboard/logs) ពីរបារចំហៀងខាងឆ្វេង។ ការចុចចូលទៅមើលនឹងបង្ហាញព័ត៌មានលម្អិតបន្ថែម។ ជាកំណត់សម្គាល់បន្ថែម អ្នកអាចឃើញថាតើព័ត៌មានអ្វីខ្លះត្រូវបានផ្ញើចេញពី harness ដែលអ្នកពេញចិត្ត។ វាមានប្រយោជន៍សម្រាប់ការសិក្សា និងការបំបាត់កំហុស។

## សំណួរទូទៅ

### "តើខ្ញុំត្រូវការ API key ដែរឬទេ?"

**ទេ!** អ្នកអាចប្រើអ្នកផ្តល់សេវាឥតគិតថ្លៃ (Kiro, OpenCode Free, Pollinations) ដោយមិនត្រូវការ API key ណាមួយ។ គ្រាន់តែភ្ជាប់ពួកវានៅក្នុងផ្ទាំងគ្រប់គ្រង។

### "តើ `auto` ជាអ្វី?"

`auto` ប្រាប់ OmniRoute ឱ្យជ្រើសរើសអ្នកផ្តល់សេវាល្អបំផុតដោយស្វ័យប្រវត្តិសម្រាប់សំណើនីមួយៗ។ វាពិចារណាលើល្បឿន ថ្លៃដើម គុណភាព និងភាពអាចប្រើបាន។ សូមមើល [មគ្គុទ្ទេសក៍ Auto-Combo](./AUTO-COMBO-GUIDE.md) សម្រាប់ព័ត៌មានលម្អិត។

### "តើវាមានតម្លៃប៉ុន្មាន?"

OmniRoute ខ្លួនវាគឺ **ឥតគិតថ្លៃ និងមានកូដប្រភពបើកចំហ**។ អ្នកបង់ប្រាក់តែសម្រាប់អ្នកផ្តល់សេវាដែលអ្នកប្រើប៉ុណ្ណោះ។ អ្នកផ្តល់សេវាជាច្រើនមានកម្រិតប្រើប្រាស់ឥតគិតថ្លៃ — សូមមើល [មគ្គុទ្ទេសក៍កម្រិតប្រើប្រាស់ឥតគិតថ្លៃ](./FREE-TIERS-GUIDE.md)។

### "តើខ្ញុំអាចប្រើវាជាមួយ Claude Code / Cursor / Copilot បានទេ?"

**បាន!** OmniRoute ដំណើរការជាមួយឧបករណ៍ណាមួយដែលគាំទ្រទម្រង់ OpenAI។ គ្រាន់តែកំណត់ base URL ទៅជា `http://localhost:20128/v1`។ សូមមើល [មគ្គុទ្ទេសក៍ឧបករណ៍ CLI](../reference/CLI-TOOLS.md) សម្រាប់សេចក្តីណែនាំអំពីការដំឡើងជាក់លាក់។

### "ចុះបើអ្នកផ្តល់សេវាណាមួយគាំង?"

OmniRoute រំលងអ្នកផ្តល់សេវាដែលបរាជ័យដោយស្វ័យប្រវត្តិ ហើយសាកល្បងអ្នកផ្តល់សេវាបន្ទាប់។ អ្នកមិនចាំបាច់ធ្វើអ្វីទេ។ សូមមើល [មគ្គុទ្ទេសក៍ Auto-Combo](./AUTO-COMBO-GUIDE.md) សម្រាប់ព័ត៌មានលម្អិត។
