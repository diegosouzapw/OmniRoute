## តើអ្នកផ្តល់សេវាគឺជាអ្វី?

សូមគិតថាអ្នកផ្តល់សេវាគឺដូចជា **ក្រុមហ៊ុនសេវាទូរសព្ទ**។ ដូចដែលអ្នកត្រូវការក្រុមហ៊ុនសេវាទូរសព្ទដើម្បីធ្វើការហៅទូរសព្ទ អ្នកក៏ត្រូវការអ្នកផ្តល់សេវា AI ដើម្បីប្រើម៉ូដែល AI ផងដែរ។ OmniRoute គឺដូចជាទូរសព្ទដែលដំណើរការជាមួយ **ក្រុមហ៊ុនសេវាទាំងអស់** — អ្នកអាចប្ដូររវាងពួកវាដោយស្វ័យប្រវត្តិ។

## ចាប់ផ្ដើមរហ័ស៖ តភ្ជាប់អ្នកផ្តល់សេវាដំបូងរបស់អ្នក

### ការដំឡើងអ្នកផ្តល់សេវាឥតគិតថ្លៃនៅពេលដំណើរការលើកដំបូង (ជាជម្រើស)

អ្នកជំនួយការនៅពេលដំណើរការលើកដំបូង ផ្ដល់កាត **ដំឡើងអ្នកផ្តល់សេវាឥតគិតថ្លៃ** យ៉ាងច្បាស់លាស់។ វាទាញយកបញ្ជីដែលមានសិទ្ធិបច្ចុប្បន្ន
ពីបញ្ជីចុះឈ្មោះអ្នកផ្តល់សេវាដែលមិនតម្រូវឱ្យផ្ទៀងផ្ទាត់អត្តសញ្ញាណរបស់ OmniRoute បន្ទាប់មកអនុញ្ញាតឱ្យអ្នកពិនិត្យ និងដកការជ្រើសរើសអ្នកផ្តល់សេវានីមួយៗ
មុនពេលបញ្ជាក់។ OmniRoute បង្ហាញសេចក្ដីជូនដំណឹងឱ្យប្រុងប្រយ័ត្នរបស់អ្នកផ្តល់សេវា និងតំណភ្ជាប់ទៅកាន់គេហទំព័ររបស់វា
ដើម្បីឱ្យអ្នកអាចពិនិត្យលក្ខខណ្ឌ ភាពឯកជន ភាពអាចប្រើបាន និងដែនកំណត់អត្រាប្រើប្រាស់របស់ភាគីទីបីជាមុនសិន។

សកម្មភាពនេះគឺជាជម្រើស៖ ការបញ្ចប់អ្នកជំនួយការនឹងមិនបង្កើតការតភ្ជាប់អ្នកផ្តល់សេវាឥតគិតថ្លៃដោយស្ងាត់ៗឡើយ។
វាបង្កើតតែអ្នកផ្តល់សេវាដែលនៅមិនទាន់មាន រក្សាទុកការតភ្ជាប់ដែលមានស្រាប់ និងត្រូវបានកែសម្រួលតាមបំណង
ដោយមិនប៉ះពាល់ ហើយរាយការណ៍អំពីអ្នកផ្តល់សេវាដែលបានបង្កើត បានកំណត់រចនាសម្ព័ន្ធរួចហើយ និងបានបរាជ័យដោយឡែកពីគ្នា។ អ្នកអាច
ព្យាយាមឡើងវិញដោយសុវត្ថិភាព តែចំពោះអ្នកផ្តល់សេវាដែលបរាជ័យ បន្ទាប់ពីទទួលបានលទ្ធផលដោយផ្នែក។

### ជម្រើស A៖ អ្នកផ្តល់សេវាឥតគិតថ្លៃ (មិនត្រូវការប័ណ្ណឥណទាន)

1. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
2. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
3. ជ្រើសរើសអ្នកផ្តល់សេវាឥតគិតថ្លៃមួយក្នុងចំណោមអ្នកផ្តល់សេវាទាំងនេះ៖
   - **Kiro AI** — ម៉ូដែល Claude ឥតគិតថ្លៃ (មិនត្រូវការការផ្ទៀងផ្ទាត់អត្តសញ្ញាណ)
   - **OpenCode Free** — ម៉ូដែល GPT ឥតគិតថ្លៃ (មិនត្រូវការការផ្ទៀងផ្ទាត់អត្តសញ្ញាណ)
   - **Pollinations** — GPT-5, Claude, Gemini ឥតគិតថ្លៃ (មិនត្រូវការ key)
   - **LongCat** — 10M tokens ឥតគិតថ្លៃ (ផ្ដល់ជូនតែមួយលើក តម្រូវឱ្យមានគណនី + KYC)
   - **Cloudflare AI** — ម៉ូដែលជាង 50, 10K neurons/ថ្ងៃ
   - **MLX Gemma 26B** — ម៉ូដែល Apple Silicon ក្នុងម៉ាស៊ីន (~38.5 tok/s, RAM ~15.9GB)
   - **MLX Qwen 3.8 27B** — ម៉ូដែល Apple Silicon ក្នុងម៉ាស៊ីន (~9.1 tok/s, RAM ~13.1GB)
4. ចុច **តភ្ជាប់**
5. រួចរាល់! ឥឡូវនេះ អ្នកអាចប្រើ AI ដោយឥតគិតថ្លៃបានហើយ។

### ជម្រើស B៖ អ្នកផ្តល់សេវា API Key (បង់ប្រាក់)

1. ទទួលយក API key ពីគេហទំព័ររបស់អ្នកផ្តល់សេវា៖
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
3. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
4. ជ្រើសរើសអ្នកផ្តល់សេវារបស់អ្នក
5. បិទភ្ជាប់ API key របស់អ្នក
6. ចុច **តភ្ជាប់**
7. រួចរាល់! ឥឡូវនេះ អ្នកអាចចូលប្រើម៉ូដែលរបស់អ្នកផ្តល់សេវានោះបានហើយ។

### ជម្រើស C៖ អ្នកផ្តល់សេវា OAuth (ការជាវប្រចាំ)

1. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
2. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
3. ជ្រើសរើសអ្នកផ្តល់សេវារបស់អ្នក (ឧ. Claude Code, GitHub Copilot)
4. ចុច **តភ្ជាប់ជាមួយ OAuth**
5. ចូលដោយប្រើគណនីរបស់អ្នក
6. រួចរាល់! ឥឡូវនេះ អ្នកអាចចូលប្រើម៉ូដែលក្នុងការជាវរបស់អ្នកបានហើយ។

### ជម្រើស D៖ ម៉ូដែល MLX ក្នុងម៉ាស៊ីន (Apple Silicon)

សម្រាប់កុំព្យូទ័រ Mac ដែលប្រើ Apple Silicon និងអង្គចងចាំរួម OmniRoute គាំទ្រការតភ្ជាប់ទៅម៉ូដែល MLX ក្នុងម៉ាស៊ីនដែលដំណើរការតាមរយៈ `mlx-lm.server` ជាអ្នកផ្តល់សេវាក្នុងម៉ាស៊ីនធម្មតាដែលឆបគ្នាជាមួយ OpenAI។

#### តម្រូវការជាមុន

- **Apple Silicon Mac** (M1/M2/M3/M4) ដែលមានអង្គចងចាំរួម 24GB+ ត្រូវបានណែនាំ
- កម្មវិធីគ្រប់គ្រងកញ្ចប់ **uv**៖ `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### ចាប់ផ្ដើមរហ័ស

1. **ដំឡើងភាពអាស្រ័យ**៖

   ```bash
   # ដំឡើង uv ប្រសិនបើមិនទាន់បានដំឡើង
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # ដំឡើង mlx-lm
   uv pip install mlx-lm
   ```

2. **ចាប់ផ្ដើមម៉ាស៊ីនមេ MLX ដោយដៃ** (ក្នុង terminal ដាច់ដោយឡែកពីគ្នា)៖

   ```bash
   # Terminal 1៖ Gemma 4 26B A4B IT-QAT (port 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Terminal 2៖ Qwen 3.8 27B MLX Mixed (port 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **តភ្ជាប់ក្នុងផ្ទាំងគ្រប់គ្រង OmniRoute**៖
   - ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
   - ជ្រើសរើស **MLX Gemma 26B** ឬ **MLX Qwen 3.8 27B**
   - ចុច **តភ្ជាប់** (មិនត្រូវការ API key)

4. **ប្រើជាមួយ OpenCode**៖
   ```bash
   # កំណត់រចនាសម្ព័ន្ធ OpenCode ឱ្យប្រើ OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # ប្រើម៉ូដែល MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### ការគ្រប់គ្រងអង្គចងចាំ

**សំខាន់**៖ ជាមួយនឹងអង្គចងចាំរួម 24GB ម៉ូដែល MLX ធំៗអាចដំណើរការបានតែ **មួយក្នុងពេលតែមួយ** ប៉ុណ្ណោះ។

- Gemma 26B៖ អង្គចងចាំអតិបរមា ~15.9GB
- Qwen 3.8 27B៖ អង្គចងចាំអតិបរមា ~13.1GB

អ្នកត្រូវតែគ្រប់គ្រងវាដោយដៃ៖

- ដំណើរការម៉ាស៊ីនមេ MLX តែមួយប៉ុណ្ណោះក្នុងពេលតែមួយ ឬ
- ដំណើរការទាំងពីរនៅលើម៉ាស៊ីនដាច់ដោយឡែកពីគ្នា ឬ
- បញ្ឈប់មួយ មុនពេលចាប់ផ្ដើមមួយទៀត

OmniRoute មិនគ្រប់គ្រងដំណើរការម៉ាស៊ីនមេ MLX ដោយស្វ័យប្រវត្តិទេ — វាគ្រាន់តែបញ្ជូនសំណើទៅកាន់ endpoint ដែលឆបគ្នាជាមួយ OpenAI ដែលអ្នកបានកំណត់រចនាសម្ព័ន្ធប៉ុណ្ណោះ។

### ជំហានទី 5៖ បញ្ចូលព័ត៌មានសម្គាល់

### ជំហានទី 6៖ សាកល្បងការតភ្ជាប់

## សំណួរទូទៅ

### "តើខ្ញុំត្រូវបង់ប្រាក់ដើម្បីប្រើ OmniRoute ដែរឬទេ?"

**ទេ!** OmniRoute គឺឥតគិតថ្លៃ និងជាប្រភពបើកចំហ។ អ្នកអាចប្រើអ្នកផ្តល់សេវាឥតគិតថ្លៃ (Kiro, OpenCode Free, Pollinations) ដោយមិនចាំបាច់បង់ប្រាក់អ្វីឡើយ។ អ្នកបង់ប្រាក់តែនៅពេលដែលអ្នកជ្រើសរើសប្រើអ្នកផ្តល់សេវាដែលគិតថ្លៃប៉ុណ្ណោះ។

### "តើខ្ញុំគួរចាប់ផ្តើមជាមួយអ្នកផ្តល់សេវាមួយណា?"

ចាប់ផ្តើមជាមួយ **Kiro AI** — វាឥតគិតថ្លៃ មិនតម្រូវឱ្យមាន API key និងផ្តល់សិទ្ធិឱ្យអ្នកប្រើម៉ូដែល Claude។ បន្ទាប់មក បន្ថែមអ្នកផ្តល់សេវាផ្សេងទៀតតាមតម្រូវការ។

### "តើខ្ញុំអាចប្រើអ្នកផ្តល់សេវាច្រើនក្នុងពេលតែមួយបានទេ?"

**បាន!** នោះហើយជាគោលបំណងសំខាន់របស់ OmniRoute។ ភ្ជាប់អ្នកផ្តល់សេវាច្រើន ហើយប្រើ `model: "auto"` ដើម្បីឱ្យ OmniRoute ជ្រើសរើសអ្នកផ្តល់សេវាដែលល្អបំផុតសម្រាប់សំណើនីមួយៗ។

### "ចុះបើអ្នកផ្តល់សេវាមួយឈប់ដំណើរការ?"

OmniRoute រំលងអ្នកផ្តល់សេវាដែលបរាជ័យដោយស្វ័យប្រវត្តិ ហើយសាកល្បងអ្នកផ្តល់សេវាបន្ទាប់។ អ្នកមិនចាំបាច់ធ្វើអ្វីឡើយ។

### "តើខ្ញុំផ្តាច់ការភ្ជាប់អ្នកផ្តល់សេវាដោយរបៀបណា?"

### "តើខ្ញុំអាចប្រើ API key ដែលមានស្រាប់របស់ខ្ញុំបានទេ?"

**បាន!** ប្រសិនបើអ្នកមាន API key សម្រាប់ OpenAI, Anthropic, Google ជាដើមរួចហើយ អ្នកអាចប្រើពួកវានៅក្នុង OmniRoute។ គ្រាន់តែបិទភ្ជាប់ពួកវានៅពេលភ្ជាប់អ្នកផ្តល់សេវា។
