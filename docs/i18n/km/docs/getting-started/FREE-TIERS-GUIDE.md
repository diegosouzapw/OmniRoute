## កម្រិតឥតគិតថ្លៃជាអ្វី?

ក្រុមហ៊ុនផ្តល់សេវា AI ជាច្រើនផ្តល់ជូនទម្រង់មួយចំនួននៃ **ការចូលប្រើដោយឥតគិតថ្លៃ**។ អាស្រ័យលើក្រុមហ៊ុនផ្តល់សេវា វាអាចមានន័យថាជា endpoint ដែលមិនតម្រូវឱ្យមានការផ្ទៀងផ្ទាត់អត្តសញ្ញាណ កូតាដែលកើតឡើងជាថ្មីតាមកាលកំណត់ ការចូលប្រើដោយមិនកំណត់បរិមាណសរុបប៉ុន្តែមានការកំណត់អត្រា ជំនួយឥណទានពេលចុះឈ្មោះ ការអនុម័តដោយដៃ ឬការផ្សព្វផ្សាយបណ្តោះអាសន្ន។ ជម្រើសមួយចំនួនតម្រូវឱ្យមានគណនី API key កាតឥណទាន KYC ឬការយល់ព្រមលើលក្ខខណ្ឌជាក់លាក់របស់ក្រុមហ៊ុនផ្តល់សេវា។

OmniRoute **ប្រមូលផ្តុំ** ការតភ្ជាប់ដែលបានកំណត់រចនាសម្ព័ន្ធទៅក្នុង endpoint តែមួយ។ អ្នកនៅតែត្រូវចុះឈ្មោះដោយឡែកពីគ្នាសម្រាប់ក្រុមហ៊ុនផ្តល់សេវានីមួយៗដែលតម្រូវឱ្យមានគណនី។ ភ្ជាប់គណនីទាំងនោះ ហើយប្រើ `model: "auto"` ដើម្បីបញ្ជូនសំណើក្នុងចំណោមគោលដៅដែលមានសិទ្ធិ។ ការដំឡើងថ្មីអាចមិនមានគោលដៅដែលមិនតម្រូវឱ្យមាន key និងមានសិទ្ធិឡើយ។ ការដំឡើង OmniRoute តែឯងមិនធានាថានឹងទទួលបានការឆ្លើយតបការជជែកដោយជោគជ័យនោះទេ។

- `hasFree` គឺជាទិន្នន័យមេតាសម្រាប់ការស្វែងរក។ វាអាចតំណាងឱ្យកូតាដែលកើតឡើងជាប្រចាំ ការចូលប្រើដោយមិនប្រើសោ
  ឥណទានពេលចុះឈ្មោះ កម្មវិធីអនុម័ត ឬកម្មវិធីប្រូម៉ូសិន។
- `recurring-uncapped` មានន័យថា មិនមានកម្រិតអតិបរមានៃថូខិនដែលបានប្រកាសនោះទេ។ ទោះជាយ៉ាងណា កម្រិតអត្រា និង
  កម្រិតភាពស្របគ្នានៃការប្រើប្រាស់នៅតែត្រូវបានអនុវត្ត។
- `one-time-initial` មិនកើតឡើងម្តងទៀតទេ បន្ទាប់ពីជំនួយពេលចុះឈ្មោះត្រូវបានប្រើអស់។
- អ្នកផ្តល់សេវាដែលមាន `tos: avoid` ត្រូវបានដកចេញពីការកំណត់ផ្លូវដោយស្វ័យប្រវត្តិតាមលំនាំដើម (`excludeTosAvoid`)។ ការភ្ជាប់គណនីមិនរំលងតម្រងនេះទេ។ ការបដិសេធការកំណត់ណាមួយដោយប្រតិបត្តិករ គួរតែធ្វើឡើងបន្ទាប់ពីពិនិត្យលក្ខខណ្ឌរបស់អ្នកផ្តល់សេវា និងហានិភ័យគណនី។
- ធាតុដែលបានសម្គាល់ថា `discontinued` នៅតែជាភស្តុតាងប្រវត្តិសាស្ត្រ ហើយមិនត្រូវបង្ហាញថា
  ឥតគិតថ្លៃនាពេលបច្ចុប្បន្នទេ។

### 2. ការកំណត់ផ្លូវឆ្លាតវៃ

- គុណភាព — តើអ្នកផ្តល់សេវាណាមួយស័ក្តិសមបំផុតសម្រាប់កិច្ចការនេះ?
- សមត្ថភាព — តើអ្នកផ្តល់សេវាណាមួយនៅសល់កូតា?

### 3. ការសន្សំ Token

បំពង់ដំណើរការបង្ហាប់របស់ OmniRoute អាចកាត់បន្ថយ token របស់ prompt និងលទ្ធផលឧបករណ៍ដែលមានសិទ្ធិ។ ចំនួន
សន្សំជាក់ស្តែងអាស្រ័យលើខ្លឹមសារ engine ដែលបានជ្រើសរើស វិធីគណនារបស់អ្នកផ្តល់សេវា និងការកំណត់
កម្រិតរក្សាភាពត្រឹមត្រូវ; ការបង្ហាប់មិនធ្វើឱ្យកូតារបស់អ្នកផ្តល់សេវាទាំងអស់កើនឡើងជាចំនួនដងថេរនោះទេ។

### 4. ការគាំទ្រគណនីច្រើន

ប្រសិនបើលក្ខខណ្ឌរបស់អ្នកផ្តល់សេវាអនុញ្ញាតឱ្យមានគណនី ឬព័ត៌មានសម្គាល់អត្តសញ្ញាណច្រើន OmniRoute អាចចាត់ទុក

## សំណួរទូទៅ

### "តើនេះពិតជាឥតគិតថ្លៃមែនទេ?"

កាតាឡុកកត់ត្រាលក្ខខណ្ឌដែលបានផ្សព្វផ្សាយដោយអ្នកផ្តល់សេវា និងការស្រាវជ្រាវរបស់គម្រោង ប៉ុន្តែការផ្តល់ជូនអាចផ្លាស់ប្តូរបាន។
សូមផ្ទៀងផ្ទាត់តម្លៃ កូតា គោលការណ៍ឯកជនភាព និងលក្ខខណ្ឌសិទ្ធិទទួលបានបច្ចុប្បន្នរបស់អ្នកផ្តល់សេវាមុនពេលប្រើប្រាស់។

### "តើកម្រិតឥតគិតថ្លៃនឹងអស់ដែរឬទេ?"

អ្នកផ្តល់សេវាទាំងអស់អាចកំណត់អត្រាប្រើប្រាស់ ផ្លាស់ប្តូរម៉ូដែល ផ្អាកសិទ្ធិចូលប្រើ ឬឈប់ដំណើរការ។ ការតភ្ជាប់
ច្រើនជួយបង្កើនលទ្ធភាព fallback ប៉ុន្តែមិនធានាថានឹងមាន route ឥតគិតថ្លៃដែលអាចប្រើបានជានិច្ចនោះទេ។

### "តើខ្ញុំអាចប្រើអ្នកផ្តល់សេវាឥតគិតថ្លៃសម្រាប់ production បានទេ?"

បាន លុះត្រាតែ SLA ការគ្រប់គ្រងទិន្នន័យ ដែនកំណត់ និងលក្ខខណ្ឌរបស់អ្នកផ្តល់សេវា បំពេញតាមតម្រូវការ
production របស់អ្នក។ workload សំខាន់ៗគួរតែមាន fallback ដែលត្រូវបានត្រួតពិនិត្យ និងសមស្របតាមកិច្ចសន្យា។

### "តើមានលក្ខខណ្ឌលាក់កំបាំងអ្វីខ្លះ?"

ការដោះដូរអាចរួមមានដែនកំណត់តឹងរ៉ឹង បញ្ជីរង់ចាំ KYC ការផ្ទៀងផ្ទាត់កាតឥណទាន ការប្រើ prompt
សម្រាប់ការបណ្តុះបណ្តាល ភាពឯកជនខ្សោយជាងមុន គ្មាន SLA ការផ្លាស់ប្តូរម៉ូដែលញឹកញាប់ ការរឹតបន្តឹងតាមភូមិសាស្ត្រ ការគិតថ្លៃលើសកូតា ឬ
ហានិភ័យពាក់ព័ន្ធនឹងគោលការណ៍គណនី។ OmniRoute បង្ហាញទិន្នន័យមេតាដែលមាន; អ្នកជាអ្នកជ្រើសរើសថាតើត្រូវបើកប្រើអ្វីខ្លះ។

### "តើខ្ញុំអាចទទួលបានកូតាឥតគិតថ្លៃបន្ថែមដោយរបៀបណា?"

1. តភ្ជាប់អ្នកផ្តល់សេវាឥតគិតថ្លៃបន្ថែម
2. បើកប្រើម៉ាស៊ីនបង្ហាប់ដែលសមស្រប និងវាស់វែងការសន្សំសម្រាប់ workload របស់អ្នក
3. ប្រើ `auto/cheap` ដើម្បីផ្តល់អាទិភាពដល់អ្នកផ្តល់សេវាឥតគិតថ្លៃ/តម្លៃថោក
4. បន្ថែមអ្នកផ្តល់សេវា ឬ credentials ដែលត្រូវបានអនុញ្ញាត ដោយមិនបំពានលក្ខខណ្ឌរបស់អ្នកផ្តល់សេវា

### "តើអ្នកផ្តល់សេវាឥតគិតថ្លៃមានគុណភាពអន់ជាងមែនទេ?"

មិនចាំបាច់ដូច្នោះទេ។ អ្នកផ្តល់សេវាមួយចំនួនផ្តល់ជូនគ្រួសារម៉ូដែលដូចគ្នាដែលមានតាមរយៈ route
បង់ប្រាក់ ប៉ុន្តែដែនកំណត់ រយៈពេលឆ្លើយតប ភាពឯកជន ភាពអាចទុកចិត្តបាន និងកំណែម៉ូដែលអាចខុសគ្នា។ ប្រើទំព័រ
ចំណាត់ថ្នាក់អ្នកផ្តល់សេវាឥតគិតថ្លៃជាសូចនាករគុណភាព ហើយផ្ទៀងផ្ទាត់ម៉ូដែលពិតប្រាកដដែលត្រូវបានផ្តល់ជូន។
