ការបរាជ័យត្រូវបានចាត់ថ្នាក់ មុនពេលធ្វើការសម្រេចចិត្តសាកល្បងឡើងវិញ។

ការបរាជ័យបណ្ដោះអាសន្ន ដូចជា ការអស់ពេលរង់ចាំ កំហុសបណ្ដាញ ការកំណត់អត្រា និងការឆ្លើយតប 5xx របស់អ្នកផ្ដល់សេវា អាចប្ដូរទៅប្រើអ្នកផ្ដល់សេវាផ្សេង។ កំហុសផ្ទៀងផ្ទាត់អត្តសញ្ញាណ កំហុសសិទ្ធិ ការស្នើសុំមិនត្រឹមត្រូវ ម៉ូដែលដែលមិនអាចប្រើបាន និងការបរាជ័យដែលមិនស្គាល់ មិនត្រូវបានសាកល្បងឡើងវិញដោយគ្មានការពិចារណានោះទេ។

គោលការណ៍ឆ្លងអ្នកផ្ដល់សេវាលំនាំដើម អនុញ្ញាតឱ្យសាកល្បងជាមួយអ្នកផ្ដល់សេវាបានរហូតដល់បីដង សាកល្បងឡើងវិញនៅពេលមានការកំណត់អត្រា និងការអស់ពេលរង់ចាំ ហើយរក្សាការបិទដំណើរការផ្នែករដ្ឋបាលឱ្យដាច់ដោយឡែកពីស្ថានភាពសៀគ្វីបណ្ដោះអាសន្ន។

ស្ថានភាពសៀគ្វីមាន `closed`, `open` និង `half_open`។ រយៈពេលសម្រាកកំណត់ពេលសម្រាប់ការសាកល្បងដែលមានដែនកំណត់; ការសាកល្បងដែលជោគជ័យនឹងបិទសៀគ្វី ហើយការសាកល្បងដែលបរាជ័យនឹងបើកវាឡើងវិញ។
