OmniRoute បំបែកទិន្នន័យតេឡេមេទ្រីនៃកូតារបស់អ្នកផ្តល់សេវាចេញពីការគណនារបស់ Ghostlight។

## ស្ថានភាពដែលឆ្លុះបញ្ចាំងការពិត

- `healthy` មានន័យថា ប្រភពមួយបានរាយការណ៍ថា នៅមានសមត្ថភាពដែលអាចប្រើបាន។
- `approaching_limit` មានន័យថា ប្រភពមួយបានរាយការណ៍ថា សមត្ថភាពដែលនៅសល់ស្ថិតនៅកម្រិតទាបជាង ឬស្មើនឹងកម្រិតកំណត់ដែលបានកំណត់រចនាសម្ព័ន្ធ។
- `exhausted` ត្រូវបានបញ្ចេញតែនៅពេលដែលប្រភពមួយរាយការណ៍ថា សមត្ថភាពនៅសល់សូន្យ ឬការប្រើប្រាស់បានដល់កម្រិតកំណត់។
- `unavailable` មានន័យថា ប្រភពដែលគាំទ្រមួយមិនអាចត្រឡប់ទិន្នន័យបាន។
- `unknown` មានន័យថា មិនមានប្រភពដែលគាំទ្រ ឬមិនស្គាល់កម្រិតកំណត់របស់អ្នកផ្តល់សេវា។

ស្ថានភាពមិនស្គាល់មិនមែនមានន័យថាបានប្រើអស់ទេ ហើយវាក៏មិនបិទអ្នកផ្តល់សេវាដែរ។

ប្រភពត្រូវបានផ្តល់អាទិភាពតាមលំដាប់ដូចខាងក្រោម៖ API ផ្លូវការរបស់អ្នកផ្តល់សេវា, API សម្រាប់ការប្រើប្រាស់ដែលបានផ្ទៀងផ្ទាត់អត្តសញ្ញាណ, បឋមកថាឆ្លើយតបដែលបានផ្គូផ្គងយ៉ាងច្បាស់លាស់, ការកំណត់រចនាសម្ព័ន្ធដោយអ្នកគ្រប់គ្រង, ការប៉ាន់ស្មានមូលដ្ឋាន និងស្ថានភាពមិនស្គាល់។ ការប៉ាន់ស្មានមូលដ្ឋានមិនត្រូវបានបង្ហាញជាទិន្នន័យចេញវិក្កយបត្ររបស់អ្នកផ្តល់សេវាឡើយ។

បឋមកថាឆ្លើយតបត្រូវបានញែកតែតាមរយៈការផ្គូផ្គងអ្នកផ្តល់សេវាដែលបានកំណត់យ៉ាងច្បាស់លាស់ប៉ុណ្ណោះ។ ឈ្មោះបឋមកថាទូទៅមិនត្រូវបានសន្មតថាអនុវត្តជាសកលឡើយ។
