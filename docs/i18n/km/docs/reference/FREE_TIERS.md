## តារាងចំណុចត្រូវយកចិត្តទុកដាក់ចំពោះ ToS

> **សញ្ញាសម្គាល់ ToS គឺជាការណែនាំ មិនមែនជាច្រកគ្រប់គ្រងការកំណត់ផ្លូវទេ។** តាមលំនាំដើម អ្នកផ្តល់សេវាដែលបានសម្គាល់ `tos` នៅតែត្រូវបានដាក់បញ្ចូលក្នុងការកំណត់ផ្លូវ និងការរួមបញ្ចូល/ផ្លូវបម្រុង; សញ្ញាសម្គាល់នេះគ្រាន់តែបង្ហាញនៅលើ `/dashboard/free-tiers` និង `/api/free-tier/summary` ប៉ុណ្ណោះ។ ប៉ារ៉ាម៉ែត្រឃ្វីរី `excludeTosAvoid` ប៉ះពាល់តែទិដ្ឋភាពសង្ខេបប៉ុណ្ណោះ មិនមែនការកំណត់ផ្លូវសកលទេ។ សេចក្តីសម្រេចស្ថិតនៅក្នុង `open-sse/config/freeTierCatalog.ts` (សម្រាប់ផ្តល់ព័ត៌មាន មិនត្រូវបានអានដោយម៉ាស៊ីនកំណត់ផ្លូវទេ)។

> នេះជាការអានសង្ខេបអំពីលក្ខខណ្ឌរបស់អ្នកផ្តល់សេវានីមួយៗ សម្រាប់ប្រូកស៊ីផ្ទាល់ខ្លួនដែលរៀបចំបង្ហោះដោយខ្លួនឯង និងប្រើដោយអ្នកប្រើតែម្នាក់។ `caution` = មានប្រការអំពីការប្រើប្រាស់ផ្ទាល់ខ្លួន ឬប្រូកស៊ី ដែលគួរតែពិនិត្យមើល; `ambiguous` = មិនច្បាស់លាស់; `ok` = អនុញ្ញាតយ៉ាងច្បាស់លាស់។ សម្រាប់ផ្តល់ព័ត៌មានប៉ុណ្ណោះ មិនមែនជាដំបូន្មានផ្នែកច្បាប់ទេ — អ្នកជាអ្នកសម្រេចចិត្ត។

### ⚠️ ការប្រុងប្រយ័ត្ន — ប្រការអំពីការប្រើប្រាស់ផ្ទាល់ខ្លួន / ប្រូកស៊ី ដែលគួរតែពិនិត្យមើល (16)
