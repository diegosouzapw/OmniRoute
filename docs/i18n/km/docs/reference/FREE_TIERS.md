## ហេតុអ្វីបានជាចំនួនរបស់យើងតូចជាងចំនួនរបស់កម្មវិធីប្រមូលផ្តុំផ្សេងទៀត

តួលេខ "ថូខិនឥតគិតថ្លៃក្នុងមួយខែ" ភាគច្រើននៅក្នុងវិស័យនេះ គឺជាផលបូកនៃតួលេខដែលដាក់ស្លាកតាមម៉ូដែលនីមួយៗ។ តួលេខរបស់យើងមិនមែនបែបនោះទេ ដោយចេតនា៖

- **ក្រុមកូតារួមនីមួយៗត្រូវបានរាប់តែម្តងប៉ុណ្ណោះ។** គម្រោងឥតគិតថ្លៃរបស់ Mistral ផ្តល់កូតា 1B/ខែ មួយសម្រាប់អង្គការនីមួយៗ; ការរាយវានៅក្រោមម៉ូដែលប្រាំ មិនធ្វើឱ្យវាក្លាយជា 5B ទេ។ បើបូកតាមម៉ូដែលនីមួយៗ កាតាឡុករបស់យើងផ្ទាល់នឹងបង្ហាញ **~7.4B** (បានគណនាឡើងវិញនៅ 2026-09-03; តួលេខនេះមិនត្រូវបានត្រួតពិនិត្យដោយ CI ទេ — សូមវាស់វាឡើងវិញរាល់ពេលដែលកាតាឡុកផ្លាស់ប្តូរ) — ចំណងជើងបង្ហាញ **~1.47B** ពីព្រោះនោះជាចំនួនដែលគណនីមួយរបស់អ្នកផ្តល់សេវានីមួយៗពិតជាអាចប្រើបាន។

## តារាងកំណត់សម្គាល់ ToS

> **ទង់ ToS គ្រាន់តែជាការណែនាំ មិនមែនជាច្រកកំណត់ការបញ្ជូនទេ។** ក្រុមហ៊ុនផ្តល់សេវាដែលត្រូវបានសម្គាល់ `tos` នៅតែត្រូវបានរួមបញ្ចូលក្នុងការបញ្ជូន និង combo/fallback តាមលំនាំដើម។ ទង់នេះគ្រាន់តែបង្ហាញនៅលើ `/dashboard/free-tiers` និង `/api/free-tier/summary` ប៉ុណ្ណោះ។ ប៉ារ៉ាម៉ែត្រសំណួរ `excludeTosAvoid` ប៉ះពាល់តែទិដ្ឋភាពសង្ខេបប៉ុណ្ណោះ មិនមែនការបញ្ជូនជាសកលទេ។ ការវិនិច្ឆ័យស្ថិតនៅក្នុង `open-sse/config/freeTierCatalog.ts` (សម្រាប់ជាព័ត៌មាន មិនត្រូវបានអានដោយម៉ាស៊ីនបញ្ជូនទេ)។

> ការអានដោយសង្ខេបអំពីលក្ខខណ្ឌរបស់ក្រុមហ៊ុនផ្តល់សេវានីមួយៗ សម្រាប់ប្រូកស៊ីផ្ទាល់ខ្លួនដែលបង្ហោះដោយខ្លួនឯង និងប្រើដោយអ្នកប្រើតែម្នាក់។ `caution` = មានខលក្ខខណ្ឌអំពីការប្រើប្រាស់ផ្ទាល់ខ្លួន ឬប្រូកស៊ីដែលគួរតែពិនិត្យមើល; `ambiguous` = មិនច្បាស់លាស់; `ok` = អនុញ្ញាតយ៉ាងច្បាស់លាស់។ នេះជាព័ត៌មានប៉ុណ្ណោះ មិនមែនជាដំបូន្មានផ្នែកច្បាប់ទេ — អ្នកជាអ្នកសម្រេចចិត្ត។

### ⚠️ ប្រយ័ត្ន — ខលក្ខខណ្ឌអំពីការប្រើប្រាស់ផ្ទាល់ខ្លួន / ប្រូកស៊ីដែលគួរតែពិនិត្យមើល (16)
