OmniRoute ផ្តល់ជូនបណ្តុំប្រូកស៊ីឥតគិតថ្លៃដែលបានជ្រើសរើសនៅក្នុងតារាង `free_proxies`
ហើយធ្វើសមកាលកម្មពីអ្នកផ្តល់សេវាខាងក្រៅ (1proxy, proxifly, iplocate, webshare)។ ផ្ទាំងគ្រប់គ្រង
បង្ហាញប្រូកស៊ីទាំងនេះនៅក្រោម **Settings → Free Proxies**។ ឯកសារនេះ
ពិពណ៌នាអំពីការត្រង ការតម្រៀប ការរាប់ និងការរាយការណ៍កំហុសសមកាលកម្មនៅផ្នែកម៉ាស៊ីនមេ
ដែល route សម្រាប់បញ្ជីផ្តល់ជូន។

## Route សម្រាប់បញ្ជី — `GET /api/settings/free-proxies`

ត្រឡប់ផ្នែកមួយដែលបានត្រង តម្រៀប និងបែងចែកជាទំព័រ ព្រមទាំងចំនួនសរុប។ ការត្រង និង
ការរាប់ត្រូវបានធ្វើឡើងក្នុង SQL ដូច្នេះ UI អាចបង្ហាញចំនួនសរុបពិតប្រាកដ (ឧ. `Total: 0`)
ដោយមិនចាំបាច់ផ្ទុកគ្រប់ជួរទិន្នន័យទៅក្នុងអង្គចងចាំ។

### ប៉ារ៉ាម៉ែត្រសំណើ

| ប៉ារ៉ាម៉ែត្រ      | ប្រភេទ                             | លំនាំដើម  | អត្ថន័យ                                                                                                                            |
| ----------------- | ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`      | `LIKE` ដែលប្រកាន់អក្សរធំតូចលើជួរឈរ host (និង source)។                                                                              |
| `protocol`        | string                             | `""`      | តម្រង `type`: `http` / `https` / `socks4` / `socks5`។ ទទេ = ទាំងអស់។                                                               |
| `country`         | string                             | `""`      | តម្រង `countryCode` (ISO-2)។ ទទេ = ទាំងអស់។                                                                                        |
| `minQuality`      | number                             | `0`       | យកតែជួរទិន្នន័យដែលមាន `qualityScore >= minQuality`។ `0` = គ្មានកម្រិតអប្បបរមា។                                                     |
| `disabledSources` | string                             | `""`      | លេខសម្គាល់ source ដែលបំបែកដោយសញ្ញាក្បៀស ដើម្បីដកចេញ (ឧ. `proxifly,webshare`)។                                                      |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = ពិន្ទុតាមលំដាប់ចុះ; `latency` = latency តាមលំដាប់ឡើង (តម្លៃ null នៅចុងក្រោយ); `recent` = `lastValidated` តាមលំដាប់ចុះ។ |
| `offset`          | number                             | `0`       | ចំណុចចាប់ផ្តើមនៃការបែងចែកជាទំព័រ។                                                                                                  |
| `limit`           | number                             | `50`      | ទំហំទំព័រ (ត្រូវបានកំណត់កម្រិតនៅផ្នែកម៉ាស៊ីនមេ)។                                                                                   |

### ការឆ្លើយតប

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` បង្ហាញចំនួនសរុបដែលបានត្រង **មុនពេល** បែងចែកជាទំព័រ ដូច្នេះ UI អាចបង្ហាញ
`Total: N` និង `hasMore` ដាច់ដោយឡែកពីគ្នា។ `syncErrors` ប្រើលេខសម្គាល់ source ជា key ហើយ
ត្រូវបានបំពេញតែសម្រាប់ source ដែលបានបរាជ័យក្នុងការធ្វើសមកាលកម្មចុងក្រោយប៉ុណ្ណោះ — លទ្ធផល `Total: 0`
មិនត្រូវបានទុកដោយគ្មានការជូនដំណឹងឡើយ។

## បន្ថែមទៅក្នុង pool — `POST /api/settings/free-proxies/[id]/add-to-pool`

ដំឡើងប្រូកស៊ីឥតគិតថ្លៃមួយទៅក្នុង pool `proxy_registry` ដែលបានគ្រប់គ្រង។ ផ្ទៀងផ្ទាត់
upstream ជាមុនសិន; នៅពេលជោគជ័យ វាត្រឡប់លេខសម្គាល់ប្រូកស៊ីថ្មីក្នុង pool និង latency ដែលបានវាស់។

## សមកាលកម្ម — `POST /api/settings/free-proxies/sync`

ទាញយក source ដែលបានបើកទាំងអស់ឡើងវិញ (ឬសំណុំរងនៅក្នុង `{ "sources": [...] }`)។ source នីមួយៗ
ធ្វើសមកាលកម្មដោយឯករាជ្យ; source ដែលបរាជ័យត្រូវបានកត់ត្រាក្នុង `syncErrors` ហើយ
source ផ្សេងទៀតនៅតែបញ្ចប់ ដូច្នេះការធ្វើសមកាលកម្មដោយផ្នែកមិនលុបទិន្នន័យល្អពីមុនឡើយ។

## ស្ថិតិ — `GET /api/settings/free-proxies/stats`

ត្រឡប់ទិន្នន័យសរុប `total / inPool / avgQuality / bySource / lastSyncAt`
ដោយមិនរួមបញ្ចូល payload នៃជួរទិន្នន័យ — ប្រើដោយ widget បឋមកថានៃផ្ទាំងគ្រប់គ្រង។
