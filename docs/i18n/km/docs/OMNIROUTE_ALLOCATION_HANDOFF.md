ការបែងចែកមិនមែនជាកូតារបស់អ្នកផ្តល់សេវាទេ។

ក្រុមកូតាកំណត់ថា API keys ណាខ្លះអាចប្រើប្រាស់ក្រុមធនធានរបស់អ្នកផ្តល់សេវា និងរបៀបអនុវត្តគោលការណ៍កម្រិតរឹង កម្រិតទន់ ឬការប្រើប្រាស់កើនឡើងភ្លាមៗ។ កូតារបស់អ្នកផ្តល់សេវាគឺជាសមត្ថភាពខាងក្រៅដែលរាយការណ៍ដោយអ្នកផ្តល់សេវា ឬដោយប្រភពដែលបានកំណត់រចនាសម្ព័ន្ធយ៉ាងច្បាស់។ ថវិកាផ្ទៃក្នុងរបស់ Ghostlight គឺជាដែនកំណត់អភិបាលកិច្ចដែលកំណត់ដោយអ្នកគ្រប់គ្រង។

ប្រតិបត្តិការ `ensurePool` មានលក្ខណៈ idempotent៖ ក្រុមដែលដូចគ្នាបេះបិទនឹងមិនផ្លាស់ប្តូរ ការបែងចែកដែលបានផ្លាស់ប្តូរនឹងត្រូវបានធ្វើបច្ចុប្បន្នភាព ហើយក្រុមដែលមិនទាន់មាននឹងត្រូវបានបង្កើត។ វាត្រូវបានរៀបចំឡើងសម្រាប់ស្វ័យប្រវត្តិកម្ម និងកម្មវិធីហៅ API ដែលមានដែនកំណត់។

ចំណុចបញ្ចប់ស្ថានភាពដែលអាចអានបានតែប៉ុណ្ណោះគឺ `GET /api/omniroute/status`។ ពាក្យបញ្ជាផ្ទៀងផ្ទាត់គឺ `npm run omniroute:verify` ហើយវាមិនធ្វើសំណើទៅកាន់ម៉ូដែលជាក់ស្តែងទេ។
