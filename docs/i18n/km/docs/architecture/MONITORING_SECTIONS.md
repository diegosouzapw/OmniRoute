## ផ្នែកការត្រួតពិនិត្យ (បានរៀបចំឡើងវិញ)

ឥឡូវនេះ ផ្នែកការត្រួតពិនិត្យមាន **សកម្មភាពនៅខាងលើ** ហើយបន្ទាប់មកមាន **ក្រុមរង 3**៖

```
ការត្រួតពិនិត្យ
├── សកម្មភាព             ← មតិព័ត៌មានតាមបន្ទាត់ពេលវេលា (ធាតុកម្រិតខ្ពស់)
├── ក្រុមកំណត់ហេតុ
│   ├── កំណត់ហេតុ (ទាំងអស់)
│   ├── កំណត់ហេតុប្រូកស៊ី
│   └── កំណត់ហេតុកុងសូល
├── ក្រុមសវនកម្ម
│   ├── កំណត់ហេតុសវនកម្ម
│   ├── សវនកម្ម MCP
│   └── សវនកម្ម A2A
└── ក្រុមប្រព័ន្ធ
    ├── ស្ថានភាព
    └── ពេលដំណើរការ
```

### អ្វីដែលបានផ្លាស់ប្តូរពីរចនាសម្ព័ន្ធចាស់

| មុន                                                                                        | ក្រោយ                                                   |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| សកម្មភាព = ផ្ទាំងនៅក្នុងកំណត់ហេតុ ដែលបង្ហាញកំណត់ហេតុសវនកម្ម                                | សកម្មភាព = មតិព័ត៌មានដាច់ដោយឡែក (`/dashboard/activity`) |
| ក្រុមប៉ារ៉ាម៉ែត្រការចំណាយនៅក្នុងការត្រួតពិនិត្យ                                            | បានផ្លាស់ទីទៅផ្នែកការចំណាយ                              |
| បញ្ជីរាបស្មើ៖ កំណត់ហេតុ សកម្មភាព (កំណត់ហេតុ) សវនកម្ម ស្ថានភាព ពេលដំណើរការ តម្លៃ ថវិកា កូតា | រចនាសម្ព័ន្ធជា 3 ក្រុម + ផ្នែកការចំណាយដាច់ដោយឡែក        |

## សកម្មភាព ធៀបនឹងកំណត់ហេតុសវនកម្ម

| វិមាត្រ                    | សកម្មភាព (`/dashboard/activity`)                                 | កំណត់ហេតុសវនកម្ម (`/dashboard/audit`)                  |
| -------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------ |
| **គោលបំណង**                | មតិព័ត៌មានព្រឹត្តិការណ៍សម្រាប់អ្នកប្រើ ("ថ្មីៗនេះមានអ្វីកើតឡើង") | កំណត់ហេតុអនុលោមភាព / សុវត្ថិភាព                        |
| **ប្រភពទិន្នន័យ**          | `GET /api/compliance/audit-log?level=high`                       | `GET /api/compliance/audit-log?level=all`              |
| **ទម្រង់**                 | បន្ទាត់ពេលវេលា ដាក់ជាក្រុមតាមថ្ងៃ កិរិយាសព្ទដែលងាយយល់ + រូបតំណាង | តារាងបង្រួមដែលបែងចែកជាទំព័រ 50/ទំព័រ                   |
| **តម្រង**                  | ប្រភេទព្រឹត្តិការណ៍                                              | សកម្មភាព កម្រិតធ្ងន់ធ្ងរ អ្នកអនុវត្ត ចន្លោះកាលបរិច្ឆេទ |
| **ការនាំចេញ**              | មិនមាន                                                           | ការនាំចេញ JSON                                         |
| **តម្រងអ្នកអនុវត្ត**       | មិនអនុវត្ត                                                       | អាចត្រងតាមអ្នកអនុវត្តបាន                               |
| **ព្រឹត្តិការណ៍ដែលបង្ហាញ** | សកម្មភាពកម្រិតខ្ពស់តែប៉ុណ្ណោះ (បញ្ជីអនុញ្ញាត)                    | ព្រឹត្តិការណ៍សវនកម្មទាំងអស់                            |

### បញ្ជីអនុញ្ញាតសកម្មភាពកម្រិតខ្ពស់

ត្រូវបានកំណត់ក្នុង `src/lib/audit/highLevelActions.ts`។ វាគ្រប់គ្រងថាតើព្រឹត្តិការណ៍ណាខ្លះបង្ហាញក្នុង
មតិព័ត៌មានសកម្មភាព។ បញ្ជីអនុញ្ញាតរួមមាន៖

- ព្រឹត្តិការណ៍បន្ថែម/ដកចេញ/សាកល្បងអ្នកផ្តល់សេវា
- ការបង្កើត/ធ្វើបច្ចុប្បន្នភាព/លុបបន្សំ
- វដ្តជីវិតសោ API (បង្កើត ដកហូត ប្តូរថ្មី)
- ការឈានដល់កម្រិតកំណត់ថវិកា
- ការចូល/ចេញពីប្រព័ន្ធផ្ទៀងផ្ទាត់អត្តសញ្ញាណ
- ការបង្កើតសម័យភ្នាក់ងារ Cloud
- ការចុះឈ្មោះឧបករណ៍ MCP
- ការបង្កើត/លុប Webhook
- ការផ្លាស់ប្តូរក្រុម/ផែនការកូតា (សកម្មភាព `quota.*`, Group B)
- ព្រឹត្តិការណ៍វេទិកា (ធ្វើបច្ចុប្បន្នភាព ដាក់ពង្រាយ)
- ដំឡើង/ដកជំនាញចេញ

ព្រឹត្តិការណ៍ដែលមិនស្ថិតក្នុងបញ្ជីនេះ បង្ហាញតែនៅក្នុងកំណត់ហេតុសវនកម្មប៉ុណ្ណោះ។
