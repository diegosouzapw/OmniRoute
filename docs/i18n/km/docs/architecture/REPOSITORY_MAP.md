- **`_ideia/`** — កំណត់ចំណាំរចនា (ប្រភេទ defer / notfit / viable)
- **`_mono_repo/`** — គម្រោងរងប្រវត្តិសាស្ត្រ (omnirouteCloud, omnirouteSite, vscode-extension)
- **`_references/`** — clone សម្រាប់តែអាននៃគម្រោង OSS ដែលពាក់ព័ន្ធ (LiteLLM, 9router, ClawRouter, CLIProxyAPI, modelrelay, new-api, ជាដើម) សម្រាប់យោងឆ្លងកាត់អំឡុងពេលអភិវឌ្ឍ
- **`_tasks/`** — ឯកសារតាមដាន task សម្រាប់ release នីមួយៗ (មិនផ្លូវការ)

មិនត្រូវបានរួមបញ្ចូលក្នុងលទ្ធផល `npm pack` ទេ។ សូមមើល `.npmignore`។

## បានបង្កើត / មិនត្រូវបានតាមដានដោយ Git

| ផ្លូវ                  | គោលបំណង                                  |
| ---------------------- | ---------------------------------------- |
| `node_modules/`        | ភាពអាស្រ័យរបស់ npm                       |
| `.next/`               | លទ្ធផលនៃការ build របស់ Next.js           |
| `coverage/`            | របាយការណ៍ coverage របស់ c8               |
| `logs/`                | កំណត់ហេតុពេលដំណើរការ                     |
| `package/`             | ទីតាំងរៀបចំបណ្ដោះអាសន្នសម្រាប់ npm pack  |
| `.playwright-mcp/`     | វត្ថុបង្កើតពីការធ្វើតេស្ត Playwright MCP |
| `.issues/`             | ឃ្លាំងសម្ងាត់ issue ក្នុងម៉ាស៊ីន         |
| `tsconfig.tsbuildinfo` | ឃ្លាំងសម្ងាត់ incremental របស់ TS        |
