## 1. Antigravity ប្រៀបធៀបនឹង Antigravity CLI (agy)

អ្នកផ្តល់សេវាទាំងពីរប្រើប្រាស់ **ប្រព័ន្ធខាងក្រោយ Google ដូចគ្នា** — OAuth client, ការធ្វើឱ្យ token ស្រស់ឡើងវិញ, endpoints និងគណនី Google គឺដូចគ្នាទាំងអស់។ ភាពខុសគ្នាគឺម៉ូដែលដែលអ្នកអាចមើលឃើញ។

> សូមមើល [សេចក្តីប្រកាសអំពី Antigravity CLI](https://antigravity.google/blog/introducing-google-antigravity-cli) សម្រាប់ការប្រៀបធៀបផ្លូវការរបស់ Google។

**មូលហេតុដែលកាតាឡុកម៉ូដែលខុសគ្នា**៖ CLI របស់ Google ត្រូវបាន "បង្កើនប្រសិទ្ធភាពសម្រាប់ល្បឿន និងការប្រើធនធានតិច" និង "បង្កើនប្រសិទ្ធភាពរួមគ្នាជាមួយម៉ូដែល Gemini" (យោងតាមប្លុកផ្លូវការរបស់ Google)។ ផលិតផល Web/IDE ត្រូវបាន "បង្កើនប្រសិទ្ធភាពសម្រាប់ភាពទូលំទូលាយ"។ CLI ប្រើ `:fetchAvailableModels` ដើម្បីស្វែងរកម៉ូដែលដោយថាមវន្ត ខណៈដែល IDE ប្រើបញ្ជីដែលបានជ្រើសរើសថេរ។

**ក្នុងការអនុវត្តជាក់ស្តែង**៖ ប្រើបុព្វបទ `agy/` សម្រាប់ម៉ូដែល Gemini (ឧ. `agy/gemini-3.7-flash-high`)។ ប្រើ `antigravity/` សម្រាប់បញ្ជីដែលបានជ្រើសរើសថេរ។ ទាំងពីរភ្ជាប់ទៅប្រព័ន្ធខាងក្រោយ Google ដូចគ្នា ប៉ុន្តែបង្ហាញការដាក់ឈ្មោះម៉ូដែលខុសគ្នា។ កូតាត្រូវបានចែករំលែក — ការប្រើអ្នកផ្តល់សេវាណាមួយនឹងត្រូវរាប់បញ្ចូលក្នុងដែនកំណត់របស់គណនី Google ដូចគ្នា។

## 3. របៀបទទួលបាន projectId

2. ហៅ `loadCodeAssist` ដើម្បីស្វែងរក projectId

## 4. URI បញ្ជូនបន្ត OAuth

### បញ្ហា

Google OAuth តម្រូវឱ្យមាន URI បញ្ជូនបន្តត្រឹមត្រូវ។ តាមលំនាំដើម OmniRoute ប្រើ `http://127.0.0.1:20128/callback` (loopback)។ វាដំណើរការសម្រាប់ build ក្នុងម៉ាស៊ីនមូលដ្ឋាន ប៉ុន្តែ **មិនដំណើរការសម្រាប់ការដាក់ឱ្យប្រើប្រាស់ពីចម្ងាយ** (ឧទាហរណ៍ ម៉ាស៊ីនមេដែលចូលប្រើតាមរយៈ IP របស់ LAN)។

Google បដិសេធ URI បញ្ជូនបន្តដែល៖

- ប្រើអាសយដ្ឋាន IP (ត្រូវតែជាដូមែនដែលបញ្ចប់ដោយ `.com`, `.org` ជាដើម)
- មិនត្រូវគ្នានឹង URI បញ្ជូនបន្តដែលបានចុះឈ្មោះក្នុងការកំណត់រចនាសម្ព័ន្ធ OAuth client

### ដំណោះស្រាយ

**ជម្រើស A៖ ប្រើដំណើរការ OAuth ដែលមានស្រាប់ (លំនាំដើម)**

- ដំណើរការនៅពេលអ្នកចូលប្រើ OmniRoute ពី `localhost` ឬ `127.0.0.1`
- មិនត្រូវការការកំណត់រចនាសម្ព័ន្ធទេ

**ជម្រើស B៖ ព័ត៌មានសម្គាល់អត្តសញ្ញាណ OAuth ផ្ទាល់ខ្លួន**

- កំណត់ `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` ក្នុង environment របស់អ្នក
- ផ្តល់ព័ត៌មានសម្គាល់អត្តសញ្ញាណ Google OAuth ផ្ទាល់ខ្លួនរបស់អ្នក៖
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- ចុះឈ្មោះ `https://your-domain.com/callback` ជា URI បញ្ជូនបន្តដែលបានអនុញ្ញាតនៅក្នុង Google Cloud Console

**ជម្រើស C៖ ប្រើ agy CLI សម្រាប់ការចូលដំបូង**

- ដំណើរការ `agy login` នៅលើម៉ាស៊ីនដែលនឹងចូលប្រើ OmniRoute
- ដំណើរការ OAuth នឹងបញ្ចប់ក្នុងម៉ាស៊ីនមូលដ្ឋាន ហើយ token នឹងត្រូវបានរក្សាទុក
- នាំចូលការតភ្ជាប់ទៅក្នុង OmniRoute តាមរយៈ Dashboard

### ដែនកំណត់

- ព័ត៌មានសម្គាល់អត្តសញ្ញាណ OAuth ផ្ទាល់ខ្លួនតម្រូវឱ្យមានឈ្មោះដូមែន (Google មិនទទួលយកអាសយដ្ឋាន IP ជា URI បញ្ជូនបន្តទេ)
- ប្រសិនបើអ្នកមិនមានដូមែនទេ សូមប្រើជម្រើស A ឬ C ជំនួសវិញ

## 5. ការដោះស្រាយបញ្ហា៖ នៅពេលការដំឡើងស្វ័យប្រវត្តិបរាជ័យ

### តំបន់របស់គណនីត្រូវបានរារាំង

**រោគសញ្ញា**៖ `agy login` បង្ហាញសារ "Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location."

**មូលហេតុដើម**៖ គណនី Google មានវាល backend មួយឈ្មោះ "Country Association" ដែលត្រូវបានកំណត់នៅពេលចុះឈ្មោះ។ agy CLI និង Cloud Code API ពិនិត្យវាលនេះយ៉ាងតឹងរ៉ឹង — មិនដូច Gemini លើ web ដែលពិនិត្យតែ IP បច្ចុប្បន្នរបស់អ្នកប៉ុណ្ណោះ។

> ដើម្បីពិនិត្យ ឬផ្លាស់ប្តូរតំបន់ដែលភ្ជាប់ជាមួយគណនីរបស់អ្នក សូមចូលទៅកាន់ [ទម្រង់ Google Country Association](https://policies.google.com/country-association-form)។

**ហេតុអ្វីបានជា Gemini លើ web ដំណើរការ ប៉ុន្តែ agy មិនដំណើរការ**៖

- Gemini លើ web / Google One៖ ពិនិត្យតែ IP បច្ចុប្បន្នប៉ុណ្ណោះ (proxy អាចឆ្លងកាត់បាន)
- agy CLI / Cloud Code API៖ អានវាល Country Association របស់ backend (proxy មិនអាចជួយបានទេ)

**ដំណោះស្រាយ**៖

1. ចូលទៅកាន់ [ទម្រង់ Google Country Association](https://policies.google.com/country-association-form) ខណៈពេលកំពុងប្រើ IP របស់សហរដ្ឋអាមេរិក
2. ដាក់សំណើផ្លាស់ប្តូរតំបន់ (ជ្រើសរើស "I live in a different country")
3. រង់ចាំ 1-24 ម៉ោង ដើម្បីឱ្យ Google ដំណើរការសំណើ + ផ្ញើការជូនដំណឹងតាមអ៊ីមែល
4. បន្ទាប់មក `agy login` គួរតែដំណើរការដោយជោគជ័យ

### គណនីមិនមាន project របស់ Cloud Code

**រោគសញ្ញា**៖ កំណត់ហេតុបង្ហាញ `loadCodeAssist returned no project id` និង `onboardUser failed (400)`។

**មូលហេតុដើម**៖ គណនីនេះមិនធ្លាប់បានចុះឈ្មោះជាមួយ Google Cloud Code ទេ ហើយការចុះឈ្មោះដំបូងដោយស្វ័យប្រវត្តិបានបរាជ័យ។

**ដំណោះស្រាយ**៖ ដំណើរការ `agy login` ដោយដៃ ដើម្បីចាប់ផ្តើមការចុះឈ្មោះ Cloud Code បន្ទាប់មកធ្វើឱ្យ token ស្រស់ឡើងវិញនៅក្នុង OmniRoute Dashboard។

### Token ផុតកំណត់ ឬត្រូវបានដកហូត

**រោគសញ្ញា**៖ កំហុស 401 នៅក្នុងកំណត់ហេតុ ឬសារ "Token has expired"។

**ដំណោះស្រាយ**៖ ធ្វើឱ្យ token ស្រស់ឡើងវិញនៅក្នុង Dashboard → Providers → agy → ចុចរូបតំណាង refresh។ ប្រសិនបើ refresh token ត្រូវបានដកហូត អ្នកនឹងត្រូវផ្ទៀងផ្ទាត់អត្តសញ្ញាណឡើងវិញតាមរយៈ OAuth។
