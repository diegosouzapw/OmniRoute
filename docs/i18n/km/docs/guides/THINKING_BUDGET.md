> **API:** `GET` / `PUT` `/api/settings/thinking-budget`

ថវិកាការគិតកំណត់ថាតើ OmniRoute **សរសេរឡើងវិញនូវប៉ារ៉ាម៉ែត្រការគិត/ការវែកញែករបស់ម៉ាស៊ីនភ្ញៀវ** នៅពេលបញ្ជូនទៅកាន់អ្នកផ្តល់សេវាឬអត់។ វា **មិន** បើក ឬបិទការបង្ហាប់ ការកំណត់ផ្លូវ ឬឃ្លាំងសម្ងាត់ប្រអប់បញ្ចូលនោះទេ។

### អ្វីដែល `auto` ដកចេញ

នៅពេលរបៀបជា `auto` នោះ `stripThinkingConfig()` នឹងលុបវាលខាងក្រោម (ក្នុងចំណោមវាលផ្សេងទៀត)៖

- OpenAI / Responses: `reasoning`, `reasoning_effort`
- Claude: `thinking` និង `output_config.effort` នៅពេលមាន
- Gemini: `generationConfig.thinking_config` / `thinkingConfig`

ប្រសិនបើម៉ាស៊ីនភ្ញៀវមួយ (ឧ. Codex Desktop) បានផ្ញើ `reasoning: { effort: "ultra", summary: "detailed" }` នោះ **auto នឹងទម្លាក់វត្ថុនោះចោល**។ ប្រភពខាងលើអាចនៅតែគិតថ្លៃថូខឹនវែកញែកមួយចំនួន ប៉ុន្តែជាញឹកញាប់វាត្រឡប់ធាតុវែកញែកដែល **ទទេ ឬមានតែទិន្នន័យដែលបានអ៊ិនគ្រីប** — ដូច្នេះ UI មិនបង្ហាញស្ទ្រីមការគិតដែលមានប្រយោជន៍ទេ។

## ការបង្ហាញការគិត (កម្មវិធីភ្ញៀវ Codex / Responses)

ដើម្បីឱ្យកម្មវិធីភ្ញៀវបង្ហាញអត្ថបទនៃការគិត អ្នកត្រូវមាន **ទាំងអស់** ដូចខាងក្រោម៖

1. របៀប Thinking Budget = **`passthrough`** (ឬ custom/adaptive ដែលនៅតែរក្សាសំណើសុំសេចក្តីសង្ខេបឱ្យនៅដដែលគ្រប់គ្រាន់សម្រាប់ផ្លូវដែលអ្នកប្រើ)។
2. កម្មវិធីភ្ញៀវស្នើសុំសេចក្តីសង្ខេប ឧ. Codex `model_reasoning_summary = "detailed"` / `auto` (មិនមែន `none`)។
3. ប្រភពខាងលើពិតជាស្ទ្រីម `response.reasoning_summary_text.*` (ឬមាន `reasoning.summary` ដែលមិនទទេនៅលើធាតុនោះ)។

ប្រសិនបើអ្នកទទួលបានតែ “ការគិតឯកជនដែលបានអ៊ិនគ្រីប” នោះអាចដោយសារ៖

- របៀបគឺ **`auto`** (សំណើរបស់កម្មវិធីភ្ញៀវត្រូវបានដកចេញ) ឬ
- ប្រភពខាងលើបានត្រឡប់ `encrypted_content` ដោយគ្មានអត្ថបទសេចក្តីសង្ខេប (ដែនកំណត់របស់អ្នកផ្តល់សេវា; OmniRoute អាចបង្ហាញបានតែអត្ថបទជំនួសប៉ុណ្ណោះ មិនមែនអត្ថបទធម្មតាទេ)។

## ឧទាហរណ៍ API

```bash
# អាន
curl -sS https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN"

# បានណែនាំសម្រាប់ការបង្ហាញការគិតក្នុង Codex / Desktop
curl -sS -X PUT https://localhost:20128/api/settings/thinking-budget \
  -H "Authorization: Bearer $OMNIROUTE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"passthrough","customBudget":10240,"effortLevel":"medium"}'
```

គ្រោងទិន្នន័យ (`updateThinkingBudgetSchema`)៖ `mode` ∈ `passthrough|auto|custom|adaptive`; `customBudget`, `effortLevel`, `baseBudget`, `complexityMultiplier` ជាជម្រើស។

### ការរក្សាទុក / ការចាប់ផ្តើមឡើងវិញ

តម្លៃត្រូវបានរក្សាទុកក្រោមសោការកំណត់ `thinkingBudget` និងផ្ទុកចូលនៅពេលដំណើរការចាប់ផ្តើម (`hydrateThinkingBudgetConfig`)។ បន្ទាប់ពីផ្លាស់ប្តូរតាមរយៈ DB ឬផ្លូវមួយចំនួនដែលមិនមែនជា API សូម **ចាប់ផ្តើមដំណើរការ OmniRoute ឡើងវិញ** ដើម្បីឱ្យ singleton ក្នុងអង្គចងចាំត្រូវគ្នានឹងទិន្នន័យលើថាស។
