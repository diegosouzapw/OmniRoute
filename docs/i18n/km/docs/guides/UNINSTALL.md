## ការលុបការដំឡើងរហ័ស (v3.6.2+)

OmniRoute ផ្តល់ស្គ្រីបភ្ជាប់មកជាមួយចំនួនពីរសម្រាប់ការលុបចេញដោយស្អាត៖

### រក្សាទិន្នន័យរបស់អ្នក

```bash
npm run uninstall
```

វាលុបកម្មវិធី OmniRoute ប៉ុន្តែ **រក្សាទុក** មូលដ្ឋានទិន្នន័យ ការកំណត់រចនាសម្ព័ន្ធ API keys និងការកំណត់របស់អ្នកផ្តល់សេវា នៅក្នុង `~/.omniroute/`។ ប្រើជម្រើសនេះ ប្រសិនបើអ្នកមានគម្រោងដំឡើងឡើងវិញនៅពេលក្រោយ និងចង់រក្សាការរៀបចំរបស់អ្នក។

### ការលុបចេញទាំងស្រុង

```bash
npm run uninstall:full
```

វាលុបកម្មវិធី **ព្រមទាំងលុបជាអចិន្ត្រៃយ៍** នូវទិន្នន័យទាំងអស់៖

- មូលដ្ឋានទិន្នន័យ (`storage.sqlite`)
- ការកំណត់រចនាសម្ព័ន្ធរបស់អ្នកផ្តល់សេវា និង API keys
- ឯកសារបម្រុងទុក
- ឯកសារកំណត់ហេតុ
- ឯកសារទាំងអស់នៅក្នុងថត `~/.omniroute/`

> ⚠️ **ការព្រមាន៖** `npm run uninstall:full` មិនអាចត្រឡប់ក្រោយបានទេ។ ការតភ្ជាប់អ្នកផ្តល់សេវា combos, API keys និងប្រវត្តិការប្រើប្រាស់ទាំងអស់របស់អ្នក នឹងត្រូវលុបជាអចិន្ត្រៃយ៍។

## ការលុបការដំឡើងដោយដៃ

### ការដំឡើង NPM ជាសកល

```bash
# លុប package សកល
npm uninstall -g omniroute

# (ជាជម្រើស) លុបថតទិន្នន័យ
rm -rf ~/.omniroute
```

### ការដំឡើង pnpm ជាសកល

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# បញ្ឈប់ និងលុប container
docker stop omniroute
docker rm omniroute

# លុប volume (លុបទិន្នន័យទាំងអស់)
docker volume rm omniroute-data

# (ជាជម្រើស) លុប image
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# បញ្ឈប់ និងលុប containers
docker compose down

# លុប volumes ផងដែរ (លុបទិន្នន័យទាំងអស់)
docker compose down -v
```

### កម្មវិធី Electron សម្រាប់កុំព្យូទ័រលើតុ

**Windows៖**

- បើក `Settings → Apps → OmniRoute → Uninstall`
- ឬដំណើរការកម្មវិធីលុបការដំឡើង NSIS ពីថតដំឡើង

**macOS៖**

- អូស `OmniRoute.app` ពី `/Applications` ទៅធុងសំរាម
- លុបទិន្នន័យ៖ `rm -rf ~/Library/Application Support/omniroute`

**Linux៖**

- លុបឯកសារ AppImage
- លុបទិន្នន័យ៖ `rm -rf ~/.omniroute`

### ការដំឡើងពីកូដប្រភព (git clone)

```bash
# លុបថតដែលបាន clone
rm -rf /path/to/omniroute

# (ជាជម្រើស) លុបថតទិន្នន័យ
rm -rf ~/.omniroute
```

## ថតទិន្នន័យ

តាមលំនាំដើម OmniRoute រក្សាទុកទិន្នន័យនៅទីតាំងខាងក្រោម៖

| វេទិកា        | ផ្លូវលំនាំដើម                      | ការកំណត់ជំនួស                  |
| ------------- | ---------------------------------- | ------------------------------ |
| Linux         | `~/.omniroute/`                    | អថេរបរិស្ថាន `DATA_DIR`        |
| macOS         | `~/.omniroute/`                    | អថេរបរិស្ថាន `DATA_DIR`        |
| Windows       | `%APPDATA%/omniroute/`             | អថេរបរិស្ថាន `DATA_DIR`        |
| Docker        | `/app/data/` (volume ដែលបាន mount) | អថេរបរិស្ថាន `DATA_DIR`        |
| អនុលោមតាម XDG | `$XDG_CONFIG_HOME/omniroute/`      | អថេរបរិស្ថាន `XDG_CONFIG_HOME` |

### ឯកសារនៅក្នុងថតទិន្នន័យ

| ឯកសារ/ថត             | ការពិពណ៌នា                                                    |
| -------------------- | ------------------------------------------------------------- |
| `storage.sqlite`     | មូលដ្ឋានទិន្នន័យចម្បង (អ្នកផ្តល់សេវា, combos, ការកំណត់, keys) |
| `storage.sqlite-wal` | កំណត់ហេតុសរសេរជាមុនរបស់ SQLite (បណ្តោះអាសន្ន)                 |
| `storage.sqlite-shm` | អង្គចងចាំរួមរបស់ SQLite (បណ្តោះអាសន្ន)                        |
| `call_logs/`         | បណ្ណសារទិន្នន័យ payload នៃសំណើ                                |
| `backups/`           | ការបម្រុងទុកមូលដ្ឋានទិន្នន័យដោយស្វ័យប្រវត្តិ                  |
| `log.txt`            | កំណត់ហេតុសំណើពីប្រព័ន្ធចាស់ (ជាជម្រើស)                        |

## ផ្ទៀងផ្ទាត់ការលុបចេញទាំងស្រុង

បន្ទាប់ពីលុបការដំឡើង សូមផ្ទៀងផ្ទាត់ថាមិនមានឯកសារណាមួយនៅសល់ទេ៖

```bash
# ពិនិត្យមើលកញ្ចប់ npm សកល
npm list -g omniroute 2>/dev/null

# ពិនិត្យមើលថតទិន្នន័យ
ls -la ~/.omniroute/ 2>/dev/null

# ពិនិត្យមើលដំណើរការដែលកំពុងដំណើរការ
pgrep -f omniroute
```

ប្រសិនបើមានដំណើរការណាមួយនៅតែកំពុងដំណើរការ សូមបញ្ឈប់វា៖

```bash
pkill -f omniroute
```
