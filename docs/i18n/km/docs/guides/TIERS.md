OmniRoute រៀបចំអ្នកផ្តល់សេវាដែលគាំទ្រចំនួន 352 ទៅជា 3 កម្រិតសេដ្ឋកិច្ច។ សំណើនីមួយៗ
ត្រូវបានបញ្ជូនឆ្លងកាត់ពួកវាតាមលំដាប់ រហូតដល់មានមួយឆ្លើយតបដោយជោគជ័យ — អ្នក
នឹងទទួលបានការឆ្លើយតបដែលអាចប្រើបានក្នុងតម្លៃទាបបំផុត ដោយមិនចាំបាច់សរសេរកូដ fallback ឡើយ។

## កម្រិត 1 — ការជាវ

**អ្នកផ្តល់សេវាដែលអ្នកបានបង់ប្រាក់រួចហើយ។** OmniRoute ប្រើកូតាទាំងអស់ឱ្យអស់ មុនពេល
វាផុតកំណត់។

នឹងកំណត់អាទិភាពស្របតាមនោះ។ ដើម្បីបញ្ជូនទៅកម្រិត 1 ជាមុន ហើយផ្លាស់ទៅ
កម្រិតបង់ប្រាក់តែនៅពេលកូតាអស់ សូមប្រើ id `auto/thrifty` — ឬ `auto/subscription`

## តេឡេមេទ្រី

Dashboard → **Usage** បង្ហាញ tokens ដែលបានប្រើក្នុងមួយកម្រិតក្នុងមួយថ្ងៃ។ ប្រើវាដើម្បី៖

- បញ្ជាក់ថាកម្រិត 1 ត្រូវបានប្រើប្រាស់ពេញលេញ (បើមិនដូច្នោះទេ អ្នកកំពុងខ្ជះខ្ជាយតម្លៃនៃការជាវ)
- កំណត់ថាម៉ូដែលកម្រិត 2 ណាខ្លះត្រូវបានជ្រើសរើសច្រើនបំផុត (បង្រួមឱ្យនៅសល់ 1-2)
- ផ្ទៀងផ្ទាត់ថាកម្រិត 3 សន្សំប្រាក់លើបន្ទុកការងារសាកល្បង/រុករក

## លំនាំទូទៅ

### បន្ទុកការងារឥតគិតថ្លៃទាំងស្រុង

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

បង្ខំឱ្យផ្តោតខ្លាំងទៅកាន់កម្រិត 3; ប្រើកម្រិត 2 តែប៉ុណ្ណោះ ប្រសិនបើកម្រិត 3 មិនអាចប្រើបាន។

### ផ្តល់អាទិភាពដល់ការជាវ ជាមួយ fallback តម្លៃថោក

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

បញ្ជីតាមលំដាប់ជាក់លាក់ដែលផ្គូផ្គងនឹងកម្រិត 1 → កម្រិត 2 → កម្រិត 3។
