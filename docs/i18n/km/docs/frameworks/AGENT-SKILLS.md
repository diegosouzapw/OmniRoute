## ទិដ្ឋភាពទូទៅ

កាតាឡុកនេះមាន **Agent Skills ចំនួន 45** (REST API ចំនួន 23 + CLI ចំនួន 21 + លំហូរការងារកំណត់រចនាសម្ព័ន្ធចំនួន 1)។ ជំនាញនីមួយៗមាន៖

- **ID ផ្លូវការ** មួយ (`omni-auth`, `cli-serve` ជាដើម)
- ឯកសារ **SKILL.md** មួយនៅក្នុង `skills/{id}/SKILL.md` ដែលមាន YAML frontmatter (`name`, `description`) + ខ្លឹមសារ markdown លម្អិត
- **REST endpoints** (សម្រាប់ជំនាញ API) ឬ **CLI subcommands** (សម្រាប់ជំនាញ CLI) ដែលទាញយកពី OpenAPI spec និង CLI registry
- **GitHub raw URL** មួយសម្រាប់ទាញយកដោយផ្ទាល់៖ `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## ការស្វែងរក REST API

| Endpoint                     | Method | Description                                                    | Auth         |
| :--------------------------- | :----- | :------------------------------------------------------------- | :----------- |
| `/api/agent-skills`          | GET    | រាយកាតាឡុក (`?category=api\|cli\|config&area=<area>` ជាជម្រើស) | គ្មាន        |
| `/api/agent-skills/{id}`     | GET    | ទទួលយកទិន្នន័យមេតារបស់ជំនាញតែមួយ                               | គ្មាន        |
| `/api/agent-skills/{id}/raw` | GET    | ទាញយក SKILL.md ជា `text/markdown`                              | គ្មាន        |
| `/api/agent-skills/coverage` | GET    | ស្ថិតិគ្របដណ្តប់ (ចំនួនឯកសារ SKILL.md ដែលមាន)                  | គ្មាន        |
| `/api/agent-skills/generate` | POST   | ដំណើរការកម្មវិធីបង្កើត (dryRun/prune/onlyIds)                  | ការគ្រប់គ្រង |

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ឧទាហរណ៍ — ទាញយក SKILL.md តែមួយ៖

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

## កម្មវិធីបង្កើត

កម្មវិធីបង្កើតអានកាតាឡុកដែលបានរៀបចំ + OpenAPI spec + CLI registry ហើយសរសេរ `skills/{id}/SKILL.md` សម្រាប់ធាតុនីមួយៗ៖

```bash
# មើលជាមុន (ដំណើរការសាកល្បង ដោយមិនសរសេរទិន្នន័យ)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# បង្កើតឡើងវិញទាំងស្រុង
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# បង្កើត IDs ជាក់លាក់ឡើងវិញ
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

ការឆ្លើយតបរបស់កម្មវិធីបង្កើតគឺជា `GeneratorReport`៖

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
