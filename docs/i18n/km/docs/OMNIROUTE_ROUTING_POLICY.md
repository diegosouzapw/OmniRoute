ការកំណត់ផ្លូវរក្សាទុកតក្កវិជ្ជាជ្រើសរើសសមត្ថភាព និងបន្សំដែលមានស្រាប់ បន្ទាប់មកអនុវត្តកត្តានៃការបែងចែក សុខភាព សៀគ្វី កូតា ភាពយឺត ភាពអាចទុកចិត្តបាន ចំណូលចិត្តម៉ូដែល និងចំណូលចិត្តថ្លៃដើម។

ពិន្ទុសម្របខ្លួនអាចពន្យល់បាន ហើយត្រឡប់ទាំងបេក្ខជនដែលបានជ្រើសរើស និងបេក្ខជនដែលបានតម្រៀបចំណាត់ថ្នាក់ទាំងអស់។ កូតាដែលបានប្រើអស់ ការបែងចែកដែលត្រូវបានបដិសេធ និងសៀគ្វីដែលបើក គឺមិនមានសិទ្ធិត្រូវបានជ្រើសរើសទេ។ កូតាដែលមិនស្គាល់នៅតែមានសិទ្ធិត្រូវបានជ្រើសរើស ដោយមានកត្តាកូតាអព្យាក្រឹត។

ការមើលផ្លូវជាមុនមានលទ្ធផលថេរ និងមិនធ្វើសំណើទៅម៉ូដែល upstream ណាមួយឡើយ៖

`POST /api/omniroute/route/preview`

ការឆ្លើយតបរួមមានពិន្ទុបេក្ខជន កត្តា ហេតុផល អ្នកផ្តល់សេវាដែលបានជ្រើសរើស និង `liveRequestExecuted: false`។
