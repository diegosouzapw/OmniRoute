> **Ukratko**: Instalirajte → Povežite besplatnog pružatelja usluge → Usmjerite svoj IDE na OmniRoute. Gotovo.

---

## 1. korak: Instalirajte OmniRoute

Odaberite željeni način:

### Opcija A: npm (preporučeno)

```bash
npm install -g omniroute
```

### Opcija B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` je najviša **objavljena** stabilna SemVer verzija. Ne prati git granu `main`. Za GitOps fiksirajte verziju s `diegosouzapw/omniroute:X.Y.Z`. Pogledajte [Oznake slika / kanali izdanja](../guides/DOCKER_GUIDE.md#release-channels).

### Opcija C: Iz izvornog koda

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## 2. korak: Pokrenite OmniRoute

```bash
omniroute
```

OmniRoute se pokreće na adresi `http://localhost:20128`. Nadzorna ploča otvara se automatski.

---

## 3. korak: Povežite besplatnog pružatelja usluge

OmniRoute možete koristiti **potpuno besplatno** povezivanjem besplatnog pružatelja usluge.

### Opcija A: Kiro (besplatni Claude — bez kreditne kartice)

1. Otvorite nadzornu ploču na adresi `http://localhost:20128`
2. Idite na **Pružatelji usluga** → **Dodaj pružatelja usluge**
3. Odaberite **Kiro AI**
4. Kliknite **Poveži** (API ključ nije potreban!)
5. Gotovo! Sada imate besplatan pristup modelima Claude.

### Opcija B: OpenCode Free (bez autentifikacije)

1. Otvorite nadzornu ploču na adresi `http://localhost:20128`
2. Idite na **Pružatelji usluga** → **Dodaj pružatelja usluge**
3. Odaberite **OpenCode Free**
4. Kliknite **Poveži** (API ključ nije potreban!)
5. Gotovo! Sada imate besplatan pristup većem broju modela.

### Opcija C: Pollinations (ključ nije potreban)

1. Otvorite nadzornu ploču na adresi `http://localhost:20128`
2. Idite na **Pružatelji usluga** → **Dodaj pružatelja usluge**
3. Odaberite **Pollinations**
4. Kliknite **Poveži** (API ključ nije potreban!)
5. Gotovo! Sada imate besplatan pristup modelima GPT-5, Claude, Gemini i drugima.

---

## 4. korak: Provjerite radi li

Na stranici [API ključevi](http://localhost:20128/dashboard/api-manager) izradite novi ključ. Spremite ga jer se neće ponovno prikazati. Imajte na umu da je ovaj ključ namijenjen alatima za pristup sustavu OmniRoute, a ne za pristup uzvodnim pružateljima usluga.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Trebali biste vidjeti popis povezanih modela.

## 5. korak: Usmjerite svoj IDE ili CLI na OmniRoute

U svojem IDE-u ili CLI alatu postavite:

```
Osnovni URL: http://localhost:20128/v1
API ključ:   [kopirajte iz Nadzorna ploča → Krajnje točke]
Model:       auto
```

To je sve! Vaš IDE sada koristi OmniRoute s automatskim odabirom pružatelja usluge.

### Primjer za IDE: VSCode/Continue.dev

1. U VSCodeu instalirajte proširenje [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Ažurirajte `~/.continue/config.yaml` dodavanjem sljedećih redaka:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. U oknu za razgovor proširenja Continue.dev odaberite `OmniRoute - Auto` kako biste slali zahtjeve sustavu OmniRoute.
4. (Neobavezno) Vježba za čitatelja — neka vaš IDE ažurira `config.yaml` svim ostalim unaprijed pripremljenim konfiguracijama 😊

### Primjer za CLI: Codex CLI

1. U svojem operacijskom sustavu trajno postavite varijablu okruženja.
   Za macOS/Linux (dodajte u `~/.bashrc` ili `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Za Windows (naredbeni redak):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Sada pokrenimo Codex konfiguriran za OmniRoute. Pokrenite:

```
omniroute launch-codex --model auto
```

To možete učiniti ručno putem naredbe `codex` i parametara naredbenog retka kojima se određuju krajnja točka i API ključ, no uz prethodnu naredbu OmniRoute će se pobrinuti za sve.

Isto pokretanje jednom naredbom funkcionira i za druge CLI alate putem generičkog pokretača — `omniroute run <target>` podržava `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` i `gemini` (pogledajte [CLI integracije](../guides/CLI-INTEGRATIONS.md)).

3. CLI bi sada trebao slati zahtjeve sustavu OmniRoute.

### Potvrdite da vaš alat usmjerava zahtjeve na OmniRoute

Pojedinosti zahtjeva možete vidjeti klikom na [Nadzor/Zapisnici](http://localhost:20128/dashboard/logs) na lijevoj bočnoj traci. Klikom možete pregledati dodatne pojedinosti. Usput možete vidjeti koje se informacije šalju iz vašeg omiljenog razvojnog okruženja. To je korisno za učenje i otklanjanje pogrešaka.

## Česta pitanja

### „Trebam li API ključ?”

**Ne!** Besplatne pružatelje usluga (Kiro, OpenCode Free, Pollinations) možete koristiti bez API ključa. Samo ih povežite na nadzornoj ploči.

### „Što je `auto`?”

`auto` govori sustavu OmniRoute da automatski odabere najboljeg pružatelja usluge za svaki zahtjev. U obzir uzima brzinu, cijenu, kvalitetu i dostupnost. Pojedinosti potražite u [Vodiču za Auto-Combo](./AUTO-COMBO-GUIDE.md).

### „Koliko to košta?”

Sam OmniRoute je **besplatan i otvorenog koda**. Plaćate samo pružatelje usluga koje koristite. Mnogi pružatelji usluga imaju besplatne pakete — pogledajte [Vodič za besplatne pakete](./FREE-TIERS-GUIDE.md).

### „Mogu li ga koristiti s alatima Claude Code / Cursor / Copilot?”

**Da!** OmniRoute radi sa svim alatima koji podržavaju format OpenAI. Samo postavite osnovni URL na `http://localhost:20128/v1`. Posebne upute za postavljanje potražite u [Vodiču za CLI alate](../reference/CLI-TOOLS.md).

### „Što ako neki pružatelj usluge prestane raditi?”

OmniRoute automatski preskače neuspješne pružatelje usluga i pokušava sa sljedećim. Ne morate ništa učiniti. Pojedinosti potražite u [Vodiču za Auto-Combo](./AUTO-COMBO-GUIDE.md).
