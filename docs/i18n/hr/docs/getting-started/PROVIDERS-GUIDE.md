> **Ukratko**: Pružatelj je veza s AI uslugom (kao što su OpenAI, Anthropic ili Google). Za upotrebu OmniRoutea potreban vam je barem jedan pružatelj.

---

## Što je pružatelj?

Zamislite pružatelja kao **mobilnog operatera**. Baš kao što vam je za pozive potreban mobilni operater, za upotrebu AI modela potreban vam je pružatelj AI usluga. OmniRoute je poput telefona koji radi sa **svim operaterima** — možete se automatski prebacivati između njih.

### Vrste pružatelja

| Vrsta           | Što je to                             | Primjeri                          | Cijena                      |
| --------------- | ------------------------------------- | --------------------------------- | --------------------------- |
| **Besplatni**   | Plaćanje nije potrebno                | Kiro, OpenCode Free, Pollinations | $0                          |
| **API ključ**   | Potreban vam je API ključ             | OpenAI, Anthropic, Google         | Plaćanje prema potrošnji    |
| **OAuth**       | Prijava putem vašeg računa            | Claude Code, GitHub Copilot       | Pretplata                   |
| **Web kolačić** | Upotrebljava sesiju vašeg preglednika | ChatGPT Web (Codex), Gemini Web   | $0 (upotrebljava vaš račun) |

### Pružatelji s web-kolačićima

Pogledajte **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** za opće upute za postavljanje, ograničenja, rješavanje problema i smjernice za autentifikaciju specifične za pojedinog pružatelja.

## Brzi početak: povežite svojeg prvog pružatelja

### Neobavezno početno postavljanje besplatnih pružatelja

Čarobnjak pri prvom pokretanju nudi zasebnu karticu **Postavi besplatne pružatelje**. Trenutačni
popis prihvatljivih pružatelja izvodi iz registra OmniRouteovih pružatelja koji ne zahtijevaju autentifikaciju, a zatim vam omogućuje pregled i poništavanje odabira svakog
pružatelja prije potvrde. OmniRoute prikazuje upozorenje pružatelja i poveznicu na njegovu stranicu
kako biste najprije mogli pregledati uvjete treće strane, pravila privatnosti, dostupnost i ograničenja brzine zahtjeva.

Ova je radnja neobavezna: dovršavanjem čarobnjaka nikada se potajno ne stvaraju veze s besplatnim pružateljima.
Stvaraju se samo pružatelji koji još nedostaju, postojeće prilagođene veze ostaju
nepromijenjene, a izvješće zasebno prikazuje stvorene, već konfigurirane i neuspjele pružatelje. Nakon djelomičnog rezultata možete
bez rizika ponovno pokušati samo s neuspjelima.

### Opcija A: besplatni pružatelj (bez kreditne kartice)

1. Otvorite nadzornu ploču na adresi `http://localhost:20128`
2. Idite na **Pružatelji** → **Dodaj pružatelja**
3. Odaberite jednog od ovih besplatnih pružatelja:
   - **Kiro AI** — Besplatni Claude modeli (autentifikacija nije potrebna)
   - **OpenCode Free** — Besplatni GPT modeli (autentifikacija nije potrebna)
   - **Pollinations** — Besplatni GPT-5, Claude i Gemini (ključ nije potreban)
   - **LongCat** — 10M besplatnih tokena (jednokratna dodjela, potreban račun i KYC)
   - **Cloudflare AI** — Više od 50 modela, 10K neurona dnevno
   - **MLX Gemma 26B** — Lokalni model za Apple Silicon (~38.5 tokena/s, ~15.9GB RAM-a)
   - **MLX Qwen 3.8 27B** — Lokalni model za Apple Silicon (~9.1 tokena/s, ~13.1GB RAM-a)
4. Kliknite **Poveži**
5. Gotovo! Sada imate besplatan pristup AI-ju.

### Opcija B: pružatelj s API ključem (plaćeni)

1. Nabavite API ključ na web-stranici pružatelja:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Otvorite nadzornu ploču na adresi `http://localhost:20128`
3. Idite na **Pružatelji** → **Dodaj pružatelja**
4. Odaberite svojeg pružatelja
5. Zalijepite svoj API ključ
6. Kliknite **Poveži**
7. Gotovo! Sada imate pristup modelima tog pružatelja.

### Opcija C: OAuth pružatelj (pretplata)

1. Otvorite nadzornu ploču na adresi `http://localhost:20128`
2. Idite na **Pružatelji** → **Dodaj pružatelja**
3. Odaberite svojeg pružatelja (npr. Claude Code ili GitHub Copilot)
4. Kliknite **Poveži putem OAutha**
5. Prijavite se svojim računom
6. Gotovo! Sada imate pristup modelima iz svoje pretplate.

### Opcija D: lokalni MLX modeli (Apple Silicon)

Za Mac računala s procesorima Apple Silicon i objedinjenom memorijom OmniRoute podržava povezivanje s lokalnim MLX modelima koji se putem `mlx-lm.server` izvode kao standardni lokalni pružatelji kompatibilni s OpenAI-jem.

#### Preduvjeti

- **Mac s procesorom Apple Silicon** (M1/M2/M3/M4), preporučuje se 24GB ili više objedinjene memorije
- Upravitelj paketa **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Brzi početak

1. **Instalirajte ovisnosti**:

   ```bash
   # Instalirajte uv ako već nije instaliran
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Instalirajte mlx-lm
   uv pip install mlx-lm
   ```

2. **Ručno pokrenite MLX poslužitelje** (u zasebnim terminalima):

   ```bash
   # Terminal 1: Gemma 4 26B A4B IT-QAT (priključak 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Terminal 2: Qwen 3.8 27B MLX Mixed (priključak 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Povežite se na nadzornoj ploči OmniRoutea**:
   - Idite na **Pružatelji** → **Dodaj pružatelja**
   - Odaberite **MLX Gemma 26B** ili **MLX Qwen 3.8 27B**
   - Kliknite **Poveži** (API ključ nije potreban)

4. **Upotrebljavajte s OpenCodeom**:
   ```bash
   # Konfigurirajte OpenCode za upotrebu OmniRoutea
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <vaš-omniroute-api-ključ>

   # Upotrebljavajte MLX modele
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Upravljanje memorijom

**Važno**: Uz 24GB objedinjene memorije istodobno se može izvoditi samo **jedan veliki MLX model**.

- Gemma 26B: ~15.9GB vršne potrošnje memorije
- Qwen 3.8 27B: ~13.1GB vršne potrošnje memorije

Time morate upravljati ručno:

- Istodobno pokrećite samo jedan MLX poslužitelj ili
- Pokrenite ih na zasebnim računalima ili
- Zaustavite jedan prije pokretanja drugog

OmniRoute ne upravlja automatski procesima MLX poslužitelja — samo usmjerava zahtjeve prema krajnjim točkama kompatibilnima s OpenAI-jem koje konfigurirate.

#### Podrška za pozivanje alata

Oba modela podržavaju pozivanje alata kompatibilno s OpenAI-jem. Testirajte pomoću:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "Koliko je 2+2? Upotrijebi alat za izračun."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Izračunaj", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Rješavanje problema

| Problem                     | Rješenje                                                                                              |
| --------------------------- | ----------------------------------------------------------------------------------------------------- |
| Poslužitelj se ne pokreće   | Provjerite `uv run mlx_lm.server --help` i potvrdite ID-ove modela                                    |
| Nedostatak memorije         | Osigurajte da je pokrenut samo jedan model; zatvorite druge aplikacije; provjerite Monitor aktivnosti |
| Veza je odbijena            | Provjerite radi li poslužitelj na ispravnom priključku (11435/11436)                                  |
| Spori odgovori              | Prvi zahtjev učitava model u memoriju (~30-60 s); sljedeći su zahtjevi brzi                           |
| Pozivanje alata ne uspijeva | Provjerite podržava li model alate; provjerite zapise OmniRoutea radi pogrešaka u prevođenju          |

## Kako povezati pružatelja (korak po korak)

### 1. korak: Otvorite nadzornu ploču

U pregledniku otvorite `http://localhost:20128`.

### 2. korak: Otvorite pružatelje

Kliknite **Pružatelji** na bočnoj traci.

### 3. korak: Kliknite Dodaj pružatelja

Kliknite gumb **+ Dodaj pružatelja**.

### 4. korak: Odaberite pružatelja

Pregledajte popis ili potražite svojeg pružatelja. Kliknite ga.

### 5. korak: Unesite vjerodajnice

- **Besplatni pružatelji**: Vjerodajnice nisu potrebne — samo kliknite **Poveži**
- **Pružatelji s API ključem**: Zalijepite svoj API ključ
- **OAuth pružatelji**: Kliknite **Poveži putem OAutha** i prijavite se

### 6. korak: Testirajte vezu

Kliknite **Testiraj vezu** kako biste provjerili radi li.

### 7. korak: Gotovo!

Vaš je pružatelj sada povezan. Možete ga upotrebljavati uz `model: "auto"` ili izravno navesti pružatelja.

## Upotreba više pružatelja

OmniRoute najbolje funkcionira s **više pružatelja**. Time dobivate:

- **Automatsko prebacivanje** — Ako jedan pružatelj zakaže, OmniRoute pokušava sa sljedećim
- **Optimizaciju troškova** — OmniRoute odabire najjeftinijeg pružatelja za svaki zahtjev
- **Optimizaciju brzine** — OmniRoute odabire najbržeg pružatelja za svaki zahtjev
- **Optimizaciju kvalitete** — OmniRoute odabire najboljeg pružatelja za svaki zadatak

### Preporučena konfiguracija

Za najbolje iskustvo povežite najmanje **3 pružatelja**:

1. **Jednog besplatnog pružatelja** (Kiro, OpenCode Free ili Pollinations) — Uvijek dostupan
2. **Jednog brzog pružatelja** (Groq, Cerebras) — Za brze odgovore
3. **Jednog kvalitetnog pružatelja** (OpenAI, Anthropic, Google) — Za složene zadatke

Zatim upotrijebite `model: "auto"` i OmniRoute će automatski odabrati najboljeg pružatelja za svaki zahtjev.

## Česta pitanja

### "Moram li platiti za korištenje OmniRoutea?"

**Ne!** OmniRoute je besplatan i otvorenog koda. Možete upotrebljavati besplatne pružatelje usluga (Kiro, OpenCode Free, Pollinations) bez ikakvog plaćanja. Plaćate samo ako odlučite upotrebljavati pružatelje usluga koji se naplaćuju.

### "S kojim pružateljem usluge trebam započeti?"

Započnite s **Kiro AI** — besplatan je, ne zahtijeva API ključ i omogućuje vam pristup modelima Claude. Zatim prema potrebi dodajte još pružatelja usluga.

### "Mogu li istodobno upotrebljavati više pružatelja usluga?"

**Da!** Upravo je to smisao OmniRoutea. Povežite više pružatelja usluga i upotrijebite `model: "auto"` kako bi OmniRoute odabrao najboljeg za svaki zahtjev.

### "Što ako pružatelj usluge prestane raditi?"

OmniRoute automatski preskače pružatelje usluga koji nisu uspjeli obraditi zahtjev i pokušava sa sljedećim. Ne morate ništa poduzeti.

### "Kako mogu odspojiti pružatelja usluge?"

Idite na Pružatelji usluga → kliknite pružatelja usluge → kliknite **Odspoji**.

### "Mogu li upotrebljavati svoje postojeće API ključeve?"

**Da!** Ako već imate API ključeve za OpenAI, Anthropic, Google itd., možete ih upotrebljavati u OmniRouteu. Samo ih zalijepite prilikom povezivanja pružatelja usluge.
