## Kategorije

- **Besplatno** — besplatna razina s API ključem (konfigurira se putem nadzorne ploče)
- **Bez autentifikacije** — javne krajnje točke koje uopće ne zahtijevaju ključ ni prijavu
- **OAuth** — postupkom prijave upravlja OmniRoute, API ključ nije potreban
- **Web-kolačić** — obuhvaća web-aplikaciju pružatelja usluge uz autentifikaciju kolačićem
- **API ključ** — pružatelj usluge koji se plaća i konfigurira putem API ključa (moguće je dobiti besplatne kredite)
- **Lokalno** — izvodi se na korisnikovu računalu (Ollama, LM Studio, vLLM itd.)
- **Pretraživanje** — pružatelji usluga web-pretraživanja
- **Zvuk** — pružatelji usluga samo za zvuk (TTS/STT)
- **Nadređeni proxy** — pružatelji usluga koji prosljeđuju zahtjeve drugim pružateljima usluga
- **Agent u oblaku** — dugotrajni agenti za programiranje (Codex Cloud, Devin, Jules)
- **Sustav** — interni pružatelji usluga sustava OmniRoute (povratna petlja itd.)

Dodatne oznake: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (gdje je prikazano): `native` — stvarni API za pozivanje funkcija; `emulated` — polje `tools` emulira se putem upita pomoću datoteke `webTools.ts` (blokovi `<tool>{...}</tool>` raščlanjuju se regularnim izrazom); `none` — polje `tools` trenutačno se neprimjetno odbacuje. Pogledajte #7286.

Upotrijebite nadzornu ploču na `/dashboard/providers` kako biste omogućili, konfigurirali i testirali svakog pružatelja usluge.
