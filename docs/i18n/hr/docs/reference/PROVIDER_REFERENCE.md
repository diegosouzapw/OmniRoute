## Kategorije

- **Besplatno** — besplatni sloj s API ključem (konfigurirano putem nadzorne ploče)
- **Bez autentifikacije** — javne krajnje točke koje uopće ne zahtijevaju ključ ili prijavu
- **OAuth** — tijek prijave obrađuje OmniRoute, nije potreban API ključ
- **Web kolačić** — omotava web aplikaciju pružatelja putem autentifikacije kolačićima
- **API ključ** — plaćeni pružatelj konfiguriran putem API ključa (mogu se primijeniti besplatni krediti)
- **Lokalno** — radi na korisnikovom stroju (Ollama, LM Studio, vLLM, itd.)
- **Pretraživanje** — pružatelji web pretraživanja
- **Audio** — pružatelji samo za audio (TTS/STT)
- **Uzvodni proxy** — pružatelji koji proxyju drugim pružateljima
- **Agent u oblaku** — dugotrajni agenti za kodiranje (Codex Cloud, Devin, Jules)
- **Sustav** — interni pružatelji OmniRoutea (povratna petlja, itd.)

Dodatne oznake: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Pozivanje alata` (gdje je prikazano): `native` — stvarni API za pozivanje funkcija; `emulated` — niz `tools` je emuliran putem upita preko `webTools.ts` (blokovi `<tool>{...}</tool>` parsirani regexom); `none` — `tools` se trenutno tiho odbacuje. Pogledajte #7286.

Koristite nadzornu ploču na `/dashboard/providers` za omogućavanje, konfiguriranje i testiranje svakog pružatelja.
