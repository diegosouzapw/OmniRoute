OmniRoute isporučuje odabrani skup besplatnih proxy poslužitelja u tablici `free_proxies`,
sinkroniziran iz vanjskih izvora (1proxy, proxifly, iplocate, webshare).
Nadzorna ploča prikazuje ih pod **Postavke → Besplatni proxy poslužitelji**. Ovaj dokument
obuhvaća filtriranje, sortiranje, prebrojavanje i prijavljivanje pogrešaka sinkronizacije
na strani poslužitelja koje pruža ruta za dohvaćanje popisa.

## Ruta popisa — `GET /api/settings/free-proxies`

Vraća filtrirani, sortirani i paginirani podskup zajedno s ukupnim brojem rezultata. Filtriranje i
prebrojavanje izvršavaju se u SQL-u, tako da korisničko sučelje može prikazati stvarni ukupan broj (npr. `Ukupno: 0`)
bez učitavanja svakog retka u memoriju.

### Parametri upita

| Param             | Vrsta                              | Zadano    | Značenje                                                                                                                     |
| ----------------- | ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `search`          | niz znakova                        | `""`      | `LIKE` osjetljiv na velika i mala slova nad stupcem hosta (i izvora).                                                        |
| `protocol`        | niz znakova                        | `""`      | Filtar `type`: `http` / `https` / `socks4` / `socks5`. Prazno = sve.                                                         |
| `country`         | niz znakova                        | `""`      | Filtar `countryCode` (ISO-2). Prazno = sve.                                                                                  |
| `minQuality`      | broj                               | `0`       | Samo retci za koje vrijedi `qualityScore >= minQuality`. `0` = bez donje granice.                                            |
| `disabledSources` | niz znakova                        | `""`      | ID-jevi izvora odvojeni zarezima koje treba isključiti (npr. `proxifly,webshare`).                                           |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = rezultat silazno; `latency` = latencija uzlazno (null vrijednosti na kraju); `recent` = `lastValidated` silazno. |
| `offset`          | broj                               | `0`       | Početak paginacije.                                                                                                          |
| `limit`           | broj                               | `50`      | Veličina stranice (ograničena na strani poslužitelja).                                                                       |

### Odgovor

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` predstavlja filtrirani ukupan broj **prije** paginacije, tako da korisničko sučelje može prikazati
`Ukupno: N` i `hasMore` neovisno jedno o drugome. `syncErrors` koristi ID izvora kao ključ i
popunjava se samo za izvore čija posljednja sinkronizacija nije uspjela — rezultat `Ukupno: 0`
nikada se ne prikazuje bez objašnjenja.

## Dodavanje u skup — `POST /api/settings/free-proxies/[id]/add-to-pool`

Promiče besplatni proxy poslužitelj u upravljani skup `proxy_registry`. Najprije provjerava valjanost
izvornog poslužitelja; u slučaju uspjeha vraća ID novog proxy poslužitelja u skupu i izmjerenu latenciju.

## Sinkronizacija — `POST /api/settings/free-proxies/sync`

Ponovno dohvaća podatke iz svih omogućenih izvora (ili podskupa navedenog u `{ "sources": [...] }`). Svaki
izvor sinkronizira se neovisno; izvor čija sinkronizacija ne uspije zabilježuje se u `syncErrors`, dok
ostali svejedno dovršavaju sinkronizaciju, pa djelomične sinkronizacije nikada ne brišu prethodno valjane podatke.

## Statistika — `GET /api/settings/free-proxies/stats`

Vraća agregirane vrijednosti `total / inPool / avgQuality / bySource / lastSyncAt`
bez sadržaja redaka — upotrebljavaju ih widgeti u zaglavlju nadzorne ploče.
