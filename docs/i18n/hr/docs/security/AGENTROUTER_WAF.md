Uzvodni pristupnik `agentrouter` primjenjuje filtar sadržaja temeljen na ključnim riječima na
`messages[].content`. Filtar je djelomično deterministički (uvijek blokira
određene izraze), a djelomično probabilistički (osjetljiv na rafalno slanje — postaje
agresivniji nakon brzog niza zahtjeva, a oporavlja se nakon razdoblja mirovanja).

Kada WAF blokira zahtjev, vraća:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Opseg filtra

WAF provjerava samo `messages[].content`. **Ne** provjerava:

- `system` prompt
- Strukturirane blokove sadržaja (`tool_result`, `tool_use`, `thinking`, `image`)
- Polja `description` i `input_schema` alata
- Metapodatke zahtjeva, zaglavlja ili ID modela

## Obrasci koji se uvijek blokiraju (bez obzira na velika i mala slova)

| Obrazac                                  | Napomene                                              |
| ---------------------------------------- | ----------------------------------------------------- |
| Bilo koja varijanta izraza `Lorem ipsum` | Blokiran je cijeli latinski lorem rječnik             |
| `language model` (samostalno)            | "the language model" i "large language model" prolaze |
| `virtual assistant`                      | "AI assistant" prolazi                                |
| `I'm here to help`                       | Sam izraz "here to help" također se blokira           |
| `Claude, made by Anthropic`              | Samo cijeli izraz                                     |

## Obrasci koji se gotovo uvijek blokiraju

| Obrazac                                                    | Napomene                                                    |
| ---------------------------------------------------------- | ----------------------------------------------------------- |
| `placeholder`                                              | Kada se pojavljuje samostalno (ne kao naziv parametra itd.) |
| `dummy data`                                               | Uobičajen početni izraz za testne podatke                   |
| `foo bar baz`                                              | Kanonski izraz za rezervirano mjesto                        |
| Ponavljani kratki tokeni (`AAA BBB CCC`, `test test test`) | Detektor prekomjernog umetanja ključnih riječi              |

## Ponašanje pod opterećenjem

Nakon približno 5 zahtjeva poslanih u brzom slijedu tijekom kratkog razdoblja, WAF počinje blokirati sadržaj
koji bi inače prošao. Ograničenje se ublažava nakon približno 5–10 sekundi
mirovanja. Riječ je o istom ograničivaču učestalosti zahtjeva, vezanom uz IP adresu i ključ, koji uzrokuje
povremene pogreške `400 content-blocked` kada Claude Code ili Codex CLI
brzo uzastopno izvršava više poziva za uporabu alata / slanje poruka.

## Ublažavanja već primijenjena u OmniRouteu

1. **`open-sse/services/wafRateLimit.ts`** — zaštita od rafalnog slanja koja nameće
   minimalni razmak od 500 ms između odlaznih zahtjeva prema bilo kojem URL-u
   `agentrouter:*`. Taj je razmak znatno ispod praga ljudske percepcije kašnjenja i sprječava
   aktiviranje WAF-a pri uobičajenom prometu.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — kada uzvodni sustav vrati
   `400 content-blocked`, izvršitelj ponavlja zahtjev prema istom URL-u uz
   eksponencijalno povećavanje odgode (1,5 s, 3,0 s, najviše 2 pokušaja). Nakon odgode
   WAF obično popusti i ponovljeni zahtjev uspije.

3. **`tests/unit/compression/harness.test.ts`** — testni ulaz
   `longInput` promijenjen je iz `"lorem ipsum dolor sit amet ".repeat(40)`
   u `"example content for testing purposes ".repeat(40)` kako se, kada
   Claude Code pročita ovu datoteku pomoću alata `Read`, sadržaj datoteke
   ne bi vratio kroz blok `tool_result` i aktivirao WAF.

## Smjernice za promptove i izlaz alata

Ako sesija Claude Codea ili Codex CLI-ja opetovano nailazi na
`400 content-blocked`, provjerite sadrže li najnovija korisnička poruka i najnoviji
rezultat alata neki od prethodno navedenih obrazaca te ih preformulirajte. Uobičajena
zaobilazna rješenja:

- Zamijenite `Lorem ipsum …` izrazom `example text …` ili stvarnim sadržajem
  koji test ili testni ulaz pokušava modelirati.
- Zamijenite `placeholder` (kada se pojavljuje samostalno) izrazom `example value`,
  `sample value` ili stvarnom vrijednošću.
- Zamijenite `language model` izrazom `large language model` ili `the model`.
- Zamijenite `dummy data` izrazom `sample data` ili realističnim početnim vrijednostima.
- Zamijenite `I'm here to help` / `here to help` konkretnijim
  uvodom (npr. "I'll review the file you mentioned").

## Prijavljivanje lažno pozitivnih rezultata uzvodnom sustavu

Trenutačni je filtar pretjerano agresivan — blokira "Lorem ipsum" u
blokovima `tool_result` iako operator očito nije namjeravao
ubaciti prompt. Operatori koji žele da se to ispravi na izvoru trebali bi se
obratiti organizaciji `agentrouter.org` i prijaviti lažno pozitivne rezultate. Prethodno navedeni popis blokiranih izraza
empirijski je rezultat ispitivanja uzvodnog sustava na dan 2026-08-03.
