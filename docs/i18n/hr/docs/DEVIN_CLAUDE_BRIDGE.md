`devin-cli-agentic` omogućuje stvarnom izvršnom okruženju Claude Code da koristi OmniRouteovu lokalnu krajnju točku Anthropic
Messages, dok službeni Devin CLI pruža odgovore modela putem ACP stdio. Ne
mijenja postojeće pružatelje Anthropic, Claude OAuth, Claude Web ni `devin-cli`.

> **Trenutačno stanje: prikvačen Claude Code `2.1.258`; izvanmrežna provjera i provjera uživo posljednji su put zabilježene
> na verziji `2.1.220`.** Prikvačena verzija `2.1.220` dovršila je tri izolirana scenarija putem Devin CLI-ja
> `3000.2.17` i modela `swe-1-7-lightning`; to završno pokretanje uživo potvrdilo je poteze `Read`,
> `Edit` i `Bash` kojima upravlja klijent, uspješne rezultate naredbe `npm test`, otkrivanje projektnih naredbi i
> vještina, usmjeravanje isključivo kroz Devin te potpun izostanak izlaznog prometa prema Claudeu. Prikvačena verzija zatim je podignuta na `2.1.258`
> (generaciju CLI-ja koju oponaša OmniRouteov Claude identitet i prvu liniju koja izvorno isporučuje
> razinu Fable 5.1). Na novoj prikvačenoj verziji instalacijski sloj i `claude --version`
> provjereni su na prikvačenoj osnovnoj slici, a paket jediničnih testova mosta, `compose config` i
> statički dokaz izolacije prolaze — ali izvanmrežni simulirani scenarij i paket od tri scenarija
> uživo još nisu ponovno pokrenuti. Ponovno ih pokrenite (pogledajte „Ažuriranje prikvačenih alata”) prije nego što se
> oslonite na most s ovom prikvačenom verzijom.

## Arhitektura

```text
Claude Code 2.1.258 (izolirani Linux spremnik bez ovlasti korisnika root)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (format Claude, pružatelj bez autentifikacije)
  -> devin acp --agent-type summarizer (službeni ACP stdio, bez Devin alata)
  -> Devin račun u namjenskom volumenu devin-auth
```

Zadani ACP agent službenog CLI-ja može izvršavati vlastite alate, stoga ga ovaj most ne
koristi. Pokreće fiksni ACP agent `summarizer`, čiji službeni način rada CLI-ja nema alate, i
uokviruje serijalizirani Anthropic zahtjev kao trag izvršavanja. Kada je potrebna još jedna radnja
kojom upravlja Claude, odgovor mora sadržavati točno jednu klijentsku omotnicu alata. Svaki ACP
`tool_call` ili `tool_call_update` odbacuje se prije nego što se odgovor može prijaviti kao
uspješan.

Serijalizator u `open-sse/executors/devin-agentic/serializer.ts` zadržava `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` i
alate koje isporučuje Claude Code. Slike i nepoznati blokovi izričito uzrokuju neuspjeh. Veliki rezultati alata
koriste vidljivu oznaku skraćivanja.

Parser prihvaća jednu samostalnu omotnicu `<tool>{...}</tool>` po potezu modela. Provjerava
naziv prema popisu alata iz zahtjeva, validira argumente prema JSON shemi tog alata,
odbacuje kombinaciju narativa i radnji te dopušta jedan ograničeni pokušaj ispravka. Claude Code zatim
lokalno izvršava dobiveni Anthropic `tool_use` i šalje `tool_result` natrag kroz
OmniRoute.

## Izolacija i model prijetnji

Instalacija, račun i konfiguracija Claudea na glavnom računalu izvan su opsega i smatraju se
zabranjenima. Usluge Compose:

- izvode se kao UID/GID `10001:10001`, s korijenskim datotečnim sustavom samo za čitanje, uklonjenim mogućnostima i
  opcijom `no-new-privileges`;
- koriste privatni `/home/bridge`, namjenski volumen konfiguracije Claudea, izolirane OmniRoute podatke
  i zaseban volumen `devin-auth`;
- montiraju samo jednokratne radne prostore/dokaze `.sandbox`;
- ne montiraju korisnički direktorij glavnog računala, Keychain, SSH, vjerodajnice za oblak ni Docker socket;
- izrađuju eksplicitna okruženja i uklanjaju varijable API-ja, OAutha i usmjeravanja za Anthropic;
- usmjeravaju zaključivanje Claude Codea isključivo na `http://omniroute:20128` uz ključ namijenjen samo lokalnoj uporabi.

Izvanmrežni profil koristi internu mrežu. U profilu uživo OmniRoute pristupa
službenim Devin krajnjim točkama samo putem `network-guard`; nepovezana su odredišta odbijena.
Claude Code ima zasebnu zaštitu koja zabranjuje sav izlazni promet te može pristupiti samo lokalnoj usluzi OmniRoute
putem `NO_PROXY`. Datoteke revizije zaštite montira samo njihov proces zaštite. Skripte
provjeravaju vlasništvo nad datotekama, način rada, broj poveznica i svaku odluku prije izvoza
dokaza bez tokena.

Neovisno pokrenite dokaz izolacije:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

On provjerava topologiju, imenovane točke montiranja, postavke za rad bez ovlasti korisnika root i samo za čitanje, eksplicitno lokalno usmjeravanje,
odsutnost osjetljivih varijabli okruženja, odsutnost Docker socketa, blokirani pristup adresama
`api.anthropic.com` i `claude.ai`, odabir pružatelja isključivo za Devin te izričiti neuspjeh kada
ACP pozadinski sustav nije dostupan.

## Početno postavljanje i uobičajena uporaba

Izgradite prikvačenu sliku:

```bash
./scripts/devin-bridge/build
```

Autentificirajte samo izolirani Devin volumen:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Naredba za prijavu koristi službeni tijek s ručnim tokenom namijenjen udaljenim/kontejnerskim
okruženjima. Vrijednost se unosi izravno u upit CLI-ja; ne prosljeđuje se kao argument
procesa, ne zapisuje se u Git niti se kopira s glavnog računala.

Pokrenite izolirano izvršno okruženje Claude Code:

```bash
./scripts/devin-bridge/launch
```

`launch` ponovno provjerava izolaciju, Devin autentifikaciju i otkrivanje modela prije
pokretanja kontejneriziranog Claude Codea. Nikada ne pokreće izvršnu datoteku Claude s glavnog
računala. Aliasi modela mogu se postaviti u `.env.devin-bridge`; svaka konfigurirana
vrijednost mora zadržati prefiks `devin-cli-agentic/`.

## Naredbe za provjeru valjanosti

Ponovljiv izvanmrežni postupak ne zahtijeva Devin račun i nema pristup internetu tijekom izvođenja:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Autentificirani aktivacijski postupak uživo jest:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Pokretač uživo čeka između scenarija kako bi izbjegao naglo otvaranje ACP sesija i
provjerava strukturirane događaje Claudeova toka umjesto da vjeruje tekstualnim tvrdnjama. Njegova tri
scenarija dokazuju:

1. izravno čitanje projekta i analizu nedostataka;
2. stvarni `Edit`, klijentski `Bash` `npm test` i završni rezultat;
3. otkrivanje `/bridge-check` i `bridge-proof`, čitanje projekta, još jedan uspješan
   klijentski `npm test` i dovršetak bez neriješenih zadataka.

Završna kontrola također provjerava reviziju Devinove mreže i zahtijeva da revizija Claudeova izlaznog
prometa ostane prazna.

## Ažuriranje prikvačenih alata

Slika prikvačuje Node, Claude Code i Devin CLI u
`docker/devin-bridge/Dockerfile`. Za ažuriranje:

1. promijenite eksplicitne verzije;
2. zamijenite kontrolne zbrojeve Devinove arhive za obje arhitekture vrijednostima za službeni
   artefakt;
3. ponovno izgradite i pokrenite svaku izvanmrežnu naredbu za provjeru valjanosti;
4. potvrdite verzije unutar slike;
5. ponovno pokrenite autentificirani paket od tri scenarija uživo.

Nemojte globalno instalirati nijedan CLI na glavno računalo niti zamijeniti provjeru kontrolnog zbroja
neprovjerenim preuzimanjem.

## Dijagnostika i čišćenje

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  prikazuje lokalno usmjeravanje i pročišćene pogreške izvršitelja.
- `.sandbox/evidence/mock-acp.jsonl` bilježi determinističke lažne ACP radnje.
- `.sandbox/evidence/claude-stream.jsonl` bilježi stvarno izvanmrežno izvođenje Claude Codea.
- `.sandbox/evidence/live-*.jsonl` bilježi tri provjerena toka uživo.
- `.sandbox/evidence/egress.jsonl` i `.sandbox/evidence/claude-egress.jsonl` provjerene su
  kopije revizija zaštitnog mehanizma bez tokena.

Zaustavite pripadajuće kontejnere i mreže uz očuvanje volumena za prijavu/konfiguraciju:

```bash
./scripts/devin-bridge/clean
```

Uklonite cijelo okruženje u vlasništvu mosta, uključujući imenovane volumene:

```bash
./scripts/devin-bridge/clean --all
```

## Ograničenja

- Most se oslanja na fiksnu ulogu `summarizer` bez alata jer Devin CLI `3000.2.17`
  ne izlaže neutralnog ACP agenta bez alata. Adapter kompenzira međurezultate
  oblikovane kao sažeci, ali jedan ograničeni pokušaj popravka ipak može izričito ne uspjeti.
- Aktivni ACP pozivi mogu vratiti privremene odgovore `502`/`504`. Testni okvir raspoređuje scenarije;
  trajni neuspjeh ostaje fail-closed i nikada ne odabire drugog pružatelja usluge.
- ACP kontekst rekonstruira se iz svakog Anthropic zahtjeva; ne postoji afinitet
  procesa/sesije.
- Podržan je jedan poziv alata po odgovoru modela; paralelni pozivi se odbijaju.
- Slike izričito nisu podržane. Mogućnosti vizualne obrade, izlaz razmišljanja, kontrole intenziteta i kontekstni prozor od 1M
  ne oglašavaju se.
- SSE upotrebljava valjane događaje Anthropic životnog ciklusa, ali se emitira nakon što se prikupi
  ograničeni ACP tijek; ACP segmenti ne prosljeđuju se inkrementalno.
