OmniRoute organizira 352 podržana pružatelja usluga u 3 ekonomske razine. Svaki
zahtjev prolazi kroz njih redom dok jedan ne vrati uspješan odgovor — tako
dobivate najjeftiniji izvediv odgovor bez potrebe za pisanjem pričuvnog koda.

## Razina 1 — Pretplata

**Pružatelji usluga koje već plaćate.** OmniRoute iskorištava svu dostupnu kvotu prije
nego što istekne.

| Pružatelj usluga                    | Zašto razina 1                                          |
| ----------------------------------- | ------------------------------------------------------- |
| Claude Code OAuth                   | Anthropic Pro/Team — fiksna cijena, često neiskorišteno |
| OpenAI Codex (pretplata na ChatGPT) | Plus/Team uključuje kvotu za Codex                      |
| GitHub Copilot                      | Po korisničkom mjestu — kvota se obnavlja mjesečno      |
| Cursor IDE                          | Kvota plana Pro                                         |
| Antigravity / Devin Desktop         | Ugrađene kvote                                          |

**Strategija**: prvo usmjeravajte ovamo svaki zahtjev koji odgovara prednostima
modela. Praćenje kvote nadzire nadolazeća obnavljanja, a kombinirana strategija
`reset-aware` određuje prioritete u skladu s time. Kako biste najprije usmjeravali
na razinu 1 i prelazili na plaćene razine tek kada se kvota potroši, upotrijebite
identifikator `auto/thrifty` — ili `auto/subscription` kako biste ostali na kapacitetu
uključenom u plan i umjesto toga odbili zahtjev. Pogledajte
[Usmjeravanje s prioritetom pretplate](../routing/SUBSCRIPTION_LADDER.md).

## Razina 2 — Jeftino

**Pružatelji usluga s naplatom po tokenu ispod 1 USD za 1 milijun tokena.** Rezervirano za velik opseg posla
ili nakon što kvote razine 1 dosegnu ograničenja.

| Pružatelj usluga                       | Cijena (ulaz/izlaz) | Prednosti                            |
| -------------------------------------- | ------------------- | ------------------------------------ |
| DeepSeek V4 Pro                        | $0.27 / $1.10 za 1M | Kod, zaključivanje                   |
| GLM-4.5                                | $0.60 / $2.20 za 1M | Dugačak kontekst                     |
| MiniMax M1                             | $0.20 / $1.10 za 1M | Brzina                               |
| Qwen Coder                             | $0.30 / $1.20 za 1M | Kod                                  |
| OpenRouter (optimizirano prema cijeni) | varira              | Više od 100 modela, dinamički odabir |

**Strategija**: kombinacija `cost-optimized` odabire model s najnižom cijenom po tokenu
koji zadovoljava filtar mogućnosti zadatka (slike, JSON način rada, alati, maksimalni kontekst).

## Razina 3 — Besplatno

**Pružatelji usluga bez troška** — besplatni planovi, programi kredita, dnevne OAuth kvote.

| Pružatelj usluga | Besplatna kvota / krediti                                         |
| ---------------- | ----------------------------------------------------------------- |
| Kiro AI          | Besplatna razina za Claude (velikodušna politika poštene uporabe) |
| OpenCode Free    | Bez autentifikacije, velikodušna ograničenja učestalosti          |
| Qoder            | Besplatni OAuth                                                   |
| Google Vertex AI | 300 USD kredita za nove račune                                    |
| Amazon Q         | Besplatna razina za korisnike AWS-a                               |
| Pollinations     | Otvoreni javni API                                                |
| Cloudflare AI    | Besplatna razina Workers AI                                       |

**Strategija**: kombinacija `auto` s ograničenjem proračuna usmjerava ovamo kada razine 1 i 2 zakažu
ili kada je postavljeno `useFreeOnly=true`. Besplatni pružatelji usluga često imaju stroža
ograničenja učestalosti — prekidač strujnog kruga ponovno ih aktivira nakon razdoblja čekanja.

## Konfiguriranje razina

Nadzorna ploča → **Razine** → dodijelite svoje pružatelje usluga. Zadane postavke (iz `tierDefaults.json`) su
razumne; uredite ih kada imate određene pretplate kojima želite dati prednost ili pružatelje usluga koje želite isključiti.

Bodovanje značajke Auto-Combo na temelju 16 čimbenika također uzima u obzir razinu. Pogledajte
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetrija

Nadzorna ploča → **Uporaba** prikazuje broj potrošenih tokena po razini i danu. Upotrijebite to kako biste:

- Potvrdili da je razina 1 u potpunosti iskorištena (u suprotnom rasipate vrijednost pretplate)
- Utvrdili koji se modeli razine 2 najčešće odabiru (objedinite ih na 1–2)
- Provjerili štedi li razina 3 novac na poslovima testiranja i istraživanja

## Uobičajeni obrasci

### Potpuno besplatno radno opterećenje

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Snažno usmjerava prema razini 3; razinu 2 upotrebljava samo ako razina 3 nije dostupna.

### Pretplata kao prvi izbor uz jeftinu pričuvnu opciju

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Izričit poredani popis koji odgovara redoslijedu razina 1 → razina 2 → razina 3.
