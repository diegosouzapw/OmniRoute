## 1. Antigravity u odnosu na Antigravity CLI (agy)

Oba pružatelja koriste **istu Googleovu pozadinsku infrastrukturu** — identičan OAuth klijent, osvježavanje tokena, krajnje točke i Google račune. Razlika je u tome koje modele vidite.

> Pogledajte [najavu Antigravity CLI-ja](https://antigravity.google/blog/introducing-google-antigravity-cli) za Googleovu službenu usporedbu.

| Aspekt                     | `antigravity` (IDE)                          | `agy` (CLI)                                               |
| -------------------------- | -------------------------------------------- | --------------------------------------------------------- |
| **Googleov proizvod**      | Antigravity 2.0 / Antigravity IDE            | Antigravity CLI                                           |
| **Pozadinski sustav**      | Isti Google Cloud Code API                   | Isti Google Cloud Code API                                |
| **OAuth / token**          | Isti klijent, isto osvježavanje              | Isti klijent, isto osvježavanje                           |
| **Katalog modela**         | Statički odabran popis (ugrađen u OmniRoute) | Dohvaća se uživo od Googlea putem `:fetchAvailableModels` |
| **Modeli Claude**          | Sonnet 4.6, Opus 4.6 (po 4 varijante svakog) | Sonnet 4.6, Opus 4.6 (po 4 varijante svakog)              |
| **Nazivi modela Gemini**   | Jasne oznake (Low/Medium/High)               | Izvorni ID-ovi (extra-low/low/agent)                      |
| **Dodatni modeli**         | `gpt-oss-120b-medium`                        | Može uključivati dodatne Googleove modele                 |
| **Zadani slučaj upotrebe** | Integracija s IDE-ovima (VS Code, JetBrains) | Pristup putem CLI-ja / API-ja                             |
| **Kvota**                  | Dijeli se s agy (isti Google račun)          | Dijeli se s antigravity (isti Google račun)               |

**Dostupni modeli (potvrđeno eksperimentom, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (različite razine razmišljanja)
- Claude: Sonnet 4.6, Opus 4.6 (svaki s varijantama default/low/medium/high)
- Ostalo: GPT-OSS 120B Medium
- **Claude Sonnet 5 NIJE dostupan** — podržane su samo varijante 4.6

**Zašto se katalog modela razlikuje**: Googleov CLI „optimiziran je za brzinu i malo dodatnog opterećenja” te je „zajednički optimiziran s modelima Gemini” (prema Googleovu službenom blogu). Web-proizvod/IDE „optimiziran je za sveobuhvatnost”. CLI koristi `:fetchAvailableModels` za dinamičko otkrivanje modela, dok IDE koristi statički odabran popis.

**U praksi**: Za modele Gemini koristite prefiks `agy/` (npr. `agy/gemini-3.7-flash-high`). Za statički odabran popis koristite `antigravity/`. Oba pristupaju istoj Googleovoj pozadinskoj infrastrukturi, ali izlažu različite nazive modela. Kvota se dijeli — upotreba bilo kojeg pružatelja računa se u ograničenja istog Google računa.

## 2. Google One AI Pro: Sustav kvota

> Pogledajte [Antigravity dokumentaciju: Planovi](https://antigravity.google/docs/plans) za službene pojedinosti o kvotama i [Promjene Antigravity planova](https://antigravity.google/blog/changes-to-antigravity-plans) za najnovije izmjene cijena.

Google Antigravity upotrebljava **dvoslojnu kvotu** koja se temelji na „obavljenom radu” (računalnom opterećenju), a ne na broju poruka.

### Dva sloja

| Sloj                 | Što predstavlja                     | Ciklus osvježavanja                                                         |
| -------------------- | ----------------------------------- | --------------------------------------------------------------------------- |
| **5-satni interval** | Trenutačno dostupna količina „rada” | Poništava se 5 sati nakon prvog zahtjeva u sesiji                           |
| **7-dnevna osnova**  | Fiksno tjedno ograničenje           | Ako se dosegne, nadjačava 5-satno osvježavanje; blokira do idućeg razdoblja |

**Kako se izračunava „obavljeni rad”**: Zadaci koji intenzivno upotrebljavaju agente (npr. „Refaktoriraj cijeli ovaj repozitorij”) troše kvotu mnogo brže od jednostavnih zadataka (npr. „Ispravi ovu funkciju”). Ne postoji nadzorna ploča koja prikazuje potrošnju u stvarnom vremenu.

### Razine planova

| Plan         | Cijena     | Kvota                                 | Tjedno ograničenje                    |
| ------------ | ---------- | ------------------------------------- | ------------------------------------- |
| Free         | $0         | Značajna kvota, osvježava se tjedno   | Da                                    |
| AI Pro       | $19.99/mo  | Visoka kvota, klizno osvježavanje 5 h | Da (nadjačava 5-satno ako se dosegne) |
| AI Ultra 5x  | $99.99/mo  | 5x veća kvota od plana Pro            | Nema tjednog ograničenja              |
| AI Ultra 20x | $199.99/mo | 20x veća kvota od plana Pro           | Nema tjednog ograničenja              |

### Gemini u odnosu na modele koji nisu Gemini

- **Gemini modeli** (Flash + Pro): Dijele jedno ograničenje učestalosti, koje se troši prema cijenama API-ja. Ako je Flash 8x jeftiniji od modela Pro, dobivate 8x više Flash tokena.
- **Modeli koji nisu Gemini** (Claude, GPT-OSS): Imaju **zasebna** ograničenja učestalosti. Mogu ostati dostupni čak i kada je Gemini blokiran.

### AI krediti (prekoračenje)

> Pogledajte [Google One AI krediti](https://support.google.com/googleone/answer/14534406) kako biste saznali kako krediti funkcioniraju.

Kada se osnovna kvota iscrpi:

- **Nikad**: Čeka se osvježavanje kvote; prikazuje se „Dosegnuta je osnovna kvota modela”
- **Uvijek**: Automatski se upotrebljavaju AI krediti; sustav se vraća na osnovnu kvotu kada se ona osvježi

Krediti se kupuju zasebno i oduzimaju prema standardnim cijenama API-ja.

### Ključne pojedinosti

- Kvota se **dijeli na razini računa** — isti Google račun u okruženju Antigravity IDE, CLI-ju i OmniRouteu dijeli jednu kvotu
- Svaki Google račun ima vlastitu neovisnu kvotu — više računa = više kvota
- Korisnici plana AI Pro prijavili su **7-dnevne blokade** umjesto 5-satnih poništavanja kada se dosegne tjedna osnovna kvota (Google je potvrdio da je to namjerno zbog velike potražnje)

**Kada je kvota vašeg računa iscrpljena**: OmniRoute automatski ponovno pokušava sa sljedećim dostupnim računom u kombiniranoj ruti. Nije potrebna ručna intervencija.

## 3. Kako dobiti projectId

Svaka antigravity/agy veza treba Google Cloud Code `projectId`. Bez njega krajnja točka `/v1internal:models` vraća 404.

### Metoda A: Automatski (preporučeno)

OmniRoute to obavlja automatski. Kada putem OAutha na nadzornoj ploči dodate novi Google račun:

1. OmniRoute osvježava token
2. Poziva `loadCodeAssist` kako bi pronašao projectId
3. Ako projekt ne postoji, poziva `onboardUser` kako bi ga izradio
4. Ponovno poziva `loadCodeAssist` kako bi dobio novostvoreni projectId
5. Sprema ga u bazu podataka

**To funkcionira za većinu računa** — nisu potrebni ručni koraci.

### Metoda B: Ručno putem agy CLI-ja

Ako automatsko otkrivanje ne uspije (pogledajte 5. odjeljak da biste saznali kada se to događa):

```bash
# Instalirajte agy CLI (ako već nije instaliran)
npm install -g @anthropic-ai/agy

# Prijavite se svojim Google računom
agy login

# Odaberite račun koji treba registrirati
# Time se pokreće registracija za Cloud Code i dodjeljuje projectId
```

Nakon uspješnog izvršavanja naredbe `agy login`, osvježite token na nadzornoj ploči OmniRoutea. projectId će se automatski pronaći.

### Kako provjeriti

Provjerite bazu podataka:

```bash
# Unutar spremnika OmniRoute
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Ili provjerite zapise:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuth URI za preusmjeravanje

### Problem

Google OAuth zahtijeva valjani URI za preusmjeravanje. OmniRoute prema zadanim postavkama koristi `http://127.0.0.1:20128/callback` (povratna petlja). To funkcionira za lokalne međuverzije, ali **ne funkcionira za udaljene implementacije** (npr. poslužitelj kojem se pristupa putem LAN IP adrese).

Google odbija URI-je za preusmjeravanje koji:

- Upotrebljavaju IP adrese (mora se upotrebljavati domena koja završava s `.com`, `.org` itd.)
- Ne podudaraju se s registriranim URI-jima za preusmjeravanje u konfiguraciji OAuth klijenta

### Rješenje

**Opcija A: Upotrijebite ugrađeni OAuth tijek (zadano)**

- Funkcionira kada OmniRouteu pristupate putem `localhost` ili `127.0.0.1`
- Nije potrebna konfiguracija

**Opcija B: Prilagođene OAuth vjerodajnice**

- Postavite `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` u svojem okruženju
- Navedite vlastite Google OAuth vjerodajnice:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Registrirajte `https://your-domain.com/callback` kao ovlašteni URI za preusmjeravanje u Google Cloud Consoleu

**Opcija C: Upotrijebite agy CLI za početnu prijavu**

- Pokrenite `agy login` na računalu koje će pristupati OmniRouteu
- OAuth tijek dovršava se lokalno, a tokeni se pohranjuju
- Uvezite vezu u OmniRoute putem nadzorne ploče

### Ograničenja

- Prilagođene OAuth vjerodajnice zahtijevaju naziv domene (Google ne prihvaća IP adrese kao URI-je za preusmjeravanje)
- Ako nemate domenu, umjesto toga upotrijebite opciju A ili C

## 5. Otklanjanje poteškoća: kada automatsko postavljanje ne uspije

OmniRoute za većinu računa automatski obavlja otkrivanje vrijednosti projectId i početno postavljanje. Kada to ne uspije, glavni je uzrok obično nešto od sljedećeg:

### Regija računa je blokirana

**Simptom**: `agy login` vraća poruku „Provjera prihvatljivosti nije uspjela: vaš trenutačni račun ne ispunjava uvjete za Antigravity jer trenutačno nije dostupan na vašoj lokaciji.”

**Glavni uzrok**: Google računi imaju pozadinsko polje „Country Association” postavljeno tijekom registracije. agy CLI i Cloud Code API strogo provjeravaju to polje — za razliku od web-verzije Geminija, koja provjerava samo vašu trenutačnu IP adresu.

> Da biste provjerili ili promijenili regiju povezanu sa svojim računom, posjetite [Googleov obrazac za povezivanje zemlje](https://policies.google.com/country-association-form).

**Zašto web-verzija Geminija funkcionira, ali agy ne funkcionira**:

- Web Gemini / Google One: provjerava samo trenutačnu IP adresu (proxy prolazi provjeru)
- agy CLI / Cloud Code API: čita pozadinsko polje Country Association (proxy ne pomaže)

**Rješenje**:

1. Posjetite [Googleov obrazac za povezivanje zemlje](https://policies.google.com/country-association-form) dok upotrebljavate IP adresu iz SAD-a
2. Pošaljite zahtjev za promjenu regije (odaberite „Živim u drugoj zemlji”)
3. Pričekajte od 1 do 24 sata da Google obradi zahtjev i pošalje obavijest e-poštom
4. Nakon toga bi `agy login` trebao uspjeti

### Račun nema Cloud Code projekt

**Simptom**: Zapisi prikazuju `loadCodeAssist returned no project id` i `onboardUser failed (400)`.

**Glavni uzrok**: Račun nikada nije registriran u Google Cloud Codeu, a automatsko početno postavljanje nije uspjelo.

**Rješenje**: Ručno pokrenite `agy login` kako biste pokrenuli registraciju u Cloud Codeu, a zatim osvježite token na OmniRouteovoj nadzornoj ploči.

### Token je istekao ili je opozvan

**Simptom**: Pogreške 401 u zapisima ili poruke „Token je istekao”.

**Rješenje**: Osvježite token putem Nadzorna ploča → Pružatelji usluga → agy → Kliknite ikonu za osvježavanje. Ako je sam token za osvježavanje opozvan, morat ćete se ponovno autentificirati putem OAuth-a.
