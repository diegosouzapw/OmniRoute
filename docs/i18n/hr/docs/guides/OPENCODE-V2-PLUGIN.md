`@omniroute/opencode-plugin-v2` dodaje cijeli vaš OmniRoute katalog — modele, kombinacije i
automatske kombinacije — u OpenCode v2 odabirnik modela, zajedno s nazivima za prikaz, cijenama i
ograničenjima besplatne razine.

To je zaseban paket od paketa `@omniroute/opencode-plugin` jer OpenCode v1 i v2 učitavaju
dodatke putem različitih ugovora. Odaberite onaj koji odgovara vašoj glavnoj verziji OpenCodea; ništa se
ne dijeli između njih, pa nadogradnja jednog nikada ne zahtijeva nadogradnju drugog.

## Preduvjeti

- OpenCode v2.
- Dostupan OmniRoute pristupnik (`http://localhost:20128` prema zadanim postavkama).
- Node.js 22 ili 24.

## Instalacija

Dodajte dodatak u `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modeli će se zatim prikazivati kao `omniroute/<provider>/<model>`; `providerId` određuje taj prefiks i
ID integracije pod kojim OpenCode pohranjuje vjerodajnicu.

## Vjerodajnice

Dodatak traži ključ pristupnika na tri mjesta, ovim redoslijedom:

1. **Vjerodajnica koju ste povezali u OpenCodeu.** Dodatak registrira integraciju kako bi
   OpenCodeov vlastiti tijek autentifikacije mogao pohraniti ključ. Ništa se ne sprema u `opencode.json` — preporučuje se ova mogućnost.
2. `apiKey` u opcijama dodatka, za nadjačavanje po projektu. Time se ključ stavlja u datoteku koju
   možda predajete u repozitorij.
3. `OMNIROUTE_API_KEY` u okruženju.

Ako nije navedena nijedna od te tri mogućnosti, katalog je prazan i dodatak to jednom navodi pri pokretanju, umjesto
da vam ostavi prazan odabirnik bez objašnjenja.

### Token za upravljanje zaseban je ključ

Kombinacije, stanje pružatelja i obogaćivanje (nazivi za prikaz, cijene i ograničenja besplatne razine) dolaze s
krajnjih točaka pristupnika `/api/*`, koje većina implementacija štiti **upravljačkim** tokenom,
a ne ključem za zaključivanje:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<upravljački token za čitanje>"
}
```

Ako nije postavljen, `managementReadToken` vraća se na `apiKey`. Kada pristupnik odbije tu zamjensku vrijednost,
katalog se i dalje objavljuje, ali sa sirovim ID-ovima modela umjesto naziva za prikaz, bez uklanjanja duplikata
kanonskih pseudonima, bez cijena i bez kombinacija. Dodatak jednom upozorava za svaku krajnju točku kada se to dogodi,
navodeći krajnju točku i što je izgubljeno — tako degradirani odabirnik nikada nije zagonetka.

## Opcije

| Ključ                            | Zadana vrijednost                                | Napomene                                                                                                               |
| -------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                    | ID pružatelja, ID integracije i prefiks pod kojim se modeli prikazuju                                                  |
| `baseURL`                        | obavezno                                         | Korijen pristupnika, samo `http(s)`; sufiks `/v1` dodaje se gdje je potreban                                           |
| `apiKey`                         | povezana vjerodajnica, zatim `OMNIROUTE_API_KEY` | Ključ za razgovor za `/v1/*`                                                                                           |
| `managementReadToken`            | vraća se na `apiKey`                             | Ključ za `/api/*` — obično **nije** isti                                                                               |
| `displayName`                    | `"OmniRoute"`                                    | Naziv pružatelja u odabirniku                                                                                          |
| `timeoutMs`                      | `10000`                                          | Vremensko ograničenje dohvaćanja po krajnjoj točki (automatske kombinacije koriste 5 s)                                |
| `modelCacheTtlMs`                | `300000`                                         | TTL predmemorije kataloga; snimka na disku ubrzava hladna pokretanja                                                   |
| `timeouts`                       | vraća se na `timeoutMs`                          | Vremenska ograničenja po krajnjoj točki u ms: `models`, `combos`, `autoCombos`, `enrichment`                           |
| `enrichment`                     | `true`                                           | Dohvaćanje naziva, cijena i ograničenja besplatne razine                                                               |
| `providerTag`                    | `true`                                           | Dodavanje prefiksa s uzvodnim pružateljem kojem se zahtjev usmjerava nazivu za prikaz                                  |
| `usableOnly`                     | `false`                                          | Zadržavanje samo pružatelja za koje pristupnik prijavljuje da su konfigurirani                                         |
| `visibleModels` / `hiddenModels` | `[]`                                             | Popisi dopuštenih vrijednosti s točnim podudaranjem ili podudaranjem sufiksa; zabrana ima prednost                     |
| `geminiSanitization`             | `true`                                           | Uklanjanje ključnih riječi JSON-Schema koje Gemini odbija iz shema alata (alati s `$ref` prosljeđuju se neizmijenjeni) |
| `apiFormat.allowAnthropic`       | `false`                                          | Usmjeravanje dopuštenih ID-ova kroz blok Anthropic API-ja                                                              |
| `apiFormat.anthropicModels`      | `[]`                                             | Puni ID-ovi modela koji se usmjeravaju prema Anthropicu                                                                |
| `logLevel` / `startupDebug`      | `warn` / `false`                                 | Opširnost zapisnika                                                                                                    |

## Kako katalog ostaje ažuran

Katalog se dohvaća po potrebi i sprema u predmemoriju tijekom `modelCacheTtlMs`, a snimka na disku omogućuje dostupnost
posljednjeg poznatog kataloga kada pristupnik nije dostupan — prekid rada ne košta vas ništa osim
ažurnosti. Modeli i kombinacije objavljuju se čim stignu; automatske kombinacije, popis pružatelja
i sloj obogaćivanja uključuju se kada stignu, tako da jedna spora krajnja točka ne može blokirati
cijeli izbornik.

Nazivi sadrže ono što pristupnik zna: izvornog pružatelja kojem se model usmjerava, oznaku `[Free]`
i pripadajući budžet — tako da se dvije veze koje nude isti model i dalje mogu
razlikovati. Isključite prefiks s `"providerTag": false`.

Ne postoji naredba za ručno osvježavanje: naredbe sustava OpenCode v2 predlošci su upita, a ne povratni pozivi,
pa je dodatak ne može izložiti. Osvježavanja slijede TTL; od glavnog se sustava traži ponovno učitavanje samo kada
se katalog ili sloj doista promijeni, nikada pri svakom osvježavanju.

## Pozivanje alata na Geminiju

Gemini odbija cijeli zahtjev čije deklaracije alata sadrže `$schema` ili
`additionalProperties`, odgovarajući s `400 INVALID_ARGUMENT`. Dodatak uklanja te ključne riječi iz
shema alata namijenjenih Gemini modelu ovog pružatelja, a svaki drugi zahtjev ostavlja netaknutim.
Alat koji sadrži `$ref` prosljeđuje se netaknut umjesto da se iz njega uklanjaju ključne riječi jer bi uklanjanje
reference proširilo shemu tako da „prihvaća bilo što”.
Postavite `"geminiSanitization": false` da biste to isključili.

## Rješavanje problema

| Simptom                                             | Uzrok                                                                                                        |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Izbornik ne prikazuje nijedan OmniRoute model       | Nije pronađen ključ (provjerite upozorenje pri pokretanju) ili pristupnik nije dostupan                      |
| Neobrađeni ID-jevi modela, bez kombinacija i cijena | Krajnje točke za upravljanje odbile su token — postavite `managementReadToken`                               |
| Sesija prikvačena na `opencode-<id>/…`              | Dodatak v1 objavio je `opencode-<id>`; v2 objavljuje samo `<id>`, stoga ponovno odaberite model pod `<id>/…` |
