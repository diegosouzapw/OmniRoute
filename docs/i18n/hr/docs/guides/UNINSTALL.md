## Brza deinstalacija (v3.6.2+)

OmniRoute nudi dvije ugrađene skripte za čisto uklanjanje:

### Sačuvajte svoje podatke

```bash
npm run uninstall
```

Ova naredba uklanja OmniRoute aplikaciju, ali **čuva** vašu bazu podataka, konfiguracije, API ključeve i postavke pružatelja usluga u `~/.omniroute/`. Koristite ovu opciju ako planirate ponovnu instalaciju kasnije i želite sačuvati svoju postavku.

### Potpuno uklanjanje

```bash
npm run uninstall:full
```

Ova naredba uklanja aplikaciju **i trajno briše** sve podatke:

- Bazu podataka (`storage.sqlite`)
- Konfiguracije pružatelja usluga i API ključeve
- Datoteke sigurnosnih kopija
- Datoteke zapisa (log)
- Sve datoteke u direktoriju `~/.omniroute/`

> ⚠️ **Upozorenje:** `npm run uninstall:full` je nepovratno. Sve vaše veze s pružateljima usluga, kombinacije, API ključevi i povijest korištenja bit će trajno izbrisani.

## Ručno uklanjanje

### NPM globalna instalacija

```bash
# Ukloni globalni paket
npm uninstall -g omniroute

# (Neobavezno) Ukloni direktorij s podacima
rm -rf ~/.omniroute
```

### pnpm globalna instalacija

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Zaustavi i ukloni kontejner
docker stop omniroute
docker rm omniroute

# Ukloni volume (briše sve podatke)
docker volume rm omniroute-data

# (Neobavezno) Ukloni image
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Zaustavi i ukloni kontejnere
docker compose down

# Ukloni i volumeove (briše sve podatke)
docker compose down -v
```

### Electron desktop aplikacija

**Windows:**

- Otvori `Settings → Apps → OmniRoute → Uninstall`
- Ili pokreni NSIS deinstalacijski program iz direktorija za instalaciju

**macOS:**

- Povuci `OmniRoute.app` iz `/Applications` u Trash
- Ukloni podatke: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Ukloni AppImage datoteku
- Ukloni podatke: `rm -rf ~/.omniroute`

### Instalacija iz izvornog koda (git clone)

```bash
# Ukloni kloniranu mapu
rm -rf /path/to/omniroute

# (Neobavezno) Ukloni direktorij s podacima
rm -rf ~/.omniroute
```

## Direktoriji s podacima

OmniRoute pohranjuje podatke na sljedećim lokacijama prema zadanim postavkama:

| Platforma      | Zadana putanja                  | Zamjena                         |
| -------------- | ------------------------------- | ------------------------------- |
| Linux          | `~/.omniroute/`                 | `DATA_DIR` env varijabla        |
| macOS          | `~/.omniroute/`                 | `DATA_DIR` env varijabla        |
| Windows        | `%APPDATA%/omniroute/`          | `DATA_DIR` env varijabla        |
| Docker         | `/app/data/` (montirani volume) | `DATA_DIR` env varijabla        |
| Sukladno s XDG | `$XDG_CONFIG_HOME/omniroute/`   | `XDG_CONFIG_HOME` env varijabla |

### Datoteke u direktoriju s podacima

| Datoteka/Direktorij  | Opis                                                               |
| -------------------- | ------------------------------------------------------------------ |
| `storage.sqlite`     | Glavna baza podataka (dobavljači, kombinacije, postavke, ključevi) |
| `storage.sqlite-wal` | SQLite write-ahead log (privremeno)                                |
| `storage.sqlite-shm` | SQLite shared memory (privremeno)                                  |
| `call_logs/`         | Arhive tereta zahtjeva                                             |
| `backups/`           | Automatske sigurnosne kopije baze podataka                         |
| `log.txt`            | Naslijeđeni zapisnik zahtjeva (neobavezno)                         |

## Provjera potpunog uklanjanja

Nakon deinstalacije, provjerite da nisu preostale nikakve datoteke:

```bash
# Provjeri postoji li globalni npm paket
npm list -g omniroute 2>/dev/null

# Provjeri postoji li direktorij s podacima
ls -la ~/.omniroute/ 2>/dev/null

# Provjeri postoje li aktivni procesi
pgrep -f omniroute
```

Ako je bilo koji proces još aktivan, zaustavite ga:

```bash
pkill -f omniroute
```
