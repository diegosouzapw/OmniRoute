> **Ukratko**: OmniRoute rangira svoje **besplatne** pružatelje prema kvaliteti modela koristeći **Arena AI
> ELO rezultate (u stilu LMArene)**. Otvorite stranicu **Rangiranje besplatnih pružatelja** na
> nadzornoj ploči kako biste vidjeli koji besplatni pružatelji nude najbolje modele za vaš zadatak —
> ukupno ili filtrirano prema kategoriji (programiranje, pregled, dokumentacija, otklanjanje pogrešaka).

---

## Što je to

OmniRoute registrira 329 pružatelja, uključujući 155 kataloških stavki označenih kao **besplatne/bez autentifikacije**
(bez autentifikacije,
OAuth s besplatnom razinom ili API ključ s besplatnom razinom — pogledajte
[Vodič kroz besplatne razine](../getting-started/FREE-TIERS-GUIDE.md) i cijeli
[Direktorij besplatnih razina](../reference/FREE_TIERS.md)). Problem je u tome što se kvaliteta modela
besplatnih pružatelja znatno razlikuje. Pružatelj bez autentifikacije koji nudi vrhunski model mnogo je korisniji
od onoga koji nudi mali zastarjeli model.

**Rangiranje besplatnih pružatelja** odgovara na pitanje „**koji mi besplatni pružatelj daje najbolji model?**”
povezivanjem kataloga svakog besplatnog pružatelja s **rezultatima kvalitete dobivenima od zajednice** s
**Arena AI ljestvice** (ELO na temelju ljudskih preferencija, isti koncept na kojem se temelji LMArena
arena chatbotova). Pružatelji se zatim rangiraju prema kvaliteti svojeg **najboljeg besplatnog modela**.

Rangiranje se izračunava iz tri stvarna izvora:

1. Popisi besplatnih pružatelja — `NOAUTH_PROVIDERS`, uz stavke `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` označene s `hasFree`
   (`src/shared/constants/providers.ts`).
2. Katalog modela svakog pružatelja iz registra pružatelja
   (`open-sse/config/providerRegistry.ts`).
3. Rezultati prikladnosti za zadatak izvedeni iz ELO-a, koje mehanizam
   za sinkronizaciju Arena ELO-a pohranjuje u DB tablicu `model_intelligence` (`src/lib/arenaEloSync.ts`).

Logika povezivanja nalazi se u `src/lib/freeProviderRankings.ts`.

## Kako pristupiti

### Stranica nadzorne ploče

Otvorite nadzornu ploču i idite na **Troškovi → Rangiranje besplatnih pružatelja** ili izravno otvorite:

```
/dashboard/free-provider-rankings
```

Stranica (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) prikazuje:

- **Postolje za prva 3 mjesta** (🥇 🥈 🥉) najbolje rangiranih besplatnih pružatelja.
- Potpunu **tablicu rangiranja** sa stupcima: **Rang**, **Pružatelj**, **Najbolji model**,
  **Rezultat**, **Prosječni rezultat**, **Modeli**, **Vrsta**.
- **Gumbe za filtriranje kategorija**: _Sve kategorije_, _Zadano_, _Programiranje_, _Pregled_,
  _Dokumentacija_, _Otklanjanje pogrešaka_.

Oznaka **Vrsta** svakog pružatelja pokazuje na koji je način besplatan:

| Oznaka   | Značenje                                              |
| -------- | ----------------------------------------------------- |
| `NOAUTH` | Uvijek besplatan, vjerodajnice nisu potrebne          |
| `OAUTH`  | OAuth pružatelj s besplatnom razinom (`hasFree`)      |
| `APIKEY` | Pružatelj API ključa s besplatnom razinom (`hasFree`) |

Rezultati se prikazuju kao lako razumljive oznake (npr. _Elitan_, _Izvrstan_, _Vrlo dobar_,
_Dobar_, _Prosječan_), a ne kao neobrađeni brojevi jer je temeljna vrijednost relativna
ocjena kvalitete, a ne postotak.

### API krajnja točka

Stranica se temelji na javnoj krajnjoj točki za čitanje
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parametri upita (validirani pomoću Zoda):

| Parametar  | Vrsta  | Zadano | Napomene                                                                                                    |
| ---------- | ------ | ------ | ----------------------------------------------------------------------------------------------------------- |
| `category` | string | (nema) | Jedno od `default`, `coding`, `review`, `documentation`, `debugging`. Izostavite za kombinirano rangiranje. |
| `limit`    | number | `50`   | Ograničeno na raspon `1–100`.                                                                               |

Struktura odgovora:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` je izvorna Arena ELO vrijednost; `score` je normalizirana vrijednost prikladnosti za zadatak
(pogledajte u nastavku). Pružatelji bez ocijenjenih modela izostavljaju se iz odgovora.

## Kako funkcioniraju bodovi

### Izvor: ljestvica Arena AI

Mehanizam za sinkronizaciju Arena ELO-a (`src/lib/arenaEloSync.ts`) dohvaća dvije ljestvice — `text`
i `code` — iz API-ja ljestvice Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Svaki unos na ljestvici
sadrži naziv modela, dobavljača, ELO `score`, interval pouzdanosti i broj glasova.

Kategorije ljestvice preslikavaju se u kategorije zadataka OmniRoutea:

| Ljestvica Arena | Kategorije zadataka OmniRoutea                    |
| --------------- | ------------------------------------------------- |
| `text`          | `default`, `review`, `documentation`, `debugging` |
| `code`          | `coding`                                          |

### Normalizacija (ocjena prikladnosti za zadatak)

Neobrađeni ELO bodovi normaliziraju se zasebno za svaku ljestvicu u **vrijednost prikladnosti za zadatak u rasponu `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Ocjena nikada ne doseže `0` ni `1`, čime se ostavlja prostor za korisničke prilagodbe. To je
polje `score` koje vidite u odgovoru API-ja i oznaka prikazana na nadzornoj ploči.

### Pouzdanost

Svaki unos dobiva razinu pouzdanosti na temelju broja glasova u Areni:

| Pouzdanost | Glasovi |
| ---------- | ------- |
| `high`     | ≥ 5.000 |
| `medium`   | ≥ 1.000 |
| `low`      | < 1.000 |

### Pohrana i svježina podataka

Normalizirani unosi zapisuju se u tablicu baze podataka `model_intelligence` uz
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Unosi **ističu nakon
7 dana**, pa se dobavljač koji se prestane sinkronizirati s vremenom uklanja umjesto da poslužuje
zastarjele podatke.

Sinkronizacija je **uključena prema zadanim postavkama**:

- Pokreće se jednom pri pokretanju poslužitelja, a zatim periodično prema vremenskom rasporedu
  (`src/lib/arenaEloSync.ts`, povezano iz `src/instrumentation-node.ts`).
- **Ne blokira rad i nikada nije kobna** — ako dohvaćanje iz vanjskog izvora ne uspije, OmniRoute nastavlja
  raditi, a ljestvice jednostavno prikazuju posljednje valjane podatke (ili prazno stanje).

Njome upravljaju dvije varijable okruženja (dokumentirane u
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Varijabla                 | Zadana vrijednost | Svrha                                                              |
| ------------------------- | ----------------- | ------------------------------------------------------------------ |
| `ARENA_ELO_SYNC_ENABLED`  | `true`            | Postavite na `false` kako biste isključili izlaznu sinkronizaciju. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h)     | Interval sinkronizacije u sekundama.                               |

### Ručna sinkronizacija / status / brisanje

Operatorima je na raspolaganju autentificirana upravljačka krajnja točka za ručno upravljanje
(`src/app/api/intelligence/sync/route.ts` — zahtijeva upravljačku autentifikaciju):

```
GET    /api/intelligence/sync          # trenutačni status sinkronizacije (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # pokretanje ručne sinkronizacije; tijelo: { "dryRun": true } za pregled bez zapisivanja
DELETE /api/intelligence/sync          # brisanje svih sinkroniziranih arena_elo unosa inteligencije
```

Ako je stranica s ljestvicama prazna, ručni `POST /api/intelligence/sync` (ili jednostavno
ponovno pokretanje poslužitelja) ponovno će je popuniti.

### Usklađivanje modela s ljestvicom

ID-jevi modela u registru i nazivi modela u Areni ne podudaraju se uvijek u potpunosti. Rangiranje koristi
fleksibilno usklađivanje (`findMatchingIntelligence` u `src/lib/freeProviderRankings.ts`):

1. Točno podudaranje prema normaliziranom ID-ju modela.
2. Podudaranje nakon uklanjanja završnog sufiksa verzije (npr. `kimi-k2.6` → `kimi-k2`).
3. Podudaranje prefiksa (naziv modela na ljestvici prefiks je ID-ja u registru).

Tijekom sinkronizacije uklanjaju se poznati prefiksi dobavljača (`anthropic/`, `openai/`, `google/`, …),
a mala mapa pseudonima proširuje kanonske nazive na varijante koje OmniRoute koristi
interno, tako da modele ostaje moguće pronaći pod bilo kojim nazivom.

### Kako se dobavljač rangira

Za svakog besplatnog dobavljača mehanizam ocjenjuje svaki model u njegovu katalogu, a zatim:

- **Najbolji model** = model dobavljača s najvišom ocjenom.
- **Prosječna ocjena** = srednja vrijednost ocjena svih ocijenjenih modela tog dobavljača.
- **Modeli** = broj modela dobavljača koji su imali ocjenu Arene.

Dobavljači se najprije razvrstavaju prema **ocjeni najboljeg modela**, a zatim prema prosječnoj ocjeni. Time se nagrađuje
dobavljač koji nudi barem jedan kvalitetan besplatan model.

## Kako ga koristiti za odabir besplatnih pružatelja usluga

1. **Odaberite odgovarajuću kategoriju.** Upotrijebite filtar **Coding** za agentska/programerska radna opterećenja ili
   ostavite **All Categories** / **Default** za opći razgovor. Isti pružatelj usluga može
   biti različito rangiran u različitim kategorijama jer se njegov najbolji model razlikuje ovisno o ljestvici.
2. **Za jednokratne postavke preferirajte vodeća mjesta.** Ako želite povezati samo jednog ili dva besplatna
   pružatelja usluga, započnite s najbolje rangiranima u svojoj kategoriji.
3. **Provjerite oznaku Type.** Pružatelji usluga `NOAUTH` najbrže se povezuju (bez
   vjerodajnica). Besplatne razine `OAUTH` / `APIKEY` zahtijevaju brzu registraciju, ali često nude
   naprednije modele. Korake za povezivanje potražite u [Vodiču za besplatne razine](../getting-started/FREE-TIERS-GUIDE.md).
4. **Povežite nekoliko pružatelja i prepustite odabir značajci Auto-Combo.** Isti podaci Arena ELO koji pokreću
   ovu stranicu također se koriste za **faktor prikladnosti za zadatak** mehanizma bodovanja Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, redoslijed razrješavanja:
   `user_override → arena_elo → models_dev_tier → static table`). Nakon što povežete
   najbolje besplatne pružatelje usluga, usmjeravanje s `model: "auto"` (npr. `auto/coding`) automatski će
   davati prednost kvalitetnijim besplatnim modelima za svaki zahtjev. Potpuni sustav bodovanja sa 16 faktora
   potražite u dokumentu [Auto-Combo](../routing/AUTO-COMBO.md).
