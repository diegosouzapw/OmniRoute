> **Izvor istine:** `src/lib/obsidian/api.ts` (REST + klijent za sinkronizaciju),
> `src/lib/db/obsidian.ts` (pohrana tokena / osnovnog URL-a / WebDAV-a),
> `src/lib/obsidianSync.ts` (WebDAV sinkronizacija trezora), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP alata), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API-ji postavki). Registracija alata
> i povezivanje opsega nalaze se u `open-sse/mcp-server/server.ts`.

## Što je to

OmniRoute povezuje se s **Obsidian** trezorom kao **izvorom konteksta** — lokalnom bazom
znanja u Markdownu koju agenti čitaju i zapisuju putem ugrađenog MCP poslužitelja.
Integracija komunicira s dodatkom zajednice **Obsidian Local REST API** koji se izvodi
unutar aplikacije za stolna računala, pa agenti mogu pretraživati bilješke, čitati,
zapisivati i parcijalno mijenjati datoteke, pregledavati sadržaj trezora, raditi s
dnevnim i tjednim periodičnim bilješkama, upravljati oznakama, pokretati naredbe
Obsidiana te, opcionalno, koordinirati dvosmjernu sinkronizaciju trezora između
stolnog i mobilnog uređaja.

Klijent (`src/lib/obsidian/api.ts`) obavija Local REST API sljedećim mogućnostima:

- **Ponovni pokušaj uz odgodu** za privremene pogreške `5xx`, **istek nakon 30 sekundi** putem `AbortController`.
- **Klasifikacija pogrešaka prema tipu** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Razumljiva uputa za slučaj kada „nije moguće pristupiti Obsidianu”** koja upozorava
  na čestu pogrešku s priključkom (HTTP na `27123`, **ne** MCP krajnja točka na `27124`)
  i navodi oblik adrese za Tailscale.
- **Kodiranje putanja** relativnih u odnosu na trezor kako bi putanje bilješki s razmacima i kosim crtama bile sigurne.

## Postavljanje

Za Obsidian token ili osnovni URL **ne postoji varijabla okruženja** — oboje se
pohranjuje u SQLite tablici `key_value` (imenski prostor `obsidian`) putem
`src/lib/db/obsidian.ts`. Token je **šifriran u mirovanju** (AES-256-GCM, uz rezervnu
podršku za običan tekst radi kompatibilnosti unatrag). Konfigurirajte ga na kartici
**Izvori konteksta** nadzorne ploče krajnje točke (`ObsidianSourceCard`) ili putem
REST API-ja postavki.

> [!IMPORTANT]
> Dodatak **Obsidian Local REST API** mora biti instaliran i pokrenut. Njegovo REST
> sučelje sluša na adresi **HTTP `127.0.0.1:27123`** (zadani osnovni URL). Priključak
> `27124` je _zasebna_ MCP/HTTPS krajnja točka i ruta postavki izričito ga odbija.
> Ako se povezujete s drugog uređaja, upotrijebite `http://<tailscale-ip>:27123`.

### Konfiguracijski ključevi (SQLite `key_value`, imenski prostor `obsidian`)

| Ključ             | Namjena                                                      | Šifrirano |
| ----------------- | ------------------------------------------------------------ | --------- |
| `api_key`         | Token nositelja za Local REST API                            | da        |
| `base_url`        | Osnovni REST URL (zadano `http://127.0.0.1:27123`)           | ne        |
| `vault_path`      | Apsolutna putanja do direktorija trezora (za sinkronizaciju) | ne        |
| `webdav_username` | Generirano WebDAV korisničko ime (sinkronizacija trezora)    | ne        |
| `webdav_password` | Generirana WebDAV lozinka (sinkronizacija trezora)           | da        |
| `webdav_enabled`  | Je li omogućena WebDAV sinkronizacija trezora                | ne        |

### Konfiguriranje putem REST-a

```bash
# Spremanje i provjera valjanosti tokena za Local REST API (POST ga provjerava putem provjere statusa)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Provjera statusa veze (vraća connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Prekid veze (briše pohranjeni token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Sve metode zahtijevaju autentifikaciju na nadzornoj ploči. `POST` odbija svaki URL na
priključku `27124` i prije pohranjivanja provjerava valjanost tokena pozivanjem krajnje
točke statusa Local REST API-ja.

### WebDAV sinkronizacija trezora

`src/app/api/settings/obsidian/webdav/route.ts` upravlja opcionalnom sinkronizacijom
trezora temeljenom na WebDAV-u (koju pokreće `src/lib/obsidianSync.ts`). Njezinim
omogućivanjem OmniRoute se usmjerava na lokalni direktorij trezora i generira se
nasumični par WebDAV korisničkog imena i lozinke:

```bash
# Omogućivanje WebDAV sinkronizacije za direktorij trezora (generira korisničko ime i lozinku)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Dohvaćanje statusa WebDAV sinkronizacije (vjerodajnice se vraćaju samo dok je omogućena)
curl http://localhost:20128/api/settings/obsidian/webdav

# Onemogućivanje WebDAV sinkronizacije (briše vjerodajnice i upravljanu datoteku .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Izvor konteksta po API ključu (opcionalno)

Konfiguracija Obsidiana može se ograničiti **na pojedini API ključ** putem tablice
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Kada MCP poziv sadrži
ID autentificiranog API ključa, `getObsidianConfigForApiKey()` daje prednost vlastitom
tokenu, osnovnom URL-u i putanji trezora tog ključa (`source: "api_key"`), a u suprotnom
se vraća na globalnu konfiguraciju (`source: "global"`).

## MCP alati (22)

Definirani su u `open-sse/mcp-server/tools/obsidianTools.ts`. Token/osnovni URL određuju se
pri svakom pozivu (prvo prema API ključu, a zatim globalno). Alati koji pristupaju OmniRoute **poslužitelju za sinkronizaciju**
(četiri alata `obsidian_sync_*`) dodatno zahtijevaju autentifikacijski token za sinkronizaciju konfiguriran
u postavkama OmniRoutea.

### Alati za čitanje (`read:obsidian`)

| Alat                         | Opis                                                                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Provjerava je li lokalni REST API dostupan i autentificiran.                                                                  |
| `obsidian_search_simple`     | Pretražuje puni tekst sadržaja bilješki; vraća isječke s putanjama datoteka.                                                  |
| `obsidian_search_structured` | Pretražuje pomoću JSON Logic izraza (filtri and/or/regex/path).                                                               |
| `obsidian_read_note`         | Čita bilješku prema putanji relativnoj u odnosu na trezor; po želji određeni naslov/blok/frontmatter.                         |
| `obsidian_list_vault`        | Navodi datoteke i direktorije u trezoru (stablo stavki).                                                                      |
| `obsidian_get_document_map`  | Dohvaća strukturu naslova bilješke kao mapu naslova → brojevi redaka.                                                         |
| `obsidian_get_note_metadata` | Dohvaća frontmatter, oznake, poveznice te broj znakova/riječi bez punog sadržaja.                                             |
| `obsidian_get_active_file`   | Dohvaća putanju i sadržaj trenutačno aktivne datoteke u Obsidianu.                                                            |
| `obsidian_get_periodic_note` | Dohvaća dnevnu/tjednu/mjesečnu periodičnu bilješku za datum (danas ako je izostavljen).                                       |
| `obsidian_get_tags`          | Navodi sve oznake trezora s njihovim učestalostima.                                                                           |
| `obsidian_list_commands`     | Navodi dostupne ID-ove naredbi Obsidiana (upotrebljava se s `obsidian_execute_command`).                                      |
| `obsidian_sync_status`       | Status OmniRoute poslužitelja za sinkronizaciju: radi li, naziv trezora, priključak, vrijeme rada, posljednja sinkronizacija. |
| `obsidian_sync_conflicts`    | Navodi neriješene sukobe sinkronizacije (putanja, putanja sukoba, vrijeme otkrivanja).                                        |

### Alati za pisanje (`write:obsidian`)

| Alat                             | Opis                                                                                                     |
| -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Stvara ili prepisuje bilješku zadanim Markdown sadržajem.                                                |
| `obsidian_append_note`           | Dodaje sadržaj bilješci; po želji određenom naslovu/bloku.                                               |
| `obsidian_patch_note`            | Precizno dodaje ispred/iza ili zamjenjuje sadržaj naslova, bloka ili polja frontmattera.                 |
| `obsidian_delete_note`           | Trajno briše bilješku iz trezora.                                                                        |
| `obsidian_move_note`             | Premješta ili preimenuje bilješku unutar trezora.                                                        |
| `obsidian_execute_command`       | Izvršava naredbu Obsidiana prema njezinu ID-u naredbe.                                                   |
| `obsidian_open_file`             | Otvara datoteku u Obsidianu (stvara je ako ne postoji).                                                  |
| `obsidian_sync_trigger`          | Pokreće trenutačnu dvosmjernu sinkronizaciju trezora između računala i mobilnog uređaja.                 |
| `obsidian_sync_resolve_conflict` | Razrješava sukob sinkronizacije: zadržava `local` (mobilni uređaj), `remote` (računalo) ili `keep-both`. |

> [!NOTE]
> Ciljevi alata `obsidian_patch_note` prihvaćaju `targetType` vrijednosti `heading | block | frontmatter`
> i `operation` vrijednosti `append | prepend | replace`, uz neobavezni
> `createTargetIfMissing`. Četiri alata `obsidian_sync_*` komuniciraju s lokalnim
> poslužiteljem za sinkronizaciju (`http://127.0.0.1:27781` prema zadanim postavkama) i zahtijevaju token za sinkronizaciju.

### Opsezi

Alati za čitanje zahtijevaju `read:obsidian`; alati za pisanje zahtijevaju `write:obsidian`. Provedba
je identična kao za Notion — obrađuje je `withScopeEnforcement()` u
`open-sse/mcp-server/server.ts`, uvjetovana postavkom `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, pri čemu
dopušteni opsezi dolaze iz `OMNIROUTE_MCP_SCOPES` ili konteksta opsega API ključa. Pogledajte
[MCP-SERVER.md](./MCP-SERVER.md).

## Krajnje točke

| Metoda   | Putanja                         | Svrha                                                                   |
| -------- | ------------------------------- | ----------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Vraća `{ connected, hasToken, baseUrl, vaultPath }`.                    |
| `POST`   | `/api/settings/obsidian`        | Sprema i provjerava token (odbija port `27124`).                        |
| `DELETE` | `/api/settings/obsidian`        | Prekida vezu (briše spremljeni token).                                  |
| `GET`    | `/api/settings/obsidian/webdav` | Status sinkronizacije putem WebDAV-a i vjerodajnice (dok je omogućena). |
| `POST`   | `/api/settings/obsidian/webdav` | Omogućuje sinkronizaciju putem WebDAV-a za direktorij trezora.          |
| `DELETE` | `/api/settings/obsidian/webdav` | Onemogućuje sinkronizaciju putem WebDAV-a.                              |

> Ovo su rute postavki nadzorne ploče. Samom se trezoru pristupa putem lokalnog REST API-ja
> Obsidiana (konfiguriranog `base_url`) i putem gore navedenih MCP alata — ne postoji
> javna krajnja točka Obsidian proxyja `/v1`.

## Slučajevi upotrebe

- **Odgovori utemeljeni na trezoru** — `obsidian_search_simple` / `obsidian_search_structured`,
  a zatim `obsidian_read_note`, kako bi agent odgovarao na temelju vaših stvarnih bilješki.
- **Pisanje bilješki / vođenje dnevnika** — `obsidian_write_note`, `obsidian_append_note` ili
  precizni `obsidian_patch_note` za zapisivanje rezultata rada agenta, sažetaka ili dnevnih bilješki
  (`obsidian_get_periodic_note`) u trezor.
- **Navigacija trezorom** — `obsidian_list_vault`, `obsidian_get_document_map` i
  `obsidian_get_tags` za istraživanje strukture prije čitanja/pisanja.
- **Automatizacija Obsidiana** — `obsidian_list_commands` + `obsidian_execute_command` za
  pokretanje dodataka/naredbi putem agenta; `obsidian_open_file` za prikaz bilješke u korisničkom sučelju.
- **Mobilna sinkronizacija** — omogućite sinkronizaciju putem WebDAV-a, a zatim upotrijebite `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  za koordinaciju između stolnog i mobilnog uređaja te rješavanje sukoba.
