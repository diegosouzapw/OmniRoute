> **Izvor istine:** `src/lib/localCorpus/index.ts` (ograničeni indeks teksta),
> `src/lib/localCorpus/configured.ts` (konfigurirano izvršno okruženje),
> `src/lib/db/localCorpus.ts` (trajna pohrana korijenske putanje),
> `open-sse/mcp-server/tools/localCorpusTools.ts` (3 MCP alata samo za čitanje) i
> `src/app/api/settings/local-corpus/route.ts` (API za postavke).

## Što je to

Local Corpus omogućuje operateru da MCP poslužitelju OmniRoutea izloži jedan izričito odobreni direktorij tekstnih datoteka. Datoteke ostaju u izvornom direktoriju: OmniRoute u SQLiteu pohranjuje samo kanonsku korijensku putanju i održava indeks pretraživanja u memoriji. Sadržaj korpusa ne kopira se u repozitorij ni u bazu podataka.

Indeks se osvježava inkrementalno. Nepromijenjene datoteke ponovno se upotrebljavaju na temelju veličine i vremena izmjene, promijenjene datoteke ponovno se čitaju i sažimaju algoritmom SHA-256, a izbrisane datoteke uklanjaju se. Pretraživanje osvježava indeks stariji od 30 sekundi; pozivatelji također mogu zatražiti trenutačno osvježavanje.

## Konfiguriranje izvora

Ruta za postavke zahtijeva istu autentifikaciju za upravljanje kao i ostali API-ji za postavke. Poslana putanja mora već postojati i mora biti apsolutna putanja direktorija.

```bash
# Povežite odobreni direktorij
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Provjerite konfiguraciju i status indeksa
curl http://localhost:20128/api/settings/local-corpus

# Prekinite vezu bez izmjene izvornih datoteka
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP alati

Sva tri alata zahtijevaju `read:local-corpus`. Odgovori alata prikazuju relativne putanje i osnovni naziv korijenskog direktorija, ali nikada njegovu apsolutnu putanju.

| Alat                  | Opis                                                                                           |
| :-------------------- | :--------------------------------------------------------------------------------------------- |
| `local_corpus_status` | Prijavljuje stanje konfiguracije, veličinu indeksa, ograničenja i vrijeme zadnjeg osvježavanja |
| `local_corpus_search` | Pretražuje indeksirani tekst i vraća ograničene isječke po retcima (do 20 rezultata)           |
| `local_corpus_read`   | Čita ograničeni raspon redaka iz jedne dopuštene datoteke relativne u odnosu na korpus         |

Primjeri MCP ulaza:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Sigurnosna ograničenja

- Popis dopuštenih vrsta usmjeren je na tekst: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` i `.yml`.
- Simboličke veze preskaču se. Putanje za čitanje kanoniziraju se i moraju ostati unutar
  konfiguriranog korijena; apsolutne putanje i pokušaji prolaska kroz direktorije odbijaju se.
- Izuzimaju se osjetljivi i generirani nazivi direktorija: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` i
  `secrets`.
- Zadana ograničenja iznose 5.000 datoteka, 1 MiB po datoteci, ukupno 64 MiB indeksiranog sadržaja,
  približno 4.000 znakova po segmentu pretraživanja i 400 redaka po čitanju.
- Datoteke koje sadrže NUL smatraju se netekstualnima te se preskaču ili odbijaju.

Binarni dokumenti kao što su PDF, DOCX, slike i arhive namjerno nisu podržani. Prije indeksiranja pretvorite ih u odobreni tekstni format u konfiguriranom direktoriju.

## Napomene za rad

- Promjena ili brisanje konfiguriranog korijena briše zajednički indeks u memoriji.
- Ponovno pokretanje procesa odbacuje indeks; sljedeće pretraživanje ponovno ga izgrađuje iz konfiguriranog izvora.
- `local_corpus_status` ne pokreće prisilno skeniranje. Upotrijebite `local_corpus_search` s
  `refresh: true` kada je potrebno trenutačno ponovno skeniranje.
- Neuspjesi skeniranja i čitanja bilježe se brojčano ili vraćaju kao pročišćene pogreške; izvorne datoteke nikada se ne mijenjaju.
