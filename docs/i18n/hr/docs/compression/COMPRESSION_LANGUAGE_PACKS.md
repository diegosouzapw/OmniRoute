Caveman kompresija može učitati pakete pravila specifične za jezik uz ugrađena pravila za engleski.
Time jezgreni mehanizam ostaje stabilan, dok se paketi za portugalski, španjolski, njemački, francuski, talijanski, japanski i
buduće jezike mogu razvijati neovisno.

## Lokacija

Jezični paketi nalaze se u:

```txt
open-sse/services/compression/rules/<language>/
```

Trenutačno isporučeni paketi (provjereni prema sadržaju direktorija `rules/`):

| Jezik                | Direktorij     | Prisutne kategorije pravila                         |
| -------------------- | -------------- | --------------------------------------------------- |
| Engleski             | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Španjolski           | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugalski (Brazil) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonezijski         | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Talijanski           | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Njemački             | `rules/de/`    | `context`, `filler`, `structural`                   |
| Francuski            | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japanski             | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Napomena o usklađenosti:** Paketi `en`, `es`, `pt-BR`, `id` i `it` imaju svih 5 kategorija; `de`, `fr` i `ja` isporučuju se s 3 kategorije. Za nedostajuće kategorije `dedup` i `ultra` neprimjetno se koriste ugrađena pravila za engleski. Doprinosi za dodavanje datoteka `dedup.json` i `ultra.json` manjim paketima su dobrodošli.
>
> Paket `pt-BR` temelji se na sustavu **[Troglodita](https://github.com/leninejunior/troglodita)** autora Leninea Júniora — sustavu kompresije osmišljenom od temelja za gramatiku brazilskog portugalskog (smanjenje pleonazama, uklanjanje poštapalica specifičnih za PT-BR, tehničke kratice za brazilsku razvojnu zajednicu).
>
> Mjerodavni popis kategorija i shema za svaku kategoriju nalaze se u [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema, nacrt 2020-12).

## Otkrivanje jezika

`languageDetector.ts` koristi jednostavne heuristike za određivanje jezika iz teksta upita. Konfigurirani
zadani jezik i dalje se poštuje, a otkrivanje se može onemogućiti konfiguracijom kada je potrebna
potpuna kontrola.

Rezultat otkrivanja koristi se samo za odabir paketa pravila. Ne mijenja usmjeravanje prema pružatelju, odabir
lokalizacije ni jezik korisničkog sučelja.

## Struktura konfiguracije

Postavke kompresije mogu sadržavati:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` upravlja zadanim postavkama nadzorne ploče i pretpregleda. `cavemanConfig` je konfiguracija izvršnog mehanizma
koja se koristi kada Caveman komprimira tekst poruke.

## Dodavanje jezičnog paketa

1. Stvorite `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Upotrijebite format pravila Caveman iz `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Zamjene trebaju biti konzervativne i ne smiju mijenjati kôd, identifikatore, URL-ove ili JSON.
4. Dodajte ili ažurirajte testove za odabir jezika i ponašanje zamjena.
5. Izložite nove oznake nadzorne ploče/i18n ako se jezik pojavljuje u izbornicima korisničkog sučelja.

## API

Dostupne pakete moguće je dohvatiti pomoću:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Krajnja točka za pretpregled prihvaća nadjačavanja jezične konfiguracije:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Svih 6 jezičnih paketa u verziji v3.8.0 dobilo je klauzulu `SHARED_BOUNDARIES`, koja se primjenjuje pri svakom
intenzitetu Caveman (LITE, FULL, ULTRA). Ona nalaže pogonu da sačuva ove uzorke u izvornom obliku,
bez obzira na uklanjanje okolnog suvišnog sadržaja:

| Vrsta uzorka                             | Primjer                                |
| ---------------------------------------- | -------------------------------------- |
| Ograđeni blokovi kôda                    | ` ```python\n...\n``` `                |
| Umetnuti kôd                             | `` `my_var` ``                         |
| URL-ovi                                  | `https://example.com/path`             |
| Putanje datoteka (apsolutne + relativne) | `/etc/hosts`, `./src/index.ts`         |
| Zaglavlja pogrešaka                      | `Error:`, `TypeError:`, `SyntaxError:` |
| Retci praćenja stoga                     | `  at functionName (file.ts:12:3)`     |

Ti su uzorci uneseni u `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (prethodno `[]`). Konstanta
se nalazi u `open-sse/services/compression/types.ts`.

### Zašto je to važno

Bez klauzule SHARED_BOUNDARIES agresivni načini rada Caveman mogli bi ukloniti sadržaj koji izgleda kao ponavljajući
prozni tekst, ali je zapravo isječak kôda, putanja datoteke ili praćenje stoga pogreške. SHARED_BOUNDARIES djeluje kao
sigurnosna mreža neovisna o jeziku koja se primjenjuje prije pravila za uklanjanje suvišnog sadržaja.

### Prilagodba preservePatterns

Dodatni uzorci mogu se dodati tijekom izvođenja putem postavki kompresije:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Prilagođeni uzorci proširuju (ne zamjenjuju) 6 zadanih uzoraka.

## Operativne napomene

- Ugrađena pravila za engleski ostaju pričuvna opcija kada jezični paket nedostaje.
- Nevaljani ugrađeni JSON paketi ne prolaze provjeru valjanosti kako se kvaliteta artefakata izdanja ne bi neprimjetno smanjila.
- Paketi pravila sadržavaju samo podatke i ne bi trebali uvoziti kôd niti izvršavati proizvoljnu logiku.
- Sloj analitike kompresije bilježi odabrani način rada i pogon, a ne puni tekst upita.
