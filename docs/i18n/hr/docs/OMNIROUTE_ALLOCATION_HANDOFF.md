Alokacija nije kvota pružatelja usluge.

Skupovi kvota definiraju koji API ključevi mogu koristiti skup pružatelja usluge te kako se primjenjuju stroga, fleksibilna ili pravila za kratkotrajna prekoračenja. Kvota pružatelja usluge vanjski je kapacitet koji prijavljuje pružatelj usluge ili izričito konfigurirani izvor. Interni proračuni Ghostlighta ograničenja su upravljanja koja definira administrator.

Operacija `ensurePool` idempotentna je: identičan skup ostaje nepromijenjen, promijenjena alokacija ažurira se, a skup koji nedostaje stvara se. Namijenjena je automatizaciji i API pozivateljima s definiranim ograničenjima.

Krajnja točka statusa samo za čitanje jest `GET /api/omniroute/status`. Naredba za provjeru jest `npm run omniroute:verify`; ne šalje stvarni zahtjev modelu.
