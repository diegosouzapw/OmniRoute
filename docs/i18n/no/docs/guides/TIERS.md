OmniRoute organiserer de 352 støttede leverandørene i 3 økonomiske nivåer. Hver
forespørsel sendes gjennom dem i rekkefølge til én returnerer et vellykket svar — du
får det billigste brukbare svaret uten å måtte skrive reservekode.

## Nivå 1 — Abonnement

**Leverandører du allerede betaler for.** OmniRoute bruker opp all tilgjengelig kvote før
den utløper.

| Leverandør                        | Hvorfor nivå 1                              |
| --------------------------------- | ------------------------------------------- |
| Claude Code OAuth                 | Anthropic Pro/Team — fastpris, ofte ubrukt  |
| OpenAI Codex (ChatGPT-abonnement) | Plus/Team inkluderer Codex-kvote            |
| GitHub Copilot                    | Per bruker — kvoten tilbakestilles månedlig |
| Cursor IDE                        | Kvote i Pro-abonnementet                    |
| Antigravity / Devin Desktop       | Innebygde kvoter                            |

**Strategi**: rut hit først for hver forespørsel som passer til modellens
styrker. Kvotesporingen overvåker kommende tilbakestillinger, og kombinasjonsstrategien
`reset-aware` prioriterer deretter. For å rute til nivå 1 først og bare gå videre
til betalte nivåer etter hvert som kvoten brukes opp, bruker du ID-en `auto/thrifty` — eller
`auto/subscription` for å holde deg til kapasiteten som er inkludert i abonnementet, og avvise forespørselen hvis den ikke er tilgjengelig. Se
[Abonnementsprioritert ruting](../routing/SUBSCRIPTION_LADDER.md).

## Nivå 2 — Billig

**Leverandører med betaling per token under $1/1M tokens.** Reservert for arbeid med høyt volum
eller etter at kvotene på nivå 1 har nådd grensene.

| Leverandør                    | Pris (inndata/utdata) | Styrker                 |
| ----------------------------- | --------------------- | ----------------------- |
| DeepSeek V4 Pro               | $0.27 / $1.10 per 1M  | Kode, resonnering       |
| GLM-4.5                       | $0.60 / $2.20 per 1M  | Lang kontekst           |
| MiniMax M1                    | $0.20 / $1.10 per 1M  | Hastighet               |
| Qwen Coder                    | $0.30 / $1.20 per 1M  | Kode                    |
| OpenRouter (prisoptimalisert) | varierer              | 100+ modeller, dynamisk |

**Strategi**: kombinasjonen `cost-optimized` velger modellen med lavest $/token som oppfyller
oppgavens funksjonsfilter (bildestøtte, JSON-modus, verktøy, maksimal kontekst).

## Nivå 3 — Gratis

**Kostnadsfrie leverandører** — gratisnivåer, kredittprogrammer og daglige OAuth-kvoter.

| Leverandør       | Gratis kvote / kreditter                        |
| ---------------- | ----------------------------------------------- |
| Kiro AI          | Gratis Claude-nivå (romslig rimelig bruk)       |
| OpenCode Free    | Ingen autentisering, romslige hastighetsgrenser |
| Qoder            | Gratis OAuth                                    |
| Google Vertex AI | $300 i kreditter for nye kontoer                |
| Amazon Q         | Gratisnivå for AWS-brukere                      |
| Pollinations     | Åpent offentlig API                             |
| Cloudflare AI    | Gratisnivå for Workers AI                       |

**Strategi**: kombinasjonen `auto` med budsjettgrense ruter hit når nivå 1+2 mislykkes,
eller når `useFreeOnly=true` er angitt. Gratisleverandører har ofte strengere
hastighetsgrenser — kretsbryteren gjenoppretter dem etter ventetiden.

## Konfigurere nivåer

Kontrollpanel → **Nivåer** → tilordne leverandørene dine. Standardinnstillingene (fra `tierDefaults.json`) er
fornuftige; rediger dem når du har bestemte abonnementer du vil prioritere, eller leverandører du vil ekskludere.

Auto-Combos poengberegning med 16 faktorer tar også hensyn til nivået. Se
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemetri

Kontrollpanel → **Bruk** viser tokens brukt per nivå per dag. Bruk dette til å:

- Bekrefte at nivå 1 utnyttes fullt ut (ellers sløser du bort abonnementsverdien)
- Identifisere hvilke modeller på nivå 2 som velges oftest (konsolider til 1–2)
- Kontrollere at nivå 3 sparer penger på arbeidsbelastninger for testing/utforskning

## Vanlige mønstre

### Helt gratis arbeidsbelastning

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Styrer i stor grad mot nivå 3; bruker bare nivå 2 hvis nivå 3 er utilgjengelig.

### Abonnementsprioritert med billig reserveløsning

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Eksplisitt sortert liste som tilsvarer nivå 1 → nivå 2 → nivå 3.
