## Rask avinstallering (v3.6.2+)

OmniRoute tilbyr to innebygde skript for fullstendig avinstallering:

### Behold dataene dine

```bash
npm run uninstall
```

Dette fjerner OmniRoute-applikasjonen, men **bevarer** databasen, konfigurasjonene, API-nøklene og leverandørinnstillingene dine i `~/.omniroute/`. Bruk dette hvis du planlegger å installere på nytt senere og ønsker å beholde oppsettet ditt.

### Fullstendig fjerning

```bash
npm run uninstall:full
```

Dette fjerner applikasjonen **og sletter permanent** alle data:

- Database (`storage.sqlite`)
- Leverandørkonfigurasjoner og API-nøkler
- Sikkerhetskopier
- Loggfiler
- Alle filer i katalogen `~/.omniroute/`

> ⚠️ **Advarsel:** `npm run uninstall:full` kan ikke angres. Alle leverandørtilkoblingene, kombinasjonene, API-nøklene og brukshistorikken din blir slettet permanent.

## Manuell avinstallering

### Global NPM-installasjon

```bash
# Fjern den globale pakken
npm uninstall -g omniroute

# (Valgfritt) Fjern datakatalogen
rm -rf ~/.omniroute
```

### Global pnpm-installasjon

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Stopp og fjern containeren
docker stop omniroute
docker rm omniroute

# Fjern volumet (sletter alle data)
docker volume rm omniroute-data

# (Valgfritt) Fjern imaget
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Stopp og fjern containere
docker compose down

# Fjern også volumer (sletter alle data)
docker compose down -v
```

### Electron-skrivebordsapp

**Windows:**

- Åpne `Innstillinger → Apper → OmniRoute → Avinstaller`
- Eller kjør NSIS-avinstalleringsprogrammet fra installasjonskatalogen

**macOS:**

- Dra `OmniRoute.app` fra `/Applications` til papirkurven
- Fjern data: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Fjern AppImage-filen
- Fjern data: `rm -rf ~/.omniroute`

### Kildekodeinstallasjon (git clone)

```bash
# Fjern den klonede katalogen
rm -rf /path/to/omniroute

# (Valgfritt) Fjern datakatalogen
rm -rf ~/.omniroute
```

## Datakataloger

OmniRoute lagrer som standard data på følgende steder:

| Plattform      | Standardbane                  | Overstyring                       |
| -------------- | ----------------------------- | --------------------------------- |
| Linux          | `~/.omniroute/`               | Miljøvariabelen `DATA_DIR`        |
| macOS          | `~/.omniroute/`               | Miljøvariabelen `DATA_DIR`        |
| Windows        | `%APPDATA%/omniroute/`        | Miljøvariabelen `DATA_DIR`        |
| Docker         | `/app/data/` (montert volum)  | Miljøvariabelen `DATA_DIR`        |
| XDG-kompatibel | `$XDG_CONFIG_HOME/omniroute/` | Miljøvariabelen `XDG_CONFIG_HOME` |

### Filer i datakatalogen

| Fil/katalog          | Beskrivelse                                                        |
| -------------------- | ------------------------------------------------------------------ |
| `storage.sqlite`     | Hoveddatabase (leverandører, kombinasjoner, innstillinger, nøkler) |
| `storage.sqlite-wal` | SQLite-logg for forhåndsskriving (midlertidig)                     |
| `storage.sqlite-shm` | Delt SQLite-minne (midlertidig)                                    |
| `call_logs/`         | Arkiver med forespørselsdata                                       |
| `backups/`           | Automatiske databasesikkerhetskopier                               |
| `log.txt`            | Eldre forespørselslogg (valgfritt)                                 |

## Kontroller fullstendig fjerning

Etter avinstalleringen kontrollerer du at det ikke finnes noen gjenværende filer:

```bash
# Se etter global npm-pakke
npm list -g omniroute 2>/dev/null

# Se etter datakatalog
ls -la ~/.omniroute/ 2>/dev/null

# Se etter kjørende prosesser
pgrep -f omniroute
```

Hvis en prosess fortsatt kjører, stopper du den:

```bash
pkill -f omniroute
```
