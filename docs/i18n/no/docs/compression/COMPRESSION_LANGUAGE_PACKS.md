Caveman-komprimering kan laste inn språkspesifikke regelpakker i tillegg til de innebygde engelske reglene.
Dette holder kjernemotoren stabil, samtidig som portugisiske, spanske, tyske, franske, italienske, japanske og
fremtidige språkpakker kan utvikles uavhengig.

## Plassering

Språkpakkene ligger under:

```txt
open-sse/services/compression/rules/<language>/
```

Pakker som leveres for øyeblikket (verifisert mot innholdet i katalogen `rules/`):

| Språk                | Katalog        | Tilgjengelige regelkategorier                       |
| -------------------- | -------------- | --------------------------------------------------- |
| Engelsk              | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Spansk               | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugisisk (Brasil) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indonesisk           | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Italiensk            | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Tysk                 | `rules/de/`    | `context`, `filler`, `structural`                   |
| Fransk               | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Japansk              | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Merknad om samsvar:** Pakkene `en`, `es`, `pt-BR`, `id` og `it` har alle de fem kategoriene. `de`, `fr` og `ja` leveres med tre kategorier. De manglende kategoriene `dedup` og `ultra` bruker automatisk de innebygde engelske reglene som reserve. Bidrag for å legge til `dedup.json` og `ultra.json` i de mindre pakkene er velkomne.
>
> Pakken `pt-BR` er basert på **[Troglodita](https://github.com/leninejunior/troglodita)** av Lenine Júnior – et komprimeringssystem utviklet fra bunnen av for brasiliansk-portugisisk grammatikk (reduksjon av pleonasmer, fjerning av PT-BR-fyllord og tekniske forkortelser for det brasilianske utviklermiljøet).
>
> Den autoritative kategorilisten og skjemaet for hver kategori finnes i [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema-utkast 2020-12).

## Språkdeteksjon

`languageDetector.ts` bruker enkle heuristikker for å utlede språket fra ledeteksten. Det
konfigurerte standardspråket respekteres fortsatt, og deteksjon kan deaktiveres via konfigurasjonen når nøyaktig
kontroll er nødvendig.

Resultatet av deteksjonen brukes bare til å velge regelpakker. Det endrer ikke ruting til leverandører, valg av
lokalitet eller språk i brukergrensesnittet.

## Konfigurasjonsstruktur

Komprimeringsinnstillingene kan inneholde:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` styrer standardinnstillingene for kontrollpanelet og forhåndsvisningen. `cavemanConfig` er kjøretidskonfigurasjonen for motoren
som brukes når Caveman komprimerer meldingstekst.

## Legge til en språkpakke

1. Opprett `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Bruk Caveman-regelformatet fra `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Vær konservativ med erstatninger, og unngå å endre kode, identifikatorer, URL-er eller JSON.
4. Legg til eller oppdater tester for språkvalg og erstatningsatferd.
5. Gjør nye etiketter for kontrollpanelet/i18n tilgjengelige hvis språket vises i velgere i brukergrensesnittet.

## API

Tilgjengelige pakker kan hentes med:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Endepunktet for forhåndsvisning godtar overstyringer av språkkonfigurasjonen:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Alle de 6 språkpakkene fikk en `SHARED_BOUNDARIES`-klausul i v3.8.0 som brukes ved alle
Caveman-intensiteter (LITE, FULL, ULTRA). Den instruerer motoren om å bevare disse mønstrene ordrett,
uavhengig av fjerning av omkringliggende fylltekst:

| Mønstertype                     | Eksempel                               |
| ------------------------------- | -------------------------------------- |
| Avgrensede kodeblokker          | ` ```python\n...\n``` `                |
| Kode i løpende tekst            | `` `my_var` ``                         |
| URL-er                          | `https://example.com/path`             |
| Filbaner (absolutte + relative) | `/etc/hosts`, `./src/index.ts`         |
| Feilhoder                       | `Error:`, `TypeError:`, `SyntaxError:` |
| Linjer i stakksporingen         | `  at functionName (file.ts:12:3)`     |

Disse mønstrene fylles inn i `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (tidligere `[]`). Konstanten
finnes i `open-sse/services/compression/types.ts`.

### Hvorfor dette er viktig

Uten SHARED_BOUNDARIES kunne aggressive Caveman-moduser fjerne innhold som så ut som gjentakende
prosa, men som egentlig var en kodesnutt, filbane eller feilstakk. SHARED_BOUNDARIES fungerer som et
språkuavhengig sikkerhetsnett som brukes før reglene for fylltekst kjøres.

### Tilpasse preservePatterns

Flere mønstre kan legges til under kjøring via komprimeringsinnstillingene:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Egendefinerte mønstre utvider (erstatter ikke) de 6 standardmønstrene.

## Driftsmerknader

- Innebygde engelske regler brukes fortsatt som reserve når en språkpakke mangler.
- Ugyldige innebygde JSON-pakker består ikke valideringen, slik at utgivelsesressurser ikke forringes uten varsel.
- Regelpakker inneholder bare data og skal ikke importere kode eller kjøre vilkårlig logikk.
- Analysemodulen for komprimering registrerer valgt modus og motor, ikke hele ledeteksten.
