OmniRoute leveres med et kuratert utvalg av gratis proxyer i tabellen `free_proxies`,
synkronisert fra eksterne leverandører (1proxy, proxifly, iplocate, webshare).
Kontrollpanelet viser disse under **Innstillinger → Gratis proxyer**. Dette dokumentet
beskriver filtrering, sortering, telling og rapportering av synkroniseringsfeil på
serversiden som listeruten tilbyr.

## Listerute — `GET /api/settings/free-proxies`

Returnerer et filtrert, sortert og paginert utsnitt samt et totalt antall. Filtrering
og telling utføres i SQL, slik at brukergrensesnittet kan vise det reelle totalantallet
(f.eks. `Totalt: 0`) uten å laste inn hver rad i minnet.

### Spørringsparametere

| Parameter         | Type                               | Standardverdi | Betydning                                                                                                              |
| ----------------- | ---------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`          | Skiller mellom store og små bokstaver ved bruk av `LIKE` på verts- og kildekolonnen.                                   |
| `protocol`        | string                             | `""`          | `type`-filter: `http` / `https` / `socks4` / `socks5`. Tom = alle.                                                     |
| `country`         | string                             | `""`          | `countryCode`-filter (ISO-2). Tom = alle.                                                                              |
| `minQuality`      | number                             | `0`           | Bare rader med `qualityScore >= minQuality`. `0` = ingen nedre grense.                                                 |
| `disabledSources` | string                             | `""`          | Kommaseparerte kilde-ID-er som skal utelates (f.eks. `proxifly,webshare`).                                             |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`     | `quality` = synkende poengsum; `latency` = stigende latenstid (nullverdier sist); `recent` = synkende `lastValidated`. |
| `offset`          | number                             | `0`           | Startpunkt for paginering.                                                                                             |
| `limit`           | number                             | `50`          | Sidestørrelse (begrenses på serversiden).                                                                              |

### Respons

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` gjenspeiler det filtrerte totalantallet **før** paginering, slik at
brukergrensesnittet kan vise `Totalt: N` og `hasMore` uavhengig av hverandre.
`syncErrors` bruker kilde-ID-en som nøkkel og fylles bare ut for kilder der den
siste synkroniseringen mislyktes – et resultat med `Totalt: 0` er aldri uten
forklaring.

## Legg til i utvalg — `POST /api/settings/free-proxies/[id]/add-to-pool`

Flytter en gratis proxy til det administrerte `proxy_registry`-utvalget. Validerer
oppstrømskilden først. Ved suksess returneres ID-en til den nye proxyen i utvalget
samt målt latenstid.

## Synkronisering — `POST /api/settings/free-proxies/sync`

Henter alle aktiverte kilder på nytt (eller delsettet i `{ "sources": [...] }`).
Hver kilde synkroniseres uavhengig. En kilde som feiler, registreres i `syncErrors`,
mens de andre fortsatt fullføres, slik at delvise synkroniseringer aldri sletter
tidligere gyldige data.

## Statistikk — `GET /api/settings/free-proxies/stats`

Returnerer aggregatet `total / inPool / avgQuality / bySource / lastSyncAt`
uten radnyttelasten – brukes av kontrollpanelets topptekst-elementer.
