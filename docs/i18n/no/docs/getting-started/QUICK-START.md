> **Kort fortalt**: Installer → Koble til en gratis leverandør → Pek IDE-en din mot OmniRoute. Ferdig.

---

## Trinn 1: Installer OmniRoute

Velg metoden du foretrekker:

### Alternativ A: npm (anbefalt)

```bash
npm install -g omniroute
```

### Alternativ B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` er den høyeste **publiserte**, stabile SemVer-versjonen. Den følger **ikke** git `main`. Fest versjonen til `diegosouzapw/omniroute:X.Y.Z` for GitOps. Se [Avbildningstagger / utgivelseskanaler](../guides/DOCKER_GUIDE.md#release-channels).

### Alternativ C: Fra kildekoden

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Trinn 2: Start OmniRoute

```bash
omniroute
```

OmniRoute starter på `http://localhost:20128`. Kontrollpanelet åpnes automatisk.

---

## Trinn 3: Koble til en gratis leverandør

Du kan bruke OmniRoute **uten å betale noe** ved å koble til en gratis leverandør.

### Alternativ A: Kiro (gratis Claude — krever ikke betalingskort)

1. Åpne kontrollpanelet på `http://localhost:20128`
2. Gå til **Leverandører** → **Legg til leverandør**
3. Velg **Kiro AI**
4. Klikk på **Koble til** (ingen API-nøkkel kreves!)
5. Ferdig! Du har nå gratis tilgang til Claude-modeller.

### Alternativ B: OpenCode Free (ingen autentisering)

1. Åpne kontrollpanelet på `http://localhost:20128`
2. Gå til **Leverandører** → **Legg til leverandør**
3. Velg **OpenCode Free**
4. Klikk på **Koble til** (ingen API-nøkkel kreves!)
5. Ferdig! Du har nå gratis tilgang til flere modeller.

### Alternativ C: Pollinations (ingen nøkkel kreves)

1. Åpne kontrollpanelet på `http://localhost:20128`
2. Gå til **Leverandører** → **Legg til leverandør**
3. Velg **Pollinations**
4. Klikk på **Koble til** (ingen API-nøkkel kreves!)
5. Ferdig! Du har nå gratis tilgang til GPT-5, Claude, Gemini og flere.

---

## Trinn 4: Kontroller at det fungerer

Opprett en ny nøkkel under [API-nøkler](http://localhost:20128/dashboard/api-manager). Oppbevar denne nøkkelen, siden den ikke vises igjen. Vær oppmerksom på at denne nøkkelen brukes av verktøy for å få tilgang til OmniRoute, ikke for å få tilgang til oppstrømsleverandører.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Du skal se en liste over de tilkoblede modellene dine.

## Trinn 5: Pek IDE-en eller CLI-verktøyet ditt mot OmniRoute

Angi følgende i IDE-en eller CLI-verktøyet ditt:

```
Grunn-URL:  http://localhost:20128/v1
API-nøkkel: [kopier fra Kontrollpanel → Endepunkter]
Modell:     auto
```

Det var alt! IDE-en din bruker nå OmniRoute med automatisk valg av leverandør.

### IDE-eksempel: VSCode/Continue.dev

1. Installer utvidelsen [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) i VSCode.
2. Oppdater `~/.continue/config.yaml` ved å legge til følgende linjer:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Velg `OmniRoute - Auto` i chattepanelet for Continue.dev for å sende forespørsler til OmniRoute.
4. (Valgfritt) Oppgave til leseren – få IDE-en din til å oppdatere `config.yaml` med alle de andre forhåndsbygde konfigurasjonene 😊

### CLI-eksempel: Codex CLI

1. Angi miljøvariabelen permanent i operativsystemet ditt.
   For macOS/Linux (legg den til i `~/.bashrc` eller `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

For Windows (Ledetekst):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. La oss nå starte Codex, men konfigurert for OmniRoute. Kjør:

```
omniroute launch-codex --model auto
```

Du kan gjøre dette manuelt via `codex` og kommandolinjeparametere for å angi endepunktet og API-nøkkelen, men med kommandoen ovenfor tar OmniRoute seg av alt for deg.

Den samme oppstarten med én kommando fungerer for andre CLI-verktøy via den generiske startfunksjonen — `omniroute run <target>` støtter `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` og `gemini` (se [CLI-integrasjoner](../guides/CLI-INTEGRATIONS.md)).

3. CLI-verktøyet skal nå sende forespørsler til OmniRoute.

### Bekreft at verktøyet ditt ruter til OmniRoute

Du kan se detaljene for forespørselen ved å klikke på [Overvåking/Logger](http://localhost:20128/dashboard/logs) i venstre sidepanel. Ved å klikke deg videre kan du se flere detaljer. Du kan også se hvilken informasjon som sendes fra favorittverktøyet ditt. Dette er nyttig både for læring og feilsøking.

## Vanlige spørsmål

### «Trenger jeg en API-nøkkel?»

**Nei!** Du kan bruke gratisleverandører (Kiro, OpenCode Free, Pollinations) uten noen API-nøkkel. Bare koble dem til i kontrollpanelet.

### «Hva er `auto`?»

`auto` ber OmniRoute om automatisk å velge den beste leverandøren for hver forespørsel. Den tar hensyn til hastighet, kostnad, kvalitet og tilgjengelighet. Se [veiledningen for Auto-Combo](./AUTO-COMBO-GUIDE.md) for mer informasjon.

### «Hvor mye koster det?»

Selve OmniRoute er **gratis og har åpen kildekode**. Du betaler bare for leverandørene du bruker. Mange leverandører har gratisnivåer — se [veiledningen for gratisnivåer](./FREE-TIERS-GUIDE.md).

### «Kan jeg bruke det med Claude Code / Cursor / Copilot?»

**Ja!** OmniRoute fungerer med alle verktøy som støtter OpenAI-formatet. Bare angi grunn-URL-en som `http://localhost:20128/v1`. Se [veiledningen for CLI-verktøy](../reference/CLI-TOOLS.md) for spesifikke konfigurasjonsinstruksjoner.

### «Hva skjer hvis en leverandør blir utilgjengelig?»

OmniRoute hopper automatisk over leverandører som feiler, og prøver den neste. Du trenger ikke å gjøre noe. Se [veiledningen for Auto-Combo](./AUTO-COMBO-GUIDE.md) for mer informasjon.
