OmniRoute jagab 352 toetatud teenusepakkujat 3 majanduslikku tasemesse. Iga
päring läbib neid järjekorras, kuni üks neist tagastab eduka vastuse — nii
saate odavaima toimiva vastuse, ilma et peaksite varuloogikat kirjutama.

## Tase 1 — Tellimus

**Teenusepakkujad, kelle eest te juba maksate.** OmniRoute kasutab kogu
kvoodi ära enne selle aegumist.

| Teenusepakkuja                  | Miks tase 1                                              |
| ------------------------------- | -------------------------------------------------------- |
| Claude Code OAuth               | Anthropic Pro/Team — fikseeritud hind, sageli kasutamata |
| OpenAI Codex (ChatGPT tellimus) | Plus/Team sisaldab Codexi kvooti                         |
| GitHub Copilot                  | Kasutajapõhine — kvoot lähtestub iga kuu                 |
| Cursor IDE                      | Pro-paketi kvoot                                         |
| Antigravity / Devin Desktop     | Sisseehitatud kvoodid                                    |

**Strateegia**: suunake siia esmalt kõik päringud, mis sobivad mudeli
tugevustega. Kvoodijälgija jälgib lähenevaid lähtestamisi ning `reset-aware`
kombineeritud strateegia määrab nende põhjal prioriteedid. Taseme 1 esimesena
kasutamiseks ja tasulistele tasemetele liikumiseks alles kvoodi lõppemisel kasutage
ID-d `auto/thrifty` — või `auto/subscription`, et piirduda paketis sisalduva
mahuga ja selle ammendumisel töö katkestada. Vaadake
[Tellimust eelistav marsruutimine](../routing/SUBSCRIPTION_LADDER.md).

## Tase 2 — Odav

**Kasutuspõhise tasuga teenusepakkujad, kelle hind on alla $1/1M tokeni.**
Mõeldud suuremahulisteks töödeks või kasutamiseks pärast taseme 1 kvootide
piirini jõudmist.

| Teenusepakkuja                        | Hind (sisend/väljund)  | Tugevused                 |
| ------------------------------------- | ---------------------- | ------------------------- |
| DeepSeek V4 Pro                       | $0.27 / $1.10 1M kohta | Kood, arutlusvõime        |
| GLM-4.5                               | $0.60 / $2.20 1M kohta | Pikk kontekst             |
| MiniMax M1                            | $0.20 / $1.10 1M kohta | Kiirus                    |
| Qwen Coder                            | $0.30 / $1.20 1M kohta | Kood                      |
| OpenRouter (hinna järgi optimeeritud) | varieerub              | 100+ mudelit, dünaamiline |

**Strateegia**: kombinatsioon `cost-optimized` valib madalaima $/tokeni hinnaga
mudeli, mis vastab ülesande võimekusfiltrile (nägemine, JSON-režiim, tööriistad,
maksimaalne kontekst).

## Tase 3 — Tasuta

**Nullkuluga teenusepakkujad** — tasuta tasemed, krediidiprogrammid, OAuthi
päevakvoodid.

| Teenusepakkuja   | Tasuta kvoot / krediit                                  |
| ---------------- | ------------------------------------------------------- |
| Kiro AI          | Tasuta Claude'i tase (helde mõistliku kasutuse piirang) |
| OpenCode Free    | Autentimist pole, helded päringusageduse piirangud      |
| Qoder            | Tasuta OAuth                                            |
| Google Vertex AI | $300 krediiti uuele kontole                             |
| Amazon Q         | Tasuta tase AWS-i kasutajatele                          |
| Pollinations     | Avalik avatud API                                       |
| Cloudflare AI    | Workers AI tasuta tase                                  |

**Strateegia**: kombinatsioon `auto` koos eelarvepiiranguga suunab päringud
siia, kui tasemed 1 ja 2 ebaõnnestuvad või kui määratud on `useFreeOnly=true`.
Tasuta teenusepakkujatel on sageli rangemad päringusageduse piirangud —
kaitselüliti taastab nende kasutamise pärast ooteaega.

## Tasemete seadistamine

Juhtpaneel → **Tasemed** → määrake oma teenusepakkujad. Vaikeseaded (failist
`tierDefaults.json`) on mõistlikud; muutke neid, kui soovite eelistada konkreetseid
tellimusi või teatud teenusepakkujad välistada.

Auto-Combo 16 teguril põhinev hindamine arvestab samuti taset. Vaadake
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## Telemeetria

Juhtpaneel → **Kasutus** näitab päevas tasemeti kulutatud tokeneid. Kasutage seda,
et:

- kontrollida, kas tase 1 on täielikult kasutatud (vastasel juhul raiskate tellimuse väärtust);
- tuvastada, milliseid taseme 2 mudeleid valitakse kõige rohkem (koondage valik 1–2 mudelile);
- veenduda, et tase 3 säästab testimise ja uurimise töökoormuste puhul raha.

## Levinud mustrid

### Täielikult tasuta töökoormus

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

Suunab tugevalt taseme 3 poole; kasutab taset 2 ainult siis, kui tase 3 pole
saadaval.

### Tellimus esimesena, odav varuvariant

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

Selgesõnaline järjestatud loend, mis vastab järjestusele tase 1 → tase 2 → tase 3.
