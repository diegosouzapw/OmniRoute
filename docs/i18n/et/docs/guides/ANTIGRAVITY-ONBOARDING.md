## 1. Antigravity vs. Antigravity CLI (agy)

Mõlemad pakkujad kasutavad **sama Google'i taustsüsteemi** — identne OAuthi klient, lubade värskendamine, lõpp-punktid ja Google'i kontod. Erinevus seisneb selles, milliseid mudeleid teile kuvatakse.

> Google'i ametliku võrdluse leiate [Antigravity CLI väljakuulutamisest](https://antigravity.google/blog/introducing-google-antigravity-cli).

| Aspekt               | `antigravity` (IDE)                                                | `agy` (CLI)                                                 |
| -------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------- |
| **Google'i toode**   | Antigravity 2.0 / Antigravity IDE                                  | Antigravity CLI                                             |
| **Taustsüsteem**     | Sama Google Cloud Code API                                         | Sama Google Cloud Code API                                  |
| **OAuth / luba**     | Sama klient, sama värskendamine                                    | Sama klient, sama värskendamine                             |
| **Mudelikaust**      | Staatiline kureeritud loend (OmniRoute'i koodi jäigalt kirjutatud) | Google'ist `:fetchAvailableModels` kaudu reaalajas hangitud |
| **Claude'i mudelid** | Sonnet 4.6, Opus 4.6 (mõlemal 4 varianti)                          | Sonnet 4.6, Opus 4.6 (mõlemal 4 varianti)                   |
| **Gemini nimetused** | Selged sildid (Low/Medium/High)                                    | Ülesvoolu ID-d (extra-low/low/agent)                        |
| **Lisamudelid**      | `gpt-oss-120b-medium`                                              | Võib sisaldada Google'i lisamudeleid                        |
| **Vaikekasutus**     | IDE-integratsioon (VS Code, JetBrains)                             | CLI-/API-juurdepääs                                         |
| **Kvoot**            | Jagatud agy-ga (sama Google'i konto)                               | Jagatud antigravity-ga (sama Google'i konto)                |

**Saadaolevad mudelid (katsega kinnitatud, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (erinevad mõtlemistasemed)
- Claude: Sonnet 4.6, Opus 4.6 (mõlemal default/low/medium/high variandid)
- Muud: GPT-OSS 120B Medium
- **Claude Sonnet 5 EI OLE saadaval** — toetatud on ainult 4.6 variandid

**Miks mudelikaust erineb**: Google'i CLI on „optimeeritud kiiruse ja vähese ressursikulu jaoks” ning „koos Gemini mudelitega optimeeritud” (Google'i ametliku ajaveebi kohaselt). Veebi-/IDE-toode on „optimeeritud kõikehõlmavuse jaoks”. CLI kasutab mudelite dünaamiliseks avastamiseks funktsiooni `:fetchAvailableModels`, samas kui IDE kasutab staatilist kureeritud loendit.

**Praktikas**: Kasutage Gemini mudelite jaoks eesliidet `agy/` (nt `agy/gemini-3.7-flash-high`). Staatilise kureeritud loendi jaoks kasutage eesliidet `antigravity/`. Mõlemad kasutavad sama Google'i taustsüsteemi, kuid mudelite nimetused on erinevad. Kvoot on jagatud — kummagi pakkuja kasutamine arvestatakse sama Google'i konto piirangute hulka.

## 2. Google One AI Pro: kvoodisüsteem

> Ametlikud kvoodi üksikasjad leiate dokumendist [Antigravity dokumentatsioon: paketid](https://antigravity.google/docs/plans) ja uusimad hinnamuudatused artiklist [Antigravity pakettide muudatused](https://antigravity.google/blog/changes-to-antigravity-plans).

Google Antigravity kasutab sõnumite arvu asemel **kahetasandilist kvooti**, mis põhineb tehtud tööl („Work Done“ ehk arvutuslikul kaalul).

### Kaks tasandit

| Tase                | Mis see on                      | Värskendustsükkel                                                                      |
| ------------------- | ------------------------------- | -------------------------------------------------------------------------------------- |
| **5-tunnine spurt** | Kohe kasutatav tehtud töö kogus | Lähtestatakse 5 tundi pärast seansi esimest päringut                                   |
| **7-päevane baas**  | Nädalane range ülempiir         | Selle täitumisel alistab 5-tunnise värskenduse; lukustab järgmise 7-päevase perioodini |

**Kuidas „Work Done“ arvutatakse**: Rohkelt agente kasutavad ülesanded (nt „Refaktoreeri kogu see repositoorium“) kulutavad kvooti palju kiiremini kui lihtsad ülesanded (nt „Paranda see funktsioon“). Tarbimist näitavat reaalajas juhtpaneeli ei ole.

### Paketitasemed

| Pakett       | Hind        | Kvoot                                         | Nädalane piirang                            |
| ------------ | ----------- | --------------------------------------------- | ------------------------------------------- |
| Free         | $0          | Arvestatav kvoot, värskendatakse kord nädalas | Jah                                         |
| AI Pro       | $19.99/kuu  | Suur kvoot, 5-tunnine jooksev värskendus      | Jah (täitumisel alistab 5-tunnise piirangu) |
| AI Ultra 5x  | $99.99/kuu  | 5x Pro kvoot                                  | Nädalane piirang puudub                     |
| AI Ultra 20x | $199.99/kuu | 20x Pro kvoot                                 | Nädalane piirang puudub                     |

### Gemini mudelid ja muud mudelid

- **Gemini mudelid** (Flash + Pro): Jagavad üht kiirusepiirangut, mida vähendatakse API hinnastuse alusel. Kui Flash on 8x odavam kui Pro, saate kasutada 8x rohkem Flashi tokeneid.
- **Muud mudelid** (Claude, GPT-OSS): Neil on **eraldi** kiirusepiirangud. Need võivad jääda kättesaadavaks isegi siis, kui Gemini kasutamine on lukustatud.

### AI-krediit (limiidi ületamine)

> Krediidi toimimise kohta vaadake teavet lehelt [Google One’i AI-krediit](https://support.google.com/googleone/answer/14534406).

Kui baaskvoot on ammendatud:

- **Mitte kunagi**: Oodake kvoodi värskendamist; kuvatakse „Baasmudeli kvoot on täis“
- **Alati**: Kasutatakse automaatselt AI-krediiti; baaskvoodi värskendamisel minnakse sellele tagasi

Krediiti ostetakse eraldi ja arvestatakse maha API tavahinnastuse alusel.

### Olulised üksikasjad

- Kvoot on **konto tasemel jagatud** — sama Google’i konto Antigravity IDE-s, CLI-s ja OmniRoute’is kasutab ühist kvoodikogumit
- Igal Google’i kontol on eraldi sõltumatu kvoot — mitu kontot = mitu kvoodikogumit
- AI Pro kasutajad on teatanud **7-päevastest lukustustest** 5-tunniste lähtestamiste asemel, kui nädalane baaskvoot täitub (Google kinnitas, et suure nõudluse korral on see taotluslik)

**Kui teie konto kvoot on ammendatud**: OmniRoute proovib kombineeritud marsruudil automaatselt järgmist saadaolevat kontot. Käsitsi sekkumine pole vajalik.

## 3. Kuidas hankida projectId

Iga antigravity/agy ühendus vajab Google Cloud Code’i `projectId`-d. Ilma selleta tagastab otspunkt `/v1internal:models` veakoodi 404.

### Meetod A: automaatne (soovitatav)

OmniRoute tegeleb sellega automaatselt. Kui lisate juhtpaneeli OAuthi kaudu uue Google’i konto:

1. OmniRoute värskendab tokenit
2. Kutsub projectId tuvastamiseks välja `loadCodeAssist`
3. Kui projekti pole, kutsub selle loomiseks välja `onboardUser`
4. Kutsub äsja loodud projectId hankimiseks uuesti välja `loadCodeAssist`
5. Salvestab selle andmebaasi

**See toimib enamiku kontode puhul** — käsitsi toiminguid pole vaja.

### Meetod B: käsitsi agy CLI kaudu

Kui automaatne tuvastamine ebaõnnestub (juhtumite kohta vaadake jaotist 5):

```bash
# Installige agy CLI (kui see pole juba installitud)
npm install -g @anthropic-ai/agy

# Logige sisse oma Google'i kontoga
agy login

# Valige konto, mis vajab kasutuselevõttu
# See käivitab Cloud Code'i registreerimise ja määrab projectId
```

Pärast käsu `agy login` õnnestumist värskendage OmniRoute’i juhtpaneelil tokenit. projectId tuvastatakse automaatselt.

### Kuidas kontrollida

Kontrollige andmebaasi:

```bash
# OmniRoute'i konteineris
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

Või kontrollige logisid:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuthi ümbersuunamise URI

### Probleem

Google OAuth nõuab kehtivat ümbersuunamise URI-d. OmniRoute kasutab vaikimisi `http://127.0.0.1:20128/callback` (tagasisilmus). See toimib kohalike järkude puhul, kuid **ei tööta kaugjuurutuste korral** (nt LAN-i IP kaudu kasutatavas serveris).

Google lükkab tagasi ümbersuunamise URI-d, mis:

- Kasutavad IP-aadresse (kasutada tuleb domeeni, mille lõpus on `.com`, `.org` vms)
- Ei ühti OAuthi kliendi konfiguratsioonis registreeritud ümbersuunamise URI-dega

### Lahendus

**Variant A: kasutage sisseehitatud OAuthi voogu (vaikimisi)**

- Toimib, kui avate OmniRoute'i aadressilt `localhost` või `127.0.0.1`
- Seadistamine pole vajalik

**Variant B: kohandatud OAuthi identimisteave**

- Määrake oma keskkonnas `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web`
- Sisestage oma Google OAuthi identimisteave:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Registreerige Google Cloud Console'is volitatud ümbersuunamise URI-na `https://your-domain.com/callback`

**Variant C: kasutage esmaseks sisselogimiseks agy CLI-d**

- Käivitage `agy login` masinas, millest OmniRoute'i kasutatakse
- OAuthi voog viiakse kohalikult lõpule ja tõendid salvestatakse
- Importige ühendus Dashboardi kaudu OmniRoute'i

### Piirangud

- Kohandatud OAuthi identimisteave nõuab domeeninime (Google ei aktsepteeri IP-aadresse ümbersuunamise URI-dena)
- Kui teil pole domeeni, kasutage selle asemel varianti A või C

## 5. Tõrkeotsing: kui automaatne seadistamine ebaõnnestub

OmniRoute tuvastab projectId ja teeb enamiku kontode esmase seadistamise automaatselt. Ebaõnnestumise korral on algpõhjuseks tavaliselt üks järgmistest:

### Konto piirkond on blokeeritud

**Sümptom**: `agy login` tagastab teate „Sobivuse kontroll ebaõnnestus: teie praegune konto ei vasta Antigravity kasutamise tingimustele, sest teenus pole praegu teie asukohas saadaval.”

**Algpõhjus**: Google'i kontodel on taustsüsteemis väli „Country Association”, mis määratakse registreerimise ajal. agy CLI ja Cloud Code API kontrollivad seda välja rangelt — erinevalt Gemini veebiversioonist, mis kontrollib ainult teie praegust IP-aadressi.

> Kontoga seotud piirkonna kontrollimiseks või muutmiseks avage [Google'i riigiseose vorm](https://policies.google.com/country-association-form).

**Miks Gemini veebiversioon töötab, kuid agy mitte**:

- Gemini veebiversioon / Google One: kontrollib ainult praegust IP-aadressi (puhverserverist piisab)
- agy CLI / Cloud Code API: loeb taustsüsteemi välja „Country Association” (puhverserverist pole abi)

**Parandus**:

1. Avage USA IP-aadressi kasutades [Google'i riigiseose vorm](https://policies.google.com/country-association-form)
2. Esitage piirkonna muutmise taotlus (valige „Ma elan teises riigis”)
3. Oodake 1–24 tundi, kuni Google taotluse töötleb ja saadab e-posti teavituse
4. Seejärel peaks `agy login` õnnestuma

### Kontol puudub Cloud Code'i projekt

**Sümptom**: logides kuvatakse `loadCodeAssist returned no project id` ja `onboardUser failed (400)`.

**Algpõhjus**: kontot pole kunagi Google Cloud Code'is registreeritud ja automaatne esmane seadistamine ebaõnnestus.

**Parandus**: käivitage Cloud Code'is registreerimise käivitamiseks käsitsi `agy login`, seejärel värskendage tõendit OmniRoute'i Dashboardis.

### Tõend on aegunud või tühistatud

**Sümptom**: logides kuvatakse tõrked 401 või teated „Tõend on aegunud”.

**Parandus**: värskendage tõendit asukohas Dashboard → Providers → agy → klõpsake värskendamise ikooni. Kui värskendustõend ise on tühistatud, peate OAuthi kaudu uuesti autentima.

```
└─ Käsitsi: käivitage masinas `agy login`

```
