**OmniCopilot** lisab kõik OmniRoute’i pakutavad mudelid GitHub Copilot Chati _natiivsesse_
mudelivalikusse. Ei mingit teist külgriba ega eraldi vestlusliidest — Copiloti agendirežiim,
tööriistakutsed, MCP-serverid ja kohandatud juhised töötavad edasi, kuid kasutavad teie valitud mudelit.

|                            |                                                                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Installimine (VS Code)** | [Marketplace → `diegosouzapw.omnicopilot`](https://marketplace.visualstudio.com/items?itemName=diegosouzapw.omnicopilot)                        |
| **Installimine (harud)**   | [Open VSX](https://open-vsx.org/extension/diegosouzapw/omnicopilot) — Cursor, Windsurf, VSCodium, Theia, code-server, Gitpod, Antigravity, Kiro |
| **Lähtekood / vead**       | [github.com/diegosouzapw/OmniCopilot](https://github.com/diegosouzapw/OmniCopilot) (MIT)                                                        |
| **Nõuded**                 | VS Code 1.104+                                                                                                                                  |

> **Copiloti tellimust pole vaja.** Alates VS Code 1.122-st töötab keelemudeli pakkuja
> ilma GitHubi sisselogimise ja Copiloti paketita. Reasisesed kooditäiendused ja
> manustel põhinevad funktsioonid ei kuulu pakkuja API-sse ning vajavad endiselt Copilotit.

## Seadistamine

1. **Käivitage OmniRoute** — `npm install -g omniroute && omniroute` (juhtpaneel aadressil `http://localhost:20128`).
2. **Installige laiendus** — otsige laienduste vaates fraasi „OmniRoute“.
3. **Valige mudel** — Copilot Chat → mudelivalik → **Halda mudeleid…** → **OmniRoute**, seejärel märkige
   soovitud mudelid.

Kui OmniRoute töötab vaikepordil, pole midagi vaja seadistada. Kaugserveri korral avage
**OmniRoute’i ikoon tegevusribal** (või käivitage `OmniRoute: Manage Connection`) ja määrake:

- **Serveri URL** — serveri juuraadress, nt `http://192.168.0.15:20128`. Järelliite `/v1` lisab
  laiendus; ärge seda lisage.
- **API-võti** — ainult juhul, kui serveris on määratud `REQUIRE_API_KEY`. See talletatakse VS
  Code SecretStorage’i kaudu operatsioonisüsteemi võtmehoidlasse, mitte kunagi faili `settings.json`.

## Mida mudelivalik kuvab

Laiendus ei kuva töötlemata `GET /v1/models` vastust — see kohandab seda ning kuvatav arv
on kataloogi suurusest väiksem kahel teadlikul põhjusel.

### Iga mudeli kohta küsitakse üks ID

`MODELS_CATALOG_PREFIX_MODE` vaikeväärtus on **`dual`**, mis avaldab iga mudeli kaks korda — ühe korra
lühikese alias-prefiksiga ja ühe korra pakkuja kanoonilise prefiksiga —, et vanemad kliendi
konfiguratsioonid suudaksid jätkuvalt mõlemat vormi lahendada:

```
cc/claude-sonnet-4-6        ← alias-prefiks
claude/claude-sonnet-4-6    ← kanooniline prefiks, sama mudel
```

Laiendus saadab päringu **`GET /v1/models?prefix=alias`**, nii et iga mudeli kohta saabub üks ID,
muutmata teie teiste klientide jaoks kogu serverit hõlmavat seadistust. Võrdlusserveris vähendas see
**2345 kirjet 1396-ni — 949 duplikaati, kaduma ei läinud ühtegi mudelit.**

Kui eelistate selle parandada serveriüleselt _iga_ kliendi jaoks, määrake juhtpaneelil
funktsioonilipu `MODELS_CATALOG_PREFIX_MODE` väärtuseks `alias`. Päringuparameetri ja
režiimipõhise tabeli leiate jaotisest
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix).

### Mudelid, millega ei saa vestelda, peidetakse

Kataloog sisaldab ka pildi-, video-, heli-, ümberjärjestus-, manustus- ja modereerimismudeleid.
Vestluspäringu korral lükatakse need niikuinii tagasi:

```
HTTP 400 — Mudel '<id>' on pildiloome mudel ja seda ei saa kasutada lõpp-punktiga
/v1/chat/completions. Kasutage selle asemel POST /v1/images/generations.
```

seega filtreeritakse need välja välja `type` alusel enne mudelivalikusse jõudmist. **Responses-API
mudelid säilitatakse** — iga Codexi / GPT-5.x kirje avaldab `supported_endpoints: ["responses"]`
ning OmniRoute teisendab need `/v1/chat/completions` jaoks, mistõttu on need täielikult kasutatavad.

### Pakkujad, mida te pole seadistanud

Kataloog sisaldab **aktiivse ühendusega** pakkujate mudeleid ning kõiki **noAuth**
pakkujaid — võtmeta pakkujaid, mis moodustavad suure osa tasuta tasemest. See on taotluslik. Nende
peitmiseks lisage need juhtpaneeli seadetes loendisse `blockedProviders`; laienduses ei muutu
midagi.

## Juhtpaneel VS Code'i vahekaardil

`omnicopilot.dashboardOpen: "editor"` kuvab OmniRoute'i juhtpaneeli välise brauseri asemel redaktori vahekaardil Simple Browseri kaudu. Manustamine tuleb **serveris eraldi lubada** muutujaga `DASHBOARD_ALLOW_EMBED=vscode`, mille korral edastatakse HTML-lehed päisega `frame-ancestors 'self' vscode-webview:` vaikeväärtuste `frame-ancestors 'none'` + `X-Frame-Options: DENY` asemel. API-pind (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) säilitab mõlemal juhul ranged päised.

> ⚠️ **See on kompileerimisaegne, mitte käitusaegne lipp.** Next.js kompileerib `headers()` marsruutide manifesti, mistõttu loeb `next.config.mjs` muutujat paketi kompileerimise ajal
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Selle eksportimine juba kompileeritud serveri käivitamise eel ei muuda midagi — päised on juba sisse kompileeritud.

```bash
# muutuja peab olema olemas KOMPILATSIOONIKÄSU käivitamisel
DASHBOARD_ALLOW_EMBED=vscode npm run build        # või npm run build:release
npm start
```

| Paigaldusviis              | Kas manustamise saab lubada?                                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Lähtekoodist               | ✅ määrake muutuja kompileerimiskäsus, nagu eespool näidatud                                                                                     |
| `npm install -g omniroute` | ❌ avaldatud pakett sisaldab eelkompileeritud komplekti — kompileerige selle asemel lähtekoodist                                                 |
| Dockeri tõmmis             | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — Docker Hubi eelkompileeritud tõmmises pole manustamine lubatud |

Ilma manustamist lubava järguta keeldub leht raami sees avanemast, laiendus tuvastab selle vastuse päistest ja kasutab varuvariandina välist brauserit — midagi ei lähe katki ning sellest teavitatakse üks kord.
Vaadake faili [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) ja probleemi
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Muude tööriistade seadistamine VS Code'is

**`OmniRoute: Configure Coding CLI`** kasutab `omniroute` CLI-d, et luua kasutusvalmis profiilid tööriistadele Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code, Kilo ja Roo — need on samad konfiguratsioonid, mida kirjeldatakse failis
[`CLI-INTEGRATIONS.md`](CLI-INTEGRATIONS.md). API-võti edastatakse CLI-le keskkonnamuutuja `OMNIROUTE_API_KEY` kaudu, mitte kunagi käsureal.
