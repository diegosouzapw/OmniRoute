## Kiire eemaldamine (v3.6.2+)

OmniRoute pakub kahte sisseehitatud skripti puhtaks eemaldamiseks:

### Andmete säilitamine

```bash
npm run uninstall
```

See eemaldab OmniRoute rakenduse, kuid **säilitab** teie andmebaasi, konfiguratsioonid, API-võtmed ja teenusepakkuja seaded kaustas `~/.omniroute/`. Kasuta seda, kui plaanid hiljem uuesti paigaldada ja soovid oma seadistuse säilitada.

### Täielik eemaldamine

```bash
npm run uninstall:full
```

See eemaldab rakenduse **ja kustutab jäädavalt** kõik andmed:

- Andmebaas (`storage.sqlite`)
- Teenusepakkuja konfiguratsioonid ja API-võtmed
- Varufailid
- Logifailid
- Kõik failid kaustas `~/.omniroute/`

> ⚠️ **Hoiatus:** `npm run uninstall:full` on pöördumatu. Kõik teie teenusepakkuja ühendused, kombinatsioonid, API-võtmed ja kasutusajalugu kustutatakse jäädavalt.

## Käsitsi eemaldamine

### NPM globaalne install

```bash
# Eemalda globaalne pakett
npm uninstall -g omniroute

# (Valikuline) Eemalda andmekataloog
rm -rf ~/.omniroute
```

### pnpm globaalne install

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Peata ja eemalda konteiner
docker stop omniroute
docker rm omniroute

# Eemalda maht (kustutab kõik andmed)
docker volume rm omniroute-data

# (Valikuline) Eemalda pilt
docker rmi diegosouzapw/omniroute:latest
```

### Docker Compose

```bash
# Peata ja eemalda konteinerid
docker compose down

# Eemalda ka mahud (kustutab kõik andmed)
docker compose down -v
```

### Electron'i lauaarvutirakendus

**Windows:**

- Ava `Settings → Apps → OmniRoute → Uninstall`
- Või käivita NSIS-i eemaldaja install-kataloogist

**macOS:**

- Lohista `OmniRoute.app` kaustast `/Applications` prügikasti
- Eemalda andmed: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Eemalda AppImage fail
- Eemalda andmed: `rm -rf ~/.omniroute`

### Lähtekoodist install (git clone)

```bash
# Eemalda kloonitud kataloog
rm -rf /path/to/omniroute

# (Valikuline) Eemalda andmekataloog
rm -rf ~/.omniroute
```

## Andmekataloogid

OmniRoute salvestab andmeid vaikimisi järgmistesse asukohtadesse:

| Platvorm    | Vaikimisi asukoht             | Ülekirjutamine                     |
| ----------- | ----------------------------- | ---------------------------------- |
| Linux       | `~/.omniroute/`               | `DATA_DIR` keskkonnamuutuja        |
| macOS       | `~/.omniroute/`               | `DATA_DIR` keskkonnamuutuja        |
| Windows     | `%APPDATA%/omniroute/`        | `DATA_DIR` keskkonnamuutuja        |
| Docker      | `/app/data/` (ühendatud maht) | `DATA_DIR` keskkonnamuutuja        |
| XDG-ühilduv | `$XDG_CONFIG_HOME/omniroute/` | `XDG_CONFIG_HOME` keskkonnamuutuja |

### Failid andmekataloogis

| Fail/kataloog        | Kirjeldus                                                     |
| -------------------- | ------------------------------------------------------------- |
| `storage.sqlite`     | Peamine andmebaas (pakkujad, kombinatsioonid, seaded, võtmed) |
| `storage.sqlite-wal` | SQLite kirjutusloogika logi (ajutine)                         |
| `storage.sqlite-shm` | SQLite jagatud mälu (ajutine)                                 |
| `call_logs/`         | Päringute sisu arhiivid                                       |
| `backups/`           | Automaatsed andmebaasi varukoopiad                            |
| `log.txt`            | Pärandpäringute logi (valikuline)                             |

## Kontrolli täielikku eemaldamist

Pärast eemaldamist kontrolli, et ei jäänud alles ühtegi faili:

```bash
# Kontrolli globaalset npm paketti
npm list -g omniroute 2>/dev/null

# Kontrolli andmekataloogi
ls -la ~/.omniroute/ 2>/dev/null

# Kontrolli töötavaid protsesse
pgrep -f omniroute
```

Kui protsess on veel töös, peata see:

```bash
pkill -f omniroute
```
