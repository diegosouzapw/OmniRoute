> **Lühidalt**: Installi → Ühenda tasuta teenusepakkuja → Suuna oma IDE OmniRoute'i kasutama. Valmis.

---

## 1. samm: installi OmniRoute

Vali eelistatud meetod:

### Variant A: npm (soovitatav)

```bash
npm install -g omniroute
```

### Variant B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` viitab uusimale **avaldatud** stabiilsele SemVer-versioonile. See **ei** järgi giti haru `main`. GitOpsi jaoks fikseeri versioon kujul `diegosouzapw/omniroute:X.Y.Z`. Vaata jaotist [Tõmmise sildid / väljalaskekanalid](../guides/DOCKER_GUIDE.md#release-channels).

### Variant C: lähtekoodist

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## 2. samm: käivita OmniRoute

```bash
omniroute
```

OmniRoute käivitub aadressil `http://localhost:20128`. Juhtpaneel avaneb automaatselt.

---

## 3. samm: ühenda tasuta teenusepakkuja

Saad OmniRoute'i kasutada **täiesti tasuta**, ühendades tasuta teenusepakkuja.

### Variant A: Kiro (tasuta Claude — krediitkaarti pole vaja)

1. Ava juhtpaneel aadressil `http://localhost:20128`
2. Ava **Teenusepakkujad** → **Lisa teenusepakkuja**
3. Vali **Kiro AI**
4. Klõpsa **Ühenda** (API-võtit pole vaja!)
5. Valmis! Nüüd on sul tasuta juurdepääs Claude'i mudelitele.

### Variant B: OpenCode Free (autentimist pole vaja)

1. Ava juhtpaneel aadressil `http://localhost:20128`
2. Ava **Teenusepakkujad** → **Lisa teenusepakkuja**
3. Vali **OpenCode Free**
4. Klõpsa **Ühenda** (API-võtit pole vaja!)
5. Valmis! Nüüd on sul tasuta juurdepääs mitmele mudelile.

### Variant C: Pollinations (võtit pole vaja)

1. Ava juhtpaneel aadressil `http://localhost:20128`
2. Ava **Teenusepakkujad** → **Lisa teenusepakkuja**
3. Vali **Pollinations**
4. Klõpsa **Ühenda** (API-võtit pole vaja!)
5. Valmis! Nüüd on sul tasuta juurdepääs GPT-5-le, Claude'ile, Geminile ja teistele mudelitele.

---

## 4. samm: kontrolli, kas see töötab

Loo jaotises [API-võtmed](http://localhost:20128/dashboard/api-manager) uus võti. Salvesta see võti, sest seda ei kuvata enam uuesti. Pane tähele, et see võti on mõeldud tööriistade juurdepääsuks OmniRoute'ile, mitte ülesvoolu teenusepakkujatele.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Peaksid nägema oma ühendatud mudelite loendit.

---

## 5. samm: suuna oma IDE või CLI OmniRoute'i kasutama

Määra oma IDE-s või CLI-tööriistas järgmised väärtused:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

See ongi kõik! Sinu IDE kasutab nüüd OmniRoute'i koos automaatse teenusepakkuja valikuga.

### IDE näide: VSCode/Continue.dev

1. Installi VSCode'is laiendus [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue).
2. Lisa oma faili `~/.continue/config.yaml` järgmised read:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Vali Continue.devi vestluspaanil `OmniRoute - Auto` ja sinu päringud saadetakse OmniRoute'ile.
4. (Valikuline) Ülesanne lugejale: lase oma IDE-l lisada faili `config.yaml` ka kõik muud valmis konfiguratsioonid 😊

### CLI näide: Codex CLI

1. Määra oma operatsioonisüsteemis keskkonnamuutuja püsivalt.
   macOS-i/Linuxi puhul (lisa faili `~/.bashrc` või `~/.zshrc`):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windowsi puhul (käsuviip):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Nüüd käivitame Codexi OmniRoute'i jaoks seadistatuna. Käivita:

```
omniroute launch-codex --model auto
```

Saad seda teha käsitsi käsu `codex` ja käsureaparameetrite abil, määrates lõpp-punkti ning API-võtme, kuid ülaltoodud käsu kasutamisel hoolitseb OmniRoute kõige eest sinu eest.

Sama ühe käsuga käivitamine töötab üldise käiviti kaudu ka teiste CLI-dega — `omniroute run <target>` toetab sihtmärke `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` ja `gemini` (vaata [CLI-integratsioonid](../guides/CLI-INTEGRATIONS.md)).

3. CLI peaks nüüd saatma päringud OmniRoute'ile.

### Veendu, et sinu tööriist suunab päringud OmniRoute'ile

Päringu üksikasju saad vaadata, klõpsates vasakul külgribal valikut [Jälgimine/logid](http://localhost:20128/dashboard/logs). Edasi klõpsates näed rohkem üksikasju. Lisaks saad vaadata, millist teavet sinu eelistatud tööriist edastab. See on kasulik nii õppimiseks kui ka silumiseks.

## Levinud küsimused

### „Kas mul on vaja API-võtit?”

**Ei!** Saad kasutada tasuta teenusepakkujaid (Kiro, OpenCode Free, Pollinations) ilma ühegi API-võtmeta. Ühenda need lihtsalt juhtpaneelil.

### „Mis on `auto`?”

`auto` käsib OmniRoute'il valida iga päringu jaoks automaatselt parima teenusepakkuja. See võtab arvesse kiirust, hinda, kvaliteeti ja saadavust. Üksikasju vaata [Auto-Combo juhendist](./AUTO-COMBO-GUIDE.md).

### „Kui palju see maksab?”

OmniRoute ise on **tasuta ja avatud lähtekoodiga**. Maksad ainult kasutatavate teenusepakkujate eest. Paljudel teenusepakkujatel on tasuta paketid — vaata [tasuta pakettide juhendit](./FREE-TIERS-GUIDE.md).

### „Kas saan seda kasutada koos Claude Code'i / Cursori / Copilotiga?”

**Jah!** OmniRoute töötab kõigi tööriistadega, mis toetavad OpenAI vormingut. Määra baasaadressiks lihtsalt `http://localhost:20128/v1`. Konkreetseid seadistusjuhiseid vaata [CLI-tööriistade juhendist](../reference/CLI-TOOLS.md).

### „Mis saab siis, kui teenusepakkuja lakkab töötamast?”

OmniRoute jätab mittetöötavad teenusepakkujad automaatselt vahele ja proovib järgmist. Sa ei pea midagi tegema. Üksikasju vaata [Auto-Combo juhendist](./AUTO-COMBO-GUIDE.md).
