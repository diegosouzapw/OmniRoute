## Mis see on

Local Corpus võimaldab operaatoril teha ühe sõnaselgelt heaks kiidetud tekstifailide kataloogi
OmniRoute'i MCP-serverile kättesaadavaks. Failid jäävad oma algsesse kataloogi: OmniRoute salvestab
SQLite'i ainult kanoonilise juurtee ja hoiab mälus otsinguindeksit. See ei
kopeeri korpuse sisu hoidlasse ega andmebaasi.

Indeksit värskendatakse järk-järgult. Muutmata faile kasutatakse uuesti nende suuruse ja muutmisaja
põhjal, muudetud failid loetakse uuesti ning räsitakse SHA-256 abil ja kustutatud failid eemaldatakse.
Otsing värskendab üle 30 sekundi vanust indeksit; kutsujad saavad taotleda ka kohest
värskendamist.

## Allika konfigureerimine

Seadistuste marsruut nõuab sama haldusautentimist nagu teised seadistuste API-d.
Edastatav tee peab juba olemas olema ja olema absoluutne kataloogitee.

```bash
# Ühenda heakskiidetud kataloog
curl -X POST http://localhost:20128/api/settings/local-corpus \
  -H "Content-Type: application/json" \
  -d '{"rootPath":"/absolute/path/to/approved-text"}'

# Kontrolli konfiguratsiooni ja indeksi olekut
curl http://localhost:20128/api/settings/local-corpus

# Katkesta ühendus lähtefaile muutmata
curl -X DELETE http://localhost:20128/api/settings/local-corpus
```

## MCP-tööriistad

Kõik kolm tööriista nõuavad õigust `read:local-corpus`. Tööriistade vastused kuvavad suhtelised teed ja
juurkataloogi baasnime, kuid mitte kunagi selle absoluutset teed.

| Tööriist              | Kirjeldus                                                                                  |
| :-------------------- | :----------------------------------------------------------------------------------------- |
| `local_corpus_status` | Teatab konfiguratsiooni oleku, indeksi suuruse, piirangud ja viimase värskendamise aja     |
| `local_corpus_search` | Otsib indekseeritud tekstist ja tagastab piiratud, reapõhised katkendid (kuni 20 tulemust) |
| `local_corpus_read`   | Loeb ühe lubatud korpuse suhtelise faili piiratud reavahemiku                              |

MCP-sisendite näited:

```json
{ "query": "Red River monitoring", "limit": 10, "refresh": false }
```

```json
{ "relativePath": "hydrology/stations.md", "startLine": 20, "endLine": 80 }
```

## Turvapiirangud

- Lubatud failitüüpide loend on tekstikeskne: `.cfg`, `.csv`, `.geojson`, `.htm`, `.html`, `.ini`,
  `.js`, `.json`, `.jsonl`, `.jsx`, `.log`, `.md`, `.mjs`, `.ps1`, `.py`, `.sh`,
  `.sql`, `.toml`, `.ts`, `.tsx`, `.txt`, `.xml`, `.yaml` ja `.yml`.
- Sümbollingid jäetakse vahele. Lugemisteed kanoniseeritakse ja need peavad jääma
  konfigureeritud juurkataloogi sisse; absoluutsed teed ja kataloogipuus liikumise katsed lükatakse tagasi.
- Tundlikud ja genereeritud katalooginimed jäetakse välja: `.build`, `.codex`, `.env`,
  `.git`, `.next`, `.omniroute`, `.ssh`, `coverage`, `dist`, `node_modules` ja
  `secrets`.
- Vaikimisi piirangud on 5000 faili, 1 MiB faili kohta, kokku 64 MiB indekseeritud sisu,
  ligikaudu 4000 märki otsingulõigu kohta ja 400 rida lugemise kohta.
- NUL-märki sisaldavaid faile käsitletakse mittetekstilistena ning need jäetakse vahele või lükatakse tagasi.

Binaardokumendid, nagu PDF-id, DOCX-id, pildid ja arhiivid, ei ole teadlikult toetatud.
Teisendage need enne indekseerimist konfigureeritud kataloogis lubatud tekstivormingusse.

## Kasutusmärkused

- Konfigureeritud juurkataloogi muutmine või kustutamine tühjendab jagatud mälusisese indeksi.
- Protsessi taaskäivitamisel indeks kaob; järgmine otsing koostab selle konfigureeritud
  allikast uuesti.
- `local_corpus_status` ei käivita sunnitud skannimist. Kui on vaja kohest kordusskannimist, kasutage
  `local_corpus_search` koos parameetriga `refresh: true`.
- Skannimis- ja lugemistõrked loendatakse või tagastatakse puhastatud veateadetena; lähtefaile
  ei muudeta kunagi.
