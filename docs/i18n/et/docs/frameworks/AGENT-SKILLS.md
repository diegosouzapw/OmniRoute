> **Tõeallikas:** `src/lib/agentSkills/` (kataloog, generaator, parserid) + kataloog `skills/` (failid SKILL.md)
> **Viimati uuendatud:** 2026-08-02 — v3.8.50

Agent Skills on struktureeritud SKILL.md failid, mis õpetavad välistele agentidele, MCP klientidele ja A2A orkestreerijatele OmniRoute'i REST API ning CLI kasutamist. Erinevalt lahendusest [Omni Skills](./SKILLS.md) (mis koosneb OmniRoute'i sees käivitatavatest LLM-i tööriistadefinitsioonidest) on Agent Skills _dokumentatsioonikataloog_ — staatiline markdown, mille saab edastada otse agendi konteksti.

---

## Ülevaade

Kataloog sisaldab **45 Agent Skill'i** (23 REST API + 21 CLI + 1 konfiguratsiooni töövoog). Igal oskusel on:

- **Kanooniline ID** (`omni-auth`, `cli-serve` jne)
- Fail **SKILL.md** asukohas `skills/{id}/SKILL.md`, mis sisaldab YAML-i eessisu (`name`, `description`) ja põhjalikku markdown-sisu
- OpenAPI spetsifikatsioonist ja CLI registrist tuletatud **REST lõpp-punktid** (API oskused) või **CLI alamkäsud** (CLI oskused)
- **GitHubi toorvaate URL** reaalajas laadimiseks: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## Arhitektuur

```
src/shared/constants/agentSkills.ts    — 45 kirjega kureeritud loend (nimi/kirjeldus/kategooria/valdkond/ikoon)
src/lib/agentSkills/
  catalog.ts                           — getCatalog(), getSkillById(), filterCatalog(), computeCoverage()
  generator.ts                         — generateAgentSkills() kirjutab SKILL.md faili asukohta skills/{id}/
  openapiParser.ts                     — eraldab REST lõpp-punktid failist docs/openapi.yaml
  cliRegistryParser.ts                 — eraldab CLI alamkäsud failist bin/cli-registry.ts
  schemas.ts                           — Zod-skeemid: AgentSkillSchema, SkillCoverageSchema jne
  types.ts                             — TypeScripti liidesed: AgentSkill, SkillCoverage jne

skills/{id}/SKILL.md                   — Genereeritud + kureeritud markdown-failid (kokku 45)

src/app/api/agent-skills/
  route.ts                             — GET /api/agent-skills
  [id]/route.ts                        — GET /api/agent-skills/{id}
  [id]/raw/route.ts                    — GET /api/agent-skills/{id}/raw (text/markdown)
  coverage/route.ts                    — GET /api/agent-skills/coverage
  generate/route.ts                    — POST /api/agent-skills/generate (autentimine nõutud)

open-sse/mcp-server/tools/agentSkillTools.ts  — 3 MCP tööriista (loend, hankimine, katvus)
src/lib/a2a/skills/listCapabilities.ts        — A2A oskus: list-capabilities
```

`omni-mcp`, `omni-compression`, `cli-providers`, `cli-eval`, `omni-agents-a2a`, `omni-combos-routing`, `omni-auth`, `omni-resilience`, `omni-inference`, `cli-serve`.

## REST API avastamine

| Lõpp-punkt                   | Meetod | Kirjeldus                                                             | Autentimine |
| :--------------------------- | :----- | :-------------------------------------------------------------------- | :---------- |
| `/api/agent-skills`          | GET    | Kataloogi loend (valikuline `?category=api\|cli\|config&area=<area>`) | puudub      |
| `/api/agent-skills/{id}`     | GET    | Ühe oskuse metaandmete hankimine                                      | puudub      |
| `/api/agent-skills/{id}/raw` | GET    | SKILL.md hankimine vormingus `text/markdown`                          | puudub      |
| `/api/agent-skills/coverage` | GET    | Katvuse statistika (mitu SKILL.md faili on olemas)                    | puudub      |
| `/api/agent-skills/generate` | POST   | Generaatori käivitamine (dryRun/prune/onlyIds)                        | haldus      |

Näide — kõigi API-oskuste loend:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

Näide — ühe SKILL.md faili hankimine:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## Kuidas välised agendid oskusi kasutavad

### 1. Avastamine REST-i kaudu

```bash
# Hangi täielik kataloog
curl "http://your-omniroute/api/agent-skills" | jq '.skills[] | {id, name, category}'

# Hangi SKILL.md konteksti sisestamiseks
curl "http://your-omniroute/api/agent-skills/omni-providers/raw" > omni-providers.md
```

### 2. Avastamine MCP kaudu

```typescript
// Claude Desktopi / Cursori MCP-kliendis:
const result = await client.callTool("omniroute_agent_skills_list", {
  category: "api",
});
// result.skills → AgentSkill-objektide massiiv, igaühel rawUrl
```

### 3. Avastamine A2A kaudu

```python
import requests

resp = requests.post("http://your-omniroute/a2a", json={
    "jsonrpc": "2.0", "id": "1",
    "method": "message/send",
    "params": {"skill": "list-capabilities", "messages": [{"role": "user", "content": "list"}]}
})
table = resp.json()["result"]["artifacts"][0]["content"]
# table on Markdowni tabel kõigi 45 oskuse ID ja rawUrl veergudega
```

### 4. Otsene GitHubi toorfaili päring (server pole vajalik)

```bash
BASE="https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills"
curl "${BASE}/omni-providers/SKILL.md"
```

## Generaator

Generaator loeb kureeritud kataloogi, OpenAPI spetsifikatsiooni ja CLI registrit ning kirjutab iga kirje jaoks faili `skills/{id}/SKILL.md`:

```bash
# Eelvaade (proovikäivitus, midagi ei kirjutata)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# Täielik taasgenereerimine
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# Konkreetsete ID-de taasgenereerimine
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

Generaatori vastus on `GeneratorReport`:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
