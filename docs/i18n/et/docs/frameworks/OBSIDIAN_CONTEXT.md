> `src/lib/db/obsidian.ts` (tõendi / baas-URL-i / WebDAV-i püsiv talletus),

> `src/app/api/settings/obsidian/webdav/route.ts` (seadete API-d). Tööriistade registreerimine

## Mis see on

OmniRoute ühendub **Obsidiani** hoidlaga kui **kontekstiallikaga** — kohaliku Markdowni
teadmusbaasiga, mida agendid loevad ja kirjutavad sisseehitatud MCP-serveri kaudu.
Integratsioon suhtleb töölauarakenduses töötava kogukonna lisandmooduli
**Obsidian Local REST API** kaudu, võimaldades agentidel otsida märkmeid, lugeda,
kirjutada ja paigata faile, kuvada hoidla sisu, töötada päeva- ja nädalapõhiste
perioodiliste märkmetega, hallata silte, käivitada Obsidiani käske ning (valikuliselt)
koordineerida kahesuunalist töölaua↔mobiilseadme hoidla sünkroonimist.

Klient (`src/lib/obsidian/api.ts`) ümbritseb Local REST API järgmiste funktsioonidega:

- **Eksponentsiaalse viivitusega korduskatsed** ajutiste `5xx` vigade korral ja
  **30-sekundiline ajalõpp** `AbortController`-i kaudu.
- **Tüübitud vigade klassifitseerimine** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Kasutajasõbralik vihje „Obsidianiga ei saa ühendust”**, mis juhib tähelepanu
  levinud pordiveale (HTTP pordil `27123`, **mitte** MCP lõpp-punkt pordil `27124`)
  ja Tailscale’i vormingule.
- Hoidla suhtes **relatiivsete teede kodeerimine**, et tühikute ja kaldkriipsudega
  märkmete teed oleksid turvalised.

## Seadistamine

Obsidiani tõendi ega baas-URL-i jaoks **ei ole keskkonnamuutujat** — mõlemad
salvestatakse SQLite’i tabelisse `key_value` (nimeruum `obsidian`) faili
`src/lib/db/obsidian.ts` kaudu. Tõend on **puhkeolekus krüptitud** (AES-256-GCM,
tagasiühilduva lihtteksti-varuvariandiga). Seadistage see lõpp-punkti juhtpaneeli
vahekaardil **Kontekstiallikad** (`ObsidianSourceCard`) või seadete REST API kaudu.

> [!IMPORTANT]
> Lisandmoodul **Obsidian Local REST API** peab olema installitud ja töötama. Selle REST-
> liides kuulab aadressil **HTTP `127.0.0.1:27123`** (vaikimisi baas-URL). Port `27124`
> on _eraldi_ MCP/HTTPS-i lõpp-punkt ja seadete marsruut lükkab selle sõnaselgelt tagasi.
> Teisest seadmest ühenduse loomisel kasutage `http://<tailscale-ip>:27123`.

### Konfiguratsioonivõtmed (SQLite’i `key_value`, nimeruum `obsidian`)

| Võti              | Otstarve                                                  | Krüptitud |
| ----------------- | --------------------------------------------------------- | --------- |
| `api_key`         | Local REST API kandjatõend                                | jah       |
| `base_url`        | REST-i baas-URL (vaikimisi `http://127.0.0.1:27123`)      | ei        |
| `vault_path`      | Hoidla kataloogi absoluutne tee (sünkroonimiseks)         | ei        |
| `webdav_username` | Genereeritud WebDAV-i kasutajanimi (hoidla sünkroonimine) | ei        |
| `webdav_password` | Genereeritud WebDAV-i parool (hoidla sünkroonimine)       | jah       |
| `webdav_enabled`  | Kas WebDAV-i hoidla sünkroonimine on lubatud              | ei        |

### Seadistamine REST-i kaudu

```bash
# Local REST API tõendi salvestamine ja valideerimine (POST valideerib olekukontrolli kaudu)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Ühenduse oleku kontrollimine (tagastab connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Ühenduse katkestamine (kustutab salvestatud tõendi)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Kõik meetodid nõuavad juhtpaneelil autentimist. `POST` lükkab tagasi kõik pordi `27124`
URL-id ja valideerib tõendi, kutsudes enne salvestamist Local REST API oleku lõpp-punkti.

### WebDAV-i hoidla sünkroonimine

`src/app/api/settings/obsidian/webdav/route.ts` haldab valikulist WebDAV-il põhinevat
hoidla sünkroonimist (mida juhib `src/lib/obsidianSync.ts`). Selle lubamisel suunatakse
OmniRoute kohalikku hoidla kataloogi ning luuakse juhuslik WebDAV-i kasutajanime ja
parooli paar:

```bash
# WebDAV-i sünkroonimise lubamine hoidla kataloogi jaoks (loob kasutajanime ja parooli)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV-i sünkroonimise oleku hankimine (autentimisandmed tagastatakse ainult siis, kui see on lubatud)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV-i sünkroonimise keelamine (kustutab autentimisandmed ja hallatava .stignore-faili)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### API-võtmepõhine kontekstiallikas (valikuline)

Obsidiani konfiguratsiooni saab tabeli `api_key_context_sources` kaudu piirata
**API-võtme kaupa** (`src/lib/db/apiKeyContextSources.ts`). Kui MCP-kutse sisaldab
autenditud API-võtme ID-d, eelistab `getObsidianConfigForApiKey()` selle võtme enda
tõendit, baas-URL-i ja hoidla teed (`source: "api_key"`); vastasel juhul kasutatakse
globaalset konfiguratsiooni (`source: "global"`).

## MCP tööriistad (22)

Määratletud failis `open-sse/mcp-server/tools/obsidianTools.ts`. Luba/baas-URL määratakse
iga kutse jaoks (esmalt API-võtme põhine, seejärel globaalne). Tööriistad, mis kasutavad OmniRoute'i **sünkroonimisserverit**
(neli tööriista `obsidian_sync_*`), nõuavad lisaks OmniRoute'i seadetes konfigureeritud sünkroonimise autentimisluba.

### Lugemistööriistad (`read:obsidian`)

| Tööriist                     | Kirjeldus                                                                                           |
| ---------------------------- | --------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Kontrollib, kas Local REST API on kättesaadav ja autenditud.                                        |
| `obsidian_search_simple`     | Täistekstiotsing märkmete sisust; tagastab väljavõtted koos failiteedega.                           |
| `obsidian_search_structured` | Otsib JSON Logicu avaldise abil (and/or/regex/path filtrid).                                        |
| `obsidian_read_note`         | Loeb märkme hoidla-suhtelise tee järgi; soovi korral konkreetse pealkirja, ploki või frontmatter'i. |
| `obsidian_list_vault`        | Loetleb hoidlas olevad failid ja kataloogid (kirjete puuna).                                        |
| `obsidian_get_document_map`  | Hangib märkme pealkirjastruktuuri kaardistusena pealkirjad → reanumbrid.                            |
| `obsidian_get_note_metadata` | Hangib frontmatter'i, sildid, lingid ning tähe- ja sõnaarvu ilma täieliku sisuta.                   |
| `obsidian_get_active_file`   | Hangib Obsidianis praegu aktiivse faili tee ja sisu.                                                |
| `obsidian_get_periodic_note` | Hangib kuupäeva päeva-, nädala- või kuumärkme (vaikimisi tänase).                                   |
| `obsidian_get_tags`          | Loetleb kõik hoidla sildid koos nende esinemissagedustega.                                          |
| `obsidian_list_commands`     | Loetleb saadaolevad Obsidiani käskude ID-d (kasutamiseks koos käsuga `obsidian_execute_command`).   |
| `obsidian_sync_status`       | OmniRoute'i sünkroonimisserveri olek: töötamine, hoidla nimi, port, tööaeg, viimane sünkroonimine.  |
| `obsidian_sync_conflicts`    | Loetleb lahendamata sünkroonimiskonfliktid (tee, konfliktse faili tee, tuvastamise aeg).            |

### Kirjutamistööriistad (`write:obsidian`)

| Tööriist                         | Kirjeldus                                                                                                  |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Loob või kirjutab üle etteantud Markdowni sisuga märkme.                                                   |
| `obsidian_append_note`           | Lisab märkmele sisu; soovi korral konkreetse pealkirja või ploki alla.                                     |
| `obsidian_patch_note`            | Lisab täpselt määratud pealkirja, ploki või frontmatter'i välja järele või ette või asendab selle.         |
| `obsidian_delete_note`           | Kustutab märkme hoidlast jäädavalt.                                                                        |
| `obsidian_move_note`             | Teisaldab või nimetab hoidlas oleva märkme ümber.                                                          |
| `obsidian_execute_command`       | Käivitab Obsidiani käsu selle käsu ID järgi.                                                               |
| `obsidian_open_file`             | Avab faili Obsidianis (loob selle, kui seda pole olemas).                                                  |
| `obsidian_sync_trigger`          | Käivitab kohe kahesuunalise töölaua↔mobiilseadme hoidla sünkroonimise.                                     |
| `obsidian_sync_resolve_conflict` | Lahendab sünkroonimiskonflikti: säilitab `local` (mobiilse), `remote` (töölaua) või `keep-both` (mõlemad). |

> [!NOTE]
> Tööriista `obsidian_patch_note` sihtmärgid aktsepteerivad `targetType` väärtusi `heading | block | frontmatter`
> ja `operation` väärtusi `append | prepend | replace` ning valikulist
> `createTargetIfMissing` väärtust. Neli tööriista `obsidian_sync_*` suhtlevad kohaliku sünkroonimisserveriga
> (vaikimisi `http://127.0.0.1:27781`) ja nõuavad sünkroonimisluba.

### Ulatused

Lugemistööriistad nõuavad ulatust `read:obsidian`; kirjutamistööriistad nõuavad ulatust `write:obsidian`. Jõustamine
toimib samamoodi nagu Notionis — seda haldab `withScopeEnforcement()` failis
`open-sse/mcp-server/server.ts`, selle aktiveerib `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ning
lubatud ulatused pärinevad muutujast `OMNIROUTE_MCP_SCOPES` või API-võtme ulatuse kontekstist. Vaadake
[MCP-SERVER.md](./MCP-SERVER.md).

## Lõpp-punktid

| Meetod   | Tee                             | Otstarve                                                            |
| -------- | ------------------------------- | ------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Tagastab `{ connected, hasToken, baseUrl, vaultPath }`.             |
| `POST`   | `/api/settings/obsidian`        | Salvestab ja valideerib pääsutõendi (keeldub pordist `27124`).      |
| `DELETE` | `/api/settings/obsidian`        | Katkestab ühenduse (kustutab salvestatud pääsutõendi).              |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV-i sünkroonimise olek ja identimisteave (kui see on lubatud). |
| `POST`   | `/api/settings/obsidian/webdav` | Lubab hoidla kataloogi WebDAV-i kaudu sünkroonida.                  |
| `DELETE` | `/api/settings/obsidian/webdav` | Keelab WebDAV-i kaudu sünkroonimise.                                |

> Need on töölaua seadete marsruudid. Hoidlale endale pääseb ligi Obsidiani
> kohaliku REST API (seadistatud `base_url`) ja ülaltoodud MCP-tööriistade kaudu —
> avalikku Obsidiani `/v1`-puhverserveri lõpp-punkti ei ole.

## Kasutusjuhud

- **Hoidlal põhinevad vastused** — `obsidian_search_simple` / `obsidian_search_structured`
  ja seejärel `obsidian_read_note`, et agent vastaks sinu tegelike märkmete põhjal.
- **Märkmete koostamine / päeviku pidamine** — `obsidian_write_note`, `obsidian_append_note` või
  täppismuutmiseks mõeldud `obsidian_patch_note`, et logida agendi väljund, kokkuvõtted või igapäevased märkmed
  (`obsidian_get_periodic_note`) hoidlasse.
- **Hoidlas navigeerimine** — `obsidian_list_vault`, `obsidian_get_document_map` ja
  `obsidian_get_tags`, et uurida struktuuri enne lugemist/kirjutamist.
- **Obsidiani automatiseerimine** — `obsidian_list_commands` + `obsidian_execute_command`, et
  käivitada agendi kaudu pistikprogramme/käske; `obsidian_open_file`, et kuvada märge kasutajaliideses.
- **Mobiilne sünkroonimine** — luba WebDAV-i kaudu sünkroonimine, seejärel kasuta funktsioone `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`,
  et koordineerida töölaua↔mobiilseadme sünkroonimist ja lahendada konflikte.
