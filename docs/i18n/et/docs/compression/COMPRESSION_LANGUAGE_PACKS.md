Cavemani tihendus saab lisaks sisseehitatud inglise keele reeglitele laadida keelespetsiifilisi reeglipakette.
See hoiab põhimootori stabiilsena, võimaldades samal ajal portugali, hispaania, saksa, prantsuse, itaalia, jaapani ja
tulevastel keelepakettidel iseseisvalt areneda.

## Asukoht

Keelepaketid asuvad kataloogis:

```txt
open-sse/services/compression/rules/<language>/
```

Praegu tarnitavad paketid (kontrollitud kataloogi `rules/` sisu põhjal):

| Keel                  | Kataloog       | Olemasolevad reeglikategooriad                      |
| --------------------- | -------------- | --------------------------------------------------- |
| Inglise               | `rules/en/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Hispaania             | `rules/es/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Portugali (Brasiilia) | `rules/pt-BR/` | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Indoneesia            | `rules/id/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Itaalia               | `rules/it/`    | `context`, `dedup`, `filler`, `structural`, `ultra` |
| Saksa                 | `rules/de/`    | `context`, `filler`, `structural`                   |
| Prantsuse             | `rules/fr/`    | `context`, `filler`, `structural`                   |
| Jaapani               | `rules/ja/`    | `context`, `filler`, `structural`                   |

> **Võrdväärsuse märkus:** pakettidel `en`, `es`, `pt-BR`, `id` ja `it` on kõik 5 kategooriat; paketid `de`, `fr` ja `ja` sisaldavad 3 kategooriat. Puuduvate kategooriate `dedup` ja `ultra` puhul kasutatakse märkamatult inglise keele sisseehitatud reegleid. Väiksematele pakettidele failide `dedup.json` ja `ultra.json` lisamiseks on kaastööd teretulnud.
>
> Pakett `pt-BR` põhineb Lenine Júniori loodud süsteemil **[Troglodita](https://github.com/leninejunior/troglodita)** — see on Brasiilia portugali keele grammatika jaoks nullist loodud tihendussüsteem (pleonasmide vähendamine, PT-BR täitesõnade eemaldamine, tehnilised lühendid Brasiilia arendajate kogukonnale).
>
> Kanooniline kategooriate loend ja iga kategooria skeem asuvad failis [`open-sse/services/compression/rules/_schema.json`](../../open-sse/services/compression/rules/_schema.json) (JSON Schema mustandi versioon 2020-12).

## Keele tuvastamine

`languageDetector.ts` kasutab viiba teksti keele määramiseks lihtsaid heuristikaid. Seadistatud vaikekeelt
arvestatakse endiselt ning täpse juhtimise vajaduse korral saab tuvastamise konfiguratsioonis keelata.

Tuvastamise väljundit kasutatakse ainult reeglipakettide valimiseks. See ei muuda teenusepakkuja marsruutimist, lokaadi
valikut ega kasutajaliidese keelt.

## Konfiguratsiooni struktuur

Tihendussätted võivad sisaldada järgmist:

```json
{
  "languageConfig": {
    "enabled": true,
    "defaultLanguage": "en",
    "autoDetect": true,
    "enabledPacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  },
  "cavemanConfig": {
    "language": "en",
    "autoDetectLanguage": true,
    "enabledLanguagePacks": ["en", "pt-BR", "es", "id", "de", "fr", "ja"]
  }
}
```

`languageConfig` juhib töölaua/eelvaate vaikesätteid. `cavemanConfig` on käitusaegse mootori konfiguratsioon,
mida kasutatakse siis, kui Caveman tihendab sõnumi teksti.

## Keelepaketi lisamine

1. Looge `open-sse/services/compression/rules/<language>/<pack>.json`.
2. Kasutage Cavemani reeglivormingut, mida kirjeldatakse failis `docs/compression/COMPRESSION_RULES_FORMAT.md`.
3. Hoidke asendused konservatiivsed ning vältige koodi, identifikaatorite, URL-ide või JSON-i muutmist.
4. Lisage või värskendage keelevaliku ja asenduskäitumise teste.
5. Lisage uued töölaua/i18n-i sildid, kui keel kuvatakse kasutajaliidese valikutes.

## API

Saadaolevaid pakette saab pärida järgmiselt:

```bash
curl http://localhost:20128/api/compression/language-packs
```

Eelvaate lõpp-punkt aktsepteerib keelekonfiguratsiooni alistusi:

```bash
curl -X POST http://localhost:20128/api/compression/preview \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "standard",
    "text": "Por favor, eu gostaria que voce basicamente resumisse isso.",
    "config": {
      "languageConfig": {
        "defaultLanguage": "pt-BR",
        "autoDetect": true
      }
    }
  }'
```

## SHARED_BOUNDARIES (v3.8.0)

Kõigile kuuele keelepaketile lisati versioonis v3.8.0 klausel `SHARED_BOUNDARIES`, mida rakendatakse igal
Cavemani intensiivsustasemel (LITE, FULL, ULTRA). See juhendab mootorit säilitama järgmised mustrid muutmata kujul,
olenemata ümbritsevate täitesõnade eemaldamisest:

| Mustri tüüp                          | Näide                                  |
| ------------------------------------ | -------------------------------------- |
| Piiratud koodiplokid                 | ` ```python\n...\n``` `                |
| Reasisene kood                       | `` `my_var` ``                         |
| URL-id                               | `https://example.com/path`             |
| Failiteed (absoluutsed + suhtelised) | `/etc/hosts`, `./src/index.ts`         |
| Veapäised                            | `Error:`, `TypeError:`, `SyntaxError:` |
| Pinujälje read                       | `  at functionName (file.ts:12:3)`     |

Need mustrid määratakse väljal `DEFAULT_CAVEMAN_CONFIG.preservePatterns` (varem `[]`). Konstant
asub failis `open-sse/services/compression/types.ts`.

### Miks see oluline on

Ilma klauslita SHARED_BOUNDARIES võivad agressiivsed Cavemani režiimid eemaldada sisu, mis näib korduva
proosana, kuid on tegelikult koodilõik, failitee või veapinu. SHARED_BOUNDARIES toimib
keelest sõltumatu kaitsemehhanismina, mida rakendatakse enne täitesõnade reegleid.

### preservePatterns-i kohandamine

Täiendavaid mustreid saab käitusajal lisada tihendussätete kaudu:

````json
{
  "cavemanConfig": {
    "preservePatterns": [
      "```[\\s\\S]*?```",
      "`[^`]+`",
      "https?://\\S+",
      "(?:/|\\./)[^\\s]+",
      "\\b(?:Error|TypeError|SyntaxError|RangeError):",
      "\\s+at\\s+\\S+\\s+\\(\\S+:\\d+:\\d+\\)"
    ]
  }
}
````

Kohandatud mustrid laiendavad kuut vaikemustrit, mitte ei asenda neid.

## Kasutusalased märkused

- Kui keelepakett puudub, kasutatakse endiselt ingliskeelseid sisseehitatud reegleid.
- Vigased sisseehitatud JSON-paketid ei läbi valideerimist, et väljalaske ressursid märkamatult ei halveneks.
- Reeglipaketid sisaldavad ainult andmeid ega tohiks importida koodi ega käitada suvalist loogikat.
- Tihendamise analüütikakiht salvestab valitud režiimi ja mootori, mitte viiba täisteksti.
