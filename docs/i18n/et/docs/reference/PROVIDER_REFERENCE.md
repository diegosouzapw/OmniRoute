## Kategooriad

- **Tasuta** — tasuta pakett API-võtmega (seadistatakse juhtpaneeli kaudu)
- **Autentimiseta** — avalikud lõpp-punktid, mis ei nõua võtit ega sisselogimist
- **OAuth** — sisselogimisvoogu haldab OmniRoute, API-võtit pole vaja
- **Veebiküpsis** — pakendab pakkuja veebirakenduse, kasutades küpsisepõhist autentimist
- **API-võti** — tasuline pakkuja, mis seadistatakse API-võtmega (võivad kehtida tasuta krediidid)
- **Kohalik** — töötab kasutaja arvutis (Ollama, LM Studio, vLLM jne)
- **Otsing** — veebiotsingu pakkujad
- **Heli** — ainult heliga töötavad pakkujad (TTS/STT)
- **Ülemvoo puhverserver** — pakkujad, mis vahendavad päringuid teistele pakkujatele
- **Pilveagent** — pikaajaliselt töötavad programmeerimisagendid (Codex Cloud, Devin, Jules)
- **Süsteem** — OmniRoute'i sisemised pakkujad (loopback jne)

Lisamärgendid: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tööriistade kutsumine` (kui näidatud): `native` — tegelik funktsioonide kutsumise API; `emulated` — massiivi `tools` emuleeritakse viiba kaudu failis `webTools.ts` (regulaaravaldistega sõelutavad plokid `<tool>{...}</tool>`); `none` — `tools` jäetakse praegu vaikimisi kõrvale. Vt #7286.

Kasutage iga pakkuja lubamiseks, seadistamiseks ja testimiseks juhtpaneeli aadressil `/dashboard/providers`.
