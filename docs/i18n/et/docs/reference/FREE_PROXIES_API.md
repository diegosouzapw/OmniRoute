OmniRoute sisaldab kureeritud tasuta puhverserverite kogumit tabelis `free_proxies`,
mida sünkroonitakse väliste teenusepakkujatega (1proxy, proxifly, iplocate, webshare).
Juhtpaneel kuvab need jaotises **Settings → Free Proxies**. Selles dokumendis
käsitletakse serveripoolset filtreerimist, sortimist, loendamist ja
sünkroonimisvigade esitamist, mida loendimarsruut võimaldab.

## Loendimarsruut — `GET /api/settings/free-proxies`

Tagastab filtreeritud, sorditud ja lehekülgedeks jaotatud osa koos koguarvuga.
Filtreerimine ja loendamine toimuvad SQL-is, seega saab kasutajaliides kuvada
tegeliku koguarvu (nt `Total: 0`) ilma kõiki ridu mällu laadimata.

### Päringuparameetrid

| Parameeter        | Tüüp                               | Vaikeväärtus | Tähendus                                                                                                             |
| ----------------- | ---------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------- |
| `search`          | string                             | `""`         | Tõstutundlik `LIKE` hosti (ja allika) veerus.                                                                        |
| `protocol`        | string                             | `""`         | `type`-filter: `http` / `https` / `socks4` / `socks5`. Tühi = kõik.                                                  |
| `country`         | string                             | `""`         | `countryCode`-filter (ISO-2). Tühi = kõik.                                                                           |
| `minQuality`      | number                             | `0`          | Ainult read, mille puhul `qualityScore >= minQuality`. `0` = alampiir puudub.                                        |
| `disabledSources` | string                             | `""`         | Komadega eraldatud välistatavate allikate ID-d (nt `proxifly,webshare`).                                             |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality`    | `quality` = skoor kahanevalt; `latency` = latentsus kasvavalt (nullid lõpus); `recent` = `lastValidated` kahanevalt. |
| `offset`          | number                             | `0`          | Lehekülgjaotuse algus.                                                                                               |
| `limit`           | number                             | `50`         | Lehekülje suurus (serveripoolse ülempiiriga).                                                                        |

### Vastus

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 lähteteenusest"],
    "webshare": ["võrgu ajalõpp"]
  }
}
```

`total` kajastab filtreeritud koguarvu **enne** lehekülgedeks jaotamist, et
kasutajaliides saaks väärtusi `Total: N` ja `hasMore` üksteisest sõltumatult
kuvada. `syncErrors` on võtmete kaudu seotud allika ID-dega ja täidetakse ainult
nende allikate puhul, mille viimane sünkroonimine nurjus — tulemusest `Total: 0`
ei vaikita kunagi.

## Kogumisse lisamine — `POST /api/settings/free-proxies/[id]/add-to-pool`

Teisaldab tasuta puhverserveri hallatavasse `proxy_registry` kogumisse. Esmalt
valideeritakse lähteteenus; õnnestumise korral tagastatakse uue kogumi
puhverserveri ID ja mõõdetud latentsus.

## Sünkroonimine — `POST /api/settings/free-proxies/sync`

Hangib uuesti kõik lubatud allikad (või alamhulga väljal `{ "sources": [...] }`).
Iga allikas sünkroonitakse eraldi; nurjunud allikas salvestatakse väljal
`syncErrors` ja ülejäänud viiakse siiski lõpule, mistõttu osaline sünkroonimine
ei kustuta kunagi varasemaid kehtivaid andmeid.

## Statistika — `GET /api/settings/free-proxies/stats`

Tagastab koondandmed `total / inPool / avgQuality / bySource / lastSyncAt` ilma
ridade andmekogumita — seda kasutavad juhtpaneeli päise vidinad.
