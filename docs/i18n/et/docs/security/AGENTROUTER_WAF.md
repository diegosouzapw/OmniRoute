`agentrouter`-i ülesvoolu lüüs rakendab väljale `messages[].content` märksõnapõhist sisufiltrit. Filter on osaliselt deterministlik (blokeerib alati
teatud fraasid) ja osaliselt tõenäosuslik (tundlik päringupuhangute suhtes — muutub
kiirete päringute järel agressiivsemaks ning taastub pärast jahtumisperioodi).

Kui WAF blokeerib päringu, tagastab see:

```
HTTP/1.1 400 Bad Request
{"error":{"code":"content-blocked","message":"content-blocked (request id: ...)","param":"","type":"agent_router_api_error"}}
```

## Filtri ulatus

WAF kontrollib ainult välja `messages[].content`. See **ei** kontrolli:

- `system`-viipa
- Struktureeritud sisuplokke (`tool_result`, `tool_use`, `thinking`, `image`)
- Tööriista välju `description` ja `input_schema`
- Päringu metaandmeid, päiseid ega mudeli ID-d

## Alati blokeeritavad mustrid (tõstutundetud)

| Muster                          | Märkused                                                      |
| ------------------------------- | ------------------------------------------------------------- |
| Mis tahes `Lorem ipsum`-variant | Kogu ladinakeelne lorem-sõnavara blokeeritakse                |
| `language model` (eraldi)       | "the language model" ja "large language model" lubatakse läbi |
| `virtual assistant`             | "AI assistant" lubatakse läbi                                 |
| `I'm here to help`              | Ka eraldiseisev "here to help" blokeeritakse                  |
| `Claude, made by Anthropic`     | Ainult täielik fraas                                          |

## Peaaegu alati blokeeritavad mustrid

| Muster                                                     | Märkused                                                    |
| ---------------------------------------------------------- | ----------------------------------------------------------- |
| `placeholder`                                              | Kui see esineb eraldiseisvalt (mitte parameetri nimena jne) |
| `dummy data`                                               | Levinud algandmete fraas fikstuuride jaoks                  |
| `foo bar baz`                                              | Kanooniline kohatäitefraas                                  |
| Korduvad lühikesed sõned (`AAA BBB CCC`, `test test test`) | Märksõnade kuhjamise tuvastaja                              |

## Käitumine koormuse all

Pärast ligikaudu 5 kiiret päringut lühikese ajavahemiku jooksul hakkab WAF blokeerima sisu,
mis tavaliselt läbi läheks. Piirangule vastav päringukorv leeveneb pärast ligikaudu 5–10 sekundit jõudeolekut.
See on sama IP ja võtmega seotud kiiruspiiraja, mis põhjustab
katkendlikke `400 content-blocked`-tõrkeid, kui Claude Code või Codex CLI
teeb kiiresti järjest mitu tööriistakasutuse või sõnumisaatmise päringut.

## OmniRoute'is juba rakendatud leevendusmeetmed

1. **`open-sse/services/wafRateLimit.ts`** — päringupuhangu kaitse, mis jõustab
   vähemalt 500 ms pikkuse vahe mis tahes `agentrouter:*`-URL-ile saadetavate
   väljaminevate päringute vahel. See vahe jääb inimese tajutavast latentsusest tublisti allapoole ja takistab
   WAF-i aktiveerumist tavapärase liikluse korral.

2. **`BaseExecutor.WAF_RETRY_CONFIG`** — kui ülesvoolu teenus tagastab
   `400 content-blocked`, proovib täitur sama URL-i uuesti
   eksponentsiaalse viivitusega (1,5 s, 3,0 s, maksimaalselt 2 katset). Pärast viivitust
   on WAF tavaliselt leevenenud ja korduskatse õnnestub.

3. **`tests/unit/compression/harness.test.ts`** — testifikstuuri
   `longInput` väärtus muudeti vormilt `"lorem ipsum dolor sit amet ".repeat(40)`
   vormile `"example content for testing purposes ".repeat(40)`, et juhul, kui
   Claude Code loeb seda faili tööriistaga `Read`, ei liiguks faili sisu
   tagasi läbi `tool_result`-ploki ega käivitaks WAF-i.

## Juhised viipade ja tööriistaväljundi jaoks

Kui Claude Code'i või Codex CLI seanss saab korduvalt
`400 content-blocked`-tõrkeid, kontrollige viimast kasutaja sõnumit ja kõige
värskemat tööriistatulemust ülaltoodud mustrite suhtes ning sõnastage see ümber. Levinud
lahendused:

- Asendage `Lorem ipsum …` fraasiga `example text …` või tegeliku sisuga,
  mida test või fikstuur püüab modelleerida.
- Asendage `placeholder` (kui see esineb eraldiseisvalt) fraasiga `example value`,
  `sample value` või tegeliku väärtusega.
- Asendage `language model` fraasiga `large language model` või `the model`.
- Asendage `dummy data` fraasiga `sample data` või realistlike algväärtustega.
- Asendage `I'm here to help` / `here to help` konkreetsema
  avafraasiga (nt "I'll review the file you mentioned").

## Valepositiivsete tulemuste raporteerimine ülesvoolu teenusele

Praegune filter on liiga agressiivne — see blokeerib "Lorem ipsum" teksti
`tool_result`-plokkides, kuigi operaator ei kavatsenud ilmselgelt
viipa sisestada. Operaatorid, kes soovivad probleemi algallikas parandada, peaksid
võtma ühendust saidiga `agentrouter.org`, et valepositiivsetest tulemustest teatada. Ülaltoodud blokeerimisloend
on ülesvoolu teenuse empiirilise testimise tulemus seisuga 2026-08-03.
