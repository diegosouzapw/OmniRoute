> **વપરાશકર્તાઓ માટે**: એક સરળ માર્ગદર્શિકા શોધી રહ્યા છો? મફત AI મેળવવા માટે પગલું-દર-પગલાં સૂચનાઓ માટે [મફત ટાયર્સ માર્ગદર્શિકા](../getting-started/FREE-TIERS-GUIDE.md) જુઓ.

> **છેલ્લું સંશોધન:** 2026-06-17 — પ્રતિ-પ્રદાતા વેબ સંશોધન (અધિકૃત દસ્તાવેજો + છેલ્લા 7 દિવસના સમાચાર, પ્રતિકૂળ ચકાસણી સાથે 50-એજન્ટ પાસ) દરેક મફત-ટાયર ક્વોટા + ToS ને તાજું કરે છે. **આંશિક પુનરાવર્તન 2026-09-02** (`gemini`, `ollama-cloud`, `groq`, `nara`, `mistral` — નીચેની તારીખવાળી નોંધ જુઓ).
> **સત્યનો સ્ત્રોત (કેટલોગ):** `open-sse/config/freeModelCatalog.ts` (પ્રતિ-મોડેલ બજેટ, પૂલ-ડિડ્યુપ્ડ). નીચે આપેલા ટોકન-બજેટ નંબરો લાઇવ વેબ સંશોધનમાંથી આવે છે અને તે એક **અંદાજ** છે — [પદ્ધતિ અને ચેતવણીઓ](#methodology--caveats) જુઓ.

## TL;DR — OmniRoute ખરેખર કેટલું મફત અનુમાન એકત્રિત કરે છે?

| મેટ્રિક                                         | ટોકન્સ / મહિનો      | અર્થ                                                                                                                                                                                                                                                                                                   |
| :---------------------------------------------- | :------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **દસ્તાવેજીકૃત પુનરાવર્તિત અનુદાન (સ્થિર)**     | **~1.62B**          | મફત-ટાયર **પૂલ** (પ્રતિ-મોડેલ કેટલોગ), દરેક શેર કરેલ પૂલ **એકવાર** ગણાય છે. `/api/free-tier/summary` પાછળનો લાઇવ સ્ત્રોત અને ડેશબોર્ડનું ફ્રી-ટાયર બજેટ પૃષ્ઠ. **આ નંબરનો ઉપયોગ કરો.**                                                                                                                 |
| **+ સાઇનઅપ ક્રેડિટ્સ સાથેનો પ્રથમ મહિનો**       | **~2.22B**          | સ્થિર + એક-વખતની સાઇનઅપ ક્રેડિટ્સ (Z.AI 20M, DeepSeek 5M, …), પ્રતિ એકાઉન્ટ ડિડ્યુપ્ડ. **ફક્ત પ્રથમ મહિનો** — પુનરાવર્તિત થતું નથી.                                                                                                                                                                    |
| **+ કાયમી ધોરણે મફત, કોઈ પ્રકાશિત મર્યાદા નથી** | _અન-ક્વોન્ટિફાયેબલ_ | `siliconflow`, `glm-cn` (GLM-4-Flash), `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud` — વાસ્તવિક પુનરાવર્તિત ઍક્સેસ, દર/સમવર્તી-મર્યાદિત, **ગણવા માટે કોઈ ટોકન મર્યાદા નથી**. સૂચિબદ્ધ, ક્યારેય સરવાળો નથી (તેમને `RPM×24/7` પર ગણવું એ ફુગાવો છે જેને આપણે નકારીએ છીએ). |
| **+ ડિપોઝિટ-અનલૉક બૂસ્ટ**                       | **+~24M**           | એક-વખતનું **$10** OpenRouter ટોપ-અપ તેના મફત પૂલને 50 → 1000 req/day સુધી વધારે છે. તેને અલગથી જાણ કરવામાં આવે છે જેથી તે સ્થિર સંખ્યાને ક્યારેય વધારતું નથી.                                                                                                                                          |
| **+ પ્રાદેશિક ઓળખ ચકાસણી પાછળ**                 | **+~6M**            | `modelscope` (અલીબાબા ક્લાઉડ બાઈન્ડિંગ + મેઇનલેન્ડ-ચાઇના વાસ્તવિક-નામ ચકાસણી). વાસ્તવિક પુનરાવર્તિત ક્વોટા, `gatedRecurringTokens` / `gatedProviders` તરીકે અને ડેશબોર્ડ પર ખુલ્લો મૂકવામાં આવે છે. હેડલાઇનમાં ક્યારેય સરવાળો નથી: પ્રાદેશિક ઓળખ ચકાસણી પાછળ +~6M.                                     |
| સૈદ્ધાંતિક મર્યાદા (બધી દર મર્યાદાઓ, 24/7)      | ~10B                | દરેક પ્રદાતા દર મર્યાદાનો સરવાળો નોન-સ્ટોપ ઉપયોગ માટે એક્સ્ટ્રાપોલેટ કરવામાં આવે છે. **ગેરંટી નથી** — આને હેડલાઇન ન કરો.                                                                                                                                                                               |

**પ્રામાણિક હેડલાઇન:** _OmniRoute 35 મફત-ટાયર પૂલમાંથી **દર મહિને ~1.62B દસ્તાવેજીકૃત મફત ટોકન્સ** (સાઇનઅપ ક્રેડિટ્સ સાથે તમારા પ્રથમ મહિનામાં ~2.22B સુધી) એકત્રિત કરે છે — ઉપરાંત કાયમી ધોરણે મફત, નો-કેપ પ્રદાતાઓની લાંબી યાદી — અને RTK + કેવમેન કમ્પ્રેશન (15–95% ટોકન બચત) તેને વધુ વિસ્તૃત કરે છે._

> **આ અગાઉના ~1.94B થી શા માટે ઘટ્યું.** 2026-06-17 નું રિફ્રેશ એ પ્રમાણિકતા સુધારણા છે, નુકસાન નથી: `gemini` હવે પૂલ-ડિડ્યુપ્ડ છે (દરેક ફ્લેશ વેરિઅન્ટને અલગથી ગણવાથી ફૂલી ગયું હતું, 462M → 60M), `cloudflare-ai` તેના વાસ્તવિક 10k-ન્યુરોન્સ/દિવસ પર સુધારવામાં આવ્યું (122M → 30M), `doubao` ને એક-વખતની સાઇનઅપ ક્રેડિટ તરીકે પુનઃવર્ગીકૃત કરવામાં આવ્યું (પુનરાવર્તિત નથી), અને બંધ કરાયેલા ટિયર્સ દૂર કરવામાં આવ્યા (`chutes`/`phind`/`kluster` બંધ કરાયા). `llm7` (સાચું 5M/દિવસ → 150M) અને નવા મફત પ્રદાતાઓ (Kilo, OpenCode Zen, Z.AI GLM-Flash) દ્વારા આંશિક રીતે સરભર કરવામાં આવ્યું.
>
> **v3.8.42 માં ~1.37B સુધી વધુ સુધારવામાં આવ્યું:** `longcat` ને 150M/મહિનાની પુનરાવર્તિત ગ્રાન્ટમાંથી તેના મફત પૂર્વાવલોકન સમાપ્ત થયા પછી એક-વખતની 10M સાઇનઅપ ક્રેડિટ તરીકે પુનઃવર્ગીકૃત કરવામાં આવ્યું. એ જ પ્રમાણિકતાનો નિયમ — કોઈ પ્રદાતા ભૂલથી છોડવામાં આવ્યો ન હતો.
>
> **Felo Web ને નિવૃત્ત કર્યા પછી 2026-08-26 ના રોજ અપડેટ કરાયું:** Felo Web ને બાકાત રાખવામાં આવ્યું છે કારણ કે તેની GPL-વ્યુત્પન્ન ઉત્પત્તિ/લાઇસન્સિંગ HOLD પર છે; તે સમયે સ્ત્રોતે 38 પૂલ કીની જાણ કરી હતી. પૂલની ગણતરી લાઇવ છે અને CI-ગેટ્ડ છે (`check:docs-counts` જો ઉપરોક્ત સંખ્યાઓ `computeFreeModelTotals()` થી અલગ પડે તો બિલ્ડને નિષ્ફળ કરે છે).
>
> **પ્રદાતાઓના પોતાના પૃષ્ઠો સામે 2026-09-02 ના રોજ ફરીથી ઓડિટ કરાયું** (સ્ત્રોતો: `open-sse/config/freeModelCatalog.data.ts` માં દરેક ફરીથી ઓડિટ કરાયેલ એન્ટ્રીની બાજુમાં `// evidence:` ટિપ્પણીઓ): `gemini` અને `ollama-cloud` હવે ટોકન આંકડો પ્રકાશિત કરતા નથી (ગૂગલે 2025-12-23 ના રોજ પ્રતિ-મોડેલ મફત કોષ્ટક દૂર કર્યું; Ollama ની મફત યોજના "સ્ટાર્ટર વપરાશ ક્રેડિટ્સ" છે) અને હવે **અનકેપ્ડ** તરીકે સૂચિબદ્ધ છે, ક્યારેય સરવાળો કરવામાં આવ્યો નથી (−80M); `groq` એ પાંચ **પ્રતિ-મોડેલ** 200K-TPD કેપ્સ (દરેક 6M, +15M) છે જેમાં ત્રણ નિવૃત્ત ID છોડી દેવામાં આવ્યા છે; `nara` એ એક 7M/દિવસની બકેટ છે (+60M, 210M). `mistral` નું 1B ફક્ત એકાઉન્ટ કન્સોલમાં જ દેખાય છે — પદ્ધતિ હેઠળ _પુરાવા વર્ગો_ જુઓ.
>
> **2026-09-03 ના રોજ સુધારવામાં આવ્યું (#11773):** `cerebras` ને 30M/મહિનાની પુનરાવર્તિત ગ્રાન્ટ (જૂની નો-કાર્ડ 1M ટોકન્સ/દિવસની ટ્રાયલ) માંથી એક-વખતની $5 સાઇનઅપ ક્રેડિટ તરીકે પુનઃવર્ગીકૃત કરવામાં આવ્યું છે જેને ચુકવણી પદ્ધતિની જરૂર છે. LongCat જેવો જ પ્રમાણિકતાનો નિયમ.
>

## બે શાસન — ગણતરી વિ. નિર્ણય

ઓમ્નીરૂટ "શું તે મફત છે?" નો જવાબ બે શાસન દ્વારા આપે છે જે ઇરાદાપૂર્વક વિવિધ સ્ત્રોતો વાંચે છે:

| શાસન                 | સત્યનો સ્ત્રોત                                                                                                                                                           | સપાટીઓ                                                                                                                     |
| :------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| **ગણતરી / પ્રદર્શન** | નિર્ધારિત કેટલોગ — શિપ કરેલ બેઝલાઇન જે રડાર ફીડ દ્વારા ઓવરલે કરવામાં આવે છે (`getRadarCatalog`)                                                                          | મફત-ટિયર કુલ, બજેટ કાર્ડ, ડેશબોર્ડ્સ                                                                                       |
| **નિર્ણય લેવો**      | ફક્ત શિપ કરેલ કેટલોગ (`FREE_MODEL_BUDGETS` માં `open-sse/config/freeModelCatalog.data.ts`) વત્તા સ્થાનિક હ્યુરિસ્ટિક્સ (`:free` સફિક્સ, શૂન્ય કિંમત, `grantsFreeAccess`) | `src/shared/utils/freeModels.ts` ના દરેક ઉપભોક્તા: મોડેલ આયાત, `auto/*` રૂટિંગ, `GET /v1/models`, અને બ્રાઉઝર પૂર્વાવલોકનો |

જ્યારે પણ ફીડ ઉપલબ્ધ હોય ત્યારે ગણતરી સુધારી શકાય છે. નિર્ણય રિલીઝ આર્ટિફેક્ટ પર રહે છે, તેથી જવાબ બ્રાઉઝર અને સર્વર પર સમાન હોય છે, ઓફલાઇન પુનરાવર્તિત કરી શકાય તેવું હોય છે, અને ડેટાબેઝ વિના ચકાસી શકાય તેવું હોય છે. બ્રાઉઝર પૂર્વાવલોકનને એક સ્ત્રોત વાંચવા દેવું જ્યારે સર્વર આયાત બીજો સ્ત્રોત વાંચે ત્યારે એવું પૂર્વાવલોકન ઉત્પન્ન કરશે જે ક્લિક કરવા પર શું થાય છે તેની સાથે અસહમત હોય — આ વિભાજન ઇરાદાપૂર્વક રાખવામાં આવ્યું છે.

## પદ્ધતિ અને ચેતવણીઓ

- સંખ્યાઓ **ઉપલી-બાઉન્ડ અંદાજો** છે જે દરેક પ્રદાતાની દસ્તાવેજીકૃત ફ્રી-ટાયર મર્યાદાઓમાંથી **2026-06-17** સુધીની છે, જે વેબ સંશોધન દ્વારા એકત્રિત કરવામાં આવી છે. ફ્રી ટાયર સતત બદલાય છે — કોઈ આંકડા પર આધાર રાખતા પહેલા ફરીથી ચકાસો.

- `estMonthlyFreeTokens` = ફક્ત પુનરાવર્તિત માસિક ટોકન્સ. **એક-વખતની સાઇનઅપ ક્રેડિટ્સ પુનરાવર્તિત થતી નથી** અને 0 તરીકે ગણાય છે. બંધ કરાયેલા ટાયર પણ 0 છે.
- દૈનિક ટોકન કેપ → `માસિક = દૈનિક × 30`. ફક્ત RPD દસ્તાવેજીકૃત → `RPD × ~800 આઉટપુટ ટોકન્સ × 30`. ફક્ત RPM/TPM (કોઈ દૈનિક કેપ નથી) → **અનકેપ્ડ** (નીચે જુઓ).
- **કાયમી ધોરણે મફત, પરંતુ કોઈ પ્રકાશિત ટોકન કેપ નથી** (`siliconflow`, `glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): આ વાસ્તવિક પુનરાવર્તિત મફત ઍક્સેસ છે, દર/સહવર્તીતા-મર્યાદિત. અમે તેમને `recurring-uncapped` તરીકે વર્ગીકૃત કરીએ છીએ અને **તેમને ક્યારેય સરવાળો કરતા નથી** — `RPM × 24/7 × 30d` નો ગુણાકાર કાલ્પનિક છત (જે ફુગાવાને આપણે નકારીએ છીએ) ઉત્પન્ન કરશે. તેઓ સૂચિબદ્ધ છે જેથી તમે જાણો કે તેઓ અસ્તિત્વમાં છે.
- **ડિપોઝિટ-અનલોક બૂસ્ટ:** એક-વખતનો નાનો ટોપ-અપ જે કાયમી ધોરણે મફત ક્વોટા વધારે છે (OpenRouter: $10 → 1000 req/day ≈ +24M/mo). એક અલગ આંકડા તરીકે જાણ કરવામાં આવે છે, જે સ્થિર હેડલાઇનથી દૂર રાખવામાં આવે છે.
- **પાત્રતા-ગેટવાળા ક્વોટા** (`eligibilityGate: "regional-identity"`): એક વાસ્તવિક પુનરાવર્તિત ક્વોટા જે ફક્ત પ્રદેશ-બાઉન્ડ ઓળખ ચકાસણી પછી જ ખુલે છે (આજે મેઇનલેન્ડ-ચાઇના વાસ્તવિક-નામ ચકાસણી). સમાન પૂલ-ડિડ્યુપ નિયમ સાથે એક અલગ આંકડા (`gatedRecurringTokens`) માં ગણવામાં આવે છે, ક્યારેય સ્થિર હેડલાઇનમાં નહીં. શાસન (`freeType`) યથાવત છે, તેથી રૂટીંગ યથાવત છે.
- **પુરાવા વર્ગો.** નિયમ: કેટલોગમાંની સંખ્યા તેની એન્ટ્રીની બાજુમાં `// evidence:` ટિપ્પણીમાં તેના સ્ત્રોતને ટાંકે છે — `public-page` (એક પ્રદાતા પૃષ્ઠ જે કોઈ પણ વાંચી શકે છે), `api-public` (પ્રદાતાનો એક અપ્રમાણિત એન્ડપોઇન્ટ, દા.ત. router.bynara.id પર NaraRouter નો સાર્વજનિક પ્લાન એન્ડપોઇન્ટ), અથવા `console-verified <date> por <who>` (આંકડો ફક્ત એક એકાઉન્ટ કન્સોલની અંદર જ દેખાય છે; ટિપ્પણી કોણે અને ક્યારે જોયું તે રેકોર્ડ કરે છે, અને સાર્વજનિક પૃષ્ઠ જે કહે છે કે કેપ અસ્તિત્વમાં છે). આજની સ્થિતિ: 2026-09-02 ના રોજ ફરીથી ઓડિટ કરાયેલા પાંચ બ્લોક્સ તેને ધરાવે છે (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); 2026-09-02 ના ફરીથી ઓડિટ પહેલાની એન્ટ્રીઓ જ્યાં સુધી તેમને સ્પર્શ ન થાય ત્યાં સુધી અગાઉના સંશોધનનો વારસો મેળવે છે; પુરાવા ટિપ્પણી વિનાની કોઈપણ **નવી અથવા બદલાયેલી** સંખ્યા એક ભૂલ છે. આજે ફક્ત `mistral` કન્સોલ-ચકાસાયેલ છે.

## શા માટે અમારો આંકડો અન્ય એગ્રીગેટર્સ કરતાં નાનો છે

આ ક્ષેત્રમાં મોટાભાગના "દર મહિને મફત ટોકન્સ"ના આંકડા પ્રતિ-મોડેલ લેબલ્સનો સરવાળો હોય છે. અમારો આંકડો એવો નથી, અને તે ઇરાદાપૂર્વક છે:

- **દરેક શેર કરેલ પૂલ એકવાર ગણાય છે.** મિસ્ટ્રલની મફત યોજના પ્રતિ સંસ્થા એક 1B/મહિનાની મર્યાદા છે; તેને પાંચ મોડેલ હેઠળ સૂચિબદ્ધ કરવાથી તે 5B બનતું નથી. પ્રતિ મોડેલનો સરવાળો કરીએ તો, અમારી પોતાની સૂચિ **~7.4B** વાંચશે (2026-09-03 ના રોજ ફરીથી ગણતરી કરાઈ; આ આંકડો CI-ગેટ નથી — જ્યારે પણ સૂચિ બદલાય ત્યારે તેને ફરીથી માપો) — હેડલાઇન **~1.47B** કહે છે કારણ કે દરેક પ્રદાતાનું એક ખાતું ખરેખર એટલું જ ખર્ચ કરી શકે છે.
- **દૈનિક મર્યાદાઓ રૂપાંતરિત થાય છે, દરો નહીં.** દસ્તાવેજીકૃત ટોકન્સ/દિવસની મર્યાદા `× 30` બને છે; દસ્તાવેજીકૃત વિનંતીઓ/દિવસની મર્યાદા `RPD × ~800 tokens × 30` બને છે; જે પ્રદાતા ફક્ત પ્રતિ-મિનિટ વિનંતીઓ પ્રકાશિત કરે છે તેની પાસે **કોઈ** માસિક આંકડો નથી અને તેને _અનકેપ્ડ_ તરીકે સૂચિબદ્ધ કરવામાં આવે છે, ક્યારેય સરવાળો કરવામાં આવતો નથી. દર મર્યાદાને 24/7 વડે ગુણવું એ ફુગાવો છે જેને અમે નકારીએ છીએ.
- **પ્રાદેશિક ઓળખ ચકાસણી પાછળના ક્વોટા અલગથી દર્શાવવામાં આવે છે** (`+~6M behind regional identity verification`), કારણ કે મોટાભાગના વાચકો તેનો ઉપયોગ કરી શકતા નથી.
- **સાઇનઅપ ક્રેડિટ્સ ફક્ત પ્રથમ મહિના માટે હોય છે** અને તેને બીજા આંકડા તરીકે દર્શાવવામાં આવે છે, ક્યારેય સ્થિર સંખ્યામાં ભેળવવામાં આવતા નથી.
- **આ આંકડો CI દ્વારા લાગુ કરવામાં આવે છે.** `npm run check:docs-counts` કેટલોગમાંથી કુલ રકમની ફરીથી ગણતરી કરે છે અને જ્યારે આ ફાઇલ, README અથવા બજેટ કાર્ડ તેમાંથી અલગ પડે ત્યારે બિલ્ડ નિષ્ફળ કરે છે.

## ToS ધ્યાન કોષ્ટક

> **ToS ફ્લેગ સલાહકારી છે, રૂટીંગ ગેટ નથી.** `tos` તરીકે ચિહ્નિત પ્રદાતાઓ ડિફોલ્ટ રૂપે રૂટીંગ અને કોમ્બો/ફોલબેકમાં શામેલ હોય છે; આ ફ્લેગ ફક્ત `/dashboard/free-tiers` અને `/api/free-tier/summary` પર જ દેખાય છે. `excludeTosAvoid` ક્વેરી પેરામીટર ફક્ત સારાંશ દૃશ્યને અસર કરે છે, વૈશ્વિક રૂટીંગને નહીં. ચુકાદો `open-sse/config/freeTierCatalog.ts` માં રહેલો છે (માહિતીપ્રદ, રૂટીંગ એન્જિન દ્વારા વાંચવામાં આવતો નથી).

> સ્વ-હોસ્ટેડ, સિંગલ-યુઝર પર્સનલ પ્રોક્સી માટે દરેક પ્રદાતાની શરતો પર એક ઝડપી નજર. `caution` = વ્યક્તિગત-ઉપયોગ અથવા પ્રોક્સી કલમ તપાસવા યોગ્ય; `ambiguous` = અસ્પષ્ટ; `ok` = સ્પષ્ટપણે મંજૂર. માહિતીપ્રદ, કાનૂની સલાહ નથી — તમે નક્કી કરો.

## OpenCode Free: ક્લાયન્ટ-કોન્ટ્રાક્ટ પ્રતિબંધ (#14313)

કીલેસ `opencode` પ્રદાતા (જાહેર `https://opencode.ai/zen/v1`) OpenCode ક્લાયન્ટ કોન્ટ્રાક્ટ સાથે મેળ ન ખાતી કોઈપણ વિનંતીને **403 `FreeTierError`** અને વાક્ય _"OpenCode's free tier can only be used from within OpenCode"_ સાથે નકારે છે. આ એક વિનંતી-આધારિત અસ્વીકૃતિ છે (સમાન વિનંતી આકાર માટે દરેક એકાઉન્ટ પર સમાન ચુકાદો), મોડેલ પ્રતિબંધ અથવા કનેક્શન કૂલડાઉન નથી — OmniRoute તેને `project_route_error` તરીકે વર્ગીકૃત કરે છે, મોડેલ લોકઆઉટ / કૂલડાઉન છોડી દે છે, અને (સિન્થેટિક `noauth` પાથ પર) ટૂંકા TTL માટે ઓટો-કોમ્બો પુનઃ-પસંદગીને થોભાવે છે. બિન-ખાલી ટૂલ સૂચિ, `stream: true`, અને OpenCode સેશન/UA હેડર્સ (`opencodeFreeTierContract.ts`) ધરાવતી વિનંતીઓ મોકલો અથવા 403 ની અપેક્ષા રાખો.
