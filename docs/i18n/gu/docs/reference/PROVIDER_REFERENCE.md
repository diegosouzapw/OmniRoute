## કેટેગરીઓ

- **મફત** — API કી સાથેનું મફત ટિયર (ડૅશબોર્ડ દ્વારા કૉન્ફિગર કરેલું)
- **પ્રમાણીકરણ વિના** — જાહેર એન્ડપોઇન્ટ્સ, જેમને કોઈ કી અથવા સાઇન-ઇનની બિલકુલ જરૂર નથી
- **OAuth** — સાઇન-ઇન પ્રવાહ OmniRoute દ્વારા સંચાલિત થાય છે, API કીની જરૂર નથી
- **વેબ કૂકી** — કૂકી પ્રમાણીકરણ દ્વારા પ્રોવાઇડરની વેબ ઍપને રૅપ કરે છે
- **API કી** — API કી દ્વારા કૉન્ફિગર કરાયેલો પેઇડ પ્રોવાઇડર (મફત ક્રેડિટ્સ લાગુ પડી શકે છે)
- **લોકલ** — વપરાશકર્તાના મશીન પર ચાલે છે (Ollama, LM Studio, vLLM વગેરે)
- **શોધ** — વેબ શોધ પ્રોવાઇડર્સ
- **ઑડિયો** — માત્ર ઑડિયો પ્રોવાઇડર્સ (TTS/STT)
- **અપસ્ટ્રીમ પ્રૉક્સી** — અન્ય પ્રોવાઇડર્સને પ્રૉક્સી કરતા પ્રોવાઇડર્સ
- **ક્લાઉડ એજન્ટ** — લાંબા સમય સુધી ચાલતા કોડિંગ એજન્ટ્સ (Codex Cloud, Devin, Jules)
- **સિસ્ટમ** — OmniRouteના આંતરિક પ્રોવાઇડર્સ (લૂપબૅક વગેરે)

વધારાના ટૅગ્સ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`ટૂલ કૉલિંગ` (જ્યાં દર્શાવ્યું હોય ત્યાં): `native` — વાસ્તવિક ફંક્શન-કૉલિંગ API; `emulated` — `tools` ઍરેને `webTools.ts` દ્વારા પ્રૉમ્પ્ટમાં અનુકરિત કરવામાં આવે છે (રેગેક્સથી પાર્સ કરેલા `<tool>{...}</tool>` બ્લૉક્સ); `none` — હાલમાં `tools`ને કોઈ સૂચના વિના અવગણવામાં આવે છે. #7286 જુઓ.

દરેક પ્રોવાઇડરને સક્ષમ, કૉન્ફિગર અને ચકાસવા માટે `/dashboard/providers` પરના ડૅશબોર્ડનો ઉપયોગ કરો.
