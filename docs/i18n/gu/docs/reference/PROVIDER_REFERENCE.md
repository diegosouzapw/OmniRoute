## શ્રેણીઓ

- **મફત** — API કી સાથેનું મફત સ્તર (ડૅશબોર્ડ દ્વારા ગોઠવેલું)
- **પ્રમાણીકરણ વિનાનું** — સાર્વજનિક એન્ડપોઇન્ટ્સ જેને કોઈ કી કે સાઇન-ઇનની જરૂર નથી
- **OAuth** — સાઇન-ઇન પ્રક્રિયા OmniRoute દ્વારા સંચાલિત થાય છે, API કીની જરૂર નથી
- **વેબ કૂકી** — કૂકી પ્રમાણીકરણ દ્વારા પ્રદાતાની વેબ ઍપને આવરે છે
- **API કી** — API કી દ્વારા ગોઠવાતો સશુલ્ક પ્રદાતા (મફત ક્રેડિટ લાગુ પડી શકે છે)
- **સ્થાનિક** — વપરાશકર્તાના મશીન પર ચાલે છે (Ollama, LM Studio, vLLM વગેરે)
- **શોધ** — વેબ શોધ પ્રદાતાઓ
- **ઑડિયો** — માત્ર ઑડિયો માટેના પ્રદાતાઓ (TTS/STT)
- **અપસ્ટ્રીમ પ્રૉક્સી** — અન્ય પ્રદાતાઓ તરફ પ્રૉક્સી કરતા પ્રદાતાઓ
- **ક્લાઉડ એજન્ટ** — લાંબા સમય સુધી ચાલતા કોડિંગ એજન્ટો (Codex Cloud, Devin, Jules)
- **સિસ્ટમ** — OmniRoute-આંતરિક પ્રદાતાઓ (લૂપબૅક વગેરે)

વધારાના ટૅગ્સ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`ટૂલ કૉલિંગ` (જ્યાં દર્શાવ્યું હોય ત્યાં): `native` — વાસ્તવિક ફંક્શન-કૉલિંગ API; `emulated` — `tools` ઍરેનું `webTools.ts` દ્વારા પ્રૉમ્પ્ટ-અનુકરણ કરવામાં આવે છે (regex દ્વારા પાર્સ કરાયેલા `<tool>{...}</tool>` બ્લૉક્સ); `none` — હાલમાં `tools` કોઈ સૂચના વિના અવગણવામાં આવે છે. #7286 જુઓ.

દરેક પ્રદાતાને સક્ષમ કરવા, ગોઠવવા અને ચકાસવા માટે `/dashboard/providers` પરના ડૅશબોર્ડનો ઉપયોગ કરો.
