OmniRoute `free_proxies` કોષ્ટકમાં મફત પ્રોક્સીઓનો કાળજીપૂર્વક પસંદ કરેલો સમૂહ પ્રદાન કરે છે,
જે બાહ્ય પ્રદાતાઓ (1proxy, proxifly, iplocate, webshare)માંથી સમન્વયિત થાય છે. ડેશબોર્ડ
આ પ્રોક્સીઓને **Settings → Free Proxies** હેઠળ દર્શાવે છે. આ દસ્તાવેજ
લિસ્ટ રૂટ દ્વારા ઉપલબ્ધ કરાવવામાં આવતા સર્વર-સાઇડ ફિલ્ટરિંગ, સૉર્ટિંગ, ગણતરી અને સમન્વયન-ભૂલ રિપોર્ટિંગને
આવરી લે છે.

## લિસ્ટ રૂટ — `GET /api/settings/free-proxies`

કુલ ગણતરી સાથે ફિલ્ટર કરેલો, સૉર્ટ કરેલો અને પૃષ્ઠાંકિત ભાગ પરત કરે છે. ફિલ્ટરિંગ અને
ગણતરી SQLમાં થાય છે, જેથી UI દરેક પંક્તિને મેમરીમાં લોડ કર્યા વિના વાસ્તવિક કુલ સંખ્યા (દા.ત. `Total: 0`)
દર્શાવી શકે.

### ક્વેરી પેરામીટર્સ

| પેરામીટર          | પ્રકાર                             | ડિફૉલ્ટ   | અર્થ                                                                                                                        |
| ----------------- | ---------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------- |
| `search`          | સ્ટ્રિંગ                           | `""`      | હોસ્ટ (અને સ્રોત) કૉલમ પર કેસ-સેન્સિટિવ `LIKE`.                                                                             |
| `protocol`        | સ્ટ્રિંગ                           | `""`      | `type` ફિલ્ટર: `http` / `https` / `socks4` / `socks5`. ખાલી = બધા.                                                          |
| `country`         | સ્ટ્રિંગ                           | `""`      | `countryCode` ફિલ્ટર (ISO-2). ખાલી = બધા.                                                                                   |
| `minQuality`      | સંખ્યા                             | `0`       | માત્ર `qualityScore >= minQuality` ધરાવતી પંક્તિઓ. `0` = કોઈ ન્યૂનતમ મર્યાદા નહીં.                                          |
| `disabledSources` | સ્ટ્રિંગ                           | `""`      | બાકાત રાખવાના કૉમાથી અલગ કરેલા સ્રોત ids (દા.ત. `proxifly,webshare`).                                                       |
| `sortBy`          | `quality` \| `latency` \| `recent` | `quality` | `quality` = સ્કોર ઉતરતા ક્રમમાં; `latency` = લેટન્સી ચઢતા ક્રમમાં (nulls છેલ્લે); `recent` = `lastValidated` ઉતરતા ક્રમમાં. |
| `offset`          | સંખ્યા                             | `0`       | પૃષ્ઠાંકનની શરૂઆત.                                                                                                          |
| `limit`           | સંખ્યા                             | `50`      | પૃષ્ઠનું કદ (સર્વર-સાઇડ પર મર્યાદિત).                                                                                       |

### પ્રતિસાદ

```json
{
  "success": true,
  "data": {
    "proxies": [/* FreeProxyRecord[] */],
    "total": 137,
    "hasMore": true
  },
  "stats": {
    "total": 137,
    "inPool": 12,
    "avgQuality": 64.2,
    "bySource": [{ "source": "1proxy", "count": 90 }],
    "lastSyncAt": "2026-07-11T09:30:00.000Z"
  },
  "syncErrors": {
    "proxifly": ["HTTP 429 from upstream"],
    "webshare": ["network timeout"]
  }
}
```

`total` પૃષ્ઠાંકન **પહેલાંની** ફિલ્ટર કરેલી કુલ સંખ્યા દર્શાવે છે, જેથી UI
`Total: N` અને `hasMore`ને સ્વતંત્ર રીતે રેન્ડર કરી શકે. `syncErrors`માં કી તરીકે સ્રોત id હોય છે અને
તે માત્ર એવા સ્રોતો માટે ભરાય છે જેમનું છેલ્લું સમન્વયન નિષ્ફળ ગયું હતું — `Total: 0` પરિણામ
ક્યારેય કોઈ જાણકારી વિના રહેતું નથી.

## પૂલમાં ઉમેરવું — `POST /api/settings/free-proxies/[id]/add-to-pool`

મફત પ્રોક્સીને મેનેજ કરેલા `proxy_registry` પૂલમાં પ્રમોટ કરે છે. પહેલાં
અપસ્ટ્રીમને માન્ય કરે છે; સફળતા પર નવા પૂલ પ્રોક્સીનું id અને માપવામાં આવેલી લેટન્સી પરત કરે છે.

## સમન્વયન — `POST /api/settings/free-proxies/sync`

બધા સક્ષમ સ્રોતો (અથવા `{ "sources": [...] }`માં આપેલો ઉપસમૂહ) ફરીથી મેળવે છે. દરેક
સ્રોત સ્વતંત્ર રીતે સમન્વયિત થાય છે; નિષ્ફળ થતો સ્રોત `syncErrors`માં નોંધાય છે અને
બાકીના હજુ પણ પૂર્ણ થાય છે, જેથી આંશિક સમન્વયન અગાઉનો સારો ડેટા ક્યારેય કાઢી નાખતું નથી.

## આંકડા — `GET /api/settings/free-proxies/stats`

પંક્તિ પેલોડ વિના `total / inPool / avgQuality / bySource / lastSyncAt` એકંદર માહિતી
પરત કરે છે — તેનો ઉપયોગ ડેશબોર્ડ હેડર વિજેટ્સ દ્વારા થાય છે.
