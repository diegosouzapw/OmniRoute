## અવલોકન

Playground Studio `/dashboard/playground` ને સરળ Monaco-આધારિત એડિટરમાંથી
સંપૂર્ણ સુવિધાયુક્ત પરીક્ષણ કાર્યસ્થળમાં રૂપાંતરિત કરે છે. તે જૂના `page.tsx` ને ચાર ટૅબ અને સહિયારી કન્ફિગ પેન રેન્ડર કરતા `PlaygroundStudio`
શેલથી બદલે છે.


## ટૅબ્સ

### ચૅટ ટૅબ

`ChatPlayground.tsx` ને મલ્ટિ-ટર્ન સ્ટ્રીમિંગ વર્કબેન્ચ તરીકે વિકસાવે છે:

- `MarkdownMessage.tsx` દ્વારા સંપૂર્ણ માર્કડાઉન રેન્ડરિંગ (કોડ બ્લૉક્સ, કોષ્ટકો, યાદીઓ, લિંક્સ).
- સહિયારી કન્ફિગ પેનમાંથી મેળવાયેલ સિસ્ટમ પ્રોમ્પ્ટ.
- દરેક સંદેશ દીઠ ટોકન/ખર્ચ (પ્રોમ્પ્ટ + પૂર્ણતા ટોકન્સ).
- છેલ્લો પ્રતિસાદ ફરીથી જનરેટ કરવાની સુવિધા.
- SSE સ્ટ્રીમિંગ સાથે `POST /v1/chat/completions` પર મોકલે છે.

### સરખામણી ટૅબ

પ્રૉક્સી માટેનું મુખ્ય વિભેદક: એક પ્રોમ્પ્ટને વધુમાં વધુ **4 મોડલ પર સમાંતરે** ચલાવો.

- વધુમાં વધુ 4 કૉલમ, જેમાંની દરેક `/v1/chat/completions` પરથી સ્વતંત્ર રીતે સ્ટ્રીમ કરે છે.
- કૉલમ ઉમેરવા માટે `+ મોડલ ઉમેરો` બટન (Cmd+K શૉર્ટકટ).
- `બધાં ચલાવો ▶`, `Promise.all` + દરેક કૉલમ માટે અલગ `AbortController` દ્વારા બધા સ્ટ્રીમને એકસાથે ટ્રિગર કરે છે.
- વૈશ્વિક **બધાં રદ કરો** દરેક ચાલુ સ્ટ્રીમને અટકાવે છે.
- દરેક કૉલમનું `ProviderMetrics` રીઅલ ટાઇમમાં TTFT, TPS, ટોકન્સ અને અંદાજિત ખર્ચ દર્શાવે છે.
- મેટ્રિક્સને **"ક્લાયન્ટ-સાઇડ અંદાજ"** (D12) તરીકે લેબલ કરવામાં આવ્યા છે — પ્રથમ SSE ચંકથી માપવામાં આવે છે.

### API ટૅબ

પ્રવીણ વપરાશકર્તાઓ માટે મૂળ Monaco એડિટરનો 100% હિસ્સો જાળવી રાખે છે (D14):

- 10 એન્ડપૉઇન્ટ્સ: ચૅટ કમ્પ્લીશન્સ, કમ્પ્લીશન્સ, એમ્બેડિંગ્સ, ઇમેજિસ, ઑડિયો, સ્પીચ, ટ્રાન્સક્રિપ્શન્સ, મૉડરેશન્સ, રીરૅન્ક, સર્ચ.
- મલ્ટિમોડલ ફાઇલ અપલોડ.
- રીઅલ-ટાઇમ આઉટપુટ સાથે SSE સ્ટ્રીમિંગ.
- `ApiTab.tsx` તરીકે રૅપ કરાયેલ (લેઝી-લોડેડ, `ssr: false`).

### બિલ્ડ ટૅબ

ટૂલ્સ/ફંક્શન કૉલિંગ અને સ્ટ્રક્ચર્ડ આઉટપુટ UI:

- `ToolsBuilder.tsx` — દરેક ટૂલ માટે JSON સ્કીમા એડિટર સાથે `tools[]` ઉમેરો/સંપાદિત કરો/દૂર કરો.
  `ToolDefinitionSchema` (Zod) દ્વારા પેરામીટર્સને માન્ય કરે છે.
- `StructuredOutputEditor.tsx` — JSON મોડ ટૉગલ + JSON સ્કીમા એડિટર.
  `StructuredOutputSchema` (Zod) દ્વારા સ્કીમા સામે પ્રતિસાદને માન્ય કરે છે.
- `tools[]` અને/અથવા `response_format` સાથે `/v1/chat/completions` પર વિનંતી મોકલે છે.

## કૉન્ફિગ પેન (સહિયારું)

`StudioConfigPane.tsx` — હંમેશાં દૃશ્યમાન, સંકોચી શકાય તેવું.

| ફીલ્ડ            | કમ્પોનન્ટ             | નોંધો                                                                     |
| ---------------- | --------------------- | ------------------------------------------------------------------------- |
| એન્ડપોઇન્ટ       | `<select>`            | `PlaygroundEndpoint` સાથે મેળ ખાતા 10 વિકલ્પો                             |
| મોડેલ            | `<input>`             | મુક્ત ટેક્સ્ટ, દા.ત. `openai/gpt-4o`                                      |
| સિસ્ટમ પ્રોમ્પ્ટ | `<textarea>`          | તમામ ટૅબમાં મોકલવામાં આવે છે                                              |
| પેરામીટર્સ       | `ParamSliders`        | temperature, max_tokens, top_p, presence/frequency penalty, seed, stop    |
| પ્રીસેટ્સ        | `PresetPicker`        | નામ આપેલા કૉન્ફિગ સ્નૅપશૉટ લોડ/સેવ કરો (DBમાં સંગ્રહિત)                   |

કૉન્ફિગ સ્ટેટ જળવાઈ રહે છે.

## પ્રોમ્પ્ટ સુધારક

`ImprovePromptButton.tsx` → `useImprovePrompt.ts` → `POST /api/playground/improve-prompt`:

1. મોડલ "ક્વોટાનો વપરાશ થશે" એવી ચેતવણી આપે છે.
2. પુષ્ટિ કર્યા પછી, રૂટને `{ system, prompt, model, tone }` મોકલે છે.
3. રૂટ આંતરિક રીતે `promptImprover.META_SYSTEM_PROMPT` સાથે `/v1/chat/completions`ને કૉલ કરે છે.
4. `{ improvedSystem?, improvedPrompt?, tokensIn, tokensOut }` પરત કરે છે.
5. UI, કૉન્ફિગ પેનના સિસ્ટમ પ્રોમ્પ્ટ અને ચૅટ ટૅબના યુઝર પ્રોમ્પ્ટને પૅચ કરે છે.

## પ્રીસેટ્સ

`PresetPicker.tsx` → `usePresets.ts` → `/api/playground/presets/*`:

- `playground_presets` SQLite ટેબલમાં સંગ્રહિત થાય છે (માઇગ્રેશન `084_playground_presets.sql`).
- દરેક પ્રીસેટ આને સંગ્રહે છે: `name`, `endpoint`, `model`, `system`, `params_json`, `created_at`.
- CRUD: `GET` સૂચિ, `POST` બનાવવું, `GET /:id`, `PUT /:id`, `DELETE /:id`.

## સ્ટ્રીમ મેટ્રિક્સ

`useStreamMetrics.ts` + `streamMetrics.ts` (પ્યોર ફંક્શન):

- `start()` — રિક્વેસ્ટ શરૂ થવાનો સમય રેકોર્ડ કરે છે.
- `onFirstChunk()` — TTFT રેકોર્ડ કરે છે.
- `onChunk(n)` — કમ્પ્લીશન ટોકનની સંખ્યા એકત્રિત કરે છે.
- `finish(usage?)` — અંતિમ મેટ્રિક્સની ગણતરી કરે છે: `ttftMs`, `totalMs`, `tps`, `tokensIn`, `tokensOut`, `costUsd`.
- કિંમત `src/lib/playground/types.ts`માં આવેલી સ્ટૅટિક ટેબલમાંથી લેવામાં આવે છે ("અંદાજિત" તરીકે લેબલ કરેલી — D13).

## બૅકએન્ડ રૂટ્સ

| મેથડ     | પાથ                              | હૅન્ડલર                                                                                                       |
| -------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `POST`   | `/api/playground/improve-prompt` | `ImprovePromptRequestSchema` વડે Zod-વૅલિડેશન કરે છે; મેટા-પ્રોમ્પ્ટ સાથે `/v1/chat/completions`ને કૉલ કરે છે |
| `GET`    | `/api/playground/presets`        | `{ presets: PlaygroundPresetListItem[] }` પરત કરે છે                                                          |
| `POST`   | `/api/playground/presets`        | પ્રીસેટ બનાવે છે; `PlaygroundPresetCreateSchema`ને વૅલિડેટ કરે છે                                             |
| `GET`    | `/api/playground/presets/:id`    | એક પ્રીસેટ અથવા 404 પરત કરે છે                                                                                |
| `PUT`    | `/api/playground/presets/:id`    | આંશિક અપડેટ                                                                                                   |
| `DELETE` | `/api/playground/presets/:id`    | 204                                                                                                           |

ઑથ: વૈકલ્પિક (`REQUIRE_API_KEY`). ભૂલો `buildErrorBody()` દ્વારા (કડક નિયમ #12).

## સમસ્યા નિવારણ

| લક્ષણ                                         | કારણ                            | ઉકેલ                                                                                            |
| --------------------------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------- |
| API ટૅબમાં Monaco એડિટર રેન્ડર થતું નથી       | SSR દ્વારા Monaco લોડ થયું      | ચકાસો કે `ApiTab`, `dynamic(..., { ssr: false })` નો ઉપયોગ કરે છે                               |
| તુલનાત્મક સ્ટ્રીમ્સ ક્રમશઃ શરૂ થાય છે         | `Promise.all` નો ખોટો ઉપયોગ     | તમામ સ્ટ્રીમની શરૂઆત એક જ `Promise.all` કૉલમાં ડિસ્પૅચ થવી જોઈએ                                 |
| મેટ્રિક્સમાં TTFT માટે `null` દેખાય છે        | પ્રથમ ચંક હેન્ડલર જોડાયેલું નથી | તપાસો કે SSE રીડર લૂપમાં `useStreamMetrics.onFirstChunk()` કૉલ થાય છે                           |
| પ્રીસેટ કાયમ રહેતું નથી                       | DB માઇગ્રેશન ચલાવ્યું નથી       | `npm run db:migrate` ચલાવો અથવા સર્વર પુનઃપ્રારંભ કરો (સ્ટાર્ટઅપ વખતે માઇગ્રેશન આપમેળે ચાલે છે) |
| પ્રોમ્પ્ટ સુધારવાથી 502 મળે છે                | Config માં મોડેલ સેટ કરેલું નથી | સુધારો કરતા પહેલાં વપરાશકર્તાએ Config પેનમાં મોડેલનું નામ દાખલ કરવું આવશ્યક છે                  |
| નિકાસ કરેલા કોડમાં `MISSING_API_KEY` દેખાય છે | પ્લેસહોલ્ડર દાખલ થયું નથી       | `codeExport.ts` હંમેશાં `API_KEY_PLACEHOLDER = "$OMNIROUTE_API_KEY"` નો ઉપયોગ કરે છે            |
