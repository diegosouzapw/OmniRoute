> વાયરિંગ `open-sse/mcp-server/server.ts`માં છે.

## તે શું છે

OmniRoute **Notion** વર્કસ્પેસ સાથે **સંદર્ભ સ્રોત** તરીકે કનેક્ટ થઈ શકે છે — એક વાંચવા/લખવા યોગ્ય
જ્ઞાન આધાર, જેને એજન્ટ્સ બિલ્ટ-ઇન MCP સર્વર દ્વારા ઍક્સેસ કરે છે. Notion
ઇન્ટિગ્રેશન ટોકન કૉન્ફિગર થઈ જાય પછી, MCP ટૂલ્સ LLMને પેજ અને ડેટાબેઝ શોધવા,
પેજની સામગ્રી અને બ્લોક ટ્રી વાંચવા, ફિલ્ટર/સૉર્ટ સાથે ડેટાબેઝ ક્વેરી કરવા અને નવા
બ્લોક ઉમેરવા દે છે — આ બધું OmniRoute મારફતે પ્રૉક્સી થાય છે (પુનઃપ્રયાસ, સમયસમાપ્તિ અને ભૂલ વર્ગીકરણ સાથે),
જેથી મોડલ ક્યારેય Notion APIને સીધું ઍક્સેસ કરતું નથી.

આ ઇન્ટિગ્રેશન સત્તાવાર Notion REST API
(`https://api.notion.com/v1`, `Notion-Version: 2026-03-11`) પરનું પાતળું, મજબૂત બનાવેલું રૅપર છે. ક્લાયન્ટ
(`src/lib/notion/api.ts`) આ સુવિધાઓ ઉમેરે છે:

- `429` અને `5xx` માટે **એક્સ્પોનેન્શિયલ બૅકઑફ સાથે પુનઃપ્રયાસ** (વધુમાં વધુ 3 પ્રયાસો).
- `AbortController` મારફતે **55-સેકન્ડની વિનંતી સમયસમાપ્તિ**.
- **પ્રકારબદ્ધ ભૂલ વર્ગીકરણ** — `NotionAuthError` (401/403),
  `NotionNotFoundError` (404), `NotionRateLimitError` (429, `retry after`
  સંકેતોનું પાલન કરે છે), `NotionValidationError` (400/409), `NotionServerError` (5xx),
  `NotionTimeoutError`.
- **સંદેશ સ્વચ્છીકરણ**, જે દર્શાવતા પહેલાં સ્ટૅક-ટ્રેસ જેવા અંશો દૂર કરે છે.

## સેટઅપ

Notion ટોકન માટે **કોઈ પર્યાવરણ ચલ નથી** — તે
`src/lib/db/notion.ts` મારફતે SQLite `key_value` કોષ્ટકમાં (નેમસ્પેસ `notion`, કી `integration_token`)
સંગ્રહિત થાય છે. તેને Endpoint ડૅશબોર્ડના **Context Sources** ટૅબમાંથી
(`ObsidianSourceCard`ના સમકક્ષ `NotionSourceCard`) અથવા સેટિંગ્સ REST API મારફતે કૉન્ફિગર કરો.

> [!NOTE]
> આ ટોકન એક **Notion આંતરિક ઇન્ટિગ્રેશન ટોકન** છે. અહીં ઇન્ટિગ્રેશન બનાવો:
> <https://www.notion.com/my-integrations>, ત્યારબાદ તમે OmniRouteને જે પેજ/ડેટાબેઝ
> ઍક્સેસ કરવા દેવા માંગો છો, તે આ ઇન્ટિગ્રેશન સાથે શેર કરો (Notionનું પરવાનગી મોડલ શેર-આધારિત છે,
> સમગ્ર વર્કસ્પેસ-આધારિત નથી).

### REST મારફતે કૉન્ફિગર કરો

```bash
# ઇન્ટિગ્રેશન ટોકન સાચવો + માન્ય કરો (POST પરીક્ષણ શોધ ચલાવીને માન્ય કરે છે)
curl -X POST http://localhost:20128/api/settings/notion \
  -H "Content-Type: application/json" \
  -d '{"token":"ntn_xxx"}'

# કનેક્શનની સ્થિતિ તપાસો
curl http://localhost:20128/api/settings/notion

# ડિસ્કનેક્ટ કરો (સંગ્રહિત ટોકન સાફ કરે છે)
curl -X DELETE http://localhost:20128/api/settings/notion
```

ત્રણેય પદ્ધતિઓ માટે ડૅશબોર્ડ પ્રમાણીકરણ (`isAuthenticated`) જરૂરી છે. `POST` પર,
OmniRoute ટોકન સાચવે છે અને તરત જ 1-પરિણામવાળી પરીક્ષણ શોધ ચલાવે છે; જો Notion
ભૂલ ઑબ્જેક્ટ પરત કરે, તો ટોકન સાફ કરવામાં આવે છે અને કૉલ `400` સાથે નિષ્ફળ જાય છે.

## MCP ટૂલ્સ (6)

`open-sse/mcp-server/tools/notionTools.ts`માં વ્યાખ્યાયિત છે. કૉલ સમયે ટોકન
`getNotionToken()` મારફતે મેળવવામાં આવે છે; જો કોઈ ટોકન કૉન્ફિગર ન હોય, તો ટૂલ
`"Notion integration token not configured. Set it in Settings > Context Sources."`
થ્રો કરે છે.

| ટૂલ                          | સ્કોપ          | વર્ણન                                                                                        |
| ---------------------------- | -------------- | -------------------------------------------------------------------------------------------- |
| `notion_search`              | `read:notion`  | ટેક્સ્ટ ક્વેરી દ્વારા પેજ અને ડેટાબેઝ શોધે છે (શીર્ષકો, IDs અને URLs પરત કરે છે). પેજિનેટેડ. |
| `notion_get_page`            | `read:notion`  | પેજના ID દ્વારા તેની સામગ્રી અને મેટાડેટા મેળવે છે.                                          |
| `notion_list_block_children` | `read:notion`  | બ્લોક અથવા પેજના તમામ ચાઇલ્ડ બ્લોક્સની યાદી આપે છે (બ્લોક ટ્રી). પેજિનેટેડ.                  |
| `notion_query_database`      | `read:notion`  | વૈકલ્પિક `filter` + `sorts` (Notion API ફૉર્મેટ) સાથે ડેટાબેઝ ક્વેરી કરે છે. પેજિનેટેડ.      |
| `notion_get_database`        | `read:notion`  | ID દ્વારા ડેટાબેઝનું સ્કીમા/મેટાડેટા મેળવે છે.                                               |
| `notion_append_blocks`       | `write:notion` | હાલના બ્લોક અથવા પેજમાં ચાઇલ્ડ બ્લોક્સ ઉમેરે છે (દર વિનંતીએ વધુમાં વધુ 100 બ્લોક).           |

### ઇનપુટ પેરામીટર્સ

- `notion_search` — `query` (1–500 અક્ષરો), `pageSize` (1–100, ડિફૉલ્ટ 20),
  `startCursor` (વૈકલ્પિક).
- `notion_get_page` — `pageId` (32-અક્ષરનું હેક્સ અથવા UUID).
- `notion_list_block_children` — `blockId`, `pageSize` (1–100, ડિફૉલ્ટ 50),
  `startCursor` (વૈકલ્પિક).
- `notion_query_database` — `databaseId`, `filter` (વૈકલ્પિક, Notion ફિલ્ટર ફૉર્મેટ),
  `sorts` (વૈકલ્પિક ઍરે), `pageSize` (1–100, ડિફૉલ્ટ 50), `startCursor` (વૈકલ્પિક).
- `notion_get_database` — `databaseId`.
- `notion_append_blocks` — `blockId`, `children` (બ્લોક ઑબ્જેક્ટ્સનું ઍરે),
  `after` (વૈકલ્પિક સ્થાન).

### સ્કોપ્સ

વાંચન ટૂલ્સ માટે `read:notion` અને લેખન ટૂલ માટે `write:notion` જરૂરી છે.
`open-sse/mcp-server/server.ts`માં `withScopeEnforcement()` દ્વારા સ્કોપ્સ માત્ર ત્યારે જ લાગુ કરવામાં આવે છે
જ્યારે `OMNIROUTE_MCP_ENFORCE_SCOPES=true` હોય; કૉલરને મંજૂર સ્કોપ્સ
`OMNIROUTE_MCP_SCOPES` (અલ્પવિરામથી અલગ કરેલા) અથવા પ્રમાણિત API કીના સ્કોપ સંદર્ભમાંથી
મળે છે. સંપૂર્ણ સ્કોપ મોડલ માટે [MCP-SERVER.md](./MCP-SERVER.md) જુઓ.

## એન્ડપોઇન્ટ્સ

| પદ્ધતિ   | પાથ                    | હેતુ                                          |
| -------- | ---------------------- | --------------------------------------------- |
| `GET`    | `/api/settings/notion` | `{ connected, hasToken }` પરત કરે છે.         |
| `POST`   | `/api/settings/notion` | ઇન્ટિગ્રેશન ટોકન સાચવે છે + માન્ય કરે છે.     |
| `DELETE` | `/api/settings/notion` | ડિસ્કનેક્ટ કરે છે (સંગ્રહિત ટોકન સાફ કરે છે). |

> આ ડેશબોર્ડ સેટિંગ્સ રૂટ્સ છે. કોઈ સાર્વજનિક `/v1` Notion પ્રૉક્સી
> એન્ડપોઇન્ટ **નથી** — Notionને ફક્ત ઉપરોક્ત MCP ટૂલ્સ મારફતે જ ઍક્સેસ કરવામાં આવે છે.

## ઉપયોગના કિસ્સાઓ

- **જ્ઞાન-આધારિત જવાબો** — જવાબ આપતા પહેલાં એજન્ટને વર્કસ્પેસમાં `notion_search` કરવા અને
  ટોચનું પરિણામ `notion_get_page` કરવા દો, જેથી પ્રતિસાદોમાં વાસ્તવિક આંતરિક દસ્તાવેજોનો સંદર્ભ આપવામાં આવે.
- **ડેટાબેઝ-આધારિત વર્કફ્લો** — ફિલ્ટર્સ + સૉર્ટ્સ સાથે કાર્યો/CRM ડેટાબેઝ પર
  `notion_query_database` ચલાવો, ત્યારબાદ પંક્તિઓનો સારાંશ આપો અથવા તેમને પ્રાથમિકતા મુજબ વર્ગીકૃત કરો.
- **પાછું લખવું / લૉગિંગ** — મીટિંગ નોંધો, રનના સારાંશો અથવા એજન્ટનું આઉટપુટ
  હાલના પેજમાં ઉમેરવા માટે `notion_append_blocks` વાપરો (ફક્ત ઉમેરવું; કોઈ વિનાશકારી ફેરફારો નહીં).
- **માળખાનું અન્વેષણ** — પેજના બ્લૉક ટ્રીમાં આગળ વધવા માટે `notion_list_block_children`
  અથવા ક્વેરી કરતાં પહેલાં ડેટાબેઝની પ્રોપર્ટી સ્કીમા શોધવા માટે `notion_get_database` વાપરો.
