OmniRoute એજન્ટ-સંબંધિત ત્રણ અલગ ઇન્ટરફેસ ઉપલબ્ધ કરાવે છે. પ્રથમ નજરે તેઓ સમાન લાગે છે, પરંતુ તેઓ અલગ સમસ્યાઓનું નિરાકરણ લાવે છે. યોગ્ય ઇન્ટરફેસ પસંદ કરવા માટે આ પૃષ્ઠનો ઉપયોગ કરો.

## ટૂંકમાં

| ઇન્ટરફેસ                        | આ માટે શ્રેષ્ઠ                                                                                                                                | ટ્રાન્સપોર્ટ                  | માનક                     |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ------------------------ |
| **A2A — એજન્ટ-થી-એજન્ટ**        | A2A પ્રોટોકૉલનો ઉપયોગ કરતા પીઅર એજન્ટ્સ સાથે આંતર-એજન્ટ સહયોગ                                                                                 | HTTP પર JSON-RPC 2.0          | A2A v0.3 (ખુલ્લું સ્પેક) |
| **ACP — CLI એજન્ટ્સ રજિસ્ટ્રી** | વપરાશકર્તાના મશીન પર ઇન્સ્ટૉલ થયેલા CLI કોડિંગ એજન્ટ્સને શોધવા / રજિસ્ટર કરવા / શરૂ કરવા (Cursor, Cline, Codex CLI, Claude Code, Aider વગેરે) | HTTP REST                     | OmniRoute-વિશિષ્ટ        |
| **ક્લાઉડ એજન્ટ્સ**              | બાહ્ય ક્લાઉડ સેવાઓને લાંબા સમય સુધી ચાલતાં કોડિંગ કાર્યો સોંપવા (Codex Cloud, Devin, Jules, Cursor Cloud)                                     | HTTP REST + DB-સમર્થિત કાર્યો | OmniRoute-વિશિષ્ટ        |

આ ત્રણેય સ્વતંત્ર છે — કોઈપણ ઉપસમૂહ પસંદ કરો.

## નિર્ણય વૃક્ષ

```
શું તમને આ મશીનની બહાર કાર્ય કરવા માટે ક્લાઉડ સેવાની જરૂર છે (Codex Cloud / Cursor Cloud / Devin / Jules)?
├─ હા → ક્લાઉડ એજન્ટ્સ (POST /api/v1/agents/tasks)
└─ ના → આગળ વધો
    │
    શું તમારી પાસે A2Aનો ઉપયોગ કરતો અને સહયોગ કરવા ઇચ્છતો પીઅર એજન્ટ છે?
    ├─ હા → A2A (POST /a2a)
    └─ ના → આગળ વધો
        │
        શું તમારે સ્થાનિક રીતે ઇન્સ્ટૉલ થયેલા CLI કોડિંગ એજન્ટ્સની સૂચિ બનાવવી / તેમને કૉન્ફિગર કરવા છે?
        ├─ હા → ACP (GET /api/acp/agents)
        └─ ના → સાદા /v1/chat/completionsનો ઉપયોગ કરો
```

## 1. A2A — એજન્ટ-થી-એજન્ટ

**સ્પેક:** [A2A v0.3](https://a2a-protocol.org)
**OmniRoute એન્ડપૉઇન્ટ:** `POST /a2a` (JSON-RPC 2.0)
**એજન્ટ કાર્ડ:** `GET /.well-known/agent.json`

### ક્યારે ઉપયોગ કરવો

- એવી મલ્ટિ-એજન્ટ સિસ્ટમ બનાવતી વખતે જેમાં OmniRoute પીઅર્સ પૈકીનું એક હોય
- Google ADK જેવા ફ્રેમવર્ક્સ અથવા સામાન્ય એજન્ટ મેશમાં રહેલા એજન્ટ્સ માટે OmniRouteની રૂટિંગ ઇન્ટેલિજન્સ (સ્માર્ટ રૂટિંગ, ક્વોટા મેનેજમેન્ટ વગેરે) ઉપલબ્ધ કરાવતી વખતે
- OmniRouteને માનક ડિસ્કવરી + ઇન્વોકેશન ઇન્ટરફેસ પાછળ રૅપ કરતી વખતે

### મેથડ્સ

- `message/send` — સંદેશ સબમિટ કરો અને સિંક્રનસ પ્રતિસાદ મેળવો
- `message/stream` — સંદેશ સબમિટ કરો + SSE-સ્ટ્રીમ કરેલી પ્રગતિ ઇવેન્ટ્સ મેળવો
- `tasks/get` — ID દ્વારા કાર્ય વાંચો
- `tasks/cancel` — ચાલી રહેલું કાર્ય રદ કરો

### બિલ્ટ-ઇન સ્કિલ્સ (6)

- `smart-routing` — પ્રોમ્પ્ટને શ્રેષ્ઠ કૉમ્બો મારફતે રૂટ કરો
- `quota-management` — દરેક પ્રદાતા માટે ક્વોટાની સ્થિતિનો રિપોર્ટ આપો
- `provider-discovery` — ઇન્સ્ટૉલ થયેલા પ્રદાતાઓની તેમની ક્ષમતાઓ સહિત સૂચિ બનાવો
- `cost-analysis` — વિનંતી/વાતચીતના ખર્ચનો અંદાજ કાઢો
- `health-report` — દરેક પ્રદાતા માટે બ્રેકર/કૂલડાઉન/લૉકઆઉટ સ્થિતિ એકત્રિત કરો
- `list-capabilities` — એજન્ટની ઉપલબ્ધ સ્કિલ્સ અને મેટાડેટાની ગણના કરો

### વિગતવાર માહિતી

ટ્રાન્સપોર્ટની વિગતો, એજન્ટ કાર્ડની સંરચના, કાર્ય TTL કૉન્ફિગ અને નવી સ્કિલ્સ ઉમેરવા માટેના ટેમ્પ્લેટ માટે [A2A-SERVER.md](./A2A-SERVER.md) જુઓ.

## 2. ACP — CLI એજન્ટ્સ રજિસ્ટ્રી

**OmniRoute એન્ડપોઇન્ટ:** `GET /api/acp/agents`
**સ્રોત:** `src/lib/acp/{index,manager,registry}.ts`

### તે શું છે

ACP એ OmniRouteની **સ્થાનિક CLI એજન્ટ ઇન્વેન્ટરી** છે. તે હોસ્ટ પર કયા કોડિંગ CLI ઇન્સ્ટોલ થયેલા છે (Cursor, Cline, Claude Code, Codex CLI, Continue વગેરે) તે શોધે છે, તેમની આવૃત્તિઓ નિર્ધારિત કરે છે અને તેમને ડેશબોર્ડ પર દર્શાવે છે, જેથી વપરાશકર્તા દરેક CLIને OmniRoute તરફ નિર્દેશિત કરવા માટે ગોઠવી શકે.

આ કોઈ બાહ્ય પ્રોટોકોલ નથી — તે એક આંતરિક રજિસ્ટ્રી છે, જે "CLI Tools" UI અને CLI ફિંગરપ્રિન્ટ ટ્રેકિંગને કાર્યરત કરે છે ([CLI-TOOLS.md](../reference/CLI-TOOLS.md) જુઓ).

### તે શું કરે છે

- ઇન્સ્ટોલ થયેલ CLI બાઇનરી માટે હોસ્ટની તપાસ કરે છે (OS મુજબ `which` / `where`નો ઉપયોગ કરે છે)
- દરેક CLIની આવૃત્તિ વાંચે છે (`<bin> --version`ને કૉલ કરે છે)
- વૈકલ્પિક રીતે વપરાશકર્તા-વ્યાખ્યાયિત કસ્ટમ એજન્ટ્સ સ્વીકારે છે (બાઇનરી પાથ + આવૃત્તિ તપાસ + સ્પૉન આર્ગ્યુમેન્ટ્સ)
- કસ્ટમ એજન્ટ્સને સેટિંગ્સમાં કાયમી રીતે સાચવે છે
- ડેશબોર્ડને એકીકૃત સૂચિ પરત કરે છે

### REST API

| એન્ડપોઇન્ટ        | પદ્ધતિ | વર્ણન                                                               | પ્રમાણીકરણ |
| ----------------- | ------ | ------------------------------------------------------------------- | ---------- |
| `/api/acp/agents` | GET    | શોધાયેલા + કસ્ટમ એજન્ટ્સની સૂચિ (ઇન્સ્ટોલ થયેલા/કુલ સંખ્યા)         | API કી     |
| `/api/acp/agents` | POST   | કસ્ટમ એજન્ટ ઉમેરો/અપડેટ કરો/દૂર કરો (બોડીમાં ક્રિયા ડિસ્ક્રિમિનેટર) | API કી     |

POST માટે બોડીનું સ્વરૂપ (`src/app/api/acp/agents/route.ts`માં `customAgentBodySchema`):

```json
{
  "action": "add|update|remove",
  "id": "cursor",
  "name": "Cursor",
  "binary": "/usr/local/bin/cursor",
  "versionCommand": "--version",
  "providerAlias": "cursor",
  "spawnArgs": ["--api-base", "http://localhost:20128"],
  "protocol": "stdio"
}
```

### ઉપયોગના કિસ્સા

- ડેશબોર્ડનું "CLI Tools" પૃષ્ઠ શું ઇન્સ્ટોલ થયેલું છે તેની સૂચિ દર્શાવે છે અને દરેકને OmniRoute તરફ નિર્દેશિત કરવામાં મદદ કરે છે
- કસ્ટમ એજન્ટ્સ અદ્યતન વપરાશકર્તાઓને એવા આંતરિક/માલિકીના CLI નોંધાવવા દે છે, જેના વિશે OmniRouteને મૂળભૂત રીતે જાણ નથી
- શોધનું પરિણામ `cli-tools` ફિંગરપ્રિન્ટ મેટ્રિક્સને માહિતી પૂરી પાડે છે

### ACPનો ઉપયોગ ક્યારે ન કરવો

- ACP કાર્યોને _ચલાવતું_ નથી. તે માત્ર CLIને શોધે અને ગોઠવે છે. ખરેખર કોઈ CLIને ઉપયોગમાં લેવા માટે, OmniRoute દ્વારા પૂરા પાડવામાં આવેલા env vars (`OPENAI_BASE_URL`, `OPENAI_API_KEY` વગેરે) સાથે તેને તમારે જાતે શરૂ કરવું પડે છે.

## 3. ક્લાઉડ એજન્ટ્સ

**OmniRoute એન્ડપોઇન્ટ્સ:** `/api/v1/agents/tasks/*` (જીવનચક્ર) + `/api/cloud/*` (આંતરિક જોડાણ વ્યવસ્થા)
**સ્રોત:** `src/lib/cloudAgent/`

### તે શું છે

તૃતીય-પક્ષ ક્લાઉડ કોડિંગ એજન્ટ્સ માટેનું એક સમાન ઇન્ટરફેસ. તમે પ્રોમ્પ્ટ + રિપોઝિટરી URL સબમિટ કરો છો, OmniRoute તેને યોગ્ય ક્લાઉડ એજન્ટને મોકલે છે, સ્થિતિની સમયાંતરે તપાસ કરે છે અને પરિણામો પરત કરે છે.

### સમર્થિત એજન્ટ્સ (4, બધાની `src/lib/cloudAgent/agents/`માં પુષ્ટિ થયેલી છે)

- `codex-cloud` — OpenAI Codex Cloud
- `devin` — Cognition Devin
- `jules` — Google Jules

### જીવનચક્ર

```
POST /api/v1/agents/tasks
  → એજન્ટના દરેક ક્લાસ માટે BaseAgent.createTask()
  → બાહ્ય સેવા કામ શરૂ કરે છે
  → DBમાં ટાસ્ક રો બનાવવામાં આવે છે (cloud_agent_tasks)
  ↓
GET /api/v1/agents/tasks/[id]
  → પ્રદાતા પાસેથી જરૂરિયાત મુજબ સ્થિતિ સિંક થાય છે
  → વર્તમાન સ્થિતિ + યોજના + પ્રવૃત્તિ લૉગ પરત કરે છે
  ↓
POST /api/v1/agents/tasks/[id]   (ક્રિયા: "approve" | "message" | "cancel")
  → પ્રદાતાને ફોરવર્ડ કરે છે (અથવા સ્થાનિક રીતે રદ થયેલું ચિહ્નિત કરે છે)
  ↓
DELETE /api/v1/agents/tasks/[id]
  → સ્થાનિક રીતે રદ કરે છે
```

### પ્રમાણીકરણ

⚠️ **તમામ `/api/v1/agents/tasks/*` એન્ડપોઇન્ટ્સ માટે મેનેજમેન્ટ પ્રમાણીકરણ જરૂરી છે** (કમિટ `588a0333`). v3.8.0થી માત્ર Bearerનો ઉપયોગ કરતા કૉલર્સને 401 પ્રતિસાદ મળે છે.

### વિગતવાર માહિતી

`CloudAgentBase` કરાર, દરેક એજન્ટની વિશિષ્ટતાઓ, સ્કીમાની વિગતો અને ક્રેડેન્શિયલ જોડાણ વ્યવસ્થાના એન્ડપોઇન્ટ્સ માટે [CLOUD_AGENT.md](./CLOUD_AGENT.md) જુઓ.

## તુલના: A2A વિરુદ્ધ Cloud Agents

બંનેમાં "લાંબા સમય સુધી ચાલતા કાર્યો" હોય છે, પરંતુ અલગ-અલગ સ્તરો પર:

| પાસું                  | A2A                                                                                  | Cloud Agents                           |
| ---------------------- | ------------------------------------------------------------------------------------ | -------------------------------------- |
| માનક                   | Open A2A v0.3                                                                        | OmniRoute-વિશિષ્ટ                      |
| કમ્પ્યુટ ક્યાં ચાલે છે | OmniRouteની અંદર (રૂપરેખાંકિત કોમ્બોનો ઉપયોગ કરે છે)                                 | બાહ્ય (Codex / Devin / Jules સર્વર્સ)  |
| કાર્યનો સમયગાળો        | ડિફૉલ્ટ TTL 5 મિનિટ (`TaskManager`માં રૂપરેખાંકિત કરી શકાય છે)                       | મિનિટોથી કલાકો                         |
| રિપો-જાગૃત             | ના (ફક્ત પ્રોમ્પ્ટ્સ મોકલે છે)                                                       | હા (રિપો URL + બ્રાન્ચ)                |
| ઉપયોગનો કિસ્સો         | ક્રોસ-એજન્ટ સહયોગ, સેવા તરીકે સ્માર્ટ રૂટિંગ                                         | "રિપો Yમાં ફીચર X અમલમાં મૂકો" સોંપવું |
| પ્રમાણીકરણ             | `/a2a` માટે વૈકલ્પિક `OMNIROUTE_API_KEY`; `/api/a2a/*` REST હેલ્પર્સ માટે મેનેજમેન્ટ | હંમેશાં મેનેજમેન્ટ                     |

## એકીકરણનાં ઉદાહરણો

### OmniRouteની A2A ક્ષમતાઓ શોધો

```bash
curl http://localhost:20128/.well-known/agent.json
```

તમામ 6 સ્કિલ્સ, ટ્રાન્સપોર્ટ્સ અને વર્ઝન સાથે Agent Card પરત કરે છે.

### OmniRouteને A2A એજન્ટ તરીકે કૉલ કરો

```bash
curl -X POST http://localhost:20128/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "message/send",
    "params": {
      "messages": [{"role": "user", "content": "Route this prompt"}],
      "skill": "smart-routing"
    },
    "id": 1
  }'
```

### ACP દ્વારા ઇન્સ્ટોલ કરેલા CLI એજન્ટ્સની સૂચિ મેળવો

```bash
curl http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>"
```

### કસ્ટમ CLI એજન્ટ ઉમેરો

```bash
curl -X POST http://localhost:20128/api/acp/agents \
  -H "Authorization: Bearer <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "add",
    "id": "my-custom-cli",
    "name": "My Custom CLI",
    "binary": "/opt/mycli/bin/mycli",
    "versionCommand": "--version",
    "providerAlias": "openai"
  }'
```

### Cloud Agent કાર્ય સબમિટ કરો

```bash
curl -X POST http://localhost:20128/api/v1/agents/tasks \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{
    "providerId": "devin",
    "prompt": "Implement feature X in repo Y",
    "source": {
      "repoName": "user/repo",
      "repoUrl": "https://github.com/user/repo",
      "branch": "main"
    }
  }'
```

### ક્લાઉડ કાર્યની સ્થિતિ તપાસો

```bash
curl http://localhost:20128/api/v1/agents/tasks/<task-id> \
  -H "Cookie: auth_token=..."
```

## ક્યારે શું વાપરવું

- **ચેટબોટ / કોપાઇલટ ફ્રન્ટએન્ડ** → `/v1/chat/completions` (OpenAI-સુસંગત — એજન્ટ પ્રોટોકોલ નથી)
- **મલ્ટિ-એજન્ટ સહયોગ** → A2A
- **ડૅશબોર્ડમાં સ્થાનિક CLIની સૂચિ દર્શાવવી** → ACP
- **લાંબા સમય સુધી ચાલતા કોડિંગ કાર્યો ક્લાઉડ સેવાઓને સોંપવા** → Cloud Agents
