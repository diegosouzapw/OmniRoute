> અને સ્કોપ વાયરિંગ `open-sse/mcp-server/server.ts`માં છે.

## તે શું છે

OmniRoute **Obsidian** વૉલ્ટ સાથે **સંદર્ભ સ્રોત** તરીકે જોડાય છે — એક સ્થાનિક Markdown
જ્ઞાનભંડાર, જેને એજન્ટ્સ બિલ્ટ-ઇન MCP સર્વર મારફતે વાંચે અને તેમાં લખે છે. આ
ઇન્ટિગ્રેશન ડેસ્કટૉપ ઍપની અંદર ચાલી રહેલા **Obsidian Local REST API** કમ્યુનિટી પ્લગઇન
સાથે સંચાર કરે છે, જેથી એજન્ટ્સ નોંધો શોધી શકે, ફાઇલો વાંચી/લખી/પૅચ કરી શકે, વૉલ્ટની
યાદી જોઈ શકે, દૈનિક/સાપ્તાહિક આવર્તક નોંધો સાથે કામ કરી શકે, ટૅગ્સનું સંચાલન કરી શકે,
Obsidian કમાન્ડ્સ ચલાવી શકે અને (વૈકલ્પિક રીતે) દ્વિદિશીય ડેસ્કટૉપ↔મોબાઇલ વૉલ્ટ સિંકનું
સંકલન કરી શકે.

ક્લાયન્ટ (`src/lib/obsidian/api.ts`) Local REST APIને નીચેની સુવિધાઓ સાથે રૅપ કરે છે:

- ક્ષણિક `5xx` માટે **બૅકઓફ સાથે પુનઃપ્રયાસ**, `AbortController` મારફતે **30-સેકન્ડનો સમયસમાપ્તિ સમય**.
- **ટાઇપ કરેલું ભૂલ વર્ગીકરણ** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- એક **મૈત્રીપૂર્ણ "Obsidian સુધી પહોંચી શકાતું નથી" સંકેત**, જે સામાન્ય પોર્ટની ભૂલ
  (HTTP `27123` પર, `27124` પરના MCP એન્ડપોઇન્ટ પર **નહીં**) અને Tailscale સ્વરૂપ સમજાવે છે.
- વૉલ્ટ-સાપેક્ષ **પાથ એન્કોડિંગ**, જેથી સ્પેસ/સ્લૅશ ધરાવતા નોંધ પાથ સુરક્ષિત રહે.

## સેટઅપ

Obsidian ટોકન અથવા બેઝ URL માટે **કોઈ environment variable નથી** — બંને
`src/lib/db/obsidian.ts` મારફતે SQLite `key_value` ટેબલમાં (નેમસ્પેસ `obsidian`)
સંગ્રહિત થાય છે. ટોકન **સંગ્રહિત અવસ્થામાં એન્ક્રિપ્ટેડ** છે (AES-256-GCM, પ્લેઇનટેક્સ્ટ
બૅકવર્ડ-કમ્પેટિબિલિટી ફૉલબૅક સાથે). Endpoint ડૅશબોર્ડના **Context Sources** ટૅબ
(`ObsidianSourceCard`)માંથી અથવા સેટિંગ્સ REST API મારફતે કૉન્ફિગર કરો.

> [!IMPORTANT]
> **Obsidian Local REST API** પ્લગઇન ઇન્સ્ટૉલ કરેલું અને ચાલુ હોવું આવશ્યક છે. તેનું REST
> ઇન્ટરફેસ **HTTP `127.0.0.1:27123`** (ડિફૉલ્ટ બેઝ URL) પર સાંભળે છે. પોર્ટ `27124`
> એક _અલગ_ MCP/HTTPS એન્ડપોઇન્ટ છે અને સેટિંગ્સ રૂટ દ્વારા સ્પષ્ટપણે નકારવામાં આવે છે.
> અન્ય ડિવાઇસ પરથી કનેક્ટ કરતા હો, તો `http://<tailscale-ip>:27123` વાપરો.

### કૉન્ફિગરેશન કીઝ (SQLite `key_value`, નેમસ્પેસ `obsidian`)

| કી                | હેતુ                                            | એન્ક્રિપ્ટેડ |
| ----------------- | ----------------------------------------------- | ------------ |
| `api_key`         | Local REST API બેરર ટોકન                        | હા           |
| `base_url`        | REST બેઝ URL (ડિફૉલ્ટ `http://127.0.0.1:27123`) | ના           |
| `vault_path`      | વૉલ્ટ ડિરેક્ટરીનો ઍબ્સોલ્યુટ પાથ (સિંક માટે)    | ના           |
| `webdav_username` | જનરેટ કરેલું WebDAV યુઝરનેમ (વૉલ્ટ સિંક)        | ના           |
| `webdav_password` | જનરેટ કરેલો WebDAV પાસવર્ડ (વૉલ્ટ સિંક)         | હા           |
| `webdav_enabled`  | WebDAV વૉલ્ટ સિંક સક્ષમ છે કે નહીં              | ના           |

### REST મારફતે કૉન્ફિગર કરો

```bash
# Local REST API ટોકન સાચવો + માન્ય કરો (POST સ્ટેટસ ચેક દ્વારા માન્ય કરે છે)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# કનેક્શન સ્ટેટસ તપાસો (connected, hasToken, baseUrl, vaultPath પરત કરે છે)
curl http://localhost:20128/api/settings/obsidian

# ડિસ્કનેક્ટ કરો (સંગ્રહિત ટોકન સાફ કરે છે)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

બધી મેથડ્સ માટે ડૅશબોર્ડ ઑથેન્ટિકેશન આવશ્યક છે. `POST` પોર્ટ `27124` પરના કોઈપણ URLને
નકારે છે અને સંગ્રહ કરતા પહેલાં Local REST API સ્ટેટસ એન્ડપોઇન્ટને કૉલ કરીને ટોકન માન્ય કરે છે.

### WebDAV વૉલ્ટ સિંક

`src/app/api/settings/obsidian/webdav/route.ts` વૈકલ્પિક WebDAV-આધારિત
વૉલ્ટ સિંકનું સંચાલન કરે છે (જે `src/lib/obsidianSync.ts` દ્વારા સંચાલિત છે). તેને સક્ષમ
કરવાથી OmniRoute સ્થાનિક વૉલ્ટ ડિરેક્ટરી તરફ નિર્દેશિત થાય છે અને રૅન્ડમ WebDAV
યુઝરનેમ/પાસવર્ડ જોડી બનાવે છે:

```bash
# વૉલ્ટ ડિરેક્ટરી માટે WebDAV સિંક સક્ષમ કરો (યુઝરનેમ/પાસવર્ડ બનાવે છે)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# WebDAV સિંક સ્ટેટસ મેળવો (ક્રેડેન્શિયલ્સ માત્ર સક્ષમ હોય ત્યારે પરત મળે છે)
curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV સિંક અક્ષમ કરો (ક્રેડેન્શિયલ્સ + સંચાલિત .stignore સાફ કરે છે)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### પ્રતિ-API-કી સંદર્ભ સ્રોત (વૈકલ્પિક)

Obsidian કૉન્ફિગને `api_key_context_sources` ટેબલ મારફતે **પ્રતિ API કી**
સ્કોપ કરી શકાય છે (`src/lib/db/apiKeyContextSources.ts`). જ્યારે MCP કૉલમાં ઑથેન્ટિકેટેડ
API કી id હોય, ત્યારે `getObsidianConfigForApiKey()` તે કીના પોતાના ટોકન/બેઝ-URL/વૉલ્ટ-પાથને
(`source: "api_key"`) પ્રાથમિકતા આપે છે અને અન્યથા ગ્લોબલ કૉન્ફિગ (`source: "global"`)નો
ફૉલબૅક તરીકે ઉપયોગ કરે છે.

## MCP સાધનો (22)

`open-sse/mcp-server/tools/obsidianTools.ts` માં વ્યાખ્યાયિત છે. ટોકન/base-URL દરેક કૉલ માટે ઉકેલવામાં આવે છે (પહેલાં પ્રતિ-API-key, પછી વૈશ્વિક). OmniRoute **sync server** નો ઉપયોગ કરતા સાધનો (ચાર `obsidian_sync_*` સાધનો) માટે વધુમાં OmniRoute સેટિંગ્સમાં ગોઠવેલ sync auth token જરૂરી છે.

| સાધન                         | વર્ણન                                                                                               |
| ---------------------------- | --------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Local REST API પહોંચી શકાય તેવું અને પ્રમાણિત છે કે નહીં તે તપાસો.                                  |
| `obsidian_search_simple`     | નોંધની સામગ્રીમાં પૂર્ણ-ટેક્સ્ટ શોધ; ફાઇલ પાથ સાથે અંશો પરત કરે છે.                                 |
| `obsidian_search_structured` | JSON Logic અભિવ્યક્તિ (and/or/regex/path ફિલ્ટર્સ) નો ઉપયોગ કરીને શોધો.                             |
| `obsidian_read_note`         | vault-સાપેક્ષ પાથ દ્વારા નોંધ વાંચો; વૈકલ્પિક રીતે ચોક્કસ heading/block/frontmatter વાંચો.          |
| `obsidian_list_vault`        | vault માં ફાઇલો અને ડિરેક્ટરીઓની યાદી આપો (entries નું વૃક્ષ).                                      |
| `obsidian_get_document_map`  | નોંધનું heading માળખું headings → line numbers ના નકશા તરીકે મેળવો.                                 |
| `obsidian_get_note_metadata` | સંપૂર્ણ સામગ્રી વિના frontmatter, tags, links, char/word count મેળવો.                               |
| `obsidian_get_active_file`   | Obsidian માં હાલમાં સક્રિય ફાઇલનો પાથ + સામગ્રી મેળવો.                                              |
| `obsidian_get_periodic_note` | કોઈ તારીખ માટે દૈનિક/સાપ્તાહિક/માસિક આવર્તક નોંધ મેળવો (છોડી દેવાય તો આજની તારીખ).                  |
| `obsidian_get_tags`          | બધા vault tags ને તેમની આવર્તન સંખ્યા સાથે સૂચિબદ્ધ કરો.                                            |
| `obsidian_list_commands`     | ઉપલબ્ધ Obsidian command IDs ની યાદી આપો (`obsidian_execute_command` સાથે ઉપયોગ કરો).                |
| `obsidian_sync_status`       | OmniRoute sync server ની સ્થિતિ: ચાલી રહ્યું છે કે નહીં, vault નું નામ, port, uptime, છેલ્લું sync. |
| `obsidian_sync_conflicts`    | ઉકેલાયા ન હોય તેવા sync conflicts ની યાદી આપો (path, conflict path, detected-at).                   |

### લેખન સાધનો (`write:obsidian`)

| સાધન                             | વર્ણન                                                                             |
| -------------------------------- | --------------------------------------------------------------------------------- |
| `obsidian_write_note`            | આપેલ Markdown સામગ્રી સાથે નોંધ બનાવો અથવા તેના પર ફરીથી લખો.                     |
| `obsidian_append_note`           | નોંધમાં સામગ્રી ઉમેરો; વૈકલ્પિક રીતે ચોક્કસ heading/block માં.                    |
| `obsidian_patch_note`            | heading, block અથવા frontmatter field પર ચોકસાઈપૂર્વક append/prepend/replace કરો. |
| `obsidian_delete_note`           | vault માંથી નોંધ કાયમી રીતે કાઢી નાખો.                                            |
| `obsidian_move_note`             | vault ની અંદર નોંધ ખસેડો અથવા તેનું નામ બદલો.                                     |
| `obsidian_execute_command`       | Obsidian command ને તેના command ID દ્વારા ચલાવો.                                 |
| `obsidian_open_file`             | Obsidian માં ફાઇલ ખોલો (જો તે અસ્તિત્વમાં ન હોય તો બનાવે છે).                     |
| `obsidian_sync_trigger`          | તાત્કાલિક દ્વિદિશીય desktop↔mobile vault sync શરૂ કરો.                            |
| `obsidian_sync_resolve_conflict` | sync conflict ઉકેલો: `local` (mobile), `remote` (desktop), અથવા `keep-both` રાખો. |

> [!NOTE]
> `obsidian_patch_note` ના targets `heading | block | frontmatter` પૈકીનું `targetType`
> અને `append | prepend | replace` પૈકીનું `operation` સ્વીકારે છે, સાથે વૈકલ્પિક
> `createTargetIfMissing`. ચાર `obsidian_sync_*` સાધનો સ્થાનિક sync
> server (મૂળભૂત રીતે `http://127.0.0.1:27781`) સાથે સંચાર કરે છે અને તેમને sync token જરૂરી છે.

### Scopes

વાંચન સાધનો માટે `read:obsidian` જરૂરી છે; લેખન સાધનો માટે `write:obsidian` જરૂરી છે. અમલીકરણ
Notion જેવું જ છે — `open-sse/mcp-server/server.ts` માં `withScopeEnforcement()` દ્વારા સંભાળવામાં આવે છે,
`OMNIROUTE_MCP_ENFORCE_SCOPES=true` પર સક્રિય થાય છે, અને માન્ય scopes
`OMNIROUTE_MCP_SCOPES` અથવા API key ના scope context માંથી મેળવવામાં આવે છે. જુઓ
[MCP-SERVER.md](./MCP-SERVER.md).

| પદ્ધતિ   | પાથ                             | હેતુ                                                      |
| -------- | ------------------------------- | --------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | `{ connected, hasToken, baseUrl, vaultPath }` પરત કરે છે. |
| `POST`   | `/api/settings/obsidian`        | ટોકન સાચવે છે + માન્ય કરે છે (પોર્ટ `27124` નકારે છે).    |
| `DELETE` | `/api/settings/obsidian`        | ડિસ્કનેક્ટ કરે છે (સંગ્રહિત ટોકન સાફ કરે છે).             |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV સિંકની સ્થિતિ + ઓળખપત્રો (સક્ષમ હોય ત્યારે).       |
| `POST`   | `/api/settings/obsidian/webdav` | વૉલ્ટ ડિરેક્ટરી માટે WebDAV સિંક સક્ષમ કરે છે.            |
| `DELETE` | `/api/settings/obsidian/webdav` | WebDAV સિંક અક્ષમ કરે છે.                                 |

> આ ડૅશબોર્ડ સેટિંગ્સના રૂટ્સ છે. વૉલ્ટ સુધી Obsidian
> Local REST API (રૂપરેખાંકિત `base_url`) અને ઉપરનાં MCP સાધનો દ્વારા પહોંચવામાં આવે છે — કોઈ
> સાર્વજનિક `/v1` Obsidian પ્રૉક્સી એન્ડપોઇન્ટ નથી.

## ઉપયોગના કિસ્સાઓ

- **વૉલ્ટ-આધારિત જવાબો** — `obsidian_search_simple` / `obsidian_search_structured`
  પછી `obsidian_read_note`, જેથી એજન્ટ તમારી વાસ્તવિક નોંધોના આધારે જવાબ આપે.
- **નોંધ લેખન / જર્નલિંગ** — એજન્ટનું આઉટપુટ, સારાંશો અથવા દૈનિક નોંધો
  (`obsidian_get_periodic_note`) વૉલ્ટમાં નોંધવા માટે `obsidian_write_note`, `obsidian_append_note` અથવા
  ચોક્કસ ફેરફાર કરતું `obsidian_patch_note`.
- **વૉલ્ટ નેવિગેશન** — વાંચવા/લખવા પહેલાં માળખું શોધવા માટે `obsidian_list_vault`, `obsidian_get_document_map` અને
  `obsidian_get_tags`.
- **Obsidian ઑટોમેશન** — એજન્ટમાંથી પ્લગઇન્સ/કમાન્ડ્સ ચલાવવા માટે `obsidian_list_commands` + `obsidian_execute_command`;
  UIમાં નોંધ દર્શાવવા માટે `obsidian_open_file`.
- **મોબાઇલ સિંક** — WebDAV સિંક સક્ષમ કરો, પછી ડેસ્કટૉપ↔મોબાઇલનું સંકલન કરવા અને વિરોધાભાસો ઉકેલવા માટે `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`.
