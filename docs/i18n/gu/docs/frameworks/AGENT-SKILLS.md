> **સત્યનો સ્રોત:** `src/lib/agentSkills/` (કૅટલૉગ, જનરેટર, પાર્સર્સ) + `skills/` ડિરેક્ટરી (SKILL.md ફાઇલો)
> **છેલ્લે અપડેટ કરેલ:** 2026-08-02 — v3.8.50

Agent Skills એ સંરચિત SKILL.md ફાઇલો છે, જે બાહ્ય એજન્ટો, MCP ક્લાયન્ટ્સ અને A2A ઑર્કેસ્ટ્રેટર્સને OmniRouteના REST API અને CLIનો ઉપયોગ કેવી રીતે કરવો તે શીખવે છે. [Omni Skills](./SKILLS.md)થી વિપરીત (જે OmniRouteની અંદર અમલમાં મુકાતી LLM ટૂલ વ્યાખ્યાઓ છે), Agent Skills એક _દસ્તાવેજીકરણ કૅટલૉગ_ છે — સ્થિર markdown જેને સીધું જ એજન્ટ સંદર્ભમાં આપી શકાય છે.

---

## અવલોકન

કૅટલૉગમાં **45 Agent Skills** (23 REST API + 21 CLI + 1 કન્ફિગરેશન વર્કફ્લો) સામેલ છે. દરેક સ્કિલમાં આ હોય છે:

- એક **પ્રમાણભૂત ID** (`omni-auth`, `cli-serve`, વગેરે)
- `skills/{id}/SKILL.md`માં YAML ફ્રન્ટમેટર (`name`, `description`) + સમૃદ્ધ markdown બોડી ધરાવતી **SKILL.md** ફાઇલ
- OpenAPI સ્પેસિફિકેશન અને CLI રજિસ્ટ્રીમાંથી મેળવેલા **REST એન્ડપોઇન્ટ્સ** (API સ્કિલ્સ) અથવા **CLI સબકમાન્ડ્સ** (CLI સ્કિલ્સ)
- લાઇવ ફેચ માટેનું **GitHub raw URL**: `https://raw.githubusercontent.com/diegosouzapw/OmniRoute/refs/heads/main/skills/{id}/SKILL.md`

## REST API શોધ

| એન્ડપોઇન્ટ                   | પદ્ધતિ | વર્ણન                                                             | પ્રમાણીકરણ |
| :--------------------------- | :----- | :---------------------------------------------------------------- | :--------- |
| `/api/agent-skills`          | GET    | કેટલોગની સૂચિ (વૈકલ્પિક `?category=api\|cli\|config&area=<area>`) | કોઈ નહીં   |
| `/api/agent-skills/{id}`     | GET    | એકલ સ્કિલનું મેટાડેટા મેળવો                                       | કોઈ નહીં   |
| `/api/agent-skills/{id}/raw` | GET    | SKILL.md ને `text/markdown` તરીકે મેળવો                           | કોઈ નહીં   |
| `/api/agent-skills/coverage` | GET    | કવરેજ આંકડા (કેટલી SKILL.md ફાઇલો અસ્તિત્વમાં છે)                 | કોઈ નહીં   |
| `/api/agent-skills/generate` | POST   | જનરેટર ટ્રિગર કરો (dryRun/prune/onlyIds)                          | સંચાલન     |

ઉદાહરણ — તમામ API સ્કિલ્સની સૂચિ:

```bash
curl "http://localhost:20128/api/agent-skills?category=api"
```

ઉદાહરણ — એક SKILL.md મેળવો:

```bash
curl -H "Accept: text/markdown" "http://localhost:20128/api/agent-skills/omni-providers/raw"
```

## A2A શોધ

A2A સ્કિલ `list-capabilities` સંપૂર્ણ 45-સ્કિલ કેટલોગને markdown કોષ્ટક આર્ટિફેક્ટ તરીકે પરત કરે છે. બાહ્ય ઓર્કેસ્ટ્રેટર્સ તેને આ રીતે ઇન્વોક કરી શકે છે:

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "message/send",
  "params": {
    "skill": "list-capabilities",
    "messages": [{ "role": "user", "content": "List all capabilities" }]
  }
}
```

પ્રોટોકોલની વિગતો માટે [A2A-SERVER.md](./A2A-SERVER.md) જુઓ.

### 1. REST દ્વારા શોધ


## જનરેટર

જનરેટર ક્યુરેટેડ કેટલોગ + OpenAPI સ્પેસિફિકેશન + CLI રજિસ્ટ્રી વાંચે છે અને દરેક એન્ટ્રી માટે `skills/{id}/SKILL.md` લખે છે:

```bash
# પૂર્વાવલોકન (ડ્રાય રન, કોઈ લખાણ નહીં)
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":true}'

# સંપૂર્ણ પુનઃજનન
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"prune":false}'

# ચોક્કસ ID ફરીથી જનરેટ કરો
curl -X POST http://localhost:20128/api/agent-skills/generate \
  -H "Authorization: Bearer <admin-key>" \
  -H "Content-Type: application/json" \
  -d '{"dryRun":false,"onlyIds":["omni-providers","cli-serve"]}'
```

જનરેટરનો પ્રતિસાદ `GeneratorReport` છે:

```json
{
  "generated": ["omni-providers", "cli-serve"],
  "unchanged": [],
  "pruned": [],
  "orphansDetected": [],
  "errors": []
}
```
