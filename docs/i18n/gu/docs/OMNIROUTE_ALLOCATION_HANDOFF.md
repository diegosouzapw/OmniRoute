ફાળવણી એ પ્રદાતાનો ક્વોટા નથી.

ક્વોટા પૂલ નક્કી કરે છે કે કઈ API કીઓ પ્રદાતા પૂલનો ઉપયોગ કરી શકે અને હાર્ડ, સોફ્ટ અથવા બર્સ્ટ નીતિઓ કેવી રીતે લાગુ પડે. પ્રદાતાનો ક્વોટા એ પ્રદાતા દ્વારા રિપોર્ટ કરાયેલી બાહ્ય ક્ષમતા અથવા સ્પષ્ટ રીતે કૉન્ફિગર કરાયેલા સ્રોતમાંથી મળતી ક્ષમતા છે. Ghostlightના આંતરિક બજેટ એ વ્યવસ્થાપક દ્વારા નિર્ધારિત શાસન મર્યાદાઓ છે.

`ensurePool` ઑપરેશન આઇડેમ્પોટન્ટ છે: સમાન પૂલ યથાવત્ રહે છે, બદલાયેલી ફાળવણી અપડેટ થાય છે અને ગેરહાજર પૂલ બનાવવામાં આવે છે. આ ઑટોમેશન અને મર્યાદિત API કૉલર્સ માટે બનાવાયેલ છે.

ફક્ત વાંચવા માટેનું સ્ટેટસ એન્ડપોઇન્ટ `GET /api/omniroute/status` છે. ચકાસણી કમાન્ડ `npm run omniroute:verify` છે; તે કોઈ લાઇવ મોડેલ રિક્વેસ્ટ કરતું નથી.
