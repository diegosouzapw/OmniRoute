`@omniroute/opencode-plugin-v2` તમારા સમગ્ર OmniRoute કૅટલૉગ — મોડલ્સ, કોમ્બોઝ અને
ઑટો-કોમ્બોઝ — ને ડિસ્પ્લે નામો, કિંમત અને ફ્રી-ટિયર
બજેટ્સ સાથે OpenCode v2ના મોડલ પિકરમાં મૂકે છે.

તે `@omniroute/opencode-plugin`થી અલગ પૅકેજ છે, કારણ કે OpenCode v1 અને v2
પ્લગિન્સને અલગ કૉન્ટ્રાક્ટ દ્વારા લોડ કરે છે. તમારા OpenCodeના મુખ્ય વર્ઝન સાથે મેળ ખાતું પૅકેજ પસંદ કરો;
બંને વચ્ચે કંઈપણ શેર થતું નથી, તેથી એકને અપગ્રેડ કરવાથી બીજાને અપગ્રેડ કરવાની ફરજ પડતી નથી.

## આવશ્યકતાઓ

- OpenCode v2.
- ઍક્સેસ કરી શકાય તેવું OmniRoute ગેટવે (ડિફૉલ્ટરૂપે `http://localhost:20128`).
- Node.js 22 અથવા 24.

## ઇન્સ્ટૉલેશન

`opencode.json`માં પ્લગિન ઉમેરો:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

ત્યારબાદ મોડલ્સ `omniroute/<provider>/<model>` તરીકે દેખાય છે; `providerId` તે પ્રીફિક્સ અને
OpenCode જે ઇન્ટિગ્રેશન હેઠળ ક્રેડેન્શિયલ સંગ્રહે છે તેનો id નક્કી કરે છે.

## ક્રેડેન્શિયલ્સ

પ્લગિન નીચેના ત્રણ સ્થળે, આ ક્રમમાં, ગેટવે કી શોધે છે:

1. **તમે OpenCodeમાં કનેક્ટ કરેલું ક્રેડેન્શિયલ.** પ્લગિન એક ઇન્ટિગ્રેશન રજિસ્ટર કરે છે, જેથી
   OpenCodeનો પોતાનો ઑથ ફ્લો કી સંગ્રહી શકે છે. `opencode.json`માં કંઈપણ સંગ્રહાતું નથી — આ વિકલ્પને પ્રાધાન્ય આપો.
2. દરેક પ્રોજેક્ટ માટે ઓવરરાઇડ તરીકે પ્લગિન વિકલ્પોમાં `apiKey`. આ કીને એવી ફાઇલમાં મૂકે છે
   જેને તમે કમિટ કરી રહ્યા હોઈ શકો છો.
3. એન્વાયર્નમેન્ટમાં `OMNIROUTE_API_KEY`.

ત્રણમાંથી એકપણ ઉપલબ્ધ ન હોય તો કૅટલૉગ ખાલી રહે છે અને તમને નિઃશબ્દ ખાલી પિકર આપવાને બદલે
પ્લગિન સ્ટાર્ટઅપ સમયે એક વાર તેની જાણ કરે છે.

### મેનેજમેન્ટ ટોકન એક અલગ કી છે

કોમ્બોઝ, પ્રોવાઇડર હેલ્થ અને એનરિચમેન્ટ (ડિસ્પ્લે નામો, કિંમત, ફ્રી-ટિયર બજેટ્સ)
ગેટવેના `/api/*` એન્ડપૉઇન્ટ્સમાંથી આવે છે, જેને મોટાભાગનાં ડિપ્લોયમેન્ટ્સ ઇન્ફરન્સ કીને બદલે
**મેનેજમેન્ટ** ટોકન વડે સુરક્ષિત કરે છે:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

સેટ ન કરેલું હોય તો `managementReadToken`, `apiKey`નો ઉપયોગ કરે છે. જ્યારે ગેટવે આ ફૉલબૅકને નકારે છે
ત્યારે પણ કૅટલૉગ પ્રકાશિત થાય છે, પરંતુ ડિસ્પ્લે નામોને બદલે કાચા મોડલ ids સાથે, કૅનોનિકલ
ઍલિયસ ડિડુપ્લિકેશન વિના, કિંમત વિના અને કોમ્બોઝ વિના. આવું થાય ત્યારે પ્લગિન દરેક એન્ડપૉઇન્ટ માટે એક વાર ચેતવણી આપે છે,
જેમાં એન્ડપૉઇન્ટ અને શું ગુમ થયું તેનું નામ જણાવે છે — જેથી ક્ષીણ થયેલું પિકર ક્યારેય રહસ્ય ન રહે.

## વિકલ્પો

| કી                               | ડિફૉલ્ટ                                             | નોંધો                                                                                                          |
| -------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                       | પ્રોવાઇડર id, ઇન્ટિગ્રેશન id અને તે પ્રીફિક્સ જેના હેઠળ મોડલ્સ દેખાય છે                                        |
| `baseURL`                        | આવશ્યક                                              | ગેટવે રૂટ, માત્ર `http(s)`; જ્યાં જરૂરી હોય ત્યાં `/v1` સફિક્સ ઉમેરાય છે                                       |
| `apiKey`                         | કનેક્ટ કરેલું ક્રેડેન્શિયલ, પછી `OMNIROUTE_API_KEY` | `/v1/*` માટે ચૅટ કી                                                                                            |
| `managementReadToken`            | `apiKey`નો ઉપયોગ કરે છે                             | `/api/*` માટેની કી — સામાન્ય રીતે સમાન કી **નથી**                                                              |
| `displayName`                    | `"OmniRoute"`                                       | પિકરમાં પ્રોવાઇડરનું નામ                                                                                       |
| `timeoutMs`                      | `10000`                                             | દરેક એન્ડપૉઇન્ટ માટે ફેચ ટાઇમઆઉટ (ઑટો-કોમ્બોઝ 5sનો ઉપયોગ કરે છે)                                               |
| `modelCacheTtlMs`                | `300000`                                            | કૅટલૉગ કૅશ TTL; ડિસ્ક સ્નૅપશૉટ કોલ્ડ સ્ટાર્ટને વૉર્મ કરે છે                                                    |
| `timeouts`                       | `timeoutMs`નો ઉપયોગ કરે છે                          | msમાં દરેક એન્ડપૉઇન્ટ માટેનાં બજેટ્સ: `models`, `combos`, `autoCombos`, `enrichment`                           |
| `enrichment`                     | `true`                                              | નામો, કિંમત અને ફ્રી-ટિયર બજેટ્સ મેળવો                                                                         |
| `providerTag`                    | `true`                                              | ડિસ્પ્લે નામ પહેલાં તે જે અપસ્ટ્રીમ પ્રોવાઇડર તરફ રૂટ કરે છે તેનું નામ ઉમેરો                                   |
| `usableOnly`                     | `false`                                             | ગેટવે જે પ્રોવાઇડર્સને પ્રોવિઝન્ડ તરીકે રિપોર્ટ કરે છે માત્ર તેમને જ રાખો                                      |
| `visibleModels` / `hiddenModels` | `[]`                                                | ચોક્કસ-અથવા-સફિક્સ અલાઉલિસ્ટ્સ; ડિનાયને પ્રાધાન્ય મળે છે                                                       |
| `geminiSanitization`             | `true`                                              | ટૂલ સ્કીમામાંથી Gemini નકારે છે તે JSON-Schema કીવર્ડ્સ દૂર કરો (`$ref` ટૂલ્સ કોઈ ફેરફાર વિના ફૉર્વર્ડ થાય છે) |
| `apiFormat.allowAnthropic`       | `false`                                             | અલાઉલિસ્ટ કરેલા idsને Anthropic API બ્લૉક મારફતે રૂટ કરો                                                       |
| `apiFormat.anthropicModels`      | `[]`                                                | Anthropic તરફ રૂટ કરેલા સંપૂર્ણ મોડલ ids                                                                       |
| `logLevel` / `startupDebug`      | `warn` / `false`                                    | લૉગર વર્બોસિટી                                                                                                 |

## કૅટલોગ કેવી રીતે અદ્યતન રહે છે

કૅટલોગને જરૂર પડે ત્યારે મેળવવામાં આવે છે અને `modelCacheTtlMs` માટે કૅશ કરવામાં આવે છે, તેમજ ડિસ્ક સ્નૅપશૉટ
ગેટવે ઉપલબ્ધ ન હોય ત્યારે છેલ્લે જાણીતો કૅટલોગ ઉપલબ્ધ રાખે છે — આઉટેજના કારણે તમને માત્ર
તાજગીનું જ નુકસાન થાય છે. મોડેલ્સ અને કોમ્બોઝ આવતા જ પ્રકાશિત થાય છે; ઑટો-કોમ્બોઝ, પ્રદાતા
સૂચિ અને સંવર્ધન ઓવરલે ઉપલબ્ધ થતાં જ તેમાં સમાવિષ્ટ થાય છે, જેથી એક ધીમું એન્ડપોઇન્ટ સમગ્ર
પિકરને અટકાવી ન શકે.

નામોમાં ગેટવે પાસે રહેલી માહિતી સામેલ હોય છે: મોડેલ જે અપસ્ટ્રીમ પ્રદાતા તરફ રૂટ થાય છે તે, `[Free]` માર્કર
અને તેની સાથે મળતું બજેટ — જેથી સમાન મોડેલ વેચતા બે કનેક્શન્સને
અલગ ઓળખી શકાય. `"providerTag": false` વડે પ્રિફિક્સ બંધ કરો.

કોઈ મૅન્યુઅલ રિફ્રેશ કમાન્ડ નથી: OpenCode v2 કમાન્ડ્સ પ્રોમ્પ્ટ ટેમ્પ્લેટ્સ છે, કૉલબૅક્સ નહીં,
તેથી પ્લગઇન એવું કમાન્ડ ઉપલબ્ધ કરાવી શકતું નથી. રિફ્રેશ TTLને અનુસરે છે; હોસ્ટને ફક્ત ત્યારે જ ફરી લોડ કરવા
કહેવામાં આવે છે જ્યારે કૅટલોગ અથવા ઓવરલે ખરેખર બદલાયેલ હોય, દરેક રિફ્રેશ વખતે નહીં.

## Gemini પર ટૂલ કૉલિંગ

Gemini એવી આખી રિક્વેસ્ટને નકારે છે જેના ટૂલ ડિક્લેરેશન્સમાં `$schema` અથવા
`additionalProperties` હોય છે અને જવાબમાં `400 INVALID_ARGUMENT` આપે છે. પ્લગઇન આ પ્રદાતાના
Gemini મોડેલ માટે મોકલાતી ટૂલ સ્કીમામાંથી તે કીવર્ડ્સ દૂર કરે છે અને અન્ય દરેક રિક્વેસ્ટને અસ્પર્શિત રાખે છે.
`$ref` ધરાવતું ટૂલ દૂર કરવાની પ્રક્રિયા વિના અસ્પર્શિત રીતે ફૉર્વર્ડ કરવામાં આવે છે, કારણ કે
રેફરન્સ દૂર કરવાથી સ્કીમા "કંઈપણ સ્વીકારવા" જેટલી વ્યાપક બની જશે.
તેને બંધ કરવા માટે `"geminiSanitization": false` સેટ કરો.

## સમસ્યા નિવારણ

| લક્ષણ                                          | કારણ                                                                                                                            |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| પિકરમાં કોઈ OmniRoute મોડેલ દેખાતું નથી        | કોઈ કી ઉકેલાઈ નથી (સ્ટાર્ટઅપ ચેતવણી તપાસો), અથવા ગેટવે ઉપલબ્ધ નથી                                                               |
| રૉ મોડેલ ids, કોઈ કોમ્બોઝ નહીં, કોઈ કિંમત નહીં | મેનેજમેન્ટ એન્ડપોઇન્ટ્સે ટોકન નકાર્યું — `managementReadToken` સેટ કરો                                                          |
| `opencode-<id>/…` પર પિન કરેલું સેશન           | v1 પ્લગઇને `opencode-<id>` પ્રકાશિત કર્યું હતું; v2 `<id>`ને ઉપસર્ગ વિના પ્રકાશિત કરે છે, તેથી `<id>/…` હેઠળ મોડેલ ફરી પસંદ કરો |
