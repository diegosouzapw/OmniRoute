## 1. Antigravity વિરુદ્ધ Antigravity CLI (agy)

બંને પ્રદાતાઓ **સમાન Google બૅકએન્ડ**નો ઉપયોગ કરે છે — એકસમાન OAuth ક્લાયન્ટ, ટોકન રિફ્રેશ, એન્ડપોઇન્ટ્સ અને Google એકાઉન્ટ્સ. તફાવત એ છે કે તમને કયા મોડલ્સ દેખાય છે.

> Googleની અધિકૃત સરખામણી માટે [Antigravity CLIની જાહેરાત](https://antigravity.google/blog/introducing-google-antigravity-cli) જુઓ.

| પાસું                   | `antigravity` (IDE)                                  | `agy` (CLI)                                               |
| ----------------------- | ---------------------------------------------------- | --------------------------------------------------------- |
| **Google પ્રોડક્ટ**     | Antigravity 2.0 / Antigravity IDE                    | Antigravity CLI                                           |
| **બૅકએન્ડ**             | સમાન Google Cloud Code API                           | સમાન Google Cloud Code API                                |
| **OAuth / ટોકન**        | સમાન ક્લાયન્ટ, સમાન રિફ્રેશ                          | સમાન ક્લાયન્ટ, સમાન રિફ્રેશ                               |
| **મોડલ કૅટલૉગ**         | સ્થિર, પસંદ કરેલી સૂચિ (OmniRouteમાં હાર્ડકોડ કરેલી) | Googleમાંથી `:fetchAvailableModels` દ્વારા લાઇવ ચકાસાય છે |
| **Claude મોડલ્સ**       | Sonnet 4.6, Opus 4.6 (દરેકના 4 વેરિઅન્ટ્સ)           | Sonnet 4.6, Opus 4.6 (દરેકના 4 વેરિઅન્ટ્સ)                |
| **Gemini નામકરણ**       | સ્પષ્ટ લેબલ્સ (Low/Medium/High)                      | અપસ્ટ્રીમ IDs (extra-low/low/agent)                       |
| **વધારાના મોડલ્સ**      | `gpt-oss-120b-medium`                                | Googleના વધારાના મોડલ્સનો સમાવેશ થઈ શકે છે                |
| **ડિફૉલ્ટ ઉપયોગનો કેસ** | IDE એકીકરણ (VS Code, JetBrains)                      | CLI / API ઍક્સેસ                                          |
| **ક્વોટા**              | agy સાથે વહેંચાયેલો (સમાન Google એકાઉન્ટ)            | antigravity સાથે વહેંચાયેલો (સમાન Google એકાઉન્ટ)         |

**ઉપલબ્ધ મોડલ્સ (પ્રયોગ દ્વારા ચકાસાયેલ, 2026-07-29)**:

- Gemini: 3.6 Flash, 3.5 Flash, 3.1 Pro, 3 Flash, 2.5 Flash (વિચારના વિવિધ સ્તરો)
- Claude: Sonnet 4.6, Opus 4.6 (દરેકમાં default/low/medium/high વેરિઅન્ટ્સ)
- અન્ય: GPT-OSS 120B Medium
- **Claude Sonnet 5 ઉપલબ્ધ નથી** — માત્ર 4.6 વેરિઅન્ટ્સ સમર્થિત છે

**મોડલ કૅટલૉગ અલગ કેમ છે**: Googleની CLI "ઝડપ અને ઓછા ઓવરહેડ માટે ઑપ્ટિમાઇઝ કરેલી" અને "Gemini મોડલ્સ સાથે સહ-ઑપ્ટિમાઇઝ કરેલી" છે (Googleના અધિકૃત બ્લૉગ અનુસાર). Web/IDE પ્રોડક્ટ "વ્યાપકતા માટે ઑપ્ટિમાઇઝ કરેલી" છે. CLI મોડલ્સને ગતિશીલ રીતે શોધવા માટે `:fetchAvailableModels`નો ઉપયોગ કરે છે, જ્યારે IDE સ્થિર, પસંદ કરેલી સૂચિનો ઉપયોગ કરે છે.

**વ્યવહારમાં**: Gemini મોડલ્સ માટે `agy/` પ્રીફિક્સનો ઉપયોગ કરો (દા.ત. `agy/gemini-3.7-flash-high`). સ્થિર, પસંદ કરેલી સૂચિ માટે `antigravity/`નો ઉપયોગ કરો. બંને સમાન Google બૅકએન્ડનો ઉપયોગ કરે છે, પરંતુ મોડલ્સનાં અલગ નામકરણ રજૂ કરે છે. ક્વોટા વહેંચાયેલો છે — કોઈપણ પ્રદાતાનો ઉપયોગ સમાન Google એકાઉન્ટની મર્યાદાઓમાં ગણાય છે.

## 2. Google One AI Pro: ક્વોટા સિસ્ટમ

> સત્તાવાર ક્વોટાની વિગતો માટે [Antigravity Docs: Plans](https://antigravity.google/docs/plans) અને કિંમતોના નવીનતમ ફેરફારો માટે [Changes to Antigravity Plans](https://antigravity.google/blog/changes-to-antigravity-plans) જુઓ.

Google Antigravity સંદેશાની સંખ્યાને બદલે "કરાયેલ કાર્ય" (કમ્પ્યુટેશનલ વજન) પર આધારિત **દ્વિ-સ્તરીય ક્વોટા**નો ઉપયોગ કરે છે.

### બે સ્તરો

| સ્તર                   | તે શું છે                         | રિફ્રેશ ચક્ર                                                                                   |
| ---------------------- | --------------------------------- | ---------------------------------------------------------------------------------------------- |
| **5-કલાકની સ્પ્રિન્ટ** | "કરાયેલ કાર્ય"નો તાત્કાલિક સંગ્રહ | સત્રમાં પ્રથમ વિનંતી પછી 5 કલાકે રીસેટ થાય છે                                                  |
| **7-દિવસની બેઝલાઇન**   | સાપ્તાહિક મહત્તમ મર્યાદા          | આ મર્યાદા પૂરી થતાં 5-કલાકના રિફ્રેશને અવગણે છે; આગામી 7-દિવસના સમયગાળા સુધી ઍક્સેસ બંધ રહે છે |

**"કરાયેલ કાર્ય"ની ગણતરી કેવી રીતે થાય છે**: એજન્ટનો વધુ ઉપયોગ કરતી ટાસ્ક (દા.ત. "આ સમગ્ર રિપોઝિટરીને રિફેક્ટર કરો") સરળ ટાસ્ક (દા.ત. "આ ફંક્શનને ઠીક કરો") કરતાં ક્વોટા વધુ ઝડપથી વાપરે છે. વપરાશ દર્શાવતું કોઈ રીઅલ-ટાઇમ ડૅશબોર્ડ નથી.

### Gemini અને Non-Gemini મોડલ

- **Gemini મોડલ** (Flash + Pro): API કિંમતના આધારે વપરાતી એક જ રેટ લિમિટ શેર કરે છે. જો Flash, Pro કરતાં 8x સસ્તું હોય, તો તમને 8x વધુ Flash ટોકન મળે છે.
- **Non-Gemini મોડલ** (Claude, GPT-OSS): તેમની **અલગ** રેટ લિમિટ હોય છે. Geminiની ઍક્સેસ બંધ હોય ત્યારે પણ તે ઉપલબ્ધ રહી શકે છે.

### AI ક્રેડિટ્સ (મર્યાદાથી વધુ વપરાશ)

> ક્રેડિટ્સ કેવી રીતે કાર્ય કરે છે તે જાણવા માટે [Google One AI credits](https://support.google.com/googleone/answer/14534406) જુઓ.

જ્યારે બેઝલાઇન ક્વોટા સમાપ્ત થઈ જાય:

- **ક્યારેય નહીં**: ક્વોટા રિફ્રેશ થાય ત્યાં સુધી રાહ જુઓ; "Baseline model quota reached" દર્શાવે છે
- **હંમેશાં**: AI ક્રેડિટ્સનો આપમેળે ઉપયોગ કરો; બેઝલાઇન રિફ્રેશ થતાં ફરી તેના પર સ્વિચ થાય છે

ક્રેડિટ્સ અલગથી ખરીદવામાં આવે છે અને પ્રમાણભૂત API કિંમત પ્રમાણે કપાય છે.

### મુખ્ય વિગતો

- ક્વોટા **એકાઉન્ટ સ્તરે શેર થાય છે** — Antigravity IDE, CLI અને OmniRouteમાં સમાન Google account એક જ ક્વોટા સંગ્રહ શેર કરે છે
- દરેક Google accountનો પોતાનો સ્વતંત્ર ક્વોટા હોય છે — એકથી વધુ એકાઉન્ટ = એકથી વધુ ક્વોટા સંગ્રહ
- AI Pro વપરાશકર્તાઓએ જાણ કરી છે કે સાપ્તાહિક બેઝલાઇન પૂરી થતાં 5-કલાકના રીસેટને બદલે **7-દિવસ માટે ઍક્સેસ બંધ** થાય છે (Googleએ પુષ્ટિ કરી છે કે ઊંચી માંગને કારણે આ ઇરાદાપૂર્વકની ડિઝાઇન છે)

**જ્યારે તમારા એકાઉન્ટનો ક્વોટા સમાપ્ત થાય છે**: OmniRoute કૉમ્બો રૂટમાં આગળના ઉપલબ્ધ એકાઉન્ટ સાથે આપમેળે ફરી પ્રયાસ કરે છે. કોઈ મેન્યુઅલ હસ્તક્ષેપની જરૂર નથી.

## 3. projectId કેવી રીતે મેળવવું

દરેક antigravity/agy કનેક્શન માટે Google Cloud Code `projectId` જરૂરી છે. તેના વિના, `/v1internal:models` એન્ડપોઇન્ટ 404 પરત કરે છે.

### પદ્ધતિ A: આપમેળે (ભલામણ કરેલ)

OmniRoute આ પ્રક્રિયા આપમેળે સંભાળે છે. જ્યારે તમે Dashboard OAuth દ્વારા નવું Google account ઉમેરો છો:

1. OmniRoute ટોકનને રિફ્રેશ કરે છે
2. projectId શોધવા માટે `loadCodeAssist`ને કૉલ કરે છે
3. જો કોઈ પ્રોજેક્ટ અસ્તિત્વમાં ન હોય, તો એક પ્રોજેક્ટ બનાવવા માટે `onboardUser`ને કૉલ કરે છે
4. નવું બનાવેલું projectId મેળવવા માટે `loadCodeAssist`નો ફરી પ્રયાસ કરે છે
5. તેને ડેટાબેઝમાં સાચવે છે

**આ મોટાભાગના એકાઉન્ટ માટે કાર્ય કરે છે** — કોઈ મેન્યુઅલ પગલાંની જરૂર નથી.

### પદ્ધતિ B: agy CLI દ્વારા મેન્યુઅલી

જો આપમેળે શોધ નિષ્ફળ જાય (આ ક્યારે થાય છે તે માટે વિભાગ 5 જુઓ):

```bash
# agy CLI ઇન્સ્ટોલ કરો (જો પહેલેથી ઇન્સ્ટોલ કરેલું ન હોય)
npm install -g @anthropic-ai/agy

# તમારા Google accountથી લૉગ ઇન કરો
agy login

# જે એકાઉન્ટને ઑનબોર્ડિંગની જરૂર છે તે પસંદ કરો
# આ Cloud Code રજિસ્ટ્રેશન શરૂ કરે છે અને projectId સોંપે છે
```

`agy login` સફળ થયા પછી, OmniRoute Dashboardમાં ટોકન રિફ્રેશ કરો. projectId આપમેળે શોધાઈ જશે.

### ચકાસણી કેવી રીતે કરવી

ડેટાબેઝ તપાસો:

```bash
# OmniRoute કન્ટેનરની અંદર
node -e "const db=require('better-sqlite3')('/app/data/storage.sqlite'); \
  console.log(JSON.stringify(db.prepare(\
    'SELECT email,project_id FROM provider_connections WHERE provider=\"agy\"'\
  ).all(), null, 2))"
```

અથવા લૉગ્સ તપાસો:

```
podman logs omniroute 2>&1 | grep "projectId discovered"
```

## 4. OAuth રીડાયરેક્ટ URI

### સમસ્યા

Google OAuth માટે માન્ય રીડાયરેક્ટ URI જરૂરી છે. OmniRoute ડિફૉલ્ટ રૂપે `http://127.0.0.1:20128/callback` (લૂપબૅક) નો ઉપયોગ કરે છે. આ સ્થાનિક બિલ્ડ માટે કાર્ય કરે છે, પરંતુ **રિમોટ ડિપ્લોયમેન્ટ માટે નિષ્ફળ જાય છે** (દા.ત., LAN IP દ્વારા ઍક્સેસ કરાતું સર્વર).

Google એવા રીડાયરેક્ટ URIને નકારે છે જે:

- IP ઍડ્રેસનો ઉપયોગ કરે છે (ડોમેનનો અંત `.com`, `.org` વગેરેમાં થવો આવશ્યક છે)
- OAuth ક્લાયન્ટ કૉન્ફિગમાં નોંધાયેલા રીડાયરેક્ટ URI સાથે મેળ ખાતા નથી

### ઉકેલ

**વિકલ્પ A: બિલ્ટ-ઇન OAuth ફ્લોનો ઉપયોગ કરો (ડિફૉલ્ટ)**

- જ્યારે તમે `localhost` અથવા `127.0.0.1` પરથી OmniRoute ઍક્સેસ કરો ત્યારે કાર્ય કરે છે
- કોઈ કૉન્ફિગરેશનની જરૂર નથી

**વિકલ્પ B: કસ્ટમ OAuth ક્રેડેન્શિયલ્સ**

- તમારા એન્વાયર્નમેન્ટમાં `ANTIGRAVITY_OAUTH_CLIENT_TYPE=web` સેટ કરો
- તમારા પોતાના Google OAuth ક્રેડેન્શિયલ્સ આપો:
  ```
  GOOGLE_OAUTH_CLIENT_ID=your-client-id
  GOOGLE_OAUTH_CLIENT_SECRET=your-client-secret
  ```
- Google Cloud Consoleમાં `https://your-domain.com/callback` ને અધિકૃત રીડાયરેક્ટ URI તરીકે નોંધાવો

**વિકલ્પ C: પ્રારંભિક લૉગિન માટે agy CLIનો ઉપયોગ કરો**

- જે મશીન OmniRouteને ઍક્સેસ કરશે તેના પર `agy login` ચલાવો
- OAuth ફ્લો સ્થાનિક રીતે પૂર્ણ થાય છે અને ટોકન્સ સંગ્રહિત થાય છે
- ડેશબોર્ડ મારફતે કનેક્શનને OmniRouteમાં ઇમ્પોર્ટ કરો

### મર્યાદાઓ

- કસ્ટમ OAuth ક્રેડેન્શિયલ્સ માટે ડોમેન નામ જરૂરી છે (Google રીડાયરેક્ટ URI તરીકે IP ઍડ્રેસ સ્વીકારતું નથી)
- જો તમારી પાસે ડોમેન ન હોય, તો તેના બદલે વિકલ્પ A અથવા Cનો ઉપયોગ કરો

## 5. સમસ્યાનિવારણ: ઑટોમેટિક સેટઅપ નિષ્ફળ જાય ત્યારે

OmniRoute મોટાભાગનાં એકાઉન્ટ્સ માટે projectId શોધ અને ઑનબોર્ડિંગ ઑટોમેટિક રીતે સંભાળે છે. જ્યારે તે નિષ્ફળ જાય છે, ત્યારે સામાન્ય રીતે મૂળ કારણ નીચેનામાંથી કોઈ એક હોય છે:

### એકાઉન્ટનો પ્રદેશ અવરોધિત છે

**લક્ષણ**: `agy login` આ સંદેશ આપે છે: "પાત્રતા તપાસ નિષ્ફળ થઈ: તમારું વર્તમાન એકાઉન્ટ Antigravity માટે પાત્ર નથી, કારણ કે તે હાલમાં તમારા સ્થાન પર ઉપલબ્ધ નથી."

**મૂળ કારણ**: Google એકાઉન્ટ્સમાં નોંધણી સમયે સેટ થયેલ બૅકએન્ડ "Country Association" ફીલ્ડ હોય છે. agy CLI અને Cloud Code API આ ફીલ્ડને કડક રીતે તપાસે છે — જ્યારે વેબ Gemini માત્ર તમારા વર્તમાન IPને તપાસે છે.

> તમારા એકાઉન્ટ સાથે સંકળાયેલ પ્રદેશ તપાસવા અથવા બદલવા માટે [Google Country Association Form](https://policies.google.com/country-association-form)ની મુલાકાત લો.

**વેબ Gemini કાર્ય કરે છે પરંતુ agy કેમ કાર્ય કરતું નથી**:

- વેબ Gemini / Google One: ફક્ત વર્તમાન IP તપાસે છે (પ્રૉક્સીથી કામ થઈ જાય છે)
- agy CLI / Cloud Code API: બૅકએન્ડ Country Association ફીલ્ડ વાંચે છે (પ્રૉક્સી મદદ કરતું નથી)

**ઉકેલ**:

1. US IPનો ઉપયોગ કરતાં હો ત્યારે [Google Country Association Form](https://policies.google.com/country-association-form)ની મુલાકાત લો
2. પ્રદેશ બદલવાની વિનંતી સબમિટ કરો ("હું અલગ દેશમાં રહું છું" પસંદ કરો)
3. Google પ્રક્રિયા પૂર્ણ કરે અને ઇમેઇલ સૂચના મોકલે તે માટે 1-24 કલાક રાહ જુઓ
4. ત્યારબાદ `agy login` સફળ થવું જોઈએ

### એકાઉન્ટમાં કોઈ Cloud Code પ્રોજેક્ટ નથી

**લક્ષણ**: લૉગ્સમાં `loadCodeAssist returned no project id` અને `onboardUser failed (400)` દેખાય છે.

**મૂળ કારણ**: એકાઉન્ટ ક્યારેય Google Cloud Code સાથે નોંધાયેલું નથી અને ઑટોમેટિક ઑનબોર્ડિંગ નિષ્ફળ ગયું છે.

**ઉકેલ**: Cloud Code નોંધણી ટ્રિગર કરવા માટે `agy login` મૅન્યુઅલી ચલાવો, ત્યારબાદ OmniRoute ડેશબોર્ડમાં ટોકન રિફ્રેશ કરો.

### ટોકન સમાપ્ત થઈ ગયું છે અથવા રદ કરવામાં આવ્યું છે

**લક્ષણ**: લૉગ્સમાં 401 ભૂલો અથવા "ટોકન સમાપ્ત થઈ ગયું છે" સંદેશા દેખાય છે.

**ઉકેલ**: ડેશબોર્ડ → પ્રોવાઇડર્સ → agy → રિફ્રેશ આઇકન પર ક્લિક કરીને ટોકન રિફ્રેશ કરો. જો રિફ્રેશ ટોકન પોતે જ રદ કરવામાં આવ્યું હોય, તો તમારે OAuth મારફતે ફરીથી ઑથેન્ટિકેટ કરવું પડશે.
