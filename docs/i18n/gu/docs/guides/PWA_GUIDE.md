OmniRoute સંપૂર્ણપણે ઇન્સ્ટોલ કરી શકાય તેવી Progressive Web App તરીકે ઉપલબ્ધ છે. જ્યારે તમે કોઈપણ મોબાઇલ બ્રાઉઝર — Android (Chrome) અથવા iOS (Safari) — પરથી ડૅશબોર્ડ ઍક્સેસ કરો છો, ત્યારે તમે "હોમ સ્ક્રીન પર ઉમેરો" વિકલ્પ પસંદ કરીને કોઈપણ ઍપ સ્ટોરની જરૂર વિના મૂળ ઍપ જેવો અનુભવ મેળવી શકો છો.

## PWA શું છે?

Progressive Web App, OmniRoute વેબ ડૅશબોર્ડને એવી ઍપમાં ફેરવે છે જે મૂળ મોબાઇલ ઍપ જેવી દેખાય અને અનુભવાય છે. ઇન્સ્ટોલ થયા પછી, તે:

- તમારા હોમ સ્ક્રીન પરથી તેના પોતાના આઇકન સાથે શરૂ થાય છે
- પૂર્ણસ્ક્રીનમાં ખૂલે છે — બ્રાઉઝર ઍડ્રેસ બાર કે ટૅબ UI વિના
- સમર્પિત કનેક્ટિવિટી પેજ સાથે ઑફલાઇન કાર્ય કરે છે
- ઝડપી લોડિંગ માટે સ્ટેટિક ઍસેટ્સ કૅશ કરે છે
- પોર્ટ્રેટ અને લૅન્ડસ્કેપ એમ બંને ઓરિએન્ટેશનને સપોર્ટ કરે છે

## ઇન્સ્ટોલેશન

### Android (Chrome)

1. Chrome માં OmniRoute ડૅશબોર્ડ ખોલો: `http://YOUR_IP:20128`
2. Chrome આપમેળે **"OmniRoute ને હોમ સ્ક્રીન પર ઉમેરો"** બૅનર બતાવશે, અથવા:
   - **⋮** મેનુ (ત્રણ બિંદુઓ) પર ટૅપ કરો → **"હોમ સ્ક્રીન પર ઉમેરો"** અથવા **"ઍપ ઇન્સ્ટોલ કરો"**
3. પ્રોમ્પ્ટની પુષ્ટિ કરો
4. OmniRoute તમારા હોમ સ્ક્રીન પર એક સ્વતંત્ર ઍપ તરીકે દેખાશે

### iOS (Safari)

1. Safari માં OmniRoute ડૅશબોર્ડ ખોલો: `http://YOUR_IP:20128`
2. **શેર** બટન (તીરવાળું બૉક્સ) પર ટૅપ કરો
3. નીચે સ્ક્રોલ કરો અને **"હોમ સ્ક્રીન પર ઉમેરો"** પર ટૅપ કરો
4. તેને નામ આપો (ડિફૉલ્ટ નામ "OmniRoute" છે) અને **ઉમેરો** પર ટૅપ કરો
5. OmniRoute ઍપ આઇકન સાથે તમારા હોમ સ્ક્રીન પર દેખાશે

### ડેસ્કટૉપ (Chrome / Edge)

1. OmniRoute ડૅશબોર્ડ ખોલો
2. ઍડ્રેસ બારમાંના **ઇન્સ્ટોલ આઇકન** પર ક્લિક કરો (અથવા ⋮ → "OmniRoute ઇન્સ્ટોલ કરો...")
3. પ્રોમ્પ્ટની પુષ્ટિ કરો
4. OmniRoute એક સ્વતંત્ર વિન્ડો તરીકે ખૂલશે — કોઈ ટૅબ નહીં, કોઈ ઍડ્રેસ બાર નહીં

## સુવિધાઓ

### પૂર્ણસ્ક્રીન અનુભવ

મૅનિફેસ્ટને `display: "fullscreen"` સાથે કૉન્ફિગર કરવામાં આવ્યું છે, જેનો અર્થ એ છે કે ઇન્સ્ટોલ કરેલી ઍપ સંપૂર્ણ સ્ક્રીનનો ઉપયોગ કરે છે — બ્રાઉઝર ક્રોમ કે સ્ટેટસ બારનું ઓવરલૅપ નહીં. આ ડૅશબોર્ડને ખરેખર મૂળ ઍપ જેવો અનુભવ આપે છે.

### ઑફલાઇન સપોર્ટ

OmniRoute માં એક સર્વિસ વર્કર (`sw.js`) સામેલ છે, જે બુદ્ધિશાળી કૅશિંગ પ્રદાન કરે છે:

| ઍસેટનો પ્રકાર                                            | વ્યૂહરચના                           | વર્તન                                                                                                  |
| -------------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **ઍપ શેલ**                                               | કૅશ-પ્રથમ                           | `/`, `/offline`, મૅનિફેસ્ટ અને આઇકન ઇન્સ્ટોલેશન વખતે પહેલેથી કૅશ થાય છે                                |
| **સ્ટેટિક ઍસેટ્સ** (CSS, JS, છબીઓ, ફોન્ટ્સ)              | કૅશ ફૉલબૅક સાથે નેટવર્ક-પ્રથમ       | નેટવર્કમાંથી નવીનતમ સામગ્રી મેળવે છે; ઑફલાઇન હોય ત્યારે કૅશનો ઉપયોગ કરે છે                             |
| **Next.js બંડલ્સ** (`/_next/`)                           | કૅશ અપડેટ સાથે નેટવર્ક-પ્રથમ        | નેટવર્કમાંથી મેળવે છે અને કૅશ અપડેટ કરે છે; ઑફલાઇન હોય ત્યારે કૅશ કરેલું વર્ઝન આપે છે                  |
| **નેવિગેશન રિક્વેસ્ટ્સ**                                 | બાયપાસ (ક્યારેય ઇન્ટરસેપ્ટ થતી નથી) | HTTP/3→HTTP/2 ફૉલબૅક બ્રાઉઝર સંભાળે છે; નિષ્ક્રિય QUIC સૉકેટ `Response.error()` માં ફેરવાવું જોઈએ નહીં |
| **API / ડૅશબોર્ડ રૂટ્સ** (`/api/`, `/a2a`, `/dashboard`) | બાયપાસ (ક્યારેય કૅશ થતા નથી)        | હંમેશાં સીધા સર્વર પર જાય છે — સર્વિસ વર્કર દ્વારા ક્યારેય ઇન્ટરસેપ્ટ થતા નથી                          |

### ઑફલાઇન પેજ

જ્યારે નેટવર્ક ઉપલબ્ધ ન હોય અને વપરાશકર્તા નવા પેજ પર જાય, ત્યારે સર્વિસ વર્કર એક સમર્પિત `/offline` પેજ પ્રદાન કરે છે, જે:

- સ્પષ્ટ **"કનેક્ટિવિટી સમસ્યા"** સંદેશ બતાવે છે
- રિયલ ટાઇમમાં અપડેટ થતું લાઇવ **ઑનલાઇન/ઑફલાઇન સ્ટેટસ સૂચક** બતાવે છે
- કનેક્ટિવિટી પાછી આવે ત્યારે ફરીથી લોડ કરવા માટે **"કનેક્શનનો ફરી પ્રયાસ કરો"** બટન પ્રદાન કરે છે
- નિદાન માટે **સ્ટેટસ પેજ**ની લિંક આપે છે

### ઍપ આઇકન્સ

OmniRoute દરેક પ્લૅટફૉર્મ માટે ઑપ્ટિમાઇઝ કરેલા આઇકન્સ પ્રદાન કરે છે:

| ફાઇલ                   | કદ               | ઉપયોગ                                       |
| ---------------------- | ---------------- | ------------------------------------------- |
| `icon-512.png`         | 512×512          | Android ઇન્સ્ટોલ પ્રોમ્પ્ટ, સ્પ્લૅશ સ્ક્રીન |
| `apple-touch-icon.png` | 180×180          | iOS હોમ સ્ક્રીન આઇકન                        |
| `icon-192.svg`         | 192×192 (વેક્ટર) | Android ઍડેપ્ટિવ આઇકન                       |
| `apple-touch-icon.svg` | 180×180 (વેક્ટર) | Apple ફૉલબૅક                                |
| `favicon.svg`          | વેક્ટર           | બ્રાઉઝર ટૅબ્સ                               |
| `favicon.ico`          | બહુવિધ કદ        | જૂના બ્રાઉઝર્સ                              |

### આપમેળે રજિસ્ટ્રેશન

સર્વિસ વર્કર રૂટ લેઆઉટમાંના `<PwaRegister />` કમ્પોનન્ટ દ્વારા આપમેળે રજિસ્ટર થાય છે. વપરાશકર્તાએ કોઈ કાર્યવાહી કરવાની જરૂર નથી — બ્રાઉઝર માન્ય મૅનિફેસ્ટ અને સર્વિસ વર્કર શોધે કે તરત જ ઍપ ઇન્સ્ટોલ કરી શકાય તેવી બની જાય છે.

## ટેકનિકલ આર્કિટેક્ચર

### સર્વિસ વર્કર (`public/sw.js`)

કોઈ ફ્રેમવર્ક પર આધારિત ન હોય એવો મૂળભૂત સર્વિસ વર્કર, જેમાં આ સુવિધાઓ છે:

- **ઇન્સ્ટોલ તબક્કો**: ઍપ શેલને અગાઉથી કૅશ કરે છે (રૂટ, ઑફલાઇન પેજ, મેનિફેસ્ટ, આઇકન્સ)
- **ઍક્ટિવેટ તબક્કો**: જૂના કૅશ વર્ઝન સાફ કરે છે અને તમામ ક્લાયન્ટ્સનો કબજો લે છે
- **ફેચ તબક્કો**: રિક્વેસ્ટના પ્રકારના આધારે બુદ્ધિશાળી રૂટિંગ કરે છે (નેવિગેશન, સ્ટેટિક ઍસેટ, API)
- **કૅશ વર્ઝનિંગ**: `omniroute-pwa-v3` — અપડેટ વખતે નવું કૅશ ફરજિયાત બનાવવા માટે આને વધારો

### લેઆઉટ મેટાડેટા (`src/app/layout.tsx`)

રૂટ લેઆઉટ PWA અનુપાલન માટે જરૂરી તમામ મેટા ટૅગ્સ પ્રદાન કરે છે:

- `/manifest.webmanifest` માટેની `manifest` લિંક
- iOS સ્ટૅન્ડઅલોન મોડ માટે `apple-web-app-capable: true`
- `apple-web-app-status-bar-style: black-translucent`
- Android Chrome માટે `mobile-web-app-capable: yes`
- `theme-color: #0b0f1a`
- એક છેડાથી બીજા છેડા સુધી રેન્ડરિંગ માટે `viewport-fit: cover`

### કમ્પોનન્ટ: `PwaRegister`

`src/shared/components/PwaRegister.tsx` પર આવેલું આ ક્લાયન્ટ કમ્પોનન્ટ:

1. માઉન્ટ થતી વખતે ચાલે છે (માત્ર ક્લાયન્ટ-સાઇડ પર)
2. બ્રાઉઝરમાં `serviceWorker` સપોર્ટ છે કે નહીં તે તપાસે છે
3. `/sw.js` ને શાંતિથી રજિસ્ટર કરે છે (ઍપને અવરોધવાનું ટાળવા માટે ભૂલો અવગણવામાં આવે છે)
4. કશું રેન્ડર કરતું નથી (`return null`) — આ માત્ર સાઇડ-ઇફેક્ટ માટેનું કમ્પોનન્ટ છે

## Termux સાથે ઉપયોગ કરો (Android)

Termux મારફતે Android પર OmniRoute ચલાવતી વખતે PWA કોઈ અવરોધ વિના કાર્ય કરે છે:

1. Termuxમાં OmniRoute શરૂ કરો: `npx omniroute`
2. એ જ ફોન પર Chrome ખોલો: `http://localhost:20128`
3. "હોમ સ્ક્રીન પર ઉમેરો" દ્વારા PWA ઇન્સ્ટોલ કરો
4. PWA સ્થાનિક Termux સર્વર સાથે કનેક્ટ થાય છે — બધું ઉપકરણ પર જ ચાલે છે

આ સંયોજનનો અર્થ એ છે કે તમારો Android ફોન **સર્વર** (Termux) અને **ક્લાયન્ટ** (PWA) બંને છે — એક સંપૂર્ણ સ્વયં-સમાવિષ્ટ AI ગેટવે.

## અન્ય ઉપકરણોમાંથી ઉપયોગ કરો

તમારા OmniRoute સર્વરને બ્રાઉઝર દ્વારા ઍક્સેસ કરી શકતા કોઈપણ ઉપકરણ પર PWA ઇન્સ્ટોલ કરો:

- **બીજો ફોન/ટૅબ્લેટ**: `http://PHONE_IP:20128` પર જાઓ અને PWA ઇન્સ્ટોલ કરો
- **લૅપટૉપ**: Chrome/Edge ખોલો અને તેને ડેસ્કટૉપ PWA તરીકે ઇન્સ્ટોલ કરો
- **બ્રાઉઝર ધરાવતું સ્માર્ટ TV**: ડૅશબોર્ડને પૂર્ણ સ્ક્રીનમાં ઍક્સેસ કરો

## કસ્ટમાઇઝેશન

### ઇન્સ્ટન્સનું નામ

PWAનું શીર્ષક `Dashboard → Settings`માં રહેલી **Instance Name** સેટિંગનું પાલન કરે છે. જો તમે તમારા ઇન્સ્ટન્સનું નામ બદલીને "મારું AI ગેટવે" રાખો છો, તો ઇન્સ્ટોલ કરાયેલ PWA એ નામ દર્શાવશે.

### કસ્ટમ ફેવિકોન

જો તમે `Dashboard → Settings` દ્વારા કસ્ટમ ફેવિકોન અપલોડ કરો છો, તો ડેસ્કટૉપ પરનું PWA આઇકન તે કસ્ટમ આઇકનને પ્રતિબિંબિત કરશે. મોબાઇલ હોમ સ્ક્રીન આઇકન્સ અગાઉથી બનાવેલી `icon-512.png` અને `apple-touch-icon.png` ફાઇલોનો ઉપયોગ કરે છે.

## મર્યાદાઓ

- **પુશ સૂચનાઓ નથી** — સર્વિસ વર્કર Push API અમલમાં મૂકતું નથી. તેના બદલે સૂચનાઓ Electron એપ દ્વારા સંચાલિત થાય છે.
- **બૅકગ્રાઉન્ડ સિંક નથી** — ઑફલાઇન ક્રિયાઓને ફરી ચલાવવા માટે કતારમાં મૂકવામાં આવતી નથી. PWA મુખ્યત્વે ડૅશબોર્ડ દર્શાવવા માટે છે.
- **iOS પ્રતિબંધો** — iOS પર Safari તમામ PWA સુવિધાઓને સમર્થન આપતું નથી (દા.ત., ઇન્સ્ટોલ પ્રોમ્પ્ટ મેન્યુઅલ છે અને બૅકગ્રાઉન્ડ સર્વિસ વર્કર્સ મર્યાદિત છે).
- **કૅશનું કદ** — સર્વિસ વર્કર ફક્ત સ્ટેટિક એસેટ્સને કૅશ કરે છે. `/api/` રૂટ્સમાંથી મળતા મોટા પ્રતિસાદ પેલોડ્સ ક્યારેય કૅશ થતા નથી.
- **મોબાઇલ પર કસ્ટમ આઇકન્સ** — સેટિંગ્સમાં ફેવિકોન બદલવાથી મોબાઇલ પર હોમ સ્ક્રીન આઇકન અપડેટ થતું નથી (આ માટે PWA આઇકન્સ ફરીથી જનરેટ કરવા જરૂરી છે).
