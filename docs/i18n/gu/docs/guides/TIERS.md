OmniRoute 352 સમર્થિત પ્રદાતાઓને 3 આર્થિક સ્તરોમાં ગોઠવે છે. દરેક
વિનંતી તેમાંથી ક્રમશઃ પસાર થાય છે, જ્યાં સુધી કોઈ એક સફળતાપૂર્વક પ્રતિસાદ ન આપે — જેથી
ક્યારેય fallback કોડ લખ્યા વિના તમને સૌથી સસ્તો વ્યવહારુ પ્રતિસાદ મળે છે.

## સ્તર 1 — સબ્સ્ક્રિપ્શન

**એવા પ્રદાતાઓ જેમને તમે પહેલેથી જ ચૂકવણી કરો છો.** OmniRoute ક્વોટાની સમયમર્યાદા
સમાપ્ત થાય તે પહેલાં તેનો સંપૂર્ણ ઉપયોગ કરે છે.

| પ્રદાતા                              | શા માટે સ્તર 1                                     |
| ------------------------------------ | -------------------------------------------------- |
| Claude Code OAuth                    | Anthropic Pro/Team — નિશ્ચિત દર, ઘણીવાર વણવપરાયેલો |
| OpenAI Codex (ChatGPT સબ્સ્ક્રિપ્શન) | Plus/Teamમાં Codex ક્વોટા સામેલ છે                 |
| GitHub Copilot                       | પ્રતિ-સીટ — ક્વોટા દર મહિને રીસેટ થાય છે           |
| Cursor IDE                           | Pro પ્લાનનો ક્વોટા                                 |
| Antigravity / Devin Desktop          | બિલ્ટ-ઇન ક્વોટા                                    |

**વ્યૂહરચના**: મોડેલની ક્ષમતાઓને અનુરૂપ દરેક વિનંતીને પહેલાં અહીં રૂટ કરો.
ક્વોટા ટ્રૅકર નજીક આવતા રીસેટ પર નજર રાખે છે અને `reset-aware`
કોમ્બો વ્યૂહરચના તે મુજબ પ્રાથમિકતા આપે છે. સ્તર 1ને પહેલાં રૂટ કરવા અને ક્વોટા સમાપ્ત થતાં જ
ચૂકવેલાં સ્તરો પર જવા માટે `auto/thrifty` id વાપરો — અથવા પ્લાનમાં સમાવિષ્ટ
ક્ષમતા સુધી મર્યાદિત રહેવા અને તે ઉપલબ્ધ ન હોય તો નિષ્ફળ થવા માટે `auto/subscription`
વાપરો. [સબ્સ્ક્રિપ્શન-પ્રથમ રૂટિંગ](../routing/SUBSCRIPTION_LADDER.md) જુઓ.

## સ્તર 2 — સસ્તું

**1M ટોકન દીઠ $1થી ઓછી કિંમત ધરાવતા પ્રતિ-ટોકન ચુકવણીવાળા પ્રદાતાઓ.** વધુ વોલ્યુમવાળા કામ
માટે અથવા સ્તર 1ના ક્વોટાની મર્યાદા પૂરી થયા પછી ઉપયોગ માટે અનામત.

| પ્રદાતા                        | કિંમત (ઇનપુટ/આઉટપુટ) | ક્ષમતાઓ            |
| ------------------------------ | -------------------- | ------------------ |
| DeepSeek V4 Pro                | 1M દીઠ $0.27 / $1.10 | કોડ, તર્કશક્તિ     |
| GLM-4.5                        | 1M દીઠ $0.60 / $2.20 | લાંબો કોન્ટેક્સ્ટ  |
| MiniMax M1                     | 1M દીઠ $0.20 / $1.10 | ઝડપ                |
| Qwen Coder                     | 1M દીઠ $0.30 / $1.20 | કોડ                |
| OpenRouter (કિંમત-ઑપ્ટિમાઇઝ્ડ) | બદલાય છે             | 100+ મોડેલ, ગતિશીલ |

**વ્યૂહરચના**: કોમ્બો `cost-optimized` કાર્યની ક્ષમતા ફિલ્ટર
(વિઝન, JSON મોડ, ટૂલ્સ, મહત્તમ કોન્ટેક્સ્ટ)ને અનુરૂપ સૌથી ઓછા $/ટોકનવાળું મોડેલ પસંદ કરે છે.

## સ્તર 3 — મફત

**શૂન્ય-ખર્ચવાળા પ્રદાતાઓ** — મફત સ્તરો, ક્રેડિટ પ્રોગ્રામ્સ, OAuth દૈનિક ક્વોટા.

| પ્રદાતા          | મફત ક્વોટા / ક્રેડિટ્સ             |
| ---------------- | ---------------------------------- |
| Kiro AI          | મફત Claude સ્તર (ઉદાર વાજબી-ઉપયોગ) |
| OpenCode Free    | કોઈ auth નહીં, ઉદાર દર મર્યાદાઓ    |
| Qoder            | મફત OAuth                          |
| Google Vertex AI | નવા એકાઉન્ટ માટે $300ની ક્રેડિટ્સ  |
| Amazon Q         | AWS વપરાશકર્તાઓ માટે મફત સ્તર      |
| Pollinations     | ખુલ્લી જાહેર API                   |
| Cloudflare AI    | Workers AIનું મફત સ્તર             |

**વ્યૂહરચના**: જ્યારે સ્તર 1+2 નિષ્ફળ જાય અથવા `useFreeOnly=true` સેટ કરેલું હોય,
ત્યારે બજેટ મર્યાદા સાથેનો કોમ્બો `auto` અહીં રૂટ કરે છે. મફત પ્રદાતાઓની
દર મર્યાદાઓ ઘણીવાર ઓછી હોય છે — circuit breaker તેમને backoff બાદ ફરી કાર્યરત કરે છે.

## સ્તરોનું કૉન્ફિગરેશન

ડૅશબોર્ડ → **સ્તરો** → તમારા પ્રદાતાઓ ફાળવો. ડિફૉલ્ટ્સ (`tierDefaults.json`માંથી) સમજદારીપૂર્ણ
છે; જ્યારે તમારી પાસે પ્રાથમિકતા આપવા માટે ચોક્કસ સબ્સ્ક્રિપ્શન્સ અથવા બાકાત રાખવા માટે પ્રદાતાઓ હોય ત્યારે તેને સંપાદિત કરો.

Auto-Comboનું 16-પરિબળ સ્કોરિંગ પણ સ્તરને ધ્યાનમાં લે છે. જુઓ
[`docs/routing/AUTO-COMBO.md`](../routing/AUTO-COMBO.md).

## ટેલિમેટ્રી

ડૅશબોર્ડ → **વપરાશ** પ્રતિ દિવસ, પ્રતિ સ્તર વપરાયેલા ટોકન્સ દર્શાવે છે. આનો ઉપયોગ આ માટે કરો:

- સ્તર 1નો સંપૂર્ણ ઉપયોગ થઈ રહ્યો છે તેની પુષ્ટિ કરો (નહીં તો તમે સબ્સ્ક્રિપ્શનનું મૂલ્ય વેડફી રહ્યા છો)
- સ્તર 2ના કયા મોડેલ સૌથી વધુ પસંદ થાય છે તે ઓળખો (1-2 સુધી એકત્રિત કરો)
- પરીક્ષણ/અન્વેષણના વર્કલોડ પર સ્તર 3 નાણાં બચાવે છે તેની ચકાસણી કરો

## સામાન્ય પેટર્ન્સ

### સંપૂર્ણપણે મફત વર્કલોડ

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "costInv": 0.5, "tierPriority": 0.3 } } }
}
```

સ્તર 3 તરફ મજબૂત રીતે દોરી જાય છે; સ્તર 3 અનુપલબ્ધ હોય ત્યારે જ સ્તર 2નો ઉપયોગ કરે છે.

### સસ્તા fallback સાથે સબ્સ્ક્રિપ્શન-પ્રથમ

```json
{
  "strategy": "priority",
  "targets": [
    { "provider": "claude-code-oauth", "weight": 1 },
    { "provider": "deepseek", "weight": 1 },
    { "provider": "kiro", "weight": 1 }
  ]
}
```

સ્તર 1 → સ્તર 2 → સ્તર 3ને અનુરૂપ સ્પષ્ટ ક્રમબદ્ધ સૂચિ.
