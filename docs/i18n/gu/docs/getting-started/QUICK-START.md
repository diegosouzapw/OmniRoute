## પગલું 1: OmniRoute ઇન્સ્ટોલ કરો

તમારી પસંદગીની પદ્ધતિ પસંદ કરો:

### વિકલ્પ A: npm (ભલામણ કરેલ)

```bash
npm install -g omniroute
```

### વિકલ્પ B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` એ સૌથી ઊંચું **પ્રકાશિત** સ્થિર SemVer છે. તે git `main` ને અનુસરતું **નથી**. GitOps માટે `diegosouzapw/omniroute:X.Y.Z` પિન કરો. [ઇમેજ ટૅગ્સ / રિલીઝ ચેનલ્સ](../guides/DOCKER_GUIDE.md#release-channels) જુઓ.

### વિકલ્પ C: સોર્સમાંથી

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## પગલું 2: OmniRoute શરૂ કરો

```bash
omniroute
```

OmniRoute `http://localhost:20128` પર શરૂ થાય છે. ડૅશબોર્ડ આપમેળે ખુલે છે.

---

## પગલું 3: મફત પ્રોવાઇડરને કનેક્ટ કરો

તમે કોઈ પણ ચૂકવણી કર્યા વિના મફત પ્રોવાઇડરને કનેક્ટ કરીને OmniRoute નો ઉપયોગ કરી શકો છો.

### વિકલ્પ A: Kiro (મફત Claude — ક્રેડિટ કાર્ડની જરૂર નથી)

1. `http://localhost:20128` પર ડૅશબોર્ડ ખોલો
2. **પ્રોવાઇડર્સ** → **પ્રોવાઇડર ઉમેરો** પર જાઓ
3. **Kiro AI** પસંદ કરો
4. **કનેક્ટ કરો** પર ક્લિક કરો (API કીની જરૂર નથી!)
5. થઈ ગયું! હવે તમને Claude મૉડલ્સની મફત ઍક્સેસ મળી ગઈ છે.

### વિકલ્પ B: OpenCode Free (પ્રમાણીકરણ વિના)

1. `http://localhost:20128` પર ડૅશબોર્ડ ખોલો
2. **પ્રોવાઇડર્સ** → **પ્રોવાઇડર ઉમેરો** પર જાઓ
3. **OpenCode Free** પસંદ કરો
4. **કનેક્ટ કરો** પર ક્લિક કરો (API કીની જરૂર નથી!)
5. થઈ ગયું! હવે તમને અનેક મૉડલ્સની મફત ઍક્સેસ મળી ગઈ છે.

### વિકલ્પ C: Pollinations (કીની જરૂર નથી)

1. `http://localhost:20128` પર ડૅશબોર્ડ ખોલો
2. **પ્રોવાઇડર્સ** → **પ્રોવાઇડર ઉમેરો** પર જાઓ
3. **Pollinations** પસંદ કરો
4. **કનેક્ટ કરો** પર ક્લિક કરો (API કીની જરૂર નથી!)
5. થઈ ગયું! હવે તમને GPT-5, Claude, Gemini અને અન્ય મૉડલ્સની મફત ઍક્સેસ મળી ગઈ છે.

## પગલું 4: તે કાર્ય કરે છે તેની ચકાસણી કરો

[API કીઝ](http://localhost:20128/dashboard/api-manager)માંથી નવી કી બનાવો. આ કી ફરીથી દેખાશે નહીં, તેથી તેને સાચવી રાખો. નોંધ રાખો કે આ કી ટૂલ્સને OmniRoute ઍક્સેસ કરવા માટે છે, અપસ્ટ્રીમ પ્રોવાઇડર્સને ઍક્સેસ કરવા માટે નહીં.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

તમને તમારા કનેક્ટ કરેલા મૉડલ્સની સૂચિ દેખાવી જોઈએ.

## પગલું 5: તમારા IDE અથવા CLI ને OmniRoute તરફ નિર્દેશિત કરો

તમારા IDE અથવા CLI ટૂલમાં આ સેટ કરો:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

બસ એટલું જ! હવે તમારું IDE પ્રોવાઇડરની આપમેળે પસંદગી સાથે OmniRoute નો ઉપયોગ કરે છે.

### IDE ઉદાહરણ: VSCode/Continue.dev

1. VSCode માં [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) એક્સ્ટેન્શન ઇન્સ્ટોલ કરો.
2. નીચેની લાઇનો ઉમેરવા માટે તમારું `~/.continue/config.yaml` અપડેટ કરો:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev ચૅટ પેનમાં `OmniRoute - Auto` પસંદ કરો અને તમે OmniRoute ને વિનંતીઓ મોકલશો.
4. (વૈકલ્પિક) વાચક માટે અભ્યાસ — તમારા IDE પાસે અન્ય તમામ પહેલેથી બનાવેલા કૉન્ફિગરેશન્સ સાથે `config.yaml` અપડેટ કરાવો 😊

### CLI ઉદાહરણ: Codex CLI

1. તમારી ઑપરેટિંગ સિસ્ટમમાં એન્વાયર્નમેન્ટ વેરિએબલને કાયમી રીતે સેટ કરો.
   macOS/Linux માટે (તમારા `~/.bashrc` અથવા `~/.zshrc` માં ઉમેરો):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows (Command Prompt) માટે:

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. હવે OmniRoute માટે કૉન્ફિગર કરેલું Codex શરૂ કરીએ. ચલાવો:

```
omniroute launch-codex --model auto
```

એન્ડપોઇન્ટ અને API કી નિર્દિષ્ટ કરવા માટે તમે `codex` અને કમાન્ડ લાઇન પેરામીટર્સ દ્વારા આ જાતે કરી શકો છો, પરંતુ ઉપરના કમાન્ડ સાથે OmniRoute તમારા માટે બધું સંભાળી લે છે.

આ જ એક-કમાન્ડ લૉન્ચ જેનરિક લૉન્ચર દ્વારા અન્ય CLI માટે પણ કાર્ય કરે છે — `omniroute run <target>` એ `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen` અને `gemini` ને સપોર્ટ કરે છે ([CLI ઇન્ટિગ્રેશન્સ](../guides/CLI-INTEGRATIONS.md) જુઓ).

3. હવે CLI એ OmniRoute ને વિનંતીઓ મોકલવી જોઈએ.

### ખાતરી કરો કે તમારું ટૂલ OmniRoute તરફ રૂટ થઈ રહ્યું છે

ડાબી સાઇડબારમાંથી [મોનિટરિંગ/લૉગ્સ](http://localhost:20128/dashboard/logs) પર ક્લિક કરીને તમે વિનંતીની વિગતો જોઈ શકો છો. આગળ ક્લિક કરવાથી તમને વધુ વિગતો જોવા મળશે. વધારાની નોંધ તરીકે, તમારા મનપસંદ હાર્નેસમાંથી કઈ માહિતી મોકલવામાં આવે છે તે પણ તમે જોઈ શકો છો. શૈક્ષણિક અને ડિબગિંગના દૃષ્ટિકોણથી આ ઉપયોગી છે.

## સામાન્ય પ્રશ્નો

### "શું મને API કીની જરૂર છે?"

**ના!** તમે કોઈ પણ API કી વિના મફત પ્રોવાઇડર્સ (Kiro, OpenCode Free, Pollinations)નો ઉપયોગ કરી શકો છો. ફક્ત તેમને ડૅશબોર્ડમાં કનેક્ટ કરો.

### "`auto` શું છે?"

`auto` OmniRoute ને દરેક વિનંતી માટે શ્રેષ્ઠ પ્રોવાઇડર આપમેળે પસંદ કરવાનું કહે છે. તે ઝડપ, ખર્ચ, ગુણવત્તા અને ઉપલબ્ધતાને ધ્યાનમાં લે છે. વિગતો માટે [Auto-Combo માર્ગદર્શિકા](./AUTO-COMBO-GUIDE.md) જુઓ.

### "તેનો કેટલો ખર્ચ થાય છે?"

OmniRoute પોતે **મફત અને ઓપન-સોર્સ** છે. તમે ફક્ત તમે ઉપયોગ કરતા પ્રોવાઇડર્સ માટે જ ચૂકવણી કરો છો. ઘણા પ્રોવાઇડર્સ પાસે મફત ટિયર્સ છે — [મફત ટિયર્સ માર્ગદર્શિકા](./FREE-TIERS-GUIDE.md) જુઓ.

### "શું હું તેનો ઉપયોગ Claude Code / Cursor / Copilot સાથે કરી શકું?"

**હા!** OmniRoute એ OpenAI ફોર્મેટને સપોર્ટ કરતા કોઈ પણ ટૂલ સાથે કાર્ય કરે છે. ફક્ત બેઝ URL ને `http://localhost:20128/v1` પર સેટ કરો. વિશિષ્ટ સેટઅપ સૂચનાઓ માટે [CLI ટૂલ્સ માર્ગદર્શિકા](../reference/CLI-TOOLS.md) જુઓ.

### "જો કોઈ પ્રોવાઇડર બંધ થઈ જાય તો શું?"

OmniRoute નિષ્ફળ ગયેલા પ્રોવાઇડર્સને આપમેળે છોડી દે છે અને પછીના પ્રોવાઇડરને અજમાવે છે. તમારે કંઈ કરવાની જરૂર નથી. વિગતો માટે [Auto-Combo માર્ગદર્શિકા](./AUTO-COMBO-GUIDE.md) જુઓ.
