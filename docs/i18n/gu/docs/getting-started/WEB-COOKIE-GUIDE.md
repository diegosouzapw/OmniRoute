Web Cookie પ્રદાતાઓ OmniRoute ને API કીને બદલે તમારા હાલના બ્રાઉઝર સત્ર દ્વારા AI સેવાનો ઉપયોગ કરવાની મંજૂરી આપે છે. જ્યારે તમારી પાસે પહેલેથી જ કોઈ સેવાની વેબસાઇટ દ્વારા તેની ઍક્સેસ હોય અને તમે ઇચ્છતા હોવ કે OmniRoute એ જ પ્રમાણિત સત્રનો ઉપયોગ કરે, ત્યારે તેઓ ઉપયોગી છે.

API-કી પ્રદાતાઓથી વિપરીત, Web Cookie પ્રદાતાઓ તમારા બ્રાઉઝર દ્વારા વેબસાઇટને મોકલવામાં આવતા ઓળખપત્રોનો ઉપયોગ કરીને પ્રમાણિત કરે છે.

# શરૂ કરતા પહેલાં

> **મહત્વપૂર્ણ:** ઓળખપત્રો હંમેશાં **સક્રિય નેટવર્ક વિનંતી**માંથી કૉપિ કરો, તમારા બ્રાઉઝરના કૂકી સ્ટોરેજમાંથી **નહીં**.

પ્રમાણીકરણની ઘણી સમસ્યાઓ ખોટી જગ્યાએથી કૂકીઝ કૉપિ કરવાથી થાય છે.

## Cookie Storageમાંથી કૉપિ કરશો નહીં

મોટાભાગનાં બ્રાઉઝર્સ સંગ્રહિત કૂકીઝ આના દ્વારા દર્શાવે છે:

```
DevTools
→ Application (અથવા Storage)
→ Cookies
```

આ કૂકીઝ યોગ્ય દેખાતી હોવા છતાં, તે આ પ્રકારની હોઈ શકે છે:

- જૂની
- અધૂરી
- ફક્ત પ્રમાણિત વિનંતીઓ પર મોકલાતી કૂકીઝ વિનાની

આ મૂલ્યોનો ઉપયોગ કરવાથી, તેઓ માન્ય દેખાતા હોવા છતાં, પ્રમાણીકરણ નિષ્ફળ થઈ શકે છે.

## સક્રિય વિનંતીમાંથી કૉપિ કરો

તેના બદલે, સફળ વિનંતીની કૂકીઝનો ઉપયોગ કરો:

```
DevTools
→ Network
→ પૃષ્ઠ રિફ્રેશ કરો
→ ચેટ અથવા વાર્તાલાપ વિનંતી ખોલો
→ Request Headers
→ Cookie
```

`Cookie` વિનંતી હેડરમાં તમારા બ્રાઉઝરે સફળતાપૂર્વક ઉપયોગ કરેલી ચોક્કસ પ્રમાણીકરણ માહિતી હોય છે.

મોટાભાગના Web Cookie પ્રદાતાઓ માટે, આ જ મૂલ્ય OmniRouteમાં પેસ્ટ કરવું જોઈએ.

# સામાન્ય સેટઅપ

મોટાભાગના Web Cookie પ્રદાતાઓ માટે સેટઅપ પ્રક્રિયા સમાન છે.

1. પ્રદાતાની વેબસાઇટમાં સાઇન ઇન કરો.
2. બ્રાઉઝરના Developer Tools ખોલો.
3. **Network** ટૅબ ખોલો.
4. પૃષ્ઠ રિફ્રેશ કરો.
5. પ્રમાણિત ચેટ અથવા વાર્તાલાપ વિનંતી ખોલો.
6. જરૂરી પ્રમાણીકરણ ઓળખપત્રો કૉપિ કરો.
7. OmniRoute ખોલો.
8. **Providers → Add Provider** પર જાઓ.
9. તમારો Web Cookie પ્રદાતા પસંદ કરો.
10. ઓળખપત્રો પેસ્ટ કરો.
11. **Test Connection** પર ક્લિક કરો.
12. પ્રદાતાને સાચવો.

જરૂરી ચોક્કસ ઓળખપત્રો પ્રદાતા પર આધાર રાખે છે.

# Web Cookie પ્રદાતાઓ શું કરી શકે અને શું કરી શકતા નથી

Web Cookie પ્રદાતાઓ વેબસાઇટના ચેટ ઇન્ટરફેસનો ફરીથી ઉપયોગ કરે છે. તેઓ સત્તાવાર API જેવી ક્ષમતાઓ પ્રદાન કરતા **નથી**.

## સમર્થિત

- તમારા હાલના બ્રાઉઝર સત્રનો ઉપયોગ કરીને પ્રમાણિત કરવું
- તમારા એકાઉન્ટ દ્વારા ઉપલબ્ધ મૉડલ્સને ઍક્સેસ કરવાં
- ચેટ પ્રતિસાદોને સ્ટ્રીમ કરવા
- API કીની જરૂર નથી

## સમર્થિત નથી

- ફંક્શન કૉલિંગ
- ટૂલ કૉલિંગ
- સ્વચાલિત ફાઇલ સંપાદન
- એજન્ટ આધારિત IDE વર્કફ્લો
- ફક્ત API માટેની સુવિધાઓ

આ અપેક્ષિત વર્તન છે અને કોઈ બગ **નથી**.

જો તમને ટૂલ એક્ઝિક્યુશન, સ્વચાલિત ફાઇલ સંપાદન અથવા અન્ય એજન્ટ વર્કફ્લોની જરૂર હોય, તો Web Cookie પ્રદાતાને બદલે **API-કી પ્રદાતા**નો ઉપયોગ કરો.

# માન્યતા અંગેની મર્યાદા

સફળ **Test Connection** અથવા કૂકી માન્યતા માત્ર એટલું ચકાસે છે કે આપેલાં ઓળખપત્રો અપેક્ષિત ફોર્મેટમાં હોવાનું જણાય છે.

Issue #7857નું નિરાકરણ ન આવે ત્યાં સુધી, સફળ માન્યતા પ્રદાતા સફળતાપૂર્વક પ્રમાણિત થશે તેની **ખાતરી આપતી નથી**.

જો પ્રમાણીકરણ હજુ પણ નિષ્ફળ જાય, તો ખાતરી કરો કે તમે ઓળખપત્રો બ્રાઉઝર કૂકી સ્ટોરેજને બદલે સક્રિય નેટવર્ક વિનંતીમાંથી કૉપિ કર્યાં હતાં.

---

# સમસ્યાનિવારણ

## પ્રમાણીકરણ નિષ્ફળ જાય છે

ખાતરી કરો કે ઓળખપત્રો અહીંથી કૉપિ કરવામાં આવ્યાં હતાં:

```
Network
→ Request Headers
→ Cookie
```

અને અહીંથી **નહીં**:

```
Application
→ Cookies
```

---

## કૂકી બ્રાઉઝરમાં કાર્ય કરે છે પરંતુ OmniRouteમાં નહીં

કેટલાક પ્રદાતાઓ એવી કૂકીઝનો સમાવેશ કરે છે જે ફક્ત પ્રમાણિત વિનંતીઓ દરમિયાન જ મોકલવામાં આવે છે.

વાર્તાલાપ સફળતાપૂર્વક ખોલ્યા પછી નવી નેટવર્ક વિનંતીમાંથી ઓળખપત્રો ફરીથી કૉપિ કરો.

---

## સત્ર સમાપ્ત થઈ ગયું

Web Cookie પ્રદાતાઓ તમારા હાલના બ્રાઉઝર સત્રનો ઉપયોગ કરે છે.

જો તમારું બ્રાઉઝર સત્ર સમાપ્ત થઈ જાય અથવા તમે સાઇન આઉટ કરો, તો તમારે ઓળખપત્રોનો નવો સમૂહ કૉપિ કરવો પડશે.

---

## Test Connection સફળ થાય છે પરંતુ વિનંતીઓ નિષ્ફળ જાય છે

Issue #7857નું નિરાકરણ ન આવે ત્યાં સુધી, માન્યતા સફળ થવી એ પ્રમાણીકરણ વિનંતી સફળ થશે તેની ખાતરી આપતું નથી.

આગળ સમસ્યાનિવારણ કરતા પહેલાં નવી પ્રમાણિત વિનંતીમાંથી તમારા ઓળખપત્રો ફરીથી કૉપિ કરો.

# પ્રદાતાનું ઉદાહરણ

સંપૂર્ણ પ્રદાતા-વિશિષ્ટ પગલું-દર-પગલું માર્ગદર્શન માટે, જુઓ:

- **Claude Web** — `docs/providers/CLAUDE_WEB.md`

Claude Web માર્ગદર્શિકા Web Cookie પ્રદાતા માટેની સંપૂર્ણ સેટઅપ પ્રક્રિયા દર્શાવે છે અને સંદર્ભ અમલીકરણ તરીકે કાર્ય કરે છે.

# શ્રેષ્ઠ પ્રથાઓ

- નવી પ્રમાણિત વિનંતીમાંથી ઓળખપત્રો કૉપિ કરો.
- જૂની કૂકીઝનો ફરીથી ઉપયોગ કરવાનું ટાળો.
- Web Cookie પ્રદાતાઓનો ઉપયોગ કરતી વખતે તમારું બ્રાઉઝર સત્ર સક્રિય રાખો.
- કૉપિ કરેલી કૂકીઝને સંવેદનશીલ ઓળખપત્રો તરીકે ગણો.
- જ્યારે તમને ફંક્શન કૉલિંગ અથવા એજન્ટ વર્કફ્લોની જરૂર હોય ત્યારે API-કી પ્રદાતાઓનો ઉપયોગ કરો.
