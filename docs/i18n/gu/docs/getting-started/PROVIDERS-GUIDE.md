## પ્રદાતા શું છે?

પ્રદાતાને **ફોન કેરિયર** જેવો સમજો. જેમ કૉલ કરવા માટે તમારે ફોન કેરિયરની જરૂર પડે છે, તેમ AI મૉડલનો ઉપયોગ કરવા માટે તમારે AI પ્રદાતાની જરૂર પડે છે. OmniRoute એવા ફોન જેવું છે જે **બધા કેરિયર** સાથે કામ કરે છે — તમે તેમની વચ્ચે આપમેળે સ્વિચ કરી શકો છો.

### પ્રદાતાઓના પ્રકાર

| પ્રકાર       | તે શું છે                         | ઉદાહરણો                           | ખર્ચ                              |
| ------------ | --------------------------------- | --------------------------------- | --------------------------------- |
| **મફત**      | કોઈ ચુકવણી જરૂરી નથી              | Kiro, OpenCode Free, Pollinations | $0                                |
| **API કી**   | તમારે API કીની જરૂર છે            | OpenAI, Anthropic, Google         | ઉપયોગ દીઠ ચુકવણી                  |
| **OAuth**    | તમારા એકાઉન્ટ વડે લૉગિન કરો       | Claude Code, GitHub Copilot       | સબ્સ્ક્રિપ્શન                     |
| **વેબ કૂકી** | તમારા બ્રાઉઝર સત્રનો ઉપયોગ કરે છે | ChatGPT Web (Codex), Gemini Web   | $0 (તમારા એકાઉન્ટનો ઉપયોગ કરે છે) |

### વેબ કૂકી પ્રદાતાઓ

સામાન્ય સેટઅપ સૂચનાઓ, મર્યાદાઓ, સમસ્યાનિવારણ અને પ્રદાતા-વિશિષ્ટ પ્રમાણીકરણ માર્ગદર્શન માટે **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** જુઓ.

## ઝડપી શરૂઆત: તમારા પ્રથમ પ્રદાતાને કનેક્ટ કરો

### પ્રથમ વખત માટે વૈકલ્પિક મફત-પ્રદાતા સેટઅપ

પ્રથમ વખતની વિઝાર્ડમાં સ્પષ્ટ **મફત પ્રદાતાઓ સેટ અપ કરો** કાર્ડ આપવામાં આવે છે. તે OmniRouteની પ્રમાણીકરણ-વિના પ્રદાતા રજિસ્ટ્રીમાંથી વર્તમાન
પાત્ર સૂચિ મેળવે છે અને પછી પુષ્ટિ કરતાં પહેલાં તમને દરેક
પ્રદાતાની સમીક્ષા કરવા અને પસંદગી દૂર કરવાની મંજૂરી આપે છે. OmniRoute પ્રદાતાની સાવચેતીની સૂચના અને તેની સાઇટની લિંક બતાવે છે,
જેથી તમે પહેલાં તૃતીય-પક્ષની શરતો, ગોપનીયતા, ઉપલબ્ધતા અને દર મર્યાદાઓની સમીક્ષા કરી શકો.

આ ક્રિયા વૈકલ્પિક છે: વિઝાર્ડ પૂર્ણ કરવાથી ક્યારેય મફત-પ્રદાતા કનેક્શનો મૌન રીતે બનાવવામાં આવતાં નથી.
તે માત્ર હજુ પણ ગેરહાજર હોય તેવા પ્રદાતાઓ બનાવે છે, હાલનાં કસ્ટમાઇઝ કરેલાં કનેક્શનોને
અસ્પર્શિત રાખે છે અને બનાવેલા, પહેલેથી ગોઠવેલા તથા નિષ્ફળ પ્રદાતાઓની અલગથી જાણ કરે છે. આંશિક પરિણામ પછી તમે
માત્ર નિષ્ફળતાઓ માટે સુરક્ષિત રીતે ફરી પ્રયાસ કરી શકો છો.

### વિકલ્પ A: મફત પ્રદાતા (ક્રેડિટ કાર્ડની જરૂર નથી)

1. `http://localhost:20128` પર ડૅશબોર્ડ ખોલો
2. **પ્રદાતાઓ** → **પ્રદાતા ઉમેરો** પર જાઓ
3. આ મફત પ્રદાતાઓમાંથી એક પસંદ કરો:
   - **Kiro AI** — મફત Claude મૉડલ (કોઈ પ્રમાણીકરણ જરૂરી નથી)
   - **OpenCode Free** — મફત GPT મૉડલ (કોઈ પ્રમાણીકરણ જરૂરી નથી)
   - **Pollinations** — મફત GPT-5, Claude, Gemini (કોઈ કી જરૂરી નથી)
   - **LongCat** — 10M ટોકન મફત (એક વખતની ફાળવણી, એકાઉન્ટ + KYC જરૂરી)
   - **Cloudflare AI** — 50+ મૉડલ, 10K ન્યુરૉન/દિવસ
   - **MLX Gemma 26B** — સ્થાનિક Apple Silicon મૉડલ (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — સ્થાનિક Apple Silicon મૉડલ (~9.1 tok/s, ~13.1GB RAM)
4. **કનેક્ટ કરો** પર ક્લિક કરો
5. થઈ ગયું! હવે તમને મફત AI ઍક્સેસ મળી ગઈ છે.

### વિકલ્પ B: API કી પ્રદાતા (ચુકવણીવાળો)

1. પ્રદાતાની વેબસાઇટ પરથી API કી મેળવો:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128` પર ડૅશબોર્ડ ખોલો
3. **પ્રદાતાઓ** → **પ્રદાતા ઉમેરો** પર જાઓ
4. તમારો પ્રદાતા પસંદ કરો
5. તમારી API કી પેસ્ટ કરો
6. **કનેક્ટ કરો** પર ક્લિક કરો
7. થઈ ગયું! હવે તમને તે પ્રદાતાના મૉડલની ઍક્સેસ મળી ગઈ છે.

### વિકલ્પ C: OAuth પ્રદાતા (સબ્સ્ક્રિપ્શન)

1. `http://localhost:20128` પર ડૅશબોર્ડ ખોલો
2. **પ્રદાતાઓ** → **પ્રદાતા ઉમેરો** પર જાઓ
3. તમારો પ્રદાતા પસંદ કરો (દા.ત., Claude Code, GitHub Copilot)
4. **OAuth વડે કનેક્ટ કરો** પર ક્લિક કરો
5. તમારા એકાઉન્ટ વડે લૉગિન કરો
6. થઈ ગયું! હવે તમને તમારા સબ્સ્ક્રિપ્શન મૉડલની ઍક્સેસ મળી ગઈ છે.

### વિકલ્પ D: સ્થાનિક MLX મૉડલ (Apple Silicon)

યુનિફાઇડ મેમરી ધરાવતા Apple Silicon Mac માટે, OmniRoute નિયમિત OpenAI-સુસંગત સ્થાનિક પ્રદાતાઓ તરીકે `mlx-lm.server` દ્વારા ચાલતા સ્થાનિક MLX મૉડલ સાથે કનેક્ટ થવાનું સમર્થન કરે છે.

#### પૂર્વજરૂરિયાતો

- **Apple Silicon Mac** (M1/M2/M3/M4), 24GB+ યુનિફાઇડ મેમરીની ભલામણ કરવામાં આવે છે
- **uv** પૅકેજ મેનેજર: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### ઝડપી શરૂઆત

1. **નિર્ભરતાઓ ઇન્સ્ટૉલ કરો**:

   ```bash
   # જો uv પહેલેથી ઇન્સ્ટૉલ કરેલું ન હોય તો તેને ઇન્સ્ટૉલ કરો
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm ઇન્સ્ટૉલ કરો
   uv pip install mlx-lm
   ```

2. **MLX સર્વરો મૅન્યુઅલી શરૂ કરો** (અલગ ટર્મિનલોમાં):

   ```bash
   # ટર્મિનલ 1: Gemma 4 26B A4B IT-QAT (પોર્ટ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ટર્મિનલ 2: Qwen 3.8 27B MLX Mixed (પોર્ટ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ડૅશબોર્ડમાં કનેક્ટ કરો**:
   - **પ્રદાતાઓ** → **પ્રદાતા ઉમેરો** પર જાઓ
   - **MLX Gemma 26B** અથવા **MLX Qwen 3.8 27B** પસંદ કરો
   - **કનેક્ટ કરો** પર ક્લિક કરો (કોઈ API કી જરૂરી નથી)

4. **OpenCode સાથે ઉપયોગ કરો**:
   ```bash
   # OmniRouteનો ઉપયોગ કરવા માટે OpenCode ગોઠવો
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX મૉડલનો ઉપયોગ કરો
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### મેમરી વ્યવસ્થાપન

**મહત્વપૂર્ણ**: 24GB યુનિફાઇડ મેમરી સાથે એક સમયે માત્ર **એક મોટું MLX મૉડલ ચાલી શકે છે**.

- Gemma 26B: ~15.9GB મહત્તમ મેમરી
- Qwen 3.8 27B: ~13.1GB મહત્તમ મેમરી

તમારે આનું મૅન્યુઅલી વ્યવસ્થાપન કરવું પડશે:

- એક સમયે માત્ર એક MLX સર્વર ચલાવો, અથવા
- બંનેને અલગ મશીનો પર ચલાવો, અથવા
- બીજું શરૂ કરતાં પહેલાં એકને બંધ કરો

OmniRoute MLX સર્વર પ્રક્રિયાઓનું આપમેળે વ્યવસ્થાપન કરતું નથી — તે ફક્ત તમે ગોઠવેલા OpenAI-સુસંગત એન્ડપૉઇન્ટ પર વિનંતીઓ રૂટ કરે છે.

#### ટૂલ કૉલિંગ સમર્થન

બંને મૉડલ OpenAI-સુસંગત ટૂલ કૉલિંગને સમર્થન આપે છે. આની સાથે પરીક્ષણ કરો:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "2+2 કેટલા થાય? calculator ટૂલનો ઉપયોગ કરો."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "ગણતરી કરો", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

| ------------------------ | ---------------------------------------------------------------------------------- |

## પ્રદાતાને કેવી રીતે કનેક્ટ કરવો (પગલું-દર-પગલું)

### પગલું 1: ડૅશબોર્ડ ખોલો

તમારા બ્રાઉઝરમાં `http://localhost:20128` પર જાઓ.

### પગલું 2: પ્રદાતાઓ પર જાઓ

સાઇડબારમાં **પ્રદાતાઓ** પર ક્લિક કરો.

### પગલું 3: પ્રદાતા ઉમેરો પર ક્લિક કરો

**+ પ્રદાતા ઉમેરો** બટન પર ક્લિક કરો.

### પગલું 4: તમારો પ્રદાતા પસંદ કરો

સૂચિ બ્રાઉઝ કરો અથવા તમારા પ્રદાતાને શોધો. તેના પર ક્લિક કરો.

### પગલું 5: ઓળખપત્રો દાખલ કરો

- **મફત પ્રદાતાઓ**: કોઈ ઓળખપત્રોની જરૂર નથી — ફક્ત **કનેક્ટ કરો** પર ક્લિક કરો
- **API કી પ્રદાતાઓ**: તમારી API કી પેસ્ટ કરો
- **OAuth પ્રદાતાઓ**: **OAuth વડે કનેક્ટ કરો** પર ક્લિક કરીને લૉગ ઇન કરો

### પગલું 6: કનેક્શનનું પરીક્ષણ કરો

તે કાર્ય કરે છે તેની ખાતરી કરવા માટે **કનેક્શનનું પરીક્ષણ કરો** પર ક્લિક કરો.

### પગલું 7: પૂર્ણ!

તમારો પ્રદાતા હવે કનેક્ટ થઈ ગયો છે. તમે તેનો ઉપયોગ `model: "auto"` સાથે કરી શકો છો અથવા પ્રદાતાને સીધો નિર્દિષ્ટ કરી શકો છો.

## અનેક પ્રદાતાઓનો ઉપયોગ

OmniRoute **અનેક પ્રદાતાઓ** સાથે શ્રેષ્ઠ રીતે કાર્ય કરે છે. તેનાથી તમને મળે છે:

- **સ્વચાલિત ફૉલબૅક** — જો એક પ્રદાતા નિષ્ફળ જાય, તો OmniRoute પછીના પ્રદાતાનો પ્રયાસ કરે છે
- **ખર્ચ ઑપ્ટિમાઇઝેશન** — OmniRoute દરેક વિનંતી માટે સૌથી સસ્તો પ્રદાતા પસંદ કરે છે
- **ઝડપ ઑપ્ટિમાઇઝેશન** — OmniRoute દરેક વિનંતી માટે સૌથી ઝડપી પ્રદાતા પસંદ કરે છે
- **ગુણવત્તા ઑપ્ટિમાઇઝેશન** — OmniRoute દરેક કાર્ય માટે શ્રેષ્ઠ પ્રદાતા પસંદ કરે છે

### ભલામણ કરેલું સેટઅપ

શ્રેષ્ઠ અનુભવ માટે ઓછામાં ઓછા **3 પ્રદાતાઓ**ને કનેક્ટ કરો:

1. **એક મફત પ્રદાતા** (Kiro, OpenCode Free, અથવા Pollinations) — હંમેશા ઉપલબ્ધ
2. **એક ઝડપી પ્રદાતા** (Groq, Cerebras) — ઝડપી પ્રતિસાદો માટે
3. **એક ગુણવત્તાયુક્ત પ્રદાતા** (OpenAI, Anthropic, Google) — જટિલ કાર્યો માટે

પછી `model: "auto"` નો ઉપયોગ કરો અને OmniRoute દરેક વિનંતી માટે આપમેળે શ્રેષ્ઠ પ્રદાતા પસંદ કરશે.

## સામાન્ય પ્રશ્નો

### "શું OmniRoute નો ઉપયોગ કરવા માટે મારે ચૂકવણી કરવી પડશે?"

**ના!** OmniRoute મફત અને ઓપન-સોર્સ છે. તમે કંઈપણ ચૂકવ્યા વિના મફત પ્રદાતાઓ (Kiro, OpenCode Free, Pollinations) નો ઉપયોગ કરી શકો છો. જો તમે ચૂકવણીવાળા પ્રદાતાઓનો ઉપયોગ કરવાનું પસંદ કરો, તો જ તમારે ચૂકવણી કરવી પડશે.

### "મારે કયા પ્રદાતાથી શરૂઆત કરવી જોઈએ?"

**Kiro AI** થી શરૂઆત કરો — તે મફત છે, તેને API કીની જરૂર નથી અને તે તમને Claude મોડેલ્સની ઍક્સેસ આપે છે. ત્યારબાદ જરૂરિયાત મુજબ વધુ પ્રદાતાઓ ઉમેરો.

### "શું હું એકસાથે અનેક પ્રદાતાઓનો ઉપયોગ કરી શકું?"

**હા!** OmniRoute નો મુખ્ય હેતુ જ આ છે. અનેક પ્રદાતાઓને કનેક્ટ કરો અને દરેક વિનંતી માટે OmniRoute ને શ્રેષ્ઠ પ્રદાતા પસંદ કરવા દેવા માટે `model: "auto"` નો ઉપયોગ કરો.

### "જો કોઈ પ્રદાતા બંધ થઈ જાય તો શું થશે?"

OmniRoute નિષ્ફળ ગયેલા પ્રદાતાઓને આપમેળે છોડી દે છે અને પછીના પ્રદાતાને અજમાવે છે. તમારે કંઈ કરવાની જરૂર નથી.

### "હું પ્રદાતાને કેવી રીતે ડિસ્કનેક્ટ કરી શકું?"

Providers પર જાઓ → પ્રદાતા પર ક્લિક કરો → **Disconnect** પર ક્લિક કરો.

### "શું હું મારી હાલની API કીઓનો ઉપયોગ કરી શકું?"

**હા!** જો તમારી પાસે OpenAI, Anthropic, Google વગેરે માટે પહેલેથી API કીઓ હોય, તો તમે OmniRoute માં તેનો ઉપયોગ કરી શકો છો. પ્રદાતાને કનેક્ટ કરતી વખતે ફક્ત તેમને પેસ્ટ કરો.
