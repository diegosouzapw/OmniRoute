- **fix(responses):** a Chat Completions provider that stopped on the token limit or a content filter now surfaces as `response.incomplete` with `incomplete_details` (`max_output_tokens` / `content_filter`), matching the real Responses API contract, instead of silently reporting `status: "completed"` ([#14806](https://github.com/diegosouzapw/OmniRoute/pull/14806)). A truncated, degenerating generation was previously indistinguishable from a genuine successful completion. Fixed in both Chat→Responses stream translators (`translator/response/openai-responses.ts` and `transformer/responsesTransformer.ts`); upstream mid-stream errors still take priority.
