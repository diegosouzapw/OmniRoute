- **fix(command-code):** route Responses-shaped bodies to `/provider/v1/responses`, where `reasoning: {"effort":"none"}` is honored. The chat endpoint's effort enum is `low|medium|high|xhigh|max` — no disable value — and silently drops a nested `reasoning.effort`, so reasoning-off was impossible for GPT-5.6 and DeepSeek models. Verified live 2026-09-24: `/responses` + effort none → `reasoning_tokens: 0`; `/chat` + `reasoning:{effort:"none"}` → 41 reasoning tokens.
