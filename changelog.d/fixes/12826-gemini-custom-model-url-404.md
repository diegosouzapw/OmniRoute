- **fix(gemini):** build the upstream URL from the payload-rule-rewritten body model and drop the deprecated `thinkingBudget` when a `thinkingLevel` is set ([#12826](https://github.com/diegosouzapw/OmniRoute/pull/12826)) — custom-model aliases such as `gemini-3.7-flash-high` (rewritten by an override rule to `gemini-3.7-flash`) previously 404'd because the executor inserted the original alias into `/models/{model}:generateContent` while the body named the real id. `BaseExecutor.buildUrlForBody()` now derives the URL model from the prepared body (falling back to the executor model when the body carries none, so every other provider is unchanged), chatCore logs the rewrite and keys Gemini RPM/RPD accounting to the wire model, and a Gemini 3.x string `thinkingLevel` supplied by a request or payload rule replaces the deprecated numeric `thinkingBudget` instead of being sent alongside it.
