- **fix(api):** `/v1/models` no longer advertises ids that cannot be used. Claude Code discovery aliases (`claude/…`) now mirror reasoning-effort variants already in the catalog (e.g. `claude/codex/gpt-6-sol-high`), so every listed model is pickable from Claude Code; listing of those variants still follows `OMNIROUTE_DISABLE_THINKING_LEVEL_VARIANTS`. Functional-gateway mirrors are no longer emitted for a model whose owner is connected under an alias prefix (e.g. `cx/…` with a `codex` connection), for the gateway's own models, for OmniRoute-synthesized ids (`claude/…` discovery aliases, `no-think/…` variants), through a gateway disabled in `blockedProviders`, or for models outside the gateway's authoritative live catalog (matched on the full id the gateway would receive, as at request time) — each of those was listed but rejected at request time.
