- **fix(translator):** `/v1/responses` streaming no longer emits `response.output_text.delta` for a message item after its `response.output_item.done` ([#13693](https://github.com/diegosouzapw/OmniRoute/issues/13693)) — upstreams that interleave plain text after a real `tool_calls` delta (deepseek-v4, Kimi-style empty-`tool_calls` payloads) used to strand those deltas on an already-closed item, which Codex CLI rejects as `OutputTextDelta without active item` and whose text silently vanished from `response.completed.output`; post-close text now opens a fresh message item at the next free `output_index` so every done item stays immutable and the tail text reaches the client in full.
