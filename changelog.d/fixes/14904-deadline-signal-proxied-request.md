- **fix(sse):** `/v1/chat/completions`, `/v1/messages` and `/v1/responses` no longer fail with HTTP 500 `Cannot read private member #state` ([#14904](https://github.com/diegosouzapw/OmniRoute/pull/14904)). Next.js hands route handlers without a `dynamic` export a Proxy around the `NextRequest`, and `withDeadlineSignal()` rebuilt it with `new Request(request, init)`, which reads the input's private fields. The wrapped request is now rebuilt from its public accessors (url, method, headers, redirect, body stream). — thanks @TrippyEngineer
