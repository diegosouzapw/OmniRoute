- **fix(livews):** the fresh-install anonymous window on the dashboard WebSocket now also requires the upgrade's real TCP peer to be local. Forwarding headers (`x-forwarded-for` / `x-real-ip`) mark a reverse-proxy or tunnel hop and fail closed, matching `isLoopbackRequest()` on the HTTP routes, so a remote client reaching a loopback-bound pre-setup instance through a tunnel can no longer read the dashboard before setup completes ([#14256](https://github.com/diegosouzapw/OmniRoute/issues/14256)).
