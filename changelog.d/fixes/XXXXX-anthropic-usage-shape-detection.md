Anthropic `usage.input_tokens` excludes prompt-cache reads and writes. Those bodies fell through to the Responses API branch of the usage extractor, which stored `input_tokens` alone while also storing the cache counters. The cost calculator then subtracted the cache from an input that never contained it, so fresh input tokens were billed at $0, and stored input did not match the streaming path. The extractor now recognises an Anthropic Messages body (`type: "message"`) by its shape and stores input + cache read + cache creation, as the streaming path and the native Claude ids already did. Responses API usage (whose `input_tokens` already includes `input_tokens_details.cached_tokens`), OpenAI chat and Gemini usage are unchanged.
