- **fix(dashboard):** the live dashboard WebSocket client now backs off 1s, 2s, 4s, 8s, 16s, then every 30s when the server rejects a session after the upgrade (UNAUTHORIZED, forbidden origin, server full), instead of re-dialing about twice per second forever. Only an accepted session (the server's `welcome` frame) resets the backoff, and events from a superseded socket no longer start a second reconnect loop.
