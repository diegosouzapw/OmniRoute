- **fix(auth):** a request that fails upstream (for example with a 502) no longer makes the next request for the same no-auth model answer `401 No active credentials`: the short model lock now surfaces like a real connection's cooldown, so the request waits it out when a retry wait is configured and otherwise gets a `429` with a `Retry-After`. A 401 or 403 from a no-auth provider, or a refusal that depends on the request itself, also stops starting a token refresh that can only fail, which cost several seconds per request and let repeated failures open the provider-wide refresh breaker for 30 minutes ([#14151](https://github.com/diegosouzapw/OmniRoute/pull/14151)) — thanks @maxmad64bis
