- **fix(cursor):** tool calling through the `cursor` provider works again. Any request whose model invoked a tool hung until `CURSOR_STREAM_TIMEOUT_MS` and returned `502 cursor-agent stream timed out`; when it did not hang, the model reported the OmniRoute tool namespace as unavailable and fell back to Cursor's built-ins, so harnesses such as opencode stalled. The agent protocol is now aligned with the `agent.v1` schema embedded in the Cursor Agent CLI: tools go on `RequestContext.tools` (field 7, not `rules` on field 2) and are advertised as an `McpDescriptor` through `mcp_meta_tool_options`, the blocking `mcp_state_exec_args` (field 36) handshake is answered, `span_context` (field 19) is no longer mistaken for the event variant, Responses-API (flat) tool definitions are read, and a Cursor built-in shell exec is bridged to the client's shell tool instead of failing closed on the timeouts Cursor stamps on every exec.
