- **fix(guardrails):** The Vision Bridge no longer whole-request reroutes an explicitly requested bare model id whose vision capability is unknown. `kimi-for-coding` has no `MODEL_SPECS` entry, so its capability resolved to `null` (unknown) and the guardrail treated unknown exactly like proven text-only, silently answering every image request with `command-code/moonshotai/Kimi-K2.6` on a different provider connection. Unknown capability on a bare, non-combo id now keeps the requested model and describes the images instead, and a successful whole-request reroute is logged at `warn` with the original and substitute model ids. Provider-qualified ids, zero-vision combos, forced modes and `auto/` are unchanged ([#14003](https://github.com/diegosouzapw/OmniRoute/issues/14003))
