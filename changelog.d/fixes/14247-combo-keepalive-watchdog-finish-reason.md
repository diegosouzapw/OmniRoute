- **fix(sse):** the default early-stream keepalive threshold (2 000 ms) equalled the tightest client first-byte watchdog, so combo requests — which always take the default tier, since a combo arrives as a bare name with no provider prefix, and never resolve inside 2 s — had their keepalive byte land at 2 003 ms while the client aborted at 2 011–2 016 ms with zero bytes received (a 499 with nothing diagnosable in it). The default tier is now half the observed watchdog (1 000 ms) and the keepalive cadence is 1 500 ms; the deliberately long slow tier for browser-session and anonymous-fallback providers is unchanged ([#14247](https://github.com/diegosouzapw/OmniRoute/pull/14247))
- **fix(sse):** `normalizeOpenAICompatibleFinishReason()` now maps the Claude `stop_reason` vocabulary onto its exact OpenAI equivalent (`end_turn`/`stop_sequence`/`pause_turn`→`stop`, `tool_use`→`tool_calls`, `refusal`→`content_filter`, `model_context_window_exceeded`→`length`).
