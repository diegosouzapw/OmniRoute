- **fix(api-keys):** adding a token limit to an API key no longer replaces the key's existing limit for the same scope. A key now holds one limit per scope and reset interval, so daily, weekly and monthly limits coexist. Migration 196 rebuilds `api_key_token_limits` with that uniqueness while keeping every limit, token counter and reset log. `POST /api/usage/token-limits` updates by `id` when one is given and returns 409 if that would collide with another limit, or 404 for an unknown id ([#14801](https://github.com/diegosouzapw/OmniRoute/pull/14801)).
