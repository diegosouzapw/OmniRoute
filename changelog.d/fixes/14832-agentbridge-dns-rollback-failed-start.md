- **fix(mitm):** a failed AgentBridge start now reverts the `/etc/hosts` entries it had already provisioned. Provisioning runs before the proxy is spawned, so a spawn failure threw past every teardown step and left each target hostname pointed at `127.0.0.1:<port>` with nothing listening there — whatever else owns that port (Caddy/Vaultwarden on `:443`, for instance) then answered the SNI with a TLS `internal_error` alert, and the hostnames stayed broken machine-wide with no way back from the UI. The rollback is best-effort and never masks the original startup error ([#14832](https://github.com/diegosouzapw/OmniRoute/pull/14832)) — thanks @adevwithpurpose
