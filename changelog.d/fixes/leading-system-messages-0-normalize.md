- **fix(claude):** stop Anthropic rejecting requests where a textual `role:"system"` message lands at `messages[0]`. The mid-conversation-system passthrough (native `claude` provider, Opus with betas) keeps system-role messages inside `messages[]`, but Anthropic treats `messages[0]` as the initial-system-prompt position and 400s **any** system-role message there — not just the empty-directive shape #10457 handled. Once a request carries tools (skill invocation, attached documents), `applyOutputStyles()` unshifts `[OmniRoute Output Styles]...` as a text `system` message onto the front of the array, turning on the mid-conversation path and sending the textual leading system upstream unchanged. Adds `normalizeLeadingSystemMessages()`, which hoists textual leading systems into the top-level `system` parameter (appended after existing blocks so the prompt-cache prefix is undisturbed), keeps the #10457 directive-only relocation, and drops bare `content: []` placeholders.
