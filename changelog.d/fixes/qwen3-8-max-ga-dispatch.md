- **fix(providers):** `opencode-go/qwen3.8-max` now dispatches with the exact id the upstream ships ([#14181](https://github.com/diegosouzapw/OmniRoute/issues/14181)). The global deprecation map still forwarded the GA id to `qwen3.8-max-preview` — true when Alibaba only exposed the preview, but OpenCode Go now ships the GA model, so every request was rewritten and rejected upstream with `401 Model qwen3.8-max-preview is not supported`. The stale mapping is removed, `qwen3.8-max` got its own `MODEL_SPECS` entry (same 1M-context envelope the rewrite used to provide for the preflight), the preview spec no longer aliases the GA id, and opencode-go registers the GA row with the qwen routing flags (`targetFormat: "claude"`, reasoning, no vision). Providers that legitimately expose the preview id (qoder, bailian-coding-plan) are unchanged.
