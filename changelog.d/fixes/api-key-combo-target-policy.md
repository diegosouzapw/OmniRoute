- **fix(api):** honor `allowedCombos` during combo candidate pre-dispatch checks (#12886 follow-up). When an API key had both `allowedCombos` and `allowedModels` restricted, `comboTargetPassesKeyModelPolicy` verified inner targets only against direct model restrictions, causing all targets of an explicitly authorized combo to be skipped with 503/429. Explicit non-auto combo permissions now override the key's direct `allowedModels` and `blockedModels` rules for inner targets, while direct model requests and `auto/*` routers retain their restrictions. Restricted `/v1/models` catalogs now also re-check synthesized effort, no-thinking, and synced-effort IDs against the API-key allow-list.
