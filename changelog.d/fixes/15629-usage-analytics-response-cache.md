- **perf(usage):** cache slow `GET /api/usage/analytics` responses for 60 s per query and share in-flight computations, so repeated dashboard visits (API Manager, Costs, Budget, Analytics) no longer block the event loop — and every other request, including `/v1` traffic — for several seconds on large `usage_history` tables. Tunable with `OMNIROUTE_ANALYTICS_CACHE_TTL_MS` (0 disables) and `OMNIROUTE_ANALYTICS_CACHE_MIN_COMPUTE_MS` ([#15629](https://github.com/diegosouzapw/OmniRoute/pull/15629)) — thanks @HDBR
