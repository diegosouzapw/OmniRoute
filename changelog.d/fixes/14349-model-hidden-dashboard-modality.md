- **fix(models):** the provider-detail model visibility controls work again — after #12172 scoped the dashboard's hide/unhide writes to `modality: "chat"`, the flag is stored in `hiddenModalities.chat` instead of the legacy top-level `isHidden`, but the dashboard reader still inspected only the legacy flag. Chat-hidden models therefore kept rendering as visible: the eye toggle never flipped, "Hide all" left the `{active}/{total} active` count unchanged, the **Hidden** filter stayed empty and hidden models were still offered as Test-all targets, while `/v1/models` (which resolves visibility server-side) did drop them. The precedence rule now lives in one shared module (`isHiddenForModality`) consumed by both the DB layer and the dashboard, so the reader cannot drift from the writer again; legacy rows hidden before #12172 keep reading as hidden ([#14349](https://github.com/diegosouzapw/OmniRoute/pull/14349)) — thanks @SCys
