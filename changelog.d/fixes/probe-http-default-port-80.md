- **fix(proxy):** the reachability fast-fail probe now uses port 80 for `http` proxies that omit one ([#14157](https://github.com/diegosouzapw/OmniRoute/issues/14157)). The WHATWG URL parser drops the port when it equals the scheme default, so `http://user:pass@host:80` reached `defaultPortForScheme` with an empty port and got probed on 8080 — the probe failed, the request was rejected with `Proxy Fast-Fail`, and the healthy connection went into cooldown. `https` (443) and socks5 (1080) defaults were already correct; only the `http` case was wrong. Proxies with explicit non-default ports are unaffected.
