- **fix(translator):** sanitize `$ref` and `$`-prefixed keys in Gemini/Antigravity `function_response.response` payloads. Google Cloud Code and Gemini endpoints parse `$ref` inside `function_response.response` as unresolvable OpenAPI references and fail with HTTP 400 `INVALID_ARGUMENT`. Keys are now renamed to `_ref` during translation, preventing session-bricking 400 loops when tools output JSON Schemas or OpenAPI specs.
