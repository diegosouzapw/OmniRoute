- **fix(cursor):** the Cursor agent transport now honours the configured proxy. It talks raw HTTP/2 through `http2.connect()`, which opens its own socket and therefore bypassed both the global fetch proxy patch and the undici dispatcher — a provider proxy set in the dashboard (and `HTTPS_PROXY`) was silently ignored and Cursor traffic egressed on the host IP. A CONNECT tunnel (TLS-wrapped for `https://` proxies) or a SOCKS4/4a/5/5h tunnel is now opened first and handed to http2 via `createConnection`; proxy selection reuses `resolveProxyForRequest()`, so precedence, `NO_PROXY` and local-address bypasses match every other egress path.
- **fix(cursor):** model discovery now resolves the connection's configured proxy before calling Cursor's `AvailableModels`, rather than sending the import request directly.
