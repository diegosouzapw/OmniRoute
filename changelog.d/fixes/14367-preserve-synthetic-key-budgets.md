- **fix(cost):** orphan health-check repair no longer deletes the spend policy of the deployment-time environment key. `repairOrphanDomainRows` treated `api_keys` as the complete set of `domain_budgets` / `domain_cost_history` owners, but the env-key identity (`OMNIROUTE_API_KEY` / `ROUTER_API_KEY`) authenticates without ever being persisted there — every row it owned looked like a broken reference and was silently deleted on every startup and periodic pass. Since `checkBudget()` is fail-open when no budget row exists, the deletion lifted the spend ceiling instead of tightening it. Synthetic identities (`@/shared/constants/apiKeyIdentities`) are now excluded from the orphan count and delete; genuinely unowned rows are still removed (#14367).
