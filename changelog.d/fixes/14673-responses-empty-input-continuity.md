- **fix(sse):** Chat→Responses requests no longer reach GitHub Copilot `/responses` with neither `input` nor `previous_response_id`, which it rejected with `400 One of "input" or "previous_response_id" or 'prompt' or 'conversation' must be provided`. The translator now injects a placeholder user item when `input` would ship empty (system-only turns, empty messages, orphan-filtered tool results) and no continuity field is present, and the `auto` previous-response-id policy keeps `previous_response_id` when `input` is empty instead of stripping the only continuity field. An explicit `strip` mode still strips.
