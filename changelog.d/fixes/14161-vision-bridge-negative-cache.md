- **fix(guardrails):** `getBestVisionModel()` no longer rescans the whole model catalog on every call when nothing is usable. Only a successful pick was cached, so an install that sends images with no vision-capable describer walked every provider in `PROVIDER_MODELS` and issued a credential lookup per candidate, on the request-serving event loop, for every image of every request. A `null` outcome is now remembered for 30 seconds, dropped as soon as a candidate becomes usable, and can be tuned or disabled with `OMNIROUTE_VISION_BRIDGE_NEGATIVE_CACHE_MS` ([#14161](https://github.com/diegosouzapw/OmniRoute/pull/14161))
