- **fix(usage):** bound the in-flight pending-request map by retained bytes, not entry count alone — the 5000-entry cap bounded COUNT but not MEMORY (each entry retains up to four preview-truncated payloads, landing a worst-case burst near 250 MB). A 256 MB byte ceiling now evicts stale-marked-then-oldest entries after every insert, instead of waiting for the 5-minute age sweep; the UPDATE paths are measured too, so the ceiling cannot no-op. Pending ids also gained a monotonic suffix: the previous 24-bit random suffix collided ~52% of the time across a 5000-request burst.
