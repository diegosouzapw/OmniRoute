- **fix(cli):** generated `omniroute api` commands no longer send a literal `{id}` (or any other `{param}`) to the server. The generator now takes path parameters from the path template itself, so a parameter declared only on the path item or not declared at all still gets its `--<param>` flag and is substituted; generation fails if a brace would survive. The six committed command files that still shipped the literal placeholder (`providers`, `api-keys`, `memory`, `playground`, `provider-nodes`, `usage`) are regenerated ([#PENDING](https://github.com/diegosouzapw/OmniRoute/pull/PENDING)), reported in #15928 by @hongkongkiwi — thanks @pacocartones
