- **refactor(mcp):** `createMcpServer` now registers tools instead of also implementing them (#15159 M-01). The audit found `open-sse/mcp-server/server.ts` mixing a 784-line registration function with twelve handler bodies, and prescribed "file = register + wrap. `handle*` → `tools/canonical/*.ts`". Two of M-01's three parts had already landed with M-06 (#15468), which moved the internal hop into `internalFetch.ts` and closed graph cycles 193/194; this completes the third. The twelve handlers — `handleGetHealth`, `handleListCombos`, `handleGetComboMetrics`, `handleSwitchCombo`, `handleCreateCombo`, `handleCheckQuota`, `handleRouteRequest`, `handleCostReport`, `handleListModelsCatalog`, `handleWebSearch`, `handleXSearch`, `handleWebFetch` — move verbatim into `tools/opsTools.ts`, `tools/inferenceTools.ts` and `tools/webTools.ts`, grouped by the surface each talks to rather than one file per handler, matching how `advancedTools.ts` already holds sixteen. `server.ts` drops 1538 → 1068 lines and reads as registration. The shared coercion helpers moved to a new leaf, `coercions.ts`: `withScopeEnforcement` wraps every registration and also calls `toRecord`, so leaving the helpers inline would have forced `tools/*` to import `server.ts` — reintroducing exactly the edge M-06 removed to close those cycles. `check-cycles` holds at 13, unchanged. No behavioural change: 493/493 MCP vitest tests and 25/25 focused MCP unit tests pass, and 11 of the 12 handler bodies are byte-identical to the originals after comment and whitespace normalisation — the twelfth differs only by the rename below. The local `toNumber` is now `toFiniteNumber` because `no-restricted-syntax` (#7879) bars that name in favour of `src/shared/utils/numeric.ts`, and the old `server.ts` carried a suppression for it; renaming removes the suppression instead of relocating it into a fresh file. Its semantics are unchanged and it is still _not_ the canonical helper, which also parses numeric strings — swapping that in is a real behaviour change and needs its own PR with a test.
