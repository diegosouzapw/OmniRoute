- **feat(backend):** the proxy-registry bulk import ceiling is now an operator setting (`proxyBulkImportLimit`, default 100, hard cap 10,000) instead of a constant hardcoded in two places. Previously `bulkImportProxiesSchema` and the dashboard's pre-flight check each carried their own literal `100`, so raising the limit meant editing source and the two could drift apart — a dashboard that accepted more rows than the API would. Both now resolve the same configured value through `resolveProxyBulkImportLimit`, the route reads it per request so a change applies without a restart, and the "maximum N proxies per import" message interpolates the real limit in all 66 locales rather than stating 100. Values above the cap clamp to the cap rather than falling back to the default, so an operator who asks for more than the ceiling gets the ceiling instead of silently less than they had. Fresh installs are unchanged ([#13917](https://github.com/diegosouzapw/OmniRoute/issues/13917))
