- **feat(api):** `UNPRICED_USAGE_BUDGET_POLICY` feature flag chooses how per-key daily/weekly USD limits treat usage of a model with no configured price. `fail_closed` stays the default and keeps the #13257 verdict; `count_as_zero` counts that usage as $0 and still enforces priced spend. A key blocked only by unpriced usage now gets a 400 that names the unpriced models instead of a low "quota reached (N%)". Admins see the unpriced models on the dashboard home page, via a banner in every UI locale, and in `GET /api/pricing/unpriced-usage` ([#14608](https://github.com/diegosouzapw/OmniRoute/pull/14608), closes [#14604](https://github.com/diegosouzapw/OmniRoute/issues/14604)) — thanks @xiaoyaner0201
