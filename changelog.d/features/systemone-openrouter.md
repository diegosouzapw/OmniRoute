- **feat(api):** `POST /v1/systemone` proxies System One models (TypeSafe Jev: typed `noul` / `choice` / `score` answers with calibrated probabilities, not text) through OpenRouter's System One API using the existing dashboard `openrouter` credentials — no extra key or provider. The body is the TypeSafe shape `{ model, state, questions }`, so the TypeSafe JS/Python SDKs work by pointing their base URL at OmniRoute. Requests honor API-key endpoint (`systemone` category), connection and model restrictions (bare `jev-latest` and `~typesafe/…` are canonicalized to `typesafe/…`), the prompt-injection guard scans `state` and question instructions, and upstream 401/403/429/5xx put the connection into cooldown. Token usage is recorded like other requests, and the exact USD cost OpenRouter returns in `usage.cost` is charged to the API-key budget and exposed in `X-OmniRoute-Response-Cost` (#13987).
