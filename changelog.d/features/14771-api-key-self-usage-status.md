- **feat(api-keys):** `/v1/me/status` now reports today's and this week's USD, request and token usage, a `limits[]` list covering every per-key limit (daily/weekly USD usage limits, budgets, token limits, key quota) measured on its own enforcement window, and masked account labels plus cache-first `accountQuotas` limited to the connections the key can reach and the providers the admin chose to share. The endpoint also accepts `x-api-key`. A per-key `anthropicRateLimitHeaders` mode (`auto` / `forward` / `strip`) controls whether pooled accounts' `anthropic-ratelimit-*` and `anthropic-organization-id` headers reach the client; `auto` forwards them only for keys pinned to one shared connection. The API manager gains the matching controls and a per-key details page with usage, limits, account quotas and editors for token limits and key quota ([#14771](https://github.com/diegosouzapw/OmniRoute/pull/14771)).
