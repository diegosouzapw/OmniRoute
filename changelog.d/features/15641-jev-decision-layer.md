- **feat(jev):** opt-in decision layer (System One / bring-your-own classifier) — routing intent + complexity + safety, compression planning, MCP tool input/output guards, decision-assisted tool search, a cache-read gate, keepalive tuning and tool-loop advisories, wired into the chat/completions, messages and responses surfaces. Off by default: only `OMNIROUTE_JEV_ENABLED=on` engages it — a TypeSafe credential alone changes nothing. Every lane is fail-open: with no credential resolved the behavior is byte-identical to a build without the feature, and each lane can be toggled independently via `OMNIROUTE_JEV_FEATURES`. Runs against TypeSafe's System One wire or any OpenAI-compatible classifier endpoint (`OMNIROUTE_JEV_WIRE`), with a self-request guard so a classifier pointed at OmniRoute's own gateway cannot recurse. Registers the `typesafe` provider (alias `jev`) so the dashboard credential path resolves.
