- **feat(home):** the home Provider Topology now shows a logo-only router core with an electric "kame beam" on active links, a live **Recent Requests** panel (polls `/api/usage/call-logs` every ~3s, gated by the topology appearance toggle + page visibility), a ring that grows with the provider count so many providers no longer overlap, and only surfaces providers with an enabled connection — untested/failing connections no longer clutter the map. The router core is a landscape tile whose in-flight counter sits beside the logo (and holds its slot when idle, so the core cannot drift off the ring's centre as calls start and stop). Nodes are ordered by connection `global_priority` and then by creation time, so adding a provider appends it instead of pushing the existing map around, and a compatible node without a custom `icon_url` now renders the same bundled logo the providers page shows instead of a generic glyph. The error counter and the red edges reflect **every** currently-failing provider (`/api/provider-metrics` gained `topology.errorProviders`); previously only the most recent failure was reported, so a second failure silently cleared the first. A failure also now **expires on its own** after 10s instead of leaving a provider red forever once it stopped being called. All topology animations honour `prefers-reduced-motion` ([#8450](https://github.com/diegosouzapw/OmniRoute/pull/8450)) — thanks @nguyenha935
