- **feat(api-keys):** new `USAGE_LIMIT_IGNORE_UNPRICED` feature flag (Settings → Feature flags, off by default). When on, per-key USD usage quotas count models that have no price as $0 instead of failing closed (#12341), so keys that use subscription or free models without pricing rows are no longer reported and blocked as over quota. Priced spend is still enforced, and `dailyHasUnpricedUsage` / `weeklyHasUnpricedUsage` still report the unpriced usage ([#14799](https://github.com/diegosouzapw/OmniRoute/pull/14799)).
