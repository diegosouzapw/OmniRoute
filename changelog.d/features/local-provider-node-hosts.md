- **feat(network):** new `OMNIROUTE_LOCAL_PROVIDER_NODE_HOSTS` lets operators list hostnames (typically a Docker/Compose service name such as `reranker`) that provider-node routing treats as local: eligible for `/v1/rerank`, `/v1/audio/*` and the local health check without the `*_REMOTE_PROVIDER_NODES` flags, and called directly instead of through `HTTP(S)_PROXY` or a pinned proxy — so a sidecar no longer needs a hard-coded container IP. Empty by default; IP literals and cloud-metadata names are rejected with a warning (#14635)
