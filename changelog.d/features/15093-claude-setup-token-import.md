- **feat(oauth):** Claude Code connections can be added from a `claude setup-token` token. Dashboard → Claude Code → **Add Connection** now opens on a **Setup Token** tab (Browser Login is one click away and no longer starts on open); `POST /api/oauth/claude/import-token` verifies the token with one `max_tokens: 1` request before storing a refresh-less OAuth connection named "Setup token", and re-pasting the same token updates that connection. The connect dialog also resets to its first step with an empty field on every open ([#15093](https://github.com/diegosouzapw/OmniRoute/pull/15093)) — thanks @dpozimski
